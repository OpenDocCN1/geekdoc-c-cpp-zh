## 15.3 Conversions [class.conv]

- Type conversions of class can be defined by constructors and conversion functions. These conversions are user-defined and are used for implicit conversions (Clause 7), for explicit access control (Clause 14). Access control rules (8.4, 8.2).
- User-defined conversions are applied only when they are unambiguous (13.2, 15.3.2). Conversions obey the order of overload resolution (6.4).
- At most one user-defined (constructor or conversion function) is implicitly applied to a single value. Example:
```cpp
struct X {
  operator int();
};
struct Y {
  operator X();
};
Y a;
int b = a;
int c = X(a); // error, a.operatorX() not tried
// OK: a.operatorX()
```
- User-defined conversions are used implicitly only if they are unambiguous. A conversion function in a derived class does not hide a conversion function in a base class unless the two functions convert to the same type. Type overload resolution (16.3.3) selects the best conversion function to perform the conversion. Example:
```cpp
struct X {
    operator int();
}

struct Y : X {
    operator char();
}

void f(Y& a) {
    if (a) // ill-formed: X::operator int() or Y::operator char()
}
```

### 15.3.1 Conversion by constructor [class.conv]

A constructor declared without the function-specifier `explicit` performs a conversion from the types of its parameters (if any) to the type of its class. Such a constructor is called a converting constructor. Example:
```cpp
struct X {
    X(int);
    X(const char*, int = 0);
    X(int, int);
}
```
```cpp
void f(X arg) {
    X a = 1; // a = X(1)
    X b = "Jessie"; // b = X("Jessie",0)
    a = 2;
    f(3);
    f({1, 2});
}
```

Note: An explicit constructor constructs objects just like non-explicit constructors, but does so only where the direct-initialization (11.6) or casts (8.2.9, 8.4) are explicitly used; see also 16.3.1.4. A default constructor may be an explicit constructor; such a constructor will be used to perform default-initialization or value-initialization (11.6). Example:
```cpp
struct Z {
    explicit Z();
    explicit Z(int);
    explicit Z(int, int);
}
```
```cpp
Z a; // OK: default-initialization performed
Z b = {}; // OK: direct-initialization syntax used
Z c = {}; // error: copy-list-initialization
Z a1 = 1; // error: no implicit conversion
Z a3 = Z(1); // OK: direct-initialization syntax used
Z a2(1); // OK: direct-initialization syntax used
```
```cpp
Z* p = new Z(1);
Z* a = (Z)(1);
Z* b = static_cast<Z>(1);
Z* c = { 3, 4 };

// OK: direct initialization syntax used
// OK: explicit cast used
// OK: explicit cast used
// error: no implicit conversion
```

A non-explicit copy/move constructor (15.8) is a converting constructor. Note: An implicitly-declared copy/move constructor is not an explicit constructor; it may be called for implicit type conversions.
