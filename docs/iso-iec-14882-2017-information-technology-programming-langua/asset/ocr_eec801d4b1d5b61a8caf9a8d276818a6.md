# 12.2.6 Nested type names [class.nested.type]

1 Type names obey the same scope as other names. In particular, type names defined within a class definition cannot be used without class qualification. [Example:]

```
struct X {
    typedef int I;
    class Y { /* ... */ };
    I a;
};

 b; // error
Y c; // error
X::Y d; // OK
X::I e; // OK
```

- end example|
