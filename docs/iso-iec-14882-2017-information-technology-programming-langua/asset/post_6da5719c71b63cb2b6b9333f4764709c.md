## 8.3.6 Alignof [expr.alignof]

An alignof expression yields the alignment requirement of its operand. The operand should be a type-id representing a complete object type, or an array reference, or one of those types. The result is an integral constant of type size_t. When alignof is applied to a reference, the result is the alignment of the referenced type. When alignof is applied to an array, the result is the alignment of the element type.
