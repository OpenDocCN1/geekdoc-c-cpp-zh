```
slice_array<>() operator[](slice slicearr);
```

Returns: An object that holds references to elements of the controlled sequence selected by slicearr.
[Example]
valarray<char> v0("abcdefijklmnop", 16);
valarray<char> v1("ABCDE", 5);
v0[slice(2, 5, 3)] = v1;
// v0 = valarray<char>{"AbAdeFghCjDMnEp"}
- end example |

```
valarray operator[](const gslice& slicearr) const;
```

Returns: A valarray containing those elements of the controlled sequence designated by gslice.
[Example]
const valarray<char> v0("abcdefijklmnop", 16);
const size_t lv = { 2, 3 };
const size_t dv = { 7, 2 };
const valarray<size_t> len(lv, 2), str(dv, 2);
// v0[slice(3, len, str)] returns
// v0 = valarray<char>{"abcAErgCijD1EnFp"}
- end example |
