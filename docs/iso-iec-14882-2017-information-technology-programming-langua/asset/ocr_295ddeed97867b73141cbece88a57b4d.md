# ISO/IEC 14882:2017(E)

```
template <class charT, class traits>
ununspecified quoted(basic_string_view<charT, traits> s,
charT delim = charT('\'), charT escape = charT('\\\')); {
```

2 Returns: An object of unspecified type such that it is an instance of basic_ostream with member type char_type the same as charT and member type traits_type, which in the second and third forms is the same as traits, then the expression << quoted(s, delim, escape) behaves as a formatted output (30.7.5.1) of out. This character sequence seq, initially consisting of the following elements:

+   (2.1) delim.

+   (2.2) Each character in s. If the character is equal to escape or delim, as determined by traits_type::eq, first output escape.

+   (2.3) delim.

Let x be the number of elements in seq. Then padding for delim as described in 30.7.5.2.1 is determined as if by calling out.rddbuf()->putn(n), where n is the larger of out.width() and x, and out() is called. The expression << quoted(s, delim) behaves as basic_ostream<charT, traits>& and value out.

```
template <class charT, class traits>
unspecified quoted(basic_string<charT, Allocator<charT>> s,
charT delim = charT('\'), charT escape = charT('\\\')); {
```

3 Returns: An object of unspecified type such that

(3.1) If in is an instance of basic_istream with member types char_type and traits_type the same as charT and traits, respectively, then the expression >> quoted(s, delim, escape) behaves as it extracts the following characters from using operator>>(basic_istream<charT, traits>&) which may throw ios_base::failure(30.5.3.1.1):

+   (3.1.1) --- Skip the first character equal to delim, as determined by traits_type::eq; then

+   (3.1.3) --- Until an unescaped delim character is reached or in, extract characters from in and append them to s, except that an escape is reached, ignore it and append the next character to s.

+   (3.1.4) --- Discard the final character.

+   (3.1.5) --- Restore the flags to its original value.

+   (3.1.2) --- Otherwise, in >> s.

+   (3.2) If out is an instance of basic_ostream with member types char_type and traits_type the same as charT and traits, respectively, then the expression << quoted(s, delim, escape) behaves as the const basic_string<charT, traits, Allocator<charT>>& overload of the quoted function.

The expression in >> quoted(s, delim, escape) shall have type basic_istream<charT, traits>& and value in it. The expression << quoted(s, delim, escape) shall have type basic_ostream<charT, traits>& and value out.
