# ISO/IEC 14882:2017(E)

cv-qualified type is a single conversion, and not the sequence of the pointer to member conversion followed by a qualification conversion (7.5).

A prvalue of "pointer to member of B of type cc T", where B is a class type, can be converted to a prvalue of "pointer to member of D of type cc T", where D is a derived class (Clause 13) of B. If B is an inaccessible (Clause 14), ambiguous (13.2), or virtual (13.1) base class of D, or a base class of a virtual base class of D, a program that necessitates this conversion is illformed. The result of conversion refers to the same member as the pointer before the conversion takes, but it refers to the base class as if it were the derived class. The result refers to the member in D's instance of B. Since the result has type "pointer to member of B of type cc T", induction with a object is valid; the result is the same as if indirecting the pointer to member of B with the subclass of D. The member pointer value is converted to the member pointer value of the destination type.;61

# 7.13 Function pointer conversions [conv.fptr]

A prvalue of "pointer to noexcept function" can be converted to a prvalue of "pointer to noexcept function". The result is a pointer to the function. A prvalue of "pointer to member of type noexcept function" can be converted to a function of type "pointer to member of noexcept function". The result points to the member

Example:

```
void (*p)();
void (**p)(); // error: cannot convert pointer to noexcept function
struct S { typedef void (*p)(); operator p(); };
void (*q) noexcept(); // error: cannot convert pointer to noexcept function
```

- end example

# 7.14 Boolean conversions [conv.bool]

A arithmetic value, unspecified enumeration, pointer, or pointer type can be converted to a prvalue of type bool. A zero value, null pointer or member pointer value is converted to false; any other value is converted to true. For de-initialization (11.6), a prvalue of type std::nullptr_t can be converted to a prvalue of type bool; the resulting value is false.

# 7.15 Integer conversion rank [conv.rank]

Every integer type has an integer conversion rank defined as:

+   No signed integer types other than char and signed char (if char is signed) have the same rank, even if they have the same representation.

+   The rank of long int type shall be greater than the rank of long int, which is greater than the rank of int, which shall be greater than the rank of short int, which shall be greater than the rank of signed char.

+   The rank of any unsigned integer type equal the rank of the corresponding unsigned integer type.

+   The rank of any standard integer type shall be greater than the rank of any extended integer type with the same size.
