# ISO/IEC 14882:2017(E)

3 [Note: For purposes of exposition, class directory_iterator (30.10.13) is shown above as a friend of class directory_entry. Friendship allows the directory_iterator implementation to cache already available attribute values directly into a directory_entry object without the cost of an unneeded call to refresh(). —end note]

4 [Example]:

```
using namespace std;

// use cached last write time to minimize disk accesses
for (auto& x : directory_iterator("")) {
    cout << x.path() << " " << x.last_write_time() << endl;
}

// call to refresh a stale cache
for (auto& x : directory_iterator("")) {
    length_function(x.path()); // cache becomes
    x.refresh();
    cout << x.path() << " " << x.last_write_time() << endl;
}
```

On implementations that do not cache the last write time, loops will return in a potentially expensive call to the std::filesystem::last_write_time function. Implementations that do cache the last write time, the first use will cache the cached value and so not return in a potentially expensive call to the std::filesystem::last_write_time function. The code is portable to any implementation, regardless of whether or not it caches. — example

# 30.10.1.2. directory_entry constructors

[fs.dir.entry.constrs]

```
directory_entry(const path& p);
directory_entry(const path& p, error_code& ec);
```

+   1 Effects: Constructs an object of type directory_entry, then refresh() or refresh(ec), respectively.

+   2 Postconditions: path() == p if no error occurs, otherwise path() == std::filesystem::path();

+   3 Throws: As specified in 30.10.7.

# 30.10.1.2. directory_entry_modifiers

[fs.dir.entry.mods]

```
void assign(const path& p);
void assign(const path& p, error_code& ec);
```

+   1 Effects: Equivalent to pathobject::p = p, then refresh() or refresh(ec), respectively. If an error occurs, the values of any cached attributes are unspecified.

+   2 Throws: As specified in 30.10.7.

```
void replace_filename(const path& p);
void replace_filename(const path& p, error_code& ec);
```

+   3 Effects: Equivalent to pathobject.replace_filename(p), then refresh() or refresh(ec), respectively. If an error occurs, the values of any cached attributes are unspecified.

+   Throws: As specified in 30.10.7.

```
void refresh();
void refresh(error_code& ec) noexcept;
```

+   4 Effects: Stores the current values of any cached attributes of the file p resolves to. If an error occurs, an error is reported (30.10.7) and the values of any cached attributes are unspecified.
