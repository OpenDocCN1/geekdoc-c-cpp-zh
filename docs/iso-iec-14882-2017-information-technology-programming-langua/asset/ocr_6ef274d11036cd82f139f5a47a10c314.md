
+   1. If last2 was not given in the argument list, it denotes first2 + (last1 - first1) below.
2. Returns: If last1 == last2 return false. Otherwise true if every iterator i in the range [first, last1), the following conditions hold: *i == *(first2 + (i - first1)), pred(i, *(first2 + (i - first1))) == false. Otherwise, returns false.
3. Complexity:

+   (3.1) For the overloads with ExecutionPolicy.
if InputIterator1 and InputIterator2 meet the requirements of random access iterators (27.2) and last1 - first1 == last2, then no applications of the corresponding predicate;
(3.2) at least min(last1 - first1, last2 - first2) applications of the corresponding predicate.
(3.2.1) For the overloads with ExecutionPolicy.
if ForwardIterator1 and ForwardIterator2 meet the requirements of random access iterators and last1 - first1 == last2, then no applications of the corresponding predicate;
(3.2.2) min(last1 - first1, last2 - first2) applications of the corresponding predicate.
