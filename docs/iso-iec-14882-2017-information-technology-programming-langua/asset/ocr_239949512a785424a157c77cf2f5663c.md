# ISO/IEC 14882:2017(E)

# 20.5.4.6 Replacement functions [replacement.functions]

+   1 Clauses 21 through 33 and Annex D describe the behavior of numerous functions defined by the C++ standard library. Under, however, circumstances, certain of these descriptions also apply to replacement functions defined in the program (20.3).

+   2 A C++ program may provide the definition for any of the following dynamic memory allocation functions declared in header <new>(6.7.4, 21.6);
```
operator new(std::size_t)
operator new(std::size_t, std::align_val_t)
operator new(std::size_t, const nothrow_t)
operator new(std::size_t, std::align_val_t, const nothrow_t)
operator delete(void)
operator delete(void, std::size_t)
operator delete(void, std::size_t, std::align_val_t)
operator delete(void, std::size_t, const nothrow_t)
operator delete(void, std::size_t, std::align_val_t, const nothrow_t)
operator delete(std::size_t)
operator delete(std::size_t, std::align_val_t)
operator delete(std::size_t, const nothrow_t)
operator delete(std::size_t, std::align_val_t, const nothrow_t)
operator delete(void)
operator delete(void, std::size_t)
operator delete(void, std::size_t, std::align_val_t)
operator delete(void, std::size_t, const nothrow_t)
operator delete(void, std::size_t, std::align_val_t, const nothrow_t)
```

+   3 The program's definitions are used instead of the default versions supplied by the implementation (21.6). Such replacement occurs prior to program startup (6.2, 6.6). The program's declarations shall not be specified as inline. No diagnostic is required.

# 20.5.4.7 Handler functions [handler.functions]

+   1 The C++ standard library provides a definition of the following handler function (Clause 21):

+   (1.1) terminate_handler

+   2 A C++ program may install different handler functions during execution, supplying a pointer to a function defined in the program or the library as argument (to respectively):

+   (2.1) set_new_handler

+   (2.2) set_terminate

See also subclasses 21.6.3, Storage allocation errors, and 21.8, Exception handling.

+   3 A C++ program can get to the current handler function by calling the following functions:

+   (3.1) get_new_handler

+   (3.2) get_terminate

+   4 Calling the set_* and get_* functions shall not incur a data race. A call to any of the set_* functions shall synchronize with subsequent calls to the same set_* and to the corresponding get_* function.
