## 26.2.3 序列容器

序列容器以严格的线性顺序组织一组相同类型的对象。库提供了四种基本序列容器：vector, forward_list, list 和 deque。此外，还提供了 array 作为序列容器，因为它具有固定数量的元素并提供了序列操作。库还提供了容器适配器，可以从基本序列容器或用户定义的其他序列类型轻松构造抽象数据类型，如栈或队列。
