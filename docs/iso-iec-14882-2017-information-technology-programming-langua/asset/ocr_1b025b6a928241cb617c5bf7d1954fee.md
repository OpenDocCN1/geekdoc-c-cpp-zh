# 4.6 Program execution

The semantic descriptions in this document define a parameterized deterministic abstract machine. The machine places no requirement on the structure of conforming implementations. In particular, they need not copy or emulate the structure of the abstract machine. Rather, conforming implementations are required to emulate (only) the observable behavior of the abstract machine as explained below.

Certain aspects and operations of the abstract machine are undefined (defined, for example, size_t). These constitute the parameters of the abstract machine. Each implementation should include documentation describing its characteristics and behavior in these respects.⁷ Such documentation should define the instance of the abstract machine (referred to as the "corresponding instance")

Other aspects and operations of the abstract machine are described in this document as unspecified (for example, evaluation of expressions in a non-initializer if the allocation function fails to allocate memory (8.3.4)). Where possible, this document defines a set of allowable behaviors. The deterministic aspects of the abstract machine. An instance of the abstract machine can have more than one possible execution for a given program and input.

Other operations are described in this document as undefined (for example, the effect of attempting to modify a const). [Note: This document imposes no requirements on the behavior of programs that contain undefined behavior. — end note]

A conforming execution of a well-formed program shall produce the observable behavior as one of the possible executions of the conforming instance of the abstract machine with the same program and the same input. However, if such execution encounters an undefined operation, this document places no requirement on the implementation executing that program with input (not even with regard to operations proceeding the first undefined operation)

An instance of each object with automatic storage duration (6.7.3) is associated with each entry into this block. Object exists and retains its last-stored value during the execution of the block and while the block is active (by a call of function or receipt of a signal).

The requirements on a conforming implementation are:

+   (7.1) Accesses through globals are evaluated strictly according to the rules of the abstract machine.

+   (7.2) At program termination, all data written into files is defined to one of the possible results that the execution of the program to the abstract semantics would have produced.
