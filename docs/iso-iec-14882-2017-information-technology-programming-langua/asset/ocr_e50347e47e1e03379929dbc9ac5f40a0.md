# ISO/IEC 14882:2017(E)

floating-literal: one of
f I F L

A floating literal consists of an optional prefix specifying a base, an integer part, a radix point, a fraction, an e, E, p or O optionally signed exponent, and an optional type suffix. The integer and fraction parts both consist of a sequence of decimal (base ten) digits if there is no prefix, or hexadecimal (base sixteen) digits if the prefix is 0x or O. The floating literal is a **decimal literal** in the former case and a **hexadecimal literal** in the latter case. Optional single quotes in a **digit-sequence** or **hexadecimal-digit-sequence** are allowed when determining its value. *Example*: The floating literals 1.678e-19 and 0x1.67bp-19 are equivalent. Either the integer part or the fraction part (not both) can be omitted. Either the radix point or the E and the exponent (not both) can be omitted from adecimal literal. The integer part, the radix point, and the fraction part (not both) form the **significand** of the floating literal. In a decimal floating literal, the exponent, if present, indicates the power of 10 by which the significand is scaled. In a hexadecimal floating literal, the exponent indicates the power of 2. The floating literals 0xC.6bp+2 have the same value. If the scaled value is in the range of representable values for its type, the larger or smaller representable value near the scaled value, chosen in an implementation-defined manner. The type of a float literal is **double** unless specified by a suffix. The suffixes L and F specify **long** and **float**, respectively. If the scaled value is not in the range of representable values for its type, the program is ill-formed.
