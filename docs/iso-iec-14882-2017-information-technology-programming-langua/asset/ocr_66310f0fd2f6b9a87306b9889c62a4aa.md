# ISO/IEC 14882:2017(E)

Table 90 — Associative container requirements (in addition to
container) (continued)

| Expression | Return type | Assertion/note pre/post-condition | Complexity |
| --- | --- | --- | --- |
| a.erase(q1, q2) | iterator | erases the elements in the range [q1, q2). Returns an iterator pointing to the element pointed to by q2 prior to any elements being erased. If no such element exists, a.end() is returned. | log(a.size()) + N, where N has the value distance(q1, q2). |
| a.clear() | void | a.erase(a.begin(), a.end()) returns true. | linear in a.size(). |
| b.find(k) | iterator const_ | returns an iterator pointing to an element with k, or b.end() if such an element is not found. | logarithmic |
| a_tran.find(ke) | iterator const_ | returns an iterator pointing to an element with key such that c(r, ke) && !c(ke, r), or a_tran.end() if such an element is not found. | logarithmic |
| b.count(k) | size_type | returns the number of elements with key to k | log(b.size()) |
| a_tran.count(ke) | size_type | returns the number of elements with key r such that c(r, ke) && !c(ke, r) | log(a_tran.size()) + a_tran.count(ke) |
| b.lower_bound(k) | iterator const_ | returns an iterator pointing to the first element with key less than k, or b.end() if such an element is not found. | logarithmic |
| a_tran.lower_bound(k1) | iterator const_ | returns an iterator pointing to the first element with key r such that c(kl, r), or a_tran.end() if such an element is not found. | logarithmic |
| b.upper_bound(k) | iterator const_ | returns an iterator pointing to the first element with key greater than k, or b.end() if such an element is not found. | logarithmic |
| a_tran.upper_bound(ku) | iterator const_ | returns an iterator pointing to the first element with key r such that c(ku, r), or a_tran.end() if such an element is not found. | logarithmic |
