# ISO/IEC 14882:2017(E)

# 23.17.6.7 time_point_cast

```
template <class TDuration, class Clock>
constexpr time_point<Clock, Duration>&
time_point_cast(const time_point<Clock, Duration>& t);
```

+   1 Remarks: This function shall not participate in overload resolution unless ToDuration is a specialization of duration.

+   2 Returns:
time_point<Clock, TDuration>(duration_cast<TDuration>(t.time_since_epoch()))

```

floor(const time_point<Clock, Duration>& tp);
```

+   3 Remarks: This function shall not participate in overload resolution unless ToDuration is a specialization of duration.

+   4 Returns: time_point<Clock, TDuration>(floor<TDuration>(tp.time_since_epoch()))

```
template <class TDuration, class Clock, class Duration>

ceil(const time_point<Clock, Duration>& tp);
```

+   5 Remarks: This function shall not participate in overload resolution unless ToDuration is a specialization of duration.

+   6 Returns: time_point<Clock, TDuration>(ceil<TDuration>(tp.time_since_epoch()))


# 23.17.7 Clock

The types defined in this subclass shall satisfy the TrivialClock requirements (23.17.3).

# 23.17.7.1 Class system_clock

Objects of class system_clock represent wall time from the system-realtime clock.

```
class system_clock {
public:
  using rep = ratio<specified, unspecified>;
  using period = ratio<specified, unspecified>;
  using duration = chrono::duration<rep, period>;
  using time_point = chrono::time_point<system_clock>;
  static constexpr bool is_steady = unspecified;

  static time_point now() noexcept;

  // Map to C API
  static time_t to_time_t (const time_point& tp) noexcept;
  static time_point from_time_t(time_t t) noexcept;
};
```
