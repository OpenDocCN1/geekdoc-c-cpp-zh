# 8.3.1 Unary operators

The unary operation performs: the expression to which it is applied be a pointer to an object, or a pointer to a function and the result is an value referring to the object or function c-m. Otherwise, if the type of the expression is “pointer to T”, the result of the result is “T”. [Note: Initialization through a pointer to an incomplete type (other than void) is valid. The value has be obtained in using literals (to initialize a reference, for example); this value must not be converted to a type. see 7.1 — end note]

The result of each following unary operators is a value.

The result of the unary & operator is a pointer. The operand shall be a value or a qualified-id. If the operand is a qualified-id naming a non-static or variant member of some class C with type T, the result has type “pointer to member of class T” with the same cv-qualification. Otherwise, if the type of the expression is T, the result has “pointer to T” and is pointer to the address of the designated object (4.4) or pointer to the designated function. [Note: In particular, the address of an object of type “ce” can be taken via pointer arithmetic (8.7) and comparison (8.9,8.10), an object that array element address is taken in this way is considered to belong to any element of type T. [Example:]

```
struct A { int };
struct B { :: };
int a;
int *p1 = &a; // defined behavior
int *p2 = p1 + 1; // defined behavior, with value true
bool b = *p2; // Note: Pointer from a non-static data member (10.1.1) does not affect the member qualifier with the non-static data member. — end note
```

A pointer to member is only formed when it is used and its operand is a qualified-id in parentheses. [Note: That, the expression &(qualified-id), is enclosed in parentheses, does not form an expression of “pointer to member”. Neither does qualified-id, because there is no implicit conversion from qualified-id for a non-static member function to the “pointer to member function” as there is from an value of type to the “pointer to function” (7.3). Nor is &qualified-id a pointer to member, even within the scope of the unqualified-id’s class. — end note
