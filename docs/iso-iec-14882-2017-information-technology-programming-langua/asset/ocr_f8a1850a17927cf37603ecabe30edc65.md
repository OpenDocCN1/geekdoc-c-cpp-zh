# 29.6.8 Random number distribution class templates

# 29.6.8.1 In general

Each type instantiated from a class template in this section 29.6.8 satisfies the requirements of a random number distribution (29.6.16) type.

Descriptions are provided in this section 29.6.8 only for distribution operations that are not described in 29.6.1 or for operations where there is additional semantic information. In particular, declarations for copy constructors, for assignment operators, for, operators, and for equality and inequality operators are not shown in the synopses.

The algorithms for producing each of the specified distributions are implementation-defined.

The value of each probability density p(z) and of each discrete probability function P(zi) specified in this section is 0 everywhere outside its stated domain.

273 b is introduced to avoid any attempt to produce more randomness than can be held in RealType.
