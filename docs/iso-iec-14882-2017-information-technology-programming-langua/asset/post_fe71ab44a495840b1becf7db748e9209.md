Effects: Characters starting at s until it has extracted the struct tm and remaining format characters used by time_put<>::put to produce one of the following formats, or until it encounters an error. The format depends on the value returned by date_order() as shown in Table 80.

Effects: Characters starting at s until it has extracted the (perhaps abbreviated) name of a weekday or month. If it finds an abbreviation that is followed by characters that could match a full name, it continues until it matches the full name or fails. It sets the appropriate struct tm member.

Returns: An iterator pointing immediately beyond the last character recognized as part of a valid name.

```cpp

```

Effects: Characters starting at s until it has extracted an unambiguous identifier. It is implementation-defined whether two-digit numbers are accepted, and (if so) what century they are assumed to be. The tm->year member accordingly.

Returns: An iterator pointing immediately beyond the last character recognized as part of a year identifier.

```cpp
iter_type_get_date(iter_type s, iter_type end, ios_base& f,
    ios_base::iostate& err, tm t, char modifier) const;
```

Requires: t to point to an object.

Effects: The function starts by evaluating err = ios_base::goodbit. It reads characters starting at s until it encounters an error, or until it has extracted and assigned those struct tm members, and any remaining format characters, corresponding to a conversion directive appropriate for the ISO/IEC 9945 format date, by concatenating '%', the modifier character when non-NULL, the format character. When concatenation fails to yield a complete valid directive the function leaves the object pointed to t unchanged and evaluates err |= ios_base::failbit. When s == end evaluates to true after reading a character the function evaluates err |= ios_base::eofbit.

For complex conversions such as %, X, or X that invoke the modifiers E or 0, when the function is unable to unambiguously determine one or all tm members from the input sequence [s, end], it evaluates err |= ios_base::failbit. In such cases the values of out tm members may be outside their valid range.

Remarks: It is unspecified whether calls to do_get() with the address of the same struct tm object will update the current contents of the object or simply overwrite its. Portable programs should zero out the object before invoking the function.

Returns: An iterator pointing immediately after the last character recognized as part of a valid sequence for the given format and modifier.

### 25.4.5.3.1 time_put members

```cpp
iter_type put(iter_type s, ios_base& str, char_type fill, const tm* t,
              const char* pattern, const char* end);
iter_type put(iter_type s, ios_base& str, char_type fill, const tm* t,
              char format, char modifier = 0);
```

1. Effects: The first step through the sequence from pattern to end, identifying characters that are part of format. Each character that is not part of a sequence is returned immediately, and each sequence, as it is identified, results in a call to do_put; thus elements and other characters are interleaved in the order in which they appear. The first character of each sequence is equal to '%', followed by an optional modifier char and a format spec as defined for strftime. If no modifier is present, mod is zero. For each valid sequence, call do_put(s, str, t, format, modifier).
2. The second call do_put returns the last character produced.
3. [Note: The argument may be used in implementation-defined formats or by derivations. A space character is a reasonable default for this argument.]
4. Returns: An iterator pointing immediately after the last character produced.
