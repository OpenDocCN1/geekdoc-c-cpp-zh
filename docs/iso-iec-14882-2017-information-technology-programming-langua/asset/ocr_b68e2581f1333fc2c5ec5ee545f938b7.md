If a virtual function has a non-throwing exception specification, all declarations, including the definition of, any function that overloads that virtual function in a derived class has a non-throwing exception specification, unless the overriding function is defined as deleted.; | Example:

```
struct B {
    virtual void f() noexcept;
    virtual void g();
    virtual void h() noexcept = delete;
};
```

```
struct D : B {
    void f(); // ill-formed
    void g() noexcept; // OK
    void h() = delete; // OK
```

The declaration of D:f is ill-formed because it has a potentially-throwing exception specification, whereas B:f has a non-throwing exception specification. — end example

An expression is potentially-throwing if

+   (6.1) e is a function (8.2.2) whose postfix-expression has a function type, a pointer-to-function type, with a potentially-throwing exception specification,

+   (6.2) e implicitly invokes a function (such as an overloaded operator, an allocation in a new-expression, a constructor for a function argument, or a destructor if e is a full-expression (4.6) that is potentially-throwing,

+   (6.3) e is a throw-expression cast that refers to a reference type and requires a runtime cast (8.2.7), or

+   (6.4) e is a dynamic-cast expression that casts to a pointer

+   (6.5) e is a type expression applied to a (possibly evaluated) built-in unary * operator applied to a pointer to a polymorphic class

+   any of the initializer-list (4.6) of e is potentially-throwing.

An implicitly-declared constructor for a class X, or a constructor with a noexcept-specifier that is defaulted on its first declaration, has potentially-throwing exception specification if and only if any of the following constructs is potentially-throwing:

+   (7.1) a constructor selected by overload resolution in the implicit definition of the constructor for class X to initialize a properly constructed subobject, or as a default argument expression, or,

+   (7.2) a subexpression of such an initialization, or,

+   (7.3) for a default constructor, a default member initializer.
