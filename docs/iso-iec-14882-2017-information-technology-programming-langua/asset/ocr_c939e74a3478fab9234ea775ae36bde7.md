# 26.5.7 Class template unordered_multiset [unord.multiset.overview]

# 26.5.7.1 Class template unordered_multiset overview

An unordered_multiset is an associative container that supports equivalent keys (instance of unordered_multiset may contain multiple copies of the same key value) and where each element's is the element itself. The unordered_multiset class supports forward iterators.

An unordered_multiset satisfies all of the requirements of a container, of an unordered associative container, and of an allocator-aware container (Table 86). It provides the operations described in the preceding tables for equivalent keys: that, unordered_multiset<Key> supports the a_eq operations and not, the n_umq operations. For a Key type, the iterator and const_iterator types are both constant iterator types. It is unspecified whether they are the same type.

This section only describes operations on unordered_multiset that are not described in the requirement tables, or for which there is additional semantic information.
