# D.6.4 Class strstream

```
namespace std {
  class strstream
  : public basic_iostream<char> {
  public:
    // Types
    using char_type = char;
    using int_type = traits<char>::int_type;
    using pos_type = traits<char>::pos_type;
    using off_type = traits<char>::off_type;

    // constructors/destructor
    strstream();
    strstream(char* s, int n,
      ios_base::openmode mode = ios_base::in|ios_base::out);
    virtual ~strstream();

    // Members
    strstreambuf* rdbuf() const;
    void freeze(bool freezef = true);
    int pcount() const;
    char* str();

  private:
    strstreambuf sb; // exposition only
  };n}
```

The class strstream supports reading and writing from objects of class strstream. It supplies a strstreambuf object to control the associated array. For the sake of exposition, the maintained interface is presented here as:

+   - sb, the strstreambuf object.
