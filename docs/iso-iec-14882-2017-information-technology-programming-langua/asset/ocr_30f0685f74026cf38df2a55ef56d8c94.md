# 26.3.9 Class template forward_list

# 26.3.9.1 Class template forward_list overview

A forward_list is a container that supports forward iterators and allows constant insert and erase operations within the sequence, with storage management handled automatically. Random access to list elements is not supported. *Note: It is intended that forward_list have space or time overhead relative to a hand-written style linked list. Features that would conflict with goal have been omitted.*

A forward_list satisfies all of the requirements of a container (Table 83), except that the size() member is not provided and operator== linear complexity. A forward_list also satisfies all of the requirements for an allocator-aware container (Table 86). In addition, a forward_list satisfies the assign member (Table 87) and all of the other container requirements (Table 88). Descriptions are provided here only for operations on forward_list that are not described in that table or for containers with additional semantics.

*Note: Modifying any list requires access to the element preceding the first of interest, but in a forward_list there is no constant-time way to access a preceding element. For this reason, ranges that are modified, such as those used to erase and splice, must be at the beginning.*
