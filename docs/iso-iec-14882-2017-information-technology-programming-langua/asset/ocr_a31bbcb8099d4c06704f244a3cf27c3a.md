# § 24.3.2.6. basic_string::erase [erase]

```
basic_string& erase(size_type pos = 0, size_type n = npos);
```

+   1 Throws: out_of_range if pos > size();

+   2 Effects: The effective length len of the string to be removed as the smaller of n and size() - pos.

+   3 The function replaces the string controlled by *this with a string of length size() - len whose first pos elements are a copy of the initial elements of the original string controlled by *this, and remaining elements are a copy of the elements of the original string controlled by *this beginning at pos + len.

+   4 Returns: *this.

```
iterator erase(const_iterator p);
```

+   5 Throws: Nothing.

+   6 Effects: Removes the character referred to by p.
