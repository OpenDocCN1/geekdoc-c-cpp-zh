# 9.6.1 The break statement

The break statement shall only occur in an iteration-statement or a switch statement of the smallest iteration-statement or switch statement; control passes to the statement following the terminated statement, if any.

# 9.6.2 The continue statement

The continue statement shall only occur in an iteration-statement or switch statement to pass to the loop continuation of the smallest iteration-statement, which is to the end of the loop.

```
while (foo) {
    do {
        for (;;) {
            // ...
            // ...
        }
        continue;
    } while (foo);
}
```

a continue not contained in an enclosed statement is evaluated as convert goto.

# 9.6.3 The return statement

The copy-or-braced-init-list of a return statement is called. A return statement with no operand shall be used only in a function whose return type is void; (15.1)—a constructor or a destructor (15.4)—void. A return statement with any other type of void shall be used only in a function whose return type is cv void; the return statement initializes the value or result of the object (explicit or implicit) function by copy-initialization (11.6) from the operand. [Note: A return statement may invoke an invocation of a constructor to perform a copy or move of the operand if it is not a value or if its types differ from the return type of the function.
