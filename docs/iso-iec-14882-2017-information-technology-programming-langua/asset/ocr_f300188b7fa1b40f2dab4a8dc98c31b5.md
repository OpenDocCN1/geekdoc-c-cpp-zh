```
constexpr size_type find(basic_string_view str, size_type pos = 0) const noexcept;
```

Let pos be the lowest position, if possible, such that the following conditions hold:

```
(6.1) pos <= xpos
(6.2) xpos + str.size() <= size()
(6.3) traits::eq(at(xpos + I), at(I)) for all elements I of the string referenced by str.
```

Effects: Determines xpos.
Returns: xpos if the function can determine such a value for xpos. Otherwise, returns npos.

```
constexpr size_type rfind(basic_string_view str, size_type pos = npos) const noexcept;
```

Let pos be the highest position, if possible, such that the following conditions hold:
