# 20.4.2.1 Bitmask types [bitmask.types]

+   1 Several types defined in Clauses 21 through 33 and Annex D are bitmask types. Each bitmask type can be implemented as an enumerated type that overload operators, as an integer type, or as a bitset (23.9.2).

+   2 The bitmask type bitmask can be written:

```
// For exposition only.
// int_type is an integer type capable of representing all values of the bitmask type
enum bitmask = int_type;
V_0 = 1 << 0, V_1 = 1 << 1, V_2 = 1 << 2, V_3 = 1 << 3, \dots;
```

```
inline constexpr bitmask C_0(V_0);
inline constexpr bitmask C_1(V_1);
inline constexpr bitmask C_2(V_2);
inline constexpr bitmask C_3(V_3);
```

```
constexpr bitmask operator&(bitmask X, bitmask Y) {
    return static_cast<bitmask>(n        static_cast<int_type>(X) & static_cast<int_type>(Y));
}
```

```
constexpr bitmask operator|(bitmask X, bitmask Y) {
    return static_cast<bitmask>(n        static_cast<int_type>(X) | static_cast<int_type>(Y));
}
```

```
constexpr bitmask operator^(bitmask X, bitmask Y) {
    return static_cast<bitmask>(n        static_cast<int_type>(X) ^ static_cast<int_type>(Y));
}
```

```
constexpr bitmask operator-(bitmask X) {
    return static_cast<bitmask>(-(static_cast<int_type>(X)));
}
```

```
bitmask& operator&=(bitmask X, bitmask Y) {
    X = X & Y; return X;
}
```

```
bitmask& operator|=(bitmask X, bitmask Y) {
    X = X | Y; return X;
}
```

```
bitmask& operator-=(bitmask X, bitmask Y) {
    X = X - Y; return X;
}
```
