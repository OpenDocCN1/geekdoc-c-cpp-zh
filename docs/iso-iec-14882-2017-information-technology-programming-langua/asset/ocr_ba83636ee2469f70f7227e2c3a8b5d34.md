# ISO/IEC 14882:2017(E)

```
class process {
    static process* run_chain;
    static process* running;
};
```

```
process::::running = get_main();
process::::run_chain = running;
```

The static data member run_chain of class process is defined in global scope; the namespace process::run_chain specifies that the run_chain is a member of class process and in the scope of class process. The static data member defines the initializer expression to the static data member of class process. 

> [Note: The static data member has been defined, it exists even if no objects of its class have been created. [Example: In the example above, run_chain and running exist even if no objects of class are created by the program. — end example.] — note.]

5 Static data members of classes in namespace scope have the linkage of non-local variables (6.6, 6.6.2, 6.6.3, 6.6.4). A local class cannot have static data members (12.4), — end note.

# 12.2.4 Bit-fields

7 A static data member is not mutable (10.1.1). [class.bit]

+   1 A member-declarator of the form identifier attribute-specifier-seq : constant-expression specifies a bit-field; its length is set off from the bit-field name by a colon. The optional attribute-specifier-seq applies to the bit-field is not part of the type of the class. The constant-expression must be an integral constant with a value greater than or equal to zero. The value of the integral constant may be larger than the number of bits in the representation (6.9) of the bit-field. The excess bits are used as padding bits and not participating in the value representation of the bit-field. Alignment of bit-fields is implementation-defined. Bit-fields are packed into a single allocation unit. [Note: Bit-fields stride allocation units on some members and not others. Bit-fields are aligned left-to-right on some,, left-to-right. — end note.]

2 A declaration for a bit-field that omits the identifier declares an unnamed bit-field. Unnamed bit-fields are not members and cannot be initialized. [Note: An unnamed bit-field is useful for padding to conform to externally-imposed layouts. — end note.] As a special case, an unnamed bit-field with a width of zero bit-field may specify alignment of the next bit-field at an allocation unit boundary. When declaring an unnamed value of the constant-expression be equal to zero.
