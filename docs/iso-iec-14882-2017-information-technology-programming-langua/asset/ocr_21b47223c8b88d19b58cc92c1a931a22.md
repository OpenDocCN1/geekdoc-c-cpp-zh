# 29.6.1.5 Random number engine adaptor requirements [rand.req.adapt]

+   1 A random number engine adaptor (commonly shortened to adaptor) of type A is a random number engine that takes values by some other random number engine, and applies an algorithm to those values in order to deliver a sequence of values with randomness properties. An engine b of B adapted in this way is termed a base engine in this context. The expression a.base() will be valid and return a const reference to a's base engine.

+   2 The requirements of a random number engine adaptor type should be interpreted as follows with respect to a random number engine adaptor type.

```
A::
```

+   3 Effects: The base engine is initialized as if by its default constructor.

```
bool operator=(const A& a1, const A& a2);
```

+   4 Returns: if a1's base engine is equal to a2's base engine. Otherwise returns false.

```
A::(result_type s);
```

+   5 Effects: The base engine is initialized with s.
