## 23.15.3, Helper classes

```cpp
namespace std {
template <class T, T v>
struct integral_constant {
    static constexpr T value = v;
    using type = T;
    constexpr integral_constant() noexcept {}
    constexpr integral_constant(const T&) noexcept {}
    constexpr operator T() const noexcept { return v; }
    constexpr operator bool() const noexcept { return static_cast<bool>(v); }
};
```

- `integral_constant` is a helper class that represents a constant value at compile time.

## 23.15.4, Unary traits

- This subclass contains templates that may query the properties of a type.
- Each of these templates is a `true_type` or `false_type`.

## 23.15.1, Primary categories

- The primary categories correspond to the descriptions given in 6.9.
- For any given type T, one of the primary categories has a value member that evaluates to true.
- Note: For any given type, exactly one of the primary categories has a value member that evaluates to true.

| Template | Condition | Comments |
| :--- | :--- | :--- |

| `template <class T> struct is_integral;` | T is an integral type (6.9.1) | |
| `template <class T> struct is_floating_point;` | T is a floating-point type (6.9.1) | |
| `template <class T> struct is_array;` | T is an array type (6.9.2) known or unknown extent (26.3.7) is not an array type. Includes pointers to functions but non-static members. |
| `template <class T> struct is_pointer;` | T is a pointer (6.9.2) | |
| `template <class T> struct is_lvalue_reference;` | T is an lvalue reference (11.3.2) | |
| `template <class T> struct is_rvalue_reference;` | T is an rvalue reference (11.3.2) | |
| `template <class T> struct is_member_object_pointer;` | T is a pointer to non-static data member | |

## 23.15.4.2 Composite type traits

1. These templates provide convenient compositions of the primary type categories, corresponding to the descriptions given in 6.9.
2. For any given type T, the result of applying one of these templates to T and to cv T shall yield the result.

### Table 41 — Composite type category predicates

| Template | Condition | Comments |
| :--- | :--- | :--- |
| `template <class T> struct is_reference;` | T is an value reference or an rvalue reference | |
| `template <class T> struct is_arithmetic;` | T is an arithmetic type (6.9.1) | |
