# 29.6.4.2 Class discard_block_engine [rand.disc]

+   A discard_block_engine random number adaptor produces numbers selected from those by some engine e. The state x, of a discard_block_engine object x consists of the state e, its bias and an additional integer n. The size of the state is the size of e's state plus 1.
The transition algorithms all behave as follows: If n ≥ r, advance the state of e from e, to e_{i+r} and set n to 0. In any case, increment n and advance e's current state e, to e_{i+1}.
The operation algorithm yields the value returned by the last invocation of e() while advancing e's state as described above.

```
template<class Engine, size_t p, size_t r>
 discard_block_engine {
public:
    // types
    using result_type = typename Engine::result_type;

    // engine characteristics
    static constexpr size_t block_size = p;
    static constexpr size_t used_block = r;
    static constexpr result_type min() { return Engine::min(); }
    static constexpr result_type max() { return Engine::max(); }

    // constructors and seeding functions
    discard_block_engine();
    explicit discard_block_engine(const Engine& e);
    explicit discard_block_engine(Engine&& e);
    explicit discard_block_engine(result_type s);
    template<class Sseq> explicit discard_block_engine(Sseq& q);
    void seed();
    template<class Sseq> void seed(Sseq& q) (result_type s);

    // generating functions
    result_type operator()();
    void discard(unsigned long n);

    // property functions
    const Engine& base() const noexcept { return e; };
```
