# 23.11.4 unique_ptr creation [unique_ptr.create]

```
template <class T, class Args> unique_ptr<T> make_unique(Args&&... args);

Returns: This function does not participate in overload resolution T is not an array of bound.
Returns: unique_ptr<T>(new T(std::forward<Args>(args)...));
```

```
template <class T> unique_ptr<T> make_unique(size_t n);

Returns: This function does not participate in overload resolution T is not an array of bound.
Returns: unique_ptr<T>(new remove_extent<T>[n]());
```

# 23.11.5 unique_ptr specialized algorithms [unique_ptr.special]

```
template <class T, class D> void swap(unique_ptr<T>, D& x, unique_ptr<T>, D& y);

Returns: This function does not participate in overload resolution is_swappable_v<D> is true.
Effects: Calls x.swap(y).
```

```
template <class T1, class D1, class T2, class D2>
bool operator=(const unique_ptr<T1>, D1& x, const unique_ptr<T2>, D2& y);
Returns: x.get() != y.get();

template <class T1, class D1, class T2, class D2>
bool operator=(const unique_ptr<T1>, D1& x, const unique_ptr<T2>, D2& y) noexcept;
Returns: x.get() != !y.get();

template <class T1, class D1, class T2, class D2>
bool operator=(const unique_ptr<T1>, D1& x, const unique_ptr<T2>, D2& y);
Requires: Let CT denote
common_type<typename unique_ptr<T1, D1>::pointer,
typename unique_ptr<T2, D2>::pointer>
```

Then the specialization shall be a function object type (23.14) that induces a strict weak ordering (28.7) on the pointer values.

```
Returns: less<CT>(x.get(), y.get());
Returns: If unique_ptr<T1, D1>::pointer is not implicitly convertible to CT or unique_ptr<T2, D2>::pointer is not implicitly convertible to CT, the program is ill-formed.
```

```
template <class T1, class D1, class T2, class D2>
bool operator=(const unique_ptr<T1>, D1& x, const unique_ptr<T2>, D2& y) noexcept;
Returns: !(y < x);
```

```
template <class T1, class D1, class T2, class D2>
bool operator=(const unique_ptr<T1>, D1& x, const unique_ptr<T2>, D2& y);
Returns: y < x.
```
