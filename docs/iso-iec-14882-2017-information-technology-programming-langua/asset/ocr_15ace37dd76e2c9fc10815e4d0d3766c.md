# 15.4 (destructors)

Change: User-declared destructors have an implicit exception specification.

Rationale: Clarification of destructor requirements.

Effect on original feature: Valid `C\+\+ 2003` code may execute differently in this International Standard. In particular, those that throw exceptions call `std::terminate` (without calling `std::unexpected`) if their exception specification is not-throwing.

# C.2.7 Clause 17: templates [diff.cpp03.temp]

# 17.1

Change: Remove export.

Rationale: No implementation consensus.

Effect on original feature: A valid C\+\+ 2003 declaration containing `export` is ill-formed in this International Standard..

# 17.2

Change: Remove whitespace for nested template template angle brackets.

Rationale: Considered a persistent but minor annoyance. Templates representing non-class types would exacerbate whitespace issues.

Effect on original feature: Change to semantics of well-defined. A valid C\+\+ 2003 expression containing a right angle bracket (`>`) followed by another right angle bracket may be treated as two templates. For example, the code in C\+\+ 2003 because `>>` is the right shift operator, invalid in this International Standard because `>>` closes templates.

```
template <class T> struct Y {
  int<class B> y;
  X V y = 1 >> 2;
};
```

# 17.6.4.2

Change: Allow default of templates with internal linkage.

Rationale: Over constrained, simplify overload rules.

Effect on original feature: A valid C\+\+ 2003 program could get a different result than this International Standard.
