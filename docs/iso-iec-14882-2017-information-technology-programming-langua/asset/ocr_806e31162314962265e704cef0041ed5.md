+   8 A brace-or-equal-initializer shall appear only in the data member. (For static members, see 12.2.3.2; for non-static data members, see 15.6.2 and 11.6.1). A brace-or-equal-initializer for a non-static data specifies a default initializer for the member, and shall not directly or indirectly cause the implicit definition of a default constructor for the enclosing class or the exception specification of constructor.

+   9 A member shall not be declared with the extern storage-class-specifier. Within a class, a member shall not be declared with the thread_storage-class-specifier unless also declared.

+   10 The declarator-seq may be omitted in constructor, declaration and conversion functions only; when declaring another it shall contain a type-specifier that is not a cv-qualifier. The member-declarator-list can be omitted only after an enum-specifier or in a friend declaration (14.3). A pure-specifier shall be used only in the declaration of a virtual function (13.3) that is not a friend declaration.

+   11 The optional attribute-specifier-seq in a member-declaration pertains to all of the entities declared by the member-declarators; it shall not appear if the member-declarator-list is omitted

+   12 A virt-specifier shall contain at most one of each virt-specifier. A virt-specifier shall appear only in the declaration of a virtual function (15.3).

+   13 Non-static data members shall not have incomplete types. In particular, a class C shall not contain a non-static member of class C, but it can contain a pointer or reference to an object of class C.

+   [14 Note: See 8.1 for restrictions on the use of non-static data members and non-static member functions.]

+   [15 Note: The type of a non-static member function is an ordinary function type, and the type of a non-static data member is an ordinary object type. There are no special function types or data member types.

+   [16 Example: A simple example of a class definition is
struct tnode {
  char word[20];
  int count;
  tnode* left;
  tnode* right;
};

which contains an array of twenty characters, an integer, and two pointers to objects of the same type. Once this definition is given, the declaration

tnode s, *s;

declares s to be a tnode and s to be a pointer to a tnode. With these declarations, s->count refers to the member of the object which s points to; s->left refers to the left subtree pointer of the object; s->right->word[0] refers to the initial character of the word of the right subtree of s.

+   17 Non-static data members of a (non-union) class with the same access control (Clause 14) are allocated all that later members have higher addresses within a class object. The order of allocation of non-static data members with different access control is unspecified (Clause 14).
