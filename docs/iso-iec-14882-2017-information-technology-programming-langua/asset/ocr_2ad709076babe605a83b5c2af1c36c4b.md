+   1 The class basic_istream defines a number of member function signatures that assist in reading and interpreting input from sequences controlled by a stream buffer.
2 Two groups of member function signatures share common properties: the formatted input functions (or extractors) and the unformatted input functions. Both groups are described as if they obtain (or extract) input characters by calling rdbuf()->sgetc() or rdbuf()->getc(). They may use other public members of istream.
