# 17.5.6.2 Partial ordering of function templates [temp.func.order]

+   1 If a function template is overloaded, the use of a function template specialization may be ambiguous because template argument deduction (17.8.2) may associate the function template specialization with more than one function template declaration. Partial ordering of overloaded function template declarations is used in the following contexts to select the function template to which a function template refers:
  (1.1) during overload resolution for a call to a function template specialization (16.3.3);
  (1.2) when the address of a function template specialization is taken;
  (1.3) when a placement operator delete is a function template specialization is selected to match a placement operator new (6.4.2, 8.3.4); or an explicit instantiation
  (1.4) when a friend function declaration (17.5.4), an explicit specialization (17.7.2) (17.7.3) refers to a function template specialization.

+   2 Partial ordering occurs when two functions are more specialized than the other by transforming each template term (in each turn; except of template argument deduction using the function deduction). The process determines whether one of the templates is more specialized than the other. If so, the more specialized template is chosen by the partial ordering process.

+   3 To produce the transformed template, for each type, non-type, or template parameter deduction using the function template parameters (in 17.5.3) synthesizes a unique value, type, or class template respectively (including [Note: The type replacing the placeholder in the type of value synthesized for a non-type template parameter is also a synthesized type — end note]) If only one of the function templates M is a non-static member of class A, M is considered to have a new first parameter in its function list. Given as the case the member of A or if M has no ref-qualifier and the reference to c of the other template has ref-qualifier and the first parameter of the other template has reference type. Otherwise, the new parameter is of type “value reference to c A”. [Note: This allows for a non-static member to refer to a non-member function and the results to be equivalent to the ordered non-members.— end note] [Example:

```
struct A {
template<class R> int operator(R&);
// #1
```

```
template<class T, class R> int operator*(T&, R&);
// #2
```

```
// The declaration of B::operator* is transformed into the equivalent of
template<class R> int operator*(const B&, const R&);
// #1a
```

```
int main() {
A a;
B b;
b* = a;
}
// calls #1a
```

+   4 Using the transformed function's function type, perform type deduction against the other template as described in 17.8.2.4.

[Example:
template<class T> struct A { };
