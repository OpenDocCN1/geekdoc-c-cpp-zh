# 26.3.11 Class template vector [vector.overview]

# 26.3.11.1 Class template vector overview

+   1 A vector is a container that supports (amortized) constant time insert and erase operations at the end; insert and erase in the middle linear time. Storage management is handled automatically, though hints can be given to improve efficiency.\2 A vector satisfies all the requirements of a container and of a reversible container (given in tables in 26.2), of sequence container including most of the optimal sequence container requirements (26.2.3), of an allocator-aware container (Table 80), and for an element type other than bool, of a contiguous container (26.2.1). The operations are push_front, pop_front member functions, which are not provided. Descriptions are provided here only for operations on vector that are not described in one of these tables or for operations where additional semantic information.

```
namespace std {
template <class T, class Allocator = allocator<T>>
class vector {
  // types:
  using value_type = T;
  using allocator_type = Allocator;
  using pointer = typename allocator_traits<Allocator>::pointer;
  using const_pointer = typename allocator_traits<Allocator>::const_pointer;
  using reference = value_type&;
  using const_reference = const value_type&;
  using difference_type = implementation_defined; // see 36.2
  using implementation_defined = implementation_defined; // see 36.2
  using iterator = implementation_defined; // see 36.2
  using const_iterator = implementation_defined; // see 36.2
  using reverse_iterator = std::reverse_iterator<iterator>;
  using const_reverse_iterator = std::reverse_iterator<const_iterator>;
```
