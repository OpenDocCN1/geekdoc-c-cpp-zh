# 27.2.6 Bidirectional iterators [bidirectional.iterators]

1 A class or pointer type X satisfies the requirements of a bidirectional iterator, in addition to satisfying the requirements for forward iterators, the following expressions are valid as shown in Table 98.

Table 98 — Bidirectional iterator requirements (in addition to forward iterator)

| Expression | Return type | Operational semantics | Assertion/note pre-/post-condition |
| --- | --- | --- | --- |
| --r | X& | | Requires: there exists s such that r == ++s. Postconditions: r is dereferable.<br>--(r) == r.<br>--r == --s implies r == s.<br>&r == &&r. | |
| r-- | convertible to const X& | { X tmp = r; --r; return tmp; } | |
| *-- | reference | | |

> [Note: Bidirectional iterators allow algorithms to move iterators backward as well as forward. — end note]

# 27.2.7 Random access iterators [random.access.iterators]

1 A class or pointer type X satisfies the requirements of a random access iterator, in addition to satisfying the requirements for bidirectional iterators, the following expressions are valid as shown in Table 99.

Table 99 — Random access iterator requirements (in addition to bidirectional iterator)

| Expression | Return type | Operational semantics | Assertion/note pre/post-condition |
|---|---|---|--|
| r += n | X& | { difference_type m = n; if (m > 0) while (m--) ++r; else while (m++) --r; return r; } | |
| a + n | X | | a + n = n + a. |
| n + a | | return r += n - n; | Requires: The absolute value of n is in the range of representable values of difference_type. |
| r -= n | X& | | |
| a - n | X | { X type tmp = a; return tmp -= n; } | |
| b - a | | difference_type return n | Requires: there exists a value n type of difference_type such that a + n = b. |
| a[n] | convertible to reference | *(a + n) | |
| a < b | contextually converted to bool | b - a > 0 | < is a total ordering relation |
| a > b | contextually converted to bool | b < a | > is a total ordering relation opposite to < |
| a >= b | contextually converted to bool | !(a < b) | |
