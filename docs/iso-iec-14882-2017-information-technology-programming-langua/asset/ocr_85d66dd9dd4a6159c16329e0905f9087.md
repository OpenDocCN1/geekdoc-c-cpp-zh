template <class T>
pair<T*, prtdiff_t> get_temporary_buffer(prtdiff_t n) noexcept;

+   Effects: Returns a pointer to initializer, returns contiguous storage for N adjacent objects of type T, for non-negative number N. It is implementation-defined whether over-aligned objects are supported (6.11).

+   Remarks: Calling get_temporary_buffer with a positive number n is a non-binding request to return storage for n objects of type T. In this case, an implementation is permitted to return instead storage for a non-negative number N of objects (including N = 0). [Note: The return is non-binding to allow latitude for implementation-specific optimizations of its management, and may be ignored].

+   Returns: If n < 0 or if null could be obtained, returns a pair P such that first is a null pointer and second == returns a pair P such that first refers to the address of the uninitialized storage and second refers to its capacity N (in the units of sizeof(T)).

```
template <class T> void return_temporary_buffer(T* p);
```

+   Effects: Deallocates the storage returned by p.

+   Requires: p is a pointer value returned by an earlier call to get_temporary_buffer that has not been invalidated by an intervening call to return_temporary_buffer(T).

+   Throws: None-class

# D.12 Deprecated traits [depr.meta.types]

The header <traits> has the following addition:

```
namespace std {

template <class T> constexpr is_literal_type_v = is_literal_type<T>::value;

template <class T> struct result_of_ = / not defined
template <class Fn, class... Args> struct result_of<Fn(Args...)>;

}
```

+   Requires: is_literal_type, remove_all_extents<T> is a complete type or void. If result_of<Fn(Args...)> then all types in the parameter pack ArgTypes are complete types, or void, or of unknown bound.

+   is_literal_type is a TypeTrait (23.15.1) with a base characteristic of true_type if T is a literal type (6.9), and false otherwise. The partial specialization result of result_of<Fn(Args...)> is a TransformationTrait whose member typedef type is defined if and only if invoke_result<Fn, Args...>::type is defined. If type is defined, it names the same type as invoke_result<Fn, Args...>.

+   The behavior of a program that has specializations for is_literal_type or is_literal_v is undefined.
