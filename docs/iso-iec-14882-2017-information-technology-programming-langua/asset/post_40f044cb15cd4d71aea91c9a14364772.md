- 7 A iterator is a regex_token_iterator object that points to a final sequence of characters at the end of the sequence. In this suffix the member holds a pointer to the data member suffix. suffix.match is true. first points to the beginning of the final sequence, and suffix..second points to the end of the final sequence.

- 2 Requires: Each initialization value of submatches shall be >= -1.

- 3 Effects: The first constructor initializes the member subs to hold the single value submatch. The second constructor initializes the member subs to hold a copy of the argument submatches. The third and fourth constructors initialize the member subs to hold a copy of the sequence of integers pointed to by the range [submatches.begin(), submatches.end()) and [submatches, submatches+N), respectively.

- 4 Each constructor sets N to 0 and position to tokiter_iterator(a, b, re, m). If position is not an end-of-sequence iterator the constructor sets result to the address of the current match. Otherwise if any of the values stored in subs is equal to -1 the constructor sets this to a suffix iterator that points to the range [a, b), otherwise sets this to an end-of-sequence iterator.

## 31.13 Modified ECMAScript regular expression grammar

- 1. The regular expression recognized by basic_regex objects constructed with the ECMAScript flag that is specified by ECMA-262, as specified as below.

- 2. Objects of type specialization of basic_regex within themselves a default-constructed instance of their traits template parameter, hereafter referred to as traits_inst. This traits_inst object is used to support type localization of the regular expression: basic_regex member.

- 3. The following productions within the ECMAScript grammar are modified as follows:
```
ClassAtom
ClassAtomEx
ClassAtomCollatingElement
ClassAtomEquivalence
```

- 4. The following new productions are added:
```
ClassAtomEx
ClassAtomCollatingElement
ClassAtomEquivalence
ClassName
ClassNameCharacter
ClassNameCharacter
```

- 5. The behavior of the internal state machine used to match a sequence of characters is defined in ECMA-202.

- 6. The regular expression may be modified by regex_constants::syntax_option flags.

- 7. The names recognized as valid are: alpha, blank, cntrl, digit, graph, lower, print, space, upper, xdigit.

- 8. ClassName used when ClassAtomCollatingElement production is valid if the value returned by traits_inst.colename is empty.

- 9. The results from traits_inst.classname are bitwise OR'ed together and subsequently passed to traits_inst.isctype.

- 10. ClassName used when ClassAtomEquality production is valid if the value returned by traits_inst.transform_primary

- 11. When the sequence of characters being transformed contains an invalid name the translator will throw an exception of type regex_error.

- 13. Where the regular expression requires the conversion of a sequence of characters to an integral value, this is accomplished by calling traits_inst.value.
