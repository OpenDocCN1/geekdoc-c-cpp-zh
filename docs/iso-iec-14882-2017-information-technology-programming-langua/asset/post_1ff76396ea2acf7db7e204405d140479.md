# 30.10.15.9 Create hard link

```
void create_hard_link(const path& to, const path& new_hard_link);
void create_hard_link(const path& to, const path& new_hard_link,
                               error_code& ec) noexcept;
```

- 1 Effects: Established the postcondition, as by POSIX symlink().
- 2 Postconditions:
  - exists(to) && exists(new_hard_link) && equivalent(to, new_hard_link)
  - The contents of the file or directory are not changed.
- 3 Throws: As specified in 30.10.7.
- 4 [Note: Some operating systems do not support hard links at all or support them only for regular files. Some file systems (such as the FAT file system) do not support hard links regardless of the operating system. Some file systems limit the number of links per file. -- end note]

# 30.10.15.11 Current path [fs.op.current_path]

```
path current_path();
path current_path(error_code ec);
```

- 1 Returns: The absolute path of the current working directory, whose pathname in the native format is obtained as by POSIX getcwd(). The signature with argument ec returns path() if an error occurs.
- 2 Throws: As specified in 30.10.7.
- 3 Remarks: The current working directory is the directory, associated with the process, which is used as the starting location in position resolution for relative paths.
- 4 [Note: The current_path() name was chosen to emphasize that the returned value is a path, not just a single directory.—end note]
- 5 [Note: The path returned by many operating systems is a dangerous global variable. It may be changed unexpectedly by a third-party or system library functions, or by another thread.—end note]

```

void current_path(const path& p, error_code ec) noexcept;
```

- 6 Effects: Establishes the postcondition, as if POSIX chdir().
- 7 Postconditions: equivalent(p, current_path()).
- 8 Throws: As specified in 30.10.7.

# 30.10.15.12 Equivalent [fs.op.equivalent]

```
bool equivalent(const path& p1, const path& p2);
bool equivalent(const path& p1, const path& p2, error_code ec) noexcept;
```

- 1 Let s1 and s2 be file_status, determined as if status(p1) and status(p2), respectively.
- 2 Effects: Determines if s1 == s2 and p1 and p2 resolve to the same file system entity, else false. If (!exists(s1) && !exists(s2)) || (is_other(s1) && is_other(s2))) an error is reported in 30.10.7.
- 3 Returns: true, if s1 == s2 and p1 and p2 resolve to the same file system entity, else false. The signature with argument ec returns path() if an error occurs.
- 4 Two paths are considered to resolve to the same file system entity if two candidates reside on the same device at the same location. This is determined as the values of the POSIX stat st_dev and equal st_ino.
- 5 Throws: As specified in 30.10.7.

# 30.10.15.14 File size

```
uintmax_t file_size(const path& p);
uintmax_t file_size(const path& p, error_code ec) noexcept;
```

- 1 Returns:
  - If (p) is false, an error is reported in 30.10.7.
  - Otherwise, if is_file(p), the size in bytes of the file p resolves to, determined by the value of POSIX stat st_size obtained by POSIX stat().
  - Otherwise, the result is implementation-defined.
The signature with argument ec returns static_cast<uintmax_t>() if an error occurs.
- 2 Throws: As specified in 30.10.7.

# 30.10.15.19 Is empty

```
bool is_empty(const path& p);
bool is_empty(const path& p, error_code ec) noexcept;
```

- 1 Effects:
  - (1.1) - Determine file_type s, as if status(p) or status(ec), respectively.
  - (1.2) - For the signature with argument ec, return false if an error occurs
  - (1.3) - Otherwise, if is_directory(s):
    - (1.3.1) - Create a variable itr, if by directory_iterator itr(p) or directory_iterator itr(p), respectively.
    - (1.3.2) - For the signature with argument ec, return false if an error occurs
    - (1.3.3) - Otherwise, return itr = directory_iterator().
  - (1.4) - Otherwise:
    - (1.4.1) - Determine uintmax_t sz, as if file_size(p) or file_size(ec), respectively.
    - (1.4.2) - For the signature with argument ec, return false if an error occurs
    - (1.4.3) - Otherwise, return sz = 0.
- 2 Throws: As specified in 30.10.7.
