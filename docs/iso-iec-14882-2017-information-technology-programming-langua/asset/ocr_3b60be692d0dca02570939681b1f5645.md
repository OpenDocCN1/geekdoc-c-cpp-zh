```
*(first + (i - result)) == old_value
pred*(first + (i - result)) != false
```

6 Returns: result + (last - first).

7 Complexity: Exactly last - first applications of the corresponding predicate.

# 28.6.6 Fill

```
template<class Forwarditerator, class T>
void fill(Forwarditerator first, Forwarditerator last, const T& value);
template<class ExecutionPolicy, class Forwarditerator>
void fill(ExecutionPolicy&& exec, 
           Forwarditerator first, Forwarditerator last, const T& value);
```

```
template<class Outputiterator, class Size, class T>
void outputfill_n(Outputiterator first, Size n, const T& value);
template<class ExecutionPolicy, class Outputiterator, class Size, class T>
void outputfill_n(ExecutionPolicy&& exec, 
                  Outputiterator first, Size n, const T& value);
```

+   1 Requires: The value shall be assignable (7.2.1) to the output iterator. The type Size should be converted to an integral (7.8, 15.3).

+   2 Effects: The fill algorithms assign value through all iterators in the range [first, last). The fill_n algorithms assign value through all iterators in the range [first, last) if n is positive, otherwise they do nothing.

+   3 Returns: fill_n returns first + n for non-negative values of n and first for negative values.

+   4 Complexity: Exactly last - first, n, or 0 assignments, respectively.

The generate_n algorithms invoke the function object gen and assign the return value through all iterators in the range [first + n, if n is positive, otherwise they do nothing.

+   4 Complexity: Exactly last - first, n, or 0 invocations of gen and assignments, respectively.
