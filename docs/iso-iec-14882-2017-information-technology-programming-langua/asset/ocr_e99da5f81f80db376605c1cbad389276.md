# ISO/IEC 14882:2017(E)

(1.1) the first argument of a constructor has type allocator_arg_t and the second argument has type Alloc or

(1.2) the last argument of a constructor has type Alloc.

# 23.10.7 Allocator-uses construction [allocator.uses_construction]

Uses-allocator construction with Alloc refers to the construction of an object obj of type T, using constructor arguments v1, v2, ... of types V1, V2, ..., respectively, and an allocator of type Alloc, according to the following rules:

+   (1.1) if uses_allocator<V, Alloc> is true and is_constructible_v<T, V1, V2, ...> is true, then obj is initialized as obj(v1, v2, ...);

+   (1.2) if uses_allocator<V, Alloc> is true and is_constructible_v<T, allocator_arg_t, Alloc, V1, V2, ...> is true, then obj is initialized as obj(allocator_arg, Alloc, V1, V2, ...);

+   (1.3) if uses_allocator<V, Alloc> is true and is_constructible_v<T, V1, V2, ..., Alloc> is false, then obj is initialized as Alloc();

+   (1.4) otherwise, the request for uses_allocator-construction is ill-formed. [Note: An error will result if uses_allocator<V, Alloc> is true but the specific class does not have an allocator. This definition prevents a failure to pass the allocator to an allocator. — end]

# 23.10.8 Allocator traits [allocator.traits]

The class allocator_traits supplies a interface to all allocator types. An allocator cannot be a non-class, however, if allocator_traits satisfies the required interface. [Note: Thus, it is always possible to create a derived class from an allocator. — end]

```
namespace std {
template <class Alloc> struct allocator_traits {
  using allocator_type = Alloc;
  using value_type = typename Alloc::value_type;
  using pointer = see below;
  using const_pointer = see below;
  using void_pointer = see below;
  using const_void_pointer = see below;
  using difference_type = see below;
  using size_type = see below;
  bool propagate_on_container_copy_assignment = see below;
  bool propagate_on_container_move_assignment = see below;
  bool propagate_on_container_swap = see below;
  bool is_always_equal = see below;

template <class T> struct rebind_alloc = see below;
template <class T> struct rebind_traits = allocator_traits<T>;

  static pointer allocate(Alloc& a, size_type n);
  static pointer allocate(Alloc& a, size_type n, const void_pointer hint);
  static void deallocate(Alloc& a, pointer p, size_type n);
};
```
