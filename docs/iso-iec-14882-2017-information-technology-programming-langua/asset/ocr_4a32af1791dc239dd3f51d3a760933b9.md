# ISO/IEC 14882:2017(E)

# 26.5.6 Class template unordered_set [un.set]

# 26.5.6.1 Class template unordered_set overview [unordered.set.overview]

An unordered_set is an unordered associative container that supports unique keys (an `unordered_set` contains at most one of each value) and in which the elements' keys are the elements. The unordered_set supports forward iterators.

An unordered_set satisfies all of the requirements of a container, an associative container, and of an allocator-aware container (Table 86). It provides the operations described in the following requirements for unique keys: that is, an `unordered_set` supports the `a_eq` operations. For an `unordered_set<Key>` the key type and the value type are both `Key`. The `iterator` and `const_iterator` types are constant iterator types. It is specified whether they are the same type.

This section describes operations on `unordered_set` that are not described in one of the requirement lists, or for which there is additional semantic information.

    using const_pointer = allocator_traits<Allocator>::const_pointer;
    using reference = value_type&;
    using const_reference = const value_type&;
    using size_type = implementation-defined; // see 26.2
    using difference_type = implementation-defined; // see 26.2

    using iterator = implementation-defined; // see 26.2
    using const_iterator = implementation-defined; // see 26.2
    using local_iterator = implementation-defined; // see 26.2
    using const_local_iterator = implementation-defined; // see 26.2
    using node_type = unspecified;
    using insert_return_type = INSERT_RETURN_iterator<node_type>;
//26.5.6.2. construct(copy/destroy)

    size_type n = 0 // see below,
