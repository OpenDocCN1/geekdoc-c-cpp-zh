## 23.11.2.1 unique_ptr constructors [unique_ptr.single.ctor]

```cpp
const unique_ptr(pointer p) noexcept;
const unique_ptr(nullptr p) noexcept;
```

- 1 D shall satisfy the requirements of DefaultConstructible (Table 22), and construction shall not throw an exception.

- 2 Effects: Constructs a unique_ptr that owns p, value-initializing the stored pointer and the stored deleter.

- 3 Postconditions: `get() == nullptr`; `get()` returns a reference to the stored deleter.

- 4 Remarks: If `is_pointer<v_deleter_type>` is true or `is_default_constructible<v_deleter_>` is false, this constructor shall not participate in overload resolution.

- 5 D shall satisfy the requirements of DefaultConstructible (Table 22), and construction shall not throw an exception.

- 6 Effects: Constructs a unique_ptr which owns p, value-initializing the stored pointer with p and value-initializing the deleter.

- 7 Postconditions: `get() == p.get_deleter()` returns a reference to the stored deleter.

- 8 Remarks: If `is_pointer<v_deleter_type>` is true or `is_default_constructible<v_deleter_>` is false, this constructor shall not participate in overload resolution. If class template argument deduction (16.3.1.8) would select the template corresponding to this constructor, then the program is ill-formed.

```cpp
unique_ptr(pointer p, see below d1) noexcept;
unique_ptr(pointer p, see below d2) noexcept;
```

The signature of these constructors depends on whether D is a reference type. If D is a non-reference type A, then the signatures are:

```cpp
unique_ptr(pointer p, const A& d) noexcept;
unique_ptr(pointer p, const A& d) noexcept;
```

If D is an invalid reference type A& then the signatures are:

```cpp
unique_ptr(pointer p, A& d) noexcept;
unique_ptr(pointer p, A& d) = delete;
```

- 11 If D is a reference type A, then the signatures are:

```cpp
unique_ptr(pointer p, const A& d) noexcept;
unique_ptr(pointer p, const A& d) = delete;
```

- 12 Effects: Constructs a unique_ptr object which owns p, initializing the pointer with p and initializing the deleter from std::decltype(d)(d).

- 13 Remarks: Constructors shall not participate in order resolution unless is_constructible_v<D, decltype(d)> is true.

- 14 Postconditions: get_deleter() returns a reference to the stored deleter. If D is a reference type then get_deleter() returns a reference to the value.

- 15 Remarks: If class type argument deduction (16.3.1.8) would cause function template construction to either of these constructors, the program is ill-formed.

- [Example]:

```cpp
D;
unique_ptr<int, D1>(new int()); // D must be MoveConstructible
unique_ptr<int, D2>(new int()); // D must be CopyConstructible
unique_ptr<int, D3>(new int()); // D3 holds a reference to d
unique_ptr<int, const D4>(new int()); // error: value object combined with reference type
```

- 18 Effects: Constructs a unique_ptr by transferring ownership from u to this. If D is a reference type, get_deleter() returns the deleter that was constructed from u; otherwise, this deleter is constructed from u.get_deleter(). The deleter is constructed with std::forward<E>. --- end note

- 19 Postconditions: get() yields the value u.get() yielded before the construction, get_deleter() returns a reference to the stored deleter. If D is a reference type then get() and get_deleter() return the same value.

## 23.11.1.2.3 unique_ptr assignment

unique_ptr_operator=(unique_ptr&& u) noexcept;

- If D is not a reference type, D shall satisfy the requirements of MoveAssignable (Table 25) and assignment of the deleter from an rvalue of D shall not throw an exception. Otherwise, D is a reference type; remove_reference_t<D> shall satisfy CopyAssignable requirements and assignment of the deleter from value of D shall not throw an exception.

- Effects: Transfers ownership from u to this as calling reset(u.release()) followed by get_deleter() = std::forward<E>(u.get_deleter()).
- Returns: *this.

## 23.11.1.2 unique_ptr modifiers [unique.ptr.single.modifiers]

```cpp
pointer release() noexcept;
Postconditions: get() == nullptr;
Returns: The value get() had at the start of the release.

void reset(pointer* p = nullptr) noexcept
- Requires: The expression get_deleter() shall be formed, shall have well-defined behavior, and shall not throw exceptions.
- Effects: Assigns to the stored pointer, and then if only the old value of the stored pointer, old_p was not equal to nullptr, call get_deleter(old_p). [Note: The order of operations is significant because the call to get_deleter() may destroy this. --- end note];
- Postconditions: get() == p. [Note: The postcondition does not hold if the call to get_deleter() destroys this-this-get() is no longer a valid expression. --- end note];

void swap(unique_ptr& u) noexcept
- Requires: get_deleter() shall be swappable [20.5.3.2] and shall not throw an exception under swap.
- Effects: Invokes swap on the stored pointers and on the stored deleters of *this and u.
```

## 23.11.1.3 unique_ptr for array objects with a runtime length [unique.ptr.runtime]

```cpp
namespace std {
template<class T, class D> class unique_ptr<T[], D> = {
public:
    using see below;
    using element_type = T;
    using deleter_type = D;

// 23.11.1.3.1. constructors
constexpr unique_ptr() noexcept;
template<class U> constexpr unique_ptr(U p) noexcept;
template<class U> unique_ptr(U p, see below d) noexcept;
template<class U> unique_ptr(U p, see below d) noexcept;
unique_ptr(unique_ptr&& u, U p) noexcept;
template<class U, class E> constexpr unique_ptr(unique_ptr<U, E>, E&& u) noexcept;
constexpr unique_ptr(nullptr_t) noexcept;

    ~destructor();
    ~unique_ptr();
};
```
