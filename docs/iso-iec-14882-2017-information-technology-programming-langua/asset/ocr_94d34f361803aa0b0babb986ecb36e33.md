```
struct timespec;

time_t mktime(struct tm* tmptr);
time_t time(time_t* timer, int base);
int timespec_get(struct timespec*, int base);
char* astime(const struct tm* tmptr);

struct tm* gmtime(const time_t* timer);

}
```

+   1. The contents of the header <time> are the same as the C standard library header <time.h>.223

+   2. The functions astime, gmtime, and localtime are not required to avoid data races (20.5.5.9).

# 23.18.2 type_index overview

[type.index.overview]

```
namespace std {
class type_index {
public:
    type_index=(const type_index& rhs) const noexcept;
    operator!=(const type_index& rhs) const noexcept;
    operator<(const type_index& rhs) const noexcept;
    operator>(const type_index& rhs) const noexcept;
    operator>=(const type_index& rhs) const noexcept;
    operator<=(const type_index& rhs) const noexcept;

    size_t hash_code() const noexcept;
    const char* name() const noexcept;
private:
    const type_info* info;
// Note that the value of a pointer here, rather than a reference,
    // means that the default copy/move constructor and assignment
    // operators will be provided and work as expected.
}
```

+   1. The class type_index provides a simple wrapper for type_info which can be used as an index type in associative containers (26.4) and in unordered associative containers (26.5).

223) strftime supports the C conversion specials C, D, e, f, g, h, r, t, u, v, w, and z, and the modifiers E and O.
