
# ISO/IEC 14882:2017(E)

An object of type scoped_lock controls the ownership of lockable objects within a scope. A scoped_lock obtains ownership of lockable objects throughout the scoped_lock object's lifetime (6.8). The behavior of a program is undefined if the lockable objects referenced by pm do not exist for the entire lifetime of the scoped_lock object. When sizeofof...(MutexTypes) is 1, the supplied Mutex type must have the BasicLockable requirements (33.2.5.2). Otherwise, the mutex types must satisfy the Lockable requirements (33.2.5.3).

explicit scoped_lock(MutexTypes... m);

Requires: If a Mutex type is not a recursive mutex, the thread does not own the corresponding mutex element of m. Effects: Initializes with pm(...). If sizeof...(MutexTypes) is 0, then lock(m). Otherwise, lock(m...).

explicit scoped_lock(MutexTypes... m, adopt_lock_t);

Requires: The calling thread owns the mutexes in m.

Effects: Initializes with pm(m...).

Throws: Nothing.

scoped_lock();

Effects: For all i in [0, sizeof...(MutexTypes)], get<i>(pm).unlock().

## 33.4.4.3 Class unique_lock

```cpp
namespace std {
    template <class Mutex>
    class unique_lock {
    public:
        using mutextype = Mutex;
        // 33.4.4.1. construct/destroy
        unique_lock() noexcept;
        explicit unique_lock(mutex& m, defer_lock_t) noexcept;
        unique_lock(mutex& m, adopt_lock_t) noexcept;
        unique_lock(mutextype& m, try_to_lock_t);
        template <class Clock, class Duration>
        unique_lock(Clock& m, const chrono::time_point<Clock, Duration>& abs_time);
        template <class Rep, class Period>
        unique_lock(mutextype& m, const chrono::duration<Rep, Period>& rel_time);
        ~unique_lock();

        unique_lock(const unique_lock&) = delete;
        unique_lock& operator=(const unique_lock&) = delete;

        unique_lock(unique_lock&&) noexcept;
        unique_lock& operator=(unique_lock&&) noexcept;

        // 33.4.4.3. locking
        void lock();
        bool try_lock();

        template <class Rep, class Period>
        bool try_lock_for(const chrono::duration<Rep, Period>& rel_time);

        template <class Clock, class Duration>
        bool try_lock_until(const chrono::time_point<Clock, Duration>& abs_time);

        void unlock();

    private:
        mutex_type* pm; // exposition only
        bool owns(); // exposition only

        template<class Mutex> unique_lock(unique_lock<Mutex>) -> unique_lock<Mutex>;

        template<class Mutex>
        void swap(unique_lock<Mutex>& x, unique_lock<Mutex>& y) noexcept;
};};
```

An object of type unique_lock controls the ownership of a lockable object within a scope. Ownership of the lockable object may be acquired at construction or after construction, and are not copyable but can be transferred, acquisition to unique_lock. Objects of type unique_lock are not copyable. The behavior of a program depends on whether the container pm is null and the lockable object pointed to pm does not exist for the remaining lifetime of the unique_lock object. The supplied Mutex type meets the BasicRequirements (33.2.5.1).

> Note: unique_lock<Mutex> meets the BasicRequirements. If Mutex meets the Lockable requirements (33.2.5.3), unique_lock<Mutex> also meets the TimedLock requirements (33.2.5.4), unique_lock<Mutex> also meets the TimedLock requirements.

## 33.4.4.3.1 unique_lock_constructors, destructor, and assignment [thread.lock_unique.cons]

- unique_lock() noexcept;
  Effects: Constructs an object of type unique_lock.
  Postconditions: pm == nullptr and owns == false.

- unique_lock(mutex_type& m);
  Requires: if mutex_type is not a recursive mutex the thread does not hold the mutex.
  Effects: Constructs an object of type unique_lock and calls m.lock().
  Postconditions: pm == addressof(m) and owns == true.

- unique_lock(mutex_type& m, defer_lock_t) noexcept;
  Effects: Constructs an object of type unique_lock.
  Postconditions: pm == addressof(m) and owns == false.

- unique_lock(mutex_type& m, try_to_lock_t);
  Requires: The supplied Mutex type shall meet the Lockable requirements (33.2.5.3). If mutex_type is not a recursive mutex the calling does not out the mutex.
  Effects: Constructs an object of type unique_lock and calls m.try_lock().
  Postconditions: pm == addressof(m) and owns == res, where res is the value returned by the call to m.try_lock().

- unique_lock(mutex_type& m, adopt_lock_t);
  Requires: The calling thread owns the mutex.
  Effects: Constructs an object of type unique_lock.
  Postconditions: pm == addressof(m) and owns == true.
  Throws: Nothing.

- template<class Clock, class Duration> unique_lock(mutex_type& m, chrono::time_point<Clock, Duration>& abs_time);
  Requires: If mutex_type is not a recursive mutex the calling does not out the mutex. The supplied Mutex shall meet the Lockable requirements (33.2.5.4).
  Effects: Constructs an object of type unique_lock and calls m.try_lock_until(abs_time).
  Postconditions: pm == addressof(m) and owns == res, where res is the value returned by the call to m.try_lock_until(abs_time).

- template<class Rep, class Period> unique_lock(mutex_type& m, chrono::duration<Rep, Period>& rel_time);
  Requires: If mutex_type is not a recursive mutex the calling does not out the mutex. The supplied Mutex shall meet the Lockable requirements (33.2.5.4).
  Effects: Constructs an object of type unique_lock and calls m.try_lock_for(rel_time).
  Postconditions: pm == addressof(m) and owns == res, where res is the value returned by the call to m.try_lock_for(rel_time).

- unique_lock(const unique_lock&) = delete;
- unique_lock& operator=(const unique_lock&) = delete;

- unique_lock(unique_lock&&) noexcept;
- unique_lock& operator=(unique_lock&&) noexcept;
