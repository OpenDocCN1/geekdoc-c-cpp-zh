# ISO/IEC 14882:2017(E)

## Class template packaged_task

The class packaged_task defines a type for wrapping a future object so that the return value of the function or callable object is stored in a future (whether normal or exceptional) stored in the shared state.

When the packaged_task object is invoked, its stored state is invoked and the shared state will then be able to access the stored state.

```cpp
namespace std {

template<class> class packaged_task; // not defined

template<class R, class... Args>
class packaged_task<R(Args...)> {
public:
    // construction and destruction
    packaged_task();
    template<class F>
    packaged_task(F&& f);
    ~packaged_task();

    // no copy
    packaged_task(const packaged_task&) = delete;
    packaged_task& operator=(const packaged_task&&) = delete;
};
```

### packaged_task member functions

packaged_task() noexcept;
- 1 Effects: Constructs a packaged_task object with no shared state and no stored state.

```cpp
template <class F>
packaged_task(F&& f);
```
- 2 **Requires**: INVOKE(f, t1, t2, ..., tN) (23.14.3), where t1, t2, ..., tN are values in Args..., shall be a valid expression. Invoking a copy of f shall have the same name as invoking f.
- 3 **Remarks**: This constructor shall not participate in overload resolution if decay<T> is the same type as packaged_task<R(Args...)>.
- 4 **Effects**: Constructs a new packaged_task object with a shared state and initializes the object's state with std::forward<F>(f).
- 5 **Throws**:
    - (5.1) Any exceptions thrown by the constructor or move constructor of f.
    - (5.2) For the first version, bad_alloc memory for the internal data structures could not be allocated.
    - (5.3) For the second version, any exceptions thrown by allocator_traits<Allocator>::template rebind_traits<unspecified_type>::allocate.

packaged_task(packaged_task&& rhs) noexcept;
- 6 Effects: Constructs a new packaged_task object and transfers ownership of rhs's shared state to *this, leaving rhs with no shared state. Moves the stored task from rhs to *this.
Postconditions: rhs has no shared state.

packaged_task&& operator=(packaged_task&& rhs) noexcept;
- Effects:
    - Releases any shared state (33.6.5);
    - calls packaged_task(std::move(rhs)).swap(*this).

packaged_task();
- Effects: Abandons any shared state (33.6.5).

void swap(packaged_task&& other) noexcept;
- Effects: Exchanges the shared states and stored tasks of *this and other.
Postconditions: *this has the same shared state and stored task (if any) prior to the call to swap, other has the same shared state and stored task (if any) as prior to the call to swap.
