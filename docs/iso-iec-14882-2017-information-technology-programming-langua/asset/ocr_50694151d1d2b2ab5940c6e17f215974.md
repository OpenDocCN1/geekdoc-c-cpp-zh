# 11.6.1 Aggregates

[dcl.init.aggr] An aggregate is an array or class (Clause 12)

+   1 — user-provided, explicit, or inherited constructors ([15.1).

+   (1.1) — private or protected non-static data members (Clause 14),

+   (1.2) — virtual functions

+   (1.4) — virtual, private, or protected base classes ([13.1).

> [Note: Aggregate initialization does not allow accessing and private class members' constructors. — end note].

+   2 The elements of the aggregate are:

+   (2.1) — for array, the array elements in increasing sort order, or

+   (2.2) — for class, the data in declaration order, followed by the next non-static data members ([12.2.2) that are not members of an anonymous union, or declaration

+   3 When an aggregate is initialized by an initializer list as specified in 11.6.4, the elements of the initializer list are taken as initializers for the elements of the aggregate, in order. Each element is copy-initialized from the corresponding initializer-clause. If the initializer-clause is absent and a narrowing conversion ([11.6.4) is required to convert the expression, the program is ill-formed.
