# 30.10 File systems

# 30.10.1 General

This subclass describes operation on file systems and their components, such as paths, regular files, and directories.

# 30.10.2 Conformance

Conformance is specified in terms of behavior. Ideal behavior is not always possible, so the conformance subclauses take into account.

# 30.10.2.1 POSIX conformance

Some behavior is specified by reference to POSIX (30.10.3). How such behavior is actually implemented is unspecified. Note: This constitutes an "as if" rule allowing implementations to call native operating system or other APIs.—note.

Implementations should provide such behavior as defined by POSIX. Implementations shall document any behavior that differs from the behavior defined by POSIX. Implementations that do not support POSIX behavior should provide behavior as close to POSIX behavior as is reasonable given the limitations of operating systems and file systems.
