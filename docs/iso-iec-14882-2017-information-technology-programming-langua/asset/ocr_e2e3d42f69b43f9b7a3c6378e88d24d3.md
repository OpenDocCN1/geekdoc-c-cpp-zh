# 10.1.7.3 Elaborated type specifiers

```
elaborated-type-specifier:
    class attribute-specifier-seq_opt nestamel-name-specifier_opt identifier
    class simple-template-id
    class nested-name-specifier_opt simple-template-id
    enum nested-name-specifier_opt identifier
```

+   1 An attribute-specifier-seq shall not appear in an elaborated-type-specifier unless the latter is constituent of a declaration. If an elaborated-type is the constituent of a declaration, the declaration is ill-formed unless it is an explicit instantiation (17.7.3) or it has one of the following (17.7.2):

```
class attribute-specifier-seq_opt identifier;
    friend class ::opt simple-template-id;
    friend class nested-name-specifier_opt identifier;
    friend class nested-name-specifier_opt simple-template-id;
```

In the first case, the attribute-specifier-seq, if any, pertains to the class being declared; the attributes in the attribute-specifier-seq are thereafter attributes of the class which is named. If the identifier resolves to a class-name or enum-name, the elaborated-type-specifier introduces it into the declaration as a simple type-specifier introduces its type. # 10.1.7.4 The auto specifier

+   1 The auto and decltype(auto) type-specifiers are used to designate a placeholder type that will be replaced by deduction from initialization. The auto-type-specifier is also used to replace a structured binding declaration (11.5).
