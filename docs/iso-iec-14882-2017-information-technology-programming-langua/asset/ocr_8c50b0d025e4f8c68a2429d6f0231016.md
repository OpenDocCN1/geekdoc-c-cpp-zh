10 Member functions (including virtual member functions, 13.3) can be called under object construction. Similarly, act under object construction can be the operand of the typeid operator (8.2.8) or of a dynamic_cast (8.2.7). However, if these operations are performed in a cot-initializer (or in a function called directly or indirectly from a cot-initializer) before all the mem-initializers for base classes have completed, the program has undefined behavior. [Example:

```
class A {
public:
    A();
};

class B : public A {
    int j;
public:
    B() : A(f()), // undefined: calls member function base A not yet initialized
        j(f()) {}    // well-defined: bases are all initialized
};

class C {
public:
    C(int);
};

class D : public B, C {
    int i;
public:
    D() : C(f()), // undefined: calls member function but base C not yet initialized
        i(f()) {}    // well-defined: bases are all initialized
};
```
