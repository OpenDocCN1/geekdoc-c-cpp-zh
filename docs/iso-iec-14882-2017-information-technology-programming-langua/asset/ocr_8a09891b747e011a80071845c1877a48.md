# ISO/IEC 14882:2017(E)

Throws: Any exception by calling the selected constructor of T.

Remarks: This function does not participate in overload resolution unless there is exactly one occurrence
of Types... and is_constructible<T, Args...> is true. If T's selected constructor is a
const constructor, this constructor shall be a const constructor.

```
template <class T, class U, Args...>
constexpr explicit variant(in_place_type<T>, initializer_list<U> il, Args&... args);
```

Effects: The initialized value is as if direct-non-list-initializing an object of type T with
arguments il, std::forward<Args>(args)...;

Postconditions: holds_alternative<T>(*this) is true.

Throws: Any exception by calling the selected constructor of T.

Remarks: This function does not participate in overload resolution unless there is exactly one occurrence
of Types... and is_constructible<T, initializer_list<U>> is true. If T's
selected constructor is a const constructor, this constructor shall be a const constructor.

```
template <size_t I, Args... constexpr explicit variant(in_place_type<T>, Args&... args);
```

Effects: The initialized value is as if direct-non-list-initializing an object of type T i with
arguments il, std::forward<Args>(args)...;

Postconditions: index(I) is I.

Throws: Any exception by calling the selected constructor of Ti.

Remarks: This function does not participate in overload resolution unless

+   - I is less than sizeof...(Types)
- is_constructible<_v<T>, Args...> is true.

If T's selected constructor is a const constructor, this constructor shall be a const constructor.

```
template <size_t I, class U, Args...>
constexpr explicit variant(in_place_type<T>, initializer_list<U> il, Args&... args);
```

Effects: The initialized value is as if direct-non-list-initializing an object of type T with
arguments il, std::forward<Args>(args)...;

Postconditions: index(I) is I.

Remarks: This function does not participate in overload resolution unless

+   - I is less than sizeof...(Types)
- is_constructible<_v<T>, initializer_list<U>& Args...> is true.

If T's selected constructor is a const constructor, this constructor shall be a const constructor.

```
// allocator-extended constructors
template <class Alloc>
variant(allocator_arg_t, const Alloc&);
template <class Alloc>
variant(allocator_arg_t, const Alloc&, variant v);
template <class Alloc>
variant(allocator_arg_t, const Alloc&, variant&& v);
template <class Alloc, class T>
variant(allocator_arg_t, const Alloc&, T&& t);
template <class Alloc, class T, class...>
variant(allocator_arg_t, const Alloc&, in_place_type<T>, Args&... args);
```
