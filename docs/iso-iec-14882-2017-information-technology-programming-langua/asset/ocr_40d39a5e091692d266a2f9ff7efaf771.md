+   3 A virtual member function does not have to be overridden, for example:
struct B {
  virtual void fO();
};
struct D : B {
  void fint();
};
struct D2 : D {
  void fO();
};
The function f(int) in class D hides the virtual function f() in its base class; D::f(int) is not a virtual function. However, f() declared in D2 has the same name and the same parameter list as B::f(), and therefore is a virtual function that overrides the function B::f() even though B::f() is not visible in class D2. — end note

+   4 If a virtual function in class B is marked with the virt-specifier final and in a class derived from B a function D : overrides B::f, the program is ill-formed. [Example:
struct B {
  virtual void fO() const final;
};
struct D : B {
  void fO() const; // D::f attempts to override final B::f
};
 end note
