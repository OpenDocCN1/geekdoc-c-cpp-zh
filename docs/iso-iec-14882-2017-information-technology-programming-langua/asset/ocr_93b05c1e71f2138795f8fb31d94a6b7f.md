- (8.3) if X is a nested class of Y (12.5), or if shall be a member of a base class of Y (this lookup applies when turning to Y's enclosing classes, starting with the innermost class),33 or

31) This lookup applies whether the definition of X is nested within Y's definition or whether X's definition appears in a namespace scope Y's definition (12.2.5).
