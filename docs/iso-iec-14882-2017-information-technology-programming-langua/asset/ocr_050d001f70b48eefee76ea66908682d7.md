# D.4.3 Header <cdbool> synopsis

```
#define __bool_true_false_are i
```

+   1 The contents of the header <cdbool> are the same as the C standard library header <stdool.h>, with the following changes: The header <cdbool> and <cmath.h> shall not define macros named bool, true, or false.

SEE ALSO: ISO C 7.18

# D.4.4 Header <ctgmath> synopsis

```
#include <complex>
#include <cmath>
```

+   1 The header <ctgmath> simply includes the headers <complex> (29.5.1) and <cmath> (29.9.1).

> [Note: The overloads in C type-generic macros are already provided in <complex> and <cmath> by "sufficient" declarations. — end note]

| <float.h> | <setjmp.h> | <stdint.h> | <uchar.h> | |

The header <cmath> behaves as if it includes the header <complex>. The header <tgmath> behaves as if it includes the header <cmath>.
Every C header, each of which has a name of the form name.h, behaves as if each name placed in the standard library namespace scope, except for the functions described in 29.9.5, the declaration of :byte (21.2.1), and the functions and template declarations described in 21.2.5. It is unspecified whether these macros are declared or defined within namespace scope (6.3.0) of the namespace std and are injected into the global namespace scope (10.3.3).

> [Example: The header <stdlib.h> provides its declarations and definitions within the namespace std. may also provide the same declarations and definitions within the global namespace, as much as in the C Standard. It may provide these names within the namespace std. — end example]
