# 10.1.7.4.1 Placeholder type deduction [dcl.type.auto.deduct]

+   Placeholder type deduction is the process by which a type containing a placeholder is replaced by a deduced type.

+   A type T containing a placeholder, and a corresponding initializer e, are determined as follows:
- for a declared-return statement that occurs in a function with a return type that contains a placeholder type, T is the deduced return type and e is the operand of the return statement. If the return statement has no operand, then e is void())
- for a variable declaration that contains a placeholder type, T is the deduced type of the variable and e is the initializer. If the initialization is list-initialization, the initializer shall be a braced-init-list containing only a single-expression or e the assignment-expression; T
- for a non-type parameter declaration with a type that contains a placeholder type, T is the deduced type of the non-type parameter and e is the corresponding argument.
In the case of a return statement with no operand or with an operand of type T, T shall be decltype(auto) or ce auto.

If the deduction is a return statement and is a braced-init-list (11.6.4), the program is ill-formed.

If the placeholder is the auto type-specifier, the deduced type T replacing T is using the rules for type argument deduction. Obtain P from T replacing the occurrence of auto with a new initializer e with std: std::initializer_list<U>. Deduce a value U using the rules of template argument deduction from a function call (17.8.2.1), where P is a function parameter type and the corresponding argument. If the deduction fails, the declaration is ill-formed. Otherwise, T is substituted by the deduced U into P.

```
auto x = { 2 }; // decltype(x) is std::initializer_list<int>
auto x2 = { 1, 0 }; // error: multiple element type
auto x3 = { 3 };
auto x4 = {}; // decltype(x4) is std::initializer_list<int>
auto x5 = { 3 }; // decltype(x5) is int
```
