# 30.10.8.3 path requirements

+   In addition to the requirements (30.10.5), function template parameters named Source shall be one of:
- basic_string<EChar, traits, Allocator>. A function argument const Source source shall have an effective range [source.begin(), source.end).
- basic_string_view<EChar, traits>. A function argument const Source source shall have an effective range [source.begin(), source.end).\n- A type meeting the input requirements that iterates over NCTCTS. The value type shall be an encoded character. A function argument [source, end) where end is the first iterator with an element value equal to iterator_traits<Source>::value_type().

+   2 Functions template parameters named Source shall not participate in overload resolution unless
- Source is a specialization of basic_string or basic_string_view, or
- qualified_iterator_traits<decay<Source>>::value_type is valid and denotes a densely encoded character type (17.8.2).

+   3 [ Note: See conventions (30.10.8.2) for how the types above and their encodings convert to path::value_type and its encoding.— end note ]

+   4 Arguments of type Source shall not be null pointers.
