The simple-type-specifier opt is a placeholder for a type deduced from (10.1.7.4). A type-specifier of the form type-nested-name-specifier_opt template-name is a class template that is not an injected-class. The other simple-type-specifiers specify either a previously-declared type, a type determined from an expression, or one of the fundamental types (6.9.1). Table 11 summarizes the valid combinations of simple-type-specifiers and the types they specify.

When multiple simple-type-specifiers are allowed, they can be freely intermixed with other decl-specifiers in any order.
