+   1 The member-specification in a class declaration defines the full set of the class; no member can be added elsewhere. A direct member of a class X is a member of X that was first declared within the member-specification of X, including anonymous union objects (12.3.1) and direct members thereof. Members of a class are data members, member functions (12.2.1), nested types, enumerators, and member templates (17.5.2) and specializations. [Note: A specialization of a static data member template is a specialization of a member class template is a member function. — end note]

+   2 A member-declaration does not declare new members of the class if it is
(2.1) — a friend declaration (14.3)
(2.2) — a static_assert-declaration,
(2.3) — a using-declaration (10.3.3), or
(2.4) — an empty-declaration.

For other member-declaration, each declared that is not an unnamed bit-field (12.2.4) is a member of the class, and each such member-declaration shall declare at least one member of the class or declare least one unnamed bit-field.

3 A member or member function may declare static in its member-declaration, in which case it is a static member (a static member (12.2.2.3) or static member function (12.2.2.1), respectively). Any other declaration is a non-static member (a non-static data member or non-static member function (12.2.2), respectively). [Note: a non-static data member of non-reference type is a member of a class object (4.5) — end note]

4 A member shall not be declared twice in the member-specification, except that

+   (5.1) — a nested class or member class template can be declared and then later defined, and
(5.2) — an enumeration can be introduced with an opaque-enum-declaration and redeclared with an new-specifier.

> [Note: A single name can denote several functions provided their types are sufficiently different (Clause 16) — end note]

6 A class is considered a completely-defined object type (6.9) or complete type by the closing ) of the class-identifier. The member-specification is regarded complete within function bodies, default arguments, noexcept-specifiers, and default member initializers (including such things in nested classes). Otherwise it is regarded as incomplete within its own class member-specification.
