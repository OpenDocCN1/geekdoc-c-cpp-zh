# 31.8.2 basic_regex constructors

```
basic_regex();
```

+   1 Effects: Constructs an object of class basic_regex that does not match any character sequence.
   explicit basic_regex(const char* p, flag_type f = regex_constants::ECMAScript);
2 Requires: p shall not be a null
3 Throws: regex_error if p is not a valid regular expression.
4 Effects: Constructs an object of class basic_regex; the object's internal state machine is constructed from the regular expression contained in the array of charT of length traits<charT>::length(p) whose first element is designated by p, and interpreted according to flags f.
5 Postconditions: flags() returns mark_count() the number of marked sub-expressions within the expression.
basic_regex(const char* p, size_t len, flag_type f);
6 Requires: p shall not be a null.
7 Throws: regex_error if p is not a valid regular expression.
8 Effects: Constructs an object of class basic_regex; the object's internal state machine is constructed from the regular expression constructed in the sequence of characters [p, p+len), and interpreted according the flags specified in f.
9 Postconditions: flags() returns mark_count() returns the number of marked sub-expressions within the expression.
basic_regex(const basic_regex& e);
10 Effects: Constructs an object of class basic_regex as a copy of the object e.
11 Postconditions: flags() and mark_count() return e.flags() and e.mark_count(), respectively.
