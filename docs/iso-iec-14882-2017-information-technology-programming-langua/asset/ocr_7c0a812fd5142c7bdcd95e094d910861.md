# ISO/IEC 14882:2017(E)

```
template <class money> unspecified get_money(moneyT& mon, bool intl = false);
```

Requires: The type money shall be either long double or a specialization of the basic_string template (Clause 24).

Effects: The expression in >> get_mon(mon, intl) described below behaves as a formatted function (30.7.2.1).

Returns: An object of unspecified type if that is an object of type basic_istream<charT, then the expression in >> get_money(mon, intl) behaves as if called f(in, mon, intl); where the function f is defined:

```
template <class charT, class traits, class money>
void f(basic_ios<charT, traits>& in, moneyT& mon, bool intl) {
    using Iter = istreambuf_iterator<char>;
    using Money = get_money<charT, Iter>;

    ios_base::iosstate err = ios_base::goodbit;
    const Money getMon = use<Money>(in.getloc());

    mg.get(Iter(in.rdbuf()), Iter(), intl, str, err);

    if (Iter(in.rdbuf()) != err || err != err) {
        in.setstate(err);
    }
}
```

The expression in >> get_money(mon, intl) shall have type basic_istream<charT, traits>& and return value in.

```
template <class money> unspecified put_money(const moneyT& mon, bool intl = false);
```

Requires: The type money shall be either long double or a specialization of the basic_string template (Clause 24).

Returns: An object of unspecified type if that is an object of type basic_ostream<charT, traits> then the expression << put_money(mon, intl) behaves as a formatted function (30.7.5.2.1) that calls f(out, mon, intl), where the function f is defined:

```
template <class charT, class traits, class money>
void f(basic_ostream<charT, traits>& out, const moneyT& mon, bool intl) {
    using Iter = ostreambuf_iterator<char>;
    using Money = put_money<charT, Iter>;

    const Money mPut = use<Money>(out.getloc());
    Iter end = mp.put(Iter(out.rdbuf()), intl, str.fill(), mon);

    if (end.failed()) {
        out.setstate(ios_base::badbit);
    }
}
```

The expression << put_money(mon, intl) shall have type basic_ostream<charT, traits>& and return value.
