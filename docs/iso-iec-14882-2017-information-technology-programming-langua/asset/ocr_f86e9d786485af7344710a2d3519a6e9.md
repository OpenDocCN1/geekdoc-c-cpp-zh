# ISO/IEC 14882:2017(E)

# 23.14.11.1 Class template is_bind_expression [func.bind.isbind]

```
namespace std {
  template<class T> struct is_bind_expression; // see below
}
```

1 The class template is_bind_expression can be used to detect function objects generated by bind. The function template uses is_bind_expression to detect subexpressions.

2 Instantiations of the is_bind_expression template shall meet the requirements. The implementation shall provide a definition that has a characteristic of true_type if T is a type returned from bind, otherwise it shall have a characteristic of false_type. A program may specialize this template for a user-defined T to have a characteristic of true_type to indicate that T should be treated as a subexpression associated with U.

# 23.14.11.2 Class template is_placeholder [func.bind.isplace]

```
namespace std {
  template<class T> struct is_placeholder; // see below
```

1 The class template is_placeholder can be used to detect placeholders _1, _2, and so on. The function template uses is_placeholder to detect placeholders.

2 Instantiations of the is_placeholder template shall meet the requirements. The implementation shall provide a definition that has the characteristic of integral_constant<int, J> if T is the type of std::placeholders::_J; otherwise it shall have a characteristic of integral_constant<int, O>. A program may specialize this template for a user-defined T to have a characteristic of integral_constant<int, N> with N > 0 to indicate that T should be treated as a placeholder type.
