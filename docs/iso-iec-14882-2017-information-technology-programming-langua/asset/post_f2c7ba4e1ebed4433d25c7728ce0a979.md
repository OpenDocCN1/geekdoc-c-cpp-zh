
# ISO/IEC 14882:2017(E)

> [Note: This constructor allows creation of an empty shared_ptr with a non-null stored pointer.
-- end note]

```
shared_ptr(const shared_ptr& r) noexcept;
template<class Y> shared_ptr(const shared_ptr<Y>& r) noexcept;
```

Remarks: The second constructor shall not participate in overload resolution Y* is compatible with Y*.

Effects: If r is empty, constructs an empty shared_ptr object; otherwise, constructs a shared_ptr that shares ownership with r.

Postconditions: get() == r.get() && use_count() == r.use_count().

```
shared_ptr(shared_ptr&& r) noexcept;
template<class Y> shared_ptr(shared_ptr<Y>&& r) noexcept;
```

Remarks: The constructor shall not participate in overload resolution Y* is compatible with Y*.

Effects: Move a shared_ptr instance from r.

Postconditions: *this contains the only value of r. r.get() == nullptr.

```
template<class Y> explicit shared_ptr(shared_ptr<Y>&& r);
```

Effects: Constructs a shared_ptr that shares ownership with r and copies of the pointer stored in r. If an exception is thrown, the constructor has no effect.

Postconditions: use_count() == r.use_count().

Throws: bad_ptr when r.expired().

Remarks: This constructor shall not participate in overload resolution Y* is compatible with T*.

```
template<class Y, D> shared_ptr(unique_ptr<Y>, D& d);
```

Remarks: This constructor shall not participate in overload resolution Y* is compatible with T* and unique_ptr<Y>,:pointer is convertible to element_type.

Effects: If r.get() == nullptr, equivalent to shared_ptr(r). Otherwise, if D is not a reference type, equivalent to shared_ptr(r.release(), r.get_delete()). Otherwise, equivalent to shared_ptr(r.release()), ref(r.get_delete())). If an exception is thrown, the constructor has no effect.

# 23.11.2.2 shared_ptr destructor

```
[util.smartptr.shared_ptr.dest]
```

- *this is empty or shares ownership with another shared_ptr instance (use_count() > 1), there are no side effects.
- Otherwise, *this owns an object p and a deleter, d(p) is called.
- Otherwise, *this owns a pointer, and delete p is called.

> [Note: Since the destruction of this decreases the number of instances that share ownership with *this by one, after this has been destroyed all shared_ptr instances that share ownership with *this will report a use_count() that is one less than its previous value.
-- end note]

# 23.11.2.3 shared_ptr assignment

```
[util.smartptr.shared_ptr.assign]
```

```
shared_ptr& operator=(const shared_ptr& r) noexcept;
template<class Y> shared_ptr& operator=(const shared_ptr<Y>& r) noexcept;
```

Effects: Equivalent to shared_ptr(r).swap(*this).

Returns: *this.

[Note: the use count updates by the temporary object construction and destruction are not observable effects, so the implementation may meet the effects (and the implied guarantees) via different means, without creating a temporary. In particular, the example:

```
shared_ptr<int> p(new int);
shared_ptr<void> q(p);
p = p;
q = q;
```

both assignments may be no-op. — end note

```
shared_ptr& operator=(shared_ptr&& r) noexcept;
template<class Y> shared_ptr& operator=(shared_ptr<Y>&& r) noexcept;
```

Effects: Equivalent to shared_ptr(std::move(r)).swap(*this).

Returns: *this.

```
template<class Y, class D> shared_ptr& operator=(unique_ptr<Y, D&&> r);
```

Effects: Equivalent to shared_ptr(std::move(r)).swap(*this).

Returns: *this.

# 23.11.2.4 shared_ptr modifiers

```
void swap(shared_ptr& r) noexcept;
```

Effects: Exchanges the contents of *this and r.

```
void reset() noexcept;
```

Effects: Equivalent to shared_ptr().swap(*this).

```
template<class Y> void reset(Y* p);
```

Effects: Equivalent to shared_ptr(p).swap(*this).

```
template<class Y, class D> void reset(Y* p, D d);
```

Effects: Equivalent to shared_ptr(p, D).swap(*this).

```
template<class Y, class D, class A> void reset(Y* p, D D, A A);
```

Effects: Equivalent to shared_ptr(p, d, a).swap(*this).

Returns: *get().

Remarks: When T is an array type or void, it is unspecified whether this member function is declared. If it is declared, it is unspecified what its return type is, except that the declaration (although not the definition) of the function shall be well formed.

T operator->() const noexcept;
```

Requires: get() != 0;

When T is an array type, it is unspecified except that member function is defined. If it is declared, it is unspecified what its return type is, except that the declaration (although not the definition) of the function shall be well formed.

```
element_type operator[](ptrdiff_t i) const;
```

Requires: get() != 0 && i >= 0. If T is U[N], i < N.

```

```

When T is an array type, it is unspecified except that member function is defined. If it is declared, it is unspecified what its return type is, except that the declaration (although not the definition) of the function shall be well formed.

Throws: Nothing.

```
long use_count() const noexcept;
```

Returns: The shared_ptr objects, *this, that share ownership with *this, or when this is empty.

Synchronization: None.

> [Note: use_count() == nullptr does not imply a return value of use_count(). — end note]
> [Note: weak_ptr<T> can affect the return value of use_count(). — end note]
> [Note: When multiple threads access the value of use_count() == 1, the result should be treated as access to a previously destroyed shared_ptr in any sequence. — end note]

# 23.11.2.6 shared_ptr comparison [util.smart.shared.cmp]

```

```

Returns: a() = b.get().

```

Returns: less()(a.get(), b.get()).
```

```

6 Returns: The first function template returns less<shared_ptr<T>::element_type*>>(a.get(), nullptr). The second function template returns less<shared_ptr<T>::element_type*>(nullptr, a.get()).

7 Returns: The first function template returns nullptr < a. The second function template returns a a <

```
template<class T, class... Args>
shared_ptr<T> make(Args&&...);
template<class T, class... Args, template<class A, class... Args2>
shared_ptr<T> make(A&& a, Args&&...);
```

Requires: The expression : new (pv) (T(std::forward<Args)...)), where pv has type void* and points to storage to hold an object of type T, shall be well-formed. A shall be an allocator<20.5.3.5>. The constructor and destructor of A shall not throw exceptions.

Effects: Allocates memory for an object of type T and constructs an object in memory via the placement new-expression new (pv) (T(std::forward<Args)...)). The template allocate_shared uses a copy to allocate. If an exception is thrown, the functions have no effect.

3 Returns: A shared_ptr stores and owns the address of the newly constructed object of T.

4 Postconditions: get() != 0 && use_count() == 1.

5 Throws: bad_alloc, or an exception from A::allocate or from the constructor of T.

6 Remarks: The shared_ptr constructor called by this function shared_from_this with the address of the newly constructed object of T. Implementations should perform no than one memory allocation. [Note: This provides efficiency to an intrusive smart pointer. — end note]

[Note: These functions will typically allocate more memory than sizeof(T) to allow for bookkeeping structures such as the reference count. — end note]
