# 29.6.1.2 Seed sequences

+   1 A seed sequence is an object that consumes integer-valued data and produces a requested number of unsigned integer values, 0 ≤ i < 2^n, based on the consumed data. [Note: Such an object provides a mechanism to allow replication of random variables. This can be useful, for example, in applications requiring large numbers of random number engines. — note]

+   2 A S satisfies the requirements of a seed sequence if the expressions shown in this section 102 are valid and have indicated the semantics, or if S also satisfies all other requirements of section 29.6.1.2. In that Table and this section:

+   a) T is the type named by S's result_type;

+   b) q is a value of S and r is a possible value of S;

+   c) ib and ie are mutable random iterators with an unsigned integer value_type of at least 32 bits;

+   d) rb and re are random access iterators with an unsigned integer value_type of at least 32 bits;

+   e) ob is an output iterator;

+   f) il is a value of initializer_list<T>.
