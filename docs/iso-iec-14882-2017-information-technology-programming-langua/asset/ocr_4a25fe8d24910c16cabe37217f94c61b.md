# ISO/IEC 14882:2017(E)

# 27.7 Range access

1. In addition to being available via inclusion of the <iterator> header, the function templates in 37.7 are available when any of the following headers are included: <array>, <deque>, <forward_list>, <list>, <map>, <regex>, <set>, <string>, <string_view>, <unordered_map>, <unordered_set>, and <vector>.

```
template <class> constexpr auto begin(C c) -> decltype(c.begin());
template <class> constexpr auto begin(const C c) -> decltype(c.begin());
```

2. Returns: c.begin();

```
template <class> constexpr auto end(C c) -> decltype(c.end());
template <class> constexpr auto end(const C c) -> decltype(c.end());
```

3. Returns: c.end();

```
template <class, size_t N> constexpr T begin(T (&array[N])) noexcept
```

4. Returns: array + N.

```
template <class, size_t N> constexpr T end(T (&array[N])) noexcept
```

5. Returns: array + N.

```
template <class> constexpr auto begin(const C c) noexcept(noexcept(std::begin(c)))
-> decltype(std::begin(c));
```

6. Returns: std::begin(c);

```
template <class> constexpr auto rbegin(const C c) noexcept(noexcept(std::end(c)))
-> decltype(std::end(c));
```

7. Returns: std::end(c);

```
template <class> constexpr auto rbegin(const C c) -> decltype(c.rend());
template <class> constexpr auto rbegin(const C c) -> decltype(c.rend());
```

8. Returns: c.rend();

```
template <class> constexpr auto rend(const C c) -> decltype(c.rend());
template <class> constexpr auto rend(const C c) -> decltype(c.rend());
```

9. Returns: c.rend().

```
template <class, size_t N> constexpr reverse_iterator<T*> rbegin(T (&array[N]));
```

10. Returns: reverse_iterator(array + N).

```
template <class, size_t N> constexpr reverse_iterator<T*> rend(T (&array[N]));
```

11. Returns: reverse_iterator(array).

```
template <class> constexpr auto rbegin(const E& e) -> initializer_list<const E>;
```

12. Returns: reverse_iterator(e.end());

```
template <class> constexpr auto rend(const E& e) -> initializer_list<const E>;
```

13. Returns: reverse_iterator(e.begin());

```
template <class> constexpr auto rbegin(const C c) -> decltype(std::begin(c));
Returns: std::begin(c);
```
