## 24.3.2 Class template basic_string

The template basic_string describes objects that can store a sequence of a varying number of char-like objects with the first element at position zero. Such a sequence is also called a "string" if the type of the char-like objects it holds is clear from context. In the rest of this Clause, the type of the char-like objects it holds is designated by the Allocator class as a template parameter to allocate and free storage for the contained objects. In all cases, size() <= capacity(). The functions described in this Clause report two kinds of errors, each associated with a type:

- (1) a length error is associated with type length_error;
- (2) an out-of-range error is associated with type out_of_range.

```cpp
namespace std {
    template<class charT, class traits = char_traits<charT>, class Allocator = allocator<charT>>
    class basic_string {
    public:
        // types:
        using traits_type = traits;
        using value_type = charT;
        using allocator_type = Allocator;
        using size_type = typename allocator_traits<Allocator>::size_type;
        using difference_type = typename allocator_traits<Allocator>::difference_type;
        using pointer = typename allocator_traits<Allocator>::pointer;
        using const_pointer = typename allocator_traits<Allocator>::const_pointer;
        using reference = value_type&;
        using const_reference = value_type&;

        using iterator = implementation_defined;
        using const_iterator = implementation_defined;
        using reverse_iterator = std::reverse_iterator<iterator>;
        using const_reverse_iterator = std::reverse_iterator<const_iterator>;
        static const size_type npos = -1;

        Allocator::value_type must not be the same name as charT.
