# 27.2.3 Input iterators [input/iterators]

+   1 A class or pointer type X is used as an input iterator for the value type T if X satisfies the Iterator (27.22) and EqualityComparable (Table 20) requirements and the expressions in Table 95 are valid and have the indicated semantics.

+   2 In Table 95, the term domain of == is (required to be) defined in the ordinary mathematical sense to denote the set of values over which == is for the iterators it uses. This can be changed with order. Each algorithm adds requirements on the domain of == to be inferred from the uses that algorithm makes of == and !=. Example: The call find(a,b,x) is defined only if the property p defined as follows: b has property p and a value has property p (*i==x) if (*i==x and **i has property p). — example
