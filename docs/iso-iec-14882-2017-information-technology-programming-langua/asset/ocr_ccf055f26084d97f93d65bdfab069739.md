# 29.5.7 complex value operations [complex.value.ops]

```
1 template<class T> real(const complex<T>& x);
Returns: x.real();
```

```
2 template<class T> imag(const complex<T>& x);
Returns: x.imag();
```

```
3 template<class T> abs(const complex<T>& x);
Returns: The magnitude of x.
```

```
4 template<class T> arg(const complex<T>& x);
Returns: The phase angle of x, or atan2(imag(x), real(x)).
```

```
5 template<class T> norm(const complex<T>& x);
Returns: The squared magnitude of x.
```

```
6 template<class T> conj(const complex<T>& x);
Returns: The complex conjugate of x.
```

```
7 template<class T> proj(const complex<T>& x);
Returns: The projection of x onto the Riemann sphere.
```

8 Remarks: Behaves the same as the Function cproj, defined in 7.3.9.4.

```
9 template<class T> polar(const complex<T>& x, const T& theta = 0);
Returns: rho must be non-negative and non-NaN. theta must be finite.
```

```
10 Returns: The value corresponding to a complex number whose magnitude is rho and whose phase is theta.
```
