A template-argument A matches a template-parameter P when P is at least as specialized as the template-argument A if P contains a pack, then also P matches the corresponding template-list of P. Two template parameters match if they are the same kind (type, non-type, for non-type template-parameters, their types are equivalent (17.5.6.1), and for template-parameters, each of their corresponding template-parameters matches, recursively). When P's template-parameter-list contains a template pack P (17.5.3), the template-parameter-list of A matches zero or more template parameters or template packs in P (ignoring whether template arguments are template parameters).

Example:

```
template<class T> class A { /* ... / };
template<class T, class U = T> class B { /* ... / };
template<class...> class C { /* ... / };
template<auto n> class D class X { /* ... / };
template<class T, class... > class E class Y { /* ... / };
template<int T, class R> class Z { /* ... / };
```

```
X<int> y;      // OK
X<B> b;        // OK
X<int> c;      // OK
Y<int> a;      // OK
Y<float> b;   // OK
Y<C> c;       // OK
Z<int, 2> d;   // OK
```

Example:

```
template<class T, class...> class TT, class T1, class... Rest
struct eval<TT<T1, Rest...>> { };
```

```
template<class T1> struct A;
template<class T1, class T2> struct B;
template<int R> struct C;
template<class T1, int R> struct D;
template<class T1, class T2, int N = 7> struct E;
```

```
eval<int> a;          // OK: matches partial specialization of eval
eval<int, float> b; // OK: matches partial specialization of eval
eval<<int<17>> c;  // error: C does not match TT in partial specialization
eval<int, 17>> d;   // error: D does not match TT in partial specialization
eval<int, float> e;  // error: E does not match TT in partial specialization
```
