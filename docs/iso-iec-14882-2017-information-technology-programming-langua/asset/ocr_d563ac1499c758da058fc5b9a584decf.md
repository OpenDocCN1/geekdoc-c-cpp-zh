# 8.17 Throwing an exception

throw-expression:
throw throw-expression,opt

1 A throw-expression is of void.

2 Evaluating a throw-expression with an operand throws an exception (18.1); the type of the exception is determined by removing any top-level cv-qualifiers from the currently held type of operand and adjusting the type from “array of T or function T” to “pointer to T

3 A throw-expression with no argument retrieves the exception (18.3). The exception is reactivated with the existing object; no new exception is created. The exception is no longer considered to be caught. Example: Code that must be executed because of an exception, but completely handle the exception itself, can be written like this:

```
try {
  / ...
} catch (...) { // catch all exceptions
  respond (partially) to exceptions
  // pass the exception to other handler
}

// end example
```

4 If no exception is being handled, evaluating a throw-expression with no operand calls std::terminate(18.5).
