# 23.16 Compile-time rational arithmetic [ratio]

# 23.16.1 In general [ratio.general]

1 This subclass describes the ratio library. It provides a class template which exactly represents finite rational number with a numerator and denominator representable by compile-constants of type intmax_t.

2 Throughout this subclass, the names of template parameters are used to express type requirements. A template parameter is named R1 or R2, and the template argument is not a specialization of the ratio template, the program is ill-formed.
