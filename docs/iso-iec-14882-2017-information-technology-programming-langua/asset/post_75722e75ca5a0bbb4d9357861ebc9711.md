## 23.5.3.1 Construction [tuple.constr]

- For each tuple constructor, an exception is thrown only if the construction of one of the types in Types throws an exception.
- The default move and copy constructor, respectively, of tuple shall be constexpr function if and only if all required-element-initializations for copy and move, respectively, would satisfy the requirements for a constexpr function. The default move and copy constructor of tuple<...> shall be constexpr functions.
- The destructor of tuple shall be a trivial destructor if (is_trivially_destructible_v<Types> && ...) is true.
- In the constructors that follow, let i be in the range [0, sizeof...(Types)]. In order, the i-th type in Types, and the i-th type in a template parameter named Types, which is zero-based.

```cpp
explicit constructor tuple();
```

**Effects:** Initialize each element.

**Remarks:** This constructor shall not participate in overload resolution unless is_default_constructor_v<T> is true for all i. [Note: This behavior can be implemented by a constructor template with default-constructor for at least one. — end note] The constructor is explicit if and only if T is not implicitly default-constructor for at least one i. [Note: This behavior can be implemented with a trait that checks whether a T can be initialized with {}. — end note]

```cpp
explicit constructor tuple(const Types&&&);
```

**Effects:** Initialize each element in the tuple with the value of the corresponding parameter.

**Remarks:** This constructor shall not participate in overload resolution unless sizeof...(Types) == ... and is_convertible_v<T, U> is true for all i. The constructor is explicit if and only if is_convertible_v<const T, U&> is false for at least one i.

```cpp
template <class Types...> explicit constructor tuple(const Types&&... u) : ...;
```

**Effects:** Initialize each element of *this with std::forward<Types>(u).

```cpp
tuple(const tuple& u) = default;
```

**Requires:** is_convertible_v<T, U> is true for all i.

**Effects:** Initialize each element of *this with the corresponding element of u.

```cpp
template <class Types...> explicit constructor(const tuple<Types...>&& u) : ...;
```

**Effects:** Initialize each element of *this with the corresponding element of u.

- sizeof...(Types) == sizeof...(U)
- is_convertible_v<T, const U&> is true for all i, and
- sizeof...(Types) != 1, or (when Types...) expands to T and UTypes...) expands to U
- !is_constructible_v<const tuple<U>&, T> && !is_constructible_v<T, const tuple<U>> && !is_same_v<T, U> is true.

The constructor is explicit if and only if is_constructible_v<const U, T> is false for at least one i.

```cpp
template <class... Utypes> explicit constexpr tuple(tuple<UTypes...>& u);
```

**Effects:** For all i, it initializes the i-th element of *this with std::forward<U>(get<i>(u)).

**Remarks:** This constructor does not participate in overload resolution.

- (18.1) size(...) == sizeof...(UTypes)...
- (18.2) is_constructible_v<T, U> is 1, or when for all i, size(...) == 1 expands to T and Utypes expands to U !is_constructible_v<U, T> && !is_constructible_v<T, tuple<U>> && !is_same_v<T, U> is true.

The constructor is explicit if and only if is_constructible_v<const U, T> is false for at least one i.

```cpp
template <class U1, class U2> explicit constexpr tuple(pair<U1, U2>& u);
```

**Effects:** it initializes the first element with u.first and the second element with u.second.

**Remarks:** This constructor does not participate in overload resolution size...(UTypes) == 2, is_constructible_v<CT0, U1> is true or is_constructible_v<CT1, U2> is true. The constructor is explicit if and only if is_constructible_v<const U1, T1> is false or is_constructible_v<const U2, T2> is false.

```cpp
template <class U1, class U2> explicit tuple(pair<U1, U2>& u);
```

**Effects:** it initializes the first element with std::forward<U1>(u.first) and the second element with std::forward<U2>(u.second).

**Remarks:** This constructor does not participate in overload resolution size...(UTypes) == 2, is_constructible_v<CT0, U1> is true or is_constructible_v<CT1, U2> is true. The constructor is explicit if and only if is_constructible_v<const U1, T1> is false or is_constructible_v<const U2, T2> is false.

```cpp
template <class Alloc>
explicit tuple(allocator_arg_t, Alloc a, const Utypes&...);
template <class Alloc>
explicit tuple(allocator_arg_t, Alloc a, Utypes&...);
template <class Alloc>
explicit tuple(allocator_arg_t, Alloc a, const tuple&&...);
template <class Alloc>
explicit tuple(allocator_arg_t, Alloc a, tuple&&);
template <class Alloc>
explicit tuple(allocator_arg_t, Alloc a, Utypes&&...);
template <class Alloc>
explicit tuple(allocator_arg_t, Alloc a, const tuple<UTypes...>&...);
template <class Alloc>
explicit tuple(allocator_arg_t, Alloc a, Utypes&&...);
template <class Alloc>
explicit tuple(allocator_arg_t, Alloc a, const pair<U1, U2>&);
template <class Alloc>
explicit tuple(allocator_arg_t, Alloc a, pair<U1, U2>&&);
```

**Requires:** Alloc shall meet the requirements for an Allocator (20.5.3.5).

**Effects:** Equivalent to the preceding constructors except that each element is constructed with users-allocator constructor (23.10.7.2).

## 23.5.3.2 Assignment [tuple,assign]

For each tuple assignment operator, an exception is thrown only if the assignment of one of the types in Types throws an exception. In the function descriptions that, let i be in the range [0, sizeof...(Types)] in order, Ti be the i-th type in Types, and Ui be the i-th type in a template parameter named Utypes, where indexing is zero-based.

```cpp
tuple& operator=(const tuple& u);
```

**Effects:** This operator shall be defined unless is_copy_assignable_v<T> is true for all i.

**Returns:** *this.

```cpp
tuple& operator=(tuple&& u);
```

**Effects:** For all i, assign std::forward<T>(get<i>(u)) to *this.

**Remarks:** This operator is defined unless is_move_assignable_v<T> is true for all i.

```cpp
template <class... Utypes> tuple& operator=(const tuple<Utypes...>&& u);

```

**Effects:** For all i, assign std::forward<U>(get<i>(u)) to *this.

**Remarks:** This constructor does not participate in overload resolution size...(Types) == ... . The constructor is explicit if and only if is_constructible_v<const U, T> is false for at least one i.

```cpp
template <class U1, class U2> tuple& operator=(pair<U1, U2>& u);
```

**Effects:** it initializes the first element with std::forward<U1>(u.first) and the second element with std::forward<U2>(u.second).

**Remarks:** This constructor does not participate in overload resolution size...(UTypes) == 2.

## 23.5.3.3 swap [tuple.swap]

```cpp
void swap(tuple& rhs) noexcept;
```

1. Each element in *this is swappable with rhs.
2. **Effects:** Swap each element in *this and its corresponding element in rhs.
3. **Remarks:** The expression noexcept is equivalent to the logical AND of the following expressions: is_swappable_v<T>, where Ti is the i-th type in Types.
4. **Throws:** Unless one of the element-wise swap calls an exception.

## 23.5.3.4 Tuple creations [tuple.creation]

1. In the function descriptions that, the members of XTypes are denoted by Xi, for i in [0, sizeof...(XTypes)], where indexing is zero-based.

```cpp
template<class TTypes>
constexpr tuple<TTypes...> make_tuple(TTypes&&... t);
```

2. The pack VTypes is defined as follows. Let Ui, decay_t<Ti> for each Ti, in Types. If Ui is a specialization of reference_wrapper, then Vi in VTypes is Ui::type; otherwise Vi is Ui.

3. **Returns:** tuple<TTypes...>(std::forward<T>(t)...).

4. **Example:**
```cpp
int i; float j;
make_tuple(1, ref(i), ref(j)) creates a tuple<int, float&, float&
```

```cpp
template<class TTypes>
constexpr tuple<TTypes...> forward_as_tuple(TTypes&&... t) noexcept;
```

5. **Effects:** Constructs a tuple of references to the arguments in t suitable variables, a program shall ensure that the return value of this function does not outline any of its arguments.

6. **Returns:** tuple<TTypes...>(std::forward<TTypes>(t)).

```cpp
template<class TTypes>
constexpr tuple(TTypes&&... t) noexcept;
```

7. **Remarks:** When an argument t is ignore, assigning any value to the corresponding tuple element has effect.
