# ISO/IEC 14882:2017(E)

# 10.1.3 The typedef specifier

Declarations containing the typedef specifier (6.9.2) declare identifiers that can be used for naming fundamental (6.9.1) or compound (6.9.2) types. The typedef specifier shall not be combined in a decl-specifier-seq with any other kind of spec except a defining-type, and it shall not be used in the decl-specifier-seq of a parameter-declaration (11.3.5) nor in the decl-specifier-seq of a function-definition (11.4). If a typedef specifier appears in a declaration without a declarator, the program is ill-formed.

```
typedef-name:
identifier
```

A name declared with the typedef specifier becomes a typedef-name. Within the scope of its declaration, a typedef-name is syntactically equivalent to a keyword and the type associated with the identifier in the declaration in Clause 11. A typedef is a synonym for another type. A typedef-name does not introduce a new class declaration (12.1) or enumeration declaration. [Example:

```
typedef int MILES, KICKLES;
MILES distance,
extern int KICKLES metric;
```

are all correct declarations; the type of distance is int-declaration and of metric is "pointer to int". -- end example

+   2 A typedef-name can be introduced by an alias-declaration. The identifier using the keyword becomes a typedef-name and the optional attribute-specifier-seq following the identifier appears to be typedef-name. Such has the same semantics as if it were introduced by the typedef specifier. In particular, it does not introduce a new type. [Example:

```
void handler_t = void (*)(int);
extern void (*qsort)(int,
void *paroid,cell); // ill-formed

-- end example] The typedef-specifier-seg of the defining-type-id shall not define a class or enumeration if the alias-declaration is the declaration of a template-declaration.
```

```

-- end example
```
