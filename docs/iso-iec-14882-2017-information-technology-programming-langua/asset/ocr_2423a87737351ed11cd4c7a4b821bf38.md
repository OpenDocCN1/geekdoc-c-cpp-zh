# ISO/IEC 14882:2017(E)

# 31.11.3 regex_search

```
template <class BidirectionalIterator, class Allocator, class CharT, class traits>
bool regex_search(BidirectionalIterator first, BidirectionalIterator last,
match_results<BidirectionalIterator, Allocator&>& m,
nconst basic_regex<CharT, traits>& e,
regex_constants::match_flag_type flags = regex_constants::match_default);
```

+   * Requires: BidirectionalIterator shall satisfy the requirements of a Bidirectional Iterator (27.6).

+   * Effects: Determines whether there is sub-sequence [first, last) that matches the regular expression. The parameter flags is used to control how the expression is matched against the character sequence. Returns true if such a sequence exists, false otherwise.

+   * Postconditions: m.ready() == true in all cases. If the function returns false, then the effect on parameter m is unspecified unless m.size() and m.empty() returns true. Otherwise the effects on parameter m are given in Table 130.

Table 136 – Effects of regex_search algorithm

| Element | Value |
| --- | --- |
| m.size() | 1 + e.mark_count() |
| m.empty() | false |
| m.prefix().first | m[0].first |
| m.prefix().matched | m.prefix().first != m.prefix().second |
| m.suffix().first | m[0].second |
| m.suffix().second | last |
| m.suffix().matched | m.suffix().first != m.suffix().second |
| m[0].first | The start of the sequence of characters that matched the regular expression |
| m[0].second | The end of the sequence of characters that matched the regular expression |
| m[0].matched | true |
| m[n].first | For all integers 0 < n < m.size(), the start of the sequence that matched sub-expression n. Alternatively, if sub-expression n did not participate in the match, then last |
| m[n].second | For all integers 0 < n < m.size(), the sequence that matched sub-expression n. Alternatively, if sub-expression n did not participate in the match, then last |
| m[n].matched | For all integers 0 < n < m.size(), true if sub-expression n participated in the match, false otherwise |

```
template <class CharT, class Allocator, class traits>
bool regex_search(const CharT* str, match_results<const CharT*, Allocator&>& m,
const basic_regex<CharT, traits>& e,
regex_constants::match_flag_type flags = regex_constants::match_default);
```

+   * Returns: regex_search(str, str + char_traits<CharT>::length(str), m, e, flags).
