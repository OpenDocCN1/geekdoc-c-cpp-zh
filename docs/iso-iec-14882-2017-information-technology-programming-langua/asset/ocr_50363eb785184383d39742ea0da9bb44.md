# 24.3.5 Hash support [basic.string.hash]

```
template<class> struct hash<string>
template<class> struct hash<u16string>
template<class> struct hash<u32string>
template<class> struct hash<wstring>;
```

If S is one of these types, SV is the corresponding string value, and s is an object of type S, then hash(s)(s) = hash(SV).

# 24.3.6 Suffix for basic_string literals [basic.string.literals]

```
string operator"(const char* str, size_t len);
```

Returns: str(str, len).

```
u16string operator"(const char16_t* str, size_t len);
```

Returns: u16string(str, len).

```
u32string operator"(const char32_t* str, size_t len);
```

Returns: u32string(str, len).

```
wstring operator"(const wchar_t str, size_t len);
```

Returns: wstring(str, len).

> [Note: The suffix s is used for :chrono duration literals there is no conflict, since duration suffixes applies to numbers and string literal suffixes to character arrays. — end note]
