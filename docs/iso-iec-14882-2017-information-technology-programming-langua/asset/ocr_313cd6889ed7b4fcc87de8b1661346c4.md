```

    virtual void f();
```

Similarly, before the lifetime of an object has started but after the storage which the object will occupy has been reused or released, or after the lifetime of an object has ended and before the storage which the object is occupied by reused, any gvalue that refers to the original object may be used only in limited ways. For an object under construction or destruction, see 15.7. Otherwise, a gvalue refers to allocated storage (6.4.5), and using the properties of the gvalue that do not depend on its value is well-defined. The program has undefined behavior.

(7.1) the gvalue is used to access the object, or

(7.2) the gvalue is used to call a non-static member function of the object, or

(7.3) the gvalue is used to bind a reference to a virtual base class (11.6.3), or

(7.4) the gvalue is used as the operand of a dynamic_cast (8.2.7) or as the operand of typeid.

If, after the lifetime of an object has ended and before the storage which the object is occupied or released, a new object is created at the storage location which the original object occupied, a pointer that pointed to the original object, a reference to the original object, or the name of the original object will automatically refer to the new object and, once the lifetime of the new object has started, can be used to manipulate the new object.
