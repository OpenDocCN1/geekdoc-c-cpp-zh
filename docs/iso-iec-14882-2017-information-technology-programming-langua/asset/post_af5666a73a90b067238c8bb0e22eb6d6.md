## 25.4.1.4 Class template codecvt

```cpp
namespace std {
    class codecvt_base {
    public:
        enum result { ok, partial, error, nconv };
    };

    template <class internT, class externT, class state>
    class codecvt : public facet, public codecvt_base {
    public:
        using intern_type = internT;
        using extern_type = externT;
        using state_type = state;

        explicit codecvt(size_t refs = 0);

        result out(
            state& state,
            const internT* const from, const internT*& from_end, const internT*& from_next,
            externT* const to, externT* const to_end, externT* const to_next) const;

        result unshift(
            state& state,
            externT* const to, externT* const to_end, externT* const to_next) const;

        result in(
            state& state,
            const externT* const from, const externT*& from_end, const externT*& from_next,
            internT* const to, internT* const to_end, internT*& to_next) const;

        int encoding() const noexcept;
        bool always_nconv() const noexcept;
        int length(const state& const, const externT* const end, size_t max) const noexcept;

        static locale::id id;

    protected:
        codecvt();
        virtual result out_(
            state& state,
            const internT* from, const internT* from_end, const internT&* from_next,
            externT* to, externT* to_end, externT&* to_next) const;
        virtual result do_in(
            state& state,
            const internT* from, const externT* from_end, const externT&* from_next,
            internT* to, internT* to_end, internT&* to_next) const;
        virtual result do_unshift(
            state& state,
            externT* to, externT* to_end, externT&* to_next) const;
        virtual int do_encoding() const noexcept;
        virtual bool do_always_noconv() const noexcept;
        virtual int do_length(state& state, const externT* from, const externT* end, size_t max) const;
        virtual int do_max_length() const noexcept;
    };
```

- 1 The class codec<internT, externT> is for use when converting from one encoding to another, such as wide characters to multibyte characters or between wide encodings such as Unicode and EUC.
- 2 The specializations required in (25.4.1.1) convert the implementation-defined native character sets: char_t, char16_t, char, mbstate_t convert between UTF-16 and UTF-8, and specialization<char32_t, char, mbstate_t> convert between UTF-32 and UTF-8 encodings. codec<wchar_t, char, mbstate_t> converts between native character sets for narrow and wide characters. Specializations on mbstate_t perform conversion between encodings. Other objects of type state can contain any state that is used to communicate to or from.

## 25.4.1.4.2 codec virtual functions

```cpp
result do_out(
    state& state,
    const externT* from, const internT* from_end, const internT& from_next,
    externT& to, externT* to_end, externT& to_next) const;

result do_in(
    state& state,
    const externT* from, const externT* from_end, const internT& from_next,
    internT* to, internT* to_end) const;
```

- 1 Requires: (from < from_end && to < to_end) well-defined and true; state initialized at the beginning of a sequence, or equal to the result of converting the preceding characters in the.
- 2 Effects: Translates characters in the source range [from, from_end), producing the results in sequences starting at destination. Converts no more than (from_end - from) source elements, and no more than (to_end - to) destination characters. It stops if an element cannot be successfully converted. If returns noconv, internT and externT are the same type and the converted sequence is identical to the input sequence [from, from_next). to_next is set equal to, the value of state is unchanged, and there are no changes to the values in [to, to_end).
- 3 A codec facet that is used by basic_filebuf(3.9) shall have the property that if do_out(state, from, from_end, from_next, to_end, to_next) would return ok, where from != from_end, then do_out(state, from + 1, from_next, to_end, to_next) shall also return ok, and if do_in(state, from, from_end, from_next, to_end, to_next) would return ok, where to != to_end, then do_in(state, from, from_end, from_next, to + 1, to_next).
    - Note: As a result of operations on state, it can return ok or partial and set from_next == from and to_next != to.
- 4 Remarks: Its operations on state are unspecified. [Note: This argument can be used, for example, to maintain state, if conversion options (such as only) or to identify a cache of offsets.]
- 5 Returns: An enumeration value, as summarized in table 71.

(236) Internally, this means that basic_filebuf uses the mappings from internal to external characters is 1 to N: a codec facet that is used must translate one character at a time.

Table 71 — do_in/do_out result values

| Value | Meaning |
|---|---|
| ok | completed the conversion |
| partial | not all characters converted |
| error | encountered a character in [from, from_end] it could not convert |
| noconv | internT and externT are the same type, and input sequence is appended to converted sequence |

A value of partial, if (from_next == from_end), indicates that either the destination sequence has not absorbed all the destination, or additional source elements are needed before another element can be produced.

```cpp
result do_unshift(state& state, externT* to, externT* to_end, externT& to_next) const;
```

- Returns: (to < to_end) well-defined and true; state initialized, at the beginning of a sequence, or equal to the result of converting the preceding characters in the sequence.
- Effects: Characters starting at that point are appended to a sequence when the current state is given by state. No more than (to_end - to) destination elements, and leaves the internT pointer beyond the last element successfully stored.
- Returns: An enumeration, summarized in 72.

Table 72 — do_unshift result values

| Value | Meaning |
|---|---|
| ok | completed the sequence |
| partial | space for more (to_end - to) destination elements was needed to terminate a sequence given the value of state |
| error | an unspecified error has occurred |
| noconv | no termination is needed for this state_type |
