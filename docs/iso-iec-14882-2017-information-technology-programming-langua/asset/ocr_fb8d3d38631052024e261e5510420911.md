# 23.10.5 Align             [ptr.align]

```
1 void* align(size_t size, size_t size, void*& ptr, size_t space);
2 Effects: If it is to fix bytes of size aligned by alignment into the buffer pointed to by\ptr with length, the function updates ptr to represent the first possible address of storage
decases space by the number of bytes used for alignment. Otherwise, the function does nothing.
```

3 Requires:

+   (2.1) alignment be a power of two
(2.2) ptr shall represent the address of contiguous storage of at least space bytes

4 Returns: A null if the requested aligned buffer would not fit into the available space, otherwise
adjust the value of ptr.

> [Note: The function updates ptr and space arguments so that it can be called repeatedly
 different alignment and uses space for the same buffer. end note]

# 23.10.7 uses_allocator             [allocator.uses]

# 23.10.7.1 uses_allocator             [allocator.uses.trait]

```
template <class T, class Alloc> struct T has a nested allocator_type that is convertible to Alloc.
```

Remarks: Automatically detects whether T is convertible from Alloc.
meets the BaseTypeRequires (23.15.1). The implementation shall provide a definition that
is derived from true_type if the qualified-id T::allocator_type is valid and denotes a type (17.8.2)
and is_convertible_v<T, T::allocator_type> != false, otherwise it shall be derived from
false_type. A program may specialize this template to derive from true_type for a user-defined
T that does not have a nested allocator_type but nonetheless be constructed with an allocator
wherever.

> 221 pointer_safety::preferred might be returned to indicate that a leak detector is running so that the program can avoid
spurious leak reports.
