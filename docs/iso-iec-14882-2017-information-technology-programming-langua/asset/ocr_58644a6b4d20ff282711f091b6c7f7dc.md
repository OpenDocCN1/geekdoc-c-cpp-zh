# ISO/IEC 14882:2017(E)

# 23.17.5 Class template duration [time::duration]

1 A duration type measures between two points in time (time_points). A duration has a representation which holds a count of ticks and a tick period. The tick period is the amount of time which occurs from one to the next, in units of seconds. It is expressed as a rational constant using the template ratio.

```
template <class Rep, Period = ratio<1>>
class duration {
public:
    using rep = Rep;
    using Period = typename Period::type;
private:
    Rep rep_; // exposition only
public:
    // 23.17.5, construct/copy/destroy
    constexpr duration() = default;
    template <class Rep2>
    constexpr duration(const Rep2&, class Period2 = Period) 
    template <class Rep2>
    constexpr duration(const Rep2, Period2& d) -duration(0) = default;
    constexpr duration(const duration) = default;
    duration& operator=(const duration) = default;
```

```
// 23.17.5, arithmetic
    constexpr common_type<duration> operator+(const duration) const;
    constexpr common_type<duration> operator-(const duration) const;
    constexpr duration operator+(const duration&);
    constexpr duration operator+(int);
    duration& operator+=(const duration&);
    duration& operator+=(int);
    constexpr duration operator-(const duration&);
    duration& operator-=(const duration&);
    constexpr duration operator*(const rep& rhs);
    duration& operator*=(const rep& rhs);
    constexpr duration operator%(const rep& rhs);
    duration& operator%=(const rep& rhs);
```

```
// 23.17.5, special values
    static constexpr duration zero();
    static constexpr duration min();
    static constexpr duration max();
```

2 Rep shall be an arithmetic type or class enclosing an arithmetic type. If duration is instantiated with a duration type as the argument for the template parameter Rep, the program is ill-formed.

3 If Period is not a specialization of ratio, the program is ill-formed. If Period::num is not positive, the program is ill-formed.

4 Members of duration shall not throw exceptions other those thrown by the indicated operations on their representations.
