The class basic_ofstream<charT, traits> supports writing to named files. It uses a basic_filebuf<charT, traits> to control the associated sequence. For the sake of exposition, the maintained data is presented here as:

+   sb, the filebuf object.

# 30.9.4.1 basic_ofstream constructors [ofstream.cons]

```
basic_ofstream();
```

> Effects: Constructs an object of class basic_ofstream<charT, traits>, initializing the base class with basic_ofstream<charT, traits>&(rhs) (30.7.5.1) and initializing sb with basic_filebuf<charT, traits>() ((30.9.2.1).

```
explicit basic_ofstream(const char* s,
ios_base::openmode mode = ios_base::out);
explicit basic_ofstream(const filesystem::path::value_type s,
ios_base::openmode mode = ios_base::out); // wide systems only; see 30.9.1
```

> Effects: Constructs an object of class basic_ofstream<charT, traits>, initializing the base class with basic_ofstream<charT, traits>&(rhs) (30.7.5.1) and initializing sb with basic_filebuf<charT, traits>() ((30.9.2.1), which returns rdbuf()->open(s, mode | ios_base::out). If function returns a null pointer, calls setstate(failbit).
