- 3 Node_handle is for specified pair. Any implementation is permitted to provide equivalent functionality without providing a class with this name.
- 4 If a user-defined specialization of pair exists for const Key, T or pairKey, where Key is the container's key_type and T is the container's mapped_type, the behavior of involving node handles is undefined.

```cpp
template<class unspecified>
class node_handle {
:
    // These type declarations are described in Tables 90 and 01.
    using value_type = see below; // not for map containers
    using key_type = see below; // not for set containers
    using mapped_type = see below; // not for set containers
    using allocator_type = see below;
private:
    using container_node_type = unspecified;
    using allocator_traits = allocator<container_node_type>;
public:
    node_handle() noexcept = ptr_(), alloc_() {}
    typename node_handle::rebind_traits<container_node_type>::pointer ptr;
    optional<allocator_type> alloc_ = alloc_,
public:
    const value_type value() const noexcept; // not for map containers
    const key_type key() const noexcept; // not for set containers
    const mapped_type mapped() const noexcept; // not for set containers
    allocator_type get_allocator() const;
    explicit operator bool() const noexcept;
    bool empty() const noexcept;
    void swap(node_handle& other) noexcept(allocator_traits::propagate_on_container_swap::value ||
        allocator_traits::is_always_equal==value);
    friend void swap(node_handle x, node_handle y) noexcept(noexcept(x.swap(y))) {
        x.swap(y);
    }
};
```

## 26.2.4.2 node_handle constructors, copy, and assignment [container.node.cons]

```cpp
node_handle(node_handle&& nh) noexcept;
```

- Effects: Constructs a node_handle object initializing ptr_ with nh.ptr_. Constructs alloc_ with nh.alloc_. Assigns nullptr to nh.ptr_ and assigns nullptr to nh.alloc_.

```cpp
node_handle& operator=(node_handle&&);
```

- Requires Either alloc_, or allocator_traits::propagate_on_container_move_assignment is true, or alloc_ == nh.alloc_;
- Effects:
    - If ptr_ != nullptr, destroys the value_type subobject in the container_type object pointed to by ptr_, calling allocator_traits::destroy, then deallocates ptr_ by calling allocator_traits::rebind_traits<container_node_type>::deallocate.
    - Assigns nh.ptr_ to ptr_
    - If alloc_, or allocator_traits::propagate_on_move_assignment is true, moves nh.alloc_ to alloc_
    - Assigns nullptr to nh.ptr_ and assigns nullptr to nh.alloc_
    - Returns: *this.
- Throws: Nothing.

## 26.2.4.3 node_handle destructor [container.node.dtor]

```cpp
~node_handle();
```

- Effects: If ptr_ != nullptr, destroys the value_type subobject in the container_type object pointed to by ptr_, calling allocator_traits::destroy, then deallocates ptr_ by calling allocator_traits::rebind_traits<container_node_type>::deallocate.

## 26.2.4.4 node_handle observers [container.node.observers]

```cpp
value_type& key() const;
```

- Requires: empty() == false.
- Returns: A reference to the value_type subobject in the container_type object pointed to by ptr_
- Throws: Nothing.

```cpp
key_type& key() const;
```

- Requires: empty() == false.
- Returns: A non-const reference to the key_type member of the value_type subobject in the container_node_type object pointed to by ptr_
- Throws: Nothing.
- Remarks: Modifying the key through the returned reference is permitted.

```cpp
mapped_type& mapped() const;
```

- Requires: empty() == false.
- Returns: A reference to the mapped_type member of the value_type subobject in the container_node_type object pointed to by ptr_
- Throws: Nothing.

```cpp
allocator_type get_allocator() const;
```

- Requires: empty() == false.
- Returns: *alloc_
- Throws: Nothing.

```cpp
explicit operator bool() const noexcept;
```

- Returns: ptr_ != nullptr;

```cpp
bool empty() const noexcept;
```

- Returns: ptr_ == nullptr.

## 26.2.4 node_handle modifiers [container.node.modifiers]

```cpp
void swap(node_handle h)
noexcept(allocator_traits::propagate_on_container_swap == value ||
    allocator_traits::is_always_equal==value);
```

- Requires: allocator_traits::propagate_on_container_swap == value || allocator_traits::is_always_equal==value;
- 1 If allocator_traits::propagate_on_container_swap == value || allocator_traits::is_always_equal==value, swaps the contents.
- 2 If allocator_traits::propagate_on_container_swap == value || allocator_traits::is_always_equal==value, swaps the contents.

## 26.2.4.5 insert [container.node.insert]

- 1 Associative containers return a pair containing an iterator to the inserted element and a boolean.
```cpp
template<class Iterator, class bool>
struct insert_result {
  Iterator it;
  bool inserted;
};
```
- 2 Associative containers store only one element per key.
- 3 If the key already exists, the element is not inserted and the boolean is false.

## 26.2.4.6 equality [container.node.equality]

- 1 Associative containers provide a method to compare keys.
- 2 The comparison is performed by the comparator provided to the container.
- 3 If no comparator is provided, `operator<` is used.
