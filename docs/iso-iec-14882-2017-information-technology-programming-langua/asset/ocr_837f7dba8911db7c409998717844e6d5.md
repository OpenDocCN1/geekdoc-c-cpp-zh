# 29.6.4.4 Class template shuffle_order_engine

+   1 A shuffle_order_engine random number engine adapter produces the random numbers that are produced by some base engine, but delivers them in a different sequence. The state x, of a shuffle-order_engine object x consists of state e, of its base engine, and an additional value Y of the delivered by e, and an additional sequence V of k values of the delivered by e. The size of the state is of e's state k+1.

+   2 The transition algorithm performs the values produced by e. The state transition is performed as:

+   a) Calculate an integer j = $\frac{i-1}{	ext{size\_of\_e}+1}$

+   b) Set Y to V_j and set V_i to e.

+   3 The generation algorithm yields the value Y produced while advancing e's state as described.
