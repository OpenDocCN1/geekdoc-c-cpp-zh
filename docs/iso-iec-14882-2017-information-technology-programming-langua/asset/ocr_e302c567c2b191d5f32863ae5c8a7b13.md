# ISO/IEC 14882:2017(E)

The result of applying sizeof to a base class object is the size of the base class type.78 When applied to an array, the result is the total number of bytes in the array. This implies that the size of an array of n elements is n times the size of an element.

The sizeof operator can be applied to a pointer to a function, but will not be applied directly to a function.

The value-to-pointer(7.1), array-to-pointer(7.2), and function-to-pointer(7.3) standard conversions are applied to the operand of sizeof. If the operand is a value, the temporary materialization conversion (7.4) is applied.

The sizeof... expression shall name a parameter pack. The sizeof... yields the number of arguments provided for the parameter pack identifier. A sizeof... expression is a pack (17.5.3). [Example:

```
template<class... Types>
struct count {
    static const std::size_t value = sizeof...(Types);
};
 end example
```

The result of sizeof... is a constant of type std::size_t. [Note: std::size_t is defined in the standard header <cdef>(21.2.1, 21.2.4). — end note]

# 8.3.4 New

The new-expression attempts to create an object of the type-id (11.1) or new-type to which it is applied. The type of that object created will be the allocated type, but not an class type or array thereof (4.5, 6.9, 13.4). [Note: References are not objects, references cannot be created by new-expressions. — end note] [Note: The new-expression may be a cv-qualified type, in which case the object created by the new-expression has — end note]

+   new-expression:
  :opt new new-expression_opt new-type-id new-initializer_opt
  :opt new new-expression_opt (type-id) new-initializer_opt

+   new-placement:
  {
    new-type-id:
      type-specifier-seq new-declarator_opt
    new-declarator:
      ptr-operator new-declarator_opt
      nopt-new-declarator
    nopt-new-declarator:
      [ attribute-specifier-seq [ constant-expression ] attribute-specifier-seq_opt
    new-initializer:
      ( expression-list_opt )
      braced-init-list

Entities created by a new-expression have dynamic duration (6.7.4). [Note: The lifetime of an object is not necessarily restricted to the scope in which it is. — end note] If the entity is a non-array object, the new-expression returns a pointer to the created object. If it is an array, the new-expression returns a pointer to the initial element of the array.

> 78 The actual size of a base class object may be less than the size of sizeof to the most, due to virtual base classes and less strict packing requirements on base class objects.
