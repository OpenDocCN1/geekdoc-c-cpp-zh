# ISO/IEC 14882:2017(E)

# 29.8.4 Inner product [inner.product]

```
template <class Iterator1, class Iterator2, class T>
T inner_product(InputIterator1 first, InputIterator last1,
               Iterator2 first, T init);
template <class Iterator1, class Iterator2, class T,
           classBinaryOperation1, class BinaryOperation2>
T inner_product(InputIterator1 first, InputIterator last1,
               Iterator2 first, T init,
               BinaryOperation1 binary_op1,
               BinaryOperation2 binary_op2);
```

+   - Requires: T shall meet the requirements of CopyibleibleTable 24) and Assignable (Table 26). Types in ranges: [first1, last1] and first2 + (last1 - first1); binary_op1 and binary_op2 shall neither elevate iterators or surranges;^{283}

+   - Effects: Computes its result by initializing the accumulator with the initial value init and modifying it with acc = acc + (*i1) * binary_op1(acc, *i2, +12) for every iterator i1 in the range [first1, last1) and iterator i2 in the range [first2, first2 + (last1 - first1)] in order.

# 29.8.5 Transform reduce [transform.reduce]

```
template <class Iterator1, class Iterator2, class T>
T transform_reduce(InputIterator1 first, InputIterator last1,
               Iterator2 first, T init);
template <class ExecutionPolicy>
T transform_reduce(ForwardIterator1, ForwardIterator2, class T>
T transform_reduce(ExecutionPolicy&& exec, 
               ForwardIterator1 first, ForwardIterator1 last1,
               ForwardIterator2 first,
               T init);
```

+   - Effects: Equivalent to:
    return transform_reduce(first1, last1, first2, init, plus<>(), multiplies<>());

```
template <class Iterator1, class Iterator2, class T,
           class Binary1, class Binary2>
T transform_reduce(InputIterator1 first, InputIterator last1,
               Iterator2 first,
               T init,
               BinaryOperation1 binary_op1,
               BinaryOperation2 binary_op2);
```

```
template <class ExecutionPolicy>
 class ForwardIterator1, class ForwardIterator2, class T,
 class BinaryOperation1, class BinaryOperation2>

               T init,
```

+   - Requires:

> 283) The use of fully closed ranges is intentional.
