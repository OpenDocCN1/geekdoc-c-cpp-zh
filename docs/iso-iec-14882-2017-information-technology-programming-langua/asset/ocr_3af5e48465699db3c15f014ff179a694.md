# 10.3.2 Namespace aliases [namespace.alias]

+   1 A namespace-alias-definition declares an alternate name for a namespace according to the following grammar:
namespace-alias:
  identifier
namespace-alias-definition:
  namespace-alias identifier = qualified-namespace-specifier;
  qualified-namespace-specifier:
    nested-name-specifier namespace-name

+   2 The identifier in a namespace-alias-definition is a synonym for the name of the namespace denoted by the qualified-namespace-specifier and becomes a namespace-alias.[Note: When looking up a namespace-name in a namespace-alias-definition, only namespace names are considered, see 6.4.6. — end note]

+   3 In a declarative region, a namespace-alias can be used to redefine a namespace-alias declared in that declarative region to refer to the namespace to which it already refers.[Example: The following declarations are well-formed:
namespace Company_with_very_long_name { /* ... */
namespace CWLN = Company_with_very_long_name;
namespace CWLN = Company_with_very_long_name; // OK duplicate
namespace CWLN = CWLN;
}]

# 10.3.3 The using declaration [namespace.udecl]

+   using-declaration:
  using-declaration-list:
    using-declarator ...
    using-declarator ... opt
using-declarator:
  typename_opt nested-name-specifier unqualified-id

+   1 Each using-declaration in a using-declaration introduces a set of declarations into the declarative region where the using-declaration appears. The set of declarations introduced is found by performing name lookup in the using-declaration, excluding functions that are hidden described below (6.6.3, 13.2) If the using-declaration does not name a constructor, the unqualified-id is declared in the declarative region as a synonym for each declaration introduced by the using-declaration.[Note: Only the specified name is so declared; if declaring an enumeration name in a using-declaration does not declare its enumerators in the using-declaration’s declarative region. — end note] If the using-declaration names a constructor, it declares that the class inherits the set of constructor declarations introduced by the using-declaration from the nominated base.

> (98) A using-declaration with more than one using-declaration is equivalent to a corresponding sequence of using-declaration each.
