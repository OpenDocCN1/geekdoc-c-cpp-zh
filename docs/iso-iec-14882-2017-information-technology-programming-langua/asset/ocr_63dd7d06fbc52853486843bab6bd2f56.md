# ISO/IEC 14882:2017(E)

Table 71 — do_in/do_out result values

| Value | Meaning |
|---|---|
| ok | completed the conversion |
| partial | not all characters converted |
| error | encountered a character in [from, from_end] it could not convert |
| noconv | internT and externT& are the same type, and input sequence is appended to converted sequence |

A value of partial, if (from_next == from_end), indicates that either the destination sequence has not absorbed all the destination elements, or additional source elements are needed before another element can be produced.

```
result=do_unshift(stateT&, externT& to_end, externT&_to_next) const;
```

+   - Returns: (to < to_end) well-defined and true; state initialized, if the beginning of a sequence, or else equal to the result of converting the preceding characters in the sequence.

+   - Effects: Characters starting at that point are appended to a sequence when the current state is given by state.237 No more than (to_end - to) destination elements, and leaves the internT pointer pointing beyond the last element successfully stored.

+   - Returns: An enumeration, summarized in Table 72.

Table 72 — do_unshift result values

| Value | Meaning |
|---|---|
| ok | completed the sequence |
| partial | space for more (to_end - to) destination elements was needed to terminate a sequence given the value of state |
| error | an unspecified error has occurred |
| noconv | no termination is needed for this state_type |

+   - Returns: -1 if the encoding of the externT sequence is state-dependent; else the constant of externT characters need an internal character; or 0 if this is not a constant.238


+   - Returns true if (do_in and do_out()) return noconv for all valid values. codecvt<char, mstate_t> returns true.
