# 23.175.5 Pointer modifications

[meta.trans.ptr]

Table 49 — Pointer modifications

| Template | Comments |
| --- | --- |
| template <class T> struct remove_pointer; | If T has type ("possibly cv-qualified") pointer to T1" then the typedefed type names T1; otherwise, it names T. |
| template <class T> struct add_pointer; | If T has a referable type (20.3.18) or a cv void type then the member typedef type names the same type as remove_reference_<T>; otherwise, type names T. |

# 23.15.7.6 Other transformations

[meta.trans.other]

Table 50 — Other transformations

| Template | Comments |
| --- | --- |
| template <size_t Len, size_t Align = default_alignment> struct aligned; | The value of default-alignment shall be the most stringent requirement for any C++ object whose size is no greater than Len (6.9). The member typedef type is a POD type suitable for use as uninitialized storage or any object whose size is at most Len whose divisor is Align. Requirements: Align shall not be zero. Align shall be equal to align(T) for some type T to default-alignment. |
| template <size_t Len, class Types> struct aligned_union; | The member type shall be a POD type suitable for use of uninitialized storage for any object whose type is listed in Types; its size shall be at least Len. The member value shall be an integral constant of type size_t whose value is the strictest of listed types. Requirements: At least one type is provided. |
| template <class T> struct decay; | Let U be reference<T>. If is_array_v<U> is true, or is_function<U> is true, the member typedef type shall equal remove_typedef_ext<T>. The other member typedef type shall equal add_pointer<T>. Note: This is similar to remove_cv<T> (7.1), pointer-to-pointer(T), and function-to-pointer(T) conventions which apply when an expression is used as rvalue, but also strips cv-qualifiers from class types in order to more closely match by-value argument passing. -- end |

| template <bool B, class T = void> struct enable_if; template <bool B, class F> struct conditional; template <class... T> struct common_type; | If B is true, the member typedef type shall equal T; otherwise, there shall be no member type. If B is false, the member typedef type shall equal F; the member type shall equal F. Unless this type is specialized (as specified in Note B, below), the member type shall be defined or omitted as specified in Note A. If it is omitted, there shall be no member type. Each type in the parameter pack T shall be cv, void, or any type of unknown kind. |
