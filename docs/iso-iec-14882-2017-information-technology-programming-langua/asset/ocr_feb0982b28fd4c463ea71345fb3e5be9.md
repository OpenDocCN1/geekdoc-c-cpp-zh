# 23.17.5. duration non-arithmetic [time.duration.nonmember]

In the function descriptions that, CD represents the return type of function. CR(A,B) represents common_type<A, B>.

```
template <Class Rep1, Class Period1, Class Rep2, Class Period2>
constexpr common_type<duration<Rep1, Period1>, duration<Rep2, Period2>>
operator+(const duration<Rep1, Period1>& lhs, const duration<Rep2, Period2>& rhs) {
};
```

Returns: CD(lhs.count()) + CD(rhs.count()).

```
template <Class Rep1, Class Period1, Class Rep2, Class Period2>
constexpr common_type<duration<Rep1, Period1>, duration<Rep2, Period2>>
operator-(const duration<Rep1, Period1>& lhs, const duration<Rep2, Period2>& rhs) {
};
```

Returns: CD(lhs.count()) - CD(rhs.count()).

Remarks: This operator shall not participate in overload resolution unless Rep2 is implicitly convertible to CR(Rep1, Rep2).
