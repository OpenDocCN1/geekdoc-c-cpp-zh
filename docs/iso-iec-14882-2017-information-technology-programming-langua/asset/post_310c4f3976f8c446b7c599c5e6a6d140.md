## 27.5.3 Move iterators

Class move_iterator is an iterator adapter with the same behavior as the underlying iterator except its indirection operator implicitly converts the value returned by the underlying iterator's indirection to rvalue. Some generic algorithms can be called with move iterators to replace copying with

Example:

```cpp
list<string> s;
// populate the list
vector<string> v1(s.begin(), s.end()); // copies strings into v1
vector<string> v2(move_iterator(s.begin()), move_iterator(s.end())); // moves strings into v2
```

## 27.5.3.1 Class move_iterator

```cpp
namespace std {
template <class Iterator>
class move_iterator {
public:
    using value_type = typename Iterator::value_type;
    using category = typename iterator_traits<Iterator>::category;
    using difference_type = typename iterator_traits<Iterator>::difference_type;
    using pointer = Iterator*;
    using reference = typename Iterator::reference;

    move_iterator(Iterator i);

    constexpr move_iterator(const move_iterator<Iterator>& u) const;
    constexpr move_iterator(const move_iterator<Iterator>& u, int);

    constexpr Iterator::iterator_type base() const;
    constexpr reference operator*() const;
    constexpr pointer operator->() const;

    move_iterator& operator++() const;
    constexpr move_iterator& operator++(int) const;
    move_iterator& operator--() const;
    constexpr move_iterator& operator--(int) const;

    constexpr move_iterator operator+(difference_type n) const;
    constexpr move_iterator& operator+=(difference_type n);
```

```cpp
constexpr move_iterator operator-(difference_type n) const;
constexpr move_iterator& operator=(difference_type n);
constexpr Iterator operator[](difference_type n) const;

private:
    Iterator current;
};

## 27.5.3.2 move_iterator requirements [move.iter.ops]

- 1 The template Iterator shall meet the requirements of an iterator (27.2.3). Additionally, if any of the bidirectional or random access functions are instantiated, the template shall meet the requirements for a Birectional Iterator (27.2.6) or a Random Access Iterator (27.2.7), respectively.
