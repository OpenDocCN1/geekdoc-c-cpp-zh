# 28.6.9 Unique [alg.unique]

```
template<class ForwardIterator>
ForwardIterator unique(ForwardIterator first, ForwardIterator last);
template<class ExecutionPolicy, class ForwardIterator>
ForwardIterator unique(ExecutionPolicy&& exec, ForwardIterator first);
```

```
template<class ForwardIterator, class BinaryPredicate>
ForwardIterator unique(ForwardIterator first, ForwardIterator last, BinaryPredicate pred);
template<class ExecutionPolicy, class BinaryPredicate>
ForwardIterator unique(ExecutionPolicy&& exec, ForwardIterator first, ForwardIterator last, BinaryPredicate pred);
```

+   Requires: The function shall be an equivalence relation. The type of *first must satisfy the MoveAssignable requirements (Table 25).

+   Effects: For a non-empty range, it eliminates all but the first from every consecutive group of equivalent elements referred to by the iterator in the range [first + 1, last) for which the condition holds *(i - 1) == *i && pred(*i) != false.

+   Returns: The end of the range.

+   Complexity: For non-empty ranges, exactly (last – first) – 1 applications of the corresponding predicate.
