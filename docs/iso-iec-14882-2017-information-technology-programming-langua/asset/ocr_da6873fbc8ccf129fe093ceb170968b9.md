# 24.5.6 Multibyte string and character conversion functions

+   1 [Note: The headers <cctype> (21.2.2) and <cwchar> (24.5.4) declare the functions described in this subclause.—note]

```
int mbistize(const mbstate_t* ps);
int mbstlen(const char* s, size_t n);
size_t mbcsowcs(wchar_t* pwcs, const char* s, size_t n);
size_t mbcsstom(char* s, const wchar_t* pwcs, size_t n);
```

+   2 Effects: These functions have the semantics in the C standard library.

SEE ISO: C 7.22.1, 7.29.8, 7.29.6.1

```
int mbtowcs(wchar_t* pw, const char* s, size_t n);
int mbtowchar(char* s, wchar_t* pw);
```

+   3 Effects: These functions have the semantics in the C standard library.

+   4 Remarks: Calling these functions may introduce a data race (20.5.5.9) with other calls to the same function.

```
size_t mbrblen(const char* s, size_t n, mbstate_t* ps);
size_t mbrtcs(wchar_t* pw, const char* s, size_t n, mbstate_t* ps);
size_t mbtowtom(char* s, wchar_t* pw, mbstate_t* ps);
size_t mbtowcsrt(wchar_t** desc, const char** src, size_t len, mbstate_t* ps);
size_t mbtowcschar(char* s, const wchar_t** src, size_t len, mbstate_t* ps);
```

+   5 Effects: These functions have the semantics in the C standard library.

+   6 Remarks: Calling these functions with an mbstate_t* argument that is a null pointer value may introduce a data race (20.5.5.9) with other calls to the same function with an mbstate_t* argument
