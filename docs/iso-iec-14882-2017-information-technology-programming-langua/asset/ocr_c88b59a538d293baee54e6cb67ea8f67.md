# ISO/IEC 14882:2017(E)

basic_ostream(basic_ostream&&& rhs);

Effects: Move constructs from the value rhs. The class and the contained basic_stringbuf. Next basic_ostream<charT, traits>::set_rdbuf(ksb) is called to install the contained basic_stringbuf.

# 30.8.4.2 Assign and swap

basic_ostream operator=(basic_ostream&&& rhs);

Effects: Assigns the base and members of *this from the base and corresponding members of rhs.

+   Returns: *this.

void swap(basic_ostream&&& rhs);

Effects: Changes the state of *this and rhs by calling basic_ostream<charT, traits>::swap(rhs) and sb.swap(rhs.sub).

```
template <class charT, class traits, class Allocator>
void swap(basic_ostream<charT, traits, Allocator>&& x,
basic_ostream<charT, traits, Allocator>&& y);
```

Effects: As if by y.

# 30.8.5 Class template basic_stringstream

```
namespace std {
template <class charT, class traits = char_traits<charT>,
class Allocator = allocator<charT>>
class basic_stringstream : basic_iostream<charT, traits> {
public:
  using char_type = charT;
  using int_type = typename traits::int_type;
  using pos_type = typename traits::pos_type;
  using off_type = typename traits::off_type;
  using traits = traits;
  using allocator_type = Allocator;

// basic_stringstream constructor
  explicit basic_stringstream(
  const basic_string<charT, traits, Allocator>& str,
  ios_base::openmode which = ios_base::out | ios_base::in);
  explicit basic_stringstream(
  const basic_string<charT, traits, Allocator>&& str,
  ios_base::openmode which = ios_base::in);
  basic_stringstream(const basic_string<charT, traits, Allocator>&& rhs) = delete;
```
