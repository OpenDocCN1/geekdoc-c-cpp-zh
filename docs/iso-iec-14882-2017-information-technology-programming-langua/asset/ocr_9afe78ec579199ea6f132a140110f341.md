The implicitly-defined default constructor performs the set of initializations of the class that would be performed by a user-defined default constructor for class with no ctor-initializer (15.6.2) and an empty compound statement. If that user-defined default constructor would be ill-formed, the program is ill-formed. Before the default constructor for a class is implicitly defined, the non-provided default constructors for its base and non-static data members shall have been implicitly defined. [Note: An implicitly-declared default constructor might have an exception specification, An explicitly-declared default constructor has an implicit exception, see 14.4. — end note]

Default constructors are called to create class objects of static, thread, or automatic duration (6.7.1, 6.7.2, 6.7.3) defined without an initializer (11.6), or are called to create class objects of dynamic storage duration (6.7.4) defined by a new-expression in which the new-initializer is used (8.3.4), or when the explicit type conversion is used (8.2.3). A program is ill-formed if the default constructor for an object is implicitly used and the constructor is not accessible (Clause 14).

[Note: 15.6.2 describes the order in which constructors for base classes and non-static data members are called and how arguments can be specified for these constructors. — end note]

A return statement in the body of a constructor shall not specify a return value. The address of a constructor shall be ignored.
