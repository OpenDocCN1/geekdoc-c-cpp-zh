If a program ends the lifetime of an object of type T with static (6.7.1), or automatic (6.7.3) storage duration and if T has a non-trivial destructor, the program must ensure that the original type occupies that storage location when the implicit destructor takes place; otherwise the behavior of the program is undefined. This is true even if the block is exited with an exception. [Example]:

```
class T {
    struct B {
        ~B();
    };
    void h() {
        B b;
        new (&b) T; // undefined behavior at block exit
    }
};
```
