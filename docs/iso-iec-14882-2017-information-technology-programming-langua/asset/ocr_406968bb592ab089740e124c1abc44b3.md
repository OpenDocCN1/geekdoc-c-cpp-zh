2 A local class of non-closure type shall not have member templates. Access control rules (Clause 14) apply to member templates. A destructor shall not be a member. A non-template member function (11.3.5) with a given name and a member template function of the same name, both could be used to generate a specialization of the same type, both be declared in a class. When both exist, use of that name and type refers to the non-template member unless an explicit template argument is supplied. [Example:

```
template <class T> struct A {
    void f(int);
    template <class T2> void f(T2);
};

template <class> void A::f(int) // non-template member function
template <class> template <T> void A::f(int) // member function template specialization

int main() {
    A<char> ac;
    ac.f(1);    // non-template
    ac.f('c');  // template
    ac.f(1);    // template
}
// end example
```
