# C.2.10 Clause 22: diagnostics library [diff.cpp03.diagnostics]

22.4
Change: Thread-local error numbers.
Rationale: For new threads.
Effect on original feature: Valid but implementation-specific C++ 2003 code that relies on errno being the same across threads may change behavior in this Standard.

# C.2.11 Clause 23: general utilities library [diff.cpp03.utilities]

23.10.4
Change: Minimal support for garbage-collected regions.
Rationale: Required by new feature.
Effect on original feature: Valid C++ 2003 code, compiled without traceable pointer support, that interacts with new C++ code using declared reachable behavior.

23.14.5, 23.14.6, 23.14.7, 23.14.8, 23.14.9, D.8.3
Change: Standard function object types are no longer derived from std::unary_function or std::binary_function.
Rationale: By new feature: unary_function and binary_function are no longer defined.
Effect on original feature: Valid C++ 2003 code that depends on object types being derived from unary_function or binary_function may fail in this International Standard.

# C.2.12 Clause 24: strings library [diff.cpp03.strings]

24.3
Change: basic string requirements no longer allow reference-counted strings.
Rationale: Invalidation is costly with reference-counted strings. This change regularizes behavior in this International Standard.
Effect on original feature: Valid C++ 2003 code may execute efficiently in this International Standard.

24.3.2.1
Change: Loose basic_string invalidation rules.
Rationale: Allow small-string optimization.
Effect on original feature: Valid C++ 2003 code may execute differently in this International Standard. Some constant members, such as data and c_str, no longer invalidate iterators.

# C.2.13 Clause 26: containers library [diff.cpp03.containers]

26.2
Change: Complexity of size() member function remains constant.
Rationale: Lack of specification of size() resulted in divergent implementations with inconsistent performance characteristics.
Effect on original feature: Some container implementations that conform to C++ 2003 may not conform to the specified size() requirements in this International Standard. Adjusting containers such as std::list may require incompatible changes.
