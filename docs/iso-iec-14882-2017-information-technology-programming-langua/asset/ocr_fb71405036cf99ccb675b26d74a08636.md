# 29.6.8.4.5 Class template_extreme_value_distribution [rand.dist.pos,extreme]

+   An extreme_value_distribution random number produces numbers x distributed according to the probability density function²⁷⁵

```
p(x,a) = \frac{1}{b} \exp\left(\frac{a-x}{b}\right) - \exp\left(\frac{a-x}{b}\right)\right);
```

```
template<class RealType = double>
class extreme_value_distribution {
public:
    using result_type = RealType;
    using param_type = unspecified;

    // constructor and reset functions
    explicit extreme_value_distribution(RealType a = 0.0, RealType b = 1.0);
    explicit extreme_value_distribution(const param_type& param);
    void reset();

    // generating functions
template<class URBG>
    result_type operator()(URBG& g);
template<class URBG>
    result_type operator()(URBG& g, const param_type& param) const;

    // property functions
    RealType a() const;
    RealType b() const;
    param_type param(const param_type& param) const;
    result_type min() const;
    result_type max() const;
};

explicit extreme_value_distribution(RealType a = 0.0, RealType b = 1.0);
```

+   2. Requires: 0 < b.

Effects: Constructs an extreme_value_distribution object; and a and b correspond to the respective parameters of the distribution.

> ²⁷⁵ The distribution corresponding to this probability density function is also known (with a possible change of variable) as the Gumbel Type I, the log-Weibull, or the Fisher-Tippett Type I distribution.
