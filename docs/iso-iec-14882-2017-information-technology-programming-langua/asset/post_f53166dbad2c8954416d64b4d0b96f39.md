
# ISO/IEC 14882:2017(E)

[Note: Implementations are strongly encouraged to query secondary storage, and not consider !exists(p) an error. -- end note]

[Example: For POSIX-based operating systems, absolute(p) is simply current_path()/p. For Windows-based operating systems, absolute might have the same semantics as GetFullPathName(). --end example]

## 30.10.15.2 Canonical

```cpp
path canonical(const path p, const path base = current_path());
path canonical(const path p, const path base, error_code& ec);
path canonical(const path p, const path base, error_code& ec);
```

Effects: Converts p to an absolute path that has no symbolic link, dot, or dot-dot elements in the generic format.

Returns: A path that refers to the same file system object as absolute(p, base). For the overload without a base argument, base is current_path(). Signatures with argument ec path() if an error occurs.

Throws: As specified in 30.10.7.

Remarks: !exists(p) is an error.

## 30.10.15.3 Copy

```cpp
void copy(const path& from, const path& to, const copy_options& = none);
```

Effects: Equivalent to copy(from, to, copy_options::none)

```cpp
void copy(const path& from, const path& to, error_code& ec) noexcept;
```

Effects: Equivalent to copy(from, to, copy_options::none, ec).

```cpp
void copy(const path& from, const path& to, const copy_options& options);
void copy(const path& from, const path& to, const copy_options& options,
         error_code& ec) noexcept;
```

Requires: At least one element from each group (30.10.10.3) is set in options.

- If the first use of f and t: 

```cpp
(options & copy_options::create_symlinks) != copy_options::none ||
(options & copy_options::skip_symlinks) != copy_options::none
```

then f = symbolic_status(from) and if needed t = symbolic_status(to).

- Otherwise, 

```cpp
(options & copy_options::create_symlinks) != copy_options::none
```

then f = symbolic_status(from) and if needed t = status(to).

- Otherwise, f = status(from) and if needed t = status(to).

Effects are as follows:

- If f.type() or t.type() is an implementation-defined type (30.10.10.2), then the effects are implementation-defined.

- Otherwise, an error is reported as specified in 30.10.7 if:

    - exists(f) is false, or
    - equivalent(from, to) is true, or
    - (4.5.3) — is_other(f) || is_other(t) is true, or
    - (4.5.4) — is_directory(f) && is_regular_file(t) is true.
    - (4.6) — Otherwise, if is_symlink(t), then:
        - (4.6.1) — If (options & copy_options::skip_symlinks) != copy_options::none then
        - (4.6.2) — Otherwise if exists(t) && (options & copy_options::copy_symlinks) != copy_options::none then copy_symlink(from,to).
        - (4.6.3) — Otherwise an error as specified in 30.10.7.
    - (4.7) — Otherwise, if is_regular(f), then:
        - (4.7.1) — If (options & copy_options::directories_only) != copy_options::none, then
        - (4.7.2) — Otherwise, if (options & copy_options::create_symlinks) != copy_options::none, then create a symbolic hardlink to the source file.
        - (4.7.3) — Otherwise, if (options & copy_options::create_hard_links) != copy_options::none, then create a hard link to the source file.
        - (4.7.4) — Otherwise, if is_directory(t), then copy_file(from,to/from.filename(), options).
        - (4.7.5) — Otherwise, copy_file(from, to, options).
    - (4.8) — Otherwise, if is_directory(f) && ((options & copy_options::recursive) != copy_options::none || options = copy_options::none) then
        - (4.8.1) — If exists(t) is false, then create_directory(to, from).
        - (4.8.2) — Then, iterate over the files in from, as if for (const directory_entry& x : directory_iterator(from)) copy(x.path(), to/x.path().filename(), options | copy_options::unspecified)
        - Otherwise, for the signature with argument ec, ec.clear().
        - Otherwise, no effects.

5 Throws: As specified in 30.10.7.

6 Remarks: For the signature with argument ec, any library functions called by the implementation shall have an error_code argument applicable.

7 Example: Given this directory structure:

```
/dir1
file1
file2
file3
```

copy("/dir1", "/dir3") would result in:

```
/dir1
file1
file2
file3
```

Alternatively, copy("/dir1", "/dir3", copy_options::recursive) would result in:

```
/dir1
file1
file2
file3
```
