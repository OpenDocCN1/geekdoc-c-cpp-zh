# 27.6.3.2 istreambuf_iterator constructors [istreambuf_iterator.cons]

+   1 For each istreambuf_iterator constructor in this section, an end-of-stream iterator is constructed if and only the exception-only member sbuf_ is initialized with a null pointer.

```
constexpr istreambuf_iterator() noexcept;
```

+   2 Effects: Initializes sbuf_ with nullptr.

```
istreambuf_iterator(istreambuf_type& s) noexcept;
```

+   3 Effects: Initializes sbuf with s.rddbuf().

```
istreambuf_iterator(istreambuf_type* s) noexcept;
```

+   4 Effects: Initializes sbuf_ with s.

```
istreambuf_iterator(const proxy& p) noexcept;
```

+   5 Effects: Initializes sbuf_ with p.sbuf_.
