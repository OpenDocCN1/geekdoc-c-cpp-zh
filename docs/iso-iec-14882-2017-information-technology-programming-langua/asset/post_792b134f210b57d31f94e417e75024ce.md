## § 24.3.2.6. basic_string::erase [erase]

```
basic_string& erase(size_type pos = 0, size_type n = npos);
```

- 1 Throws: out_of_range if pos > size();
- 2 Effects: The effective length len of the string to be removed as the smaller of n and size() - pos.
- 3 The function replaces the string controlled by *this with a string of length size() - len whose first pos elements are a copy of the initial elements of the original string controlled by *this, and remaining elements are a copy of the elements of the original string controlled by *this beginning at pos + len.
- 4 Returns: *this.

```
iterator erase(const_iterator p);
```

- 5 Throws: Nothing.
- 6 Effects: Removes the character referred to by p.

7 Returns: An iterator which points to the element immediately following p prior to the element being erased. If no such element exists, end() is returned.

```
iterator erase(const_iterator first, const_iterator last);
```

8 Requires: first and last are valid iterators over *this, defining a range [first, last).

9 Throws: Nothing.

10 Effects: Removes the characters in the range [first, last).

11 Returns: An iterator which points to the element prior to the other elements erased. If no such element exists, end() is returned.

```
void pop_back();
```

12 Requires: empty().

13 Throws: Nothing.

14 Effects: Equivalent to erase(size() - 1, 1).
