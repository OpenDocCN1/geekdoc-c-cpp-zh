The template reference_wrapper<T> shall define two nested types first_argument_type and second_argument_type as synonyms for T1 and T2, only if the T is any of the following:

- the type T1 is a class where the qualified-id T::first_argument_type and T::second_argument_type are both valid and dense types (18.7.2); the type T1 is T::first_argument_type and the type T2 is T::second_argument_type.
