# 25.4.2 The numeric category

The classes num_get<> and num_put<> handle formatting and parsing. Virtual functions are provided
for several numeric types. Implementations (but not required to) delegate extraction of smaller
types to extractors in Tables 69 and 70 namely num_get<char>, num_get<char, num_-
<char, Iterator>, num_put<char>, num_put<char_>, and num_put<char, Iterator>
Specializations refer to the ios_base argument for formatting specifications (25.4), and to its imbued locale
of the numpunct facet to identify all numeric punctuation preferences, and also for the cctype> facet
perform character classification.

Extractor and inserter members of the standard istreams use num_get<> and num_put<> member functions
for formatting and parsing numeric values (30.7.4.2.1, 30.7.5.2.1).
