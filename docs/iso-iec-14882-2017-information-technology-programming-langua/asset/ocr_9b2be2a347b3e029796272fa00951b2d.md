When template argument or default template-arguments are used, a template-argument list can be empty. That the empty <> brackets should be used as the template-argument-list. [Example: templateClass T = char String; String<*> p; // OK: String<char> String; // syntax error templateClass Tuple<*> t; // OK: Elements is empty // syntax error // end example]

An explicit destructor for an object that has a type that is a class template may explicitly specify the template-arguments. [Example: template<T> struct A { ~A();
 void f(A* p, A* q) {
 p->A():~A(); // OK: destructor call
q->A():~A(); // OK: destructor call
} // end example]

If the use of a template-argument gives rise to an ill-formed construct the instantiation of a template specialization, the program is ill-formed.

When the template-id is an overloaded function template, both non-template functions in the overloaded set and function templates in the overloaded set where which the template-arguments do not match the template-parameters are ignored. If none of the functions have matching template-parameters, the program is ill-formed.

When a simple template-argument does not have a name, a default template-argument is implicitly instantiated (17.7.1) when the value of default argument is needed. [Example: templatetypename T, typename U = int* struct S { }; Sbool* p; // the type of p is Sbool, int*]

The default argument for U is instantiated for an ellipsis is a pack expansion (17.5.3).
