# ISO/IEC 14882:2017(E)

# 20 Library introduction

# 20.1 General

This Clause describes the contents of the C++ standard library, how a well-formed C++ program makes use of the library, and how a conforming implementation may provide the entities in the library.

The following subclasses define the definitions (20.3), method of extension (20.4), and organization (20.5.1) of the library. Clauses 20.5, Clauses 21 through 33, and Annex D specify the contents of the library, as well as library requirements and constraints on well-formed C++ programs and conforming implementations.

Detailed specifications for each of the components in the library are Clauses 21–33,

The language support library (Clause 21) provides components that are required by certain parts of the C++ language, such as memory allocation (8.3.4, 8.3.5) and exception processing (Clause 18).

The diagnostics library (Clause 22) provides a consistent framework for reporting errors in a C++ program, including predefined exception classes.

The general utilities library (Clause 23) includes components used by other library entities, such as a predefined allocator for dynamic storage management (6.7.4), and components as infrastructure in C++ programs, such as tuples, wrappers, and facilities.

The strings library (Clause 24) provides support for representing text as sequences of type char, sequences of type char16_t, sequences of type char32_t, and sequences of type wchar_t, and sequences of any other character-like type.

The localization library (Clause 25) provides extended internationalization support for text processing.

The containers (Clause 26), iterators (Clause 27), and algorithms (Clause 28) libraries provide a C++ program with access to a subset of the most used algorithms and data structures.

The numerics library (Clause 29) provides numeric algorithms and complex number components that extend support for numeric processing.
