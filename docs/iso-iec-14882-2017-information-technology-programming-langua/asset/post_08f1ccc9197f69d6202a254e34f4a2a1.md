## 29.6.1.3 Uniform random bit generator requirements [rand.req.urng]

A uniform random bit generator g of type G is a function object returning unsigned integers whose each value in the range of possible results has ideally equal probability of being returned. [Note: The degree to which g's results approximate the ideal is often determined statistically. — end note]

A class G satisfies the requirements of a uniform random bit generator if the expressions in Table 103 are valid and if G satisfies all other requirements of this section 29.6.1.3. In Table and throughout this section:

- a) T is the type named by G's associated result_type, and
- b) g is a value of G.

Table 103 — Uniform random bit generator requirements

| Expression | Return type | Pre/post-condition | Complexity |
|---|---|---|---|
| G::result_type | T | T is an unsigned integer type (6.9.1). | compile-time |
| g() | T | Returs a value in the closed interval [G::min(), G::max()). | amortized |
| G::min() | T | Denotes the least value potentially returned by operator(). | compile-time |
| G::max() | T | Denotes the greatest value potentially returned by operator(). | compile-time |

The following relation shall hold: G:min() < G:max().

## 29.6.1.4 Random number engine requirements [rand.req.eng]

A random number engine (commonly shortened to engine) e type E is a uniform random bit generator that additionally meets the requirements (e.g., for seeding and for input/output) in this section.

At any time, e has a state, for some integer i ≥ 0. Upon construction, e has an initial state e0. An engine's state may be established by a constructor, a state function, or a suitable operator.

- the size of E in multiples of the result_type, as an integral constant; the algorithm TA by which E's state e, is advanced to its successor state e+i; and the generation GA by which E's state is mapped to a value of type result_type.
