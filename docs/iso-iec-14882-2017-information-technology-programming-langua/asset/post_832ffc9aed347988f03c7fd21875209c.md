# 8.20 Constant expressions [expr.const]

- Constant expressions that satisfy additional requirements as detailed in this subsection; other contexts have different semantics on whether or not an expression satisfies these requirements. Expressions that satisfy these requirements, assuming that collision is prevented, are called constant expressions. [Note: Expressions can be evaluated during translation. — end note]

constant-expression

An expression is a constant expression unless the evaluation of e, following the rules of the abstract machine (4.6), would evaluate one of the following expressions:

- this (8.1.2), except in a constexpr function or const constructor that is being evaluated as of e;

- an invocation of that other const constructor or for a literal, a constexpr function, or an implicit invocation of a destructor (15.4) [Note: Overload resolution (16.3) is applied as usual — end note];

- an invocation of an instantiated constexpr function or const constructor that fails to satisfy the requirements for a constexpr function or const constructor (10.1.5);

- an expression that would exceed the implementation-defined limits (see Annex B);

- an operation that has undefined behavior as specified in Clauses 4 through 19 of this definition [Note: including, for signed integer overflow (Clause 8), pointer arithmetic (8.7), division by zero (8.6), or shift operations (8.8) — end note];

- an inactive-to-value conversion (7.1) it is applied to

- a non-volatile value of integral or enumeration type that refers to a non-volatile const object with a preceding initialization, initialized with a constant expression,

- a non-volatile value that refers to a subobject of a string literal (5.13.5)

- a non-volatile value that refers to a non-volatile object defined with constexpr, or that refers to a non-mutable subobject of any such object, or

- a non-volatile value of literal type that refers to a non-volatile object whose lifetime began during the evaluation of e;

(2.8) an value-to-r conversion (7.1) that is applied to a gvalue refers to a non-active member of a union or a subobject thereof;

(2.9) an invocation of an implicitly-defined copy/move constructor or copy/move assignment operator for a union whose active member (if any) is mutable, unless the lifetime of the union object began during evaluation of e;

(2.10) an assignment expression (8.18) or invocation of an assignment (15.8) that would change the active member of one;

(2.11) an id-expression that refers to a variable or data member of reference type unless the reference has a preceding identifier and either

- (2.11.1) it is initialized with a constant expression or

- (2.11.2) its lifetime begins within the evaluation of e;

(2.12) in a lambda-expression, where refers to this or to a variable with automatic storage duration outside that lambda-expression, where the reference would an od-use (6.2, 8.1,5); Example:

If e satisfies the constraints of a constant expression, and evaluation of e would evaluate an operation that has undefined behavior as specified in Clauses 20 through 33 of this document, it is unspecified e is a constant expression.

```
Example:
int x;
struct A {
    constexpr A(bool b) : m(b) {}
    int m;
};
constexpr int v = A(true).m; // OK: constructor initializes m with the value
constexpr int w = A(false).m; // error: initializer for m, which is not constant
constexpr int f1(int k {
    constexpr x = k; // error: x is not initialized by a constant expression
                           because lifetime of k began outside the initializer of x
    return x;
}
constexpr int f2(int k {
    int x = k; // OK: not required to be a constant expression
                because x is not constexpr
    return x;
}
constexpr int incr(int &n) {
    ++n;
}
constexpr int g(int k {
    int x = incr(k); // error: incr(k) is not a constant expression
                      because lifetime of k began outside the expression incr(k)
    return x;
}
constexpr int h(int k {
    int x = incr(k); // OK: incr(k) is not required to be a constant expression
    return x;
}
constexpr int y = h(1); // OK: initializes y with the value
                         // h(1) is a constant expression because
                         // the lifetime of k begins inside h(1)
```

- An integer constant expression is an expression of integral or unscoped enumeration type, implicitly converted to a value, where the converted expression is a constant expression. [Note: Such expressions may be used as bit-field values (12.2.4), as enumerators if the underlying type is not fixed (10.2), and as alignments (10.6.2).] -- end note

- A converted constant expression of type T is an expression, implicitly converted to T, where the converted expression is a constant expression and the implicit conversion sequence contains only

- (4.1) user-defined conversions,

- (4.2) reference-to-value conversions (7.1),

- (4.3) array-to-pointer conversions (7.2),

- (4.4) function-to-pointer conversions (7.3),

- (4.5) qualification conversions (7.5).

- (4.6) — integral promotions (7.6)

- (4.7) — integral conversions (7.8) other than narrowing conversions (11.6,4),

- (4.8) — null pointer conversions (7.11) from std::nullptr_t,

- (4.9) — null member pointer conversions (7.12) from std::nullptr_t, and

- (4.10) — function pointers (7.13),

and the reference binding (if any) binds. [Note: Such expressions may be used in new expressions (8.3,4), as array initializers (9.4,2), as enumerator initializers if the type is fixed (10.2), as array bounds (11.3,4) and as non-template arguments (17.3) — end note] A contextually constant expression of type bool is an expression, converted to bool (Clause 7), where the converted expression is constant and the conversion sequence contains only constants

A constant expression is either a glue constant expression that refers to an entity that is a permitted result of a constant expression (as defined below), or a pure constant expression whose value satisfies the following constraints:

- (5.1) — if the value is an object of class, each non-static data member refers to an entity that is a permitted result of a constant expression,

- (5.2) — if the value is of pointer, it contains the address of an object with static storage duration, the address just past the end of such an object (8.7), the address of, or a null pointer value,

- (5.3) — if the value is an array or array type, each subscript satisfies these constraints for the value.

An entity is a permitted result of a constant expression if it is an object with static storage duration, or if it is not a temporary or an object whose value satisfies the above constraints, or if it is a function.
