# ISO/IEC 14882:2017(E)

```
struct A {
    A();
    A(const A&);      // copies from values
    A(A&&);           // moves from rvalues
};

void g() {
    A a;
    shared_ptr<A> spl = factory(a);      // "a" binds to A(const A&)
    shared_ptr<A> spl = factory(std::move(a)); // "a" binds to A(A&&)
};
```

In the first call, A1 is deduced as A&&, so it is forwarded as a non-const reference. This binds to the constructor A(const A&), which copies the value from a. In the second call to factory, because of the call std::move(a); A1 is deduced as A&&, so it moves to the constructor A(A&&), which moves the value. end example

# 23.2.7 Function template decltype

The library provides the function template decltype to simplify the definition of expressions which occur as unvaluated expressions (Clause 8).

```
template <class T> T& value_reference<T>& declval() noexcept; // unvaluated operand
```

+   2 Remarks: If this is order-deduced (6.2), the program is ill-formed.

template <class T, class From> decltype(static_cast<T>(declval<From>())) convert(From&&)
declares a function template T which only participates in overloading if the type From is converted to T. For another example see class template common_type(23.15.7.6). end example
