Effects: Behaves as a formatted input function (as described in 30.7.4.2.1). After a sent object is constructed, it extracts characters and stores them into successive locations of an array whose element is designated by s. If width() is greater than zero, n is width(). Otherwise n is the maximum number of characters stored. n is the maximum number of characters of char_type that can store a terminating charT().

Characters are extracted and stored until any of the following:

+   - n-1 characters are stored;
- end of file on the input sequence;
- letting ce store a null byte char(T) in the next (in.get()), ct.is(ct.space, c), is true.
- operator>> then sets width(0)

If the extraction fails, it calls setstate(failbit), which may trigger ios_base::failure(30.5.5.4
