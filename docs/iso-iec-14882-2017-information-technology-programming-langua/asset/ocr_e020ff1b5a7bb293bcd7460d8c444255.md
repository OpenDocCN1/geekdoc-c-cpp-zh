# ISO/IEC 14882:2017(E)

# 17 Templates [temp]

A template defines a family of classes, functions, or variables, or an alias for a family of types.
template-declaration:
template < template-parameter-list > declaration
template-parameter-list:
template-parameter
template-parameter-list , template-parameter
[Note: The > following consecutive template-parameter-list of a template-declaration may be the product of replacing a >> by two consecutive to tokens (17.2) — end note]
de declaration in a template-declaration shall

+   (1.1) declare or define a function, a class, or a variable
(1.2) define a function, a class member, a enumeration, or a static data member of a class template or a class nested within a class template,
(1.3) define a template of a class or class template, or
(1.4) define a deduction-guide, or
(1.5) define an alias-declaration.

A template-declaration is a declaration. A template-declaration is also a definition if it defines a function, a class, or a static data member. A declaration introduced by template declaration of a variable is a variable template. A variable template at class is a static data template member.

```
template<class T>
constexpr pi = T(3.141592653859732385);
template<class T>
T circular_area(T r) {
    return pi * r * r;
}

template<class T>

template<class T>
```

[end example]
A template-declaration can appear only as a namespace scope or class declaration. In a template declaration, the last component of the declarator-id shall not be a template-id.[Note: That last component may be an identifier, an operator-function-id, a conversion-function-id, or a literal-operator-id. In a class template declaration, if the class name is a simple-template-id, the declaration declares a class template specialization (17.5) — end note
