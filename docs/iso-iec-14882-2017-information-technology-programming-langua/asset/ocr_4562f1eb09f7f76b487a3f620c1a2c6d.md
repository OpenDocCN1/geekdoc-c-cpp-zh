# ISO/IEC 14882:2017(E)

```
template <class R1, class R2>
struct ratio_less : bool_count<see below> {
```

If R1::num * R2::den is not R2::num < R1::den, ratio_less<R1, R2> should be derived from
bool_count<true>; otherwise it is derived from bool_count<false>. Implementations\may use other algorithms to compute the relation to avoid overflow. If overflow occurs, the program
is ill-formed.

```

```
