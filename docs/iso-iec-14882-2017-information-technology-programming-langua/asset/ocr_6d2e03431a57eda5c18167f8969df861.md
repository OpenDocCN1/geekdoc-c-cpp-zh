A member or a member template may be nested within enclosing class templates. In an explicit specialization for such a member, the member declaration shall be preceded by a `template` for each enclosing class template that is explicitly specialized.
template<class T> class A {
template<class T> class B {
void mf();
};
template<class T> class A<T>::B {
templateemplate<class T> void A<int>::B::mf();
} // end example]

In an explicit specialization for a member of a class template or a member template that appears in namespace scope, the member template and all of its enclosing class templates may remain unspecialized, except that the declaration shall explicitly specialize a class template if its enclosing class templates are not explicitly specialized as well. In such explicit specialization declaration, the keyword `template-parameter-list` shall be provided instead of the `template` preceding the explicit specialization declaration of the member. The types of the template-parameters in the template-parameter-list shall be the same as those specified in the primary template definition. [Example:
template<class T1> class A {
template<class T2> class B {
template<class T3> void mf(T3);
void mf();
};
template <> template<class X> class A<int>::B {
template<class T> void mfi(T);
};
template <> template<class T> void A<int>::B<double>:::mf1(T t) { }
template<class Y> template <
void A<Y>::B<double>:::mf2() { } // ill-formed; `B<double>` is specialized but // its enclosing class template A is not // end example]
