## 30.7.4 Input streams [input.streams]

The header defines types and a function that control input from a stream buffer along with a function template that extracts from stream rvalues.

### 30.7.4.1 Class template basic_istream [istream]

```cpp
namespace std {
template <class charT, class traits = char_traits<charT>>
class basic_istream : virtual public basic_ios<charT, traits> {
public:
    // types (inherited from basic_ios (30.5.5)):
    using char_type = charT;
    using int_type = typename traits::int_type;
    using pos_type = typename traits::pos_type;
    using off_type = typename traits::off_type;
    using traits_type = traits;

    // 30.7.4.1. constructor/destructor
    explicit basic_istream(basic_streambuf<charT, traits>* sb);
    virtual ~basic_istream();

    // 30.7.4.2. prefix/suffix
    charT& operator()();
    operator&(basic_istream<charT, traits>& i) operator&(&(basic_istream<charT, traits>& i);
    basic_istream<charT, traits>& operator()();
    operator>>(basic_istream<charT, traits>& i) operator&(&(basic_istream<charT, traits>& i);
    basic_istream<charT, traits>& operator()();
    basic_istream<charT, traits>& operator>>(short& n);
    basic_istream<charT, traits>& operator>>(unsigned short& n);
    basic_istream<charT, traits>& operator>>(int& n);
    basic_istream<charT, traits>& operator>>(unsigned int& n);
    basic_istream<charT, traits>& operator>>(long& n);
    basic_istream<charT, traits>& operator>>(unsigned long& n);
    basic_istream<charT, traits>& operator>>(long long& n);
    basic_istream<charT, traits>& operator>>(long long& n);
    basic_istream<charT, traits>& operator>>(float& f);
    basic_istream<charT, traits>& operator>>(double& f);
    basic_istream<charT, traits>& operator>>(long& f);

    basic_istream<charT, traits>& operator=(void* p);
    basic_istream<charT, traits> operator=(void* p);
    basic_istream<charT, traits> operator=(basic_streambuf<charT, traits>* sb);

    // 30.7.4.3. unformatted input
    streamsize gcount() const;
    int_type get() const;
    basic_istream<charT, traits>& get(char_type& c);
    basic_istream<charT, traits>& get(char_type* s, streamsize n);
    basic_istream<charT, traits>& get(char_type* s, streamsize n, char_type delim);
    basic_istream<charT, traits>& get(basic_streambuf<charT, traits>& sb);
    basic_istream<charT, traits>& get(basic_streambuf<charT, traits>& sb, char_type delim);

    basic_istream<charT, traits>& getline(char_type* s, streamsize n);
    basic_istream<charT, traits>& getline(char_type* s, streamsize n, char_type delim);

    basic_istream<charT, traits>& ignore(streamsize n = 1, int_type e = traits::eof());
    int_type peek();
    basic_istream<charT, traits>& read(char_type* s, streamsize n);
    streamsize read(char_type* s, streamsize n);

    basic_istream<charT, traits>& putchar(char_type c);
    basic_istream<charT, traits>& unget();
    sync();

    pos_type tellg();
    basic_istream<charT, traits>& seekg(pos_type);
    basic_istream<charT, traits>& seekg(off_type off, ios_base::seekdir dir);

protected:
    // 30.7.4.1.1, move constructor
    basic_istream(basic_istream&& rhs) = delete;
    basic_istream(basic_istream&& rhs);

    // 30.7.4.1.2, assign and swap
    basic_istream&operator=(const basic_istream& rhs) = delete;
    basic_istream&operator=(basic_istream& rhs);
    void swap(basic_istream& rhs);

    // 30.7.4.2, character extraction templates
    template<class charT, class traits>
    basic_istream<charT, traits>& operator>>(basic_istream<charT, traits>&, charT&);
    template<class charT, class traits>
    basic_istream<charT, traits>& operator>>(basic_istream<charT, traits>&, unsigned char&);
    template<class charT, class traits>
    basic_istream<charT, traits>& operator>>(basic_istream<charT, traits>&, signed char&);

    template<class charT, class traits>
    basic_istream<charT, traits>& operator>>(basic_istream<charT, traits>&, charT&);
    template<class charT, class traits>
    basic_istream<charT, traits>& operator>>(basic_istream<charT, traits>&, unsigned char&, signed char&);
};
```

1 The class basic_istream defines a number of member function signatures that assist in reading and interpreting input from sequences controlled by a stream buffer.
2 Two groups of member function signatures share common properties: the formatted input functions (or extractors) and the unformatted input functions. Both groups are described as if they obtain (or extract) input characters by calling rdbuf()->sgetc() or rdbuf()->getc(). They may use other public members of istream.

If one of the called functions throws an exception, unless explicitly noted otherwise, the input function sets badbit in error. If badbit is not in exceptions(), the input function throws the exception without completing its actions, or it does not throw anything and proceeds as if the function had returned a failure indication.

### 30.7.4.1.1 basic_stream constructors [stream.cons]

explicit basic_stream(basic_streambuf<charT,traits>* sb);

1. Effects: Constructs an object of class basic_stream, initializing the base subject with basic_ios::init(sb) (30.5.5,2).
2. Postconditions: gcount() == 0.
basic_stream(const basic_stream& rhs);
3. Effects: Moves constructs from the rhs value. This is accomplished by default constructing the class, copying the gcount() from rhs, calling basic_ios<charT,traits>::move(rhs) to initialize the base class, and setting the gcount() for rhs to 0.
virtual ~basic_stream();
4. Effects: Destroys an object of class basic_stream.
5. Remarks: Does not perform any operations on rdbuf().

### 30.7.4.2 Class basic_stream:: assign and swap [stream.assign]

basic_stream&operator=(basic_stream& rhs);

1. Effects: as by swap(rhs).
2. Returns: *this.

void swap(basic_stream& rhs);
3. Effects: Calls basic_ios<charT,traits>::swap(rhs). Exchanges the values returned by gcount() and rhs. gcount().
