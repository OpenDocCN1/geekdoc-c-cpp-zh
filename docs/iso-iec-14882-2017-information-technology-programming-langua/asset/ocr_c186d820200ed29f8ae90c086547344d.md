# ISO/IEC 14882:2017(E)

Table 91 — Unordered associative container container requirements (in add-tion to container) (continued)

| Expression | Return type | Assertion/note pre-/post-condition | Complexity |
|---|---|---|--|
| a_uniq.insert(t) | pair<iterator, bool> | Requires: if t is a non-const rvalue expression, value_type shall be MoveInsertable into X; otherwise, value_type shall be CopyInsertable into X. Effects: Inserts t if and only if there is no element in the container with key equivalent to the key of t. The component of the returned pair indicates whether the insertion takes place, and the iterator component points to the element equivalent to the key of t. | Average case O(1), worst case O(a_uniq.size()) |
| a_eq.insert(t) | iterator | Requires: if t is a non-const value expression, value_type shall be MoveInsertable into X; otherwise, value_type shall be CopyInsertable into X. Effects: Inserts t, and returns an iterator pointing to the newly inserted element | Average case O(1), worst case O(a_eq.size()) |
| a.insert(p, t) | iterator | Requires: if t is a non-const value expression, value_type shall be MoveInsertable into X; otherwise, value_type shall be CopyInsertable into X. Effects: Equivalent to a.insert(t). Return value is an iterator pointing to the element with key equivalent to that t. The iterator p is a hint pointing to the search should start. Implementations are permitted to ignore the hint. | Average case O(1), worst case O(a.size()) |
| a.insert(i, j) | void | Requires: value_type shall be PlaceConstructable into X from *1. Requires: i and j are not Iterators in a. Equivalent to a.insert(t) for each element in [i, j). | Average case O(N), where N is distance(i, j). Worst case O(N(a.size() + 1)). |
