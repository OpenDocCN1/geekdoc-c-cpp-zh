## 23.11.2.20 get_deleter [util.smartptr.deleter]

```cpp
template<class D, class T>
get_deleter(const D& d) returns address_of(d) noexcept;
```

- 1 Returns: If p returns a pointer to d, of uninvalided d, returns address_of(d); otherwise returns nullptr. The pointer remains valid as long as there exists a shared_ptr instance that owns d. [Note: It is unspecified whether the pointer remains longer than that. This can happen if the implementation doesn't destroy the deleter until all shared_ptr instances share ownership with p have been destroyed. — end note ]

## 23.11.2.23 Class template weak_ptr [util.smartptr.weak]

1 The weak_ptr class stores a reference to an object that is already managed by a shared_ptr. To access the object, a weak_ptr can be converted to a shared_ptr using the following method constructor:

```cpp
namespace std {
  template<class T> class weak_ptr {
  public:
    using element_type = T;
```

```cpp
weak_ptr(weak_ptr<T> r) noexcept;
```

## 23.11.2.3.1 weak_ptr constructors [util.smartptr.weak.const]

```cpp
constexpr weak_ptr() noexcept;
```

- 1 Effects: Constructs an empty weak_ptr
Postconditions: use_count() == 0.

```cpp
weak_ptr(const weak_ptr<Y>& r) noexcept;
template<class Y> weak_ptr(const shared_ptr<Y>& r) noexcept;
```

- 3 Remarks: The first and second constructors will not participate in overload resolution unless Y is compatible with T.
- 4 Effects: If r is empty, constructs an empty weak_ptr object; otherwise, a weak_ptr object that shares ownership with r and stores a copy of the pointer stored in r.
- 5 Postconditions: use_count() == r.use_count().

```cpp
weak_ptr(weak_ptr<Y>&& r) noexcept;
template<class Y> weak_ptr(weak_ptr<Y>&& r) noexcept;
```

- 6 Remarks: The second constructor will not participate in overload resolution unless Y is compatible with T.
- 7 Effects: Move a weak_ptr instance from r.
- 8 Postconditions: *this shall contain the old value of r. if r is empty, r.use_count() == 0.

## 23.11.2.3.2 weak_ptr destructor [util.smartptr.weak.dest]

```cpp
~weak_ptr();
```

- 1 Effects: Destroys the weak_ptr object which has no effect on the object it stored pointer to.

```cpp

```

- 1 Returns: 0 if this is empty; otherwise, the number of shared_ptr<T> instances that share ownership with this.


- 3 Returns: expired() ? shared_ptr<T>(*this) : _, executed atomically.
- 4 Returns: An unspecified value such that
  - x.owner_before(y) defines a relation defined by owner_before(b) && !b.owner_before(a) in 28;
  - (4.2) under the relation defined by owner_before, !a.owner_before(b) && !b.owner_before(a), two shared_ptr or weak_ptr instances are equivalent if they share ownership or both.
