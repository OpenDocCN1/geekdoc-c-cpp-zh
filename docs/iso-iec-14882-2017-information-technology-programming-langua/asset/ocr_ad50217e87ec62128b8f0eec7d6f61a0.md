# ISO/IEC 14882:2017(E)

```
template <class T> constexpr operator!=(const optional<T>& x, nullopt_t) noexcept;

```

```
template <class T> constexpr operator=(const optional<T>& x, nullopt_t) noexcept;
Returns: bool(x);
```

```
template <class T> constexpr operator=(nullopt_t, const optional<T>& x) noexcept;
Returns: false;
```

```
template <class T> constexpr operator<=(const optional<T>& x, nullopt_t) noexcept;
Returns: false;
```

```
template <class T> constexpr operator<=(nullopt_t, const optional<T>& x) noexcept;
Returns: true;
```

```
template <class T> constexpr operator>=(const optional<T>& x, nullopt_t) noexcept;
Returns: bool(x);
```

```
template <class T> constexpr operator>=(nullopt_t, const optional<T>& x) noexcept;
Returns: false;
```

```
template <class T> constexpr operator>=(const optional<T>& x, nullopt_t) noexcept;
```

# 23.6.8 Comparison with T [optional.comp_with_t]

```
template <class T, class U> constexpr operator==(const optional<T>& x, const U& v);
```

The expression x == v will be well-formed and its result will be convertible to bool.
[Note: T need not be EqualityComparable. — end note]

Effects: Equivalent to: return bool(x) ? x == v : false;

```
template <class T, class U> constexpr operator!=(const U v, const optional<T>& x);
```

The expression x != v will be well-formed and its result will be convertible to bool.

Effects: Equivalent to: return bool(x) ? x != v : false;

```
template <class T, class U> constexpr operator<(const U v, const optional<T>& x);
```

The expression x < v will be well-formed and its result will be convertible to bool.

Effects: Equivalent to: return bool(x) ? x < v : true;

```
template <class T, class U> constexpr operator<=(const U v, const optional<T>& x);
```

The expression x <= v will be well-formed and its result will be convertible to bool.

```
template <class T, class U> constexpr operator>>(const optional<T>& x, const U& v);
```

The expression x > v will be well-formed and its result will be convertible to bool.
