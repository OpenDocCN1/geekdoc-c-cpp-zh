# 24.3.2.7 basic_string::find_last_of

size_type find_last_of(basic_string_view<charT, traits> str, size_type pos = npos) const except

Effects: Determines the highest position xpos, if possible, such that both of the following conditions hold:

+   (1.1) pos <= xpos and xpos < size();

+   (1.2) traits::eq(atpos), sv.at(I) for some element I of the data referenced by sv.
Returns: xpos if the function can determine such a value for xpos. Otherwise, returns npos.

size_type find_last_of(const charT& s, size_type pos = n) const

Effects: Equivalent to: return find_last_of(basic_string_view<charT, traits>(str), npos).

size_type find_last_of(const charT* s, size_type pos = npos) const

Returns: find_last_of(basic_string_view<charT, traits>(s, n), npos).

size_type find_last_of(const charT* s, size_type pos = npos) const
Requires: s points to an array of all traits::length(s) + 1 elements of charT.

Returns: find_last_of(basic_string_view<charT, traits>(s), npos).

size_type find_last_of(const char c, size_type pos = npos) const;

Returns: find_last_of(basic_string(1, c), npos).

# 24.3.2.7 basic_string::find_not_of

size_type find_not_of(basic_string_view<charT, traits> sv, size_type pos = 0) const except

Effects: Determines the lowest position xpos, if possible, such that both of the following conditions hold:

+   (1.1) pos <= xpos and xpos < size();

+   (1.2) traits::eq(atpos), sv.at(I) for no element I of the data referenced by sv.
Returns: xpos if the function can determine such a value for xpos. Otherwise, returns npos.
