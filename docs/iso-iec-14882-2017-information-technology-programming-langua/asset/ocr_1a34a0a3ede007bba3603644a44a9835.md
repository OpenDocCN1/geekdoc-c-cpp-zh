# 23.15 Metaprogramming and type traits [meta]

This subclass describes components using C++ programs, particularly in templates, to support the widest possible range of types, optimize template code, detect user errors, and perform inference and transformation at compile time. It includes type classifications, type inspection traits, and transformations. The type classifications describe a complete taxonomy of all possible C++ types, and where in that taxonomy a type belongs. The type inspection traits allow important characteristics of types or combinations of types to be inspected. Type transformations allow certain properties of types to be manipulated.

# 23.15.1 Requirements [meta.rqmts]

+   1 A TypeTrait describes a property of a type. It shall be a class template that takes one template argument, and optionally, additional arguments that help the property being described. It shall be DefaultConstructible, CopyConstructible and publicly unambiguously, directly or indirectly, from its base characteristic, which is a specialization of the template integral_constant determined by the requirements for the particular property being described. The member names of the base characteristic shall not be hidden and shall be unambiguously available in the TypeTrait.

+   2 A BinaryTrait describes a relationship between two types. It shall be a class template that takes two template arguments, and optionally, additional arguments that help the relationship being described. It shall be DefaultConstructible, CopyConstructible and publicly unambiguously, directly or indirectly, from its base characteristic, which is a specialization of the template integral_constant (23.15.3), determined by the requirements for the particular relationship being described. The member names of the base characteristic shall not be hidden and shall be unambiguously available in the BinaryTrait.

+   3 A TransformationTrait modifies a property of a type. It shall be a class template that takes one template argument, and optionally, additional arguments that help define the modification. It shall define a publicly accessible nested type named, which shall be a synonym for the modified type.
