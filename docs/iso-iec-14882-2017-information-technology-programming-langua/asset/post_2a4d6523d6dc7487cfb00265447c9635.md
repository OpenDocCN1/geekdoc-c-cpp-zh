### 29.6.7.1 Class seed_seq

[rand.util]

```cpp
class seed_seq {
public:
    // types
    using result_type = uint_32_t;
    // constructors
    seed_seq();
    template<class T>
    seed_seq(initializer_list<T> il);
    template<class InputIterator>
    seed_seq(InputIterator begin, InputIterator end);
    // generating functions
    template<class RandomAccessIterator>
    void generate(RandomAccessIterator begin, RandomAccessIterator end);
    // property functions
    size_t size() const noexcept;
    template<class OutputIterator>
    void param(OutputIterator dest) const;
    // copy functions
    seed_seq(const seed_seq& k) = delete;
    void operator=(const seed_seq& k) = delete;
private:
    vector<result_type> v; // exposition only
};
seed_seq();
```

```cpp
template<class RandomAccessIterator>
void generate(RandomAccessIterator begin, RandomAccessIterator end);
```

Requires: RandomAccessIterator shall meet the requirements of a mutable random access iterator ([27.2.7]). Moreover, iterator_traits<RandomAccessIterator>::value shall denote an unsigned integer type capable of accumulating 32-bit values.

Effects: If begin == end, otherwise, with s = v.size() and n = end - begin, fills the specified range [begin, end) by the following algorithm in which each operation is carried out modulo n, and T(x) is defined as x xor T(x).

- a) By way of initialization, each element of the range to value 0x8b8b8bb. Additionally, for use sequences, set p = (n-t)/2 and q = p+t, where

```cpp
t = (n >= 623) ? 1 : (n >= 68) ? 7 : (n >= 39) ? 5 : (n - 1)/2;
```

- b) With m the range of s+1 and n, transform the elements of the range: iteratively for k=0, ..., m-1, calculates values

```cpp
r1 = 164525-T[begin[k] xor begin[k+p] xor begin[k-1]]
r2 = r1 + { k mod n + v[k-1], 0 < k <= s; k mod n, s < k }
```

and, in order, increment begin[k+p] by xoring with r1, increment begin[k+q] by xoring with r2, and set begin[k] to r2.

Transform the elements of the range again, where the previous step ended: iteratively for k=m, ..., m-n-1, calculates values

```cpp
r3 = 15689341-T[begin[k] + begin[k+p] + begin[k-1]]
r4 = r3 - (k mod n)
```

and, in order, update begin[k+p] by xoring with r3, update begin[k+q] by xoring with r4, and set begin[k] to r3.
