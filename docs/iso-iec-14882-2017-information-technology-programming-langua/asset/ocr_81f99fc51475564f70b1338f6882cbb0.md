# 17.9 Deduction guides [temp.deduct.guide]

Deductions are made when a template-name appears as a type for a deduced class template argument (10.1.7.5). Deductions are not found by lookup. When performing class template argument deduction (16.3.1.8), deduction guides for the class template are considered.

```
deduction-guide:
explicit-type template-name (parameter-declaration-clause) -> simple-template-id;
```

2 [Example:

```
template<class T, class D = int>
struct S {
    T Data;
};
template<class U>
S(U) -> S<typename U::type>;

struct {
    using type = short;
    operator()();
};
S x(A); // x is of type Sshort, int
// end example;
```

3 The same restrictions apply to the parameter-declaration-clause of a deduction guide as in a function declaration (11.3.5). The simple-template-id should name a class template specialization. The template-name should be the same identifier as the simple-template-id. A deduction-guide should be declared in the scope as the corresponding class template and, for a member class, with the same access. Two deduction guides in the same translation unit for the same class template shall not have equivalent parameter-deduction-clauses.
