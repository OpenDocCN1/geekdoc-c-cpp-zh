# 6.3.7 Class scope [basic.scope.class]

+   1 The potential scope of a name declared in a class consists not only of the declarative region following the
name's point of declaration, but also of all function bodies, default arguments, noexcept-specifiers, and
brace-or-initializers of non-static members (including such things in nested).

+   2 A N named in a class S shall refer to the same declaration in this context and when reevaluated in the
complete scope of S. No diagnostic is required for a violation of this rule.

+   3 A name declared within a member function refers to the declaration of the same name whose scope extends to
end of the member function's class.

+   4 The potential scope of a declaration that extends to past the end of a class definition also extends to the
regions defined by its member definitions, even if the members are legally outside the class (which
includes static member definitions, nested classes, and member functions, including the
member function body and any portion of the declarator part of such definitions which follows the
declarator-id, including a parameter-declaration-clause and any default arguments (11.3.6).
