void k() {
    link* q = new link;

declares p to be a reference to a pointer so h(q) will leave q with the value. See also 11.6.3.

+   It is unspecified or not a reference has references, arrays of references, and pointers to references. [6.7).

+   There shall be no references to references. The declaration of a reference shall contain an initializer (11.6.3) except when the declaration contains an explicit extern (10.1.1), a (12.2) declaration within a class, or of a parameter or a return type (11.3.5). A reference used to refer to a value object or expression [Note: In particular, a reference cannot be used as a well-defined qualifier, because the only way to create such a reference is to bind it to the "object" by indirection through a null pointer, which causes undefined behavior.] cannot be bound directly to a bit-field. // end note

+   If a typedef-name (10.1.3, 17.1) or a decltype reference to cv (10.1.7.2) creates a type TR that is a reference to a type T, an attempt to create the type "value reference to cv TR" creates the type "value reference to T", while an attempt to create the type "value reference to cv TR" creates the type TR. This rule is known as reference collapsing. [Example]:

```
int i;
typef int LRI;
LRI& r1 = i; // r1 has the type int
const LRI& r2 = i; // r2 has the type int
const LRI& r3 = i; // r3 has the type int
LRI& r4 = i; // r4 has the type int
LRI& r5 = i; // r5 has the type int
decltype(r2)&r6 = i; // r6 has the type int
decltype(r2)&r7 = i; // r7 has the type int
// end example|
```

> [Note: Forming a reference to function type is ill-formed if the function type has cv-qualifiers or a ref-qualifier-seq 11.3.5. // end note]

# 11.3.3 Pointers to members

+   In a declaration D where D has the name nested-name-specifier attribute-specifier-seqopt cv-qualifier-seq D1 and the nested-name-specifier denotes a class, and the type of the identifier in the declaration T D1 is "derived-declarator-type-list T", where the identifier of D is "derived-declarator-type-list cv" pointer to member of class nested-name-specifier of type T". The optional attribute-specifier-seq [10.6.1] pertains to the pointer-to-member.

+   [Example]:

```
struct X {
    void f(int);
    int a;
}
```
