# 16.3.2 Viable functions [over.match.viable]

+   1 From the set of candidate functions constructed for a given context (16.3.1), a set of viable functions is chosen, from which the best will be selected by comparing argument sequences for the best (16.3.3). The selection of viable functions considers relationships between arguments and parameters other than the ranking of sequences.

+   2 First, to be a viable, a candidate function shall have enough parameters to agree in number with the arguments in the list.

+   (2.1) If there are m arguments in the list, all candidate functions having exactly m parameters are viable.

+   (2.2) A candidate function having more than m parameters is viable only if there is an ellipsis in its parameter list (11.3.5). For the purposes of overload resolution, any argument for which there is no corresponding parameter is considered to "match the ellipsis" (16.3.3.1).
