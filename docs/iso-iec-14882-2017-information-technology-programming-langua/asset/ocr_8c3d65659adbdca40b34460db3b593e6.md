# ISO/IEC 14882:2017(E)

# 17.6.2.3 Value-dependent expressions

Except as described below, an expression used in a context where a constant expression is required is value-dependent if any subsequence is value-dependent.

An id-expression is value-dependent if:

+   (2.1) it is type-dependent,

+   (2.2) it is the name of a non-type template parameter,

+   (2.3) it names a static data member that is a dependent member of the current instantiation and is initialized in a member-declarator;

+   (2.4) it names a static member function that is a dependent member of the current instantiation, or

+   (2.5) it is a constant literal that is initialized with an expression that is value-dependent.

Expressions of the following form are value-dependent if the unary-expression or expression is type-dependent

```
sizeof unary-expression
sizeof ( type-id )
typeid ( expression )
typeid ( type-id )
alignof ( expression )
noexcept ( expression )
```

> Note: For the standard library offsetof, see 21.2. — end note

Expressions of the following form are value-dependent if either the type-id or simple-type is dependent
or the expression or cast-expression is value-dependent:

```
simple-type-specifier ( expression-list_opt )
static_cast < type-id > ( expression )
const_cast < type-id > ( expression )
reinterpret_cast < type-id > ( expression )
( type-id ) cast-expression
```

Expressions of the following form are value-dependent:

```
sizeof ... ( identifier )
fold-expression
```

An expression of the form &qualified-id where the qualified-id names a dependent member of the current
instantiation is value-dependent. evaluating cast-expression as a constant expression (8.20) succeeds and the result of the evaluation refers to a templated entity that is an object with static or thread storage or a member function.

# 17.6.2.4 Dependent template arguments

+   A template-argument is dependent if its type is dependent or the constant expression it specifies

+   A non-type template-argument is dependent if the corresponding non-type template-parameter
value-dependent.

+   Furthermore, a non-type template-argument-the template-argument designates or points to a member of the current
instantiation or a member of a dependent type.

+   A template-argument is dependent if it names a template-parameter or a qualified-id that refers
to a member of an unknown specialization.
