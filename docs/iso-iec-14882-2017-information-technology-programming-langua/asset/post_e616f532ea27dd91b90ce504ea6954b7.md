* *Effects:* An insertion in the middle of the deque invalidates all the iterators to the deque, but has no effect on the validity of elements of the deque.

2 *Exceptions:* If an insertion is thrown other than by the copy constructor, move constructor, assignment operator, or move assignment operator of T there are none. If an exception is thrown while inserting a single element at end, there are none. Otherwise, if an exception is thrown by the move constructor of a non-Copyable T, the effects are unspecified.

3 *Complexity:* The complexity is linear in the number of elements inserted plus the lesser of the beginning and end of the deque. Inserting a single element at the beginning or end of a deque always takes constant time and causes a call to a constructor of T.

4 *Effects:* An erase operation that erases the last element of a deque invalidates only the past-the-end iterator and all iterators and references to the erased elements. An erase operation that erases neither the first element nor the last element of a deque invalidates all iterators and references to the erased elements, the past-the-end iterator, and all iterators and references to all elements of the deque.

> *Note:* pop_front and pop_back are erase operations.

5 *Complexity:* The number of calls to the destructor of T is the same as the number of elements erased, but the number of calls to the assignment operator of T is no less than the number of elements before the erased elements and the number of elements after the erased elements.

6 *Throws:* Unless an exception is thrown by the copy constructor, move constructor, assignment operator, or move assignment operator.

## 26.3.9 Class template forward_list

### 26.3.9.1 Class template forward_list overview

A forward_list is a container that supports forward iterators and allows constant insert and erase operations within the sequence, with storage management handled automatically. Random access to list elements is not supported. *Note: It is intended that forward_list have space or time overhead relative to a hand-written style linked list. Features that would conflict with goal have been omitted.*

A forward_list satisfies all of the requirements of a container (Table 83), except that the size() member is not provided and operator== linear complexity. A forward_list also satisfies all of the requirements for an allocator-aware container (Table 86). In addition, a forward_list satisfies the assign member (Table 87) and all of the other container requirements (Table 88). Descriptions are provided here only for operations on forward_list that are not described in that table or for containers with additional semantics.

*Note: Modifying any list requires access to the element preceding the first of interest, but in a forward_list there is no constant-time way to access a preceding element. For this reason, ranges that are modified, such as those used to erase and splice, must be at the beginning.*
