# 23.12.3. Class polymorphic_allocator [mem.polymorphic_allocator.class]

A specialization of class pmr::polymorphic_allocator conforms to the Allocator requirements (20.5.3.5). Constructed with different memory resources, different instances of the same specialization of pmr::polymorphic_allocator allows objects that use polymorphic_allocator to behave as if they used different allocator at runtime even though they use the same allocator type.

```
template <class T>
class polymorphic_allocator {
    memory_resource* memory_rarc;

public:
    using value_type = T;

    // 23.12.3.1. constructors
    polymorphic_allocator() noexcept;
    polymorphic_allocator(memory_resource* r);

    polymorphic_allocator(const polymorphic_allocator& other) = default;

    template <class U>
    polymorphic_allocator(const polymorphic_allocator<U>& other) noexcept;

    polymorphic_allocator&
    operator=(const polymorphic_allocator& rhs) = delete;

    // 23.12.3.2. member functions
    T* allocate(size_t n);
    void deallocate(T* p, size_t n);

    template <class T, class... Args>
    void construct(T* p, Args&&... args);
```
