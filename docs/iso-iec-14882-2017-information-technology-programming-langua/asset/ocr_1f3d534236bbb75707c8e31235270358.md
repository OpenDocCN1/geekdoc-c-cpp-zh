+   11 When a new-expression calls an allocation function and the first argument of the new-expression expresses the amount of space requested to the allocation function as type size::size_t. That shall be no less than the size of the object being created; it may be greater than the size of the object created only if the object is array. For arrays of char, unsigned char, and std::byte, the difference between the result of the new-expression and the address returned by the allocation function is an integral multiple no greater than the size of the array created. [Note: because allocation functions are extended to return addresses that are appropriate for objects of any type with fundamental alignment, this common idiom of aligning character arrays into objects of other types will be placed.] — end

+   12 When a new-expression calls an allocation function and that has been extended, the size argument to the call shall be no greater than the sum of the sizes for the omitted calls as specified above, plus the size if it has not been extended, plus any padding necessary to align the objects within the allocated memory.

+   13 The new-placement syntax is used to supply additional arguments to an allocation function; such an expression is called a new-expression.

+   14 Overload is performed on a function called by assembling an argument list. The first argument is the amount of space requested, and has type size::size_t. If the type of the allocated object has new-alignment, the next argument is the type's alignment, and has type std::align_val_t. The new-placement syntax is used, the initializer-clauses in its expression-list are the succeeding arguments. If no matching function is found and the allocated object type has new-extended alignment, the argument is removed from the argument list, and overload resolution is performed again.
