# 33.6.10.1 packaged_task member functions

packaged_task() noexcept;

+   1 Effects: Constructs a packaged_task object with no shared state and no stored state.

```
template <class F>
packed_task(F&& f);
```

+   2 Requires: INVOKER<R>(f, t1, t2, ..., tN) (23.14.3), where t1, t2, ..., tN are values of the responding types in ArgTypes..., shall be a valid expression. Invoking a copy of f shall have the same name as invoking f.

+   3 Remarks: This constructor_<R> shall not participate in overload resolution if decay<T> is the same type as packaged_task<R(ArgTypes...)>>.

+   4 Effects: Constructs a new packaged_task object with a shared state and initializes the object's state with std::forward<F>(f).

+   5 Throws:

+   (5.1) Any exceptions thrown by the constructor or move constructor of f.

+   (5.2) For the first version, bad_alloc memory for the internal data structures could not be allocated.

+   (5.3) For the second version, any exceptions thrown by allocator_traits<Allocator>::template rebind_traits<unspecified_type>:::allocate.

packaged_task(packaged_task&& rhs) noexcept;

+   6 Effects: Constructs a new packaged_task object and transfers ownership of rhs's shared state to *this, leaving rhs with no shared state. Moves the stored task from rhs to *this.

Postconditions: rhs has no shared state.
