# 22.5 System error support [syserr]

+   1 This subclause describes components that the standard library and C++ programs may use to report error conditions originating from the operating system or other low-level application interfaces.

+   2 Components described in this subclause shall not change the value of errno (22.4). Implementations should leave the state provided by other libraries unchanged.
