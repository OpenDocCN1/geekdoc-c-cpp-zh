+   (4.3) otherwise, if e is an xvalue, decltype(e) is T&, where T is the type of e;

+   (4.4) otherwise, if e is an lvalue, decltype(e) is T&& where T is the type of e;

+   (4.5) otherwise, decltype(e) is the type of e.

The operand of the decltype specifier is an unvaluated operand (Clause 8).

If the operand of a decltype-specifier is a prune, the temporary conversion is not applied (7.4) and no result is produced for the primal. The type may be invalid. [Note: As a result, storage is not allocated for the prvalue and it is not destroyed. A class is not instantiated as a result of being the type of a function call in this context. In this context, the purpose of writing a decltype-specifier is analogue to that of a value, so the same reasons for requiring a conversion do not apply.
