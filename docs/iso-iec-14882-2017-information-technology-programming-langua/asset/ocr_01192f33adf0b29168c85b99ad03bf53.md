11 Return type deduction for a template with a placeholder in the declared type occurs when the definition is instantiated if the function body contains a return statement with a non-dependent operand. Note: Therefore any specialization of the template function will cause an instantiation. Any errors that from this instantiation are not in the immediate context of the function type and can be ill-formed (17.7.2) -- end note | [Example]:

```
template <T> auto f(T t) { return t; }
typef decltype(f(int())) int_t;
template<T> auto f(T t) { return t; }
void g() { (*f)(int*) = &f; }
```

> // return type deduced at instantiation time
// instantiates <int> to reduce return type
// instantiates both f to determine return types,
// chosen second

-- end example

```
template<typename T> struct A {
```

-- end example

13 A function declared with a return type that uses a placeholder type shall not be virtual (13.3).

14 An explicit declaration (17.7.2) does not cause the instantiation of an entity declared using a placeholder type, but it also not prevent that entity from being instantiated as needed to determine its type. [Example]:

```
template <typename T> auto f(T t) { return t; }
```
