
# ISO/IEC 14882:2017(E)

explicit valarray(size_t n);

Effects: Constructs a valarray that has length n. Each element of the array is value-initialized (11.6).

valarray(const T& v, size_t n);

Effects: Constructs a valarray that has length n. Each element of the array is initialized with v.

valarray(const T* p, size_t n);

Requires: p points to an array (11.3.4) of at least n elements.

Effects: Constructs a valarray that has length n. Each element of the array is initialized with the first n values pointed to by the first argument.

valarray(const valarray& v);

Effects: Constructs a valarray that has the same length as v. The elements are initialized with the values of the corresponding elements of v.

valarray(valarray&& v) noexcept;

Effects: Constructs a valarray that has the same length as v. The elements are initialized with the values of the corresponding elements of v.

Complexity: Constant.

```cpp
valarray(initializer_list<T> il);
```

Effects: Equivalent to valarray(il.begin(), il.size()).

```cpp
valarray(const slice_array<T>);
valarray(const gslice_array<T>);
valarray(const mask_array<T>);
valarray(const indirect_array<T>);
```

These constructors convert one of the four reference templates to a valarray.

```cpp
~valarray();
```

Effects: The destructor is applied to every element *this; an implementation may return all allocated memory.

# 29.7.2.3 valarray assignment [valarray.assign]

```cpp
valarray& operator=(const valarray& v);
```

- 1 Effects: Each element of *this is assigned the value of the corresponding element of v. The length of v is not equal to the length of *this; resizes *this to make the two arrays the same length, if by calling resize(v.size()); before performing the assignment.
- 2 Postconditions: size() == v.size().
- 3 Returns: *this.

```cpp
valarray& operator=(valarray&& v) noexcept;
```

- 4 Effects: this obtains the value of v. The value of v after the assignment is not specified.
- 5 Returns: *this.
- 6 Complexity: Linear.

> 278 This copy constructor is the preferred method for converting a C to a valarray rather than an alias. Implementations in which arrays share storage are permitted, but they must implement a copy-on-reference mechanism to ensure that arrays are conceptually distinct.

> 279 This copy constructor creates a distinct array rather than an alias.

```cpp
valarray&& operator=(initializer_list<T> il);
```

- 7 Effects: Equivalent to return *this = valarray(il);

```cpp
valarray&& operator=(const T& v);
```

- 8 Effects: Assigns v to each element of *this.
- 9 Returns: *this.

```cpp
valarray&& operator=(const slice_array<T>& s);
valarray&& operator=(const gslice_array<T>& g);
valarray&& operator=(const mask_array<T>& m);
```

- 10 Requires: The length of the array to which the assignment equals size(). The value of an element in the left-hand side of a valarray assignment operator does not depend on the value of another element in that left-hand side.
- 11 operators allow the results of a generalized assignment operator to be assigned directly to a valarray.

# 29.7.2.4 valarray element access [valarray.access]

```cpp
const T& operator[](size_t n) const;
T& operator[](size_t n);
```

- 1 Requires: n < size().
- 2 Returns: A reference to the corresponding element of the array. [Note: the expression a[i] = q, a[i] evaluat to true for any non-constant valarray<T>, any q, and for any size_t i where the value of i is less than the length of a. — end note]
- 3 Remarks: The expression a[i+j] = a[i] + b[j] evaluates to true for all size_t i and size_t j where i+j < a.size(). [Note: This property indicates an absence of aliasing and may be used by optimizing compilers. Inlining, constant propagation, tracking of pointers obtained from operator new, and other techniques to generate efficient valarrays.— end note]
- 4 The expression a[i] == &b[j] evaluates to true for any two arrays a and b and for size_t i and size_t j where i < a.size() and j < b.size(). This absence of aliasing may be used to advantage by optimizing compilers.
- 5 Returns the reference to the subscript array which is valid until the member function resize(size_t, T) [29.7.2.8] is called for the array or until the lifetime of array ends, whichever happens first.

# 29.7.2.5 valarray subset operations [valarray.sub]

- 1 member operator[] is overloaded to provide several ways to select sequences of elements from those constrained by *this. Each of these operations returns a subset of the array. The const-qualified versions return this subset as a new valarray. The const template object that has references to the original array, working in conjunction with other operators to allow selective reference (slicing) of the controlled sequence. In each case the selected element should exist.
```cpp
const valarray& operator[](slice slice) const;
```
- 2 Returns: A valarray containing the elements designated by slice. Example:
```cpp
const valarray<char> v0("abcdefijklmnop", 16);
v0[slice(2, 5, 3)] returns valarray<char>("cdef");
```

```cpp
valarray operator[](slice slice);
```

Returns: An object that holds references to elements selected by slice. Example:
```cpp
const valarray<char> v0("abcdefijklmnop", 16);
valarray<char> v1("ABCDE", 5);
v0[slice(2, 5, 3)] = v1; returns valarray<char>("AdeFghjn");
```

```cpp
valarray operator[](const gslice& slicearr) const;
```

Returns: A valarray containing those elements designated by gslice. Example:
```cpp
const valarray<char> v0("abcdefijklmnop", 16);
const size_t lv = { 2, 3 };
const size_t dv = { 7, 2 };
const valarray<size_t> len(lv, 2), str(dv, 2);
v0[slice(3, len, str)] returns valarray<char>("abcAErgijDEnF");
```

```cpp
valarray operator[](const gslice& slicearr) const;
```

Returns: A valarray containing those elements designated by gslice. Example:
```cpp
const valarray<char> v0("abcdefijklmnop", 16);
valarray<char> v1("ABCDE", 6);
const bool vb[] = { false, false, true, true, false, true };
v0[valarray(vb, 6)] = v1; returns valarray<char>("abCghijklmnop");
```

```cpp
valarray operator[](const valarray<size_t>& indarr) const;
```

Returns: A valarray containing those elements designated by indarr. Example:
```cpp
const valarray<char> v0("abcdefijklmnop", 16);
const size_t v1[] = { 7, 5, 2, 3, 8};
v0[valarray<size_t>(v1, 5)] returns valarray<char>("hfcdci");
```

```cpp
indirect_array<T> operator[](const valarray<size_t>& indarr) const;
```

Returns: An object that holds references to elements selected by indarr. Example:
```cpp
const valarray<char> v0("abcdefijklmnop", 16);
valarray<char> v1[] = "ABCDE";
const size_t v1[] = { 7, 5, 2, 3, 8};
v0[valarray<size_t>(v1, 5)] = v1; returns valarray<char>("abCdEghijklmnop");
```

# 29.7.2.6 vararray unary operators

```cpp
valarray operator() const;
valarray operator() const;
valarray operator() const;
valarray operator!() const;
```

- Requires: Each of these operators may only be instantiated for a type T to which the indicated operator can be applied and for which the indicated operator returns a value which is of type T (bool for operator!) or which may be unambiguously converted to type T (bool for operator!). Each element of the result of applying the indicated operator to the corresponding element of the array.
- Returns: A valarray whose length is size(T). Each of the returned array is initialized with the result of applying the indicated operator to the corresponding element of the array.

# 29.7.2.7 vararray compound assignment

```cpp
valarray operator*=(const valarray v);
valarray operator/=(const valarray v);
valarray operator*=(const valarray v);
valarray operator+=(const valarray v);
valarray operator-=(const valarray v);
valarray operator*=(const valarray v);
valarray operator+=(const valarray v);
valarray operator<<=(const valarray v);
valarray operator>>=(const valarray v);
```

- Requires: size() == v.size(). Each of these operators may only be instantiated for a type T if the indicated operator can be applied to two operands of type T. The value of the left-hand side of a vararray compound assignment operator does not depend on the value of another element in that left side.
