# 11.3.6 Default arguments [dlcl.ft.default]

If an initializer-clause is specified in a parameter-declaration this initializer-clause is used as a default argument. Default arguments will be used in cases where trailing arguments are missing.

[Example: The declaration
void point(int = 3, int = 4);
declares a function that can be called with zero, one, or two arguments of type int. It can be called in part of these ways:
point(1,2); point(1);
The last two are equivalent to point(1,4) and point(3,4). — end example

A default argument should be specified only in the parameter-declaration-clause of a function declaration or lambda-expression. In the latter case, the initializer-clause shall be an assignment-expression. A default argument shall not be specified for a parameter pack. If it is specified in a parameter-declaration-clause, it shall not occur within a declarator or abstract-declarator of a parameter-declaration.

For template functions, default arguments can be added in later declarations of a function in the same scope. Declarations in different scopes have completely distinct sets of default arguments. That is, declarations in inner scopes do not acquire default arguments from declarations in outer scopes, and vice versa. In a given declaration, each parameter subsequent to a function with a default argument must have a default supplied in this or a previous declaration or be a function parameter pack. A default argument shall not be redefined by a later declaration (not even to the same value). [Example:

```
void g(int = 0, ...);
// OK, ellipsis is not a parameter so it can follow
void point(int, int);
// parameter with a default argument
void f(int = 7);
void h() {
    f(3);
}
// OK, f(3,3)
```

+   102 This means that default arguments cannot appear, for example, in declarations of pointers to functions, references to functions, or typedef declarations.
