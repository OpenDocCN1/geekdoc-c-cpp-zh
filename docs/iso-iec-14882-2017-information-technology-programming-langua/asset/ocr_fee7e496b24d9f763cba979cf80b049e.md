# # 21 Language support library [language.support]

# ## 21.1 General [support.general]

+   1 This Class describes the function signatures that are called implicitly, and the types of objects generated implicitly, during the execution of C++ programs. It also describes the headers that declare these function signatures and define any related types.

+   2 The following subclasses describe common type definitions used throughout the library, characteristics of the predefined types, functions starting and termination of a C++ program, support for dynamic memory management, support for exception processing, support for initializer lists, and other runtime support, as summarized in Table 32.

Table 32 — Language support library summary
| Subclass | Header(s) |
| :--- | :--- |
| 21.2 | Common definitions | <cstddef>, <cstdlibdef> |
| 21.3 | Implementation properties | <limits>, <cfloat> |
| 21.4 | Integer types | <cctype> |
| 21.5 | Start and termination | <cstdlibdef> |
| 21.6 | Dynamic memory management | <new> |
| 21.7 | Type identification | <typeinfo> |
| 21.8 | Exception handling | <exception> |
| 21.9 | Initializer lists | <initializer_list> |
| 21.10 | Other runtime support | <csignal>, <ctimearg>, <cstdlib> |
