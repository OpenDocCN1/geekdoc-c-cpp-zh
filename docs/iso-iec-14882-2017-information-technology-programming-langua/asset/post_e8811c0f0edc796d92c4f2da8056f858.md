# 17.8 Function template specializations [temp.fct.spec]

1 A function instantiated from a template is called a function template specialization: so is it an explicit specialization of a function template. Template arguments can be specified when naming the function template specialization, deduced from the context (e.g., deduced from the arguments in a call to the function template specialization, see 17.8.2), or obtained from default template arguments.

2 Each function specialization instantiated from a template has its own copy of any static variable.

```
[Example]
template<class T> void f(T* p) {
    static T;
}

void g(int a, char* b) {
    // calls <int>(int*)
    f(&a);
    f(&b);
    // calls <char>(char**)
}
```

f<int>(int) has a static variable of type int and f(char**) has a static variable of type char. —end example
