# 30.7.5 Rvalue stream insertion [ostream.rvalue]

template <class charT, traits, class T> basic_ostream<charT, traits>& operator<<((basic_ostream<charT, traits>& os, const T& x);

+   1 Effects: As if by: os <<

+   2 Returns: os.

+   3 Remarks: This function shall not participate in overload resolution unless the expression os << x is well-formed.

# 30.7.6 Standard manipulators [std.manip]

+   1 The header <iomanip> defines several functions that support extractors and inserters that alter information maintained by class_base and its derived classes.

```
specified setflags(ios_base::flags mask);
```

+   2 Returns: An object of unspecified type such that if it is an object of type basic<charT, traits> then the expression out << setflags(mask) behaves as if called f(out, mask), or if it is an object of type basic_istream<charT, traits> then the expression in >> setflags(mask) behaves as if called f(in, mask), where the function f is defined as:

```
void f(ios_base&, ios_base::flags mask) {
    // reset specified flags
    str.setflags(base.flags(), mask);
}
```

The expression out << setflags(mask) shall have type basic_ostream<charT, traits>& and value. The expression in >> setflags(mask) shall have type basic_istream<charT, traits>& and in value.

```
specified setflags(ios_base::int);
```
