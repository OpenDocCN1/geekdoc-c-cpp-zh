## 26.4.4 Class template map [map]

### 26.4.4.1 Class template map overview [map.overview]

A map is an associative container that contains unique keys (contains at most one value) and provides retrieval of values of another type T based on the keys. The map classes support bidirectional iterators.

A multiset satisfies all the requirements of a container (26.2), and of an associative container (Table 8). A map also provides most operations described in 26.2.6 for unique keys. This means that a map supports the unique operations in 26.2.6 but not the equality operations. For a map<Key,T>, the key_type is Key and the value_type is pair<const Key,T>. Descriptions are provided here for operations on map that are not described in these tables or for operations
