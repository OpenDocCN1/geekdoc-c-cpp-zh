## 14.3 Friends [class::friend]

1 A friend of a class is a function or class that given permission to use the private and protected member names from the class. A class specifies its friends, if by way of friend declarations. These declarations grant special rights to the friends, but they do not make the nominated friends members of the benefiting class. [Example: The following example illustrates the differences between members and friends:

```
class X {
    int a;
    friend void friend_set(X*, int);
public:
    void member_set(int);
};

void friend_set(X* p, int i) { p->a = i; }
void X::member_set(int i) { a = i; }

void f() {
    X obj;
    friend_set(&obj,10);
    obj.member_set(10);
}
```
— end example

2 Declaring a class to be a friend implies that the names of private and protected members from the class granting friendship can be accessed in the base-specifiers and member declarations of the benefited class. [Example:

```
class A {
    class B { }
    friend class X;
};

struct X : A::B {
    // OK: A::B accessible to friend
    A::B my;
    // OK: A::B accessible to member
    class Y {
        A::B my;
        // OK: A::B accessible to nested member
    };
};
```
— end example [Example:

```
class X {
    enum a = 100;
    friend class Y;
};

class Y {
    int a;
}; // OK, Y is a friend of X
```

3 A friend declaration that does not declare a function shall have one of the following:

- friend elaborated-type-specifier;
- friend simple-type-specifier;
- friend typename-type-specifier; [Note: A friend declaration may be the template-declaration (Clause 17.5).—end note] If the type specifier in a friend declaration designates a (possibly-qualified) class, that class is declared as friend or otherwise; the friend declaration is ignored. [Example:

```
class C;

class X {
    friend C; // OK: class C is a friend
};

class X {
    friend C; // OK: class C is a friend
    friend D; // error: no type D in scope
    friend class D; // OK: elaborated-type-specifier declares class
};

template <typename T> class R {
    friend T; // class C is a friend of R
}; R<int>; // OK: "friend int;" is ignored
// end example
```

4 A function declared in a friend declaration has the linkage of the namespace of which it is a member (6.5). Otherwise, the function retains its linkage (10.1).

5 When a friend declaration refers to an overloaded name or operator, only the function specified by the types becomes a friend. A member function of a class can be a friend of class Y. [Example:

```
class Y {
    friend void X::foo(int); // constructors can be friends
    friend void X::x(char); // constructors can be friends
    friend void X::~X(); // destructors can be friends
};
// end example
```

6 A function can be defined in a friend declaration of a class if only the class is a non-local class (12.4), the function name is unqualified, and the function has namespace scope. [Example:

```
class M {
    friend void f(); // definition of global f, a friend of M
    // not the definition of a member function
};
// — end example
```

7 Such a function is an inline function (10.1.6). A friend function defined in a class is in the (lexical) scope of the class in which it is defined. A friend function defined outside the class is not (6.4.1).

8 No storage-class-specifier appears in the decl-friend-seq of a friend declaration.

9 A name nominated by a friend declaration shall be accessible in the scope of the class containing the friend declaration. The meaning of the friend declaration is same whether the friend declaration appears in the private or public (12.2) portion of the class member-specification.

10 Friendship is neither inherited nor transitive. [Example:

```
class A {
    friend class B;
    int a;
};
class B {
    friend class C;
};
class C {
    void f(A* p) {
        p->a++; // error: C is not a friend of A despite being a friend of B
    }
};
class D : public B {
    void f(A* p) {
        p->a++; // error: D is not a friend of A despite being derived from B
    }
}
// end example
```
