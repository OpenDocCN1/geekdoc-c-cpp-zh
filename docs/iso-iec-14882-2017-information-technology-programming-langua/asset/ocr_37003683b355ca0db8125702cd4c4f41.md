+   2 The class template defines an object that controls conversions between wide string objects of class basic_string<char, char_traits<char>, Wide_alloc> and byte string objects of class basic_string<char, char_traits<char>, Byte_alloc>. The template defines the types wide_string and byte_string as synonyms for these types. Conversion between a sequence of Elements (stored in a wide_string) and multiplicity sequences (stored in a byte_string) is performed by an object of class Codec meets the requirements of the standard-conversion facet codec<Elem, char, mbstate_t>.

+   3 An object of this class template stores:
(3.1) byte_err_string = a byte string to display on errors
(3.2) wide_err_string — a wide string to display on errors
(3.3) cvptr — a pointer to the allocated object (which is free when wstring_count is destroyed)
(3.4) cvstate — a conversion state object
(3.5) cvcount — a conversion count

+   5 Returns: cvcount.

+   6 Effects: The first member function convert the single-element byte sequence to a wide string, The second member function must convert the null-terminated sequence starting at ptr to a wide string. The third member function must convert the sequence stored in a wide string to a wide string. The fourth member function must convert the sequence within the range [first, last) to a wide string.

+   7 In all cases:

+   (7.1) If the cvstate was not constructed with an explicit value, it will be set to its default value (the initial conversion state) before the conversion begins. Otherwise it shall be left unchanged.

+   (7.2) The number of elements successfully converted is stored in cvcount.

+   8 Returns: If no conversion error occurs, the member function shall return the converted wide string.
