# 29.6.16 Random number distribution requirements [rand.req.dist]

1 A random number distribution (commonly shortened to distribution) d of type D is a function object returning values that are distributed according to an mathematical probability density function p(z) or to an associated discrete probability function P(z). A distribution identifies its associated probability function p(z) or P(z).

2 An associated probability function is typically expressed using externally-supplied quantities as the parameters of the distribution. Distribution parameters are identified in this context by writing, for example, p(a|b) or P[a|b], to name parameters, or by writing, p(z|p) or P(z|p), to denote the distribution's parameters taken as a whole.

3 A D satisfies the requirements of a random number distribution if the expressions shown in Table 105 are valid and have the indicated semantics, and if D and its associated types satisfy all other requirements of this section 29.6.16. In Table and through this section,

+   a) The type is D's associated result_type;

+   b) The type is D's associated param_type;

+   c) d is a value of D, and x and y are (possibly const) values of D;

+   d) gl and lub are values of T respectively corresponding to the greatest lower and the upper bound on the values potentially returned by d's operator(), as determined by the current values of d's parameters;

+   e) p is a (possibly const) value of P;

+   f, g1, and g2 are values of T satisfying the requirements of a random bit generator (29.6.1.3).

+   g) os is an value of the type of some class template specialization basic_ostream<charT, traits>; and is is an value of the type of some class template specialization basic_istream<charT, traits>; where charT and traits are constrained according to Clauses 24 and 30.
