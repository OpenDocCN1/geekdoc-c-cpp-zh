# 25.6.4 Class template unordered_map

25.6.4.1 Class template unordered_map overview

> An unordered_map is an unordered associative container that supports unique keys (an unordered_map contains at most one of each value) and associates values of another type mapped_type with the keys. The unordered_map supports forward iterators.

> An unordered_map satisfies all the requirements of a container, of an unordered associative container, and of an allocator-aware container (Table 86). It provides the operations described in the preceding requirements for unique keys; that is, unordered_map supports the u_unique operations in that, not the a_eq operations. For unordered_map<Key, T>, the key type is Key, the mapped type is T, and the value type is pair<Key, T>.
