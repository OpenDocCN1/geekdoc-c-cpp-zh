## 12.4 Local class declarations [class.local]

- 1 A class can be declared within a function definition; such a class is called a local class. The name of a local class is local to its enclosing scope. The local class is in the scope of the enclosing scope, and has the same access to non-static variables as the enclosing function does. Declarations in a local class shall not od-use (6.2) a variable with automatic storage from an enclosing scope. — Example:

```
int x;
void f() {
static int s;
int x;
const int N = 5;
extern q();

struct local {
int g() { return x; } // od-use of automatic variable x
int h() { return s; } // OK
int k() { return q(); } // OK
int l() { return q(); } // OK
int m() { return N; } // OK: not od-use
int* o() { return N; } // od-use of automatic variable N
}

local* p = 0; // local: not in scope
 — end example
```

- 2 An enclosing function has no access to members of the local class; it obeys the access rules (Clause 14). Member functions of a local class shall be defined within their definition, if they are defined at all.

- 3 If X is a local nested class Y may be declared in class X and later defined in the definition of class X or later defined in the same scope as the definition of class X. A class nested within a local class is a local class.

- 4 A local class shall not have static data members.

## Multiple base classes [class.mi]

- 1 A class can be derived from any number of base classes. [Note: The use of more than one direct base class is called inheritance. — end note]: [Example]:

```
class A { /* ... };
class B { /* ... };
class C { /* ... };
class D : public A, public B, public C { /* ... }; [Note: The order of derivation is not significant except as specified by the semantics of initialization by constructor (15.6), cleanup (15.4), and storage layout (12.2, 14.1). — end note]

- 3 A class shall not be specified as a direct base of a derived class more than once. [Note: A class can be an indirect base more than once and can be a direct and an indirect base. There are limited things that can be done with such a class. The non-static data members and member functions of the direct base cannot be referred to in the scope of the derived class. However, the static members, enumerations types cannot be referred to. — end note]: [Example]:

```
class X { /* ... };
class Y : public X, public X { /* ... }; // ill-formed

```

- 4 A base classifier that does not contain the keyword virtual specifies a non-virtual base. A base classifier that contains the keyword virtual specifies a virtual base. For each distinct occurrence of a non-virtual base class in the class lattice of the most derived, the most derived class (4.5) shall contain the corresponding base class subobject of that type. For each distinct base class virtual, the most derived class shall contain a single base class subobject of that type.
