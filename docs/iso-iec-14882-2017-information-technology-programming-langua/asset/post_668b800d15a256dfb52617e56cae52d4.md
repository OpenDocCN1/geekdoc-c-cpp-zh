Two unordered containers a and b compare equal if a.size() == b.size(), and for every-container group [Ea, Ea] obtained from a.equal_range(a), there exists an equivalent-container group [Eb1, Eb2] obtained from b.equal_range(b), such that ispermutation(Ea, Eb1, Eb2) returns true. For unordered_value_type, the complexity of operator== (the number of calls to the operator== of value returned by a(), and the hash function returned by a()) is proportional to N in the average case and to N² in the worst case, where N is a.size(). For unordered_map and unordered_multimap, the complexity of operator== is proportional to Σ Ei in the average case and to N², where Ei is the size of the ith-container group in a. ## 26.2.7 Exception safety

- 1 For unordered containers, clear(k) does not throw an exception, unless exception is thrown by the container's Hash or Pred object (if any).
- 2 For unordered containers, if an exception is thrown by any operation other than the container's hash function from within insert or erase a single element, the insertion has no effect.
- 3 For unordered containers, swap throws an exception unless exception is thrown by the container's Hash or Pred object (if any).
- 4 For unordered containers, if an exception is thrown from within rehash(n) function other than the container's hash function or comparison function, the rehash(n) function has no effect.

## 26.3 Sequence containers

- 1 The headers <array>, <deque>, <forward_list>, and <vector> define class templates that meet the requirements for sequence containers.
- 2 Equality comparison is of partitioning if no objects that compare equal fall into different partitions

## 26.3.2 Header <array>

```cpp
#include <initializer_list>

namespace std {
  // 26.3.7, class, template array
  template<class T, size_t N> struct array {
    template<class T, size_t N>
    bool operator=(const array<T, N>& x, const array<T, N>& y);
    template<class T, size_t N>
    bool operator*=(const array<T, N>& x, const array<T, N>& y);
    template<class T, size_t N>
    bool operator+=(const array<T, N>& x, const array<T, N>& y);
    template<class T, size_t N>
    bool operator-=(const array<T, N>& x, const array<T, N>& y);
    template<class T, size_t N>
    bool operator<=(const array<T, N>& x, const array<T, N>& y);
    template<class T, size_t N>
    void swap(array<T, N>& x, array<T, N>& y) noexcept(noexcept(x, y));
  };

  template<class T, size_t N> struct class_type {
    template<class T, size_t N> class tuple_element;
    template<class T, size_t N> array_type;
    struct tuple_size<class T, size_t N, array_type>;
    template<class T, size_t N, class T, size_t N> noexcept
    const T get(const array<T, N>& x) noexcept;
    const T& get(const array<T, N>& x) noexcept;
    template<class T, size_t N, class T, size_t N> noexcept
    const T& get(const array<T, N>& x) noexcept;
    template<class T, size_t N, class T, size_t N> noexcept
    const T& get(const array<T, N>& x) noexcept;
  };
```
