## 17.5.5.3 Members of class template specializations

[temp.class.spec.mfunc] The template parameter list of a class template partial specialization shall match the template parameter list of the class template partial specialization. The template argument of member of a class template partial specialization shall match the template argument list of the class template partial specialization. A class-template specialization is a distinct template. The members of the class template specialization are unrelated to the members of the primary template. Class template partial specialization are used in a way that requires a definition shall be defined; the definitions of members of the primary template are used as definitions for members of a class template partial specialization. An explicit specialization of a member of a class template partial specialization is declared in the same way as an explicit specialization of the primary template. [Example:


## 17.5.6 Function templates

- A function template defines an unbounded set of related functions. [Example: A family of sort functions might be declared like this

```cpp

```

A function template can be overloaded with other function templates and non-template functions (11.3.5).
A non-template function is not related to a function template (i.e., unless it has the same name and type as a potentially generated function template specialization).^{139}
