To prevent respawning the player into a dangerous place on screen (such as right into the path of a projectile) and causing instant death upon respawn, the player is made invulnerable for a few seconds:

```
// we need to be invulnerable for a little while

The player regains its susceptibility to explode projectile in 3 s time, which is done with an Invoke call to MakeVulnerable():

```
