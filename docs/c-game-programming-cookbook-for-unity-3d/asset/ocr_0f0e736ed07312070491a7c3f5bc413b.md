The standard slot weapon controller (as described in Chapter 6) is used by this player. For this weapon controller to work correctly, itsParent variable needs to be set to an empty GameObject named GunMountPoint and the layer of that gameObject to be layer 9, the layer named "enemy projectile." This will ensure that weapons are parented to the right part of the player character and that the projectiles are identified correctly.

Expand the player's GameObject in the Hierarchy window of the Unity editor and you will see a lot of objects in it. As you get deeper into the hierarchy of gameObjects, you will start to expand the bones of the skeleton to the player. Deep under the bip B001 Right Hand is an empty GameObject named GunMountPoint. The GunMountPoint is where weapons will be attached and it will move around the right hand, moving the weapon as though the player character was holding it.

GunMountPoint GameObject is stored in theParent variable of the Standard_SlotWeaponController component attached to the player (see Figure 11.4) and the gameObject that will act as parent to all weapons in the game. By changing its layer, projectiles belong to that layer, too. This is how the game identifies projectiles as the player's and are fired by them.

The variable weaponControl will provide the reference we need to communicate with it, as required:

```
// get a reference to the weapon controller
weaponControl=myGO.GetComponent<Standard_SlotWeaponController>();
```

As discussed in Chapter 3, the player manager deals with all of the data associated with a player. Next in the script, if it does not already have a reference to set, myManager is set up with an instance of BasePlayer for health/damage and scoring. We then set its name with setName() and its health with SetHealth(). The health value is used a little differently than you might think in it is treated more as a lives system than health points. It is set to 3, and each time the player hits a projectile it will be respawned a single health taken away; when there is no health left the game will end:
