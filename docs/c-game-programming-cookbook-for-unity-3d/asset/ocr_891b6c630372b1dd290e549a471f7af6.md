# 11.6.1 Script Breakdown

The player derives from BaseTopDown.cs, which was described back in Chapter 5. The game-specific Player_LBS script adds weapon control, respawning, invulnerability, and a data manager:

```
public class Player_LBS : BaseTopDown
```

Skipping past the variable declarations, we can see that the Init() function comes first. Notice that there is no Start() function attached to this script; expected behavior might be to call the Init() function from Start(), but in this case the player's Init() function will be called from the game controller so there is no need for a Start() function in this class:

```
public override void Init ()
```

Calling base.Init() means that the Init() function in the base class (the one that this script is derived from) will be called. It's a good way to keep all of the setup code from the original function without having to duplicate or override it:

```
base.Init();
```
