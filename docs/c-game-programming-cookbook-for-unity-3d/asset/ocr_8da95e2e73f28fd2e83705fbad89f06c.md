When the player passes by all of the waypoints around the track, the variable isDone is set to true. This Boolean is used when the player hits the trigger on the start/finish line to see whether or not the lap should be increased. Increasing laps in this way (rather than just incrementing the current lap counter at the start/finish line) ensures that the player has driven all the way around the track and crosses the finish line:

public bool IsLapDone() {

RaceFinished() is the function responsible for finding out the player's final race position and telling the player when it is time to stop racing. First, our internal variables are set up for use in other scripts, which is isFinished, race Running, and finalPosition:

```
public void RaceFinished() {
    isFinished=true;
    raceRunning=true;
}
```

finalPosition gets its value by hitting up the GlobalRaceManager for its race position via GetPosition(passing in this player's ID myID):

```
// find out which position we finished in
int finalPosition=
GlobalRaceManager.Instance.GetPosition(myID);
```

To tell the player that the race has finished, this script uses Unity's function GameObject.SendMessageUpwards(). What does this is a message from this script to the gameObject and every ancestor of it. If there is a component script attached to, containing a function naming the message being sent, in case, PlayerFinishedRace(), then it will be called.

This part of the code could have stored a reference to the player's control script directly, but that would mean hard the player script, which reduces the overall flexibility of this script. For example, the player control script for this game is named PlayerController_MVD. The player control script for the example Tank Battle is named PlayerController_TB. If we wanted to make a reference to the player's script for this game, it would need to be in a variable of type PlayerController_MVD, and for the Tank Battle game, would in a variable of a different type: PlayerController_TB. To make this work for both games would mean that we need to create either two separate scripts or two different versions of the script. Instead, SendMessageUpwards() will send out the message to everything without caring about what type of script it is talking to, just in case
