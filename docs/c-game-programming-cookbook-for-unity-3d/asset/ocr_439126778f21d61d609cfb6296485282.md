# # C# GAME PROGRAMMING COOKBOOK for UNITY 3D
Jeff W. Murray

C# Game Programming Cookbook for Unity 3D presents a highly flexible core framework to create just any type of game by plugging in different script components. Most scripts function within the game framework or in your own structures.

The first ten chapters set up the flexible, reusable framework based on C# and suitable for all game types. The book also explains scripting of generic, reusable, and common functionality.

The remainder of the text adds game-specific code to the framework to create four example games: a top-down arcade shooter, a futuristic racing combat game, a tank arena deathmatch game, and a classic arcade-vertical shooting 'em up. The games encompass artificial intelligence (path following, target chasing, and line-of-sight patrolling behaviors), game state control, wheel colliders, and weapon inventory management.

# Features

+   - Provides an industry-level, C#-based framework for many game genres that offers extensibility in any direction you require
- Includes extensive breakdowns of all core scripts, detailing what they do and how they work
- Illustrates common and important programming concepts, as singleton patterned scripts, static variables, and inheritance, in the example games
- Contains useful utility scripts, including a scene loading manager, timer, waypoint manager, spawning, and cameras
- Requires some experience with C# programming
- Offers the Unity 3D game project files on the book's CRC Press web page

Reducing your coding, repurposing, or adaptation time, this book provides script-based components that you can use to jump start your projects. The book's modular components can be mixed and matched to build kinds of video games for the Unity game engine. The techniques and concepts discussed give you a solid foundation in game development.
