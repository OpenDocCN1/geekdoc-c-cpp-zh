To make sure the player is always heading in the right direction along the track, the CheckWrongWay() function uses the waypoint system to look ahead to the next-waypoint and check the angle of the vehicle the ideal angle to reach the waypoint. When the angle goes over a certain threshold (here, it is set to 90), then the wrong-way message is displayed.

First up, the function checks that currentWaypointTransform has something in it. If this reference was at null, it would break the code. Rather than that, the check will return out of the function instead:

```
public void CheckWrongWay()
{
    if (currentWaypointTransform==null)
    return;
}
```

The script will use the waypoint from currentWaypointTransform to check that the vehicle is traveling in the right direction. The first step in doing is to calculate a value, relative to the vehicle, with Transform.InverseTransformPoint(). Essentially, what happens is that the world vector provided by currentWaypointTransform.position is converted to the local space belonging to myTransform(the vehicle), providing relativeTarget with its vector:

```
Vector3 relativeTarget =
myTransform.InverseTransformPoint (currentWaypointTransform.
position;
```

Though a technical description of Mathf.Atan2 would be complicated, is can use here relatively easily; in this code, Atan2 is used to convert the x and z values of the vector relativeTarget into an angle:

```
targetAngle = Mathf.Atan2 (relativeTarget.x,
relativeTarget.z);
```

The result of Mathf.Atan2 will be in radians, so a quick call to Mathf.Rad2Deg is required to convert it to degrees:

```
targetAngle *= Mathf.Rad2Deg;
```

Since relativeTarget was a vector relative to the vehicle, we can assume that the value of targetAngle of 0° will be forwarded along the vehicle's forward axis and that 90°–90° will be out of its right or left. targetAngle now holds the result of how many degrees the vehicle (along its forward vector) is out from facing the waypoint.
