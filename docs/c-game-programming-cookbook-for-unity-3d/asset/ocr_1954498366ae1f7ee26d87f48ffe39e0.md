The UpdateRacerState() function is used to tell all of the drivers when there is
a change in the state of the race running. When it is called, each race control script, from
the HashtableControllers, receives a function call to UpdateRacerState(), passing a in
parameter of raceRunning, the Boolean variable holding a state of whether or not the race
is still running:

```
void UpdateRacerState() {
    for ( int b = 1; b <= numberOfRacers; b++) {
        tempRC = (RaceController)[b];
        tempRC.UpdateRacerState(raceRunning);
    }
}
```
