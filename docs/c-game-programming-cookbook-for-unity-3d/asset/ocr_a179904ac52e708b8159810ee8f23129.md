The global race manager tracks the race state and whether the race is running, but it will also communicate it to each player's race controller. LateUpdate() starts by getting the state of the race from raceControl.raceRunning and storing it into a variable namedRaceRunning:

```
public override void LateUpdate() {
    // get the state of the race from the race controller
    isRaceRunning= raceControl.raceRunning;
```

If the race is running, this function will go on do all the things we need to during the race:

if(isRaceRunning) {
```

We regularly call Check_If_Car_Is_Flipped() to check to see whether the car's rotation is irregular angles, to see whether it has flipped and needs respawning:

```
// check to see if we've crashed and are upside

Check_If_Car_Is_Flipped();

Whenever the race is running on an AI, gunControl should be able to fire, so gun-Control.canControl is set to true:
