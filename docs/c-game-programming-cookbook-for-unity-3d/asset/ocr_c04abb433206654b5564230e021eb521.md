After setting up the GUI and rendering two labels, we move on to the code to render the horizontal slider, which looks like this:

```
audioSFXSliderValue = GUI.HorizontalSlider(new Rect (0, 200, 300, 50 ),naudioSFXSliderValue, 0.0f, 1f);
```

Here, we use the audioSFXSliderValue variable (a float) to return the return value that the GUI.
HorizontalSlider gives back. A slider may take up to five parameters as follows:

+   1. A rectangle defining the size of the area the slider.

+   2. The current value at to render the slider handle. The audioSFXSliderValue variable is used, and it's OK for the GUI.HorizontalSlider to send feedback to use itself, as we set audioSFXSliderValue to the return value of the slider and at the same time we set the value of the handle to the same variable.

+   3. The value at the left end of the slider. Your slider can start anywhere, but in this case, we need it to start at 0.
