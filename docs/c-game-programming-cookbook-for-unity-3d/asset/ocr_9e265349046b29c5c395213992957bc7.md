The default values for the player manager data manager are set up here:

```
// if a player manager is not set in the editor, let's try to find one
if (myPlayerManager==null)
    myPlayerManager=myGO.GetComponent<BasePlayerManager>();

myData=myPlayerManager.DataManager;
myData.SetName("Player");
myData.SetHealth(3);
```

The health system of the data manager is used, but instead of health points, ownerID is used again here to tell the game controller which part of the UI (either player 1 or player 2) to update with this player's default number of lives:

```
// update UI lives
if (ownerID==1)
{
    // our owner ID is 1, we must be player 1
    GameController_IP.Instance.UpdateLivesP1(myData.GetHealth());
} else
{
    // we are player 2, so that we instead
    GameController_IP.Instance.UpdateLivesP2(myData.GetHealth());
}
```

Setting the isControlled variable to true will add a new script component from the script Mouse_Input.cs to be used as input for this player:

```
if (isControlled)
{
    // we are going to use mouse controls, add a mouse input
    // controller
    mouse_input=gameObject.AddComponent<Mouse_Input>();
}
```

With Init() all, the didInit Boolean variable is set to true. Other functions will refer to this to check that the player has been set up before trying to manipulate it in ways that might otherwise cause errors or problems:

```
didInit=true;
```
