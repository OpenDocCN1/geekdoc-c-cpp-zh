Once the GUI.matrix is set, everything we draw in the OnGUI function will be scaled accordingly so we can go and start drawing the menus.

To set a skin, we need to tell Unity about it in the OnGUI function. You can use as many different skins as you like, changing/setting the skin is as easy

```
// set the GUI skin to use our custom menu skin
GUI.skin=menuSkin;
```

In our UI function, menuSkin is a public variable so that we can set the GUI skin value in the Inspector window of the editor.

To help us to position the menu and for the most flexibility, we will render it within a group. Using a group is similar to drawing the UI inside a window, which can be moved around its contents keeping the same layout. The coordinate system for the GUI contents within the group starts at 0,0 in the top left of the group and remains unaffected by screen positioning (which continues to be determined by the group rather than by its content).

```
GUI.BeginGroup(new Rect (default_width / 2 - 150, height / 2 - 250, 500, 500));
```

Putting content into a group is simple. Using GUI.BeginGroup() within an OnGUI function to start the content and GUI.EndGroup() once the content is complete.

```
GUI.Label(new Rect (0, 50, 30, 50 ), displayName="textarea");
```

One way to get text onto the screen is to use UILabel. In the line above, we define a rectangle where we are going to render (keep in mind that this is happening within a group, so the coordinate system starts at 0 top left of the group). This is the name of the game, we are using a string to hold the game name called gameDisplayName. A public string in this way means we can change the game name in the Unity editor's Inspector window without having to edit the script.

The final part of the GUI.Label line is a GUI. This is just a string that refers to a style defined in GUISkin. In this case, it's the style "textarea", and it makes sure when this text is rendered that it uses the correct font, size, and text alignment.
