# ### 3.3.1 Script Breakdown

There is nothing particularly outstanding about the start of the script—Awake() function calls Init() after setting the didInit Boolean to false:

```
public class BasePlayerManager : MonoBehaviour
{
    public bool didInit;

    // the user manager and AI controllers are publicly accessible so
    // that our individual control scripts can access them easily
    public BaseUserManager DataManager;

    // note that we initialize on Awake in this class so that it is
    // ready for other classes to access our details when they
    // initialize on Start
    public virtual void Awake()
    {
        didInit=false;
        Init();
    }
```
