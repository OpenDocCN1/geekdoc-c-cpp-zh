Along the way, doubts may set in as to whether or not things are working as they should with the AI—the function includes some.DrawRay calls that will make lines appear in the editor where the rays are being cast. This will only happen in the editor when Gizmos are set to true (use the Gizmos icon above the window to this):

```
// this draw raycast so we can see what it is doing
Debug.DrawRay(myTransform.position, myTransform.forward + 
(myTransform.right * 0.5f), wallAvoidDistance);
Debug.DrawRay(myTransform.position, myTransform.forward + 
(myTransform.right * -0.5f), wallAvoidDistance);
```

The actual raycasting happens next, using the AI's forward vector—myTransform—with an offset to the side—myTransform multiplied by half so that the angle goes diagonally out from the bot—with the ray starting at myTransform.position.
The Physics.Raycast function is used here as follows:

bool Physics.Raycast( Vector3 origin, Vector3 direction, RayCastHit hitInfo, out distance)

The variable wallAvoidDistance is used as the distance parameter for raycasting, which may be set in the Unity Inspector window. When the AI moves faster, it will usually help the patrolling if this value is higher as the bot can look ahead for obstacles.
 a call to Physics.Raycast finds something, it will return true, meaning we can easily use it in an statement:

```
// cast a ray out from our AI and put the 'result'
// into the variable named hit

forward + (myTransform.right * 0.5f), out hit,
```
