The first player object added to the list of players in the Unity editor Inspector needs to be the main player, in gaming terms we call this "player one". When players are generated, the SpawnController stores their objects in an array so they can be accessed later, from other scripts. Access to the array is provided by the function GetPlayerGO(index number). Here, we call upon the SpawnController to return the main player object to be stored in playerGO1:

```
// grab a reference to player's gameObject for later
playerGO0 = SpawnController.Instance.GetPlayerGO( 0 );
```

GetComponent() is used to grab a reference to the main player's controller script, which is stored in the variable named thePlayerScript:

The next line assigns an ID number to the player, used later to identify the origin of projectiles:

```
// assign this player the id of 0
thePlayerScript.SetID( 0 );
```

To allow control of the main player by the user, SetUserInput is called. We also keep a reference to this player script in the variable focusPlayerScript, since it is the player that the game controller will be focused when providing data to the UI and the camera that needs to focus on:

```
// set player control
thePlayerScript.SetInput( true);

// as this is the user, we want to focus on this for UI etc.
focusPlayerScript = thePlayerScript;
```
