With all the other games, the SpawnControllerSetUpPlayers() function is
used to instantiate players into the game. It requires an array of positions and an array of
rotations, which are made here. This game only has a single start point and an array of
start points as other games might have, but it uses the same system purely for the sake
of consistency throughout the book. Of course, if you are the reader who is going to take
this game and add 50 players to it, then is no doubt, going to be useful to have:

```
for(int i=0; i<totalPlayers; i++)
{
    tempQuat= Quaternion.identity;

    if(i=0)
    {
        // place player 1 at the default start position of
        //-5,0,0
        tempVec3= new Vector3(-5, 0, 0);
    }
    else {
        // we will player 2 a start position 5 units to
        // the right of the start position of player 1
        tempVec3= new Vector3(-5 + (i*5), 0, 0);
    }
    playerStarts[i]=tempVec3;
    playerRotations[i]=tempQuat;
}
```
