weaponController.NextWeaponSlot() tells the controller to move to the next slot:

```csharp
void OnTriggerEnter(Collider other)
{
    if (other.gameObject.layer==12 )
    {
        // tell our sound controller to play a powerup sound
        BaseSoundController.Instance.PlaySoundByIndex( 3,
        myTransform.position );

        // hit a powerup trigger
        Destroy (other.gameObject);

        // advance to the next weapon
        weaponControl.NextWeaponSlot( false);
    }
}
```

The respawning process takes a little time, so isRespawning is a Boolean to ensure that it does not try to respawn more than once at the same time:

```csharp
isRespawning=true;

The game controller's PlayerHit() function will make a nice explosion effect at the position of the transform passed into it:

```csharp
// blow us up!
GameController_IP.Instance.PlayerHit ( myTransform );
```

This player's data manager tracks health levels. myDataManager.ReduceHealth() takes a single integer parameter of how much health should be reduced. In this game, the health level is treated as lives, so it is called to take away one life here:

```csharp
// reduce lives by one
myDataManager.ReduceHealth(1);
```

The game controller is called on to update the UI, either UpdateLivesP1() or UpdateLivesP2(), depending on the ownerID for this player:

```csharp
// update UI lives
if ( ownerID==1 )
{
    // as our ID is 1, we must be player 1
    GameController_IP.Instance.UpdateLivesP1( myDataManager.GetHealth());
} else {
    // as our ID is 2, we must be player 2
    GameController_IP.Instance.UpdateLivesP2( myDataManager.GetHealth());
}
```

When this player's health level is less than 1, it is game over for this player:

```csharp
if(myDataManager.GetHealth()<1) // - game over
{}
```

Reaching the else of this condition means that the player just needs to be respawned and that it has more than 1 life remaining. The player model is hidden with GameObject.SetActive():

```csharp
// hide body
theMeshGO.SetActive(false);
```

The weapon is disabled (it will be re-enabled when the player is respawned):

```csharp
// disable and hide weapon
weaponControl.DisableCurrentWeapon();
```

Finally, a call to the Respawn() function of this class is scheduled to happen 2 s from now via Unity's Invoke():

```csharp
// respawn
Invoke("Respawn", 2f);
}

After the player has been destroyed by an enemy projectile, it is hidden from view and its collisions ignored. The Respawn() function resets the player state back to operational:

```csharp
void Respawn()
{
```

By the end of this function call, the player will have respawned, which means IsRespawning is now to be set to false:

```csharp
// reset the 'we are respawning' variable
isRespawning= false;
```

To prevent respawning the player into a dangerous place on screen (such as right into the path of a projectile) and causing instant death upon respawn, the player is made invulnerable for a few seconds:

```csharp
// we need to be invulnerable for a little while
MakeInvulnerable();
```

The player regains its susceptibility to explode projectile in 3 s time, which is done with an Invoke call to MakeVulnerable():

```csharp
Invoke("MakeVulnerable", 3);
```

The player's spaceship body is set active, effectively displaying it again, here:

```csharp
// show ship body again
thisMesh.SetActive(true);
```

Any power-ups are lost on respawn by setting the weapon slot back to the beginning. If you wanted to keep power-ups even after a life is lost, you could comment this line out or perhaps replace it with weaponControl.PrevWeaponSlot() to downgrade the weapon to the previous slot rather than reset it all the way back to the beginning:

```csharp
// revert to the first weapon
weaponControl.SetWeaponSlot(0);
```

The EnableCurrentWeapon() function on weaponControl will make sure that the weapon is displayed correctly after it is re-enabled:

```csharp
// show the current weapon (since it was hidden when it was re-enabled)
weaponControl.EnableCurrentWeapon();
```

The Invulnerable() and MakeVulnerable() functions set the shield accordingly:

```csharp
void Invulnerable()
{
    isInvulnerable = true;
    shield.SetActive(true);
}

void MakeVulnerable()
{
    isInvulnerable = false;
    shield.SetActive(false);
}
```

The only thing left when the player has out of life is to tell the game controller. This is handled in the Enemy_IP script.
