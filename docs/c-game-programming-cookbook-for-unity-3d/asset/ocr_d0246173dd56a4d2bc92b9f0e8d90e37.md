The FireProjectile() function is where the projectile gets instantiated. It was called by that function, Fire():

```
public virtual void FireProjectile( Vector3 fireDirection, int
ownerID )
{
```

The function MakeProjectile will do the work in getting a projectile into the scene, but returns a transform that this function can use to set up:

```
// make our first projectile
theProjectile= MakeProjectile( ownerID );
```

Now the FireProjectile contains a transform; the code uses the Transform.LookAt() function to align it along the target trajectory passed in the parameter fireDirection. Since LookAt() requires a position vector (as opposed to a direction vector), it takes the projectile's current position from FireProjectile.position and adds the direction vector to it. This will adjust the new projectile's rotation so that its z-axis is facing in the required direction of travel:

```
// direct the projectile toward the direction of fire
theProjectile.LookAt( theProjectile.position + fireDirection );
```

To send the projectile on its way, the projectile's rigidbody has its velocity set to the required direction multiplied by projectileSpeed.
