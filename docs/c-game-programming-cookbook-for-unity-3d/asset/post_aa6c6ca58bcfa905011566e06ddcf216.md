// store this object in our list of objects

For occasions where it is preferable to return a newly instantiated object's gameObject rather than the transform, the SpawnGO (GO going short for GameObject) function is available. It works exactly the same as the Spawn function, but instead of returning the newly instantiated object's transform, it returns its gameObject.

```cs
// here just provide a convenient function to return the spawned
// objects' gameObject rather than its transform
public GameObject SpawnGO(GameObject anObject, Vector3 aPosition,
Quaternion aRotation)
{
    if (objectList == null)
        objectList = new ArrayList();

    // instantiate the object
    tempGO = (GameObject) Instantiate(anObject, aPosition, aRotation);
    tempTrans = tempGO.transform;

    // store this object in our list of objects
    objectList.Add(tempTrans);

    // return the object to whatever was calling
    return tempGO;
}
```

The SpawnController.cs script track every object that it has created. Each one is stored in the array (Array List type variable) named objectList. To have SpawnController.cs return the whole list, the function GetAllSpawnedTransforms() is provided.

## 4.3.2 Trigger Spawner

The TriggerSpawner.cs script instantiates an object when another object enters the trigger to which the script is attached. One use for this script would be to spawn an enemy when the player reaches a particular area in a level:

```cs
public class TriggerSpawner : MonoBehaviour
{
    public GameObject ObjectToSpawnOnTrigger;
    public Vector3 offsetPosition;
    public bool onlySpawnOnce;
    public int layerToCauseTriggerHit = 13; // this should be set to the
    // number of the camera layer

    private Transform myTransform;

    void Start()
    {
        Vector3 tempPos = transform.position;
        tempPos.y = Camera.main.transform.position.y;
        transform.position = tempPos;

        // cache transform
        myTransform = transform;
    }

    void OnTriggerEnter(Collider other)
    {
        // make sure that the layer of the object entering we
        // trigger is the one to cause the boss to spawn
        if (other.gameObject.layer != layerToCauseTriggerHit)
            return;

        // instantiate the object to spawn on trigger enter
        Instantiate(ObjectToSpawnOnTrigger, myTransform.position + offsetPosition, Quaternion.identity);

        // if we are to only spawn once, destroy this gameobject
        // after spawn occurs
        if (onlySpawnOnce)
            Destroy(gameObject);
    }
}
```

### 4.3.3 Path Spawner

This script fulfils a specific need, albeit one that may crop frequently in game development. The path spawner makes a new object appear in the game and tells its waypoint-following code to follow (which waypoint controller script to use for finding waypoints).

In the example game Interstellar Paranoids from Chapter 14, it is used for the path-following enemies in each level. Pathways are stored in prefabs, which may be dragged into each scene to build levels. The Path_Spawner.cs script component is attached to the parent GameObject in the path prefabs, identifying which enemies to spawn, and then as they are spawned, telling them to use the waypoint path from the prefab.

## 4.3 Spawn Scripts

With a path spawner system, the enemies never need to have any path names or waypoint objects hard-coded—them it can create and guide any enemy capable of following a path.

The prefabs/objects to spawn are stored in an array called spawnObjectPrefabs. This array can be as small or large as you like—if there is more than one, timeBetweenSpawners will schedule each one after the other.

There are two ways this script will begin to spawn objects from the spawnObjectPrefabs list. One is to set the shouldAutoStartSpawningOn variable to true, and the other is to use a trigger system based on the position of the camera. In the example Interstellar Paranoids, the trigger system is used so that enemies do not appear until the camera (and with the player) are within range.

Below is the Path_Spawner.cs script in full:

```cs
public class Path_Spawner : MonoBehaviour
{
    public Waypoints ControllerControl;

    // should we start spawning based on distance from the camera?
    // if distanceBased is false, we will need to call this class from
    // elsewhere, to spawn
    public bool distanceBasedSpawnStart;
    // if we're using distance based spawning, at what distance
    // we start?
    public float distanceFromCameraToSpawnAt = 35f;

    // if the distanceBasedSpawnStart is false, we can have the path
    // spawner just start spawning automatically
    public bool shouldAutoStartSpawningOnLoad;

    public float timeBetweenSpawns = 1;
    public int totalAmountSpawn = 10;
    public bool shouldReversePath;

    public GameObject[] spawnObjectPrefabs;

    private int totalSpawnObjects;

    private Transform myTransform;
    private GameObject tempObj;

    private int spawnCounter = 0;
    private int currentObjectNum;
    private Transform cameraTransform;
    private bool boolSpawner;

    public bool shouldSetSpeed;
    public float speedToSet;

    public bool shouldSetSmoothing;
    public float smoothingToSet;

    public bool shouldSetRotate;
    public float rotateToSet;

    private bool shouldAutoStartSpawningOn;
    private bool spawning;

    void Start()
    {
        Init();
    }

    void Init()
    {
        myTransform = transform;
        cameraTransform = Camera.main;

        if (cameraTransform == null)
            return;

        totalSpawnObjects = spawnObjectPrefabs.Length;

        if (shouldAutoStartSpawningOnLoad)
        {
            spawning = true;
            InvokeRepeating("doSpawn", 0, timeBetweenSpawns);
        }
    }

    void Update()
    {
        if (spawning && !shouldAutoStartSpawningOnLoad)
            return;

        float aDist = Vector3.Distance(transform.position, cameraTransform.position);
        if (distanceBasedSpawnStart && aDist < distanceFromCameraToSpawnAt)
        {
            spawning = true;
            InvokeRepeating("doSpawn", 0, timeBetweenSpawns);
        }
    }

    void doSpawn()
    {
        SpawnObject();
    }

    void SpawnObject()
    {
        if (spawnCounter >= totalAmountSpawn)
        {
            CancelInvoke("doSpawn");
            spawning = false;
            return;
        }

        tempObj = Instantiate(spawnObjectPrefabs[currentObjectNum], myTransform.position, Quaternion.identity);

        if (shouldReversePath)
        {
            tempObj.SendMessage("SetReversePath", true);
        }

        if (ControllerControl != null)
        {
            tempObj.SendMessage("SetWayController", ControllerControl);
        }

        if (shouldSetSpeed)
        {
            tempObj.SendMessage("SetSpeed", speedToSet);
        }

        if (shouldSetSmoothing)
        {
            tempObj.SendMessage("SetSmoothingRate", smoothingToSet);
        }

        if (shouldSetRotate)
        {
            tempObj.SendMessage("SetRotateSpeed", rotateToSet);
        }

        spawnCounter++;
        if (currentObjectNum > totalSpawnObjects - 1)
        {
            currentObjectNum = 0;
        }
    }

    private void OnDrawmosSelected()
    {
        Gizmos.color = new Color(0, 1, 0, 0.5f);
        Gizmos.DrawCube(transform.position, new Vector3(20, 0, 20));
    }
}
```
