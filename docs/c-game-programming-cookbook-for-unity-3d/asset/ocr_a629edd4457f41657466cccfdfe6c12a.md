The GlobalRaceManager manager script instance gets a call to StartRace(), too, so that its race states can get started:

```
void StartRace ()
{
    // the SetPlayerLocks function tells all players to unlock
    SetPlayerLocks (false);

    // tell the global race manager that we are now racing
    GlobalRaceManager.Instance.StartRace();
}
```

A few times by the script already in this section, the SetPlayerLocks tells players whether or not they should be locked in place. As discussed in Chapter 5, when the vehicle controller is outlined, locking the vehicles will constrain their x and z axes but not the y-axis. This is so that the vehicle will still be affected by gravity; it can can look natural at the beginning of the game. If the vehicle's y-axis were locked, the car would sit exactly at its position in the game world resting (which may be slightly above ground or perhaps too low) and not in its resting spot against the ground.

In SetPlayerLocks(), all of the play scripts held in the playerArray are called with the SetLock() function to pass the required state:

```
void SetPlayerLocks ( bool aState )
{
    // tell all of the players to set their locks
    for ( int i = 0; i < numberOfRacers; i++)
{
        thePlayerScript = ( CarController_MVD) playerList
        thePlayerScript.SetLock(aState);
    }
}
```
