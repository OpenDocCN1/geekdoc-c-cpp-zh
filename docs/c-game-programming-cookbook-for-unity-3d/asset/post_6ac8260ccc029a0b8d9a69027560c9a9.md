## 6.1.2.1 Script Breakdown

The BaseWeaponScript class derives from MonoBehavior:

```cs
using UnityEngine;
using System.Collections;

public class BaseWeaponScript : MonoBehaviour
{
    public virtual void Start()
    {
        Init();
    }
}
```

Init() begins grabbing a reference to the transform and the layer at which this gameObject with this script attached to is set. This will be used to disable collisions between the layer of the weapon and the actual projectile so that the projectile does not explode as soon as it is instantiated: Init()

```cs
public virtual void Init()
{
    // cache the transform
    myTransform= transform;

    // cache the layer (we'll set all projectiles to avoid
    // layer in collisions so that things don't
    // themselves!)
    myLayer= gameObject.layer;

    // load the weapon
    Reloaded();
}
```

The Enable() and Disable() functions set the Boolean variable canFire to true and false, respectively. This will be checked elsewhere in the code before allowing any projectile firing. Note that the visual representation of the weapon is not hidden here; that task is left to the slot control script to deal with rather than the weapon itself:

```cs
public virtual void Enable()
{
    canFire=true;
}

public virtual void Disable()
{
    canFire=false;
}
```

When the weapon is fired, the assumption is made that it will not be loaded for a certain period of time (otherwise, you could, in theory, fire thousands of projectiles each second). To keep track of when the weapon is in a loaded state, this script uses the Boolean variable isLoaded. Timed call to the Reloaded() function, after firing, will reset the weapon state again:

```cs
public virtual void Reloaded()
{
    // the 'isLoaded' var tells us if this weapon is loaded and
    // ready to fire
    isLoaded=true;
}
```

Collider() is used to set a collider to be ignored by a projectile. For example, when the script is applied to a player, it should ignore the player's collider so as to prevent the newly created projectile from exploding instantly. It should be set, using the Unity editor Inspector window, to a collider that would likely destroy the projectile as it was spawned. If no parentCollider is, the script will still work, but the projectile will not ignore any collider:

```cs
public virtual void SetCollider( Collider aDecoder)
{
    parentCollider=aCollider;
}
```
