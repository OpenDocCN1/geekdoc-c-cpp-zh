For incidental spawning, such as particle effects, the SpawnController.cs script provides a Spawn() method.
At this stage, you need to understand prefabs, and in turn, how they can be dynamically added to the scene. Turn to the documentation:

+   [Prefabs are] ... a collection of predefinedGameObjects & Components that are re-usable throughout your game.

They are saved into the project, available in the same way regular assets are, and may be dragged into a scene or added dynamically through code using the Instantiate keyword. Instantiate makes a clone of the object you pass in as a parameter and returns a reference to the clone.

Instantiate takes three parameters:

+   object An existing object (such as a prefab or gameObject) to make a copy of

+   position Vector3 for the new object

+   rotation Quaternion for the new object

One important consideration to keep in mind is that there is a CPU hit for instantiation as memory is freed and allocated for it. This is much more noticeable on mobile platforms, particularly those lower performing systems such as older (3–4-year-old) devices. In situations where performance is an issue, it is advisable to use an object pooling system. Test early, and keep an eye out for performance hits like this.
