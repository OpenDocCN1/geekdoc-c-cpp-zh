At low speeds, it is difficult to turn the vehicle quickly. When the user crashes
to a wall, slow turning speed can make the game a very frustrating experience.
The aim of this overridden version of UpdatePhysics() is to add some turn helper
force, to make the vehicle turn at lower speeds so that getting out of a crash may be
ier. It also means that the vehicle can do some run donuts on the track, but that
another story...

Here we check the value of mySpeed (which, of course, holds the player's
movement speed) and see whether it is below the value of TorqueHelperMaxSpeed.
The intention is that its value will be set in the Unity Inspector window. If mySpeed
gre than TorqueHelperMaxSpeed, no helper force will be applied to the vehicle.
