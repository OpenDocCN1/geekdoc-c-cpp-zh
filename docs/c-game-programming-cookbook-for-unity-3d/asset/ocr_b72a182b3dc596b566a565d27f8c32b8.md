The movement of the spaceship is aligned to its transform.localPosition. The reason
for this is, in Interstellar Paranoids, the player is parented to the camera as it makes it
way through the level. We do not want to affect the global position of the ship; it needs to
stay within the coordinate space of the camera to stay on, and only its local position
changed when we move around it:

```
// move our transform to updated position
transform.localPosition += new Vector3(moveXAmount, 0,
moveAmount);
```

Mathf.Clamp is a built-in utility function to take a value and clamp it between
a minimum and a maximum value. When you pass a value into Mathf.Clamp, if it is
than the maximum value, the return value will be the maximum value. If the value
passed in is less than the minimum value, it will return the minimum.
