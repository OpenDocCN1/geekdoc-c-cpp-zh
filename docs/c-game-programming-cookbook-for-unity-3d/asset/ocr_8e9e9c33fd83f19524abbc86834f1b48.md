Like its real-life counterpart, our car uses a steering system to move them left or right. Rather than force the car towards a particular direction, the AIController will supply inputs that our CarController_MVD script can use as though they were user inputs. As you may recall from Chapter 9, the AI system has a specific state for steering inputs based on viewpoints. Here the AIController object is called to set its state to AIStates.AIState.steer_to_waypoint:

```
// tell the AI controller to go into waypoint steering
// mode
AIController.SetAIState(AIStates.AIState.steer_to_waypoint);
```

As this is an AI vehicle, the default input method needs to be disabled (otherwise, the AI may have to fight against the player input):

```
// disable our default method
default_input.enabled=false;
```
