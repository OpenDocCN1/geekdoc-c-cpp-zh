The next step is to find out the relative position of the waypoint from the (myTransform) transform.InverseTransform converts a position from world space into local space. In this case, we take the position of the waypoint and convert it into the local space of myTransform.

The result of the transform.InverseTransformPoint space conversion is stored in a Vector3 type called RelativeWaypointPosition. This vector now represents the direction that the AI would need to reach the next waypoint.

By dividing the x value of RelativeWaypointPosition by its magnitude, we end up with a number that, in layman's terms, says how much we need to turn left or right to be facing the waypoint, a number that is perfect for use as horizontal input to a steering system. The code below places the calculated steer value into the variable (variable name used for horizontal input throughout this book):

```
RelativeWaypointPosition=myTransform;
InverseTransform( currentWaypointPosition;
// by dividing the horz position by the magnitude,
// we get a decimal percentage of the turn angle
// that we can use to drive the wheels
horz=RelativeWaypointPosition.x /\ RelativeWaypointPosition.magnitude);
```

Now that contains the amount required to turn towards the next waypoint, this value may be used to slow down the bot if it is moving too fast.
The absolute (never negative) value of horz is checked against 0.5 to decide whether or not acceleration should be used. If the turn is more than 0.5, acceleration is set to 0. The acceleration into the vert is calculated by taking the RelativeWaypointPosition z divided by its magnitude, the horizontal turn subtracted from it. The idea is, even though the distance to the waypoint along the AI bot's z-axis is taken into account, the more the turn is, the less the acceleration value will be. In many cases, this should help the AI to get around corners without crashing:

```

// it doesn't apply any engine torque when going
// around a sharp turn...

 vert=RelativeWaypointPosition.z /
 RelativeWaypointPosition.magnitude-
Math.Abs ( horz );
}
else{
 NoMove();
}
```
