```
void SavePrefs() {
    PlayerPrefs.SetFloat(gamePrefsName+"_SFXVol",
        audioSFXSliderValue);
    PlayerPrefs.SetFloat(gamePrefsName+"_MusicVol",
        audioMusicSliderValue);
    PlayerPrefs.SetFloat(gamePrefsName+"_GraphicsDetail",
        graphicsSliderValue);

    // set the quality setting
    QualitySettings.SetQualityLevel((int)graphicsSliderValue);
}
```

PlayerPrefs is used to save our settings to disk. The example games in this book use an optional string variable gamePrefsName to attach to the PlayerPrefs key names so that our preferences will be saved individually for each game. This is completely optional—Unity saves preferences on a per-game basis, so your preferences will never be shared across projects. In this case, all of the game examples in this book are saved into a single Unity project, the prefix ensures that each game will save its settings despite them all being lumped into the same preferences files.
QualitySettings.QualityLevel is used to set Unity's quality level. QualitySettings takes an integer number with the second parameter being a Boolean value to set whether or not expensive changes will be applied. These are settings that may cause the game to stall. It may not be a good idea to cause stalling (e.g., where SetQualityLevel is used for real-time quality switching based on frame rate), but in this case, it will have no noticeable impact on the player, so we can go ahead and apply all settings here.

# 10.2 In-Game User Interface

The user interface used for the games in this book is extremely basic but entirely functional. Each script derives from a class called BaseUIDataManager, which declares several common variables and provides some basic functions to deal with them.

| player_score | The player's score |
| player_lives | The amount of health or lives that the player has |
| player_highscore | The highest score achieved in the game so far |
| gamePrefsName | A string to prefix all PlayerPrefs references (see the earlier section in this chapter for a more in-depth discussion on how PlayerPrefs is used) |
