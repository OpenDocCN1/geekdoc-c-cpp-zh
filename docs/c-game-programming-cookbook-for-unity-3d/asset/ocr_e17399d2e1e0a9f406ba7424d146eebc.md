Functions for turning left and right, TurnLeft() and TurnRight(), respectively, are used by the cases for AIState.stopped_turning_left and AIState.stopped_turning_right. The two cases also check obstacleFinderResult to see whether the path ahead is clear. If the path is clear (when obstacleFinderResult contains zero), the state is changed to AIState.
moving_looking_for_target:

