PlayerFinished() lets the player know that it is finished racing. As well as disabling firing with canFire set to false, everything that might drive or steer the player is disabled in this function:

```
public void PlayerFinished()
{
    // disable this vehicle
    isAIControlled = false;
    canControl = false;
    canFire = false;
    AIController.canControl = false;
    motor = 0;
    steer = 0;
}
```

To keep the car upright, Check_If_Car_Is_Flipped() function simply checks the localEulerAngles of the car to see whether its rotations are out of the ordinary. These values are not exactly scientific; the rotation values it checks against were decided by trial and error until it felt right and detected most cases:

```
void Check_If_Car_Is_Flipped()
{
    if((myTransform.localRulerAngles.z > 80 &&

}
```
