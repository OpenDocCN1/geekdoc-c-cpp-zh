
In an attempt to prevent projectiles from colliding with the parent object or with other projectiles spawned closely, `Physics.IgnoreLayerCollision()` is used. `Physics.IgnoreLayerCollision()` takes two numbers (both integers) referring to which layers should ignore colliding with each other. The layer numbers from the Tags and Layers manager accessible via the menu Edit -> Project Settings -> the Unity Editor Inspector by clicking on the layer dropdown and clicking on the Add layer button. This is applied globally, which means that once two layers are on Unity's list, everything placed on those layers will no longer register collisions.

In this case, the first layer is the weapon's layer for `myTransform.gameObject.layer` and the second taken from the variable `myLayer`, which is set in the Init() function of this script:

```
Physics.IgnoreLayerCollision(myTransform.gameObject.layer, myLayer);
```

## 7 Recipe: Waypoints Manager

### 7.1 Waypoint System

Both the racing game Motor Vehicle Doom and the shoot 'em up Interstellar Paranoids will need waypoints for the AI players. In Motor Vehicle Doom, we use waypoints for the AI and also for the main player for the following reasons:

- 1. To check that the main player is heading in the right direction. The car controller code will track the player's position on the track (based on which waypoint has been passed) and check its forward vector to make sure that it is facing the next waypoint along the track. If the player's forward vector is not within a certain tolerance angle, the game will display a wrong way message and eventually respawn the car the right way.
- 2. To enable the respawning system to find a "safe" place along the track to respawn the player as to use its rotation to point the respawned car in the right direction along the track.
- 3. To find out how far the vehicle has traveled around the track, which is used to compare the other players progress amounts to to calculate race positions.

Interstellar Paranoids uses waypoints for moving all of the enemies. Enemies are simple path followers that move along a path firing until they reach the end, where they are destroyed.

            // this one as we need
            lastPos = TempTrans.position;

    {
        // make sure that we have populated the transforms
        // list, if not, populate it
        if(transforms==null)
            GetTransforms();

        // the distance variable is just used to hold the
        // 'current' distance when we are comparing, so that
        // we can find the closest distance = Math.Infinity;

        // Iterate through them and find the closest one
        for (int i = 0; i < transforms.Count; i++)
        {
            // grab a reference to a transform
            Transform TempTrans = (Transform)transforms[i];

            // calculate the distance between the current
            // transform and the passed in transform's
            diff = (TempTrans.position - fromPos);
            float curDistance = diff.sqrMagnitude;
            // now compare distances - making sure that
            // we are not closer than the closest object
            // (whose distance is held by the variable
            // (distance)
            if (curDistance < distance)

                    closest = TempTrans;

                    // waypoint
                    TempIndex=i;

                    // set our 'winning' distance
                    // to the distance we just found
                    // found
                    distance = curDistance;
                }
            }
        }
        return TempIndex;
    }
