In an attempt to prevent projectiles from colliding with the parent object or with other projectiles spawned closely,Physics.IgnoreLayerCollision() is used. Physics.IgnoreLayerCollision() takes two numbers (both integers) referring to which layers should ignore colliding with each other. The layer numbers from the Tags and Layers manager accessible via the menu Edit -> Project Settings -> the Unity Editor Inspector by clicking on the layer dropdown and clicking on the Add layer button. This is applied globally, which means that once two layers are on Unity's list, everything placed on those layers will no longer register collisions.

In this case, the first layer is the weapon's layer for myTransform.gameObject.layer and the second taken from the variable myLayer, which is set in the Init() function of this script:

```
Physics.IgnoreLayerCollision(myTransform.gameObject.layer, myLayer);
```
