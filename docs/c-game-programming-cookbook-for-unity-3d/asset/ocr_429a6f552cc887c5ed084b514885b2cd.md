Before trying to follow any sort of path, it is a good idea to check that the initialization (didInit will be true) and the last waypoint has not been reached. If didInit is false or the last waypoint has been reached, the path-following should stop and the function returns:

A Vector3 called targetMoveVec a vector for the bot to move along, toward the waypoint. This movement vector is calculated by subtracting the position of the bot from the current waypoint transform position. The vector is then normalized by Unity's Vector3.Normalize function to strip away the magnitude. Note that the waypoint's transform is held in the current waypointTransform, put there by earlier call to the UpdateWaypoints() function:
