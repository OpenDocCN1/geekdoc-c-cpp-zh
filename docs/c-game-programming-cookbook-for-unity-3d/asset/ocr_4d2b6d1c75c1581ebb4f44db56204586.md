The PlayerPrefs calls out the total number of players for the game, which is also as a formality (it doesn't actually do anything or get) in all but the game Interstellar Paranoids. As the game has a cooperative game mode, we use the total-Players to decide which mode to start in. None of the other example games uses this key, although you could utilize it if you add multiplayer later on.

The next line calls on a function called LoadLevel and passes in the name of the scene to load. The variable singleGameStartScene is used, again a public string for easy editing in the Unity Editor Inspector, to determine which scene to load for a single player game. In this system, we also have a variable named coopGameStartScene which, when used, will branch off and display a different layout (with the addition of a "Start Co-op game" button) and will be used to launch a co-op game.
