The GetInput() function is virtual and is designed to be overridden if needed. This makes it easier to switch control systems if you define a new class from this one for other games. The variables horizontal_input and vertical_input are float values populated by the input controller in GetInput() and used to control the player later in the script:

```
public void GetInput (
    // this is just a 'default' function that (if needs be) should
    // be overridden in the glue code
    horizontal_input = default_input.GetHorizontal();
    vertical_input = default_input.GetVertical();
)
```

When the amount to move is calculated (using the input values as a multiplier), we use Time.deltaTime to make movement frame independent. By multiplying the movement-amount by deltaTime (the time since the last update), we move adapts to the amount of time between updates rather than only updating when the engine has to do:

```
// calculate movement amounts for X and Z axis
moveAmount = horizontal_input * Time.deltaTime * moveXpeed;
moveAmount = vertical_input * Time.deltaTime * moveZSpeed;
```
