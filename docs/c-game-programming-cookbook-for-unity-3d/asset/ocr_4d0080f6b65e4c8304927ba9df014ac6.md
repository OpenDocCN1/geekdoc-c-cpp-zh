Along with the audio, this exploded needs a nice explosion particle effect.
Rather than duplicate code whenever we need an explosion, the function Explode()
never does exactly that:

```
// play an explosion effect at the enemy position
Explode ( aPosition );
```

The hitID variable (integer) tells where the projectile came from. In this game,
when there is more than one player, it is used to tell which player to award the score.
if hitID is 1, it is the main user. The score for this hit goes to mainPlayerData-
Manager, player I's data manager:

```
if(hitID==1)
    // tell main data manager to add score
    mainPlayerData1.AddScore( pointsValue );
```

The user interface code will display info for one player by default, or for two players
when totalPlayers is more than 1. Here the UpdateScoreP() function is passed player I's
score:

```
// update the score on the UI
UpdateScoreP( mainPlayerData1.GetScore() )
} else
```

As there are two potential players in this game, the check to see whether player 2
caused hit does not check against a specific ID. If the ID of this hit is not (1 as per
hitID variable), we assume that this is the second player. The score will be added to the
data manager of player 2, and the user interface goes out to the UpdateScoreP2(
function:

```
// tell main data manager to add score
mainPlayerData2.AddScore( pointsValue )

// update the score on the UI
UpdateScoreP2( mainPlayerData2.GetScore() )
}
```

The power-ups will appear after a certain number of hits by the player(s). In this line,
a counter variable named powerExplosionCounter, to track explosions, is incremented:

```
// count how many have been destroyed and if necessary spawn a
// powerup instead
powerExplosionCounter++
```

When powerExplosionCounter passes the value of the variable numberOf
ExplosionsToMakePower, a power-up is instantiated in the game scene. It is assumed
that numberOfExplosionsToMakePower is set or modified in the Unity editor
Window. The Instantiate calls a prefab referenced in the variable powerUpPrefab,
nit is spawned whenever the enemy hit happened. powerExplosionCounter is reset to 0
after the Instantiate:

```
if( powerExplosionCounter>numberOfExplosionsToMakePower )
```
