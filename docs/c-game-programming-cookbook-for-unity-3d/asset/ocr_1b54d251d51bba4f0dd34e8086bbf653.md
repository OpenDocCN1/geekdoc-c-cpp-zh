# 4.3 Spawn Scripts

In many cases, using Unity's built-in Instantiate function would be enough for creat-
ing objects for a desktop computer-based game, but instantiating gameObjects in Unity
be an expensive process, particularly noticeable on mobile devices. Common
method of getting around the processor hit is using pooling. Pooling is where you have
group of objects that you use and reuse without destroying them. Instead, pooled
of are hidden rather than entirely removed from memory. With this method, the
memory is already allocated and the objects already exist but you are enabling and disbling them rather than having the performance hit of creating new ones and deleting
unused uses.

Building a pool management system is beyond the scope of this book, although cen-
tralizing the spawning system will make it easy to switch spawning for a better solu-
t in the future. There are a couple of pool managers available to buy from the Unity
Asset Store, or you may want to take a look at some free code called Unity Patterns (http://unitypatterns.com/new-tool-objectpooling/).
