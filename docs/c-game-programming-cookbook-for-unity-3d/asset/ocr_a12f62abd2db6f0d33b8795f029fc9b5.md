If you have never dealt with gizmos, they are quite simple little icons or helper switches to make editing easier. Unity relies heavily on gizmos for the editor and how you interact with it, as well as provide a nice interface for you to build your own custom types.

All gizmos drawing needs to be done in one of two functions (called automatically by the engine):

| OnDrawGizmos | Called every frame. All gizmos are pickable. |
| OnDrawGizmosSelected | Called only when the object with the script attached is selected. |

The OnDrawGizmos() function is a runtime class (called automatically by the game engine) where we can draw our gizmos and do some editor-based manipulation.
