4. Wave spawning. Attacks are made from prefabs containing groups of enemies. A wave spawner script named Wave_Spawner.cs instantiates the prefabs in a random order and keeps track of how many enemies there are in the level so that it knows when to spawn the next wave. Another small script called WaveProperties is attached to the enemy prefab to tell the spawner how many enemies it contains.

5. Projectiles. The projectiles are made up of the following:

+   a. Automatic Destroy Object script AutomaticDestroyObject

+   b. ProjectileControllercs

+   c. Rigidbody component.

+   d. A sphere collider for in-game will derive from the BaseUI

6. User Interface. The user interface for game is BaseUI DataManager script from Chapter 10, Section 10.2, which adds data management. The main menu uses the main menu system outlined in Chapter 10.

7. Top Down Camera. One of the camera scripts from Chapter 4.

8. Sound Controller. The sound controller script from Chapter 8.

9. Music Controller. The music controller script from Chapter 8.

Note that those components already described in detail elsewhere in this book will not be covered in this section (the full list of ingredients, from early in this section, states which scripts are from elsewhere).
