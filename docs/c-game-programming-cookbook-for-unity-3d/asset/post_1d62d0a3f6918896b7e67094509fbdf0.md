StartPlayer() is scheduled by the Init() function to be called several seconds after the level first loads. Until this point, the player (or players) will be held in place. This function starts out by grabbing references to the Player_SpaceShip_IP component with Unity's GameObject.GetComponent(), followed by another GetComponent() call to find the DataManager component (BasePlayerManager and DataManager scripts were discussed back in Chapter 3):

```csharp
public void startPlayer() {
    Debug.Log("StartPlayer!!!");
    // find the player's control script and hold it in playerScript
    playerScript = gameObject.GetComponent<Player_SpaceShip_IP>();
    mainPlayerDataManager = gameObject.GetComponent<BasePlayerManager>().DataManager;
}
```

Now that references have been stored for playerScript and mainPlayerDataManager, a message is sent to the player's control script to call its StartGame() function. GameObject.SendMessage() is used to send it: all ready to play! gameObject.SendMessage("GameStart");

If there is more than one player, the game controller is going to know how and where to talk to the second player. This part of the script grabs the same component as did for the first player but this time for the second player and placed into variables suffixed with 2 instead of 1: now, if totalPlayers > 1, let's tell it to get going.

```csharp
playerScript2 = gameObject2.GetComponent<Player_SpaceShip_IP>();
mainPlayerDataManager2 = gameObject2.GetComponent<BasePlayerManager>().DataManager;
```

Just as with the first player, a message is sent to the player's Player_SpaceShip_IP-component to prepare the player by calling StartGame() function: gameObject.SendMessage("GameStart");

StopMovingForward() and ContinueForward() will be called from another script when movement through the level is required to stop.

In this game, when the player reaches the boss at the end of the level, StopMovingForward() is called, then ContinueForward() will be called once the boss has been defeated before the next level is started by Invoke("FinishedLevel", 3f);

```csharp
public void BossDestroyed() {
    ContinueForward();
    if(BossWinNextLevel) {
        // go to next level
        Invoke("FinishedLevel", 3f);
    }
}
```

The SceneManager variable contains a reference to SceneManager component that will be responsible for figuring out which level to load next. First, GetSceneManager() is called to make sure we have a working reference to it. As long as SceneManager exists (and is not null), the call to GoNextLevel() will have the scene manager load the next scene and increment its current counter:

```csharp
if(sceneManager != null) {

    Debug.LogError("SCENE DOES NOT EXIST!");
}
```

To find the SceneManager.cs script component, the GetSceneManager() function needs to find its gameObject. The gameObject has been named SceneManager in the Unity editor, so a call to GameObject.Find() should return it without any trouble:

```csharp
void GetSceneManager() {
    // find loader object
    sceneManagerGO = GameObject.Find("SceneManager");
}
```

Assuming the gameObject has been found and a reference stored in sceneManagerGO, we do a quick check here to go ahead and grab another reference, this time to the SceneManager component itself:

```csharp
if(sceneManagerGO != null) {
    sceneManager = sceneManagerGO.GetComponent<SceneManager>();
}
```

The hitID variable (integer) tells where the projectile came from. In this game, when there is more than one player, it is used to tell which player to award the score. if hitID is 1, it is the main user. The score for this hit goes to mainPlayerData, player 1's data manager:

```csharp

    mainPlayerData1.AddScore(pointsValue);
```

The user interface code will display info for one player by default, or for two players when totalPlayers is more than 1. Here the UpdateScoreP() function is passed player 1's score:

As there are two potential players in this game, the check to see whether player 2 caused hit does not check against a specific ID. If the ID of this hit is not (1 as per hitID variable), we assume that this is the second player. The power-ups will appear after a certain number of hits by the player(s). In this line, a counter variable named powerExplosionCounter, to track explosions, is incremented:

```csharp
// count how many have been destroyed and if necessary spawn a
// powerup instead
powerExplosionCounter++;
```

When powerExplosionCounter passes the value of the variable numberOfExplosionsToMakePower, a power-up is instantiated in the game scene. It is assumed that numberOfExplosionsToMakePower is set or modified in the Unity editor. powerExplosionCounter is reset to 0 after the Instantiate:

```csharp
if(powerExplosionCounter>numberOfExplosionsToMakePower){
    Instantiate(powerUpPrefab, aPosition, Quaternion.identity);
    powerExplosionCounter=0;
}
```

Explode() is a simple function to instantiate an explosion effect as required. only parameter is a position for the explosion to happen at:

```csharp
public void Explode(Vector3 aPosition) {
    // instantiate an explosion at the position
    Instantiate(explosionPrefab, aPosition, Quaternion.identity);
}
```
