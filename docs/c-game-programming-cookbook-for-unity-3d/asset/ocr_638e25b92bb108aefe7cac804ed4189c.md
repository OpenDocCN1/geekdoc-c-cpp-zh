When a projectile hits an enemy or collides with a player, the object being hit needs to know where to react to the collision. In the example game Laser Blast Survival, projectile identification is made simply by layer—all player projectiles are set to layer 9, and all enemy projectiles are on layer 17. Set the layer on the gun-mounting-point object (the object that will be the parent to the weapon), and this script will use the same layer when assigning layers to the projectiles.

Another method for checking where projectiles have come is to assign each player with a unique ID and to use the SetOwner() function to tell the projectiles who owns each one. This method is employed in the Interstellar Paranoids and Tank Battle example games.
