As with the other example games in this book, players and enemies are dynamically created by the game controller when the game starts. References to several prefabs and gameObjects are set in the Unity editor Inspector window. These are

+   * Game controller Unity editor Inspector references:

+   * Explosion Prefab—A particle effect for explosions.
* Player Parent—An empty GameObject that will act as a parent object for players. This is to keep things neat—when the game is running, for any reason you need to look at a particular player you can easily access it by expanding the player object prefab.
* Start Points—These are gameObjects in the scene that the game controller can use to get position and rotation information from, for use with positioning the cars at the start of the game.
* Camera Script—This refers to the camera, which has an instance of the script Camera_Third_Person.cs attached to it. The game controller requires this reference to be set up communicate with the camera.
* Lap Text—A GameObject with the GIText component attached, which renders the user's current lap to the screen.
* Pos Text—A GameObject with the GIText component attached, which renders the user's current position in the race.
* Count 3—A GameObject used to display the number 3 during the 3-2-1 countdown at the start of the race.
* Count 2—A GameObject used to display the number 2 at the start of the race.
