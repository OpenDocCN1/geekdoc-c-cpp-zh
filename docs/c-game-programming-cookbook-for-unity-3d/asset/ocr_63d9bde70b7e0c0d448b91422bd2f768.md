Hashables have a key and a value, which makes them ideal for storing player-related

Hashtable. They must be initialized before:

```
// initialize our hashtables ready for putting objects into
racePositions=new Hashtable();

raceFinished=new Hashtable();
```

GetUniqueID() does more than provide a unique ID for each player of the game.
The RaceController script (RaceController.cs—discussed earlier in this chapter)
calls it, in passing a reference to itself (its instance) as a parameter. This function then
stores a reference to it in the raceControllers Hashtable, with the key being its ID. We also
use the ID to set up entries for raceLaps, racePositions, and raceFinished,
will be used by this class to track player state:

```
public int GetUniqueID(RaceController theRaceController){
```

Making each ID number unique is a case of incrementing an ID counter called
currentID whenever an ID is called:

```
currentID++;

// now set up some default data for this new player
```

The raceLaps Hashtable stores the current lap each racer is attempting to complete,
st at 1:

```
// this player will be on its first lap
raceLaps.Add(currentID, 1);
```

racePositions is a Hashtable for storing the current position of each player. It is in
no order, so it is similar to a score table, there will need to be some ordering to
find who is winning the race. The default position for all of the players is in last place
(note that players start at 1 in this function, not at 0 as arrays—for that reason, the
last place is racePositions.Count+1);

```
// this player will be in last position
racePositions.Add(currentID, racePositions.Count + 1);
```
