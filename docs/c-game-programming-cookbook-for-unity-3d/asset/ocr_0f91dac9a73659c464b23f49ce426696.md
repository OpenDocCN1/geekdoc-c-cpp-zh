currentRotation is a float representing the angle, in degrees, that we need to turn the camera to try and reach the target rotation wantedRotation. It's an interpolation carried out by Math.SmoothDampAngle.

Math.SmoothDampAngle is an interpolation function designed specifically for between two angles. It will automatically catch the return value between 0 and 360 as well as choose the correct way around (if your value is 181°, it interpolate rather than down so that the rotation has a natural flow and doesn't go back on itself).

The Unity documentation tells us that SmoothDampAngle takes the following parameters (in order of how they should be passed in):

| current | The current position. |
| target | The position we are trying to reach. |
| currentVelocity | The current velocity; this is modified by the function every time you call it. |
| smoothTime | Approximately the time it will take to reach the target. a smaller value will reach the target faster. |
| maxSpeed | Optionally allows you to clamp the maximum speed. |

In this part of the code, theVelocity variable holds the current velocity of the interpolated move, but it is not actually used anywhere else in the script. It's a required field for SmoothDampAngle, so we provide it for the function to work right and forget about it.
