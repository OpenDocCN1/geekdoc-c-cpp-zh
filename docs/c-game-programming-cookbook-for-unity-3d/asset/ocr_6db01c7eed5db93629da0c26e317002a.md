By calculating position with Time.deltaTime, the transition from start value to target value is smoothed over a repeatable, fixed amount of time rather than being frame-rate dependent and based on how many times the Mathf.Lerp calculation line is called:

```
currentHeight = Mathf.Lerp(currentHeight, wantedHeight,
Damping *= Time.deltaTime);
```

Now that the script has calculated how much to rotate the camera and how high it should be on the y-axis, the script goes to calculate where the camera is going to go position-wise.

wantedPosition is a Vector3 variable that will hold the target position. The first target position is the transform's position and an adjustment for using the currentHeight variable calculated above:

```
wantedPosition = target.position;
wantedPosition.y = currentHeight;
```

The next part of the code calculates how far behind the player need to move the camera. For this, the script uses Mathf.SmoothDampAngle.zVelocity represents speed of movement of the camera along its z-axis, but it is purely a formality to use with SmoothDampAngle and does not get used anywhere else in the script:

```
usedDistance = Mathf.SmoothDampAngle(usedDistance, distance,
ref zVelocity, distanceSnapTime);
```

To place the camera at the correct position around the target using only a rotation, the solution lies within using Quaternion.Euler. This rather frightening sounding function converts Euler angle Vector3-based rotations into a rotation. That is, you rotate in rotation values and you get back a direction vector instead. Multiply by how far back we want the camera from the player, then add that to the player's current position, and we have the correct rotation, position, and offset for the camera:

```
wantedPosition += Quaternion.Euler(0, currentRotationAngle,
) * new Vector3(0, 0, -usedDistance);
```

The final part of the function causes the camera to look at the target (player). It does this using Unity's built-in LookAt() function. We pass in the position of the target object (as a Vector3) and add an extra offset where the camera is going to go, via the LookAtAdjustVector variable. You can also add an up vector to the LookAt() function, but in this case we don't need to.
