Calculating the distance between two transforms will take into account x, y, and z
coordinates. For the examples in this book, waypoint following only to work on
a two-dimensional plane and the y-axis may be done away completely. Doing so
s solve problems with ground-based games where the height combined with the x- and
y-axis ensures not advancing the current waypoint at the right times. If we
were making a game based in the air, you would most likely need to comment this part
out and use x, y, and z.

BothPosition, a cached Vector3 of the bot's position, and nodePosition, the cached
waypoint position, are stripped of the y-axis in the code below:

```

// waypoint to advance on the next one

myPosition=myTransform.position;
myPosition.y=0;

// get waypoint position and 'flatten' it
nodePosition=currentWaypointTransform.position;
nodePosition.y=0;
```
