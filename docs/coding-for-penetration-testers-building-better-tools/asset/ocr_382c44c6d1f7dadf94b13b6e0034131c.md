Perl distributions are available for many platforms, from the standard Perl available from perl.org, to specific versions that have additional features and come packaged with a variety of utilities and tools, as those from ActiveState. In general, distributions within the same major version are relatively compatible, and we can move our Perl code from one to another without major rewrites. Perl code can be developed in a variety of tools, from simple editors to specialized integrated development environments. We can also make use of additional features, such as the ability to create graphical interfaces for our scripts, and through the use of some utilities, compile them into executable binaries.

Scripting in Perl follows most of the standard conventions we can find in other scripting or programming languages. We can use of various data structures, such as variables and arrays to store data in our scripts. We can execute commands in a shell, through the use of backticks, in a very similar way as we do in Swiss scripting with the bash shell. We can make use of arguments, control statements such as loops and conditionals, as well as regular expressions, file input and output, and many of the other standard programming language features.
