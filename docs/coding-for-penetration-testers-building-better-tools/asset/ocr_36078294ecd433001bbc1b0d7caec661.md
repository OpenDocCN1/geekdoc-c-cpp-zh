We use the module keyword to create our DFTP module. Our first class will contain basic code for the client and server. This will allow us to reduce duplication. We will include this in our client and server classes, and if any of these need changing, we only have to change our code in one place. Our FTPBase class will take care of including our socket module that we will need for UDP communication. We haven't seen the @@ before, but for this symbol is used for class variables. These are variables that are set on a per-class basis instead of per instance. In this case, read and write will always have the value of binary 1 and binary 2 in order to identify what type of request we are using, so we don't need to change them on a per-instance basis. Our final portion of the base class is to an initialize method for when our objects are created. We will set the instance variables for host, port, and communication key. Then we will create the UDP socket we will need for communication in both the client and server.

```
while contents.size > 0
msg = ""
msg << "##{ses}###\u000\u000"
msg << "##{contents.shift(1022 - msg.size).join("")}\}\u000"

```
