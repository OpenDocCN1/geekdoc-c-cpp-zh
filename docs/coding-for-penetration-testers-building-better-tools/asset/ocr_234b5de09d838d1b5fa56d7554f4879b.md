# FIGURE 9.1 Launching the GNU debugger.

After we run the program, we want to inspect the state of the program. By hitting "CTRL+c" we will break the execution of the program. We can see that the program recieve a "SIGINT" signal, which means it was sent an interrupt signal which was caused by pressing "CTRL+c". Once the program is stopped we issue the command "i r". This command is short for "info registers" which will show the values look like each of the registers. Knowing generally what these values look like before we exploit a program is useful so that we can see what looks different during an exploit.

These registers are important because they indicate the current state of the application. We see the general purpose registers first: EAX, ECX, EDX, and EBX. These registers are short for Extended Accumulator Pair, Extended Counter Pair, Extended Data Pair, and Extended Base Pair.
