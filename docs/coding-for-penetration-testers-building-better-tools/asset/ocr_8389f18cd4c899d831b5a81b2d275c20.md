# Causing Our Crash

Now that we have our application running, it is time to find out if our application has a vulnerability. We do this by causing it to crash and looking at what happens in our debugger. The first step of building an exploit frequently involves sending a large number of easily recognized characters. In this case we will use the letter "A." We use "A" because it is easily identifiable as 0x41 and it is also an instruction which can be frequently left in our exploit because it increments the ECX register. This normally won't impact the execution of our program. To begin, we'll build our Python framework for connecting and talking to our network service.

```
import socket
s = socket.socket()
host = '127.0.0.1'

s.connect((host, port))
print s.recv(1024)

s.send(buf)
print s.recv(1024)
s.close  # Close the socket when done
```
