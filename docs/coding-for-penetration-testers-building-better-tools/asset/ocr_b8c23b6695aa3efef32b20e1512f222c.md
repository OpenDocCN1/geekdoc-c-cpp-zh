print "hello world!\n";nAfter creating the file, setting the permissions to make it executable,

# FIGURE 3.2 Hello World script and output.

Let's take a look at this very simple script. We start with the
shebang, as we discussed in Chapter I, Introduction to command shell
scripting. In this case, we can generally find the Perl interpreter
located at /usr/bin/perl on most UNIX-like systems. If it isn't there, we
can find it with whereis perl or we can manually check other
common directories such as /usr/local/bin, /bin, or /opt/bin/. If all
else fails and we have administrative access to the system, we can do
a find for it, by issuing something like find -name perl -print.
