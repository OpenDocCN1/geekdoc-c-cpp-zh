We can also easily enter a new shell, simply by issuing the shortened name of the shell as a command. For example, to enter the C shell, we issue the csh command.

# Warning

When working with shells, entering a new shell is actually adding another layer of shell on top of the shell we are already using. For example, if we were already in our bash shell and typed bash again, we would be two shells deep. In order to return to our original bash shell, we would enter the exit command, which would bring us one shell back up to the original. We can easily see how running multiple layers of shells could very quickly become confusing.
