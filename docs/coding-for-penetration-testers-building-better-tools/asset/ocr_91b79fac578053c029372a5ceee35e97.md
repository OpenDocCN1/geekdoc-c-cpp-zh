actually pulling any specific data. Now we just need to run our module. For this work, we will need to save our file, and restart Metasploit. This means having to restart our handler as well as relaunch our backdoor.

# Tip

Once a module has been loaded into Metasploit the first time, it can be updated without restarting by typing in “reload” when you are using the module. But for newly created modules, your only option is to restart.
