If we want to introduce a new application of our own to run at boot time we just need to make a new entry, let's take a crack at it. Seeing as this is a very common Registry location where we might want to write to, and the path is a bit long to keep typing repeatedly, we will put together a small script to handle the creation of our value in the appropriate place.

```
import winrm
# Place Script Here
script = """
$regpath = "HKLM:software/microsoft/windows/currentversion/run"
$apppath = "$windir%/system32/calc.exe"
$name = "Calc"
Write-Host "Before"
Get-ItemProperty
"HKLM:software/microsoft/windows/currentversion/run"
Set-ItemProperty -path $regpath -name $name -value $apppath
Write-Host "After"
Get-ItemProperty
"HKLM:software/microsoft/windows/currentversion/run"
"""
ses = winrm.Session('172.16.85.130', auth=('sussurro','Abc123!'))
r = ses.run_ps(script)
print(r.std_out)
print(r.std_err)
```
