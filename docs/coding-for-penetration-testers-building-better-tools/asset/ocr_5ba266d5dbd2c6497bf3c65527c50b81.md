For writing data, we need to check for both filename and data to write. We build a conditional that for the write key and the data key set in our _GET array. If both keys are set, we set $file to our filename and $data to the data we want to write. Next, we open the file in the append mode by specifying a+ as the mode. Our fopen function returns a file handle, which we handle for fwrite takes two options, the file handle and the data to write. After we write data, we close the file handle and print a success message to the screen.
