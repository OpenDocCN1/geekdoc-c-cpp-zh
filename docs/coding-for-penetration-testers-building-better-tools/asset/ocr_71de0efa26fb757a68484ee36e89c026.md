Now that we have converted the function to a class, we have to update our code to create a new instance of our MyHead class and then call that getHeader in order to get our data. ```
#!/usr/bin/ruby
require 'net/http'
class MyHead
  def initialize(host,port = nil)
    @host = host
    @port = port.to_i || 80
  end
  def getHeader()
    Net::HTTP.start(@host.to_s,@port) do |http|
      resp = http.head('/')
      return [resp['server'].to_s,resp['Last-Modified'].to_s
    end
    return [nil,nil]
  end
end
if ARGV.size <= 0 || ARGV.size > 2
  print "Usage: #{$0} Host [Port]\n"
  exit
