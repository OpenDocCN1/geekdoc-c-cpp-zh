# FIGURE 1.4 Output from helloworld.sh.

Briefly stepping through what we did, the first line in our script dictates to the operating system how exactly we want to interpret everything that follows. The line #!bin/bash is composed of two parts. The first part, #!, is known as a shebang (some people prefer hashbang). This tells the operating system that this line will specify the interpreter for our script. The second part is the interpreter, in this case /bin/bash is the bash shell. It is possible that bash is located elsewhere in the file system, and we can determine its location by running bash.

The second line, uses the command “echo” to print to the screen string “Hello World.”
