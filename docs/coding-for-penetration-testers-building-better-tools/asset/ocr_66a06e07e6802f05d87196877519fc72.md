For each of the groups we execute “net localgroup <username>” for the group. We use the session object to execute our command. Notice that we are both hiding the command so it won’t show up on the victim’s desktop as well channelizing the output that we can easily retrieve the output text. After the command has run, we retrieve the data and then close the session and process.

We then have to clean the output from the command as it has a lot of header and other information in it. As a result, we will chop off the first six lines and the last line. This will get us just the list of users for the group. We will append this onto the group array in the third field (field number 2) as long as the output from the “net localgroup” command didn’t come empty.

Finally, we append the table information, and print it out and save it loot. We will make sure that our data stays persistent in case we need to go back and look at it later and store in the database.

The final set of data we need is our network information. Unfortunately much of this doesn’t live in WMI, but instead we will have to run commands. We will use the same command technique that we did in the groups function to get our data out, but we will have to execute far more commands to get the data we need.
