any particular directory. Now that we have something to serve, we need a small script to run Netcat and serve it out as a service on a port. We execute this script by running it as sudo ./ncwebserver.

```
#!/bin/bash
while true; do nc -l -p 8080 -q < index.html; done
```

Let's have a quick look at what we did here. We start out with the shebang, as we discussed in Chapter 1, Introduction to command shell scripting. We set up a while loop, implemented all on a single line. We first set the condition of our loop with while true; will always evaluate to true, so what we have created is an infinite loop. Next, we execute Netcat with the -l (the lowercase L, not the numeral 1) option, causing it to listen on the port we have specified with -p we then use the less than operator to direct the contents of the file index.html to the Netcat process, and close out our loop with done. If all goes well, we should see results similar to Fig. 7.1 when we open a browser and browse to localhost.
