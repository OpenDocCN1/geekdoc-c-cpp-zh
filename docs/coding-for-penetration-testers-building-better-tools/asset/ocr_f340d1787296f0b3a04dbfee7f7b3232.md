We start, with the shebang. Then we set up a variable, $file, and put the string testfile into it. This will be the filename we will be working with the script. On the second line, we make use of backtracks, just as we did in Chapter 1, Introduction to command shell scripting, with bash. In this case, our backtracks include the Linux command touch, which will update the timestamps of the filename we have stored in $file, and will also create the file if it does not already exist.

Next, we will make a copy of the timestamps that already exist in our file. We will use the stat command, which is built into Perl. The stat command will return a bit of information to us about the file, including the timestamps in which we are interested. We can address the stat command as though it were an array in order to access the particular bits in which we are interested. Here we will make use of stat like (stat($file) [8]), e.g., in order to access the eighth element, the accessed timestamp for the file.
