# NASL in Nessus and OpenVAS

Ideally, when we build custom scripts for penetration testing, we want them to be as versatile and multipurpose as possible. NASL provides us with a good tool for doing this, as our plug-ins generally be used in both Nessus and OpenVAS. This gives us the full support of the commercial version of Nessus where we are able to afford it and allowed to use it, as well as the ability to make use of OpenVAS in situations where we aren’t willing to use Nessus.

For the purposes of creating plug-ins, as we will discuss shortly, there are no major differences between the two. Since the code bases between the two applications diverged, many of the changes and features added to Nessus were in the name of changes to the client end and in the name of performance. For our purposes, the two are largely interchangeable. In our examples, we will be using OpenVAS, as this is what ships with Kali.

In order to use OpenVAS on Kali, we will need to go to the Vulnerability Analysis section in the GUI menu and click on opensvas setup. We will see OpenVAS go through some configuration steps and download a few things, then we will be all set to.
