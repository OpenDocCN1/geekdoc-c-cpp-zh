We will also need to look at a conditional statement in order to understand how to control execution of blocks based on a condition. To do this, we are going to build some code that will enumerate through some of the built-in arrays in PHP that provide access to server variables and environment variables.

```
<?php
if(function_exists('php_uname'))
{
    print "Server Uname is: ";
    print php_uname();
    print "\n";
}

foreach (\$ENV as $i) {
    print "$ENV[$i] = {$ENV[$i]}\n";
}
$keys = array_keys($SERVER);
for($i = 0; $i < count($keys); $i++) {
    if ($keys[$i] == '_' || $keys[$i] == 'ORACLE_HOME') {
        continue;
    }
    print "$SERVER[$keys[$i]] = {$SERVER[$keys[$i]]}\n";
}

$i = 0;
$keys = array_keys($_GET);
while($i < count($keys)) {
    print "$GET[$keys[$i]] = {$GET[$keys[$i]]}\n";
    $i++;
}
?>
```

To begin the script, we start by checking to see if the php_uname function exists. If it does, the statement will return true, and our code block will execute. The conditional should return true if we are on a Linux box, but it may not return true if we are on Windows. If it is true, it will print the output in a readable format.
