The first way we create a variable called key that stores the value “name.” Next we look at the object id of that object. The object id will differ when we run this different times, so your value may differ from the one in the example. We then use that variable “key” as our key for creating our array of hashes. Next, we create a for loop to iterate through the array and print the object ID of each class. English: For each element (i) in myList, print the object ID of the first object of each element (i).

That value is converted to a string so that we can use it in our print statement. As indicated by the different object IDs, we can see that each instance of name has a different object ID. If we were to create a hash with 1000 examples like this, we would be using additional memory unnecessarily.

In Ruby 2.1 and higher, using a string as the key will cause the string to be frozen. A frozen string will be preserved in memory for each single instance. Before Ruby 2.1, this would result in a different id for each key. Let’s see what that looks like in Ruby 2.1 and higher.

```
=> {"Name":"Ruby"}, {"Name":"Rulez"}
>> myList = [{ "name" => "Ruby"}, { "name" => "Rulez" }]
=> [{"name":"Ruby"},{"name":"Rulez"}]
>> myList.each { |i| print i.keys.first.object_id.to_s+"\n"}
16983060
16983060
=> [{"name":"Ruby"},{"name":"Rulez"}]
>> myList[0].keys.first.frozen?
>> true
>> "name".frozen?
=> false
```

In this instance, we create our list of hashes using the string “name” as our key. When we create our list of hashes and then iterate through it, the keys have the same instance id. We can tell that this is because the string is a frozen string by looking at the first element of the MyList array to retrieve the first hash, retrieving the keys, looking at the first key, and then asking of if that string is frozen. We see that it is, but a normal string of “name” is not.
