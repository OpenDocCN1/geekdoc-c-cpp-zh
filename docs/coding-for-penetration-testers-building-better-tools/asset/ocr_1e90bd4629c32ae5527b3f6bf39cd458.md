As with the net user command, a bit of scripting will help us out when we want to pull all the groups and their membership information and log it to a file.
for /F "delims=* tokens=1 skip=4" %i in ('net localgroup') do net localgroup %i >> c:\groups.txt

We can pull all the groups on the system, get their membership list, and log all to a file. The net localgroup command puts an asterisk at the beginning of each group name. But when we query the group name we need to strip the * character. To do this, we add some additional options to the loop. The delims keyword lets the for loop know how to split apart the output from net localgroup. We use the tokens keyword to get element 1, and skip lets us skip the first four header lines. We iterate through each element of the net localgroup <groupname> command.
