On some operating systems, such as Windows, we are likely to find only the built-in graphical and text-based shells, although we may potentially find more added by a particularly technical user. For purposes of penetration testing, text-based shells tend to be the more useful for us to access.

## What Is a Script?

A script, short for scripting language, is a programming language like any other, and may be similar in nature to other languages such as C++ or Java. The primary difference between a scripting language and other programming languages is that a program written in a scripting language is interpreted rather than compiled.

When we look at a traditional programming language, such as C++, the text we write defines the commands we want and is processed through a compiler and turned into machine code that is directly executable by the kernel/CPU. The resultant file is not human-readable. Any changes to our commands mean we have to send the changed text through the compiler again, resulting in a completely new executable. In interpreted languages, the text we create that contains our commands is read by an interpreter that does the conversion to machine code itself, as it is running the script. The text here is still human-readable and does not have to be recompiled if a change is made.

Normally, scripting languages have their own interpreters, so we need to install a separate interpreter for Python, another for Ruby, and so on. Shell scripts are a bit of a special case, as the scripts are interpreted using the shell itself, and the interpreter is already present as part of the shell.

## Note

The various languages we discuss in the course of this book, including shell scripts, Python, and others, are used to automate tasks. While some languages are faster than others, the primary goal of scripting is often speed of development and ease of use rather than execution speed. In many cases, a script is more than enough to handle the task at hand.

## Shell Scripts

Shell scripts are frequently used for:
- Automating repetitive administrative tasks.
- Glue-logic for complex system interactions.
- Rapid prototyping of ideas.
- Processing and transforming files.

One of the main advantages of shell scripts is that they provide access directly to the operating system's features. Because the interpreter is the shell itself, we can write scripts that use standard commands without needing an external environment. This makes them particularly powerful for system administration and penetration testing, where we need to interact with various tools quickly.
