client knows it can start sending data.

If no type was set, we are getting a continuation of a session. If the session is set, the session exists in our session hash, we continue processing the packet. If the session exists, we add the data data array in our session. If this was the last packet, we write out our file. We open a new file with the filename that the client passed us, and write data from our array into the file. We convert the array to a string to reassemble it for easy storage. Once we write the information to the file, we close the file and delete the session. We have now successfully transferred file. Our module is finished. We now only have to write the scripts that will use the new DFTP module we created. We save our file as DFTP.rb so Ruby will know how to load the file when we include.

Now we create our client. Because we've included most of the important code in our module, our client is simple. We need to open the file we want to send, create a new DFTP client class instance, and send the data.

```
#!/usr/bin/ruby
require 'DFTP'
require_relative
file = File.open(ARGV[0],"r").read
c = DFTPClient.new('localhost',53,'abc123')
c.send_file(ARGV[1],file)
```

Our code includes the DFTP module the same way we include any of the built-in modules: with the require keyword. To read in our data, we use the familiar File class to open the first argument passed to the script in read mode and store the data in the file variable. We create a DFTPClient instance to connect to localhost on port 53, the DNS port. We set our key to abc123.
