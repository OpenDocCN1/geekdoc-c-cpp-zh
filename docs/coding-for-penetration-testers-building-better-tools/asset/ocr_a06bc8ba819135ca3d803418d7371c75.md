Our entire command executes ping -c 1 $host. The -c flag allows us to limit the number of ping packets that are sent. We send a single packet to the host we are operating on using -c 1. Then, we pass the output of that ping command to grep, which searches for the string "bytes". We then pass that output to the wc command. The wc command counts the number of words in whatever is sent to it. We run the ping command, and we will find the occurrence of the string "bytes" at least once. This happens whether it fails or succeeds. But on a successful ping, we will find it more than once. We are using the wc command in order to count the occurrences of the string, with more than indicating a successful ping to the host.

If the ping succeeds, we echo a message to the console and return to the main body of the script. If the ping fails, we echo a message to the console and quit.

In the portcheck function, we set up a simple for loop in order to see if they are open. Here we use for to loop from the starting port to the stopping port, each taken from the arguments with which the script was run. We then enter a do loop that contains the heart of our entire script.

This line makes use of the /dev/tcp device we enabled in bash earlier. In essence, we attempt to echo (nothing) to /dev/tcp/<host name><port number>; if that works, we take the results of that command and send them to /dev/null, effectively throwing them away, using a redirect of any errors we might encounter to send them to the console, throwing them away also. In addition, we use the && operator (and) in order to echo the string <port number> to the console. Ultimately, this allows us to detect whether a port is open and echo the port number if it is.
