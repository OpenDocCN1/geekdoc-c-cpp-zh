To execute the interactive shell, type `scapy` in your Kali window.
There may be warning messages. In the end, we are greeted with Welcome to Scapy and a familiar Python prompt. We're in business. Where do we start? To see the types of packets that Scapy can create, type `ls()` and press **Enter**. This will give you the full list of every type of packet you can create with the framework.
