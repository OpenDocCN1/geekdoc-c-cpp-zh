Now that we have a process to work with, we can set about it. In PowerShell, we can kill a process using the Stop-Process cmdlet. Stop-Process can be run using either the process ID or the process name as an argument. If we use the process, we can simply run Stop-Process 3916. If we use the process, we need to add an argument, such as Stop-Process -processname iexplore.
