```
#ping a device to see if it is up
function pingcheck
{
  ping=`ping -c 1 $Host | grep bytes | wc -l`
  if [ "$ping" -gt 1 ]; then
    echo "$host is up"
  else
    echo "$host is down quitting"
    exit
  fi
}
#function portcheck
#test a port to see if it is open
function portcheck
{
  for ((counter=$startport; counter<=$stopport; counter++))
  do
    echo >/dev/tcp/$host/$counter > /dev/null 2>&1 && echo "$counter open"
  done
}
#run our functions
pingcheck
portcheck
```

At the top of the script, we find the shebang to indicate the interpreter we wish to use, and a few lines to assign the values from the argument to the host we wish to scan (host), the starting port (startport), and the stopping port (stopport). On the second line, we also encounter the comment mark we can use in bash: #. The command allows us to direct the interpreter to ignore anything on the line after the #. We then have two functions: pingcheck to check if our host is available on the network and portcheck to test for open ports.

In the pingcheck function, we are chaining a few different tools to evaluate whether we can reach the device on the network, and placing the final result in the ping variable.
