Let's take a quick look at what we've done here. We first assign the URL for our file to the $src variable. We will also need to specify where we are going to save the file. We are going to save this to the Windows temp directory in "C:/Windows/temp". When we specify the path in powershell, we use the "/" path syntax because "\" is an escape character.

We next instantiate our object to interface with the Web, System.Net.WebClient, using $web as a handle for it. This will allow us to interact with websites. The WebClient interface has a number of different ways that it can retrieve and upload data, but we use the DownloadFile method. We specify the handle for our web object, passing the URL that we are downloading and where we want to store it, as in $web.DownloadFile($url, $path). This is a fairly simple piece of code for handling Web traffic on a Windows machine. When we run the script, we should see output similar to Fig. 6.8.
