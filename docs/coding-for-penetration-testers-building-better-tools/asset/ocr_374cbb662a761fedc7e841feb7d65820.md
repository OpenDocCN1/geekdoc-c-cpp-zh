# Command Execution

Command execution is an important concept within PHP because we find vulnerabilities in PHP applications, being able to execute arbitrary code on the server will help us further our access to the machine. There are three basic ways to execute commands on the operating system in PHP: the passthru, exec, and system functions. Passthru will allow us to print the output of the executed code to the screen, while the other two will return data in different ways. Let's look at passthru first, in an example we see in the real world: some scripts executing code to facilitate sys-admin tasks. Let's take a script that will list out attributes of a file that is passed into it.

```
<?php
print "PRE>";
$file = $_GET['file'];
passthru("ls -l $file");
print "</PRE>";n?>
```

Our code takes the file variable passed in the get line, and executes an ls -1 on the output. The output from the passthru command is printed directly to the screen. We wrap the output in PRE tags so that it will appear normal. Let's start by using the script as it is intended: Save the script as systest.php and see that the output is the directory listing from the /var/www/html subdirectory. Now, let's look at how we abuse a script like this. Remember all shell commands that we looked at in Chapter 1, Introduction to command scripting. Let's put those to use. Go to http://localhost/systest.php?file=;cat/etc/passwd.
