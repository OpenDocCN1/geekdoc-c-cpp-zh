# Warning

When building any script that executes commands, use caution when securing the script. If it is publicly accessible, you don't want anyone else using the script, ensure that as tools like these are deployed, you clean up afterward so you aren't the one who leads to a host compromised by a bad guy.

# Putting It All Together

Having a basic PHP shell at our disposal will be very useful for penetration tests where we either have the ability to run code on the Web server or have the ability to include our PHP. To try out the skills we have just learned, we are going to build a basic PHP shell. We will be looking at command execution, form handling, conditionals, and more. We don't want anyone to notice we're doing with our script, so to make it a little harder to detect by simple log watching, we are going to submit shell commands to our script and see the output.
