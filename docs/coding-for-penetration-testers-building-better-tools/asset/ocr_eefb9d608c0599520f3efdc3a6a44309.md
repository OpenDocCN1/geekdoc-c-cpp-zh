# Exploiting PHP Scripts

PHP scripts are among the most exploited scripts on the Internet. Searching for PHP on http://exploit-db.com will yield pages of results. Writing secure PHP isn’t hard, but most resources for learning PHP don’t focus on writing secure PHP. Consequently, as people come up with great new ideas for applications, security is frequently an afterthought. That—coupled with some fairly common and simple-to-remedy Web misconfigurations—leads to getting hacked every day. In this section we will concentrate on Remote File Inclusion (RFI) and Cross-Site Scripting (XSS) vulnerabilities. We will see how these coding oversights and configuration problems can lead to big compromises.
