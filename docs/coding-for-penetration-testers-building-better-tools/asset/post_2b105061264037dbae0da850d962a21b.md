## Metadata in Media Files

In media files, we can find all manner of interesting metadata. We may be able to find data on the setting used on the camera or software that created or has been used to manipulate the image, geographic location information, thumbnails of the original image, and quite a few other bits of information. Given that the format of the file is largely binary-encoded data, the human-readable strings in the file are relatively easy to parse, even with the naked eye. This makes the job particularly easy for tools such as `strings`, or even grep, for that matter.

If, e.g., we wanted to search through a list of images in order to find those that contained a particular item of information, such as a particular model or serial number of a camera, we could very easily do this with a short bit of script in bash. Let's take a look at what we see in a JPEG file that was generated by a digital camera by running `strings` on it. In the case of the results shown in Fig. 8.5, we got back some interesting bits.

## Putting It All Together

Let's take a look at what we can put together for a script to do some of the things we have discussed in this chapter. We've talked about pulling information from Google, using Web automation, and searching files for metadata, so we'll get that all together in one package.

```
#!/usr/bin/perl
use WWW::Mechanize;
$site = @ARGV[0];
$filetype = @ARGV[1];
$searchurl="http://www.google.com/search?hl=en&q=$site%3A$filetype%3A$filetype"
$mech = WWW::Mechanize->new();
$mech->agent_('Windows Mozilla');
$mech->get($searchurl);
for $links=$mech->find_all_links(url_regex=qr/\w+\.\+$filetype/);
for $link ($links) {
  $url = $link->abs;
  @urlbits = split /:\, $url, 2;
  @moreurlbits = split /:\, $urlbits[1], 4];
  @moreurlbits = split /\, $moreurlbits, 2];
  $url = $moreurlbits[0];
  if (length($url) < 1) {next}
  $filename = $url;
  $filename = s/\..*\/([^\/])*$/$1/;
  print "downloading $url to $filename\n";
  $mech->get($url, ':content' => $filename);
}
@files = glob (".*filetype");
print "files = \$files[0]\n";
print "files 1 = \$files[1]\n";
for $file (@files) {
  print "running strings against $file\n";
  echo -e "********************\$filename\n********************\n\n" >> stringsreport.txt;
}
`strings $file >> stringsreport.txt`;
```

```

```

Here we have combined some of the things we put together. Down to 20, we have the same script we used to download files from Google. The bits at the end will be working with those files to pull the metadata from them.

One of the first pieces we have to look at is the line @files=glob(*filetype); This line uses the glob function in Perl in order to return us a list of files that match the extension we have in $filetype, and place that list of files in the array @files. Now we have the list of files, we can do a little work with, similarly to the batch scripting with strings we did earlier in the chapter. This work is all done inside our for loop.

Inside the loop, we iterate through the list of files in @files and, very much as we did in our script, we run strings against each of them. Here we are using backticks (``) in order to run the command and need to echo each text to the report file. We also have an if statement inside the loop to check for pdf being the string in $filetype, running exiftool against the file in $file (yes, exiftool supports PDFs), and generating a separate report for the EXIF data.
