## Interfacing with the Event Logs

Working with the event logs in PowerShell is a very easy task to carry out. Microsoft has given us a simple interface to work with them, although there are a few limitations. Again, we will look at how to work with the event logs in PowerShell interactive mode, just as we did earlier in this section with processes.

The first thing we are likely to want to do on our target system with the event logs is to look at what we have on the system. For this, we can use the Get-EventLog cmdlet, with the list argument, as in Get-EventLog -List. When we run this cmdlet, we should see output similar to that shown in Fig. 6.5.

Convenient, once we have the list of event logs in hand, we can use the same cmdlet with a different argument to list the content of a specific log. When we look at a log on a given system, there will likely be a very large amount of information in it, so will also want to filter what is returned to us, unless we are jumping the log contents out to a file. We can get the last few messages from the log that we specify by using the -newest argument with Get-EventLog, as import winrm

```python
import winrm
# Place Script Here
script = ""
Get-EventLog -List | ForEach-Object { Get-EventLog $_.Log -Newest 10 }

s = winrm.Session('172.16.85.130', auth=('sussurro','Abc123!'))
r = s.run_ps(script)
print r.std_out
```

We have added to our script so that it will use the ForEach-Object cmdlet. This cmdlet will take output line from the preceding command and then perform an action on it. In this example we have told it to fetch the latest 10 items from the eventlog that it found the list. This should get the latest 10 events from each log in the event\log.
