Comparison Operators

|---|---|

We would use any of these in our if statement, like so:

```
#!/bin/bash
NUM1="4"

fi
```

# Looping

There are several different mechanisms we can use in bash in order to repeat a loop. Primarily, the for loop and the while loop are the most commonly used and useful. Both ultimately have similar results, carried out in a slightly different way.

With the for loop, we can work through a list, completing an operation on each item in it. For example:

```
#!/bin/bash
for files in /var/log/*
do
  echo $files
done
```
