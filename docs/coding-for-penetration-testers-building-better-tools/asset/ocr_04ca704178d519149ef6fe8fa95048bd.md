# CHAPTER 8

# Information gathering

# Abstract

In this chapter, we look into information gathering and how it can be of great use to us in the the course of a penetration test. We talk about automating searches with Google, parsing text and automating Web interaction with Perl, and finding and working with the metadata stored in documents, files, visual media, and other structures intended for digital storage of information. We also look at the various tools we might want to use for search and sift through such data once we have it.
