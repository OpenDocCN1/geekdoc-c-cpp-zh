We've dealt with files in two different ways so far, so let's look at the third way. PHP can also read and write to files in a conventional way. We have used file open commands in other languages, such as Ruby and Python, and PHP has a command that is very similar to the commands we've seen before. The fopen function allows us to open a file for reading, writing, or appending, just like the other languages. To explore this, let's look at a script that will allow us to read or write data, depending on the get line.
