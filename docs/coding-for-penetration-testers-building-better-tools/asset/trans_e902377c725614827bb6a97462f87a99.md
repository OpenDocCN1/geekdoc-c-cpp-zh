仅凭时间作为会话值（session value）是非常糟糕的。PHP 有内置会话处理功能；不要尝试发明轮子。在大多数情况下，如果某种语言提供了生成伪随机数会话的机制，请直接使用该机制。当我们尝试创建新事物时，更容易编写出有漏洞的代码，而且它可能没有专家编写的那么安全——除非你是该领域的专家，如果是那样，请记住在创建出新且很棒的东西时，将其回馈社区。

# 总结

在本章中，我们探索了使用脚本语言进行利用的不同策略和方法论。通过 Python，我们创建了一个利用缓冲区溢出漏洞获取远程 shell 的利用程序。一旦我们有了 POC 代码，我们便查看了如何使用 Ruby 将我们的利用程序转换为更通用的 Metasploit 利用程序。

现在的许多漏洞存在于 Web 中，因此我们查看了三种不同类型的 Web 漏洞：RFI、命令执行和 XSS。我们利用 RFI 漏洞将自己的 shell 包含到有漏洞的应用程序中，然后查看如何向同一个应用程序注入 PHP Meterpreter shell。我们检查了命令执行漏洞，并演示了如何通过有漏洞的 Web 应用程序启动命令。最后，我们查看了搜索页面中的 XSS 漏洞，并将多段代码组合在一起创建了一个可以运行的 XSS 利用程序。

我们已经探索了多种帮助利用脚本来推进对目标网络访问的方法。我们可以构建并移植网络利用程序，利用 Web 漏洞，并窃取会话以获得 Web 页面上的额外访问。我们已经使用过 Ruby、PHP、Python 和 JavaScript。每个示例都显示了脚本对于渗透测试的利用阶段至关重要，现在我们更好地掌握了如何在渗透测试过程中使用脚本来获取对网络和 Web 资源的额外访问。

# 引言

一旦渗透测试人员找到了进入机器的方法，下一步是收集资产信息，并利用这些信息获取对网络或其他资源的进一步访问。脚本编写可以帮助在利用成功后收集信息，而 Meterpreter 脚本可以被用于获取进一步的访问。然后，一旦网络后渗透完成，测试人员可以使用数据库漏洞挖掘数据并获取 shell 访问。本章带读者通过基础脚本编写、Meterpreter 脚本、数据挖掘和 shell 访问的步骤。详细探讨了从命令行操作 Windows 操作系统；因为收集 Windows 信息时使用的许多命令在 Linux 上也相似，因此也探讨了网络信息收集。

# 为什么后渗透利用很重要

后渗透利用利用我们已有的访问并尝试扩展和提升这种访问。理解网络资源如何交互以及如何从一个受攻击的机器跳转到另一个，为我们的客户增加了价值。正确识别环境中的有漏洞机器并证明漏洞是可利用的是好的。但能够收集信息以支持证明重大的业务影响则更好。
