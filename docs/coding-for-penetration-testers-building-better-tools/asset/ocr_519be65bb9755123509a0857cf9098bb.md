# Starting a Template

The first step to creating a Metasploit exploit module is to create our class and initialization method. The information in the initialization method includes the name of the module, the description, payload parameters, and information about the exploit targets. Let's start building our class by building an initial template.

# Note

The template we are using in this example is a modified version of the template provided with the Metasploit Framework. You can find the full template with Metasploit at https://github.com/rapid7/metasploit-framework/wiki/How-to-get-started-writing-an-exploit. The Metasploit template is also updated as new features are added to Metasploit. So, if a module is not working correctly with the example template, consult the template in the listed article.
