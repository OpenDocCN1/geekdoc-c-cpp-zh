# FIGURE 8.4 Strings output.

We can make use of strings to sort through all the files in a directory with a tiny bit of scripting:

```
#!/bin/bash
find . -name \*.ppt | (
  while read file; do
    echo -e "************************************$file\n************************************\n\n"" >> stringsreport.txt;
    strings $file >> stringsreport.txt;
done)
```

So we do a quick find, searching for the .ppt files in the directory from which we are executing the script, passing the results off to a while loop. Inside the loop, we echo a line out to our report file so that we can delineate the different files in the report, then run strings against the filename in $filename and echo those to the file as well.
