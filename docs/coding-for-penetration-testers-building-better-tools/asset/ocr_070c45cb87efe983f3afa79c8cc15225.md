# Getting Our Shell

We now have a working exploit. All we need to do in order to use it is to try it out and see if it spawns our shell. Next, we begin by restarting gdb and running our vulnerable code. Then, send our exploit string. Once the string is sent, our exploit should execute, and then we should be able to access port 8675 on our local host and have a shell.

When we access our shell we will want to use netcat instead of Telnet. Telnet adds additional characters for terminal control that will mess with our shell. So instead we are going to issue the command “nc -v 127.0.0.1 8675”. The "-v" is so that it will increase verbosity and we can see when our shell connects.
