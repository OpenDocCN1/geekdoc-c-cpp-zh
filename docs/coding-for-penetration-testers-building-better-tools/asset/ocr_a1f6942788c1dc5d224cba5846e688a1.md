Printf takes a number of arguments, where the first argument is the format string and each subsequent argument is a value to be printed in the format string. This is best illustrated via an example.

```
<?php
$i = 5;
$f = 5.5;
$b = array(1,2,3,4,5);
$a = array('a' => 'b', 'c' => 'd');
printf("My values are: %d, %2.2f, %d, %d, %s\n", $i, $f, $b, $a[0], $h['a']);
?>
```

We bring back our familiar testing code and substitute our output for a printf statement. We see that for decimal integers we use %d, for floats we use %f (in this case formatting up to two characters before the decimal and two characters after), and for string values we use %s (in this case the b output from our hash). We can create very complex format strings with printf, including binary output when required.
