Let's have a quick look at what we're doing. The first line that takes in
the arguments for the script, make using the method we used in param. This essentially
the same thing as we used in Chapter 1, Introduction to
command shell scripting, but with slightly less code. In this case we
are taking the filenames from the command line. We use gc,
which reads the contents of the file in $Filenames (very much like cat
in Linux), and places them into $contents. The variable $ms is a handle
for the IO.MemoryStream object that we will use shortly for a bit of
storage. We set up $cs and $sw as handles for the
IO.Compression.DeflateStream and StreamWriter objects,
resively. Once we have our objects all set up, we write the
compressed contents of the files to our memory stream and close the
stream writer.

Now that our script contents are in storage we can convert them.
The Base64-converted string of the text in our memory stream,
$ms, is assigned to the $code variable. This is the code that we
end up in our .bat file. We then go backward through the process
to perform compression and convert our script, ending up at a
decompressed ASCII text version, which we pass off to Invoke-
Expression in order to execute the code in the context of the current
shell.
