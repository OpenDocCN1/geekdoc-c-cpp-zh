So let's walk through the script and see exactly what we are doing. We have the standard shebang at the top, and then we run wget in order to retrieve oui.txt from the Institute of Electrical and Electronics Engineers (IEEE) Web site. Note that, for the wget command only, we redirect the output of the command to /dev/null by using 2>/dev/null, effectively keeping the output of wget from displaying to the console.
