We can simply run our script by typing python hello.py in a shell window. Linux or UNIX environments also offer a second way to run Python scripts: We can make the script executable by typing chmod ux hello.py and then ./hello.py. Now, using Kali, let's make it happen! # Note

Why does the second way of running the script work? The first line "!/usr/bin/python," explicitly says what interpreter to use to run the script. This will work for any interpreter, including perl, ruby, and a number of others.

```
root@mostdefinitelynotkali:~/Desktop$ python hello.py
Hello <your name>!
root@mostdefinitelynotkali:~/Desktop$ chmod u+x hello.py
@mostdefinitelynotkali:~/Desktop$ ./hello.py
Hello <your name>!
root@mostdefinitelynotkali:~/Desktop#
```
