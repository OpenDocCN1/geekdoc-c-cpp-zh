With our next block of code, we want to iterate through each element of the $ENV array, an array which surfaces operating environment variables to PHP. To do this, we use a foreach loop, where we specify that each element returned from the keys function should be assigned to a variable. The loop will iterate for each key in the $ENV array, and we can access the current key through the $i variable. When we print our output, we want to see our variable name with the dollar sign, indicating to the viewer that it is a variable. To make the dollar sign print, and not evaluated as a variable, we put our escape character \ in front of the dollar sign to indicate that it shouldn't be evaluated. We use the curly braces to indicate that the whole expression $ENV[$i] should be evaluated, and we will have the value at the current key of the _ENV array inserted into our string to print.
