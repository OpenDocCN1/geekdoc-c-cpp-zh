# PHP Basics

In order to run our PHP scripts, we will have to make sure our Web server is running. To do this, we start Apache Kali 2 by issuing the command service apache start. Next, we will change into the Web directory which is /var/www/html. This directory is the root website for the Apache server, and the files we create will be accessible via our website at http://localhost.

Now that our site is configured, let's build a simple PHP page. Base64 is an encoding method used frequently on the Internet to encode data for transmission. The giveaway is a string of text that ends in one or more signs. When we run Base64-encoded data, the easiest way to decode it is to go to a script. For our first PHP page, let's build one.

For our first Web page, we want to be able to accept input through the URL or through a form. When we submit data, there are three ways we can access that data. The first is either through the $_GET or the $_POST array. These arrays contain, as we could possibly guess, data submitted via GET and POST requests. The second is through the $_REQUEST array, which contains the values of the $_GET array, the $_POST array and the $_COOKIE array. The third requires a PHP setting called register_globals to be enabled in the PHP configuration file. In Version 5 of PHP, this is disabled by default as it is seen as less secure, which is why it is mentioned here.
