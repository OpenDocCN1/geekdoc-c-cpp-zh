```
What is the name of your organizational unit?\n    [Unknown]: Engineering\nWhat is the name of your organization?\n    [Unknown]: ACME Software\nWhat is the name of your city or locality?\n    [Unknown]: San Francisco\nWhat is the name of your State or Province?\n    [Unknown]: CA\nWhat is the two-letter country code for this unit?\n    [Unknown]: US\nIs CN=Alice Lee, OU=Engineering, O=ACME Software, L=San Francisco, ST=CA, C=US correct?\n    [no]: yes
```

The keytool uses names in the X.500 format, whose components are Common Name (CN), Organizational Unit (OU), Organization (O), Location (L), State (ST), and Country (C), to identify key owners and certificate issuers.

Finally, specify a key password, or press Enter to use the keystore password as the key password.

Suppose Alice wants to give her public key to Bob. She needs to export a certificate file:

```
keytool -exportcert -keystore alice.certs -alias alice -file alice.cer
```

Now Alice can send the certificate to Bob. When Bob receives the certificate, he can print it:

```
keytool -printcert -file alice.cer
```

The printout looks like this:

```
Owner: CN=Alice Lee, OU=Engineering, O=ACME Software, L=San Francisco, ST=CA, C=US\nIssuer: CN=Alice Lee, OU=Engineering, O=ACME Software, L=San Francisco, ST=CA, C=US\nSerial number: 470835c\nValid from: Sat Oct 06 18:26:38 PDT 2007 until: Fri Jan 04 17:26:38 PST 2008\nCertificate fingerprints:\n         MD5: BC:18:15:27:85:69:48:81:5A:C3:0B:1C:06:11:B7:81\n         SHA1: 31:0A:A0:B8:C2:8B:BB:85:7C:EF:C0:57:E5:94:95:61:47:6D:34\n         Signature algorithm name: SHA1withDSA\n         Version: 3
```

If Bob wants to check that he got the right certificate, he can call Alice and verify the certificate fingerprint over the phone.
