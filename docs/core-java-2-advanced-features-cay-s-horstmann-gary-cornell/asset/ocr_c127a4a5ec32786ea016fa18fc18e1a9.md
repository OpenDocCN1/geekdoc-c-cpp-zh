When inserting into a list, table, or tree, you also need to check whether the data should be inserted between items or replace the item at the drop location. For a list, invoke the `insert` method of the `JList.DropLocation`. For the other components, see the API notes for their drop location classes at the end of this section.

To summarize, to turn a component into a drop target, add a transfer handler that specifies the following:

+   - When a dragged item can be accepted
+   - How the dropped data are imported

In addition, if you add drop support to a `JList`, `JTable`, `JTree`, or `JTextComponent`, you should set the drop mode.
