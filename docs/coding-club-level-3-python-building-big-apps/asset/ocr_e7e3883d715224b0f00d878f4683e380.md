# Adding a bat

In this chapter we will add two bats to our game. First, we must design a Bat class and then use it to manufacture two bats to add to our table object.

The bat is to be a simple rectangle that moves up and down the screen (Figure 5.1). The ball must bounce off our bat in a similar way to the walls. We would like a re-usable class that can be used in other games.
