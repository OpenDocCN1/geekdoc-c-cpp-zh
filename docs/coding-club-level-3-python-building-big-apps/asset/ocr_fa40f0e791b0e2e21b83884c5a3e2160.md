# Analysis of Code Box 2.2

```
`romeo = cat.Cat()`
```

This is where we order an object from our cat factory. Computer scientists say: “We have made an instance of the Cat class.” They might even say that we have instantiated a cat object. Romeo is the object and it is created by the Cat class (hence the capital letter). The Cat class is in `cat.py` so we tell `main.py` when we throw the dot operator. This dot is used to link the class with its location. In non-coding language, this line of code translates as:

> “Create an object called Romeo using the cat factory found in the `cat.py` file.”

Thus we have a cat! And he is called Romeo! All done with one line of code.
