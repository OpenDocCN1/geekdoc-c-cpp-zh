This is not, however, a good way of doing it as we are trying to build a Table class. A factory that can only build one type of table is not much use. What if we wanted a longer table? The net would be too far to the left. A taller table would have a net that did not reach the bottom! But we have variables that hold the width and height properties of the table object, so we can calculate the coordinates from these in the method. Then the net will always be in the correct place:

For a vertical net:

+   - [top x-coord] becomes self.width/2
+   - [top y-coord] becomes 0
+   - [bottom x-coord] becomes self.width/2
+   - [bottom y-coord] becomes self.height

For a horizontal net:

+   - [left x-coord] becomes 0
+   - [left y-coord] becomes self.height/2
+   - [right x-coord] becomes self.width
+   - [right y-coord] becomes self.height/2
