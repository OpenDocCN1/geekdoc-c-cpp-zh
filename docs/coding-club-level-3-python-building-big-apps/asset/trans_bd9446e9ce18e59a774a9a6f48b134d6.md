### 函数设计过程

如果我们决定只检测球是否到达两个球拍的前缘，碰撞检测本可以很简单。但如果我们想要水平放置的球拍，或者把它们放在屏幕中央并让球从各个侧面弹开呢？为了让 Bat 类更有用，我们将添加这一完整功能。于是，设计师借助类似第 82 页的草图以及一本代表球拍与球碰撞的书，开始解决这个问题。

这里输入的所有变量最终都会被用到：

- `collision_direction`  
  将存储与球拍相撞的是哪条边（"N"、"S"、"E" 或 "W"）。
- `collision`  
  是一个布尔变量，如果检测到碰撞，它将被设置为 `True`。
