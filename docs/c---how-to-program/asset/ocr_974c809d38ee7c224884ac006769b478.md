# 新时代公民道德建设实施纲要

一、总体要求

1. 指导思想。以马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观、习近平新时代中国特色社会主义思想为指导，坚持依法治国和以德治国相结合，坚持社会主义核心价值体系，坚持以人民为中心的发展思想，坚持马克思主义道德观、社会主义道德观，倡导讲道德、尊道德、守道德，不断提高人民思想觉悟、道德水准、文明素养，培养担当民族复兴大任的时代新人，促进社会全面进步、人的全面发展。

2. 方针原则。坚持马克思主义道德观、社会主义道德观，坚持社会主义核心价值体系，坚持把社会公德、职业道德、家庭美德、个人品德建设作为着力点，坚持把立德树人贯穿学校教育全过程，坚持发挥社会主义法治的促进和保障作用，坚持积极引导青少年培育和践行社会主义核心价值观。

3. 目标任务。在全社会大力弘扬社会主义核心价值观，积极传播中华民族传统美德，深入推进社会公德、职业道德、家庭美德、个人品德建设，不断提高公民道德素质和社会文明程度，为全面建成小康社会、全面建设社会主义现代化国家提供精神力量。
