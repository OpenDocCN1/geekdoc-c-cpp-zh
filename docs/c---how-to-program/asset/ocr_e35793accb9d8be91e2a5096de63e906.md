# Compiler Flags for C99 and C11 on GNU gcc for Linux

GNU supports many C99 and C11 features (but not C11's multithreading). To compile for C99, you must use the compiler flag -std=c99 as in

```
gcc -std=c99 YourProgram.c -o YourExecutableName
```

Similarly, for C11 you must use the flag -std=c11 (as showed in Section 1.10.2):

```
gcc -std=c11 YourProgram.c -o YourExecutableName
```

On Windows, you can install GCC to run C99 or C11 programs by downloading either Cygwin (www.cygwin.com) or MinGW (sourceforge.net/projects/mingw). Cygwin is a complete Linux-style environment for Windows, while MinGW (Minimalist GNU for Windows) is a native Windows port of the compiler and related tools.
