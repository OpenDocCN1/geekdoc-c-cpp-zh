

## 7.12 节 函数的指针

- 函数指针（第 343 页）包含函数在内存中的地址。函数名实际上就是执行函数任务的代码在内存中的起始地址。
- 指向函数的指针可以传递给函数、从函数返回、存储在数组中，并可赋值给其他函数指针。
- 指向函数的指针通过解引用来调用函数。调用函数时，函数指针可以直接用作函数名。
- 函数指针的一个常见用途是基于文本、菜单驱动的系统。
