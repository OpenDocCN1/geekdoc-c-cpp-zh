## 10.10 插曲：求值策略

如果你不想读这一节，可以跳过。但如果你读了，会更有趣。

不同语言在向函数传递参数时有着不同的行为。

有些语言会复制参数的值。有些语言只是让参数名成为实参的别名。还有些语言通过某个关键字让你选择。

编程语言采用的具体方式称为其**求值策略**。

三种非常常见的策略是：

- **按共享传递（Call by Sharing）：** 这就是 Python 采用的方式。当你调用函数时，参数变成与对应实参相同的对象的引用。这意味着，如果在函数内部修改了参数所引用的对象，调用方会看到这个变化。但是，如果你给参数赋予一个新值，调用方不会看到这个变化。

  ```python
def foo(x):
    # 修改传入的对象。调用方会看到这个变化。
    x[1] = 99

    # 给 x 赋予一个新列表。调用方 _不会_ 看到这个变化。
    x = [4, 5, 6]

a = [1, 2, 3]

foo(a)
print(a)  # [1, 99, 3]
  ```

- **按值传递（Call by Value）：** 会创建实参的副本并将其存储在参数中。C 语言等使用这种方式。（有时人们说 Python 是按值传递，但严格来说这并不准确，因为参数传入时并不会被复制；复制的只是对实参的引用。你可以在调用函数时复制参数，从而让 Python 模拟按值传递。）

  ```python
# 在 Python 中模拟按值传递

def foo(x):
    # 修改传入的对象。调用方通常会看到这个
    # 变化，但如果他们调用时传入的是副本，
    # 那么只有副本会受到影响。
    x[1] = 99

a = [1, 2, 3]

# 通过复制来模拟按值传递
foo(a.copy())

print(a)  # [1, 2, 3]
  ```

```python
def get_ship_locations():
    """
    要求用户输入若干个 X, Y, Z 飞船坐标。
    返回所有坐标的列表。
    """
    done = False  # 当用户要求结束时设为 True

    locations = []  # 所有飞船位置的主列表

    while not done:
        xyz = input('输入飞船位置 x,y,z（或 "done"）：')
        if xyz == "done":
            done = True
        else:
            # 获取 x,y,z 坐标的列表
            xyz_list = xyz.split(',')
            # 转换为整数
            for i, v in enumerate(xyz_list):
                xyz_list[i] = int(v)
            # 构建主列表
            locations.append(xyz_list)

    return locations

locations = get_ship_locations()
print(locations)
```

### 解决问题的步骤：执行计划

下面是用 `math.pow()` 计算点 p0 和 p1（两者都是 X,Y,Z 三元组的列表）之间距离的代码：

```python
d = math.sqrt(
    math.pow(p0[0] - p1[0], 2) +  # X 的差值
    math.pow(p0[1] - p1[1], 2) +  # Y 的差值
    math.pow(p0[2] - p1[2], 2)    # Z 的差值
```

这是第二种选择：

```python
dx = p0[0] - p1[0]  # X 的差值
dy = p0[1] - p1[1]  # Y 的差值
```

你更喜欢哪一种？两者应该给出等价的结果。

F = G * (m1 * m2) / (r * r)

其中 m1 是一个行星的质量，m2 是另一个行星的质量，r 是它们之间的距离。
