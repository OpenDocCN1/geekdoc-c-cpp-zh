## 10.7 多返回值

问题解决步骤：理解问题。

你始终可以从函数返回列表、字典或任何东西，但你也可以返回两个值并将它们赋给不同的变量。

```
# Function that returns the argument times 10, and divided by 10

def timesdiv10(x):
    return x * 10, x / 10

a, b = timesdiv10(100)

print(a, b)  # 1000 10
```

或者你可以将结果赋给单个变量。结果将是一个元组，它是一个只读列表，你可以用方括号表示法访问它：

```
a = timesdiv10(100)

print(a[0], a[1])  # 1000 10
```

神奇！

## 10.8 什么构成一个好的函数

问题解决步骤：理解问题。

最大的规则是“只做一件事并做好它”。

这更像是一个指导方针而不是规则，因为在编程方面你是老板。

但这是一个很好的指导方针，只要能做到就应该遵循。

你使用函数的主要用途是：

- 数学方程
- 任何重复发生的事情
- 将代码分解为更小、独立的部分

让我们更详细地谈谈最后一项，因为它不太明显。

非常频繁——几乎总是——你会从需要执行的一系列步骤开始来解决这个问题，像这样：

```
# While we still have data to process
# Process the data
# Output the data
```

然后你进去填充处理数据和输出数据的所有代码。

但这可能会导致臃肿、难以阅读的 while 循环。最好这样编码：

```
while d in data:
    d = process(d)
    output(d)
```

然后编写函数 `process()` 和 `output()` 来操作传入的数据。

这使得循环的逻辑非常容易阅读。而易读性是王道（如果你愿意，也可以说是女王）。

如果你发现有大量代码变得深度嵌套，也许是时候将它们拆分为函数了，即使你只从那个单一位置调用这些函数。

知道何时将代码拆分为函数更多是一种艺术而非科学。如果你开始觉得代码有点难以处理，请考虑将其拆分为不同函数后的样子。如果你更喜欢这样，就去做吧！

## 10.9 位置参数与关键字参数

问题解决步骤：理解问题。

我们稍后会更详细地讨论这个问题，但函数参数在 Python 中可以分为这两个大类：位置参数和关键字参数。

位置参数是必须在函数调用中出现在特定位置的参数。

例如，如果我们想计算 14^12，我们需要以特定顺序将这两个参数传递给 `math.pow()` 函数，该函数期望底数在前，指数在后：

```
math.pow(14, 12)  # 56693912375296.0
```

如果你把 12 放在前面，你会得到不同的答案。这些是位置参数。

但对于某些函数，在位置参数之后，你可以指定额外的关键字参数。这些参数由特定名称标识。

例如，通常 `print()` 会在字符串末尾加上换行符。但你可以通过 `end` 关键字参数覆盖此行为，告诉 `print()` 在行尾放置空字符串（即什么都不放）：

```
# Together, prints "Beej" on a single line

print("Be", end="")
print("ej")
```

注意我们必须按名称标识关键字参数。

如果你查阅文档，你可能会看到类似这样的内容（`print()` 的文档）：

```
print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)
```
