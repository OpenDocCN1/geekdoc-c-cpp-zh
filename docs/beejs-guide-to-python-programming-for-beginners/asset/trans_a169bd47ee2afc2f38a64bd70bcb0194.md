这就是循环。我们在条件为 True 时反复运行同一段代码。至少，这能为我们省去大量打字！

Python 有几种循环语句，但在本节中，我们将重点介绍所谓的 while 循环。它会在条件为真时反复执行某些操作。

下面是一个从 1200 数到 1210 的示例⁵：

```
x = 1200

while x <= 1210:
    print(x)
    x += 1

print("All done!")
```

只要条件 x <= 1210 为 True，它就会重复循环体（所有缩进的部分）。

你会看到，在循环体内部，每次迭代我们都会将 x 递增（加一），使它逐步增加到 1210。

如果我们不递增 x 会怎样？那样的话，它会永远循环下去。我们称之为无限循环。如果你的程序长时间运行却没有输出（或重复输出），它可能陷入了无限循环。

如果你的程序陷入无限循环，你该如何退出？按 CTRL-C（也称为 “break”）即可。这样就会回到 shell 提示符。

请记住，本章程序的目标之一是要求用户输入一个介于 5 和 50 之间的数字。如果他们输入的数字超出该范围，我们需要再次询问。也就是说，我们需要在用户未提供有效输入时循环。现在先思考一下这个问题，稍后我们会再回来处理。

## 6.8 循环：for 循环

### 解决问题的步骤：理解问题

除了 while 循环之外，我们还有一种称为 for 循环的“猛兽”。我们稍后会看到它非常强大，但现在我只想讨论按特定次数循环的情况。（与在条件为真时循环相对。）

下面是一个使用 for 循环和名为 range() 的函数打印从 0 到 9 的数字的示例。（range() 会返回一种称为迭代器（iterator）的东西。更多关于迭代器的内容将在后续章节中介绍——现在，只需了解它们如何与 for 循环一起使用即可。）

```
for i in range(10):  # loop from 0 to 9
    print(i)
```

注意几点：

- i 是循环索引的经典变量名。
- 如果你有嵌套循环（循环中的循环——稍后会详述），可以使用 j，然后 k，等等。
- 我们会一直循环到 range() 参数之前的一个数。到达但不超过该参数。

但等等，还有更多！range() 多才多艺！它不仅能从零数到接近某个数字，你还可以给它另一个起始点：

```
for i in range(5, 10):  # loop from 5 to 9
    print(i)
```

现在你愿意出多少钱？它能切片、能切丁！但我们还没说完！你还可以告诉 range() 每一步跳过多少！

但我们如何反复询问，直到用户输入有效内容为止？我们需要循环！在输入无效时循环如何？当然可以！

```python
input_valid = False  # Assume it's invalid to start

while not input_valid:  # While not input valid ("while input invalid")
    x = input("Enter a number, 5-50 inclusive: ")
    x = int(x)

    if x >= 5 and x <= 50:
        input_valid = True  # We got a good number!
```

让我们研究一下这个模式，因为这是 while 的一种常见用法。

我们首先假设成功条件未满足。然后在每次循环迭代中用 if 检查它是否满足。并且只要成功条件不为真，我们就继续循环。

现在，如果输入超出范围，我们还应该打印一条错误信息。怎么做？用两行代码就能做到。

如果 if 条件为 True，则输入有效。否则输入无效，我们应该打印一条消息……用 if...else！

（注意：下面的代码是上面程序的延续。请留意行号！）

```python
if x >= 5 and x <= 50:
    input_valid = True  # We got a good number!
else:
    print("The number must be between 5 and 50, inclusive!")
```

如果你还没有这样做，请编写这段代码并运行它。不，它不是完整的程序，但它是程序的完整第一步，我们可以先测试它再继续，以确保这部分正常工作。

运行它，并输入一些数字试试。如果你输入无效数字，它应该会提示你并再次询问。如果你输入有效数字，input_valid 变为 True，while 循环就会退出（因为继续条件是 not input_valid，此时它为 False）。

一旦你确认它运行正确，让我们回到规格说明，专注于打印星号。

### 解决问题的步骤：设计计划

如果用户输入 x，我们总共要打印 x 个字符。其中前 30 个将是 #，之后的将是 *。

在开始之前，让我们使用一种不同的规划技巧：简化问题。

让我们暂时忽略 *，只打印用户指定数量的 # 字符。稍后我们再为 * 添加代码。

> > 简化问题可以让你更容易地处理它，并引导你找到之后添加缺失功能的方法。

这个简化阶段的计划并不难：

对于用户输入的数量：
    打印一个 '#'。

### 解决问题的步骤：执行计划

因为我们知道要打印多少个 #（用户输入了数字！），所以这里非常适合使用 for 循环。让我们打印这些 #：

```python
# Print the line
for i in range(x):
    print("#")
```

运行它！结果如何？

嗯。看起来它把井号打印在每一行上。print() 函数会在行尾添加一个换行符。我们需要覆盖该行为，有一种简单的方法可以做到。

```
# Print the line
for i in range(x):
    print("#", end="")  # Set the end-of-line character to nothing
print()  # Add a newline to the end of the line
```

我们在那里施展了一点魔法。我们向 print() 传递了另一个参数，告诉它我们希望在行尾放置一个空字符串（""），而不是它通常附加的换行符。

你甚至可以发疯，写成 end="Beej"，它会在每个井号后面加上单词 "Beej"。试试吧。发疯去吧。

快成功了！但我们还没有脱离困境。我们需要让它做到：当字符超过 30 个之后，打印 * 而不是 #。

### 解决问题的步骤：设计计划

这类似于之前打印一行的计划，但还记得吗？我们当时简化了它。所以现在需要增加一些复杂性以满足规格要求。

对于用户输入的数量：
如果我们在第 30 个字符或之前：
    打印一个 "#"。
否则：
    打印一个 "*"。

这看起来非常适合在我们的 for 循环中使用 if！

### 解决问题的步骤：执行计划

让我们在最后的 for 循环中添加这个 if 逻辑：

```
# Print the line
for i in range(x):
    if i < 30:
        print("#", end="")  # Set the end-of-line character to nothing
    else:
        print("*", end="")
print()  # Add a newline to the end of the line
```

这里有一些微妙但重要的点需要注意：

- 如果用户输入 40，则 i 的值从 0 运行到 39，因为当 i 达到最大值时，for 循环体不会执行。
- 但 0 到 39 仍然有 40 次迭代，对吗？就像 0、1、2、3 总共有 4 次迭代一样。所以即使计数器从 0 运行到 39，我们仍然得到了全部 40 个字符。
- 不过，由于计数器从 0 开始，这意味着最后一个会是 # 的字符发生在 i 为 29 时，而不是 i 为 30 时。这就是我们测试 i < 30 而不是 i < 31 的原因。

就这样，我们完成了！

一定要用边界情况测试。边界情况是指那些位于程序条件边缘的输入。

例如，我们有对输入与 5 和 50 进行比较的条件。所以用 4、5、50 和 51 来测试，覆盖这些条件的两侧。

代码中还有哪里存在边界情况？对了：打印时的 if。前 30 个应该是 #，之后是 *。所以用 30 测试，确保全部是 #；然后用 31 测试，确保有一个 *。

测试边界情况是一种强大的编程技巧，所有开发者都会充分利用它。
