## 12.7 导入特定属性

有一种 `import` 的替代语法，可以用来将模块中的属性直接引入到全局命名空间中。

我是什么意思？

关键是，如果你厌倦了在访问某个特定函数或数据时输入模块名后跟一个点，你可以改为直接引入使用。

我们来做一个例子。

time 模块有一个名为 `ctime()` 的函数，它以经典格式打印时间。

```python
import time

print(time.ctime())  # "Sun Feb  9 13:37:00 2020"
```

但如果你要反复调用它，代码里到处都是 `time.` 就会显得很糟糕。

我们可以这样做：

```python
# Bring in ctime() explicitly:

from time import ctime

print(ctime())  # Look, ma! No "time."!
```

如果一个模块中有多个你想要导入的东西，你可以用逗号列表将它们引入：

```python
# import all three!

from time import ctime, localtime, monotonic
```

或者，如果你感觉大胆，可以全部导入！

```python
from time import *
```

但我通常不建议这样做。Python 执行它需要时间，如果你只需要几样东西，就明确指定它们。

此外，很多开发者依赖模块名作为视觉提示，表明我们正在谈论模块中的函数。如果我们遇到如下代码：

```python
print(ctime())
```

这是程序员自己定义的函数，还是我们从某处导入的东西？把模块名放在前面有助于缓解这种歧义：

```python
print(time.ctime())
```

所以一般来说，我只有在这样做能让代码明显更易读时，才使用 `from ... import`。

记住：可读的代码就是高价值的代码！
