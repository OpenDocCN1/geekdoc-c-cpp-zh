
```
round(2.5)  # 2
round(3.5)  # 4
```

你还可以告诉 round() 你想四舍五入到多少位小数：

```
round(3.1415926, 4)  # 3.1416
```

请注意，由于浮点数精度的限制，Python 还有一些奇怪的舍入行为⁶。

若要始终向上或向下取整，请使用 math 模块中的 ceil() 和 floor() 函数。

ceil() 返回大于该数字的下一个整数，而 floor() 返回小于该数字的前一个整数。

对于正数来说，这一点非常合理：

```
import math

math.ceil(2.1)  # 3
math.ceil(2.9)  # 3
math.ceil(3.0)  # 3
math.ceil(3.1)  # 4

math.floor(2.1)  # 2
math.floor(2.9)  # 2
math.floor(3.0)  # 3
math.floor(3.1)  # 3
```

但对于负数，它的行为方式可能与你预期的不同：

```
import math

round(2.3)      # 2
math.floor(2.3) # 2

round(-2.3)     # -2
math.floor(-2.3) # -3 (!!)

round(2.8)      # 3
math.ceil(2.8)  # 3

round(-2.8)     # -3
math.ceil(-2.8) # -2 (!!)
```

round() 会取最接近的整数，而 floor() 会取下一个更小的整数。对于负数，就是离零更远的那个整数。而 ceil() 则正好相反。

如果你希望有一个能同时处理正数和负数的向上取整函数，你可以编写一个类似这样的辅助函数：

```
import math

def round_up(x):
    return math.ceil(x) if x >= 0 else math.floor(x)

round_up(2.0)  # 2
round_up(2.1)  # 3
round_up(2.8)  # 3

round_up(-2.0)  # -2
round_up(-2.8)  # -3
```

我把 round_down() 留作练习。:)

```
round_up(-2.1)  # -3
round_up(-2.8)  # -3
```

如果你希望始终向上取整到下一个整数，而不是采用银行家舍入法，可以使用这个技巧：将数字加上 0.5，然后将其转换为 int()。（如果数字为负数，则减去 0.5。）

```
int(0.5 + 0.5)  # 1
int(1.5 + 0.5)  # 2
int(2.5 + 0.5)  # 3

int(2.8 + 0.5)  # 3
int(2.2 + 0.5)  # 2

int(-2.2 - 0.5)  # -2
int(-2.8 - 0.5)  # -3
```

### 15.13 大数

Python 非常擅长处理大整数。事实上，它拥有我们所说的*任意精度整数运算*能力。这意味着我们可以保存大到内存能处理的数字，而这个数字可以非常大。

所以如果你让 Python 计算 100000!，它会照做。顺便提一下，结果有 465,575 位数字。完全没问题。

但浮点数（带小数点的数字）则*并非如此*。Python 通常用 64 位来表示浮点数，这意味着精度是有限制的——你的数字最多只能有 16 位，不过你可以把它提升到巨大的正次幂或负次幂，从而得到非常大或非常小的数。

浮点数非常出色，因为它能表示极大和极小的数字，但你能使用的位数是有限的。

### 16.1 什么是 REPL？

REPL，发音为 REP-al，是 Read-Evaluate-Print Loop（读取-求值-打印循环）的缩写。

很好。我是说，真的，非常棒。

但这到底是什么意思？！

看这里。如果你在命令行（或你操作系统的任何变体）中运行 Python，你会看到一个像这样的提示符：

```
$ python
Python 3.8.0 (default, Oct 23 2019, 18:51:26)
[GCC 9.2.0] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>>
```

它就坐在那里，等待你输入内容。

实际上，它正在读取。也就是 REPL 中的 Read 部分。

所以输入点什么，然后按回车！

```
>>> print("Hello, world!")
Hello, world!
```

按下回车后发生的事情是，Python 对你的表达式进行了求值，并打印了结果。然后它又打印了一个 >>> 提示符，因为它在循环中执行这一切！这就是 REPL！

你可以用这种方法来快速测试 Python 命令以了解它们的运作方式。它通常不用于开发，但如果方便，它就在那里。

任何时候你看到 >>> 提示符，它都在等待下一条 Python 命令。

```
>>> a = 20
>>> b = 30
>>> c = a + b
>>> print(c)
50
```

那么多行命令呢？让我们试试在循环中打印数字：

```
>>> for i in range(5):
...
```

等等！那个 ... 提示符是什么？那意味着 Python 正在等待更多内容。上一行以冒号结尾，表示后面会有一个代码块。所以 Python 正在等待一个缩进正确的代码块。（在空行上按回车可退出该代码块。如果你卡在 ... 模式中，只需不断按回车，直到回到 >>> 提示符。）

那不是 Python。它是文档，并且有自己的阅读方式。

一般来说：

S. 指的是我们正在操作的字符串。例如，如果我说：

在文档中，字符串 "fee fie foe foo" 由 S 表示。

-> 后面的内容表示返回值的类型。这个函数返回一个整数。

在文档中，方括号表示函数的可选参数。注意在上面的例子中，我没有传入 start 或 end……它们位于方括号中，所以是可选的。

更仔细地看，你会发现方括号是嵌套的。这意味着你可以使用 sub 和 start 进行调用……然后 end 变为可选。不存在仅使用 sub 和 end 而不提供 start 的调用方式。可选参数 end 仅在可选参数 start 已经指定的情况下才可选。

### 16.4 dir()——快速而粗略的帮助

内置函数 dir() 与 help() 类似，但极其简短。它只是返回某个特定对象上的方法列表。

例如，我们可以通过调用 dir({})（或将任何字典传给 dir()）来获取字典上附加的方法和数据列表。

 '__doc__', '__eq__', '__format__', '__ge__', '__getattribute__',

虽然不如 help() 好，但如果你在想“我该调用什么来从字典中取出值来着？哦，对了。values()！我找到了！”，它可能会让你快速得到答案。

### 16.5 退出 REPL

由于 REPL 将键盘作为“文件”读取，你应该发送一个 EOF（文件结束²）字符来表明它应该结束了。

在 Mac、Linux、BSD、Ultrix、MINIX、SunOS、IRIX、HP-UX、Solaris、GNU Hurd、Plan 9 From Bell Labs 以及任何 Unix 变体上，从键盘输入 CTRL-d 表示 EOF。

在 Windows、Windows、Windows、Windows 以及任何 Windows 变体和 MS-DOS 上，从键盘输入 CTRL-z 表示 EOF，随后按回车。

此外，在任何系统上，你都可以在 >>> 提示符下输入 exit() 来退出。
