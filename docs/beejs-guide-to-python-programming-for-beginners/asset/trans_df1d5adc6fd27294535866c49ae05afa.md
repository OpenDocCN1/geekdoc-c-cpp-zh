## 13.4 以经典方式读取文件

问题解决步骤：理解问题。

在许多编程语言中，读取文件有三个步骤：

- 1. 打开文件以进行读取。
- 2. 从文件中读取数据。
- 3. 关闭文件。

这是非常非常常见的。
“打开”和“关闭”文件是什么意思？
嗯，这类似于你在编辑器中打开文件然后关闭它。
“打开”是指请求操作系统¹（OS）给你访问文件的权限。你可以打开以进行读取、写入或两者兼有。
对于本节，我们希望请求 OS 打开文件以进行读取。
“关闭”文件与打开相反。我们告诉 OS 我们已完成文件的使用。OS 会进行必要的清理。你应该始终关闭打开的任何文件。（你打开的所有文件在程序运行完成后会自动关闭，但你仍应显式关闭它们²。）
而“读取”实际上是将磁盘上的文件数据拉入内存中的字符串。

问题解决步骤：制定计划
让我们编写一些代码³来读取我们的 wargames.txt 文件并在屏幕上打印出内容。
我们的步骤将是：

- 1. 打开文件
- 2. 读取数据
- 3. 关闭文件
- 4. 打印数据

## 问题解决步骤：执行计划

```
# Open the file
f = open("wargames.txt")

# Read all data from the file
data = f.read()

# Close the file
f.close()

# Print out the data we read earlier
print(data)
```

需要注意的一些事项：

- - 我们打开文件时没有指定读取或写入。在 Python 中，默认是“读取”。
- - 注意我们在打印任何内容之前就关闭了文件。我们不必这样做，但它演示了我们现在如何在内存中拥有数据的副本。我们仍然可以使用它，即使我们已经关闭了文件。

由于我们有数据的副本，我们可以做各种各样的事情来更改它。

如果你将最后两行修改为：

```
# Print out the data we read earlier
print(data.upper())
```

我们将得到大写输出。（但原始文件当然仍然是小写！）这是我们的副本，可以随意使用！

## 13.5 使用 with 打开文件

现在有一种更规范⁴的方法使用 Python 中的 with 语句读取文件。

之前，我们读取文件

```
f = open("wargames.txt")
data = f.read()
f.close()
print(data)
```

使用 with 语句的等价形式如下所示：

```
with open("wargames.txt") as f:
    data = f.read()
    print(data)
```
