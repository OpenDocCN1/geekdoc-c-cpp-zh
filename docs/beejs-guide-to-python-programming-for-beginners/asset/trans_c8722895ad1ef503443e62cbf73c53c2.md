
你想出的任何解决方案都可能在解决错误的问题！当你能把问题完全解释给别人听时，你就知道你已经理解它了。

### 2. 制定计划

你打算如何利用手头的工具和你所学的技术来解决这个问题？当你能轻松地把计划转换成代码时，你就知道计划已经制定好了。

通常在制定计划时，你会意识到对问题还有某些方面没有完全理解。这时只需暂时回到第 1 步，直到弄清楚，然后再回来继续制定计划。

### 3. 执行计划

将你的计划转换成代码并让它运行起来。

在这个阶段，你往往会发现要么有你不理解的地方，要么有计划没有考虑到的地方。后退一两步，直到问题解决，然后再回到这里。

### 4. 回顾

回顾你写好的代码，思考哪些做对了，哪些做错了。下次你会有什么不同的做法？在编写代码时你学到了哪些技巧？有没有什么地方可以更好地组织代码，或者有没有什么地方可以删除冗余代码？

有趣的是，开发人员将问题解决的步骤应用于整个程序，也应用于程序内部的更小问题。一个大的计算问题总是由许多子问题组成！问题解决框架被嵌套使用于问题解决框架之中！现实生活中的一个问题可能是“盖房子”。但这由许多子问题组成，比如“打地基”、“搭墙架”和“盖屋顶”。而这些子问题又由子子问题组成，比如“平整土地”和“浇筑混凝土”。在编程中，我们把问题分解成越来越小的子问题，直到我们知道如何用已知的技术来解决它们。如果我们不知道解决它的技术，就去学一个！成为一名开发者就等于成为一名问题解决者。问题并不容易，但这就是为什么它能带来丰厚回报。所以你应该有这样的预期：无论你在这本书、编程挑战网站、学校还是工作中看到编程问题，答案都不会显而易见。你需要付出许多努力并花上大量时间去完成最初的问题解决步骤，然后才有资格开始编码。

### 2.5 什么是 Python？

Python 是一种编程语言。这意味着人类大致能读懂它，而机器可以完全读懂它。（前提是你不要犯哪怕最微小的错误！）这是一个很好的组合，因为人们不擅长阅读机器使用的实际代码 10110101010110。我们使用这些高级语言来帮助我们应对。

在这种情况下，另一个名为 Python 解释器的软件会读取我们用 Python 语言编写的代码并运行它，执行我们请求的操作。

所以在开始之前，我们需要安装 Python 解释器。这是整本书中最令人恼火和痛苦的部分之一，但幸运的是只需要做一次。

你以为所有代数都没用……哼！

在编程中有一个常见模式，比如你想给一个变量加上 5。不管它现在是什么值，我们都希望它比当前值多 5。

我们可以这样做：

```python
x = 10
x = x + 5  # x = 10 + 5 = 15
```

这种模式非常常见，因此我们可以使用一种简写形式。

这两行代码是等价的：

```python
x = x + 10
x += 10
```

下面这两行同样等价：

```python
x = x / 5
x /= 10
```
