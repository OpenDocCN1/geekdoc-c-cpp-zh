A refresher: with equations of the form:

a x² + b x + c = 0

you can solve for x with the quadratic formula:

x = (-b ± √b² - 4ac) / 2a

Your program should plug a, b, and c into the above formula and print out the result value in x.

Make sure b² ≥ 4ac or there won't be a solution and you'll get a "domain error" when you try to take the square root of a negative number. Some test values for a, b, and c that work: 5, 9, 3, or 20, 140, 60.

What is that ± symbol after -b in the equation? That's "plus or minus". It means there are actually two equations, one with + and one with -:

x_plus = (-b + √b² - 4ac) / 2a   x_minus = (-b - √b² - 4ac) / 2a

Solve them both and print out both answers for a given a, b, and c.
