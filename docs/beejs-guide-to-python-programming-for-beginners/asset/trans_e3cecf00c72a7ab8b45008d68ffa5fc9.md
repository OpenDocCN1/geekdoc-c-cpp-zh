

```
except IOError as e:
    print(f'head.py: {filename} {e.strerror}')
```

当我们运行它时，无论遇到哪种错误情况，都会得到一条友好的错误信息：

```
$ python head.py noperm.txt 5

$ python head.py / 5
head.py: / Is a directory

$ python head.py nofile.txt 5
head.py: nofile.txt No such file or directory
```

相当简洁！

还剩下什么？哦，对了——我们还需要真正实现“只显示文件前若干行”这个功能。

有几种处理方式。

第一种，我们可以用 `while` 循环，并测试是否到达文件末尾或是否达到所需行数，以先到者为准。

那样做没问题。但更直接的做法可能是在计数器达到足够大时直接跳出循环。`break` 语句可以在循环进行到一半时退出循环。

```
line_count = 0  # Number of lines we've read so far

try:
    with open(filename) as f:
        for line in f:
            line_count += 1
            if line_count > total_count:
                break
            print(line, end="")

except IOError as e:
    print(f'head.py: {filename} {e.strerror}')
```

如你所见，我们一直记录已读取的行数，一旦超过目标行数，就直接跳出循环，然后就完成了。

而且它确实可以工作！

```
$ python head.py rocks.txt 3
marble
coal
granite
```

对错误输入和异常情况都非常健壮。这就是我们所说的**防御性编程**：你为最坏情况做好准备，并处理这些情况而不至于崩溃。这是一个好策略，因为它不仅让程序能更好地处理错误，还迫使你停下来想一想，一开始可能会出现哪些错误。而且，正如我们所说，数小时的调试可以节省你几分钟的规划时间。

### 15.1 算术

加法、减法、乘法，还有——别这就睡着了——除法。小学四年级数学的“四大天王”。

作为快速术语总结：

- 两个数相加的结果叫*和*。
- 两个数相减的结果叫*差*。
- 两个数相乘的结果叫*积*。
- 两个数相除的结果叫*商*（还可能有一个*余数*）。

我不打算讨论这些运算符是做什么的，并假定你从多年前就还记得。

但我想谈谈运算顺序，因为你可能已经忘了。

我是什么意思？

看这个表达式：1 + 2 × 3

如果我们先算 1 + 2，得到 3。然后乘以 3，得到答案 9。

但等等！如果我们先算 2 × 3 得到 6，然后加 1，得到的答案是 7！

所以……到底是哪个？9 还是 7？

我们需要知道的是*运算顺序*，即一个运算符相对于另一个运算符的*优先级*。哪个先算，+ 还是 ×？

对于算术，规则是：先做所有乘法和除法，再做所有加法和减法。

### 15.4 负数

我在这里不多讲，但负数是小于 0 的数，用数字前面的减号表示。−7 表示“比 0 小 7”。

我知道这是个疯狂的概念。比如，桌子上怎么会有 −12 个苹果？这似乎不太符合实际。

但一个更贴近生活的例子可能是我说：“我欠你 −35 美元！”这实际上意味着，你欠我 35 美元！

记住一些简单的规则：

负数乘以负数，结果是正数。

−3 × −7 = 21

负数乘以正数，结果是负数。

−3 × 7 = −21

负数加上正数，就像从正数中减去这个负数：

−7 + 100 = 93

或者，等价地：

100 + (−7) = 100 − 7 = 93

### 15.5 绝对值

可以把绝对值想象成数轴上任何数离 0 有多远。

10 离 0 有 10 远。10 的绝对值是 10。

2.8 离 0 有 2.8 远。2.8 的绝对值是 2.8。

嗯，这似乎有点平淡。为什么要费心？

原因在这里：

−17 离 0 有 17 远。−17 的绝对值是 17。

规则是：

- 正数的绝对值是它本身。
- 负数的绝对值是它的相反数，也就是它的正数版本。

总而言之，如果是负数，绝对值会把它变成正数。

在数学符号中，我们用竖线表示绝对值：

x = −17 如果 x 是 −17...
|x| = 17 ...那么 x 的绝对值是 17。
|12| = 12 12 的绝对值是 12。
| −13.8 | = 13.8 −13.8 的绝对值是 13.8。

在 Python 中，我们使用内置函数 `abs()` 计算绝对值：

```
print(abs(-17))  # 17
print(abs(28.2))  # 28.2
```

就优先级而言，你可以把绝对值看成类似括号的东西。先计算绝对值内部的内容，然后再对结果取绝对值。

### 15.6 指数的威力

假设你想把数字 7 自己乘自己，比如 8 次。我们可以这样写：

7 × 7 × 7 × 7 × 7 × 7 × 7 × 7

我想这还不算太糟。

那就更进一步。我想把 7 自己乘自己 3490 次。你处理这件事的时候，我要去酒吧了。完成后告诉我。

幸运的是，数学家们很懒。他们讨厌多写东西，所以凭空发明新的记法来避免额外的工作。就像我不断把厨房垃圾压实，这样就不用跑出去倒一样。

实际上，不，真的不是那样²。

所以他们发明的是另一种表示“3490 个 7 相乘”的方式，不用写一长串 7 和 ×。它看起来像这样：

7³⁴⁹⁰（读作“7 的 3490 次方”）

这意味着 3490 个 7 相乘。我们把这称为“幂运算”或“乘方”。

或者，换句话说：

7⁸ = 7 × 7 × 7 × 7 × 7 × 7 × 7 × 7

我们有很多有趣的事实！准备好了吗？

在例子 7⁸ 中，数字 7 我们称为*底数*，数字 8 我们称为*指数*。

如果你想在 Python 中写这段代码，你会写：

```
print(7**8)  # 打印 5764801
```

指数必须是非负数，也就是零或更大。

但等等——零？你怎么把一个数自己乘零次？这是个合理的问题，也是自古以来困扰哲学家的问题。但数学家不会！就像权力狂热的数字独裁者一样，他们喊道：“这是我们发明的，我们宣布任何数的零次方都是 1。到此为止！”

所以就是这样。n⁰ = 1，对所有 n 成立。

² 除了懒惰的因素外，其实真不是那样。
