
## 14.7 捕获多个异常

问题解决步骤：理解问题

如果你的 try 块抛出多个异常怎么办？

原来你只需拥有多个 except 子句即可捕获多个异常。

让我们试一个将一个数除以另一个数的程序：

```python
x, y = input('Enter two numbers separated by a space: ').split()

x = int(x)
y = int(y)

print(f'{x} / {y} == {x / y}')
```

可能抛出哪些异常？

好问题。虽然有一个内置异常的列表³，但并不是很明显何时抛出哪个异常。

最简单的做法是在 REPL 中尝试。但尝试什么？

像反派一样思考。会有什么事情出错？可以向这个程序传入哪些糟糕的输入？

好好想想。我数出四种因用户输入错误而可能出错的情况。你能看出吗？

嗯，我们在获取输入，通过 .split() 处理，然后将结果赋给两个变量。所以 split() 最好返回长度为 2 的列表，否则就会出问题。

我要把那行代码放到 REPL 中看看，如果我输入的不是用空格分隔的两个数字会怎样。

```
>>> x, y = input("Enter 2 numbers: ").split()
Enter 2 numbers: 1
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ValueError: not enough values to unpack (expected 2, got 1)
```

看吧！我输入了一个数字，它抛出了 ValueError 异常（消息说值不够）。

让我们试试太多值的情况：

```
>>> x, y = input("Enter 2 numbers: ").split()
Enter 2 numbers: 1 2 3
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ValueError: too many values to unpack (expected 2)
```

又是 ValueError！这意味着我们可以这样做来捕获它：

```python
try:
    x, y = input('Enter two numbers separated by a space: ').split()
    x = int(x)
    y = int(y)
    print(f'{x} / {y} == {x / y}')
except ValueError:
    print("That's not two numbers separated by a space!")
```

这样就能捕获它了。这里有一个运行示例：

```
Enter two numbers separated by a space: 1 2 3
That's not two numbers separated by a space!
```

耶！

下一个可能出错的地方是什么？

嗯，我们正在转换为 int()... 如果传入一些糟糕的东西，比如单词 manfrengensenton，这个函数会做什么？

再次在 REPL 中：

```
>>> int("manfrengensenton")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ValueError: invalid literal for int() with base 10: 'manfrengensenton'
```

嘿，又是 ValueError！很方便，我们已经用合适的错误消息捕获了它。完全处理了。

这解决了我看到的四种可能引发异常的情况中的三种。第四种是什么？

- 戴上数学帽。你看出来了吗？

没错，我们在那里进行除法... 而除以零是不允许的。做了会怎样？

我们上面已经看到，会得到一个 ZeroDivisionError。所以让我们把它加到代码末尾：

```
try:
    x, y = input('Enter two numbers separated by a space: ').split()
    x = int(x)
    y = int(y)
    print(f'{x} / {y} == {x / y}')
except ValueError:
    print("That's not two numbers separated by a space!")
except ZeroDivisionError:
    print("Can't divide by zero!")
```

所以正如你所见，你可以在 try 之后用各自的 except 子句处理任意多种不同类型的异常。

## 14.8 捕获多个异常 II

如果你想用相同的处理代码处理多个异常，可以将它们做成一个列表：

```
except (FileNotFoundError, PermissionError):
    print("File not found or insufficient permissions")
```

这并不常用，因为通常你希望对不同的异常采取不同的处理方式。

## 14.9 获取更多异常信息

每个异常实际上都是一个类的实例。而类名就是你在 except 子句中使用的名称。

因为它是实例，所以它附带了一些我们可以获取的额外信息，但首先，我们必须将其绑定（赋给）一个变量名。我们可以用 as 语句做到这一点。

```python
try:
    1 / 0
except ZeroDivisionError as e:  # e is a reference to the exception
    print(e)
    print(repr(e))  # Print its representation
```

结果为：

division by zero
ZeroDivisionError('division by zero')

这对于获取更详细的信息可能很有用。在上一章的示例中，我们捕获 ValueError，但我们看到了三种可能导致它的不同情况。我们可以使用这种技术在需要时向用户提供有关异常性质的更详细信息。

所有异常都有一个名为 args 的属性，它是创建异常时传入参数的列表。其中第一个通常是人类可读的错误消息。

例如，这段代码：

```python
try:
    1 / 0
except Exception as e:
    print(e.args[0])
```

打印出有用的消息：

division by zero

此外，任何基于 IOError 的异常都包含字符串属性 strerror，其中包含与错误对应的人类可读错误消息。你可以在异常文档²中找到从 IOError 派生的异常列表。

## 14.10 捕获所有异常

不指定特定异常的 catch 语句会捕获所有先前未捕获的异常。

因此，空白的 catch 应该 definitely 放在最后，在所有其他 catch 之后。Python 会在第一个匹配的 catch 处停止，即使它是“捕获所有”。

当你在任何 catch 中时，你可以查看内置函数 sys.exc_info() 的结果。该函数返回一个元组（如果你不熟悉元组，就把它想成“列表”）包含三条信息：异常的类型、对异常本身的引用，以及 traceback³。

让我们修改我们的除法程序以捕获所有异常并打印出异常信息：

```python
import sys

try:
    x, y = input('Enter two numbers separated by a space: ').split()
    x = int(x)
    y = int(y)
    print(f'{x} / {y} == {x / y}')

except:
    print(sys.exc_info())
```

这里有一些示例运行：

```
Enter two numbers separated by a space: 1
(<class 'ValueError'>, ValueError('not enough values to unpack (expected 2, got 1)'), <traceback object at 0x7f789974f8b0>)
```

```
Enter two numbers separated by a space: a b
(<class 'ValueError'>, ValueError('invalid literal for int() with base 10: 'a''), <traceback object at 0x7f6d0c9732c0>)
```

```
Enter two numbers separated by a space: 1 0
(<class 'ZeroDivisionError'>, ZeroDivisionError('division by zero'), <traceback object at 0x7fe2ea373040>)
```

这种方式捕获并检查异常并不常见。但它是你工具箱中的另一个工具。

谨慎使用捕获所有。它们可能会隐藏你未预料到且本应放行的异常。实际上它们很少见。

## 14.11 最后 finally

问题解决步骤：理解问题

这里有一个更大的结构。我们已经讨论过 try 和 catch，但有一种方法可以添加无论发生什么、无论是否发生异常都会运行的代码。

它是 finally 子句，位于 except 子句之后。

再次强调，这段代码无论如何都会运行。

```
try:
    print(1/1)
except ZeroDivisionError:
    print("Divide by zero!")
finally:
    print("All done!")
```

上述代码将打印：

```
1
All done!
```

如果我们把第一行改为 print(1/0)，我们会得到除零异常，输出将是：

```
Divide by zero!
All done!
```

在所有情况下，finally 块都会运行。

如果需要，你可以使用这个块来执行最终化或清理代码。

try-except 非常常见。finally 则没那么常见，但也不算完全罕见。
