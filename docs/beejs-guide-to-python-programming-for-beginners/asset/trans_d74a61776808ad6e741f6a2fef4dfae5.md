
过程与读取类似，只是当我们打开文件时，需要指定我们想要写入。（如果我们不另外告诉 open()，它会假设我们是打开用于读取。）

**警告：** 如果你以写入方式打开一个已有文件，该文件的内容会立即丢失！

让我们打开一个文件并使用 write() 方法向其中写入一些数据。

```
with open("newfile.txt", "w") as f:
    f.write("Hello, world!\n")
```

好了！如果你运行它，然后查看一下，你会看到一个名为 newfile.txt 的文件，其中包含那些神奇的文字。

现在你有能力将数据保存到磁盘并再次读取！

### 问题解决步骤：制定计划

看起来下一步合理的步骤是将文件读入内存，以便以后可以操作它。

那么有几个问题：

对于第一个问题，希望你一直在阅读本章，并了解如何打开文件进行读取以及如何从中读取单行。

但是如何保存所有这些行呢？

想想我们到目前为止讨论过的所有数据结构……列表、字典、对象……文件最像什么？

在接下来的几句话中我剧透之前，先好好想想。

你可能会争辩说每一行都像一个对象。是的。拥有一个代表行的类也不会错。但无论如何你仍然需要存储一个行列表。

是的，列表似乎是个好主意。从某种意义上说，文本文件只是一个行列表。

所以让我们一次读取文件一行，并在过程中将其存储到列表中。

这看起来像是一段自包含的代码，所以我将编写一个函数，它接受文件名作为参数，然后返回该文件中所有行的列表。

- 创建一个空列表
- 打开文件
- 对于文件的每一行，将其追加到列表中
- 返回列表

### 问题解决步骤：执行计划

```python
def read_file(filename):
    """Read a file from disk"""
    lines = []

    with open(filename) as f:
        for line in f:
            lines.append(line)

    return lines

if filename is not None:
    lines = read_file(filename)
else:
    lines = []

# Print it out just to make sure it works right
print(lines)
```

现在如果我们运行它并指定输入文件名，它应该打印出包含该文件中所有行的列表。

当然，我们需要一个示例输入文件。你可以在 VS Code 中创建一个——只需编辑一个名为 lines.txt 的新文件并在其中放入你想要的内容。（大约五行适合测试。）如果你不想麻烦，examples 目录中有一个 lines.txt 文件。

### 问题解决步骤：制定计划

这就像我们到目前为止做过的许多其他输入循环一样：

- 打印提示
- 解析输入
- 运行命令
- 当用户说退出时停止循环

### 问题解决步骤：执行计划

你的标准输入循环。它唯一能做的就是让你输入 q：

```
# Main loop

done = False

while not done:
    command = input("> ").strip()

    if command[0] == 'q':
        done = True
```

如果你按 RETURN，它会立即报错，因为如果字符串为空，command[0] 就不存在。

这里常见的操作是如果用户输入空行就打印另一个提示。我们可以在 input() 行之后添加以下内容来实现：

```
# if the user entered a blank line, just give them another prompt
if command == '':
    continue
```

最后，让我们添加一些输出作为 else，以告诉用户如果他们输入了我们不识别的内容：

```
else:
    print("unknown command")
```

好的！现在如果我们运行它，我们应该能够处理空行、未知命令以及 q 退出。

```
>

```
