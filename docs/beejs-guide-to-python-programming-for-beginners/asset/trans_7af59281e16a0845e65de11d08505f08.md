

Vim 是一个复杂且难以学习的编辑器。但一旦你学会了它，我坚持认为它是这个星球上最快的编辑器。我现在就用它来输入这句话。

要学习它，我推荐 OpenVim 的交互式 Vim 教程，以及这份从入门到精通的 Vim 命令参考。

将以下内容⁶输入到你的编辑器中（下面的行号仅供参考，不应输入）：

```
print("Hello, world!")
print("My name's Beej and this is (possibly) my first program!")
```

打开“文件 → 保存”菜单来保存文件。

## 19.8 运行程序！

回到你的终端窗口，输入 ls -la 来获取目录列表：

```
$ ls -la
total 8
drwxr-xr-x  3 beej  staff   96 Nov 18 23:27 .
drwxr-xr-x+ 123 beej  staff 3936 Nov 18 23:14 ..
-rw-r--r--  1 beej  staff   87 Nov 18 23:27 hello.py
```

就在那里！hello.py 的大小为 87 字节（大致相当于字符数）。

让我们来运行一下这个小家伙吧。还记得程序只是做某件事的配方吗——你觉得我们的 hello.py 程序会做什么呢？猜一猜！

然后输入以下命令来运行它（如果 python 不行，根据你的系统尝试 python3 或 py）：

```
python hello.py
```

然后按下回车键！[天使合唱！]

```
$ python hello.py
Hello, world!
My name's Beej and this is (possibly) my first program!
```

你刚刚写了一些指令，而电脑执行了它们！接下来：写一个《雷神之锤 III》的克隆版！好吧，也许中间可能还有一些我略过的小细节，但正如欧比旺·克诺比曾经说过的：“你已经迈出了进入更大世界的第一步。”
