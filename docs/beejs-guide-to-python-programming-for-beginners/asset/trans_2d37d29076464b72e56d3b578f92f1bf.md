### 简介

*这是一本 alpha 质量的书。里面当然会有错误。如果你发现了，请在 GitHub 上提交 issue，或提交 pull request，或发送电子邮件至 beej@beej.us。当缺陷数量降到足够低时，我会推出印刷版。*

大家好！你们好吗？我的生活相当忙碌，有时候实在无法回答你的问题。在这种情况下，我通常只会删除消息。这不是针对个人；我只是永远没有时间给出你所需的详细解答。

一般来说，问题越复杂，我回复的可能性就越低。如果你能在发邮件之前缩小问题范围，并确保包含任何相关信息（例如平台、编译器、你收到的错误消息，以及任何你认为可能帮助我排查问题的内容），你获得回复的可能性就会大得多。更多建议，请阅读 ESR 的文档《提问的智慧》。

如果你没有得到回复，请继续钻研，尝试找到答案；如果仍然找不到，就再写信给我，附上你已找到的信息，希望这些信息足以让我帮上忙。

在我唠叨完该怎么给我写信、不该怎么写之后，我只想让你知道，我非常感谢这本指南多年来获得的所有赞誉。这确实鼓舞士气，而且听到它被用于好的用途，我也很高兴！:-) 谢谢！
