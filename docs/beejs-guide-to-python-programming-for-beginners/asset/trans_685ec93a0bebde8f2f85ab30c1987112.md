
拥有某种辅助函数，能够按名称查找电影对象，可能会很方便，类似于这样：

```
def find_movie_by_name(movies, name):
    for m in movies:
        if m.name == name:
            return m

    return None  # Didn't find it
```

并用它来稍微清理代码。对于影院也可以有类似的辅助函数。（当然，电影越多，查找所需的时间就越长。字典可能是这里更合适的数据结构。）但这种方法无法处理有两部同名电影或两个同名影院的情况。因此还需要找到另一种变通方法——也许可以用每个影院和电影的唯一标识号作为键？现在……那么将放映时间添加到这一切中的额外目标又该怎么处理呢？

## 解题步骤：理解问题。

这个问题乍一看可能并不棘手，但细节会让你措手不及。你可能会想，没问题，我们只需给 Movie 类添加时间，对吧？是的，但是……不同的影院都在放映同一部电影，但放映时间不同。如果你仔细想想，一部电影的放映时间更像是附着在影院上的数据，而不是附着在电影上的数据。迪士尼说：“今年冬天上映：《星球大战47》，晚上8点和10点！”这毫无意义。他们不知道影院什么时候会放映这部电影！那好吧，那我们就把时间挂到 Theater 类上。

但这又给我们带来了另一个问题。我们如何将一组时间与特定的 Movie 对象关联起来？我们需要在代码中表明它们是关联的，以便可以将它们一起打印出来。

## 解题步骤：制定计划

我们可以用一个新类——称为 MovieTime——来实现，该类既包含对电影的引用，也包含该电影放映的时间列表。然后我们可以将这个新类的实例添加到 Theater 对象中。这样，如果我们有一个对 Theater 的引用，就可以查找其 MovieTime 对象列表，然后对每一个 MovieTime 对象，查找其中包含的 Movie 对象引用，并连同时间一起打印出来。我们在中间插入一个新类，同时持有电影和放映时间。这样就能将它们捆绑在一起。

## 解题步骤：执行计划

让我们添加这个新类，它同时持有对电影的引用及其放映时间：

```
class MovieTime:
    """Holds a movie and the times it is playing"""
    def __init__(self, movie, times):
        self.movie = movie
        self.times = times
```

然后我们需要修改 Theater 类，使其保存 MovieTime 对象列表，而不是 Movie 对象列表。

```
class Theater:
    """Holds all the information about a specific theater."""
    def __init__(self, name):
        self.name = name
        self.movietimes = []  # <-- Now this is MovieTime objects
```

现在，当我们构建影院信息列表时，需要向影院的列表中添加新的 MovieTime 对象。MovieTime 对象包含对所放映电影的引用，以及放映时间列表。

```
# McMenamin's is showing Star Wars and Shaun of the Dead
theaters[0].movietimes.append(MovieTime(movies[0], ["7pm", "9pm", "10pm"]))
theaters[0].movietimes.append(MovieTime(movies[1], ["5pm", "8pm"]))

# Tin Pan is showing Shaun of the Dead and Fastest Indian
theaters[1].movietimes.append(MovieTime(movies[1], ["2pm", "5pm"]))
theers[1].movietimes.append(MovieTime(movies[2], ["6pm", "8pm", "10pm"]))

# Tower is showing all three
theaters[2].movietimes.append(MovieTime(movies[0], ["3pm"]))
theaters[2].movietimes.append(MovieTime(movies[1], ["5pm", "7pm"]))
theaters[2].movietimes.append(MovieTime(movies[2], ["6pm", "7pm", "8pm"]))
```

最后，在打印时，我们需要从 MovieTime 对象中提取电影和放映时间，以便打印：

```
def print_theater(theater):
    """Print all the information about a theater."""

    print(f'{theater.name} is showing:')

    for mt in theater.movietimes:
        m = mt.movie
        t = " ".join(mt.times)  # Make string of times separated by spaces
        print(f'    {m.name} ({m.genre}, {m.duration} minutes): {t}')
```

就是这样！

## 解题步骤：回顾。

除了上一次“回顾”中提到的改进之外，我们也许还能在处理时间的方式上稍作改进。

目前，我们将时间存储为字符串，但更好的做法是将它们存储为 Python 标准库⁸中的 datetime 对象。
