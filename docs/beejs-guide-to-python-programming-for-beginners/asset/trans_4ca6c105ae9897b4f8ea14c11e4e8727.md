
我们在这里开始深入探讨的是面向对象编程的世界。要讨论它的一切肯定会信息过载，所以我们只是在这里从基础开始，后续会重新审视一些概念。

这里有一些术语，延续上面星舰的例子。

首先，我们将构造新的星舰对象，这些对象保存关于一艘船的所有信息。

当对象被构造时，它是基于一个蓝图完成的。我们称这个蓝图为类。

所以我们将在类中定义星舰的蓝图，然后基于该类构建多个不同的星舰。

让我们从尽可能简单的方式开始。这不会是常见的做事方式，但它是一个让你入门的地方。我们很快会改进它。

首先，我们将定义一个新的类。记住，这只是星舰的蓝图——它本身不是一艘星舰。

类名按惯例使用驼峰命名法！让我们定义那个星舰类！

```python
class StarShip:
    pass
```

...就这样？那里的 pass 是什么？

好吧，你抓到我了。出于自卫，我确实说过我们要从简单开始（而且不太正确）。我们那里有一个 StarShip 类，不过它就像一张空白的蓝图。里面什么都没有。

关键字 pass 在 Python 中表示“什么都不做”。它只是用来告诉 Python 这个类内部没有主体。

随机术语事实：我们也说星舰对象是 StarShip 类的一个实例。

构造一个新的星舰对象也被称为从类实例化对象。

让我们继续从蓝图制作几个对象。

```python
class StarShip:
    pass

s0 = StarShip()
s1 = StarShip()
s2 = StarShip()
```

在类名后加上括号，我们是在告诉 Python 我们正从 StarShip 类创建一个新的星舰对象。事实上，我们制作了三个，并将每个的引用分别保存在 s0、s1 和 s2 中。当然，它们目前还没有名字或位置，但我们很快会解决这个问题。

如果我们打印其中一个，会得到类似这样的结果：

```python
print(s1)  # <__main__.StarShip object at 0x7fa11828c8e0>
```

不太好看。但我们很快也会让它变好。

## 11.5 制作不同的星舰

问题解决步骤：理解问题。

在之前的例子中，我们所有的星舰对象都是相同的且不包含任何信息。

我们需要一种方法在星舰构造时传入这些信息。

我们通过在类内部定义一个特殊函数来实现这一点。

另一个有趣的术语事实：在类内部声明的函数称为方法。

这个特殊函数始终命名为 __init__()（带双下划线），称为构造函数。

让我们为我们的 StarShip 类添加一个构造函数，允许我们在构造船只时传入船名：

```python
class StarShip:
    def __init__(self, shipname):  # The constructor
        self.name = shipname

s0 = StarShip("MCRN Tachi")
s1 = StarShip("Red Dwarf")
s2 = StarShip("USCSS Nostromo")
```

哇，现在……有太多难以阅读的标点符号³需要梳理。

而且函数里还有那个奇怪的 self 参数，不知道是什么意思！

让我们从 self⁴ 开始。这是本章中最难理解的概念之一，所以我们会花一些时间在它上面。

还记得类是蓝图，而对象是根据该蓝图制作的吗？

并且在它们被构造后，你会得到对那个新创建对象的引用？（这些就是我们存储在 s0、s1 和 s2 中的引用。）

那么，在 __init__() 方法内部正在构造的对象怎么办？它已经存在但尚未完全初始化。但是在构造函数内部，我们有一个对正在构建的对象的引用。而这个引用就在 self 中。

self 的意思是“该方法正在操作的对象”。

奇怪的是，当我们实例化星舰时，我们只向 __init__() 传递了一个参数。

```python
s0 = StarShip("MCRN Tachi")
```

显然 __init__() 有两个参数：self 和 name。怎么回事？

```python
def __init__(self, shipname):  # The constructor
```

参数的数量不需要与参数的数量匹配吗？

确实需要！但 Python 在这里在你背后做了一些狡猾的事情。当方法为特定对象被调用时，Python 会自动用正在操作的对象填充第一个参数。我们不用担心它。

然后 Python 会取我们实际传递的参数并附加在后面。

让我们再看看那个构造函数：

```python
class StarShip:
    def __init__(self, shipname):  # The constructor
        self.name = shipname

s0 = StarShip("MCRN Tachi")
```

这是一个非常常见的模式，所以让我们确保我们理解这里发生了什么。特别是，self 后面有一个奇怪的点。这是什么意思？但在那之前，让我们先看看 shipname。

当我们创建新的星舰 s0 时，我们传入名称 "MCRN Tachi"。这会调用构造函数 __init__()。

Python 会自动将对现在正在构造的对象的引用放入 self 中。然后它将字符串 "MCRN Tachi" 复制到函数的 shipname 参数中。所以 shipname 是 "MCRN Tachi"。

现在我们到了核心部分。self.name？故事继续！

我们也可以用这种方式修改船只的位置：

```python
s0.location[1] = 99

print(s0.location)  # [0, 99, 0]
```

这很重要！即使我们更改了 s0 属性的值，其他对象（如 s1 和 s2）的属性仍然保持不变！（直到我们明确更改它们。）

我们已成功将单个船只的所有信息捆绑到这个单一对象中。很整洁。

## 11.8 关于方法的更多内容

问题解决步骤：理解问题。

记住方法是可以连接到对象的函数。就像你可以把属性看作对象拥有的东西一样，你可以把方法看作对象做的事情。

让我们再添加一个方法来设置船只位置。

```python
class StarShip:
    def __init__(self, name):  # The constructor
        self.name = name
        self.location = [0, 0, 0]  # <-- Add this

    def set_location(self, x, y, z):
        """Set a ship's location to x,y,z"""

        self.location[0] = x
        self.location[1] = y
        self.location[2] = z

s0 = StarShip("MCRN Tachi")

print(s0.location)  # [0, 0, 0]

s0.set_location(10, 20, 30)

print(s0.location)  # [10, 20, 30]
```

在第 6 行，我们定义了新的方法 set_location()。重要的是，注意第一个参数是 self，它将被初始化为表示我们正在设置位置的对象。（也就是说，当我们调用 s0.set_location() 时，self 在 set_location() 内部将被设置为引用 s0。）

有趣的调试事实：如果你的方法出现参数数量不正确错误，请确保 self 是第一个参数！

然后在第 17 行，当我们在 s0 上调用 set_location() 时，self 被设置为 s0，而 x、y 和 z 分别被设置为 10、20 和 30。

属性！

## 11.9 漂亮打印

现在当我们打印其中一个星舰对象时，Python 会在屏幕上打印类似这样的内容：

```python
<__main__.StarShip object at 0x7fa11b28c9e0>
```

不太有用。让我们覆盖该功能，让它打印更友好的内容。

继续将此方法添加到 StarShip 类中：

```python
def __str__(self):
    """Return string representation of this object."""
    return f'{self.name}: {self.location}'
```

__str__() 方法返回一个字符串，用于在任何时候打印对象时使用。

现在如果我们构建三艘新船并全部打印：

```python
s0 = StarShip("Rocinante")
s1 = StarShip("Red Dwarf")
s2 = StarShip("USCSS Nostromo")

s0.set_location(10, 20, 30)
s1.set_location(40, 50, 60)
s2.set_location(70, 80, 90)

print(s0)
print(s1)
print(s2)
```

我们会得到一些不错的输出，像这样：

```
Rocinante: [10, 20, 30]
Red Dwarf: [40, 50, 60]
USCSS Nostromo: [70, 80, 90]
```

完美！

## 11.10 对象是可变的

当你将一个对象赋给另一个对象时，你不会得到第二个对象。你得到的是对第一个对象的另一个引用。就像列表和字典发生的情况一样。

或者换句话说，用对象进行赋值不会产生新对象。两个变量都是同一个对象的名称。（详情请参阅附录 C。）

```python
class Forest:
    pass

x = Forest()  # Construct a new object
y = x

x.antelopes = 4

print(y.antelopes)  # 4, since y and x refer to the same object
```

这意味着你可以将对象作为参数传递给函数，并且函数可以更改对象属性中的值。

```python
def set_antelopes_to_10(o):
    o.antelopes = 10

class Forest:
    pass

x = Forest()
x.antelopes = 4

set_antelopes_to_10(x)
```
