## 7.8 从字符串中获取单个字符

Problem-solving step: **Understanding the Problem.**

如果我们想从字符串中提取单个字符怎么办？

我们可以做到，但需要引入新的记号来允许它：[ 和 ]，又称方括号。

让我们只打印字符串中的前两个字符：

```python
x = "Beej!"
print(x[0])  # Print character in position 0, "B"
print(x[1])  # Print character in position 1, "e"
print(x[4])  # Print character in position 4, "!"
```

阅读这段代码时，x[1] 会读作“x 下标 1”，是对经典数学记号 x₁ 的致敬。这里的 1 被称为字符串的索引。

**Really important:** 索引号从 0 开始！！字符串中的第一个字符有时在口语中被称为零号字符，第二个字符有时被称为一号字符，接着是二号、三号，等等，以避免歧义。如果你想确保无误，就说“索引 3 处的字符”。

**Fun Indexing Fact:** 今天所有正在使用的编程语言都使用 0 基索引（即索引从 0 开始）。这样做有一些有用的数学含义，即使思考起来更棘手。

在这里做一些实验。尝试获取字符串末尾之后的字符？会发生什么？（我们稍后会学习如何缓解这个问题。）

如果尝试使用负索引会怎样？你认为会发生什么？实际发生了什么？

原来在 Python 中，如果指定负索引，它会从字符串末尾开始获取字符！

```python
x = "Beej!"
print(x[-1])  # Print 1st from the end character: "!"
print(x[-4])  # Print 4th from the end character: "e"
print(x[-5])  # Print 5th from the end character: "B"
```

我们接下来在谈论切片时会用到这些。

## 7.9 切片

Problem-solving step: **Understanding the Problem.**

切片是字符串的一部分。你通过知道字符串中的起始索引和结束索引，并用冒号 : 分隔它们来指定切片。

如果你运行它，你会看到它依次打印每个字符：

```
character: H
character: e
character: l
character: l
character: o
character: !
```

如果你需要逐字符遍历字符串，可以使用它。当然，如果你只想遍历字符串的一部分，可以先对其进行切片！

这里还有一个可能有用的小技巧是 enumerate() 函数。它会返回一系列索引-值对。也就是说，它同时返回字符串中的索引和该索引处的字符。

```
s = "Hello!"

for i, c in enumerate(s):
    print("character at index", i, "is:", c)
```

输出：

```
character at index 0 is: H
character at index 1 is: e
character at index 2 is: l
character at index 3 is: l
character at index 4 is: o
character at index 5 is: !
```

如果需要同时知道索引和字符，这很有用。稍后我们会更详细地介绍 enumerate() 函数。

## 7.13 字符串函数和方法

Problem-solving step: Understanding the Problem.

Python 有很多内置函数可以帮助你操作和使用字符串。

这里有一些例子：

| Function | Example | Description |
|---|---|---|
| bool() | bool(s) | 转换为布尔值。唯一会转换为 False 的字符串是空字符串 ""。（这意味着空字符串在 if 条件中会被视为 False。） |
| float() | float(s) | 转换为浮点值。 |
| input() | input(s) | 打印提示 s，然后返回键盘输入的字符串。 |
| int() | int(s) | 转换为整数值。 |
| len() | len(s) | 返回字符串的长度。 |
| print() | print(s) | 打印字符串。 |

请注意 len() 函数——我们将用它来告诉我们字符串中有多少个字符。

但现在我想介绍一个你今后会经常遇到的新术语和编码风格：方法。

方法是在特定对象上工作的函数。我们在“方法”和“对象”上有点超前，但现在你可以把它们想成在特定字符串上工作的函数。

但这不就是我们刚才看到的那些函数吗？

是的，你抓到我了。但我们使用它们的方式不同！耶！这一切在未来某天会更明了，但请先忍耐一下。

```
print(f"another number: {1000:4}")
print(f"another number: {50:4}")
print(f"another number: {250:4}")
```

输出：

```
another number: 1000
another number:   50
another number:  250
```

:4 表示以 4 个空格宽的字段输出表达式。这为我们提供了一种很好的方式使后续行的列对齐，就像打印电子表格一样。

另一件事它可以做的是指定打印浮点数的小数位数。

```
x = 3.1415926
print(f"Pi is {x:.2f}")  # Pi is 3.14
```

该格式字符串表示“将 x 打印为浮点数，小数点后 2 位”。

F 字符串在控制输出方面非常强大。我们在后续会继续探索。

### 7.14.1 .format() 方法

还有另一种打印格式化字符串的方法，与 F 字符串非常相似：使用 .format()：

```
x = 3.1415926
print("Pi is {:.2f}".format(x))  # Pi is 3.14
```

由于 F 字符串的流行，这种形式已不再受欢迎。

### 7.14.2 % printf 运算符

如果你追溯到更早的时代，你可能会发现 % 被用作 printf 运算符来格式化输出的实例。示例：

```
x = 3.1415926
print("Pi is %.2f" % x)  # Pi is 3.14
```

它更不受欢迎了。F 字符串是新潮流。

> Fun Computing History Fact: printf() 是 C 编程语言中的一个函数，被认为非常棒，以至于 Python 的创建者决定用 % 运算符来将其永恒化，该运算符做同样的事情。而且即使现在，F 字符串中用于描述打印数据的类型的格式说明符也与 C 语言中的相同。对于一个诞生于 1970 年代的语言来说，这不算差吧，嗯？

请注意，printf % 运算符与算术取模（余数）运算符 % 相同。Python 会查看运算符的参数并做出正确的事情。如果左参数是字符串，那就是 printf。如果是数字，那就是取模。
