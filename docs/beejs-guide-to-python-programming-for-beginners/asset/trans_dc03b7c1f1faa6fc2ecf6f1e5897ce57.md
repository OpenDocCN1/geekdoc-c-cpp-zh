

## 15.8 平方根

平方根是个有趣的概念。它是平方的逆运算，如果你还记得前面章节的内容，平方就是将一个数提升到 2 次幂。而平方根正是它的逆运算。

它问的问题是：“对于给定的一个数，我需要让哪个数与自身相乘，才能得到这个数？”

我们来举例说明！

但在举例之前，那个看起来像闪电形状的线条符号，就是表示一个数的平方根的数学符号。

我们来求 9 的平方根：
√9 = ?

这其实是在问：哪个数与自身相乘得到 9？或者换句话说，哪个数的 2 次幂等于 9？再换句话说，哪个数的平方等于 9？

到现在你应该已经想到了：
3 × 3 = 9
同样地：
3² = 9
所以：
√9 = 3

其他一些呢？
√16 = ? √25 = ? √36 = ? √12180100 = ?

注意这些数的结果都是整数。如果一个数的平方根是整数，我们就把这个数称为完全平方数。16、25、36……这些全都是完全平方数。

但你其实可以对任何数开平方根。
√17 ≈ 4.123105625617661

17 不是完全平方数，因为它的结果不是整数。

现在，你可能在想：如果尝试对一个负数开平方根会发生什么？
√−100 = ?

稍加思考后，你可能会意识到，没有任何数乘以自身会得到 −100，所以……
你能怎么办？

你可能会想，“我们完蛋了！”但数学家们可不会。他们简单地定义了：
√−1 = i

并围绕他们所谓的虚数³建立了一整套数学体系，这些虚数实际上有着一些惊人的应用。不过这些内容你可以自己去查阅。

除了平方根，还有立方根。它问的是：“哪个数的立方得到这个数？”它用根号上方的一个小 3 来表示：
∛27 = x

它是方程：
x³ = 27

的逆运算。

你能算出 x 是多少吗？

那在 Python 里怎么做呢？

对于平方根，推荐的方法是使用你导入的 `math` 模块中的 `sqrt()` 函数：

```
import math

print(math.sqrt(12180100))  # prints 3490.0
```

那立方根呢？好吧，对于立方根，我们要回到指数并学习一个小秘密。你可以将数提升到分数次幂。关于这个有很多规则，但简单来说，下面的等式是成立的：

√x = x^(1/2)   ∛x = x^(1/3)   ∜x = x^(1/4)

依此类推。将一个数提升到 1/3 次幂，等同于对它开立方根！

比如，如果我们想计算 4913 的立方根，可以这样算：

∛4913 = 4913^(1/3) = 17

在 Python 里，你可以用普通的幂运算符 `**` 来完成：

```
print(4913**(1/3))  # prints 16.999999999999996
```

嘿——等一下，这不是 17！这是怎么回事？

其实，计算机中的浮点数并不是精确的。它们很接近，但不是精确值。这是开发人员需要注意的事情，要么接受它，要么绕开它。

最后，因为平方根、立方根以及所有其他根本质上都是指数的另一种形式，所以它们与指数具有相同的优先级：在算术运算之前计算。

## 15.9 阶乘

阶乘是个有趣的函数。

基本上，如果我说“5 的阶乘”，意思是我想知道 5 乘以所有小于 5 的正整数、一直乘到 1 的结果。

所以我需要计算：
5 × 4 × 3 × 2 × 1
答案是 120。

但写“factorial”这个词有点冗长，所以我们有专门的符号：感叹号 `!`。“5 的阶乘”写作 `5!`。

另一个例子：
6! = 6 × 5 × 4 × 3 × 2 × 1 = 720

可以想象，阶乘增长得非常快。

40! = 815915283247897734345611269596115894272000000000

在 Python 中，你可以使用 `math` 模块中的 `factorial()` 函数来计算阶乘。

```
import math

print(math.factorial(10))  # prints 3628800
```

阶乘本质上是乘法的另一种形式，因此与乘法具有相同的优先级。在加减法之前计算。

## 15.10 科学计数法

对于非常大的浮点数，你可能会看到这样的内容：

```
print(2.7**100)  # 1.3689147905858927e+43
```

末尾的 `e+43` 是什么？

这就是我们所说的科学计数法。它是一种书写非常大（或非常小）数字的简写方式。

上面的数字 `1.3689147905858927e+43`，在数学上表示：

1.3689147905858927 × 10^43

10^43 是一个很大的数字。所以用 1.3689……去乘以它，结果确实是一个非常大的数。

但这还没完。我们也可以用科学计数法表示非常小的数字。

```
print(3.6/500000000000000000)  # 7.2e-19
```

`7.2e-19` 表示：

7.2 × 10^-19

而 10^-19 是一个非常小的数字（非常接近 0——记得 10^-19 = 1/10^19），所以用它乘以 7.2 的结果也非常小。

记住这些：
- 如果末尾看到 `e-` 加某个数，说明这是一个非常小的数字（接近 0）。
- 如果末尾看到 `e+` 加某个数，说明这是一个非常大的数字（远离 0）。

## 15.11 对数

做好准备，因为接下来会有点奇怪。

好吧，也不算太怪，但确实有点怪。

对数，通常简称为 log，有点像指数的逆运算。

但它和平方根那种“逆”并不是同一种方式。

是不是很方便？

对于对数，我们说“以 x 为底 y 的对数”。例如“以 2 为底 32 的对数”，写作：

log₂ 32

它问的是：“2 的多少次幂等于 32？”用数学表示：

下面两个等式都成立：

x = log₂ 32
2^x = 32

那么答案是什么？稍微尝试一下，你可能会发现 2^5 = 32，因此：

x = log₂ 32 = 5

虽然对数的底可以是任何数，但常见的主要有三种：2、10 和 e。

以 2 为底在编程中非常常见。事实上，它太常见了，以至于如果你在计算机相关语境中看到有人写 `log n`，你应该默认他们指的是 log₂ n。

e 是自然对数的底数，在数学中常见，在计算机领域则不那么常见。

那它们有什么用呢？

在编程中，你经常看到对数的地方是使用大 O 表示法来表示计算复杂度。

要在 Python 中计算一个数的对数，可以使用 `math` 模块中的 `log()` 函数。将底数作为第二个参数传入（如果不指定，则计算自然对数，即以 e 为底）。

例如，计算 log₂ 999：

```
import math

print(math.log(999, 2))  # Prints 9.96434086779242

# Because 2^9.96434086779242 == 999. Ish.
```

这里需要记住的重要一点是：当一个数变大时，它的对数仍然保持较小。下面是一些例子：

| x | log₂x |
|---|------|
| 1 | 0.0000 |
| 10 | 3.3219 |
| 100 | 6.6439 |
| 1000 | 9.9658 |
| 10000 | 13.2877 |
| 100000 | 16.6096 |
| 1000000 | 19.9316 |
| 10000000 | 23.2535 |

一个很大的数，其以 2 为底的对数往往是一个小得多的数。

## 15.12 舍入

当我们对一个数进行舍入时，我们是在寻找某个小数位数下最接近的数，并舍弃所有比该小数位数更小的位数。

默认情况下，我们指的是 0 位小数，也就是想舍入到最近的整数。

所以如果我说“将 2.3 舍入到最近的整数”，你会回答“2”，因为 2 是离 2.3 最近的整数。

如果我说“将 2.8 舍入到最近的整数”，你会回答“3”，因为 3 是离 2.8 最近的整数。

当我们舍入到一个更大的数时，称为向上舍入。

另一个方向则是向下舍入。

但如果我说“将 2.5 舍入到最近的整数”呢？它正好位于 2 和 3 中间！在这种情况下，按照惯例，我们很多人学的是向上舍入。所以答案是 3。

我们也可以通过声明舍入方向来强制一个数向某个特定方向舍入。

“将 x 除以 3，然后向上舍入。”

在 Python 中，我们有几种舍入方式。

可以使用内置的 `round()` 函数。

但它的行为和我们平时习惯的略有不同。值得注意的是，像 1.5、2.5、3.5 这样与两个整数等距的数字，总是舍入到最近的偶数。这通常被称为“四舍六入五成双”或“银行家舍入”。

```
round(2.8)  # 3
round(-2.2) # -2
round(-2.8) # -3

round(1.5)  # 2
```
