### 5.3 从一个变量赋值给另一个变量

让我们看看这段代码：

```
x = 1000
y = x
```

这里发生了一些有趣的事情，我希望你注意。现在它不会特别有用，但当我们后面接触到更中级的数据类型时，它会有用。

当你这样做时，x 和 y 都引用同一个 1000。

这句话听起来有点奇怪。

但可以这样想：在计算机内存的某个地方存储着值 1000。x 和 y 都引用那一个值。

如果你这样做：

```
x = 1000
y = 1000
```

现在有两个 1000 值。x 指向一个，y 指向另一个。

最后，接着原来的示例：

```
x = 1000
y = x
y = 1000
```

这里发生的是：首先有一个 1000，x 引用它。

然后我们把 x 赋值给 y，现在 x 和 y 都引用同一个 1000。

但接着我们又把另一个 1000 赋值给 y，所以现在有两个 1000，分别由 x 和 y 引用。

（这里的细节比我提到的要复杂得多。如果你足够疯狂，可以去看附录 C。）

要点：变量只是内存中对象的名称。你可以将一个变量赋值给另一个变量，让它们都指向同一个对象。

我们这么早把它放进你的大脑，是为了以后能重新唤起它。

### 5.4 你的计算心智模型

问题解决步骤：理解问题。

这是个大重点，所以要仔细听。

编程时，对程序运行时应发生什么保持一个心智模型是非常重要的。

让我们看看之前的例子。在脑中逐行执行，同时跟踪系统状态的变化：

```
x = 34      # Variable x is assigned value 34
print(x)
x = 90      # Variable x is assigned value 90
print(x)
```

在开始之前，x 没有值。所以在头脑中这样表示：“x 没有值；它是无效的”。

然后第一行运行。

x 现在是 34。

然后第二行运行。

x 仍然是 34，我们把它打印出来。（所以打印出 34。）

然后第三行运行。

x 不再是 34，而是 90。34 消失了。

然后第四行运行。

x 仍然是 90，打印出 90。

然后代码执行完毕，程序退出。屏幕上会留下打印出的“34”和“90”。

*这就是*保持计算的心智模型。

这是能够调试的关键。当你的心智计算模型与实际程序运行结果不同时，就说明某处有 bug。你必须深入代码，找到心智模型与实际程序运行*第一次*出现分歧的地方。那里就是 bug 所在。

函数是一段代码，当你*调用*它时（也就是你要求它做某事时），它会为你做一些事情。函数接受*参数*，你可以*传入*参数来改变函数的行为。此外，函数会*返回*一个值，你可以在函数完成工作后取回这个值。

所以我们这里有 `input()` 函数[^8]，当你调用它时，它会从键盘读取输入。作为参数，你可以传入一个*提示信息*，在用户准备输入时显示给他们。它会返回用户输入的任何内容。

你的程序应该将 a、b、c 代入上述公式，并打印出 x 的结果值。

确保 b² ≥ 4ac，否则不会有解，而且当你尝试对负数取平方根时会得到“domain error”。一些可以使用的 a、b、c 测试值：5、9、3 或 20、140、60。

方程中 -b 后面的 ± 符号是什么？那是“加或减”。这意味着实际上有两个方程，一个用 +，一个用 -：

x_plus = (-b + √(b² - 4ac)) / 2a   x_minus = (-b - √(b² - 4ac)) / 2a

对于给定的 a、b、c，分别求解并输出两个答案。

那么 b² - 4ac 的平方根呢？如何计算它？下面是一个计算 2 的平方根的演示程序——用它来学习如何使用 math.sqrt() 函数，然后将其应用到这个问题上。

```
import math    # You need this for access to the sqrt() function
x = math.sqrt(2)  # Compute sqrt(2)
print(x)  # 1.4142135623730951
```

### 6.4 布尔代数和表达式

问题解决步骤：理解问题。

George Boole¹ 是一个相当有趣的人物。从 19 世纪早期的平凡出身开始，他发展出了在许多方面成为现代计算基础的数学。相当了不起。

他所发展的是我们今天所称的布尔代数。

别担心——它比你想的那种代数更容易。事实上，你已经知道了，只是没有正式地、也不以这个名字。

在布尔逻辑中，我们关心表达式是真还是假。然后我们可以据此做出决策。

在进入计算机内容之前，我们先做一些人类相关的例子。

难度：简单。以下表达式对你来说是真还是假？

- 我住在北美。
- 现在正在下雨。
- 猫优于狗。

希望这并不特别具有挑战性。让我们通过引入 AND 的概念来提高难度。对于这些情况，整个表达式只有在所有子表达式都为真时才为真。

例如，陈述“我身高超过 190 厘米 AND 我年龄小于 30 岁”是假的。虽然我身高超过 190 厘米，但我不是小于 30 岁，所以整个表达式为假。

相比之下，“我喜欢狗 AND 我喜欢摩托车”为真，因为这两个子表达式都为真。

如果两者都不是真，结果也为假。

难度：中等。以下表达式对你来说是真还是假？

- 我住在欧洲 AND 我年龄大于 25。
- 现在正在下雨 AND 现在正在阳光明媚。
- 猫优于狗 AND 狗优于猫。

好吧！让我们做 AND 的一个变体，即 OR。有 OR 时，只要一个或两个子表达式为真，整个表达式就为真。

例如，我不喜欢跑步，但我喜欢骑自行车。尽管如此，以下陈述为真，因为至少有一个子表达式为真：“我喜欢跑步 OR 我喜欢骑自行车”。真。

这是对以下问题的聪明回答的基础：

> 你想要汤还是沙拉？

> “真。我想要汤或我想要沙拉。”

> “滚出我的餐厅，布尔狂热者！”

难度：中等。以下表达式对你来说是真还是假？

- 我住在欧洲 OR 我年龄大于 25。
- 现在正在下雨 OR 现在正在阳光明媚。
- 猫优于狗 OR 狗优于猫。

好吧！现在还有一件事要记住：除非表达式中有括号另行说明，否则 AND 的优先级高于 OR。也就是说，先做 AND，然后做 OR。

难度：高级。

假设正在下雨，我超过 25 岁，这条鱼很大。我们可以评估这个表达式：

It's sunny AND this fish is big OR I'm over 25.

我们先做 AND。不是晴天，鱼很大。所以这是“false AND true”，求值为“false”。

所以用“false”替换那个 AND 表达式。然后我们做 OR：

false OR I'm over 25.

现在我超过 25 岁，所以求值为“false OR true”，即“true”。

所以整个表达式为真。

你可以用括号来覆盖：

It's sunny AND (this fish is big OR I'm over 25).

先做括号里的运算。所以现在我们评估 OR，求值为“true OR true”，即“true”。然后我们评估 AND，即"It's sunny AND true"，即“false AND true”，即“false”。

所以整个表达式为假。

让我们用一些数值条件表达式做些例子。它们求值为真还是假？

- 1 < 5
- 5 > 1
- 1 < 5 AND 5 < 10
- 1 < 5 OR 5 < 10
- 1 < 5 AND 5 > 10 OR 10 > 20
- 1 < 5 AND (5 > 10 OR 10 > 20)

答案：

- True
- True
- True AND True = True
- False OR True = True
- True AND False OR False = False OR False = False
- True AND (False OR False) = True AND False = False

有时开发者（但更常是硬件人员）用所谓的真值表来描述这些运算。真值表显示布尔表达式对于某些给定输入的结果会是什么。

这些表通常使用 1 表示 True，0 表示 False。

以下是我们迄今为止看到的运算的一些真值表。

| A | B | A AND B |
|---|---|---|
| 0 | 0 | 0 |

*块可以用制表符或空格的任意组合进行缩进，只要块中的每一行都以相同的制表符或空格模式开头即可。官方建议在 Python 中使用 4 个空格进行缩进。*

*Python 中的缩进块是大多数开发者在喜欢或讨厌方面意见很强的事情之一。个人而言，我说无论你对它们的怪癖感觉如何，都要在任何语言中做一个好开发者。*

然后这个讨厌的 else 是什么？那是 if 的一个超级方便的功能。如果条件为 False，则 else 下面的块会被求值。基本上，我们在说，“如果条件为真，则执行此操作，否则执行此操作。”

if-else 家族中我们还可以使用一个构造：elif。它是 else if 的缩写，用于需要检查多个条件时。

```
if x < 10:
    print("x is less than 10")
elif x < 20:
    print("x is less than 20")
elif x < 30:
    print("x is less than 30")
else:
    print("x is greater than or equal to 30")
```

在这个例子中，首先检查 x 是否小于 10。如果为 False，则测试下一个条件，以此类推。如果都不匹配，则进入 else 情况。

if 语句是我们使用布尔逻辑控制程序流程的核心。它是计算机根据输入做出决策的方式。没有 if，就没有计算——它的重要性就在于此！

而作为开发者，你的工作是想出那种逻辑，那些 if 语句和条件，使你的程序对给定输入产生正确的输出。

这里有一个现实生活中的例子。假设你需要在屋顶上铺一些瓦片。步骤是放置一块瓦片，将其钉牢，然后移动到下一个位置。

- 移动到下一个位置

- 将其钉上

- 将其钉上

但这啰嗦得令人厌烦。最好这样做：

- 当我们尚未放置 4 块瓦片时：
  - 放置一块瓦片
  - 将其钉上

这就是循环。我们在条件为 True 时反复运行同一段代码。至少，这能为我们省去大量打字！

Python 有几种循环语句，但在本节中，我们将重点介绍所谓的 while 循环。它会在条件为真时反复执行某些操作。

下面是一个从 1200 数到 1210 的示例⁵：

```
x = 1200

while x <= 1210:
    print(x)
    x += 1

print("All done!")
```

只要条件 x <= 1210 为 True，它就会重复循环体（所有缩进的部分）。

你会看到，在循环体内部，每次迭代我们都会将 x 递增（加一），使它逐步增加到 1210。

如果我们不递增 x 会怎样？那样的话，它会永远循环下去。我们称之为无限循环。如果你的程序长时间运行却没有输出（或重复输出），它可能陷入了无限循环。

如果你的程序陷入无限循环，你该如何退出？按 CTRL-C（也称为 “break”）即可。这样就会回到 shell 提示符。

请记住，本章程序的目标之一是要求用户输入一个介于 5 和 50 之间的数字。如果他们输入的数字超出该范围，我们需要再次询问。也就是说，我们需要在用户未提供有效输入时循环。现在先思考一下这个问题，稍后我们会再回来处理。

### 6.8 循环：for 循环

### 解决问题的步骤：理解问题

除了 while 循环之外，我们还有一种称为 for 循环的“猛兽”。我们稍后会看到它非常强大，但现在我只想讨论按特定次数循环的情况。（与在条件为真时循环相对。）

下面是一个使用 for 循环和名为 range() 的函数打印从 0 到 9 的数字的示例。（range() 会返回一种称为迭代器（iterator）的东西。更多关于迭代器的内容将在后续章节中介绍——现在，只需了解它们如何与 for 循环一起使用即可。）

```
for i in range(10):  # loop from 0 to 9
    print(i)
```

注意几点：

- i 是循环索引的经典变量名。
- 如果你有嵌套循环（循环中的循环——稍后会详述），可以使用 j，然后 k，等等。
- 我们会一直循环到 range() 参数之前的一个数。到达但不超过该参数。

但等等，还有更多！range() 多才多艺！它不仅能从零数到接近某个数字，你还可以给它另一个起始点：

```
for i in range(5, 10):  # loop from 5 to 9
    print(i)
```

现在你愿意出多少钱？它能切片、能切丁！但我们还没说完！你还可以告诉 range() 每一步跳过多少！

但我们如何反复询问，直到用户输入有效内容为止？我们需要循环！在输入无效时循环如何？当然可以！

```python
input_valid = False  # Assume it's invalid to start

while not input_valid:  # While not input valid ("while input invalid")
    x = input("Enter a number, 5-50 inclusive: ")
    x = int(x)

    if x >= 5 and x <= 50:
        input_valid = True  # We got a good number!
```

让我们研究一下这个模式，因为这是 while 的一种常见用法。

我们首先假设成功条件未满足。然后在每次循环迭代中用 if 检查它是否满足。并且只要成功条件不为真，我们就继续循环。

现在，如果输入超出范围，我们还应该打印一条错误信息。怎么做？用两行代码就能做到。

如果 if 条件为 True，则输入有效。否则输入无效，我们应该打印一条消息……用 if...else！

（注意：下面的代码是上面程序的延续。请留意行号！）

```python
if x >= 5 and x <= 50:
    input_valid = True  # We got a good number!
else:
    print("The number must be between 5 and 50, inclusive!")
```

如果你还没有这样做，请编写这段代码并运行它。不，它不是完整的程序，但它是程序的完整第一步，我们可以先测试它再继续，以确保这部分正常工作。

运行它，并输入一些数字试试。如果你输入无效数字，它应该会提示你并再次询问。如果你输入有效数字，input_valid 变为 True，while 循环就会退出（因为继续条件是 not input_valid，此时它为 False）。

一旦你确认它运行正确，让我们回到规格说明，专注于打印星号。

### 解决问题的步骤：设计计划

如果用户输入 x，我们总共要打印 x 个字符。其中前 30 个将是 #，之后的将是 *。

在开始之前，让我们使用一种不同的规划技巧：简化问题。

让我们暂时忽略 *，只打印用户指定数量的 # 字符。稍后我们再为 * 添加代码。

> > 简化问题可以让你更容易地处理它，并引导你找到之后添加缺失功能的方法。

这个简化阶段的计划并不难：

对于用户输入的数量：
    打印一个 '#'。

### 解决问题的步骤：执行计划

因为我们知道要打印多少个 #（用户输入了数字！），所以这里非常适合使用 for 循环。让我们打印这些 #：

```python
# Print the line
for i in range(x):
    print("#")
```

运行它！结果如何？

嗯。看起来它把井号打印在每一行上。print() 函数会在行尾添加一个换行符。我们需要覆盖该行为，有一种简单的方法可以做到。

```
# Print the line
for i in range(x):
    print("#", end="")  # Set the end-of-line character to nothing
print()  # Add a newline to the end of the line
```

我们在那里施展了一点魔法。我们向 print() 传递了另一个参数，告诉它我们希望在行尾放置一个空字符串（""），而不是它通常附加的换行符。

你甚至可以发疯，写成 end="Beej"，它会在每个井号后面加上单词 "Beej"。试试吧。发疯去吧。

快成功了！但我们还没有脱离困境。我们需要让它做到：当字符超过 30 个之后，打印 * 而不是 #。

### 解决问题的步骤：设计计划

这类似于之前打印一行的计划，但还记得吗？我们当时简化了它。所以现在需要增加一些复杂性以满足规格要求。

对于用户输入的数量：
如果我们在第 30 个字符或之前：
    打印一个 "#"。
否则：
    打印一个 "*"。

这看起来非常适合在我们的 for 循环中使用 if！

### 解决问题的步骤：执行计划

让我们在最后的 for 循环中添加这个 if 逻辑：

```
# Print the line
for i in range(x):
    if i < 30:
        print("#", end="")  # Set the end-of-line character to nothing
    else:
        print("*", end="")
print()  # Add a newline to the end of the line
```

这里有一些微妙但重要的点需要注意：

- 如果用户输入 40，则 i 的值从 0 运行到 39，因为当 i 达到最大值时，for 循环体不会执行。
- 但 0 到 39 仍然有 40 次迭代，对吗？就像 0、1、2、3 总共有 4 次迭代一样。所以即使计数器从 0 运行到 39，我们仍然得到了全部 40 个字符。
- 不过，由于计数器从 0 开始，这意味着最后一个会是 # 的字符发生在 i 为 29 时，而不是 i 为 30 时。这就是我们测试 i < 30 而不是 i < 31 的原因。

就这样，我们完成了！

一定要用边界情况测试。边界情况是指那些位于程序条件边缘的输入。

例如，我们有对输入与 5 和 50 进行比较的条件。所以用 4、5、50 和 51 来测试，覆盖这些条件的两侧。

代码中还有哪里存在边界情况？对了：打印时的 if。前 30 个应该是 #，之后是 *。所以用 30 测试，确保全部是 #；然后用 31 测试，确保有一个 *。

测试边界情况是一种强大的编程技巧，所有开发者都会充分利用它。

### 7.8 从字符串中获取单个字符

Problem-solving step: **Understanding the Problem.**

如果我们想从字符串中提取单个字符怎么办？

我们可以做到，但需要引入新的记号来允许它：[ 和 ]，又称方括号。

让我们只打印字符串中的前两个字符：

```python
x = "Beej!"
print(x[0])  # Print character in position 0, "B"
print(x[1])  # Print character in position 1, "e"
print(x[4])  # Print character in position 4, "!"
```

阅读这段代码时，x[1] 会读作“x 下标 1”，是对经典数学记号 x₁ 的致敬。这里的 1 被称为字符串的索引。

**Really important:** 索引号从 0 开始！！字符串中的第一个字符有时在口语中被称为零号字符，第二个字符有时被称为一号字符，接着是二号、三号，等等，以避免歧义。如果你想确保无误，就说“索引 3 处的字符”。

**Fun Indexing Fact:** 今天所有正在使用的编程语言都使用 0 基索引（即索引从 0 开始）。这样做有一些有用的数学含义，即使思考起来更棘手。

在这里做一些实验。尝试获取字符串末尾之后的字符？会发生什么？（我们稍后会学习如何缓解这个问题。）

如果尝试使用负索引会怎样？你认为会发生什么？实际发生了什么？

原来在 Python 中，如果指定负索引，它会从字符串末尾开始获取字符！

```python
x = "Beej!"
print(x[-1])  # Print 1st from the end character: "!"
print(x[-4])  # Print 4th from the end character: "e"
print(x[-5])  # Print 5th from the end character: "B"
```

### 8.3 什么是列表？

问题解决步骤：理解问题。

还记得普通变量只保存一个东西吗？好吧，列表是可以保存很多东西的变量。

*有趣的列表事实：* 大多数其他语言对列表有不同的名称：它们称之为“数组”。其实是同一个东西。

但是等等——如果一个列表可以保存很多东西，我们如何区分呢？我怎么告诉 Python 我想要列表中的第二样东西？或者第五样？

幸运的是，这很简单；我们只需指定包含所需内容的列表的索引。

可以把它想象成一排邮箱，编号从 0 开始，然后是 1、2，一直编到邮箱的总数。每个邮箱可以存放一个东西，你可以通过邮箱编号来引用它。

让我们看一个简单的例子：

```
x = [10, 3, 7, 9]
```

这是一个列表。我们之所以知道它是列表，是因为它周围有方括号。它是一个包含四个整数的列表。

让我们打印出列表中的第零个元素。我们通过在列表变量名后使用方括号并在括号内给出索引来实现。是不是看起来眼熟？这和我们从字符串中获取单个字符的语法是一样的！

```
print(x[0])  # prints 10
```

以及索引 2 处的元素：

```
print(x[2])  # prints 7
```

你还记得字符串有一个很酷的技巧：可以使用负数索引来引用字符串末尾的字符吗？我们可以对列表做同样的事情！

```
print(x[-1])  # prints 9, the element at the end of the list
```

记住，和字符串一样，索引从零开始。

延续“你还能对字符串做的那些事”的主题，你还可以像切字符串一样对列表进行切片。

```
a = [1, 2, 3, 4, 5]
b = a[1:-1]  # Slice all but the first and last elements
print(b)  # [2, 3, 4]
```

你还可以单独设置某个元素，而让列表的其余部分保持不变：

```
x[1] = 99
print(x[1])  # now prints 99
```

这让我们看到了列表和字符串之间的一个显著区别：列表是可变的。你可以在不创建新列表的情况下更改列表中的各个元素！记住，字符串是不能更改的——你只能创建新的字符串。

这是一个关键的区别，我们现在要详细讨论它，稍后还会再讨论。它是新手开发人员容易困惑的一大来源。

### 8.4 列表赋值

你还记得很早以前在“变量”那一章中，我讲过变量赋值是如何工作的吗？如果必要的话，请重新回顾一下。

你当时是不是在想，这到底有什么关系？

好吧，我们要再次探讨它，但这次是在列表的背景下。

我们刚才提到，列表与整数不同，列表是可变的。我们可以更改它们。这产生了一些有趣的后果。

让我们看看字符串与列表的对比。

```
x = "Hello"
y = x
```

在这个例子中，正如我们之前所学，内存中只有一个字符串 `"Hello"`，而 `x` 和 `y` 都指向它。

字符串是不可变的。所以你不能这样做：

```
x = "Hello"
y = x

# Change character at index 2 to 'Z'
x[2] = "Z"  # ERROR! Strings are immutable--you can't change them
```

但列表是可变的。我们可以更改列表中的内容。让我们做一个类似的例子：

```
x = ["A", "B", "C", "D"]
y = x

# Change string at index 2 to 'Z'
x[2] = "Z"  # Works

print(x[2])  # "Z"
print(y[2])  # "Z" also!!!
```

等等——这是怎么回事？我们更改了 `x` 的第二个索引处的值，但 `y` 也跟着变了！这怎么会发生？

记住：这是因为当我们执行：

```
x = ["A", "B", "C", "D"]
y = x
```

`x` 和 `y` 都指向了同一个列表。这里只有一个列表。`x` 和 `y` 都引用它。所以如果你更改了那一个列表，你就会在 `x` 和 `y` 上都看到这一变化。

（如果你能更改字符串，它也会以同样的方式工作。但你不能，因为它是不可变的。）

- 可变类型包括以下这些（其中一些我们还没有讨论过）：
    - 列表
    - 字典
    - 对象¹
    - 集合

如果你想要列表的副本，而不只是引用的副本，该怎么办？你可以用多种方式强制复制列表，这里有三种常见的方式：

```
b = a.copy()    # Copy with .copy() method
b = list(a)     # Copy with the list() function
b = a[:]        # Copy by slicing the entire list
```

### 8.5 `for` 与列表——强大的组合

问题解决步骤：理解问题。

还记得我们的老朋友 `for` 循环吗？我们用它与 `range` 一起循环特定次数，也用它与字符串一起遍历字符串中的每个字符。

我们还可以将它与列表²一起使用，按顺序对每个列表元素进行操作！

下面是一个简单的例子，它打印列表中的所有元素：

```
x = [11, 55, 33, 99]

for i in x:
    print(f"element is: {i}")
```

这将输出：

```
element is: 11
element is: 55
element is: 33
element is: 99
```

但是等等，还有更多！

回想一下上面的内容：如果你知道元素的索引，就可以从列表中取出该元素，例如 `x[2]`。

让我们用另一种方式将这些组合起来使用 `for` 和列表。这个例子与上面做的是同一件事，只是方式不同：

```
x = [11, 55, 33, 99]

for i in range(4):
    print(f"element is: {x[i]}")
```

虽然这不是地道的 Python³ 风格（第一个例子更好），但它演示了如何使用变量作为索引。我们在循环内部引用 `x[i]`，然后让 `i` 变化以遍历每个元素的索引。

让我感到别扭的是，`range()` 中硬编码了 `4`。它只适用于长度为 4 的列表。让我们看看能否修复它。

剧透一下：你可以使用 `len()` 获取列表中的元素数量。

让 `range()` 上升到“列表的长度”，而不是 `4`：

```
x = [11, 55, 33, 99]

for i in range(len(x)):     # <--
    print(f"element is: {x[i]}")
```

现在它适用于任何长度的列表——好多了！

### 8.6 `for` 与 `enumerate()`

问题解决步骤：理解问题。

在上面的例子中，我们用 `for` 遍历了列表中的元素本身，也用 `range()` 遍历了列表中元素的索引。

如果你想同时做到这两点呢？也就是说，你既想要元素，又想要索引？

有一个值得一提的函数是 `enumerate()`。它会遍历列表中的每个元素，返回元素及其索引。你可以同时得到它们！

```
x = [11, 55, 33, 99]

for i, v in enumerate(x):
    print(f"The element at index {i} has value {v}")

并且输出：

```
[1, 4, 3, 8, 5, 12]

x = [1, 2, 3]

### 9.3 什么是字典？

问题解决步骤：理解问题。

还记得对于列表，我们可以用索引编号作为键来从列表中获取值，也可以用相同的索引编号将内容存储到那个“槽位”中吗？

对于存储按编号索引的信息集合来说，这确实很方便，对吧？

那么，如果你想用一个不是数字的东西来引用某个槽位呢？如果你想使用，比如说，一个字符串，如下所示？

```
x = [1, 2, 3]
x["beej"] = 3490  # Not going to work with a list
```

这会让 Python 不高兴，因为 "beej" 不是整数。而列表需要的是整数。

但我们可以用字典（简称 dict）来绕过这个限制。

声明字典的方式稍有不同，但这里有一个简单的入门示例：

```
d = {}  # Squiggly braces, not square brackets!
d["beej"] = 3490
print(d["beej"])  # 3490
```

用法上非常相似，尽管变量的初始声明方式与列表不同。

对于字典，方括号中的值称为键，存储在那里的值称为值。

```
# key      value
# |         |
# ---      -----
d["goats"] = "awesome"
```

你使用键来查找字典中的值，或者在字典中设置值。

键可以是任何不可变类型（例如整数、浮点数、字符串）。值可以是任何类型。

### 9.6 这个字典有这个键吗？

else:
    print(f"Value of key x is {d[x]}")
```

### 9.11 字典是可变的

问题解决步骤：理解问题。

当你对一个字典进行赋值复制时，复制的是对同一个字典的引用，而不是创建一个新字典。就像列表和其他任何东西一样。

这一点很重要，因为字典和列表一样，都是可变的。

```
d = { "beej": 3490 }
e = d  # both e and d refer to the same dict!
e["beej"] = 3491  # modify it
print(d["beej"])  # 3491
```

如果你想复制一个字典，可以使用以下任一方法：

```
d = { "beej": 3490 }
e = d.copy() # make a copy, the preferred way
e = dict(d)  # make a copy
```

第一种方式是首选，因为它更容易阅读，而易于阅读的代码就是快乐代码™。

### 10.9 位置参数与关键字参数

问题解决步骤：理解问题。

我们稍后会更详细地讨论这个问题，但函数参数在 Python 中可以分为这两个大类：位置参数和关键字参数。

位置参数是必须在函数调用中出现在特定位置的参数。

例如，如果我们想计算 14^12，我们需要以特定顺序将这两个参数传递给 `math.pow()` 函数，该函数期望底数在前，指数在后：

```

如果你把 12 放在前面，你会得到不同的答案。这些是位置参数。

但对于某些函数，在位置参数之后，你可以指定额外的关键字参数。这些参数由特定名称标识。

### 10.10 插曲：求值策略

如果你不想读这一节，可以跳过。但如果你读了，会更有趣。

不同语言在向函数传递参数时有着不同的行为。

有些语言会复制参数的值。有些语言只是让参数名成为实参的别名。还有些语言通过某个关键字让你选择。

编程语言采用的具体方式称为其**求值策略**。

三种非常常见的策略是：

- **按共享传递（Call by Sharing）：** 这就是 Python 采用的方式。当你调用函数时，参数变成与对应实参相同的对象的引用。这意味着，如果在函数内部修改了参数所引用的对象，调用方会看到这个变化。但是，如果你给参数赋予一个新值，调用方不会看到这个变化。

  ```python
def foo(x):
    # 修改传入的对象。调用方会看到这个变化。
    x[1] = 99

    # 给 x 赋予一个新列表。调用方 _不会_ 看到这个变化。
    x = [4, 5, 6]

a = [1, 2, 3]

foo(a)
print(a)  # [1, 99, 3]
  ```

- **按值传递（Call by Value）：** 会创建实参的副本并将其存储在参数中。C 语言等使用这种方式。（有时人们说 Python 是按值传递，但严格来说这并不准确，因为参数传入时并不会被复制；复制的只是对实参的引用。你可以在调用函数时复制参数，从而让 Python 模拟按值传递。）

  ```python
# 在 Python 中模拟按值传递

def foo(x):
    # 修改传入的对象。调用方通常会看到这个
    # 变化，但如果他们调用时传入的是副本，
    # 那么只有副本会受到影响。
    x[1] = 99

a = [1, 2, 3]

# 通过复制来模拟按值传递
foo(a.copy())

print(a)  # [1, 2, 3]
  ```

def get_ship_locations():

    """
    done = False  # 当用户要求结束时设为 True

            for i, v in enumerate(xyz_list):

            # 构建主列表
            locations.append(xyz_list)

    return locations

### 11.5 制作不同的星舰

问题解决步骤：理解问题。

另一个有趣的术语事实：在类内部声明的函数称为方法。

这个特殊函数始终命名为 __init__()（带双下划线），称为构造函数。

让我们为我们的 StarShip 类添加一个构造函数，允许我们在构造船只时传入船名：

### 11.10 对象是可变的

当你将一个对象赋给另一个对象时，你不会得到第二个对象。你得到的是对第一个对象的另一个引用。就像列表和字典发生的情况一样。

或者换句话说，用对象进行赋值不会产生新对象。两个变量都是同一个对象的名称。（详情请参阅附录 C。）

```python
class Forest:
    pass

x = Forest()  # Construct a new object
y = x

x.antelopes = 4

print(y.antelopes)  # 4, since y and x refer to the same object
```

这意味着你可以将对象作为参数传递给函数，并且函数可以更改对象属性中的值。

```python
def set_antelopes_to_10(o):
    o.antelopes = 10

class Forest:
    pass

x = Forest()
x.antelopes = 4

set_antelopes_to_10(x)
```




```
print(x.antelopes)  # 10!
```

请记住，当你调用函数时，实际上是在将实参赋值给形参名，因此两者指向的是同一个对象。也就是说，在上面的代码中，`o` 与 `x` 指向同一个对象，就像我们执行了 `o = x` 赋值一样。

### 11.11 对象与 None

我们已经看到，变量可以指向值 `None` 来表示“什么都没有”。

这在对象中经常用于表示某种“未找到”或错误状态。

例如，假设我们有一个对象列表，以及一个按名称搜索对象的函数。该函数应返回一个 `name` 属性与传入函数的 `name` 参数匹配的对象。

但此时自然会浮现一个问题！如果列表中不存在该名称的对象怎么办？函数应该返回什么？`None` 是不二之选。

```
class Person:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return self.name

def get_person_by_name(person_list, name):
    """Return a person object with this name, or None if not found"""
    for p in person_list:
        if p.name == name:
            # If we found them, return the object
            return p

    # If we got here, we didn't find anyone by that name
    return None

person_list = [
    Person("Annie"),
    Person("Beej"),
    Person("Chris")
]

p = get_person_by_name(person_list, "Chris")

print(p)  # "Chris"

p = get_person_by_name(person_list, "Dave")

if p is None:
    print("Dave's not here.")
```

### 11.12 测试属性

有时在运行时，你想知道对象是否具有某个属性。或者你以字符串形式拥有属性名，并想在对象上获取或设置该属性。

有三个内置函数可以帮助实现这一点：

- `hasattr()` 用于测试对象上是否存在某属性。
- `getattr()` 返回属性的值，如果属性不存在，还可以返回默认值。
- `setattr()` 设置属性的值，如果属性不存在则创建它。

这为编写对象提供了更大的灵活性，因为你可以让对象拥有可选属性。

让我们演示一下！

```
class Foo:
    pass

f = Foo()
f.bar = 12

print(hasattr(f, "bar"))    # True
print(hasattr(f, "frotz"))  # False

print(getattr(f, "bar"))            # 12
print(getattr(f, "frotz", None))    # None, since attr frotz doesn't exist

setattr(f, "frotz", 99)  # Just like saying "f.frotz = 99"

print(f.frotz)  # 99
```

我不会说这些函数在日常使用中非常频繁，但它们是你工具库中的有力补充。

## 解题步骤：执行计划

让我们添加这个新类，它同时持有对电影的引用及其放映时间：

```
class MovieTime:

class Theater:

theaters[2].movietimes.append(MovieTime(movies[1], ["5pm", "7pm"]))
theaters[2].movietimes.append(MovieTime(movies[2], ["6pm", "7pm", "8pm"]))

def print_theater(theater):

```

### 12.7 导入特定属性

有一种 `import` 的替代语法，可以用来将模块中的属性直接引入到全局命名空间中。

我是什么意思？

关键是，如果你厌倦了在访问某个特定函数或数据时输入模块名后跟一个点，你可以改为直接引入使用。

我们来做一个例子。

time 模块有一个名为 `ctime()` 的函数，它以经典格式打印时间。

```python
import time

print(time.ctime())  # "Sun Feb  9 13:37:00 2020"
```

但如果你要反复调用它，代码里到处都是 `time.` 就会显得很糟糕。

我们可以这样做：

```python
# Bring in ctime() explicitly:

from time import ctime

print(ctime())  # Look, ma! No "time."!
```

如果一个模块中有多个你想要导入的东西，你可以用逗号列表将它们引入：

```python
# import all three!

from time import ctime, localtime, monotonic
```

或者，如果你感觉大胆，可以全部导入！

```python
from time import *
```

但我通常不建议这样做。Python 执行它需要时间，如果你只需要几样东西，就明确指定它们。

此外，很多开发者依赖模块名作为视觉提示，表明我们正在谈论模块中的函数。如果我们遇到如下代码：

```python
print(ctime())
```

这是程序员自己定义的函数，还是我们从某处导入的东西？把模块名放在前面有助于缓解这种歧义：

```python
print(time.ctime())
```

所以一般来说，我只有在这样做能让代码明显更易读时，才使用 `from ... import`。

记住：可读的代码就是高价值的代码！

# 获取命令后面的所有参数

if command[0] == 'q':
    done = True

# 列出文件内容
elif command[0] == 'l':
    handle_list(args, lines)
```

没错，差一错误已经出名到拥有自己的维基百科页面了。

正如其名称所示，我们的计算出现了“一位”的偏差。但为什么会这样？怎么会这样？

这是人与计算机之间一个非常常见的分歧。我们人类喜欢让列表从索引“1”开始，而计算机喜欢让列表从索引“0”开始。这是一场由来已久的战斗。就连罗马人也是从“I”开始计数的，但那主要是因为罗马数字直到公元 725 年才有了零这个字符——真是后知后觉！

而在这种情况下，输入数字的是人，他们从索引“1”开始计数。我们打印给人类看的输出也从索引“1”开始……

但在 Python 中，行是放在一个从索引“0”开始的列表中的！

## 解决问题的步骤：制定计划

我们需要做一些数学计算。

- 当我们要从人类（1-based）索引转换为计算机（0-based）索引时，需要从数字中减去 1。1 变成 0。
- 当我们要从计算机（0-based）索引转换为人类（1-based）索引时，需要给数字加上 1。0 变成 1。

因为我们使用 start 和 end 来索引列表，我倾向于让它们是 0-based 的，因为列表本身就是 0-based 的。

这里有一个通用的经验法则：

- 当用户输入一个 1-based 的数字时，尽快将其转换为 0-based，供程序内部使用。
- 当你必须显示一个 1-based 的数字时，尽可能长时间地保持 0-based，只在最后输出时再转换。

尽量减少这些转换，只在输入和输出时进行，可以帮你省去很多头疼的问题。

不应该做什么：不要直接到处加上 +1 和 -1，然后指望一切顺利。那样做无疑会走向疯狂。停下来，理解问题，制定计划。然后再执行。

## 解决问题的步骤：执行计划

我要在这里写一个小辅助函数，用来把 0-based 索引转换为 1-based 索引，因为我想我们会在很多地方用到它。而且它能帮助让代码更清晰；与其到处写一堆 +1 和 -1，不如用一个对将来阅读代码的人具有一定意义的函数名。

```python
def one_to_zero(n):
    """将一个数字从1-based索引转换为0-based索引。"""
    return n - 1

接下来做什么最简单的事情？“删除一行”怎么样？

## 解决问题的步骤：理解问题

我们想要删除一行。这就像从包含所有行的列表中移除一个元素一样简单。

我们只需要知道要移除的元素编号。

当然，用户是在 `d` 命令后面输入它的，所以我们可以从那里获取。

但记住：用户输入的是 1-based 的！我们在用这个数字删除一行之前，必须将它转换为 0-based……否则我们会删除错误的行。

## 解决问题的步骤：制定计划

所以我们应该能够：

- 在主输入循环中添加一个处理函数
- 在删除处理函数中，获取要删除的行号
- 将其转换为 0-based
- 从所有行组成的列表中删除那一行

稍微查一下帮助文档就会发现，`pop()` 方法会从列表中移除指定索引处的元素：

```text

    移除并返回索引处的项（默认是最后一项）。
```

## 解决问题的步骤：执行计划

让我们在主输入循环中添加对处理函数的调用，只要用户请求删除操作：

现在让我们编写删除处理函数。一开始它和列出内容的处理函数很相似：我们要获取用户输入的行号，并将其转换为 0-based。

然后确保它在有效范围内。

然后用 `pop()` 方法删除那一行。

```python
def handle_delete(args, lines):
    """删除文件中的一行。"""
    if len(args) == 1:

    else:
        print("usage: d line_num")
        return
    # 确保行号在有效范围内
    if line_num < 0 or line_num >= len(lines):
        print("no such line")
```

```python
def write_file(lines, filename):
    """Write a file to disk"""
    with open(filename, "w") as f:
        for line in lines:
            f.write(line)
```
```

```
```python
def handle_write(args, lines):
    """Handle the write command"""
    if len(args) == 1:
        filename = args[0]
    else:
        print("usage: w filename")
        return
    write_file(lines, filename)
```
```

### 14.5 使用异常进行错误处理

问题解决步骤：理解问题

异常是表示出了问题另一种方式。

我们已经见过一些这些。例如，如果我们运行执行以下操作的代码：

```python
int("Hello!")  # Convert Hello! to integer
```

Python 会不高兴。“Hello!”不是它听说过的数字。当我们运行它时，我们会得到这条消息，程序退出：

```text
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ValueError: invalid literal for int() with base 10: 'Hello!'
```

这就是异常的实际作用。我们尝试了一些代码，它引发了异常来告诉我们我们正在做的事情根本行不通。

异常因 Python 中的各种原因而被引发（有时也称为抛出）。

尝试打开一个不存在的文件进行读取：

```text
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
FileNotFoundError: [Errno 2] No such file or directory: 'keyser_soze.txt'
```

尝试将一个数字除以零：

```text
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ZeroDivisionError: division by zero
```

你看到的异常最后一行的那些第一个缩写词？那就是发生的异常的名称。

```text
ValueError
FileNotFoundError
ZeroDivisionError
```

因此，就像使用返回值来指示错误一样，异常也指示发生了错误。

现在——我们如何检测它并做些什么？

### 14.6 捕获异常

问题解决步骤：理解问题

请耐心，因为这段代码在执行方式上有点不同。

我们将结合使用两个新语句：`try` 和 `except`。让我们直接用一个可以剖析的例子开始：

```python
try:
    x = input("Enter a number: ")
    x = int(x)  # Convert to integer
    print(x * 1000)
except ValueError:
    print(f'error converting "{x}" to integer')
```

那里发生了什么？先看大块。我们有一个 `try` 块和一个 `except` 块。

把 `try` 块想象成在用户每次都输入正确信息的那种光鲜梦幻世界中你想要执行的代码。

就像用户输入 3490，然后它顺利转换为整数，然后你打印出 3490000。

完美。

但如果用户输入 beans 而不是数字呢？`int()` 会大发雷霆并引发 `ValueError`，就像我们之前看到的那样。

这里的魔力是，如果发生了这种情况，`try` 块的执行会立即停止，Python 将控制权转移到匹配的 `except` 块（如果存在）。

例如，这里是一个成功的运行：

```text
Enter a number: 3490
3490000
```

这里是一个引发异常的运行：

```text
Enter a number: beans
error converting "beans" to integer
```

你看它如何直接转移控制到 `except` 块中？

这就是我们处理异常的方式！

### 14.9 获取更多异常信息

每个异常实际上都是一个类的实例。而类名就是你在 except 子句中使用的名称。

因为它是实例，所以它附带了一些我们可以获取的额外信息，但首先，我们必须将其绑定（赋给）一个变量名。我们可以用 as 语句做到这一点。

```python
try:
    1 / 0
except ZeroDivisionError as e:  # e is a reference to the exception
    print(e)
    print(repr(e))  # Print its representation
```

结果为：

division by zero
ZeroDivisionError('division by zero')

这对于获取更详细的信息可能很有用。在上一章的示例中，我们捕获 ValueError，但我们看到了三种可能导致它的不同情况。我们可以使用这种技术在需要时向用户提供有关异常性质的更详细信息。

所有异常都有一个名为 args 的属性，它是创建异常时传入参数的列表。其中第一个通常是人类可读的错误消息。

例如，这段代码：

```python
try:
    1 / 0
except Exception as e:
    print(e.args[0])
```

打印出有用的消息：

division by zero

此外，任何基于 IOError 的异常都包含字符串属性 strerror，其中包含与错误对应的人类可读错误消息。你可以在异常文档²中找到从 IOError 派生的异常列表。

### 14.10 捕获所有异常

不指定特定异常的 catch 语句会捕获所有先前未捕获的异常。

因此，空白的 catch 应该 definitely 放在最后，在所有其他 catch 之后。Python 会在第一个匹配的 catch 处停止，即使它是“捕获所有”。

当你在任何 catch 中时，你可以查看内置函数 sys.exc_info() 的结果。该函数返回一个元组（如果你不熟悉元组，就把它想成“列表”）包含三条信息：异常的类型、对异常本身的引用，以及 traceback³。

让我们修改我们的除法程序以捕获所有异常并打印出异常信息：

```python
import sys

try:
    x, y = input('Enter two numbers separated by a space: ').split()
    x = int(x)
    y = int(y)
    print(f'{x} / {y} == {x / y}')

except:
    print(sys.exc_info())
```

这里有一些示例运行：

```
Enter two numbers separated by a space: 1
(<class 'ValueError'>, ValueError('not enough values to unpack (expected 2, got 1)'), <traceback object at 0x7f789974f8b0>)
```

```
Enter two numbers separated by a space: a b
(<class 'ValueError'>, ValueError('invalid literal for int() with base 10: 'a''), <traceback object at 0x7f6d0c9732c0>)
```

```
Enter two numbers separated by a space: 1 0
(<class 'ZeroDivisionError'>, ZeroDivisionError('division by zero'), <traceback object at 0x7fe2ea373040>)
```

这种方式捕获并检查异常并不常见。但它是你工具箱中的另一个工具。

谨慎使用捕获所有。它们可能会隐藏你未预料到且本应放行的异常。实际上它们很少见。

### 14.11 最后 finally

问题解决步骤：理解问题

这里有一个更大的结构。我们已经讨论过 try 和 catch，但有一种方法可以添加无论发生什么、无论是否发生异常都会运行的代码。

它是 finally 子句，位于 except 子句之后。

再次强调，这段代码无论如何都会运行。

```
try:
    print(1/1)
except ZeroDivisionError:
    print("Divide by zero!")
finally:
    print("All done!")
```

上述代码将打印：

```
1
All done!
```

如果我们把第一行改为 print(1/0)，我们会得到除零异常，输出将是：

```
Divide by zero!
All done!
```

在所有情况下，finally 块都会运行。

如果需要，你可以使用这个块来执行最终化或清理代码。

try-except 非常常见。finally 则没那么常见，但也不算完全罕见。

### 14.12 还有什么？else！

问题解决步骤：理解问题

就当你以为 try-except-finally 就是全部时，原来我们可以在其中添加 else，形成 try-except-else-finally。

完全有可能你永远不会看到这个，但我想在这里快速提一下。只是瞥一眼：

```
try:
    print("This is what we're trying to do")
    print("and where exceptions might occur.")

except:
    print("Caught an exception!")

else:
    print("This only runs if there was no exception.")

finally:
    print("This runs no matter what.")
```

使用 else 可以在发生异常时让你更好地控制程序的流程。

### 14.15 重新引发异常

有时你可能对异常发生感兴趣，但又不想让它停止。你希望它继续传播，以便调用方也能看到它。

我们可以在 catch 中使用单独的 raise 很简单地做到这一点。

下面的函数如果发生 ValueError 会记录它，但随后会重新引发它，以便主代码中的 try 块可以捕获它：

```
def makeint(x):
    try:
        return int(x)
    except ValueError:
        print("Hey, I saw an exception!")
        print("But I'll let someone else handle it.")
        raise  # Re-raise the exception
try:
    x = makeint("bee")
except ValueError as v:
    print(f'Exception: {v}')
```

这会输出：

```
Hey, I saw an exception!
But I'll let someone else handle it.
Exception: invalid literal for int() with base 10: 'bee'
```

### 15.4 负数

我在这里不多讲，但负数是小于 0 的数，用数字前面的减号表示。−7 表示“比 0 小 7”。

我知道这是个疯狂的概念。比如，桌子上怎么会有 −12 个苹果？这似乎不太符合实际。

但一个更贴近生活的例子可能是我说：“我欠你 −35 美元！”这实际上意味着，你欠我 35 美元！

记住一些简单的规则：

负数乘以负数，结果是正数。

−3 × −7 = 21

负数乘以正数，结果是负数。

−3 × 7 = −21

负数加上正数，就像从正数中减去这个负数：

−7 + 100 = 93

或者，等价地：

100 + (−7) = 100 − 7 = 93

### 15.5 绝对值

可以把绝对值想象成数轴上任何数离 0 有多远。

10 离 0 有 10 远。10 的绝对值是 10。

2.8 离 0 有 2.8 远。2.8 的绝对值是 2.8。

嗯，这似乎有点平淡。为什么要费心？

原因在这里：

−17 离 0 有 17 远。−17 的绝对值是 17。

规则是：

- 正数的绝对值是它本身。
- 负数的绝对值是它的相反数，也就是它的正数版本。

总而言之，如果是负数，绝对值会把它变成正数。

在数学符号中，我们用竖线表示绝对值：

x = −17 如果 x 是 −17...
|x| = 17 ...那么 x 的绝对值是 17。
|12| = 12 12 的绝对值是 12。
| −13.8 | = 13.8 −13.8 的绝对值是 13.8。

在 Python 中，我们使用内置函数 `abs()` 计算绝对值：

```
print(abs(-17))  # 17
print(abs(28.2))  # 28.2
```

就优先级而言，你可以把绝对值看成类似括号的东西。先计算绝对值内部的内容，然后再对结果取绝对值。

### 15.6 指数的威力

我想这还不算太糟。

那就更进一步。我想把 7 自己乘自己 3490 次。你处理这件事的时候，我要去酒吧了。完成后告诉我。

幸运的是，数学家们很懒。他们讨厌多写东西，所以凭空发明新的记法来避免额外的工作。就像我不断把厨房垃圾压实，这样就不用跑出去倒一样。

实际上，不，真的不是那样²。

所以他们发明的是另一种表示“3490 个 7 相乘”的方式，不用写一长串 7 和 ×。它看起来像这样：

7³⁴⁹⁰（读作“7 的 3490 次方”）

这意味着 3490 个 7 相乘。我们把这称为“幂运算”或“乘方”。

或者，换句话说：

7⁸ = 7 × 7 × 7 × 7 × 7 × 7 × 7 × 7

我们有很多有趣的事实！准备好了吗？

在例子 7⁸ 中，数字 7 我们称为*底数*，数字 8 我们称为*指数*。

```

所以就是这样。n⁰ = 1，对所有 n 成立。

### 15.8 平方根

平方根是个有趣的概念。它是平方的逆运算，如果你还记得前面章节的内容，平方就是将一个数提升到 2 次幂。而平方根正是它的逆运算。

它问的问题是：“对于给定的一个数，我需要让哪个数与自身相乘，才能得到这个数？”

我们来举例说明！

但在举例之前，那个看起来像闪电形状的线条符号，就是表示一个数的平方根的数学符号。

我们来求 9 的平方根：
√9 = ?

这其实是在问：哪个数与自身相乘得到 9？或者换句话说，哪个数的 2 次幂等于 9？再换句话说，哪个数的平方等于 9？

到现在你应该已经想到了：
3 × 3 = 9
同样地：
3² = 9
所以：
√9 = 3

其他一些呢？
√16 = ? √25 = ? √36 = ? √12180100 = ?

注意这些数的结果都是整数。如果一个数的平方根是整数，我们就把这个数称为完全平方数。16、25、36……这些全都是完全平方数。

但你其实可以对任何数开平方根。
√17 ≈ 4.123105625617661

17 不是完全平方数，因为它的结果不是整数。

现在，你可能在想：如果尝试对一个负数开平方根会发生什么？
√−100 = ?

稍加思考后，你可能会意识到，没有任何数乘以自身会得到 −100，所以……
你能怎么办？

你可能会想，“我们完蛋了！”但数学家们可不会。他们简单地定义了：
√−1 = i

并围绕他们所谓的虚数³建立了一整套数学体系，这些虚数实际上有着一些惊人的应用。不过这些内容你可以自己去查阅。

除了平方根，还有立方根。它问的是：“哪个数的立方得到这个数？”它用根号上方的一个小 3 来表示：
∛27 = x

它是方程：
x³ = 27

的逆运算。

你能算出 x 是多少吗？

那在 Python 里怎么做呢？

对于平方根，推荐的方法是使用你导入的 `math` 模块中的 `sqrt()` 函数：

```
import math

print(math.sqrt(12180100))  # prints 3490.0
```

那立方根呢？好吧，对于立方根，我们要回到指数并学习一个小秘密。你可以将数提升到分数次幂。关于这个有很多规则，但简单来说，下面的等式是成立的：

√x = x^(1/2)   ∛x = x^(1/3)   ∜x = x^(1/4)

依此类推。将一个数提升到 1/3 次幂，等同于对它开立方根！

比如，如果我们想计算 4913 的立方根，可以这样算：

∛4913 = 4913^(1/3) = 17

在 Python 里，你可以用普通的幂运算符 `**` 来完成：

```
print(4913**(1/3))  # prints 16.999999999999996
```

嘿——等一下，这不是 17！这是怎么回事？

其实，计算机中的浮点数并不是精确的。它们很接近，但不是精确值。这是开发人员需要注意的事情，要么接受它，要么绕开它。

最后，因为平方根、立方根以及所有其他根本质上都是指数的另一种形式，所以它们与指数具有相同的优先级：在算术运算之前计算。

### 15.9 阶乘

阶乘是个有趣的函数。

所以我需要计算：

答案是 120。

6! = 6 × 5 × 4 × 3 × 2 × 1 = 720

### 15.10 科学计数法

对于非常大的浮点数，你可能会看到这样的内容：

```
print(2.7**100)  # 1.3689147905858927e+43
```

末尾的 `e+43` 是什么？

这就是我们所说的科学计数法。它是一种书写非常大（或非常小）数字的简写方式。

上面的数字 `1.3689147905858927e+43`，在数学上表示：

1.3689147905858927 × 10^43

10^43 是一个很大的数字。所以用 1.3689……去乘以它，结果确实是一个非常大的数。

但这还没完。我们也可以用科学计数法表示非常小的数字。

```
print(3.6/500000000000000000)  # 7.2e-19
```

`7.2e-19` 表示：

7.2 × 10^-19

而 10^-19 是一个非常小的数字（非常接近 0——记得 10^-19 = 1/10^19），所以用它乘以 7.2 的结果也非常小。

记住这些：
- 如果末尾看到 `e-` 加某个数，说明这是一个非常小的数字（接近 0）。
- 如果末尾看到 `e+` 加某个数，说明这是一个非常大的数字（远离 0）。

### 15.11 对数

做好准备，因为接下来会有点奇怪。

好吧，也不算太怪，但确实有点怪。

对数，通常简称为 log，有点像指数的逆运算。

但它和平方根那种“逆”并不是同一种方式。

是不是很方便？

对于对数，我们说“以 x 为底 y 的对数”。例如“以 2 为底 32 的对数”，写作：

log₂ 32

它问的是：“2 的多少次幂等于 32？”用数学表示：

下面两个等式都成立：

x = log₂ 32
2^x = 32

那么答案是什么？稍微尝试一下，你可能会发现 2^5 = 32，因此：

x = log₂ 32 = 5

虽然对数的底可以是任何数，但常见的主要有三种：2、10 和 e。

以 2 为底在编程中非常常见。事实上，它太常见了，以至于如果你在计算机相关语境中看到有人写 `log n`，你应该默认他们指的是 log₂ n。

e 是自然对数的底数，在数学中常见，在计算机领域则不那么常见。

那它们有什么用呢？

在编程中，你经常看到对数的地方是使用大 O 表示法来表示计算复杂度。

要在 Python 中计算一个数的对数，可以使用 `math` 模块中的 `log()` 函数。将底数作为第二个参数传入（如果不指定，则计算自然对数，即以 e 为底）。

例如，计算 log₂ 999：

```
import math

print(math.log(999, 2))  # Prints 9.96434086779242

# Because 2^9.96434086779242 == 999. Ish.
```

这里需要记住的重要一点是：当一个数变大时，它的对数仍然保持较小。下面是一些例子：

| x | log₂x |
|---|------|
| 1 | 0.0000 |
| 10 | 3.3219 |
| 100 | 6.6439 |
| 1000 | 9.9658 |
| 10000 | 13.2877 |
| 100000 | 16.6096 |
| 1000000 | 19.9316 |
| 10000000 | 23.2535 |

一个很大的数，其以 2 为底的对数往往是一个小得多的数。

### 15.12 舍入

当我们对一个数进行舍入时，我们是在寻找某个小数位数下最接近的数，并舍弃所有比该小数位数更小的位数。

默认情况下，我们指的是 0 位小数，也就是想舍入到最近的整数。

所以如果我说“将 2.3 舍入到最近的整数”，你会回答“2”，因为 2 是离 2.3 最近的整数。

如果我说“将 2.8 舍入到最近的整数”，你会回答“3”，因为 3 是离 2.8 最近的整数。

当我们舍入到一个更大的数时，称为向上舍入。

另一个方向则是向下舍入。

但如果我说“将 2.5 舍入到最近的整数”呢？它正好位于 2 和 3 中间！在这种情况下，按照惯例，我们很多人学的是向上舍入。所以答案是 3。

我们也可以通过声明舍入方向来强制一个数向某个特定方向舍入。

“将 x 除以 3，然后向上舍入。”

在 Python 中，我们有几种舍入方式。

可以使用内置的 `round()` 函数。

但它的行为和我们平时习惯的略有不同。值得注意的是，像 1.5、2.5、3.5 这样与两个整数等距的数字，总是舍入到最近的偶数。这通常被称为“四舍六入五成双”或“银行家舍入”。

```
round(2.8)  # 3
round(-2.2) # -2
round(-2.8) # -3

round(1.5)  # 2
```




```
round(2.5)  # 2
round(3.5)  # 4
```

你还可以告诉 round() 你想四舍五入到多少位小数：

```
round(3.1415926, 4)  # 3.1416
```

请注意，由于浮点数精度的限制，Python 还有一些奇怪的舍入行为⁶。

若要始终向上或向下取整，请使用 math 模块中的 ceil() 和 floor() 函数。

ceil() 返回大于该数字的下一个整数，而 floor() 返回小于该数字的前一个整数。

对于正数来说，这一点非常合理：

```
import math

math.ceil(2.1)  # 3
math.ceil(2.9)  # 3
math.ceil(3.0)  # 3
math.ceil(3.1)  # 4

math.floor(2.1)  # 2
math.floor(2.9)  # 2
math.floor(3.0)  # 3
math.floor(3.1)  # 3
```

但对于负数，它的行为方式可能与你预期的不同：

```
import math

round(2.3)      # 2
math.floor(2.3) # 2

round(-2.3)     # -2
math.floor(-2.3) # -3 (!!)

round(2.8)      # 3
math.ceil(2.8)  # 3

round(-2.8)     # -3
math.ceil(-2.8) # -2 (!!)
```

round() 会取最接近的整数，而 floor() 会取下一个更小的整数。对于负数，就是离零更远的那个整数。而 ceil() 则正好相反。

如果你希望有一个能同时处理正数和负数的向上取整函数，你可以编写一个类似这样的辅助函数：

```
import math

def round_up(x):
    return math.ceil(x) if x >= 0 else math.floor(x)

round_up(2.0)  # 2
round_up(2.1)  # 3
round_up(2.8)  # 3

round_up(-2.0)  # -2
round_up(-2.8)  # -3
```

我把 round_down() 留作练习。:)

```

round_up(-2.8)  # -3
```

如果你希望始终向上取整到下一个整数，而不是采用银行家舍入法，可以使用这个技巧：将数字加上 0.5，然后将其转换为 int()。（如果数字为负数，则减去 0.5。）

```
int(0.5 + 0.5)  # 1
int(1.5 + 0.5)  # 2
int(2.5 + 0.5)  # 3

int(2.8 + 0.5)  # 3
int(2.2 + 0.5)  # 2

int(-2.2 - 0.5)  # -2
int(-2.8 - 0.5)  # -3
```

### 15.13 大数

Python 非常擅长处理大整数。事实上，它拥有我们所说的*任意精度整数运算*能力。这意味着我们可以保存大到内存能处理的数字，而这个数字可以非常大。

所以如果你让 Python 计算 100000!，它会照做。顺便提一下，结果有 465,575 位数字。完全没问题。

但浮点数（带小数点的数字）则*并非如此*。Python 通常用 64 位来表示浮点数，这意味着精度是有限制的——你的数字最多只能有 16 位，不过你可以把它提升到巨大的正次幂或负次幂，从而得到非常大或非常小的数。

浮点数非常出色，因为它能表示极大和极小的数字，但你能使用的位数是有限的。

### 17.3 Python 编译器优化

如果你取上面来自 REPL 的这个例子：

并且你把它放在一个 python 程序中，比如 test.py：

### 17.4 驻留

在上面同一个例子中：

```
>>> s = "Beej!"
>>> t = "Beej!"
>>> s is t
False
```

如果我们使用不同的字符串，比如 "Alice" 呢？

```
>>> s = "Alice"
>>> t = "Alice"
>>> s is t
True
```

True?? 这是怎么回事？为什么 Alice 会得到特殊待遇？
或者看这个：

```
>>> x = 257
>>> y = 257
>>> x is y
False
```

这没问题——但然后看看这个，用 256 代替 257：

```
>>> x = 256
>>> y = 256
>>> x is y
True
```

又是 True？
我们正在进入 Python 的一个深层语言特性，叫做 internment。基本上 Python 确保某些特定数据值的内存中只有一个副本。
对于这些值，所有变量都将引用内存中的同一项。
它们是：

- 介于 -5 和 256 之间（含）的整数。
- 只包含字母、数字或下划线的字符串。
- The `None` object.

这就是为什么 "Beej!" 没有被驻留（因为它包含标点符号），而 "Alice" 被驻留的原因。

你可以用 `sys.intern()` 来驻留自己的字符串以优化字典查找，但这是 99.99999% 的 Python 程序员永远不会费心去做的事情。

### 18.1 如何像大佬一样计数

你们现在应该都已经明白我有多爱数字了。所以我会继续谈论它们！耶！

在某个时候，你可能听说过计算机运行在一堆 1 和 0 上。它们是二进制的。但这是什么意思？

作为人类，我们习惯于数字。我们经常使用它们。7 个小矮人。限速 55。墙上 99 瓶 [你最喜欢的饮料]。

我们使用数字 0-9。并且重复使用它们。

计算机则只有两个数字：0 和 1。

这似乎有点限制。如果想超过 1，比如说到 2，会怎样？

幸运的是，有一个变通方法。当计算机想要超过 1 时，它们做的事情和我们人类想要超过 9 时做的一样：我们都会增加另一个位。

作为一个在桌上数苹果的人，你从 0、1 开始，继续数下去... 7、8、9... 然后个位上的数字用完了，个位代表我们迄今为止看到的单个物品（1s of items）数量。

所以你增加另一个位，十位，它代表我们迄今为止看到的物品的 10s 数量。

如果我们数到 27 个苹果，一个由 2 和 7 组成的数字，我们知道我们有 2 10s 的苹果，和 7 1s 的苹果。让它沉淀一下。十位上的每个值都值 10 个苹果。而个位上的每个值都值 1 个苹果。

因此对于 27 个苹果，我们有 2 × 10 + 7 × 1 = 27 个苹果。

让我们用 $100 做同样的事情。用这个，我说百位上有一个 1，十位上有一个 0，个位上有一个 0。这意味着值是 1 × 100 + 0 × 10 + 0 × 1 或 $100。

计算机在数字用完时也会经历同样的过程，只是它们用完数字要快得多，因为它们只有两个。

让我们用二进制数苹果。0、1、... 哦不！我们用完了数字。我们必须增加另一个位。除了这次，在二进制中，它不是十位...而是二位。

所以基数也与数字中任何一位代表的值相关联。这是有道理的，因为我们在数字用完时必须增加一个新位，如果我们有数字 0-9，那么下一个位必须代表 10s 的数量，因为那是 9 之后的东西。
