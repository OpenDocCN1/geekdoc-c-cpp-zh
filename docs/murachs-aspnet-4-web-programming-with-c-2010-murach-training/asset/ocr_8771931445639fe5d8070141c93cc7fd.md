# The Product List application

![](bbox=[0.155, 0.105, 0.835, 0.67])

# Description

+   - The ProductList application uses a ListView control to display a list of all the products in the Products table. The ListView control is bound to a SqlDataSource control that works in DataSet mode.
+   - The ListView control uses Item and AlternatingItem templates to display every other row with a different background color.
+   - A DataPager control is used within the ListView control to display four products on each page.
