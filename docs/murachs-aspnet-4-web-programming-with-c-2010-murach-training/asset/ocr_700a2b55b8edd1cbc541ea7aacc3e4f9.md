# Description

+   - .NET applications work by using services of the .NET Framework. The .NET Frame-\nwork, in turn, accesses the operating system and computer hardware.

+   - The .NET Framework consists of two main components: the .NET Framework Class\nLibrary and the Common Language Runtime.

+   - The .NET Framework Class Library provides pre-written code in the form of classes that\nare available to all of the .NET programming languages. These classes are organized into\ngroups called namespaces. The classes that support ASP.NET web programs are stored in\nthe System.Web namespace.

+   - The Common Language Runtime, or CLR, manages the execution of .NET programs by\ncoordinating essential functions such as memory management, code execution, security,\nand other services.

+   - The Common Type System is a component of the CLR that ensures that all .NET applica-\ntions use the same data types regardless of what programming languages are used to\ndevelop the applications.

+   - All .NET programs are compiled into Microsoft Intermediate Language (MSIL) or just\nIntermediate Language (IL), which is stored on disk in an assembly. This assembly is\nthen run by the CLR.
