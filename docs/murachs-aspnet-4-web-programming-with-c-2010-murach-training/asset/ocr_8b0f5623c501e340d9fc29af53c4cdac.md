# Description

+   - A *role* allows you to apply the same access rules to a group of users.
+   - Each user may be associated with one or more roles.
+   - By default, roles are disabled. To enable them, you need to click on the Enable Roles link in the Security tab.
+   - Once you enable roles, you can click on the Create or Manage Roles link in the Security tab to display the page shown above. This page lets you add roles, manage all users associated with a role, and delete roles.
