# The dialog box for defining the Select statement

![](bbox=[0.155, 0.099, 0.706, 0.456])

# Description

+   - To configure the Select statement, you choose whether you want to use a custom SQL statement or specify the columns from a table or view in the database.
+   - If you choose to select the columns from a table or view, you can choose the table or view and columns you want retrieved. You can click the ORDER BY button to specify how the records should be sorted. And you can click the WHERE button to specify the selection criteria as shown in figure 13-6.
+   - If you choose to use custom SQL statements, the next dialog box lets you enter the SQL statements as shown in figure 13-8 or click the Query Builder button to build the query as shown in figure 13-9.
