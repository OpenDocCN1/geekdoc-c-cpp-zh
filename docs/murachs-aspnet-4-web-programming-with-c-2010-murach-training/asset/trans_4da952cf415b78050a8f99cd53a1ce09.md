
## 如何使用图像映射控件

*图像映射*是一幅具有多个可点击区域的图像，这些区域称为*热区*。图6-20展示了*图像映射控件*如何在ASP.NET中提供创建图像映射的简单方式。

图像映射控件允许你创建三种类型的热区：矩形、圆形和多边形。此图中的示例显示了两本书，每本书都有一个多边形热区。每个热区由PolygonHotSpot元素定义，多边形形状在Coordinates属性中使用一系列指示热区顶点的x和y坐标来定义。

可以使用类似的技术来定义矩形和圆形热区。要创建矩形热区，可以使用Top、Bottom、Left和Right属性指定其各边的位置。要创建圆形热区，可以使用X、Y和Radius属性指定其圆心的x和y坐标以及半径长度。

遗憾的是，Visual Studio没有提供便捷的点击式编辑器来定义热区。因此，你需要使用单独的图形程序来确定图像映射热区的x和y坐标，尤其是多边形热区。一旦确定了这些坐标，就可以返回Visual Studio为图像映射创建热区元素。

图像映射的HotSpotMode属性指示当用户点击热区时，页面是链接到另一个页面（Navigate）还是回发到服务器（PostBack）。如果将此属性设置为Navigate，则应将每个热区的NavigateUrl属性设置为希望在点击热区时显示的页面URL。如果将此属性设置为PostBack，则应将每个热区的PostBackValue属性设置为希望在点击热区时传递给图像映射Click事件处理程序的值。然后，可以在Click事件处理程序中使用e参数的PostBackValue属性来确定点击了哪个热区。此图中的代码示例说明了这一点。

请注意，你也可以为每个热区单独指定HotSpotMode属性，而不是为整个图像映射指定。这样，当点击某些热区时执行回发，当点击其他热区时链接到其他页面。

### 图像映射控件的 aspx 代码

```aspx
<asp:ImageMap ID="imapBooks2009" runat="server"
    ImageUrl="~/new_books_2009.jpg" HotSpotMode="PostBack"
    OnClick="imapBooks2009_Click">
    <asp:PolygonHotSpot Coordinates="1, 19, 114, 0, 122, 53, 106, 143,
        26, 158, 24, 149" PostBackValue="C++" />
    <asp:PolygonHotSpot Coordinates="128, 21, 241, 42, 218, 178, 103, 159"
        PostBackValue="JavaScript" />
</asp:ImageMap>
```

### 图像映射的 Click 事件处理程序

```csharp
protected void imapBooks2009_Click(object sender, ImageMapEventArgs e)
{
    string book;
    if (e.PostBackValue.Equals("C++"))
        book = "C++ 2008";
    else
        book = "JavaScript and DOM Scripting";
}
```

### 图像映射常用属性

| 属性 | 说明 |
|---|---|
| ImageUrl | 要显示的图像的URL。 |
| HotSpotMode | 设置热区的行为。PostBack导致页面回发，Navigate链接到另一个页面。此属性也可以为各个热区元素指定。 |

### 说明

- *图像映射控件*允许你显示带有*图像映射*的一个或多个热区。当用户点击热区时，页面要么回发，要么链接到另一个页面。
- 要在用户点击热区时回发页面，请将HotSpotMode属性设置为PostBack，并将热区的PostBackValue属性设置为希望传递给Click事件处理程序的值。
- 要在用户点击热区时链接到另一个页面，请将HotSpotMode属性设置为Navigate，并在热区的NavigateUrl属性中指定页面的URL。
- 要创建CircleHotSpot元素，请使用X、Y和Radius属性。要创建RectangleHotSpot元素，请使用Top、Bottom、Left和Right属性。要创建PolygonHotSpot元素，请使用Coordinates属性。

### 日历控件的 SelectionChanged 事件处理程序

```csharp
protected void clnArrival_SelectionChanged(object sender, EventArgs e)
{
    ddlMonth.SelectedValue = clnArrival.SelectedDate.Month.ToString();
    ddlDay.SelectedValue = clnArrival.SelectedDate.Day.ToString();
    clnArrival.Visible = false;
    ibtnCalendar.Visible = true;
}
```

### Calendar 类的常用属性

| 属性 | 说明 |
