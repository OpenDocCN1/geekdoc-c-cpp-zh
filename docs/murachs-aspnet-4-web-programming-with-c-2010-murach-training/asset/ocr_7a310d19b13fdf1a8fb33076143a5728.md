The third group of server controls defines a label with the text “Quantity:” followed by a text box named txtQuantity. Then, two validator controls provide data validation for the text box. Notice that both specify txtQuantity in the ControlToValidate attribute and Dynamic in the Display attribute. The range validator also provides MaximumValue, MinimumValue, and Type attributes, which specify that the quantity must be an integer in the range from 1 to 500.

The last group of controls for this page contains the two buttons. Here, the OnClick attribute names the event handler that will be executed when this button is clicked. In contrast, the btnCart button uses the PostBackUrl property to indicate that when the user clicks the button, the Cart.aspx page should be requested rather than the Order.aspx page. Since the CausesValidation attribute is set to False, the validation controls for the txtQuantity text box won’t be executed when this button is clicked.
