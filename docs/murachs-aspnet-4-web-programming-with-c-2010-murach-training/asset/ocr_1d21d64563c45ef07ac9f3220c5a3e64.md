# How to use
the GridView control

In this chapter, you’ll learn how to use the GridView control. This control lets you display the data from a data source in the rows and columns of a table. It includes many advanced features, such as automatic paging and sorting. It lets you update and delete data with minimal C# code. And its appearance is fully customizable.
