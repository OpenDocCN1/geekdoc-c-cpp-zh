# The web server controls presented in this chapter

| Control | Name | Suggested prefix | Description |
|---|---|---|---|
| A | Label | lbl | Displays descriptive information. |
| [icon] | TextBox | txt | Lets the user enter or modify a text value. |
| [icon] | Button | btn | Submits a page for processing. |
| [icon] | LinkButton | lbtn | Submits a page for processing. |
| [icon] | ImageButton | ibtn | Submits a page for processing. |
| [icon] | HyperLink | hlnk | Lets the user move to another page in the application. |
| [icon] | DropDownList | ddl | Lets the user choose an item from a list that drops down from the control. |
| [icon] | ListBox | lst | Lets the user choose one or more items from a list. |
| [icon] | CheckBox | chk | Turns an option on or off. |
| [icon] | CheckBoxList | cbl | Turns options in a list of options on or off. |
| [icon] | RadioButton | rdo | Turns an option on or off. Only one radio button in a group can be on. |
| [icon] | RadioButtonList | rbl | Turns an option in a list of options on or off. Only one radio button in the list can be on. |
| [icon] | Image | img | Displays an image. |
| [icon] | ImageMap | imap | Displays an image with one or more clickable areas that submit the page for processing when clicked. |
| [icon] | BulletedList | blst | Displays a bulleted or numbered list. |
| [icon] | Calendar | cln | Displays a calendar and lets the user select one or more dates. |
| [icon] | FileUpload | upl | Displays a text box and a button that lets the user browse for a file to be uploaded. |

# Description

+   - The button, image button, and link button controls all provide the same functionality. They differ only in how they appear on the form.
+   - The check box list and radio button list controls serve as containers for a collection of check box or radio button items. They’re typically used to create a list of check boxes or radio buttons that are bound to a data source.
