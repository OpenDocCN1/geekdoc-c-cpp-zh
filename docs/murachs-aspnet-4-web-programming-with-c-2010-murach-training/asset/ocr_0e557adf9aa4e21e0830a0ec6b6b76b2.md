# Description

+   - The *Secure Sockets Layer*, or SSL, is the protocol used by the World Wide Web that allows clients and servers to communicate over a *secure connection*.
+   - With SSL, the browser encrypts all data that’s sent to the server and decrypts all data that’s received from the server. Conversely, the server encrypts all data that’s sent to the browser and decrypts all data that’s received from the browser.
+   - SSL is able to determine if data has been tampered with during transit.
+   - SSL is also able to verify that a server or a client is who it claims to be.
+   - The URL for a secure connection starts with **HTTPS** instead of **HTTP**.

# Notes

+   - To test an application that uses SSL, you must run the application under the control of IIS. For information on how to do that, see chapter 4.
+   - With some browsers, a lock icon is displayed when a secure connection is being used.
