# How to authenticate and authorize users

In the last chapter, you learned how to secure the transmission of data between client and server. Now, you’ll learn how to restrict access to some of the pages of an application, but let authorized users access those pages. To provide this functionality without writing a single line of code, you can use the Web Site Administration Tool and the login controls.
