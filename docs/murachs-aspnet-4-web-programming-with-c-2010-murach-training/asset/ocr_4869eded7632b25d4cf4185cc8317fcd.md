# Description

+   - *List boxes* and drop-down lists typically contain one or more list items. You can load list items by using C# code or the ListItem Collection Editor. See figures 6-13 and 6-14 for details.
+   - A list box lets a user choose one or more items from a list of items. A drop-down list lets a user choose an item from a drop-down list of items.
