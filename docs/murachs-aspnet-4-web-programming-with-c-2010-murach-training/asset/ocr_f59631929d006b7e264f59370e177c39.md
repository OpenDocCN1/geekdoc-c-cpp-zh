# The four tabs of the Web Site Administration Tool

+   - **Home:** Displays the home page.
+   - **Security:** Lets you configure users, roles, and access rules. For more information, see chapter 19.
+   - **Application:** Lets you create custom application settings, configure SMTP email support (see chapter 20), control debugging and tracing settings, and start or stop the application.
+   - **Provider:** Lets you configure providers for features such as membership and roles.

# Description

+   - The Web Site Administration Tool lets you configure certain web.config settings using a browser-based interface.
+   - To start the Web Site Administration Tool, open the project in Visual Studio 2010 and choose Website→ASP.NET Configuration.
