# How to disable browser page caching

Figure 20-13 shows how you can use four ASP.NET methods to prevent a user’s browser from caching pages. All of these methods work by adding information to the HTTP headers that are sent to the browser along with the page.

Unfortunately, some browsers ignore these headers, so these techniques don’t guarantee that a page won’t be cached. Still, it’s not a bad idea to add the code in this figure to the Page_Load method of any ASP.NET page that gets important data like customer or product information.
