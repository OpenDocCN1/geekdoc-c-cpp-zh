# DetailsView template elements

| Element | Description |
|---|---|
| ItemTemplate | The template used for an individual field. |
| AlternatingItemTemplate | The template used for alternating fields. |
| EditItemTemplate | The template used for a field in Edit mode. |
| InsertItemTemplate | The template used for a field in Insert mode. |
| HeaderTemplate | The template used for the header text for a field. |

# The aspx code for a custom template field

```
<asp:TemplateField HeaderText="Name:">
    <ItemTemplate>
        <asp:Label ID="Label8" runat="server" Text='<%# Bind("Name") %>'>
        </asp:Label>
    </ItemTemplate>
    <EditItemTemplate>
        <asp:TextBox ID="txtName" runat="server" Text='<%# Bind("Name") %>' Width="200px" MaxLength="50">
        </asp:TextBox>
    </EditItemTemplate>
    <InsertItemTemplate>
        <asp:TextBox ID="txtName" runat="server" Text='<%# Bind("Name") %>' Width="200px" MaxLength="50">
        </asp:TextBox>
    </InsertItemTemplate>
    <HeaderStyle HorizontalAlign="Left" Width="150px" />
    <ItemStyle Width="250px" />
</asp:TemplateField>
```

# Description

+   - You can use template fields to control the appearance of the fields in a DetailsView control using the same techniques you use to work with template fields in a GridView control. See figure 14-15 in chapter 14 for more information.
