# Description

+   - The Configure Data Source dialog box asks you to identify the data connection for the database you want to use. If you’ve previously created a connection for that database, you can select it from the drop-down list. To see the connection string for that connection, click the + button below the drop-down list.
+   - To create a new connection, click the New Connection button to display the Add Connection dialog box. Then, enter the name of the database server in the Server Name text box or select it from the drop-down list. For SQL Server Express, you can use localhost\sqlexpress as the server name.
+   - After you enter the server name, select the authentication mode you want to use (I recommend Windows Authentication). Then, select the database you want to connect to from the Select or Enter a Database Name drop-down list.
+   - To be sure that the connection is configured properly, you can click the Test Connection button.
