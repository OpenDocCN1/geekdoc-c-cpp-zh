

## 如何包含外部样式表

```
<head runat="server">
    <title>Chapter 5: Future Value</title>
    <link href="Main.css" rel="stylesheet" type="text/css" />
</head>
```

## 如何将样式嵌入到HTML文档中（不推荐）

### 在style元素中包含样式表

```
<head runat="server">
    <title>Chapter 5: Future Value</title>
    <style type="text/css">
        h1 {
            color: blue;
            font-size: 16pt;
        }
    </style>
</head>
```

### 使用内联元素的style属性

```
<span style="color: red; font-size: 14pt;">Warning!</span>
```

## 使用两个样式表的网页部分

```
<head runat="server">
    <title>Chapter 5: Shopping Cart</title>
    <link href="Styles/Main.css" rel="stylesheet" type="text/css" />
    <link href="Styles/Order.css" rel="stylesheet" type="text/css" />
</head>
```

## 说明

- 只要可能，最佳实践是使用*外部样式表*。为此，你需要在head元素中编码一个link元素。
- 当你为外部CSS文件指定相对URL时，该URL是相对于当前文件的。
- 你可以在单个页面中包含两个或更多外部样式表。然后，第一个样式表中的样式首先应用，接着是第二个样式表中的样式，以此类推。
- 创建外部样式表后，你可以在页面的设计视图中为其生成link元素。为此，选择“格式→附加样式表”命令，然后在显示的“选择样式表”对话框中选择样式表。
- 你也可以在源视图中通过将样式表从解决方案资源管理器拖到页面的head元素来生成link元素。
- 如果使用内部样式表，样式会出现在文档head部分的style元素中。
- 如果使用内联样式，样式会出现在应用这些样式的内联元素的style属性中。

## CSS规则集的组成部分

![](img/c024ccf88e28c30c07dd410d4342288f_198_0.png)

## 一个简单的样式表

```
/* Adjust the styles for the body */
body {
    background-color: #F5F5F5;
}

/* Adjust the styles for the headings */
h1 {
    color: #FF0000;
}
h2 {
    font-style: italic;
    color: #00008B;
    border-bottom: 3px solid #00008B;
}

/* Adjust the styles for the paragraphs */
p {
    text-indent: 2em;
    margin-top: 0;
    margin-bottom: 5px;
}
```

## 说明

- 一个CSS规则集由一个选择器和一个声明块组成。在Visual Studio中，规则集被称为样式规则。
- CSS选择器由编码在规则集开头的标识符组成。
- CSS声明块由一个左大括号、零个或多个声明以及一个右大括号组成。
- CSS声明由一个属性、一个冒号、一个值和一个分号组成。虽然块中最后一个声明的分号是可选的，但最佳实践是编写它。
- 为了使代码更易于阅读，你可以在规则集内使用空格、缩进和空行。
- CSS注释以`/*`字符开始，以`*/`字符结束。CSS注释可以写在单行上，也可以跨越多行。
- Visual Studio提供了生成规则集的功能。详情见图5-15。

## 如何为元素、ID和类编写选择器

规则集的选择器标识了规则应应用于的HTML元素。为了更好地理解这一点，图5-10展示了如何使用CSS规则集的三种基本选择器：元素选择器、ID选择器和类选择器。

*元素选择器*标识诸如body、h1或p元素之类的HTML元素。例如，第一个示例中的选择器应用于此图顶部HTML中显示的h2元素。此规则集内的第一条规则将字体设置为Arial（如果有的话），否则设置为通用无衬线字体。然后，第二条规则将h2元素上方的边距设置为5像素，第三条规则将h2元素下方的边距设置为零。

*ID选择器*以井号（#）开头，应用于由id属性标识的单个HTML元素。例如，`#main`应用于具有值为“main”的id属性的HTML元素。正如你所见，那是HTML代码中的第一个div元素。在该规则集内，第一条规则在div周围添加两像素宽的黑色实线边框；第二条规则在边框外放置10像素的外边距；第三条规则在边框和div内容之间放置10像素的内边距。

*类选择器*以句点（.）开头，应用于所有由具有指定值的class属性标识的HTML元素。例如，`.copyright`应用于所有具有值为copyright的class属性的元素。这里，唯一分配给该类的元素是footer div中的段落。然后，该规则集中的规则将段落中的文本右对齐，并将字体大小减小到基础字体大小的80%。

请注意，因为在此图的示例中copyright类只使用了一次，所以我可以使用ID选择器而不是类选择器。事实上，通常只有在需要对多个元素应用格式时才会使用类选择器。我在这里使用类选择器只是为了说明它们的工作方式。

虽然此图仅展示了如何将规则集用于HTML元素，但你也可以将ID和类选择器的规则集用于服务器控件。要为服务器控件编写ID选择器，你编写一个井号，后跟控件id属性的值，就像对HTML元素所做的那样。服务器控件的类选择器类似于HTML元素的类选择器，只是类名必须编写在控件的CssClass属性上。这是因为服务器控件没有class属性。你将在接下来介绍的应用中看到CssClass属性的使用方式。

需要注意的是，你为服务器控件指定的样式会应用于渲染后的HTML。例如，假设我想对下拉列表应用样式。一种方法是根据控件的ID或CssClass值为其编写规则集。另一种方法是为select元素编写规则集，因为下拉列表会渲染为select元素。虽然通常不需要这样做，但在下一章中你会看到一个可能很有用的示例。

## 可以通过元素、ID或类选择的HTML

```
<div id="main">
  <h2>New! HTML, XHTML, and CSS</h2>
  <p>This book teaches you how to develop web pages the professional way, using HTML/XHTML to provide the content and structure of the elements on a page and CSS to format and lay out those elements.</p>
</div>
<div id="footer">
  <p class="copyright">&copy; Copyright 2010 Mike Murach &amp; Associates, Inc.</p>
</div>
```

## 按元素、ID和类选择的CSS规则集

### 元素

```
h2 {
  font-family: Arial, sans-serif;
  margin-top: 5px;
  margin-bottom: 0;
}
```

### ID

```
#main {
  border: 2px solid black;
  margin: 10px;
  padding: 10px;
}
```

### 类

```
.copyright {
  text-align: right;
  font-size: 80%;
}
```

## 说明

- 你只需指定元素名称即可为HTML元素编写选择器。
- 为带有id属性的HTML元素或ASP.NET服务器控件编写选择器时，你编写一个井号（#）后跟id值。
- 为带有class属性的HTML元素编写选择器时，你编写一个句点后跟类名。然后，规则集将应用于具有该类名的所有元素。
- 类选择器也可以应用于ASP.NET服务器控件。为此，你需要在控件的CssClass属性上编写类名。
