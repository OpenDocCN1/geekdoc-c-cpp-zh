# Description

+   - The Category Maintenance application uses a GridView control to let the user update or delete rows in the Categories table.
+   - To edit a category, the user clicks the Edit button. This places the GridView control into edit mode. The user can then change the Short Name or Long Name and click Update. Or, the user can click Cancel to leave edit mode.
+   - To delete a category, the user clicks the Delete button.
+   - The user can add a category to the table by entering data into the text boxes beneath the GridView control and clicking the Add New Category button.
+   - If the user attempts to update or add a row with a column that is blank, an error message is displayed.
