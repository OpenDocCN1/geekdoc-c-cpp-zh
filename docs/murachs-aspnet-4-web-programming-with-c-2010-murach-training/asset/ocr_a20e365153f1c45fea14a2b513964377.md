# How to use AJAX

This chapter introduces you to the ASP.NET server controls that provide for building AJAX-enabled web pages. These controls let you develop web applications that are more responsive to users and that help reduce the load on the web server. It also introduces you to jQuery AJAX, another technique you can use to develop AJAX-enabled web pages.
