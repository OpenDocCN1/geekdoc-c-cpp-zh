# Perspective

The goal of this chapter has been to teach you the HTML and CSS essentials that you need for ASP.NET programming. So at this point, you should feel qualified to modify the HTML that’s generated by Visual Studio so it contains the content you need and so it’s structured in a logical way that makes it easy to apply CSS. In addition, you should feel qualified to code some basic CSS for formatting and page layout.

Of course, there’s a lot more to HTML and CSS than what’s presented in this chapter. So if you want to learn more, we recommend our book Murach’s HTML, XHTML, and CSS. This book teaches you everything you need to develop web pages from scratch. Of course, when you work in Visual Studio, much of the HTML is generated for you. In addition, as a programmer, you may not be responsible for coding the CSS for a page. Even so, it makes sense for you to have a solid understanding of how this code works.
