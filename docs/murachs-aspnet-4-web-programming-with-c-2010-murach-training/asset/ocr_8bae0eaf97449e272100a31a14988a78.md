# The syntax of the Select statement for joining two tables

```
Select column-list
From table-1
    [Inner] Join table-2
    On table-1.column-1 {=|<|>|<=|>=|< >} table-2.column-2
[Where selection-criteria]
[Order By column-list]
```

# A Select statement that joins data from the Products and Categories tables

```
Select ShortName, ProductID, Name, UnitPrice
From Categories Inner Join Products
    On Categories.CategoryID = Products.CategoryID
Order By Categories.CategoryID
```

# Concepts

+   - A join lets you combine data from two or more tables into a single result set.
+   - The most common type of join is an inner join. This type of join returns rows from both tables only if their related columns match.
