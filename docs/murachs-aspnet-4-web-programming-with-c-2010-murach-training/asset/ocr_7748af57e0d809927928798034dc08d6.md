# How to apply a style sheet theme to all pages in the application

```
<system.web>
    <pages styleSheetTheme="Halloween" />
</system.web>
```

# How to apply a style sheet theme to a single page

# At design time

```
<%@ Page Language="C#" StylesheetTheme="Halloween" %>
```

# At runtime by overriding the StyleSheetTheme property in the code-behind file

```
public override string StyleSheetTheme
{
    get
    {
        return Session["myTheme"].ToString();
    }
    set
    {
        Session["myTheme"] = value;
    }
}
```

# How to remove a style sheet theme from a single page

# At design time

```
<%@ Page Language="C#" StylesheetTheme="" %>
```

# At runtime

```
public override string StyleSheetTheme
{
    get { return ""; }
    set { }
}
```

# Description

+   - To apply or remove a style sheet theme at design time, you can use the StyleSheetTheme attribute. This works just like the Theme attribute does for customization themes.
+   - To apply or remove a style sheet theme at runtime, you can override the StyleSheetTheme property of the page.
