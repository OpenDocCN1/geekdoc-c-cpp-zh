# Description

+   - This version of the Category Maintenance application uses a GridView control to update and delete rows and a DetailsView control to insert rows. These controls are bound to an ObjectDataSource control that accesses the Categories table of the Halloween database.
+   - The data access class named CategoryDB provides the select, insert, update, and delete methods.
