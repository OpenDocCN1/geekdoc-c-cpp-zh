# Description

+   - The Cart.aspx page uses a list box to display the shopping cart.
+   - The btnContinue button uses cross-page posting to post back to the Order.aspx page. The other buttons post back to the Cart page, where the event handler specified by the OnClick attribute of the button is executed.
