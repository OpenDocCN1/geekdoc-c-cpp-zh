# Implementing a Lock Enforcement Advice

In this particular case, we don't need a full-blown *around advice*, such as the one we used in the
logging example. All that our advice needs to do is to check whether the target object is locked and
throw an exception if it is.

For that purpose, we can use a somewhat simpler *before advice*, which doesn't require us to make
a call to `MethodInvocation.Proceed()`:

```
```csharp
using System;
using System.Reflection;
using Spring.Aop;

namespace LockableAspectDemo
{
    public class LockEnforcerAdvice : IMethodBeforeAdvice
    {
        public void Before(MethodBase method, object[] args,
        object target)
        {
            ILockable lockable = target as ILockable;
            if (lockable != null && lockable.IsLocked)
            {
                throw new LockViolationException
                    ("Attempted to modify locked object.", target);
            }
        }
    }
}
