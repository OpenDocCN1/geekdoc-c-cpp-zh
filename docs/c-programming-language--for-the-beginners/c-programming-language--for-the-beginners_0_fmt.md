### 引用传递函数调用 — 使用指针增加数值

```c
void increment(int *var)
{
    /*
     * 虽然我们正在对变量 var 进行增加操作，
     * 但 var 是一个指针，存储着变量 num 的地址，
     * 这意味着增加操作实际上是在 num 存储数值的地址上进行的。
     */
    *var = *var + 1;
}

int main()
{
    int num = 20;
    /* 这种调用函数的方式被称为“引用传递”。我们没有传递变量 num，
       而是传递了它的地址 */
    increment(&num);
    printf("Value of num is: %d", num);
}
```

# 5.3 C – 函数指针

带示例的 C – 函数指针

在 C 语言中，我们可以有一个指向函数的指针的概念，这在 C 中被称为函数指针。在本教程中，我们将学习如何声明一个函数指针以及如何使用此指针调用函数。为了理解这个概念，你应该具备关于函数和 C 中的指针的基础基础知识。

### 如何声明函数指针？

`function_return_type(*Pointer_name)(function argument list)`

例如：
`double (*p2f)(double, char)`

在这里，`double` 是函数的返回值，`p2f` 是函数指针的名字，`(double, char)` 是该函数的参数列表。这意味着该函数的第一个参数是 `double` 类型，第二个参数是 `char` 类型。

让我们通过一个示例来理解这一点：这里我们有一个函数 `sum`，它计算两个数字之和并返回结果。我们创建了一个指向该函数的指针 `f2p`，我们正在使用这个函数指针 `f2p` 调用该函数。

```c
int sum (int num1, int num2)
{
    return num1 + num2;
}

int main()
{
    /* 下面两行也可以写成一条语句，
       如下所示：void (*fun_ptr)(int) = &fun;
    */
    int (*f2p) (int, int);
    f2p = sum;
    // 使用函数指针调用函数
    int op1 = f2p(10, 13);
    // 使用函数名的普通方式调用函数
    int op2 = sum(10, 13);
    printf("Output1: Call using function pointer: %d", op1);
    printf("\nOutput2: Call using function name: %d", op2);
    return 0;
}
```

**输出：**
```
Output1: Call using function pointer: 23
Output2: Call using function name: 23
```

**关于函数指针的几点：**

1. 如注释所示，你可以在一条语句中声明函数指针并向其赋值一个函数，例如：`void (*fun_ptr)(int) = &fun;`

- 如果年份能被 4 整除但不能被 100 整除，那么它也是闰年。
- 如果年份不能被 4 整除，则不是闰年。

让我们用 C 代码实现检查逻辑。为理解下面的程序，你应该具备 [C 编程 if..else 与嵌套 if](https://example.org/part0000.xhtml_ifelse) 中的相关知识（链接占位符，实际路径应根据源文本嵌入超链保持透传未改动）。

```
#include <stdio.h>

int main()
{
    int y;
    printf("Enter Year:");
    scanf("%d", &y);
    if ((y % 4 == 0 && y % 100 != 0) || (y % 400 == 0))
        printf("%d is a leap year\n", y);
    else
        printf("%d is not a leap year\n", y);
    return 0;
}
```

## C 语言实现：连接两个字符串

在下面的程序中，用户将被要求输入两个字符串，程序随后会将它们拼接起来。对于拼接操作，我们并未使用标准库函数`strcat()`，而是自行编写了逻辑将第二个字符串追加到第一个字符串的末尾。

```
/* 该 C 程序用于在不使用标准库函数 strcat() 的情况下连接两段字符数组 */
#include <stdio.h>

int main()
{
    char str1[50], str2[50], i, j;
    printf("\n 请输入第一个字符串: ");
    scanf("%s", str1);
    printf("\n 请输入第二个字符串: ");
    scanf("%s", str2);
    /* 此循环用于计算已存在长度并存入变量 i 中 */
    for (i = 0; str1[i] != '\0'; ++i);
    /* 将第二个字符串追加到第一个字符串末尾 */
    for (j = 0; str2[j] != '\0'; ++j, ++i) {
        str1[i] = str2[j];
    }
    str1[i] = '\0';
    printf("\n 连接后的字符串: %s", str1);
    return 0;
}
```

## C 程序将十进制转换为二进制数

该程序将输入的十进制数转换为二进制数。

```
#include <stdio.h>
long decimalToBinary(int decimalnum) {
    int rem, temp = 1;
    long binarynum = 0;
    while (decimalnum != 0) {
        rem = decimalnum % 2;
        decimalnum = decimalnum / 2;
        binarynum = binarynum + rem * temp;
        temp = temp * 10;
    }
    return binarynum;
}
int main() {

    scanf("%d", &decimalNum);
```

## 计算等边三角形面积的程序

等边三角形的三条边长度相等（所有三边都相等）。在本教程中，我们分享了一个 C 程序，该程序以三角形的边长作为输入，计算并显示其面积作为输出。

为了计算等边三角形的面积，我们必须知道三角形的边长。此程序会提示用户输入边长，并使用公式`Area = sqrt(3)/4 * side * side`来计算面积。这里`sqrt()`指的是头文件`<math.h>`中定义的平方根函数，因此在开头包含了该头文件。

```
#include <stdio.h>
#include <math.h>

int main()
{
    int triangle_side;
    float temp_variable, triangle_area;
    printf("\n 请输入边长: ");
    scanf("%d", &triangle_side);
    temp_variable = sqrt(3) / 4;
    triangle_area = temp_variable * triangle_side * triangle_side;
    printf("三角形面积: %f", triangle_area);
    return 0;
}
```

**输出示例**：
```
Enter Side: 2
Result: 1.732051
```
