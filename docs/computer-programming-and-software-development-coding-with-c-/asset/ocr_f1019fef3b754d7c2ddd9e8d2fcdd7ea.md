Reinforcement learning is a type of learning in which an agent, like a vehicle, interacts with an environment, for example, a highway, and reacts accordingly. For example, to accelerate, break, or turn, given a determined interaction like signals, traffic lights, pedestrians, or other vehicles. Depending on the action the agent takes, it can be rewarded or punished. In this way, the agent learns to make decisions that increase the reward or decrease the punishment.
