The code is organized in two major folders: public and src. The public folder contains static assets such as HTML and CSS. The src folder contains React components and other JavaScript code files. The application runs entirely in the browser, but needs a development server and a build tool. We are using Snowpack, a lightweight build tool. Snowpack configuration is stored in snowpack.config.js file. Here, we configure the public directory to be mounted to the root URL and the src directory to be mounted to the dist path. We can start the development server using the npm start command. To better demonstrate the structure of the user interface, I installed the React Developer Tools browser extension.
