## 第 8 章 如何探索 Switch 语句

Switch 语句是另一种可以控制程序流程的语句。虽然 if else 语句使用得更常见，但在某些情况下，switch 语句提供了强大的替代方案。Switch 语句允许我们根据表达式模式匹配来执行代码段。这听起来可能比实际更抽象或更复杂，所以让我们看几个例子。这里，我们有一个标准的 switch 语句。

```
switch (productCategory)
{
    case "Coffee":
    Console.WriteLine("The Coffee category");
    // Do other stuff
    break;

    case "Food":
    Console.WriteLine("The Food category");
    break;

    case "Merchandise":
    Console.WriteLine("The Merch category");
    break;
}
```

在语句开始时，我们使用 switch 关键字，然后在括号中定义一个表达式。在此示例中，我们的 switch 表达式将评估为存储在 product category 变量中的字符串值。然后该字符串值将与下面的每个 case 模式进行比较，如果找到匹配项，则关联的代码块将被执行。所以如果产品类别是 food，只有第二个 case 部分中的语句会被执行，而它上面的和下面的 case 则会被忽略。我们还必须在 switch 部分内包含 break 关键字。这让 C# 知道它可以退出 switch 语句并恢复正常的程序流程。
