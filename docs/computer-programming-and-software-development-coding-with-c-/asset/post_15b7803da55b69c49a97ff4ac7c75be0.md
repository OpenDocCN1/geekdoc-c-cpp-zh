### What is an Agent?

An **AI agent** is a system that uses a large language model (LLM) to reason through a problem, decide on actions, and execute those actions using external tools. Unlike a standard chatbot, an agent can interact with its environment, retrieve information, and perform tasks autonomously to achieve a goal.

### Core Components

- **Model**: The underlying LLM (e.g., GPT-4, Claude, Llama) that powers reasoning.
- **Tools**: Functions or APIs the agent can call, such as web search, calculators, or database queries.
- **Memory**: Mechanisms to store and recall past interactions or context.
- **Orchestration**: The loop that manages the agent's reasoning, tool use, and response generation.
