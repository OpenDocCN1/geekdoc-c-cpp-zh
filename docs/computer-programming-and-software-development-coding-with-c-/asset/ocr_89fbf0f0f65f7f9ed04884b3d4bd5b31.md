$\hat{y} = \beta_0 * 1 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_k x_k$

$\hat{y}_i = \beta_0 + \sum_{i=1}^{m} x_i \beta_i$

$J(\beta) = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 + \lambda \sum_{j=1}^{m} (\beta_j)^2$

The L2 penalization term with a small lambda value, example, 0.0001, will cause some of the beta coefficients to be very close to 0, but not 0. In other words, here's how ridge keeps all the features in the model, even if they are very small.
