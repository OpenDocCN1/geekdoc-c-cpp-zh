A getter begins with the get keyword, followed by the name of the property in parentheses, and we specify the property data type. The body of the getter can include code to process the property value before returning it. The getter then returns the processed value. The setter has a single parameter, which is the value assigned to the property. The setter has no return value. The setter is executed any time a value is assigned to the associated property, so we can use the body of the setter to perform an operation when the property is changed such as filtering our list of products.
