If this sink is used to deliver a payload with executable code, it may lead to a scripting attack. The name of dangerouslySetInnerHTML was chosen deliberately to warn developers against using it and make it easier to find potential security vulnerabilities in code reviews. The Company bug tracker renders dynamic HTML on the bug details screen, which leads to a DOM XSS vulnerability. First, we will find the XSS sink.
