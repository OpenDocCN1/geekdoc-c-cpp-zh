When the user clicks the button, Angular executes the method bound to the click event. The code in the method toggles the `showImage` property from false, its default value, to true. Angular's change detection detects that change and automatically reevaluates all the bindings. The interpolation changes the button text from Show to Hide, and the `ngIf` adds the image element to the DOM, displaying the image. This is the Angular way to modify DOM elements.
