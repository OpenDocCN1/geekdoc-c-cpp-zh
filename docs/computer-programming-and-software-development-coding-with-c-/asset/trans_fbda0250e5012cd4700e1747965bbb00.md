现在，还有一种情况是 `T` 不作为输入使用，而仅作为输出使用。那么你就可以使用 `out` 关键字将类型参数定义为协变的。这意味着当你查看 `Program.cs` 文件时，你仍然可以将一个 `ItemAdded<Employee>` 委托赋值给一个 `ItemAdded<Employee>` 变量，当然，因为它就是该类型。但你现在也可以使用一个更不具体的类型，例如 `ItemAdded<object>`。
