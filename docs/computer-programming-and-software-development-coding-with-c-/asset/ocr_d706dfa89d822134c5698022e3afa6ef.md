The HTML parser in the browser no longer treats this as HTML tags. There are more types of scripting vulnerabilities than just DOM XSS. We have also learned about stored and reflected XSS attacks. Those types of attacks come into play when rendering is involved and data is coming not only from browser XSS sources, but also from other places, like databases and external services. rendering, or SSR for short, is a useful React pattern that can improve application performance and load time in certain scenarios. It is very popular, but if used without caution, it may lead to XSS bugs. Using SSR to render configuration data as a JSON object is often used and may lead to reflect that XSS. Proper sanitization is necessary to safely render JSON objects for React code to consume in the browser.
