Be sure to add FormsModule from the Angular forms package to the imports array of an appropriate Angular module, in this case AppModule.

```
@NgModule({
  imports: [
    BrowserModule,
    FormsModule ],
  declarations: [
    AppComponent,
    ProductListComponent ],
  bootstrap: [ AppComponent ]
})
export class AppModule { }
```

This ensures that the ngModel directive is available to any template defined in a component associated with that module. We'll talk more about Angular modules later in this book.
