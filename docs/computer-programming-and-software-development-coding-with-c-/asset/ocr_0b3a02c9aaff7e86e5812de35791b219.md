```
@Injectable({
  providedIn: 'root'
})
export class ProductService {...}
```

Set the providedIn property to root. Register a service for a specific component and its children using its component decorator. Use the providers property to register the service.

```
constructor(private productService: ProductService) { }
```

In any class that needs the service, specify the service as a dependency. Use a constructor parameter to define the dependency. The Angular injector will inject an instance of the service when the component is instantiated. In summary, we built the product data service, so our product list component no longer has hard coded products. Next, we'll see how to modify the service to retrieve data using HTTP.
