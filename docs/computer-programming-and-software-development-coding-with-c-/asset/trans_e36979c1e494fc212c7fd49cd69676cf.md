之所以需要这个选项，是因为返回的 JSON 数据具有小写的属性名，而我们的 C# 对象具有大写的名称，这样可以确保它们能够匹配。现在有了它，我们就可以实现 GetPeople 方法了。我将先创建一个更具体的地址，这将是我们上面的 baseUri，然后我们加上 /people。这样就能到达我们 GetPeople 方法的特定位置。WebClient 有一个 DownloadString 选项，使用时传入地址。可以想象，这会返回一个字符串，所以我们将创建一个变量来保存该字符串 reply。

```
```csharp
public IEnumerable<Person> GetPeople()
{
    string address = $"{baseUri}/people";
    string reply = client.DownloadString(address);
}
```
```

该 reply 采用 JSON 格式，因此最后一步是将它反序列化为 C# 对象。为此，我们使用 JsonSerializer，并调用

Deserialize 方法。Deserialize 有一个泛型类型参数，这是我们希望将 JSON 数据转换成的类型。在本例中，我们将指定 IEnumerable。Deserialize 有两个参数，一个是 JSON 字符串，即我们的 reply，另一个是可选的 JsonSerializerOptions。所以从中返回的是一个 IEnumerable，我们可以从 GetPeople 方法返回它。

```
public IEnumerable<Person> GetPeople()
{
    string address = $"{baseUri}/people";
    string reply = client.DownloadString(address);
    return JsonSerializer.Deserialize<IEnumerable<Person>>(reply, options);
}

public Person GetPerson(int id)
{
    string address = $"{baseUri}/people/{id}";
    string reply = client.DownloadString(address);
    return JsonSerializer.Deserialize<Person>(reply, options);
}
```

GetPerson 方法类似，所以我将先复制粘贴代码，然后再做一些修改。对于 Web 服务地址，我们写 people/{id}，因此我们会传入 id 参数。对于 Deserialize 方法，我们不再使用 IEnumerable，而是使用 Person。如果此时构建，我们应该能得到成功的构建。我们的构建成功了，我们实现了 IPersonReader 接口。再次说明，这意味着我们的 ServiceReader 同时具有 GetPeople 和 GetPerson 方法，在本例中它使用 WebClient 发起服务调用，然后将其转换为我们可以使用的 C# 对象。那么让我们在应用程序中使用新的 ServiceReader。为此，我将进入 PeopleViewer 项目，在查看代码之前，我将添加对我们新的 DataReader 的引用。所以我将在 Dependencies 上，选择 Add Project Reference，然后添加对 PersonReader.Service 的引用，即我们刚刚创建的项目。我们想要使用它的地方是在 PeopleController 中，它位于应用程序的 Controllers 文件夹中。所以让我们打开 PeopleController.cs 来看看我们有什么。在 PeopleController 中，我们有三个动作，对应于网页上的链接。如果我们查看 UseService 动作，它目前有两行代码。第一行在 ViewData 中设置一个 title 值。ViewData 是一组键值对，我们可以在视图中使用该值并向用户显示。在本例中，我们将标题设置为 Using a Web Service。第二行创建并返回视图。第一个参数是视图的名称，在本例中为 Index。第二个参数是我们传递的模型。在我们的例子中，我们的模型是 people 数据。让我们添加一些代码来使用我们新的 ServiceReader。我将先声明一个变量，其类型为 IPersonReader，名为 reader，并将其设为 new ServiceReader。同样，我按 Ctrl+点来引入 using 语句。接下来，我想在该数据读取器上调用 GetPeople 方法。根据接口，我知道它返回一个 IEnumerable，所以我们创建一个名为 people 的变量，并将其设为 reader.GetPeople 方法返回的内容。我还将设置另一项 ViewData，即 ReaderType。这是一种在 UI 上显示特定读取器类型的方式，以确保我们使用的是正确的读取器。

```
using Microsoft.AspNetCore.Mvc;
using PersonReader.Interface;
using System.Collections.Generic;

namespace PeopleViewer.Controllers
{
    public class PeopleController : Controller
    {
        public IActionResult UseService()
        {
            ViewData["Title"] = "Using a Web Service";
            return View("Index", new List<Person>());
        }

        public IActionResult UseCSV()
        {
            ViewData["Title"] = "Using a CSV File";
            return View("Index", new List<Person>());
        }

        public IActionResult UseSQL()
        {
            ViewData["Title"] = "Using a SQL Database";
            return View("Index", new List<Person>());
        }
    }
}
```

为此，我们将写 reader.GetType 然后 .ToString，以便将其存储在我们的 ViewData 中。最后一件事是我需要将模型传递给视图，所以不要使用空列表，我们将把 IEnumerable 传递过去。这样应该就能让我们的应用程序运行起来。
