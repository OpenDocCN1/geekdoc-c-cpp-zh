

在浏览器执行它之前需要语法。TypeScript 是微软开发的一种语言。它是 JavaScript 的超集，这意味着所有 JavaScript 都是有效的 TypeScript。TypeScript 代码会被转译为纯 JavaScript。这是什么意思？使用 TypeScript 开发的代码必须先编译并转换为可比较的 JavaScript 语法，然后浏览器才会执行它。这样，我们作为开发者在开发过程中可以获得 TypeScript 功能的好处，而浏览器仍然能理解代码。TypeScript 的关键优势之一是其强类型，这意味着一切都有数据类型。正因为这种强类型，TypeScript 具有强大的工具支持，包括内联文档、语法检查、代码导航和高级重构，因此 TypeScript 有助于我们更好地推理代码。而且 TypeScript 实现了 ES 2015 的面向对象特性，此外还有更多。它实现了类、接口和继承。因此，如果你有 C#、C++ 或 Java 等编程语言的经验，使用 TypeScript 可能会感觉非常自然。本书不需要任何 TypeScript 的先前知识。我们会在需要时讲解你需要的内容。但如果你想了解更多关于 TypeScript 的信息，请查看 TypeScript Playground。该网站允许你实时使用 TypeScript 编码，查看转译后的 JavaScript 并运行结果，而无需安装任何东西。

现在，让我们安装开始构建 Angular 应用所需的内容。我们旅程的第一步是安装所需的东西，从代码编辑器开始。有许多编辑器支持 TypeScript，要么开箱即用，要么通过插件。我们将选择 Angular 开发者最常用的编辑器之一，Visual Studio Code，通常简称为 VS Code。你可以使用你选择的编辑器，但请记住，如果你选择一个理解 TypeScript 的编辑器，你使用 TypeScript 的体验会愉快得多。如果你的项目需要使用 Visual Studio，请考虑先使用 VS Code 学习 Angular，然后再将技能迁移到 Visual Studio。你会很高兴这么做的。但我们需要安装 npm，但我们不能直接安装 npm。我们通过安装 Node 来安装它，使用 https://nodejs.org/en/download。按照此链接会带我们进入 Node 的下载页面，该页面会安装 npm。Angular 最低需要 npm 6.11 版本。然后选择适合你操作系统的安装程序。如果还没有，现在就安装 Node。安装 Node 会安装 npm。在继续之前，让我们检查一下 npm 版本。打开一个命令窗口并输入 npm --version。确保你至少有 npm 6.11 版本。

我们现在已经安装了代码编辑器和所需版本的 npm。既然我们已经安装了 npm，我们就可以用它来安装我们需要的所有其他东西。那么，我们还需要什么呢？嗯，我们需要构成 Angular 框架的 Angular 库。我们想要 Angular CLI，它是 Angular 的命令行界面。我们可以使用 CLI 生成代码、执行应用程序、部署到生产环境等等。我们需要 TypeScript，这是我们与 Angular 一起使用的语言，我们还想要测试工具、linter 和其他支持库。但是，我们需要手动使用 npm 安装每一个这些吗？幸运的是，答案是否定的，至少不是直接的。更常见的做法是定义一个 package.json 文件，其中列出了我们 Angular 应用所需的每个包。

正如你所见，它们有很多。我们还可以指定每个包的期望版本。然后我们告诉 npm 使用 package.json 文件安装所有定义的包及其依赖项。在 package.json 文件中，包列表分为两部分。dependencies 列表是用于开发且必须部署的包。devDependencies 列表是仅用于开发的包。dependencies 列表包括主要的 Angular 包，以及支持包，例如用于处理数据的 RxJS。devDependencies 包括 Angular CLI。TypeScript 在 devDependencies 中，因为我们在部署前将代码转译为 JavaScript，并且其中许多是用于单元测试的。通过为我们的 Angular 应用定义 package.json 文件，我们确保团队中的每个人都安装了适当的包和版本。我们将在下一步设置 Angular 应用时了解如何安装 package.json 文件中的所有包。

## 第 2 章 如何设置和运行 Angular 应用

在设置和执行我们的示例 Angular 应用之前，让我们先看看我们将遵循的步骤。我们首先导航到项目文件夹。项目文件夹是包含 package.json 文件的文件夹。此文件包含应用程序所需的所有包的列表。然后，我们运行 npm install 以安装 package.json 文件中定义的包。如果安装成功，我们通过运行 npm start 来执行应用程序。我已经为我们将在本书中构建的 Angular 应用生成了 package.json 文件。我还创建了支持文件、样式表和数据文件。使用示例应用作为起点可以让我们快速开始构建 Angular 应用，因为它已经有我们可以操作的数据和准备好的样式表。但不用担心，我们在让这个示例应用运行起来后，马上就会从头创建一个 Angular 应用。我已使用 VS Code 打开了 APM 工作文件夹。首先，让我们谈谈目录结构。

![](img/0155736aec718cf18821e9f10a5d308d_33_1.png)

如果你看到一条消息告诉你运行 fix，不要这样做。运行 fix 会尝试更新某些包的版本而不更新所有包，这会在你尝试运行应用程序时导致错误。此 fix 消息告诉你存在漏洞和永远不会部署的库，例如测试库，因此忽略此消息。请注意，我们现在在这里有一个 node_modules 文件夹。这是 npm 安装所有包的位置。此文件夹很大，因此当你将文件检入源代码控制系统时，你可能希望将其排除。现在我们已经为示例应用安装了库，让我们尝试运行它。到目前为止，我们已经导航到项目文件夹并成功运行 npm install 以安装 package.json 文件中定义的包。现在我们准备启动示例应用。还记得我们 package.json 文件中的 scripts 区域吗？这是 start 脚本。
