So, what else do we need? Well, we need the Angular libraries that comprise the Angular framework. We'll want the Angular CLI, which is the command line interface for Angular. We can use the CLI to generate code, execute our application, deploy to production, and much more. We need TypeScript, which is the language we use with Angular, and we'll want testing tools, linters, and other supporting libraries. But, do we need to manually install each of these with npm? Luckily, the answer is no, at least not directly. A more common practice is to define a package.json file that lists each package we need for our Angular application.
