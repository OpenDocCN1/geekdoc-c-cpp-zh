## 第 8 章 如何使用 new() 约束

在本演示中，你将学习如何使用 new() 约束来调用你的泛型类型参数的无参构造函数。这里，我打开了 GenericRepository 类。让我们在这个 GenericRepository 类中创建一个我称之为 CreateItem 的方法，并从该方法返回类型 T 的新实例。正如你所见，这行代码被红色下划线标出。当你悬停其上时，你可以看到这里的错误，无法创建变量类型 "T" 的实例，因为它没有 new() 约束。

要调用构造函数，你必须确保类型 T 实际上有一个无参构造函数。为了确保这一点，你将添加 new() 约束。此约束必须是最后定义的约束。顺序与 C# 中的正常继承方式相同。你在这里定义类名如 Entity base，或者使用关键字 class 或 struct。然后你定义泛型类型参数所需的所有接口，最后，如果你需要通过调用无参构造函数来创建类型 T 的实例，你可以定义 new() 约束。现在有了这个 new() 约束和这个 CreateItem 方法，这意味着现在在 Program.cs 文件中那个 GenericRepository 你现在有了这个 CreateItem 方法，它返回新的 employee 实例。
