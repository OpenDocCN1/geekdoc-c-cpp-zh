## 第9章 如何使用指令添加逻辑：ngIf

我们可以把指令看作是一种自定义的 HTML 元素或属性，用来增强和扩展我们的 HTML。我们可以构建自己的自定义指令，也可以使用 Angular 内置的指令。之前，我们已经看到了如何构建一个组件并将其用作自定义指令。我们使用该指令来显示产品列表模板。除了构建我们自己的自定义指令外，我们还可以使用 Angular 的指令。我们将要学习的 Angular 指令是结构型指令。结构型指令通过添加、删除或操作元素及其子元素来修改视图的结构或布局。它们帮助我们利用 if 逻辑和 for 循环来增强 HTML。注意指令名称前面的星号。

![](img/0155736aec718cf18821e9f10a5d308d_87_0.png)

这个星号标志着该指令是结构型指令。让我们先来看看 `ngIf`。`ngIf` 是一种结构型指令，它根据表达式来决定移除或重新创建文档对象模型树的一部分。

现在，如果我们取消注释产品数据，再次查看浏览器，表格就会重新出现。使用 `ngIf`，关联的元素及其子元素会被真正地从 DOM 中添加或移除。但我们仍然没有用产品填充表格。另一个结构型指令是 `ngFor`。`ngFor` 会对可迭代列表中的每一项重复渲染 DOM 树的一部分。因此，我们定义一个 HTML 块，描述如何显示单个项目，并告诉 Angular 使用该块来显示列表中的每一项。

```
<tr *ngFor='let product of products'>
  <td></td>
  <td>{{ product.productName }}</td>
  <td>{{ product.productCode }}</td>
  <td>{{ product.releaseDate }}</td>
  <td>{{ product.price }}</td>
  <td>{{ product.starRating }}</td>
</tr>
```

例如，假设我们想要在表格的一行中显示每个产品。我们定义一个表格行及其子表格数据元素。然后，对于产品列表中的每个产品，该表格行元素及其子元素都会被重复渲染。这里的 `let` 关键字创建了一个名为 `product` 的变量。我们可以在这个元素上、任何兄弟元素上或任何子元素上引用这个变量。注意这里使用的是 `of` 而不是 `in`。我们稍后会详细讨论这一点。现在，让我们回到演示中。我们再次查看 `ProductListComponent` 及其模板。

那么，为什么 `ngFor` 的语法是 `product of products` 而不是 `product in products` 呢？这样做的原因与 ES 2015 的 for 循环有关。ES 2015 同时有 `for of` 循环和 `for in` 循环。`for of` 循环类似于普通循环，它遍历一个可迭代对象，比如数组。例如，假设我们有一个人员昵称数组。如果我们使用 `for of` 遍历这个列表，我们会看到每个昵称被记录到控制台。`for in` 循环遍历对象的属性。当处理像这样的数组时，数组索引是可枚举的属性，具有整数名称，除此之外与一般的对象属性相同。所以我们会看到每个数组索引被记录到控制台。为了帮助记住区别，可以把“in”想象成遍历索引。由于 `ngFor` 指令遍历的是可迭代对象，而不是它们的属性，Angular 选择了在 `ngFor` 表达式中使用 `of` 关键字。现在让我们用一些清单来结束本节，这些清单可以在我们使用模板、插值和指令时参考。清单是重新检查我们理解和工作的好方法。让我们从模板开始。构建较短的模板时，使用内联模板。然后在 `Component` 装饰器中指定 `template` 属性。使用双引号或单引号来定义模板字符串，或者使用 ES 2015 的反引号将 HTML 布局在多行。使用内联模板时，通常没有设计时的语法检查，所以要特别注意语法。对于较长的模板，使用链接模板。在 `Component` 装饰器中指定 `templateUrl` 属性，并定义外部模板文件的路径。构建完模板后，我们构建其组件，并学习如何将该组件用作指令。还记得我们的步骤吗？首先，我们在任何其他组件的模板中将该指令用作元素。我们使用指令组件的选择器作为指令名称。然后，我们声明该组件，使其可用于与此 Angular 模块关联的任何模板。我们将该组件添加到
