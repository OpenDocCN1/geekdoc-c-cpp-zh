```
class Program
{
    static void Main(string[] args)
    {
        GenerateTasksReport();

        for (var i = 0; i < Q1Results.Responses.Count; i++)
        {
            var currentResponse = Q1Results.Responses[i];

            if (currentResponse.WouldRecommend < 7.0)
            {
                Console.WriteLine(currentResponse.Comments);
            }
        }
    }
}
```

所以让我们添加 for 关键字，然后打开一对括号和下面将运行的关联代码块。然后在括号内部，我们必须设置我们之前查看过的那三个部分。首先，让我们创建一个初始化器，通常称为 i 代表增量或索引。然后让我们设置一个条件来评估是否实际运行循环。对于这一点，我们可以说只要 i 小于，嗯，小于什么？我们不想在这里放置一个任意数字。我们实际上希望它等于我们数据集中回复的数量。这样我们的循环就会一直迭代回复，直到处理完所有项目为止。获取回复数量的一种简单方法是说 Q1Results.Responses.Count。Count 是列表类型上一个非常有用的属性，可以轻松给出它包含的项目数。然后在条件之后，我们可以简单地输入 i++。这段小代码会在每次循环运行后将 i 增加一，然后 i 会在条件表达式中再次检查，以查看是否应再次运行。在我们的循环代码块内部，让我们思考一下现在想在这里做什么。本质上，我们想要从我们正在迭代的列表中获取当前项目或调查回复，然后获取其评论，但仅当 WouldRecommend 分数小于七时。所以首先，让我们获取当前项目并将其分配给一个变量以便操作。我们可以说 var currentResponse = Q1Results.Responses。然后紧接着，我们可以使用一对方括号并传入数字 i。方括号是 C# 中一种字典语法，允许我们使用索引或换句话说这个变量数字从列表或集合中获取项目。在这种情况下，i 迭代器变量工作得很好，因为我们可以用它来引用我们正在遍历的列表中的当前项目。在下一行，让我们使用条件来检查当前项目的推荐分数是否小于七，然后创建一个新的代码块。这是一个很好的例子，说明我们如何实际上可以组合不同类型的语句，以获得对程序流程更精细的控制。我们本质上是使用选择语句来过滤迭代语句的工作。最后，在 if 块内部，目前我们可以简单地使用 Console.WriteLine 并传入 currentResponse.Comments。这样它将在应用程序窗口中显示出来时运行。这就完成了我们的 for 循环。此代码将打印出我们调查回复中所有可能有顾虑的客户的个人评论。现在，for 循环实际上非常有趣，可以使用调试器逐步执行，所以让我们在循环开始处设置一个断点，然后启动应用程序并查看其工作原理。首先我们会像预期一样停在循环的开始处，但请注意，整行没有像通常那样高亮为黄色。相反，只有这个循环的初始化部分被高亮。记住，初始化器只在循环开始时运行一次，以创建并分配这个变量。当我们再次单击下一步时，我们会移动到条件表达式。C# 总是在每次循环运行之前检查此条件是否仍然为真。

![](img/0155736aec718cf18821e9f10a5d308d_572_0.png)

我们的数据中有超过 0 条评论，所以这将结果为真。所以让我们逐步进入我们的代码块。那段代码将执行，之后我们会回到顶部的增量器部分。这会在每次循环结束后运行，以增加我们的变量，以便我们继续遍历项目。

![](img/0155736aec718cf18821e9f10a5d308d_572_1.png)

所以如果我们继续逐步执行，该条件将被再次评估，然后代码块将再次运行。此模式将继续进行我们所有的回复项目，直到到达列表末尾。请注意，有时我们会进入 if 块，有时不会，这取决于推荐分数。最终，我们将到达数据集的末尾，我们的应用程序逻辑将结束。如果我们检查控制台，我们可以看到已打印出几条评论。所有这些评论都包含来自不满意客户的改进建议。虽然设置工作正常，但 C# 提供了其他处理循环的选项，在某些情况下可以大大简化此过程。让我们接下来看看这些其他类型的循环。

## 第 10 章 如何探索不同类型的循环

现在我们对循环有了工作知识，让我们开始探索这些语句的一些变体或替代类型。我简要提到过有四种类型的循环。我们已经查看了标准的 for 循环，所以现在让我们探索这另外三种。所有这些选项基本上实现相同的事情，它们重复运行代码块，但每个在特定情况下都有优势。
