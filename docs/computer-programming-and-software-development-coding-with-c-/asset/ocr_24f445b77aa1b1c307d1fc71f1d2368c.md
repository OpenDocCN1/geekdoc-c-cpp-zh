Now if we uncomment out the product data and look again at the browser, our table reappears. With ngIf, the associated element and its children are literally added or removed from the DOM. But we still aren't populating the table with our products. Another structural directive is ngFor. ngFor repeats a portion of the DOM tree once for each item in an iterable list. So we define a block of HTML that defines how we want to display a single item and tell Angular to use that block for displaying each item in the list.
