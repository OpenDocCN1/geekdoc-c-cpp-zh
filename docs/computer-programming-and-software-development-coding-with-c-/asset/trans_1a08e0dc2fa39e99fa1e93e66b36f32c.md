## Introduction

Angular 是一个用于构建大型和小型的 Web 应用的框架。使用 Angular，你可以构建一个网站，也可以构建一个产品管理和库存应用。本书提供了开始构建 Angular 应用所需的基础知识。随着我们阅读本书的旅程，我们将发现 Angular 的众多功能并找到关键问题的答案；例如什么是组件，我们把用户界面的 HTML 放在哪里，何时使用数据绑定，为什么我们需要服务，以及如何构建 Angular 应用？本书引导你走上正确的道路，让你与 Angular 的旅程更加愉快和高效。Angular 是一个用于构建应用的 JavaScript 框架。这些应用完全在用户的浏览器中运行。我们使用已知的技术，包括 HTML 和 CSS 来构建用户界面，并使用 TypeScript 编写代码，TypeScript 是 JavaScript 的增强版本。为什么选择 Angular 而不是其他 JavaScript 框架？好吧，还有很多其他 JavaScript 框架，但 Angular 让我们的 HTML 更具表达力。我们可以直接在 HTML 中嵌入功能，例如 if 条件、for 循环和局部变量。
