JSON object. The Company Bug Tracker developers have implemented SSR for one of the application screens. We are still using Snowpack, but one of the screens will be rendered by a different application on server side. To do this, we introduced a new element to Snowpack configuration, routes.

```
```js
import proxy from 'http2-proxy';

/** @type {import("snowpack").SnowpackUserConfig} */
export default {
  mount: {
    public: '/',
    src: '/dist'
  },
  plugins: [
  ],
  routes: [
    {
      match: "routes",
      src: "/new.html",
      dest: (req, res) => proxy.web(req, res, { port: 8081 })
    }
  ],
  optimize: {
  },
  packageOptions: {
  },
  devOptions: {
    open: "none"
  },
  buildOptions: {
  }
};
```
```
