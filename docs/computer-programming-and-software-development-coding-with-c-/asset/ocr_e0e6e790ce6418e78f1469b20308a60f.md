# Chapter 9 How to Add Logic with Directives: ngIf

We can think of a directive as a custom HTML element or attribute we use to power up and extend our HTML. We can build our own custom directives or use Angular's directives. Previously, we've seen how to build a component and use it as a custom directive. We use the directive to display our product list template. In addition to building our own custom directives, we can use Angular's directives. The Angular directives we'll look at are structural directives. A structural directive modifies the structure or layout of a view by adding, removing, or manipulating elements and their children. They help us to power up our HTML with if logic and for loops. Notice the asterisk in front of the directive name.
