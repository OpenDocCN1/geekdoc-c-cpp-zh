We want to use the ngModel directive in our ProductListComponent, which is owned by AppModule. So in the AppModule, we need to import the appropriate system module that exposes the ngModel directive. Since the ngModel directive is most often used when building data entry forms, ngModel is part of FormsModule. So we import that. Now the ngModel directive and any of the other Angular forms directives are visible to any component declared by AppModule, including our ProductListComponent.
