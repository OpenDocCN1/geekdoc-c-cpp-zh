# 17.1 Nodes and Linked Lists

A linked list, such as the one diagrammed in Display 17.1, is a simple example of a dynamic data structure. It's called a dynamic data structure because each of the boxes in Display 17.1 is a variable of a struct or class type that has been dynamically created with the new operator. In a dynamic data structure, these boxes, known as nodes, contain pointers, diagrammed as arrows, that point to other nodes. This section introduces the basic techniques for building and maintaining linked lists.
