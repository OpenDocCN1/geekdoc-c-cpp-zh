The conditional operator is a notational variant on certain forms of the if–else statement. This variant is illustrated below. Consider the statement

```
```cpp
if (n1 > n2)
    max = n1;
else
    max = n2;
```
```

This can be expressed using the conditional operator as follows:

```
```cpp
max = (n1 > n2) ? n1 : n2;
```
```

The expression on the right-hand side of the assignment statement is the **conditional operator expression**:

```
```cpp
(n1 > n2) ? n1 : n2;
```
```

The ? and : together form a ternary operator know as the conditional operator. A conditional operator expression starts with a Boolean expression followed by a ? and then followed by two expressions separated with a colon. If the Boolean expression is true, then the first of the two expressions is returned; otherwise, the second of the two expressions is returned.
