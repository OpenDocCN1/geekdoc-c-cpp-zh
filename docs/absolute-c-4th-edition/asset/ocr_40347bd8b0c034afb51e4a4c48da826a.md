see in Chapter 12, you can use a stream object connected to a text file in place of cin to do input from a file using getline.)

You cannot use cin >> to read in a blank character. If you want to read one character at a time, you can use cin.get, which we discussed in Section 9.2. The function cin.get reads values of type char, not of type string, but it can be helpful when handling string input. Display 9.5 contains a program that illustrates both getline and cin.get used for string input. The significance of the function newline is explained in the pitfall entitled "Mixing cin >> variable; and getline."
