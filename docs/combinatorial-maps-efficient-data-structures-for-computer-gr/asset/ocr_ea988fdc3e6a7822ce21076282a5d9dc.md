# FIGURE 2.27

(a) F = G = {a, b, c, d, e, f, g}; f = {(b, c), (c, d), (e, d), (f, g), (g, f)} is a partial function.

(b) F = {a, b, c, d, e, f, g}; P = {(a, ∅), (b, c), (c, d), (d, e), (e, ∅), (f, g), (g, f), (∅, ∅)} is a partial permutation.

(c) F = {a, b, c}; I = {(a, b), (b, a) (c, ∅), (∅, ∅)} is a partial involution.

2. ∀x₁, x₂ ∈ F, P(x₁) = P(x₂) ≠ ∅ ⟹ x₁ = x₂.

In other words, ∅ denotes the “undefinition”. Let F′ be the subset of F such that P is defined on the elements of F′. So, for any x ∈ F′, P(x) ≠ ∅, and, for any x ∈ F \ F′, P(x) = ∅. P⁻¹, the inverse of P, is defined by:

+   1. P⁻¹(∅) = ∅;

+   2. Let y ∈ F; if x ∈ F exists such that P(x) = y, then P⁻¹(y) = x, else P⁻¹(y) = ∅.

Note that, for any x ∈ F, either P(x) = ∅, or P⁻¹(P(x)) = x.

A partial involution I is a partial permutation such that, ∀x ∈ F, either P(x) = ∅, or P(x) ≠ ∅ ⟹ P(P(x)) = x (cf. Fig. 2.27(c)).

Hypermaps can be defined using partial permutations instead of permutations. Assuming that f(∅) = ∅ for any partial function, it is easy to define the composition of partial permutations, and thus also the permutation group related to a set of partial permutations. The orbit of an element related to a set of partial permutations is defined as before, but ∅ does not belong to the orbit; let S = {P₁, …, Pₖ} be a set of partial permutations defined on F: ⟨S⟩(x) = {P(x) | P ∈ ⟨S⟩} \ {∅}, for x ∈ F. As before, it denotes also this set of elements together with the partial permutations of S.
