# FIGURE 8.4

(a) A semi-simplicial set. An i-simplex is represented as a geometric i-simplex, and face operators are represented by arrows (d_j corresponds to arrows numbered j). B is a 0-face of P, since d0(d2(P)) = d1(d0(P)) = B. The boundary of simplex P contains simplices A, B, C, G, H, I. The star of simplex B contains simplices B, G, P, I, Q, J.

(b) Another semi-simplicial set, such that a semi-simplicial set morphism exists between the semi-simplicial sets depicted on (a) and (b). Note that N' is incident twice to C', and that 2-simplex R' is incident to 0-simplices C' and D'. Note also that L' and M' have the same boundary, as K' and O'.

(c) (resp. (d)) Geometric realization of the semi-simplicial set depicted on (a) (resp. (b)).
