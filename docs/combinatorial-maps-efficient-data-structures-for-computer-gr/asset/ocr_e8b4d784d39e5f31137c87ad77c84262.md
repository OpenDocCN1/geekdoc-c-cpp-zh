A dangling cell corresponds to a particular case of multi-incidence. A 2D example is depicted in Fig. 5.15: two darts which belong to two consecutive edges of a same face are 2-sewn. This creates a dangling edge, i.e. an edge which is incident twice to a face (since darts 1 and $\beta_2(1)=2$ belong to the same face and to the same edge), and which has one of its two vertices incident only to this edge (since $\beta_2(1)=2=\beta_1(1)$). Dangling edges can be created in any dimension. In 3D, a similar construction can create dangling faces by applying the 3-sew operation. More generally, dangling cells can be constructed in any dimension.
