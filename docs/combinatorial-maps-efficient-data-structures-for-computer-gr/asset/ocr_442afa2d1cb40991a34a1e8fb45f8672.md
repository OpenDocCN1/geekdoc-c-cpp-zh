# Algorithm 73: geomRemoveNGMap(gm,d,i): remove an i-cell for embedded n-Gmaps

Input: gm: an embedded n-Gmap; d ∈ gm.Darts: a dart such that c₁(d) is i-removable; i ∈ {0,…,n−1}.

Result: Remove the i-cell c₁(d) and update the embedding.

```
1 if i ≠ 0 then
2   foreach dart d' ∈ c₁(d) not already considered do
3     todelete ← true;
4     e' ← NULL;
5     foreach dart e ∈ c₀(d') do
6       if e ∉ c₁(d) then
7         todelete ← false;
8         d₁ ← e;
9       if e.Point ≠ NULL then
10        e' ← e;
11     if todelete then
12       delete e'.Point; e'.Point ← NULL;
13     else if e' ∈ c₁(d) then
14       d₁.Point ← e'.Point; e'.Point ← NULL;
15 else deletePoint(d);
16 removeNGMap(gm,d,i);
```
