The i-chamfering operation is defined in Def. 72. This operations takes as input an n-Gmap G and one of its i-cell C. It mainly consists in creating new sets of darts D^j, for each i + 1 ≤ j ≤ n. Intuitively, each D^j corresponds to the j-cells required to chamfer the initial i-cell.

## Definition 72 (chamfering) Let G = (D, α0, …, αn) be an n-Gmap, C be one of its i-cells, with i ∈ {0, …, n − 1}. The n-Gmap resulting from the i-chamfering of C in G is G_i-chf(C) = (D′, α′0, …, α′n) defined by:

- ∀j ∈ {i + 1, …, n}, let D^j be a set of new darts, such that a bijection φ^j maps C onto D^j. Let φ^i be the identity on C;
- D′ = D ∪_{j=i+1}^n D^j;
- 1. ∀j ∈ {0, …, n}, j ≠ i + 1, ∀d ∈ D, α′j(d) = αj(d);
  2. ∀d ∈ D \ C, α′i+1(d) = αi+1(d);
  3. ∀d ∈ C, α′i+1(d) = φ^{i+1}(d).
- ∀j ∈ {i + 1, …, n}, ∀d ∈ C:
  4. ∀k ∈ {0, …, i − 1}, α′k(φ^j(d)) = φ^j(αk(d));
  5. ∀k ∈ {i, …, j − 1}, α′k(φ^j(d)) = φ^j(αk+1(d));
  6. α′j(φ^j(d)) = φ^{j−1}(d);
  7. if j < n, α′j+1(φ^j(d)) = φ^{j+1}(d);
  8. ∀k ∈ {j + 2, …, n}, α′k(φ^j(d)) = φ^j(αk(d)).

The chamfering operation is illustrated in Fig. 6.45; it is applied to vertex C = {1,2,3,4,5,6} of a 2-Gmap describing the surface of a cube. D^1 = {1^1,2^1,3^1,4^1,5^1,6^1} and D^2 = {1^2,2^2,3^2,4^2,5^2,6^2} are the sets of new darts, φ^1 (resp. φ^2) associates darts d and d^1 (resp. d^2).

α′ involutions are defined on D by items 1 − 3 of the definition. For the example, nothing is changed, except for the darts of C, which are 1-linked with the darts of D^1 according to φ^1 (item 3): so, each dart incident to a corner of a face in the initial object is now linked with a new dart (for instance, α′1(1) = 1^1); this is the first part of the insertion of a new edge into each corner of each face.

α′ involutions are defined on the new darts by items 4 − 8 of the definition:

- for D^1:
  - each edge inserted into an initial face is constructed, by defining α′0, according to α1 (item 5); this is the second part of the insertion of a new edge into each corner of each face (for instance, α′0(1^1) = 2^1);
  - α′1 is defined, according to the definition of α′1 for the darts of C (item 6): so α′1 is an involution (for instance, α′1(1^1) = 1); this is the last part of the insertion of a new edge into each corner of each face;

The $i$-chamfering operation is implemented by Algorithm 64. As above, the given $n$-Gmap is modified, instead of building a new $n$-Gmap as result of the operation. The algorithm is a direct translation of the definition. First, new darts are created, and stored into phi associative arrays (there is an associative array phi[j] for each $j \in \{1,\ldots,n\}$). Then, the $\alpha$ links are defined for these darts according to the definition.

Remember that $\alpha_{i+1}$ is modified for the darts of $c_i(d)$ (line 18). In order to avoid side effects, this is done in a second loop, after having defined all the $\alpha$ links for the new darts. Thus, the definition of the links for these new darts is based on the original $\alpha$ links of the $n$-Gmap. Moreover, and due to the same reason, it is also necessary to be careful for the second loop, in order to correctly iterate through the darts of $c_i(d)$. For that, the darts of $c_i(d)$ are stored in a data structure (for example a stack) during the first loop (line 2); the iteration of the second loop is done through this data structure, and not through a cell iterator (line 17).

The complexity of Algorithm 64 is linear in the number of darts #d of the chamfered $i$-cell times $\log #d$. Indeed, $n$ being a constant, the loops iterating through $j$ and $k$ (lines 7, 8, 10 and 15) are bounded and thus can be considered as constants, and the accesses to the associative array are done in log time.

# Algorithm 64: chamferingNGMap(gm,d,i): chamfer an i-cell for n-Gmaps

Input: gm: an n-Gmap;
        d ∈ gm.Darts: a dart;
        i ∈ {0, ..., n−1}.

Result: Chamfer the i-cell c_i(d).

```
1 phi ← an array of n − i + 1 empty associative arrays between darts;
2 foreach dart d' ∈ c_i(d) do
3     phi[i][d'] ← d';
4     for j ← i + 1 to n do
5         phi[j][d'] ← createDartNGMap(gm);
6 foreach dart d' ∈ c_i(d) do
7     for j ← i + 1 to n do
8         for k ← 0 to i − 1 do
9             phi[j][d'.Alphas[k]] ← phi[j][d'.Alphas[k]];
10        for k ← i to j − 1 do
11            phi[j][d'.Alphas[k]] ← phi[j][d'.Alphas[k + 1]];
12        phi[j][d'.Alphas[j]] ← phi[j − 1][d'];
13        if j < n then
14            phi[j][d'.Alphas[j + 1]] ← phi[j + 1][d'];
15        for k ← j + 2 to n do
16            phi[j][d'.Alphas[k]] ← phi[j][d'.Alphas[k]];
17 foreach dart d' ∈ c_i(d) do
18     d'.Alphas[i + 1] ← phi[i + 1][d'];
```

In Fig. 6.49, a 2-Gmap is extruded along a path. Three darts in G_extr(G'), dd'⁰, dd'¹ and dd'², correspond to each pair (d, d'), such that d (resp. d') is a dart of G (resp. G'). The rules for linking the darts are similar to the 1D case:

- - α₀''(dd'⁰) = d(α₀'(d'))⁰. For example, α₀''(a1⁰) = a2⁰;
- - α₀''(dd'¹) = (α₀(d))d'¹. For example, α₀''(a1¹) = b1¹;
- - α₀''(dd'²) = (α₀(d))d'². For example, α₀''(a1²) = b1²;
- - α₁''(dd'⁰) = dd'¹ (and reciprocally). For example, α₁''(a1⁰) = a1¹;
- - α₁''(dd'²) = (α₁(d))d'². For example, α₁''(a1²) = h1²;
- - α₂''(dd'⁰) = (α₁(d))d'⁰. For example, α₂''(a1⁰) = h1⁰;
- - α₂''(dd'¹) = dd'² (and reciprocally). For example, α₂''(a1¹) = a1²;
- - α₃''(dd'⁰) = (α₂(d))d'⁰. For example, α₃''(h1⁰) = i1⁰;
- - α₃''(dd'¹) = (α₂(d))d'¹. For example, α₃''(h1¹) = i1¹;
- - α₃''(dd'²) = d(α₁'(d'))². For example, α₃''(a2²) = a3².

These rules can be generalized for dimension n, and the extrusion operation is defined in Def. 73. n + 1 bijections φʲ are defined in order to associate the different darts issued from the same pair of original darts (i.e. φⁱ(dd') = dd'ⁱ). The first three items in the definition define α'' for the darts of D⁰, the three next items define α'' for the darts of Dⁿ, and the last four items define α'' for the darts of D¹, …, Dⁿ⁻¹ (note that the definitions for D⁰ and Dⁿ are simply particular cases of the general definitions).

## Definition 73 (extrusion) Let G = (D, α₀, …, αₙ) be an n-Gmap and G' = (D', α₀', α₁') be a 1-Gmap. The (n + 1)-Gmap resulting from the extrusion of G along G' is G_extr(G') = (D'', α₀'', …, αₙ₊₁''), defined by:

- - ∀j ∈ {0, …, n}, let Dʲ be a set of new darts, such that a bijection φʲ maps D × D' onto Dʲ;
- - D'' = ∪_{j=0}^n Dʲ;
- ∀d ∈ D, ∀d' ∈ D':
  1. α₀''(φ⁰(d, d')) = φ⁰(d, α₀'(d'));
  2. α₁''(φ⁰(d, d')) = φ¹(d, d');
  3. ∀i ∈ {2, …, n + 1}, αᵢ''(φ⁰(d, d')) = φ⁰(α_{i-1}(d), d');
  4. ∀i ∈ {0, …, n − 1}, αᵢ''(φⁿ(d, d')) = φⁿ(αᵢ(d), d');
