### 4.2.3 Unsew 操作

$i$-unsew 操作，定义于 Def. 20，是 $i$-sew 操作的逆。它总是可以对非 $i$-free darts 进行 $i$-unsew。

**Definition 20 (i-unsew).** 设 $G=(D,\alpha_0,\ldots,\alpha_n)$ 是一个 $n$-Gmap，$i\in\{0,\ldots,n\}$ 且 $d\in D$ 是一个非 $i$-free dart。由 $G$ 通过 $i$-unsew $d$ 和 $\alpha_i(d)$ 得到 $n$-Gmap 为 $G_{i\text{-unsew}(d)}=(D,\alpha_0,\ldots,\alpha_{i-1},\alpha'_i,\alpha_{i+1},\ldots,\alpha_n)$，其中 $\alpha'_i$ 定义为：$\forall e\in D$，

- 如果 $e\in\langle\alpha_0,\ldots,\alpha_{i-2},\alpha_i,\alpha_{i+2},\ldots,\alpha_n\rangle(d)$，$\alpha'_i(e)=e$；
- 否则，$\alpha'_i(e)=\alpha_i(e)$。

$i$-unsew 操作是将 $\alpha_i$ 设置为该轨道 $\langle\alpha_0,\ldots,\alpha_{i-2},\alpha_i,\alpha_{i+2},\ldots,\alpha_n\rangle(d)$ 中每个 dart $e$ 的恒等。因此，对该轨道中任意一个 dart 应用 $i$-unsew 会产生相同的结果。

很容易证明 $i$-sew 和 $i$-unsew 互为逆：对两个 $i$-free darts $d$ 和 $d'$ 应用 $i$-sew，然后对 $d$ 应用 $i$-unsew，会得到原始的 $n$-Gmap；对 dart $d$ 应用 $i$-unsew，该 dart 为非 $i$-free，然后对 $d$ 和 $d'$ 应用 $i$-sew，使得 $d$ 和 $d'$ 原本由 $\alpha_i$ 链接，会得到原始的 $n$-Gmap。因此，我们可以通过查看 sew 操作的例子并反向阅读图形来看到 unsew 操作的例子。例如，考虑 Fig. 4.6(b) 给出的 3-Gmap，对 dart 1 应用 1-unsew 操作会得到 Fig. 4.6(a) 给出的 3-Gmap。另一个例子，从 Fig. 4.9(c) 给出的 3-Gmap 开始，对 dart 1 应用 3-unsew 操作会得到 Fig. 4.9(a) 给出的 3-Gmap。

## 4.3 完备性，多重关联

在本节中，我们证明任何 $n$-Gmap 都可以通过基本操作构建。为此，提出了两种构建 $n$-Gmap 的基本构造方法：第一种方法是通过迭代创建过程，从 0 维开始逐步增加 $n$-Gmap 的维度直到对象的维度，并在每一步为新维度缝合一些 darts；第二种方法直接在对象的维度开始，添加一些孤立的 darts，并在任意维度缝合一些 darts。注意，与基本操作一样，这些构造方法的主要兴趣主要在理论上，实际应用中通常使用高级操作。

### 4.3.1 通过增加维度构造

第一种构造方法对应于为 $n$-Gmaps 的直观介绍所描述的分解过程的逆（参见第 3.2 节）。它从 0D 开始，包含一组 darts 且 $\alpha_0$ 等于恒等式。该 darts 集描述了一组孤立顶点。然后对一些 darts 进行 0-sew，以便将对应的顶点配对。维度通过添加初始化为恒等式的 $\alpha_1$ 而增加。这产生了一组孤立边，其边界是之前的顶点对。然后对一些 darts 进行 1-sew 以粘合对应的边，通过识别顶点。这产生了一组细分曲线。维度通过添加初始化为恒等式的 $\alpha_2$ 而增加，产生了一组孤立面，其边界是之前的细分曲线。现在对一些 darts 进行 2-sew 以识别一些边以及它们的边界。这沿着它们的边粘合对应的面，产生了一组细分曲面，依此类推。

该过程可以在任意维度中推广。为此，迭代应用以下两个操作：

- 通过添加初始化为恒等式的 $\alpha_n$ 增加维度；
- 对一些 darts 进行 $n$-sew 以识别一些 $(n-1)$-胞（及其边界）。记住，只有当它们具有相同的结构时，两个 $(n-1)$-胞的识别才可能。
