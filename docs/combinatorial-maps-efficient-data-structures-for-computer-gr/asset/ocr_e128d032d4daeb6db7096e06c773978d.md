# FIGURE 8.12

In a numbered simplicial quasi-manifold, the implicit orientation of an n-simplex is inverse from the implicit orientations of the n-simplices which share an (n − 1)-simplex with it.

If all simplices are coherently oriented, Q is orientable (and oriented), else Q is not orientable. Another way consists in choosing also an n-simplex with its implicit orientation, and to traverse all simplices which must have this orientation, i.e. the simplices adjacent to the simplices adjacent to the initial simplex, and then iterate this process. At the end, either the half of the simplices of Q have been traversed, and Q is orientable (the set of traversed simplices corresponds to one orientation, the remaining simplices correspond to the other orientation), either all simplices of Q have been traversed and Q is not orientable.

This process can be applied for the associated connected premap P. Let H = (D, α₁ ∘ α₀, …, αₙ ∘ α₀) be the hypermap of the orientations of P. H contains at most two connected components: either H contains two connected components, and P is orientable (as Q), either H contains one connected component, and P is not orientable (as Q).

Conversely, let H = (D, β₁, …, βₙ) be a connected n-hypermap. H⁻¹ = (D, β₁⁻¹, …, βₙ⁻¹) is the hypermap inverse of H. Let H′ = (D′, β₁′, …, βₙ′), such that D ∩ D′ = ∅, and an isomorphism φ exists, which maps H onto the inverse of H′ (in other words, H′ is a copy of H⁻¹). Define P = (D ∪ D′, π₀, …, πₙ), with:

+   - π₀|D = φ; π₀|D′ = φ⁻¹;
+   - for 1 ≤ i ≤ n, πᵢ|D = βᵢ′ ∘ φ; πᵢ|D′ = βᵢ ∘ φ⁻¹.

P is a connected orientable premap, such that its hypermap of the orientations contains two connected components, which are H and H′.
