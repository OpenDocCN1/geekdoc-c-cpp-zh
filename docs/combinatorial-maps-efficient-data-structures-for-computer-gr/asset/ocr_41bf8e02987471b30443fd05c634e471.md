0-simplices numbered (2), namely b (resp. d, f, h), correspond to ⟨α₀, α₁⟩(1) = ⟨⟩[0,2]\{2}(1) (resp. ⟨α₀, α₁⟩(8), ⟨α₀, α₁⟩(3), ⟨α₀, α₁⟩(5)); 0-simplices numbered (1), namely c (resp. e, i), correspond to ⟨α₀, α₂⟩(7) = ⟨⟩[0,2]\{1}(7) (resp. ⟨α₀, α₂⟩(9), ⟨α₀, α₂⟩(1)); 0-simplices numbered (0), namely a (resp. g, j), correspond to ⟨α₁, α₂⟩(1) = ⟨⟩[0,2]\{0}(1) (resp. ⟨α₁, α₂⟩(4), ⟨α₁, α₂⟩(2)).

The face operators are defined in the following way: let I = (j₀, …, jᵢ, …, jᵢ) be such that i ≥ 1, d be a dart, and σ be the simplex associated to ⟨⟩[0,n]\I(d); then dᵢ(σ) is the (i − 1)-simplex associated with ⟨⟩[0,n]\(I − {jᵢ})(d). For instance in Fig. 8.10:

+   - d₀(A) = L, since A is associated with ⟨⟩[0,2]\{0,1,2}(1) = ⟨⟩(1) and L is associated with ⟨⟩[0,2]\({0,1,2}−{0})(1) = ⟨α₀⟩(1); d₁(A) = l, since l is associated with ⟨⟩[0,2]\({0,1,2}−{1})(1) = ⟨α₁⟩(1); d₂(A) = K, since K is associated with ⟨⟩[0,2]\({0,1,2}−{2})(1) = ⟨α₂⟩(1); note that this is coherent with the fact that, for any 0, i ≤ i ≤ n, αᵢ corresponds to an “adjacency relation” between n-simplices sharing a common face obtained by dᵢ;

+   - d₀(K) = i (resp. d₁(K) = a), since K is associated with ⟨⟩[0,2]{0,1}(1) = ⟨α₂⟩(1) and i (resp. a) is associated with ⟨⟩[0,2]\{1}(1) = ⟨α₀, α₂⟩(1) (resp. ⟨⟩[0,2]\{0}(1) = ⟨α₁, α₂⟩(1)); d₀(l) = b (resp. d₁(l) = a), since l is associated with ⟨⟩[0,2]{0,2}(1) = ⟨α₁⟩(1) and b (resp. a) is associated with ⟨⟩[0,2]\{2}(1) = ⟨α₀, α₁⟩(1) (resp. ⟨⟩[0,2]\{0}(1) = ⟨α₁, α₂⟩(1)); d₀(L) = b (resp. d₁(L) = i), since L is associated with ⟨⟩[0,2]\{1,2}(1) = ⟨α₀⟩(1) and b (resp. i) is associated with ⟨⟩[0,2]\{2}(1) = ⟨α₀, α₁⟩(1) (resp. ⟨⟩[0,2]\{1}(1) = ⟨α₀, α₂⟩(1));

At last, any 0-simplex corresponding to an orbit ⟨⟩[0,n]{i} = ⟨α₀, …, αᵢ, …, αₙ⟩ is numbered i (and this is coherent with the numbering of face operators).

So, any n-premap can be associated with a unique n-dimensional numbered simplicial quasi-manifold.

In conclusion, n-dimensional numbered simplicial quasi-manifolds are equivalent to n-premaps, and the conversion processes described above are inverse to each other.

# Cellular quasi-manifolds and n-Gmaps

The conversion processes described above still apply for n-dimensional cellular quasi-manifolds and n-Gmaps. So, n-dimensional cellular quasi-manifolds are equivalent to n-Gmaps.
