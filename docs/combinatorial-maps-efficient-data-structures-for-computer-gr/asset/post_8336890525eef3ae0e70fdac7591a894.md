
The α_j links are defined when processing α_j(d); this is why this definition is done in both directions.

α_{i-1} is initialized by following the path of darts α_{i-1} ∘ (α_i ∘ α_{i-1})^k(d) until obtaining either an i-free dart, or a dart such that its dart associated by α_i is (i-1)-free. The first case corresponds to the definition of α'_{i-1} in the i-boundary map. However, in this case, it is not possible to define α_{i-1}, as the second dart concerned by this definition is not yet created: the definition will be done when the second extremity of this path will be processed. For this second dart, the first dart is no longer i-free, because its corresponding dart is already created and linked with it by α_i. However, the new dart is (i-1)-free since it was not yet (i-1)-linked, and this corresponds to the second case. So, α_{i-1}(d') = α_i(d''), and reciprocally. As d' = f(d) and α_i(d'') = f(α_{i-1} ∘ (α_i ∘ α_{i-1})^k(d)), this is equivalent to α''_{i-1}(f(d)) = f(α_{i-1} ∘ (α_i ∘ α_{i-1})^k(d)); this corresponds to item 2 of the i-closure definition.

The complexity of Algorithm 47 is linear in the number of darts of a G-map. Indeed, each dart is considered exactly once in the main foreach loop. In this loop, each operation is atomic except the while loop (line 11) which is linear in the number of darts in the path α_{i-1} ∘ (α_i ∘ α_{i-1})^k(d). However, these darts are considered exactly twice, the first time when d is processed, and the second time when the second i-free dart is processed. In other words, these paths are disjoint for different pairs of i-free darts. So, the overall complexity of the algorithm is linear in the number of darts of the n-Gmap.

To illustrate the behavior of this algorithm, consider the 2-Gmap given in Fig. 6.4(a), and apply the 2-closure algorithm. Darts are processed in any order, and there is nothing to do for non-2-free darts. So, for example, start with dart d = 5. A new dart d' = 26 is created, and darts 5 and 26 are 2-sewn. The first loop (line 4) considers only j = 0. As d'' = 6 is 2-free, the new dart is not 0-sewn. The second loop (line 11) allows to define α_1. Starting from d'' = 4, d'' = 18 is reached after one iteration; it is 2-free, thus α_1 is not defined for d'. Then another 2-free dart is processed, for example d = 17. As for the previous case, a new dart d' = 28 is created, darts 17 and 28 are 2-sewn, α_0 and α_1 are not defined for new dart 28. Now if dart d = 18 is considered, a new dart d' = 27 is created, and darts 18 and 27 are 2-sewn. First, as d'' = 17 is not 2-free, α_0(27) is defined as α_2(17) = 28, and α_0(28) is defined as 27 (lines 7 and 8). Second, starting from d'' = 9, d'' = 5 is reached after one iteration; dart 5 is not 2-free, but α_2(5) is 1-free. Thus α_1(27) is defined as α_2(5) = 26, and α_1(26) is defined as 27 (lines 14 and 15).

The principle is similar in 3D. Consider for example the 3-Gmap given in Fig. 6.5(a), and apply the 3-closure operation. If dart d = 32 is first processed, a new dart d' = 32' is created, and darts 32 and 32' are 3-sewn. The first loop (line 4) considers j ∈ {0,1}, but in both cases, α_j(32) is 3-free. The second loop (line 11) allows to define α_2. Starting from d'' = α_2(32), d'' = 19 is obtained after one iteration; it is 3-free, and thus α_2 is not defined for dart 32'. Consider now d = 31; a new dart d' = 31' is created, and darts 31 and 31' are 3-sewn. During the first loop, darts 31' and 32' are 0-sewn. Consider now d = 20; a new dart d' = 20' is created, and darts 20 and 20' are 3-sewn. No sew is done during the first loop; darts 20' and 31' are 2-sewn, as dart d'' = 31 is obtained, which is such that α_3(31) is 2-free, and which is not 3-free.

## 6.1.2 For n-maps

The i-closure operation, for i ≥ 2, is defined in Def. 56 for an n-map M. As for n-Gmaps, new darts are created, one for each i-free dart in M; these darts are linked among themselves by β_j, ∀j ∈ {1,…,n}, j ≠ i, according to the corresponding links in the inverse of the i-boundary map M_{\partial_i} (cf. Def. 49 page 175); each new dart is linked by β_i with its corresponding dart in M.

**Definition 56 (i-closure)** Let M = (D, β_1, …, β_n) be an n-map, i ∈ {2,…,n}, and M_{\partial_i}^{-1} = (D', β_1', …, β_n') be the inverse of the i-boundary map of M. The i-closure of M is the n-map M_i-close = (D'', β_1'', …, β_n'') defined by:

1. D'' = D ∪ {d''_1, …, d''_{|D'|}}, where {d''_1, …, d''_{|D'|}} is a set of new darts, such that a bijection f maps D' onto {d''_1, …, d''_{|D'|}};
2. ∀j ∈ {1,…,n} such that j ≠ i:
   - ∀d ∈ D, β_j''(d) = β_j(d);
   - ∀d' ∈ D', β_j''(f(d')) = f(β_j'(d'));
3. ∀d ∈ D \ D', β_i''(d) = β_i(d);
4. ∀d ∈ D', β_i''(d) = f(d), β_i''(f(d)) = d.

The 2-closure operation is illustrated in Fig. 6.6. Starting from the 2-map with boundary given in (a), the 2-map shown in (b), obtained by applying the 2-closure operation, has no 2-boundary. In the initial 2-map, six darts are 2-free, thus six new darts are created, numbered from 13 to 18. These new darts are linked by β_2'' with their corresponding darts. Moreover, these new darts are linked among themselves by β_1'', according to the corresponding links in the inverse of the 2-boundary map M_{\partial_2}^{-1}.

The 2-map depicted in Fig. 6.7 has 1-boundaries and 2-boundaries. In this case, the 2-closure operation produces a 2-map without 2-boundary, but it still has 1-boundaries.

The 1-closure operation is defined in Def. 57.

**Definition 57 (1-closure)** Let M = (D, β_1, …, β_n) be an n-map, with n > 0, and M_{\partial_1} = (D', β_1', …, β_n') be the corresponding 1-boundary map. The 1-closure of M is the n-map M_1-close = (D'', β_1'', …, β_n'') defined by:

1. D'' = D ∪ {d''_1, …, d''_{|D'|}}, where {d''_1, …, d''_{|D'|}} is a set of new darts, such that a bijection f maps D' onto {d''_1, …, d''_{|D'|}};
2. ∀j ∈ {2,…,n}:
   - ∀d ∈ D, β_j''(d) = β_j(d);
   - ∀d' ∈ D', β_j''(f(d')) = f(β_j'(d'));
3. ∀d ∈ D \ D', β_1''(d) = β_1(d);
4. ∀d ∈ D', β_1''(d) = f(d), β_1''(f(d)) = β_0^k(d), where k is the smallest positive integer such that β_0^k(d) is 0-free.

There are two differences with the definition of the i-closure for i ≥ 2. First, the 1-boundary map M_{\partial_1} is considered and not its inverse. Indeed, all darts in D' are 1-free, thus M_{\partial_1} = M_{\partial_1}^{-1}. Second, β_1''(f(d)) is not equal to d, since β_1 is not an involution. It is equal to β_0^k(d), k being the smallest positive integer such that β_0^k(d) is 0-free. Intuitively, β_1 defines polygonal lines, and β_0 is the second extremity of the open polygonal line incident to d.

In the initial 1-map, there is one 1-free dart (numbered 3), thus one dart (numbered 4) is created. β_1''(3) = f(3) = 4, since dart 4 is the new dart corresponding to dart 3. However, it is more complex to define β_1''(4), since it is necessary to retrieve the 0-free dart belonging to the same polygonal line. So, β_0^k(3) has to be computed, where k is the smallest positive integer such that β_0^k(3) is 0-free. Thus β_1''(4) = β_0^2(3) = 1.
