# *Relations, functions, permutations, involutions, compositions*

Let $F$ and $G$ be two sets. A relation $R$ between $F$ and $G$ is a set of pairs $(x,y)$ such that $x\in F$ and $y\in G$, i.e. it is a subset of $F\times G$, the *cartesian product* of $F$ and $G$, which is $\{(x,y)\mid x\in F, y\in G\}$. An oriented graph can be associated with any relation (and conversely), i.e. the graph $(F\cup G,R)$: cf. Fig. 2.24(a). The graph is bipartite when $F$ and $G$ are disjoint.

Relation $R$ is *symmetric* when $xRy\Rightarrow yRx$: cf. Figs. 2.24(b) and (c); in other words, when two vertices $x$ and $y$ are connected by $(x,y)$ in the associated graph, then they are also connected by $(y,x)$. A *nonoriented edge* $\{x,y\}$ can be defined by a set of two opposite edges $(x,y)$ and $(y,x)$, and a *nonoriented graph* can be defined as the graph associated with a symmetric relation.

A *function* (or a *map*) $\phi$ is a relation such that, for any $x\in F$, there is exactly one $y\in G$ such that $(x,y)\in\phi$; $y$ is denoted $\phi(x)$; so, in the corresponding graph, any vertex has exactly one edge (cf. Fig. 2.24(d)). Let $F'\subset F$, and let $G'\subset G$ be the set of all *images* of elements of $F'$ by $\phi$, i.e. $G'=\{y\in G\mid\exists x\in F',\phi(x)=y\}$. Then $\phi':F'\to G'$, defined by: $\forall x\in F',\phi'(x)=\phi(x)$, is the restriction of $\phi$ to $F'$, denoted $\phi'=\phi|_{F'}$. The graph corresponding to $\phi'$ is a *subgraph* of the graph associated with $\phi$, which contains vertices corresponding to elements of $F'$.
