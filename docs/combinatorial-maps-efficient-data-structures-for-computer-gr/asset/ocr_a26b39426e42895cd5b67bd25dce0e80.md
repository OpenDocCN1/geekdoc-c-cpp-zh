# **FIGURE 2.24**

(a) Graph of a relation $R$: $F=\{a,b,c\}$, $G=\{a,b,d,e\}$, $R=\{(a,a),(a,b),(a,d),(b,b),(b,d),(c,d)\}$.

(b) Graph of a symmetric relation $R'$: $F'=G'=\{a,b,c,d,e\}$, $R'=\{(a,a),(a,b),(a,d),(b,a),(b,d),(c,d),(d,a),(d,b),(d,c)\}$.

(c) Another representation of the nonoriented graph associated with $R'$.

(d) Graph of a function $\phi$: $F=\{a,b,c,d\}$, $G=\{b,c\}$, $\phi=\{(a,b),(b,b),(c,b),(d,c)\}$.

(e) A permutation $P$: $F=\{a,b,c,d,e,f\}$, $P=\{(a,b),(b,c),(c,a),(d,d),(e,f),(f,e)\}$.

(f) $P^{-1}$, the inverse of $P$, is: $P^{-1}=\{(b,a),(c,b),(a,c),(d,d),(e,f),(f,e)\}$.
