Moka was used for different projects, for which users need to describe real 3D objects, with possibly multi-incidence and mixing different types of cells. For example, Moka was used to describe physical objects in order to propose a topology-based physical simulation [177, 176], or to define a discrete pyramid representing objects in images with different discrete embeddings [72, 92].

The MokaARCHI project [134, 136] is based on Moka for the reconstruction of 3D buildings from 2D autocad plans (see Fig. 7.12).
