# Definition 62 (0-cell removal)

Let M = (D, β_1, ..., β_n) be an n-map and C be a removable 0-cell. The n-map resulting from the 0-removal of C in M is M_{R0}(C) = (D', β'_1, ..., β'_n), defined by:

+   D' = D \ C;

+   ∀j ∈ {1, ..., n}, ∀d ∈ D':
+   - if d ∉ β_j^{-1}(C) \ C, β'_j(d) = β_j(d);
+   - otherwise, β'_j(d) = β_j ∘ (β_1)^k(d), k being the smaller positive integer s.t. β_j ∘ (β_1)^k(d) ∉ C.

Look again at Fig. 6.20; C = {1,8}. For j = 1, β_1^{-1}(C) \ C = {7,10}; thus, β'_1(7) = 2 and β'_1(10) = 8. For j = 2, β_2^{-1}(C) \ C = {7,10}, thus β'_2(7) = 10 and β'_2(10) = 7. k = 1 for all cases.

An example of 0-removal in 3D is presented in Fig. 6.24. Vertex {1,3,6,8,10,11} is removed from the 3-map depicted in Fig. 6.24(b) (only darts around the removed vertex are drawn). The vertex is 0-removable, because β_1 ∘ β_2 = β_2 ∘ β_0 for each of its darts (for example β_1 ∘ β_2(1) = β_2 ∘ β_0(1) = 10). For j = 1, β_1^{-1}(C) \ C = {2,4,5,7,9,12}, and, for example, β'_1(2) = β_1(8). For j = 2, β_2^{-1}(C) \ C = {2,4,5,7,9,12}, and, for example, β'_2(2) = β_2 ∘ β_1(2) = 9. For j = 3, β_3^{-1}(C) \ C = {2,4,5,7,9,12}, and, for example, β'_3(2) = β_3 ∘ β_1(2) = 7.
