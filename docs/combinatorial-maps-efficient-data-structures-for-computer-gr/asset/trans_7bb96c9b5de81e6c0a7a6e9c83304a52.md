设G是一个关联图，并令c^i是G的一个顶点。c^i的闭包是G的一个子图，使得c^i是其根；换句话说，它包含c^i、所有满足在G中存在从c^i到c^k的路径的顶点c^k（因此k < i），以及G中连接这些顶点的所有边。c^i的边界是c^i的闭包减去c^i及其关联边。设G^-是从G反转所有边而得到的图；c^i的星（相应地，真星）是G中对应于G^-中c^i的闭包（相应地，c^i的边界）的子图。c^i在G中的邻域是G的一个子图，它包含星的全体顶点和c^i的边界，以及连接这些顶点的所有边。c^i的严格邻域是c^i的邻域减去c^i及其所有关联边，再加上所有满足边(c^{i+1}, c^i)和(c^i, c^{i-1})在G中存在的边(c^{i+1}, c^{i-1})。

**定义89（n-曲面）[84, 85]**

- 1. 一个关联图是一个0-曲面，如果它恰好由两个顶点c^0和c'^0组成，并且没有边；
- 2. 一个关联图G是一个n-曲面，n > 0，如果它是连通的，并且对于任意顶点c^i，c^i的严格邻域是一个(n − 1)-曲面。

请记住，0-球面是两个点的集合：因此0-球面的结构对应于0-曲面。刻画n-曲面的性质是一个局部性质，它必须对图的任意顶点成立，即对相关细分的任意胞腔成立。与n-G映射的对应关系将在下面解释。

注意，所有主胞腔的维数都是n。此外，n-曲面满足以下切换性质：参见图8.16(f)和(g)。设G是一个n-曲面，向其添加两个顶点c^{n+1}和c^{-1}，并添加将c^{n+1}与任何编号为n的顶点相连、以及将任何编号为0的顶点与c^{-1}相连的边。那么对于任意胞腔x^i和y^j，b(x^i) ∩ s(y^j)要么为空，要么恰好由两个元素组成，其中b(x^i)（相应地，s(y^j)）是x^i的边界中编号为i − 1的顶点的集合（相应地，y^j的星中编号为j + 1的顶点的集合）。

## 8.3 一些推论

### 8.3.1 映射链

**定义与基本操作**

对于若干应用而言，处理其他类别的“对象”可能是有用的，例如那些胞腔是拟流形但自身并非拟流形的细分“对象”。这引出了映射链的定义：

**定义90（映射链）[104]** 一个n维映射链是一个元组C = ((G^i)_{i=0,…,n}, (σ^i)_{i=1,…,n})，满足（参见图8.17(a)和(b)）：

- 1. ∀i, 0 ≤ i ≤ n, G^i = (D^i, α_0^i, …, α_{i-1}^i, α_i^i = ω)是一个i维广义映射，使得ω在D^i上无定义；
- 2. ∀i, 1 ≤ i ≤ n, σ^i : D^i ⟶ D^{i-1}；
   对于 i ≥ 2，σ^i满足：对于D^i的任意达特d：
   - (a) 对于任意j，0 ≤ j ≤ i − 2，σ^i(α_j^i(d)) ∈ {σ^i(d), α_j^{i-1}(σ^i(d))}（换句话说，σ^i是一个将G^i的轨道⟨α_0^i, …, α_{i-2}^i⟩与G^{i-1}的轨道⟨α_0^{i-1}, …, α_{i-2}^{i-1}⟩的（一个子集）相关联的函数）；
   - (b) σ^{i-1} ∘ σ^i ∘ α_{i-1}^i(d) = σ^{i-1} ∘ σ^i(d)。

i-G映射的任意连通分量是一个i维胞腔，即i-胞腔：这就是为什么α_i^i = ω无定义，以便仅描述胞腔的内部。这些胞腔通过面算子σ^i连接。

映射链可以按以下方式构造：取孤立的胞腔及其边界，然后等同胞腔（参见图8.17(e)和(f)）。更精确地说，首先注意，任意n-G映射都可以关联一个映射链（参见图8.17(c)和(d)以及下面的转换过程）。因此，一个孤立的i-胞腔c_i是对应于i-G映射G^{c_i} = (D^{c_i}, α_0^{c_i}, …, α_{i-1}^{c_i}, α_i^{c_i} = Id)的映射链，该i-G映射包含唯一的连通分量。G^{c_i}的典范边界是(D^{c_i}, α_0^{c_i}, …, α_{i-1}^{c_i})。因此，与G^{c_i}关联的映射链包含一个i-胞腔及其典范边界（参见图8.17(e)）。然后很容易定义一种操作来等同两个i-胞腔G^{c_i} = (D^{c_i}, α_0^{c_i}, …, α_{i-1}^{c_i}, α_i^{c_i} = ω)和G^{c'_i} = (D^{c'_i}, α_0^{c'_i}, …, α_{i-1}^{c'_i}, α_i^{c'_i} = ω)，使得：

- 1. 存在一个函数φ : D^{c_i} → D^{c'_i}，使得对于任意d ∈ D^{c_i}，对于任意j，0 ≤ j ≤ i − 1，φ(α_j^{c_i}(d)) ∈ {φ(d), α_j^{c'_i}(φ(d))}；换句话说，这些胞腔之间存在一种对应关系，因此它们的结构中有公共元素；
- 2. 对于任意d ∈ D^{c_i}，σ^i(d) = σ^i(φ(d))。换句话说，这两个胞腔共享相同的边界。

该操作包括：对于任意满足σ^{i+1}(d′) = d ∈ G^{c_i}的达特d′ ∈ G^{i+1}，修改σ^{i+1}，使得σ^{i+1}(d′) = φ(d)，并移除G^{c_i}。

已经定义了映射链的子类：例如，当对于任意i ≥ 1，σ^i是i-胞腔边界的轨道⟨α_0^i, …, α_{i-2}^i⟩与一个(i − 1)-胞腔之间的同构时，i-胞腔的结构与其边界之间存在严格的对应关系。这些性质可用于定义优化的数据结构。

- 1. 对于任意i，0 ≤ i ≤ n，在G的轨道⟨α_{i+1}, …, α_n⟩的集合与D^i之间存在一个双射φ^i。例如，在图8.17(c)和(d)中：
  - (d)中D^2的所有达特对应于(c)中的轨道⟨⟩；
