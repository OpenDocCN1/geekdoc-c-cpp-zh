# FIGURE 4.13

Construction of a 3D object by applying the first method (partial representation). The first line shows the different n-Gmaps, and the second line the corresponding objects.
(a) 1-Gmap (D, α₀, Id_D) corresponds to (e), a set of isolated edges.
(b) 2-Gmap (D, α₀, α₁, Id_D) obtained after forty 1-sew operations, and one increase dimension operation. This 2-Gmap corresponds to eleven faces, shown in (f).
(c) 3-Gmap (D, α₀, α₁, α₂, Id_D) obtained after twenty 2-sew operations and one increase dimension operation. This 3-Gmap corresponds to the 3D subdivided object shown in (g) containing two volumes.
(d) 3-Gmap (D, α₀, α₁, α₂, α₃) obtained after one 3-sew operation, and (h) the corresponding 3D subdivided object.
