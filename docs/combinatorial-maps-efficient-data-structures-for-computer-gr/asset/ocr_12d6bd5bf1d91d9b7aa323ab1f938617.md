# 3.2 n-Gmaps

For n-Gmaps, the process of successive decompositions is similar to the one explained in the previous section for n-maps. There are only two differences:

+   1. the original object is not oriented (it can be orientable or not);
+   2. one more decomposition is applied: instead of ending the process with edges, the edges are decomposed into isolated vertices.

Due to these similarities, n-Gmaps are explained using the same examples presented in the previous section, and all the decomposition steps are not explained again, but only the last one.
