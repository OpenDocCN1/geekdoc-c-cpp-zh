In the example of Fig. 6.15, only one face is incident to edge {3, 4, 5, 6}, which is thus a dangling edge. Before defining the i-removal operation, the i-removability condition is defined in Def. 58: it characterizes the cells which can be removed. As explained above, an i-cell can be removed if it has at most two (i + 1)-cells incident.
