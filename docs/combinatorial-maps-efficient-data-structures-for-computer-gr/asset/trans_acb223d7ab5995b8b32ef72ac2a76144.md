## 5.3.3 完备性

借助这两种构造方法，可以构造任意 n-map。

### 定理 3（第一种 n-map 构造或销毁方法的完备性）

任意 n-map 都可以通过一系列解缝和降维操作变换为 0 维中的一组孤立飞镖，且解缝操作总是应用于尽可能高的维度。反之，任意 n-map 都可以从 0 维中的一组孤立飞镖出发，仅通过升维和缝合操作来构造，且缝合操作总是应用于尽可能高的维度。

这个定理的证明很容易。首先，证明任何 n-map 都可以通过应用一系列降维和解缝操作，分解为 0 维中的一组飞镖。设 M 为一个 n-map。对任意非 n-自由飞镖应用 n-解缝操作。该操作总是可以应用于非 n-自由飞镖，并且至少使 n-自由飞镖的数量增加两个。因此，最终所得 n-map 的所有飞镖都是 n-自由的。接下来，可以应用降维操作，产生一个 (n − 1)-map。该过程可以重复，直到获得由一个孤立飞镖集组成的 0-map。为了证明定理的第二部分，让我们按相反顺序考虑上述操作序列，并将每个操作替换为它的逆操作（将降维替换为升维，将 i-解缝替换为 i-缝合）。该序列将 0-map 变换为 M。

对第二种构造方法，可以陈述类似的定理和证明。

### 定理 4（第二种 n-map 构造或销毁方法的完备性）

任意 n-map 都可以通过一系列 i-解缝和移除孤立飞镖操作变换为空的 n-map。反之，任意 n-map 都可以从空 n-map 开始，应用添加孤立飞镖和 i-缝合操作来构造。

该定理第一部分的证明基于以下事实：i-解缝操作可以应用于任意非 i-自由飞镖，至少使 i-自由飞镖的数量增加两个。当一个飞镖被孤立时，它可以被移除。这样我们得到一个操作序列，它最终销毁了 n-map；为了得到最初的 n-map，可以按相反顺序应用逆操作，从而证明了该定理。

## 5.3.4 多重关联

任意 n-map 都可以通过基本构造操作来构造；现在研究可能的配置。实际上，缝合操作有两种情况：第一种是两个不同单元的识别；第二种是一个单元与其自身的识别。对于实际应用，识别（几乎）总是应用于两个不同单元。

这种特定的识别一般不用于通常的应用。它可以很容易地避免，要么以构造的方式在缝合操作的定义中增加一个约束，要么直接对 n-map 的定义增加一个约束。在第一种情况下，i-缝合操作被限制为仅将属于两个不同轨道 ⟨β₁, …, βᵢ₋₂, βᵢ₊₂, …, βₙ⟩ 的两个飞镖作为输入。在第二种情况下，在 n-map 的定义中增加一个约束，要求任意飞镖 d 不属于 ⟨β₁, …, βᵢ₋₂, βᵢ₊₂, …, βₙ⟩(βᵢ(d))。注意，通过在遍历 n-map 时搜索这样的飞镖，很容易测试该约束是否满足。
