In conclusion, any incidence graph has a simplicial analog, which is a (numbered) abstract simplicial complex. But if you try to intuitively deduce an incidence graph from a given subdivision, be careful with multi-incidence! That is why incidence graphs are often used for representing subdivisions with convex cells, avoiding thus multi-incidence: such subdivisions are regular CW-complexes [39, 139]: cells are homeomorphic to balls (due to the convexity property), and no multi-incidence occurs (for the same reason).
