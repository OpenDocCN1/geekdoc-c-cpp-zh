# FIGURE 4.14

Construction of a 2D object by applying the second method. The first line shows the different 2-Gmaps, and the second line the corresponding objects.
(a) 2-Gmap (D, Id_D, Id_D, Id_D) corresponds to (e), a set of isolated faces with boundaries.
(b) 2-Gmap (D, α0, Id_D, Id_D), obtained after seven 0-sew operations, corresponds to the object shown in (f).
(c) 2-Gmap (D, α0, Id_D, α2), obtained after one 2-sew operation, corresponds to the object shown in (g).
(d) 2-Gmap (D, α0, α1, α2), obtained after seven 1-sew operations, corresponds to the object shown in (h).
