## 3.1.1.2 2D

同样的过程可以应用于没有边界的 2D 有向拟流形，即闭合有向曲面，如图 3.4(a) 所给的例子。拟流形由四个面组成，标记为 f₁ 到 f₄，九条边和七个顶点。注意无界面 f₁ 的存在，这是因为该对象没有边界。

# FIGURE 3.4

(a) 一个没有边界的 2D 有向拟流形。
(b) 曲面的分解产生一组由 β₂ 链接的孤立有向面。
(c) 描述孤立有向面边界的有向多边形曲线的分解产生一组由 β₁ 链接的孤立有向边。
(d) 对应 2-图的表示。Darts 和 β₁ 如上所示表示。由 β₂ 关联的两个 darts 由灰色线段连接。

首先，有向曲面通过将每条边拆分为两部分进行分解，产生图 3.4(b) 中绘制的孤立有向面集合。由于初始拟流形是相干定向的（即所有面具有相同的定向），则为每条拆分边检索到正确的定向，即在拆分前描述同一条边的两条边定向方向相反。两条拆分边在初始对象中描述同一条边的信息是通过添加一个链接两条边的关系 $\beta_2$ 来表示的。注意该关系是对称的，因此 $\beta_2$ 是一个对合，即从边集合到边集合的双射，等于其逆。

每个孤立面的边界是一个 1D 有向拟流形，因此上面为 1D 情况介绍的构造适用：每个闭合有向多边形曲线通过将每个顶点拆分为两部分进行分解，产生孤立有向边的集合（见图 3.4(c)），这就是描述初始 2D 有向拟流形的 2-图的 darts 集合。与 1D 类似，添加一个 $\beta_1$ 关系以链接一条有向边和同一面中在拆分前共享一个公共顶点的下一条边。

注意两个关系 $\beta_1$ 和 $\beta_2$ 在分解过程中直接定义在有向边（即 darts）上。因此 2-图是 darts 集合加上 $\beta_1$，一个置换，和 $\beta_2$，一个对合（见图 3.4(d)）。还要注意 2D 拟流形的每条边在对应的 2-图中恰好由两个 darts 描述。Darts 用黑色箭头绘制，有时编号或标记。$\beta_2$ 关系由穿过两个相关 darts 的灰色线段表示（例如 $\beta_2(1)=5$，$\beta_2(2)=17$），而 $\beta_1$ 关系隐式表示，因为两个相关的 darts 连续绘制（例如 $\beta_1(1)=2$，$\beta_1(2)=3$）。

2-图的每个 dart 描述了初始 2D 有向拟流形中一个顶点 $v$ 的一部分、一条有向边 $e$ 的一部分和一个有向面 $f$ 的一部分，这三个胞腔 $v$、$e$ 和 $f$ 彼此相邻。此外，$v$ 是有向边 $e$ 的起点。例如图 3.4(d) 中的 dart 1 在图 3.4(a) 中描述了顶点 $v_1$ 的一部分、边 $e_2$ 的一部分和面 $f_2$ 的一部分（并且 $v_1$、$e_2$ 和 $f_2$ 全部相邻）。图 3.5(a) 的 2-图中每个 dart 对应的顶点、边和面部分在图 3.5(b) 中表示。

每个 dart 描述顶点的一部分、边的一部分和面的一部分这一事实对 $n$-图中胞腔的定义有重要影响。事实上，有必要考虑属于同一胞腔的所有 darts 的集合以描述整个胞腔。这些 darts 集合可以从给定的 dart $d$ 通过某些特定的轨道检索得到：

- $\langle\beta_1\rangle(d)$ 是包含 dart $d$ 的面；
- $\langle\beta_2\rangle(d)$ 是包含 dart $d$ 的边；
- $\langle\beta_2 \circ \beta_1^{-1}\rangle(d)$ 是包含 dart $d$ 的顶点。

例如，在图 3.5(a) 给出的 2-图中，包含 dart 1 的顶点为 ⟨β₂ ∘ β₁⁻¹⟩(1) = {1,6,9}；包含 dart 1 的边为 ⟨β₂⟩(1) = {1,5}，包含 dart 1 的面为 ⟨β₁⟩(1) = {1,2,3,4}。更一般地，每个胞腔由属于同一胞腔的所有 darts 的集合组成；胞腔的结构由 βᵢ 关系给出（见图 3.6）。

该分解过程可应用于任何没有边界的 2D 有向拟流形。图 3.4 中描绘了平面的一个细分，图 3.7 中描绘了细分环面。

与 1D 情况类似，可以同时表示多个 2D 有向拟流形。每个拟流形由一个不同的连通分支描述，整个 2-图描述所有考虑的对象。两个 darts d₁ 和 d₂ 属于同一连通分支，如果 d₁ 和 d₂ 之间存在由 β₁ 或 β₂ 两两链接的 darts 路径。对于任意 dart d，⟨β₁, β₂⟩(d) 表示包含 d 的连通分支：从 d 出发，通过尽可能多次地应用 β₁ 和 β₂ 即可检索其连通分支的所有 darts。
