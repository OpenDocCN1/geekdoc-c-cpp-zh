Other operations have been defined on 2D topological map: we can cite for example a robust region filling algorithm [65], a deformable partition method preserving the topology of the whole partition [74], a topological criterion allowing to control the evolution of the Betti numbers during the segmentation [100] or a method to approximate the digital polygonal curves of an image [69]. Indeed, the main advantage of topological map is to fully describe the topology of the image partition, while allowing easily to add geometric and colorimetric information. Moreover efficient operations can be defined for modifying the partition. For these reasons, they are a very good basic tool for efficient image processing methods.
