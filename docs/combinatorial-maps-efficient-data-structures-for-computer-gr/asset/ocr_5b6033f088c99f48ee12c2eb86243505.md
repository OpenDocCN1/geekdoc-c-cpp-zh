# 6.5 Expansion

The expansion operation is the inverse of the contraction operation. It consists in adding a new i-cell inside an existing given (i − 1)-cell, possibly cutting this (i − 1)-cell in two. As before, the expansion operation is defined here only for n-Gmaps; the conversion for n-maps can be done without particular difficulty.

Figure 6.38 summarizes the links between the four operations: removal, contraction, insertion and expansion.

The expansibility condition and the expansion operation, defined in Defs. 70 and 71, are directly deduced from the insertability condition and the insertion operation, by duality (i.e. i + 1 is replaced by i − 1).

# Definition 70 (expansible cell)

Let G = (D, α₀, …, αₙ) and C = (D′, α₀′, …, αₙ′) be two n-Gmaps, i ∈ {0, …, n}, and γ be a bijection from BV′ ⊆ D′ to BV ⊆ D. C is i-expansible into G according to γ if:

+   - C contains exactly one contractible i-cell;
+   - ∀d′ ∈ BV′, d′ is i-free;
+   - ∀j ∈ {0, …, n} s.t. |i − j| ≥ 2:
+     - ∀d ∈ BV s.t. αⱼ(d) ∈ BV, γ⁻¹ ∘ αⱼ(d) = αⱼ′ ∘ γ⁻¹(d);
+     - ∀d′ ∈ BV′ s.t. αⱼ′(d′) ∈ BV′, γ ∘ αⱼ′(d′) = αⱼ ∘ γ(d′);
+   - ∀d ∈ BV, αᵢ(d) = γ ∘ (α′ᵢ₋₁ ∘ α′ᵢ)ᵏ ∘ α′ᵢ₋₁ ∘ γ⁻¹(d), k being the smaller positive integer s.t. (α′ᵢ₋₁ ∘ α′ᵢ)ᵏ ∘ α′ᵢ₋₁ ∘ γ⁻¹(d) ∈ BV′.
