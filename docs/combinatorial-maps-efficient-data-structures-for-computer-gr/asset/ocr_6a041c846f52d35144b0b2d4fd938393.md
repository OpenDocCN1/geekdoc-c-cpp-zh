The last operation presented in this chapter is the *triangulation*. This operation consists in splitting a given $i$-cell by inserting a vertex inside it.

As illustrated in Fig. 6.50, the 1-triangulation operation consists in adding a vertex inside an edge. For each dart $d$ of the edge, a new dart $d^0$ is created: $\alpha'_0(d)=d^0$, $\alpha'_1(d^0)=(\alpha_0(d))^0$, and $\alpha'_2(d^0)=(\alpha_2(d))^0$ (and reciprocally). Other $\alpha$ links are not modified.
