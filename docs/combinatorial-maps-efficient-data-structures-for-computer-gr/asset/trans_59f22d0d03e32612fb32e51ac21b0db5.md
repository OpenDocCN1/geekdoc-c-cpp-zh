## 5.4 数据结构、迭代器和算法

在本节中，数据结构和算法被定义以便在计算机软件中处理 n-图。我们选择使用算法语言以便于在不同的编程语言中编码。为了简化记号，我们在算法中不区分指向一个元素的指针和元素本身。

这里的目标是描述一种编码 darts 和关系的方案。我们选择基于指针结构的解决方案，但很容易修改算法以处理其他可能性。注意，这里仅描述了数据结构的组合部分。你可以在第 7 章看到两个示例，展示如何表示几何部分。这里介绍的解决方案例如在 CGAL [61] 的组合图包中使用。

### 5.4.1 数据结构

n-图的定义的基本元素是 dart。因此主要的数据结构是表示 darts 的那个。在维度 n 中，一个 dart 结构包含一个 Betas 数组，其中有 n + 1 个指针用于表示不同的 βi 链接。我们选择在这里显式编码 β0 关系以提高效率。事实上，在算法中，通常需要检索给定 dart 的同一面中的两个邻居 darts。如果编码了 β0，此操作以恒定时间执行，而否则需要遍历面 [或更糟，如果所考虑的面具有 1-边界，则需要遍历 n-图的所有 darts]。

# 列表 5.1

n-图的 Dart 数据结构

```
structure Dart
{
    pointer to Dart Betas[n+1];
    Boolean Marks[NB_MARKS];
};
```

除了 n + 1 个指针之外，dart 结构还包含一个 Boolean 数组 Marks，用于标记 darts。这些标记在多个算法中用于以恒定时间测试一个 dart 是否已被处理。它们也可以用于标记具有特定属性的 n-图的一部分。标记的数量由一个常数 NB_MARKS 定义，可以由用户根据其需求固定。一般来说，8 个对于通常的应用已经足够。在算法中，标记满足一个重要不变量：对于未使用的标记，所有 darts 始终未被标记。这一不变量使我们能够避免在算法中初始化标记，并且通常比取消所有 darts 的标记更有效的做法是仅在每个算法结束时取消已标记的 darts 的标记。

nMap 结构主要由一组 darts Darts 和一组整数 FreeMarks 组成，用于管理 Boolean 标记。注意 nMap 的维度 n 可以是全局常量、模板参数或创建 n-图的函数的参数。null_dart 是一个特定的 dart，用于描述空闲 darts。如 n-图的定义所述，dart d 是 i-自由的当且仅当 βi(d) = ∅。这里使用一个 dart 代替 ∅ 的特定值 [例如 NULL] 使我们能够在算法中使用 null_dart 作为哨兵 [参见例如算法 29]。注意，这个特定 dart 不属于 n-图的 darts 集合。

# 列表 5.2

nMap 数据结构

```
structure nMap
{
  set of Dart Darts;
  set of integer FreeMarks;
  Dart null_dart;
};
```

nMap 具有一组空闲标记，即未使用的标记。创建新的 nMap 时，我们在空闲标记集合中添加 0 到 NB_MARKS − 1 之间的所有整数，这对应于所有可用的标记 [参见算法 22]。此外我们初始化特殊 dart null_dart 使其对所有 βi 都链接到自身。这将使我们能够在不事先测试空闲 darts 的特殊情况的情况下组合多个 β 链接。最后 null_dart 的所有标记都初始化为 false。

# 算法 22：createNMap(n)：创建一个新的 n-图

输入：n：n-图的维度。

输出：一个空的新 n-图。

```
1 cm ← a new nMap;
2 cm.Darts ← ∅;
3 cm.FreeMarks ← ∅;
4 for i ← 0 to n do
5   cm.null_dart.Betas[i] ← cm.null_dart;
6 for i ← 0 to NB_MARKS − 1 do
7   add i in cm.FreeMarks;
8   cm.null_dart.Marks[i] ← false;
9 return cm;
```

当算法需要一个标记时，我们只需从该集合中获取一个索引并将其从集合中移除 [参见算法 23]。如上所述，标记满足不变量：cm 的所有 darts 对于这个新标记都是未标记的。我们可以在算法中使用这个标记，并在结束时取消所有已标记 darts 的标记并通过将它添加到空闲标记集合中来释放标记 [参见算法 24]。在释放标记之前，必须确保 cm 的所有 darts 对于该标记都是未标记的。此测试未在算法 24 中执行，因为它代价高昂，但可以为调试目的添加。

# 算法 23：reserveMarkNMap(cm)：为 n-图保留一个新标记

输入：cm：一个 n-图。
输出：一个新保留标记的索引；
如果没有更多可用标记则为 -1。

```
1 if cm.FreeMarks is empty then return -1;
2 i ← an element of cm.FreeMarks;
3 remove i from cm.FreeMarks;
4 return i;
```

# 算法 24：freeMarkNMap(cm,i)：为 n-图释放一个保留标记

输入：cm：其所有 darts 对于标记 i 都是未标记的 n-图；
i：保留标记的索引。
结果：释放保留标记 i。

```
1 add i into cm.FreeMarks;
```

我们可以通过测试它是否属于 FreeMarks 来测试一个标记是否空闲或已保留。此外，给定一个保留标记 i，我们可以通过直接查看 d.Marks[i] 来测试一个 dart d 是否被标记 [参见算法 25]，并且我们可以通过将 d.Marks[i] 设置为 true/false 来标记/取消标记这个 dart [参见算法 26 和 27]。

# 算法 25：isMarkedNMap(d,i)：测试 n-图中的一个 dart 是否被标记

输入：d：一个 dart；
i：保留标记的索引。
输出：当且仅当 d 对于标记 i 被标记时为 True。

```
1 return d.Marks[i];
```

最后，算法 28 描述了给出给定索引 i 时返回 βi 的逆置换的索引 inv(i) 的函数。

所有这些算法的复杂度为恒定时间，因为只应用原子操作，并且没有循环，除了算法 22；但在这种情况下 n 和 NB_MARKS 是常数值。一个栈被用来存储空闲标记的集合，允许以恒定时间访问新的空闲标记以及以恒定时间插入和移除元素。

注意，可以在 nMap 数据结构中添加一个 Boolean 掩码数组，该数组为每个标记定义

```
**Algorithm 26:** `markNMap(d,i)`: mark a dart for *n*-maps

**Input:** d: a dart;  
        i: the index of a reserved mark.  
**Result:** Mark dart d for mark i.  
`1 d.Marks[i] ← true;`
```

```
**Algorithm 27:** `unmarkNMap(d,i)`: unmark a dart for *n*-maps

**Input:** d: a dart;  
        i: the index of a reserved mark.  
**Result:** Unmark dart d for mark i.  
`1 d.Marks[i] ← false;`
```

对应于标记/未标记的值。借助这些掩码，我们能够以恒定时间反转 n-图所有 darts 的标记值。这在我们知道它们全部被标记时非常有效地取消 n-图所有 darts 的标记。

### 5.4.2 迭代器

正如我们之前看到的，单元是通过轨道概念定义的。因此能够遍历属于 n-图给定轨道的 darts 是很重要的。幸运的是，这可以通过算法 29 轻松实现。该算法是通用的，因为它允许遍历任何轨道 ⟨βᵢ₁, ..., βᵢₖ⟩(d)，适用于任何有效序列 (i₁, ..., iₖ) 和任何 dart d。我们说序列 (i₁, ..., iₖ) 是有效的如果：

- ∀j ∈ {1, ..., k}: iⱼ ∈ {0, ..., n};
- ∀j,l ∈ {1, ..., k}: j ≠ l ⇒ iⱼ ≠ iₗ;
- 0 ∈ (i₁, ..., iₖ) ⇔ 1 ∈ (i₁, ..., iₖ)。

使用整数的 *序列*，因为整数的顺序可以在算法中被考虑 [参见例如第 172 页的算法 43]。

**Algorithm 28:** `inv(i)`: return the inverse index of i for *n*-maps

**Input:** i ∈ {0, ..., n}.  
**Output:** The inverse index of i.  
`1 if i = 0 then return 1;`
