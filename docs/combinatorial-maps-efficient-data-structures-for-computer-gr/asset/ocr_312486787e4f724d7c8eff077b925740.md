+   - i = n − 1;
+   - or 0 ≤ i < n − 1, and, ∀d ∈ C, α_{i+1} ∘ α_{i+2}(d) = α_{i+2} ∘ α_{i+1}(d).

Note that an (n − 1)-cell is always removable in an n-Gmap. This is a consequence of the quasi-manifold definition: in nD, at most two n-cells are incident to a given (n − 1)-cell. When 0 ≤ i < n − 1, the condition “∀d ∈ C, α_{i+1} ∘ α_{i+2}(d) = α_{i+2} ∘ α_{i+1}(d)” ensures that at most two (i + 1)-cells C1, incident to a given dart d of C, and C2, incident to α_{i+1}(d), are incident to C (possibly with C1 = C2).

The i-removal operation is defined in Def. 59. It can be applied to a removable i-cell C; as explained above, removing C invalidates α_i for the darts linked with C. Let D^S denote this set of darts. The resulting n-Gmap is obtained by removing all the darts of C, and by redefining α_i for the darts of D^S. For each dart d ∈ D^S, the path of darts (α_i ∘ α_{i+1})^k ∘ α_i(d) is followed until obtaining a dart belonging to D^S. All others α_j, j ≠ i, are not modified, nor α_i for the darts which do not belong to D^S.

# Definition 59 (cell removal) Let G = (D, α0, …, αn) be an n-Gmap and C be a removable i-cell. Let D^S = α_i(C) \ C be the set of darts i-linked with C which do not belong to C. The n-Gmap resulting from the i-removal of C in G is G_{R_i}(C) = (D′, α′0, …, α′n), defined by:

+   - D′ = D \ C;
+   - ∀j ∈ {0, …, n}, j ≠ i, α′j = αj|D′;
+   - ∀d ∈ D′ \ D^S, α′i(d) = αi(d);
+   - ∀d ∈ D^S, α′i(d) = (αi ∘ α_{i+1})^k ∘ αi(d), k being the smaller positive integer s.t. (αi ∘ α_{i+1})^k ∘ αi(d) ∈ D^S.

The path of darts followed for modifying αi corresponds to (αi ∘ α_{i+1})^k ∘ αi, k being the smaller positive integer such that a dart which belongs to D^S is reached. For the four previous examples, k is always equal to 1. But k can be greater than 1, for instance for configurations in which multi-incidence occurs, as illustrated in Fig. 6.16. In the initial 2-Gmap in Fig. 6.16(a), an edge is a loop. When this edge is removed, the path of darts associated with dart 5 (resp. 12) is (4 = α1(5), 2 = α1 ∘ α2 ∘ α1(5), 12 = (α1 ∘ α2)^2 ∘ α1(5)) (resp. (3, 1, 5)).

As illustrated in Fig. 6.17, other configurations can lead to k > 1, for instance when the n-Gmap has boundaries. In this example, the initial 2-Gmap in Fig. 6.17(a) has one 1-boundary; edge {1, 2, 9, 10} is incident to this boundary. For its removal, the path associated with 8 is (1 = α1(8), 9 = α1 ∘ α2 ∘ α1(8), 8 = (α1 ∘ α2)^2 ∘ α1(8)). Thus, after applying the 1-removal, edge {7, 8} is incident to the boundary.
