Algorithm 60: isInsertableNGMap(gm, c, i, assoc): test if an i-cell is insertable for n-Gmaps

**Input:** gm, c: two *n*-Gmaps;

              i ∈ {0, ..., n};

              assoc: a mapping from c.Darts to gm.Darts.

**Output:** True iff c can be inserted in gm according to assoc.

```text
1  if c contains more than one i-cell then return false;
2  if the i-cell in c is not removable then return false;
3  assoc⁻¹ ← an associative array between darts, inverse of assoc;
4  foreach dart d ∈ assoc do
5      if not isFreeNGMap(d, i) then return false;
6      d′ ← assoc[d];
7      foreach j ∈ {0, ..., i − 2, i + 2, ..., n} do
8          if d.Alphas[j] ∈ assoc and
9              assoc[d.Alphas[j]] ≠ assoc[d].Alphas[j] then
10             return false;
11         if d′.Alphas[j] ∈ assoc⁻¹ and
                assoc⁻¹[d′.Alphas[j]] ≠ assoc⁻¹[d′].Alphas[j] then
                return false;
12     d₂ ← d.Alphas[i + 1];
13     while d₂ ≠ assoc do
14         d₂.Alphas[i].Alphas[i + 1];
15     if assoc[d₂] ≠ d′.Alphas[i] then return false;
16 return true;
