$$a / b + c / d = (ad + bc) / bd$$

$$a / b - c / d = (ad - bc) / bd$$

$$a / b \times c / d = ac / bd$$

$$(a / b) / (c / d) = ad / bc,$$ 其中 $c / d \ne 0$。

\(A + B = [a_{ij} + b_{ij}]\)

\(A - B = [a_{ij} - b_{ij}]\)

仅当 A 的列数与 B 的行数相同时，才定义 A 与 B 的乘法（\(A * B\)）。如果 A 的大小为 \(m \times n\)，B 的大小为 \(n \times t\)，则 \(A * B = [c_{ik}]\) 的大小为 \(m \times t\)，且元素 \(c_{ik}\) 由以下公式给出：

\(c_{ik} = a_{i1}b_{1k} + a_{i2}b_{2k} + \cdots + a_{in}b_{nk}\)
