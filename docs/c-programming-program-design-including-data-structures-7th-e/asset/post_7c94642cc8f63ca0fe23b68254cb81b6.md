## PROGRAMMING EXAMPLE: DVD Store (Revisited)

In Chapter 16, we designed a program to help a DVD store automate its DVD rental process. That program used an (unordered) linked list to keep track of the DVD inventory in the store. Because the search algorithm in a linked list is sequential and the list is fairly large, the search could be time consuming. In this chapter, you learned how to organize data into a binary tree. If the binary tree is nicely constructed (that is, it is not linear), then the search algorithm can be improved considerably. Moreover, in general, item insertion and deletion in a binary search tree are faster than in a linked list. We will, therefore, redesign the DVD store program so that the DVD inventory can be maintained in a binary tree. As in Chapter 16, we leave the design of the customer list in a binary tree as exercises for you.
