# 762 Making an ASMX Service

# Deploying

Deploying an XML web service is just like deploying a web application.
They're effectively the same thing.

One benefit of ASMX over WCF is the simple configuration. In fact, if you check out the configuration file for the application you built, you'll see that the only configuration information revolves around the Entity Model.
Adding ASMX to a web project is easy.

Important thing that you need to know: After you deploy, the sample test doesn't run anymore. You'll still get the information service page, but if you try to run the test script, you'll get the message in Figure 2-5. This is just for safety and can be overridden, though I don't advise it in a production environment.
