
The third pass finds the \n character and squeezes that out. On the fourth pass, IndexOfAny() runs out of white space characters to find and returns -1 (not found). That ends the loop.

The RemoveWhiteSpace program prints out a string containing several forms of white space. The program then strips out white space characters. The output from this program appears as follows:

```
before: this is a
string
after:thisisastring
Press Enter to terminate...
```

## Let's Split() that concatenate program

The RemoveWhiteSpace program demonstrates the use of the Concat() and IndexOf() methods; however, it doesn't use the most efficient approach. As usual, a little examination reveals a more efficient approach using our old friend Split(). You can find the program containing this code — now in another example of a method — on the website under RemoveWhiteSpaceWithSplit. The method that does the work is shown here:

![](img/6df7bb88e9302e98442acc219cfbd7fc_89_0.png)

```csharp
// RemoveWhiteSpace -- The RemoveSpecialChars method removes every
// occurrence of the specified characters from the string.
// Note: The rest of the program is not shown here.
public static string RemoveSpecialChars(string input, char[] targets)
{
    // Split the input string up using the target
    // characters as the delimiters.
    string[] subStrings = input.Split(targets);

    // output will contain the eventual output information.
    string output = "";

    // Loop through the substrings originating from the split.
    foreach(string subString in subStrings)
    {
        output = String.Concat(output, subString);
    }
    return output;
}
```

This version uses Split() method to break input string into a set of substrings, using characters as delimiters. The delimiter is not included in the substrings created, which has the effect of removing them. The logic here is much simpler and less-prone. The foreach loop in the second half puts the pieces back together using Concat(). The output from the program is unchanged. Pulling the code out into method further makes it clearer.

## Formatting Your Strings

The String class also provides the Format() method for formatting output, especially numbers. In its simplest form, Format() allows insertion of string, numeric, or Boolean input in the middle of format string. For example, consider this call:

```csharp
string myString = String.Format("{0} times {1} equals {2}", 2, 5);
```

The first argument to Format() is known as the format string. The {n} items in the middle of format string indicate that the nth argument following format string is inserted at that point. {0} refers to the first argument (in this case, 2), {1} refers to the next (that is, 5), and so on. This returns a string. The resulting string is

```
"2 times 5 equals 10"
```

Unless directed, Format() uses default output for each argument type. Format() enables you to affect output format by including specifiers controls in placeholders. See Table 3-1 for listing of these specifiers. For example, {0:E6} says, “Output the number in exponential form, using six spaces for the fractional part.”

| :--- | :--- | :--- |
| Control | Example | Result | Notes |
| C — currency | {0:C} of 123.456 | $123.46 | The currency sign depends on Region setting. |
| | {0:C} of -123.45 | ($123.45) | Specify Region control. |
| D — decimal | {0:D5} of 123 | 00123 | Integers only. |
| E — exponential | {0:E} of 123.45 | 1.2345E+02 | Also known as scientific notation. |
| F — fixed | {0:F2} of 123.4567 | 123.46 | The number after F indicates the number of digits after the decimal point. |
| N — number | {0:N} of 123456.789 | 123,456.79 | Adds commas and rounds off to nearest 100th. |

The Console.WriteLine() method uses the same placeholder system. The first placeholder, {0}, takes the first variable or value listed after the format string part of the statement, and so on. Given the exact same arguments as in the earlier Format() call, Console.WriteLine() would write the same string to the console. You also have access to the format specifiers. From now on, I use the formatted form of WriteLine much of the time, rather than concatenate items to form the final string with the + operator.

These format specifiers can seem a bit bewildering. (I didn't even mention the currency and date controls.) Explore the topic “format specifiers” in the Help Index for more information. To help you wade through these options, the following OutputFormatControls program enables you to enter a floating-point number followed by a specifier. The program then displays the number, using the specified:

```csharp
// OutputFormatControls -- Allow the user to reformat input numbers
// using a variety of specifiers input at time.
namespace OutputFormatControls
{
    using System;
    public class Program
    {
        public static void Main(string[] args)
        {
            // Keep looping -- inputting numbers until the user
            // enters a blank line rather than a number.
            for(;;)
            {
                // First input a number -- terminate when the user
                // inputs nothing but a blank line.
                Console.WriteLine("Enter a double number");
                string numberInput = Console.ReadLine();
                if (numberInput.Length == 0)
                {
                    break;
                }
                double number = Double.Parse(numberInput);
                // Now input the specifier codes; split them
                // using spaces as dividers.
                Console.WriteLine("Enter the format specifiers"
                    + " separated by a blank "
                    + "(Example: C E F1 NO 000000.00000)");
                char[] separator = { ' ' };
                string formatString = Console.ReadLine();
                string[] formats = formatString.Split(separator);
                // Loop through the list of format specifiers.
                foreach(string s in formats)
                {
                    if (s.Length != 0)
                    {
                        // Create a complete format specifier
                        // from the letters entered earlier.
                        string formatCommand = "{0:" + s + "}";
                        // Output the number entered using the
                        // reconstructed format specifier.
                        Console.Write(
                            "The format specifier {0} results in ", formatCommand);
                        try
                        {
                            Console.WriteLine(formatCommand, number);
                        }
                        catch(Exception)
                        {
                            Console.WriteLine("<illegal control>");
                        }
                        Console.WriteLine();
                    }
                }
            }
        }
    }
}
```
