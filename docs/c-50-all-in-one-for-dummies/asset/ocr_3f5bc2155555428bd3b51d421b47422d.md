Much that you most likely have discovered about C# can be run using a command prompt and cs.exe. Fact is, that's a less-than-wonderful way to program. It's unforgiving and slow, and it's hard to remember the specifics of the language. An Integrated Development Environment (IDE) is a program that provides a platform for development. Programmers who used to starting with a blank screen and a command often miss an IDE as slow, boggedged-down waste of time. However, I have never failed to see any of the others change their time after working in Visual Studio. It's quick, easy to use, and smart.

It's true that you don't have to use an IDE to program, but if you're going to use one, it should be Visual Studio. It was purposely built to write C# code, and it's hard to construct Windows programs. (Sales pitch over — Microsoft, I'll take your 20 bucks now)

There are other options, however. MonoDevelop is a tool built for Linux users to write .NET code, which works in Windows. SharpDevelop is another IDE that has some awesome potential as a testing platform. These tools are both free.

Seriously, ever since I did to write Effective Visual Studio .NET, I have been a fan of Visual Studio. It truly makes writing software easier. It doesn't replacing knowing the language or understanding object-oriented programming or the .NET Framework, but it makes life a little smoother.

This chapter introduces you to the various versions of Visual Studio and discusses the C# projects available to you.
