## Setting Options

Choose the Options menu item to open the Options dialog box, which looks a whole like Figure 3-1. It is generally designed to set Boolean type options like Show This or Provide or change paths to resources where Visual Studio will store files.

## Environment

The Environment section is where you begin in the Options dialog box. Sections here include the font details of code-editing screens, key mappings, and the RSS feed settings for the Start page.

The Font and Colors settings will probably be interest only when you need them for a presentation. Sixteen points is the size of choice for most readers, including myself. There are a number of "code friendly" fonts out there, and this is where you select them.

## Defining the Start Page

The Start Page is the first page you see when you start Visual Studio. It consumes an RSS feed from Microsoft news related to the kind of development you, as a Visual Studio when you first installed the software. Often, people change rules, and the RSS feed no longer applies to their work. This is a problem.

The solution is the Start Page News Channel field. You can pick any RSS feed you are interested in using for your Start Page content. If you like Microsoft Developer content, you can choose Scott Hansen's for your Start Page. If you are interested in security, you can use Exotic Liability's blog. If you like stillness, you can use the feed at www.semf.net. Alternatively, you can set it to nothing. You're in charge.

## Keyboard commands

The most useful settings in the Options box are the Keyboard settings. This is where you make Visual Studio feel like Emacs (a popular code editor) through the use of keyboard mappings.

Keyboard mappings are combinations you set to run commands from keyboard by clicking your mouse. For example, one commonly used mapping is Ctrl-C, which copies material in the same way that clicking the Edit menu and then clicking Copy does. Many developers using keyboard mapped commands make the development faster and easier.

The keyboard settings essentially enable you to set keyboard commands for any menu selection in Visual Studio. Apply the Following Additional Keyboard Mapping Scheme drop-down enables the keys mappings to be different, if you happen to use the mappings of other development environments.

## Language

By language, I don't know the Internationalization setting that enables you to change the display language of Visual Studio if you have additional language packs installed (although that is neat). I am talking about the programming languages you work with in Visual Studio. The Languages options section is where you can provide settings for each of these programming languages.

The Text Editor options change how the Code Editor behaves. All the languages Visual Studio supports out of the box appear in the tree view under the main heading and you to alter general options, tapping, formatting, sometimes advanced options, and miscellaneous features of the text editor.

For instance, look at C#. To open the C# view, click where it says C# with the little triangle in the Options tree view (that's a WPF tree view — you'll get used to it). The first view in the Options panel is the General. Here you can change the default options for statement completion, various behavior settings, and what the Code Editor should display aside from the code.

The other panels you can use:

- * Tabs: This section is for people who are obsessive about the tabbing of their source code. The Tabs panel determines how many spaces make a tab, and Visual Studio should insert them automatically.
- * Advanced: This section should probably be called Miscellaneous. Everything that doesn't fit into other categories is here. In this section, handling comments, interface implementation, and refactoring details all have a check box that basically says, "If you don't like it when Visual Studio does this, click here."
- *Formatting: Formatting in C# is in-depth. Generally, C# coders are a little picky about the look of their code. Visual Studio does a lot of work to help make your code the way you want it, but you have to tell it what to do. Options for formatting include:
    - Automatic formatting
    - Indentation
    - Newlines
    - Spacing
    - Wrapping
- *IntelliSense: The most interesting field is the list of characters that "commit" an IntelliSense. By typing one of these characters, you select the highlighted member.

## Neat stuff

Here's a short list of used features that you will know when you need.

- To implement a new source control provider, first install the package (for instance, Team) and then go to Source Control in Options to pick the one you use.
- Many people recommend that you store your projects in a short path, like C:\Projects. You can change where you store projects in the Projects and Solutions section in the dialog box.
- Set up automatic Windows Forms data binding in the Designer for custom controls (that you have bought or built) in the Windows Forms Designer / Data Customization section of the Options box.
- If you are one of those crazy people who think table names should not be pluralized, you can turn off that behavior in the Data Designer in the Database Tools / OR Designer section of the Options box.
- You can teach Visual Studio to open a file with a given editor using the Text Editor / File Extension section of the Options panel.

## Using snippets

Snippets are little bits of precoded logic that are meant to help you remember how to perform some standard code functions in various languages. In VB, for instance, you might not remember to read from a file, so there is a snippet for that. In C#, you may want to implement a property getter and setter, so you use a shortcut to get the snippet in place.

## Using snippets

You can use a snippet in a few different ways, most of which are somewhat slow. The fastest way is through the use of key commands. To use a snippet this way, type its shortcut code and press Tab twice. For instance, try these steps:

2. In the new class that is created, place the cursor inside the curly braces.
3. Type prop.
4. Press Tab twice.
