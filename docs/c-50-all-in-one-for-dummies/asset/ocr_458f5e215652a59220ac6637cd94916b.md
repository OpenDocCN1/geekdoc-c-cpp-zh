+   * Radio buttons allow for a single selection within a range of choices. The choices are determined by the GroupName property. After one of the radio buttons is selected, the group can only be entered unselectmatically.

```
<StackPanel Orientation="Horizontal">
<RadioButton GroupName="RSample"
IsChecked="true"
Content="Red" Margin="15,15" />
<RadioButton GroupName="RSample"
Content="White" Margin="15,15" />
<RadioButton GroupName="RSample"
Content="Blue" Margin="15,15" />
</StackPanel>
```

+   * Slider: The slider is a ranged input. Similar to the ProgressBar, the control takes Minimum, Maximum, and Interval values. You can specify to show Ticks, the Location, and the Frequency. Tick defines the lines that show on slider.

```
<Slider Interval="1" Margin="1" Maximum="10" IsSnapToTickEnabled="True"
TickPlacement="Right" TickFrequency="1" />
```

+   * DatePicker: New in Visual Studio 2012, the DatePicker control provides a method for getting (or displaying) date by combining a TextBox with a Calendar control. Included in the many options is the capability to select multiple dates for a range of dates.

```
<DatePicker />
```

+   * Calendar: Also new in Visual Studio 2012 is the Calendar Control. The difference between the Calendar and the DatePicker is always in full display mode whereas the DatePicker's default look is similar to a text box.

```
<Calendar />
```
