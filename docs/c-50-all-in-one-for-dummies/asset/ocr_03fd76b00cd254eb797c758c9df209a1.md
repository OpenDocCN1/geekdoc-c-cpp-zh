# Using other kinds of input controls

ASP.NET provides a number of other input types that are combinations of the above, or nontraditional inputs (see Figure 3-5). They are all special-controls, which are not needed in your toolbox so you can use them when the needs arises.

They include the following input types:

+   * FileUpload: The FileUpload does exactly what it says. It creates an HTML input of type File and makes the form encetype (encoding type) into multipart form-data. This allows the web server to accept a long stream of binary data, which you can then parse with a streamreader.
* Imagemaps: Imagemaps are nearly relics of a bygone era. Essentially, they allow you to mark off by pixel maps on top of images and assign regions within those maps to URLs or other actions. This control assists you by using the framework. You still have to provide the map. Now, usually people separate images.
* Calendars: The calendar control is just a textbox that helps the user format dates properly. It works well. There are a ton of formatting options, — check them out in the panel.
