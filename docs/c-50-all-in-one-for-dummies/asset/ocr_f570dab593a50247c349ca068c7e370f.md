The program begins with a definition of the Vehicle class.

The definition of a class can appear either before or after the class — it doesn't matter. However, you should, unlike me, adopt a style and stick with it. Book IV, which talks about Visual Studio, shows the more conventional technique of creating a separate .cs file to contain each class, but just put the extra class in your Program.cs file for now.
