# Copying websites with “Copy Web”

If you have a website project, you have a Visual Studio–driven option for the xcopy option. Because these sites don't compile all the .aspx files along, this tool fits the bill.

To run it, look for the Copy Web icon in Solution Explorer (or find the Copy Site command on the Website menu). I highlighted the icon with a red box in Figure 5-8. It launches the Copy Web design surface, which looks like the Windows Explorer browsers in Figure 5-6, except it comes with neat buttons.
