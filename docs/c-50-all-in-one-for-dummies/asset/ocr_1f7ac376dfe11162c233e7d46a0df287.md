# 496 Working without Primary Interop Assemblies

7. Change the Main procedure to the following (just enough to get Excel rolling):

```
static void Main(string[] args)
{
    Microsoft.Office.Interop.Excel.Application xl = new Application();
    xl.Quit();
}
```

8. Right-click on the Solution and add New Project.

9. Add a new Setup project.

10. Right-click the setup project and add Project.

11. Select Primary Output.

12. Click OK.

The setup project will automatically determine what to deploy with the application. In Visual Studio 2012, with C# 3.0, it will deploy the Interop assemblies, as shown in Figure 7-1.
