```
for (int loopcounter = 1; loopcounter <= 10; loopcounter++)

```
try{

the exception is highlighted in green; I can tap to and add the exception

# Making snippets

Snippets are XML files that follow a format understood by Visual Studio.
They include a Header and Snippet element. The Header includes a title,
which is how the snippet is referred to. The Snippet, where all the
work is done, includes a Code element, which has to be inserted.

The best way to make a new snippet is to modify an existing one. Snippets
be found in your Visual Studio install directory, which could be in C:\nProgram Files (x86)\Microsoft Visual Studio 11.0\VC#:\nSnippets\1033 if you are on a 64-bit operating system (otherwise you might)
drop the (x86).
