# # SQL Injection attacks

A SQL Injection attack happens when a hacker enters a line of SQL code into an input field to query a database in a form on a Web page (such as the username and password text boxes in a login form). Malicious SQL code causes the database to act in an unexpected way or allow the hacker to gain access to, alter, or damage the database.

The best way to understand how a hacker uses a SQL Injection is to see an example. For instance, a web page has accepts a Product ID from the user in a text box and returns product details based on the Product ID the user entered. The code on the server looks like this:

```
// GetProductID from user
string productId = TextBox1.Text;
// Get information from the database
string selectString = 'SELECT * Items WHERE ProductID = ' + productId + '*
SqlCommand cmd = new SqlCommand(selectString, conn);
conn.Open();
SqlDataReader myReader = cmd.ExecuteReader();
//Process results
myReader.Close();
conn.Close();
```

Normally, a user enters the appropriate information into the text box. By a cracker attempting a SQL Injection attack would enter the following string into TextBox1:

```
"FOOBAR\';DELETE FROM Items;--"
```

The SQL code that would be run by your code would look like this:

```
SELECT * Items WHERE ProductID = 'FOOBAR';DELETE FROM Items;--
```

The SQL Server executes some code you didn't expect; in this case, the code deleted everything in the items table.
