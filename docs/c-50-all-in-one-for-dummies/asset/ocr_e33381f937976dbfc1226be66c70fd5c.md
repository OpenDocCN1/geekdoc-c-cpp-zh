# Breaking Down the Projects

All is left to do after you have run the setup program and set your defaults is start on a project and get your dirty. All the project types (except one or two) in the first two minibooks were Console applications, meaning they are meant to be run at the command prompt. There are a lot more projects available.

Notice four main kinds of projects in the Visual Studio New Project dialog box.

+   **Windows Store projects** are full-screen packaged apps that go in the Windows Store for Windows 8 users. (usually) packaged for distribution, but rather deployed to the store for distribution there.

+   **Windows projects** are rich client applications that compile into .EXES and run on your computer. Microsoft Word is a Windows application.

+   **Web projects** make websites and require a web server to run. (A web server is included with Visual Studio for development purposes.) Microsoft.com is an example of a web application.

+   **Special projects** includes things like setup projects (projects that build setup programs) and database projects (projects that give a framework for databases). They are usually used with a Windows or web application. The Setup.exe program you run in the the preceding section to install Visual Studio is an example of one of these special projects — a setup project.
