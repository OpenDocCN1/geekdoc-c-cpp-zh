# Defining the Start Page

The Start Page is the first page you see when you start Visual Studio. It consumes an RSS feed from Microsoft news related to the kind of development you, as you Visual Studio when you first installed the software. Often, people change rules, and the RSS feed no longer applies to their work. This is a problem.

The solution is the Start Page News Channel field. You can pick any RSS feed you are interested in using for your Start Page content. If you like Microsoft Developer content, you can choose Scott Hansen's for your Start Page. If you are interested in security, you can use Exotic Liability's blog. If you like stillness, you can use the feed at www.semf.net. Alternatively, you can set it to nothing. You're in charge.

# Keyboard commands

The most useful settings in the Options box are the Keyboard settings. This is where you make Visual Studio feel like Emacs (a popular code editor) through the use of keyboard mappings.

Keyboard mappings are combinations you set to run commands from keyboard by clicking your mouse. For example, one commonly used mapping is Ctrl-C, which copies material in the same way that clicking the Edit menu and then clicking Copy does. Many developers using keyboard mapped commands make the development faster and easier.

The keyboard settings essentially enable you to set keyboard commands for any menu selection in Visual Studio. Apply the Following Additional Keyboard Mapping Scheme drop-down enables the keys mappings to be different, if you happen to use the mappings of other development environments.

# Language

By language, I don't know the Internationalization setting that enables you to change the display language of Visual Studio if you have additional language packs installed (although that is neat). I am talking about the programming languages you work with Visual Studio. The Languages options section is where you can provide settings for each of these programming languages.

The Text Editor options change how the Code Editor behaves. All the languages Visual Studio supports out of the box appear in the tree view under the main heading and you to alter general options, tapping, formatting, sometimes advanced options, and miscellaneous features of the text editor.
