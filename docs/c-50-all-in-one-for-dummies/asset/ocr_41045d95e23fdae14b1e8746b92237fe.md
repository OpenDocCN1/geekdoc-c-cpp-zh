# 758 Making ASMX Service

Running the service
Press F5 and run the service. If all goes well, you should see something like
Figure 2-2. This is the default visualization for a service — remember that you didn't make a user interface; IIS did this for you, to make it easier to test.
External users can see this.

Clicking the Service Description gives you the WSDL for the whole service.
This is what a .NET application needs to build its proxy. Note in the
browser's address bar that all it does is append WSDL to the end of the URL.

Clicking the Hello link gives you a service and implementation
guidance for the method. You will have one of these links for every one of
the classes marked with WebMethod.

Recommendation: Change the namespace before using it in client applications to distinguish it from other services on the Web (http://tempuri.org/ is available for XML services that are under development, but published XML services should use a more unique name).
If you want to make your service more easily discoverable, you can use your company's domain name as part of the name.
Many XML services use URIs that do not need to point to actual resources on the Web (XML service name namespace is optional).
For XML services using C, you can specify the namespace using the Namespace attribute. The Namespace attribute is applied to the class that contains the URI. Below is a code example that sets the namespace to "http://microsoft.com/webservices".

For more details on namespaces, see the Recommendation on Namespaces in XML.
For details on URIs, see the WSDL Specification.
For details on URIs, see RFC 2396.

```
[Namespace("http://microsoft.com/webservices")
public class MyService
{
    [WebMethod]
    public string HelloWorld()
    {
    }
}]
```

# Building the code for SHARP

First you need to get set up. Here's what you need to do to start using the
template:

+   1. Add a new Empty Web Application project to the solution by right-
clicking the service and selecting Add New Project. Name the project
SharpASM.

+   2. If you haven't added data, add a data connection to the ConferenceDB.
The database is downloadable from http://csharpforduddummies.net.
