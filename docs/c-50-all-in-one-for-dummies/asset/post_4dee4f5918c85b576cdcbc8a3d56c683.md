The explorer should look like Figure 3-4. The files are organized into folders and should stay that way. The setup process for the development environment reads right from the directories.

The ConsoleApplication is about the simplest project type, and it is a great place to begin creating your own. Open the ConsoleApplication directory and take a look at the files it contains

- assemblyinfo.cs: This file goes directly into the project. Take a look at the code; it is the exact code that is in the assemblyinfo file in a project, except where project-specific variables surrounded by dollar signs. Those are placeholders for the content that will get filled.

- csConsoleApplication.csproj: This is the actual project file; the name will be replaced by the new project-creation process. As with the other included files, there are variable names within the XML of the file.
- csConsoleApplication.template: This is the magic file that tells the project-creation process how to build the new project. The important part is the TemplateContent element, which contains the name of the ProjectFile and the ProjectItems that go into the finished product. This is clearly where you put new files if you needed them.

- program.cs: This is the default file for the application. This is where you begin when you start coding. Take a look at the code — it should look familiar.

So does that leave you? You can change the projects. Try these steps:

1. Copy the ConsoleApplication directory from C:\Program Files\Microsoft Visual Studio 11.0\Common\IDE\ProjectTemplates\CSharp\Windows\1033.
2. Paste the directory back into the folder — it should make ConsoleApplication — Copy.
3. Drag your new class to your desktop temporarily.
4. Open C:\Program Files\Microsoft Visual Studio 10.0\Common\IDE\ProjectTemplates\CSharp\Windows\1033\ClassLibrary.
5. Copy the class1.cs file from folder.
6. Paste it into the new ConsoleAndClass folder on your desktop.

7. Right-click csConsoleApplication.vtemplate and select Edit from the menu to open the file in Notepad.

8. In the file, change each instance of ConsoleApplication to ConsoleApplication.
9. Add the bonded line to the file, in order to reference the new file.

```xml
<?xml version="1.0" encoding="utf-8"?>
<VTemplate Version="3.0" Type="Project" xmlns="http://schemas.microsoft.com/developer/VisualStudio/2005">
<TemplateData>
<Package Name="F40ACEC1-301F-11D3-B4F9-00C479EFFBC" ID="2320" />
<Description Package="F40ACEC1-301F-11D3-B4F9-00C479EFFBC" ID="2321" />
<Icon Package="F40ACEC1-301F-11D3-B4F9-00C479EFFBC" ID="4548" />
<TemplateType>Microsoft.CSharp.ConsoleApplication/</TemplateType>
<RequiredFrameworkVersion>2.0</RequiredFrameworkVersion>
<SortOrder>70</SortOrder>
<NumberOfCategoriesToRollUp>1</NumberOfCategoriesToRollUp>
<NumberParentCategoriesToRollUp>
<CreateFolder="true"/>
<DefaultName="ConsoleApplication"/></DefaultName>
<ProvideDefaultName="true"/></ProvideDefaultName>
</TemplateData>
<TemplateContent>
<Project File="csConsoleApplication.csproj">
<ItemGroup>
<ProjectItem TargetFileName="Properties\AssemblyInfo.cs" ReplaceParameters="true" OpenEditor="true" />
<ProjectItem ReplaceParameters="true" OpenEditor="true">Program.cs</ProjectItem>
<ProjectItem ReplaceParameters="true" OpenEditor="true">Class1.cs</ProjectItem>
</ItemGroup>
</Project>
</TemplateContent>
</VTemplate>
```

10. Save and close ConsoleApplication.vtemplate.
11. Rename consoleapplication.csproj to consoleclass application.csproj.
12. Copy the directory back to the original folder.
13. Close Visual Studio Command Prompt as Administrator.
14. Open the Visual Studio All Programs in the Start Bar, by Visual Studio 2010.
15. Close Visual Studio Command Prompt as Administrator.
