What's cool here is that you can right-click any breakpoint and completely alter the properties of that breakpoint. It try — the important options are described in this list:

+   * Location: Specifies the location of the line of code that should host the breakpoint. This is convenient if you have filters set and you find you to shift a line back.
* Condition: You can teach the breakpoint to stop at this line only if a certain variable is a specific value.
* Hit Count: Stop here only the xth time it is hit.
* Filter: It's similar to Condition, except that you can use values such as MachineName, ProcessName, ProcessId, ThreadName, and ThreadId. It's useful for multiprocessor development, among other things.
* WhenHit: You can do more than just stop on a breakpoint — instead, you can do something like print a value to the Output window, or even run a test script.
