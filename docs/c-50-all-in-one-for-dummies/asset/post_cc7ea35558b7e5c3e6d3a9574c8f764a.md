TreeView: The TreeView is a hierarchical ItemsControl much like Windows Explorer. The nodes (or branches) can be expanded or contracted, giving a nice user interface into any multilevel data. (See Figure 2-21.)

The sample shown in Listing 2-16 (taken from MSDN) uses hard-coded data, but with a simple hierarchical template tree views can be bound just like any other.

Unlike the ComboBox and DataGrid examples, here the following TreeView XAML works without extra code.

<TreeView Name="MyTreeView">

## Exploring Common XAML Controls 599

- DataGrid: Also new in the .NET 4 (along with the DatePicker and Calendar controls) is the DataGrid. (See Figure 2-22.) Consp absent from the earlier versions of WPF, this control was part of the WPF toolkit, an out-of-band release that is a great resource for WPF information.

The DataGrid has five base columns:

- DataGridTextColumn: For Text
- DataGridCheckboxColumn: For Boolean
- DataGridComboBoxColumn: For ListItems
- DataGridHyperlinkColumn: For displaying Links
- DataGridTemplateColumn: For designing custom columns

The DataGrid can be set to AutoGenerate the columns based on the data it is bound to (as in the sample). It uses reflection to determine the best column type based on the data.

The following XAML won't produce the right output without additional code in the code-behind file. The (Binding) element in line 3 needs some code support.

```xml
<DataGrid HorizontalAlignment="Stretch" VerticalAlignment="Stretch"
AutoGenerateColumns="True" ItemsSource="{Binding People}">
</DataGrid>
```
