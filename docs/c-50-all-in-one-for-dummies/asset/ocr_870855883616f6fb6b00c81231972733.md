# Exploring the Binding Modes

You have full control over how the binding relationship you create behaves. Multiple types of binding modes are available to you in WPF. These include:

+   * The OneTime binding mode is used when you use the source property to initially set the target property value. Subsequent changes to the source property are not reflected in the target property. Similarly, changes to the target property are not reflected in the source property.

+   * The OneWay binding mode is typically used for read-only behaviors. In this mode, data from the source property sets the initial value of the target property. Subsequent changes to the source will automatically update the target property value. Conversely, any changes made to the target property value are not reflected in the source property.
