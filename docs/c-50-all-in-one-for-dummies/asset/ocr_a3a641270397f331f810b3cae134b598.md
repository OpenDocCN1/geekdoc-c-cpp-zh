The following lists down some of the most important practices for securing your web applications:

+   * Keep your Internet Information Server (IIS) up to date.
* Back up everything.
* Avoid using a Querystring variable (the values after the page name in a URL).
* Don't leave HTML comments in place. Any user can view the HTML code and see your comments by choosing View:Source.
* Don't depend on client-side validation for security — it can be faked.
* Use strong passwords.
* Don't assume the user you sent comes from your form and is safe. It is easy to fake a form post.
* Make sure that error messages don't give any user information about your application. E-mail show the error messages instead of displaying them to the user.
* Use Secure Sockets Layer.
* Don't store anything useful on your server.
* Close unused ports on your web server.
* Turn off SMTP on IIS unless you need to.
* Run a virus checker if you allow uploads.
* Don't run your application as Administrator.
