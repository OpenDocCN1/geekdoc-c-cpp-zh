# Showing Stuff to the User

Web surfers want to look at stuff. For them to look at it, you have to show it. Most of the controls in the ASP.NET control library are about showing things to the user.

Although there are a lot of controls, only some of them apply to the subject of this book — C#. This doesn't mean you shouldn't use them, but they are more about the HTML and less about the code on the server. So I am just going to cover a few controls. For more, please pick up ASP.NET For Dummies.

# Labels versus plain old text

The basic item on an average web page is text. You find a text box, maybe two, and a handful of images as well. Most of what is there is text.

Text comes in a few flavors in ASP.NET. The two I want to talk about are Label text and, well, text. Label text is text inside a span that you can change with C# code. Then there is just normal text on the page. This text is static — downloaded to the client just as you typed it.

To see what I mean, start a new web project. Just follow these steps:

+   1. Click the New Project button and select ASP.NET Empty Web Application.
I called mine WebControls.
2. Make a new Web Form called Text.aspx.
3. Change to Design view.
There will be a default div that you saw in Chapter 2.
4. Put your cursor inside the blue box labeled div and then type something innovative, like This is new text; then press Enter.
5. On the new line, drag a Label from the Toolbox.

6. Double-click elsewhere on the form to get to the code-behind.
