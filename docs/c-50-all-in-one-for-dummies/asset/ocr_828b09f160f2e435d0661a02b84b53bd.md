# Designing in the Designer

In truth, there is little to say about the Windows Forms designer itself. The individual controls have some nice designer features, but the designer itself doesn't do much.

# Web Forms

Web programming resembles WPF programming more than it resembles Windows Forms programming, but it's run from a web server and viewed in a browser. (Book VI is all about web forms.) The designer has a back-end code element, you can see a split view, as shown in Figure 2-3.

Getting around the HTML designer is easy. I want to point out two features in the HTML designer. These features can be found in a menu strip along the bottom of the designer view:

+   * The view change buttons, which read Source, Design, and Split: Source shows only the HTML code. Design shows the visual designer. Split, unsurprisingly, shows both in two panels, just like the WPF designer.
* The small document tree next to the view change buttons: This shows you in the hierarchical tree where your cursor is and its relationship to the rest of the HTML designer.
