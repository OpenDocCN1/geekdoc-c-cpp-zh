# Finding Out More about WPF Data Binding 621

WPF provides a number of controls called ItemsControls that allow you to bind collections of objects to them. Examples of ItemsControls are ListBox and ComboBox (among others). Collections are bound to an ItemsControl through the ItemsSource attribute. A data template can also be applied to each object bound through the ItemsControl ItemTemplate attribute.

Through Property inheritance, the ItemsSource of the ListBox is defaulted to the DataContext of Window. The [Binding] element simply states that you use the current binding of its parent, you are setting the DataContext recursion up the element tree until it reaches a place where a binding is set. Remember that in the GenerateData, binding to the list of Servers to the Window itself, so the ListBox will inherit that list as its Source.

The data template was defined in resources to describe a Server Status object will be used to render each object bound. You can see this through the ItemTemplate attribute that uses the StaticResource points to the ServerTemplate that was defined in resources.
