# Listing 2-45: The View Code-Behind

```
public class CustomerMaintenance : Window
{
    public CustomerMaintenance()
{
        InitializeComponent();
        DataContext = new CustomerMaintenanceViewModel();
    }
}
```

Wait! Didn we not say you want to remove all code from the code-behind? Not all code. Almost all code. Event handlers with stuff logic, definitely. But you have to have two lines in the constructor: Initialize(), which renders all the XAML, and the DataContext assignment. You might have cases for additional code logic in the code-behind, and those cases might be perfectly valid. Use critical thought before you start adding code in places where it can't be tested or reused.
