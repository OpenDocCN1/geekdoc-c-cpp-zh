# Hacking item templates

Items work the same way. Check into C:\Program Files(x86)\Microsoft Visual Studio 11.0\Common7\IDE\ItemTemplates\CSharp and you'll see the same set of item types that show in the Add New item dialog box:

+   * Code
* Data
* General
* Office
* Reporting
* Silverlight
* Web
* Windows Forms
* WPF

If you dig into a directory through the Code/1033 folder, you will find more or less the same kinds of things you saw in the project templates in the preceding section. The templates are in directories (and have to stay that way). These files include a .vtemplate file that has the details Visual Studio needs. The files that go into the project are in, too.

Yes, some of these item templates are duplicates of the items in the project templates. I don't like that, but I can't see any way around it.

Look in the Code/1033 folder. There is a ClassLibrary directory that maintains the Class template, if you were to right-click a project name and select Add New Class. Suppose that you want to put the default comment block in here, here's what to do:

+   1. Duplicate the Class.
2. Open the class.cs file in Visual Studio.
3. Add the bold lines to the file.

The file in the project group looks like the following listing. To edit it, you just make a new line before the class declaration and type ///

```
using System;
using System.Collections.Generic;
$if($targetframeworkversion$ >= 3.5)using System.Linq;
endifusing System.Text;
```
