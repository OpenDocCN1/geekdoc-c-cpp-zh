
## Using Lists

Suppose you need to store a list of MP3 objects, each of which represents one item in your MP3 music collection. As an array, it might look like this:

```csharp
MP3[] myMP3s = new MP3[50];      // Start with an empty array.
myMP3s[0] = new MP3("Norah Jones"); // Create an MP3 and add it to the array.
// ... and so on.
```

With a list collection, it looks like this:

```csharp
List<MP3> myMP3s = new List<MP3>();    // An empty list
myMP3s.Add(new MP3("Avril Lavigne")); // Call the list's Add() method to add.
// ... and so on.
```

So what, you say? These examples look similar, and the list doesn't appear to provide any advantage over the array. But what happens when you add the 50th MP3 to the array and then want to add a 51st? You're out of room. Your only course is to declare a new, larger array and then copy all MP3s from the old array into the new one. Also, if you remove an MP3 from the array, your array is left with a gaping hole. What do you put into that empty slot to take the place of the MP3 you ditched? The value null, maybe?

The list collection sails happily on, in the face of those same obstacles. Want to add MP3 number 51? No problem. Want to junk your old Pat Boone MP3s? (Are there any?) No problem. The list takes care of healing itself after you delete old Pat.

![](img/6df7bb88e9302e98442acc219cfbd7fc_147.png)

If your list (or array, for that matter) can contain null, be sure to check for null when you're looping through it with foreach. You don't want to call the Add() method on a null item. It results in an error.

![](img/6df7bb88e9302e98442acc219cfbd7fc_147_0.png)

The ListCollection example in this book shows some of the things you can do with List<T>. The following code intersperses explanations with code. The following code shows how to instantiate a new, empty list. In other words, this list can hold only strings:

```csharp
// List<T>: note angle brackets plus parentheses in the List<T> declaration;
// T is a "parameter type."
List<string> nameList = new List<string>();
nameList.Add("one"); // Fine.
nameList.Add(new Student("Bois")); // Compiler error!
```

You add items to a List<T> using its Add() method. The preceding code successfully adds one string to the list, but then runs into trouble trying to add an integer and then Student. The list was instantiated for strings, so the compiler rejects both attempts.

The next code fragment instantiates a completely new list for int and adds two values to it. Afterward, the foreach loop iterates the list, printing out the ints:

```csharp
// Instantiate for int.
List<int> intList = new List<int>();
intList.Add(3);                // Fine.
intList.Add(4);
Console.WriteLine("intList:");
foreach(int i in intList)
{
    Console.WriteLine("i = " + i);
}
```

The following bit of code instantiates a list to hold Students and adds two students with its Add() method. But then notice the array of Students which I add to the list using its AddRange() method. AddRange() lets you add a whole array or (almost) any other collection to the list all at once:

```csharp
// Instantiate for Student.
List<Student> studentList = new List<Student>();
Student student1 = new Student("Vigil");
Student student2 = new Student("Finch");
studentList.Add(student1);
studentList.Add(student2);
Student[] students = { new Student("Mox"), new Student("Fox") };
studentList.AddRange(students); // Add whole array to List.
Console.WriteLine("Num students in studentList = " + studentList.Count);
```

(Don’t worry about the “new Student” stuff. I get to that topic in Book II.)

![](img/6df7bb88e9302e98442acc219cfbd7fc_148_0.png)

You can easily convert lists to arrays and vice versa. To put an array into a list, use the list’s AddRange() method as described. To convert a list to an array, call the list’s ToArray() method:

```csharp
Student[] students = studentList.ToArray();  // studentList is a List<Student>.
```

List<T> also has a number of other methods for adding items, including methods to insert one or more items anywhere in the list and methods to remove items or clear the list. Note that List<T> also has a Count property. (This single nit can trip you up if you’re used to the Length property on arrays and strings. For collections, it’s Count.)

The next snippet demonstrates several ways to search a list: IndexOf() returns the array-style index of an item within the list, if found, or -1 if not found. The code also demonstrates accessing an item with array-style indexing and via the Contains() method. Other searching methods include BinarySearch(), not shown:

```csharp
// Search with IndexOf().
Console.WriteLine("Student2 at " + studentList.IndexOf(student2));
string name = studentList[3].Name; // Access list by index.
if(studentList.Contains(student1)) // student1 is a Student object.
{
    Console.WriteLine(student1.Name + " contained in list");
}
```

The final code segment demonstrates several more List<T> operations, including sorting, inserting, and removing items:

```csharp
studentList.Sort(); // Assumes Student implements IComparable interface (Ch 14).
studentList.Insert(3, new Student("Ross"));
studentList.RemoveAt(3); // Deletes the third element.
Console.WriteLine("removed " + name); // Name defined above
```

That’s only a sampling of the List<T> methods. You can look up the full list in Help.

![](img/6df7bb88e9302e98442acc219cfbd7fc_149_0.png)

To look up generic collections you have to look in the Help index for the term List<T>. If you try searching for just List, you’ll be lost in a list of lists of lists. If you want to see information about the whole set of collection classes (well, the generic ones), search the index for generic collections.

## Using Dictionaries

You’ve no doubt used Webster’s or another dictionary. Dictionaries are based on key-value pairs. In C#, the dictionary is represented as Dictionary<TKey, TValue>. TKey represents the key, and TValue represents the value.

![](img/6df7bb88e9302e98442acc219cfbd7fc_149_1.png)

The dictionary is like a list, but instead of an integer index, you use a key to find the value. This is particularly useful when you have a unique identifier for each item, like a student ID or a product code.

```csharp
Dictionary<string, string> dict = new Dictionary<string, string>();
dict.Add("Apple", "a fruit");
dict.Add("Banana", "a yellow fruit");
dict.Add("Cherry", "a red fruit");
```

To add items to a dictionary, you use the Add() method or the indexer. If you try to add a key that already exists, the Add() method will throw an exception. The indexer, however, will update the value.

```csharp
dict["Apple"] = "a red fruit"; // Updates the value
```

To retrieve a value from a dictionary, you use the indexer or the Get() method. If the key doesn't exist, the indexer will throw an exception. To be safer, use the TryGetValue() method.

```csharp
string value;
if (dict.TryGetValue("Banana", out value))
{
    Console.WriteLine(value);
}
```

To remove an item from a dictionary, use the Remove() method or the Clear() method.

```csharp
dict.Remove("Banana");
```

To iterate through a dictionary, you can use a foreach loop. Each iteration yields a KeyValuePair<TKey, TValue>.

```csharp
foreach (KeyValuePair<string, string> entry in dict)
{
    Console.WriteLine(entry.Key + ": " + entry.Value);
}
```

The dictionary also has the Keys and Values properties, which return collections of just the keys or just the values.

```csharp
foreach (string key in dict.Keys)
{
    Console.WriteLine(key);
}

foreach (string value in dict.Values)
{
    Console.WriteLine(value);
}
```

Dictionaries are a powerful tool for storing and retrieving data when you need to look up items by a unique key.
