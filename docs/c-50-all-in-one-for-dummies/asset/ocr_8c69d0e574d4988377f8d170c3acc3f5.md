# Editing, Validating, Converting, and Visualizing Your Data

In the preceding section, you got a taste of binding syntax and saw data appear on the screen. This section builds on this knowledge and shows you a simple example of updating data, from user interface elements as well as updating the user interface with changes to objects behind the scenes.

The complete solution is available on the web in the BindingSample2 project.

To do this, follow these steps:

+   1. Create a new WPF Application project and name it BindingSample.
Reuse the Car that you created in BindingSample1 (Note: If copying and pasting this class, ensure you change the namespace of the class to BindingSample2.)
In this example, you display the model of a Car object (the DataContext) in TextBox controls. This enables you to edit the values of the Car properties. You will also use a TwoWay data binding mode so that changes made from the user interface will be reflected in the Car object, and any changes made to the Car object from codebehind will be reflected in the user interface.
2. Define two buttons, one that shows a message box containing the current value of the DataContext, the other that forces changes to the DataContext through code-behind.
