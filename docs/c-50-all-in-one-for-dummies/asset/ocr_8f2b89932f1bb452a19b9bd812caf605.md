Web applications are different, though because layers have different scalability needs. Sometimes the database is loaded, and sometimes the web server is. You must be to separate the layers of the application, as shown in Figure 1-4 — that where services start to become useful.

Because the services use a common format — usually XML over HTTP — you can easily install parts of the application on their own machines to isolate them physically. Because the functionality of the deleted part is called a service, you can scale the application horizontally — from one to multiple servers.
