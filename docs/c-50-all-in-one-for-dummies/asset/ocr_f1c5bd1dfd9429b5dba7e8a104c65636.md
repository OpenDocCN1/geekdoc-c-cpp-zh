Here are some examples of the values available:

+   - AUTH_USER: The logged-in user.

+   - REMOTE_USER: The same as AUTH_USER.

+   - CONTENT_LENGTH: Size of the request. This is useful if a file is uploaded.

+   - HTTP_USER_AGENT: Which browser the client is using.

+   - REMOTE_ADDR: The IP number of the client computer.

+   - QUERY_STRING: All the stuff after the question mark in the request.
Check out the Address bar of a browser in many web applications to say
What I mean.

+   - ALL_HTTP: Every header variable (request details made available to the
server) by the client.

In total, there are usually 63 variables in the header. The most commonly
accessed of them are in the System.Web.HttpRequest class. You'll also
find the collection of ServerVariables there. You can find out more
getting to class in Chapter 4 of this minibook. Search MSDN on
ServerVariables to get the complete list.
