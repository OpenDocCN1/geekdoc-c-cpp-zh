# Testing Web Applications with Visual Studio

It's easy to test web applications using Visual Studio, though it isn't a well-advertised feature.

This is available only in Team System. If you have Professional, you can't do web tests. Also important: Don't have to test a web project in your solution — you can write a web test against any URL.

Follow these steps to test your web project:

+   1. Choose File:New: Project and select Web Performance and Load Test Project.

+   2. In the new project, right-click the project and select New Performance and Load Test.

+   3. In the Test dialog box, select Web Test.

+   4. Change the test name to GoogleTest.Webtest and click OK.

The Web Test Recorder opens in your browser (see Figure 5-5).

I am going to use Google for this test, please don't use a production website of your own for testing.
