# Element binding

In this chapter, you bind Label and TextBox controls to properties of underlying objects. You're not limited to this scenario; you can bind to just anything from primitive variables to properties gleaned from UIElements. Binding in particular has its own component in the Binding expression. For instance, suppose that you have a TextBox and Label control in your window. You'd like to have the Content of the Label automatically update with changes in the TextBox. The XAML code to accomplish Element Binding between the TextBox and Label looks similar to

```
<Label xName="lblCar"
Content={Binding
    ElementName=txtCar,
    Path=Text} />
<TextBox xName="txtCar"
    Width="200" Height="25" / />
```

The C# code to define this binding looks similar

```
Binding b = new
Binding("Text");
b.ElementName = "txtCar";nBindingOperations.SetBinding(lblCar, Label.Content, b);
```

Just these steps to add validation to your Car class:

1. Open the Car.cs file and edit the class to also implement the IDataErrorInfo interface, like this:

```
public class Car : INotifyPropertyChanged, DataErrorInfo
```

Implementing this interface adds the following methods to the Car class:

```
public string Error
{
    get { throw new NotImplementedException(); };
}
```

```
public string this[string columnName]
{
    get { throw new NotImplementedException(); };
}
```

2. Get the Method property of the Error property to return null.

Now it's time to add some validation rules to the properties of the Car object. The Car Make and Model properties should enforce the rule that they must always be at least three characters in length.
