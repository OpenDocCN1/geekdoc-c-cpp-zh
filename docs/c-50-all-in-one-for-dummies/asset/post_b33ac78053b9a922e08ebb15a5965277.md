## Shifting C# Toward Dynamic Typing

So-called "dynamic languages" are a trend that keeps coming back, like Hawaiian shirts. Dynamic languages are languages that allow for loose typing, rather than static. The concept started in the 1960s with LISP. Dynamic languages came back in the late 1980s for two reasons: network management scripting and the artificial intelligence craze. Thanks to the web, the buzz is back again.

The Wide Web, for those of you who are not old enough to remember, was built on View Source and dynamic languages. Microsoft's original web development language, Active Server Pages, were built on VBScript — a dynamic language.

The web is better with a dynamic programming environment, so the trend is probably here to stay this time (until the next big thing, anyways). C# isn't the only language that is adding dynamic language features, and dynamic type isn't the only language feature that has been added to make it more appealing for web programmers.

Several dynamic languages have been around for a while, like:

- Perl
- Visual Basic
- Smalltalk
- LISP
- Scheme

While some of these aren't as popular as they once were, they are still there and have pushed the trend into the newer languages.
