The first thing to make in MainWindow.xaml is the namespace for the local assembly (BindingSample3) was added to the Window (identified by the namespace definition in the Window tag with the prefix local). This allows you to instantiate classes that are defined in the current assembly in XAML, such as BooleanToConverter.

```
xmlns:local="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
xmlns:local="clr-namespace:BindingSample3"
Title="MainWindow" Height="400" Width="525">
<Window.Resources>
    <local:BooleanToConverter x:Key="BooleanToConverter" />
</Window>
```

In the resources, initialize an instance of your BooleanTo Converter, which is available to you through the local namespace.

```
<local:BooleanToConverter x:Key="BooleanToConverter" />
```
