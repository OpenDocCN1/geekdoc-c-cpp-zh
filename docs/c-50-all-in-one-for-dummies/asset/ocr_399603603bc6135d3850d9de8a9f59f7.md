# Managing Files 725

The New Web Site dialog box includes several items, but you're concerned
with only one, the ASP.NET Web site. Here are all the options:

+   * ASP.NET Web site: This is what you want. It is a file share that represents
just what it says: a website made up of ASP.NET files. Fantastic. Not as
simple as it sounds, but it is the right start.
* Silverlight Script Web: This isn't the right place to talk Silverlight.
Like WPF, it is XAML (rhymes with "camel") project, but it
designed for the web. It is Microsoft's answer to Adobe Flash.
* ASP.NET Web service: Don't use this; use WCF for Web Services.
* Empty Web site: Just a folder and a share.
* WCF Service: A template for a service. Book VII covers these.
* ASP.NET Reports Web site: Same as the first bullet selection except it
includes a bunch of references to the Report Definition Language (RDL)
structure.
* Dynamic Data Link to SQL site: This is a simple, auto-generated
forms-over-data site. I don't care for them, and they aren't great
amples of C#, so I skip them for now. Linq to SQL is end-of-life (mean
Microsoft is not supporting it anymore).
* Dynamic Data Entities Web site: Again, an auto-generated forms-overadata site. Not what you're looking for.

If you cancel out of the New Web Site dialog box, add a New Project, and
click the Web in the Templates tree view (under C#), you will find
a whole list of guides (see Figure 5-2).
