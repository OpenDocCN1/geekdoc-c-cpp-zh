# Using single-item selection controls

After collecting text, the next common user-input gathering operation is asking them to choose an item from a list. In HTML, you can do this with check boxes, radio buttons, or drop-down lists (see Figure 3-3).

ASP.NET provides all of these items:

+   **The Boolean check box:** This is just one single check box where the answer is Yes or No. This is still considered a single item selection even though there is only one item to select and is used to represent a Boolean or in the C# code. It is represented by the checkbox control.

+   **The radio button list:** Radio buttons are nice because they prevent the user from selecting more than one while seeing all the options. Lists are an interesting beast, because they can be bound to collections. I cover that in the later section, "Data Binding." This control is radiolistcontrol.

+   **The drop-down list:** Represented by the dropdown control, this type of list allows the user to choose to see and select one item, which closes the list. It can also be bound to a collection.
