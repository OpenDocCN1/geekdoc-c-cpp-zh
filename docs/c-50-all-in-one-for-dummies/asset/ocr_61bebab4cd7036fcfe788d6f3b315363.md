# Paneling the Studio

Paneling: That's just so seventy.

To be as flexible as it needs to, Visual Studio has a large collection of modular windows that are called panels. These panels do everything that isn't involved with directly editing a design or code. They manage files, manage objects, show feedback, and all sorts of stuff.

Visual Studio has something like 23 panels. I don't have to discuss them all here, so I cover only five — the ones you use every day. The rest you can find in the View menu.
