# 764 Making an ASMX Service

```
SharpReference.conferencesSoapClientserviceReference = new SharpReference.conferencesSoapClient();
SharpReference.Conference[] conferences = serviceReference.conferencesAtLocation(3);
Console.WriteLine("There will be {0} conferences at location number.", conferences.Length);
Console.ReadKey();
```

Notice that the conferencesLocation method now returns an array rather than a List<Conference>. The consuming language doesn't have to have generics, but it does to have arrays (if it conforms to WS-I). That's the only assumption we can make. (See Figure 2-7).
