If you have any experience with HTML, you recognize 90 percent of what is on the screen. <html>, <head>, <body>, and <form> are all common HTML tags that you can find on any web page. The two tags that begin with <asp are ASP.NET Server controls, and that is what <F5> I am talking about.

To see what these controls do, press <F5>. IIS launches, your web browser launches, and your new page appears (see Figure 2-2).
