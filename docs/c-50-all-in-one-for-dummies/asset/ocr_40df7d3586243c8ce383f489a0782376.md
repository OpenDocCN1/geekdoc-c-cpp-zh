# 736 Deploying Your Masterpiece

![](bbox=[0.248, 0.114, 0.856, 0.513])

**Figure 5-9:** Packaging for publishing.

Starting at the top — you can isolate 64-bit operating systems with the Platform drop-down list. This is good when you're developing in 32 bit but know your server is 64. Right below that is a link to the Help files, in case you don't have this chapter handy.

In the Items to Deploy section, you can call the deployment to deploy marked and compiled files, which is what you need to do. There are options to debug symbols, too — remember, they don't run if they aren't there, and it gives you a little faster. You can always add them if you need them.

You can use MsDeploy with Visual Studio. MsDeploy is a new feature of IIS that assists with the deployment of really complex web applications. Search for it on TechNet for more information. It takes a Zip file, which you can configure in the MsDeploy Package Settings section.
