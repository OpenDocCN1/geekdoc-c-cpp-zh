# Multiple-item selection controls

Sometimes you want the user to be able to choose more than one of the items available in a list. HTML has two controls that handle that: the listbox and the checkbox list (see Figure 3-4).

ASP.NET repeats these, like:

+   * The listbox: This list is like a dropdownlist, except there is no expansion required — use the expanded list, scroll by and all. To select more than one item, the user is usually required to hold down the control or command key while clicking.

+   * The checklist: This is exactly what it sounds like: list of check boxes. It looks just like a radio button list, except with check boxes. You can see what I mean in Figure 3-4.
