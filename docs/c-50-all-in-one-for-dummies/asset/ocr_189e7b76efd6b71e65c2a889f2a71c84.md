# Making an ASMX Service

# Breaking down the sample code

The TheService.asmx.cs file does all the work in the new service, starting with the code in the template. Run that code one at a time to:

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Web;
using System.Web.Services;

namespace ANewService
{
    /// <summary>
    /// Summary description for TheService
    /// </summary>
    /// [WebServiceBinding(Namespace = "http://tempuri.org/",
    ConformsTo = WsProfiles.BasicProfile1)]
    /// [ComponentModel.Toolbox(false)]
    /// To allow this Service to be called from script, using ASP.NET AJAX,
    /// uncomment the following line:
    /// [System.Web.Services.ScriptService]
    public class TheService : System.Web.Services.WebService
{
    [WebMethod]
    public string HelloWorld()
    {
        return "Hello World";
    }\}
```

There are eight things to point out:

+   * Line 5 in the System.Web.Services namespace; it's essential to keep the rest of the template.

+   * Line 12 sets the Namespace for the .NET classes. The namespace, just like the namespace can be anything you want. It doesn't refer to a real place on the web.

+   * Line 13 sets the Web Service Binding. WS-I is the Web Services Interoperability organization (you guessed it) even more standards for web services. Basic Profile 1 is more or less the industry standard. You can find out more at www.ws-i.org.

+   * Line 14 declares if the item should show up in design timeboxes.

+   * Line 16 (when uncommented) activates runtime support for AJAX.

+   * Line 17 is a normal, every class definition, not that it inherits System.Web.Services.WebService.

+   * On Line 20, you can see the [WebMethod] attribute. This allows you to control what methods are available to the service from the class, and there are few attributes for fine-grained control.

+   * The code itself is fairly boring — functional code is exactly the same as it would be in a normal class. All the things that make it a web service are in the declaration.
