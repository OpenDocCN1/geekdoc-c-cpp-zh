# 774 Creating a WCF Service

Fortunately, there is the Service Configuration Editor. Shown in Figure 3-5, the Service Configuration Editor allows you to manage the complex options that are WCF's primary power.

![](bbox=[0.259, 0.211, 0.715, 0.458])

Figure 3-5:
The Service Configuration Editor.

Using the Service Configuration Editor for adding a service endpoint seems more complex than it ought to be. Just follow these steps:

+   1. Open the Web.config of your project by choosing File:Open and navigate to your Web.config.
2. Click Create a New Service in the main window of the editor.
3. Click Browse and find the compiled DLL SHARPService.dll if you used my naming.
4. Double-click the DLL.
5. As shown in Figure 3-6, click the Registration service, click Open, and then Next.
6. Confirm the service contract.
7. Click Next.

The editor opens in the design window.

It should be in the Bin folder named SHARPService.dll if you used my naming.

The services that are represented appear.

(See, I told you it would be useful later!)

In the Binding Configuration, you'll see what I mean about the number of options. Select the Existing Binding Configuration radio button and check out the drop-down list. The items in list are covered in the sidebar, "Using different endpoints." For now, accept the default.
