# Using some better fitting gear: Using the statement

Now you've using FileStream and StreamWriter in action, I should point out the main way to do stream in C# — inside a using statement:

```
<resource>
{
  the resource.
}
```

Using is a construct that automates the process of cleaning up using a stream. Encountering the curly brace of the using block, C# manages "flushing" the stream and closes it for you. (To flush is to push any bytes left over in the stream's buffer to the associated file before it gets closed. Thinking of pushing a handle to drain the last water out of ... trout stream.) Using eliminates the common error of forgetting to flush and close a file after writing to it. leave open files lying around.

With using, you'd need to write

```
Stream fileStream = null;
TextWriter writer = null;
t{
  // Create and use the stream, then ...
}
finally{
  stream.Flush();
  stream.Close();
  stream = null;
}
```

How I declared the stream and write above the try block (so they're visible through the method). I also declared the FileStream and writer variables using abstract base classes rather than the concrete types FileStream and StreamWriter. That's a good practice. I set to null so the compiler won't complain about uninitialized variables.
