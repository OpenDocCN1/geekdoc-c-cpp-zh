A user control is a collection of reusable XAML. It can be made up of any number of elements and is implemented with the same rules as when you implement a normal Window (for instance, you can have only one root element). You can also define properties (including dependency properties!) on user controls.

Project is available on the web BindingSample3.

Follow these steps to create your sample:

+   1. Create a new WPF application named BindingSample3.
2. Add a new User Control to the project; name it GreenCheck.xaml.
3. Replace the XAML in GreenCheck.xaml with the following: 

```
<UserControl x="BindingSample.Check"
xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
xmlns:d="http://schemas.openxmlformats.org/markup-compatibility"
xmlns:mc="http://schemas.microsoft.com/expression/blend/2008"
m:Ignorable="d"
d:Width="50" d:Height="50">
<Canvas x:Name="Canvas" Width="50.4845" Height="49.6377">
Canvas.Left="0" Top="0">
<Path x:Name="CheckPath" Width="43.4167" Height="45.6667">
Canvas.Left="0" Top="1.3113-006"
Stretch="Fill" Fill="#FF0066D3"
Data="M 19.0833, 45.6667 L 41.4167, 26.6667 L 38,31.3113-006 L 19.0833,48.5283 L 24.2617,25.5333 L 30,27.9267 L 17.4167,44.225/>
/>
</Canvas>
</UserControl>
```

You're not expected to come with things like the CheckPath off the top of your head. (The path is what describes how the check mark is drawn.) In the Expression Suite, you design tools allow you to draw items in a graphics program and export your final graphics in a XAML format. Expression Design was the tool used to create the user controls in this example.
