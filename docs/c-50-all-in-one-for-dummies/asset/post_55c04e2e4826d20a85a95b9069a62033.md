## Setting up your markup for binding

Back in the Active Server Page days, you put all your data on the page by printing it. Sounds simple, but it had a lot of problems. Foremost, your form had to have a lot of knowledge about the data it was showing. This is a bit different. Anyway, the format for doing it was

```
<% ThisWhatIWantPrint %>
```

If you needed a list, you looped in the surrounding code. If you needed a method result, you just put the method in there. What you saw was you got.

Data binding is the more enlightened form of getting data on the screen. The controls that are built into ASP.NET know how to handle data on their own, so that your data meets some specifics.

Data binding is accomplished by setting a property of a control to a member of the underlying class. For a single control, a text box, you set the property in question, like this:

```
<asp:Label Id='Label1' runat='server' Text='<%DataBindingToThisVariable %>' />
```

If you're binding to a repeating control, like a Grid or a ListBox, then you set the DataSource property. I show you how to do that in the next section.

The variables you are needing to be in the code-behind and be public. If they aren't, you will get runtime errors. That's why binding in the code is a good idea, which I do in the next section.

## Data binding using the code-bind

Rather than set a property directly in the markup, you can set it equal to a value in the code-bind. For a repeating control, you can set a DataSource property in the C# code for the control. Then, when you bind the page, it uses that value to load the right value or values from the code-bind.

Keep in mind, though that with the Text property of a Label (for instance) this is just data binding. I am just setting a value.

Try it with the Show example. Just follow these steps:

- 1. Keep the label text simple - just drop the Text property, like:

```html
<!DOCTYPE html PUBLIC "-//W3C//DTD HTML 1.0 Transitional//EN" "http://www.w3.org/TR/html1/transitional.dtd">
<html xmlns="http://www.w3.org/1999/xhtml">
@Page Language="C#" AutoEventBack="true" CodeBehind="Text.aspx.cs" Inherits="Chapter_3.Text">
<head runat="server">
  <title></title>
</head>
<body>
  <form id="form" runat="server">
    <div>
      This is some text. <br />
      <asp:Label Id="Label" runat="server" />
    </div>
  </form>
</body>
</html>
```

- 2. In the code-bind, set the Text property equal to the property on the control that you want to bind. Notice that there is no DataBind command for the page:

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Web;
using System.Web.UI;
using System.Web.UI.Controls;

namespace Chapter_3
{
    public partial class Text : System.Web.UI.Page
    {
        protected void Page_Load(object sender, EventArgs e)
        {
            Show show = new Show { ID = 1, Channel = 5, EpisodeTitle = "ASP.NET DataBinding", ScheduledTime = new DateTime(2009, 4, 12, 12, 0), ShowTitle = "C# Show" };
            Label.Text = show.EpisodeTitle;
        }
    }
}
```

- 3. Run the application to see the value set. This works well, but remember, this is only simple data binding. It's just setting values. Full data binding is for controls with repeating properties.
