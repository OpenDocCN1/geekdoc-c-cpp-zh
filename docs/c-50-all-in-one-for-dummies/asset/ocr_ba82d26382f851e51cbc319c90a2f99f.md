So what's the process of creating tables this way? Well, you can name rows and cells and then manage them in the code-behind using C#. In all honesty, that's not how I recommend doing things.

Tables are good for two things — layout and tabular data. Layout has been superseded by CSS. I recommend using CSS to lay things out.

For tabular data, tables still work. However, there is a more interesting solution. The GridView (found in the Data section of the Toolbox) is just as functional — and it is bindable. I chat more about that in the “Data Binding” section, later in this chapter.
