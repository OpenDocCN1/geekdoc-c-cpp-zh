# Making an ASMX Service 759

Right-click the SharpAsmx project and add an Entity Data Model by selecting New Item and picking ADO.NET Entity Data Model from the list.

(It's under Data.) I named it SHARP.edmx.

When the Entity Data Model wizard appears, select Generate from Database and click Next.

In Your Data Connection, pick the ConferenceDb you added in Step 1; keep the rest of the defaults.

When it asks you to copy the file to your project, choose No.

You don't need copies of the database floating around.

In Your Database Objects, pick all the tables except sysdiagrams and change the Model Namespace to ConferenceDB.

An example appears in Figure 2-3.

6. Click Finish.

That's how you set up an ASMX web project. You have a data source, an entity model (you could use your organization's domain model, or, hand-rolled procedures and ADO.NET, or whatever), and a starting point for the service.

Next, you add some services that make sense of your user interface. There are two schools of thought on this. First, you can roll up the entity model in the service namespace itself. Second, you could write a separate business layer and just call the Business Layer (BL) methods with the services.
