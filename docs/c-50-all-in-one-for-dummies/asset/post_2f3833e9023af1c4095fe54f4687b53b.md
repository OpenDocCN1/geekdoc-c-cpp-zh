
## Versioning the Versions

Visual Studio has lots of different versions (a metric ton of them — a bushel and a peck, even).

The reason is its famous licensing problem. If Microsoft just sold the whole package for what it was worth, only the Fortune 50 could afford it, and it would cut out 99 percent of its audience. If Microsoft makes a lot of different versions and tries to incorporate the features that different groups of people use, it can capture nearly 100 percent of the audience.

![](img/6df7bb88e9302e98442acc219cfbd7fc_527_0.png)

This book focuses on the Professional Edition, as I mentioned in the Introduction. However, much of the sample code works in any version — though the step lists are different.

In this chapter I run down the features and benefits of all the major editions. At the end of the section, a grid shows the major features and what each edition includes.

## Express

Express is the free version of Visual Studio.

Express is significantly less functional than the Professional Edition, you can compile nearly every code sample in this Express. It has the power of .NET Framework, which is also free, and gives you a significant means of learning C#.

Express edition is not designed for making production software. It lacks er projects and many of the tools for team development. Nonetheless, it runs C# as well as anything else — remember that C# is just a language.

Express has a number of different subeditions. Express divides the Microsoft development sphere into technological sections: one for each major platform. This hobbyist developer can be allowed to focus on his passions.

- **Visual Studio Express for Windows 8**: The Windows Store and its applications are going to revolutionize the world of Express. Express for Windows 8 makes it possible to develop your Windows Store style apps for free and just have the deployment costs associated with using the store. You can develop C#, C++, and JavaScript Windows 8 apps using this edition, as well as related components. This version is great for learning the language and for participating in open source application projects, though. Open source projects (which you contribute code, not a whole project for pay) are good for Express editions. I recommend that you start here if you have nothing else.

- *Visual Studio Express 2012 for Windows Desktop*: Like the Windows 8 edition, the Windows Desktop edition of Visual Studio allows you to write apps that run on Windows Desktop in 7 or 8 (the server editions) in a variety of languages. It's not possible to have large multi-tier applications like you would find in big companies, but it is possible to write a simple WPF or Windows Forms project and component.

- *Visual Studio Express 2012 for Web*: Web edition is an interesting free edition of Visual Studio. It's designed around the creation of web pages using ASP.NET, ASP.NET MVC, or Silverlight. Because those languages are compiled, you can write production software for free. All the better for you and me.

Both VB and C# are supported by this writing, and most of the functionality of the projects in Visual Studio is available. Find out more at www.microsoft.com/express.

- *Visual Studio Express for Windows Phone*: As of this writing, the Windows Phone edition of Visual Studio is still version 2010, but I am betting it will be 2012 by the time you read this. WP Edition was one of the first platform-specific editions created and was clearly the model for this batch of Express editions. This package gives you all of the things you need to build, debug, and deploy Windows Phone apps using XAML and C# or VB.NET.

## Professional

Professional Edition is designed for professional programmers. This edition of Visual Studio is the one I use daily. It's made to generate stand-alone programs that solve specific problems.

Microsoft is on the ball, with three goals for its Professional Edition:

- Enabling emerging trends
- Inspire developer delight
- Ride the next-generation platform wave

That hits the nail on the head. This is the edition that entire book is built on, and I recommend for the production of most programs, although it costs money.

## Team System

Visual Studio Team System, usually referred to as VSTS, is the grand pooh-bah of the Microsoft platform. It connects to Team Foundation Server (a Microsoft product that provides team metrics for software development), provides a plethora of software creation metrics when teams are involved in the development.

Figure 1-1 shows a little of what I’m talking about. Build statistics and development details can be gathered using the dashboard in SharePoint.

Facts are facts — Team System is cool software, but it doesn’t work without a big enterprise environment around you. It needs SharePoint, Exchange, and SQL Server to work right.

## MSDN

The Microsoft Developer Network (MSDN) is the best way to get Microsoft products. It's for development only, but you can get everything. Basically how it works is you go to Amazon or elsewhere and buy the code. Then you go to http://msdn.microsoft.com and register the code with your Live Account.

- Microsoft Office
- Windows client
- Windows Server
- SQL Server
- SharePoint and BizTalk

## Academic

If you can't afford MSDN but you're a school student or an instructor, buy the Academic edition of Visual Studio, intended just for learning. It's less expensive than MSDN, but is even more limited from the licensing perspective.

## Installing Visual Studio

Visual Studio Professional, the edition that I use for most of this book, installs much like any other Windows program. First, assure your machine can run Visual Studio. Then you run the setup program (or it automatically runs from the DVD) and make a few decisions.
