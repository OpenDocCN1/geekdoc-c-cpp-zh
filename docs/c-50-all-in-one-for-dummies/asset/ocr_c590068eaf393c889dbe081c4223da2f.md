# Breaking Down the Projects 515

+   - Test Project: If you're working in Visual Studio, right-click a method, and select Create Unit Test, you will get this kind of project. In the case where you make a test project manually, this is your project. (You can also run NUUnit, xUnit, and other popular unit test frameworks inside Visual Studio. For example, if you use NUUnit, your NUUnit Test Adapter in NUUnit Documentation.)

+   - Silverlight: Admitted, Microsoft Expression would be your best choice for Silverlight. If you want to use Visual Studio, however, you can use this project.

+   - SQL Server Project: Again, I would use Microsoft SQL Server Management Studio to make database projects. If you have to use Visual Studio for some reason, this is your project.

+   - Reports Application: You can include reports in your Windows or web application. If you're deploying directly to Reporting Services, this project does the job.

Other kinds of projects: It's easy to make your own project type for Visual Studio, and there are a bunch of them out there. Some of them are patterns, some of them are languages, and some of them are new project outputs. Here are a few of my favorites:

+   - ASP.NET MVC: Model View Controller (MVC), a project type that allows for a separation of duties between development teams. This project allows you to make ASP.NET applications using MVC. Search MSDN for more information.

+   - IRONRuby: An implementation of Ruby in Visual Studio.

+   - IRONPython: An implementation of Python in Visual Studio.
