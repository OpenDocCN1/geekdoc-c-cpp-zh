# Output of the visual tools

The reason that the visual tools often aren't used in enterprise environments is that the tools put out are rather sophisticated. If you switch to Code View and right-click an instance of an object (such as the PartTable object) and select Go to Definition, you see the code behind the designer.

2-12 shows what you see when you first get in there. The box marking the region near the top of the code window is marked as Windows Form generated code, and you can't help notice that the line number is in the twenties and the one after that is in the four hundreds. A lot of generated code.
