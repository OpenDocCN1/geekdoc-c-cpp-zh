Open source projects (which you contribute code, not a whole project for pay) are good for Express editions. I recommend that you start here if you have nothing else.

+   * Visual Studio Express 2012 for Windows Desktop: Like the Windows 8 edition, the Windows Desktop edition of Visual Studio allows you to write apps that run on Windows Desktop in 7 or 8 (the server editions) in a variety of languages. It's not possible to have large multi-tier applications like you would find in big companies, but it is possible to write a simple WPF or Windows Forms project and component.

+   * Visual Studio Express 2012 for Web: Web edition is an interesting free edition of Visual Studio. It's designed around the creation of web pages using ASP.NET, ASP.NET MVC, or Silverlight. Because those languages are compiled, you can write production software for free. All the better for you and me.

Both VB and C# are supported by this writing, and most of the functionality of the projects in Visual Studio is available. Find out more at www.microsoft.com/express.

+   * Visual Studio Express for Windows Phone: As of this writing, the Windows Phone edition of Visual Studio is still version 2010, but I am betting it will be 2012 by the time you read this. WP Edition was one of the first platform-specific editions created and was clearly the model for this batch of Express editions. This package gives you all of the things you need to build, debug, and deploy Windows Phone apps using XAML and C# or VB.NET.

# Professional

Professional Edition is designed for professional programmers. This edition of Visual Studio is the one I use daily. It's made to generate stand-alone programs that solve specific problems.

Microsoft is on the ball, with three goals for its Professional Edition:

+   * Enabling emerging trends

+   * Inspire developer delight

+   * Ride the next-generation platform wave

That hits the nail on the head. This is the edition that entire book is built on, and I recommend for the production of most programs, although it costs money.
