# 504 Versioning the Versions

As good as it is, Professional doesn’t have every feature that Microsoft has
to offer. The comprehensive team management features, reporting, check-in,
and testing features are reserved for the pricify version: Team System.

# Team System

Visual Studio Team System, usually referred to as VSTS, is the grand pooh-
bah of the Microsoft platform. It connects to Team Foundation Server (a
Microsoft product that provides team metrics for software development),
provides a plethora of software creation metrics when teams are
involved in the development.

Figure 1-1 shows a little of what I’m talking about. Build statistics and devel-\op details can be gathered using the dashboard in SharePoint.

Facts are facts — Team System is cool software, but it doesn’t work
without a big enterprise environment around you. It needs SharePoint,
Exchange, and SQL Server to work right.
