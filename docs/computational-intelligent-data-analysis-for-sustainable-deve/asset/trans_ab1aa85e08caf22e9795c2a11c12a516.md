### 目标与范围

本系列旨在捕捉数据挖掘与知识发现领域的新进展和应用，同时总结数据分析中有用的计算工具和技术。本系列鼓励通过出版广泛的教科书、参考书和手册，整合数学、统计和计算方法与技术。非常鼓励包含具体示例和应用。本系列的范围包括但不限于数据挖掘与知识发现的方法与应用、建模、算法、理论与基础、数据与知识可视化、数据挖掘系统与工具以及隐私与安全问题等领域的书籍。
