# 6.2.2  Issue 2: Sensitivity of Results Given the Uncertainty in Project Cost and In-Kind Contribution

A major issue that arises in comparing theoretical optimal solutions to actual project funding schedules is the accuracy of grant requestors’ cost estimates. Based on the project data from Bradford County, it would appear that project expenses have historically been substantially underestimated. For 2002 through 2008, the average actual cost of projects in any given year varied from 30% under the grant request to 85% over it. The amount actually paid for an individual project by Bradford County ranged from 428% above the quote in the grant proposal to 66% below it, and averaged 54% above.
