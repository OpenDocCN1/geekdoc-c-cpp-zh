| Symbol | Definition |
|---|---|
| $N_p$ | Number of pressures: $N_p = |P|$. |
| $p_i$ | Element of the $P$ vector: $i \in \{1, \ldots, N_p\}$. |
| $R$ | Vector of receptors. |
| $N_r$ | Number of receptors: $N_r = |R|$. |
| $r_i$ | Element of the $R$ vector: $i \in \{1, \ldots, N_r\}$. |
| $O$ | Vector of the outcomes. |
| $o_i$ | Outcome of the activity $A_i$. For activities that are energy sources, it is the energy (in TOE) produced in 1 year by a plant of 1 MW. |
| $T^p$ | Total outcome of the regional plan. It is the sum of the outcomes of the single activities. |
| $\mathcal{M}$ | Matrix defining the relation between activities and pressures. |
| $m_i^j$ | Element of the matrix $\mathcal{M}$. Dependency of activity $a_i$ on pressure $p_j$. |
| $\mathcal{D}$ | Matrix defining the dependency between primary and secondary activities. |
| $d_{ij}$ | Element of the matrix $\mathcal{D}$. It measures the dependency of (secondary) activity $a_j$ on (primary) activity $a_i$. |
| $\mathcal{N}$ | Matrix defining the relation between pressures and receptors. |
| $n_i^j$ | Element of the matrix $\mathcal{N}$. It is the effect of pressure $p_i$ on receptor $r_j$. |
| $C$ | Vector of costs: $|C| = N_a$. |
| $c_i$ | Element of the $C$ vector. Unit cost of activity $a_i$. |
| $A^P$ | Set of the indexes of the primary activities; if $i \in A^P$, then $A_i$ is a primary activity. |
| $A^S$ | Set of indexes of the secondary activities; if $i \in A^S$, then $A_i$ is a secondary activity. |
| $A^P_{ren}$ | Set of indexes of those primary activities that provide renewable energy. |
| $G$ | Vector of magnitudes. |
| $B$ | Total available budget. |
| $U_i$ | Maximum energy that can be produced by energy source $a_i$ in the Region. |
| $L_i$ | Minimum energy that must be produced by energy source $a_i$ in the Region. |
| $F_i$ | Minimum fraction (percentage) of energy that should be produced by energy source $a_i$ in the Region. |
