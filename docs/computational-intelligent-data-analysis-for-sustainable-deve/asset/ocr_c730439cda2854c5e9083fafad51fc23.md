# 9.3.1.1 Signal Decomposition

Empirical Mode Decomposition is a data-driven method that decomposes a signal into a set of Intrinsic Mode Functions (IMFs). Each IMF is an oscillatory signal that consists of a subset of frequency components from the original signal. As opposed to Fourier, wavelet, and similar methods, EMD constructs these component signals directly from the data by identifying local extrema and setting envelopes around the signal in an iterative process. A fit is then performed on the local extrema to create an IMF. After the creation of an IMF, it is subtracted from the original signal and the process repeats to identify the next IMF. This identification and removal process continues until the original signal has been completely described by a set of IMFs. The output of the EMD process is the set of IMFs; generally, this set is a small number of signals (usually less than ten for the data considered here) that, when summed together, completely match the original signal. The EMD algorithm does not explicitly compute oscillation frequencies, amplitudes, or phase angles as with other signal decomposition techniques; instead, the IMFs are derived directly from the input signal based on its local extrema. A complete mathematical description of the EMD algorithm is beyond the scope of this chapter but can be found in [9–12]. The EMD and associated Hilbert-Huang Transform have also been recently proposed as methods for isolating inter-area modes in power systems [16, 17].
