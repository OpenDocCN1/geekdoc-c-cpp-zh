# TABLE 3.1 Definitions

| | Unaggregated Model | Aggregated Model |
|---|---|---|
| Intermediate demand | $T = \{T^n\} = \{t^n\}$ | $\tilde{T} = \{\tilde{T}^n\} = \{\tilde{t}^n\}$ |
| Final demand | $f = \{f^n\} = \{f_i^n\}$ | $\tilde{f} = \{\tilde{f}^n\} = \{\tilde{f}_i^n\}$ |
| Total output | $x = \{x^n\} = \{x_i^n\}$ | $\tilde{x} = \{\tilde{x}^n\} = \{\tilde{x}_i^n\}$ |
| Input coefficients | $A = \{A^n\} = [a_{ij}^n]$ | $\tilde{A} = \{\tilde{A}^n\} = [\tilde{a}_{ij}^n]$ |
| Leontief inverse | $L = \{L^n\} = [l_{ij}^n]$ | $\tilde{L} = \{\tilde{L}^n\} = [\tilde{l}_{ij}^n]$ |
| Carbon intensity (emissions per unit output) | $c = \{c^n\} = \{c_i^n\}$ | $\tilde{c} = \{\tilde{c}^n\} = \{\tilde{c}_i^n\}$ |
| Carbon footprint | $w = \{w^n\} = \{w_i^n\}$ | $\tilde{w} = \{\tilde{w}^n\} = \{\tilde{w}_i^n\}$ |

$x = (I - A)^{-1} f \qquad (3.3)$

where $I$ is an identity matrix and $(I - A)^{-1}$ is called the Leontief inverse, indicating the amount of outputs required directly (by the final demand) or indirectly (via intermediate demand in the upstream production) to satisfy one unit of final demand.

The convention for matrices and vectors used for the unaggregated model and the aggregated model (letters with a bar) is provided in Table 3.1. Matrices are expressed in capital letters, while vectors and scalars are expressed in lowercase letters.

Consider there are $n$ sectors and $k$ regions. The size of matrix $T$ before aggregation is therefore $nk \times nk$, with the size of each block matrix $T^n$ being $n \times n$. The aggregation rules are defined as follows:

+   1. Sectors within one region can be aggregated but sectors in different regions cannot.
+   2. More than one aggregation within a region is allowed (such as the aggregation of Sectors 1 and 2, and the aggregation of Sectors 3, 4, and 5 in Region 1 at the same time).
+   3. Aggregations in several regions simultaneously are allowed (such as the aggregation of Sectors 1 and 2 in Region 1 and the aggregation of Sectors 1, 2, and 3 in Region 2 at the same time). Assume that $n$ sectors in Region $r$ are grouped into $n(r) \le n$ sectors.

Define

$m = \left[ \sum_{r=1}^{k} n(r) \right] \le nk$
