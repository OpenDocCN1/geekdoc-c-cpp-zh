# 10.2 MEASURE-CORRELATE-PREDICT

We consider wind resource estimation derived by a methodology known as Measure-Correlate-Predict; see Figure 10.2. In terms of notation, the wind at a particular location is characterized by speed denoted by x and direction θ. Wind speed is measured by anemometers, and wind direction is measured by wind vanes. The 360° direction is split into multiple bins with a lower limit (θₗ) and an upper limit (θᵤ). We give an index value of J = 1…j for the directional bin.
