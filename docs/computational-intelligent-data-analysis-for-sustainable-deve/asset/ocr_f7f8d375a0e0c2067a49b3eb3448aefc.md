Bradford County uses a more traditional ranking method. Project proposals are solicited once a year, and funding decisions are based on an environmental ranking that is adjusted based on in-kind contributions received. The county requires a minimum in-kind contribution of 10% to consider a project for funding. For every percentage of in-kind offered above 10%, 0.5 is added to the environmental benefit score. Also, no township can receive more than one project unless all townships that submit projects get funding for at least one project. This modified ranking system can be easily adapted to a binary program and compared for potential gains in efficiency.
