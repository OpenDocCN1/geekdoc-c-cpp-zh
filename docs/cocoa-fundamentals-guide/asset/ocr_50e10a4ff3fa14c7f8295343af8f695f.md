Cocoa Objects

The init method in this example could have returned nil or could have substituted a different object. Because you can send a message to nil without raising an exception, nothing would happen in the former case (perhaps a debugging headache). You should always rely on the initialized instance instead of the "raw" just-allocated one. Therefore, you should nest the allocation message inside the initialization message and test the Object from the initializer before proceeding.

```
id myObject = [[MyClass alloc] init];
if (myObject) {
    [myObject doSomething];
} else {
    // error recovery...
}
```

Once an object is initialized, do not initialize it again. If you attempt to reinitialize, the framework class of the instantiated object often raises an exception. For example, the second initialization in this example would result in NSInvalidArgumentException being raised.

```
NSString *str = [[NSString alloc] initWithString:@"Foo"];
str = [str initWithString:@"Bar"]
```

# Implementing an Initializer

There are critical rules to follow when implementing an init method that serves as a class's initializer, or if there are multiple initializers, its designated initializer (see "Multiple Initializers and the Designated Initializer" (page 82)).

+   * Always invoke the superclass (super) initializer first.
* Check the object returned by the superclass. If it is nil, then initialization cannot proceed; return nil to the receiver.
* When initializing instance variables that are references to objects, retain or copy the object as necessary (memory-managed code).
* After setting instance variables to hold valid values, return self unless

+   * It was necessary to return a substituted object, in which case release the freshly allocated object first (in memory-managed code).
* A problem prevented initialization from succeeding, in which case return nil.

The method in Listing 2-3 illustrates these rules.

# Listing 2-3 An example of an initializer

```
(id)initWithAccount:(NSString *)identifier {
    if (self = [super init]) {
        Account *ac = [accountDictionary forKey:identifier];
        if (ac) {
            // object with that ID already exists
            [release];
            return [retain];
        }
        if (identifier) {
            account = [identifier copy]; // account is instance variable
        }
    }
    return nil;
```
