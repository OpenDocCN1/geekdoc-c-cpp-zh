## 什么是 Cocoa？

- **文件系统和 URL。** NSFileManager 为文件操作提供一致的接口，例如创建、删除和移动文件；NSFileHandle 允许在更低级别进行文件操作（例如，在文件中查找）；NSBundle 在 bundle 中查找资源并动态加载其中的一些资源（例如，nib 文件和代码）。你使用 NSURL... 来表示、访问和管理数据的 URL 源。

- **并发。** NSThread 创建多线程程序，并且有各种锁类用于控制线程对资源的访问。你使用 NSOperation 和 NSOperationQueue 以优先级和依赖顺序执行多个操作（并发或非并发）。使用 NSTask，你的程序可以分派一个进程来执行并监控其进度。

- **进程间通信。** 此类别中的大多数类表示各种系统端口、套接字和服务器，可用于实现低级 IPC。NSPipe 表示 BSD 管道，即进程之间单向通信通道。

> 注：名称类不在 iOS 版本中。

- **网络。** NSSystemService 和 NSServiceBrowser 类支持零配置网络架构 Bonjour。Bonjour 是一种强大的系统，用于在 IP 网络上发布和浏览服务。

- **通知。** 请参阅“Foundation Paradigms and Policies”第 31 页中通知类的摘要。

- **归档和序列化。** 此类别中的类使对象分发和持久化成为可能。NSCoder 及其子类，使用 NSCoding 协议，以与体系结构无关的方式表示数据对象，使用类信息与数据一起存储。NSKeyedarchiver 和 NSKeyedunarchiver 提供用于编码对象和值以及以不依赖于编码方法顺序的方式解码它们的方法。

- **Objective-C 类。** NSException 和 NSAssertion 提供了一种面向对象的方式在代码中进行断言和处理异常。NSInvocation 是 Objective-C 消息的静态表示，你可以存储它并稍后在另一个对象中调用消息；它被撤销管理器（UndoManager）和分布式对象系统使用。NSMethodSignature 记录类型信息并用于方法转发。ClassDescription 是用于解码和查询类的关系和属性的抽象类。

- **XML 处理。** Foundation 在平台上具有 XMLParser 类，它是字符串解析器的面向对象实现，使你能够以事件驱动的方式处理 XML 数据。

- **谓词和表达式。** 谓词类——NPredicate、NSCompoundPredicate 和 NSComparisonPredicate 封装了获取或过滤对象的逻辑条件。NSPrediction 对象表示谓词中的表达式。

## 什么是 Cocoa？

iOS 的 Foundation 框架具有 Mac OS X 的类子集。以下类别的类仅存在于 Foundation 的 Mac OS X 版本中：

- *Spotlight 查询。* NSMetadataItem、NSMetadataQuery 和相关的查询类封装文件系统元数据并使其可以查询该元数据。

- *脚本。* 此类别中的类有助于使你的程序响应 AppleScript 脚本和 Apple 事件命令。

- *分布式对象。* 你使用分布式对象类进行同一台计算机或网络上不同计算机之间的进程通信。其中两个类，NSDistantObject 和 NSProtocolChecker，具有与 Cocoa 其余部分不同的根类（NSProxy）。

## AppKit（Mac OS X）

AppKit 是一个框架，包含实现 Mac OS X 中图形化、事件驱动界面的所有对象；窗口、按钮、菜单、滚动条、文本字段——AppKit 为你处理所有细节，它高效地在屏幕上绘制、与硬件设备和缓冲区通信、清除绘图区域并裁剪视图。AppKit 中的类数量乍一看可能令人望而生畏。然而，大多数 AppKit 类是支持类，你间接使用它们。它们允许你在以下级别使用 AppKit：

- *使用 Interface Builder 从用户界面对象创建到应用程序控制器对象的连接，控制器对象管理用户界面并协调用户界面与内部数据结构之间的数据流。为此，你可能会使用现成的控制器对象（用于 Cocoa 绑定）或可能需要实现一个或多个自定义控制器类——特别是这些类的 action 和 delegate 方法。你可能需要实现一个在用户选择菜单项时调用的方法（除非它具有可接受的默认实现）。

- *以编程方式控制用户界面，这需要更熟悉 AppKit 类和协议。例如，允许用户从一个窗口拖动图标到另一个窗口需要一些编程并熟悉 NSDragger... 协议。

- *通过子类化 NSObject 或其他类来实现自己的对象。子类化时，你使用图形函数编写绘图方法。子类化需要更深入地了解 AppKit 的工作原理。
