# Object Comparison

Although they are not strictly introspection, methods, the hash and isEqual methods fulfill a similar role. They are indispensable runtimes for identifying and comparing objects. But instead of querying the runtime for information about an object, they rely on class-specific comparison.

The hash and isEqual methods, both declared by the NSObject protocol, are closely related. The hash method must be implemented to return an integer that can be used as a address in a hash table. If two objects are equal (determined by the isEqual: method), they must have the same hash value. If your object could be included in collections as NSObject objects, you need to define hash and verify the invariant that if two objects are equal, they return the same hash value. The default NSObject implementation of isEqual: simply checks for pointer equality.

Using the isEqual: method is straightforward; it captures the receiver against the object supplied as a parameter. Object comparison frequently informs decisions about what should be done with an object. As Listing 2-11 illustrates, you can use isEqual: decide whether to perform an action, in this case to save preferences that have been modified.

# Listing 2-11 Using isEqual:

```
(void)saveDefaults {
NSDictionary *prefs = [self preferences];
if (![origValues isEqual:prefs]) {
[Preferences savePreferencesDefaults:prefs];
}
```

If you are creating a subclass, you might need to override isEqual to add checks for points of equality. The subclass must define an attribute that has to be the same value in two instances for them to be considered equal. For example, if you create a subclass of NSObject called MyWidget that contains two variables, name and data, both of these must be the same value for instances of MyWidget to be considered. Listing 2-12 illustrates how you might implement isEqual: for the MyWidget class.

# Listing 2-12 Overriding isEqual:

```
(BOOL)isEqual:(id)other {
if (self == other)
  return YES;
if (![other isKindOfClass:[self class]])
  return NO;
return [self isEqual:other];
}
(BOOL)isEqualToWidget:(MyWidget*)widget {
if (self == widget)
  return YES;
if ([self name isEqual:[widget name]])
  return NO;
if ([self data isEqualData:[widget data]])
  return NO;
return YES;
}
```

This isEqual: method first checks for pointer equality, then class equality, and finally invokes an object comparator whose name indicates the class of object in the comparison.
