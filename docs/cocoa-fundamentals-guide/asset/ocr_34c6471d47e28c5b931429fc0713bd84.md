Communicating with Objects

# The Notification Object

A notification is an object, one of NSNotification. This object encapsulates information about an event, such as a window focusing or a network connection. When the event happens, the object handling posts the notification to the notification center, which immediately broadcasts the notification to all registered observers.

An NSNotification contains any name, an object, and an optional dictionary. The name is a tag identifying the notification. The object is any poster that the notification wants to send to observers of that notification (typically it is the object that posted the notification). It is similar to the sender object in delegation messages, allowing the receiver to query the object for information. The dictionary stores information related to the event.

# Notification Centers

A notification center manages the sending and receiving of notifications. It notifies all observers of notifications meeting specific criteria. The information is encapsulated in NSNotification objects. Client objects register themselves with the notification center as observers of specific notifications posted by other objects. When an event occurs, an object posts an appropriate notification to the notification center. The notification center dispatches a message to each registered observer, passing the notification as the sole parameter. It is possible for the posting object and the observing object to be the same.

Cocoa includes two types of notification centers:

+   - A notification center (instance of NSNotificationCenter) manages notifications within a single task.
- A distributed notification center (instance of NSDistributedNotificationCenter) manages notifications across multiple tasks on a single computer.

Note that contrast to any other Foundation classes, NSNotificationCenter is not toll-free bridged to its Core Foundation counterpart (CFNotificationCenterRef).

# NotificationCenter
