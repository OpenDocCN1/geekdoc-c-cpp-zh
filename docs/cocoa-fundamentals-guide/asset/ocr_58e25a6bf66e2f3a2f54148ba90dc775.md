In summary, allocation not allocates memory for an object but initializes two small but very important attributes of any object: its isa instance variable and its retain count. Initializing methods as init must initialize objects with their particular characteristics and return a functional object.

# # Initializing an Object

Initialization sets the instance variables of an object to reasonable and useful values. It can also allocate and prepare other resources needed by the object, loading them necessary from an external source such as a file. Every object that declares instance variables should implement an initializer—unless the default set-to-zero initialization is sufficient. If an object does not implement an initializer, Cocoa invokes the initializer of its nearest ancestor class.

# # The Form of Initializers

NSObject declares the prototype for initializers; it is an instance method typed to return an object of type. Overriding init is for subclasses that require no additional data to initialize their objects. But often initialization depends on external data to set an object to a reasonable initial state. For example, if you have an Account class: to initialize Account object properly requires a unique account number, and this must be supplied to the initializer. Initializers take one or more parameters; the requirement is that the initializer begins with the letters "init". (The stylistic convention init... is used to refer to initializers).

> Note: Instead of implementing an initializer with parameters, a subclass can implement a simple init and use "set" methods immediately after initialization to set the object to a useful initial state. (Accessor methods encapsulate of object by setting and getting the values of instance variables). Or, if the subclass uses properties and the related access syntax, it may assign values to the properties immediately after initialization.

Cocoa has plenty of initializers with parameters. Here are a few (with the defining class in parentheses):

```
(initWithArray:(NSArray*)array from:(NSSet)
(initWithTimeInterval:(NSTimeInterval)interval)ToBeAddedSinceDate:(NSDate*)date
(initWithContentRect:(NSRect)contentRect styleMask:(unsigned int)style backing:(NSBackingStoreType)bufferType defer:(BOOL)flag:(NSWindow)
(initWithFrame:(NSRect)frame:(NSControl and NSView))
```

These initializers methods that begin with "init" and return an object of the dynamic type id. Other than that, follow the Cocoa conventions for multiparameter methods, often using WithType: or FromSource: the first and most important parameter.
