# Is Cocoa?

Beginning with Mac OS v10.5, the window and class of the AppKit support enhanced animation features.

NSView is the superclass for all objects displayed in a window. All subclasses implement a drawing using graphics functions; drawRect: is the primary method you override when creating a new NSView.

+   * Controller classes for Cocoa bindings. The abstract NSController class and its subclasses NSObjectController, NSArrayController, NSDictionaryController, and NSTreeController are part of the implementation of Cocoa bindings. This technology automatically synchronizes the application data in objects and the presentation of that in a user interface. "The Model-View-Controller Design Pattern" (page 160) for a description of these types of controller objects.

+   * Panels (dialog). The NSPanel class is a subclass of NSWindow that you use to display transient, or, information. For example, you would use an instance of NSPanel, rather than an instance of NSWindow, to display error messages or query the user for a remarkable or unusual circumstances. The AppKit implements some dialogs for you, such as the Save, Open, and Print dialogs, using these dialog gives you a consistent look and feel across operations.

+   * Menus and cursors. The NSMenu, NSMenuItem, and NSCursor classes define the look and behavior of the menus and cursors that your application displays to.

+   * Grouping and scrolling views. The NSBox, NSScrollView, and NSSplitView classes provide graphic "accessories" to other objects or collections of views. With the NSBox class you can group elements in window and draw a border around the entire group. The NSSplitView class lets you append views vertically or horizontally, partitioning each view some amount of a common territory; a sliding control bar redistributes the territory among the views. NSScrollView class and its helper, NSCClipView, provide a scrolling mechanism as well as the graphic objects that let the user indent and control a scroll. The NSRuler allows you to add a ruler and markers to a scroll view.

+   * Table and views. The NSTableView displays data in rows and columns. NSTableView is ideal for but not limited to, displaying database records, where rows correspond to each record and columns contain record attributes. The user can edit individual fields and rearrange the views. You control the behavior and content of an NSTableView by setting its delegate and data source objects. Outline views (instances of NSOutlineView, a subclass of NSTableView) offer another approach to tabular data. With the NSBrowser class you can create an object with which users can display and navigate hierarchical data.

# Text and Fonts

The Cocoa text system is based on the Core Text framework, which was introduced in Mac OS v10.5. The Core Text framework provides a modern, low-level, high-performance technology for laying out text. If you use the Cocoa system, you should use Core Text.

The NSText class implements a simple editable text-input field, and the NSTextView class provides more editing features for large text bodies.

NSTextView, a subclass of the NSText class, defines the extended text system. NSTextView supports rich text, attributes (graphics, file, and other), input management and key binding, and marked text attributes.
