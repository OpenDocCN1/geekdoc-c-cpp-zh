# What Is Cocoa?

Generally, the system libraries and frameworks of iOS that ultimately support UIKit a subset of the libraries and frameworks in Mac OS X. For example, there is no Carbon environment in IOS, there is no command-line environment (the BSD environment in Darwin), there are no printing frameworks and services, and QuickTime is absent from the platform; because of the nature of the devices supported by iOS, there are some frameworks, both public and private, that are specific to iOS.

The following summarizes some of the frameworks found at each layer of iOS, starting from the foundation layer.

+   - Core OS. This level contains the kernel, the file system, networking infrastructure, security, power management, and a device drivers. It also has the libsystem library, which supports POSIX/BSD 4.4/C99 APIs and includes system-level APIs for many tasks.
- Core Services. The frameworks in this layer provide core services, such as string manipulation, collection management, networking utilities, contact management, and preferences. They also provide services based on hardware features of a device, such as the GPS, accelerometer, and gyroscope. Examples of frameworks in this layer are Core Location, Core Motion, and System Configuration.

This layer includes both Foundation and Core Foundation, which provide abstractions for common data types such as strings and collections. The Core Framework layer also contains Core Data, a framework for object management and persistence.

+   - Media. The frameworks and services in this layer depend on the Core Services layer and provide graphical and multimedia services to Cocoa. They include Core Graphics, Text, OpenGL ES, Core Animation, AVFoundation, Core Audio, and video playback.

+   - Core Touch. The frameworks in this layer directly support applications in iOS. They include frameworks such as Game Kit, Map Kit, and Iad.

The Cocoa Touch layer and the Core Services each have an Objective-C framework that is especially important for developing applications for iOS. These are the core frameworks in iOS:

+   - UIKit. The framework provides object displays in your user interface and defines the structure for application, including event handling and drawing. For a description of UIKit, see "UIKit (iOS)" (page 44).

+   - Foundation. This framework defines the behavior of objects, establishes mechanisms for management, and provides objects for primitive data types, collections, and operating-system services. Foundation is essentially an object-oriented version of the Cocoa framework; see "Foundation" (page 30) for a discussion of the Foundation framework.

> Notes: This document uses "Cocoa" generally referring to things that are common between the platforms. When it is necessary to say something about Cocoa on a given platform, it uses a phrase such as "Cocoa in Mac OS X"
