# Cocoa Objects

+   - The subclass and class methods (class and instance) return the receiver's superclass class, respectively, as Class objects.

+   - You can determine the class membership of objects with the methods isKindOfClass: and isMemberOfClass;; the latter method is for testing whether the receiver is an instance of the specified class. The method subclassOfClass: tests inheritance.

+   - The respondsToSelector: method tests whether the receiver implements a method by a selector. The class method instancesRespondToSelector: tests whether instances of given class implement the specified method.

+   - The conformsToProtocol: method tests whether the receiver (object or class) conforms to a given protocol.

+   - The isEqual: and hash methods are used in object comparison.

+   - The description method allows an object to return a string describing its contents; this is often used in debugging (the print-object command) and the @ specifier for objects in formatted strings.

See "Introspection" (page 87) for more information.

**Object encoding and decoding.** The following methods permit to object encoding and decoding (as part of the archiving process):

+   - The encodeWithCoder: and initWithCoder: are the sole members of the NSCoding protocol. The first allows an object to encode its variables and the second enables an object to initialize from decoded instance variables.

+   - The NSObject declares other methods related to object encoding: classCoder, replacementObjectForCoder;; and awakeAfterDecoding:

See Archiving and Serializations Programming Guide for further information.

+   - **Message forwarding.** The forwardInvocation: method permit object to forward a message to another object.

+   - **Message dispatch.** A set of methods beginning with performSelector allows you to dispatch messages after a specified delay and dispatch messages (synchronously or asynchronously) from a secondary thread to the main thread.

NSObject has several other methods, including class methods for versioning and posting (the latter a class present itself to the runtime as another class). It also includes methods that you access runtime structures, such as method selectors and function pointers to method implementations.
