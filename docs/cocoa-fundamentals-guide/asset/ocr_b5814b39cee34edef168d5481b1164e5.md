# CHAPTER 1

What Is Cocoa?

> **iOS Note:** Cocoa for iOS supports application development and not development of any kind of executable.

You can use several programming languages when developing Cocoa software, but the essential, required language is Objective-C: a superset of ANSI C that has been extended with certain syntactical and semantic features (derived from Smalltalk) to support object-oriented programming. The few added conventions are easy to learn and use. Because Objective-C rests on a foundation of ANSI C, you can freely interact strict C with Objective-C code. Moreover, you can call functions in non-Cocoa programmatic interfaces in `/usr/include`. You can even mix C++ code with your Cocoa and link the compiled code into the same executable.

**Mac OS Note:** In Mac OS, you can also program in Cocoa using scripting bridges such as PyObj (the Python-Objective C bridge) and RubyCocoa (the Ruby-Cocoa bridge). Both bridged languages let you write Cocoa applications in scripting scripting. Both of these are interpreted, interactive, and object-oriented programming languages make it possible for Python or Ruby objects to send messages to Objective-C objects as they were Python or Ruby objects, and for Objective-C objects to send messages to Python or Ruby objects. For more information, see *Ruby and Python Programming for Mac OS X*.

The most important Cocoa libraries are packaged in two core frameworks for each framework: Foundation and AppKit for Mac OS X, and Foundation and UIKit for iOS. As all frameworks, these contain not only a dynamically shared library (or several versions of libraries required for backward compatibility), header files, API documentation, and related resources. The powering of Foundation with AppKit or UIKit reflects the division of Cocoa programmatic interfaces into those classes that are not related to a general user interface and those that. For each platform, its core frameworks are essential to any Cocoa project whose end product is application. Both platforms additionally support the *Core Data* framework, which is important and useful as the core frameworks.

Mac OS X also ships several other frameworks that publish Cocoa programmatic interfaces, such as the WebKit and Foundation Book frameworks; more Cocoa frameworks will be added to the operating system over time. See "The Cocoa Frameworks" (page 29) for further information.
