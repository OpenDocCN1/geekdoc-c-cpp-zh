Inherited initializers are a concern when you create a subclass. Sometimes a superclass init... method sufficiently initializes instances of your class. Because it is more likely it won, you should override the superclass's initializer. If you don't, the superclass's implementation is invoked, and because the superclass knows nothing about your class, your instances may not be correctly initialized.

# Multiple Initializers and the Designated Initializer

A class can define more than one initializer. Multiple initializers let clients of class provide the input for the same initialization in different forms. The NSSet class, offers several initializers that accept the same data in different forms; one an NSArray, another a count, a nil-terminated list of elements:

+   - (id)initWithArray:(NSArray *)array;
- (id)initWithObjects:(id *)objects count:(unsigned)count;
- (id)initObject:(id)firstObj
