# CHAPTER 5

Communicating with Objects

Control objects do not (and should not) retain their targets. However, clients of controls sending action messages (applications), are responsible for ensuring that their targets are able to receive action messages. To do this, they may have to retain their targets in memory-managed environments. This precaution applies equally to delegates and data sources.

# The Action

An action is a message control sends to the target, or from the perspective of the target, the method implements to respond to the action message. A control or sel is frequently the case in AppKit—a control's own action is an instance variable of SEL An Objective-C type used to specify the signature of a message. An action message must have a simple, distinct signature. The method it invokes nothing and has also some parameter of type id. By convention, it is named sender. Here is an example of NSResponder class, which defines a number of action methods:

```
(void)capitalize:(id)sender;
```

Action methods declared by Cocoa classes can also have the following signature:

```
(IBAction)delete:(id)sender;
```

In this case, IBAction does not designate a type for a return value; no is returned. IBAction is a type qualifier that Interface Builder notices during application development to synchronize actions added programmatically with one of action methods defined for a control.

> iOS Note: In UIKit, action selectors can also take other forms. See "Target-Action in UIKit" (page 186) for details.

The sender parameter identifies the control sending the action message (although it can be another object substituted by the actual sender). The idea behind this is similar to a return address on a postcard. The target can query for more information if it needs to. If the actual sender substitutes another object, you should treat that as the own. For example, if you have a text field and when the user enters, the action method nameEntered is invoked in the target:

```
(void)nameEntered:(id)sender
NSString *name = [sender stringValue];
if ([name isEqualToString:@"*"]) {
MutMutableArray *names = [sender nameList];
[names addObject:name];
[sender setNSString:@"*"];
}
```

Here the method extracts the contents of the text field, adding the string to an array cached as an instance variable, and clears the field. Other queries to the sender would be asking an NSMatrix object for its selected row ([sender selectedRow]), asking an NSButton for its state ([sender state]), and asking any cell associated with a control for its tag ([sender cell tag]), a tag being a numeric identifier.
