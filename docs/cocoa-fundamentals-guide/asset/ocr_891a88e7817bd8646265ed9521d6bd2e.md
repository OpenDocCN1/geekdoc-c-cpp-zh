What Is Cocoa?

The drawing models are similar for AppKit and UIKit. Animation is integrated into the UIKit drawing implementation. The programmatic software UIKit directly provides for drawing a bit more limited compared to AppKit. The framework offers classes and functions for Bezier paths, PDF generation, and unattached line and rectangle drawing (through functions in Uraphics.h). You use UIColor objects to set colors in the current graphics context and UIImage objects to represent and encapsulate them. For drawing greater sophistication, an application must use the Core Graphics or OpenGL ES.

# General User-Interface Classes

Objects on an iOS interface are visibly different from those on a Mac X user interface. Because of the nature of the device—specifically the smaller size and the use of fingers instead of the mouse and keyboard for—user objects in iOS are typically larger (to be an adequate target for touches) at the same time as efficient use of real estate is possible. These objects are sometimes based on visual and tactile analogs of an entirely different sort. For example, consider the date picker object, which is instantiated from a class that both the UIKit and AppKit frameworks define. In Mac OS X, the date picker looks like:

![](bbox=[0.181, 0.376, 0.333, 0.408])

This style of date picker has two tiny areas for incrementing date components, and thus is suited to manipulation by a mouse pointer. Contrast with this date picker in iOS applications:

| Jan 29 | 1 |
| Wed 30 | 2 54 AM |
| Today | 3 55 PM |
| Fri 1 | 4 56 |
| Sat 2 | 5 57 |

This style of date picker is more suited for finger touches as an input source; you can swipe a month, or row column to spin it to a new value.

As AppKit controls, many of UIKit classes fall into functional groups:

+   - **Controls.** The subclasses of UIColor instantiate objects that users communicate their intent to an application. In addition to the standard button object (UIButton) and slider object (UISider), there is a control that switches off/on (UISwitch), a spinning-wheel for selecting multidimensional values of (UIView), a control for paging through documents (UIPageControl), and others.
- **Modal.** These two classes inheriting from UIView are for displaying messages to users either in the form of "sheets" attached to views or windows (UIActionSheet) or as an unattached alert dialog (UIAlert). On iPad, an application can use popovers (UIPoverController) instead of sheets.
- **Scroll.** The UIScrollView class enables instances of its subclasses to respond to touches within large views. As users scroll, the scroll view displays indicators of position within the document. The subclass implementation varies table views, text views, and web views.
