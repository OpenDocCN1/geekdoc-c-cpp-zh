What Is Cocoa?

Xcode builds projects from source code written in C, C++, Objective-C, and Objective-C++. It generates executables of all types supported in Mac OS X including command-line tools, plugins, extensions, and applications. (For iOS, only application executables are possible) Xcode permits almost unlimited configuration of building and debugging tools, executable packaging (including property lists and localized bundles), build processes (including copy-file, script-file, and other phases), and the user interface (including detached and multiple code editors). Xcode also supports various source-code management systems— CVS, Subversion, and Perforce—allowing you to add files to a repository, commit changes, updated versions, and compare versions.
