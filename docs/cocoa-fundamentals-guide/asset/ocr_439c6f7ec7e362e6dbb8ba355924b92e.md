# Communicating with Objects

> Note: Most of the classes of the Cocoa frameworks are compliant with key-value-coding. Some are key-value observing; check the reference documentation for details.

You can also establish bindings programmatically but for most situations you use the Interface Builder application to establish bindings. In Interface Builder, you start dragging NSController objects from the library into your nib file. Then use the Bindings pane of the Info window to specify the relationships between the properties of the view, controller, and model objects of your application and the attributes you want bound.

Figure 5-5 gives an example of binding. It shows the "Tax" column of the top window bound to the model attribute taxable, where the controller is TransactionsController (an NSArray object); the controller is itself bound to an array of model objects (not shown).
