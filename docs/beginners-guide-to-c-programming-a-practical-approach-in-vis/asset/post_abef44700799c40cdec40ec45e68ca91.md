The program crashed and Visual Studio has shown the error in the code editor saying that "Input string was not in a correct format". Since the program has crashed, we cannot quit it by clicking the cross button at its top right. Instead, we have to close using the usual stop button in Visual Studio. However if the user runs this program by double-clicking on it outside of Visual Studio, he/she will not have these opportunities. This is where try-catch statement comes into play.

- 8. We will cover our code lines inside the try-catch block by modifying the event handler method of Code 14.3 as follows:

```csharp
private void multiplyButton_Click(object sender, EventArgs e)
{
    try
    {
        int inputNum = Convert.ToInt32(input.Text);
        int result = 2 * inputNum;
        output.Text = result.ToString();
    }
    catch (Exception exceptionObject)
    {
        MessageBox.Show(exceptionObject.ToString());
    }
}
```

Code 14.4

When we type try and press Tab key twice on the keyboard, the try-catch structure is formed automatically.

In this code, the program will try to do the required operation. If something fails, the error will be caught in the catch block. The argument of the catch keyword is the exceptionObject which is an instance of Exception. The information regarding the error is recorded in this object. Thanks to this, we can display the contents of the error by the code line MessageBox.Show(exceptionObject.ToString());
