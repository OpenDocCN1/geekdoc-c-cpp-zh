# 6.3.3. TabControl

TabControl provides a tabbed layout similar to the tabs we use in Internet browsers. The advantage of the TabControl is that we can use the form area effectively, he same area is used multiple times. Furthermore, the user may switch different tabs easier compared to opening and closing different forms in an application. Commonly used properties of the TabControl are as follows:

+   - **SizeMode**: Sets the sizing of tabs. It may take the following values: **Normal**, **FillToRight** and **Fixed**.
+   - **MultiLine**: Sets if more than one row of tabs are permitted or not.
+   - **TabPages**: Sets the Names of the tabs.

Let's use TabControl in a simple example. We'll enter text in a TextBox in the first tab and this text will be displayed in all capitals on a Label in the second tab.
