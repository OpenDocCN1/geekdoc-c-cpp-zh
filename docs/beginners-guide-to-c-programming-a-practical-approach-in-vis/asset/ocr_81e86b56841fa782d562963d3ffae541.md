# 2.3. Main Panes and Menus of the IDE

The main sections of this window are: Get Started, File Opening Tools, Developer News and the Solution Explorer from left to right. We can access the documents and new features of Visual Studio from the Get Started section. Open/New Project part is for opening/creating new files or projects. Developer News section shows developer news from the Microsoft's website. Solution Explorer lists files of a project; it is currently empty since we haven't opened any projects yet.
