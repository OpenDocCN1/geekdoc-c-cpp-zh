## 5.8. ListBox

ListBox 显示项目列表。它用于向用户显示项目并让用户从中选择项目。项目可以在开发期间以可视方式添加到 ListBox，也可以在运行时以编程方式添加。

ListBox 常用属性和方法如下：

> 我们到目前为止多次提到过 **methods**。如您所注意到的，它们用于执行功能。请注意，方法在其后使用括号，如下所示。

- **Clear()**: 从 ListBox 中删除所有项目。
