The main properties of LinkLabels are as follows:

+   - **LinkColor**: Sets the text colour of the LinkLabel.
+   - **VisitedLinkColor**: The colour of the LinkLabel after the link is visited by the user.
+   - **LinkBehavior**: Sets if the link will be underlined or not.
