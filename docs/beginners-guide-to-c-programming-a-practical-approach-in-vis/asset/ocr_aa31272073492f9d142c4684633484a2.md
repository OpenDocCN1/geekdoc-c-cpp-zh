# 7.1.3. Variable Types

Variable types define the type of variables and the amount of allocated space in memory for these variables. Variable types in C# can be classified in three categories: numeric variable types, character variable types and other variable types. Firstly, let’s see these variable groups in three separate tables:

| Data type | Value range | Allocated memory |
|---|---|---|
| byte | 0-255 | 1 byte (8 bits) |
| sbyte | -128-127 | 1 byte (8 bits) |
| short | -32768-32767 | 2 bytes (16 bits) |
| ushort | 0-65535 | 2 bytes (16 bits) |
| int | -2,147,482,648 - 2,147,482,647 | 4 bytes (32 bits) |
| uint | 0-4,294,967,295 | 4 bytes (32 bits) |
| long | 9,223,372,036,854,775,808 - 9,223,372,036,854,775,807 | 8 bytes (64 bits) |
| ulong | 0-18,446,744,073,709,551,615 | 8 bytes (64 bits) |
| float | ±1.5×10⁻⁴⁵ ~ ±3.4×10³⁸ | 4 bytes (32 bits) |
| double | ±5×10⁻³²⁴ ~ ±1.7×10³⁰⁸ | 8 bytes (64 bits) |
| decimal | ±1×10⁻²⁸ ~ ±7.9×10²⁸ | 16 bytes (128 bits) |
