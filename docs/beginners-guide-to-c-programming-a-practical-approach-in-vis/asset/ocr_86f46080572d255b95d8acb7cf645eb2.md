# 6.2. Dialog Type Controls

Dialog type controls provide small dialogs for the user to make a selection.

# 6.2.1. ColorDialog

ColorDialogs are used for selecting a colour. It has the following important properties:

+   - **DialogResult**: The type of the returned colour value.
+   - **ShowDialog**: Used for displaying the dialog window.

Let’s use a ColorDialog to set the background colour of the form in an example:

+   1. Create a C# project in Visual Studio.
+   2. Drag&drop a ColourDialog to the form. It will appear in the pane below the form. Set its Name property as selectColourDialog.
