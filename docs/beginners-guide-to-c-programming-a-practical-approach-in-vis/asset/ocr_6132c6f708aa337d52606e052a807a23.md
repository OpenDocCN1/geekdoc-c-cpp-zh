Since the method will output an integer value, its return type is set as int just after the public keyword. Then written the name of the method: FindGreater. After the name, the parameters (inputs) of the method are declared, number1 and number2 which are both integer type variables. We’ll write the contents of the method inside curly brackets to form the method body:

```
public int FindGreater(int number1, int number2)
{
    int greater;
    if (number1 > number2)
    {
        greater = number1;
    }
    else
    {
        greater = number2;
    }
    return greater;
}
```

Code 11.3

We declared an integer variable inside the method called greater which will hold the value of the greater variable. Then we used a simple if-else structure to determine the greater number and assigned it to the variable greater. Finally we returned the greater variable with the keyword return in the code line return greater;. Note that we use the return keyword to return (output) a value from a method.
