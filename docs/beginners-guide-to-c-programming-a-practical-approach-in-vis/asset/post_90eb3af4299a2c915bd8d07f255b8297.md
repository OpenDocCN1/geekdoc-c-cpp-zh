## 9.4. The Do-While Loop

Do-while loops are similar to while loops. Their difference is that the loop condition is checked at the end of the loop block in a do-while structure as follows:

```
loop variable initialization
do
{
    The code that will be repeated will be written here.
    Loop variable change (usually increment/decrement).
}
while(loop condition)
```

Code 9.21

As it is seen from this template, when the do-while loop begins, the loop block executes once and then the loop condition is checked. If this condition is satisfied, the loop continues. And as in the while loop, the loop ends when the loop condition is not satisfied. The do-while loop executes at least once as you can see from this code structure.

## 9.5. Break and Continue Keywords

We have used the break keyword in conditional statements. It can also be used for the same manner in loops. When the break keyword is executed inside the loop block, the loop immediately ends, i.e. the break keyword breaks the loop.

There is another keyword used in loops: continue. The continue keyword does a similar job as the break keyword. It stops the execution of the current loop block and skips to beginning of the loop. Both break and continue keywords are used in conjunction with conditional statements in loops.

Let’s use these keywords in our while loop example.

- 1. Open the while loop project and find the populateButton_Click(...) method as in Code 9.25.

```csharp

{
    int stopValueInt = Convert.ToInt32(stopValue.Text);
    int i = 0;
    while (i <= stopValueInt)
    {
        numbersComboBox.Items.Add(i);
        i++;
    }
}
```

Code 9.25 (cont’d)

- 2. Let’s skip to the beginning when the loop variable is 3 using the continue keyword:

```csharp
private void populateButton_Click(object sender, EventArgs e)

}
```

### Why does the program go into an infinite loop?

At i=3, the if condition is satisfied and the continue command is executed. The program jumps to the start of the loop with i=3, the if condition is again satisfied with i=3, the continue keyword is executed again jumping the program to the start of the loop with i=3... This procedure repeats over and over causing an infinite loop. We simply need to update the loop variable before the continue command inside the if block as follows to get rid of this programming error

```csharp
private void populateButton_Click(object sender, EventArgs e)
{
    int stopValueInt = Convert.ToInt32(stopValue.Text);
    int i = 0;
    while (i <= stopValueInt)
    {
        if (i==3)
        {
            i++;
            continue;
        }
        numbersComboBox.Items.Add(i);
        i++;
    }
}
```

Code 9.27 (cont'd)

After this modification, we can run the program and it works fine. When i=3, the condition of the if statement is satisfied, the loop variable is increased to 4 and then the program skips to the beginning of the loop with this new loop variable value. The value 3 is not added to the ComboBox because the program skips to the beginning of the loop at i=3 without executing the code lines below the if statement:

## 10.1. Arrays

Arrays make our lives easier by enabling to save same type data in a list format so that we can access them easily using an index. We can imagine the structure of an array as follows:

| Index | 0 | 1 | 2 | 3 | 4 | ... | n-1 |
| Element | 1st element | 2nd element | 3rd element | 4th element | 5th element | ... | nth element |

Table 10.1. Typical array structure

As you can see, each element of an array has an index starting from 0. This is a rule, therefore for an n element array, the indices of its elements will take the values of 0, 1, 2, ..., n-1.
