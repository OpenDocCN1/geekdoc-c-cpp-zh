# 12.5. Property Structures

We can send and read value from a class using property structures.
There are two blocks in a property structure: set and get. The set block sets a variable while the get block reads the value of the same variable.
The template of the typical property structure is as follows:

```
public string property_name
{
    get
    {
        return code; // The value of the property read here
    }
}
```
