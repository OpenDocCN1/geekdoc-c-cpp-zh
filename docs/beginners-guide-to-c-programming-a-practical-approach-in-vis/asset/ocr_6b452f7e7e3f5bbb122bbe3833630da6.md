# 5.11. MonthCalendar

This control shows calendar in month format so that the user can pick a date from it. MonthCalendar is similar to DateTimePicker. Their difference is that MonthCalendar's calendar view is always open for selecting a date, while the user needs to click on the DateTimePicker to open the view to select date.
