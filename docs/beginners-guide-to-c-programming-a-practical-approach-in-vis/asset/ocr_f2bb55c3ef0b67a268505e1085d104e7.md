The **Change colour** and **Exit** menu items (buttons) are under the **File** menu as shown above. The reason of inserting & symbols in these names is assigning shortcut keys to these items. When the user presses **Alt+(shortcut letter)** on the keyboard, the respective menu item will be activated. In this example, when the user presses **Alt+F**, the File menu will open; and then if **Alt+C** is pressed, the **Change colour** item will be selected, and with the **Alt+X** combination, **Exit** item will be activated. The shortcut letter is shown as underlined as you can see in Figure 6.2. We can assign any letter as the shortcut. Conventionally, the **X** letter is assigned to the **Exit** item in desktop applications, as we did in this example.
