# 11.6. Passing Arrays to Methods

When the number of parameters (inputs) is unknown at the time of programming, these parameters are passed as arrays. The keyword params is used for this operation. Let's use this property in a simple project. We'll declare a method which multiplies numbers where it will multiply the any number of inputs entered by the user.
