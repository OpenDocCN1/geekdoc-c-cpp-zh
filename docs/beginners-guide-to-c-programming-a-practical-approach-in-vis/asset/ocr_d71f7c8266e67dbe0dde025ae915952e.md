# 5.18. TextBox

TextBoxes are probably the most frequently used controls after the Button in Windows Forms applications. TextBoxes are simply used to gather text input from the user. It has the following important properties:

+   - **MultiLine**: Sets if the text input may span multiple lines.
+   - **WordWrap**: If the text overflows single line, it will automatically be wrapped to the next line.
+   - **ScrollBars**: Sets if the text scrolling bars will be visible.

In our example, we'll gather text from multiple TextBoxes and merge them before adding to a ListBox.
