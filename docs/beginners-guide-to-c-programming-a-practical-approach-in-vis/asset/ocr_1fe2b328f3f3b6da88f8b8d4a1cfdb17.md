# 6.3.5. SplitContainer

SplitContainer is used to divide the form in two vertical or horizontal panels. The sizes of these dividing panels are resizable.

Let's use a SplitContainer to divide a form in an example:

+   1. Create a C# project.
+   2. Add a SplitContainer to the form. The SplitContainer will divide the form in two panels as follows:

![](bbox=[0.35, 0.38, 0.65, 0.6])

Figure 6.69. SplitContainer divides the form to two vertical panels by default

3. The SplitContainer divides the whole form to two vertical panels by default. We can change these settings from the SplitContainer Tasks dialog which is opened by clicking the arrow on the SplitContainer as follows:
