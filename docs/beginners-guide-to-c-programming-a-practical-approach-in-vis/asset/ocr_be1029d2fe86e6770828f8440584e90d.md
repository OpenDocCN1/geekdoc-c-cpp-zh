7. When the Add Info Button is clicked, the Texts of the TextBoxes will be read, merged and added to the ListBox. For this, create the default event handler of the button, addInfoButton_Click(…), by double-clicking on it and add the following code:

```
private void addInfoButton_Click(object sender, EventArgs e)
{
    infoListBox.Items.Add(nameTextBox.Text + "-" + lessonTextBox.Text + "-" + gradeTextBox.Text);
    nameTextBox.Clear();
    lessonTextBox.Clear();
    gradeTextBox.Clear();
}
```

Code 5.26

In the first line, merged texts are passed to the Add() method for performing addition to the ListBox. In this operation, the + operators merge texts. Moreover, hyphens (-) are placed between the texts. It is worth noting that hyphens are written inside double quotes to tell Visual Studio that hyphens should be considered as texts.

After adding merged texts to the ListBox, TextBoxes are cleared by applying the method Clear(). Therefore, all TextBoxes are cleared without user intervention making them ready for entering new inputs.
