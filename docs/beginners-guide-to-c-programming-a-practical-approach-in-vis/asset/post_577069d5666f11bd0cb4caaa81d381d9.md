```
## 11.5.2. Call by Reference

When a variable is passed to a method by reference, the original variable itself (not its copy) is passed to the method. Therefore if it is altered in the method, the value of the original variable will also be affected. Variables are passed by value by default. If we want to pass by reference, we need to use the ref keyword in front of these variables in method

```
CallByReference(ref myString);
MessageBox.Show("Value of the string after passed to CallByReference() method: " + myString);
}
