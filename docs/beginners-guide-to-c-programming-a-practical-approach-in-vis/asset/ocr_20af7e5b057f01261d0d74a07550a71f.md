# 16.5. Exporting the Game as a Standalone Program

We developed our Random Platformer and can play it inside Unity. However, we have to be able to distribute the game as an executable file so that any gamer can play it. Exporting our game is straightforward in Unity. For this, click File → Build Settings:

![](bbox=[0.35, 0.32, 0.68, 0.6])

Figure 16.86. Launching the Build Settings dialog

In the dialog, select the Platform as PC, Mac, Linux Standalone and set the target platform as Windows. Then, click the Build button:
