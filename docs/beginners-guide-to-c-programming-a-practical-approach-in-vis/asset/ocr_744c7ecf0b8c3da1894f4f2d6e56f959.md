# 5.15. ProgressBar

ProgressBar is used for displaying the progress during an operation. It has the following commonly used properties:

+   - **Minimum**: Minimum value of the ProgressBar.
+   - **Maximum**: Maximum value of the ProgressBar.
+   - **Step**: Incremental value of the ProgressBar.

Let’s see a ProgressBar in action in a simple example:

+   1. Create a new C# project in Visual Studio.
+   2. Place a ProgressBar, a Button and a ListBox on the form as follows:
