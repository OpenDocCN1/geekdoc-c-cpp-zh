### 3.3. Files Included in the Project

Let's also overview our project files in the Windows Explorer. Please navigate to the folder you created for your project and open it in Windows to see the contents as below:

![](img/41d82527c4e41cdb7e56259564306ddc_31_0.png)

Figure 3.11. Files and folders in the project directory

As you can see, there are several files and folders in our project directory. The widely used file extensions and associated file properties can be summarized as follows:

- **.cs files:** These are the source code files for C# projects. cs is an abbreviation for c sharp.
- **.sln files:** These are **solution** files. They contain the project information. Saved projects are opened via their .sln files.
- **.resx files:** These are resource files that hold information regarding the resources (such as strings) we add to the projects.
