# 5.16. RadioButton

RadioButtons are used for selecting among different options.

> RadioButtons are similar to CheckBoxes however only one RadioButton can be selected in a form or group at a time.

The frequently used properties of RadioButtons are as follows:

+   - **Checked:** Sets if the RadioButton will be checked initially.
+   - **AutoCheck:** Sets if the RadioButton will automatically be selected when clicked.
+   - **Enabled:** Sets if the RadioButton will be available for checking.
