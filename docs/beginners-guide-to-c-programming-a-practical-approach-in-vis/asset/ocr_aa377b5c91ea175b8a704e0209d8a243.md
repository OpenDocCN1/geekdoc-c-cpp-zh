# 7.1.5. String Conversions

We frequently need to convert string type variables to others and vice versa because form controls generally use string type input and output. Examples include TextBox and Label. The data read from them are strings and we need to use strings to update their Text properties. On the other hand, string type variables cannot be converted implicitly or explicitly to others because the sizes of the string type variables are not fixed. Therefore, we use special methods to convert string types to others and other types to strings.

# 7.1.5.1. From String to Other Types

There are two ways for converting string type data to other types: Parse() and the methods of the Convert class.

+   - **Parse():** This method is used in the following way:

```
variable_type.Parse(string to be converted)
```
