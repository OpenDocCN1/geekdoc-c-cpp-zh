如你所见，项目目录中有多个文件和文件夹。常用的文件扩展名及相关文件属性可总结如下：

- **.cs 文件：**这些是 C# 项目的源代码文件。cs 是 c sharp 的缩写。

### 3.4. 在窗体上添加标签控件

我们的目标是在应用程序中显示“Hello, World!”文本。因此，我们需要在窗体上添加一个能够在窗体上显示文本的窗体控件。
