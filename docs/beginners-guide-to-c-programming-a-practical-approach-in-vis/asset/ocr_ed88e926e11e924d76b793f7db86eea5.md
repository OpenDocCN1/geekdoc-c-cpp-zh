# LOOPS

Loops are used when a code line or code block has to be executed multiple times depending on a condition. For example, consider a database with name entries in it. If we want to display all the names one by one, we would do it in the following way:

```
MessageBox.Show(entry 1);
MessageBox.Show(entry 2);
MessageBox.Show(entry 3);
.
MessageBox.Show(entry n-1);
MessageBox.Show(entry n);
```

Code 9.1

In this code, entries refer to the data in the database. As you can see, the number of code lines would be intractable. Instead, we can do the same job using a loop in a more elegant and easier way:

```
for(each entry in the database)
{
MessageBox.Show(current entry);
}
```
