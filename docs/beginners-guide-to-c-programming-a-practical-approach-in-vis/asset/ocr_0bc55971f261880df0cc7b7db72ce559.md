# 2.1. Downloading and Installing Visual Studio

Please navigate to https://www.visualstudio.com/downloads/ in your web browser. You'll see the download page shown in Figure 2.1.

![](bbox=[0.15, 0.26, 0.85, 0.46])

Figure 2.1. Visual Studio download options

Click on the Free download button of the Visual Studio Community edition. This will initiate the download of the online installer having the size of a few megabytes. Double click on the downloaded file and then you'll get the following message:

![](bbox=[0.35, 0.7, 0.65, 0.82])

Figure 2.2. Visual Studio installation – first message

Please click Continue in this message if you agree to the terms so that the installer will start preparing the installation:

![](bbox=[0.35, 0.8, 0.65, 0.92])

Figure 2.3. Visual Studio installation – second message
