# 7.1.2. Rules about Variable Naming

We cannot use any name we want as a variable name. Here are the basic rules on variable naming:

+   - Variable names cannot include space(s). For example, the declaration:

```
int my integer;
```

Code 7.6

is illegal since there is a space between the characters y and i in the variable name. If we want to use such a name, we may use a hyphen (-) or underscore (_) for this aim as follows:

```
int my_integer;
int my-integer;
```

Code 7.7

+   - Variable names cannot start with numbers or special characters. They have to start with a letter. The declaration:

```
int 8segment;
```

Code 7.8

is wrong. However we may include numbers or special characters after the first character of the variable name as follows:

```
int segment8to2_a;
```

Code 7.9

+   - Variable names in C# are case-sensitive. The variable my_integer and My_integer refer to different variables.
+   - Variable names cannot be selected from C# keywords. For example, the keyword continue cannot be used as a variable name. C# has about 75 keywords. Therefore it is in general unlikely to choose one of them as a variable name. You may refer to the C# keywords list from the website https://docs.microsoft.com/en-us/dotnet/articles/csharp/language-reference/keywords/ when you are in doubt about this.
