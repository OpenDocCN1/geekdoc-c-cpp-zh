Let's now try to understand what these code lines mean. The first line changeButton.Text = "Clicked!"; means “Set the Text property of the control named changeButton to "Clicked!" ”. You can see that the texts are written inside double quotes in C#. Moreover, each code line should be terminated by a semicolon. These are important rules.

The second line, this.BackColor = Color.White; means that “Set the background colour of this to white.” Here, this refers to the form itself. Therefore, these two lines will change the text of the button to “Clicked!” and the background colour of the form to white when the button's Click event happens.
