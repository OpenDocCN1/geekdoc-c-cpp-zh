# 10.2.2. ArrayList

ArrayLists are collection types which are flexible alternatives to usual arrays. ArrayLists have two main advantages: they can hold different data types and they resize automatically as new elements are added or removed. Since the length of an ArrayList is dynamic, their length is not specified during declaration. Another advantage of ArrayLists is that there are various useful methods enabling us to alter the ordering of the structure dynamically.

ArrayLists have integer indices which start from 0 as in usual arrays.
