# 2.1.1 The Principal Role

+   - ✓ Explain what a main function is, which is the starting point of every C program.
+   - ✓ What does the int return type mean, and what is the necessary syntax?
+   - ✓ To show how a basic program is executed, provide examples of simple main functions.

# 2.1.2 Files for Headers

+   - ✓ In a C program, talk about the function of header files (#include).
+   - ✓ The purpose of user-defined headers and common standard library headers (such as stdio.h and stdlib.h) should be explain.
+   - ✓ Assist readers in adding the headers that their applications need.

# 2.1.3 Notes and Recordkeeping

+   - ✓ In order to improve code readability and documentation, emphasize the significance of comments.
+   - ✓ Use of single- and multi-line (/* */) comments and // are shown.
+   - ✓ To clarify the rationale of the code, encourage the habit of contributing insightful comments.

# 2.1.4 Statements and Declarations

+   - ✓ Talk about how statements and declarations vary in C.
+   - ✓ Describe how declarations are used to declare the data types that variables may contain.
+   - ✓ Introduce basic expressions, assignments, and function calls.
