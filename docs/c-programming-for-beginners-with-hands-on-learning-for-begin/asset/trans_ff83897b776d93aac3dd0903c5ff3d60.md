### 1.1 编程语言概述

计算机可以通过编程语言从人类接收指令。每种编程语言都是为特定工作或目的而设计的，具有自己的语法、语义和用途。我们将在本部分探讨编程语言的更广阔世界，然后特别集中于 C。

- 探讨编程语言的历史演变，从早期的汇编和机器码开始。

- 突出编程历史中的重要转折点，例如过程式语言的发展以及 Fortran、COBOL 和 Lisp 的使用。

#### 1.1.2 编程语言类型

- 根据这些范式将编程语言分为命令式、面向对象、函数式和声明式类别。
- 讨论每个范式的特性和应用。
- 描述高级语言和低级语言之间的差异。

#### 1.1.3 编程语言的分类

- 根据所使用的应用将语言分为通用、脚本、系统编程、Web 开发等类别。
- 考察领域特定语言（DSL）在细分市场中的作用。

#### 1.1.4 编程语言的流行度与趋势

### 1.2 为什么学习 C？

学习一门编程语言需要时间和精力，最佳语言取决于你的目标和需要完成的任务。本节将探讨人们投入时间掌握 C 编程语言的强有力论据。

#### 1.2.1 其他语言的基础

谈谈 C 如何成为一门基础语言，影响 Java 等语言，并作为 C++、C# 和 Objective-C 等众多语言的基础。

告诉他们学习 C 可以为他们学习低级操作和内存管理提供坚实的概念基础。

#### 1.2.2 效率与成就

- 由于 C 专注于效率和性能，因此是系统级编程、嵌入式系统和具有严格性能要求的应用程序的首选语言。
- 讨论 C 如何用于设备驱动程序、操作系统和需要高性能的应用程序的创建。

#### 1.2.3 对硬件的控制

描述 C 如何通过为开发人员提供对硬件的完全控制而适用于固件开发和系统编程等工作。

谈谈了解低级操作、指针和内存分配对于需要精细控制的工作至关重要。

#### 1.2.4 稳定性和统一性

- 强调 C 的跨平台可移植性以及设计可在多种平台上无需更改即可运行的代码的重要性。
- 讨论 ANSI C 和后续标准如何有助于保证编程的可移植性和统一性。

#### 1.2.5 大型社区和资源

- 引起注意庞大的 C 编程社区以及用于故障排除和学习的丰富资源。
- 讨论 C 在开源项目、专业开发和学术环境中仍然如此流行的原因。

#### 1.2.6 使用的灵活性

- 发现 C 的多种用途，包括实时系统、高性能计算、游戏创建和操作系统开发。
- 提供用 C 开发的有效系统和项目的实例，以证明其适应性。

#### 1.2.7 职业机会

- 讨论学习 C 可能对你的职业生涯带来的好处，因为许多雇主更青睐具有扎实低级编程背景的应聘者。
- 强调航空、嵌入式系统和网络安全领域对 C 程序员的需求。

- 强调 B 编程语言的影响以及迫使 C 发展的缺点。
