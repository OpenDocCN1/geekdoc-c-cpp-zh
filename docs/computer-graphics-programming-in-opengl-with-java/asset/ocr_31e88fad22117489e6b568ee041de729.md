# ### 4.6.1 Instancing

Instancing provides a mechanism for telling the graphics card to render multiple copies of an object using only a single Java call. This can result in a significant performance benefit, particularly when there are thousands or millions of copies of the object being drawn—such as when rendering many flowers in a field, or many zombies in an army.

We start by changing the glDrawArrays() call in our Java/JOGL application to glDrawArraysInstanced(). Now we can ask OpenGL to draw as many copies as we want. We can specify drawing 24 cubes as follows:

```
```
glDrawArraysInstanced(GL_TRIANGLES, 0, 36, 24);
