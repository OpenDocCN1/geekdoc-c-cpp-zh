Here is an overview of how a display() function using a matrix stack is typically organized:

| Stage | Steps |
|---|---|
| **Setup** | • Instantiate the matrix stack. |
| **Camera** | • Push a new matrix onto the stack. (this will instantiate an empty VIEW matrix.)<br>• Apply transform(s) to the view matrix on the top of the stack. |
| **Parent** | • Push a new matrix onto the stack (this will be the parent MV matrix—for the first parent, it duplicates the view matrix).<br>• Apply transforms to incorporate the parent’s M matrix into the duplicated view matrix.<br>• Send the topmost matrix (“get”) to the MV uniform variable in the vertex shader.<br>• Draw the parent object. |
| **Child** | • Push a new matrix onto the stack. This will be the child’s MV matrix, duplicating the parent MV matrix.<br>• Apply transforms to incorporate the child’s M matrix into the duplicated parent MV matrix.<br>• Send the topmost matrix (“get”) to the MV uniform variable in the vertex shader.<br>• Draw the child object. |
| **Cleanup** | • Pop the child’s MV matrix off the stack.<br>• Pop the parent’s MV matrix off the stack.<br>• Pop the VIEW matrix off the stack. |

Note that the pyramid (“sun”) rotation on its axis is in its own local coordinate space, and should not be allowed to affect the “children” (the planet and moon, in this case).
