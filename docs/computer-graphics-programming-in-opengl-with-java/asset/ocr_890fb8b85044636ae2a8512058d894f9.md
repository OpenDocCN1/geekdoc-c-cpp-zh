# Line primitives:

| Primitive | Description |
|---|---|
| GL_LINES | [示意图：两组独立线段] Vertices that pass through the pipeline form distinct lines:<br><br>*vertices:* 0 1 2 3 4 5 etc.<br><br>*lines:* [线段示意图] |
| GL_LINE_STRIP | [示意图：由连续顶点构成的线段] Each vertex that passes through the pipeline efficiently forms a line with the previous vertex:<br><br>*vertices:* 0 1 2 3 etc.<br><br>*lines:* [线段示意图] |
| GL_LINE_LOOP | Same as GL_LINE_STRIP, except a line is also formed between the very first and very last vertices. |

| GL_LINE_STRIP_ADJACENCY | Similar to GL_LINES_ADJACENCY, except that line vertices overlap as for GL_LINE_STRIP. |
