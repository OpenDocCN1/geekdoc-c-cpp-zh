## 动态分配内存

到目前为止，每当你声明一个变量时，C++ 都会为其分配所需的内存。当创建该变量的函数结束时，C++ 会释放该内存。这种用于局部变量的内存被称为栈。但还有一种内存，它独立于程序中的函数而持续存在。你，也就是程序员，负责分配和释放这种内存，它统称为堆（或自由存储区）。
