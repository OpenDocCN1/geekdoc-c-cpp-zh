# 1. Цель работы

Изучение конструкции и принципа действия гидравлических машин, а также получение навыков работы с ними.

# 2. Теоретическая справка

Гидравлические машины — это устройства, предназначенные для преобразования механической энергии двигателя в энергию потока жидкости или для преобразования энергии потока жидкости в механическую энергию. Основными элементами гидравлических машин являются насосы и гидравлические двигатели.
