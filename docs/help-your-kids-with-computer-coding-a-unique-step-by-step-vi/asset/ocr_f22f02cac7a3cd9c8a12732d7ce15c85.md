Print a silly sentence by running the 'pick' function once each of the three lists. Use the 'print' command to show the sentence on the screen.

Add an 'a' so that the sentence makes sense (see below)

```
print(pick(name), pick(verb), 'a', pick(noun), end='\n')
```

Save and run the program to get a silly sentence made from the lists of names, verbs, and nouns.

This adds a period at the end, while the "\n" starts a new line

# EXPERT TIPS

Readable code
it's very important to write a program that can be easily understood. It makes the program easier to change in the future because you don't have to start by solving the puzzle of how it works!

The program keeps printing silly sentences if the 'print' command is wrapped in a "while" loop.

Wraps the print command in a loop

```
while True:
print(pick(name), pick(verb), 'a', pick(noun), end='\.')
input()
```

Prints a new sentence every time the "Enter" key is pressed

The program will keep on creating random sentences

The "input()" function waits for the user to press the "Enter" key before, printing another sentence. Without it it would print them too fast to read.
