# Unicode

As computers across the world began to share data, the limits of ASCII began to show. Thousands of characters used in hundreds of languages had to be represented, so a universal standard called Unicode was agreed upon.

![](bbox=[0.638, 0.073, 0.934, 0.225])

Unicode has over 110,000 characters!

International code
Unicode represents all the languages of the world. For example, the Arabic characters are represented in the range 0600–06FF.

![](bbox=[0.066, 0.273, 0.178, 0.355])

Unicode characters
Unicode characters are represented by their hexadecimal value, which appears as a series of letters and numbers (see pp.182–183). Each character has its own code. More characters are added all the time, and there are some unusual ones, as a mini umbrella.

Hexadecimals

Hexadecimal numbers have a base of 16. Ordinary decimal numbers are used for 0 to 9, and the values 10–15 are represented by the letters A to F. Each hexadecimal number has an equivalent binary value.

Unicode in Python
Unicode can be used to display special characters in Python. Simply type a string containing a Unicode code.

Putting "u" before the hexadecimal code tells the — computer this is Unicode

The Unicode value of é as hexadecimal
The same value as binary

```
ë = 00EB = 11100111
```

```
>>> 'Zo\u00EB'
'Zoë'
```

The code is translated into the character "ë"
