# Skywriting

In this program, you control a plane. As you fly it will leave a smoke trail, so you can draw the name in the sky. Start a new project and add the plane sprite, then add this script.

You can only use colors that appear on the Scratch interface. To select red, click in the square and then click on the red stop button above the stage

+   - Flying high

Use the left and right keys to turn the plane. Switch on the smoke with the "a" key and turn it off with the "z" key. Press the spacebar to clear the sky.

```

set pen size to 3
forever
move 2 steps

```

# Turtle graphics

Using sprites to draw pictures is called "turtle graphics." That because there's a type of robot called a turtle that can be moved around the floor to draw pictures. The first programming language to use turtle graphics was called LOG.

Rotates right

```
when right arrow key pressed
turn 10 degrees
when left arrow key pressed
turn 10 degrees
when a key pressed
pen down
when z key pressed
pen up
when space key pressed
clear
```
