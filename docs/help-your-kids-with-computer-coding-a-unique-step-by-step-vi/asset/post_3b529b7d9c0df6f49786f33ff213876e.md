
## True or false?

Computers decide what to do by asking questions and determining whether the answers are true or false. Questions that only have two possible answers are called “Boolean expressions”.

## Comparing numbers

You can compare numbers using the "=" block from the “Operators” section of the blocks palette.

## "=" block

This block will give one of two answers: “true” if the two numbers in the boxes are equal, and “false” if they aren’t.

![](img/72d218a7a73c4d4abc7be582ebd85385_63_0.png)

![](img/72d218a7a73c4d4abc7be582ebd85385_63_1.png)

### True answer
Using "=" block in a speech block will make “true” or “false” appear in a sprite’s speech bubble.

### False answer
If the numbers in the block are different, the sprite’s speech bubble will contain the word “false”.

The "not" block can simplify things by reversing the answer of a Boolean expression, it's easier to check if someone's age is not 10 to check if every other possible age.

The "not" block changes the answer around, from true to false and from false to true.

## Decisions and branches

Tests of whether something is true or false can be used to tell the computer what to do. It will perform a different action depending whether the answer is true or false.

## Making decisions

The "if" blocks use Boolean expressions to decide what to do. To use them, put other blocks inside their "jaws". The blocks inside the "if" blocks will only run if the answer is true.

## Using the "if-then" block

The "if-then" block lets you choose whether or not run part of script depending on the answer to a Boolean expression. Attach this script to the sprite out.

![](img/72d218a7a73c4d4abc7be582ebd85385_65_2.png)

```
when clicked ask Do you want to meow? and wait answer = yes play sound meow until done hmm for 2 secs
```

| Is answer? | True | False |
| :--- | :--- | :--- |
| | meow | skip |

- Meowing
This program checks the Boolean expression and will run the part between the "if-then" block's jaws if is true. This means the cat only meows when you tell it to.

- How it works
The program checks whether Boolean expression is true. If it is, it runs the blocks inside the "if-then" block

## Branching instructions

Often you want a program to do one thing if true, and something else if is not. The "if-then-else" block gives a program two possible routes, called "branches". Only one branch will run depending on the answer to the Boolean expression.

## Keyboard controls

Using "Sensing" blocks with "if-then" blocks allows you to move a sprite around the screen using the keyboard. The "key pressed?" block has a menu of most of the keys on the keyboard, so a sprite can be programmed to react to any. You can also link actions to the click of a mouse button.

This block checks if a key is being pressed. You can choose which key to check.

```
key space ▼
```

This block checks if the mouse button is being pressed

```
mouse down?
```

Putting everything inside a "forever" block repeats the checks for key presses

"Sensing" blocks Adding these inside an "if-then" block allows the program to detect if a mouse button or key is being pressed. The script checks to see if the arrow is pressed. If it is, the sprite moves upwards on the

```
when clicked
if key up arrow pressed? then
change y by -10
```

```
if key down arrow pressed? then
change y by -10
```

```
if key left arrow pressed? then
change x by -10
```

