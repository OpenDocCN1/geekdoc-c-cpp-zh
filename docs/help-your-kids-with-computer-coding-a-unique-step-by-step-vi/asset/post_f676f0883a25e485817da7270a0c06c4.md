## Draw a flowchart

Coders often plan programs on paper, to help them write better code with fewer errors. One way to plan is to draw a flowchart—a diagram of the steps and decisions that the program needs to follow.

- This flowchart shows the plan for the Turtle controller function. It takes a letter ("do") and number ("val") and turns them into a turtle command. For example, "F" and "100" will be turned into the command forward(100). If the function doesn't recognize the letter, it reports an error to the user.

Each command has two variables: "do" (a string) tells the turtle what to do, and "val" (an integer, or whole number) tells the turtle how much or how far to do it.

The function has to decide if the "do" value is a letter recognizes.

If "do" isn't, the function runs through other letters it recognizes.

### The Turtle controller

The first part of the program is a function that moves the turtle, one command at a time. It is planned out in the flowchart on the previous page. This code enables the turtle to convert the "do" and "val" values into movement commands.

This code creates the Turtle controller function. It turns "do" inputs into directions for the turtle, and "val" inputs into angles and distances.

![](img/72d218a7a73c4d4abc7be582ebd85385_143_0.png)

- Loads all the commands that control the turtle
- Defines "do" and "val" inputs for the function

```python
from turtle import *
def turtle_controller(do, val):
    do = do.upper()
    if do == 'F':
        forward(val)
    elif do == 'B':
        backward(val)
    elif do == 'R':
        right(val)
    elif do == 'L':
        left(val)
    elif do == 'U':
        penup()
    elif do == 'D':
        pendown(val)
    elif do == 'N':
        reset()
    else:
        print('Unrecognized command ')
```

- This command converts all the letters in "do" to upper case (capital letters).
- This tells the function to turn a "do" value of F into the turtle command "forward".
- As in the flowchart, the function checks the "do" counter against all the letters it understands.
- This command instructs the turtle to stop drawing on the page.
- This command tells the turtle to start drawing on the page.
- This command resets the turtle's position to the center of the screen.
- This message appears if the "do" value is a letter that the function cannot recognize.

## EXPERT TIPS

### Clear coding

It's not only computers that need to be able to read code, it should be clear to people too.

Use functions to break code into chunks.

Give your variables names that make more sense than "aily".

Use plenty of comments (using the "#" symbol) to explain what is happening.

Don't use symbols that can be confused with others: an upper-case "O" looks like zero, a lower-case "L".
