

# 角色碰撞

了解一个角色何时碰到另一个角色是非常有用的——例如在游戏中。使用“感应”（Sensing）模块在角色互相接触时触发事件，或者当角色穿过特定颜色的区域时触发事件。

# 使用“感应”模块

使用“感应”模块将你的可控制猫变成一个游戏。首先，将上一页创建的移动脚本添加到猫角色，然后添加“room1”背景和大象角色。使用“声音”（Sounds）标签页，为大象添加“trumpet2”音效，然后编写它的脚本。

- 找到大象

此脚本使用“感应”模块来控制猫和大象之间的关系。当猫越来越近时，大象会变大。当猫触碰它时，大象会切换装帧、发出声音并隐藏在另一个地方。

![](img/72d218a7a73c4d4abc7be582ebd85385_68_1.png)

> “重复”（forever）循环不断感应并调整大象的大小和位置

> 这检查了猫距离大象有多远

```
when clicked
forever
  set size to 200
  distance to Sprite1 %
  if touching Sprite1 ? then
    switch costume to elephant-b
    play sound trumpet2 until done
    switch costume to elephant-a
  go to x: pick random (-240) to (240) y:
```

猫越远，大象就越小

> 如果角色触碰，“如果”（if-then）模块内部的模块就会运行

> 此模块为大象选择一个随机的隐藏位置

# 等待

如果可以让脚本暂停一下，玩游戏或查看程序运行将会变得更容易。不同的模块可以让脚本等待几秒或等待某事发生。

> 等待模块
“等待”（wait secs）模块等待指定的时间。“等待直到”（wait until）模块响应程序中发生的情况。

![](img/72d218a7a73c4d4abc7be582ebd85385_70_0.png)

![](img/72d218a7a73c4d4abc7be582ebd85385_70_1.png)

- “等待直到”模块：此模块等待其表达式为真。

# 广播

“事件”（Events）菜单中的广播（broadcast）模块允许角色发送和接收消息。消息除了名称外不包含任何信息，但可以用于微调角色的动作。角色只对其程序编写的消息做出——它们忽略其他消息。

此“事件”模块让角色向所有其他角色发送消息

当角色接收消息时启动脚本

```
broadcast message1

# 对话

要在角色之间创建对话，使用“广播消息并等待”（broadcast message and wait）模块配合“说”（say）模块，让你的角色使用气泡说话。开始一个新项目并添加两个角色。将左侧的脚本给一只猴，将右侧的两个脚本给另一个。

```
broadcast message1 and wait
```

> △ 等待模块
此模块发送消息，然后等待所有对消息做出反应的脚本完成，程序继续

![](img/72d218a7a73c4d4abc7be582ebd85385_72_0.png)

第一只猴开始对话

![](img/72d218a7a73c4d4abc7be582ebd85385_72_1.png)

“说”模块让你的角色使用气泡说话

“hello”消息触发了第二只猴的脚本

```

```

```

```

```
