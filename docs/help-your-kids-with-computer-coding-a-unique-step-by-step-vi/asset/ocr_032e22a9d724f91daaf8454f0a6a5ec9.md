# Pens and turtles

Each sprite has a pen tool that can draw a line behind it wherever it goes. To create a picture, turn on the pen and move the sprite across the stage, like moving a pen across paper.

# Pen blocks

The dark green blocks are used to control the pen. Each sprite has its own pen that can be turned on by using the “pen down” block and turned off using the “pen up” block. The size and color of the pen can also be changed.

# Draw a square

To draw a square, you simply put the pen on the stage and then move the sprite in a square shape. Use a loop to draw the sides and turn the corners.

The sprite will leave a line behind it

![](bbox=[0.683, 0.656, 0.873, 0.783])

Change the shape
This code will draw a square. To draw a triangle, change the “repeat” loop to repeat three times for the three sides, and change the turn from 90 to 120 degrees.
