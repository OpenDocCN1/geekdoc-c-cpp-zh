# Save the code window

Click the "File" menu and select "Save As." Enter the file name "HelloWorld" and click "Save".

```

```

# How IDLE works

Always follow these three steps in IDLE: write the code, save it, and then run it. Remember, code that hasn't been saved won't run. A warning will come up if you try.

```
>>>
Hello World!
>>>
```

The message will appear without quote marks
