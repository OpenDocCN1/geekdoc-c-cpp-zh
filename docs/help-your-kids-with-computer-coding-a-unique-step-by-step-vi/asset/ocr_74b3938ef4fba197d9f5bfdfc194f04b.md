# Python 3 on a Mac

Before you install Python 3 on a Mac, make sure you get permission from the computer's owner. You may also need to ask the owner to provide an admin password during installation.

+   Go to the Python link
Type the address below into your web browser to open the Python website. Click on "Download" in the navigation panel to go to the download page.

+   Download Python
Check which operating system your Mac has (see page 88) and click on the matching version of Python 3. You will be prompted to save a .dmg file. Save it on your Mac desktop.

```
http://www.python.org
```

+   * 3.3.3 Mac OS X 64-bit... (for Mac OS 10.6 and later)
* 3.3.3 Mac OS X 32-bit... (for Mac OS 10.5 and later)

+   Install
Double-click the .dmg file. A window will open with several files in it, including the Python installer file "Python.mpkg". Double-click to start the installation.

+   Run IDLE
During installation, click "next" at each prompt to accept the default settings. After installation ends, open the "Applications" folder on your Mac and open the "Python" folder (make sure you select Python 3, not Python 2). Double-click "IDLE" to check the installation worked.
