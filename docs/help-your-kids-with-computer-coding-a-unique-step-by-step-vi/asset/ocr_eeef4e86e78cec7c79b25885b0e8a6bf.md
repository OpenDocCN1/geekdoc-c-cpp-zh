# Variables

In coding, a variable is the name for a place where you can store information. Variables are used to remember things such as the score, a player's name, or a character's speed.

# Creating a variable

You can create a variable to use using the "Data" section of the blocks palette. Once a variable has been created, new blocks appear in the blocks palette ready for you to use.

![](bbox=[0.586, 0.226, 0.715, 0.368])

+   * Storing data: Variables are like boxes where you can store different bits of information for your program.

+   1 Make a variable
 First, click the "Data" button in the blocks palette. Then select the "Make Variable" button.

+   2 Name the new variable\ Give it a name that will help you remember what it does. Select which sprites will use the variable, then click "OK".
