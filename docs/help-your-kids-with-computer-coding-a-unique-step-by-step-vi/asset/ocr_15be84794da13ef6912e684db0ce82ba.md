# Loops in Python

Programs that contain repeating lines of code can be time-consuming to type in and difficult to understand. A clearer way of writing them is by using a loop command. The simplest loops are those that repeat a certain number of times, such as “for” loops.

# Repeating things

“for” loop repeats the code without having to type it again. It can be used to repeat something certain number of times, for example, if you want to print the names of a class of 30 students.

![](bbox=[0.535, 0.26, 0.932, 0.435])

+   Program the turtle
- “for” loop can also be used to shorten the code. This program allows the user to control a turtle that draws a line as it moves across the screen, the user can draw shapes on the screen, by directing the turtle’s movements.

```
from turtle import *
forward(100)
right(120)
forward(100)
right(120)
forward(100)
right(120)
```

> Loads all the commands that control the turtle

> This command moves the turtle forward

This makes the turtle turn 120 degrees to the right

+   The turtle draws a triangle
- The program tells the turtle how to draw a triangle by giving it the length of the three sides and the angles between them. The turtle will appear in a separate window when you run the program.

+   Use a “for” loop
- The program gives the turtle the same two commands, “forward(100)” and “right(120)”, three times – once for each side of the triangle. An alternative to this is to use these two commands inside a “for” loop. Try drawing a triangle simply using the code shown below.

```
for i in range(3):
    forward(100)
    right(120)
```

> The “for” loop tells the program to repeat the instructions three times
