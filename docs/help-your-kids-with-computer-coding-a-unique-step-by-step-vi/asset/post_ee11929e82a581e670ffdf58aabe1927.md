## Which window?

There are two different windows to choose from in IDLE. The code window can be used to write and save programs, while the shell window runs Python instructions right away.

## The code window

So far in this book, the code window has been used to write programs. You enter the program, save it, run it, and the output appears in the shell window.

### Running programs
This process is used for running Python programs. Programs always have to be saved before running them.

- *Enter a program in the code window*
Enter this code in the code window, save it, and click "Run module" in the "Run" menu to run the program.

- *Output in the shell window*
When the the program runs, its output (the results of the program) is shown in the shell window.

```python
a = 10
b = 4
print(a + b)
print(a - b)
```

> Give "a" the value 10
> Give "b" the value 4
> The "print" command shows the answers to these sums

```python
>>>
14
6
```

> The answers to the sums in the shell window

## The shell window

Python can also understand commands that are typed in the shell window. They run as soon as you type them in, and the result is shown straight away.

> The first two commands have no output because they are just assigning values to "a" and "b"

```python
>>> a = 10
>>> b = 4
>>> a + b
14
>>> a - b
6
```

> Code and output together
The shell window shows the code and the output together. It's easier to tell which answer belongs to which sum when the commands are typed in the shell window.

> Test your ideas
The shell window gives you an immediate response, which makes it ideal for testing instructions and exploring what they can do.

## Python playground

The shell window can be used to try out all sorts of Python commands, including drawing. The turtle is used to draw on screen in the same way that the pen is used in Scratch.

## Colors in the code

IDLE color-codes the text. The colors give you some clues about what Python thinks each piece of text.

```python
>>> from turtle import *
>>> forward(100)
>>> right(12)
>>> forward(100)
```

Enter the code
Type these instructions in the shell window. They run after each one is typed. As the turtle moves, it draws a line.

- Built-in functions
Commands in Python, such as "print", are shown in purple.

- Strings in quotes
Green indicates strings. If the brackets are green, there's a missing quote.

- Most symbols and names
Most code is shown in black.

Turtle graphic
Can work out how to draw other shapes, such as a square or a pentagon. To start over, type "clear()" into the shell window.

Output
Python's output in the shell window is shown in blue.

Keywords
Keywords, such as "if" and "else", are orange. Python won't let you use keywords as variable names.

Errors
Python uses red to alert you to any error messages in the shell window.

## Which window should you use?

Should you use the code window or the shell? It depends on the type of program you're writing, and whether it is to be repeated.

### Code window
The code window is ideal for longer pieces of code because they can be saved and because it's easier than retyping all the instructions if you want to do the same thing again or try something similar. It needs to be saved and run each time, though.

## Code vs Shell

### Shell window
The shell window is perfect for quick experiments, such as checking something. It doesn't save, if you're trying something, use the code window instead.

## Variables

Variables are used to remember information. They are like boxes where data can be stored.

### Creating a variable
A number or string can be assigned to a variable using the "=" sign.

```python
>>> name = "Alice"
>>> age = 25
```

### Printing a variable
The "print" command is used to show the value of a variable.

```python
>>> print(name)
Alice
```

### Changing the contents of a variable
To change the value of a variable, simply assign it a new value.

```python
>>> gifts = 2
>>> print(gifts)
2
>>> gifts = 3
>>> print(gifts)
3
```
