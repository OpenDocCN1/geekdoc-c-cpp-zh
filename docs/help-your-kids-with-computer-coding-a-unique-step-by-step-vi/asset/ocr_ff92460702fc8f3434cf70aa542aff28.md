# ASCII

+   > ASCII table

In ASCII, a decimal value is given to each character in the upper- and lower cases. Numbers are also assigned to punctuation and other characters, such as a space.

+   > ASCII in binary

Because each character has a number, that then needs to be converted to binary to be stored in a computer.

> R = 82 = 1010010
r = 114 = 1110010

+   v ASCII in Python

You can convert between ASCII and binary code in languages, including Python.

This command prints the character, the ASCII value, and the binary value for each in the name "Sam"

```
>>> name = 'Sam'
>>> for c in name:
print(c, ord(c), bin(ord(c)))
```
