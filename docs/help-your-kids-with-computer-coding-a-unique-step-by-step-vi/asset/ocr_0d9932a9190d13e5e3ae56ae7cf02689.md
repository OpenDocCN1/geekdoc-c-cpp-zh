# # Branching instructions

Often you want a program to do one thing if a condition is true, and something else if it is not. The "if-then-else" block gives a program two possible routes, called "branches". Only one branch will run, depending on the answer to the Boolean expression.

# Branching program

This program has two branches: one will run if the answer is "yes", and the other run if it is not.
