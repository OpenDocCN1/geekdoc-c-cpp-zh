# Python 3 on Ubuntu

If you use the Linux operating system Ubuntu, you can download Python 3 without having to use a browser—just follow the steps below. If you have a different version of Linux, ask the computer's owner to install Python 3 for you.

![](bbox=[0.678, 0.055, 0.973, 0.229])

+   Go to Ubuntu Software Center
Find the Ubuntu Software icon in the Dock or the Dash and double-click.

![](bbox=[0.358, 0.239, 0.466, 0.316])

+   Enter "Python" into the search bar
You will see a search box in the top right. Type "Python" in the box and press enter.

```
Python
```

Look for version 3

+   Select IDLE and click "Install"
Look for "IDLE (using Python)". Highlight the version beginning with the number 3 and click "Install".

| IDLE (using Python-3.3) | (17) |
| Integrated Development Environment for Python | Install |

+   Select Dash
After installation finishes, double-click the program works. First, select the Dash icon in the top right.

![](bbox=[0.386, 0.555, 0.466, 0.633])

+   Run IDLE
Enter "IDLE" into the search bar and double-click on the blue-and-yellow IDLE (using Python 3") icon.

![](bbox=[0.796, 0.555, 0.893, 0.633])

+   A Python window opens
A window like the one below should open. You can now start coding—just type into the window after the angle brackets.
