# Installing Python

Before you can use the Python programming language, you need to download and install it on your computer. Python 3 is free, easy to install, and works on Windows PCs, Macs, and Linux operating systems as Ubuntu.

# What is IDLE?

When you install Python 3, you'll also get a free program called IDLE (Integrated Development Environment). Designed for beginners, IDLE includes a basic text editor that allows you to write and edit Python code.

> EXPERT TIPS

# Save code

When saving work in Python, you will need to use the "File > Save As..." menu command so you can name your files. First create a folder to keep all your files in. Give the folder a clear name, like "PythonCode", and agree with the person who owns the computer where to keep it.

# WINDOWS

+   - Windows

Before you download Python, check what kind of operating system your computer has. If you have Windows, find out whether it's the 32-bit or 64-bit version. Click the "Start" button, right-click "Computer", and left-click "Properties". Then choose the option appears.
