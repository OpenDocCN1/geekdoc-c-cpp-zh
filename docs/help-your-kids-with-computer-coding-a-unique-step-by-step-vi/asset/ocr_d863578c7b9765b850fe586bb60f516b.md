# Make games with Python

You could create your own game using Python. The PyGame library, which is available to download from the web, comes with lots of functions and tools that make it easier to build games. Start by making simple games, then progress to more complex ones.

# Different versions of Python

When you find code elsewhere (in other books or online), it may be written for a different version of Python. The versions are similar, but you might need to make small changes.

```
print ('Hello World') // Python 2
```

```
print('Hello World') // Python 3
```

# Debug your code

Debugging is an important part of programming. Don't give up if something isn't working. Remember that computers will only do what you tell them, so look through the code and figure out why it's not working. Sometimes looking over it with another programmer helps you find bugs quicker.
