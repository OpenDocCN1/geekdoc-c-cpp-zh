# # Numbering the characters

Each character in a string is allocated a number according to its position. This position number can be used to look at individual letters or symbols, or to pull out of a string.

![](bbox=[0.595, 0.025, 0.934, 0.235])

+   - Counting begins from zero
When counting the positions, Python starts at 0. The second character is in position 1, the third in position 2, and so on.

Counting the characters
The position number is called an "index". It can be used to pull out a particular letter from a string.

```
>>> a = 'FLAMINGO'
```

The sixth letter, "N", is in position 5

```
>>> a[3]
Square brackets go around the index
```

```
'M'
The character in position 3 from the variable "a"
```

![](bbox=[0.066, 0.403, 0.547, 0.533])

The last character, "O", is in position 7

+   - Slicing
Two indices can be used to pull out a part of the string or "slice". The letter in the last position is not included.

+   - From the start or the end
If you leave the start or end index, Python will automatically use the first or the last character of the string.

```
>>> a[1:7]
'LAMING'
Colon defines the range of characters
A slice from index 1 to index 6 of variable "a"
```

```
>>> a[3:]
'FLA'
>>> a[:3]
'MING'
Ends at index 7nStarts at index 0
```

# # Apostrophes

Strings can go in single or double quotation marks. However, the string should start and end with the same type of quotation marks. This book uses single quotes. But what happens if you want to use an apostrophe in your string?

```
>>> print('It\s a cloudy day.')
It's a cloudy day.
```

+   - Escaping the apostrophe
Python doesn't read an apostrophe as the end of the string, type a "\" before it. This is called "escaping it."

The apostrophe is included in the string
