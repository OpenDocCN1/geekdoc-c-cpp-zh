
# Making windows

Many programs have windows and buttons that can be used to control them. These make up the "graphical user interface," or "GUI" (pronounced gooey).

## Make a simple window

# Add buttons to the window

Make the GUI more interactive by adding buttons. A different message will be displayed when the user clicks each button.

- Create two buttons
Write this code to create a simple window with two buttons.

```

    print('Thank you!') # This message appears when button B is pressed
def bAction():
    print('Ouch! That hurt!')

buttonA.pack() # This label will appear on button A
buttonB.pack() # This label will appear on button B
This code tells the computer to put the buttons in the window
```

# Roll the dice

Tkinter can be used to build a GUI for a simple application. The code below creates a program that simulates rolling a six-sided dice.

- Create a dice simulator
This program creates a button, when pressed, tells the function "roll()" to display a random number between 1 and 6.

![](img/72d218a7a73c4d4abc7be582ebd85385_156_0.png)

```
from tkinter import *
from random import randint
def roll():
    text.delete(0.0, END)
    text.insert(END, str(randint(1,6)))
window = Tk()
text = Text(window, width=1, height=1)
buttonA = Button(window, text='Press to roll!', command=roll)
text.pack()
buttonA.pack()
```

This imports the function "randint" from the random library

This clears the text inside the box and replaces it with a random number between 1 and 6

This creates a text box to display the random number

This tells the program function to run when the button is clicked

This label appears on the button

- Press the button to roll the dice
Run the program, then click the button to roll the dice and see the result. This program can be simply changed so that it simulates a 12-sided dice, or a coin being tossed.

# Drawing on a canvas

To create graphics using Python, you need to make a blank area to draw on. This is known as a canvas. You can use x and y coordinates to tell Python exactly where to draw on the canvas.

> EXPERT TIPS

## Coordinates

In Tkinter, x coordinates get larger moving to the right, and y coordinates get larger moving downward. (0,0) is in the top-left corner.

![](img/72d218a7a73c4d4abc7be582ebd85385_158_0.png)

# Create a graphics program

Use this code to create a window and put a canvas inside it. It will then draw random circles on the canvas.

```
from random import *
from tkinter import *
size = 500
window = Tk()
canvas = Canvas(window, width=size, height=size)
canvas.pack()
while True:
    col = choice(['pink', 'orange', 'yellow'])
    x0 = randint(0, size)
    y0 = randint(0, size)
    canvas.create_oval(x0, y0, x0 + d, y0 + d, fill=col)
    window.update()
```

# Making shapes

As well as adding windows, buttons, and colors (GUI), Tkinter can also be used to draw shapes. Rectangles and ovals are useful for drawing all of types. Once a canvas has been created, the following functions can be used to draw on it

![](img/72d218a7a73c4d4abc7be582ebd85385_159_0.png)

```
>>> tkinter import * # Creates a canvas
>>> window = Tk()
>>> drawing = Canvas(window, width=500, height=500)
>>> drawing.pack() # Draws a rectangle
>>> drawing.create_rectangle(100, 100, 300, 200)
>>> drawing.create_oval(170, 70, 230, 130)
>>> drawing.create_oval(190, 90, 210, 110)
>>> drawing.create_oval(30, 30, 80, 80)
```

Sets the size of the canvas

Coordinates

The first number (“x”) tells how far along. The second number (“y”) tells how far down. The top-left corner of the rectangle is at (50,50). The bottom-right is at (250,300).

```
>>> drawing.create_rectangle(50, 50, 250, 300)
```

Sets the coordinates
