
# Using JavaScript

JavaScript is great for creating mini programs that run inside HTML, bringing websites to life and allowing users to interact with them. Although it works like Python, JavaScript code is more concise and trickier to learn.

# Getting input

As with Python, you can use JavaScript to ask the user for information. JavaScript can do this with a pop-up box. The following program prompts the user to enter their name and responds with a greeting.

This line creates a pop-up box and stores the text the user into it

- This script stores the user's name in a variable. Type the code into the IDLE code window and remember to save it with `index.html`.

The text in quotes appears in the box

```javascript
<script>
var name = prompt("Please enter your name");
var greeting = "Hello " + name + "!";
document.write(greeting);
</script>
```

JavaScript lines always end with a semicolon

The `<script>` tag shows where the JavaScript ends

This line displays the greeting

- Double-click the HTML file to launch a browser window. Enter your name in the box and click "OK" to see the greeting.

# Events

An event is any action that a program can detect, as a mouse click or a keystroke. The section of code that reacts to an event is called an "event handler". Event handlers are used a lot in JavaScript and can trigger many different functions, making web pages fun and interactive.

# Loops in JavaScript

A loop is a section of code that repeats. Using loops is much quicker and easier than typing out the same line of code over and again.

# Loop code

Like Python, JavaScript uses "for" to set up a loop. The repeated lines of code are enclosed in curly brackets. This loop creates a simple counter that increases each time it repeats.

# Loop output

Save the code as a "html" file and run it. It keeps repeating as long as less than "x<6" in the code. To increase the number of repeats, use a higher number after the "x<"-symbol.

```javascript
<script>
for (var x=0; x<6; x++) {
  document.write("Loop count: " + x);
}
</script>
```

The <script> tag introduces the JavaScript code

This line creates a counter called "x" with a starting value of 0, rising by "x+" in each repeat loop

This line tells the computer to write the text "Loop count: " followed by counter number

# Bad programs

Not all programs are fun games or useful apps. Programs are designed to steal your data or damage your computer. They will often seem harmless, and you might not realize that you have been a victim.

# Malware

Programs that do things without your knowledge or permission are known as “malware”. Unauthorized access to a computer is a crime, but there are many different types of programs that try to sneak on your computer.

- Worm
A worm is a type of malware that crawls around a network from computer to computer. Worms can clog networks, slowing them down—the first worm brought the Internet to a virtual standstill in 1988.

![](img/72d218a7a73c4d4abc7be582ebd85385_213_0.png)

- Virus
Just like a virus in the human body, this malware copies itself over and again. They are usually spread through emails, USB sticks, or other methods of transferring files between computers.

![](img/72d218a7a73c4d4abc7be582ebd85385_213_1.png)

# REAL WORLD
## Famous worm

On May 5, 2000, Internet users in the Philippines received emails with the subject “ILOVYOU”. An attachment appeared to be a love letter, but was actually a piece of malware that corrupted files.

- ILOVYOU
This worm quickly spreads to computers around the world. It is estimated to have cost more than $20 billion to fix the damage it caused.

![](img/72d218a7a73c4d4abc7be582ebd85385_213_2.png)

# What malware does

Viruses, worms, and trojans are all types of malware that are created to get into your machine, but what do they do once they have infected their target? They might delete or corrupt files, steal passwords, or seek to control your machine for some larger purpose as part of an organized “zombie botnet”.

![](img/72d218a7a73c4d4abc7be582ebd85385_214_0.png)

- > Zombie botnets
Botnets are collections of infected computers that can be used to send spam emails, or flood a target website with traffic to bring it crashing down.

# Good software to the rescue

Thankfully, people aren’t defenseless in the fight against malware. Anti-malware software has become big business, with many providers competing to provide the best protection. Two well-known examples are firewalls and antivirus programs.

| LINGO | Hackers |

Coders who study and write malware are known as “hackers”. Those who write malware to commit crimes are known as “black-hat” hackers, and those who write programs to try to protect against malware are known as “white-hat” hackers.

![](img/72d218a7a73c4d4abc7be582ebd85385_214_1.png)

- > Antivirus programs
Antivirus software tries to detect malware. It identifies bad programs by scanning files and comparing their contents with a database.

- > Firewalls
Firewalls aim to prevent malware and dangerous network traffic from reaching your computer. They can scan all incoming data from the Internet.

## Raspberry Pi

The Pi is a credit-card-sized computer, created to teach the basics of how computers work. For its size it is impressively powerful, with the ability to run similar programs to a modern PC.

![](img/72d218a7a73c4d4abc7be582ebd85385_215_0.png)

- Audio output for headphones or speakers
- Two USB connectors for a mouse, a keyboard, or any other add-ons
- Video output for older TVs
- Input and output pins for sensing and control (good for robots)
- Network connection to access the Internet
- Removable memory store operating systems, programs, and data
- HDMI video output—to connect to modern TVs
- Power connector

## Arduino

The Arduino is cheaper than the Pi, but less powerful. It is often used as a low-cost and simple way to build custom electronic or robotic machines.

![](img/72d218a7a73c4d4abc7be582ebd85385_215_1.png)

- Many input and output pins make the Arduino very adaptable
- Microcontroller—a single-chip computer
- Reset button
- Sockets for connecting the Arduino to other electronics
- USB connector used to load programs on the Arduino from a PC
- Power connector
