# Input

The "input()" function is used to accept input from the keyboard to a program. It waits until the user finishes typing and presses the "return" or "Enter" key.

> The "input()" function allows users to interact with a program using their keyboard

![](bbox=[0.615, 0.298, 0.913, 0.353])

+   Using input
A program can prompt the user what to type. The message is inside the brackets of "input()".

Adding a space after the colon makes the output look timid

+   Output in the shell window
When the program is run, the message "Enter your name: " and its response appear in the shell window.

```
name = input('Enter your name: ')
print('Hello', name)
```

Enter your name: Jina
Hello Jina

> What the program outputs depends on what name the user types

> Program outputs message

> User types in their name

# Output

The "print()" function is used to display characters in the shell window. It can be used to show a combination of text and variables.

![](bbox=[0.613, 0.583, 0.933, 0.663])

> Output is displayed on the screen

+   Create some variables
Set up three variables for this simple experiment. Two are strings and one is an integer (whole number).

+   Using the "print()" function
You can put several items inside the brackets of the "print()" function. You can combine variables of different types, and even strings and variables.

```
>>> a = 'Dave'
>>> b = 'is'
>>> c = 12
```

> Quote marks show these strings

```
>>> print(a, b, c)
Dave is 12
>>> print('Goodbye', a)
Goodbye Dave
```

> No quote marks as this is an integer

> Comma separates the different items
