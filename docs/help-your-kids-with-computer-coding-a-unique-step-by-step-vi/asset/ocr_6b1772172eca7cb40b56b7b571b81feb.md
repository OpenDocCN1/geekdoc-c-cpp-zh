# Adding more sprites

+   1. Add a sprite from the sprite library. The flying hippo ("Hippo1") is great for this game.
2. Click on the bat in the sprite list.
3. Click on the bat's script and hold the mouse button down.
4. Drag the bat's script to the new sprite in the sprite list.
5. The script will copy across to the new sprite.
