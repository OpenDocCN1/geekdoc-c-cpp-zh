# Help!

It can be hard to write a program if you don't know about some of the blocks you could use. Scratch has a help menu to make sure you understand every block.

+   - Block help
To find out more about a particular block, click the 'block help' button on the cursor bars at the top of the screen.

![](bbox=[0.066, 0.303, 0.195, 0.335])

The help window explains every block
This is the 'block help' button

+   - Ask a question
The cursor will turn into a question mark. Use this to click on the block you want to know about.

The cursor becomes a question mark

![](bbox=[0.066, 0.463, 0.275, 0.488])

+   - Help window
The help window opens to tell you how the block works, with tips on how it can be used.

# Learn another language

You're now on your way to mastering your first programming language. Learning other languages will enable you to write different types of programs. Why not try Python? What you've already learned about Scratch will help you pick up Python quickly.

+   - Similar to Scratch
Python uses loops, variables, and branches too. Use your Scratch knowledge to start learning Python!
