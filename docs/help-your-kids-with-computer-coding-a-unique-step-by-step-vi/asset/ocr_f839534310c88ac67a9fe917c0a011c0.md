# Logical operators

Logical operators are used to compare variables against numbers or strings, or even other variables. The resulting answer is either “True” or “False".

![](bbox=[0.588, 0.273, 0.934, 0.403])

+   - == "Equals" operator
- != "Not equal to" operator
- < "Less than" operator
- > "Greater than" operator
- <= "Less than or equal to" operator
- >= "Greater than or equal to" operator

```
>>> toys = 10
>>> toys == 1
False
>>> toys > 1
True
>>> toys < 1
False
>>> toys != 1
True
>>> toys <= 10
True
>>> toys == 9 or toys == 10
True
>>> toys == 10
False
```

Types of comparison operators There are six comparison operators. Python uses two equals signs to compare if two things are the same. (A single sign is used to assign a value to a variable.)
