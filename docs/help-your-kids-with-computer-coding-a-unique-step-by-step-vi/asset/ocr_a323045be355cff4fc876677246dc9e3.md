# How it works

If the user decides not to carry on after the third question and types "stop", the break command is executed and the program leaves the loop.

# Skipping

The "continue" keyword can be used to skip a question without leaving the loop. It tells the program to ignore the rest of the code inside the loop and skip to the start of the next loop.

# Insert a continue

Add an "if" statement inside the loop to see if the user answered "skip". If so, the program will print "Skipping" and execute a "continue" to skip to the next loop.

```
table = 7
for i in range(1,13):
    print('What\s', i, 'x', table, '?')
    guess = input()
    if guess == 'stop':
        break
    if guess == 'skip':
        print('Skipping')
        continue
    ans = i * table
    if int(guess) == ans:
        print('Correct!')
    else:
        print('No, it\s', ans, ans)
print('Finished')
```
