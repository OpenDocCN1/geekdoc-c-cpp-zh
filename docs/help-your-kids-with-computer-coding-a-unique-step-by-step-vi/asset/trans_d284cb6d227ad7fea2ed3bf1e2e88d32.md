

# 使用微电脑

由于具有许多连接选项，微电脑可以做许多无穷尽的事情。这里是一些建议。

![](img/72d218a7a73c4d4abc7be582ebd85385_216_0.png)

### 电脑
连接键盘、鼠标和显示器，即可获得一台功能完整的台式电脑。

![](img/72d218a7a73c4d4abc7be582ebd85385_216_1.png)

### 音频输出
连接一组扬箱，然后通过网络向它们发送音乐。

![](img/72d218a7a73c4d4abc7be582ebd85385_216_2.png)

### 手机
使用手机将电脑连接到互联网。

![](img/72d218a7a73c4d4abc7be582ebd85385_216_3.png)

### 小配件
连接 LED 灯和其他简单的电子设备来制作机器人或小配件。

![](img/72d218a7a73c4d4abc7be582ebd85385_216_4.png)

### 电视
连接电视并将其作为媒体中心，展示你所有的电影和照片。

![](img/72d218a7a73c4d4abc7be582ebd85385_216_5.png)

### 摄像头
将一个基础摄像头连接到你的微电脑，创建你自己的摄像头。

![](img/72d218a7a73c4d4abc7be582ebd85385_216_6.png)

### USB
连接一个 USB 硬盘并在网络上共享你的文件。

![](img/72d218a7a73c4d4abc7be582ebd85385_216_7.png)

### SD 卡
通过更换 SD 卡来更改你微电脑上的程序。

# 现实世界
自制机器人

凭借其体积小、成本低、重量轻等特点，微电脑正越来越多地用于构建不同类型的机器人。例如：

- 记录大气天气状况的气象球。
- 可以像蝙蝠一样利用声波感知障碍物的微型车载。
- 用于拾取和移动不同对象的机械臂。
- 由 Arduino 控制的机器人蜘蛛。

# 成为更优秀程序员的方法

就像滑雪、学钢琴或打网球一样，编码是一项随着时间推移会变得越来越好的技能。成为真正的专家可能需要多年，但如果你在这个过程中收获了乐趣，它感觉就像是一段毫不费吹力的旅程。这里是一些帮助你成为大师程序员的建议。

- 多写代码
人们说熟能生巧——事实确实如此。你写的代码越多，就会表现得越好。坚持下去，你很快就会成为专家。

- 保持好奇心
阅读关于编程的网站和书籍，并尝试他人的代码。你会学到一些专家技巧，这些技巧可能你自己需要好几年才能摸索出来。

![](img/72d218a7a73c4d4abc7be582ebd85385_217_0.png)

- 借鉴灵感
如果你遇到一个很棒的程序，想想如何用自己的方式编写它。寻找聪明的主意来使用，优秀的程序员会互相借鉴想法并尝试改进它们。

- 教给朋友看
教别人编程，你自己也会学到很多。解释代码是如何运作的是确保你彻底理解它的极方法。

- 训练你的大脑
你的大脑就像肌肉——如果你锻炼它，它就会变得更强。做一些你认为像程序员一样的事情。解决逻辑谜题和脑筋急转弯，玩玩数独，练习数学。

# 术语表

**算法**:一组指令。

**调用**: 使用函数。

**事件**: 程序可以响应的某些。

**压缩**: 使数据变小的方法。

**执行**: 运行。

**ASCII**: 美国信息交换标准。

**二进制**: 0 和 1 的系统。

**布尔**: 只有两个答案的问题。

**GUI**: 图形用户界面。

**输入**: 输入电脑的数据。

**文件**: 文件的集合。

**浮点数**: 带有小数的数字。

**位**: 信息的最小单位。

**硬件**: 电脑的物理部分。

**整数**: 不包含小数的数字。

**内存**: 存储数据的电脑芯片。

**编程语言**: 用于给出指令的语言。

**语句**: 完整的指令。

**接口**: 用户与软件交互的。

**模块**: 可以重复的代码段。

**随机**: 具有不可预测结果的函数。

**字符串**: 字符序列。

**IP 地址**: 用于识别个体的数字序列。

**运算符**: 执行功能的符号。

**运行**: 让程序启动。

**语法**: 决定程序结构的规则。

**OS**: 操作系统为其他程序提供基础。

**服务器**: 存储文件的电脑。

**木马**: 伪装成其他软件的恶意软件。

**库**: 函数的集合。

**单步**: 逐一步运行电脑的方式。

**循环**: 重复执行的代码部分。

**输出**: 程序产生的数据。

**元组**: 用逗号分隔的项列表。

**端口**: 用于特定程序的数字序列。

**套接字**: IP 地址和端口的。

**Unicode**: 用于表示符号的通用代码。

**处理器**: 运行程序的电子芯片。

**机器码**: 电脑理解的基础语言。

**软件**: 运行在电脑上的程序。

**变量**: 可以存储信息的具命名位置。

**恶意软件**: 设计用于电脑的软件。

**程序**: 电脑遵循的指令集。

**精灵**: 可移动的对象。
