## Moving the sprite

Coordinates are used to move a sprite to a particular spot on the stage. It doesn't matter how near or far away the spot is. The “glide 1 secs to x:0 y:0” block from the “Motion’ section of the blocks palette makes the sprite glide there smoothly.

![](img/72d218a7a73c4d4abc7be582ebd85385_58_0.png)

Positive numbers move sprites up and right, negative numbers move them down and left.

Change the coordinate numbers to make the sprite go elsewhere:

```
when clicked
glide 1 secs to x: 150 y: 100
glide 1 secs to x: -150 y: -100
glide 1 secs to x: -200 y: 100
glide 1 secs to x: 0 y: 0
```

![](img/72d218a7a73c4d4abc7be582ebd85385_58_1.png)

Moves to the middle of the stage

```
change x by -10
change y by 125
```

```

set y to 180
```

## Making your own music

Scratch has blocks that can be used to invent musical sounds. You have a whole orchestra of instruments to conduct, as well as a full drum kit. The length of each note is measured in beats.

This decides how low or high the pitch of a note is:

```
play note [60] for [0.5] beats
```

Big numbers make a note longer. It can also be shorter than a beat, as shown here:

```
set instrument to [1]
```

Click here to choose an instrument from a drop-down menu

```
play drum [1] for [0.25] beats
```

```
rest for [0.25] beats
```

Use this menu to choose between different types of drum

This block adds a silent break in the music. Higher numbers will give you a longer break
