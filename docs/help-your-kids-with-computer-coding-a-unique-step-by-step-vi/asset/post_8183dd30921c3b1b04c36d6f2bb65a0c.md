
## Game ingredients

The most common ingredients in games are often combined into a “game engine”. Engines provide an easy-to-use base so that new games can be developed quickly.

- All games must have a good story and some sort of goal aim for, such as saving the princess. Well-designed game logic keeps players interested.

![](img/72d218a7a73c4d4abc7be582ebd85385_206_0.png)

- In a virtual world, the rules of the real world, such as gravity and collisions, must be re-created to make the game more believable.

![](img/72d218a7a73c4d4abc7be582ebd85385_206_1.png)

As games become more realistic their graphics must become more complex. Body movements, smoke, and water are particularly hard to get right.

- Familiar controls that make sense to the player help make a great game. Good control design makes the player forget that they are using a controller.

![](img/72d218a7a73c4d4abc7be582ebd85385_206_2.png)

All of the words spoken in the game must be recorded, as well as the background music and the sound effects that change throughout the game.

## Serious games

Games are being used for more than just fun. Pilots, surgeons, and soldiers are just some of the professionals who use games at work for training purposes. Some businesses even use strategy games to improve their employees’ planning skills.

![](img/72d218a7a73c4d4abc7be582ebd85385_206_5.png)

- Human players often play alongside or against computer-controlled players. Artificial intelligence programming allows these characters to respond realistically.

## Making apps

Mobile phones have opened up a world of possibilities for coders. With a computer in everyone’s pocket, mobile apps can use new inputs, such as location-finding and motion-sensing, to give users a better experience.

## What is an app?

“App” (short for “application”) is a word that describes programs that run on mobile devices, smartphones, tablets, and even wearable technology such as watches. There are many different categories of apps that do different things.

## How to build an app

There are many questions to answer before building an app. What will it do? What devices will it run on? How will the user interact with it? Once these questions are answered, building an app is a step-by-step process.

![](img/72d218a7a73c4d4abc7be582ebd85385_208_0.png)

- Mac
- Android
- Which operating system?

Will the app target a certain type of mobile device? Coders can often use tools that let them write their application once and then adapt it for different operating systems.

- Have an idea
Any idea for a new app must be well suited to mobile devices. It might be a completely new idea, or it could be an improvement on an already existing idea to make a better version.

- Learn to make apps
Whichever platform the app will run on, a coder needs to learn the language and other skills needed to build a good app. Online tutorials and local coding clubs can help.

![](img/72d218a7a73c4d4abc7be582ebd85385_208_1.png)

- Create the program
Good apps take time to make. A basic version might be working in weeks, but for an app to be really successful, it will need to be developed for a few months before its release.

- Test it
Users will quickly get rid of an app if it contains bugs. Putting in tests as part of the code, and getting friends and family to try out the app can help clean up any errors before the app is released.

## HTML
HTML (HyperText Markup Language) is the standard language for creating the structure of web pages. It uses tags to define different elements of a web page, such as headings, paragraphs, images, and links.

```html
<!DOCTYPE html>
<html>
<head>
<title>My Web Page</title>
</head>
<body>
<h1>This is a heading</h1>
<p>This is a paragraph.</p>
<img src="image.jpg" alt="Image description">
<a href="https://www.google.com">This is a link</a>
</body>
</html>
```
