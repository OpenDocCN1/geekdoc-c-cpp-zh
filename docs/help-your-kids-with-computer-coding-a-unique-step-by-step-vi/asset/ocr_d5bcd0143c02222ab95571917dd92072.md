# True or false?

Computers decide what to do by asking questions and determining whether the answers are true or false. Questions that only have two possible answers are called “Boolean expressions”.

# Comparing numbers

You can compare numbers using the “=” block from the “Operators” section of the blocks palette.

# “=” block

This block will give one of two answers:“true” if the two numbers in the boxes are equal, and “false” if they aren’t.

![](bbox=[0.063, 0.375, 0.485, 0.505])

![](bbox=[0.515, 0.375, 0.935, 0.505])

True answer
Using “=”block in a speech block will make “true” or “false”appear in a sprite’s speech bubble.

False answer
If the numbers in the block are different, the sprite’s speech bubble will contain the word “false”.

# Comparing variables

You can use variables inside comparison blocks. It’s not worth comparing fixed numbers because the result will always be the same, whereas the value of variables can change.

![](bbox=[0.415, 0.645, 0.685, 0.695])

This means “equals”, so the block is asking if ‘age’ is equal to 7. The answer is “false”, because “age” is 10

![](bbox=[0.415, 0.735, 0.685, 0.785])

This means “more than”, so the block is asking if ‘age’ is greater than 11. The answer is “false”, 10 is not bigger than 11

![](bbox=[0.063, 0.785, 0.245, 0.815])

This means “less than”, so the block is asking if ‘age’ is less than 18. The answer will be “true”, 10 is smaller than 18

![](bbox=[0.415, 0.845, 0.685, 0.895])

Create a variable
Click the “Data” block in the blocks palette and create a new variable called ‘age’. Set its value to 10 (click on the block to make sure the value changed). Drag the “age”variable into the comparison blocks.
