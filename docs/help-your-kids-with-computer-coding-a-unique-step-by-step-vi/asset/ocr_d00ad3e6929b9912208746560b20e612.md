# Adding more sprites

The monkey can now be moved across the stage using the left and right arrow keys. To make the game more interesting, add some more sprites. Give some bananas to throw, and a bat to throw them at!

![](bbox=[0.833, 0.156, 0.933, 0.262])

Add the “Bananas” sprite from the sprite library, then give it script. When the game starts, the monkey will be hiding the bananas. When the spacebar is pressed, they will shoot vertically up the stage. The bananas then reappear at one side of the stage, where they can be picked up again.

```
when clicked
set rotation style left-right
point in direction 0
show
forever
  repeat until
    go to Monkey 1
    key space pressed?
  repeat 35
    move 10 steps
  if
    pick random 1 to 2 = 1
    go to x: 210 y: -140
  else
    go to x: -210 y: -140
  show
wait until
  touching Monkey 1 ?
```

This makes the bananas stay upright

Sets the bananas' direction to up

This block makes the bananas visible on the stage—they'll be hidden later

The bananas will stick to the monkey until the spacebar is pressed

This loop moves the bananas up the stage

This “if-then-else” block makes the bananas reappear on the right or left side of the stage, randomly

This makes the script wait until the monkey picks up the bananas
