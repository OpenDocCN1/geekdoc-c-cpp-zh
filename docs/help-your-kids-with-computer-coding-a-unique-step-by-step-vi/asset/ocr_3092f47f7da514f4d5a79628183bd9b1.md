# Working in IDLE

Follow these steps to make a Python program using IDLE. It will teach you how to enter, save, and run programs.

> EXPERT TIPS
Different windows

Python uses two windows—the “shell” window and the “code” window (see pages 106–107). We've given them different colors to tell them apart.

+   Start IDLE
Start up IDLE using the instructions for your computer's operating system (see pp.88–91). The shell window shows the program output (any information the program produces) and any errors.
