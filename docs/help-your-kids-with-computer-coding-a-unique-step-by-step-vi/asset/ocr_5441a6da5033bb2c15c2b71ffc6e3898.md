# Random numbers

The "pick random" block can be used to select a random number between two values. This block is useful for rolling dice in a game or when you want to mix up a sprite's contents.

# EXPERT TIPS

# Gaming

Computers often use random numbers to add surprises to games. For example, an alien can be made to appear in a random place, or after a random amount of time. It can be used to select a random value, as if you were rolling a dice, or a random costume for a sprite.

```
pick random 1 to 10
```

# Hard math

Simple "Operator" blocks can do most calculations, but Scratch can also do more complex math. The "mod" block divides two numbers and gives the remainder, which is the number that is left over. The "round" block rounds to the nearest number, and the "sqrt" block gives the square of a root.

```
mod 3
```

Divides 3 by 3 and gives the remainder—the number that is left over

Gives nearest whole number to 44.7

```
round 44.7
```

Chooses different functions from the drop-down menu

# More math

The "Operator" section has blocks of advanced math functions that can be used to do complex calculations.

```
sqrt 9
```

Calculates the square root of 9
