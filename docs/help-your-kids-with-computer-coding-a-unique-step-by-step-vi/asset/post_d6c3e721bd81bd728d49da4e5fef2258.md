# Ways to become a better programmer

Like skiing, learning the piano, or playing tennis, coding is a skill that you'll get better and better over time. It can take years to become a true expert, but if you're having fun on the way, it will feel like an effortless journey. Here are a few tips to help you become a master programmer.

- Code a lot
People say practice makes perfect—and it's true. The more code you write, the better you'll get. Keep going and you'll soon be an expert.

- Be nosy
Read websites and books about programming and try out other people's code. You'll pick up expert tips and tricks that might have you years to figure out on your own.

![](img/72d218a7a73c4d4abc7be582ebd85385_217_0.png)

- Steal ideas
If you come across a great program, think how you might code it in your own. Look for clever ideas to use the best programmers copy each other's ideas and try to improve them.

- Show a friend
Teach someone else to code and you'll learn a lot yourself. Explaining how coding works is a great way of making sure you understand it thoroughly.

- Train your brain
Your brain is like a muscle—if you exercise it, it will get stronger. Do things that you think like a programmer. Solve logic puzzles and brainteasers, take up Sudoku, and work on your math.

# Test your code

Test your code by entering crazy values to see what happens. See how well it stands up to errors. Try rewriting it to improve it or try rewriting someone else's—you'll learn all their secret tricks.

# Build a robot army

You can connect your computer to all sorts of programmable devices, from flashing LED lights to robots. It's fun and you'll learn lots as you figure out how to conquer the world.

# Learn new languages

Become multilingual. Every new programming language you learn will teach you more about the ones you already know (or thought you knew). You download free versions of most languages.

# Pull a computer to bits

Take an old computer apart to see how it works (ask permission!). There aren't many components, so it won't take long to figure out all the bits are. Best of all, build your own computer and run your code on it.

# Win a prize

When your skills develop, why not enter an online coding contest? There are lots to choose from all different levels. The toughest worldwide competitions are Google's Code Jam, but there are easier challenges.

# Glossary

**algorithm**: A set of step-by-step instructions followed.

**call**: To use a function.

**event**: Something that a program can react to.

**compression**: A way of making data smaller.

**execute**: To run.

**ASCII**: American Standard Code for Interchange.

**binary**: A system of 0s and 1s.

**Boolean**: A question that has two possible answers.

**GUI**: Graphical user interface.

**input**: Data entered into a computer.

**file**: A collection of files.

**float**: A number with a decimal point.

**bit**: The smallest unit of information.

**hardware**: The physical parts of a computer.

**integer**: Any number that does not contain a decimal point.

**memory**: A computer chip that stores data.

**programming language**: A language used to give instructions.

**statement**: The smallest complete instruction.

**interface**: The means by which the user interacts with software.

**module**: A section of code that can be reused.

**random**: A function with unpredictable outcomes.

**string**: A series of characters.

**IP address**: A series of numbers used to identify an individual.

**operator**: A symbol that performs a function.

**run**: To make a program start.

**syntax**: The rules that determine how a program is structured.

**OS**: The operating system provides the base for other programs.

**server**: A computer that stores files.

**trojan**: A piece of malware that pretends to be another software.

**library**: A collection of functions.

**single-step**: A way of running a computer one step at a time.

**loop**: Part of a program that repeats itself.

**output**: Data produced by a computer program.

**tuple**: A list of items separated by commas.

**port**: A series of numbers used for a specific program.

**socket**: The combination of IP address and a port.

**Unicode**: A universal code used to represent symbols.

**processor**: An electronic chip that runs programs.

**machine code**: The basic language understood by computers.

**software**: The programs that run on a computer.

**variable**: A named place where you can store information.

**malware**: Software designed to harm a computer.

**program**: A set of instructions that a computer follows.

**sprite**: A movable object.

**virus**: A type of malware that multiplies itself to spread.
