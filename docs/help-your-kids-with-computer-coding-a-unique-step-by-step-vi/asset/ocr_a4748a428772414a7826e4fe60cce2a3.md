# ## Simple calculations

In Python, simple calculations can be made by typing into the shell window. The "print()" function is not needed for this—Python gives the answer straight away. Try these examples in the shell window:

![](bbox=[0.663, 0.296, 0.843, 0.372])

```
>>> 12 + 4
16
```

The shell window to get instant results

```
>>> 12 - 4
8
```

The answer appears when you press "Enter"

+   - Addition
Use the "+" symbol to add numbers together.

+   - Subtraction
Use the "-" symbol to subtract the second number from the first one.

![](bbox=[0.803, 0.423, 0.933, 0.543])

Computers use the "*" symbol, not "x", for multiplication

```
>>> 12 * 4
48
```

```
>>> 12 / 4
3.0
```

Division in Python gives an answer as a float (number with a decimal point)

+   - Multiplication
Use the "*" symbol to multiply two numbers.

+   - Division
Use the "/" symbol to divide the first number by the second one.

# ## Using brackets

Brackets can be used to instruct which part of a sum to do first. Python will always work out the value of the sum in the bracket, before solving the rest of the problem.

First it works out that 6+5 = 11, then 15 is multiplied by 3

First it works out that 5 * 3 = 15, and 15 is added to 6.

```
>>> (6 + 5) * 3
33
```

```
>>> 6 + (5 * 3)
21
```

+   - Addition first
In this sum, brackets are used to instruct Python to do the addition first.

+   - Multiplication first
Brackets are used to do the multiplication first, in order to end up with the correct answer.
