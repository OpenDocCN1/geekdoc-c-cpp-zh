# Selection sort

"Selection sort" works differently to "insertion sort". It swaps pairs of items rather than constantly shifting all of the items. Each swap moves one number to its final (sorted) position.

Swap the smallest value with the first value

![](bbox=[0.233, 0.235, 0.645, 0.295])

Swapping positions
Switching one with another is usually quick and doesn't affect anything else in the list.

Swaps 1 and 2

![](bbox=[0.233, 0.3, 0.64, 0.4])

Swap the smallest value in the unsorted part (2) with the first value in the unsorted part (6)

Swaps 2 and 6

![](bbox=[0.233, 0.373, 0.64, 0.463])

3 is the smallest value in the unsorted part. Swap it with 5, the first value in the unsorted part

Swaps 3 and 5

![](bbox=[0.233, 0.533, 0.64, 0.623])

5 isn't in the right position yet, but 4 is smaller so it's swapped

Swaps 4 and 6

![](bbox=[0.233, 0.623, 0.64, 0.713])

The largest number is in last position after the swap, so no further swapping is required

Sorted!

# Sorting in Python

There are lots of different sorting algorithms, each with different strengths and weaknesses. Python's "sort()" uses an algorithm called "Timsort", named after its designer, Tim Peters. It's based on two sorting algorithms: "Insertion sort" and "Merge sort". Type in this code to see how it works.

> "a" is a list of unsorted numbers

```
>>> a = [4, 9, 3, 8, 2, 6, 1, 5, 7]
>>> a.sort()
>>> a
[1, 2, 3, 4, 5, 6, 7, 8, 9]
```

This calls the "sort()" function

The numbers in list "a" are now sorted
