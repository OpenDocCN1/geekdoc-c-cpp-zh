
# Dictionaries

Dictionaries are like lists but they have labels. These labels, called "keys", identify items instead of index numbers. Every item in a dictionary has a key and a value. Items in a dictionary don't have to stay in a particular order, and the contents of a dictionary can be changed.

- Create a dictionary: This program creates a dictionary called "age". The key for each item is the name of a person. The value is their age.

![](img/72d218a7a73c4d4abc7be582ebd85385_136_0.png)

Dictionaries use curly brackets

Items in a dictionary are separated by commas

Use a colon between a key and a value

```
>>> { 'Mary': 10, 'Sanjay': 8 }
```

A key works the same way as an index number

A value stored in the dictionary (always comes after a colon)

```
>>> print(age) {'Sanjay': 8, 'Mary': 10}
```

The key for this item is 'Sanjay'

The value of 'Mary' is 10

Name of the dictionary

Dictionary name

New key

- Print the dictionary: The order of the items can change, because the positions of items in dictionary are not fixed.

- Add a new item: A new value can be added to the dictionary by labeling it with the new key.

```
>>> age['Owen'] = 11
{'Owen': 11, 'Sanjay': 8, 'Mary': 10}
```

Adds a new item to the dictionary

The new value is now in the dictionary

The existing value are still there

```
>>> age['Owen'] = 12
>>> print(age)
{'Owen': 12, 'Sanjay': 8, 'Mary': 10}
```

Assign a new value to the item labeled 'Owen'

- Change a value: Assign a new value to an existing key to change its value.

The value for 'Owen' has changed

- Delete an item: An item in a dictionary doesn't affect other items because they are identified by their key, not by their position in the dictionary.

```
>>> del age['Owen']
>>> print(age)
{'Sanjay': 8, 'Mary': 10}
```

The item labeled 'Owen' no longer appears in the dictionary

# Remember how variables only store values?

Variables are like boxes that hold values. The value in one variable can be copied and stored in another. It's like photocopying the value contained in box "a" and storing a copy in box "b".

> How variables work
> Each variable is like a box containing a piece of paper with a value written on it.

- 1 Assign a value to a variable
Assign the value 2 to variable "a", then assign the value in "a" to variable "b". The value 2 is copied and stored in "b".

```
>>> a = 2
>>> b = a
>>> print('a =', a, 'b =', b)
a = 2 b = 2
```

This copies the contents of "a" into "b".

"a" and "b" contain the value 2

This prints out the variable names with their values

- 2 Change a value
If you change the value stored in one variable it won't affect the value stored in another. In the same way, changing what's written on a piece of paper in box "a" won't affect what's on the paper in box "b".

```
>>> a = 100
>>> print('a =', a, 'b =', b)
a = 100 b = 2
```

"a" contains 100, but "b" still contains 2

- 3 Change a different value
Change the value in "b" to 22. Variable "a" still contains 100. Even though the value of "b" was copied from "a" at the start, they are now independent—changing "b" doesn't change "a".

```
>>> b = 22
>>> print('a =', a, 'b =', b)
a = 100 b = 22
```

"b" now contains 22, but "a" is still 100

# What happens if a list is put in a variable?

Copying the value in a variable creates two independent copies of the value. This works if the value is a number, but what about other types of value? If a variable contains a list it works a bit differently.

Use square brackets to create a list

- Copy a list
Store the list [1, 2, 3] in a variable called "list". Then store the value of "list" in another variable "listB". Now both variables contain [1, 2, 3].

```
>>> listA = [1, 2, 3]
>>> listB = listA
>>> print('listA', listA, 'listB', listB)
listA = [1, 2, 3] listB = [1, 2, 3]
```

This prints out the variable names with their values to see what's inside them

"listA" and "listB" hold the same value

This changes the second item in the list

- Change list A
Change the value in "listA" to 1000, now contains 1000 as well. Changing the copy of the list changed the original list too.

```
>>> listA[1] = 1000
>>> print('listA', listA, 'listB', listB)
listA = [1, 1000, 3] listB = [1, 1000, 3]
```

The second item of both "listA" and "listB" has't been changed.

- Change list B
Change the value of "listB" to 75. "listA" is now 75 as well. Changing the copy of the list changed the original list as well.

```
>>> listB[2] = 75
>>> print('listA', listA, 'listB', listB)
listA = [1, 1000, 75] listB = [1, 1000, 75]
```

The third item of both "listA" and "listB" has been changed

# Copy lists
To make a separate copy of the list, use the "copy()" function. "listC" will contain a link to a new list whose values are copies of "listA". "listC" won't change "listA", and changing "listA" won't change "listC".

What's on?
A variable containing a list doesn't hold the list itself, just a link to it. Copying the value in a variable copies the link. So both "listA" and "listB" contain a link to the same list.

```
>>> listC = listA.copy()
```

# Variables and functions
Variables created inside a function (local variables) and variables in the main program (global variables) work in different ways.

# Local variables
Local variables exist inside a single function, so the main program and other functions can't use them. If you try to use a local variable outside of the function, an error appears.

- Variable inside the function
Create a local variable called "func1". Print out the value of "a" by calling "func1" from the main program.

- Variable outside the function
If you try to print "a" directly from the main program, it gives an error: "a" only exists inside "func1". Local variables are like stars in a car—they are inside the car (function) but no one can see them

![](img/72d218a7a73c4d4abc7be582ebd85385_139_0.png)

```
>>> def func1():
    a = 10
    print(a)
>>> func1()
10
func1 prints the value of "a"
```

```
>>> print(a)
Traceback (most recent call last):
File "<module>", line 1, in <module>
    print(a)
NameError: name 'a' is not defined


# Global variables
A variable created in the main program is called a global variable. Other functions can read it, but they can't change its value.

- Variable outside the function
Create a global variable called "b" in the main program. The new function ("func2") can read the value of "b" and print it.

- Same global variable
We can also print "b" directly from the main program because it wasn't created inside a function.

![](img/72d218a7a73c4d4abc7be582ebd85385_139_1.png)

```
>>> b = 1000
>>> func2():
    print(b)
>>> func2()
1000
func2 gives you the value stored in "b"
```

```
>>> print(b)
1000
```

Global variable "b" can be used anywhere in the main program Global variables are like people walking along the street—everyone can see them

# Variables as input to functions
When a variable is used as input to a function its value is copied into a new local variable. Therefore, changing the value of this new local variable inside the function doesn't change the value of the original variable.

- Changing values inside a variable
"func3" uses input "y", which is a local variable. It prints the value of "y", then changes that to "bread" and prints the new value.

- Print variable
Printing the value of "z" after calling "func3" it hasn't changed. Calling "func3" copies the value in "z" into local variable "y", but "z" is left unchanged.

```
>>> def func3(y):
  print(y)
  y = 'bread'
  print(y)
>>> z = 'bread'
>>> func3(z)
# This creates a local variable "z"
bread bread
```

y contains the value passed to it when "func3" is called
 contains "bread"
This creates a local variable "z"
The input "y" now contains the value of "z" passed to it when "func3" is called
Local variable "y" of "func3" holds a copy of the value in "z". Although "y" has been changed to "bread", the value in global variable "z" isn't affected and is still "bread"

# Masking a global variable
A global variable can't be changed by a function. A function trying to change a global variable actually creates a local variable with the same name. It covers up, or "masks", the global variable with a local version.

- Changing a global variable
global "c" is given the value 12345. "func4" gives "c" the value 555 and prints it out. It looks like our global variable "c" has been changed.

```
>>> c = 12345
>>> def func4():
  c = 555
  print(c)
>>> func4()
555
```

Initial value in global variable "c"
Prints the value of "c" inside "func4"

- Print variable
If we print "c" from outside the function, we see that "c" hasn't changed at all. "func4" only prints the value of its new local variable—also called "c".

```
>>> print(c)
12345
```

The value in global variable "c" hasn't changed
