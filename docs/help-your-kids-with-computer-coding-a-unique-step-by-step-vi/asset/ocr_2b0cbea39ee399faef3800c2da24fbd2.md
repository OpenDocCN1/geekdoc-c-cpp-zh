# Scratch interface

This is Scratch’s screen layout, or “interface.” The stage is on the left and programs are created on the right.

+   Experiment
Click the buttons and tabs to explore and experiment with the Scratch interface. The projects that follow explain how to use them.

# EXPERT TIPS

# Menu and tools

This is what the menu options at the top of the screen.

+   - File
  Save work or start a new project.
- Edit
  Undo any mistakes or change the stage size.
- Tips
  If you get stuck, find help here.

# CURSOR TOOLS

Click on the tool you want to use, and then click on the sprite or script that you want to use it.

+   - Copy a sprite or script.
- Delete a sprite or script.
- Enlarge a sprite.
- Shrink a sprite.
- Get help on a block.
