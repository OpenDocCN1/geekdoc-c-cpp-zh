# # Python 3 on Windows

Before you install Python 3 on a Windows PC, make sure you get permission from the computer's owner. You may also need to ask the owner to provide an admin password during installation.

+   **Go to the Python website**
Type the address below your Internet browser to open the Python website. Click on "Download" to open the download page.

+   **Download Python**
Click on the latest version of Python for Windows, beginning with the number 3, which will be near the top of the list.

```
http://www.python.org
```

This is the URL (web address) for Python

Choose this if you have a 32-bit version of Windows

+   - Python 3.3.3 Windows x86 MSI Installer

+   - Python 3.3.3 Windows x86-64 MSI Installer

Don't worry about the exact number, as long as it has a 3 at the front

Choose this if you have a 64-bit version of Windows

+   **Install**
The installer file will download automatically. When it finishes, double-click to install Python. Choose "install for all users" and click "next" at each prompt, without changing the default settings.

+   **Run Idle**
Now check that the program installed correctly. Open the "Start" menu, click on "All Programs", "Python", and then choose "IDLE".
