
# Forever loops

Some loops run forever. If you set the condition in a "while" loop to be "True", it can never be false and the loop will never end. This can either be useful or very annoying.

![](img/72d218a7a73c4d4abc7be582ebd85385_126_0.png)

- Create a forever loop
The loop condition is set to "True". Nothing happens inside the loop will make "True" anything but "True", so the loop runs forever.

The typed word is stored in the variable "answer"

```python
while True:
    # The loop is always 'True' so never end
    answer = input('Type a word and press enter: ')
    print('Please do not type ' + answer + ' again.')
```

- What the program looks like
On the opposite monster the program's loop condition checked to see what the user's answer. If the answer isn't "y", the loop will stop. The loop shown above doesn't check the answer, so the user can't make it.

No matter what is typed, this loop keeps going on

```python
>>>
Type a word and press enter: tree
Please do not type 'tree' again
Type a word and press enter: hippo
Please do not type 'hippo' again
Type a word and press enter: water
Please do not type 'water' again
Type a word and press enter
```

> REMEMBER
"forever" block

The "forever" block in Scratch? It repeats the code inside until the red stop button is clicked. A "True" loop does exactly the same thing. It can be used to make a program doing something, such as asking questions or printing a number, as long as the program is running.

If you get stuck in an infinite loop, you can stop it from IDLE. Click in the Python shell window, then hold down the "CTRL-C" key and press the "CTRL-C". This asks IDLE to stop the program. You might have to press a few times. This is similar to clicking the red button in Scratch.

# Escaping loops

Programs can get stuck in a loop, but there are ways to escape. The word "break" leaves a loop (even a "forever" loop), and the word "continue" skips to the start of the next loop.

## Inserting breaks

Putting a break into a loop makes the program jump out of the loop at once—even if the loop condition is true. Any commands inside the loop that come after the break are ignored.

```python
table = 7
for i in range(1, 13):
    print('What\'s', i, 'x', table, '?')
    guess = input()
    if guess == ans:
        print('Correct!')
    else:
        print('No, it\'s', ans)
    print('Finished')
```

- **Write a simple program**
This program tests the user on the 7 multiplication table. The program continues looping until all 12 questions are answered. Write this program in the code window because it will be edited.

- **Insert a "break"**
A "break" can be added so the user can escape the loop. The program executes a break if the user types "stop".

```python
table = 7
for i in range(1,13):
    print('What\'s', i, 'x', table, '?')
    guess = input()
    if guess == 'stop':
        break
    ans = i * table
    if int(guess):
        print('Correct!')
    else:
        print('No, it\'s', ans)
    print('Finished')
```

> "guess" equals "stop", the program skips the rest of the loop and prints "Finished"

> "ans" variable holds the correct answer to the question

# Skipping

The "continue" keyword can be used to skip a question without leaving the loop. It tells the program to ignore the rest of the code inside the loop and skip to the start of the next loop.

# Insert a continue

Add an "if" statement inside the loop to see if the user answered "skip". If so, the program will print "Skipping" and execute a "continue" to skip to the next loop.

```python
table = 7
for i in range(1,13):
    print('What\'s', i, 'x', table, '?')
    guess = input()
    if guess == 'stop':
        break
    ans = i * table
    if guess == 'skip':
        print('Skipping')
        continue
    if int(guess) == ans:
        print('Correct!')
    else:
        print('No, it\'s', ans)
    print('Finished')
```

# What happens

If the user doesn’t want to answer a question, they can type "skip" and continue to the next question.

```python
>>>
What’s 1 x 7 ?
Type "skip"
Skipping
What’s 2 x 7 ?
14
Correct!
What’s 3 x 7 ?
```

The loop goes around again as normal when the answer is correct.

# Lists

If you need to keep lists of data in one place, you can put it in a list. Lists can contain numbers, strings, other lists, or a combination of all these.

# What is a list?

A list is a structure in Python where items are kept in order. Each entry is given a number that you can use to refer back to. You can change, delete, or add to the items in a list at any point.

# Looking at lists

Each item in a list sits inside quote marks, and is separated from the next item by a comma. The whole list sits inside pair of square brackets. The list is stored in the variable `mylist`

```python
>>>list = ['apple', 'milk', 'cheese', 'lemonade', 'tea']
```

This character is used to make code over two lines. The items in the list sit inside pair of square brackets. Just like strings, Python starts counting the items in a list from zero. So, here, position (or index) of "apple" is "0".

# How it works

You can think of lists as a row of shelves in a kitchen. Each shelf holds one item from the list. To make changes to an item, you must refer to the shelf it is on. Typing `mylist[1] = 'cake'` would replace "milk" on shelf 1 with "cake".

```python
[0]
```

The value of `mylist[2]` is "cheese"

```python
[1]
```

You could add an orange to the front of the cake by typing `mylist.insert(3, 'orange')`. The ice cream would then move to position 4, and so on

```python
[2]
```

To get to an item on the list, you must go to the right shelf. Writing `del mylist[4]` would delete "lemonade" from the list, and move "tea" into position 4 instead.

```python
[3]
```

You could add a new item, "pie", at the end of the list by writing `mylist.append('pie')`. This will then be added after "tea", in position 6

```python
[4]
```

The position of an item in a list is called its "index"

```python
[5]
```

# Using lists

Once a list has been created, you can write programs to manipulate the data inside it—in a loop; for example. You can also combine lists to make new lists.

![](img/72d218a7a73c4d4abc7be582ebd85385_130_0.png)

# Mutable objects

Lists in Python are "mutable". This means they can change. You can add or delete items, or switch around their order. Other functions in Python, such as tuples (pp. 134–135), can't altered once you create them. They are called "immutable".

- The list is stored in the variable "names"

```python
>>> names = ['Simon', 'Kate', 'Vanya']
>>> for item in names:
    print('Hello', item)
```

- The body of the loop must be indented by four spaces

Hello Simon
Hello Kate
Hello Vanya

- When run, this program displays "Hello", followed by each name on the list.

# Lists in loops

You can use a loop to work through every item in a list. This program says "Hello" to a series of names, one after the other.

```python
x = [1, 2, 3, 4]
y = [5, 6, 7, 8]
z = x + y
print(z)
[1, 2, 3, 4, 5, 6, 7, 8]
```

- Remember, lists are contained within square brackets

- The new list contains everything from list "x" followed by everything from list "y"
