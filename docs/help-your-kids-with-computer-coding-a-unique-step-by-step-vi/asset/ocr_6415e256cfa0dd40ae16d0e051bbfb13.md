# Do or do not

The “if” command means that if a condition is “True”, then the program runs a block of commands. If the condition isn’t “True”, the block is skipped. The block after the “if” command is always indented by four spaces.

+   * if condition
This code asks the user if it's birthday. It checks whether the answer is “y”. If so, a birthday message is printed.

```
ans = input('Is it your birthday?)
if ans == 'y':
    print('Happy Birthday!')
```

+   * Output if condition is “True"
Run the program and enter “y”. The message is printed. It doesn't appear if anything else is entered.

Is it your birthday? (y/n)y
Happy Birthday!

The “if” command can be combined with an “else” command. This combination means that if something is “True”, one thing happens, and if not, nothing else happens.

+   * if-else condition
