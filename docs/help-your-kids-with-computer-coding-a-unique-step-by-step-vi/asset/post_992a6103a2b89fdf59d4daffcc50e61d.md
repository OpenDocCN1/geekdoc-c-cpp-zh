Sprites are the basic components of Scratch. Every Scratch program is made up of sprites and the scripts that control them. The “Escape the dragon!” program on pages 32–37 uses the cat, dragon, and donut sprites.

## What can sprites do?

Sprites are the images on the stage. Scripts are programmed to make them do things. Sprites can be instructed to react to other sprites and the user of the program. Here are a few things sprites can do:

![](img/72d218a7a73c4d4abc7be582ebd85385_29_0.png)

- Move around the stage
- React when they touch things
- Change their appearance
- Be controlled by the user
- Play sounds and music
- Talk in speech bubbles

![](img/72d218a7a73c4d4abc7be582ebd85385_29_1.png)

## Creating and editing sprites

Games are more exciting when there are more sprites to hit, dodge, or chase each other after the stage. It's simple to create, copy, and delete sprites.

- Create a sprite
Use the buttons below the sprite list to add or create a sprite for your program.

- Copy or delete a sprite
To copy a sprite and its scripts, right-click on it in the sprite list and choose "duplicate."

![](img/72d218a7a73c4d4abc7be582ebd85385_30_0.png)

## Naming a sprite

When you start a new program in Scratch the cat sprite is called "Sprite1." It's easier to write programs if you give your sprites more meaningful names. It also makes it easier to understand and manage scripts.

- 1 Select the sprite
Select a sprite in the sprite list, and click on the blue "i" button in the corner.

![](img/72d218a7a73c4d4abc7be582ebd85385_30_1.png)

- 2 Change the name
When the information panel opens, click on the text box and use the keyboard to change the name of the sprite.

- 3 Renamed sprite
Click the blue arrow to the left of the sprite to close the information panel.

## Functions of blocks

Different types of blocks do different things in programs. Some of them make sprites move, manage some sounds, and some decide when things happen.

Motion, looks, sound, and pen
These blocks control what a sprite does on screen—this is called the output of a program. Pick a sprite and try each block to see what it does.

Events and sensing
Brown "Events" blocks make things happen. Light blue "Sensing" blocks detect information about the keyboard, mouse, and what a sprite is touching.

## Flow of scripts

When a program runs, Scratch carries out the instructions on the blocks. It starts at the top of the scripts and works its way down.

> The thoughtful cat
When this script is used with the cat sprite, the cat will wait 2 seconds, think for a moment, pause 1 second, and then move.

![](img/72d218a7a73c4d4abc7be582ebd85385_32_4.png)

Programs run from top to bottom

![](img/72d218a7a73c4d4abc7be582ebd85385_32_5.png)

To stop all scripts in a program that are running, click the red stop button above like a hexagon. You'll find it beside the green flag button used to start your program.

## Escape the dragon!

This project introduces some basic Scratch coding. It shows how to make a game to help the cat sprite dodge a fire-breathing dragon.

## Make the cat move

This stage explains how to make the cat sprite move around and chase the mouse-pointer. Follow the instructions carefully because the game might not work.

- 1 Open Scratch. Click "File" on the menu and select "New" to start a new project. The cat sprite appears.

- 2 Click the yellow "Control" button in the blocks palette. Then click the "forever" block, keep the mouse button down, and drag the block into the scripts area on the right.

![](img/72d218a7a73c4d4abc7be582ebd85385_33_0.png)

Select sprites by clicking them

![](img/72d218a7a73c4d4abc7be582ebd85385_33_1.png)

- Sprites and scripts
A project can have lots of sprites, and each sprite can have lots of scripts.

- 3 Click the "Motion" button in the blocks palette. The "Motion" commands will appear. Drag the "point toward" block into scripts area and drop inside the "forever" block. Click the arrow in the block and choose "mouse-pointer".

![](img/72d218a7a73c4d4abc7be582ebd85385_33_2.png)

```
wait 10 secs
repeat 10
forever
```

![](img/72d218a7a73c4d4abc7be582ebd85385_33_3.png)

- 4 Click the "Events" button in the blocks palette. Drag the "when green flag clicked" block into the scripts area. Join it to the top of your script.

```
clicked
forever
point towards mouse-pointer
```

![](img/72d218a7a73c4d4abc7be582ebd85385_33_4.png)
