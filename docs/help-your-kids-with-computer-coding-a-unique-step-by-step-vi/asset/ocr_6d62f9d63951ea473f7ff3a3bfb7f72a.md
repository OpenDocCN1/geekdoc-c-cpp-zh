# ## BUBBLE BLASTER

Figuring out the distance
In this game and all of others, it is important to calculate the distance between two negatives. Here is how the formula works: sqrt((x2-x1)^2 + (y2-y1)^2)

![](bbox=[0.635, 0.275, 0.795, 0.365])

```
from math import sqrt
def distance(d1, d2):
    x1, y1 = get_coords(d1)
    x2, y2 = get_coords(d2)
    return sqrt((x2-x1)**2 + (y2-y1)**2)
```
