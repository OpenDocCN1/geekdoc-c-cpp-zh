# # Making lists

Variables are perfect if you just want to remember one thing. To remember lots of similar things, lists can be used instead. Lists can store many items of data (numbers and strings) at the same time—for example, all of the high scores in a game. The following program shows one way of using a list.

+   - Create a list
  Start a new project. Go into the "Data" section of the blocks palette and click the "Make a List" button. Give your list the name "sentence".

+   - Using your list
  This script asks the user to type words into a list. Each word appears in the speech's bubble as it is added to the list.
