# Python playground

The shell window can be used to try out all sorts of Python commands, including drawing. The turtle is used to draw on screen in the same way that the pen is used in Scratch.

# Colors in the code

IDLE color-codes the text. The colors gives you some clues about what Python thinks each piece of text.

```
>>> from turtle import *
>>> forward(100)
>>> right(12)
>>> forward(100)
```

Enter the code
Type these instructions in the shell window. They run after each one is typed. As the turtle moves, it draws a line.

+   Built-in functions
Commands in Python, such as "print", are shown in purple.

+   Strings in quotes
Green indicates strings. If the brackets are green, there's a missing quote.

+   Most symbols and names
Most code is shown in black.

Turtle graphic
Can work out how to draw other shapes, such as a square or a pentagon. To start over, type "clear()" into the shell window.

Output
Python's output in the shell window is shown in blue.

Keywords
Keywords, such as "if" and "else", are orange. Python won't let you use keywords as variable names.

Errors
Python uses red to alert you to any error messages in the shell window.

# Which window should you use?

Should you use the code window or the shell? It depends on the type of program you're writing, and whether it is to be repeated.

Code window
The code window is ideal for longer pieces of code they can be saved and because it's easier than retyping all the instructions if you want to do the same thing again or try something similar. It needs to be saved and run each time, though.

# Code vs Shell

Shell window
The shell window is perfect for quick experiments, such as checking how a command works. It's also a handy calculator. It doesn't save the instructions though, if you're trying something you want to repeat, consider using the code window instead.
