# Forever loops

Some loops run forever. If you set the condition in a "while" loop to be "True", it can never be false and the loop will never end. This can either be useful or very annoying.

![](bbox=[0.655, 0.073, 0.934, 0.298])

+   Create a forever loop
The loop condition is set to "True". Nothing happens inside the loop will make "True" anything but "True", so the loop runs forever.

The typed word is stored in the variable "answer"

```
while True:
    # The loop is always 'True' so never end
    answer = input('Type a word and press enter: ')\n    print('Please do not type '\'' + answer + '\' again.')
```

+   What the program looks like
On the opposite monster the program's loop condition checked to see what the user's answer. If the answer isn't "y", the loop will stop. The loop shown above doesn't check the answer, so the user can't make it.

No matter what is typed, this loop keeps going on

```
>>>
Type a word and press enter: tree
Please do not type 'tree' again
Type a word and press enter: hippo
Please do not type 'hippo' again
Type a word and press enter: water
Please do not type 'water': again
Type a word and press enter
```

> REMEMBER
"forever" block

The "forever" block in Scratch? It repeats the code inside until the red stop button is clicked. A "True" loop does exactly the same thing. It can be used to make a program doing something, such as asking questions or printing a number, as long as the program is running.

+   EXPERT TIPS
Stop the loop
If you get stuck in an infinite loop, you can stop it from IDLE. Click in the Python shell window, then hold down the "CTRL-C" key and press the "CTRL-C". This asks IDLE to stop the program. You might have to press a few times. This is similar to clicking the red button in Scratch.
