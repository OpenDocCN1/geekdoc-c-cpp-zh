# The Internet

The Internet is a network of computers all across the world. With so many computers, clever systems are needed to make sure information goes to the right place.

# IP addresses

Every computer or phone connected to the Internet has an address, much like a building. The addresses are called "Internet Protocol (IP) addresses" and each one is made up of a series of numbers.

Internet protocol

A protocol is a list of rules.
