# Variables as input to functions

When a variable is used as input to a function its value is copied into a new local variable. Therefore, changing the value of this new local variable inside the function doesn't change the value of the original variable.

+   Changing values inside a variable
"func3" uses input "y", which is a local variable. It prints the value of "y", then changes that to "bread" and prints the new value.

+   Print variable
Printing the value of "z" after calling "func3" it hasn't changed. Calling "func3" copies the value in "z" into local variable "y", but "z" is left unchanged.

```
>>> def func3(y):
  print(y)
  y = 'bread'
  print(y)
>>> z = 'bread'
>>> func3(z)
# This creates a local variable "z"
bread bread
```

y contains the value passed to it when "func3" is called
Here contains "bread"
This creates a local variable "z"
The input "y" now contains the value of "z" passed to it when "func3" is called
Local variable "y" of "func3" holds a copy of the value in "z". Although "y" has been changed to "bread", the value in global variable "z" isn't affected and is still "bread"

# Masking a global variable

A global variable can't be changed by a function. A function trying to change a global variable actually creates a local variable with the same name. It covers up, or "masks", the global variable with a local version.

+   Changing a global variable
global "c" is given the value 12345. "func4" gives "c" the value 555 and prints it out. It looks like our global variable "c" has been changed.

```
>>> c = 12345
>>> def func4():
  c = 555
  print(c)
>>> func4())
555
```

Initial value in global variable "c"
Prints the value of "c" inside "func4"

+   Print variable
If we print "c" from outside the function, we see that "c" hasn't changed at all. "func4" only prints the value of its new local variable—also called "c".

```
>>> print(c)
12345
```

The value in global variable "c" hasn't changed
