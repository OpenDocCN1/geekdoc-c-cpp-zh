# HTML

When you open a website, your Internet browser downloads an HTML file and runs the code to turn it into a web page. To see how it works, type the code here into IDLE code window (see pp.92–93) and save it as a file with the ending "html". Double click the file and it will launch a browser window saying "Hello World!

```
<html>
<head>
<title>The Hello World</</title>
</head>
<body>
<h1>Hello World in HTML</h1>
<p>Hello World!</p>
</body>
</html>
```

Blocks of text are are surrounded by "tags", a very common feature in HTML code. This tag gives the window title

This tag shows where the HTML code ends

The "<p>" and "</p>" tags surround ordinary text
