# Making things move

Computer games are all about firing, dodging, catching, and escaping. Characters might run, spaceships, or drive fast cars. To create great games in Scratch, you need to learn how to make sprites move.

# Motion blocks

The dark blue “Motion” blocks make sprites move. Start a new project by clicking the "File" menu and choosing "New." The new project begins with the cat in the middle of the stage, ready for action.

+   First steps
Drag the "10 steps" block from the "Motion" section of the blocks palette and drop it into the scripts area to its right. Each time you click the block, the cat moves.

![](bbox=[0.285, 0.265, 0.935, 0.545])

+   Keep on moving
Drag a "forever" block from the blocks palette and drop it around the "10 steps" block. Click the green flag on the stage to run the program. The cat moves until it hits the edge of the stage.

![](bbox=[0.285, 0.555, 0.635, 0.925])

+   Bouncing
Drag an "if edge, bounce" block inside your "forever" block. Now the cat bounces when it hits the edge of the stage. The cat is upside down when it walks to the left.

This block makes the cat turn around when it hits the edge of the stage
