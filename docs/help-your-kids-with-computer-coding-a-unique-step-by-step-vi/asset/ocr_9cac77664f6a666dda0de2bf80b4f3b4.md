# Glossary

algorithm
A set of step-by-step instructions followed when performing a task: for example, by a computer program.

call
To use a function in a program.

event
Something a computer program can react to, such as a key pressed or the mouse being clicked.

GUI
The GUI, or graphical user interface, is the name for the buttons and windows that make up the part of the program you can interact with.

compression
A way of making data smaller so that it takes less storage space.

execute
See run.

hacker
A person who breaks into a computer system. "White hat" hackers work for security companies and look for problems in order to fix them. "Black hat" hackers break into systems to cause harm or to profit from them.

ASCII
"American Standard Code for Interchange"—a code used for storing text characters as binary code.

computer network
A link to two or more computers together.

file
A collection of data stored with a name.

binary code
A way of writing numbers and data that uses only 0s and 1s.

container
A part of a program that can be used to store a number of numerical values.

float
A number with a decimal point in it.

function
A piece of code that does a larger task.

bit
A binary digit—0 or 1. The smallest unit of digital information.

hardware
The physical parts of a computer that you can see or touch, such as wires, the keyboard, and the display screen.

Boolean expression
A question that has only two possible answers, such as "true" and "false".

debug
To look for and correct errors in a program.

hexadecimal
A number system based on 16, where the numbers 10 to 15 are represented by the letters A to F.

branch
A point in a program where two different options are available to choose from.

debugger
A program that checks all other programs for errors in their code.

directory
A place to store files to keep them organized.

gate
Used by computers to make decisions. Use one or more signals to produce an output signal, based on a rule. For example, "AND" gates a positive output only when input signals are positive. Other gates use "OR" and "NOT".

bug
An error in a program's code that makes it behave in an unexpected way.

GPU
A graphics processing unit (GPU) allows images to be displayed on a computer screen.

index number
A number given to an item in a list. The index number of the first item will be 0, the second one and so.

byte
A unit of digital information contains eight bits.

encryption
A way of encoding data so that only people can read or access it.

graphics
Visual elements on a screen that are not text, such as pictures, icons, and symbols.

input
Data that is entered into a computer: for example, from a microphone, keyboard, or mouse.
