# Python 快捷方式

代码 `"score += collision()"` 是 `"score = score + collision()"` 的简写。它将碰撞得分加到总分，然后更新总分。这种代码很常见，因此使用快捷方式非常有用。你也可以使用 `-` 符号执行相同的操作。例如，`"score -= 10"` 等于 `"score = score - 10"`。
