## Do or do not

The “if” command means that if a condition is “True”, then the program runs a block of commands. If the condition isn’t “True”, the block is skipped. The block after the “if” command is always indented by four spaces.

- * if condition
This code asks the user if it's birthday. It checks whether the answer is “y”. If so, a birthday message is printed.

```python
ans = input('Is it your birthday?')
if ans == 'y':
    print('Happy Birthday!')
```

- * Output if condition is “True"
Run the program and enter “y”. The message is printed. It doesn't appear if anything else is entered.

The “if” command can be combined with an “else” command. This combination means that if something is “True”, one thing happens, and if not, nothing else happens.

- * if-else condition
If “y” is entered, the program prints a special message for New Year. It shows a different message if anything else is entered.

```python
ans = input('Is it New Year? (y/n) ')
if ans == 'y':
    print('Happy New Year!')
    print('Time for Fireworks.')
else:
    print('Not yet!')
```

## Nested Loops

Loops inside a loop are called "nested loops". In nested loops, the outer loop only repeats after the inner loop has gone round its required number of times.

To make the loops repeat "n" number of times, the last number in the range must be "n + 1".

| The value of "b" | |
|---|---|
| 1 * x = 1 | First time around the outer loop (the inner loop repeats three times) |
| 2 * x = 2 | |
| 3 * x = 3 | |
| 2 * x = 4 | Second time around the outer loop |
| 3 * x = 6 | |
| 1 * x = 3 | Third time around the outer loop |
| 2 * x = 6 | |
| 3 * x = 9 | |

```python
n = 3
for a in range(1, n + 1):
    for b in range(1, n + 1):
        print(b, 'x', a)
```

## While loops

"For" loops are useful when you know how many times a task needs to be repeated. But sometimes you'll need a loop to keep repeating until something changes. A "while" loop keeps on going as long as a certain condition is true. This condition is called "loop condition" and is either true or false.

- * How it works
A loop checks if the condition is true. If it is, it goes around the loop again. If it's not, it skips the loop.

- * Create a loop
Set the starting value of the "answer" variable in the loop condition. The loop condition has to be true to start with or the loop will never run.

```python
answer = 'y'
while answer == 'y':
    print('Stay very still')
    answer = input('Is the monster friendly?')
    print('Run away!')
```
