# # Simple commands

At first glance, Python can look quite scary, especially when compared to Scratch. However, the two languages aren't actually as different as they seem. Here is a guide to the similarities between basic commands in Python and Scratch.

> Harder 104–105 commands

| Command | Python 3 | Scratch 2.0 |
| --- | --- | --- |
| Run program | "Run" menu or press "F5" (in code window) | | |
| Stop program | Press "CTRL-C" (in shell window) | | |
| Write text to | print('Hello!') | say Hello! |
| Set a variable to a number | magic_number = 42 | say magic_number to 42 |
| Set a variable to a text string | word = 'dragon' | word to dragon |
| Read text from keyboard into variable | age = input('age') print('I am ' + age) | say age? and wait join I am |
| Add a number to a variable | cats = cats + 1 or cats += 1 | change cats by 1 |
| Add | a + 2 | a |
| Subtract | a - 2 | a |
| Multiply | a * 2 | a |
| Divide | a / 2 | a |
