Ella’s birthday is July 28th. This program takes a day and a month and uses logical operators to check whether it’s Ella’s birthday.

# # Check for the birthday

Create variables for a day and a month. Use the "and" and "or" operator to check whether it is July 28th.

```
>>> day = 28
>>> month = 7
>>> day = 28 and month = 7
True
```

"and" operator checks to see if both conditions are true

Remember to use two equals signs

It’s Ella’s birthday!

# # Not the birthday detector

You can reverse the answer using the "not" logical operator. You will get the answer "True" on every day, except for Ella’s birthday.

```
>>> day = 28
>>> month = 7
>>> not (day == 28 and month == 7)
False
```

This character is used to make code over two lines

It’s Ella’s birthday, so the answer is "False"

# # Birthday or New Year’s?

Use the "or" logical operator to check whether Ella’s birthday or New Year’s. Use brackets to combine the correct days and months.

```
>>> day = 28
>>> month = 7
>>> (day == 28 and month == 7) or (day == 1 and month == 1)
True
```

Checks for the 28th of July

# # Strings

Two strings can be compared using the "==" operator or the "=" operator. Strings have to match exactly to get a "True" output.

```
>>> dog = 'Woof woof'
>>> dog == 'Woof woof'
True
```

The strings match exactly, so the answer is "True"

```
>>> dog == 'woof woof'
False
```

The strings don't match because there's not capital "W"

The strings don't match because there's an extra space before the quotation mark

# # Operator for strings

The "in" operator can be used to see whether one string is inside another string. Use it to check if a string contains a particular letter or group of letters.

This checks whether "a" is in "abc"

```
>>> 'a' in 'abc'
True
>>> 'd' in 'abc'
False
```

"d" is not in "abc", so the answer is "False"

+   * Exactly the same
Strings must match for them to be equal. This means they must use capital letters, spaces, and symbols in exactly the same way.
