## BUBBLE BLASTER

### Figuring out the distance
In this game and all of others, it is important to calculate the distance between two points. Here is how the formula works: sqrt((x2-x1)^2 + (y2-y1)^2)

![](img/72d218a7a73c4d4abc7be582ebd85385_11_2.png)

```
from math import sqrt
def distance(d1, d2):
    x1, y1 = get_coords(d1)
    x2, y2 = get_coords(d2)
    return sqrt((x2-x1)**2 + (y2-y1)**2)
```

The code 'score += collision()' is a shortcut for 'score = score + collision()'. It adds the collision score to the total. Code like this is common, so it is useful. You also do the same thing using. for example, 'score += 10' is the same as 'score = score + 10'.

## What is a computer program?

A computer program is a set of instructions that a computer follows to complete a task. “Coding", or “programming", means writing the step-by-step instructions that tell the computer what to do.

## Computer programs are everywhere

We are surrounded by computer programs. Many of the devices and gadgets we use every day are controlled by them. These machines all follow step-by-step instructions written by a computer programmer.
