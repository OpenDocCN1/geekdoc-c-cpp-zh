
# Functions

A function is a piece of code that performs a specific task. It bundles the code, gives it a name, and can be used any time by “calling” it. A function can be used to avoid entering the same lines of code more than once.

## Useful functions

Python contains lots of useful functions for performing certain tasks. When a function is called, Python retrieves the code for that function and then runs it. When the function is finished, the program returns to the line of code that called it and runs the next command.

“print()” function
This function lets the program send output to the user by printing instructions or results on the screen.

“input()” function
This function is the opposite of “print()” function. It lets the user give instructions or data to the program by typing them in.

“randint()” function
This function gives a random number (like throwing a dice). It can be used to add an element of chance to programs.

## Making and calling functions

The functions that come with Python aren’t the only ones that can be used. To make a new function, collect the code you want to use in a special “wrapper” and give it a name. This name allows the function to be called whenever it is needed.

![](img/72d218a7a73c4d4abc7be582ebd85385_131_3.png)

- 1 Define a function
The definition of a function will always have the keyword “def” and the function’s name at the beginning of the code.

- 2 Call the function
Typing the function name followed by parentheses into the shell window calls the function and shows the output.

```python
def greeting():
    print('Hello!')
```

A colon marks the end of the function’s name and the start of the code it contains

```python
>>> greeting()
Hello!
```

This is the code within the function

The “greeting” function is called and the output is displayed

Parentheses show that this is a function call, not a variable.

## Passing data to functions

A function has to be told values to work with. For example, in "print(a, b, c)", the function "print()" is passed the values "a", "b", and "c". In "height(1, 45)", the values 1 and 45 are being passed to the function "height".

![](img/72d218a7a73c4d4abc7be582ebd85385_132_0.png)

- Add parameters to the function
Values passed to a function are called "parameters". Parameters are put inside parentheses next to the function's name in its definition.

- Values are defined
The code inside the function uses the values that are passed to it.

"m" and "cm" are the parameters

Calls the function to get the answer when "m" = 1 and "cm" = 45

```python
def height(m, cm):
    total = (100 * m) + cm
    print(total, 'cm tall')
```

```python
>>> height(1, 45)
145 cm tall
```

Prints the value of "total" followed by "cm tall"

Shows that 1 m 45 cm is equal to 145 cm

Work out in the total "cm", the value of "m" needs to be multiplied by 100 (because 1 m = 100)

## Getting data back from functions

![](img/72d218a7a73c4d4abc7be582ebd85385_132_1.png)

Functions are most useful when they send some data back to the program—a return value. To make a function return a value, add "return" followed by the value to be sent.

- Define a function that returns a number
Python's "input()" always returns a string, even if never is a number. The new function below gives back a number.

- Number as output
If the program used the function "input", "a + b" would put the strings "10" and "7" together to get "107".

```python
def num_input(prompt):
    type = input(prompt)
    num = int(type)
    return num
```

```python
Enter a 10
Enter b 7
a + b = 17
```

Returns the value stored in the variable

This converts the string into a number and stores it in the variable "num"

```python
a = num_input('Enter a')
b = num_input('Enter b')
print('a + b =', a + b)
```

Adding "a + b" outputs "107" because the function "num_input" gives back numbers, not strings.

## tuples and dictionaries

Python uses lists for keeping data in order. It also has other data types for storing information called "tuples" and "dictionaries". Data types such as these, which hold lots of items, are called "containers".

## Tuples

Tuples are a bit like lists, but the items inside them can't be changed. Once a tuple is set up it stays the same.

### What is a tuple?
A tuple contains items separated by commas and surrounded by brackets. Tuples are useful for collecting several bits of data, such as a dragon's name, age, and height.

```python
>>> dragonA = ('Sam', 15, 1.70)
>>> dragonB = ('Fiona', 16, 1.68)
```

The items in a tuple are separated by commas

![](img/72d218a7a73c4d4abc7be582ebd85385_135_1.png)

### Grabbing an item from a tuple
Get an item from a tuple, use its position in the tuple (its index). Tuples count from zero, just like lists and strings.

```python
>>> dragonB[2]
1.68
```

This selects the item from position 2

```python
>>> name, age, height = dragonA
>>> print(name, age, height)
Sam 15 1.7
```

### Splitting a tuple into variables
Assign variables to the tuple "dragon"—"name", "age", and "height". Python splits the tuple into three items, putting one in each.

The items that make up the tuple "dragon" are displayed separately

### Create a list of tuples
Lists go in square brackets

- Putting tuples in a list
Tuples can be put into a list containers can go inside each other. Use this code to create a list of tuples.

```python
>>> dragons = [dragonA, dragonB]
>>> print(dragons)
[('Sam', 15, 1.7), ('Fiona', 16, 1.68)]
```

Each tuple is surrounded by round brackets inside the list's square brackets

Python displays all the items that are in the list, not just the names of the tuples
