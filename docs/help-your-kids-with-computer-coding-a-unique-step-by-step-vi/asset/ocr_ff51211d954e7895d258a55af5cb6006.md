# Using a variable

Variables can be used to change a sprite's speed. This simple script shows you how.

+   **Set the value of a variable**nCreate this script. Use the "sets steps to 0" block and change the name to 5. Drag the "move 10 steps" block into the script, but drop the "steps" variable over the "10".

+   **Changing the value of a variable**nUse the "change steps by 1" block to increase the value of the variable "steps" by 1. Put it inside the "forever" block, so the cat keeps on getting faster.
