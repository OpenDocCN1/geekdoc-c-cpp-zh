**Regions:** IaaS providers may offer services in multiple cloud regions. A cloud region should be independent both physically and virtually from other regions in a cloud provider's network but should also be accessible via high-speed private networks for data and service replication. Providers may use region replication as a method to assure a high level of uptime in their SLA.

**Security groups:** IaaS providers typically offer some form of infrastructure-based security. Some limit this to delegated user access to view, modify, or create IaaS resources; others offer a fully functional firewall service.

**Server instance:** A server instance is an operational server in an IaaS environment. It utilizes an operating system, storage resource, and CPU/memory resources. It may or may not be located on its own hardware (see discussion of public and private clouds in chapter 3).

**Snapshots:** Snapshots are common in IaaS environments and set a “point in time” backup of a server or storage resource. In the Amazon environment, snapshots are incremental, meaning that each successive snapshot stores only the changes from the previous snapshot. This speeds backup times and saves considerable storage space.

**Virtual private network (VPN):** IaaS providers may support the creation of a virtual network that limits access to servers based on IP addresses. Users may want to leverage VPN resources in their organizational environment to limit access to sensitive ports (e.g., port 22—SSH).

## USING IAAS IN A TRADITIONAL IT APPROACH

Although considering IaaS from “traditional” and “cloud-aware” perspectives may seem artificial, it provides a means to explore the functional implications of different approaches to IT service management in an IaaS environment. As with the wide range of PaaS platforms, IaaS can include a confusing array of options and certainly requires a close examination of the issues explored in chapters 2 and 3, not least of which are the staff expertise, organizational policy, and legal issues associated with moving to cloud services.

In this section we explore platforms that emphasize the traditional server life cycle model (configure, secure, deploy, manage, upgrade, and decommission). The five examples included here are prevalent in the professional literature but are certainly not exhaustive.

## IaaS Provider Examples

There are many public or community cloud providers for IaaS services. This book focuses on three in particular (Amazon, Rackspace, and Linode), but there are a host of other providers including GoGrid (http://gogrid.com), Internap (http://internap.com), and Hexagrid (www.hexagrid.com). There are IaaS brokers and value-added service providers such as RightScale and Cloudability. In the private cloud environment, solutions include Eucalyptus, Cloud Foundry, VMWare, and OpenStack.

## Amazon Web Services

Amazon Web Services (AWS, http://aws.amazon.com) is perhaps the best known IaaS cloud provider (figure 5.1). Amazon supports a wide range of services including server hosting (EC2), cloud storage (S3, EBS), service monitoring, notification services (SES, SQS), Relational Database Services (RDS), and DNS (Route 53), and service templating (CloudFormation) and monitoring (CloudWatch). In addition, Amazon provides support for public, private, and community cloud environments.

An important strength of Amazon’s service is its seven different cloud regions, which make it possible for customers to implement a geographically separated cloud infrastructure. The four levels of support include an enhanced SLA that defines support request response time, types of support activities, and scope of systems supported. The Amazon premium support costs, ranging from $49 per month to over $15,000 per month, illustrate why IaaS services tend to be cheaper than PaaS or SaaS services.

## Linode

Linode provides an IaaS service similar in scope to many of Amazon’s services (figure 5.2). Like Amazon, Linode offers different server levels, from 512 MB to 20 GB RAM. Unlike Amazon, which charges for resources by the hour, Linode charges on a monthly basis. Linode nodes (or servers) come with a specified level of included storage and CPU resources and can be deployed in one of six zones in the United States, Great Britain, or Japan. Linode uses a customized language to deploy and manage servers using the Xen virtualization platform. All Linode nodes include premium support services. Unlike some other IaaS providers discussed in this chapter, Linode offers automated backup and restoration services as well as node-balancing services. By facilitating the process of backup and balancing, Linode helps users capitalize on cloud features with little required knowledge or effort. In addition to backups, Linode offers add-on services that include extra computing resources (e.g., RAM, hard-disk space, bandwidth, or IP addresses). It supports internal cloning of servers and features configuration profiles to help manage server builds.

## Rackspace

Rackspace (http://rackspace.com) provides a range of both PaaS and IaaS IT hosting services (figure 5.3). Like Amazon, Rackspace supports several server platforms including Windows and Linux distributions. These cloud servers range in scale from 256 MB to 30 GB RAM and are licensed on a hourly basis. In addition to providing unmanaged server instances, Rackspace provides premium support including managed IT resources, PaaS services including e-mail services and web-hosting services (CloudSites), and private cloud services.

Rackspace offers a wide range of managed and unmanaged hosting services and features customization options similar to Linode’s. It offers a limited selection of machine images but provides support services as part of the hourly server charge and offers a graphical interface for backup configuration and management. Rackspace’s support for very small servers (256 MB RAM, 10 GB hard drive space) means that organizations can employ a multilevel architecture that scales servers down when possible to save computing resources. At current prices, the smallest server at Rackspace can operate for approximately $11 per month. In addition to low-cost servers, Rackspace offers managed servers that include load balancing and automatic scaling.

Like Amazon, Rackspace includes server metrics and monitoring services as part of the run-time server costs. The inclusion of an infrastructure-level backup service and built-in support services can make it an appealing option for libraries seeking more control over their server infrastructure but unsure about server management elements such as operating system and backup management.
