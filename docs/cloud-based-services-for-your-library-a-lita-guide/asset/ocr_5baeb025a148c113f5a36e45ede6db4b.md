Table 2.4 shows service/platform groupings used by 10–19 percent of participants. Services are listed multiple times (e.g., website) if their adoption rate met the range associated with the table in multiple categories.

These adoption levels indicate some common trends in the libraries surveyed. For example, older systems such as ILS and library OPACs tended to be both widely adopted and run only in a nonvirtualized environment. Likewise, client computing tended to be nonvirtualized (e.g., public client computers and staff client computers), but there were instances of desktop virtualization for both client and staff solutions. In contrast, more recently developed systems (e.g., discovery services) and datacentric systems (e.g., OpenURL resolvers) tended to be virtualized using in-house or external cloud systems or outsourced completely. For example, Table 2.2 shows that 24 percent of respondents ran a discovery service as an outsourced service, an additional 11 percent ran the service using some form of virtualized or cloud platform, and 3 percent indicated that these services were run as a nonvirtualized service. Although several systems grouped around nonvirtualized and outsourced solutions, it was interesting to note that the only service that showed a substantial locally or cloud-based (but not outsourced) virtualized solution was the library website (31 percent).

As table 2.3 shows, some systems fit into multiple implementation platforms. For example, both OPAC and library website systems fit under both internally virtualized and nonvirtualized platforms. It is interesting that this view of the data shows a grouping of systems under either nonvirtualized or outsourced solutions. This gap in adoption points to an interesting trend in cloud adoption toward outsourced solutions. Table 2.4, which shows that fewer libraries use internal and external virtual/cloud systems, supports this trend and indicates that libraries less frequently adopt internal virtualization and external PaaS/IaaS cloud solutions as compared to nonvirtualized or SaaS solutions. The lack of use of externally virtualized (e.g., PaaS or IaaS) services raises questions about the factors that influence library adoption of technology platforms and could have a considerable impact on the development of new library systems (particularly open-source solutions) in the coming years.

A second trend in the data is the prevalence of data-intensive and new genres of systems in the outsourced category while traditional systems (e.g., the ILS) remain nonvirtualized.
