Another important part of working with IaaS services is determining server capacity needs. All IaaS providers discussed here offer a variety of CPU, RAM, and storage space options, but it may be necessary to test application installs on multiple platforms to find the best-performing and most economical configuration. As an example, Uspal et al. (2011) used a multifaceted approach to test AWS server capacities against comparably sized locally virtualized and physical servers. Although there were variations in server CPU capacity and available memory, all three servers used Intel Xeon CPUs running at approximately 2 GHz and had 6–8 GB of RAM. The researchers used an input/output file testing system named Bonnie++ (www.coker.com.au/bonnie++), MySQL database loading routines, and an ImageMagick (www.imagemagick.org) image-processing routine on 10 million images on all three server platforms as a comparison of server performance. Their tests found that the Amazon server outperformed both the local physical and locally virtualized server in all three tests, with the most dramatic differences associated with file input and output operations. For example, in the Bonnie++ test Amazon servers completed read operations at 92K per second as compared with 38K per second for physical and 18K per second for locally virtualized service. Disk writing and ImageMagick processing showed similar results.

IT service monitoring is another key aspect of efficient service management. Monitoring is increasingly a built-in feature for IaaS systems but often focuses on server monitoring as opposed to application monitoring. Server resource monitoring (e.g., CPU load, hard drive usage, input/output) is important, but so is application monitoring since it allows IT departments to act ahead of application crashes. Large IT departments may have a complex monitoring system, but even small departments need a monitoring solution that ensures services are operational. For organizations seeking a large amount of control, systems such as Nagios (http://nagios.org) provide monitoring for applications, disk utilization, CPU utilization, and a host of other resources. There are also SaaS alternatives to Nagios, including NewRelic (http://newrelic.com) and LogicMonitor (http://logicmonitor.com), that offer similar-scale monitoring services.
