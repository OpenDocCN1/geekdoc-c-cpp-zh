For example, there are hosted open-source products in the ILS, DAMS, and virtual reference service (VRS) product categories. It is less common to find open-source link resolvers and cloud-based discovery services, primarily because these services rely on licensed data sets that are difficult if not impossible to obtain outside of vendor contracts. In particular, these applications that are data-management intensive are good candidates for SaaS approaches because they result in savings at both the IT level and staffing levels in the rest of the organization.

# Community Virtualization/Cloud Providers

Cloud hosting for library-specific applications is offered by commercial providers such as Equinox (http://equinox.com) and ByWater Solutions (http://bywaterwsolutions.com) and by nonprofit providers such as Lyrasis (http://lyrasis.org). Many of these providers support multiple systems and open-source platforms. This approach is also being explored by Amigos Library Services, which is piloting a virtualized deployment of the Koha open-source library system with partner libraries (www.amigos.org/node/837). The Amigos project is considering both the technical aspects of virtualized service hosting and the logistics of providing data migration and other ILS-specific services in a hosted environment.
