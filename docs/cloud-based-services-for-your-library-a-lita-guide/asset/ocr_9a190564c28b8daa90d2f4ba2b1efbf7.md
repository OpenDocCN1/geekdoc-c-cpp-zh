# Infrastructure Administration

The administration of infrastructure-level services focuses on core elements including network, server, and operating systems. Infrastructure-level administration often comes with beginning-to-end responsibility for an information service and requires the ability to design and deploy a hardware (both virtualized or physical) infrastructure, install and configure software, secure and maintain distinct IT components (e.g., server, network, security), and manage change in service configuration and deployment. This requires a familiarity with security measures (e.g., firewalls, user access, and system updates) and IT service management (e.g., service configuration, deployment, backup, failover, and depreciation) and a granular understanding of the implications of system design on the information service. In a cloud environment this also means a wider familiarity with cloud service elements that constitute an IaaS environment (e.g., server images, volume snapshots, security groups). The NIST reference model expands on infrastructure-level skill requirements with ten technical factors to be considered in relation to cloud computing adoption (Fang et al. 2011):

+   1. Creating, accessing, updating, and deleting data objects in clouds
+   2. Moving virtual machines and virtual appliances between clouds
+   3. Selecting the best IaaS vendor for a private externally hosted cloud
+   4. Tools for monitoring and managing multiple clouds
+   5. Migrating data between clouds
+   6. Single sign-on access to multiple clouds
+   7. Orchestrated processes across clouds
+   8. Discovering cloud resources
+   9. Evaluating SLAs and penalties
+   10. Auditing clouds

Some of these tasks are highly technical and require infrastructure-level expertise. For example, creating, managing, and migrating virtual machines requires understanding how to allocate infrastructure resources and configure systems and applications. Other tasks including evaluating SLAs, discovering new cloud resources, and auditing cloud services are important for all approaches to cloud computing. Given the complexity inherent in many of these technical factors, it may be necessary to choose those that are more important in a particular environment.
