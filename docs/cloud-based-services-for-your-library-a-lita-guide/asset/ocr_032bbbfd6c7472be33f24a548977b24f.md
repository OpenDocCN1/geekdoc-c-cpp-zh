In the next section we explore highly scalable platform stacks (e.g., Amazon Elastic Beanstalk, Heroku) that abandon the server model and instead adopt an application-hosting framework. As you might expect, these two types of PaaS platforms are tuned to different IT needs. For example, server-based PaaS solutions work well in generic LAMP environments where scalability is less important than access to an application stack that has certain automated management features added to it (e.g., configuration, backups, security). In contrast, application-based PaaS environments are best suited to highly customized application stacks and development environments. Regardless, server-based PaaS solutions of both forms are not widely supported by off-the-shelf library information systems. Likewise, the fixed application stack and, in some cases, limited administrative access can limit the potential uses of server-based PaaS solutions and may relegate them to testing or small production deployments.
