# Essential Characteristics

The NIST model features several essential characteristics that can be used to help differentiate cloud services. These characteristics describe an environment in which IT services can be allocated by the end user (e.g., on-demand self service), can be scaled as needed (e.g., rapid elasticity), and which are paid for by a subscription as opposed to a one-time purchase fee (e.g., measured service). NIST essential characteristics also describe an environment in which services are available across the network and IT resources are colocated to facilitate sharing and scaling. In contrast, traditional IT environments focus on locally hosted hardware purchased through one-time capital expenditures, planned as opposed to on-demand capacity, and static or more slowly changed service offerings. It is important to consider these features (e.g., elasticity, scalability, on-demand) when examining cloud solutions, but it is equally important to consider which features are preferable for a given service. For example, in the library marketplace outsourced or hosted IT services and dedicated SaaS providers often offer cloud services that are neither on-demand nor elastic but which may make use of these characteristics to create and manage their underlying cloud infrastructure.
