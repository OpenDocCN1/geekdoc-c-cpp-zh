This means that many libraries could find that their calculations more closely match Reese’s view, in which an organization saves resources by making a focused investment in just a single type of computing platform. Figure 3.1 includes a combination of these potential costs in a single ROI matrix.

Figure 3.1 groups cost areas into four sections: initial, ongoing, service management, and labor. The specifics of each area depend on an institution’s resources but could include firewalls, load balancing, network switches, Internet traffic expenses, and hardware servers. Such a model is useful as a checklist, but it can lead to a complicated cost calculation in organizations like libraries that often operate as a subunit within a larger organization. For example, libraries are often dealing with a set level of IT infrastructure that is either nonreplaceable or has no direct costs (e.g., an organizational firewall) but may see direct costs based on server acquisition need.
