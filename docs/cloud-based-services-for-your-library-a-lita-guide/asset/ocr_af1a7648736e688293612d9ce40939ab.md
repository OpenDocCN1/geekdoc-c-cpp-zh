# RedHat OpenShift

OpenShift is Red Hat's PaaS (https://openshift.redhat.com) environment (figure 4.6). It provides support for Java, Ruby, PHP, Perl, and Python applications and JavaScript frameworks including Node.js. OpenShift provides command line tools, REST-based APIs, Git integration, and a browser-based console to configure, deploy, and manage applications. OpenShift also supports cloud-based server creation and management using the AWS platform.

Much like the other PaaS platforms reviewed, OpenShift features a customized application management platform that uses platform-specific tools and instructions. Like other PaaS-based application platforms, OpenShift includes a defined SLA (https://access.redhat.com/support/), SSL, application version control, and some form of DNS management.
