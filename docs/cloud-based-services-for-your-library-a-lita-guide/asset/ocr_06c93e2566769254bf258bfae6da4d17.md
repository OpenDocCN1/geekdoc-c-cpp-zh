# Dedicated Virtual Server

A dedicated virtual server is a server to which a user account has exclusive access. Dedicated virtual servers are likely to have a web-based management console and are more likely to allow substantial access to the system for changes to application configuration and versions. At the same time, a dedicated virtual server is likely to be managed at the operating system level by the host company and to feature customized support including tutorials, guides, and even real-time assistance. Dedicated virtual servers include CPU, memory, and disk space allocations along with a level of separation from users not found in shared virtual server environments. As with shared virtual server environments, care should be taken to understand fully the security, privacy, replication, and management features of a dedicated virtual server environment. Legal and technical risks associated with running in a dedicated virtual server environment mean that it is important for providers to have automatic failover capabilities to ensure that a dedicated virtual server is not tied to specific hardware.

Dedicated virtual server environments are capable of running small-scale library-specific applications but are likely too small for discovery or DAMS services that require significant memory and disk storage. Dedicated virtual server environments are best suited for libraries with specific needs not met by hosting in a shared virtual server environment but that also do not want the cost or expertise requirements that come with dedicated server or IaaS solutions.

# Dedicated Physical Server

Dedicated physical servers more closely match a managed data center model than the other cloud computing and virtualization models discussed in this book. Many vendors offer dedicated physical servers as an alternative for organizations seeking more capacity or isolation but in a managed environment. This management level is likely to include web-based control panels and super-user access to the machine and does have even higher capacity than dedicated virtual servers. The physical isolation is likely to come with virtual network isolation as well, so that one's server is not accessible by other customers in the data center. This can be an advantage if there are significant concerns over security and privacy, but these advantages are most likely outweighed by the risks associated with being tied to specific IT hardware.
