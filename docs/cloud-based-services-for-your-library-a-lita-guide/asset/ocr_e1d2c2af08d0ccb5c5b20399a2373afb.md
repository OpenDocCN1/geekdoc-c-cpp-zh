This model uses Ylastic to provide application monitoring for both Amazon and Heroku cloud platforms and backup and region migration services for the Amazon platform. Cloudability provides cost auditing for both Amazon and Heroku. By monitoring cost and resource utilization, Cloudability allows administrators to get a consistent cross-provider view of their environment. Although it focuses exclusively on Amazon, Ylastic is able to provide advanced auditing for orphan resources such as unattached EBS volumes. This approach capitalizes on adding value to IaaS platforms by tracking overreserved resources and automating complex functions. For example, our first model highlighted the lack of a simplified backup service in the AWS web console. To address this, Ylastic provides a managed backup service for both EBS volumes and AMI creation services. As figure 5.7 shows, Ylastic offers automated and scheduled tasks that can facilitate server management. In addition, it provides a graphical interface for service replication across multiple AWS regions. Given the fact that Amazon's SLA is based on the ability of subscribers to redeploy services in another region, having a service that facilitates this process could be valuable. The automatic scalability of Heroku, the region replication services of Ylastic, and the resource use notification functions of Cloudability are all features that can save money and simplify IT environments by allowing libraries to scale their services on demand. In a traditional IT model, IT service capacity is centered around the notion of “n+1”—that is, always having more capacity than needed. In a well-managed cloud environment, services can scale up or down based on need or can be replicated into new regions when required, making it possible to provide services “just in time.”

Although Ylastic charges for its basic service, some SaaS services do come at no cost for smaller users. Cloudability, for example, provides free cost-auditing services for subscribers with less than $2,500 in cloud expenditures. Likewise, cloud configuration/monitoring services like RightScale and monitoring services including Monitor.Us include a free subscription level. Nevertheless, free services may not be desirable given the lack of local control that often comes with them (see chapter 3).

The benefits of this approach include selective redundancy across multiple cloud providers; automation of infrastructure-level tasks (e.g., backups); clearer understanding of cost and resource utilization; ability to support otherwise unavailable services via SaaS solutions; and automatic scaling, replication, and notification features that allow libraries to move away from the “just in case” models of IT planning to a “just in time” model.
