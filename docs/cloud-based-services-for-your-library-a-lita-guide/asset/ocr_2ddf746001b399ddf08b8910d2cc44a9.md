# Software as a Service and Platform as a Service

In this chapter we examine three specific forms of cloud computing and virtualization: SaaS applications by library-specific providers, PaaS using traditional server-type hosting, and PaaS using dedicated application hosting. I discuss providers that exemplify each model and evaluate each using four broad criteria: expertise required to implement and manage the service; service complexity, sustainability, and durability; service cost; and service migration and portability.

Before exploring each of these concepts in depth, it is useful to define a few technical concepts:

Containers: PaaS solutions deploy services in a construct called a container or environment. This construct defines the available resources, security, and scalability associated with a service distribution. Although containers may be started, or “spun-up,” this does not mean that they are running on distinct server resources.

Deployments/distributions: PaaS and SaaS environments offer scalability and simplicity by bundling services into a package that can be deployed as a whole on the IT infrastructure. PaaS services specifically tend to support the concept of version control in conjunction with distributions, which makes it easy to test multiple versions of the same service.
