# Security

There are a host of security issues that affect both the comfort level for adoption of cloud services and also the sustainability of a cloud-based service once it is selected. In general, the goal of system security is to prevent unauthorized access to IT infrastructure, administrative services, and user-facing services. It also includes preventing interruptions in connectivity and the hardening of systems against intrusion attempts using open ports, cracked passwords, software vulnerabilities, and back-door and man-in-the middle attacks. The work in this area includes a necessary focus on traditional IT security measures including active monitoring, firewall and application control, penetration testing, and incident management and response, but it also involves new security issues related specifically to cloud platforms, such as virtual private networking, multiplatform monitoring, data center certification, and trusted user authentication (Constantin 2011). For librarians interested in learning more about security management, Limoncelli et al.’s (2001) guide to system administration provides a foundation for approaching IT security issues and includes a focus on the role of policy and auditing in ensuring consistent and durable system security.

A central policy and procedure checklist may help organizations with security monitoring, but other areas in a cloud environment also need attention. For example, the addition of multiple platforms in a cloud computing environment means that security concerns need to be assessed both for individual systems and for the connections between systems. In addition to the common security risk areas of authentication, server isolation, and data protection, cloud-centric risk areas include security holes in the selected hypervisor platform, the risks associated with running in a common virtualized environment, and the risks associated with operating servers in a public or community network (e.g., firewalls, access, file permissions).
