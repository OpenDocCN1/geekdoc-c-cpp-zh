**32 bit vs. 64 bit operating system:** These numbers refer to the underlying architecture on which the operating system runs. These different hardware architectures require different versions of the operating system, capable of different levels of CPU and memory management. Many IaaS providers base the type of operating system on the server size selected and use some method to automatically scale a 32 bit system to a 64 bit system. Amazon does, however, support operating 64 bit computing images on 32 bit platforms, making it preferable to select a 64 bit operating system distribution if scaling to larger servers is a potential need.

**Application programming interface (API):** In cloud environments, an API is a standardized programmatic mechanism for interacting with a web service. All IaaS providers have some form of API and often provide enhanced service and functionality through programmatic tools that implement the API functions. There is some effort to begin standardizing cloud API using open-source approaches.

**Backup/restore:** IaaS providers typically have some systemwide method for handling server and storage space backups. Some vendors provide a managed backup solution (e.g., Linode); others simply provide cloud infrastructure backup tools (e.g., Amazon).

**Bandwidth/transfer in and out:** IaaS vendors monitor and charge for traffic to and from server instances. It is becoming less common for vendors to charge for incoming traffic, but all vendors discussed in this chapter charge for outgoing traffic. Some vendors (e.g., Linode) include base data transfer levels with server instances.

**Cloud file system:** Cloud file systems are differentiated from traditional file systems in that they are accessible via APIs rather than via traditional disk or mounting mechanisms. Cloud file systems may feature automatic replication, version control, and other value-added services that make them more reliable than traditional storage.

**Configuration profile:** Configuration profiles are sets of instructions that facilitate the configuration and deployment of cloud resources. This is an emerging feature of IaaS providers and is implemented differently in each IaaS solution explored in this chapter.
