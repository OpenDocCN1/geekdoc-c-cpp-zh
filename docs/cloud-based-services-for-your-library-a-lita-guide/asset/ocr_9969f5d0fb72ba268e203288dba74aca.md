# Understanding server management, service monitoring, and replication.

Server management encompasses server configuration, monitoring, security management service replication, and system updates. At the very least, a server administrator should understand how to create and manage users, how to install and secure applications, how to harden servers against attacks, how to use firewalls as an additional level of security, and how to automate logs and log rotations. Services need to be designed in such a way that they are resistant to configuration atrophy, hardened against attempts to compromise functionality, and capable of being restored or reconfigured easily.

The best way to test the ability to replicate a server is to restore it from scratch using only system backups. Where possible, processes should be automated, and where gaps in service are detected new procedures should be put in place. In the cloud environment it is important that failover plans include the ability to move into different availability zones on a single cloud provider or to migrate to other cloud providers. Services such as RightScale simplify this process by supporting a mechanism to replicate servers across multiple providers. Likewise, Amazon features the ability to migrate services via command line tools. As part of this process it is important to understand what services are available in the case of an availability zone outage.

Another approach to server replication that is gaining support in IT departments is automatic configuration and server deployment that does not rely on cloud providers. Server configuration tools such as Puppet and Chef replace the “golden egg” approach with easily deployed configuration scripts. These scripts document each step in the server creation and configuration process up to and including restoration of data and movement into production. Using such “actionable” configuration documentation, IT departments can save a great deal of time by both restoring service quickly and avoiding downtime by using the configuration scripts to monitor operating servers.
