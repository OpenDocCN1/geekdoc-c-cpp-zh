Linode's system documentation and Mitchell's AWS-focused 2011 LITA preconference tutorials (http://erikmitchell.info/lita_2011_aws/aws_tutorials.pdf) can serve as initial guides through these environments. Many companies also publish a series of higher-level guides, video tutorials, and webinars intended to help adopters implement secure services. Because Linode's documentation often includes tailored tutorials for Ubuntu, Fedora, CentOS, and other flavors of Linux, it helps readers understand both the broad concepts of system administration and the specific practices associated with a given platform. For users seeking to take advantage of PaaS solutions, both Heroku (http://devcenter.heroku.com/) and Amazon (http://aws.amazon.com/articles) include platform-specific tutorials on deploying applications in their environment.

# Get Started

This book outlines several approaches to cloud computing or virtualization, focusing on technical, organizational, and environmental factors that influence decision making in this area. For those libraries seeking to implement new services, cloud computing can provide a way to implement those services quickly and without considerable overhead for organizational IT. In contrast, libraries that are looking toward cloud computing as a way to transform existing IT practice are best served by examining their current IT service environment as well as the functional needs of their user community and then selecting cloud solutions that will both improve service quality and create room for new information services.

Library-specific systems are moving toward the cloud, and there are new opportunities for libraries to engage with industry-standard applications. The trend toward cloud computing has become mainstream in both the library and wider information community, and, although library adoption of cloud computing lags behind the corporate world, a robust range of services is available.
