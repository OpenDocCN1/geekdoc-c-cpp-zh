**Domain name service (DNS):** DNS is a global Internet application that resolves domain names (mycompany.com) to IP addresses (10.10.10.10). Cloud providers offer DNS solutions that are turned to the specific needs of cloud users, such as multiregion routing.

**Endpoint:** In cloud computing, an endpoint is the point at which the private cloud meets the Internet. Amazon offers multiple cloud regions, each of which serves as an endpoint for traffic from its internal cloud.

**File bucket/container:** The bucket or container is a unit of storage related to cloud-based file systems. Files can be uploaded only once identified with a specific bucket or container. Cloud providers may also associate access control with a bucket or container.

**Load balancers:** Cloud providers often support some automated method for implementing a load-balanced application. Load balancers monitor traffic on a given service and reroute traffic or scale server resources as needed.

**Machine images:** Machine images are the root of the launched servers in IaaS environments. Some providers (e.g., Amazon) allow users to upload, publish, and download images in a community portal; others (e.g., Rackspace, Linode) offer a smaller suite of vetted machine images. All services offer some mechanism by which customized machine images can be saved to the customer's cloud service and reused or repurposed.

**Messaging or queuing service:** These services provide independent means for sending messages to users or applications. Amazon offers multiple forms including Simple Email Service (SES) and Simple Notification Service (SNS). Messaging services can replace the need to run traditional e-mail and other messaging services on a machine image.

**Mountable volume:** Some IaaS providers offer a more traditional form of storage that can be mounted as a disk or volume on server resources. Amazon's form of this storage (elastic block storage, EBS) features user-controlled size, format, attach/detach services, and long-term storage.
