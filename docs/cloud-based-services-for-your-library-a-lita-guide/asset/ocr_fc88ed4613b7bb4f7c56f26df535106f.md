Although this may lead to a more durable architecture and more efficient use of resources, it can also make it difficult to monitor, audit, and manage these services.

To address these concerns there are an increasing number of vendors that provide value-added support on top of IaaS and PaaS services. Some key areas these SaaS services address are service auditing, server and application monitoring, service management automation/simplification, and administrative notification. In our second cloud model, the Amazon cloud described in the first section is retained but another application is deployed on the Heroku platform. The platform may be in use because of Heroku's ability to scale services easily, because of a good fit with an application stack (e.g., Ruby on Rails), or simply to build in a level of vendor redundancy. In this example, database and digital object storage services continue to be offered via the Amazon RDS and EBS services.
