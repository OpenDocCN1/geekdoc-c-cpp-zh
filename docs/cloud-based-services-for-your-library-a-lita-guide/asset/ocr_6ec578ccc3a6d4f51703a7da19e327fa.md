Google Apps Engine includes tutorials and, like other PaaS environments, supports SSL resolution and custom domain names through URL forwarding. Because it uses customized development and deployment environments, migration to and from this platform can be more difficult than with other solutions. Google Apps Engine recently emerged from beta status, however, and now features SLA levels for paid applications and premier support subscription options. In 2012, Google moved Google Apps Engine from beta to production and released a new beta service called Google Cloud Platform (http://cloud.google.com/), which features Google App Engine, Google Compute Engine, Google Cloud Storage, and Google BigQuery. Each of these four services supports different functions and could be considered to be different types of cloud services.

# Heroku

Heroku (http://heroku.com) supports the widest range of development platforms of the reviewed PaaS systems, including Java, Ruby, Python, Clojure, Scala, Play, and Node.js (figure 4.5). Heroku integrates with the Git version control system and uses something called a “dyno manifold” to deploy and run code. Like Google Apps Engine, Heroku features a scalable pricing structure that includes free and premium service levels. Premium features such as SSL, dedicated database support, as well as a host of proprietary add-ons can be added to your service framework in a pay-per-use system.
