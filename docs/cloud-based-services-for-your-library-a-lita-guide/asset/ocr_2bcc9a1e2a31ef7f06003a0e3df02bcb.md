A second key financial consideration is whether a library's current software licenses and platforms support migration to the cloud. Software licensing is important in both server operating system and higher-level applications. In some cases new licenses are required for cloud computing, particularly in the case of proprietary or managed operating systems (http://aws.amazon.com/windows/; http://aws.amazon.com/rhel/). In other cases, specific services are licensed in an SaaS model (http://salesforce.com). In extreme cases, it may not be possible to implement software in a cloud environment when licensing terms are strictly tied to traditional IT paradigms (e.g., per-CPU, per-user, or license-server models). Although higher-level library application licensing may not be affected by an implementation in cloud computing environments, it is important to check, particularly when a scaling infrastructure is likely to be chosen that would create additional run-time copies of the software.

It is worth noting that, although the shift to cloud computing has posed problems for open-source adoption in libraries, open-source software also simplifies the implementation of IT on cloud platforms given the lack of licensing issues. It is entirely possible to create a cloud infrastructure based wholly on open-source platforms, including operating systems, web publishing systems, and a range of library-specific applications. It is possible to use only open-source solutions in IaaS and PaaS environments, less likely to do so with SaaS solutions. Further, when libraries turn to open sources for operating system and core infrastructure elements (e.g., system backups and web servers), they may also take on additional system management responsibilities. One of the main areas of importance in this situation is the necessity to select open-source components that feature regular security and functional updates. Amazon seeks to make this process more sustainable by offering a certified version of Linux in its server templates (http://aws.amazon.com/amazon-linux-ami/). Other communities such as Ubuntu and CentOS offer regular updates as well. In addition, open-source platforms such as RedHat (http://redhat.com) offer paid support levels for Linux-based operating systems.
