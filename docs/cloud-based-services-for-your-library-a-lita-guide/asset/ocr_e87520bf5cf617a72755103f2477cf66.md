# Windows Azure

Windows Azure is a PaaS and IaaS service offered by Microsoft that focuses on Windows platforms for web services (figure 4.7). Whereas the other reviewed platforms tend toward platform-agnostic approaches but emphasize web servers including Tomcat, Apache, and Nginx, Windows Azure provides support for the .NET framework, Microsoft SQL server, and ASP.NET applications. Services are hosted using Microsoft’s Internet Information Server platform.

Like other services, Windows Azure supports load balancing, database integration, application version management, and development environment integration. Unlike Heroku, Windows Azure features durable digital object storage, positioning it as an alternative to the Amazon S3 platform that many PaaS providers support. Windows Azure also provides support for SaaS development
