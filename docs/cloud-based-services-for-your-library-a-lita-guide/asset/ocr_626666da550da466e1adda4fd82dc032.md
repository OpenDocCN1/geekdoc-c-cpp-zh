The NIST cloud computing model emphasizes several important tasks to undertake to ensure proper cloud security. These include elements mentioned above (e.g., managing access, mitigating risk associated with common IT use through firewalls, and detecting intrusion) in addition to designing applications that leverage cloud features to enhance, rather than undermine, security. There are also client elements such as web browser security and the use of client/server security certificates which, when implemented properly, can ensure a higher level of client/server security (Fang et al. 2011, 39). A final area of key importance, particularly in integrating IaaS and PaaS environments, is the sharing of authentication keys and accounts. RightScale, in particular, relies on the establishment of trusted relationships using administrative accounts and access keys with IaaS cloud platforms. It is worth noting that, once these trust relationships are established, users in the RightScale service have the ability to control at a very granular level the services running in those other environments. Likewise, many of the Amazon application programming interface (API) services rely on preshared keys. If these keys are saved on client machines, direct access to Amazon IaaS elements is available to any user of that machine. Cloud providers are beginning to offer ways to compartmentalize access to resources using identity management tools that allow system administrators to monitor which users access infrastructure-level resources and limit access based on login or key credentials.

Determining local capacity for implementing and administering cloud resources is grounded in an understanding of personnel skill and time availability, technical needs, and financial resources. These factors need to be compared with projected service cost and impact to get an understanding of how important a given service or cloud platform is. As our exploration of infrastructure, application, and platform administration shows, technical skill and capacity play a large role in selecting, implementing, and managing a service. Likewise, depending on the cloud service selected, there may be upper limits to the capacity of that given system.
