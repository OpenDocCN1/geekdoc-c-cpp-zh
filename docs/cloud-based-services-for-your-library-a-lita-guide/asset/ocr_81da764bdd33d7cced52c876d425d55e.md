These systems are particularly useful for small to medium-sized libraries, libraries exploring virtualized computing for the first time, and libraries seeking to empower staff who have an IT-focused skill set but limited time. The graphical control panel used by PaaS server providers simplifies configuration tasks and eliminates the need to take on infrastructure-level IT management tasks such as operating system maintenance, hardware management, and LAMP stack maintenance. At the same time, it preserves the ability to configure back-end applications. Not every vendor offers these functions, however, and the variation of services and options can make it difficult to select a provider.

Generally speaking, it is important to focus on required features (e.g., hosting functionality, account/data privacy, server location and data center quality, guaranteed capacity, and long-term company viability) and select a solution that fits those needs. PaaS server providers may oversell capacity, assuring customers “unlimited data and bandwidth,” but these assurances typically come with caveats and restrictions on content or hosting services (e.g., no streaming of video, no long-term object storage) that reduce the value of these features. Low-cost PaaS providers tend to avoid strict SLA agreements but are likely to provide a “service-level indication” without any clauses for compensation for downtime or any firm guarantee of uptime. More expensive PaaS providers support elaborated SLAs, expand access to the server to include higher levels of administrative access (e.g., root or super-user access), and shy away from overselling capacity, instead leasing a specific amount of disk space, CPU capacity, and application memory to subscribers. The following three sections explore three broad types of PaaS providers in more detail.

# Shared Virtual Server

A shared virtual server entitles you to reserved storage resources on a virtualized platform. These providers may feature “unlimited” disk space and bandwidth, but review of their SLAs show that the disk space is limited to the provision of web services hosted on the box and that they do not include backups or storage for file serving purposes. In addition, these providers may restrict CPU use and may not guarantee available memory, making these solutions best suited for website services, small-scale database hosting, or other services that do not consume large amounts of CPU or RAM. Because of these features, shared virtual servers come with the highest amount of risk in a PaaS environment but at the lowest cost.
