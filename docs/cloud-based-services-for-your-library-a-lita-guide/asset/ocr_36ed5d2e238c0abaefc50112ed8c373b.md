Beanstalk includes many built-in features such as instance and application monitoring, log file rotation, application version control, automatic scaling, and automatic load balancing. This suite of features is adequate to ensure high-quality service without considerable management tasks and, as our exploration of IT service management principles in chapters 3 and 6 show, delivers many of the key advantages of highly managed systems at a low cost. The Elastic Beanstalk is offered as a managed platform based on other AWS services including the Elastic Compute Cloud, Relational Database Service (RDS), and Simple Notification Service (SNS). This can be good for libraries that already use Amazon services for other cloud environments and have already worked through the legal and organizational issues associated with adopting a cloud provider. On the other hand, Beanstalk is designed around a specific deployment architecture, so systems deployed on it must be set up in a way that requires platform-specific approaches to database management, domain name management, and secure web service implementation.
