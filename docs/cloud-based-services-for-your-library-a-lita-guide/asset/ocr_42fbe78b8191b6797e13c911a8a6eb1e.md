# Understanding DNS.

DNS is the means by which server IP addresses are resolved to host names. When registering with a PaaS provider, you have the option of establishing a new domain name or mapping an existing domain name to your server. For libraries operating as part of a larger institution, it is likely necessary to work with organizational IT to associate the IP address of your PaaS server with an organizationally managed DNS server. To do this libraries should identify a PaaS provider that includes a dedicated IP address along with the subscription; this is required only if the library wants to use a domain name that is related to the larger institutions (e.g., myschool.edu) and not an independent domain name (e.g., library.com). DNS is a complex process that includes the ability to create subdomains, redirect traffic based on name configuration, and support SSL certificates. If your institution is looking to provide its own DNS support, a good overview of DNS can be found in Liu and Albitz (2006).

# Understanding service configuration.

The support underlying server-based PaaS environments makes it much easier to install, configure, and deploy applications. Many PaaS providers support one-click installs of common content management systems such as WordPress and Drupal. Although these features make it easier to get your site up and running, it is equally important to understand where the files and databases are located for these applications and to understand how application upgrades are handled. It is particularly important to understand how a hosting provider supports the addition of optional modules to popular content management systems. This often requires SSH and SFTP access as well as the ability to set user permissions, extract files, and complete other configuration tasks outside of a web interface.

# Understanding SSH/SFTP.

To take advantage of PaaS solutions, SSH and SFTP are required to transfer files to/from and interact with your server. Selecting a provider that supports SSH and SFTP is important to enable automation, configuration, and transfer of resources. Many sites support some form of SSH but also require additional security measures before they activate this service. When you are selecting a provider, it is worth knowing if it supports multiple SSH accounts and if there is some provision for using firewall restrictions to limit the IP addresses that can SSH to the hosted server.

# Understanding databases.

One of the most important elements of a web application is its database. Many web services such as WordPress or Drupal require specific database platforms and may require manual interaction with those databases.
