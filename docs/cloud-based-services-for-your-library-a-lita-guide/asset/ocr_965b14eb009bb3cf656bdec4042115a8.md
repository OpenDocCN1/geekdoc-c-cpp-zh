KOALA focuses on different cloud services and is valuable because it provides a consistent management interface for both public cloud services like Amazon and private cloud services such as Eucalyptus. The KOALA framework would emphasize a common toolkit over managed images and replication services but would provide adapters with a simple-to-use platform that solved the API discrepancies between providers.

The benefits of this approach include the highly distributed use of cloud vendors; automated replication of services and management of DNS that can be tied into monitoring tools; incorporation of private cloud functions; abstraction of server configuration from specific providers; and automatic configuration of enterprise-scale database and application services. At the same time, this distributed vendor model is more complex than the other approaches and may lead to overall higher costs. As seen in chapter 5, many IaaS providers are designing systems that tightly integrate with private cloud platforms through common APIs and cloud bursting functionality. This is a useful development, but libraries without large IT departments or with applications designed to run in traditional server environments may not be able to take advantage of these features.

# APPROACH FOUR:
DISTRIBUTED SAAS ENVIRONMENTS

The three approaches reviewed above are based on the premise that libraries will turn to PaaS and IaaS solutions for specific services. This is not to say that library-specific SaaS solutions are not yet mature enough for widespread adoption. There are now many options for libraries seeking SaaS solutions for all of their services. Existing vendors are expanding both their use of cloud approaches and their product suites, and new companies have emerged to provide website, virtual reference, media hosting, and other information services.
