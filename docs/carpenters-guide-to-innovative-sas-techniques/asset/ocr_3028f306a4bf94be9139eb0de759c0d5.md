The %SHOWSTYLES macro uses the macro language to write a report to Excel once for each available style.

```
```sas
title1 '11.2.3 Showing Style in Excel';

%macro showstyles;
%local i stylcnt;
proc sql noprint;
   select scan(style,2,'.')
      into: style1-stylemaxlong
      from sashelp.vstyle;
   %let stylcnt = &sqlobs;
quit;

%do i = 1 %to &stylcnt;
   ods markup tagset=excelxp
      path="&path\\results"
      file="&&style&i...xml"
      style=&&style&i
      options(sheet_name="&&style&i"
              embedded_titles='yes');

      title2 "Using the &&style&i Style";
      proc report data=sashelp.class nowd;
         column name sex age height weight;
         define age / analysis mean f=4.1;
         define height / analysis mean f=4.1;
         define weight / analysis mean f=5.1;
         rbreak after / summarize;
         run;
   ods markup close;
%end;
%mend showstyles;
ods listing close;

%showstyles
```
```

+   1. An SQL step is used to create a macro variable for each of the unique style names.
+   2. The number of styles found is saved in `&STYLENCT`.
+   3. Inside the `%DO` loop the style name will be contained in the macro variable reference `&&STYLE&I`. The filename, therefore, contains the style name.
+   4. The style of interest is specified on the STYLE= option.
+   5. The sheet name will be the name of the style.
+   6. The report code will be exactly the same for each of the styles.

7. The %SHOWSTYLES macro is called.
