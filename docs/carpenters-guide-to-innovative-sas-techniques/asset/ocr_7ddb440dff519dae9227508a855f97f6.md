The following example shows some of the flexibility of these statements by building three histograms that are overlaid by the normal distribution. In this example the plot generated by UNIVARIATE will be written to a file.

```
```sas
filename out821a "&path\\results\\g821a.emf";
goptions device=emf
goptions      gsfname=out821a
             nosm...

title1 '8.2.1 Plots by PROC UNIVARIATE';
proc univariate data=avdrpt.demog;
   class race sex;
   var ht;
   histogram /nrows=5 ncols=2
              intertile=1 cfill=cyan vscale=count
              vaxislabel='Count';
   inset mean='Mean Height: ' (5.2) / noframe position=ne
                                      height=2 font=swissxb;
run;
quit;
```

+   1. The plot is to be saved as an EMF file. EMF and the older CGM files are generally considered best if the plot is to be imported into a word processing document as it has been created. The EMF file type has the further advantage of the capability of modifying and editing the graph in the Microsoft Image Editor.

+   2. The DEVICE graphics option specifies the type of file to be created.

+   3. The GSFNAME graphics option identifies the fileref that points to the file that is to be generated.

+   4. The classification variables RACE and SEX form 10 combinations based on 5 values of RACE and 2 for SEX. These form the rows and columns for the plot.

+   5. In a color representation of the histogram, the vertical bars are cyan.

+   6. The scale of the vertical axis will be based on the patient counts. Other choices for the scale could include: PERCENT and PROPORTION.

+   7. A label is specified for the vertical axis of each of the five histograms.

+   8. The INSET statement inserts text, including various statistics, into the graph. Here the MEAN of HT is written in the upper right (NorthEast) corner of each graph using the 5.2 format and SWISSB, a SAS/GRAPH font. Notice that the default font for the title and the selected font for the INSET (SWISSB) are not particularly good choices.
