An easy way to store and pass along the needed information is through the use of a SAS data set. We can create a data set that contains the constraints for each data exception check. Each observation can then be used to build data exception and error trapping reports. For the previous example the data set might contain the following.

2.3.3b Data Set with Exception Criteria

| Obs | errtst | errvar | errval | errrtxt | erratring |
|---|---|---|---|---|---|
| 1 | lt 3.1 | potassium | potassium | Low value(<3.1) | 1 |
| 2 | gt 6.7 | potassium | potassium | High value(>6.7) | 2 |

This data set is then used by a macro to build a series of macro variable lists. These lists are then processed (each observation in the data set becomes a test or DO block). The %ERRRPT macro shown below builds these lists using an SQL step and then uses the lists to create a series of DO blocks using the macro variables in the list to 'fill in the blanks'.

```
```sas
%macro errrpt(dsn=, bylist=subject); ❶
%local i chknt;
proc sql noprint;
    select errtst, errvar, errval, errrtxt, erratring
        into :errtst1-:errtst99, ❷
        :errvar1-:errvar99,
        :errval1-:errval99,
        :errrtxt1-:errrtxt99,
        :erratring1-:erratring99
        from vallab; ❸
    %let chknt = &sqlobs; ❹
    quit;
data errrpt(keep=dsn errvar errval errrtxt erratring
        &bylst); ❺
    length dsn     $25
           errvar  $15
           errval  $25
           errrtxt $15
           erratring 8;
    set &dsn ❻ ;

%do i = 1 %to &chknt; ❼
    %* Write as many error checks as are needed;
    if &&errvar&i &&errtst&i ❽ then do;
        dsn = "&dsn";
        errvar = "&&errvar&i"; ❾
        errval = &&errval&i;
        errrtxt = "&&errrtxt&i";
        erratring= &&erratring&i;
        output errrpt;
        end;
%end;
run;
%mend errrpt;
%errrpt(dsn=advrpt.lab_chemistry,
        bylist=subject visit labdt) ❿
```
