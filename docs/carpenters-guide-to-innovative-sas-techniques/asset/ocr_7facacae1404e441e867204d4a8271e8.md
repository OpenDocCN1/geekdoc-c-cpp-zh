# LEGEND Statement

The general syntax, statement structure, and even many of the options of the AXIS statement are shared with the LEGEND statement. In the regression plots in Section 9.3.1, the legend appears at the bottom of the graph. We can change its location as well as its appearance.

```
```sas
legend1 position=(top left inside)
        value=(f='arial' t=1 'Height'
                       t=2 'Predicted'
                       t=3 'Upper 95'
                       t=4 'Lower 95')
        label=none
        frame
        across=2;

proc reg data=advrpt.demog;
model ht = wt;
plot ht*wt/conf
             legend=legend1;
run;
```
