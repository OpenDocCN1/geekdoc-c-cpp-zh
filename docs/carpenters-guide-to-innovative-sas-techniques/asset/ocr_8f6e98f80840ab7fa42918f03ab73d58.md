# ### 1.2.5 Preventing the Export of Blank Sheets

PROC EXPORT does not protect us from writing a blank sheet when our exclusion criteria excludes all possible rows from a given sheet ❶. In the following example we have inadvertently asked to list all students with SEX='q'.

```
~~~sas
proc export data=sashelp.class(where=(sex='q'))
    outfile='c:\temp\classmates.xls'
    dbms=excel2000
    replace;
    SHEET='sex: Q';
run;
```
