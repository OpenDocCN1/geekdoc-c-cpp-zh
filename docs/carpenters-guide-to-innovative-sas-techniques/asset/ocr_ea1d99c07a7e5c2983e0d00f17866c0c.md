+   - ① The macro variables that will contain the sensitive information are placed in the temporary local symbol table.
+   - ② We will read the password from the secret password data set. Notice that the user of this macro does not even need to know of the existence of the password data set.
+   - ③ Macro variables are retrieved by using the SYMGET function rather than the more common macro variable reference with an ampersand (&UU or &DBNAME). +   - ⑤ The user creates a macro called %PASSTHRU that contains only those SQL statements that are to be processed by the remote database. The user does not need to see anything inside the %SECRETSQL macro.
+   - ⑥ The macro call only contains information that is not sensitive.
