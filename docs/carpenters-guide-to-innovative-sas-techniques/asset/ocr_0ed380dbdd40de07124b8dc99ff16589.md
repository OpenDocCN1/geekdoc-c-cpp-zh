+   1. The temporary array holds the names of the variables of interest. The dimension has to be sufficiently large. In this example a dimension of three would have been sufficient.

+   2. A DO UNTIL loop is used to step through the unknown number of variables and to store their names in the array. Since we are dealing with the metadata at this point we only need to process this information one time.

+   3. The VNEXT routine retrieves successive variable names and stores the name and type in the variables NAME and TYPE.

+   4. All character variables (TYPE='C'), excluding those used in the DATA step, are selected for loading into the array of variable names.

+   5. The VNAMEX function is used to store the value contained in the variable NAME in the name list array. This function allows the resolved value of NAME to be recovered. The VNAME function would have stored the unresolved value (NAME).

+   6. The variable name is recovered from the array and stored in VARNAME. VARNAME now contains the name of the variable whose code we also need to recover. The VVALUEX function not only retrieves the value of that variable, but also the formatted value of that variable. Since we want the formatted value, this is perfect.

The general form of the original data is reconstructed by transforming these rows into columns using PROC TRANSPOSE.

```
    proc transpose data=namelist
        out=original(drop=_name_);
        by lname fname;
        id varname;
        var varvalue;
    run;
```
