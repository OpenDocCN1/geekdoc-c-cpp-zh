title1 '2.3.2b Hardcoded Exception Reporting';

data errrpt(keep=dsn errvar errval errtxt errrating
             subject visit labdt);
    length dsn      $25
           errvar   $15
           errval   $25
           errtxt   $20
           errrating 8;
    set advrpt.lab_chemistry;
    if potassium lt 3.1 then do;
       dsn = 'advrpt.lab_chemistry';
       errvar = 'potassium';
       errval = potassium;
       errtxt = 'Low value(<3.1)';
       errrating= 1;
       output errrpt;
    end;
    if potassium gt 6.7 then do;
       dsn = 'advrpt.lab_chemistry';
       errvar = 'potassium';
       errval = potassium;
       errtxt = 'High value(>6.7)';
       errrating=2;
       output errrpt;
    end;
run;

+   1. The list of variables in the error reporting data table includes the variables which form the primary key for this data (SUBJECT VISIT LABDT).
+   2. Read the data set to be checked.
+   3. Enter the DO block when this specific data exception has been detected.
+   4. Save the name of the data table being checked.
+   5. Save the name of the variable being tested.
+   6. Capture the data value for further inspection. When character values have been converted for the check, save the raw or character value. This allows you to see any text that might contribute to character to numeric conversion issues.
+   7. The error test should describe the problem detected in the data.
+   8. If required, assign an error severity code.
+   9. Write this observation out to the error report data set (ERRRPT).
+   10. The second exception criterion is tested in a DO block that is essentially the same as the first DO block 3.
