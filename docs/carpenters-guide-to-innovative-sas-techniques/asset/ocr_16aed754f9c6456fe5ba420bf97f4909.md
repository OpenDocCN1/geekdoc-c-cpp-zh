# ## CARGO (Container and Retrieval of Genomic Objects)

CARGO is a high-performance, low-latency data retrieval system specifically designed for genomic datasets. It addresses the scale and performance requirements of querying genomic variants, annotations, and coverage data at petabyte scale.

CARGO leverages a hierarchical storage engine with columnar compression and a cache-optimized index to support interactive genomic analysis workloads.

# ## Key Features

+   - **Fast retrieval**: Sub-millisecond lookup for variant-level queries
+   - **Compression-aware indexing**: Reduces storage footprint by up to 80%
+   - **Scalable**: Optimized for both large-scale batch processing and point queries
+   - **Flexible query API**: Supports SQL-like queries through a JDBC-compatible interface
+   - **Multi-tenant**: Built for concurrent access in shared infrastructure

The system operates across partitioned data shards, using a distributed caching layer to reduce latency for frequently accessed genomic intervals.
