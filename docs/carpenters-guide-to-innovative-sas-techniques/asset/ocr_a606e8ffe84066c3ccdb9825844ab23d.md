# 11.2.1 EXCELXP Tagset Documentation and Options

The operation of the EXCELXP tagset is controlled through the use of options. These are implemented using the OPTIONS option with the options themselves enclosed in parentheses which follow the OPTIONS keyword. Here the DOC= option is used to write the tagset’s full documentation to the LOG. If you want to learn about recent changes to the tagset, the CHANGELOG option (doc="changelog") will show you the timing of changes and summary of new features.
