Notice that the EXPLORER OPTIONS: TABLE OPTIONS dialog box is used to form the primary pop-up menu that you see when you right-click on a SAS data table (see the first figure in this section). The table name is brought into the script using %8b for the libref, and "&32b"N for the data set name.
