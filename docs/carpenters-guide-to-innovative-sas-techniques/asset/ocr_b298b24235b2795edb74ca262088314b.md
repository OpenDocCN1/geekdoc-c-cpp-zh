# ### 3.7.3 Repeating BY Variables

When merging, the BY variables should identify down to the row level in all, but at most one of the data sets named on the MERGE statement. This means that at most only one of the incoming data sets will not have a sufficient key (BY variables do not identify down to the row level).

When the BY variables do not form a primary key (identify down to the row level) for more than one data set, a NOTE is issued to the LOG, and more importantly, within the BY group the merge takes place as a one-to-one merge and this is rarely desirable.

> NOTE: MERGE statement has more than one data set with repeats of BY values.
