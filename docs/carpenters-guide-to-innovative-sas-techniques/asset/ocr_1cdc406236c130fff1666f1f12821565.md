Each of these functions supports a number of arguments that allow a variety of types of comparisons.

In the following example the data contains names of various metals that have possibly been

misspelled. We need to determine the correct spelling. Similar problems arise when trying to match names or drugs which also often include abbreviations. For this example we have a data set that contains all the correctly spelled metals (WORK.METALS).

In an attempt to simplify the code a bit for this example, the number of metals (10) and the maximum length of the metal’s name ($9) have been hardcoded.

```
```sas
data perfect (keep=datname value)
    potential (keep=datname name mincost);
  array metals {10} $9 _temporary_;
  do until (done);
    set metals end=done;
    cnt+1;
    metals[cnt] = name;
  end;

  do until(datdone);
    set namelist (keep=datname value)
        end=datdone;
    mincost=9999999;
    do i = 1 to 10;
      cost = compged(datname,metals(i),'il');
      if cost=0 then do;
        output perfect;
        goto gotit;
      end;
      else if cost lt mincost then do;
        mincost=cost;
        name = metals(i);
      end;
    end;
    output potential;
    gotit:
  end;
stop;
run;
