❾ The CALL EXECUTE routine is used to build a series of macro calls—one for each incoming observation. The macro %SLIDER is passed the parameters needed for each specific subject (the subject number and the associated BMI value). This is sufficient information for PROC GKPI to generate the subject specific indicator.

```
```sas
%slider(G200,24.3)
%slider(G201,21.4)
%slider(G202,25.1)
%slider(G203,36.5)
%slider(G204,18.0)
%slider(G205,25.1)
%slider(G206,23.0)
%slider(G207,24.3)
```
```

After all the calls to the macro %SLIDER have been executed, a series of PNG files will have been generated ❺. These files have been named ❾ so that they can be imported by PROC REPORT ❿ in the correct order.

```
```sas
ods pdf file="&path.\results\E10_2_4.pdf" style=default;

                 ...code not shown....
define slider / computed;
compute slider;
  compute slider/char length=62;
  slider=' ';
  imgfile = "style='postimage='c:\temp\"||trim(left(gname))||".png')";
  call define('slider','style',imgfile);
endcomp;
run;
