+   ④ The CHECK method is used to ascertain whether or not this is the first occurrence of this current clinic number, CLINNUM. This method returns a 0 if it has already been encountered and the DO block is not executed.

+   ⑤ When a hash object is instantiated for this clinic number, a value is assigned to the variable HASHNUM for this hash object. HASHNUM is also a data variable in the EACHCLIN object.

+   ⑥ Since this is the first time that this clinic number has been encountered, it is added to the EACHCLIN hash object. EACHCLIN is ordered by CLINNUM, but also stores the associated value of HASHNUM, which is the variable holding the value of the hash object for the current clinic.

+   ⑦ The FIND method is used to retrieve the HASHNUM value associated with the clinic number (CLINNUM) that was added to the PDV by the SET statement ③.

+   ⑧ This observation is added to the hash object that is associated with this clinic. The value of the variable HASHNUM has been retrieved from the hash object EACHCLIN ⑦ that contains the list of clinicspecific hash objects.

+   ⑨ The NEXT method is used to successively retrieve the HASHNUM values from the HEACH iterator object, which contains one item for each clinic number.

+   ⑩ The data stored in the hash object that are identified by the variable HASHNUM are written to the data set using the OUTPUT method. Notice that the name of the data set is constructed during the execution of the DO loop. The value stored in the variable HASHNUM was retrieved from the HEACH iterator object using the NEXT method ⑨, and this value, when used with the OUTPUT object, identifies which of the clinic-specific hash tables is to be written. The NEXT method also returns a value of CLINNUM which is used in the construction of the name of the data set.
