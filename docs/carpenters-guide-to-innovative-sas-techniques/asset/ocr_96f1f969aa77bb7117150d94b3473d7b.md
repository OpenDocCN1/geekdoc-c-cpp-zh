# ### 11.4.4 Creating Internal Links

While hyperlinks will usually point to the beginning of a file, it is not unusual for the link to point to a location within a file. This can be a location within a file other than the one being viewed or to another location within the same file. This is known as an internal link. In the example in Section 11.4.3 (see **2**) one of the links formed is a internal link.

Internal links are designated using a pound or hash sign (#). A pointer to an internal location within a file in the local directory might be named: `E11_4_3.pdf#_15`. The internal location is marked using the ANCHOR= option.

```
ods pdf anchor=_15;
```
