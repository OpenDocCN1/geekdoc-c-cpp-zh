# 10.3.3 Recursion

Consider the following example C program, which uses recursion to compute the factorial function:

```
    int factorial(int n) {
    <---------- 1
        if (n <= 1)
            return 1;
        else return (n * factorial(n - 1));
    <---------- 2
    }
    void main() {
        int value;
        value = factorial(3);
    <---------- 3
    }
```
