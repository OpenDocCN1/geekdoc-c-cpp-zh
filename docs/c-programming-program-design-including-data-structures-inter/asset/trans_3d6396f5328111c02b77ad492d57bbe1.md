要销毁一棵二叉树，对于每个节点，我们首先销毁其左子树，然后销毁其右子树，最后销毁该节点本身。必须使用运算符 delete 来释放该节点占用的内存。函数 destroy 的定义为：

```cpp

{

        destroy(p->lLink);
        destroy(p->rLink);
        delete p;
        p = NULL;
    }
}
```
