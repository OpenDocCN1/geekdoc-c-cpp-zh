8. Consider the following functions:

```
int find(int num)
{
    int first, second;

    first = num * num;
    second = first + num;

    if (second > 100)
        num = first / 10;
    else
        num = first / 20;

    return num + 2;
}
```

```
int discover(int one, int two)
{
    int secret = 0;

    for (int i = one; i < two; i++)
        secret = secret + i * i;

    return secret;
}
```
