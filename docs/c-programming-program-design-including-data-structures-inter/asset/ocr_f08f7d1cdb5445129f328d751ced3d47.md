# Initialize Stack

The operation initializeStack reinitializes the stack to an empty state. Because the stack may contain some elements and we are using a linked implementation of a stack, we must deallocate the memory occupied by the stack elements and set stackTop to NULL. The definition of this function is:

```
```
template <class Type>
void linkedStackType<Type>::initializeStack()
{
    nodeType<Type> *temp; //pointer to delete the node

    while (stackTop != NULL) //while there are elements in
                             //the stack
    {
        temp = stackTop;          //set temp to point to the
                                  //current node
        stackTop = stackTop->link; //advance stackTop to the
                                   //next node
        delete temp;              //deallocate memory occupied by temp
    }
} //end initializeStack
