As you can see from the preceding examples, every node in a binary tree has, at most, two children. Thus, every node, other than storing its own information, must keep track of its left subtree and its right subtree. This implies that every node has two pointers, say, lLink and rLink. The pointer lLink points to the root node of the left subtree of the node; the pointer rLink points to the root node of the right subtree of the node.

The following struct defines the node of a binary tree:

```
template <class elemType>
struct nodeType
{
    elemType info;
    nodeType<elemType> *lLink;
    nodeType<elemType> *rLink;
};
```
