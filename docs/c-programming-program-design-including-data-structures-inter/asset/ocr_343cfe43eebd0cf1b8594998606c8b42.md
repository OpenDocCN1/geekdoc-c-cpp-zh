+   1. Describe the two basic operations on a stack.

+   2. Suppose that stack is an object of type `stackType<int>`. What is the difference between `stack.top` and `stack.top - 1`?

+   5. Consider the following statements:

```
stackType<int> stack;
int num1, num2;
```

Show what is output by the following segment of code:

```
stack.push(12);
stack.push(5);
num1 = stack.top() + 3;
stack.push(num1 + 5);
num2 = stack.top();
stack.push(num1 + num2);
num2 = stack.top();
stack.pop();
stack.push(15);
num1 = stack.top();
stack.pop();

while (!stack.isEmptyStack())
{
    cout << stack.top() << " ";
    stack.pop();
}
cout << endl;
cout << "num1 = " << num1 << endl;
cout << "num2 = " << num2 << endl;
```
