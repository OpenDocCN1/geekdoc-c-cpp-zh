

### 初始化链表

该操作将双向链表重新初始化为空状态。该任务可以通过使用 destroy 操作来完成。函数 initializeList 的定义如下：

```cpp
template <class Type>
void doublyLinkedList<Type>::initializeList()
{
    destroy();
}
```

### 链表的长度

链表的长度（即链表中节点的数量）存储在变量 count 中。因此，该函数返回此变量的值。

```cpp
template <class Type>
int doublyLinkedList<Type>::length() const
{
    return count;
}
```

### 打印链表

print 函数输出每个节点中包含的信息。我们从第一个节点开始遍历链表。

```cpp
template <class Type>
void doublyLinkedList<Type>::print() const
{
    nodeType<Type> *current; //pointer to traverse the list

    current = first;  //set current to point to the first node

    while (current != NULL)
    {
        cout << current->info << "  ";  //output info
        current = current->next;
    }//end while
}//end print
```

### 反向打印链表

该函数按相反顺序输出每个节点包含的信息。我们从最后一个节点开始逆序遍历链表。其定义如下：

```cpp
template <class Type>
void doublyLinkedList<Type>::reversePrint() const
{
    nodeType<Type> *current; //pointer to traverse
                             //the list

    current = last;    //set current to point to the
                       //last node

    while (current != NULL)
    {
        cout << current->info << " ";
        current = current->back;
    }//end while
}//end reversePrint
```

### 搜索链表

如果在链表中找到 searchItem，search 函数返回 true；否则返回 false。该搜索算法与有序链表的搜索算法完全相同。

```cpp
template <class Type>
bool doublyLinkedList<Type>::search(const Type& searchItem) const
{
    bool found = false;
    nodeType<Type>* current; //pointer to traverse the list

    current = first;

    while (current != NULL && !found)
        if (current->info == searchItem)
            found = true;
        else
            current = current->next;

    if (found)
        found = (current->info == searchItem); //test for
                                               //equality

    return found;
}//end search
```

### 第一个和最后一个元素

front 函数返回链表的第一个元素，back 函数返回链表的最后一个元素。如果链表为空，这两个函数都会终止程序。它们的定义如下：

```cpp
template <class Type>
Type doublyLinkedList<Type>::front() const
{
    assert(first != NULL);

    return first->info;
}
```

函数 insert 的定义如下：

```cpp
template <class Type>
void doublyLinkedList<Type>::insert(const Type& insertItem)
{
    nodeType<Type> *current;       //pointer to traverse the list
    nodeType<Type> *trailCurrent;  //pointer just before current
    nodeType<Type> *newNode;       //pointer to create a node
    bool found;

    newNode = new nodeType<Type>;  //create the node
    newNode->info = insertItem;    //store the new item in the node
    newNode->next = NULL;
    newNode->back = NULL;

    if (first == NULL)  //if the list is empty, newNode is
                        //the only node
    {
        first = newNode;
        last = newNode;
        count++;
    }
    else
    {
        found = false;
        current = first;

        while (current != NULL && !found)  //search the list
        {
            if (current->info >= insertItem)
                found = true;
            else
            {
                trailCurrent = current;
                current = current->next;
            }
        }

        if (current == first) //insert newNode before first
        {
            first->back = newNode;
            newNode->next = first;
            first = newNode;
            count++;
        }
        else
        {
            //insert newNode between trailCurrent and current
            if (current != NULL)
            {
                trailCurrent->next = newNode;
                newNode->back = trailCurrent;
                newNode->next = current;
                current->back = newNode;
            }
            else
            {
                trailCurrent->next = newNode;
                newNode->back = trailCurrent;
                last = newNode;
            }
            count++;
        } //end else
    } //end else
} //end insert
```

## 删除节点

该操作从双向链表中删除给定的项（如果找到的话）。和之前一样，我们首先搜索链表，看要删除的项是否在链表中。搜索算法与之前相同。与插入操作类似，该操作（如果要删除的项在链表中）需要调整某些节点中的两个指针。删除操作有以下几种情况：

- **情况 1：**链表为空。
- **情况 2：**要删除的项位于链表的第一个节点，这要求我们更改指针 `first` 的值。
- **情况 3：**要删除的项位于链表中某处。
- **情况 4：**要删除的项不在链表中。

函数 `deleteNode` 的定义如下：

```cpp
template <class Type>
void doublyLinkedList<Type>::deleteNode(const Type& deleteItem)
{
    nodeType<Type> *current; //pointer to traverse the list
    nodeType<Type> *trailCurrent; //pointer just before current

    bool found;

    if (first == NULL)
        cout << "Cannot delete from an empty list." << endl;
    else if (first->info == deleteItem) //node to be deleted is
                                        //the first node
    {
        current = first;
        first = first->next;

        if (first != NULL)
            first->back = NULL;
        else
            last = NULL;

        count--;
        delete current;
    }
    else
    {
        found = false;
        current = first;

        while (current != NULL && !found) //search the list
            if (current->info == deleteItem)
                found = true;
            else
                current = current->next;

        if (current == NULL)
            cout << "The item to be deleted is not in "
                 << "the list." << endl;
        else if (current->info == deleteItem) //check for
                                             //equality
        {
            trailCurrent = current->back;
            trailCurrent->next = current->next;

            if (current->next != NULL)
                current->next->back = trailCurrent;

            if (current == last)
                last = trailCurrent;

            count--;
            delete current;
        }
        else
            cout << "The item to be deleted is not in list."
                 << endl;
    }//end else
}//end deleteNode
```

## 循环链表

最后一个节点指向第一个节点的链表称为**循环链表**。图 16-45 展示了各种循环链表。

![](img/dc1b115c1ae2ec0d8a557b7c2b830e8c_1134_0.png)

**图 16-45**  循环链表

在具有多个节点的循环链表中，如图 16-45(c) 所示，使指针 first 指向链表的最后一个节点是很方便的。然后，通过使用 first，就可以访问链表的第一个和最后一个节点。例如，first 指向最后一个节点，first->link 指向第一个节点。

与之前一样，循环链表通常有以下操作：

- 初始化链表（为空状态）。
- 判断链表是否为空。
- 销毁链表。
- 打印链表。
- 获取链表的长度。
- 在链表中搜索给定项。
- 在链表中插入一项。
- 从链表中删除一项。
- 复制链表。
