To destroy a binary tree, for each node, we first destroy its left subtree, then its right subtree, and then the node itself. We must use the operator delete to deallocate the memory occupied by the node. The definition of the function destroy is:

```cpp
template <class elemType>

{
    if (p != NULL)
    {
        destroy(p->lLink);
        destroy(p->rLink);
        delete p;
        p = NULL;
    }
}
```
