In Figure 19-1, the root node of this binary tree is *A*. The left subtree of the root node, which we denote by *L*<sub>A</sub>, is the set {B, D, E, G}, and the right subtree of the root node, which we denote by *R*<sub>A</sub>, is the set {C, F, H}.
