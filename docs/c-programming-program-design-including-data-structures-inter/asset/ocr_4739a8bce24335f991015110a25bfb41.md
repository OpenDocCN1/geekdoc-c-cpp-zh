# DELETE A NODE

This operation deletes a given item (if found) from the doubly linked list. As before, we first search the list to see whether the item to be deleted is in the list. The search algorithm is the same as before. Similar to the insertion operation, this operation (if the item to be deleted is in the list) requires the adjustment of two pointers in certain nodes. The delete operation has several cases:

+   - **Case 1:** The list is empty.
+   - **Case 2:** The item to be deleted is in the first node of the list, which would require us to change the value of the pointer `first`.
+   - **Case 3:** The item to be deleted is somewhere in the list.
+   - **Case 4:** The item to be deleted is not in the list.
