Now consider the statement:

```
current = current->link;
```

This statement copies the value of current->link, which is 2800, into current. Therefore, after this statement executes, current points to the second node in the list. (When working with linked lists, we typically use these types of statements to advance a pointer to the next node in the list.) See Figure 16-6.

From now on, when working with linked lists, we will use only the arrow notation.
