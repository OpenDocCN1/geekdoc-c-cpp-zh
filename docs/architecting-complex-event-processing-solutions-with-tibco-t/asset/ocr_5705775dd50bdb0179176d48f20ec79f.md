It is important to note that whenever a checkpoint occurs, all locks that the process has obtained are released. Should a process agent fail or be shut down before a checkpointed process finishes executing, the process will be recovered by the next process agent that starts.

# Deployment

Due to potential conflicts in cached object identities, process agents cannot be deployed in the same cluster as inference agents (Figure 8-6). Thus a solution requiring both inference and processing agents would require a separate cluster for each, with each cluster having its own cache agents.
