# Dashboard Agents

# Objectives

The dashboard agent provides capabilities for the real-time visualization of information in both graphical and tabular form. After reading this chapter you will be able to describe the capabilities and appropriate uses of the dashboard agent.

# Dashboard Configuration

The dashboard agent is used to provide real-time displays of information in a browser (Figure 9-1). The agent displays metric information that is created by an inference agent. The metric information is derived from information present in incoming events. A typical configuration involves several processing units, with inference, cache, and dashboard agents each deployed in dedicated processing units.

Processing units used for TIBCO BusinessEvents® Views use a special executable: be-views.exe. This is a standard executable extended to include the interfaces necessary to interact with the browser for dashboard display.
