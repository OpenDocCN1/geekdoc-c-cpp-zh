# Dashboard

Accumulated metric data can be displayed in either tabular or graphical form in a web browser. Each chart or graph defines a query that selects the metrics to be displayed. Formatting information is provided at design time. Visual alerts can be configured as well, specifying the threshold at which the alert is triggered and the visual characteristics to be used in visualizing the alert.
