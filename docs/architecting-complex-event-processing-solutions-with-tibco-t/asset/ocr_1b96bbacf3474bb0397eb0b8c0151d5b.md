# Summary

Creating a fault-tolerant solution with TIBCO BusinessEvents requires the use of appropriate backing store configurations, the use of the TIBCO Enterprise Message Service with message persistence, and the use of appropriate coordination patterns for agent work. Persistent messaging must be used for all inter-agent interactions.

Site disaster recovery requires that the storage subsystem replicate the files underlying both the backing store and the message service to the remote site.
