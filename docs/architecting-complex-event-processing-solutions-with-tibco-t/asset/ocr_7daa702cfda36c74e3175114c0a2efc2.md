**Figure 17-3:** *Claim Tracker Agent Modularization*

Figure 17-3 shows the Claim Tracker agent modularization. There are three blocks of functionality: Monitor Claim Processing, SLA Timeout Processing, and Obtain Claim Status. TIBCO BusinessEvents requires that the timeout processing for a state machine be executed in the same inference agents as the normal transition processing, thus the Monitor Claim Processing and SLA Timeout Processing are co-located in the Monitor Claim Processing IA.

As was determined in Chapter 16, initial estimates are that the solution will require twelve agents to support Monitor Claim Processing and two to support SLA Timeout Processing, so a total of fourteen Monitor Claim Processing IA agents will be required. Seventeen Claim Tracker Cache Agents will be required, each with its own backing store file. A single Obtain Claim Status IA agent is needed.
