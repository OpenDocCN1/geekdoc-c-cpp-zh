# ACEPSTContinuousQuery Example

The ACEPSTContinuousQuery example (Figure 7-9) involves three agents. The TestDriverInference agent takes the test data and generates a Transaction event, which is sent to the ProductionInference agent. The ProductionInference agent screens these transactions and generates instances of TinyTransaction and GiantTransaction, which are sent to the queryAgent.

Figure 7-10 shows the execution details for this example. The ProductionInference agent examines the incoming Transaction and generates a TinyTransaction if the amount is less than $5, and it generates a GiantTransaction if the amount is greater than $10,000. It then consumes the Transaction. The generated transactions are sent to the queryAgent.
