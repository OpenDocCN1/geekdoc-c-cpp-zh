# Channels

Channels are the mechanism by which inference agents interact with external components and other TIBCO BusinessEvents agents. Numerous types of channels are available, including

+   - Java Message Service (JMS)
+   - TIBCO Rendezvous®
+   - HTTP
+   - TCP
+   - TIBCO ActiveSpaces®
+   - TIBCO Hawk®
+   - Local

The JMS and TIBCO Rendezvous channels provide the ability to send and receive messages. The HTTP and TCP channels enable the agent to play the role of both a server and a client with these protocols. The TIBCO ActiveSpaces channel lets the agent be a leach for an external space (not to be confused with the TIBCO BusinessEvents cache that happens to be implemented using the same technology). The TIBCO Hawk channel lets the agent interact with Hawk agents and Hawk-enabled components, providing access to component status and performance information.
