# Concepts

A concept is an editable data structure that can be used for many purposes (Figure 5-5). The name of the concept should indicate what the concept is intended to represent. Each concept instance has an optional external identifier (`extID`) property that can be set at the time the concept is instantiated.¹ It is good practice to assign a value to the `extID` that is unique across all concept instances. It serves as a unique identifier that can be used for retrieving the concept when needed (discussed later in this chapter) and also serves as a key for locking the concept when locking is required (discussed in Chapter 6).
