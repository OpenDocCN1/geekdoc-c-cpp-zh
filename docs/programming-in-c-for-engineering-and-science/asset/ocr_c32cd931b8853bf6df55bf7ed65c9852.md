# Users:

This is a file of computer system records organized as follows. They are arranged so that identification numbers are in increasing order.

+   Identification number: an integer
+   User's name: two strings of the form last-name, first-name
+   Password: a string
+   Resource limit (in dollars): an integer
+   Resources used to date: a real value

# Points:

This is a text file in which each line contains a pair of real numbers representing the x coordinate and the y coordinate of a point.
