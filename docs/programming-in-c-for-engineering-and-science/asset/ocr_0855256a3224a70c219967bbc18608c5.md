+   1. Write a spell checker, that is, a program that reads the words in a piece of text and looks up each of them in a dictionary to check its spelling. Use a BST to store this dictionary, reading the list of words from a file. While checking the spelling of words in a piece of text, the program should print a list of all words not found in the dictionary.

+   2. Write a program to construct a text concordance, which is an alphabetical listing of all the distinct words in a piece of text. It should read a piece of text; construct a concordance that contains the distinct words that appear in the text and for each word, the line (or page) number of its first occurrence; and then allow the user to search this concordance. Use an array or vector of 26 BSTs, one for each letter of the alphabet, to store the concordance.
+   
+   3. Extend the program in Problem 2, so that a (linked) list of all occurrences of each word is stored. When the concordance is searched for a particular word, the program should display the line (or page) numbers of all occurrences of this word. The data structure used for the concordance is thus an array or vector of binary search trees, each of whose nodes stores an object containing a string and an ordered linked list of integers.
