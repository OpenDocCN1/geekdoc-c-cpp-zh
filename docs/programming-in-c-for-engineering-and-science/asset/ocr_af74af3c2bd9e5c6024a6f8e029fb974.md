# 13.1.2.3 Algorithm

These operations are easily organized into the following algorithm:

+   1. Declare *mileageChart*, a two-dimensional array of city mileages.

+   2. Via `cout`, display a menu of the cities.
+   
+   3. From `cin`, read two integers into *city1* and *city2*.
+   
+   4. Compute *mileage*, by looking up *mileageChart[city1][city2]*.

+   5. Via `cout`, display *mileage*.
