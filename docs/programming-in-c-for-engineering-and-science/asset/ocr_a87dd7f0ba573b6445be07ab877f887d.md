This recursive definition can be used as an algorithm for calculating factorials. To see how it works, consider using it to calculate 5!. We must first calculate 4! because 5! is defined as the product of 5 and 4!. But to calculate 4! we must calculate 3! because 4! is defined as 4 × 3!. And to calculate 3!, we must apply the inductive step of the definition again, 3! = 3 × 2!, then again to find 2!, which is defined as 2! = 2 × 1!, and once again to find 1! = 1 × 0!. Now we have finally reached the anchor case and because the value of 0! is given, we can backtrack to find the value of 1!,
