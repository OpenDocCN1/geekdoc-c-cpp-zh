Note that the number of columns (n) in A is equal to the number of rows in B, which must be the case for the product of A with B to be defined.

For example, suppose that A is the 2 × 3 matrix

A = [ 1  3  2 ; -1  4  5 ]

and B is the 3 × 4 matrix

B = [ 4  2  5  0 ; 0  -4  1  3 ; 6  0  0  2 ]

Because the number of columns (3) in A equals the number of rows in B, the product matrix AB is defined. The entry in the first row and first column is obtained by multiplying the first row of A with the first column of B, element by element, and adding these products:

[ 1  3  2 ; -1  4  5 ] [ 4  2  5  0 ; 0  -4  1  3 ; 6  0  0  2 ]

1 × 4 + 3 × 0 + 2 × 6 = 16
