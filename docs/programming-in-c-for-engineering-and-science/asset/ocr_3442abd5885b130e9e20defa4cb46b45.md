Several formulas have been developed experimentally to determine the velocity at which fluids flow through such pipes. One of these, the Manning formula, is

```
V = 1.486 / N R^(2/3) S^(1/2)
```

where

+   - V = velocity in feet per second
+   - N = roughness coefficient
+   - R = hydraulic radius = cross-sectional area / wetted perimeter
+   - S = slope of the energy gradient (= (d + 20) / 1000 for this problem)

The rate of fluid flow is equal to the cross-sectional area of the pipe multiplied by the velocity.

Write a program that inputs the reservoir’s height, roughness coefficient, hydraulic radius, and pipe radius, and computes the time required to empty the reservoir. Do this by assuming a constant flow rate for 5-minute segments.
