# 9.5.4 Input Loops: The Query Approach

Each of the preceding kinds of input loops has its disadvantages. The counting loop approach requires knowing in advance the number of values to be entered. The sentinel approach can only be used in problems where there is a suitable value to use as the sentinel. The eof mark is platform dependent. The final approach we consider is to query the user at the end of each repetition to determine whether there is more data to process. Although not without its disadvantages, this approach is the most broadly applicable.
