- **7.** 考虑一个简支梁，上面施加一个集中载荷：

  ![](img/ee01f74bfb7397ce74bbc4286ed2dd55_421_0.png)

  对于 a ≥ b，最大挠度由下式给出

  max_deflection = -P a (L² - a²)^{3/2} / (9√3 E I L)

  载荷处的挠度由下式给出

  deflection_at_load = -P a² b² / (3 E I L)
