Such an analysis may help a company decide whether to upgrade its equipment. Weighing the cost of a new robot (that presumably makes fewer mistakes) against the cost of repairing or discarding 18.3 percent of the circuit boards helps in making an informed decision.

# 12.1.2 Object-Centered Design

# 12.1.2.1 Behavior

The program should display on the screen a prompt for the name of the input file, read this name from the keyboard, and then open an ifstream to that file. It should then read via the ifstream the number of component failures for each circuit board tested, counting the occurrences of each 0, 1, 2, 3, 4, and 5, and then display the number and percentages of times each occurred.
