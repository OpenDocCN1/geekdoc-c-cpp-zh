When the end of this file is reached, it opens an ofstream named outStream to which it outputs the results.¹ These classes are declared in the fstream library, so we must have the #include <fstream> directive in any program where we wish to use them.

To begin, we must first construct an ifstream object to use as a connection from the input file to the program with a declaration of the form

```
ifstream input_stream_name;
```

Similarly, before a program can write values to a file, it must construct an ofstream object to act as a connection from the program to that file with a declaration of the form

```
ofstream output_stream_name;
```

For example, the program in Example 11.1 uses the declaration

```
ifstream inStream;
```

to construct an input stream named inStream and later,

```
ofstream outStream;
```

to construct an output stream named outStream.
