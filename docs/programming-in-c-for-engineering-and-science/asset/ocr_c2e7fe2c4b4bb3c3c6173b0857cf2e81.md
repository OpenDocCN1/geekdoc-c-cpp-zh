```
/* printAsMoney displays an amount in monetary format.

    Receive: dollars, the double value to be displayed
    Output: dollars in monetary format
    ----------------------------------------------- */

void printAsMoney(double dollars)
{
    cout << fixed << showpoint
         << setprecision(2)
         << '$' << dollars;
}
```

Note how hiding the money-format details in a void function printAsMoney() makes the main function easier to read. As noted in the introduction to this chapter, such a view of something that is simplified by hiding some of its details is referred to as abstraction or information hiding. Our printAsMoney() function “hides” the details of how the display-a-monetary-value operation is accomplished (at least as far as readers of the main function are concerned).
