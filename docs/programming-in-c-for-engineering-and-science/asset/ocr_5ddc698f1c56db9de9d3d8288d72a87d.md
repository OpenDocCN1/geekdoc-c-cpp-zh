Similarly, the forever loop

```
for
{
cout << "\nPlease enter an integer value (0 to quit): ";
cin >> value;
if (value = 0) break;
// ... do something with value ...
}
```
is an infinite loop, because its termination condition is an assignment, not a comparison. Because the result of that assignment is zero, which represents the value false in C++, this termination condition will always be false, and so the break statement will never be executed.
