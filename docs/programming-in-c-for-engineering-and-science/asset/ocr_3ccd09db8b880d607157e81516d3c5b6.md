Replacing the blank with the type of the variables to be swapped will produce a C++ function that can be incorporated into a program where this interchange of values is needed. The simple program in Example 10.4 illustrates this for int variables. (In Section 10.5 we will see how we can have the compiler perform this “blank-filling” automatically.)

# Example 10.4 Interchanging the Values of Two int Variables

```
/* Test driver for the swap() function

    Input: two integer values stored in intVar1 and intVar2
    Output: the values of intVar1 and intVar2 after swapping
    --------------------------------------------------------------*/

#include <iostream>
using namespace std;

void swap(int & first, int & second);

int main()
{
    int intVar1, intVar2;

    cout << "Enter two integers: ";
    cin >> intVar1 >> intVar2;

    swap(intVar1, intVar2);

    cout << "After using swap(), values are "
         << intVar1 << " and " << intVar2 << endl;
}
```
