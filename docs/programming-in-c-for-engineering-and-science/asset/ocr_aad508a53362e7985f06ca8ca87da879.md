2 × sum = 101 + 101 + ...101 + 101
= 100 × 101

Thus, the sum is equal to

sum = 100 × 101 / 2 = 5050

Applying his algorithm to the more general summation problem, we begin with the sum

sum = 1 + 2 + 3 + ... + (n − 2) + (n − 1) + n

reverse it,

sum = n + (n − 1) + (n − 2) + ... + 3 + 2 + 1

and then add these two equations to get

2 × sum = (n + 1) + (n + 1) + ... + (n + 1) + (n + 1)
= n × (n + 1)

Dividing by 2 gives

sum = n × (n + 1) / 2

This formula, known as Gauss’s formula, implies that function sum() can be written without using a loop at all, as shown in Example 9.2.

# Example 9.2 Function sum() — No-Loop Version

```
Receive: n, an integer
Return: the sum 1 + 2 + ... + n (0 if n < 0)
---------------------------------------------------------------*/

int sum (int n)
{
    return n*(n + 1) / 2;
}
```
