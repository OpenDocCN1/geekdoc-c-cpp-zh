# 12.6.1 A Quick Review of Function Templates

In Section 10.6 we introduced function templates, which are patterns for functions from which the compiler can create actual function definitions. A template typically has a type parameter that is used as a place holder for a type that will be supplied when the function is called. For example, we considered the following function template:

```
template <typename Item>
void swap(Item & first, Item & second)
{
    Item temporary = first;
    first = second;
    second = temporary;
}
```

When swap() is called with

```
swap(int1, int2);
```

the compiler creates an instance of swap() in which the type parameter Item is replaced by int—the type of the variables int1 and int2. But when swap() is called with char values ch1 and ch2,

```
swap(ch1, ch2);
```

the compiler creates an instance of swap() in which Item is replaced by char. Function templates thus allow a programmer to create generic functions—functions that are type independent.
