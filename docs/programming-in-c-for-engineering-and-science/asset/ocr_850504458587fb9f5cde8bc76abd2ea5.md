# 4.3.3 The Increment and Decrement Operations

Algorithms often contain instructions of the form “Increment count by 1.” that can be encoded as

```
count = count + 1;
```

or, with the preceding shortcut assignment forms, as

```
count += 1;
```

However, this kind of assignment that increments an integer variable by 1 occurs so often that a special unary increment operator ++ is provided for this operation. It can be used as a postfix operator,

```
variable++
```

or as a prefix operator,

```
++variable
```

where variable is an integer variable whose value is to be incremented by 1. Thus, the assignment statement

```
count = count + 1; // or count += 1;
```

can also be written

```
count++;
```

or

```
++count;
```
