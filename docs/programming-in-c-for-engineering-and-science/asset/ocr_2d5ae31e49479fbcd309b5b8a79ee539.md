A table can thus be viewed as a one-dimensional array whose components are also one-dimensional arrays.

C++ allows array declarations to be given in a form that reflects this perspective. To illustrate this, consider again our table of temperature readings. Suppose we first declare a type identifier TemperatureList to represent one set of readings at the three cooling plant outlets at a particular time:

```
const int NUM_OUTLETS = 3;
typedef double TemperatureList[NUM_OUTLETS];
```

We can then use this new type to declare a second type TemperatureTable as an array whose elements are TemperatureList objects:

```
const int NUM_TIMES = 4;
typedef TemperatureList TemperatureTable[NUM_TIMES];
```
