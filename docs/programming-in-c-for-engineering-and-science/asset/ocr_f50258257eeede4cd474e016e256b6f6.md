It is important to note how this function uses the explicit-value Temperature constructor to build the Temperature value to be returned. For example, in the first case of the switch statement, it uses the values of myDegrees and 'F' passed to it to build a Temperature object, which toFahrenheit() then uses as its return value for this case.

As always, we must place a prototype of the conversion methods in the class declaration:

```
class Temperature
{
public:
    Temperature();
    Temperature(double initDegrees, char initScale);

    double getDegrees() const;
    char getScale() const;

    Temperature toFahrenheit() const;
    Temperature toCelsius() const;
    Temperature toKelvin() const;

    void read(istream & in);
    void display(ostream & out) const;

private:
    double myDegrees;
    char   myScale;
};
```

Definitions of toCelsius() and toKelvin() are similar to that of toFahrenheit() and are left as exercises.
