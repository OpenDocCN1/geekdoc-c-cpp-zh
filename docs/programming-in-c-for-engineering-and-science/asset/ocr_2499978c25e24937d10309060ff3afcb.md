5/15 of $150,000 ($50,000) is depreciated; in the second year, 4/15 of $150,000 ($40,000) is depreciated; and so on, giving the following depreciation table:

| Year | Depreciation |
|------|--------------|
| 1    | $50,000      |
| 2    | $40,000      |
| 3    | $30,000      |
| 4    | $20,000      |
| 5    | $10,000      |
