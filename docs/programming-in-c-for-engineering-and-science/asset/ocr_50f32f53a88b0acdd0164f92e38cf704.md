Some expressions that are more complicated may require more than one function call. For example, if we are solving quadratic equations, we might want to calculate the discriminant √b²−4ac. We can express this in C++ as

```
sqrt(pow(b, 2) - 4.0 * a * c)
```

Note that if the value of the expression

```
pow(b, 2) - 4.0 * a * c
```

is negative, an error will result because the square root of a negative number is not a real number.
