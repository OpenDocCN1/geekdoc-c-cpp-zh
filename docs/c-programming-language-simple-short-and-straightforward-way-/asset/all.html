Brief history of C++

 

The C++ programming language has a history path in 1979. Bjarne Stroustrup, a Danish computer scientist, is working with the language called "Simula", which is a language principally intended for simulations. The Simula 67 language underpins object-oriented programming paradigm. Stroustup started working with "C" with classes. C is considered as middle-level language which has the power of Low-level language but has high-level language features and C is considered as the predecessor of C++. Bjarne Stroustrup, at Bell Labs designed C++ in the early 80s, as an object oriented language based on the C language, which powered pretty much all systems software since its creation in 1972. The first C with Classes compiler was called Cfront, which was derived from a C compiler called CPre. C++'s goal is to add object-oriented programming into C language. The ++ operator in the C language is an operator for incrementing a variable, which gives some insight into how Stroustrup regarded the language. In 1985, Stroustrup's reference to the language entitled "The C++ Programming Language" was published.

 

Reasons to use C++

 

To start with, C++ is highly recommended for beginning programmers in starting their programming career because C++ covers both procedural and object-oriented programming approach. Once someone learned the concepts behind programming language with C++, adopting or migrating to other programming language will be a lot easier whether it's object-oriented or procedural-oriented programming, as most of the things needed are pretty similar.

C++ has been around a while and it has solved several industry challenges considering that it is also the primary language that drives the mobile experience today. In addition to high performance server and middleware, C++ is a great choice for client side development on the two most popular mobile platforms Android and iOS and the two most popular desktop platforms, Windows and Mac OS X. With the recent introduction of developer tools that enable, among other things, visual design for clients, middleware, and server side apps; C++ is extremely productive and really makes it a great choice for modern app development, so learning the basics of C++ will make someone be competitive in the industry's stiff competition.

Definition of programming terms

 

The following terms are defined conceptually and operationally in order to have a common understanding of the terms used in this book.

Argument. Arguments are actual value being pass to a function.

Bug. A bug is a general term used to describe any unexpected problem with the program during execution or when the programming is already running.

Block. A block is composed of two or more C statements. Also called compound statements. A block is enclosed with a pair of { } braces.

CamelCase. CamelCase is the naming convention for compound word which uses capital letters to delimit the word parts. For example, "studName", "studAge", and "intNum".

Clause. A section in the statement.

Code. It is the term used for statements written that make up a C program.

Condition. A statement that evaluates to either true (non zero) or false (zero).

Data Type. It the type of data being stored to a storage location like variable.

Debug. This refers to the process of examining and removing errors from a program's source code.

Expression. It is a statement that result to a numeric value.

Function. Function perform a specific task.

Label. Label is used a give details to a certain line of code in C language, hence this labels are ignored by the compiler, thus it does not affect the output of the program. Usually used for internal documentation.

Null. In computer programming, null is the term used for an uninitialized, undefined, empty, or meaningless value.

Parameter. Parameters are argument declaration of a function.

Statement. A statement is a complete direction instructing the computer to carry out some task. In C, statements are usually written one per line, although some statements span multiple lines. This term can be interchangeably use with code.

Syntax. Syntax is the grammar, structure, or order of the elements in a C language or any other programming language statement. (Semantics is the meaning of these elements.)

Variable. Variables are storage location for data in C programs.

Line 2. using namespace std;

C++ uses namespaces to organize different names used in programs. Every name used in the iostream standard library file is part of a namespace called std (probably stands for "standard"). Consequently, the cout object is really called std::cout. The using namespace std; statement avoids the need for putting std:: before every reference to cout, so that the cout alone can be used in the code.

 

Line 3. int main()

This line defines the main body of the program. The only component that is required in every C++ program is the main() function. In its simplest form, the main() function consists of the name main followed by a pair of empty parentheses ( ) and a pair of braces { } presented in lines 4 and 9. Within the braces are statements that make up the main body of the program. Under normal circumstances, program execution starts at the first statement in the main() function and terminates at the last statement in main().

Usually functions are invoked or called by other functions, but main() is special. When the program starts, main() is called automatically.

main() function, like all functions, must state what kind of value it will return. The return value type for main() in the sample program is int which signifies integer number, but it's not necessary for a program that just prints the word "Hello World", hence, the value 0 in line 8 is returned just to satisfy the format. Returning values from functions is discussed in detail in the succeeding chapters of this book

 

Lines 4 and 9. { }

The curly braces { } are used to enclose the program lines that make up every C++ function including the main() function. A group of one or more statements enclosed within braces is called a block. Line 4 signifies the start of the content of the main function and line 9 signifies its end.

The program will execute and run properly with or without comments. In line 5, the comments are used to give a reference or details that the next line will print a string on-screen.

The cout is pronounced “C-out". cout statement is a library object stream under "iostream" library that displays information on-screen. Note: You don't have to return 0 explicitly, because that will happen automatically when the main() function terminates. It is also a common practice for C++ programmers to include the return 0 in the main() function, hence for the rest of the sample programs in this book includes the return 0 in its main() function.

A constant is also a data storage location used by a program. Unlike a regular variable, the value stored in a constant variable can't be changed during program execution. char word[6]={'h','e','l','l','o','\0'}

2.3 Mathematical operators precedence level and parentheses

If an expression contains more than one operator, there is an order in which operations are performed. The precedence level of operators will determine on which operation must be performed first. The order of precedence is illustrated in the statement below.

Chapter 7 - Conditional Statements in C++

This chapter presents decision making structures in C++ language. Decision making structures require that the programmer specifies one or more conditions to be evaluated or tested by the program, along with a statement or statements to be executed if the condition is evaluated to be true, and optionally, other statements to be executed if the condition is evaluated to be false. This chapter uses the different relational and logical operators and presents the fundamentals of conditional statements in C++ programming.

 

The if() statement

 

The if() statement is the commonly used conditional statement in C++ language. if() statement is the simplest form of the branching C statements. It takes an expression in parentheses and a statement or block of statements. The if() statement has different cases as follows:

 

1. Single-alternative

Single-alternative execute the statement(s) under its "true path" only when the condition is true and has no other statement(s) to execute if the condition is false.

 

Syntax of single-alternative if() statement:

if(<condition>)

{

<True Path Statement(s)>

}

 

The <condition> in the syntax should be an expression that evaluates to either true or false and the <True Path Statement(s)> can be a single statement or block of statements. If the <condition> is evaluated to be true, execute the <True Path Statement(s)>, otherwise, exit the if() statement. Below is an example of single-alternative if() statement.

 

if(5>2)

{

cout<<"The condition is True.";

}

 

In the above example, the expression 5>2 evaluates to true, hence the cout statement is executed. Below is another example that takes a compound expression using the logical operator AND.

 

if((5>2)&&(5<4))

{

printf("The condition is True.");

}

 

The first expression 5>2 in the example above evaluates to true and the second expression 5<4 evaluates to false. The compound result of the two expressions using the && operator is FALSE, hence the cout statement is not executed.

The multiple-alternative if() statement can have two or more true paths without a false path, or two or more true paths and one false path. In order for if() statement to have two or more true paths, the "else if" clause is use.

 

Syntax of multiple-alternative if() statement without a false path:

if(<condition-1>)

{

<1.True Path Statement(s)>

}

else if(<condition-2>)

{

<2. True Path Statement(s)>

}

[else if(<condition-N>)]

{

<N. True Path Statement(s)>

}

 

In the syntax, the multiple-alternative if() statement can have two or more <conditions> separated by the "else if" clause. The execution begins with the evaluation of the first <condition-1>. If the first <condition-1> evaluates to true, it's true path is executed and exits loop, hence the other <condition-2/N) are no longer evaluated. However, if the first <condition-1> evaluates to false, then evaluate the succeeding <conditions-2/N>. Once a condition evaluates to true, it's true path is executed, then exits loop. If no condition evaluates to true, and since there is no false path, the execution goes to the statement that follows the if() statement.

if ((intNum>=0)&&(intNum<=5))

}

{

cout<<"B";

}

else if(!intNum<10)

{

cout<<"C";

}

 

In the example, if the value of intNum is 0 to 5, cout<<"A"; is executed, then exits loop. If the value of intNum is 6 to 10, cout<<"B"; is executed. And in the third expression !intNum<10, if intNum is less than 10, it evaluates to false because of the ! (NOT) operator that neglects or reverses the truth and exits if() statement. Hence, if the value is greater or equal to 10, it evaluates to true and cout<<"C"; is executed.

<False Path Statement(s)>

}

The switch() statement

A switch statement allows a variable to be tested for equality against a list of values. Each value is called a case, and the variable being switched on is checked for each switch case.

 

Syntax of switch() statement:

switch(<expression>)

{

case <cons-expression-1> :

<statement(s)>;

break; /* optional */

case <cons-expression-N> :

<statement(s)>;

break; /* optional */

/* Can have any number of case statements */

default : /* Optional */

statement(s);

}

 

In the syntax, the <expression> in the "switch" keyword should be an integral type like integer values, signed or unsigned. Boolean values, where 0 is equivalent to false and any nonzero number is equivalent to true. Can also be a character, which are automatically converted to an integer value by the compiler.

The <cons-expression-1/N> in the "case" clause must be the same data type as the <expression> in the switch keyword, and it must be a constant or a literal.

The switch() statement can have any number of case statements within a switch. Each case is followed by <cons-expression-1/N>, the value to be compared to, and ends with a : colon.

When the variable being switched on is equal to a case, the statements following that case will execute until a "break" keyword is reached. When a "break" keyword is reached, it exits the switch() statement, and the execution goes to the next line following the switch() statement disregarding the succeeding case(s). Note that not every case needs to contain a "break". If no break appears, the execution will go through all the subsequent cases until a break is reached.

A switch statement can have an optional "default" clause, which must appear at the end of the switch. The "default" clause can be used for performing a task when none of the cases is true. No break is needed in the default case.

Also, note that switch() statement does not support strings as cases. In dealing with strings, it is recommended to use the if() statement.

Things to consider in conditional statement:

 

1. When to use if()statement over switch() statement:

In case of simple and few condition, if() statement executes faster and easier to write. if() statement allows complex expressions on its condition(s), while switch() wants a constant. Also if() accepts and allows all data types including string, which is not allowed in switch() statement. Thus, depending on the program’s requirement, a programmer should decide himself which conditional statement to use.

 

2. When to use switch() statement over if() statement:

If there are large number of compares for a condition in the program, use switch() over if() as long as the expressions are all integral type because switch offer more readability for the program source code. A switch statement works much faster than equivalent if() statement having more conditions to compare. It is because compiler generates a jump table for a switch during compilation. Consequently, during execution, instead of checking which case is satisfied, it only decides which case has to be executed. Also, switch() is more manageable for having higher level of indentation than if().

Chapter 8 - Looping Statements in C++

This chapter presents repetition structures in C++ language. It presents the different looping statements in C++ and the fundamentals behind their logic and algorithm.

 

What is a Loop?

 

Loops provide a way to repeat commands and control how many times they are repeated. Loops allow C++ statement to be repeated several number of times as needed. C++ provides a number of looping way and there are two types of loop in C++. The counter-controlled loop and condition-controlled loop.

 

1. Counter-controlled loop

Counter-controlled loop performs a statement in a specific number of times base from its counter. This loop keeps count on the number of times a statement is executed and runs only on specific number of times it is instructed to, and stops after. The C++ uses the for()loop statement in executing a counter-controlled loop.

A for()loop statement is a C++ programming construct that executes a block of one or more statements a certain number of times.

 

Syntax of for() statement:

for (<ctr-init>;<ctr-condition>;<ctr-modifier>)

{

<statement(s)>;

}

 

 

In the syntax, the <ctr-init> is the counter initialization. A numeric variable must be declared as the loop's counter variable, and its initial value must take place in the <ctr-init> section of the for() loop statement. The <ctr-modifier> is the counter modifier which can either be a counter increment or counter decrement. This section updates the counter on each execution of the loop until counter reaches to set the <ctr-condition> to false to exit for() loop. Finally, the <statement(s)> can be a single line statement or block of statements.

2. Condition-controlled loop

Condition-controlled loop is a way for C++ programs to repeat one or more various statements depending on condition(s) set either by the programmer initially or during run-time of the program. There are two types of condition-controlled loop in C++ which are the pre-test and post-test loop.

 

2.1 Pre-test loop

The pre-test condition controlled loop can be executed using the while() loop statement. The while() loop statement repeatedly executes a target statement(s) from 0 to N times as long as a given condition is true. The given condition is tested before the body of the loop, hence, there is a possibility that the body of the loop may not be executed if at first evaluation of the condition is false.

while(<condition>)

{

statement(s);

}

The <statement(s)> is the body of the loop which may be a single statement or a block of statements. The body of the loop iterates while the <condition> is true. When the <condition> evaluates to false, the program execution passes to the line immediately following the while() loop statement.

Notice that the <condition> appears at the end of the loop, so the <statement(s)> in the loop executes once before the condition is tested. If the condition is true, the execution goes back up to do clause, and the <statement(s)> in the loop executes again. This process repeats until the given <condition> becomes false.

Chapter 9 - User-Defined Functions in C++ Language

A function is a group of statements which together perform a task. Every C++ program has at least one function, which is the main() function. There are two types of functions in C++ which are 1) pre-defined functions which some of them has been discussed in the previous chapters of this book, and the other type is called 2) user-defined function. This chapter presents the fundamentals of defining and using a user-defined function.

 

User-defined function

 

C++ allows programmer to define functions according to their need. These functions are known as user-defined functions. To create a user-defined function, it involves function declaration known as the function prototype and function definition which defines the statements that the user-defined function will perform.

The following discussions is an example of creating a user-defined function that returns the area of a rectangle. The data needed to compute the area of a rectangle is the length and width. The name of the function would be getArea().

 

User-defined function prototype

A function prototype is simply the declaration of a function that specifies the function's name, parameters and return type. It doesn't contain function body. A function prototype gives information to the compiler that the function may later be used in the program.

 

Syntax of user-defined function prototype:

<ret-type> <func-name>(<type par1>, <type parN>,..);

 

In the syntax, the <ret-type> is the return data type of the user-defined function. The return type in the example is the area of a rectangle hence, it could be an integer data type. The <func-name> is the function name of the user-defined function, and enclose with the ( ) parentheses are the user-defined function's parameters. The parameters are the type(s) of data, which may be passed to the function, hence in the example, the needed data are the length and width of the rectangle which could be an integer data type. A user-defined function may have 0 or N number of parameters. If no parameter is needed, just leave the ( ) parentheses empty.

 

Below is the creation of the function prototype of the user-defined function getArea():

int getArea(int len, int wid);

 

The return type is integer which represents the area of the rectangle, and the parameters needed are the length and width with the names len and wid respectively of type integers.

User-defined function definition

A function definition of a user-defined function contains the block of statement that the function will perform.

<statement(s)>;

The first line in the syntax is similar to the function prototype but note that it should not end with a ; semi-colon. The compiler starts executing the codes inside the body of a function, hence if the user-defined function is not called, its body of statement(s) will not be executed.

Chapter 10 - User-Defined Data Types in C++

A data type in C++ programming language is a set of data with values having defined characteristics. There are two kinds of data types. The first one is the primitive data types or built-in types which include int, float, double, etc as discussed in chapter 3. The second one is the composite types or user-defined data types which can be constructed in a program using the primitive data types and even other composite types. This chapter presents the fundamentals of user-defined data types.

 

Structures

 

A user-defined data types or composite types can be constructed using the structure statement in C++. A structure is a collection of one or more variables grouped under a single name for easy manipulation. The variables in a structure, unlike those in an array, can be of different data types. A structure can contain any of C++'s primitive data types, including arrays and other structures. Each variable within a structure is called a member of the structure.

 

Declaring a structure

Declaring a structure is the process of creating a user-defined data type which can be later be defined. Declaring structure comes first before declaring variable of that type.

 

Syntax of struct statement:

struct <struct-name>

{

<member variable(s)>;

};

 

In the syntax, the struct keyword, which identifies the beginning of a structure declaration, must be followed immediately by the <struct-name> which is the name of the structure, or tag (which follows the same rules as other C++ variable names).

Within the braces following the <struct-name> is a list of the structure's member variables which are variable declarations that comprises the structure. And, the struct statement must end with a ; semi-colon. The structure declaration should take place before the main() function.

Below is an example of a user-defined data type using struct.

struct stud

{

unsigned int id;

char name[50];

unsigned int yob;

};

 

The name of the structure is "stud" with three member variables which are unsigned int id for the student's identification number, the char name[50] for student's name and unsigned int yob for year of birth.

 

Defining a structure

Defining a structure is similar to declaring variables of primitive type. However, in defining structure, programmer should include the struct keyword and the structure's name.

 

Syntax of defining a structure:

struct <struct-name> <struct-varname>;

 

Defining structure must adhere to the rules in declaring variables. Below is an example of declaring a variable of type stud (defining structure).

 

struct stud studRecord;

 

In the example, stud is the structure name and studRecord is the name of variable with a data type stud.

 

Accessing Structure Members

Structure members are accessed using the structure member operator (.), also called the . dot operator, between the structure name and the member name. The . dot is used to refer or access member variable(s).

 

Syntax of using the . dot access member operator:

<struct-varname>.<member-variable>

Chapter 11 - Classes in C++

Most of the discussions in chapter 10 on structures applies also to classes. Indeed, for the most part we can simply substitute the class keyword for the struct keyword when declaring the class. However, there is an important difference between structures and classes. While both has member variables, classes can also have methods which are not available in structures. Classes are the central feature of C++ and this chapter presents the fundamental of C++ classes.

 

What is a class?

 

A class is used to specify the form of an object and it combines data representation known as member variables and methods which is similar to function for manipulating that data into one neat package. The data and method within a class are called members of the class. Classes extend the built-in capabilities of C++ to assist programmer in representing and solving complex, real-world problems.

 

Creating New Types

 

Creating new type is similar to creating a structure as discussed in the previous chapter and follows similar principles. In C++, the programmer can create any type needed, and each of these new types can have all the functionality and power of the built-in data types.

Programs are usually written to solve real-world problems, such as simulating the workings of a heating system. Although it is possible to solve complex problems by using programs written with only integers and characters, it is far easier to grapple with large, complex problems if programmers can create representations of the objects like simulating the workings of a heating system which makes it easier if programmers can create variables that represent rooms, heat sensors, thermostats, and boilers. The closer these variables correspond to reality, the easier it is to write the program.

 

Classes and Members

 

Programmer can make a new type by declaring a class. A class is just a collection of variables (often of different types) combined with a set of related functions like for example a car having data with regards to its wheels, doors, seats, windows, etc. A class enables the programmer to encapsulate, or bundle, these various parts and various functions into one collection, which is called an object. This process is known as encapsulation.

Similar to structures, a class can consist of any combination of primitive data types and also other class types. The variables in the class are referred to as the member variables or data members. The functions in the class typically manipulate the member variables referred to as member functions or methods of the class. For example, a Dog class might have data members that represent age and color and its methods might include bark(), walk(), and sit().

To declare a class, use the class keyword followed by an opening brace, and then list the member variables and methods of that class and end the declaration with a closing brace and a semicolon.

 

Syntax of declaring a class:

{

// Access control keywords here

In the syntax, the <class-name> is the name that should be given to the class to be created and enclosed in the curly { } braces, the programmer can declare member variables which can be defined as either private or public as its access control and also, declaration of the member methods/methods of the class .

Chapter 12 - Exception Handling in C++

An exception is a situation in which a program has an unexpected circumstance that the section of code containing the problem is not explicitly designed to handle. In C++, exception handling is useful because it makes it easy to separate the error handling code from the code written to handle the chores of the program. This chapter presents the fundamentals of dealing with problems that arises in C++ programs.

 

What is exceptions?

 

Exceptions provide a way to react to exceptional circumstances (like runtime errors) in programs by transferring control to special functions called handlers.

To catch exceptions, a portion of code is placed under exception inspection. This is done by enclosing that portion of code in a try-block. When an exceptional circumstance arises within that block, an exception is thrown that transfers the control to the exception handler. If no exception is thrown, the code continues normally and all handlers are ignored. C++ exception handling is built upon three keywords: try, catch, and throw.

 

try: A try block identifies a block of code for which particular exceptions will be activated. It's followed by one or more catch blocks called exception handler.

catch: A program catches an exception with an exception handler at the place in a program where the programmer want to handle the problem. The catch keyword indicates the catching of an exception.

throw: A program throws an exception when a problem shows up. This is done using a throw keyword.

 

How exceptions are used

 

try blocks are created to surround areas of code that may have a problem. For example:

try

{

<SomeDangerousCodes>

}

 

catch blocks handle the exceptions thrown in the try block. For example:

try

{

<SomeDangerousCodes>

}

catch(OutOfMemory)

{

// take some actions

}

catch(FileNotFound)

{

// take other action

}

 

The basic steps in using exceptions are:

1.Identify those areas of the program in which an operation that might raise an exception, and put them in try blocks.

2.Create catch blocks to catch the exceptions if they are thrown, to clean up allocated memory, and to inform the user as appropriate.

Chapter 14 - File Management in C++

This chapter presents the fundamentals of file management in C++. It presents reading and writing of text into a text file.

 

C++ Files and Streams

 

C++ supports a number of functions that have the ability to perform basic file operations, which include naming a file, opening a file, reading from a file, writing data into a file, and closing a file. This requires another standard C++ library called fstream, which defines three new data types:

1.ofstream. This data type represents the output file stream and is used to create files and to write information to files.

2. ifstream. This data type represents the input file stream and is used to read information from files.

3. fstream. This data type represents the file stream generally, and has the capabilities of both ofstream and ifstream which means it can create files, write information to files, and read information from files.

 

To perform file processing in C++, header files <iostream> and <fstream> must be included in your C++ source file. The general format to include the iostream and fstream libraries is presented below.

#include<iostream>

#include<fstream>

 

Opening a File

 

A file must be opened before it can be read from or write to. Either the ofstream or fstream object may be used to open a file for writing and ifstream object is used to open a file for reading purpose only.

Following is the standard format for open() function, which is a member of fstream, ifstream, and ofstream objects.

 

<stream-datatype> <stream-name>;

<stream-name>.open(<filename>,ios::<mode>);

 

The <stream-datatype> can be any of the three data types under fstream library. In the second line, the first argument <filename> in the open() function specifies the name and location of the file to be opened and the second argument of the open() member function defines the mode in which the file should be opened. The <mode> can be any of the following.

1. os::app

Append mode. All output to that file to be appended to the end.

2. ios::ate

Open a file for output and move the read/write control to the end of the file.

3. ios::in

Open a file for reading.

4. ios::out

Open a file for writing.

5. ios::trunc

If the file already exists, its contents will be truncated before opening the file.

 

Example:

ofstream outfile;

outfile.open("data.txt", ios::out);

 

Programmers can combine two or more of these values by ORing them together. For example if it is needed to open a file in write mode and want to truncate it in case it already exists, following will be the format:

 

ofstream outfile;

outfile.open("data.txt ", ios::out | ios::trunc );

 

Similar way, programmers can open a file for reading and writing purpose as follows:

fstream afile;

afile.open("data.txt", ios::out | ios::in );

 

Closing a File

 

When a C++ program terminates it automatically closes flushes all the streams, release all the allocated memory and close all the opened files. But it is always a good practice that a programmer should close all the opened files before program termination.

Following is the standard format for close() function, which is a member of fstream, ifstream, and ofstream objects.

<stream-name>.close();

 

Writing to a File

 

While doing C++ programming, programmer write information to a file from the program using the stream insertion operator (<<) just as it is use to output information on- screen. The only difference is that the ofstream or fstream object should be used instead of the cout object.

 

Reading from a File

 

Programmer read information from a file into the program using the stream extraction operator (>>) just as it is use to input information from the keyboard. The only difference is that the ifstream or fstream object should be used instead of the cin object.
