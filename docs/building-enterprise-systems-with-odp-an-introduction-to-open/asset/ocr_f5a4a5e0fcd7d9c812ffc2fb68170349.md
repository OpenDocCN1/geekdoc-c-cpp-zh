# 5.3 Node Architecture

The node architecture identifies a number of functions that are commonly found in the platforms supporting application objects. Providing a technology-neutral architecture for describing them helps to identify the commonalities between different infrastructure solutions, such as JEE or .NET, and so makes the integration of different platforms simpler.
