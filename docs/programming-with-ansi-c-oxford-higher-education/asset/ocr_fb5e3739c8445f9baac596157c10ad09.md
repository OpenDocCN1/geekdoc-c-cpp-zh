2. From then onwards, it allocates four more bytes for the next object every time it runs out of memory (32 bytes).

The first call allocates memory for the entire Tablespace, which is of 32 bytes, that is, eight chunks of four bytes each.

It is not possible to allocate memory after this and thus the allocation fails.
