The use of non-type argument must now be clear. The values five and three in the first two statements of main() will replace Size of the generic array at compile time. However, it is a constant value that must be known at compile time. This is true for all non-type arguments.

# 7.3.4 Using Default Arguments

Default arguments can be used with template classes. The previous example can be rewritten as follows with default arguments.

```

#include <iostream>
using namespace std;
template <typename Type = int, int Size = 10>
// Note the use of default argument
class SafeGenericArray
{
    Type Array[Size];
public:
    Type & operator [](int Index)
    {
        if((Index < 0) || (Index > Size - 1))
        {
            cout << "Subscript out of range!";
```
