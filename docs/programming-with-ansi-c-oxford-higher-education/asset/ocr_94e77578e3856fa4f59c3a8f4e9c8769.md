+   1. Change the name of the function as operator <operator_symbol> (e.g., operator +) where the function is defined.
+   2. Use that operator as an implicit function call, wherever the function call is made in the program. Thus, Object1.function (Object2) is changed to Object1 <Operator> Object2.

> Note Excessive use of overloading operators may reduce readability, whereas using it judiciously improves readability. Overloading an operator for doing something that is not obvious, such as using '+' for subtracting arguments, is bad programming.
