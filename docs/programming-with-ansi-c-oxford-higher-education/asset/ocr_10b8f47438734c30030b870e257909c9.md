# How the Program Works

Let us now analyse the program component by component.

**Defining overloaded functions** This is a very simple example (there is no class in the program) that shows function overloading. The Add() function is overloaded (defined more than once with int, double, and string arguments) here. The function is not really needed in the program as we could have used + to add two items directly. The purpose of the Add() function is to demonstrate something that is not available in C.
