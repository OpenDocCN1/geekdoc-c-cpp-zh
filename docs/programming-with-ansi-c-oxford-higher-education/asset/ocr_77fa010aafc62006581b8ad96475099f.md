# throw() as Exception Specification

It is also possible to write throw() as an exception specification. This will not let any exception to be thrown from that function. If the function throws an exception, the program would be aborted. Thus, if void ExGen() throw() is written, that is, empty braces to follow the throw, then the function is not allowed to throw any exception. Consider the following program.

```
//ExceptionSpecifcation.cpp
#include <exception>
#include <iostream>
using namespace std;
#include <string>
class MyException
{
private:
    int ExNumber;
    string ExMessage;
public:
    MyException(int ErrNo, string Description)
    {
        ExNumber = ErrNo;
        ExMessage = Description;
    }
```
