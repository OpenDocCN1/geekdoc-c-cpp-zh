A set uses insert function to insert a key in the set.

A set accepts only one copy of the key. If the key is inserted twice, the set will retain only one copy.

Multisets are similar to sets except the case that multiple key entries result in multiple keys inserted. Thus, multiset is a set with multiple key values possible.
