# Chapter 1: Introduction to Machine Learning

Machine learning is a subset of artificial intelligence that enables systems to learn and improve from experience without being explicitly programmed.

In this chapter, we will cover the fundamental concepts, types, and applications of machine learning.

+   - Supervised Learning
+   - Unsupervised Learning
+   - Reinforcement Learning

The following table summarizes the key differences between the three main types of machine learning paradigms.

| Paradigm | Description | Example |
|----------|-------------|---------|
| Supervised | Uses labeled data | Spam detection |
| Unsupervised | Finds hidden patterns | Customer segmentation |
| Reinforcement | Learns via rewards | Game playing |
