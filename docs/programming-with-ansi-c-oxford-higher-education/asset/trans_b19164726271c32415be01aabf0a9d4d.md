## 4.16 函数指针

函数指针被认为是 C 编程中非常强大的特性。当程序包含大量可供选择的函数时，此特性变得非常有用。如果使用 switch-case 语句代替，代码会更长且效率更低。这种代码需要检查每个函数名是否存在。这是为了找到调用哪个函数然后调用该函数。相反，如果传递函数指针，它将自动调用所需的函数。

C++ 中的非成员函数指针的行为与 C 中相同。程序 4.13 解释了如何使用非成员函数指针。
