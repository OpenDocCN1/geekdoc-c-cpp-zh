When a single pure virtual function is defined inside a class, it automatically becomes abstract. The program cannot instantiate the abstract class and, thus, cannot have an object of that class.

The concepts of pure virtual function, virtual destructors, and static invocation of virtual functions are illustrated in Program 10.7.
