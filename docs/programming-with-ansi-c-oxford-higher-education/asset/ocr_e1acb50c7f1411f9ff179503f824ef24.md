# 9.6.1 Public Derivation

Figure 9.2 shows the first case where a class is derived from the base class using the public access specifier. The private member of the base class is copied to the derived class but is not visible. The public members of the base class are copied as public in the derived class.

| Base | Derived |
|------|---------|
| Private → | Not directly accessible |
| int PrivateBaseInt; | int PrivateBaseInt; |
| Public → | Public |
| int PrivateBaseInt; | int PrivateBaseInt; |
| void SetPrivateBaseInt() | void SetPrivateBaseInt() |

The base class sub-object is buried within the derived class object. The private portion of the base class, though copied, is not accessible to the derived class (though base class subobject member functions such as void SetPrivateBaseInt() can access it.)

# 9.6.2 Private Derivation

In this case, the public members of the base class become the private members of the derived class. Again, private members are not inherited. Though the private members of the base class are copied to the derived class, they are not visible. This is shown in Fig. 9.3.

| Base | Derived |
|------|---------|
| Private → | Not accessible |
| int PrivateBaseInt; | int PrivateBaseInt; |
| void SetPrivateBaseInt() | void SetPrivateBaseInt() |
| Private | Private |
| int PrivateDerivedInt; | int PrivateDerivedInt; |
| void SetPrivateDerivedInt() | void SetPrivateDerivedInt() |
| Public → | Public |
| int PublicDerivedInt; | int PublicDerivedInt; |
| void SetPublicPrivateDerivedInt() | void SetPublicPrivateDerivedInt() |
