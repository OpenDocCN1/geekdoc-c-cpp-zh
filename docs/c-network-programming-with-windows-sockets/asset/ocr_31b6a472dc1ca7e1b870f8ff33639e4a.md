Note that the first thing done in the WM_USER_GETHOSTBYNAME message handler is a call to WSAASYNCERROR(). This is a macro that determines the success of the WSAAsyncGetHostByName() request. A value of 0 (zero) means everything is fine. Other possible values are any error messages in WINSOCK.H. If WSAASYNCERROR() returns error WSAENOBUFS, the buffer passed to WSAAsyncGetHostByName() is too small. To be safe, use a buffer at least MAXGETHOSTSTRUCT bytes in size. Also, for your information, the WM_USER_GETHOSTBYNAME message handler, wParam is the asynchronous task handle currently returning operation. This means that you could use the same WM_USER message for multiple, simultaneously outstanding asynchronous requests. You would then examine wParam to determine which specific operation was returning at that instance in time.
