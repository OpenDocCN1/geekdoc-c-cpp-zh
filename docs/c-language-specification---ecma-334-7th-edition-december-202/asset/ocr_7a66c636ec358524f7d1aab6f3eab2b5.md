```
: Decimal_Digit Decorated_Decimal_Digit* Integer_Type_Suffix?
;

fragment Decorated_Decimal_Digit
: '_' * Decimal_Digit
;

fragment Decimal_Digit
: '0'..'9'
;

fragment Integer_Type_Suffix
: 'U' | 'u' | 'L' | 'l' |
'UL' | 'U1' | 'uL' | 'u1' | 'LU' | 'Lu' | '1U' | '1u'
;

fragment Hexadecimal_Integer_Literal
: ('0x' | '0X') Decorated_Hex_Digit+ Integer_Type_Suffix?
;

fragment Decorated_Hex_Digit
: '_' * Hex_Digit
;

fragment Hex_Digit
: '0'..'9' | 'A'..'F' | 'a'..'f'
;

fragment Binary_Integer_Literal
: ('0b' | '0B') Decorated_Binary_Digit+ Integer_Type_Suffix?
;

fragment Decorated_Binary_Digit
: '_' * Binary_Digit
;

fragment Binary_Digit
: '0' | '1'
;
```

The type of an integer literal is determined as follows:

+   - If the literal has no suffix, it has the first of these types in which its value can be represented: int, uint, long, ulong.
+   - If the literal is suffixed by U or u, it has the first of these types in which its value can be represented: uint, ulong.
+   - If the literal is suffixed by L or l, it has the first of these types in which its value can be represented: long, ulong.
+   - If the literal is suffixed by UL, U1, uL, u1, LU, Lu, 1U, or 1u, it is of type ulong.

If the value represented by an integer literal is outside the range of the ulong type, a compile-time error occurs.
