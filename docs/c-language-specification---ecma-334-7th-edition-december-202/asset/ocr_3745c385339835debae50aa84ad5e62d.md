# D.3.16 <summary>

This tag can be used to describe a type or a member of a type. Use <remarks> (§D.3.12) to specify extra information about the type or member.

# Syntax:

```
<summary>description</summary>
```

where

+   - *description* is a summary of the type or member.

# Example:

```
public class Point
{
    /// <summary>
    /// This constructor initializes the new Point to
    /// <paramref name="xPosition"/>,<paramref name="yPosition"/>.
    /// </summary>
    public Point(int xPosition, int yPosition)
    {
        ...
    }

    /// <summary>This constructor initializes the new Point to (0,0).</summary>
    public Point() : this(0, 0)
    {
    }
}
```

# D.3.17 <typeparam>

This tag is used to describe a type parameter for a generic type or method.

# Syntax:

```
<typeparam name="name">description</typeparam>
```

where

+   - *name* is the name of the type parameter.
+   - *description* is a description of the type parameter.

# Example:

```
/// <summary>A generic list class.</summary>
/// <typeparam name="T">The type stored by the list.</typeparam>
```
