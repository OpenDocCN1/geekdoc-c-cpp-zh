# How It Works

Basically, the role of the provider is to send notifications to the APNs server for relaying to the devices. Hence, you are sending a message of the following format:

```
{
  "aps": {
    "alert" : "You got a new message!" ,
    "badge" : 5,
    "sound" : "beep.wav"},
  "acme1" : "bar",
  "acme2" : 42
}
```

Essentially, the beep.wav file name indicates to the client to play the beep.wav file when the notification is received.
