# How It Works

The RootViewController class inherits from the UITableViewController class:

```
@interface RootViewController : UITableViewController {
```

This means that the class itself contains a Table view and that all the various method contained in the RootViewController.m file will be used to populate the Table view.

To connect the RootViewController class to an XIB file:

+   - You first created a View XIB file and then replaced the default View item with the Table View item.
+   - You also connected the dataSource and delegate outlets to the File's Owner item.
+   - The File's Owner item is then set to point to the RootViewController class.
+   - After that, you can connect the File's Owner item to the Table View item.

In the final step, you set the Root View Controller item in the Split View Controller to point to the newly created XIB file.
