# WHAT YOU LEARNED IN THIS CHAPTER

| TOPIC | KEY CONCEPTS |
|---|---|
| Accessing the accelerometer | Ensure that your View Controller conforms to the `UIAccelerometerDelegate` protocol and create an instance of the `UIAccelerometer` class.
To listen to changes in acceleration, implement the `accelerometer:didAccelerate:` method. |
| Detecting shakes | You can either use the accelerometer data or use the new Shake API in iPhone OS 3.0. For the Shake API, handle the following events: `motionBegan:`, `motionEnded:`, and `motionCancelled:`. |
