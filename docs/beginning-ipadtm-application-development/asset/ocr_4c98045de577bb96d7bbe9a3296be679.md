# SUMMARY

This chapter explained how to publish a service on the network using the `NSNetService` class and how to discover services on the local network using the `NSNetServiceBrowser` class. Once peers are discovered on the network, you can connect to them and initiate a peer-to-peer communication. A chat application is a good example of a Bonjour application.
