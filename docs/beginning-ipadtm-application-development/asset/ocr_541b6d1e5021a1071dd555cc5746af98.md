# Code Sense

One of the most common features of modern IDE is code completion, which makes the IDE automatically try to complete the statement you are typing based on the current context. In Xcode, the code-completion feature is known as Code Sense. For example, type the letters uial in a method, such as the viewDidLoad() method, and Code Sense automatically suggests the UIAlertView class (see Figure B-6; notice that the suggested characters are displayed in gray). To accept the suggested word, simply press the Tab or Enter key, or Ctrl-/.
