@implementation HelloWorldViewController

- (IBAction) btnClicked:(id) sender {
    //---display an alert view---
    UIAlertView *alert = [[UIAlertView alloc] initWithTitle:@"Hello World!"

# CUSTOMIZING YOUR APPLICATION ICON

As you saw earlier, the application installed on your iPhone Simulator uses a default white image as an icon. It is possible, however, to customize this icon. When designing icons for your iPad applications, bear the following in mind:

+   - Design your icon to be 72 × 72 pixels. Larger size is all right because iPad automatically sizes it for you. For distribution through the App Store, you need to prepare a 512 × 512 pixel image.
