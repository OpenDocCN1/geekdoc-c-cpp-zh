An object of `Class_A` aggregates an object of `Class_B`. Aggregation association is also known as a “whole-part” or “has-a” relationship. This is a looser version of the whole-part relation in which there is no lifetime dependency between an object of `Class_A` (whole) and object(s) of `Class_B` (part). For example, the FacultyRegistry class aggregates objects of the Student class. However, both can exist without the other. Class_B can belong to one or more objects—thus its multiplicity can be 1..* (denoted as 1..*). But a whole, Class_A, can aggregate 0 or more parts (denoted as 0..*).
