| STL algorithm function | Description | Examples |
|---|---|---|
| `numeric_limits<T>::digits` | Provides the number of digits in the significand (mantissa). | The following code illustrates the infinity and NaN objects. |
| `numeric_limits<T>::has_denorm` | Returns true if type T has denormalized values. |  |
| `numeric_limits<T>::has_infinity` | Returns true if type T has a representation for positive infinity. | Using infinity in computations follows mathematical rules (Korn and Korn 2000). All operations involved with NaN end with NaN; however, no exception is thrown. |

```
double zero { 0.0 };

double inf { 1.0 / zero }; // let’s generate infinity, no exception
const auto kInfinity = numeric_limits<double>::infinity();

cout << "infinity = " << inf << endl;
cout << "inf == inf ? " << ( inf == kInfinity ) << endl;
cout << "123.0 / inf = " << 123.0 / inf << endl;
cout << "inf / 123.0 = " << inf / 123.0 << endl;

// Let’s generate NaN

double nan { inf - inf };
cout << "123.0 + nan = " << 123.0 + nan << endl;
```

The following output is obtained:

```
infinity inf
inf == inf ? true
123.0 / inf = inf
123.0 / inf = 0
123.0 + nan = nan(ind)
```

Using infinity in computations follows mathematical rules (Korn and Korn 2000). All operations involved with NaN end with NaN; however, no exception is thrown.
