A built-in array can contain other built-in array(s) as its elements. This way, we can create multi-dimensional arrays, as in the following example:

```
/* Multidimensional arrays */
enum Dims { kRows = 2, kCols = 2 };
/* kRows is external, kCols internal index */
double affineMatrix[ kRows ][ kCols ] = { 0.0 }; /* initialize all elements to 0.0 */
```

Its elements can be accessed using subscripts, as in the following example:

```
/* Set all off-diagonal elements to -1 */
for( int r = 0; r < kRows; ++ r )
for( int c = 0; c < kCols; ++ c )
if( r != c )
affineMatrix[ r ][ c ] = -1.0;
```

Multidimensional structures can also be accessed with pointers. The following example performs the same action, with only one difference between lines [10] and [15]:

```
/* The same with pointers */
for( int r = 0; r < kRows; ++ r )
for( int c = 0; c < kCols; ++ c )
if( r != c )
* ( * ( affineMatrix + r ) + c ) = -1.0;
```
