| continue in the for loop<br><br>![flowchart](image) | The continue statement is used exclusively in loops (for, while, or do-while). When encountered, it causes the omission of all following statements in the loop and immediately jumps to the next iteration of the loop. If the condition is still true, iteration of the loop continues. | **continue;** | The following code snippet first creates a 2-D array object that is an array of arrays of int objects. Then, after reading its content, the sum of all elements except those on the diagonal is computed.

```cpp
const auto kRows { 12 };
const auto kCols { 12 };
std::array<std::array<int, kCols>, kRows> > _2D_array;
// ... read array from a file
// Add all components of the array
// except for the diagonal
int sum = 0;
for (int r = 0; r < kRows; ++r) {
    for (int c = 0; c < kCols; ++c) {
        if (r == c)
            continue;
        // if diagonal, skip
        sum += _2D_array[r][c];
    }
}
```

When using continue in multiple loops, as in the previous code, remember that it refers to its closest loop. |
