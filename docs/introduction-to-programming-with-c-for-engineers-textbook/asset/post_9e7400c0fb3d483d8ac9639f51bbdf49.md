### 3.13.2.2.1 For Loop

The `for` loop is used to repeat a block of code a specific number of times. It consists of three parts separated by semicolons: an initializer, a condition, and an iterator.

- **Initializer**: executed once before the loop starts. It can be a declaration, an assignment, or any expression.
- **Condition**: evaluated before each iteration. If it evaluates to true, the loop body executes; otherwise the loop terminates.
- **Iterator**: executed after each iteration, typically used to update the loop variable.

If multiple statements need to be executed within the loop, they should be enclosed in curly braces `{}`.

#### Example 1: Simple for Loop

```cpp
for (int i = 0; i < 10; ++i) {
    std::cout << i << " ";
}
```

This prints the numbers 0 through 9.

#### Example 2: Range-based for Loop (C++11)

```cpp
std::vector<int> numbers = {1, 2, 3, 4, 5};
for (int n : numbers) {
    std::cout << n << " ";
}
```

This prints each element of the vector.

#### Example 3: Loop with Empty Parts

```cpp
for (;;) {
    // infinite loop
}
```

This creates an infinite loop that runs until a `break` statement is encountered.

### 3.13.2.2.2 While Loop

The `while` loop repeats a block of code as long as a condition is true. It checks the condition before each iteration.

#### Syntax

```cpp
while (condition) {
    // loop body
}
```

#### Example

```cpp
int i = 0;
while (i < 5) {
    std::cout << i << " ";
    ++i;
}
```

This prints 0 through 4.

### 3.13.2.2.3 Do-While Loop

The `do-while` loop executes the block of code at least once and then checks the condition.

#### Syntax

```cpp
do {
    // loop body
} while (condition);
```

#### Example

```cpp
int i = 0;
do {
    std::cout << i << " ";
    ++i;
} while (i < 5);
```

This also prints 0 through 4, but guarantees at least one execution.

### 3.13.2.2.4 For-Each Loop (Range-based for)

Introduced in C++11, the range-based `for` loop simplifies iteration over containers.

#### Syntax

```cpp
for (type var : container) {
    // loop body
}
```

#### Example

```cpp
std::vector<std::string> words = {"hello", "world"};
for (const std::string& w : words) {
    std::cout << w << std::endl;
}
```

This prints each word on a new line.

### 3.13.2.2.5 Loop Control Statements

- **break**: exits the loop immediately.
- **continue**: skips the rest of the current iteration and proceeds to the next one.
- **return**: exits the entire function (and thus the loop if inside a function).

#### Example with break and continue

```cpp
for (int i = 0; i < 10; ++i) {
    if (i == 5) continue; // skip 5
    if (i == 8) break;    // stop at 8
    std::cout << i << " ";
}
```

This prints 0 1 2 3 4 6 7.

### 3.13.2.2.6 Nested Loops

Loops can be nested within each other.

#### Example

```cpp
for (int i = 0; i < 3; ++i) {
    for (int j = 0; j < 2; ++j) {
        std::cout << "i=" << i << ", j=" << j << std::endl;
    }
}
```

This outputs all combinations of `i` and `j`.

### 3.13.2.2.7 Common Pitfalls

- **Off-by-one errors**: ensure loop bounds are correct.
- **Infinite loops**: ensure the condition can become false.
- **Modifying loop variable inside the loop**: can lead to unexpected behavior.

### 3.13.2.2.8 Summary

- `for` loop: best for known iteration counts.
- `while` loop: best when condition is evaluated before each iteration.
- `do-while` loop: best when the body must execute at least once.
- Range-based `for`: best for iterating over containers.

All loop constructs in C++ are designed to provide clear and efficient control flow for repetitive tasks.
