| `sizeof expr` | Returns `std::size_t` with the size of the object in bytes. In C++, the operand is not evaluated, and expr is not evaluated when the type is used to determine its size. | `int x = 5;`<br>`std::size_t dummy = sizeof x;`<br><br>After the last line, `dummy` contains the size of `x` in bytes (e.g. four bytes in a test system), and the value of `x` is not changed (even if we set `x` to `sizeof x`, the value of `x` would not be changed since `sizeof` does not evaluate its operand expression).<br><br>`long arr[16]; // array of 16 long integers`<br>`// a way to compute the number of elements of an array`<br>`assert(sizeof arr / sizeof arr[0] == 16);`<br><br>`long *arr_ptr = arr; // make a pointer to the first element of arr`<br>`// sizeof arr_ptr returns the size of the pointer by itself (not an array)`<br>`assert(sizeof arr_ptr / sizeof(arr_ptr[0]) == 16);`<br><br>`long (&ref_arr)[16] = arr; // reference to long [16]`<br>`// reference returns size of the array`<br>`assert(sizeof(ref_arr) / sizeof(ref_arr[0]) == 16);`<br><br>A common mistake is to use a single pointer for that purpose, since in this case, `sizeof` will return the size of the pointer in bytes, as shown in the second assert. Assigning a reference to an array works perfectly—see the third assert. |
| `sizeof (type)` | Returns the size of the provided type in bytes. | Each object occupies a number of bytes that can be looked up by the sizeof operator. We have to take this into consideration when placing objects together in structures, such as in the following example: due to data alignment, the size of the whole can be greater than the sum of sizes of its parts. |
| `alignof (type) (C++11)` | Returns the alignment of the provided type in bytes. | `* expr` | Dereferences a pointer. | `// Copy memory starting from the highest addresses down`<br>`// Copy memory [assigned char * dst, unsigned char * src, int num_of_bytes)`<br>`for (i = num_of_bytes; i > 0; i--) {`<br>`    // src is one address after the source buffer`<br>`    // dst is one address after the destination buffer`<br>`    *dst = *src--; // return original value, then decrement`<br>`    dst--;`<br>`}`<br><br>`const int kBytes = 256;`<br>`unsigned char source[kBytes];`<br>`unsigned char destination[kBytes];`<br>`BackwardMemCopy(&destination[0], &source[0], kBytes);`<br><br>`BackwardMemCopy` can be used to copy overlapping memory blocks, if `src < dst`. To do so, copying starts with the uppermost addresses and proceeds downward. Bytes are copied by a while loop that performs exactly `num_of_bytes` iterations. The `dst` and `src` pointers are affected by an amount equal to the size of the byte group, since they are right-associative; the pointers are incremented by 1 and the new value of the pointer is returned to the `*` operator. As a result, each pointer is read and its value is copied to the location pointed to by the current value of the other pointer. In the best case, the source bytes are read and copied to the destination memory block. When calling `BackwardMemCopy`, the address to the first element (`destination[0]`) is used to get a pointer to the destination memory block. The same value is obtained by writing `destination`, since the name of an array is a constant pointer to its first element.<br><br>`// Copy memory starting from the highest addresses down`<br>`void BackwardMemCopy(char *dst, unsigned char *src, int num_of_bytes) {`<br>`    while (num_of_bytes-- > 0) {`<br>`        *dst-- = *src--;`<br>`    }`<br>`}` |
