### Table 6.1 Special characters and groupings of regular expressions (default ECMA standard).

| Symbol | Matches | Examples |
|---|---|---|
| `.` | Any character (a wildcard) | `.+`<br>Matches any stream of one or more characters.<br>`0001010102001100` |
| `*` | 0 or more occurrences of a character |  |
| `+` | 1 or more occurrences of a character |  |
| `?` | 0 or 1 occurrence of a character. After any of the repetition notations forces the shortest match (otherwise the longest one is sought) | `^.*$`<br>Matches a whole line: `^` for begin and `$` for end of line.<br>`0001010102001100` |
| `\|` | Alternative (or) | `(01)+`<br>Greedy search – finds the longest match of repeated 01.<br>`0001010102001100` |
| `^` | 1) Start of line or 2) negation | `(01)+?`<br>Lazy search – finds the shortest case of 01.<br>`0001010102001100` |
| `$` | End of line | `[01]+`<br>Finds the longest string of 0 or 1 with at least one char.<br>`0001010102001100` |
| `\` | Next character has special meaning | `[^01]+?`<br>Finds the shortest substring of not 0 and not 1.<br>`0001010102001100` |
| `[ ]` | Defines a character set |  |
| `{ }` | Begin-end count<br>`{ p }` – p times<br>`{ p, }` – p or more times<br>`{ p, q }` – p to q times including | `(123){2}(45){3}`<br>With `{2}`, the pattern 123 will be repeated exactly 2 times, then 45 has to be matched exactly 3 times, etc.<br>`12312312312345454545` |
| `( )` | Begin-end grouping | `<(.+>)(.+)</\1>`<br>Matches any XML tag. `\1` denotes the first grouping.<br>`<city>New York</city>` |
| `\1 \2 \3` | Group numbering (starts from 1) |  |
