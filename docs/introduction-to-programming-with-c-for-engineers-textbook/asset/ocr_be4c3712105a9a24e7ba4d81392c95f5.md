# Table A.3  Common C memory functions (in `<cstring.h>`). The C++ STL contains their counterparts—the same names with the `std::` prefix (in `<cstring>`).

| Function | Description | Examples |
|---|---|---|
| `memset` | Fills a block of memory pointed to by `dst` with `num` bytes of the value `val` (interpreted as a byte). Returns `dst`.<br><br>`void * memset( void * dest, int val, size_t num );` | The following example allocates, sets, and copies a memory buffer:

```c
int buf_size = 256; /* Size of heap alloc can be set at runtime. */

unsigned char * buf = malloc( buf_size ); /* Allocate on the heap */
if( buf == NULL )
    return; /* Error, cannot allocate memory. Exiting. */

memset( buf, 0x00, buf_size ); /* Fill buf with 0 */

char * text = "quick brown fox";

/* Get text length + sentinel 0 */
int text_total_len = strlen( text ) + 1;

memcpy( buf, text, text_total_len ); /* Copy text to buf */

char * prefix = "The ";

/* Move to make room at the beginning of text */
memmove( buf + strlen( prefix ), buf, text_total_len );

memcpy( buf, prefix, strlen( prefix ) ); /* Copy prefix but not 0 */

printf( "%s\n", buf );

free( buf ); /* Do NOT FORGET to release memory. */
``` |
| `memcpy` | Copies `num` bytes from a memory block at `src` to the memory block at `dst`. The blocks should not overlap.<br><br>`void * memcpy( void * dest, const void * src, size_t num );` | — |
| `memmove` | Copies `num` bytes from a memory block at `src` to the memory block at `dst`. The blocks can overlap. Returns `dst`.<br><br>`void * memmove( void * dest, const void * src, size_t num );` | — |
