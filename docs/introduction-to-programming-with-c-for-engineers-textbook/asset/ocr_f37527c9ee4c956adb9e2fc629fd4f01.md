**do-while loop** &  & In the do-while loop, all included statement(s) are executed once, regardless of the value of the condition. Then, the statement(s) are executed at each iteration, as long as the condition of the while loop is true. & do statement ; while( condition ) ; do { statement (s) ; } while( condition ) ; & const size_t kSize = 16; std :: array< int, kSize \&gt; tab; // define an array of ints // fill the array - this time do-while int i = 0; do tab[ i ++ ] = 0; while ( i \&lt; tab.size() ) ; This code does the same array initialization as the previous while loop. This time, a do-while is used, which first executes tab[ i ++ ] regardless of the condition! Then the condition i \&lt; tab.size() is checked and the loop continues, if and only if the condition is true. Otherwise, the loop is stopped and the next statement after the loop is executed. In this case, we can freely execute tab[ i ++ ] without checking the condition, since the size of an array is always greater than 0. int age = 0; do cout << "Enter your age ..." \&lt;\&lt; endl; cin \&gt;\&gt; age; // read age from keyboard } while( age \&lt;= 0 || age \&gt; 150 ) ; // Ask until valid range In this code, the user is asked in a do-while loop to enter a valid age value. \\
