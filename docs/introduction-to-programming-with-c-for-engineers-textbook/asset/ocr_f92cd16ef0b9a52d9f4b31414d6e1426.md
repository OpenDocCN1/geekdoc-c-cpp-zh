When traversing a tree, the `LeftRightProcess` function, whose definition starts on line [12], is called repeatedly from different nodes on different levels of the tree. Each level is expressed by a different indentation value. Therefore, at each call to `LeftRightProcess`, the indentation value is advanced by a constant value, as on line [16].
