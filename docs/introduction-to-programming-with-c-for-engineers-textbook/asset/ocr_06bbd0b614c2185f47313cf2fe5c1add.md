| Input/output manipulator | Description | Example |
|---|---|---|
| `setbase` | Sets the base of the output (allowed values are 8, 10, and 16, or 0 to reset to decimal). | ```cpp
cout << "100d = " << 100 << " dec" << endl;
cout << "100d = " << std::hex << 100 << " hex" << endl;
cout << "100d = " << std::oct << 100 << " oct" << endl;
cout << "100d = " << std::dec << 100 << " dec" << endl;
```

Output:
```text
100d = 100 dec
100d = 144 oct
100d = 64 hex
100d = 100 dec
``` |
| `dec`<br>`oct`<br>`hex` | Sets the base of the output to 10, 8, or 16. |  |
