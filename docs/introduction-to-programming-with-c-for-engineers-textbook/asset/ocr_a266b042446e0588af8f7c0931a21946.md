_A.5 Converting Bin, Oct, Dec, and Hex Values with FixBinCalc_

_FixBinCalc is an MFC application project we can use to easily convert between six numerical formats: floating-point, fixed-point, decimal, octal, binary, and hexadecimal. It was written by the author when working on FPGA programming to investigate binary values on different microprocessor_
