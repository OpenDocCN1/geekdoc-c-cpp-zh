| Operator | Description | Examples |
|---|---|---|
| `sizeof expr` | Returns `std::size_t` with the size of the object in bytes. In C++, the operand is not evaluated, and expr is not evaluated when the type is used to determine its size. | **Examples**

```cpp
int x = 5;
std::size_t dummy = sizeof x;
```

After the last line, `dummy` contains the size of `x` in bytes (e.g. four bytes in a test system), and the value of `x` is not changed (even if we set `x` to `sizeof x`, the value of `x` would not be changed since `sizeof` does not evaluate its operand expression).

With arrays, a common practice to count elements is to divide the total number of bytes by the number of bytes occupied by the first element, as in the following code:

```cpp
long arr[16]; // array of 16 long integers
// a way to compute the number of elements of an array
assert(sizeof arr / sizeof arr[0] == 16);

long *arr_ptr = arr; // make a pointer to the first element of arr
// sizeof arr_ptr returns the size of the pointer by itself (not an array)
assert(sizeof arr_ptr / sizeof(arr_ptr[0]) == 16);

long (&ref_arr)[16] = arr; // reference to long [16]
// reference returns size of the array
assert(sizeof(ref_arr) / sizeof(ref_arr[0]) == 16);
```

A common mistake is to use a single pointer for that purpose, since in this case, `sizeof` will return the size of the pointer in bytes, as shown in the second assert. Assigning a reference to an array works perfectly—see the third assert.
