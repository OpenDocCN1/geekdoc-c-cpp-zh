L1, L2, and L3 are memory blocks called *memory caches* and have different sizes and access times. Their characteristic feature is that the further from the ALU such a memory cache is, the larger its capacity – but its access time is also longer. At the very end of this specific capacity-speed triangle is the main memory: its capacity is a few orders of magnitude greater than that of the memory caches, but it also has the longest access times. This is due to the hardware technologies used to manufacture it. Registers and caches are internal processor memory (cores). But this is the *external main memory*, which, in the von Neumann architecture, contains the entire body of compiled executable code for a program as well as most of its data. More specifically, this is *operational memory*, which, unlike disk storage, can be directly addressed by a processor in order to execute a program.
