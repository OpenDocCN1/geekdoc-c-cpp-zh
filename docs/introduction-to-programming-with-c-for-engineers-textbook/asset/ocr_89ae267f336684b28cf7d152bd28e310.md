| `to_string( v )` | Converts an object to a string. | In this example, a file is opened and read line by line in the `while` loop (Section 3.13.2.2) with a call to the `getline` function. Then, the number of lowercase characters is counted and stored in `cnt_lower`.

```cpp
// Count all lowercase letters in the string
string filename( "letters.cpp" );
ifstream infile( filename );

int cnt_lower = 0; // Set to 0

string line; // Empty buffer for a line

while( getline( infile, line ) ) // Read line-by-line
{
    for( const auto c : line ) // For each char
        if( islower( c ) )
            ++cnt_lower; // Increment if lowercase
```
