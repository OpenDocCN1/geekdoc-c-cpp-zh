| `* expr` | Dereferences a pointer. | `BackwardMemCopy` can be used to copy overlapping memory blocks, if `src < dst`. To do so, copying starts with the uppermost addresses and proceeds downward. Bytes are copied by a while loop that performs exactly `num_of_bytes` iterations. The `dst` and `src` pointers are affected by an amount equal to the size of the byte group, since they are right-associative; the pointers are incremented by 1 and the new value of the pointer is returned to the `*` operator. As a result, each pointer is read and its value is copied to the location pointed to by the current value of the other pointer. In the best case, the source bytes are read and copied to the destination memory block. When calling `BackwardMemCopy`, the address to the first element (`destination[0]`) is used to get a pointer to the destination memory block. The same value is obtained by writing `destination`, since the name of an array is a constant pointer to its first element. |

```c
// Copy memory starting from the highest addresses down
void BackwardMemCopy(char *dst, unsigned char *src, int num_of_bytes) {
    while (num_of_bytes-- > 0) {
        *dst-- = *src--;
    }
}
```
