
Finally, data from the cube object's buffer needs to be copied to the newly allocated buffer. This is accomplished on lines [57–58] with the `std::memcpy` function (Section A.2.6). It copies bytes between two memory buffers, with the destination—which is pointed to by the call `fDataBuf.get()`, and the source—pointed to by `cube.fDataBuf.get()`. To get the correct number of bytes, we need to multiply the amount of data expressed by the `elems` variable from line [49] by the number of bytes allocated for each data item, i.e. `sizeof(value_type)`.
