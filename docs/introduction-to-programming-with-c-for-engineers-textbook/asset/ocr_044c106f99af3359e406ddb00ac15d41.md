| (`type`) expr | Type conversion. Used to force a type change using a value conversion procedure, which sometimes leads to data loss (e.g. converting double to char). | ```cpp
char * text = "The quick brown fox";
std::cout << text << "0x";
std::cout << std::hex << std::setfill('0') << std::setw(2);
std::cout << (size_t) text << std::endl;
```
To print the address of `text`, and not the text itself, we need to cast `text` into the `size_t` type. Here the old C-style cast is equivalent to the C++ reinterpret_cast. We also use the function `cout << std::hex` to set the `std::ios` hex flag in order to have a hexadecimal display (Table 3.14). |
