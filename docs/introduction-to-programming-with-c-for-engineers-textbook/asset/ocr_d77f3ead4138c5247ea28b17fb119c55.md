| `memcmp` | Compares `num` bytes at locations pointed to by `p1` and `p2`. Returns 0 if the two blocks are the same, or non-zero otherwise.\n\n```c\nint memcmp( const void * p1, const void * p2, size_t num );\n``` | To allocate a memory region on the heap, `malloc` is called on line [3]. To make room for a few more characters at the beginning, `memmove` is called on line [19]. New text is then copied in line [21]. But to join the strings, 0 is omitted. Finally, memory is deallocated by calling `free` on line [25]. If it is not, a memory leak will occur. When run, the following appears on the terminal:\n\n> The quick brown fox. |
