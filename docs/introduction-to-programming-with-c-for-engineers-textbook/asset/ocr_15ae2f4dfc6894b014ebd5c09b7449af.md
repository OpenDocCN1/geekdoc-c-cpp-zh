for dependent names when an instantiation happens with a particular type. Hence we can use the `typename` keyword in front of a name that is dependent on a template parameter to tell the compiler that this is the name of a type. If `typename` is not placed in front of a dependent name, the compiler treats it as a non-type name and sifts it out in the first pass. There are many additional rules involved in template parameter matching, particularly concerning the dependent and non-dependent types (*https://stackoverflow.com/q/610245*; Stroustrup 2013; Cppreference.com 2019b; Vandevoorde et al. 2017).
