+   - The currency code attribute will be used as a key to uniquely identify a currency record in the currency database
+   - The currency database can be stored for further program initialization
+   - It will be possible to add new currencies, as well as to find and access the existing ones
+   - The amount to exchange will be computed with reference to the reference currency. There will be two options:
+     - To buy currency
+     - To sell currency
