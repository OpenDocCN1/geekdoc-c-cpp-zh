Class_A "knows" about Class_B, so Class_A can call members of Class_B.
This relation is indicated by an arrow from Class_A to Class_B. "Knows" relations can be either one- or bi-directional (bi-directional arrows).
Optionally, the ends of the connections can contain quantities.
Objects of these classes do not depend on each other, but changing the interface of one can affect the other.

![](bbox=[0.328, 0.446, 0.504, 0.553])

The classes have a loose, one-directional relation. PlotServer is a class that facilitates printing services (Class_B). PartialEquationSolver (Class_A) knows and calls for services from PlotServer to print out some of its results. But the two classes are not bound. An object of the Class_B needs to be alive when called by an object of Class_A, which is fulfilled here since gPlotServer is a static object.
