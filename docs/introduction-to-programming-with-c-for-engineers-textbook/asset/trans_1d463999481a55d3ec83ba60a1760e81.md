# 7.4.8.1 基于牛顿迭代计算平方根的函数

如前所述，求解函数的根有许多应用，例如优化问题。另一个有趣的应用是计算那些没有简单实现方式的函数。在计算中，我们使用另一个有简单算法的函数。为了演示这种方法，我们将计算给定实数值的平方根。为了了解如何使用牛顿法计算平方根，让我们从希望计算的函数开始：

$$f(x)=\sqrt{x} \tag{7.49}$$

它可以写成如下形式：

$$y=\sqrt{x}$$

自然，我们假设不知道如何直接计算 $\sqrt{x}$。然而，如果我们将前一个方程的两边平方，就会得到

$$y^2=x$$

整理后得到

$$y^2-x=0$$
