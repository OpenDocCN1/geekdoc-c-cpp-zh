In addition to removing hidden characters, the `chomp()` function returns value. The return
value is 1 if the `chomp()` function finds that the string you have provided contains a hidden
newline character. The return value is 0 if the `chomp()` function finds that the string you have
provided as an argument contains no hidden newline character. In the lines accompanying com-
ment #1, Listing04_07 shows you the return values of the `chomp()` function.
