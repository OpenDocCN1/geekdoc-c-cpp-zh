# # First View of the Perl Editor

As Figure 2.25 illustrates, your first view of the DzSoft Perl Editor provides you with a Perl file that is ready to be run. Notice the Edit and Run tabs on the left and the Perl program in the edit area on the left.

As you can see from Figure 2.25, the first message you see creates an HTML document. The document consists of three lines. The first line is called the “bang” line. This identifies the directory in which the Perl interpreter resides. A blank line follows. Then you’ll see two lines that begin with `print`.
