# # Determining if Elements Are Defined

You use the defined() function in precisely the same way that you use the exists() function. As an argument, you employ the hash lookup operation. You include as the argument of the lookup function the key you want to test. The defined() function discovers whether a key has been defined. Listing09_02 pursues the same scenario described in the previous section. Dmitri Mendeleev and John Newlands used different data sets in their investigations of the Periodic Table of Elements.
