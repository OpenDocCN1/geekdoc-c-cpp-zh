# # Contexts and Returning Arrays and Hashes

As previous examples of using the argument array demonstrate, the context into which you
introduce the returned value of a function determines how it is “cast.” In other words, if you
use the returned value as a string, then it becomes a string. If you use it as a number, then it
becomes a number. (If you cast a word as a number, the value of the word is 0.) This same
relationship applies to hashes and arrays. Listing12_06 demonstrates how this works using an
array that contains information relating to the way the biosphere dissipates solar radiation. The
`sortRows()` function receives a hash as its argument. It processes the values in the hash and
returns them as an array. The `displayTable()` function then displays the sorted data.
