# # Extracting Elements from the Front of an Array

The `shift()` function removes elements from the beginning of the arrays. To understand how this works, consider Figure 7.5. When you create an array using, for example, the `list()` function, the first element you assign to the array is associated with the index position of 0. The second element you assign to the array is associated with the index position of 1. The array continues to grow in this way as you add elements. When you employ the `shift()` function, you automatically remove the element associated with the lowest index. At the same time, as you remove the element using the `shift()` function, all the elements in the array are shifted toward the front (or zero index) of the array.
