# Command Line Interactions

```
#1 Prompt for information from the user
$NameTyped = <STDIN>;
print "\nYour name: " . $NameTyped;
```

You can write programs to run at the command line without including the first two lines of Listing04_09, but it does not hurt to include them for form’s sake. In the lines associated with comment #1, you type a line that includes a handle (<STDIN>). A handle allows you to enter information. In this instance, the information you enter is stored in a scalar ($NameTyped). You then use the print() function to display the information.

Handles are dealt with more extensively in a later chapter, but for now note that the expression <STDIN> represents a convention. If the program line included only a less than sign (<) and a greater than (>) sign, with no handle identifier (STDIN), the interpreter would find no fault with the program, and you would still be able to enter input as prompted.

To run the program, you can type it and execute at the DOS prompt as you do any other Perl program. If you run the program from the DzSoft Perl Editor, select Run > Run in command prompt or press Shift + F9. Then at the prompt as instructed, type your name and press Return. The program displays your name. If you press Return a second time, the program exits. Figure 4.11 illustrates the program’s execution. # Setting Up the DzSoft DOS Window

If you execute a command prompt program from the DzSoft Perl Editor, you can change the window so that it permanently displays a white background and dark type. If you press Shift + F9 in the DzSoft Perl Editor (or just execute your program from the DOS prompt or Windows Explorer), you see the DOS window shown at the top of Figure 4.12.

To change the background so that you see dark font on a light background, right-click the control icon on the command prompt window and select Properties. You then see the dialog represented in the middle of Figure 4.12. Click the Colors tab. Then click the radio button for Screen Background. Click the white box on the color palette to set the background color. Then click the radio button for Screen Text. Click the black box on the color palette to set the text color. Click OK to close the dialog. When a dialog to confirm your changes opens, click the button for Save Properties for Future Windows with the Same Title.
