# # The while Statement

The control condition you assign to the `while` repetition statement determines whether the flow of your program can enter the statement controls. It then tests the condition with each repetition, and until the condition chances to false, the repetition continues. As Figure 11.9 illustrates, one common approach to working with a `while` control statement involves using a counter. You must place the counter inside the `while` block. You evaluate it in relation to a limiting value with each cycle of the block.
