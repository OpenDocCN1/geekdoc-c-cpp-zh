# Using the `shift()` Function

The `shift()` function applies to arrays. You can use it in the same way you use the `pop()` function to access array keys that you use in common with the lookup function to retrieve values for display. The only difference between the `pop()` and `shift()` functions is that the `pop()` function extracts items from the end of an array while the `shift()` function extracts elements from the beginning of an array. As mentioned previously in relation to the `pop()` function, given that the `shift()` function actually removes items from an array, you can enhance the performance of a program by using it.
