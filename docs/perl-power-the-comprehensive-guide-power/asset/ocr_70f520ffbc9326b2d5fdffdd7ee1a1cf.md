To retrieve values from the argument array, you can assign the array to a local array or hash. After completing this assignment, you can then use standard array and hash functions to perform operations. The operations you implemented in this chapter included sorting, printing, formatting, and performing simple calculations. Regardless of the operation performed, you can return the results.
