# # Sequence and Incremental Operations

Incremental operations involve unary operators. The sequential actions of a program can drive incremental operations. If you employ incremental operations in relation to array indexes, the sequential flow of a program can affect how you retrieve elements from an array. (Chapter 15 provides an extended discussion of regular expressions.) It then allows the sequential flow of the program to drive an iterator that retrieves the lines of the poem and displays them.
