# The read() Function

The read() function works with either three or four parameters. The first parameter identifies a file handle. The second parameter establishes a string identifier you can use to extract characters from a file during the read operation (the target string). The third parameter designates the number of characters you want to extract. The fourth parameter relates to the identifier you want to store characters in (the target string). It indicates the index position in the target string that you want to use as the beginning point as you transfer characters to it.

To use the read() function, you first call the seek() function to designate the starting point. The read() function reads from the starting point for the number of characters you designate.
