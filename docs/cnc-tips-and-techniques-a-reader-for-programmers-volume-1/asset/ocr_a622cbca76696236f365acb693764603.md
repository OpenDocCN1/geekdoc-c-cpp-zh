# Semicircle Method

A semicircle is one half of a circle or 180° arc sweep. For a full circle programming using this particular method, two half arcs are necessary.

```
```text
N30 G90 G00 X20.0 Y0 (P1) (== USING I AND J VECTORS ==)
...
G02 X-20.0 Y0 I-20.0 J0 (P2)
X20.0 Y0 I20.0 J0 (P1)
G00 ...
```
```

```
```text
N40 G90 G00 X20.0 Y0 (P1) (== USING DIRECT RADIUS R ==)
...
G02 X-20.0 Y0 R20.0      (P2)
X20.0 Y0 R20.0 (P1)
G00 ...
```
```

What is interesting about the semicircle method is that it is often used as the default for CAM-generated part programs. The main reason is that in order to output R-radius, the four-block method is not necessary and the one-block method cannot use R-radius at all. Of course, the output can be changed by the user through post-processor customization.
