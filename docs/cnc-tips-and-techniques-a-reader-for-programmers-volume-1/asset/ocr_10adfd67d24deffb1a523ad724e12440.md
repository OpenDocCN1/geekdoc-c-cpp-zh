# Lathe Cycles G70-G72 — Part 2

*March 2009, updated February 2013*

In this second essay of two, we look at the roughing and finishing cycles for turning and boring in more detail. When programming the G71/G72 lathe cycles, some general comments can be useful. Following the suggestions presented here may prevent some common programming difficulties:

# Preventing Programming Difficulties

+   - In the two-block format, both blocks have to contain the G71 or G72 command — neither is a modal command.
+   - The P-address is always the block number where the contour starts (first point).
+   - The Q-address is always the block number where the contour ends (last point).
+   - Watch the P and Q numbers as they relate to existing block numbers. Change of block numbers, such as re-sequencing, could influence the P and Q numbers. I know of only one CNC-oriented editing software (NCPlot™ from www.ncplot.com) that will automatically renumber P and Q references, if the block numbers have been changed. Also, make sure that no block number is duplicated in the program.
+   - Feedrates programmed between the P and Q blocks are for finishing cycle G70 only.
+   - The start position for the cycle is defined as the last XZ coordinate before the G71/G72 is called.
+   - For safety reasons, use the same start point for roughing with G71/G72 and finishing with G70, unless a special application is necessary.
+   - The cycle starts and ends at the initial start point, and the return to this point is automatic (do not return to the start point within the P-Q block range).
