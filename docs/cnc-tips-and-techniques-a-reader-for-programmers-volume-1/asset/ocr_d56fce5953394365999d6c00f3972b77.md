# Setting Up a New Part

*December 2008, updated February 2013*

CNC machine operators usually start a new job by studying the documentation included with the program, using the engineering drawing as the main source of information. Additional data are often covered in a setup sheet or a tooling list, along with a graphic representation of the setup. This month we look at general setup procedures that can be used for various types of CNC machines.
