## 24.7.11 Join view [range.join]

### 24.7.11.1 Overview [range.join.overview]

1 join_view flattens a view of ranges into a view.

2 The name views::join denotes a range adaptor object (24.7.2). Given a subexpression E, the expression views::join(E) is expression-equivalent to join_view{E}.

> [Example 1:
> vector<string> ss{"hello", " ", "world", "!"};
> join_view greeting{ss};
> for (char ch : greeting)
>     cout << ch;                         // prints: hello world!
> — end example]
