5 [Example 3: Because each referenced namespace is searched at most once, the following is well-defined:

```
namespace B {
    int b;

namespace A {
    using namespace B;
    int a;

namespace B {
    using namespace A;
}

void f()
{
    A::a++;
    // OK: a declared directly in A, S is {A::a}

    // OK: both A and B searched (once), S is {A::a}

    // OK: both A and B searched (once), S is {B::b}
```
