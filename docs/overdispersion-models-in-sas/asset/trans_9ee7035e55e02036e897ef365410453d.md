```
U(\beta) = \frac{\hat{Q}(y, \mu)}{\hat{\beta}} = 0. (3.4)
```

式 (3.4) 中的函数 $U(\beta)$ 是 **拟得分函数**。由 (3.2) 可知，方程 (3.4) 可写为

```
\sum_{j=1}^n \frac{Y_j - \mu_j}{\sqrt{\phi(\mu_j)}} \frac{\hat{\mu}_j}{\hat{\beta}} = 0. (3.5)
```

关于 $\beta$ 求解 (3.5) 的解不需要知道 $\phi$，因为 $\phi$ 是一个尺度参数且会被抵消。因此，这些方程化简为

```
\sum_{j=1}^n \frac{Y_j - \mu_j}{\sqrt{\phi(\mu_j)}} \frac{\hat{\mu}_j}{\hat{\beta}} = 0,
```

从计算角度来看，如果 $Y_j$ 属于指数族的某个成员且 $\phi=1$。与广义线性模型 GLMs 的情况类似，(3.5) 的解等价于第 2.6 节中的迭代加权平方程序。已知 $\hat{\beta}$ 后，可以计算离散参数 $\phi$ 的矩估计。$\phi$ 的两种常用估计是通过将 Pearson $X^2$ 或偏差除以其自由度进行标准化得到。其他矩估计也是可能的。

在温和的正则条件下，估计向量渐近方差为

```
Var(\hat{\beta}) \equiv \phi(\mathbf{D}'\mathbf{V}^{-1}\mathbf{D})^{-1}. (3.6)
```

其中 $\mathbf{D}$ 是 $n \times n$ 的一阶导数矩阵

```
\mathbf{D} = (\frac{\hat{\mu}_1}{\hat{\beta}}, \frac{\hat{\mu}_2}{\hat{\beta}}, \dots, \frac{\hat{\mu}_n}{\hat{\beta}})' \equiv (d_1, d_2, \dots, d_n)'
```

而 $\mathbf{V}$ 是方差函数的 $n \times n$ 对角矩阵

```
\mathbf{V} = \text{Diag}(v(\mu_1), v(\mu_2), \dots, v(\mu_n)) \equiv \text{Diag}(v_1, v_2, \dots, v_n).
```

注意方差 (3.6) 可写为

```
Var(\hat{\beta}) \equiv \phi \left(\sum_{j=1}^{n} d_j^{-1} d_j^{\top}\right)^{-1} (3.7)
```

对于正则链接，方程 (3.6) 变为

```
Var(\hat{\beta}) \equiv \phi(X^{\top}X)^{-1} (3.8)
```

## 3.3 口腔护理实例

为了说明拟似然估计过程，考虑表 3.1 中的数据，该数据取自一项临床试验（Schulte et al., 1998），其中 $n=17$ 名受试者连续六周使用实验性牙膏刷牙。研究结束时在每个受试者口腔的四个部位 ($m=4$) 测量 pH 值。认为如果 pH $\le 6.5$，受试者患口腔疾病的风险更高。注意 pH 测量与刷牙习惯、所用牙膏、食物摄入以及受试者的遗传特征有关。因此，自然会假设每个受试者各部位之间存在正相关且存在过度离散。

令 $T_j, j=1,2,...,n$ 表示每个 $n$ 名受试者中观察到的 pH 耗竭部位数。考虑 $T_j, j=1,2,...,n$ 不相关且同分布的简单情况，相对于二项式模型存在过度离散。$T_j$ 的均值和方差分别为 $\mu_j=m\pi$ 和 $\phi(\mu_j)=m\pi(1-\pi)$，其中 $\phi=\{1+\rho(m-1)\}$，$\pi=Prob(pH \le 6.5)$ 且 $\rho$ 为组内相关，假定为正。对于感兴趣的参数 $\pi$，链接函数为恒等函数。如果读者估计的是对数几率，则对数链接是合适的。

### 表 3.1：口腔护理研究中的 pH 数据

| pH $\le$ 6.5 的口腔部位数 | 0 | 1 | 2 | 3 | 4 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 受试者数 | 4 | 4 | 6 | 2 | 1 |

令 $t_j$ 表示 $T_j$ 的实现。在这个简单例子中，拟似然得分函数 (3.5) 的解化简为

```
$$\sum_{j=1}^{n} \frac{t_j - m\pi}{m\pi(1-\pi)} = 0.
```

在这种情况下，$\pi$ 的拟似然估计有显式解，即

$$\hat{\pi} = \frac{\sum_{j=1}^n t_j}{nm}$$

$\phi$ 的矩估计可通过计算偏差除以其自由度得到，即

$$\hat{\phi} = 2\sum_{j=1}^n \left\{ t_j \log\left(\frac{t_j}{m\hat{\pi}}\right) + (m-t_j)\log\left(\frac{m-t_j}{m-\hat{\pi}}\right) \right\}$$

程序 3.1 提供了使用 GENMOD 过程执行此拟似然估计示例的编程语句。注意簇大小为 $m=4$，我们正在创建 $n=17$ 个 '$t_j$' 的串，以使分析与 $\hat{\pi}$ 和 $\phi$ 使用的记号保持一致。

### 程序 3.1：表 3.1 中 pH 数据的拟似然分析

```sas
/*
Oral Care Example from Schulte et al., 1998
*/
data pH;
  input t f;
  m = 4;
  do i=1 to f;
    output;
  end;
  drop i;
  datalines;
0 4
1 4
2 6
3 2
4 1;
ods html close;
proc genmod data=pH;
  model t/m = binomial link=identity scale=deviance;
run;
```

GENMOD 过程产生的输出随后在输出 3.1 中给出。我们仅提供与示例讨论相关的输出选定部分。对于二项式模型，GENMOD 过程返回 $\sqrt{\phi}$ 而不是 $\phi$。在此示例中，$\pi$ 和 $\phi$ 的估计值分别为 $0.3824$ 和 $1.8878$。值 $1.8878$ 在输出中是偏差除以其自由度。组内相关 $\rho^2$ 的矩估计可通过求解方程 $\phi=\{1+\rho(m-1)$ 得到。这给出 $\rho^2 =0.30$。注意这里没有协变量且所有簇大小相同，可以进行此操作。一般来说，可能从 $\phi$ 中恢复 $\rho^2$。鉴于 $\hat{\pi}$ 的估计标准误为 $0.0810$，$\pi$ 的近似 95% 置信区间为 $(0.22, 0.54)$。在假设二项式模型意义上的朴素误差为 $0.0810/1.3740=0.0589$（输出中未报告）。该估计导致置信区间更窄，覆盖概率低于名义水平。在研究进行前，建立了基线率（pH $\le 6.5$ 的部位比例）；报告为 $71\%$。因此，我们可以得出结论，实验性牙膏在降低口腔部位患口腔疾病更高风险的比例方面是有效的。
