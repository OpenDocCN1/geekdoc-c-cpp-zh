We now turn to the Pseudo-likelihood (PL) method available in the GLIMMIX procedure. The PL method linearizes the model, and the scale parameter ϕ turns into a residual scale parameter in a weighted Normal mixed model. One advantage of the PL method over the Quasi-likelihood method is that it provides a standard error for ϕ . This would be useful for assessing the presence of overdispersion. We illustrate the computation of the PL method using the programming statements in Program 3.3.

# Program 3.3: Fitting Pseudo-likelihood (PL) Logistic Regression Model to Toxoplasmosis Data

```
data toxoplasmosis;
  set toxoplasmosis;
  city = _n_;
run;
ods html;
proc glimmix data=toxoplasmosis;
  class city;
  model t/m = z*z*z / s;
  random _residual_ / subject=city;
run;
 html close;
```

The results from running Program 3.3 are shown in Output 3.3. Note that the estimates and their standard error are the same as in Output 3.2, where we ran a Quasi-likelihood analysis. Note that the PL output provides ϕ=1.9404 with an estimated standard error of 0.5010. Since the estimate ϕ is more than twice the standard error, we might conclude there is overdispersion.

The standard errors of the beta estimates under PL reflect the inflation by √ . Later on, we will discuss simultaneous variance adjustments under a full likelihood estimation of the betas and the the overdispersion parameter.
