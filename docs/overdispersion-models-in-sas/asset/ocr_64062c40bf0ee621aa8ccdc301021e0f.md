The Rate Ratio is

```
$RR = \left(\sum_{j=1}^{n_i} y_{ij} / \sum_{j=1}^{n_i} z_{ij}\right) \cdot \left(\sum_{j=1}^{n_i} y_{2j} / \sum_{j=1}^{n_i} z_{2j}\right)$
```

An approximate 95% confidence interval for the Rate Ratio is (0.2270, 0.7283). This confidence interval was obtained by applying the inverse link function, which is the exponential function to the bounds of the model scale confidence interval ($-1.4829, -0.3170$).
