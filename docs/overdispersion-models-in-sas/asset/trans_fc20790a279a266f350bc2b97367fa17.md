

## 表 4.4: 当 $\pi=0.3, \rho=0.2,0.7$ 且 $m=4,20$ 时，Beta二项分布与随机聚集二项分布的偏度

| $\rho$ | m | Beta-二项分布 (Beta-binomial) | 随机聚集二项分布 (Random-clumped Binomial) |
|---|---|---|---|
| 0.2 | 4 | 0.5076 | 0.5184 |
| | 20 | 0.3621 | 0.5029 |
| 0.7 | 4 | 0.8256 | 0.8396 |
| | 20 | 0.8204 | 0.8622 |

当 $\rho=0$ 时，这两个分布的峰度系数 (4.25) 和 (4.26) 变为 $\{1+6\rho(1-\pi)\}/m\pi(1-\pi)+3$，这正是二项分布的峰度系数。对于退化情况 $\rho=1$，Beta-二项分布和随机聚集二项分布的峰度系数为 $1/{\pi(1-\pi)}$。为了对 Beta-二项分布和随机聚集二项分布的峰度进行有意义的比较，我们考虑 $\pi=0.5$ 的情况，此时两种分布都是对称的。也就是说偏度系数为零。对于 $\pi=0.5$，Beta-二项分布和随机聚集分布的峰度系数变为：

```
Kurtosis(Beta-binomial when $\pi=0.5$) = \frac{(3m-2)+\{3m(m-1)+2\}\rho^2}{m[1+(m-1)\rho^2]^2}$ (4.27)
```

以及

```
Kurtosis(Random-clumped when $\pi=0.5$) = \frac{(3m-2)+\{2(m-1)(3m-4)\rho^2+(m-1)(m-2)(m-4)\rho^4}{m[1+(m-1)\rho^2]^2}$ (4.28)
```

可以证明，对于 $\pi=0.5$，当 $\rho<1$ 时，随机聚集二项分布的峰度系数小于 Beta-二项分布。任何对称 Beta-二项分布的尾部都比对应的随机聚集二项分布尾部更厚。表 4.5 展示了 $\pi=0.5, \rho=0.2,0.7$ 且 $m=5,20$ 时峰度系数 (4.27) 和 (4.28) 的值。对于任何给定的 $\rho$ ($0<\rho<1$)，随着簇大小 $m$ 的增加，两种分布的峰度趋于相互发散。对于固定的 $m$，随着 $\rho$ 趋于 1，两种分布的峰度都会减小。

## **程序 4.3：** Beta-二项分布与随机聚集二项分布的概率函数图

```sas
/*
Plots of Probability Functions of
the Beta-binomial and Random-clumped Binomial Distributions
*/
%macro plots_bb_rcb(pi,rho,m);
data bb rcb;
format Distribution $14;
label Prob = "Probability";nlabel t = "Number of Successes (t)";
pi = &pi;
rho = &rho;
m = &m;
c = 1 - rho / (rho - 1);
p1 = 1 - pi;
pl1 = (1 - rho)*pi + rho;
lc1 = 1 - p1;
p2 = pi - rho;
c2 = 1 - p2;

do t=0 to m;
Z = exp(z + gamma(c) + gamma(t+c*pi) + gamma(m-t+c*pi));
Prob = gamma(m-c) - gamma(c*pi) - gamma(c*pi);
Distribution = 'Beta-binomial';
output;
Prob = exp(z) * (pi*p1**t*pl1**(m-t) + pi*p2**t*c2**(m-t));
Distribution = 'Random-clumped Binomial';
output;
end;
keep t Prob Distribution;
run;
title1 "Probability Functions Beta-binomial and Random-clumped Binomial Distributions";
ntitle2 "with Pi=&pi Rho=&rho and m=&m";
proc sgpanel data=bb rcb;
panelby / spacing=8;
var t / response=Prob group=Distribution;
run;
%mend plots_bb_rcb;
%plots_bb_rcb(0.3, 0.7, 20);
%plots_bb_rcb(0.5, 0.5, 20);
%plots_bb_rcb(0.5, 0.8, 20);
```
