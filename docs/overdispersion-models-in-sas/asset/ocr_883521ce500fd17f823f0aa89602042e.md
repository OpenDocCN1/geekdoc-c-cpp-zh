# 5.3 An Omnibus Goodness-of-fit Test

Note that the tests in Section 5.2 focus on testing for the presence of overdispersion against specific alternatives which model overdispersion. Tarcone (1979) and Dean (1992) described a variety of tests testing the “No overdispersion” null hypothesis against specific alternatives such as the Beta-binomial model. Paul and Placket (1978) and Collings and Margolin (1985) proposed similar types of tests for detecting, for instance, when the Negative-Shapiro-Wilk test of normality is an example of an omnibus test. In this section we will present tests for the model adequacy, which referred to as Omnibus tests.

Omnibus tests are designed to test if a specific distribution fits the data. The null hypothesis is that the data come from a population with a specific distribution, while the alternative hypothesis states that the data do not come from that distribution. Since there is no model specified in the alternative hypothesis, we obtain maximum likelihood estimates under the alternative. The other wellknown omnibus test is the Pearson Goodness-of-fit test. In the case of the chromosome element in 4.6 (see Table 4.3), the Pearson’s test given in Rao (1965, p. 391) and Cramer (1968, pp. 477-506) is applicable. However, when the m's are different, the construction of a Pearson’s Goodness-of-fit statistic is not straightforward because the observed expected frequencies are not associated with any value of m.
