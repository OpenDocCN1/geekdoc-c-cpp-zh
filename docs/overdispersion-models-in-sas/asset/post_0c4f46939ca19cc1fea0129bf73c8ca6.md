The quasi-likelihood estimate of $\beta$, say $\hat{\beta}$, is obtained by solving (3.3) with respect to $\beta$, that is,

```
U(\beta) = \frac{\hat{Q}(y, \mu)}{\hat{\beta}} = 0. (3.4)
```

The function $U(\beta)$ in (3.4) is the **quasi-score function**. By (3.2) equation (3.4) can be written as

```
\sum_{j=1}^n \frac{Y_j - \mu_j}{\sqrt{\phi(\mu_j)}} \frac{\hat{\mu}_j}{\hat{\beta}} = 0. (3.5)
```

The solution of (3.5) with respect to $\beta$ does not require knowledge of $\phi$ since $\phi$ is a scale parameter and cancels out. Therefore, these equations reduce to

```
\sum_{j=1}^n \frac{Y_j - \mu_j}{\sqrt{\phi(\mu_j)}} \frac{\hat{\mu}_j}{\hat{\beta}} = 0,
```

which are, from a computational point of view, if the $Y_j$'s belonged to one of the members of the exponential family for which $\phi=1$. As in the case with GLMs, the solution to (3.5) is equivalent to the iterative weighted-squares procedure in Section 2.6. With $\hat{\beta}$ in hand, a moment estimator of the dispersion parameter $\phi$ can be computed. Two commonly used estimates of $\phi$ are obtained by normalizing the Pearson $X^2$ or the Deviance, by dividing its degrees of freedom. Other moment estimators are possible.

Under mild regularity conditions, the asymptotic variance of the vector of estimates is given by

```
Var(\hat{\beta}) \equiv \phi(\mathbf{D}'\mathbf{V}^{-1}\mathbf{D})^{-1}. (3.6)
```

where $\mathbf{D}$ is the $n \times n$ matrix of first derivatives

```
\mathbf{D} = (\frac{\hat{\mu}_1}{\hat{\beta}}, \frac{\hat{\mu}_2}{\hat{\beta}}, \dots, \frac{\hat{\mu}_n}{\hat{\beta}})' \equiv (d_1, d_2, \dots, d_n)'
```

and $\mathbf{V}$ is the $n \times n$ diagonal matrix of variance functions

```
\mathbf{V} = \text{Diag}(v(\mu_1), v(\mu_2), \dots, v(\mu_n)) \equiv \text{Diag}(v_1, v_2, \dots, v_n).
```

Note that variance (3.6) can be written as

```
Var(\hat{\beta}) \equiv \phi \left(\sum_{j=1}^{n} d_j^{-1} d_j^{\top}\right)^{-1} (3.7)
```

For canonical links, equation (3.6) becomes

```
Var(\hat{\beta}) \equiv \phi(X^{\top}X)^{-1} (3.8)
```

## 3.3 An Oral Care Example

In order to illustrate the quasi-likelihood estimation procedure, consider the data in Table 3.1 taken from a clinical trial (Schulte et al., 1998) where $n=17$ subjects brushed their teeth for six consecutive weeks with experimental paste. The pH was measured at the end of the study at four sites of each subject's mouth ($m=4$). It is believed that if the pH $\le 6.5$, the subject is at higher risk of oral disease. Note that pH measurements are related to the brushing habits, toothpaste used, food consumption, and genetic characteristics of the subject. Therefore, it will be natural to assume positive correlation among sites in each subject and overdispersion.

Let $T_j, j=1,2,...,n$ denote the number of pH-depleted sites observed in each of the $n$ subjects. Let us consider the simple case where $T_j, j=1,2,...,n$ are uncorrelated and identically distributed random variables with overdispersion relative to the Binomial model. The mean and variance of $T_j$ are, respectively $\mu_j=m\pi$ and $\phi(\mu_j)=m\pi(1-\pi)$ with $\phi=\{1+\rho(m-1)\}$, where $\pi=Prob(pH \le 6.5)$ and $\rho$ is the intra-cluster correlation, which is assumed positive. For the parameter of interest $\pi$, the link function is the identity function. If the reader is estimating the log-odds, then the log link would be appropriate.

### Table 3.1: pH data from an Oral Care Study

| Number of mouth sites with pH $\le$ 6.5 | 0 | 1 | 2 | 3 | 4 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Number of subjects | 4 | 4 | 6 | 2 | 1 |

Let $t_j$ represent a realization of $T_j$. In this simple example, the solution to the quasi-likelihood score function (3.5) reduces to

```
$$\sum_{j=1}^{n} \frac{t_j - m\pi}{m\pi(1-\pi)} = 0.
```

The quasi-likelihood estimate of $\pi$ has, in this case, an explicit solution and is

$$\hat{\pi} = \frac{\sum_{j=1}^n t_j}{nm}$$

A moment estimator of $\phi$ can be obtained by computing the deviance by its degrees of freedom, that is,

$$\hat{\phi} = 2\sum_{j=1}^n \left\{ t_j \log\left(\frac{t_j}{m\hat{\pi}}\right) + (m-t_j)\log\left(\frac{m-t_j}{m-\hat{\pi}}\right) \right\}$$

Program 3.1 provides the programming statements for this example of performing the quasi-likelihood estimation using the GENMOD procedure. Note that the cluster size is $m=4$ and we are creating a string of $n=17$, '$t_j$' to make the analysis consistent with the notations used for $\hat{\pi}$ and $\phi$.

### Program 3.1: Quasi-likelihood Analysis for pH Data of Table 3.1

```sas
/*
Oral Care Example from Schulte et al., 1998
*/
data pH;
  input t f;
  m = 4;
  do i=1 to f;
    output;
  end;
  drop i;
  datalines;
0 4
1 4
2 6
3 2
4 1;
ods html close;
proc genmod data=pH;
  model t/m = binomial link=identity scale=deviance;
run;
```

The output produced by the GENMOD procedure is given next in Output 3.1. We only provide the selected portions of the output relevant to the discussion in the example. The GENMOD procedure for binomial models returns $\sqrt{\phi}$ rather than $\phi$. In this example, the estimates of $\pi$ and $\phi$ were $0.3824$ and $1.8878$, respectively. The value $1.8878$ is, in the output, the Deviance over its degrees of freedom. A moment estimator of the intra-cluster correlation $\rho^2$ can be obtained by solving the equation $\phi=\{1+\rho(m-1)$. This yields $\rho^2 =0.30$. Note that this procedure can be done here there are no covariates and all clusters are of the same size. In general, it might be possible to recover $\rho^2$ from $\phi$. Given the estimated standard error of $\hat{\pi}$ is $0.0810$, an approximate 95% confidence interval for $\pi$ is given by $(0.22, 0.54)$. The naive error, in the sense of assuming the Binomial model, is $0.0810/1.3740=0.0589$ (this is not reported in the output). This estimate leads to a narrower confidence with coverage probability below the nominal one. Prior to running the study, a baseline rate (proportion of sites with pH $\le 6.5$) was established; it was reported as $71\%$. Therefore, we can conclude that experimental toothpaste was efficacious in reducing the proportion of mouth sites at higher risk for oral disease.

Since the data are in a summary form (Table 3.1), the previous analysis can also be performed using a frequency statement, as provided next:

```sas
/*
pH Oral Care Example from Schulte et al., 1998
*/
data pH;

  m = 4;
  datalines;
0 4
1 4

3 2

  model t/m = binomial link=identity scale=deviance;
  freq f;
run;
```
