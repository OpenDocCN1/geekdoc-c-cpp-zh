# 4.8 Generalized Linear Overdispersion Models for Binomial Responses

In this chapter, we have considered overdispersion models with a common probability of success $\pi$ and a common overdispersion parameter $ho$. Analogous to the Binomial distribution, we introduce link functions to model the probability of success $\pi$. In addition to the parameter, we also have the overdispersion parameter $ho$, which potentially can be different from cluster to cluster. We will have two link functions: one for the probability of success and one for the overdispersion parameter. This class of models will be referred as **Generalized Linear Overdispersion Models (GLOM)**. They combine the modeling features of GLM with the distributional features of the overdispersed models presented here. Cluster-specific covariates can be used on both link functions. For example, on a study with two treatments, a treatment indicator variable can be used to fit a model that allows for different probabilities of success and different degrees of overdispersion. An illustrative example will be given in section 4.9.
