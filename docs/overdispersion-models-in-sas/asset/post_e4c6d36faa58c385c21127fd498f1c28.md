Given a vector of probabilities p, p=p(1),p(2),...p(d)
this module computes the inverse of the matrix C(p), say
A(p)*C(p)' = Diag(p) - p*p'
where C(p) is obtained using Cholesky decomposition.

The matrix A(i,j) is given by

```
A(i,j) = { q(i-1) / ( p(i) * q(i) ) * 0.5 if i=j
          = p(i) / ( q(i-1) * q(i) ) * 0.5 if i>j
          = 0 if i<j
```

See: Tanabe and Sagae (1992)

```
start_inv_cp(p,a,d);
q = q(1) // {1 - cumsum(p));
 i=1 to d;
  do il=i+1;
    a[i,il] = sqrt(q[i]) / p[i] / q[il,1]);
    if d > 1 then do;
      do j=1 to i-1;
        a[i,j] = sqrt(p[i]) / q[i] / q[il,1]);
      end;
    end;
  end;
finish_inv_cp;
```

For the Cadmium-Zinc example, which consists of trinomial responses, i.e., d=2, the variance-covariance matrix in equation (20) turns out to be (for simplicity we remove the subscript "j

$Var(T) = m \begin{pmatrix} \phi_1(1-\pi_1) & -\phi_1(1-\pi_1) \\ -\phi_1(1-\pi_1) & \phi_1\pi_1^2(1-\pi_1)^{-1} + \phi_2\pi_2^2(1-\pi_2)^{-1} \end{pmatrix}, \quad (7.26)$

which has an intuitive interpretation in terms of the variability among the components of the Multinomial vector T. The variance of the first component $T_1$ is adjusted by the factor $\phi_1$. Writing the second element of $T$

$T_2 = \hat{T}_2 + T_{2,1},$

where $\hat{T}_2$ is the regression of $T_2$ on $T_1$, and $T_{2,1}$ is the corresponding residual, the variance of $T_2$ is seen as the sum of the variances of two orthogonal pieces $\hat{T}_2$ and $T_{2,1}$. The first component $\hat{T}_2$, representing the variance of $T_2$ explained by $T_1$, is adjusted by $\phi_1$. The second component $T_{2,1}$ corresponding to the variance of the portion of $T_2$ that is not explained by $T_1$, is adjusted by $\phi_2$. Morel (1999) extended this interpretation to higher dimensions and provided a straightforward algebraic representation of $T_{(2)}$. For the case $d=3$, the upper-left $2\times2$ submatrix of $Var(T)$ in (7.20) is as follows. Its last column is

$m \begin{pmatrix} -\phi_1,\pi_1,\pi_3 \\ \phi_1\pi_1\pi_2(1-\pi_1)^{-1}-\phi_2\pi_2\pi_3(1-\pi_1)^{-1} \\ \phi_1\pi_3^2(1-\pi_1)^{-1}+\phi_2\pi_2^2[(1-\pi_1)^{-1}]+\phi_3\pi_3(1-\pi_3)(1-\pi_2)^{-1} \end{pmatrix}$

The transpose of this 3-dimensional column vector is the last row of $Var(T)$. Recall that $\Phi$ is estimated in (7.25).

There is more than one convenience to use $C(\pi_j)$ in (7.20). A singular value decomposition of $\Delta(\pi_j)$ yields $C(\pi_j) = \mathbf{E}_A\Lambda^{1/2}$, where the columns of $\mathbf{E}_A$ are eigenvectors of $\Delta(\lambda_1^{1/2}, \lambda_2^{1/2},...,lambda_d^{1/2})$ which are the corresponding eigenvalues, and $\Lambda^{1/2} = \text{Diag}(\lambda_1^{1/2}, \lambda_2^{1/2},...,lambda_d^{1/2})$. In the special case $\Phi$ is a diagonal matrix with elements $\phi_1,\phi_2,...,\phi_d$, using $C(\pi_j) =$

```
$\text{Var}(T) = m\sum_{i=1}^d \phi_i\lambda_i\mathbf{e}_i\mathbf{e}_i^T, \quad (7.27)$
```

where $\mathbf{e}_i$ represents the $i$-th column of $\mathbf{E}$, and the diagonal elements of $\Phi$ can be interpreted as inflating (or deflating) different components of variation.

# 7.7 The Dirichlet-multinomial Distribution

Let $\mathbf T^* = (T_1,T_2,...,T_{d+1})$ denote a $(d+1)$-dimensional multinomial-type vector of counts, whose $i$-th component represents the number of elements classified into the $i$-th category. Let $\mathbf T T$ represent the vector $\mathbf T T$ without the last category, $\mathbf T = (T_1,T_2,...,T_d)$. Recall is no loss of information using $\mathbf T T$ since $\sum_{i=1}^d T_i = m$ and thus the last category of $\mathbf T$ is uniquely determined

as $T_{d+1} = m-\sum_{i=1}^d T_i$. The vector $T$, which is usually modeled by a Multinomial distribution (as discussed in Sections 7.2 through 7.4), may exhibit high variability in the data than allowed by the Multinomial model.
