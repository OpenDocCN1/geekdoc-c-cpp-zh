We will now describe a methodology for testing for the assumption of proportionality (parallel of logistic) in the Proportional-Odds Model. The following model, which allows the regression coefficients of the covariates to depend on the response category, is a suitable model for testing the assumption of proportionality of odds.

```
$$\ln\left(\frac{\pi_1}{\pi_2+\pi_3}\right) = \alpha_1+\beta_1Z_2+\beta_2C_2+\beta_3C_3+\beta_4Z_2+\beta_5Z_2+\beta_6Z_2,\n\ln\left(\frac{\pi_1+\pi_2}{\pi_3}\right) = \alpha_2+\beta_1Z_2+\beta_2C_2+\beta_3C_2+\beta_4Z_2+\beta_5Z_2+\beta_6Z_2,\quad (7.35)$
```

Under either the Dirichlet-multinomial or Random-cluster Multinomial model and under link function (7.35), the parameter vector is the 13-dimension column vector

```
$$\theta = (\alpha_1,\alpha_2,\beta_{11},\beta_{21},\beta_{22},\beta_{13},\beta_{23},\beta_{14},\beta_{24},\beta_{25},\rho)^T.$
```
