# 2.6 Maximum Likelihood Estimation for Generalized Linear Models

Let $y_j$ represent a realization of the random variable $Y_j$, $j=1,2,...,n$, $Y_j$ from a given distribution in the exponential family. We are interested in finding the MLE of $eta$. For certain distributions, in the Binomial and Poisson distributions, $\phi$ is known to be over. In later chapters, maximum likelihood estimators will be obtained for both the vector of parameters $eta$ and the dispersion (or overdispersion) parameter. Thus, from Section 1.6 we have have that the log-likelihood function is

```
$L(\beta, \phi; \mathbf{y}) = \sum_{j=1}^n \left\{ \frac{y_j - b(\theta_j)}{\phi} + c(y_j, f(\phi)) \right\}$
```

Here $y$ represents the vector of observers $\mathbf{y} = (y_1, y_2, ..., y_n)$.

We will now consider the MLE of $eta$ when $\phi$ is either fixed or known. The k-dimensional column vector of first derivatives of (2.15) with respect to $eta$ is the gradient or score vector. That

```
$\mathbf{u}(eta) = \frac{\partial L(\beta, \phi; \mathbf{y})}{\partial \beta}$
```

Technically, each term in (2.15) is a function of the canonical parameter $	heta_j$, and $	heta_j$ of the mean $\mu_j$, and $\mu_j$ a function of the linear predictor $\eta_j$, and $\eta_j = \mathbf{x}\beta$. Thus, obtaining the gradient (2.16) requires the chain rule. For further details, we refer the reader to Chapter 2 in Hilbe (2007).

The $k \times k$ matrix of second derivatives of (2.15) is the Hessian, given by

```
$\mathbf{H}(eta) = \frac{\partial^2 L(\beta, \phi; \mathbf{y})}{\partial \beta \partial \beta}$
```

The Fisher information matrix (FIM) is negative of the expected value of the Hessian. That is,

```
$\mathbf{I}(\beta) = -E \left[ \frac{\partial^2 L(\beta, \phi; \mathbf{y})}{\partial \beta \partial \beta^1} \right] = E \left[ \frac{\partial L(\beta, \phi; \mathbf{y})}{\partial \beta^1} \frac{\partial L(\beta, \phi; \mathbf{y})}{\partial \beta^1} \right]$
```
