# 7.8 The Random-clumped Multinomial Distribution

The second over-dispersed Multinomial model we will consider here was proposed by Morel and Nagaraj (1993) and Neerchal and Morel (1998). It is a multivariate generalization of the Random-clumped Multinomial distribution covered in Section 4.3. This model can be derived as follows.

Let $Y, Y_1^0, \dots, Y_m^0$ be independent and identically distributed Multinomial random variables with parameters $(\boldsymbol{\pi}; 1)$. The $(d+1)$ category has already been removed from all these Multinomial random vectors. Let $U_1, U_2, \dots, U_m$ be independent and identically distributed Uniform(0,1) random variables, and $\rho$ be any random variable, $0 < \rho < 1$. As in Section 4.3, define

```
$Y_i = Y_i^0(U_i \le \rho) + Y_i^0(U_i > \rho), \quad i=1,2,\dots,m$$
```

where $I(.)$ denotes an indicator function.

Now consider the random variable

```
$\mathbf{T} = \sum_{i=1}^m Y_i$$
```

The mean and covariance matrix of $\mathbf{T}$ are as in equations (7.28) and (7.29). As the univariate version of the Random-clumped Binomial distribution in Chapter 4, the random vector $\mathbf{T}$ can be represented as

```
$$\mathbf{T} = (\mathbf{YN}) + (\mathbf{X|N}), \quad \quad (7.32)$
```

where $N \sim \text{Binomial}(\rho; m)$ and $(\mathbf{X|N}) \sim \text{Multinomial}((1-\rho)\boldsymbolpi; m)$ if $N < m$. The interpretation of the clustering mechanism of the Random-clumped Multinomial $T$ has been discussed in Section 4.3. Sutrachdar (2001) provides graphical representation of several scenarios depicting the cluster mechanism for multinomial responses.

It can be shown that the probability function of the random vector (7.32) is given by

```
$P_{\text{RCM}}(\mathbf{T}=\mathbf{t}) = \sum_{i=1}^{d+1} \pi_i \rho P(\mathbf{X}_i=t_i),$$ \quad \quad (7.33)$
```

where $\mathbf{X}$ is distributed as Multinomial($(1-\rho)\boldsymbolpi; m)$ for $i=1,2,\dots,d$, and $\mathbfmathbf{X}_i$ is distributed as Multinomial($(1-\rho)\pi; m$). Here $\mathbf{e}_i$ is the $i$-th column of a $d \times d$ identity matrix. Unlike the DM, the properties of the RCM distribution are less tractable. Similar to the DM, the marginals of the RCM distribution are also distributed as Random-clumped Binomials. Explicit expressions for its moments up to four order are given in Newcomer (2008). As the reader will see in the following chapters, Maximum Likelihood Estimation under this distribution is facilitated by making use of its properties.
