We proceed to make visual assessments of the probability functions. Program 4.3 provides the programming statements for generating the probability functions of the Beta-binomial and Random-clumped Binomial distributions for a given \pi, \rho and m.

# **Program 4.3:** Plots of Probability Functions of the Beta-binomial and Random-clumped Binomial Distributions

```
/*
Plots of Probability Functions of
t Beta-binomial and Random-clumped Binomial Distributions
*/
%macro plots_bb_rcb(pi,rho,m);
data bb rcb;
format Distribution $14;
label Prob = "Probability";nlabel t = "Number of Successes (t)";
pi = &pi;
rho = &rho;
m = &m;
c = 1 - rho / rho - 1;
p1 = 1 - pi;
pl1 = (1 - rho)*pi + rho;
lc1 = 1 - p1;
p2 = pi - rho;
c2 = 1 - p2;

do t=0 to m;
Z = exp(z + gamma(c) + gamma(t+c*pi) + gamma(m-t+c*pi))
Prob = gamma(m-c) - gamma(c*pi) - gamma(c*pi);
Distribution = 'Beta-binomial';
output;
Prob = exp(z) * (pi*p1**t*plc**(m-t) + pic*p2**t*pc2**(m-t));
Distribution = 'Random-clumped Binomial';
output;
end;
keep t Prob Distribution;
run;
title1 "Probability Functions Beta-binomial and Random-clumped Binomial Distributions";
ntitle2 "with Pi=&pi Rho=&rho and m=&m";
proc sgpanel data=bb rcb;
```
