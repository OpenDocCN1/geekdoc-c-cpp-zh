# Chapter 3 Quasi-likelihood Functions 55

The quasi-likelihood estimate of $\pi$ has, in this case, an explicit solution and is

$$\hat{\pi} = \frac{\sum_{j=1}^n t_j}{nm}$$

A moment estimator of $\phi$ can be obtained by computing the deviance by its degrees of freedom, that is,

$$\hat{\phi} = 2\sum_{j=1}^n \left\{ t_j \log\left(\frac{t_j}{m\hat{\pi}}\right) + (m-t_j)\log\left(\frac{m-t_j}{m-\hat{\pi}}\right) \right\}$

Program 3.1 provides the programming statements for this example of performing the quasi-likelihood estimation using the GENMOD procedure. Note that the cluster size is $m=4$ and we are creating a string of $n=17$, '$t_j$' to make the analysis consistent with the notations used for $\hat{\pi}$ and $\phi$.

# Program 3.1: Quasi-likelihood Analysis for the pH Data of Table 3.1

```
/*
Oral Care Example from Schulte et al., 1998
*/
data pH;
  input t f;
  m = 4;
  do i=1 to f;
    output;
end;
  drop i;
datalines;
0 4
1 4
2 6
3 2
4 1

;ods html close;
proc genmod data=pH;
  model t/m = / dist binomial link=identity scale=deviance;
run;
```
