Let $t_{ij}$ be the number of "favorable" responses out of $m_{ij}$ Bernoulli responses,
s$s=1,2, i=1,2, j=1,2,\dots,n,$ $t_{ij} = \sum_{k=1}^{m_{ij}} y_{sik}$. We consider the following Beta-binomial
GLOM subjects, given to the cross-over design, are treated as random,

> $$\begin{aligned} t_{ij} \text{ given } (x_{ij}, u_{ij}) \ &\sim \text{Beta-binomial}(\pi_i, \rho, m_{ij}), \ \text{logit}(\pi_i) &= \beta_0 + \beta_1x_{ij} + u_{ij} \end{aligned} \$ (10.15)

where $u_{ij}$ are independent and identically distributed Normal($0, \sigma^2$), and

+   $x_{ij} = \begin{cases} 1 & \text{if subject is in group 1} \ 0 & \text{otherwise} \end{cases}$

For each sequence $s=1,2$, and for each test product (treatment) $i=1,2$, and $n=200$, $t_{ij}$
responses were generated using the GLOM in equation (10.15) with $\pi_1=0.12$,\$\pi_2=0.08, \rho^2=0.15, \sigma=12$ and $m_{ij}=20$. The programming statements for generating and
analyzing data under such GLOM were provided in Program 10.4. We first get initial estimates
of the beta parameters using a Logistic GLMM where subjects are
t as random. GLIMMIX will treat each $t_{ij}$ as a truly Binomial outcome. The Beta-binomial GLOM is then
fit by means of initial values defined by a grid based on
