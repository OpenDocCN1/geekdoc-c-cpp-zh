We now turn to the Pseudo-likelihood (PL) method available in the GLIMMIX procedure. The PL method linearizes the model, and the scale parameter $\phi$ turns into a residual scale parameter in a weighted Normal mixed model. One advantage of the PL method over the Quasi-likelihood method is that it provides a standard error for $\phi$. This would be useful for assessing the presence of overdispersion. We illustrate the computation of the PL method using the programming statements in Program 3.3.

# Program 3.3: Fitting Pseudo-likelihood (PL) Logistic Regression Model to Toxoplasmosis Data

```
data toxoplasmosis;
  set toxoplasmosis;
  city = _n_;
run;
ods html;
proc glimmix data=toxoplasmosis;
  class city;
  model t/m = z*z*z / s;
  random _residual_ / subject=city;
run;
html close;
```

The results from running Program 3.3 are shown in Output 3.3. Note that the estimates and their standard error are the same as in Output 3.2, where we ran a Quasi-likelihood analysis. Note that the PL output provides $\phi=1.9404$ with an estimated standard error of 0.5010. Since the estimate $\phi$ is more than twice the standard error, we might conclude there is overdispersion.

The standard errors of the beta estimates under PL reflect the inflation by $\sqrt{\phi}$. Later on, we will discuss simultaneous variance adjustments. Morel, Jorge, and Nagaraj. Overdispersion Models in SAS.

# 3.5 A Carcinogenesis Pre-clinical Experiment

The aim of this example is to provide a simple application of an overdispersed Poisson model. Similar to Binomial models, overdispersed Poisson models are used to accommodate higher variability in the data permitted by the Poisson model. In a clinical experiment analyzed by Gail (1980) and by Lawless (1987), a total of 76 female rats were injected with a carcinogen for mammary cancer. Then, all animals were given Retinol Acetate to prevent mammary cancer for 60 days. After this phase, the 48 animals that remained tumor-free were randomly assigned to continue the Retinoid prophylaxis (n=23) or Control (n=25). The main objective of analysis was to assess the difference in the development of tumors between the Retinoid and Control groups. The times of occurrences to mammary tumors as well as the number of tumors during the 182-day phase can be found in Gail et al. (1980). Table 3.4 contains only the number of tumors of the 48 rats.
