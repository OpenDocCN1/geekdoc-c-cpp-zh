# 4.4 A Zero-inflated Binomial Distribution

Cohen (1966) proposed a class of mixed distributions having a probability function of the form

```
g(x;\omega,\lambda_1,\lambda_2,...,\lambda_k) = \frac{(1-\omega) + \omega f(0), x=0}{\\omega f(x;\lambda_1,\lambda_2,...,\lambda_k), x=1,2,...} (4.12)
```

where $0\le \omega\le 1$ and $f(x;\lambda_1,\lambda_2,...,\lambda_k)$ may be any discrete distribution defined over the domain $x=0,1,2,...$ with parameters $(\lambda_1,\lambda_2,...,\lambda_k)$. This distribution is useful when there is an excess of zeros, as in studies where experimental units are subjected to very low exposure. By proposing distribution (4.12), Cohen generalized the Zero-inflated Poisson distribution (Cohen, 1960) to essentially affect any discrete distribution with domain $x=0,1,2,...$. In his 1966 paper, Cohen discussed the Zero-inflated Negative-binomial. These two distributions, the Zero-inflated Poisson and the Zero-inflated Negative-binomial, will be discussed in Chapter 6. The particular case where the underlying discrete distribution is Binomial(P;m) in particular, reduces to the case Zero-inflated Binomial (ZIB) distribution with probability function

```
Pr(T=t) = \omega \binom{m}{t} P^t(1-P)^{m-t} + (1-\omega)I(t), t=0,1,...,m (4.13)
```

where $I(\cdot)$ is an indicator function. Note that distribution (4.13) is a mixture of two distributions, namely, a Binomial(P;m) with probability $P=\pi+\theta(1-\pi)$ and a degenerate distribution at zero with probability $1-\\omega$. Under parameter $P=\pi+\theta(1-\pi)$, distribution (4.13) can be written as

```
Pr(T=t) = \frac{\pi}{\pi+(1-\pi)}Pr(X=t) + \frac{\theta(1-\pi)}{\pi+\theta(1-\\pi)}I(t), t=0,1,...,m (4.14)
```

where $X \sim Binomial{\pi+\theta(1-\\pi);m\}$. When $\theta=0$, equation (4.14) reduces to Binomial($\pi;m$) distribution. On the other hand, the case $\theta=1$ provides a Zero-degenerated distribution. If $T$ has probability function as in (4.14), $T$ will be to be distributed as a Zero-inflated binomial distribution ZIB. It can be shown that the first two moments of distribution (4.14) are

```
E(T) = m\pi$ (4.15)
```

and

```
Var(T) = m\pi(1-\pi)\1+\theta(m-1)\\}$ (4.16)
```
