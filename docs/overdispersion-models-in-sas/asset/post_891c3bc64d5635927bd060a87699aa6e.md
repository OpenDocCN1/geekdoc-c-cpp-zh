The vector $\beta$ represents the parameters of the fixed part of the model. The parameters associated to the random part of the model are represented by the unknown vector $\gamma$. Similarly, $Z$ contains continuous or dummy variables, just as $X$. It is assumed that the random vector $\gamma$ and $\epsilon$ are jointly independent and normally distributed with

$$E \begin{pmatrix} \gamma \\ \epsilon \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \end{pmatrix}$$

$$Var(\begin{pmatrix} \gamma \\ \epsilon \end{pmatrix}) = \begin{pmatrix} G & 0 \\ 0 & R \end{pmatrix}$$

We want to warn the reader that since the observation vector consists of multivariate response vectors from all elements, the structure of the matrices $G$ and $R$ can be quite complex. Conditionally, given $\gamma$, expected value and variance-covariance of the observation vector are

$$E(y|\gamma) = X\beta + Z\gamma$$
$$Var(y|\gamma) = R$$

Note that in principle, we can derive the marginal distribution of the observed data starting from the distribution of $\gamma$ and $\epsilon$. The unconditional (or marginal) expected value and variance of the observation vector are given

$$E(y) = X\beta$$
$$Var(y) = ZGZ' + R$$

Models may also be thought of as G-side random effects or R-side random effects. Note that the right-hand side of the equation (10.5) contains two different (independent) random quantities, $\gamma$ and $\epsilon$. While $\gamma$ is used to capture the conditional mean to capture the subject-effect, $\epsilon$ represents the residual effect. Including $\gamma$ with an appropriate design matrix $Z$ is referred to as a G-side random effect. It is also possible to specify the variance-covariance matrix of $\epsilon$ directly to capture the within-subject correlation structure. This approach is referred to as R-side random effects. Note that models with only G-side random effects are conditional; they are also SS models. On the other hand, models containing only R-side effects are marginal and PA models. The next step in describing a GLMM is now clear. GLMM is obtained by including random effects in the linear predictor we subscript the random effects by "j" so that they act the same on all elemental units within the cluster. Note that $\gamma_j$ is still vector of appropriate dimension to accommodate possibly different random effects for the beta-parameters. The model equation for the Generalized Linear Mixed Model then becomes

$$\mu_{ji} = \mathbf{E}(\mathbf{y}_{ji}) = \mathbf{g}^{-1}(\boldsymbol{\beta}, \mathbf{x}_{ji}, \gamma_j) \left( \begin{array}{c} \mathbf{g}_j^{-1}(\mathbf{x}_{ji} + \mathbf{z}_{ji}\gamma_j) \\ \vdots \\ \mathbf{g}_d^{-1}(\mathbf{x}_{ji}\boldsymbol{\beta} + \mathbf{z}_{ji}\gamma_j) \end{array} \right)$$

where $\mathbf{z}_{ji}$ are usually variables and $\gamma = (\gamma_1', \gamma_2', ..., \gamma_n')^T$ is assumed to be a zero-mean multivariate Normal random vector. We can re-write the model equations for the mean more succinctly as

$$\left[ \mathbf{E}(\mathbf{y}|\gamma) \right] = \mathbf{g}(\gamma) = \mathbf{X}\boldsymbol{\beta} + \mathbf{Z}\gamma$$
$$\left[ \mathbf{Var}(\mathbf{y}|\gamma) = \mathbf{V}(\mu, \alpha) \right] = \mathbf{V}\left[ \mathbf{X}\boldsymbol{\beta} + \mathbf{Z}\gamma \right] \right]$$

so that we can see the correspondence between LMM and GLMM. The unconditional mean can be obtained by integrating the random effects out. This can be symbolically represented as

$$\mu_{ji} = \int \mathbf{g}_j^{-1}(\mathbf{x}_{ji}\boldsymbol{\beta} + \mathbf{z}_{ji}\gamma_j) d\mathcal{F}(\gamma_j).$$
