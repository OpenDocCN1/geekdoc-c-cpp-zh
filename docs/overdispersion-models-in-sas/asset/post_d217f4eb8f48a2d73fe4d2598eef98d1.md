Under the Binomial model several SAS procedures can provide the MLE of $\pi$, which turns out to be the ratio estimator $\hat{\pi} = \sum_{j=1}^{n} \frac{t_j}{m_j}$. For this example, we make use of the SURVEYMEANS procedure to compute $\hat{\pi}$.
```sas
data Ratio;
  set Ratio;
  call symput('Pi',trim(left(Ratio)));
run;
data out1;
  set kupper_haseman;
  pi = &Pi;
  pic = 1 - pi;
  pipic = pi * pic;
  mpi = m * pi;
  t_mpi = t - mpi;
  pit_mpi = pi * t_mpi;
  tpic = t * pic;
  mm_1 = m * (m-1);
  aux = (t_mpi*t_mpi + pit_mpi - tpic) / pipic;
  keep aux mm_1;
run;
proc means data=out1 sum noprint;
  var aux mm_1;
  output out=out2 sum=mm_1;
run;
data out2;
  set out2;
  label X2 = "GOF Test";
  label PVal = "P-Value";
  format X2 = au8.2 Pval pvalue.6;
  x2 = aux / sqrt(2*mm_1);
  x2 = x2 * x2;
  pval = 1 - probchi(x2,1,0);
run;
ods html;
title Tarone (1979) GOF Test;
proc print data=out2 noobs label;
  var x2 pval;
run;
html close;
```

Dean (1992) provides a methodology for obtaining tests for overdispersion with respect to a natural exponential. Several tests for extra-Binomial and extra-Poisson variance, similar to Tarone's test, can be obtained as special cases of Dean's methodology. We illustrate Dean's methodology using the log model discussed in Section 4.8 of Chapter 4. As before, let the probability of success $\pi_j, j=1,2,...,n$ depend on a k-dimensional row vector of covariates $x_j$ and a k-dimensional column vector of unknown parameters $\beta$, via the logit link

$$\ln\left(\frac{\pi_j}{1-\pi_j}\right)=x_j\beta=\sum_{i=1}^k x_{ji}\beta_i$$

Dean (1992) derived a score statistic for testing “$\tau=0$” when the first two moments of the form

$$E(T_j) = m_j\pi_j, \text{ and } Var(T_j) = m_j\pi_j(1-\pi_j)\{1+\tau(m_j-1)\}$$

Dean's score statistic turned out to be

$$Z = \frac{\sum_{j=1}^n (t_j-m_j\hat{\pi}_j)^2 + \hat{\pi}_j^2(t_j-m_j\hat{\pi}_j)-t_j(1-\hat{\pi}_j)\hat{\pi}_j(1-\hat{\pi}_j)}{\sqrt{2\sum_{j=1}^n m_j(m_j-1)}} (5.3)$$

Note that this score statistic (5.3) becomes when $\tau=0$. Dean (1992) points out that the use of score statistic (5.3) is appropriate for arbitrary alternatives with the first two moments indicated above. As noted earlier, the Beta-binomial and Random Binomial distributions are based on positively correlated Bernoullis with the above structure structure

To illustrate the use of score statistic (5.3) we revisit the Efron (1986) example from n=34 cities in El Salvador. The data are reported in Table 3.2. Recall that the outcome “number of cases testing for toxicity ($t_j$) out of the number of subjects sampled ($m_j$)” was analyzed as a function of the linear, quadratic, and cubic terms shown in Program 5.2. We will skip the data statements since they are the same as in Program 3.2.

### Program 5.2: Computation of Dean (1992) GOF Score Statistic for the Toxicity Example of Table 3.2

```sas
/*
Score Statistic, Dean (1992)
H0:Binomial Distribution Versus
H1:Beta-binomial or similar distribution such as
Random Binomial as far as Bernoulli outcomes are positively correlated

Toxicity in 34 cities of El Salvador
Example from Efron (1986)
*/
ods select none;
proc glimmix data=toxosis;
  model t/m = z*z / link=logit dist=bin;
  output out=data pred(pi) = pi;
run;
ods select all;
data pdata;
  set pdata;
  pic = 1 - pi;
  pipic = pi * pic;
  mpi = m * pi;
  t_mpi = t - mpi;
  pit_mpi = pi * t_mpi;
  tpic = t * pic;
  mm_l = m *(t-1);
  aux = (t*t_mpi + pit_mpi - tpic) / pipic;
  keep aux mm_l;
run;
proc means data=pdata sum noprint;
  var aux mm_l;
  output out=new sum=mm_l;
run;
data new;
  set new;
  label Z = "GOF Test";
  label Pval = "P-Value";
  format z = aux / sqrt(mm_l) .6f;
  pval = 1 - probnorm(z);
run;
ods title;
title="Score Statistic, Dean (1992)";
proc print data=new noobs label;
varvar pval;
run;
ods html close;
```

The results of the GOF test score statistic (5.3) for the toxicity data are shown below. There is strong evidence of overdispersion when the Binomial model is tested against any alternative where the Bernoulli outcomes are positively correlated within cities.

|---|---|---|

## 5.3 An Omnibus Goodness-of-fit Test

Note that the tests in Section 5.2 focus on the presence of overdispersion against specific alternatives which model overdispersion. Tarone (1979) and Dean (1992) described a variety of tests testing the “No overdispersion” null hypothesis against specific alternatives such as the Beta-binomial model. Paul and Slack (1978) and Collins and Margolin (1985) proposed similar types of tests for detecting, for instance, when the Negative-Shapiro-Wilk test of normality is an example of an omnibus test. In this section we will present tests for the model adequacy, which referred to as Omnibus tests.

Omnibus tests are designed to test if a specific distribution fits the data. The null hypothesis is that the data come from a population with a specific distribution, while the alternative hypothesis states that the data do not come from that distribution. Since there is no model specified in the alternative hypothesis, we obtain maximum likelihood estimates under the alternative. The other well-known omnibus test is the Pearson Goodness-of-fit test. In the case of the element in 4.6 (see Table 4.3), the Pearson’s test given in Rao (1965, p. 391) and Cramer (1968, pp. 477-506) is applicable. However, when the m's are different, the construction of a Pearson’s Goodness-of-fit statistic is not straightforward because the observed expected frequencies are not associated with any value of m. Meer and Morel (1998) proposed an extension of the traditional Pearson’s Chi-square statistic

$$X^2 = \sum (O_i - E_i)^2 / E_i,$$

when the cluster size m is allowed to be different. Asymptotic properties of this test have been investigated by Sutradhar et al. (2008).

Let $t_1, t_2, ..., t_n$ represent $n$ independent random variables $T_1, T_2, ..., T_n$, when these variables are allowed to have overdispersion relative to the Binomial distribution, i.e., the first two moments are as in equations (4.4) and (4.5). It is hypothesized that each $T_i$ has a certain probability function depending on the parameters $\pi$, $\rho$ and the cluster size $m_j$, where the m's are allowed to be distinct. One way of extending the traditional Pearson’s test is by pooling the data across all clusters and comparing the observed distribution of $t_j/m_j$ to the corresponding expected frequencies.
