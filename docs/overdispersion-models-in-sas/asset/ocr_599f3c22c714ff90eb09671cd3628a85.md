# 3.2 Quasi-likelihood functions

There are several approaches for modeling data exhibiting overdispersion. A widely used method is the one known as Quasi-likelihood. A quasi-likelihood function is defined without the knowledge of the likelihood function but the relation between the mean and the variance of each observation for which the quasi-likelihood function is being constructed. It can be seen that for a typical member of the exponential family, the first derivative of the log-likelihood function with respect to the mean and variance of the distribution. Quasi-likelihood function is specified in terms of its derivatives conforming to structure which is specified by the overdispersion model. Parameter estimates are obtained by solving the score function, the most iteratively by methods such as Newton-Raphson. We will see other estimation methods available in the GLIMMIX procedure. Cox and Snell (1989) pointed out that Quasi-likelihood estimation is used when the interest is on regression likelihood model where overdispersion occurs by inflation or deflation of variance by a constant factor. It can be viewed as a two-step procedure: first, estimate the systematic structure of the model then inflate deflate the variances by a suitable constant. It is interesting to note that for a one-parameter exponential family, the log likelihood is the same as the quasi-likelihood.

Let $Y_j, j=1,...,n$ be independent random variables such that $E(Y_j) = \mu_j$ and $V(Y_j) = \phi v(\mu_j)$, where $\phi$ may be unknown and $v(\mu_j)$ is a known function of $\mu_j$. As with GLMs, the mean $\mu_j$ depends on a k-dimensional row of covariates $x_j$ and a k-dimensional vector of parameters $eta$, through a twice differentiable smooth function $g(\mu_j)$ so that

```
$g(\mu_j) = \mathbf{x}_j\beta = \sum_{i=1}^{k} x_{ji}\beta_i.$
```

The function $g(\cdot)$, is the link function. Define $Q(Y_j, \mu_j)$ as

```
$$\frac{\partial Q(Y_j,\mu_j)}{\partial \mu_j} = \frac{Y_j - \mu_j}{\phi v(\mu_j)}$
```

Note that in (3.2), $Q(y,\mu)$ is such that its first derivative resembles the log-likelihood function of distributions in the exponential family. $Q(y,\mu) = \int^{\frac{y-t}{\phi v(t)}}_{\mu} t dt + C$. The quantity

```
$Q(\mu) = \sum_{j=1}^{n} Q(Y_j,\mu_j).$
```
