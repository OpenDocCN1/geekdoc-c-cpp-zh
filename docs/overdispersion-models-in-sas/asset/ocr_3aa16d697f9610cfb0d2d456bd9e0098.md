```
title "Full Model With SCALE=WILLIAMS";
run;
proc mean data=out1;
    class type_seed root_extract;
    var pi_hat;

ods html close;
```

We specified the SCALE=WILLIAMS option on the full factorial model, which is described above in Steps 1 through 4. Also, we output the predicted probabilities from Williams' model. Since there are four different predicted probabilities, one for each combination of the levels of the two factors, we printed them by computing the combinations of the levels of the two factors, rather than printing 21 predicted values from the data set "out1." The results are provided in Output 3.6.
