# 338 Overdispersion Models in SAS

![](bbox=[0.107, 0.095, 0.892, 0.703])

The Generalized Linear Models (GLM) framework provided by McCull and Nelder (1989) unifies the analysis of continuous and discrete response variables when the responses can be assumed to be independent. The GLM framework was extended by Zeger, Liang, and Albert (1998) to include random effects. The resulting models, Generalized Linear Mixed Models (GLMM), can accommodate the analysis of longitudinal data where subjects are monitored over a period of time. GLMM can also be used to analyze observations obtained on different subjects from a cluster, like those usually in cluster sampling. As indicated earlier, overdispersed Binomial (or Multinomial) data are usually a result of natural association among observations from the same cluster. Thus we provide a brief review of GLM in this chapter.
