When $Y_2 \sim \text{Negative-binomial}(\mu, \kappa)$ equation (6.23) becomes

```
$Pr(Y = y) = \begin{cases} (1-\pi_1)^y \ \Gamma(y+\frac{1}{\kappa}) & \text{if } y=0 \ \(1-\pi_1)^{\frac{1}{1+\kappa}}(\frac{\kappa\mu}{1+\kappa})^y & \text{if } y\ge1 \ \(1-\pi_1)^{\frac{1}{1+\kappa}}\frac{\Gamma(y+1)}{\Gamma(y+1/\kappa)} ... \end{cases}$
```

Thus, the mean and variance of a Negative-binomial based hurdle model are, respectively,

```
$E(Y) = \frac{1-\\pi_1}{1-\\pi_2}\mu \quad (6.31)$
```

and

```
$Var(Y) = \frac{1-\\pi_1}{1-\\pi_2}^2\mu(1+\mu+\kappa)-\frac{1-\\pi_1}{1-\\pi_2}\mu^2 \quad (6.32)$
```
