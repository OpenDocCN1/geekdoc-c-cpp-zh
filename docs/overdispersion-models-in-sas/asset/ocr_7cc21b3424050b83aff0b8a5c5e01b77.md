Initially, the unit interval is divided into R mutually exclusive intervals. For the s-th interval
A_s, s=1,2,...,R, all the $\frac{t_j}{m_j}$ are computed and the number of them that fall in the interval A_s
is is the observed frequency of $A_s$. That is,

```
$O_s = \sum_{j=1}^{554} I(\frac{t_j}{m_j} \in A_s)$
```

Expected frequencies are computationally more intense and depend on the variability of
t$m_j$'s. For instance, using the Beta-binomial distribution the expected frequency for the $A_s$
is computed as as

```
$E_s = \sum_{j=1}^{554} \sum_{t=0}^{m_j} Pr[T_j=t|T_j \sim Beta\text{-}binomial(\hat{\pi}, \hat{\rho}; m_j)] I(\frac{t}{m_j} \in A_s)$
```

where $\hat{\pi}$ and $\hat{\rho}$ are the MLE of $\pi$ and $ho$ given in Table 5.3. Similar calculations are done
the Random-clumped Binomial model. We start with $R=\max(m_j,j=1,2,...,554)=18$
intervals. We use the usual rule of thumb ensuring the expected frequency is at least 5 for
each interval. Any interval not satisfying this rule is collapsed with the previous one. The results
oftaining using module "GOF_BB" are shown in Output 5.3.
