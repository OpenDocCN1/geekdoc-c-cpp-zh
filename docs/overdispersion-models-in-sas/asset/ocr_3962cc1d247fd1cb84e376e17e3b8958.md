Similarly, for the factor Program, the program uses the first level as its reference level. the associated dummy variable is given below:

| Program | P1 |

Note that the default parameterization (called the "effects" parameterization) used by the LOGISTIC procedure provides estimates of the difference in each non-reference level compared to the average effect over all levels. Using the previously dummy variables S1, S2 and P, the two logit models being fitted are

```
$$\begin{aligned} \ln\frac{\pi_{sp1}}{1-\pi_{sp1}} &= \beta_{10} + \beta_{11}S_1 + \beta_{12}S_2 + \beta_{13}P_1 + \beta_{14}S_1P_1 + \beta_{15}S_2P_1 \ \ln\frac{\pi_{sp2}}{1-\pi_{sp2}} &= \beta_{20} + \beta_{21}S_1 + \beta_{22}S_2 + \beta_{23}P_1 + \beta_{24}S_1P_1 + \beta_{25}S_2P_1 \end{aligned}$$
```

Odds-ratios can be obtained from any of the two equations and are provided by the ODDSRATIO statement. These equations correspond to the logits based on the learning style preferences, namely, Self versus Class, and Team Class. Care should be exercised in computing odds-ratios since the School-by-Program interaction is present. For instance, in order to compute the odds-ratio for Afternoon Program versus Regular at School=1 from the first equation (learning style preference Self versus Class), one needs to compute the following log-odds:

| Logarithm of Odds | Parameter |
|---|---|
| Afternoon Program at School 1 | $\beta_{10} + \beta_{11} - \beta_{13} - \beta_{14}$ |
| Regular Program at School 1 | $\beta_{20} + \beta_{21} - \beta_{23} + \beta_{24}$ |

The logarithm of the odds-ratio under consideration is the difference of the above log-odds, that is $-2\beta_{13} - 2\beta_{14}$. Thus, the desired odds-ratio is

```
$e^{-2\beta_{13}-2\beta_{14}}$
```
