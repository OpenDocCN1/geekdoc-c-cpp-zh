$R_{CM}(\pi_i, \pi_i) \quad m(1-\rho)^2(\beta_i + \beta_d) + (\pi_i^{-1} + \pi_d^{-1}) \rightarrow 0 \quad i=1,2,...,d$
$R_{CM}(\pi_i, \pi_i') \quad m(1-\rho)\beta_{d+1} + \pi_{d+1}^{-1} \rightarrow 0 \quad i=1,2,...,d, \ i \neq i'$

where $\beta_i = \frac{\pi_i}{(1-\rho)\pi_i} + \frac{1-\pi_i}{(1-\rho)\pi_i}, \text{ and } \gamma_i = \frac{\pi_i(1-\pi_i)}{(1-\rho)\pi_i} + \frac{1}{1-\rho}, \text{ for } i=1,2,...,(d+1)$.

Comparing the limiting results for the two distributions by (8.3) and (8.4), interesting observations emerge. First of all, note that the expression of the limiting expressions in (8.4) is simple to compute, whereas the limiting expressions in (8.3) involve digamma and trigamma functions. Furthermore, it can be shown that the error of approximation for the FIM of the DM is of order $m^{-1}$, whereas the corresponding error of approximation for the RCM is of order $m$. Thus, we can conclude that while approximations will perform well for large $m$, the approximation will work much better for the RCM model than the DM model. These observations are corroborated in a large-scale simulation study, the results of which are reported in Appendix 8.1.

The limiting expressions in equations (8.3) and (8.4) are simple to compare to the elements of the associated Fisher information matrices. So, for large $m$, one may consider using them as approximations in the Fisher scoring algorithm of equation (8.1). Using the approximations we recommend the following Two-stage procedure:

**Stage 1.** An estimator $\hat{\theta} = (\hat{\pi}', \hat{\rho})$ is first obtained by using the previously described Fisher scoring procedure (8.1), where the Fisher information matrix is replaced with its limiting information matrix given in equations (8.3) and (8.4).

**Stage 2.** Once convergence is achieved for the computation of $\hat{\theta}$, the estimator $\tilde{\theta} = (\hat{\pi}', \hat{\rho}')$ is obtained by performing the extra step:

$$\tilde{\theta} = \hat{\theta} + \left\{n \mathbf{1}(\hat{\theta})\right\}^{-\frac{1}{2}} \frac{\partial L(\hat{\theta})}{\partial \theta} \quad (8.5)$$

Here, $\hat{\theta}$ is the FIM for a single observation evaluated at $\theta = \hat{\theta}$. For this final step, the updated variance-covariance matrix of $\tilde{\theta}$ is $\{n \mathbf 1(\hat{\theta})\}^{-1/2}$. The resulting estimator will be denoted by $\tilde{\theta} = (\hat{\pi}', \hat{\rho}')$.

Before proceeding, let us review the impact of the approximations in the computation of maximum likelihood estimators. We first note that there are $(d+1)(d+2)$ unique elements in each of these Fisher information matrices. Each element of $I_{RCM}$ is a summation over the multinomial space $\Omega$ containing $\frac{(m+d)!}{md!}$ terms. Thus, it will take $(d+1)(d+2)$ times $\frac{(m+d)!}{md!}$ operations to compute all the elements of the RCM distribution. For $m=100$ and $d=3$, which turns out to be 176,851, each term in the summation involves computing several multinomial probabilities. On the other hand, the approximations of summations create huge computational savings. Since multinomial probabilities do not appear in the limiting expressions, further computational savings will be realized. In the case of DM, as mentioned earlier, each element of the FIM can be actually computed as an expectation with respect to a Beta-binomial distribution. Therefore, the summation for each element of DM contains only $m$ terms. Thus, the savings due to ‘not having to loop’ is $\frac{(d+1)(d+2)}{2}$ times $m$, and is not as significant as it is in the case of the RCM distribution.
