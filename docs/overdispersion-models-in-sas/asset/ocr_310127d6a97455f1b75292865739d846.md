Under the Scale Multinomial Model, the usual variance-covariance matrix associated with each multinomial response is inflated by the single factor $\hat{\phi}=4.8323$. This is given by the Pearson's Chi-square statistic divided by its degrees of freedom. Under the Generalized Scale Multinomial Model, different components of each multinomial covariance matrix are adjusted by the factors $\phi_1=7.9296$ and $\phi_2=2.0419$. The programming statements below are used to obtain box plots of the residuals in (7.21). If the usual multinomial model with the single-factor holds for the Cadmium-Zinc data, one would expect each component of $Z_j$ to be identically distributed.

```
---
-- Box Plots Residuals Z1 and Z2;
-- Set Residuals;
if n > 1;
  Z = Z1; Component = 1; Output;
  Z = Z2; Component = 2; Output;
run;
ods hom;
ods graphics on;
proc sgplot data=Residuals;
  title "Standardized Components";
  vbox z / category=Component extreme;
run;
ods graphics off;
ods hom close;
```
