## 1.4 离散过度的扩展定义

离散过度的情况有很多。在二项/多项分布的情况下，当独立性假设（在基本单元内）或成功概率的共同性被违反时，就会产生离散过度。在泊松分布的情况下，当事件的发生率因受试者而异时就会观察到离散过度；这些发生率被假定为服从伽马变量分布。离散过度以聚类数据自然的方式出现。它在具有重复测量的纵向数据中被发现。对受试者的计数通常表现出离散过度。例如，考虑一项针对椎体骨折高风险的骨质疏松患者临床研究。在给定期间内测量事件的发生次数。同一患者可能遭受多次发生，从而对计数做出多次贡献，这导致违反了泊松分布所假设的“独立发生”。因此，这些案例并非真正来自泊松分布，从而表现出离散过度。

过去 20 年左右关于混合分布和广义线性混合模型（GLMM）的进展使离散过度得以充分发展。离散过度已超越其边界；它是一个比第 1.2 节中提供的常见表征更广泛的话题。诸如狄利克雷-多项式（Mosimann, 1962）和 Morel 和 Nagaraj (1993) 以及 Neerchal 和 Morel (1998) 提出的随机聚类分布等多项式分布的混合，相对于具有均值向量和方差-协方差矩阵的多项式分布具有离散过度，如 (1.3) 和 (1.4) 所示。具有均值和方差的负二项分布，如式 (1.5) 和 (1.6) 所示，相对于泊松分布具有离散过度。具有适当定义的随机效应的二项分布相对于二项模型具有离散过度。此外，具有随机效应的贝塔-二项分布相对于贝塔-二项具有离散过度，而贝塔-二项本身相对于二项分布具有离散过度。列表还在继续。本章附录 1.1 显示了我们打算在本书中涵盖的离散过度的一些分层图。

## 1.5 一个模拟示例

模拟相关伯努利试验的一种简单方法如下。设 Y, Y_i^0, ..., Y_m^0 为独立同分布的伯努利 ( ) 随机变量。对于每个 i,i=1,...,m，定义 Y_i 为以概率 ρ 为 Y，或以概率 (1-ρ) 为 Y_i^0,0ρ≤1。换句话说，每个 Y_i 可以表示为

```
Y_i = Y I(U_i ≤ ρ) + Y_i^0 I(U_i > ρ),                               (1.7)
```

其中 U_i 是独立的均匀 (0,1) 随机变量，I() 表示指示函数。 in for clustered data,

E(Y) = ρ, Var(Y) = ρ(1-ρ) and Corr(Y_1, Y_2) = ρ².

生成模型 (1.7) 下数据的编程语句如下所示，给出 m=5, ρ=0.6 和 ρ²=0.3。注意正在生成 n=2000 个聚类，每个聚类由 m=5 个相关的二元结果组成。

### 程序 1.1：相关伯努利结果

```
/*
Generation of correlated Bernoulli outcomes
For Y(1),Y(2),...,Y(m)
E(Y)
Pi
Var(Y)
Pi*(1-Pi)
Corr(Y(i), Y(j))
Rho*Rho
*/
data correlated bernoulli;
n = 20000; --- Number of clusters;
m = 5; --- Number of elemental units within the cluster;
pi = 0.6; --- Probability of success of each elemental unit;
rho2 = 0.3; --- Intra-cluster correlation;
seed = 16670;
rho = sqrt(rho2);
do subid = 1 to nr; --- Variable yj plays the role of y of eq. (1.7)
y = 0;
u = uniform(seed);
if u < pi then y = 1;
if i=1 to m;
y = 0;
u = uniform(seed);
if u < rho then y = y;
else do;
uu = uniform(seed);
if u < pi then y = 1;
end;
output;
end;


keep subid i;
run;
```

回想一下，数据中离散过度带来的后果之一是 Type 错误膨胀。程序 1.1 可以很容易地扩展为一个模拟来演示这种不良影响。为此，考虑一个样本 n=20 个聚类，每个大小为 m=5。聚类内的基本单元被视为独立，则我们将有总共 120 次伯努利试验，具有相同的成功概率 π。我们需要检验原假设 H₀:π=0.6 与备择假设 H₁π>0.6。对于二项分布，α=0.05 时的 Z 检验在

$Z = \frac{\pi-0.6}{\sqrt{\pi(1-\pi)}}} > 1.644$ 时拒绝原假设。真实 Type I 错误的估计值可以通过

对一系列生成为 0.160 的离散过度数据集执行此操作，然后通过计算拒绝次数来获得。程序 1.2 提供了执行此模拟所需的语句。

### 程序 1.2：估计程序 1.1 中创建的数据的 Type I 错误率

```
* Estimating actual Type I Error rate for overdispersed data;
data correlated_bernoulli; --- This data was created in Program 1.1;
    set correlated_bernoulli;
    reps = ceil(id / 20); --- Creates 1000 reps of n=20 clusters of size m=5 each;
run;
proc means data=correlated_bernoulli mean noprint;
    class reps;
    var yr;
    output=test mean=Pi_hat;
run;
data test;
set test;
    if _type_ = 1;
    z = (Pi_hat - 0.6) / sqrt(Pi_hat*(1-Pi_hat) / 100);
    p Val = 0;
    if z > 1.644 then p Val = 1;
run;
title "Monte Carlo Estimate of Type I Error Rate";
proc means data=test mean maxdec=3;
    var P_val;
run;
```
