我们现在转向 GLIMMIX 过程中可用的伪似然 (PL) 方法。PL 方法将模型线性化，尺度参数 $\phi$ 变为加权正态混合模型中的残差尺度参数。PL 方法相对于拟似然方法的一个优点是它提供了 $\phi$ 的标准误差。这对于评估过度离散的存在很有用。我们使用程序 3.3 中的编程语句说明 PL 方法的计算。

# 程序 3.3：拟合弓形虫数据的伪似然 (PL) 逻辑回归模型

```
data toxoplasmosis;
  set toxoplasmosis;
  city = _n_;
run;
ods html;
proc glimmix data=toxoplasmosis;
  class city;
  model t/m = z*z*z / s;
  random _residual_ / subject=city;
run;
html close;
```

运行程序 3.3 的结果显示在输出 3.3 中。请注意，估计值及其标准误差与我们在输出 3.2 中运行拟似然分析时相同。请注意，PL 输出提供了 $\phi=1.9404$，估计标准误差为 0.5010。由于估计值 $\phi$ 超过标准误差的两倍，我们可能会得出存在过度离散的结论。

在 PL 下，beta 估计的标准误差反映了 $\sqrt{\phi}$ 的膨胀。稍后，我们将讨论同时方差调整。Morel, Jorge, and Nagaraj. Overdispersion Models in SAS.
