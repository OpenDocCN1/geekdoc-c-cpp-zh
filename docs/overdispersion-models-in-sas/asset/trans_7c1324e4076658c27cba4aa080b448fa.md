根据上述信息，无法从前瞻性研究中重建概率。然而，并非全无希望，因为可以根据上述信息恢复 OR。此时，优势比被定义为疾病存在时具有暴露因素的优势与疾病不存在时具有暴露因素的优势之比。这些优势定义为

> 患病时具有暴露因素的优势 = $\frac{\pi_{11}}{\pi_{+1}} = \frac{\pi_{11}}{\pi_{21}}$

和

> 未患病时具有暴露因素的优势 = $\frac{\pi_{12}}{\pi_{+2}} = \frac{\pi_{12}}{\pi_{22}}$

因此，对于病例对照研究，优势比为

> OR = 患病时具有暴露因素的优势 / 未患病时具有暴露因素的优势 = $\frac{\pi_{11}}{\pi_{21}} / \frac{\pi_{12}}{\pi_{22}}$

注意，优势比在前瞻性研究和病例对照（回顾性）研究中是相同的。人们说优势比“对抽样方案不变”。这一事实对于流行病学家、医学研究人员和公共卫生从业者在病例对照研究中变得很重要。在此类研究中，相对危险度 RR = $\frac{\pi(X=1)}{\pi(X=0)}$

无法直接获得。另一方面，计算优势比很直接。在这些情况下，已知优势比和相对危险度实际上是相同的（Cornfield, 1951）。优势比的这两个特性，即对研究性质的不变性和与相对危险度的几乎相同值，使逻辑回归成为最具吸引力的统计回归之一

为了说明病例对照研究中逻辑回归的使用，我们考虑 Ille-et-Vilaine 食管癌研究。Ille-et-Vilaine 是法国大革命期间从布列塔尼省的一部分创建的法国省份。布列塔尼和诺曼底的食管癌死亡率已知很高。Tuyns 等人（1977）收集了 Ille-et-Vilaine 省的数据，其中 200 名男性（病例）被诊断为食管癌。从每个公社的选民名单中抽取了 778 名受试者（无癌症）样本。其中，775 名受试者提供了足够的信息用于分析目的。Breslow 和 Day（1980）使用此示例来说明癌症研究的各种统计方法。我们请读者参考他们书籍的第 4 章和第 5 章。Ille-et-Vilaine 病例对照研究的数据如表 2.6 所示。

## 程序 2.5：使用 GENMOD 分析 Ille-et-Vilaine 食管癌研究数据

```
/*
  Ille-et-Vilaine Study of oesophageal cancer, Tuyns et al. (1977)
*/
data one;
    input stratum $ count x1 x2;
    format alcohol $5;
    alcohol = 'High'; count = x1; output;
    alcohol = 'Low'; count = x2; output;
    drop x1 x2;
  datalines;
  25-34 Case 1 0
  25-34 Control 9 106
  35-44 Case 4 5
  35-44 Control 26 164
  45-54 Case 25 21
  45-54 Control 29 138
  55-64 Case 42 34
  55-64 Control 27 139
  65-74 Case 19 36
  65-74 Control 18 88
  75+ Case 5 8
  75+ Control 0 31
;
;
```

```
proc sort data=one;
    by age_stratum alcohol;
run;

proc transpose data=one out=oesophageal_cancer;
    by age_stratum alcohol;
    var count;
    id cancer;
run;
```

```
data oesophageal_cancer;
set oesophageal_cancer;
    m = Case + Control;
drop name_;
run;
ods html;
proc genmod data=oesophageal_cancer;
    class age_stratum alcohol;
    model case/m = age_stratum alcohol / dist=binomial link=logit type3;
    estimate 'Ln(OR) High Vs Low' alcohol 1 -1 / exp;
run;
ods html close;
```

```
proc freq data=;
tables age_stratum*alcohol*cancer / cmh;
weight=count;
```

## 2.9 电子设备故障的泊松示例

从前几节的示例中，我们转向泊松示例，这是 GLM 中使用最广泛的下一个模型。我们将说明估计值的比较并解释诊断图。Jorgensen（1961）和 Lomer 等人（1971）分析了数据，包括电子循环在运行（周）下的泊松分布，其中每个循环分为两个运行状态。数据提供在表 2.7 中。响应变量为 y_j, j=1,2,...,9，表示第 j 个循环中的故障数。向量 x_j = (x_{j1}, x_{j2}) 的分量是第 j 个运行循环中在状态一和状态二花费的时间。
