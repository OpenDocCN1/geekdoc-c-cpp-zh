# 8.1 Introduction

In Chapter 7 we considered maximum likelihood estimation of the Dirichlet-multinomial (DM) distribution proposed by Mosimann (1962), and the Random-clumped Multinomial (RCM) distribution proposed by Morel and Nagaraj (1993) and Necheral and Morel (1998). Maximum likelihood estimation of the parameters of these models using the classical Fisher scoring method poses computational challenges. In the case of the DM distribution, the challenges are overcome by noting that the Fisher information matrix (FIM) can be computed using the Beta-binomial distribution, which is the univariate version of DM. On the other hand, the case of the RCM distribution the computation of the FIM can become a huge burden, then an approximation result can be used to obtain a two-stage procedure for computing the maximum likelihood estimates. An analogous approximation result is also available for the DM distribution. In this chapter, we provide a brief look at the computational details underlying the Two-stage procedure, which is not only computationally efficient but also provides appropriate standard errors. We provide a statement of this result merely to indicate and discuss the impact of the result.
