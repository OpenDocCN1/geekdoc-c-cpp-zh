Similarly, it turns out that Correlation$(Y_i, Y_j) = \rho^2$. In fact, the structure of the elemental units is exchangeable. Let $T$ be the sum of the $Y_i$'s, $T = \sum_{i=1}^m Y_i$

```
$$T = Y \sum_{i=1}^m I(U_i \leq \rho) + \sum_{i=1}^m Y_i^* I(U_i > \rho).$$
```

then leads to the following representation of T

```
$$T=(YN)+(X|N),$ (4.10)
```

where $N \sim Binomial($\rho;m)$, $Y \sim Bernoulli($\pi)$, $N$ and $Y$ independent, and $(X|N) \sim Binomial($\pi, m-N)$ if $N < m$.

Equation (4.10) explains how overdispersion is introduced in this model and also provides a context for its name, Random-clumped Binomial distribution. Under the representation in (4.10), the outcome given $Y$ is duplicated a random number of times $N=0,1,...,m$. That is, N$ units in the cluster are exhibiting the same behavior. The remaining $m-N$ units in the cluster provide independent Bernoulli responses. The contribution of these $m-N$ units to the total count $T$ is represented by $(X|N)$. Note that the model clusters a randomly chosen respondent. Here comes the name "Random-clumped Binomial distribution. Figure 4.1 illustrates the representation of a cluster of size $m=7$. The cluster is thought of as having two subgroups. One is size 4 (in general $0 \leq N \leq 7$), and it consists of those elemental units that greatly influence each other and provide identical responses.
