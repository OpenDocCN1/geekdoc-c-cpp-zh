The cumulative logits model previously defined is also known as the Proportional-odds model. Inherent to this is the proportional odds assumption, which states that the cumulative oddsratio for any given value of the covariate is constant across categories. To be precise meaning this model specification, consider in (7.8) a single covariate "x" so there is only one $eta$ parameter.

For a given value of the covariate, x , the odds of being in a cumulative category i, i = 1, 2,...,d is $e^{x\beta}$ ,which does not depend on i. The LOGISTIC procedure provides a Score test for testing the proportional odds assumption. A non-significant test is taken as evidence that the logit surfaces (equations) are nagaraj and the odds-ratios can be interpreted as constant across all possible cumulative categories. In Section 7.11 we will provide a methodology for testing this assumption of the proportional odds assumption under the likelihood models for overdispersed Multinomial models.

Whenomial responses are nominal, cumulative logits are not very meaningful; therefore, generalized logits are used. They are defined as

```
ln \frac{\pi_{ij}}{\pi_{(d+1)}} = x\beta_i, i = 1, 2,...,d ,
```

$\beta_i = (\beta_{i1},\beta_{i2},...,\beta_{ik})$. The unknown parameter vector is the dk-dimensional vector Under the generalized log link (7.10) it can be shown the mean function turns out to be

```
$\pi_i = \frac{e^{x\beta_i}}{1 + \sum_{t=1}^{d} e^{x\beta_t}}, i = 1, 2,...,d .
```

The generalized profits are defined as

```
$\Phi^{-1}(\pi_i) = x\beta_i, i = 1, 2,...,d .
```

Its associated mean function is

```
$\pi_i = \Phi^{-1}(x\beta_i), i = 1, 2,...,d .
```

Observe that cumulative logits and link functions, the number of parameters being estimated is (d+k). For generalized logits the number of unknown parameters become "dk." In the case of binomial responses, link functions (7.8) and (7.10) are the same and reduce to the logit link defined in Chapter 2.
