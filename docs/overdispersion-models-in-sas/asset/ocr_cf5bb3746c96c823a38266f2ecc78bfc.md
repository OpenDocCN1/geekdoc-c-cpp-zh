The continuation of Program 7.5 below provides the statements for computing the Wald statistic. Note the use of the IML procedure to compute expression (7.38) using the relevant results from the ODS output in LINMIXED.

# Program 7.5: Testing the Parallelism Assumption Using a Wald Statistic (continued)

```
ods html;
title "Testing Parallelism Assumption using a Wald Statistic";
data Beta_DM;
  set Beta_DM;
  keep estimate;

run;
data Cov_DM;
  set Cov_DM;
  drop row parameter;

run;
data Beta_RCM;
  set Beta_RCM;
  keep estimate;

run;
data Cov_RCM;
  set Cov_RCM;
  drop row parameter;

run;
proc iml;
  use Beta_DM;
  read all int beta;
  use Cov_DM;
```
