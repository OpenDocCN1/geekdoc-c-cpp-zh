# Chapter 6 Likelihood Models for Overdispersed Count Responses 181

```
Prob(At Risk of UTI given $x_j$) = $(1-\omega_j) \frac{\exp(-\alpha_0-\alpha_{x_j})}{1+\exp(-\alpha_0-\alpha_{x_j})} \quad (6.23)
```

Furthermore, the estimated increase of risk for a UTI, measured by odds-ratio, and for any decrease of 100 cell counts on CD4+ is by exp($\beta_0$). The programming statements for fitting this model are provided in Program 6.4. We estimate the three quartiles of the distribution of the CD4+ cells to estimate the probability of being at risk for a UTI given any quartile value. Results are shown in Output 6.4. In the estimates, the GENMOD procedure uses @zero to indicate the portion of the statement related to the Zero-inflation Probability parameters. In Program 6.4, we use ESTIMATE statements "@zero intercept -1 cd4 -q1" to obtain the estimates and standard errors of the risk probabilities in (6.23).

# Program 6.4: ZIP Model with In($\mu_j$) = $\beta_0$ and log($\omega_j$) = $\alpha_0+\alpha_{x_j}$-UTI in Men Infected with HIV

```
ods html;
proc univariate data=urinary_tract_infection
var cd4;
output out=out2 q1= median=q2 q3=
run;
data _null;
set out2;
call output('q1',trim(left(q1)));
call output('q2',trim(left(q2)));
call output('q3',trim(left(q3)));
run;
```

```
title "Zero-Inflated Poisson Model using GENMOD"\ods output=Est;
proc genmod data=urinary_tract_infection;
model episode /dist=zip;
zerodel cd4 /link=logit;
estimate "Prob at Risk at UTI when CD4<=q1" @zero intercept -1 cd4 -q1;
estimate "Prob at Risk at UTI when CD4<=q2" @zero intercept -1 cd4 -q2;
estimate "Prob at Risk at UTI when CD4<=q3" @zero intercept -1 cd4 -q3;
estimate "Log(OR)" @zero cd4 100 / exp;
run;
```

```
title "Estimated Probabilities of Risk of UTI at Different Values of CD4;"
proc print data=ests
where label contains "Prob" and label contains "Zero Inflation"
var label;
run;
```
