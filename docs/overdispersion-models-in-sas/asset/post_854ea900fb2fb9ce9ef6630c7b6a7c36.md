
# Program 10.3: Fitting a Cumulative Logit GLMM to the Shoulder Tip Pain Data

```sas
ods html;
proc glimmix data=Shoulder_tip_pain method=quad;
class subject_id_trt gender;
model y = trt gender age time / dist=mult link=clogit;
random int / subject-subject_id;
format trt $abc. gender $xyz;
estimate 'Active Vs Placebo' trt 1 -1 / or;
title *** Fitting a Cumulative Logit GLMM to the Shoulder Tip Pain Data ***';

proc glimmix data=Shoulder_tip_pain_empirical=classical method=quad;
class subject_id_trt gender;
model y = trt gender age time / dist=mult link=clogit;
random int / subject-subject_id;
format trt $abc. gender $xyz;
estimate 'Active Vs Placebo' trt 1 -1 / or;
title1 *** Fitting a Cumulative Logit GLMM to the Shoulder Tip Pain Data ***';
title2 *** with an Empirical Variance for Estimates of Fixed Effects ***';
title3 *** with the MBN small sample variance correction ***';
ods html close;
```

The Solution for Fixed Effects as well as Type III of Fixed Effects are also shown in Output 10.3. We requested the odds-ratio of Active Placebo.
