The ratio of the baseline rates to Proagide is exp(-β₂), and the ratio of the treatment phase rates Placebo to Proagide is Note that β₁ is the effect of randomization. Furthermore, the Placebo rate Treatment Phase to Baseline is R₁ = exp(β₁), which captures the Placebo effect, and the Proagide rate Treatment Phase to Baseline is R₂ = exp(β₂ + β₃). 
Finally, R₃ = exp(-β₁) represents the ratio of R₁ to R₂. This ratio R₃, can be viewed as the ratio of the treatment rates Placebo to Proagide after normalizing each rate by its associated baseline. The rates, their logarithms, and their standard errors can be estimated from the GLIMMIX procedure by using the methodology explained in the previous example. The programming statements are shown in the continuation of Program 9.3.

# Program 9.3: Continuation

```
ods html;
*** Rates Proagide Trial ***
proc glimmix data=seizures;
class id;
model cnt = xl trt xl1*trt dist=poison offset=time
dffm=none covb s;
random_residual / subject=type vcorr;
estimate 'Rate Placebo Baseline' int 1 / ilink;
estimate 'Rate Placebo Treatment Phase' int 1 / ilink;
estimate 'Rate Proagide Baseline' int 1 / ilink;
estimate 'Placebo TRT Phase' trt-1 1 xl1*trt 1 / ilink;
estimate 'Placebo Proagide Baseline' trt-1 1 xl1*trt -1 / ilink;
estimate '(R1) Baseline TRT Phase / Placebo Baseline' xl1 1 / ilink;
estimate '(R2) Proagide TRT Phase / Proagide Baseline' xl1 1*trt 1 / ilink;
estimate '(R3) = (R1) / (R2) xl1*trt -1 / ilink;
run;\ods html close;
```
