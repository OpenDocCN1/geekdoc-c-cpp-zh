# # 8.5 The Housing Satisfaction Example Revisited

This was discussed in Section 7.9. The reader may recall that two independent samples of neighborhoods were taken from the rural and urban areas of Montevideo, Minnesota. Five households were selected from each sampled neighborhood. The families from each provided information describing their satisfaction with their homes. The degrees of satisfaction were classified as “Unsatisfied,”Satisfied” and “Very Satisfied.” The rural data, which can be found in Table 7.4, were used to illustrate the fitting of the DM and RCM models to this data. We found that the two distributions provide essentially the same fit for examples with small cluster sizes, i.e., (m, j=2,...,18). We would like to illustrate the Two-stage procedure where the cluster sizes are relatively small. As in the previous example, we use the module “DM_RCM_Exact_Approximate”, which provides the maximum likelihood estimates using both the FIM and cluster size approximations. The statements to invoke the macro are given below.

```
/*
Housing Satisfaction, Brier(1980), Non-Metropolitan area (Rural)
*/
data housing;
input t1 t2 t3;
datalines;
  3 2 0
  ...
  (MORE DATA)
  5 0 0
  
;
```
