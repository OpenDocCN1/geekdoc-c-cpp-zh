The programming statements for fitting the Poisson GLMM (10.13) using NLMIXED procedure are given below. For the degrees of freedom, which in GLMIX are 6 due to the option "residual" and in NLMIXED 9, the results are identical.

```
proc nmlife data=;
parms logis 0 beta1 beta2 1 alpha1 alpha2 1;
if (group = 1) then alpha = alpha1+ beta1*logstd +;
elelse alpha = alpha2+ beta2*logstd +;
ambda = exp(alpha);
 y = poisson(lambda);
random = normal(0,exp(2*logsig)) subject=pump;
estimate 'alpha-alpha2' alpha-alpha2;
estimate 'bet-beta2' bet-beta2;
estimate 'Sigma*' exp(2*logsig);
run;
```
