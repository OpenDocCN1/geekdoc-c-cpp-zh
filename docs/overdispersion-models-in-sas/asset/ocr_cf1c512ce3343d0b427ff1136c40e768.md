The estimated Kappa coefficient tuned out to be $\kappa=0.3888$ with an estimated variance $\hat{v}(\kappa)=0.0598$. The documentation of the FREQ procedure provides an asymptotic formula of $\hat{v}(\kappa)$, which is obtained using the Delta Method. The approximate 95% confidence interval turned out to be (0.27,0.51). The interval is obtained using $\kappa\pm1.96\sqrt{\hat{v}(\kappa)}$. In this example, there are three categories, and therefore, the FREQ procedure computes a weighted Kappa as well. By default, PROC FREQ uses Cicchetti and Allison (1971) weights. We recommend the reader to Chapter 18 of Fleiss et al. (2003), and documentation for PROC FREQ for more information on the weighted Kappa.
