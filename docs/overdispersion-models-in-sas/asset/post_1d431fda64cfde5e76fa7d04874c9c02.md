
# Overdispersion Models in SAS

If $\tilde{\pi}_j = \frac{t_j}{m_j}$ is an observed proportion, its associated logit is defined as

```
$$\ln\left(\frac{\tilde{\pi}_j}{1-\tilde{\pi}_j}\right) = \ln\left(\frac{t_j}{m_j-t_j}\right)$$$
```

In practice these quantities are slightly modified as

```
$$\ln\left(\frac{t_j+0.5}{m_j-t_j+0.5}\right)$$$
```

in order to avoid numerical problems when $t$ is either zero or $m$. The estimated linear predictors are $\hat{\eta}_j = \hat{\beta}_0 + \hat{\beta}_1X_j$. The programming statements are provided in Program 2.2. The results produced by GLIMMIX are provided in Output 2.2.

In dosage mortality studies, the quantity of interest is the LD50, the dosage that is lethal for 50% of the population. This quantity can also be thought of as the median tolerance level for the population. Under the logistic regression model, LD50 is readily available as the solution to

> $\beta_0 + \beta_1 LD50 = \ln\left(\frac{\pi}{1-\pi}\right)$

by taking $\pi=\frac{1}{2}$. In this case $\frac{\pi}{1-\pi}=1$ and therefore, $LD50=\frac{\beta_0}{\beta_1}$. In Murray’s example,

an estimate of LD50 is $\frac{10.3279}{2.4582}=4.2014$. This dosage in the natural log scale.

Then, the LD50 is $e^{4.2014}=66.78$ mg/100 cc .

## Chapter 2 Generalized Linear Models

We fit a Probit model for Murray’s data. In a Probit model, the mean function is defined as

$\pi_j = \Phi(\mathbf{x}_j\boldsymbol{\beta})$

where $\Phi(\cdot)$ is the cumulative distribution function of a standard Normal distribution. Thus, the Probit link is

$\Phi^{-1}(\pi_j) = \beta_0 + \beta_1\mathbf{x}_j$

Note that with Probit link the estimated linear predictors $\hat{\eta}_j = \hat{\beta}_0 + \hat{\beta}_1\mathbf{x}_j$ are Z-scores. A subject with a predicted score of zero has 50% probability, with a predicted score of 1.64 has 95% probability, etc. The programming statements for fitting a Probit model using GLIMMIX including the diagnostic plots are

```
ods html;
ods graphics on;
title "Dosage-Mortality of pyrethins on Male Flies, Murray (1938)"
title2 "GLM with Binomial Distribution and Probit Link";
proc glimmix data=pythrins plots=residual;
model t/m = x / dist=binomial link=probit;
run;
ods graphics off;
ods html;
```

The LD50 is obtained by solving the equation

$\beta_0 + \beta_1 LD50 = \Phi^{-1}(\pi)$

with $\pi =\frac{1}{2}$. For this value of $\Phi^{-1}(\pi) = 0$ and as in the logistic regression case, LD50 = $-\frac{\beta_0}{\beta_1}$. Using the estimates provided in Table 2.5, an estimate of LD50 is 4.1972 when the scale is $e^{4.1972}=66.50$ mg/cc, almost the same as the value obtained under the logistic model. ## Program 2.3: Fitting a Binomial Model with Probit and Logit Links to the Dosage-Mortality Data of Pyrethins Using PROC PROBIT

```
ods html;
title1 "Dosage-Mortality of Pyrethins on Male Flies, Murray (1938)"
title2 "GLM with Binomial Distribution and Logit Link using PROC PROBIT";
proc probit data=pyrethins log;
model t/m = dose / logistic inversecl;
run;
title "Dosage-Mortality of Pyrethins on Male Flies, Murray (1938)"
title2 "GLM with Binomial Distribution and Probit Link using PROC PROBIT";
proc prob data=pyrethins log;
model t/m = dose / inversecl;
run;
ods html;
```

The option "log" in the PROC requests the analysis performed on the natural logarithm of dose. The option "inversecl" provides the Lethal Dose (LD) estimates in increments of 1% that kill from 1% to 99% of the population. These LDs are calculated on the log scale and on the dosage scale. Selected results are produced in output 2.3.
