**Stage 2.** Once convergence is achieved for the computation of $\hat{	heta}$, the estimator $	ilde{	heta} = (\hat{\pi}', \hat{ho}')$ is obtained by performing the extra step

```
$$\tilde{	heta} = \hat{	heta} + \left\{n \mathbf{1}(\hat{	heta})\right\\}^{-\frac{1}{2}} \frac{\partial L}(\hat{	heta})}{\partial \theta} \quad (8.5)$
```

Here, $\hat{	heta}$ is the FIM for a single observation evaluated at $\theta = \hat{	heta}$. For this final step, the updated variance-covariance matrix of $\tilde{	heta}$ is $\{n \mathbf 1}(\hat{	heta})\}^{-1/2}$. The resulting estimator will be denoted

by $\tilde{	heta} = (\hat{\pi}', \hat{ho}')$.

Before proceeding, let us review the impact of the approximations in the computation of maximum likelihood estimators. We first note that there are $(d+1)(d+2)$ unique elements in each of these Fisher information matrices. Each element of $I_{RCM}$ is a

summation over the multinomial space $\Omega$ containing $\frac{(m+d)!}{md!}$ terms. Thus, it will take $(d+1)(d+2)$ times $\frac{(m+d)!}{md!}$ operations to compute all the elements of the RCM distribution. For $m=100$ and $d=3$, which turns out to be 176,851, each term in the summation involves computing several multinomial probabilities. On the other hand, the approximations of summations create huge computational savings. Since multinomial probabilities do not appear in the limiting expressions, further computational savings will be realized. In the case of DM, as mentioned earlier, each element of the FIM can be actually computed as an expectation respect to a Beta-binomial distribution. Therefore, the summation for each element of DM contains only $m$ terms. Thus, the savings due to ‘not having to loop’ is $\frac{(d+1)(d+2)}{2}$ times $m$, and is not as significant as it is in the case of the RCM distribution.
