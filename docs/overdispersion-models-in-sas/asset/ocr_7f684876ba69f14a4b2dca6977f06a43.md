The Wald Chi-square statistic for testing the significance of the logarithm of the odds-ratios is 77.57 with one degree of freedom. The likelihood ratio tests (reported under Type 3) correspond to generalized analysis of variance discussed. The associated value of the likelihood-ratio statistic is 79.52. Both statistics are asymptotically equivalent. The estimated common-odds (reported under Contrast Estimate Results) is 5.31, with (3.66, 7.70) as an approximate 95% confidence interval. As seen in linear regression models, the estimate of the logarithm of the odds-ratios has been adjusted by the stratification variable (in the age in years). The common odds-ratio is usually estimated by the Cochran-Mantel-Haenszel (CMH) estimator. This estimator can be obtained using the programming statements given below. The value of the CMH estimator is 5.16 with an approximate 95% confidence interval (3.56, 7.47). It also provides the log estimator of the sample, which is 5.10 with an approximate 95% confidence interval (3.51, 7.41). The log estimator allows a correction for zero cell counts. Since two of the cell counts in the data set are zero, the latter is preferred. Note the similarities of the logistic regression and CMH results.
