Note that each city (“id”) has been treated as a “cluster” in order to make use of GEE in the “random” statement. The offset variable is “inz”, which represents the natural logarithm of the number of inhabitants in 1920. The logarithm of the ratio R, as in equation (9.14), is 0.1998 with an estimated standard error of R = 0.0247, as in equation (9.15). An approximate 95% confidence interval for the parameter ln(R), using equations (9.14)and (9.15), is (0.1514, 0.2482). The point estimate of R is R = exp(0.1998) = 1.2212. Thus, from 1920 to 1930, the population of the cities in the sample increased by about 22%. An approximate 95% confidence interval for R is obtained by applying the inverse link (exponential function) to the previous bounds. This yields (1.1635,1.2818).
