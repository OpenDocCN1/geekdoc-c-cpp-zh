The program below provides statements for the parallelism assumption via a likelihood ratio test. A likelihood ratio test is constructed from the log-likelihood functions of the unrestricted model in equation (7.35) and the log-likelihood functions of the Proportional-odds Model in equation (7.34). The fitting of the "reduced model" (Proportional-odds Model) is obtained in the program.

# Program 7.5: Testing the Parallelism Assumption Using a Likelihood Ratio Test (continued)

```
ods html;
title "Proportional-Odds Model -- Dirichlet-multinomial Distribution";
ods output FitStatistics;Fit_DM;
Proc nlmixed birth_defects;\params al=3.7,a2=-2.4,b1=-0.2,b2=3.1,b3=5.5,b4=-1.8,b5=-1.7,rhoc=0.5;
bounds 1-rho=0;
etal=a1+b1*zn2+b2*cd2+b3*cd3+b4*zn2+b5*zn2;
eta2=a2+b1*zn2+b2*cd2+b3*cd3+b4*zn2+b5*zn2;
gamma1=1/(1+exp(-etal));
gamma2=1/(1+exp(-eta2));
p1=gamma;
p2=gamma2-gamma1;
p3=1-p1-p2;
t=t1+t2+t3;
c=(1-rhoc)*rho;
const=ligma(m+1)-ligma(t1)-ligma(t2+1)-ligma(t3+1);
loglik=ligma((p1+(rhoc)*rho1)*(t1+(rhoc)*rho2)*(t2+(rhoc)*rho3)*(rhoc**t3))
+ (p2+(rhoc)*rho1)*(t1+(rhoc)*rho2)*(t2+(rhoc)*rho3)*(rhoc**t3))
+ (p3+(rhoc)*rho1)*(t1+(rhoc)*rho2)*(t2+(rhoc)*rho3)*(rhoc**t3))
+const;
model t1=general(loglik);
```

```
Title "Proportional-Odds Model --led Multinomial Distribution";nods output FitStatistics;Fit_ROM_Reduced_DM_Dimensions=0;

+ (p2+(rhoc)*rho1)*(t1+(rhoc)*rho2)*(t2+(rhoc)*rho3)*(rhoc**t3))
+ (p3+(rhoc)*rho1)*(t1+(rhoc)*rho2)*(t2+(rhoc)*rho3)*(rhoc**t3))
+const;
model t1=general(loglik);
```
