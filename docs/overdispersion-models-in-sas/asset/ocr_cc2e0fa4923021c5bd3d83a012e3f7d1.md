If the canonical link is assumed, the maximum likelihood score equations (2.19) become

```
$X^T(\mathbf{y} - \boldsymbol{\mu}) = 0$.
```

In this case, equations (2.22) and (2.23) can be simplified further. The iterative procedure simplifies to a point where it can be easily implemented in any computer language. Under canonical link we then has

```
$$\hat{\beta}_{(S+1)} = \hat{\beta}_{(S)} + (X^T\mathbf{V}X)^{-1} X^T(\mathbf{y} - \boldsymbol{\mu})$
```

which can be written as

```
$$\hat{\beta}_{(S+1)} = \hat{\beta}_{(S)} + \left(\sum_{j=1}^{n} \mathbf{x}_j^T \mathbf{v}_j^{-1} \mathbf{x}_j\right)^{-1} \sum_{j=1}^{n} \mathbf{v}_j^{-1} (\mathbf{y}_j - \boldsymbol{\mu})$
```

Here, as previously defined in Section 2.2, $\mathbf{X} =(\mathbf{x}_1,,\mathbf{x}_2,\dots,\mathbf{x}_n)^T$.

Note that under canonical link the Hessian does not involve y and therefore will coincide with **I**, the FIM. Thus, the Newton-Raphson and the Scoring Method would be identical. This is indeed a pleasant result. The variance-covariance matrix of the MLE is estimated by this Hessian or the FIM, depending on the method of estimation. This is usually a large sample result. Under certain regularity, maximum likelihood estimators enjoy optimal properties. They are unbiased or asymptotically unbiased. MLEs are asymptotically efficient in the sense that they achieve the Cramer-Rao lower bound when the sample size tends to infinity. This means that no other unbiased estimator has a lower asymptotic mean squared error than the MLE. Furthermore, they are asymptotically normal; that is, as the sample size increases, the distribution of the MLE tends to the Gaussian distribution.
