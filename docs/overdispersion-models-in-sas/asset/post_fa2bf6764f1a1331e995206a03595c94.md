```
title2 "Negative-Binomial Hurdle Model";nproc nlmixed data=Milk Consumption;
parms alpha=0 beta=0 kappa=0.5;
bounds kappa > 0;
p1 = 1/(1+exp(-alpha));
mu = exp(beta);
a = 1/kappa;
p = 1 / (1 + kappa*mu);
p2 = p^a;
if y=0
else ll = log((1-p1)/(1-p2)) + a * log (p) + y * log (1-p)
ll -= gamma(y+a) - gamma(a)
ll -= freq*ll;
model y = general(1);
predict 1/(1+exp(-alpha)) out=PredMilk_2;
estimate 'Pl' = 1/(1+exp(-alpha));
estimate 'Mu' = exp(beta);
estimate 'Kappa' = 1/(1+exp(-alpha))/(1/(1+exp(-alpha)))**(kappa))*exp(beta)*exp(beta);
estimate 'Variance' = 1/(1+exp(-alpha))/(1/(1+exp(-alpha)))**(kappa))*exp(beta) * (1+exp(beta)+kappa*exp(beta);
1/(1+exp(-alpha))/(1/(1+exp(-alpha))**(kappa))*exp(beta)*exp(beta);
1/(1+exp(-alpha))/(1/(1+exp(-alpha))**(kappa))*exp(beta);
run;
```

Selected parts of the results of Program 6 are given in Output 6. Under both models, the estimated values of $\pi_i = Pr(Y, 0)$ are the same, i.e., $\pi_i = 0.4037$. Once the hurdle is crossed, the estimated mean of the positive counts is $(1-\hat{\pi}_1) \frac{\hat{\mu}}{(1-\hat{\pi}_2)}$ where $\pi_2 = Pr(Y_2, 0)$. In this example, both hurdle models provided the value: 1.1095. Not the true Akaike Information Criterion (AIC), the corrected information (AICC), and the Schwarz Bayesian Information Criterion (BIC) are smaller under the Negative-binomial hurdle model, suggesting that this model might be preferred over the Poisson hurdle model. We will corroborate this observation by performing a Pearson's Goodness-of-fit test, similar to the one computed in Program 6.2. The estimated means under the two models (see equations (6.27) and (6.30)) turned out to be 1.1095, which coincides with the arithmetic mean attained from the MEANS procedure. That is not the case for the variance. The estimated variance under the Poisson hurdle model is 2.28, while that obtained under the Negative-Binomial hurdle model (see equation (6.31)) is 1.568. The latter variance is much closer to 1.564—the usual variance reported by the MEANS procedure. Note that the variances of the two models under discussion are larger than their mean. Thus, these models exhibit overdispersion. Furthermore, the estimated mean of a Poisson is in this case 1.1095, the two hurdle models also exhibit overdispersion relative to the Poisson distribution.

# Program 6.7: Goodness-of-fit Tests for the Hurdle Models—Daily Milk Consumption Data

```
/*
   Milk Consumption Example -- Mullahy (1986)
*/
%macro gof_test(File,Distribution,DF);
proc iml;
/* Input:    File = File Containing Observed and Expected Frequencies
               Distribution = Distribution being fitted
               DF = Degrees of Freedom for GOF Test
   Output:   Pearson's GOF and Associated P-value */
--- Get observed and expected frequencies;
use &File var (freq);
read all into obs;
use &File var (pred);
read all into exp_f;
sum1       = obs[,1];
sum2       = exp_f[,1];
exp_f[7,1] = exp_f[7,1] + sum1 - sum2;
sum2       = exp_f[,1];
--- Compute Chi-square GOF statistics and P-values;
chi = 0;
do j = 1 to 7;
  chi = chi + obs[j] * obs[j] / exp_f[j];
end;
chi = round(chi &n, 0.01);
df = &DF;
npval = 1 - probchi(chi,df,0);
--- Print results;
x0 = ('0', '1', '2', '3', '4', '5');
distribution = ({&Distribution};};
x1 = obs / sum;
x2 = exp / sum;
mattrib x0   label=Value of Y';      format=8.0;
mattrib x1   label='Observed Frequencies'; format=10.4;
mattrib x2   label='Expected Frequencies'; format=10.4;
mattrib chi label='Chi-square';        format=8.2;
mattrib df   label='DF';                format=8.0;
mattrib pval label='P-Value';          format=pvalue;

print 'Goodness-of-fit Results';
print x0 x1 x2;
print Distribution chi pval;
quit;
%end gof_test;\ods html;
title1 "Milk Consumption Example -- Mullahy (1986)"
title2 "Poisson Hurdle Model";
```
