In the framework of GLM, the mean $\mu_j$, $j=1,2,...,n$, depends on $k$-dimensional row vector of known covariates $\mathbf{x}_j$ and a $k$-dimensional column vector of unknown parameters $\mathbf{eta}$, through a twice differentiable smooth function $g(\cdot)$ so that

```
$g(\mu_j) = \mathbf{x}_j\mathbf{eta} = \sum_{i=1}^k x_{ji}\beta_i. (2.10)
```

The function $g(\cdot)$ is called a **link function**, and $\mathbf{x\beta}$ is called the **linear predictor**. Recall that the link function was previously defined in Section 1.6 of Chapter 6. The linear predictor is usually denoted as $\eta_j = \mathbf{x}_j\mathbf{eta}$. In the case of classical regression models discussed in Section 2.2,
n$\mu_j = \mathbf{x}_j\mathbf{eta} = \sum_{i=1}^k x_{ji}\beta_i$, so the link function is the identity function. Note that $\mu_j = g^{-1}(\mathbf{x}_j\mathbf{eta})$nwhereas $g^{-1}(\cdot)$ is the mean function. In Table 1.2 of Chapter 1 we provided the mean and canonical link functions for the Bernoulli and Poisson distributions. From now on, $g(\cdot)$ will be used to denote any link function, including canonical link functions. Thus, the main characteristics of a GLM are:

+   1. **The random component**: the components of $Y_j$, $j=1,2,...,n$ are independent and distributed according to one of the distributions in the exponential family.

+   2. **The systematic component**: the linear predictors $\eta_j = \mathbf{x}_j\mathbf{eta}$, $j=1,2,...,n$, are such that $\mathbf{x}_j$ is a vector of known covariates, and $\mathbf{eta}$ is the unknown vector of parameters.

+   3. **The link function**: the link between the random and systematic parts that is $g(\mu_j) = \eta_j$, $j=1,2,...,n$.

In all these examples the random component is $Y_j$ and the linear predictor is $\eta_j = \mathbf{x}_j\mathbf{eta}$.
