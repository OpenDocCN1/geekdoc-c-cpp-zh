# 前言

本书重点介绍使用各种 SAS 过程对表现出过度离散的数据进行建模和分析。过度离散，也称为额外变异，出现在二项、多项和计数类型的数据中，当方差大于二项、多项或泊松模型所允许的方差时。这种现象是由数据的聚类和缺乏独立性引起的。正如 McCullagh 和 Nelder（1989）指出的那样，“过度离散在实践中并不少见。事实上，有人会认为过度离散是实践中的常态，而名义离散则是例外。”过度离散问题每天都会被制药部门、生物统计和生物计量部门、大学、政府机构、健康研究组织和抽样调查组织的从业者遇到。本书的目的是提供正确分析和建模此类问题所需的技巧。这些技巧包括似然和似然模型，以及广义估计方程（GEE）、广义线性过度离散模型（GLOM）、广义线性混合模型（GLMM）。
