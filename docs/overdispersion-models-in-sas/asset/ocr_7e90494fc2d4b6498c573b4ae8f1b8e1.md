Let $y_{ij}$ represent the counts of the j-th subject, $j=1,2,...,n$, in the i-th treatment group, $i=1,2$, at the t-th time, $t=1,2,...,m$. Conditioning on a given subject, $y_{ijt}$, $t=1,2,...,m$ are assumed to be independent but not necessarily identically ZIP random variables. It is possible that these means of such random variables are not only functions of the treatment group but also of time. It is completely feasible that the rates of events with those ZIP random variables are, in the model scale, a function of some linear trend. In order to simplify matters, we assume the ZIP rates with the repeated outcomes of a given subject are entirely a function of the treatment group, and of course of an additional random component that accounts for the fact that the repeated measurements of each subject are positively correlated and exhibit overdispersion. We consider the ZIP GLOMM

```
$y_{ij} \text{ given } \left(x_{ij};u_{ij}\right) \sim \text{Zero-inflated Poisson}(\lambda_{ij},\omega)\n\log(\lambda_{ij}) = \beta_0 + \beta_1x_{ij} + u_{ij}\quad(10.17)
```

where $\omega$ is the additional parameter of zeros relative to the Poisson distribution, $u_{ij}$ are independent and identically distributed $Normal(0,\sigma^2)$, and

+   - $x_{ij} = \begin{cases} 1 & \text{if subject is in group 1} \ 0 & \text{otherwise.} \end{cases}$

For each group (treatment), $i=1,2$, we generated 200 subjects with $m=12$ measurements representing monthly assessments of a one-year study, according to the ZIP GLOMM with parameters $eta_0=0.70$, $eta_1=0.40$, $\omega=0.20$ and $\sigma^2=1.20$. Based on the fixed part of the GLOMM in equation (10.17), we have that the expected number of counts for the first group is $(1-\omega)e^{eta_0} = 0.80(e^{0.70}) \approx 2.403$. Similarly, for the second group, the expected number of counts is $(1-\omega)e^{eta_1} = 0.80(e^{0.40}) \approx 1.1918$. Thus, the ratio of the expected number of counts for generating and analyzing data under the ZIP GLOMM previously described are provided in Program 10.6. As in the case of the BB and RCB GLOMMs, we first initial estimates of the beta parameters and the random component by fitting a Poisson GLOMM where subjects are treated as random. This information can be obtained using the GLIMMIX procedure. Selected results from Program 10.6 are depicted in Output 10.6.
