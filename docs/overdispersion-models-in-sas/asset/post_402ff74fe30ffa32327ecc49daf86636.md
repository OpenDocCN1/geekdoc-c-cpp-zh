
# Overdispersion Models in SAS

$O_s = \sum_{j=1}^{n_s} I\left(\frac{t_j}{m_j} \in A_s\right) \quad (5.5)$

and

$E_s = \sum_{j=1}^{n_s} \text{Pr}(T_j = t) I\left(\frac{t}{m_j} \in A_s\right), \quad (5.6)$

where $I(.)$ represents an indicator function and $\text{Pr}(T=t)$ is evaluated by the maximum likelihood estimates of $\pi$ and $\rho$. Note that $\sum_{s=1} O_s = \sum_{s=1} E_s = n$. If the clusters are all of the same size, it can be shown that the expression (5.6) for frequentist reduces to

$E = m \text{Pr}\left(\frac{T}{m} \in A_s\right)$ and that the Chi-square statistic will become the usual Pearson's GOF statistic.

This omnibus testing with varying 'm's is found in Neerchel and Morel (1998). They fit the Beta-binomial and Random-clumped Binomial distributions to three data sets (referred as Datasets I, II and III) on induced mutagenic damage, previously analyzed by Haseman and Soares (1976). A group of male mice were first treated with a suspected mutagen and later with one or more untreated females. The female mice became pregnant, and after a certain time they were sacrificed and then examined the frequency of living and dead implantations (an implantation is an early stage of fetus). Since implantations or fetuses from the same mother need to respond similarly, it is reasonable to treat them as a natural cluster. Table 5.2 details Dataset III, which is based on n=554 DBA/23 females x CD-1 male mating. The table provides the number of female mice with "d" implantation of those frequencies is the number of female mice n=554. Note that the total number of implantations (cluster sizes in the pregnant mice varies between 1 and 18. The value of dead implantations varies between zero and nine. As reported in Neerchel and Morel (1998), it turned out that both the Beta-binomial and Random-clumped Binomial models fit Dataset I. On the other hand, the Random-clumped Binomial distribution fit Dataset II marginally and Dataset III adequately. The Beta-binomial model did not fit either Dataset II or Dataset III.

We first fit Table 5.2 to get the MLE of $\pi$ and $\rho$. Then, we compute the omnibus GOF test described in (5,4), (5,5), and (5,6). To this end, we use the modules "GOF_GB" and "GOF_RCB" provided by Dr. Santosh C. Sudradhar by Pfizer Inc.

These modules can be found in Appendices 5.1 and 5.2, respectively. The iterative procedure in these modules is based on the Fisher Information matrix and not on the Hessian matrix, as is in case 4 when we used the NLMIXED procedure. Both procedures are asymptotically equivalent. Program 5.3 provides the necessary statistics for the analysis of the mutagenic data of Table 5.2. The modules "GOF_GB" and "GOF_RCB" should be loaded first before invoking them. We output the residuals based on the observed and expected frequencies (5.6) into the data "Resid_GB" and "Resid_RCB" in construct QQ-plots for the residuals. Table 5.3 provides the MLE results under the Beta-binomial and Random-clumped models.

Initially, the unit interval is divided into R mutually exclusive intervals. For the s-th interval $A_s, s=1,2,...,R$, all the $\frac{t_j}{m_j}$ are computed and the number of them that fall in the interval $A_s$ is the observed frequency of $A_s$. That is,

$O_s = \sum_{j=1}^{554} I\left(\frac{t_j}{m_j} \in A_s\right)$

Expected frequencies are computationally more intense and depend on the variability of $t_j$'s. For instance, using the Beta-binomial distribution the expected frequency for the $A_s$ is computed as

$E_s = \sum_{j=1}^{554} \sum_{t=0}^{m_j} Pr[T_j=t|T_j \sim \text{Beta-binomial}(\hat{\pi}, \hat{\rho}; m_j)] I\left(\frac{t}{m_j} \in A_s\right)$

where $\hat{\pi}$ and $\hat{\rho}$ are the MLE of $\pi$ and $\rho$ given in Table 5.3. Similar calculations are done the Random-clumped Binomial model. We start with $R=\max(m_j,j=1,2,...,554)=18$ intervals. We use the usual rule of thumb ensuring the expected frequency is at least 5 for each interval. Any interval not satisfying this rule is collapsed with the previous one. The results using module "GOF_BB" are shown in Output 5.3.
