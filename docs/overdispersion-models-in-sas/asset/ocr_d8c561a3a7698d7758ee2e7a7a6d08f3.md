# 278 Overdispersion Models in SAS

```
****************************************************************/\n/* Module: Stage2RCM(m,T) */
/* This module performs the Two-Stage Procedure */
/* under the Random-clumped Multinomial Distribution */
/* m - cluster size */
/* T - nxk matrix of counts (ti1,ti2,...,tk) where ti is a */
/* nl vector of observed counts in category i */
****************************************************************/
Start Stage2RCM(m, T);
/* Stage 1 *
k = ncol(T);
n = nrow(T);
theta = j(k,1,0);
theta = AMLERCM(m, T);

/* Stage 2 */
pi = theta[1:(k-1)];
rho = theta[k];
INVFIM = inv(n*FIRMCM(m, pi, rho));
Old = 0;
Scores = j(k,1,0);
Do j = 1 to n;
tj = T[j,1:(k-1)];
Scores = Scores + gradRCM(m, pi, rho, tj);
Old = Old + log(ProbRCM(m, pi, rho, tj));
End;

--- Updates Theta, Step size will be halved up to 20 times --
si = 0;
Lnew = Lold - 1;
Do Until (Lnew > Lold);
theta = theta + (0.5*si)*INVFIM*Scores;
pi = theta[1:(k-1)];
rho = theta[k];
Lnew = 0;
Do j = 1 to n;
tj = T[j,1:(k-1)];
Lnew = Lold + log(ProbRCM(m, pi, rho, tj));
End;

si = si + 1;
if si > 20 then do;
print "NOTE: At Stage 2, Step size halved 20 times\nnurther improvement";
Lnew = Lold + 0.000001;
end;
End;
if si <= 20 then theta = thetaNew;
Return(theta);

Finish;
Store Module=Stage2RCM;
Quit;
Run;
```
