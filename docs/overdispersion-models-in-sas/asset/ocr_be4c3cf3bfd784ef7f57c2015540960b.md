# 5.1 Introduction

In this chapter we will consider two types of Goodness-of-fit (GOF) tests. Both types are usually referred to GOF in general, we will see that the two types have crucial differences regarding the null and alternative hypotheses. In the first type of, the null hypothesis that there is no overdispersion is tested against specific alternatives, such as the Beta-binomial or Random-clumped Binomial models. An illustration of these for overdispersion was given in Section 4.6, when we tested the hypothesis $H_0 : \rho=0$ versus the alternative hypothesis $H_1 : \rho>0$ under the Beta-binomial, Random-clumped Binomial, Zero-inflated Binomial (ZIB), and the Generalized Binomial with Additive Interaction models for the chromosome data of Table 4.1. An example of the second type of GOF testing the adequacy of a specific model was also illustrated with the chromosome data of Table 4.1.
