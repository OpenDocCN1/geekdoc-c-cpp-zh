The coefficients of kurtosis (4.25) and (4.26) of the two distributions become $\{1+6\rho(1-\pi)\}/m\pi(1-\pi)+3$ when $\rho=0$, which is the coefficient of kurtosis of the Binomial distribution. For the degenerate case $\rho=1$, the coefficient of kurtosis of the Beta-binomial and the Random-clumped Binomial distribution is $1/{\pi(1-\pi)}$. To meaningfully compare the kurtosis of the Beta-binomial and Random-clumped Binomial distributions, we consider the case $\pi=0.5$, for which both distributions are symmetric. That is, the coefficient of skewness is zero. For $\pi=0.5$, the coefficients of kurtosis of the Beta-binomial and Random-clumped distributions become:

```
Kurtosis(Beta-binomial when $\pi=0.5$) = \frac{(3m-2)+\{3m(m-1)+2\}\rho^2}{m[1+(m-1)\rho^2]^2}$ (4.27)
```

and

```
Kurtosis(Random-clumped when $\pi=0.5$) = \frac{(3m-2)+\{2(m-1)(3m-4)\rho^2+(m-1)(m-2)(m-4)\rho^4}{m[1+(m-1)\rho^2]^2}$ (4.28)
```

It can be shown that for $\pi=0.5$, the coefficient of kurtosis of the Random-clumped Binomial is less than that of the Beta-binomial $\rho<1$. The tails of any symmetric Beta-binomial distribution are heavier than that of the corresponding Random-clumped Binomial distribution. Table 4.5 depicts the value of the coefficients of kurtosis (4.27) and (4.28) for $\pi=0.5$, $\rho=0.2,0.7$, and $m=5,20$. For any given $\rho$, $0<\rho<1$, as the cluster size $m$ increases the kurtosis of both distributions tends to diverge from each other. For fixed $m$, the kurtosis of either distribution decreases as $\rho$ approaches one.

## 4.8 Generalized Linear Overdispersion Models for Binomial Responses

In this chapter, we have considered overdispersion models with a common probability of success $\pi$ and a common overdispersion parameter $\rho$. Analogous to the Binomial distribution, we introduce link functions to model the probability of success $\pi$. In addition to the parameter, we also have the overdispersion parameter $\rho$, which potentially can be different cluster to cluster. We will have two link functions: one for the probability of success and one for the overdispersion parameter. This class of models will be referred as **Generalized Linear Overdispersion Models (GLOM)**. They combine the modeling features of GLM with the distributional features of overdispersed models presented here. Cluster-specific covariates can be used on both link functions. For example, on a study with two treatments, a treatment indicator variable can be used to fit a model that allows for different probabilities of success and different degrees of overdispersion. An illustrative example will be given in section 4.9.

Suppose that $T_j, j=1,2,...,n$ are independent and independently distributed overdispersed binomial random variables with parameters $(\pi,\rho;m)$. This is the case in the example discussed in Section 4.6. The log-likelihood function can be expressed as:

```
$L(\hat{\theta};t) = \sum_{j=1}\ln[Pr(T =t_j)], \quad (4.29)$
```

where $\theta = (\pi,\rho)^T$ represents the parameter vector and $t = (t_1,t_2,...,t_n)^T$ the observed data. The MLE of $\theta$, say $\hat{\theta} = (\hat{\pi},\hat{\rho})^T$, can be found iteratively as:

```
$$\hat{\theta}^{(S+1)} = \hat{\theta}^{(S)} + I(\hat{\theta}^{(S)})^{-1}u(\hat{\theta}^{(S)}), \quad (4.30)$$
```

where $u(\hat{\theta}^{(S)})$ is the two-dimensional column vector of first derivatives of the log-likelihood function $u(\theta) = \frac{\partial L(\theta;t)}{\partial\theta}$ evaluated at $\hat{\theta}^{(S)}$, and $I(\hat{\theta}^{(S)})$ is the 2x2 Fisher information:

```
$matrix = -E \left[ \begin{matrix} \frac{\partial^2 L(\theta;t)}{\partial\theta_1^2} & \frac{\partial^2 L(\theta;t)}{\partial\theta_1\partial\theta_2} \\ \frac{\partial^2 L(\theta;t)}{\partial\theta_2\partial\theta_1} & \frac{\partial^2 L(\theta;t)}{\partial\theta_2^2} \end{matrix} \right]$ evaluated at $\hat{\theta}^{(S)}.$
```

The iterative procedure (4.30) corresponds to the Fisher Scoring Method. The subscript "s" refers to the step or iteration. The actual numerical method used may vary.

Like GLMs, the $T_j$'s are independent and belong to the same distribution, but they are not identically distributed. In other words, $T_j, j=1,2,...,n$ are distributed according to an overdispersed Binomial distribution with parameters $(\pi_j,\rho_j;m_j)$. The mean parameter $\pi_j$ is assumed to depend on a k-dimensional row vector of known covariates $x_j$ and a k-dimensional column vector of unknown parameters $\beta$, through a twice differentiable smooth function $g(\cdot)$, so that:

```
$g(\pi_j) = x_j\beta = \sum_{i=1}^k x_{ji}\beta_i. \quad (4.31)$
```

Similarly, the overdispersion parameter $\rho_j$ might depend on an h-dimensional row vector of known covariates $z_j$, and an h-dimensional column vector of unknown parameters $\alpha$, through a twice differentiable smooth function $f(\cdot)$, so that:

```
$f(\rho_j) = z_j\alpha = \sum_{i=1}^h z_{ji}\alpha_i. \quad (4.32)$
```
