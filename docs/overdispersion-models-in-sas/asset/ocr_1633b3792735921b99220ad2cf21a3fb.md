# 9.4 Estimation Methods

In SAS there are two methods for computing the model-estimators that are used in the calculation of the empirical variance estimate. The GENMOD procedure uses a moment-based methodology based on seminal papers by Liang and Zeger (1986), and Zeger and Liang (1986). On the other hand, one of the two used in GLIMMIX is a pseudo-likelihood estimation based on linearization (with Wolfinger and O'Connell, 1993). We begin with the following algorithm used by GENMOD for fitting the specified model by GEEs. Note that this is not general in a likelihood-based method of estimation, so inferences based on likelihoods are not possible for GEE methods. The algorithm used by GENMOD can be summarized as follows:

+   1. Compute an initial estimate of $\boldsymbol{eta}$ with an ordinary generalized linear model assuming independence among the repeated measurements, i.e., $\mathbf{R}(\{\alpha\})$ is an identity $m_j \times m_j$ matrix.

+   2. Compute the working correlations $\mathbf{R}(\{\alpha\})$ on the standardized residuals, which current $\boldsymbol{eta}$, and the assumed structure of $\mathbf{R}(\{\alpha\})$.

+   3. Compute the estimate of the covariance in equation (9.3).

+   4. Update $\boldsymbol{eta}_{(s+1)} = \boldsymbol{eta}_{(s)} + (\mathbf{D}^T \mathbf{V}^{-1} \mathbf{D})^{-1} \mathbf{D}^T \mathbf{V}^{-1} (\hat{\mathbf{y}} - \hat{oldsymbol{\mu}})$.

+   5. Repeat 2-4 until convergence is achieved.
