# 6.3 The Zero-inflated Poisson and Zero-inflated Negative-binomial Distributions

As stated in Section 4.3, Cohen (1966) proposed a class of mixed distributions having a probability function of the form

```
g(y; \omega, \alpha_1, \alpha_2, \dots, \alpha_k) = \begin{cases} \omega+(1-\omega)f(0), & \text{if } y=0 \ (1-\omega)f(y; \alpha_1, \alpha_2, \dots, \alpha_k), & \text{if } y \ge 1 \end{cases} \quad (6.9)
```
