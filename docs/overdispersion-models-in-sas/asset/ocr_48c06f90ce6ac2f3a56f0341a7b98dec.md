```
proc transpose data=correlated_bernoullis out=new;
  by subid;
  id i;
  var y;

run;

ods html;

  var _1 - 5;
  run;

  run;

```

Output 1.1 indicates that the mean of each $Y_i$ (as expected) approximately $\pi = \sqrt{\pi(1-\pi)} = \sqrt{(0.6)(0.4)} = 0.4849$. The estimated standard deviations are about $ho^2 = 0.3$. The estimated correlations among elemental units are about Note that the correlation structure of the repeated measures is **exchangeable**. That is, $Corr(Y_i, Y_j) = ho^2, i \neq t$, for $i=1,2,...,m$.
