To find the $eta$ that minimizes (2.4), one needs to find the vector of first derivatives of (2.4) with respect to $eta$, and equate it to zero,

```
$\frac{\partial S(\beta)}{\partial\beta} = -2X'y+2X'X\beta = 0.$\quad (2.5)
```

The solution to (2.5) is the familiar least squares estimator

```
$\hat{eta} = (X'X)^{-1}X'y.$\quad (2.6)
```

Obviously, in this simplified approach the matrix $X'X$ is of full rank.

It can be demonstrated that $\hat{eta}$, the least squares estimator of $eta$, is unbiased. Its covariance matrix is

```
$Var(\hat{eta}) = \sigma^2(X'X)^{-1}.$
```

The estimator $\hat{eta}$ is a Best Unbiased Estimator (BLUE) in the sense that it is an unbiased estimator with minimum variance among all estimators that are linear functions of the observations, that is, among estimators of the form $\hat{eta}=Ry$ where $R$ is an knx matrix of real numbers. The minimum value of the sum of squared residuals, $(y_j-\hat{y}_j)^2$, provides a natural estimator of $\sigma^2$. It can be shown that the estimator

```
$\hat{\sigma}^2 = \frac{\sum_{j=1}^n(y_j-\hat{y}_j)^2}{n-k}.$\quad (2.7)
```

is unbiased for $\sigma^2$.

The reader may have noticed that the OLS method does not require the $\varepsilon_j$'s in equation (2.1) to be normally distributed. The BLUE property holds as far as they are correlated with $E(\varepsilon_j) = 0$ and $Var(\varepsilon_j) = \sigma^2$. The Maximum Likelihood Estimator (MLE) of $\theta = (\beta', \sigma^2)$, say $\hat{	heta} = (\hat{eta}', \hat{\sigma}^2)$, can be found when the $\varepsilon_j$'s are independent and identically distributed
