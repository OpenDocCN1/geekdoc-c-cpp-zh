For instance, one might consider a model where ln(μⱼ) and log(σ_ⱼ) are both linear functions of the CD4+ cell counts. The accompanying statements for fitting a model in GENMOD are given below.

```
title "ZIP Model - UTI in Men Infected with HIV";
proc genmod data=urinary_tract_infection;
model episode = cd4 / dist=zip;
zerocodel link=logit;
```
