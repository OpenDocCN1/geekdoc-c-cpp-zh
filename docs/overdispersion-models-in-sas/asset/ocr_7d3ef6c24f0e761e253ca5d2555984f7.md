# 204 Overdispersion Models in SAS

```
$$\pi_j = g^{-1}(\mathbf{0}, x_j) \n \begin{aligned} &= g^{-1}(\mathbf{0}, x_j) \ &\vdots \ &= g^{-1}(\mathbf{0}, x_j) \end{aligned} \quad (7.6)$
```

Note that $g^{-1}(\cdot)$ is the mean function, whereas $g(\cdot)$ is the link function. When multinomial responses are ordinal, which means that the responses are qualitatively ordered, it is meaningful to model the cumulative probabilities

```
$$\sum_{h=1}^H \pi_{hj} = F(\alpha_i + x_j\beta), \quad i=1, 2, \dots, d, \quad (7.7)$
```

$F(\cdot)$ is a continuous distribution function and $\beta = (\beta_1, \beta_2, \dots, \beta_k)^T$. Note that the model consists of a common regression parameter $\beta$ and a separate intercept parameter for each response. Thus, the unknown parameter is the $(d+k)$-dimensional vector $\theta = (\alpha', \beta')^T$ with $\alpha = (\alpha_1, \alpha_2, \dots, \alpha_d)^T$. The logistic and normal cumulative distribution yield the popular link functions known as **cumulative logits** and **cumulative probs**. Cumulative logits are defined

```
$$\ln \frac{\pi_{hj}}{\sum_{h=1}^H \pi_{hj}} = \alpha_i + x_j\beta, \quad i=1, 2, \dots, d, \quad (7.8)$
```

and cumulative probs as

```
$$\Phi^{-1}(\frac{\pi_{hj}}{\sum_{h=1}^H \pi_{hj}}) = \alpha_i + x_j\beta, \quad i=1, 2, \dots, d, \quad (7.9)$
```

where $\Phi^{-1}(\cdot)$ is the inverse of a standard normal cumulative distribution function. Under the cumulative log link (7,8) it can be shown the mean function turns to be

```
$$\pi_{hj} = \frac{e^{\alpha_i + x_j\beta}}{1 + e^{\alpha_i + x_j\beta}}, \quad i=1, 2, \dots, d.$
```

Under the cumulative prob link

```
$$\pi_{hj} = \Phi(\alpha_i + x_j\beta), \quad i=1, 2, \dots, d.$
```
