## 4.4 A Zero-inflated Binomial Distribution

Cohen (1966) proposed a class of mixed distributions having a probability function of the form

```
g(x;\omega,\lambda_1,\lambda_2,...,\lambda_k) = \frac{(1-\omega) + \omega f(0), x=0}{\omega f(x;\lambda_1,\lambda_2,...,\lambda_k), x=1,2,...} (4.12)
```

where $0\le \omega\le 1$ and $f(x;\lambda_1,\lambda_2,...,\lambda_k)$ may be any discrete distribution defined over the domain $x=0,1,2,...$ with parameters $(\lambda_1,\lambda_2,...,\lambda_k)$. This distribution is useful when there is an excess of zeros, as in studies where experimental units are subjected to very low exposure. By proposing distribution (4.12), Cohen generalized the Zero-inflated Poisson distribution (Cohen, 1960) to essentially affect any discrete distribution with domain $x=0,1,2,...$. In his 1966 paper, Cohen discussed the Zero-inflated Negative-binomial. These two distributions, the Zero-inflated Poisson and the Zero-inflated Negative-binomial, will be discussed in Chapter 6. The particular case where the underlying discrete distribution is Binomial(P;m) in particular, reduces to the case Zero-inflated Binomial (ZIB) distribution with probability function

```
Pr(T=t) = \omega \binom{m}{t} P^t(1-P)^{m-t} + (1-\omega)I(t), t=0,1,...,m (4.13)
```

where $I(\cdot)$ is an indicator function. Note that distribution (4.13) is a mixture of two distributions, namely, a Binomial(P;m) with probability $P=\pi+\theta(1-\pi)$ and a degenerate distribution at zero with probability $1-\omega$. Under parameter $P=\pi+\theta(1-\pi)$, distribution (4.13) can be written as

```
Pr(T=t) = \frac{\pi}{\pi+(1-\pi)}Pr(X=t) + \frac{\theta(1-\pi)}{\pi+\theta(1-\pi)}I(t), t=0,1,...,m (4.14)
```

where $X \sim Binomial{\pi+\theta(1-\pi);m\}$. When $\theta=0$, equation (4.14) reduces to Binomial($\pi;m$) distribution. On the other hand, the case $\theta=1$ provides a Zero-degenerated distribution. If $T$ has probability function as in (4.14), $T$ will be to be distributed as a Zero-inflated binomial distribution ZIB. It can be shown that the first two moments of distribution (4.14) are

```
E(T) = m\pi (4.15)
```

and

```
Var(T) = m\pi(1-\pi)\frac{1+\theta(m-1)}{1} (4.16)
```

Thus, the Zero-inflated Binomial distribution has overdispersion relative to the Binomial distribution. Note that the overdispersion parameter $\theta$ in (4.16) represents the parameter $\rho^2$ in equation (4.5).

Park et al. (1996) provided an algorithm for generating correlated Bernoulli outcomes $Z_i$'s.

Their algorithm has clear connections with the Zero-inflated Binomial distribution. Sutradhar (2001) proved that $T = \sum_{i=1}^m Z_i$, with probability function (4.14) if Bernoulli outcomes are assumed to have common probability of success and common correlation.

## 4.5 A Generalization of the Binomial Distribution

Altham (1978) proposed two generalizations of the Binomial distribution which the Bernoulli outcomes are identically distributed but not independent. The proposed generalizations led to a two-parameter distribution where m variables are assumed to have a symmetric joint distribution with no second or higher 'order' interactions. Different generalizations are obtained depending on whether the 'additive' or 'multiplicative' definition of 'interaction' for discrete variables is used. These two generalizations allow the variance to be greater or less than the variance under the Binomial distribution. In other words, Altham's generalizations allow for either overdispersion or undersdispersion. We will focus only on the 'additive' generalization. This additive model was published simultaneously by Kupper and Haseman (1978). We will skip the details of the derivation of the Binomial distribution with Additive Interaction. Which provides the probability function

```
$Pr(T=t) = Pr(X=t) \left( \alpha \frac{t(t-1)}{\pi} + \frac{(m-t)(m-t-1)}{1-\pi} - \frac{\alpha m(m-1)}{2} +1 \right), t=0,1,...,m$ (4.17)
```

where $X = Binomial(m,\pi)$.

Altham proved that the parameter $\alpha$ is not allowed to vary freely in the $[-1, 1]$ interval. For (4.17) to be a proper probability function

```
$\frac{-2}{m-1} \min \left( \frac{1-\pi}{\pi}, \frac{\pi}{1-\pi} \right) \leq \alpha \leq U(m,\pi),$ (4.18)
```

```
$U(m,\pi) \equiv 2 m + \frac{(1-2\pi)^2}{4\pi(1-\pi)}$ for large $m$.
```

When $\alpha = 0$, distribution (4.17) corresponds to independence among the Bernoulli outcomes, that is, to a Binomial($\pi, m$). When $\alpha > 0$ ($\alpha < 0$), it corresponds to the case of over (or under) dispersion. Altham showed that for certain values of $\alpha$, distribution (4.17) is a mixture of three binomials, namely,

```
$$T = \begin{cases} A+2 & \text{with probability } \frac{1}{2}m(1-\pi) \\ B & \text{with probability } \frac{1}{2}m(1-\pi)\alpha \\ C & \text{with probability } \frac{1}{2}m(1-\pi)(1-\alpha) \end{cases} (19)
```

where $A \sim Binomial(\pi, m)$, $B \sim Binomial(\pi, m)$ and $C \sim Binomial(\pi, m)$.

## 4.6 An Example with Secondary Association (page 98)

Skellam (1948) analyzed a data set on the secondary association in Brassica, a group of temperate herbs. At meiosis, the special process of cell division, there are bivalents. A bivalent is a structure consisting of two homologous chromosomes. For a nucleus $j=1,...,n$, let $T_j$ represent the total number of bivalents showing association. If the probability of association is constant for all nuclei and is the same for all pairs of bivalents, and they act independently, the Binomial distribution would be appropriate for this. We will see that Binomial distribution does not fit the data and that overdispersion is present. Only the Beta-binomial, the Random-clumped Binomial and the Generalized Binomial with Additive provide reasonable fits.
