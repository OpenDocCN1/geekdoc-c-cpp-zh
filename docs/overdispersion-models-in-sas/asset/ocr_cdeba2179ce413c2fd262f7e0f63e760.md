If we let $T = \sum_{i=1}^{m} Y_i$, defined as in equation (1.7), it can be shown $E(T) = m\pi$ and $Var(T) = m\pi(1-\pi)+ho^2(m-1)$. Therefore, the binomial-type random variable $T$ derived from the mixture model (1) exhibits overdispersion relative to the Binomial Distribution. For $m=5$, $\pi=0.6$ and $ho^2=0.3$, the target values for the mean and the variance in the simulation are $E(T) = m\pi=(5)(0.6) = 3.00$ and $Var(T) = m\pi(1-\pi)+\rho^2(m-1)=(5)(0.6)(0.4)+(0.3)(2)=2.64$, which can be verified by adding the following statements to Program 1.1. We obtain 3.004 and 2.636 as empirical estimates of the mean and variance, respectively, in our simulation using 20,000 replications.
