We consider the ZINB GLOMM

```sas
$y_{ij} \text{ given } (x_{ij}; u_{ij}) \sim \text{Zero-inflated Negative-binomial}(\lambda_{ij}, \kappa, \omega),$
\log(\lambda_{ij}) = \beta_0 + \beta_1 x_{ij} + u_{ij}$
```

where $\kappa$ is the overdispersion parameter, $\omega$ is the additional proportion of zeros relative to the Negative-binomial distribution, $u_{ij}$ are independent and identically distributed Normal$(0, \sigma^2)$, and

```sas
$x_{ij} = \begin{cases} 1 & \text{if subject is in group 1} \\ 0 & \text{otherwise}. \end{cases}$
```

As in the ZIP GLOMM, we assume n=200, m=12, $\beta_0=0.70, \beta_1=0.40, \omega=0.20$ and $\sigma^2=1.20$. The additional parameter of overdispersion is assumed to be $\kappa=0.15$. ## Program 10.7: A Zero-inflated Negative-binomial GLOMM

```sas
/*
Generation of data under a Zero-inflated Negative-binomial GLOMM
with parameters Beta0, Betal, Kappa, W, and Sigma**2
*/
data zbind_glomm;
    beta0 = 0.70;
    betal = 0.40;
    kappa = 0.15;
    w = 0.20;
    sigma2 = 1.2;
    m = 12;
    n = 200;
    seed = 1917;
    nl = n+1;
    n2 = n+n;
    alpha = 1 / kappa;
    sigma = sqrt(sigma2);
    do i=1 to n;
        u = uniform(seed);
        if u > w then do;
            Group = 1;
            mu = exp(Beta0+Betal+u); /* Note: original OCR likely had typo 'z' for 'u' */
            kappa = kappa * mu;
            beta = rang(seed,alpha);
            Y = ranpoi(seed,u);
            output;
        end else do;
            Group = 2;
            Y = 0;
            output;
        end;
    end;
    do i=n+1 to n2;
        z = Sigma*(seed);
        do t=1 to m;
            u = uniform(seed);
            if u > w then do;
                Group = 0;
                mu = exp(Beta0 +z);
                kappa = kappa * mu;
                beta = rang(seed, alpha);
                Y = ranpoi(seed, u);
                output;
            end else do;
                Group = 1;
                Y = 0;
                output;
            end;
        end;
    end;
    keep t group y;
run;
```

  parms b0=0.49 b1=0.3 kappa=0.8 w=0.1 0.2 sigma=1.13;
  bounds kappa > 0 and kappa < 1;
  mu = exp(b0+b1*group);
  a = 1/kappa;
  p = lgamma(kappa*a);
  z = lgamma(y+a) - lgamma(y+1);
  if y<=0 then
    ll = log((1-w)*p);
  else ll = log(w) + a * log(p) + y * log(1-p);
  model y = ll;
  random u-normal(0,sigma) subject=id;
  estimate "Expected Counts Group 1" (1-w)*exp(b0+b1);
  estimate "Expected Counts Group 0" (1-w)*exp(b0);
  estimate "Ratio Expected Counts Group 1 Va 0" exp(b1);
  estimate "Sigma*2" sigma*sigma;
run;
ods close;

## 10.7 Concluding Remarks

In this chapter, we presented some fundamental concepts regarding Generalized Linear Mixed Models (GLMM). We highlighted the estimation method known as Maximum Likelihood, based on adaptive Gauss-Hermite quadrature, which is the estimation method used in all the examples in this chapter. This is one of the methods used in the GLIMMIX procedure. The other method, the Pseudo-likelihood method based on linearization, was discussed in Chapter 9. Examples, the Multenter Randomized Trial of Section 10.2 and the Pump Reliability at a Pressed Water Reactor Nuclear Power Plant of Section 10.3, were used to illustrate the fitting of a Binomial and a Poisson GLMM. A third example, the Shoulder Study discussed in Section 9.9, was revisited in the context of a Multinomial GLMM.
