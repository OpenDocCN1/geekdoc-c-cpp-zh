

# SAS 中的过度离散模型

如果 $\tilde{\pi}_j = \frac{t_j}{m_j}$ 是一个观测到的比例，则其对应的对数几率定义为

```
$$\ln\left(\frac{\tilde{\pi}_j}{1-\tilde{\pi}_j}\right) = \ln\left(\frac{t_j}{m_j-t_j}\right)$$$
```

在实践中，这些量略作修改为

```
$$\ln\left(\frac{t_j+0.5}{m_j-t_j+0.5}\right)$$$
```

以避免当 $t$ 为零或 $m$ 时的数值问题。估计的线性预测值为 $\hat{\eta}_j = \hat{\beta}_0 + \hat{\beta}_1X_j$。编程语句在程序 2.2 中提供。GLIMMIX 产生的结果在输出 2.2 中提供。

在剂量死亡研究中，感兴趣的量是 LD50，即对 50% 的人群致死的剂量。该量也可以被视为人群的中位耐受水平。在逻辑回归模型下，LD50 可通过求解

> $\beta_0 + \beta_1 LD50 = \ln\left(\frac{\pi}{1-\pi}\right)$

取 $\pi=\frac{1}{2}$ 得到。在这种情况下 $\frac{\pi}{1-\pi}=1$，因此，$LD50=\frac{\beta_0}{\beta_1}$。在 Murray 的例子中，

LD50 的估计值为 $\frac{10.3279}{2.4582}=4.2014$。该剂量在自然对数尺度上。

然后，LD50 为 $e^{4.2014}=66.78$ mg/100 cc 。

## 第 2 章 广义线性模型

我们为 Murray 的数据拟合一个 Probit 模型。在 Probit 模型中，均值函数定义为

$\pi_j = \Phi(\mathbf{x}_j\boldsymbol{\beta})$

其中 $\Phi(\cdot)$ 是标准正态分布的累积分布函数。因此，Probit 连接为

$\Phi^{-1}(\pi_j) = \beta_0 + \beta_1\mathbf{x}_j$

请注意，使用 Probit 连接时，估计的线性预测值 $\hat{\eta}_j = \hat{\beta}_0 + \hat{\beta}_1\mathbf{x}_j$ 为 Z 分数。预测得分为零的受试者有 50% 的概率，预测得分为 1.64 的受试者有 95% 的概率，等等。使用 GLIMMIX 拟合 Probit 模型的编程语句包括诊断图为

```
ods html;
ods graphics on;
title "Dosage-Mortality of pyrethins on Male Flies, Murray (1938)"
title2 "GLM with Binomial Distribution and Probit Link";
proc glimmix data=pythrins plots=residual;
model t/m = x / dist=binomial link=probit;
run;
ods graphics off;
ods html;
```

我们跳过了输出的描绘。表 2.5 总结了最大似然结果。

LD50 通过求解方程得到

$\beta_0 + \beta_1 LD50 = \Phi^{-1}(\pi)$

其中 $\pi =\frac{1}{2}$。对于该值 $\Phi^{-1}(\pi) = 0$，与逻辑回归情况相同，LD50 = $-\frac{\beta_0}{\beta_1}$。使用表 2.5 中提供的估计值，LD50 的估计值为 4.1972，尺度为 $e^{4.1972}=66.50$ mg/cc，几乎与逻辑模型下得到的值相同。GLIMMIX 残差诊断图在图 2.3 中显示。请注意，大多数残差为非负，并且残差与分位数图显示出与直线的一定偏离。比较图 2.2 和图 2.3 得出一个结论，在此特定示例中，Probit 模型提供了更好的拟合。之前的结论。

## 程序 2.3：使用 PROC PROBIT 对拟雷氏剂量-死亡数据拟合 Probit 和 Logit 连接的二项模型

```
ods html;
title1 "Dosage-Mortality of Pyrethins on Male Flies, Murray (1938)"
title2 "GLM with Binomial Distribution and Logit Link using PROC PROBIT";
proc probit data=pyrethins log;
model t/m = dose / logistic inversecl;
run;
title "Dosage-Mortality of Pyrethins on Male Flies, Murray (1938)"
title2 "GLM with Binomial Distribution and Probit Link using PROC PROBIT";
proc prob data=pyrethins log;
model t/m = dose / inversecl;
run;
ods html;
```

PROC 中的 "log" 选项请求对剂量的自然对数进行分析。选项 "inversecl" 提供从杀死人群 1% 到 99% 的 1% 增量的致死剂量 (LD) 估计。这些 LD 在对数尺度和剂量尺度上计算。选定的结果在输出 2.3 中产生。
