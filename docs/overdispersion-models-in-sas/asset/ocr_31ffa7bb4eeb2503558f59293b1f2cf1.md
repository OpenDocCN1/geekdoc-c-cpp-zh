# 9.6 An Example on Seizure Counts for Epileptics

Thall and Vail (1990) analyzed data from a clinical trial aimed to study the efficacy of the antiepileptic drug Progabide. Patients suffering from partial or complex partial seizures were randomized to receive either Progabide or a placebo. There was a lead-in phase lasting eight weeks where patients were not exposed to any treatment. The number of seizures during this eight-week period was recorded and used as a baseline. Randomization was performed at the end of this period, which was followed by a treatment phase lasting eight weeks. During this period, each patient reported to the clinic for an assessment every two weeks and reported the number of epileptic seizures occurring during the previous two weeks. Although each patient was "crossed over" to the other treatment, only the baseline data and the data from the four visits during the treatment phase are analyzed.

Let Y_ij denote the number of seizures reported by subject i, i = 1,2,...,59 in time interval j, j = 1,2,...,5 of length t_ij. Note that j = 1 represents the baseline with an eight-week duration, and j ≥ 2 represents the four treatment phase visits with a two-week duration each. Then, Y_ij / t_ij represents the number of seizures for time unit. Thus, the model being fit is the log-linear model with logarithm of t_ij as an offset;

```
ln{ E(Y_ij) } = β0 + β1 X_i1 + β2 X_i2 + β3 X_i1 X_i2 + ln(t_ij),   (9.9)
```

where X_ij = { 1 if Treatment Phase
2 if Baseline }
