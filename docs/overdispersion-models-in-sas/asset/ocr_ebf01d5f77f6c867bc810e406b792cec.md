The quasi-likelihood estimate of $\beta$, say $\hat{eta}$, is obtained by solving (3.3) with respect to $\beta$, that is,

```
U(\eta) = \frac{\hat{Q}(y, \mu)}{\hat{\beta}} = 0. (3.4)
```

The function **U(\eta)** in (3.4) is the **quasi-score function**. By (3.2) equation (3.4) can be written as

```
\sum_{j=1}^n \frac{Y_j - \mu_j}{\phi(\mu_j)}} \frac{\hat{\mu}_j}{\hat{\beta}} = 0. (3.5)
```

The solution of (3.5) with respect to $\beta$ does not require knowledge of $\phi$ since $\phi$ is a scale parameter and cancels out. Therefore, these equations reduce to

```
\sum_{j=1}^n \frac{Y_j - \mu_j}{\phi(\mu_j)}} \frac{\hat{\mu}_j}{\hat{\beta}} = 0,
```

which are, from a computational point of view, if the $Y_j$'s belonged to one of the members of the exponential family for which $\phi=1$. As in the case with GLMs, the solution to (3.5) is equivalent to the iterative weighted least-squares procedure in Section 2.6. With $\hat{eta}$ in hand, a moment estimator of the dispersion parameter $\phi$ can be computed. Two commonly used estimates of $\phi$ are obtained by normalizing the Pearson $X^2$ or the Deviance, by dividing its degrees of freedom. Other moment estimators are also possible.

Under mild regularity conditions, the asymptotic variance of the vector of parameter estimates is given by

```
Var(\\hat{\beta}) \equiv \phi(\mathbfmathbf{D}'\mathbf{V}^{-1}\mathbf{D})^{-1}. (3.6)
```

where **\mathbf{D}** is the nx matrix of first derivatives

```
\mathbf{D} = (\frac{\hat{\mu}_1}{\hat{\beta}}, \frac{\hat{\mu}_2}{\hat{\beta}}, \dots, \frac{\hat{\mu}_n}{\hat{\beta}})^' \equiv (\mathbf{d}_1, \mathbf{d}_2, \dots, \mathbf{d}_n)'
```

and **\V** is the nxn diagonal matrix of variance functions

```
\mathbf{V} = \mathbf{Diag}(v(\mu_1), v(\mu_2), \dots, v(\mu_n)) \equiv \mathbf{Diag}(v_1, v_2, \dots, v_n).
```
