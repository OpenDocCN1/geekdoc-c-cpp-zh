# **Program 4.1: Maximum Likelihood Estimation of Chromosome Data under Five Distributions**

> * Maximum Likelihood Estimation Skellam's (1948) Chromosome Data Example under the following distributions:
Binomial, Beta-binomial, Random-clumped Binomial, Zero-inflated Binomial and a Generalized-Binomial Distribution with Additive Interaction

```
data chromosome;
m = 3;
input freq;
n+ freq;
if n = 4 then
 call symput('n',trim(left(n))); --- "n" is total number of clusters;
drop n;

```

```
title 'Random-clumped Binomial Distribution';
proc nmlixed data=chromosome;
parms Pi=0.4 0.5 0.6, Rho=0.2 0.3 0.4;
bounds 0 < rho < 1;
c = 1 / rho - rho - 1;
z = lambda(t) - lambda(m-t+1);
pic = 1 - pi;
freq = * (z + lambda(c) + lambda(t*c) + lambda(m-t+c)*pic)
lambda(m-c) - lambda(c*pi) + lambda(c*pic);
model t = general(l);
predict pred & * exp(z + lambda(c) + lambda(t*c) + lambda(m-t+c))
lambda(m-c) - lambda(c*pi) + lambda(c*pic) out=pred2;
```
