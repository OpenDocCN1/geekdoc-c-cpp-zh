# 9.6 An Example on Seizure Counts for Epileptics

Thall and Vail (1990) analyzed data from a clinical trial to study the efficacy of the antiepileptic drug Progabide. Patients suffering from partial or complex seizures were randomized to receive either Progabide or a placebo. There was a lead-in phase lasting eight weeks where patients were not exposed to treatment. The number of seizures during this eight-week period was recorded and used as a baseline. Randomization was performed at the end of this period, which was followed by a treatment phase lasting eight weeks. During this period, each patient reported to the clinic for an assessment every two weeks and reported the number of epileptic seizures occurring during the two weeks. Although each patient "crossed over" to the other, only the baseline data the data from the four visits during the treatment phase are analyzed.

$Y_{ij}$, denote the number of seizures reported by subject $i$, $i=1, 2,...,59$ in time interval, $j=1, 2,...,5$ of length $t_{ij}$. Note that $j=1$ represents the baseline with an eight-week duration, and $j \geq 2$ represents the four treatment phase visits with a two-week duration. Then, the number of seizures per time unit fits the log-linear model with logarithm of time as an offset,

```
$E(Y_{ij}) = \beta_0 + \beta_1 X_{i1} + \beta_2 X_{i2} + \beta_3 X_{i1} X_{i2} + \ln(t_{ij}), \quad (9.9)$ $
```
