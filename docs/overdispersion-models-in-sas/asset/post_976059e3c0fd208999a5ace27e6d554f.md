## 1.4 An Extended Definition of Overdispersion

There are many cases of overdispersion. In the case of the Binomial/Multinomial distribution, overdispersion results when either the assumption of independence (within elemental units) or common probability of success is violated. In the case of the Poisson distribution, overdispersion is observed when the rate of the events varies subject to subject; such rates are assumed to be distributed as a Gamma variable. Overdispersion arises in a natural way of clustered data. It is found in case of longitudinal data with repeated measurements. Observed counts on subjects usually exhibit overdispersion. For instance, think of a clinical study of osteoporotic patients at high risk for vertebral fractures. The number of incidents is measured over a given period. The same patient may suffer multiple occurrences and thereafter make several contributions to the count, which leads to the violation of the "independent occurrences" assuming the Poisson distribution. Therefore, the cases are not truly arising from a Poisson distribution and thus exhibit overdispersion.

The developments in the last 20 years or so on mixture distributions and Generalized Linear Mixed Models (GLMM) have brought overdispersion to full. Overdispersion has surpassed its boundaries; it is a broader topic than the common characterization provided in Section 1.2. Mixtures of Multinomial distributions, such as the Dirichlet-multinomial (Mosimann, 1962) and the Random-clumping distribution proposed by Morel and Nagaraj (1993) and Neerchal and Morel (1998), have overdispersion relative to the multinomial distribution with the mean vector and variance-covariance matrix, as in (1.3) and (1.4). The Negative-binomial distribution with mean and variance, as depicted in equations (1.5) and (1.6), exhibits overdispersion relative to the Poisson distribution. A Binomial distribution with random effects properly defined has overdispersion relative to the Binomial model. Additionally, a Beta-binomial distribution with random effects has overdispersion relative to the Beta-binomial, and the Beta-binomial itself has overdispersion relative to the Binomial distribution. The list goes on and on. Appendix 1.1 in this chapter shows some hierarchical diagrams of overdispersion that we intend to cover in this book.

## 1.5 A Simulated Example

A simple way of simulating correlated Bernoulli trials is as follows. Let Y, Y_i^0, ..., Y_m^0 be independent and identically distributed Bernoulli ( ) random variables. For each i,i=1,...,m, define Y_i as Y with probability ρ, or as Y_i^0 with probability (1-ρ),0ρ≤1. In other words, each Y_i can be represented by the

```
Y_i = Y I(U_i ≤ ρ) + Y_i^0 I(U_i > ρ),                               (1.7)
```

where the U_i are independent uniform (0,1) random variables, and I() denotes an indicator function. in for clustered data,

E(Y) = ρ, Var(Y) = ρ(1-ρ) and Corr(Y_1, Y_2) = ρ².

The programming statements for generating data under model (1.7) are provided next for m=5, ρ=0.6 and ρ²=0.3. Note that n=2000 clusters are being generated, each consisting of a string of m=5 correlated binary outcomes.

### Program 1.1: Correlated Bernoulli Outcomes

```
/*
Generation of correlated Bernoulli outcomes
For Y(1),Y(2),...,Y(m)
E(Y)
Pi
Var(Y)
Pi*(1-Pi)
Corr(Y(i), Y(j))
Rho*Rho
*/
data correlated bernoulli;
n = 20000; --- Number of clusters;
m = 5; --- Number of elemental units within the cluster;
pi = 0.6; --- Probability of success of each elemental unit;
rho2 = 0.3; --- Intra-cluster correlation;
seed = 16670;
rho = sqrt(rho2);
do subid = 1 to nr; --- Variable yj plays the role of y of eq. (1.7)
y = 0;
u = uniform(seed);
if u < pi then y = 1;
if i=1 to m;
y = 0;
u = uniform(seed);
if u < rho then y = y;
else do;
uu = uniform(seed);
if u < pi then y = 1;
end;
output;
end;


keep subid i;
run;
```

Recall that one of the consequences of overdispersion in the data is inflated Type Errors. Program 1.1 can be easily extended to a simulation to demonstrate this undesirable effect. To this end, consider a sample of n=20 clusters each size m=5. The elemental units within the clusters are treated as independent, then we will have a total of 120 Bernoulli trials with the same probability of success π. We need to test the null H₀:π=0.6 versus the alternative hypothesis H₁π>0.6. For the binomial distribution, the Z-test at α=0.05 is to reject the null when

$Z = \frac{\pi-0.6}{\sqrt{\pi(1-\pi)}}} > 1.644$. An estimate of the true Type I Error can be obtained by

performing this on a series of overdispersed data sets generated to be 0.160, and then by computing the number of rejections. Program 1.2 provides the necessary statements to perform this simulation.

### Program 1.2: Estimating Type I Error Rate for Data Created in Program 1.1

```
* Estimating actual Type I Error rate for overdispersed data;
data correlated_bernoulli; --- This data was created in Program 1.1;
    set correlated_bernoulli;
    reps = ceil(id / 20); --- Creates 1000 reps of n=20 clusters of size m=5 each;
run;
proc means data=correlated_bernoulli mean noprint;
    class reps;
    var yr;
    output=test mean=Pi_hat;
run;
data test;
set test;
    if _type_ = 1;
    z = (Pi_hat - 0.6) / sqrt(Pi_hat*(1-Pi_hat) / 100);
    p Val = 0;
    if z > 1.644 then p Val = 1;
run;
title "Monte Carlo Estimate of Type I Error Rate";
proc means data=test mean maxdec=3;
    var P_val;
run;
```

$\rho^2=0.3$, the estimated Type I Error runs out 0.160, about three times the nominal level of 0.05. We can now rerun Programs 1.1 and Program 1.2, appropriately concatenated for other values of $\rho^2$. The following table provides a summary for three runs using the same seed above convenience.
