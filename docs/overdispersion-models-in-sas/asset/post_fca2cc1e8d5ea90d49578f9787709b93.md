Note that the default parameterization (called the "effects" parameterization) used by the LOGISTIC procedure provides estimates of the difference in each non-reference level compared to the average effect over all levels. Using the previously dummy variables S1, S2 and P, the two logit models being fitted are

```
$$\begin{aligned} \ln\frac{\pi_{sp1}}{1-\pi_{sp1}} &= \beta_{10} + \beta_{11}S_1 + \beta_{12}S_2 + \beta_{13}P_1 + \beta_{14}S_1P_1 + \beta_{15}S_2P_1 \\ \ln\frac{\pi_{sp2}}{1-\pi_{sp2}} &= \beta_{20} + \beta_{21}S_1 + \beta_{22}S_2 + \beta_{23}P_1 + \beta_{24}S_1P_1 + \beta_{25}S_2P_1 \end{aligned}$$
```

Odds-ratios can be obtained from any of the two equations and are provided by the ODDSRATIO statement. These equations correspond to the logits based on the learning style preferences, namely, Self versus Class, and Team Class. Care should be exercised in computing odds-ratios since the School-by-Program interaction is present. For instance, in order to compute the odds-ratio for Afternoon Program versus Regular at School=1 from the first equation (learning style preference Self versus Class), one needs to compute the following log-odds:

| Logarithm of Odds | Parameter |
|---|---|
| Afternoon Program at School 1 | $\beta_{10} + \beta_{11} - \beta_{13} - \beta_{14}$ |
| Regular Program at School 1 | $\beta_{20} + \beta_{21} - \beta_{23} + \beta_{24}$ |

The logarithm of the odds-ratio under consideration is the difference of the above log-odds, that is $-2\beta_{13} - 2\beta_{14}$. Thus, the desired odds-ratio is

```
$e^{-2\beta_{13}-2\beta_{14}}$
```

# 7.5 Quasi-likelihood Models

A straightforward approach to handle overdispersion in multicategory counts is to multiply the multinomial covariance matrix by a scalar. A quasi-likelihood approach using a scale adjustment is presented in Chapter 5 of McCullagh and Nelder (1983). As pointed earlier in Chapter 3 in the context of binomial responses, commonly used methods to inflate (or deflate if underdispersion is present) the variance estimates are based on the Deviance and the Pearson’s Chi-square statistics. These single-variance inflation methods can be extended to multinomial responses. To that end, let us assume, as we do in Section 7.3, a sequence of d-dimensional Multinomial-type random vectors T₁, T₂, ..., Tn such that for each j = 1, 2, ..., n

```
E(T_j) = m_j\pi_j, \quad (7.15)
```

with $\pi_j$, as in (7.6). In its simplest form, overdispersion in the Multinomial distribution can be represented by multiplying the multinomial variance-covariance matrix (7.5) by an unknown scale parameter $\phi$. That is,

```
Var(T_j) = m_j\Delta(\pi_j). \quad (7.16)
```

As in Chapter 3, a consistent estimator of the scale parameter $\phi$ can be obtained either from the Deviance or the Pearson’s Chi-square statistic, each of them by their degrees of freedom. For multinomial responses, the Deviance and the Pearson’s Chi-square statistic are defined as

```
D = 2\sum_{j=1}^{n} \sum_{i=1}^{d_j} \log(\frac{t_{ij}}{m_j\pi_{ij}}), \quad (7.17)
```

and

```
X^2 = \sum_{j=1}^{n} \sum_{i=1}^{d_j} \frac{(t_{ij} - m_j\hat{\pi}_{ij})^2}{m_j\hat{\pi}_{ij}^2}, \quad (7.18)
```

with $\hat{\pi}_{(d+1)} = 1 - \sum_{i=1}^{d}\hat{\pi}_i$. The Pearson’s Chi-square statistic can also be expressed as

```
X^2 = \sum_{j=1}^{n} m_j(T_j - m_j\hat{\pi}_j)^T \Delta^{-1}(T_j - m_j\hat{\pi}_j), \quad (7.19)
```
