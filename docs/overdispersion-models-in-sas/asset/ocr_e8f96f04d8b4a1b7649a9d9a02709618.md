The response, indicates a learning style preference, is nominal since there is not a natural ordering among the possible alternatives (Self, Team, Class). We thus fit a Generalized Logits Model as in equation (7.10). Let $\pi_{sp}$ represent the probability that a student in school (s=1,2,3) and program (p=1 if=Program and p=2 if=After) prefer learning style (i=1 if=Self, i=2 if=Team and i=3 if=Class). The reference style is Class. There are two types (d=2) based on comparing the style Class (i=1) versus Class (i=3), and the style team (i=2) versus Class (i=3). Each logit is a function of the factors School, Program, and the School-by-Program interaction. Program 7.1 provides the programming statements for fitting the School Data with generalized logits using the LOGISTIC procedure. When there are more than two response levels, PROC LOGISTIC fits the cumulative logit model unless the LINK=option is specified.

# Program 7.1: Fitting the School Data with Generalized Logits

```
/* Program Example
from Stokes, Davis, and Koch (2000)
Fitting of a Generalized Logits */

data school;
  length Program $ Style $ Count @@@
datalines;
  1 regular 10 1 regular team 17 1 regular class 26
  1 afternoon self 5 1 afternoon team 12 1 afternoon class 50
  2 regular 21 2 regular team 17 2 regular class 26
  2 afternoon self 16 2 afternoon team 12 2 afternoon class 36
  3 regular self 15 3 regular team 15 3 regular class 16
  3 afternoon self 12 3 afternoon team 12 3 afternoon class 20
;

ods html;
 graphics on;
proc logistic data=school;
  freq Count;
  class Program(ref=School);
  model Style(order=data)=School Program*Program / link=logit;
  oddsratio program;
run;
ods graphics off;
 html close;
```

The Class statement of the LOGISTIC procedure generates appropriate dummy variables to fit the model requested in Program 7.1. Output 1 provides the definition of the dummy variables. It is important to know that these dummy variables are created so we can construct estimates of the odds-ratings as needed for the analysis.
