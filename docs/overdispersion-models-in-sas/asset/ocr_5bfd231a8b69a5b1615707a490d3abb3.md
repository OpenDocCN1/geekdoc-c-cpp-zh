Similarly, the probability function (6.9) can be also extended to the Negative-binomial distribution. If $f(\mu,\kappa)$ corresponds to the probability function of a NB distribution with parameters $(\mu,\kappa)$, then the probability function of a Zero-inflated Negative-binomial (ZINB) with parameters $(\mu,\kappa)$ is given

```
$Pr(Y=y)=\omega Ill(y=0)+(1-\omega)\frac{\Gamma(y+\frac{1}{\kappa})}{\Gamma(\frac{1}{\kappa})\Gamma(y+1)}\left(\frac{\kappa\mu}{1+\kappa}\right)^y,y=0,1,...$ (6.14)
```

In the case of the ZIP distribution, zeros in the ZINB distribution arise from different sources, namely a zero-degenerate distribution with probability $\omega$, and from a Negative-binomial(\mu,\kappa)$ with probability $(1-\omega)$. Observe that distributions (6.10) and (6.13) are both finite mixture distributions. Show that the mean and variance of the ZINB distribution are

```
$E(Y)=(1-\omega)\mu$ (6.15)
```

and

```
$Var(Y)=(1-\omega)\{\mu(1+\kappa)+\omega^2\}.$ (6.16)
```

In the case of the ZIP distribution, the fact that

```
$Var(Y)=(1-\omega)\{\mu(1+\kappa)+\omega^2\>}(1-\omega)\mu=E(Y)$
```

indicates that an excess of zeros in the NB distribution implies overdispersion. Again, overdispersion refers to comparing the mean with the variance. As in the case of Poisson, there is no direct comparison for variance of ZINB and NB. Also, note that

```
$(1-\omega)\{\mu(1+\kappa)+\omega^2\>}(1-\omega)(\mu+\omega^2)$
```

which indicates that the ZINB data exhibits more variability than ZIP while retaining the same proportion of excess zeros. This is analogous to the fact NB exhibits overdispersion relative to Poisson.
