```
/*

ods html;

ods html close;
```

The maximum likelihood results are provided in Output 7.3. It can be seen (Morel 1992) that the Dirichlet-multinomial and the Random-clumped Multinomial distributions are identical when the cluster size is two. Furthermore, we have found that two distributions provide essentially the same fit for examples with small cluster sizes. In this example, where cluster size is five, the two models seem to produce almost identical results.
