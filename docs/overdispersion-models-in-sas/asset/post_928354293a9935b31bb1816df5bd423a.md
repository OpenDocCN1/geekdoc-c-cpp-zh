Purpose: To write a SAS macro in order to compute MLE and perform GOF-test under Beta Binomial distribution. This GOF_BB macro computes the MLE iteratively using the Fisher-Scoring method based on Direct Likelihood. Required: To call other module in fisherbb.sas

# Chapter 5 Goodness-of-fit Tests for Overdispersed Binomial Models 139

List of variables:
inds = input SAS data (MUST contain two variables t, m)
t = cluster count
m = cluster size

Usage: %GOF_BB(inds=inds, t=t, m=m, title2=data set)

Comment: Varying cluster sizes (m) were assumed. Initial number of classes to GOF = MAX(m)+1

```sas
%macro GOF_BB(inds , t, m, title2 = "Data: ");
title "Goodness-of-fit test under Beta Binomial distribution"
title2 "&title2";

* Starting IML procedure;
proc iml;

* Print input information;
file print;

* Module: FISHERB: This module can be called to compute Fisher information under BB distribution;

```sas
start FISHERB;
do ij = 1 to m;
    AH = j(2,2,0);

    do i = 1 to mj[ij]+1;
        u = -1;
        mct = exp(gamma(mj[ij]+1)-gamma(u+1)-gamma(mj[ij]-u+1));
        part1 = exp(gamma(c)-gamma(mj[ij]+c));
        part2 = exp(gamma(u*pi)-gamma(c*pi));
        part3 = exp(gamma(mj[ij]-u+c*-pi)-gamma(c-1*pi));

        pt = (mct*part2*part3);

        aux3 = 0;
        aux2 = 0;
        aux1 = 0;

        aux3 = sum(1/(c;c+mj[ij] = 1));
        if (u > 0) then aux1 = sum(1/(c:pi + u -1));
        if (u < mj[ij]) then aux2 = sum(1/(c:cpic+mj[ij] - u));

        derbb1 = c*(aux1-aux2);
        derbb2 = (pi*aux1+pi*aux2-aux3) b;

        * Compute Fisher information for each different;

        AH[1,1] = AH[1,1] + derbb1*pt;
        AH[1,2] = AH[1,2] + derbb2*pt;
        AH[2,2] = AH[2,2] + derbb2*pt;
        * end =;
    end;
end;
```
