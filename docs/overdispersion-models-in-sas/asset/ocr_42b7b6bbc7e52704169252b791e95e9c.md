# Table 7.8: Guidelines for Interpreting Kappa

| Kappa | Interpretation |
| --- | --- |
| < 0 | No agreement |
| 0.0 — 0.20 | Very low agreement |
| 0.21 — 0.40 | Low agreement |
| 0.41 — 0.60 | Moderate agreement |
| 0.61 — 0.80 | Full agreement |
| 0.81 — 1.00 | Almost perfect agreement |

According to these guidelines, any value of the Kappa coefficient greater than 0.60 is considered either full agreement or almost perfect agreement. Since the point estimate of Kappa in Sissel's and Ebert's ratings was 0.38 with an approximate 95% confidence interval of about (0.26, 0.51), one might say, based on the above guidelines, that the agreement between the two movies was between low and moderate.

# ## Appendix 7.1: Data Generation under the Dirichlet-multinomial and Random-clumped Multinomial Distributions

In this appendix, we describe the generation of a random sample $\mathbf{t}_1, \mathbf{t}_2, \dots, \mathbf{t}_n$ under either the Dirichlet-multinomial or the Random-clumped Multinomial distribution.

Under the Dirichlet-multinomial model, a random sample $\mathbf{p}_1, \mathbf{p}_2, \dots, \mathbf{p}_n$ is first generated from a (d+1) dimensional Dirichlet distribution density function

```
$f_D(\mathbf{p}; \alpha_1, \alpha_2, \dots, \alpha_{(d+1)}) = \frac{\Gamma(\alpha_1 + \alpha_2 + \dots + \alpha_{(d+1)})}{\prod_{i=1}^{d+1} \Gamma(\alpha_i)} \prod_{i=1}^{d+1} p_i^{\alpha_i-1}$
```

where $\alpha_i = c\pi, i=1,2,\dots,(d+1), c = \rho^2(1-\rho), 0 < \rho < 1,$ and $\Gamma(\cdot)$ denotes the gamma function. Then, given $\mathbf{p}_j, j=1,2,\dots,n, \mathbf{t}_j$ is generated from a Multinomial distribution with parameters $\mathbf{p}_j$ and $m$.
