## 6.5 Generalized Linear Overdispersed Models for Count Responses

In the context of Generalized Linear Overdispersed Models (GLOM), the mean parameter $\mu$ (mean), the overdispersion parameter $\kappa$, and in the case of ZIP and ZINB distributions, the weight parameter to depend on known covariates and unknown parameters via appropriate link functions. In practice it is possible to have families of link functions for the three parameters previously discussed. Extending the ideas in Section 4.8, let us assume $Y_{j,j=1,...,n$ are independent random variables with a probability function as in (6,6), (6.10) or (6.13). Associated with each cluster $j=1,2,...,n$ there be:

(1) a $k$-dimensional row vector of covariates $x_j$ and a $k$-dimensional column vector of unknown parameters $\beta_j$,
(2) an $r$-dimensional row vector of known $v_j$, and an $r$-dimensional column vector of unknown parameters $\delta_j$,
(3) an $s$-dimensional row vector of known parameters $z_j$ and an $s$-dimensional column vector of unknown parameters $\alpha$ such that

These functions $f(.)$, $g(.)$, and $h(.)$ are twice differentiable smooth functions. There are, that the reader might have noticed, three linear parameters, namely $\eta_{1} = \mathbf{x}\mathbf{\beta}$, $\eta_{2} = \mathbf{v}\mathbf{\delta}$ and $\eta_{3} = \mathbf{z}\mathbf{\alpha}$. Maximum likelihood estimates can be obtained iteratively using appropriate numerical methods.

Currently, GENMOD, GLIMMIX, and COUNREG procedures support maximum likelihood estimation using the Negative-binomial distribution, with COUNREG allowing for linear and quadratic variance functions. GENMOD and COUNREG handle Zero-inflated Poisson (ZIP) and Zero-inflated Negative-binomial (ZINB) models. Both procedures permit the use of link functions, such as the log and profit, on the Zero-inflation Probability parameter. The ZIP and ZINB distributions can be fit using the NLMIXED procedure, which requires the user to write his/her own programming statements.

## 6.6 An Example of Urinary Tract Infections (UTI) in Men Infected with HIV

Van den Brooks (1995) proposed a score test for testing the Zero-inflation probability parameter $\omega$ in the case of the Zero-inflated Poisson distribution (6.10), which permits us to test whether the number of zeroes is too large to fit the Poisson distribution. Van den Brooks's test is illustrated using data from a study conducted in the Department of Internal Medicine at the Utrecht Hospital, the Netherlands, where $n=98$ human immunodeficiency virus (HIV)-infected men were followed for two years. Urinary cultures were obtained during the first visit and every six months when symptoms of urinary tract infections (UTI) occurred, or when patients had fever. CD4+ counts were also measured to determine how well the immune system working in people who have been diagnosed with immunodeficiency (HIV). A normal CD4+ count ranges from 500 to 1500 cells per milliliter. In general, a decreasing CD4+ count is an indication of the progression of HIV. This means that the immune system is getting weaker; as a result, the patient is more likely to get sick. For more details on this we refer to Hoopelman et al. (1992).
