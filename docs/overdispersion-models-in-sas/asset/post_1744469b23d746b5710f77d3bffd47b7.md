```sas
ods html;
title "Pump Reliability at a Pressured Water Reactor Nuclear Power Plant";
proc glimmix data=pump method=quad;
  class group;
  model y = group logstd*group / noint dist=poisson link=log
    solution ddfm=residual;
  random it / subject=pump;
  estimate "Difference Y-intercepts" group 1 -1;
  estimate "Difference Slopes" group 1 -1;
run;
ods html close;
```

In Analysis of Covariance, with response Y and covariate X, the "MODEL Y = X GROUP X*GROUP," provides a test of parallelism of the straight lines among the groups (equality of slopes). A re-parameterization of the previous ANCOVA model as "MODEL Y = X*GROUP / NOINT," provides unbiased estimates of both the y-intercepts and the slopes of the regression lines. The latter re-parameterization has been requested in Program 10.2 through GLIMMIX for the Poisson GLMM described in (10.13). Output 10.2 provides excerpts from the output of Program 10.2.

Furthermore, the slopes are not statistically different (P-value=0.2633). The programming statements for fitting the Poisson GLMM (10.13) using NLMIXED procedure are given below. For the degrees of freedom, which in GLMIX are 6 due to the option "residual" and in NLMIXED, the results are identical.

```sas
proc nlmixed data=pump;
  parms logstd 0 beta1 beta2 1 alpha1 alpha2 1;
  if (group = 1) alpha = alpha1+ beta1*logstd;
  else alpha = alpha2+ beta2*logstd;
  lambda = exp(alpha);
  y = poisson(lambda);
  random = normal(0,exp(2*logstd)) subject=pump;
  estimate 'alpha-alpha2' alpha-alpha2;
  estimate 'beta-beta2' beta-beta2;
  estimate 'Sigma*' exp(2*logstd);
run;
```

# 10.4 Example Multinomial Model with Random Effects

In this section we will demonstrate the fitting of a Multinomial model with random effects using the shoulder pain study of Section 9.9. In the study, there were 22 subjects in the active group (with abdominal suction) and 19 subjects in the control group (without abdominal suction). Recall that after laparoscopic surgery, patients were asked to rate their pain on a visual analog scale, morning and afternoon, for three days after the operation (for a total of six different times). The response was ordinal with a five category group, where the value “1” indicated “low pain,” and “5” indicated “high pain.” were covariates, namely Gender, Age, and Time, with all time being subject-specific. Let $y_{ij}$ represent the response of the j-th subject in the i-th treatment group at the i-th time, $i=1, 2, j=1, 2, \dots,$ ($n_i=22, n_j=19, t=1, 2, \dots, 6$), with

$$E(y_{ij}) = \frac{\pi_{1ij}}{\pi_{1ij} + \pi_{2ij} + \pi_{3ij} + \pi_{4ij}}$$

Note that a subject with his/her repeated measures constitutes a cluster. We consider the following Logit GLMM as

$$\ln(\pi_{1ij} / (\pi_{2ij} + \pi_{3ij} + \pi_{4ij})) = \alpha_1 + \beta_1X_{ij} + \beta_2X_{2ij} + \beta_3X_{3ij} + \beta_4t + u_{ij}$$
$$\ln(\pi_{2ij} / (\pi_{1ij} + \pi_{3ij} + \pi_{4ij})) = \alpha_2 + \beta_1X_{ij} + \beta_2X_{2ij} + \beta_3X_{3ij} + \beta_4t + u_{ij}$$
$$\ln(\pi_{3ij} / (\pi_{1ij} + \pi_{2ij} + \pi_{4ij})) = \alpha_3 + \beta_1X_{ij} + \beta_2X_{2ij} + \beta_3X_{3ij} + \beta_4t + u_{ij}$$
$$\ln(\pi_{4ij} / (\pi_{1ij} + \pi_{2ij} + \pi_{3ij})) = \alpha_4 + \beta_1X_{ij} + \beta_2X_{2ij} + \beta_3X_{3ij} + \beta_4t + u_{ij}$$

where the $u_{ij}$ are independent and identically distributed $N(0, \sigma^2)$.
