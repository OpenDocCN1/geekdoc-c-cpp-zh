# 7.5 Quasi-likelihood Models

A straightforward approach to handle overdispersion in multicategory counts is to multiply the multinomial covariance matrix by a scalar parameter. A quasi-likelihood approach using a scale adjustment is presented in Chapter 5 of McCullagh and Nelder (1983). As pointed earlier in Chapter 3 in the context of binomial responses, commonly used methods to inflate (or deflate if underdispersion is present) the variance estimates are based on the Deviance and the Pearson’s Chi-square statistics. These single-variance inflation methods can be extended to multinomial responses. To that end, let us assume, as we do in Section 7.3, a sequence of d-dimensional Multinomial-type random vectors T₁, T₂, ..., Tn such that for each j = 1, 2, ..., n

```
E(T_j) = m_j\pi_j, \quad (7.15)
```

with $\pi_j$, as in (7.6). In its simplest form, overdispersion in the Multinomial distribution can be represented by multiplying the multinomial variance-covariance matrix (7.5) by an unknown scale parameter $\phi$. That is,

```
Var(T_j) = m_j\Delta(\pi_j). \quad (7.16)
```

As in Chapter 3, a consistent estimator of the scale parameter $\phi$ can be obtained either from the Deviance or the Pearson’s Chi-square statistic, each of them by their degrees of freedom. For multinomial responses, the Deviance and the Pearson’s Chi-square statistic are defined as

```
D = 2\sum_{j=1}^{n} \sum_{i=1}^{d_j} \log(\\frac{t_{ij}}{m_j\pi_{ij}}), \quad (7.17)
```

and

```
X^2 = \sum_{j=1}^{n} \sum_{i=1}^{d_j} \frac{(t_{ij} - m_j\hat{\pi}_{ij})^2}{m_j\hat{\pi}_{ij}^2}, \quad (7.18)
```

with $\hat{\pi}_{(d+1)} = 1 - \sum_{i=1}^{d}\hat{\pi}_i$. The Pearson’s Chi-square statistic can also be expressed as

```
X^2 = \sum_{j=1}^{n} m_j(T_j - m_j\hat{\pi}_j)^T \Delta^{-1}(T_j - m_j\hat{\pi}_j), \quad (7.19)
```

The variance model in (7.16) imposes a restriction, namely that all the elements in the multinomial variance-covariance matrix are adjusted by the same relative amount. In particular, this means that the extent of overdispersion (or underdispersion) is same for all components
