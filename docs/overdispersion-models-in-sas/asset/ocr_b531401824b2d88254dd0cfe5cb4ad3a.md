The NLMIXED procedure, like other SAS procedures, provides the Akaike Information Criterion (AIC), the Schwarz Bayesian Information Criteria (BIC). If "L" is the likelihood function evaluated at the parameter estimates, "n" is the number of observations (number of clusters), and "u" is the number of parameters being estimated, then AIC, AIC, and BIC are defined as

> AIC = -2 ln(L) + 2u
AICC = -2 ln(L) + \frac{2u}{n-u-1}, and
BIC = -2 ln(L) + u\ln(n).

These statistics help to find the model that best explains the data with a minimum number of parameters. The preferred model is the one with the lowest value.
