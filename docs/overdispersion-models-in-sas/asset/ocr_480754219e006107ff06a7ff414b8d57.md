Williams modified the iterative least-squares procedure in equation (2.23) of Chapter 2 to allow the weights (inflation factors) $w_j^{-1} = [1 + (m_j - 1)	heta]$ to be used in conjunction with the variance function $v_j = m_j\pi_j(1 - \pi_j)$. Note that the variance of $T_j$ is $v_jw_j^{-1}$. For known $	heta$, the Quasi-likelihood estimator of $eta$ can be solved iteratively

```
$\hat{eta}_{(s+1)} = \hat{eta}_{(s)} +(\mathbf{X}'\mathbf{W}\mathbf{X})^{-1}\mathbf{X}'\mathbf{W}(\mathbf{y}-oldsymbol{\mu}),\quad$ (3.10)
```

where $\mathbf{V} = \text{Diag} [m_1\pi_1(1-\pi_1), m_2\pi_2(1-\pi_2), ..., m_n\pi_n(1-\pi_n)] = (v_1, v_2, ..., v_n)$ and

```
$\mathbf{W} = \text{Diag} [\frac{1}{1+(m_1-1)\theta}, \frac{1}{1+(m_2-1)\theta}, ..., \frac{1}{1+(m_n-1)\theta}] = \text{Diag}(w_1, w_2, ..., w_n).$ The case $	heta=0$ makes $\mathbf{W} = \mathbf{I}$, the identity matrix. Then, the above iterative procedure becomes the one for finding the MLE of $eta$.
```

When a $w_j$ is associated with the $j$-th subject (cluster), the usual Pearson-square statistic

```
$\chi^2 = \sum_{j=1}^n \frac{w_j(t_j-m_j\hat{\pi}_j)^2}{m_j\hat{\pi}_j(1-\hat{\pi}_j)},\quad$ (3.11)
```

Williams performed Taylor's series expansion on $E(X^2)$ to derive the moment estimator

```
$\hat{	heta} = \frac{\sum_{j=1}^n w_j(1-w_jv_j)}{\sum_{j=1}^n w_j(m_j-1)(1-w_jv_j)},\quad$ (3.12)
```

where $h_j$ is the variance of the linear predictor $\hat{\eta}_j = \mathbf{x}'\boldsymbol{eta}$.

The algorithm proposed by Williams to estimate $eta$ and $	heta$ simultaneously is as follows.

+   Step 1: Assume $	heta=0$ ($w_j=1$) and obtain $\hat{eta}$, the MLE of $eta$ using the algorithm in equation (2.23) of Chapter 2. Evaluate the Pearson's chi-square statistic $X^2$ using equation (3.11).
