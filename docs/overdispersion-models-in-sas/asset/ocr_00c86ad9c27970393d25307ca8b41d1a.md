Let $\mathbf{D}(0,\mathbf{x}_j)=\mathbf{D}_j$ represent the $d 	imes r$ matrix of first partial derivatives of $\mathbf{g}(0,\mathbf{x}_j)$ with respect
to $	heta_0$, and let $\mathbf{D}_j = (\mathbf{D}_{j,1}, \mathbf{D}_{j,2}, ..., \mathbf{D}_{j,m_j})^	op$ represent the $(	ext{dm})_j 	imes r$ matrix of first partial
derivatives associated with mean vector $oldsymbol{\mu}_j$. The GEE estimator of $	heta$ can be obtained as a
consistent solution, $\hat{	heta}$, of the generalized estimating equations

```
$\sum_{j=1}^n \mathbf{D}_j^	op \mathbf{V}_j^{-1} (\mathbf{y}_j - oldsymbol{\mu}_j) = \mathbf{0}. \quad (9.23)$
```

A solution to the generalized estimating equations (9.23) is obtained in most of the
applicatively iterated. A consistent estimate of the asymptotic variance-covariance matrix of
the parameter estimates, the so-called "sandwich" variance is given by

```
$\widehat{Var}(\hat{	heta}) = \hat{\mathbf{H}}^{-1} \hat{\mathbf{G}} \hat{\mathbf{H}}^{-1}, \ \quad (9.24)$
```

$\hat{\mathbf{H}} = \sum_{j=1}^n \mathbf{D}_j^	op (\hat{\mathbf{V}}_j^{-1}) \mathbf{D}_j (\hat{oldsymbol{	heta}})$, $\hat{\mathbf{G}} = \sum_{j=1}^n (\mathbf{d}_j - ar{\mathbf{d}})(\mathbf{d}_j - ar{\mathbf{d}})^	op$,

```
$\mathbf{d}_j = \mathbf{D}_j^	op (\hat{\mathbf{V}}_j^{-1}) (\mathbf{y}_j - oldsymbol{\mu}_j(\hat{oldsymbol{	heta}}))$, and $ar{\mathbf{d}} = \frac{\sum_{j=1}^n \mathbf{d}_j}{n}$.
```

Note that $\hat{\mathbf{d}}$ is assumed to be the null vector. The assumption $ar{\mathbf{d}} = \mathbf{0}$ holds if $\hat{	heta}$ is an
 solution to the estimating equations (9.23). In practice, since $\hat{	heta}$ is an approximation to
the solution within a pre-established tolerance, $\hat{\mathbf{d}}$ might be useful as in the
SURVEYLOGISTIC procedure. When GENMOD sets $ar{\mathbf{d}} = \mathbf{0}$, one might see minor differences
the estimated standard errors between SURVEYLOGISTIC and GENMOD.
