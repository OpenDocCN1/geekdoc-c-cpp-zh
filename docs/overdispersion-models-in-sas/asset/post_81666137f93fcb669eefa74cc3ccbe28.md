Note that $g^{-1}(\cdot)$ is the mean function, whereas $g(\cdot)$ is the link function. When multinomial responses are ordinal, which means that the responses are qualitatively ordered, it is meaningful to model the cumulative probabilities

```
$$\sum_{h=1}^H \pi_{hj} = F(\alpha_i + x_j\beta), \quad i=1, 2, \dots, d, \quad (7.7)$$
```

$F(\cdot)$ is a continuous distribution function and $\beta = (\beta_1, \beta_2, \dots, \beta_k)^T$. Note that the model consists of a common regression parameter $\beta$ and a separate intercept parameter for each response. Thus, the unknown parameter is the $(d+k)$-dimensional vector $\theta = (\alpha', \beta')^T$ with $\alpha = (\alpha_1, \alpha_2, \dots, \alpha_d)^T$. The logistic and normal cumulative distribution yield the popular link functions known as **cumulative logits** and **cumulative probs**. Cumulative logits are defined

```
$$\ln \frac{\pi_{hj}}{\sum_{h=1}^H \pi_{hj}} = \alpha_i + x_j\beta, \quad i=1, 2, \dots, d, \quad (7.8)$$
```

and cumulative probs as

```
$$\Phi^{-1}(\frac{\pi_{hj}}{\sum_{h=1}^H \pi_{hj}}) = \alpha_i + x_j\beta, \quad i=1, 2, \dots, d, \quad (7.9)$$
```

where $\Phi^{-1}(\cdot)$ is the inverse of a standard normal cumulative distribution function. Under the cumulative log link (7,8) it can be shown the mean function turns to be

```
$$\pi_{hj} = \frac{e^{\alpha_i + x_j\beta}}{1 + e^{\alpha_i + x_j\beta}}, \quad i=1, 2, \dots, d.$$
```

Under the cumulative prob link

```
$$\pi_{hj} = \Phi(\alpha_i + x_j\beta), \quad i=1, 2, \dots, d.$$
```

The cumulative logits model previously defined is also known as the Proportional-odds model. Inherent to this is the proportional odds assumption, which states that the cumulative odds ratio for any given value of the covariate is constant across categories. To be precise meaning this model specification, consider in (7.8) a single covariate "x" so there is only one $\beta$ parameter.

For a given value of the covariate, $x$, the odds of being in a cumulative category $i$, $i = 1, 2,...,d$ is $e^{x\beta}$, which does not depend on $i$. The LOGISTIC procedure provides a Score test for testing the proportional odds assumption. A non-significant test is taken as evidence that the logit surfaces (equations) are parallel and the odds-ratios can be interpreted as constant across all possible cumulative categories. In Section 7.11 we will provide a methodology for testing this assumption of the proportional odds assumption under the likelihood models for overdispersed Multinomial models.

When multinomial responses are nominal, cumulative logits are not very meaningful; therefore, generalized logits are used. They are defined as

```
ln \frac{\pi_{ij}}{\pi_{(d+1)}} = x\beta_i, i = 1, 2,...,d ,
```

$\beta_i = (\beta_{i1},\beta_{i2},...,\beta_{ik})$. The unknown parameter vector is the $dk$-dimensional vector. Under the generalized log link (7.10) it can be shown the mean function turns out to be

```
$\pi_i = \frac{e^{x\beta_i}}{1 + \sum_{t=1}^{d} e^{x\beta_t}}, i = 1, 2,...,d .$
```

The generalized logits are defined as

```
$\Phi^{-1}(\pi_i) = x\beta_i, i = 1, 2,...,d .$
```

Its associated mean function is

```
$\pi_i = \Phi^{-1}(x\beta_i), i = 1, 2,...,d .$
```

Observe that cumulative logits and link functions, the number of parameters being estimated is $(d+k)$. For generalized logits the number of unknown parameters become "dk." In the case of binomial responses, link functions (7.8) and (7.10) are the same and reduce to the logit link defined in Chapter 2.

## 7.4 An Example of a Generalized Logit Model

The example is taken from Stokes, Davis, and Koch (2000) and is used in the LOGISTIC procedure to illustrate the fitting of a Generalized Logit Model. The background of this data set is given in the SAS documentation. We are using this example from the SAS documentation, already familiar to many readers, as an introduction to Generalized Logit Model estimation. Discussion of overdispersion in this context will be introduced in subsequent sections. Over the course of one school year, third-graders were exposed to three different styles: a self-paced computer-learning style, an afternoon approach, and a traditional class approach. The students were asked which they prefer, and their preferences, classified by the type of program they are in, a regular school day versus a regular day supplemented with an afternoon program. The response, indicates a learning style preference, is nominal since there is not a natural ordering among the possible alternatives (Self, Team, Class). We thus fit a Generalized Logits Model as in equation (7.10). Let $\pi_{sp}$ represent the probability that a student in school (s=1,2,3) and program (p=1 if Program and p=2 if Afternoon) prefer learning style (i=1 if Self, i=2 if Team and i=3 if Class). The reference style is Class. There are two types (d=2) based on comparing the style Class (i=1) versus Class (i=3), and the style team (i=2) versus Class (i=3). Each logit is a function of the factors School, Program, and the School-by-Program interaction. Program 7.1 provides the programming statements for fitting the School Data with generalized logits using the LOGISTIC procedure. When there are more than two response levels, PROC LOGISTIC fits the cumulative logit model unless the LINK=option is specified.

## Program 7.1: Fitting the School Data with Generalized Logits

```sas
/* Program Example
from Stokes, Davis, and Koch (2000)
Fitting of a Generalized Logits */

data school;
  length Program $ Style $ Count @
datalines;
  1 regular 10 1 regular team 17 1 regular class 26
  1 afternoon self 5 1 afternoon team 12 1 afternoon class 50
  2 regular 21 2 regular team 17 2 regular class 26
  2 afternoon self 16 2 afternoon team 12 2 afternoon class 36
  3 regular self 15 3 regular team 15 3 regular class 16
  3 afternoon self 12 3 afternoon team 12 3 afternoon class 20
;

ods html;
graphics on;
proc logistic data=school;
  freq Count;
  class Program(ref=School);
  model Style(order=data)=School Program*Program / link=logit;
  oddsratio program;
run;
ods graphics off;
html close;
```
