# 2.2 Linear Regression Models

Let $Y_j, j=1,2,...,n$, independent random variables, and let $y_j$ represent a realization of $Y_j$. Associated with each observation $y_j$ are a $k$-dimensional row vector of known covariates

$mathbf{x}_j = (x_{1j},x_{2j},...,x_{kj})$ and a $k$-dimensional column vector of unknown parameters
$oldsymbol{eta} = (eta_1,eta_2,...,eta_k)^T$ such that the mean of $y_j$, with $\mathbf{x}_j$ and $oldsymbol{eta}$ is

```
$y_j = \mathbf{x}_j\boldsymbol{eta} + \varepsilon_j = \sum_{i=1}^k x_{ij}\beta_i + \varepsilon_j \quad (2.1)
```

where the $\varepsilon_i$'s are uncorrelated random variables such that $E(\varepsilon_i)=0$ and $Var(\varepsilon_i)=\sigma^2$. This is the classical linear regression model. The linear model (2.1) in matrix form is written as

```
$\mathbf{y} = \mathbf{X}\boldsymbol{eta} + \boldsymbol{\varepsilon} \quad (2.2)
```

where $y$ is an $n$1 vector, $y=(y_1,y_2,...,y_n)^T$, $X$ is an $n \times k$ matrix of known covariates,
$\mathbf{X} = (\mathbf{x}_1,\mathbf{x}_2,...,\mathbf{x}_n)^T$, $oldsymbol{eta}$ a $k$-dimensional column vector of unknown parameters
$oldsymbol{eta} = (eta_1,eta_2,...,eta_k)^T$, and $\varepsilon$ is an $n \times 1$ vector of disturbances, $\varepsilon = (\varepsilon_1,\varepsilon_2,...,\varepsilon_n)^T$. It is assumed that $n > k$.

The usual method for estimating $oldsymbol{eta}$ is the well-known method of Least Squares (LS), also referred to the method of Ordinary Least Squares (OLS). The OLS estimate of $oldsymbol{eta}$ minimizes the sum of squares

```
$S(\boldsymbol{eta}) = \sum_{j=1}^n \varepsilon_j^2 = \sum_{j=1}^n (y_j - \sum_{i=1}^k x_{ij}\beta_i)^2 \quad (2.3)
```

In matrix form, equation (2.3) can be written as

```
$S(\boldsymbol{eta}) = \boldsymbol{\varepsilon}^T\boldsymbol{\varepsilon} = (\mathbf{y}-\mathbf{X}\boldsymbol{eta})^T(\mathbf{y}-\mathbf{X}\boldsymbol{eta}) \quad (2.4)
```
