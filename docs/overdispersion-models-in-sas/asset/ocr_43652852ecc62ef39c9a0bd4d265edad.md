# 102 Overdispersion Models in SAS

Suppose that $T_j, j=1,2,...,n$ are independent and independently distributed overdispersed binomial random variables with parameters $(\pi,ho;m)$. This is the case in the chromosome example discussed in Section 4.6. The log-likelihood function can be expressed as

```
$L(\hat{\theta};t) = \sum_{j=1}\ln[Pr(T =t_j)], \quad (4.29)$
```

where $	heta = (\pi,\rho)^T$ represents the parameter vector and $t = (t_1,t_2,...,t_n)^T$ the observed data. The MLE of $	heta$, say $\hat{\theta} = (\hat{\pi},\hat{\rho})^T$, can be found iteratively as

```
$$\hat{\theta}^{(S+1)} = \hat{\theta}^{(S)} + I(\hat{\theta}^{(S)})^{-1}u(\hat{\theta}^{(S)}), \quad (4.30)$
```

where $u(\hat{\theta}^{(S)})$ is the two-dimensional column vector of first derivatives of the log-likelihood function $u(\theta) = \frac{\partial L(\theta;t)}{\partial\theta}$ evaluated at $\hat{\theta}^{(S)}$, and $I(\hat{\theta}^{(S)})$ is the 2x2 Fisher information

```
$matrix = -E \left[ \begin{matrix} \frac{\partial^2 L(\theta;t)}{\partial\theta_1^2} & \frac{\partial^2 L(\theta;t)}{\partial\theta_1\partial\theta_2} \ \frac{\partial^2 L(\theta;t)}{\partial\theta_2\partial\theta_1} & \frac{\partial^2 L(\theta;t)}{\partial\theta_2^2} \end{matrix} \right]$ evaluated at $\hat{\theta}^{(S)}.$ The iterative
```

procedure (4.30) corresponds to the Fisher Scoring Method. The subscript "s" refers to the step or iteration. The actual numerical method used may vary.

Like GLMs, the $T_j$'s are independent and belong to the same distribution, but they are not identically distributed. In other words, $T_j, j=1,2,...,n$ are distributed according to an overdispersed Binomial distribution with parameters $(\pi_j,\rho_j;m_j)$. The mean parameter $\pi_j$ is assumed to depend on a k-dimensional row vector of known covariates $x_j$ and a k-dimensional column vector of unknown parameters $\beta$, through a twice differentiable smooth function $g(\cdot)$, so that

```
$g(\pi_j) = x_j\beta = \sum_{i=1}^k x_{ji}\beta_i. \quad (4.31)$
```

Similarly, the overdispersion parameter $\rho_j$ might depend on an h-dimensional row vector of known covariates $z_j$, and an h-dimensional column vector of unknown parameters $\alpha$, through a twice differentiable smooth function $f(\cdot)$, so that

```
$f(\rho_j) = z_j\alpha = \sum_{i=1}^h z_{ji}\alpha_i. \quad (4.32)$
```
