The vector β represents the parameters of the fixed part of the model. The parameters associated to the random part of the model are represented by the unknown vector γ. Similarly, Z contains continuous or dummy variables, just as X. It is assumed that the random vector γ and ε are jointly independent and normally distributed with

```
E \begin{pmatrix} \gamma \ \epsilon \end{pmatrix} = \begin{pmatrix} 0 \ 0 \end{pmatrix}
```

and variance-covariance matrix

```
Var(\begin{pmatrix} \gamma \ \epsilon \end{pmatrix}) = \begin{pmatrix} G & 0 \ 0 & R \end{pmatrix}
```

We want to warn the reader that since the observation vector consists of multivariate response vectors from all elements, the structure of the matrices G and R can be quite complex. Conditionally, given γ, expected value and variance-covariance of the observation vector are

```
E(y|γ) = Xβ + Zγ\nVar(y|γ) = R
```

Note that in principle, we can derive the marginal distribution of the observed data starting from the distribution of γ and ε. The unconditional (or marginal) expected value and variance of the observation vector are given

```
E(y) = Xβ\nVar(y) = ZGZ' + R
```

Models may also be thought of as G-side random effects or R-side random effects. Note that the right-hand side of the equation (10.5) contains two different (independent) random quantities, γ and ε. While γ is used to capture the conditional mean to capture the subject-effect, ε represents the residual effect. Including γ with an appropriate design matrix Z is referred to as a G-side random effect. It is also possible to specify the variance-covariance matrix of ε directly to capture the within-subject correlation structure. This approach is referred to as R-side random effects. Note that models with only G-side random effects are conditional; they are also SS models. On the other hand, models containing only R-side effects are marginal and PA models.
