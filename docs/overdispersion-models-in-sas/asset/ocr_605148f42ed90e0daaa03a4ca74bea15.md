# Chapter 2 Generalized Linear Models

We fit a Probit model for Murray’s data. In a Probit model, the mean function is defined as

$\pi_j = \Phi(\mathbf{x}_joldsymbol{eta})$

where $\Phi(\cdot)$ is the cumulative distribution function of a standard Normal distribution. Thus, the Probit link is

$\Phi^{-1}(\pi_j) = \mathbf{eta}_0 + eta_1\mathbf{x}_j$

Note that with a Probit link the estimated linear predictors $\hat{\eta}_j = \hat{eta}_0 + \hat{eta}_1x_j$ are Z-scores. A subject with a predicted score of zero has 50% probability of “success”, with a predicted score of 1.64 has a 95% probability, etc. The programming statements for fitting a Probit model using GLIMMIX procedure including the diagnostic residual plots are

```
ods html;
ods graphics on;
title "Dosage-Mortality of pyrethrins on Male Flies, Murray (1938)"
title2 "GLM with Binomial Distribution and Probit Link";
proc glimmix data=pyrethrins plots=residualpanel;
  model t/m = x / dist=binomial link=probit solution;
run;
ods graphics off;
ods html;
```
