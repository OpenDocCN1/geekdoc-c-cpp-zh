Lawless (1987) found evidence against the Poisson model and overdispersion was present in the model. Lawless then fitted a Binomial model with random effects. The type of model, which belongs to the family of Generalized Linear Mixed Models, will be discussed later in the book. For illustrative purposes we now fit a Quasi-like Poisson model. The programming statements are found in Program 3.4. This time, we make use of the GENMOD procedure and request LS-Means for the Control and Retinoid groups. An estimate of the Retinoid effect is made as well. The main results are provided in Output 3.4.

# Program 3.4: Fitting an Overdispersed Poisson Model--Tumor Data of Table 3.4

```
/*
Number of Tumors in Rats
Example from Lawless (1987) and Gail et al. (1980)
*/
data number_of_tumors;
  input group5 n 88;
  do retid=1 to n;
    input y 88;
    output;
  end;
  drop n;
datalines;
  Retinoid 23 1 0 2 1 4 3 6 1 1 5 2 1 5 2 3 4 5 4 5 1 2
  Control 25 7 11 9 2 9 4 6 7 6 1 13 2 1 10 4 5 4 5 11 11 9 12 1 3 3 3
;
ods html;
proc genmod data=number_of_tumors;
  class group;
  model y = group / dist=poisson link=log scale=pearson;
  lsmeans group;
    estimate "Logarithm Ratio Control Vs Retinoid" group 1 -1;
run;
ods html close;
```
