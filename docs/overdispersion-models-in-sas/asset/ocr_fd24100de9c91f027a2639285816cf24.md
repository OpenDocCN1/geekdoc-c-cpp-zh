# Overdispersion Models in SAS

If $	ilde{\pi}_j = \frac{t_j}{m_j}$ is an observed proportion, its associated logit is defined as

```
$$\ln\left(\frac{\tilde{\pi}_j}{1-\tilde{\pi}_j}\right) = \ln\left(\frac{t_j}{m_j-t_j}\right)$$$
```

In practice these quantities are slightly modified as

```
$$\ln\left(\frac{t_j+0.5}{m_j-t_j+0.5}\right)$$$
```

in order to avoid numerical problems when t, is either zero or m . The estimated linear predictors are $\hat{\eta}_j = \hat{eta}_0 + \hat{eta}_1X_j$. The programming statements are provided in Program 2.2. The results produced by GLIMMIX are provided in Output 2.2.
