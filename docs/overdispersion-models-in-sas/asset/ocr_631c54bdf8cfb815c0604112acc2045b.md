# Chapter 6 Likelihood Models for Overdispersed Count Responses 177

Van den Broek (1995) considered the following ZIP model

```
Pr(Y_j = y_j) = \omega I(y_j = 0) + (1-\omega) \frac{e^{-\mu_j} \mu_j^{y_j}}{\Gamma(y_j+1)}, j=1,2,...,n=(98) \(6.20)
```

where In($\mu_i$) = $\mathbf{x}_i\mathbf{eta} = \sum x_i\beta_i$. Note that this model corresponds to a GLOM with logarithmic link on $\mu_i$ and identity link on $\omega$. The Score tests have the advantage that they do not require the fitting of the ZIP model (6.19). They are based on the estimates obtained under the reduced model ($\omega=0$), namely, the standard Poisson model

```
Pr(Y_j = y_j) = \frac{e^{-\mu_j} \mu_j^{y_j}}{\Gamma(y_j+1)}, j=1,2,...,n .
```

Van den Broek's proposed test statistic

```
S = \frac{\left{\{egin{array}{c} I(y_j=0) \ e^{-\mu_j}-1 \end{array}\right\}^2}{\left{\{egin{array}{c} 1 \ e^{-\mu_j}-1 \end{array}\right\}^{-2}} - \hat{\mathbf{\mu}}\mathbf{X}' \text{Diag}(\hat{\mathbf{\mu}}) \mathbf{X}^{-1}\mathbf{X}'\mathbf{\mu}} \(6.21)
```

where I is an indicator function, $\hat{\mu}_j = \exp(\mathbf{x}\mathbf{eta})$, $\mathbf{x}_j$, the vector of observed covariates associated with the j-th subject, $\mathbf{eta}$ the vector of maximum likelihood estimates, $\hat{\mathbf{\mu}}==(\hat{\mu}_1,\hat{\mu}_2,...,\hat{\mu}_n)'$ and $\mathbf{X}=(\mathbf{x}_1,\mathbf{x}_2,...,\mathbf{x}_n)'$ the matrix of covariates. Under the null hypothesis $H_0:\omega=0$, the score test (6.20) is asymptotically distributed as a Chi-square random variable with one degree of freedom. Van den Broek found that the linear predictor $\eta_{ij} = \mathbf{x}\mathbf{eta}$ contains an intercept the score test statistics (6.20) reduces to

```
S = \frac{\left{\{egin{array}{c} I(y_j=0) \ e^{-\mu_j}-1 \ \end{array}\right\}^2}{\left{\{egin{array}{c} 1 \ e^{-\mu_j}-1 \ \end{array}\right\}^{-2}} - n\hat{\mathbf{\mu}} \(6.22)
```
