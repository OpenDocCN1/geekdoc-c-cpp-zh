The GLIMMIX procedure uses two main estimation methods, namely, the Pseudo-likelihood based on linearization, and the Maximum Likelihood Estimator based on adaptive Gauss-Hermite quadrature. The former method was discussed in Chapter 9. In the adaptive Gauss-Hermite quadrature method, the integrals associated with the log likelihood of the GLMM are approximated by summations. For instance, if f(x) is a probability density function and the function p(x) is to be integrated with respect to x, then the adaptive quadrature approximation

```
f(x)p(x) \approx \sum_{i=1}^{N} w_i f(x_i)
```

N denotes the number of quadrature points, w_i are the quadrature weights, and x_i the abscissas. In GLIMMIX this method is requested with the model option METHOD=QUAD. The quadrature rule in the GLIMMIX procedure is adaptive in the sense that the user does not specify the number of quadrature points (nodes) but the QPOINTS= suboption of the METHOD=QUAD option, then the number of quadrature points is determined by evaluating the log likelihood at the starting values and respectively larger numbers of nodes until a tolerance is met. In addition, the GLIMMIX procedure centers and scales the quadrature points by using the empirical EBEs (of) the random effects and the Hessian (second derivative) matrix from the EBE optimization. This centering and scaling improves the likelihood approximation by placing the abscissas to the density function of random effects. Refer to the SAS documentation for the GLIMMIX procedure for further details on the adaptive Gauss-Hermite quadrature method; the documentation also presents the pros and cons of this method and discusses the Pseudo-likelihood method based on linearization. If the user selects the implementation of the quadrature rule with a single quadrature point, that is,

```
proc glmix method=quad(qpoints=1);
```

the results will be identical to

```
proc glimmix method=laplace;
```

Computationally, two methods are not identical, however. the option METHOD=LAPLACE can be applied to a considerably larger class of models. For details, see the SAS documentation for the GLIMMIX procedure. In the NLMIXED procedure, the adaptive Gauss-Hermite quadrature is the default integration method. All the examples discussed in this chapter are handled via the adaptive Gauss-Hermite quadrature.
