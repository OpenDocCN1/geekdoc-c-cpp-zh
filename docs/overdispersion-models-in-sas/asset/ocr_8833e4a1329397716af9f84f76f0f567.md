specified directly without conditioning on subjects. Inferences, as previously stated, are at the population-average level. R-side effects are also called "residual" effects. Models in practice might have several G-side and/or R-side effects. Linear Normal models containing both effects can be handled by the MIXED procedure. The concept of a mixed model can be extended to any distribution in the exponential family. This extended family of models is known as Generalized Linear Mixed Models (GLMM) and can be handled by the GLIMMIX procedure. Other procedures in SAS, such as NLMIXED, permit the use of GLMMs. For more information on mixed models, GLMMs, and non-linear models with random effects, we refer the reader to Littell et al. (2006). We now present a simple simulated example, in the same structure as the hair growth application described above, to illustrate the G-side and R-side random effects. The programming statements of the data generation as well as the fitted programs are included in Program 9.1.

# Program 9.1: Generating Continuous and Binary Data from a Random Effects Model

```
data hair;
    seed = 1999;
    beta = 1.386294;   *--- P is approximately 0.8;
    do Subj_id=1 to 1000;
    s1 = 2*normal(seed);
    s2 = sqrt(1.5)*normal(seed);
        do week=1 to 8;
            score = round(s1 + normal(seed), 0.01);
            p     = 1/(1+exp(-beta - s2));
            y     = 0;
            u     = uniform(seed);
            if u < p then y = 1;
            output;
        end;
    end;
keep subj_id score y;
run;

ods html;
title "*** Linear Mixed Model with G-side Random Effects ***";
proc glimmix data=hair;
    class subj_id;
    model score = / s;
    random int / subject=subj_id;
run;

title "*** Linear Mixed Model with R-side Random Effects ***";
proc glimmix data=hair;
    class subj_id;
    model score = / s;
    random _residual_ / subject=subj_id type=cs;
run;
```
