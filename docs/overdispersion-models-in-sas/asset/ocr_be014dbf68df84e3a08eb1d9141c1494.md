Now we turn to the Pseudo-likelihood Estimation by Linearization, used by the GLIMMIX procedure. This method is best motivated using the basic setup of a linear mixed model (see section "Mixed Models Theory" in the documentation of the MIXED procedure). Therefore, we start with a brief introduction. In general, a linear mixed model is written as

```
$y = X\beta + Z\gamma + \varepsilon, \quad (9.5)$
```

where, in general linear models, $X$ represents the design matrix (or the matrix of known covariates), and $\beta$ is an unknown vector of parameters. The vector $\beta$ represents the parameters of the fixed part of the model. The parameters associated with the random part of the model are represented by the unknown vector $\gamma$. The $Z$ contains either continuous or dummy variables, as also seen with $X$. See McCulloch and Searle (2001) for an account of the historical developments of the mixed model. It is assumed that the random vectors $\gamma$ and $\varepsilon$ are jointly and normally distributed with mean

```
$$\begin{pmatrix} \gamma \ \varepsilon \end{pmatrix}$
```

and variance-covariance matrix

```
$Var(\begin{pmatrix} \gamma \ \varepsilon \end{pmatrix}) = \begin{pmatrix} G & 0 \ 0 & R \end{pmatrix}$
```

Notations used in the previous expression are the effects of the G-side and R-side, used here to describe the two different ways of incorporating random effects. If $y$ in equation (9.5) represents a realization of the random vector $Y$, it can be shown that

```
$Var(Y) = GZ^TG + R.$
```

$Var(Y)$ can be modeled by properly defining the variance-covariance structures of $G$ and $R$. Because of the additive nature of the relationship among $G$, $R$, and $Var(Y)$, many mixed models will have equivalent G-side and R-side specifications, as illustrated in the hair growth example of 9.2.

The general set-up of a Generalized Linear Mixed Model (GLMM) is

```
$E(y|\gamma) = g^{-1}(X\beta + Z\gamma) = g^{-1}(\eta) = \mu, \quad (9.6)$
```
