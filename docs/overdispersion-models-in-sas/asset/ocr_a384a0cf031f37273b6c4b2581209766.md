# 98 Overdispersion Models in SAS

```
panelby / spacing=8;
var t / response=Prob group=Distribution;
run;
%mend plots_bb_rcb;
%plots_bb_rcb(0.3, 0.7, 20);
%plots_bb_rcb(0.5, 0.5, 20);
%plots_bb_rcb(0.5, 0.8, 20);
```

Plot 4.1 displays the probability functions of the Beta-binomial Binomial distributions when $\pi=0.3$, $\rho=0.7$. Unlike the Beta-binomial, the Random-clumped Binomial exhibits two peaks. These peaks are approximately located at the points $m(1-\rho)\pi$ and $m\{(1-ho)\pi+ho\}$. Recall that in the Random-clumped Binomial distribution, these two values are the means of the two mixing Binomial distributions. For $\pi=0.5$ both distributions are symmetric. Plot 4.2 shows the probability functions for $\pi=0.5$, $ho=0.5$ and $m=20$. The Beta-binomial distribution has an upside down U-shape, while the Random-clumped Binomial distribution changes to a U-shape. Although the Random-clumped Binomial distribution changes as $\rho$ changes to 0.8 (see Plot 4.2), the Beta-binomial distribution tends to behave in a similar way, its probability function tends to maintain an M-shape. We have observed that the clump size $m$ gets the M-shape of the Random-clumped Binomial becomes more pronounced, while the Beta-binomial becomes flatter.

Program 4.3 is a useful exploratory tool for developing insights into the behavior of the two main overdispersion models presented in this chapter. We invite the reader to run this program for various configurations of the parameters and compare the resulting probability histograms. It will be instructive to note that the shapes of these distributions differ remarkably, even for small changes in the values of the parameters.
