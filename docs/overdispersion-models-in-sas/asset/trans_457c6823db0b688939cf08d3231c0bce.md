## 1.2 过度离散

考虑一项研究，其中实验单元是簇，并且簇内的每个基本单元被划分为两个互斥的类别。如果我们假设基本单元是独立的且具有共同的成功概率，则二项式模型适用于分析数据。聚类导致基本单元之间缺乏独立性。成功概率可能在簇内的一个基本单元到另一个基本单元之间变化。因此，数据通常表现出比二项式模型允许的方差更大的方差。这种现象，如前所述，被称为 **过度离散或额外变异。**

过度离散可能由其他因素引起。模型中遗漏的变量会导致过度离散。也就是说，响应概率实际上是多个协变量的函数，而模型只包含其中一部分。这种拟合不足表现为过度离散。后面呈现的一些诊断图也会受到这种过度离散的影响。

过度离散也出现在多项响应上（在计数数据上）根据多项分布（泊松）模型进行分析时，其方差可能大于模型所假设的抽样变异所能归因的部分。McCullough 和 Nelder（1989，第 124-125 页）指出：

> “过度离散在实践中并不少见。事实上，有些人会认为过度离散是实践中的常态，而正常离散”

**欠离散** 现象的发生频率较低。Cox 和 Snell（1988，第 107 页）指出“欠离散有时会被观察到，尽管这种情况并不常见。”它可能发生在存在对积极响应的竞争时。在一个人品尝甜饮料的情况下，他或她可能会觉得第二杯饮料没有那么甜——即使它确实如此。虽然这里会出现过度离散，但这种现象在此不予处理。

正如 Stigler（1986）所讨论的那样，源于聚类总体的过度离散的例子可以追溯到 1986 年的文献。具有过度离散的多项式模型的例子可能出现（在遗传性状的致畸研究中，该性状以一定概率传递给同一母亲的后代）；在生殖毒性实验中，化学物质被给予母鼠，而响应是在个体胎儿上测量的；（c）在个体接受治疗并被允许通过支持小组相互互动的实验中，如戒烟计划或戒酒计划；（d）在家庭调查中，家庭内（或邻里内）的受访者可能受到一两个个体的强烈影响。

有许多论文包含讨论和说明过度离散现象及其对由于 I 型错误率膨胀而导致的错误推断后果的例子。有关致畸学和毒理学领域的某些相关例子见 Williams（1975，1982），Williams 等人（1988），Kupper 和 Hashem（1978），Hashem 和 Kupper（1979），Kupper 等人（1986），Shirley 和 Hickling（1981），Paul（1982），Park（1986），Lefkopoulou 等人（1989），Ryan（1992），Liang 和 McCullough（1993），Carr 和 Porter（1993），Donner 等人（1994），Morel 和 Koehler（1995），以及 Morel 和 Neerchal（1997）。Rosner（1984）和 Donner（1989）在眼科学中发现了过度离散的重要例子，Altham（1977）和 Cohen（1976）在住院兄弟姐妹配对的研究中，Crowter（在种子萌发分析中），Heckman 和 Wills（1977）与一项面板研究相关，Efron（1986）在萨尔瓦多 34 个城市的弓形虫病流行病学例子中，以及 Moore（1987）在广岛原子弹幸存者染色体畸变建模中。

关于泊松模型下过度离散的早期评论见 Student（1919）。泊松过度离散的例子可发现于（a）纵向研究计数和率的分析中，以及（b）行为研究和存在个体间变异的数目研究中。

## 1.3 过度离散的常见表征

过度离散现象可以用一阶矩来表征。假设 T 是一个二项变量，则

$$E(T) = m\pi$$

其中 $\pi$ 表示成功概率。此外，如果单元是独立的，则方差为

$$Var(T) = m\pi(1-\pi)$$

然而，如果单元是聚类的，则方差更大。如果我们令 $\rho^2$ 为过度离散参数，则

$$Var(T) = m\pi(1-\pi)(1+\rho^2)$$

其中 $0 \le \rho^2 < \infty$。同样，过度离散的定义可以扩展到多项分布的情况。由 m 个基本单元组成的簇，其中基本单元被划分为 $(d+1)$ 个类别。令 T 表示计数向量 $d$ 维，对应于前 $d$ 个类别，其中第 $i$ 个分量表示被划分为第 $i$ 个类别的基本单元数。对于聚类数据，向量 T 通常用多项分布建模，但数据往往表现出比多项分布模型允许的更高的变异性。为了适应这种过度离散，通常假设以下矩结构：

$$E(T) = m\mu$$

$$Var(T) = m[Diag(\pi) - \pi\pi^T\{1+\rho^2\}$$

其中 $\pi = (\pi_1, \pi_2, ..., \pi_d)$ 是概率向量，$0 < \pi_i < 1$，$\sum\pi_i \le 1$，而 $\rho$（或 $\rho^2$）是过度离散参数。如果多项式类型的 T 具有均值和方差-协方差矩阵，则称其相对于多项分布具有过度离散。当 $\rho=0$ 时，式（1.2）和（1.4）中的方差估计量简化为二项式/多项式模型。

回想一下，对于泊松随机变量 Y，$E(Y) = Var(Y) = \mu, \mu > 0$。泊松随机变量是给定时间间隔内事件发生次数的计数。与二项式情况一样，推导泊松随机变量的性质需要对过程做出基本假设。当这些假设不满足时，可能会出现过度离散。当 Y 是泊松类型的随机变量时，如果其前两个矩的形式为

$$E(Y) = \mu, Var(Y) = \mu(1+\rho^2)$$

则称 Y 具有过度离散
