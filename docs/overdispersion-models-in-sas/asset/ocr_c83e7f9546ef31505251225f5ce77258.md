# Chapter 6 Likelihood Models for Overdispersed Count Responses 199

```
pl = 0.4;
mu = 10;
kappa = 0.1;
alpha = 1 / kappa;
beta = kappa * mu;
seed = 1983;
```

```
* Underlying True Mean and Variance;
p2 = (1+(kappa+mu))**(alpha);
plc = 1 - p1;
p2c = 1 - p2;
Phi = plc / p2c;
Mean = Phi/mu;
Var = Phi*mu*(1+mu+kappa*mu) - Mean*Mean;
```

```
do j=1 to n
  u = uniform(seed);
  if u <= pl then
    Y = 0;
    output;
  else
    -- Crossing the hurdle;
    -- Truncated Neg-bin using Rejection Method;
    do until (y>0)
      uu = beta * rangam(seed, alpha);
      y = ranpoi(seed, uu);
    end
    output;
;
```

```
drop alpha beta kappa;
run;
```

```
title2 "Underlying True Mean and Variance";
proc data=NB_Hurdle_Data noobs;
where j = 1;
  var Mean Var;
  format _all 8.4;
run;
```

```
title2 "Estimated Mean and Variance";
proc means=NB_Hurdle_Data n mean var maxdec=4;
  var y;
run;
```
