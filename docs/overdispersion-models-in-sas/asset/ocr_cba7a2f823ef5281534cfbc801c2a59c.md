# 5.4 Extension of the GOF When Covariates Are Present: The Hiroshima Chromosome Aberration Example

As pointed out in Section 4.8, in the presence of cluster-specific covariates, both the probability of success π and the overdispersion parameter ρ can potentially differ from cluster to cluster. To model this situation we suggested the use of two link functions, referred to GLOM, for the probability of success and one for the overdispersion parameter. The link functions, as defined in equations (4.31) and (4.32),

```
$g(\pi_i) = x_i\beta = \sum_{j} x_{ij}\beta_j$ and $f(\rho_i) = z_i\alpha = \sum_{j} z_{ij}\alpha_j$.
```

The GOF test in equation (5.4) can be accommodated to account not only for varying cluster sizes, but also for varying probability of success and degrees of overdispersion. To that end, find the first maximum likelihood estimator

```
$\hat{\theta} = (\hat{\beta}, \hat{\alpha})$, $\hat{\beta} = (\hat{\beta}_1, \hat{\beta}_2, \dots, \hat{\beta}_k)$ and $\hat{\alpha} = (\hat{\alpha}_1, \hat{\alpha}_2, \dots, \hat{\alpha}_h)$.
```

Now, modify the expected frequencies $E_j$ in equation (5.6) as

```
$E_j = \sum_{j=1}\sum_{t=0}^{m_j} Pr[T_j = t | T_j] \sim$ According to normal distribution with parameters $(\hat{\pi}_j, \hat{ho}_j, m_j)$; $\{\frac{t}{m_j} \in A_j\}$ $(5.7)$
```

where $\hat{\pi}_j = g^{-1}(x_j\hat{\beta})$ and $\hat{ho}_j = f^{-1}(z_j\hat{\alpha})$.
