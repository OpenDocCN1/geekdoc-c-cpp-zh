```
**** Logistic Model with G-side Random Effects ****
proc glimmix data=hair;
 class subj_id;
 model y (ref='0') = = / dist=binary link=logit s;
 random int / subject=subj_id;
  estimate 'P' int 1 / ilink;

**** Logistic Model with R-side Random Effects ****
proc glimmix data=hair;
 class subj_id;
 model y (ref='0') = = / dist=binary link=logit s;
 random_residual / subject=subj_id type=cs;
  estimate 'P' int 1 / ilink;

ods html close;
```

In this example we generate hair assessment data for 100 subjects. Continuous responses (score) are generated from the Normal distribution. Note the nested loops (weeks within subject) so that all for the same subject share a common random effect. The program also generates a binary response (y), corresponding to whether or not the subject had appreciable hair growth relative to the previous week.
