We first fit Table 5.2 to get the MLE of $\pi$ and $ho$. Then, we compute the omnibus GOF test described in (5,4), (5,5), and (5,6). To this end, we use the modules "GOF_GB" and "GOF_RCB" provided by Dr. Santosh C. Sudradhar by Pfizer Inc.

These modules can be found in Appendices 5.1 and 5.2, respectively. The iterative procedure in these modules is based on the Fisher Information matrix and not on the Hessian matrix, as is in case 4 when we used the NLMIXED procedure. Both procedures are asymptotically equivalent. Program 5.3 provides the necessary statistics for the analysis of the mutagenic data of Table 5.2. The modules "GOF_GB" and "GOF_RCB" should be loaded first before invoking them. We output the residuals based on the observed and expected frequencies (5.6) into the data "Resid_GB" and "Resid_RCB" in construct QQ-plots for the residuals. Table 5.3 provides the MLE results under the Beta-binomial and Random-clumped models.
