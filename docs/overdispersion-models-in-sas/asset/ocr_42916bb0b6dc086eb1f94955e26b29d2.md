Thus, the Wald statistic for testing (7.37) is

```
$$X^2 = (C\hat{\theta})^T C \hat{V}(\hat{\theta}) C^{-1} (C\hat{\theta})$ \quad (7.38)$
```

which under the null hypothesis is asymptotically distributed as a Chi-square statistic with five degrees of freedom. In this example, the matrix $\hat{V}(\hat{\theta})$ is of full rank. Therefore, the degrees of freedom are determined by the rank of matrix $C$, namely five.

Program 7.5 contains the programming statements for fitting both the Dirichlet-multinomial and Random-clumped Multinomial models to the Birth Defects Study Data of Table 7.2 using the link function (7.35). We skipped the statements related to the reading of the data. They can be found in Program 7.2. In this example we make use of the NLMIXED procedure. The CONSTRAINT statement in NLMIXED provides the Wald test in (7.38) normalized by its degrees of freedom. This can be approximated by an F-distribution. Since our models (DM and RCM) are likelihood-based, we can also compute a likelihood ratio test and a test score corresponding to the Wald test in (7.38). Note that in the ODS statements, specific tables have been outlined to compute the Wald and Likelihood-ratio test for testing the parallelism assumption. The initial estimates for the parameters involved in the cumulative logits were linked by the LOGISTIC procedure (not shown here). # Program 7.5: Testing Assumption of Proportionality of Odds under the Dirichlet-multinomial and Random-clumped Multinomial Models–Prenatal Exposure to Calcium and Zinc Data

```
/*
Birth Defect Example from Morel and Koehler (1995)
fitting the Generalized Overdispersed Models
dichlet-multinomial and Random-clumped Multinomial.
Testing the Proportionality Assumption using the
CONSTRAINT statement in the NLMIXED procedure.
*/
\ods html;
Title "Testing Proportionality Assumption -- Dirichlet-multinomial Distribution"
ods output Contrast=Prop_Sum_DM FitStatistics=Fit_DM_full
ParameterEstimates-Betas_DM CovMatParmEst=Cov_DM;
Proc nlmixed data=birth_defects;
parms a1=3.7, a2=-2.4, b11=-0.2, b21=-0.2, b12=3.1, b22=3.1,
b13=5.5, b23=5.5, b14=-1.8, b24=-1.8, b15=-1.7, b25=-1.7,
rho=0;
```
