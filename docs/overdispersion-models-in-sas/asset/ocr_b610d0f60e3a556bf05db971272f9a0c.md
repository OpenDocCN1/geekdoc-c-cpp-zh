# 9.8 The GEE Methodology for Multinomial Responses

Consider a situation where n are clusters. As pointed out earlier chapters, these clusters can be, for example, households, where members of a household are the elemental units; pregnant rates, which will the fetuses within a single rate are the elemental units; where members of a support group are the elemental units; and so on. In a longitudinal study involving repeated measures, each individual constitutes a cluster, and the repeated measurements are the elemental units. Let $m_j$ represent the number of elemental units in the $j^{th}$ cluster, $j=1,2,...,m_j$. Let $y_j$ denote a $(d+1)$-dimensional column vectors,

```
$y_j^* = (y_{j1}^*, \dots, y_{jd}, y_{j,d+1})$. The vector $y_j^*$ consists entirely of zeros except for position s, which will contain one of the $l$-th unit in the $j$-th cluster falls in the $s$-th category. Let
```

```
$\pi_{j}^* = (\pi_{js1}^*, \dots, \pi_{jsd})$ denote the expected value of $y_{js}^*$. Then, we $0 < \pi_{js} < 1$ and
```

```
$\sum_{s=1}^{d+1}\pi_{js} = 1$. Due to this linear dependency the last category of $y_{j}^*$ will be dropped. Let $y_j$ and
```

$\pi_j$, represent, the vectors $y_j^*$ and $\pi_j^*$ without the last category. Associated with each $y_j$ is a $k$-dimensional known row vector of explanatory variables $\mathbf{x}_j$ such that the mean $\pi_j$ depends on a $r$-dimensional vector of unknown parameters $oldsymbol{	heta}$ and the vector of explanatory variables $\mathbf{x}_j$ through a smooth link function $g(oldsymbol{	heta},\mathbf{x}_j)$ such that

```
$\pi_j = g^{-1}(\boldsymbol{	heta},\mathbf{x}_j)$
```

```
$= \begin{pmatrix} g_1^{-1}(\boldsymbol{	heta},\mathbf{x}_{j1}) \ \vdots \ g_d^{-1}(\boldsymbol{	heta},\mathbf{x}_{jd}) \end{pmatrix}$ (9.21)
```

Examples of link functions (9.21) were given in Section 7.3. The GEE methodology can now be implemented using the mean-structure given above and a variance-covariance structure $\mathbf{V}_j$ for the observations vectors $y_{ji}$, $l=1,2,...,m_j$, where

```
$Var = \begin{pmatrix} y_{j1} \ y_{j2} \ \vdots \ y_{j,m_j} \end{pmatrix} = \mathbf{V}_j$ (9.22)
```
