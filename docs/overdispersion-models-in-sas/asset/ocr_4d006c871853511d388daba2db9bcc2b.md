# Program 10.3: Fitting a Cumulative Logit GLMM to the Shoulder Tip Pain Data

```
ods html;
proc glimmix data=Shoulder_tip_pain method=quad;
class subject_id_trt gender;
model y = trt gender age time / dist=mult link=clogit;
random int / subject-subject_id;
format trt $abc. gender $xyz;
estimate 'Active Vs Placebo' trt 1 -1 / or;
title *** Fitting a Cumulative Logit GLMM to the Shoulder Tip Pain Data ***';

proc glimmix data=Shoulder_tip_pain_empirical=classical method=quad;
class subject_id_trt gender;
model y = trt gender age time / dist=mult link=clogit;
random int / subject-subject_id;
format trt $abc. gender $xyz;
estimate 'Active Vs Placebo' trt 1 -1 / or;
title1 *** Fitting a Cumulative Logit GLMM to the Shoulder Tip Pain Data ***';
title2 *** with an Empirical Variance for Estimates of Fixed Effects ***';
title3 *** with the MBN small sample variance correction ***';
ods html close;
```

The results of Program 10.3 for the first model are also depicted in Output 10.3.
The Model information output shows, among others, that the response is ordinal Multinomial, the link function is Cumulative Logit, the estimation technique is Maximum Likelihood, the likelihood was approximated by the Gauss-Hermite Quadrature method. The estimate of the variance of the random intercepts σ² turned to be 4.6759 with an estimated standard error of 1.6741. The Solution for Fixed Effects as well as Type III of Fixed Effects are also shown in Output 10.3. We requested the odds-ratio of Active Placebo. Its estimated value was 17.86 (the P-value associated to the logarithm of the odds-ratio was 0.0004). Recall the estimated odds ratio under the GEE Logit model discussed in Section 9.9 of Chapter 9 was 14.52.
