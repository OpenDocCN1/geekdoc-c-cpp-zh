# Program 10.4: Generation and Analysis of Data under a Beta-binomial GLOMM

```
/*
Beta-binomial GLOMM

Beta-binomial Model with Logit Link and Random Effects
Random effects due to Cross-over Design

t given u ~ Beta-binomial(pi,rho,n)
logit(pi) ~ beta0 + betal * X + u
u ~ Normal(0,sigma=sigma)
*/
data GLOMM, bn;
n = 200;
pi_1 = 0.12;
pi_2 = 0.08;
m = 20;
rho_2 = 0.15;
sigma = 1.2;
seed = 1983;
beta0 = log(pi_1/(1-pi_1));
betal = log(pi_2/(1-pi_2)) - beta0;
c = 1 / rho_2 / rho_2 - 1;

--- Overdispersion Parameter;
----------------------
--- u ~ Normal(0,sigma=sigma);
--- Seed;
----------------------
--- Sequence AB;
n----------------------
do Subj_id=1 to n;
----------------------
Sequence = 'AB';
u = sigma * normal(seed);
--- Period 1;-
Period = 1;
Product = 1;
X = 1 / (1 + exp(- beta0 - u));
pi = c * pi;
a = c - a;
y1 = rangam(seed, a);
y2 = rangam(seed, b);
y = y1 / (y1 + y2);
t = rabnin(seed,m,p);
output:
--- Period 2;-
Period = 2;
Product = 0;
X = 1 / (1 + exp(- beta0 - betal - u));
pi = c * pi;
a = c - a;
y1 = rangam(seed, a);
y2 = rangam(seed, b);
y = y1 / (y1 + y2);
t = rabnin(seed,m,p);
output:
---*-
end;
----------------------
--- Sequence BA;
----------------------
do Subj_id=n+1 to n+n;
----------------------
Sequence = 'BA';
```
