If the Poisson model holds equations (9.10) provide the maximum likelihood estimator of $\hat{eta}$, say
hat{eta}$, with the variance estimate of $\hat{eta}$ being

```
$$\widehat{Var}(\hat{eta}) = \left(\sum_{j=1}^{n} \mathbf{x}_j \hat{x}_j^T\right)^{-1} = \hat{\mathbf{I}}_0^{-1}, \quad (9.11)$
```

where $\hat{v}_j = \mu_j = \exp\{\mathbf{x}_j^T \hat{eta} + \ln(z_j)\}$. Furthermore, when the Poisson model assumption is not
satisfied, an estimator of the asymptotic variance of $\hat{eta}$ can be obtained using the GEE
methodology, which is given by

```
$$\widehat{Var}(\hat{eta}) = \hat{\mathbf{I}}_0^{-1} \hat{\mathbf{I}}_0^{-1}, \quad (9.12)$
```

where $\hat{\mathbf{I}}_i = \sum_{j=1}^{n_i} (y_j - \mu_j)(y_j - \mu_j) \mathbf{x}_j^T$.

Consider now the following Poisson model for k independent groups

```
$$E(y_{ij}) = \exp\{\hat{eta} + \ln(z_{ij})\}, i=1, 2,...,k, j=1, 2,...,n_i. \ \quad (9.13)$
```

It can be shown that the maximum likelihood estimator of $\beta_i$ is given by

```
$$\hat{\beta}_i = \ln\left(\frac{\sum_{j=1}^{n_i} y_{ij}}{\sum_{j=1}^{n_i} z_{ij}}\right) = \ln(\hat{R}_i), i=1, 2,...,k. \ \quad (9.14)$
```

For the i-th group, it can be shown that equation (9.10) becomes

```
$$\exp(\hat{\beta}_i) \left(\sum_{j=1}^{n_i} z_{ij}^{-1}\right) \left[\sum_{j=1}^{n_i} (y_{ij}-z_{ij}) \exp(\hat{\beta}_i)\right] = 0,$
```

where $\exp(\hat{\beta}_i) = R_i$. Therefore, the solution to this equation yields the explicit representation
given above in equation (9.14). Similarly, the sandwich estimator in equation (9.12) provides the
large sample size estimator of asymptotic variance of the logarithm of the ratio of the means,
nnamely,

```
$$\widehat{Var}(\hat{\beta}_i) = \left(\\sum_{j=1}^{n_i} (y_{ij}/\hat{R}_i z_{ij})^{-2}\right)^2, \quad i=1, 2,...,k. \ \quad (9.15)$
```
