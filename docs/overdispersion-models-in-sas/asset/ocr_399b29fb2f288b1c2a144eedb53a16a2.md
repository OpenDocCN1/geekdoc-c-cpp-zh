# Program 9.7: Testing for Homogeneity with clustered Trinomial Outcomes

```
/*
Testing for Homogeneity with clustered Trinomial outcomes.

Underlying probability vectors are

Product        2         3
------      ------ -----
1               0.880   0.110   0.010
2               0.900   0.075   0.025
*/
data test of homogeneity;
n = 175;      -- Number of Panels (Clusters) per Test Product;
m = 8;        -- Number of Repeated Measurements per Panelist;
rho2 = 0.15;  -- Intra Cluster Correlation;
pill1 = 0.880;  -- Probability Category 1, Product 1;
pill2 = 0.900;  -- Probability Category 1, Product 2;
p12 = 0.110;  -- Probability Category 2, Product 1;
p22 = 0.075;  -- Probability Category 2, Product 2;
seed = 1972;  -- Initial Seed;
rho = sqrt(rho2);
cpill12 = pill1 + pill12;
cpill22 = pill12 + pill22;
dj = 1 to n;
Product = 1;
Subid = -;
YY
y = 3;
u = uniform(seed);
if u < cpill12 then y = 2;
if u < pill1 then y = 1;
doi = 1 to mj;
Y = 3;
```
