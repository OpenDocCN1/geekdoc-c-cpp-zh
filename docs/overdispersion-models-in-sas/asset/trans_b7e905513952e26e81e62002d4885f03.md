## 1.6 指数族

本书要涵盖的主要任务，即拟似然函数、广义线性模型（GLM）、广义估计方程（GEE）和广义线性混合模型（GLMM），都是由指数族所有成员适用的众多统计方法的普遍性所驱动的。因此，我们首先通过概述其一些性质，对指数族密度进行简要介绍。指数族是一类具有某些特征和性质的密度函数族。该族的成员包括正态、二项分布、伯努利、多项、泊松、负二项、Beta 和 Gamma 分布。这一分布族在经典统计推断技术中起着非常重要的作用。遵循文献，我们在分析中使用规范参数和规范链接设置，但所有示例都将使用族记法，这可能是规范的，也可能不是规范的。

该族中的密度函数可以写成

```
$f(y) = \exp\left(\frac{y\theta - b(\theta)}{\phi} + c(y, \phi)\right\},\quad (1.8)$
```

$b(\cdot)$ 和 $c(\cdot)$ 是某些特定函数。参数 $\theta$ 是一个实值 **位置参数**，被称为 **自然**（或规范）参数。函数 $b(\theta)$ 被称为 **累积量**，参数 $\phi$ 被称为 **离散（或尺度）参数**。我们假设 $b(\theta)$ 是连续二阶可微的。在正态分布的情况下，参数 $\phi$ 对应于方差 $\sigma^2$，并且在功能上与均值无关。另一方面

```
$Var(Y) = \phi v(\mu) \quad (1.11)$
```

表 1.3 显示了伯努利和泊松分布作为指数族成员的主要特征。请注意，对于伯努利分布，均值和规范链接函数分别是 logistic 和对数函数。对于二项分布（未在表 1.3 中显示）也是如此。对于泊松分布，指数函数和对数函数分别是相关的均值和链接函数。

# 表 1.3：伯努利和泊松分布的主要特征

| 特征 | Bernoulli | Poisson |
|---|---|---|
| 概率函数（通常形式） | $\pi^y(1-\pi)^{1-y}, y=0,1, 0<\pi<1$ | $e^{-\lambda}\lambda^y/y!, y=0,1,2,...,\lambda>0$ |
| 累积量 $b(\theta)$ | $\log(1+e^\theta)$ | $\exp(\theta)$ |
| 均值函数 | $\pi = \frac{e^\theta}{1+e^\theta}$（logistic 函数） | $\lambda = \exp(\theta)$（指数函数） |
| 规范链接函数 | $\log(\frac{\pi}{1-\pi}) = \theta$（logit 链接） | $\log(\lambda) = \theta$（对数链接） |
| 离散参数 $\phi$ | 1 | 1 |
| 方差函数 $v(\mu)$ | $\pi(1-\pi)$ | $\lambda$ |
| 概率函数（规范） | $\exp\{y\ln(\frac{\pi}{1-\pi})+\ln(1-\pi)\}$ | $\exp\{y\ln(\lambda)-\lambda-\ln(y!)\}$ |

## 广义线性模型

### 2.1 引言

标准线性模型由两个组成部分构成：系统效应和随机误差。广义线性模型（GLM）是将通常的线性回归推广到二项、泊松、负二项、Gamma 和 分布的扩展。最初由 Nelder 和 Wedderburn（1972）提出，它先于拟似然、广义估计方程（GEE）和广义线性混合模型（GLMM）。在本章中，我们将回顾 GLM 的基本概念，强调过离散。

### 2.2 线性回归模型

设 $Y_j, j=1,2,...,n$，为独立随机变量，且 $y_j$ 表示 $Y_j$ 的一个实现。与每个 $y_j$ 相关联的是一个已知的 $k$ 维行协变量向量 $\mathbf{x}_j = (x_{1j},x_{2j},x_{kj})$ 和一个未知的 $k$ 维列参数向量 $\boldsymbol{\beta} = (\beta_1,\beta_2,...,\beta_k)^T$，使得

```
$y_j = \sum_{i=1}^k x_{ij}\beta_i + \varepsilon_j \quad (2.1)$
```

其中 $\varepsilon_i$'s 是不相关的随机变量，使得 $E(\varepsilon_i)=0$ 且 $Var(\varepsilon_i)=\sigma^2$。这是经典的线性模型。线性模型（2.1）的矩阵形式为

```
$\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon} \quad (2.2)$
```

其中 $y$ 是一个 $n$1 向量，$y=(y_1,y_2,...,y_n)^T$，$X$ 是一个 $n \times k$ 已知协变量矩阵，$\mathbf{X} = (\mathbf{x}_1,\mathbf{x}_2,...,\mathbf{x}_n)^T$，且 $\varepsilon$ 是一个 $n \times 1$ 扰动向量，$\varepsilon = (\varepsilon_1,\varepsilon_2,...,\varepsilon_n)^T$。假设 $n > k$。
