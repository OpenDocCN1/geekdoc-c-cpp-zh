# Program 2.1: Gains in Weight—Simple Linear Regression Using OLS and MLE Methods

```
/*
nedecor and Cochran 1980, 7th Ed. Pages 156-157
Gains in Weight Example
*/
data gains_in_weight;
  do Rat=1 to 15;
    input x @@
    output;
  end;
datalines;
  50 64 76 64 74 60 69 68 57 48 57 49 46 65
  128 158 159 119 133 112 96 126 132 118 107 106 82 103 104
;

proc sort data=gains_in_weight;
  by rat;
run;
proc transpose data=gains_in_weight out=gains_in_weight
  (rename=(COL1=Initial_Weight COL2=Gains));
  by rat;
  var x;
run;
ods html;
  graphics on;
  title """ MLE Results -- Gains in Weight Data ****"
proc glimmix data=gains_in_weight_plots=residualpanel;
  model Gains = Initial_Weight / solution;
run;
  title """ MLE Results -- Gains in Weight Data ****"
proc glimmix data=gains_in_weight noremli;
  model Gains = Initial_Weight / solution;
run;
ods graphics off;
ods html close;
```

In the case of model (2.1), the GLIMMIX procedure does not use any iterative fitting. However, the scale parameter $\sigma^2$ is estimated by the residual sum of squares by the residual degrees of freedom $(n-k=13)$ providing $\hat{\sigma}^2$, rather than the total number of rats $(n=15)$ which would correspond to $	ilde{\sigma}^2$. The latter is the maximum likelihood estimator whereas the former is an unbiased estimator and a well-known method. Unlike PROC GLM and REG, the GLIMMIX procedure provides an estimate of the standard error of $	ilde{\sigma}^2$. To obtain $\hat{\sigma}^2$ of the scale parameter $\sigma^2$, the NOREML option should be included in the PROC GLIMMIX statement. The main results of Program 2.1 are reported in Output 2.1.
