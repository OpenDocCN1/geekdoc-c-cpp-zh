
## Table 3: The fseek() Function and Various Possibilities

| **Statement** | **Operation** |
| :--- | :--- |
| fseek(file_pointer, 0L, 0) | Move the file pointer to the beginning of the file |
| fseek(file_pointer, 0L, 1) | Stay at current position |
| fseek(file_pointer, 0L, 2) | Move the file pointer to the end of the file |
| fseek(file_pointer, k, 0) | Move file pointer (k+1)th byte forward from the beginning of the file |
| fseek(file_pointer, -k, 2) | Move the file pointer (k-1)th byte backward from the end of the file |

When the operation is successful, the function fseek returns a zero. When unsuccessful operations are performed, the function returns −1. An example of unsuccessful operation is fseek(fp_item,5,2). The number 2 denotes EOF. Thus, the statement fseek(fp_item, 5, 2) attempts to move file pointer 5 bytes forward from the end of the file. C library also contains a rewind function to position the file pointer at the beginning. Its working is similar to that of fseek(file_pointer,0L,0).

Program 8 illustrates the use of function fseek to display the record available in a disk file and positioned on the position supplied by the user:

### ▶ Program 8

```c
/* Program to illustrate the use of function fseek*/
#include<stdio.h>

/* Beginning of main function */
int main()
{
    FILE *fp_item;
    struct item
    {
        int i_itemno;
        char c_itemname[20];
        int i_itemqty;
        float f_itemrate;
    } items;
    
    int i_ctr=0, i_num, i_recsz=sizeof(items);
    char c_temp, c_ans;

    fp_item=fopen("itemb", "rb");
    if (fp_item==NULL)
        printf("Error in opening a file\n");
    else
    {
        do
        {
            printf("\nEnter the position of the item you would like to display: ");
            scanf("%d", &i_num);
            c_temp=getchar();
            rewind(fp_item);
            fseek(fp_item, --i_num*i_recsz, 1);

            if (fread(&items, i_recsz, 1, fp_item)!=0)
            {
                printf("\n The record you are searching for is....\n\n");
                printf("    %d %-15s %5.2f  %5d ", items.i_itemno,
                    items.c_itemname,
                    items.f_itemrate, items.i_itemqty);
                printf("\n");
            }
            else
                printf("\nThe record you are searching is not available.\n");
            
            printf("\nWould you like to continue (y/n): ");
            scanf("%c", &c_ans);
        } while (c_ans=='y' || c_ans=='Y');
    }
    fclose(fp_item);
    return 0;
}
/* End of function main */
```

**Output:**

> Enter the position of the item you would like to display: 2
> The record you are searching for is....
>        2 Pencil                1.50     50
> Would you like to continue (y/n): y
> Enter the position of the item you would like to display: 3
> The record you are searching is not available.
> Would you like to continue (y/n): n

The file created with Program 7 is opened in Program 8 in read mode. The user is asked to type the position. The statement `fseek(fp_item,--i_num*i_recsz,1);` is provided with three parameters. The first parameter is the file pointer `fp_item` pointing to file *itemb*. The second parameter is `--i_num*i_recsz`, where the variable `i_recsz` is the size of one record in bytes. In Program 8, the variable `i_recsz` would be the sum of bytes required to hold data elements itemno, itemname, itemrate, and itemqty of structure variable items. Thus, the value of `i_recsz` would be 28 bytes. The variable `i_num` is the position where the file pointer is to be positioned. As decrement operator has been used along with the variable `i_num`, the value of `i_num` is decremented by 1 before multiplying it to `i_recsz`. The result of expression `--i_num*i_recsz` is then used to calculate the number of bytes that the file pointer is to be moved forward. The function `fseek`, as described in a table, moves k+1 byte forward from the position provided as third parameter, where k is the set of bytes and 1 stands for one set of such bytes. Thus, k should be taken 1 less than the intended movement. If the user enters 5, then the file pointer should be moved 4*28 bytes forward from the beginning of the file. Thus, the function `fseek` will position the file pointer to 4*28 bytes from the beginning of the file, and it is the fifth record that is desired by the user.

Once the file pointer is positioned at a proper position, the function `fread` is used to read the record. The `fread(&items, i_recsz, 1, fp_item)` statement reads the record where the file pointer is positioned. The `fread` function returns the number of records read from the file. If it returns 1 in Program 8, the record is available on the position supplied by the user and is displayed on the screen. If it returns 0, no record is available on that position, and thus, appropriate message is displayed on the screen.

Note the statement rewind(fp_item) in Program 8. The function rewind is used to set the file pointer at the beginning of the file. When the first iteration is performed and the user enters 5, the file pointer is positioned at 28*4 bytes forward in the file. Now, if the user wishes to continue to search, the file pointer needs to be repositioned to the beginning of the file. The rewind(fp_item) statement rewinds and positions the file pointer fp_item to the beginning of file itemb.

## Locating the File Pointer Position

The function ftell is used to know the position in a file at which its corresponding file pointer is pointing. It returns this position as a long int, which is an offset from the beginning of the file. The syntax of the function ftell is as follows:

```c
n = ftell(file_pointer);
```

The function ftell accepts one parameter. The parameter is the file pointer, which is pointing to the file to be accessed. Program 9 illustrates the use of function ftell:

### ▶ Program 9

```c
/* Program to illustrate the use of function ftell */
#include<stdio.h>
#include<string.h>
#define TRUE 1
#define FALSE 0

/* Beginning of main function */
int main()
{
    FILE *fp_item;
    struct item
    {
        int i_itemno;
        char c_itemname[20];
        int i_itemqty;
        float f_itemrate;
    } items;
    
    int i_recsz=sizeof(items);
    int i_ctr=0, i_num, found;
    char c_temp, c_ans, c_item[20];

    fp_item=fopen("itemb","rb");
    if (fp_item==NULL)
        printf("Error in opening a file\n");
    else
    {
        do
        {
            printf("\n Enter Name of item: ");
            scanf("%s", c_item);
            rewind(fp_item);
            found=FALSE;
            while (fread(&items, i_recsz, 1, fp_item)!=0)
            {
                if (strcmp(c_item, items.c_itemname)==0)
                {
                    i_num = ftell(fp_item) / i_recsz;
                    found = TRUE;
                    break;
                }
            }
            if (!found)
                printf("\nThe record you are searching is not available.\n");
            else
            {
                printf("\n The record is available at position %d\n", i_num);
                printf("The record details are.........\n");
                printf("%d %s %.2f %d", items.i_itemno, items.c_itemname, items.f_itemrate, items.i_itemqty);
            }
            c_temp = getchar();
            printf("\nDo you want to continue: ");
            scanf("%c", &c_ans);
        } while (c_ans == 'y' || c_ans == 'Y');
    }
    fclose(fp_item);
    return 0;
}
/* End of function main */
```

**Output:**

> Enter Name of item: Pen
> The record is available at position 1
> The record details are.........
> 1 Pen 10.00 12
> Do you want to continue: y
>
> Enter Name of item: Pencil
> The record is available at position 2
> The record details are.........
> 2 Pencil 1.50 50
> Do you want to continue: y
>
> Enter Name of item: Eraser
> The record you are searching is not available.
> Do you want to continue: n

Program 9 accepts the name of the item from the user. It then reads the record of the file itemb one by one. The read record contains item name. This item name is compared with the item name supplied by the user using strcmp function. If the match is successful, the function ftell is called with the file pointer fp_item as its parameter. The function ftell then returns the position of the record that is displayed on the screen. It actually returns the total number of bytes preceding the file pointer position from within the file. For example, if 140 is returned by the function ftell, the position of record is 140/28 = 5, where 28 is the number of bytes occupied by a structure item.

The variable named *found* is used to check whether the record corresponding to item name supplied by the user exists or not. Initially, the value of variable *found* is set to FALSE. Later, when a successful match is obtained, the value of variable *found* is set to TRUE. If the value of variable *found* is set to FALSE, it indicates that no record containing the item name supplied by the user is found and an appropriate message is displayed on the screen.
