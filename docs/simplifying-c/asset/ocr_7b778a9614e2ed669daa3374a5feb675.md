# I Appendix: List of Common Header Files and Their Library Functions

The library functions in C language at times accept parameters from the user. The parameters are of different data types. We have classified the data types as per the classification in the following Table 1:

Table 1: Conventions Used in Function Parameters

| Specification Used | Parameter Type |
|:-------------------|:---------------|
| ch                 | Character      |
| db                 | Double         |
| fl                 | File           |
| int                | Integer        |
| lg                 | Long integer   |
| ptr                | Pointer        |
| str                | String         |
| uint               | Unsigned integer|

Table 2 lists some header files available in C compiler along with the inbuilt functions provided in these header files:

Table 2: Commonly Used Inbuilt Functions

| Header File | Library Function | Return Type | Description                                                                                                      |
|:------------|:-----------------|:------------|:-----------------------------------------------------------------------------------------------------------------|
| ctype.h     | isalnum(ch)      | int         | Determines whether or not the parameter is alphanumeric. It returns a nonzero value if the character is alphanumeric; otherwise, 0. |
| ctype.h     | isalpha(ch)      | int         | Determines whether or not the parameter is alphabetic. It returns a nonzero value if the character is alphabetic; otherwise, 0. |
| ctype.h     | isascii(ch)      | int         | Determines whether or not the parameter is the American Standard Code for Information Interchange (ASCII) character. It returns a nonzero value if true; otherwise, 0. |
