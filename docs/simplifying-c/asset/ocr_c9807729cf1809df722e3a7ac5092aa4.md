# Numeric Constant

Numeric constants have the capacity to store numeric value. They are further divided in two categories: integer constants and real constants.

# Integer Constant

Integer constant refers to a whole number. C language supports three types of integer constants, namely, decimal, hexadecimal, and octal.

The decimal constant is formed by the combination of digits 0 to 9. It is also possible to prefix unary plus or minus to decimal constants.

The hexadecimal constant is formed by the combination of digits 0 to 9 and letters A to F. The letters A to F refer to decimal values 10 to 15, respectively. The hexadecimal numbers have base 16. It is differentiated from the decimal numbers by using 0x or 0X as prefix in C Language.

The octal constant is formed by the combination of digits 0 to 7. The base of this number system is 8. It is differentiated from the decimal numbers by using o or O as prefix in C language. A list of some valid and invalid integer constants as per C Language rules are listed in Table 6.
