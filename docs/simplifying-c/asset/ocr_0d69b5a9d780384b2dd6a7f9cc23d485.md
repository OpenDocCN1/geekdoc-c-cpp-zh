# Standard Input

Standard input, more commonly known as stdin, is a data in the form of a text stream that goes into a C program. As we know that in most cases, we enter data to our programs using the keyboard; in C, the keyboard is considered as a standard input file. The user transfers the data using the keyboard character by character. These characters are then stored in a temporary memory location called buffer until the entire line is read. In most cases, the end of line is indicated by pressing the Enter key on the keyboard. Once the entire line is read, the C program converts it into appropriate data type and stores them in appropriate variables. As the input is stored in a buffer initially, it becomes easy to edit the entry that is being done. For example, if we are entering a number and by mistake we enter a wrong number. Then, by pressing the Backspace key, we can easily delete the wrong entry and correct it before it gets stored in the variable. Figure 1 shows the concept of buffering using standard input:

# Standard Output

Standard output, more commonly known as stdout, is a text stream where a program writes its output data. The monitor is considered to be a default standard output file unless the output is redirected to any other file. In this case, the compiler takes data from the memory block and passes it to the C program; a function within this program, which is based on some specification, then generates a stream of characters. These characters are then displayed on the monitor. Figure 2 shows the concept of output using standard output stream:
