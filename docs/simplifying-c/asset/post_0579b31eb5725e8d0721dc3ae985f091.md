It can be observed in Figure 8 that the flow of the control is from top to bottom. To stop the flow from executing all statements, we use the keyword break. If the break statement is not used at the end of action block, the compiler will go on executing all the statements of the following action block till it finds a break statement or it encounters the end of switch structure. In addition, it is not compulsory that the default case has to appear at the end of all action blocks. It can appear anywhere within the switch structure. For example, it can be the first case and still the switch structure will work fine. Program 9 illustrates the use of switch structure:

### ▶ Program 9

```c
/* Program to illustrate the use of switch structure */

#include <stdio.h>

/* Beginning of main function */
main()
{
/* Declare variable */
int i_first, i_second;
int i_choice, i_result;

/* Input Data */
printf("Enter first number: ");
scanf("%d", &i_first);
printf("\nEnter second number: ");
scanf("%d", &i_second);

/* Print Menu */
printf("\n*****Operation Menu*****\n");
printf("Enter 1 to perform Addition.\n");
printf("Enter 2 to perform Subtraction.\n");
printf("Enter 3 to perform Multiplication.\n");
printf("Enter 4 to perform Division.\n\n");

/* Accept user choice */
printf("Enter your choice : ");
scanf("%d", &i_choice);

/* Check for choice entered and perform the required operation */
/* switch structure begins */
switch(i_choice)
{
  case 1:
    i_result = i_first + i_second;
    printf("\nAddition of %d + %d is %d\n", i_first, i_second, i_result);
    break;
  case 2:
    i_result = i_first - i_second;
    printf("\nSubtraction of %d - %d is %d\n", i_first, i_second, i_result);
    break;
  case 3:
    i_result = i_first * i_second;
    printf("\nMultiplication of %d * %d is %d\n", i_first, i_second, i_result);
    break;
  case 4:
    if(i_second == 0)
      printf("\nDivision not possible\n");
    else
    {
      i_result = i_first / i_second;
      printf("\nDivision of %d / %d is %d\n", i_first, i_second, i_result);
    }
    break;
  default:
    printf("\nInvalid choice no operation possible.\n");
}  /* switch structure ends */
return;
}  /* End of main function */
```

It can be observed in Program 9 that the switch structure takes the value of i_choice and compares it with different case values such as 1, 2, 3, and 4. In case any choice matches with the case value specified, the operation mentioned within that case block is executed. Observe that in case 4, we have used the if-else statement. As the else statement had multiple statements to execute, we have provided a scope for it. Note that we have not used the break statement in the default action statement. Once the default action block is executed, the next statement indicates end of the switch structure, and the flow will automatically move downward from this point of the switch structure.

Let us take one more example to understand the usage of switch structure better. Program 10 illustrates the use of switch structure, where the default action block is placed in the beginning.

### ▶ Program 10

```c
/* Program to illustrate the use of switch structure */
#include <stdio.h>
#include <ctype.h>

/* Beginning of main function */
main()
{
	/* Declare variable */
	char c_character;

	/* Input Data */
	printf("Enter a character: ");
	scanf("%c", &c_character);

	/* Check for entered character and determine its type */

	/* switch structure begins */
	switch(c_character)
	{
	default:
		if(isdigit(c_character))
			printf("\nCharacter %c is number.\n", c_character);
		else if (isalpha(c_character))
			printf("\nCharacter %c is consonant.\n", c_character);
		else
			printf("\nCharacter %c is special character.\n", c_character);
		break;
	case 'A':
	case 'a':
	case 'E':
	case 'e':
	case 'I':
	case 'i':
	case 'O':
	case 'o':
	case 'U':
	case 'u':
		printf("\nCharacter %c is vowel\n", c_character);
	}	/* switch structure ends */
	return;
}	/* End of main function */
```

### Output 1:

```text
Enter a character: e
Character e is vowel
```

### Output 2:

```text
Enter a character: 0
Character 0 is number
```

### Output 3:

```text
Enter a character: q
Character q is consonant
```

### Output 4:

```text
Enter a character: $
Character $ is special character
```

It can be observed in Program 10 that the default statement is placed at the start of the switch structure. The last statement in the default action block is the break statement. The break statement here becomes compulsory to stop the compiler from executing any other case actions. In addition, observe that we have written only one action block for case A, a, E, e, I, i, O, o, U, and u. As soon as any of the case matches the value of c_character, the execution control is transferred to the statement `printf("\nCharacter %c is vowel\n", c_character);`. Note that we have not written the break statement after the action block for the above case. The reason is similar to the one indicated in Program 9.

Note that when the switch cases are written, the case labels cannot be duplicated. This means that one constant (integer or character) can occur only once as a case label. In case of Program 10, case A and case a refer to two different labels as the ASCII value of A and a is not same. The American National Standards Institute (ANSI) C gives us a provision to create maximum 257 case labels.

The multiway selection construct is thus useful if we have many options to select.

## Summary

In this chapter, we have learned how to change the flow of execution of a program. C language provides decision constructs, such as if, if-else, nested if, if-else ladder, and switch case, to change the flow of execution. The decision constructs, namely, if, if-else, and nested if, are used for two-way selection. For a multiway selection, we use the if-else ladder and the switch-case decision structure. We also discussed the problem of dangling else that arises when if statements are nested in a program.
