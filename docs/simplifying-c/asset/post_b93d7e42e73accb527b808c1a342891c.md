### 11.2 Structures in C Language

To use a structure in C language, we first need to define a structure template. The template identifies the name and members of the structure. The keyword `struct` helps the user to define a structure template. The syntax to define a structure is as follows:

```
struct structure_name {
    datatype member1;
    datatype member2;
    datatype member3;
    .
    .
    datatype membern;
};
```

In the preceding syntax, the keyword `struct` is followed by the name of the structure. The name of a structure is an identifier and has to be unique throughout the scope of the program. The variables to be grouped together in a structure are placed between curly braces. The structure template is terminated by a semicolon (;) at the end of the closing curly braces.

The scope of the structure template is similar to that of normal variables. The structure template can be declared outside the main function or within the main function. If the structure template is defined within the main function, its scope will be limited to the main function only. If it is defined outside the main function, the structure assumes global scope. Such a structure can be accessed in all the functions of the program that are defined below the structure definition.

A structure template that holds contact details of a person, such as name, phone number, and electronic-mail (email), can be defined using the syntax shown in Figure 2:

![](img/5d422ba7108ffdf64376be51eaf0c459_234_0.png)

Figure 2 shows that the structure has three data members called `c_name`, `li_phone`, and `c_email`. The data member’s `c_name` and `c_email` are character array, while `li_phone` is an unsigned long integer. The name of the structure template is `contact`. No memory space is allocated by the compiler when a structure template is declared. The memory gets allocated only when we declare a variable of type structure. Once a template is defined, it works as a data type in C. This is the reason why a structure is called a derived data type. A programmer can now define variables of structure data type as per their need. The next section discusses how to declare structure variables in C language.

### 11.3 Structure Variables

Once the structure template is defined, it can be used as a data type. The name of the structure acts as a user-defined data type. The syntax to declare a structure is as follows:

```
struct struct_name name_of_variable;
```

It is now possible for us to define variables of the struct `contact` shown in Figure 2. Assume that we need to define two contacts; the definition will then be as mentioned:

```
struct contact contact1, contact2;
```

We have declared two structure variables, namely, `contact1` and `contact2`, of type `contact`. Each of these structure variables can now contain a string named `c_name` that holds 25 characters, an unsigned long integer variable `li_phoneno`, and a string named `c_email` with 30 characters, as shown in Figure 3:

![](img/5d422ba7108ffdf64376be51eaf0c459_235_0.png)

**Figure 3: Structure Variables Occupying Separate Memory Space**

As mentioned earlier, the structures do not occupy any memory until they are associated with the structure variable. In the preceding case that declares two structure variables, the declaration of structure `contact` will not occupy any memory until the structure variables `contact1` and `contact2` are declared. Thus, the members of the structure will not have any existence until they are associated with structure variables.

A structure variable can also be defined at the time of declaration of template, as shown in Table 1:

**Table 1: Alternate Definition of Structures**

| Method 1 | Method 2 |
| :--- | :--- |
| `struct contact` | `struct` |
| `{` | `{` |
| `char c_name[25];` | `char c_name[25];` |
| `unsigned long int li_phoneno;` | `unsigned long int li_phoneno;` |
| `char c_email[30];` | `char c_email[30];` |
| `} contact1, contact2;` | `} contact1, contact2;` |

It can be seen in Table 1 that we have declared the variables before terminating the structure template. Both the methods mentioned in Table 1, though available in C language, are seldom used by programmers for the purpose of declaring a structure. The second definition that does not include the template name does not allow us to declare any new variable of structure within the program.

Similar to normal variables, the structure variables also reserve memory space. This memory space is not a predefined similar to that of `int`, `char`, and other data type, as the number of members in a structure may vary. C language provides one special operator to find the size of the structure. The usage of the `sizeof` operator is shown in the next section.

### 11.4 Size of Structure Variables

The size of memory allocated to a structure is equal to the sum of the sizes of all the data members it holds. Program 1 illustrates the declaration of structure template, structure variables, and printing memory occupied by a structure type variable:

**Program 1**

```c
/* Program illustrating the size of structure */
#include<stdio.h>
/* Beginning of main function */
main()
{
  /* Declaration of Structure */
  struct contact
  {
    char c_name[25];
    unsigned long int li_phoneno;
    char c_email[30];
  };
  /* Display size of structure contact */
  printf("The size of structure contact is %d\n", sizeof(struct contact));
  return;
}
/* End of function main */
```

**Output:**
```
The size of structure contact is 64
```

It can be observed in Program 1 that the output of the program is 64 bytes and not 59 bytes, as expected. The compiler when allocating memory to the structure variable adds additional bytes, if needed, to align all the addresses of the data members according to the largest sized data member. This is the reason we get the size as 64 bytes instead of 59 bytes.

Let us try to understand this concept more clearly. In case of the template `contact`, the `char` data type occupies 1 byte, while the `unsigned long int` occupies 4 bytes. The larger size out of the two is 4 bytes. Therefore, the compiler will align all the variable addresses in the multiple of 4. The first variable `c_name` will thus occupy 28 (25 + 3) bytes, the `unsigned long int` will occupy 4 bytes, and the `c_email` will occupy 32 (30 + 2) bytes. The compiler has added 3 + 2 = 5 bytes extra to align all the structure members evenly, as shown in Figure 4:

![](img/5d422ba7108ffdf64376be51eaf0c459_236_0.png)

This extra byte padding is also referred to as struct member alignment. The extra bytes padded to align the address are known as holes. This padding is done so that each member of the structure can be accessed faster without delays. Modern Central Processing Units (CPUs) perform better in data transfer when the fundamental data types, such as integer and float, are stored in the memory addresses that are in multiples of their length. The data members that have unaligned memory allocation require extra data transfer, thereby resulting in performance degradation.

It is advisable to group members of the same data type together at the time of structure declaration to minimize the extra padded bytes needed for the alignment. For example, if the structure declaration shown in Figure 4 is defined as shown in Figure 5, the single structure member will occupy 60 bytes instead of 64 bytes:

![](img/5d422ba7108ffdf64376be51eaf0c459_237_0.png)

**Figure 5: Structure with Rearranged Structure Members**

It can be seen in Figures 4 and 5 that two structures with the same data elements, but with different arrangement of data elements, make a different sized structure.

### 11.5 Assigning Values to Structure Members

As mentioned earlier, the structure members are associated with the structure variables. Each data member of a structure can then be used as an independent variable. To access the data members, we need to create a link between a member and a variable of the structure. This link is established using the member operator "." (dot). Program 2 illustrates the usage of dot operator:

**Program 2**

```c
/* Program to store and retrieve contacts using a structure */
#include<stdio.h>
/* Beginning of main function */
main()
{
/* Declaration of structure */
struct contact
{
char c_name[25];
char c_email[30];
unsigned long int li_phoneno;
};

/* Structure alias */
```
