# Function calloc

The function calloc is used to allocate memory space that will store elements of the same data type. It allocates contiguous block of memory. Once the memory is allocated, it then sets all bytes to zero. The function malloc reserves single block of specified size, while the function calloc reserves $n$ memory blocks, each of specified size. The syntax of using the function calloc is as follows:

```
ptr=(cast-type*) calloc(n, element-size);
```

The preceding statement allocates contiguous space for n memory blocks, each of the size specified. All bytes are initialized to zero and a pointer to the first byte of the allocated region is returned. If there is not enough space, a NULL pointer is returned. For example, to allocate memory space for 25 float elements that are all initially zero, the following statements can be used:

```
float *fptr;
fptr = (float *) calloc(25, sizeof(float));
```
