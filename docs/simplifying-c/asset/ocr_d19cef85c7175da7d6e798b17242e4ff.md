i_arr+1 is 65520, which was not expected. The address of the second element in the first row was expected in i_arr +1. However, i_arr when incremented by 1 is directly incremented by 12. The address 65520 is an address of the first element in the second row. Similarly, i_arr+2 returned 65532. The expected address was the address of the third element in the first row, but the address returned is the address of the first element in the third row. Thus, when an integer is added to a pointer in an array i_arr, the address location is advanced by 24 (12 × 2) bytes. Note that we may get different addresses each time the program is executed.
