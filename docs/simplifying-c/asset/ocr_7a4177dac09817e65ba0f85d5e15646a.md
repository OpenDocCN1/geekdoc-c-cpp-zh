# Symbolic Constant Definition

A symbolic constant refers to a short name given to either a set of characters or a numeric value in a C program. A symbolic constant PI has been used in Program 2. A preprocessor directive #define is used to define any symbolic constant. It instructs the compiler to replace all occurrences of symbolic constants with the values specified against it. The symbolic constants are usually defined using capital letters to differentiate them from variables used in C programs. Two examples of the symbolic constants are as follows:

```
#define PI 3.14
#define P printf
```

The first example defines a symbolic constant PI for 3.14, while the second example defines a symbolic constant P for printf. Here, PI and P are referred to as symbol and constant as the value of 3.14 and printf will not change throughout the execution of C Program.
