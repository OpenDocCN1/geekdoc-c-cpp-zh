#include<stdio.h>
/* Function prototype*/
int min(int *,int*);
main()
{
    /* Declare variable */
    int *ptr_list,*ptr_temp, i_num, i_ctr, i_min;
    
    /* Accept number of integers in list */
    printf("How many numbers would you to store in a list: ");
    scanf("%d", &i_num);

    ptr_list=(int *)malloc(i_num*sizeof(int));

    if (ptr_list==NULL)
    {

        exit(1);
    }
    /* Assignment of pointer to a list to a temporary variable*/
    ptr_temp=ptr_list;

    for (i_ctr=1; i_ctr <= i_num; i_ctr++)
    {
        printf("Enter the integer number %d: ",i_ctr);

        ptr_temp++;
    }
    /* Reassignment of pointer variable to beginning of list*/
    ptr_temp=ptr_list;
    /* Function called for finding minimum element from a list*/
    i_min=min(ptr_temp,i_num);
    printf("\n The minimum element of the list is \n", i_min);
    /* Free allocated memory block*/
    free(ptr_list);

}

int min(int *ptr_temp, int i_num)
{
    int i_min,i_ctr;

    i_min=*ptr_temp;
    /* Increment pointer variable by one location*/
    ptr_temp++;
    /* For-loop to scan all elements of list to find minimum element*/
    for (i_ctr=2; i_ctr<=i_num; i_ctr++)
    {
        if (*ptr_temp<i_min)
            i_min=*ptr_temp;
        ptr_temp++;
    }
    /* Returning minimum of entire list*/
    return(i_min);
}

## Function calloc

The function calloc is used to allocate memory space that will store elements of the same data type. It allocates contiguous block of memory. Once the memory is allocated, it then sets all bytes to zero. The function malloc reserves single block of specified size, while the function calloc reserves $n$ memory blocks, each of specified size. The syntax of using the function calloc is as follows:

```
ptr=(cast-type*) calloc(n, element-size);
```

The preceding statement allocates contiguous space for n memory blocks, each of the size specified. All bytes are initialized to zero and a pointer to the first byte of the allocated region is returned. If there is not enough space, a NULL pointer is returned. For example, to allocate memory space for 25 float elements that are all initially zero, the following statements can be used:

```
float *fptr;
fptr = (float *) calloc(25, sizeof(float));
```

## Function realloc

The memory allocated with function calloc or malloc might be insufficient or may exceed the requirement. In both the situations, it is advisable to change the memory size already allocated to the variable. This process of changing the memory space already allocated is called reallocation of memory. The realloc function, when used, changes the size of a previous allocated block of memory. The new size can be larger or smaller than the size of the previous block.

If the request is to make existing block larger in size, then the old contents remain unchanged and memory is added to the end of the block. If the size is made smaller, then the block is truncated from the end and the remaining contents are unchanged. In case the original block size cannot be resized, then the function realloc will attempt to assign a new block of memory. Here, the realloc function will copy the old block contents at new location. A new address location will consequentially be returned and assigned to the address pointer. If the realloc function fails to attempt a new memory block, then it returns NULL; in such a case, we may tend to lose the existing data. The syntax to use the function realloc is as follows:

```
ptr = realloc( ptr, newsize );
```

The preceding statement allocates contiguous memory space as per the value specified in *newsize*. For example, if initially 50 bytes have been allocated with the function malloc using following statement:

```
ptr = (char * ) malloc(50 );
```

To extend memory allocation by additional 20 bytes, the following statement can be used:

```
ptr = realloc(ptr,70 );
```

After execution of the preceding statement, the original contents will be retained and the memory block size will be increased from 50 bytes to 70 bytes. Figure 4 shows the memory representations of the bytes allocated by the compiler after the realloc function is used:

## Function free

Compilers use a mechanism of automatic memory management called garbage collection to free unwanted or unused memory space that has been allocated at compile time. The availability of an identifier within a program is governed by the storage class of the identifier as discussed in Chapter 8. This storage class is also used at the time of garbage collection to identify whether a memory block can be freed or not. When we allocate memory dynamically at runtime the responsibility to free unwanted or used memory space lays with programmer. Managing of memory space is more required when we have limited storage, in such cases unwanted or unused memory blocks should be freed as soon as possible. The syntax to use the function free is as follows:

```
free(ptr);
```

The preceding syntax, when used, will free a memory block within the heap that is associated with pointer *ptr*. After the compiler frees the memory block the pointer ptr is assigned a NULL value.

## 14.2 Concept of Linked List

We have seen that an array allocates contiguous bytes of memory for all its elements as a one block. Even when the dynamic memory allocation function is used, the entire block is to be contiguous in memory. Can we write a program that may store each element of array at different places in memory? The answer is yes. Then a next question that arises is how to keep track of individual addresses of each memory. With the knowledge of pointers and structures, which we have already discussed, a linked list can be created within a C program. A linked list allocates space for each element separately in its own block of memory called a *linked list element* or *node*. As discussed earlier in Chapter 11, an array of structures can also be created within a C program. Thus, in this case, each node will be a structure. Pointers will be used to connect each node of the list. All nodes in a link list create a linking between each other similar to a chain. Each node will contain an address of another node.
