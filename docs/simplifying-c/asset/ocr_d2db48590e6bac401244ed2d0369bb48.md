Now the question that arises is how to access other elements of the row. Pointer arithmetic *(i_arr+0) results in address of the first element of the first row. When an integer value 1 is added to *(i_arr + 0), the result is the address of the second element in the first row. When an integer value 2 is added to *(i_arr + 0), the result is the address of the third element in the first row. Similarly, when integer values 1 and 2 are added to *(i_arr + 1), the result is the address of the second and third elements of the second row. When integer values 1 and 2 are added to *(i_arr + 2), the result is the address of the second and third elements of the third row. If *(i_arr + 1) + 1 results to the address of the second element of the second row, there is a possibility that the prefixing dereference operator * to *(i_arr + 1) + 1 results into value stored at the second row and the second column.
