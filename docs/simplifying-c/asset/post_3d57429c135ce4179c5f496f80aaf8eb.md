Till now, we have concentrated on formatted input and output functions; C language also provides us with an option of unformatted input and output functions. The next section discusses about the functions available for unformatted I/O operations.

## 4.4 Unformatted Functions

The unformatted functions, as the name suggests, cannot format data and work with only a character data type. As it only works with the character data type, unformatted functions do not need a conversion symbol similar to the formatted functions. In case the user enters a numeric value, it is considered as a character. Let us now explore the usage of different input functions available under unformatted functions.

### Unformatted Single Character I/O Functions

As mentioned in Table 1, C language provides us with two unformatted input functions getchar and getc that work on character data type. Similarly, we have two corresponding output functions putchar and putc to give us the output. The syntax to use the character input and output functions is shown in Figure 5:

- Input
  - `identifier name = getchar();`
  - `identifier name = getc(stdin);`
- Output
  - `putchar(identifier name);`
  - `putc(identifier name , stdout);`

**Figure 5: Syntax of Character I/O Functions**

Figure 5 shows that the syntax of both the input functions is almost identical, except for the use of the standard input stream in getc. As the getc function can also be used with text files, it becomes compulsory to indicate which file it actually refers to. The use of stdin here refers to the keyboard. Similar is the case with function putc: here, stdout refers to the monitor. Program 10 illustrates the usage of character I/O functions mentioned before:

## Program 10

```c
/* Program to illustrate the use of unformatted function */
#include<stdio.h>
/* Beginning of main function */
main()
{
/* Declare variables */
char c_choice, c_temp;

/* Use of getchar and putchar */
printf("\nEnter your choice : ");
c_choice = getchar();
printf("\nYour entered choice is : ");
putchar(c_choice);

/* Clear Buffer */
c_temp = getchar();

/* Use of getc and putc */
printf("\nEnter your choice again : ");
c_choice = getc(stdin);
printf("\nYour entered choice is : ");
putc(c_choice,stdout); 
printf("\n");
return;
} 
/* End of function main */
```

Output:

```
Enter your choice : v
Your entered choice is : v
Enter your choice again : a
Your entered choice is : a
```

In Program 10, we have used the same variable c_choice two times. When the first occurrence of c_choice = getchar(); is encountered, the compiler waits for the user to enter a character. Any character keyed at this point will be stored in the variable `c_choice`. A user at this point needs to enter the data carefully because pressing of space bar, Enter key, tab key, or any other nonprintable key also becomes a legitimate entry.

In Program 10, when the user enters the data, two characters are actually placed in buffer. The first character refers to the `c_choice` and the other character refers to the Enter key. Due to this, we may get a problem in reading the value of `c_choice` for the second time. To make things work, we have cleared the second character by storing its value in `c_temp`.

Most of the times, the user, rather than dealing with only a single character, deals with a set of characters called string. The next section discusses about how to input and output a string using unformatted function.

### Unformatted String I/O Functions

C language provides us with two unformatted functions `gets()` and `puts()` to input and output a string. A string in C is represented as a set of characters that is always terminated with a null character (\0). The syntax of the unformatted string I/O function is as follows:

`gets(identifier name);` and `puts(identifier name);`

Program 11 illustrates the use of unformatted string I/O functions:

## Program 11

```c
/** Program to illustrate how to read and display strings **/
#include<stdio.h>
/** Beginning of main function **/
main()
{
/** Declare character array **/
char s_city[50];

/** Read data in array **/
printf("\nEnter the name of city: ");
gets(s_city);

/** Print data from array **/
printf("\nThe name of the city is: ");
puts(s_city);
printf("\n");
return;
}
/** End of function main **/
```

Output:

```
Enter the name of city: Ahmedabad
The name of the city is: Ahmedabad
```

In Program 11, the `gets` function takes the name of the character array as a parameter and stores the data in it. The data is read from the standard input stream till the user presses the Enter key. The function then discards the newline character and stores the rest of the data into the character array. If no error occurs at the time of reading, it returns the string; otherwise, it returns a null pointer.

Note that the usage of function gets is not recommended by experts. The reason is that the user cannot specify the length of the array passed to function gets. This creates a serious problem as the data entered can be of much larger size compared to the size of array. Thus, there is a possibility of buffer overflow, which may lead to application failure.

## Summary

In this chapter, we have learned about how to accept data from the user at run time and how to display the results. To accept data from the user, C language provides us inbuilt functions. The inbuilt functions use a temporary memory known as buffer. This buffer is then used as a text stream that connects the input or output device with the program. The default streams available with all C programs are stdin, stdout, and stderr. The inbuilt functions were classified as formatted and unformatted. The formatted function make use of conversion symbol known as format code to input or output data. On the other hand, unformatted functions only work on character data type.
