# Program 4

```
/* Program to illustrate how to read and display strings */
#include<stdio.h>
/* Beginning of main function */
main()
{
    /* Declare character array */
    char s_student[50];

    /* Read data in array */
    printf("\nEnter the name of student: ");
    scanf("%s",&s_student);

    /* Print data from array */
    printf("\nThe name of the student is %s\n", s_student);

    return;
}  /* End of function main*/
```

# Output 1:

```
Enter the name of student: vidita arolkar
The name of the student is vidita
```

# Output 2:

```
Enter the name of student: harshit jain
The name of the student is harshit
```

It can be observed from Program 4 that in both the outputs, the first name has been accepted as an input. This happens because of the property of the `%s` format code. In C, when `%s` format code is used to read a string, the reading terminates after encountering a space or an Enter key, whichever comes first. In both the previous outputs, as space was encountered before the Enter key, the reading terminated and only the first names were accepted as legal inputs. The surname in both the cases would still remain in the buffer.

C provides us with a format code `%[list of characters]` to solve the problem faced in Program 4. Here the [list of characters] contains the characters that we want to enter from keyboard. This format when used along with function `scanf` accepts all the characters that are specified in the square brackets `[ ]`. The function `scanf` will stop reading when it does not find a character from within the list. Some valid formats and their description is given in Table 3.

| Table 3: Usage of format code %[list of characters] |  |
| :--- | :--- |
| Format | Description |
| `scanf([a-z], &s_student);` | The function `scanf` accepts only lower case alphabets from a to z. |
| `scanf([A-Z], &s_student);` | The function `scanf` accepts only upper case alphabets from A to Z. |
| `scanf([0-9], &s_student);` | The function `scanf` accepts only digits from 0 to 9. |
