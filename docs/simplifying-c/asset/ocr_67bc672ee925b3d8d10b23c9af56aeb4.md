# Conditional Operators

In Program 2, we have used a decision structure *if* to make a decision whether the number is odd or even. C language provides us an operator known as *conditional operator* or *ternary operator* for condition checking. This operator consists of combination of two symbols, that is, **?** and **:**. The syntax to use conditional operator is as follows:

    (Condition) ? (True Statement) : (False Statement);

The condition in the preceding syntax refers to a relational expression, which results in true or false. True and false statements can be an expression or a constant value. Program 8 illustrates the use of conditional operator. The program is used to find the minimum value from the two entered values.

# ▶ Program 8

```
```C
/* Program to illustrate the use of conditional operator */
#include <stdio.h>
/* Beginning of main function */
main( )
{
   /* Declare variables */
   int i_num1, i_num2, i_minimum;
   /* Accept the value of num1 and num2 */
   printf("\n Enter the value of num1: ");
   scanf("%d",&i_num1);
   printf("\n Enter the value of num2: ");
   scanf("%d",&i_num2);
   /* Use of conditional operator */
   i_minimum = (i_num1 <= i_num2) ? (i_num1) : (i_num2);
   /* Print the minimum value */
   printf("\nthe minimum value of the two is %d \n", i_minimum);
   return;
}
/* End of function main */
```
