
## Program 4

```c
/* Program to illustrate how to read and display strings */
#include<stdio.h>
/* Beginning of main function */
main()
{
    /* Declare character array */
    char s_student[50];

    /* Read data in array */
    printf("\nEnter the name of student: ");
    scanf("%s", &s_student);

    /* Print data from array */
    printf("\nThe name of the student is %s\n", s_student);

    return;
}  /* End of function main */
```

### Output 1

```
Enter the name of student: vidita arolkar
The name of the student is vidita
```

### Output 2

```
Enter the name of student: harshit jain
The name of the student is harshit
```

It can be observed from Program 4 that in both the outputs, the first name has been accepted as an input. This happens because of the property of the `%s` format code. In C, when `%s` format code is used to read a string, the reading terminates after encountering a space or an Enter key, whichever comes first. In both the previous outputs, as space was encountered before the Enter key, the reading terminated and only the first names were accepted as legal inputs. The surname in both the cases would still remain in the buffer.

C provides us with a format code `%[list of characters]` to solve the problem faced in Program 4. Here the [list of characters] contains the characters that we want to enter from keyboard. This format when used along with function `scanf` accepts all the characters that are specified in the square brackets `[ ]`. The function `scanf` will stop reading when it does not find a character from within the list. Some valid formats and their description are given in Table 3.

### Table 3: Usage of format code %[list of characters]

| Format | Description |
| :--- | :--- |
| `scanf([a-z], &s_student);` | The function `scanf` accepts only lower case alphabets from a to z. |
| `scanf([A-Z], &s_student);` | The function `scanf` accepts only upper case alphabets from A to Z. |
| `scanf([0-9], &s_student);` | The function `scanf` accepts only digits from 0 to 9. |
| `scanf("%[A-Z,0-9]", &s_student);` | The function `scanf` accepts upper case alphabets from A to Z as well as digits from 0 to 9. |
| `scanf("%[,z,0-9]", &s_student);` | The function `scanf` accepts a comma, lower case z and digits from 0 to 9. |

The exact opposite of `%[list of characters]` format is `%[ ^list of characters]`. In this case, the reading of data will stop as soon as the user enters one of the characters within the list. Program 5 illustrates the use of format `%[ ^list of characters]`:

## Program 5

```c
/* Program to illustrate how to read and display strings */
#include<stdio.h>
/* Beginning of main function */
main()
{
    /* Declare character array */
    char s_student[50];

    /* Read data in array */
    printf("\nEnter the name of student: ");
    scanf("%[^\n]", &s_student);

    /* Print data from array */
    printf("\nThe name of the student is %s\n", s_student);
    return;
}
/* End of function main */
```

### Output 1

```
Enter the name of student: vidita arolkar
The name of the student is vidita arolkar
```

### Output 2

```
Enter the name of student: harshit jain
The name of the student is harshit jain
```

In Program 5, both the outputs now contain full names. This works as we have used `%[ ^\n]` as a format code. The escape sequence `\n` represents new line and the format code here specifies that the user has to read data till the Enter key is pressed. It can be seen in the earlier programs that the way the output is presented makes an impact on the result. The next section discusses formatted output.

## Output Function

The presentation of information is the most critical aspect of programming. C language provides a predefined function called `printf` to show the output. The syntax of the function is as follows:

```c
printf("format string", list of identifiers); or printf("message string");
```

It can be seen in the preceding syntax that the `printf` function is used to display only messages on the screen or can be used to show message along with value of the variables. In the later case, the function needs two parameters, namely, a format string that has message along with format code and a list of identifiers. It is possible to use the escape sequence characters discussed in Chapter 2 of this book along with the `printf` functions. Program 6 illustrates the use of escape sequence character with `printf`:

Two escape characters represent tab space; hence, the third line shows a gap between the two words escape and sequence. As mentioned in Table 2, C language provides us with many format codes. Program 7 illustrates the usage of some of these format codes:

## Program 7

```c
/* Program to illustrate the use of format code */
#include <stdio.h>
/* Beginning of main function */
main()
{
    /* Declare variables */
    int i_number;
    /* Accept the value */
    printf("\n Enter the value of number : ");
    scanf("%d", &i_number);
    /* Print value in different base */
    printf(" \n Value in base 10 is : %d\n", i_number);
    printf(" \n Value in base 16 is : %x\n", i_number);
    printf(" \n Value in base 16 is : %p\n", i_number);
    printf("\n Value in base 8 is : %o\n", i_number);
    printf("\n Value in character is : %c\n", i_number);
    return;
}
/* End of function main */
```

### Output

```
Enter the value of number: 60
Value in base 10 is: 60
Value in base 16 is: 3c
Value in base 16 is: 0x3c
Value in base 8 is: 74
Value in character is: <
```

In Program 7, we have entered an integer value. This value is then converted into different number systems as well as a character by using proper format code. Note that we have used two format codes to represent the value in base 16, `%x`, and `%p`.

The numbers that are displayed as output at times need to be justified as per the requirement of the user. There may also be a need to pad the number with zero or display specific number of decimal digits. To perform such formatting, we need to modify the format code by preceding it with width, precision represented as dot (.), and length. The general format code thus can be written as follows:

```
%[flag][width][.precision][length] format code
```

The terms represented in square brackets are optional. Table 4 lists the detailed usage of flags:

### Table 4: Detailed Usage of Flag

| Flags | Description |
| :---: | :--- |
| - | Used to left justify the data within its field. |
| + | Used to indicate preceding plus or minus sign with signed data types. |
| space | Used to insert a space as prefix, if the first character of a signed data type is not plus or minus sign. |
| # | Used to force an alternative form of output, for example:<br>- The first digit of an octal number will always be a 0.<br>- Inserts 0X in front of a hexadecimal numbers.<br>- A decimal point should always be present in all float numbers.<br>- Trailing zeros are not removed when g format code is used. |
| 0 | Used to pad zeros up to the field width on the left-hand side of the data. It is normally used with d, i, o, u, x, X, e, and f format codes. In case - flag is also used, the pad effect gets nullified. |

More than one value of the flag shown in Table 4 can be combined and used to give proper format to the output. The term *width* in the syntax represents total number of characters places in which the value of the variable is to be printed, *length* refers to the number of digits after the decimal place in case of float value, number of characters to be printed from a string in case of a character array, and for int value, it refers to the number
