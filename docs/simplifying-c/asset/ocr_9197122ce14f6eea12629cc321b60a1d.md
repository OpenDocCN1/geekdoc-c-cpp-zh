It can be seen in Program 4 that we have defined a function called calculator that takes three parameters, that is, two integers and one character values, as an input from the function main. It also returns an integer value back to the function main. The job of this function is to work as a simple calculator and perform the given mathematical operation on the two integer parameters entered. If the mathematical operation is successfully performed, then the function returns a value of i_result. In case of unsuccessful operation, i_result is assigned a value -999, and then, this value is returned. It can be seen in Figure 7 that once the call to function calculator is made within the function main, the flow of execution sequence is altered. The execution control from the point of function call jumps to the starting address of the function calculator. Compared to Programs 2 and 3, there is a change in the execution. In Program 4 along with control transfer, the compiler also sends value of variables i_first, i_second, and c_operator to the function calculator. These values are then assigned to the local variables i_first, i_second, and c_operator of the function calculator. Then the statements within the function calculator are executed. Once the function calculator's execution is completed, the execution control flow is transferred back to the statement that made the function call within the function main. The value returned by the function calculator is then assigned to the variable i_result in the function main. The statements within the function main are then again executed in sequence.
