## Bitwise Operators

It has been mentioned earlier that C language was actually designed for the purpose of writing system software codes. Interacting with raw bits is one of the applications in system software. C language allows us to operate directly at bit level using six bitwise operators. Table 5 lists the bitwise operators available in C and their usage:

**Table 5: Bitwise Operators**

| Symbol | Name | Usage | No. of Operands Required |
| :--- | :--- | :--- | :--- |
| `&` | Bitwise AND | To perform AND operation on two bits | Two |
| `|` | Bitwise OR | To perform OR operation on two bits | Two |
| `~` | Bitwise NOT | To perform NOT operation on one bit | One |
| `^` | Bitwise Exclusive OR | To perform XOR operation on two bits | Two |
| `<<` | Left Shift | First operand to be shifted left the number of bits specified by the second operand | Two |
| `>>` | Right Shift | First operand to be shifted right the number of bits specified by the second operand | Two |

To perform bitwise AND, OR, Exclusive OR (XOR), left shift, and right shift operations, we require two operands. The NOT operation, on the other hand, only requires one operand. The value that the operands can hold is either 0 or 1. Table 6 lists the result of some bitwise operations done on two operands A and B:

**Table 6: Truth Table for Bitwise Operations**

| A | B | ~A | ~B | A & B | A \| B | A ^ B |
|---|---|---|---|---|---|---|
| 0 | 0 | 1 | 1 | 0 | 0 | 0 |
| 0 | 1 | 1 | 0 | 0 | 1 | 1 |
| 1 | 0 | 0 | 1 | 0 | 1 | 1 |
| 1 | 1 | 0 | 0 | 1 | 1 | 0 |

Program 10 illustrates the usage of bitwise operators:

### Program 10

```c
/* Program to illustrate the use of bitwise operators */
#include <stdio.h>
/* Beginning of main function */
main() {
/* Declaration of three integer variables */
unsigned int u_first, u_second, u_result;

/* Accept values of variables */
printf("\nEnter value of first: ");
scanf("%u", &u_first);
printf("\nEnter value of second: ");
scanf("%u", &u_second);

/* Bitwise operation */
u_result = u_first & u_second;
printf("\nResult of AND operation is %d", u_result);

u_result = u_first | u_second;
printf("\nResult of OR operation is %d", u_result);

u_result = u_first ^ u_second;
printf("\nResult of XOR operation is %d", u_result);

u_result = u_first << 1;
printf("\nResult of Left shift operation is %d", u_result);

u_result = u_second >> 2;
printf("\nResult of Right shift operation is %d", u_result);

u_result=~u_first;
printf("\nResult of NOT operation is %d\n", u_result);
return;
}
/* End of function main */
```

## Special Operators

C language provides four categories of special operators called comma operator, size of operator, pointer operators, and member selection operators. Table 7 lists the symbols used for these operators and their purpose of usage:

**Table 7: Special Operators**

| Category | Symbol | Name | Usage |
| :------- | :----- | :----- | :----- |
| Comma | `,` | Comma | To separate identifiers at the time of declaration and performing multiple operation |
| Sizeof | `sizeof()` | Size Of | To check the size of the data type |
| Pointer | `&` | Ampersand | To identify Address or reference of an identifier |
| | `*` | Indirection | To provide indirection to pointer identifiers |
| Member Selection | `.` | Dot | To access members of structure or union |
| | `->` | Member by | To access members of structure or union when pointer type identifier of a structure or a union is defined |

The comma operator is used to separate two expressions or words in C language. We have used it to separate identifiers defined in the programs discussed in this chapter. It is also used in looping constructs discussed in later chapter. Program 11 shows the usage of the `sizeof()` operator:

### Program 11

```c
/* Program to illustrate the usage of size of operator */
#include <stdio.h>
/* Beginning of main function */
main( )
{
/* Declare variables */
unsigned int i_first;
float i_second;

printf("\nThe size of int data type is %d",sizeof(int));
printf("\nThe size of float data type is %d",sizeof(i_second));
printf("\nThe size of double data type is %d \n",sizeof(double));
```

It can be observed from the output of Program 11 that the size of any data type allocated by the compiler can be obtained by using the identifier name or the data type itself in the parenthesis. The size of operator is also known as compile-time operator as the operator is depended on the compiler. The sizes shown in the output are as per GNU Compiler Collection (GCC) compiler. The output of Program 11 will vary from compiler to compiler.

## 5.2 Precedence and Associativity of Operators

C language designers have predefined the precedence and associativity of each operator used in C. The precedence of an operator tells the compiler the order in which the operators should be evaluated. In case two operators with the same precedence are part of an expression, then associativity is taken into account. The associativity of operators tells the compiler from which side (from left to right or vice versa) the expression should be resolved.
