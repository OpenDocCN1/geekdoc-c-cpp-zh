## 13.8 Function feof

Programs 2 and 4 use the `EOF` marker to check whether the end of a file has been reached or not. The C library also provides the function `feof` declared in the header file `stdio.h`. Its primary purpose is to check whether a stream operation has reached the end of a file. The input file functions return `EOF` in cases when the actual end of the file is reached as well as in case of an error. The function `feof` thus can be used to check whether we have reached the end of a file or an error has occurred. The syntax of the function `feof` is as follows:

```c
int feof(file_pointer);
```

It accepts the file pointer as a parameter. The return value of the function is an integer. A nonzero value signifies that the end of the file has been reached; a value of zero signifies that it has not. Program 5 illustrates the use of the function `feof`.

### Program 5

```c
/* Program to illustrate the usage of function feof */
#include <stdio.h>

/* Beginning of main function */
main()
{
    char c_temp;
    /* declaring file pointer */
    FILE *fp_names;

    /* Opening a file names.txt in writing mode */
    fp_names = fopen("names.txt", "w");
    if (fp_names == NULL)
    {
        printf("File could not be opened successfully.\n");
        exit(1);
    }

    printf("\nEnter data you want to enter into a file, Press Ctrl+D at the end: ");

    /* Accepting characters from keyboard */
    while ((c_temp = getchar()) != EOF)
    {
        /* writing characters to a file */
        fputc(c_temp, fp_names);
    }

    /* Closing a file */
    fclose(fp_names);

    /* Opening a file in reading mode */
    fp_names = fopen("names.txt", "r");
    if (fp_names == NULL)
    {
        printf("File could not be opened successfully.\n");
        exit(1);
    }

    printf("\nPrinting contents of file...\n");

    /* Reading characters from a file */
    while ((c_temp = fgetc(fp_names)) != EOF)
    {
        /* Displaying characters on screen */
        printf("%c", c_temp);
    }
    printf("\n");

    /* Usage of feof() function */
    if (feof(fp_names))
        printf("End of file was reached.\n");
    else
        printf("Unread records are remaining in the file.\n");

    fclose(fp_names);
    return;
}
/* End of function main */
```

## 13.9 General I/O in Text Files

In Program 2, we have seen that the contents can be written to a file one character at a time. Program 3 transfers strings to a disk file. Program 4 transfers integers to a file. However, what shall be done if the situation demands working with a combination of these data types? For such situations, the functions `fscanf` and `fprintf` can be used. The function `fprintf` is used to store data in a file. The function `fscanf` is used to read data from a file. The syntax of these functions is similar to that of the functions `scanf` and `printf`, with a single difference: they accept an additional parameter, that is, the file pointer. These functions are also useful for storing formatted data.

The syntax of the function `fprintf` is as follows:

```c
fprintf(file_pointer, format_specifiers, data);
```

The function `fprintf` accepts three parameters. The first parameter is a pointer to the file in which contents are to be stored. The second parameter is the format specifier, and it is used to indicate the data type of the data to be stored. The third parameter is the variables, which can be a set of variables, constants, or expressions.

The syntax of the function `fscanf` is as follows:

```c
fscanf(file_pointer, format_specifiers, variables);
```

The function `fscanf` accepts three parameters. The first parameter is a pointer to the file from which contents are to be read. The second parameter is the format specifier, and it is used to indicate the data type of the data being read. The third parameter is the variables in which the actual data read from the file will be stored.

Let us write a program that accepts information about items bought from a store in a file. The information accepted includes item name, rate of item, and quantity purchased. The details will be stored in a file, and at the end, the total amount to be paid will be displayed on the screen. Program 6 illustrates the working of functions `fscanf` and `fprintf` to perform the operations mentioned.

### Program 6

```c
/* Program to illustrate the functions fprintf and fscanf */
#include <stdio.h>

/* Beginning of main function */
main()
{
    FILE *fp_item;
    char c_itemname[20], c_ans;
    int i_itemqty, i_ctr = 0;
    float f_itemrate, f_amount = 0;

    fp_item = fopen("item", "w"); /* Opening a file for writing */
    if (fp_item == NULL)
    {
        printf("Error in opening a file\n");
        exit(1);
    }
    else
    {
        do
        {
            i_ctr = i_ctr + 1;
            printf("\nEnter record number %d: ", i_ctr);
            printf("\nEnter item name, item rate and item quantity: ");
            scanf("%s %f %d", c_itemname, &f_itemrate, &i_itemqty);
            /* writing into file */
            fprintf(fp_item, "%s %f %d\n", c_itemname, f_itemrate, i_itemqty);
            printf("\nWould you like to add another record yes(y)/No(n): ");
            scanf(" %c", &c_ans);
        } while ((c_ans == 'y') || (c_ans == 'Y'));
        fclose(fp_item);
    }

    fp_item = fopen("item", "r");
    if (fp_item == NULL)
    {
        printf("Error in opening a file\n");
        exit(1);
    }
    else
    {
        printf("\nThe records entered in file are:\n\n");
        while ((fscanf(fp_item, "%s %f %d", c_itemname, &f_itemrate, &i_itemqty)) != EOF)
        {
            printf("%-10s %5.2f %5d\n", c_itemname, f_itemrate, i_itemqty);
            f_amount = f_amount + f_itemrate * i_itemqty;
        }
        printf("Total amount to be paid is %.2f Rs.\n", f_amount);
    }
    fclose(fp_item);
    return;
}
/* End of function main */
```
