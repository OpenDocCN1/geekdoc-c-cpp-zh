/* Program to calculate the sum of elements of an array using pointer arithmetic */

Program 6 accesses each element of an array using *(i_arr + i_ctr), where i_ctr is a counter ranging from 0 to 4. Thus, each element is accessed one by one, and its value is added to i_sum. In the end, the value of i_sum is displayed on the screen.

So far we have seen that the name of an array can act as a pointer to an array. Thus, further operations on an array can be performed using pointer arithmetic on the name of an array. However, what will happen if a programmer writes a statement i_arr++ in his/her program. In such a case, when the program is executed, the starting address of an array will be lost after the execution of i_arr++ statement. So, to be cautious, an additional pointer to an array should be used to perform array operations. Program 7 illustrates the use of additional pointer pointing to an array:

## Program 7

```c
/* Program to illustrate the assignment of pointer to array to another pointer variable */
#include<stdio.h>

/* Beginning of function main */
main()
{
    /* Declare variables */
    int i_arr[10], i_num, i_ctr, i_rev, i_temp, *p_arr;
    /* Accept input from user */
    printf("How many elements would you like to enter: ");
    scanf("%d", &i_num);
    /* Accept values of array elements from user*/
    for (i_ctr=0; i_ctr<i_num; i_ctr++)
    {
        printf("\nEnter element i_arr[%d]", i_ctr);
        scanf("%d", &i_arr[i_ctr]);
    }
    /* Store address of array in a pointer variable */
    p_arr=i_arr;

    /* For-for-loop to reverse elements of an array*/
    for (i_ctr=0, i_rev=i_num-1; i_ctr<i_rev; i_ctr++, i_rev--)
    {
        i_temp=*(p_arr + i_ctr);
        *(p_arr + i_ctr)=*(p_arr + i_rev);
        *(p_arr + i_rev)=i_temp;
    }
    /* Display new values of array*/
    for (i_ctr=0; i_ctr<i_num; i_ctr++)
    {
        printf("\nThe new value of a[%d]", i_ctr);
        printf(" %d", *(p_arr + i_ctr));
    }
    return;
}
/* End of function main */
```

**Output:**

```
How many elements would you like to enter: 4
Enter element i_arr[0]: 12
Enter element i_arr[1]: 34
Enter element i_arr[2]: 56
Enter element i_arr[3]: 11
The new value of i_arr[0]: 11
The new value of i_arr[1] 56
The new value of i_arr[2] 34
The new value of i_arr[3] 12
```

The preceding program reverses an array. Thus, the first element of an array will be the last and the last element of an array will be the first. The second element of an array will be the second last and the second last element will be the second. If an array contains odd number of elements, the element in the middle of an array remains unchanged. Though not required, to be cautious, a array pointer is copied to another pointer and further operations are performed using a new pointer.

In Program 7, a pointer variable *p_arr is declared. The elements of an array are scanned using the scanf statement. The pointer variable p_arr is assigned the address of an array i_arr with p_arr = i_arr; statement. The for loop is written to access elements of an array. Two counters named i_ctr and i_rev are initialized in a program. The i_ctr variable is initialized to 0 and i_rev is initialized to i_num-1. The values stored at addresses p_arr + i_ctr and p_arr + i_rev are interchanged. A temporary variable is used to interchange the values stored at locations p_arr + i_ctr and p_arr + i_rev. After interchanging, the variable i_ctr is incremented by 1 and the i_rev variable is decremented by 1. In the second iteration of the for loop, the second number of array and the second last element of array will be interchanged. The for loop will continue till the value of i_ctr is less than i_rev. In the end, the new values of array are displayed on the screen.
