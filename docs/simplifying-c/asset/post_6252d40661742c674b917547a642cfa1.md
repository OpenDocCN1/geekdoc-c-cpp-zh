## 12.3 Pointer Expressions

Similar to other variables, the pointer variables can also be used in expressions. For example, if ptr1 and ptr2 are properly declared and initialized pointers, then the following statements are valid:

```c
mult = *ptr1 * *ptr2;
sum = sum + *ptr1;
total = *ptr2 / *ptr1 + 17;
*ptr2 = *ptr2 + 40;
```

By now we have learned how to declare, initialize, and access variables values using pointer. We have also mentioned that the pointer variables can be used in expressions. Let us use our knowledge of pointers to write a program that adds two integers using pointers. Program 3 illustrates the addition of two integer variables using pointers:

## Program 3

```c
/* Program to add two integers using pointers*/
#include<stdio.h>

/* Beginning of function main */
main()
{
/* Declare variable */
int i_first, i_second, i_sum;
int *p_x,*p_y,*p_sum;
p_x=&i_first;
p_y=&i_second;
p_sum=&i_sum;

/* Accept value of x and y */
printf("\n Enter the value of first: ");
scanf("%d",p_x);
printf("\n Enter the value of second: ");
scanf("%d",p_y);

/* Sum of elements using dereference operator with pointers*/
p_sum=*p_x + *p_y;

/* Display the result */
printf("\n The sum of two integers i_first and i_second is %d\n",*p_sum);
return;
}
/* End of function main */
```

**Output:**

Enter the value of first: 10

Enter the value of second: 30

The sum of two integers i_first and i_second is 40

In Program 3, we have declared three integer variables named i_first, i_second, and i_sum, and three pointers variables named p_x, p_y, and p_sum. The statement p_x = &i_first; indicates that p_x points to i_first. Similarly, p_y points to i_second and p_sum points to i_sum. Later in the program, the pointers are used to store the input values provided by the user. Note that in the scanf statements used in this program, the pointers p_x and p_y are not prefixed with & as in usual scanf statements. This is because the pointer variables p_x and p_y themselves contain an address. As discussed earlier, the value stored at address, which is available in p_x, can be accessed by *p_x. Similarly, the value stored at address, which is available in p_y, can be accessed by *p_y. The statement *p_sum = *p_x + *p_y; adds the values and stores the result at address, which i_sum holds. The result is then displayed on the screen.

## 12.4 Operations on Pointers

We have seen that the pointer variables can be used in expressions. The dereferencing operators are used to access the values to use them in expressions.

C language also allows us to add integers to a pointer. We can also subtract integers from pointers. For example, if ptr1 is a pointer, then ptr1 +1, ptr1 +8, ptr1–2, and ptr1–7 are all valid operations. An addition and subtraction of one pointer from another pointer is also a valid operation. For example, if ptr1 and ptr2 are pointers that points to elements of the same array, the difference of ptr2 and ptr1 can give us the number of elements between ptr1 and ptr2.

The pointers can also be compared using relational operators. For example, comparisons such as ptr1 < ptr2, ptr1 > ptr2, ptr1 == ptr2, and ptr1 != ptr2 are all valid. The following is the list of operations that can be performed over pointers:

- **Addition:** Means that an integer value can be added to a pointer
- **Subtraction:** Means that an integer value can be subtracted from a pointer
- **Comparison:** Means that the pointers can be compared if they point to the elements of the same data type
- **Difference:** Means that one pointer can be subtracted from other if both point to the elements of the same data type
- **Assignment:** Means that one pointer can be assigned to another pointer if both of them are of the same data type

You might wonder that what will happen when a pointer is incremented or decremented. Assume that ptr is a pointer declared of integer data type. Remember that a pointer to integer is an address in memory. A pointer itself is definitely NOT an integer. The reason a pointer variable is associated to a data type is to find the total bytes allocated by the compiler in the primary memory for that data type. The pointer when incremented or decremented is incremented or decremented by the amount of size of memory allocated to the data type that it points to.

Thus, the pointer i_ptr that points to integer data when incremented by 1 will be automatically incremented by 4, if the size of integer data type occupies 4 bytes in a system when we use gcc compiler. Similarly, the value of i_ptr when decremented by 1 will be automatically decremented by 4 bytes. Figure 9 illustrates the new value stored in a pointer when it is incremented by 1:

![](img/5d422ba7108ffdf64376be51eaf0c459_266_0.png)

Thus, if the pointer variable i_ptr is incremented by 4, it will point to location 65502 + (4 * 4) = 65518. The decrement operator when used along with pointers works in the similar manner. For example, assume that the address 65100 is stored in the pointer i_ptr initially. Now, executing the statement i_ptr--; will decrement the value 65100 by 4. Hence, the new value stored in i_ptr will be 65096 (65100 – 4). Similarly, if c_ptr is a pointer pointing to a character data type, incrementing pointer by 1 will advance the pointer by 1 byte, as shown in Figure 10:

![](img/5d422ba7108ffdf64376be51eaf0c459_267_0.png)

As per ANSI C standards a character occupies 1 byte of storage space. The increment and decrement operations are useful when performed on pointer variable that points to elements of array. Pointers and arrays are discussed in the next section. The following is a list of operations that cannot be performed on pointers:

- Two pointers cannot be multiplied. The expression ptr1 * ptr2 is illegal.
- Two pointers cannot be divided. The expression ptr1 / ptr2 is illegal.
- One pointer cannot be subtracted from another when they do not point to the same data type.
- A pointer cannot be multiplied by a constant. The expression p1 * 4 is illegal.

Pointers and arrays are very closely linked in C language. Arrays have been discussed in detail in Chapter 9.
