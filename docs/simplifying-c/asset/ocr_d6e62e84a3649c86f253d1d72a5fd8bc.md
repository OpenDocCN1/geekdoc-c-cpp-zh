In Figure 1, the terms CAge and CStatus refer to the current age and citizenship status. These terms are known as variables. The term variable refers to an entity that is capable of storing a value and has a tendency to change its value during the execution time of the program. The change in the value of the variable could be due to application of arithmetic operation on it, or by direct allocation of value to it, or by any other valid means.

# ➤ **Basic Symbols of a Flowchart**

The American National Standard Institute (ANSI) has standardized symbols that can be used while drawing a flowchart. These symbols are categorized as input/output, terminal, processing, decision, connectors, and flow line symbols. Figure 2 shows the various symbols along with its description:

| **Symbol** | **Name** | **Purpose** | **Example** | **Description** |
|---|---|---|---|---|
| (Oval) | Oval | Terminal | Start<br>Stop | Start execution sequence<br>Stop execution sequence |
| (Parallelogram) | Parallelogram | Input / Output | Accept P<br>Print P | Accept value of variable P<br>Print value of variable P |
| (Rectangle) | Rectangle | Process | X = Y + Z | Multiply value of Y and Z, then store it in X |
| (Diamond) | Diamond | Decision | x > ? | if X = Y, then follow path indicated by Yes; otherwise, follow the path indicated by No |
| (Circle) | Circle | Connector | (Star) | An entry at the connecting point represented by * in flowchart |
| (Arrow) | Arrow | Flow line | (Arrow) | Guides the path to follow in next step |
