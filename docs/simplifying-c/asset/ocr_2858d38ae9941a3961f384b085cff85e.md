# Practical Exercises

+   Q1.  Write a program to find the maximum of two integer numbers using conditional operator.

+   Q2.  Write a program to find the maximum of three integer numbers using conditional operator.

+   Q3.  Write a program to find whether an entered number is odd or even using modulo and conditional operators.

+   Q4.  Write a program that accepts hexadecimal integer and prints its decimal equivalent.

+   Q5.  Write a program to calculate the net salary given to an employee having a basic salary of Rs. 25,000 using the salary breakup mentioned as follows:
Company gives incentives in the form of the following heads:
DA = 48% of Basic, HRA = 15% of Basic, CA = 5% of Basic, MA = Rs.500.
Company deducts amount in following heads:
PF = 8.33% of (Basic + DA), Professional Tax = 100
The formula used to calculate the salary is Net Salary = Basic + DA + HRA + CA + MA –(PF + Professional Tax)

+   Q6.  Write a program to calculate total minutes for an accepted float value representing hours and minutes.

+   Q7.  Write the C program that accepts number of years from a user and displays it in months and days.

+   Q8.  Write a program to input two numbers i_first and i_second. Check whether the number i_first is divisible by number i_second or not. (DO not use % operator)

+   Q9.  A quadratic function has the form f(x) = ax² + bx + c. Write a program that accepts value of a, b, c, and x to evaluate f(x).

+   Q10.  Write a program that accepts three integer variables i_first, i_second, and i_num.
Shift right the variable i_first by i_num bits and left shift the variable i_second by i_num bits.
