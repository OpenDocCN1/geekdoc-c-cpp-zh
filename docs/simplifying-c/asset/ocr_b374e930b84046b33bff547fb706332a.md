# Practical Exercises

+   - **Q1.** Write a program that will examine the value of a floating-point variable called `f_temperature` and print one of the following messages, depending on the value assigned to `f_temperature`.
	- ICE, if the value of temp is less than 0.
	- WATER, if the value of temp lies between 0 and 100
	- STEAM, if the value of temp exceeds 100.

+   - **Q2.** Write a program to accept the value of a variable x. Using this value, find the value of Y as per the conditions mentioned:
	- Y = 3x + 5 if x > 0
	- = 2x − 0 if x < 0
	- = 0 if x = 0.

+   - **Q3.** Write a program to find the maximum of three integer values.

+   - **Q4.** Assume that you have 1000, 500, 100, 50, 20, 10 5, 2, and 1 Rupees currency note. Enter an integer value and convert it to minimum number of notes required. For example, if N = 1050, then output is 2 notes 1 of 1000 and 1 of 50.

+   - **Q5.** Write a program to enter a numeric value within the range from 1 to 7 and give its corresponding week day.

+   - **Q6.** Write a program to enter a numeric value within the range from 1 to 12 and give its corresponding month name.

+   - **Q7.** Write a program to accept a basic salary and number of days attended from user. Calculate the monthly take home salary of an employee based on the breakup given as follows:
	- Income:
		- DA = 48% of Basic, HRA = 15% of Basic, CA = 5% of Basic, MA = Rs.500.
	- Deduction:
		- PF @ of 8.33% of Basic + DA,
		- Professional tax = 60 if basic < 5000, 80 if basic >= 5000 & < 10000, 100 otherwise.
	- Net Salary = Basic Salary + Income − Deduction.

+   - **Q8.** Write a program to accept year salary of an employee and professional tax paid. Calculate the income tax to be paid by an individual based on the information given:
	- An employee gets standard deduction of Rs 25,000.00 if his gross earning is less than or equal to Rs.1, 50,000; otherwise, the standard deduction is Rs. 20,000.00.
	- He/She gets full deduction of his professional tax.
	- Taxable income calculated is the amount remaining after deducting standard deduction and professional tax.
	- Income tax to be paid is calculated using the following table:

| Taxable Income in Rs. | Calculate IT as |
|---|---|
| Up to 100000 | Nil |
| Between 100001 and 150,000 | 10% of excess over 100000 |
