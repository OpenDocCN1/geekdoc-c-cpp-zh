```
fwrite(address of variable, size of datatype of variable, number of such variables, file_pointer);
```

The function fwrite accepts four parameters. The first parameter is the address of the variable to be written to the disk. The second parameter is the size of the variable in bytes. The size of the operator can be used to calculate the number of bytes occupied by a variable. The third parameter is the number of such variables to be written to a file at a time. This parameter of the function fwrite is very useful when the collection of variables, such as array, is to be dumped. The data can be organized as a structure and the entire structure array can be dumped to a file. This results into writing of a multiple records in a file at a time. The last parameter is the file pointer pointing to a file in which the data is to be stored.

To read the contents from binary file, the function fread can be used. The syntax of the function fread is as follows:

```
fread(address of variable, size of data type of variable, number of such variables, file_pointer);
```

The format of the function fread is much similar to that of the function fwrite. It also accepts four parameters. The first parameter is the address of the variable in which the data read from the file will be stored. The second parameter is the size of the data type of variable indicated in the first parameter. The third parameter is the number of such variables to be read from the file at a time. The last parameter is the file pointer pointing to a file from which the data is to be read.
