It can be seen in Figure 4 that when the function main is called by the operating system, only two variables, namely, i_number and i_result, are active. The value in i_number is the value entered by the user in Output 1. When the main function calls the function factorial, another stack entry is done in the memory. At this point, the previous stack entry belonging to the function main becomes inactive. In the new stack entry, three variables are there: i_number, i_result, and i_ctr. As the variables belong to different stack entries, they do not interfere with each other. Once the processing of function factorial is over, the control is returned back to the main function. At this point, the stack entry belonging to the function factorial is removed from the memory and the stack entry for the function main becomes active again.

The values shown in the blocks in the preceding figure are final values and not intermediate results. In case when the function factorial is called, the values of i_result and i_ctr will be initially 1. Then, as the for loop is processed, the value of i_ctr will be 2, 3, 4, and 5, and the corresponding value of i_result will be then 2, 6, 24, and 120, respectively. When the value of i_ctr becomes 6, the execution of the for loop stops and the function factorial returns the control along with the value of variable i_result back to the function main using the statement return(i_result).
