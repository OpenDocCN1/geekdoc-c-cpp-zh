# ▲ Figure 5: Syntax of Character I/O Functions

Figure 5 shows that the syntax of both the input functions is almost identical, except for the use of the standard input stream in getc. As the getc function can also be used with text files, it become compulsory to indicate which file it actually refers to. The use of stdin here refers to the keyboard. Similar is the case with function putc: here, stdout refers to the monitor.
