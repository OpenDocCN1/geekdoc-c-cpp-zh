
Once the memory representation of a two-dimensional array is known, the next question arises is how to access individual elements using pointers. Similar to one-dimensional array, the name of the array itself contains address of the first element of an array. Thus, the name of an array acts as a pointer variable. If some pointer arithmetic is applied on the pointer variable, which points to an array, individual elements can be accessed. It is a bit tricky to understand how individual addresses can be accessed using pointer to an array.

It can be seen in Figure 13 that the array i_arr is a two-dimensional array containing nine elements. Virtually, it has three rows and three columns. A very common thought that comes in mind is that a counter variable can be added to array pointer to access each individual element. However, it is not so. Let's assume that an array i_arr starts from memory location 1000. When 1 is added to i_arr, the address accessed should be 1004. However, it is not the case when a pointer variable i_arr is pointing to a two-dimensional array. Instead, the next address accessed is the address of the next row.

Let us write a program and print address locations accessed by adding an integer value to an array pointer. Program 8 illustrates the use of pointers along with two-dimensional array.

## Program 8

```c
/* Program to illustrate pointers and two-dimensional arrays */
#include<stdio.h>

/* Beginning of function main */
main()
{
    /* Initialization of array at compile time*/
    int i_arr[3][3]={45,60,12,43,44,65,57,18,32};

    /* Address of array */
    printf("\nThe address stored in i_arr is %u",i_arr);
    printf("\nThe address stored in i_arr + 1 is %u", i_arr+1);
    printf("\nThe address stored in i_arr + 2 is %u \n",i_arr+2);
    return;
}
/* End of function main */
```

### Output

The address stored in i_arr is 65508

The address stored in i_arr + 1 is 65520

The address stored in i_arr + 2 is 65532

Program 8, when executed, displays three addresses as an output. The first address stored in i_arr, which is a pointer to any array, is 65508. The second address stored in i_arr+1 is 65520, which was not expected. The address of the second element in the first row was expected in i_arr +1. However, i_arr when incremented by 1 is directly incremented by 12. The address 65520 is an address of the first element in the second row. Similarly, i_arr+2 returned 65532. The expected address was the address of the third element in the first row, but the address returned is the address of the first element in the third row. Thus, when an integer is added to a pointer in an array i_arr, the address location is advanced by 24 (12 × 2) bytes. Note that we may get different addresses each time the program is executed.

Let us modify Program 8 by adding some more statements. Program 9 illustrates this modification:

## Program 9

```c
/* Program to illustrate dereference pointer and two-dimensional array*/
#include<stdio.h>

/* Beginning of function main */
main()
{
    /* Initialization of array at compile time*/
    int i_arr[3][3]={45,60,12,43,44,65,57,18,32};

    printf("\nThe address stored in *(i_arr + 0) is %u",*i_arr);
    printf("\nThe address stored in *(i_arr + 1) is %u", *(i_arr+1));
    printf("\nThe address stored in *(i_arr + 2) is %u",*(i_arr+2));

    printf("\n\nThe address stored in i_arr is %u",i_arr);
    printf("\nThe address stored in i_arr + 1 is %u", i_arr+1);
    printf("\nThe address stored in i_arr + 2 is %u",i_arr+2);

    return;
}

/* End of function main */
```

The address stored in *(i_arr + 1) is 65520
The address stored in *(i_arr + 2) is 65532

The address stored in i_arr is 65508
The address stored in i_arr + 1 is 65520
The address stored in i_arr + 2 is 65532

You might have noticed that when Program 9 is executed, the result of *(i_arr+1) and (i_arr+1) are identical. Similarly, the result of i_arr + 1 and *(i_arr +1), and i_arr+2 and *(i_arr+2) are also identical. They point to the first elements of different rows. Now the question that arises is how to access other elements of the row. Pointer arithmetic *(i_arr+0) results in address of the first element of the first row. When an integer value 1 is added to *(i_arr + 0), the result is the address of the second element in the first row. When an integer value 2 is added to *(i_arr + 0), the result is the address of the third element in the first row. Similarly, when integer values 1 and 2 are added to *(i_arr + 1), the result is the address of the second and third elements of the second row. When integer values 1 and 2 are added to *(i_arr + 2), the result is the address of the second and third elements of the third row. If *(i_arr + 1) + 1 results to the address of the second element of the second row, there is a possibility that the prefixing dereference operator * to *(i_arr + 1) + 1 results into value stored at the second row and the second column. Let us write a program to cross check the aforementioned statements. Program 10 illustrates the access of elements in two dimensional array with pointers.
