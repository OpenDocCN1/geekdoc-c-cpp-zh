| **Table 3: The fseek() Function and Various Possibilities** | |
| :--- | :--- |
| **Statement** | **Operation** |
| fseek(file_pointer,0L,0) | Move the file pointer to the beginning of the file |
| fseek(file_pointer,0L,1) | Stay at current position |
| fseek(file_pointer,0L,2) | Move the file pointer to the end of the file |
| fseek(file_pointer, k, 0) | Move file pointer (k+1)th byte forward from the beginning of the file |
| fseek(file_pointer, -k,2) | Move the file pointer (k-1)th byte backward from the end of the file |

When the operation is successful, the function fseek returns a zero. When unsuccessful operations are performed, the function returns −1. An example of unsuccessful operation is fseek(fp_item,5,2). The number 2 denotes EOF. Thus, the statement fseek(fp_item, 5, 2) attempts to move file pointer 5 bytes forward from the end of the file.
C library also contains a rewind function to position the file pointer at the beginning. Its working is similar to that of fseek(file_pointer,0L,0).
