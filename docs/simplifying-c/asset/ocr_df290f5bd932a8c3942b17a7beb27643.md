```
int calculator(int i_first, int i_second, char c_operator);
```

The preceding syntax indicates that the function `calculator` expects three parameters when the function is invoked. Next condition to keep in mind is that the first two parameters should be of type integer and the third should be of type character. At the time of function call, both these conditions should be satisfied. In Program 4, the function `calculator` has been called using the statement `i_result = calculator(i_first, i_second, c_operator);`, and the three parameters used here are called actual parameters. As the number of parameters required and the order sequence of data type are correct, the program works fine. The function `calculator` could also be called as follows:

```
i_result = calculator(i_second, i_first, c_operator);
```

Program 4 would still work fine if we use the call given in the preceding syntax. Here also, we have specified three parameters of which the first two are integer type and the third is of character type. In case of the multiplication or addition operator, the result of both the calls aforementioned would remain the same, but for all other operators, the result would differ.
