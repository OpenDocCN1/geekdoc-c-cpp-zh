# ### 11.9 Structure and Function

As discussed in Chapter 8 of this book, functions help in creating modular programs. Functions interact with other functions using parameters. Till now we have used primitive data types as parameter of functions. A structure may also be passed as a parameter to a function. Similarly, it is also possible to write functions that return structure variable. Program 7 illustrates the how to pass structure as a parameter to function.

▶ **Program 7**

