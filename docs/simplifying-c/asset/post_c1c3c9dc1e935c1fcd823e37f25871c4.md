## Conditional Operators

In Program 2, we have used a decision structure *if* to make a decision whether the number is odd or even. C language provides us an operator known as *conditional operator* or *ternary operator* for condition checking. This operator consists of combination of two symbols, that is, **?** and **:**. The syntax to use conditional operator is as follows:

```
(Condition) ? (True Statement) : (False Statement);
```

The condition in the preceding syntax refers to a relational expression, which results in true or false. True and false statements can be an expression or a constant value. Program 8 illustrates the use of conditional operator. The program is used to find the minimum value from the two entered values.

## Program 8

```c
/* Program to illustrate the use of conditional operator */
#include <stdio.h>
/* Beginning of main function */
main( )
{
   /* Declare variables */
   int i_num1, i_num2, i_minimum;
   /* Accept the value of num1 and num2 */
   printf("\n Enter the value of num1: ");
   scanf("%d",&i_num1);
   printf("\n Enter the value of num2: ");
   scanf("%d",&i_num2);
   /* Use of conditional operator */
   i_minimum = (i_num1 <= i_num2) ? (i_num1) : (i_num2);
   /* Print the minimum value */
   printf("\nthe minimum value of the two is %d \n", i_minimum);
   return;
}
/* End of function main */
```

In Program 8, the statement `i_minimum = (i_num1 <= i_num2) ? (i_num1) : (i_num2);` depicts the usage of conditional operator. The conditional operator is used to check whether the variable `i_num1` is less than or equal to `i_num2`. When resolving conditions in C, at times we need multiple conditions to be taken into account. C language provides operators known as logical operators to handle such situations. The next section discusses about logical operators.

## Logical Operators

The logical operators are used to compare Boolean expressions. The result of the Boolean expression is always Boolean. C languages provides us three logical operators, namely, AND, OR, and NOT. Table 3 presents the list and usage of these logical operators along with the number of operands required in an expression and its syntax:

**Table 3: Logical Operators**

| Symbol | Name | No. of Operands Required | Syntax |
| :--- | :--- | :--- | :--- |
| && | Logical AND | Two | Expression 1 && Expression 2 |
| \|\| | Logical OR | Two | Expression 1 \|\| Expression 2 |
| ! | Logical NOT | One | !(Expression) |

The expressions 1 and 2 in Table 3 can be a binary expression, a unary expression, or a constant value. Logical AND is used when all the given conditions in an expression needs to be satisfied, while logical OR is used when any one of the given conditions needs to be satisfied. Logical NOT, when used along with an expression, checks whether or not the expression is evaluated to value 0. If the expression evaluates to value 0, the result of the NOT operation is 1, which means true. In all other cases, the result of the NOT operation is 0, which means false.

As mentioned earlier, logical or Boolean expression gives as an output value that is Boolean. The Boolean values are represented by either 0 or 1, where 1 refers to true and 0 refers to false. Table 4 lists the output of different logical operations:

**Table 4: Truth Table of Logical Operations**

| Return value of Expression 1 | Return value of Expression 2 | Expression 1 && Expression 2 | Expression 1 \|\| Expression 2 | !(Expression 1) |
| :--- | :--- | :--- | :--- | :--- |
| 0 | 0 | 0 | 0 | 1 |
| 1 | 0 | 0 | 1 | 0 |
| 0 | 1 | 0 | 1 | 1 |
| 1 | 1 | 1 | 1 | 0 |

It can be seen in Table 4 that the AND operator returns 1 only if both expressions return value 1, while the OR operator returns 1 when any of the expressions return value 1. The NOT operator, when used, simply toggles the value of an expression. Program 9 illustrates the use of logical operators in C program:
