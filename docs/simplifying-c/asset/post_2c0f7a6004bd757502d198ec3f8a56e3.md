In Program 3, we have defined an array of size five. The loop used for reading data iterates 10 times, and so, instead of reading only 5 values, we are able to read 10 values. The compiler allows us to read 10 values due to the property of contiguous memory in the array. This property of the array may cause problems at times. Let us try to understand how it stores the value at the sixth position of the array.

As mentioned earlier, the name of the array refers to an address of the first element. The compiler calculates the rest of the addresses using the first address as base. The formula to calculate the address of any element is as follows:

> Address of element at index I = Base address of the array + (size of the data type × Index I)

For example, if a float array starts at address 655208 and we need to find the starting address of element in index 3, then the preceding formula can be written as follows:

```
Address of element at index 3 = 655208 + (4 × 3)
= 655208 + 12
= 655220
```

The address can be cross verified with the elements shown in Figure 3. This equation holds for any index. Thus, even when we have defined only five elements in the array, the compiler, using the aforementioned formula, calculates the address of any index and stores a value there.

The array elements in which values are once assigned can be used as normal variables. We can perform operations such as assignment, comparison, and others on the array elements. Program 4 illustrates how to find the maximum value from a given array:

## Program 4

```c
/* Program to find the maximum value from an array */  
#include<stdio.h>  
#define MAX 5  
  
/* Function to find maximum value */  
int findmax(int *temp)  
{  
   int i_ctr;  
   /* Initialize first element of array to maximum */  
   int i_max = temp[0];  
   
   /* Compare with other elements in array */  
   for(i_ctr = 1; i_ctr < MAX; i_ctr++)  
   {  
        if(temp[i_ctr] > i_max)  
            i_max = temp[i_ctr];  
   }  
   return i_max;  
}  
/* End of function */  
   
/* Beginning of main function */  
main()  
{  
   /* Declare variables */  
   int i_ctr, i_max;  
   int i_array[MAX];  
   
   /* Read Data */  
   
   for(i_ctr = 0; i_ctr < MAX; i_ctr++)  
   {  
        printf("\nElement %d: ",i_ctr + 1);  
        scanf("%d",&i_array[i_ctr]);  
   }  
   
   i_max = findmax(i_array);  
   /* Print Data */  
   printf("\nThe maximum value in the array is %d\n",i_max);  
   return;  
}  
/* End of function main */
```

In Program 4, we have defined two functions, namely, main and findmax. The function main accepts the array elements and passes it to the function findmax. The function findmax accepts an address of array and returns an integer value. We observed the use of int *temp in the function findmax, where temp represents the pointer that can store address of integer variable. As the array defined in function main was of integer type, the pointer temp accepted the address of the first element of the array and then itself started working as an array. All the values were obtained by using the aforementioned address formula.

## Multidimensional array

Most of the data that we use is represented in multiple dimensions. For example, consider the data given in Table 1:

**Table 1: Sample Data**

| Roll No. | English | Math | Science | Drawing |
| :------- | :------ | :--- | :------ | :------ |
| 1        | 75      | 90   | 40      | 40      |
| 2        | 50      | 60   | 70      | 85      |
| 3        | 80      | 85   | 55      | 60      |

It can be observed in Table 1 that the data shows marks obtained by roll number 1, 2, and 3 in English, Math, Science, and Drawing, respectively. The data here is represented in multiple dimensions as we have three rows and four columns. The data of listed in Table 1 can be easily represented in C using the two-dimensional array. If the marks obtained are assumed to be integer, then the syntax of a multidimensional array can be declared as follows:

```c
int i_mark[row size][column size];
```

In the preceding syntax, row size refers to the roll number of student and column size refers to different subjects. Both these values are integer values. The entity i_mark[0][3] would then refer to marks obtained by roll number 1 in Drawing. Figure 4 shows the memory representation of the multidimensional array:

![](img/5d422ba7108ffdf64376be51eaf0c459_207_0.png)

**Figure 4: Memory Representation of the Multidimensional Array**

It can be observed in Figure 4 that the multidimensional array can be stored in two different ways in the memory. The allocation of elements can be done in a row-major form or a column-major form. In both the cases, the address of the elements would remain the same. The job of fetching the correct value for a given index will be done by the compiler. The general syntax to define a multidimensional array is as follows:

```c
data type identifier[size 1]...[size n];
```

The preceding syntax can be modified as per the need of the program. In normal cases, we may not need arrays that have more than three dimensions. The array I_mark defined before is said to be a two-dimensional array as it has one row and one column.

The two-dimensional arrays, similar to one-dimensional array, can also be initialized at compile time. The syntax to initialize the two-dimensional array at compile time is as follows:

```c
data type identifier[row size][column size] = { value 1, value 2, ..., value n };
```

For example, the array `int I_mark[3][4];` can be initialized at the compile time, as shown next:

```c
int i_mark[2][3] = {75, 90, 40, 40, 50, 60, 70, 85, 80, 85, 55, 60};
```

or

```c
int i_mark[2][3] = {{75, 90, 40, 40},{50, 60, 70, 85},{80, 85, 55, 60}};
```
