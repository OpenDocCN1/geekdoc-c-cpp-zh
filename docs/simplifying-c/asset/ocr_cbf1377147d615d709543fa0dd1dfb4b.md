# 8.9 Advantages of Functions

A user can create single function for a program that has code length of 50 lines. However, if the code length of a program goes beyond 50 lines, using only single function may lead to problems. The program may become too large and complex, thus making maintenance of the program problematic. The testing and debugging of a program also becomes difficult. Testing is the process of reviewing and executing a program with the intent of detecting errors. Debugging is the process of isolating and correcting the errors present in the program. The use of functions in programs gives the following advantages:

+   - Improves the readability of the program.
- Allows us to follow a structured approach of programming.
- Understanding and maintenance of program becomes easy.
- Debugging of problems becomes easy as we need to work on the problematic function only, rather than the entire program source code.
- Functions once written can be used to make a user-defined library, thus allowing the function to be used many times.
