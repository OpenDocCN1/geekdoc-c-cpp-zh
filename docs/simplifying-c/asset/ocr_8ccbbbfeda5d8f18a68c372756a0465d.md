# 1.2 Techniques of Solving Problem

Now, we know that to solve a problem using computer, first we need to develop a manual solution. The solution can be devised using various techniques, of which three most commonly used techniques are as follow:

+   - Representing a solution as pseudocode
- Drawing a flowchart
- Writing an algorithm

Users can use any of these techniques to solve a problem manually as per their convenience. Let’s discuss about these techniques in brief in the following subsections.

# Representing a Solution as Pseudocode

It is always easier to express thoughts using one’s mother tongue. For example, if someone scribbles few steps to solve the problem of voting eligibility in Hindi, Gujarati, Marathi, or English language, then it could be considered as pseudocode. The term pseudo is a Greek word, which means false or fake. Hence, the term pseudocode means writing a fake code in any language that is spoken across the globe. This code is written in a manner such that in times of need, it can be converted into a program source code of any desired programming language.

However, solutions to large problems tend to become complex and lengthy. In addition, natural language statements have the tendency to generate multiple meanings per statement, and the pseudocode can be misinterpreted if read by persons other than the person who wrote it. The pseudocode for the problem of voting eligibility is as follows:

```
Get current age and citizenship status of Mr. Mohit Aroklar
If current age is equal to or greater than 18, and citizenship status is equal to Indian
Then Mr. Mohit Aroklar is eligible to vote in the assembly elections
Else Mr. Mohit Aroklar is NOT eligible to vote in the assembly elections
```

It can be observed that the statements have formed a logical sequence. This sequence can be mapped to any formal language (that is, programming language) after knowing the syntax of the language.

# Drawing a Flowchart

A flowchart is a pictorial representation of a sequence of steps to be performed for solving a given problem. It uses a fixed set of symbols to represent various types of instructions. These symbols are joined by a solid line having arrows that show the flow of the statements. Flowcharts are probably the best tool to solve the problem manually as they could be drawn by anybody having the knowledge of the symbols. The flowchart is normally prepared as a first step toward the solutions of the problem. The logic and the flow of a problem can be easily understood from a flowchart.
