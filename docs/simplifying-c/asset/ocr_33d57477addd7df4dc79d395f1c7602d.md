# C Keywords

A keyword refers to the words that have been predefined by the designer of the language. ANSI C standard supports 32 predefined keywords. Each keyword has a predefined meaning associated to it, and can be used for specific purpose only. The list of the keywords available in ANSI C is listed in Table 4:

**Table 4: ANSI C Keywords**

| auto | double | int | struct |
| :--- | :--- | :--- | :--- |
| break | else | long | switch |
| case | enum | register | typedef |
| char | extern | return | union |
| const | float | short | unsigned |
| continue | for | signed | void |
| default | goto | sizeof | volatile |
| do | if | static | while |

The keywords in C are case sensitive and adhere to strict syntax. The use of these keywords has been discussed in subsequent chapters throughout the course of study.

# Identifier

A user is allowed to create a word of his own by making use of C character set: such a word is known as an *identifier*. A language has its own rule for defining an identifier. It consists of a set of letters, digits, and some special characters. Examples of identifiers are totalcost, RATE, float, and add(). Here, totalcost and RATE are names of a variable, add() is the name of a function, and float is a predefined keyword.
