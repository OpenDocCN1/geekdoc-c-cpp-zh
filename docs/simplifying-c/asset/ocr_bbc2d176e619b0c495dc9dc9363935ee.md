Till now we replaced only single characters using substitution macro. The preprocessor directive #define can also be used to replace the entire strings. Program 7 illustrates the usage of preprocessor directive to replace strings:

# Program 7

```
```c
/* Program to illustrate the usage of preprocessor directives to replace 
   strings */

#define GOOD printf("You are a good learner\n")
main()
{
    int i_num;
    printf("\n How many C programs have you written so far: ");
    scanf("%d",&i_num);
    if ( i_num > 100 )
        GOOD;
    else
        printf("\nSorry you need to practice more.\n");
    return;
}
```
```

**Output 1:**

```
How many C programs have you written so far: 150
You are a good learner
```

**Output 2:**

```
How many C programs have you written so far: 75
Sorry you need to practice more.
```

In Program 7, an entire string printf("You are a good learner\n") has been replaced by a macro name. The #define directives can also be used to replace predefined variables and operator in C. Program 8 illustrates the usage of preprocessor directive to replace integer data type and plus operator.

# Program 8

```
```c
/* Program to illustrate the usage of preprocessor directive 
   to replace predefined data type and operator */
#include<stdio.h>
#define MARKS int
#define PLUS +
main()
{
    MARKS i_eng, i maths, i_science, i_total;
    printf("Enter marks scored in English, Maths and Science: ");
    scanf("%d %d %d", &i_eng, &i maths, &i_science);
    i_total = i_eng PLUS i maths PLUS i_science;
    printf("Total marks scored is %d\n", i_total);
    return;
}
