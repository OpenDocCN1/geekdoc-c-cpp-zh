# 13.9 General I/O in Text Files

In Program 2, we have seen that the contents can be written to a file one character at a time. Program 3 transfers strings to disk file. Program 4 transfers integers to a file. However, what shall be done if situation demands to work with combination of these data types. For such situations, the functions fscanf and fprintf can be used. The function fprintf is used to store data in a file. The function fscanf is used to read data from a file. The syntax of these functions is similar to that of the functions scanf and printf with a single difference. It accepts an additional parameter, that is, file pointer. These functions are also useful to store formatted data.

The syntax of the function fprintf is as follows:

```
fprintf(file_pointer, format_specifiers, data);
```

The function fprintf accepts three parameters. The first parameter is pointer to file in which contents are to be stored. The second parameter is format specifier, and it is used to indicate data type of the data to be stored. The third parameter is variables in which the data can be a set of variables, constant, or expressions.

The syntax of the function fscanf is as follows:

```
fscanf(file_pointer, format_specifiers, variables);
```

The function fscanf accepts three parameters. The first parameter is a pointer to file from which contents are to be read. The second parameter is format specifier, and it is used to indicate data type of the data being read. The third parameter is variables in which the actual data read from the file will be stored.
