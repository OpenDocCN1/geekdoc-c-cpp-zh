### 7.1 Type of Loop

The loop structure always has an entry point and an exit point. The entry point indicates beginning of the loop, and the exit point indicates the breaking or terminating point of the loop. Figure 1 illustrates a concept of loop:

![](img/5d422ba7108ffdf64376be51eaf0c459_142_0.png)

**Figure 1: Concept of Loop**

It can be seen in Figure 1 that the logical flow of the loop indicates the action block will be repeated infinitely. To stop the loop from being executed infinitely, we need to introduce a test condition that controls the execution of the loop. The entry point block and the exit point block normally represent this test condition.

Loops, irrespective of the programming language they are used in, are classified as pretest (or entry controlled) or posttest (or exit controlled) loops. Within the two classes, the loops can be further classified as event-controlled (or sentinel events) or counter-controlled loops. The next subsection discusses about pretest and posttest loops.

#### Pretest and Posttest Loops

A loop can be classified as pretest or posttest based on the point where the control test condition is checked. If the control test condition is checked at the entry point, the loop is called a pretest loop. Figure 2 illustrate a logical flow of the pretest loop:

![](img/5d422ba7108ffdf64376be51eaf0c459_143_0.png)

It can be observed in Figure 2 that before executing any statement of the action block, we check for test condition. Entry in the loop is possible only if the test condition is evaluated to true. It is for this reason that the pretest loop is also known as entry-controlled loop. If the test condition is evaluated to false, the loop terminates. Note that if the test condition is evaluated to false, when trying to enter the loop for the first time, the action block of pretest loop will not be executed at all.

The posttest loop is exactly the opposite of the pretest loop. Here, the control test condition is checked at the exit point. Figure 3 illustrate a logical flow of the posttest loop:

![](img/5d422ba7108ffdf64376be51eaf0c459_143_1.png)

It can be observed in Figure 3 that the compiler will directly start executing the first statement within the action block. Entry in the loop is possible irrespective of the result of the test condition for the first time. The test condition will be checked at the exit point. It is for this reason that the posttest loop is also known as exit-checked loop. If the test condition is evaluated to true, the flow of control is transferred back to the first statement in action block. If the test condition is evaluated to false, the loop terminates. Note that in any case, the posttest loop will always be executed once.

The next subsection discusses about the event-controlled (or sentinel) and counter-controlled loops.

#### Counter-Controlled Loop and Event-Controlled Loop

To manage the repetition in loop, we need a loop counter. For example, assume that we need to repeat a block of statements for 10 times. In such a case, we need a variable that keeps track of the number of times repetition has happened. This variable at the beginning of the loop will be assigned a value 1. As the action block execution finishes, the variable will be updated by adding 1 to it. The test condition then will check if the value of the loop counter is equal to 10 or not. If the value of the loop counter is not equal to 10, the loop will continue execution. In case the value of the loop counter is equal to 10, the loop will terminate. The loop designed in the preceding example is known as counter-controlled loop. The reason it is called counter controlled is that we know beforehand how many times the loop will be executed.

Consider a case where we don’t know the exact number of time a loop will be executed. Instead, we wait for a specific event to happen. On occurrence of the said event, we terminate the loop. Such a loop is known as event-controlled or sentinel loop. For example, assume that a program has to keep accepting a number from the user till a number 0 is entered. Here, the user may enter 0 in the first iteration; if so, the loop terminates as soon as it starts. If the user enters 0 in the fifth iteration, then the loop is executed for five times. Thus, it is not fixed when the loop in consideration is going to terminate as it waits for an event (user enters 0).

### 7.2 Repetition in C

C language provides three types of loop structures, namely, *for*, *while*, and *do ... while*. The loop structures for and while are pretest loops, and *do ... while* is a posttest loop. All these three loop structures can be used to create a counter-controlled loop or an event-controlled loop. The loop structure *for* is generally used to create a counter-controlled loop. Event-controlled loops on the other hand are created using the *while* and *do ... while* loop structures.
