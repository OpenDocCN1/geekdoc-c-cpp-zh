# ### Program 3

```
/* Program to add two integers using pointers*/
#include<stdio.h>

/* Beginning of function main */
main()
{
/* Declare variable */
int i_first, i_second, i_sum;
int *p_x,*p_y,*p_sum;
p_x=&i_first;
p_y=&i_second;
p_sum=&i_sum;

/* Accept value of x and y */
printf("\n Enter the value of first: ");
scanf("%d",p_x);
printf("\n Enter the value of second: ");
scanf("%d",p_y);

/* Sum of elements using dereference operator with pointers*/
p_sum=*p_x + *p_y;

/* Display the result */
printf("\n The sum of two integers i_first and i_second is
%d\n",*p_sum);
return;
}
/* End of function main */
```

**Output:**

Enter the value of first: 10

Enter the value of second: 30

The sum of two integers i_first and i_second is 40

In Program 3, we have declared three integer variables named i_first, i_second, and i_sum, and three pointers variables named p_x, p_y, and p_sum. The statement p_x = &i_first; indicates that p_x points to i_first. Similarly, p_y points to i_second and p_sum points to i_sum. Later in the program, the pointers are used to store the input values provided by the user. Note that in the scanf statements used in this program, the pointers p_x and p_y are not prefixed with & as in usual scanf statements. This is because the pointer variables p_x and p_y themselves contain an address. As discussed earlier, the value stored at address, which is available in p_x, can be accessed by *p_x. Similarly, the value stored at address, which is available in p_y, can be accessed by *p_y. The statement *p_sum = *p_x + *p_y; adds the values and stores the result at address, which i_sum holds. The result is then displayed on the screen.
