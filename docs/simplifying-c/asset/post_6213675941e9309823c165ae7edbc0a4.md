We have already mentioned in Chapter 9 that an array is a data structure used to store elements that have the same data type. The elements of an array are stored in sequence, one after the other. This arrangement is known as contiguous memory allocation. Till now, an array has been used to store numeric data such as age, marks, and height. In practical scenario, we need to store data such as name of person or city. Numeric arrays will not work in such cases and hence the need of character array arises. In this chapter, we will learn what a string is, how to define a character array, and how to store and retrieve data from character array. We will also learn to perform various operations on character array.

### 10.1 String

The term string, in general, refers to a series of character that represents an entity such as name. Most of the programming languages provide logical implementation of strings. The reason to provide a logical implementation rather than physical implementation is the nature of string. Almost all strings that are used in program are of variable-length characters; hence, it becomes difficult to store the string in a fixed-length data type. For example, if we want to store the name of a city such as Ahmedabad or Mumbai, then the number of characters used in both these strings is different. Due to this variable property of the string, most languages allow different format of string. Figure 1 shows the different format of strings along with examples:

![Figure 1: String Format](img/5d422ba7108ffdf64376be51eaf0c459_217_0.png)

It can be seen in Figure 1 that in all the string formats, one additional character is required. In case of fixed-length string, we need to specify a delimiter that identifies the end of string. This delimiter cannot become a part of the string data as it works as end of string marker. For example, in Figure 1, * has been used as delimiter; hence, if we write a string Ahme*dabad, it will be converted to two string Ahme and datab. Same is the case with the delimited strings; the only difference is the amount of memory space occupied in memory. In case of fixed-length strings, if the number of characters in the string is less than the allocated fixed size, then the remaining memory blocks will always be wasted. The length-controlled strings require the string to start with a numeric value that identifies the number of characters in the string.
C language allows both fixed-length as well as variable-length string formats. The next section discusses how to define a string using character array.

### 10.2 Character Array as String

C language allows us to group set of characters terminated by a null character (\0) together to generate meaningful data entities. This sequence of characters is known as a string. The syntax of defining a character array is as follows:

```
char identifier name[size];
```

where the identifier name refers to any valid C variable name and the size is the total number of characters that can be stored in the array. As C uses a delimiter to mark end of string, the number of characters that can be stored in the array will always be one less than the size of array. For example, the definition char s_name[10]; defines a character array called s_name capable of storing 10 characters. The array here can store only one name and is considered as one dimensional.
