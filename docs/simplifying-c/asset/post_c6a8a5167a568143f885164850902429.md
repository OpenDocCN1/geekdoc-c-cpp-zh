## 4.3 Formatted Functions

The formatted functions are considered to be all-purpose functions. These functions, as can be seen from Table 1, are used to input or output all type of data, may it be char, int, float, or double. The general syntax of the formatted function is shown in Figure 3:

![](img/5d422ba7108ffdf64376be51eaf0c459_75_0.png)

It can be seen in Figure 3 that the function name can be scanf or printf. The format specifier string identifies the data type format in which the values of the variables are to be read or written. The identifier list consists of the address of variables in case of scanf and names of variables in case of print. Before we continue further, let us understand the concept of address and name of a variable. An identifier when defined in C program is associated with three entities, as shown in Figure 4:

![](img/5d422ba7108ffdf64376be51eaf0c459_75_1.png)

It can be observed in Figure 4 that an identifier has name, value, and address. At times we need to utilize the value of the identifier in an expression and make use of the name of the identifier. On the other hand, if we want to store a value that is entered by the user, we refer to an address of the identifier. In C, the address of an identifier is accessed by prefixing ampersand (&) symbol to the identifier name. The most common mistake the new programmers make is that they do not use the ampersand (&) symbol at the time of reading the data. Let us now have a look at how the formatted functions work.

### Input Function

The activity to accept input from a user happens in almost all programs. C language provides a predefined function called scanf to take the input. The syntax of the function is as follows:

```c
scanf("format string", address list of identifiers);
```

The preceding syntax consists of two parts, namely, a format specifier that identifies the data type and an address list of identifiers. The format string consists of certain predefined set of alphabets. Each alphabet refers to a specific data type. It is possible to read multiple data in one scanf call. In this case, the format specifier will contain the format code usually separated by a space, and the address list will contain addresses of the identifiers in which the data needs to be stored. Table 2 is the list of format specifier that is used for reading or writing data:

**Table 2: Format Specifier String**

| Data Value | Data Type | Format code |
| :--- | :--- | :--- |
| Integer | short int / int | %d or %i |
| | unsigned int | %u |
| | long unsigned int | %lu |
| | long int | %ld |
| Hexadecimal | int | %x or %p |
| Octal | int | %o |
| Character | signed char | %c |
| | unsigned char | %c |
| | char * (String) | %s |
| Real | float | %f or %g |
| | double | %lf |
| | long double | %Lf |

It can be observed from Table 2 that we have different format specifier for different data types. The format specifier is required to be written in the order that we want the data to be entered. The programs written in earlier chapter has already used the function scanf. Program 1 illustrates the use of scanf function:

#### Program 1

```c
/* Program to illustrate the use of scanf */
#include <stdio.h>
/* Beginning of main function */
main()
{
    /* Declare variables */
    int i_first;
    double d_second;
    char c_choice;

    /* Read and print the values */
    printf( "\nEnter the values : ");
    scanf ( "%d%lf%c",&i_first, &d_second, &c_choice);
    printf( "\nValues of the variables are %d %lf %c\n" ,i_first,d_second,c_choice);
    return;
}
/* End of function main */
```

**Output 1:**

```
Enter the values: 45 57.76 g
Values of the variables are 4557 0.760000 g
```

**Output 2:**

```
Enter the values: 75 65.50 t
Values of the variables are 75 65.500000
```

In Program 1, we have used three variables: two are numeric and one character. The program just asks us to enter the values without specifying the order in which we need to enter. In addition, we observed that the format string does not have any separators to separate the format codes.

In Output 1, the user would like to enter 45, 57.76, and g in the variables. However, C allocates the values as 4557, 0.760000, and g. Out of the three values entered, only one value seems to be as per the choice of the user. Let us try to understand what happened here. The user entered 4557.76g from the keyboard without inserting any separator in between the values. The data from the keyboard generated a stream of characters. At the time when the result was to be printed, the output function tried to convert the data into integer. As the stream data 4557 did not have any decimal place in between, it was assumed to be an integer. When . (dot) was read from the stream, the compiler tried to map it with the next variable data type; hence, .76 was allocated to variable d_second, and finally, g was allocated to c_choice.

To solve this problem, the user in Output 2 enters the data using space as a separator. The entry that the user does here is 75, 65.50, and t. It can be seen that the first two variables are assigned appropriate values, while the last one seems to be wrong. In fact, the output is absolutely correct. In this case also, the data is first converted to stream. When the first space is encountered, the value 75 is allocated to i_first. Then the compiler drops the space and allocates 65.50 to d_second. The space after 65.50 is the problem here, as space is also considered a valid alphabet of C language and the compiler allocates the value of space to c_choice. As space indicates a nonprintable character, it is not visible in the output. We may wonder at this point as to what happened to character t entered at the time of input. It is still in the stream; it will be either allocated to new variable or dropped from consideration, depending on the data type of the new variable. In case the next variable to be read is of character data type, t will be allocated to it; in all other cases, it will be simply dropped from the stream.

The property of C language mentioned earlier needs the programmer to be bit careful at the time of writing the programs. A small modification that the programmer needs to do here is ask the inputs by specifying appropriate message. Program 2 shows the modified version of Program 1:

#### Program 2

```c
/* Program to illustrate the use of scanf */
#include <stdio.h>
/* Beginning of main function */
main()
{
/* Declare variables */
int i_first;
double d_second;
char c_choice;

/* Read and print the values */
printf("\nEnter the value of i_first: ");
scanf("%d",&i_first);
printf("\nEnter the value of d_second: ");
scanf("%lf",&d_second);
printf("\nEnter the value of c_choice: ");
scanf("%c",&c_choice);
printf("\nValues of the variables are %d %lf %c\n"
, i_first,d_second,c_choice);
return;
}
/* End of function main */
```

**Output 1:**

```
Enter the value of i_first: 56
Enter the value of d_second: 75.66
Enter the value of c_choice: 
Values of the variables are 56 75.660000
```

In Program 2, the problem of reading first two variables gets solved easily by converting a single scanf statement into multiple scanf statements. However, the problem of character data still exists; in this case, the problem is the Enter key. This problem would not have happened in case we had read the character value first. To solve the problem, we need to make use of temporary variable so that the value of the Enter key is allocated to the temporary variable. We can use the unformatted function here. Program 3 illustrates the usage of a temporary variable:

#### Program 3

```c
/* Program to illustrate the usage of temporary variable */

#include<stdio.h>
/* Beginning of main function */
main()
{
    /* Declare variables */
    int i_first;
    double d_second;
    char c_choice, c_temp;

    printf("Enter the value of i_first: ");
    scanf("%d", &i_first);
    printf("Enter the value of d_second: ");
    scanf("%lf", &d_second);

    /* Use temporary variable to clear the stream */
    c_temp=getchar();

    printf("\nEnter the value of c_choice: ");
    scanf("%c", &c_choice);
    printf("\nValues of the variables are %d %lf %c\n",
           i_first, d_second, c_choice);
    return;
}
/* End of function main */
```

**Output 1:**

```
Enter the value of i_first: 45
Enter the value of d_second: 78.25
Enter the value of c_choice: h
Values of the variables are 45 78.250000 h
```

**Output 2:**

```
Enter the value of i_first: r
Enter the value of d_second: 
Enter the value of c_choice: 
Values of the variables are -28851 0.000000
```

**Output 3:**

```
Enter the value of i_first: 56
Enter the value of d_second: h
Enter the value of c_choice: 
Values of the variables are 56 0.000000
```

In Program 3, the use of statement c_temp = getchar(); solves our problem and we are able to get the desired output, as seen in Output 1. One more interesting thing to note here is that the compiler terminates the reading of a value if any invalid character is encountered. Observe that in Output 2, after the message *Enter the value of i_first*, the compiler expected an integer value, but received a character. In this case, the compiler terminated the input and directly gave the output. The output here is considered to be garbage as it is of no use. Similar case happened in Output 3.
