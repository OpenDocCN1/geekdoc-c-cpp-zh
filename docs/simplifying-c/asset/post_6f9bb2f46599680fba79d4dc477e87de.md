A system works on the fundamental principles of input, process, and output. The programs that we design represent the processing part of the system. The process normally converts raw data into information. The raw data represents input, while the information represents output. The output generated is always dependent on the input that has been provided to the program. The input can be provided to the program statically or dynamically. In static input, the raw data does not change with every run of program, while in dynamic input, the raw data has a tendency to change in every run of program. C language does not provide any construct for input/output (I/O) operations. The I/O operations in C are handled using inbuilt functions. These functions are collectively known as standard I/O library. In this chapter, we shall discuss about C streams, and basic I/O operations and different functions, such as formatted and unformatted functions, that can be used to perform these operations.

## 4.1 C Streams

The initial programmers had a very hard time handling the I/O operations. The programs created had to explicitly identify the input device where the input would be taken from and the output device where the output would be sent to. The programmer thus, instead of concentrating on the solution of problem, also had to look for hardware-specific problems that could arise from the I/O operations. The Unix operating system provided a concept of abstract devices. This concept removed the need for a program to identify the kind of devices used.

The concept of data stream was used to provide the device abstraction. A data stream is an ordered sequence of data bytes that can be read until the end of the file. The option of the Unix operating system to support the concept of data streams provided three standard streams, namely, standard input, standard output, and standard error. Most C run-time environments provide equivalent functionality, regardless of the nowadays operating system. The standard streams are opened automatically when a C program is executed, thus making it convenient for the programmer to use them. This section gives details of the three streams mentioned.

### Standard Input

Standard input, more commonly known as stdin, is a data in the form of a text stream that goes into a C program. As we know that in most cases, we enter data to our programs using the keyboard; in C, the keyboard is considered as a standard input file. The user transfers the data using the keyboard character by character. These characters are then stored in a temporary memory location called buffer until the entire line is read. In most cases, the end of line is indicated by pressing the Enter key on the keyboard. Once the entire line is read, the C program converts it into appropriate data type and stores them in appropriate variables. As the input is stored in a buffer initially, it becomes easy to edit the entry that is being done. For example, if we are entering a number and by mistake we enter a wrong number. Then, by pressing the Backspace key, we can easily delete the wrong entry and correct it before it gets stored in the variable. Figure 1 shows the concept of buffering using standard input:

It can be seen in Figure 1 that the input is in the form of a text string. After the C program receives this data at the time of compilation, it is converted into an appropriate data type. In this case, the data has been converted to a word HELLO and a number 25.

### Standard Output

Standard output, more commonly known as stdout, is a text stream where a program writes its output data. The monitor is considered to be a default standard output file unless the output is redirected to any other file. In this case, the compiler takes data from the memory block and passes it to the C program; a function within this program, which is based on some specification, then generates a stream of characters. These characters are then displayed on the monitor. Figure 2 shows the concept of output using standard output stream:

### Standard Error

Standard error, more commonly known as stderr, is another output stream. This data stream is used to output error messages or diagnostics by programs. The stream stderr is independent of the standard output and can be redirected separately. A classic usage of this stream is done when the user tries to open a file on a secondary storage. This stream can be used to check whether the file with specified name exists or not and give appropriate message. The usage of this stream is given in the chapter related to files.

The three streams mentioned before are used by the programmers whenever they use the I/O operations in C language. The streams in real sense are pointers that point to a particular text file. The concept of pointers will be discussed in later chapters. The next section discusses about different input and output functions available in C language.

## 4.2 Input and Output Functions

C language uses modular approach of programming. This approach allows us to break the program parts into small units called functions. C language has a huge library of functions available for various functionalities. One of such functionalities is to provide input to the program and receive output from the program. To provide input and output, C language provides inbuilt functions. The functions for input and output are based on the data types, and are categorized as formatted functions and unformatted functions. Table 1 lists the input and output functions available in C language:

**Table 1: List of Input and Output Functions**

| Formatted Function | | Used for | Data Type It Works with |
| :--- | :--- | :--- | :--- |
| scanf() | Input | All |
| printf() | Output | All |

| Unformatted Function | | Type | Data Type It Works with |
| :--- | :--- | :--- |
| getchar() | Input | char |
| gets() | Input | char |
| getc() | Input | char |
| putchar() | Output | char |
| putc() | Output | char |
| puts() | Output | char |

It can be observed from Table 1 that C language provides us with many input and output functions. Each of these functions has a specific usage. Many vendors have added additional I/O functions in their versions of C. For example, Turbo C has functions such as getch() and getche() for input, while putch() and putche() for output.
