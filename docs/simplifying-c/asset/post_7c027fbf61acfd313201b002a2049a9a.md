
# The While Loop

The while loop is a pretest loop that is used when the number of times the statement needs to be executed cannot be predetermined. The syntax of the while loop is as follows:

```
while (test condition)
   Action block;
```

The test condition mentioned in the preceding syntax is a relational expression or a positive constant. The action block of the while loop is executed only when the test condition is evaluated to true. Figure 6 illustrates the logical flow of the while loop:

![](img/5d422ba7108ffdf64376be51eaf0c459_151_0.png)

▲ **Figure 6: Logical Flow of the While Loop**

As the test condition is checked at the entry point, the while loop is considered to be an entry-controlled loop. If the test condition is evaluated to false at first time itself, the action block of the loop will not be executed at all. Program 6 illustrates the use of while loop to calculate the greatest common divisor of two positive numbers.

## Program 6

```c
/* Program to calculate the greatest common divisor of two positive
    numbers using the while loop */

#include <stdio.h>

/* Beginning of main function */
main()
{
   /* Declare variable */
   int i_num1, i_num2, i_remainder, i_temp;
   /* Input Data */
   printf("Enter the first number: ");
   scanf("%d", &i_num1);

   printf("Enter the second number: ");
   scanf("%d", &i_num2);
   /* Check if both numbers are positive and greater than 0 */
   if((i_num1 > 0) && (i_num2 > 0))
   {
      /* Swap values if needed */
      if(i_num2 > i_num1)
      {
         i_temp = i_num2;
         i_num2 = i_num1;
         i_num1 = i_temp;
      }

      /* Find greatest common divisor */
      i_remainder = i_num1 % i_num2;
      printf("The greatest common divisor of %d and %d is ", i_num1, i_num2);
      while(i_remainder)
      {
         i_num1 = i_num2;
         i_num2 = i_remainder;
         i_remainder = i_num1 % i_num2;
      }

      /* Print the greatest common divisor */
      printf("%d\n", i_num2);
   }
   else
   {
      printf("One or Both of the entered number is zero or negative\n");
   }
   return;
} /* End of main function */
```

**Output 1:**

Enter the first number: 25
Enter the second number: 20
The greatest common divisor of 25 and 20 is 5

**Output 2:**

Enter the first number: 44
Enter the second number: 0
One or Both of the entered number is zero or negative

It can be observed in Program 6 that the while loop is an event-controlled loop. Here, the event that terminates the loop is `i_remainder == 0`. In Program 6, if the value of the expression `i_remainder = i_num1 % i_num2;` is evaluated to 0 initially, the while loop is not executed at all. Output 1 gives us a correct value of the greatest common divisor, while Output 2 indicates an error condition.

Let us take another example of the while loop. Program 7 illustrates the use of while loop to calculate the factorial of a positive number greater than 0.

## Program 7

```c
/* Program to calculate the factorial of a positive number greater than 0
using the while loop */
#include <stdio.h>

/* Beginning of main function */
main()
{
    /* Declare variable */
    long l_factorial = 1;
    int i_number, i_ctr = 1;

    /* Input Data */
    printf ("Enter a number: ");
    scanf ("%d", &i_number);

    /* Check if number is greater than 0 */
    if(i_number > 0)
    {
        /* Calculate factorial */
        while(1)
        {
            l_factorial = l_factorial * i_ctr;
            /* Check if counter is equal to number */
            if(i_ctr == i_number)
                break;
            i_ctr++;
        }
        printf("Factorial of %d is %ld\n", i_number, l_factorial);
    }
    else
        printf("The number entered is zero or negative\n");

    return;
} /* End of main function */
```

**Output 1:**

Enter a number: 4
Factorial of 4 is 24

**Output 2:**

Enter a number: -10
The number entered is zero or negative

It can be seen in Program 7 that the while loop uses a constant as a test condition. The use of constant value 1 will always be evaluated to true, hence, the while loop here becomes an infinite loop. To terminate the loop, we have used an event `i_ctr == i_number`. If this condition is evaluated to true, the loop terminates. Output 1 gives us a correct factorial, while Output 2 indicates an error condition.

> The initial programmers have to be cautious as normally they make a mistake of terminating the while statement with a semicolon. In such cases, the compiler may or may not raise error.

# The Do...While Loop

The do...while statement is a posttest loop whose action block is executed at least once. The test condition is always checked at the time of exiting the loop. Hence, it is also known as exit-controlled loop. The syntax of the do...while loop is as follows:

```
do
  Action block;
while (test condition);
```

Figure 7 illustrates the logical flow of the do...while loop:

![](img/5d422ba7108ffdf64376be51eaf0c459_154_0.png)

▲ **Figure 7: Logical Flow of the Do...While Loop**

The action block of the do...while statement in most cases is a compound statement. In case we use a single statement within the action block, it might lead to an infinite loop. For example, look at the code snippet given in the following:

```c
do                          or          do
  printf("Hello\n");                    printf("Hello\n");
while (1);                      while (i_ctr <= 10);
```

In both the aforementioned cases, the loop will go on executing infinitely as there is no stopping criterion. Program 8 illustrates the use of the do...while loop to find out whether the entered number is prime or not:

## Program 8

```c
/* Program to find whether the entered positive number is prime or not using the do...while loop */

#include <stdio.h>
#include <math.h>

/* Beginning of main function */
main()
{
  /* Declare variable */
  int i_number, i_divisor = 3;
  double d_limit;

  /* Input Data */
  printf("Enter a number: ");
  scanf("%d", &i_number);

  /* Check if number is greater than 0 */
  if(i_number > 0)
  {
    /* Beginning of switch structure */
    switch(i_number)
    {
      /* Identify special cases */
      case 1:
        printf("Number %d is special number\n", i_number);
        break;
      case 2:
      case 3:
        printf("Number %d is a prime number\n", i_number);
        break;
      /* Check whether number is prime or not */
      default:
        d_limit = sqrt(i_number);

        /* Check whether number is divisible by 2 */
        if(i_number % 2 == 0)
        {
          printf("Number %d is not prime\n", i_number);
          break;
        }

        /* Check whether number is divisible by other
           numbers like 3, 5 so on*/
        /* Beginning of do...while loop */
        do
        {
          if(i_number % i_divisor == 0)
          {
            printf("Number %d is not prime\n", i_number);
            break;
          }
          else
            i_divisor += 2;
        }
        while(i_divisor <= (int)d_limit);
        /* End of do...while loop */

        if(i_divisor > (int)d_limit)
          printf("Number %d is prime number\n", i_number);
    }
    /* End of switch structure */
  }
  else
    printf("The number entered is zero or negative\n");
  return;
} /* End of main function */
```

**Output 1:**

Enter a number: 1
Number 1 is special number

**Output 2:**

Enter a number: 2
Number 2 is a prime number

**Output 3:**

Enter a number: 17
Number 17 is prime number

**Output 4:**

Enter a number: 121
Number 121 is not prime number

**Output 5:**

Enter a number: -10
The number entered is zero or negative

In Program 8, we have used the decision structures if and if-else along with a do...while loop. Observe that the do...while loop used in the program has two exit points: the first is the test condition `i_number % i_divisor == 0` and the second is the test condition `i_divisor <= (int)d_limit`. In either case, the control flow will first come into the loop and then divert to the next statement immediately after the loop. Note that to execute the preceding program in Linux/Unix environment, we will have to use command `gcc prog7_8.c -lm`. The parameter `-lm` here refers to linking of math.h file included in the program.

All the three loop structures, that is, for, while, and do...while, can be used interchangeably. There is no restriction that one has to use a for loop for generating counter-controlled loop. In the same way, it is not necessary that the while or do...while loop is to be only used for generating event-controlled loop. The user as per his/her convenience can use any of these loop structures to design a counter-controlled loop or an event-controlled loop.
