C provides us with modulo operator (%); its purpose is to get a remainder value of division. The usage of the modulo operator is shown in Program 2:

/* Program to illustrate the usage of modulo operator */
#include <stdio.h>

/* Beginning of main function */
main( )
{
    int i_num;
    /* Accept the value of num */
    printf("\n Enter a number : ");
    scanf("%d",&i_num);

    /* Check whether number is even or odd */
    if(i_num % 2 == 0)
        printf("\n Number %d is Even \n",i_num);
    else
        printf("\n Number %d is Odd \n",i_num);

}

Program 2 is designed to check whether the entered number is odd or even. We know that if a number is divisible by 2, then it is an even number; otherwise, it is an odd number. To check this divisibility, we actually check whether the remainder of the division is zero or not. Modulo operator in C language gives us this remainder value directly. In the preceding program, the statement if(i_num % 2 = 0) checks whether the remainder of the number when divided by 2 is zero or not, and based on the output decides which line is to be printed on the screen.

Note that the module operator works with only integer operands. If we try to use it with float operand, it will give us an error.
