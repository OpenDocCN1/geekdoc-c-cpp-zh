# Summary

In this chapter, we have learned about the concepts of primitive, and user defined/ derived data types. The primitive data types that we discussed are int, char, float, and void. Each of these data types, except for void, can be prefixed with modifiers. The modifiers change the size requirement and the range of values that can be stored in an identifier. The modifiers discussed were short, long, signed, and unsigned. We also learned about the usage of a user-defined data type named typedef, which allows the programmer to give an alias to an existing primitive or derived data type. The derived data type enum was discussed along with example. Further, we discussed the concept of pointers. Pointers are special variables that stores address of other variables as its value. Pointers are the only variables that can be declared as having void data type.
