In the previous chapter, we have discussed about a C token called *identifier*. Identifiers are integral part of any C program. For example, assume that in our program, we have defined an identifier named *joining_month*, which is used to store the numeric value of month in which an employee has joined the organization. This identifier can then store any value between number 1 and 12, as we only have 12 months in the calendar year. It is not possible here to store a value such as 1.8, as the value will be inappropriate. This example suggests that the type of values stored in an identifier also has significance. C language uses certain reserve words to identify the type of data value that can be stored in an identifier. As the reserve word associates a data value type with the identifier, it is known as data type. In this chapter, we will understand and discuss in detail about different data types available in C and their usage. We will also learn about user-defined data type and enumerated data type.

# ## 3.1 Understanding Data Type

The type of data value that can be stored in an identifier is known as its data type. If an identifier *joining_month* is assigned a data value 8, then we would say that the identifier is capable of storing an integer data. This in turn states that the data type of the identifier *joining_month* is an integer. Similarly, if an identifier *total_marks* is assigned a data value 95.75, then we would say that it is capable of storing real data; hence, its data type has to be real.

Reserved words of C are used to associate two entities with an identifier. First is the type of value that can be stored in the identifier, and second is the memory space required for storage by the identifier. The compiler designers associate a pre-allocated fixed memory space with a data type. Thus, it becomes easier for the compiler to handle different identifiers used in C.
