Once the memory representation of a two-dimensional array is known, the next question arises is how to access individual elements using pointers. Similar to one-dimensional array, the name of the array itself contains address of the first element of an array. Thus, the name of an array acts as a pointer variable. If some pointer arithmetic is applied on the pointer variable, which points to an array, individual elements can be accessed. It is a bit tricky to understand how individual addresses can be accessed using pointer to an array.

It can be seen in Figure 13 that the array i_arr is a two-dimensional array containing nine elements. Virtually, it has three rows and three columns. A very common thought that comes in mind is that a counter variable can be added to array pointer to access each individual element. However, it is not so. Let's assume that an array i_arr starts from memory location 1000. When 1 is added to i_arr, the address accessed should be 1004. However, it is not the case when a pointer variable i_arr is pointing to a two-dimensional array. Instead, the next address accessed is the address of the next row.

Let us write a program and print address locations accessed by adding an integer value to an array pointer. Program 8 illustrates the use of pointers along with two-dimensional array.

/* Program to illustrate pointers and two-dimensional arrays */
#include<stdio.h>

/* Beginning of function main */
main()
{
    /* Initialization of array at compile time*/
    int i_arr[3][3]={45,60,12,43,44,65,57,18,32};

    /* Address of array */
    printf("\nThe address stored in i_arr is %u",i_arr);
    printf("\nThe address stored in i_arr + 1 is %u", i_arr+1);
    printf("\nThe address stored in i_arr + 2 is %u \n",i_arr+2);
    return;
}
/* End of function main */
