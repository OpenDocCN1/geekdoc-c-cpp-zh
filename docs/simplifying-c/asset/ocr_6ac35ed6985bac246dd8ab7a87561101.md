| Table 3: Usage of format code %[list of characters] |  |  |
| --- | --- | --- |
| Format | Description |  |
| scanf(\"%[A-Z,0-9]\",&s_student); | The function scanf accepts upper case alphabets from A to Z as well as digits from 0 to 9. |  |
| scanf(\"\[,z,0-9]\",&s_student); | The function scanf accepts a comma, lower case z and digits from 0 to 9. |  |

The exact opposite of %[list of characters] format is %[ ^ list of characters]. In this case, the reading of data will be stop as soon as the user enters one of the characters within the list. Program 5 illustrates the use of format %[ ^ list of characters]:

# ▸ Program 5

```
/ * Program to illustrate how to read and display strings */
#include<stdio.h>
/ * Beginning of main function */
main()
{
/* Declare character array */
char s_student[50];

/* Read data in array */
printf("\nEnter the name of student: ");
scanf("%[\^\n]",&s_student);

/* Print data from array */
printf("\nThe name of the student is %s\n",s_student);
return;
}
/ * End of function main */
```

Output 1:

Enter the name of student: vidita arolikar
The name of the student is vidita arolikar

Output 2:

Enter the name of student: harshit jain
The name of the student is harshit jain

In Program 5, both the outputs now contain full names. This works as we have used %[ ^\n] as a format code. The escape sequence \n represents new line and the format code here specifies that the user has to read data till the Enter key is pressed.
