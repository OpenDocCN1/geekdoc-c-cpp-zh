# Function malloc

The function malloc is used to allocate a memory block of specified size at runtime. The function reserves a memory block and returns a void pointer that point to the starting address of the memory block. As learned in Chapter 3 the void pointer can be pointed to any required data type, thus creating a memory block to represent a specific data type value. The syntax of function malloc is as follows:

```
ptr = (cast type *) malloc(size in bytes);
```

The function malloc accepts only one argument. The argument is the size of memory required to be allocated in bytes. The size value can be a constant, such as 100, or an expression, such as 25 * sizeof(int). The value returned by function malloc is a pointer pointing to the starting memory location of an entire block. This pointer can be type casted to any valid C data type. For example, to allocate 100 bytes of memory, which can contain integers, the following statements can be used:

```
int *ptr;
ptr=(int *) malloc(100);
```

Assume that a programmer wants to allocate a memory block to store 25 integers. As different compilers may allocate different bytes to integers to avoid any problems in size allocation, the following statements can be used:

```
int *ptr;
ptr=(int *) malloc(25 * sizeof(int));
```

In the preceding statement, the size of memory block allocated will depend on the value returned by sizeof(int). If the value returned by sizeof(int) is 2 bytes, then 50 bytes will be allocated in the memory, and if the size returned is 4 bytes, then 100 bytes will be allocated in the memory.
