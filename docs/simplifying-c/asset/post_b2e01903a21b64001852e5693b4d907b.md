## Function with Parameter and Return Value

Functions that accept an input parameter from the calling function and also return a value to the calling function are known as function with parameter and a return value. Here, there is a two-way data transfer from the called function to the calling function, and vice versa. Program 4 illustrates a function that accepts parameter as well as returns a value. Note that a function is capable of returning only one value, but accept one or more parameters:

### Program 4

```c
/* Program to illustrate the use of a function that accepts parameter and
   returns a value */
/* Program to calculate result of an expression */
#include <stdio.h>

/* Beginning of function calculator */
int calculator(int i_first, int i_second, char c_operator)
{
   /* Declare local variable */
   int i_result;

   /* Beginning of switch structure */
   /* Check for choice entered and Perform the required operation */
   switch(c_operator)
   {
      case '+':
         i_result =  i_first + i_second;
         break;
      case '-':
         i_result =  i_first - i_second;
         break;
      case '*':
         i_result =  i_first * i_second;
         break;
      case '/':
         if(i_second == 0)
            i_result = -999;
         else
            i_result =  i_first / i_second;
         break;
      case '%':
         i_result = i_first % i_second;
         break;
      default:
         i_result = -999;
   }
   /* End of switch structure */
   return(i_result);
}
/* End of function calculator */

/* Beginning of function main */
int main()
{
   /* Declare local variable */
   int i_first, i_second, i_result;
   char c_operator, c_temp;
   /* Input Data */
   printf("Enter first number : ");
   scanf("%d", &i_first);
   c_temp = getchar();
   printf("\nEnter second number : ");
   scanf("%d", &i_second);
   c_temp = getchar();
   printf("\nEnter the operator : ");
   scanf("%c", &c_operator);

   /* Call function calculator */
   i_result = calculator(i_first, i_second, c_operator);

   if(i_result != -999)
      printf("\nThe result of operation %d %c %d is %d\n", i_first, c_operator, i_second, i_result);
   else
      printf("\nIncorrect mathematical operator or division by zero error.\n");
   return 0;
}
/* End of function main */
```
