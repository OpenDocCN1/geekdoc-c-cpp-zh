Program 6 accesses each element of an array using *i_arr + i_ctr), where i_ctr is a counter ranging from 0 to 4. Thus, each element is accessed one by one, and its value is added to i_sum. In the end, the value of i_sum is displayed on the screen.

So far we have seen that the name of an array can act as a pointer to an array. Thus, further operations on an array can be performed using pointer arithmetic on the name of an array. However, what will happen if a programmer writes a statement i_arr++ in his/her program. In such a case, when the program is executed, the starting address of an array will be lost after the execution of i_arr++ statement. So, to be cautious, an additional pointer to an array should be used to perform array operations. Program 7 illustrates the use of additional pointer pointing to an array:

# Program 7

```
/\* Program to illustrate the assignment of pointer to array to another pointer variable \*/
#include<stdio.h>

/\* Beginning of function main \*/
main()
{
   /\* Declare variables \*/
   int i_arr[10],i_num,i_ctr,i_rev,i_temp,*p_arr;
   /\* Accept input from user \*/
   printf("How many elements would you like to enter: ");
   scanf("%d",&i_num);
   /\* Accept values of array elements from user\*/
   for (i_ctr=0;i_ctr<i_num;i_ctr++)
   {
      printf("\nEnter element i_arr[%d]",i_ctr);
      scanf("%d",&i_arr[i_ctr]);
   }
   /\* Store address of array in a pointer variable \*/
   p_arr=i_arr;

   /\* For-for-loop to reverse elements of an array\*/
   for (i_ctr=0,i_rev=i_num-1; i_ctr<i_rev; i_ctr++, i_rev--)
   {
      i_temp=*(p_arr + i_ctr);
      *(p_arr + i_ctr)=*(p_arr + i_rev);
      *(p_arr + i_rev)=i_temp;
   }
   /\* Display new values of array\*/
   for (i_ctr=0;i_ctr<i_num;i_ctr++)
   {
      printf("\nThe new value of a[%d]",i_ctr);
      printf(" %d", *(p_arr + i_ctr));
   }
   return;
}
/\* End of function main \*/
```
