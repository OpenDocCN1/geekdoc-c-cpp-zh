## 09 Arrays

### OBJECTIVES

- What is an Array
- Describe Array Dimension

In the previous chapters, we have learned how to use primitive data types, such as int, char, float, and others, in C language. These data types were used to define single variables. Single variables at times do not suffice our requirements. For example, assume that we need to calculate the result of a class of 30 students. If we use primitive data types, we need 30 different variables. To manage 30 different variables at a time is always a problem. C language provides us a concept of derived data types to overcome this problem. In this chapter, we will discuss about a derived data types called array. We will also learn how to store and retrieve data from array and application of array.
Let’s first discuss what an array is.

### 9.1 What is an Array

As mentioned earlier, managing independent variables is always a problem. C language allows us to create a data structure using the existing primitive data types. This data structures can be managed easily. An array is one such data structure. An array is defined as a sequence of elements having the same data type, stored in the memory one after the other, and referred by common name. Figure 1 shows a memory representation of an array variables as well as other variables:

![](img/5d422ba7108ffdf64376be51eaf0c459_198_0.png)

It can be observed in Figure 1 that a set of variables create a block that is identified as Marks. As the elements are stored one after the other in sequence, the memory allocation is known as contiguous memory allocation. Marks here represent an array with seven elements. Each element has the same data type.

As the entire block is referred by the name *Marks*, the C compiler needs a mechanism to identify individual elements within this block. To identify each element in the block, index value is used. The index value in C language starts from zero. The elements of the array Marks are thus identified as Marks[0], Marks[1], Marks[2], Marks[3], Marks[4], Marks[5], and Marks[6]. Each of these elements independently works as a single variable. All the operations that can be performed on normal variables can also be performed on array elements. Figure 2 represents the modified memory representation of an array:

![](img/5d422ba7108ffdf64376be51eaf0c459_199_0.png)

It can be observed in Figure 2 that individual array element now has a name such as Marks[0], Marks[1], and so on. The indexes used are integers or an expression that results into an integer. No other index values are allowed. The array name when used without an index refers to the address of the first element of an array. In other words, it refers to start the address of an array.

It can also be observed that the memory block shown in Figure 2 looks like a table with one row and one column. C allows us to have different dimensions of array. The next section discusses the dimensions of array.

### 9.2 Array Dimension

C categorizes arrays as single-dimensional array and multidimensional array. The single-dimensional array has one row, while multidimensional array has multiple rows and multiple columns. The number of rows and columns in multidimensional array are specified by the user. Let us now discuss how to define and use single-dimensional array.

- **Single-Dimensional Array**
We know that an array is used to group multiple variables of the same data type under a single name. The syntax to declare a single-dimensional array is as follows:

`data type identifier[size];`

Data type identifies the type of data stored in the array; it can be integer, float, char, double, or any of the primitive data types. The identifier refers to name of the array and size indicates the maximum number of elements that can be stored in the array.
For example, `float f_marks[10];` defines a variable f_marks as an array, which is capable to store 10 float values.

An array once defined can be initialized at compile time or at runtime. In compile time initialization, the values are assigned at the time when the array is declared. In runtime initialization, user enters the value at the time of execution of the program. The syntax to initialize the array at compile time is as follows:

```
data type identifier[size] = { value 1, value 2, ......., value n };
or
data type identifier [ ] = { value 1, value 2, ......., value n };
```

The size of an array is optional if the values are assigned at compile time. In this case, the compiler will automatically assign the size to the array, depending on the number of values specified. Program 1 illustrates the use of array and initialization at compile time:

▶ **Program 1**

```c
/* Program to illustrate the use of array */
#include<stdio.h>
/* Beginning of main function */
main()
{
/* Declare variables */
int i_ctr;
float f_marks[10]={55.75,50.25,75.55,65,75.85};
/* Print the values in array */
printf("Elements of array\n");
for(i_ctr = 0; i_ctr < 10; i_ctr++)
printf("\nValue of element number %d is %.2f\n",i_ctr+1,f_marks[i_ctr]);
return;
}
/* End of function main */
```

**Output:**

```
Elements of array
Value of element number 1 is 55.75
Value of element number 2 is 50.25
Value of element number 3 is 75.55
Value of element number 4 is 65.00
Value of element number 5 is 75.85
Value of element number 6 is 0.00
Value of element number 7 is 0.00
Value of element number 8 is 0.00
Value of element number 9 is 0.00
Value of element number 10 is 0.00
```

In Program 1, we have defined the array to be of size 10. At the time of initialization, we only specified five values. The compiler hence allocated the values to the first five elements and rest of the values was initialized to zero. Figure 3 shows the memory representation of the array f_marks:

![](img/5d422ba7108ffdf64376be51eaf0c459_201_0.png)

▲ **Figure 3: Memory Representation of Array f_marks**

It can be observed in Figure 3 that each element of the array occupies 4 byte of memory. The total memory occupied by the array would then be obtained as the size of the array multiplied by the size of the data type. In preceding case, the size of the array is 10 and the size of the float is 4, hence the total memory occupied would be 10 × 4 = 40 bytes.

Even though the compile time initialization of array is allowed, it is seldom used. Most programmers prefer runtime initialization of array. The array values are read in the similar fashion as any normal variable. The only difference at the time of reading is the usage of the index. Program 2 illustrates the usage of runtime initialization of the array:

▶ **Program 2**

```c
/* Program to illustrate the use of array */

#include<stdio.h>
#define MAX 25

/* Beginning of main function */
main()
{
   /* Declare variables */
   int i_ctrl, i_num;
   int i_array[MAX];

   /* Read Data */
   printf("Number of elements in array: ");
   scanf("%d",&i_num);

   for(i_ctrl = 0; i_ctrl < i_num ; i_ctrl++)
   {
      printf("\nElement %d: ",i_ctrl + 1);
      scanf("%d",&i_array[i_ctrl]);
   }

   /* Print Data */
   for(i_ctrl = 0; i_ctrl < i_num ; i_ctrl++)
   printf("Value of element number %d is %d\n",i_ctrl+1,i_array[i_ctrl]);
   return;
}
/* End of function main */
```

**Output:**

```text
Number of elements in array: 5

Element 1: 55
Element 2: 27
Element 3: -19
Element 4: 39
Element 5: 12

Value of element number 1 is 55
Value of element number 2 is 27
Value of element number 3 is -19
Value of element number 4 is 39
Value of element number 5 is 12
```

In Program 2, we have defined the array to be of size 25. When the data is entered, we have used only five out of these. This is the normal case in most of the application. In addition, C compiler does not check the bounds of array. The bounds need to be handled by the programmer. For example, if the programmer defines an array of size 5 and the user reads 10 values in it, the compiler in this case will generate error only for compile time initialization. However, for runtime initialization, it will not generate any error. The user needs to be careful in such scenario as the reading of extra elements might overwrite a legitimate variable of program. Program 3 illustrates the example of array bounds:

▶ **Program 3**

```c
/* Program to illustrate the use of array */

#include<stdio.h>
#define MAX 5

/* Beginning of main function */
main()
{
   /* Declare variables */
   int i_ctr;
   int i_array[MAX];

   /* Read data */
   printf("Enter values\n");
   for(i_ctr = 0; i_ctr < 10 ; i_ctr++)
   {
      printf("\nElement %d", i_ctr + 1);
      scanf("%d",&i_array[i_ctr]);
   }

   /* Print Data */
   printf("Array Elements\n");
   for(i_ctr = 0; i_ctr < 10 ; i_ctr++)
   printf("\nValue of element number %d is %d\n",i_ctr+1,i_array[i_ctr]);
}
```
