Now, let us declare identifiers of integer data type and a character data type, and have a look at the change in memory. The identifier of integer data type can be declared as int i_num = 42; and the identifier of character data type can be declared as char c_ans='y';. When these statements are executed, some area will be reserved in the memory for both the identifiers, namely, i_num and c_char. It is assumed that the system takes 4 bytes to store an integer and 1 byte to store a character. Then the computer memory will hold values as shown in Figure 2:

![](bbox=[0.41, 0.52, 0.66, 0.74])

Assume that when the program is executed, the compiler stores the integer variable i_num at starting address 4000 and character variable c_ans is stored at address 50000. Note that the address of a variable is the starting address of the first byte occupied in the memory by that variable. Thus, even though the variable i_num is stored within memory location 4000 to 4003, its address is still considered to be 4000.
