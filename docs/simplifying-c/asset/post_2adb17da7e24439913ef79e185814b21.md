## 5.1 Operators

At some point of time during our studies, all of us have learned mathematics, wherein we have performed operations such as addition, subtraction, multiplication, and division of two numbers. For example, 7 + 5 is how we represent an addition in mathematics, where 7 and 5 are termed as constant; on the other hand, + is a special symbol that identifies the operation to be performed on the constants. An operator can be defined as a special symbol in a language that identifies the operation that can be performed on the operands in the language. The operators in C are categorized into eight types, as shown in Figure 1:

### Arithmetic Operators

C language provides different operators, such as +, -, *, /, and %, to perform arithmetic operations. Table 1 lists the various operator symbols, their name, and their usage:

**Table 1: Arithmetic Operators**

| Symbol | Name | Usage |
| :--- | :--- | :--- |
| + | Addition operator | Add two operands; Unary plus |
| − | Subtraction operator | Subtract two operands; Unary minus |
| * | Multiplication operator | Multiply two operand |

| % | Modulo operator | Remainder of division of two operands |

The first four operators listed in Table 1 are used in most of the mathematical expressions. C language provides us with an additional operator % known as modulo operator. It is used to get a remainder when performing division of two operands. The operands can be a variable or a constant. Let us now see how we can use these operators in an expression. For example, consider the following C statement:

```
i_area = i_length * i_breadth;
```

shown in Figure 2. This statement is called a binary C expression, where i_area, i_length, and i_breadth are known as C identifiers or variables. The reason it is known as binary C expression is that it consists of an expression of the form operand 1 operator operand 2. Operand 1 will always be a single value, but operand 2 can be another expression or a constant value. The example statement, when executed, results in two operations, as shown in Figure 2:

The arithmetic operations in C language can be categorized as integer arithmetic, real arithmetic, or mixed mode arithmetic based on the operand used in the expression. The next section discusses these arithmetic operations in detail.

### Integer Arithmetic

In C language, when the operands used in the expression are positive or negative whole numbers, the arithmetic is considered to be an integer arithmetic. The resultant expression is called an integer expression, whose result is always an integer. Program 1 gives an example of integer arithmetic:

**Program 1**

```c
/* Program to illustrate the use of integer arithmetic */
#include <stdio.h>

/* Beginning of main function */
main() 
{
 /* Declare variables */
int i_base, i_height, i_area;

/* Accept the value of base and height */
printf("\nEnter the value of base of triangle: ");
scanf("%d",&i_base);
printf("\nEnter the value of height of triangle: ");
scanf("%d",&i_height);

/* Calculate area of triangle */
i_area = (i_base * i_height) / 2;

/* Print Area */
printf("\nArea of triangle with base %d and height %d is %d\n", i_base,i_height,i_area);
return;
}
/* End of function main */
```

**Output 1:**

| Output |
| :--- |
| Enter the value of base of triangle: 10 |
| Enter the value of height of triangle: 15 |
| Area of triangle with base 10 and height 15 is 75 |

**Output 2:**

| Output |
| :--- |
| Enter the value of base of triangle: 5 |
| Enter the value of height of triangle: 15 |
| Area of triangle with base 5 and height 15 is 37 |

Program 1 is designed to calculate the area of a triangle. Output 1 of the program does not have any problem. Let's observe Output 2 carefully: as per the conventional mathematics, (5 × 15)/2 should result in 37.50. However, it can be seen in Output 2 that the value of area is 37 instead of 37.50. This is the reason why we said that the output of an integer arithmetic is always an integer value. The division operator in C language works differently from conventional mathematics. In conventional mathematics, 7/10 would give us 0.7, but in C language, it would give us 0. Here, as we have used integer operands, the result of division has also to be integer. To make sure that the result is an integer, the compiler truncates the fractional part.

C provides us with modulo operator (%); its purpose is to get a remainder value of division. The usage of the modulo operator is shown in Program 2:

**▶ Program 2**

```c
/* Program to illustrate the usage of modulo operator */
#include <stdio.h>

/* Beginning of main function */
main( )
{
    int i_num;
    /* Accept the value of num */
    printf("\n Enter a number : ");
    scanf("%d",&i_num);

    /* Check whether number is even or odd */
    if(i_num % 2 == 0)
        printf("\n Number %d is Even \n",i_num);
    else
        printf("\n Number %d is Odd \n",i_num);
    return;
}
/* End of function main */
```

**Output 1:**

```
Enter a number: 12
Number 12 is Even
```

**Output 2:**

```
Enter a number: 15
Number 15 is Odd
```

Program 2 is designed to check whether the entered number is odd or even. We know that if a number is divisible by 2, then it is an even number; otherwise, it is an odd number. To check this divisibility, we actually check whether the remainder of the division is zero or not. Modulo operator in C language gives us this remainder value directly. In the preceding program, the statement `if(i_num % 2 == 0)` checks whether the remainder of the number when divided by 2 is zero or not, and based on the output decides which line is to be printed on the screen.

Note that the modulo operator works with only integer operands. If we try to use it with float operand, it will give us an error.
