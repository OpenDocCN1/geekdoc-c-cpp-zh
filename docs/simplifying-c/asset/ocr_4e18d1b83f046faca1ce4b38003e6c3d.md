Program 3 is used to calculate the multiplication of two given numbers. Although small, this program has been divided it into two functions. The first function main accepts the values to be multiplied, and the second function multiply performs the actual multiplication.

The program starts with the comment statement that declares the purpose of a program. We then include the required header files. The next statement is known as prototype statement. It is needed in C if a user-defined function is written after the function main. The main function declares three integer variables, and asks the user to give the values of two of them. These values are then passed to the function multiply by using the statement i_multiply = multiply(i_first, i_second), where i_first and i_second are known as parameters of the function multiply. After encountering this statement, the control is transferred to the function multiply. This function then multiplies the value and stores it in i_result. The value of i_result is then returned back to the statement in main function and assigned to i_multiply. Finally, the main function prints the value of multiplication and exits from the program.
