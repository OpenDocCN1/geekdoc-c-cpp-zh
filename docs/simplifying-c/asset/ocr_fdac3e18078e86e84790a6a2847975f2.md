A selective statement is one that decides which statement or set of statements are to be executed, depending on the result of a relational comparison of two expressions. An iterative statement refers to a statement that allows repetition of a code snippet to be executed again and again. Detailed discussion of labeled, jump, selection, and iteration statements has been done in later chapters.
