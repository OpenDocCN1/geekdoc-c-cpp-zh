# **String Constant**

String in C represents set of characters. It is denoted by using sequence of characters enclosed within double quotes. String constants don’t have any ASCII value associated with it. In C, string constant “H” is not equal to single character constant 'H'. This happens because of the way in which these constants are stored in the memory. The string constant “H” will be allocated two memory spaces, while 'H' will be allocated only one memory space. This is due to the fact that strings in C are ended by adding \’0’ , a null character. Examples of string constants are “C Programming”, “Language”, and “H”.

# **Back Slash Characters**

C language provides a special two-character constant. These constants are known as back slash characters or escape sequences. They are known as back slash characters as the first character is always a back slash \( \ ), and as the output of these constants is not a printable character but white space, they are also known as escape sequence characters. Similar to single-character constants, these constants also have an ASCII value associated with them. Table 8 lists the back slash constants available in C language along with their ASCII values and usage purpose:

Table 8: Back Slash Characters
| Back Slash Character | ASCII Value | Usage Purpose |
| :--- | :--- | :--- |
| \0 | 0 | Inserting null value |
| \a | 7 | Inserting audible alert |
| \b | 8 | Inserting backspace |
| \t | 9 | Inserting horizontal tab |
| \n | 10 | Inserting new line |
| \v | 11 | Inserting vertical tab |
| \f | 12 | Inserting form feed |
| \r | 13 | Inserting carriage return |
| \" | 34 | Inserting double quote |
| \' | 39 | Inserting single quote |
| \? | 63 | Inserting question mark |
| \\ | 92 | Inserting back slash |

The escape sequences are mostly used to format the input or output of a program. For example, \‘t’ is used to separate values by inserting a tab in between them. Various escape sequence characters have been used to format the input and output of programs used in this book.
