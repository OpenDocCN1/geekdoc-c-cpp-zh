# 5.4  Statements in C Language

The expression designed from operands and operators are converted to C statements. The statements generated may or may not be executable statements. In a C program, the executable statements cause some action to be taken, while the nonexecutable statements work as comments. C Language provides us six categories of statements, as shown in Figure 12:

It can be seen in Figure 13 that an expression in C program is an executable statement. Normally, the expression is converted into a C statement by terminating it with a semicolon (;). The semicolon indicates the end of statement to the compiler. All C statements that end with a semicolon are executable. A group of zero or more statements combined together in opening and closing curly braces is referred to as a compound statement.
