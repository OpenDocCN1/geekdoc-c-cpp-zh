### 12.1 Understanding Pointer Variables

We know that a pointer is a variable that can store address of an identifier. Similar to primitive data type variables, such as integer, float, and others, pointer is also associated with a name, a value, and an address in memory. The difference between a variable of primitive data type and a pointer variable is the value stored in them. The value stored in variables of primitive data types can be an integer, float, double, or character, but the value stored in the pointer variable will always be of type unsigned integer that refers to a memory address of other variable. Pointers are frequently used in C language. Thus, it is very necessary to understand the concept of pointers in detail. Primary memory of a computer can be thought of as a collection of cells, as shown in Figure 1:

![](img/5d422ba7108ffdf64376be51eaf0c459_259_0.png)

▲ Figure 1: Memory Organization

Now, let us declare identifiers of integer data type and a character data type, and have a look at the change in memory. The identifier of integer data type can be declared as `int i_num = 42;` and the identifier of character data type can be declared as `char c_ans='y';`. When these statements are executed, some area will be reserved in the memory for both the identifiers, namely, i_num and c_ans. It is assumed that the system takes 4 bytes to store an integer and 1 byte to store a character. Then the computer memory will hold values as shown in Figure 2:

![](img/5d422ba7108ffdf64376be51eaf0c459_259_1.png)

▲ Figure 2: Computer's Memory after Memory Allocation to Variables

Assume that when the program is executed, the compiler stores the integer variable i_num at starting address 4000 and character variable c_ans is stored at address 50000. Note that the address of a variable is the starting address of the first byte occupied in the memory by that variable. Thus, even though the variable i_num is stored within memory location 4000 to 4003, its address is still considered to be 4000. Each time a program is executed, different memory addresses can be allocated to the identifiers. Now, there are two ways to access a value 42 stored in the memory. The first way is to access it with the identifier i_num. The second way is to access it using address. The address of identifiers, such as i_num or c_ans, can be stored in the pointer variables. These pointer variables can be then used to access the value stored in the memory. The syntax to declare a pointer variable is as follows:

```plaintext
datatype  *ptr_variable;
```

where datatype can be any valid C data type and ptr_variable is a pointer variable that can hold address of an identifier of specified data type. For example, to declare a pointer variable p that can hold address of an identifier of an integer data type, the following statement can be used:

```c
int *ptr;
```

Note that the statement `int ptr;` indicates that identifier ptr can store a value of integer type, and the statement `int *ptr` indicates that identifier ptr is a variable that can hold address of another variable, which stores an integer value. To access an address of a variable, a reference operator (&) can be used. The & operator when prefixed to a variable returns the address of that variable. Thus, `&i_num` returns address of the first byte occupied by the variable i_num. In the aforementioned case, 4000 will be returned. This address can be allocated to the pointer variable by using the following assignment statement:

```c
ptr = &i_num;
```

Figure 3 illustrates the assignment of address to a pointer variable:

![](img/5d422ba7108ffdf64376be51eaf0c459_260_0.png)

Now, the next question that arises is how to access the value 42 using the pointer variable ptr? It is simple. The pointer variable ptr can be prefixed by a reference operator asterisk (*) to access the value 42. Figure 4 illustrates that *ptr and identifier i_num hold the same value:

![](img/5d422ba7108ffdf64376be51eaf0c459_260_1.png)

In other words, since we can access the value of i_num using ptr, we can say that ptr points to i_num. It is possible to assign a NULL value to a pointer variable. The statement `int *ptr = NULL;` defines a pointer with an initial value NULL. Program 1 illustrates the use of pointers in a C program.

#### ▶ Program 1

```c
/*Program to illustrate pointer variables*/
#include<stdio.h>
/*Beginning of function main */
main()
{
  /* Declare variables */
  int i_num;
  float f_num;
  int *i_ptr1,*i_ptr2;
  float *f_ptr;
  /* Assign values to variables*/
  i_num=10;
  f_num=40.54;
  /* Assign address of variables to pointer variables */
  i_ptr1=&i_num;
  i_ptr2=&i_num;
  f_ptr=&f_num;
  /* Print details of variables */
  printf("\n\nThe value of i_num is %d", i_num);
  printf("\n\n i_num identifies %u location in memory", &i_num);
  printf("\n\n Pointer variable i_ptr1 contains %u ", i_ptr1);
  printf("\n\n Pointer variable i_ptr2 contains %u ",i_ptr2);
  printf("\n\nthe value of *i_ptr1 is %d", *i_ptr1);
  printf("\n\nthe value of *i_ptr2 is %d", *i_ptr2);
  printf("\n\nthe value of f_num is %f", f_num);
  printf("\n\n f_num identifies %u location in memory", &f_num);
  printf("\n\nPointer variable f_ptr contains %u",f_ptr);
  printf("\n\nthe value of *f_ptr is %f\n", *f_ptr);
  return;
}
/* End of function main */
```

Output:

i_num identifies 65524 location in memory
Pointer variable i_ptr1 contains 65524
Pointer variable i_ptr2 contains 65524
The value of *i_ptr1 is 10
The value of *i_ptr2 is 10
The value of f_num is 40.540001
f_num identifies 65520 location in memory
Pointer variable f_ptr contains 65520
The value of *f_ptr is 40.540001

In Program 1, two variables are declared. The i_num variable is of integer type and f_num variable is of float type. Both the variables are initialized with values 10 and 40.54, respectively. Then three pointer variables are declared. The pointers i_ptr1 and i_ptr2 are declared of type integer. Both of them are made to point to variable i_num using the statements `i_ptr1=&i_num` and `i_ptr2=&i_num`. Thus, the pointer variables i_ptr1 and i_ptr2 contain address of the same variable i_num. Then a pointer variable f_ptr of float data type is declared. The pointer variable f_ptr is assigned an address of f_num. ### 12.2 Chain of Pointers

We have seen that a pointer contains address. The pointer variable itself is also stored within the primary memory along with normal variables. The statement `int *ptr;` indicates that ptr is a pointer that can hold address of a variable of an integer type. Now, a question arises that can we store address of pointer ptr in some other pointer? The answer is yes. It is possible to make a pointer point to another pointer. Thus, a chain of pointers can be created.
