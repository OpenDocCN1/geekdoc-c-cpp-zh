# Standard Error

Standard error, more commonly known as stderr, is another output stream. This data stream is used to output error messages or diagnostics by programs. The stream stderr is independent of the standard output and can be redirected separately. A classic usage of this stream is done when the user tries to open a file on a secondary storage. This stream can be used to check whether the file with specified name exists or not and give appropriate message. The usage of this stream is given in the chapter related to files.

The three streams mentioned before are used by the programmers whenever they use the I/O operations in C language. The streams in real sense are pointers that point to a particular text file. The concept of pointers will be discussed in later chapters. The next section discusses about different input and output functions available in C language.

# 4.2 Input and Output Functions

C language uses modular approach of programming. This approach allows us to break the program parts into small units called functions. C language has a huge library of functions available for various functionalities. One of such functionalities is to provide input to the program and receive output from the program. To provide input and output, C language provides inbuilt functions. The functions for input and output are based on the data types, and are categorized as formatted functions and unformatted functions.
