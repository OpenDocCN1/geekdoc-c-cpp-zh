
In general, the element a[rownum][column] in a two-dimensional array can be accessed with pointers using the following pointer arithmetic:

```c
a[rownum][column] = *(*(a + rownum) + column)
```

Note that the statements written in Program 10 can be reduced with nested for loop. Let us now write a program to display the transpose of a matrix. When a matrix is transposed, the row values of a matrix gets interchanged with its column values. Program 11 illustrates the use of nested for loop to access individual elements of a two-dimensional array:

### ▶ Program 11

```c
/* Program to create transpose of a matrix */
#include <stdio.h>

/* Beginning of function main */
main()
{
    /* Declare variables */
    int i_mat[3][3], i_row, i_col, i_temp;

    /* Accept values of matrix from user */
    printf("Enter the values for 3 x 3 matrix\n");
    for (i_row = 0; i_row <= 2; i_row++)
    {
        for (i_col = 0; i_col <= 2; i_col++)
        {
            scanf(" %d", *(i_mat + i_row) + i_col);
        }
    }

    /* Create transpose of matrix */
    for (i_row = 0; i_row <= 2; i_row++)
    {
        for (i_col = 0; i_col <= 2; i_col++)
        {
            if (i_row < i_col)
            {
                /* interchange of values */
                i_temp = *(*(i_mat + i_row) + i_col);
                *(*(i_mat + i_row) + i_col) = *(*(i_mat + i_col) + i_row);
                *(*(i_mat + i_col) + i_row) = i_temp;
            }
        }
    }

    /* Display transpose of matrix */
    printf("The transpose of matrix is:\n");
    for (i_row = 0; i_row <= 2; i_row++)
    {
        for (i_col = 0; i_col <= 2; i_col++)
        {
            printf(" %d", *(*(i_mat + i_row) + i_col));
        }
        printf("\n");
    }
    return;
} /* End of function main */
```

### Pointer Variable as Function Parameters

In Chapter 8, we learned that the address of identifiers can be passed as a parameter to functions. When the address of variable is passed as a function parameter, the receiving parameter must be a pointer variable. The process of calling a function by passing address to an identifier as a parameter and receiving it as a pointer is known as call by address. Earlier, we have written functions that accepted values. The process of calling a function by passing values of an identifier as a parameter is known as call by value. Program 13 illustrates the usage of call by address mechanism:

### ▶ Program 13

```c
/* Program to exchange values of two variables with call by reference process */
#include <stdio.h>
/* Function prototype */
void exchange(int *, int *);
/* Beginning of function main */
main()
{
    /* Initialize variables */
    int i_first = 10, i_second = 20;

    /* Print old values */
    printf("\nThe old values of first and second are %d and %d", i_first,
           i_second);

    /* Function call to exchange for swapping values of two variables */
    exchange(&i_first, &i_second);

    /* Print new values */
    printf("\nThe new values of first and second are %d and %d", i_first,
           i_second);
    return;
} /* End of function main */

/* Beginning of function exchange */
void exchange(int *i_first, int *i_second)
{
    int i_temp;
    i_temp = *i_first;
    *i_first = *i_second;
    *i_second = i_temp;
} /* End of function exchange */
```

**Output:**

```text
The old values of first and second are 10 and 20
The new values of first and second are 20 and 10
```

Program 13 calls a function exchange in the main program. The parameters of a function exchange are pointers. These addresses are received by the pointers `i_first` and `i_second`. Now, when the values of `i_first` and `i_second` are manipulated, the new values are written to the memory addresses directly. Thus, when a function is returned and the values of `i_first` and `i_second` are displayed again in calling function, new values are displayed on the screen.
