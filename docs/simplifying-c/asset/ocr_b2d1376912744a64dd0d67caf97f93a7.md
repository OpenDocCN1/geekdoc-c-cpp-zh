# ### 13.8 Function feof

Programs 2 and 4 use the EOF marker to check whether end of file has been reached or not. C library also provides function _feof_ declared in the header file _stdio.h_. Its primary purpose is to check whether a stream operation has reached the end of a file. The input file functions return EOF in case when the actual end of file is reached as well as in case of an error. The function _feof_ thus can be used to check whether we have reached an end of file or an error has occurred. The syntax of the function _feof_ is as follows:

```
int feof(file_pointer);
```

It accepts the file pointer as a parameter. The return value of the function is an integer. A nonzero value signifies that the end of the file has been reached; a value of zero signifies that it has not. Program 5 illustrates the use of function _feof_.
