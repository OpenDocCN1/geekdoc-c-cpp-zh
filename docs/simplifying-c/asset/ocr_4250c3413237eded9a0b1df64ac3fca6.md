# **The Do...While Loop**

The do...while statement is a posttest loop whose action block is executed at least once. The test condition is always checked at the time of exiting the loop. Hence, it is also known as exit-controlled loop. The syntax of the do...while loop is as follows:

```
```
do
  Action block;
while (test condition);
```
```

The action block of the do...while statement in most cases is a compound statement. In case we use a single statement within the action block, it might lead to an infinite loop. For example, look at the code snippet given in the following:

```
```c
do                          or          do
  printf("Hello\n");                    printf("Hello\n");
while (1);                      while (i_ctr <= 10);
```
```
