structure template is defined within the main function, its scope will be limited to the main function only. If it is defined outside the main function, the structure assumes global scope. Such a structure can be accessed in all the functions of the program that are defined below the structure definition.

# 11.3 Structure Variables

Once the structure template is defined, it can be used as a data type. The name of the structure acts as a user-defined data type. The syntax to declare a structure is as follows:

```
struct struct_name name_of_variable;
```

It is now possible for us to define variables of the struct contact shown in Figure 2. Assume that we need to define two contacts; the definition will then be as mentioned:

```
struct contact contact1, contact2;
```
