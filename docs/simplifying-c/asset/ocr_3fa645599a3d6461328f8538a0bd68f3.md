So far we have discussed about the fundamental data types such as integer, character, and float. However, practically, in almost all programming language, programmer needs to group data together to form larger constructs. An example of grouping data called array has already been discussed in earlier chapter. As mentioned earlier, arrays are used to store large groups of data that are of the same data type.

Assume that we need to create a phone directory by using arrays. In this case, we will need two arrays to be created and managed. A two dimensional character array will be required to store the name of the persons, while a one dimensional numeric array will be needed to store the phone numbers. Managing two different arrays would lead to the problem of mapping a name with phone number. The management of two different arrays would become simpler if the programming language itself allowed us to use a construct that logically relates name and phone number. C language has a construct called structure that allows us to pack data of different data types as one logical unit. This logical unit is called a record. In this chapter, we will learn about what is a structure, how to define a structure in C, and different operations that can be performed using a structure.
