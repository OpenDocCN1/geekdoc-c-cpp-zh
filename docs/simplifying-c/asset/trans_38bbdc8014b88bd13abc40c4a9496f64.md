## 10.3 字符串的初始化

在第 4 章中，我们学习了如何在运行时使用内置函数（如 `printf` 和 `gets`）接受用户输入的数据。作为一种灵活的语言，C 语言还允许我们在编译时初始化字符数组。初始化字符数组最简单的方法是在声明数组时使用字符串字面量进行赋值。在编译时初始化数组的语法如下：

```
char s_name[10] = "Ahmedabad";
```

其中 "Ahmedabad" 被称为字符串字面量。该字符串的内存表示将是图 2 中所示的那样。C 编译器会自动在我们用双引号括起来的字符末尾添加一个空字符（`\0`）。

初始化字符数组的另一种方法是使用单个字符，如下所示：

```
char s_name[10] = { 'P', 'u', 'n', 'e', '\0'};
```

由于字符串是由单个字符序列组成的，我们需要在此显式指定一个空字符。尽管这种方法可用，但由于操作繁琐，很少使用。迄今为止讨论的示例都涉及固定长度的字符串格式。如前所述，我们也可以使用可变长度的字符串。

如果在声明数组时省略数组的大小，则会自动定义可变长度字符串。定义将如下所示：

```
char s_name[ ] = "Baroda";
```

C 编译器将自动为数组分配 7 个字节；数组的大小计算为双引号内的总字符数加 1。如果在字符序列中插入前置或前导空格，在计算大小时也会将其包含在内。声明可变长度字符串格式的另一种方法是使用指针。前面的定义可以修改如下：

```
char *s_name = "Baroda";
```

这里，首先定义一个字符串字面量，然后将第一个字符的地址分配给指针变量。因此，字符 $B$ 的地址将被分配给 $s$\_name。由于剩余字符在内存中按顺序排列，因此可以轻松地访问它们。
一旦字符串可用，我们需要学习如何格式化和显示它们。下一节讨论了与字符串一起使用的不同格式化方法。

## 10.4 显示字符串

在第 4 章中，我们学习了如何格式化数值数据。与数字类似，字符串也可以以不同的格式显示。显示的通用格式与用于数值数据的格式类似，即 `\%[标志]\[宽度]\[.] \[长度\] 格式码`。程序 1 说明了字符串显示格式的使用：

### 程序 1

```
/* 演示字符串显示格式的程序 */

#include<stdio.h>
/* 主函数开始 */
main()
{
	/* 声明字符数组 */
	char s_student[15];
	/* 读取数组中的数据 */
	printf("\n\nEnter the full name of student: ");
	scanf("%[^\n]",&s_student);
	/* 打印字符串的不同格式 */
	printf("\n\nThe name of the student in different formats\n");
	printf("%s\n",s_student);
	printf("%7s\n",s_student);
	printf("%-15s\n",s_student);
	printf("%15.5s\n",s_student);
	printf("%.5s\n",s_student);
	printf("%-15.5s\n",s_student);
	return;
}
/* 主函数结束 */
```

     navde

存储在数组中的每个字符（包括空字符和空格）都由一个称为美国信息交换标准代码（ASCII）值的数值表示。因此，在内存中，字符串只是一组 ASCII 值。由于这个原因，可以对字符串元素执行算术运算。下一节讨论了如何在 C 语言中操作字符串。

## 10.5 操作字符串

字符串可以用许多不同的方式进行操作。我们可以对字符串执行诸如查找字符串长度、比较两个字符串是否相同、连接两个字符串、在字符串中查找字符、在字符串中查找子字符串等许多操作。C 语言提供了一系列优秀的内置函数来操作字符串。要使用这些函数，我们需要在程序中包含 `string.h` 头文件。

尽管 C 库中提供了内置函数，但我们编写了自己的程序来执行上述操作，以便清楚地了解这些函数的工作方式。下一节讨论了上述操作。

-   字符串长度

字符串长度定义存储在空字符之前的字符总数（包括空格）。数组的大小和存储在其中的字符串长度可能不同。例如，如果我们定义了一个如下所示的字符串：

```
char s_product[15] = "Computer";
```

那么，尽管这里数组的大小是 15，但字符串的实际长度是 8，因为空字符之前只有八个字符。程序 2 说明了使用 C 函数查找字符串长度的方法。该函数以指向字符元素的指针作为输入，并返回代表字符串长度的整数值。

### 程序 2

```
/* 查找字符串长度的程序 */

#include<stdio.h>

/* 计算字符串长度的函数 */
int strlen(char *s_str)
{
  int i_len;
  for ( i_len = 0; s_str[i_len] != '\0'; i_len++);
  return i_len;
}
/* 函数结束 */

/* 主函数开始 */
main()
{
  /* 声明字符数组 */
  char s_str[25];
  int i_len;
  /* 读取数组中的数据 */
  printf("\nEnter a string : ");
  scanf("%[^\n]",&s_str);
  i_len = strlen(s_str);
  /* 打印字符串长度 */
  printf("\nThe length of string %s is %d",s_str, i_len);
  return;
}
/* 主函数结束 */
```

**输出：**

```
Enter a string : Happy Birthday
The length of string Happy Birthday is 14
```

从程序 2 中可以看出，尽管数组的大小是 25，但获得的字符串长度为 14。程序 2 有两个函数，即 `main` 和 `strlen`；长度在 `strlen` 中计算并返回给 `main`。下一节讨论了如何比较两个字符串。

-   字符串比较

我们常常需要检查两个字符串是否包含相同的字符集。由于数组是一种数据结构，我们不能使用数组名来检查字符串是否相等。字符串是逐个字符进行检查的，以确定它们是否相同。这种比较基于存储在每个索引处的字符的 ASCII 值。然后，字符串被评估为等于、大于或小于另一个字符串。程序 3 说明了如何比较两个字符串：

### 程序 3

```
/* 比较两个字符串的程序 */
#include<stdio.h>

/* 比较字符串的函数 */
int strcmp(char *s_str1, char *s_str2)
{
    int i_ctr;

    for (i_ctr = 0; s_str1[i_ctr] != '\0' || s_str2[i_ctr] != '\0';
           i_ctr++)
    {
        if (s_str1[i_ctr] != s_str2[i_ctr])
            return (s_str1[i_ctr]-s_str2[i_ctr]);
    }
    return 0;
}
/* 函数结束 */

/* 主函数开始 */
main()
{
    /* 声明字符数组 */
    char s_str1[25], s_str2[25], c_temp;
    int i_result;

    /* 读取数组中的数据 */
    printf("\nEnter string one : ");
    scanf("%[^\n]",&s_str1);
    c_temp = getchar();

    printf("\nEnter string two : ");
    scanf("%[^\n]",&s_str2);

    i_result = strcmp(s_str1, s_str2);
    if (i_result == 0)
        printf("\nStrings \"%s\" and \"%s\" are same.\n",s_str1,s_str2);
    else
        printf("\nStrings \"%s\" and \"%s\" are not
               same.\n",s_str1,s_str2);
    return;
}/* 主函数结束 */
```

Strings "C Programming" and "C Programming" are same.
