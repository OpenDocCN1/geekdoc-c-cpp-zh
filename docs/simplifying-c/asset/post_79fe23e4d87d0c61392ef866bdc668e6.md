C library has function fputs to write the entire string to a file. The function fgets can be used to read file, one string at a time. The usage of functions fgets and fputs is as easy as functions fgetc and fputc. The syntax of the function fputs is as follows:

```c
fputs(string, file_pointer);
```

The function fputs accepts two parameters. String is the collection of characters to be stored in a file. The file_pointer is a pointer pointing to an opened file in which the string is to be stored.
The syntax of the fgets function is as follows:

```c
fgets(string, max, file_pointer);
```

The function fgets accepts three parameters. The first parameter is address of the string where the characters are to be stored. The second parameter max specifies maximum length of the string. The third parameter is a file pointer. When the function fgets attempts to read a string from a file, it searches for a new line character (\n) followed by a null character (\0). If the null character is found, it is considered as an end of string. Another case to be taken care of by the function fgets is maximum number of characters that can be considered as a string. It is specified as a second parameter. Once maximum limit is reached, another set of characters either ending with \n or max characters will be considered as new string.

Let us write a program to write lines typed by the user in a file and then read the contents of the file and display it on the screen. Program 3 illustrates the use of functions fgets and fputs.

/* Program to illustrate working of the fgets and fputs functions*/
#include<stdio.h>

/* Beginning of main function */
main()

    char str_lines[80];

        printf("%s",str_lines);
    fclose(fp_aboutme);
    printf("\n");
    return;
}
/* End of function main */

### 13.7 Integer and File

Program 2 writes and reads characters from a file. Program 3 writes and reads strings from a file. C library also holds functions to read and write integers to a file. These functions are very useful when we deal with integer data. The general syntax of function putw is as follows:

```c
putw(integer, fp);
```

where the parameter integer is the integer to be written to a file and fp is a file pointer associated with a file in which the integer is to be written.

The general syntax of function getw is as follows:

```c
integer = getw(fp);
```

where fp is a file pointer associated with a file from which the integer is to be fetched. The variable integer is assigned an integer value read from a file by the function getw.
