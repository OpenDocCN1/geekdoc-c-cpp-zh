# Multidimensional array

Most of the data that we use is represented in multiple dimensions. For example, consider the data given in Table 1:

| | English | Math | Science | Drawing |
| :-- | :-- | :-- | :-- | :-- |
| **Table 1: Sample Data** | | | | |
| Roll No. | | | | |
| 1 | 75 | 90 | 40 | 40 |
| 2 | 50 | 60 | 70 | 85 |
| 3 | 80 | 85 | 55 | 60 |

It can be observed in Table 1 that the data shows marks obtained by roll number 1, 2, and 3 in English, Math, Science, and Drawing, respectively. The data here is represented in multiple dimensions as we have three rows and four columns. The data of listed in Table 1 can be easily represented in C using the two-dimensional array. If the marks obtained are assumed to be integer, then the syntax of a multidimensional array can be declared as follows:

```
int i_mark[row size][column size];
```

In the preceding syntax, row size refers to the roll number of student and column size refers to different subjects. Both these values are integer values.
