
## 2.1 Generation of Languages

Computer language has been classified as lower level or machine level, middle level, and higher level language. In the initial days of computer programming, the language used to write a program was machine dependent. A person who wrote a program needed to know the architecture of the machine on which the program would be executed. The programs that were written in initial days had sentences that were framed using sequences of 0 and 1. The programming languages evolved with the evolution of computer hardware. From historical perspective, the programming languages can be categorized into five generations. This section discusses the programming language generations in brief.

### First Generation

The first language used to write a program for computers consisted of strings of only two digits, i.e., 0 and 1. As only two numbers were used, the number system was known as binary number system and the language came to be known as machine language. At times it was also known as lower level language. The programmers required advanced technical skills in order to develop a program using binary numbers. Though programs could be developed, it took extremely long time to design, code, and test the programs.

### Second Generation

An attempt was made to simplify the process of writing the computer programs by creating a language known as assembly language. The statements in the assembly language were framed using symbols and abbreviations. As the programs were written in a user-understandable form, they could not be directly understood by the computer.

A translator called assembler was used to translate an assembly program into machine code required by the computer, and vice versa. Assembly language provided a clear cut advantage by making programming easy as compared to machine language. However, it still suffered from a major disadvantage that it did not run as fast as the machine language program.

### Third Generation

Third-generation programming languages became a boon to the programmers. They provided a more natural means of developing programs by enabling the users to write programs using English language, such as statements of a program. Such programming languages are in use today and are called high-level languages.

One of the third-generation programming languages named COmmon Business Oriented Language (COBOL) became a successful language used for writing business applications across various business domains. C language also falls in the category of third-generation languages; though some authors consider it as a middle-level language. The statement is debatable; however, the discussion on it is out of the scope of this book. We will consider it to be a higher level language.

### Fourth Generation

The usage of second and third-generation languages needs the user to be a technically trained person. The influx of computers in almost every home has resulted in a drive toward even greater ease of use of programming languages. A programming language is so designed that even nontechnical users can develop their own applications. The main focus when using fourth generation language is rapid development of applications. Report generators, query languages, and application generators are examples of the fourth-generation languages.

### Fifth Generation

A fifth-generation programming language is based on the concept of solving problems using constraints given to the program, rather than using an algorithm written by a programmer. It uses the domain of artificial intelligence (AI) to obtain constraint-based solutions. The fifth-generation language can be considered as an attempt to make a computer behave similar to human being behavior. Future development in the area of AI may result in programming system that accepts spoken statements from a user and then generates a computer program intended to produce the required output.

Today, none of the five language generations mentioned earlier has become obsolete. We are using all the five generations of languages at some point of time. The user may feel that the first- and second-generation languages are not used by him/her directly, but it is extensively used indirectly by the user without his/her knowledge. The explanation for the same is given in the end of this chapter.

## 2.2 History of C Language

The origin of C language dates back to 1972. Dennis M. Ritchie is the man who owns the credit of creating the C language. It was derived from the Basic Common Purpose Programming Language, commonly known as BCPL. The aim of developing C language was to build a robust system software. However, it became a pet of the programmers in the coming years, and has been used for developing all kind of software. Hence, it has come to be known as a general-purpose programming language.

Although created in 1972, it was standardized in 1989 by the American National Standard Institute (ANSI). Since then, it came to be known as ANSI C. Vendors such as Apple, Borland, Microsoft, and IBM have built their own versions of C and C compilers based on the ANSI standards. Some of them have even provided an integrated development environment, more commonly known as IDE, for easy and fast development of C programs.

C is a structured language for programming. It allows the program to be split into subprograms known as functions. Once generated, these functions are reusable. Set of such functions then constitutes a C program. The approach of splitting a program into subprogram is known as modular programming. The modular approach of programming helps us to solve problem arising in the design of the program easily, as we have to concentrate on only one function rather than an entire program. Usually, programs written in C language can be ported to different machines having different operating systems and compilers with almost negligible modification. Thus, it is considered to be a portable language.

It is surprising to know that we are surrounded by C programs. Almost all operating systems, such as Windows, Unix, and Linux, have a large blocks of C program codes in them. If you remove the code from these operating systems, possibly the entire operating system may crash. Databases such as Oracle, MySQL, and networking protocols also use C program codes. Though the presence of the C programs is not visible around us, they form a backbone of many applications in Information Technology (IT) industry.

## 2.3 First C Program

Let's now write our first C Program. A C program has a predefined structure and certain set of words that can be used in it. If we do not follow this structure, then we will get errors. Program 1 is an example of a simple C program:

> Program 1

```c
/* My first C program */
#include <stdio.h>
main()
{
    printf("First step towards learning C Language.");
    return;
}
```

Output:

First step towards learning C Language.

The program written in Program 1 is used to print a message "First step towards learning C Language." on the monitor screen. The purpose of each line used in the program is explained in Figure 1:

![](img/5d422ba7108ffdf64376be51eaf0c459_39_0.png)

In Figure 1, the first line is a comment line. A comment line is not included in the executable counterpart of C program. It is used for documentation purpose. The statement `#include <stdio.h>` is an inclusion of a header file. Next, `main()` is known as a user-defined function, while `printf()` is known as an inbuilt or a library function. User-defined functions are the functions that are created by users as per their requirement. The functions already available in C compilers library that a user can make use of in a program are known as inbuilt or library functions. To understand the structure of a C program better, let us have a look at one more C program, i.e., Program 2:

> Program 2

```c
/* Program to calculate circumference of a circle */
#include <stdio.h>
#define PI 3.14          /* Definition of a symbolic constant */
main()
/* Name of user defined function */
{
/* Beginning of function */

float f_radius, f_crF;   /* Declaration of two float variables */
printf("Enter the value of radius: ");   /* Message printing */
scanf("%f", &f_radius);       /* Accepting value of radius from user */
f_crF = 2 * PI * f_radius;   /* Calculation of circumference */
/* Print the value of circumference */
printf("\n Circumference of circle with radius %f is %f \n", f_radius, f_crF);
return;                     /* Exit the function */
                            /* End of function */
}
```

Output:

```
Enter the value of radius: 7
Circumference of circle with radius 7.000000 is 43.959999
```
