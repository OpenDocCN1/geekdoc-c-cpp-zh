
```c
struct node
{
    int i_item;
    struct node *ptr_next;
};
```

Thus, the first node of the list will contain the address of the second node. The second node will contain the address of the third node, and so on. Memory for each node in the linked list will be declared with the function *malloc*. When the node is not required, the memory allocated to it will be released by using the function *free*. Note that each structure may contain multiple data members. Each member can be of different data types. Program 2 illustrates how to create a linked list:

/* Structure definition of link list */
struct linklist

    struct linklist *ptr_next;

typedef struct linklist node;

node * additem(node *ptr_temp);
void updateitem(node *ptr_temp);
void displayitems(node *ptr_temp);

    printf("\n Enter the item which you would like to enter: ");

In Program 2, a structure named `linklist` is defined. It contains two elements. The first element is an item, which is of integer type. The second item is of type pointer to structure. It is declared as member of structure to store the address of the structure, which is again of type `linklist`. Thus, in Program 2, the list created will be a list of integers. The `typedef` statement is used to create a synonym for `struct linklist`. A pointer variable named `head` is declared in the beginning of the program, and it is initially initialized to `NULL`. The `head` pointer is declared to store the address of the first node in the list. The `NULL` value stored in `head` indicates that the list does not contain any node. Three functions are defined in Program 2. Let us understand each of them one by one.

The first function is `additem`. It accepts one argument. The argument is a pointer to a node. When the function `additem` is called, the pointer variable `head`, which contains the starting address of the list, is passed as an argument. In the function `additem`, another pointer variable `ptr_start` of type `node` is declared. The `ptr_start` pointer is used to preserve the starting address of the list in the `additem` function. The function `malloc` is used to allocate memory for each node. When the first item of a list is created, the address returned by the function `malloc` would be the address of the starting element of the list. Therefore, this address is returned back and accepted in the pointer variable `head` in the calling function `main`. To check whether the list is empty or not, the `(tempnode == NULL)` condition is used. If the list is not empty, the pointer variable `tempnode` is advanced by one node at a time using the `tempnode=tempnode->ptr_next;` statement. The list is traversed till the `(tempnode->ptr_next==NULL)` condition is true. This indicates that `tempnode` points to the last node in the list. The function `malloc` is called to allocate memory equal to the size of `node`, and the address of the memory allocated is accepted in `tempnode->ptr_next` (last node) of the list. The new value to be added in the list is added using the `tempnode->i_item=i_n;` statement. The value in `tempnode->ptr_next` is set to `NULL`, indicating that now this node is the last node. The preserved starting address of the list is returned and accepted in the pointer variable `head` in the function `main`. Figure 6 illustrates insertion of a new element in the list:

The second function `displayitems` in the program is defined to traverse and display the items in a list. Similar to the function `additem`, the pointer variable `head`, which contains the address of the starting element of the list, is passed as an argument. It is accepted in the pointer variable `tempnode`. One by one, each node is traversed using a `while` loop, and the items are displayed on the screen. Once a node is traversed, `tempnode` is advanced to the next location with the `tempnode=tempnode->ptr_next;` statement. The loop continues till `tempnode != NULL`. The `tempnode` is set to `NULL` when the `tempnode` points to the last node and the statement `tempnode=tempnode->ptr_next;` is executed.

The list is then traversed till the old item is obtained. The `tempnode` pointer variable that initially contains the address of the start of the list is used.
