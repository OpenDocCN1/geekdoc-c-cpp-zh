# ■ Three-Dimensional Array

The data of the sales analysis mentioned earlier can be stored in an array shown in the following:

```
int i_sales[year][product][salesman];
```

where year refers to the number of years to be considered, product refers to the number of products the company has, and salesman refers to the number of salesman that works in the company. The values in the array elements would then refer to sales done by a salesman for a particular product in a particular year.
