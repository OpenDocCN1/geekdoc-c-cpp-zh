
Note that argc and argv are names of variables; hence, there is no compulsion to use the same names in function definition. For example, int main(int l_num, char *c_vector[]) is also a valid definition.

We have discussed two scopes of variables in this chapter: global and local. The global variables are accessible to all functions, whereas local variables are restricted to functions in which they are defined. C language also provides us with storage class specifiers that define where the variable will be stored and what would be its property. The next section discusses storage class specifiers.

## 8.8 Storage Classes

The C variables are stored in primary memory and Central Processing Unit (CPU) registers. The user can specify the location where he/she wants to store the variable by using the storage class as a prefix at the time of variable declaration. C language provides us with four storage class specifiers, namely, automatic, external, register, and static. Let us now discuss them one by one.

### Automatic Variables

By default, all the variables have storage class as automatic. To explicitly define the class of variable as automatic, we use the keyword auto. The following syntax allows us to define an automatic storage class for a variable:

```
auto data type identifier;
```

For example, the definition auto char c_choice; indicates that the variable c_choice is of type character and its storage class is automatic. The variables whose storage class is defined as auto are created automatically when the function is invoked and destroyed when the function returns the control back to the calling function. The variables are stored in the primary memory and, by default, are assigned a garbage value (value that does not have any significance to the user).

### External Variables

The modular approach of programming at times requires the programmer to share a variable between two functions or programs. The storage class external allows us to share variables between two different functions or programs. It is necessary that the variable should be defined as global variable in at least one program. In other programs, we can access the variable by using the keyword extern. The following syntax allows us to define an external storage class for a variable:

```
extern data type identifier;
```

For example, the definition extern float f_average; indicates that the variable f_average is of type float and its storage class is external. The extern prefixed to the variable conveys the compiler to look for the actual variable definition in some other included program. The default value of the external variable is zero, and they are stored in the primary memory. Once the external variables come into existence, they are available within the program as long as the program runs.

### Register Variables

The counter-controlled loops require a counter variable now and then to check which iteration of loop is being executed. If the counter variables are stored in the primary memory, the access to these variables becomes slow. To have fast access to variables, we can store the variables in the CPU registers. C language provides us a storage class called register for the said purpose. The following syntax allows us to define a register storage class for a variable:

```
register data type identifier;
```

For example, the definition register int i_ctr; indicates that the variable i_ctr is of type integer and its storage class is register. The register class variables are accessible only in the region of the function they are defined in. They exist as long as the function is active. The register class variables are assigned garbage value by default. One has to be cautious while using register class variables, as at times the compiler may convert them to automatic class variables and store them in the primary memory. The reason for this conversion is the limitation of a number of CPU registers.

### Static Variables

All the three storage classes discussed till now create temporary variables in the memory. The static storage class variables when defined are made permanent within a specified region. A static storage class variable is stored permanently in the primary memory and, by default, is assigned value zero. The following syntax allows us to define a static storage class for a variable:

```
static data type identifier;
```

For example, the definition static int i_result; indicates that the variable i_result is of type integer and its storage class is static. If used as local variable of a function, these variables are usable within the functions and preserve their previous values held by them between function calls. Table 4 lists the major properties of the four storage classes discussed in this chapter:

**Table 4: Properties of Storage Class Variables**

| Storage Class | Keyword | Accessibility Range | Existence | Storage Location | Default Value |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Automatic | auto | Accessible within the block it is defined | From the time of function being invoked till completion of function | Primary memory | Garbage |
| External | extern | Accessible within multiple programs | From the time of function being invoked till completion of program | Primary memory | Zero |
| Register | register | Accessible within the block it is defined | From the time of function being invoked till completion of function | CPU register | Garbage |
| Static | static | Accessible within the block it is defined | From the time of function being invoked till completion of function | Primary memory | Zero |

## 8.9 Advantages of Functions

A user can create single function for a program that has code length of 50 lines. However, if the code length of a program goes beyond 50 lines, using only single function may lead to problems. The program may become too large and complex, thus making maintenance of the program problematic. The testing and debugging of a program also becomes difficult. Testing is the process of reviewing and executing a program with the intent of detecting errors. Debugging is the process of isolating and correcting the errors present in the program. The use of functions in programs gives the following advantages:

- Improves the readability of the program.
- Allows us to follow a structured approach of programming.
- Understanding and maintenance of program becomes easy.
- Debugging of problems becomes easy as we need to work on the problematic function only, rather than the entire program source code.
- Functions once written can be used to make a user-defined library, thus allowing the function to be used many times.
