# Practical Exercises

Q1.  Write a program that uses a C function, which will read a string and rewrite it in the alphabetic order. For example, PROGRAM will be printed as AGMOPRR.

Q2.  Write a program that accepts a string from a user. Create a user-defined function that checks if the string is palindrome or not. A string is considered as palindrome if reading the string from front side as well as back side results in the same set of characters. For example, MADAM is palindrome.

Q3.  Write a program that accepts a string and a character from a user. Create a user-defined function that counts number of occurrence of a character within the string.

Q4.  Write a program that accepts a string from a user. Create a user-defined function that will print out all the rotations of the string typed into it. For example, if the string entered is "BITE". The output is BITE ITEB TEBI EBIT.

Q5.  Write a program that accepts two strings from a user. Create a user-defined function that checks whether string 2 is part of string 1 or not. Find out how many times string 2 appears in string 1 and give start address of each occurrence as output.

Q6.  Write a program that accepts a string and a character from a user. Create a user-defined function REMOVE (str, char) to delete all the occurrence of character char within string str. The string should be properly arranged after the removal of character.

Q7.  Write a program that accepts a string and an integer from a user. Create a user-defined function Encrypt (str, num) that encrypts all the characters within string str by adding num to the ASCII value of each character.

Q8.  Write a program to accept a string, a character, and a symbol. Create a user-defined function that replaces that character within a string with a given symbol.

Q9.  Write a program to remove additional blank spaces in a string. If the black spaces are enclosed within double quotes, then it should not be removed.

Q10.  Write a program to accept N city names from a user. Sort this array in descending order of city name. Then ask the user the name of a city. Insert this name at an appropriate place within the list.

Q11.  Write a program to accept N city names from a user. Sort this array in ascending order of city name. Then ask the user the name of a city. Delete this name and rearrange the list.

Q12.  Write a program that accepts city name from a user. Check whether the city name exists in the list of N cities. If the city name exists, then list the position of the city within the list; otherwise, display appropriate message.
