Till now we have seen that structures can be nested, array of structure can be declared, structure variables can be passed as parameter to functions, and functions can return a structure. All the operation that are performed using structure can also be performed using unions. A union can be nested, array of unions can be declared, union variables can be passed as parameter to functions, and functions can return a union. Individual union members can also be passed in a function as a parameter. In addition, structures can be nested within a union and unions can be nested within a structure.

In all the aforementioned programs, it can be seen that once a structure variable is defined, each of its data elements is allocated a fixed memory space. Many times the allocated memory space is too large. For example, to store gender of a contact, we require only a single bit and not a complete byte. C language provided a very good feature called bit fields to overcome the problem of memory space wastage. The next section discusses the usage of bit fields.

# ## 11.11 Bit fields

Bit field refers to the data elements that use only few bits, rather than using the memory in bytes. The bit fields provide the functionality to convey the exact amount of bits required for storage of value to the compiler. Assume that in the structure template of contact defined in the previous programs, we need to add three additional data members, namely, phone status, gender, and marital status. As mentioned earlier, to store gender of a contact, we require only a single bit of storage space in memory. Similarly, to indicate whether a phone number is office phone number or residence phone number, we need only 1 bit of storage space. The marital status of a person can be committed, never married, married, widowed, or divorced. In this case, the value range is 0-4. Hence, a maximum 3 bits are required to store the data regarding marital status.
