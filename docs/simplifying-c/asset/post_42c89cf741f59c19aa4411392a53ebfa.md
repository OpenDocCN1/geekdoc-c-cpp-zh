In C language, six types of tokens have been identified, namely, keyword, identifier, constant, string, operator, and special character. ### Identifier

A user is allowed to create a word of his own by making use of C character set: such a word is known as an *identifier*. A language has its own rule for defining an identifier. It consists of a set of letters, digits, and some special characters. Examples of identifiers are totalcost, RATE, float, and add(). Here, totalcost and RATE are names of a variable, add() is the name of a function, and float is a predefined keyword. Before continuing our discussion further, let us first understand the meaning of the term variable.

### Variable Name

To generate an output, C program accepts data from the user. To store data in a computer, memory space is used. The data within this memory space can change based on the operations performed on it. The name used to identify the data is known as variable name. The data that is capable of changing itself is called a variable. The term variable and variable name is used interchangeably. C language follows the following rules to define a variable name.

- 1. The variable names are case sensitive; hence, cost, cosT, c0St, c0St, Cost, and COST are considered as different variable names.
- 2. Names of keywords cannot be used as variable. However, keywords in all capital letters can become a valid variable name as int is different from INT.
- 3. Variable name can consist of letter, digit, and special character. In C, underscore ( _ ) is the only special character allowed in variable names.
- 4. Letter or underscore can be the first character of a variable name in C.
- 5. The maximum length of variable name as per the ANSI standards is 31 characters, although it is dependent on the compiler.

### Numeric Constant

Numeric constants have the capacity to store numeric value. They are further divided in two categories: integer constants and real constants.

### Integer Constant

Integer constant refers to a whole number. C language supports three types of integer constants, namely, decimal, hexadecimal, and octal.

The decimal constant is formed by the combination of digits 0 to 9. It is also possible to prefix unary plus or minus to decimal constants.

The hexadecimal constant is formed by the combination of digits 0 to 9 and letters A to F. The letters A to F refer to decimal values 10 to 15, respectively. The hexadecimal numbers have base 16. It is differentiated from the decimal numbers by using 0x or 0X as prefix in C Language.

The octal constant is formed by the combination of digits 0 to 7. The base of this number system is 8. It is differentiated from the decimal numbers by using o or O as prefix in C language. A list of some valid and invalid integer constants as per C Language rules are listed in Table 6.
