# **Practical Exercises**

+   Q1. Write a program that uses function digit (N, k) that returns the value of the kth digit from the right of the number N. For example, the function call digit (254693, 2) should return 9. Similarly, the function call digit (7622, 6) = 0.

+   Q2. Write a program that uses a function to check whether an entered three digit number is palindrome or not. A number would be considered as palindrome if the reverse of a number is equal to the actual number.

+   Q3. Write a program that uses a function called binary that converts a decimal number to its binary equivalent.

+   Q4. Write a program that uses a function called octal that converts a decimal number to its octal equivalent.

+   Q5. Write a program that uses a function called decimal that converts a hexadecimal number to its decimal equivalent.

+   Q6. Write a program that contains two C functions, namely, function upow(x) and fact(n). Using this functions, evaluate the sum of the series 1 + x + x^2/2! + x^3/3! + x^4/4! + ... + x^n/n!.

+   Q7. Write a program that uses recursive function fibo that generates a Fibonacci series containing N elements.
