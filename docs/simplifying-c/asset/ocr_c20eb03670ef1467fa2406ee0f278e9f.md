As the entire block is referred by the name *Marks*, the C compiler needs a mechanism to identify individual elements within this block. To identify each element in the block, index value is used. The index value in C language starts from zero. The elements of the array Marks are thus identified as Marks[0], Marks[1], Marks[2], Marks[3], Marks[4], Marks[5], and Marks[6]. Each of these elements independently works as a single variable. All the operations that can be performed on normal variables can also be performed on array elements.
