# ■ **Pointer**

An identifier when defined is associated with three entities, namely, an address in memory, the size of memory to be allocated, and a value. As C language was designed to build system software, it provides inbuilt features using which a user can directly interact with the physical memory of the computer. In this section, we will discuss in brief about a concept called *pointer*.

A *pointer* is a special variable that can be defined in C language. The variable is considered to be special here because the value in the variable always refers to a memory address. The syntax to define a pointer variable is as follows:

```
```
				data type *identifier name;
```
```

In the preceding syntax, the identifier name is a normal variable name and follows all the rules applicable for defining an identifier. The \* indicates that the variable defined is a *pointer*. The data type here indicates that the address stored in the pointer variable will be a point to the given data type.
