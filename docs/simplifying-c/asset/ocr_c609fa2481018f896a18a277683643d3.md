# 11.10 Union

A union is a collection of related data elements of different data types similar to a structure. However, unions differ from structure in terms of memory allocated to its data element. As mentioned earlier, structure variable allocates individual memory space to each of its data elements. Union, on the other hand, allocates only one memory space. This memory space allocated is equal to the size of the highest memory space required by a data element. Thus, the members that compose a union share the same storage area within the memory. The difference between memory area allocated to a union and a structure can be seen in Figures 9 and 10, respectively:

It can be observed in Figures 9 and 10 that for a structure, the size in bytes is the sum total of size of all the elements in the structure plus the padding bytes. In case of a union, the size of union in bytes is equal to the size of the largest variable element in the union. The union variable thus stores information in one field at a time. The data elements of the union share the memory area. Hence, at any given moment of time, the value of only one data element can be preserved in the memory.
