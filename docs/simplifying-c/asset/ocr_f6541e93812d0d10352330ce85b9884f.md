# ### 2.6 Words in a C Language

The characters given in Table 3 are used to form words in C language. These words are then used to form sentence known as C statement. A set of such logically sequential C statements form a C program. A word in C is known as a token of C. Each character discussed in Table 3 is itself a token. In C language, six types of tokens have been identified, namely, keyword, identifier, constant, string, operator, and special character.
