# 13.2 Files and Streams

A stream is a sequence of elements, which may be characters or digits. As discussed in Chapter 4, C program treats input and output as streams. In other words, the data input from the keyboard and displayed on display terminal are streams of characters or digits. Thus, the programmer does not have to worry about the different ways of sending and receiving data to various devices. The reason is that in all cases, it is the same type of stream that is send and received. Data send to and received from files are also streams. The only thing the user has to worry about is specifying pointer to a file to be accessed.

To declare pointer to a file, FILE structure type is used. It is a structure defined in a stdio.h header file. The syntax to define pointer to file is as follows:

```
FILE \*fp;
```

In the preceding syntax, note that FILE is typed in upper case. The asterisk precedes the identifier name, indicating that the identifier is a pointer. The identifier *fp* here points to a file as it is declared to be of type FILE. Assuming that the programmer aims to work with file named contacts, the file pointer declaration can be as follows:

```
FILE \*fp_contacts;
```

The name of the identifier is chosen to be *fp_contacts* to increase the readability of a program. It suggests that the file pointer is pointing to the file named contacts. The prefix *fp* stands for file pointer.

When a C program is executed, the following three streams are automatically opened:

+   Standard input connected to standard input device keyboard

+   Standard output connected to standard output device display terminal (monitor)

+   Standard error connected to the display terminal (monitor)

These three files are referenced using standard predefined identifiers of the FILE type. The standard input file is referenced using file pointer *stdin*. The standard output file is referenced using file pointer *stdout*. The standard error file is referenced using file pointer *stderr*.

C library functions, such as *printf*, *putc*, and *putchar*, use the *stdout* file pointer to display output. Library functions, such as *scanf*, *getc*, and *getchar*, use the *stdin* file pointer to accept input from the keyboard. These library functions consider *stdin* and *stdout* as default arguments. Thus, the programmers do not need to worry about their declarations. However, to work with user files, the programmer has to explicitly declare a file pointer and an associate file pointer with the file he/she desires to work with. Once a file pointer is declared and associated with a file, various operations can be performed on the file.
