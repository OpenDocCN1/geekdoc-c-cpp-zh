The heap, as mentioned in Chapter 8, is used for dynamic memory allocation. The size of heap keeps changing when the program is executed and memory is allocated to the variables. The size of the heap shrinks when the memory is allocated to the variables and increases when the memory is freed by a programmer. At times the entire heap area may be allocated and no further allocation of memory can be done. In such situation, the memory allocation function will return a NULL pointer.
