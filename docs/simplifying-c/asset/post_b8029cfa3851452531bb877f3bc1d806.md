From the earlier discussion, it can be seen that a structure becomes a very useful entity to group related elements under one name. C language provides another such construct called union to group related elements. The next section discusses the concept of unions.

## 11.10 Union

A union is a collection of related data elements of different data types similar to a structure. However, unions differ from structure in terms of memory allocated to its data element. As mentioned earlier, structure variable allocates individual memory space to each of its data elements. Union, on the other hand, allocates only one memory space. This memory space allocated is equal to the size of the highest memory space required by a data element. Thus, the members that compose a union share the same storage area within the memory. The difference between memory area allocated to a union and a structure can be seen in Figures 9 and 10, respectively:

![](img/5d422ba7108ffdf64376be51eaf0c459_250_1.png)

It can be observed in Figures 9 and 10 that for a structure, the size in bytes is the sum total of size of all the elements in the structure plus the padding bytes. In case of a union, the size of union in bytes is equal to the size of the largest variable element in the union. The union variable thus stores information in one field at a time. The data elements of the union share the memory area. Hence, at any given moment of time, the value of only one data element can be preserved in the memory. For example, if we had three data elements in a union, then the values of each of them is entered one by one. The value of only the third data element will be available at the output. Unions are normally used in situations when the value needs to be assigned to only one member at any given moment.

The syntax of defining a union is similar to the one used for defining a structure. The union members can also be accessed using the dot operator similar to the structure members. Program 9 illustrates the use of union:

## Program 9

```c
/* Program to illustrate difference between structure and union*/

#include<stdio.h>
/* Beginning of main function */
main()
{
/* Declaration of Union */
union contact
{
	char c_name[25];
	char c_email[30];
};

typedef union contact Contact;
/* Declaration of union variables */
Contact contact1, contact2;

/* Initialize union members */
printf("Enter the information:\n");
printf("\n Enter name: ");
scanf("%[^\n]",contact1.c_name);
printf("\n Enter e-mail address:");
scanf(" %s",contact1.c_email);
printf("\nEnter the information:\n\n");

printf(" Enter name: ");
scanf(" %[^\n]", contact2.c_name);
printf("\n Enter e-mail address:");
scanf(" %s", contact2.c_email);

printf("\nThe information of contacts recently entered.\n");
printf("Contact information\n");
printf(" Name : %s\n",contact1.c_name); /* Displaying structure member value */
printf(" Email address : %s\n", contact1.c_email);
printf("Contact information\n");
printf(" Name : %s\n", contact2.c_name);
printf(" Email address : %s\n", contact2.c_email);
return;
}
/* End of function main */
```

Till now we have seen that structures can be nested, array of structure can be declared, structure variables can be passed as parameter to functions, and functions can return a structure. All the operation that are performed using structure can also be performed using unions. A union can be nested, array of unions can be declared, union variables can be passed as parameter to functions, and functions can return a union. Individual union members can also be passed in a function as a parameter. In addition, structures can be nested within a union and unions can be nested within a structure.

In all the aforementioned programs, it can be seen that once a structure variable is defined, each of its data elements is allocated a fixed memory space. Many times the allocated memory space is too large. For example, to store gender of a contact, we require only a single bit and not a complete byte. C language provided a very good feature called bit fields to overcome the problem of memory space wastage. The next section discusses the usage of bit fields.

## 11.11 Bit fields

Bit field refers to the data elements that use only few bits, rather than using the memory in bytes. The bit fields provide the functionality to convey the exact amount of bits required for storage of value to the compiler. Assume that in the structure template of contact defined in the previous programs, we need to add three additional data members, namely, phone status, gender, and marital status. As mentioned earlier, to store gender of a contact, we require only a single bit of storage space in memory. Similarly, to indicate whether a phone number is office phone number or residence phone number, we need only 1 bit of storage space. The marital status of a person can be committed, never married, married, widowed, or divorced. In this case, the value range is 0-4. Hence, a maximum 3 bits are required to store the data regarding marital status.
