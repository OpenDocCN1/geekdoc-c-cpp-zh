/* Program to illustrate the use of different int formats */
#include <stdio.h>
/* Beginning of main function */
main( )
{
    /* Declare variables */
    int i_number;
    /* Accept the value */
    printf("\nEnter the value of number : ");
    scanf("%d", &i_number);
    /* Print value in different formats */
    printf("%d\n", i_number);
    printf("%06d\n", i_number);
    printf("%6d\n", i_number);
    printf("%-3d\n", i_number);
    return;
}

In Program 8, the value of number is 99. The digits thus have a length of 2. If *width* is more than 2, then the value 99 will be printed right justified using six positions, as can be seen in the third and fourth lines of the output. It can also be observed that %d as such does not specify any width value; by default, the value considered here is 1. This shows that in case *width* is less than the actual digits to be displayed, the entire digit will be shown as it is, but may seem to be left justified, as can be seen in the second and fifth lines of the output.
