To perform bitwise AND, OR, Exclusive OR (XOR), left shift, and right shift operations, we require two operands. The NOT operation, on the other hand, only requires one operand. The value that the operands can hold is either 0 or 1. Table 6 lists the result of some bitwise operations done on two operands A and B:

**Table 6: Truth Table for Bitwise Operations**

| A | B | ~A | ~B | A & B | A \| B | A ^ B |
|---|---|---|---|---|---|---|
| 0 | 0 | 1 | 1 | 0 | 0 | 0 |
| 0 | 1 | 1 | 0 | 0 | 1 | 1 |
| 1 | 0 | 0 | 1 | 0 | 1 | 1 |
| 1 | 1 | 0 | 0 | 1 | 1 | 0 |

```c
/* Program to illustrate the use of bitwise operators */
#include <stdio.h>
/* Beginning of main function */
main() {
/* Declaration of three integer variables */
unsigned int u_first, u_second, u_result;

/* Accept values of variables */
printf("\nEnter value of first: ");
scanf("%u", &u_first);
printf("\nEnter value of second: ");
scanf("%u", &u_second);

/* Bitwise operation */
u_result = u_first & u_second;
printf("\nResult of AND operation is %d", u_result);

u_result = u_first | u_second;
printf("\nResult of OR operation is %d", u_result);

u_result = u_first ^ u_second;
printf("\nResult of XOR operation is %d", u_result);

u_result = u_first << 1;
printf("\nResult of Left shift operation is %d", u_result);

u_result = u_second >> 2;
printf("\nResult of Right shift operation is %d", u_result);

u_result=~u_first;
printf("\nResult of NOT operation is %d\n", u_result);
return;
}
/* End of function main */
