Let us write another C program that calculates the sum of elements of an array using pointers. Program 6 illustrates calculation of the sum of elements of an array using pointers.

# Program 6

```
/* Program to calculate the sum of elements of an array using pointer arithmetic */
#include<stdio.h>
/* Beginning of function main */
main()
{
/* Declare variables */
int i_ctr,i_arr[5]={10,14,12,35,67}; i_sum=0;
/* For-loop to calculate sum of array elements*/
for (i_ctr=0; i_ctr<=4; i_ctr++)
{
i_sum=i_sum + *(i_arr + i_ctr);
}
printf("The sum of elements of an array is %d\n",i_sum);
return;
}
```
