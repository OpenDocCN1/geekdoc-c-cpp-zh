## Function with Parameter and No Return Value

Functions that accept an input parameter from the calling function but do not return a value to the calling function are known as function with parameter and no return value. Here, there is one-way data transfer from the calling function to the called function. Program 5 illustrates a function that accepts parameter but does not return a value:

### Program 5

```c
/* Program to illustrate the use of a function that takes parameter but does not return value */
/* Program prints the Fibonacci series 0 1 1 2 3 .... */

#include <stdio.h>

/* Beginning of function fibonacci */
void fibonacci(int i_number)
{
    /* Declare local variables */
    int i_fibo1 = 0, i_fibo2 = 1, i_fibo3;
    /* Beginning of switch */
    switch(i_number)
    {
        case 1:
            printf("\n%d  ", i_fibo1);
            break;
        default:
            printf("\n%d  %d  ", i_fibo1, i_fibo2);
            while(i_number > 2)
            {
                /* generate new term */
                i_fibo3 = i_fibo1 + i_fibo2 ;

                /* swap values */
                i_fibo1 = i_fibo2;
                i_fibo2 = i_fibo3;

                /* print fibonacci number */
                printf("%d  ", i_fibo3 );

                i_number--;
            }
    }
    /* End of switch */
}
/* End of function fibonacci */

/* Beginning of function main */
main()
{
    /* Declare local variables */
    int i_number;

    /* Accept value from user */
    printf("\nEnter number of elements required in fibonacci series : ");
    scanf("%d", &i_number);

    /* Check if value entered is positive */
    if(i_number > 0)
        fibonacci(i_number);
    else
        printf("Enter a positive number.\n");
        return;
}
/* End of function main */
```

## 8.5 Parameter Passing in Function

It can be seen in Programs 4 and 5 that both these programs accept parameters from the function main. These parameters have data types such as int, float, char, struct, and union. It is also possible that a parameter of a function can be a function call. The actual content that is passed to the called function can be a value of a variable or an address of a variable. Depending on what content is passed, we have two parameter passing mechanisms in C language, namely, pass by value and pass by address. The next subsection discusses the pass-by-value mechanism of parameter passing.

### Pass-by-Value Mechanism

If the calling function passes the value of the variable as content to the called function, then it is said to have used the concept of pass by value. When the calling function passes a value of a variable to the called function, the compiler assigns the value passed to an appropriate local variable of the called function. Once this assignment operation is done, the original values of the parameters in the calling function are blocked and cannot be modified till the function call processing is over. All the operations are then performed using the local variable of the called function. As the pass-by-value technique protects the data of variable in the calling function, it is a preferred way of parameter passing. Programs 4 and 5 have used the pass-by-value technique for passing parameters. The next subsection discusses about pass-by-address technique of parameter passing.

### Pass-by-Address Mechanism

At times it becomes necessary to pass the reference of the variable in the calling function to the called function. Passing reference establishes a direct link between the actual parameters and the corresponding formal parameters. When the called function changes the value of the formal parameter, this change actually modifies the value of the actual parameter. Programming language such as C++ calls this technique as pass by reference. C language does not actually support direct pass by reference. In C language, to pass the reference, we actually pass the address of the variable. This technique of passing the address of a variable to the called function by the calling function is called pass by address. Pass-by-address technique uses the concepts of pointers learned in Chapter 3. Program 6 illustrates the use of pass-by-address technique.
