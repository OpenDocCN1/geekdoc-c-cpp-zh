It can be observed in Figure 1 that the preprocessor inserts the entire code of file stdio.h in the program in which the preprocessor directive is defined. Normally, the files included are either header files with .h extension or C files with .c extension. We may include any text file in a C program without worrying about the extension. The text file included should contain statements that adhere to C syntax. C language provides a huge collection of header files in the C library. Functions and declarations available in these header files can be readily used by programmers.

The preprocessor, when it finds #include directive with a header file name, first locates the header file. Then it inserts the contents of the header file in C program. Note that we have used less than ($<$) and greater than ($>$) symbols to enclose the file name. These symbols direct the preprocessor to locate the header file from within the system library. Another form of using the same directive is to enclose the file name between double quotation (“”). The syntax for enclosing the file name between double quotations is as follows:

```
   #include “file name”
```

For example, #include “factorial.c” includes a user-created file named factorial.c in the current C program. As the file name is enclosed within double quotes (“”), the preprocessor looks for the file in the folder that contains the source code. Normally, it tries to look into the current folder. This preprocessor directive helps to create personal C library. The reason for creating a personal library is to reuse the code once it has been written. For example, the function to calculate the factorial of a number can be used for many different purposes. We can define the function in one C program. Let us name the program as prog15_1.c. Later, prog15_1.c can be included in another C program using the #include directive. The factorial function then can be used as if it is defined in the same program. Let us create these programs to understand the need and working of file inclusion directive.
