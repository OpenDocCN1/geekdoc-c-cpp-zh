It can be seen in Figure 9 that once the call to function fibonacci is made within the function main, the flow of execution sequence is altered. The execution control from the point of function call jumps to the starting address of the function fibonacci. Here, along with the control transfer, the compiler also sends the value of variable i_number to the function fibonacci. This value is then assigned to the local variables i_number of the function fibonacci. Then the statements within the function fibonacci are executed. Once the function fibonacci's execution is completed, the execution control flow is transferred back to the statement that made function call within the function main. The statements within the function main are then again executed in sequence.
