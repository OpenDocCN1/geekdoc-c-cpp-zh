# **Variable Name**

To generate an output, C program accepts data from the user. To store data in a computer, memory space is used. The data within this memory space can change based on the operations performed on it. The name used to identify the data is known as variable name. The data that is capable of changing itself is called a variable. The term variable and variable name is used interchangeably. C language follows the following rules to define a variable name.

+   1. The variable names are case sensitive; hence, cost, cosT, c0St, c0St, Cost, and COST are considered as different variable names.
2. Names of keywords cannot be used as variable. However, keywords in all capital letters can become a valid variable name as int is different from INT.
3. Variable name can consist of letter, digit, and special character. In C, underscore ( _ ) is the only special character allowed in variable names.
4. Letter or underscore can be the first character of a variable name in C.
5. The maximum length of variable name as per the ANSI standards is 31 characters, although it is dependent on the compiler.

Table 5 list the example of some valid and invalid variables names of C:

**Table 5: Example of Valid and Invalid Variable Names**
| Variable name | Valid | Reason |
| --- | --- | --- |
| Float | Yes | Float is not same as keyword float |
| FLAG | Yes | Capital letters are part of C character set |
| total_cost | Yes | Underscore and characters are allowed |
| age35 | Yes | First letter is character, rest can be digits or underscore |
| _percent | Yes | First letter can be underscore |
| _2square | Yes | First letter can be underscore |
| _char | Yes | Not same as keyword char |
| char | No | Use of keyword not allowed |
| Total marks | No | Blank space not allowed |
| total&items | No | Special character & not allowed |
| 5marks | No | First character has to be letter or underscore |
| _filename. | No | Period not allowed |
| *node | No | First character has to be letter or underscore |
