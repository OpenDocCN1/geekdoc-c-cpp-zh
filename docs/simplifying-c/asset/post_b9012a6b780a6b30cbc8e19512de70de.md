## 2.4 Structure of a C program

From Program 1 and 2, we can say that a C program is a collection of blocks called functions. A function is made up of one or more statements used for performing a predefined task. Figure 2 shows a complete structure of a C program:

### Documentation Section

Documentation section is an optional section in the structure of a C program. As the name indicates, it is used for the purpose of documentation and normally includes details such as purpose of program, author details, important logical aspects, and date of creation. The statements within this section are called comment lines in C. C program uses an opening (/*) and closing (*/) tokens to represent a comment. Whenever the text is enclosed between /* and */, it is considered as a comment in C. Comments are not processed by C compiler and are left as they are.

Comments in C program can be added anywhere in a program. It is always a good practice to use comments within the functions as it improves the readability and understanding of the program. A comment in C can be a single-line comment or a multiple-line comment. Few examples of comments are listed in Table 2.

**Table 2: Example of Comments in C**

| Comment Example |
|---|
| `/* A comment line in C program */` |
| `/* A comment line in`<br>`two lines */` |
| `/* A comment`<br>`line that`<br>`is written`<br>`in more`<br>`than two line */` |
| `// Single line comment` |

As can be seen in Table 2, C language provides one more set of tokens (//) to add a single line comment. A C statement that is preceded by // is considered to be comment line by C compiler and is not processed. The // characters cannot be used to write a comment that spans beyond single line. If the comment exceeds single line then we will have to enclose it between /* and */, alternatively we can also prefix each line by //.

### Symbolic Constant Definition

A symbolic constant refers to a short name given to either a set of characters or a numeric value in a C program. A symbolic constant PI has been used in Program 2. A preprocessor directive #define is used to define any symbolic constant. It instructs the compiler to replace all occurrences of symbolic constants with the values specified against it. The symbolic constants are usually defined using capital letters to differentiate them from variables used in C programs. Two examples of the symbolic constants are as follows:

```c
#define PI 3.14
#define P printf
```

The first example defines a symbolic constant PI for 3.14, while the second example defines a symbolic constant P for printf. Here, PI and P are referred to as symbol and constant as the value of 3.14 and printf will not change throughout the execution of C Program.

### File Include Section

C program provides a huge list of inbuilt or library functions. Some examples of such inbuilt functions are scanf, pow, and sqrt. These functions have a predefined purpose, for example, function scanf is used to read data from the keyboard, function pow is used for calculating value of x raised to a given power, and function sqrt is used to find square root of a given number. We can use these functions in our program if needed. To use these functions in a program, we need to include files that hold information about these functions. In C, these files are known as header files and usually have a file extension .h. The syntax to include header files in our program is `#include <filename.h>`. The list of header files available in C and their use is given in Appendix I of this book.

### Global Variable Declaration Section

The use of C variables is governed by the place of their declaration. The function in which the variables are declared becomes the scope of the variable, which is decided by using opening and closing curly braces { }. The variables defined within curly braces are known as local variables. For example, the variables f_radius and f_crf used in Program 2 are local variables of the function main. These variables cannot be used outside the scope. At times we need to use a variable in all the functions, such a variable is known as global variable. This variable is defined before defining all the functions. The detailed discussion of global variables will be done in chapter dealing with functions in C language.

### Main Function

All C programs contain one function with the name main( ). This is the function from where the execution of any C program starts. The control is first transferred to this function, and from here, the rest of the operations are carried out. In Programs 1 and 2, the core logic of solving the problem is part of the function main. It is possible that the core logic may be defined as a separate function and the function main uses it for solving the problem.

### User-Defined Function

C program provides us a facility of splitting a single program into set of small functions. These functions can then be used independently in a program. In this subsection, we will see how two functions can be used in a single program.

The structure of the C program shown in Figure 2 is not a standard, although used by almost all programmers. It is also possible to interchange the place of sections within a C program. For example, user-defined function section can be interchanged with the main program section, and vice versa. Programs 3 and 4 give an example of such changes:

### Program 3

```c
/* Program to multiply two numbers */

#include <stdio.h>

/* Prototype of a function multiply */
int multiply(int, int);

/* Beginning of main function */
main ( )
{
 int i_first, i_second, i_multiple;
 printf("Enter the value of first number: ");
 scanf("%d", &i_first);
 printf("Enter the value of second number: ");
 scanf("%d", &i_second);
 i_multiply = multiply(i_first, i_second);
 printf("\n The value of %d * %d is %d \n",i_first, i_second,
i_multiply);
return;
}
/* End of function main */

/* Beginning of user-defined functions multiply */
int multiply (int i_first, int i_second)     /* Name of user defined
 function */
{
                              /* Beginning of function */
 int i_result;               /* Integer variable to be used in function */
 i_result = i_first * i_second;/* Multiplication of two numbers */
return(i_result);           /* Return the value of multiplication to main( ) */
}
/* End of function multiply */
```

**Output:**
Enter the value of first number: 35
Enter the value of second number: 73
The value of 35 * 73 is 2555

Program 3 is used to calculate the multiplication of two given numbers. Although small, this program has been divided it into two functions. The first function main accepts the values to be multiplied, and the second function multiply performs the actual multiplication.

The program starts with the comment statement that declares the purpose of a program. We then include the required header files. The next statement is known as prototype statement. It is needed in C if a user-defined function is written after the function main. The main function declares three integer variables, and asks the user to give the values of two of them. These values are then passed to the function multiply by using the statement i_multiply = multiply(i_first, i_second), where i_first and i_second are known as parameters of the function multiply. After encountering this statement, the control is transferred to the function multiply. This function then multiplies the value and stores it in i_result. The value of i_result is then returned back to the statement in main function and assigned to i_multiply. Finally, the main function prints the value of multiplication and exits from the program.
