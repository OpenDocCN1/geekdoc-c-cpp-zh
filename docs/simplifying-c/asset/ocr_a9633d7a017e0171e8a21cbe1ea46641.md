In Program 5, it is observed that we have used the statement for( ; ; ) that does not contain any expression. As no expression is specified, there is no loop control variable, rather the loop is controlled by an event. The event here refers to a number 0 entered by the user. As the loop is controlled by event, this loop becomes an event-controlled loop. All the for loops used in programs preceding Program 5 were counter controlled.

It can be observed in Output 1 that the loop stops after the sixth iteration; in Output 2, it stops after the fifth iteration; and in Output 3, it stops after the first iteration itself. Note that in Output 2, even though we have entered four values, the total of both odd and even numbers is still 3. The negative number entered in Output 2 was not considered in calculation due the initial condition if(i_num >= 0).

One has to be cautious about deciding the terminating condition while using the for loop as an event-controlled loop. In the case of Program 5, the loop terminates only when the user enters a number 0. When the user enter 0, the compiler evaluates the condition if(i_num >= 0) to true, then the condition if(!i_num) is evaluated to false; hence, the control gets transferred to the statement else break;. The break statement terminates the loop. If the user does not write a break statement, the loop will go in an infinite sequence.
