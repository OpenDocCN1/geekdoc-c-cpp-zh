# ## 11.4 Size of Structure Variables

The size of memory allocated to a structure is equal to the sum of the sizes of all the data members it holds. Program 1 illustrates the declaration of structure template, structure variables, and printing memory occupied by a structure type variable:

```
► Program 1

```
/* Program illustrating the size of structure */
#include<stdio.h>
/* Beginning of main function */
main()
{
  /* Declaration of Structure */
  struct contact
  {
    char c_name[25];
    unsigned long int li_phoneno;
    char c_email[30];
  };
  /* Display size of structure contact */
  printf("The size of structure contact is %d\n", sizeof(struct contact));
  return;
}
/* End of function main */
```
```

**Output:**
```
The size of structure contact is 64
```

It can be observed in Program 1 that the output of the program is 64 bytes and not 59 bytes, as expected. The compiler when allocating memory to the structure variable adds additional bytes, if needed, to align all the addresses of the data members according to the largest sized data member. This is the reason we get the size as 64 bytes instead of 59 bytes.

Let us try to understand this concept more clearly. In case of the template contact, the char data type occupies 1 byte, while the unsigned long int occupies 4 bytes. The larger size out of the two is 4 bytes. Therefore, the compiler will align all the variable addresses in the multiple of 4. The first variable c_name will thus occupy 28 (25 + 3) bytes, the unsigned long int will occupy 4 bytes, and the c_email will occupy 32 (30 + 2) bytes. The compiler has added 3 + 2 = 5 bytes extra to align all the structure members evenly, as shown in Figure 4:
