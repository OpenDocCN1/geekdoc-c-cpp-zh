In Program 2, we have defined the array to be of size 25. When the data is entered, we have used only five out of these. This is the normal case in most of the application. In addition, C compiler does not check the bounds of array. The bounds need to be handled by the programmer. For example, if the programmer defines an array of size 5 and the user reads 10 values in it, the compiler in this case will generate error only for compile time initialization. However, for runtime initialization, it will not generate any error. The user needs to be careful in such scenario as the reading of extra elements might overwrite a legitimate variable of program.
