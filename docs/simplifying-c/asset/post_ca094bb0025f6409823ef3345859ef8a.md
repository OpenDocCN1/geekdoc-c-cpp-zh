### The Function Prototype

C language does not allow us to use any identifier before it has been declared. The declaration of an identifier has two scopes, namely, global and local. If an identifier is declared above all the functions used in the C program, then the identifier can be used and modified within all the functions below. Such an identifier is said to have a global scope. Similarly, an identifier may have a scope that is limited to a function. In such a case, the identifier can only be used and modified within the function that it is declared.

A function prototype is an indication to the C compiler that a function with the specified parameter can be referenced in the main function or any other function, before being defined in the program. In most of the cases, the executable statements of the function whose prototype is defined are written after the completion of the main function. For example, the declaration `float add(float, float);` refers to a function called add. The function add takes two float parameters as input and return one float parameter as an output. Almost all the header files available in C language library contain the prototype of the readily available C functions.

Note that if the function executable statements are defined before they are accessed, then we do not need a prototype statement for such functions.

### The Caller Function and Called Function

A function once defined can be used as a normal executable statement within the C program. In Figure 2, we have defined two functions, namely, main and add. Here, the function add is used in the function main, hence the function main is referred to as a caller function, while function add is referred to as a called function.

When a function is called, the execution sequence control is transferred to the called function. After the execution of the called function, the execution sequence control is transferred back to the caller function.

### The Actual Parameter and Formal Parameter

The parameters, sometimes called arguments, that are used at the time of function call are referred to as actual parameters. When the function call is made along with the execution sequence control, the compiler also sends the value of the actual parameter to the called function. The identifiers in the called function that is assigned the value of actual parameters are known as formal parameters. Both actual parameter and formal parameter can have the same name, as they are local to the function in which they are used. In Figure 2, the statement `result = add(num1, num2);` is a function call, and num1 and num2 are the actual parameters. The float identifiers num1 and num2 defined in the function add are formal parameters.

Note that there has to be one-to-one mapping between the actual and formal parameters. Any mismatch will lead to a compilation error of the program. The next section discusses about the different types of functions available in C language.

## 8.3 | Categories of C Function

C language supports huge collection of functions to implement many features of the language. For example, all Input/Output (I/O) operations are handled using C functions such as scanf, printf, and so on. C language categorizes function into two categories, namely, inbuilt functions and user-defined functions. The next section discusses about inbuilt C function.

### Inbuilt C Functions

The functions that are predefined and already available in compiled form in a C library are known as inbuilt C functions, generally referred to as library functions. Some examples of inbuilt C functions are scanf, printf, sqrt, isupper, and strcmp. To use the inbuilt C functions, we have to include the header file that contains the prototype of the function. Appendix I at the end of this book lists the header files and the functions available in them.

### User-Defined Function

Other than the functions available is C library, the users also need to create functions of their own. The functions created by the users for their individual usage are known as user-defined functions. The function main is the compulsory user-defined function required in all executable C programs. The general syntax for declaring a C function is as follows:

```text
data type  function name([data type parameter 1, ..., data type parameter n])
{
    declaration Statement
    Executable Statements
}
```

In the preceding syntax, each user-defined function is identified by its name. The naming convention of the function is similar to that of a variable in C language. The only difference is that in functions, a parenthesis set is suffixed after the name. The function also has a data type; the data type here refers to the type of data the function will return back to the caller function. If the function only returns control but no value, then the data type is defined as void. The parameters are optional, but in case they are present, they refer to the input that will be accepted by the function. Each parameter has its own data type. These parameters are known as formal parameters, and are local to the function and do not exists outside the function. The declaration statement refers to the definition of variables used in the function. The executable statements are the ones that will be executed once a call to a function is made. Program 1 illustrates a C program that uses function to find the factorial of a given positive number:

**Program 1**

```c
/* Program to illustrate user-defined function */
/* Prototype of function factorial */
/* It takes an integer-value as input */
/* Returns a long integer value as output */
long factorial(int);
#include <stdio.h>
/* Beginning of main function */
main()
{
    /* Declare variable */
    int i_number;
    long l_result;
    /* Input Data */
    printf("Enter a number : ");
    scanf("%d", &i_number);
    /* Check if number is greater than 0 */
    if(i_number > 0)
    {
        /* Call function factorial */
        l_result = factorial(i_number);
        /* Print the value of factorial */
        printf("Factorial of %d is %ld\n", i_number, l_result);
    }
    else
        printf("The number entered is zero or negative\n");
    return;
}
/* End of function main */
/* Function to calculate factorial of a positive number greater than 0 */
long factorial(int i_number)
{
    long l_result=1;
    int i_ctr;
    for(i_ctr= 1; i_ctr <= i_number; i_ctr++)
    {
        l_result = l_result * i_ctr;
    }
    return(l_result);
}
/* End of function factorial */
```

**Output 1:**

```text
Enter a number: 5
Factorial of 5 is 120
```

**Output 2:**

```text
Enter a number: -10
The number entered is zero or negative
```

It can be seen in Program 1 that we have defined a function factorial that takes as an input an integer value, and after processing, the input returns a long integer value. Observe that we have used variable `i_number` and `l_result` in both functions the main and the factorial.
