It can be observed in Figure 3 that each element of the array occupies 4 byte of memory. The total memory occupied by the array would then be obtained as the size of the array multiplied by the size of the data type. Even though the compile time initialization of array is allowed, it is seldom used. Most programmers prefer runtime initialization of array.
