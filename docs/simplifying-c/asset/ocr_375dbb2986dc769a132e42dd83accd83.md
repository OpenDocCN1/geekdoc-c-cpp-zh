# 10.3 Initializing Strings

In Chapter 4, we have learned how to accept data from a user at run time using inbuilt functions such as printf and gets. C being a flexible language also allows us to initialize the character array at compile time. The simplest way to initialize the character array is to assign the string using string literal when the array is declared. The syntax to initialize the array at compile time is as follows:

```
char s_name[10] = "Ahmedabad";
```

where "Ahmedabad" is known as a string literal. The memory representation of the string will be the one shown in Figure 2. The C compiler automatically adds a NULL character (\0) at the end of characters that we write in double quotes.

Another way to initialize the character array is to use single characters as in the following:

```
char s_name[10] = { 'P', 'u', 'n', 'e', '\0'};
```

As the string is formed using sequence of single characters, we explicitly need to specify a NULL character here. This method, though available, is seldom used as it is tedious. The examples discussed till now referred to fixed-length string format. As mentioned earlier, we can have a variable-length string also.

The variable-length strings are defined automatically if we omit the size of array at the time of array declaration. The definition will look as follows:

```
char s_name[ ] = "Baroda";
```

The C compiler will allocate 7 bytes automatically to the array; the size of array is calculated as the total characters within double quotes plus 1. Preceding or leading blank places, if inserted in the sequence of characters, are also included at the time of size
