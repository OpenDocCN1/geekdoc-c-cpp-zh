Generally, macro names used in the preprocessor directives are typed in capitals. In this way, other variables used in a program are differentiated from the macros. Program 3 illustrates the usage of preprocessor directive for substitution of symbolic constant:

# ▶ Program 3

```
```
/* Program to calculate the area of a circle */
#include<stdio.h>
#define PI 3.14
main()
{
    float f_rad, f_area;

    printf("\n Enter radius ");
    scanf("%f", &f_rad);

    f_area=PI*f_rad*f_rad;
    printf("Area of radius is: %f ", f_area);
    printf("\n");
    return;
}
```
```

**Output:**

Enter radius 4
Area of radius is: 50.240002

Program 3 calculates the area of a circle with radius 4. The area of a circle is calculated as PI * f_rad, where the value of *PI* is predefined as 3.14 and f_rad is the radius of the circle provided by the user. The value of *PI* will be the same throughout the program. Thus, it can be defined using the preprocessor directive. It increases the readability of a program. Program 3, when compiled, will be first preprocessed by the preprocessor. The preprocessor will locate PI in the entire program. It will substitute PI with 13.4, as shown in Figure 2:
