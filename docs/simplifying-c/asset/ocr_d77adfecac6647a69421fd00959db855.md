Note that argc and argv are name of variables; hence, there is no compulsion to use the same names in function definition. For example, int main(int l_num, char *c_vector[]) is also a valid definition.

We have discussed two scopes of variables in this chapter: global and local. The global variables are accessible to all function, whereas local variables are restricted to functions in which they are defined. C language also provides us with storage class specifiers that define where the variable will be stored and what would be its property. The next section discusses storage class specifier.

# ### 8.8 Storage Classes

The C variables are stored in primary memory and Central processing Unit (CPU) registers. The user can specify the location where he/she wants to store the variable by using the storage class as a prefix at the time of variable declaration. C language provides us with four storage class specifiers, namely, automatic, external, register, and static. Let us now discuss them one by one.

# #### ■ Automatic Variables

By default, all the variables have storage class as automatic. To explicitly define the class of variable as automatic, we use the keyword auto. The following syntax allows us to define an automatic storage class for a variable:

```
auto data type identifier;
```

For example, the definition auto char c_choice; indicates that the variable c_choice is of type character and its storage class is automatic. The variables whose storage class is defined as auto are created automatically when the function is invoked and destroyed when the function returns the control back to the calling function. The variables are stored in the primary memory and, by default, are assigned a garbage value (value that does not have any significance to the user).

# #### ■ External Variables

The modular approach of programming at times requires the programmer to share a variable between two functions or programs. The storage class external allows us to share variables between two different functions or programs. It is necessary that the variable should be defined as global variable in at least one program. In other programs, we can access the variable by using the keyword extern. The following syntax allows us to define an external storage class for a variable:

```
extern data type identifier;
```

For example, the definition extern float f_average; indicates that the variable f_average is of type float and its storage class is external. The extern prefixed to the variable conveys the compiler to look for the actual variable definition in some other included program. The default value of the external variable is zero, and they are stored in the primary memory. Once the external variables come into existence, they are available within the program as long as the program runs.
