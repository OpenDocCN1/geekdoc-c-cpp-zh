
# C Data Types

Observe the usage of `i_` as a prefix along with the actual identifier name in the preceding examples. This notion of prefixing `i_` gives an indication that the identifier defined would be of type integer. Hence, if a programmer who is trying to maintain the C program, even if he is at the 1000th line of a program, can easily know the type of identifier without looking at its definition. This convention of defining an identifier has been used throughout this book.

The memory space allocated to the data type `int` is compiler-dependent. In some compilers, it uses 2 bytes of memory space, while in others, it may use 4 bytes of memory. To verify the size of an integer data type, we can use the `sizeof` operator, which will be discussed afterward. The range of values that can be stored within the identifier will also differ based on the number of bytes allocated by the compiler. Table 1 lists the range of signed integer data type:

**Table 1: Range of Signed Integer Data Type**

| Data Type | Memory Allocated by the Compiler in Bytes | Bits | Description | Value Range | Minimum | Maximum |
| :-------- | :---------------------------------------: | :---: | :---------- | :---------- | :------ | :------ |
| int       |                    2                      |  16   | Data type used to store a positive or a negative whole number in an identifier | -32768 to +32767 | -32768 | +32767 |
|           |                    4                      |  32   | Data type used to store a positive or a negative whole number in an identifier | -2147483648 to +2147483647 | -2147483648 | +2147483647 |

The value range listed in Table 1 depends on the number of bytes allocated to the memory space by the compiler. For signed integers, the value range is calculated as $-2^{(n - 1)}$ to $+2^{(n - 1)} - 1$, where $n$ refers to the number of bits required for storage of the range of values.

By default, all integer identifiers are considered to be signed. Hence, we can also store a negative value in the identifier, and in many cases, we may only require positive values; for example, the age of a person, year of birth, and date of birth can never be negative. C language provides certain modifiers to resolve such problems. Table 2 lists the modifiers available in C and their purpose:

**Table 2: Data Type Modifiers**

| Modifier | Description | Examples of Declaration | Explanation |
| :------- | :---------- | :---------------------- | :---------- |
| short    | Modifier used to allocate half the memory space as compared to the data type `int` | `short int s_month;`<br>`short s_month;` | Both the declarations define a variable named `s_month` that can store signed integer value. |
| long     | Modifier used to allocate double the memory space as compared to the data type `int` | `long l_credit_amount;`<br>`long int l_credit_amount;` | Both the declarations define a variable named `l_credit_amount` that can store signed integer value. |
| unsigned | Modifier used to store a positive whole number | `unsigned u_age;`<br>`unsigned int u_age;` | Both the declarations define a variable named `u_age` that can store **only positive integer** value. |
|          |            | `unsigned short int u_age;`<br>`unsigned short u_age;` | Both the declarations define a variable named `u_age` that can store **only positive integer** value. |
|          |            | `unsigned long int u_age;`<br>`unsigned long u_age;` | Both the declarations define a variable named `u_age` that can store **only positive integer** value. The value range will depend on the memory allocated for storage by the compiler. |

The modifiers used in Table 2 can be used by a programmer to control the type of value that can be given by the user and the memory space allocation done by the compiler. Table 3 lists the range of values that can be stored in an unsigned integer:

**Table 3: Range of Unsigned Integer Data Type**

| Modifier | Memory Allocated by the Compiler in Bytes | Bits | Description | Value Range | Minimum | Maximum |
| :------- | :-----------------------------------------: | :---: | :---------- | :---------- | :------ | :------ |
| unsigned |                    2                      |  16   | Modifier prefixed to the `int` data type, such that only positive whole number is stored in an identifier | 0 to 65535 | 0 | 65535 |
|          |                    4                      |  32   | Modifier prefixed to the `int` data type, such that only positive whole number is stored in an identifier | 0 to 4294967295 | 0 | 4294967295 |

The value range listed in Table 3 also depends on the number of bytes allocated by the compiler to unsigned integer data type. For unsigned integers, the range is calculated as $0$ to $2^n - 1$, where $n$ refers to the number of bits required to store one element of the mentioned data type.

Having looked at the details of integer data type of C, let’s write a simple program that illustrates the usage of the integer data type along with its modifiers.

**Program 1**

```c
/* Program to illustrate the use of integer data type */

#include <stdio.h>
/* Beginning of main function */
main( )
{
    /* Declaration of three integer variable */
    int i_length, i_breadth, i_area;
    /* Accept values of length and breadth */
    printf("\n Enter the value of length:");
    scanf("%d",&i_length);
    printf("\n Enter the value of breadth:");
    scanf("%d",&i_breadth);
    /* Calculation of area */
    i_area = i_length * i_breadth;
    /* Printing of result */
    printf("\n Area of a rectangle with length %d and breadth %d is %d", i_length, i_breadth, i_area);
    return;
}
/* End of function main */
```

**Output 1:**

```
Enter the value of length: 35
Enter the value of breadth: 46
Area of a rectangle with length 35 and breadth 46 is 1610
```

**Output 2:**

```
Enter the value of length: -50
Enter the value of breadth: 150
Area of a rectangle with length -50 and breadth 150 is -7500
```

In Output 1, it seems that the program works fine. The Output 2 gives us a negative area value. In real life, negative value of length, breadth, or area is not possible. As C itself does not verify the correctness of the data entered, it becomes the duty of the programmer to ensure that the data accepted is correct. In addition, the result of multiplication of two positive values in most of the times is a value that is greater than the ones used in the multiplication. Thus, we should always make sure that the data type of the variable that stores the result has to be appropriate.

This example states that the designer of the program should consider factors such as the actual data that will be stored, its range, and other attributes before actually deciding on what data types are to be used with the identifiers.

## Real

Most of the financial and mathematical calculations require a real number in calculation. In such situations, the data type *int* does not work. To use real values in C language, we need to use keyword *float* as the data type. Float data type uses 4 bytes of memory storage space and have a precision of six decimal digits in most cases. For higher precision values, keyword *double* is used instead of float. Double data types use 8 bytes of memory storage space and are precise up to 16 decimal digits. We can also use *long* as a prefix to double. This increases the value range of double. Table 4 lists a brief description of float data type:

**Table 4: Description of Float Data Type**

| Data Type | Memory Allocated by the Compiler in Bytes | Description | Precision Digits | Value Range |
| :--- | :--- | :--- | :--- | :--- |
| float | 4 | To store positive or negative numbers with decimal points | 6 | ±3.4E-38 to ±3.4E+38 |
| double | 8 | For storing real values with more precision than float | 15 | ±1.7E-308 to ±1.7E+308 |
| long double | 10, 12, or 16 | For storing real values with the most precision (depends on compiler) | 18-19 | ±1.7E-4932 to ±1.7E+4932 |

In Table 4, we have specified range in scientific notation as C supports scientific representation of a real numbers. For example, the number 25.75 is represented as 0.2575e2, where 0.2575 is known as mantissa and 2 is known as exponent. The mantissa and exponent both can be positive or negative. The float variable when used allows us to extend the value range of the values stored. Program 2 shows the usage of float, double, and long double data type:

**Program 2**

```c
/* Program to illustrate the use of real data type*/
#include <stdio.h>

/* Beginning of main function */
main( )
{
/* declare three float variables */
float f_first;
double d_second;
long double ld_third;

/* Accept the values and print them */
printf("\n Enter value of the first variable :\");
scanf("%f",&f_first);
printf("\n First = %f\n",f_first);
printf("\n Enter value of the second variable :\");
scanf("%lf",&d_second);
printf("\n Second = %lf\n",d_second);
printf("\n Enter value of the third variable :\");
scanf("%lf",&ld_third);
printf("\n Third = %lf\n", ld_third);
return;
}
/* End of function main */
```

**Output:**

```
Enter value of the first variable: 345678.234567
First = 345678.250000
```
