A computer program is logical sequence of instructions written in any programming language that guides a computer to achieve a predefined solution. The process of writing a computer program is called programming. Generally, many computer programs are combined to make software. A software is a collection of different programs, procedures, and documentation combined together to perform a task using computer. Software is classified in two categories: system software and application software. System software is a collection of programs that allows an efficient interaction between the hardware of a computer and the user. Operating system, translator, linker, and loader are examples of system software. Application software is a collection of programs that allows a user to perform a specific data processing activity on a computer. The data processing activity can be of different types, such as managing accounts, desktop publication (DTP), database management, and communication.

One may often ask why do we need to learn a new language to write a computer program. Why not simply write the program in the languages known to us, such as English, French, Sanskrit, or Spanish? Well, the reason is that an instruction written in natural language at times can have multiple meaning. For computer programs to work efficiently, each sentence needs to be clear and precise.

A programming language is known as a formal language and is derived from natural language. It consists of a subset of characters used in a natural language and a set of predefined rules defined by the language designer. These rules form the syntax of that language and define how to write instructions in a programming language. The rules specified also guarantee that an instruction will have one and only one meaning. To learn a programming language, we only need to learn a new syntax. The case is similar in natural languages, for example, if we want to speak or write Hindi language fluently, we first need to learn the grammar of Hindi language.

This chapter discusses in brief the generation of languages, history of a formal language called C, the structure of C program, and the character set used to write a program in C language. The words in C language are also discussed, and finally, the chapter ends with the creation and execution of C program.
