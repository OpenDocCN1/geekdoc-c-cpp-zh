It can be seen in Figure 4 that when the function main is called by the operating system, only two variables, namely, i_number and i_result, are active. The value in i_number is the value entered by the user in Output 1. When the main function calls the function factorial, another stack entry is done in the memory. The C function, depending on the parameters that it takes and returns, is classified into four types. The next section discusses these four types.

### 8.4 Types of Function

A function, depending on whether the parameters are present or not and whether the function returns a value or not, may fall under any of the following function types:

- Function with no parameter and no return value
- Function with no parameter and return value
- Function with parameter and return value
- Function with parameter and no return value

Let us now discuss each of the preceding function types in detail.

## Function with No Parameter and No Return Value

Functions that neither accept any parameter from the calling function nor they return any value to it is known as function with no parameter and no return value. Here, there is no data transfer between the calling and called functions. However, transfer of execution sequence does exist. Program 2 illustrates a function that has no parameter and no return value:

**Program 2**

```c
/* Program to illustrate the use of a function that has no parameter and
   no return value */
/* Program finds day of week for a given birth date using zeller's
   congruence */

#include <stdio.h>

/* Declare global variables */
unsigned int u_day, u_month, u_year;

/* Function to accept value form user */
void inputdata(void)
{
    do
    {
        printf("\nEnter day : ");
        scanf("%u", &u_day);
    }
    while((u_day <= 0) || (u_day > 31));
    do
    {
        printf("\nEnter month : ");
        scanf("%u", &u_month);
    }
    while((u_month <= 0) || (u_month > 12));
    do
    {
        printf("\nEnter year : ");
        scanf("%4u", &u_year);
    }
    while((u_year <= 1900) || (u_year >= 9999));
}
/* End of function inputdata */
/* Beginning of function main */

main()
{
    /* Declare local variables */
    unsigned int u_weekday;

    /* Call function inputdata */
    inputdata();

    /* Use Zeller’s formula to calculate day of week */
    u_day += u_month < 3 ? u_year-- : u_year - 2;
    u_weekday = (23 * u_month / 9 + u_day + 4 + u_year / 4 - u_year/100
    + u_year/400) % 7;

    /* Print day of week */
    switch(u_weekday)
    {
        case 1:
            printf("\nYou were born on Monday\n");
            break;
        case 2:
            printf("\nYou were born on Tuesday\n");
            break;
        case 3:
            printf("\nYou were born on Wednesday\n");
            break;
        case 4:
            printf("\nYou were born on Thursday\n");
            break;
        case 5:
            printf("\nYou were born on Friday\n");
            break;
        case 6:
            printf("\nYou were born on Saturday\n");
            break;
        default:
            printf("\nYou were born on Sunday\n");
    }
    return;
} /* End of function main */
```

Output:

```
Enter day : 
Enter month : 11
Enter year : 2004

You were born on Wednesday
```

It can be seen in Program 2 that a function called inputdata has been defined. This function neither takes any parameter nor returns any values. The job of this function is to accept the data values for three variables, namely, u_day, u_month, and u_year, from the user. These three variables have been defined as global, and hence can be accessed by all the functions within the program. Thus, even though the values are accepted in function inputdata, they are processed in the function main. Observe that in Program 2, the function inputdata has been defined using the syntax void inputdata(void). The term void within the parameter list bracket indicates that no parameters are passed to this function.

It is possible to omit this statement and redefine the function as `void inputdata()`. The data type of function is compulsory as if we omit it, the compiler will consider it to be of type integer. By default, all functions in case of absence of return data type are considered to return an integer value. Figure 5 illustrates the change in flow of execution sequence after the call to function inputdata is made within the function main:

It can be seen in Figure 5 that once the call to function inputdata is made within the function main, the flow of execution sequence is altered. The execution control from the point of function call jumps to the starting address of the function inputdata. Then the statements within the function inputdata are executed. Once the function inputdata’s execution is completed, the execution control flow is transferred back through the exit point to the statement below the function call within the function main. The statements within the function main are then again executed in sequence.

## Function with No Parameter and Return Value

Functions that do not accept any parameter from the calling function, but return a value to the calling function are known as function with no parameter and return value. Here, there is one way of data transfer from the called function to the calling function. Program 3 illustrates a function that has no parameter but returns a value:

**Program 3**

/* Program to illustrate the use of a function that has no parameter but
   returns a value */
/* Program finds whether a number is prime or not */
#include <stdio.h>
#include <math.h>

/* Declare global variable */
int i_number;

/* Beginning of function */
int primo(void)
{
    /* Declare local variable */
    int i_divisor = 3;
    double d_limit;

    /* Beginning of switch structure */
    switch (i_number)
    {
        case 2:
        case 3:
            return(1);
        /* Check whether number is prime or not */
        default:
            d_limit = sqrt(i_number);
            /* Check whether number is divisible by 2 */
            if(i_number % 2 == 0)
                return(0);
            /* Check whether number is divisible by other numbers like 3,
                5 so on */
            /* Beginning of do...while loop */
            do
            {
                if( i_number % i_divisor == 0)
                    return(0);
                else
                    i_divisor += 2;
            }
            while(i_divisor <= (int)d_limit);
            /* End of do...while loop */
    }
    /* End of switch structure */
    return(1);
}
/* End of function primo */

/* Beginning of function main */
main()
{
    /* Declare local variable */
    int i_result;

    /* Accept value from user */
    printf("\nEnter a number : ");
    scanf("%d", &i_number);

    /* Check if value entered is positive */
    if(i_number > 0)
    {
        /* Call function primo */
        i_result = primo();

        /* Check the value of i_result */
        if(i_result)
            printf("\n%d is a prime number.\n", i_number);
