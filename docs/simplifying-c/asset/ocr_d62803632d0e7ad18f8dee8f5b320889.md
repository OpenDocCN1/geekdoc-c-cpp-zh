statement as `#define PI 3.14;`. Figure 3 illustrates the expansion of the source code that contains define statement with semicolon at the end:

# ▲ Figure 3: Macro Substitution without Error

It can be observed in Figure 3 that the preprocessor simply replaces all the contents found after macro name. Thus, the statement f_area = PI * f_rad * f_rad, when received by the preprocessor, is converted to f_area = 3.14; * f_rad * f_rad. The preprocessor will not generate any error at this point. However, the translator will not allow the program to compile, as this statement is syntactically incorrect.

Normally, both macro name and macro body are written in a single line. No semicolon (;) is expected at the end of a preprocessor directive. We can extend a preprocessor directive by more than one line by placing a backslash (\) character at the end of each line. However, the macro will be expanded into a single line. Program 4 illustrates how to define a multiple line macro:
