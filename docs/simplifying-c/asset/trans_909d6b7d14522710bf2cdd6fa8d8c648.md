# 附录：常用头文件及其库函数列表

C 语言中的库函数有时接受来自用户的参数。这些参数具有不同的数据类型。我们根据下表 1 中的分类对数据类型进行了分类：

### 表 1：函数参数中使用的约定

| 使用的规范 | 参数类型 |
|:-------------------|:---------------|
| ch                 | 字符         |
| db                 | 双精度浮点数 |
| fl                 | 文件         |
| int                | 整数         |
| lg                 | 长整数       |
| ptr                | 指针         |
| str                | 字符串       |
| uint               | 无符号整数   |
