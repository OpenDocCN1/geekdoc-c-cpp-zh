Preprocessor directives are usually placed in the source program before the main function statement. However, they can be defined anywhere within the program; it is not necessary to define all preprocessor directives at the beginning of the program or before the main function. As a C program is preprocessed sequentially, the use of preprocessor directive will come in effect only if the directive is used in statements written after its definition.
