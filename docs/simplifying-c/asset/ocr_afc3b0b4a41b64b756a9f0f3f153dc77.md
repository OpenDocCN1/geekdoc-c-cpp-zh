It can be observed in Figure 8 that the flow of the control is from top to bottom. To stop the flow from executing all statements, we use the keyword break. If the break statement is not used at the end of action block, the compiler will go on executing all the statements of the following action block till it finds a break statement or it encounters the end of switch structure. In addition, it is not compulsory that the default case has to appear at the end of all action blocks. It can appear anywhere within the switch structure.
