It can be seen in Program 2 that a function called inputdata has been defined. This function neither takes any parameter nor returns any values. The job of this function is to accept the data values for three variables, namely, u_day, u_month, and u_year, from the user. These three variables have been defined as global, and hence can be accessed by all the functions within the program. Thus, even though the values are accepted in function inputdata, they are processed in the function main. Observe that in Program 2, the function inputdata has been defined using the syntax void inputdata(void). The term void within the parameter list bracket indicates that no parameters are passed to this function.
