## 06
Sequence Control in C

## OBJECTIVES

- Explain Decision Structure

We have mentioned in Chapter 1 of this book that a program is always executed in a sequence from top to bottom. The statements are executed one after the other sequentially in the order that they appear in a C program. The compiler by default transfers the control to the next statement once the execution of current statement is finished. In practical scenario, this sequential flow does not work. We at times need to change the sequence of execution based on certain conditions, or may need to execute certain set of statements repeatedly. In this chapter, we will learn about a control structure used to alter the flow of execution. This control structure is called a decision structure. We will also discuss about different variants of the decision structure and see how to use them in a program.

### 6.1
Decision Structure

The decision structure of C language is used to make selections. Selection allows us to choose option from two or more options available within the program. In C language, decision structures allow us to perform predefined actions based on the results of one or more conditions. C language provides two types of selection statements, called two-way selection and multiway selection. The next section discusses about the two-way selection.

### The Two-Way Selection

A two-way selection in C language represents a conditional statement that can be evaluated as true or false by the compiler. The true answer leads to the execution of one or more action statements. In case of answer being false, the other set of action statements is executed. A general flowchart of the two-way selection is shown in Figure 1:

![](img/5d422ba7108ffdf64376be51eaf0c459_118_0.png)

Figure 1: Flowchart of a Two-Way Selection

It can be observed in Figure 1 that regardless of the set of action statements executed, C compiler continues the execution of the next statement after the selection. The two-way selection is implemented in C using the *if* and *else* keywords.

The keyword *if* is used for conditional transfer of control. It is used in combination with an expression that can be evaluated to true or false. There are three variants of *if* statements called simple *if* statement, *if-else* statement, and nested *if* statements. Each of them is used in different situations. The next subsection discusses the usage of simple *if* statement.

### The Simple If Statement

A simple if statement represents a case where an action is to be taken only when a specified condition is true and no action is to be taken in case of false condition. The syntax of simple if statement is as follows:

```
if ( test condition )
Action statements;
```

It can be observed in the preceding syntax that the test condition is always written within parenthesis. It is normally an expression that results to an integer value. Any non-zero value represents true, while a zero value represents false. The test condition is not terminated by a semicolon. In case a semicolon is used, the conditional statement is converted into a *null statement*. From the execution point of view, the null statement does not have any significance. By default, the scope of *if* statement is the statement exactly after the test condition. To increase the scope of *if* statement to multiple statements, we need to enclose the statements within opening and closing curly brackets. The statements when embedded within opening and closing curly brackets are called compound statement. Figure 2 illustrates the logical flow of a simple *if* statement:

![](img/5d422ba7108ffdf64376be51eaf0c459_119_0.png)

Figure 2: Logical Flow of a Simple If Statement

It can be observed in Figure 2 that initially the test condition is evaluated. If the value of the test condition is a positive non-zero (true), then control is transferred to the first statement in the true action statement block. The statements within the true action block are then executed. If the value of test condition is zero, *then* no action is taken. The control is transferred to the next statement in sequence after *if* at completion of the true action block or in case no action is taken. Program 1 illustrates the use of simple *if* statement:

#### Program 1

```c
/** Program to illustrate the use of simple if statement */
#include<stdio.h>
/** Beginning of main function */
main()
{
    /** Declare variables */
    float f_purchase, f_discount = 0.0;
    float f_dis_amount, f_payment;
    
    /** Read values */
    printf("\nEnter total purchase amount: ");
    scanf("%f", &f_purchase);
    
    /** Calculate discount amount */
    if (f_purchase >= 5000.00)
        f_discount = 0.15;
    
    f_dis_amount = f_purchase * f_discount;
    
    /** Calculate payment */
    f_payment = f_purchase - f_dis_amount;
    
    /** Output Data */
    printf("\nTotal payment to be made Rs. %.2f\n", f_payment);
    printf("Total discount availed Rs. %.2f\n", f_dis_amount);
    
    return;
}
/** End of main function */
```

#### Output 1:

```
Enter total purchase amount: 7500
Total payment to be made Rs. 6375.00
Total discount availed Rs. 1125.00
```

#### Output 2:

```
Enter total purchase amount: 4500
Total payment to be made Rs. 4500.00
Total discount availed Rs. 0.00
```

It can be observed in Program 1 that the program is used to calculate discount in case a purchase of Rs. 5000 or more is made. Here, the statement if (f_purchase >= 5000.00) is the decision structure that assigns a new value to f_discount if the test condition is true. The two outputs indicate that in the first case, the new value (0.15) is assigned to f_discount, while in second case, the old value (0.00) is used.

Observe that in the test condition of Program 1, we have used a relational operator (>=). We can use any valid C operator such as relational, logical, comma, assignment, or any other in the test conditions. Program 2 illustrates the use of logical operators along with relational operators in simple if statement:
