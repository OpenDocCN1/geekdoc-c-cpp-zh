# Bitwise Operators

It has been mentioned earlier that C language was actually designed for the purpose of writing system software codes. Interacting with raw bits is one of the applications in system software. C language allows us to operate directly at bit level using six bitwise operators. Table 5 lists the bitwise operators available in C and their usage:

**Table 5: Bitwise Operators**

| Symbol | Name | Usage | No. of Operands Required |
| :--- | :--- | :--- | :--- |
| `&` | Bitwise AND | To perform AND operation on two bits | Two |
| `\|` | Bitwise OR | To perform OR operation on two bits | Two |
| `~` | Bitwise NOT | To perform NOT operation on one bit | One |
| `^` | Bitwise Exclusive OR | To perform XOR operation on two bits | Two |
| `<<` | Left Shift | First operand to be shifted left the number of bits specified by the second operand | Two |
| `>>` | Right Shift | First operand to be shifted right the number of bits specified by the second operand | Two |
