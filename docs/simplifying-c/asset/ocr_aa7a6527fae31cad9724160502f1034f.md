```
$ ./a.out
```

This command will display the output of prog2_1.c on the screen. As compilation of all C programs leads to an output file a.out, it is a good practice to provide the file name of the output file along with the gcc command as parameter. Thus, an output file once created with the given name can be reused many times until there is a change in the actual source code. The following command shows how to pass a parameter to gcc command:

```
$ gcc -o prog2_1 prog2_1.c
```

where the first prog2_1 represents the output file name, while the second occurrence represents the source file name. After a successful execution of the preceding command, the compiler will now create a file named prog2_1 instead of a.out. We can run this file using the following syntax:

```
$ ./prog2_1
```

Many other parameters are also available with gcc command and can be checked by using the command $ man gcc.

The method mentioned here is the most basic method for creating and executing a C program on Linux environment. The process of creating and executing a C program mentioned before can also work on Windows platform, provided you have a Linux emulator installed on Windows. Additional features required to create and execute a C program will be discussed as we move on with the chapters in this book.

# Points to Remember

The proverb *practice makes man perfect* is to be always remembered by all the initial learners of C programming. Along with lot of practice, we need to remember the points mentioned in the following paragraph to reduce the mistakes committed during programming:

+   1. All needed header files should be included before declaring the main( ) function.
2. An executable C program should always contain only one main( ) function.
3. Two functions with the same name are not allowed in C program.
4. Normally, C programs are written using lower case letters, but upper case can also be used.
5. Identifiers are case sensitive.
6. There should be at least one blank space between two C tokens.
7. Usually, C statements end with a semi colon.
8. Comment can be inserted anywhere in the C program as per the need of the programmers.
9. Always write a proper comment before writing a function.
10. Every opening curly bracket should have a corresponding closing curly bracket.
11. Meaningful name should be given to a variable name used in C program. For example, if a variable is supposed to store student name, then it should be defined as studentname or student_name.
