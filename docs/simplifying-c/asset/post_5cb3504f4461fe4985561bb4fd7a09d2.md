
## Enumerated Data Type

```c
enum identifier {value 1, value 2, value 3, ......., value n};
```

where `enum` is the keyword. The identifier defines a new data type. Value 1 to Value n refers to the names associated with numeric constants 0, 1, 2, ..., n. The variable defined using `enum` can be assigned any numeric value or values given in curly brackets. An example of `enum` data type is as follows:

```c
enum result {first, second, pass, fail};
enum result grade;
grade = first;
```

where the first statement defines enumerated data type *result*. The next statement declares a variable *grade* of type *result*. The last statement assigns value *first* to *grade*, where *first*, *second*, *pass*, and *fail* refer to the numeric constants 0, 1, 2, and 3, respectively. These numeric constants are assigned by the compiler automatically. It is possible to modify these values and assign new values. For example, if we want *first* to be equivalent to 60, *second* to be equivalent to 50, *pass* to be equivalent to 40, and *fail* to be equivalent to 30, then we may rewrite the first statement in the given example as:

```c
enum result {first=60, second=50, pass=40, fail=30};
```

Now, the statement *grade = first* would be equivalent to *grade = 60*. The enumerated data type variables can be assigned only the values that have been previously declared. Program 5 illustrates the usage of enumerated data type:

### ▶ Program 5

```c
/* Program to illustrate the use of enumerated data type */
#include <stdio.h>

/* Beginning of main function */
main()
{
    /* Declare new data type boolean */
    enum boolean {false, true};
    int i_number;

    /* Declare enumerated variable  flag */
    enum boolean flag;
    flag = true;

    /* Read a positive number */
    while(flag)
    {
        printf("\n Enter a number : ");
        scanf("%d", &i_number);

        /* Reset the flag */
        if(i_number >= 0)
            flag = false;
    }
    printf("\n The number entered is %d\n", i_number);
    return;
}
/* End of function main */
```

**Output 1:**

```text
                Enter a number: 5
                The number entered is 5
```

**Output 2:**

```text
                Enter a number: -10
                Enter a number: -15
                Enter a number: 10
                The number entered is 10
```

In Program 5, we have created a derived data type named *boolean*, whose variable when defined can have values *false* or *true*. A variable named *flag* has been defined as type *boolean*. This variable is then used in a loop to check that the value entered in the variable *i_number* is always positive. Observe in Output 1, we were asked to enter the value of number only once. As the value entered was positive, the *flag* was reset and we came out of the loop. In Output 2, we had to enter the value of number three times. The input was negative for the first two inputs, so *flag* was not reset. However, in the third input, the *flag* was reset and we came out of the loop. This code can be used by a programmer to make sure that the value entered in the variable will always be positive.

## ■ Pointer

An identifier when defined is associated with three entities, namely, an address in memory, the size of memory to be allocated, and a value. As C language was designed to build system software, it provides inbuilt features using which a user can directly interact with the physical memory of the computer. In this section, we will discuss in brief about a concept called *pointer*.

A *pointer* is a special variable that can be defined in C language. The variable is considered to be special here because the value in the variable always refers to a memory address. The syntax to define a pointer variable is as follows:

```c
data type *identifier name;
```

In the preceding syntax, the identifier name is a normal variable name and follows all the rules applicable for defining an identifier. The `*` indicates that the variable defined is a *pointer*. The data type here indicates that the address stored in the pointer variable will be a point to the given data type. For example, a definition `int *i_ptr;` can be interpreted as *i_ptr* is a pointer variable, which stores address that refers to integer variable. Program 6 illustrates the use of *pointer*:

### ▶ Program 6

```c
/* Program to illustrate the use of pointer */
#include<stdio.h>
/* Beginning of main function */
main()
{
  /* Declare variables */
  int i_num, *i_ptr;
  /* Assign address of i_num to i_ptr */
  i_ptr = &i_num;

  /* Read data in i_num */
  printf("\nEnter a number: ");
  scanf("%d", &i_num);
  /* Print the value using pointer */
  printf("\nThe number %d is stored at %u\n", *i_ptr, i_ptr);
  printf("\nAddress of number is %u", &i_num);
  printf("\nAddress of pointer is %u and value in pointer is %u\n", &i_ptr, i_ptr);
  return;
}
/* End of function main */
```

**Output:**

```text
Enter a number: 999
The number 999 is stored at 65524
Address of number is 65524
Address of pointer is 65522 and value in pointer is 65524
```

In Program 6, we have defined two variables. The first variable is a normal integer variable, while the second one is a pointer variable capable of storing an address of another integer variable. Figure 2 shows the sequence of execution for Program 6:

![](img/5d422ba7108ffdf64376be51eaf0c459_68_0.png)

It can be observed in Figure 2 that when the variables are declared, two memory blocks are reserved in the memory at addresses 65522 and 65524, respectively. The address 65522 refers to variable *i_ptr* and address 65524 refers to variable *i_num*. The statement `i_ptr = &i_num` assigns address of *i_num* to *i_ptr*. Finally, the statement `printf("\nThe number %d is stored at %u\n", *i_ptr, i_ptr);` prints the value of *i_num* by using the pointer dereference. Here, *i_ptr* is interpreted as get the value stored at the address mentioned in *i_ptr*. Note that the address assigned to the variable may differ at each run of the program. ## 3.5 Void Pointers

Pointer variables are special as they can be defined as `void` data type initially and then made to point to any specific data type as per the need of the user. The concept of void pointers comes in very handy when the user allocates memory to variables at run time (concept of dynamic memory allocation discussed in Chapter 14 of this book). Program 7 illustrates the use of void pointers:

### ▶ Program 7

```c
/* Program to illustrate the use of void pointer */
#include <stdio.h>
/* Beginning of main function */
main()
{
    /* Declare variables */
    int i_num;
    float f_num;
    void *v_ptr;
    /* Read data in i_num */
    printf("\nEnter a number: ");
    scanf("%d", &i_num);
    /* Assign address of i_num to v_ptr */
    v_ptr = &i_num;
    /* Print the value using pointer */
    printf("\nThe number stored in i_num is %d\n", *(int *)v_ptr);
    /* Read data in f_num */
    printf("\nEnter a number: ");
    scanf("%f", &f_num);
    /* Assign address of f_num to v_ptr */
    v_ptr = &f_num;
    /* Print the value using pointer */
    printf("\nThe number stored in f_num is %f\n", *(float *)v_ptr);
    return;
} /* End of function main */
```

**Output:**

```text
Enter a number: 55
The number stored in i_num is 55
Enter a number: 75.55
The number stored in f_num is 75.550003
```

It can be seen in Program 7 that we have declared a void pointer variable named *v_ptr*. This pointer is first assigned the address of variable *i_num*. In the `printf` statement, it is then type casted (concept discussed in Chapter 5 of this book) and dereferenced to get the value of integer variable. The same variable is then reassigned the address of float variable and used to print its value. Thus, a user, if he/she knows how to handle void pointer, can perform desired operations using only one void pointer variable. The pointers will be discussed in detail in Chapter 12 of this book; at present, we have simply discussed what the pointer means. Array at some point of time will use the concept of pointers.

## Summary

In this chapter, we have learned about the concepts of primitive, and user defined/derived data types. The primitive data types that we discussed are `int`, `char`, `float`, and `void`. Each of these data types, except for `void`, can be prefixed with modifiers. The modifiers change the size requirement and the range of values that can be stored in an identifier. The modifiers discussed were `short`, `long`, `signed`, and `unsigned`. We also learned about the usage of a user-defined data type named `typedef`, which allows the programmer to give an alias to an existing primitive or derived data type. The derived data type `enum` was discussed along with example. Further, we discussed the concept of pointers. Pointers are special variables that store address of other variables as its value. Pointers are the only variables that can be declared as having `void` data type.
