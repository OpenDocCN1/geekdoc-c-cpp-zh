The function ftell then returns the position of the record that is displayed on the screen. It actually returns the total number of bytes preceding the file pointer position from within the file. For example, if 140 is returned by the function ftell, the position of record is 140/28 = 5, where 28 is the number of bytes occupied by a structure item.

The variable named *found* is used to check whether the record corresponding to item name supplied by the user exists or not. Initially, the value of variable *found* is set to FALSE. Later, when a successful match is obtained, the value of variable *found* is set to TRUE. If the value of variable *found* is set to FALSE, it indicates that no record containing the item name supplied by the user is found and an appropriate message is displayed on the screen.
