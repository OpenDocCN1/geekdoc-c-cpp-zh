# 2.3 First C Program

Let's now write our first C Program. A C program has a predefined structure and certain set of words that can be used in it. If we do not follow this structure, then we will get errors. Program 1 is an example of a simple C program:

▶ Program 1

```
"/* My first C program */"
"#include <stdio.h>"
"main( )"
"{"
" printf(\"First step towards learning C Language.\");"
" return;"
"}"
```

Output:

First step towards learning C Language.

The program written in Program 1 is used to print a message First step towards learning C Language. on the monitor screen. The purpose of each line used in the program is explained in Figure 1:

![](bbox=[0.238, 0.523, 0.85, 0.674])

In Figure 1, the first line is a comment line. A comment line is not included in the executable counterpart of C program. It is used for documentation purpose. The statement #include <stdio.h> is an inclusion of a header file. Next, main( ) is known as a user-defined function, while printf( ) is known as an inbuilt or a library function. User-defined functions are the functions that are created by users as per their requirement. The functions already available in C compilers library that a user can make use of in a program are known as inbuilt or library functions.
