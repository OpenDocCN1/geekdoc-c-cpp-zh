
## 13.10 I/O in Binary Files

So far we have discussed programs that worked with text files. As discussed earlier, working with binary files is more efficient than text files. Binary files are preferred when the data stored in files is of record type. To write contents to binary file, function `fwrite` can be used. The syntax of the function `fwrite` is as follows:

```c
fwrite(address of variable, size of datatype of variable, number of such variables, file_pointer);
```

The function `fwrite` accepts four parameters. The first parameter is the address of the variable to be written to the disk. The second parameter is the size of the variable in bytes. The `sizeof` operator can be used to calculate the number of bytes occupied by a variable. The third parameter is the number of such variables to be written to a file at a time. This parameter of the function `fwrite` is very useful when the collection of variables, such as array, is to be dumped. The data can be organized as a structure and the entire structure array can be dumped to a file. This results into writing of a multiple records in a file at a time. The last parameter is the file pointer pointing to a file in which the data is to be stored.

To read the contents from binary file, the function `fread` can be used. The syntax of the function `fread` is as follows:

```c
fread(address of variable, size of data type of variable, number of such variables, file_pointer);
```

The format of the function `fread` is much similar to that of the function `fwrite`. It also accepts four parameters. The first parameter is the address of the variable in which the data read from the file will be stored. The second parameter is the size of the data type of variable indicated in the first parameter. The third parameter is the number of such variables to be read from the file at a time. The last parameter is the file pointer pointing to a file from which the data is to be read. Program 7 illustrates the use of functions `fread` and `fwrite` within a binary file:

### Program 7

            items.i_itemno=++i_ctr;
            printf("\n ************Enter record %d:*********** ",

            scanf("%s %f %d",&items.c_itemname,&items.f_itemrate,&items.i_itemqty);
            c_temp=getchar();

            /* writing into file*/
            fwrite(&items,sizeof(items),1,fp_item);
            printf("\nwould like to add another record yes(y)/No(n): ");
            scanf("%c",&c_ans);
        }while (c_ans=='y' || c_ans == 'Y');
        fclose(fp_item);
    }

    if (fp_item==NULL)
        printf("Error in opening a file\n");
    else

        while (fread(&items,sizeof(items),1,fp_item) != 0)

In Program 7, file `itemb` is opened in write mode. The mode specification is `wb`, where `b` stands for binary. The values accepted from the user to store in a file are organized as a structure. The values are then scanned from the user using the function `scanf`. These values are stored in a binary file named `itemb` using the function `fwrite`. The first parameter of function `fwrite` is the address of structure variable `items`. The second parameter is the `sizeof` operator with structure variable as a parameter. The third parameter is 1. It indicates that at a time, only one block of byte size specified in the second parameter will be written in a file. The fourth parameter is the file pointer pointing to a file in which the data is to be stored. The user can continue to enter as many records as he/she wishes. To terminate the loop, the user may specify character `n` or `N`. The file `item` is then closed.

To read the file `itemb`, it is opened in `rb` mode. To read the contents from the file, the function `fread` is used. The `fread` function accepts four parameters as specified in its syntax. The first parameter is the address of the structure. The second parameter is the `sizeof` structure `items`. The third parameter is 1. The fourth parameter is the file pointer pointing to a file from which the contents are to be read. The function `fread` returns the number of records read from the file. Actually, it will be of the same number as specified as a third parameter. When EOF has been reached, the function `fread` cannot read anything, and thus, it returns 0. Thus, the return value of `fread` can be used to terminate the condition. Once the file contents are read, the while loop terminates. The opened file is then closed using the function `fclose`.

## 13.11 Random File Access

So far we have discussed file functions that are useful for reading and writing data sequentially. However, at times we are interested in accessing only a particular record. It may be the 5th record directly, or the 10th record, or the last record. Situation may demand accessing the 5th record when the file pointer is positioned at the 10th record. In such situation, the file pointer is to be moved backward. This random access of files can be achieved with the help of the functions `fseek`, `ftell`, and `rewind` available in C library. Let us discuss each of them one by one.

### Repositioning File Pointer

The function `fseek` is used to move the file position to a desired location within the file. The syntax of the function `fseek` is as follows:

```c
fseek(file_pointer, offset, position);
```

The function `fseek` accepts three parameters. The first parameter is the file pointer that points to the desired file. In the preceding syntax, the second parameter `offset` is the number of bytes a file pointer is to be moved by the function `fseek`. The `offset` may be positive or negative. Positive offset is used to instruct function `fseek` to move file pointer forward in the file. Negative offset is used to move backward in a file. Position can take one of the three values 0, 1, and 2, where 0 indicates beginning of file, 1 indicates current position of file pointer, and 2 indicates EOF. The data type of `offset` is `long`.
