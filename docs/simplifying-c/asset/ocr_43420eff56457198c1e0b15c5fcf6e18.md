The difference observed in the usage of normal structures and pointer structures is the way the variables are accessed. The dot (. ) operator is used to access individual members of the structures as discussed in Chapter 11. However, to access structure members with pointer to a structure, arrow (\( \rightarrow \)) operator is used. For example, to scan the value of c\_name, scanf("%[ \^\n]", ptrcontact\( \rightarrow \)c\_name) will be used. Let us write a program to understand how pointer to a structure works. Program 16 illustrates the usage of pointer to structure.
