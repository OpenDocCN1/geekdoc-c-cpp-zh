The initial programmers normally make a mistake of terminating the *for* statement with a semicolon. Program 4 illustrates this mistake:

# ▶ Program 4

```
/* Program to print numbers from 1 to 50 using the for loop */
#include <stdio.h>
/* Beginning of main function */
main()
{
    /* Declare variable */
    int i_ctr;

    /* Print values from 1 to 50 */
    for(i_ctr = 1 ; i_ctr <= 50; i_ctr++);
    {
        printf("%02d ",i_ctr);

        if((i_ctr % 10) == 0)
            printf("\n");
    }

    return;
}
/* End of main function */
```

**Output:**

![](bbox=[0.25, 0.68, 0.85, 0.7])

Program 4 was written to print numbers from 1 to 50. However, the output of the program is only 51. The reason of this wrong output is the mistake that we did in statement for(i_ctr = 1 ; i_ctr <= 50; i_ctr++). Here, we have terminated the *for* statement with a semicolon. The compiler did not generate any error in this case, as it assumed that there is no statement to be executed within the *for* loop. Even though no statements were executed within the loop, the loop counter was initialized to 1 and incremented by 1 until its value became 51, and the condition `i_ctr <= 50` evaluated to false. This kind of *for* loop is referred to as delay loop. The delay loop does not execute any statement, but simply initialize, checks the test condition, and updates the value of the loop counter.
