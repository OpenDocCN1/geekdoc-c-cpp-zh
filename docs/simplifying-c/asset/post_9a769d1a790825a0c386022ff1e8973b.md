
area = (base * height)/2;
roll_no = 14;

In the first example, an expression is assigned to the variable area, while the second example assigns a constant value 14 to the variable roll_no. Note that the left operand of the assignment statement has to be a single variable.

The special symbol = is also used as a shorthand operator. The shorthand operator is used to reduce the size of expressions and improve the readability of C programs. To convert the special symbol = into a shorthand operator, we prefix any arithmetic operator to =. The syntax of a shorthand operator is as follows:

identifier AOp= expression; or identifier AOp= constant value;

where the identifier is any valid variable name, AOp refers to an arithmetic operator, and AOp= is a shorthand operator. Some examples of the shorthand operators are as follows:

counter += 1;
table *= 2;
first /= (second + third);

The statement counter += 1; is equivalent to counter = counter + 1; while table *= 2; is equivalent to table = table * 2; and first /= (second + third); is equivalent to first = first / (second + third). It can be observed from these examples that if a variable appears on both the left-hand side (LHS) and right-hand side (RHS), then we can use the shorthand operator in such expressions. The expression built by using shorthand operator is known as a compound assignment statement. If a compound assignment contains a binary expression, as shown in example 3, the binary expression will always be resolved first. With certain amount of practice, shorthand operators can become an efficient tool to improve the readability of C programs. Program 6 illustrates the usage of shorthand operators:

## Relational Operators

As mentioned earlier, comparisons play a major role in most of the complex C programs. The result of the comparison is used to change the flow of execution of program. For example, to give incentive to an employee, we may check for the sales that the employee has done. If it exceeds the predefined target given to the employee, then the employee may get a raise in his salary. A C language expression for this scenario can be written as if (total_sales > target_given) then raise_in_basic = basic * 0.25; where the special symbol > is a relational operator.

C language has six relational operators for the purpose of comparison. Table 2 lists the relational operators and their use:

### Table 2: Relational Operators

| Symbol | Name | Usage |
| :--- | :--- | :--- |
| == | Equal To | Checks whether operand 1 is equal to operand 2. |
| != | Not Equal To | Checks whether operand 1 is not equal to operand 2. |
| > | Greater Than | Checks whether operand 1 is greater than operand 2. |
| < | Less Than | Checks whether operand 1 is less than operand 2. |
| >= | Greater Than Equal To | Checks whether operand 1 is greater than or equal to operand 2. |
| <= | Less Than Equal To | Checks whether operand 1 is less than or equal to operand 2. |

In mathematics, to check the equality of two operands, we use a single equal to sign (=). In C language, we use double equal to signs (==) to check the equality as = is used as an assignment operator here. The syntax for using relational operators is as follows:

(Expression-1) ROP (Expression-2)

where Expression-1 and Expression-2 can be arithmetic expressions, variable, or constant, and ROP refers to one of the relational operator mentioned in Table 2. The entire expression here is known as relational expression. The result of a relational expression is always either true or false. Relational operators are generally used along with decision structures, such as if, or control structures, such as for, while, and do. These structures are discussed in detail in Chapter 6 and 7. ## Increment and Decrement Operators

Assume a scenario where we are assigned a task to write a program that keeps track of number of times a six has been hit by a batsman in an ongoing cricket match. Here, we will define one variable, say, counter, and assign it value 0 initially. Then, every time a six is hit by the batsman, we will add 1 into this counter. The step of adding 1 to the old value of the counter can be represented using the shorthand operator as counter += 1.

Similarly, if we are asked to keep track of the number of over that remains to be bowled in a match, we can use another variable, say, over_counter, and initially assign it to maximum overs that can be played. Then, as an over gets completed, we will deduct 1 from the variable over_counter. The step of deducting 1 from the old value of over_counter can be represented using the shorthand operator as over_counter -= 1.

C language provides two unary operators, namely, ++ and --, for the purpose of increment and decrement of value by 1. The expression formed by using increment or decrement operator is termed as unary expression, as these operators require only one operand. The operator ++ is known as increment operator, while the operator -- is known as decrement operator. The expression can further be termed as postfix expression or prefix expression, depending on where these operators are placed. The syntax for using these operators is as follows:

```text
++identifier or identifier++
--identifier or identifier--
```

where the operators ++ and -- are either prefixed or suffixed to an identifier. When we prefix the operators, the statement becomes preincrement or predecrement statement. On the other hand, when it is suffixed, we call it post increment or post decrement statement.

When these operators are used only for increment or decrement of an identifier, their effect on the evaluation of expression is not much of a concern as they only add value 1 to the existing value of the identifier.
