
## 11.8 Array of structure

We have used the example of address book to understand the concept of structures. Programmatically, to store two contacts, two structure variables were required and declared individually. If we were to maintain information of 100 contacts, it would become cumbersome to define and manage 100 different variables. The problem can be solved by defining an array, where each element of the array is a structure variable. The concept is illustrated in Figure 8:

![](img/5d422ba7108ffdf64376be51eaf0c459_243_1.png)

It can be seen in Program 5 that if the structure contains another structure, for example, structure date within structure contact, we can use dot operator to access the data elements of the nested structure as well as the structure variable itself. No parentheses are required to force the order of evaluation as a dot operator is evaluated from left to right. Figure 7 illustrates the storage of birth date as part of the structure contact in the form of embedded structure:

![](img/5d422ba7108ffdf64376be51eaf0c459_243_0.png)

Till now the structure variables defined were used as a single variable. We can also define an array of structures. The next section discusses how to define and use an array of structure.

Program 6 illustrates how to define an array of structure.

### Program 6

```c
/* Program to define and use array of structure */
#include<stdio.h>
/* Beginning of main function */
main()
{
	int i_ctr, i_no;

/* Declaration of Structure */
struct date
{
	unsigned int i_dd;
	unsigned int i_mm;
	unsigned int i_yyyy;
};

struct contact
{
	char c_name[25];
	char c_email[30];
	unsigned long int li_phoneno;
	struct date dob;
};

typedef struct contact Contact;

/* Array of structure */
Contact contactdetails[100];

printf("How many contacts would you like to enter: ");
scanf("%d", &i_no);

for (i_ctr = 0; i_ctr < i_no; i_ctr++)
{
	printf("\nEnter details of contact %d:\n", i_ctr+1);
	printf(" Enter name: ");
	scanf(" %[\n]", contactdetails[i_ctr].c_name);
	printf("\n Enter Phone number: ");
	scanf("%ld", &contactdetails[i_ctr].li_phoneno);
	printf("\n Enter e-mail address :");
	scanf(" %s", &contactdetails[i_ctr].c_email);
	printf("\n Enter Birthdate (dd mm yyyy) : ");
	scanf("%u %u %u", &contactdetails[i_ctr].dob.i_dd,
	&contactdetails[i_ctr].dob.i_mm, &contactdetails[i_ctr].dob.i_yyyy);
}
/* Print data elements of structure array */
printf("\nInformation of contacts recently entered.....\n");
for (i_ctr = 0; i_ctr < i_no; i_ctr++)
{
	printf("\n Contact information %d\n\n", i_ctr+1);
	printf("  Name : %s\n\n", contactdetails[i_ctr].c_name);
	printf("  Phone Number : %ld\n\n",
	contactdetails[i_ctr].li_phoneno);
	printf("  Email address : %s\n\n",
	contactdetails[i_ctr].c_email);
	printf("  Birtdate : ");
	printf("%u-%u-%u\n", contactdetails[i_ctr].dob.i_dd, contactdetails[i_ctr].dob.i_mm, contactdetails[i_ctr].dob.i_yyyy);
	printf(" ************************************************\n");
}

return;
}
/* End of function main */
```

It can be seen in Program 6 that we have defined an array named contactdetails of size 100. The compiler thus reserves the memory area to store 100 contacts at compile time. The user may choose to store less number of contacts at the time of executing the program. Hence, number of contact to be stored in an array is taken as input from the user. The data members of the structure are now accessed using array index variable and a dot operator. For example, contactdetails[0].c_name will contain the name of a contact person stored in the first location of the structure array.

## 11.9 Structure and Function

As discussed in Chapter 8 of this book, functions help in creating modular programs. Functions interact with other functions using parameters. Till now we have used primitive data types as parameter of functions. A structure may also be passed as a parameter to a function. Similarly, it is also possible to write functions that return structure variable. Program 7 illustrates the how to pass structure as a parameter to function.

### Program 7

```c
/* Program to input and display contact details using functions */
#include<stdio.h>
/* declaration of structure */
struct date
{
unsigned int i_dd;
unsigned int i_mm;
unsigned int i_yyyy;
};

struct contact
{
char c_name[25];
char c_email[30];
long int li_phoneno;
struct date dob;
};

typedef struct contact Contact;

/* Function prototypes*/
/* getcontact , input: nothing, returns: structure variable of type Contact*/
Contact getcontact();
/* displaycontact, input: structure variable of type contact, returns: void */
void displaycontact(Contact);

/* Beginning of function main */
main()
{
/* Declare variable */
Contact newcontact;
/* Call function getcontact */
newcontact = getcontact();
/* Call function displaycontact */
displaycontact(newcontact);
return;
}
/* End of function main */
/* Definition of function getcontact */
Contact getcontact()
{
Contact temp;
printf("\n Enter name: ");
scanf(" %[\n]", temp.c_name);
printf("\n Enter Phone number: ");
scanf("%ld", &temp.li_phoneno);
printf("\n Enter e-mail address : ");
scanf("%s", &temp.c_email);
printf("\n Enter Birthdate (dd mm yyyy) : ");
scanf("%u %u %u", &temp.dob.i_dd, &temp.dob.i_mm, &temp.dob.i_yyyy);
return(temp);
}
/* End of function getcontact */

/* Definition of function displaycontact */
void displaycontact(Contact x)
{
    printf("\nThe information of contacts recently entered........\n");
    printf("\nContact information:\n");
    printf(" Name : %s\n\n", x.c_name);
    printf(" Phone Number : %ld\n\n", x.li_phoneno);
    printf(" Email address : %s\n\n", x.c_email);
    printf(" Birthdate : ");
    printf("%u-%u-%u\n\n", x.dob.i_dd, x.dob.i_mm, x.dob.i_yyyy);
}
/* End of function displaycontact */
```

**Output:**

```text

Enter Phone number: 2341234
Enter e-mail address: harshitjain123@rediffmail.com
Enter Birthdate (dd mm yyyy): 15 7 1978
The information of contacts recently entered.....
Contact information
Name: Harshit Jain

Email address: harshitjain123@rediffmail.com

```

It can be seen in Program 7 that we have used two functions, namely getcontact and displaycontact. The values of data members of the structure are assigned input using the function getcontact. The function displaycontact is used to display the values of data member. Observe that the definition of structure template is made global by defining the template above the main function. Thus, the structure template definition will be available to all the functions defined even outside the main function.

To receive structure in the function displaycontact as a parameter, the function has to be aware of the structure definition. Similarly, the function getcontact has to be aware of the structure contact’s definition, so that a temporary structure variable with the same data type can be defined within the function getcontact.

Often, there is a need to pass individual member of a structure as a function parameter, rather than the entire structure variable itself. For example, if a structure that stores information of an employee has data members such as name of employee, designation, basic salary, and other related fields, then to write a function that calculates salary of the employee, we may need to pass only name and basic salary of the employee instead of an entire structure.
