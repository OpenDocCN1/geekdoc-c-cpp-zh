The first location of an array can be accessed using name of an array. Thus, i_a is a pointer pointing to an array containing starting location of an array. In the preceding case, it will be 1000. In other words, the pointer i_a points to the element stored in i_a[0]. Thus, the value of i_a and &i_a[0] are same. Each memory location in an array can be accessed using pointer arithmetic. According to pointer arithmetic, incrementing i_a by 1 will result to 1004, which is the address of the second element in array. If i_a is incremented by 2, the result will be 1008, which is the address of the third element in the array. In particular, i_a added to the value of array index can result to memory location of each element in an array. If i_a contains an address, the dereference operator * can be used to access the value. Thus, the value of the first element of an array can be accessed using *i_a. Similarly, the value of the second element of an array can be accessed using *(i_a+1), the third element of an array can be accessed using *(i_a+2), and so on, as shown in Figure 12:
