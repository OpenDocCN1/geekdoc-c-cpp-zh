As mentioned earlier, the structures do not occupy any memory until they are associated with the structure variable. In the preceding case that declares two structure variables, the declaration of structure contact will not occupy any memory until the structure variables contact1 and contact2 are declared. Thus, the members of the structure will not have any existence until they are associated with structure variables.

A structure variable can also be defined at the time of declaration of template, as shown in Table 1:

**Table 1: Alternate Definition of Structures**

| | |
|---|---|
| struct contact | struct |
| { | { |
| char c_name[25]; | char c_name[25]; |
| unsigned long int li_phoneno; | unsigned long int li_phoneno; |
| char c_email[30]; | char c_email[30]; |
| } contact1, contact2; | } contact1, contact2; |


It can be seen in Table 1 that we have declared the variables before terminating the structure template. Both the methods mentioned in Table 1, though available in C language, are seldom used by programmer for the purpose of declaring a structure. The second definition that does not include the template name does not allow us to declare any new variable of structure within the program.

Similar to normal variables, the structure variables also reserve memory space. This memory space is not a predefined similar to that of int, char, and other data type, as the number of members in a structure may vary.
