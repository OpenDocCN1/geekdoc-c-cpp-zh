C language also allows us to add integers to a pointer. We can also subtract integers from pointers. For example, if ptr1 is a pointer, then ptr1 +1, ptr1 +8, ptr1–2, and ptr1–7 are all valid operations. An addition and subtraction of one pointer from another pointer is also a valid operation. For example, if ptr1 and ptr2 are pointers that points to elements of the same array, the difference of ptr2 and ptr1 can give us the number of elements between ptr1 and ptr2.

The pointers can also be compared using relational operators. For example, comparisons such as ptr1 < ptr2, ptr1 > ptr2, ptr1 == ptr2, and ptr1 != ptr2 are all valid. The following is the list of operations that can be performed over pointers:

+   - **Addition:** Means that an integer value can be added to a pointer
- **Subtraction:** Means that an integer value can be subtracted from a pointer
- **Comparison:** Means that the pointers can be compared if they point to the elements of the same data type
- **Difference:** Means that one pointer can be subtracted from other if both point to the elements of the same data type
- **Assignment:** Means that one pointer can be assigned to another pointer if both of them are of the same data type

You might wonder that what will happen when a pointer is incremented or decremented. Assume that ptr is a pointer declared of integer data type. Remember that a pointer to integer is an address in memory. A pointer itself is definitely NOT an integer. The reason a pointer variable is associated to a data type is to find the total bytes allocated by the compiler in the primary memory for that data type. The pointer when incremented or decremented is incremented or decremented by the amount of size of memory allocated to the data type that it points to.

Thus, the pointer i_ptr that points to integer data when incremented by 1 will be automatically incremented by 4, if the size of integer data type occupies 4 bytes in a system when we use gcc compiler.
