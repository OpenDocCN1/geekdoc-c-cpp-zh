# Simplifying C

Second Edition

C language is the first course for all computer programming aspirants. This book is designed to fulfill the needs of all the beginning aspirants of C language. It will serve as a textbook for the students of Engineering (BE/Btech), Computer Applications (BCA/MCA), Computer Science (BSc/MSc), and Diploma Programs with no prior programming experience. Beginning with basic concepts of logic development, this book gives a detailed coverage of C language constructs, functions, pointers, arrays, strings, structure, union, files, and preprocessor directives. It contains code of many executable C programs that can run on various C compilers, such as gcc, Borland Turbo C/C++, and Visual Studio.

## Salient features of the book:

- Clear organizational structure, supplemented by easy to understand figures and tables.
- Program tracing technique to assist user in validating the algorithm.
- Easy to understand collection of real life programs.
- Plenty of review questions and programming exercises at the end of each chapter.
- Emphasize on using modular approach of programming by using more user-defined functions.
- Each concept has been supplemented with detailed theoretical discussion.
