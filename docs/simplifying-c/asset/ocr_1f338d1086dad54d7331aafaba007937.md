# 13.11 Random File Access

So far we have discussed file functions that are useful for reading and writing data sequentially. However, at times we are interested in accessing only a particular record. It may be the 5th record directly, or the 10th record, or the last record. Situation may demand accessing the 5th record when the file pointer is positioned at the 10th record. In such situation, the file pointer is to be moved backward. This random access of files can be achieved with the help of the functions fseek, ftell, and rewind available in C library. Let us discuss each of them one by one.

# Repositioning File Pointer

The function fseek is used to move the file position to a desired location within the file. The syntax of the function fseek is as follows:

```
fseek(file_pointer, offset , position);
```

The function fseek accepts three parameters. The first parameter is the file pointer that points to the desired file. In the preceding syntax, the second parameter offset is the number of bytes a file pointer is to be moved by the function fseek. The offset may be positive or negative. Positive offset is used to instruct function fseek to move file pointer forward in the file. Negative offset is used to move backward in a file. Position can take one of the three values 0, 1, and 2, where 0 indicates beginning of file, 1 indicates current position of file pointer, and 2 indicates EOF. The data type of offset is long.
