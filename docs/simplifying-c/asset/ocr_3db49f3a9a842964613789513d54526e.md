# 15.3 Macro Expansion

Macros are brief abbreviations for fragment of code. Wherever macro name is used in a program, it is replaced by the contents of the macro body. The process of replacing a macro call with the contents of the macro body is called expansion of the macro call. We can create macros with the #define directive. The syntax to define macro is as follows:

```
#define macro_name macro_body
```

For example, #define TRUE 1 defines a macro named TRUE with associated macro body as 1. After the definition of the macro TRUE, if the macro is used as part of an expression within the C program, all such occurrences of macro TRUE will be replaced with value 1.
