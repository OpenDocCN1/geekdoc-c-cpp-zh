## 10.3 Initializing Strings

In Chapter 4, we have learned how to accept data from a user at run time using inbuilt functions such as printf and gets. C being a flexible language also allows us to initialize the character array at compile time. The simplest way to initialize the character array is to assign the string using string literal when the array is declared. The syntax to initialize the array at compile time is as follows:

```
char s_name[10] = "Ahmedabad";
```

where "Ahmedabad" is known as a string literal. The memory representation of the string will be the one shown in Figure 2. The C compiler automatically adds a NULL character (\0) at the end of characters that we write in double quotes.

Another way to initialize the character array is to use single characters as in the following:

```
char s_name[10] = { 'P', 'u', 'n', 'e', '\0'};
```

As the string is formed using sequence of single characters, we explicitly need to specify a NULL character here. This method, though available, is seldom used as it is tedious. The examples discussed till now referred to fixed-length string format. As mentioned earlier, we can have a variable-length string also.

The variable-length strings are defined automatically if we omit the size of array at the time of array declaration. The definition will look as follows:

```
char s_name[ ] = "Baroda";
```

The C compiler will allocate 7 bytes automatically to the array; the size of array is calculated as the total characters within double quotes plus 1. Preceding or leading blank places, if inserted in the sequence of characters, are also included at the time of size calculation. Another way to declare a variable-length string format is to use pointers. The preceding definition can be modified as follows:

```
char *s_name = "Baroda";
```

Here, a string literal is first defined and then the address of the first character is assigned to the pointer variable. Hence, the address of character $B$ will be assigned to $s$\_name. As the remaining characters are aligned in sequence in the memory, they can be easily accessed.
Once the strings are available to us, we need to learn how to format and display them. The next section discusses different formatting methods used with string.

## 10.4 Displaying Strings

In Chapter 4, we have learned how to format numeric data. Similar to numbers, a string can also be displayed in different formats. The general format of display is similar to the one used in numeric data, that is, \%[flag]\[width]\[.\] \[length\] format code. Program 1 illustrates the use of string display formats:

### Program 1

```
/* Program to illustrate display formats of string */

#include<stdio.h>
/* Beginning of main function */
main()
{
	/* Declare character array */
	char s_student[15];
	/* Read data in array */
	printf("\n\nEnter the full name of student: ");
	scanf("%[^\n]",&s_student);
	/* Print different formats of string */
	printf("\n\nThe name of the student in different formats\n");
	printf("%s\n",s_student);
	printf("%7s\n",s_student);
	printf("%-15s\n",s_student);
	printf("%15.5s\n",s_student);
	printf("%.5s\n",s_student);
	printf("%-15.5s\n",s_student);
	return;
}
/* End of function main */
```

## 10.5 Manipulating Strings

The strings can be manipulated in many different ways. We can perform operations such as finding string length, comparing whether two strings are same or not, joining two strings, finding a character within a string, finding a sub string within a string, and many more on the strings. C has provided a very good collection of inbuilt functions to manipulate the strings. To use these functions, we need to include string.h header file in our programs.

Even though the inbuilt functions are available in C library, we have written our own programs to perform the operations mentioned before so as to get a clear idea of how these functions work. The next section discusses the operations aforementioned.

-   Length of String

The length of a string is defined as the sum of total number of characters, including blanks spaces, stored before the NULL character. It is possible that the size of array and the length of the string stored in it are not the same. For example, if we have a string defined as follows:

```
char s_product[15] = "Computer";
```

Then, although the size of array here is 15, the actual length of the string is 8, as there are only eight characters before the NULL character. Program 2 illustrates the use of C function that finds the length of a string. This function takes as an input a pointer to character element and returns an integer value representing string length.

### Program 2

```
/* Program to find length of string */

#include<stdio.h>

/* Function to calculate length of string */
int strlen(char *s_str)
{
  int i_len;
  for ( i_len = 0; s_str[i_len] != '\0'; i_len++);
  return i_len;
}
/* End of Function */

/* Beginning of main function */
main()
{
  /* Declare character array */
  char s_str[25];
  int i_len;
  /* Read data in array */
  printf("\nEnter a string : ");
  scanf("%[^\n]",&s_str);
  i_len = strlen(s_str);
  /* Print length of string */
  printf("\nThe length of string %s is %d",s_str, i_len);
  return;
}
/* End of function main */
```

```
The length of string Happy Birthday is 14
```

-   Comparison of Strings

As an array is a data structure, we cannot use the name of arrays to check whether the strings are equal or not. The strings are checked character by character one at a time to find out whether they are same or not. This comparison is done based on the ASCII values of the character stored at each index. The strings are then evaluated as equal, greater, or lesser than the other string. Program 3 illustrates how to compare two strings:
