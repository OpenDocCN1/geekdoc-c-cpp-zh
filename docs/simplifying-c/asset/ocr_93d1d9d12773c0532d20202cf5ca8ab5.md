A system works on the fundamental principles of input, process, and output. The programs that we design represent the processing part of the system. The process normally converts raw data into information. The raw data represents input, while the information represents output. The output generated is always dependent on the input that has been provided to the program. The input can be provided to the program statically or dynamically. In static input, the raw data does not change with every run of program, while in dynamic input, the raw data has a tendency to change in every run of program. C language does not provide any construct for input/output (I/O) operations. The I/O operations in C are handled using inbuilt functions. These functions are collectively known as standard I/O library. In this chapter, we shall discuss about C streams, and basic I/O operations and different functions, such as formatted and unformatted functions, that can be used to perform these operations.

# 4.1 C Streams

The initial programmers had a very hard time handling the I/O operations. The programs created had to explicitly identify the input device where the input would be taken from and the output device where the output would be sent to. The programmer thus, instead of concentrating on the solution of problem, also had to look for hardware-specific problems that could arise from the I/O operations. The Unix operating system provided a concept of abstract devices. This concept removed the need for a program to identify the kind of devices used.

The concept of data stream was used to provide the device abstraction. A data stream is an ordered sequence of data bytes that can be read until the end of the file. The option of the Unix operating system to support the concept of data streams provided three standard streams, namely, standard input, standard output, and standard error. Most C run-time environments provide equivalent functionality, regardless of the nowadays operating system. The standard streams are opened automatically when a C program is executed, thus making it convenient for the programmer to use them. This section gives details of the three streams mentioned.
