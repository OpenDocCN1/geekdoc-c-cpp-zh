called reallocation of memory. The realloc function, when used, changes the size of a previous allocated block of memory. The new size can be larger or smaller than the size of the previous block.

If the request is to make existing block larger in size, then the old contents remain unchanged and memory is added to the end of the block. If the size is made smaller, then the block is truncated from the end and the remaining contents are unchanged. In case the original block size cannot be resized, then the function realloc will attempt to assign a new block of memory. Here, the realloc function will copy the old block contents at new location. A new address location will consequentially be returned and assigned to the address pointer. If the realloc function fails to attempt a new memory block, then it returns NULL; in such a case, we may tend to lose the existing data. The syntax to use the function realloc is as follows:

```
ptr = realloc( ptr, newsize );
```

The preceding statement allocates contiguous memory space as per the value specified in *newsize*. For example, if initially 50 bytes have been allocated with the function malloc using following statement:

```
ptr = (char * ) malloc(50 );
```

To extend memory allocation by additional 20 bytes, the following statement can be used:

```
ptr = realloc(ptr,70 );
```

After execution of the preceding statement, the original contents will be retained and the memory block size will be increased from 50 bytes to 70 bytes. Figure 4 shows the memory representations of the bytes allocated by the compiler after the realloc function is used:
