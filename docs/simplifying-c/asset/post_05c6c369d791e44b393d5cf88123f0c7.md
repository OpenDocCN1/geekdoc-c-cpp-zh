### 5.3 Expression Evaluation in C

Till now our focus of discussion was on different operators available in C and their usage in expression. Evaluation of expression is a major concern if the statements are not properly formed. Consider the expression: `result = first * second + third / fourth – fifth`. In the preceding expression, the multiplication of identifiers `first` and `second` will be done initially, and its value will be stored in a temporary location. Then `third` will be divided by `fourth` and its value will be stored in another temporary location. The values in both the temporary locations will then be added, and finally `fifth` will be subtracted. Figure 10 shows the evaluation order of this expression:

![](img/5d422ba7108ffdf64376be51eaf0c459_112_0.png)

It can be seen in Figure 10 that if two operators with the same priority appear in an expression, they are evaluated based on their associativity, in this case left to right. To modify the sequence of evaluation, we can make use of brackets. If we rewrite the expression as `result = first + second * (third − fourth) / fifth`; then the identifiers `third` and `fourth` will be subtracted initially, resulting in intermediate result 1. The intermediate result 1 will then be multiplied with the `second`, giving intermediate result 2. The intermediate result 2 will then be divided by `fifth`. Finally, addition with the `first` will be done. Figure 11 shows the evaluation order of the new expression:

![](img/5d422ba7108ffdf64376be51eaf0c459_113_0.png)

Program 12 illustrates how expressions are evaluated in C:

#### Program 12

```c
/* Program to illustrate the evaluation of expression */

#include <stdio.h>
/* Beginning of main function */
main()
{
/* Declaration and initialization of unsigned integer variables */
unsigned int u_first = 25, u_second = 5, u_third = 15;
unsigned int u_fourth = 10, u_fifth = 12, u_result;
/* Expression without brackets */
u_result = u_first * u_second + u_third / u_fourth - u_fifth;
printf("Result of evaluation without using brackets = %d", u_result);
/* Expression with brackets */

u_result = u_first + u_second * (u_third - u_fourth) / u_fifth;
printf("\n Result of evaluation using brackets = %d \n", u_result);
return;
} /* End of function main */
```

**Output:**

Result of evaluation without using brackets = 114
Result of evaluation using brackets = 27

It can be observed in Program 12 that the output of the same expression drastically changes when brackets are used to control the evaluation. The expressions used in C language are known as C statements. The next section discusses in brief about the statement categories available in C language.

### 5.4 Statements in C Language

The expression designed from operands and operators are converted to C statements. The statements generated may or may not be executable statements. In a C program, the executable statements cause some action to be taken, while the nonexecutable statements work as comments. C Language provides us six categories of statements, as shown in Figure 12:

![](img/5d422ba7108ffdf64376be51eaf0c459_114_0.png)

▲ Figure 12: Category of C Statements

Program 9 has made use of expression, compound, selection, and iteration statements. The pictorial representation of these statements is shown in Figure 13:

![](img/5d422ba7108ffdf64376be51eaf0c459_114_1.png)

▲ Figure 13: Example of C Statements

It can be seen in Figure 13 that an expression in C program is an executable statement. Normally, the expression is converted into a C statement by terminating it with a semicolon (;). The semicolon indicates the end of statement to the compiler. All C statements that end with a semicolon are executable. A group of zero or more statements combined together in opening and closing curly braces is referred to as a compound statement. All C programs consist of a compound statement; as soon as we enclose a C program code snippet within `{ }`, it becomes a compound statement. The compound statement is not terminated by a semicolon. In case we terminate the compound statement with a semicolon, the compiler at the time of compilation will generate error.

A selective statement is one that decides which statement or set of statements are to be executed, depending on the result of a relational comparison of two expressions. An iterative statement refers to a statement that allows repetition of a code snippet to be executed again and again. Detailed discussion of labeled, jump, selection, and iteration statements has been done in later chapters.
