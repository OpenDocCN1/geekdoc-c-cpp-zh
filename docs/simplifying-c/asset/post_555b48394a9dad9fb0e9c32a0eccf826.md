
### 15.4 #undef Directive

At times it is desirable to undefine an existing macro. This can be accomplished by the `#undef` directive. For example, to undefine the macro `TRUE` defined in Program 10, the statement `#undef TRUE` can be used. Once a macro has been undefined, the identifier associated with that macro can be reused to define another macro in a subsequent `#define` directive.

C has a rich collection of directives; the next section discusses the conditional compilation directives available with C.

### 15.5 Conditional Compilation

So far we have seen that statements in a C program are executed sequentially. To change the sequence of execution, or skip some statements, or execute one set of statements on one condition and another set on another condition, we have discussed sequence control structures in Chapter 6. A preprocessor conditional compilation directive causes the preprocessor to compile portions of the source code based on conditions specified by the user. These directives test a constant expression or an identifier to determine which tokens the preprocessor should pass on to the compiler and which tokens should be bypassed during preprocessing. Table 3 lists the various directives and their purpose:

| Directive | Purpose |
| :--- | :--- |
| `#if` | The code following the `#if` directive will be executed only when the condition specified along with `#if` is true |
| `#ifdef` | To check whether the macro is defined or not |
| `#else` | To specify alternate code to be executed in case of if condition failure |
| `#ifndef` | To specify set of statements to be executed if macro is not defined |
| `#elif` | To specify alternate condition in case of if condition failure |
| `#endif` | End of if expression |

We have defined macro `CUBE` in Program 11. Program 12 illustrates the usage of `#ifdef` directive to check whether `CUBE` is defined or not. If defined, the statements following the `#if` directive will be compiled.

▶ **Program 12**

```c
/* Program to illustrate the #ifdef conditional compilation directive */
#include <stdio.h>
#define CUBE(i_x) (i_x * i_x * i_x)
#define TRUE 1

main()
{
  int i_num = 10, i_result;
  #ifdef CUBE
  i_result = 1000 / CUBE(i_num);
  #else
  i_result = 1000 / (i_num * i_num * i_num);
  #endif

  printf("The result is %d. \n", i_result);
  return;
}
```

**Output:**
```
The result is 1.
```

Similar to the `#ifdef` directive, the `#ifndef` directive can also be used within C programs. Program 13 illustrates the usage of the `#ifndef` directive to check whether or not macro `TRUE` is already defined. There is a chance of `TRUE` being defined as we have included the `stdio.h` header file. Thus, we would like to define a macro named `TRUE` only if it is undefined.

▶ **Program 13**

```c
/* Program to illustrate the usage of #ifndef directive */
#include <stdio.h>

#ifndef TRUE
#define TRUE 1
#endif

main()
{
  #ifndef TRUE
  printf("The value of TRUE is %d\n", TRUE);
  #endif

  return;
}
```

**Output:**
```
The value of TRUE is 1
```

### 15.6 #error Directive

The `#error` directive is used to diagnose compile time error messages and generate meaningful messages during debugging. The general syntax for the `#error` directive is as follows:

```c
#error error_message
```

When the `#error` directive is encountered, the error message specified in a program is displayed. Let us write a program to print a table of a number specified by a user. The programmer uses a macro named `MAX` to decide the number of iterations for printing the table. For example, if `MAX` is 5 and `i_num` is 3, 5 iterations will be printed. Therefore, the last iteration will be 3 * 5 = 15.

▶ **Program 14**

```c
/* Program to illustrate the usage of #error directive */
#include <stdio.h>

main()
{
    int i_ctr, i_num;
    printf("\n Enter the number: ");
    scanf("%d", &i_num);
    
    #ifndef MAX
    #error MAX is not defined!!!!
    #endif
    
    for (i_ctr = 1; i_ctr <= MAX; i_ctr++)
    {
        printf("\n%d * %d = %d", i_num, i_ctr, i_num * i_ctr);
    }
    printf("\n");
    return;
}
```

**Compilation Error:**
```
Prog15_14.c:13:4: #error MAX is not defined!!!!
Prog15_14.c: In function 'main':
Prog15_14.c:15: error: 'MAX' undeclared (first use in this function)
Prog15_14.c:15: error: (Each undeclared identifier is reported only once
Prog15_14.c:15: error: for each function it appears in.)
```

In Program 14, we check whether macro `MAX` is defined or not. If the statement `#ifndef MAX` is evaluated to true, the program reports an error mentioned using the `#error` directive. Otherwise, it will execute the rest of the statements within the program. Program 14, when compiled using `gcc`, will result in a compilation error as shown under the heading of "Compilation Error" in Program 14. The same program when compiled with Turbo C might give a different output.

### 15.7 Stringizing Operator

The stringizing operator, as the name implies, converts the macro parameter to a string. The sign `#` is used as a stringizing operator. When the stringize operator immediately precedes the name of one of the macro parameters, the parameter passed to the macro is enclosed within quotation marks and is treated as a string literal. Program 15 illustrates the use of the stringizing operator. It includes a macro named `MULTIPLY`, which can be used to display the multiplication of two numbers:

▶ **Program 15**

```c
/* Program to illustrate the usage of Stringizing operator */
#include <stdio.h>
#define MULTIPLY(x) printf(#x " = %d \n", x)

main()
{
    MULTIPLY(5 * 6);
    return;
}
```

**Output:**
```
5 * 6 = 30
```

It can be observed in Program 15 that the preprocessor converts the line `MULTIPLY(5 * 6)` into `printf("5 * 6" " =  %d \n", 5 * 6)`. As the stringizing operator `#` is preceding parameter `x`, the value in `x` is replaced as `"5 * 6"`. Thus, the output of the program is `5 * 6 = 30`.

### 15.8 Token-Pasting Operator

As the name suggests, the token-pasting operator allows separate tokens to be joined into a single token. If a macro definition contains an argument that has a token pasting operator prefixed or suffixed to it, then such an argument is replaced with its corresponding actual argument. The macro will only be expanded after all the token pasting operators of the macro definition are resolved. The token-pasting operator (`##`) is at times also called the merging operator. Program 16 illustrates the usage of the token pasting operator to join two strings one after another:

▶ **Program 16**

```c
/* Program to illustrate the usage of token-pasting operator */
#include <stdio.h>
#define JOIN(str1, str2) str1 ## str2

main()
{
    int i_total_quantity = 40;
    printf("Total quantity is %d", JOIN(i_total, _quantity));
    return;
}
```

**Output:**
```
Total quantity is 40
```

It can be observed in Program 16 that using the token-pasting operator, we can create a valid variable name.
