```
"/* Program to illustrate the usage of #error directive */"
#include<stdio.h>
main()
{
    int i_ctr, i_num;
    printf("\n Enter the number: ");
    scanf("%d", &i_num);
    #ifndef MAX
    #error MAX is not defined!!!!
    #endif
    for (i_ctr = 1; i_ctr <= MAX; i_ctr++)
    {
        printf("\n%d * %d = %d", i_num, i_ctr, i_num*i_ctr);
    }
    printf("\n");
    return;
}
```

In Program 14, we check whether macro MAX is defined or not. If the statement `#ifndef MAX` is evaluated to true, the program reports an error mentioned using `#error` directive. Otherwise, it will execute the rest of the statements within the program. Program 14, when compiled using `gcc`, will result into compilation error shown under the heading of compilation error in Program 14. The same program when compiled with Turbo C might give different output.

# **15.7 Stringizing Operator**

Stringizing operator, as the name implies, converts the macro parameter to a string. The sign `#` is used as a stringizing operator. When the stringize operator immediately precedes the name of one of the macro parameters, the parameter passed to the macro is enclosed within quotation marks and is treated as a string literal. Program 15 illustrates the use of stringizing operator. It includes a macro named MULTIPLY, which can be used to display multiplication of two numbers:

# ▶ Program 15

```
"/* Program to illustrate the usage of Stringizing operator */"
#include<stdio.h>
#define MULTIPLY(x) printf(#x " = %d \n", x)
```
