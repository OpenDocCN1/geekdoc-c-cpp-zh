# ▲ Figure 3: Steps for Creating and Executing a C Program

Figure 5 shows that the box of the compiler contains two different programs, namely, a preprocessor and a translator. The preprocessor takes input from the text editor and processes it to removes all the preprocessor directive statements from the source code. It then provides the processed C code to the translator, which converts the C code into an object code.

We have already mentioned earlier that many vendors have come up with C and also provide different C compilers. The usage and features of the compilers may vary from vendor to vendor, but the aforementioned sequence of creating and executing a C program remains the same. We have discussed here one approach of creating, editing, compiling, and executing a C program using GNU Compiler Collection (gcc) open-source compiler. This compiler is available for operating systems such as Windows, Unix, and Linux, and comes bundled with all Linux versions.

As mentioned earlier, we can use any good text editor to create a C program. The only thing that should be kept in mind is the fact that the file created should be saved with an extension .c. Make sure that c is in lower case. In Linux environment, we have editors such as vi, emacs, pico, and many more. Choose the one you are comfortable with. Once the program is ready, save it; for example, assume that Program 1 given in this chapter is saved as prog2_1.c, then the following command is written on the Linux prompt to compile it:

```
$ gcc prog2_1.c
```

If everything goes fine, a new prompt line will be visible. In case, we have errors, then appropriate error message would appear on the screen. If error occurs, we need to rectify the program and recompile. If no error appears, it means that the compilation is successful and an executable file with the name a.out is available in the same directory as the source file.
