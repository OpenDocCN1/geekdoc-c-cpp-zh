```
enum identifier {value 1, value 2, value 3, ......., value n};
```

where enum is the keyword. The identifier defines a new data type. Value 1 to Value n refers to the names associated with numeric constants 0, 1, 2, ...., n. The variable defined using enum can be assigned any numeric value or values given in curly brackets. An example of enum data type is as follows:

```
enum result {first, second, pass, fail};
enum result grade;
grade = first;
```

where the first statement defines enumerated data type *result*. The next statement declares a variable *grade* of type *result*. The last statement assigns value *first* to *grade*, where *first*, *second*, *pass*, and *fail* refer to the numeric constants 0, 1, 2, and 3, respectively. These numeric constants are assigned by the compiler automatically. It is possible to modify these values and assign new values. For example, if we want *first* to be equivalent to 60, *second* to be equivalent to 50, *pass* to be equivalent to 40, and *fail* to be equivalent to 30, then we may rewrite the first statement in the given example as: enum result {*first* =60, *second* =50, *pass* =40, *fail* =30}; Now, the statement *grade = first* would be equivalent to *grade = 60*. The enumerated data type variables can be assigned only the values that have been previously declared. Program 5 illustrates the usage of enumerated data type:

# ▶ Program 5

```
/* Program to illustrate the use of enumerated data type */
#include <stdio.h>

/* Beginning of main function */
main( )
{
    /* Declare new data type boolean */
    enum boolean {false,true};
    int i_number;

    /* Declare enumerated variable  flag */
    enum boolean flag;
    flag = true;

    /* Read a positive number */
    while(flag)
    {
        printf("\n Enter a number : ");
        scanf("%d",&i_number);

        /* Reset the flag */
        if(i_number >= 0)
        flag = false;
    }
    printf("\n The number entered is %d\n",i_number);
    return;
}
/* End of function main */
```
