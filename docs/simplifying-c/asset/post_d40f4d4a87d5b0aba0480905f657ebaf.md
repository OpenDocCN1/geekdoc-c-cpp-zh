The structure template for contact can be redefined as shown in Figure 11:

```c
struct contact
{
    char c_name[25];
    char c_email[30];
    unsigned long int i_phone;

    unsigned int b_phonestatus : 1;
    unsigned int b_gender : 1;
    unsigned int b_relationship : 3;
};
```

![](img/5d422ba7108ffdf64376be51eaf0c459_253_0.png)

Figure 11 shows that the number of bits required to be allocated to a data element are specified by a non-negative integer preceded by a colon.

If a series of bit fields defined in a sequence does not add up to the size of an `int`, padding can take place. Thus, in the preceding case, 1 byte storage space will be occupied to store all the three data members, namely, phone status, gender, and marital status. If the bit fields were not used, the amount of storage occupied by the three data elements would be 12 bytes in case the compiler assigned 4 bytes to an integer variable. It can be seen that 11 bytes of memory space for one variable has been saved. If the number of such variables was large, the memory space saved would have been considerable.

Variables defined by using bit fields can be accessed in the same manner as other structure variable data members. However, there is one drawback in utilizing the bit fields. The bit fields cannot be assigned a value at run time using the `scanf` statement, as the format specifier does not support input of bits. Program 10 illustrates the usage of bit fields to store gender of a contact person:

# Program 10

```c
/* Program to illustrate the usage of bit fields in a structure*/
#include<stdio.h>

/* Beginning of main function */
main()
{
    /* Declaration of structure */
    struct contact
    {
        char c_name[25];
        char c_email[30];
        unsigned long int li_phoneno;
        unsigned int b_gender : 1; /* Bit field declared to store gender of a contact*/
    };

    unsigned int u_temp;
    typedef struct contact Contact;
    /* Declaring structure variables */
    Contact contact1;

    printf("Enter the information:\n");
    printf("\n Enter name: ");
    scanf("%[^\n]", contact1.c_name);

    printf("\n Enter Phone number: ");
    scanf("%ld", &contact1.li_phoneno);
    printf("\n Enter e-mail address:");
    scanf("%s", contact1.c_email);
    printf("\nEnter gender Male(0) / Female (1): ");
    scanf("%u", &u_temp);
    /* Assign value to bit field */
    contact1.b_gender = u_temp;

    printf("\nThe information you recently entered......\n");
    printf("\nName : %s", contact1.c_name);
    printf("\nPhone number : %ld", contact1.li_phoneno);
    printf("\nEmail Address : %s", contact1.c_email);
    if (contact1.b_gender == 0)
        printf("\nGender: Male\n");
    else
        printf("\nGender : Female\n");

    return;
}
/* End of function main */
```

**Output:**

```
Enter the information:

Enter name: Harshit Jain

Enter Phone number: 2341234

Enter e-mail address: harshijtjain123@rediffmail.com

Enter gender Male(0) / Female (1): 0

The information you recently entered.....

Name: Harshit Jain
Phone number: 2341234
Email Address: harshijtjain123@rediffmail.com
Gender: Male
```

In Program 10, we have defined a temporary variable u_temp to read the value of gender. The variable u_temp requires 4 bytes of memory storage. It is not possible to read a value in a bit field directly from the keyboard as no supporting format specifier is available in C language. To assign a value to the bit field, we have used the statement `contact1.b_gender = u_temp`. Once the value is assigned to `contact1.b_gender`, the variable `u_temp` is no longer required. The data member `contact1.b_gender` can now be used in any expression. In Program 10, we are comparing the value of `contact1.b_gender` with 0 to indicate whether the person is male or female.

Note that only the data element with the int data type can be converted to bit field element. For other data type specifiers, the bit fields will not work.
