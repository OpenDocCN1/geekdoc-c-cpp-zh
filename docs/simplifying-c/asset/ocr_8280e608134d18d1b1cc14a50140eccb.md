# 3.5 Void Pointers

Pointer variables are special as they can be defined as void data type initially and then made to point to any specific data type as per the need of the user. The concept of void pointers comes in very handy when the user allocates memory to variables at run time (concept of dynamic memory allocation discussed in Chapter 14 of this book). Program 7 illustrates the use of void pointers:

# ▶ Program 7

```
/* Program to illustrate the use of void pointer */
#include <stdio.h>
/* Beginning of main function */
main()
{
    /* Declare variables */
    int i_num;
    float f_num;
    void *v_ptr;
    /* Read data in i_num */
    printf("\nEnter a number: ");
    scanf("%d",&i_num);
    /* Assign address of i_num to v_ptr */
    v_ptr = &i_num;
    /* Print the value using pointer */
    printf("\nThe number stored in i_num is %d\n",*(int *)v_ptr);
    /* Read data in f_num */
    printf("\nEnter a number: ");
    scanf("%f",&f_num);
    /* Assign address of f_num to v_ptr */
    v_ptr = &f_num;
    /* Print the value using pointer */
    printf("\nThe number stored in f_num is %f\n",*(float *)v_ptr);
    return;
} /* End of function main */
```

**Output:**

Enter a number: 55
The number stored in i_num is 55
Enter a number: 75.55
The number stored in f_num is 75.550003

It can be seen in Program 7 that we have declared a void pointer variable named v_ptr. This pointer is first assigned the address of variable i_num. In the printf statement, it is then type casted (concept discussed in Chapter 5 of this book) and dereferenced to get the value of integer variable. The same variable is then reassigned the address of float variable and used to print its value.
