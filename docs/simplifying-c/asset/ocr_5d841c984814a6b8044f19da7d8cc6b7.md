| stdio.h | fputc(ch,fl) | int | Puts a single character at the position pointed by file pointer fl. |

| stdio.h | putc(ch,fl) | int | Puts a single character in the file fl |
| stdio.h | putchar(ch) | int | Puts a single character onto the standard output device. |
