## 01 Introduction to Logic Development

### **OBJECTIVES**

- Describe Steps for Solving Problem
- Describe Techniques of Solving Problem

Nowadays, computers are capable of solving numerous problems. The problems can be as simple as adding two numbers or as complex as launching a missile. People who use computers most of the time assume that a computer does all the work on its own; however, it is not true. Any problem whose solution is not known cannot be solved using a computer. A computer only works on the set of instructions given to it by a programmer. If it does not understand any of the given instructions, the solution may go haywire. Hence, the sole responsibility of devising a solution to the problem lies in the hands of the programmer. This chapter discusses a general approach of solving a problem and various techniques used to reach a solution of any given problem.

### 1.1 Steps for Solving Problem

As mentioned earlier, it is humans who solved the problems, not the computers. A computer simply assists us in solving the problems faster. Irrespective of the type and complexity of problems, we need to follow the steps mentioned below to solve them:

- Define the problem
- Identify the input, output, and constraints
- Find various alternative solutions
- Select the best possible alternative
- Prepare detailed stepwise result for the identified alternative
- Compute the required result using the identified set of instructions
- Check the correctness of the answer obtained

These steps, though look simple, require a good amount of efforts from the user while devising. The steps 1 through 5 are all performed by the user. The work of a computer comes into picture only in the 6th and 7th steps. This simply suggests that the critical part of achieving the solution to a problem is done by the user.

Let's take an example of a problem. Assume that we need to know whether Mr. Mohit Arolkar is eligible to vote in assembly elections for India or not. To get an answer to the preceding problem, knowledge of two things is important: the current age and citizenship status of Mr. Mohit Arolkar. Therefore, two main inputs to solve the given problem would be current age and citizenship status. If the current age and citizenship status are provided to the computer through instruction, the solution is applicable for any person irrespective of the name of that person. The output of the solution will always be whether a person is eligible to vote or not eligible to vote in the assembly elections. The only constraint to this solution is that it will work within the states of India, but not in other countries, as other countries have different eligibility criteria for voters.

### 1.2 Techniques of Solving Problem

Now, we know that to solve a problem using a computer, first we need to develop a manual solution. The solution can be devised using various techniques, of which three most commonly used techniques are as follow:

- Representing a solution as pseudocode
- Drawing a flowchart
- Writing an algorithm

Users can use any of these techniques to solve a problem manually as per their convenience. Let’s discuss about these techniques in brief in the following subsections.

#### Representing a Solution as Pseudocode

It is always easier to express thoughts using one’s mother tongue. For example, if someone scribbles few steps to solve the problem of voting eligibility in Hindi, Gujarati, Marathi, or English language, then it could be considered as pseudocode. The term pseudo is a Greek word, which means false or fake. Hence, the term pseudocode means writing a fake code in any language that is spoken across the globe. This code is written in a manner such that in times of need, it can be converted into a program source code of any desired programming language.

However, solutions to large problems tend to become complex and lengthy. In addition, natural language statements have the tendency to generate multiple meanings per statement, and the pseudocode can be misinterpreted if read by persons other than the person who wrote it. The pseudocode for the problem of voting eligibility is as follows:

```
Get current age and citizenship status of Mr. Mohit Aroklar
If current age is equal to or greater than 18, and citizenship status is equal to Indian
Then Mr. Mohit Aroklar is eligible to vote in the assembly elections
Else Mr. Mohit Aroklar is NOT eligible to vote in the assembly elections
```

It can be observed that the statements have formed a logical sequence. This sequence can be mapped to any formal language (that is, programming language) after knowing the syntax of the language.

#### Drawing a Flowchart

A flowchart is a pictorial representation of a sequence of steps to be performed for solving a given problem. It uses a fixed set of symbols to represent various types of instructions. These symbols are joined by a solid line having arrows that show the flow of the statements. Flowcharts are probably the best tool to solve the problem manually as they could be drawn by anybody having the knowledge of the symbols. The flowchart is normally prepared as a first step toward the solutions of the problem. The logic and the flow of a problem can be easily understood from a flowchart.
