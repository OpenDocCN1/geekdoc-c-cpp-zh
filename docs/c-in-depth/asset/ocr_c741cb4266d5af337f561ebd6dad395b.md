```
int year;
printf("Enter year : ");
scanf("%d",&year);
if(year%100==0)
{
    if(year%400==0)
        printf("Leap year\n");
    else
        printf("Not leap\n");
}
else
{
    if(year%4==0)
        printf("Leap year\n");
    else
        printf("Not leap\n");
}
```

Note that we can write this program using a single if condition and && and || operators.

```
if(year%4==0 && year%100!=0 || year%400==0)
    printf("Leap year\n");
else
    printf("Not leap\n");
```
