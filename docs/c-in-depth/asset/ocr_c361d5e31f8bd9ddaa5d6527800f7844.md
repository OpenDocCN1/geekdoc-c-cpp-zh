# 10.5 Assignment of Structure Variables

We can assign values of a structure variable to another structure variable, if both variables are defi of the same structure type. For example-

```
```c

    char name[20];
    int rollno;
    float marks;
}
main()
{
    struct student stu1={"Oliver",12,98};
