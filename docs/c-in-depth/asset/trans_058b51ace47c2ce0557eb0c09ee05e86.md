## C 语言深入解析
本书在不损害文本和程序清晰性的前提下深入讲解每个主题。这种方法使本书既适合新手也适合高级程序员。结构良好的程序易于初学者理解，对经验丰富的程序员也有用。本书包含约 300 个程序、210 道练习题和 80 道编程练习，并附有解答和解题提示。本版新增了五章。关于项目开发和库创建的章节可以帮助学生实践所学知识，成为一名出色的 C 程序员。
