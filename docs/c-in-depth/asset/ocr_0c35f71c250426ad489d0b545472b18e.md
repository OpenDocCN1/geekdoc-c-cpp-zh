In all the three cases the compiler reserves space only for a pointer variable inside the function. In the function call, the array name is passed without any subscript or address operator. Since array name represents the address of first element of array, hence this address is assigned to the pointer variable in the function. So inside the function we have a pointer that contains the base address of the array.

In the above program, the argument a is declared as a pointer variable whose base type is int, and it is initialized with the base address of array arr. We have studied that if we have a pointer variable containing the base address of an array, then we can access any array element either by pointer notation or subscript notation. So inside the function, we can access any iᵗʰ element of arr by writing *(a+i) or a[i]. Since we are directly accessing the original array hence all the changes made to the array in the called function are reflected in the calling function.
