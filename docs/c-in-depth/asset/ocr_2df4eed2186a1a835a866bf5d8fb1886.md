Here if d = 2, m = 5 then the control will go in case (5-1), and since there is no break, all statements of cases 4, 3, 2, 1 will be executed. Hence j = 2+30+31+28+31 = 122. This shows that the flexibility of switch statement according to the need and logic of the program.
