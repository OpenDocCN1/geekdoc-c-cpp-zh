```c
#include<stdio.h>
main( )
{
char ch;
printf("Enter an alphabet : ");
scanf("%c", &ch);
switch(ch)
{
case 'a':
case 'e':
case 'i':
case 'o':
case 'u':
printf("Alphabet is a vowel\n");
break;
default:
printf("Alphabet is a consonant\n");
}
}
```
```

In this program, if someone enters a vowel in upper case then it will be regarded as a consonant. One solution to this problem is to add 5 more cases for upper case vowels. But we can solve this problem in another way without adding any cases. We have studied earlier that switch expression can be a function call returning an int or char. So change the switch expression to tolower(ch) and now our problem will be solved. tolower() is a library function which converts upper case to lower case, header ctype.h has to be included to use this function.
```
