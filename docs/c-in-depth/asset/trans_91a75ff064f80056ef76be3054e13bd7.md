## 问题 8

编写一个函数，将字符串转换为整数（字符串包含十进制数制中的整数）。

```c
/*P9.30*/
#include<stdio.h>
#include<string.h>
main()
{
    char str[20];
    printf("Enter a number : ");
    scanf("%s",str);
    printf("%d\n",str_to_i(str));
}
int str_to_i(char str[])
{
    int i,num=0;
    if(str[0]=='-')
        i=1;
    else
        i=0;
    while(i<strlen(str))
        num=num*10+(str[i++]-48);

    if(str[0]=='-')
        return -num;
    else
        return num;
}
```
