The nodes of a linked list are not stored contiguously in memory. In array list we could perform the operations using the array name. In the case of linked list, we'll perform all the operations w the help of a pointer that points to the first node the linked list. This pointer is generally named s and it is the only source through which we can access our linked list. The list will be considered em if the pointer start contains NULL value.
