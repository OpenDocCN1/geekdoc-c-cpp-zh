Now we can perform masking operations to manipulate the different flags like this-

```
*To switch on error flag*/
flags=flags|_F_ERR;

*To switch off write flag*/
flags&=~F_WRIT;

*To toggle incoming flag*/
flags=flags^_F_IN;

*To test EOF flag*/
if((flags&_F_EOF)==0)
printf("EOF flag is not set ");
else
printf("EOF flag is set ");
```
