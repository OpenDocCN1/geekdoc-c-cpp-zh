(14) a = 10, b = 5

Since the precedence of assignment operator is less than that of conditional operator so the conditional statement is interpreted as- ( a?b?max = a : max) = b;
Now this statement reduces to statement 10 a?b?max = a : max = b; which results in an error. So the solution is to put parentheses around the third operand as- a?b?max = a : (max = b);
