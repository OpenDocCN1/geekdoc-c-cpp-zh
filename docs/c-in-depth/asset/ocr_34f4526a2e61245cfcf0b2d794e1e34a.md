# 11.12.2 fread()

Declaration: size_t fread(void *ptr, size_t size, size_t n, FILE *fptr);

Here ptr is a pointer which points to the block of memory which receives the data read from the file, size is the length of each item in bytes, n is the number of items to be read from the file and fptr is a file pointer which points to the file from which the data is read.

On success it reads n items from the file and returns n, if error or end of file occurs then it returns a value less than n. We can use feof() and ferror() to check these conditions.
