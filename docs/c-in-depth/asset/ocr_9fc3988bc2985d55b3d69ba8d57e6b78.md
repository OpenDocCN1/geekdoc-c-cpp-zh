# ## 2.12 Comments

Comments are used for increasing readability of the program. They explain the purpose of the program and are helpful in understanding the program. Comments are written inside /* and */. There can be a string constant or a character constant.

Some examples of comments are

```
/*Variable b represents basic salary*/
```

(single line comment)

```
/*This is a C program to calculate simple interest */
```

(multiple line comment)

Comments can't be nested i.e. we can't write a comment inside another comment.
