Here pa is declared as an array of pointers. Every element of this array is a pointer to an integer. pa[i] gives the value of the iᵗʰ element of ‘pa’ which is an address of any int variable and *pa[i] gives the value of that int variable.

The array of pointers can also contain addresses of elements of another array.

```
/*P8.24 Program for understanding array of pointers*/
#include<stdio.h>
main()
{
    int i,arr[4]={5,10,15,20};
    int *pa[4];
    for(i=0;i<4;i++)
        pa[i] = &arr[i];
    for(i=0;i<4;i++)
    {
        printf("pa[%d] = %u\t",i,pa[i]);
        printf("*pa[%d] = %d\n",i,*pa[i]);
    }
}
```
