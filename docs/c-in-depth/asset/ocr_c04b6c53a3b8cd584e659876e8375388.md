(20) In this program we'll get the error of misplaced else. Since x <= y is true, so MACRO(x) will be expanded as-
if (x<=y)
    if (x<=5) printf("x = %d\n",x);;
else
    if (y<=5) printf("y = %d\n",y);;
The double semicolons cause the problem. A single semicolon is considered as a null statement so there are two statements in the if part, but they are not inside parentheses. So to compile this program correctly, we'll have to remove one semicolon from the macro expansion or from the macro call, or we may enclose the macro call inside parentheses.
