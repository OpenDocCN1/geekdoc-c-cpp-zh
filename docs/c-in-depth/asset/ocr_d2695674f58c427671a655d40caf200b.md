The link of second node should point to first node hence
p2->link = p1;
Now we will traverse the linked list with p3 pointer and shift pointers p1 and p2 forward. We p1 to the link part of p2, so that link of each node will now point to its previous node.

```
p2->link=p1;
while(p3!=NULL)
{
    p1=p2;
    p2=p3;
    p3=p3->link;
    p2->link=p1;
}
```

When this loop will terminate p3 will be NULL, p2 will point to last node, and link of each noc now point to its previous node. Now start should point to the last node of the linked list, which node of reversed linked list.
start = p2;
