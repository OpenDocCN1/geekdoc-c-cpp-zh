# Problem 3

Write a program to enter any string and print it in reverse order.

```
/*9.25 Program to enter any string and print it in reverse order.*/
#include<stdio.h>
main()
{
char str[20];
int len;
printf("Enter any string : ");
scanf("%s",str);
len=strlen(str)-1;
while(len>=0)
{
printf("%c",str[len]);
len--;
}
printf("\n");
}
```
