# # 5.2.1 Nesting of if...else

We can have another if...else statement in the if block or the else block. This called nesting of if...else statements. Here is an example of nesting where we have if...else inside both if block and else block.

```
```c
if(condition 1)
{
if(condition 2)
statementA1;
else
statementA2;
}
else
{
if(condition 3)
statementB1;
else
statementB2 ;
}
