## 11.13 rewind()

Declaration: `rewind(FILE *fptr);`

该函数用于将文件位置指针移动到文件的开头。这里 `fptr` 是 FILE 类型的指针。`rewind()` 函数在打开文件进行更新时很有用。

使用 `rewind(fptr)` 等价于 `fseek(fptr, 0L, 0)`。
