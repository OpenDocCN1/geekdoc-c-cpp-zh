Elements of C

Every language has some basic elements and grammatical rules. Before understanding programming, it must be known the basic elements of C language. These basic elements are character set, variables, datatypes, constants, keywords (reserved words), variable declaration, expressions, statements etc. All of these are used to construct a C program.



The characters that are used in C programs are given below-
