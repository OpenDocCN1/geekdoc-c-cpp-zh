# Pointers

```
void func(char,void(*fp)(float));
void funl(float);
printf("Function main() called\n");
func('a',funl);
```

Here () is a function which accepts two arguments, a char and a function pointer. This function pointer can point to any function that accepts a float and returns nothing. The function pointer can be sent as second argument to the function func(). The function main() calls function func() while the function func() calls funl() indirectly using function pointer. Now we'll write the same program and this time we'll send a pointer that contains the address of function funl().

```
void func(char,void(*fp)(float));
void funl(float);
void (*p)(float);
p=funl;
printf("Function main() called\n");
func('a',p);
void func(char b,void (*fp)(float)) /*Value of p stored in fp*/
{
printf("Function func() called\n");
(*fp)(8.5); /*Calling funl indirectly using pointer*/
}
void funl(float f)
{
printf("Function funl() called\n");
}
```

Output:
Function main() called
Function func() called
Function funl() called
