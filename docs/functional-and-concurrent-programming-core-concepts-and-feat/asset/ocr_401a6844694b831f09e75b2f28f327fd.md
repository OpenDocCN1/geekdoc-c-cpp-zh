Lists can contain elements that are themselves lists. A list of lists can be flattened by repeated concatenation:

```
flatten(List(List(1, 2, 3), Nil, List(4, 5), List(6))) // List(1, 2, 3, 4, 5, 6)
List(1, 2, 3) ::: Nil ::: List(4, 5) ::: List(6)      // List(1, 2, 3, 4, 5, 6)
```

# Figure 7.5 Recursive strategy for function flatten.

The list returned by function flatten begins with the elements of the first inner list and continues by concatenation with the result of flattening the tail (Figure 7.5):

```
flatten(list) = concat(head(list), flatten(tail(list))
```

The actual implementation mimics the equality, adding only a special consideration for the empty list:

```
def flatten[A](list: List[List[A]]): List[A] = list match
  case Nil          => Nil
  case head :: tail => concat(head, flatten(tail))
```

# Listing 7.11: Recursive implementation of list flattening.

Note the signature of the function, from List[List[A]] to List[A], since it makes sense only for nested lists.

```
zip(List(A, B, C), List(1, 2, 3)) // List((A,1), (B,2), (C,3))
```
