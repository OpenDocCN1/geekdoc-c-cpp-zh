# 8.2 Sets of Integers as Binary Search Trees

A proper implementation of mappings as binary search trees would define a tree type parameterized by the types of keys and values, and by some notion of ordering on the type used for keys. To keep the code clear, this case study does not use type or ordering parameterization: Keys are integers, compared by their natural order. Furthermore, all the apropos algorithms and implementing functions are centered on keys, not values—stored values are not relevant to the discussion of recursion. Accordingly, the code ignores values and stores only keys, thus implementing a set of keys instead of a mapping from keys to values.
