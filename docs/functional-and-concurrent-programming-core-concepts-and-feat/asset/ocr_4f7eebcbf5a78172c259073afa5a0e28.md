# 2.8 Optional Arguments

Optional arguments are another feature that is available in many languages. They allow programmers to specify a default value for an argument, making this argument optional when you apply the function:

```
```scala
def formatMessage(msg: String,
    user: String = "",
    withNewline: Boolean = true): String =
    val sb = StringBuilder()
    if user.nonEmpty then sb.append(user).append(": ")
    sb.append(msg)
    if withNewline then sb.append("\n")
    sb.result()
```
```

Listing 2.6: Example of a function with default values for some of its arguments.

In this function, the user string defaults to the empty string, and the withNewline flag defaults to true. All of the following are valid calls of this function:

```
```scala
formatMessage("hello") // "hello\n"
formatMessage("hello", "Joe") // "Joe: hello\n"
formatMessage("hello", "Joe", false) // "Joe: hello"
```
```

# 2.9 Named Arguments

You may have a need to invoke the formatMessage function to format a message with no user and no newline:

```
```scala
formatMessage("hello", false) // rejected by the compiler
```
```

This does not work because the function expects a string as the second argument, not the Boolean false, which should be the third argument. To get around this difficulty, you need to specify the name of the argument explicitly:

```
```scala
formatMessage("hello", withNewline = false) // "hello"
```
