# Replacing a Pattern with Another Pattern in a String

The replacement operation is used to replace the pattern p1 by another pattern p2. This is done by writing REPLACE(text, pattern1, pattern2). For example,

("AAABBBBCCC", "BBB", "X") = AAAXCCC
("AAABBBBCCC", "X", "YYY") = AAABBBYCCC

+   Step 1: [INITIALIZE] SET POS = INDEX(TEXT, P1)
+   Step 2: SET TEXT = DELETE(TEXT, POS, LENGTH(P1))
+   Step 3: INSERT(TEXT, POS, P2)
+   Step 4: EXIT
