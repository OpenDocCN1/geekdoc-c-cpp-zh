When calculating the efficiency of the Johnson's algorithm, we see that the data is processed as one observation at a time, thereby taking O(n) time where n is the volume of the data. Then the data must be sorted which will again take at least O(n x log n) time. Since, O(n x log n) term dominates. Johnson's algorithm gives an optimal schedule in O(n log n) time.
