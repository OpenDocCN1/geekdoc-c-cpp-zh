# Examples of Expressions Using the Precedence Chart

If we have the following variable declarations:
int a = 0, b = 1, c = -1;
float x = 2.5, y = 0.0;

then,

+   (a) a && b = 0
+   (b) a < b && c < b = 1
+   (c) b + c || ! a
+       = ( b + c ) || !(a)
+       = 0 || 1
+       = 1
+   (d) x * 5 & 5 || ( b / c )
+       = ((x * 5) & 5) || ( b / c )
+       = (12.5 & 5) || (1/-1)
+       = 1
+   (e) a <= 10 && x > 1 && b
+       = ((a <= 10) && (x > 1)) && b
+       = (1 && 1) && 1
+       = 1
+   (f) !x || !c || b + c
+       = ((!x) || (!c)) || (b + c)
+       = (0 || 0) || 0
+       = 0
+   (g) x * y < a + b || c
+       = ((x * y) < (a + b)) || c
+       = (0 < 1) || -1
+       = 1
+   (h) x > y || !a || c++
+       = ((x > y) || (!a)) || (c++)
+       = (1 + 1) || 0
+       = 1
