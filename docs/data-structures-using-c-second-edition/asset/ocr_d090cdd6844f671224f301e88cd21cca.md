The insertion operation inserts a string s in the main text τ at the kth position. The general syntax of this operation is INSERT(text, position, string). For example, INSERT('XYZYZY', 3, 'AAA') = 'XYZAAAZYZ'". Figure 4.9 shows an algorithm to insert a string in a given text at the specified position. This algorithm first initializes the indices into the string to zero. From Steps 3 to 5, the contents of NEW_STR are built up. If τ is exactly equal to the position at which the substring has to be inserted, then the inner loop copies the contents of the substring into NEW_STR. Otherwise, the contents of the text are copied into it.
