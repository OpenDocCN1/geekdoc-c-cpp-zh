This means, if a tree τ has 10,000,000 nodes, then its height is 21.

# Extended Binary Trees

A binary tree τ is said to be an extended binary tree (or a 2-tree) if each node in the tree has either no child or exactly two children. Figure 9.8 shows how an ordinary binary tree is converted into an extended binary tree.

In an extended binary tree, nodes having two children are called internal nodes and nodes having no children are called external nodes. In Fig. 9.8, the internal nodes are represented using circles and the external nodes are represented using squares.

Figure 9.8 (a) Binary tree and (b) extended binary tree

To convert a binary tree into an extended tree, every empty sub-tree is replaced by a new node. The original nodes in the tree are the internal nodes, and the new nodes added are called the external nodes.

# Representation of Binary Trees in the Memory

In the computer's memory, a binary tree can be maintained either by using a linked representation or by using a sequential representation.

# Linked representation of binary trees

In the linked representation of a binary tree, every node will have three parts: the data element, a pointer to the left node, and a pointer to the right node. So in C, the binary tree is built with a node type given below.

```
```c
struct node {
    struct node *left;
    int data;
    struct node *right;
};
```
```
