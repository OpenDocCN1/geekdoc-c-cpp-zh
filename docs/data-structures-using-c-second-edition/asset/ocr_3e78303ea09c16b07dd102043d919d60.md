# Example 2.2 Show that $400n^3 + 20n^2 = O(n^3)$.

Solution By definition, we have $0 \le h(n) \le cg(n)$ Substituting $400n^3 + 20n^2$ as $h(n)$ and $n^3$ as $g(n)$, we get $0 \le 400n^3 + 20n^2 \le cn^3$ Dividing by $n^3$ $0/n^3 \le 400n^3/n^3 + 20n^2/n^3 \le cn^3/n^3$ $0 \le 400 + 20/n \le c$ Note that $20/n \to 0$ as $n \to \infty$, and $20/n$ is maximum when $n = 1$. Therefore, $0 \le 400 + 20/1 \le c$ This means, $c = 420$ To determine the value of $n_0$, $0 \le 400 + 20/n_0 \le 420$ $-400 \le 400 + 20/n_0 - 400 \le 420 - 400$ $-400 \le 20/n_0 \le 20$ $-20 \le 1/n_0 \le 1$ $-20 \cdot n_0 \le 1 \le n_0$. This implies $n_0 = 1$. Hence, $0 \le 400n^3 + 20n^2 \le 420n^3 \forall n \ge n_0=1$.

# Example 2.3 Show that $n = o(n \log n)$.

Solution By definition, we have $0 \le h(n) \le cg(n)$ Substituting $n$ as $h(n)$ and $n \log n$ as $g(n)$, we get $0 \le n \le c n \log n$ Dividing by $n \log n$, we get $0/n \log n \le n/n \log n \le c n \log n / n \log n$ $0 \le 1/\log n \le c$ We know that $1/\log n \to 0$ as $n \to \infty$ To determine the value of $c$, it is clearly evident that $1/\log n$ is greatest when $n=2$. Therefore, $0 \le 1/\log 2 \le c = 1$. Hence, $c = 1$. To determine the value of $n_0$ we can write $0 \le 1/\log n_0 \le 1$ $0 \le 1/\log n_0$ Now, $\log n_0 = 1$, when $n_0 = 2$. Hence, $0 \le n \le c n \log n$ when $c=1$ and $\forall n \ge n_0=2$.

# Example 2.4 Show that $10n^3 + 20n \neq o(n^3)$.

Solution By definition, we have $0 \le h(n) \le cg(n)$ Substituting $10n^3 + 20n$ as $h(n)$ and $n^3$ as $g(n)$, we get $0 \le 10n^3 + 20n \le cn^3$ Dividing by $n^2$ $0/n^3 \le 10n^3/n^2 + 20n/n^2 \le cn^3/n^2$ $0 \le 10n + 20/n \le c$ $0 \le (10n^3 + 20n)/n \le c$ Hence, $10n^3 + 20n \neq o(n^3)$
