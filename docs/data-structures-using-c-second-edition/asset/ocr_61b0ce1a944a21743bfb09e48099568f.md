The C code to handle Case 4 is as follows:

```
void del_case4(struct node *n)
{
    struct node *s;
    s = sibling(n);
    if ((n -> parent -> color == RED) && (s -> colour == BLACK) &&
    (s -> left -> colour == BLACK && (s -> right -> colour == BLACK))
    {
        s -> colour = RED;
        n -> parent -> colour = BLACK;
    } else
        del_case5(n);
}

Case 5: N is the Left Child of P and S is Black, S's Left Child is Red, S's Right Child is Black. In this case, perform a right rotation at s. After the rotation, s's left child becomes s's parent and n's new sibling. Also, interchange the colours of s and its new parent. Note that now all paths still have equal number of black nodes, but n has a black sibling whose right child is red, so we fall into Case 6. Refer Fig. 10.63.

The C code to handle case 5 is given as follows:

```
void del_case5(struct node *n)
{
    struct node *s;
    s = sibling(n);
    if (s -> colour == BLACK)
    {
        /* the following code forces the red to be on the left of the left of the parent,
        or right of the right, to be correctly operated in case 6. */
        if ((n == n -> parent -> left) && (s -> right -> colour == BLACK) && (s -> left
        -> colour == RED))
        {
            rotate_right(s);
        }
        else if ((n == n -> parent -> right) && (s -> left -> colour == BLACK) && (s ->
        right -> colour == RED))
            rotate_left(s);
    }
}
