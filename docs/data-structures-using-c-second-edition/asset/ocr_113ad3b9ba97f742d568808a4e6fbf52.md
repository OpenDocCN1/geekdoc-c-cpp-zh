# 2. Write a program to convert the lower case characters of a string into upper case.

```
#include <stdio.h>
#include <conio.h>
int main()
{
   char str[100], upper_str[100];
   int i=0;
   clrscr();
   printf("\n Enter the string :");
   gets(str);
   while(str[i] != '\0')
   {
      if(str[i]>='a' && str[i]<='z')
         upper_str[i] = str[i] - 32;
      else
         upper_str[i] = str[i];
      i++;
   }
   upper_str[i] = '\0';
   printf("\n The string converted into upper case is : ");
   puts(upper_str);
   return 0;
}
```

# Output

Enter the string : Hello
The string converted into upper case : HELLO

# Appending a String to Another String

Appending one string to another string involves copying the contents of the source string at the end of the destination string. For example, if s1 and s2 are two strings, then appending s1 to s2 means we have to add the contents of s1 to s2. So, s1 is the source string and s2 is the destination string. The appending operation would leave the source string s1 unchanged and the destination string s2 = s2 + s1. Figure 4.5 shows an algorithm that appends two strings.

Note The library function strcat(s1,s2) which is defined in string.h concatenates string s2 to s1.

```
Step 3: SET I = I + 1

Step 4: Repeat Steps 5 to 7 while SOURCE_STR[J] != NULL
Step 5: DEST_STR[I] = SOURCE_STR[J]
Step 6: SET I = I + 1
Step 7: SET J = J + 1
[END OF LOOP]
Step 8: DEST_STR[I] = NULL
Step 9: Exit
```
