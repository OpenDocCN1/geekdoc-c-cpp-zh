## 内容与覆盖范围

本书共分16章。

第1章 C语言简介 回顾了基本的C语言结构，帮助读者熟悉本书编写程序所需的基本C语法和概念。

第2章 数据结构与算法简介 介绍了作为创建高效程序基础的数据结构和算法。本章解释了如何计算时间复杂度，这是评估算法性能的关键概念。

从第3章开始，每一章都详细讨论单个数据结构。

第3章 数组 对一维数组、二维数组和多维数组进行了详细解释，也解释了可对这些数组执行的操作。

第4章 字符串 讨论了字符串（也称为字符数组）的概念。本章不仅关注字符串的读写，还解释了可用于操作字符数组的各种操作。

第5章 结构体与联合体 讨论了结构体和联合体。结构体是不同类型的相关数据项的集合，用于实现链表、树、图等其他数据结构。我们还将了解联合体，它也是不同数据类型变量的集合，只不过在联合体中，任何时候只能在一个字段中存储信息。

第6章 链表 讨论了不同类型的链表，如单链表、双链表、循环链表、双向循环链表、带头链表和多重链表。当需要动态分配内存时，链表是首选的数据结构。

第7章 栈 重点介绍了称为栈的后进先出（LIFO）数据结构的概念。本章还展示了使用数组和链表对这些数据结构进行实际实现。它还展示了如何使用栈来评估算术表达式。

第8章 队列 讨论了称为队列的先进先出（FIFO）数据结构的概念。本章还提供了队列的实际应用。

第9章 树 重点介绍二叉树、其遍历方案和内存表示。本章还讨论了表达式树、锦标赛树和霍夫曼树，它们都是简单二叉树的变体。

第10章 高效二叉树 在第9章讨论的树的基础上进一步深入，讨论了高效二叉树，扩大了讨论范围。本章讨论了二叉搜索树、线索二叉树、AVL树、红黑树和伸展树。

第11章 多路搜索树 探讨了单个节点中可以包含多个键值的树，如M路搜索树、B树、B+树、Trie树和2-3树。

第12章 堆 讨论了三种堆——二叉堆、二项堆和斐波那契堆。本章不仅解释了这些数据结构的操作，还进行了比较，从而突出了每种结构的关键特征。

第13章 图 包含对称为图的非线性数据结构的详细探讨。它讨论了图的内存表示、遍历方案以及图在现实世界中的应用。

第14章 搜索与排序 涵盖了计算机科学中最常见的两种操作，即搜索和排序值列表。它给出了不同搜索和排序技术的技术、复杂度和程序。

第15章 哈希与冲突 讨论了不同的哈希方法和解决冲突的技术。

第16章 文件及其组织 是本书的最后一章，讨论了与文件组织相关的概念。它解释了硬盘上文件的不同组织方式以及可用于快速检索数据的索引技术。

本书还提供了一套七个附录。

附录A 介绍了C程序中动态内存分配的概念。

附录B 简要讨论了用于自动内存管理的垃圾回收技术。

附录C 解释了回溯法，这是一种使用栈的递归算法。

附录D 讨论了Johnson算法，该算法用于需要确定不同活动最优执行顺序的应用中。

附录E 包含两个C程序，展示了如何读写二进制文件。

附录F 包含一个C程序，展示了如何使用地址计算排序对数字列表进行排序。

附录G 提供了所有客观题的按章节答案。
