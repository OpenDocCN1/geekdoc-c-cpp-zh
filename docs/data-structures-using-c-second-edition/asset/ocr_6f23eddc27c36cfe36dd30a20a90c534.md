+   • There is a path from v_i to v_k and a path from v_k to v_j where all the nodes use v_1, v_2, ..., v_k. Therefore, P_{k,i}[1][k] = 1 AND P_{k,i}[k][j] = 1

Hence, the path matrix P_n can be calculated with the formula given as:

P_n[i][j] = P_{n-1}[i][j] V (P_{n-1}[i][k] ^ P_{n-1}[k][j])

where v indicates logical or operation and ^ indicates logical AND operation.
