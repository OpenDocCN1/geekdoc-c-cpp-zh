# Figure 9.1: Identity

As the last assertion demonstrates with ReferenceEquals(), serial Number1 and serialNumber3 are not the same reference. However, the code constructs them with the same values and both are logically associated with the same physical product. If one instance was created from data in the database and another was created from manually entered data, you would expect that the instances would be equal and, therefore, that the product would not be duplicated (reentered) in the database. Two identical references are obviously equal; however, two different objects could be equal but not reference equal. Such objects will not have identical object identities, but they may have key data that identifies them as being equal objects.
