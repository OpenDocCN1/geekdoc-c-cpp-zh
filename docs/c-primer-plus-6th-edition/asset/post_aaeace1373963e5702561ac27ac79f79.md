## for Versus while

In C++ the for and while loops are essentially equivalent. For example, the for loop

```
for (init-expression, test-expression; update-expression)
{
    statement(s)
}
```

could be rewritten in this way:

```
init-expression;
while (test-expression)
{
    statement(s)
    update-expression;
}
```

Similarly, the while loop

```
while (test-expression)
    body
```

could be rewritten in this way:

```
for (; test-expression;)
    body
```

This for loop requires three expressions (or, more technically, one statement followed
by expressions), but they can be empty expressions (or statements). Only the two
semicolons are mandatory. Incidentally, a missing test expression in a for loop is construed
as true, this loop runs forever:

```
for (; ; )
    body
```

Because for loops and while loops are nearly equivalent, the one you use is largely
matter of style. There are three differences. As just mentioned, that an omitted
condition in a for loop is interpreted as true. The second is that you can use the initialization-statement in a for loop to declare a variable that is local to the loop; you can't do
that with a while loop. Finally, there is a slight difference when the body includes a continue
statement, which is discussed in Chapter 6. Typically, programmers use for loops

counting loops because the for loop format enables you to place all the relevant information—initial value, terminating value, and method of updating the counter—in one place. Programmers often use while loops when they don't know in advance precisely how many times a loop will execute.

### Tip

Keep in mind the guidelines when you design a loop:

- Identify the condition that terminates loop execution.
- Initialize that condition before the first test.
- Update the condition in each loop cycle before the condition is tested again.

One thing about for loops is that their structure provides a place to implement these three guidelines, helping you to remember to do so. But these guidelines apply to a while loop, too.

### Punctuation

Both for loops and while loops have bodies that consist of a single statement or the parenthesized expressions. As you've seen, a single statement can be a block, which can contain several statements. Keep in mind that braces, no indentation, define a block. Consider the following loop, for example:

The indentation tells you that the program author intended the i++ statement to be part of the loop body. The absence of braces, however, tells the compiler that the body consists solely of the first cout statement. Then the loop keeps printing the first character of the array indefinitely. The program never reaches the i++ statement because it is outside the loop.

The following example shows another potential pitfall:

```
i = 0;
while (name[i] != '\0'); // problem semicolon
{
    cout << name[i] << endl;
    i++;
}
```

In other words, the body of the loop is now a null statement—that is, followed by a semicolon. All the material in braces now comes *after* the loop and is never reached. Instead, the loop runs forever. Beware the semicolon.
