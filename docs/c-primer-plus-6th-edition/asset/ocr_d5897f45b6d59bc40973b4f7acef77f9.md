# Unbound Friend Functions to Template Classes

The bound friend functions in the preceding section are template specializations of a template declared outside a class. An int specialization gets an int function specialization, and so on. By declaring a template inside a class, you can create unbound friend functions for every function specialization is a friend to every class specialization. For unbound friends, the friend template type parameters are different from the template class parameters:

```
template <typename T>
class ManyFriend
{
    template <typename C, typename D> friend void show(C &, D &);
};
```

Listing 14.24 shows an example that uses an unbound friend. In it, the function show2(hfil, hfi2) gets matched to the following specialization:
void show2<ManyFriend<int>&, ManyFriend<int> &>
(ManyFriend<int> & c, ManyFriend<int> & d);

Because it is a friend to all specializations of ManyFriend, this function has access to the item members of all specializations. But it only uses access to ManyFriend<int> objects.

Similarly, show2(hfd, hfi2) gets matched to this specialization:
void show2<ManyFriend<double>&, ManyFriend<int> &>
(ManyFriend<double> & c, ManyFriend<int> & d);
