# The Logical AND Operator: &&

The logical AND operator, written as &&, also combines two expressions into one. The resulting expression has the value true only if both of the original expressions are true. Here are some examples:

```
5 && 4 == 4 // true because both expressions are true
5 == 3 && 4 == 4 // false because first expression is false
5 > 3 && 5 > 10 // false because second expression is false
5 > 8 && 5 > 10 // false because first expression is false
5 < 8 && 5 < 2 // true because both expressions are true
5 > 8 && 5 < 2 // false because both expressions are false
```

Because the && has a lower precedence than the relational operators, you don't need to use parentheses in these expressions. Like the || operator, the side effects act as a sequence point, so the left side is evaluated, and any effects are carried out before the right side is evaluated.
