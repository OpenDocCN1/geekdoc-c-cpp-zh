A class design attempts to separate the public interface from the specifics of the imple-\mentation. The public interface represents the abstraction component of the design. Gath-
er the implementation details together and separating them from the abstraction is
called encapsulation. Data hiding (putting data into the private section of a class) is
instance of encapsulation, and so hiding functional details of an implementation in the
private section, and the Stock class does with set_tot(). Another example of encapsulation
is the usual practice of placing class function definitions in a separate file from the class
declaration.
