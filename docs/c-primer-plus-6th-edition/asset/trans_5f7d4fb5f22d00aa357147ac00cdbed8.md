

## 数组替代方案

```
a1[-2]: 20.2 at 0x28ccc8
a3[2]: 20.2 at 0x28ccc8
a4[2]: 1.62 at 0x28cca8
```

## 程序说明

首先，注意无论我们使用的是内置数组、vector 对象还是 array 对象，我们都可以使用标准的数组记法来访问各个成员。其次，你可以从地址中看出，数组对象使用的是与内置数组相同的内存区域（在本例中为栈），而 vector 对象则存储在不同的区域（自由存储区或堆）。第三，注意你可以将一个数组对象赋给另一个数组对象。对于内置数组，你必须逐元素复制数据。

接下来，这一点值得特别注意，请看这一行：

```
a1[-2] = 20.2;
```

索引为 -2 有什么含义？请回忆它被翻译为以下形式：

```
*a1-2) = 20.2;
```

用文字表达，就是在 a1 指向的位置向后移动两个元素，并把 20.2 放在那里。也就是说，在数组之外的位置的信息。C++ 与 C 一样，不会检查越界错误。在这个特定例子中，该位置恰好落在数组对象 a3 中。另一个编译器将值 20.2 放在了 a4 中，而其他编译器可能会做出更糟糕的选择。这就是内置数组不安全行为的一个例子。

vector 和 array 对象能防止这种行为吗？如果让它们的话可以。也就是说，你仍然可以编写不安全的代码，例如以下代码：

```
a2[-2] = .5; // 仍然允许
a3[200] = 1.4;
```

然而，你有替代方案。其中之一是使用 at() 成员函数。就像你可以使用 cin 对象的 getline() 成员函数一样，你也可以使用 array 类型的对象的 at() 成员函数：

```
a2.at(1) = 2.3; // 将 2 分配给 a2[1]
```

方括号记法与 at() 成员函数之间的区别在于，如果你使用 ()，无效的索引会在运行时被捕获，程序默认情况下会中止。这种额外的检查是以增加运行时间为代价的，这就是为什么 C++ 给你选择使用哪种记法的选项。更进一步，这些类提供了使用对象的方式，可以减少意外越界错误的几率。例如，这些类具有 begin() 和 end() 成员函数，让你可以在不意外超出边界的情况下限定范围。但我们将把这一讨论留到第 16 章。

## 摘要

数组、结构和指针是三种 C++ 复合类型。数组可以在单个数据对象中保存多个相同类型的值。通过使用索引或下标，你可以访问数组中的各个元素。

结构可以在单个数据对象中保存不同类型的值，你可以使用成员运算符 (.) 来访问各个成员。结构的第一步是创建结构模板，定义结构包含哪些成员。该模板的名称或标签成为新的类型标识符。你可以声明该类型的结构。

联合可以保存单个值，但它可以是多种类型，成员名指示正在使用的是哪一种。

指针是设计用来保存地址的变量。我们说指针指向它所保存的地址。指针声明始终说明指针指向的对象类型。对指针应用解引用运算符 (*) 会得到指针所指向位置的值。

字符串是一系列以空字符结尾的字符。字符串可以用带引号的字符串表示，在这种情况下空字符被隐含理解。你可以将字符串存储在 char 数组中，或用初始化为该指针的指针到 char 来表示字符串。strlen() 函数返回字符串的长度，不包括空字符。strcpy() 函数将字符串从一个位置复制到另一个位置。使用这些函数时，需要包含 cstring 或 string.h 头文件。

C++ string 类，由 string 头文件支持，提供了一种替代的、用户友好的字符串处理方式。特别是，string 对象会自动调整大小以容纳存储的字符串，你可以使用赋值运算符来复制字符串。

new 运算符允许在程序运行时请求数据对象的内存。运算符返回其获得的内存的地址，你可以将该地址赋给指针。访问内存的唯一方式是使用指针。对于单个变量，你可以使用解引用运算符 (*) 来表示一个值。如果数据对象是数组，你可以像使用数组名一样使用指针；如果数据对象是结构，你可以使用指针解引用运算符 (*) 来访问结构成员。

指针和数组密切相关。如果 ar 是数组名，则表达式 ar[i] 或 *(ar + i)，解释为数组第一个元素的地址。因此，数组名的作用与指针相同。反过来，你可以使用带名称的记法和指针来访问由 new 分配的数组中的元素。

new 和 delete 运算符让你可以显式控制数据对象何时分配以及何时归还到内存池。自动变量在函数内声明，静态变量在函数外定义或使用 static 关键字定义，其灵活性较低。自动变量在包含它的块（通常是函数定义）进入时产生，并在块离开时失效。静态变量在程序持续期间存在。
标准模板库（STL），由 C++98 标准添加，提供了一个 vector 模板类，提供了一种替代自行实现的动态数组的方案。C++11 提供了 array 模板类，提供了一种替代固定大小内置数组的方案。
