One of the goals of object-oriented programming is to provide reusable code. When you develop a new project, particularly if the project is large, it's nice to be able to reuse code rather than to reinvent it. Employing old code saves time and it has already been used and tested, can help prevent the introduction of bugs into a program. The less you have to concern yourself with details, the better you can concentrate on overall program strategy.

Traditional C function libraries provide reliability through predefined, precompiled functions, such as strlen() and rand(), that you can use in your programs. Many vendors provide specialized C libraries that provide functions beyond those of the standard C library. For example, you can purchase libraries of database management functions and of screen control functions. However, function libraries have a limitation: Unless the vendor supplies the source code for its functions (and often it doesn't), you can't extend or modify the functions to meet your particular needs. Instead, you have to shape your program to meet the workings of the library. Even if the vendor does supply the source code, you run the risk of unintentionally modifying how a function works or of altering the relationships among library functions as you add your changes.
