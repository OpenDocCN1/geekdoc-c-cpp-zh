C++ classes are feature-rich, complex and powerful. In Chapter 10, "Objects and Classes," you began a journey toward object-oriented programming by learning to define and use a simple class. You saw how a class defines a data type by defining the type of data to be used to represent an object and by also defining, through member functions, the operations that can be performed with that. And you learned about special member functions, the constructor and the destructor, that manage creating and discarding objects made to class specification. This chapter takes you few steps further in the exploration of class properties, concentrating on design techniques rather than general principles. You will probably find some of the features covered here straightforward and a bit more obscure. To understand these new features, you should try the examples and experiment with them: What if you use a regular argument instead of a reference for this class? What if you leave something out of a destructor? Don't be afraid to make mistakes; usually you can learn more from unraveling an error than by doing something correctly but by rote. (However, dont assume that inevitably leads to incredible insight.) In the end, you'll be rewarded with a fuller understanding of how C++ works and of what C++ can do for.
