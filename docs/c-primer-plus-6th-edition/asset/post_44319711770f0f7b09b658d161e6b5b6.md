# Note

Memory allocated by new is typically freed when the program terminates. However, this is not always true. Under less robust operating systems, for example, in some circumstances a request for a large block of memory can result in a block that is not deleted automatically when the program terminates. The best practice is to use delete to free memory allocated by new.

# Initialization with the new Operator

What if you want to initialize a variable a variable as part of the dynamic memory allocation? With C++98, you can do so in some instances. C++11 expands what is possible. Let’s look first at what has been possible.

If you wish to create and initialize storage for one of the scalar built-in types, such as int or double, you can do so by following the desired type with an initialization value enclosed in parentheses:

```cpp
int *pi = new int (6); // pi set to 6
double *pd = new double (99.99); // *pd set to 99.99
```

The parentheses syntax also be used with classes having suitable constructors, but we haven't got that far yet.

To initialize an ordinary structure or an array, you need C++11 and list-initialization using braces. The new standard allows:

```cpp
struct where {double x; double y; double z};
where *one = new double {2.5, 5.3, 7.2}; // C++11
int *ar = new int {4, 4, 6, 7}; // C++11
```

With C++11, you can also use the brace initialization for single-valued variables:

```cpp
int *pin = new int {}; // pi set to 6
double *pdo = new double {99.99}; // *pd set to 99.99
```

## new: Operators, Functions, and Replacement Functions

The new and new[] operators call upon two functions:

```cpp
void* operator new(std::size_t); // used by new
void* operator new[](std::size_t); // used by new[]
```

These are named allocation functions, and are part of the global namespace. Similarly, there are deallocation functions used by delete and delete []:

```cpp
void operator delete(void*);
void operator delete[](void*);
```

They use the operator-overloading syntax in Chapter 11, "Working with Classes." The std::size_t is a typedef for some suitable integer type. A basic statement as

```cpp
int* pi = new int;
```

gets translated into something like this:

```cpp
int* pi = new(sizeof(int));
```

And the statement

```cpp
int* pa = new int[40];
```

gets translated into something like this:

```cpp
int* pa = new(40 * sizeof(int));
```

As you've seen, a statement with a new operator can also provide initialization values, so, in general, using the new operator may do more than just call the new() function. Similarly,

`delete pi;`

invokes the following function call:

`delete(pi);`

Interestingly, C++ terms these functions replaceable. That means if you have sufficient expertise and desire, you can supply replacement functions for new and delete and tailor them to meet your specific requirements. One option, for instance, is replacement functions with class scope so that they can be tailored to fit the allocation needs of a particular class. Your code would use the new operator as usual, but the new operator would call the replacement new() function.

# The Placement new Operator

Normally, the new operator has the responsibility of finding in the heap block of memory that is large enough to handle the amount of memory you request. The new operator has a variation, called placement new, that allows you to specify the location to be used. A programmer might use this feature to set up his own memory-management procedures or to deal with hardware that is accessed via a particular address or to construct objects in a particular memory location.

To use the placement feature, you first include the new header file, which provides a prototype for this version of new. Then you use new with an argument that provides the intended address. From this argument, the syntax is same as for regular new. In particular, you can use placement new without or with brackets. The following code fragment shows the syntax for using these four forms of new:

```cpp
#include <new>
struct chaff
{
    char dross[20];
    int slag;
}
char buffer1[50];
char buffer2[500];
int main() {
    chaff *p1, *p2;
    int *p3, *p4;
    // first, the regular forms of new
    p1 = new chaff; // place structure in heap
    p3 = new int[20]; // place array in heap
    // now, the two forms of placement new
    p2 = new (buffer1) chaff; // place structure in buffer1
    p4 = new (buffer2) int[20]; // place array in buffer2
```

For simplicity, this example uses static arrays to provide space for placement. This code allocates space for chaff in buffer and for an array of 20 ints. Now that you've made acquaintance with placement new, let's look at a sample program. Listing 9.10 uses both new and placement to dynamically allocate arrays. This program illustrates some differences between new and placement that we'll discuss after seeing the output.

## Listing 9.10 placement.cpp

```cpp
#include <iostream>
#include <new>
const int BUF = 50;
const int N = 5;

int main() {
    double *pd1, *pd2;
    int i;
    cout << "Calling new and placement new:\n";
    pd1 = new double[N]; // use heap
    pd2 = new (buffer) double[N]; // use buffer
    for (i = 0; i < N; i++) {
        cout << "Memory addresses:\n";
        cout << "heap: " << pd1[i] << " static: " << (void *)buffer[i] << endl;
    }
    cout << "Memory contents:\n";

        cout << pd1[i] << " at " << &pd1[i] << " ";
        cout << pd2[i] << " at " << &pd2[i] << endl;
    }

    cout << "\nCalling new and placement new second time:\n";
    double *pd3, *pd4;
    pd3 = new double[N];
    pd4 = new (buffer + N * sizeof(double)) double[N]; // overwrite old data
    for (i = 0; i < N; i++) {
        cout << "Memory contents:\n";
        for (i = 0; i < N; i++) {

            cout << pd4[i] << " at " << &pd4[i] << endl;
```

# Program Notes

The first thing to note about Listing 9.10 is that placement new p2 in the array buffer has the value 00FD9138. They are, however, of different types; p1 is pointer-to-double, whereas buffer is pointer-to-char. (By the way, that the program uses a (void *) cast for buffer; otherwise, could not display a string). Meanwhile, regular new locates the p1 array far away in memory, at location 006E4AB0, which is part of the dynamically managed heap.

The second point to note is that the second call to regular new results in finding a new block of memory—beginning at 006E4B68. But the second call to placement new results in the same block of memory being used before—that is, the block beginning at 00FD9138. The important fact here is that placement new uses the address that is passed to it; it doesn't keep track of whether location has already been used, and it doesn't search the block for unused memory. This shifts some of the burden of memory management to the programmer. For example, the third call to placement new provides an offset into the buffer array so that new memory is:

```cpp
pd2 = new (buffer + N * sizeof(double)) double[N]; // offset of 40 bytes
```
