# The typeid operator and type_info Class

The typeid operator lets you determine whether two objects are the same type. Some-what like sizeof, it accepts two kinds of arguments:

+   - The Name of a class
- An expression that evaluates to an object

The typeid operator returns a reference to a type_info object, where type_info is a class defined in the typeinfo header file (formerly typeinfo.h).The type_info class overloads the == and != operators so you can use these operators to compare types. For example, the following expression evaluates to bool true if pg points to a Magnificent(Magnificent) == and false otherwise:

```
typeid(Magnificent) == typeid(pg)
```

If pg happens to be a null pointer, the program throws a bad_type exception. This exception type is derived from the exception class and is declared in the typeinfo header file.

The implementation of the type_info class varies among vendors, but it includes a name() member that returns an implementation-dependent string that is typically (but not necessarily) the name of the class. For example, the following statement displays the string for the class of the object to the pointer pg points:

```
cout << "Now processing type " << typeid(*pg).name() << "\n";
```
