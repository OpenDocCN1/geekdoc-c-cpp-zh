The various nonstandard characters in the output vary from system to system; they are one of the reasons that StringBad deserves to be called bad. Newer compiler/operating system combinations typically abort the program before displaying the line about having -1 objects left, and some of them might report a General Protection Fault (GPF). A GPF indicates that a program tried to access a memory location forbidden to it; this is another bad sign.
