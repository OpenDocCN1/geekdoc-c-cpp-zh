# 简单变量

程序通常需要存储信息——也许是谷歌股票的当前价格、纽约市八月的平均湿度、美国宪法中最常见的字母及其相对频率，或可用的猫王模仿者的数量。为了在计算机中存储信息，程序必须跟踪三个基本属性：

- 信息存储在哪里
- 在那里保存什么值
- 存储的是什么类型的信息

到目前为止，本书示例中使用的策略是声明一个变量。声明中使用的类型描述了信息种类，而变量名在符号上表示值。例如，假设实验室主管助理 Igor 使用以下语句：

```
int braincount;
braincount = 5;
```

这些语句告诉程序它正在存储一个整数，并且名称 braincount 表示该整数的值，在本例中为 5。实质上，程序找到一块足够大的内存来容纳一个整数，记录该位置，并将值 5 复制到该位置。然后你可以在程序中稍后使用 braincount 来访问该内存。这些语句不会告诉你（或 Igor）值存储在内存中的何处，但程序也会跟踪该信息。事实上，你可以使用 & 运算符检索 braincount 在内存中的地址。你将在下一章学习该运算符，当你研究识别数据的第二种策略——使用指针时。

# 变量名

C++ 鼓励你为变量使用有意义的名称。如果一个变量表示一次旅行的费用，你应该称它为 cost_of_trip 或 costOfTrip，而不是仅仅 x 或 cot。你必须遵循简单的 C++ 命名规则：

- 名称中可以使用字符是字母字符、数字和下划线（_）字符。
- 名称中的第一个字符不能是数字。
- 大写字符被认为与小写字符不同。

# 简单变量

- 你不能为名称使用 C++ 关键字。
- 以下划线字符开头或以下划线字符后跟大写字母开头的名称保留供实现使用——即编译器及其使用的资源。以单个下划线字符开头的名称保留供实现用作全局标识符。
- C++ 对名称的长度没有限制，并且名称中的所有字符都有效。

倒数第二点与前面的几点有点不同，使用诸如 __time_stop 或 _Donut 这样的名称不会产生编译器错误；相反，它会导致未定义行为。换句话说，结果无从得知。没有编译器错误的原因是名称不是非法的，而是为实现保留以供使用。关于全局名称的部分指的是名称声明的位置；第 4 章涉及该主题。

最后一点将 C++ 与 ANSI C（C99）区分开来，后者仅保证名称的前 63 个字符有效。（在 ANSI C 中，两个名称如果前 63 个字符相同，则被视为相同，即使第 64 个字符不同。）

以下是一些有效和无效的 C++ 名称：

```
int poodle; // valid
int Poodle; // valid and distinct from poodle
int PODLE; // valid and even more distinct
Int terrier; // invalid -- has to be int, not Int
int my_star3 // valid
int _Mystars3; // valid but reserved -- starts with underscore
int 4ever; // invalid -- because starts with a digit
int double; // invalid -- double is a C++ keyword
int begin; // valid -- begin is a Pascal keyword
int __foils; // valid but reserved -- starts with two underscores evenint _the_very_best_variable_i_be_version_112; // valid
int honky-tonk; // invalid -- no hyphens allowed
```

如果你想从两个或多个词形成一个名称，规则是用下划线分隔单词，如 my_onions，或将每个词后的第一个字符大写，如 myEyeTooth。（C 老兵倾向于在 C 传统中使用下划线评分方法，而那些使得更容易看到各个单词并区分，例如 carDip 和 carRip，或 boat_sport 和 boats_port。
