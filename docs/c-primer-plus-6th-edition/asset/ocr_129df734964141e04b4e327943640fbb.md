At first glance, this looks odd because there is just one semicolon instead of two. But that's okay because for-init-statement is identified as a statement, and a statement has its own semicolon. As for for-init-statement, it's identified as either an expression-statement or a declaration. This syntax rule replaces an expression followed by a semicolon with a statement, which has its own semicolon. This boils down to that C++ programmers will be able to declare and initialize a variable in a for loop initialization, and they'll do whatever is necessary to C++ syntax and to the English language to make it possible.

There's a practical aspect to declaring a variable in for-init-statement that you should know about. A variable exists only within the for statement. That is, after the program leaves the loop, the variable is eliminated:

```
for (int i = 0; i < 5; i++))
cout << "C++ knows loops.";
cout << i << endl; // oops! i no longer defined
```
