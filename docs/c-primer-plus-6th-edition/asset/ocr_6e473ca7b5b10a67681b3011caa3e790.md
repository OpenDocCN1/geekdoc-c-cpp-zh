```

```

And here's the result:

But then the program executes the following code:

```
callme(headline2);
cout << "headline2: " << headline2 << endl;
```

Here, callme() passes headline2 by value instead of reference, and the result causes a serious problem:

String passed by value:
"Lettuce Prey"
"Lettuce Prey" object deleted, 2 left
headline2: D0*

First, passing headline2 as a function argument somehow causes the destructor to be called. Second, although passing by value is supported to protect the original argument from change, the function misses upon the original string before recognition, and some nonstandard characters get displayed. (The exact text will depend on what pens to sitting in memory).
