# set_difference()

```
template<class InputIterator1, class InputIterator2,
class OutputIterator>
Iterator set_difference(InputIterator1 first1,
Iterator1 last1, InputIterator2 first2,
Iterator2 last2, OutputIterator result);
```

```
template<class InputIterator1, class InputIterator2,
class OutputIterator, class Compare>
Iterator set_difference(InputIterator1 first1,
Iterator1 last1, InputIterator2 first2,
Iterator2 last2, OutputIterator result,
Compare comp);
```

set_difference() function constructs the set that is the difference between the ranges [first1, last1) and [first2, last2) and copies the result to the location pointed by result. The resulting range does not overlap either of the original ranges. The function returns a past-the-end iterator for the constructed range. The difference is the set that contains the elements found in the first set but not the second. The first version uses <, and the second version uses the comparison object comp to determine the order.


```
template<class InputIterator1, class InputIterator2,
class OutputIterator, class Compare>
Iterator set_symmetric_difference(
InputIterator1 first1, InputIterator1 last1,
InputIterator2 first2, InputIterator2 last2,
OutputIterator result, Compare comp);
```

set_symmetric_difference() function constructs the set that is the symmetric difference between the ranges [first1, last1) and [first2, last2) and copies the result to the location pointed by result. The resulting range does not overlap either of the original ranges. The function returns a past-the-end iterator for the constructed range. The symmetric difference is the set that contains the elements found in the first set but not in the second and the elements found in the second set but not the first. It's the same as the difference between the union and the intersection. The first version uses <, and the second version uses the comparison object comp to determine the order.
