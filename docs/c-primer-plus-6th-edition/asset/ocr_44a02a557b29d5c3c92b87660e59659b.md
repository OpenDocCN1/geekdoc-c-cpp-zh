template. Such parameters are yet another template feature addition that is used to implement the STL.

Listing 14.21 shows an example that begins with these lines:

```
template <typename T> class Thing;
class Crab
```

The template parameter is template <typename T> class Thing. Here template <typename T> is the type, and Thing is the parameter. What does this imply? Sup-pose you have this declaration:

```
Crab<King> legs;
```

For this to be accepted, the template parameter King has to be a template class declaration matches that of the template parameter Thing:

```
template <typename T>
class King {...};
```

The Crab declaration in Listing 14.21 declares two objects:

```
Thing<int> s1;
Thing<double> s2;
```

The previous declaration for legs would result in substituting King<int> for Thing<int and King<double> for Thing<double>. However, Listing 14.21 has this declaration:

```
Crab<Stack> nebula;
```

Hence, in this, Thing<int> is instantiated as Stack<int>, and Thing<double> is instantiated as Stack<double>. In short, the template parameter Thing is replaced by whatever template T is used as a template argument in declaring a Crab object.

The Crab declaration makes three assumptions about the template class represented by Thing. The class should have a push() method, and these methods should have a particular interface. The Crab can use any template class that matches the Thing type declaration and has the Stack push() and pop() methods. This chapter happens to have one such class, the Stack template defined in stacktp.h, so the example uses that.
