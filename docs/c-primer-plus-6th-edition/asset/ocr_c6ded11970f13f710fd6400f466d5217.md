```
travel_time sum(travel_time t1, travel_time t2)
{
travel_time total;

total.mins = (t1.mins + t2.mins) % M_per_hr;
total.hours = t1.hours + t2.hours +

    (t1.mins + t2.mins) / M_per_hr;

return total;
}
```

```
void show_time(travel_time t)
{
    using namespace std;
    cout << t.hours << " hours, "
         << t.mins << " minutes\n";
}
```

travel_time acts just like a standard type name; you can use it to declare variables, return types, and function types. Because variables such as total and t1 are travel_time structures, you can apply the dot membership operator to them. Note that the sum() function returns a travel_time structure, you can use it as an argument for the show_time() function. C++ functions, by default, pass arguments by value, the show_time(sum(trip, day3)) function first evaluates the sum(trip, day3) function in order to find its return value. The show_time() call then passes sum()'s return value, not the function itself, to show_time(). Here's the output of the program in Listing 7.11:

Two-day total: 10 hours, 40 minutes
Three-day total: 15 hours, 12 minutes
