## 注释
指针是 C++ 中最强大的工具之一。它们也是最危险的，因为它们允许进行不利于计算机的操作，例如使用未初始化的指针访问内存或尝试两次释放同一块内存。此外，直到你通过实践熟悉指针记法和指针概念，指针可能会令人困惑。由于指针是 C++ 编程的重要组成部分，它们将在本书的后续讨论中反复出现。本书还将多次讨论指针。希望每次接触都能让你更熟悉它们。

## 类型的组合

本章介绍了数组、结构体和指针。这些可以以各种方式组合起来，因此让我们回顾一下其中的一些可能性，从一个结构体开始：

```cpp
struct antarctica_years_end {
    int year;
    /* some really interesting data, etc. */
}
```

我们可以创建这种类型的变量：
`antarctica_years_end s01, s02, s03; // s01, s02, s03 are structures`

我们可以使用成员运算符访问成员：
`s01.year = 1998;`

我们可以创建一个指向此类结构体的指针：
`antarctica_years_end * pa = &s02;`

只要指针已被设置为有效地址，那么我们就可以使用直接成员运算符来访问成员：
`pa->year = 1999;`

我们可以创建结构体的数组：
`antarctica_years_end trio[3]; // array of 3 structures`

然后我们使用成员运算符来访问元素的成员：
`trio[0].year = 2003; // trio[0] is a structure`

这里，trio 是一个数组，但 trio[0] 是一个结构体，而 trio[0].year 是船结构体的一个成员。因为数组名是一个指针，所以我们也可以使用直接成员运算符：
`trio(opt+1)->year = 2004; // same as trio[1].year = 2004;`

我们可以创建一个指针数组：
`const antarctica_years_end * arp[3] = {&s01, &s02, &s03};`

这开始看起来有点复杂。我们如何用这个数组访问数据？
好吧，如果 arp 是一个指针数组，那么 arp[1] 必须是一个指针，我们就可以用它来使用直接成员运算符来访问成员：

```cpp
std::cout << arp[1]->year << std::endl;
```

我们可以创建一个指向它的指针：

```cpp
const antarctica_years_end **ppa = arp;
```

这里，arp 是数组的名称；因此，它是其第一个元素的地址。但这个第一个元素是一个指针，所以 ppa 必须是指向 const antarctica_years_end 的指针的指针，因此有 \\*。有几种方法可以搞乱这个声明。例如，你可以省略 const，或者一两个，调换字母，或者以其他方式破坏结构类型。以下是 C++11 版本的 auto 转换的一个实例。编译器完全清楚 arp 是什么类型，因此它可以为你推断类型：

```cpp
auto ppb = arp; // C++11 automatic type deduction
```

过去，编译器利用其对正确类型的了解来抱怨你在声明中可能犯的错误；现在它可以让你利用其知识。如何使用 ppa 来访问数据？因为 ppa 是指向结构体的指针的指针，所以可以用它使用直接成员：

```cpp
std::cout << (*ppa)->year << std::endl;
std::cout << (*ppb+1)->year << std::endl;
```

因为 ppa 指向 arp 的第一个成员，*ppa 就是第一个成员，即 &s01。所以 (*ppa)->year 是 s01 的 year 成员。在第二个语句中，ppb+1 指向下一个元素，arp[1]，即 &s02。需要括号来获得正确的关联。例如，ppa->year 将尝试对 ppa->year 应用 * 运算符，这会失败，因为 year 成员不是指针。
这真的正确吗？

清单 4.23 将前面所有的语句合并成一个简短的：

清单 4.23 mixtypes.cpp

```cpp
// mixtypes.cpp -- some combinations
#include <iostream>

struct antarctica_years_end
{
    int year;
    /* some interesting data, etc. */
};

int main()
{
  antarct_years_end s01, s02, s03;
  s01.year = 1998;
  antarct_years_end * pa = &s02;
  pa->year = 1999;
  antarct_years_end trio[3]; // array of 3 structures
  trio[0].year = 2003;
  std::cout << trio->year << std::endl;
  const antarctica_years_end * arp[3] = {&s01, &s02, &s03};
  std::cout << arp[1]->year << std::endl;
  const antarctica_years_end ** ppa = arp;
  auto ppb = arp; // C++11 automatic type deduction
  // or else use antarctica_years_end ** ppb = arp;
  std::cout << (*ppb)->year << std::endl;
  std::cout << (*(ppb+1))->year << std::endl;
  return 0;
}
```

该程序按承诺编译并运行。

## 数组的替代方案

本章前面提到 vector 和 array 模板类作为内置数组的替代方案。现在让我们简要看看它们是如何使用的，以及使用它们的一些好处。

## vector 模板类

vector 模板类与 string 类相似，因为它是一个动态数组。你可以在运行时设置 vector 对象的大小，并且可以向末尾追加新数据或在中间插入新数据。基本上，它是使用 new 创建动态数组的替代方案。实际上，vector 类确实使用 new 和 delete 来管理内存，但它会自动完成。

此时我们不会深入探讨成为模板类意味着什么。相反，我们将看看一些基本实践问题。首先，要使用 vector 对象，你需要包含头文件。其次，vector 标识符是 std 命名空间的一部分，所以你可以使用它。第三，vector 使用不同的语法来表示元素数量。第四，vector 类使用不同的语法来表示数据。以下是一些示例：

```cpp
#include <vector>
...
using namespace std;
vector<int> vi; // create a vector of ints
int n;
cin >> n;
vector<double> vd(n); // create a vector of size n
vector<double> vd = {1.1, 2.2, 3.3}; // initialize with values
```
