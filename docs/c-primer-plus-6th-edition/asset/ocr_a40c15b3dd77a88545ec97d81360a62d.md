Notice that the formal variable is type polar. When you pass a polar structure to this function, the structure contents are copied into the datas structure, and the function then uses that in its work. Because datas is a structure, the function uses the membership (dot) operator (see Chapter 4) to identify structure members.

Next, let's try something ambitious and write a function that converts rectangular coordinates to polar. We'll have the function accept a rect structure as its argument and return a polar structure to the calling function. This function includes functions from the math library, so the program has to include the cmmath header file (math.h on older systems). Also on some systems you have to tell the compiler to load the math library (see Chapter 1, "Getting Started with C++\ You can use the Pythagorean theorem to get the distance from the horizontal and vertical vertices:

```
distance = sqrt( x * x + y * y)
```

The atan2( ) function() from the math library calculates the angle from the x and y values:

(There's also an atan( ) function, but it doesn't distinguish between 180 degrees apart. That uncertainty is no more desirable in a math function than it is in a wilderness guide.)

Given these formulas, you can write the function as follows:

```
// convert rectangular to polar coordinates
polar_to_polar(rect xypos) // type polar
{
    polar answer;

    answer.distance =
    sqrt(xypos.x * xypos.x + xypos.y * xypos.y);
    answer.angle = atan2(xypos.y, xypos.x);
    return answer; // returns a polar structure
}
```
