# Summary

C++ encourages the use of multiple files in developing programs. An organizational strategy is to use a header file to define user types and provide function prototypes for functions to manipulate the user types.You should use a separate source code for the function definitions. Together, the header file and the source file define the user-defined type and how it can be used. main() and other functions using those functions can go into a third file.

C++'s storage schemes determine how long variables remain in memory (storage duration) and what parts of a program have access to them (scope and linkage). Automatic variables are those that are defined within a block, as a function body or a block within the body.They exist and are known only when the program executes statements in the block that contains them. Automatic variables may be declared using the storage class register or with no qualifier, in which case the variable is automatically automatic. The register specifier is a hint to the compiler that the variable is heavily used, but that is deprecated in C++11.

Static variables exist for the duration of a program. A variable defined outside any function is known to all functions following its definition (file scope) and is available to other files in the program (external linkage). For another file to use such a variable, that file must declare it using the extern keyword.
