# Simple Variables

The most common symbol set in the United States is the ASCII character set, described in Appendix C,"The ASCII Character Set." A numeric code (ASCII code) represents each character in the set. For example, 65 is the code for the character A, and 77 is the code for the character M. For convenience, this book assumes ASCII code in its examples. However, a C++ implementation uses whatever code is native to its host system—for example, EBCDIC (pronounced "eb-se-dik") on IBM mainframe. Neither ASCII nor EBCDIC international need that, and C++ supports a wide-character type that can hold a large range of values, such as are used by the international character set. You'll learn about the `char` type later in this chapter.

Listing 3.5 `chartype.cpp`

```
// chartype.cpp -- the char type
#include <iostream>
int main()
{
    using namespace std;
    char ch;           // declare a char variable

    cout << "Enter a character: " << endl;
    cin >> ch;
    cout << "Hola! ";
    cout << "Thank you for the " << ch << " character." << endl;
    return 0;
}
```

Here's the output from the program in Listing 3.5:
Enter a character:
M
Hola! Thank you for the M character.

The interesting thing is that you print M, not the corresponding character code, 77. Also the program prints M, not 77. If you peer into your memory, you find that 77 is the value stored in the ch variable. Magic, as it is, lies in the char type but cin and cout. These wisely facilitate conversions on your behalf. On input, cin converts the character input M to the value 77. On output, cout converts the 77 to the displayed character M; cin and cout are guided by the type of variable. If you place the same value 77 in an int variable, cout displays it as 77. (That, it displays two characters.) Listing 3.6 illustrates this point. It also shows how to write a literal in C++: Enclose the character within single quotation marks, as in 'M'. (Note that the example doesn't use double quotation marks. C++ uses quotation marks for a character and double quotation marks for a string. The cout object can handle either, but as Chapter 4 introduces the cout function, Finally the program introduces a cout feature, the cout.put() function which displays a single character.
