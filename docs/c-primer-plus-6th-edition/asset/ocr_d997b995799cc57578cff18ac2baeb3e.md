Note that the Stonew class has three constructors. They allow you to initialize a Stonew object to a floating-point number of pounds or to a combination of stone and pounds. You can create a Stonew object without initializing it:

```
Stonew blossom(132.5);    // weight = 132.5 pounds
Stonew buttercup(10, 2);   // weight = 10 stone, pounds
Stonew bubbles();             // weight = default value
```

The class doesn't really need to declare a destructor because the automatic default constructor is fine for this case. On the other hand, providing an explicit declaration prepares for the future, when you will have to define constructors.

Also the Ston class provides two display functions. One displays the weight in pounds, and the other displays the weight in stone and pounds. Listing 11.17 shows the class methods implementation. Note that each constructor assigns values to all three private members. Thus, creating a Stonew object automatically sets both representations of weight.

# Listing 11.17 stonew.cpp

```
// stonew.cpp -- Stonew methods
#include <iostream>
using std::cout;
#include "stonew.h"

// construct Stonew object from double value
Stonew::Stonew(double lbs)
{
    stone = int (lbs) / lbs_per_stn; // integer division
    pds_left = int (lbs) % Lbs_per_stn + lbs - int(lbs);
    pounds = lbs;
}
```

```
// construct Stonew object from stone, double values
Stonew::Stonew(int stn, double lbs)
{
    stone = stn;
    pds_left = lbs;
    pounds = stn * Lbs_per_stn + lbs;
}
```

```
Stonew::Stonew()             // default constructor, wt = 0
{
    stone = pounds = pds_left = 0;
}
```

```
Stonew::~Stonew()             // destructor
{
}
```
