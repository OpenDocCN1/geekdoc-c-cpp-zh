```
switch (integer-expression)
{
    case label1 : statement(s)
    case label2 : statement(s)
    ...
    default : statement(s)
}
```

A C++ switch statement acts as a routing device that tells the computer which line of
to execute next. On reaching a switch statement, a program jumps to the line
labeled with the value corresponding to the value of integer-expression. For example,
if integer-expression has the value 4, the program goes to the line that has a case 4:
label. The value integer-expression, as the name suggests, must be an expression that
reduces to an integer value. Also each label must be an integer constant. Most
often, labels are simple or char constants, such as 1 or 'q', or enumerators.
integer-expression doesn't match any of the labels, the program jumps to the line
abled. The default label is optional. If you omit it and there is no match, the
program jumps to the next statement following the switch (see Figure 6.3).

The switch statement is different from similar statements in languages as Pascal as
a very important way. Each C++ case label functions only as a label, not as a bound-
between choices. That is, if a program jumps to a particular line in a switch, it then
sequentially executes all the statements following that line in the switch unless explicitly
direct otherwise. Execution does not automatically stop at the next case.To make
execution stop at the end of a particular group of statements, you must use the break
statement. This causes execution to jump to the statement following the switch.
