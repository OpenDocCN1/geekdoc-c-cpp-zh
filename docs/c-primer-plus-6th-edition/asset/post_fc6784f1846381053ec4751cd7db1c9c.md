# Answers to Chapter Review for Chapter 10

- 1. A class is a definition of a user-defined type. A class declaration specifies how data is to be stored, and it specifies the methods (class member functions) that can be used to access and manipulate that data.

- 2. A class represents the operations you can perform on a class object with a public interface of class methods; this is abstraction. The class can use private visibility (the default) for data members, meaning the data can be accessed only through the member functions; this is data hiding. Details of the implementation, such as data representation and method code, are hidden; this is encapsulation.

- 3. A class defines a type, including how it can be used. An object is a variable or another data object, such as that produced by new, which is created and used according to the class definition. The relationship between a class and an object is the same as that between a standard type and a variable of that type.

- 4. If you create a class, you can define its methods outside the class declaration using the scope resolution operator (::). This helps organize code.

- 5. Example:
```cpp
#include <string>
class BankAccount
{
private:
    std::string name;
    double balance;
public:
    BankAccount(std::string n, double b = 0.0) : name(n), balance(b) {}
    void deposit(double amount) { balance += amount; }
    void withdraw(double amount) { balance -= amount; }
    void show() const {
        std::cout << "Account: " << name << ", Balance: " << balance << std::endl;
    }
};

int main() {
    BankAccount account("Alice", 1000.0);
    account.deposit(500.0);
    account.withdraw(200.0);
    account.show();
    return 0;
}
```

- 6. Constructors are used to initialize objects. They have the same name as the class and no return type.

- 7. Destructors are used to clean up resources when an object is destroyed. They have the same name as the class preceded by a tilde (~).

- 8. Friend functions allow external functions to access the private and protected members of a class.

- 9. Inline functions are a suggestion to the compiler to replace a function call with the actual function code to reduce overhead.

- 10. Templates allow you to write generic code that works with any type.

- 11. Encapsulation is the practice of hiding the internal details of an object and exposing only an interface.

- 12. Inheritance allows a new class (derived) to inherit properties and methods from another class (base).

- 13. Polymorphism is the ability of different objects to respond to the same function call in their own way.

- 14. Function overloading allows multiple functions to have the same name but different parameters.

- 15. Operator overloading allows you to redefine the behavior of operators for user-defined types.
