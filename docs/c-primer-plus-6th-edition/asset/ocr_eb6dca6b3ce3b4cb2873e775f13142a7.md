```
void change(const int * pt, int n);

int main()
{
    int pop1 = 38383;
    const int pop2 = 2000;

    cout << "pop1, " << pop1 << ", " << pop2 << endl;
    change(&pop1, -103);
    change(&pop2, -103);
    cout << "pop1, pop2: " << pop1 << ", " << pop2 << endl;
    return 0;
}
```

```
void change(const int * pt, int n)
{
    int * pc;

    pc = const_cast<int *>(pt);
    *pc += n;
}
```

The const_cast operator can remove the const from const int * pt, thus allowing the compiler to accept the following statement in change:

```
*pc += n;
```

However, because pop2 is declared as const, the compiler may protect it from any change, as is shown by the following sample output:
npop1, pop2: 38383, 2000
pop1, pop2: 38280, 2000

As you can see, the change to const pop1 but not pop2. The pointer is declared as const *, so it cannot change the value of the pointed-to-int. The pointer pc has const cast away, so it can be used to change the pointed-to-value, but only if that value itself wasn't const. Therefore, pc can be used to alter pop1 but not pop2.

The static_cast operator has the same syntax as the other operators:
static_cast <type-name> (expression)

It's valid only if type_name can be converted implicitly to the same type that expression has, or vice versa. The type cast is an error.
