# Number-Reading Loops

Say you're preparing a program to read a series of numbers into an array.You want to give the user to terminate input before filling the array. One way to do this is utilize how cin behaves. Consider the following code:

```
int n;
cin >> n;
```

What happens if the user responds by entering a word instead of a number? Things occur in such a mismatch:

+   - The value of n is left unchanged.
- The mismatched input is left in the input queue.
- An error flag is set in the cin object.
- The call to the cin method returns false, if converted to type bool, returns false.

The fact that the method returns false that you can use non-numeric input to terminate a number-reading loop.The fact non-numeric input sets an error flag means that you have to reset the flag before the program can read more.
clear() method, which also resets the end-of-file(EOF) condition (see Chapter 5), resets the bad input flag.(Either bad input or the EOF can cause cin to return false. Chapter 17, "Input, Output, and Files," discusses how to distinguish between the two cases.) Let's look at a couple examples that illustrate these techniques.

Say you want to write a program that calculates the average weight of your day's catch of fish. With a five-fish limit, so a five-element array can hold all the data, but it is possible you could catch fewer fish. Listing 6.13 uses a loop that terminates if the array is full or you enter non-numeric input.

# Listing 6.13 cinfish.cpp

```
// cpp.cpp -- non-numeric input terminates loop
#include <iostream>
const int Max = 5;
int main()
{
    using namespace std;
    // get data
    double fish[Max];
    cout << "Please enter the weights of your fish.\\n";
    cout << "You may enter up to " << Max
         << << " fish <q to terminate.\\n";
    cout << "fish #1: \n";
    int i = 0;
    while (i < Max && cin >> fish[i]) {
        if (++i < Max)
            cout << "fish #" << i+1 << ": \n";
    }
}
```
