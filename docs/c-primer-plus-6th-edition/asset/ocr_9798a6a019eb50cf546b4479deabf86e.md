# Filling the Array

Because a function with an array argument accesses the original array, not a copy, you can use a function to assign values to array elements. One argument to the function will be the name of the array to be filled. In general, a program might manage more than one person's investments, hence more than one, so you don't want to build the array size into the function. Instead, you pass the array size as a second argument, as in the previous example. It's possible that you might want to read data before filling the array, so you want to build that feature into the function. You might enter fewer than the maximum number of elements, it makes sense to have the function return the actual number of values entered. These considerations suggest the following function prototype:

int fill_array(double array[], int limit);

The function takes an array name and an argument specifying the maximum number of items to read. For example, if you use this function with an array of five elements, you pass 5 as the second argument. If you then enter only three values, the function returns 3.
You can use a loop to read successive values into the array, but how can you terminate the loop early? One way is to use a special value to indicate the end of input. Because no property should have a negative value, you can use a negative number to indicate the end of input. The function should do something about bad input, as terminating further input. Given these considerations, you can code the function as:

```
int fill_array(double array[], int limit)
{
    using namespace std;
    double temp;
    int i;
    for (i = 0; i < limit; i++)
    {
        cout << "Enter value #" << (i + 1) << ": ";
        if (!(cin >> temp) // bad input
        {
            cin.clear();
            while (cin.get() != '\n')
                continue;
        }
        cout << "Bad input; input process terminated.\n";
    }
}
```
