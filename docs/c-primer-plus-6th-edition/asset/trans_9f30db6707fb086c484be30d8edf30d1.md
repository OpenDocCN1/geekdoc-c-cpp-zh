## STL 函数

STL 算法库，由 algorithm 和 numeric 头文件支持，提供大量基于迭代器的非成员模板函数。如第 16 章所述，模板参数被选用来指示应满足哪些特定参数模型。例如，ForwardIterator 用于指示参数至少应满足前向迭代器的要求，而 Predicate 用于指示参数应为具有一个参数的函数对象。C++ 标准将算法分为四组：非修改序列操作、修改序列操作、排序及相关操作符，以及数值操作。（C++11 将数值操作从 STL 移至 numeric 库，但不影响其使用方式。）术语序列操作表示函数以一对迭代器作为参数来定义要操作的范围或序列。术语修改意味着函数允许更改容器。

## STL 函数 1287

现在让我们更详细地查看这些非修改序列操作。对于每个函数，讨论显示原型(s)，随后是简要说明。迭代器对表示范围，所选模板参数名称指示迭代器类型。如同在范围 [first, last) 中从 first 到不包括 last 一样，通常情况下，某些函数接受范围，这些范围不必在同一容器中。例如你可以使用 equal() 来比较一个 list 和一个 vector。作为参数传递的函数是对象，可以是指针（函数名即为示例）或定义了 () 操作的对象。如第 16 章所述，谓词是一个具有一个参数的布尔函数，二元谓词是一个具有两个参数的布尔函数。函数不必是 bool 类型，只要它们对 false 返回 0，对 true 返回非零值即可。
