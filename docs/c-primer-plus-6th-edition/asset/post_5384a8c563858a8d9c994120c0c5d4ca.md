# C++ Inline Functions

Inline functions are a C++ enhancement designed to speed up programs. The primary distinction between normal functions and inline functions is not in how you code them but in how the C++ compiler incorporates them into a program. To understand the difference between inline functions and normal functions, you need to peer more deeply into the programmer's innards we have so far. Let's do that now.

The final product of the compilation process is an executable program, which consists of a set of machine language instructions. When you start a program, the operating system loads these instructions into the computer's memory so that each instruction has a particular memory address. The computer goes through these instructions step-by-step. Sometimes, as you have a loop or a branching statement, program execution skips instructions, jumping backward or forward to a particular address. Normal function calls also involve a program jump to another address (the function's address) and then jump back when the function terminates. Let's look at a typical implementation of that process in a little more detail. When a program reaches the function call instruction, the program stores the memory address of the instruction immediately following the function call, copies arguments to the stack (a block of memory reserved for that purpose), jumps to the memory location that marks the beginning of the function, executes the function (perhaps returning a value in a register), and then jumps back to the address it saved. Jumping back and forth and keeping track of where to jump means that there is an overhead in elapsed time.

# Chapter 8 Adventures in Functions

C++ inline functions provide an alternative. With inline functions, the compiler replaces the function call with the actual code of the function, which eliminates the overhead of the function call. However, this can also increase the size of the program if the function is large and called many times. You should be selective about using inline functions. They are best used for small, frequently called functions.

To use this feature, you must take at least one of two actions:

- Prefix the function declaration with the keyword inline
- Prefix the function definition with the keyword inline

A common practice is to omit the prototype and place the entire definition (meaning the function header and all code) where the prototype would normally go. The compiler does not have to honor your request to make a function inline. It might decide the function is too large or notice it calls itself (recursion is not allowed or indeed possible for inline functions), or the feature might not be turned on or implemented for your compiler.
