## Incore Formatting

The iostream family supports I/O between a program and a terminal. The fstream family uses the same interface to provide I/O between a program and a file. The C++ library
also provides an ostream family, which uses the same interface to provide I/O between a
program and a string object. That is, you can use the ostream methods you've used
with cout to write formatted information into a string object, and you can use istream
methods such as getline() to read information from a string object. The process of
reading formatted information from a string object or writing formatted information
to a string object is termed inline formatting. Let's take a brief look at these facilities.
The sstream family of string supersedes the sstream header file of char-array support.

The sstream header file defines an ostringstream class that is derived from the
ostream class. There is also a wstringstream class based on wstream, for wide characters). If you create an string object, you can write information to it, which it stores. You can use the same methods with an ostring object that you can with
cout. That is, you can do something like the following:

```cpp
stringstream outstr;
double price = 380.0;
char* ps = " for a copy of the ISO/IEC C++ standard!";

outstr.precision(2);

outstr << "Pay only CHF " << price << ps << endl;
```

The formatted text goes into a buffer, and the object uses dynamic memory allocation
to expand the buffer size as needed. The ostring class has a member function,
called str(), which returns a string object initialized to the buffer's contents:

```cpp
string mes = outstr.str(); // returns strings with formatted information
```

Using the str() method "freezes" the object, and you can no longer write to it.

## Listing 17.21 strout.cpp

```cpp
// strop.cpp -- incore formatting (output)
#include <iostream>
#include <sstream>
#include <string>
int main()
{
    using namespace std;
    ostringstream outstr; // manages a string stream

    string hdisk;
    cout << "What's the name of your hard disk? ";
    getline(cin, hdisk);
    int cap;
    cout << "What's its capacity in GB? ";
    cin >> cap;
    // write formatted information to string stream
    outstr << "The hard disk " << hdisk << " has a capacity of "
        << cap << " gigabytes.\n";
    string result = outstr.str(); // save result
    cout << result; // show contents

    return 0;
}
```

The ostringstream class lets you use the istream family of methods to read data
from an istringstream object, which can be initialized from a string object.

Suppose facts is a string object. To create an stringstream object associated with this string, you can use the following:

```cpp
stringstream instr(facts); // use facts to initialize stream
```

Then you use istream methods to read data from instr. For example, if instr contained a bunch of integers in character format, you could read them as follows:

```cpp
int n;
int sum = 0;
while (instr >> n)
    sum += n;
```

## Summary

A stream is a flow of bytes into or out of memory. A buffer is a temporary holding area in memory that acts as an intermediary between a program and a file. Information can be transferred between a buffer and a file, using large chunks of data such as disk drives. C++ handles input by connecting a buffered stream to a program and its source. Similarly, C++ handles output by connecting a buffered stream to a program and to its target. The istream and ofstream files define a rich set of classes for managing streams. C++ programs that include the istream file automatically open streams, managing them with objects. The cin object connects to the standard input device, which by default, a keyboard. The cout object manages the standard output stream, which connects to the standard output device, typically a monitor. The cerr and clog objects manage unbuffered and buffered streams connected to the standard error device.

The I/O class library provides a variety of useful methods. The istream class defines versions of the extraction operator (>>) to recognize all the basic C++ types and convert input to those types. The get() method of methods and the getline() method provide further support for single-character input and string input. The ostream class defines versions of the insertion operator (<<) to recognize all the basic C++ types and convert them to suitable character output. The put() method provides further support for single-character output. The istream and ostream classes provide similar support for wider characters.

You can control the format output using ios_base class methods and by using manipulators (functions that can be concatenated with insertion) defined in the istream and iomanip files. These methods and manipulators let you control the number base, the field width, the number of decimal places displayed, the system used to display floating-point values, and other elements.

The ofstream file provides class definitions that extend the istream methods to file I/O. The ofstream class associates an istream object with a file, you can use all the istream methods for reading the file. Similarly, associating an ostream object with a file lets you use the ostream methods to write to a file. Associating an ofstream object with a file lets you employ both input and output methods with the file.

To associate a file with a stream, you can provide the filename when initializing a stream object or you can create a file stream object and use the open() method to associate the stream with a file. The close() method terminates the connection.
