You can combine the definition of a structure form with the creation of structure variables. To do so, you follow the closing brace with the variable name or names:

```cpp
struct perks
{
    int key_number;
    char car[12];
} mr_smith, ms_jones; // two perks variables
```

You can initialize a variable you create in this fashion:
```cpp
struct perks
{
    int key_number;
    char car[12];
} mr_glitz = {
    7, // value for mr_glitz.key_number member
    "Packard" // value for mr_glitz.car member
};
```

However, keeping the structure definition separate from the variable declarations usually makes a program easier to read and follow.
Another thing you can do with structures is create a structure with no type name. You do this by omitting a tag name while simultaneously defining a structure form and a variable:

```cpp
struct
{
    // no tag
    int x; // 2 members
    int y;
} position; // a structure variable
```

This creates one variable called position. You can access its members with the membership operator, in position.x, but there is no general name for the type. You can't subsequently create other variables of the same type. This book doesn't use limited form of structure.
Aside from the fact that a C++ program can use the structure tag as a type name, C structures have all the features so far for C++ structures, apart from the C++11 changes. C++ structures go further. Unlike structures, for example, C++ structures can have member functions in addition to member variables. But these more advanced features are typically used with classes rather than structures, so we will discuss them when we cover classes, beginning with Chapter 10, "Objects and Classes."

# Arrays of Structures

The inflatable structure contains an array (the name array). It's also possible to create arrays whose elements are structures. The technique is exactly the same as for creating arrays of the fundamental types. For example, to create an array of 100 inflatable structures, you could do the following:

```cpp
inflatable gifts[100]; // array of 100 inflatable structures
```

This makes gifts an array of inflatables. Hence each element of the array, such as gifts[0] or gifts[99], is an inflatable object and can be used with the membership operator:

```cpp
cin >> gifts[0].volume; // use volume of first struct
cout << gifts[99].price << endl; // display price of last struct
```

Keep in mind that if gifts itself is an array, not a structure, constructions such as gifts.price are not valid.

To initialize an array of structures, you combine the rule for initializing arrays (a brace-enclosed, comma-separated list of values for each element) with the rule for structures (a brace-enclosed, comma-separated list of values for each member). Because each element of the array is a structure, value is represented by a structure initialization. Thus, you wind up with a brace-enclosed, comma-separated list of values, each of which itself is a

```cpp
inflatable guests[2] = // initializing an array of structs
{
    {"Bambi", 0, 21.99}, // first structure in array
    {"Godzilla", 2000, 565.99} // next structure in array
};
```

As usual, you can format this any way you like. For example, both initializations can be on the same line, or each separate structure member initialization can get a line of its own.

# Bit Fields in Structures

C++, like C, enables you to specify structure members that occupy a particular number of bits. This can be handy for creating a data structure that corresponds, say, to a register on hardware device. The field type should be an integral or enumeration (enumeration discussed later in this chapter), and a colon followed by a number indicates the actual number of bits to be used. You can use unnamed fields to provide spacing. Each member is termed a *bit field*. Here's an example:

```cpp
struct torge_register
{
    unsigned int SN : 4; // 4 bits for SN value
    unsigned int : 4; // 4 bits unused
    bool goodIn : 1; // valid input (1 bit)
    bool goodToggle : 1; // successful toggling
};
```

You can initialize the fields in the usual manner, and use standard structure notation to access bit fields:

```cpp
torge_register tr = { 14, true, false };
```

```cpp
if (tr.goodIn) // if statement covered in Chapter 6
```

Bit fields are typically used in low-level programming. Often, using an integral type and the bitwise operators used in Appendix E, "Other Operators," provides an alternative approach.

# Unions

A union is a data format that can hold different data types but only one type at a time. That is, whereas a structure can hold, say, an int and a long and a double, a union can hold an int, a long, or a double. The size of the union is the size of its largest member. For example, consider the following:

```cpp
union oneall
{
    int int_val;
    long long_val;
    double double_val;
};
```

You can use oneall to hold different values at times:

```cpp
oneall pail;
pail.int_val = 15; // store an int
cout << pail.int_val;

pail.double_val = 1.38; // store a double
cout << pail.double_val;
```

One use for a union is to save space when an item can use different formats. For example, suppose you manage an inventory of widgets, some of which have integer ID, and some of which have string ID. In that case, you could use the following:

```cpp
struct widget {
    char brand[20];
    int type;
    union {
        long id_num; // type 1
        char id_char[20]; // other widgets
    };
};
widget prize;
```

```cpp
if (prize.type == 1) // if-else statement
    cin >> prize.id_num;
else
    cin >> prize.id_char;
```

# Enumerations

The C++ enum facility provides an alternative to const for creating symbolic constants. It also lets you define new types in a fairly restricted fashion. The syntax for enum resembles structure. For example, consider the following statement:

```cpp
enum spectrum {red, orange, green, blue, violet, indigo, ultraviolet};
```

This statement does two things:

-   It makes spectrum the name of a new type; spectrum is termed an enumeration, much as a struct variable is called a structure.
-   It establishes red, orange, yellow, and so on, as symbolic constants for the integer values 0–7. These constants are called enumerators.
