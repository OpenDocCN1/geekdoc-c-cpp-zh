## Other istream Class Methods

第 3 章到第 5 章讨论了 get() 和 getline() 方法。正如你可能回忆的那样，它们提供了以下额外的输入功能：

- get(char &) 和 get(void) 方法提供不跳过空白字符的单字符输入。
- get(char *, int, char) 和 getline(char *, int, char) 函数默认读取整行而不是单个单词。

这些是非格式化输入函数，因为它们只是按原样读取字符，不跳过空白字符也不执行数据转换。
让我们来看一下这两个组的 istream 类成员函数。

## Single-Character Input

当使用 char 参数或根本不使用参数时，get() 方法会获取下一个输入字符，即使它是空格、制表符或换行符。get(char & ch) 版本将其输入字符赋给其参数，而 get(void) 版本使用其输入字符，转换为整数，通常为 int，作为其返回值。

### The get(char &) Member Function

让我们先尝试 get(char &)。假设你的程序中有以下循环：

```
int ct = 0;
char ch;
cin.get(ch);
while (ch != '\n')
{
    cout << ch;
    ct++;
    cin.get(ch);
}
```

cout << ct << endl;

如果 cin.get(char &) 遇到文件末尾，无论是真实的还是从键盘模拟的，DOS 和 Windows 命令提示符下为 Ctrl+Z，Unix 下在行首为 Ctrl+D，它不会为其参数赋值。如果程序已到达文件末尾，就没有值可分配，这完全正确。此外，该方法调用 setstate(failbit)，这会导致 cin 测试为 false：

```
char ch;
while (cin.get(ch))
{
    // process input
}
```

只要有有效输入，cin.get(ch) 的返回值就是 cin，评估为 true，循环继续。到达文件末尾时，返回值评估为 false，终止循环。

### The get(void) Member Function

(void) 成员函数也读取空白字符，但它使用其返回值向程序传达信息。因此你会这样使用它：

```
int ct = 0;
char ch;
ch = cin.get();      // use return value
while (ch != '\n')
{
    cout << ch;
    ct++;
    ch = cin.get();
}
```

cout << ct << endl;

(void) 成员函数返回类型为 int，或取决于字符集和区域设置的某些更大的整数类型。这使得以下内容无效：

```
char c1, c2, c3;
cin.get().get() >> c3;  // not valid
```

这里 cin.get() 返回一个 int 值。因为返回值不是类对象，所以你不能对其应用成员运算符。因此，你会得到语法错误。但是，你可以在提取序列的末尾使用 cin.get()：

```
char c1;
cin.get(c1).get();    // valid
```

(void) 返回类型为 int 这一事实意味着你不能在其后跟随提取运算符。但由于 cin.get(c1) 返回 cin，它可以作为 get() 的合适前缀。此特定代码将返回第一个输入字符，将其赋给 c1，然后返回第二个输入字符并丢弃它。

到达真实或模拟的文件末尾时，cin.get(void) 返回值 EOF，这是一个由 iostream 头文件提供的符号常量。此设计特性允许以下用于读取输入的构造：

```
int ch;
while ((ch = cin.get()) != EOF)
{
```

// process input
}

你应该为 ch 使用类型 int 而不是类型 char，因为 EOF 值可能无法表示为 char 类型。

## Which Form of Single-Character Input to Use?

在 >>、get(char &) 和 get(void) 之间进行选择时，应该使用哪一个？首先，你需要决定是否要跳过空白字符。如果跳过空白字符很方便，你应该使用提取运算符 >>。例如，为菜单选项提供便利时跳过空白字符：

```
cout << "a. annoy client       b. bill client\n"
cout << "c. calm client\n      d. deceive client\n"
cout << "q.n";
cout << "Enter a, b, c, d, or q: ";
char ch;
cin >> ch;
while (ch != 'q')
{
switch(ch)
{

}
cout << "Enter a, b, c, d, or q: ";
cin >> ch;
}
```

要输入响应，你键入 b 并按 Enter，生成两个字符的响应 b\n。如果使用除 get() 之外的其他方法，你必须在每次循环中添加代码来处理该 \n 字符，提取运算符会方便地跳过它。 如果你用 C 编程过，你可能遇到过换行符似乎作为无效结果出现在程序中的情况。这是一个容易修复的问题，但很麻烦。

如果你希望程序检查每个字符，你应该使用其中一个 get() 方法。例如，单词计数程序可以使用空白字符来确定单词何时结束。在两个 get() 方法中，get(char &) 方法具有更清晰的接口。get(void) 方法的主要优点是它与标准 C getchar() 函数非常相似，这意味着你可以通过包含 iostream 而不是 stdio.h，将 getchar() 全局替换为 cin.get()，并将 putc() 全局替换为 cout.put()，将 C 程序转换为 C++ 程序。

String Input: getline(), get(), and ignore()
接下来，让我们回顾第 4 章“Custom Types”中介绍的 getline 成员函数。getline() 成员函数和 get() 的字符串读取版本读取字符串，两者具有相同的函数签名，简化自更通用的模板声明：

```
istream & get(char *, int, char);
istream & get(char *, int);
istream & getline(char *, int, char);
istream & getline(char *, int);
```

第一个参数，回顾一下，是放置输入字符串的位置。第二个参数是读取的最大字符数加一。额外的字符为存储输入作为字符串时使用的终止空字符留出空间。）第三个参数指定用作输入分隔符的字符。仅使用两个参数的版本使用换行符作为分隔符。每个函数读取最多最大字符数或直到遇到分隔符字符，以先到者为准。

例如，以下代码将输入读入字符数组 line：

```
char line[50];
cin.get(line, 50);
```

cin.get() 函数在遇到 49 个字符后读取输入到数组中，默认情况下，在遇到换行符后，以先到者为准。get() 和 getline() 之间的区别在于 get() 将换行符留在输入流中，使其成为下一次输入操作的第一个字符，而 getline() 从输入流中提取并丢弃换行符。

第 4 章说明了这两个函数的两参数形式的使用。现在让我们来看一下三参数版本。第三个参数是分隔符字符。输入分隔符会导致输入停止，即使尚未达到最大字符数。因此，默认情况下，两种方法在达到行尾之前读取输入，而未读取分配的字符数。就像默认情况一样，get() 将分隔符留在输入队列中，而 getline() 不会。
