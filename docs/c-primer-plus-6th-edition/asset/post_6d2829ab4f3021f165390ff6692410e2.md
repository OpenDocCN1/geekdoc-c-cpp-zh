## Changing the Number Base Used for Display

The `ostream` inherits from the `ios` class, which inherits from the `ios_base` class. The `ios_base` class stores information that describes the format state. For example, bits in one class member determine the number base used, whereas another member determines the field width. By using manipulators, you can control the number base used to display integers. By using `ios_base` member functions, you can control the field width and the number of places displayed to the right of the decimal. Because the `ios_base` class is an indirect base class for `ostream`, you can use its methods with `ostream` objects (or descendants), such as `cout`.

> The members and methods found in the `ios_base` class were formerly found in the `ios` class. Now `ios_base` is a base class to `ios`. In the new system, `ios` is a template class with `char` and `wchar_t` specializations, and `ios_base` contains the non-templated features.

Let's look at how to set the number base used in displaying integers. To control whether integers are displayed in base 10, base 16, or base 8, you can use the `dec`, `hex`, and `oct` manipulators. For example, the following function call sets the number base format state for the `cout` object to hexadecimal:

```cpp
hex(cout);
```

After you do this, a program will print integer values in hexadecimal format until you set the format state to another choice. Note that the manipulators are not member functions, they don't have to be invoked by an object.

Although the manipulators are really functions, you normally see them used with:

```cpp
cout << hex;
```

## Adjusting Field Width

You probably noticed the columns in 17.4 line up because the `width()` method sets the field width. The `width()` method returns the current width, which you can use to save the state. The `width()` method affects only the next item displayed, then it reverts to the default. Listing 17.4 shows how the width() method works.

## Listing 17.4 width.cpp

```cpp
// width.cpp -- using the width method
#include <iostream>

int main()
{
    using std::cout;
    int w = cout.width(30);
    cout << "default field width = " << w << ":\n";

    for (long i = 1; i <= 100; i *= 10)
    {
        cout.width(5);
        cout << i << '<<';
        cout.width(8);
        cout << i * i << ":\n";
    }

    return 0;
}
```

Here is the output from 17.4:

```
default field width = 0:
N      N * N:
1      1:
10     100:
100:   10000:
```

The `width()` method affects only the next item, then reverts to the default. This is because `width()` is a member function, and it returns the previous field width, not the width to which it was just set. The default field width is zero. Because `cout` does not truncate data, it always expands a field to fit.
