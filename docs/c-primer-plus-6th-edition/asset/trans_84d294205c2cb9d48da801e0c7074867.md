## 第 5 章 循环和关系表达式

其他控制语句，如 if 和 while，与 for 的处理方式类似。这在视觉上强化了控制语句与函数调用之间的区别。常见的实践也是缩进 for 语句的主体，使其突出。

### 表达式和语句

for 控制部分使用三个表达式。在其自我设定的语法限制内，C++ 是一种非常富有表现力的语言。任何值或值与运算符的有效组合都构成一个表达式。例如，10 是一个值为 10 的表达式（毫无悬念），而 28 * 20 是一个值为 560 的表达式。在 C++ 中每个表达式都有一个值。通常值是显而易见的。例如，下面的表达式由两个值和加法运算符构成，其值为 49：

22 + 27

有时值就不那么明显了。例如，下面是一个表达式，因为它由两个值和赋值运算符构成：

x = 20

C++ 定义赋值表达式的值为左侧成员的值，因此该表达式的值为 20。赋值表达式具有值这一事实允许如下语句：

maids = (cooks = 4) + 3;

表达式 cooks = 4 的值为 4，因此 maids 被赋值为 7。然而，仅因为 C++ 允许这种行为并不意味着你应该鼓励它。但使这种奇怪的语句成为可能的那条规则也使下面的语句成为可能：

x = y = z = 0;

这是一种快速将多个变量设为相同值的方法。优先级表（参见附录 D，“运算符优先级”）显示赋值是从右到左结合的，因此首先 0 被赋给 z，然后 z = 0 被赋给 y，依此类推。

最后，如前所述，诸如 x < y 的表达式会计算出 bool 值 true 或 false。清单 5.3 中的简短程序说明了表达式值的一些要点。<< 运算符的优先级高于表达式中使用的运算符，因此代码使用括号来强制正确的顺序。

### 清单 5.3 express.cpp

```
// express.cpp -- values of expressions
#include <iostream>
int main()
{
  using namespace std;
  int x;

  cout << "The expression x = 100 has the value ";
  cout << (x = 100) << endl;
  cout << "Now x = " << x << endl;
  cout << "The expression x < 3 has the value";
  cout << (x < 3) << endl;
  cout << "The expression x > 3 has the value";
  cout << (x > 3) << endl;
  cout.setf(ios_base::boolalpha); // newer C++ feature
  cout << "The expression x < 3 has the value";
  cout << (x < 3) << endl;
  cout << "The expression x > 3 has the value";
  cout << (x > 3) << endl;
```

以下是清单 5.3 程序的输出：

The expression x = 100 has the value 100
Now x = 100
The expression x < 3 has the value 0
The expression x > 3 has the value 1
The expression x < 3 has the value false
The expression x > 3 has the value true

通常，cout 在显示前会将值转换为 int，但 cout.setf(ios::boolalpha) 函数调用会设置一个标志，指示 cout 显示单词 true 和 false 而不是 1 和 0。

> 注意

> C++ 表达式是一个值或值与运算符的组合，并且每个 C++ 表达式都有一个值。

要计算表达式 x = 100，C++ 必须将值 100 赋给 x。当评估表达式的行为改变内存中的数据值时，我们称评估具有副作用。因此，评估赋值表达式会产生改变赋值的副作用的副作用。你可能会把赋值看作是预期效果，但从 C++ 构造的角度来看，评估表达式是主要效果。并非所有表达式都有副作用。例如，评估 x + 15 计算出一个新值，但它不会改变 x 的值。但评估 ++x + 15 确实会产生副作用，因为它涉及递增 x。

从表达式到语句只是一小步；你只需加上分号。因此，下面是一个表达式：

age = 100

而下面是一个语句：

age = 100;

### 非表达式和语句

一些概念，例如了解 for 循环的结构，对于理解 C++ 至关重要。语法中也有一些相对次要的方面，当你理解语言时可能会突然困扰你。我们现在来看其中的几个。
虽然添加分号到任何表达式会使其成为语句，但反过来不成立。也就是说，从语句中删除分号不一定会将其转换为表达式。我们到目前为止使用的语句类型中，return 语句、声明语句和 for 语句不符合语句 = 表达式 + 分号的模式。例如，这是一个语句：

int toad;

片段 int toad 不是一个表达式并且没有值。这使得以下代码无效：

```
eggs = int toad * 1000; // invalid, not an expression
cin >> int toad; // can't combine declaration with cin
```

同样，你不能将一个 for 循环赋给一个变量。在下面的例子中，for 循环不是一个表达式，因此它没有值，你不能对其赋值：

```
int fx = for (int i = 0; i < 4; i++)
cout << i; // not possible
```

### 弯曲规则

C++ 在 C 循环中添加了一个特性，需要对 for 循环语法进行一些调整。这是原始语法：

```
for (expression; expression; expression)
statement
```

具体来说，for 结构的控制部分由三个表达式组成，如本章前面所定义的那样，用分号分隔。C++ 循环允许你做如下操作：

```
for (int i = 0; i < 5; i++)
```

也就是说，你可以在 for 循环的初始化区域声明一个变量。这很方便，但它不符合原始语法，因为声明不是表达式。这种非法行为最初是通过定义一种新的表达式类型，即声明语句表达式，即去掉分号的声明，只能出现在 for 语句中，来容纳的。然而，这种调整已被放弃。相反，for 语句的语法已修改为如下：

```
for (for-init-statement condition; expression)
statement
```

乍一看，这看起来很奇怪，因为只有一个分号而不是两个。但没关系，因为 for-init-statement 被识别为语句，而语句有自己的分号。至于 for-init-statement，它被识别为表达式语句或声明。这种语法规则用一个表达式后跟分号替换为一个语句，该语句有自己的分号。这归结为 C++ 程序员将能够在 for 循环初始化中声明和初始化一个变量，并且他们会做 C++ 语法和英语语言需要做的一切使其成为可能。

在 for-init-statement 中声明变量有一个实际方面你应该知道。变量仅存在于 for 语句内。也就是说，程序离开循环后，变量被消除：

```
for (int i = 0; i < 5; i++))
cout << "C++ knows loops.";
cout << i << endl; // oops! i no longer defined
```

你还应该知道的是，较旧的 C++ 实现遵循更早的规则，并将前面的循环视为 i 在循环前声明，使其在循环终止后仍然可用
