In order to simplify notation, the Student class contains this typedef:
typef std::array<double> ArrayDB;

This enables the remaining code to use the more convenient notation ArrayDB instead of std::vector<double>. Thus, methods and functions can refer to the ArrayDB type.
Pacing this typedef in the private portion of the class definition means that it can be used internally in the Student implementation but not by outside users of the Student class.
