## C++11 中的 auto 声明

C++11 引入了一种机制，允许编译器从初始化值的类型推导出类型。为此它保留了 auto 的含义，auto 是源自 C 的关键字，但此前从未使用过。（第 9 章讨论了 auto 的先前含义。）只需在初始化声明中使用 auto 代替名称，编译器就会为其分配与初始化表达式相同的类型：

```cpp
auto n = 100;      // n is int
auto x = 1.5;       // x is double
auto y = 1.3e12l;   // y is long double
```

然而，这种类型推导并不是真正针对简单情况的。事实上，你甚至可能走偏。例如，假设 x、y 和 z 都 intended 为 double 类型。考虑以下代码：

```cpp
auto x = 0.0;    // x is double because 0.0 is double
double y = 0;       // y is automatically converted to 0.0
auto z = 0;        // z is int because 0 is int
```

使用 int 而不是 0.0 并不能解决显式类型的问题，但能解决自动类型转换的问题。自动类型推导在处理复杂类型时变得更有用，例如 STL（标准模板库）中的类型。例如，C++98 代码可能是：

```cpp
std::vector<double> scores;
std::vector<double>::iterator pv = scores.begin();
```

```cpp
C++11 allows you to write this instead:
std::vector<double> scores;
auto pv = scores.begin();
```

我们将在后面再次提到 auto 的这种新含义，当它与手头的主题更相关时。

## Programming Exercises

1. 编写一个简短的程序，询问你的身高（以英寸为单位）并将身高转换为英尺和英寸。程序应使用下划线表示输入位置。也使用 const 表示转换因子。
2. 编写一个简短的程序，询问你的身高（以英尺和英寸为单位）以及体重（以磅为单位）。（使用三个变量存储信息。）程序应报告你的身体质量指数（BMI）。计算 BMI 时，首先将身高从英尺和英寸转换为英尺（1 英尺 = 12 英寸）。然后将身高以英寸为单位转换为米，乘以 0.0254。然后将体重从磅转换为千克，除以 2.2。最后，通过用千克质量除以身高（米）的平方来计算 BMI。使用常量表示各种转换因子。
3. 编写一个程序，要求用户输入以度、分、秒表示的纬度，然后以十进制格式显示纬度。一度有 60 角分，一角分有 60 角秒；用常量表示这些值。你应为每个输入值使用单独的变量。示例运行应如下所示：
   Enter a latitude in degrees, minutes, and seconds:
   First, enter the degrees: 37
   Next, enter the minutes of arc: 51
   Finally, enter the seconds of arc: 19
   37 degrees, 51 minutes, 19 seconds = 37.8553 degrees
4. 编写一个程序，要求用户输入秒数作为整数（使用 long 或，如果可用，long long），然后显示等效的时间（以天、小时、分钟和秒表示）。使用常量表示一天中的小时数、一小时中的分钟数和一分钟中的秒数。输出应如下所示：
   Enter the number of seconds: 31600000
   31600000 seconds = 365 days, 17 hours, 46 minutes, 40 seconds
5. 编写一个程序，要求用户输入当前世界人口和当前美国人口（或你选择的某个其他国家）。将信息存储在 long 变量中。程序应显示美国（或其他国家）人口占世界人口的百分比。输出应如下所示：

   Enter the population of the U.S.: 310763781
   The population of the U.S. is 4.5042% of the world population.
   你可以使用互联网获取更多数据。
6. 编写一个程序，询问你行驶了多少英里以及使用了多少加仑汽油，并返回汽车的每加仑英里数。或者，如果你愿意，程序可以要求以公里为单位的距离和以升为单位的油耗，然后以每 100 公里升数报告结果。
