```
void oil(int x)
{
  using namespace std;
  int texas = 5;

  cout << "In oil(), texas = " << texas << \ &texas = ";
  cout << &texas << endl;
  cout << "In oil(), x = " << x << ", &x = ";
  cout << &x << endl;
  // start a block
  int texas = 113;
  cout << "In block, texas = " << texas << endl;
  cout << " &texas = " << &texas << endl;
  cout << "In block, x = " << x << ", &x = ";
  cout << &x << endl;
} // end a block
  cout << "Post-block texas = " << texas << endl;
  cout << " &texas = " << &texas << endl;
}
```

Here is the output from the program 9.4:

main(), texas = 0012FED4
main(), year = 2011, &year = 0012FEC8
oil(), texas = 5, &texas = 0012FED4
oil(), x = 31, &x = 0012FD84
block, texas = 113, &texas = 0012FDD8
block, x = 31, &x = 0012FD84
Post-block texas = 5, &texas = 0012FDE4
main(), texas = 31, &texas = 0012FED4
main(), year = 2011, &year = 0012FEC8

Notice that each of the three variables in List 9.4 has its own distinct address and that the program only uses the particular variable in scope at the moment, so assigning the value 133 to texas in the inner block of oil() has no effect on the other variables of the same name. (As usual, the actual address values and format will differ from system to system.)

Let's summarize the sequence of events. When main() starts, the program allocates space for texas and year, and these come into scope. When the program calls oil(), these variables remain in memory but pass out of scope. Two new variables, x and texas, are allocated and come into scope. When program execution the inner block of oil(), the new texas (hidden) is superseded by an newer definition. The variable x, however, stays in scope because the block does not define a new x. When execution exits the block, the new texas is freed, and texas #2 comes back into scope. When the oil() function terminates, that texas and x expire, and the original texas and year come back into scope.
