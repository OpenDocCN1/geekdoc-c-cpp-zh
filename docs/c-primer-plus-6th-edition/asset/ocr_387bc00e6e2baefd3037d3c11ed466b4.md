# The Mechanics of Creating a Program

To use the g++ compiler, you first open a command prompt window. Cygwin and MinGW do this for you when you start those programs. To compile a source file name great.cpp, you type the following command at the prompt:

```
g++ great.cpp
```

If the program compiles successfully, the resultant executable file is named a.exe.

# Windows Compilers

Windows products are too abundant and too often revised to make it reasonable to describe them all individually. At the present the most popular is Microsoft Visual C++ 2010, which is available in the free Microsoft Visual C++ 2010 Expression Edition. The Wikipedia link (http://en.wikipedia.org/wiki/List_of_compilers) provides a comprehensive list of compilers for many platforms, including Windows. Despite differences and goals, compilers share some common features.

Typically, you must create a project for a program and add to it the file or files constituting the program. Each vendor sells an IDE with menu options and, possibly, automated assistance, to create a program. One very important matter you must establish is the kind of program you're creating. Typically, the compiler offers many choices, such as a Windows application, an MFC application, a dynamic link library, an ActiveX control, a DOS or character-mode executable, a static library, or a console application. Some of these may available in both 64-bit and 32-bit versions.

Because the programs in this book are generic, you should avoid those that require platform-specific code, such as Windows applications. Instead, you need to run in a character-based mode. The choice depends on the compiler. In general, you should look to see if there is an option labeled Console, character-mode, or DOS executable and try that. For instance, in Microsoft Visual C++ 2010, select the Win32 Console Application, click Application Settings, and select the Project option. In C++Builder XE, select Console Application under C++Builder Projects.

After you have set up it, you have to compile and link your program. The IDE typically gives you several choices, such as Compile, Build, Make, Build All, Link, Execute, Run, and Debug (but not necessarily these in the same IDE):

+   - Compile the code that is currently open
- Build or Make typically means compile the code for all the source code files in the project. This is an incremental process. That is, if the project has three files, and you change just one, and then that one is recompiled.
- Build All typically means compile all the source code files from scratch.
- As described earlier, Link combine the compiled source code with the necessary library code.
- Run or Execute means run the program. Typically, if you have not done the earlier steps, Run means before trying to run a program.
- Debug means run the program with the option of going through step-by-step.
