# 介绍 for 循环

情况常常要求程序执行重复性任务，例如一次一个地将数组元素相加，或多次打印某条消息。C++ 的 for 循环使此类任务变得容易完成。让我们看一下清单 5.1 中的一个循环，看看它做了什么，然后讨论其工作原理。

清单 5.1 forloop.cpp

```cpp
// forloop.cpp -- introducing the for loop
#include <iostream>
int main()
{
    using namespace std;
    int i; // create a counter; initialize; test; update
    for (i = 0; i < 5; i++)
        cout << "C++ knows loops.\n";
    cout << "C++ knows when to stop.\n";
    return 0;
}
```

以下是清单 5.1 程序的输出：

```
C++ knows loops.
C++ knows loops.
C++ knows loops.
C++ knows loops.
C++ knows loops.
C++ knows when to stop.
```

此循环首先将整数 i 设置为 0：

i = 0

这是循环的初始化部分。然后在循环测试中，程序测试 i 是否小于 5：

i < 5

如果是，程序执行以下语句，该语句称为循环体：
cout << "C++ knows loops.\n";

然后程序使用循环的更新部分将 i 增加 1：

i++

循环的更新部分使用 ++ 运算符，称为自增运算符。它将操作数的值增加 1。（自增运算符并不局限于循环。例如，你可以在程序中将 i++; 用作语句代替 i = i + 1;。）递增 i 完成了循环的第一次循环。

接下来，循环通过将新的 i 值与 5 进行比较开始新一轮循环。因为新值（1）也小于 5，所以循环打印另一行并再次递增。这为测试、执行语句、更新 i 值的全新循环做好了准备。该过程一直持续到循环更新为 5。然后下一次测试失败，程序继续执行循环之后的下一条语句。

# for 循环的各部分

for 循环提供了一步一步的配方来执行重复操作。让我们更详细地看看它是如何设置的。for 循环的通常部分处理以下步骤：
1. 初始设置一个值
2. 执行测试以查看循环是否应继续
3. 执行循环操作
4. 更新用于测试的值

C++ 循环设计将这些元素放置在可以一目了然的位置。初始化、测试和更新操作构成了一个用括号括起来的三部分控制区。每个部分都是一个表达式，分号将表达式彼此分开。控制之后跟随的语句称为循环体，只要表达式保持为真，就会执行它：

```cpp
for (initialization; test; update)
    body
```

for 是一个入口条件循环。这意味着在每次循环之前都会评估测试表达式。循环在测试表达式为假之前永远不会执行主体。例如，假设你运行清单 5.2 中的程序，但给出 0 作为起始值。因为测试条件在第一次评估时就失败了，所以循环体永远不会被执行：

清单 5.2 num_test.cpp

```cpp
// num_test.cpp -- use numeric test for loop
#include <iostream>
int main()
{
    using namespace std;
    cout << "Enter the countdown value: ";
    int limit;
    cin >> limit;
    int i;
    for (i = limit; i--) // quits when i is 0
        cout << "i = " << i << "\n";
    cout << "Done now that i = " << i << "\n";
    return 0;
}
```

以下是清单 5.2 程序的输出：

Enter the countdown value: **4**
i = 4
i = 3
i = 2
i = 1
Done now that i = 0

请注意，循环在达到 0 时终止。

诸如 i < 5 之类的关系表达式如何融入这个以 0 值终止循环的框架中？在引入 bool 类型之前，关系表达式求值为 1 表示真和 0 表示假。表达式 3 < 5 的值为 1，而 5 < 0 的值为 0。现在 C++ 增加了 bool 类型，关系表达式求值为 bool 字面量 true 和 false 而不是 1 和 0。然而，这种变化不会导致不兼容，因为 C++ 程序会在期望整数的地方将 true 和 false 转换为 1 和 0，并在期望 bool 值的地方将 0 转换为 false、非零转换为 true。
