# Statements and Semicolons

A statement represents an action to be taken. To understand your source code, a compiler needs to know when one statement ends and another begins. Some languages use a state-separator. FORTRAN, for example, use the end of the line to separate one statement from the next. Pascal uses a semicolon to separate one statement from the next. You can omit the semicolon in certain cases, such as after a statement just before an END, when you're not actually performing two statements.(Pragmatists and minimalists will agree whether can implies). But C++, uses a semicolon as a terminator rather as a separator. The difference is that a semicolon acting as a terminator of the statement rather than a marker between statements. The practical upshot is that in C++ you should never omit the semicolon.
