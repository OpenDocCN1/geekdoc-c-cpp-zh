Table 5.3 cin.get (ch) Versus cin.get ()

| Property | cin.get (ch) | ch=cin.get () |
|---|---|--|
| Method for conveying input character | Assign to argument ch | Use function value to assign to ch |
| Function value for character input | A class istream object (true after bool conversion) | Code for character as type int value |
| Return value at EOF | A class istream object (false after bool conversion) | EOF |

So which would use, cin.get () or cin.get (char)? The form with the character argument is integrated fully into the object approach because its return value is an istream object.This means, for example, that you can use chains. For example, the following code means reads the next character into ch1 and the following input character into ch2:

```
cin.get(ch1); cin.get(ch2);
```

This works because the function call cin.get (ch1) returns the object, which then acts as the object to get (ch2) is attached.

# Nested Loops and Two-Dimensional Arrays

Earlier in this chapter you saw that for loop is a natural tool for processing arrays. Now let's go a step further and look at how for loop within a loop (nested loops) serves to handle two-dimensional arrays.

First, let examine a two-dimensional array. Arrays used so far in this chapter are termed one-dimensional arrays because you can visualize each as a single row of data. You can visualize a two-dimensional array as more like a table, having both rows and columns of data. You can use a two-dimensional array, for example, to represent quarterly sales for six districts, with one row for each district. Or you can use a two-dimensional array to represent the position of RoboD on a computerized game board.

C++ does not provide a two-dimensional array type. You can create an array for which each element is itself an array. For example, suppose you want to store maximum data for five cities over a 4-year period. In that case, you can declare an array as follows:

```
int maxtemps[4][5];
```
