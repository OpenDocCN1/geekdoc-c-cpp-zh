

## 介绍 for 循环

什么是完整表达式？它是并非更大表达式的子表达式的表达式。完整表达式的例子包括表达式语句的表达式部分，以及作为 while 循环测试条件的表达式。

序列点有助于明确后缀递增何时发生。例如，考虑以下代码：

```
while (guests++ < 10)
cout << guests << endl;
```

（稍后本章将讨论的 while 循环，其工作方式类似于仅具有测试表达式的 for 循环。）有时 C++ 新手会认为“先使用值，然后递增它”意味着在此上下文中，在 cout 语句中使用 guests 之后再递增 guests。然而，guests++ < 10 是一个完整表达式，因为它是 while 循环条件，因此该表达式的结尾是一个序列点。因此，C++ 保证副作用（递增 guests）在程序继续执行到 cout 之前发生。但是，使用后缀形式可以保证 guests 在比较之后被递增，

现在考虑以下语句：

```
y = (4 + x++) + (6 + x++);
```

表达式 4 + x++ 不是完整表达式，因此 C++ 不保证 x 会在子表达式 4 + x++ 求值后立即递增。此处的完整表达式是整个赋值语句，分号标记了序列点，因此 C++ 保证在程序移动到下一条语句之前，x 已被递增两次。C++ 未指定 x 是在每个子表达式求值后递增还是仅在所有表达式求值后递增，这就是为什么应避免此类语句的原因。

C++11 文档已放弃“序列点”一词，因为该概念在讨论多线程执行时无法适用。相反，描述以排序为框架，其中某些事件被描述为在其他事件之前排序。这种描述性方法并非旨在改变规则；目标是提供能够清晰处理多线程编程的语言。

### 前缀与后缀

显然，如果前缀或后缀形式用于某种目的，例如函数参数或为变量赋值，则使用哪种形式会产生差异。但如果递增或递减表达式的值未被使用会怎样？例如，

```
x++;
```

和
```
++x;
```

是否不同？或者

```
for (n = lim; n > 0; --n)
```

和

```
for (n = lim; n > 0; n--)
```

是否不同？

从逻辑上讲，在这两种情况下，前缀或后缀形式的使用并无区别。表达式的值未被使用，因此唯一的效果是副作用。在这里，使用的是后缀表达式，因此保证在程序移动到下一步之前，递增 x 和递减 n 的效果会被执行；前缀形式和后缀形式对程序的行为没有影响，选择可能对执行速度产生微小影响。对于内置类型和现代编译器而言，这似乎不是问题。C++ 允许您为类定义这些运算符。在这种情况下，用户定义一个通过递增值并返回它的前缀函数。后缀版本首先复制值，递增该值，然后返回复制的值。因此，对于类而言，前缀版本比后缀版本更高效。

简而言之，对于内置类型，使用哪种形式可能无关紧要。对于使用用户定义递增和递减运算符的用户定义类型，前缀形式更高效。

### 递增/递减运算符与指针

您也可以对指针以及基本变量使用递增运算符。请记住，对指针添加递增运算符会使其值增加其指向类型所占的字节数。递增和递减指针时同样适用此规则：

```
double arr[5] = {21.1, 32.8, 23.4, 45.2, 37.4};
double *pt = arr; // pt points to arr[0], i.e. to 21.1
++pt; // pt points to arr[1], i.e. to 32.8
```

您还可以使用这些运算符结合 * 运算符来更改指针指向的数量。对指针应用 * 和 ++ 会引发关于什么被解引用以及什么被递增的问题。这些操作由运算符的优先级和结合性决定。前缀递增、递减和解引用运算符都具有相同的优先级，从左到右。后缀递增和递减运算符都具有相同的优先级，其优先级高于前缀优先级。这两个运算符从左到右操作。

前缀运算符的从右到左结合规则意味着 ++pt 表示首先对 pt 应用 ++（因为 ++ 在 * 的右侧），然后对 pt 的新值应用 *：

```
double x = ++pt; // increment pointer, take the value; i.e., arr[2], or 23
```

另一方面，++pt 表示 pt 指向的值，然后递增该值：

```
++pt; // increment the pointed to value; i.e., change 23.4 to 24.4
```

这里，pt 仍然指向 arr[2]。接下来，考虑以下组合：

```
(*pt)++; // increment pointed-to value
```

括号表示首先对指针进行解引用，得到 24.4。然后 ++ 运算符将其递增到 25.4；pt 仍然指向 arr[2]。最后，考虑以下组合：

```
x = *pt++; // dereference original location, increment pointer
```

后缀 ++ 运算符的优先级意味着 ++ 运算符作用于 pt，而不是 *pt，因此指针被递增。但由于使用了后缀运算符，被解引用的地址是原始地址 &arr[2]，而不是新地址。因此，*pt++ 的值是 arr[2]，即 25.4，但语句完成后 pt 的值是 arr[3] 的地址

> 注 递增和递减指针遵循指针算术规则。因此，如果 pt 指向数组的第一个成员，则 ++pt 会使其指向第二个成员。

### 组合赋值运算符

Listing 5.5 使用以下表达式来更新循环计数器：

```
i = i + by
```

C++ 有一个组合加法和赋值运算符，可以更简洁地实现相同结果：

```
i += by
```

++ 运算符将两个操作数的值相加并将结果赋给左侧操作数。这意味着左侧操作数必须是您可以为其赋值的内容，例如变量、数组元素、结构成员，或通过解引用指针标识的数据：

```
int k = 5;
k += 3; // ok, k set to 8
int *pa = new int[10]; // pa points to pa[0]
p[4] = 12;
pa[4] += 6; // ok, pa[4] set to 18
*(pa + 4) += 7; // ok, pa[4] set to 25
pa += 2; // ok, pa points to the former pa[2]
34 += 10; // quite wrong
```

每个算术运算符都有一个对应的赋值运算符，如表 5.1 所总结。每个运算符的工作方式都类似于 +=。因此，例如，以下语句将 k 的当前值替换为大 10 倍的值：

k *= 10;

### 5.1 组合赋值运算符

| Operator | Effect (L=left operand, R=right operand) |
| --- | --- |
| += | Assigns L + R to L |

### 复合语句，或块

C++ for 语句的格式或语法可能对您来说似乎很受限制，因为循环体必须是一个单一语句。如果您希望循环体包含多个语句，这似乎很别扭。C++ 通过语法漏洞提供了一种方法，让您可以在循环体中放入任意多的语句。诀窍是使用成对的大括号构造复合语句，或块。块由成对的大括号及其包含的语句组成，就语法而言，计为一个单一语句。例如，Listing 5.8 中的程序使用大括号将三个语句组合成一个块。这使得循环体能够提示用户、读取输入并执行计算。该程序计算您输入的数字的运行总和，并提供了使用 += 运算符的自然机会。

### Listing 5.8 block.cpp

```
// use a block statement
#include <iostream>
int main() {
{
	using namespace std;

	cout << "The Amazing Account will sum and average ";
	cout << "five numbers for you.\n";
	cout << "Please enter five values:\n";
	double number;
	double sum = 0.0;
	for (int i = 1; i <= 5; i++) {
	{
			cout << "Value " << i << " : ";
		cin >> number;
		sum += number;
	}		// block starts here
}
}
// block ends here
