

## Summary

友元允许你为类开发更灵活的接口。一个类可以将其它的函数、其它类以及其它类的成员函数声明为友元。在某些情况下，你可能需要使用前向声明并在类声明和方法的顺序上多加注意，以使友元能够正确配合。

嵌套类是在其它类内部声明的类。嵌套类便于设计实现其它类但不必成为公共接口一部分的辅助类。

C++ 异常机制提供了一种灵活的方式来处理尴尬的编程事件，例如不适当的值、失败的 I/O 尝试等。抛出异常会终止直接或间接导致该异常的函数调用，该调用必须在 try catch 块中。catch 块紧跟在 try 块之后，并且为了捕获异常，catch 块会执行 catch 块中的代码。此代码可能尝试修复问题，也可能终止程序。一个类可以用嵌套类设计，当检测到特定于该类的问题时可以抛出这些嵌套类。一个函数可以包含异常规范，标识该函数中可能抛出的异常，尽管 C++11 已弃用该特性。未捕获的异常（没有 catch 块的异常）默认会终止程序。未预期的异常（与异常规范不匹配的异常）也会如此。The

dynamic_cast 运算符用于将派生类指针转换为基类指针；其主要目的是确保调用虚函数是安全的。typeid 返回一个 type_info 对象。可以比较两个 typeid 值以确定对象是否为特定类型，并且返回的 type_info 对象可用于获取有关对象的的信息。

dynamic_cast、static_cast、const_cast 和 reinterpret_cast 运算符比通用类型转换机制提供更安全、文档更好的类型转换。

## The string Class

许多编程应用需要处理字符串。C 提供了一些支持，使用 string.h（cstr in C++）系列的字符串，而早期的 C++ 实现提供了自制的类来处理字符串。第 4 章“复合类型”介绍了 ANSI/ISO C++ string 类。第 12 章“类与动态内存分配”通过其最简朴的 string 类说明了设计表示字符串的类的一些方面。

请记住，string 类由 string 头文件支持。（请注意，string.h 和 cstr 头文件支持 C 库函数用于 C 风格字符串，而不是 string 类。）使用类的关键在于了解其公共接口，而 string 类有一套广泛的方法，包括几个构造函数，用于分配字符串、连接字符串、比较字符串、访问单个元素的重载运算符，以及用于在字符串中查找字符和子字符串等。简而言之，string 类有提供。
