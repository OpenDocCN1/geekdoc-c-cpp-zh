# Program Notes

First, let's note how painless it is to use the VECTOR namespace in Listing 11.15. The following declaration places the name of the Vector class in scope:

```
using VECTOR::Vector;
```

Because all the Class methods have class scope, importing the class name also makes the Vector methods available, without the need for any further declarations. Next, let's talk about random numbers. The standard ANSI C library, which also comes with C++, has a rand() function that returns a random integer in 0 to 359. The random walk program uses the modulus operator to get an initial seed value to generate a random value. That value is used as the seed for the next call, and so on. The numbers are pseudorandom and normally produce the set of 10 random numbers. (The exact values depend on the implementation). However, the srand function lets you override the default seed and initiate a different sequence of random numbers. This program uses the return value of time(0) to set the seed. The time() function returns the current calendar time, often implemented as the number of seconds since some specific date. (More generally, time() takes the address of a time_t variable and puts the time into that variable and returns it. Using 0 for the address argument obviates the need for an otherwise unneeded time_t variable.) Thus, the following statement sets a different seed each time you run the program, making the output appear even more random:

```
srand(0);
```

The stdlib header file (formerly stdlib.h) contains the prototypes for srand() and rand(), cctime (formerly time.h) contains the time() prototype. (C++11 provides more extensive random number functions supported by the random header file.)

The program uses the result vector to keep track of the walker's progress. On each cycle of the loop, the program sets the vector to a new direction and adds it to the current result vector. When the magnitude of result exceeds the target distance, the loop terminates.

By setting the vector, the program displays the final position in rectangular terms and in polar terms.
