# count()

```
template<class InputIterator, class T>
typename iterator_traits<InputIterator>::difference_type
count(InputIterator first, InputIterator last, const T& value);
```

The count() returns the number of elements in the range [first, last) that match the value.The T== operator for the value type is used to compare values. The return type is an integer that is large enough to contain the maximum number of items the container can hold.

# count_if()

```
template<class InputIterator, class Predicate>
typename iterator_traits<InputIterator>::difference_type
count_if(InputIterator first, InputIterator last, Predicate pred);
```

The count_if() returns the number of elements in the range [first, last) for which the object pred returns a true value when passed the element as an argument.

# mismatch()

```
template<class InputIterator1, class InputIterator2>
pair<InputIterator1, InputIterator2>
mismatch(InputIterator1 first1, InputIterator1 last1, InputIterator2 first2, InputIterator2 last2);
```

```
template<class InputIterator1, class InputIterator2, class BinaryPredicate>
pair<InputIterator1, InputIterator2>
mismatch(InputIterator1 first1, InputIterator1 last, InputIterator2 first2, BinaryPredicate pred);
```

Each of the mismatch() finds the first element in the range [first1, last) that doesn't match the corresponding element in the range beginning at first2 and returns a pair iterators to the two matching elements. If no mismatch is found, the return value is pair(last1, first2 + (last - first1).The first version uses the == operator to test matching. The second version uses the binary predicate function to compare elements. Elements pointed to by it1 and it2 don't match if (*it1, *it2) is false.
