# Static and Dynamic Binding

If the derived class does not redefine the virtual function, the vtbl holds the address of the original version of the function. If the derived class defines a new function and makes it virtual, its address is added to the vtbl (see Figure 13.5). Note that whatever you define 1 or 10 virtual functions for a class, you add just one address member to an object; it's the size that varies.

```
class Scientist{
    char name[40];
    public:
        virtual void show_name();
        virtual void show_all();
    };
    class Physicist : public Scientist {
        char field[40];
        public:
            void show_all(); // redefined
            virtual void show_field(); // new (function)
    };
```
