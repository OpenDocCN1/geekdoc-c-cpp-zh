### 新类型

C++11 添加了 long 和 unsigned long 类型以支持 64 位整数（更宽）以及 char16_t 和 char32_t 类型分别支持 16 位和 32 位字符表示。它还添加了“原始”字符串。第 3 章“处理数据”讨论了这些新增内容。

### 统一初始化

C++11 扩展了大括号封闭列表（列表初始化）的适用性，使其可用于所有内置类型以及用户定义类型（即类对象）。列表可带或不带 = 符号使用：

```
int x = {5};
double y = {2.75};
short quar[5] = {4,5,2,6,1};
```

此外，列表初始化语法还可用于 new 表达式：

```
int * ar = new int [4]{2,4,6,7}; // C++11
```

对于类对象，可以使用大括号列表代替圆括号列表来调用构造函数：

```
class Stump
{
private:
    int roots;
    double weight;
public:
    Stump(int r, double w) : roots(r), weight(w) {}
    Stump s1(3,15.6); // old style
    Stump s2{5, 43.4}; // C++11
    Stump s3 = {4, 32.1}; // C++11
```

但是，如果一个类有一个参数为 std::initializer_list 模板的构造函数，那么只有该构造函数可以使用列表初始化形式。列表初始化的各个方面已在第 3、4、9、10 和 16 章中讨论。

### 缩窄

初始化列表语法可防止缩窄——即防止将数值赋给无法容纳该值的数值类型。普通初始化允许你执行可能有意义也可能没有意义的操作：

```
char c1 = 1.57e27; // double-to-char, undefined behavior
char c2 = 459585821; // int-to-char, undefined behavior
```

如果使用初始化列表语法，编译器会禁止尝试将值存储在比值“更窄”的类型中的类型转换：

```
char c1 {1.57e27}; // double-to-char, compile-time error
char c2 = {459585821}; // int-to-char, out of range, compile-time error
```

但是，向更宽类型的转换是允许的。并且如果值在该类型允许的范围内，则允许向更窄类型的转换：

```
char c1 = {66}; // int-to-char, in, allowed
double c2 = {66}; // int-to-double, allowed
```

### std::initializer_list

C++11 提供了 initializer_list 模板类（在第 16 章“字符串类和标准模板库”中讨论），可作为构造函数参数使用。如果一个类有一个构造函数，则只能对该构造函数使用大括号语法。列表中的项应全部为同一类型或可转换为同一类型。STL 提供了带有 initializer_list 参数的构造函数：

```
vector<int> a1(10); // uninitialized vector with 10 elements
vector<int> a2(10); // initializer-list, a2 has 1 element set to 10
vector<int> a3(4,6,1); // 3 elements set to 4,6,1
```

initializer_list 头文件为此模板类提供了支持。类 begin() 和 end() 成员函数指定列表的范围。你也可以对普通函数以及构造函数使用 initializer_list 参数：

```
#include <initializer_list>
double sum(std::initializer_list<double> il);
int main()
{
    double total = sum({2.5,3.1,4}); // 4 converted to 4.0
}
{
    double tot = 0;
    for (auto p = il.begin(); p!=il.end(); p++)
        tot += *p;
    return tot;
}
```

### 声明

C++11 实现了多个简化声明的特性，特别是在使用模板时出现的情况。

### auto

C++11 去除了关键字 auto 作为存储类说明符的旧含义（第 9 章“内存模型和命名空间”），并将其用于（第 3 章）实现自动类型推导，前提是提供了显式的初始化器。编译器将变量的类型设置为初始化值的类型：

```
auto mason = 112; // mason is type int
auto pt = &mat; // pt is type int *
double fm=(double, int);
auto pf = fm; // pf is type double (*) (double,int)
```

auto 关键字可以简化模板声明。例如，如果 il 是 std::initializer_list<double> 类型的对象，你可以把

```
for (std::initializer_list<double>::iterator p = il.begin();
p!=il.end(); p++)
```

替换为：

```
for (auto p = il.begin()); p!=il.end(); p++)
```

### decltype

decltype 关键字创建一个与表达式指示的类型相同的变量。下面的语句意味着“与 x 相同类型”，其中 x 是一个表达式：

这里有几个例子：

```
double x;
int n;
decltype(x*n) q; // q same type as x*n, i.e., double
decltype(&x) pd; // pd same as &x, i.e., double *
```

这在模板定义中特别有用，因为类型可能要到特定实例化时才确定：

```
template<typename T, typename U>
void ef(T t, U u)
{
decltype(T*U) tu;
}
```

这里，tu 的类型是 T*U 操作的结果类型，假设该操作已定义。例如，如果 T 是 char 且 U 是 short，则 tu 将是 int 类型，因为整数算术中会进行整数提升。

decltype 的工作原理比 auto 更复杂，并且结果类型可能是引用或 const 限定，具体取决于所使用的表达式。这里有一些例子：

```
int j = 3;
int &k = j;
const int &n = j;
decltype(n) il; // il type const int &
decltype(j) i2; // i2 type int
decltype((j)) i3; // i3 type int &
decltype(k + 1) i4; // i4 type int
```

有关导致这些结果的规则，请参阅第 8 章“函数探险”。
