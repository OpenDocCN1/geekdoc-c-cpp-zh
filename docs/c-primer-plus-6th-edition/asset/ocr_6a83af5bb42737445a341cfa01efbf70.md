```
vector<double> gr8(arr1, arr1 + LIM);
ostream_iterator<double, char> out(cout, " ");
transform(gr8.begin(), gr8.end(), out, sqrt);
```

This code calculates the square root of each element and sends the results to
the output stream. The destination iterator can be in the original range. For example,
replacing it with gr8.begin() would copy the new values over the old
values. Clearly, the functor used must be one with a single argument.

The second version uses a functor that takes two arguments, applying the function to
one element from each of ranges. It takes an additional argument, which comes third
in order, identifying the start of the range. For example, if m8 were a second
vector<double> object and if mean(double, double) returned the mean of two values,

```
transform(gr8.begin(), gr8.end(), m8.begin(), out, mean);
```

Now you want to add the two arrays.You can't use + as an argument because,
for type double,+ is not a function. You could define a function to add
t numbers and use it:

```
double add(double x, double y) { return x + y; }
```

```
transform(gr8.begin(), gr8.end(), m8.begin(), out, add);
```

But then you have to define a function for each type. It would be better to
define a template, except that you do not have to because the STL already has. The
functional (formerly function.h) header defines several template class function objects,
including one plus<>().

Using the plus<>() class for ordinary addition is possible, if awkward:

```
#include <functional>

plus<double> add; // create a plus<double> object
double y = add(2.2, 3.4); // using plus<double>::operator()
```

But it is easy to provide a function object as an argument:
transform(gr8.begin(), gr8.end(), m8.begin(), out, plus<double>());

Here, rather than create a named object, the code uses plus<double> constructor
to construct a functor to do adding. (The parentheses indicate the default con-
struct; which passed to transform() is the constructed function.)

The STL provides functor equivalents for the built-in arithmetic, relational, and log-
ical operators. Table 16.12 shows the names for these functor equivalents. They can be
used with the C++ built-in types or any user-defined type that overloads the corre-
sponding operator.
