## Program Notes

The program in Listing 16.12 uses the for_each() algorithm and an outint() function to display the lists. With C++11, you could use the range-based for loop include:
(auto x : three) cout << x << " ";

The main difference between insert() and splice() is that insert() copies a copy of the original range into the destination, whereas splice() moves the original range into the destination. Thus, after the contents of one moving three, one is left empty. (The splice() method has prototypes for moving single elements and a range of elements). The splice() method leaves iterator valid. That is, if you set a iterator to point to an element in one, that iterator still points to the same element after splice() relocates it in three.

Notice unique() only reduces adjacent equal values to a single value. After the program executes three.unique(), three contains two fours and six sixties that weren't adjacent. By applying sort() and then unique() limits each value to a single appearance.

## The list Toolbox

The list methods provide a handy toolbox. Suppose, for example, you have two matching lists to organize. You could sort each list, merge them, and then use unique() to remove multiple entries.

The sort(), merge(), unique() methods also each have a version that accepts an additional argument to specify an alternative function be used for comparing elements. Similarly, the remove() method has a version with an additional argument that specifies a function used to determine whether an element is removed. These arguments are examples of predicate functions, to which we will return later.

## forward_list (C++11)

C++11 adds forward_list as a container class. This class implements a singly linked list. In this kind of list, each item is linked to the next item, but not to the preceding item. Therefore, the class requires a forward iterator, not a bidirectional iterator.

## queue

The queue template (declared in the queue header) is another adapter class. It supports the same operations as list. The main difference between the two is that with priority_queue, the largest item gets to the front. You can also alter the comparison used to determine what gets to the head by providing an optional argument:

```cpp
priority_queue<int> pq1; // default
priority_queue<int, vector<int>, greater<int>> pq2; // use greater
```

The function is a predefined function object, and it is discussed later.

## stack

Like queue, stack (declared in the stack header) is an adapter class. It has an underlying class (vector, by default). The template is more restrictive than vector. Not does it permit random access to elements, the stack doesn't allow you to iterate through a stack. Instead, it limits you to the basic operations. You can push a value onto the top of a stack, pop an element from the top of a stack, view the value at the top of a stack, check the number of elements, and test whether the stack is empty.

## array (C++11)

The array template class, introduced in Chapter 4 and defined in the array header file, is not an STL container because it has a fixed size. Thus, operations that would resize a container, such as push_back() and insert(), are not defined for array. But those members functions that make sense, such as operator[]() and at(), are provided. And you can use many STL algorithms, as copy() and for_each(), with array objects.
