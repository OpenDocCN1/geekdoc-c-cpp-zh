

# 第16章 string 类和标准模板库

方法有很多，但这些足以拼凑出一个图形上暗示的单词游戏 Hangman 的示例程序。该游戏将单词列表存储在 string 对象数组中，随机挑选一个单词，让你猜测其中的字母。猜错六次，你就输了。程序使用 find() 函数来检查你的猜测，并使用 ++ 运算符来构建一个 string 对象以跟踪你的错误猜测。为了跟踪你的正确猜测，程序会创建一个与单词长度相同且由连字符组成的单词。连字符会被正确的猜测所替换。16.3 节列出了该程序。

## 列表 16.3 hangman.cpp

```
// hangman.cpp -- some string methods
#include <iostream>
#include <string>
#include <cstdlib>
#include <ctime>
#include <cctype>
using std::;
const int NUM = 26;
const string wordlist[NUM] = {"apiary", "beetle", "cereal",
"danger", "esign", "florid", "garage", "health", "insult",
"jackal", "keeper", "loaner", "manage", "nonce", "onset",
"plaid", "quilt", "remote", "stolid", "train", "useful",
"valid", "whence", "xenon", "yearn", "zippy"};

int main()
{
using std::cout;
using std::cin;
using std::tolower;
using std::endl;
std::srand(std::time(0));
char play;
cout << "Will you play a word game? <y/n> ";
cin >> play;
play = tolower(play);
while (play == 'y')
{
    string target = wordlist[std::rand() % NUM];
    int length = target.length();
    string attempt(length, '-');
    string badchars;
    int guesses = 6;
cout << "Guess my secret word. It has " << length
    << " letters, and you guess\n"
    << "one letter at a time. You get " << guesses
    << " wrong guesses.\n";
cout << "Your word: " << attempt << endl;
while (guesses > 0 && attempt != target)
{
    char letter;
    cout << "Guess a letter: ";
    cin >> letter;
    if (badchars.find(letter) != string::npos
    || attempt.find(letter) != string::npos)
    {
        cout << "You already guessed that. Try again.\n";
        continue;
    }
    int loc = target.find(letter);
    if (loc == string::npos)
    {
        cout << "Oh, bad guess!\n";
        --guesses;
        badchars += letter; // add to string
    }
    else
    {
        cout << "Good guess!\n";
        attempt[loc]=letter;
        // check if letter appears again
        loc = target.find(letter, loc + 1);
        while (loc != string::npos)
        {
            attempt[loc]=letter;
            loc = target.find(letter, loc + 1);
        }
    }
}
cout << "Your word: " << attempt << endl;
if (attempt != target)
{
    if (badchars.length() > 0)
    {
        cout << "Bad choices: " << badchars << endl;
    }
    cout << guesses << " bad guesses left\n";
}
if (guesses > 0)
    cout << "That's right!\n";
else
    cout << "Sorry, the word is " << target << ".\n";
cout << "Will you play another? <y/n>";
cin >> play;
play = tolower(play);
}
cout << "Bye\n";

return 0;
}
```

## 程序说明

在列表 16.3 中，关系运算符的重载让你可以像对待数值变量一样对待字符串：

```
while (guesses > 0 && attempt != target)
```

这比使用 strcmp() 处理 C 风格字符串要容易得多。
程序使用 find() 来检查一个字符是否已被选择；如果已被选择，它会在 bad 字符串（错误猜测）或 attempt 字符串（正确猜测）中找到：

```
if (badchars.find(letter) != string::npos
|| attempt.find(letter) != string::npos)
```

npos 是 string 类的静态成员。它的值，回顾一下，是 string 对象允许的最大字符数。由于索引从零开始，它比最大可能索引大一，可用于表示未找到字符或字符串。

程序利用了 += 运算符的重载版本之一可让你将单个字符追加到字符串的事实：

```
badchars += letter; // append a char to a string object
```

程序的核心首先检查所选字母是否在谜底单词中：

```
int loc = target.find(letter);
```

如果 loc 是一个有效值，它可以放在答案字符串的相应位置：

```
attempt[loc] = letter;
```

然而，给定字母可能在谜底单词中出现多次，因此程序必须继续检查。程序使用了 find() 的可选第二个参数，该参数指定在字符串中开始搜索的位置。因为字母在位置 loc 处被找到，下一次搜索应从 loc + 1 开始。while 循环会一直搜索，直到不再出现该字符。注意，如果 loc 是字符串的末尾，find() 会表示搜索失败：

// check if letter appears again
loc = target.find(letter, loc + 1);
while (loc != string::npos)
{
attempt[loc]=letter;
loc = target.find(letter, loc + 1);
}
```

## string 类还提供什么？

string 库提供了许多其他设施。有用于擦除字符串部分或全部的函数，用于用另一个字符串的部分或全部替换一个字符串的部分或全部，用于向字符串中插入材料或从字符串中删除材料，用于比较一个字符串的部分或全部与另一个字符串的部分或全部，以及用于从字符串中提取子字符串的函数。还有用于将一个字符串的一部分复制到另一个字符串的函数，以及用于交换两个字符串内容的功能。其中大多数被重载，以便它们既适用于 C 风格字符串也适用于 string 对象。附录 F 简要描述了 string 库，但让我们在这里谈谈更多特性。

首先，考虑自动调整大小的特性。在列表 16.3 中，每次程序将一个字母追加到字符串时会发生什么？它可能会重新分配到邻近的内存中，而该内存已在使用中。它可能必须分配一个新的块，然后将旧内容复制到新位置。这样做效率低下，因此许多 C++ 实现会分配比实际字符串更大的内存块，为字符串增长提供空间。然后如果字符串最终超过其大小，程序会分配一个两倍大小的新块，以提供更多空间而无需持续调整大小。capacity() 方法返回当前块的大小，而 reserve() 方法允许你请求当前块的最小大小。

列表 16.4 显示了一个使用这些方法的示例。

```
// str2.cpp
#include <iostream>
#include <string>
int main()
{
	using namespace std;
	string empty;
	string small = "bit";
	string larger = "Elephants are a girl's best friend";
	cout << "Sizes:" << empty.size() << endl;
	cout << "small:" << small.size() << endl;
	cout << "larger:" << larger.size() << endl;
	cout << "Capacities:" << empty.capacity() << endl;
	cout << "empty:" << empty.capacity() << endl;
	cout << "small:" << small.capacity() << endl;
	cout << "larger:" << larger.capacity() << endl;
	empty.reserve(50);
	cout << "Capacity after empty.reserve(50) : "
	<< empty.capacity() << endl;
	return 0;
}
```

以下是列表 16.4 中程序在一个 C++ 实现中的输出：

- empty: 0
- small: 3
- larger: 34
- Capacities:
- empty: 15
- small: 15
- larger: 47

Capacity after empty.reserve(50): 63
请注意，此实现使用 15 个字符的最小容量，并且似乎使用小于 16 的倍数作为容量的标准。其他实现会做出不同的选择。

如果您有一个 string 对象但需要一个 C 风格字符串怎么办？例如，您可能想打开一个在 string 对象中的文件名：

```
string filename;
cout << "Enter file name: ";
cin >> filename;
ofstream fout;
```

坏消息是 open() 方法需要一个 C 风格字符串参数。好消息是 c_str() 方法返回一个指向 C 风格字符串的指针，该字符串的内容与调用的 string 对象相同。您可以使用它：
fout.open(filename.c_str());

## 字符串变体

本节将 string 类视为基于 char 类型。其实，正如前面提到的，string 库实际上是基于一个模板类：

```
template<class charT, class traits = char_traits<charT>
class Allocator = allocator<charT> =
basic_string {...};
```

basic_string 模板带有四个特化，每个特化都有一个 typedef 名称：

```
typedef basic_string<char> string;
typedef basic_string<wchar_t> wstring;
typedef basic_string<char16_t> u16string; // C++11
typedef basic_string<char32_t> u32string; // C++11
```
