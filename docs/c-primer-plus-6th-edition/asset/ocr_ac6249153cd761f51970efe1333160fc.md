# Program Notes

The program in Listing 4.17 uses new to allocate memory for the type int and double data objects. This occurs while the program is running. The pointers pt and pd point to these two data objects. Without them, you cannot access those locations. With them, you can use *pt and *pd just as you use variables. You assign values to *pt and pd assign values to the new data objects. Similarly, you print *pt and *pd to display those values.
The program in Listing 4.17 also demonstrates one of the reasons to declare the type pointer points. To an address in itself reveals only the beginning address of the object stored, not its type or number of bytes used. Look at the addresses of the two values. They are just numbers with no type or size information. Also note that the size of a pointer-to-int is the same as the size of a pointer-to-double. Both are addresses. But use_new.cpp declares the pointer types, the program knows that *pd is a double of 8 bytes, whereas use_new.cpp prints the value of *pd, cout can tell how many bytes to read and how to interpret them.

Another point to note is that typically new uses a different block of memory than the. Both the ordinary variables nights and pd have their values stored in a memory region called the stack, whereas the memory allocated by new is in a region called the heap or free store.
