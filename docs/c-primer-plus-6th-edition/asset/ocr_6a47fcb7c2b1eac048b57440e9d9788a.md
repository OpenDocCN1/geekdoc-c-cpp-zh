# Program Notes

To create a string of n visible characters, you need store for n + 1 characters in order to have space for the null character. So the function in Listing 7.10 asks for n + 1 bytes to hold the string. Next, it sets the byte to the null character. Then it fills in the rest of the array back to front. In Listing 7.10, the following loop cycles n times as n decreases to 0, filling n elements:

```
while (n-- > 0)
npstr[n] = c;
```

At the start of the final cycle, n has the value 1. Because n-- means the value and then decrement it, the while loop test condition compares 1 to 0, finds the test to be true, and continues. But after making the test, the function decrements n to 0,so ptr[0]
