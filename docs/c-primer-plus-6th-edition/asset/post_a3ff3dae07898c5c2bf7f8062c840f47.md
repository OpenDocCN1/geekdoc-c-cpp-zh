# Other istream Class Methods

Chapters 3 to 5 discuss the get() and getline() methods. As you may recall, they provide the following additional input capabilities:

- The get(char &) and get(void) methods provide single-character input that doesn't skip over white space.
- The get(char *, int, char) and getline(char *, int, char) functions by default read entire lines rather than single words.

These are unformatted input functions because they simply read character as is, without skipping over white space and without performing data conversions.
Let's look at these two groups of istream class member functions.

## Single-Character Input

When used with a char argument or no argument at all, the get() methods fetch the next input character, even if it is a space, tab, or newline character. The get(char & ch) version assigns its input character to its argument, and the get(void) version uses the input character, converted to an integer (typically int), as its return value.

## The get(char &) Member Function

Let's try get(char &) first. Suppose you have the following loop in program:

```cpp
int ct = 0;
char ch;
cin.get(ch);
while (ch != '\n')
{
    cout << ch;
    ct++;
    cin.get(ch);
}
```

cout << ct << endl;
```

If cin.get(char &) encounters the end of a file, either real or simulated from the keyboard (Ctrl+Z for DOS and Windows command prompt, Ctrl+D at the beginning of a line for Unix), it does not assign a value to its argument. This is quite right if the program has reached the end of the file, there is no value to be assigned. Furthermore, the method calls setstate(failbit), which causes cin to test as false:

```cpp
char ch;
while (cin.get(ch))
{
    // process input
}
```

As long as there's valid input, the return value for cin.get(ch) is cin, which evaluates as true, the loop continues. Upon reaching end-of-file, the return value evaluates as false, terminating the loop.

## The getchar() Member Function

The (void) member function also reads white space, but it uses its return value to communicate to a program. So you would use it in this way:

```cpp
int ct = 0;
char ch;
ch = cin.get();      // use return value
while (ch != '\n')
{
    cout << ch;
    ct++;
    ch = cin.get();
}
```

cout << ct << endl;

The (void) member function returns type int (or some larger integer type, depending on the character set and locale). This makes the following invalid:

```cpp
char c1, c2, c3;
cin.get().get() >> c3;  // not valid
```

Here cin.get() returns an int value. Because return value is not a class object, you can't apply the membership operator to it. Thus, you get a syntax error. However, you can use cin.get() at the end of an extraction sequence:

```cpp
char c1;
cin.get(c1).get();    // valid
```

The fact that (void) returns type int means you can't follow it with an extraction operator. But because cin.get(c1) returns cin, it makes a suitable prefix to get(). This particular code would return the first input character, assign it to c1, and then return the second input character and discard it.

Upon reaching the end-of-file, real or simulated, cin.get(void) returns the value EOF, which is a symbolic constant provided by the iostream header file. This design feature allows the following construction for reading input:

```cpp
int ch;
while ((ch = cin.get()) != EOF)
{
```

## Table: get(ch) vs get()

| Property | get(ch) | get() |
| :--- | :--- | :--- |
| Input type | char & | int |
| Return value | cin (object) | int |
| Skips white space | No | No |
| End-of-file | sets failbit | returns EOF |

## Which Form of get() should you use?

Given the two methods, get(char &) and get(void), which should you use? If you want to skip white space, you should use the (void) version. For example:

```cpp
char ch;
cin.get(ch);
while (ch != '\n')
{
    // process input
}
```

If you want to include the newline character, you should use the (char &) version. For example:

```cpp
char ch;
cin.get(ch);
while (ch != '\n')
{
    // process input
}
```

The difference between get(char &) and get() is that get(char &) leaves the newline in the input stream, making the first character of the next input operation, whereas get() does not.

## String Input: getline(), get(), and ignore()

Next, let's review the getline() member functions introduced in Chapter 4 "Custom Types". The getline() member function and the string-reading version of get() read strings, and both have the same signatures (simplified from the general template declaration):

```cpp
istream & get(char *, char);
istream & get(char *, int);
istream & getline(char *, int, char);
istream & getline(char *, int);
```

The first argument, recall, is the location to place the input string. The second argument is one greater than the maximum number of characters to read. The third argument specifies a character to act as a delimiter for input. The versions with just arguments use the newline as a delimiter. 

```cpp
char line[50];
cin.get(line, 50);
```

The cin.get() function reads input into the array after encountering 49 characters, by default, after encountering a newline character, whichever comes first. The difference between get() and getline() is that get() leaves the newline in the input stream, making the first character of the next input operation, whereas getline() does not.
