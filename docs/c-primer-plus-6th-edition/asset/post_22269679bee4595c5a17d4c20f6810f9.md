## Friend Classes

When you want to make one class a friend to another? Let’s look at an example. Suppose you want to program a simple simulation of a television and a remote control. You decide to define a Tv class representing a television and a Remote class representing a remote control. Clearly, there should be some sort of relationship between these classes, but what kind? A remote control is not a television and vice versa, so the is-a relationship of public inheritance doesn’t apply. Nor is it a component of the other, so the has-a relationship of containment or private or protected inheritance doesn’t apply. What is true that a remote control can modify the state of a television this this making the Remote class a friend to the Tv class.

Let’s define the Tv class. You can represent a television with a set of state members—that is, variables that describe various aspects of the television. Here are some of the possibles:

- On/off
- Channel setting
- Volume setting
- Cable or antenna tuning mode
- TV tuner or A/V input

The tuning mode reflects the fact that, in the United States, the spacing between channels for channels 14 and up is different for cable reception than it is for UHF broadcast reception. The input selection chooses between TV, which could be either cable or broadcast TV, and a DVD. Some sets may offer more choices, such as multiple DVD/Blu-inputs, but this list is for the purposes of this example.

Also a television has some parameters that aren’t state variables. For example, televisions vary in the number of channels you can receive, and you can include a member to track that value.

Next, you must provide the class with methods for altering the settings. Many televisions these days hide their controls behind panels, but it’s still possible with most televisions to change channels, and on, without a remote control. However, often you can go up or down channel at a time but can’t select a channel at random. Usually, there’s a button for increasing the volume and for decreasing the volume.

A remote control should duplicate the controls built into the television. Many of its methods can be implemented using Tv methods. In addition, a remote control provides random access channel selection. That is, you can go directly from channel 2 to channel 20 without going through all the intervening channels. Also many remotes work in two or more modes, for example, as a television controller and a DVD controller.

These considerations suggest a definition like that as shown in Listing 15.1. The definition includes several constants defined as enumerations. The following statement makes Remote a friend class:

```
friend class Remote;
```

A friend declaration can appear in a public, private, or protected section; the location makes no difference. Because the Remote class mentions the TV class, the compiler has to know about the TV class before it can handle the Remote class. The simplest way to accomplish this is to define the TV class first. Alternatively, you can use a forward declaration; we will discuss this option soon.

## Listing 15.1 tv.h

```
// tv.h -- Tv and Remote classes
#ifndef TV_H_
#define TV_H_

class Tv {
public:
    friend class Remote; // Remote can access TV private parts
    enum (Off, On);
    enum (MinVal, MaxVal = 20);
    enum (Antenna, Cable);
    enum (TV, DVD);

    Tv(int s = Off, int mc = 125) : state(s), volume(5),
        maxchannel(mc), channel(2), (Cable), input(TV) {}
    void onoff() {state = (state == On) ? Off : On;}
    bool ison() const {return state == On;}
    bool vol();
    bool volold();
    void changechannel();
    void changeinput();
    void set_mode() {mode = (mode == Antenna) ? Cable : Antenna;}
    void set_input() {input = (input == TV) ? DVD : TV;}
    void settings(); // display all settings
private:
    int state; // on or off
    int volume; // assumed to be digitized
    int maxchannel; // maximum number of channels
    int channel; // current channel setting
    int mode; // broadcast or cable
    int input; // TV or DVD
};
```

The main point to this exercise is class friendship is a natural idiom in which to express some relationships.Without some of friendship, you would either have to make the awkward parts of the Tv class public or construct some awkward, larger class that encompasses both a television and a remote control. And that solution wouldn’t reflect the fact that a single remote control can be used with several televisions.
