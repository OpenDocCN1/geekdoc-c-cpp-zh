    return 0;
}

# Program Notes

Consider this function call:
show_list3(x*x, '!\', 7, mr);

The first argument matches T to double and value to x*x. The remaining three types (char, int, std::string) are placed in the Args pack, and the remaining three values ('!', 7, mr) are placed in the Args pack.

Next, the show_list3() function uses cout to display value (approximately 7.38905) and the string ". That takes care of displaying the first item in the list.

Next comes this call:
show_list3(args...);

This, given the expansion of args... is the same as the following:
show_list3('!\', 7, mr);

As promised, the list is shortened by one item. This time T and value become char and '!', the remaining two types and values are packed into Args and args, respectively. The next recursive call processes these reduced packs. Finally, when args is empty, the version of show_list3() with no arguments is called, and the process terminates.

Here is the output for the two function calls in Listing 18.5:

14, 2.71828, 7.38905, '!', 7, Mr. String objects!
