# More Things to Do to Vectors

There are many programmers commonly do this with arrays, such as search, sort, randomize the order, and so on. No! The STL takes a broader view, defining nonmember functions for these operations. Instead of defining a separate find() member function for each container, it defines a single find() member function that can be for all containers. This design philosophy solves a lot of duplicate work. For example, suppose you have 8 container classes and 10 operations to support. If each class had its own member function, you'd need 8x10, or 80, separate member function definitions. But with the STL approach, you'd just need 10 nonmember function definitions. And if you defined a new container class, provided that followed the proper guidelines, it could use the existing 10 nonmember functions to find, sort, and so on.

On the other hand, the STL sometimes defines a member function even if it defines a nonmember function for the same task. The reason is that for some actions, there is a class-specific algorithm that is more efficient than the more general algorithm. Therefore, the vector swap() will be more efficient than the nonmember swap(). On the other hand, the nonmember version will allow you swap contents between two different kinds of containers.

Let's examine three representative STL functions: for_each(), random_shuffle(), and sort(). The for_each() function can be used with any container class. It takes three arguments. The first two are iterators that define a range in the container, and the last is a pointer to function. (More generally, the last is function object; you'll learn about function shortly.) The for_each() function then applies the pointed-to-function must not alter the value of the container elements. You can use the for_each() function instead of a loop. For example, you can replace the code

```
vector<Review>::iterator pr;
for (pr = books.begin(); pr != books.end(); pr++)
    ShowReview(*pr);
```

with the following:
for_each(books.begin(), books.end(), ShowReview);

This enables you to avoid tiring your hands (and code) with explicit use of iterator variables. 

The random_shuffle() function takes two iterators that specify a range and rearranges the elements in that range random order. For example, the following statement rearranges the order of all the elements in the books vector:
random_shuffle(books.begin(), books.end());

Unlike for_each, which works with any container, this function requires that the container class allow random access, which the vector support. 
The sort() function, too, requires that the container support random access. It comes in two versions. The first version takes two iterators to define a range, and it sorts the range by using the < operator defined for the type element stored in the container. For example, the following sorts the contents of coolstuff in ascending order, using the built-in < operator to compare values:

```
vector<int> coolstuff;
...
sort(coolstuff.begin(), coolstuff.end());
```

If the container elements are user-defined objects, then there has to be an operator() function defined with that type of object to use sort(). For example, you could sort a vector containing Review objects if you provided either a Review member function or a nonmember function for operator< (). Because Review is a structure, its members are public, like this:

```cpp
bool operator<(const Review& r1, const Review& r2)
{
    if (r1.title < r2.title)
        return true;
    else if (r1.title == r2.title && r1.rating < r2.rating)
        return true;
    else
        return false;
}
```

With a function like this in place, you could sort a vector of Review objects (such as books):

```
sort(books.begin(), books.end());
```

This version of the operator<() function sorts in lexicographic order of the title members. If two objects have the same title members, they are then sorted in ratings order. But suppose you want to sort in decreasing order or in order of ratings instead of date. In such a case, you can use the second form of sort(). It takes three arguments. The first two, iterators that indicate the range. The final argument is a pointer to a function (more generally, a function object) to be used instead of operator<() for making the comparison. The return value should be convertible to bool, with false meaning the two arguments are in the wrong order. Here’s an example of such a function:

```cpp
bool WorseThan(const Review& r1, const Review& r2)
    if (r1.rating < r2.rating)
        return true;
    else
        return false;
}
```

With this function in place, you can use the following statement to sort the Review objects by rating:

```
sort(books.begin(), books.end(), WorseThan);
```

Note that the WorseThan function does a total ordering, while operator<() does a weak ordering. If two objects have the same title member, operator<() treats them as equivalent. If you want to sort by rating instead, you can use WorseThan() with the second form of the sort() function. 

Here is the complete code for the program in Listing 16.9:

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

using namespace std;

struct Review {
    string title;
    int rating;
};

bool operator<(const Review& r1, const Review& r2)
{
    if (r1.title < r2.title)
        return true;
    else if (r1.title == r2.title && r1.rating < r2.rating)
        return true;
    else
        return false;
}

bool WorseThan(const Review& r1, const Review& r2)
{
    if (r1.rating < r2.rating)
        return true;
    else
        return false;
}

bool FillReview(Review & rr)
{
    cout << "Enter book title (quit to quit): ";
    getline(cin,rr.title);
    if (rr.title == "quit")
        return false;
    cout << "Enter book rating: ";
    cin >> rr.rating;
    if (!cin)
        return false;
    // get rid of rest of input line
    while (cin.get() != '\n')
        continue;
    return true;
}

void ShowReview(const Review & rr)
{
    cout << rr.rating << "\t" << rr.title << endl;
}

int main()
{
    vector<Review> books;
    Review temp;
    while (FillReview(temp)) {
        books.push_back(temp);
    }

    if (books.size() > 0) {
        cout << "You entered the following:\n";
        for_each(books.begin(), books.end(), ShowReview);

        cout << "Sorted by title:\n";
        sort(books.begin(), books.end());
        for_each(books.begin(), books.end(), ShowReview);

        cout << "Sorted by rating:\n";
        sort(books.begin(), books.end(), WorseThan);
        for_each(books.begin(), books.end(), ShowReview);

        cout << "After shuffling:\n";
        random_shuffle(books.begin(), books.end());
        for_each(books.begin(), books.end(), ShowReview);
    } else {
        cout << "No entries.\n";
    }
    cout << "Bye.\n";
    return 0;
}
```
