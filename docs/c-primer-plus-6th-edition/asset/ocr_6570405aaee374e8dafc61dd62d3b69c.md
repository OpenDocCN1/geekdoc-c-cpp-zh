The effects of calling setf() can be undone with unsetf(), which has the following
prototype:

```
void unsetf(fmtags mask);
```

Here is a bit pattern. All bits set to 1 in mask cause the corresponding bits to be
unset. That setf() sets bits to 1, and unsetf() sets bits to 0. Here's an example:

```
cout.setf(ios_base::showpoint);    // show trailing decimal point
cout.unsetf(ios_base::showpoint);   // don't show trailing decimal point
cout.setf(ios_base::boolalpha);      // display true, false
cout.unsetf(ios_base::boolalpha);     // display 1, 0
```

You may have noticed that there is no special flag to indicate the default mode for de-playing floating-point numbers. Here's how the system works. Fixed notation is used if the
fixed bit, and only the fixed bit is set. Scientific notation is used if the scientific bit and
only the scientific bit is set.Any other combination, as no bits set or both bits results,
the default mode is used. So one way to invoke the default mode is:

```
cout.setf(0, ios_base::floatfield);    // go to default
```

The second argument turns both off, and the first argument doesn't set any bits. A
orter way to accomplish the same end is to use unsetf() with ios_base::floatfield:
cout.unsetf(ios_base::floatfield);    // go to default

If you know for certain that cout were in the fixed state, you could
ios_base::fixed as an argument to unsetf(), but using ios_base::floatfield works,
regardless of the current state of cout, so it's a better choice.
