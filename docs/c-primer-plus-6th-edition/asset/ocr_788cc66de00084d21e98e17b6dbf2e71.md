# The Null Pointer and new

Much code was written when new (the old new) returned a null pointer upon failure.
Some compilers handled the transition to the new new by letting the user set a flag or switch to choose which behavior stayed. Currently, the standard provides for an alternative form of new that still returns a null pointer. Its use looks like this:

```
int * pi = new (std::nothrow) int;
int * pa = new (std::nothrow) int[500];
```

Using this function, you could rewrite the core of Listing 15.13 this way:
Big * pb;

```
pb = new (std::nothrow) Big[10000]; // 1,600,000,000 bytes
if (pb == 0)
{
    cout << "Could not allocate memory. Bye.\n";
    exit(EXIT_FAILURE);
}
```
