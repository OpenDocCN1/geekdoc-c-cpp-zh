Note that the following code makes sense whether or not the first input statement reads the entire line:

```
while (cin.get() != '\n') continue;
```

If get() reads the whole line, it still leaves the newline in place, and this code reads discards the newline character. If get() just reads part of the line, this code reads discards the rest of the line. If you didn't dispose the rest of the line, the next input statement would begin at the beginning of the remaining input on the first input line. With this example, that would result in the program reading the string sniffer into the title array.

# # File Input and Output

Most computer programs work with files. Word processors create document files. Database programs create and search files of information. Compilers create source code files and generate executable files. A file itself is a bunch of bytes stored on some device, perhaps magnetic tape, a floppy disk, or a hard disk. Typically, the operating system manages files, keeping track of their locations, their sizes, when they were created, and so on. Unless you're programming the operating system, you normally dont to worry about those. What you need is a way to connect to a file, a way to have a program read the contents of a file, and a way to have a program create and write to files. Redirection (as discussed earlier in this chapter) can provide some file support, but it is more limited than explicit I/O from within a program. Redirection from the operating system, from C++, is not available on all systems. This book has already touched on file I/O, and this chapter explores the topic more thoroughly.

The C++ I/O class package handles file input and output as it handles input and output. To write to a file, you create an ostream object and use the ostream methods, such as the << insertion operator or write(). To read a file, you create an ifstream object and use the ifstream methods, such as the >> operator or get(). Files require more management than standard input and output. For example, you might want to associate a newly opened file with a stream. You can open a file in read-only, write-only mode, or read-write mode. If you want to write to a file, you might want to create a new file, replace an old file, or add one to a file. You might want to move back and forth through a file. To help handle these tasks, C++ defines several new classes in the fstream (formerly fstream.h) header file, including the ifstream class for file input and the ofstream class for file output. C++ also defines the fstream class for simultaneous I/O. These classes are derived from the iostream header file, so objects of these new classes are able to use the methods you've already learned.
