## 使用修改后的 Student 类

再次，是时候测试新类了。注意，Student 类的两个版本具有完全相同的公共接口，因此你可以用相同的程序测试这两个版本。唯一的区别是，你必须包含 `student.i` 而不是 `student.h`，并且链接程序时需要使用 `studenti.cpp` 而不是 `student.cpp`。列表 14.6 显示了该程序。确保将其与 student.cpp 一起编译。

```cpp

#include <iostream>

}
```
