## 整数类型

整数是没有小数部分的数字，例如 2、98、-5286 和 0。假设你将无限数量视为极限，则存在无限多个整数，因此有限的计算机内存无法表示所有可能的整数。因此，一种语言只能表示整数的一个子集。某些语言提供一种整数类型（一型通用），C++ 提供了几种选择。这给了你选择最适合程序特定要求的整数类型的选项。这种将类型与数据匹配的关注预示着 OOP 的设计数据类型。

各种 C++ 整数类型在用于保存数据的内存量上有所不同。更大的内存块可以表示更大的整数值范围。有些类型（有符号类型）可以表示正值和负值，而其他类型（无符号）则不能表示负值。描述整数所用内存量的常用术语是宽度。C++ 的基本整数类型，按宽度递增的顺序排列，是 char、short、int、long，以及 C++11 中的 long long。每种都有有符号和无符号版本。这提供了十种不同的整数类型的选择！让我们更详细地看看这些整数类型。因为 char 有一些特殊属性（它最常用于表示字符而不是数字），本章涵盖其他类型。

## short、int、long 和 long 整数类型

计算机内存由称为位组成。（参见本章后面的“位和字节”。）通过使用不同数量的位来存储值，C++ 的 short、int、long 和 long long 可以表示多达四种不同的整数宽度。如果每种类型在所有系统上始终具有某种特定宽度会很方便——例如，如果 short 始终为 16 位，int 始终为 32 位，等等。但生活并不那么简单。

## 简单变量

没有一种选择适合所有计算机设计。C++ 提供了一个灵活的标准，具有一些保证的最小尺寸，其取自 C。以下是你得到的：

- 一个 short 整数至少为 16 位宽。
- 一个 int 整数至少与 short 一样大。
- 一个 long 整数至少为 32 位宽且至少与 int 一样大。
- 一个 long long 整数至少为 64 位宽且至少与 long 一样大。

## 位和字节

计算机内存的基本单位是位。将位视为你可以设置为关或开的电开关。关表示值 0，开表示值 1。8 位的内存块可以设置为 256 种不同的组合。数字 256 来自于每个位有两个可能设置，使得 8 位的组合总数为 2 x 2 x 2 x 2 x 2 x 2 x 2 x 2 = 256。因此，8 位单元可以表示，例如，0 到 255 或 -128 到 127 的值。每增加一位，组合数就会翻倍。这意味着你可以将 16 位设置为 65,536 个不同的值，将 32 位单元设置为 4,294,967,296 个不同的值，将 64 位单元设置为 18,446,744,073,709,551,616 个不同的值。作为比较，unsigned long 不能表示地球当前的人口或我们银河系中恒星的数量，但 long 可以。（等等，unsigned long 不能表示地球当前的人口或我们银河系中恒星的数量，但 long 可以。）

字节意味着 8 位的内存单元。在这种意义上，字节是描述计算机内存量的度量单位，其中千字节等于 1024 字节，兆字节等于 1,024 千字节。然而，C++ 对字节的定义不同。C++ 字节由最少相邻的位组成，以容纳实现的基本字符集。也就是说，可能的值数必须等于或超过不同字符的数量。在美国，基本字符集通常是 ASCII 和 EBCDIC 集合，它们由 8 位表示，因此在这些系统上 C++ 字节通常为 8 位。对于更大的字符集，例如 Unicode，一些实现可能使用 16 位或 32 位字节。有些使用八位字节来表示 8 位字节。

许多系统目前使用最小保证，使得 16 位和 long 为 32 位。这仍然为 int 留下了几个选择。它可以为 16、24 或 32 位宽并满足标准。它可以为 64 位，前提是 long 和 long long 至少与之一样宽。通常，int 对于 Windows XP、Windows Vista、Windows 7、MacOS OS X、VAX 以及许多其他小型计算机实现的 IBM PC 实现是 16 位（与 short 相同）。一些实现让你可以选择如何处理 int（你的实现使用什么？下一个示例展示了如何在不打开手册的情况下确定你系统的限制。）类型宽度在实现之间的差异会导致你在将 C++ 程序从一个环境移动到另一个环境时出现问题，包括同一系统上的不同编译器。但稍加注意，如本章后面所述，可以最大程度地减少这些问题。

## 第 3 章 处理数据

你使用这些类型名称来声明变量，就像你使用 int 一样：

```
short score;                      // creates a type short integer variable
int temperature;               // creates a type int variable
long position;                  // creates a type long integer variable
```

实际上，short 是 short int 的简写，long 是 long int 的简写，但几乎没有人使用较长的形式。

这四种类型——int、short 和 long——是有符号名称，意味着每个将其范围大致分为正值和负值。例如，16 位 int 的范围从 -32,768 到 +32,767。
