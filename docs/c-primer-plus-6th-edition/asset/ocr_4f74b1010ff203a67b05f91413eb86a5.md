endl manipulator flushes the buffer and inserts a newline character. You use these manipulators
law you would use as a variable name:

```
cout << "Hello, good-looking!" << flush;
cout << "Wait just a moment, please." << endl;
```

Manipulators are, in fact, functions. For example, you can flush the cout buffer by calling the flush() function directly:
flush(cout);

However, the ofstream overloads the << insertion operator in such a way that the following expression gets replaced with the flush(cout) function call:
cout << flush

Thus, you can use the more convenient insertion notation to flush with success.

# Formatting with cout

Theostream insertion operator converts values to text form. By default, they format values as:

+   - A type char value, if it represents a printable character, is displayed as a character in a field one character wide.
- Numeric integer types are displayed as decimal integers in a field wide enough to hold the number and, if present, a minus sign.
- Strings are displayed in a field equal to the length of the string.

The default behavior for floating-point types has changed. The following are the differences between ancient and current C++ implementations:

+   - New style—Floating-point types are displayed with a total of six digits, except that trailing zeros are not displayed.(Note that the number of digits has no connection to the precision to which the number is stored.) The number is displayed in fixed-point notation or in E notation (see Chapter 3, “Dealing with Data”), depending on the value of the number. In particular, E notation is used if the exponent is 6 greater or -5 smaller. Again, the field is wide enough to hold the number and, if present, a minus sign. The default behavior corresponds to using the C library function fprintf with a % specifier.
- Old style—Floating-point types are displayed with six places to the right of the decimal, except that trailing zeros aren't displayed.(Note that the number of digits displayed has no connection to the precision to which the number is stored.) The number is displayed in fixed-point notation or in E notation (see Chapter 3), depending on the value of the number.Again, the field is wide enough to hold the number and, if present, a minus sign.

Because each value is displayed in a width equal to its size, you have provide spaces between values explicitly; otherwise, consecutive values would run together.
