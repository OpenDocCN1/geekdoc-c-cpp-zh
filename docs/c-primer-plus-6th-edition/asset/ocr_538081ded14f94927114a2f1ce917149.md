# Which cin.get() Should You Use?

Listing 4.5 in Chapter 4 uses this code:

```
char name[ArSize];
...
cout << "Enter your name:\n";ncin.get(name, ArSize).get();
```

The last line is equivalent to two consecutive function calls:

```
cin.get(name, ArSize);
cin.get();
```

One version of cin.get() takes two arguments: the array name, which is the address of the string (technically, type char*), and ArSize, which is an integer of type int. (Recall that the name of an is the address of its first element, the name of a character array is type char*). Then the program uses cin.get() with no arguments. And most recently, we've used cin.get() this way:

```
char ch;
cin.get(ch);
```

This cin.get() has one argument, and it is type char.
Again it is time for you of familiar with C to get excited or confused. In C if a function takes a pointer-to-char and int as arguments, you cannot successfully use the function with a single argument of that type. But you can do so in C++ because the language supports an OOP feature called function overloading. Overloading allows you to create different functions that have the same name, provided that they have different argument lists. If, for example, you use cin.get(name, ArSize) in C++, the compiler finds the version of cin.get() that uses a char* as an argument. And if you use cin.get(ch), the compiler fetches the version that uses a single type argument. And if the code provides no arguments, the compiler uses the version of cin.get() that takes no arguments.

Function overloading enables you to use the same name for related functions that perform the same basic task in different ways or for different types. This is another topic awaiting you in Chapter 8. Meanwhile, with the istream class, you can customize to function overloading by using the get() examples that come with istream. To distinguish the different function versions, we'll include the argument list when referring to them. Thus, cin.get() means the version that takes no arguments, and cin.get(char) means the version that takes one argument.
