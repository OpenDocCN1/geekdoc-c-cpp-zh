# Chapter 17 Input, Output, and Files

If you want a program to examine every character, you should use one of the get () methods. For example, a word-counting program could use white space to determine when a word comes to an end. Of the two get () methods, the get (char &) method has the classifier interface. The main advantage of the get (void) method is that it is closely resembles the standard C getchar() function, which means you can convert a C program to a C++ program by including iostream instead of stdio.h, globally replacing getchar() with cin.get(), and globally replacing C::put() with cout.put().

String Input: getline(), get (), and ignore ()
Next, let's review the getline member functions introduced in Chapter 4,"Custom Types".The getline() member function and the string-reading version of get () read strings, and both have the same function signatures (simplified from the more general template declaration):

```
istream & get (char *, char);
istream & get (char *, int);
istream & getline(char *, int, char);
istream & getline(char *, int);
```

The first argument, recall, is the location to place the input string. The second argument is one greater than the maximum number of characters to read. The additional character leaves space for the terminating newline character used in storing the input as a string.) The third argument specifies a character to act as a delimiter to input. The versions with just arguments use the newline as a delimiter. Each function up to the maximum characters or until it encounters the delimiter character, whichever comes first.

For example, the following code reads input into the character array line:

```
char line[50];
c.get(line, 50);
```

The cin.get() function reads input into the array after encountering 49 characters, by default, after encountering a newline character, whichever comes first. The difference between get() and get() is that get() leaves the newline in the input stream, making the first character by the next input operation, whereas getline() extracts and discards the newline character from the input stream.

Chapter 4 illustrated using the two-argument form for these two functions. Now let's look at the three-argument versions. The third argument is the delimiter character. Entering the delimiter causes input to cease, even if the maximum number of characters hasn't been reached. So by default, both methods read input if they reach the end of a line before reading the allotted number of characters. Just as in the default case, get() leaves the delimiter in the input queue, and getline() does not.
