# Observations About Returning Objects

When a member or standalone function returns an object, you have choices. The function could return a reference to an object, a constant reference to an object, an object, or a constant object. By now, you've seen examples of all the last, so it's a good time to review your options.

# Returning a Reference to a const Object

The usual reason for using a const reference is efficiency, but there are restrictions on when this can be used. If a function returns an object that is passed to it, either by object invocation or as a method argument, you can increase the efficiency of the method by having it return a reference. For example, you wanted to write a function Max() that returned the larger of two Vector objects, where Vector is the class developed in Chapter 11. The function would be used in this manner:

```
Vector force1(50,60);
Vector force2(10,70);
Vector max;
max = Max(force1, force2);
```

Either of the following two implementations work:

```
// version 1
Vector Max(const Vector &v1, const Vector &v2)
{
  if (v1.magval() > v2.magval())
    return v1;
  else
    return v2;
}
```

```
// version 2
const Vector &Max(const Vector &v1, const Vector &v2)
{
  if (v1.magval() > v2.magval())
    return v1;
  else
    return v2;
}
```
