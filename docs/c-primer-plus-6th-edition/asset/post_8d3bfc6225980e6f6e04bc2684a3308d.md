## The Array Function Idiom

Suppose you want a function to process an array, say of type double. If the function is intended to modify the array, the prototype might look like this:

```cpp
void f_modify(double array[], int n);
```

If the function preserves values, the prototype might look like this:

```cpp
void f_no_change(const double array[], int n);
```

Of course, you can omit the variable names in the prototypes, and the return type might be something other than void. The main points are that array is a pointer to the first element of the array and that the number of elements is passed as an argument; either function can be used with any size of array as long as it is an array of double:

```cpp
double rewards[1000];
double faults[50];
f_modify(rewards, 1000);
f_modify(faults, 50);
```

This idiom (pass the array name and size as arguments) works by passing two numbers—the array address and the number of elements. As you have seen, the function loses some knowledge about the original array; for example, it can't use sizeof to get the size and relies on you to pass the correct number of elements.

## Functions Array Ranges

As you've seen, C++ functions that process arrays need to be informed about the kind of data in the array, the location of the beginning of the array, and the number of elements in the array. The traditional C/C++ approach to functions that process arrays is to pass a pointer to the start of the array as one argument and to pass the size of the array as a second argument. (The pointer tells the function where to find the array and the kind of data in it.) gives the function the information it needs to find all the data.

There is another approach to giving a function the information it needs: specify a range of elements. This can be done by passing two pointers—one identifying the start of the array and one identifying the end of the array. The C++ Standard Template Library (STL), presented in Chapter 16, "The string Class and the Template Library", for example, generalizes the range approach. The STL approach uses the concept of “one past the end” to indicate an extent. That is, in case of an array, the array identifying the end of the array would be a pointer to the location just after the last element. For example, suppose you have this declaration:

```cpp
double element[20];
```

Then the two pointers element and element + 20 define the range. First, element, being the name of the array, points to the first element. The expression element + 19 points to the last element (that is, element[19]), so element + 20 points to one past the end of the array. Passing a range to a function tells which elements to process.
