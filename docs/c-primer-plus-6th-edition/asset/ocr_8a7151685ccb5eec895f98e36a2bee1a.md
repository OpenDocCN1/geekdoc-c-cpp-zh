No choice is suitable for all computer designs. C++ offers a flexible standard with some guaranteed minimum sizes, which it takes from C. Here's what you get:

+   - A short integer is at least 16 bits wide.
- An int integer is at least as big as short.
- A long integer is at least 32 bits wide and at least as big as int.
- A long long integer is at least 64 bits wide and at least as big as long.

# Bits and Bytes

The fundamental unit of computer memory is the bit. Think of bit as an electric switch that you can set to either off or on. Off represents value 0, and on represents the value 1. An 8-bit chunk of memory can be set to 256 different combinations. The number 256 comes from the fact that each bit has two possible settings, making the total of combinations for 8 bits 2 x 2 x 2 x 2 x 2 x 2 x 2 x 2 = 256. Thus, an 8-bit unit can represent, say, the values of 0 through 255 or -128 through 127. Each additional bit doubles the number of combinations. This means you can set a 16-bit to 65,536 different values, a 32-bit unit to 4,294,967,296 different values, and a 64-bit unit to 18,446,744,073,709,551,616 different values. As a point of comparison, unsigned long cannot the Earth's current population or the number of stars in our galaxy, but long can.

A byte means an 8-bit unit of memory. In this sense the byte is the unit of measurement that describes the amount of memory in a computer, with a kilobyte equal to 1024 bytes and a megabyte equal to 1,024 kilobytes. However, C++ defines byte differently. The C++ byte consists of least adjacent bits to accommodate the basic character set for the implementation. That is, the number of possible values must equal or exceed the number of distinct characters. In the United States, the basic character sets are usually ASCII and EBCDIC sets, which are accounted for by 8 bits, so the C++ byte is typically 8 bits on systems using those. For larger character sets, such as Unicode, some implementations may use a 16-bit or 32-bit byte. Some use the octet to denote an 8-bit byte.

Many systems currently use the minimum guarantee, making 16 bits and long 32 bits. This still leaves several choices for int. It could be 16, 24, or 32 bits in width and meet the standard. It could be 64, providing that long and long are are at least that wide. Typically, int is 16 bits (the same as short) for IBM PC implementations for Windows XP, Windows Vista, Windows 7, MacOS OS X, VAX, and many other mincomputer implementations.
