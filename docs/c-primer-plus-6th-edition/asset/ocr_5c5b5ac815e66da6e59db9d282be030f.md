```
int x = 10;
int y = 23;
int &&& r1 = 13;
int &&& r2 = x + y;
double &&& r3 = std::sqrt(2.0);
```

Note that r2 really binds to the value to which x + y evaluates at that time. That is, r2 binds to the value 23, and r2 is unaffected by subsequent changes to x or y.

Interestingly, binding an rvalue to an rvalue reference results in the value being stored in a location whose address can be taken. That is, although you cannot apply the & operator to 13, you can apply it to r1. This binding of the value to particular addresses is what makes it possible to access the data through the rvalue references.

Listing 18.1 provides a short example illustrating some of these points about value references.

# Listing 18.1 rvref.cpp

```
// rvref.cpp -- simple uses of rvalue references
#include <iostream>

inline double f(double tf) {return 5.0*(tf-32.0)/9.0};
int main() {
    using namespace std;
    double &&r1 = 21.5;
    double &&r2 = 1.8 * tc + 32.0;
    double &&r3 = f(r2);
    cout << "tc value and address: " << tc << ", " << &tc << endl;
    cout << "r1 value and address: " << r1 << ", " << &r1 << endl;
    cout << "r2 value and address: " << r2 << ", " << &r2 << endl;
    cout << "r3 value and address: " << r3 << ", " << &r3 << endl;
    cin.get();
    return 0;
}
```
