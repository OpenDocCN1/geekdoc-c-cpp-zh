## Program Notes

The program in Listing 5.11 has some interesting points. One, of course, is the test. You want the loop to continue as long as word is not mate. That is, you want the test to continue as long as strcmp() says the two strings are not the same. The most obvious test for that is:
`strcmp(word, "mate") == 0 // strings are not the same`

This statement has the value 1 (true) if the strings are unequal and the value 0 (false) if they are equal. But what strcmp(word, "mate") by itself? It has a nonzero value (true) if the strings are unequal and the value 0 (false) if the strings are equal. In essence, the function returns true if the strings are different and false if they are the same. You can use the function instead of the whole relational expression. This produces the same behavior and less typing. Also it's the way C and C++ programmers have traditionally used strcmp().

## Testing for Equality or Order

You can use strcmp() to test C-style strings for equality or order. The following expression is true if str1 and str2 are identical:

```cpp
strcmp(str1,str2) == 0
```

## Introducing for Loops

The expressions

```cpp
strcmp(str1, str2) != 0
```

and

```cpp
strcmp(str1, str2)
```

are true if str1 and str2 are not identical. The following expression is true if str1 precedes str2:

```cpp
strcmp(str1, str2) < 0
```

And the following expression is true if str1 follows str2:

```cpp
strcmp(str1, str2) > 0
```

Thus, the strcmp() function can play the role of the ==, !=, <, and > operators, depending on how you set up a test condition.

Next, compare1.cpp uses the increment operator to march the variable ch through the alphabet:

You can use the increment and decrement operators with character variables because char is an integer type, so the operation actually changes the integer code stored in the variable. Also note that using an array index makes it simple to change individual characters in a string:

## Comparing string Class Strings

Life is a bit simpler if you use string classes instead of C-style strings because the class design allows you to use relational operators to make the comparisons. This is possible because one can define class functions that "overload," or redefine, operators. Chapter 12, "Classes and Dynamic Memory Allocation," discusses how to incorporate this feature into classes, but from a practical standpoint, all you need to know is that you can use the relational operators with string class objects. ## Program Notes

In Listing 5.12, the following test condition uses a relational operator with a string object on the left and a C-style string on the right:
`word != "mate"`

The way string class overloads the != operator allows you to use it as long as least one of the operands is a string object; the remaining operand can be either a string object or a C-style string.

The string class design allows you to use a string object as a single entity, as in the relational test expression, or as an aggregate object for which you can use array notation to extract individual characters.

As you can see, you can achieve the same results with C-style strings as string objects, but programming with strings is simpler and more intuitive.
