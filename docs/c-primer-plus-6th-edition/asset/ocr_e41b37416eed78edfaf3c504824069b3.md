# for Versus while

In C++ the for and while loops are essentially equivalent. For example, the for loop

```
for (init-expression, test-expression; update-expression)
{
    statement(s)
}
```

could be rewritten in this way:

```
init-expression;
while (test-expression)
{
    statement(s)
    update-expression;
}
```

Similarly, the while loop

```
while (test-expression)
    body
```

could be rewritten in this way:

```
for (; test-expression;)
    body
```

This for loop requires three expressions (or, more technically, one statement followed
by expressions), but they can be empty expressions (or statements). Only the two
semicolons are mandatory. Incidentally, a missing test expression in a for loop is construed
as true, this loop runs forever:

```
for (; ; )
    body
```

Because for loops and while loops are nearly equivalent, the one you use is largely
matter of style. There are three differences. As just mentioned, that is an omitted
condition in a for loop is interpreted as true. The second is that you can use the initialization-
st in a for loop to declare a variable that is local to the loop; you can't do
with a while loop. Finally, there is a slight difference that the body includes a continue
statement, which is discussed in Chapter 6. Typically, programmers use for loops
