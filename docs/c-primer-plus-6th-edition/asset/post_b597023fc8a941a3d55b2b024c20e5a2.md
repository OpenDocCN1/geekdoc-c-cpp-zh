## The if Statement

When a C++ program must choose whether to take a particular action you usually implement the choice with if. The if comes in two forms: if and if else. Let's investigate the simple if. It is modeled after ordinary English, as in "If you have money, you get cookie." The if statement directs a program to execute statement or block if test condition is true and to skip statement block if the condition is false. Thus, an if statement lets a program decide whether particular statement should be executed.

The syntax for the if statement is similar to that of while:

```cpp
if (test-condition)
    statement
```

A true test condition causes the program to execute statement, which can be a single statement or block. A false test condition causes the program to skip statement (see Figure 6.1). As test, an if condition is cast to a bool value, zero becomes false and nonzero becomes true. The entire if construction counts as a single statement. Most often, test condition is a relational expression such as those used to control loops. Suppose, for example, that you want a program that counts the spaces in the input as well as the total number of characters. You can use cin.get(char) in a while loop to read the characters and then use an if statement to identify and count spaces. Listing 6.1 does just that, using the period (.) to recognize the end of a sentence.

### Listing 6.1 if.cpp

```cpp
// if.cpp using the if statement
#include <iostream>
int main() {
    using std::cin;
    using std::cout;
    char ch;
    int spaces = 0;
    int total = 0;
    cin.get(ch);
    while (ch != '.') // quit at end of sentence
    {
        if (ch == ' ') // check if ch is a space
            ++spaces;
        ++total; // done every time
        cin.get(ch);
    }
    cout << " " << spaces << " spaces, " << total << " characters in sentence" << "\n";
    return 0;
}
```

Here's some sample output from the program in Listing 6.1:
```
The balloon was an inflatable dog.
6 spaces, 46 characters in sentence
```
As the comments in Listing 6.1 indicate, ++spaces statement is executed only when ch is a space. Because it is outside the if statement, ++total statement is executed in every cycle. Note that the newline character is generated by pressing Enter.

## The if else Statement

Whereas an if statement lets a program decide whether particular statement block is executed, an if else statement lets a program decide which of two statements or blocks is executed. It's an invaluable statement for creating alternative courses of action. C++ if else statement is modeled after English, as in "If you have money, you get cookie, else you just get air." The if else statement has this general form:

```cpp
if (test-condition)
  statement1
else
  statement2
```

if test-condition is true, or nonzero, the program executes statement1 and skips over statement2. Otherwise, when test-condition is false, or zero, the program skips statement1 and executes statement2 instead.

```cpp
if (answer == 192)
  cout << "That's right!"
else
  cout << "You'd better review Chapter 1 again.";
```

Each statement can be either a single statement or a statement delimited by braces (see Figure 6.2). The entire else statement constructs syntactically as a single statement.

For example, suppose you want to alter incoming text by scrambling the letters while keeping the newline character intact. In that case, each line of input is converted to an output line of equal length. This means your program to take one course of action for newline characters and a different course of action for all other characters. As Listing 6.2 shows, if else makes this task easy. The listing also illustrates the std::scope, one of the alternatives to a using directive.

### Listing 6.2 ifelse.cpp

```cpp
// ifelse.cpp using the if else statement
#include <iostream>
int main()
{
    char ch;

    std::cout << "Type, and I shall repeat.\n";
    cin.get(ch);
    while (ch != '\n')
    {
        if (ch == '\n')
            std::cout << ch;    // done if newline
        else
            std::cout << ++ch;  // done otherwise
        cin.get(ch);
    }
    // try ch + 1 instead of ++ch for interesting effect
    std::cout << "\nPlease cause the slight confusion.\n";
    cin.get();
    cin.get();
    return 0;
}
```

Here's some sample output from the program in Listing 6.2:
```
Type, and I shall repeat.
An ineffable joy suffused me as I beheld
An inflatable influence
The wonders of modern computing.
others of performing
Please cause the slight confusion.
```

Note that one of the comments in Listing 6.2 suggests changing ++ch to ch+1 for an interesting effect. Can you deduce what it will be? If not, try it out and see if you can explain what's happening. (Hint: Think about how count handles different types).

## Formatting if else Statements

Keep in mind the two alternatives in an if else statement must be single-statements. If you need more than one statement, you must use braces to collect them into a single block statement. Unlike some languages, such as BASIC and FORTRAN, C++ does not automatically consider everything between if and else a block, so you have to use braces to make the statements a block. The following code, for example, produces a compiler error:

```cpp
if (condition)
    statement1;
    statement2;
else
    statement3;
```
In this case, statement2 is considered part of the if block, and statement3 is the else statement. To fix this, use braces:

```cpp
if (condition)
{
    statement1;
    statement2;
}
else
{
    statement3;
}
```

## The else if else Construction

Computer programs, like life, might present you with a choice of more than two selections. You can extend the C++ if else statement to meet such a need. As you've seen, the else should be followed by a single statement, which can be a block.

```cpp
if (test-condition1)
    statement1
else if (test-condition2)
    statement2
else
    statement3
```

If test-condition1 is true, the program executes statement1 and skips the rest. If test-condition1 is false, the program tests test-condition2. If test-condition2 is true, it executes statement2. If both are false, it executes statement3. This format is much cleaner than nesting if else statements:

```cpp
if (test-condition1)
    statement1
else
{
    if (test-condition2)
        statement2
    else
        statement3;
}
```

This looks like a new structure—an else if contained within a second. This revised format looks much cleaner, and it enables you to skip through the code to pick out the different alternatives. This entire construction still feels as one statement.
