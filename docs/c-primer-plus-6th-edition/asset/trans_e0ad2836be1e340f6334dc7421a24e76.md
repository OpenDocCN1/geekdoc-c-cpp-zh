

## 附录 D 运算符优先级

某些符号，例如 * 和 &，用于多个运算符。在这种情况下，一种形式是一元的（一个操作数），另一种是二元的（两个操作数），编译器使用上下文来确定其含义。表 D.1 将运算符组标记为一元或二元，其中同一符号用于两种方式。

以下是一些关于优先级和结合性的示例。
这里有一个示例，编译器必须决定是先将 5 加到 3 还是先将 5 乘以 6：

```
3 + 5 * 6
```

* 运算符的优先级高于 + 运算符，因此它首先应用于 5，使表达式变为 3 + 30，即 33。
这里有一个示例，编译器必须决定是先将 6 除入 120 还是先将 6 乘以 5：

```
120 / 6 * 5
```

/ * 具有相同的优先级，但这些运算符从左到右结合。这意味着共享操作数（6）左侧的运算符先被应用，因此表达式变为 20 * 5，即 100。
这里有一个示例，编译器必须决定是先递增 str 还是先解引用 str：

```
char * str = "Woa";
char ch = *str++;
```

++ 运算符的优先级高于一元 * 运算符。这意味着递增运算符作用于 str 而不是 *str。也就是说，该操作递增指针，使其指向下一个字符，而不是更改指向的字符之后的内容。然而，由于 *str 是后缀形式，指针在将 *str 的值赋给 ch 之后才递增。因此，此表达式将 w 赋给 ch 并将 str 移动到指向 h 字符。
这里有一个类似的示例：

```
char * str = "Woa";
char ch = ++str;
```

++ 运算符和一元 * 运算符具有相同的优先级，但从右到左结合。因此，同样是 str 而不是 *str 被递增。由于 ++ 运算符是前缀形式，首先递增 str，然后再解引用结果。因此，str 移动到指向 h 字符，并将 h 字符赋给 ch。
请注意，表 D.1 在“优先级”列中使用二元或一元来区分使用相同符号的两个运算符，例如一元取地址运算符和二元按位与运算符。

## 其他运算符

为避免终端臃肿，本书正文未涵盖三组运算符。第一组是按位运算符，可让你操作值中的单个位；这些运算符继承自 C。第二组是双成员解引用运算符；它们是 C++ 的新增功能。第三组包括 C++11 新增的运算符：alignof 和 noexcept。本附录简要总结了这些运算符。

## 按位运算符

按位运算符对整数值的位进行操作。例如，左移运算符将位向左移动，按位取反将每个 1 转换为 0，每个 0 转换为 1。C++ 总共有六个这样的运算符：<<、>>、-、&、| 和 ^。

## 移位运算符

左移运算符的语法如下：

```
value << shift
```

这里 value 是要移位的整数，shift 是要移位的位数。例如，以下将值 13 中的所有位向左移动三位：

```
13 << 3
```

空出的位置用零填充，移出末端的位被丢弃（图 1.）。

由于每个位位置代表的值是其右侧的两倍（参见附录 A,"数字基数"），将一位移位相当于将值乘以 2。同样，将两位移位相当于乘以 2²，将 n 位移位相当于乘以 2^n。因此，13 << 3 的值为 13×2³，即 104。

左移运算符提供了在汇编语言中经常找到的功能。然而，汇编左移运算符直接更改寄存器的内容，而 C++ 左移运算符生成新值而不更改现有值。例如，考虑以下内容：

```
int x = 20;
int y = x << 3;
```

此代码不会更改 x 的值。表达式 x << 3 使用 x 的值生成新值，就像 x + 3 生成新值而不更改 x 一样。
如果你想使用左移运算符更改变量的值，你必须同时使用赋值。你可以使用常规赋值或 << 运算符，它将移位与赋值结合起来：

```
x = x << 4;
y <<= 2;
// regular assignment
// shift and assign
```
