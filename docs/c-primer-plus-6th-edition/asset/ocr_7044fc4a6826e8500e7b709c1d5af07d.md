# Use const When You Can

There are three strong reasons to declare reference arguments as references to constant data:

+   * Using const protects you against programming errors that inadvertently alter data.
* Using const allows a function to process both const and non-const actual arguments, whereas a function that omits const in the prototype can only accept non-const data.
* Using a const reference allows the function to generate and use a temporary variable appropriately.

You should declare formal reference arguments as const whenever it is appropriate to do.

C++11 introduces a second kind of reference, called an rvalue reference, that can refer to an rvalue. It is declared using:

```
double && ref = std::sqrt(36.00); // not allowed for double &&
double j = 15.0;
double && jref = 2.0*j + 18.5; // not allowed for double &&
std::cout << ref << '\n'; // display 6.0
std::cout << jref << '\n'; // display 48.5
```

The rvalue reference was introduced mainly to help library designers provide more efficient implementations of certain operations. Chapter 18,"Visiting the New C++ Standard," discusses how value references are used to implement an approach called move semantics. The original reference type (the one declared using a single &) is now called an lvalue reference.

# Using References with a Structure

References work wonderfully with structures and class, C++ user-defined types.
Indeed, references were introduced primarily for use with these types, not for use with the basic-in types.

The method for using a reference to a basic variable:as a function parameter is the same as the method for using a reference to a structure:You use the & operator when declaring a structure parameter. For example, suppose we have the following structure:

```
struct free_throws {
  std::string name;
  int made;
  int attempts;
  float percent;
};
```

Then a function using a reference to this type could be prototyped as follows:

```
void set_pc(free_throws & ft); // use a reference to a structure
```

If the intent is that the function does not alter the structure, use const:
void display(const free_throws & ft); // don't allow changes to structure
