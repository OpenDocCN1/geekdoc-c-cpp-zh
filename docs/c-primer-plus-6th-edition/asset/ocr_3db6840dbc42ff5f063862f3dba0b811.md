With a function like this in place, you could sort a vector of Review objects (such as books):

```
sort(books.begin(), books.end());
```

This version of the operator<() function sorts in lexicographic order of the title members. If two objects have the same title members, they are then sorted in ratings order. But suppose you want to sort in decreasing order or in order of ratings instead of date. In such a case, you can use the second form of sort(). It takes three arguments. The first two, iterators that indicate the range. The final argument is a pointer to a function (more generally, a function object) to be used instead of operator<() for making the comparison. The return value should be convertible to bool, with false meaning the two arguments are in the wrong order. Here’s an example of such a function:

```
bool WorseThan(const Review& r1, const Review& r2)
    if (r1.rating < r2.rating)
        return true;
    else
        return false;
```

With this function in place, you can use the following statement to sort the books of Review objects in increasing rating values:

```
sort(books.begin(), books.end(), WorseThan);
```

Note that the WorseThan() function does a complete job than operator<() of ordering Review objects. If two objects have the same title member, the operator<() sorts by using the rating. But if two objects have the same rating member, WorseThan() treats them as equivalent. The first kind of ordering is called total ordering, if a < b and b < a are false, then a and b must be identical. With strict weak ordering, that’s not so. They might be identical, or they might just have one part that is the same, such as the rating member in the WorseThan() example. Instead of saying the two objects are identical, the best you can do for strict weak ordering is that they are equivalent.
