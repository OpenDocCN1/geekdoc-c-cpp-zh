```
cin.operator>>(fname); // istream class method
operator>>(cin, lname); // regular function
```

让我们更仔细地检查字符串输入函数。两者如前所述，都找到要输入的目标字符串。存在限制。第一个限制因素是字符串的最大允许大小，由常量 string::npos 表示。这通常是 unsigned int 的最大值，因此对于普通的交互式输入来说，它不会构成实际限制。但是，如果你尝试将整个文件的内容读入单个字符串对象，则它可能成为一个因素。第二个限制因素是程序可用的内存量。

字符串类的 getline 函数从输入中读取并存储到字符串对象中，直到出现以下三种情况之一：

- 遇到文件结束，在这种情况下输入流的 eof 被设置，意味着 fail() 和 eof() 方法返回 true。
- 到达分隔字符（默认为 \n），在这种情况下它会被从输入中移除但不存储。
- 达到最大可能字符数（string::npos 和可用于分配的内存字节数中较小者），在这种情况下输入流的 failbit 被设置，意味着 fail() 方法将返回 true。

（输入流有一个记账系统来跟踪流的错误状态。在此，设置 eof 表示检测到文件结束；设置 failbit 表示检测到输入错误；设置 badbit 表示某些无法识别的故障，例如硬件故障；设置 goodbit 表示一切正常。第17章“输入、输出和文件”对此进行了讨论。）

字符串的 operator>> 函数的行为类似，只是它不是读取并丢弃分隔字符，而是读取到空白字符为止并将该字符留在输入队列中。空白字符是换行符、制表符或更一般地，任何 isspace() 返回 true 的字符。

因此，在本书中，你已经看到了几个控制台字符串输入的示例。因为输入函数使用字符串对象并且识别文件结束，所以你也可以将它们用于文件输入。清单 16.2 显示了一个简短的示例，从文件中读取字符串。它假设文件包含以冒号字符分隔的字符串，并使用指定分隔符的 getline() 方法显示这些字符串。然后将字符串显示到一个输出。

## 清单 16.2 strfile.cpp

```
// strfile.cpp -- read strings from a file
#include <iostream>
#include <fstream>
#include <string>
#include <cstdlib>
int main()
using namespace std;
ifstream fin;
fin.open("tobuy.txt");
if (fin.is_open() == false)
{
    cerr << "Can't open file. Bye.\n";
    exit(EXIT_FAILURE);
}
string item;
int count = 0;
getline(fin, item, ':');
while (fin) // while input is good
{
    ++count;
    cout << count << " :" << " " << item << endl;
    getline(fin, item, ':');
}
cout << "Done\n";
fin.close();
return 0;
```

以下是示例 tobuy.txt 文件：
sardines:chocolate ice cream corn:leeks
cottage cheese:olive oil:butter:tofu

通常，为了使程序找到文本文件，文本文件应与可执行程序位于同一目录中，有时也应与项目文件位于同一目录中。或者你可以提供完整路径名。在 Windows 系统上，请记住在 C 风格字符串中序列 \\ 表示单个反斜杠：
fin.open("C:\\CPP\\Progs\\tobuy.txt"); // file = C:\CPP\Progs\tobuy.txt

以下是清单 16.2 程序的输出：

1: sardines
2: chocolate ice cream
3: pop corn
4: leeks
5:
cottage cheese
6: olive oil
7: butter
8: tofu
9:

Done

## 使用字符串

到目前为止，你已经了解到你可以以多种方式创建字符串对象，显示字符串对象的内容，将数据读入字符串对象，向字符串对象追加，对字符串对象赋值，并连接两个字符串。还能做什么？

你可以比较字符串。所有六个关系运算符都为字符串对象重载，如果一个对象在排序序列中更早出现，则认为它小于另一个对象。如果机器排序序列是 ASCII 码，则意味着数字小于大写字符，而大写字符小于小写字符。每个关系运算符都以三种方式重载，以便你可以将字符串与另一个字符串对象比较，将字符串对象与 C 风格字符串比较，以及将 C 风格字符串与字符串对象比较：

```
string snake1("cobra")
string snake2("coral")
char snake3[20] = "anaconda";
if (snake1 < snake2) // operator<(const string &, const string &)
...
if (snake1 == snake3) // operator==(const string &, const char *)
...
if (snake3 != snake2) // operator!=(const char *, const string)
```

你可以确定字符串的大小。size() 和 length() 成员函数返回字符串中的字符数：

```
if snake1.length() == snake2.size()
cout << "Both strings have the same length.\n"
```

为什么有两个函数做同样的事情？length() 成员来自字符串类的早期版本，而 size() 是为 STL 兼容性而添加的。

你可以用多种方式在字符串中搜索子字符串或字符。表 16.2 提供了 find() 方法的四个变体的简短描述。请记住 string::npos 是字符串中最大可能的字符数，通常是最大的 int 或 unsigned long 值。

## 字符串类

| 表 16.2 重载的 find() 描述 |  |
| 方法原型 | 描述 |
| size_type find(const string & str, size_type pos = 0) const | 在调用字符串的 pos 位置开始搜索，找到子字符串 str 的第一次出现。找到时返回子字符串的第一个字符的索引，未找到时返回 string::npos |
| size_type find(const char * s, size_type pos = 0) const | 在调用字符串的 pos 位置开始搜索，找到子字符串 s 的第一次出现。找到时返回子字符串的第一个字符的索引，未找到时返回 string::npos |
| size_type find(const char * s, size_type n) | 在调用字符串的 pos 位置开始搜索，找到由 s 中的前 n 个字符组成的子字符串的第一次出现。找到时返回子字符串的第一个字符的索引，未找到时返回 string::npos |
| size_type find(char ch, size_type pos = 0) const | 在调用字符串的 pos 位置开始搜索，找到字符 ch 的第一次出现。找到时返回该字符的索引，未找到时返回 string::npos |

字符串库还提供了相关的 rfind()、find_first_of()、find_last_of()、find_first_not_of() 和 find_last_not_of() 方法，每个方法都与 find() 方法具有相同的一组重载签名。rfind() 方法找到子字符串或字符的最后一次出现。find_first_of() 方法找到调用字符串中参数中任意字符的第一次出现。例如，以下语句将返回 "cobra" 中 r 的位置（即索引 3），因为这是 "cobra" 中 "hark" 中字母的第一次出现：

```
int where = snake1.find_first_of("hark");
```

find_last_of() 方法的工作方式相同，只是它找到最后一次出现。因此，以下语句将返回 "cobra" 中 a 的位置：

```
int where = snake1.find_last_of("hark");
```

find_first_not_of() 方法找到调用字符串中第一个不是参数中字符的字符。因此，以下将返回 cobra 中 c 的位置，因为 c 在 hunk 中找不到：

```
int where = snake1.find_first_not_of("hark");
```
