# Table 6.2 The &&

| The Value of expr1 && expr2 |
| expr1 == true | expr1 == false |
| expr2 == true | false | false |

Listing 6.5 shows how to use && to cope with a common situation, terminating a while loop, for two reasons. In the listing, a while loop reads values into an array. One test (i < ArSize) terminates the loop when the array is false. The second test (temp > 0) gives the user option of quitting early by entering a negative number. The program uses two if statements, if an else statement, and for a loop, so it demonstrates several topics from this chapter and Chapter 5.

# Listing 6.5 and.cpp

```
// and.cpp -- using the logical AND operator
#include <iostream>
const int ArSize = 6;
int main() {
    using namespace std;
    float naaq[ArSize];
    cout << "Enter the NAAQs (New Age Awareness Quotients) "
    cout << "of your neighbors. Program terminates "
    cout << "when you make n\" " << ArSize << " entries "
    cout << "or enter a negative value.\nn";

    int i = 0;
    float temp;
    cout << "First value: ";
    cin >> temp;
    while (i < ArSize && temp >= 0) // 2 quitting criteria {
        naaq[i] = temp;
        ++;
        if (i < ArSize) { // room left in the array {
            cout << "Next value: ";
            cin >> temp; // so get next value
        }
    }
    if (i == 0)
        cout << "No data-bye\n";
}
```
