# STL Functions 1303

The is_partitioned() function returns true if the range is empty or if it is partitioned
by pred—that is, arranged so that all elements satisfying pred precede all those that do
not. Otherwise, the function returns false.

# partition()

```
template<class BidirectionalIterator, class Predicate>
BidirectionalIterator partition(BidirectionalIterator first,
BidirectionalIterator last,
Predicate pred);
```

The partition() places each element whose val is such that pred(val) is
true before all elements that don't meet its test. It returns an iterator to the position fol-\lowing the last position holding a value for which the predicate object was true.

# stable_partition()

```
template<class BidirectionalIterator, class Predicate>
BidirectionalIterator stable_partition(BidirectionalIterator first,
BidirectionalIterator last,
Predicate pred);
```

The stable_partition() places each element whose val is such that
pred(val) is true before all elements that don't meet its test. This function preserves the
relative ordering within each of the two groups. It returns an iterator to the position fol-\lowing the last position holding a value for which the predicate object was true.

# partition_copy() (C++11)

```
template<class InputIterator, class OutputIterator, class Predicate>
pair<OutputIterator, OutputIterator> partition_copy(
InputIterator first, InputIterator last,
OutputIterator out_true, OutputIterator out_false
Predicate pred);
```

The partition_copy() function copies each element whose val is such that
pred(val) is true to the range beginning with out_true and the remaining elements to
t range beginning with out_false. It returns a pair object containing an iterator to
t end of the range that begins with out_true and an iterator to the end of the range
 begins with out_false.
