# Features of the main ( ) Function

Stripped of the trimmings, the sample program shown in Listing 2.1 has the following fundamental structure:

```cpp

  statements
```

These lines state that there is a function called main(), and they describe how the function behaves. Together they constitute a function definition. This definition has two parts: the first line, int main(), which is called the function header, and the portion enclosed in braces { and }, which is the function body. (A quick search on the Web reveals braces go by other names, including "curly brackets," "flower brackets," "fancy braces," and "chicken lips.") However, the ISO Standard uses the term "braces." The function header is a capsule summary of the function's interface with the rest of the program, and the function body represents instructions to the computer about what the function should do. In C++ each complete instruction is called a statement. You must terminate each statement with a semicolon, so do not omit the semicolons when you type the examples.

# Statements and Semicolons

A statement represents an action to be taken. To understand your source code, a compiler needs to know when one statement ends and another begins. Some languages use a state-separator. FORTRAN, for example, use the end of the line to separate one statement from the next. Pascal uses a semicolon to separate one statement from the next. You can omit the semicolon in certain cases, such as after a statement just before an END, when you're not actually performing two statements. (Pragmatists and minimalists will agree whether can implies). But C++, uses a semicolon as a terminator rather as a separator. The difference is that a semicolon acting as a terminator of the statement rather than a marker between statements. The practical upshot is that in C++ you should never omit the semicolon.

# The Function Header as an Interface

Right now the main point is to remember that if C++ syntax requires you to begin the definition of the main() function with your header: int main(). This discusses the function header syntax in more detail, in the section "Functions," but for those who can't put their curiosity on, here's a preview.

In general, a C++ function is activated, or called, by another function, and the function header describes the interface between function and the function that calls it. The part preceding the function name is called the function return type; it describes information flow from a function back to the function that calls it. The part following the parentheses is called the argument list or parameter list; it describes information flow from the calling function to the called function. This description is a bit confusing when you apply it to main() you normally don't call main() from other parts of your program. Typically, however, main() is called by startup code that the compiler adds to your program to mediate between the program and the operating system.
