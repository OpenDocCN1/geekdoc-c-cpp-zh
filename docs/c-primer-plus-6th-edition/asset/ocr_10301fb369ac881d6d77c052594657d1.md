# The if Statement 259

```
if (ch == 'A')
    a_grade++; // alternative # 1
else
    if (ch == 'B') // alternative # 2
        b_grade++; // subalternative # 2a
    else
        SOSO++; // subalternative # 2b
```

If ch is not 'A', the program goes to the else. There, a second else subdivides that alternative into two more choices. C++'s free formatting enables you to arrange these elements into an easier-to-read format

```
if (ch == 'A')
    a_grade++; // alternative # 1
else if (ch == 'B') // alternative # 2
    b_grade++;
else
    SOSO++; // alternative # 3
```

This looks like a new structure—an else if else contained within a second. This revised format looks much cleaner, and it enables you to skip through the code to pick out the different alternatives. This entire construction still feels as one statement.
Listing 6.3 uses this preferred formatting to construct a modest quiz program.

Listing 6.3 ifelse.cpp

```
// ifelse.cpp - using if else if else
#include <iostream>
const int Fave = 27;
int main()
{
    using namespace std;
    int n;

    cout << "Enter a number in the range 1-100 to find ";
    cout << "my favorite number: ";
    do
{
        cin >> n;
        if (n < Fave)
            cout << "Too low guess again: ";
        else if (n > Fave)
            cout << "Too high guess again: ";
        else
            cout << Fave << << " is right!\n";
    } while (n != Fave);
    return 0;
}
```
