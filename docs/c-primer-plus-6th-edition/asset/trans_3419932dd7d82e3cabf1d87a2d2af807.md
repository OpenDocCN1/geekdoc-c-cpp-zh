## 程序说明

在许多上下文中，C++ 将数组的地址解释为其第一个元素的地址。因此，以下语句使 pw 成为指向类型 double 的指针，然后将 pw 初始化为 wages，即 wages 数组第一个元素的地址：

```
double *pw = wages;
```

对于 wages，就像任何数组一样，我们有以下等式：

```
wages = &wages[0] = address of first element of array
```

为了证明这不是开玩笑，程序在表达式 &stacks[0] 中显式使用了地址运算符，以将 ps 指针初始化为 stacks 数组的第一个元素。

## 指针、数组和指针算术 169

接下来，程序检查 pw 和 *pw 的值。前者是一个地址，后者是该地址处的值。因为 pw 指向第一个元素，所以 *pw 显示的值是第一个元素的值，即 10000。然后程序将 pw 加一。正如所承诺的，这将数值增加了八，因为在此系统上 double 为 8 字节。此时的 pw 等于第二个元素的地址。因此，*pw 现在是 20000，即第二个元素的值（参见图 4.10）。图中的地址已调整以匹配更宽的 [.]

```
double wages[3] = {10000.0, 20000.0, 30000.0};
short stacks[3] = {3, 2, 1};
double * pw = wages;
short * ps = &stacks[0];
```

在此之后，程序对 ps 执行类似的步骤。这次，因为 ps 指向类型 short，而 short 为 2，将指针加 1 会使其值增加 2（0x28cca + 2 = 0x28cec 十六进制）。同样，结果是使指针指向数组的下一个元素。

> 注意：对指针变量加一会使其值增加其所指向类型的字节数。

现在考虑数组表达式 stacks[1]。C++ 编译器将此表达式视为你写成 *(stacks + 1)。后者意味着计算第二个元素的地址，然后在那里查找值。结果正是 stacks[1] 的含义。（运算符优先级要求你使用括号。没有它们，就会将 *stacks 相加而不是 stacks）。
程序输出证明 *(stacks + 1) 和 stacks[1] 相同。同样，*(stacks + 2) 与 stacks[2] 相同。一般来说，无论何时使用数组记法，C++ 都会进行以下转换：
arrayname[i] 变成 *(arrayname + i)

## 第4章 复合类型

如果你使用指针而不是数组名，C++ 会进行相同的转换：pointername[i] 变成 *pointername + i

因此，在许多方面，你可以以相同的方式使用指针名和数组名。
你可以用方括号使用两者。你可以用解引用运算符 (*) 对两者进行操作。在大多数表达式中，每个表达式都代表一个地址。一个区别是你可以更改指针的值，而数组名是常量：

```
pointername = pointername + 1; // valid
arrayname = arrayname + 1; // not allowed
```

一个区别是，对数组名应用 sizeof 运算符会得到数组的大小，但对指针应用则会得到指针的大小，即使指针指向该数组。例如，在清单 4.9 中，pw 和 wages 都引用同一个数组。对它们应用 sizeof 运算符会产生以下结果：

```
24 = size of wages array << displaying wages
4 = size of pw pointer << displaying pw
```

这是一个 C++ 不将数组名解释为地址的情况。

## 数组的地址

取数组的地址是数组名不被解释为其地址的另一个情况。但等等，数组名不是被解释为数组的地址吗？不完全是——数组名被解释为数组第一个元素的地址，而应用地址运算符会得到整个数组的地址

```
short tell[10]; // tell an array of 20 bytes
cout << &tell << endl; // displays &tell[0]
cout << &tell << endl; // displays address of whole array
```

在数值上，这两个地址相同，但在概念上 &tell，以及 tell，是 2 字节内存块的地址。表达式 +1 将地址值增加 2，而 &tell + 1 将地址值增加 20。另一种解释是说 tell 是类型为指向 short 的，或 short *，而 &tell 是类型为指向 20 个 shorts 的数组，或 short (*) [20]。

现在你可能想知道这种类型描述的来源。首先，这里是你如何声明和初始化该类型的指针：

```
short (*pas) = &tell; // pas points to array of 20 shorts
```

如果你省略括号，优先级规则会将 [20] 与 pas 关联起来，使其成为 20 个指向 short 的指针数组，因此括号是必要的。接下来，如果你想描述一个变量的类型，你可以使用该变量的声明作为指南并删除变量名。因此，pas 的类型是 short (*) [20]。另请注意，因为 pas 被设置为 &tell，所以 *pas 等同于 tell，因此 (*pas) [20] 将是 tell 数组的第一个元素。

简而言之，使用 new 创建数组并使用指针访问不同元素是一件简单的事情。你只需将指针视为数组名。理解为什么这样工作是一个有趣的挑战。如果你真的想理解数组和指针，你应该仔细回顾它们之间的相互关系。

## 总结指针要点

你最近接触了大量指针知识，所以让我们总结到目前为止关于指针和数组所揭示的内容。

### 声明指针

要声明指向特定类型的指针，使用以下形式：

```
typeName * pointerName;
```

以下是一些示例：

```
double * pn;              // pn can point to a double value
char * pc;               // pc can point to a char value
```

这里 pn 和 pc 是指针，double * 和 char * 是 C++ 中指向 double 和指向 char 的类型的记法。

### 为指针赋值

你应该将内存地址赋给指针。你可以对变量应用 & 运算符以获取命名内存的地址，而 new 运算符返回未命名内存的地址。

以下是一些示例：

```
double * pn;              // pn can point to a double value
double * pa;              // so can pa
char * pc;               // pc can point to a char value
double bubble = 3.2;      // assign address of bubble to pn
pn = &bubble;             // assign address of newly allocated char memory to pc
c = new char;
pa = new double[30];    // assign address of 1st element of array of 30 to pa
```

### 解引用指针

解引用指针意味着引用指向的值。你对指针应用解引用或间接值运算符 (*) 来解引用它。因此，如果 pn 是指向 bubble 的指针，如前例中所示，那么 *pn 就是指向的值，在本例中为 3.2。

以下是一些示例：

```
cout << *pn;      // print the value of bubble
*pc = 'S';               // place 'S' into the memory location whose address is pc
```
