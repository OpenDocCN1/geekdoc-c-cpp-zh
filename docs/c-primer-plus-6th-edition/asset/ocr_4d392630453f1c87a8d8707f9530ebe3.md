# I/O and Exceptions

Suppose that an input function eofbit Does this cause an exception to be thrown? By default, the answer is no. However, you can use the exceptions() method to control how exceptions are handled.

First, here's some background. The exceptions() method returns a bitfield with three bits corresponding to eofbit, failbit, and badbit. Changing the stream state involves clear() or setState(), which uses clear(). After changing the stream state, the clear() method compares the current stream state to the value returned by exceptions(). If a bit is set in the value and the corresponding bit is set in the current state, clear() throws an ios_base::failure exception. This would happen, for example, if both had badbit. If it follows that exceptions() returns goodbit, no exceptions are thrown. The ios_base::failure exception class derives the std::exception class and has a what() method.

The default setting for exceptions() is goodbit—that is, no exceptions thrown. However, the overloaded exceptions(istate) function gives you control over the behavior:

```
cin.exceptions(badbit); // setting badbit causes exception to be thrown
```

The bitwise OR operator(), as discussed in Appendix E, allows you to specify more than one. For example, the following statement results in an exception being thrown if either badbit or eofbit is subsequently set:

```
cin.exceptions(badbit | eofbit);
```
