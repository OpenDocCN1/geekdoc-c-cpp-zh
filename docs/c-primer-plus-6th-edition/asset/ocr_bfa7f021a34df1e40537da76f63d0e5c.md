# Chapter 17 Input, Output, and Files

Suppose facts is a string object. To create an stringstream object associated with this string, you can use the following:

```
istream instr(facts); // use facts to initialize stream
```

Then you use istream methods to read data from instr. For example, if instr contained a bunch of integers in character format, you could read them as follows:

```
int n;
int sum = 0;
while (instr >> n)
sum += n;
```

Listing 17.22 uses the overloaded >> operator to read the contents of a string one at a time.

# Listing 17.22 strcin.cpp

```
// strcin.cpp -- formatted reading from a char array
#include <iostream>
#include <sstream>
#include <string>
int main()
{
    using namespace std;
    string lit = "It was a dark and stormy day, and " the full moon glowed brilliantly";
    istringstream instr(lit); // use buf for input
    string word;
    while (instr >> word) // read a word a time
        cout << word << endl;
    return 0;
}
```
