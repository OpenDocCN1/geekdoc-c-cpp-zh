结构体还能做另一件事，即创建一个没有类型名的结构体。你通过在同时定义结构体形式和变量时省略标签名来实现：

```cpp
struct
{
    // no tag
    int x; // 2 members
    int y;
} position; // a structure variable
```

这会创建一个名为 position 的变量。你可以用成员运算符访问其成员，如 position.x，但该类型没有通用名称。你不能随后创建其他相同类型的变量。本书不使用这种受限的结构体形式。

# 结构体数组

inflatable 结构体包含一个数组（name 数组）。也可以创建元素为结构体的数组。技术与创建基本类型数组完全相同。例如，要创建包含 100 个 inflatable 结构体的数组，可以这样做：

```cpp
inflatable gifts[100]; // array of 100 inflatable structures
```

这使得 gifts 成为 inflatable 的数组。因此数组的每个元素，如 gifts[0] 或 gifts[99]，都是一个 inflatable 对象，可以使用成员运算符：

```cpp
cin >> gifts[0].volume; // use volume of first struct
cout << gifts[99].price << endl; // display price of last struct
```

请记住，如果 gifts 本身是数组而不是结构体，那么 gifts.price 之类的构造是无效的。

要初始化结构体数组，你将初始化数组的规则（每个元素的用大括号括起来的、逗号分隔的值列表）与初始化结构体的规则（每个成员的用大括号括起来的、逗号分隔的值列表）结合起来。因为数组的每个元素都是一个结构体，所以值由结构体初始化表示。因此，你最终得到的是一个用大括号括起来的、逗号分隔的值列表，其中每个值本身就是一个

```cpp
inflatable guests[2] = // initializing an array of structs
{
    {"Bambi", 0, 21.99}, // first structure in array
    {"Godzilla", 2000, 565.99} // next structure in array
};
```

像往常一样，你可以按任意方式格式化。例如，两个初始化都可以放在同一行，或者每个单独的结构体成员初始化都可以单独占一行。

# 结构体中的位域

C++ 如同 C 一样，允许你指定占用特定位数数的结构体成员。这对于创建与硬件设备上的寄存器等相对应的数据结构非常方便。字段类型应为整型或枚举（枚举将在本章后面讨论），冒号后跟一个数字表示实际使用的位数。你可以使用未命名字段提供间隔。每个成员称为 *位域*。这里有一个例子：

```cpp
struct torge_register
{
    unsigned int SN : 4; // 4 bits for SN value
    unsigned int : 4; // 4 bits unused
    bool goodIn : 1; // valid input (1 bit)
    bool goodToggle : 1; // successful toggling
};
```

你可以以通常的方式初始化字段，并使用标准结构体表示法访问位域：

```cpp
torge_register tr = { 14, true, false };
```

```cpp
if (tr.goodIn) // if statement covered in Chapter 6
```

位域通常用于低级编程。通常，使用整型和附录 E“其他运算符”中使用的按位运算符提供了一种替代方法。

# 联合体

联合体是一种可以保存不同数据类型但一次只能保存一种类型的数据格式。也就是说，虽然结构体可以保存 int 和 long 和 double，联合体可以保存 int、long 或 double。联合体的大小是其最大成员的大小。例如，考虑以下内容：

```cpp
union oneall
{
    int int_val;
    long long_val;
    double double_val;
};
```

你可以在不同时间使用 oneall 保存不同的值：

```cpp
oneall pail;
pail.int_val = 15; // store an int
cout << pail.int_val;

pail.double_val = 1.38; // store a double
cout << pail.double_val;
```

联合体的一种用途是在项目可以使用不同格式时节省空间。例如，假设你管理一批小部件的库存，其中一些具有整数 ID，一些具有字符串 ID。在这种情况下，你可以使用以下内容：

```cpp
struct widget {
    char brand[20];
    int type;
    union {
        long id_num; // type 1
        char id_char[20]; // other widgets
    };
};
widget prize;
```

```cpp
if (prize.type == 1) // if-else statement
    cin >> prize.id_num;
else
    cin >> prize.id_char;
```

# 枚举

C++ 的 enum 设施提供了一种替代 const 创建符号常量的方式。它还让你以相当受限的方式定义新类型。enum 的语法类似于结构体。例如，考虑以下语句：

```cpp
enum spectrum {red, orange, green, blue, violet, indigo, ultraviolet};
```

此语句做了两件事：

-   它使 spectrum 成为一种新类型的名称；spectrum 被称为枚举，就像 struct 变量被称为结构体一样。
-   它将 red、orange、yellow 等建立为整数值 0–7 的符号常量。这些常量称为枚举数。
