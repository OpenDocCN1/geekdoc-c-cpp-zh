# An Implementation Comment

The implementation described in the preceding sections stores both rectangular and polar coordinates for a vector in the Vector object. However, the public interface doesn't depend on this fact. All the interface calls is for that both representations can be displayed and that individual values be returned. The internal implementation could be quite different. As mentioned earlier, the code could store just the x and y components. Then, the magval() method, which returns the value of magnitude of the vector, could calculate the magnitude from the x and y values instead of looking up the value as stored in the object. Such an approach changes the implementation but leaves the user interface unchanged. This separation of interface from implementation is the goals of OOP. It lets you fine-tune an implementation without changing the code in programs that use the class.

Both of these implementations have advantages and disadvantages. Storing the data means that the object occupies more memory and that code has to be careful to update both rectangular and polar representations each time a Vector object is changed. But data look-up is faster. If an application often needs to access both representations would be preferable; if polar data were needed only infrequently, the other implementation would be better.You could choose to use one implementation in one program and the second implementation in another, yet retain the same user interface for.

# Taking the Vector Class on a Random Walk

Listing 11.5 provides a short program that uses the revised Vector class. It simulates the famous Drunkard's Walk problem. Actually, now that drinks are recognized as a serious health problem rather than as source of amusement, its usually called the Random Walk problem. The idea is to place someone at a lamppost. The person begins walking, but the direction of each step varies randomly from the direction of the preceding step. One way of phrasing the problem is: How many steps does it take the walker to travel, say 50 feet away from the post? In terms of vectors, this amounts to adding a bunch of randomly oriented vectors until sum exceeds 50.
