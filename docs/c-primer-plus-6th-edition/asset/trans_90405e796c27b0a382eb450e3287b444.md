你可能想知道 unique_ptr 与 auto_ptr 不同之处在于它如何区分安全和可能不安全。答案是它使用了 C++11 新增的移动构造函数和右值引用，如第 18 章所述。
此外，unique_ptr 相对于 auto_ptr 还有另一个优势。它具有可用于数组的变体。记住，你必须将 delete 与 new 配对，将 delete [] 与 new [] 配对。auto_ptr 模板使用 delete，而不是 delete []，因此它只能与 new 一起使用，不能与 new [] 一起使用。但 unique_ptr 具有 new[]、delete [] 版本：

```
std::unique_ptr<double> _pda(new double(5)); // will use delete
```

## 警告

你应该仅对由 new 分配的内存使用 auto_ptr 或 shared_ptr 对象，而不是对由 new [] 分配的内存使用。你不应该对未通过 new [] 分配的内存使用 auto_ptr、shared_ptr 或 unique_ptr，或在 unique_ptr 的情况下，未通过 new 或 new [] 分配的内存使用。

## 选择智能指针

应该使用哪种指针类型？程序使用多个指向同一对象的指针，shared_ptr 是你的选择。例如，你可能有一个指针数组和一些辅助指针来标识特定元素，例如最大和最小。或者你可能有两种类型的对象，它们包含指向同一对象的指针。或者你可能有一个指向指针的 STL。许多 STL 算法包括复制或赋值操作，这些操作可与 shared_ptr 一起工作，但不能与 unique_ptr 一起使用（你会收到编译器警告）或 auto_ptr（你会得到未定义行为）。如果你的编译器不提供 shared_ptr，你可以从 Boost 库中获取一个版本。
如果程序不需要指向同一对象的多个指针，unique_ptr 就能胜任。它是返回由 new 分配的内存指针的函数的返回类型的良好选择。这样，拥有权就会转移给被赋予返回值的 unique_ptr，并且智能指针承担调用 delete 的责任。你可以将 unique_ptr 对象存储在 STL 容器中，只要你不调用复制或将 unique_ptr 赋给另一个 unique_ptr 的方法或算法，例如 sort ()。例如，假设进行了适当的包含和 using 语句，以下代码片段可以在程序中使用：

```
}

{
    cout << *pi << ' ';
```

对 push_back() 的调用之所以有效，是因为它传递了一个临时的 unique_ptr 以赋给一个 unique_ptr。还要注意，如果 show 按值而不是按引用传递对象，则 for_each() 语句将失败，那么将需要将 pi 初始化为来自 vp 的非临时 unique_ptr，而这是不允许的。如前所述，编译器会捕获对 unique_ptr 的不当使用。

在与可以将一个 shared_ptr 赋给另一个 shared_ptr 相同的条件下，你可以将 unique_ptr 赋给 shared_ptr——源必须是右值。如前所述，在以下代码中 make_int() 是一个返回类型为 unique_ptr<int> 的函数：

```

shared_ptr<int> spp(pup); // not allowed, pup an lvalue
shared_ptr<int> spr(make_int(rand() % 1000)); // ok
```

# 标准模板库

STL 提供了一组表示容器、迭代器、函数对象和算法的模板。容器是一个单元，如数组，可以容纳多个值。STL 容器是同质的；也就是说，它们保存相同类型的值。算法是完成特定任务的配方，例如对数组进行排序或在列表中查找值。迭代器是你可以像指针让你在数组中移动一样在容器中移动的对象；它们是指针的泛化。函数对象是可以像函数一样工作的对象；它们可以是类或函数指针（包括函数名，因为函数名充当指针）。STL 让你构建各种容器，包括数组、队列和列表，这让你执行各种操作，包括搜索、排序和匹配。

Alex Stepan 和 Meng Lee 在惠普开发了 STL，并于 1994 年发布了实现。ISO/ANSI C++ 委员会投票将其作为 C++ 标准的一部分纳入。STL 并不是面向对象编程的例子。相反，它代表了一种不同的编程范式，称为泛型编程。这使得 STL 在它所做的事情以及其方法方面都很有趣。

# vector 模板类

第 4 章简要介绍了 vector 类。我们现在将更仔细地研究它。在计算中，术语 vector 对应于数组，而不是第 11 章“使用类”中讨论的数学向量。（在数学上，N 维数学向量可以用一组 N 个分量表示，在这方面，数学向量具有内积和外积等附加属性，而计算机向量不一定具有这些属性。）计算风格的向量保存一组可以随机访问的值。也就是说，你可以使用索引访问向量的第 10 个元素，而无需访问前 9 个元素，以及第 14 章中介绍的 varlay 和 ArrayFP 类，以及第 4 章中介绍的 array 类。也就是说，你可以创建一个 vector 对象，使用一个 vector 到另一个 vector，并使用 [] 运算符访问 vector 元素。为了使类通用，你使其成为模板。这就是 STL 所做的，在 vector（以前是 vector.h）头文件中定义一个模板。

要创建 vector 模板对象，你使用通常的 <type> 记法来指示要使用的类型。此外，vector 模板使用动态内存分配，你可以使用初始化参数来指示你想要多少个 vector 元素：

```
#include vector
using namespace std;
vector<int> ratings(5); // a vector of 5 ints
int n;
cin >> n;
vector<double> scores(n); // a vector of n doubles
```

创建 vector 对象后，[] 的运算符重载使得可以使用通常的数组记法来表示单个元素：ratings[0] = 9; for (int i = 0; i < n; i++) cout << scores[i] << endl;

```
// vect1.cpp -- introducing the vector template
#include <iostream>
#include <string>
#include <vector>

const int NUM = 5;
int main()
{
  using std::vector;
  using std::string;
  using std::cin;
  using std::cout;
  using std::endl;

  vector<int> ratings(NUM);
  vector<string> titles(NUM);
  cout << "You will do exactly as told. You will enter\n"
    << NUM << " book titles and your ratings (0-10).\n";
  int i;
  for (i = 0; i < NUM; i++)
  {
    cout << "Enter title #" << i + 1 << ": ";
    getline(cin,titles[i]);
    cout << "Enter your rating (0-10): ";
    cin >> ratings[i];
    cin.get();
  }
  cout << "Thank you. You entered the following:\n"
    << "Rating\tBook\n";
  for (i = 0; i < NUM; i++)
  {
    cout << ratings[i] << "\t" << titles[i] << endl;
  }

  return 0;
}
```
