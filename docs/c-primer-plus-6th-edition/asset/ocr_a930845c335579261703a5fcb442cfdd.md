# Chapter 7 Functions: C++'s Programming Modules

Listing 7.5 makes the following function call:

```
int sum = sum_arr(cookies, ArSize);
```

Here cookies is the name of an array, by C++ rules cookies is the address of the array's first element. The function passes an address. Because the array has int elements, cookies must be pointer-to-int, or int *.This suggests that the correct function header should be:

```
int sum_arr(int *arr, int n) // arr = array name, n = size
```

Here *arr has replaced arr[]. It turns out that both headers are correct in C++ the notations * and arr[] have the identical meaning (and only when) in a function header or function prototype. Both mean arr is a pointer-to-int. However, the array notation (int arr[]) symbolically reminds you that arr not only points to an int, but to the first element of an array of ints. This book uses the array notation when the pointer is the first element of an array. Remember that the notations *arr and arr[] are not synonymous in any other context. For example, you can use the notation tip (int pointer) to declare a pointer in the body of a function.

Given that the variable arr is actually a pointer, the rest of the function makes sense. As you might recall from the discussion of dynamic arrays in Chapter 4, you can use the bracket notation well with array name or pointers to access elements of an array.Whether arr is a pointer or an array name, the expression arr[3] means the fourth element of the array.And it probably will not do harm at this point to remind you of the two identities:

```
arr[i] = *(arr + i) // values in two notations
&arr[i] = arr + i // addresses in two notations
```

Remember that adding one to a pointer, including an array name, actually adds a value equal to the size, in bytes, of the type to which the pointer points. Pointer addition and array subscription are equivalent ways of counting elements from the beginning of an array.

# The Implications of Using Arrays as Arguments

Let's look at the implications of Listing 7.5.The function call sum_arr(cookies, ArSize) passes the address of the first element of the cookies array and the number of elements of the array to the sum_arr() function.The function initializes the cookies to the pointer variable arr and initializes ArSize to the int variable n. This means Listing 7.5 doesn't really pass the array to the function. Instead, it tells the function where the array is (address), what kind of elements it has (the type), and how many elements it has (the n variable). (See Figure 7.4.)Armed with information, the function uses the original array. If you pass an ordinary variable, the function works with a copy.
