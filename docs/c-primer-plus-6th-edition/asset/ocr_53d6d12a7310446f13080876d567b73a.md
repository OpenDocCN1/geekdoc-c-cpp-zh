Note

Each function, including constructors and destructors, has this pointer. The property of this pointer points to the invoking object. If a method needs to refer to the invoking object as a whole, you can use the expression *this. Using the const qualifier qualifies this as being a pointer to const; in that case, you cannot use this to change the object's value.

What you want to return, however, is not this is the address of the object. You want to return the object itself, that is symbolized by *this. (Recall that applying the dereferencing operator * to a pointer yields the value to which the pointer points.) You can now complete the method definition by using *this as an alias for the invoking object:

```
const Stock & Stock::topval(const Stock & s) const
{
    if (s.total_val > total_val)
        return s; // argument object
    else
        return *this; // invoking object
```
