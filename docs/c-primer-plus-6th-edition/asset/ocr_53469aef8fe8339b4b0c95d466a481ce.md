# C++ Inline Functions

Inline functions are a C++ enhancement designed to speed up programs. The primary distinction between normal functions and inline functions is not in how you code them but in how the C++ compiler incorporates them into a program. To understand the difference between inline functions and normal functions, you need to peer more deeply into the programmer's innards we have so far. Let's do that now.
