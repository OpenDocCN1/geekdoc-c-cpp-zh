in the range [first2,first2 + (last - first1)). That is, it calculates a value from the first elements of each sequence, from the second elements of each sequence, and so on, it reaches the end of the sequence. (Hence the second sequence should be at least long as the first.) The function then returns the returning value of acc.

# partial_sum()

```
template <class InputIterator, class OutputIterator>
OutputIterator partial_sum(InputIterator first, InputIterator last,
OutputIterator result);
```

```
template <class InputIterator, class OutputIterator, class BinaryOperation>
OutputIterator partial_sum(InputIterator first, InputIterator last,
OutputIterator result,
BinaryOperation binary_op);
```

The partial_sum() function assigns *first toresult or *first * *(first + 1) to
*(result + 1) (first version) or assigns binary_op(*first, *(first + 1)) to
*(result + 1) (second version), and so on. The nth element of the sequence beginning contains the sum (or binary equivalent) of the first n elements of the sequence beginning at first. The function returns the past-end iterator for the result. The algorithm allows result to be first—that is, it allows the result to be copied over the original sequence, if desired.

# adjacent_difference()

```
template <class InputIterator, class OutputIterator>
OutputIterator adjacent_difference(InputIterator first, InputIterator last,
OutputIterator result);
```

```
template <class InputIterator, class OutputIterator, class BinaryOperation>
OutputIterator adjacent_difference(InputIterator first, InputIterator last,
OutputIterator result,
BinaryOperation binary_op);
```

The adjacent_difference() function assigns *first to the location result (*result
= *first). Subsequent locations in the target range are assigned the differences (or
binary_op equivalent) of adjacent locations in the source range. That is, the next location
in the target range (result + 1) is assigned *(first + 1) - *first (first version) or
binary_op*(first + 1), *first (second version), and so on. The function returns
the past-end iterator for the result. The algorithm allows result to be first—that is,
it it allows the result to be copied over the original sequence, if desired.
