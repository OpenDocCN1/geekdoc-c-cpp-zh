# The bool Type

The ANSI/ISO C++ has added a new type (new to C++, that is), called bool.
Named in honor of the English mathematician George Boole, who developed a mathe-
ical representation of the laws of logic. In computing, a Boolean variable is one whose
value can be either true or false. In the C++, like C, has not had a Boolean type.
Instead, as you'll see greater detail in Chapters 5 and 6, C++ interprets nonzero
as true and zero false as values. Now, you can use the bool type to represent true
and false, and the predefined true and false represent those values. That is, you
make statements like the following:

```
bool is_ready = true;
```

The literals true and false can be converted to int by promotion, which true
converting to 1 and false to 0:

```
int ans = true;      // ans assigned 1
int promise = false;   // promise assigned 0
```

Any numeric or pointer value can be converted implicitly (that is, without an
explicit type cast). Any nonzero value converts to true, whereas a zero
value converts to false:

```
bool start = -100;   // start assigned true
bool stop = 0;          // stop assigned false
```

After the book introduces statements (in Chapter 6, "Branching Statements and
Logical Operators"), the bool type will become a common feature in the examples.
