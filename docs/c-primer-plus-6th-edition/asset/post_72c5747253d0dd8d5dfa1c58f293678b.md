Table 5.3 cin.get (ch) Versus cin.get ()

| Property | cin.get (ch) | ch=cin.get () |
|---|---|--|
| Method for conveying input character | Assign to argument ch | Use function value to assign to ch |
| Function value for character input | A class istream object (true after bool conversion) | Code for character as type int value |
| Return value at EOF | A class istream object (false after bool conversion) | EOF |

So which would use, `cin.get ()` or `cin.get (char)`? The form with the character argument is integrated fully into the object approach because its return value is an istream object. This means, for example, that you can use chains. For example, the following code reads the next character into ch1 and the following input character into ch2:

```cpp
cin.get(ch1); cin.get(ch2);
```

This works because the function call `cin.get (ch1)` returns the object, which then acts as the object to which `get (ch2)` is attached.

Prob the main use for the `get ()` form is to make quick-and-dirty conversions from the `getchar()` and `putchar()` functions of stdio.h to `cin.get()` and `cout.put()` methods of istream. Just replace one header file with the other and globally replace `getchar()` and `putchar()` with their alike-like method equivalents. If the old code uses a type int variable for input, you have to make adjustments if your implementation has multiple prototypes for `get ()`.

## Nested Loops and Two-Dimensional Arrays

Earlier in this chapter you saw that `for` loop is a natural tool for processing arrays. Now let's go a step further and look at how `for` loop within a loop (nested loops) serves to handle two-dimensional arrays.

First let us examine a two-dimensional array. Arrays used so far in this chapter are termed one-dimensional arrays because you can visualize each as a single row of data. You can visualize a two-dimensional array as more like a table, having both rows and columns of data. You can use a two-dimensional array, for example, to represent quarterly sales for six districts, with one row for each district. Or you can use a two-dimensional array to represent the position on a computerized board.

C++ does not provide a two-dimensional array type. You can create an array for which each element is itself an array. For example, suppose you want to store maximum data for five cities over a 4-year period. In that case, you can declare an array as follows:

```cpp
int watertemps[4][5];
```

This declaration means that `watertemps` is an array with four elements. Each of these elements is an array of five integers (see Figure 5.5). You can think of the `watertemps` array as representing four rows of five temperature each.

Figure 5.5 An array of arrays. `watertemps[0]` is the first element of the `watertemps` array; hence `watertemps[0]` is itself an array of five ints. The first element of the `watertemps[0]` array is `watertemps[0][0]`, and this element is a single int. Thus, you need to use two subscripts to access the elements. You can think of the first subscript as representing the row and the second subscript as representing the column (see Figure 5.6). The `watertemps` array viewed as a table:

| | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| watertemps[0] | watertemps[0][0] | watertemps[0][1] | watertemps[0][2] | watertemps[0][3] | watertemps[0][4] |
| watertemps[1] | watertemps[1][0] | watertemps[1][1] | watertemps[1][2] | watertemps[1][3] | watertemps[1][4] |
| watertemps[2] | watertemps[2][0] | watertemps[2][1] | watertemps[2][2] | watertemps[2][3] | watertemps[2][4] |
| watertemps[3] | watertemps[3][0] | watertemps[3][1] | watertemps[3][2] | watertemps[3][3] | watertemps[3][4] |

Figure 5.6 Accessing array elements with subscripts.

Suppose you want to print all the array contents. In that case, you can use one `for` loop to change rows and a nested `for` loop to change columns:

```cpp
for (int row = 0; row < 4; row++)
    for (int col = 0; col < 5; ++col)
        cout << watertemps[row][col] << "\t";
    cout << endl;
```

For each value of row, the inner loop cycles through all the col values. This example prints tab character (\t in C++ escape character) after each value and a newline character after each complete row.

## Initializing a Two-Dimensional Array

When you create a two-dimensional array, you have the option of initializing each element. The technique is based on that for initializing a one-dimensional array. Remember that you do this by providing a comma-separated list of values enclosed in braces:

```cpp
// initializing a one-dimensional array
int btus[5] = { 23, 26, 24, 31, 28 };
```

For a two-dimensional array, each element is itself an array, so you can initialize each element using a form like that in the previous code example. Thus, the initialization is a comma-separated series of one-dimensional initializations, all enclosed in the set of braces:

```cpp
int watertemps[4][5] = // 2-D array
{
    {96, 100, 87, 101, 105}, // values for watertemps[0]
    {96, 98, 101, 107, 104}, // values for watertemps[1]
    {97, 101, 93, 108, 107}, // values for watertemps[2]
    {98, 103, 95, 109, 108} // values for watertemps[3]
};
```

You can visualize `watertemps` as four rows of five numbers each. The term {94, 98, 87, 103, 101} initializes the first row, represented by `watertemps[0]`. As a matter of style, placing each row of data on its own line, if possible, makes the data easier to read.

C++ does not provide a two-dimensional array type. You can create an array for which each element is itself an array. For example, suppose you want to store maximum data for five cities over a 4-year period. In that case, you can declare an array as follows:

```cpp
// nested.cpp
#include <iostream>
int main()
{
    using namespace std;
    const int Cities = 5;
    const int Years = 4;
    const int* cities[Cities] = // nested loops - 2-D array
    {
        "Gribble City",
        "Gribbletown",
        "New Gribble",
        "San Gribble",
        "Gribble Vista"
    };

    int watertemps[Years][Cities] = // 2-D array
    {
        {96, 100, 87, 101, 105}, // values for watertemps[0]
        {96, 98, 101, 107, 104}, // values for watertemps[1]
        {97, 101, 93, 108, 107}, // values for watertemps[2]
        {98, 103, 95, 109, 108} // values for watertemps[3]
    };

    cout << "Maximum temperatures for 2008 - 2011\n\n";
    for (int city = 0; city < Cities; ++city)
    {
        cout << cities[city] << ":\t";
        for (int year = 0; year < Years; ++year)
        {
            cout << watertemps[year][city] << "\t";
        }
        cout << endl;
    }

    cin.get();
    return 0;
}
```
