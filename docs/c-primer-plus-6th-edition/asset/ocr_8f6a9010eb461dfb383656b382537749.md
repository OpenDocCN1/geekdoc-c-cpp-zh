The only way sum_arr() knows the number of elements in the array is through what you tell it with the second argument, you can lie to the function. For example, the second program uses the function, it makes this calls:

```
sum = sum_arr(cookies, 3);
```

By telling the function that cookies has just three elements, you get the function to calculate the sum of the first three.
Why stop there?You can also lie about where the array starts:

```
sum = sum_arr(cookies + 4, 4);
```

Because cookies acts as the address of the first element, cookies + 4 acts as the address of the fifth element. This statement says the fifth, seventh, and eighth elements of the array. Note in the output how the call to the function assigns a different address to add than the first two calls did. And, you can use &cookies[4] instead of cookies + 4 as the argument; they both mean the same thing.

# Note

To indicate the kind of array and the number of elements to an array-processing function, you pass the information as two separate arguments:

```
void fillArray(int arr[], int size);      // prototype
Don't pass the array size using brackets: the future.
void fillArray(int arr[size]);              // NO -- bad prototype
```
