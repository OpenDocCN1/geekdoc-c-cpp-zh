Because C++ handles C-style strings as addresses, you get little satisfaction if you try to use the relational operators to compare strings. Instead, you can go to the C-style string library and use strcmp() to compare strings. This function takes two addresses as arguments.That means the arguments are pointers, string constants, or character array names. If the first strings are identical, strcmp() returns the value 0, and if the first string follows the second alphabetically, strcmp() returns a negative value. Actually, in the system calling “sequence” is more accurate than “alphabetically.” This means that characters are compared according to the system for characters. For example, in ASCII code, uppercase letters have smaller values than lowercase letters, so uppercase precedes lowercase in the collating sequence. Therefore, the string “zoo” precedes the string “aviary”. The fact that comparisons are based on code values means that uppercase and lowercase letters differ, the string “roo” is different from the string “foo”.

In some languages, like BASIC and Pascal, strings stored in differently sized arrays are not equal to each other. But C strings are defined by the terminating null character, not by the size of the containing array. This means that two strings can be identical even if they are contained in differently sized arrays:

```
char big[80] = "Daffy"; // 5 letters plus \0
char little[6] = "Daffy"; // 5 letters plus \0
```

By the way, although you can't use relational operators to compare strings, you can use them to compare characters because characters are actually integer types. Therefore, the following is valid code, at least for the ASCII and Unicode character sets, for displaying the characters of the alphabet:

```
for (ch = 'a'; ch <= 'z'; ch++)
cout << ch;
```
