# Program Notes

To create a string of n visible characters, you need to store for n + 1 characters in order to have space for the null character. So the function in Listing 7.10 asks for n + 1 bytes to hold the string. Next, it sets the byte to the null character. Then it fills in the rest of the array back to front. In Listing 7.10, the following loop cycles n times as n decreases to 0, filling n elements:

```cpp
while (n-- > 0)
pstr[n] = c;
```

At the start of the final cycle, n has the value 1. Because n-- means the value and then decrement it, the while loop test condition compares 1 to 0, finds the test to be true, and continues. But after making the test, the function decrements n to 0, so pstr[0]

# Functions and Structures

Let's move from arrays to structures. It's easier to write functions for structures than arrays. Although structure resemble arrays in both can hold several data items, structure behave like basic, single-valued variables when it to functions. That is, unlike an array, a structure ties its data to a single entity, or data object, that will be treated as a unit. Recall that you can assign one structure to another. Similarly, you can pass structures by value, just as you would do with ordinary variables. In that case, the function works with a copy of the original structure. Also a function can return a structure. There is no funny business like the name of an array being the address of its first element. The name of a structure is simply the name of the structure, and if you want its address, you have to use the & operator. (C++ and C both use the & symbol to identify reference variables, to be discussed in Chapter 8.)

The most direct way to program using structures is to treat them as you would treat basic types—that is, pass them as arguments and use them, if necessary, as return values. However there is one disadvantage passing structures by value. If the structure is large, the space and effort involved in making a copy of structure can increase memory requirements and slow down the system. For those reasons (and because, at first, C didn't allow the passing of structures by value), many C programmers prefer passing the address of a structure and then using a pointer to access the structure contents. C++ provides a third alternative, called passing by reference, that is discussed in Chapter 8. Let's examine the other two choices now, beginning with passing and returning entire structures.

# Passing and Returning Structures

Passing structures by value makes the most sense when the structure is relatively compact, so let's look at a couple examples along those lines. The first example deals with travel time (not to be confused with travel time). Some maps will tell you that it is 3 hours, 50 minutes, from Thunder Falls to Bingo City and 1 hour, 25 minutes, from Bingo City to Grotesque. You can use a structure to represent such times, using one integer for the hour value and a second member for the minute value. Adding two times is a little tricky because you might have to transfer some of the minutes to the hours part. For example, the two preceding times sum to 4 hours, 75 minutes, which should be converted to 5 hours, 15 minutes.

#include <iostream>

struct travel_time
{
    int hours;
    int mins;
};

const int Minsperhr = 60;

travel_time sum(travel_time t1, travel_time t2)
{
    travel_time total;
    total.hours = t1.hours + t2.hours + (t1.mins + t2.mins) / Minsperhr;
    total.mins = (t1.mins + t2.mins) % Minsperhr;
    return total;
}

int main()
{
    using namespace std;
    travel_time day1 = {5, 45};
    travel_time day2 = {4, 55};
    travel_time day3 = sum(day1, day2);
    cout << "Two-day total: " << day3.hours << " hours, " << day3.mins << " minutes\n";

    travel_time day4 = {10, 32};
    travel_time day5 = sum(day3, day4);
    cout << "Three-day total: " << day5.hours << " hours, " << day5.mins << " minutes\n";

    return 0;
}
