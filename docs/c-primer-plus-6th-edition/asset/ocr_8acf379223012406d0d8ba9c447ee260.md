# The break and continue Statements 281

```
char line[ArSize];
int spaces = 0;

cout << "Enter a line of text:\n";
cin.get(line, ArSize);
cout << "Complete line:\n" << line << endl;
cout << "Line through first period:\n";
for (int i = 0; line[i] != '\0'; i++) {
    cout << line[i]; // display character
    if (line[i] == '.') // quit if it's a period
        break;
    if (line[i] != ' ') // skip rest of line
        continue;
    spaces++;
}
cout << "\n" << spaces << " spaces spaces\n";
cout << "Done.\n";
return 0;
```
