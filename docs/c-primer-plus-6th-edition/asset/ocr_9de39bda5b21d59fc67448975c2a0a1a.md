# Integer Types

Integers are numbers with no fractional part, such as 2, 98,-5286, and 0. There are of
tegers, assuming that you consider an infinite number to be a limit, so no finite amount of
computer memory can represent all possible integers. Thus, a language can represent only
a subset of integers. Some languages offer one integer type (one type fits all),
C++ provides several choices. This gives you the option of choosing the integer type that
bets a program's particular requirements. This concern with matching type to data
presages the design data types of OOP.

The various C++ integer types differ in the amount of memory they use to hold an
larger block of memory can represent a larger range in integer values. Also
some types (signed types) can represent positive and negative values, whereas others
(unsigned) can't represent negative values. The usual term for describing the amount
of memory used for an integer is width. C++'s basic integer types, in order of increasing width, are char, short, int, long, and,
with C++11, long. Each comes in signed and unsigned versions. This gives
a choice of ten different integer types! Let's look at these integer types in more detail.
Because the char has some special properties (it's most used to represent char-
acters instead of numbers), this chapter covers the other types.

# The short, int, long, and long Integer Types

Computer memory consists of called bits. (See the "Bits and Bytes" later in
this chapter.) By using different numbers of bits to store values, the C++ short,
int, long and long can represent up to four different integer widths. It would be
convenient if each type were always some particular width for all systems—for example, if
short were always 16 bits, int were always 32 bits, and so on. But life is not that simple.
