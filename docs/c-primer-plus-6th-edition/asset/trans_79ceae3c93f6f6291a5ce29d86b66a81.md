## 使用 get() 进行行定向输入

让我们尝试另一种方法。cin 对象还有另一个成员函数 get()，它有多种变体。其中一种变体的工作方式与 getline() 非常相似。它接受相同的参数，以相同的方式解释它们，并读取到行尾。但与读取并丢弃换行符不同，get() 会将该换行符留在输入队列中。假设你连续使用两次 get() 调用：

```cpp
cin.get(name, ArSize);
cin.get(dessert, ArSize); // a problem
```

![](img/cd111a87c1db9aff4db4b18834327463_142_0.png)
Figure 4.5 getline() reads and replaces the newline character.

由于第一次调用会将换行符留在输入队列中，该换行符将成为第二次调用看到的第一个字符。因此，get() 认为它已到达行尾而没有找到任何内容可读。在没有帮助的情况下，get() 根本无法越过该换行符。

幸运的是，有一种 get() 的变体可以提供帮助。调用 cin.get()（不带参数）会读取下一个单个字符，即使它是换行符，因此你可以用它来处理换行符并为下一行输入做好准备。也就是说，以下序列：

```cpp
cin.get(name, ArSize); // read first line
cin.get(); // read newline
cin.get(dessert, ArSize); // read second line
```

另一种使用 get() 连接或合并两个类成员函数的方法如下：
cin.get(name, ArSize).get(); // concatenate member functions

之所以可行，是因为 cin.get(name, ArSize) 返回 cin 对象，该对象随后被用作调用 get() 函数的对象。类似地，以下

语句将两个连续的输入行读入数组 name1 和 name2；它等同于对 cin.getline() 进行两次单独调用：

```cpp
cin.getline(name1, ArSize).getline(name2, ArSize);
```

Listing 4.5 使用了连接。在第 11 章“使用类”中，你将学习如何将此功能纳入你的类定义中。

# Listing 4.5 instr3.cpp

// instr3.cpp -- reading more than one word with get() & get()

{
    using namespace std;
    const int ArSize = 20;
    char name[ArSize];
    char dessert[ArSize];
