
C 风格字符串。但逐行读取而不是逐词读取使用不同的语法。清单 4.10 展示了这种差异。

# Listing 4.10 strtype4.cpp

```cpp
// strtype4.cpp -- line input
#include <iostream>
#include <string> // make string class available
#include <cstring>     // C-style string library
int main() {
{
    using namespace std;
    char buffer[20];
    string str;
    cout << "Length of string in char before input: ";
    cout << strlen(buffer) << endl;
    cout << "Length of string in str before input: ";
    cout << str.size() << endl;
    cout << "Enter a line of text:\n";
    cin.getline(buffer, 20); // indicate maximum length
    cout << "You entered: " << buffer << endl;
    cout << "Enter another line of text:\n";
    getline(cin, str); // cin now an argument; no length specifier
    cout << "You entered: " << str << endl;
    cout << "Length of string in char after input: ";
    cout << strlen(buffer) << endl;
    cout << "Length of string in str after input: ";
    cout << str.size() << endl;

    return 0;
}
```

以下是清单 4.10 程序的一个示例运行：

Length of string in char before input: 27
Length of string in str before input: 0
Enter a line of text:
peanut butter
You entered: peanut butter
Enter another line of text:
blueberry jam
You entered: blueberry jam
Length of string in char after input: 13
Length of string in str after input: 13

请注意，程序说在输入前 char 数组中字符串的长度是 27，这比数组的大小还要大！这里发生了两件事。首先，未初始化数组的内容是未定义的。其次，strlen() 函数的工作方式是从数组的第一个元素开始计数字节，直到遇到空字符。在这种情况下，第一个空字符直到数组末尾之后的几个字节才出现。未初始化数据中第一个空字符出现的位置本质上是随机的，因此使用此程序可能会得到不同的结果。

另请注意，在输入前 str 中的字符串长度为 0。那是因为未初始化的字符串对象会自动设置为零大小。

这是将一行读入数组的代码：

```cpp
cin.getline(buffer, 20);
```

点表示法表明 getline() 函数是 istream 类的类方法。 （请记住 cin 是一个 istream 对象。）正如前面提到的，第一个参数是目标数组，第二个参数是数组大小，getline() 用它来避免溢出数组。

这是将一行读入字符串对象的代码：

```cpp
getline(cin,str);
```

没有点表示法，这表明此 getline() 不是类方法。因此它将 cin 作为参数，告诉它从哪里查找输入。没有字符串大小的参数，因为字符串对象会自动调整大小以适应字符串。

那么为什么 getline() 是 istream 类方法而另一个 getline() 不是呢？ istream 类在 string 类被添加之前很久就已成为 C++ 的一部分。因此，istream 类识别 C++ 类型，如 double 和 int，但它不知道 string 类型。因此，存在用于处理 double、int 和其他基本类型的 istream 类方法，但不存在用于处理 string 对象的 istream 类方法。

由于不存在用于处理 string 对象的 istream 类方法，你可能会想知道为什么会有这样的代码：

```cpp
cin >> str; // read a word into the str object
```

事实证明，像以下代码（以伪装的表示法）使用 istream 类的成员函数：

```cpp
cin >> x; // read a value into a basic C++ type
```

但 string 类的等价物使用 string 类的友元函数（同样以伪装的表示法）。你必须等到第 11 章才能看到友元函数是什么以及这种技术是如何工作的。在此期间，你可以使用 cin 和 cout 与 string 对象，而不必担心其内部工作原理。

# Other Forms of String Literals

C++ 回顾一下，除了 char 外还有 wchar_t 类型。C++11 还增加了 char16_t 和 char32_t 类型。可以创建这些类型的数组和字符串字面量。C++ 分别使用 L、u 和 U 前缀用于这些类型的字符串字面量。以下是它们如何使用的一个示例：

```cpp
wchar_t title[] = L"Chief Astrogator"; // w_char string
char16_t name[] = U"Felonia Ripova"; // char_16 string
char32_t car[] = U"Humber Super Snipe"; // char_32 string
```

C++11 还支持 Unicode UTF-8 的编码方案。在该方案中，一个字符可以根据数值存储在从 8 位单元或八位字节到 4 位单元的任何位置。C++ 使用 u 前缀来表示该类型的字符串字面量。

C++11 的另一个新增功能是原始字符串。在原始字符串中，字符仅代表其自身；序列 \n 不会被解释为换行符；它只是两个普通字符，反斜杠和 n，并且会在屏幕上显示为两个字符。例如，你可以在字符串中使用 " 而不是字面量，不再可以使用它来删除字符串的两端。因此，原始字符串使用 "(" 和 "))" 作为定界符，并且你可以使用 R 前缀将它们标识为原始字符串：

```cpp
cout << R"(King Tutt uses \\n" instead of endl.") << '\n';
```

这将显示以下内容：

Jim "King" uses \n instead of endl.

标准字面量等价物是：

```cpp
cout << "Jim \"King\" uses \\\n instead of endl." << '\n';
```

这里我们必须使用 \\ 来解码单个 \ 被解释为转义序列的第一个字符。

如果你在输入原始字符串时按下 Enter 或 Return 键，这只会将光标移动到屏幕的下一行，它也会在原始字符串中放置一个回车字符。
如果想在原始字符串中使用组合 " 怎么办？ （谁不会呢）
编译器会不会把第一个出现的 " 解释为字符串的结束？会的。但原始语法允许你在开头和（这意味着相同的附加字符必须出现在最后和 " 之间）。因此，以 R"*( 开头的字符串（必须以 "*）结尾。因此，语句

```cpp
cout << R"*((Who wouldn't?", she whispered.)*\*" << endl;
```

将显示以下内容：

"(Who wouldn't?)", she whispered.

# Chapter 4 Compound Types

简而言之，默认定界符 "(" 和 "))" 已被 "*+ 和 "* " 替换。你可以使用基本字符集的任何成员作为定界符的一部分，除了空格、左括号、右括号、反斜杠以及制表符或换行符等字符。

前缀可以与其它字符串前缀组合以生成 wchar_t 等的原始字符串。它可以是复合前缀的第一部分或最后一部分：Ru、Ur 等。

# Introducing Structures

假设你想存储关于一名篮球运动员的信息。你可能想存储他的名字、薪水、身高、体重、得分平均值、罚球命中率、助攻等等。你希望某种数据表单能够将所有这些信息保存在一个单元中。数组不行。虽然数组可以保存多个项目，但每个项目必须是相同类型。也就是说，一个数组可以保存 20 个元素，另一个可以保存 10 个浮点数，但单个数组不能在其他元素中存储 int 和 float。

满足你愿望的答案（存储关于篮球运动员的信息）是 C++ 结构。结构比数组更灵活的数据，因为单个结构可以保存不止一种类型。这使你能够通过将所有相关的篮球信息存储在单个变量中来统一你的数据表示。如果你想跟踪整个球队，你可以使用结构数组。结构类型也是 C++ OOP 大量的垫脚石。现在学习一点关于结构的内容，将使你更接近 C++ 的 OOP 核心。

结构是用户定义的类型，结构声明用于定义类型的数据属性。在你定义类型后，你可以创建该类型的变量。创建结构是一个两部分的过程。首先，你定义一个结构描述，描述和标记可以存储在结构中的不同数据类型。然后你可以创建变量，或更一般地，遵循描述计划的结构数据对象。

例如，假设 Bloataire, Inc. 想要创建一个类型来描述其充气产品线的成员。特别是，结构应保存项目的名称、其体积（立方英尺）和售价。以下是满足需求的结构描述：

```cpp
struct inflatable // structure declaration
{
    char name[20];
    float volume;
    double price;
};
```
