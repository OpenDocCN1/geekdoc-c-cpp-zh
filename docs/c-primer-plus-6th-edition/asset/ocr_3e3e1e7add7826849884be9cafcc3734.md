# Floating-Point Types

Like ANSI C, C++ has three floating-point types: float, double, and long. These types are described in terms of the number of significant figures they can represent and the minimum allowable range of exponents. Significant figures are the meaningful digits in a number. For example, writing the height of Mt. Shasta in California as 14,179 feet uses five significant figures, for it specifies the height to the nearest foot. But writing the height of Mt. Shasta as around 14,000 feet uses two significant figures, for the result is rounded to the nearest thousand foot; in this case, the remaining three digits are just placeholders. The number of significant figures doesn't depend on the location of the decimal point. For example, you can write the height 14.179 thousand feet. Again, this five significant digits because the value is accurate to the fifth digit.

In effect, the C and C++ requirements for significant digits amount to float being at least 32 bits, double being at least 48 bits and no smaller than float, and long being at least as big as double. Both can be the same size. Typically, however, float is 32 bits, double is 64 bits, and long double is 80, 96, or 128 bits. Also the range in exponents for all types is at -37 to +37. Use cfloat or float.h header to find the limits for your system. (cfloat is the C++ version of C float.h file) Here are some annotated entries from the float.h file for Borland C++Builder:

```
// the following are the minimum number of significant digits
#define DBL_DIG 15      // double
#define FLT_DIG 6       // float
#define LDB_DIG 18      // long double
```

```
// the following are the number of bits used to represent the mantissa
#define DBL_MANT_DIG 53
#define FLT_MANT_DIG 24
#define LDB_MANT_DIG 64
```

```
// the following are the maximum and minimum exponent values
#define DBL_MAX_EXP +308
#define FLT_MAX_EXP +38
#define LDB_MAX_EXP +4932
```

```
#define DBL_MIN_EXP -307
#define FLT_MIN_EXP -37
#define LDB_MIN_EXP -4931
```
