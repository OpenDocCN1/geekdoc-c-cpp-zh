This new implementation of the *Brass and BrassPlus* accounts can be used in the same manner as the old one because the class methods have the same names and interfaces as before. For example, to convert Listing 13.10 to the new implementation, just need to take these steps to convert usebrass2.cpp to a usebrass3.cpp file:

+   - Link usebrass2.cpp with acctabc.cpp instead of brass.cpp.
- Include acctabc.h instead of brass.h.
- Replace

```
Brass * p_clients[CLIENTS];

with

AcctABC * p_clients[CLIENTS];
```

Listing 13.13 shows the resulting example, named usebrass3.cpp.
