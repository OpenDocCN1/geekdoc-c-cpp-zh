The write() method can also be used with numeric data. You would pass it the address of a number, type cast to char *:

```
long val = 560031841;
out.write((char *) &val, sizeof(long));
```

This doesn't translate a number to the correct characters; instead, it transmits the bit representation stored in memory. For example, a 4-byte value such as 56003184 would be transmitted as 4 separate bytes. An output device such as a monitor would then try to interpret each byte as if it were ASCII (or whatever code). So 56003184 would appear onscreen as some 4-character combination, most likely gibberish. (But maybe not; try it and see.) However, write() does provide a compact, accurate way to store numeric data in a file. We will return to this possibility later.

# Flushing the Output Buffer

Consider what happens as a program uses cout to send to the standard output. Because the ofstream buffer class output the cout object, isn't sent to its destination immediately. Instead, it accumulates in the buffer until the buffer is full. The program flushes the buffer, sending the contents on and clearing the buffer for new data. Buffering is a great time-saver when the standard output is connected to a hard disk. After all, you don't want a program to access the hard disk 52 times to send 512 bytes. It's much more effective to collect 512 bytes in a buffer and write them to a hard disk in a single operation.

For screen output, however, filling the buffer is less critical. It would be inconvenient if you had to reread the message "Press any key to continue" so that it continue. In the case of screen output, the program doesn't necessarily wait until the buffer is full. Sending a newline to the buffer, for example, normally flushes the buffer. Also as mentioned before, most C++ implementations flush the buffer when input is pending. That is, suppose you have the following:

```
cout << "Enter a number: ";
float num;
 >> num;
```

The fact that the program expects input causes it to display the cout message (that is, flush the "Enter a number: " message) immediately, even though the output lacks a newline character. Without this feature, the program would wait for input without prompting the user with the cout message.
