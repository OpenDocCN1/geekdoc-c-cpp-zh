### 预处理器方式的符号常量

climits 文件包含类似这样的行：

```
#define INT_MAX 32767
```

回想一下，C++ 编译过程首先将源代码通过预处理器处理。这里的 #define 与 #include 一样，是一个预处理器指令。告诉预处理器这个特定指令的是：查找程序中 INT_MAX 的实例并将其每个出现都替换为 32767。因此 #define 指令的工作方式类似于文本编辑器或文字处理软件中的全局搜索和替换命令。独立程序在这些替换发生后才会被编译。预处理器查找单个标记并跳过嵌入的词。也就是说，预处理器不会将 PINT_MAX 替换为 P32767IM。你也可以使用 #define 来定义自己的符号常量（参见列表 3.2）。然而，#define 指令是 C 的遗留物。C++ 有一种更好的创建符号常量的方法（使用 const 关键字，在后面的章节中讨论），因此你不会使用 #define。但某些头文件，特别是那些设计为同时用于 C 和 C++ 的头文件，确实会使用它。

### 初始化

初始化与声明结合使用。例如，以下语句声明 n_int 变量并将其设置为可能的最大类型值：

```
int n_int = INT_MAX;
```

你也可以使用字面常量，例如 255，来初始化值。你可以初始化一个变量为另一个变量，前提是另一个变量已被定义。你甚至可以初始化一个变量为表达式，前提是在程序执行到达声明时表达式中的所有值都是已知的：

```
int uncles = 5;                      // 将 uncles 初始化为 5
int aunts = uncles;                  // 将 aunts 初始化为 5
int chairs = aunts + uncles + 4;    // 将 chairs 初始化为 14
```

将 uncles 的声明移到这组语句的末尾将使另外两个初始化失效，因为在程序尝试初始化其他变量时 uncles 的值是未知的。

前面显示的初始化语法来自 C；C++ 有一种与 C 不共享的初始化语法：

```
int owls = 101;               // 传统的 C 初始化，将 owls 设置为 101
int wrens (432);                   // 替代的 C++ 语法，将 wrens 设置为 432
```

### 警告

如果你没有初始化在函数内部定义的变量，该变量的值是不确定的。这意味着该值是变量创建之前恰好位于该内存位置的值。

如果你知道变量的初始值应该是什么，就初始化它。确实，将变量的声明与赋值的分离可以制造短暂的悬念：

```
short year;                  // 它会是什么？
year = 1492;                   // 哦
```

但在声明时初始化变量可以防止你忘记稍后设置值。

### 使用 C++11 的初始化

还有一种用于数组和结构体的初始化格式，但在 C++98 中也可以用于单值变量：

```
int hamburgers = {24}; // 将 hamburgers 设置为 24
```

使用大括号初始化器为单值变量并不特别常见，但 C++11 标准在某些方面扩展了它。首先，它可以有或没有等号使用：

```
int emus{}; // 将 emus 设置为 0
int rheas = {12}; // 将 rheas 设置为 12
```

其次，大括号可以为空，在这种情况下变量被初始化为 0：

```
int rocs{}; // 将 rocs 设置为 0
int psychics{}; // 将 psychics 设置为 0
```

第三，它提供了更好的类型转换错误保护，我们将在本章末尾再次讨论这一主题。

为什么，原因充分，你可能会问，语言需要更多替代方案？正如它可能看起来，原因是让 C++ 对初学者更友好。过去，C++ 对不同类型使用不同的初始化形式，用于初始化类变量的形式与用于普通结构体的形式不同——而在这一点上，又与用于使普通变量的初始化更像类变量初始化的括号形式不同。C++ 添加了更多类似初始化类变量的形式。C++11 使能够对所有类型使用大括号语法（有或没有 =）成为可能——一种通用的初始化语法。在未来，教材可能会介绍你使用大括号形式进行初始化，并将其他形式作为为向后兼容而保留的历史怪癖提及。

### 无符号类型

你刚刚学习的四种类型中的每一种都有一个无符号变体，不能保存负值，其优点是增加了它们可以保存的最大值。例如，如果 short 表示范围 -32,768 到 +32,767，无符号版本可以表示范围 0 到 65,535。当然，你应该只对永远不会为负的量使用无符号类型，例如人口、豆子计数和快乐面部表情。要创建基本整数类型的无符号版本，你只需使用关键字 unsigned 来修改声明：

```
unsigned short change; // unsigned short 类型
unsigned int revert; // unsigned int 类型
unsigned int quarterback; // unsigned int 类型
unsigned long gone; // unsigned long 类型
unsigned long long lang_; // unsigned long long 类型
```

请注意，unsigned 本身是 unsigned int 的简写。

列表 3.2 说明了无符号类型的使用。它还展示了如果你的程序尝试超出整数类型的限制可能会发生什么。最后，它给你最后一次查看预处理器 #define 语句的机会。

### 列表 3.2 exceed.cpp

```
// exceed.cpp 超出某些整数限制
#include <iostream>
#define ZERO 0 // 使 ZERO 成为 0 值的符号
#include <climits> // 定义 INT_MAX 为最大 int 值
int main() {
    using namespace std;
    short sam = SHRT_MAX; // 将变量初始化为最大值
    unsigned short sue = sam; // 如果变量已经超出则可以

    cout << "Sam has " << sam << " dollars and Sue has " << sue << ";
    cout << " dollars deposited." << endl;
    cout << "Add $1 to each account." << endl << "Now";
    sam = sam + 1;
    sue = sue + 1;
    cout << "Sam has " << sam << " dollars and Sue has " << sue << ";
    cout << " dollars deposited.\nPoor Sam!" << endl;
    sam = ZERO;
    sue = ZERO;
    cout << "Sam has " << sam << " dollars and Sue has " << sue << ";
    cout << " dollars deposited." << endl;
    cout << "Take $1 from each account." << endl << "Now";
    sam = sam - 1;
    sue = sue - 1;
    cout << "Sam has " << sam << " dollars and Sue has " << sue << ";
    cout << " dollars deposited." << endl << "Lucky Sue!" << endl;
    return 0;
}
```

以下是列表 3.2 中程序的输出：

Sam has 32767 dollars and Sue has 32767 dollars deposited.
Add $1 to each account.
Now Sam has -32768 dollars and Sue has 32768 dollars deposited.
Poor Sam!
Sam has 0 dollars and Sue has 0 dollars deposited.
Take $1 from each account.
Now Sam has -1 dollars and Sue has 65535 dollars deposited.
Lucky Sue!
