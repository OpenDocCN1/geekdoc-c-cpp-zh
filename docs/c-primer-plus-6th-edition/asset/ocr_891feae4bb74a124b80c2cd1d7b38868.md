C++ provides a special syntax for class constructors that can be used to initialize data members. This syntax consists of a colon followed by a comma-separated list of initializers. This is placed after the parameter list of the constructor arguments and before the opening brace of the function body. Each initializer consists of the name of the member being initialized followed by parentheses containing the initialization value. Conceptually, these initializations take place when the object is created and before any statements in the function body. The syntax looks like this:

```
queue(int qs) : qsize(qs), items (0), front (NULL), rear (NULL) { }
```

This form is obligatory if the data member is a nonstatic const member or reference, except that C++11 in-class initialization can be used for nonstatic const members. C++11 allows in-class initialization (that is, initialization in the class definition):

```
class Queue
{
private:
    Node * front = NULL;
    enum (Q_SIZE = 10);
    Node * rear = NULL;
    int items = 0;
    const int qsize = Q_SIZE;
};
```

This is equivalent to using a member initialization list. However, any constructor a membership initialization list will override the corresponding in-class initializations.
