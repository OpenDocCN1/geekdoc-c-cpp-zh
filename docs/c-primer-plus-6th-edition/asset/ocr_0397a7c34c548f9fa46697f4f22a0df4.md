# Additional Members for Sequence Containers 1279

Table G.6 Operations Defined for Some Sequences
| Operation | Description | Container |
| :--- | :--- | :--- |
| a.emplace_back(args) | Appends an object T using the T constructor with the arguments packed into args. | vector, list, deque |
| a.push_front(t) | Inserts a copy of t before the first element. | forward_list, deque |
| a.push_front(rv) | Inserts a copy of rv before the first element. Move semantics may be used. | forward_list, deque |
| a.emplace_front() | Inserts in the front of an object T using the T constructor with the arguments packed into args. | forward_list, deque |
| a.pop_front() | Erases the first element. | forward_list, deque |
| a[n] | Returns * (a.begin() + n). | vector, deque, array |
| a.at(n) | Returns * (a.begin() + n); throws out_of_range exception if n > a.size(). | vector, deque, array |

The vector template additionally has the methods in Table G.7. Here, a is a vector container and n is an integer of X::size_type.

Table G.7 Additional Operations for Vectors
| Operation | Description |
| :--- | :--- |
| a.capacity() | Returns the total number of elements the vector can hold without requiring reallocation. |
| a.reserve(n) | Alerts object that memory for at least n elements is needed. After the method call, the capacity will be at least n elements. Reallocation occurs if n is greater than the current capacity. If n is greater than a.max_size(), the method throws a length_error exception.|

The list template additionally has the methods in Table G.8. Here, a and b are list containers, and T is the type stored in the list, such as int, t is a value of type T, and j are input iterators, q2 and p are iterators, q and q are dereference iterators, and n is an integer of X::size_type. The table uses the standard STL notation [i, j], meaning the range from i up to, but not including, j.
