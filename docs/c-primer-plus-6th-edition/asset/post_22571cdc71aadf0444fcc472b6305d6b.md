
## Chapter 16 The string Class and the Standard Template Library

There are many methods, but these are enough to put together a sample program that's a graphically implied version of the word game Hangman. The game stores a list of words in an array of string objects, picks a word at random, and lets you guess letters in the word. Six wrong guesses, and you lose. The program uses the find() function to check your guesses and the ++ operator to build a string object to keep track of your wrong guesses. To keep track of your good guesses, the program creates a word length as the word consisting of hyphens. The hyphens are replaced by correct guesses. Listing 16.3 shows the program.

### Listing 16.3 hangman.cpp

```cpp
// hangman.cpp -- some string methods
#include <iostream>
#include <string>
#include <cstdlib>
#include <ctime>
#include <cctype>
using namespace std;
const int NUM = 26;
const string wordlist[NUM] = {"apiary", "beetle", "cereal",
"danger", "esign", "florid", "garage", "health", "insult",
"jackal", "keeper", "loaner", "manage", "nonce", "onset",
"plaid", "quilt", "remote", "stolid", "train", "useful",
"valid", "whence", "xenon", "yearn", "zippy"};

int main()
{
using std::cout;
using std::cin;
using std::tolower;
using std::endl;
    srand(time(0));
    char play;
    cout << "Will you play a word game? <y/n> "; cin >> play;
    play = tolower(play);
    while (play == 'y')
    {
        string target = wordlist[rand() % NUM];
        intint length = target.length();
        string attempt(length, '-');
        string badchars;
        int guesses = 6;
        cout << "Guess my secret word. It has " << length
            << " letters, and you guess\n"
            << "one letter at a time. You get " << guesses
            << " wrong guesses.\n";
        cout << "Your word: " << attempt << endl;
        while (guesses > 0 && attempt != target)
        {
            char letter;
            cout << "Guess a letter: ";
            cin >> letter;
            if (badchars.find(letter) != string::npos
            || attempt.find(letter) != string::npos)
            {
                cout << "You already guessed that. Try again.\n";
                continue;
            }
            int loc = target.find(letter);
            if (loc == string::npos)
            {
                cout << "Oh, bad guess!\n";
                --guesses;
                badchars += letter; // add to string
            }
            else
            {
                cout << "Good guess!\n";
                attempt[loc]=letter;
                // check if letter appears again
                loc = target.find(letter, loc + 1);
                while (loc != string::npos)
                {
                    attempt[loc]=letter;
                    loc = target.find(letter, loc + 1);
                }
            }
        }
        cout << "Your word: " << attempt << endl;
        if (attempt != target)
        {
            if (badchars.length() > 0)
            {
                cout << "Bad choices: " << badchars << endl;
            }
            cout << << << " * bad guesses left\n";
        }
        if (guesses > 0)
            cout << "That's right!\n";
        else
            cout << "Sorry, the word is " << target << "*.\n";
    }
    cout << "Will you play another? <y/n> ";
    cin >> play;
    play = tolower(play);

    cout << "Bye\n";

    return 0;
}
```

### Program Notes

In Listing 16.3, the fact that the relational operators are overloaded lets you treat strings in the same fashion would treat numeric variables: The program uses find() to check whether a character was selected; if already selected, it will find (bad guesses) or in the attempt string (good guesses).

The npos is a static member of the string class. Its value, recall, is the maximum allowable number of characters for a string. Because indexing begins at zero, it is greater than the largest possible index and can be used to indicate failure to find a character. The program makes use of the fact that one of the overloaded versions of += lets you append individual characters to a string: The heart of the program begins by checking whether the chosen letter is in the mystery word: If loc is a valid value, it can be placed in the corresponding location in the answer string: However, given letter might occur more than once in the mystery word, so the program has to keep checking. The program uses the optional second argument to find(), which specifies a starting place in the string from which to begin. Because the letter was found at loc, the next search should begin at loc + 1. While loop keeps the searching until no occurrences of that character are. Note that find() indicates failure if loc is the end of the string:

```cpp
// check if letter appears again
loc = target.find(letter, loc + 1);
while (loc != string::npos)
{
    attempt[loc]=letter;
    loc = target.find(letter, loc + 1);
}
```

### What Else Does the string Class Offer?

The string library supplies many other facilities. There are functions for erasing part or all of a string, for replacing part or all of one string with part of another string, for inserting material into a string or removing material from a string, for comparing part or all of one string with part of another string, and for extracting a substring from a string. There's a function for copying part of one string to another string, and for swapping the contents of two strings. Most of these are overloaded so that they work with C-style strings as well as string objects. Appendix F describes the string library briefly, but let's talk about a few more here.

First, think about the automatic sizing feature. In Listing 16.3, what happens each time the program appends a letter to a string? It because it might realloc into neighboring memory that is already in use. It may have to allocate a new block and then copy the old contents to a new location. It would be inefficient to do this, so many C++ implementations allocate a block of memory larger than the actual string, giving the string room to grow. Then if the string eventually exceeds its size, the program allocates a new block twice the size to afford more room without continuous resizing. The capacity() method returns the size of the current block, and the reserve() method allows you to request a minimum size for the current block.

Listing 16.4 shows an example that uses these methods.

```cpp
// str2.cpp
#include <iostream>
#include <string>
int main()
{
    using namespace std;
    string empty;
    string small = "bit";
    string larger = "Elephants are a girl's best friend";
    cout << "Sizes:" << empty.size() << endl;
    cout << "small:" << small.size() << endl;
    cout << "tlarger:" << larger.size() << endl;
    cout << "Capacities:" << empty.capacity() << endl;
    cout << "empty:" << empty.capacity() << endl;
    cout << "small:" << small.capacity() << endl;
    cout << "tlarger:" << larger.capacity() << endl;
    empty.reserve(50);
    cout << "Capacity after empty.reserve(50) : "
    << empty.capacity() << endl;
    return 0;
}
```

Here is the output of the program in Listing 16.4 for one C++ implementation:

Capacities:
empty: 15
small: 15

Note that this implementation uses a minimum capacity of 15 and seems to use less than multiples of 16 as standard for capacities. Other implementations make different choices.

### String Varieties

This section treats the string class as if it were based on the char type. In fact, as mentioned earlier, the string library really is based on a template class:

```cpp
template<class charT, class traits = char_traits<charT>
class Allocator = allocator<charT> =
basic_string {...};
```

The basic_string template comes with four specializations, each of which has a typedef name:

```cpp
typedef basic_string<char> string;
typedef basic_string<wchar_t> wstring;
typedef basic_string<char16_t> u16string; // C++11
typedef basic_string<char32_t> u32string; // C++11
```
