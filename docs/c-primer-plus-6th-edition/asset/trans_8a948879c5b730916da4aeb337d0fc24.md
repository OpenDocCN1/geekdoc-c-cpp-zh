## 浮点类型

与 ANSI C 一样，C++ 有三种浮点类型：float、double 和 long double。这些类型根据它们能表示的有效数字位数以及允许的指数最小范围来描述。有效数字是数字中有意义的数字。例如，将加州沙斯塔山的高度写为 14,179 英尺使用了五个有效数字，因为它指定了精确到英尺的高度。但将沙斯塔山的高度写为大约 14,000 英尺使用了两个有效数字，因为结果四舍五入到最近的千英尺；在这种情况下，其余三个数字只是占位符。有效数字的位数与小数点的位置无关。例如，你可以写高度为 14.179 千英尺。同样，这也是五个有效数字，因为该值精确到第五位数字。

实际上，C 和 C++ 对有效数字的要求相当于 float 至少为 32 位，double 至少为 48 位且不小于 float，long double 至少与 double 一样大。两者可以是相同大小。通常情况下，float 为 32 位，double 为 64 位，long double 为 80、96 或 128 位。此外，所有类型的指数范围都在 -37 到 +37 之间。使用 cfloat 或 float.h 头文件查找你系统的限制。（cfloat 是 C float.h 文件的 C++ 版本）以下是 Borland C++Builder 的 float.h 文件中的一些带注释的条目：

## 读取包含文件

C++ 源文件顶部包含指令往往带有神秘咒语般的气息；与 C++ 程序员学习不同，通过阅读和经验，他们了解哪些头文件添加了哪些特性，并且仅为了使程序工作而包含它们。不要将包含文件视为某种神秘和深奥的知识；请随意打开它们并阅读它们。它们是文本文件，因此你可以轻松阅读。你在程序中包含的文件存在于你的计算机上或你的计算机可以使用的位置。找到你使用的包含文件并查看它们包含的内容。你会很快发现你使用的源文件和头文件是知识和信息的极佳来源——在某些情况下，是最好的文档。以后，当你进入更复杂的包含和使用应用程序中的其他非标准库时，这种习惯会为你带来好处。

## 浮点常量

当你在程序中写一个浮点常量时，程序将其存储为什么浮点类型？默认情况下，像 8.24 和 2.4E8 这样的浮点常量是 double 类型。如果你希望常量为 float，请使用 f 或 F 后缀。对于 long double 类型，使用 l 或 L 后缀。（因为小写 l 看起来很像数字 1，大写 L 是更好的选择）。以下是一些示例：

```
1.234f      // a float constant
2.45E08     // a float constant
2.345324E28  // a double constant
2.2L        // a long double constant
```

## 浮点数的优点和缺点

浮点数相对于整数有两个优点。首先，它们可以表示整数之间的值。其次，由于缩放因子，它们可以表示更广的数值范围。另一方面，浮点运算比整数运算稍慢，并且可能丢失精度。清单 3.9 说明了最后一点。
