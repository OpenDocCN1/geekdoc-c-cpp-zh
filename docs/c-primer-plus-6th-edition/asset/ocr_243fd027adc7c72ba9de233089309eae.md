Other compilers may produce programs that crash when division zero occurs. It is best to write code that behaves in the same controlled fashion on all systems.

# Calling abort ()

One way to handle this is to call the function abort() if one argument is the negative of the other.The abort() function has its prototype in the cstdlib (or stdlib.h) header file. A typical implementation, if called, sends a message as "abnormal program termination" to the standard error (the same as one used by cerr) and terminates the program. It returns an implementation-dependent value that fails to call the operating system, or if the program was initiated by the parent process. Whether abort() flushes buffers (that is, memory areas used to store material for transfers to and from files) depends on the implementation. If you prefer, you can use exit(), which does flush buffers, but displaying a message. Listing 15.7 shows a short program that uses abort().
