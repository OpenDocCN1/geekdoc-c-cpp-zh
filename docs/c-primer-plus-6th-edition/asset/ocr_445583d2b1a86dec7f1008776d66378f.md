# Nested Loops and Two-Dimensional Arrays

common C++ practice of initializing an array of pointers to a string constants. That is, cities is declared as an array of pointers-to-char. Makes each element, such as cities[0], a pointer-to-char that can be initialized to the address of a string. The program initializes cities[0] to the address of the "Gribble City" string, and so on. Thus, this array of pointers behaves like an array of strings.

Listing 5.20 nested.cpp

```
// nested.cpp -- nested loops and 2-D array
#include <iostream>
const int Cities = 5;
const int Years = 4;
int main()
{
    using namespace std;
    const char * cities[Cities] = // array of pointers
        // to 5 strings
        "Gribble City",
        "Gribbletown",
        "New Gribble",
        "San Gribble",
        "Gribble Vista"
    };
    int matemps[Years][Cities] = // 2-D array
    {
        {96, 100, 87, 101, 105}, // values for matemps[0]
        {96, 98, 91, 107, 104}, // values for matemps[1]
        {97, 101, 93, 108, 107}, // values for matemps[2]
        {98, 103, 95, 109, 108} // values for matemps[3]
    };

    cout << "Maximum temperatures for 2008\n\n";
    for (int city = 0; city < Cities; ++city)
    {
        cout << cities[city] << ":\t";
        for (int year = 0; year < Years; ++year)
        {
            cout << matemps[year][city] << "\t";
        }
        cout << endl;
    }

    cin.get();
    return 0;
}
```
