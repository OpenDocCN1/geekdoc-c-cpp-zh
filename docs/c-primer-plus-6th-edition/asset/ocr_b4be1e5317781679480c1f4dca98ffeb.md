# Program Notes

Note that when a constructor has a single argument, you can use the following form when initializing a class object:

```
// a syntax for initializing a class object
// using a constructor with one argument
Stonew incognito = 275;
```

This is equivalent to the other two forms shown earlier:

```
// standard syntax forms for initializing class objects
Stonew incognito = 275;
Stonew incognito = Stonew (275);
```

However, the last two forms can also be used with constructors that have multiple arguments.

Next, note the following two assignments from Listing 11.18:

```
incognito = 276.8;
taft = 325;
```

The first of these assignments use the constructor with a type double argument to convert 276.8 to a Stonew value. This sets the pounds member of incognito to 276.8. Because it uses the constructor, this assignment also sets the stone and pds_list of the class. The second assignment converts a type int value to double and then uses Stonew (double) to set all three member values in the process.

Finally, note the following function call:

```
display(422, 2); // convert double to double, then to Stonew
```

The prototype for display() indicates that its first argument should be the Stonew object. Either a Stonew & formal parameter... Confronted with an int argument, the compiler looks for a Stonew (int) constructor to convert the int to the desired Stonew type. Failing to find that constructor, the compiler looks for a constructor with some other built-in type that an int can be converted. The Stonew (double) constructor fits the bill. The compiler converts int to double and then uses Stonew (double) to convert the result to a Stonew object.

# Conversion Functions

Listing 11.18 converts a number to a Stonew object. Can you do the reverse? That is, can you convert a Stonew object to a double value, as in the following?

```
Stonew wolfe (285.5);
double host = wolfe; // ?? possible ??
```

The answer is that you can do this—but not by using constructors. Constructors only provide for converting another type to the class. To do the reverse, you have to use a special form of a C++ operator function called a conversion function.
