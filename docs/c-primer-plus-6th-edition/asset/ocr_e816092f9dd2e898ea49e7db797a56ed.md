# Specifiers and Qualifiers

Certain C++ keywords, called storage class specifiers and cv-qualifiers, provide additional information about storage. Here's a list of the storage class specifiers:

```
auto (eliminated as a specifier in C++11)
register
static
extern
thread_local (added by C++11)
mutable
```

You've already seen most of these, and you can use no more than one of them in a single declaration, except that thread_local can be used with static or extern. To review, prior to C++11, the keyword auto could be used in a declaration to document that the variable is an automatic variable. (In C++11, auto is used for automatic deduction.) The keyword register is used in a declaration to indicate the register storage class, which in C++11, is simply an explicit way of saying the variable is automatic. The keyword static, when used with a file-scope declaration, indicates internal linkage. When used with a local declaration, it indicates static storage for a local variable. The keyword extern a reference declaration—that is, the declaration refers to a variable defined elsewhere. The keyword thread_local indicates that the duration of the variable is the duration of the thread, to as much as a regular static variable is to the whole program. The keyword mutable is explained in terms of const, so let's look at the cv-qualifiers first before returning to mutable.
