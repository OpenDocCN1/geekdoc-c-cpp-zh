# 当你需要更多时：wchar_t

程序可能需要处理无法容纳在单个 8 位字节内的字符（例如日文汉字系统）。C++ 以几种方式处理这个问题。首先，如果一个大型字符集是实现的<|message|> 基本字符，编译器可以定义 char 为 16 字节或更大。其次，实现可以同时支持一个较小的<|message|> 基本集和一个较大的扩展集。通常的 8 位 char 可以表示基本字符，另一种类型，称为 wchar_t（宽字符类型），wchar_t 类型是一个整数类型，具有足够空间来表示系统上使用的扩展集。它具有与另一种整数类型相同的大小和属性，该类型称为底层类型。类型的选择取决于实现，因此在一种系统上可能是 unsigned short，而在另一种系统上可能是 int。

```cpp
wchar_t bob = L'LP'; // a wide-character constant
wcout << L"total" << endl; // outputting a wide-character string
```

在 wchar_t 为 2 字节的系统上，此代码将每个字符存储在 2 字节的内存单元中。本书不使用宽字符类型，但你应该了解它，特别是如果你参与国际化编程或使用 Unicode 或 ISO 10646。

# 新的 C++11 类型：char16_t 和 char32_t

随着编程社区对 Unicode 的经验增加，很明显 wchar_t 不够用。事实证明，在计算机系统上对字符和字符字符串进行编码比仅仅使用 Unicode 值（称为码点）更复杂。特别是，在编码字符时，使用具有确定大小和符号性的类型是有用的。wchar_t 的位和大小可能因实现而异。因此 C++11 引入了类型 char16_t，它是无符号且为 16 位，以及 char32_t，它是无符号且为 32 位。C++11 使用前缀 u 表示 char16_t 字符和字符串常量，如 'uC' 和 u"be good"。类似地，它使用前缀 U 表示 char32_t 常量，如 U'R' 和 U"dirty rat"。char16_t 是 \u00F6 形式的通用字符名的自然匹配，而 char32_t 是 \U0000222B 形式的通用字符名的自然匹配。前缀 u 和 U 用于分别表示类型为 char16_t 和 char32_t 的字符字面量：

```cpp
char16_t chl = u'q'; // basic character in 16-bit form
char32_t ch22 = U'\U0000222B'; // universal character name in 32-bit form
```

与 wchar_t 一样，char16_t 和 char32_t 各自都有一个底层类型，它是内置类型之一。但底层类型在一台系统上可能与另一台系统上的不同。

# bool 类型

ANSI/ISO C++ 添加了一个新类型（对 C++ 来说是新的），称为 bool。以开发逻辑定律数学表示的英国数学家 George Boole 的名字命名。在计算中，布尔变量是其值可以为真或假的变量。在 C++ 中，像 C 一样，一直没有布尔类型。相反，正如你在第 5 章和第 6 章中会看到更详细的内容，C++ 将非零解释为真，将零解释为假。现在，你可以使用 bool 类型来表示真和假，并且预定义的 true 和 false 表示这些值。也就是说，你可以写出如下语句：

```cpp
bool is_ready = true;
```

字面量 true 和 false 可以通过提升转换为 int，其中 true 转换为 1，false 转换为 0：

```cpp
int ans = true; // ans assigned 1
int promise = false; // promise assigned 0
```

任何数值或指针值都可以隐式转换（即无需显式类型转换）。任何非零值转换为 true，而零值转换为 false：

```cpp
bool start = -100; // start assigned true
bool stop = 0; // stop assigned false
```

在本书介绍语句（第 6 章“分支语句和逻辑运算符”）之后，bool 类型将成为示例中的常见特性。

# const 限定符

现在让我们回到常量符号名的主题。符号名可以暗示常量所代表的内容。如果程序在多个地方使用该常量，你需要更改值，只需更改单个符号定义即可。本章前面提到的 #define 语句（参见侧边栏“符号常量预处理器方式”）表明 C++ 有更好的处理常量的方法。这种方法就是使用 const 限定符。它告诉编译器该变量在初始化后不能被修改。如果程序在多个地方使用该常量，你需要更改值，只需更改单个符号定义即可。这种方法就是使用 const 限定符。它告诉编译器该变量在初始化后不能被修改。如果程序在多个地方使用该常量，你需要更改值，只需更改单个符号定义即可。这种方法就是使用 const 限定符。它告诉编译器该变量在初始化后不能被修改。假设，例如，

```cpp
const int Months = 12;
```

如果你尝试更改值，编译器会生成错误。这确保了常量在程序执行期间永远不会被意外更改。
