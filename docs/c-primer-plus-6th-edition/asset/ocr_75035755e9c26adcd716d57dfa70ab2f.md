The class aspect means that to use vararray objects, you need to know something
about class constructors and other methods. Here are several examples that you use some
of the constructors:

```
double gpa[5] = {3.1, 3.5, 3.8, 2.9, 3.3};
vararray<double> v1; // an array of double, size 0
vararray<int> v2(8); // an array of 8 elements
vararray<int> v3(10,8); // an array of 8 elements, each set to 10
```

```
vararray<double> v4(gpa,4); // an array of 4 elements

```

As you can see, you can create an array of zero size, an empty array of a given

the values from an ordinary array. With C++11, you can also use an initializer list:

```
vararray<int> v5 = {20, 32, 17, 9}; // C++11
```

- The max() method returns the largest element.
