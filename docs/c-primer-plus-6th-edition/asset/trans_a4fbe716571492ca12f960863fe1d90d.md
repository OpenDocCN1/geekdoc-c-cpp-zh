

# 尾随返回类型

C++11 引入了一种新的函数声明语法，其中返回类型放在函数名和参数列表之后，而不是之前：

```
double f1(double, int);               // 传统语法
auto f2(double, int) -> double;      // 新语法，返回类型为 double
```

对于通常的函数声明来说，新语法看起来像是可读性的倒退，但它确实使得可以使用 decltype 来指定模板函数类型成为可能：

```
template<typename T, typename U>
auto eff(T t, U u) -> decltype(T * U)
{
}
```

所解决的问题是，T 和 U 在编译器读取 eff 参数列表之前不在作用域内，因此任何对 decltype 的使用都必须放在参数列表之后。新语法使得这成为可能。

# 模板别名：using =

能够为长或复杂的类型标识符创建别名非常方便。C++ 已经为此目的提供了 typedef：

```
typedef std::vector<std::string>::iterator itType;
```

C++11 提供了创建别名的第二种语法：

```
using itType = std::vector<std::string>::iterator;
```

区别在于新语法可用于部分模板特化，而 typedef 不能：

```
template<typename T>
using arr12 = std::array<T,12>;      // 用于多个别名的模板
```

此语句通过将 int 参数设置为 12 来特化 array<T,int> 模板。例如，考虑以下声明：

```
std::array<double, 12> a1;
std::array<std::string, 12> a2;
```

它们可以用以下内容替换：

```
arr12<double> a1;
arr12<std::string> a2;
```

# nullptr

空指针是指保证不指向有效数据的指针。传统上，C++ 在源代码中使用 0 来表示此指针，尽管内部表示可能不同。这会带来一些问题，因为它使 0 既是指针常量也是整数常量。如第 12 章“类与动态内存分配”中所讨论的，C++11 引入了关键字 nullptr 来表示空指针；它是一种指针类型，不能转换为整数类型。为保持向后兼容，C++ 仍然允许使用 0，并且表达式 nullptr == 0 的求值为 true，但使用 nullptr 提供了更好的类型安全性。例如，值 0 可以传递给接受 int 参数的函数，但编译器会将尝试向此类函数传递 nullptr 视为错误。因此，为了清晰和增加安全性，如果你的编译器接受，请使用 nullptr。

# 智能指针

使用 new 从堆或自由存储区分配内存的程序在不再需要内存时应使用 delete。早期，C++ 引入了 auto_ptr 智能指针来帮助自动化该过程。随后的编程经验，特别是与 STL 的经验表明，需要更复杂的东西。在程序员的经验和 BOOST 库提供的解决方案的指导下，C++11 弃用了 auto_ptr 并引入了三种新的智能指针类型：unique_ptr、shared_ptr 和 weak_ptr。第 16 章讨论了第一个。

新的智能指针设计为可与 STL 容器和移动语义一起使用。

# 异常规范更改

C++ 提供了指定函数可能抛出的异常（如果有）的语法：

```
void f501(int) throw(bad_dog);      // 可以抛出 bad_dog 异常
void f733(long long) throw();       // 不抛出异常
```

通过经验，C++ 编程社区的集体经验是，实践中异常规范并未按预期工作。因此，C++11 标准弃用了异常规范。然而，委员会认为记录函数不抛出异常具有一定的价值，并添加了 noexcept 关键字

```
void f875(short, short) noexcept; // 不抛出异常
```

# 作用域枚举

传统的 C++ 枚举提供了一种创建命名常量的方法。然而，它们的类型检查水平相当低。枚举名称的作用域是包含枚举定义的范围，这意味着在同一作用域中定义的两个枚举不能具有同名的枚举成员。最后，枚举可能无法完全移植，因为不同的实现可能会选择不同的底层类型。C++11 引入了一种枚举变体来解决这些问题。新形式通过在定义中使用 class 或 struct 来表示：

```
enum Oldi {yes, no, maybe}; // 传统形式
enum class New {never, sometimes, often, always}; // 新形式
enum struct New2 {never, lever, never}; // 新形式
```

新形式通过要求显式作用域来避免冲突。因此，你将使用 New::never 和 New2:: 来标识那些特定的枚举。第 10 章“对象与类”提供了更多细节。

# 显式转换运算符

在 C++ 早期的令人兴奋的特性之一是为类建立自动转换的简易性。随着经验的积累，人们认识到自动类型转换可能导致意外的转换问题。C++ 通过引入关键字 explicit 来抑制由单参数构造函数引发的自动转换来解决问题的某一方面：

```
class Plebe {
    Plebe(int); // 自动 int 到 plebe 转换
    explicit Plebe(double); // 需要显式使用
    ...
};
```

```
Plebe a, b;
a = 5; // 隐式转换，调用 Plebe(5)
b = 0.5; // 不允许
b = Plebe(0.5); // 显式转换
```

C++11 扩展了 explicit 的使用，使转换函数也能类似地处理：

```
class Plebe {
    // 转换函数
    operator int() const;
    explicit operator double() const;
    ...
};
```

```
Plebe a, b;
int n = a; // int-Plebe 自动转换
double x = b; // 不允许
x = double(b); // 显式转换，允许
```

# 成员类内初始化

许多 C++ 初学者曾想知道为什么他们不能简单地通过在类定义中提供值来初始化成员。现在他们可以了。语法如下所示：

```
class Session
{
    int mem1 = 10; // 类内初始化
    double mem2{1966.54}; // 类内初始化
    short mem3;
public:
    Session() // #1
    Session(short s) : mem3(s) // #2
    Session(int n, double d, short s) : mem1(n), mem2(d), mem3(s) {} // #3
};
```

你可以使用等号或初始化的大括号为前两个构造函数提供值，但不能使用括号大小的版本。结果与为 mem1 和 mem2 提供成员初始化列表条目相同。

注意，使用类内初始化避免了在构造函数中重复代码，减少了工作量和程序员出错和无聊的机会。

这些默认值会被在成员初始化列表中提供值的构造函数覆盖，因此第三个构造函数会覆盖类内成员初始化。

# 基于范围的 for 循环

基于范围的 for 循环简化了为内置数组和具有 begin() 和 end() 方法来标识范围的类（例如 std::string 和 STL 容器）编写循环。循环对数组或容器中的每个元素应用指示的操作：

```
double prices[5] = {4.99, 10.99, 6.87, 7.99, 8.49};
for (double x : prices)
    std::cout << x << std::endl;
```

这里，x 采用 prices 中每个元素的值。x 的类型应与数组元素的类型匹配。更简单和更安全的方法是使用 auto 声明 x；编译器将从 prices 声明中的信息推导出类型：

```
double prices[5] = {4.99, 10.99, 6.87, 7.99, 8.49};
for (auto x : prices)
    std::cout << x << std::endl;
```

如果你想修改数组或容器的元素，请使用引用类型：

```
std::vector<int> vi(6);
for (auto &x : vi)    // 如果循环改变内容则使用引用
    x = std::rand();
```

# 新的 STL 容器

C++11 将 forward_list、unordered_map、unordered_multimap、unordered_set 和 unordered_multiset 添加到其 STL 容器集合中。forward_list 是一个单向链表，只能单向遍历；它比双向链表容器更简单、更经济。其他四个容器支持哈希表。

C++11 还添加了 array 模板，其中指定一种类型和固定数量的元素：

```
array<int,360> ar;    // 包含 360 个 int 的数组
```

此模板类不满足所有模板要求。例如，由于大小固定，你不能使用任何改变容器大小的方法，例如 push_back()。但 array 确实具有 begin() 和 end() 方法，这使你能够使用许多基于范围的 STL 算法与 array 对象。
