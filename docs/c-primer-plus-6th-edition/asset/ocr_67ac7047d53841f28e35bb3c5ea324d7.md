+   * You can use cin with the >> operator to read a variety of data types.
* You can use cin with the get() method to read individual characters and with the getline() method to read a line of characters at a time.
* You can use cin with methods such as eof() and fail() to monitor the success of an input attempt.
* The object itself, when used as a test condition, is converted to the Boolean value true if the last read succeeded and to false otherwise.

File input parallels this very closely:

+   * You must include the fstream header.
* The fstream header defines an istream class for handling input.
* You need to declare one or more istream variables, or objects, which you can name as you please, as long as you respect the usual naming conventions.
* You must associate with the std namespace; for example, you can use the direct or the std:: prefix for elements as ifstream.
* You need to associate a specific istream object with a specific file; one way to do so is use the open() method.
* When you're finished with a file, you should use the close() method to close the file.
* You can use an istream object with the >> operator to read a variety of data types.
* You can use an istream object with the get() method to read individual characters and with the getline() method to read a line of characters at a time.
* You can use an istream object with methods such as eof() and fail() to monitor the success of an input attempt.
* An istream object itself, when used as a test condition, is converted to the Boolean value true if the last read succeeded and to false otherwise.

Note that the istream header file provides a predefined istream object called cin, you can declare your own istream object, choosing a name for it and associating it with a file. Here's how you could declare such objects:

```
ifstream inFile;           // inFile an istream object
ofstream fin;               // fin an istream object
```

Here's how you can associate with particular files:

```
inFile.open("bowling.txt");   // inFile used to read bowling.txt file
char filename[50];
cin >> filename;               // user specifies a name
fin.open(filename);             // fin used to read specified file
```

Note that the open() method requires a C-style string as its argument. This can be a literal string or a string stored in an array.
