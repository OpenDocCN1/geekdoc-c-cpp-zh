## 使用 new 和 delete 的示例

让我们看一个 new 和 delete 如何管理从键盘输入的字符串的例子。清单 4.22 定义了一个函数 getname()，它返回指向输入字符串的指针。该函数将输入读入一个临时数组，然后使用 [] 和适当的尺寸创建一个大小足以容纳输入字符串的内存块。该函数返回指向该块的指针。这种方法可以为运行大量字符串的程序节省大量内存。在现实生活中，当我们中的许多人生活时，使用 string 类会更容易，该类在其设计中内置了 new 和 delete 的使用。

假设你的程序必须读取 1,000 个字符串，并且最长的字符串可能长达 79 个字符，但大多数字符串比这短得多。如果你使用 char 数组来保存字符串，你就需要 1,000 个每个 80 个字符的数组。那就是 80,000 字节，其中很大一部分内存将未被使用。或者，你可以创建一个包含 1,000 个指向 char 的指针的数组，然后使用 new 只为每个字符串分配所需的内存量。这可以节省数万字节。不是为每个字符串使用一个数组，你就可以使内存适合输入。更好的是，你也可以使用 new 来找到存储所需指针数量的空间。嗯，这对现在来说有点太雄心勃勃了。现在使用 1,000 个指针的数组也有点太雄心勃勃了，清单 4.22 说明了一些技术。此外，为了说明 delete 的工作原理，程序使用它来释放内存以便重用。

## 指针、数组和指针算术

清单 4.22 delete.cpp

```cpp
// delete.cpp -- using the delete operator
#include <iostream>
#include <cstring> // or string.h
using namespace std;
char * getname(void); // function prototype
int main() {
    char * name; // create pointer but no storage

    name = getname(); // assign address of string to name
    cout << name << " at " << (int *) name << "\n";
    delete [name]; // memory freed

    name = getname(); // reuse freed memory
    cout << name << " at " << (int *) name << "\n";
    delete [name]; // memory freed again
    return 0;
}

char * getname() // return pointer to new string
{
    char temp[80]; // temporary storage
    cout << "Enter last name: ";
    cin >> temp;
    char * pn = new char[strlen(temp) + 1];
    strcpy(pn, temp); // copy string into smaller space

    return pn; // temp lost when function ends
}
```

以下是清单 4.22 中程序的示例运行：
Enter last name: Fredeldumpkin
Fredeldumpkin at 0x004326b8
Enter last name: Pook
Pook at 0x004301c8

## 程序说明

考虑清单 4.22 中程序中的函数 getname()。它使用 cin 将输入的单词放入 temp 数组中。接下来，它使用 new 分配内存来保存该单词。包括空字符，程序需要 strlen(temp) + 1 个字符来存储字符串，所以这是提供给 new 的值。空间可用后，getname() 使用标准库函数 strcpy() 将字符串从 temp 复制到新块中。该函数不检查字符串是否合适，但 getname() 通过使用 new 请求正确的字节数来覆盖。最后，函数返回 pn，即字符串副本的地址。

在 main() 中，返回值（地址）被赋给指针 name。该指针指向在 getname() 函数中分配的内存块——在 main() 中定义，但程序打印字符串和字符串的地址。

接下来，在释放 name 指向的块之后，main() 第二次调用 getname()。C++ 不保证新释放的内存会在下次使用内存时首先被选中，在此示例运行中并非如此。

请注意 getname() 分配内存而 main() 释放它。通常不是一个好主意将 new 和 delete 放在不同的函数中，因为这样更容易忘记使用 delete。
