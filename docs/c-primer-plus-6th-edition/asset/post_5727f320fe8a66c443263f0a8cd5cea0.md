
# The string Class

Table 16.1 string Class Constructors

| Constructor | Description |
| --- | --- |
| string() | Creates a default string object of 0 size (default constructor). |
| string (const char * s, size_type n) | Initializes a string object to the NTS pointed to by s and continues for n characters, even if it exceeds the size of the NTS. |
| template<class Iter> string(Iter begin, Iter end) | Initializes a string object to the values in the range [begin, end), where begin and end act like pointers and specify locations; the range includes begin and is up to not including end. |
| string(const string &str, size_type pos, size_type n = npos) | Initializes a string object to the str, starting at position pos in str and going to the end of str or using n characters, whichever comes first. |
| string(&& str) noexcept (C++11) | Initializes a string object to the string object str; str may be altered (move constructor). |
| string(initializer_list<char> il) (C++11) | Initializes a string object to the characters in the initializer list il. |

## Program Notes

The start of the C-style string in Listing 16.1 illustrates that you can initialize a string to a regular string and display it by using the overloaded << operator:

```
string one("Lottery Winner!"); // ctor #1
cout << one << endl; // overloaded <<
```

The next constructor initializes the string object two to a string consisting of 20 characters:

```
string two(20, '$'); // ctor #2
```

The copy constructor initializes the string object three to the string object:

```
string three(one); // ctor #3
```

The overloaded += operator appends the string " Oops!" to the string one:

```
one += " Oops!"; // overloaded +=
```

This particular example app a C-style string to a string object. However, the += operator is multiply overloaded so that you can also append string objects and single characters:

```
one = two; // append string object (not in program)
one += '!'; // append a type char value (not in program)
```

Similarly, = operator is overloaded so that you can assign a string object to a string, a C-style string to a string object, or a simple char value to a string object:

```
two = "Sorry! That was "; // assign a C-style string
two = one; // assign a string object (not in program)
two = '?'; // assign a char value (not in program)"
```

Overloading the [] operator, as the String example in Chapter 12, permits access to individual characters in a string object by array notation:

```
three[0] = 'P';
```

A default constructor creates an empty string that later be given a value:

```
string four; // ctor #4
four = two + three; // overloaded += =
```

The second line uses the overloaded + to create a temporary string object, which is then assigned, so the overloaded = operator, to the four object. As you might expect, the + operator concatenates its two operands into a single string object. The operator is multiply overloaded, so the second operand can be a string object or a C-style string or a char.

The fifth constructor takes a C-style string and an integer argument, with the integer indicating how many characters to copy:

```
char als[] = "All's well that ends well";
string five(als,20); // ctor #5
```

Here, as output shows, just the first 20 characters "All's well that ends" are used to initialize the five object. As Table 16.1, if the character exceeds the length of the C-style string, the requested number of characters is still copied. Replacing 20 with 40 in the preceding example would result in 15 characters being copied at the end of five. (That is, the constructor would interpret the contents in memory following the string "All's well that ends well" as char characters.

The sixth constructor has a template argument:

```
template<class Iter> string(Iter, Iter);
```

The intent is that begin and end act like pointers to two locations in memory. (In general, begin and end can be iterators, generalizations of pointers extensively used in the STL.) The constructor then uses the values between the locations pointed to initialize the string object. The notation [begin, end), borrowed from mathematics, means the range begin but doesn't include end.

Now you use this constructor to initialize an object to part of another string object—say, the object five. The following does not work:

```
string seven(five + 6, five + 10);
```

The reason is that the name of an object, unlike the name of an array, is not treated as the address of object, hence five is not a pointer and five + 6 is meaningless. However, five [6] is a char value, so &five [6] is an address and can be used as an argument to the constructor:

```
string seven(&five[6], &five[10]);// ctor #6 again
```

The seventh constructor copies a portion of one string object to the constructed object:

```
string eight(four, 7, 16); // ctor #7
```

This statement creates 16 constructors from four to eight, starting at position 7 (the eighth character) in four

## C++11 Constructors

The string (string && str) noexcept is similar to the copy constructor in that the new string is a copy of str. However, unlike the copy constructor, it doesn't guarantee that str will be treated as const. This form of constructor is termed a move constructor. The compiler can use it in some situations instead of the copy constructor to

optimize performance. Chapter 18, "Visiting with the New C++ Standard," discusses this topic in the section "Move Semantics and the rvalue Reference."

The string(initializer_list<char>) constructor enables initialization of the string class. That is, it makes declarations like the following:

```
string piano_man = {'L', 'i', 'g', 'z', 't'};
string comp_lang = {'L', 'i', 's', 'p'};
```

This may not be useful for the string class because using C-style strings is easier, but it does satisfy the intent to make the list-initialization syntax universal.This chapter will discuss the initializer_list template later on.

## The string Class Input

Another useful thing to know about class is what inputs are available. For C-style strings, recall, you have three options:

```
char info[100]; // read a word
cin >> info;
cin.getline(info, 100); // read a line, discard 

cin.get(info, 100); // read a line, leave \n in queue
```

For string objects, recall, you have two options:

```
string stuff; // read a word
cin >> stuff;
getline(cin, stuff); // read a line, discard \n
```

Both versions of getline() allow for an optional argument that specifies which character to delete input:

```
cin.getline(info, 100, ':'); // read up to :, discard :
getline(stuff, ':'); // read up to :, discard :
```

The main operational difference is that the string versions automatically size the string object to hold the input characters:

```
char fname[10];
string fname;
cin >> fname; // could be a problem if input size > 9 characters
cin >> fname; // can read a ver, very long word
cin.getline(fname, 10); // may truncate input
getline(cin, fname); // no truncation
```

The automatic sizing feature allows the string version of getline() to dispense with the numeric parameter that limits the number of characters to be read.

A design difference is that the C-style string input facilities are methods of the istream class, whereas the string versions are standalone functions.That's why cin is an invoking object for C-style string input and a function argument for string object input.
