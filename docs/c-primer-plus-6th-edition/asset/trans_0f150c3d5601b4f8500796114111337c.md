# 表达式中的转换

考虑当你在同一个表达式中组合两种不同的算术类型时会发生什么。 C++ 在这种情况下会进行两种自动转换。 首先，一些类型在出现时会自动转换。 一些类型在与表达式中的其他类型组合时会被转换。

首先，让我们检查自动转换。 在求值时，C++ 将 bool、unsigned char、signed char 和 short 值转换为 int。 特别是，true 被提升为 1，false 被提升为 0。 这些转换是整型提升。 例如，考虑以下语句：

```cpp
short chickens = 20; // line 1
short ducks = 35; // line 2
short fowl = chickens + ducks; // line 3
```

要执行第 3 行的语句，C++ 程序会获取 chickens 和 ducks 的值并将两者都转换为 int。 程序将结果转换为 short 类型，因为答案被赋给一个 short 类型变量。 你可能会觉得这有点迂回，但它是有道理的。 int 类型通常被选为计算机最自然的类型，这意味着计算机可能对该类型进行计算最快。

还有更多的整型提升： unsigned short 类型如果 short 比 int 小，则会被转换为 int。 如果两种类型大小相同，则 unsigned short 会被转换为 unsigned short。 同样，wchar_t 会被提升为以下类型中的第一个能够容纳其范围的类型：int、unsigned int、long 或 unsigned long。

# 第 3 章 处理数据

然后是当你算术组合不同类型时发生的转换，例如将 int 加到 float。 当操作涉及两种类型时，较小的会被转换为较大的。 例如，清单 3.11 中的程序将 9.0 除以 5。 因为 9.0 是 double，所以程序在执行除法之前将 5 转换为 double。 更一般地说，编译器会通过一个检查清单来确定算术表达式中进行哪些转换。 C++11 对列表稍作修改。 以下是编译器按顺序遍历的 C++11 版本的列表：

- 1. 如果任一操作数是 long double 类型，则另一个操作数会被转换为 double。
- 2. 否则，如果任一操作数是 double，则另一个操作数会被转换为 double。
- 3. 否则，如果任一操作数是 float，则另一个操作数会被转换为 float。
- 4. 否则，操作数是整数类型，并且会进行整型提升。
- 5. 在这种情况下，如果两个操作数都是有符号的或都是无符号的，并且其中一个的等级低于另一个，则会被转换为较高等级。
- 6. 否则，一个操作数是有符号的，一个是无符号的。 如果无符号操作数的等级高于有符号操作数，则后者会被转换为无符号操作数的类型。
- 7. 否则，如果有符号类型可以表示无符号类型的所有值，则无符号操作数会被转换为有符号类型的类型。
- 8. 否则，两个操作数都会被转换为有符号类型的无符号版本。

ANSI 遵循与 ISO 2003 C++ 相同的规则，后者与前述规则略有不同，而 K&R C 的规则略有不同。 例如，经典 C 总是将 float 提升为 double，即使两个操作数都是 float。

该列表引入了整数类型的等级概念。 简而言之，正如你可能预期的那样，有符号整数类型的最佳等级从高到低为 long、long、int、short 和 signed char。 无符号类型具有与相应有符号类型相同的等级。 三个字符 char、signed char 和 unsigned 具有相同的等级。 bool 类型具有最低等级。 wchar_t、char16_t 和 char32_t 具有与其底层类型相同的类型。

# 传递参数时的转换

通常，C++ 函数原型控制传递参数时的转换，正如你在第 7 章“函数：C++ 编程语言”中所学的那样。 然而，放弃原型控制以传递参数是可能的，尽管不明智。 在这种情况下，C++ 会对 char 和 short 类型（有符号和无符号）应用整型提升。 此外，为了与经典 C 中大量代码保持兼容，C++ 会将 float 参数提升为 double，当传递给放弃原型的函数时。

# 类型转换

C++ 使你能够通过类型转换机制显式强制类型转换。 （C++ 认识到类型规则的必要性，也认识到偶尔需要覆盖这些规则的必要性）。 类型转换有两种形式。 例如，要将存储在名为 thorn 的变量中的 int 值转换为 long 类型，你可以使用以下任一表达式：

- (long) thorn // 返回 thorn 的 long 类型转换
- long (thorn) // 返回 thorn 的 long 类型转换

类型转换不会改变 thorn 本身； 相反，它会创建一个指示类型的新值，然后你可以在表达式中使用它，如下所示：
`cout << int('Q'); // displays the integer code for 'Q'`

更一般地说，你可以执行以下操作：

- (typename) value // 将 value 转换为 typeName
- typeName (value) // 将 value 转换为 typeName

第一个是标准的 C。 第二个是纯 C++。 新形式背后的想法是使类型转换看起来像一个函数。 这使得内置类型的类型转换与你为用户定义类设计的类型转换类似。

C++ 还引入了四种类型转换运算符，它们在如何使用上更具限制性。 第 15 章“友元、异常等”涵盖了它们。 在这四种中，static_cast<> 运算符可用于转换。

# 第 3 章 处理数据

清单 3.14 typecast.cpp

```cpp
// typecast.cpp -- forcing type changes
#include <iostream>
int main() {

    using namespace std;
    int auks, bats, costs;

    // the following statement adds values as double,
    // then converts the result to int
    auks = 19.99 + 11.99;

    // these statements add values as int
    bats = (int) 19.99 + (int) 11.99; // old C syntax
    costs = 19.99 + 11.99; // new C++ syntax
    cout << "auks = " << auks << ", bats = " << bats << ";\n";
    cout << "costs = " << costs << endl;

    char ch = 'Z';
    cout << "The code for " << ch << " is: " // print as char
    cout << (int)ch << endl; // print as int
    cout << "Yes, the code is: " << endl;
    cout << static_cast<int>(ch) << endl; // using static_cast
    return 0;
}
```

以下是清单 3.14 程序的结果：
auks = 31, bats = 30, costs = 30
The code for Z is 90
Yes, the code is 90

首先，19.99 到 11.99 得到 31.98。 当此值被赋给 int 变量时，它会被截断为 31。 但使用类型转换会先将两个值截断为 19 和 11，然后再相加，使得 bats 和 costs 均为 30。 然后两个语句使用类型转换将 char 类型值转换为 int，然后再显示结果。 这些转换使用 cout 将值作为整数打印，而不是作为字符。 该程序说明了使用类型转换的两个原因。 首先，你可能有存储为 double 类型但用于计算类型值的值。 例如，你可能正在将位置拟合到网格或建模整数值，例如人口、浮点数。 你可能希望计算将这些值视为 int。 类型转换使你能够做到这一点。 请注意，对于这些值，将值转换为 int 再相加，与先相加再转换为 int 得到的结果不同。
