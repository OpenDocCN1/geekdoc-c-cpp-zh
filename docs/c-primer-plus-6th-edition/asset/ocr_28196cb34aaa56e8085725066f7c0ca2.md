That's because references, like const data, can be initialized only when created. For simple data members, as front and items, it doesn't make much difference whether you use a member initializer list or use assignment in the function body. As you'll see in Chapter 14, it's more efficient to use the member initializer list for members that are themselves class objects.

# The Member Initializer List Syntax

If Class is a class and if mem1, mem2, and mem3 are class data members, a class construc-or use the following syntax to initialize the data members:

```
Classy::Classy(int n, int m) :mem1(n), mem2(0), mem3(n*m + 2)
{
  //...
}
```

This initializes mem1 to n, mem2 to 0, and mem3 to n*m + 2. Conceptually, these initialization-tions take place when the object is created and any code within the brackets is exe-cuted. Note the following:

+   * This form can be used only with constructors.
* You must (at least, in-C++11) use this form to initialize a nonstatic const data member.
* You must use this form to initialize a reference data member.

Data members are initialized in the order in which they appear in the class declaration, not in the order in which initializers are listed.

# Caution

You can't use the member initializer list syntax with class methods other than constructors.

The parenthesized form used in the member initializer list can be used in ordinary ini-ializations, too. That is, if you like, you can replace code such as

```
int games = 162;
double talk = 2.71828;
with
 games(162);
double talk(2.71828);
```

This allows initializing built-in types to look like initializing class objects.
