# Things to Do to Vectors

Besides allocating storage, what else can the vector template do for you? All the STL
containers provide certain basic methods, including size(), which returns the number of\lements in a container, swap(), which exchanges the contents of two containers,
begin(), which returns an iterator that refers to the first element in a container, and
end(), which returns an iterator that represents the past-end-for-the container.
What is an iterator? It's a generalization of a pointer. In fact, it can be a pointer. Or it
be an object for pointer-like operations such as dereferencing (for example,
operator*) and incrementing (for example, operator++()) have been defined.
You'll see later, generalizing pointers to iterators allows the STL to provide a uniform
interface for a variety of container classes, including ones for which simple pointers
n't work. Each container class defines a suitable iterator. The type name for this iter-
tator is a class scope typedef iterator. For example, to declare an iterator for a
type double<vector<double>>, you would use this:

```
vector<double>::iterator pd; // pd an iterator
```

Suppose scores is a vector<double> object:

```
vector<double> scores;
```
