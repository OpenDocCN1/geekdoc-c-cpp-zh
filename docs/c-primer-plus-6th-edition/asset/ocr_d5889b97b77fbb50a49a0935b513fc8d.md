# Friend or No Friend?

The time class declaration makes the operator<< function a friend to the Time class. But this function, although not longterm to the ostream class, is not a friend to that class. The operator<<() function takes an ostream argument and a Time argument, so it might seem that this function has to be a friend to both classes. If you look at the code for the function, you'll notice the function accesses individual members of the Time object but only the ostream object as a whole. Because operator<<() accesses private Time members, it has to be a friend to the Time class. Because it does not directly access ostream members, the function does not have to be a friend to the ostream class. That's why it means you don't have to tinker with the ostream definition.

Note that the new operator<<() definition uses the ostream reference or as it does in the expression cout << trip. But you could use the operator with other ostream objects, in which case you would refer to those objects.

# What? You Don't Know of Any Other ostream Objects?

Another ostream is cerr, which routes output to the standard error stream, which by default, is the display. In Unix, Linux, and the Windows Command Line environment you can redirect the standard error to a file. Remember that Chapter 6, "Branching States and Logical Operators," introduces ostream objects, which can be used to output to a file. Through the magic of inheritance (see Chapter 13, "Class Inheritance"), ostream objects can use ostream methods. Thus you can use the operator<<() to write time data to files as well as to the screen. You just pass a suitably initialized of object instead of cout as the first argument.

The call << trip should use the cout object itself, not a copy, so the function passes the argument as a reference instead of value. Thus, the expression cout << trip causes os to be an alias for cout, and the expression cerr << trip causes to be an alias for cerr. The Time object can be passed by value or by reference because either form makes the object values available to the function. Again, passing by reference uses memory and time than passing by value.
