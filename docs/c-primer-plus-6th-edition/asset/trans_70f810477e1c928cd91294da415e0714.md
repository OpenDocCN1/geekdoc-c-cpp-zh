

# string 类

表 16.1 string 类构造函数

| 构造函数 | 描述 |
| --- | --- |
| string() | 创建一个大小为 0 的默认字符串对象（默认构造函数）。 |
| string (const char * s, size_type n) | 将字符串对象初始化为 s 所指向的 NTS，并继续 n 个字符，即使它超过了 NTS 的大小。 |
| template<class Iter> string(Iter begin, Iter end) | 将字符串对象初始化为范围 [begin, end) 中的值，其中 begin 和 end 像指针一样起作用并指定位置；该范围包括 begin 且不包括 end。 |
| string(const string &str, size_type pos, size_type n = npos) | 将字符串对象初始化为 str，从 str 中的位置 pos 开始并持续到 str 的末尾或使用 n 个字符，以先到者为准。 |
| string(&& str) noexcept (C++11) | 将字符串对象初始化为字符串对象 str；str 可能会被更改（移动构造函数）。 |
| string(initializer_list<char> il) (C++11) | 将字符串对象初始化为初始化列表 il 中的字符。 |

清单 16.1 str.cpp

```
// strl.cpp -- introducing the string class
#include <iostream>
#include <string>
// using string constructors

int main()
{
    using namespace std;
    string one("Lottery Winner!"); // ctor #1
    cout << one << endl; // overloaded <<
    string two(20, '$'); // ctor #2
    cout << two << endl;
    string three(one); // ctor #3
    cout << three << endl;
    one += " Oops!"; // overloaded +=
    cout << one << endl;
    two = "Sorry! That was ";
    three[0] = 'p';
    string four; // ctor #4
    four = two + three; // overloaded += =
    cout << four << endl;
    char all[20] = "All's well that ends well";
    string five(alls,20); // ctor #5
    cout << five << "!\n";
    string six(alls+6, all + 10); // ctor #6
    cout << six << " ";
    string seven(&five[6], &five[10]); // ctor #6
    cout << seven << "...\n";
    string eight(four, 16); // ctor #7
    cout << eight << " in motion!" << endl;
    return 0;
}
```

清单 16.1 中的程序使用了重载的 += 运算符，它将一个字符串附加到另一个字符串，重载的 = 运算符用于将一个字符串赋给另一个字符串，重载的 [] 运算符用于访问字符串中的单个字符。

well,...

## 程序说明

清单 16.1 中 C 风格字符串的开头说明了你可以通过使用重载的 << 运算符将字符串初始化为常规字符串并显示它：

```
string one("Lottery Winner!"); // ctor #1
cout << one << endl; // overloaded <<
```

下一个构造函数将字符串对象 two 初始化为由 20 个字符组成的字符串：

```
string two(20, '$'); // ctor #2
```

拷贝构造函数将字符串对象 three 初始化为字符串对象：

```
string three(one); // ctor #3
```

重载的 += 运算符将字符串 " Oops!" 附加到字符串 one：

```
one += " Oops!"; // overloaded +=
```

这个特定示例将 C 风格字符串附加到字符串对象。然而，+= 运算符是多次重载的，因此你也可以附加字符串对象和单个字符：

```
one = two; // append string object (not in program)
one += '!'; // append a type char value (not in program)
```

同样，= 运算符被重载，以便你可以将字符串对象赋给字符串，将 C 风格字符串赋给字符串对象，或将简单的 char 值赋给字符串对象：

```
two = "Sorry! That was "; // assign a C-style string
two = one; // assign a string object (not in program)
two = '?'; // assign a char value (not in program)"
```

重载 [] 运算符，如第 12 章中的 String 示例，允许通过数组表示法访问字符串对象中的单个字符：

```
three[0] = 'P';
```

默认构造函数创建一个稍后可以赋值的空字符串：

```
string four; // ctor #4
four = two + three; // overloaded += =
```

第二行使用重载的 + 创建一个临时的字符串对象，然后将其赋给 four 对象，即重载的 = 运算符。正如你可能预期的那样，+ 运算符将其两个操作数连接成一个单一的字符串对象。该运算符是多次重载的，因此第二个操作数可以是字符串对象或 C 风格字符串或 char。

第五个构造函数接受一个 C 风格字符串和一个整数参数，整数指示要复制的字符数：

```
char als[] = "All's well that ends well";
string five(als,20); // ctor #5
```

这里，正如输出所示，仅使用前 20 个字符 "All's well that ends" 来初始化 five 对象。如表 16.1 所示，如果字符超过 C 风格字符串的长度，仍会复制所请求数量的字符。将前面的示例中的 20 替换为 40 将导致在 five 的末尾复制 15 个字符。（也就是说，构造函数会将字符串 "All's well that ends well" 之后内存中的内容解释为 char 字符。

第六个构造函数有一个模板参数：

```
template<class Iter> string(Iter, Iter);
```

其意图是 begin 和 end 像指向内存中两个位置的指针一样起作用。（通常，begin 和 end 可以是迭代器，STL 中广泛使用的指针的泛化。）构造函数然后使用位置之间指向的值来初始化字符串对象。符号 [begin, end)，借用自数学，表示范围 begin 但不包括 end。

现在你使用此构造函数将对象初始化为另一个字符串对象的部分——例如对象 five。以下不起作用：

```
string seven(five + 6, five + 10);
```

原因是对象的名称与数组的名称不同，不被视为对象的地址，因此 five 不是指针，five + 6 无意义。然而，five [6] 是一个 char 值，因此 &five [6] 是一个地址，可以用作构造函数的参数：

```
string seven(&five[6], &five[10]);// ctor #6 again
```

第七个构造函数将一个字符串对象的一部分复制到构造的对象中：

```
string eight(four, 7, 16); // ctor #7
```

此语句从 four 中位置 7（four 的第八个字符）开始创建 16 个构造函数到 eight

## C++11 构造函数

string (string && str) noexcept 与拷贝构造函数类似，因为新字符串是 str 的拷贝。然而，与拷贝构造函数不同，它不保证 str 将被视为 const。这种形式的构造函数称为移动构造函数。编译器可以在某些情况下使用它而不是拷贝构造函数来优化性能。第 18 章“与新 C++ 标准会面”在“移动语义和右值引用”部分讨论了这个主题。

string(initializer_list<char>) 构造函数使字符串类的初始化成为可能。也就是说，它使以下声明成为可能：

```
string piano_man = {'L', 'i', 'g', 'z', 't'};
string comp_lang = {'L', 'i', 's', 'p'};
```

这对于 string 类可能没有用，因为使用 C 风格字符串更容易，但它确实满足了使列表初始化语法通用的意图。本章稍后将讨论 initializer_list 模板。

## string 类输入

关于类可用的输入，知道另一件有用的事情。对于 C 风格字符串，回忆一下，你有三个选项：

```
char info[100]; // read a word
cin >> info;
cin.getline(info, 100); // read a line, discard 

cin.get(info, 100); // read a line, leave \n in queue
```

对于字符串对象，回忆一下，你有两个选项：

```
string stuff; // read a word
cin >> stuff;
getline(cin, stuff); // read a line, discard \n
```

getline() 的两个版本都允许一个可选参数来指定要删除的输入字符：

```
cin.getline(info, 100, ':'); // read up to :, discard :
getline(stuff, ':'); // read up to :, discard :
```

主要的操作区别是字符串版本会自动调整字符串对象大小以容纳输入字符：

```
char fname[10];
string fname;
cin >> fname; // could be a problem if input size > 9 characters
cin >> fname; // can read a ver, very long word
cin.getline(fname, 10); // may truncate input
getline(cin, fname); // no truncation
```

自动调整大小功能使字符串版本的 getline() 能够省去限制要读取字符数的数字参数。

设计上的区别是 C 风格字符串输入设施是 istream 类的方法，而字符串版本是独立的函数。这就是为什么 cin 是 C 风格字符串输入的调用对象，而对于字符串对象输入则是函数参数。这也适用于 >> 形式，如果代码以函数形式编写则很明显：
