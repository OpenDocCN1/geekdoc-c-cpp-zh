Figure 15.3 throw versus return.

After the code responds by displaying messages, it rethrows the exception, which means, in this case, sending the exception up to main(). (In general, a rethrown exception rises to the next try-catch combination that catches that particular type of exception. If no handler is found, by default, aborts.)
