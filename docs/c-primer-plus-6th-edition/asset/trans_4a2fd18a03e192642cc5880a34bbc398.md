

# 函数指针

声明需要 *pf 周围的括号以提供正确的运算符优先级。括号的优先级高于 * 运算符，*pf(int) 表示 pf() 是一个返回指针的函数，而 (*pf)(int) 表示 pf 是一个指向函数的指针：

```
double (*pf)(int); // pf points to a function that returns double
double *pf(int);    // pf() is a function that returns a pointer-to-double
```

在正确声明 pf 之后，你可以将它赋值为匹配函数的地址：

```
double pam(int);
double (*pf)(int);
// pf now points to the pam() function
pf = pam;
```

注意 pam() 在签名和返回类型上都与 pf 匹配。编译器会拒绝不匹配的赋值：

```
double ned(double);
int ted(int);
double (*pf)(int);
pf = ned;    // invalid -- mismatched signature
pf = ted;     // invalid -- mismatched types
```

让我们回到前面提到的 estimate() 函数。假设你想传递要编写的代码行数以及估计算法的地址，例如 pam() 函数。它可以具有以下原型：
void estimate(int lines, double (*pf)(int));

该声明表示第二个参数是指向一个具有 int 参数和 double 返回值的函数的指针。要让 estimate() 使用 pam() 函数，你将传递 pam() 的地址给它：
estimate(50, pam); // function call estimate() to use pam()

很明显，使用函数指针的棘手部分在于编写原型，而地址则非常简单。

## 使用指针调用函数

现在我们进入该技术的最后一部分，即使用指针调用指向的函数。线索在指针声明中。在那里，回忆一下，(*pf) 扮演的角色与函数名相同。因此，你所要做的就是像使用函数名一样使用 (*pf)：

```
double pam(int);
double (*pf)(int);
// pf now points to the pam() function
pf = pam;
double x = pam(4); // call pam() using the function name
double y = (*pf)(5); // call pam() using the function pointer
```

实际上，C++ 也允许你像使用函数名一样使用 pf：

```
double y = pf(5);    // also call pam() using the pointer pf
```

使用第一种形式更丑陋，但它提供了强烈的视觉提醒，代码正在使用函数指针。

> 历史与逻辑
神圣的语法！pf 和 (*pf) 如何等价？一派观点认为，因为 pf 是指向函数的指针，所以 *pf 是一个函数；因此，你应该使用 (*pf)() 作为函数调用。第二派观点认为，函数的名称是指向该函数的指针，指向函数的指针会像函数名一样起作用；因此你应该使用 pf() 作为函数调用。C++ 采取折中观点，认为两种形式都是正确的，或者至少是允许的，即使它们在逻辑上彼此不一致。在你过于严厉地评判这种妥协之前，请反思，能够持有在逻辑上不一致的观点是人类思维过程的标志。

## 一个函数指针示例

清单 7.18 演示了在程序中使用函数指针。它调用 estimate() 两次，一次传递 betsy() 函数地址，一次传递 pam() 地址。在第一种情况下，estimate() 使用 betsy() 计算所需小时数，在第二种情况下，estimate() 使用 pam() 进行计算。这种设计促进了程序开发。当 Ralph 开发他自己的时间估算算法时，他不必重写 estimate()。相反，他只需要提供自己的 ralph() 函数，确保它具有正确的签名和返回类型。当然，重写 estimate() 并不是一项困难的任务，但同样的原则适用于更复杂的代码。此外，函数方法允许 Ralph 修改 estimate() 的行为，即使他没有访问 estimate() 源代码的权限

清单 7.18 fun_ptr.cpp

```
// fun_ptr.cpp -- pointers to functions
#include <iostream>
double betsy(int);
double pam(int);

// second argument is pointer to a type double function that
// takes a type int argument
void estimate(int lines, double (*pf)(int));

int main()
{
    using namespace std;
    int code;

cout << "How many lines of code do you need? ";
cin >> code;
cout << "Here's Betsy's estimate:\n";
estimate(code, betsy);
cout << "Here's Pam's estimate:\n";
estimate(code, pam);
return 0;
}

double betsy(int lns)
{
  return 0.05 * lns;
}

double pam(int lns)
{
  return 0.03 * lns + 0.0004 * lns * lns;
}

void estimate(int lns, double (*pf)(int))
{
  using namespace std;
  cout << lns << " lines will take ";
cout << (*pf)(lns) << " hour(s)\n";
}
```

以下是清单 7.18 程序的一个示例运行：

How many lines of code do you need? 30
Here's Betsy's estimate:
30 lines will take 1.5 hour(s)
Here's Pam's estimate:
30 lines will take 1.26 hour(s)

以下是该程序的第二个示例运行：

How many lines of code do you need? 100
Here's Betsy's estimate:
100 lines will take 5 hour(s)
Here's Pam's estimate:
100 lines will take 7 hour(s)

## 函数指针主题的变体

使用函数指针时，记号可能会令人望而生畏。让我们看一个示例，说明函数指针的一些挑战以及处理它们的方法。首先，这里是一些共享相同签名和返回类型的函数的原型：

```
const double * f1(const double ar[], int n);
const double * f2(const double [], int n);
const double * f3(const double *, int n);
```

签名看起来可能不同，但它们是相同的。首先，回忆在函数原型参数列表中 const double 和 const double * 具有完全相同的含义。其次，回忆在原型中你可以省略标识符。因此，const double ar[] 可以简化为 const double []，而 const double * ar 可以简化为 const double *。因此，前面显示的所有函数签名具有相同的含义。函数定义另一方面提供了标识符，因此在该上下文中 const ar[] 或 const double * ar 都可以使用。

接下来，假设你希望声明一个可以指向其中一个函数的指针。技术是，如果 pa 是期望的指针，取目标函数的原型并用 (*pa) 替换函数名：

```
const double * (*p1)(const double *, int);
```

这可以与初始化结合：

```
const double * (*p1)(const double *, int) = f1;
```

使用 C++11 自动类型推导，你可以简化为：

```
auto p2 = f2; // C++11 automatic type deduction
```

现在考虑以下语句：

```
cout << (*p1)(av,3) << ": " << (*p1)(av,3) << endl;
cout << p2(av,3) << ": " << *p2(av,3) << endl;
```

两者 (*p1)(av,3) 和 p2(av,3)，回忆一下，调用指向的函数（f1）和 f2()，在这种情况下使用 av 和 3 作为参数。这两个函数的返回值。返回值是 const double *（即值的地址）。因此，每个 cout 表达式的第一部分应打印 double 值的地址。要查看地址处实际存储的值，我们需要对这些地址应用 * 运算符，而表达式 (*p1)(av,3) 和 *p2(av,3) 就是这样做的。

有了三个函数可供使用，使用函数指针数组会很方便。可以通过其指针依次使用每个函数。这会是什么样子？很明显，它看起来会像单个指针的声明，会在某处有一个 [3] 来表示三个指针的数组。问题是放在哪里。这里是答案（初始化）：

```
const double * (*pa[3])(const double *, int) = {f1,f2,f3};
```

为什么是 pa[3]？好吧，pa 是一个包含三个字符串的数组，而声明一个包含三个事物的数组的开始是这样的：pa[3]。声明的其余部分是关于要放入数组中的是什么类型的事物。运算符优先级将 [] 排在 * 之上，因此 pa[3] 表示 pa 是一个包含三个指针的数组。声明的其余部分指示每个指针指向什么：一个具有 const double *, int 签名和 return
