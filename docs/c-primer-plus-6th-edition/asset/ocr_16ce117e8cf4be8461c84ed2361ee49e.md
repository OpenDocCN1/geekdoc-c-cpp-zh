Consider the code for the Sum() function. Note that the argument is a reference but that the return type is not a reference. The code would produce the same results if the Time object was passed by value, but it's utterly faster and more memory-efficient to pass to a reference.

However, the return value cannot be a reference. The reason is that the function creates a new Time object (sum) that represents the sum of the other two Time objects. Returning the object, as this code, creates a copy of the object that the calling function can use. If the return type were Time&, however, the reference would be to the sum object.
