# Redefining I/O

The ISO/ANSI C++98 standard revised I/O a couple of ways. First, the change from ostream.h to ostream, with placing the classes in the std namespace. Second, the I/O classes have been rewritten. To be an international language, C++ has to be able to handle character sets that require a 16-bit or wider character type. The language added the wchar_t (or "wide") character type to the traditional 8-bit char (or "narrow") type. C++11 adds char6_t and char32_t types. Each type needs its own I/O facilities. Rather than develop two (or, now) separate sets of classes, the standards committee developed a template set of I/O classes, including basic_iostream<charT, traits<charT>> and basic_ostream<charT, traits<charT>. The traits<charT>, in turn, is a template class that defines particular traits for a character type, such as how to compare and its EOF value. The C++11 Standard provides char and wchar_t specializations of the I/O classes. For example, ist and ostream are typedefed for char specializations. Similarly, wstream and wostream are wchar_t specializations. For example, there is wcout for outputting wide character streams. The ostream header file contains these definitions.

Certain type-independent information that should be kept in the ios_base class has been moved to the new ios_base class. This includes the various formatting constants such as ios::fixed, which is now ios_base::fixed. Also ios_base contains some options that aren't available in the old ios.
