# The sizeof Operator and the limits Header File

The sizeof operator reports that int is 4 bytes on the base system, which uses an 8-bit byte.You can use the sizeof operator to a type name or to a variable. When you use the sizeof operator with a type name, such as int, enclose the name in parentheses. When you use the operator with a variable, such as n_short, parentheses are optional:

```
cout << "int is " << sizeof (int) << " bytes.\n"
cout << "short is " << sizeof n_short << " bytes.\n"

```

The limits file defines symbolic constants (in the sidebar, "Symbolic Constants for the Preprocessor Way," later in chapter") to represent type limits. As mentioned previously, INT_MAX represents the largest value type int can hold; this turned out to be 2,147,483,647 for our Windows 7 system. The compiler manufacturer provides a file that reflects the values appropriate to that compiler.
