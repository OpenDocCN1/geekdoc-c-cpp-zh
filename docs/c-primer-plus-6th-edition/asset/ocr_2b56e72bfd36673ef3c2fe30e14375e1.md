# Which Form of Single-Character Input to Use?

Given the choice of >>, get (char á), and get (void), which should you use? First, you need to decide whether you want to skip over white space. If skipping white space is convenient, you should use the extraction operator, >>. For example, skipping white space is convenient for offering menu choices:

```
cout << "a. anoy client       b. bill client\n"
cout << "c. calm client\n      d. deceive client\n"
cout << "q.n";
cout << "Enter a, b, c, d, or q: ";
char ch;
cin >> ch;
while (ch != 'q')
{
switch(ch)
{

}
out << "Enter a, b, c, d, or q: ";
cin >> ch;
}
```

To enter, a response, you type b and press Enter, generating the two-character response b'n. If you used other than get ( ), you would have to add code to process that \n character on each loop cycle, the extraction operator conveniently skips it. (If you've programmed in C, you've probably encountered a situation in which the newline appears to the program as an invalid result. It's an easy problem to fix, but it is a nuisance.)
