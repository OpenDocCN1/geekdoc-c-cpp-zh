# Functions and array Objects

Class objects in C++ are based on structures, some of the programming considerations that apply to structures also apply to classes. For example, you can pass an object value to a function, in which case the function act on a copy of the original object. Alternatively, you can pass a pointer to an object, which allows the function to act on the original object. Let's look at an example using the C++11 array template class.

Suppose we have an array intended to hold expense figures for each of the seasons of the year:

```
std::array<double, 4> expenses;
```

(Recall that using the array requires the array header file and the name array is part of the std namespace. If we want a function to display the contents of expenses, we can pass expenses by value:

```
show(expenses);
```

But if we want a function that modifies the expenses object, we need to pass the address of the object to the function:

```
fill(&expenses);
```

(The next chapter discusses an alternative approach, using references.) This is the same approach that Listing 7.13 used for structures.

How can we declare these functions? The type of expenses is array<double, 4>, so that what will appear in the prototypes:

```
void show(std::array<double, 4>& da); // da an object
void fill(std::array<double, 4>* pa); // pa a pointer to an object
```

These considerations form the core of the sample program. The program adds more features. First, it replaces 4 with a symbolic constant:

```
const int Seasons = 4;
```

Second, it adds a array object containing four string objects representing the four seasons:

```
const std::array<std::string, Seasons> Snames =
{"Spring", "Summer", "Fall", "Winter"};
```

Note that the array template is not limited to holding the basic data types; it can use classes too. Listing 7.15 presents the program in full.
