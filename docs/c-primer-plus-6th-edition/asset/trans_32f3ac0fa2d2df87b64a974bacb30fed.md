

# 第7章 函数：C++的编程模块

数组的地址不包含有关数组大小的任何信息，因此通常将数组大小作为单独的参数传递。或者，您可以传递指向数组开头的指针和指向末尾后一个位置的指针来指示范围，正如STL中的算法所做的那样。

C++提供三种表示C风格字符串的方法：使用字符数组、字符串常量或指向char的指针。所有这些都是类型 char*（指向字符的指针），因此它们作为类型 char* 传递给函数。C++使用空字符（\0）来终止字符串，字符串函数通过测试空字符来确定它们正在处理的任何字符串的结束位置。

C++还提供 string 类来表示字符串。函数可以接受 string 对象作为参数并使用 string 作为返回值。string 类的 size() 方法可用于确定存储字符串的长度。

C++将结构视为基本类型，这意味着您可以按值传递它们并将它们用作返回类型。但是，如果结构很大，按值传递可能效率较低，更有效的方法是传递指向结构的指针并让其与原始数据一起工作。这些相同的考虑也适用于类对象。

C++函数可以是递归的；也就是说，特定函数的代码可以包含对其自身的调用。

C++函数的名称充当函数的地址。通过使用指向函数的参数，您可以将第二个函数的名称传递给第一个函数，以便第一个函数调用它。
