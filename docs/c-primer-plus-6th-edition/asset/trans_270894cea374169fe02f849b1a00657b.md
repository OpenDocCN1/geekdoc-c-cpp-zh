大多数人对加法、减法、乘法和除法的熟悉程度超过对取模运算的熟悉程度，让我们花点时间来看一下取模运算符的实际作用。取模运算符返回整数除法的余数。结合整数除法使用，取模运算符在需要将一个数量划分为整数单位的问题中特别有用，例如将英寸转换为英尺和英寸，或将美元转换为四分之一美元、角、镍币和便士。在第 2 章中，

Listing 2.6 将英制石的重量转换为磅。Listing 3.12 反转了该过程，将磅重的重量转换为石。石，你记得，是 14 磅，大多数英国浴室秤都是按此单位校准的。该程序使用整数除法找到重量中完整的石数，并使用取模运算符找到剩余的磅数。

### Listing 3.12 modulus.cpp

```
// modulus.cpp -- uses % operator to convert lbs to stone
#include <iostream>
int main() {
    using namespace std;
    const int Lbs_per_stn = 14;
    int lbs;

    cout << "Enter your weight in pounds: ";
    cin >> lbs;
    int stone = lbs / Lbs_per_stn; // whole stone
    int pounds = lbs % Lbs_per_stn; // remainder in pounds
    cout << lbs << " pounds are " << stone << " stone, and " << pounds << " remainder pound(s).\n";
    return 0;
}
```

以下是 Listing 3.12 程序的一个示例运行：

Enter your weight in pounds: 181
181 pounds are 12 stone, 13 pound(s).

在表达式 lbs / Lbs_per_stn 中，两个操作数都是 type int，因此计算机执行整数除法。以 lbs 值为 181 为例，表达式求值为 12。12 与 14 的乘积为 168，所以将 14 除入 181 的余数为 13，这就是 lbs % Lbs_per_stn 的值。现在你在技术上，如果不是情感上，已经准备好在前往大不列颠旅行时应对关于你体重的问题了。

## Conversion on Initialization and Assignment

C++ 在允许你将一种类型的数值赋给另一种类型的变量方面相当宽松。每当你这样做时，值就会转换为接收变量的类型。例如，假设 so_long 是 long 类型，thirty 是 short 类型，并且你的程序中有以下语句：

```
so_long = thirty; // assigning a short to a long
```

程序取出 thirty 的值（通常是 16 位值）并在进行赋值时将其扩展为 long 值（通常是 32 位值）。请注意，扩展创建了一个新的值以放入 so_long；thirty 的内容保持不变。
将值赋给范围更大的类型通常不会有问题。例如，将 short 值赋给 long 变量不会改变值；它只是提供了更多的位来工作。然而，将像 2111222333 这样的大值赋给 float 变量会导致精度丢失。因为 float 只能有六位有效数字，该值可以四舍五入为 2.11122E9。因此，虽然有些转换是安全的，但有些可能存在困难。Table 3.3 指出了一些可能的问题。

## Table 3.3 Potential Numeric Conversion Problems

| Conversion Type | Potential Problems |
|---|---|
| Floating-point type to smaller floatingpoint type, such as double to float | Loss of precision (significant figures); value might be out of range for target type, in which case result is undefined. |
| Floating-point type to integer type | Loss of fractional part; original value might be out of range for target type, in which case result is undefined. |
| Bigger integer to smaller integer type, such as long to short | Original value might be out of range for target type; typically just the low-order bytes are copied. |

赋给 bool 变量的零值会被转换为 false，非零值会被转换为 true。

将浮点值赋给整数类型会带来几个问题。首先，将浮点转换为整数会导致截断数字（丢弃小数部分）。其次，float 值可能太大而无法放入狭窄的 int 变量中。在这种情况下，C++ 不定义应得到什么结果；这意味着不同的实现可能会做出不同的响应。

### Listing 3.13 init.cpp

```
// init.cpp -- type changes on initialization
#include <iostream>
int main() {

    using namespace std;
    cout.setf(ios_base::fixed, ios_base::float);
    float tree = 3; // int converted to float
    int guess(3.9832); // double converted to int
    int debt = 7.2E12; // result not defined in C++
    cout << "tree" << tree << endl;
    cout << "guess" << guess << endl;
    cout << "debt" << debt << endl;

    return 0;
}
```

以下是 Listing 3.13 程序在一个系统上的输出：

```
tree = 3.000000
guess = 3
debt = 163481904
```

在这种情况下，tree 被赋值为浮点值 3.0。将 3.9832 赋给 int 变量 guess 会导致其被截断为 3；C++ 在将浮点类型转换为整数类型时使用截断（丢弃小数部分）而不是四舍五入（找到最接近的整数值）。最后，int 变量 debt 无法容纳值 7.2E12。这造成了一种 C++ 不定义结果的情况。在该系统上，debt 最终得到值 163481904，约为 1.6E09。嗯，这是一种减少巨额债务的新颖方法

某些编译器会警告可能的数据丢失，用于将整数变量初始化为浮点值的那些语句。debt 显示的值因编译器而异。例如，在第二个系统上运行 Listing 3.13 中的同一程序产生了 214783647 的值。
