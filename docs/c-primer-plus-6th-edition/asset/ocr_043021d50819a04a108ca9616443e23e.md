# Using Strings in an Array

The two most common ways of getting a string into an array are to initialize an array to a string constant and to read keyboard or file input into an array. Listing 4.2 demonstrates these approaches by initializing one array to a quoted string and using cin to place the input into a second array. The program also uses the C library function strlen() to get the length of a string. The standard c header file (or string.h for older implementations) provides declarations for this and many other string-related functions.

Listing 4.2 strings.cpp

```
// strings.cpp -- storing strings in an array
#include <iostream>
#include <cstring> // for the strlen()
int main()
{
    using namespace std;
    const int Size = 15;
    char name[Size] = // empty array
    char name2[Size] = "C++owboy"; // initialized array
    // NOTE: some implementations may require the static keyword
    // to initialize the array name2

    cout << "Howdy! I'm " << name2 << "\n";
    cout << "! What's your name?\n";
    cin >> name;
    cout << "Well, " << name << ", your name has "\n";
    cout << strlen(name) << " letters and is stored\n";
    cout << "In an array of " << sizeof(name) << " bytes.\\n";
    cout << "Your initial is " << name[0] << "\n";
    name2[3] = '0'; // set to null character
    cout << "Here are the first 3 characters of my name: "\n";
    cout << name2 << endl;

    return 0;
}
```
