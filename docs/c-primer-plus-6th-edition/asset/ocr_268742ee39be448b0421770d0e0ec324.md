# When to Use Function Overloading

You might find function overloading fascinating, but you shouldn't overuse it. You should reserve function overloading for functions that perform basically the same task with different forms of data. Also you might want to check whether you can accomplish the same thing by using default arguments. For example, you could replace the single, string-oriented left () function with two overloaded functions:

```
char * left(const char * str, unsigned n); // two arguments
char * left(const char * str);           // one argument
```

But using the single with a default argument is simpler. There's just one function to write instead of two, and the program requires memory for just one function instead of two. If you decide to modify the function, you have edit only one however, If you require different types of arguments, default arguments are no avail, so in case, you should use function overloading.

# What Is Name Decoration?

How does C++ keep track of which function is which? It assigns a secret identity to each of these functions. When you use the editor of your C++ development tool to write and compile programs, your C++ compiler performs a bit of magic on your behalf—known as name decoration or mangling—through which each name is encoded, based on the formal parameters specified in the function's prototype. Consider the following undecoration function prototype:

```
MyFunctionFoo(int, float);
```

This format is fine for us humans; know that the function accepts two arguments of int and float, and it returns a value of type long. For your own use, the compiler documents this interface by transforming the name into an internal representation with a more unsightly appearance, perhaps something like this:

```
?MyFunctionFoo@YAXH
```

The apparent decipher the original name (or mangling, depending on your attitude) encodes the number and types of parameters. A different function signature would result in a different set of symbols being added, and different compilers would use different conventions for their efforts at decorating.
