```
char ch;
while (cin.get(ch))
{
    // process input
}
```

As long as there's valid input, the return value for cin.get(ch) is cin, which evaluates as true, the loop continues. Upon reaching end-of-file, the return value evaluates as false, terminating the loop.

# The getchar () Member Function

The (void) member function also reads white space, but it uses its return value to communicate to a program. So you would use it in this way:

```
int ct = 0;
char ch;
ch = cin.get();      // use return value
while (ch != '\n')
{
    cout << ch;
    ct++;
    ch = cin.get();
}
```

cout << ct << endl;

The (void) member function returns type int (or some larger integer type, depending on the character set and locale). This makes the following invalid:

```
char c1, c2, c3;
cin.get().get() >> c3;  // not valid
```

Here cin.get() returns an int value. Because return value is not a class object, you can't apply the membership operator to it.Thus, you get a syntax error. How-ever, you can use cin.get() at the end of an extraction sequence:

```
char c1;
cin.get(c1).get();    // valid
```

The fact that (void) returns type int means you can't follow it with an extraction operator. But because cin.get(c1) returns cin, it makes a suitable prefix to get(). This particular code would return the first input character, assign it to c1, and then return the second input character and discard it.

Upon reaching the end-of-file, real or simulated, cin.get (void) returns the value EOF, which is a symbolic constant provided by the iostream header file. This design feature allows the following construction for reading input:

```

while ((ch = cin.get()) != EOF)
```
