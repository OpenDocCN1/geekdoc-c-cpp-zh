## Pointer Arithmetic

C++ allows you to add an integer to a pointer. The result of adding one equals the original address plus a value equal to the number of bytes in the pointed-to-object. You can subtract an integer from a pointer to take the difference between two pointers. The last operation, which yields an integer, is meaningful only if the two pointers point to the same array (pointing to one position past the end is allowed, too); then it yields the separation between the two elements.

Here are some examples:

```cpp
int tacos[10] = {5,2,8,4,1,2,2,4,6,8};

pt = pt + 1;                // now pt is 3004 if an int is 4 bytes
int *pe = &tacos[9];        // pe is 3036 if an int is 4 bytes
pe = pe - 1;                // now pe is 3032, the address of tacos[8]
int diff = pe - pt;        // diff is 7, the separation between
                             // tacos[8] and tacos[1]
```
