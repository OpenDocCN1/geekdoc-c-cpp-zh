# Chapter 3 Dealing with Data

You use these type names to declare variables just as you would use int:

```
short score;                      // creates a type short integer variable
int temperature;               // creates a type int variable
long position;                  // creates a type long integer variable
```

Actually, short is for short int and long is for long int, but hardly any- uses the longer forms.

The four types—int, short, and long—are signed names, meaning each splits its range approximately between positive and negative values. For example, a 16-bit int runs from -32,768 to +32,767.

If you know how your system's sizes up, you can use C++ tools to investigate type sizes with a program. First, the sizeof operator returns the size in, bytes, of a type or variable. An *operator* is a built-in language element that operates on one or more items to produce a value. For example, the addition operator, represented by +, adds two values). Recall that the meaning of *byte* is implementation dependent, so a 2-byte int could be 16 bits on some system and 32 on others. The *climits* header (or, for older implementations, the *limits.h* header) contains information about type limits. In particular, it defines symbolic names to represent different limits. For example, it defines INT_MAX as the largest possible int and CHAR_BIT as the number of bits in a byte. Listing 3.1 demonstrates how to use these facilities. The program also illustrates *initialization*, which is the use of a declaration statement to assign a value to a variable.

# Listing 3.1 limits.cpp

```
// limits.cpp -- some integer limits
#include <iostream>
#include <climits>               // use limits.h for older systems
int main()
{
    using namespace std;
    int n_int = INT_MAX;
    short n_short = SHRT_MAX;      // symbols defined in climits file
    long n_long = LONG_MAX;
    long n_long = LLONG_MAX;

    // sizeof yields size of type or of variable
    cout << "int is " << sizeof(int) << " bytes." << endl;
    cout << "short is " << sizeof(n_short) << " bytes." << endl;
    cout << "long is " << sizeof(n_long) << " bytes." << endl;
    cout << "long long is " << sizeof(n_long) << " bytes." << endl;

    cout << "Maximum values:" << endl;
    cout << "int: " << n_int << endl;
    cout << "short: " << n_short << endl;
```
