# Unexpected String Input

Some forms of input for get(char *, int) and getline() affect the stream state. As with the other input functions, encountering end-of-file sets eofbit, and anything that corrupts the stream, device failure other special sets badbit. Two other special cases are no input and input that meets or exceeds the maximum number of characters specified by the function call. Let's look at those cases now.

If either method fails to extract any characters, the method places a null character into the input string and uses setState() to set failbit. When would a method fail to extract any characters? One possibility is if an input method immediately encounters end-of-file. For get(char *, int), another possibility is if you enter an empty line:

```cpp
char temp[80];
while (cin.get(temp,80)) // terminates on empty line
```

# Input with cin 1109

Interestingly, an empty line does not cause getline() to set failbit. That's because getline() still extracts the newline character, even if it doesn't store it. If you want a getline() loop to terminate on an empty line, you can write it this way:

```cpp
char temp[80];
while (cin.getline(temp, 80) && temp[0] != '\0') // terminates on empty line
```

Now suppose the number of characters in the input queue meets exceeds the maximum specified by the input method. First, consider getline() and the following code:

```cpp
char temp[30];
while (cin.getline(temp, 30))
```

The getline() will read consecutive characters from the input queue, placing them in successive elements of the temp array, until (in order of testing) end-of-file is encountered, the next character to be read is the newline character, or until 29 characters have been stored. If end-of-file is set, failbit is set. If the next character to be read is a newline character, that character is read and discarded. And if 29 characters were read, failbit is set, unless the next character is a newline. Thus an input line of 30 characters or more will terminate.

Now consider the get(char *, int) method. It tests the number of characters, end-of-file second, and for the next character a newline third. It does not set the failbit if it reads the maximum number of characters. Nonetheless, you can tell if too many characters were extracted by the input method using peek (the next section) to see the next character. If it's a newline, then get() must have read the entire line. If it's not a newline, then get() must have stopped before reaching the end. This technique doesn't necessarily work with getline() because getline() reads and discards the newline, so the next character. Table 17.6 summarizes these behaviors.

# Other istream Methods

Other istream methods we discussed so far include peek(), count(), and putback(). The read() function reads a given number of bytes and stores them in the specified location. For example, suppose you've used cin.get(my, 80) to read a line into the array and want to know how many characters were read. You could use the strlen() function to count the characters in the array, but it would be quicker to use cin.count() to report how many characters were read from the input stream.

The count() method returns the number of characters read by the last unformatted extraction method. That means characters read by a get(), getline(), ignore(), or read() method not by the extraction operator (>), which formats input to fit particular types. For example, suppose you've used cin.get(my, 80) to read a line into the array and want to know how many characters were read. You could use the strlen() function to count the characters in the array, but it would be quicker to use cin.count() to report how many characters were read from the input stream.

The putback() function inserts a character back into the input string. The inserted character then becomes the first character read by the next input statement. The putback() method takes one argument, which is the character to be inserted, and returns type istream&, which allows it to be concatenated with other istream methods. Using peek() is like using get() to read a character and then using putback() to place the character back in the input stream. However, putback() gives you the option of putting back a character that is different from the one just read.
