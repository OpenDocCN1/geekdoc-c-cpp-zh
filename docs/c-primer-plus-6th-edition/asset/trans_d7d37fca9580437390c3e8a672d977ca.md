

## 第17章 输入、输出与文件

between a stream and a file. 类构造函数和 open() 方法接受一个可选的第二个参数，该参数提供文件模式。文件模式决定了诸如文件是否要读和/或写、打开文件进行写入时是否截断它、尝试打开不存在的文件是否会出错，以及是否使用二进制或文本模式等事项。

文本文件以字符形式存储所有信息。例如，数值会被转换为字符表示。常用的插入和提取运算符，以及 get() 和 getline()，支持这种模式。二进制文件使用相同的内部二进制形式存储所有信息。二进制文件以更准确和紧凑的方式存储数据，特别是浮点值，但可移植性较差。read() 和 write() 方法支持二进制输入和输出。

seekg() 和 seekp() 函数为文件提供了 C++ 随机访问。这些方法可让你将文件指针定位到文件开头、文件末尾或当前位置。tellg() 和 tellp() 方法报告当前位置。

sstream 头文件定义了 istream 和 ostream 类，你可以使用 stream 和 ostream 方法从字符串中提取信息并将信息格式化到字符串中。

for (int i = 0; i < index; i++)
