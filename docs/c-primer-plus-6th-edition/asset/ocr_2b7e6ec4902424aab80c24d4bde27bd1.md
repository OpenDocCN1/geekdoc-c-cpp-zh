# Alternative Representations of Bitwise Operators

C++ provides alternative representations of several bitwise operators, as shown in Table E.4.They provide for locales that do not have the traditional bitwise operators as part of their character sets.

# Table E.4 Bitwise Operator Representations

| Standard Representation | Alternative Representation |
|---|---|n| & | bitand |
| &= | and_eq |
| | | bitor |
| |= | or_eq |
| ~ | compl |
| ^ | xor |
| ^= | xor_eq |

These alternative forms let you write statements like the following:
b = compl a bit b; // same as b = -a & b;
c = aor b; // same as c = a ^ c;
