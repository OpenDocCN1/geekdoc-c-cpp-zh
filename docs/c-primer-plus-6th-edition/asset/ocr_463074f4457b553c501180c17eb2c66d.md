# Using a Template Recursively

Another example of versatility is that you can use templates recursively. Another example, given the earlier definition of an array template, you can use it as follows:

```
ArrayTP< ArrayTP<int, 5>, 10> twodee;
```

This makes twodee an array of 10 elements, each of which is an array of five ints. The equivalent ordinary array would have this declaration:

```
int twodee[10];
```

Note that the syntax for templates presents the dimensions in the opposite order from the equivalent ordinary two-dimensional array. The program in Listing 14.18 tries this idea. It uses the ArrayTP template to create one-dimensional arrays to hold the sum and average value of each of the 10 sets of numbers. The method cout..width(2) causes the next item to be displayed as a field width of characters, unless a larger width is needed to show the whole number.

# Listing 14.18 twodee.cpp

```
// twodee.cpp -- making a 2-d array
#include <iostream>
#include "arraytp.h"
int main(void)
{
    using std::cout;
    using std::endl;
    ArrayTP<int, 10> sums;
    ArrayTP<double, 10> aves;
    ArrayTP<ArrayTP<int, 5>, 10> twodee;

    int i, j;

    for (i = 0; i < 10; i++)
    {
        sums[i] = 0;
        for (j = 0; j < 5; j++)
        {
            twodee[i][j] = (i + 1) * (j + 1);
        }
    }
```
