# Automatic Conversions and Type Cases for Classes

The next topic on the class menu is type conversion. We'll look into how C++ handles conversions to and user-defined types. To set the stage, let's first review how C++ handles conversions for its built-in types. When you make a statement that assigns a value of one standard type to another standard type, C++ automatically converts the value to the same type as the receiving variable, provided that the two types are compatible. For example, the following statements generate numeric type conversions:

```
long count = 8;           // int value converted to long
double time = 11;        // int value converted to double
int side = 3.33;          // double value 3.33 converted to int 3
```

These assignments work because C++ recognizes that different numeric types represent the same base—a number—and because C++ incorporates built-in rules for making the conversions. Recall from Chapter 3, "Dealing with Data," however, that you may lose some precision in these conversions. For example, assigning 3.33 to the int variable side results in side getting the value 3,03 part.

The C++ language does not automatically convert types that are not compatible. For example, the following statement fails because the left side is a pointer type, whereas the right side is a number:

```
int * p = 10; // type clash
```
