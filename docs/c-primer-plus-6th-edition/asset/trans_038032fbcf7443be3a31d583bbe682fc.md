请注意，字符串常量（使用双引号）与字符常量（使用单引号）不可互换。字符，例如 'S'，是代码的简写表示。在 ASCII 系统上，'S' 只是 83 的另一种写法。因此，以下语句将值 83 分配给 shirt_size：

```cpp
char shirt_size = 'S'; // this is fine
```

但 "S" 不是字符常量；它表示由两个字符组成的字符串，即 S 字符和 \0 字符。更糟糕的是，"S" 表示字符串存储的内存地址。像以下这样的语句会将内存地址分配给 shirt_size：

```cpp
char shirt_size = "S"; // illegal type mismatch
```

由于字符串在 C++ 中是独立的类型，C++ 编译器不会允许这种胡闹。（我们将在本章后面回到这一点——我们已经讨论过指针。）

# 连接字符串字面量

有时一个字符串可能太长而无法容纳在一行代码中。C++ 使你能够连接字符串字面量——即把两个带引号的字符串合并为一个。事实上，任何仅由空白字符（空格、制表符和换行符）分隔的两个字符串都会自动连接成一个。因此，以下输出语句彼此等价：

```cpp
cout << "I'd give my right arm to be " " a great violinist.\n";
cout << "I'd give my right arm to be a great violinist.\n";
cout << "I'd give my right arm ar" "m" to be a great violinist.\n";
```

请注意，连接会将空格添加到连接后的字符串中。第二字符串的第一个字符紧跟在第一字符串的最后一个字符 \0 之后。第一个字符串中的 \0 字符会被最后一个字符串的第一个字符替换。

# 在数组中使用字符串

将字符串放入数组的两种最常见方法是将数组初始化为字符串常量，以及将键盘或文件输入读入数组。清单 4.2 通过将一个数组初始化为带引号的字符串并使用 cin 将输入放入第二个数组来演示这些方法。该程序还使用 C 库函数 strlen() 来获取字符串的长度。标准的 cstring 头文件（或旧实现中的 string.h）提供了此函数以及许多其他字符串相关函数的声明。

清单 4.2 strings.cpp

```cpp
// strings.cpp -- storing strings in an array
#include <iostream>
#include <cstring> // for the strlen()
int main()
{
    using namespace std;
    const int Size = 15;
    char name[Size]; // empty array
    char name2[Size] = "C++Cowboy"; // initialized array
    // NOTE: some implementations may require the static keyword
    // to initialize the array name2

    cout << "Howdy! I'm " << name2 << "\n";
    cout << "! What's your name?\n";
    cin >> name;
    cout << "Well, " << name << ", your name has \n";
    cout << strlen(name) << " letters and is stored\n";
    cout << "In an array of " << sizeof(name) << " bytes.\n";
    cout << "Your initial is " << name[0] << "\n";
    name2[3] = '0'; // set to null character
    cout << "Here are the first 3 characters of my name: \n";
    cout << name2 << endl;

    return 0;
}
```

# 程序说明

从清单 4.2 你能学到什么？首先，请注意 size 运算符给出整个数组的大小，即 15 字节，但 strlen() 函数返回存储在数组中的字符串的大小，而不是数组本身的大小。此外，strlen() 只计算可见字符，不计算空字符。因此，对于 Basicman 的长度，它返回的值是 8，而不是 9。如果 cosmic 是一个字符串，则容纳该字符串的最小数组大小为 strlen(cosmic) + 1。

由于 name1 和 name2 是数组，你可以使用索引来标识数组中的单个字符。例如，程序使用 name1[0] 来查找该数组中的第一个字符。程序还将 name2[3] 设置为空字符。这使得字符串在三个字符后结束，即使数组中仍有字符（参见图 4.3）。

```cpp
const int ArSize = 15;
char name2[ArSize] = "C++Cowboy";
```

```cpp
// instrl.cpp
#include <iostream>
int main()
{
    using namespace std;
    const int ArSize = 20;
    char name[ArSize];
    char dessert[ArSize];

    cout << "Enter your name: ";
    cin >> name;
    cout << "Enter your dessert: ";

    cout << "Your name is " << name << ".\n";

}
```
