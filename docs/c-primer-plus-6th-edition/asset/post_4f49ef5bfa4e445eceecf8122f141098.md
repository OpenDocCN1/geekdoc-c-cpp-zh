# Things to Do to Vectors

Besides allocating storage, what else can the vector template do for you? All the STL containers provide certain basic methods, including size(), which returns the number of elements in a container, swap(), which exchanges the contents of two containers, begin(), which returns an iterator that refers to the first element in a container, and end(), which returns an iterator that represents the past-end-for-the container.

What is an iterator? It's a generalization of a pointer. In fact, it can be a pointer. Or it is an object for pointer-like operations such as dereferencing (for example, operator*) and incrementing (for example, operator++()) have been defined.

You'll see later, generalizing pointers to iterators allows the STL to provide a uniform interface for a variety of container classes, including ones for which simple pointers don't work. Each container class defines a suitable iterator. The type name for this iterator is a class scope typedef iterator. For example, to declare an iterator for a type `double<vector<double>>`, you would use this:

```cpp
vector<double>::iterator pd; // pd an iterator
```

Suppose scores is a vector<double> object:

```cpp
vector<double> scores;
```

Returning to the example, what's an iterator that refers to an element one past the last element in a container. The idea is similar to the idea of a null character being one past the last character in a C-style string, where the null character is the value in the element, and past-end is a pointer (or iterator) to the element. The end() member function identifies the past-end location. If you set an iterator to the first element in a container and keep incrementing, it will eventually reach the past-end, and past-end and pd are defined as in the preceding example, you can display the contents with this code:

```cpp
for (pd = scores.begin(); pd != scores.end(); ++pd)
cout << " << " << *pd << endl;
```

All containers have the methods you discussed. The vector class also has one handy method, called push_back(), adds an element to the end of a vector. While doing so, it attends to manage memory so the vector size increases to accommodate added members. This means you can write code like the following:

```cpp
vector<double> scores; // create an empty vector
double temp;
while (cin >> temp && temp >= 0)
  scores.push_back(temp);
cout << "You entered " << scores.size() << " elements " << scores << "\n";
```

Each loop cycle adds one more element to the scores object. You don't have to pick the number of element when you write the program or run the program. As long as the program has access to sufficient memory, it will expand the size of scores as necessary.

**Note**
A range [it1, it2) is specified by two iterators it1 and it2, and runs from it1 up to, but not including, it2. An insert() method completes erase(). It takes three arguments. The first gives the position ahead of which elements are be inserted. The second and third parameters define the range to be inserted. This range is typically part of another container. For example, the following code inserts all but the first element of new_v ahead of the first element of old_v:

```cpp
vector<int> old_v;
vector<int> new_v;
...
old_v.insert(new_v.begin(), new_v.end());
```

Incidentally, this is a case where past-the-end element is handy because it makes simple to append something to the end of a vector. In this code the new material is inserted ahead of old.end(), meaning it’s placed after the last element in the vector:

```cpp
old_v.insert(old_v.end(), new_v.begin() + 1, new_v.end());
```
