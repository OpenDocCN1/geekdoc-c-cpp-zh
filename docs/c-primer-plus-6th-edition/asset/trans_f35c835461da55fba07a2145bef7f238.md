## 智能指针模板类

智能指针是一个类对象，它像指针一样工作但具有额外的功能。这里我们将介绍三个智能指针模板，它们可以帮助管理动态内存分配的使用。让我们先看看可能需要什么以及如何实现。考虑以下函数：

```
void remodel(std::string & str)
{
    std::string * ps = new std::string(str);
    ...
    str = ps;
    return;
}
```

你可能已经看到了它的缺陷。每次调用函数时，它都会从堆分配内存但从不释放内存，从而造成内存泄漏。你也知道解决方案——只需在 return 语句之前添加以下语句记住释放已分配的内存：

delete ps;

然而，涉及“只需记住”这一短语的解决方案很少是最好的解决方案。有时你不会记住。或者你会记住但意外删除或注释掉代码。即使你确实记住了，仍然可能出现问题。考虑以下变体：

```
void remodel(std::string & str)
{
    std::string * ps = new std::string(str);
    ...
    if (weird_thing())
        throw exception();
    str = *ps;
    delete ps;
    return;
}
```

如果抛出异常，delete 语句将无法到达，再次出现内存泄漏。

你可以在第14章“在 C++ 中重用代码”中说明的那样修复该疏忽，但如果有更近的解决方案就好了。让我们思考一下需要什么。当函数如 remodel() 终止时，无论是正常终止还是抛出异常，局部变量都会从栈内存中移除——因此指针占用的内存被释放。如果 ps 所指向的内存也能被释放就好了。如果 ps 有一个析构函数，析构函数可以在 ps 存在时释放所指向的内存。因此，ps 的问题在于它只是一个普通指针，而不是具有析构函数的类对象。如果它是一个对象，你可以删除其所指向的内存。这就是 auto_ptr、unique_ptr 和 shared_ptr 背后的思想。auto_ptr 模板是 C++98 的解决方案。C++11 弃用 auto_ptr 提供了另外两个作为替代方案。然而，尽管已弃用，auto_ptr 已使用了多年，如果你的编译器不支持另外两个，它将是你的选择。

### 使用智能指针

这三个智能指针模板（auto_ptr、unique_ptr 和 shared_ptr）各自定义了一个指针式对象，旨在由 new 直接或间接分配地址。当智能指针过期时，其析构函数会删除以释放内存。因此，如果你将 new 返回的地址分配给这些对象之一，你就不必记住释放内存；它将由智能指针对象自动释放。图 16.2 说明了 auto_ptr 与普通指针之间的行为差异。shared_ptr 和 unique_ptr 在此情况下具有相同的行为。

要创建其中一个智能指针对象，你需要包含 memory 头文件，其中包含模板定义。然后你使用模板语法实例化所需的指针类型。例如，auto_ptr 模板包含以下构造函数：

```
template<class X> class auto_ptr {
public:
    explicit auto_ptr(X* p = 0) throw();
    ...;
```

（throw() 记号表示此构造函数不抛出异常。像 auto_ptr 一样，它已被弃用）。因此，对于类型为 x 的 auto_ptr 对象，你将得到一个指向 X 的 auto_ptr 对象：

```
auto_ptr<double> pd(new double); // pd an auto_ptr to double
                             // (use in place of double * pd)
auto_ptr<string> ps(new string); // ps an auto_ptr to string
                             // (use in place of string * ps)
```

```
void demol() {
    double * pd = new double; // #1
    *pd = 25.5; // #2
    return; // #3
}
```

#1: 为 pd 和一个 double 值创建存储，保存地址：

| pd |  | 10000 |
|---|---|---|
|  | 4000 | 10000 |

#2: 将值复制到动态内存中：

| 10000 | 25.5 |
|---|---|
| 4000 | 10000 |

#3: 丢弃 pd，留下动态内存中的值：

| 25.5 |
|---|
| 10000 |

```
void demo2() {
    auto_ptr<double> ap(new double); // #1
    *ap = 25.5; // #2
    return; // #3
}
```

#1: 为 ap 和一个 double 值创建存储，保存地址：

| 10080 |  |  |

| 6000 | 10080 |

#2: 将值复制到动态内存中：

| 10080 | 25.5 |
|---|---|
| 6000 | 10080 |

#3: 丢弃 ap，且 ap 的析构函数释放动态内存。

这里 new double 是 new 返回的指向新分配内存块的指针。它是 auto_ptr<double> 构造函数的参数；即，它是与原型中形式参数 p 对应的实际参数。同样，new string 也是构造函数的参数。另外两个智能指针使用相同的语法：
unique_ptr<double> pdu(new double); // pdu an unique_ptr to double
shared_ptr<string> pss(new string); // pss a shared_ptr to string

## 智能指针模板类

因此，要转换 remodel() 函数，你需要执行以下三个步骤：

- 1. 包含 memory 头文件。
- 2. 用指向 string 的智能指针对象替换指向 string 的指针。
- 3. 删除 delete 语句。

以下是使用 auto_ptr 完成这些更改后的函数：

```
#include <memory>
void remodel(std::string &str)
{
    std::auto_ptr<std::string> ps (new std::string(str));
    if (weird_thing())
        throw exception();
    str = *ps;
    // delete ps; NO LONGER NEEDED
    return;
}
```

请注意智能指针属于 std 命名空间。清单 16.5 展示了一个使用三种智能指针的简单程序。（你的编译器需要支持 C++11 的 shared_ptr 和 unique_ptr 类。）每个指针都放在一个块中，以便在执行离开块时指针过期。Report 类使用冗长的方法来报告对象何时被创建或销毁。

## 清单 16.5 smartptrs.cpp

```
// smartptrs.cpp -- using three kinds of smart pointers
// requires support of C++11 shared_ptr and unique_ptr
#include <iostream>
#include <string>
#include <memory>
class Report
{
private:
    std::string str;
public:
    Report(const std::string s) : str(s)
    {
        std::cout << "Object created!\n";
    }
    ~Report() {
        std::cout << "Object deleted!\n";
    }
    void comment() const {
        std::cout << str << "\n";
    }
};
int main()
{
```

```
{
  std::auto_ptr<Report> ps = new Report("using auto_ptr*");
  ps->comment(); // we use -> invoke a member function
}
```

```
{
  std::shared_ptr<Report> ps = new Report("using shared_ptr*");
  ps->comment();
}
```

```
{
  std::unique_ptr<Report> ps = new Report("using unique_ptr*");
  ps->comment();
}
```

```
return 0;
}
```

Object created!

Object deleted!
Object created!

这些类中的每一个都有一个显式构造函数接受指针作为参数。因此，不存在从指针到智能指针对象的自动类型转换：
shared_ptr<double> pd;
double *p_reg = new double; // not allowed (implicit conversion)
pd = shared_ptr<double>(p_reg); // allowed (explicit conversion)
shared_ptr<double> pshared = p_reg; // not allowed (implicit conversion)
shared_ptr<double> pshared(p_reg); // allowed (explicit conversion)

智能模板类被定义为在大多数方面智能指针对象像普通指针一样工作。例如，给定 ps 是一个智能对象，你可以解引用 (*ps)、使用它访问成员 (ps->puffIndex)，并将其分配给指向相同类型的普通指针。你也可以将一个智能指针对象分配给另一个相同类型的智能指针对象，但这会引发下一个部分涵盖的问题。
但首先，有一件事你应该对这三种智能指针都避免：
string vacation("I wandered lonely as as a cloud.");
shared_ptr<string> pvac(&vacation); // NO!

当 pvac 过期时，程序将对非堆内存应用 delete 操作符，这是错误的。
