# Further Assignment Operator Overloading

Before looking at the new listings for the String class example, let's consider another matter. Suppose you want to copy an ordinary string to a String object. For example, suppose you getline() to read a string and you want to place it in a String object. The class methods already allow you to do the following:

```
String name;
char temp[40];
cin.getline(temp, 40);
name = temp; // use constructor to convert temp
```

However, this might not be a satisfactory solution if you have to do it. To see why, let's review the final statement:

+   1. The program uses the String(const char *) constructor to construct a String object containing a copy of the string stored in temp. Remember from Chapter 11,"Working with Classes," that a constructor with a single argument serves as a conversion function.
2. In Listing 12.6, in this chapter, the program uses the String &operator=(const String &) function to copy information from the temporary object to the name object.
3. The program calls the ~String() destructor to delete the temporary object so that it works directly with ordinary strings. This removes the extra steps of creating and destroying a temporary object. Here's one possible implementation:

String &String::operator=(const char *s)

```
{
delete []str];nlen = std::strlen(s);
str = new char[len + 1];
std::strcpy(str, s);
return *this;
}
```

As usual, you must deallocate memory formerly managed by str and allocate memory for the new string.
