# ### Another Version of cin.get()

Nostalgic C users might yearn for C's I/O functions, getchar() and putchar(). They are available in C++ if you want. You use the stdio.h header file as you would in C (or the more current cdio). You can use member functions from the istream and ostream classes that work in the same way. Let's look at that approach.

The cin.get() member function with no arguments returns the next character from the input. That is, use it in this way:

```
ch = cin.get();
```

(Recall that cin.get(ch) returns an object, not the character read.) This function works much the same as C's getchar(), returning the character code as a type int value. Similarly, you can use the cout.put() function (see Chapter 3,"Dealing with Data") to display the character:

```
cout.put(ch);
```

It works like C's putchar(), except that its argument should be type char instead of type.

Note

Originally, the put() member had the single prototype put(char). You could pass it to an int argument, which would then be type cast to char. The Standard calls for a single prototype; however, some C++ implementations provide: put(char), put(signed char), and put(unsigned char). Using put() with an int argument in these implementations generates an error message because there is more than one choice for converting the int. An explicit type, such as cin.put(char (ch)), works for int types.

Use cin.get() successfully, you need to know how to handle the EOF condition. When the function returns the EOF, there are no more characters to be returned. cin.get() returns a special value, represented by the symbolic constant EOF. This constant is defined in the istream header file. The EOF value must be different from any valid character value so that the program won't confuse EOF with a regular character.
