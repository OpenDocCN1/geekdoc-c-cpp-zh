# Chapter 18 Visiting with the New C++ Standard

Listing 18.6 somefds.h

```
// somefds.h
#include <iostream>

template <typename T, typename F>
T use_f(T v, F f)
{
    static int count = 0;
    count++;
    std::cout << " use_f count = " << count
              << " " << &count << << " " << &count << std::endl;

    return f(v);
}

class Fp
{
private:
    double z;
public:
    Fp(double z = 1.0) : z_(z) {}
    double operator()(double p) { return z_*p; }
};

class Fq
{
private:
    double z;
public:
    Fq(double z = 1.0) : z_(z) {}
    double operator()(double q) { return z_+q; }
};
```

The use_f template uses the parameter f to represent a callable type:
return f(v);

Next the program in Listing 18.7 calls the use_f() template function six times.
