This chapter looks how to use new and delete with classes and how to deal with the subtle problems that dynamic memory can cause. This might sound like a short list of topics, but these topics affect constructor design, destructor design, and operator overloading.

Let's look at a specific example of how C++ can add to your memory load. Suppose you want to create a class with a member that represents someone's last name. The simplest, most primitive way is to use a character array to hold the name. But this has drawbacks. You might use a 14-character array and then run into Bartholomew Smeadsbury. Or be safe, you might use a 40-character array. But if you create an array of 2,000 objects, you'll lose a lot of memory with character arrays (At that point, you're adding to the computer's memory load.) There is an alternative.

Often it is much better to decide many matters, as how much storage to use, when a program runs rather than when it's compiled. The usual C++ approach to storing a name in an object is to use the new operator in a class constructor to allocate the correct amount of memory while the program is running.
