## 程序说明

《清单 5.4》中的程序创建了一个数组来保存阶乘值。元素 0 是 0!，元素 1 是 1!，以此类推。因为前两个阶乘都等于 1，所以程序将阶乘数组的前两个元素设为 1.0。记住，数组的第一个元素的索引值为 0。之后，程序使用一个循环将每个阶乘设为其索引与前一个阶乘的乘积。该循环说明了你可以在循环体中使用循环计数器作为变量。

《清单 5.4》中的程序演示了 for 循环如何与数组配合使用，通过提供一种方便的方式依次访问每个数组成员。《清单 5.4》使用 const 来为数组大小创建一个符号表示 ArSize。然后它在数组出现的地方都使用 ArSize，例如在数组定义中以及处理数组的循环的限制中。现在，如果你想将程序扩展到，例如 20 个阶乘，你只需在程序中将 ArraySize 设为 20 并编译即可。通过使用符号常量，你避免了必须单独更改每个 16 为 20。

> 通常最好定义一个 const 值来表示数组中的元素个数。你可以在数组声明中以及对数组大小的所有引用中使用 const 值，例如在 for 循环中。

限制表达式 < ArraySize 反映了具有 ArraySize 个元素的数组的下标从 0 到 ArraySize - 1 的事实，因此数组索引应停止在 ArraySize 之前。你也可以使用 i <= ArraySize - 1，但与之相比看起来很别扭。

请注意，程序在 main() 体之外声明了 const 变量 ArraySize。这使得 ArraySize 对 main() 数据外部。声明 ArraySize 的这种方式带来的两个后果是 ArraySize 在程序持续期间存在，并且程序中的所有函数都可以使用它。在这种特定情况下，程序只有一个，所以在外部声明 ArraySize 几乎没有实际效果。但多函数程序通常受益于共享外部常量，所以我们接下来会预测使用它们。

此外，此示例提醒我们可以使用 std:: 而不是 using 指令使标准名称可用。

## 改变步长

到目前为止，本章中的循环示例在每个周期中将循环计数器增加或减少一。你可以通过更改更新表达式来改变这一点。例如，《清单 5.5》中的程序按用户选择的步长增加循环计数器。它没有使用 i++ 作为更新表达式，而是使用表达式 i = i + by，其中 by 是用户选择的步长。

清单 5.5 bigstep.cpp

```
// bigstep.cpp -- count as directed
#include <iostream>
int main()
{
using std::cout;      // a using declaration
using std::cin;
using std::endl;
cout << "Enter an integer: ";
int by;
cin >> by;
cout << "Counting by " << by << "s:\n";
for (int i = 0; i < 100; i = i + by)
cout << i << endl;
return 0;
```

以下是《清单 5.5》程序的一个示例运行。

Enter an integer: 17
Counting by 17s:
0
17
34
51
68
85

当 i 达到 102 时，循环退出。这里的主要观点是更新表达式可以是任何有效表达式。例如，如果你想在每个周期中平方并加 10，你可以使用 i = i * i + 10。

另一个要点是要注意最好测试不等式。例如，测试 i == 100 在这种情况下会失败，因为 i 跳过了 100 的值。

最后，这个示例说明了使用 using 声明而不是 using 指令。

## 使用 for 循环的字符串

for 循环提供了一种直接的方式依次访问字符串中的每个字符。例如，《清单 5.6》使你能够输入一个字符串然后按字符反向显示。你可以在此示例中使用 string 对象或 char 数组，两者都允许你使用数组表示法访问字符串中的单个字符；《清单 5.6》使用 string 对象。string 类的 size() 方法给出字符串中的字符数；循环在其初始化表达式中使用该值将 i 设为字符串中最后一个字符的索引，不包括空字符。为了向下计数，程序使用递减运算符（--）在每次循环中将数组下标减少一。此外，《清单 5.6》使用大于等于关系运算符（>=）来测试循环是否已到达第一个元素。我们很快会总结所有运算符。

清单 5.6 for1.cpp

```
// for1.cpp using for with a string
#include <iostream>
#include <string>
int main()
{
using namespace std;
cout << "Enter a word: ";
string word;
cin >> word;

// display letters in reverse order
for (int i = word.size() - 1; i >= 0; i--)
cout << word[i];
cout << "\nBye.\n";

return 0;
```

以下是《清单 5.6》程序的一个示例运行：

Enter a word: animal
lamina
Bye.

是的，程序成功地将 animal 倒过来打印；选择 animal 作为测试词比选择回文词如 rotator、redder 或 stats 更能清楚地说明此程序的效果。

## 自增（++）和自减（--）运算符

C++ 提供了几个在循环中经常使用的运算符；让我们花点时间来检查它们。你已经见过其中两个：自增运算符（++）和自减运算符（--）。这些运算符执行两个常见的循环操作：使循环计数器增加或减少一。然而，他们的故事比到目前为止你所看到的要多。每个运算符都有两种变体：前缀版本在操作数之前，如 ++x。后缀版本在操作数之后，如 x++。两种版本对操作数有相同的效果，但它们在何时发生方面有所不同。这就像预付或事后支付割草的费用；两种方法对你的钱包有相同的最终效果，但钱增加的时间不同。《清单 5.7》对此进行了演示，针对自增运算符。

清单 5.7 plus_one.cpp

```
// plus_one.cpp - the increment operator
#include <iostream>
int main() {

    using std::cout;
    int a = 20;
    int b = 20;

cout << "a = " << a << "; b = " << b << "\n";
cout << "a++ = " << a++ << "; ++b = " << ++b << "\n";
cout << "a = " << a << "; b = " << b << "\n";
return 0;
```

以下是《清单 5.7》程序的输出：

- a = 20; b = 20
- a++ = 20; ++b = 21
- a = 21; b = 21

粗略地说，记号 a++ 表示“在求值表达式中使用 a 的当前值，然后递增 a 的值”。类似地，记号 ++b 表示“首先递增 b 的值，然后在求值表达式中使用新值”。例如，我们有以下关系：

```
int x = 5;
int y = ++x; // change x, then assign to y
y is 6, x is 6

int z = 5;
int y = z++; // assign to y, then change z
y is 5, z is 6
```

使用自增和自减运算符是一种简洁、方便的方式来处理使值增加或减少一的常见任务。

自增和自减运算符是巧妙的小运算符，但它们不能在同一语句中对同一个值进行多次自增或自减。问题在于使用后更改和更改后使用规则可能存在歧义。也就是说，以下内容在不同系统上可能产生不同的结果：

```
x = 2 * x++ (3 - ++x); // don't do it as an experiment
```

C++ 未定义此类语句的正确行为。

## 副作用和序列点

让我们更仔细地看看 C++ 对自增运算符何时生效的规定和未规定。首先，回顾一下副作用是在求值表达式时修改了某些东西，例如存储在变量中的值所产生的效果。序列点是程序执行中的一个点，在该点保证所有副作用在继续执行下一条语句之前都已求值。语句中的分号标记一个序列点。这意味着语句中由赋值运算符、自增和自减运算符所做的所有更改必须在程序继续执行下一条语句之前完成。我们将在后面章节中讨论的一些运算符具有序列点。完整的表达式结束也是一个序列点。
