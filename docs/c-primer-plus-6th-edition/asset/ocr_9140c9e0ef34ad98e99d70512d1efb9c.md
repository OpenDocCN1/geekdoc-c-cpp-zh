The class description specifies all the operations that can be performed on objects of class. To perform such an action on a particular object, you send a message to the object. For example, if you want the cout object to display a string, you send a message that says so. In fact,, C++ provides several ways to send messages. One way, using a class method, is essentially a function call like the ones you'll see soon. The other way, which is the one used with cin and cout, is to redefine an operator. Thus, the following statement uses the redefined operator to send the "display message" to:

```
cout << "I am not a crook."
```

In this case, the message comes with an argument, which is the string to be displayed. (See Figure 2.5 for a similar example.)
