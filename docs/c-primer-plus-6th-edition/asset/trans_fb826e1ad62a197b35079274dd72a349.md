## 大端和小端

奇怪的是，使用整数二进制表示的两种计算平台可能不会以相同的方式表示同一个数字。例如，Intel 机器使用小端架构存储字节，而 Motorola 处理器、IBM 大型机、SPARC 处理器和 ARM 处理器采用大端方案。 （然而，后两种系统可以配置为使用任一方案。）

术语大端和小端可以被认为意味着“大端在内”和“小端在内”——指的是内存中一个字（通常是一个 2 字节单元）中字节的顺序。在 Intel 计算机（小端）上，低位字节先存储。这意味着十六进制值 0xABC 将以 0xCD 0xAB 的形式存储在内存中。Motorola（大端）机器将以相反顺序存储相同的值，因此 0xABC 将以 0xAB 0xCD 的形式存储在内存中。

乔纳森·斯威夫特的《格列佛游记》是这些术语的最终来源。斯威夫特通过发明两个有争议的政治派别来讽刺许多政治争论的非理性

小人国人：大端派，他们坚持认为打破鸡蛋的正确一端是大端，而小端派则主张打破鸡蛋的小端。

作为一名软件工程师，你应该了解你所针对的平台的字序。其他方面中，它会影响通过网络传输的数据的解释以及数据在二进制文件中的存储方式。在前面的示例中，2 字节内存模式 0xABCD 在小端机器上代表十进制值 52,651，在大端机器上代表十进制值 43,981。

## C++ 保留字

C++ 为其自身和 C++ 库保留了一些字。你不应该在声明中使用保留字作为标识符。保留字分为三类：关键字、替代标记和 C++ 库保留名称。

### C++ 库保留名称

编译器不会让你使用关键字和替代标记作为名称。还有另一类禁止的名称，其保护并非绝对——保留名称，即为 C++ 库保留的名称。如果你将其中一个用作标识符，其效果是未定义的。也就是说，它可能会生成编译器错误，或者它可能会生成警告，这可能会导致程序运行不正确，或者它可能完全没有任何问题。

C++ 语言保留库头文件中使用的大宏名称。如果程序包含头文件，你不应该将该头文件中定义的大宏名称（或由头文件包含的头文件中的名称，等等）用于其他目的。例如，如果你直接或间接使用头文件 <limits>，你不应该使用 CHAR_BIT 作为标识符，因为它在该头文件中已用作大宏。

C++ 语言为任何用途保留以两个下划线开头或以下划线开头后跟大写字母的名称，并为用作全局变量保留以下划线开头的名称。因此不要在任何情况下创建名称如 __gink 或 __Lynx，以及在全局命名空间中名称如 _lynx。

### 具有特殊含义的标识符

C++ 语言保留在库头文件中声明为外部链接的名称。对于函数，这包括函数签名（名称和参数列表）。例如，假设你有以下代码：

```
#include <cmath>
using namespace std;
```

在这种情况下，函数签名 tan(double) 是保留的。这意味着你的程序不应该声明具有以下原型的函数：

```
int tan(double); // do not do it
```

这与库 tan() 原型不匹配，后者返回类型 double，但它确实匹配签名。然而，以下原型是可以的：

```
char *tan(char *); // ok
```

即使它匹配 tan() 标识符，它也不匹配签名。

### 具有特殊含义的标识符

C++ 社区不愿添加新关键字，因为它们可能与现有代码冲突。这就是为什么标准委员会例如重新利用了 auto 关键字并对其他关键字如 virtual 和 delete 使用了多个关键字的原因。C++11 实施了另一种方法以避免添加关键字，那就是使用具有特殊含义的标识符。这些标识符 override 和 final 不是关键字，但它们用于实现语言特性。编译器使用上下文来确定它们是作为普通标识符使用还是作为语言特性使用：

```
class F {
  int final; // #1
public:
  ...
  virtual void unfold(){} = final; // #2
}
```

第 #1 行的 final 用作普通标识符，第 #2 行的 final 用于调用语言特性。这两种用法不会相互冲突。
此外，C++ 还有许多在程序中常见但未保留的标识符。这些包括头文件名、库函数名以及 main，即执行开始时所需的函数名。只要你避免命名空间冲突，你就可以将这些标识符用于其他目的，尽管没有理由这样做。也就是说，除了缺乏常识之外，没有任何东西可以阻止以下代码：

```
// allowable but silly
#include <iostream>
int iostream(int a);
```

```
int main ()
{
    cout << istream(5) << '\\n';
    return 0;
}
```

```
int istream(int a)
{
    int main = a + 1;
    int cout = a - 1;
    return main*cout;
}
```

## ASCII 字符集
