# Functions and Two-Dimensional Arrays

To write a function that has a two-dimensional array as an argument, you need to remember that the name of an array is treated as its address, so the corresponding formal parameter is a pointer, just the tricky part is declaring the pointer correctly. Suppose, for example, that you start with this code:

```cpp
int data[3][4] = {{1,2,3,4}, {9,8,7,6}, {2,4,6,8}};
int total = sum(data, 3);
```

What should the prototype for sum() look like? And why does the function pass the number of rows (3) as an argument and not also the number of columns (4)?
Well, data is the name of an array with three elements. The first element is itself, an array of four int values. Thus, the type of data is pointer-to-array-of-four-int, so an appropriate prototype would be:

```cpp
int sum(int (*ar2)[4], int size);
```

# Chapter 7 Functions: C++'s Programming Modules

The parentheses are needed because the following declaration would declare an array of pointers-to-int instead of a single pointer-to-array-of-four-int, and a function parameter cannot be an array:

```cpp
int *ar2[4]
```

Here's an alternative format that means exactly the same thing as this first prototype, but, perhaps, is easier to read:

```cpp
int sum(int ar2[][4], int size);
```

Either prototype types show that ar2 is a pointer, not an array. Also note that the pointer type specifies it points to an array of four ints. Thus, the pointer type specifies the number of columns, which is why the number of columns is not passed as a separate function argument.

Because the pointer type specifies the number of columns, the sum() function only works with four columns. But the number of rows is specified by the size, so sum() can work with a varying number of rows:

```cpp
int a[100][4];
int b[6][4];
...
int total1 = sum(a, 100);    // sum all of a
int total2 = sum(b, 6);      // sum all of b
int total3 = sum(a, 10);     // sum first 10 rows of a
int total4 = sum(ar2, 20);   // sum next 20 rows of a
```

Given that the parameter ar2 is a pointer to an array, how do you use it in the function definition? The simplest way is to use ar2 as if it were the name of a two-dimensional array. Here's a possible function definition:

```cpp
int sum(int ar2[][4], int size)
{
    int total = 0;
    for (int r = 0; r < size; r++)
        for (int c = 0; c < 4; c++)
            total += ar2[r][c];
    return total;
}
```

Again, note that the number of rows is whatever is passed to the size parameter, but the number of columns is fixed at four, both in the parameter declaration for ar2 and in the inner for loop.

Here's why you use array notation. Because ar2 points to the first element (element 0) of an array-of-four-int, the expression ar2 + r points to element number r. Therefore ar2[r] is element number r. That element is itself an array-of-four-int, so ar2[r] is the name of array-of-four-int. Applying this to an array element, so ar2[r][c] is an element of the array-of-four-int, has a single value. The pointer ar2 is to be dereferenced to get to

# Functions and C-Style Strings

Recall a C-style string consists of a series of characters terminated by the null character. Much of what you've learned about array functions applies to strings, too. For example, passing a string as an argument means passing an address, and you can use const to protect string argument from being altered. But there are a few twists to strings that you'll unravel now.

# Functions with String Arguments

Suppose you want to pass a string as an argument to a function. You have three choices for representing a string:

- An array of char
- A quoted string (also called string literal)
- A pointer-to-char

All three choices, however, are type-to-char (more concisely, char *), so you can use all of them as string-processing functions:

```cpp
char ghost[15] = "minimum";
char *str = "minimum";
int nl = strlen(ghost);      // ghost is &ghost[0]
int np = strlen(str);        // pointer to char
int ns = strlen("minimum");  // address of string
```

Informally, you can say that you're passing a string as an argument, but you're really passing the address of the first character in the string. This implies string function prototype should use char * as the type representing string.

# Chapter 7 Functions: C++'s Programming Modules

One important difference between a C-style string and a regular array is that the string has a built-in terminating character.(Recall that char array containing characters but no null character is just an array and not a string.) That means you don't have to pass the size of the string as an argument. Instead, the function can use a loop to examine each character in the string in turn until the loop reaches the terminating character. Listing 7.9 illustrates that approach with a function that counts the times a given character appears in a string. Because the program doesn't need to deal with negative values, it uses unsigned int type for counting.

# Listing 7.9 strgfun.cpp

```cpp
// strgfun.cpp -- functions with a string argument
#include <iostream>
unsigned int count_str(const char * str, char ch);
int main()
{
    using namespace std;
    char mmm[15] = "minimum"; // string in an array
    // some systems require char with static to enable array initialization
    char *str = "minimum"; // str points to string

    unsigned int ms = count_str(mmm, 'm');
    unsigned int us = count_str(str, 'u');
    cout << ms << " characters in " << mmm << endl;
    cout << us << " characters in " << str << endl;
    return 0;
}

// this function counts the number of ch characters in the string
unsigned int count_str(const char * str, char ch)
{
    unsigned int count = 0;

    while (*str) // quit when *str is '\0'
    {
        if (*str == ch)
            count++;
        str++; // move pointer to next char
    }
    return count;
}
```

# Program Notes

Because the count_str() function in Listing 7.9 shouldn’t alter the original string, it uses the const modifier when it declares the parameter str. If you mistakenly let the function alter part of the string, the compiler catches your error. Of course, you can use array notation to declare count_str(const char str[]) in the function:

```cpp
unsigned int count_str(const char str[], char ch) // also okay
```

However, using pointer notation reminds you that the argument doesn’t have to be the name of an array but be some other form of pointer. The function itself demonstrates a standard way to process the characters in a string:

```cpp
while (*str)
{
    statements
    str++;
}
```

Initially, str points to the first character in the string, so *str represents the first character itself. For example, immediately after the first function call, *str has the value m, the first character in minimum. As long as the character is not the null character (\0), *str is nonzero, the loop continues. At the end of each loop, the expression str++ increments the pointer by 1 so that it points next to the string. Eventually, str points to the terminating null character, making *str equal to 0, which is the numeric code for the null character. That condition terminates the loop. (Why are string-processing functions ruthless? Because they stop at nothing.)
