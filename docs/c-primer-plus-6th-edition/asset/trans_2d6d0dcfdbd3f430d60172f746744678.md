让我们构造一个函数来显示类型为 polar 结构的内容。C++ 库中的数学函数（借自 C）假定角度以弧度为单位，因此你需要以单位测量角度。但为了显示目的，你可以将弧度测量转换为度。这意味着乘以 180/π，大约为 57.29577951。下面是该函数：

// show polar coordinates, converting angle to degrees
void show_polar(polar dapos)
{
    using namespace std;
    const double Rad_to_deg = 57.29577951;

    cout << "distance = " << dapos.distance << "\n";
    cout << "angle = " << dapos.angle * Rad_to_deg;
    cout << " degrees\n";
}
```

## 第 7 章 函数：C++ 的编程模块

注意形式参数的类型为 polar。当你将一个 polar 结构传递给此函数时，结构内容会被复制到数据结构中，然后函数在其工作中使用该数据。因为数据是结构，函数使用成员（点）运算符（见第 4 章）来标识结构成员。

接下来，让我们尝试做一些雄心勃勃的事情，编写一个将直角坐标转换为极坐标的函数。我们将让该函数接受 rect 结构作为其参数并向调用函数返回一个 polar 结构。该函数包含数学库中的函数，因此程序必须包含 cmath 头文件（旧系统上为 math.h）。此外在某些系统上你必须告诉编译器加载数学库（见第 1 章“开始使用 C++”）。你可以使用毕达哥拉斯定理从水平和垂直顶点得到距离：

```
distance = sqrt( x * x + y * y)
```

数学库中的 atan2() 函数从 x 和 y 值计算角度：

（也有 atan() 函数，但它无法区分相差 180 度的情况。这种不确定性在数学函数中并不比在荒野向导中更受欢迎。）

给定这些公式，你可以按如下方式编写函数：

// convert rectangular to polar coordinates
polar rect_to_polar(rect xypos) // returns type polar
{
    polar answer;

    answer.distance =
    sqrt(xypos.x * xypos.x + xypos.y * xypos.y);
    answer.angle = atan2(xypos.y, xypos.x);
    return answer; // returns a polar structure
}
```

// structfun.cpp -- functions with a structure stream
#include <iostream>
#include <cmath>

// structure declarations
struct polar
{
    double distance; // distance from origin
    double angle; // direction from origin
};

struct rect
{
    double x;      // horizontal distance from origin
    double y;      // vertical distance from origin
}

// prototypes
polar rect_to_polar(rect xypos);
void show_polar(polar dapos);

int main()
{
    using namespace std;
    rect rplace;
    polar pplace;

    cout << "Enter the x and y values: ";
    while (cin >> rplace.x >> rplace.y) // slick use of cin
    {
        pplace = rect_to_polar(rplace);
        show_polar(pplace);
        cout << "Next two numbers (q to quit): ";
    }
    cout << "Done.\n";
    return 0;
}

// convert rectangular to polar coordinates
polar rect_to_polar(rect xypos)
{
    using namespace std;
    polar answer;

    answer.distance = sqrt(xypos.x * xypos.x + xypos.y * xypos.y);
    answer.angle = atan2(xypos.y, xypos.x); // returns a polar structure
    return answer;
}

// show polar coordinates, converting angle to degrees
void show_polar(polar dapos)
{
    using namespace std;
    const double Rad_to_deg = 57.29577951;

    cout << "distance = " << dapos.distance << ",";
    cout << " angle = " << dapos.angle * Rad_to_deg << ",";
    cout << " degrees\n";
}
```

### 程序说明

我们已经讨论了清单 7.12 中的两个函数，所以让我们回顾一下程序如何使用 cin 控制循环：

回想一下 cin 是 istream 类的对象。提取运算符（>>）被设计成这样，cin >> rplace.x 也是该类型的对象。正如你在第 11 章“使用类”中将会看到的那样，类运算符是用函数实现的。
当你使用 cin >> rplace.x 时，程序调用一个函数，该函数返回一个类型为 stream 的值。如果你将提取运算符应用于 cin >> rplace.x 对象（如 cin >> rplace.x >> rplace.y），你再次得到一个 istream 类的对象。因此，整个 while 循环测试表达式求值为 cin，当用作测试表达式时，如你可能回忆的那样，会被转换为布尔值 true 或 false，具体取决于输入是否成功。在清单 7.12 的循环中，例如，cin 期望输入两个数字。如果用户输入 q，如示例输出所示，cin 认识到 q 不是数字。它将 q 留在输入队列中并返回一个被转换为 false 的值，从而终止循环。

要提前终止此循环，你输入一个负数。这将输入限制为非负值。这种限制适合某些程序的需求，但更典型的是你希望有一种终止循环的方法，而不排除某些数值。使用 cin >> 作为测试条件消除了此类限制，因为它接受所有有效数值输入。当你需要输入数字时，你应该记住这一点。此外，你应该记住非数值输入会设置错误条件，从而阻止读取更多输入。如果程序输入到输入循环，你必须使用 cin.clear() 重置输入，并且可能需要通过读取来摆脱有问题的输入。清单 7.7 说明了这些技术。

### 传递结构地址

假设你想通过传递结构的地址而不是传递整个结构来节省时间和空间。这需要重写函数，使其使用指向结构的指针。首先，让我们看看如何重写 show_polar() 函数。你需要做三处更改：

- 调用函数时，传递结构的地址（&polar）而不是结构本身（pplace）。
- 将形式参数声明为指向 polar 的指针——即类型 *。因为函数不应该修改结构，使用 const 修饰符。
- 因为形式参数是指针而不是结构，使用间接成员运算符（->）而不是成员运算符（点）。

做出这些更改后，函数看起来像这样：

// show polar coordinates, converting angle to degrees
void show_polar(const polar * pda) {
    using namespace std;
    const double Rad_to_deg = 57.29577951;

    cout << "distance = " << pda->distance << "\n";
    cout << "angle = " << pda->angle * Rad_to_deg << "\n";
    cout << "degrees\n";
}
```

接下来，让我们修改 rect_to_polar。这更复杂，因为原始的 rect_to_polar 函数返回一个结构。为了充分利用指针效率，你应该使用指针而不是返回值。这样做的方法是向函数传递两个指针。第一个指向要转换的结构，第二个指向要保存转换结果的结构。函数不是返回新结构，而是修改调用函数中的现有结构。因此，第一个参数是 const 指针，第二个不是 const。否则，你应用与将 show_polar() 转换为指针参数相同的原则。清单 7.13 显示了重写后的程序。
