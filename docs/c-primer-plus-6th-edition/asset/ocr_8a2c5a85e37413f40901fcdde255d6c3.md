# Returning an Error Code

A more flexible approach than aborting is to use a function's return value to indicate a problem. For example, the get(void) member of the ofstream class ordinarily returns the ASCII value EOF if it encounters the end-of-file. This approach doesn't work for hmean(). Any numeric value could be a valid return value, so there's no value available to indicate a problem. In this kind of situation, you use a pointer or a reference argument to get a value back to the calling program and use the function return value to indicate success or failure. The ifstream uses overloaded >> operators a variant of this technique. By informing the calling program of the success or failure, you give the program the option of taking actions other than aborting. Listing 15.8 shows an example of this approach. It redefines hmean() as a bool function whose return value indicates success or failure. It adds a third argument for obtaining the answer.
