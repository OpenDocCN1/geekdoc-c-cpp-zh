# Constructors and Destructors in Review

Now that we've gone through a few examples of constructors and destructors, you might want to pause and assimilate what has passed. To help you, here is a summary of these methods.

A constructor is a special class member function that's called whenever an object of that class is created. A class constructor has the same name as its class, but through function overloading, you can have more than one constructor with the same name, provided that each has its own signature, or argument list. Also a constructor has no declared type. Usually a constructor is used to initialize members of a class. Your initialization method should match the constructor's argument list. For example, suppose the Bozo class has the following prototype for a class constructor:

```
Bozo(const char * fname, const char * lname); // constructor prototype
```

In this case, you can use it to initialize new objects as follows:

```
Bozo bozzetta = bozo("Bozzetta", "Biggens"); // primary form
Bozo fufu("Pufu", "O'Deweeb"); // short form
Bozo *pc = new Bozo("Popo", "Le Pew"); // dynamic object
```

If C++11 rules are in effect, you can use initialization instead:

```
Bozo bozzetta = bozo("Bozzetta", "Biggens"); // C++11
Bozo fufu("Pufu", "O'Deweeb"); // C++11;
Bozo *pc = new Bozo("Popo", "Le Pew"); // C++11
```

If a constructor has one argument, the constructor is invoked if you initialize an object to a value that has the same type as the constructor argument. For example, suppose you have this constructor prototype:

```
Bozo(int age);
```

Then you can use any of the following forms to initialize an object:

```
Bozo drizzle = bozo(44); // primary form
Bozo roon(66); // secondary form
Bozo tubby = 32; // special form for one-argument constructors
```

Actually, the third example is a new point, not a review point, but it seemed like a nice time to tell you about it. Chapter 11 mentions a way to turn off this feature because it can lead to unpleasant surprises.

# Caution

A constructor that you can use with a single argument allows you to use assignment syntax to initialize an object to a value:

```
Classname object = value;
```

This feature can cause problems, but it can be blocked, as described in Chapter 11.
