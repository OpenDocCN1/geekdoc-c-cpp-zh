The vararray has many features besides the ones discussed so far. For example, if numbers is a vararray<double> object, the following statement creates an array of bool numbers with vbool[i] set to the values [i]—that is, to true or false: vararray<bool> vbool = numbers > 9;

There are extended versions of subscribing. Let's look at one—the slice class. A slice object can be used as an array index, in which case it represents, in general, not just value but a subset of values. A slice object is initialized to three integer values: the start, the number, and the stride. The start indicates the index of the first element to be selected, the number indicates the number of elements to be selected, and the stride represents the spacing between elements. For example, the object constructed by slice(1,4,3) means the four elements whose indices are 1, 4, 7, and 10. That is, add stride to the next element, and so on until four elements are selected. If, varint is a vararray<int> object, then the following statement would select elements 1, 4, 7 and 10 to the value:

```
varint slice[1,4,3] = 10; // set elements to 10
```

This special facility allows you to use a one-dimensional vararray object to represent two-dimensional data. For example, suppose you want to represent an array with 4 rows and 3 columns.You store the information in a 12-element vararray object.Then a slice(0,3,i) object used as a subscript would represent elements 0, 1, and 2—that is, the first row. Similarly, a slice(0,4,3) subscript would represent elements 0, 3, 6, and 9—that is the first column. Listing 16.21 illustrates some features of slice.
