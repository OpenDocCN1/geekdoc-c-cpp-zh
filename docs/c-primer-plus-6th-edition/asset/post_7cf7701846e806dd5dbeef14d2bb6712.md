## Initialization Rules for Arrays

C++ has several rules about initializing arrays. They restrict what you can do, and they determine what happens if the number of array elements doesn't match the number of values in the initializer. Examine these rules:

You can use this initialization only when defining the array. You cannot use it later, and you cannot assign one array wholesale to another:

```cpp
int cards[4] = {3, 6, 8, 10}; // okay
int hand[4];             // okay
hand[4] = {5, 6, 7, 9}; // not allowed
hand = cards;           // not allowed
```

But you can use subscripts and assign values to the elements of an array individually. When initializing an array, you can provide fewer values than array elements. For example, the following initializes only the first two elements of `hotelTips`:

```cpp
float hotelTips[5] = {5.0, 2.5};
```

If you partially initialize an array, the compiler sets the remaining elements to zero. Thus, it's easy to initialize all elements of an array to zero—just explicitly initialize the first element to zero and then let the compiler initialize the remaining elements to zero:

```cpp
long totals[500] = {0};
```

Note that if you initialize to {1} instead of {0}, the first element is set to 1; the rest get set to 0.

If you leave the square brackets [] empty when you initialize an array, the C++ compiler counts the elements for you. Suppose, for example, that you make this declaration:

```cpp
short things[] = {1, 5, 3, 8};
```

The compiler makes `things` an array of four elements.

## Letting the Compiler Do It

Often, letting the compiler count the number of elements is poor practice because its count can be different from what you think it should be. You could, for instance, accidentally omit an initial value from the list; however, this approach can be a safe one for initializing character array to string, and if your main concern is the program, you know how large an array is, you can do something like this:

```cpp
short things[] = {1, 5, 3, 8};
int num_elements = sizeof things / sizeof(short);
```

Whether this is useful or lazy depends on the circumstances.

## C++11 Array Initialization

As Chapter 3, "Dealing with Data," mentioned, C++11 makes the brace form of initialization (list-initialization) a universal form for all types. Arrays already use list-initialization, but the C++11 version adds a few more features.

- First, you can use sign when initializing an array:

```cpp
double earnings[4] = {1.2e4, 1.6e4, 1.1e4, 1.7e4}; // with C++11
```

- Second, you can use empty braces to set all the elements to 0

```cpp
unsigned int counts[10] = {}; // all elements set to 0
float floats[] = {}; // all elements set to 0
```

Third, as discussed in Chapter 3, list-initialization protects against narrowing:

```cpp
// The following would cause a compile error because of narrowing conversion
int x = {3.14}; 
```

## Strings

A string is a series of characters stored in consecutive bytes, terminated by a null character. The null character, represented by `'\0'`, is used to mark the end of the string. C++ has two ways of dealing with strings: the first is to use a char array, and the second is to use the string class from the Standard Template Library (STL).

The char array approach is more low-level. To initialize a char array, you can list each character individually:

```cpp
char greeting[6] = {'H', 'e', 'l', 'l', 'o', '\0'};
```

However, it is much easier to use a string literal, which automatically includes the null character:

```cpp
char greeting[] = "Hello";
```

The `string` class is much more powerful and flexible. It handles memory management automatically and provides a wide range of functions for manipulating strings.
