# Stream States

Let's take closer look at what happens for inappropriate input. A cin or cout object\contains a data member (inherited from the ios_base class) that describes the stream state.
A stream state (defined as type iostate, when in, is a bitmask type, such as
described earlier) consists of three ios_base elements: eofbit, badbit, and failbit.
Each element is a single bit that can be set (1) or cleared (0). When a operation
eaches the end of a file, it sets eofbit. When a operation fails to read the expected
characters, in the earlier example, it sets failbit. IO failures, such as trying to read a
on-accessible file or writing to a write-protected disk, also can set failbit to 1.
The badbit element is set when some undiagnosed failure may have corrupted the
stream. (Implementations do not necessarily agree about which events set failbit and
set badbit.) When all of these three states are set to 0, everything is fine. Pro-
grams can check the stream state and use that information to decide what to do next.
Table 17.4 lists these bits, along with some ios_base methods that report or alter the
stream state.

# Table 17.4 Stream States

| Member | Description |
| --- | --- |
| eofbit | Is set to 1 if end-of-file reached. |
| badbit | Is set to 1 if stream may be corrupted; for example, there could be a file read error. |
| failbit | Is set to 1 if an input operation failed to read the expected characters or an output operation failed to write the expected characters. |
| good | Just another saying 0. |
| good() | Returns true if the stream can be used (all bits are cleared). |
| eof() | Returns true if eofbit is set. |
