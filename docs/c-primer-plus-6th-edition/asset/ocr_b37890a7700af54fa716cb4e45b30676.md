# Procedural and Object-Oriented Programming

Although in this book we occasionally explored the OOP perspective of programming, we will usually stick pretty close to the standard procedural approach of languages as C, Pascal, and BASIC. Let's look at an example that clarifies the OOP out-look differs from that of procedural programming.

As the newest member of the Giants softball team, you've been asked to keep the team statistics. Naturally, you turn to your computer for help. If you were a procedural programmer, you might think along these lines:

> Let's say, I want to enter name, times at bat, number of hits, batting averages (for those who don't follow baseball or softball, the batting average is the number of hits divided by the player's official number of times at bat; at a bat terminates when a player gets on base or makes out, but certain events, such as getting a walk, don't count as official times at bat), and all those other basic statistics for each player. Wait, the computer is supposed to make life easier for me, so I want to figure it out of that, such as the batting average. Also I want the program to report the results. How should I organize this? I guess I do things right and use functions. Yeah, I make `main()` call a function to get the input, another function to make the calculations, and then a third function to report the results. what happens when I get data from the next? I don't want to start from scratch again. Okay, I can add a function to update the statistics. Maybe I'll need a `main()` Hmmm...how am I going to represent the data? I could use an array of strings to hold the players' names, another name to hold the hits at bats each player, another name to hold the hits, and so on. No, that's dumb. I can design a structure to hold all the information for a single player and use an array of structures to represent the whole team.

In short, with a procedural approach, you will concentrate on the procedures you will follow and think about how to represent the data. (So that you don't have to keep the program running the whole season, you probably want to be able to save data to a file and read data from a file.)
