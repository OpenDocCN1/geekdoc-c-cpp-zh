
# Program Notes

The following is the input part of the program in Listing 6.5:

```
cin >> temp;
while (i < ArSize && temp >= 0) // 2 quitting criteria
{
    naaq[i] = temp;
    ++i;
    if (i < ArSize)             // room left in the array
    {
        cout << "Next value: ";
        cin >> temp; // so get next value
    }
}
```

The program begins by reading the first input value into a temporary variable called temp. Then the while test condition checks whether there is room left in the array (i < ArSize) and whether the input value is non-negative (temp >= 0). If it is, the program copies the value to the array and increases the index by one. That is, because array numbering starts at zero, i equals 0, the first cycle through the loop assigns a value to naaq[0] and then sets i to 1.

The loop terminates when the array is filled or when the user enters a negative number. Note that the loop reads another value into temp only if i is less than ArSize—that is, only if there is still room left in the array.

After it gets data, the program uses an if else statement to comment if no data was entered (that is, if the first entry was a negative number) and to process the data if any is present.

# Range Tests

Note that each part of a range test should use the AND operator to join two complete relational expressions:

```
if (age > 17 && age < 35)    // OK
```

Don't borrow from mathematics and use the following notation:

```
if (17 < age < 35)          // Don't do this!
```

If you make this mistake, the compiler will catch it as an error because it is still valid C++ syntax. The `<` operator associates from left to right, so the previous expression means the following:

```
if ( (17 < age) < 35)
```

But *17 < age* is either true, or 1, else false, or 0. In either case, the expression 17 < age less than 35, so the entire test is always true!

# The Logical NOT Operator : !

The `!` operator operates, or reverses the true value of, the expression that follows. That is, if expression is true, then `!expression` is false—and vice versa. More precisely, if expression is true, or nonzero, then `!expression` is false. Incrementally, many people call the exclamation point *bang*, making it `“bang-ex”` and `!!“bang-ex”`.

Usually you can clearly express a relationship without using the operator:

```
if (!(x > 5))                // if (x <= 5) is clearer
```

But the operator can use with functions that return true/false values or values that can be interpreted. For example, `strcmp(s1,s2)` returns a nonzero (true) value if the C-style strings `s1` and `s2` are different from each other and a zero value if they are the same. They are the: `strcmp(s1,s2)` is true if the two strings are equal.

The de-defined function `is_int()`, we will further discuss in a moment, returns true if its argument is within the range of values that can be assigned to type int. The program then uses the test

# Range Tests

Note that each part of a range test should use the AND operator to join two complete relational expressions:

```
if (age > 17 && age < 35)    // OK
```

Don't borrow from mathematics and use the following notation:

```
if (17 < age < 35)          // Don't do this!
```

If you make this mistake, the compiler will catch it as an error because it is still valid C++ syntax. The `<` operator associates from left to right, so the previous expression means the following:

```
if ( (17 < age) < 35)
```

But *17 < age* is either true, or 1, else false, or 0. In either case, the expression 17 < age less than 35, so the entire test is always true!

# The Logical NOT Operator : !

The `!` operator operates, or reverses the true value of, the expression that follows. That is, if expression is true, then `!expression` is false—and vice versa. More precisely, if expression is true, or nonzero, then `!expression` is false. Incrementally, many people call the exclamation point *bang*, making it `“bang-ex”` and `!!“bang-ex”`.

Usually you can clearly express a relationship without using the operator:

```
if (!(x > 5))                // if (x <= 5) is clearer
```

But the operator can use with functions that return true/false values or values that can be interpreted. For example, `strcmp(s1,s2)` returns a nonzero (true) value if the C-style strings `s1` and `s2` are different from each other and a zero value if they are the same. They are the: `strcmp(s1,s2)` is true if the two strings are equal.
