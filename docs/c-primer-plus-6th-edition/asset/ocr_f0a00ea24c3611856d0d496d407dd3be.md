# C++ Inline Functions

```
int main()
{
    hubba (2);
    hubba (4);
    hubba (10);
    ...
}
```

```
int main()
{
    n = 2;
    for (int i = 0; i < n; i++)
        cout << "hubba!";
        cout << "\n";
}...
```

```
n = 10;
for (int i = 0; i < n; i++)
    cout << "hubba!";
    cout << "\n";
}
```

```
void hubba(int n)
{
    for (int i = 0; i < n; i++)
        cout << "hubba!";
        cout << "\n";
}
```
