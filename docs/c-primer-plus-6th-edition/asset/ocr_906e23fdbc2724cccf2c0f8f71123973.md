# The string Class 955

This particular example app a C-style string to a string object. However, the += operator is multiply overloaded so that you can also append string objects and single characters:

```
one = two; // append string object (not in program)
one += '!'; // append a type char value (not in program)
```

Similarly, = operator is overloaded so that you can assign a string object to a string, a C-style string to a string object, or a simple char value to a string object:

```
two = "Sorry! That was "; // assign a C-style string
two = one; // assign a string object (not in program)
two = '?'; // assign a char value (not in program)"
```

Overloading the [] operator, as the String example in Chapter 12, permits access to individual characters in a string object by array notation:

```
three[0] = 'P';
```

A default constructor creates an empty string that later be given a value:

```
string four; // ctor #4
four = two + three; // overloaded += =
```

The second line uses the overloaded + to create a temporary string object, which is then assigned, so the overloaded = operator, to the four object. As you might expect, the + operator concatenates its two operands into a single string object. The operator is multiply overloaded, so the second operand can be a string object or a C-style string or a char.

The fifth constructor takes a C-style string and an integer argument, with the integer indicating how many characters to copy:

```
char als[] = "All's well that ends well";
string five(als,20); // ctor #5
```

Here, as output shows, just the first 20 characters "All's well that ends" are used to initialize the five object. As Table 16.1, if the character exceeds the length of the C-style string, the requested number of characters is still copied. Replacing 20 with 40 in the preceding example would result in 15 characters being copied at the end of five. (That is, the constructor would interpret the contents in memory following the string "All's well that ends well" as char characters.

The sixth constructor has a template argument:

```
template<class Iter> string(Iter, Iter);
```

The intent is that begin and end act like pointers to two locations in memory. (In general, begin and end can be iterators, generalizations of pointers extensively used in the STL.) The constructor then uses the values between the locations pointed to initialize the string object. The notation [begin, end), borrowed from mathematics, means the range begin but doesn't include end.
