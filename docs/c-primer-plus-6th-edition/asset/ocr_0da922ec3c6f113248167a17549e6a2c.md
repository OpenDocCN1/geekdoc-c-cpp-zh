# The const Qualifier

note #define statements earlier in this chapter (see the sidebar "Symbolic Constants
Preprocessor Way") promises that C++ has a better way to handle symbolic constants.
That way is to use the const keyword to modify a variable declaration and initialization.
Suppose, for example, that you use a symbolic constant for the number of months in a
Year. Just enter this line in a program:

```
const int Months = 12; // Months is symbolic constant for 12
```

Now you can use Constants in a program instead of 12. (A bare 12 in a program might
represent the number of months in a foot or the number of donuts in a dozen, but the
name tells you what the value 12 represents.) After you initialize a constant as
Months, its value is set. The compiler does not let you change the value
Months. If you try to, for example, g++ gives an error that the program used
asignment of a read-only variable. The keyword is termed a qualifier because it
qualifies the meaning of declaration.

A common practice is to capitalize the first character in a name to help remind your-
self Months is a constant. This is no universal constant, but it helps separa-
rate the constants from variables when you read a program. Another convention is to
make all the constants uppercase; this is the usual convention for constants created using
#define. Yet another convention is to begin constant names with the letter k, as in
months. And there are other conventions. Many organizations have particular coding
conventions they expect their programmers to follow.

The general form for creating a constant is:

```
const type name = value;
```

Note that you initialize a const in the declaration. The following sequence is no good:

```
const int toes; // value of toes undefined at this point
toes = 10; // too late!
```

If you don't provide a value when you declare the constant, it ends up with an unpre-
fied value you cannot modify.
If your background is in C, you might feel that the #define statement, which is dis-
cussed earlier, does the job adequately. For one thing, it lets
you specify the type. Second, use C++'s scoping rules to limit the defi-
nition to functions or files. (Scoping rules describe how widely known a name
is to different modules; you'll learn about this in more detail in Chapter 9,"Memory
Models and Namespaces.") Third, you can use const with more elaborate types, such as
arrays and structures, as discussed in Chapter 4.

Tip

If you are coming to C++ from C and are about to use #define to define a symbolic
constant, use const instead.

ANSI C uses the const qualifier, which it borrows from C++. If you're familiar
with the ANSI C version, you should be aware that the C++ version is slightly different.
