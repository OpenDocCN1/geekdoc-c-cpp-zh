## 数制

文明使用了许多系统来表示数字。有些系统，如罗马数字，不适合做算术。另一方面，印度数字系统，经修改并传至欧洲作为阿拉伯数字系统，促进了数学家、科学家和商人的计算。现代计算机系统基于首次出现在印度数字系统中的占位概念和使用零。然而，它们将这些原则推广到其他数制。虽然我们日常记数基于 10，如下一节所述，计算世界经常使用基于 8（八进制）、16（十六进制）和 2（二进制）的数字。

## 十进制数（基数 10）

我们书写数字的方法基于 10 的幂。例如，考虑数字 2,468。2 表示 2 千，4 表示 4 百，6 表示十，8 表示 8 个一：

2,468 = 2*1,000 + 4*100 + 6*10 + 8*1

一千是 10*10*10，可写为 10³，或十的 3 次方。使用此记法，我们可以这样写前面的关系：

2,468 = 2*10³ + 4*10² + 6*10¹ + 8*10⁰

因为这个数字基于 10 的幂，我们称其为基数 10，或十进制。你也可以使用另一个数字作为基数。例如，C++ 让你使用基数 8（八进制）和 16（十六进制或 hex）来书写整数数字。注意 10⁰ 是 1，就像任何非零数到零次方一样。

## 八进制整数（基数 8）

八进制数基于 8 的幂，因此基数 8 记法在书写数字时使用数字 0–7。C++ 使用 0 前缀来表示八进制记法。因此，0177 是一个八进制值。你可以使用 8 的幂来找到等价的基数 10 值：

| Octal | Decimal |
| --- | --- |

因为 Unix 操作系统经常使用值的八进制表示，C++ 可以提供八进制记法。

## 十六进制数（基数 16）

十六进制数基于 16 的幂。这意味着十六进制中的 10 代表值 16 + 0，或 16。为了表示 9 到十六进制 16 之间的值，你需要几个额外的数字。标准十六进制记法使用字母 a–f 用于此目的。C++ 接受这些字符的小写或大写版本，如表 A.1 所示。

| Hexadecimal Digit | Decimal Value |
| --- | --- |
| a or A | 10 |
| b or B | 11 |
| c or C | 12 |
| d or D | 13 |
| e or E | 14 |
| f or F | 15 |

C++ 使用 0x 或 0X 来表示十六进制记法。因此，0x2B3 是一个十六进制值。要找到 0x2B3 的十进制等价值，你可以计算 16 的幂：

| Hexadecimal | Decimal |
| --- | --- |
| 0x2B3 | = 2x16² + 11x16¹ + 3x16⁰ / = 2x256 + 11x16 + 3x1 / = 691 |

硬件文档经常使用十六进制记法来表示诸如内存位置和端口号之类的值。

## 二进制数（基数 2）

无论你使用十进制、八进制还是十六进制记法书写整数，计算机都将其存储为二进制，或基数 2。二进制记法仅使用两个数字 0 和 1。例如，10010111 是一个二进制数。注意，然而，C++ 不提供以二进制记法书写数字的方式。二进制数基于 2 的幂：

| Binary | Decimal |
| --- | --- |
| 10010111 | = 1×2⁷ + 0×2⁶ + 0×2⁵ + 1×2⁴ + 1×2³ + 0×2² + 1×2¹ + 0×2⁰ = 128 + 0 + 0 + 16 + 8 + 0 + 2 + 1 = 155 |

二进制记法与计算机内存非常匹配，其中每个单独的单元，称为位，可以设置为或关闭。如果你将偏移识别为 0 并将设置识别为 1。内存通常以字节或八位组为单位使用，每个字节为 8 位。注意，如第 2 章“开始 C++”所述，C++ 中的字节不一定是 8 位，但本附录将遵循常见做法，使用二进制表示八位组。字节中的位按对应的 2 的幂编号。因此，最右边的位是位号 0，下一个位是 1，以此类推。例如，图 A.1 表示一个 2 字节整数。
