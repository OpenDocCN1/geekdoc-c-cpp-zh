# Adaptable Functions and Functor Adapters

The predefined functions in Table 16.12 are all adaptable. Actually, the STL has five related concepts: adaptable generators, adaptable unary functions, adaptable binary functions, adaptable predicates, and adaptable binary predicates.

What makes a functor adaptable is that it carries typedef members identifying its argument type and return type. The members are all result_type, first_argument_type, and second_argument_type, and they represent what they sound like. For example, the return type of a plus<int> is identified as plus<int>::result_type, and this would be a typedef for.

The significance of a functor being adaptable is that it can be used by function adapter objects, which assume the existence of these typedef members. For example, a function with an argument that is an adaptable functor can use the result_type member to declare a variable that matches the function's return type.
