# Function Overloading 413

Overloaded functions are analogous to verbs having more than one meaning. For example, Miss Piggy can root at the ball park for the home team, and she can run in soil for truffles. The context (one hopes) tells you meaning of root is intended in each case. Similarly, C++ uses the context to decide which version of an overloaded function is intended.

The key to function overloading is a argument list, also called the function signature. If two functions use the same name and types of arguments in the same order, they have the same signature; the variables names don't matter. C++ enables you to define two functions by the same name, provided that the functions have different signatures. The signature can differ in the number of arguments or in the type of arguments, or both. For example, you can define a set of () functions with the following prototypes:

```
void print(const char *str, int width); // #1
void print(double d, int width); // #2
void print(long l, int width); // #3
void print(int i, int width); // #4
void print(const char *str); // #5
```

When you use a () function, the compiler matches you to the prototype that has the same signature:

```
print("Pancakes", 15); // use #1
print("Syrup"); // use #5
print(1999.0, 10); // use #2
print(1999, 12); // use #4
print(1999L, 15); // use #3
```

For example, print("Pancakes", 15) uses a string and an integer as arguments, and it matches Prototype #1.

When you use overloaded functions, you need to be sure you use the proper types in the function call. For example, consider the following statements:

```
unsigned int year = 3210;
print(year, 6); // ambiguous call
```

Which prototype does the () call match? It doesn't match any of them! A lack of matching prototype doesn't automatically rule out one of the functions because C++ will try to use standard conversions to force a match. If, the only prototype is #2, the function call print(year, 6) would convert the year value to double. But in the early code there are three prototypes that take a number as the first argument, providing three different choices for converting year with this ambiguous situation, C++ rejects the function call as an error.

Some signatures appear to be different from each another nonetheless can coexist. For example, consider these two prototypes:

```
double cube(double x);
double cube(double & x);
```
