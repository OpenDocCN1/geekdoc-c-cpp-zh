# Listing 17.7 showwpt.cpp

```
// showwpt.cpp -- setting the precision, showing trailing point
#include <iostream>

int main()
{
    using std::cout;
    using std::ios_base;

    float price1 = 20.40;
    float price2 = 1.9 + 8.0 / 9.0;

    cout.setf(ios_base::showpoint);
    cout << "Furry Friends" is $\$ " << price1 << "!\n";
    cout << "Fiery Fiend" is $\$ " << price2 << "!\n";

    cout.precision(2);
    cout << "Furry Friends" is $\$ " << price1 << "!\n";
    cout << "Fiery Fiend" is $\$ " << price2 << "!\n";

    return 0;
}
```

Here is the output of the program in Listing 17.7, using the current C++ formatting:

"Furry Friends" is $20.4000!\n"Fiery Fiend" is $2.78889!\n"Furry Friends" is $20.\\n"Fiery Fiend" is $2.8!

This output shows the trailing zeros for the first line. The third line shows the decimal point but no trailing zeros because the precision has been set to 2 and two digits already have been displayed.

# More About setf()

The setf() method controls several other formatting choices besides the decimal point displayed, so let's take a look at it. The ios_base class has a protected data member in which individual bits (called flags in this context) control different formatting aspects, such as the number base and whether trailing zeros are displayed. Turning a flag is called setting the flag (or bit) and means setting the bit to 1. (Bit flags are the program equivalent to setting DIP switches to configure computer hardware). The hex, dec, and oct manipulators, for example, adjust the three flag bits that control the number base.

The setf() function provides another means of adjusting flag bits.
The setf() function has two prototypes. The first is:

fmtflags(int fmtflags);
