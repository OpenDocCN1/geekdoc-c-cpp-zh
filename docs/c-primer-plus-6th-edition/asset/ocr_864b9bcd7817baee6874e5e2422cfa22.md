# Chapter 16 The String Class and the Standard Template Library

```
void show(const vist v, int cols)
{
    using std::cout;
    using std::endl;

int lim = v.size();
for (int i = 0; i < lim; ++i)
{
    cout.width(3);
    cout << v[i];
    if (i % cols == cols - 1)
        cout << endl;
    else
        cout << ' ';
}
if (lim % cols == 0)
    cout << endl;
}
```

The operator + is defined for valarray objects, such as valint, and it's defined for a single element, such as valint[1]. But as the code in Listing 16.21 notes, the operator is not defined for slice-subscripted valarray units, such as valint[slice(1,4,3)]. Therefore, the program constructs full objects from the slices to enable addition:

```
vint(valint[slice(1,4,3)]) // calls a slice-based constructor
```
