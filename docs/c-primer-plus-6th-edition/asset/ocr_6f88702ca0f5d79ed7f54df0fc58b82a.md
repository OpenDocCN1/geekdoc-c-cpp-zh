# Turning a Bit On

The two operations each turn on the bit in lottabis that corresponds to the bit represented by bit:

```
lottabis = lottabis | bit;
lottabis |= bit;
```

Each sets the corresponding bit to 1, regardless of the former value of the bit. That's because ORing 1 with either 0 or 1 produces 1. All other bits in lottabis remain unaltered. That's ORing 0 with 0 produces 0, and ORing 0 with 1 produces 1.

# Toggling a Bit

The two operations each toggle the bit in lottabis that corresponds to the bit represented by bit. That is, they turn on if it is off, and turn off if it is:

```
lottabis = lottabis ^ bit;
lottabis ^= bit;
```

XORing 1 with 0 produces 1, turning an bit off, and XORing 1 with 1 produces 0, turning an an bit off. All other bits in lottabis remain unaltered. That's XORing 0 with 0 produces 0, and XORing 0 with 1 produces 1.

# Turning a Bit Off

The following operation turns off the bit in lottabis that corresponds to the bit represented by bit:

```
lottabis = lottabis & -bit;
```

These statements turn the bit off, regardless of its prior state. First, the operator -bit produces an integer with all bits set to 1 *except* the bit that was originally set to 1; that bit ANDing 0 with any result produces 0, thus turning that bit off. All other bits in lottabis are unchanged. That's ANDing 1 with any bit produces the value that bit had before.

Here's a brief way of doing the same thing:

```
lottabis & -bit;
```
