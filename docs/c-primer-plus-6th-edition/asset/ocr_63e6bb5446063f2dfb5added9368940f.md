wc report1 report2 report3

Here we is the program name, and report1,report2, and report3 are filenames passed to the program as command-line arguments.
++ has a mechanism for letting a program running in a command-line environment access the command-line arguments. You can use the following alternative function head for main():

```
int main(int argc, char *argv[])
```

The args represents the number of arguments on the command line. The count includes the command name itself. The argv variable is a pointer to a pointer to a char. This sounds a bit abstract, but you can treat arg as if it were an array of pointers to the command-line arguments, argv[0] being a pointer to the first character of a string holding the command name, argv[1] being a pointer to the first character of a string holding the first command-line argument, and so on. That is, argv[0] is the first string from the command line, and so on. For example, suppose you have the following command:

```
wc report1 report2 report3
```

In this case, argc would be 4, argv[0] would be wc, argv[1] would be report1, and so on. The following loop would print each command-line argument on a separate line:

```
for (int i = 1; i < argc; i++)
cout << argv[i] << endl;
```

Starting with i = 1 just prints the command-line arguments; starting with i = 0 would print the command name as.
Command-line arguments, of course, go-in-hand with command-line operating systems such as the Windows command prompt mode, Unix, and Linux. Other setups may allow you to use command-line arguments:

+   - Many IDEs (Integrated Development Environments) have an option for providing command-line arguments. Typically, you will have to navigate through a series of menu choices that lead to a box which you can type the command-line arguments. The exact set of steps varies from vendor to vendor and from to upgrade, so check your documentation.
- Many IDEs can produce executable files that run under in the Windows command prompt mode.
