对于输入，情况有点不同。只要输入足够短，可以放入数组中，使用鸟类动物进行输入是安全的。但是，使用鸟类进行输入是不合适的：

- 有些编译器将字符串字面量视为只读常量，如果你尝试向其写入新数据，会导致运行时错误。字符串字面量常量在 C++ 中是这种行为，但并非所有编译器都已从旧行为中更改。
- 有些编译器使用一个字符串字面量的副本来表示程序中该字面量的所有出现。

放大第二点。C++ 不保证字符串字面量是唯一存储的。也就是说，如果你在程序中多次使用字符串字面量 "wren"，编译器可能会存储该字符串的多个副本，也可能只存储一个副本。如果是后者，那么将 bird 设置为其中一个 "wren" 就会使其指向该字符串的唯一副本。向一个字符串读取值可能会影响你认为在别处独立的字符串。在任何情况下，由于 bird 指针被声明为 const，编译器会阻止任何尝试更改 bird 所指向位置内容的尝试。

更糟糕的是将信息读入 ps 所指向的位置。因为 ps 未初始化，你不知道信息会落到哪里。它可能会覆盖内存中已有的信息。坦白说，避免这些问题很容易：你使用一个足够大的 char 数组来接收输入，并且不要使用字符串常量来接收输入或使用未初始化的指针来接收输入。（或者你可以使用 std::string 对象而不是数组来规避这些问题）。

> 注意
当你将字符串读入程序风格的字符串时，你应该始终使用先前分配的内存的地址。该地址可以是数组名称的形式，也可以是指针已使用 new 初始化的形式。

接下来，注意以下代码实现了什么：

```
ps = animal;               // set ps to point to string
cout << animal << " at " << (int*) animal << endl;
cout << ps << " at " << (int*) ps << endl;
```

它产生以下输出：

fox at 0x0065fd30

因此 ps 显示字符串 "fox"，但 (int *) ps 显示字符串所在的位置。注意，给 ps 赋值不会复制字符串；它复制的是地址。这导致两个指针（animal 和 ps）指向同一内存位置和字符串。

要获取字符串的副本，你需要做更多。首先，你需要为字符串分配内存。你可以通过声明第二个数组或使用 new 来做到这一点。第二种方法需要你使存储适合字符串：

```
ps = new char[strlen(animal) + 1]; // get new storage
```

字符串 "fox" 并没有完全填满 animal 数组，因此这种方法会浪费空间。这段代码使用 strlen() 找到字符串的长度；它加一以获得长度，包括空字符。程序使用 new 分配刚好足够容纳字符串的空间。

接下来，你可能需要将字符串从 animal 数组复制到新分配的空间。你不需要给 ps 赋值，因为那只是更改 ps 中存储的地址并丢失程序访问新分配内存的唯一方式。相反，你需要使用 strcpy() 函数：

```
strcpy(ps, animal); // copy string to new storage
```

strcpy 函数接受两个参数。第一个是目标地址，第二个是要复制的字符串的地址。确保目标已分配并且有足够的空间容纳副本是你的责任。这里使用 strlen() 找到正确的大小并使用 new 获取空闲内存来实现这一点。

注意，通过使用 strcpy() 和 new，你获得了 "fox" 的两个独立副本：

```
fox at 0x0065f430
fox at 0x004301c8
```

注意，我们将新存储定位在远离 animal 的内存位置。

你经常会遇到需要将字符串放入数组的需求。你在初始化数组时使用运算符；否则，你使用 strcpy() 或 strncpy()。你已经见过 strcpy() 函数；它工作如下：

```
char food[20] = "carrots"; // initialization
strcpy(food, "flan"); // otherwise
```

注意，像下面这样的东西可能会导致问题，因为 food 数组比字符串小：

```
strcpy(food, "a picnic basket filled with many goodies");
```

# 使用 new 创建动态结构

你已经看到在运行时而不是编译时创建数组是有利的。结构也是如此。你只需要为程序在常规运行期间需要的结构数量分配空间。同样，new 运算符是使用的工具。有了它，你可以创建动态结构。同样，动态意味着内存是在运行时分配的，而不是在编译时分配的。顺便说一下，因为类与结构非常相似，你能够将本节中学到的技术用于结构和类。

使用 new 与结构有两个部分：创建结构和访问其成员。要创建结构，使用 new 与结构类型。例如，要创建 inflatable 类型的未命名结构并将其地址分配给合适的指针，你可以使用以下内容：

```
inflatable * ps = new inflatable;
```

这将 ps 分配为一块足够大的空闲内存的地址，可以容纳 inflatable 类型的结构。注意，语法与 C++ 内置类型完全相同。

棘手的部分是访问成员。当你创建动态结构时，你使用结构名称的点成员运算符，因为结构没有名称。你只有它的地址。C++ 为这种情况提供了一个运算符：箭头成员运算符 (->)。该运算符由连字符后跟大于号组成，对于指向结构的指针，它的作用与点运算符对结构名称的作用相同。例如，如果 ps 指向类型为 inflatable 的结构，那么 ps->price 就是指向结构的 price 成员（参见图 4.11）。

> 提示
有时新的 C++ 用户会混淆何时使用点运算符以及何时使用箭头运算符来指定结构成员。规则很简单：如果结构标识符是结构的名称，则使用点运算符。如果标识符是指向结构的指针，则使用箭头运算符。

访问结构成员的第二种，更丑陋的方法是意识到如果 ps 是指向结构的指针，(*ps) 表示指向的结构本身。然后，因为 ps 是一个结构，(*ps).price 是结构的 price 成员。C++ 运算符优先级规则要求你在这种构造中使用括号。
