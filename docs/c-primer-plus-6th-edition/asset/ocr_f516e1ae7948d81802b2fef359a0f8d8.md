# 1002 Chapter 16 The String Class and the Standard Template Library

```
int casts[10] = {6, 7, 2, 9, 4 , 11, 8, 7, 10, 5};
vector<int> dice[10];
copy(casts, casts + 10, dice.begin()); // copy array to vector
```

The first iterator arguments to copy() represent the location to where the first item is copied. The first two arguments must be input iterators (or better), the final argument must be an output iterator (or better). The copy() function overwrites existing data in the destination container, and the container has to be large enough to hold the copied elements. So you can use copy() to place data in an empty vector—at least not resorting to a trick that is revealed later in this chapter.

Now suppose you want to copy information to the display. You could use copy() if there was an iterator representing the output stream. The STL provides such an iterator with ostream_iterator. Using STL terminology, this template is a model of the output iterator. It is also an example of an adapter—class or function that converts some other interface to an interface used by the STL. You can create an iterator of this kind by including the iterator (formerly iterator.h) header file and making a declaration:

```
#include <iterator>
```

```
...
ostream_iterator<int, char> out_iter(cout, " ");
```

The out_iterator becomes an adapter that allows you to use cout to display information. This first template argument (int, in this case) indicates the data type being sent to the output stream. The second template argument (char, in this case) indicates the character type used by the output stream.(Another possible value would be wchar_t). The first constructor argument (cout, in this case) identifies the output stream being used. It could also be a stream for file output. The final character argument is a separator to be displayed after each item sent to the output stream.

You could use the iterator:

```
*out_iter++ = 15; // works like cout << 15 << "
```

For a regular pointer, this would mean assigning the value 15 to the pointed-to-location and incrementing the pointer. For this ostream_iterator, however, the state means sending 15 and then a string consisting of a space to the output stream managed by cout. Then it should get ready for the next output operation. You could use the iterator with copy() as follows:

```
copy(dice.begin(), dice.end(), out_iter); // copy vector to output stream
```

This would mean copying the entire range of the dice container to the output stream—that is, to display the contents of the container

Or you could skip creating a named iterator and construct an anonymous iterator instead. That is, you could use the adapter like this:

```
copy(dice.begin(), dice.end(), ostream_iterator<int, char>(cout, " "));
```
