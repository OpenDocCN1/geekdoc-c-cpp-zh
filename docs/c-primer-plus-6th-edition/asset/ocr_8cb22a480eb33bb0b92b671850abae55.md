# Program Notes

The main() function in Listing 7.3 uses a while loop to provide repeated input (and to keep your loop skills fresh). Note that it uses cin >> rather than cin.get(ch) or ch = cin.get(ch) to read a character. There's a good reason for this. Recall that the cin.get() reads all characters, including spaces and newlines, whereas cin >> skips spaces and newlines. When you respond to the prompt, you have to press Enter at the end of each line, generating a newline. The cin >> approach completely skips these newlines, but the cin.get() reads the newline following each number entered as the next character to display. You can program around this nuisance, but it's simpler to use two arguments: a character c as the program in Listing 7.3.
The_chars() function takes the character c and an integer n. It uses a loop to display the character number of times the integer specifies:

```
while (n-- > 0)           // continue until n reaches 0
    cout << c;
```

Notice that the program decrements the n variable, where n is the formal parameter from the argument list. This variable is assigned the value of the times variable in main(). The while loop decreases n to 0, but the sample run-strategies, changing the value of n has no effect on times. Even if you use the name n instead of times in main(), the value of n in main() is unaffected by changes in the value of n in n_chars().

For example, you might get to pick six numbers from a card having 51 numbers. Then the Lotto managers pick numbers at random. If your choice matches theirs, you win a million dollars or so. Our function will calculate the probability that you have a winning pick.
