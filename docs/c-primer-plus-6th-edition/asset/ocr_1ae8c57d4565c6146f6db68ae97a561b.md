# Chapter 7 Functions: C++s Programming Modules

```
const double * f1(const double ar[], int n);
const double * f2(const double [], int int);
const double * f3(const double *, int int);
```

The signatures might look different, but they are the same. First, recall that in a function- prototype parameter list const double and const double * have exactly the same meaning. Second, recall that in a prototype you can omit identifiers. Therefore, const double ar[] can be reduced to const double [], and const double * ar can be reduced to const double *. So all the function signatures show previously have the same meaning. Function definitions, on the other hand, provide identifiers, so either const ar[] or const double * ar serve in that context.

Next, suppose you wish to declare a pointer that can point to one of three functions. The technique, you'll recall, is if pa is the desired pointer, take the prototype for a target function and replace the function name with (*pa):

```
const double * (*p1)(const double *, int);
```

This can be combined with initialization:

```
const double * (*p1)(const double *, int) = f1;
```

With the C++11 automatic type deduction, you can simplify this by:

```
auto p2 = f2; // C++11 automatic type deduction
```

Now consider the following statements:

```
cout << (*p1)(av,3) << ": " << (*p1)(av,3) << endl;
cout << p2(av,3) << ": " << *p2(av,3) << endl;
```

Both (*p1)(av,3) and p2(av,3), recall, calling the pointed-to functions (f1) and f2 (), in this case with av and 3 arguments. The return values of these two functions. The return values are const double * (that is, address of value). So the first part of each cout expression should print the address of double value. To see the actual value stored at the addresses, we need to apply the * operator to these addresses, and what's the expressions (*p1)(av,3) and *p2(av,3) do.

With three functions to work with, it could be handy to have an array of function pointers. One could use each function, via its pointer, in turn. What would that look like? Clearly, it would look something like the declaration of a single pointer, there would be a [3] somewhere to indicate an array of three pointers. The question is where. Here is the answer (initialization):

```
const double * (*pa3)(const double *, int) = {f1,f2,f3};
```

Why the pa[3]? Well, pa is an array of three strings, and the starting for declaring an array of three things is this: pa[3]. The rest of the declaration is about what kind of thing is to be placed in array. Operator precedence ranks [] higher than *, so pa[3] says pa is an array of three pointers. The rest of the declaration indicates what each pointer points to: a function with a signature of const double *, int and return
