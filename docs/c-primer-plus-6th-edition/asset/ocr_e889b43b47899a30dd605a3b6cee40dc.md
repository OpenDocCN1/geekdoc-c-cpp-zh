# C++11 Null Pointer

In C++98, the literal O has two meanings—it can be the numeric 0, and it can be the null pointer—making it difficult for the reader and compiler to distinguish between the two. Some programmers use (void *) to identify the pointer version.(The null pointer itself may have a nonzero representation). Other programmers use NULL, a C macro to represent the null pointer. However, this proved to be an incomplete solution. C++11 provides a better solution by introducing a new keyword, nullptr, the null pointer. You can use O as before—otherwise an enormous amount of existing code would be invalidated—but henceforth the recommendation is to use nullptr instead:

```
str = nullptr; // C++11 null pointer notation
```
