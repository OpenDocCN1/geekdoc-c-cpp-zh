> It is usually a good idea to define a const value to represent the number of elements in an
array. You can use the const value in the array declaration and in all other references to the
array size, such as in a for loop.

The limit expression < ArraySize reflects the fact that subscripts for an array with
ArraySize elements run from 0 to ArraySize, the array index should stop one before
ofArraySize. You could use it << ArraySize - 1 instead, but it looks awkward in
comparison.
Note that the program declares the const variable ArraySize outside the body of
main(). mentions this makes ArraySize exter-
data. The two consequences of declaring ArraySize in this fashion are that ArraySize exists
for the duration of the program and that all functions in the program can use it. In this
particular case, the program has just one, so declaring ArraySize externally has little
practical effect. But multifunction programs often benefit from sharing external constants,
so we'll predict using them next.
