The | = operator combines the bitwise OR operator with assignment:

```
a |= b; // set a to a | b
```

The bitwise XOR operator (*) combines two integer values to produce a new integer. Each bit in the new value is set to 1 if one or the other, but not both, of the corresponding bits in the original values is set to 1. If both corresponding bits are 0 or both are 1, the final bit is set to 0 (see Figure E.5).
