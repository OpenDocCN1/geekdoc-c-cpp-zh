```
            std::cout << "Harmonic mean of " << x << " and " << y << " is " << z << std::endl;

        return false;

        return true;
    }
}
```

## 异常机制

现在让我们看看如何使用异常机制处理问题。C++ 异常是对程序运行期间出现的异常情况的响应，例如尝试除以零。异常提供了一种将控制权从程序的一个部分转移到另一个部分的方法。处理异常有三个组成部分：

- 抛出异常
- 使用处理器捕获异常
- 使用 try 块

当出现问题时，程序会抛出异常。例如，你可以修改列表 15.7 中的 `hmean()` 使其抛出异常而不是调用 `abort()` 函数。throw 语句本质上是一次跳转；也就是说，它告诉程序跳转到另一位置的语句。`throw` 关键字表示抛出异常。它后面跟着一个值，例如字符串或对象，表示异常的性质。

程序在想要处理的地方使用异常处理器捕获异常。`catch` 关键字表示捕获异常。处理器以关键字 `catch` 开头，后面跟着括号中的类型声明，表示它响应的异常类型。然后，后面跟着一个用大括号括起来的代码块，表示要采取的行动。`catch` 关键字连同异常类型一起充当标签，标识当抛出异常时执行应跳转到的程序点。异常处理器也称为 catch 块。

try 块标识一个代码块，其中特定异常将被激活。它后面跟着一个或多个 catch 块。try 块由关键字 try 表示，后面跟着一个用大括号括起来的代码块，表示将注意到异常的代码。

最简单地了解这三个元素如何协同工作的方法是查看一个简短的示例，例如列表 15.9 中的示例。

### 列表 15.9 error3.cpp

```
// error3.cpp -- using an exception
#include <iostream>
double hmean(double a, double b);

int main() {
    double x, y, z;

    std::cout << "Enter two numbers: ";
    while (std::cin >> x >> y) {
        try { // start of try block
            z = hmean(x,y); // end of try block
        } catch (const char * s) { // start of exception handler
            std::cout << s << std::endl;
            std::cout << "Enter a new pair of numbers: ";
            continue; // end of handler
        }
        std::cout << "Harmonic mean of " << x << " and " << y
            << " is " << z << std::endl;
        std::cout << "Enter next set of numbers <q to quit>: ";
    }
    std::cout << "Bye!\n";
    return 0;
}

double hmean(double a, double b) {
    if (a == -b)
        throw "bad hmean() arguments: a = -b not allowed";
    return 2.0 * a * b / (a + b);
}
```

以下是列表 15.9 程序的示例运行。

```

Harmonic mean of 3 and 6 is 4
Enter next set of numbers <q to quit>: 10 -10
bad hmean() arguments: a = -b not allowed
Enter a new pair of numbers: 1 19
Harmonic mean of 1 and 19 is 1.9
Enter next set of numbers <q to quit>: q
Bye!
```

## 程序说明

列表 15.9 中的 try 块如下所示：

```
try {
    // start of try block
    z = hmean(x,y);
    // end of try block
}
```

如果此块中的任何语句导致抛出异常，则此块之后的 catch 块将处理该异常。如果程序在该 try 块（或任何其他 try 块）之外调用 hmean()，它将没有机会处理异常。

抛出异常如下所示：

```
if (a == -b)
    throw "bad hmean() arguments: a = -b not allowed";
```

在这种情况下，抛出的异常是字符串 "bad hmean() arguments: a = -b not allowed"。异常类型可以是字符串，如本例所示，也可以是其他 C++ 类型。类类型是通常的选择，正如本章中的示例所说明的那样。

执行 throw 有点像执行 return 语句，因为它终止了函数执行。但是，与将控制权返回给调用程序不同，throw 会导致程序通过当前函数调用的序列回溯，直到找到包含 try 块的函数。在列表 15.9 中，该函数与调用函数相同。很快你会看到一个涉及回溯多个函数的示例。在这种情况下，throw 将程序控制权返回给 main()。在那里，程序会查找与抛出的异常类型匹配的异常处理器（位于 try 块之后）。

处理器或 catch 块如下所示：

```
catch (const char * s) // start of exception handler
{
    std::cout << s << std::endl;
    std::cout << "Enter a new pair of numbers: ";
    continue;
} // end of handler
```

catch 块看起来有点像函数定义，但它不是。关键字 catch 将其标识为处理器，而 const char * s 表示此处理器匹配抛出的字符串异常。此 s 的声明在抛出匹配异常时就像函数参数定义一样。此外，如果异常与此处理器不匹配，程序将执行大括号内的代码。

如果程序在 try 块中执行语句而未抛出任何异常，它将跳过 try 块之后的 catch 块或块，并转到处理器之后的第一个语句。因此，当列表 15.9 程序的示例运行处理值 3 和 6 时，程序执行直接转到输出语句并报告结果。

让我们追踪在将值 10 和 -10 传递给 hmean() 之后示例运行中发生的事件。如果它导致 hmean() 抛出异常。这将终止 hmean()。回溯，程序确定 hmean() 是从 main() 中的 try 块调用的。它查找具有与异常类型匹配的类型 catch 块。唯一的 catch 块具有 const char * 参数，因此匹配。检测到匹配后，程序将字符串 "bad hmean() arguments: a = -b not allowed" 分配给变量 s。接下来，程序执行处理器中的代码。首先，它打印 s，即捕获的异常。然后它指示用户输入新数据。最后，它执行 continue 语句，这会导致程序跳过循环的其余部分并再次跳转到其开头。continue 语句将程序带到循环开始的事实说明处理器是循环的一部分，并且 catch 行充当标签来指导程序流程（参见图 15.2）。

你可能会想知道如果函数抛出异常而没有 try 块或没有匹配的处理器会怎样。默认情况下，程序最终会调用 abort() 函数，但你可以修改这种行为。我们将在本章后面返回此主题。

## 使用对象作为异常

通常，函数抛出异常对象。这样做的一个重要优点是，你可以使用不同的异常类型来区分产生异常的不同函数和情况。对象可以携带信息，你可以使用此信息来识别导致抛出异常的条件。此外，在特定的 catch 块中可以使用该信息来决定采取什么行动。这里，例如，是 hmean() 函数可能抛出的异常的一种设计：

```
class bad_hmean {
private:
  double v1;
  double v2;
public:
  bad_hmean(double a = 0, double b = 0) : v1(a), v2(b) {}
```
