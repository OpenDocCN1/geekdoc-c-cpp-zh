# Other Useful Iterators

The iterator header file provides some special-purpose predefined iterator types in addition to iterator_iterator and istream_iterator.They are reverse_iterator, back_insert_iterator, front_insert_iterator, and insert_iterator.

Let's start with seeing what a reverse iterator does. In essence, reversing a reverse iterator causes it to decrement. Why not decrement a reverse iterator? The main reason is to simplify using existing functions. You can display the contents of the dice container. As you can see, you can use copy() and istream_iterator to copy the contents to the output stream:

```
ostream_iterator<int, char> out_iter(cout, " ");
copy(dice.begin(), dice.rend(), out_iter); // display in forward order

```

Now you want to print the contents in reverse order. (Perhaps you are forming-reverse-reversal studies).There are several approaches that don't work, but rather than within them, let's go to one does.The vector class has a member called rbegin() that returns a reverse iterator pointing to past-the-end and a member rend() that returns a reverse iterator pointing to the first element. Because incrementing a reverse iterator decrements it, you can use the following statement to display the contents backwards:

```
copy(dice.rbegin(), dice.rend(), out_iter); // display in reverse order

```

You don't have to declare a reverse iterator.
