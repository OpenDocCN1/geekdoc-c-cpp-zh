The destructor begins by announcing when the destructor gets. This part is informative but not essential. However, the delete statement is vital. Recall that the string member points to memory allocated with new. When a StringB object expires, the str pointer expires. But the memory str pointed to remains allocated unless you delete to free it. Deleting an object frees the memory occupied by the object itself, but it does not automatically free memory pointed to by pointers that were member objects. For that, you must use the destructor. By placing the delete statement in the destructor, you ensure that the memory that a constructor allocates new with the object expires.

Warning

Whenever you use new to allocate memory, you should use delete in the corresponding destructor to free that memory. If you use new [] (with brackets), then you should use delete [] (with brackets).
