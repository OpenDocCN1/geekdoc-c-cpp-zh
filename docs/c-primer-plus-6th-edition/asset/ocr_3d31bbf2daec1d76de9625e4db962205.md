Using protected members may simplify writing the code, but it has a design defect. For example, continuing with the BrassPlus example, if balance were protected, you could write code like this:

> **Caution**
You should prefer private to protected access control for class data members, and you should use base-class methods to provide derived classes to base-class data.

However, protected access control can be quite useful for member functions, giving derived classes access to internal functions that are not available publicly.
