# An Example of Using new and delete

Let's look at an example of how new and delete to manage string input from the keyboard. Listing 4.22 defines a function getname() that returns a pointer to an input string. This function reads the input into a temporary array and then uses [] with an appropriate size to create a chunk of memory sized to fit to the input string. The function returns the pointer to the block. This approach could conserve a lot of memory for programs that run a large number of strings. In real life, when many of us live, it would be easier to use the string class, which has the use of new and delete built into its design.

Suppose your program has to read 1,000 strings and the largest string could be 79 characters long, but most of the strings are much shorter than that. If you used char arrays to hold the strings, you'd need 1,000 arrays of 80 characters each. That's 80,000 bytes, and much of that memory would be being unused. Alternatively, you could create an array of 1,000 pointers to char and then use new to allocate only the amount of memory needed for each string. That saves tens of thousands of bytes. Instead of having to use a array for every string, you fit the memory to the input. Even better, you could also use new to find space to store only as many pointers as needed.
