# 函数和结构

让我们从数组转向结构。为结构编写函数比为数组编写函数更容易。虽然结构与数组相似，两者都可以保存多个数据项，但结构在函数中表现得像基本单值变量。也就是说，与数组不同，结构将其数据绑定到单个实体或数据对象，该对象将被视为一个单元。回想一下，你可以将一个结构赋给另一个结构。同样，你可以按值传递结构，就像处理普通变量一样。在这种情况下，函数使用原始结构的副本。函数也可以返回一个结构。没有像数组名称是其第一个元素的地址那样的奇怪情况。结构的名称就是结构的名称，如果你想要其地址，你必须使用 & 运算符。（C++ 和 C 都使用 & 符号来标识引用变量，将在第 8 章中讨论。）

使用结构进行编程的最直接方法是将其视为基本类型——也就是说，将其作为参数传递，并在必要时用作返回值。然而按值传递结构有一个缺点。如果结构很大，复制结构所需的空间和工作量可能会增加内存需求并减慢系统速度。出于这些原因（并且最初 C 不允许按值传递结构），许多 C 程序员更喜欢传递结构的地址然后使用指针访问结构内容。C++ 提供了第三种替代方案，称为按引用传递，将在第 8 章中讨论。让我们现在检查另外两种选择，从传递和返回整个结构开始。

```cpp
#include <iostream>
// Listing 7.11 - using structures

struct travel_time
{
    int hours;
    int mins;
};

const int Minsperhr = 60;

travel_time sum(travel_time t1, travel_time t2)
{
    travel_time total;
    total.hours = t1.hours + t2.hours + (t1.mins + t2.mins) / Minsperhr;
    total.mins = (t1.mins + t2.mins) % Minsperhr;
    return total;
}

int main()
{
    using namespace std;
    travel_time day1 = {5, 45};
    travel_time day2 = {4, 55};
    travel_time day3 = sum(day1, day2);
    cout << "Two-day total: " << day3.hours << " hours, " << day3.mins << " minutes\n";

    travel_time day4 = {10, 32};
    travel_time day5 = sum(day3, day4);
    cout << "Three-day total: " << day5.hours << " hours, " << day5.mins << " minutes\n";

    return 0;
}
```
