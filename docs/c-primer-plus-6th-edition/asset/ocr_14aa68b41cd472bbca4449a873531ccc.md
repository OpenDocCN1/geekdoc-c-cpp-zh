# Chapter 8 Adventures in Functions

This loop counts how many times you can remove a digit from n until none are left. Recall that n /= 10 is short for n = n / 10. If n is 8, for example, the test condition assigns to n the value 8 / 10, 0, because it's integer division. That terminates the loop, and digits remain at 1. If n is 238, the first loop test sets n to 238 / 10, 23. That's nonzero, so the loop increases digits to 2. The next cycle sets n to 2 / 10, or 0. Again, that's nonzero, so digits grows to 3. The next cycle sets n to 2 / 10, or 0, and the loop leaves, leaving digits to the correct value, 3.

Now suppose you have the number five and you want to return the first three digits. You can get that value by dividing the number by 10 and then dividing the answer by 10. Each division by 10 removes one more digit the right end. To calculate the number of digits to lop, you just subtract the number of digits to be shown from the total number of digits. For example, to show four digits of a nine-digit number, you lop off the five digits. You can do this approach as follows:

```
ct = digits - ct;
while (ct--)
num /= 10;
```

Listing 8.10 incorporates this code into a new left() function. The function includes some additional code to handle special cases, such as asking for zero digits or asking for more digits than the number possesses. Because the signature of the new left() differs from that of the old left(), you can use both functions in the program.

```
// leftover.cpp overloading the left() function
#include <iostream>
unsigned long left(unsigned long num, unsigned int ct);
char * left(const char *str, int n = 1);

int main() {
	using namespace std;
	char * trip = "Hawaii"; // test value
	unsigned long n = 12345678; // test value
	int i;
	char * temp;

for (i = 1; i < 10; i++) {
	cout << left(n, i) << endl;
	temp = left(trip,i);
	cout << temp << endl;

delete temp; // point to temporary storage
}
return 0;}
```
