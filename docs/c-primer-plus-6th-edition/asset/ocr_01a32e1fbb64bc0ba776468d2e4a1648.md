C++ also recognizes C comments, which are enclosed between /* and */ symbols:

```

```

Because the C-style comment is terminated by /* rather than the end of a line, you can spread it over more than one line. You can use either or both in your programs. # The C++ Preprocessor and the iostream File

Here's the short version of what you need to know. If your program is to use the usual C++ input or output facilities, provide these two lines:

```
#include <iostream>
using namespace std;
```

There are some alternatives to using the second line, but let's keep things simple for now. (If your compiler doesn't C++98 compatible, it will have many other problems with the examples in this book.) That all you really must know to make your programs work, but let's take a more in-depth look.

C++, like C, uses a preprocessor. This is a program that processes a source file before the main compilation takes place. (Some C++ implementations, you might recall from Chapter 1, use a translator to convert a C++ program to C) Although the translator is also a preprocessor; we're not discussing preprocessor; instead, we're discussing the one that handles directives beginning with #.) You don't have to do anything to invoke this preprocessor. It automatically operates when you compile the program.

Listing 2.1 uses the #include directive:

```
#include <iostream>    // a PREPROCESSOR DIRECTIVE
```

This directive tells the preprocessor to add the contents of the iostream file to your program. This is a typical preprocessor action: adding or replacing the text in the source code before it's compiled.

This raises the question of why you should add the contents of the iostream file to the program. The answer concerns communication between the program and the outside world. The io in iostream refers to input, which is information brought into the program, and to output, which is information sent out of the program.
