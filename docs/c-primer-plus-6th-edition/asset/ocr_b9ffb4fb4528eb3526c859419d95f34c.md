# # Just a Moment—Building a Time-Delay Loop

Sometimes its useful to build a time delay into a program. For example, you might have encountered programs that flash a message onscreen and then go on to something else before you read the message. You would end up amazed that you've missed irretrievable information of vital importance. It would be much nicer if the program passed 5 seconds before moving on. The while loop is handy for producing this effect. A technique from the early days of personal computers was to make the counter count for a while to use up time:

```
long wait = 0;
while (wait < 10000)
    // counting silently
    wait++;
```

The problem with this approach is that you have to change the clock limit when you change computer processor speed. The ANSI C and the C++ libraries have a function to help you do this. The function is called clock(), and it returns the time elapsed since a program started execution. There are a couple complications, First, clock() doesn't necessarily return time in seconds. Second, the return type might be long on some systems, unsigned on others, and perhaps on some other types.

But the etime header file time.h on less implementations provides solutions to these problems. It defines a symbolic constant, CLOCKS_PER_SEC, that equals the number of time units per second. Dividing the system time by this value yields seconds. Or you can multiply seconds by CLOCKS_PER_SEC to get the time in the system units. Second, etime establishes clock_t as an alias for the clock() return type. (See the sidebar "Type Aliases," later in this chapter). This means you can declare a variable as clock_t, and the compiler converts it to long or unsigned int whatever is proper for your system.
