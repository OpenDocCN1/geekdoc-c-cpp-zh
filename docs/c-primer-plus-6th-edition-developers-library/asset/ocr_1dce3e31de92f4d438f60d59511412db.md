Typecasting num to long makes sure the calculation is done as a long calculation, not an int calculation. On a system with a 16-bit int, multiplying two ints produces a result that is truncated to an int before the value is returned, possibly losing data.

```
long square(int num)
{
    return ((long) num) * num;
}
```
