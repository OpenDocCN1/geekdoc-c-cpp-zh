# Minimum-Width Types

The minimum-width types guarantee a type that is at least a certain number of bits in size. Table RS.V.27 lists the minimum-width types. These types always exist.

Table RS.V.27 Minimum Width Types

| typedef Name | Properties |
|---|---|
| int_least8_t | At least 8 bits signed |
| int_least16_t | At least 16 bits signed |
| int_least32_t | At least 32 bits signed |
| int_least64_t | At least 64 bits signed |
| uint_least8_t | At least 8 bits unsigned |
| uint_least16_t | At least 16 bits unsigned |
| uint_least32_t | At least 32 bits unsigned |

# Fastest Minimum-Width Types

For a particular system, some integer representations can be faster than others. So stdint.h also defines the fastest type for representing at least a certain number of bits. Table RS.V.28 lists the fastest minimum-width types. These types always exist. In some cases, there might be no clear-cut choice for fastest; in that case, the system simply specifies one of the choices.

Table RS.V.28 Fastest Minimum-Width Types

| typedef Name | Properties |
|---|---|
| int_fast8_t | At least 8 bits signed |
| int_fast16_t | At least 16 bits signed |
