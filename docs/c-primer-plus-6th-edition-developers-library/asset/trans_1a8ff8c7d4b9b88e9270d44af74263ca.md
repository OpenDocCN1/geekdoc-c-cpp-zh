## 扩展整数常量

stdint.h 头文件定义了一些宏，用于指定各种扩展整数类型的常量。本质上，该宏是对底层类型的一次类型转换——也就是对在特定实现中表示该扩展类型的基本类型进行强制转换。

宏名称的构成方式是：取类型名称，将 _t 替换为 _C，并将所有字母变为大写。例如，要将 1000 变为 uint_least64_t 类型的常量，可使用表达式 UINT_LEAST64_C(1000)。
