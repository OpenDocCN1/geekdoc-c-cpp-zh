# Character Handling: ctype.h

These functions take int arguments, which should be able to be represented as either unsigned char values or as EOF; the effect of supplying other values is undefined. In Table RS.V.4, “true” is used as shorthand for “a nonzero value.” Interpretation of some definitions depends on the current locale setting, which is controlled by the functions of locale.h; the table shows the interpretations for the “C” locale.
