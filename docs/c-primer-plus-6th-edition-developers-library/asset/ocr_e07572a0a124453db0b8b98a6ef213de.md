# Floating-point Characteristics: float.h

The float.h header file defines several macros representing various limits and parameters. Table RS.V.9 lists the macros, with C11 additions shown in italics. Many of the macros refer to this model of floating-point representation:

x = s b^e sum_{k=1}^{p} f_k b^{-k}

If the very first digit f1 is nonzero (and x is nonzero), the number is termed a normalized floating-point number. Section VIII of this appendix explains this and the meanings of some of these macros more fully.
