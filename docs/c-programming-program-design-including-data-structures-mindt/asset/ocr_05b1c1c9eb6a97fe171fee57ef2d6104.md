> > **NOTE**  
> > In this linked implementation of stacks, the memory to store the stack elements is allocated dynamically. Logically, the stack is never full. The stack is full only if we run out of memory space. Therefore, in reality, the function `isFullStack` does not apply to linked implementation of stacks. However, the class `linkedStackType` must provide the definition of the function `isFullStack`, because it is defined in the parent abstract class `stackADT`.
