From the errors reported by the compiler, we see that the compiler not only identifies

After correcting all of the syntax errors, a correct program is as follows:

```
    #include <iostream>

    using namespace std;

    int main()
    {
        int num;
        int tempNum;

        num = 18;

        tempNum = 2 * num;

        cout << "Num = " << num << ", tempNum = " << tempNum << endl;

        return 0;
    }
```

The output is:

Num = 18, tempNum = 36
