  $$
  \begin{aligned}
  a/b + c/d &= (ad + bc)/bd\\
  a/b - c/d &= (ad - bc)/bd\\
  a/b \times c/d &= ac/bd\\
  (a/b)/(c/d) &= ad/bc;\text{ 其中 } b\ne0.

  $$
  
  分数的比较方式如下：若 $ad$ op $bc$，则 $a/b$ op $c/d$，其中 op 是任意关系运算符。例如，$a/b < c/d$ 当且仅当 $ad < bc$。设计一个类——比如 `fractionType`——对分数执行算术运算和关系运算。重载算术运算符和关系运算符，以便可以使用相应的符号执行运算。另外，重载流插入运算符和流提取运算符，以便于输入和输出。

  `cin >> x;`
  
  应将 2/3 存入 x。语句
  
  `cout << x + y << endl;`
  
  应以分数形式输出 $x + y$ 的值。语句
