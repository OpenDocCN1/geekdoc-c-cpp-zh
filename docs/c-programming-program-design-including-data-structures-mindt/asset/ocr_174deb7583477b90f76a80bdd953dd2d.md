Suppose $a/b$ and $c/d$ are fractions. Arithmetic operations on fractions are defined by the following rules:

$$\begin{aligned}
a/b + c/d &= (ad + bc)/bd\\
a/b - c/d &= (ad - bc)/bd\\
a/b \times c/d &= ac/bd\\
(a/b)/(c/d) &= ad/bc;\text{ in which }b\ne0.
\end{aligned}$$

Fractions are compared as follows: $a/b$ op $c/d$ if $ad$ op $bc$, in which op is any of the relational operations. For example, $a/b < c/d$ if and only if $ad < bc$.
