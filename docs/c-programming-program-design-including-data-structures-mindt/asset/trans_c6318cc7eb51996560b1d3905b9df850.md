### 摘要

多模态检索增强生成（Multimodal RAG）已成为一种有前景的方法，它通过利用外部多模态知识来提高生成内容的质量和准确性。本综述旨在全面概述多模态 RAG 的最新进展，涵盖其关键组成部分、方法和应用。
