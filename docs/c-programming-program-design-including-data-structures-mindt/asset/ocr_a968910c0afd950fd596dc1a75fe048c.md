After this, we visit the vertices that are directly connected to 2 and are not visited, and so on.

As in the case of the depth first traversal, because it might not be possible to traverse the entire graph from a single vertex, the breadth first traversal also traverses the graph from each vertex that is not visited. Starting at the first vertex, the graph is traversed as much as possible; we then go to the next vertex that has not been visited. To implement the breadth first search algorithm, we use a queue. The general algorithm is:

+   a. For each vertex `v` in the graph
+      - if `v` is not visited
+        - add `v` to the queue // *start the breadth first search at v*
+   
+   b. Mark `v` as visited
+   
+   c. while the queue is not empty
+      - c.1. Remove vertex `u` from the queue
+      - c.2. Retrieve the vertices adjacent to `u`
+      - c.3. for each vertex `w` that is adjacent to `u`
+        - if `w` is not visited
+          - c.3.1. Add `w` to the queue
+          - c.3.2. Mark `w` as visited
