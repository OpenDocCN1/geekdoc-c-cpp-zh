26. Determine whether the following are valid `switch` statements. If not, explain why. Assume that `n` and `digit` are `int` variables. (11)

```
a. ```cpp
switch (n <= 2)
{
    case 0:
        cout << "Draw." << endl;
        break;
    case 1:
        cout << "Win." << endl;
        break;
    case 2:
        cout << "Lose." << endl;
        break;
}
```
```

        break;
    case 3:
        cout << "high." << endl;
}
