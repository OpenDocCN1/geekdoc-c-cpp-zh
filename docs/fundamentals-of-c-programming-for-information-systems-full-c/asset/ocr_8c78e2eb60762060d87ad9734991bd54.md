# 5.3 Passing Arguments by Value

When a program calls ComputeTrainingRate(float restingRate, float age), the calling program, by default, passes the value of each argument to the corresponding parameter. This is called passing arguments by value, which is the default way of passing data to a method.

When an argument is passed by value, if the value of the corresponding parameter is changed within the called method, that will not affect the value of the argument in the calling program—that is, if the value of age is changed within the ComputeTrainingRate method, that will not have any effect on the value of age in the calling program, btnGrade_Click.
