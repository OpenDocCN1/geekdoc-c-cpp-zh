# 11.5 Menus

Buttons on a form provide a convenient way to access a limited number of major functions that are performed frequently. Menus provide access to additional functions. We will look at two types of menus:

+   1. The top-level menu (main menu) that is displayed at the top of the form to let you select form-wide functions
+   2. Context menus (shortcut menus) that are displayed when you right click an object, to let you select functions that apply to that object
