# The general syntax to create an array

The general syntax of the statement to create an array is

```
Type[] VariableName = new Type(ArraySize)
```

where ArraySize is the number of elements of the array, Type is the type of data to be stored in the array and VariableName is any valid variable name.

Alternatively, you may use two different statements:

```
Type[] VariableName
```

```
VariableName = new Type(ArraySize)
```
