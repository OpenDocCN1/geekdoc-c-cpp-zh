Note that recordCount is a value type variable. So, it must be passed by reference for ComputePercent to change its value.

The complete code for ComputePercent method is shown in Figure 8-28. This method reads each student’s name and two exam scores, computes the percent score, stores the names in the array referenced by the parameter names and stores the percent scores in the array referenced by percentScores.

# Figure 8-28: The ComputePercent method

```
20 private void ComputePercent(string[] names, float[] percentScores, ref int recordCount )
21 {
22     int index = 0;
23     string currentLine;
24     string[] fields;
25     float percentScore;

27
28     while (examReader.EndOfStream == false)
29     {
30         currentLine = examReader.ReadLine();

32         percentScore = 100*(float.Parse(fields[1]) + float.Parse(fields[2]))/200;
33
34         names[index] = fields[0]; //Store name into names array
35         percentScores[index] = percentScore; // Store percent into percentScores
36         index = index + 1;
37     }

39 }
```
