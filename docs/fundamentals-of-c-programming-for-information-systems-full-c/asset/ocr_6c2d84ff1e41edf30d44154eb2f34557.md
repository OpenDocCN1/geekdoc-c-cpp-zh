# Decision Structures and Validation

The programs presented in Chapters 1 and 2 have simple structures, called **sequence structures**, where the statements are processed sequentially, starting with the first statement and ending with the last, processing each statement, exactly one time. In this chapter, we look at **decision (selection) structure**, which lets you execute a block of statements only under certain conditions.

# 3.1 Flowchart for Decision Structure

Because the discount applies only to orders greater than 10 dollars, the program has to check the value of subtotal and select alternate routes depending on the value. Such a structure that allows a program to execute one or more statements only if a certain condition is true is called a **decision (or selection) structure.**
