# 6.1 Working with ScrollBars

The ScrollBar controls, HScrollBar and VScrollBar, let you select a number between two limits determined by the values of the Minimum and Maximum properties. The two ScrollBars are essentially the same, except that the VScrooBar lets you scroll horizontally, and the VScrollBar lets you scroll vertically. In this section, you will use the HScrollBar.
