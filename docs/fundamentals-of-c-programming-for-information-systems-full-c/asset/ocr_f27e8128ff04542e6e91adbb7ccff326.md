# Displaying a List of Values in a ComboBox

Binding the Text property of a ComboBox to a field shows only the data from the current record. The purpose of the EmpId ComboBox is not to show the EmpId from the current record, but to display all EmpIds so the user can select one to find the corresponding record. How do you do that?

First, you need to set two important properties of the ComboBox (or ListBox):

+   - Set DataSource to the binding source.
+   - Set DisplayMember to the field.

Setting these two properties would display a list of all EmpIds in the ComboBox.
