# Clearing a ListBox

The Clear method of the Items collection clears all lines (items) from the ListBox. Figure 1-30 shows the code to clear the TextBoxes and the ListBox.

# Figure 1-30: Code to clear controls

```
private void cmdClear_Click(object sender, EventArgs e)
{
    txtScoops.Clear();
    txtUnitPrice.Clear();
    lstOutput.Items.Clear();
}
```
