## 4.2 Console Applications

In a Console Application, the user interacts with the application through the console rather than through the controls on a form. So, the development of the form is simpler; however, the user interface is limited.

To use the console, you need to change the Output type setting of the project using the following steps:

- Open the project. We will use the project named Ch4_Loops from Tutorial_Starts folder in the next tutorial.
- Open the Properties window by double clicking Properties in Solution Explorer.
- Select Application. Change Output type to Console Application.

The use of console is illustrated in Tutorial 1.
