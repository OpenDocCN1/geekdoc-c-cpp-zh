# Watch Out for Hidden Blank Lines at the End of Text Files!

If you accidentally hit the Enter key to insert a blank line at the end of the text file, you will get an error at line 56 (percentScore = float.Parse(fields[1]) + float.Parse(fields[2]))/2;). This is because when a blank line is split, the resulting array does not have the elements like fields[1] and fields[2].
