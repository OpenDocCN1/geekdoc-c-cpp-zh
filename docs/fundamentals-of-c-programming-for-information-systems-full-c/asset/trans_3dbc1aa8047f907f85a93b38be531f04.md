## 4.2 控制台应用程序

在控制台应用程序中，用户通过控制台而不是窗体上的控件与应用程序交互。因此，窗体的开发更简单；但是用户界面受限。

要使用控制台，你需要按照以下步骤更改项目的输出类型设置：

- 打开项目。在下一个教程中，我们将使用 Tutorial_Starts 文件夹中名为 Ch4_Loops 的项目。
- 在解决方案资源管理器中双击“属性”，打开属性窗口。
- 选择“应用程序”。将“输出类型”更改为“控制台应用程序”。

控制台的使用在教程 1 中演示。
