# Looking Up Values in an Array Using a Loop

An alternative to using the Array.IndexOf method to find the index of a data item is to use a loop to compare each element of the array to the data item whose index is to be found. For example, to find the index of “March” in the months array, compare each month in the months array to “March” until a match is found or all elements are compared. Figure 7-22 shows the code that uses a for loop.

# Figure 7-22: Look up sales using a for loop

```
// Alternate method using a loop:
// Compare each month in the array to the specified month
int index = 0;
for (index = 0; index < months.Length; index++)
{
    if (months[index] == monthName)
    {
        unitsSoldInMonth = unitsSold[index];
        lblUnitsSold.Text = unitsSoldInMonth.ToString();
        break; // if month is found jump out of the loop
    }
}
// Diplay a message, if month was not found
if (index >= months.Length)
{
    MessageBox.Show("Month not found");
    return;
}
```
