# 12.5 Displaying Data in Details View

The DataGridView displays an entire table in a scrollable window. This is convenient when the number of records and fields in a table is relatively small.

The details view displays one record at a time, with each data item displayed in a separate control, like Label, TextBox or CheckBox. This makes editing/adding/deleting individual records easier, and is particularly suitable when there is a large number of records and fields.

To display employee data in details view, select Details from the dropdown list for Employee data table, as shown in Figure 12-23.
