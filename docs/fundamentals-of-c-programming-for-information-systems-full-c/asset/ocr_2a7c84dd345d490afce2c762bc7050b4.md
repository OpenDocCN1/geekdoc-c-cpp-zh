A major feature of the code is that the size of the array is increased dynamically whenever the number of records read from the file equals the size of the array. Thus, the code is intended to read from files that contain a very large number of records and is expected to grow in size. The actual file used here (Vendor.txt), however, is very small to make it easy to track execution of the code and to test the loop.
