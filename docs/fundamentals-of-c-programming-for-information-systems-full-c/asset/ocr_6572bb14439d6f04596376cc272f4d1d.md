# Displaying Employee Records in a ListView

Displaying the data in a ListView involves the following steps:

+   - Retrieve Employee records, and access each row using a while loop.
+   - Use the GetValues method to get the entire current row, and store it in an object array.
+   - Convert the object array to a String array.
+   - Create a ListViewItem using the String array.
+   - Add the ListViewItem to the ListView.
