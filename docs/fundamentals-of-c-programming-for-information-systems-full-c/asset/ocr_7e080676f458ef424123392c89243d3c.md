# Pretest Loops

The while loop has a Boolean expression that is checked at the beginning of the loop. So, the while loop is called a pretest loop. Because it is a pretest loop, if the Boolean expression is false in the very first iteration, the statements in the loop will not be processed even once. For example, if investValue is initialized to a value greater than 500,000, the statements in the loop will not be processed.
