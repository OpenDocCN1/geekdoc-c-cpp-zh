# Tutorial 2: while Loop: Financial Planning Application

This application uses a while loop in a financial planning application that helps you determine how many years it will take to reach a targeted amount of savings, as shown in Figure 4-8. This example also is used to show the application of do-while and for loops.

In this example, yearly investment and yearly growth rate are used to forecast the future value of investments for each year, while investment value is less than the target of $500,000. It is assumed that investments are made at the beginning of each year. Figure 4-9 shows the flowchart of the while statement.
