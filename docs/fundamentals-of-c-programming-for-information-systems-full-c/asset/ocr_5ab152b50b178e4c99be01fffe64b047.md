# Exercises

# Exercise 1-1: Maximum heart rate

The maximum heart rate during exercise is given by the formula: (220 - age). Create a form named HeartRate, within a project named Exercises_Ch1, to let the user enter an integer age into a TextBox, and compute and display the maximum rate in a Label by clicking a button.

# Exercise 1-2: MPG

The miles per gallon is given by dividing the miles driven by the gallons of gas used. Assume both are nonintegers. Create a form named MilesPerGallon, within a project named Exercises_Ch1. The form should let the user enter the miles driven and gallons used into two TextBoxes, and compute and display the miles per gallon in a Label by clicking a button.
