# Events of CheckBoxes

Two important events of the CheckBox are the CheckStateChanged event and the CheckedChanged event.

The CheckStateChanged event is triggered when the value of CheckState property changes.
The CheckedChanged event is triggered when the value of Checked property changes.

You may use these event handlers to take actions when the Checked or CheckState properties change.
