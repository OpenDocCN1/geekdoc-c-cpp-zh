# Changing colours

One simple way to jazz up your background is to make it change colour every few seconds. That can look pretty cool.

Here’s the code that you need to make this happen:

![](bbox=[0.042, 0.268, 0.445, 0.486])

+   1 To apply the code to your background, first, select your background and then click on ‘Scripts’.

+   2 Select the blocks you need from the ‘Events’, ‘Control’ and ‘Looks’ menus. Drag these blocks into place, as shown, above.

+   3 When you click the green flag, the background colour will change every two seconds. You can alter how quickly it changes colour by adjusting the number in the ‘wait 2 secs’ box. Try it on different backgrounds and see which one you like the best.
