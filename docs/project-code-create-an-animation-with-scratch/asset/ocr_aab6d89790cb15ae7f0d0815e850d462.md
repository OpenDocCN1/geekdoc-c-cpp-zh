# PROJECT PAGE:
USER INTERACTION

How to add some user interaction. Open the Scratch project named ‘animation4.sb2’.

![](bbox=[0.62, 0.18, 0.93, 0.33])

There are now two sprites - Avery and a bat. Avery will walk back and forth until you tell her to do something else. We’ve also added a spooky, whirling forest background using the same method as the colour changing background on page 23, but by choosing ‘whirl’ from the menu instead of ‘colour’.

1 Avery might be a bit scared by the spooky forest. You can get her to jump up and down using this piece of code (right). Hold the mouse button down until she jumps. The ‘IF mouse down? THEN’ block asks the computer to look for a user interaction to see if the mouse has been clicked.

![](bbox=[0.6, 0.47, 0.97, 0.62])

2 You can get Avery to turn a somersault or leap by using this code, and holding down the up arrow key on your keyboard.

![](bbox=[0.54, 0.68, 0.99, 0.94])

3 You can’t see the bat sprite, but if you press the space bar, the bat flies from the top of the screen. If the bat hits Avery, it says ‘Ouch’ and you hear a popping sound. If the bat misses, it disappears.
