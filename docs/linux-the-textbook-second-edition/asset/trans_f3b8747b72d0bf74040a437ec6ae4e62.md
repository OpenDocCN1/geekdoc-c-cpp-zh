### 项目 2

在你的 Linux 系统上，将一个内部挂载的、不是系统磁盘的 SATA 硬盘镜像到一个 USB 闪存驱动器上。SATA 硬盘可以用作你最初在上面创建 zpool 的第一个 vdev，USB 闪存驱动器可以作为你附加到 zpool 作为镜像的新 vdev。以下是一些关于如何成功完成此问题的建议：

- a. 确保你知道系统磁盘的逻辑设备名称，例如 /dev/sda。
不要不小心使用该驱动器来完成此问题，否则你将使系统磁盘无法使用！
- b. 确保你已在你的 Linux 系统上安装了 ZFS，如附录 A，W26.4.7 所示！
- c. 你必须在对它们使用 zpool 命令之前卸载 SATA 硬盘和闪存驱动器。
- d. 首先在 SATA 硬盘上创建一个 zpool 并将该池命名为 sata_usb_test。
- e. 你应该确保闪存驱动器与 SATA 硬盘具有相同的容量。
- f. 在镜像对上创建 zfs 数据集，但在从机器上移除闪存驱动器之前，务必删除数据集并销毁 zpool。

### 项目 3

在你的 Linux 系统上镜像两个 USB 闪存驱动器。第一个 USB 闪存驱动器可以用作你最初在上面创建 zpool 的第一个 vdev，第二个 USB 闪存驱动器可以用作你附加到 zpool 的新 vdev 作为镜像（使用 zpool attach 命令）。以下是一些关于如何成功完成此问题的建议：

- a. 确保你已在你的 Linux 系统上安装了 ZFS，如附录 A，W26.4.7 所示！
- b. 你必须在对它们使用 zpool 命令之前卸载闪存驱动器。
- c. 你应该确保每个闪存驱动器具有相同的容量。
- d. 最初，在第一个闪存驱动器上创建一个 zpool。
- e. 在镜像对上创建 zfs 数据集，但在从机器上移除闪存驱动器之前，务必删除数据集并销毁 zpool。

### 项目 4

本项目的假设是，你想要备份的源目录和文件是在第二个持久媒体设备上创建和维护的，例如另一个内部 SATA 或外部 USB 硬盘，或 USB 闪存驱动器。不是在系统磁盘上。这与本章中推荐的存储模型一致！因此，你不需要使用任何脚本文件或 Linux 文件复制命令来实现所选目录或文件的归档。

使用 mdadm 提供的 RAID 功能来实现源磁盘及其上的分区的“自动”备份。参见书网站上第 W26 章第 4.8 节，了解 mdadm 的介绍。

特别是，使用第 W26 章示例 W26.8b 中为 mdadm 提供的 RAID 1 镜像方法，书网站上，以实现你想要备份的目录和文件的自动备份。提供你用来提供你使用 mdadm 采用的策略的确切和具体的命令，以详细、明确和条理清晰的报告格式呈现。
