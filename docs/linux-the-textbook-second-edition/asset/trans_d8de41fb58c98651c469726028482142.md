## 17.6.3.2 用于备份和恢复的脚本文件

系统管理员可以通过部署用户编写的脚本文件来快速高效地进行备份和归档。无论它们是用 Python（或其他脚本语言）编写，还是用嵌入了前面命令行功能的 shell 编程语言编写，都可以用来促进和自动化文件、目录或文件系统的备份、恢复和归档。此外，还有多个在线来源提供备份和归档脚本文件，我们将不论证规划、编码或维护此类脚本文件与使用在线现成程序的必要性。

以下是使用 tar 的传统应用的 Bash shell 脚本文件示例。

### Example 17.7 用于自动化 tar 备份的简单 Bash Shell 示例

目标：以下 Bash shell 脚本将备份目录 /home/bob/bashtest 到之前创建的名为 simple_backup 的另一个目录，并以压缩格式保存。

步骤：按以下顺序执行以下步骤以完成此示例的要求。

1. 在你的主目录中创建一个名为 bashtest 的子目录。
2. 在你的主目录中创建一个名为 simple_backup 的另一个子目录。
3. 使用你选择的编辑器创建以下文件并将该文件命名为 backup.bash。

```bash
#!/bin/bash
# To backup additional directories, put more pathnames in the
# following command,
# separated by spaces, such as /home/bob /home/sarwar etc.
backup_source=/home/bob/bashtest
backup_destination=/home/bob/simple_backup
filename=back1.tgz
echo "Backing up your bashtest directory"
tar --create --verbose --gzip --file $backup_destination/$filename
$backup_source
echo "Backup Complete"
```

4. 使用命令 ./backup.bash 执行 Bash 脚本

## 17.6.3.3 用于备份和恢复的软件：“Zillas” 和 Ghost

有许多商业软件和硬件包可以部署来备份和归档你的系统。一个非常易于使用的商业产品，允许你以“广播”方式通过网络克隆整个硬盘，从服务器到一台或多台机器，是 Norton Ghost。但两个最易获得、最有用且免费的软件设施，可以执行各种文件系统备份和恢复、磁盘恢复和磁盘克隆操作，是 FileZilla 和 Clonezilla。

### 17.6.3.3.1 FileZilla

FileZilla 名义上是一个基于图形的 ftp 客户端和服务器程序，可以使用 ssh 作为系统之间的隧道或通道。它具有许多有用的功能和菜单选项，允许系统管理员成功、保密且高效地通过网络全局备份和恢复单个文件或目录。它最适用于备份和恢复单用户文件和目录。

它不是前面各节所示命令行设施的替代品或替代品。图 17.10 说明了 FileZilla “客户端”版本的屏幕显示和菜单。

客户端和服务器，在我们的例子中是运行 Linux Mint 的本地机器和远程 Linux 机器之间必须启用 ssh 通信协议。你可以登录到远程服务器上的一个账户，也可以匿名登录，如果启用了该功能。

在客户端启动 FileZilla 后，要登录到远程主机服务器，你需要提供服务器的 IP 地址、登录名和密码以及端口号（ssh 为 22）。一旦成功登录，本地机器的目录和文件结构显示在图左侧。远程机器的目录结构显示在图右侧。要在机器之间传输文件或目录，你只需在左侧或右侧的适当窗格之间拖放。如果你正在覆盖先前传输的文件或目录，FileZilla 的默认行为是给你机会覆盖或重命名正在传输的文件。

FileZilla 屏幕顶部的许多其他菜单选项允许你影响首选项、设置书签等。例如，通过菜单选项 Manage Bookmarks 和 Site Manager，你可以在登录到远程服务器站点后立即自动使多个本地目录和远程目录可用于 ssh 传输。

### 17.6.3.3.2 Clonezilla

Clonezilla 是普通单机用户进行分区和整盘克隆最有用且最易获得的工具。它的“live”版本可以部署来执行整个磁盘的非广播克隆，包括引导扇区。

该技术允许普通用户或系统管理员快速拍摄整个磁盘的快照，从而大大增强和促进所采用的任何备份策略。

例如，在一个大单盘上，Clonezilla 能够快速复制整个磁盘，以便克隆可以像原始磁盘一样使用。因此，与其使用前面所示的任何其他备份方案，不如在任何单一瞬间创建系统上任何磁盘的精确副本。当然，你必须权衡这与任何其他备份策略的优缺点。

在 Linux 中，使用 Clonezilla 可以克隆整个系统磁盘，包括引导分区。

这将允许你拥有系统磁盘的可启动副本，可能还包含你的所有用户数据文件。在 CloneZilla 中，源磁盘可以是内部硬盘，而目标克隆可以是 USB 连接外壳中的外部安装硬盘。如果你在只能容纳一个内部硬盘的笔记本电脑上运行 Linux，这是一个非常有用的程序。

## 17.6.3.4 使用 git 和 GitHub 备份文件系统

git 命令和 GitHub 是你可以用来为你的软件项目创建分布式版本控制系统的有用、高效且强大的手段。它们也可以用作基于云的存储和归档设施，特别是如果你遵循本章中我们推荐的存储模型。也就是说，如果你的 Linux 操作系统安装在 SSD 上，并且所有用户数据文件都存储在另一个持久介质上，例如额外的 SSD 或硬盘。

当然，使用私有 GitHub 仓库进行备份和归档不是免费的。此外，GitHub 上可存储的数据量有限。因此，这种备份和归档方法最适合在 GitHub 公共仓库中拥有少量用户数据存储需求的普通用户。此外，如果你使用我们推荐的另一种数据存储模型，则执行 GitHub 归档和备份的机制将取决于该数据存储模型。
