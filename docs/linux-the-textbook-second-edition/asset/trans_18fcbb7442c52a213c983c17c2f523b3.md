
## 前言

### 作者

两位作者合计拥有近 75 年的大学一线教学实践经验。我们始终坚持本书的编写理念，源于我们不愿使用那些庞大而难啃的 Linux 参考资料（无论是在线还是纸质），也不愿使用简短的“速查”指南来教授这一主题中有意义、完整且贴近实际的入门课程。我们仍然坚信，采用教科书式的教学方法，配合融入章节内教程和练习的教学法，以及每章末尾实用的基础与进阶习题集，能够让我们以“课堂讲授—实验—课后作业”的形式呈现 Linux 的所有重要主题。

在第二版中，我们继续以我们认为最优的学习效果为目标进行微调，即：对新旧主题进行深思熟虑的排序，精心设计且与时俱进的课程，以及与本书章节顺序同步的课后练习/问题。为辅助教学，我们还在前面的章节中加入了大量指向后续章节的前向引用，并在后面的章节中加入了指向前面内容的后向引用。

### 目标读者

第二版遵循与第一版相同的意图和核心原则，尤其是在范围和内容方面。它旨在作为一本关于现代 21 世纪 Linux 操作系统的教科书。它采用入门级的教学风格，与上一版的阐述方式和布局非常相似。

除了新增的两章系统编程和两章系统管理外，本书前 14 章既适合完全的新手，也适合有经验的 Linux 系统用户使用。本书既可用于非正式的继续教育环境（在家或工作场所），也可用于正式的高等教育课堂学习环境。希望进一步拓展知识的专业人士也能从本书的深度和广度中受益。它面向所有有学习意愿的人。

### 第二版中本书的宗旨

我们在核心章节中的首要宗旨，仍然是对 Linux 应用用户接口（AUI）进行教学式描述。我们力求让读者深入了解系统的内部工作机制，并解释一些重要的 Linux 概念、数据结构和算法。典型的例子包括对 Linux 文件、进程和输入/输出（I/O）重定向概念的深入描述。

我们的第二个宗旨是从 C/C++ 库和 Linux 系统调用的角度，全面描述 Linux 应用程序员接口（API）。在编写第二版时，尤其是系统编程章节，我们确实假定读者已具备 C/C++ 编程的基础到中级知识。

我们的第三个宗旨是介绍一些重要的 Linux 软件工程工具，供 C/C++ 软件、Python 程序和 shell 脚本开发者使用。

最后，我们的辅助宗旨是在由系统“超级内核”控制的现代 21 世纪 Linux 环境中，呈现并定位各种系统管理主题。这些主题既可应用于单一、独立的 Linux 系统环境，也可应用于分布式计算环境。其内容范围可以从笔记本电脑或台式机系统扩展到中小型服务器级系统，乃至更广泛的系统。

### 发行版信息与新增内容

我们在本版中用来演示所有内容的 Linux 系统发行版（或称“风味版本”）来自 Debian 和 Red Hat（RHEL）家族：Debian、Ubuntu、Linux Mint 和 CentOS。我们选择这些发行版，主要是因为它们非常易于安装和使用，因此被全球大量普通 Linux 用户广泛使用。对于想在自己的 PC 上安装系统的普通用户来说，它们都是免费可用的。典型的例子是免费的 CentOS，而 RHEL 是唯一仅以商业方式提供的。

最重要的是，我们选择了集成 systemd 的最新版本——Debian 9.1、Ubuntu 16.04、Linux Mint 18.2 和 CentOS 7.4。

在演示 Linux 命令时，默认情况下我们只在命令前加上 Bash shell 提示符“$”，并使用 Debian 家族发行版会给出的输出。该输出在 Debian、Ubuntu、Linux Mint 以及 CentOS 上通常是一致的。当命令的语法、执行方式和输出与 Debian 家族发行版上的默认情况有显著差异时（尤其是在附录 A 中关于 Debian 和 CentOS 的部分），我们会按如下方式在命令前加上 shell 提示符，以帮助您区分命令是在哪个发行版上执行的：

```text
[root@debian]# for Debian
[root@centos]# for CentOS
```

默认情况下，在大多数场景中，我们使用传统的基于文本的命令行界面，即在所选发行版和版本上呈现的基于文本的终端窗口界面。图形用户界面（GUI）桌面的使用也是我们讲解中不可或缺的一部分，只要有必要，并且能为初学者带来便利，我们就会使用它。

由于这些版本在内核中使用 systemd，它们与此前未采用 systemd 的主要发行版本有明显不同。这些发行版和版本在许多方面也优于任何其他当代的、名义上的 Linux 发行版，并且与之截然不同。它们也与其他类 UNIX 操作系统（如 TrueOS、UNIX 和 OS X）有明显区别。本书这一版涵盖了许多旧式、更传统的 Linux 及其他类 UNIX 系统教学方式无法包含的主题——systemd 和 ZFS 就是典型例子。

本版与上一版最大的区别在于，将全书内容划分为三大模块：

- 第 1–14 章构成 Linux 基础核心模块。
- 第 15 章和第 16 章构成系统编程模块。
- 第 17 章和第 18 章构成系统管理模块。

我们还提供了两个附录（A 和 B）。附录 A 是一套在 Debian 家族和 Red Hat 家族系统上安装关键软件的说明。附录 B 是进一步参考书目的列表。关键术语表可在 https://www.crcpress.com/9781138710085 下载。

读者会从这一变化中获得什么好处？将本书划分为这些模块并配齐所有补充材料，最大的好处是本书可以用于更多样化的学习场景。我们将在后面的“阅读路径”一节中详细描述这些场景。

鉴于 Linux 在操作系统市场中占有广泛而分散的份额，我们认为有必要在书中增加涵盖这些新增内容的指导材料，包括以下各项：

- 一个完整的 systemd 教程章节，并将 Linux 中所有内容的讲解都置于 systemd 环境框架内
- 两个全新的、完整的 Linux 系统编程与 Linux API 章节
- 一个全新且内容广泛的 Linux 系统管理章节，使用 systemd 详细说明如何在您自己的 PC 上安装、维护和更新/升级 Linux 系统
- 一个经过修订和更新的网络与互联网互联章节，使其符合当前标准
- 全面覆盖系统调用接口、文件、Linux 内核中与文件相关的数据结构、文件 I/O 范式以及文件操作 API
- 广泛覆盖 Linux 进程和线程的概念、Linux 内核中与进程相关的内核数据结构、进程管理 API 以及信号处理
- 全面覆盖 Linux 中使用管道和命名管道（FIFO）进行的进程间通信
- 使用 GUI 桌面环境，例如 Linux Mint 上的 Cinnamon
- 新增图表、表格、交互式 shell 会话、章节内教程、章节内练习，以及章末基础与进阶问题、习题和项目
- 覆盖许多新命令，并增强对现有命令的覆盖
- 为书中几乎所有内容提供重要的 Web 资源最新 URL
- 新增 nano 文本编辑器章节
- 重新设计的文本布局，使印刷文档更适合主动学习者使用

在本书网站上的高级补充章节中，所有章节均以字母“W”开头，以帮助您将它们与印刷版章节区分开来：

- 一个完整的 Python 3 编程语言及其在 Linux 中使用的教程章节（第 W19 章）

- 更多高级系统管理主题，例如 Linux 中 CUPS 打印的全面介绍（第 W26 章）
