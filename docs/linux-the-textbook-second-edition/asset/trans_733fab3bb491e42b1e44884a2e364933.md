可以使用带 `-R` 选项的 chmod 命令为一个或多个目录下的所有文件和目录设置访问权限。在下面的会话中，第一个命令递归地将目录 courses 下的所有文件和目录的访问权限设置为 711。第二个命令递归地将 ~/personal/letters 下的所有文件和目录的访问权限设置为 700。“递归”意味着遍历指定目录下的所有子目录，即这些示例中的 courses 和 ~/personal/letters。

```
$ chmod -R 711 courses
$ chmod -R 700 ~/personal/letters
```

如果在 chmod 命令中用单个八进制数字指定访问权限，则该命令会用它来设置“其他用户”的访问权限；“用户”和“组”的访问权限均设置为 0（即无访问权限）。如果在 chmod 命令中指定两个八进制数字，则该命令会用它们来设置“组”和“其他用户”的访问权限；“用户”的访问权限设置为 0。在下面的会话中，首先 chmod 命令将 courses 目录的“其他用户”访问权限设置为 7（rwx），所有者和组的访问权限为 0（---）。第二个 chmod 命令将 personal 目录的“组”和“其他用户”访问权限分别设置为 7（rwx）和 0（--），文件所有者无访问权限。`ls -l` 命令显示了这些命令的结果。

```
$ chmod 7 courses
$ chmod 0 personal
$ ls -l
```

在下面的会话中，第一个 chmod 命令将 courses 目录的访问权限设置为所有者和组均为 7（rwx）。第二个 chmod 命令将 personal 目录的“组”和“其他用户”访问权限分别设置为 7（rwx）和 0（--），文件所有者无访问权限。`ls -l` 命令显示了这些命令的结果。

使用掩码作为参数时，umask 命令可用于设置掩码值。掩码值可以指定为三位或四位八进制数。在下面的会话中，我们展示了 umask 命令在不使用和带 `-S` 选项时的用法。

```
$ umask 077
$ umask
0077
$ umask -S u=rwx,g=,o=
$ umask
0077
$
```

umask 命令通常放在 Linux 的系统启动文件 ~/.profile 中，包括 Mint 18，以便每次登录系统时执行。

umask 的参数是一个以八进制表示的位掩码，标识在创建新文件时要关闭的权限位。其他访问权限位的值由布尔表达式计算得出：

```
A = B AND C' = BC'
```

这里，A 是分配给新创建文件或目录的访问权限，B 是默认访问权限（目录或可执行文件为 777，文本文件为 666），C 是当前掩码值。C'（读作“非 C”或“C prime”）称为否定，或 C 的 1 的补码。某二进制数的 1 的补码是通过将 1 替换为 0，0 替换为 1 得到。例如，四位二进制数 1011 的 1 的补码是 0100。两个二进制变量的按位布尔函数 AND 当且仅当两个位均为 1 时返回 1；否则返回 0。在计算上述等式中的 A 时，AND 函数比较 B 和 C' 中相应的位，当且仅当两个位均为 1 时返回 1；否则返回 0。

我们现在展示几个 Linux 如何为给定掩码的新创建文件和目录分配访问权限的示例。我们使用上述布尔表达式确定掩码值为 022 时新创建目录或可执行文件的访问权限。

```
C = 022        = 000 010 010
C'             = 111 101 101
B = 777        = 111 111 111
A = B AND C'   = 111 101 101 = 755 (octal) = 111101101 (binary)
                        rwxr-xr-x (symbolic)
```

因此，文件访问权限为 755（用户可读、可写、可执行，组和其他用户可读、可执行）。对于文本文件，B 为 666。因此，新创建文本文件的访问权限将如下为 644：

```
C'             = 111 101 101
B = 666        = 110 110 110
A = B AND C'   = 110 100 100 = 644 (octal) = 110100100 (binary)
                        rw-r--r-- (symbolic)
```

掩码值为 077 时新创建文本文件的访问权限为 600，如下所示：

```
C = 077        = 000 111 111
C'             = 111 000 000
B = 666        = 110 110 110
A = B AND C'   = 110 000 000 = 600 (octal) = 110000000 (binary)
                        rw------ (symbolic)
```

我们现在做一个 Bourne shell 会话来验证前面的结果。注意，掩码设置为 022 时，新创建的目录（labs）和可执行文件（hello）的权限为 755（rwx1-xr-x），而

新创建的文本文件 tempfile 的权限为 644（rw-r--r--），如前所述计算。掩码设置为 077 时，目录（lectures）和可执行文件（greeting）的权限为 700（rwx------），文本文件（textfile）的权限为 600（rw------）。

```
$ umask 022
$ mkdir labs
$ cc hello.c -o hello
$ cat > tempfile
date
pwd
$ ls -ld labs hello tempfile
-rwxr-xr-x 1 sarwar faculty 6945 Aug 5 22:27 hello
drwxr-xr-x 2 sarwar faculty 2 Aug 5 22:26 labs
-rw-r--r-- 1 sarwar faculty 9 Aug 5 22:30 tempfile
$ umask 077
$ mkdir lectures
$ cc hello.c -o greeting
$ cat > testfile
date
echo "Hello, world!"
$ ls -ld lectures greeting testfile
-rwx------ 1 sarwar faculty 6945 Aug 5 22:28 greeting
drwx------ 2 sarwar faculty 2 Aug 5 22:27 lectures
-rw------ 1 sarwar faculty 26 Aug 5 22:29 testfile
$
```

作者更喜欢掩码值为 077，这样新文件始终以完全保护的方式创建，即文件对所有者具有完全访问权限，对其他人没有任何权限。此掩码允许您拥有一个完全私有的系统，不允许其他用户读取、写入或执行您的文件，或读取、写入或搜索您的目录。请记住，您可以根据需要使用 chmod 命令更改文件的访问权限。另一个常见的 umask 值是 027，它给予组成员默认权限，而不给予其他用户权限。

## 5.6 特殊访问位

除了本章所述的九个常用访问权限位外，还有三个额外的位具有特殊意义。这些位被称为 set-user-ID（SUID）位、SGID 位和粘滞位。
