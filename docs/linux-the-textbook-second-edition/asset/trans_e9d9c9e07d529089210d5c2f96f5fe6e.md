
语法：
  sftp [-option(s)] host
  sftp [user@]host[:file ...]
  sftp [user@]host[:dir[/]]
  sftp sftp -b batchfile [user@]host

用途：登录到指定主机并进入类似ftp的交互式命令模式。第二种语法允许在非交互模式下或交互之后自动检索文件。第三种语法允许sftp在远程目录中启动。最后一种语法允许使用从批处理文件（而非标准输入）中获取的命令进行自动化文件传输会话。如果批处理文件是"-"，则命令从标准输入中获取。

常用选项/功能：
  -C          通过将此标志传递给ssh来启用压缩
  -o ssh_option   以ssh_config文件中使用的格式将选项传递给ssh

以下会话展示了在sftp中执行的示例命令。正如?命令的输出所示，本地主机的命令以字母"l"开头（除了ln），如lls、lmkdir、lpw和lumask。此外，任何以'!'字母开头的Linux shell命令都会在本地主机上执行，如!pwd。

## 11.8.8 打包的ssh应用程序

除了之前展示的可以在终端或控制台窗口中执行的命令行ssh操作之外，在Linux、Windows、iOS/OS X机器上，还有三个非常强大且便捷的图形前端应用程序可直接使用，它们可以实现与ssh、scp和sftp相同的功能。

第一个应用程序名为FileZilla，它允许你通过SSH连接在不同计算机系统之间传输文件和目录。我们将在第17章系统管理中讨论它的一些功能。

第二个应用程序PuTTY是最流行的SSH客户端。如第2章所示，它允许你从Windows机器通过SSH连接登录Linux机器并执行命令。

第三个应用程序是termius，是一款在App Store上可供iPod和iPad等iOS设备使用的免费应用。它允许你从iPod或iPad建立到运行Linux的远程服务器的ssh连接，并打开一个功能齐全的CUI终端窗口进入该服务器。Mac和Linux用户也可以使用终端窗口并利用ssh命令与SSH服务器建立连接。

## 11.8.9 交互式聊天

你可以使用talk命令与你的主机或网络上远程主机上的用户进行交互式聊天。以下是该命令的简要说明。

**语法：**
    talk user [tty]
**用途：**与登录在**tty**终端上的**用户**发起交互式通信。

**user**参数是登录名，如果对方在您的主机上，则使用其登录名。如果您想交谈的对象在另一台主机上，请使用**login_name@host**作为**user**。如果该人多次登录同一台主机，则需要**tty**参数。

当你使用talk命令发起通信请求时，对方屏幕会收到一条中断消息，告知其该请求。对方需要执行talk命令来回复你。这样就建立了一条通信通道，双方用户的显示屏被分为两半。上半部分显示你输入的文本，下半部分显示对方的回复。你和对方可以同时输入。talk命令只是将你在键盘上输入的字符复制到对方的屏幕上。当你们任何一方按下<Ctrl+C>时，聊天会话即可终止。如果你正在使用vim编辑器，并且在通信期间屏幕出现混乱，可以使用<Ctrl+L>重新绘制屏幕。

假设用户**sarwar**想与另一个用户**bob**交谈，并且两人都登录到同一台主机上。以下来自**sarwar**的命令会向**bob**发起交谈请求。

```
$ talk bob
```

当**sarwar**按下<Enter>后，**bob**屏幕顶部会显示以下消息。

```
[Waiting for your party to respond]
Message from Talk_Daemon@upibm7.egr.up.edu at 13:36 ...
talk: connection requested by sarwar@upibm7.egr.up.edu.
talk: respond with: talk sarwar@upibm7.egr.up.edu
```

当**bob**运行talk sarwar命令时，**bob**和**sarwar**的屏幕都会分成两半，上半部分显示[连接已建立]消息，光标移到两个屏幕的顶部。现在**bob**和**sarwar**都准备好交谈了。如果**bob**在使用shell时想忽略**sarwar**的请求，只需按<Enter>即可。

如果**bob**登录在另一台主机上——比如**Linux10**——**sarwar**需要运行以下命令来发起交谈请求。

```
$ talk bob@Linux10
```

如果**sarwar**在**Linux20**上登录了一次，而**bob**想与**sarwar**通信，那么他对前述请求的回复应该是talk sarwar@Linux20。如果**bob**在**Linux10**上多次登录，则**sarwar**的以下命令会在终端**tty p2**（**bob**登录的终端之一）上发起交谈请求。

```
$ talk bob@Linux10 tty p2
```

如果因为其他用户不断用过多请求打扰你，你想屏蔽所有交谈请求，请执行

```
$ mesg n
$
```

此命令仅对当前会话有效。如果你想在每次登录时屏蔽所有交谈和写请求，请将此命令放入你的~/.profile文件中。这样做的效果只是剥夺了组和其他人在/dev目录中对你的终端文件的写权限。因此，你也可以通过对终端文件使用chmod 600命令来实现同样的效果，如下面会话所示。注意在执行mesg n、mesg y、chmod 600 /dev/pts/2和chmod 620 /dev/pts/2命令前后，/dev/pts/2文件权限的变化。
