## 6.7 在文本文件中定位和删除重复内容

你可以使用 uniq 命令删除文本文件中除一个之外的所有连续重复行。该命令适用于排序后的文件，尽管它也可以在未排序的文件上工作，如示例所示。我们将在第 7 章讨论排序。下面是对该命令的简要总结。

Syntax:
uniq [options] [input-file] [output-file]
Purpose: Remove repetitious lines from the sorted input-file and send unique (nonrepeated) lines to output-file. The input-file does not change. If no output-file is specified, the output of the command is sent to standard output. If no input-file is specified, the command takes input from standard input.
Commonly used options/features:
-c  Precede each output line by the number of times it occurs
-d  Display the repeated lines
-f N  Ignore the first N fields in input lines while doing comparisons
-i  Perform case-sensitive comparison of input lines
-s c  Ignore the first c characters in input lines while doing comparisons
-u  Display the lines that are not repeated

以下会话说明了 uniq 命令的工作原理。cat 命令用于显示示例文件的内容。uniq sample 命令显示只有连续的重复行才被视为重复。uniq -c sample 命令显示文件中每一行的行数。uniq -d sample 命令用于仅输出重复行。最后，uniq -d sample out 命令将命令的输出发送到 out 文件。cat out 命令用于显示 out 的内容。请注意，如果重复行相邻，uniq 命令在未排序的文件上也能工作。

```
$ cat sample
This is a test file for the uniq command.
It contains some repeated and some nonrepeated lines.
Some of the repeated lines are consecutive, like this.
Some of the repeated lines are consecutive, like this.
And, some are not consecutive, like the following.
Some of the repeated lines are consecutive, like this.
The above line, therefore, will not be considered a repeated
line by the uniq command, but this will be considered repeated!
line by the uniq command, but this will be considered repeated!
$ uniq sample
This is a test file for the uniq command.
It contains some repeated and some nonrepeated lines.
Some of the repeated lines are consecutive, like this.
And, some are not consecutive, like the following.
Some of the repeated lines are consecutive, like this.
The above line, therefore, will not be considered a repeated
line by the uniq command, but this will be considered repeated!
$ uniq -c sample
  1 This is a test file for the uniq command.
  1 It contains some repeated and some nonrepeated lines.
  1 Some of the repeated lines are consecutive, like this.
  1 And, some are not consecutive, like the following.
  1 Some of the repeated lines are consecutive, like this.
  1 The above line, therefore, will not be considered a repeated
  2 line by the uniq command, but this will be considered repeated!
$ uniq -d sample
Some of the repeated lines are consecutive, like this.
line by the uniq command, but this will be considered repeated!
$ uniq -d sample out
$ cat out
Some of the repeated lines are consecutive, like this.
line by the uniq command, but this will be considered repeated!
$
```

## 6.8 打印文件和控制打印作业

我们在第 2 章中简要讨论了 Linux 用于打印文件的命令。在本节中，我们全面介绍文件打印，包括与打印和打印机控制相关的命令。这些命令包括用于打印文件、检查打印机上打印请求/作业的状态以及取消打印作业的命令。我们描述了基于 Berkeley Software Distribution (BSD) 或 System V UNIX 的两套用于打印和控制打印作业的命令，这些命令在 Linux Mint 中均可用。

### 6.8.1 Linux 打印文件的机制

打印文件的过程与显示文件类似；在两种情况下，一个或多个文件的内容都会发送到输出设备。在显示输出的情况下，输出设备是显示屏，而在打印输出的情况下，输出设备是打印机。另一个主要区别源于每个用户都有一个独立的显示屏，但典型的 Linux（或任何分时）系统中的许多用户可能共享一台打印机。因此，当你使用 cat 或 more 命令显示文件时，Linux 会立即将文件内容发送到显示屏。然而，当你打印文件时，其内容不会立即发送到打印机，因为打印机可能正忙于打印其他文件（你的或其他用户的）。为处理多个请求，先到先得的机制会将打印请求放入与你发送打印请求的打印机相关联的队列中，并在打印机可用时按顺序处理请求。

Linux 为系统中的每台打印机维护一个打印请求队列，称为打印队列。每个请求称为一个作业。作业会被分配一个编号，称为作业 ID。当你使用命令打印文件时，系统会制作你文件的临时副本，为你的请求分配作业 ID，并将作业放入命令行中指定的打印机相关联的打印队列中。当打印机完成当前作业后，它会从打印队列的前端获取下一个作业。因此，当打印机可用并且你的作业位于打印队列的头部时，你的作业将被处理。

一个名为打印机调度程序或打印机守护进程的 Linux 进程执行维护打印队列并将打印作业导向正确打印机的任务。该进程称为 lpd。它在系统启动时在后台开始执行并等待你的打印请求。我们将在第 10 章讨论守护进程，但现在，你可以将守护进程视为一个在后台运行的进程，你在它与终端交互时并不察觉其存在。

Linux 系统有两套不同的用于打印和控制打印作业的命令集，基于 BSD 或 System V UNIX。表 6.2 包含两套系统的打印相关命令列表；所有命令在 Linux Mint 中均可用。超级用户——系统管理员——通常使用最后两个命令 lpc 和 lptest。

此外，你还可以利用通用 UNIX 打印系统 Common UNIX Printing System (CUPS) 的功能来完成下面各节中显示的所有内容。我们在本书网站第 W26 章的系统管理部分“CUPS Printing”中详细介绍了 CUPS 打印。

### 6.8.2 打印文件

如表 6.2 所示，你可以在 Linux 系统上使用 lp 命令和 lpr 命令打印文件。必须非常注意的是，你绝不要尝试使用 lp 或 lpr 命令打印非文本文件，尤其是包含控制字符的文件（例如可执行文件，如 a.out）。这样做不会打印出你想要的内容，并且会浪费许多打印纸张。甚至不要尝试测试。如果不小心，你确实发送了非文本文件的打印请求，请立即关闭打印机并通知你的系统管理员你需要帮助。
