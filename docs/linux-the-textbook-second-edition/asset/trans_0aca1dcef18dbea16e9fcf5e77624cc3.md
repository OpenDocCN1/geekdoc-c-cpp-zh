## 7.4 正则表达式

*正则表达式*是常量与运算符符号（称为运算符）的序列，它表示一组字符串，通常称为*搜索模式*。大多数 Linux 工具一次一行地处理文本文件。正则表达式用于在单行中搜索文件内容中的所需模式。它们不能用于搜索从一行开始到另一行结束的模式。

正则表达式允许你搜索特定大小的字符串。你可以搜索具有特定字母、数字和标点符号模式的字符串。你可以搜索一个以元音开头和结尾、并包含两个连续字母“l”的单词。你如何处理由正则表达式标识的字符串，取决于你用来标识它们的工具。诸如 vim 之类的文本编辑器可以用新字符串替换它们，有些工具则简单地将它们显示在屏幕上。

某些 shell 元字符与正则表达式中使用的运算符类似。虽然命令行中的元字符在传递给命令之前会由 shell 处理和展开，但正则表达式由命令处理。Bourne shell、Bash、C shell 以及 find 和 cpio 等工具使用元字符，而不使用正则表达式。另一方面，awk、egrep、emacs、expr、grep、more、perl、python、sed 和 vim 等工具使用正则表达式。为了防止 shell 处理它们，正则表达式中的运算符在作为 shell 命令中的选项传递时必须用引号括起来。

Linux 中的不同工具支持不同的运算符集，但几乎所有支持正则表达式的 Linux 工具都支持以下运算符：`()`、`[]`、`.`、`^`、`$` 和 `*`。有些工具还使用 `|`、`?` 和 `+` 等附加运算符。表 7.1 通过示例说明了这些运算符和其他运算符的用途。

## 7.5 搜索文件

Linux 具有强大的文件搜索工具，允许你查找文本文件中包含特定表达式、字符串或模式的行。例如，如果你有一个包含公司员工记录的大文件，每条记录占一行，你可能希望搜索文件中包含 John Johnsen 信息的行。允许文件搜索的工具是 grep、egrep 和 fgrep。下面是这些工具的简要说明。

```
Syntax:
 grep [options] pattern [file-list]
 egrep [options] [string] [file-list]
 fgrep [options] [expression] [file-list]
```

用途：在 file-list 中的文件中搜索给定的模式、字符串或表达式；如果没有 file-list，则从标准输入获取输入

输出：将包含给定模式、字符串或表达式的行输出到标准输出

# 常用选项/特性：

+   -c 仅打印匹配行的数量
+   -i 在匹配过程中忽略字母大小写
+   -l 仅打印包含匹配行的文件名
+   -n 打印匹配行时同时显示行号
+   -r 递归读取目录下的文件（如果未指定，则为 home 目录）；仅当在命令行中指定了符号链接时才跟随这些链接
+   -s 对 shell 脚本有用；抑制错误消息（返回状态设置为 0 表示成功，非 0 表示不成功——参见第 10 章）
+   -v 打印不匹配的行
+   -w 将给定模式作为字符串进行搜索

在这三个命令中，fgrep 命令最快但限制最多；egrep 最慢但最灵活，允许充分利用正则表达式；grep 速度合理，并且在对正则表达式的支持方面相当灵活。在接下来的会话中，我们将使用说明中所示的一些选项来演示这些命令的用法。在这些会话中，我们使用与 7.3 节中描述 sort 工具时相同的 students 文件。我们使用 cat 命令显示该文件。
