## 17.9.2.1 sudo

在 Linux 上，程序、命令和文件传统上是通过用户和组权限访问的。每个用户都有一个唯一的标识符，给出为用户名或 UID。用户属于唯一的组，给出为组名或 GID。特定用户和组有权访问可用的程序、命令和文件。

sudo 程序或命令允许以 root 身份，甚至以其他用户身份运行单个命令。只有系统管理员或 root 用户才能使用策略列表文件（名为 sudoers），该文件包含每个用户可以执行的命令。因此，管理员控制用户在系统上的特权。当任何用户需要运行需要 root 权限的命令时，该用户在控制台终端中输入 sudo command，允许他们以 root 特权运行命令。然后，sudo 会在其策略列表文件中咨询其权限列表。如果用户有权运行该命令，则运行该命令。如果用户无权运行该命令，sudo 会拒绝执行。运行 sudo 不需要知道 root 的密码，但默认情况下需要用户自己的密码才能成功执行。

有关 sudo 命令的更详细描述（在我们的代表性 Linux 系统上启用和使用它的众多示例），请参阅本书网站上的第 W26 章，第 W26.9.2.1.1–W26.9.2.1.3 节。我们还在附录 A 的第 17.9.2.1 节中提供了如何在 Debian 系列和 CentOS 系统上安装 sudo 命令的安装说明。

su 命令（“switch user”的缩写）允许用户切换角色并在不注销自己的帐户的情况下成为系统超级用户。如果你想承担 root 角色，你必须知道 root 帐户的密码。在我们的代表性 Linux 系统上，此命令受到限制，建议将需要在系统上拥有更高级别特权的用户包含在 sudoers 文件中。这样他们就可以按命令为基础执行特权操作。

## 练习 17.48

红队现场手册是什么？蓝队现场手册是什么？渗透测试是什么？在渗透测试的上下文中，为什么你需要其中之一或两者？

入侵检测系统（IDS）通常是监控网络或系统是否存在未经授权的活动或用户协议违规的软件应用程序。它通过特定于软件的接口应用，最重要的是通过日志文件监控。

各种免费或商业 IDS，从防病毒软件到监控骨干网络流量的分层系统，都可用。它们可分为网络 IDS（NIDS）或主机 IDS（HIDS）。监控操作系统文件的 IDS 是 HIDS 的示例。分析传入网络流量的 IDS 是 NIDS 的示例。此外，IDS 可按检测策略分类。最著名的检测策略类型是基于签名的检测（识别不良模式，例如恶意软件）和基于异常的检测（检测与“良好”流量的预定义模型的偏差，这通常使用某种形式的 人工智能。具有某种预定和结构化响应协议的 IDS 被称为 IPS。

典型的网络 IDS 试图通过监控网络流量来检测恶意活动，例如暴力攻击、拒绝服务攻击、端口扫描或尝试通过监控网络流量破解计算机。

以下是可在我们的 Linux Mint 系统上安装但默认未安装的一些免费 IDS 的部分列表：

- - 高级入侵检测环境（AIDE）是 Linux Mint HIDS，可以监控和分析操作系统的内部结构。
- - Snort 是 Linux Mint NIDS，可对 IP 网络进行数据包记录和实时流量分析。
- - fail2ban 是 Linux Mint IPS 的示例。它基于来自 LAN 或互联网进入系统的恶意活动采取的许多可配置操作之一，是锁定尝试通过 ssh 以错误密码登录超过五次的 IP 地址。这可以防止通过端口 22 的暴力攻击。

这三个 IDS 可通过 Linux Mint 软件管理器获得。了解它们安装和配置细节的最佳方法是阅读其在线文档和教程。
