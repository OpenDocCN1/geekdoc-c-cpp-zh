## 17.2 从 DVD ISO 映像介质进行全新安装及初步系统配置

本节假定你已经获得了要安装的 Linux 系统的 DVD ISO 映像介质，并且你的系统是一台 64 位、X86 架构的计算机，你愿意使用至少一整块硬盘来安装系统。如果你尚未获得 ISO 映像，或没有 64 位计算机，你应遵循第 17.2.2 节列出的网站上的在线文档来获取 DVD 介质的 ISO 映像。

由于 Linux 系统的安装在不同发行版之间差异很大，并且随着后续升级和发布而发生显著变化，我们仅提供 Linux 系统安装的示例。有关 Linux Mint 的具体安装说明，请参阅附录 A，第 17.2 节，Linux Mint 是我们的默认 Linux 发行版。

你也可以使用为 32 位机器设计的软件系统发行版，但请注意，本章中展示的一些功能仅限于 64 位架构机器。

“获取 DVD ISO 映像介质”是指下载你想要使用的软件发行版的 ISO 文件，然后将该 ISO 映像刻录到 DVD，或复制到 USB 闪存驱动器。我们在此不提供这些过程的说明。

在撰写本书时，我们用来说明一切的 Linux 系统处于以下发行版：

Debian 9.1, Ubuntu 16.04LTS, Linux Mint 18.2, CentOS 7.4

请注意，为 Linux 举例说明的一些系统管理任务在软件的更早（或更晚）发行版中以不同方式完成！

本节还假定你不会永久运行来自持久或非持久介质（如 USB 闪存驱动器或 CD/DVD）的 Linux 系统的“live”版本。你可以在想要随意试用 Linux 以了解你最喜欢哪种“风格”时这样做。

如第 17.1 节所述，如果你想在虚拟环境中安装 Linux，使其与计算机硬件上的其他操作系统同时运行，我们在书网站的第 W23 章“虚拟化方法”中提供了具体说明。我们在那里给出了将 Ubuntu Linux 作为“访客”操作系统安装的具体细节，使用 LXC/LXD 和 VirtualBox。

### 17.2.1 安装前和安装后考虑及选择

所有 Linux 系统都有可在安装前确定的最低硬件和驱动程序要求。这些硬件要求列在每个系统的在线文档中。

### 安装前考虑

一旦你确定计算机系统硬件满足或超过这些最低要求，以下问题列表建议了在继续安装之前，你可以在默认安装选项之外做出的非常重要的考虑。与其将这些建议视为高度正式的约束，你应将它们视为非正式呈现的指南，说明你如何在非常主观地根据你使用计算机的方式来选择 Linux 系统安装的某些方面。

- 0. 根据你希望以 Linux 运行计算机的方式，硬件是否有足够的物理内存？这是性能方面的考虑。在任何情况下，你都应首先考虑增加物理内存的数量或大小

- 1. 使用软件管理器安装你需要使用但默认未预装的绝对必要的应用程序（Firefox、LibreOffice）。对我们来说，按优先级顺序包括 opensshd、Filezilla、Gparted、VirtualBox 和 Webmin。我们还在 Cinnamon 桌面上为所有重要应用程序放置了桌面图标。我们在附录 A 中提供了部分安装说明。
- 2. 我们高度推荐的存储模型规定使用 ZFS，因此我们安装了 zfsutils-linux 软件包。Linux Mint 操作系统是基于 SSD 构建的，我们在安装 zfsutils-linux 后立即添加了一对用于用户数据文件存储的镜像 vdev 旋转硬盘。
- 3. 由于打印文档是我们系统需要执行的基本操作，我们通过通用 UNIX 打印系统（CUPS；如网站第 W26 章第 W26.5 节“CUPS 打印”中详细所示）连接并设置了一台通过 USB 连接指向计算机硬件的激光打印机。
- 4. 我们将 Linux Mint 系统作为基本 ssh 服务器暴露在互联网上，因此我们立即修改了 sshd 配置文件，并根据本章所示为其构建了 ufw 防火墙规则，以保护系统。此外，我们还安装了 fail2ban 软件包并使用其默认设置以防止主要针对端口 22 的暴力攻击。如果你使用的是 CentOS 系统，selinux 默认启用并强制执行，而在 Debian 系列中则不是。
- 5. 我们将 Linux Mint 系统最小化地作为 Web 服务器暴露（使用 nginx 和我们在网站上展示的自定义程序），但采用了这些应用程序的默认安全措施。
- 6. 我们在系统上只需要少量额外的用户和组，因此我们立即使用第 17.3.4 节所示的方法设置了它们，并在必要时添加。这与第 2 项一致。这种添加新用户和组的方法的主要优势在于，用户及其数据文件位于他们自己的冗余硬盘对上，与操作系统安装分开且独立维护。我们认为这种模型对于单用户计算机桌面系统、共享多用户计算机或低到中级企业级服务器也很有用。

有各种 Linux 命令可以调查系统硬件，为你提供进行性能调优和安装后修改系统的基础。其中一些是 lscpu、lshw、hwinfo、lspci、lsusb、inxi、lsblk、df、fdisk、mount、free、hdparm，以及检查 /proc 目录的相关内容。我们在前几章中详细说明了一些这些命令的使用，并在本章中也举例说明了一些。

但是，为了获得他们系统实际安装后配置的非常有用的摘要，我们发现 Linux inxi 命令是初学者最有用和最快捷的方式。

我们展示了该命令的三种用法，在三台不同服务器级机器上：运行 Linux Mint 的 HP ProLiant MicroServer、运行 Debian 9 的 IBM System x3650 [-7979E9U]，以及运行 CentOS 7.4 的 Dell PowerEdge T110。

请注意，在运行 CentOS 7.4 的 Dell PowerEdge T110 上，我们必须先以超级用户身份安装 inxi，使用命令 yum install inxi。
