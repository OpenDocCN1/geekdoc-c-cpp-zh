

## 操作系统概述

Linux 的历史发展以开放系统方法为特征，即源代码在用户之间自由分发。Linux 的多个版本的发展沿着三个主要分支进行。各种版本的兼容性发行版旨在标准化系统。POSIX 和单一 UNIX 规范是相关的标准化工作。我们认为 Linux 系统未来的三个令人兴奋且具有挑战性的新发展如下：

- 1. 将 Zettabyte 文件系统（ZFS）作为根文件系统纳入内核
- 2. systemd 及其“超级内核”功能的进一步开发和普及
- 3. 用 Wayland 协议取代 X Window 系统协议。

## 2.2 Linux 命令的结构

Linux 可以非常高效地使用图形用户界面（GUI），尤其是对新手而言。但在关键时刻，使用基于文本的 CUI 也是必不可少的。因此，Linux 命令的正确键入语法可确保在所有代表性系统上正确执行命令。

用户成功登录到 Linux 计算机后，shell 提示符，例如 $ 字符，会出现在屏幕上。shell 提示符只是计算机系统发出的消息，表示它已准备好接受在提示符后直接跟随的命令行上的击键。单个 Linux 命令在命令行上键入的一般语法或结构如下：

```
$ command [-option(s)] [option argument(s)] [command argument(s)]
```

其中

$ 是来自计算机的命令行或 shell 提示符；
[ ] 中包含的任何内容并非总是必需；
command 是该 shell 中有效的 Linux 命令名称，以小写字母表示；
[-option(s)] 是改变 command 行为的一个或多个修饰符；
[option argument(s)] 是改变 [-option(s)] 行为的一个或多个修饰符；
[command argument(s)] 是受 command 影响的一个或多个对象。

- 1. 空格分隔 command、选项、选项参数和命令参数，但在多个 option(s) 或多个选项参数之间不需要空格。
- 2. 多个选项或选项参数的顺序无关紧要。
- 3. 选项和选项参数之间可选择空格字符。
- 4. 始终按 <Enter> 键以提交命令进行解释和执行。
