## 17.6.2.4 Restoring Archived Files with tar

你可以使用 tar 命令的 --extract 选项来恢复（解包）归档。要恢复在第 17.6.2.3 节中创建的归档并将其放置在名为 ~/backups 的目录中，可以运行以下命令序列。cp 命令将归档文件复制到归档文件被假定位于主目录中，复制到归档文件将被恢复的目录（~/backups）。cd 命令用于将目标目录设为当前目录。最后，tar 命令用于执行恢复。请注意目标目录是当前目录。

```
$ cp unixbook.tar ~/backups
$ cd ~/backups
$ tar --extract --verbose --file unixbook.tar
```

有时，你可能需要恢复 tar 归档中的文件子集。系统管理员经常在系统崩溃后这样做（通常是由电源浪涌引起的磁盘磁头崩溃导致），并随之破坏了一些用户文件。在这种情况下，系统管理员只从备份归档中恢复位于损坏磁盘部分上的那些文件。只要知道要恢复的文件的路径名，选择性恢复就可以通过 --extract 操作实现。如果你不记得要恢复的文件的路径名，可以使用 --list 操作来显示归档文件上的文件和目录的路径名。带有 t 选项的 tar 命令的输出格式类似于 ls -l 命令的输出，如以下会话所示。如示例输出所示，第一字段指定文件类型和访问权限，第二字段指定文件所有者的用户 ID/组 ID，第三字段显示文件大小（以字节为单位），接下来的几个字段显示文件最后修改的时间和日期，最后一个字段显示存储在归档中的文件的路径名。

如果归档包含大量文件，可以将带有 --list 操作的 tar 命令的输出通过管道传递给 more 命令以分页查看。如果你知道文件名但不知道其路径名，可以将带有 --list 操作的 tar 命令的输出通过管道传递给 grep 命令。文件也可以选择性地恢复，或选择性地查看其路径名。以下会话说明了这些要点。
