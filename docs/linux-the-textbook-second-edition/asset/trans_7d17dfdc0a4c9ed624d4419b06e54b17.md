

## 表10.2
ps命令显示的Linux进程状态的简要说明

| 第一个字符 | 描述 | 附加字符 | 描述 |
| --- | --- | --- | --- |
| D | 处于磁盘或其他短期可中断等待中的进程 | + | 前台进程 |
| X | 已死进程 | < | 进程已提高调度优先级 |
| R | 可运行进程，等待获取CPU | L | 进程锁定在内存中——例如，用于原始I/O |
| S | 睡眠进程——等待小于20秒 | N | 进程已降低CPU调度优先级 |
| T | 已停止/挂起的进程 | S | 会话首领进程——例如，登录shell |
| W | 空闲中断进程/线程 | L | 多线程 |
| Z | 僵尸进程 |  |  |

等待时间小于20秒。最后，处于R+状态的进程是一个前台进程，它已准备好运行，正在等待被调度使用CPU。我们将在10.6节中详细讨论前台和后台进程。

```
$ ps -u
USER PID %CPU %MEM VSZ RSS TTY STAT START TIME COMMAND
sarwar 27753 0.0 0.0 23192 5404 pts/0 Ss 07:23 0:00 -bash
sarwar 27797 0.0 0.0 37680 3356 pts/0 R+ 07:39 0:00 ps -u
$
```

你可以指定一个以逗号分隔的UID列表，来显示属于这些UID的进程的相同信息，例如使用ps -u 1004,1009,1020。提醒一下，UID是/etc/passwd文件中一行的第三个字段。注意，前三个进程的状态是Ss+，这意味着它们是前台空闲的会话首领进程。换句话说，它们是前台登录shell进程，已经超过20秒没有使用CPU了。

你可以使用-U选项来显示属于该选项后指定的逗号分隔用户名的所有进程的默认状态。在下面的示例中，显示了属于用户sarwar的所有进程。ps -U john,bob,davis,sunil,goldman,ibraheem命令将显示属于用户john、bob、davis、sunil、goldman和ibraheem的所有进程的默认状态。

```
$ ps -U sarwar
PID TTY TIME CMD
19919 ? 00:00:00 system d
19923 ? 00:00:00 (sd-pam)
19937 ? 00:00:00 sshd
27753 pts/0 00:00:00 bash
27799 pts/0 00:00:00 ps
$
```

你还可以使用用户的逗号分隔UID列表来显示相同的信息。因此，ps -U 1004命令显示UID为1004的用户的所有进程的默认状态。类似地，ps -U 1004,1005,1001命令显示UID为1001、1004和1005的用户的所有进程的默认状态。你可以使用-a和-x选项来显示关于你的进程、属于其他用户的进程、系统进程以及未连接到任何控制终端（如守护进程）的进程的信息。你可以通过使用ps -ax | wc -l命令来确定系统上运行的所有进程（包括所有系统进程和守护进程）的总数。输出包含一个标题行以及分别对应于ps -ax和wc -l进程的各一行。因此，如果不计算命令行本身产生的两个进程，我们的Linux Mint系统上当前运行着176个进程。

```
$ ps -ax | wc -l
    177
$
```

你还可以使用ps -e | wc -l命令来确定机器上运行的进程数量。

你可以使用-H选项来显示系统运行进程中对内核可见的线程，在Solaris中称为轻量级进程（LWP）。ps -axH | wc -l命令的输出显示为283。在这283行中，一行是输出标题，另外各一行分别用于ps -axH和wc -l命令。因此，当前系统上运行的176个进程中共有280个内核可见线程。

```
$ ps -axH | wc -l
283
$
```

虽然-j、-l、-u和-v选项允许你以已知顺序显示预定义关键字的值和标准头部信息，但-O和-o选项允许你显示自定义输出：你选择的关键字的值、你喜欢的顺序，以及你喜欢的头部。在下面的会话中，我们展示了如何使用这些选项的ps命令。关键字dsiz和tsiz分别是进程内存映像的数据段和文本/代码段的大小（以千字节为单位）。wchan是进程正在等待的事件。会话中的最后一个命令再次展示了如何自定义输出的头部。

```
$ ps -o dsiz,tsiz,vsz,rss,wchan
DSIZ TSIZ   VSZ   RSS WCHAN
22217 974  23192 5472 wait
29114 89   29204 1604 -
$ ps -o dsiz,tsiz,lwp,nlwp,wchan,pcpu,pmem,flags,args
DSIZ TSIZ  LWP NLWP WCHAN  %CPU %MEM F COMMAND
22217 974  14738 1 wait   0.0  0.0 0 -bash
29142 89   14813 1 -      0.0  0.0 0 ps -o dsiz,tsiz,lwp,nlwp,wchan,pcpu,pmem
$ ps -o user,pid=SON -o ppid=MOM -o args
USER   SON   MOM COMMAND
sarwar 14738 14738 -bash
sarwar 14814 14738 ps -o user,pid=SON -o ppid=MOM -o args
$
```

其中一些字段和对应的关键字是显而易见的，我们已在本章前面讨论过其中几个。然而，一些我们现在要讨论的关键字是新的并且不那么明显。你可以使用ps L命令显示所有关键字，如下所示：

```
$ ps L
%cpu        %CPU
%mem        %MEM
...
[Output truncated]
$
```

## 图10.6 Linux进程的内存映像。

数据段、栈段和文本/代码段是进程内存映像的一部分。Linux进程内存映像的另外三个部分是共享库、堆和环境。图10.6显示了Linux进程的内存映像。环境由命令行参数和五个shell变量（HOME、PATH、SHELL、USER和LOGNAME）组成，这些变量可以通过指向两个以空字符结尾的字符串指针数组的指针来访问。栈从高内存向低内存增长，堆从低内存向高内存增长。文本和已初始化数据部分由exec(2)系统调用从程序文件中读取，未初始化数据（bss）部分也由exec(2)系统调用初始化为零。
