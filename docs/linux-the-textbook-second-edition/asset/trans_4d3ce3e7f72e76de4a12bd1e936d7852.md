

Debian—作为 root，使用以下命令：

```
[root@debian] # apt-get install sudo
```

然后使用以下命令为自己或指定用户授予 sudo 权限：

```
[root@debian] # visudo
```

然后你的默认文本编辑器将打开（在我们的 Debian 9.1 系统上为 nano），你可以在 sudoers 文件中标题为“# User privilege specification”的部分输入以下行：

```
username            ALL=(ALL:ALL)       ALL
```

其中 username 是你想要授予完全 sudo 权限的用户名。

保存文件并退出编辑器。

Ubuntu—截至本书撰写之时，sudo 已安装，并且默认用户在 sudoers 组中。这可以通过命令 id -Gn 来检查

Linux Mint—截至本书撰写之时，sudo 已安装，并且默认用户在 sudoers 组中。这可以通过命令 id -Gn 来检查

For CentOS Installation

截至本书撰写之时，sudo 已安装，但作为 root，你必须为自己（或指定用户）授予 sudo 权限。要为自己或指定用户授予 sudo 权限，请使用以下命令：

```
[root@centos] # visudo
```

然后你的默认文本编辑器将打开，你可以在 sudoers 文件中标题为“# User privilege specification”的部分输入以下行：

```
username            ALL=(ALL:ALL)       ALL
```

其中 username 是你想要授予完全 sudo 权限的用户名。

保存文件并退出编辑器。
