## 17.8.1.4 系统磁盘使用情况评估

除了 CPU 使用率和内存管理之外，观察、评估和修改持久存储介质，特别是硬盘驱动器的资源的能力，对系统管理员的任务至关重要。即使对于普通用户来说，磁盘空间也是一种宝贵的商品，无论是千兆字节容量硬盘的可用性和更低的成本。考虑一个计算机系统，它只能在它最快的总线架构上物理支持一个内部硬盘，或者一个普通用户正在存储大型文件，例如视频或其他类型的媒体文件。

传统上，Linux du 命令允许你以多种格式获取文件和目录的基于文本的磁盘使用情况摘要。然后管理员可以根据系统的用例采取行动来精简硬盘使用。有关 du 命令的更多信息，请参阅你 Linux 系统上 du 的手册页。

## 17.8.2 使用 ip 命令进行网络配置

系统管理员在进行安装后网络配置时，最重要和最有用的命令是 ip 命令。以下各节说明了此命令的基本用法，并给出了一个用例示例，说明如何将多个 IP 地址分配给一个 NIC。NIC 是系统硬件用于与网络接口的设备。

使用新工具包，添加新 IP 地址与旧方法一样简单：

```text
ip addr add 192.168.1.1/24 dev eth0
```

### 17.8.2.1 基本 ip 命令语法、选项和操作

ip 命令手册页的简写版本如下：

```text
ip

Syntax: ip [ Options] Object { Command | help }
ip [ -force ] -batch filename
where
Object  { link | addr | addrlabel | route | rule | neigh | ntable | tunnel | tuntap | maddress | mroute | mrule | monitor | xfrm | netns | l2tp | tcp_metrics }
Options: { -V[ersion] | -h[uman-readable] | -s[tatistics] | -r[esolve] | -f[amily] { inet | inet6 | ipx | dnet | link } | -o[neline] | -n[etns] name | -a[ll] | -c[olor] }
```

### Command:

指定对对象执行的操作。可能的操作集取决于对象类型。

对于大多数对象，可能的命令是 add、delete 和 show。有些对象不允许所有这些操作或有一些额外的命令。help 命令适用于所有对象。它打印出可用命令和参数语法约定列表。稍后请参阅第一个示例的语法和输出。

如果未给出命令，通常 show 命令是默认的，如果该选项可以应用于指定的对象。

**Purpose:** Show or manipulate routing, devices, policy routing, and tunnels

**Output:** Output or modified routing, devices, policy routing, or tunnels

### Commonly used options/features:

- addr: IP address

要查看 ip addr 命令的简写帮助语法显示，输入以下内容：

```text
$ ip addr help
Usage: ip address {add|change|replace} IFADDR dev IFNAME [ LIFETIME ]
            [ CONFFLAG-LIST ]
    ip address del IFADDR dev IFNAME [mngtmpaddr]
    ip address {show|save|flush} [ dev IFNAME ] [ scope SCOPE-ID ]
              [ to PREFIX ] [ FLAG-LIST ] [ label LABEL ] [up]
        ip address {showdump|restore}
IFADDR := PREFIX | ADDR peer PREFIX
          [ broadcast ADDR ] [ anycast ADDR ]
          [ label IFNAME ] [ scope SCOPE-ID ]
Output truncated...
$
```

从之前的列表中，你可以看到可用于操作对象 addr 的命令，即 add、change、replace、del(ete)、show、save、flush 和 showdump。

要查看名为 enp2s0 的特定 NIC 的状态，输入以下内容：

```text
$ ip addr show enp2s0
```

### Example 17.10 Assigning Several IP Addresses to a NIC

**Objectives:** 使用 Linux ip 命令为系统的 NIC 分配多个 IP 地址。

**Prerequisites:** 第 11 章关于网络和互联网络的所有内容，以及书籍网站上第 W20 章关于进程间通信的相关部分。你的系统上具有超级用户权限。

**Requirements:** 按呈现的顺序执行以下步骤。

1. 如果你需要临时使用额外的 IP 地址，你可以使用以下通用格式命令将其添加到任何网络接口：

```text
$ sudo ip address add <ip-address>/<netmask> dev <interface>
```

一个实际的示例如下：

```text
$ sudo ip address add 192.168.0.100/24 dev enp2s0
[sudo] password for bob: QQQ
$
```

之前的命令将使用 24 位网络掩码向网络接口添加一个额外的 IP 地址，该地址将添加到 NIC enp2s0 已分配的任何当前 IP 地址之上。

你可以使用以下命令检查结果：

```text
$ ip address show enp2s0
2: enp2s0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc mq state UP group default qlen 1000
    link/ether e4:11:5b:12:c2:77 brd ff:ff:ff:ff:ff:ff
    inet 192.168.0.6/24 brd 192.168.0.255 scope global enp2s0
        valid_lft forever preferred_lft forever
    inet 192.168.0.100/24 scope global secondary enp2s0
        valid_lft forever preferred_lft forever
    inet6 fe80::e611:5bff:fe12:c277/64 scope link
        valid_lft forever preferred_lft forever
```
