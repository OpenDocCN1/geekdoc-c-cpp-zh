正如你在该屏幕显示中所看到的（它显示了我们主目录中的文件列表，而不会与你主目录中的文件列表相同），当前工作目录中每个文件的信息都以八列显示。第一列显示文件的类型，其中 d 代表目录，l 代表符号链接，而 – 代表普通或常规文件。也在第一列中，以 r、w 或 x 显示该文件对用户、组和其他人的访问模式。第二列显示指向该文件的链接数。第三列显示该文件所有者的用户名。第四列显示该文件的组名。第五列显示该文件在磁盘上占用的字节数。第六列显示该文件上次修改的日期。第七列显示该文件上次修改的时间。第八列也是最后一列，显示文件名。这种执行命令的方式是列出有关文件的更完整信息的好方法。使用更完整信息的示例有（1）以便你能知道字节大小并能够将文件放入某个便携式存储介质中，或（2）显示访问模式，以便你可以更改特定文件或目录的访问模式。

你也可以通过使用 ls 命令的另一种变体，为当前工作目录中的单个文件获取文件列表，如下所示：

```
$ ls -la myfile
-rw-r--r--  1 bob  bob  797 Jan 16 10:00 myfile
$
```

此变体显示了特定文件 myfile 的长列表及其相关信息。你在命令行输入内容的分解为（1）ls，即命令名；（2）-la，即选项；以及（3）myfile，即命令参数。

如果你在输入时出现错误，将命令名或命令其他部分拼写错误怎么办？在命令行输入以下内容：

```
$ lx -la myfile
lx: not found
$
```

Linux 返回的 lx: not found 是错误信息。Linux 操作系统中没有 lx 命令，因此会显示错误信息。如果你输入了不存在的选项，也会收到错误信息。如果你提供了当前工作目录中不存在的文件名，也会收到错误信息。这说明了 Linux 命令执行的一个重要点。如果没有显示错误信息，则命令已正确执行，结果可能或可能不会出现在屏幕上，这取决于命令实际执行的操作。如果你收到错误信息显示，你必须在 Linux 执行你输入的命令之前纠正该错误。

## 2.4.4 创建、删除和管理目录

文件维护的另一个关键方面是你用于在计算机上的 Linux 账户中创建、删除和组织目录的一组程序和相关的 Linux 命令。在文件系统中移动时，你要么向上移动，要么向下移动以到达你想要使用的目录。当前工作目录正上方的目录称为当前工作目录的父目录。当前工作目录下直接的目录或目录称为当前工作目录的子目录。有关文件系统结构的更多信息，请参阅第 4 章。初学者最常见的错误是文件放置错误。他们无法使用 ls 命令列出的文件名，因为他们已将文件放置或创建在文件结构中当前工作目录上方或下方的目录中。当你创建文件时，如果你也在自己的主目录下创建了一组逻辑组织的目录，你将知道在哪里存储文件。在以下命令集中，我们在主目录下创建一个目录并使用该新目录存储文件。

要在当前工作目录下创建新目录，你使用 mkdir 命令。mkdir 命令的一般语法如下：

Syntax:
mkdir [options] dirnames
Purpose: Create directory or directories specified in dirnames
Output: New directory or directories
Commonly used options/features:
-m MODE    Creates a directory with given access modes
-p         Creates parent directories that don’t exist in the pathnames specified in dirnames

要创建名为 first 的子目录或子目录于当前工作目录下，输入以下内容：

```
$ mkdir first
$
```

此命令现在已在当前工作目录下，或作为其子目录，创建了一个名为 first 的新子目录。参考图 2.3 以获取此新子目录目录位置的图形描述。

要将当前工作目录更改为此新子目录，你使用 cd 命令。cd 命令的一般语法如下：

Syntax:
cd [directory]
Purpose: Change the current working directory to directory or return to the home directory when directory is omitted
Output: New current working directory

要通过沿路径结构向下进入到名为 first 的指定目录来更改当前工作目录为 first，输入以下内容：

```
$ cd first
$
```

你始终可以使用 pwd 命令验证当前工作目录是什么。pwd 命令的一般语法如下：

Syntax:
pwd
Purpose: Display the current working directory on screen
Output: Pathname of current working directory

你可以通过输入以下内容验证 **first** 现在是当前工作目录：

```
$ pwd
/home/bob/first
$
```

Linux 在命令行上的输出显示当前工作目录或文件夹的路径名。如前所述，此路径是通过 Linux 运行的计算机的完整文件结构的文本路由，以当前工作目录结束。在此输出示例中，路径从 / 开始，即文件系统的根。然后下降到目录 home，即运行 Linux 的计算机上文件系统的一个主要分支。然后下降到目录 bob，另一个分支，即用户的家目录名。最后下降到名为 first 的分支，即当前工作目录。

在某些系统上，根据默认设置，确定当前工作目录的另一种方法可以简单地通过查看命令行提示符来完成。此提示符可能以当前工作目录的完整路径为前缀，以当前工作目录结尾。

要返回到主目录，或子目录 first 的父目录，可以输入以下内容：

```
$ cd
$
```

另一种方法是输入以下内容，其中波浪号字符 (~) 解析为，或是主目录完整路径的替代：

```
$ cd ~
$
```

要验证你现在已上升到主目录，输入以下内容：

```
$ pwd
/home/bob
$
```

你也可以上升到主目录上方的目录，有时称为当前工作目录的父目录，输入以下内容：

```
$ cd ..
$
```

在此命令中，两个点 (..) 代表当前工作目录上方的父目录或分支。不要忘记在 cd 和第一个点之间输入空格字符。要验证你已上升到主目录的父目录，输入以下内容：

```
$ pwd
/home
$
```

要下降到主目录，输入以下内容：

```
$ cd
$
```

要验证主目录中以字母 my 开头的有两个文件，输入以下命令：

```
$ ls my*
myfile myfile2
$
```
