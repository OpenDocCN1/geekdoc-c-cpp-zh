
这些技术通常用于文本文件。此外还有*有损压缩*技术，用于减小文件大小，以便在网络上存储、处理和传输内容。有损压缩技术通常用于图像文件，例如联合图像专家组（JPEG）格式。在本章中，我们将讨论用于压缩和解压缩文本及可执行文件的工具，以及用于显示和搜索压缩文件的命令。

Linux 操作系统提供了许多用于压缩和解压缩文件以及对压缩文件执行各种操作的命令。这些命令包括 GNU 工具 `gzexe`（压缩可执行文件）、`gzip`（压缩文件）、`gunzip`（解压缩用 gzip 压缩的文件）、`zcat`（显示压缩文件；`gzcat` 功能相同）、`gzcmp`（比较压缩文件）、`gzforce`（强制为压缩文件添加 .gz 扩展名，以免 gzip 重复压缩）、`gzmore`（分页显示压缩文件）以及 `zgrep`（用于压缩文件的 grep 命令；它可在可能已压缩的文件中搜索正则表达式）。本节将主要讨论文件压缩与解压缩。

## 7.7.1 gzip 命令

gzip 命令是 GNU 用于压缩文件的工具。压缩后的文件以原文件名加上 .gz 扩展名保存。与 compress 命令一样，压缩文件保留原文件的访问/修改时间、所有权和访问权限。原文件将从文件结构中移除。如果命令不带文件参数，或使用 `-` 作为参数，gzip 将从标准输入（默认为键盘）读取输入，从而允许在管道中使用该命令（见第 9 章）。我们通常以一个或多个文件作为参数来使用该命令。以下是该命令的简要说明。

- **语法：** `gzip [option] [file-list]`
- **用途：** 压缩 **file-list** 中的每个文件，并将其存储为 **filename.gz**，其中 **filename** 是原文件名。若命令行中未指定文件或指定了 `-`，则从标准输入读取输入。
- **输出：** 压缩后的 .gz 文件；若输入来自标准输入，则输出到标准输出
- **常用选项/功能：**
  - **-N** 根据 N 的值控制压缩速度（以及压缩比），1 最快，9 最慢；慢速压缩可获得更高的压缩率
  - **-c** 将输出发送到标准输出；输入文件保持不变
  - **-d** 解压缩 .gz 文件
  - **-f** 在 .gz 版本已存在、文件有多个链接或输入文件为 **stdin** 时，强制压缩
  - **-l** 对作为参数给出的压缩文件，显示未压缩和压缩版本的大小、压缩比以及未压缩文件名
  - **-r** 递归压缩作为参数指定的目录中的文件
  - **-t** 检查作为参数指定的压缩文件的完整性
  - **-v** 显示压缩百分比和压缩文件名

## 7.7.2 gunzip 命令

gunzip 命令可用于执行相反的操作，将压缩文件恢复为原始形式。`gzip -d` 命令也可完成此任务。使用 gunzip 命令时，`-N`、`-c`、`-f`、`-l` 和 `-r` 选项的用法与 gzip 命令相同。

下面的会话展示了这两个命令带参数和不带参数的使用方式。我们使用 `man bash > bash.man` 和 `man tcsh > tcsh.man` 命令将 Bourne Again shell 和 TC shell 的手册页分别保存到 bash.man 和 tcsh.man 文件中。`gzip bash.man tcsh.man` 命令用于压缩 bash.man 和 tcsh.man 文件，`gzip -l bash.man.gz tcsh.man.gz` 命令用于显示 bash.man 和 tcsh.man 文件压缩与未压缩版本的一些信息。命令输出显示了压缩百分比等信息：bash.man 压缩了 71.3%，tcsh.man 压缩了 67.6%。`gzip bash.man.gz` 命令用于表明 gzip 不会压缩已带 .gz 扩展名的文件。如果压缩文件没有 .gz 扩展名，gzip 会尝试再次压缩它。`gunzip *.man.gz` 命令用于解压缩 bash.man.gz 和 tcsh.man.gz 文件。`gzip -d *.man.gz` 命令可完成相同任务。`ls -l` 命令用于显示压缩文件保留了原文件的修改时间、所有权和访问权限。

```
$ man bash > bash.man
$ man tcsh > tcsh.man
$ ls -l *.man
-rw-r--r-- 1 sarwar faculty 367470 Aug 30 21:39 bash.man
-rw-r--r-- 1 sarwar faculty 239996 Aug 30 21:39 tcsh.man
$ gzip bash.man
$ ls -l bash.man.gz
-rw-r--r-- 1 sarwar faculty 105342 Aug 30 21:39 bash.man.gz
$ gzip bash.man.gz
gzip: bash.man.gz already has .gz suffix - unchanged
$ gunzip bash.man.gz
$ gzip bash.man tcsh.man
$ gzip -l bash.man.gz tcsh.man.gz
 compressed uncompressed ratio uncompressed_name
 105342 367470 71.3% bash.man
 77715 239996 67.6% tcsh.man
 183057 607466 69.8% (totals)
$ gunzip *.man.gz
$ ls -l *.man
-rw-r--r-- 1 sarwar faculty 367470 Aug 30 21:39 bash.man
-rw-r--r-- 1 sarwar faculty 239996 Aug 30 21:39 tcsh.man
$
```

## 7.7.3 gzexe 命令

gzexe 命令可用于压缩可执行文件。使用 gzexe 命令压缩后的可执行文件仍然可执行，并且可以通过其名称运行。而使用 gzip 命令压缩的可执行文件则不具备这一特性。因此，为了节省磁盘空间和网络带宽，在需要将可执行文件从一台计算机传输到另一台计算机（例如通过互联网发送电子邮件）时，可以使用 gzexe 命令进行压缩。以下是该命令的简要说明。

- **语法：** `gzexe [options] [file-list]`
- **用途：** 压缩 file-list 中给出的可执行文件；备份文件会以 `filename~` 形式创建，应在压缩文件成功生成后删除
- **常用选项/功能：**
  - `-d` 解压缩已压缩的文件

下面的会话演示了 gzexe 命令的用法。注意，当你用 gzexe 命令压缩可执行文件 sh.temp 时，它会在 sh.temp~ 文件中创建原文件的备份。sh.temp 文件被压缩后，可以像普通可执行文件一样运行。`gzexe -d sh.temp` 命令用于解压缩已压缩的 sh.temp 文件。压缩版本的备份保存在 sh.temp~ 文件中。

```
$ cp /bin/sh sh.temp
$ file sh.temp
sh.temp: ELF 64-bit LSB executable, x86-64, version 1 (FreeBSD), dynamically linked (uses shared libs), for FreeBSD 10.0 (1000510), stripped
$ gzexe sh.temp
sh.temp: 49.2%
$ ls -l sh*
-rwx------ 1 sarwar faculty 71133 Aug 30 21:59 sh.temp
-rwx------ 1 sarwar faculty 139264 Aug 30 21:59 sh.temp~
$ gzexe -d sh.temp
49.2%
$ ls -l sh*
-rwx------ 1 sarwar faculty 139264 Aug 30 22:00 sh.temp
-rwx------ 1 sarwar faculty 139264 Aug 30 21:59 sh.temp~
$
```

## 7.7.4 zcat 和 zmore 命令

将压缩文件还原为原始形式再显示是一个耗时过程，因为文件创建需要磁盘输入/输出。如果你只想查看原文件的内容，可以使用 Linux 命令 zcat（用于压缩文件的 cat 命令），它显示用 gzip 压缩的文件内容。该命令在显示前会解压缩文件，原文件保持不变。zmore 命令可以分屏显示压缩文件。当没有指定文件或指定 `-` 作为参数时，这些命令从 stdin 读取输入。两个命令都允许你指定一个或多个文件作为参数。以下是 zcat 命令的简要说明。

- **语法：** `zcat [options] [file-list]`
- **用途：** 将压缩文件以其原始形式连接并发送到标准输出；若未指定文件，则从标准输入读取输入
- **常用选项/功能：**
  - `-h` 显示帮助信息
  - `-r` 递归操作子目录
  - `-t` 检查压缩文件的完整性
