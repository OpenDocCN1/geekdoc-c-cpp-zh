

## 1.8.2 Shell 的历史

当你安装或以某种方式使用 Linux 时，你必须意识到 GNU 的 Not UNIX（GNU）实用程序——自由软件基金会为内核贡献的实用程序，例如各种 Linux shell——是用户界面到内核的核心。

Shell 作为 Linux 实用程序的发展与 Linux 本身以及 Linux 系统的发展并行。第一个商用 shell，Bourne shell，是由 Stephen R. Bourne 编写的。C shell，主要由 Bill Joy 在 1970 年代后期编写，于 2.0 BSD UNIX 中很快就可用了。引入时，它为编写 shell 脚本提供了类似 C 程序的编程接口。在 C shell 之后，Korn shell 于 1989 年在 Unix System V 发布版 4 中正式引入。由贝尔实验室的 David Korn 编写，它包含了一个 Bourne shell 命令的超集，具有更强大的功能。它还包含了 C shell 的一些有用特性。另一个源自 C shell 的 shell 是 Tenex C（TC）shell。它是在 1970 年代后期编写并实现的。

在本书中展示的所有当前代表性 Linux 发行版中，默认 shell 都是 GNU bash shell。Bash 由 Brian Fox 为 GNU 项目编写，并于 1989 年首次发布。它是 Bourne、Korn 和 C shell 的超集，具有多种编程和交互功能，使其对所有用户都更有用。这些功能包括命令行编辑、无限制的命令历史、作业控制、更大的 shell 函数集，以及其他编程和交互优势。

我们在第 2 章中更详细地讨论了 Linux shell 的开发历史。

主要的 Linux shell 具有略有不同的功能和命令集。在本教科书中，我们讨论所有 Linux shell 和版本通用的功能和命令集。每当我们讨论特定于某个 shell 或版本的特性或命令时，我们会明确指出。

如果你想知道你的 Linux 系统上有哪些 shell 可用，在默认的 bash 命令行上，输入 **more /etc/shells**

该命令在我们的 Linux Mint 系统上的输出如下：

```
```text
$ more /etc/shells
# /etc/shells: valid login shells
/bin/sh
/bin/dash
/bin/bash
/bin/rbash
/bin/csh
$
```

### 1.8.3 未来发展

就我们目前所见，以下三个发展对 Linux 开发者社区构成了最大的挑战：

- 1. 可能最令人兴奋和最具挑战性的当前 Linux 开发，针对所有 Linux 发行版，集中在将 Zettabyte 文件系统（ZFS）纳入内核，并让“启动”或系统磁盘使用 ZFS。ZFS 由 Sun Microsystems 在 2006 年纳入 Solaris 家族之前几年开发。如今，它是我们代表性的 Debian 家族系统 Ubuntu 和 Linux Mint 上的内核可加载模块。作为“用户文件系统”，ZFS 并不会排除使用 EXT4。我们在本书的 GitHub 站点上提供了 Web 资源列表，网址为 open-zfs.org。
- 2. 未来 Linux 系统的另一个主要挑战是 systemd 在内核中进一步发展和传播，最重要的是在容器虚拟化领域。容器虚拟化的例子有 Linux Containers version C/Linux Containers version D（LXC/LXD）和 Docker。目前，systemd 是一个“超级内核”系统管理守护进程、API 库和实用程序套件，设计为 Linux 的中央管理和配置平台。systemd 用于当前大多数 Linux 内核的实现和官方发布中。它是 Linux 初始化系统（由 Linux 内核调用以在 Linux 启动过程中初始化用户空间，并在之后最重要的是管理所有进程和服务的进程），从而取代了 Linux System V 和 BSD 风格的 init 守护进程。名称 systemd 遵循了使守护进程更容易区分的惯例，即文件名以字母“d”结尾。
- 3. 最后，用各种其他软件系统取代 X Window System 协议，例如 Wayland，有望产生更小、更有效的 GUI 系统。Wayland 是一个协议，指定了显示服务器（称为 Wayland compositor）与其客户端之间的通信，以及该协议在 C 中的参考实现。我们在本书的 GitHub 站点上提供了 Web 资源列表，获取有关 Wayland 的更多信息。

## 1.9 Linux 系统发行版的基本比较

如表 1.1 所示，Linux 系统发行版的总体发展沿着三个主要分支进行：Debian、Slackware 和 Red Hat。并且如可在 http://futurist.se 的本书 GitHub 站点上看到的 Web 资源图表所示，还有大量其他发行版，其历史和具体实现细节与这三个主要分支并行（或在某些情况下偏离）。

所有在 Web 资源图表中显示的发行版中都有非常大的多样性和发行版特定的功能实现差异。其中一些特定的发行版实现差异按我们主观的顺序列出，并简要描述如下：

- 1. 是否可以在系统上轻松安装和维护 ZFS。
- 2. 使用的内核版本以及 AUI 实现的具体细节。
- 3. 任何特定发行版中使用的包管理系统（例如高级打包工具（APT）或 Yellow Dog Updater，Modified（YUM））。
- 4. 通过包管理系统可用的应用程序软件包的多样性。
- 5. 可用的预编译和源代码包的大致数量。
- 6. 是否可以用图形包管理前端（例如 Linux Mint 中的软件管理器）安装包，以及其 GUI 的可靠性、广泛性和包容性如何。
- 7. 从文件系统根目录到用户级别的文件系统组织。
- 8. 维护每个版本的方法的可靠性，无论是“滚动”还是稳定升级。
- 9. 设备驱动程序基础，或有多少以及哪些外围设备实际上可以与系统一起工作。
- 10. 可用的 GUI 桌面管理系统，如果系统可以默认安装一个，以及它们的风格和感觉（例如 Gnome 和 K 桌面环境（KDE））。
- 11. 指令集架构支持（例如 x86、x86-64 和高级 RISC 机器（ARM））。
- 12. 默认文件系统类型以及可以轻松容纳的文件系统类型（例如 Btrfs、XFS、ZFS、ext2、ext3、ext4 和 NFSv4）。
- 13. GNU 编译器集合组件（例如 GNU C 编译器 [gcc] 和 Python）的可用性和版本。
- 14. CD/DVD/通用串行总线（USB）实时媒体映像的可用性，以及是否可以使用其中一个“试用”系统（也许甚至具有“持久性”）。
- 15. 在流行的虚拟机管理器（例如 VirtualBox 或 LXC/LXD）中系统标准映像的可用性。
- 16. 使用的安全系统（SELinux、AppArmor）。

所有这些实现差异，以及更多差异，为用户群提供了个人选择。它们允许根据用户可用的广泛用例定制用户体验。

### 1.9.1 Linux 系统标准化

发行版的多样性和分歧的缺点是，程序甚至命令在一种发行版上工作，在另一种发行版上可能不存在或无法工作。这违背了系统本身用户友好性的固有优势。人们已经尝试标准化 Linux 和 Linux——例如，通过 IEEE 可移植操作系统接口（POSIX）。该软件标准不仅涵盖 Linux，而且特别指定了程序操作和用户界面，留下其实现给开发者。已经采用了多个标准，还有更多标准被提议。例如，已采用的 POSIX 标准指定了 shell 和实用程序标准化。

最具包容性和最广泛的标准化机制无疑是单一 UNIX 规范（SUS）。它是一系列计算机操作系统标准，符合该标准是获得“Unix”名称资格的必要条件。SUS 的核心规范由 Austin Group 开发和维护，该组织是 IEEE、ISO JTC 1 SC22 和 The Open Group 的联合工作组。有关更多信息，请参阅本书 GitHub 站点上 The Open Group 的 Web 资源列表。

此外，Linux 标准库（LSB）是一种标准化规范协议，通过确保编译后的应用程序在声称符合 LSB 的 Linux 系统上运行，从而促进 Linux 发行版之间的兼容性。在本书撰写时，LSB 版本 5 是当前规范。请参阅本书 GitHub 站点上的 Web 资源列表了解 LSB。

## 摘要

操作系统是运行在计算机系统硬件上以管理其硬件和软件资源的软件。它还为计算机系统的用户提供一个简单、易于使用的虚拟机。操作系统提供的基本服务提供高效和安全的程序执行、I/O 操作、进程间通信、错误检测和报告以及文件操作。

操作系统按同时可使用系统的用户数量和可同时在系统上执行的进程数量进行分类：单用户单进程；单用户多进程；以及多用户多进程操作系统。此外，允许用户与正在执行的程序（进程）交互的操作系统称为交互式系统，而不允许的则称为批处理系统。多用户多进程交互式系统称为分时系统，Linux 就是一个典型例子。多用户多进程系统的目的是通过在并发执行的进程之间切换来提高系统资源利用率。这种能力导致系统吞吐量更高，即单位时间内完成的进程数。

要使用计算机系统，用户向操作系统发出命令。如果操作系统通过键盘接受命令，则它具有 CUI。如果操作系统允许用户通过鼠标等点按设备发出命令，则它具有 GUI。虽然 Linux 以 CUI 作为其基本界面，但它可以运行基于 X Window System（Project Athena，MIT）的软件，提供 GUI。现在大多数 Linux 系统都有两种界面。Mac OS X（Darwin），运行在 Apple 产品上，是最著名的基于 GUI 的 Linux 系统。

计算机系统由多个硬件和软件组件组成。典型的 Linux 系统的软件组件由多个层组成：应用程序、shell、语言库、系统调用接口、Linux 内核和设备驱动程序。内核是 Linux 操作系统的主要部分，执行所有与系统资源分配和释放相关的任务。shell 和应用程序层包含通常称为 AUI 的内容。语言库和系统调用接口包含 API。
