## 16.6.4 Thread Attributes

线程属性决定了线程的行为。将 `pthread_create()` 的第二个参数设为空指针时，线程将使用默认属性创建。线程的属性如下：

- *detachstate*: 分离线程属性
- *stackaddr*: 线程栈的最低地址
- *stacksize*: 线程栈的字节大小
- *guardsize*: 线程栈末尾保护缓冲区的字节大小

保护缓冲区提供对栈指针溢出的保护。

你可以使用 `pthread_attr_t` 结构来存储线程的属性并将其与我们创建的线程关联。你可以使用 `pthread_attr_init()` 函数将此结构初始化为默认属性。你可以使用其他函数来更改 `pthread_attr_t` 结构中存储的单个属性。例如，你可以使用 `pthread_attr_setdetachstate()` 函数将分离状态设为 `PTHREAD_CREATE_DETACHED` 以创建分离状态的线程，或设为 `PTHREAD_CREATE_JOINABLE` 以创建可加入状态的线程。

你可以使用 `pthread_attr_destroy()` 将 `pthread_attr_t` 中的属性设为无效值。如果 `pthread_attr_t` 是动态分配的，对 `pthread_attr_destroy()` 的调用会释放空间。

总之，你可以使用以下步骤创建具有自定义属性的线程：

- 1. 创建 `pthread_attr_t` 类型的对象
- 2. 使用 `pthread_attr_init()` 将 `pthread_attr_t` 初始化为默认属性
- 3. 使用相关函数将属性对象修改为期望值
- 4. 将属性对象的指针传递给 `pthread_create()` 以创建具有期望属性的线程
- 5. 通过调用 `pthread_attr_destroy()` 释放属性对象

以下是这些步骤的代码结构：

```
...
int retval;
pthread_t tid;
pthread_attr_t attr;

retval = pthread_attr_init(&attr);
if (retval != 0)
    return(retval);
retval = pthread_attr_setdetachstate(&attr, PTHREAD_CREATE_DETACHED);
if (retval == 0)
    retval = pthread_create(&tid, &attr, thread_fn, arg);
pthread_attr_destroy(&attr);
...
```

## 16.6.5 Thread-Specific Data

由于进程中的线程共享其地址空间，它们可以共享访问其数据区。这意味着对数据项所做的更改对其他线程可见。有时，你希望进程中的每个线程都有其自己的数据项副本，例如变量。你可以将变量的副本存储在线程特定数据区中。对此变量所做的更改对其他线程不可见。

你可以创建任意多个线程特定数据项，每个项的类型为 void*。每个此类项都由你使用 pthread_key_create() 创建的键引用。此函数的第一个参数是指向 pthread_key_t 类型对象的指针，第二个参数是线程清理函数。当每个线程终止时，清理函数会自动调用以释放线程特定数据项。即使线程在执行期间被取消，此函数也会被调用。清理函数用于防止内存泄漏。如果不需要清理函数，将第二个参数设为空。

```
...
 pthread_key_t thread_key;
 ...
 void * thread_fn (void *args)
 {
 ...
 int thread_item;
 ...
 pthread_setspecific(thread_key, thread_item);
 ...
 }
```

你可以使用 `pthread_getspecific()` 函数访问线程特定数据项，其唯一参数为键，并返回与键关联的数据项。由于线程特定值以 void 类型存储，你必须将其类型转换为期望的类型，如以下代码片段所示。

```
...
 int fd;
 ...
 fd = (int) pthread_getspecific(thread_key);
 ...
```

pthread 库为各种同步结构提供了支持，也称为原语，包括互斥锁、读写锁、信号量和条件变量。你可以使用这些原语解决并发编程中与竞争条件和临界区问题相关的各种问题。表 16.12 显示了一组与上述同步结构相关的 pthread 库函数。
