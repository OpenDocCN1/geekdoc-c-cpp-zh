## 总结

Linux 文本编辑器对于基于 CUI 的 Linux 系统界面操作至关重要，即使你使用的是 GUI，它们也非常重要。它们允许你创建对系统操作至关重要且关键的文本文件，例如 Bash shell 脚本或 systemd 单元文件，或者编辑现有的文本实体，例如应用程序的配置文件。

本章介绍了基于 CUI 的 nano 编辑器的基本知识，并给出了一些在选择更复杂（尽管也更复杂）的编辑器（如 vi、vim 或 emacs）时可能需要考虑的重要事项。
