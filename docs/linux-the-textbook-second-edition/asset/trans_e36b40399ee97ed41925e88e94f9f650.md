## 2.4.2 查看文件内容

要开始处理文件，你可以使用 cat 命令轻松创建新的文本文件。cat 命令的语法如下：

```
Syntax:
  cat [options] [file-list]
Purpose: Join one or more files sequentially or display them in the console window
Output: Contents of the files in file-list displayed on the screen, one file at a time
Commonly used options/features:
  +E      Displays $ at the end of each line
  -n      Puts line numbers on the displayed lines
  -- help Displays the purpose of the command and a brief explanation of each option
```

cat 命令是 concatenate 的缩写，允许你连接文件。在示例中，你将把键盘输入的内容连接到当前工作目录中正在创建的新文件。这是通过重定向字符 > 实现的，它获取你在标准输入（此处为键盘）中输入的内容，并将其定向到名为 myfile 的文件中。你可以将键盘及其提供的信息流视为一个文件。如第 2.2 节所述，这种用法涉及命令 cat，但不涉及选项、选项参数或命令参数。它只使用了命令、一个重定向字符以及一个名为 myfile 的目标（即目的地），重定向将指向该目标。

这与第 2.2 节中所示并简要描述的单命令相反，是在命令行上键入的多命令的最简单示例。在多命令中，你可以使用连接运算符（例如这里显示的重定向字符）将单个 Linux 命令串成链。

```
$ cat > myfile
This is an example of how to use the cat command to add plain text to a file
<Ctrl+D>
$
```

你可以随心所欲地键入任意多行文本，在键盘上按 <Enter> 键以区分文件中的各行。然后，在新的一行上，当你按住 <Ctrl+D> 时，将使用你键入的命令在当前工作目录中创建该文件。由于这是一个使用键盘创建的纯文本文件，你可以通过以下方式查看其内容：

```
$ more myfile
This is an example of how to use the cat command to add plain text to a file
$
```

这是单个 Linux 命令语法的简单示例。

more 命令的一般语法如下：

```
Syntax:
  more [options] [file-list]
Purpose: Concatenate/display the files in file-list on the screen, one screen at a time
Output: Contents of the files in file-list displayed on the screen, one page at a time
Commonly used options/features:
  +E/str    Starts two lines before the first line containing str
  -nN       Displays n lines per screen/page
  +N        Starts displaying the contents of the file at line number n
```

more 命令默认一次显示文件的一屏内容。如果文件有好几页长，你可以按键盘上的 <Space> 键继续查看后续页面，或按 Q 键退出。Linux 有一个名为 pg 的命令，其功能与 more 命令相同。

## 2.4.3 创建、删除和管理文件

要将一个文件的内容复制到另一个文件中，请使用 cp 命令。cp 命令的一般语法如下：

```
Syntax:
  cp [options] file1 file2
Purpose: Copy file1 to file2; if file2 is a directory, make a copy of file1 in this directory
Output: Copied files
Commonly used options/features:
  -i  If destination exists, prompt before overwriting
  -p  Preserves file access modes and modification times on copied files
  -r  Recursively copies files and subdirectories
```

例如，要制作一个名为 myfile 的文件的全新副本，并命名为 myfile2，请键入以下内容：

```
$ cp myfile myfile2
$
```

cp 命令的这种用法有两个必需的命令参数。第一个参数是已经存在且你想要复制的源文件。第二个参数是目标文件，即将成为副本的文件名。请注意，许多 Linux 命令可以接受普通文件作为参数，也可以接受目录文件作为参数。这可能会改变命令所完成的基本任务。同样值得注意的是，不仅文件名可以作为参数，路径名也可以。这会改变命令操作在文件系统路径结构中的位置。

要更改文件或目录的名称，可以使用 mv 命令。mv 命令的一般语法如下：

```
Syntax:
  mv [options] file1 file2
  mv [options] file-list directory
Purpose: First syntax: Rename file1 to file2
         Second syntax: Move all the files in file-list to directory
Output: Renamed or relocated files
Commonly used options/features:
  -f  Forces the move regardless of the file access modes of the destination file
  -i  Prompts the user before overwriting the destination
```

在以下用法中，mv 命令的第一个参数是源文件名，第二个参数是目标名称。

ls 命令将列出当前工作目录或文件夹中的文件或文件夹名称。此外，与我们迄今为止使用过的其他命令一样，如果你为命令的路径名列表参数提供了完整的路径名规范，那么你就可以沿该路径名列表列出文件和文件夹的名称。要查看当前工作目录中的文件名，请键入以下内容：

```
$ ls
Desktop      Documents      Downloads      Dropbox      Music      Pictures
Public      Templates      Linuxtextbook2      Videos
$
```

请注意，你得到的文件名列表可能不会与我们这里看到的完全相同，因为你的系统会在你的主目录中自动放置一些文件，就像我们使用的示例一样，此外还有我们共同创建的名为 myfile 和 myfile2 的文件。另请注意，此文件列表不包含 renamed_file 这个名字，因为我们已经删除了该文件。

你要执行的下一命令实际上只是执行 ls 命令的另一种或修改后的方式，它包含命令名和选项。如第 2.2 节所示，Linux 命令可以有选项，这些选项可以与命令一起键入命令行，以改变基本命令的行为。就 ls 命令而言，选项 l 和 a 会生成所有普通文件和系统（点）文件的更长列表，并提供有关文件的其它附带信息。别忘了在 s 和破折号之间输入空格。再次记住第 2.2 节的内容：在命令行上键入 Linux 命令时，空格用于分隔或划分命令的各个组成部分。
