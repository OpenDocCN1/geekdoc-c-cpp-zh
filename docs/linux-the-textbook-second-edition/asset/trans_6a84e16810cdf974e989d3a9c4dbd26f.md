## 17.6.2.1 使用 tar 归档和恢复文件

普通 Linux 用户如果愿意可以归档自己的工作。他们通常需要对与某个项目相关的文件对象进行此操作，以便通过电子邮件、ssh 或通过二级存储介质（USB 闪存盘、DVD 或 CD-ROM）将其传输给他人。或者他们可能希望通过相同的方法保留自己的文件系统对象作为备份。

创建归档的主要原因是处理（发送或接收）单个文件而不是完整目录层次结构的便利性。如果没有归档，发送方可能不得不发送多个文件和目录（文件结构），接收方必须以正确的层次结构恢复它们。如果没有像 tar 这样的归档工具，根据文件和目录结构的大小，发送、接收和重建文件结构可能非常耗时。

在第 7 章第 7.7 节中，我们讨论了使用 bzip2、gzip、gunzip、gzexe、xz、zcat 和 zmore 命令进行文件压缩，并指出压缩可以节省磁盘空间和传输时间。然而，压缩小文件通常不会产生太多压缩。此外，压缩一个簇大小（最小磁盘存储单元；一个或多个扇区）或更小的文件并不能帮助节省磁盘空间，即使压缩确实产生了更小的文件，因为系统最终仍会使用一个簇来保存压缩文件。不过，如果压缩确实产生了更小的文件，你在传输压缩版本时可以节省时间。如果磁盘块大小为 512 字节并且一个簇由两个以上块组成，你可以使用 tar 命令将文件打包到一个文件中，每个文件前面都有一个 512 字节的 tar 头，如图 17.7 所示。

## 17.6.2.2 八个简单的 tar

在本节中，我们展示了 tar 命令最简单的八种用法。在后续章节中，我们将通过在我们的 Linux 系统上运行的更详细的示例会话，对这些“简单 tar”进行扩展。

- 1. 创建归档
这是从目录创建归档文件最简单的命令。

```
$ tar --create --verbose --file archive_name.tar directory_name
```

其中
--create 是创建新归档的操作
--verbose 是列出正在处理的文件的操作
--file 是指定文件的操作
archive_name.tar 是归档文件的名称和
directory_name 是你想要归档的目录

- 2. 创建归档并保留其 ACL 权限
创建归档的一个简单变体是使用一个选项来保留目录所拥有的 ACL。ACL 在本书网站第 W26.9.2 节中有详细说明。

```
$ tar --acls --create --verbose --file archive_name.tar directory_name
```

其中
--acls 是保留目录所拥有的 ACL 的选项
--create 是创建新归档的操作
--verbose 是列出正在处理的文件的操作
--file 是指定文件的操作 archive_name.tar 是归档文件的名称和
directory_name 是你想要归档的目录

- 3. 提取归档
这是从归档文件提取目录最简单的命令。

```
$ tar --extract --verbose --file archive_name.tar
```

其中
--extract 是从归档文件提取 directory_name 的操作
--verbose 是列出正在处理的文件的操作
--file 是指定文件的操作 archive_name.tar 是归档文件的名称

在其最简单的形式中，从归档文件创建的目录将与归档文件的名称相同，去掉 .tar 扩展名。

- 4. 提取归档并恢复其 ACL 条目
提取归档的一个简单变体是使用一个选项来恢复归档文件所保留的 ACL（如果有）。

```
$ tar --acls --extract --verbose --file archive_name.tar
```

其中
--acls 是恢复归档文件所保留的 ACL 的选项
--extract 是提取归档文件的操作
--verbose 是列出正在处理的文件的操作
--file 是指定文件的操作 archive_name.tar 是归档文件的名称

在此最简单的形式变体中，从归档文件创建的目录将与归档文件的名称相同，去掉 .tar 扩展名。

## 5. 列出归档的内容

此过程允许你在不从中提取任何内容的情况下查看归档文件的内容。

```
$ tar --list --verbose --file archive_name.tar
```

其中
--list 是列出归档文件内容的操作
--verbose 是列出正在处理的文件的操作
--file 是指定文件的操作 archive_name.tar 是归档文件的名称

## 6. 从归档文件提取单个文件

以下命令仅从归档文件提取特定文件。

```
$ tar --extract --verbose --file archive_file.tar file_pathname
```

其中
--extract 是提取单个文件的操作
--verbose 是列出正在处理的文件的操作
--file 是指定文件的操作 archive_name.tar 是你正在提取的归档文件的名称和
file_pathname 是归档内部你要提取的文件的完整路径名规范

## 7. 从归档文件提取单个目录

从归档中提取单个文件的变体，提取单个目录，以及递归提取其任何子目录和文件，是指定你想要提取的目录名称如下：

```
$ tar --extract --verbose --file archive_file.tar directory_pathname
```

其中
--extract 是提取单个文件的操作
--verbose 是列出正在处理的文件的操作
--file 是指定文件的操作 archive_name.tar 是你正在提取的归档文件的名称和
directory_pathname 是归档内部你要提取的目录的完整路径名规范

## 8. 使用 --append 选项向现有归档添加文件或目录

要向现有归档添加文件，请执行以下操作：

```
$ tar -append -verbose --file archive_name.tar file_or_directory_name
```

其中
--append 是将单个文件或目录添加到归档的操作
--verbose 是列出正在处理的文件或目录的操作
--file 是指定文件的操作 archive_name.tar 是你正在添加文件或目录的归档文件的名称和
file_or_directory_name 是你想要添加到归档内部的文件或目录的完整路径名规范

## 17.6.2.3 使用 tar 创建归档

如前一节所述，tar 命令最常见的用途是使用 --create 或 --append 选项归档（也称为打包）文件和/或目录列表。--create 选项创建新的归档，而 --append 选项将文件附加到当前归档的末尾。
