## 2.8.4 Shell 启动文件和环境变量

每个 shell 的行为、其执行命令和程序的机制、其处理命令和程序 I/O 的方式以及其编程方式，都受某些环境变量设置的影響。

每个 Linux 系统都有一个初始系统启动文件，通常命名为 .profile 或 .login。该文件包含 shell 和一些其他实用程序的重要环境变量的初始设置。此外，当你启动特定 shell 时，会执行特定 shell 的隐藏文件。它们被称为 shell 启动文件，Bash 的是 .bashrc，C shell 的是 .cshrc。这些隐藏文件最初由系统管理员为所有用户安全使用而配置。表 2.6 列出了 Bash、Bourne、Korn 和 C shell 共有的一些重要环境变量；C shell 变量名（如果适用）在 Bash、Bourne 和 Korn shell 变量名的大写之后以小写形式给出。请注意，你的系统管理员可能未设置某些变量，例如 ENV。

## 2.9 Shell 元字符

除字母和数字之外的多数字符对 shell 具有特殊含义。这些字符称为 shell 元字符，因此如果不以特定方式在语法上指定它们，就不能将它们用作 shell 命令中的字面字符。因此，尝试不要在命名文件时使用它们。此外，当这些字符在命令中使用时，在字符前后不需要空格。但是，为了清晰起见，你可以在 shell 元字符前后使用空格。表 2.7 包含 shell 元字符列表及其用途。

shell 元字符允许你在一条命令行中指定多个目录中的多个文件。我们将在后续章节中描述这些字符的使用，但这里给出一些简单示例来解释一些常用元字符的含义：

以下命令打印你当前目录中所有文件名长度为两个字符且扩展名为 .htm1 的文件，其中第一个字符为数字，第二个为大写或小写字母。这些文件打印到打印机 spr 上。

```
$ lpr -Pspr [0-9][a-zA-Z].htm

```

```
$ ls lab[0-9]???.c
lab11a.c lab1a1.c lab123.c lab4ab.c
$
```

## 2.10 sudo 和 su 命令

sudo 命令允许被许可的用户以超级用户身份执行命令，或根据安全策略承担另一个用户的角色。su 命令允许普通用户切换用户角色或在系统上模拟超级用户。超级用户对系统上的所有内容具有文件权限和访问特权。

在以下各章中展示的许多操作中，尤其是在第 17 章系统管理中，将需要执行 sudo 或 su 命令来完成所示任务。为了使用此命令，有必要知道 root 或超级用户密码。

我们在第 W26 章第 9.2.1 节的书籍网站上对 sudo 命令给出了更完整的解释。

使用 su 命令的示例如下：

```
$ su
Password: www
/home/bob#
```
