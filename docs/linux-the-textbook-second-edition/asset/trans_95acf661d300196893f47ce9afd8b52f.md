

一个通配符模式匹配 **test-string** 的任何值。也称为 *默认情况*，它允许执行一组命令来处理异常（即错误）情况，用于 **test-string** 中的值与任何模式都不匹配的情况。连续的分号 (;;) 用于分隔 **command-list**。如果没有 ;;，则会执行下一个模式的命令列表中的第一个命令，导致程序出现意外的行为。图 12.8 描述了 case 语句的语义。

**case_demo** 文件中的以下脚本展示了 case 语句的简单但具有代表性的用法。它是一个菜单驱动程序，显示选项菜单并提示您输入选项。您的选项被读入名为 *option* 的变量。然后 case 语句将您的选项与其中四个可用模式（本例中为单个字符）逐一匹配，并在找到匹配项时执行相应的 **command-list**（本例中为单个命令）。因此，在提示符下，如果您输入 d 并按 <Enter>，则会执行 date 命令并退出 case。然后在执行 exit 0 命令后程序退出。代码之后的代码会话中给出了脚本的几个示例运行。

```
$ cat case_demo
#!/bin/bash
echo "Use one of the following options:"
echo "  d:  To display today's date and present time"
echo "  l:  To see the listing of files in your present working directory"
echo "  w:  To see who's logged in"
echo "  q:  To quit this program"
echo -n "Enter your option and hit <Enter>: "
read option
case "$option" in
    d)  date
        ;;
    l)  ls
        ;;
    w)  who
        ;;
    q)  exit 0
        ;;
esac
exit 0

## 12.7 命令分组

可以作为一组运行多个 shell 命令。以下是命令分组的简要说明：

```
```

或

{ command-list; }
```
```

目的：语法 1——在当前 Bash 的子进程下执行 command-list 中的命令
语法 2——作为一组执行 command-list 中的命令

子 shell 继承父 shell 的环境副本，除了被捕获但被忽略的信号。当使用第二种语法执行命令时，不会创建子 shell。它允许重定向 command-list 中命令的输出。在第二种语法中，最后一个命令后必须有分号，{ 后必须有空格，} 前必须有空格。以下交互式会话显示了使用两种语法进行命令分组的几个示例。
