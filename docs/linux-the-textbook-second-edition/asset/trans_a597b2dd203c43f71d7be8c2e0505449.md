## 10.6.2 Linux Daemons

尽管在后台运行的任何进程都可以称为守护进程，但在 Linux 用语中，守护进程是一个在后台运行的系统进程。守护进程经常在 Linux 中用于向用户或运行中的软件提供各种类型的服务并处理系统管理任务。例如，打印、日志记录、电子邮件、Web 浏览、通过 Secure Shell 进行远程登录、文件传输、通过社交网络站点进行交互以及 finger 服务都是通过守护进程提供的。打印服务由打印机守护进程 cupsd 通过 systemd 提供。Finger 服务（参见第 11 章）由 finger 守护进程 fingerd 处理，前提是该服务已在系统启动时启动并启用。传统的 inetd 守护进程，即 Linux Internet 超级服务器，已被作为 systemd 下的服务运行的 NetworkManager 守护进程取代。有关 systemd 守护进程和服务的更多信息，请参阅第 20 章。

## 10.6.3 Sequential and Parallel Execution of Commands

你可以在一个命令行上输入多个命令，以便对这些命令进行顺序和/或并行执行。以下是指定在一个命令行中顺序执行命令的语法的简要说明。

```
Syntax:
  cmd1; cmd2; ...; cmdN
Purpose: Execute commands cmd1, cmd2, ..., cmdN sequentially as separate processes
```

请注意，分号用作命令分隔符，因此不跟在最后一个命令之后。分号前后不需要空格，但你可以使用空格以提高清晰度。这些命令一个接一个地执行，就好像每个命令都在单独的一行中输入一样。在以下会话中，date 和 echo 命令作为单独的进程顺序执行。

```
$ date; echo Hello, World!
Wed Oct 11 22:16:05 PKT 2017
Hello, World!
$
```

你可以通过在每个命令末尾加上与号（&）来指定命令行中的并行执行命令。以与号结尾的命令也在后台执行。与号前后不需要空格，但你可以使用空格以提高清晰度。当你在后台执行命令时，shell 会显示以下一对作为输出：[jobID] PID，其中第一个作业 ID 为 1，按线性递增方式加 1 到最后使用的作业 ID。与 PID 一样，如果作业 ID 未分配给当前正在运行的进程，则作业 ID 可能会被回收。以下是指定在一个命令行中并行执行 shell 命令的语法的简要说明。

```
Syntax:
  cmd1& cmd2& ... cmdN&
Purpose: Execute commands cmd1, cmd2, ..., cmdN in parallel as separate processes
```

以下会话在 Bash 下执行。date 和 echo 命令并行且在后台执行，然后 uname 和 who 命令在前台顺序执行。通常，由于 who 命令最后执行，其输出始终最后显示。其他三个命令（date、echo 和 uname）的输出可能以任何顺序显示。这种顺序取决于进程的调度和每个进程执行所需的时间。因此，如果你再次执行命令行，可能不会重现相同的输出顺序。在以下会话中，输出按 echo、date、uname 和 who 的顺序显示。date 和 echo 命令的作业 ID 和 PID 分别为 [1] 32429 和 [2] 32430。

```
$ date & echo Hello, World! & uname; who
[1] 32429
[2] 32430
Hello, World!
Fri Jul 7 20:16:28 PDT 2017
Linux
[1]- Done
[2]+ Done
date
bob
tty8
2017-06-20 14:14 (:0)
$
```

命令行中的最后一个 & 将自上一个 & 以来的所有命令放在一个进程中。因此，在以下命令行会话中，date 命令作为一个进程执行，而 who; whoami; uname; echo Hello, World! & 中的所有命令作为另一个进程。

如以下会话所示，两个进程的作业 ID 和 PID 对分别为 [1] 32445 和 [1] 32449。请注意，两个作业的作业 ID 均为 1。此外，两个进程的 PID 不连续。最后，如会话的阴影区域所示，由于 shell 提示符在两个进程（作业）创建后但在任何或部分输出显示在屏幕上之前返回，我们必须按 <Enter> 键再次显示 shell 提示符。

```
$ date & who; whoami; uname; echo Hello, World! &
[1] 32445
Fri Jul 7 20:22:28 PDT 2017
bob
tty8
2017-06-20 14:14 (:0)
[1]+ Done
date
bob
[1] 32449
Hello, World!
$
```

正如第 12 章中将简要讨论的那样，Linux 允许你通过使用分号分隔命令并将它们括在括号中来对命令进行分组并作为一个进程执行。这称为命令分组。因为命令组中的所有命令都执行一个进程，所以它们由同一个子 shell 执行。但是，所有命令按顺序执行，一个接一个。以下是命令分组语法的简要说明。

```
Syntax:
(cmd1; cmd2; ...; cmdN)

Purpose: Execute commands cmd1, cmd2, ..., cmdN sequentially, but as one process
```

在以下 Bash 会话中，因此，date 和 echo 命令顺序执行，但作为一个进程。

```
$ (date; echo Hello, World!)
Fri Jul 7 20:38:21 PDT 2017
Hello, World!
$
```

你可以通过用其他命令或命令组分隔命令组来将命令分组与顺序执行结合起来。在以下会话中，date 和 echo 命令作为一个进程执行，然后 who 命令作为单独的进程执行。

```
$ (date; echo Hello, World\!); who
Fri Jul  7 20:40:54 PDT 2017
Hello, World!
bob          tty8           2017-06-20 14:14 (:0)
$
```

命令组可以嵌套。因此，((date; echo Hello, World!); who) 和 ((date; echo Hello, World!); (who; uname)) 都是有效命令并产生预期结果。当组作为单独的进程执行时，命令分组更有意义，如以下会话所示。

```
$ (date ; echo Hello, World\!)&
[1] 446
$ Fri Jul  7 20:42:28 PDT 2017
Hello, World!
<Enter>
[1]+ Done               ( date; echo Hello, World\! )
$ (date; echo Hello, World)& (who; uname)& whoami
[1] 453
[2] 454
bob
bob@bob-sbc-flt1 ~ $ bob          tty8           2017-06-20 14:14 (:0)
Fri Jul  7 20:44:48 PDT 2017
Hello, World
Linux

[1]- Done               ( date; echo Hello, World )
[2]+ Done               ( who; uname )
<Enter>
[2]    Done               ( who; uname )
$
```

在第二个命令组中，(date; echo Hello, World) 和 (who; uname) 在后台执行，而 whoami 命令在前台执行；所有三个命令并行执行。同样，输出的顺序取决于这些命令的调度。
