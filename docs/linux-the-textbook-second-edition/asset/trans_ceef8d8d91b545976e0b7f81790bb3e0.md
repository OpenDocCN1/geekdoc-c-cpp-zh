路由的关键在于为互联网上的每台主机分配唯一的 IP 标识。IP 通过唯一标识主机所在的网络，然后在该网络上唯一标识主机来实现这一点。标识符，即 IPv4 中的 32 位正整数和 IPv6 中的 128 位正整数，被称为主机的 IP 地址。每个 IP 数据报中都包含发送方和接收方的 IP 地址。发送方的 IP 地址使接收方能够识别并响应发送方。主机和路由器通过检查 IP 数据报上的目的 IP 地址来执行路由。

在 IPv4 中，IP 地址分为三个字段：地址类、网络 ID 和主机 ID。地址类字段标识地址的类别并决定网络 ID 和主机 ID 字段中使用的位数。该方案产生五种地址类：A、B、C、D 和 E，其中 A–C 类是最常见的。图 11.4 显示了五种地址类型的结构。属于 D 类和 E 类的 IP 地址具有特殊用途，其讨论超出了本教材的范围。一个中央机构，网络信息中心（NIC；www.internic.net），分配所有 IP 地址。

可以连接到互联网的 A–C 类网络的最大数量由表达式给出：2⁷ + 2¹⁴ + 2²¹。这里，7、14 和 21 分别是用于指定 A–C 类地址中网络 ID 的位数。因此，有 2⁷ 个 A 类网络，2¹⁴ 个 B 类网络和 2²¹ 个 C 类网络。这些数字的总和为 2,113,664 个网络。同样，用于标识三个类地址中主机 ID 的位数可用于得出可以连接到互联网的主机的最大数量。因此，每个 A 类网络约有 2²⁴ 台主机，每个 B 类网络有 2¹⁶ 台主机，每个 C 类网络有 2⁸ 台主机。三种网络类型上所有主机的总和为 3,758,096,400 台主机。由于一些特殊地址（例如广播地址和本地主机地址），A–C 类网络和主机的实际数量略小于所示数字。广播地址用于寻址网络上的所有主机。主机使用本地主机地址将数据报发送给自己。因此，以本地主机为目的地址的 IP 数据报永远不会放到网络上。

为了减缓 IPv4 地址的使用速度并减少互联网路由器上路由表的增长，互联网工程任务组（IETF；www.ietf.org）在 1993 年引入了无类别域间路由（CIDR）。在 CIDR 下，IPv4 中的网络地址空间在任何地址位边界上分配，而不仅仅是在 8 位段上。互联网上有大量无类别网络。

尽管 IPv4 地址方案可用于标识大量网络和主机，但它无法应对互联网的快速增长。IPv6 的众多优点之一是可以连接的极大量主机。借助 128 位地址，互联网上的主机最大数量将增加到大约 2^128，这大于 3.4 × 10^38。这个数字大约是现今世界人口的 6 × 2^28 倍。IPing 的一个缺点是，由于地址大小非常大，记住 IPv6 地址变得非常困难。然而，由于大多数用户更喜欢使用符号名称，记住 IPv6 地址不应构成问题。此外，与点分十进制表示法（DDN）类似的一些紧凑表示法也已为 IPv6 地址提出。许多大型公司和学术机构已被分配 IPv6 地址，包括 Google、IBM、Intel、Microsoft、MIT、UC Berkeley 和 Iowa State University。你可以使用 host 命令来查找某个组织是否已被分配 IPv6 地址，如下所示：

```
$ host stanford.edu
stanford.edu has address 171.67.215.200
stanford.edu has IPv6 address 2607:f6d0:0:925a::ab43:d7c8
stanford.edu mail is handled by 10 mxa-00000d03.gs1b.pphosted.com.
stanford.edu mail is handled by 10 mxb-00000d03.gs1b.pphosted.com.
$
```

请注意，IPv6 地址以冒号十六进制表示法显示。在这种表示法中，使用两个十六进制数字指定地址的每个字节。在地址的每两个字节之间——即四个十六进制数字——插入一个冒号（:）。如果两个连续冒号之间的数字不是四位数，则它表示两个字节序列中的最低有效半字节。例如，地址中的 82 实际上是 0082，0 是 0000，10 是 0010。两个字节序列的最右侧十六进制数字用于 128 位地址的最低有效两个字节。最后，两个连续冒号位于最不重要的十六进制数字和之前的十六进制数字之间，表示所有零。stanford.edu 的 128 位 IPv6 地址由 32 个半字节组成，因此表示如下：

|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 2 | 6 | 0 | 7 | f | 6 | d | 0 | 0 | 0 | 0 | 9 | 2 | 5 | a | 0 | 0 | 0 | 0 | 0 | 0 | a | a | 4 | 3 | d | 7 | c | 8 |

```
$ host 2607:f6d0:0:925a::ab43:d7c8

```

## 11.5.2.1 IPv4 地址的点分十进制表示法

尽管主机和路由器将 IPv4 地址作为 32 位二进制数处理，但它们对人来说很难记住。因此，IPv4 地址以 DDN 给出。在这种表示法中，IPv4 地址的全部四个字节以其十进制等价形式书写并用点分隔。因此，32 位 IP 地址

11000000 01100110 00001010 00010101

写成

192.102.10.21

图 11.5 所示的互联网通过四个路由器 R1–R4 连接四个网络。Net1 是 A 类网络，Net3 是 B 类网络，Net2 和 Net4 是 C 类网络。识别网络类别的方法是查看网络上主机 IP 地址中的最左侧十进制数字——在这种情况下，是路由器的 IP 地址。请注意，路由器分配的 IP 地址数量与它们连接的网络数量一样多。例如，路由器 R1 连接 Net1 和 Net2，具有 IP 地址 121.1.1.1 和 192.102.10.1。同样，R3 分配了三个 IP 地址，因为它互连了三个网络 Net1、Net3 和 Net4。

在特殊地址中，127.0.0.0（或 127.x.x.x，其中 x 可以是 0 到 255 之间的任意数字），也称为本地主机，由主机用于将数据包发送给自己。它也常用于在互联网上使用之前测试新应用程序。另一个特殊地址是主机 ID 字段全为 1 的地址，即定向广播地址。该地址用于将数据包发送给网络上的所有主机——即在主机使用该地址作为目的地址的本地网络上广播。
