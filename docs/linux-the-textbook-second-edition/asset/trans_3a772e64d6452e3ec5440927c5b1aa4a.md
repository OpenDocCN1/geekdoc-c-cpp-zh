

# 编辑文本文件

在诸如我们基础现代 Linux 系统上的图形用户界面环境中高效地编辑文本文件——但它们也具有改进且扩展的命令结构。

在本书撰写时，我们的基础 Linux 系统预装了以下文本编辑器：

- Debian 9.1: nano, vi
- Ubuntu 16.04: nano, vi
- Linux Mint 18.2: nano, vi
- CentOS 7.4: nano, vi, vim

如果您按照第 17 章开头所述进行了系统的基础安装，以上列表是正确的。gvim 和 Gnu emacs 未预装在我们任何基础 Linux 系统上。

在系统上安装这些编辑器的最简单和最佳方式是使用系统上可用的软件包管理系统。我们在第 17 章中展示了我们基础 Linux 系统软件包管理系统的基础知识。

我们还在附录 A 中展示了如何在我们基础 Linux 系统上安装 vi、vim 和 emacs。

如果这些编辑器尚未安装在您的 Linux 系统上，最快捷的安装方式是使用图形形式的软件包管理。这假设您使用桌面管理系统 GUI 与 Linux 系统交互，例如 Linux Mint 中的 Cinnamon。例如，当我们在 Linux Mint 系统上展示编辑器的安装时，我们在图形 Software Manager 中搜索了 vim、gvim 和 emacs，然后使用 Linux Mint Software Manager 的功能安装了以下软件包：

- 对于 vim：Vim Version 2:7.4.1689-3ubuntu1.2
- 对于 gvim：Vim-gtk 2:7.4.1689-3ubuntu1.2
- 对于 emacs：gnu emacs 24.3.1

此外，请注意，如果您通过终端窗口登录 Linux 系统，例如从 Windows 机器使用 PuTTY，则 Linux 文本编辑器的许多图形模式和使用技巧将无法使用。但这并不会阻止您使用我们为 nano 展示的传统输入命令和键盘编辑！

## 3.1.3 在 Linux 中处理文本和文件的其他方式

文本编辑器，如 nano、vi/vim/gvim 和 emacs，并不是将文本输入到文件中的唯一方式。如我们在后续章节所示，其他一些方法是通过在多个 Linux 命令中使用输出重定向，以及使用 sed 和 gawk 等传统文本处理实用程序进行“流编辑”。

输出重定向，使用 > 和 >> shell 命令运算符在多个命令中（而不是我们在第 2 章中展示的单个 Linux 命令结构）允许一种快速简便的方法将文本输入到文件中。结合我们在第 9 章中展示示例的 echo 和 cat 命令，输出（和输入）重定向是创建和修改文本文件中的文本的一种可行且高效的方式。

流编辑，简单来说，是使用代码操作来自输入流（如文件或标准输入）的文本，从而产生具有所需文本内容的输出流。它传统上并且最容易使用 sed（流编辑器）或 gawk 命令实现。这允许您将文本附加或修改到现有文件中，例如配置文件中，并例如使用基本或扩展正则表达式来构建输出流中的添加或修改。

有关 sed 的更完整文档，请参阅 Linux 系统上 sed 的 man 手册页。我们还在本书的 GitHub 站点上提供了 Web 参考，其中对 sed 进行了更完整的描述，并附有众多示例。gawk（Gnu 版 awk）是另一种流编辑方法，使用完整的复杂编程语言环境。gawk 允许您处理文本文件。有关 gawk 的更多信息，请参阅 Linux 系统上 gawk 的 man 手册页。

## 3.2 nano 编辑器的快速介绍

在本书中展示的所有 Linux 系统中最简单且最易获得的文本编辑器是 nano。对于许多用户来说，nano 将是部署文本编辑器时最有效和足够的编辑器。其他标准 Linux 编辑器中展示的许多任务都可以由 Linux 初学者使用 nano 快速轻松地完成。

要开始使用 nano，无论您只有 CUI 可用，还是通过某些桌面 GUI（如 Cinnamon 或 Gnome）与 Linux 交互，在终端窗口的 Linux 命令行中，输入以下内容：

```
```shell
$ nano
```
```

您立即能够在编辑器中输入文本，并使用物理或“虚拟”键盘（如在运行 Termius 终端应用程序的 iPad 上可用）的箭头键移动光标。nano 呈现的第一个屏幕显示如图 3.1 所示。您也可以使用 Delete 键删除当前行上的文本，删除光标在屏幕上显示文本中的当前位置之前的第一个字符。

如果您输入 **nano file2**，其中 file2 是已存在的文本文件的名称，该文本文件将在屏幕上显示，允许您对其进行更改或添加。

编辑器共有四个主要部分。顶行显示程序版本、正在编辑的当前文件名以及文件是否已被修改。接下来是显示正在编辑的文件的主编辑窗口。状态行是倒数第三行，显示重要消息。最后两行显示通过键盘“快捷方式”执行的常用命令。

### 3.2.1 简要 nano 教程

以下小节说明并解释了 nano 的一些基本操作以及一些功能。

### 3.2.1.1 创建和打开新文件

如果您想创建新文件并使用 nano 打开它，请使用以下命令：

```
$ nano
```

或

```
$ nano [filename]
```

第二个命令也用于打开现有文件，其中 filename 是现有文件的名称。如果您想打开不在当前目录中的文件，则必须使用该文件的绝对或相对路径。例如，/home/mint/filename。

图 3.2 显示了使用前面显示的第一个命令打开的文件。
在编辑器窗口底部，显示了键盘快捷键（它们不是 GUI 菜单选择！），可让您执行一些基本操作。例如，切割（和粘贴）文本，将缓冲区内容保存（写入）到文件，以及退出编辑器。

### 3.2.1.2 如何保存文件

要保存文件，请使用键盘快捷键 <Ctrl+O>。当您使用此键组合时，编辑器会提示您输入文件名（如果编辑器启动时已提供名称，则确认名称）。输入您的文件名并按 <Enter> 以该名称保存文件。

这在图 3.3 中有所说明。

### 3.2.1.3 如何剪切和粘贴文本

要剪切和粘贴已输入到缓冲区中的现有特定行文本，首先使用键盘上的箭头键将光标移动到该行上的任何字符。按 <Ctrl+K> 将整行从缓冲区中剪切出来，然后使用箭头键将光标定位到您想要将“剪切”行粘贴回缓冲区的位置。最后，使用 <Ctrl+U> 将剪切的行粘贴回去。

例如，在图 3.4 中，如果您想剪切第一行并将其多次粘贴到第一行下方两行。使用键盘上的箭头键转到第 1 行的开头，然后按 <Ctrl+K>。然后，光标在第一行下方并按 <Ctrl+U>。重复以多次执行此操作。

### 3.2.1.4 如何搜索和替换单词

此功能允许您在缓冲区中搜索特定单词，并将其替换为另一个单词。

要在 nano 中搜索单词，请按 <Ctrl+W>。然后，您将被要求输入要搜索的单词。输入单词后，按 <Enter>，工具将带您到匹配项（见图 3.5）。
