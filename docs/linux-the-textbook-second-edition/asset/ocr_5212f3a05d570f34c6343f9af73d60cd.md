The fork_exec_2.c program creates a child process that creates a directory, called dir1, in the current directory using the exec1() call. The parent process creates a file called foo in dir1, opens this file, writes the Hello, world! message into foo, resets the file pointer to the beginning of the file, reads back the Hello, world! message from foo, displays this message on standard output, removes foo from dir1, and removes the now empty dir1.
