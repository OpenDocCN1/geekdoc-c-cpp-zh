# TABLE 15.14

Linux System Calls Related to Directories

| System Call | Purpose |
|---|---|
| chdir() | Changes directory |
| mkdir() | Creates directory |
| rmdir() | Removes directory |
| remove() | Removes an empty directory; equivalent to rmdir() |
| rename() | Renames a directory |

```
struct linux_dirent64 {
    u64        d_ino;        /* "inode number" of entry */
    s64        d_off;        /* offset of disk directory entry */
    unsigned short d_reclen; /* length of this record */
    unsigned char  d_type;   /* file type, see below */
    char       d_name[0];    /* name of file */
};
```

The definition has five fields: the inode number for the file, offset of the disk directory entry, length of the directory entry, file type, and file name.

You can use several C library functions to manipulate directories, including opendir(), closedir(), readdir(), telldir(), seekdir(), and rewinddir().
