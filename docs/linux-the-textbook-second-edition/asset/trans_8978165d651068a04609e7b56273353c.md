

```bash
file_name: command not found
```

现在，考虑以下会话。请注意，**display_name** 文件中的两行 shell 脚本在我们刚刚在执行此脚本之前将 *name* 变量初始化为 John Doe 时显示为空字符串。原因是 *name* 变量在运行脚本之前未被导出，并且脚本中使用的 *name* 变量是脚本本地的。由于此本地变量 *name* 未初始化，echo 命令显示空字符串——每个未初始化变量的默认值。请注意，如果你的 *PATH* 变量包含当前目录，你可以在不使用 `./` 之前 **display_name** 的情况下运行脚本。

```bash
$ cat display_name
echo $name
exit 0
$ name="John Doe"
$ ./display_name

$
```

你可以使用 `exit` 命令将控制权转移到调用进程——前述会话中的当前 shell 进程。`exit` 命令的唯一参数是可选的整数，它作为终止进程的退出状态返回给调用进程。所有 Linux 命令在 *成功* 时返回零退出状态（即，如果它们成功执行其任务并正常终止），在 *失败* 时返回非零。命令的返回状态值存储在只读环境变量 `$?` 中，调用进程可以检查和/或显示它。在 shell 脚本中，命令的状态通常会被检查并据此采取后续行动。我们将在本章后面部分展示 `$?` 的使用。当 `exit` 命令不带参数执行时，Linux 内核为脚本设置返回状态值。

在以下会话中，*name* 变量在初始化后被导出，从而使其可用于 **display_name** 脚本。由于 *name* 变量在执行 **display_name** 脚本之前被导出，脚本显示 John Doe 而不是空字符串，这是之前会话中执行的结果。会话还显示 **display_name** 脚本的返回状态为 0。请注意，你可以在一个命令中同时初始化变量并导出它，如 `export name="John Doe"`。

```bash
$ declare -x name="John Doe"
$ ./display_name
John Doe
$ echo $?
0
$
```

我们现在展示导出的变量值副本会传递给任何后续命令。换句话说，命令只能访问导出的变量的值；它不能为该变量分配新值。考虑 **export_demo** 文件中的脚本。

```bash
$ cat export_demo
#!/bin/bash
declare -x name="John Doe"
display_change_name
display_name
exit 0
$ cat display_change_name
#!/bin/bash
echo $name
name="Plain Jane"
echo $name
exit 0
```

```bash
$ ./export_demo
John Doe
Plain Jane
John Doe
$
```

当调用 export_demo 脚本时，name 变量被设置为 John Doe 并被导出，因此它成为 export_demo 下执行的所有命令的环境的一部分。display_change_name 脚本中的第一个 echo 命令显示导出的变量（非本地）name 的值为 John Doe。然后它将本地变量 name 初始化为 Plain Jane。因此，第二个 echo 命令回显本地变量 name 的当前值并显示 Plain Jane。当 display_change_name 脚本完成执行后，display_name 脚本执行并显示导出的（非本地）name 的值，从而显示 John Doe。

```bash
$ ./export_demo
./export_demo: line 4: display_change_name: command not found
./export_demo: line 5: display_name: command not found
$
```

为避免此问题，将以下行放入你的 ~/.profile 文件中，注销后重新登录。你应该将当前目录作为 PATH 的最后一个组件，如以下会话所示，这样就不会不必要地在当前目录中搜索常用命令。

```bash
PATH=$PATH:.
```

在你的 ~/.profile 文件中包含上述行并运行 . ~/.profile 命令具有相同的效果。如果你只想在当前会话中将当前目录包含在搜索路径中，运行以下命令。

```bash
$ PATH=$PATH:.
$
```

## 12.3.6 重置变量

只要初始化它的脚本正在运行，变量就会保留其值。你可以通过显式将其初始化为空值或使用 unset 命令将变量的值重置为空（所有变量的默认初始值）。以下是此命令的简要说明：

```bash
Syntax:
unset [name-list]

Purpose: Reset or remove from the shell environment the variables or functions corresponding to the names in name-list, where name-list is a list of names separated by spaces
```

我们将在第 13 章讨论 Bash 中的函数，因此我们在此将 unset 命令的讨论限制为仅变量。以下会话显示了该命令的简单用法。变量 name 和 place 分别被设置为 John 和 Corvallis，echo 命令显示这些变量的值。unset 命令将 name 重置为空。因此，echo "$name" 命令显示空字符串（空行）。

```bash
$ declare name=John place=Corvallis
$ echo $name $place
John Corvallis
$ unset name
$ echo $name

$ echo $place
Corvallis
$
```

以下命令从 shell 环境中删除变量 *name* 和 *place*。

```bash
$ unset name place
$
```

重置变量的另一种方法是显式地为其分配空值，通过在 = 符号后不赋值并直接按 <Enter>，例如

```bash
$ country=
$ echo "$country"
$
```

## 12.3.7 创建只读定义变量

在编程时，你有时需要使用常量。你可以使用字面常量，但使用符号常量是良好的编程实践，主要是因为它使代码更易读。使用符号名称的另一个原因是代码中多处使用的常量可能需要更改。使用符号常量时，只需在一处更改，而字面常量必须在每次使用处都更改。Bash 中的符号常量可以通过初始化变量为所需值并使用 readonly、declare -r 或 typeset -r 命令使其只读来创建。此命令在 shell 脚本中很少使用，但我们为了完整覆盖 shell 变量而简要讨论它。以下是这些命令的简要说明：

```bash
Syntax:
  declare -r [name-list]
  typeset -r [name-list]
  readonly [name-list]
Purpose: Prevent assignment of new values to the variables in name-list
```

在以下会话中，*name* 和 *place* 变量在分别用 John 和 Ames 初始化后被设为只读。一旦它们变为只读，对任一变量的赋值都会失败。在以下会话的最后一条语句中，Bash 在发现 *name* 变量为只读时终止命令。因此，*place* 仍初始化为 Ames。

```bash
$ declare -r name=John place=Ames
$ echo "$name $place"
John Ames
$ declare name=Art place="Ann Arbor"
-bash: name: is read only
-bash: place: is read only
$ name=Art place="Ann Arbor"
-bash: name: readonly variable
$
```

当 readonly、declare -r 或 typeset -r 命令不带参数执行时，它会显示所有只读变量，如以下会话所示。BASHPID、BASH_VERSINFO、EUID、PPID、SHELLOPTS 和 UID 是环境变量。*name* 和 *place* 是在前一个会话中创建的用户定义只读变量。

```bash
$ declare -r
declare -r BASHOPTS="checkwinsize:cmdhist:complete_fullquote:expand_aliases:extglob:extquote:force_fignore:histappend:interactive_comments:login_shell:progcomp:promptvars:sourcepath"
declare -ir BASHPID
declare -r BASH_COMPLETION_COMPAT_DIR="/etc/bash_completion.d"
declare -ar BASH_VERSINFO=( [0]="4" [1]="3" [2]="42" [3]="1" [4]="release" [5]="x86_64-pc-linux-gnu")
declare -ir EUID="1004"
declare -ir PPID="3347"
declare -r SHELLOPTS="braceexpand:emacs:hashall:histexpand:history:interactive-comments:monitor"
declare -ir UID="1004"
declare -r name="Jim"
declare -r place="Ames"
$
```

在某些 Linux 系统上，readonly 命令的输出会显示只读变量列表以及这些变量的值。你无法重置只读变量的值。以下会话显示了一个示例：

```bash
$ unset name
-bash: unset: name: cannot unset: readonly variable
$
```

## 12.3.8 从标准输入读取

到目前为止，我们已经展示了如何在命令行级别或在程序中使用赋值语句静态地为 shell 变量赋值。如果你想编写一个交互式 shell 脚本提示用户输入键盘输入，你需要使用 read 命令将用户输入存储到 shell 变量中。此命令允许你从标准输入读取一行。以下是该命令的简要说明：

```bash
Syntax:
    read [options] [variable-list]
Purpose: Read one line from standard input and assign words in the line to variables in variable-list
Commonly used options/features:
    -a name    Read words into the "name" array
    -e         Read the whole line into the first variable; the rest of the variables are null
    -p prompt  Display "prompt" if reading from a terminal
```

一行以由空格分隔的词的形式读取（<Space> 或 <Tab> 字符，具体取决于 shell 环境变量 IFS 的值）。词按从左到右出现的顺序分配给变量。如果行中的词数多于 variable-list 中的变量数，最后一个变量会被分配多余的词。如果行中的词数少于变量数，剩余的变量会被重置为空。

我们通过以下 read_demo 文件中的脚本来说明 read 命令的语义。

```bash
$ cat read_demo
#!/bin/bash
echo -n "Enter input: "
read line
echo "You entered: $line"
echo -n "Enter another line: "
read word1 word2 word3
```
