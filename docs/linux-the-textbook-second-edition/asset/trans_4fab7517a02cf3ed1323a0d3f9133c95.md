### 4.1 引言

大多数计算机用户都使用其所用计算机系统的文件系统结构。在使用计算机系统时，用户经常执行与文件相关的操作：创建、读取、写入/修改或执行文件。因此，用户需要了解 Linux 中文件是什么、文件如何组织和管理、它们在操作系统内部如何表示，以及它们如何存储在磁盘上。由于本教科书的范围所限，本章对文件表示和存储的描述进行了简化。有关这些主题的更多细节，可参阅操作系统概念与原理方面的书籍以及 Linux 内部机制方面的书籍。

### 4.2 Linux 的文件概念

Linux 操作系统的众多显著特性之一就是其对文件的概念。这个概念简单而强大，并使得所有系统资源呈现统一的视图。在 Linux 中，文件是一个字节序列。因此，所有东西——包括网络接口卡、磁盘驱动器、通用串行总线（USB）闪存驱动器、键盘、打印机、简单/普通（文本、可执行文件等）文件或目录——都被视为文件。因此，在 Linux 中，所有输入和输出设备都被视为文件，如文件类型和文件系统结构中所述。

### 4.3 文件类型

Linux 支持七种类型的文件：

- 简单/普通文件
- 目录
- 符号（软）链接
- 字符特殊文件
- 块特殊文件
- 命名管道（也称为 FIFO）
- 套接字

你可以使用 `ls -l` 命令显示文件的类型，如表 4.1 所示。

### 4.3.1 简单/普通文件

简单/普通文件用于在辅助存储设备（通常是磁盘）上存储信息和数据。普通文件可以包含以下任何内容：

- 非结构化文本
- 用 C、C++、Java、Ruby、Python、LISP 和 Bash 等编程语言编写的源代码（或脚本）
- 通过编译（和链接）源程序创建的可执行程序
- 编译器、数据库工具、桌面出版工具和绘图软件等应用程序
- PostScript 代码
- 图片
- 视频
- 音频
- 图形
- 等等
