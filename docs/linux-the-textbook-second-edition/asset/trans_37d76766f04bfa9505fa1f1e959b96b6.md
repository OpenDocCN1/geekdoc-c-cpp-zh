

## 基本文件处理

文件的副本可以通过使用 cp 命令制作到另一个文件或目录中。 除了 > 运算符之外，cat 命令也可以用来制作文件副本，尽管使用 cp 和 cat > 命令复制文件之间存在差异（参见第 9 章）。 文件可以通过使用 mv 命令移动到另一个文件。 然而，这取决于源文件和目标文件是否在同一文件系统上，其使用可能导致或不导致文件数据从一个位置实际移动到另一个位置。 如果源文件和目标文件在同一文件系统上，则文件数据不会移动，源文件只是通过硬链接（参见第 8 章）链接到新位置（目标），并且原始/源链接被删除。 如果两个文件在不同的文件系统上，则会在新位置制作源文件的实际副本，并且源文件会从当前目录中删除（取消链接）。 文件可以通过使用 rm 命令从文件结构中删除。 该命令也可以递归地删除目录。

文件大小可以通过使用 ls -l 或 wc 命令确定； 两者都以字节为单位给出文件大小。 此外，wc 命令给出文件中的行数和单词数。 两者都可以使用 shell 元字符 *、?、[] 和 ^ 来显示多个文件的大小。

diff 命令可用于显示两个文件之间的差异。 该命令除了显示文件之间的差异外，还以可用于使两个文件相同的 ed 编辑器命令序列的形式显示有用的信息。 diff3 和 vimdiff 命令允许进行多重比较。 sdiff 命令允许并排比较两个文件并手动合并它们。 你可以使用 patch 命令代替 ed 命令来合并文件。 shasum 和 md5sum 命令允许你为文件创建称为消息摘要的唯一签名。 这些消息摘要用于识别相同的文件。 由于研究人员在 MD5 算法中发现了严重漏洞，我们不建议使用 md5sum 命令。

uniq 命令可用于删除除一个之外的所有连续重复行的出现。 使用 -d 选项，该命令可用于显示重复的行。 uniq 命令通常使用 Linux 管道和过滤器（例如 sort 和 grep 命令）一起使用，以执行更有趣的任务，如第 7 章所述。

lp（System V）或 lpr（BSD）命令都可用于在 Linux Mint 打印机上打印文件。 lpstat（System V）或 lpq（BSD）命令可用于检查打印机上所有打印作业（请求）的状态（等待、打印等）。 cancel（System V）或 lprrm（BSD）命令可用于从打印机队列中删除打印作业，以便请求的文档不会被打印。 所有这些打印命令都可在 Linux Mint 中使用。 此外，第 W26 章第 5 节详细介绍了 CUPS 打印。
