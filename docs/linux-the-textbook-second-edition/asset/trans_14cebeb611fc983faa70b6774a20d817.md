ip 命令通常位于 Linux Mint 上的 /bin 和/或 /sbin 目录中。如果收到 ip 未找到的错误消息，你应该将相关目录包含在搜索路径中并重新执行命令。你可以运行 `cat /etc/hosts` 命令来显示网络上主机的域名和 IP 地址。

## 11.5.5 请求评论

TCP/IP 标准由一系列文件描述，称为 *Requests for Comments*（RFCs）。RFC 最初作为 *Internet Drafts* 发布，并通过将其放置在已知的 RFC 仓库中，使其可供所有 Internet 用户审阅和反馈。评审过程完成后，草案可以成为标准。但并非所有 RFC 都是 *Internet Standards* 文档；有些仅供参考，其他则是实验性的。

RFC 引用格式如下：

```
```text
####   Title. Authors (up to three). Issue date. (Format: TXT=size-in-bytes,
PS=size-in-bytes, PDF=size-in-bytes) (Obsoletes xxx) (Obsoleted by RFC####)
(Updates RFC####) (Updated by RFC####) (Also FYI ####) (Status: sssss)
```
```

其中 ### 是四位十进制数字；Format 可以是 TXT（ASCII）、PS（PostScript）和 PDF（便携式文档格式）；Status 可以是 UNKNOWN、PROPOSED STANDARD、DRAFT STANDARD、STANDARD、INFORMATIONAL、EXPERIMENTAL 或 HISTORIC。以下是示例引用：

1180    TCP/IP Tutorial. T.J. Socolofsky,
       C.J. Kale. Jan-01–1991. (Format:

```
TXT=65494 bytes) (Status:
INFORMATIONAL)
```

你可以通过访问 ftp 或网站上维护的任何仓库来查看和下载 RFC。访问 RFC 最常见的方法是浏览位于 www.ietf.org/rfc.html 的网页。截至本章撰写时，该网页上维护的 RFC 索引中有 8,349 个 RFC 可用，最后一个于 2017 年 10 月提交为 Internet Standards Track 文档。如果你想收到新 RFC 公告的通知，可以订阅以下分发列表：http://mailman.rfc-editor.org/mailman/listinfo/rfc-dist。

要在浏览器中显示 RFC 的文本版本，将 www.ietf.org/rfc/rfcNNNN.txt 输入到浏览器的位置字段，其中 NNNN 是 RFC 编号。因此，要显示 RFC 2020 的文本版本，将 www.ietf.org/rfc/rfc2020.txt 输入到浏览器的位置字段。
