## 2.3.3 在Linux机器之间通过SSH客户端连接

这种方式允许一台Linux计算机上的用户通过SSH协议远程登录并注销另一台Linux计算机。正如第11章第8.5节中进一步详细说明的那样，SSH是客户端计算机与LAN或互联网上的服务器之间加密的通信通道。你用来登录另一台计算机的计算机称为SSH客户端。你想通过SSH登录的计算机称为服务器或主机系统。

在使用这种方式之前，客户端和服务器系统必须能够通过SSH通道相互通信。换句话说，服务器系统必须安装SSH服务器端软件包。这在大多数Linux系统上通常不是默认安装的，因此你必须按照针对你特定Linux发行版的安装说明进行操作。在我们的Debian家族的Linux Mint系统上，我们能够使用以下包管理命令安装服务器端软件：

```
$ sudo apt-get install openssh-server
```

客户端SSH软件在大多数Linux系统实现上默认安装，包括我们在本书中展示的所有代表性Linux系统。有关如何在我们任何代表性Linux系统上使用包管理系统的信息，请参阅附录A。
