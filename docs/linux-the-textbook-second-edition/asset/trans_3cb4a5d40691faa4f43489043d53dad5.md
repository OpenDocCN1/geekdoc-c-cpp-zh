## 9.1 引言

所有计算机软件（命令）执行以下一项或多项操作：输入、处理和输出；典型的命令执行全部三项。操作系统面临的问题是：shell 命令（内部或外部）从何处获取输入、将输出发送到何处，以及错误消息发送到何处？如果命令的输入不是命令代码的一部分（即代码中以常量和/或变量形式存在的数据），它必须来自外部源。此外部源通常是一个文件，尽管它也可能是键盘或网络接口卡等输入/输出（I/O）设备。命令输出和错误消息也可以发送到文件。为了使命令能够从文件读取或向文件写入，它必须先打开该文件。

存在命令读取输入并发送输出和错误消息的默认文件，称为标准输入、标准输出和标准错误。在 Linux 中，这些文件对于命令而言被称为标准文件。命令的输入、输出和错误可以通过 Linux 中的文件重定向功能重定向到其他文件。这使您可以将多个命令连接起来执行单个现有命令无法完成的复杂任务。本章我们讨论 Linux 中标准文件以及输入、输出和错误重定向的概念。

## 9.2 标准文件

在 Linux 中，内核为每个命令（或进程）自动打开三个文件以从中读取输入并向其发送输出和错误消息。这些文件被称为标准文件：标准输入（stdin）、标准输出（stdout）和标准错误（stderr）。默认情况下，这些文件与命令执行的终端相关联。更具体地说，键盘是标准输入，而显示屏（或您登录的控制台）是标准输出和标准错误。因此，每个命令默认从键盘获取输入并将输出和错误消息发送到

例如，命令 cat < tempfile 从 tempfile 读取输入（而不是键盘，因为 cat 的标准输入已连接到 tempfile）并将输出发送到显示屏。因此，tempfile 的内容有效地显示在监视器屏幕上。此命令与 cat tempfile 不同，在后者中 tempfile 作为命令行参数传递给 cat 命令；cat 的标准输入不会改变，仍然是命令运行的终端所连接的键盘。

类似地，在命令 grep "John" < Phones 中，grep 命令从当前目录中的 Phones 文件读取其输入，而不是从键盘读取。命令的输出和错误消息发送到显示屏。同样，此命令与 grep "John" Phones 不同，在后者中 Phones 文件作为参数传递给 grep；grep 的标准输入不会改变，仍然是命令执行的终端所连接的键盘。然而，从用户角度来看，grep 命令在两种情况下的净效果是相同的。类似地，在大多数情况下使用 < 是不需要的，因为命令无论如何都会从文件中读取。

cat 和 grep 命令如果未从命令行传递文件参数，则从标准输入获取输入。tr 命令仅从标准输入获取输入并将输出发送到标准输出。命令不使用文件作为命令行参数工作。因此，输入重定向通常与 tr 命令一起使用，如 tr -s ' ' < Bigfile。当此命令执行时，它会用单个空格替换 Bigfile 中的多个空格。

## 9.4 输出重定向

输出重定向是通过使用大于号（>）实现的。以下语法用于将显示屏从命令的标准输出分离并将其连接到 output-file。因此，如果 command 将其输出/发送到标准输出，输出将进入 output-file，而不是命令运行的终端所连接的监视器屏幕。错误消息仍发送到显示屏，如前所述。命令语法的语义如图所示 9.3。

```
Syntax:
command > output-file
Purpose: Send output of command to the file output-file instead of to the monitor screen
```

考虑 cat > newfile 命令。回想一下，cat 命令将输出发送到标准输出，默认情况下为显示屏。此命令语法将显示屏从 cat 命令的标准输出分离并将其连接到 newfile。cat 的标准输入仍连接到键盘。当此命令执行时，它会创建一个名为 newfile 的文件，其内容是您在键盘上输入的内容，直到您在新行的第一列按下 <Ctrl-D>。如果 newfile 已存在，默认情况下会被覆盖。

类似地，命令 grep "John" Phones > Phone_John 将其输出（Phones 文件中包含单词“John”的行）发送到名为 Phone_John 的文件，而不是在监视器屏幕上显示。命令的输入来自 Phones 文件。当 grep 在 Phones 中遇到文件结束字符时，命令终止。

在网络环境中，可以使用以下命令对您当前登录的计算机（客户端计算机）上驻留的文件 datafile 进行排序，排序在名为 server 的计算机上进行。命令的输出——即排序后的数据——发送到客户端计算机的显示屏。图 9.4 说明了此命令的语义。

```
$ ssh server sort < datafile
$
```

此命令是说明如何在网络环境中利用多台计算机并发执行各种任务的良好示例。如果您的计算机（称为客户端）有一个要排序的大文件 datafile，并且您不希望在网络上的各种计算机上制作该文件的多个副本以防止不一致，此命令非常有用。此命令允许您执行该任务。此类命令在服务器具有您被允许使用但不允许在自己的机器上复制的专用 Linux 工具时也很有用。我们将在第 11 章讨论与网络相关的 Linux 命令和实用程序。我们使用此示例来说明 Linux I/O 重定向功能的强大功能，而不是偏离网络环境计算的主题。

以下会话显示了本地（客户端）机器上的 Students 文件的内容以及在 sarwar 登录下在远程（服务器）机器 198.102.10.20 上执行的 sort 命令的输出。由于 sarwar 的登录受密码保护，系统在远程计算机上运行 sort 命令并在本地计算机上显示其输出之前提示他输入密码。请注意，我们显示了虚构的 ssh 服务器的 Internet 协议（IP）地址，但会话是在真实的远程机器上执行的。
