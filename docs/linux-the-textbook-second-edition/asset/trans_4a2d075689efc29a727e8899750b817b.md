主要升级程序最好在你想要进行升级时咨询在线文档。

### 17.8.1 应用级进程/线程资源管理

监控系统资源（例如进程 CPU 使用率和系统内存）以了解系统在其设计用例下的性能表现的基本原因，是为了让你能够观察、评估，然后在应用级别控制程序如何有效地使用系统资源的主要组件。

例如，如果某个特定标准应用程序（例如从在线仓库安装的 Web 服务器）或甚至用户编写程序的进程消耗了太多 CPU 或内存资源，根据你的系统设计用途确定的标准，你可以降低该任务的操作以更好地为用户群服务。另一方面，如果由于某种原因，这些相同的进程资源不足或饥饿，你也可以提高该任务的操作。在某些情况下，服务不足可能是由硬件故障或非法入侵引起的，但我们本节不涵盖这些情况。

关键是在现代 Linux 系统上以当代方式观察和评估系统资源的使用，然后根据这些观察和评估采取一些行动。这些行动当然由你根据系统的用例战略性地设计和实施的管理计划来指导。

评估进程活动的一种方法，例如通过 CPU 调度进程和进程组，是检查 proc 文件系统。我们在第 10 章第 8 节展示了 proc 的基础知识。
