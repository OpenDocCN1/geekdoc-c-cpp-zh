

## 入门 Bash 编程

涉及 `-a` 和 `-o`（逻辑 AND 和逻辑 OR）运算符的长表达式可能会变得令人困惑。您可以使用运算符 `&&`（用于逻辑 AND）和 `||`（用于逻辑 OR）以更简洁、更易读的方式编写此类表达式。`-a`、`-o`、`&&` 和 `||` 运算符也在表 12.5 和 12.6 中进行了讨论。`if_demo1` 文件中的表达式可以写成如下形式。

```
$ cat if_demo1
#!/bin/bash
if [[ "$#" -eq 1 ]] && [[ -f "$1" ]]
    then
    ...
fi
...
$
```

表达式 “A && B” 在 A 和 B 都为真时返回真。此外，在评估此表达式时，仅当 A 成功（即返回真）时才评估 B。表达式 “A || B” 在 A 或 B、或两者都为真时返回真。在这种情况下，仅当 A 失败（即返回假）时才评估 B。我们在之前的脚本中讨论了这些运算符用于表达式求值的几个示例。在下面的会话中，我们展示了这些运算符用于命令执行的几个示例。如预期，对于 `&&` 运算符，如果运算符左侧为假，则不会执行 echo 命令。同样如预期，对于 `||` 运算符，如果运算符左侧为真，则不会执行 echo 命令。

```
$ true && echo "Hello, world!"
Hello, world!
$ false && echo "Hello, world!"
$ false || echo "Hello, world!"
Hello, world!
$ true || echo "Hello, world!"
$
```

如表 12.6 所示，运算符 `&`、`|` 和 `^` 分别是按位 AND、OR 和异或 XOR。当对两个位执行按位 AND 时，结果位只有在两个位都为 1 时才为 1；否则为 0。两个位的按位 OR 只有在两个位都为 0 时结果才为 0；否则为 1。最后，两个位的 XOR 只有当其中一个位为 1 而另一个为 0 时结果才为 1；否则为 0。

脚本编写中的一个重要做法是正确缩进其中的命令/语句。程序的适当缩进增强了其可读性，使其更易于理解和维护。然而，空白既不影响程序的语法正确性，也不影响其执行时的效率。请注意我们在示例脚本中使用的缩进样式，并在编写自己的脚本时遵循它。

我们现在讨论 `if` 语句的第二个版本，该版本也允许双向分支。以下是该语句的简要描述：

```
Syntax:
    if expression
        then
            then-commands
        else
            else-commands
    fi
Purpose: To implement two-way branching
```

如果 expression 为真，则执行 then-commands 中的命令；否则，执行 else-commands 中的命令，然后执行 `fi` 之后的命令。该语句的语义如图 12.2 所示。

接下来，我们使用 `if-then-else-fi` 语句重写 `if_demo1` 程序，并使用 test 命令的替代语法。 resulting 脚本在 `if_demo2` 文件中，如以下会话所示。请注意，该程序看起来更简洁、更易读。

```
$ cat if_demo2
#!/bin/bash
if [[ $# -eq 1 ]] && [[ -f "$1" ]]
then
    filename=$1
    set -- `ls -l $filename`
    perms="$1"
    size="$5"
    set `ls -i $filename`
    inode="$1"
    echo "File Name:          $filename"
    echo "Inode Number:       $inode"
    echo "Permissions:        $perms"
    echo "Size (bytes):       $size"
    exit 0
else
    echo "$0:        Specify exactly one command line argument "
    echo "           must be an ordinary file."
    exit 1
fi
exit 0
$
```

最后，我们讨论 `if` 语句的第三个版本，该版本用于实现多路分支。以下是该语句的简要描述：

```
Syntax:
    if expression1
        then
            then-commands
    elif expression2
        elif1-commands
    elif expression3
        elif2-commands
    else
        else-commands
    fi

Purpose: To implement multiway branching
```

如果 **expression1** 为真，则执行 **then-commands** 中的命令。如果 **expression1** 为假，则评估 **expression2**，如果它为真，则执行 **elif1-commands** 中的命令。如果 **expression2** 也为假，则评估 **expression3**。如果 **expression3** 为真，则执行 **elif2-commands** 中的命令。如果 **expression3** 也为假，则执行 **else-commands** 中的命令。任何命令列表的执行后都会执行 **fi** 之后的命令。您可以在 **if** 语句中使用任意数量的 **elifs** 来实现多路分支。该语句的语义如图 12.3 所示。

我们修改 **if_demo** 文件中的脚本，以便如果命令行参数是目录，程序会显示目录中文件和子目录的数量，不包括隐藏文件。此外，程序在处理之前确保命令行参数是当前目录中存在的现有文件或目录。除了使用两个 `if` 语句外，我们在实现中还使用了 `if-then-elif-else-fi` 语句。 resulting 脚本在 `if_demo3` 文件中，如以下会话所示。请注意 `if` 语句条件中逻辑否定运算符（`!`）的使用。该运算符也可以用于按位否定，如表 12.5 和 12.6 中所述。

```
$ cat if_demo3
#!/bin/bash
if [[ ! $# -eq 1 ]]
    then
        echo "Usage: $0 file"
        exit 1
elif [ -d "$1" ]
    then
        nfiles=`ls "$1" | wc -w`
        echo "The number of files in the $1 directory is $nfiles"
        exit 0
else
    ls "$1" 2> /dev/null | grep "$1" 2> /dev/null 1>&2
    if [ $? -ne 0 ]
        then
            echo "$1: not found"
            exit 1
    fi
    if [ -f "$1" ]
    then
        filename=$1
        set -- `ls -l $filename`
        perms="$1"
        size="$5"
        set `ls -i $filename`
        inode="$1"
        echo "File Name: $filename"
        echo "Inode Number: $inode"
        echo "Permissions: $perms"
        echo "Size (bytes): $size"
        exit 0
    else
        echo "$0: argument must be an ordinary file or directory"
        exit 1
    fi
fi
$
```

```
$ ./if_demo3 lab2
lab2: not found

$ ./if_demo3 lab1 lab2
Usage: if_demo3 file

$ ./if_demo3 ~
The number of files in the /home/sarwar directory is 14

$ ./if_demo3 set_demo
File Name: set_demo
Inode Number: 16517945
Permissions: -rwxr-xr-x
Size (bytes): 245

$ ./if_demo3 /bin/ls
File Name: /bin/ls
Inode Number: 10485856
Permissions: -rwxr-xr-x
Size (bytes): 126584
```

如果参数是目录，则目录中文件和子目录的数量，不包括隐藏文件，被保存到 `nfiles` 变量中。命令 `ls "$1" 2> /dev/null | grep "$1" 2> /dev/null 1>&2` 用于检查作为命令行参数传递的文件是否存在。标准错误被重定向到 `/dev/null`（Linux 黑洞），标准输出通过使用 `1>&2` 重定向到标准错误。因此，该命令不会产生任何输出或错误消息；其唯一目的是在 `$?` 中设置命令的返回状态值。如果命令行参数存在，ls 命令成功且 `$?` 包含 0；否则，它包含非零值。如果命令行参数是文件，则显示所需的文件相关数据。请注意为设置 `nfiles` 变量的值而使用命令替换和管道。
