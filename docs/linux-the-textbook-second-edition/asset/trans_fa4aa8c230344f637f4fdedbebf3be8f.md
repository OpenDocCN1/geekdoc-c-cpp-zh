### 1.1 引言

如今有许多操作系统可供使用，有些通用性足够高，可以运行在任何类型的计算机上（从手持设备、物联网 IoT 设备到基于云的仓库规模服务器集群），有些则专门设计用于在特定类型的计算机系统上运行，包括用于控制机器人等机械设备运动的实时嵌入式计算机系统、IPads 和大量手机型号。本章中，我们描述操作系统的目的和不同类别的操作系统。在描述不同类型的操作系统以及 Linux 在此分类中的位置之前，我们呈现了当代计算机系统的分层图并讨论了操作系统的基本目的。然后我们描述不同类型的操作系统以及用于对其进行分类的参数。最后，我们确定 Linux 所属的类别并简要讨论 Linux 家族的不同成员。

使用 Linux 的人包括应用程序开发人员、系统分析师、程序员、管理员、业务经理、学者，以及只是想阅读电子邮件的人。从 20 世纪 90 年代初作为业余爱好项目开始，它与互联网的发展一起爆炸式发展，通过庞大的开发者社区，然后完全被用于商业用途。在今天完全开发和成熟的版本中，Linux 具有复杂但易于学习的基础功能，并且可扩展且易于根据用户的计算风格进行定制。理解其持久性和异质吸引力的关键之一是研究其演变的历史。

应用程序软件——电子表格、文字处理器、Web 浏览器、电子邮件软件和其他程序。程序员使用语言库、系统调用和程序生成工具（例如文本编辑器、编译器和版本控制系统）来开发软件。如果一次只允许一个用户使用计算机系统，包括单用户桌面系统、笔记本电脑、平板电脑和手机，则公平性显然不是问题。然而，如果允许多个用户使用计算机系统，则公平性和安全性是操作系统设计人员需要解决的两个主要问题。

硬件资源包括键盘、触控板、显示屏（也可能是触摸屏）、主内存（通常称为随机存取存储器或 RAM）、磁盘驱动器、网络接口卡和中央处理器 CPU。软件资源包括文字处理器、电子表格、游戏、绘图工具、图片和视频处理工具以及互联网相关工具等应用程序，如 Web 浏览器。这些应用程序位于图表的最上层，形成应用程序用户界面 AUI。AUI 通过语言库和系统调用接口粘合到操作系统内核。系统调用接口包含一组函数，可供应用程序和库例程使用，以执行内核代码以获取特定服务，例如读取文件。语言库和系统调用接口通常统称为应用程序编程接口 API。内核是操作系统的核心，在这里处理 CPU 调度、内存管理、磁盘调度和进程间通信 IPC 等问题。图中各层以扩展形式显示为 Linux 操作系统，如图 1.2 所示，并简要描述。

有两种方法可以看待操作系统：自上而下和自下而上。在自下而上的视图中，操作系统可以被视为一种软件系统，以高效、公平、有序和安全的方式分配和释放系统资源（硬件和软件）。例如，操作系统决定在程序被加载和执行之前分配多少 RAM 空间给程序。操作系统确保一次只有一个文件打印到特定打印机上，防止磁盘上的现有文件被另一个文件意外覆盖，并进一步保证，当交给 CPU 处理的程序执行完成后，程序会释放 CPU，以便其他程序可以执行。因此，在自下而上的视图中，操作系统是一个资源管理器。
