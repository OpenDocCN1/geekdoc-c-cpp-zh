### 13.5 中断（信号）处理

我们在第 10 章讨论了信号的基本概念，在那里我们将信号定义为可以发送给进程的软件中断。我们还指出，收到信号的进程可以采取三种可能的行动之一：

+   1. 采取 Linux 内核定义的默认行动
+   2. 忽略信号
+   3. 采取程序员定义的行动

在 Linux 中，可以向正在运行的程序发送多种类型的信号。其中一些信号可以通过键盘等硬件设备发送，但所有信号都可以通过 `kill` 命令发送，如第 10 章所述。最常见的导致硬件中断（和信号）的事件是在你按下 `<Ctrl+C>` 时产生的，称为键盘中断。该事件的默认内核定义行动是终止前台进程。其他导致进程接收信号的事件包括子进程终止、进程访问不在其地址空间内的主内存位置，以及由不带任何信号编号执行 `kill` 命令引起的软件终止信号。进程的地址空间是进程合法拥有并允许访问的主内存区域。表 13.1 列出了一些重要信号、它们的编号及其用途。信号编号或相应的符号名称可用于通过 `kill` 命令生成相应的信号。

Bash 的中断处理特性允许你编写程序，这些程序可以忽略信号、采取 Linux 内核为这些信号定义的行动，或者在特定类型的信号发送给它们时执行一组特定的命令。这个特性比

**表 13.1**

*一些重要的信号、它们的编号及用途*

| 信号名称 | 信号编号 | 用途 |
|---|---:|---|
| SIGHUP（挂断） | 1 | 当运行进程的用户注销时通知进程，进程终止 |
| SIGINT（键盘中断） | 2 | 当用户按下 `<Ctrl+C>` 时通知进程，进程终止 |
| SIGQUIT（退出信号） | 3 | 当用户按下 `<Ctrl+\>` 或 `<Ctrl+\>` 时通知进程，进程终止 |
| SIGKILL（确定终止） | 9 | 当用户使用 `kill -9` 命令向其发送该信号时终止进程 |
| SIGSEGV（段错误） | 11 | 当进程试图访问不属于它的内存空间时，因内存错误终止进程 |
| SIGTERM（软件终止） | 15 | 当 `kill` 命令不带任何信号编号使用时终止进程 |
| SIGTSTP（挂起/停止信号） | 18 | 挂起进程；通常是 `<Ctrl+Z>` |
| SIGCHLD（子进程结束执行） | 20 | 通知进程其某个子进程已终止 |

C shell，它只允许程序忽略键盘中断（`<Ctrl+C>`）强大得多。`trap` 命令可用于拦截信号。以下是该命令的简要说明：

**语法：**

```bash
trap ['command-list'] [signal-list]
```

**用途：** 拦截 **signal-list** 中指定的信号，并采取内核定义的默认行动、忽略信号或执行 **command-list** 中的命令；注意，**command-list** 两边的引号是必需的。

当你在脚本中使用不带任何参数的 `trap` 命令（即没有 **command-list** 和 **signal-list**）时，脚本在接收到信号时会采取默认行动。因此，使用不带任何参数的 `trap` 命令是多余的。当 `trap` 命令在单引号中没有带任何命令时，脚本会忽略 **signal-list** 中的信号。当同时指定 **command-list** 和 **signal-list** 时，脚本收到 **signal-list** 中指定的信号时，会执行 **command-list** 中的命令。

接下来，我们增强第 12 章中 **while_demo** 文件中的脚本，使你无法用 `<Ctrl+C>`（信号编号 2）、不带任何参数的 `kill` 命令（信号编号 15）或 `kill -1` 命令（生成 SIGHUP 信号）终止该程序的执行。增强版本在 **trap_demo** 文件中，如下面的会话所示。注意 `trap` 命令用于忽略信号 1、2、3、15 和 18。示例运行说明了这一点。

```bash
$ cat trap_demo
#!/bin/bash

# Intercept signals 1, 2, 3, 15, and 18 and ignore them
trap '' 1 2 3 15 18

# Set the secret code
secretcode=agent007

# Get user input
echo "Guess the code!"
echo -e "Enter your guess: \c"
read yourguess

# As long as the user input is the secret code (agent007 in this case),
# loop here: display a message and take user input again. When the user
# input matches the secret code, terminate the loop and execute the
# echo command that follows.
while [ "$secretcode" != "$yourguess" ]
do
    echo "Good guess but wrong. Try again!"
    echo -e "Enter your guess: \c"
    read yourguess
done
echo "Wow! You are a genius!"
exit 0
$ ./trap_demo
Guess the code!
Enter your guess: codecracker
Good guess but wrong. Try again!
Enter your guess: <Ctrl+C>
Good guess but wrong. Try again!
Enter your guess: agent007
Wow! You are a genius!
$
```

要终止忽略终端中断的程序，你必须使用 `kill` 命令。你可以通过按下 `<Ctrl+Z>` 挂起进程，使用 `ps` 命令获取进程的 PID，然后用 `kill` 命令终止它。或者，你可以从另一个终端登录，并按照前一句所述使用 `ps` 和 `kill` 命令。

你可以修改 **trap_demo** 文件中的脚本，使其忽略信号 1、2、3、15 和 18，清除显示屏幕并关闭回显。当回显关闭后，你从键盘输入的任何内容都不会被显示。接下来，它提示你输入口令并保存。然后再次提示你输入相同的口令，以确保你记住所输入的口令。为此，它给你两次机会。如果你两次没有输入相同的口令，它会提醒你的短期记忆不好并退出。如果你输入了相同的口令，它会清除显示屏幕并提示你再次猜口令。如果你没有输入原始口令，显示屏幕会被清除并提示你再次猜。程序在你输入原始口令之前不会终止。当你输入原始口令时，屏幕被清除，消息显示在屏幕左上角，回显被打开。因为终端中断被忽略，你无法通过按下 `<Ctrl+C>` 终止程序。`stty -echo` 命令关闭回显。因此，当你输入原始口令（或任何猜测）时，屏幕上不会显示。`stty echo` 打开回显。`clear` 命令清除显示屏幕并将光标定位在左上角。生成的脚本在 **canleave** 文件中，如下面的会话所示。

```bash
$ cat canleave
#!/bin/bash
# File Name:     ~/linux2e/chapter13/bash/canleave
# Author:        Syed Mansoor Sarwar
# Written:       August 18, 2004
# Modified:      May 8, 2004; Jul 29, 2014; July 9, 2017
# Purpose:       To allow a user to leave his/her terminal for a short
#                duration of time by locking the terminal after taking a code
#                from the user. Terminal is unlocked only when the user
#                re-enters the same code. Ignores command line arguments.
# Brief Description:
#       Clear screen and turn off echo (i.e., do not display what the user
#       types at the keyboard). Take user code, save it, and ask the user
#       to re-enter his/her code just to make sure that the user remembers
#       the code that he/she has entered. It is done twice. If the user does
#       not enter the same code, the program terminates after displaying a
#       message for the user. The user is prompted to enter the original
#       code. If the user enters the wrong code, the program keeps on
#       prompting the user until he/she enters the original code. The
#       keyboard is then unlocked, echo is turned on, and program exits.

# Ignore signals 1, 2, 3, 15, and 18
trap '' 1 2 3 15 18

# Clear the screen, locate the cursor at the top-left corner,
# and turn off echo
clear
stty -echo

# Set the secret code
echo -n "Enter your code word: "
read secretcode
echo " "

# To make sure that the user remembers the code word,
# ask the user to enter the secret code again.
echo -n "Enter your code word again: "
read same
if [ $secretcode != $same ]
then
        clear
        echo "Wrong code. Try again."
fi
```
