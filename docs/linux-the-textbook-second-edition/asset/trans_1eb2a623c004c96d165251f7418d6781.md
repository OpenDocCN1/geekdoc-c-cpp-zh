+   - **-P page-list**    打印 **page-list** 中指定的页面
+   - **-d ptr**    将打印请求发送到 **ptr** 打印机
+   - **-m**    打印完成后发送电子邮件
+   - **-n N**    打印 **file-list** 中的文件 N 份；默认是一份
+   - **-t title**    在横幅页上打印 **title**
+   - **-w**    打印完成后向用户终端写入信息

以下会话展示了如何使用 lp 命令以及不带选项的使用方法。第一个命令将示例文件打印到默认打印机。系统管理员为系统上的用户设置默认打印机。第一个打印请求的作业 ID 为 cpr-981，这告诉你打印机名称为 cpr。第二个命令使用 -d 选项指定示例文件应打印到 spr 打印机。第三个命令用于在 qpr 打印机上打印示例文件和 phones 文件各三份。

```
% lp sample
request id is cpr-981 (1 file(s))
% lp -d spr sample
request id is spr-983 (1 file(s))
% lp -d qpr -n 3 sample phones
request id is qpr-984 (2 file(s))
%
```

如前所述，lp 命令的 BSD 对应命令是 lpr 命令。下面是对该命令的简要描述。

## 语法：

```
lpr [options] file-list
```

用途：提交打印 file-list 中文件的请求

## 常用选项/功能：

+   - **-# N**    打印 file-list 中的文件 N 份；默认是一份
+   - **-P ptr**    将打印请求发送到 ptr 打印机
+   - **-T title**    在横幅页上打印 title
+   - **-m**    打印完成后发送电子邮件
+   - **-p**    使用 pr 命令格式化输出

以下会话展示了 BSD 变体的命令，这些命令执行与 lp 命令相同的打印任务。因此，第一个 lpr 命令发送打印示例文件到默认打印机的打印请求。第二个命令发送打印示例文件到 spr 打印机的请求。第三个命令在 qpr 打印机上打印示例文件和 phones 文件各三份。

```
% lpr sample
% lpr -P spr sample
% lpr -P qpr -# 3 sample
%
```

你可以使用以下命令打印示例文件，并在 pr 命令产生的每一页上打印页眉信息。垂直条 (|) 称为管道符号，我们将在第 9 章详细介绍。

```
% pr sample | lpr
%
```

你也可以使用 lpr -p sample 命令执行相同的任务。你可以使用以下命令打印带有行号和每页 pr 页眉的示例文件。你也可以使用 nl sample | lpr -p 命令执行相同的任务。

```
$ nl sample | pr | lpr
$
```

你可以通过指定适当的标志使 lpr 命令打印非标准文本文件，例如 TEX 文件。例如，你可以使用 -t 选项打印 troff 文件，使用 -n 选项打印 nroff 文件。

### 6.8.3 查找你的打印请求状态

lpstat 命令可用于显示打印机上打印作业的状态。下面是对 lpstat 命令的简要描述。

语法：
  lpstat [options]
用途：显示打印机上打印作业的状态
常用选项/功能：
  -d          显示使用 lp 命令发送到默认打印机的打印作业状态
  -o job-id-list  显示 job-id-list 中的打印作业状态；用空格分隔作业 ID，多个作业时将请求用双引号括起来
  -p printer-list 显示 printer-list 中指定的打印机上的打印作业状态
  -u user-list    显示 user-list 中用户的打印作业状态

不带任何选项时，lpstat 命令会显示你所有正在打印或等待在默认打印机打印队列中的打印作业状态。以下会话中的命令展示了该命令的一些典型用法。lpstat -p 命令显示网络上所有打印机的状态。lpstat -p qpr 显示 qpr 打印机上的打印作业状态。lpstat -u sarwar 显示用户 sarwar 的所有打印作业。命令的输出显示 sarwar 提交了三个打印作业：两个到 qpr（作业 ID 为 qpr-3998 和 qpr-3999）和一个到 tpr（作业 ID 为 tpr-203）。最后，lpstat -a 命令显示所有处于活动状态并接受打印作业的打印机。

```
$ lpstat -p
printer cpr is idle. enabled since Tue Sep 2 10:43:48 GMT 2014. available. printer mpr faulted. enabled since Mon Sep 1 10:48:29 GMT 2014. available. printer qpr now printing qpr-53. enabled since Mon Sep 1 10:48:29 GMT 2014. available. printer spr is idle. enabled since Mon Sep 1 10:48:29 GMT 2003. available.
$ lpstat -p qpr
printer qpr now printing qpr-53. enabled since Mon Sep 1 10:48:29 GMT 2014. available.
$ lpstat -u sarwar
qpr-3998 sarwar    93874 Sep  2    22:05 on qpr
qpr-3999 sarwar    93874 Sep  2    22:05
tpr-203 sarwar 93874 Sep  2    22:05 on tpr
$ lpstat -a
cpr accepting requests since Tue Sep 2 10:43:48 GMT 2014
spr accepting requests since Mon Sep 1 10:48:29 GMT 2014
$
```

下面是对 **lpstat** 命令的 BSD 对应命令 **lpq** 命令的简要描述。

**语法：**

    lpq [options]

**用途：** 显示打印机上打印作业的状态

**常用选项/功能：**

| Option | Description |
|---|---|
| `-P printer-list` | 显示 **printer-list** 中指定的打印机上的打印作业状态 |
| `-l` | 以长格式显示使用 **lpr** 命令发送到默认打印机的打印作业状态 |

### 6.8.4 取消你的打印作业

如果你意识到你提交了错误的文件进行打印，你将希望取消你的打印请求。执行此任务的命令是 **cancel**。下面是对该命令的简要描述。

**语法：**

    cancel [options] [printer]

**用途：** 取消通过 **lp** 命令发送的打印请求——即，将这些作业从打印队列中取出

**常用选项/功能：**

| Option | Description |
|---|---|
| `-jobid-list` | 取消 **jobid-list** 中指定的打印作业 |
| `-ulogin` | 取消用户 **login** 发出的所有打印请求 |

以下命令展示了如何取消打印作业。你可以使用 **lpstat** 或 **lpq** 命令显示打印机上的作业 ID，如第 6.8.3 节所示。第一个命令取消打印作业 mpr-3991。第二个命令取消用户 **sarwar** 在所有打印机上的所有打印请求。你只能取消自己的打印作业。因此，最后一个命令只有在由 **sarwar** 或超级用户运行才有效。

```
```text
$ cancel mpr-3991
request "mpr-3991" canceled
$ cancel -u sarwar mpr
request "mpr-3992" canceled
request "mpr-3995" canceled
$
```
```

cancel 命令的 BSD 对应命令是 lprm。下面是对该命令的简要描述。

**语法：**

`lprm [options] [jobID-list] [user(s)]`

**用途：** 取消使用 lpr 命令发出的打印请求——即，从打印队列中移除这些作业；`jobID-list` 中的 jobIDs 取自 `lpq` 命令的输出。

**常用选项/功能**

- `-` — 移除 **user** 拥有的所有打印作业
- `-P ptr` — 指定 **ptr** 打印机的打印队列

以下 lprm 命令执行与上一会话中描述的 cancel 命令相同的任务。

```
```text
$ lprm -Pmp 3991
mpr-3996 dequeued
$ lprm -Pmp sarwar
mpr-3997 dequeued
mpr-3998 dequeued
$
```
```

# 总结

基本文件操作包括显示文件全部或部分内容、重命名文件、将文件移动到另一个文件、删除文件、确定文件大小、比较文件、合并文件并将它们存储到另一个文件、追加新内容（可以来自另一个磁盘文件、键盘或命令的输出）在文件末尾，以及打印文件。Linux 提供了可用于执行这些操作的多个命令。

cat 和 more 命令可用于在显示屏上显示文件的所有内容。> 符号可用于将这些命令的输出发送到其他文件，>> 运算符可用于在文件末尾追加新内容。cat 命令以连续文本发送文件内容，而 more 命令则以分页形式发送。此外，more 命令具有多个有用的功能，例如显示包含特定字符串的页面。less 命令支持比 more 命令更多的功能，包括 vi 风格的前向和后向搜索。

head 和 tail 命令可用于显示文件的初始或末尾部分（head 或 tail）。这些有用的命令通常用于在不使用 file 命令（参见第 4 章）的情况下了解文件包含的数据类型。此外，file 命令无法解析所有文件的内容。
