# 17.4.3 向系统添加新硬盘

下面的示例演示如何向系统添加新硬盘并对其进行分区。我们选择使用基于 GUI 的 Gparted 分区编辑器，主要是因为它的易用性好，并且可以快速安装到 Linux Mint 上。

我们选择这个分区编辑器，而不是使用 gdisk 工具或传统的 fdisk 命令，因为它有 GUI 前端且易于使用。这种 GUI 技术不仅能让您了解磁盘的逻辑设备名，还能让您对新添加的磁盘进行分区，并同时向其中添加文件系统。

# 示例 17.5 添加新磁盘并使用 Gparted 进行“切片”或分区

- 1. 如果您的系统上尚未安装 Gparted 分区编辑器软件，请先安装它。使用基于 GUI 的软件管理器是最高效的方法。我们在附录 A 的 17.4.3 节中给出了如何使用高级打包工具（APT）或 Yellowdog Updater Modified（YUM）包管理系统从命令行安装 Gparted 的说明。此外，如果您使用 GUI 桌面管理系统，在 Linux 桌面上放置该软件的图标会很方便。
- 2. 关闭系统，正确地将新磁盘连接到系统。然后重新启动系统。
- 3. 以图形方式或从命令行启动 Gparted 分区编辑器。
- 4. Gparted 屏幕出现，如图 17.3 所示。
- 5. 系统上当前连接的磁盘显示在右上角的菜单栏中。请记下当前磁盘的所有完整路径。例如，引导盘或根磁盘可能被指定为 /dev/sda，如图 17.3 所示。
- 6. 当 Gparted 屏幕重新出现时，单击 Gparted 屏幕右上角菜单栏中向下的箭头。在该栏中滚动，直到找到您刚刚添加到系统中的磁盘。如果您刚刚添加的磁盘驱动器没有出现在 Gparted 列表中，那么您无法轻松使用该磁盘驱动器。如果它出现了，请继续下一步。在我们的系统上，新硬盘显示为 /dev/sdb。
- 7. 在菜单栏中选择该新磁盘。它会显示在 Gparted 主窗格中。在 Gparted 主窗格中单击该磁盘。现在您可以对该新磁盘进行分区和格式化。在我们的示例中，它显示为 /dev/sdb，这是我们在第 4 步插入的新磁盘。如图 17.4 所示。请注意，在该图中，磁盘包含一个分区 /dev/sdb1，上面有 ext4 文件系统，且没有标签。
- 8. 在 Gparted 窗口顶部的下拉菜单中，选择 Partition>Delete 菜单项，或者单击图标栏中的红色 X。这将删除该磁盘上的分区信息。它现在是一个待处理操作。
- 9. 要执行待处理操作，请选择下拉菜单中的 Edit>Apply All Operations。在警告窗口中，单击 Apply。将出现一个窗口，显示操作进度以及待处理操作（但愿）成功应用的结果。操作完成后，单击该窗口中的 Close 按钮。
- 10. 新磁盘现在应该是未分配的。单击主 Gparted 窗格中它的列表项。选择下拉菜单中的 Device>Create Partition Table。将“选择新的分区表类型”改为 gpt。在警告窗口中单击 Apply。该磁盘上的所有内容都将被擦除！当 Gparted 创建好新的分区表后，再次单击主 Gparted 窗格中的该磁盘。

# 17.4.4 使用 fdisk 添加磁盘

本节介绍在安装后相当长一段时间再向系统添加磁盘的更传统的方法。我们遵循推荐存储模型，与上一节中我们使用 ZFS 为额外硬盘实现的方法一致。在本节中，我们使用 fdisk 命令对其他磁盘进行分区。本节的示例使用外部挂载的 U盘，它更容易添加，并且对普通用户来说也更容易获得。该示例可以轻松扩展到内部挂载的 SATA 总线驱动器或其他总线架构。在本书网站的 W22 章“ZFS 管理和使用”中，我们给出了更多基于 ZFS 的冗余示例，以说明 ZFS 中类似级别的冗余。

# 17.4.4.1 使用 fdisk 对磁盘进行分区

fdisk 是一个命令行、交互式、对话驱动的程序，用于在 Linux 上创建和管理分区表。以下是 fdisk 语法和用法简介：

```
fdisk [options] device
fdisk -1 [device...]
```

输出：磁盘设备上新建或被操作的分区

- - N 创建新分区。输入分区号、起始扇区和结束扇区。起始扇区和结束扇区都可以用扇区号的绝对形式指定。直接按 Enter 键表示使用默认值，即起始扇区使用最大可用块的起始位置，结束扇区使用同一个块的结束位置。
- - p 显示基本分区摘要数据。这包括分区号、起始和结束扇区号、分区大小、fdisk 的分区类型代码和分区名称。
- - t 更改单个分区的类型代码。使用两字节的十六进制数输入类型代码。
- - w 写入数据。使用此命令保存更改。

sudo fdisk /dev/sdb
作为超级用户，在磁盘 /dev/sdb 上运行 fdisk

# 示例 17.6 使用 fdisk 在 U盘上放置单个分区

- - 目标：练习在一个 U盘上放置一个 Linux 分区，并在该分区上创建 ext4 文件系统。
- - 前提条件：拥有一个可以在您的系统上使用的 U盘。

要求：按顺序完成后续步骤，以满足本示例的要求。

- 1. 之前已确认您的系统能识别该 U盘，并确定其逻辑设备名（我们的是 `/dev/sdb`），然后将其插入 USB 端口。我们使用的是 8GB 金士顿 U盘；*非常可靠*，并且总能在 Linux Mint 和其他类 NIX 系统上自动挂载。
- 在 Linux Mint 上，U盘会被自动挂载。使用以下命令卸载它：
- ```bash
$ sudo umount /dev/sdb1
```
- 2. 使用 fdisk 对新添加的 U盘进行分区，确保首先删除它上面已有的任何分区。对于我们的金士顿 U盘，它上面只有一个默认分区。
