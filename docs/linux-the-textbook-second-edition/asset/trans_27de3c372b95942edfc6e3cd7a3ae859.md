### 15.1 引言

内核执行 Linux 操作系统的稳态维护，并且内核通过系统调用接口 SCI 向用户程序提供服务。这种维护是通过使用三种技术实现的：虚拟化、并发和持久性。虚拟化允许设备，例如单个或多核 CPU，表现得好像是许多 CPU 同时以时间共享方式运行。并发允许多线程或多进程程序访问硬件的虚拟化资源。持久性允许数据通过诸如固态驱动器 SSD 之类的设备上的 I/O 机制随时间保留。

在本章和随后的三章中，我们描述了 SCI 的各个组件如何在其角色中实现虚拟化、并发和持久性。本章涉及持久性。第 16 章涉及虚拟化和并发。第 W20 章涉及虚拟化和并发的通信方面。第 W21 章涉及与虚拟化、并发和持久性相关的各种实际问题。

在本章中，我们讨论了 SCI 提供的 API 用于文件处理。我们假设读者熟悉通过围绕 ISO C 标准规范构建的标准 I/O 库使用文件处理，并且该库可在包括 Linux 在内的多个操作系统平台上使用
