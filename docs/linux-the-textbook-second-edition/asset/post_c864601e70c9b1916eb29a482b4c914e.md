### Step 2. ZFS Installation

Install Linux headers. We install ZFS using dkms for our installation. The symbolic link is used here because of a bug inside the zfs distribution in Debian that doesn’t look for rm binary correctly.

```
[root@debian]# apt -y install linux-headers-$(uname -r)
[root@debian]# ln -s /bin/rm /usr/bin/rm
[root@debian]# apt-get -y install zfs-dkms
```

### Step 3. ZFS Start and Restart

At this point, zfs-dkms is installed. To start ZFS, use the following commands:

```
[root@debian]# /sbin/modprobe zfs
[root@debian]# systemctl restart zfs-import-cache
[root@debian]# systemctl restart zfs-import-scan
[root@debian]# systemctl restart zfs-mount
[root@debian]# systemctl restart zfs-share
```
