### 13.2 数值数据处理

所有Bash变量的值都以字符串形式存储。虽然这一特性使得符号数据处理变得有趣且容易，但它确实使数值数据处理有些挑战性。原因是整数数据实际上是以字符串的形式存储的。要对它们执行算术和逻辑运算，你需要将它们转换为整数，对整数数据执行必要的运算，并确保结果转换回字符串，以便正确存储在shell变量中。在本节中，我们讨论执行算术运算的不同方法，首先使用Bash的功能，然后使用bc（一种任意精度计算器），它随所有Linux发行版预装。

### 13.2.1 用于算术运算的Bash特性

在Bash中有三种方法可以对数值数据执行算术运算，而无需进行字符串到整数的转换，反之亦然。这些方法是：

- 使用let命令
- 使用shell扩展`$((expression))`
- 使用expr命令

表达式求值以长整数执行，且不进行溢出检查。当shell变量在表达式中使用时，它们会被展开（即其值被替换到表达式中），并在表达式求值之前被强制转换（即其数据类型被视为）为所需的数据类型。Bash支持的算术、逻辑和关系运算符列于表12.6中，按优先级从高到低排列。分组在一起的运算符具有相同的优先级。可以通过将表达式括在括号中来改变求值顺序。带有前导0的常量被视为八进制数；带有前导0x或0X的常量被视为十六进制数。否则，数字被视为十进制数。

Bash内置命令let允许你通过将算术表达式指定为其参数来求值。如果表达式包含空格或其他特殊字符，则必须用双引号括起来。以下是该命令的简要说明：

```
语法：
  let expression-list
用途：求值expression-list中的算术表达式
```

如果最后一个表达式求值为0，则let返回1；否则返回0。以下会话展示了let命令的交互式使用。请注意，引用shell变量的值时不需要`$`，并且在第一个let命令中没有使用引号，因为其中使用的表达式不包含空格。这些示例展示了使用let命令进行变量声明和算术表达式求值。最后一个let命令中的表达式`b**x`表示b的x次方。

```
$ let a=8 b=13
$ let c=a+b
$ echo "The value of c is $c."
The value of c is 21.
$ let a*=b
$ echo "The new value of a is $a; the product of a and b."
The new value of a is 104; the product of a and b.
$ b=2 x=10 y=20 z=30
$ let K=b**x M=b**y G=b**z
$ echo "In computer jargon 1K is $K, 1M is $M, and 1G is $G."
In computer jargon 1K is 1024, 1M is 1048576, and 1G is 1073741824.
$
```

也可以使用以下Bash表达式语法来求值算术表达式。对“expression”进行求值并返回结果。

```
语法：
  $((expression))
用途：求值“expression”并返回其值
```

在以下会话中，我们使用此语法执行与上一会话相同的任务。

```
$ b=2 x=10 y=20 z=30
$ echo "In computer jargon 1K is $((b**x)), 1M is $((b**y)), and 1G is $((b**z))."
In computer jargon 1K is 1,024, 1M is 1,048,576, and 1G is 1,073,741,824.
$
```

请注意，你可以将`$((b**x))`、`$((b**y))`和`$((b**z))`的值存储在变量K、M和G中，就像上一会话中所做的那样。但是，除非你想在之后使用这些值，否则不需要这样做。

以下是expr命令的简要说明：

```
语法：
  expr args
用途：求值表达式参数args并将结果发送到标准输出
```
