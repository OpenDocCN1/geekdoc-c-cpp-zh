

## 16.6 使用pthreads进行线程编程

我们在16.2.5节至16.2.7节中讨论了线程的一般概念、线程与进程之间的差异、线程之间共享的资源、线程与创建它们的进程共享的资源，以及线程之间数据共享的相关问题。在本节中，我们将介绍POSIX标准线程API的Gnu/Linux实现，称为pthreads。

### 16.6.1 pthread API

pthread函数和数据类型定义在头文件/usr/include/pthreads.h中。pthreads函数位于libpthread库中，不属于标准C库的一部分。因此，在gcc的命令行中应使用-lpthread选项链接此库。表16.11列出了基本pthread API函数及其简要说明。

### 16.6.2 线程创建

可以使用pthread_create()函数创建线程。下面是该函数的简要说明：

```
#include <pthread.h>
int pthread_create(pthread_t *restrict tid, const pthread_attr_t *restrict attr,
    void *(*tfn) (void *), void *restrict arg);

Success: 0
Failure: Error number
```

线程成功创建后，tid包含新创建线程的线程ID（TID）。attr参数包含线程属性，tfn是线程开始执行的函数的地址，arg是函数参数。如果将attr设置为NULL，则使用默认属性创建线程。如果将arg设置为NULL，则线程函数在没有任何参数的情况下执行。

与系统中对进程唯一的PID不同，TID对进程内的线程是唯一的。线程可以通过调用pthread_self()函数获取其ID。TID的类型为pthread_t，这是一种结构类型。该函数总是成功。您可以使用pthread_equal()函数来比较两个TID。以下是这些函数的简要说明：

```
#include <pthread.h>
int pthread_self(void);

Success: TID of the caller thread
```

每个进程至少有一个线程，通常从main函数开始。因此，每个进程都有PID和TID。在下面的会话中，process.c程序显示其PID和TID。我们编译该程序并将其可执行文件保存为proc文件。运行proc的示例输出显示进程的PID为17401，TID为2877273856。

```
$ cat process.c
#include <pthread.h>
#include <stdio.h>

int main (void)
{
    pid_t pid;
    pthread_t tid;

    pid = getpid();
    tid = pthread_self();
    printf ("pid %u tid %u\n", (unsigned int) pid, (unsigned int) tid);
    exit(0);
}
$ gcc -w process.c -o proc -lpthread
$ proc
pid 17401 tid 2877273856
$
```

我们修改该程序，使其创建一个线程，并由线程显示其PID和TID。主线程不显示其PID或TID。在下面的会话中，process_thread.c程序执行此任务。我们编译该程序并将其可执行文件保存为proc_t文件。proc_t的示例输出显示该线程位于PID为17741的进程中，线程的TID为71923456。请注意，我们使用sleep(1);调用来使父进程休眠1秒。我们将在16.6.3节讨论其目的。

```
$ cat process_thread.c

#include <stdio.h>

void thread_fn (void *);

int main (void)
{
    pthread_t tid;
    int rval;

    rval = pthread_create(&tid, NULL, thread_fn, NULL);
    if (rval != 0) {
        printf("Thread creation failed.\n");
        exit(1);
    }
    sleep(1);
    exit(0);
}

void thread_fn (void *arg)
{
    pthread_t tid;
```

在下面的会话中，thread_ids.c程序创建一个线程，该线程显示其ID以及创建它的进程的ID。主线程（即进程）显示其PID和TID。

```
$ cat thread_ids.c
#include <pthread.h>
#include <stdio.h>

void thread_fn(void *);
void displayids (const char *);

int main (void)
{
    pthread_t tid;
    int rval;

    rval = pthread_create(&tid, NULL, thread_fn, NULL);
    if (rval != 0) {
        printf("Thread creation failed.\n");
        exit(1);
    }
    displayids("Parent/Main thread:      ");
    sleep(1);
    exit(0);
}

void thread_fn (void *arg)
{
    displayids("Child thread:      ");
    return NULL;
}

void displayids (const char *s)
{
    pthread_t tid;
    pid_t pid;

    tid = pthread_self();
    pid = getpid();
    printf ("%s pid %u tid %u\n", s, (unsigned int) pid, (unsigned int) tid);
}
$ gcc -w thread_ids.c -o tids -lpthread
$ tids
Parent/Main thread:      pid 10249 tid 309786368
Child thread:            pid 10249 tid 301491968
$
```

### 16.6.3 线程终止

线程可以因以下任一原因终止：

- 1. 它从其线程函数返回。
- 2. 该线程调用`pthread_exit()`函数。
- 3. 同一进程中的另一个线程使用`pthread_cancel()`函数终止它。

在**process_thread.c**和**thread_ids.c**程序中，我们使用`sleep(1)`调用来使进程等待1秒。这样做是为了给线程足够的时间完成执行并从线程函数`thread_fn()`返回。

使用`pthread_create()`创建的线程可以是**可连接**的或**分离**的。默认情况下，它们是可连接的。创建线程的线程（或进程）可以使用`pthread_join()`等待其终止。这类似于进程用来等待子进程终止的`wait()`系统调用（或其任何变体）。以下是该调用的简要说明：

```
#include <pthread.h>
int pthread_join(pthread_t tid, void **retval);

Success: 0
Failure: Error number
```

第一个参数是要等待的线程的ID，`retval`是存放线程返回值的位置。如果第二个参数为NULL，则忽略线程的返回值。如果给定的线程已经终止，`pthread_join()`会立即返回。

以下是`pthread_exit()`调用的简要说明。

```
#include <pthread.h>
int pthread_exit(void *retval);

Success: 0
Failure: Error number
```

进程中的其他线程可以通过调用`pthread_join()`访问`retval`指针。如果线程通过从线程函数返回而终止，`pthread_join()`中的`retval`将包含返回代码。如果线程因被另一个线程取消而终止，则`retval`指向的内存位置包含`PTHREAD_CANCELED`。

如果一个可连接线程（默认）没有被`pthread_join()`等待，它在终止时不会自动清理。它会像僵尸进程一样一直存在，直到另一个线程调用`pthread_join()`获取其返回值。可以通过调用`pthread_detach()`将可连接线程转变为分离线程，该函数唯一的参数是要分离的线程的TID。另一方面，分离线程不能更改为可连接线程。您不能使用`pthread_join()`等待分离线程；它会在终止时被清理。
