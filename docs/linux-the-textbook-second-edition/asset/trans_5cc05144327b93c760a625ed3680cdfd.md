### 17.3.3 Deleting a User Account and Group from the Command Line

要使用命令行有效地从系统中删除用户账户或组，请使用 deluser 或 delgroup 命令。以下是这些命令的简要描述：

**deluser, delgroup** - 从系统中移除用户或组

**Syntax:**

```text
deluser  [options][--force] [--remove-home]   [--remove-all-files]
                     [--backup] [--backup-to DIR] user
deluser --group [options] group
delgroup [options] [--only-if-empty] group
deluser [options] user group
```

Purpose: deluser 和 delgroup 根据命令行选项和 /etc/deluser.conf 和 /etc/adduser.conf 中的配置信息从系统中移除用户和组。

Common Options:
[--conf FILE]       使用 FILE 代替 /etc/deluser.conf
--version           显示版本和版权信息

## 17.3.5 Basic Password Management

负责用户和组账户管理的人员经常需要出于明显的安全原因更改密码。这最容易通过 passwd 命令完成。我们给出此命令使用的几个基本示例。要更完整地描述 passwd 命令，请参阅 Linux 系统上的 man 手册。

要重置用户账户的密码，使用以下命令：

```
$ sudo passwd mansoor
[sudo] password for bob: QQQ
Enter new UNIX password: ZZZ
Retype new UNIX password: ZZZ
passwd: password updated successfully
$
```

要获取 passwd 命令可用选项的简要列表，使用以下命令：

```
$ sudo passwd -h mansoor
Usage: passwd [options] [LOGIN]
```

Options:
  -a, --all          报告所有账户的密码状态
  -d, --delete       删除指定账户的密码
  -e, --expire       强制使指定账户的密码过期
  -h, --help         显示此帮助信息并退出
