## 17.6.2.5 在本地和远程复制目录层次结构

你可以使用 tar 命令将一个目录复制到另一个目录。你也可以使用 cp -r 命令来实现，但使用 cp -r 的缺点是无法保留传统的文件访问权限和文件修改时间。复制后的文件和目录的访问权限由 umask 的值决定，修改时间则被设置为当前时间。为了弥补 cp -r 的这一缺点，你可以使用 cp -p 命令来保留文件权限。

使用 tar 命令的 --preserve-permissions 选项，可以在解压存档时保留文件对象的传统权限。在解压存档时，默认情况下不会保留权限，解压后的存档成员的权限由你解压所处环境中的 umask 设置决定。

例如，在下面这条具有指导意义的命令中，将对一个目录的内容进行打包（tar），更改当前工作目录，然后将原始目录内容解包到新的当前工作目录中，同时保留各成员的权限，整个过程如下所示。

```
$ mkdir pertest
$ cd pertest
~/pertest $ touch testfile2
~/pertest $ ls -la testfile2
-rw-r--r-- 1 bob bob 0 Oct 23 05:22 testfile2
~/pertest $ chmod u+x testfile2
~/pertest $ chmod g+w testfile2
~/pertest $ chmod o+wx testfile2
~/pertest $ ls -la testfile2
-rwxrwxrwx 1 bob bob 0 Oct 23 05:22 testfile2
~/pertest $ mkdir perback
~/pertest $ cd /home/bob/pertest; tar --create --verbose --file - . ) | (cd /home/bob/perback; tar --extract --preserve-permissions --file -)
./
./testfile2
~/pertest $ cd perback
~/pertest/perback $ ls -la
total 8
drwxr-xr-x 2 bob bob 4096 Oct 23 06:03 .
drwxr-xr-x 45 bob bob 4096 Oct 23 05:27 ..
-rwxrwxrwx 1 bob bob 0 Oct 23 05:22 testfile2
~/pertest/perback $
```

关键选项是在将存档解压到 /home/bob/perback 时，在解压操作中添加 --preserve-permissions。

上述命令行会话展示了 tar 命令的一个非常常见的用例，即：

- 将本地源目录打包成存档，
- 切换到本地（或远程）目标目录，
- 在后一个目录中解包（解压）存档的目录。

通过使用命令分组和管道，可以用一条命令完成整个任务。

例如，在下面这条具有指导意义的命令中，将对一个目录的内容进行打包（tar），更改当前工作目录，然后将原始目录内容解包到这个新的当前工作目录中，整个过程如下所示。

```
$ tar --create --verbose --file - . | (cd /home/bob/backup; tar --extract --verbose --file -)
```

其中（从左到右依次为）：

- --create 表示创建存档
- --verbose 表示对过程提供详细的反馈信息
- --file 指定用作存档的文件
- -（连字符）将文件指定为标准输出（stdout）。stdout 将被管道传递给另一个程序进行进一步处理
- . 表示当前工作目录
- | 表示管道，即将 stdout 重定向到管道右侧程序的标准输入（stdin）
- () 表示创建一个新的 shell。因此，管道之后的所有内容的标准输入都会被送入一个新的 shell。
- cd /home/bob/backup 指定备份的目标位置
- ; 表示开始一条新命令
- tar --extract --verbose --file 表示将详细解压操作输出到文件中
- -（连字符）表示使用标准输入（stdin）来创建存档文件

在下面的会话中，~/unixbook/examples 目录被复制到 ~/unixbook/examples.bak 目录。管道左侧的 tar 命令将存档发送到标准输出（stdout），而管道右侧的 tar 命令则从标准输入（stdin）接收存档并将其解包。

```
$ (cd ~/unixbook/examples; tar --create --verbose --file - .) | (cd ~/unixbook/examples.bak; tar --extract --verbose --file -)
./ OK
./Bshell/Domain, 14 bytes, 1 tape blocks a ./Bshell/IP, 18 bytes, 1 tape blocks
./Bshell/dns_demo1, 227 bytes, 1 tape blocks

Output truncated...

./Bshell/fs.csh, 1531 bytes, 3 tape blocks x ./Bshell/dir1, 0 bytes, 0 tape blocks
./Bshell/copy, 2222 bytes, 5 tape blocks

$
```

使用上述多命令 Linux 命令行的优点是，cd 和 tar 命令在所有 Linux（甚至 UNIX）系统上都可用。

此外，tar 命令还可用于将目录从本地机器复制到网络上的远程机器。

为了说明这一点，请在您的 Linux 系统上执行以下操作。这里我们假设您可以 rsh 到局域网中的另一台 Linux 或 UNIX 机器，并且您在该机器上拥有一个账户。在我们后面的示例会话中，该远程机器是 192.168.0.31——一台 UNIX TrueOS 机器。

## 17.6.2.6 使用 tar 解压软件发行包

公司通常使用 tar 命令来分发其软件，因为它会生成一个客户只需复制的单个文件，并且与可能包含待分发软件的未打包目录层次结构相比，它节省了磁盘空间。此外，大多数公司会将其发行包（以 tar 格式）存放在互联网网站上，客户可以通过 ftp 命令下载这些发行包。因此，tar 格式还减少了“复制”时间，并减少了客户的工作量，客户只需使用一次 get（或 mget）ftp 子命令，而如果必须下载未打包的目录层次结构，则需要执行多组命令。

由于图形界面和多媒体格式使得软件包的体积很大，因此存档在放在安全的 ftp 站点或网站上之前通常会被压缩。软件用户需要解压缩并恢复存档文件，以展开该软件包的目录层次结构。现在考虑一个文件 **VirtualBox-4.3.16-95972-SunOS.tar.gz**。在从互联网下载此文件后，为了将其恢复，我们可以使用一条多命令 Linux 命令行在本地 Linux 机器上将其解压缩并解包，如下所示：

```
$ gunzip -cd VirtualBox-4.3.16-95972-SunOS.tar.gz | tar --extract --verbose --file -
... [Output truncated]
$
```
