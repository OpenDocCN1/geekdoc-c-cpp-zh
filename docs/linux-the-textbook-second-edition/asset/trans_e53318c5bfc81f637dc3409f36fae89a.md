

## 12.3.2 变量声明

Bash 不要求你声明变量并初始化它们，但你可以使用 declare 和 typeset 命令来声明变量、初始化变量并设置其属性。变量的属性决定了可以赋值给它的值的类型及其作用域（即它可被访问的位置）。Bash 变量默认为字符串变量，但你可以将变量定义为整数类型。你还可以使用这些命令声明函数和数组（参见第 13 章）。你可以将变量标记为只读，并使变量的值对子进程可用。以下是这些命令的简要说明：

```
Syntax:
    declare    [options] [name=value]
    typeset    [options] [name=value]
Purpose:  Declare variables, initialize them, and set their attributes. Inside functions, new copies of the variables are created. Using + instead of – turns attributes off
Output:   Without name and options, display names of all shell variables and their values in the environment of the current shell. With options, display names of variables with the given attributes and their values
Commonly used options/features:
    -a each "name" is an array
    -f each "name" is a function
    -i "name" is an integer
    -r mark each "name" read-only (cannot be turned off by using +x)
    -x mark each "name" exported
```

未声明且未初始化的变量的初始值为空字符串。Bash 也不要求你在声明变量时指定其属性。你可以稍后通过使用 declare 或 typeset 命令，或通过使用其他用于设置特定属性的命令来初始化变量并设置其属性。声明一个已存在的变量不会改变其当前的值/属性。在下面的会话中，我们演示了 declare 命令的用法；如果你愿意，可以用 typeset 命令替换它。

```
$ declare age=58
$ declare -rx OS=Linux
$ echo $age
58
$ echo $OS
Linux
$ declare OS
$ declare age
$ echo $OS
Linux
$ echo $age
58
$
```

你可以使用 name=value 语法来更改变量的值，这将在 12.2.3 节中详细讨论。你可以使用这种语法来声明可被赋予字符串值的通用变量。整数变量不能被赋予非整数值；如果这样做，变量的值将变为零。非整数变量可以被赋予任何值，因为每个值都以字符串形式存储。如下所示：

```
$ name=John*
$ echo $name
John.Bates.letter John.Johnsen.memo John.email
$ echo "$name"
John*
$ name=John*
Sat Jun 10 23:19:49 PKT 2017
$ echo $name
John.Bates John.email John.Johnsen
$ echo "The name $name sounds familiar!"
The name John* sounds familiar!
$ echo \$name
$name
$ echo '$name'
$name
$
```

如果赋值语句的右侧没有用引号括起来且包含空格，shell 会假定右侧第二个及之后的单词构成一条命令，并尝试执行它。如果所假定的命令不是有效命令，shell 会显示一条错误消息，如语句 name=Jimmy Doe 所示。另一方面，对于 name=David date 命令，会显示 date 命令的输出。类似地，对于 name=James more ~/.profile | grep PATH，shell 会显示 more ~/.profile | grep PATH 命令的输出。在所有这些情况下，无论第二个及后续单词是否构成有效命令，第一个命令都不会执行。因此，name 变量的值仍然保持为会话开始时赋给它的先前值 John。

在 name=John* 语句执行后，如果 echo 命令中的 $name 没有用引号括起来，shell 会列出当前工作目录中与 John* 匹配的文件名，其中 * 被视为 shell 元字符。但是，如果当前目录中没有以字符串 John 开头的文件，echo 命令会显示 John*。然而，如果当前目录中不包含任何以字符串 John 开头的文件，echo John* 命令会显示 John*。变量 $name 必须用引号括起来才能引用 John*，例如 echo "$name"。

## 12.3.4 命令替换

命令替换允许你用命令的输出替换命令本身。以下是命令替换的简要说明。请注意语法第一种形式中反引号（也称为重音符）的使用。在本书的示例、shell 会话和脚本中，我们将使用第一种语法。

```
Syntax:
`command`
$(command)
Purpose: Execute command and substitute `command` (or $(command), if you use this syntax) with the output of the command
```

下面的会话通过几个示例说明了这一概念。在第一条赋值语句中，变量 command 被赋值为 pwd。在第二条和第三条赋值语句中，pwd 命令的输出被赋给 command 变量。

```
$ command=pwd
$ echo "The value of command is: $command."
The value of command is: pwd.
$ command=`pwd`
$ echo "The value of command is: $command."
The value of command is: /home/sarwar/linux2e/ch12.
$ command=$(pwd)
$ echo "The value of command is: $command."
The value of command is: /home/sarwar/linux2e/ch12.
$
```

命令替换可以在任何命令中指定。例如，在下面的会话中，在执行 echo 命令之前，date 命令的输出会替换 `date`。

```
$ echo "The date and time are `date`."
The date and time are Sat Jun 10 23:32:58 PKT 2017.
$
```

在本章和第 13 章中，我们将以多种方式演示命令替换的实际应用。

## 12.3.5 导出环境

当变量在某个 shell 中创建时，后续 shell 无法自动访问它。export、declare -x 或 typeset -x 命令会将变量的值传递给后续 shell。因此，当一个 shell 脚本被另一个 shell 脚本调用并执行时，它不会自动访问原始（即调用者）脚本中定义的变量，除非这些变量被明确地提供给该脚本。这些命令可用于将一个或多个 shell 变量的值传递给任何后续脚本。所有可读写的 shell 环境变量对每条命令、每个脚本和每个子 shell 都可用，因此它们在初始化时即被导出。以下是这三个命令的简要说明：

```
Syntax:
  declare -x [name-list]
  typeset -x [name-list]
  export [name-list]
Purpose: Export the names and copies of the current values in name-list to every command executed from this point on
```

下面的会话展示了 declare -x 命令的一个简单用法。place 变量被初始化为 notre dame，并被导出到当前 shell 下执行的后续命令以及当前 shell 下运行的任何子 shell。

```
$ declare -x place="notre dame"
$ export place
$
```
