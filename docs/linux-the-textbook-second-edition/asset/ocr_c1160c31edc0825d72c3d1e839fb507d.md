# 9.15 FIFOs

FIFOs, also known as named pipes, can also be used for communication between two processes executing on a system. Although processes communicating with pipes must be related to each other through a common ancestor process that you execute, processes communicating with FIFOs do not have to have this kind of relationship—they can be independently executed programs on one system. For the command line use of pipes and FIFOs, this means that pipes can be used only for communication between commands connected via a pipeline, and FIFOs can be used for communication between separately run commands.
