

/etc/passwd：`/etc/passwd` 文件包含系统中每个用户的一行信息，并描述该用户。每行有七个字段，用冒号分隔。以下为该行的格式。

```
login_name:password:user_ID:group_ID:user_info:home_directory:login_shell
```

`login_name` 是用户在系统中使用的登录名，也是用户登录时输入的名称。`password` 字段包含一个假的密码 `x`（或 `*`）。加密后的密码存储在 `/etc/shadow` 文件中。只有超级用户（即 root）对此文件拥有读写权限；其他任何人都不能读取该文件。可移植操作系统接口（POSIX）要求用户 ID（UID）为整数类型。通常，超级用户的 UID 被分配为 0。其他一些登录名也被分配了已知（或来自已知范围）的 UID。通常，UID 1–499 或 1–999 被保留。根据你所使用的 Linux 系统，UID 1,000–32,767 或 1,000–65,536 被分配给像你我这样的“普通”用户。在使用 32 位 UID 的系统中，该范围为 1,000–4,294,967,295。`group_ID` 用于标识用户所属的组，同样是一个介于 0 和 65,535 之间的整数，通常 0–99 为保留整数。`user_info` 字段包含有关用户的信息，通常是用户的全名。`home_directory` 字段包含用户主目录的绝对路径名。最后一个字段 `login_shell` 包含用户登录 shell 的绝对路径名。当用户登录时，系统会执行该字段中指定路径名所对应的命令。连续两个冒号表示该字段值缺失，这有时出现在 `user_info` 字段中。以下会话显示了在我们系统中针对用户 sarwar 的 `/etc/passwd` 文件中的那一行：

```
$ cat /etc/passwd | grep "sarwar"
sarwar:x:1004:1008:Mansoor Sarwar,,,:/home/sarwar:/bin/bash
$
```

在这一行中，登录名是 `sarwar`，密码字段包含 `x`，用户 ID 是 1004，组 ID 是 1008，个人信息是用户的全名（Mansoor Sarwar），主目录是 `/home/sarwar`，登录 shell 是 `/bin/bash`，也就是 Bash shell。以下章内练习让你在 Linux 机器上浏览文件系统，并帮助你理解 `/etc/passwd` 文件的格式。

## 4.5 浏览文件结构

现在，我们介绍一些用于浏览 Linux 文件系统、创建文件和目录、确定文件属性、主目录的绝对路径名、当前工作目录的路径名以及文件类型的常用命令。本讨论基于图 4.2 中所示的文件结构和用户名 `sarwar`。

### 4.5.1 确定主目录的绝对路径名

当你登录时，系统会将你置于主目录中。你可以使用 `echo` 和 `pwd` 命令找到主目录的完整路径名。

不带参数时，`echo` 命令会在屏幕上显示一个空行。你可以使用 `echo` 命令确定主目录的绝对路径名，如下所示：

```
$ echo $HOME
/home/sarwar
$
```

其中 `HOME` 是 Bourne shell 中的一个 shell 变量（占位符）。shell 使用该变量来跟踪主目录的绝对路径名。在 C shell 中，该变量为 `home`。我们将在第 12、13、W29 和 W30 章中详细讨论 shell 变量和 `echo` 命令。

另一种显示主目录绝对路径名的方法是使用 `pwd` 命令。你可以使用该命令来确定当前所在目录的绝对路径名，即当前工作目录，也称为当前目录。该命令不需要任何参数。当你登录时，Linux 系统会将你置于主目录中。你可以在登录后立即使用 `pwd` 命令来显示主目录的绝对路径名，如下所示：

```
$ pwd
/home/sarwar
$
```

### 4.5.2 浏览文件系统

你可以通过从主目录转到文件系统结构中的其他目录，并显示目录的内容（目录中的文件和子目录）来浏览文件系统，前提是你拥有相应的权限。我们将在第 5 章中详细讨论文件安全和访问权限。现在，我们介绍如何使用 `cd`（更改目录）和 `ls`（列出目录）命令来浏览你自己的文件和目录。

以下是 `cd` 命令的简要说明。

**语法：**

```
cd [directory]
```

**用途：** 将当前工作目录更改为 `directory`；如果未指定参数，则更改为主目录。

每次执行 `cd` 命令后，shell 变量 `PWD` 都会更新。`pwd` 命令使用该变量的值来显示当前工作目录。进入某个目录后，你可以使用 `ls` 命令查看其内容（其中文件或子目录的名称）。以下是该命令的简要说明。`cd` 和 `ls` 命令是 Linux 中使用最频繁的两个命令。

**语法：**

```
ls [option] [pathname-list]
```

**用途：** 将 `pathname-list` 中指定的目录和文件中的文件名发送到显示屏幕。

**输出：** `pathname-list` 中指定目录中的文件和目录名称；如果 `pathname-list` 仅包含文件名，则只显示这些名称。

**常用选项/特性：**

- `-F` 在目录后显示 `/`，在二进制可执行文件后显示 `*`，在符号链接后显示 `@`。
- `-a` 显示所有文件的名称，包括隐藏文件 `.`、`..` 等。
- `-h` 与 `-l` 和/或 `-s` 选项一起使用时，以人类可读的尺寸显示输出（例如 1.1 K、31 M、2.6 G）。
- `-i` 显示 inode 编号和文件名。
- `-l` 显示长列表，包括访问权限、硬链接计数、所有者、组、文件大小（以字节为单位）和修改时间。

如果该命令不带任何参数使用，它会显示当前工作目录中文件和目录的名称。以下会话演示了 `ls` 和 `cd` 命令在带参数和不带参数时的工作方式。`pwd` 命令显示当前目录的绝对路径名。除隐藏文件外，`ls` 命令显示当前目录中所有文件和目录的名称。`cd courses` 命令用于将 `courses` 目录设为当前目录。`cd ee446/exams` 命令将 `ee446/exams` 设为当前目录。`ls ~` 和 `ls $HOME` 命令显示主目录中文件和目录的名称。不带任何参数的 `cd` 命令将你置于主目录中。换句话说，它将你的主目录设为当前目录。

```
$ cd ee446/exams

Desktop  Downloads  Music    Public    Videos

courses  Documents  linux2e  Pictures  Templates
Desktop  Downloads  Music    Public    Videos

$ ls
courses  Documents  linux2e  Pictures  Templates

$
```
