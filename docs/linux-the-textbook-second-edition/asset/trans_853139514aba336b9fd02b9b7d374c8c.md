

如果软件应用程序分发在二级存储介质（USB 闪存盘、DVD 或 CD-ROM）上，你需要将适当的文件复制到适当的目录并重复之前的多个命令。

如果你想分发你编写的存储在目录层次结构中的某个软件应用程序，如前所示，你可以使用 tar 命令同时对其创建归档并进行压缩。这会在可放置在 ftp 仓库、网页上或作为电子邮件附件发送的压缩文件中创建 tar 归档。

> 将文件归档到磁盘文件是创建用于分发和备份的软件包和应用程序最现代且最具成本效益的方式。

--gzip 选项可用于生成 tar 归档的压缩版本。--gunzip 选项可用于恢复 tar 归档的压缩版本。这些选项的使用消除了使用 gzip（或 gunzip）实用程序分别压缩或解压缩归档，然后再使用 tar 命令的需要；这一步骤过程可由 tar 命令单独完成。在以下会话中，第一个 tar 命令在 ~/unixbook/backups/ub.tar.gz 文件中生成当前目录的压缩 tar 归档，第二个 tar 命令从同一文件中将压缩 tar 归档恢复到当前目录。

```
$ tar --gzip --create --file ~/unixbook/backups/ub.tar.gz .
$ tar --gunzip --extract --verbose --file ~/unixbook/backups/ub.tar.gz
Output truncated ...
$
```

## 17.6.3 其他 Linux 归档和备份设施

除了传统的 tar 设施外，系统管理员还可以使用几种其他设施和方法来归档和备份单个用户账户、文件、文件系统以及整个系统本身。如前所述，要获取本节及所有其他节中所示命令行设施的完整功能和选项列表，请查阅系统上这些命令的手册页。我们稍后将简要描述并给出一些更现代和有用的设施和方法的简单示例。此外，在本书网站的第 W22 章，标题为“ZFS 管理与使用”中，我们提供了使用 ZFS 快照在 Linux 中进行归档和备份的方法。

### 17.6.3.1 rsync

rsync 命令是一种节省空间的备份文件和目录的方式，特别是使用 ssh 通过网络从一台机器备份到另一台机器。其操作也可以通过 systemd 调度进行自动化。

其最重要的定义特征是其使用的数据传输“快速检查”算法，该算法减少了传输的数据量。这是通过仅发送源文件与相同现有目标文件（如果有）之间的差异来实现的。如果文件需要传输，因为源和目标之间存在差异，它们会使用此算法进行复制，或“同步”。该算法查找大小或修改时间已更改的文件。其他可能保留的文件对象属性（如权限或 ACL）的更改（例如权限或 ACL）会在快速检查指示目标文件需要以这种方式更新时直接在目标文件上进行。

rsync 手册页的简要摘要如下：

rsync

```
Syntax:
  Local:  rsync [OPTION...] SRC... [DEST]
Purpose: To transfer files locally or remotely using an efficient and fast data transfer algorithm.
  To copy locally, to/from (push/pull) another host over any remote shell, or to/from (push/pull) a remote rsync daemon
Remote:
via remote shell:
Pull mode: rsync [OPTION...] [USER@]HOST:SRC... [DEST]
```

```
Push mode: rsync [OPTION...] SRC... [USER@]HOST:DEST
via rsync daemon:
Pull mode: rsync [OPTION...] [USER@]HOST::SRC... [DEST]
rsync [OPTION...] rsync://[USER@]HOST[:PORT]/SRC... [DEST]
Push mode: rsync [OPTION...] SRC... [USER@]HOST::DEST
rsync [OPTION...] SRC... rsync://[USER@]HOST[:PORT]/DEST
```

Output: Transferred files, either locally or remotely.

- -a, --archive archive mode
- -A, --acls preserve ACLs (implies -p)
- --delete delete extraneous files from destination dirs
- -e --rsh=COMMAND specify the remote shell to use
- --existing skip creating new files on receiver
- -h, --human-readable output numbers in a human-readable format
- -H, --hard-links preserve hard links
- -k, --copy-dirlinks transform symlink to dir into referent dir
- -K, --keep-dirlinks treat symlinked dir on receiver as dir
- -n, --dry-run perform a trial run with no changes made
- -p, --perms preserve permissions
- -q, --quiet suppress nonerror messages
- -r, --recursive recurse into directories
- --remove-source-files sender removes synchronized files (nondir)
- -v, --verbose increase verbosity
- -z, --compress compress file data during the transfer

- SRC the source file or directory
- DEST the destination path

我们在以下示例集中做出的基本假设之一是源通常是一个随时间变化的文件对象，例如你正在通过向其中添加或删除文件来修改文件的目录，或其子目录。此外，目标是一个不变化或随时间固定的文件对象，例如当你进行备份时。当你使用归档实用程序时，这通常是这种情况，尽管如你之前在 tar 命令中所见，归档（或目标）可以通过各种方式添加或提取。

通常，我们不涵盖 rsync 的更复杂或高级用法。

我们根据示例是否适用于源和目标都在本地机器上或源或目标在远程机器上对 rsync 示例进行了组织。示例也可以分为仅处理文件或处理目录和文件的示例。

# 本地示例：

1. 使用 rsync 将名为 rsynctest 的单个文件从源当前工作目录复制到本地目标目录 /home/bob/USBit。文件以“归档”模式传输，使用 -a 选项完成。这确保了符号链接、设备、属性、权限等得以保留。

```
$ rsync -av rsynctest /home/bob/USBit
```

2. 以压缩形式复制单个本地文件，并以人类可读形式呈现操作反馈，从源 backup.tar（在当前工作目录中）复制到你有权限的目标目录 /home/mansoor/backup1。

```
$ rsync -zvh backup.tar /home/mansoor/backup1
```

3. 使用 rsync 将整个源目录内容从本地目录名 syncdir 复制到本地目标目录名 /usr/home/bob/USBint。指定源末尾的斜杠表示“复制此目录的内容”，而不是“按名称复制目录”

```
$ rsync -av syncdir/ /usr/home/bob/USBint
```

4. 以压缩形式将单个源目录 /home/bob/backups 复制到你有权限的目标目录 /home/mansoor/backups，并以人类可读形式呈现操作反馈

```
$ rsync -avzh /home/bob/backups /home/mansoor/backups/
```

5. 将单个源目录 /home/bob/backups 及其文件和子目录结构以压缩形式复制到你有权限的目标目录 /home/mansoor/backups

```
$ rsync -zvr /home/bob/backups /home/mansoor/backups
```

6. 执行试运行，在其中删除源文件并压缩传输的文件对象

```
$ rsync --dry-run --remove-source-files -zvh backup.tar /tmp/backups/backup.tar
```

远程示例：

7. 将名为 Music 的单个目录从本地机器复制到远程机器 192.168.0.8 的 mansoor 主目录中

```
$ rsync -avz Music mansoor@192.168.0.8:/home/mansoor/
```

8. 使用 ssh 将整个本地目录名 syncdir2 复制到远程机器 192.168.0.7 并进入 OS X 风格的目录 /Users/b/Linux3e

```
$ rsync -av -e ssh syncdir2 bob@192.168.0.7:/Users/b/Linux3e
```

9. 将远程目录复制到本地目录

```
$ rsync -avzh root@192.168.0.100:/home/bob/backups /home/mansoor/temp
```

10. 仅复制远程目录 /home/mansoor/Linux2e 的内容，使用 --existing 选项更新（有时称为“同步”）仅目标处已存在的文件。如果源有新文件，而目标上没有，则这些新文件不会放到目标上。

```
$ rsync -avz --existing mansoor@192.168.1.2:/home/mansoor/Linux2e/ .
```
