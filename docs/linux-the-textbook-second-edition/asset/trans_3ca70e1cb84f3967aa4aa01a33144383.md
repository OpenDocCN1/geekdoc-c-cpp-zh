## 致教师的话

新版中每一章的教学结构采用两种相似格式之一：Shell 会话格式或教程格式。

在 Shell 会话格式（用于纸质书中的所有章节，第 3、17 和 18 章除外）中，采用以下大纲：

- 学习目标
- 引言
- 按节和子节组织的主题讨论与背景
- 示例命令或主题演示以 Shell 会话形式呈现，用户输入显示的命令并显示结果
- 章内练习，用以巩固某个主题的讨论或 Shell 会话中的交互操作
- 总结
- 章末基础与进阶问题和练习，与所呈现主题对应

在教程格式（用于第 3、17、18 章以及本书网站上的所有章节）中，采用以下大纲：

- 学习目标
- 引言
- 按节和子节组织的主题讨论与背景
- 一个或多个示例会话或练习会话教程，用以说明任何特定节或子节中涉及的命令和主题
- 示例命令或主题演示以 Shell 会话形式呈现，用户输入显示的命令并显示结果
- 章内练习，用以巩固某个示例或练习会话中的讨论、某个主题或 Shell 会话中的交互操作
- 总结
- 章末基础与进阶问题和练习，与所呈现主题对应

## 阅读路径

如果本书用作 Linux 入门课程的主教材，应涵盖第 1–13 章。

如果本书用作操作系统概念与原理课程的配套教材，章节涵盖范围应由课程主要主题的顺序决定，但应包括第 4、9、10、15 和 16 章。

对于 C/C++ 或 Shell 编程课程，第 1 章和第 4–14 章，以及第 3 章和第 W25 章的相关部分对学生大有帮助。第 14 章的涵盖程度取决于课程性质——入门课程部分涵盖，高级课程全面涵盖。此外，根据所使用的文本编辑器，应涵盖第 W25 章的相关部分。

对于 Linux 系统管理课程，应使用第 4–10、17、18、W26 和 W27 章，以及第 11 和 12 章的相关部分。

在系统编程入门课程中，应涵盖第 11、15 和 16 章；第 4–10 章的相关部分；以及第 17、18、W20 和 W21 章。

最后，出于职业发展目的或在非正式学习环境中使用本书的人，可以选择符合自身学习目标的相关章节。例如，任何想学习 git 和 GitHub 基础知识的人都可以使用第 W24 章第 W5.7 节。

## 致学生和读者

最有效地使用本书的方法是边做边学。毕竟，这正是我们提供如此多命令行会话的原因。输入你在这些会话中看到的内容，并与你的 Linux 系统上得到的输出进行比较。

并在你自己的 PC 上安装你所选择的 Linux 系统，希望是从我们在书中演示所用过的系统中选择。然后实验并尝试 Linux。玩耍是学习的基础。
