

系统管理员负责创建用户账户，用户必须拥有账户才能登录并使用Linux系统。所有登录名都是公开信息，可以在 `/etc/passwd` 文件中找到。然而，用户的密码仅对该用户本人可见。这种机制可以防止用户访问彼此的​​文件。系统鼓励用户使用 `passwd` 命令频繁更改密码（参见第2章）。

在某些网络系统中，你可能需要使用 `yppasswd` 或 `nispasswd` 命令来更改你在所有网络计算机系统上的密码。不过，执行这些命令需要超级用户权限（参见5.4.1节）。如果你的Linux系统上没有找到该命令，则需要安装 `nis` 或 `yp-tools` 软件包。请向你的指导老师咨询，了解在特定系统上需要使用哪个命令。通常，只有系统管理员才能更改登录名。在某些Linux安装中，也允许用户更改自己的用户名。

这种保护机制的有效性取决于用户密码的保护程度。如果有人知道你的密码，他就可以登录系统并访问你的文件。发现用户密码的主要方法有以下几种：

- 1. 你作为账户所有者，将密码告知他人。
- 2. 用户使用多种技术猜测（或破解）另一个用户的密码，例如字典攻击、暴力破解、彩虹表攻击和爬虫攻击。
- 3. 使用网络钓鱼获取你的密码。
- 4. 使用社会工程学获取你的密码。
- 5. 使用恶意软件或键盘记录器获取你的密码。

在任何情况下都不要让其他人知道你的密码。作为安全措施，你应该定期更改密码。始终选择难以让他人猜测的密码。一个好的密码是由字母、数字和标点符号混合组成的——但必须便于你记忆。永远不要把密码写在纸上，也不要用生日或亲属、朋友、著名运动员或喜欢的电影演员的名字作为密码。此外，避免使用单词作为密码。密码学家建议，好的密码长度应为20个字符。

你可能希望浏览表5.6（见本书GitHub站点）中给出的网站，以了解更多关于各种黑客攻击或获取他人密码技术的详细信息，包括字典攻击、暴力破解、彩虹表、爬虫、网络钓鱼、恶意软件、键盘记录器和社会工程学攻击。该表还包含一个链接，指向介绍十种最流行的密码破解工具的网站。我们简要描述暴力破解法破解他人密码的方法。字典攻击、彩虹表攻击和爬虫攻击与此类似，但耗时更少。

暴力破解法通过尝试所有可能的字符组合来尝试获知你的密码，直到找到用户密码。猜测某人的密码是一个耗时的过程，通常被黑客使用。如果密码较长并且由字母、数字和标点符号组成，暴力破解法对入侵者来说会变得更加耗时。为了说明使用更复杂密码的重要性，考虑一个系统，其中密码恰好是八个字符，且仅由十进制数字组成。在最坏情况下，暴力破解法最多需要遍历10⁸（1亿）个密码。如果同一系统要求密码由数字和大写字母混合组成（共36个符号：10个数字和26个大写字母），那么密码空间将包含36⁸（约2.8万亿）个密码。如果系统要求密码由数字、大写字母和小写字母混合组成，密码空间将包含62⁸（约218万亿）个密码。想象一下，如果密码还可以包含标点符号，密码空间会有多大！许多系统在输入无效密码后会强制延迟（例如5秒）才显示下一个登录提示，以使入侵者的工作更加困难。

## 5.3 基于加密的保护

在第二种保护机制中，使用软件工具将文件转换为与其原始版本完全不同的形式。转换后的文件称为加密文件，将文件转换为加密文件的过程称为加密。使用相同的工具执行反向过程，将加密文件转换为其原始形式，称为解密。你可以使用此技术保护最重要的文件，即使其他人获得了这些文件，也无法理解其内容。图5.1展示了加密和解密过程。

Linux命令 `mcrypt` 和 `openssl` 可用于加密和解密文件。你可以通过运行 `man mcrypt` 和 `man openssl` 命令来了解更多关于这些命令的信息。我们将在第7章详细讨论这些命令。

## 5.4 基于访问权限的保护

第三种文件保护机制防止用户在未以文件所有者身份登录时访问彼此的​​文件。作为文件所有者，你可以为文件附加某些访问权限，这些权限规定了谁可以或不可以对文件进行各种类型的文件操作。该机制基于Linux下用户的类型、访问权限的类型以及文件上允许的操作类型。如果没有这种保护机制，用户就可以访问彼此的​​文件，因为Linux文件系统结构（见图4.2）有一个单一的根，系统中的所有文件都挂在该根下。在本书中，我们同义使用术语“访问权限”、“访问特权”和“访问权利”。

### 5.4.1 用户的类型

Linux系统中的每个用户都属于一个用户组，这是系统管理员在为用户分配系统账户时指定的。一个用户可以属于多个组，但典型的Linux用户只属于一个组。系统中的所有组及其成员关系都列在 `/etc/group` 文件中（见图4.2）。该文件中每组占一行，行中的最后一个字段包含组成员的登录名。文件的一个用户可以是文件的所有者、与所有者属于同一组的用户，或者拥有系统账户的所有其他人。这分别构成了Linux文件的三种用户类型：用户、组和其他人。作为文件所有者，你可以指定谁可以访问它。文件的组名称为文件的组所有者。

系统中的用户一旦登录，Linux系统通过一个整数来识别他/她，该整数称为用户ID（UID），而不是通过用户的登录名。每个Linux系统都有一个特殊用户，无论文件上的访问权限如何，该用户都可以访问系统上的所有文件。该用户管理（管理）你的Linux系统，通常称为超级用户或系统管理员。超级用户的登录名是 `root`，用户ID为0。

该文件中系统上的每个组对应一行，每行有四个以冒号分隔的字段。第一个字段指定组名，第二个字段指定关于组的一些信息，第三个字段以数字形式指定组ID，最后一个字段指定组内成员的逗号分隔列表。例如，`bin` 组的组ID为2，其成员是用户 `root`、`bin` 和 `daemon`。如果某行中的成员列表缺失（例如 `disk` 组），这意味着其成员关系在 `/etc/passwd` 文件中指定。系统管理员在将用户添加到系统时会将用户分配到某个组。该组称为用户的默认组。用户的默认组成员关系在 `/etc/passwd` 文件的用户条目中指定。系统管理员可以通过将用户名放入组的逗号分隔成员列表中，使用户成为另一个组（除默认组之外）的成员。你可以使用 `groups` 命令显示用户属于系统上的哪些组。以下会话显示 `sarwar` 仅属于 `faculty` 组；`bob` 属于 `adm`、`dialout`、`sambashare` 和 `courses` 组；`davis` 属于两个组：`dialout` 和 `lab`。

```
$ groups sarwar
faculty
$ groups bob
faculty courses
$ groups davis
dialout lab
$
```
