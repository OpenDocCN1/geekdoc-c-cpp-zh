## 1.3 Operating System Services

操作系统为用户提供许多现成的服务。这些服务大多旨在让你高效、安全地运行软件，包括应用程序和程序开发工具。一些服务是为 housekeeping 任务设计的，例如跟踪你使用系统的时间。因此，主要的操作系统服务为以下安全高效的操作和进程提供机制：

- Execution of a program
- Input and output operations performed by programs
- Communication between processes
- Error detection and reporting
- Manipulation of all types of files
- Management of users and security

这些服务的详细讨论超出了本教材的范围，但在相关主题出现时我们会简要讨论它们。

## 1.4 Character (Command Line) versus Graphical User Interfaces

要使用计算机系统，你必须向其操作系统发出命令。输入设备，例如键盘，用于发出命令。如果你使用键盘向操作系统发出命令，则操作系统具有字符用户界面 CUI， commonly known as the command line interface。如果向操作系统发出命令的主要输入设备是指点式设备，例如鼠标、触摸屏或触摸板，则操作系统具有图形用户界面 GUI。大多数，如果不是全部，操作系统都同时具有 CUI 和 GUI，你可以使用其中任何一种。有些以命令行作为主要界面，但允许你同时运行提供 GUI 的软件。诸如 UNIX 和 Linux 的操作系统具有 CUI，而 Mac OSX 和 Microsoft Windows 主要提供 GUI，但具有允许用户在终端屏幕中输入文本的功能。尽管 Linux 以 CUI 作为其基本界面，但它同样可以轻松运行使用 Wayland 提供 GUI 界面的基于 GUI 的软件。我们主要在第 17 章和第 28 章讨论 Linux GUI。

尽管 GUI 使计算机更易于使用，但它提供了一种自动化设置，减少了灵活性。GUI 还在你和想要在计算机上执行任务之间呈现了一层额外的软件，从而使任务变慢。这是因为该 GUI 软件层消耗了显著更大的系统资源来维持其可操作性。相比之下，CUI 为你提供对计算机系统的终极、细粒度控制，并允许你以任何想要的方式运行应用程序。CUI 也更高效，因为你在和计算机任务之间只需要最少的软件层，从而使你能更快完成任务。CUI 软件消耗的系统资源显著更少，以维持其可操作性。它也是可塑的，并给予用户更多控制。由于许多人习惯于流行的小工具和应用程序的图形界面，例如物联网设备、高性能视频游戏和 Web 浏览器，字符界面呈现出一种不熟悉，有时不太直观且难以向计算机系统传达命令的风格。然而，计算机科学学生通常在几次动手练习后就能应对这一挑战。

## 1.5 Types of Operating Systems

操作系统可以根据同时使用系统的用户数量和系统可同时运行的进程数进行分类。这些标准导致了三种类型的操作系统：

- Single-user, single-process system: 这些操作系统一次只允许一个用户使用计算机系统，并且用户一次只能运行一个进程。此类操作系统通常用于 PC。这些操作系统的例子有早期版本的 Mac OS、DOS 以及微软的许多 Windows 操作系统。
- Single-user, multiprocess system: 顾名思义，这些操作系统只允许单个用户使用计算机系统，但用户可以同时运行多个进程。这些操作系统也用于 PC。此类操作系统的例子有 OS/2、Windows XP Workstation 以及批处理操作系统。批处理仍在大型机计算机中常用，并且包括 UNIX、Microsoft Windows 10、Linux 和 Mac OSX 在内的现代操作系统都以批处理模式执行某些任务。甚至智能手机/物联网操作系统，包括 Android 和 iOS，也以批处理模式执行任务。
- Multiuser, multiprocess system: 这些操作系统允许多个用户同时使用计算机系统，并且每个用户可以同时运行多个进程。这些操作系统通常用于支持大学和大型企业等多用户组织的计算机。这些操作系统的例子有 UNIX、Linux、Windows 10 Server、z/OS 和 z/VM。

多用户、多进程系统用于通过复用 CPU 等昂贵资源来提高计算机系统的资源利用率。这种能力导致系统吞吐量增加（单位时间内完成的进程数）。资源利用率提高是因为，在一个具有多个进程的系统中，当一个进程执行输入或输出时（例如从键盘读取输入、捕获鼠标点击事件生成、或向硬盘上的文件写入），CPU 可以从该进程中收回并分配给另一个进程——有效地同时运行这两个进程，让它们都能取得进展[一个执行输入/输出，另一个使用 CPU]。当当前进程执行 I/O 时将 CPU 分配给另一个进程的机制称为多道程序设计。多道程序设计是所有当代多用户、多进程操作系统的关键。在单进程系统中，当使用 CPU 的进程执行 I/O 时，CPU 会处于空闲状态，因为没有其他进程可以在同一时间使用 CPU。

允许用户与正在执行的程序交互的操作系统称为交互式操作系统，而不允许的称为批处理操作系统。批处理系统在无需人工干预即可运行程序时很有用，例如运行工资数据库程序的系统。几乎所有知名当代操作系统（UNIX、Linux、Windows 等）都是交互式的。UNIX 和 Linux 也允许程序以批处理模式执行，程序在后台运行（有关 Linux 中“后台进程执行”的详细信息，请参阅第 10 章）。多用户、多进程和交互式操作系统称为分时系统。在分时系统中，CPU 快速在各个进程之间切换。这种操作方法使系统中的所有进程都能取得进展，给每个用户一种单独使用系统的印象。分时操作系统的例子有 UNIX、Linux 和 Windows 10 Server。
