## Summary

本章是对普通用户而言的 systemd 的综合基础参考和教程。从用户角度来看，我们从上到下说明了 systemd 的结构。我们定义了基本术语 unit 和 target。然后我们通过许多示例介绍了其最重要的命令 systemctl。最后，我们给出了应用这些命令的扩展且典型的用例。我们以一个基本的 Web 服务器程序作为 systemd 管理服务的示例。我们使用许多基于文本的命令涵盖了以下 systemd 主题：

- System start-up, initialization, and shutdown
- Units and unit files, with an emphasis on service unit files
- Target unit files, and their purposes and uses
- System service management basics and the systemctl command
- Other important user commands, for example, the journalctl command
- Creating, adding, and controlling a new systemd service from scratch

此外，我们将 systemd 定义为一个结合了 Linux 初始化程序和服务管理器的程序，它还包含并实现了许多其他重要的系统状态控制程序和实用工具。

我们建议 systemd 不仅是一个初始化程序和服务管理器，而且还是一个“超级内核”，它使用 Linux 内核本身作为从属程序。Linux 内核在某种抽象级别上，维护了计算机的硬件和软件组件的稳定状态

供 systemd 使用。扩展该抽象，systemd 监督并管理内核所做的一切，以优化该稳定状态条件下的操作，无论是启动、进程控制和 IPC、硬件服务、网络操作、关机，还是许多其他设施。

我们通过一些扩展示例结束了本章，展示了普通用户如何添加和控制新的 systemd 服务。
