

shell 提供一个良好的工作环境。用户定义的变量用作脚本中的临时存储区以完成手头的任务。某些环境变量如位置参数是只读的，因为你不能在不使用 set 命令的情况下更改其值。用户定义的变量也可以通过使用 readonly 命令使其变为只读。

处理 shell 变量的 Bash 命令有 =（为变量赋值）、set（设置位置参数的值并显示所有环境变量的值）、env（显示所有 shell 变量的值）、export（允许后续命令访问 shell 变量）、read（从键盘为变量赋值）、readonly（使用户定义的变量只读）、shift（将命令行参数向左移动一个或多个位置）、unset（将读写变量的值重置为空）、以及 test（评估表达式并返回 true 或 false）。

程序控制流语句 if 和 case 允许 shell 脚本的程序员实现多路分支；for、until 和 while 语句允许程序员实现循环；而 break 和 continue 语句允许用户中断脚本中循环的顺序执行。输入/输出重定向、命令替换和其他 shell 功能可以与控制流语句一起使用，就像与其他 shell 命令一样（参见第 13 章）。

Bash 有许多用于文件、整数和字符串测试的运算符。它还有许多逻辑和位运算符，以及用于使用 ;、() 和 {} 依次单独和作为组执行命令的运算符。Bash 还有 & 运算符用于后台和并行执行命令。运算符 && 和 || 可分别用于执行逻辑 AND 和 OR 操作。使用这些运算符会使代码更简洁、更紧凑。使用 ;、() 和 {} 有助于按顺序依次执行一组命令。运算符 &、| 和 ^ 可用于执行位 AND、OR 和 XOR 操作。
