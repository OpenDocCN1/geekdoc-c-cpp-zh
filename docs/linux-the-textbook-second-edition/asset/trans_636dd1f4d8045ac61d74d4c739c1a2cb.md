## 6.4 Appending to Files

向文件追加意味着在文件内容末尾添加新数据。如果文件不存在，则创建它以包含新数据。追加操作在应用程序或用户需要通过向其中添加数据来扩充文件时很有用。以下命令语法用于将一个或多个文件或键盘输入追加到文件末尾。

```
Syntax:
  cat [file-list] >> destination-file
Purpose: Append the contents of the files in file-list, in the order specified in the command line, at the end of destination-file
```

>> 操作符是 Linux 追加操作符。我们将在第 9 章详细讨论 >>、< 和 > 操作符。该章节描述了如何使你的命令的输入从文件而不是键盘读取，以及如何将你的命令的输出和错误消息从终端（或控制台窗口）重定向到文件。在本章中，我们仅使用这些操作符来描述如何将新数据追加到文件当前内容的末尾，以及如何使用 cat 命令组合多个文件的内容并将它们放入一个文件中。

以下会话说明了追加操作的工作方式。cat sample >> temp 命令将 sample 文件的内容追加到 temp 文件的末尾。命令在该命令之前和之后显示了所涉及文件的内容。命令语法可用于将多个文件追加到一个文件，如命令 cat memo1 memo2 memo3 >> memos.record 所示。该命令将 memo1、memo2 和 memo3 文件的内容追加到 memos.record 文件的末尾。

```
$ cat temp
This is a simple file used to illustrate the working of append operation. The new data will be appended right below this line.
$ cat sample
These are the new data that will be appended at the end of the test file.
$ cat sample >> temp
$ cat temp
This is a simple file used to illustrate the working of append operation. The new data will be appended right below this line.
These are the new data that will be appended at the end of the test file.
$ cat memo1 memo2 memo3 >> memos.record
$
```

如果没有可选的 file-list 参数（参见命令描述），该命令可用于将键盘输入追加到 destination-file 的末尾。cat >> test.letter 命令从键盘读取输入并将其追加到名为 test.letter 的文件。当你在新行按下 <Ctrl+D> 时，命令终止。

```
$ cat test.letter
John Doe
12345 First Lane
Second City, State 98765
$ cat >> test.letter
September 1, 2017
Dear John:
This is to inform you ...
...
<Ctrl+D>
$ cat test.letter
John Doe
12345 First Lane
Second City, State 98765
September 1, 2017
Dear John:
This is to inform you ...
...
$
```

## 6.5 Combining Files

以下命令语法可用于将多个文件组合成一个文件。

Syntax:
cat [file-list] > destination-file
Purpose: Put the contents of the files in file-list, in the order specified in the command line, and put them in destination-file

如果 destination-file 已存在，则会被覆盖。如果您没有 destination-file 的写权限，命令会显示错误消息，告知您没有权限写入该文件。如果没有可选的 file-list 参数，您可以使用该命令将键盘输入放入 destination-file。因此，该命令语法可用于创建新文件，其内容是你从键盘输入的内容，直到你在新行按下 <Ctrl+D> 为止，就像前一会话中 cat >> test.letter 命令的情况一样。

以下会话说明了该命令带参数的工作方式。ls -l 命令用于查看文件的权限。wc memo? 命令显示当前目录中以字符串 memo 开头并在其后有一个字符的所有文件的大小。第三个命令组合 memo1、memo2 和 memo3 文件的内容并按它们在命令中出现的顺序放入 memos.y2k18 文件中。wc memos.y2k18 命令用于确认 memos.y2k18 文件的行数、词数和字符数与三个 memo 文件合并后的数量相同。执行 cat memo1 memo2 memo3 > memos.2018 命令显示您没有权限写入 memos.2018。

```
$ ls -l
-r-xr--r-- 1 sarwar faculty 1687 Jan 10 19:15 memo1
```

## Syntax:

```
diff [options] [file1] [file2]
```

## Purpose:

逐行比较 file1 与 file2 并以可用于将 file1 转换为 file2 或反之的 ed 编辑器命令/指令系列的形式显示它们之间的差异；如果对 file1 或 file2 使用 – 则从标准输入读取

## Commonly used options/features:

- **-b** 忽略行尾的空白（空格和制表符），并将其他空白串视为相等
- **-e** 生成并显示可执行以将 file1 改为 file2 的 ed 编辑器脚本
- **-h** 快速比较（此时不能使用 -e 选项）

file1 和 file2 参数可以是目录。如果 file1 是目录，diff 会在其中搜索名为 file2 的文件并将其与 file2（第二个参数）进行比较。如果 file2 是目录，diff 会在其中搜索名为 file1 的文件并将其与 file1（第一个参数）进行比较。如果两个参数都是目录，命令会比较这两个目录中具有相同名称的所有文件对。

如果正在比较的文件相同，diff 命令不会产生任何输出。在没有选项使用时，diff 命令会产生可用于将 file1 转换为 file2 的 ed 编辑器指令系列，如果文件不同。指令为 a（添加）、c（更改）和 d（删除），并在表 6.1 中描述。

以下会话说明了 diff 命令的简单用法。

```
$ cat Fall_OH
Office Hours for Fall 2017
Monday
9:00 - 10:00 A.M.
3:00 - 4:00 P.M.
Tuesday
10:00 - 11:00 A.M.
Wednesday
9:00 - 10:00 A.M.
3:00 - 4:00 P.M.
Thursday
11:00 A.M. - 12:00 P.M.
2:00 - 3:00 P.M.
4:00 - 4:30 P.M.
```

指令 1c1 要求 ed 编辑器将 Fall_OH 文件中的第一行（Office Hours for Fall 2017）更改为 Spring_OH 文件中的第一行（Office Hours for Spring 2018）。6a7 指令要求 ed 编辑器在 Fall_OH 的第 6 行后追加 Spring_OH 的第 7 行。12,13d11 指令要求 ed 编辑器从 Fall_OH 中删除第 12 行和第 13 行。

以下会话说明了使用 -e 选项与 diff 命令以及如何将该命令的输出提供给 ed 编辑器以使 Fall_OH 与 Spring_OH 相同。该命令用于向您展示命令输出的样子。第二个 diff 命令（使用 > diff.script）用于将命令输出（ed 脚本）保存到 diff.script 文件中。cat >> diff.script 命令用于通过添加包含 w 和 q 的两行将 diff.script 文件转换为完整的 ed 编辑器工作脚本。正如之前所述，该命令以 <Ctrl+D> 终止。最后，运行 ed 命令根据 diff -e 命令生成的脚本更改 Fall_OH 的内容，使其与 Spring_OH 相同。209 和 177 显示了 ed 命令执行前后 Fall_OH 文件的大小。最后的命令 diff Fall_OH Spring_OH 用于确认两个文件相同。
