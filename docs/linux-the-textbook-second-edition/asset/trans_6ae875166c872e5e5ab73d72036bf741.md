## 17.3 用户管理

用户管理的两个最重要目标是服务和安全。首先是提供服务，确保用户群体能够访问并充分利用现代 Linux 系统所能提供的资源。其次是保护用户群体在利用这些资源时所需的文件和进程。在本章稍后部分，我们将会介绍系统管理员可以部署的一些安全方法，以确保系统安全。在本书网站的 “第 W23 章：虚拟化方法” 中，我们还展示了利用各种虚拟化技术（如 LXC/LXD 容器和 VirtualBox 虚拟机）的安全方法。

Linux 为用户提供服务和安全的传统技术是通过访问权限来实现的，即针对系统中的特定对象（如文件），分别授予单个用户、用户组或系统内所有其他用户相应的访问权限。我们将在第 5 章第 4 节和第 5 节中展示如何设置文件的访问权限。设计并实现用户组以及用户组的访问权限是该技术中最重要的部分。

当然，用户帐户和组的创建与配置是为用户群体提供最大服务和安全的第一个步骤。即使你是系统的唯一用户，也是如此。

设计用户帐户和组的一个非常核心的组成部分是仔细考虑我们在第 17.2.1 节第 (1) 项中推荐的用户数据存储模型。这可以通过将用户文件保存在第二块（可能是冗余的）硬盘驱动器上来实现，从而使这些文件与操作系统引导磁盘本身分开。实际做法是正确地创建用户帐户，使其主目录位于该第二块硬盘上。正如我们在第 17.4 节中所示，有各种方法可以非常轻松且有效地实现冗余持久介质的添加，从而落实上述模型。特别是，第 17.3.4 节提供了一种通用方法，说明如何按照该模型进行用户帐户和组的创建与管理。

我们这里重点讨论如何使用 `adduser`、`addgroup`、`deluser`、`delgroup`、`newusers` 和 `passwd` 命令来管理 Linux 上的用户帐户和组。这些操作通常是在 Linux 系统初始安装后相当长一段时间才进行的，但也可以在系统安装和初始化期间进行。表 17.2 简要描述了这些命令：

### 17.3.1 在 Linux 基于文本的界面中添加用户和组

`adduser` 和 `addgroup` 命令默认使用命令行选项和选项参数，向系统添加一个 “普通”（非系统级）用户或组。它们从 `/etc/adduser.conf` 获取默认配置信息。它们是较老的低级命令（如 `useradd`、`groupadd` 和 `usermod`）的更完善的前端。`adduser` 使用专利的用户 ID（UID）和组 ID（GID）值来创建新帐户和组，并默认根据骨架配置文件创建主目录，等等。

`adduser` 本身是一个脚本文件，它与以下命令及其功能交互：

```
useradd, groupadd, passwd, gpasswd, usermod, chfn, chage, edquota.
```

以下是 `adduser` 和 `addgroup` 命令语法的简要列表：

**adduser、addgroup** - 向系统添加用户或组

```
语法：
adduser [选项] [--home DIR] [--shell SHELL] [--no-create-home] [--uid ID] [--firstuid ID] [--lastuid ID] [--ingroup GROUP | --gid ID] [--disabled-password] [--disabled-login] [--gecos GECOS] [--add_extra_groups] [--encrypt-home] user

adduser --system [选项] [--home DIR] [--shell SHELL] [--no-create-home] [--uid ID] [--group | --ingroup GROUP | --gid ID] [--disabled-password] [--disabled-login] [--gecos GECOS] user

addgroup [选项] [--gid ID] group

addgroup --system [选项] [--gid ID] group

adduser [选项] user group
```

**用途：** `adduser` 和 `addgroup` 根据命令行选项以及 `/etc/adduser.conf` 中的配置信息向系统添加用户和组。它们是比 `useradd`、`groupadd` 和 `usermod` 等低级工具更友好的前端，默认会选择符合 Debian 策略的 UID 和 GID 值，创建带有骨架配置的主目录，运行自定义脚本，以及其他功能。`adduser` 和 `addgroup` 可以以五种模式之一运行。

**输出：** 新建或修改的用户帐户或组

**常用选项/功能：**
- [--quiet]
- [--debug]
- [--force-badname]
- [--help|-h]
- [--version]
- [--conf FILE]

以超级用户身份使用 `adduser` 命令的基本简单用法会执行以下五件事：

```
$ sudo adduser username
```
- 1. 创建名为 username 的用户。
- 2. 创建该用户的主目录（默认为 /home/username），并将 /etc/skel 中的文件复制到其中。
- 3. 创建一个与用户同名的组，并将该用户放入其中。
- 4. 提示输入该用户的密码（默认不在屏幕上显示）及其确认。
- 5. 提示输入该用户的个人信息，如电话号码、办公室联系方式等。

第二个示例使用了 `newusers` 命令，该命令允许以 “批处理” 模式创建新用户，并配合一个包含多个用户帐户列表的文件，这些帐户可以一次性全部添加。

`newusers` 命令的简要描述如下：

newusers——以批处理模式更新和创建新用户

语法：
    newusers [选项] [file]
用途：`newusers` 命令读取一个文件（或默认为标准输入），并使用这些信息来更新一组现有用户或创建新用户。每行的格式与标准密码文件相同，如下所示：
pw_name:pw_passwd:pw_uid:pw_gid:pw_gecos:pw_dir:pw_shell
