The ls -il command shows some of the attributes of all the files in the present working directory, including their inode numbers. The command ln Chapter3 Chapter3.hard creates a hard link to the file Chapter3; the name of the hard link is Chapter3.hard. The system creates a new directory entry (16518417, Chapter3.hard) for Chapter3 in the present working directory. Thus, you can refer to Chapter3 by accessing Chapter3.hard as well, because both names point to the same file on disk.
