为了执行外部二进制命令，需要一种机制使子进程成为要执行的命令。Linux 系统调用 exec() 可以做到这一点，允许一个进程用另一个命令的可执行代码覆盖自身。Shell 使用 fork() 和 exec() 调用协同执行外部二进制命令。图 10.3 显示了执行外部命令 sort 的事件序列，其代码位于二进制文件 /usr/bin/sort 中。

Shell 脚本（文件中的一系列 shell 命令；参见第 12 章和第 13 章）的执行与二进制命令/文件的执行略有不同。在 shell 脚本的情况下，当前 shell 创建一个子 shell 并让子 shell 按顺序在脚本文件中执行命令。脚本文件中的每个命令都以与从键盘输入命令相同的方式执行；也就是说，子 shell 为其执行的每个命令创建一个子进程。在子 shell 在脚本文件中执行命令时，父 shell 等待子进程终止。当子 shell 遇到脚本文件中的 eof 标记时，它终止。与任何其他 shell 一样，子 shell 的唯一目的是执行命令，而 eof 表示“没有更多命令”。当子 shell 终止时，父 shell 脱离等待状态并恢复执行。此事件序列如图 10.4 所示，该图还显示了脚本文件中 find 命令的执行。

除非脚本文件中的文件另有规定，否则子 shell 的类型与父 shell 相同。也就是说，如果父 shell 是 Bash，则子 shell 也是 Bash。因此，默认情况下 shell 脚本由父 shell 的“副本”执行。但是，为任何 shell 编写的 shell 脚本（C、TC、Bourne、Bash、Korn 等）都可以执行，而不论当前 shell 的类型如何。为此，只需在包含 shell 脚本的文件的第一行指定要在其下执行脚本的子 shell 的类型作为 #!full-path-name-of-the-shell。例如，以下行规定子 shell 为 Bash，因此此行之后的脚本在 Bash 下执行。

```
#!/bin/bash
```

此外，你可以通过运行该 shell 作为当前 shell 的子进程、在其下执行命令并终止该 shell 来在另一个 shell 中执行命令。子 shell 也称为子 shell。请记住，运行各种 shell 的命令为 sh 表示 Bourne shell，csh 表示 C shell，tcsh 表示 TC

## 10.5 进程属性

每个 Linux 进程都有多个属性，包括所有者 ID（在 Linux 术语中称为用户 ID [UID]）、进程 ID（PID）、父进程的 PID（PPID）、进程名称、进程状态、启动进程所执行的命令、进程优先级、进程启动时间、进程消耗的 CPU 时间百分比、进程消耗的主内存百分比、进程在虚拟内存中的大小、进程当前在主内存中的大小、进程状态、进程等待的事件（如果未运行），以及进程已运行的时间长度。从用户和程序员的角度来看，这些属性中最有用的是 PID，它用作本章后面讨论的多个进程控制命令的参数。

Linux 提供了多个工具，允许你监控当前在系统上运行的进程的属性、更改你的进程的状态并对其执行各种操作，包括停止/重新启动它们、向它们发送特定消息、使它们相互通信以及终止它们。在本章中，我们将讨论一些命令和工具，这些命令和工具允许我们静态和动态地监控进程的属性，以及执行上面提到的各种进程操作。

### 10.5.1 进程属性的静态显示

ps 命令可用于查看系统中当前进程的属性的快照。以下是 ps 命令的简要说明，其中包含 Berkeley Software Distribution（BSD）风格选项（在命令行上不带破折号执行）和 UNIX/POSIX 风格选项（在命令行上带破折号执行）的选项/功能变体。

```
Syntax:
  ps [options]
Purpose: Report static (one shot) information about process status/attributes
Output: A header line and a snapshot of the attributes of processes running on the system.
  Note: Gnu long options are preceded by two dashes.
Commonly used options/features (BSD variants without a preceding dash):
  o    Display information about the comma- or space-separated keywords after the PID field in the default output. You can assign the header of your choice for a keyword by putting an = after the keyword, followed by the header value.
```

- u Display information about the processes for the users specified in the comma-separated list of usernames; no spaces before or after the commas
- a Lift the BSD-style “only yourself” restriction
- e Display the environmental information for each process
- o Similar to -o, except that it does not show the default fields and you can change header texts for multiple using multiple -o options. If no headers are specified with keywords, the header line is not displayed.
- u Display for each process information about the following keywords: user, pid, %cpu, %mem, vsz, rss, tty, state, start, time, and command.
- x Display information about processes that do not have controlling terminals (including daemons)

# 常用选项/功能（带前导破折号的 UNIX/POSIX 变体）：

- -A Select all processes
- -e Same as the -A option: display information about all processes, including session leaders
- -f Display a full format listing, including process owner ID (UID), PID, PPID, C, process start time (STIME), TTY, time executed for (TIME), full command line (CMD)
- -l Display a long listing: F, state (S), UID, PID, PPID, C, PRI, NI, ADDR, SZ, WCHAN, TTY, TIME, CMD
- -u or -U Display a list of processes belonging to UIDs or lognames listed in the comma-separated list

ps 命令的输出首先按进程关联的终端排序，然后按其 PID 排序。你可以使用不同的选项更改默认排序顺序。如果指定了多个此类选项，命令将执行最后一个选项。本节中的 shell 会话演示了使用 ps 命令带选项和不带选项的情况。我们都在运行 Bash shell 的 Linux 机器上运行了它们。

如以下会话所示，ps 命令的输出显示了进程的四个字段，其属性每行显示一个：PID、进程附加到的终端（TTY）、进程已消耗的 CPU 时间（TIME）以及用户用于运行进程的命令（CMD）。输出显示有两个进程附加到终端 0：bash（登录 Bash）和 ps。附加到终端 0 的进程 -bash 和 ps 的 PID 分别为 27753 和 27783，并且各自运行了 0 秒。

```
$ ps
PID TTY          TIME CMD
27753 pts/0    00:00:00 bash
27783 pts/0    00:00:00 ps
$
```

```
$ ps -o pid,tty,stat,time,cmd

27753 pts/0  Ss   00:00:00 -bash
```
