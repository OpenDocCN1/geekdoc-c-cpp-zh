## 15.9.2 使用系统调用填充 stat 结构

你可以使用三个系统调用中的任何一个来用文件的属性填充 stat 结构：stat()、lstat() 和 fstat()。以下是这些调用的简要描述。

```
#include <sys/types.h>
#include <sys/stat.h>
int stat(const char *path, struct stat *sb);
int lstat(const char *path, struct stat *sb);
int fstat(int fd, struct stat *sb);

Success: 0
Failure: -1 and kernel variable errno set to indicate the type of error
```

stat() 系统调用读取 path 参数指定的文件的信息并将其存储在 sb 指向的 stat 结构（struct stat）中。path 变量中的所有组件都必须是可搜索的（即必须具有执行权限）。命名文件的访问权限无关紧要，因为此调用不处理文件的内容。如果命名文件是符号链接，stat() 系统调用将返回链接指向的文件的信息。

lstat() 系统调用的工作方式与 stat() 系统调用类似，只是如果命名文件是符号链接，则调用返回有关链接文件本身的信息，而不是其指向的位置。fstat() 系统调用返回有关打开文件的信息。

## 15.9.3 显示文件属性

一旦你使用上述系统调用之一获取文件属性并将其存储在 struct stat 类型的变量中，你就可以使用标准 I/O 输出函数（如 printf() 和 sprintf()）来显示它们。例如，下面讨论的 stat.c 程序读取 sv 变量（struct stat 类型）的属性，该文件作为命令行参数传递。然后如果它是普通文件，它会显示文件的大小（以字节为单位）。否则，它会使用库调用 perror() 显示错误消息，stat: Success。

```
$ cat stat.c
#include <sys/stat.h>
#include <sys/types.h>

int main(int argc, char *argv[])
{
    struct stat sv;

    if (argc != 2) {
        printf("Inappropriate number of command line arguments.\n");
        exit(0);
    }
    if (stat(argv[1], &sv) == 0 && S_ISREG(sv.st_mode))
        printf("File size is %d bytes\n", sv.st_size);
    else
        perror("stat");
}
$ gcc stat.c -w
$ a.out stat.c
File size is 368 bytes
$ ls -l stat.c
-rw-r--r-- 1 sarwar faculty 368 Oct 22 21:56 stat.c
$ a.out ~
stat: Success
$ a.out /usr
stat: Success
$
```

## 总结

Linux 为软件开发提供了两个 API：语言库和 SCI。应用程序程序员通常使用语言库提供的接口，而系统程序员主要使用 SCI。我们描述了 Linux 系统调用及其在文件数据和属性 I/O 的小型程序中的使用。我们的重点是普通文件。

在讨论系统调用之前，我们解释了四种导致控制转移到内核代码的事件。它们是中断、陷阱、信号和系统调用，其中前两个由系统硬件引起，后两个主要由软件引起。我们还讨论了执行系统调用时发生的事件的细节。我们简要讨论了 CSL 以及通过 fopen()、fread()、fwrite() 和 fclose() 的标准 I/O 与通过系统调用使用 open()、read()、write() 和 close() 的低级 I/O 之间的区别。

我们讨论了用于普通文件的数据 I/O 和文件属性 I/O 的系统调用，包括 open()、creat()、read()、write()、close()、truncate() 和 stat() 系统调用。对于随机 I/O，我们使用 lseek() 系统调用将文件指针设置为下一个读或写操作应执行的字节。我们展示了 lseek() 和 write() 系统调用的使用，以说明如何在 Linux 下的普通文件中创建空洞。我们通过使用 od 命令显示其八进制转储来展示文件中创建的空洞。
