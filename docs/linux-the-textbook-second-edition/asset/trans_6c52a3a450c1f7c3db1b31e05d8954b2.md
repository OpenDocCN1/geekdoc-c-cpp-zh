## 17.10.1 虚拟化应用

在系统管理背景下，LXC/LXD 容器和 VirtualBox 的重要应用是提供系统安全性的<|message|>。例如，使用这两种工具都可以将系统服务或应用程序程序隔离在与主机操作系统完全自主的访客操作系统环境中。可以将诸如安全外壳 (SSH) 服务器之类的服务运行在 LXC/LXD 容器实例中，或 VirtualBox 访客中，任何侵入该服务器及其系统空间的行为都不会侵入主机操作系统空间。如果服务器的 LAN 或 Internet 流量在任何方面受到损害，服务器可以停止、重新启动，甚至被删除，而不会影响主机操作系统。另一个例子是，如果在 LXC/LXD 容器实例或 VirtualBox 访客环境中运行一个有缺陷、漏洞百出的应用程序程序，它可能会使访客操作系统内核停止，而不会以任何方式影响主机操作系统。这两个示例案例可能是维护虚拟环境最有用的方面，但还有其他方面。

此外，这些方法还有另一个应用，即允许您在单台硬件上使用和尝试不同的操作系统。您可以在与主机系统隔离的“沙箱”中操作这些其他操作系统，同时可以同时访问主机系统和虚拟化环境。

我们强调“同时”这个词，因为可以在一台计算机上创建不同的启动环境并依次启动到这些环境中，但不能同时启动。

我们鼓励您阅读本书网站第 W23 章“虚拟化方法”中展示的所有示例，以更好地了解 Linux 中目前存在的虚拟化方法。
