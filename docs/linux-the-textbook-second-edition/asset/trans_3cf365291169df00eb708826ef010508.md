

进程可以采取默认（由内核定义）的动作、用户定义的动作，或者忽略该信号。没有任何进程可以忽略 `kill -9` 命令——这个由 Linux 设计者设置的必杀信号，用于确保系统上运行的每个进程都能被终止。使用 `nohup` 命令执行的命令即使在用户注销后也会继续运行。`kill -9 0` 命令可以可靠地终止与用户当前登录相关的所有进程。

当你启动 Linux 系统时，引导和启动操作会开始将计算机带入你通常期望的工作状态。当 Linux 内核在启动阶段接管时，systemd 超级守护进程是第一个被启动的用户态进程。`agetty` 程序处理控制台或终端连接，使你能够与系统进行交互。

在运行 Bash 的系统上，你可以使用 `pstree` 命令来显示你自己或其他用户的进程的树形结构。使用 `-a` 选项时，显示的输出包含一行关于“祖父级”systemd 进程的信息。`ps -auxf d` 命令显示系统上所有进程的完整层次结构，而 `ps -d` 命令显示特定用户的进程层次结构。

内核空间与用户空间之间可能进行的用户交互的一个关键组成部分是 `/proc` 文件系统，通常简称为 proc。我们简要概述了 proc，并展示了理解它如何帮助你评估 Linux 内核及其组件在你的计算机上管理的任务。

我们提供了一些比较，使你在 Linux 任务的背景下，能够了解进程与线程之间（如果存在）的区别。其中若干比较结果交叉引用了本章中的各节，以及本书中的其他章节和节。
