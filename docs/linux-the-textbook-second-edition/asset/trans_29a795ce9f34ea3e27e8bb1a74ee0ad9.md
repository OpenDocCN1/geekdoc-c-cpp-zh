## 17.6 文件系统备份策略与技术

在单用户 Linux 系统上，将用户文件和系统文件备份作为普通用户日常操作的一部分，其必要性是显而易见的。同样，对于复杂的多用户系统，对于任何负责系统管理的人来说，这也是必要的步骤。

根据 Linux 系统专业人士的说法，作为系统管理员，在备份系统时必须考虑一组易于记忆且重要的要点。这组要点可以用简单的疑问句形式表示为：如何（How）、什么（What）、为什么（Why）、何时（When）、何地（Where）和何人（Who）？其中一些简单问题的答案可以相互衔接，下面我们提供一份精选的示例答案列表：

- “How（如何）”最重要的意思是指使用什么命令、实用程序、应用程序或软硬件组合来完成备份和归档。这些工具将在后面的小节中介绍。它还意味着采用各种策略，以增量方式、滚动方式或完全跨越整个文件系统结构进行备份。

- “What（什么）”指的是备份哪些内容：可能只是部分用户文件和用户账户文件，也可能是全部文件，或仅某些类型的文档，整个磁盘驱动器，多个磁盘驱动器，系统文件（全部或选定的子集），等等。

- “Why（为什么）”指的是确定你所备份“什么”的相对重要性。

- “When（何时）”指的是每小时、每天一次、每周一次、每月一次，还是每次保存某个特定文件时进行备份，以及具体在什么时间，比如凌晨 3 点。

- “Where（何地）”指的是备份到本地磁盘、Dropbox/Google/Amazon 云存储、手动备份到 USB 闪存盘、通过 cron 自动备份到家庭网络中的另一台计算机或网络附加存储（NAS）、手动、完全或增量地备份到另一块硬盘，以及备份到各种级别的 RAID，或上述方式的任何变体和组合。

- “Who（何人）”指的是由系统上唯一的用户执行，由发起者或执行者执行，例如由 cron 自动执行，由指定的系统管理员手动或半自动执行，或由 Dropbox、Google 或 Amazon 的自动化流程执行。

### 17.6.2 Linux GNU tar

Linux 操作系统提供了多种实用程序，可以将文件和目录归档到单个文件中，而 tar 命令是最流行、使用最广泛且最传统的方法。

| 备份工具 | 说明 |
|---|---|
| tar | 将一个文件或目录层级结构打包为普通磁盘文件以进行备份、归档或移动到其他位置或系统的命令和选项。gtar 是 GNU 版本 |
| cpio | 不如 tar 流行，但功能基本相同 |

Linux 上现代的 tar 是 GNU 版本。

tar（tape archive 的缩写）实用程序最初设计用于将文件系统保存到磁带中作为备份，以便在系统崩溃时能够恢复文件。现在它主要用于将目录层级结构打包为普通磁盘文件。然后，该磁盘文件可以保存在本地或远程用于系统备份，或通过互联网传输给他人。它通常还通过命令行选项与压缩实用程序（如 gzip）一起使用。这样可以节省磁盘空间和传输时间。磁盘空间的节省主要源于集群内的空白空间不会被浪费。以下是 tar 实用程序的简要说明。

GNU 版本的 tar 具有一些重要的功能特性，并且语法比传统的 UNIX tar 更友好。因此，对于初学者，我们只展示 GNU 风格语法的“长格式”，因为它更直观且易于理解。当你对 tar 更加熟悉后，可以自行选择切换到 UNIX 风格的短格式。

系统管理员通常使用经济高效的归档介质来归档完整的文件系统结构作为备份，这样当系统因某种原因崩溃时，文件可以恢复。基于 Linux 的计算机系统通常因操作系统无法控制的原因而崩溃，例如电涌导致的磁盘磁头损坏。Linux 很少导致系统崩溃，因为它是一个设计、编码和测试都很完善的操作系统。在典型的安装中，备份会在每天的非工作时间（深夜或清晨）系统通常不使用时进行。

tar 命令的一般语法如下所示，此处使用 GNU 风格语法，而非传统 UNIX 风格语法：

**tar**

- **语法：** `tar [operation mode] [operation mode options] [FILE...]`
- **用途：** 将文件归档（以特定格式复制）到归档介质（可以是普通文件），或从归档介质恢复文件。目录默认递归归档和恢复
- **输出：** 已归档或已恢复的文件或目录结构

**GNU 风格用法中的主要操作和操作选项：**

- `--append` — 将文件追加到归档末尾
- `--concatenate` — 将一个归档追加到另一个归档的末尾
- `--compare` — 查找归档与文件系统之间的差异
- `--create` — 创建新磁带并在其上记录归档文件
- `--delete` — 从归档中删除
- `--extract` — 从归档中提取文件
- `--help` — 显示简短的选项摘要
- `--list` — 列出归档的内容
- `--show-defaults` — 显示选项的内置默认值
- `--test-label` — 测试归档卷标然后退出
- `--update` — 追加比归档中版本更新的文件
- `--usage` — 显示可用选项列表
- `--version` — 显示程序版本和版权信息

**常用选项：**

- `--preserve-permissions` — 提取有关传统文件权限的信息
- `--acls` — 启用 POSIX.1e ACL 支持
- `--gzip` — 通过 gzip 过滤归档
- `--verbose` — 详细列出已处理的文件
- `--file ARCHIVE.tar` — 将归档发送到名为 ARCHIVE.tar 的文件中
