

grep 工具最常见且简单的用法是显示文件中包含特定字符串、单词或模式的行。在下面的会话中，我们显示 students 文件中包含字符串 Sarwar 的那些行。行按在文件中出现的顺序显示。

```
$ grep Sarwar students
Hassaan Sarwar    hsarwar@k12.st.or        503.444.2132
Ibraheem Sarwar   ibraheem@abc.sci.com     222.123.4567
Maham Sarwar      smsarwar@k12.st.or       713.888.0000
Nabeel Sarwar     n.sarwar@xyz.net         434.555.1212
$
```

grep 命令可以用 -n 选项来显示带有行号的输出行。在下面的会话中，students 文件中包含字符串 John 的行会连同行号一起显示。

```
$ grep -n John students
1: John Johnsen    john.johnsen@tp.com      503.555.1111
4: John Johnsen    j.johnsen@psu.net        301.999.8888
$
```

你可以使用 grep 命令结合正则表达式和 shell 元字符在多个文件中搜索字符串。在下面的会话中，grep 在当前工作目录下以 .c 结尾的所有文件（C 源码文件）中搜索字符串 “include”。请注意，server.c 的访问权限已被设置，因此 grep 无法读取它；运行该命令的用户没有 server.c 文件的读取权限。

```
$ grep -n include *.c
client.c: 21: #include <stdio.h>
client.c: 22: #include <ctype.h>
client.c: 23: #include <string.h>
labl.c:  13: #include <stdio.h>
grep: can’t open server.c
$
```

你也可以使用 grep 命令的 -l 选项来显示模式出现的文件名。但是，它不会显示包含该模式的行。在下面的会话中，假设 ~/States 目录包含每个美国州的一个文件，并且该文件假设包含该州所有城市的名称（例如，Portland）。因此，grep 命令会显示包含单词 “Portland” 的文件名称——即拥有名为 Portland 的城市的州的名称。

```
$ grep -l Portland ~/States
Maine
Oregon
$
```

某些字符对 shell 和 grep 来说都是特殊字符。因此，为了确保 shell 将期望的正则表达式传递给 grep，你需要用单引号或双引号将正则表达式括起来。你可以使用反斜杠 (`\`) 来引用一个字符，除非该字符是换行符 (`\n`)。单引号 (`'`) 会引用除它本身之外的所有字符。双引号 (`"`) 会引用除 `"`, `$`, `` ` `` 或 `\` 之外的所有字符。因此，你可以在任何使用用 `"` 括起来的正则表达式的命令中用 `'` 替换 `"`，命令仍会工作，但反之则不行。在下面的会话中，我们可以互换使用单引号和双引号。用单引号和双引号括起来的表达式也会原样传递给 grep 和 egrep。

以下命令显示 students 文件中以字母 A 到 H 开头的行。在该命令中，^ 指定行的开头。

```
$ grep '^[A-H]' students
Hassaan Sarwar    hsarwar@k12.st.or    503.444.2132
David Kendall     d_kendall@msnbc.org  229.111.2013
$
```

以下命令显示 students 文件中包含八个连续小写字母的行。

```
$ grep '[a-z]\{8\}' students
Ibraheem Sarwar   ibraheem@abc.sci.com  222.123.4567
Maham Sarwar      smsarwar@k12.st.or   713.888.0000
Jamie Davidson    j.davidson@uet.edu    515.001.1212
$
```

以下命令显示 students 文件中以五个连续小写或大写字母后跟一个空格字符开头的行。

```
$ grep '^[A-Za-z]\{5\} ' students
David Kendall     d_kendall@msnbc.org   229.111.2013
Kelly Kimberly    kellyk@umich.gov      555.123.9999
Maham Sarwar      smsarwar@k12.st.or    713.888.0000
Jamie Davidson    j.davidson@uet.edu    515.001.1212
Sandy Khan        sandy.khan@isu.edu    515.101.9009
$
```

字符序列 `\<` 用于表示单词的开始。单引号（或双引号）用于确保 shell 不会将模式中的任何字母解释为 shell 元字符，如 `'\<Ke'` 或 `"\<Ke"`。因此，以下命令显示包含以字符串 "Ke" 开头的单词的行。

```
$ grep "\<Ke" students
David Kendall     d_kendall@msnbc.org   229.111.2013
Kelly Kimberly    kellyk@umich.gov      555.123.9999
$
```

通过使用正则表达式 `"\<K"`，grep 命令的输出会显示包含以字母 K 开头的单词的行。因此，命令的输出也包括 Sandy Khan 的行，如下所示。

```
$ grep "\<K" students
David Kendall     d_kendall@msnbc.org   229.111.2013
Kelly Kimberly    kellyk@umich.gov      555.123.9999
Sandy Khan        sandy.khan@isu.edu    515.101.9009
$
```

字符串 `\>` 是单词结束锚点。因此，以下命令显示包含以 "net" 结尾的单词的行。如果我们将字符串 net 替换为字符串 war，命令的输出会是什么？

```
$ grep 'net\>' students
John Johnsen        j.johnsen@psu.net        301.999.8888
Nabeel Sarwar       n.sarwar@xyz.net        434.555.1212
$
```

在以下命令中，正则表达式 "Kimberly|Nabeel" 用于让 egrep 显示包含 “Kimberly” 或 “Nabeel” 的行及其行号。请注意，正则表达式使用竖线符号 (|) 对两个字符串进行逻辑或运算。

```
$ egrep -n "Kimberly|Nabeel" students
6:Kelly Kimberly    kellyk@umich.gov        555.123.9999
10:Nabeel Sarwar    n.sarwar@xyz.net        434.555.1212
$
```

`egrep -n Kimberly\|Nabeel students` 命令也会产生相同的结果，因为竖线字符已使用 `\|` 转义。

你可以使用 -v 选项来显示不包含命令中指定的字符串的行。以下命令会输出所有不包含单词 “Kimberly” 和 “Nabeel” 的行。

```
$ egrep -v Kimberly\|Nabeel students
John Johnsen        john.johnsen@tp.com     503.555.1111
Hassaan Sarwar      hsarwar@k12.st.or      503.444.2132
David Kendall       d_kendall@msnbc.org    229.111.2013
John Johnsen        j.johnsen@psu.net      301.999.8888
Ibraheem Sarwar     ibraheem@abc.sci.com   222.123.4567
Maham Sarwar        smsarwar@k12.st.or    713.888.0000
Jamie Davidson      j.davidson@uet.edu     515.001.1212
Sandy Khan          sandy.khan@isu.edu     515.101.9009
$
```

以下命令显示 students 文件中以字母 J 开头的行。请注意 ^ 用来表示行的开头。

```
$ egrep "^J" students
John Johnsen        john.johnsen@tp.com     503.555.1111
John Johnsen        j.johnsen@psu.net      301.999.8888
Jamie Davidson      j.davidson@uet.edu     515.001.1212
$
```

以下命令显示 students 文件中以字母 J 或 K 开头的行。请注意 ^J 和 ^K 代表以字母 J 和 K 开头的行。

```
$ egrep "^J|^K" students
John Johnsen        john.johnsen@tp.com 503.555.1111
John Johnsen        j.johnsen@psu.net 301.999.8888
Kelly Kimberly      kellyk@umich.gov  555.123.9999
Jamie Davidson      j.davidson@uet.edu 515.001.1212
$
```

`egrep \^J\|\^K students` 命令可以产生相同的结果。然而，`egrep "^J|^K" students` 命令使用更简单的语法。作为经验法则，如果你需要在正则表达式中转义多个特殊字符，请将正则表达式用单引号或双引号括起来，具体视情况而定。
