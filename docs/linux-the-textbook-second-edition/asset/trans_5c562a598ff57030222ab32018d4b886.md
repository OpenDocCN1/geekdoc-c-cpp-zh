## 11.8.6 使用 scp 进行远程复制

如前所述，你可以使用 ftp 命令将文件传输到另一个网络上的远程主机，但这样做需要你登录到远程主机。scp（secure remote copy，安全远程复制）命令允许你在不登录到远程主机的情况下将文件复制到同一局域网上的远程机器。此命令在你使用网络文件系统（如网络文件系统 NFS）时在本地环境中不需要。在这种情况下，你的文件存储对你完全透明，你可以从网络上的任何主机访问它们，而无需指定包含它们的主机名称。

你可以使用 scp 命令通过 ssh 在网络上的两台主机之间复制文件。两台主机都可能是远程的。复制在经过本地主机和用户正确身份验证后在加密会话下进行。文件路径名可能包含用户和主机规范，以指示文件将被复制到该用户在给定主机上。主机名后跟冒号（:）字符。主机上的用户指定为 user@host，其中 host 可以是符号名称或 IP 地址，如以下示例所示。下面是对 scp 命令的简要描述。

**语法：**

`scp [-option(s)] [[user@]host1:]file1 ... [[user@]host2:]file2`

**用途：** 使用 ssh 通过网络在主机之间安全地复制文件

**常用选项/功能：**

| 选项 | 描述 |
|---|---|
| `-3` | 在两台远程主机之间复制是通过本地主机进行的。 |
| `-4` | 仅使用 IPv4 地址。 |
| `-6` | 仅使用 IPv6 地址。 |
| `-C` | 通过将此标志传递给 ssh 来启用压缩。 |
| `-c cipher` | 此选项传递给 ssh 以选择用于加密数据传输的密码。 |
| `-o ssh_option` | 以 ssh_config 文件中使用的格式将选项传递给 ssh。 |
| `-r` | 递归复制目录。 |
| `-p` | 从源文件保留修改时间、访问时间和模式。 |

下面的命令将当前目录中的 students 文件复制到 202.147.169.195 上的用户 sarwar 的 ~/linux2e/ch11/ 目录中。本地和远程主机上 ls -l 命令的输出证实文件已从本地主机复制到远程主机。

```
$ scp students sarwar@202.147.169.195:~/linux2e/ch11/
sarwar@202.147.169.195's password: xxxxxxx
students
100% 153 0.2KB/s 00:00
$ ls -l students
-rw-r--r-- 1 Mansoor staff 153 Oct 28 00:52 students
$ ssh sarwar@202.147.169.195 'ls -l ~/linux2e/ch11/students'
sarwar@202.147.169.195's password: xxxxxxx
-rw-r--r-- 1 sarwar faculty 153 Oct 28 00:54 /home/sarwar/linux2e/ch11/students
$
```

你可以使用远程机器的符号名称代替其 IP 地址。

```
$ scp students sarwar@linux18:~/linux2e/ch11/
sarwar@linux18's password: xxxxxx
...
$
```

下面的命令递归地将 202.147.169.195 主机上 sarwar 的整个主目录复制到本地机器的当前目录。不要忘记在 ~ 后面的空格字符后输入句点（.）。请注意，我们在命令输出的最后一行可以看到，使用 <Ctrl+C> 终止命令。
