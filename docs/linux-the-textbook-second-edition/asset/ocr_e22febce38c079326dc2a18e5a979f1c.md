# Summary

Linux text editors are critical to the operation of CUI-based interfaces to your Linux system, and also very important even if you are using a GUI. They allow you to create text files important and critical for system operations, such as Bash shell scripts or systemd unit files, or edit existing text entities such as configuration files for applications.

This chapter covered the basics of the CUI-based nano editor and gave some important considerations you might make when choosing a more sophisticated (although more complex) editor, such as vi, vim, or emacs.
