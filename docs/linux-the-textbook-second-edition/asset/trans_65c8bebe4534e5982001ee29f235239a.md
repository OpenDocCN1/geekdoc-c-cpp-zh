## 11.8.10 追踪从一个站点到另一个站点的路由

traceroute 命令利用 IP 的生存时间（TTL）字段来显示你的电子邮件、ssh 命令以及从 ftp 站点下载的文件从你的主机到远程主机（反之亦然）所经过的路由（路径中各路由器的名称）。它还能让你感受路由的速度。由于该命令会带来一些安全威胁，大多数系统管理员会禁用其执行。安全威胁源于这一事实：通过显示通往互联网上某主机的路由，有人可以推断出该主机所连接的网络的内部结构，以及网络上某些机器的 IP 地址。

traceroute 命令在 Linux Mint 系统上默认未安装，因此你必须请求系统管理员为你安装。如果你在自己的个人系统上使用 Linux Mint 并拥有 root 访问权限，可以使用命令 sudo apt install traceroute 安装它。

下面是该命令的一个简单执行示例，以展示其输出并进一步说明互联网的内部工作原理。以下命令显示了在 Linux Mint 机器上从我们的主机到 mit.edu 的路由。由于到主机的路由取决于位置，该命令在你的系统上的输出可能会有所不同。

## 小结

计算机网络始于 1969 年 10 月 29 日晚上 10:30，当时 UCLA 的学生 Charley Kline 在 ARPANET 上发送了第一条成功消息。那时，ARPANET 由四个主机组成。如今，由于互联网无处不在，没有网络的计算机是无法想象的。网页浏览、文件传输、互动聊天、电子邮件和远程登录是当今计算机用户常用的一些众所周知的服务。电子商务现象改变了人们在全球范围内处理日常事务和开展业务的方式。Linux 在一般网络领域，尤其是网络互连领域占有特殊地位，因为大多数网络协议最初都是在 Linux 平台上实现的。如今，基于 Linux 的计算机运行着提供大部分互联网服务的大多数服务器进程。

网络互连软件的核心基于 TCP/IP 协议族。该协议族除其他一些协议外，还包括著名的用于应用数据传输和路由的 TCP 和 IP 协议。互联网路由的关键是 32 位 IP 地址（IPv4）和 128 位地址（IPv6）。使用最广泛的互联网服务是网页浏览（及其提供的所有服务，如电子商务和社交网站）、电子邮件、文件传输和远程登录。Linux 系统不仅支持所有互联网服务，还有附加的实用程序来支持本地网络活动。

本章讨论的主题包括网络和互连网络的一般结构、网络模型、TCP/IP 协议族、IP 地址、DNS、互联网协议和服务，以及用于执行网络和网络互连相关任务的 Linux 实用程序。这些实用程序通过客户端–服务器软件模型实现。本章讨论的实用程序有：finger（用于查找主机上用户的信息）、ftp 和 sftp（用于文件传输）、ip、host 和 nslookup（用于检查和设置网络接口参数，以及域名与 IP 地址之间的相互转换）、ping（用于查看主机的状态）、scp（用于在 Linux 主机上进行远程复制）、ssh（用于登录网络上的远程主机并执行远程命令）、talk（用于互动聊天）、telnet（用于远程登录）以及 traceroute（用于追踪从你的主机到目标主机的数据路由）。
