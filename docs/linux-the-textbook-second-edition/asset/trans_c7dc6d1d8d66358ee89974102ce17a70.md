你可以使用 `finger` 命令在 Internet 上显示主机上某个用户的信息，前提是该主机提供 finger 服务并且运行着 finger 服务器（`fingerd`；finger 守护进程）。大多数系统上远程 finger 已被禁用。`finger Pohm@iastate.edu Ashfaq@iastate.edu` 命令可用于显示 iastate.edu 上用户 Pohm 和 Ashfaq 的信息，如果它运行着 finger 守护进程。如果主机未运行 finger 服务器，`finger` 命令会向你显示 `Connection refused` 消息，例如

```
$ finger crenshaw@up.edu
finger: connect: Connection refused
$
```

如果 DNS 无法为域名找到映射，`finger` 命令会返回相应的错误消息。这种情况下，你可以运行 `host` 命令查找目标主机的 IP 地址，然后使用 IP 地址而不是域名重新运行 `finger` 命令。

以 `*@hostname` 为参数时，命令会显示当前登录到 `hostname` 的所有用户状态。某些站点对通配符 `*` 的使用有限制——例如，要求所有查询至少使用两个字符。大多数站点今天都不允许使用通配符 `*`。

## 11.8.4 文件传输

Linux 中有几种工具可用于在同一网络或另一个网络上的远程主机之间传输文件。这些工具的经典实现使用众所周知的 FTP 协议，服务器端运行 `ftpd` 守护进程，客户端通过 `ftp` 命令调用服务。你可以使用 `ftp` 命令在 Internet 上的远程主机之间传输文件。还有 `sftpd` 守护进程，允许使用客户端 `sftp` 命令通过 SSH 协议安全传输文件。我们在第 11.8.9 节讨论该命令。

正如我们在附录 A、第 2.3.4 节以及特别是在示例 19.1 中所示，也可以在你的 Linux 系统上下载、安装并启动（使用 `systemd`）一个非常安全的 FTP 守护进程（`vsftpd`）。示例 19.1 显示了在 Linux Mint 系统上使用 `systemd` 下载、安装和启动服务的步骤。`vsftpd` 相较于系统默认安装的 `ftp` 具有许多安全优势。`vsftpd` 的主要安全特性是，与 `ftp` 以明文发送密码不同，`vsftpd` 会加密密码。

在本节中，我们展示 `ftp` 命令的使用。以下是该命令的简要说明。

**Syntax:** `ftp [options] [host]`

**Purpose:** 从或向远程 **host** 传输文件

**Commonly used options/features:**

- **-d** — 启用调试
- **-i** — 传输多个文件时禁用提示
- **-v** — 显示所有远程响应

如本章前面所述，FTP 是基于 TCP 的客户端-服务器协议。当你运行 `ftp` 命令时，`ftp` 客户端进程会在你的主机上启动并尝试与远程主机上运行的 `ftp` 服务器进程建立连接。如果在客户端发起连接请求前远程主机上未运行 `ftp` 服务器进程，则连接不会建立，`ftp` 命令会显示 `Unknown host` 错误消息。运行 `ftp` 服务器进程的站点称为 *ftp site*。当与远程 `ftp` 站点建立 `ftp` 连接后，你可以运行多个 `ftp` 命令以有效使用此工具。然而，你必须具有适当的访问权限才能向远程站点传输文件。表 11.4 介绍了部分有用的 `ftp` 命令。

大多数 ftp 站点要求你拥有该站点上的有效登录名和密码才能传输文件。一些站点允许你使用 **anonymous** 作为登录名，**guest** 或你的完整电子邮件地址作为密码来建立 ftp 会话。这样的站点被称为允许匿名 ftp。换句话说，*anonymous ftp* 是使用 ftp 协议下载公共文件的方法。

### TABLE 11.4 — A Summary of Useful ftp Commands

| 命令 | 含义 |
|---|---|
| **! [cmd]** | 在本地机器上运行 `cmd`；不带 `cmd` 参数时，调用交互式 shell |
| **help [cmd]** | 显示 `cmd` 的摘要；不带 `cmd` 参数时，显示所有 `ftp` 命令的摘要 |
| **ascii** | 将 ftp 通道设为 ASCII 模式；用于传输 ASCII 类型文件，如文本文件 |
| **binary** | 将 ftp 通道设为二进制模式；用于传输非 ASCII 文件，如包含可执行代码或图片的文件 |
| **cd** | 更改目录；类似于 Linux `cd` 命令 |
| **close** | 关闭与远程主机的 ftp 连接，但仍停留在 ftp 中 |
| **dir remotedir localfile** | 将 **remotedir** 的列表保存到本地主机的 **localfile** 中；对于长目录列表很有用，因为 ftp 命令不能使用管道 |
| **get remotefile [localfile]** | 将 **remotefile** 传输到本地机器当前工作目录中的 **localfile**；如果未指定 **localfile**，则使用 **remotefile** 作为本地文件名 |
| **ls [dname]** | 显示指定目录 **dname** 的内容；若未指定则为当前目录 |
| **mget remotefiles** | 从远程主机传输多个文件到本地主机 |
| **mput localfiles** | 从本地主机传输多个文件到远程主机 |
| **open [hostname]** | 尝试与远程主机打开连接；如果未指定 hostname 参数则提示输入 |
| **put localfile [remotefile]** | 将 **localfile** 传输到远程主机的 **remotefile**；如果未指定 **remotefile**，则使用 **localfile** 作为远程文件名 |
| **quit** | 终止 ftp 会话 |
| **user [login_name]** | 如果无法登录，则通过指定 **user_name** 作为命令参数以远程主机用户身份登录；如果未指定 **user_name** 则出现提示 |

匿名登录通常仅限下载。如果你拥有 ftp 站点计算机的账户（即不是匿名登录），那么你几乎肯定被允许下载和上传文件。
