
因此，shell 拥有与高级语言相同的结构化编程能力。当你输入一条命令并按 <Enter> 键时，shell 会解释并尝试执行该命令，它假定命令行中的第一个单词就是命令名。shell 命令可以是内建命令，也可以是外部命令。shell 拥有执行内建命令的代码，而外部命令的代码则存放在文件中。为了执行外部命令，shell 会逐个搜索多个目录，以定位包含该命令代码的文件。如果找到了该文件，并且它包含代码（二进制程序或 shell 脚本），就执行它。shell 为定位外部命令文件而搜索的目录名集合称为搜索路径。搜索路径存储在一个 shell 变量中，对于 Bourne、Korn 和 Bash shell，该变量名为 PATH；对于 C shell，变量名为 path。你可以通过在 PATH 中添加新的目录名，或从中删除某些现有目录名，来更改自己 shell 的搜索路径。

有多个 shell 可供你使用。这些 shell 在命令行层面的使用便利性以及其编程语言所提供的特性方面各有不同。在基于 Linux 的系统中，最常用的 shell 是 Bash 和 C shell。Bourne shell 最古老，并且拥有良好的编程语言。C shell 拥有更方便、更丰富的命令级接口。Korn shell 兼具两者的某些优良特性，并且是 Bourne shell 的超集。

某些字符（称为 shell 元字符）对 shell 具有特殊含义。由于 shell 会以特殊方式对待它们，因此不应在文件名中使用它们。如果你必须在命令中使用它们，就需要给它们加引号，以便让 shell 按字面意义处理它们。
