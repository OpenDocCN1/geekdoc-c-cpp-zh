有时，您可能需要连接多个命令。以下命令行演示了使用多个管道形成命令管道的使用。在此命令行中，我们使用了 grep 和 sort 过滤器。

```
$ who | sort | grep "john" | mail -s "John's Terminal" doe@coldmail.com
$
```

此命令对 who 的输出进行排序，并将包含字符串“john”的行（如果存在）作为电子邮件消息发送给 doe@coldmail.com，主题行为“John's Terminal”。就输入和输出重定向而言，此命令行等同于以下命令序列。

```
$ who > temp1
$ sort < temp1 > temp2
$ grep "john" temp2 > temp3
$ mail -s "John's Terminal" doe@coldmail.com < temp3
$ rm temp1 temp2 temp3
$
```

# 9.12 重定向和管道组合

您不能单独使用重定向运算符和管道将命令的 stdout 重定向到文件并同时将其连接到另一命令的 stdin 在单个命令行中。但是，您可以使用 tee 实用程序来实现这一点。您可以使用此实用程序告诉命令 shell 将命令的 stdout 发送到作为 tee 参数指定的一个或多个文件，以及另一个命令。以下是 tee 实用程序通常使用方式的简要说明。

![](img/2a18e06cd9c6395e451f26126ecba1fd_249_0.png)

图 9.15 ssh server cat ~/research/pvm/datafile.server | diff datafile – 命令的语义。

语法：
command1 | tee file1 file2 ... fileN | command2
目的：command1 的标准输出连接到 tee 的 stdin，tee 将其输入发送到文件 file1 到 fileN 以及 command2 的 stdin

此命令语义是 command1 被执行，其输出存储在文件 file1 到 fileN 中，并作为输入发送给 command2。tee 实用程序的使用示例在以下命令中给出。

```
$ cat names students | grep "John Doe" | tee file1 file2 | wc -l
$
```

此命令从 names 和 students 文件中提取包含字符串“John Doe”的行，将这些行通过管道传输到 tee 实用程序，tee 将这些行的副本放入 file1 和 file2 中，并将它们发送给 wc -l，后者将输出发送到显示屏。因此，names 和 students 文件中包含字符串“John Doe”的行保存在 file1 和 file2 中，并且此类行的行数显示在监视器屏幕上。图 9.16 说明了此命令行的语义。这样的命令在 shell 脚本中很有用，其中脚本后面的不同操作需要对 file1 和 file2 执行。

# 9.13 TC Shell 中的输出和错误重定向

执行输入、输出和追加操作（<、>、>>）的运算符在 TC shell 中与在其他 shell 中一样工作，如前所述。但是，在 TC shell 中不能使用文件描述符与这些运算符一起使用。此外，错误重定向在 TC shell 中的工作方式与其他 shell 不同。在 TC shell 中，输出和错误重定向的运算符是 >&。

语法：
command >& file
目的：将命令的 stdout 和 stderr 重定向到 file

例如，以下命令将 ls -l foo 命令的输出和错误重定向到 error.log 文件。命令的标准输入仍然连接到键盘。请注意，我们使用了 % 符号作为 shell 提示符，这是 TC shell 的默认值。
