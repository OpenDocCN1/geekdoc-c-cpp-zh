## 7.2 排序文件

排序意味着根据某些标准对一组项目进行排序。在计算机术语中，它意味着对一组项目（例如整数、字符或字符串）按升序（下一个项目大于或等于当前项目）或降序（下一个项目小于或等于当前项目）进行排序。例如，整数集合 {10, 103, 75, 22, 97, 52, 1} 如果按升序排序，则会变成 {1, 10, 22, 52, 75, 97, 103}，如果按降序排序，则会变成 {103, 97, 75, 52, 22, 10, 1}。同样，字典中的单词按升序排列。因此，单词 apple 出现在单词 apply 之前。

排序是常用的操作，也在各种软件系统中执行。使用排序的系统包括

- 字典中的单词
- 电话目录中人员的姓名
- 显示机场航站楼航班号排序的到达和出发时间的航空公司预订系统
- 药房中准备好的处方中显示的人员姓名
- 来自注册办公室的班级名单中列出的学生姓名

排序过程基于使用每个项目的字段或部分，已知为排序键。要确定排序列表中每个项目的位置，您可以通过使用它们的键字段来比较列表中的项目（通常一次两个）。用作键的字段的选择取决于要排序的项目。如果项目是个人记录（例如学生员工记录），姓氏、学生 ID 和社会安全号码是常用的键。如果项目是机场的航班到达和出发时间，航班号和城市名称是常用的键。

Linux sort 实用程序可用于对文本（ASCII）文件中的项目进行排序。以下是该实用程序的简要描述。

**语法：**
`sort [options] [file-list]`
**用途：** 对 **file-list** 中的 ASCII 文件中的行进行排序
**输出：** 将排序后的文件输出到标准输出
**常用选项/功能：**
`-b` 忽略前导空白
`-d` 根据通常的字母顺序排序：忽略除字母、数字和空白以外的所有字符
`-c` 检查输入是否已排序；不排序
`-f` 将小写字母和大写字母视为等效
`-m` 合并已排序的文件
`-n` 根据字符串数值比较
`+n1[-n2]` 指定字段作为排序键，从 +n1 开始，到 -n2 结束（如果未指定 -n2，则到行尾）；字段编号从 0 开始
`-o FILE` 将排序后的输出发送到 FILE 而不是标准输出
`-r` 按相反顺序排序

如果在 **file-list** 中未指定文件，sort 会从标准输入读取输入。sort 命令的输出会发送到标准输出。默认情况下，sort 会将每一行从第一列开始视为键，并按字母顺序不区分大小写进行排序。换句话说，它会重新排列文件中的行——即换行符（\n）分隔的字符串——根据所有字段的内容从左到右。因此，在 sort 命令的输出中，以数字（0–9）开头的行出现在以字母开头的行之前，小写字母出现在其对应的大写字母之前，如 a、A、b、B、c 等，并且 1,000 被视为小于 3，因为 3 大于 1,000 的第一个字母。以下会话说明了这些要点。

```
$ cat data
100
Hello
war
Zoo
20
apple
World
200
April
40
```

```
$ sort data
100
20
200
40
apple
April
Hello
war
World
Zoo
$
```

使用 -n 选项，您可以根据数值的大小对数据进行排序，将字母放在数字之前，并按数值对数字进行排序。以下 sort 命令的输出说明了这一点。

```
$ sort -n data
apple
April
Hello
war
World
Zoo
20
40
100
200
$
```

在前一个命令的输出中，以小写字母开头的行仍然出现在以对应大写字母开头的行之前。如果您希望所有以大写字母开头的行出现在以小写字母开头的行之前，您应该将环境变量 LC_ALL 设置为 C 并在在 sort 命令之前导出它，如以下会话所示。

```
$ export LC_ALL=C
$ sort -n data
April
Hello
World
Zoo
apple
war
20
40
100
200
$
```

以下命令使用电话号码作为排序键并忽略前导空白（空格和制表符）按相反顺序对文件进行排序。+3 选项指定电话号码作为排序键（因为电话号码是最后一个字段），-r 选项指示 sort 以相反顺序显示排序后的输出，-b 选项要求 sort 实用程序忽略字段之间的前导空白。

```
$ sort +3 -r -b students
Maham Sarwar      smsarwar@k12.st.or    713.888.0000
Kelly Kimberly    kellyk@umich.gov      555.123.9999

John Johnsen      j.johnsen@psu.net     301.999.8888
David Kendall     d_kendall@msnbc.org   229.111.2013
Ibraheem Sarwar   ibraheem@abc.sci.com   222.123.4567
$
```

如果字段由一个以上的空格分隔，并且行与行之间的空格数量不同，如 students 文件的情况，-b 选项很重要。原因是空格字符的 ASCII 值“小于”所有字母和数字，如果我们不跳过初始空白，将会生成意外的输出。排序键可以组合，其中一个为主键，其他为次要键，按偏好顺序指定（主键先出现）。以下命令使用姓氏作为主键，电话号码作为次要键对 students 文件进行排序。

```
$ sort +1 -2 +3 -b students
Jamie Davidson    j.davidson@uet.edu    515.001.1212
John Johnsen      j.johnsen@psu.net     301.999.8888
John Johnsen      john.johnsen@tp.com   503.555.1111
David Kendall     d_kendall@msnbc.org   229.111.2013
```
