## 7.6 剪切与粘贴

在 Linux 中，你可以使用 cut 和 paste 命令处理以表格形式存储数据的文件。表格由行组成，每一行包含一条记录，每条记录有固定数量的字段。字段之间通常用制表符或空格分隔，不过也可以使用任何字段分隔符。cut 命令允许你从一个或多个文件中剪切表格的一个或多个字段，并将它们发送到标准输出。换句话说，你可以使用 cut 命令在文件中按字段边界垂直切割表格。下面是对该命令的简要描述。

```
Syntax:
cut -blist [-n] [file-list]
cut -clist [file-list]
cut -flist [-dchar] [-s] [file-list]
Purpose: Cut out fields of a table in a file
Output: Fields cut by the command
Commonly used options/features:
-b list    Treat each byte as a column and cut bytes specified in the list
-c list    Treat each character as a column and cut characters specified in the list
-d char    Use the character char instead of the <Tab> character as field separator
-f list    Cut fields specified in the list
-n         Do not split characters (used with -b option)
-s         Do not output lines that do not have the delimiter character
```

这里，list 是一个逗号分隔的列表，使用 - 来指定字节、字符或字段的范围。下面的会话演示了 cut 命令的一些常用选项和功能。在本节中，我们使用文件 student_addresses，其内容由 cat 命令显示。

```
$ cat student_addresses
John    Doe      jdoe@xyz.com    312.111.9999    312.999.1111
Pam     Meyer    meyer@uop.pk    666.222.1212    666.555.1212
Jim     Davis    jamesd@aol.org  713.999.5555    713.413.0000
Jason   Kim      j_kim@up.org    434.000.8888    434.555.2211
Amy     Nash     nash@state.gov  888.111.4444    888.827.3333
$
```

该文件从左到右有编号为 1-5 的五个字段：名字、姓氏、电子邮件地址、家庭电话号码和工作电话号码。虽然我们可以使用任何字符作为字段分隔符，但我们选择了 <Tab> 字符，以使表格以及下面的 cut 和 paste 命令的输出呈现“列”的外观。你可以使用 -f 选项显示名字和姓氏的表。注意，-f1,2 指定的是 student_addresses 文件的第一和第二个字段。

```
$ cut -f1,2 student_addresses
John  Doe
Pam   Meyer
Jim   Davis
Jason Kim
Amy   Nash
$
```

我们通过剪切 student_addresses 文件中的表格的第一、第二和第五个字段，生成一个包含姓名（名字和姓氏）和工作电话号码的表。

```
$ cut -f1,2,5 student_addresses
John  Doe   312.999.1111
Pam   Meyer 666.555.1212
Jim   Davis 713.413.0000
Jason Kim   434.555.2211
Amy   Nash  888.827.3333
$
```

为了生成包含姓名和电子邮件地址的表，我们使用以下命令。这里，-f1-3 指定 student_addresses 文件的第 1-3 个字段。

```
$ cut -f1-3 student_addresses
John  Doe   jdoe@xyz.com
Pam   Meyer meyer@uop.pk
Jim   Davis jamesd@aol.org
Jason Kim   j_kim@up.org
Amy   Nash  nash@state.gov
$
```

我们建议你在自己的机器上运行此命令，以确认是否产生所需的输出。如果没有产生所需的输出，那么说明你在部分或全部记录中未使用 <Tab> 字符作为字段分隔符。在这种情况下，请修正表格并重新尝试该命令。

在前面的会话中，我们使用了默认的字段分隔符，即 <Tab> 字符。根据文件的格式，你可以使用任何字符作为字段分隔符。例如，正如我们在第 4 章中讨论的，/etc/passwd 文件使用冒号（:）作为字段分隔符。因此，你可以使用 cut 命令提取信息，例如用户的登录名、真实姓名、组 ID 和主目录。由于真实姓名、登录名和主目录分别是第五、第一和第六个字段，因此可以使用以下命令生成一个包含所有用户姓名及其登录 ID 和主目录的表。输出的前两行是注释，因为它们以 # 开头。

```
$ cut -d: -f5,1,6 /etc/passwd
# $FreeBSD$
#
root:Charlie &:/root
toor:Bourne-again Superuser:/root
daemon:Owner of many system processes:/root
...
sshd:Secure Shell Daemon:/var/empty
smmsp:Sendmail Submission User:/var/spool/clientmqueue
...
sarwar:Syed Mansoor Sarwar:/home/sarwar
...
$
```

注意，-d 选项用于指定 : 作为字段分隔符，同时在命令的输出中它也显示为字段分隔符。对于以空白字符分隔的文件，在 -d\ 后使用一个或多个空格字符（空白），如以下示例所示。cat sample 命令用于显示以空白分隔的文件，该文件名为 **sample**，而 cut -d\  -f1,6 sample 命令用于显示该文件的第 1 和第 6 个字段。

```
$ cat sample
1 John CS Senior john@net2net.com 3.45
2 Jane CS Junior jane@net2net.com 3.76
3 Sara CS Senior sara@net3net.vom 3.33
$ cut -d\  -f1,6 sample
1 3.45
2 3.76
3 3.33
$
```

**paste** 命令与 cut 命令互补；它水平地连接文件（cat 命令垂直地连接文件）。因此，该命令可用于按列粘贴表格。下面是对该命令的简要描述。

**语法：**
**paste [选项] 文件列表**
**用途：** 水平连接 **文件列表** 中的文件；如果使用 -（即连字符）作为文件，则使用标准输入
**输出：** 将 **文件列表** 中的文件粘贴（水平连接）后的结果
**常用选项/功能：**
**-d list**    使用列表字符作为行分隔符；默认字符为 **<Tab>**

考虑文件 **student_records**，其中包含学生姓名（名字和姓氏）、专业和当前平均绩点（GPA）。

```
$ cat student_records
John  Doe    ECE   3.54
Pam   Meyer  CS    3.61
Jim   Davis  CS    2.71
Jason Kim    ECE   3.97
Amy   Nash   ECE   2.38
$
```

我们可以使用 paste 命令水平合并两个表 **student_records** 和 **student_addresses_shortened**，并生成另一个表，如下面的会话所示。为了保持结果表较小，我们使用了原始 **student_addresses** 文件的简化版本，名为 **student_addresses_shortened**，其中仅包含名字、姓氏和工作电话号码。我们通过使用 cut -f1,2,5 student_addresses > student_addresses_shortened 命令生成了这个表。注意，paste 命令的输出显示在屏幕上，不存储在文件中。结果表有七个字段。

```
$ cat student_addresses_shortened
John  Doe   312.999.1111
Pam   Meyer 666.555.1212
Jim   Davis 713.413.0000
Jason Kim   434.555.2211
Amy   Nash  888.827.3333
```

```
$ paste student_records student_addresses_shortened
John  Doe   ECE   3.54  John  Doe   312.999.1111
Pam   Meyer CS    3.61  Pam   Meyer 666.555.1212
Jim   Davis CS    2.71  Jim   Davis 713.413.0000
Jason Kim   ECE   3.97  Jason Kim   434.555.2211
Amy   Nash  ECE   2.38  Amy   Nash  888.827.3333
$
```

假设你想使用 student_addresses_shortened 和 student_records 表来生成并显示一个包含学生姓名、专业和家庭电话号码的表。你可以通过两种方式完成。使用第一种方法时，你剪切两个表中的适当字段，将它们按你希望显示的顺序放入单独的文件中，按正确顺序粘贴两个表，然后删除这些表。下面的会话演示了这一过程及其结果。注意，执行以下命令时，新表不会保存为文件。如果你想将新表保存到文件中，请使用 paste table1 table2 > students_table 命令。students_table 包含将 table1 和 table2 的列（按该顺序）粘贴在一起的结果。

```
$ cut -f1-3 student_records > table1
$ cut -f4 student_addresses > table2
$ paste table1 table2
John Doe ECE 312.111.9999
Pam Meyer CS 666.222.1212
Jim Davis CS 713.999.5555
Jason Kim ECE 434.000.8888
Amy Nash ECE 888.111.4444
$ rm table1 table2
$
```

上述过程在空间和时间方面代价较高，因为你需要执行四条命令，在磁盘上生成两个临时文件（table1 和 table2），并在显示所需的表之后删除这些临时文件。你可以使用一种不同的方法，通过以下命令完成同样的操作。

```
$ paste student_records student_addresses | cut -f1-3,8
John Doe ECE 312.111.9999
Pam Meyer CS 666.222.1212
Jim Davis CS 713.999.5555
Jason Kim ECE 434.000.8888
Amy Nash ECE 888.111.4444
$
```

这里，你首先使用 paste student_records student_addresses 命令将两个文件中的表格合并为一个包含九列的表，然后使用 cut -f1-3,8 命令显示所需的表。显然，第二种方法是完成此任务的优选方式，因为不会创建临时文件，并且只需要一条命令。如果你想将结果表保存到 students_table 文件中，请使用命令 paste student_records student_addresses | cut -f1-3,8 > students_table。

## 7.7 压缩文件

文件大小的减小称为文件压缩，它兼具空间和时间上的优势。压缩文件占用的磁盘空间更少，在网络或因特网环境中从一台计算机传输到另一台计算机所需的时间更短，复制所需的时间也更少。压缩文件需要时间，但如果一个文件要被多次复制或传输，用于压缩文件的时间可能只是节省的总时间的一小部分。此外，如果压缩文件要长期存储在辅助存储设备（例如磁盘）上，磁盘空间的节省可能相当可观。压缩的另一个后果是，压缩文件读起来像乱码。然而，这不是问题，因为该过程完全可逆，压缩文件可以转换回其原始形式。如果你能从压缩版本中完全恢复原始文件，这种压缩称为无损压缩。
