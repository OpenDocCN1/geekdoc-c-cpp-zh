### 17.1 Introduction

如前几章所述，本书的三个主要组成部分中有两个如下：基本 Linux 操作和命令，以及 Linux 系统编程。

本章是第三个主要组成部分的核心：Linux 系统管理。

根据前言中“发行版信息和补充”部分所述，本章中我们所有的命令行会话示例默认都在 Linux Mint 上执行。这是我们从 Linux 的三大主要家族中选择的代表性发行版或“分支”，即 Debian、Slackware（openSUSE）和 Redhat（CentOS）。但在本章中，我们也通过展示在 Debian、Ubuntu 和 CentOS 上执行的示例来说明一些重要任务，例如软件应用程序的包管理。正如前言所述，只要命令、其输出或其中一个系统中的操作与默认值有显著不同，我们就会在前面加上适当的命令行提示，以帮助您区分命令或操作所执行的系统。

为了安装、维护并有效使用由硬件和软件组件组成的 Linux 系统，通常需要执行以下各节中所示的一组常见任务。在本章中，我们针对的是个人、初级用户，他们仅为自己的使用，在自己的个人桌面/笔记本/平板电脑上执行这些任务。这些常见任务也可能由指定的管理员为许多人使用的更复杂的计算机系统执行。可以将这些常见任务分为由管理员执行和由单个用户或一组普通自主用户执行的任务。

即使我们展示了这些常见任务的基础知识，也有可能从所呈现的内容推断出更大规模计算机系统的更广泛背景，由系统管理员运行。

此外，在本书网站上，我们提供了每个任务的更多详细描述，并介绍了其他高级系统管理主题。我们在适当位置特别引用了这些详细描述和高级主题。例如，在说明第 17.2.3.1 节中的系统引导和启动时，我们引用了本书网站上的第 W26 章、第 W26.2.3.1.1 节，标题为“systemd Bootup”。

要完成本章中的许多系统管理任务，需要在系统上拥有超级用户或 root 用户权限。这意味着您需要知道超级用户密码，您（或指定的系统管理员）可以在安装 Linux 系统时设置该密码。

su 和 sudo 命令都用于以 root 权限执行程序和其他命令。root 用户拥有最大权限，可以对系统做系统管理员需要做的任何事情。普通用户以降低的权限执行程序和命令。

要执行需要最大权限的操作，您必须先执行 su 或 sudo 命令。

使用 su 命令会在不带任何额外选项的情况下使您成为超级用户——或 root 用户——。系统会提示您输入 root 账户的密码。此外，su 命令允许您切换到任何用户账户。如果您执行 su 命令，系统会提示您输入密码，并且命令 shell 的当前工作目录将是您的主目录。

完成在 root shell 中运行命令后，您应该输入 exit 以离开 root shell 并返回到有限权限模式。

root shell 不是登录 shell。

相比之下，sudo 以 root 权限运行单个命令。当您执行 sudo command 时，系统会在以 root 用户身份运行 command 之前提示您输入当前用户账户的密码。要使用 sudo 命令，您必须属于 sudoers 组。有关 sudo 命令的更多信息可在第 17.9.2.1 节找到，我们在本书网站上的第 W26 章、第 W26.9.2.1 节中对其进行了更详尽的介绍。我们还在附录 A、第 17.9.2.1 节中提供了 Debian、Ubuntu、Linux Mint 和 CentOS 的安装指南，展示了如何在这些系统上安装和激活 sudo 命令，如果它尚未安装和激活。

在我们的“边学边做”方法中，我们选择了一组针对个人初级 Linux 用户的常见系统管理任务。我们提供的任务符合该初学者可能处理的任何通用用例的模型。这些任务如下：

- 1. 从 DVD 媒体全新安装（有时称为“裸机”安装）64 位、X86 架构版本的 Linux，使用 GUI 安装程序安装到单硬盘桌面系统上，并配备 GUI 桌面环境。使用默认磁盘分区方案对该系统进行初步配置，使其成为硬件上唯一的 operating system。
- 2. 说明系统如何在 systemd 的上下文中启动、启动，以及如何优雅地关闭系统。
- 3. 详细介绍使用 systemd 管理系统服务的基础知识。
