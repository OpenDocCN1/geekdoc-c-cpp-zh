## 3 编辑文本文件

- 解释在 Linux 系统上编辑文本文件的一般用途
- 对 nano 文本编辑器进行基本介绍
- 涵盖以下命令和原语：
  
  nano

在本章中，我们使用在现代基础 Linux 系统上通常可用的以下简单文本编辑器：nano。我们还评论了文本编辑的一般用途，并在这些用途的启发下，讨论了其他常见的 Linux 文本编辑器。在本书的网站上，我们对 vi/vim/gvim 和 emacs 编辑器进行了更深入的介绍。

为了强调 nano 编辑器中键盘键的使用，我们提供了用于执行命令或更改模式的键的以下排版约定参考：

- 1. 按下 Escape 键表示为 <Esc>。
- 2. 按下 Enter 键表示为 <Enter>。
- 3. 按下 <Ctrl> 键（在 nano 屏幕上以快捷形式表示为 ^）与另一个单个键组合表示为 <Ctrl+X>，其中你按住 <Ctrl> 键并同时按下 X 键（或该组合的有效键）。
- 4. 按下 Alt 键与另一个单个键组合表示为 <Alt+X>，其中你按住 <Alt> 键并同时按下 X 键（或该组合的有效键）。
- 5. 3. 和 4. 的变体显示为 <Ctrl+X> a [b]，其中你首先同时按下并释放 <Ctrl> 和 X，然后按下 a 键（或任何有效的单个键或字符字符串组合）。

你在键盘上输入或按住的内容以粗体文本显示。

现代 Linux 既使用图形用户界面（GUI），具有强大的窗口管理系统，也使用字符用户界面（CUI）。因此，为了执行诸如从脚本文件中执行多个命令、编写电子邮件消息或创建 C 语言程序等有用操作，你必须熟悉一种或多种将文本输入文件的方法。此外，你还必须熟悉如何高效地编辑现有文件——即更改其内容或以某种方式修改它们。文本编辑器允许你查看文件的内容，类似于 more 命令，以便

可以识别文件的关键特征，然后阅读并利用其中包含的信息。例如，一个没有扩展名的文件，例如 foo（而不是 foo.txt）可能是你可以用文本编辑器查看的文本文件。

我们在此考虑的编辑器都属于全屏显示编辑器。也就是说，在你用于查看或编辑文件的显示屏幕或监视器上，你能够看到文件的部分内容，它填充了分配给文本编辑器屏幕显示的大部分或全部窗口。你还能够使用键盘上的箭头键或鼠标将光标或指针移动到此全屏显示中的任何文本。该文本材料通常保存在计算机内存中的一个临时存储区域中，称为编辑器缓冲区。如果你的文件大于一屏，则随着你通过文件移动光标，缓冲区内容会发生变化。文件与缓冲区之间的区别至关重要。对于文本编辑目的，文件存储在磁盘上作为数据序列。当你编辑该文件时，你编辑的是编辑器创建的副本，该副本位于编辑器缓冲区中。你可以更改缓冲区的内容——甚至可以同时操作多个缓冲区——但当你保存缓冲区时，你会将新的数据序列写入磁盘，从而保存文件。

所有 Linux 编辑器的另一个重要操作特征是，传统上它们的操作基于击键命令，无论是单个击键还是同时或顺序按下的键组合。因为键盘是 Linux 的主要输入设备之一，所以使用击键命令的正确语法是强制性的。但键盘输入方法，一旦你习惯了它，就和鼠标/GUI 输入一样高效，或者对某些用户来说甚至更高效。击键也更灵活，使你能够更完整、更可定制地控制编辑操作。一般来说，你应该选择你最舒适的编辑器，就你喜欢与计算机交互的方式而言。当然，对于大多数初学者来说，那就是 nano。然而，你对编辑器的选择也取决于你想要进行文本创建和操作的数量和复杂性。从实际角度来看，vi、vim、gvim 和 Gnu emacs 等编辑器能够处理多个窗口中多个文件的复杂编辑任务，并为你提供视觉软件开发环境，以及文档制作和管理功能。但要利用这种功能，你必须学习执行这些任务所需的命令的机制以及它们是如何图形化或通过键入实现的——并保留这些知识。文本编辑器的基本功能列在表 3.1 中，并附有每个功能的简短描述。

对于文本编辑器 vi、vim 和 gvim，你不能立即开始向正在编辑的文件中输入文本。你必须处于插入模式才能这样做。vi、vim 和 gvim 具有模式。

在 nano（和 Gnu emacs）中，你可以立即开始向文件中输入文本。nano 是一个无模式编辑器，这就是它易于使用的原因。这基本上意味着你可以使用键盘和某些特定的指向设备，例如鼠标或键盘箭头键，立即开始输入和编辑文本。
