# 17.6.2.4 Restoring Archived Files with tar

You can restore (unpack) an archive by using the option --extract of the tar command. To restore the archive created in Section 17.6.2.3 and place it in a directory called ~/backups, you can run the following command sequence. The cp command copies the archive file, assumed to be in your home directory, to the directory (~ /backups) where the archived files are to be restored. The cd command is used to make the destination directory the current directory. Finally, the tar command is used to do the restoration. Notice that the destination directory is the current directory.

```
$ cp unixbook.tar ~/backups
$ cd ~/backups
$ tar --extract --verbose --file unixbook.tar
```

The unixbook.tar file remains intact after it has been unpacked. This result makes sense considering that the primary purpose of the tar archive is to backup files, and it should remain intact after restoration in case the system crashes after the file is restored but before it is archived again.
