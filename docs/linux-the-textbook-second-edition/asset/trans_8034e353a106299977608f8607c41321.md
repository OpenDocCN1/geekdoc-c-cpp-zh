

## 表 4.3 一些重要的隐藏文件及其用途

| 文件名 | 用途 |
|---|---|
| . | 当前工作目录 |
| .. | 当前工作目录的父目录 |
| .bash_history | 包含在 bash 下执行的命令历史 |
| .bashrc | Bash shell 的设置 |
| .cshrc | C shell 的设置 |
| .exrc | vi 的设置 |
| .login | 如果 C 或 tcsh shell 是登录 shell，则为 shell 的设置；在登录时执行 |
| .mailrc | mail 和 mailx 的设置和地址簿 |
| .profile | 如果 Bourne 或 Korn shell 是登录 shell，则为 shell 的设置；在登录时执行 |
| .rhosts | 受信任主机的域名（详见第 11 章） |
| .shrc | 如果 Bourne shell 是登录 shell，则为 shell 的设置；在登录时执行 |
| .ssh | 使用 ssh 命令可登录的服务器的密钥。首次尝试在服务器上建立会话时存储密钥 |
| .vimrc | vim 文本编辑器的设置 |
| .xsession | 自定义 X 会话脚本 |

你还可以使用带 -a 选项的 ls 命令显示目录中所有文件和目录的名称，包括隐藏文件。在以下会话中，cd 命令将你放置在主目录中，ls -a 命令显示主目录中的所有文件和目录，包括隐藏文件。

```
$ cd
$ ls -a

.bash_history courses     Downloads   .local      Public

$
```

在主目录中时，你可以使用带 -p 选项的 mkdir 命令创建 professional 目录及其下的 letters 子目录，如下所示

你可以使用 rmdir 命令删除空目录。如果目录不为空，则必须先删除其中的文件和子目录，然后才能删除它。要删除非空目录，需要使用带 -r 选项的 rm 命令（见第 6 章）。以下是 rmdir 命令的简要说明。

- Syntax: `rmdir [option] directory-names`
- Purpose: Remove the empty directories specified in directory-names
- Commonly used options/features:
    - `-p` Remove empty parent directories also

以下命令从当前工作目录中删除 letters 目录。如果 letters 目录不为空，rmdir 命令会在屏幕上显示错误信息 rmdir: letters: Directory not empty。如果 letters 目录是一个文件，命令会显示错误信息 rmdir: letters: Not a directory。

```
$ rmdir letters
$
```

以下命令从当前工作目录中删除 letters 目录，并从主目录中删除 memos。

```
$ rmdir ~/memos/letters
$
```

如果 ~/personal 目录仅包含一个名为 diary 的空子目录，你可以使用以下命令同时删除 ~/personal 和 ~/personal/diary 两个目录。我们假设你在执行此命令时位于主目录中。

```
$ rmdir -p personal/diary
$
```

### 4.5.5 确定文件属性

你可以使用带各种选项的 ls 命令确定文件的属性。选项可以一起使用，其顺序无关紧要。例如，你可以使用 -l 选项获取目录的长列表，从而显示文件的属性，例如文件的所有者。同样，你可以使用 -ld 选项显示目录的属性。以下示例说明了使用 ls 命令的 -ld 和 -l 选项。

```
$ ls -ld courses memos personal
drwxr-xr-x 2 sarwar faculty 4096 Jul  6 10:31 courses
drwxr-xr-x 2 sarwar faculty 4096 Jul  8 15:19 memos
drwxr-xr-x 2 sarwar faculty 4096 Jul  8 15:19 personal
$ cd ~/courses/ee446/exams
$ ls -l
total 44
-rw-r--r-- 1 sarwar faculty  7878 Jul  8 15:23 mid1
-rw-r--r-- 1 sarwar faculty 32253 Jul  8 15:23 mid2
drwxr-xr-x 2 sarwar faculty  4096 Jul  8 15:22 solutions
$
```

ls -l 命令显示的信息总结在表 4.1 中。

在前述两次使用 ls -l 命令中，courses、memos、personal 和 solutions 是目录，而 mid1 和 mid2 是普通文件。如前所述，我们将在第 5 章讨论访问权限和用户类型。文件的所有者是 sarwar，他属于 faculty 组。剩余字段的值不言自明。

你可以使用带 -i 选项的 ls 命令显示文件和目录的 inode 号。要显示目录的 inode 号，需要使用 ls -id 命令。以下使用示例显示 greeting 文件的 inode 号为 6278611，而目录 courses、memos 和 personal 的 inode 号分别为 6555603、6555456 和 6555324。

```
$ ls -i greeting
16517942 greeting
$ ls -id courses memos personal
16517083 courses  16517069 memos  16517079 personal
$
```

你可以使用 -F 选项识别目录、可执行文件和符号链接。ls -F 命令在可执行文件后显示星号 (*)，在目录后显示斜杠 (/)，在符号链接后显示“at”符号 (@)（第 8 章讨论），如下所示：

```
$ ls -F /
bin/    dev/    initrd.img@  lost+found/  opt/    run/    sys/    var/
boot/   etc/    lib/     media/       proc/   sbin/   tmp/    vmlinuz@
cdrom/  home/   lib64/   mnt/         root/   srv/    usr/
$
```

请注意，根目录中没有可执行文件。ls -F /bin 命令的输出将显示 /bin 目录中的所有文件都是可执行的。建议你在系统上阅读 ls 命令的在线手册页，或参阅本书记载在 CRC Press 网站上的命令附录，以获取命令的详细说明。
