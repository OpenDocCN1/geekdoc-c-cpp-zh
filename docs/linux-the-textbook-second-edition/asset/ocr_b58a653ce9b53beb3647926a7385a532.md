# 13.2 Numeric Data Processing

The values of all Bash variables are stored as character strings. Although this feature makes symbolic data processing fun and easy, it does make numeric data processing a bit challenging. The reason is that integer data are actually stored in the form of character strings. To perform arithmetic and logic operations on them, you need to convert them to integers, perform the necessary operations on the integer data, and be sure the result is converted back to a character string for its proper storage in a shell variable. In this section, we discuss different ways of performing arithmetic operations, first by using features of Bash and then with bc, an arbitrary-precision calculator, that comes prepackaged with all Linux distributions.
