

## 12.6 程序控制流命令

程序控制流命令/语句用于确定 shell 脚本中语句执行的顺序。控制脚本流程的语句有三种基本类型：双向分支、多向分支以及一个或多个命令的重复执行。Bash 中双向分支的语句是 if，多向分支的语句是 if 和 case，而重复执行某些代码的语句是 for、while 和 until。

### 12.6.1 if-then-elif-else-fi 语句

if 语句最基本的形式用于单向分支，但该语句也可用于双向和多向分支。以下是多向 if 语句的语法和简要说明。等宽字体中的单词是关键字，必须按语法所示使用。中括号中的内容为可选。所有命令列表都设计为帮助你完成手头的任务。

```
Syntax:
    if expression
        then
            [elif expression
                then
                    then-command-list]
            ...
            [else
                else-command-list]
        fi
Purpose: To implement two-way or multiway branching
```

这里，expression 是一个命令列表。expression 中命令的执行会返回 true（成功）或 false（失败）状态。我们讨论 if 语句的三个版本，这三个版本共同构成了语句的完整语法和语义。if 语句的第一个版本不带任何可选功能，从而得到通常用于单向分支的语句语法。

```
Syntax:
    if expression
        then
            then-commands
    fi
Purpose: To implement two-way branching
```

如果 expression 为 true，则执行 then-commands；否则执行 fi 之后的命令。语句的语义如图 12.1 所示。

expression 可以用 test 命令进行求值。它会求值一个表达式并返回 true 或 false。该命令有两种语法：一种使用关键字 test，另一种使用方括号。以下是该命令的简要说明：

```
Syntax:
    test [ expression ]
Or
    [[ expression ]]
Purpose: To evaluate expression and return true or false status
```

关于这种第二种语法的一个重要点是，内部的方括号表示可选的 expression，而外部的方括号是必需的，因为它们构成了 test 语句。此外，在运算符、括号、方括号或操作数之前和之后至少需要一个空格。如果需要将 test 表达式继续到下一行，你必须在按 \<Enter\> 之前使用反斜杠 (\ )，以便 shell 不会将下一行视为单独的命令。回想一下，\ 是 shell 元字符。我们在第一个会话中演示了 test 命令的使用，然后使用更简单的 [ ] 语法。

test 命令支持许多用于测试文件和整数、测试和比较字符串以及逻辑连接两个或多个表达式以形成复杂表达式的运算符。表 12.5 描述了大多数 Linux 系统上 test 命令支持的运算符的含义。

我们使用 if 语句修改 set_demo 文件中的脚本，使其仅接受一个命令行参数并检查该参数是否为文件或目录。如果脚本未带参数或带多个命令行参数运行，或命令行参数不是普通文件，则脚本会返回错误消息。脚本文件的名称为 if_demo1。

```
$ cat if_demo1
#!/bin/bash
if test $# -eq 0
then
    echo "Usage: $0 ordinary_file"
    exit 1
fi
if test $# -gt 1
then
    echo "Usage: $0 ordinary_file"
    exit 1
fi
if test -f "$1"
then
    filename=$1
    set -- `ls -l $filename`
    perms="$1"
    size="$5"
    set `ls -i $filename`
    inode="$1"
    echo "File Name:        $filename"
    echo "Inode Number:     $inode"
    echo "Permissions:      $perms"
    echo "Size (bytes):     $size"
    exit 0
fi
echo "$0: argument must be an ordinary file"
exit 1
$ ./if_demo1
Usage: if_demo1 ordinary_file
$ ./if_demo1 lab1 lab4
Usage: if_demo1 ordinary_file
$ ./if_demo1 dir1
if_demo1: argument must be an ordinary file
$ ./if_demo1 set_demo
File Name:      set_demo
Inode Number:   16517945
Permissions:    -rwxr-xr-x
Size (bytes):   245
$
```

在前面的脚本中，第一个 if 语句会在你不带任何命令行参数运行脚本时显示错误消息并退出程序。第二个 if 语句会在你带多个参数运行脚本时显示错误消息并退出程序。第三个 if 语句在前两个条件为假时执行——即当你仅带一个参数运行脚本时。如果命令行参数是普通文件，则该 if 语句会产生期望的结果。如果传入的参数不是普通文件，则第三个 if 语句的条件为假，并显示错误消息 if_demo1: argument must be an ordinary file。exit 命令用于从脚本中夺取控制。我们通常在因错误条件而终止脚本时使用 1 作为 exit 的参数（即退出状态）。退出状态 0 用于脚本的正常终止。

我们可以使用 test 命令的替代语法和表 12.5 和 12.6 中所示的逻辑 AND 运算符 -a 来重写 if_demo1 中的脚本。

```
$ cat if_demo10
#!/bin/bash
if [ "$#" -eq 1 -a -f "$1" ]
    then
        ...
fi
echo "$0: Specify exactly one command line argument that"
echo " must be an ordinary file."
exit 1
$
```
