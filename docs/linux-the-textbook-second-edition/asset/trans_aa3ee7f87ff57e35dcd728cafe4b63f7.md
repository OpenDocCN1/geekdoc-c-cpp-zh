## 4.4.2 主目录与当前工作目录

登录时，Linux 系统会将你置于一个特定的目录中，称为你的主/登录目录。例如，图 4.2 中名为 `sarwar` 的目录就是登录名为 `sarwar` 的用户的主目录。在使用 C、tcsh、Bash 或 Korn shell 时，你可以使用波浪号（`~`）字符来指定你的主目录。你当前所处的目录称为当前工作目录（也称为当前目录）。当前工作目录也用 `.`（读作“dot”）表示。当前工作目录的父目录用 `..`（读作“dot dot”）表示。

在本章后面，我们将介绍可用于确定主目录和当前工作目录的命令。我们还会介绍一些用于与 Linux 文件系统进行交互的命令。

## 4.4.3 路径名：绝对路径名与相对路径名

在分层文件系统中，文件或目录通过路径名来指定。简单来说，路径名就是文件的完整名称。路径名可以通过三种方式指定：（1）从根目录开始，（2）从当前工作目录开始，（3）从用户的主目录开始。当路径名从根目录开始指定时，它被称为绝对路径名，因为文件系统结构中的任何用户都可以从任何位置使用它。例如，`/home/faculty/sarwar/courses/ee446` 是用户 `sarwar` 主目录下 `ee446` 目录的绝对路径名。`sarwar` 主目录下名为 `mid1` 的文件的绝对路径名是 `/home/faculty/sarwar/courses/ee446/exams/mid1`。请注意，虽然如图 4.2 所示，我们的系统将 `/home` 分为 `admin`、`students` 和 `faculty` 等子目录，但大多数 Linux 系统将所有主目录都放在 `/home` 下。

从当前工作目录或用户主目录开始的路径名称为**相对路径名**。当用户 **sarwar** 登录时，系统会将他放入其主目录 **/home/faculty/sarwar**。在主目录中，**sarwar** 可以使用相对路径名 **./courses/ee446/exams/mid1** 或 **courses/ee446/exams/mid1** 来指定文件 **mid1**（参见图 4.2）。在目录 **ee446** 中的用户 **sarwar**（或任何其他人）可以使用相对路径名 **exams/mid1** 来指定同一文件。**mid1** 文件的所有者（或任何以所有者身份登录的人）也可以使用路径名 **~/courses/ee446/exams/mid1** 或 **$HOME/courses/ee446/exams/mid1** 从文件结构中的任何位置指定它。或者，你可以从个人目录中将 **ee446** 指定为 **../courses/ee446**。

典型的 Linux 系统有多个包含用户和系统文件的磁盘驱动器，但作为用户，你不必担心哪个磁盘驱动器包含你需要访问的文件。在 Linux 中，多个磁盘驱动器和/或磁盘分区可以*挂载*在同一个文件系统结构上，允许将它们作为目录访问，而不是像 MS-DOS 和 Microsoft Windows 中那样作为命名驱动器（A:、B:、C: 等）访问。你可以通过指定这些磁盘和/或分区上的文件和目录的路径名来访问它们，就像它们是单个磁盘/分区上文件结构的一部分一样。这样就为系统中的所有文件和目录提供了一个统一的视图，你无需记住驱动器的名称以及它们包含的文件和目录。

## 4.4.4 一些标准目录和文件

每个 Linux 系统都包含一组标准文件和目录。标准目录包含一些特定文件。在本节中，我们将讨论一些重要的目录。你可能想要浏览 Web 资源中列出的第一个网站（本书 GitHub 站点上的表 4.5），以了解更多关于 Mint 目录层次结构的信息。

- **根目录（/）：** 根目录位于文件系统层次结构的顶部，用斜杠（`/`）表示。它包含一些标准文件和目录，从某种意义上说，它是包含所有抽屉、文件夹和文件的主柜。

- **/bin：** 也称为二进制目录，**/bin** 目录包含大多数 Linux 程序/命令的二进制（即可执行）映像，这些程序/命令对于启动和修复单用户和多用户环境至关重要。在我们的系统上，**/bin** 目录仅包含 179 个文件，包括 `bash`、`bzexe`、`bzdiff`、`bzgrep`、`bzless`、`bzmore`、`cat`、`chmod`、`chown`、`cp`、`date`、`echo`、`egrep`、`grep`、`gunzip`、`gzip`、`kill`、`less`、`ln`、`ls`、`mkdir`、`mknod`、`more`、`mount`、`mv`、`nano`、`netstat`、`ping`、`ps`、`pwd`、`rm`、`rmdir`、`sed`、`sh`、`sleep`、`stty`、`su`、`systemd`、`tar`、`tcsh`、`umount`、`zcat`、`zdiff` 和 `zgrep`。

  超级用户和普通用户都可以使用这些程序。

- **/usr/bin：** 与某些 UNIX 系统不同，Linux 下的 **/usr/bin** 目录与 **/bin** 不同。**/usr/bin** 目录包含数百个启动或修复系统不需要的可执行程序。其中一些最常用的程序包括 `awk`、`diff`、`du`、`env`、`file`、`find`、`finger`、`gcc`、`gdb`、`groups`、`head`、`java`、`javac`、`less`、`lex`、`locate`、`lp`、`lpq`、`lpr`、`man`、`nl`、`pstree`、`sort`、`ssh`、`sudo`、`tail`、`telnet`、`time`、`top`、`touch`、`tr`、`uniq`、`vi`、`wc`、`which`、`who`、`whoami`、`zip`、`zipgrep` 和 `zipinfo`。在我们的 Linux Mint 系统上，**/usr/bin** 包含 2,078 个文件。

- **/boot：** 此目录包含启动系统所需的一切，包括引导加载程序，但不包括引导加载程序的配置文件。配置文件放在 **/etc** 目录中。例如，GRand Unified Bootloader（GRUB）引导加载程序必须位于 **/boot** 中，其配置文件位于 **/etc** 中。在我们的系统上，**/boot/grub/grub.cfg** 配置文件由 `grub-mkconfig` 实用程序使用 **/etc/grub.d** 目录中的模板生成。类似地，`systemd-boot` 加载并运行统一可扩展固件接口（EFI，或简称 UEFI）引导映像。**/boot** 目录还包含 `vmlinuz-4.4.0-21-generic` 形式的 Linux 内核引导映像。

- **/dev：** **/dev** 目录也称为设备目录，包含与连接到计算机的设备相对应的文件，包括终端、USB 和硬盘驱动器、CD-ROM 驱动器、磁带驱动器、调制解调器、显卡、网卡、打印机等。这些文件称为特殊文件，已在第 4.3.4 节中介绍。

  此目录为连接到计算机的每个设备至少包含一个文件。每个设备都有一个名称和一个编号，表示该设备的特殊文件同时反映这两者。`/dev` 目录中的一些示例文件如下：`sda` 是第一块串行高级技术附件（SATA）硬盘，`sr0` 对应 CD-ROM，`dvd` 是指向 `sr0` 的符号链接，`tty`* 对应（电传打字机）终端。我们将在第 8 章讨论 Linux 中的链接，包括符号链接。`/dev/pts` 目录用于管理伪终端。

  一个系统可能有多个每种类型的设备——例如，10 块硬盘或分区、20 个终端、100 个伪终端、两块固态硬盘等。我们在基于 Linux Mint 的系统上，`/dev` 目录中共有 223 个文件。在中小型组织的基于网络的 Linux 环境中，此目录可能包含数百个甚至超过 1,000 个文件。

- **/etc：** `/etc` 目录包含系统配置和管理所需的命令、文件和脚本。普通用户无法修改此目录中的文件。此目录中的一些文件和目录包括 `crontab`、`csh.cshrc`、`csh.login`、`csh.logout`、`group`、`inetd.conf`、`login.access`、`login.conf`、`passwd`、`printcap`、`profile`、`rc.d`、`rcp`、`shells`、`services`、`ssh`、`ssl` 和 `termcap`。此目录中大多数文件的讨论超出了本教科书的范围。不过，我们将在本节末尾简要讨论 `/etc/passwd` 文件。

- **/lib：** 库目录包含一个归档文件，其中包含针对特定语言的一组相关文件。如今的典型 Linux 系统包含 C 和 C++ 的库。其中一种语言的归档文件可供以该语言开发的应用程序使用。`/lib` 目录包含对 `/bin` 和 `/sbin` 目录中的可执行程序至关重要的库。`/usr/lib` 目录包含共享库和归档类型库（由 `ar` 命令创建）。

- **/tmp：** 多个命令和应用程序都会用到 `/tmp` 目录，它包含临时文件。你也可以将此目录用于自己的临时文件。此目录中的所有文件都会定期删除，以免磁盘（或磁盘的一个分区）被临时文件占满。文件在 `/tmp` 目录中的生命周期由系统管理员设置，因系统而异，但通常只有几分钟。系统重新启动时，`/tmp` 中的文件可能存在也可能不存在。

- **/usr：** `/usr` 目录包含子目录，其中存放着大多数实用程序、系统守护进程（参见第 10 章）、应用程序、编程工具、标准 C 头文件、共享和归档类型语言库、手册页和其他重要文档，以及源代码（伯克利软件发行版（BSD）和第三方）。此目录中两个最重要的子目录是 `bin` 和 `lib`，它们分别包含大多数 Linux 命令（实用程序、工具等）的二进制映像和语言库。

- **/home：** `/home` 目录通常用于存放系统所有用户的主目录，并以某种方式组织。例如，系统管理员可以在此目录下创建子目录，用于存放特定类型用户的主目录。例如，图 4.2 中的示意图展示了一种类似大学的设置，为行政人员、教师、职员、学生等人的主目录各设一个子目录。这些子目录标记为 `admin`、`faculty` 和 `students`。如前所述，大多数 Linux 系统将所有主目录都放在 `/home` 下。

- **/var：** `/var` 目录包含多用途的日志、临时和假脱机文件。在众多其他目录中，`/var/mail` 目录包含用于接收和保存用户传入电子邮件消息的文件。当你阅读新电子邮件时，它来自此目录中的某个文件。`/var/spool/mqueue` 目录包含未投递的邮件队列，`/var/spool/output` 目录包含行式打印机假脱机目录。`/var/tmp` 目录包含在系统重新启动之间保留的临时文件。
