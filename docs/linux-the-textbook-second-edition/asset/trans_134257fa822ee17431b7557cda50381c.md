你可以使用 getpid() 和 getppid() 调用来显示进程的 ID（PID）和其父进程的 ID（PPID）。以下是这些调用的简要说明。

```
#include <sys/types.h>
#include <unistd.h>
pid_t getpid();
```

Success: The ID of the process (PID)

Failure: -1 and kernel variable errno set to indicate the type of error

```
#include <sys/types.h>
#include <unistd.h>
pid_t getppid();
```

Success: The ID of the parent process (PPID)

Failure: -1 and kernel variable errno set to indicate the type of error

以下会话中的 pids.c 程序展示了这些调用的使用。编译和运行此程序会显示进程的 PID（14519）和其父进程的 PID（14483）。请注意，进程的父进程是登录 shell（bash），其 PID 为 14483，如 ps 命令的输出所示。

```
$ cat pids.c
void main(void)
{
	printf("Child's PID = %d\n", getpid());
	printf("Parent's PID = %d\n", getppid());
}
$ gcc -w pids.c -o pids
$ ./pids
Child's PID = 14519
Parent's PID = 14483
$ ps
  PID TTY          TIME CMD
 14483 pts/0    00:00:00 bash
 14520 pts/0    00:00:00 ps
```

## Exercise 16.8
浏览 getpgrp() 和 getpgid() 系统调用的手册页。这些调用各自的用途是什么？

在 Linux 中创建进程的唯一方法是让一个进程创建自身的克隆——即进程主内存映像的副本以及大部分相关的内核数据结构（将在本节后面讨论）。进程可以使用 fork() 系统调用来实现此目的。克隆被称为

子进程，而 fork() 的调用者被称为父进程。两个进程都有其唯一的 PID。以下是 fork() 系统调用的简要说明。

```
#include <sys/types.h>
#include <unistd.h>
pid_t fork(void);

**Success:** 0 to the child process and the PID of child to the parent process
**Failure:** -1 and kernel variable errno set to indicate the type of error
```

正如你所见，fork() 调用返回类型为 pid_t 的值。综合阅读 /usr/include/x86_64-linux-gnu/bits/types.h 和 /usr/include/x86_64-linux-gnu/bits/typesizes.h 可知，pid_t 是一个有符号的 32 位整数。这意味着你会将 fork() 用在赋值语句中，如

```
pid_t  pid;
...
pid = fork();
...
```

一旦 fork() 完成子进程的创建并在返回之前，父进程和子进程就开始作为独立进程并发运行。两者都执行 fork() 之后的语句，即用于保存 fork() 调用返回值的赋值语句。fork() 调用向子进程返回 0，并向父进程返回子进程的 PID。很难理解一个系统调用如何返回两个值，因为一个函数只能返回一个值。请注意，fork() 能够返回两个值，是因为一旦子进程被创建，fork() 就必须在两个进程中完成其执行，并在每个进程中返回一个值。

子进程继承了父进程的多个属性和特征。以下是部分列表：

- 父进程 PPFDT 的副本
- 当前工作目录
- 环境
- 根目录
- set-UID（SUID）和 set-group-ID（SGID）状态
- 信号设置
- 闹钟响起前的剩余时间
- 文件创建掩码的值，umask

尽管子进程是父进程内存映像的精确副本，但两者在许多方面有所不同：

- 两个进程都有各自的 PID。
- 两者有不同的父进程。
- 两者拥有 PPFDT 的各自副本。
- 子进程的资源利用率被设置为 0。
- 子进程只有一个执行线程，而如果父进程是多线程的，其他线程不会释放它们持有的资源。
