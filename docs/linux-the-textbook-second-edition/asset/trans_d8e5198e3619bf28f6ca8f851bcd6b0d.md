## Projects

### Project 1

编写一个简单的 Linux shell：

- a. 显示提示符并等待用户输入以 <Enter> 结束的命令
- b. 执行 shell 命令并再次提示用户输入
- c. 当用户按下 <Ctrl+D> 时终止

你应该使用自己的代码实现以下命令；也就是说，它们是内置（固有）shell 命令：

| 命令 | 目的 |
|---|---|
| finfo file | 显示文件的以下属性：类型、硬链接数、用户 ID、访问权限 |
| truncate file size | 将文件大小截断为 size 字节 |
| holes file number | 如果是普通文件，则在文件中创建 number 个空洞 |
| mkdir dname | 创建目录 dname |
| rmdir dname | 删除目录 dname |
| ls [options] [file-list] | 生成类似于 Bash ls 命令的输出；支持 -l 和 -d 选项 |
| cd [dname] | 更改目录到 dname |
