# 10.10 DigiSynth Files

DigiSynth uses the following files, which you will need to include in your project in the usual manner. Also, don't forget to copy the folders of samples and multi-samples to your proper DLL or component folder.

For VST3 and AU, you also need to add the file SynthParamLimits.h, which is in the DigiSynth sample code—remember that this file is slightly different for each synth because it contains the GUI index enumeration.
