The fundamental variable types are float, int and enumerated UINT. The Octave and Octave controls generally generate numerical values that the user uses in the GUI, and they have minimum or Lo Limit, maximum or Hi Limit and default (Def) values. The control may have no units (" or empty string). The Fc (Filter cutoff) control has the note "volt/octave" which means that this control is logarithmic.

The Filter control displays strings that define the current value. An unsigned integer (UINT) keeps track of the current setting. The Enum String column gives you the comma-separated values that will map to the UINT variable. In this example is:

+   - LPF: 0
- HPF: 1
