You can see that the note and on note events are the trigger mechanisms for the attack and release segments. The decay and release times in Figure 6.5 are what you would see in a synthesizer manual, yet for many synths this is not completely accurate. The synth manufacturers aren trying to mislead anyone—it's easier and more intuitive to learn the envelope that way. These are actually the segments for decay/release from a full scale value down to 0.0. Therefore, the decay and release controls do not set the absolute decay and release times, but rather the decay and release. In Section 6.6 you will see that the Yamaha DX7 synth actually refers to all "times" as "rates" instead. The decay and release rates are exponential rates, making them significantly more difficult to deal with than simple linear rates or slopes. More importantly, the sustain level ultimately sets the actual decay and release times as shown in Figure 6.6, where the dotted lines are the original full-scale capacitor discharge curves.
