# Rendering Audio

The voice objects make easy to render the audio. The plug-in doesn't know or how the audio is synthesized, and the code is for all synths. You loop over the voices and accumulate all notes that are turned on. The voice outputs are scaled by 0.25 in MiniSynth to get 12 dB of headroom for summing a potentially large number of voices together. Note that there are other ways of handling the headroom issue including dynamic range compression. We choose this method as a simple and reasonably effective way of dealing with potential overflow and as well you are encouraged to experiment with other methods.
