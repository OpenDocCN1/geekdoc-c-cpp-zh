# 7.9 Nonlinear Moog Ladder Filter Models

The analog filter is nonlinear in nature due to the transistor ladder diff pairs conduct current. The differential voltage and current relationship uses the tanh() function. Huovilainen (2006) proposed a nonlinear model that inserted a tanh() block in each first order LPF stage (which was based on a biquad structure) and another in the feedback path. Zavalishin (2012) proposed an "nonlinear model" by inserting two tanh() blocks in trapezoidal integral, at the input and another in the feedback path. Välmäki and Zavalishin (2012) both proposed "cheap" versions with only one tanh() block; for Välmäki it is at the input x(n), for Zavalishin it is inside the feedback loop as shown in Figure 7.30. We have also experimented with the saturating integrator used in the Oberheim SEM model or one of the LPF stages. You are urged to experiment with these as well as your own nonlinear variations. Remember that for true self-oscillation, the loop must be 4.0 nonlinear saturation gain. This is how the wavesh feature a saturation control that brings their gain up to, and beyond, unity.
