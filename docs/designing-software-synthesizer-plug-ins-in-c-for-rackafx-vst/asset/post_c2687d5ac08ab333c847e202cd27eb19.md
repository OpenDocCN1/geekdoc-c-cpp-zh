Allow the four oscillators to be any of the waveforms (like Native Instruments FM8); saw, triangle and sine. The theory regarding the sideband amplitudes and locations is complicated. You cannot simply use superposition to apply the same sideband calculations to all the harmonics in non-minus signal. Implementing it is simple, however: allow the user to choose the waveforms. # Diamond

You may recall from the last chapter that Yamaha briefly consulted with Dave Smith and some of the original vector synthesizer engineers and designers. The TG33 and SY35 were the result. These were hybrid synthesizers that combined FM/PM, sample playback, and vector synthesis into one product. FM/PM and sample playback oscillators are mixed with a vector joystick and pattern.
