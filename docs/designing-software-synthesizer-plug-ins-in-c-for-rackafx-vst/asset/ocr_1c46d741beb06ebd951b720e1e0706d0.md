and that the wavetable increment is:

```
$inc_{wavetable} = \frac{f_s}{f_0}\n= (L)inc_{midi} \quad (10.3)
```

where L is the length of the wavetable. A wavetable contains only one cycle of the waveform, so L is the length of only one cycle. We can determine this equivalent length easily as:

```
$inc_{midi} = \frac{f_{midi}}{f_s}\nf_{unity} = frequency of MIDI Unity Note\nthus\n$inc_{sample} = \frac{L}{f_{unity}}inc_{midi} \quad (10.4)
```

Note: if you are not using modulo counter/increment timebase you could reduce the equation slightly as:

```
$inc_{sample} = \frac{f_s}{f_{unity}} \quad (10.5)
```

For a single-cycle, we can find the equivalent f unity:

```
$f_{unity} = \frac{C}{N}\nC = channel count\nN = sample count \quad (10.6)
```

For pitch-less samples, the table increment is simple 1.0.

Beware of .wav files that do not have the MIDI Unity Note encoded in them. We see this on occasion, sometimes from repeat loop companies. In these cases, the unity pitch is coded in the file name, such as piano_A1.wav. You may use these kinds of files, but you will need to manually code the unity number. Alternatively you can use in audio software that will modify the embedded information and correct these complete files.

# 10.3 Multi-Samples

Sampling musical instruments was common in the early days of based synthesis; this was a time when there was much focusing on making synthesizers sound exactly like other instruments. The desire to mimic traditional instruments was a prime motivator for the development of FM synthesis. A fundamental problem with sampling any type of pitched instrument, another synthesizer, is that the formats are not generally preserved when the playback ratio changes from unity. This gives the "chipmunk effect," which is unnatural and generally unwanted at high playback ratios. For very low playback ratios, the transients become smeared out in time, and the same sound can grainy or noisy. Additionally, many musical instruments produce a variety of timbres which the same note can sound vastly different when played loudly softly. The solution to this problem is to use brute force and capture many sounds at variety of pitches and amplitudes. This yields a set of samples as multi-samples.

For differing samples, you might need to sample every single MIDI note (or as as the instrument's range dictates). We used wavetables sampled in octaves for the non-sinusoidal waveforms in Chapter 5. A common strategy is to sample in minor thirds, typically C, Eb, F# and A every octave in the instrument's range. Since aliasing is possible when the playback ratio is greater than 1.0, we use another tactic of always shifting downward when possible. Figure 10.5 describes this scheme; the C sample is used to play the Bb and B it. A sample would be used for AB and G, while F# would be used for F and E, etc. In this way, only two notes are ever pitch shifted versions.
