In the upper right of the RackAFX UI is a control that represents an alpha wheel, LCD monitor view, and knob. During the design of your project, you've noticed that the LCD is used to give you feedback about the state of your project and computer. However, it can also be used as a GUI control just like the other sliders. The LCD allows you to store up to 1024 continuous sliders inside. Anything you setup with a normal slider will work as well as the LCD embedded, and the GUI Designer lets you pick one of controls on your own custom GUI. There are several uses for the control:

+   - it's a dreary way to store the continuous controls
- if you run out of sliders, you can put 1024 more of them in the LCD
- you can use enumerated controls to create a set of presets or other global functions or configurations—we will use this extensively for global parameters in the synths such as pitch band range, and it will tidy up the GUI by using controls in a small preset
