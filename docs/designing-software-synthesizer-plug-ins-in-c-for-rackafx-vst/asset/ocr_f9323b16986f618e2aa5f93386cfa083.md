# Appendix A

# A.1 Converting the VST3 TemplateSynthSynth (Nine Steps)

Example: Converting the TemplateSynth to NewSynth (where NewSynth is the name of your new project)—you will need a simple text editor to edit the .sln, .vcproj and .vcxproj files

+   1. copy the TemplateSynth directory and change the name of the directory to NewSynth
2. open that directory and change all file names from TemplateSynth.xxx to NewSynth.xxx
3. open the .sln file (for VS2008) or the _vc10.sln file (for VS2010 and higher) with a text editor, and Replace All TemplateSynth with
4. open the .vcproj file with a text editor, and Replace All TemplateSynth with NewSynth and save
5. open the .vcproj file with a text editor, and Replace All TemplateSynth with NewSynth and save
6. open the .sln file (for VS2008) or the _vc10.sln file (for VS2010 and higher)in Visual Studio (everything else is done in VS), and a Replace in Project to replace all instances of TemplateSynth with NewSynth

+   7. use guidgen.exe to make GUIDs for the following:

```
FUID Controller::cid (0xB561D747, 0xBA004597, 0xA3BF911A,0xD5DA2FA1);
FUID Processor::cid (0x91F037DC, 0xA35343AB, 0x85C237B1,0x3774DC90)
```

Guidgen.exe and FIDs are explained in Chapter 2. Replacing the existing FIDs at the top of the VSTSynthProcessor.cpp and VSTSynthController.cpp files with your newly generated and properly formatted FIDs

+   8. set your Output Directories: open the Project Properties for your NewSynth and on the General panel, browse for your Output Directory and Intermediate Directory; this is where your .vst3 will be delivered. Make sure to use the same directories as in the NewSynth project

+   9. set your debugger VST host: open the Project Properties and the Debugging panel; in the Command field, find your VST3 host executable file, for Cubase LE Ai Elements 7.exe, and set the Attach file to YES. If you forget the Attach patch, the debugger will never launch

# A.2 Converting the AU TemplateSynth (Ten Steps)

Example: Converting the TemplateSynth to NewSynth (where NewSynth is the name of your new project)

+   1. copy the TemplateSynth directory and change the name of the directory to NewSynth
2. open the .codeproj (you don't need to rename it): at upper left of Code, click on the TemplateSynth project (it says "Two Targets" below it), and change the name to NewSynth; when prompted to Rename Project Items, answer YES
3. use Find/Replace to do a brute force replacement of TemplateSynth with NewSynth
