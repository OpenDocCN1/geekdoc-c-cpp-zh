The argument is a char and can be as simple as a string-literal... However, to make our message more meaningful, we will need to use more built-in functions for converting numbers to strings and concatenating strings. So, when a MIDI note is turned on, we want to log the event and note number and velocity so that it shows up like this:

MIDI Note On: 00 96

which would indicate a Note On Message with MIDI note number 60 (middle C) and velocity 96. Of course you can format this string how you like, but the above is short and simple. Find the note on message. The arguments have been converted from bytes to UInts to make manipulation easier on your end.
