These groups of controls are called templates. Using templates makes creating and assembling the GUI easy. The knob group templates we have designed for you are "KG" (Knob Group). The knob groups will have all the parameters that are continuous controllers, linked to float, double or types. You can break the knob group down into its fundamental components as shown in Figure 2.33.

+   - CViewContainer: a transparent container with no PNG file associated with it
- CLabel: this label has a transparent background
- CAniKnob: an animated knob that rotates
- CEditText: a text box that the user can click on and change the value to an exact one; the knob will rotate in response
- all of the knob groups are 75x85 (width x height in pixels)

And, it should be noted that the size label and edit box are all positioned relative to their output CViewContainer. When you set up a Template, it is like making a mini-GUI, and everything is relatively positioned.

When you INSERT these group Templates into a CViewContainer, you position them using the Template view container originates relative to the columnar view container. For all the synths, since they are relative, they are the same for all the columns. We have placed the knobs 5 groups apart; since they are 85 pixels in height, each group's y-coordinate is 90 pixels greater the group above it. In Figure 2.34 you can see that the y-coordinates progress this (20,110,200); However, for vertically placed controls, the 5 pixel padding is not required, so the x-coordinates progress in increments of the width of 75 pixels (5,80,155,230).
