vector mix equations work great and are simple to implement--why reinvent the wheel?

AniSynth treats the dread of wavelet oscillators as a smaller of vector mix surfaces. That, each group of four adjacent waveforms comprises one ordinary vector mix surface. The name for a group of four adjacent oscillators is a cell. The mix surface is a surface of these cells.

At any time, the output of the synth voice is a combination of the four oscillators in the cell that contains the mix point, calculated with the standard Sequential/Korg equations. This cell is called the active cell.
