There are a multitude of ways of implementing a BLEP oscillator. The residual is stored in a relatively large finely sampled array. Other manifestations are less memory intensive, and there are different table lookup techniques that can be applied. For example, if you were to go eight points into the discontinuity (or four), then you might create eight-point tables for different increment values from the module controller and interpolate between them. Our implementation is hardware-less; BLEP is a function that returns the residual correction value or 0.0 if you are outside the discontinuity transition region. You can use simple table lookup techniques to fetch the residual value according to the current phase of the oscillator. You may enable or disable interpolation of the BLEP table (it is disabled to save processing time), and of course you are encouraged to experiment with other forms of interpolation.
