LCD controls may be either continuous or enumerated types. The enumerated types support up to 256 sub-strings, though it is unlikely you will ever need that. In addition there are four sets of radio buttons, of which each can hold an enumeration up to eight sub-strings.

For each project, you will be given a table Table 2.6. For RackAFX projects, you can ignore the last column that lists the index value, which only pertains to AU sand V3. This table has all the GUI controls, limits, defaults, and variable names and values that you will attach to the controls. In this table you can see two columns Variable Type and Variable Name. The four fundamental types are float, double and enumerated UINT. The Volume and Octave controls ultimately generate numerical values that the user sees on the GUI and they have minimum or Lo Limit, maximum or Hi Limit and default (Def) values. A control may also have no units ("" or empty string). The Fc (Fe Cutoff) control has no "volt/octave" which means this control is logarithmic. Note the Octave control delivers values since the octaves are selected
