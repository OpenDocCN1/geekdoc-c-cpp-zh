# prepareForPlay()

prepareForPlay() function is where you initialize the modulation matrix source and destinations for all subcomponents. This contains all the default wiring used in NanoSynth, as well as every possible sub-component default routing. It also initializes the MIDI volume and pan values at power-on. In particular the part of the DCA setup in; the default EG connection MUST be done in the derived class. This is because not every synth (or everyone) will use EG1 for the DCA output EG. And, in the FM synth called DXSynth, there are a variable number of output EGs ranging from 1 to 4 in number. This is the function where you can change the default routing if you wish.

# update()

In the update() function you apply changes to the global parameters. This is called once per sample period. It stores the voice mode and calculates a new portamento increment value if the portamento has changed (we will get to portamento shortly). The hard sync ratio is stored, but not used in the book projects. Notice that these variables are contained in the globalVoiceParams struct.
