# 4.6 The Bilinear z-Transform

There are two approaches to converting analog filters and their associated transform functions into digital. The first approach (classical) makes use of the bilinear integrator as the basis for transform called the bilinear transform. The second approach (Virtual Analog) makes use of the bilinear integrator by directly substituting for each analog integrator in an analog block diagram. Both methods result in filters that have identical frequency responses, but the benefits of using the virtual analog will become apparent. There are filters in this all use this virtual analog technique. For completeness, the classical approach is discussed first. There is an abundant collection of analog digital filters using the bilinear transform, so you should not discount it. There are some algorithms for which no virtual model exists, yet it is possible to use these kinds of filters when necessary. An example bilinear transformed filter is shown to compare later with the virtual analog version.

To find the transfer function of the bilinear integrator, use the rules you have amassed and apply them to the difference equation in Figure 4.7.

```
y(n) = y(n-1) + \frac{T}{2}[x(n) + x(n-1)]\rightarrow Y(z) = y(z) + \frac{T}{2}[X(z) + X(z)z^{-1}]

then:
Y(z) - y(z)z^{-1} = \frac{T}{2}[X(z) + X(z)z^{-1}]
Y(z)[1-z^{-1}] = \frac{T}{2}X(z)[1+z^{-1}]
H(z) = \frac{Y(z)}{X(z)} \frac{T}{2-z^{-1}}  (4.11)
```

The idea behind the Bilinear Z-Transform (BZT) is that if digital integrator H(z) is approximating the analog H(s) = 1/s, then we have a solid relationship between z and s.

```
H(s) = \frac{1}{s}
H(z) = \frac{1}{T} \frac{2-z^{-1}}{1+z^{-1}}  (4.12)
```

Means could take an analog transfer function H(s) and replace it with 2/T(z-1)/(z+1). This should produce a transfer function H(z) in the digital domain that corresponds to H(s) in the analog domain.

It would appear that such a deal is not perfect, and we do not firstly firstly. At low frequencies, the mapping is very close, but as the frequency increases, an error in the mapping increases with the tangent or tan(1) function. Secondly, it is that to map an infinite number of analog frequencies to a finite number of digits, and this does in this fractal manner, smashing and fading of all the analog frequencies to a tiny area near Nyquist. Moreover, it maps frequencies at infinity directly to Nyquist. See Designing Audio Effects Plug-Ins in C++ for a detailed discussion.

The consequence of this first issue is to pre-warp the analog frequency domain so that after the transformation, the digital frequency response is obtained. The mapping equation is:

```
\omega_s = \tan \frac{\omega_a T}{2}}
\n\omega_a = the prewarped analog frequency
\omega_s = the desired digital frequency
T = the sample period  (4.13)
```
