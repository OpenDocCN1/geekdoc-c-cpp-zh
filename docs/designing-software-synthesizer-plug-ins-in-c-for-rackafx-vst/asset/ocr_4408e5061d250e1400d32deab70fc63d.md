It does not read 8-bit files (though you could that fairly easily), and will only read PCM or uncompressed files. The industry standard for sample files is 24-bit integer for a while, though that may change. The files for the synth are all 24-bit. Initialize the CWaveData object with a string that is for the .wav file. It opens the file and extracts the audio into a newly created floating point buffer. Once successful, you can access its member variables to get information about the sample, as its MIDI Unit Note, MIDI Pitch Fraction, length, channel count, and so on. The object can be re-used to open multiple files, but the buffers will be destroyed and recreated with the new contents. We are going to use one object .wav file in the oscillator. The SMPTE Offset value specifies the time used for the synchronization/calibration to the first sample in the waveform. This value uses a format of 0hhhhmmssff where hh is a signed value that specifies the number of hours (-23 to 23), mm is an unsigned value that specifies the number of minutes (0 to 59), ss is an unsigned value that specifies the number of seconds (0 to 59) and ff is an unsigned value that specifies the number of frames (0 to -1*) (sonicscript.com, n.d.).
