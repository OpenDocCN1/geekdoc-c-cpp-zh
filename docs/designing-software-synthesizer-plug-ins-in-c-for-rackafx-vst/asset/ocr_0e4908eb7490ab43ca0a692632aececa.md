# update()

The update() function is important for MiniSynth because this is where you configure the oscillators based on the voice mode. Notice the voice mode is saved before calling the base class function that will overwrite it (this is the only time that happens in any of the objects). If the voice mode has changed, you reconfigure the oscillator types. After configuring, you call reset() on the oscillators; that we must preserve the phase relationship between different waveforms, and that is done in reset(). How do you use the global parameters to update the oscillator waveforms.
