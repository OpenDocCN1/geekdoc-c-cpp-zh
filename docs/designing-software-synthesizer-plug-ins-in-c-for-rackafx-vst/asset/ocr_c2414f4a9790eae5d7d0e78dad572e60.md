# 6.7 Iterative Generation of the Exponential Function

To implement an envelope generator with an exponential output, we will need to generate exponential curves based on e. Not only will this be computationally expensive, it poses a fundamental problem: exponential functions never decay all the way to zero. The analog version uses e⁻ˣ as the basis for the release curve (which we actually use e⁻⁵ to mimic the 77% charged cap in analog output). During the release phase, the imaginary capacitor decays to e⁻⁵ or 0.0067 or about -43 dB. The digital version, which is linear-dB or e⁻¹¹.⁰ˣ, decays to 0.00016. It would be nice to have decay all the way to 0. We can take care of both by generating the exponential curves iteratively. This is conceptually the same as a feedback loop in a digital filter. A feedback filter with a single coefficient 0.9 is energized with a single impulse as shown in Figure 6.19. The output of the filter decays exponentially as the filter keeps multiplying its output by 0.9 repeatedly. The succession of output values would be {1.0, 0.9, 0.8, 0.73, 0.66, 0.59, 0.53, 0.48,...} and the output would never actually decay to zero.

To implement this exponentially decaying output, the only required calculation would be for the coefficient b, which sets the multiplicative step-size. We will still have the issue of the output never reaching zero. There are several ways to approach this, Nigel Redmon's implementation (see the Bibliography) solves the exponential decay issue and provides flexibility for many different curve shapes. It is also easy to modify. It, however, require a call problem unless you intend to modulate the segment durations on every sample period, which is not recommended.

For the time constant multiplier of 5.0, we would only get down to the value 0.00673 at our normalized x = 1. But we could get the setup filter with a base or offset value x₀ that is subtracted from the output on each iteration that the output decays below zero, down to -0.00067, as shown in Figure 6.20. This way, we get the shape of that particular curve with a decay all the way to zero. The same applies to the attack curve, where iteratively multiplying a coefficient and adding offset will create an increasing curve that overshoots 1.0 by some amount instead.
