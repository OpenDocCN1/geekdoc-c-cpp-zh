Chapter 9 is a turning point in the book because all of the underlying synthesizer C++ objects are set in code and will not change. Here you design MiniSynth, the Analog Modeling synthesizer. You can deviate from the book, implementing your own synth voice objects and your model coding if you wish. In Chapter 10, you learn how to use audio files to import DigiSynth, a stereo playback synthesizer. Chapter 11 on Vector Synthesis uses the sample-based oscillators in the Vector project and includes a bonus project AniSynth, which is an interpretation of the Moog Anisynthhesizer Android app. In Chapter 12, you design a clone of the Yamaha DX100 FM synthesizer. Chapter 13 is the audio effects chapter that shows you how to add a delay of effects to MiniSynth, in you greatly extend your synth capabilities. Brief Appendix shows you how to convert your VST and AU Template into the base code for your project (this isn't needed by RackAFX if it creates your project for you).
