The idea is to take this impulse train it to produce sawtooth and square waves. For example, integrating the bipolar BLIT in a sawtooth wave produces a square wave, while doubling its discontinuity produces a triangle wave. The outputs of these oscillators feature a bit of ringing on the band edges. The three block diagrams are shown in Figure 5.5, and the integrators are simple Euler types. The aliasing is not eliminated with these simple BLIT algorithms.

More complex versions of BLIT can produce very good sonically but not as good as additive synthesis. BLIT has problems that make it one of the more difficult algorithms to implement. This can be problematic Using first generation of the BLIT sequence itself. Using the sinc() function would require two calls to the sinc() function. The BLIT sequences are generated with:

```
sinc(ex)
sinc(x/M)M(x/M)
M = number of harmonics
(5.3)
```

Another idea is to sample a sum of windowed sinc() functions and store them in a set of tables corresponding to different fractional shifts of the impulse. This is necessary because the period of the desired waveform may not be an integer multiple of the sample rate. The tables would need to be recomputed at runtime. This is known as BLIT-SWS.

A larger issue is that the bandlimited overlaps, and the tail of one must be mixed with the head of the next. This requires knowing when the discontinuity is to occur and requires a look-ahead delay. This is problematic because we would like to have zero delay in synthesizing the waveform. The bandlimited impulse has be generated for every discontinuity, as the frequency becomes higher, the CPU usage increases. As Airy points out, another issue with these methods is that the integration steps in BLIT and BLIT-SWS introduce an unwanted and undesirable DC offset in the signal when the oscillator starts.
