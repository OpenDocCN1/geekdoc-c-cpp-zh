# 13.3 The CDelayLine Object

The CDelayLine object handles the low level operation of a single delay with no feedback and no wet/dry path. It is only the delay line core. You can use this object (or many of them) to create complex delay effects. We will use two of these objects as another C++ object called CStereoDelayFX, which you use as the basis for a large and robust set of delay effects if you are so inclined.
