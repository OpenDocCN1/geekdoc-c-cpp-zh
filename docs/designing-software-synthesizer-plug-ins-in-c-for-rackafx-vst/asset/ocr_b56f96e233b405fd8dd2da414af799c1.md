This clipping produces the limiting function but also adds its soft clipping distortion, and the Karg35 filters are known for their outputs at high resonance settings. In our Virtual Analog model of the Karg35, we use VA blocks with the LPF and HPF components in a delay-less feedback loop. The addition of the nonlinear processing (NLP) of the feedback loop causes a very tuning drift, however it is negligible as long as we use a clipping function. Figure 7.13 shows the nonlinear model. Note that the NLP is placed before LPF2; this is because of way the conceptual bandpass filter works in the feedback loop. LPF2 forms half of this bandpass filter, and the signal needs to be saturated to the loop and thus prior to this

The synthesis of the Karg35 LPF begins with labeling the input and output nodes of all filters. Next, the VA equations can be extracted from the cascades of filters. Then, the delay-less feedback path through the BPF can be resolved, and we can get a single VA equation to describe the complete filter. An example of this technique was shown in Chapter 4; if you intend on designing the filter, please review this example.
