The ProphetVS and Wastestation allow you to program a path consisting of four segments that correspond to the traditional attack, decay, sustain and release components of an EG. RackFX's built-in path program allows up to 15 segments, and the optional vector path generator object (available for all APIs) gives you unlimited number of segments.

The programmed path in Figure 11.11(a) is only one type. In this simplest case, the mix vector stops at vertex 0 during the note on, travels through the path terminating at vertex 4, and stays until the note is released. If the note is released after the path is finished, it simply stops. This is one of the modes in VectorSynth. The ProphetVS and Wastestation do not feature this path; instead their pathing is to move the first three segments as then stop at vertex 3 and stay not off, when the path moves into the last segment, as shown in Figure 11.11(b) (adapted from the WastestationSR Player's Guide).

Both VectorSynth and AnySynth feature this mode of operation, called sustain mode, and the second-last vertex in the joystick program is used as the sustain path. In addition to the normal sustain mode, the ProphetVS and Wastestation offering loops options. For example, moving through the path to vertex 3 and sitting on it during the sustain path, you could move to vertex 3 then loop back over some or all of the previous segments, as: 0->1->2->3->2->3->2..., where you are looping back and between vertex 2 and 3 the sustain path.

# 11.7 Orbits and Orbits

You can modulate the (x,y) coordinates of the joystick with LFOs, envelope generators, MIDI note numbers or other modulation sources. The ProphetVS and Wastestation allow you to modulate the x and y coordinates independently. For example, you modulate the x coordinate with an LFO and leave the y coordinate alone. This would shift the joystick from left to right as shown in Figure 11.12 (the joystick could be anywhere; it is located at (0,0) in this example).
