# 5.5 Quasi Bandlimited Oscillator Algorithms

Now we can focus on the pitched oscillator designer. There are two directions we can take with regards to aliasing: eliminate it or allow it to happen if the aliasing components are sufficiently low in level (especially near Nyquist) and relatively far from the fundamental frequency. To eliminate completely requires additive synthesis, which could be done in real time as events occur, or could store the waveform in a table and use synthesis, which is covered in the chapter. The problem with pure additive synthesis is that it is computationally expensive. Even though the trigonometric functions like $\sin(x)$, $\cos(x)$ and $	an(x)$ are very efficient on modern desktop and laptop systems, a low pitched oscillator like note A0 (the lowest note on a piano) is 27.5 Hz and has 800 harmonics before reaching Nyquist. This would result in 801 cases for a sawtooth or 800 from a single-source waveform. Bandlimited de facto standard in synthesis design has decades issues. The value (also caused by a phase increment) if the phase increment is greater than one sample, is not guaranteed to be bandlimited for non-sinusoidal waveforms. We will cover this in the chapter.

The idea for quasi bandlimited designs is relatively new. These designs seek to create alias-suppressed oscillators in which we tolerate some aliasing. It is especially attractive when the quasi bandlimited algorithm is simple and requires no trigonometric functions, table lookups, look ahead or other examples. The different algorithms focus on the discontinuities in the edges of the waveform.
