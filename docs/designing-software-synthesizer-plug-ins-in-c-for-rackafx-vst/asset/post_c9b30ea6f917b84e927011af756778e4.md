# 8.7 More MIDI Modulation Routings

In this section we will add all the rest of the MIDI modulator routings that each synth will possess. This includes adding key-velocity to DCA routing so that your synth becomes velocity sensitive. Table 8.4 lists the new modulation routings.

The first four rows are fairly self-explanatory—we want to map Velocity to the DCA velocity input, the Pitch Bend we to the oscillator pitch, and MIDI volume and pan controls (CC7 and CC10 respectively) to the DCA volume and panimod inputs. The sustain pedal transmits a value that is either below 64 (off) or equal to above 64 (on). The MIDI to On/Switch handles this simple technique.

These are not the only routings—you can get very clever and expressive here. For example, you could add a row that lets MIDI Velocity alter the cut-off frequency so that the cutoff moves up with increasing key velocity. Using the MIDI note as a modulation source is extremely popular as well. The last two routings are more advanced because they are Layer 0 modulations. These modulation need to be applied to the Envelope Generator(s) before the EGs write their outputs.
