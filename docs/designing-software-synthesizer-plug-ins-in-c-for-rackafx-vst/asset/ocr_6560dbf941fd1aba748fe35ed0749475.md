See the website https://code.google.com/p/music-synthesizer-for-android/Dx7Envelope for a complete description of the Yamaha DX7 envelope implementation. The EG has an extra segment and uses rates rather than absolute times to program itself. It allows you to start or end the EG on non-zero values. The description at this is extremely detailed, showing how counters and offsets are used to produce the linear-in-dB release and decay segments. There is also in interactive applet to generate EG curves. Use this information to make an accurate DX7 EG—you can use it in our DXSynynth project.
