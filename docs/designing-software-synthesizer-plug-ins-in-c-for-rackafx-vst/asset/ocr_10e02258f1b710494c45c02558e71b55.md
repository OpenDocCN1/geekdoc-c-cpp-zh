Second order filters can be synthesized from any second order block diagram containing scalar multipliers, summers and integrators. Interestingly, there are many analog block diagrams that produce the same transfer function. Historically, analog filtering books categorize and list the pros and cons of using different structures. Lindquist’s ‘Active Network Design with Signal Filtering Applications’ tabulates scores of different filter structures, equations and block diagrams. Some of the are more sensitive to errors in the filter components (the real world, non-ideal values of the R, L’s or Cs). Others allow the cutoff or the Q of the filter to be controlled by a single gain factor. In analog design, choosing the proper structure simplifies the problem at hand, so there isn’t necessarily an algorithm that everyone agrees on. However, there is a structure that is especially popular with audio designers called the State Variable Filter or SVF. It is also known as the Kerwin-Huisman-Newcomb (KNH) filter,, after its inventors. One of the interesting features of this filter topology is that it directly implements the four-mother filters, the second order LPF, HPF and BPF. The BSF can be calculated by summing the LPF and HPF outputs. Figure 4.19 shows the block diagram of the SVF filter that you can find in just about any analog filter theory book. The derivation of the transfer function from y_LP is done later in the Chapter and produces the standard order LPF function; you could also start with this function and work your ways backwards to this diagram.
