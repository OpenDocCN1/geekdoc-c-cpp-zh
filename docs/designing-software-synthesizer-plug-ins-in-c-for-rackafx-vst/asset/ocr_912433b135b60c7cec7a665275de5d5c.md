# 2.8 Designing the User Interface in the Prototype Phase

Each project starts with a GUI table that lists all the interface controls and underlying parameters that they control. In RackAFX, each control is automatically connected to a variable that you define. RackAFX writes the code for you. In VST3 and AU, you must manually define each of your controls programmatically. In RackAFX, you use the control designer. When you create a new project or open an existing one and the compiler has started, you will be able to add controls. The paradigm is to right-click on a control to set up or alter it. All the synth projects contain three basic types of controls:

+   - continuous controls—values that are continuously adjustable float, double or int data types
- enumerated UINTs—these controls present the user with a set of strings; select one of these strings at a time
- on/offitches—a special case of the enumerated UINT where the enumeration is fixed and pre-set to only two values, OFF and ON

An example of a continuous control is a volume control in dB. A slider continuously adjusts a floating point variable that controls the amplitude volume. An example of an enumerated UINT is a GUI element that lets the user select the filter type from a list of strings like "HPF", "LPF", and "BPF". The reason we call enumerated is the string list is formed from an enumeration as:

```
enum
(LPF, HPF, BPF);
```
