synthfuncs.h: a collection of structures and functions that are used throughout the synth objects; you can add more of your own here,

pluginconstants.h: another collection of structures, functions and objects that are used in the synth projects

pluginobjects.cpp: the implementation of objects declared in pluginconstants.h

Download the MiniSynth project and open it in Xcode to see the contents. Let's first examine the file groups:

+   - AU Source: this contains the files for the plug-in object itself as well as a few necessary ancillary files

+   - MiniSynth: all the synth core files; these include the oscillators, filters, and envelope generators you develop first as well as specialized Voice objects

+   - CoreAudio: the base class files and their supporting files

+   - CocoUI: the GUI files including custom controls

+   - Resources: images for custom controls and backgrounds, the .NIB file and the .plist files for the project

+   - External Frameworks:

+     - AppKit

+     - QuartzCore

+     - CoreMIDI

+     - Cocoa

+     - CoreServices

+     - AudioToolbox

+     - AudioUnit

+     - CoreAudio

+   - Products: contains file references for the two output files, the .component and .bundle; you can right click on either or choose “Show in Finder” to locate them

Of these folders, you will be spending the majority if it in the AU Source group. Its files include:

+   - AUSynth.h and AUSynth.cpp: your plug-in object AUSynth; the name of this object does NOT change from one to the next

+   - AUStructures.h and AUSynthVersion.h: helper to split struct definitions and version information

+   - AUSynth.r: the project Rez file (this is only needed for backwards compatibility with Logic 9); it is now replaced by a Dictionary in your info file

+   - AUSynth.exp: the exported prems file (more on this shortly)

+   - AUSynth_Prefix.pch: the pre-compiled header that you can safely ignore

In the CocoaUI group, you can see the Objective-C files (.h and .m) for the GUI as well as the custom controls prefixed with AU Synth group: objects are all named according to the Synth project, directly with MiniSynth or with MS:

+   - MiniSynthFactory: the .NIB File's Owner that loads the View

+   - MiniSynthView: the custom view that the factory loads

+   - WRotaryKnobMS: a custom rotary knob control control

+   - WPEditBoxMS: a custom edit control
