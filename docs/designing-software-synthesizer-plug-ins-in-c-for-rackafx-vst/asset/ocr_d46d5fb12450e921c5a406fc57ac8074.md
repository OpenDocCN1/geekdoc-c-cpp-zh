RackAFX includes a built-in object named CJoystickProgram that encapsulates a vector joystick program with up to 15 segments. The object is programmed with a simple interface. The declaration is in plugin.h, and the implementation is in pluginobjects.cpp. For VST3 and AU users, we have created a similar object CVectorPathGenerator that may also use in RackAFX. You may program this object with code, but the function names are identical to CJoystickProgram, so it is simple to switch between them.
