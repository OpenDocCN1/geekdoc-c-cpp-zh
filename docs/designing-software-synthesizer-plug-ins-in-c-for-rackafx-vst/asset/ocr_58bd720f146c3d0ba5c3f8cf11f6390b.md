All oscillators are derived from an abstract base class called COscillator. The base class object will also handle updating and calculating all variables, as well as modulating the oscillator's frequency (both linear and exponential), phase shift(for modulation), pulse width, and anything else we decide to add at a later time. Since all oscillators are derived from it, this needs to have attributes and member functions that are common to most of the derived classes. As is typical in C++, if we need some functionality that is not common to the other oscillators, we will subclass an existing object and add the functionality. We do this in Chapter 11.
