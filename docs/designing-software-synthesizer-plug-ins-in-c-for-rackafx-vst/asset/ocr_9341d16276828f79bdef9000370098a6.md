Multidimensional arrays can be tricky in C/C++ when you want to pass a pointer to an array as a function argument. Therefore CVectorPathGenerator uses a classic programming trick where we flatten the array as a single dimensional chunk of memory, arranged as concatenated table rows (this is how the compiler usually does too). A macro is defined that allows you to find cells in array. The macro is JS_PROG_INDEX:

```
#define JS_PROG_INDEX(x,y) (x)+(MAX_PROGRAM_STEPS*(y))
```

For example, the array is named m_pVPGProgramTable, you would find the cell at row 2, column 5 as:
AC_Mix = m_pVPGProgramTable[JS_PROG_INDEX(2,5)];
