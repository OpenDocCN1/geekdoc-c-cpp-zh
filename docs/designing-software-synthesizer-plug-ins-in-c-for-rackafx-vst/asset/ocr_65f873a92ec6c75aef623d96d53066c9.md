# CStereoDelayFX Member Functions

| Function Name | Description |
| --- | --- |
| setMode | sets the mode variable |
| setDelayTime_mSec | sets the delay time variable |
| setFeedback_Pct | sets the feedback variable |
| setDelayRatio | sets the ratio variable |
| setWetMix | sets the wet mix initialization function |
| preparePlay | one time initialization function |
| reset | flushes and resets the two delay lines |
| update | decodes the mode variable and sets the two delay times on the two delay line objects |
| processAudio | performs the effect |

Like the CDelayLine object, CStereoDelayFX is also a short and simple object. You can add modes of operation, more delay lines, or even filters and other processing components to the object. The plug-in will need new controls to go along with the object: delay time, feedback, delay ratio, wet/dry mix, and delay mode. These controls call the five set() functions you see in Table 13.4. # reset()

The reset() function simply calls the resetDelay() on the two member objects.

```
CStereoDelayFX::CStereoDelayFX(void)
{
    // -- zero everything
    m_dDelayTime_mSec = 0.0;
    m_dFeedback_Pct = 0.0;
    m_dDelayRatio = 0.0; // 1:1
    m_dWetMix = 0.5; // 50%
}
```
