The Fast Fourier Transform (FFT) is identical to the DFT in output. The difference is in how it is computed. Mathematicians J. W. Cooley and John Tukey derived the FFT in 1965 as a way to compute the DFT more efficiently. It takes advantage of similarities in the factors that are used in the calculation to form a recursive solution. In some books, DFT and FFT are used almost interchangeably.

## 1.12 Laplace and z-Transforms

Referring back to the Fourier series rules, there are two that might bother you. The signal to be decomposed must:

- have been in existence for all time up to negative infinity
- remain in existence for all time—forever

If you remember from Figure 1.16, the sinusoidal components also exist forever in both directions and at the same amplitude. It turns out regarding the Fourier transform is a specialized case of the Laplace transform. Laplace replaced the met restrictions regarding the constant amplitudes of the sinusoidal components, which allows for many more types. In theory, the input signal could have a definite beginning, middle and end, and its frequency components could go and over time. The Laplace transform replaces the Fourier kernel $e^{-jwt}$ with a more general version $e^{-(\sigma+j\omega)t}$ that allows the sinusoidal components to exponentially increase, remain flat (as in Fourier) or exponentially decay in time. The real coefficient $\sigma$ governs the behavior of the sinusoid's shape in time.

The Laplace transform is:

```
F(s) = \int f(t)e^{-st}dt
s = \sigma + j\omega  (1.12)
```

The discrete version of the Laplace transform is the z-Transform. In the z-Transform, you let $z = e^{ST}$ where $T$ is the sample period; we need to do this to get out of the continuous time domain $t$ and into the discrete domain $nT$. This yields:

```
F(z) = \int f(t)z^{-t}dt
F = \sum f(n)z^{-n} (1.13)
```

The z-Transform is a kind of keeping-or substitution transform that is clever—by making the simple substitution of $z = e^{ST}$ arrive at a sum involving a rational function in $z$ instead of the irrational $e^{ST}$. This means the z-Transform produces a simple polynomial or ratio of polynomials in $z$ that obey all the laws of polynomial math, making it easier to work with. It can also operate over a fixed duration rather than an infinite period.

Consider the $z^{-n}$ terms—what do they mean? Using polynomial math:

```
z^n = e^{sn}
z^{-1} = (e^{ST})^{-1} = e^{-ST}
z^{-2} = (e^{ST})^{-2} = e^{-2ST}
etc... (1.14)
```

The $T, 2T$ and $3T$ values represent 1, 2 and 3 sample intervals. The negative signs denote them as past sample intervals; a positive sign indicates future sample intervals that are not realizable in real-time, so you won't see them in this book. This is astonishing because multiplication by a simple term $T^{-n}$ understand this, consider the two sinusoids in Figure 1.21. One of them is delayed by $n$ samples.

If we can describe the first sinusoid as $e^{jwt}$ then the delayed version is $e^{jwt(t-n)}$. Because at time $t=0$, the first sinusoid starts, and its complex value is $e^{j0}$. At time $t=n$ samples, the second sinusoid starts. Its complex value must be the same as this first starting point, $e^{j0}$. The only way this will happen is if we modify the exponent as $e^{jwt(t-n)}$, so when $t=n$, the result is $e^{j0}$. Looking at the $e^{jwt(t-n)}$ term and remembering the polynomial behavior of the example, we can write the following:

```
e^{jwt(t-n)} = e^{jwt}e^{-jwn}
```

The $e^{jwt}e^{-jwn}$ term is a phase shift. The $e^{-jwn}$ is a constant for a given $n$. Multiplying the signal by this constant will shift its phase without changing its amplitude. This is how the z-Transform represents delays.
