A simplified block diagram is shown in Figure 11.19. You can see that there is one LFO hardwired as a rotor, with normal and quad phase outputs connected to the vector mix generator. There are controls for rate, x-amplitude and y-amplitude. The rate is the LFO oscillator frequency, and the x and y values are the amplitudes of the normal and quad phase LFO outputs. In addition to the hardwired amp EG and filter EG, you also have a general purpose EG and LFO as modulation sources. The modulation matrix consists of four programmable rows, each with a source, control and destination.

With the slick touchscreen interface, the AniMooog takes the path/rotor concept up a notch by showing you the orbits of each note in different colors. The orbits chase each other around the path, looking like electrons orbiting nuclei that are constantly moving. For slow orbit rates, this produces a corkscrew trace; as you increase the orbit rate, the circular orbit becomes dodecahedral, then octagonal, and so on until it becomes a multi-pointed star. These visual cues aren't just there because they look cool—they tell you when the rate becomes so fast that wavetables are being skipped as the (x,y) position moves quickly. The orbits are also bound just like in the previous synths, but in this case, the outer rectangle that contains the grid. Figure 11.20 shows a slow orbiting rotor. ## 11.6 VectorSynth and AniSynth Path Modes

The joystick programmer is different between RackAFX and VST3/AU—part of the programmer is built-in to the RackAFX client. RackAFX uses a C++ object JoystickProgram that stores and executes the vector path generation. VST3 and AU use an almost identical object called CVectorPathGenerator that you may also use with RackAFX if you wish. However, both objects feature the same vector path modes, which are a mix of the path modes found in the ProphetVS and AniMoog.

Figure 11.21 shows the different modes. In both objects, the mix ratios morph linearly through the segments over the desired time.

### once

In once mode, the joystick moves along the vector path from end without pausing. When it reaches the end vertex it sits on it until the note event is over. If the note is mid-track, it simply follows the path until it hits the last vertex or the note event is over. This mode is taken from the AniMoog and is not available on the ProphetVS/Wavestion.

### loop

In loop mode, the joystick moves from the starting vertex to the ending vertex and loops back to the beginning over a predefined time. This mode contains a hidden segment—the segment from end to start, as shown in Figure 11.21. In loop mode the path never pauses. This mode is taken from the AniMoog and is not available on the ProphetVS/Wavestion.

Figure 11.21: The path modes for VectorSynth and AniSynth are once, loop, sustain and bckfrth.

### sustain

In sustain mode, the vector path will start from the beginning and move along until it reaches the second-to-last vertex in the program. It will pause the program and sit on this vertex until a note event resumes the program operation, at which point it will move along the final segment. This mode is taken from the ProphetVS/Wavestion and is not available on AniMoog.

### bckfrth (back and forth)

![](img/b42d0dca53f4a889d8162d55f7c8c05d_740_0.png)

In Bckfrth, the vector path starts at vertex 0 uninterrupted to the final vertex, where it turns around moves backwards to the starting vertex 0, reverses direction again and moves towards the last vertex. This operation repeats and the program progresses. This mode is taken from AniMog and is not available on the ProphetVS/Wastvation.

## 11.7 The Vector and JS Program in RackAFX

RackAFX includes a vector joystick control in the classic ProphetVS/Wastvation orientation, a square turned on and shaped like a diamond as in Figure 11.22. The x-axis is A-C and the y-axis is B-D. The joystick is used to navigate the vector path. The values of the joystick represent A, B, C, and D, which are the mixes of the four oscillators.

The modulation matrix consists of four programmable rows, each with a source, control and destination. This allows you to map any modulation source to any parameter of the synth.
