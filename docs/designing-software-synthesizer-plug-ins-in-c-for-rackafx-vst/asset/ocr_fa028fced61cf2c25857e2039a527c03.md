prepareForPlay(), you initialize the sample rate of the voice objects and call each one's prepareForPlay(), which initializes them. The voice objects are NOT derived from CPlugin—we just named the one-time-init function the same to make it easy to remember. After this, you call the update() method to update each voice's internal variables and reset the last note frequency we will use for portamento/glide effects.
