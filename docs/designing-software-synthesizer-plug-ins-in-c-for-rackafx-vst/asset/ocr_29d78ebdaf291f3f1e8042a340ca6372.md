Multidimensional arrays can be tricky in C++ when you need to pass a pointer to the array as a function argument. Therefore CJoystick uses a callback programming trick which we flatten the array as a single-dimensional chunk, which the compiler usually does it too). A macro allows you to easily find cells in the array. The macro is called JS_PROG_INDEX:

```
#define JS_PROG_INDEX(x,y) ((x)+(MAX_JS_PROGRAM_STEPS(y)))
```

For example, if the array is named m_pJoystickTable you will find the cell at row 2, column 5:

```
fAC_Mix = m_pJoystickTable[JS_PROG_INDEX(2,5)];
```
