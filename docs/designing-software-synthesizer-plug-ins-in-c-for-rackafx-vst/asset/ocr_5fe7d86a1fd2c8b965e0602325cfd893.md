# 2.42 WRotaryKnob

The WRotaryKnob object consists of three controls: a static text label that is the control name, a knob that rotates as the user drags it over it and an edit box that displays the current value. This is depicted in Figure 2.48.

The user can also type a value into the box and hit , and the knob will rotate to the updated position. In way, precise values may be entered. This is also a custom control of type WPEditBox. The WRotaryKnob object is derived from Controls and the WPEditBox is derived from NSTField.
