PolyBLEP removes the need for a table and produces offset values with simple second order equations, one for the left and the other for the right. For memory constrained devices, such as mobile phones and tablets, PolyBLEP might make a nice alternative, as it requires no lookup at the expense of a bit more aligning. Our bandlimited oscillators default to normal BLEP, but we implemented both BLEP and PolyBLEP for your experiments. You can also generate your own polynomials; once you have a good residual table, you might enter some of your data points into a polynomial curve-fitting algorithm and come up with your own polynomial equations that approximate the residual curves. # 5.10 Coding the BLEP and PolyBLEP Algorithms

The BLEP and PolyBLEP functions are quite similar. They both need to do the following:

+   * identify when a trivial sawtooth point is in the transition region around the discontinuity
* identify whether the point is on the left side of the discontinuity
* measure the distance from the point to the discontinuity

+   * lookup the residual offset value from a table (BLEP)
* calculate the residual offset value from polynomial equations (PolyBLEP)

Our BLEP and PolyBLEP functions will be used for sawtooth waveforms, where the edge is where the modulo controls over the value 1.0. For a sawtooth, the edges are always falling, for an inverted sawtooth they are always rising. Their amplitude is 1.0. If you want to use the BLEP or PolyBLEP functions to process discontinuities that are at some location other than the modulo 1.0, will need to make some minor alterations to these functions. You can get more information at http://www.willpirinkle.com/synthbook/
