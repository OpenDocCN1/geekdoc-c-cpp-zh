# 11.18 AniSynth Specifications

Figure 11.40 shows AniSynth's simplified block diagram. It is identical to VectorSynth, except that the matrix of wavetable feeds the oscillators A, B, C, and D.

Figure 11.41 shows how the 36 wavetables are mapped to the joystick control. When you move the joystick, the mix surface is much more dense, with eight times as wavetables.

![](bbox=[0.328, 0.253, 0.952, 0.483])

The wavetables are indexed with 0 and advance through consecutive rows as shown in Figure 11.40. AniSynth really differs from VectorSynth in the rendering and loadSamples() functions. The GUI and modulation matrix are identical, so you can either modify VectorSynth or use it as a basis for AniSynth. To demonstrate another filter, you use the diode ladder filter in this project.

# Oscillators:

+   - four CSampleOscillators, which each play back one of 36 different wavetables; each wavetable is extracted from a .wav file

# Filter:

+   - two CDiodeLadderFilters (for one, left for right)

# LFOs

+   - two CLFOs, one general purpose and for the rotor

AniSynth does not pre-define any CSampleOscillators the way VectorSynth does. Instead, it operates off an array of CSample oscillators. It keeps track of the current active cell. The CAniSynthVoice switches out the four oscillator pointers as different cells become active. This is shown in Figure 11.42. This version of AniSynth uses single-samples and not multi-samples.
