## 11.8 The Joystick in VST3

So far, all of the controls we've used in VST have been limited to knobs and option menus. Groups controls automatically connect to a index value (tag), and they generate a single value per control. The joystick presents a bit of a problem because we need to generate two signals, one for the x-coordinate and one for the y-coordinate. These two signals automatically control Parameter objects to create the x and y coordinates of the joystick. As usual, this requires index values that we place in the control SynthParams.h.

```cpp
VECTORJOYSTICK_X
VECTORJOYSTICK_Y
```

VSTGUI has a built-in C++ object for the GUI control called CYPad, a two dimensional track-pad style control—with a joystick rotated by 45 degrees. In order to get two values of the control, you need to use the VSTGUI sub-controller feature. A sub-controller is a C++ object. VGUI comes with a built-in C++ objects for some of the common controls; you can also write your own. VSTGUI provides you with an object called PadController. Its functionality is coded in vstpadcontroller.h and vstpadcontroller.cpp, you don't need to edit any of it. You connect the C++ pad object to the CYPad GUI control and then pass pointers to the Parameter objects you created during initialization.
