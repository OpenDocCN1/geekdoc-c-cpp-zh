# Incrementing the Program

You have to increment the program on each sample interval to update the new vector mix. After incrementing the program, you can query it for the new vector mix. These two steps always go together.

```

fBD;
m_pJSProgram->incTimer();
// uses pass-by-reference to set our vars with
```

That's all there is programming the joystick path in RackAFX. The program is deleted when the plug-in is destroyed.

# 11.8 The Joystick in VST3

So far, all of the controls we've used in the VST3 projects have been limited to knobs and option menus. Groups controls automatically connect to a index value (tag), and they generate a single value per control. The joystick presents a bit of a problem because we need to generate two signals, one for the x-coordinate and one for the y-coordinate. These two signals automatically control two Parameter objects to create the x and y coordinates of the joystick. As usual, this requires index values that we place in the control enumeration SynthParams.h.

```
VECTORJOYSTICK_X
VECTORJOYSTICK_Y
```

You declare and create these in Controller::initialize(),along with the other controls.

VSTGUI has a built-in C++ object for the GUI control called CYPad, a two dimensional track-pad style control—with a vector joystick rotated by 45 degrees. In order to get two values of the control, you need to use the VSTGUI sub-controller feature. A sub-controller is a C++ object. VGUI comes with a built-in C++ objects for some of the common controls; you can also write your own. VSTGUI provides you with an object called PadController. Its functionality is coded in vstpadcontroller.h and vstpadcontroller.cpp, you don't need to edit any of it. You connect the C++ pad object to the CYPad GUI control and then pass pointers to the Parameter objects you created during initialization. Setup this new custom joystick control is a two-part process.
