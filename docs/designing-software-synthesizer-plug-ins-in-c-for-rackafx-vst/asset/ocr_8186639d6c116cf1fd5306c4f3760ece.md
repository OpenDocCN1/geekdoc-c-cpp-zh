With this, the final form of the order VA lowpass filter is synthesized and shown in Figure 4.17, and you can see that v = G(x - s). This is accomplished by relocating the synthesized feedback path from the output of the filter to the output of the delay element s(n).

The importance of the linear y = Gx + S relationship can never be stressed enough. Think about this: we took an integrator with output y = gx + s, stick it inside a delay-feedback loop and get an output that can be expressed as y = Gx + S. What do you suppose if we had this lowpass filter and stick it inside another delay-feedback loop, or if we took a series of these and stuck it inside a delay-feedback loop? Would it surprise you the output always winds up in the form y = Γ + Σ (Γ and Σ represent some generic G and S values)?

The effect of choosing the bipolar integrator is that the resulting filter behaves identically to the BZT-to-biquad approach—it is also a bilinear filter, but without applying the BZT transfer function. It also requires the pre-warping of the filter cutoff frequency. The complete calculation of the single coefficient G is:

```
double wd =
2*pi*Fc;
double T =
1/SampleRate;
double wa =
(2/T)*tan(wd*T/2);
double g =
wa*T/2;
```

Look at the difference between the VA LPF in Figure 4.17 and the direct form (half biquad) filter in Figure 4.10. The VA version only has one coefficient to calculate using only one trig function, tan(), and it only requires memory location. This is a significant advantage for speed of implementation. There are other advantages, too, regarding sensitivity of the filter to rounding errors in the coefficients.
