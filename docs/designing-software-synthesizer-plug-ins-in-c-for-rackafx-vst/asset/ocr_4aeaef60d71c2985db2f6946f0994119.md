The term b1 is called coefficient, and the denominator is a first order polynomial in s.

Applying the bilinear transform by replacing s with (z-1)/(z+1) results in a transfer function H(z):

```
H(z) = \frac{a_0+a_1z^{-1}}{1+b_1z^{-1}} \quad (4.15)
```

The T/2 term in the bilinear transform equation washes out. The terms a0, a1, and b1 are called the coefficients of the new transfer function and are intimately related to the cutoff frequency fc. You may see a vague resemblance to the analog transfer function, but the b1 is not simply equal to RC as it is in the analog version. This results in the digital block diagram shown in Figure 4.10.

The equations for the coefficients are:

```
\theta_0 = 2\pi f_c / f,\n\gamma = \frac{1}{1+\sin\theta},\na_0 = \frac{1-\gamma}{2}, \quad a_1 = \frac{1+\gamma}{2}, \quad b_1 =-\gamma \quad (4.16)
```

When the user changes the fc control of the filter, these coefficients must be recalculated. Additionally, two memory locations are used to implement the two delay blocks. Interestingly, this transform a transfer function that had a first order denominator is turned into one another with first order numerator and denominator; the transfer function is still first order.

Higher order analog filters will result in higher order digital transfer functions. A second order lowpass filter (H) will result in a second order H(z) that is described as:

```
H(z) = \frac{a_0+a_1z^{-1}+a_2z^{-2}}{1+b_1z^{-1}+b_2z^{-2}} \quad (4.17)
```

Since both the numerator and denominator are quadratic equations, this is called a bi-quadratic transfer function or simply a "biquad". The block diagram for the biquad is shown in Figure 4.11. You can see that this structure adds two more coefficients and two storage locations to the first order version. The calculation of coefficients will again involve trig functions and algebra.

Because the resulting higher order bilinear z-transformed filters are sectioned into bi-quadratic pieces, we call this "BZT-to-biquad" method. The BZT is covered in detail just about every DSP book on the market, there is plenty of information out there if you are interested.

# 4.7 Virtual Analog Filters

The term "Virtual Analog" has some variations; it might mean a filter that has been designed using digital components that mimic mimic one and two-port networks (part of analog filter theory) and implement analog circuits in a digital fashion called Wave Filtering. For others it might mean a filter whose frequency response is virtually identical to an analog filter's response. Some engineers restrict Virtual to mean the design of filters based on non-linear analog circuits. In this book, Virtual Analog (VA) filtering refers to the algorithms designed using a two-part technique: analog to digital integrator and resolution of delay-free loops.
