# 13.2 Delay Effect Topological

Our delay effect includes two structures, for the left and one for the right. These are basic delay lines with feedback. A single delay line with feedback is shown in Figure 13.6. The delay implements $z^{-D}$ or $D$ samples of delay, and it is a circular buffer. Notice that the value into the delay line is a sum of the input $x(n)$ and the current output $y(n)$, scaled by a feedback value. This leads to the paradigm “read before write,” which we use on all delay effects. It means that we read the feedback value first, then the input + feedback into the delay line. The user can adjust the delay from zero to some maximum that we choose (2 seconds). When the user changes the delay line, they are really changing the distance between the right and write index values. In our plug-in, the delay object will handle this wet/dry mixing.

In order for the delay to be interesting, we need to add the dry unprocessed signal to the delayed output. In our systems, the wet/dry mix is part of the main voice or plug-in. Our delay object is fully self-contained. Figure 13.7 shows the basic stereo delay with feedback and wet/dry components.

We can spin off variations on the basic delay, giving our delay effect with four different algorithms. The first is the stereo delay. We allow the user to adjust the delay between left and right as a ratio. The second is the ping-pong delay shown in Figure 13.8. The ping-pong delay crosses both the input and feedback paths to the opposite channel. It produces a circular kind of delay sound that starts in the center, moves to one side, then other back to the center where it starts over. A key ingredient is the ability to set the delays as ratios of one another. When the ratios are perfect (1:2, 3:5, 8:7, etc.), the effects become even more rhythmic in nature. So, we can re-use the ratio control in the ping-pong delay.
