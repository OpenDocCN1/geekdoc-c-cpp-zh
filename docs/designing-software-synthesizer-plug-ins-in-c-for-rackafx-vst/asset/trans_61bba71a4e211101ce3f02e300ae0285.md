# doVoice()

doVoice() 是所有函数中最重要的，因为它实现了渲染，而且它与 NanoSynth 的渲染代码几乎相同。调制层是相同的，唯一的区别在于音频引擎中的布线。注意音频引擎中对音高振荡器的基类调用以及求和前的缩放。

# reset()

在 reset() 中你首先调用基类，然后配置振荡器类型并清零滑音时间。
