# Shaping

Wave shaping uses a non-linear function to process and deliberately distort an input signal. We will use in Chapter 5 to change the shape of an oscillator's output. All of the filters in Chapter 7 have a NonLinear Processing (NLP) block that may be enabled. This saturates the signal with a soft clipping. In several of the filter models, the clipping comes from diodes in the original analog circuits. In others it is built into the analog circuit equations, specifically as the hyperbolic tangent function, tanh(). There are many wave shaping functions to choose from. From more harmonic distortion then we will be specifically focusing on soft-wave shapers, which produce less distortion and attempt to limit the signal in a way that is still pleasing to the ear.
