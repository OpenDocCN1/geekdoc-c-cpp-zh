# Logic

The note on logic is based on what we use in NanoSynth, plus the portamento. The logic also handles voice stealing. Figure 9.8 shows the flowchart. A note is considered to be available if no note is playing and note is pending. In this case you set the event flag, calculate start pitch (if using portamento), and start up the oscillators, EGs and LFOs. If the voice is stolen, you first store all the pending note information and set the pending flag. An issue arises if the voice being stolen is currently in the middle of a portamento glide. In this case, the increment value is calculated from the semitones between the current oscillator pitch and the target pitch. Lastly, you shut down the EGs for the steal stage.
