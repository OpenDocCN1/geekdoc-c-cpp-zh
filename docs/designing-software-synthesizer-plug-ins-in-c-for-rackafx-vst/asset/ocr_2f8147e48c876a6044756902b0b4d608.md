# 4.8 Analog Block Diagrams

In this approach, you start with the analog circuit's differential equation, produce a block diagram and take the Laplace transform of its equation to get the transfer function H(s). Start with the same RC lowpass filter, shown in Figure 4.9. A simple way to approach this circuit that many electronics books use is based on the voltage divider equation and the impedances of the elements to produce a transfer function.

```
y(t) = x(t)\frac{Z_C}{Z_R+Z_C}\nx(t)\frac{j\omega C}{R+\frac{1}{j\omega C}}\n\frac{1}{RC}(x(t)-y(t)) \int \frac{1}{RC}(x(t)-y(t))\nx(t)-y(t)\frac{1}{RC}\int y(t)
```

Figure 4.12: The block diagram for the analog RC filter.

```
H(s)=\frac{Y(s)}{X(s)}=\frac{1}{R+\frac{1}{sC}}\n\frac{1}{sRC+1}\nH(s)=\frac{1}{s/\omega_c+1}\n\omega_c=\frac{1}{RC}(4.18)
```

By letting RC = 1, $f_c = 1$, we get the normalized transfer function:

```
H(s)=\frac{1}{s+1}(4.19)
```
