The problem with nonlinear wave shaping is that it will always cause aliasing in the signal. If the nonlinearity is small,
this not be a problem. However if the saturation variable is increased, or a more nonlinear function is used, the
aliasing effects will begin to stand out. How to mitigate this is oversampling techniques.
