The CVoice object will test the oscillator and filter before using them, so setting the second filter pointer to NULL disables it. If you decided later to change the oscillators to CWaveTable and the filter to CDiodelFilter, you just change the declarations in the .h file and everything else is done automatically. Notice that the filter is named m_LadderFilter as a reminder of its type, however you might choose m_Filter1 or like to make switching objects easier in your designs. The CVoice object contains all necessary member variables and functions for basic voice operation. Table 9.1 lists the member variables and functions. Don't be intimidated by the number of variables—the derived classes, where you do most of the coding, are simple in comparison. Notice that the CVoice base class is set up for hard sync operation with the addition of a single parameter m_dRatio—this was a challenge from Chapter 5. If you are experimenting with hard sync, you can use this built-in variable; it is not used in the MiniSynth project.
