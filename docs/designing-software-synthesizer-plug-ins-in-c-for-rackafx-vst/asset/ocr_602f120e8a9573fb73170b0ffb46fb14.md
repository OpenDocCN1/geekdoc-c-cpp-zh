When we introduced the modulation matrix, we had to edit each synth object and add a stand-alone manner to use the modulation matrix if it is being used. The objects may still operate because left the other code. We will use the same strategy again for the global parameters; we will augment rather than replace code. This allows you to use the objects in other projects and plug-ins outside the scope of our synth projects.

Each of our synth objects requires the same modification for global parameters:

+   - declare a global parameter structure pointer; when NULL, global parameters are not used
- implement a init(GlobalParameters()) function in which you save your new global parameter pointer (thus enabling the functionality), and you initialize your synth variables
- use the global parameters in your update() function, where the object's parameters are updated based in (in part) on GUI control values
