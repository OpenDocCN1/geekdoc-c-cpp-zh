# readSampleBuffer()

This function reads and interpolates samples from a wave data buffer. It handles both mono and stereo file buffers and uses the same technique you saw in the CWaveTable object. It is nearly identical in core operation. For mono, it writes the left channel to the right output. You will see that this function mainly deals with indexing and bookkeeping and treats the buffer like a wave table.
