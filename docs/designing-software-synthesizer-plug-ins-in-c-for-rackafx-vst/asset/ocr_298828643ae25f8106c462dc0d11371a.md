Referring back to Chapter 1, the z-Transform is the discrete version of the Laplace transform, and it converts a signal or function whose dependent variable is discrete time n into a signal or function whose dependent variable is z. The z represents a complex frequency, which means that it can be described with real and imaginary components; this is indicated as z = a + bj or z = re + im. The input and output signals x(n) and y(n) are transformed into X(z) and Y(z). The transfer function is likewise denoted as H(z). The time domain of H(z) is h(n) and represents the impulse response of the system. The impulse response is applied at the input. For digital signals, the impulse is a single sample with value 1.0 in a stream of samples with value 0.0.
