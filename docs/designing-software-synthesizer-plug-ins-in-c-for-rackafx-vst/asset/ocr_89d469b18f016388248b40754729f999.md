# 10.9 The CDigiSynthVoice

The CDigiSynthVoice object implements the audio rendering; however, much of the object is devoted to initializing the oscillators either directly with files or folders or via sample and array sharing. The object provides both get and access to the sample and array pointers. The CDigiSynthVoice object is set up to access all oscillators, though we use only two in this design.
