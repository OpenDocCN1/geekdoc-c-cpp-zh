## prepareForPlay()

prepareForPlay() function is where you initialize the modulation source and destinations for all sub-components. This contains all the default wiring used in NanoSynth, as as every sub-component. It initializes the MIDI volume and pan values at power-on. In particular the part of DCA setup in the default EG MUST be done in the derived class. This is because not every synth (or) will use EG1 for the DCA output. And, in DXSynth, there are variable number of output EGs ranging from 1 to 4. This is the function you can change the default routing if you wish.

## update()

In the update() function you apply changes to the global parameters. This is called once per sample. It stores the voice mode and calculates a new portamento increment if portamento has changed (we will get to portamento shortly). The hard sync ratio is stored, but not used in the book. Notice that these variables are contained in the globalVoiceParams.

## reset()

The reset() function simply forwards the reset call to the sub-objects: In Voice.h you can find the remaining initialization and state functions.

## initGlobalParameters() and setModCore()

You initialize the voice-level and sub-component global parameters in this function. Most of the work is done in the sub-component initialization functions that you use last chapter. setModCore() you just forward the call to the mod matrix. The receiver will hold the mod matrix that is connected to its sub-components, and each voice has its own modulation.

## State Functions

There are state functions that you may need to override. All of our synths use DXSynth EG1 by default. These functions are used to query the mod state and note off operations. Refer to the EnvelopeGenerator if you need to: the EG is "active" if it is in any state except release, or releasePending, and canNoteOff() if it is in any state except release or releasePending. The voice is "done" when the EG is out of state.

## 9.3 Portamento

Many synths feature a portamento or glide. With this effect, triggered notes will not start at the MIDI pitch, but will glide smoothly up or down from the previously triggered note. The user controls the glide time. The pitch moves in an exponential manner as it does during normal modulation. It is ideal to someone using the pitch bend wheel or joystick—as they move the control, the pitch changes exponentially in a continuous or gliding. All the synths in this book will have built-in. The CVoice object is going to handle every bit of that, so won't have to re-code anything.
