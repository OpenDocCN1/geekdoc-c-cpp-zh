## update ()

The oscillator's function will be called on every sample interval. It is important to keep this code as short and efficient as possible. Do not allocate or destroy memory in this function, as these are CPU intensive. The update() function may be overridden in a derived class if necessary (which we need only in the wave table oscillator). The update():

- calculates the pitch shift multiplier for all oscillators except linear frequency modulation
- calculates the new fo based on the current node/frequency and all exponential modulation sources
- adds the linear frequency modulation value
- sets the current pulse value
- clamps the oscillator frequency and pulse width to the limit values

For the pitch calculation, we use the method of adding all modulations (in semitones) prior to calling the pitch multiplier function. The resulting offset is multiplied by the current oscillator pitch and the value ratio. The ratio value will be 1.0 except for the Synth, which oscillators are designed to operate at multiples of one another. Notice how the pitch is modulated first, then the linear frequency modulation after that.
