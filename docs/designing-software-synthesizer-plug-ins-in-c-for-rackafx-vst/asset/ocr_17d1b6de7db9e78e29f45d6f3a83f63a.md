# EnvelopeGenerator.h

In the EnvelopeGenerator.h file, you first #include the modulation matrix's .h file, then make declarations of the modulation matrix pointer, sources and destinations. For the EG we have:

Sources:

+   - EG attack scaling
- EG decay scaling

Destinations:

+   - normal EG output
- biased EG output

We are going to discuss the EG attack and decay scaling shortly. The destinations are simply the two outputs of the object.
