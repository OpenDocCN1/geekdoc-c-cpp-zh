# Diamond

You may recall from the last chapter that Yamaha briefly consulted with Dave Smith and some of the original vector synthesizer engineers and designers. The TG33 and SY35 were the result. These were hybrid synthesizers that combined FM/PM, sample playback, and vector synthesis into one product. FM/PM and sample playback oscillators are mixed with a vector joystick and pattern. Create your own version of this synth by combining the technology from the last chapters into one design.
