## 5.24 Sources of Modulation

## 5.25 Oscillator Starting Phase

For quasi banded oscillators, it is important that the phases of the oscillator line up properly with a sinus. This means the zeros at the half point line up, assuming 50% duty cycle for the square wave. The square wave already lines up properly, but the sawtooth and triangle wave do not. The zero crossing edge is 50% offset from the sinus or square. This means the oscillator's starting point needs to be the sawtooth and triangle waves will start with modulo=0.5. This is shown graphically in Figure 5.40. We will not implement this phase line for LFOs because we desire their shake, especially in one-shot. This is also not necessary for the wavetable since their location is based on an index and not a module value and banded wavetable are already aligned properly in Figure 5.40 (b).

## 5.26 LFO Features

For a LFO, the user is allowed to adjust the wavetable rate (frequency) and depth (amplitude) of the oscillator. Additional controls may also include:

- time delay before oscillations start
- fade-in (attack) time
- phase offset

Figure 5.40: (a) The outputs of the modulo generated sawtooth and triangle wave dont line up properly with the square and sinusoid (b) all phases are aligned with the modulo starting point offset to 0.5 for the sawtooth and the triangle.

![](img/b42d0dca53f4a889d8162d55f7c8c05d_281_0.png)

The time delay before oscillation and fade-in time mimics the way traditional musicians apply vibrato—they usually not begin it at the onset of the note event, but wait a while and apply it as the note is decaying or sustaining. Likewise, they often fade-in vibrato, increasing its intensity over time. Phase offset may be offset so that the oscillator starts at a non-zero value at some other starting point. These are optional, and you are encouraged to implement them as homework in the Chapter Challenges.

An important feature that we will add to our LFO objects is the ability to operate in three different modes:

- free-running
- synchronized
- one-shot

A free-running LFO starts oscillating at start-up or at the first note event occurs. After that, it free-runs and is applied as during subsequent note events. A synchronized LFO restarts from the beginning of each new note event. Its application will be digital each time a note is triggered; this is more useful for vibrato. A one-shot LFO outputs one cycle of the waveform and then off. This is an important method to implement because it is for creating drum and other transients. The exponential oscillator is often used in a one-shot LFO to create exponentially decaying pulse that may be used to modulate pitch, amplitude or cut-off of a filter, or all three at once.

In one-shot mode, it is important that we end the oscillator square with a value of 0.0. If the one-shot LFO does not end on 0.0, you will hear an abrupt change in the modulated parameter(s). The ramp and triangle waves will need to be adjusted to bipolar.

We also need to address the phase capabilities. With these, we make "90 degrees out of phase." We can accomplish phase inversion by simply multiplying the LFO output by -1.0, but quadrature phase must be implemented when we render the LFO output. It is actually simpler—just offset the modulo counter by 0.2 (1/4 of a period or 90 degrees) and perform the oscillator calculation.
