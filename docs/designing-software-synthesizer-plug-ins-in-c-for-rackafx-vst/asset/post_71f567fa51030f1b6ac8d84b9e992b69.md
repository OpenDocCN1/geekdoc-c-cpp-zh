The a and b coefficients represent the same sine and cosine harmonic amplitudes as before. The c terms represent the magnitude of each frequency component while the φ terms represent the phase offset of each component. Referring back to Figure 1.16 you can see that each harmonic component, including the fundamental, has a magnitude and phase that dictate its height and time offset.

Taking this one step, we can use Euler's identity (pronounced "Oiler"), which further links the sine and cosine into an orthogonal relationship as:

```
e^{jwt}=cos(wt)+jsin(wt) (1.3)
```

Orthogonal is usually defined as "related by 90 degrees," but perhaps a more intuitive definition might be "having absolutely not to do with each other; unrelated in the purest sense. Euler's identity is useful because it combines both sine and cosine in one equation, preserving their 90 degree relationship. More importantly, it is useful because it is mathematically discontinuous as it behaves like a polynomial; with calculus it is simple. The fact that the derivative and integral of e^at (either a or 1/a) by the original function is the reason we use it in the Fourier series. It greatly simplifies the solutions for frequency domain transfer functions that we observe in Chapter 4.

```
$e^{it}=\cos t+i\sin t \quad (1.4)$
$\frac{d}{dt}e^{at}=ae^{at} \quad \int e^{at}dt=\frac{1}{a}e^{at}$
```

So we can compact the Fourier series even more by using the complex sinusoid rather than sine, cosine, or phase shifted versions.

```
$f(t)=\sum_{n=-\infty}^{\infty} F_ne^{in\omega t} \quad (1.5)
```

Equation 1.5 describes a set (sum) of complex harmonics of amplitude $F_n$. Since the harmonics, $F_n$ actually contain both the magnitude and phase at the same time, coded as the real and imaginary parts of the complex sinusoid. This is why the summation term $n$ includes negative values. The magnitude and phase are still extracted with the same equations:

```
$|F_n|=\sqrt{Re(F_n)^2+Im(F_n)^2}$
$\phi(F_n)=arg(F_n)=\arctan\frac{Im(F_n)}{Re(F_n)} \quad (1.6)$
```

The real and imaginary components come directly from Euler's identity; the real components are the cosine amplitudes and the imaginary components are the same amplitudes. The phase portion is also called the argument or arg of the equation. If all of this real and imaginary stuff is freaking you out, check out Designing Audio Effects Plug-in in C++—it is in a friendly way to understand how.

There are several rules that must be obeyed for the Fourier series to hold true. The signal to be decomposed must:

- be continuous; no discontinuities or glitches
- be periodic
- have been in existence for all time until now
- remain in existence all time

The first limitation is not an issue for sampled signals that have been pass low filtered; the filtering would remove discontinuities. However, when there is a big one—must be periodic. If the signal is quasi-periodic or not periodic at all, like noise? Fourier answers with that the Fourier integral. It states that a quasi or non-periodic signal can be represented as a sum of harmonics; however, the harmonics not necessarily be mathematically related. As before, there might be an infinite number of mathematically related harmonics, but there also might be an infinite number of harmonics in the order ones. Fourier replaced the summation with an integral—the mathematical way of describing this uncountable number of harmonics:

```
$F_n=\frac{1}{2\pi}\int_{-\infty}^{\infty}f(t)e^{-in\omega t}dt \quad (1.7)
```

You can safely ignore the $1/2\pi$ constant. Here, the $F(\omega)$ term represents the harmonic amplitude for any frequency $\omega$. There are no subscripts $F(ju)$—that is, it exists for all frequencies $f(ju)$ from negative to positive energy. $F(ju)$ has a magnitude and a phase. The unique signal $F(\omega)$ is called the spectrum. Figure 1.17(b) shows the magnitude of the Fourier integral that represents some arbitrary signal $f(t)$ in Figure 1.17(a), this is a sketch and not mathematically exact. You can see that the spectrum can have both positive and negative amplitudes. We plot the magnitude or absolute value of the spectrum instead in Figure 1.17 (c). The dots at the points of the spectrum indicate that these theoretically extend out to positive and negative infinity.

When you see plots of spectrum in this book, you will always be looking at the magnitude plotted in dB). When you also see the spectrum and the magnitude are symmetrical about the y-axis. This is because the input signal $f(t)$ is real (has no imaginary components)—this will be the case with all our audio signals. You may also be disturbed by the fact that there are indeed negative frequencies in the spectra—in fact, for each frequency component will have an identical frequency over the negative side of the plot. Figure 1.17 is intentionally drawn to show how the magnitude produces the same picture, all positive. It also shows peaks (resonances) and notches (anti-resonances) because these are common in music signals. Books will show a much more generalized spectrum, usually bell shaped as in Figure 1.18 (a). Lowpass filtering this signal to the Nyquist criteria produces a clipped version of signal, also common in DSP textbooks. The clipped spectrum is said to be bandlimited.

Equation 1.7 shows a relationship between a continuous time signal and its continuous frequency domain spectrum. We can also go in the other direction and represent the spectrum as an infinite sum of time functions with Equation 1.8.

```
F(ω) = \int f(t)e^{-jωt}dt
```

Equation 1.7 is called the Fourier transform and it converts a function in $f(t)$ into a spectrum $F(\omega)$. Notably, Equation 1.8 is called the inverse Fourier transform since it performs the opposite function. The Short Time Fourier Transform (STFT) performs the integration over a finite time period between $t_1$ and $t_2$.

```
F(ω) = \int f(t)e^{jωt}dt
```
