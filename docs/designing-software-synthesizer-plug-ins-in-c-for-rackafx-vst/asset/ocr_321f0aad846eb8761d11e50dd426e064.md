# Outputs

The output controls for each operator work on the oscillator itself. For the stacked operators, tiny changes in the upstream modulators (operator three and four) can have big consequences on the overall sound. Also watch out for operator four's feedback—you can add a subtle transient to smooth bass sounds, or create parrot-squawing patches. For the parallel algorithms, the outputs blend the different frequency components. You can make xylophones easily turn chaotic by blending in carriers with non-integer ratios.
