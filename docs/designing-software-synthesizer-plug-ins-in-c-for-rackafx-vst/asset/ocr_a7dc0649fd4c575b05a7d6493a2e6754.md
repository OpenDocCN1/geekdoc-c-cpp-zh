Though the operation of the state machine seems to have many variables and methods. One thing you will learn that the EG's state is very important. It is well to determine if note events ended, or if the EG is capable of accepting a note event. There are also a lot of duplicate variables; each of the states has a set of variables to use in the calculation. Also notice the member variable m_bOutputEG, which is a flag that is set to true if the EG is connected to an output amplifier. When an EG connected to an output amplifier expires and goes into the off state, it is the signal that a note event is completely finished. It will play an important role when we make the synths polyphonic. The easiest way to understand the object is to step through the functions and discuss them.
