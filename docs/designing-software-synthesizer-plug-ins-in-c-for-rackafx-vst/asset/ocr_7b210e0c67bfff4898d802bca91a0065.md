# 7.26 Challenges

Bronze

The SEM filter's Q control adjusts from 0.5 to 25 but does not self-oscillate at the maximum value. Add the capability for self-oscillation when Q reaches this limit of 25. Hint: look at the equation for the R variable in the filter update() function and take the limit as Q goes to infinity. What value of R causes self-oscillation? Once you have it oscillating, enable the NLP and adjust the saturation control until it runs the way you like.

Sliver

Modify the CFter base class and any or all of the derived filters to implement a modatable Q control. You will be copying the same ideas for the cutoff frequency control except that Q modulates in a linear manner, so there is no volt/octave conversion needed. For this challenge, implement only a single modulation input as setModQ() and make sure to properly calculate the modulated Q value in updateFilter().

Gold

Give NanoSynth the ability to create multiple filter models and types. For example, you could use the Moog ladder filter with Oberheim harmonics to create a multi-filter.
