## 6.4 Note Off Modes

The release or sustain may get triggered before the EG has entered the sustain point represented by the "NOTE OFF" arrows in Figure 6.13. In this event, we use the last EG output as the starting point, and then descend the release or sustain segment from that. For our analog EG, this means that the release time will be longer if the note is released at a level above the sustain point and shorter if released below, as shown in Figures 6.13(c) and (d). This also tends to sound natural for many types of patches. In Figure 6.13(a) we can see the importance of the concept that the release time is the decay time from scale to 0.0, as the note is above the sustain level.

A few such as Moog Memoryoff another note mode of operation called unconditional mode. In this case, the note event does not immediately advance the EG into the release state. ## 6.5 Digital Envelope Generators

When digital synths arrived in the 1980s, manufacturers and computer musicians alike realized they were not bound to a capacitor or could create envelope generators with any shape and number of segments they wanted. Since the curves are created digitally, we can implement an envelope generator that is linear-in-dB or follows any curve or equation we like. The Yamaha DX7 envelope generators were implemented digitally using counters that mimicked exponential behavior.

For digital synthesis, we represent the capacitor voltage VCAP with our maximum value 1.0, and therefore the sustain voltage VSUS will be represented with a sustain level LSUS that is less than 1.0. When designing an EG, it is often common to represent the segments as lines rather than curves and plotted on the y-axis labeled "dB—linear-in-dB". In addition we are free to use either the analog/release rates or the absolute times for the segments. Figure 6.15 shows these digital versions with segments plotted in dB. The segment is not linear-in-dB; only the decay and release are.

The linear-in-dB EG is one popular EG incarnation, but you are only limited by your imagination here. Quite exotic EGs may be implemented using a variety of curve equations. ## 6.7 Iterative Generation of the Exponential Function

To implement an envelope generator with an exponential output, we will need to generate exponential curves based on e. Not only will this be computationally expensive, it poses a fundamental problem: exponential functions never decay the way to zero. The analog version uses $e^{-x}$ as the basis for the release curve (which we actually use $e^{-5}$ to mimic the analog output). During the release phase, the capacitor decays to $e^{-5}$ or 0.0067 or about -43 dB. The digital version, which is linear-dB or $e^{-1.0x}$, decays to 0.00016. It would be nice to have decay all the way to 0. We can take care of both by generating the exponential curves iteratively. This is conceptually the same as a feedback loop in a digital filter. A feedback filter with a single coefficient 0.9 is energized with a single impulse as shown in Figure 6.19. The output of the filter decays exponentially as the filter keeps multiplying its output by 0.9 repeatedly. The succession of output values would be {1.0, 0.9, 0.8, 0.73, 0.66, 0.59, 0.53, 0.48,...} and the output would never actually decay to zero.

To implement this exponentially decaying output, the only required calculation would be for the coefficient b, which sets the multiplicative step-size. We will still have the issue of the output never reaching zero. There are several ways to approach this, Nigel Redmon's implementation (see the Bibliography) solves the exponential decay issue and provides flexibility for many different curve shapes. It is also easy to modify. It, however, requires a call unless you intend to modulate the segment durations on every sample period, which is not recommended.

For the time constant multiplier of 5.0, we would only get down to the value 0.00673 at our normalized x = 1. But we could get the setup filter with a base or offset value $x_0$ that is subtracted from the output on each iteration that the output decays below zero, down to -0.0067, as shown in Figure 6.20. This way, we get the shape of that particular curve with a decay all the way to zero. The same applies to the attack curve, where iteratively multiplying a coefficient and adding offset will create an increasing curve that overshoots 1.0 by some amount instead.

So for each (attack, decay and release), we will need three variables: the coefficient, the offset and the TC overshoot variable that sets both the overshoot/undershoot and the curvature; small TC overshoot result in tighter curves.
