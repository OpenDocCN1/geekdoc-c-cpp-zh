## 5.5 Quasi Bandlimited Oscillator Algorithms

Now we can focus on the pitched oscillator designer. There are two directions we can take with regards to aliasing: eliminate it or allow it to happen if the aliasing components are sufficiently low in level (especially near Nyquist) and relatively far from the fundamental frequency. To eliminate completely requires additive synthesis, which could be done in real time as events occur, or could store the waveform in a table and use synthesis, which is covered in the chapter. The problem with pure additive synthesis is that it is computationally expensive. Even though the trigonometric functions like $\sin(x)$, $\cos(x)$ and $\tan(x)$ are very efficient on modern desktop and laptop systems, a low pitched oscillator like note A0 (the lowest note on a piano) is 27.5 Hz and has 800 harmonics before reaching Nyquist. This would result in 801 cases for a sawtooth or 800 from a single-source waveform. Bandlimited de facto standard in synthesis design has decades issues. The value (also caused by a phase increment) if the phase increment is greater than one sample, is not guaranteed to be bandlimited for non-sinusoidal waveforms. We will cover this in the chapter.

The idea for quasi bandlimited designs is relatively new. These designs seek to create alias-suppressed oscillators in which we tolerate some aliasing. It is especially attractive when the quasi bandlimited algorithm is simple and requires no trigonometric functions, table lookups, look ahead or other examples. The different algorithms focus on the discontinuities in the edges of the waveform.

## 5.6 Bandlimited Impulse Trains (BLIT)

Stilon and Smith proposed a method for creating alias-free waveforms using a Bandlimited Impulse Train or BLIT. The idea is to generate a softened or rounded discontinuity that would have resulted in lowpass filtering an impulse, and then produce a stream of filtered impulses. This produces a stream of sinc() functions as shown in Figure 5.4.

The idea is to take this impulse train it to produce sawtooth and square waves. For example, integrating the bipolar BLIT in a sawtooth wave produces a square wave, while doubling its discontinuity produces a triangle wave. The outputs of these oscillators feature a bit of ringing on the band edges. The three block diagrams are shown in Figure 5.5, and the integrators are simple Euler types. The aliasing is not eliminated with these simple BLIT algorithms.

More complex versions of BLIT can produce very good sonically but not as good as additive synthesis. BLIT has problems that make it one of the more difficult algorithms to implement. This can be problematic Using first generation of the BLIT sequence itself. Using the sinc() function would require two calls to the sinc() function. The BLIT sequences are generated with:

```
sinc(ex)
sinc(x/M)M(x/M)
M = number of harmonics
(5.3)
```

Figure 5.4: An equally spaced train of bandlimited impulses (a) unipolar and (b) bipolar.

Another idea is to sample a sum of windowed sinc() functions and store them in a set of tables corresponding to different fractional shifts of the impulse. This is necessary because the period of the desired waveform may not be an integer multiple of the sample rate. The tables would need to be recomputed at runtime. This is known as BLIT-SWS.

A larger issue is that the bandlimited overlaps, and the tail of one must be mixed with the head of the next. This requires knowing when the discontinuity is to occur and requires a look-ahead delay. This is problematic because we would like to have zero delay in synthesizing the waveform. The bandlimited impulse has be generated for every discontinuity, as the frequency becomes higher, the CPU usage increases. As Airy points out, another issue with these methods is that the integration steps in BLIT and BLIT-SWS introduce an unwanted and undesirable DC offset in the signal when the oscillator starts.

Brandt improved the idea by starting with a single bandlimited impulse and integrating beforehand, then storing that the pre-integrated waveform. removes the requirement for integration on-the-fly and produces a single band edge shown in Figure 5.6.
