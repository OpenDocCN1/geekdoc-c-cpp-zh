If you try to draw a radio button group and it won't let you, it means you have run out of these controls. Finally, drag the lcd into the design area and right-click to set it up. You should have something similar to Figure 2.17.

In the LCD setup, you can add or remove controls and set the color scheme. You can change the ordering of the controls. The GUI control is slightly different than the prototype UI that any of the continuous controls can be placed inside, not just the ones you are assigning throughout. This means that you could have a GUI consisting of just the LCD control and radio buttons. Add and remove controls with the Add-> and <- Remove buttons. You can re-arrange the order in the control with the Move In list nudges. After adding the LCD controls, close the setup dialog. At this point, you have one last step before it is ready—you need to go back and re-compile your plug-in to embed the GUI information inside the DLL. This is identical to the way the VGUI Designer for VST as Interface Builder in. You always need to rebuild the embedded GUI. In RackAFX, this means you need to update the Visual Studio code. There are two ways to do this: either switch back to the Prototype panel or use the Update Code button at the top left of the frame If you do not update the code in this way the design will not be saved. Switch back to Prototype to see the GUI and hit the Rebuild to rebuild the project. Now use the Load button to load the DLL. You will notice that the Custom GUI is now active—it looks like a blue knob. Click this button (or use View->Custom Plugin GUI) and your GUI will appear in its own child window. It will be cropped so that just holds all your controls shown in Figure 2.18.
