# canNoteOff()

This is the first time we need to override this function. Ordinarily, it forwards the call to the default output EG (EG1). The EG returns if it can go to a note off state, which means it is not in the release, releasePending, shutdown or offsets. For the DXVoice, we need to return true when all the EGs are connected to a carrier that can go to a note off state. This involves checking the algorithm and checking all carrier EGs. Notice the offset in the algorithm index; this is only to match the numbers given on the DX graphic (available for AU and VST3 users). Thus algorithm 1 is really voice mode 0. The switch/case statement is broken into sections depending on the number of carrier oscillators.
