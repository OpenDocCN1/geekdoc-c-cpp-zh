If you want to add your own graphics to change the look and feel or experiment with the numerous controls provided in the VSTGUI library, you must be careful about the path locations where you import the resources into Visual Studio. The graphics in our synthesizers are static objects included with the SDK but you may find many more knob and button graphics at http://www.willpark.com/synthbook/ After importing and compiling your project, re-opening the VSTGUI editor, you use the + and - buttons at the bottom of the Tabs map to add and remove resources. After adding an item, click the button labeled "more," and you should get a preview of your image file. If the preview is blank, there is a problem with your file path. Check with the VSTGUI website http://sourceforge.org/projects/vstgui/ for more information.
