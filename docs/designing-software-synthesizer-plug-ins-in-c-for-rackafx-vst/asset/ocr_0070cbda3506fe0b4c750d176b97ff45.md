The Härmä-paired Simon and Smith filter has an identical frequency response to Zavalashin's version and likewise self-oscillate. On the downside, it uses the memory registers and coefficients as the Zavalashin version and can suffer from coefficient rounding errors. It also performs when the cutoff frequency is modulated. Our tests modulating the cutoff frequency of each model with a sawtooth LFO, found differences of -48 dB (0.4%) in the test results, with extreme differences in the way the filter behaves when the cutoff frequency makes a sudden jump at the sawtooth discontinuity. The two filters clearly perform differently under time-varying operation, which if you are interested in implementing and comparing the filters, you can get the full Modified Härmä derivation and sample code at http://www.willprike/synthbook/. We will be implementing our filter using first order VA sections. Its tuning is accurate, it is stable up to Nyquist, and uses minimum of memory registers and coefficients. It can also self-oscillate.
