Chowing named these FM structures, or operators, and they are for the architecture of the DX synths, as the DXSynth in this chapter. The fundamental quality of an FM patch (searing, mellow, muted, sharp, bell, etc.) is a result of the arrangement of multiple operators. Chowing drew signal flows from top to bottom, as the oscillator points downwards. Figure 12.10 shows the Chowing abbreviation. Note that details about the EG and oscillator control frequencies are emitted. Each operator always includes an accompanying EG, the carrier oscillators are always set to the MIDI note pitch, and the modulator oscillators always use ratio of MIDI note pitch; each modulator can be tuned to a different ratio.

In addition to stacking multiple modulators upon modulators, an FM operator can also selfmodulate, as in the stacked set of four operators in Figure 12.11. The last operator in the chain (number 4) is selfmodulating.

The DX7 features six FM operators arranged in 32 different combinations. The DX100 has FM operators arranged in eight different combinations. Chowing called the combinations algorithms, and the DX synthesizers were branded “Digital Programmable Algorithm Synthesizers”—in fact, “FM” appears nowhere on the synth enclosures. Operators can be placed in series or parallel, and there can be more than one carrier. Figure 12.12 shows two more of these algorithms and the implied that are involved. The DXSynth in this chapter is a close replica of the DX100 using four operators in the same algorithm combinations. These algorithms are shown in Figure 12.13.
