When a MIDI note is turned on, you want to log the event, note number and velocity so that it shows up like this:

```
-- Note On: Ch:1 Note:60
Vel:96
```

which would indicate a Note On Message on MIDI channel 1 with MIDI note number 60 (middle C) and velocity 96. Of course you can format this string like you, but the above is short and simple. The MIDI note messages are handled in the functions StartNote() and StopNote(). Interestingly, these have different arguments.

The Control Change Messages are handled in HandleControlChange() with the arguments:

- inChannel: the MIDI channel
- inController: the MIDI CC index
- inValue: the CC value 0 to 127

All synths respond to a default set of CCs:

- Mod Wheel
- Volume CC7
- Pan CC10
- Expression CC11
- Sustain Pedal CC64
- All Notes Off

You will trap and log these messages as well as catch-all for other CC messages in HandleControlChange(). Decode the controller index and log the information. Notice that the sustain pedal is on when the CC value is 64 or greater. The CC indexes (e.g. MOD_WHEEL) are defined in synthfunctions.h.

```cpp
OSStatus AUSynth::HandleControlChange(Uint8 inChannel,
	Uint8 inController,
	Uint8 inValue,
	Uint32 tStartFrame)
```

```cpp
UINT uChannel = (UINT)inChannel;
// test channel/ignore
if (m_uMidiRxChannel != MIDI_CH_ALL && uChannel != m_uUMidiRxChannel)
	return noErr;

switch(inController)
{
	case MOD_WHEEL:
		#ifdef LOG_MIDI
		printf("-- Mod Wheel Ch:%d Value:%d \n", uChannel, inValue);
#endif
		break;
	case VOLUME_CC07:
		// --- NOTE: LOG CAPTURES VOLUME FOR ITSELF ---
		#ifdef LOG_MIDI
		printf("-- Volume Ch:%d Value:%d \n", uChannel, inValue);
#endif
		break;
	case PAN_CC10:
		// --- NOTE: LOG CAPTURES PAN FOR ITSELF ---
		#ifdef LOG_MIDI
		printf("-- Pan Ch:%d Value:%d \n", uChannel, inValue);
#endif
		break;
	case EXPRESSION_CC11:
		#ifdef LOG_MIDI
		printf("-- Expression Ch:%d Value:%d \n", uChannel, inValue);
#endif
		break;
	case SUSTAIN_PEDAL:
		// 64 or greater = ON
		bool m_bSustain = (UINT)inValue > 63 ? true : false;
		#ifdef LOG_MIDI
		if(m_bSustain)
			printf("-- Sustain Pedal ON");
		else
			printf("-- Sustain Pedal OFF");
#endif
		break;
	case ALL_NOTES_OFF:
		#ifdef LOG_MIDI
		printf("-- All Notes Off!");
#endif
		break;
	// --- other controllers
	default:
		#ifdef LOG_MIDI
		printf("-- CC Ch:%d Value:%d \n", uChannel, inValue);
#endif
		break;
}

return true;
```
