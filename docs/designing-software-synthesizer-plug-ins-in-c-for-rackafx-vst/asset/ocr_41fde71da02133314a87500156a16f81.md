# DCA EG Mod

There are more possible sources and destinations, and in this chapter we will add several of them. Figure 8.2 shows a conceptual diagram of the modulation routings in the current version of NanoSynth. The sources are lined up with the leftist destinations on the right. We see instances where one source feeds multiple destinations and where one destination's intensity is the sum of multiple sources. We want to describe the modulation matrix with this kind of flexibility built-in and no limit to the number of routings.

Now, think about how the code looks when rendering the audio. For the EG to Oscillator Fo routing, the final modulation value is the product of the intensity, range and modulation output:

```
double dEG0scMod =
m_dEG0scIntensity_OSC_FO_MOD_RANGE*dBiasedEG;
```

Next, the LFO1 scaled is added directly to the EG's modulation value. In this case, the LFO1 intensity is fixed at 1.0 and the range is also OSC_FO_MOD_RANGE.

```
m_Osc1.setFcmodExp(dLFO1Out*OSC_FO_MOD_RANGE +
dEGOscMod);
```

The EG1 to filter cutoff has the intensity fixed at 1.0 and uses the filter cutoff range FILTER_FC_MOD_RANGE.

```
m_Filter1.setFcmod(dEGOut*FILTER_FC_MOD_RANGE);
```

When the key track is enabled, the filter's control is forced to match the oscillator's frequency, which is derived from the MIDI note number, so that it is the Note Number to Filter MC connection we see in Figure 8.1. Here, the intensity (0.5 to 2.0) controls the range as well. Remember that the MIDI note number had to be transformed into a frequency before multiplied with the intensity value.
