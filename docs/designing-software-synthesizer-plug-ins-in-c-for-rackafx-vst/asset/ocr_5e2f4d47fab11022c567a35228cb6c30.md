# 11.19 The CAAniSynthVoice Object

CAAniSynthVoice is derived from CVectorSynth, and so it inherits all of the vector synth variables and functions.
The only real difference is in the do() function, and the fact that CAAniSynthVoice needs to maintain the array of wavelet buffer pointers. The voice object creates a set of uninitialized CSampleOscillator objects depending on the number of cells per side you choose. You then initialize each oscillator with a separate .wav file or a folder of files. setActiveCell() initializes the lookup logic for swapping the oscillator pointers.

# Constructor

In the constructor, you initialize the variables. Since this is a derived class, the constructor will be called last in the sequence (CVoice->CDigiSynthVoice->CVectorSynthVoice->CAAniSynthVoice). The majority of work here is in setting up the filters; the diode ladder filter has a severe cut in passband response as Q is increased, so we add a little compensation here—as always, feel free to experiment with this.
