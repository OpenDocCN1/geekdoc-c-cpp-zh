
# Modulation Layers

Before looking at the modulation matrix object, we need to think about the modulation layers. For NanoSynth, it's very simple; the LFO and EG modulate the oscillators, filter and DCA. There is only one layer of modulation. But what if we added another LFO called LFO2 to NanoSynth that modulated LFO1's frequency as in Figure 8.7? Then we would have two layers and need to use the modulation matrix twice. The important thing to keep in mind is that the destinations define the layer number.

The modulation matrix is designed to use two layers at the most; however, you can easily modify it to use many layers as you want. We will start by implementing the Layer 1 modulation in the NanoSynth. Later in the chapter, we will add some advanced MIDI modulations that will occur in Layer 0.

A conceptual CMod class diagram is shown in Figure 8.8 while Table 8.2 lists the member variables and functions. The object is fairly simple; the member variables consist of arrays for the sources and destinations, followed by a pointer to the matrix, and a variable indicating the number of rows in the matrix. The member functions are named in a straightforward manner; the most important functions are:

- addMatrixRow()—adds a newly created row to the matrix after checking to make sure the row doesn't exist
- doMod()—performs the operation of looping through rows and accumulating sources into destinations

The majority of the functionality is implemented in the ModulationMatrix.h file, so have a look at that. The first part consists of the member declarations. Notice that the matrix is statically declared and is of the maximum worst case size when every source modulates every destination. There is no removeMatrixRow() function—you can't. When you design the synth, you fill only the rows that you need for your routings. The unused rows are not processed.

```cpp
class CModulationMatrix{
public:
    CModulationMatrix(void);
    ~CModulationMatrix(void);
protected:
    // --- the matrix of mod-rows with the worst-case size (every source
    // modulates every destination
    // This is a double-pointer because it is allocated dynamically (*)
    // and points to an array of pointers(**)
    modMatrixRow** m_ppMatrixCore;
```

# getModMatrixCore() and setMatrixCore()

The getModMatrixCore() and setMatrixCore() simply get and set the pointer; during the set, the matrix is deleted if it already exists. The matrix core is dynamically allocated during construction. getMatrixSize() just iterates through the rows and calculates the size.

```cpp
// --- get the matrix core
modMatrixRow** getModMatrixCore(){return m_ppMatrixCore;}

// --- set the matrix core
void setModMatrixCore(modMatrixRow** pModMatrix)
{
    if(m_ppMatrixCore)
    {
        for(int i=0; i<m_nSize; i++)
        {
            // delete pointer
            modMatrixRow* pRow = m_ppMatrixCore[i];
            delete pRow;
            m_nSize--;
        }
    }
    m_nSize = 0;
    delete [] m_ppMatrixCore;
}

m_ppMatrixCore = pModMatrix;
m_nSize = getMatrixSize();
```

clearSources() and clearDestinations()

# addMatrixRow() and others

The addMatrixRow() function adds a row but checks to make sure it doesn't exist using the matrixRowExists() function. Rows are never duplicated. The deleteMatrix() function destroys all pointers and the array. The enableDestinationRow() function enables or disables matrix rows using the boolean flag in the modRow structure.

```cpp
inline void addMatrixRow(modMatrixRow* pRow)
{
    if(!m_ppMatrixCore)
        createMatrixCore();

    // add if not existing
    if(!matrixRowExists(pRow->uSourceIndex, pRow->uDestinationIndex))
    {
        m_ppMatrixCore[m_nSize] = pRow;
        m_nSize++;
    }
    else
        delete pRow;
}

inline bool matrixRowExists(UINT uSourceIndex, UINT uDestinationIndex)
{
    if(!m_ppMatrixCore) return false;

    for(int i=0; i<m_nSize; i++)
    {
        modMatrixRow* pRow = m_ppMatrixCore[i];

        // find matching index source/destination pairs
        if(pRow->uSourceIndex == uSourceIndex &&
            pRow->uDestinationIndex == uDestinationIndex)
        {
            return true;
        }
    }
    return false;
}
```

```cpp
inline void deleteMatrix(){
    if(!m_ppMatrixCore) return;

    for(int i=0; i<m_nSize; i++)
    {
        // delete pointer
        modMatrixRow* pRow = m_ppMatrixCore[i];
        delete pRow;
        m_nSize--;
    }
    m_nSize = 0;
    delete [] m_ppMatrixCore;
    m_ppMatrixCore = NULL;
}
```

# checkDestinationLayer()

The checkDestinationLayer() function checks the destination index to decide if it is a Layer 0 or Layer 1 destination. This is where you define more layers if you wish. You can now see why the destinations enumeration has the Layer 0 destinations first—you just check to see if the target destination is within the bounds of the first and last enumeration in the group.
