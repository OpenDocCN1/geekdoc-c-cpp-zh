# 5.17 Pseudo Random Noise (PN Sequence) Oscillator

Pseudo random noise (PN) generators create a noise-like output that is not purely flat in spectral content but possesses a pleasant sound. // fNoise is 0 -> 32760.0
float fNoise = (float)rand(); // normalize and make bipolar
fNoise = 2.0*(fNoise/32767.0) - 1.0; (roll off -3 dB/octave from DC to Nyquist) has a roll off that resembles a lowpass or filter. The noise sequence repeats so it can be used analytically, if a recording could be made with the noise stimulus, then the signal could be de-convolved and the impulse response of the noise recovered. The de-convolution can be carried out since the signal is deterministic and known priori. There are several ways to create a PN Sequence. The version here is from D'Attour (2002) and we will use a 32-bit unsigned integer (UINT) to perform the operations.

The PN Sequence is generated by first loading a 32-bit register with an initial non-zero value (any non-zero value may be used). During each sample interval, two or more bits are XORed together. The XOR (Exclusive-OR) operation produces a binary 1 when the two inputs are different (0 and 1 or 0). Then, the entire register is shifted to the right. The XOR value is inserted into the MSB of the register. The resulting register is the value for that sample period. The bits that are XORed during the operation are pre-determined by PN algorithms. Different register sizes, and output widths, have different sets of acceptable bits for the XOR-ing process.

For a 32-bit register, the bits to XOR together are bits b0, b1, b27, and b28. The algorithm then becomes:

+   - start with a 32-bit register initialized to any value
- on each sample period form the result:

$b31 = b0\oplus b1\oplus b27\oplus b28$;

+   - shift the register to the right by one bit
- load the MSB (b 31) with the calculated value
- convert the UINT to a floating point number and scale-ing formulas for each:

The C++ code for this generator is already implemented in synthfunctions.h and requires a macro definition to extract the bits from the 32-bit unsigned integer register, which is the argument to the main function.

| Word Length | Formula |
|---|---|
| 8 | $h_0 = b_0\oplus b_1\oplus b_2\oplus b_3$ |
| 16 | $h_4 = b_0\oplus b_1\oplus b_4\oplus b_7$ |
| 24 | $h_8 = b_0\oplus b_1\oplus b_8\oplus b_{11}$ |
| 32 | $h_{12} = b_0\oplus b_1\oplus b_{12}\oplus b_{15}$ |
| 64 | $h_{16} = b_0\oplus b_1\oplus b_{16}\oplus b_{31}$ |

# 5.18 Random Sample and Hold Oscillator

The Random Sample and Hold (RS&H) oscillator samples and holds values from a white noise source. The hold-period is the T of the oscillator frequency $f_s$, so a Hz RS&H would hold each value for one second. This produces a random step sequence. When to modulate the pitch of an oscillator, it produces random values and sounds like a game-sound effect. When using the PN sequence as source, the fluctuations have patterns that repeat quasi-randomly and quasi-periodically.
