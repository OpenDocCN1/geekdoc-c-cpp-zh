# 5.20 Waveable Oscillators

A Waveable Oscillator is a table-based system for creating periodic signals. A buffer is pre-loaded with one cycle, minus one sample of. The waveform can be mathematical (sin, cos, pulse, square, triangle, etc.) or a recorded signal. The idea is that you read through the table and output samples from it. Consider a table of 1024 samples consisting of one cycle of sinusoid, one sample shown in Figure 5.33.

The table is indexed with the value i, which starts at 0; the last entry in the table is at i = 1023, the sample just before the waveform starts over.

Suppose you are at i = 0, during each sample, you read out one value and advance to the next. At the end of the buffer, you wrap around and start all over. You can now see the table stores one cycle but not exactly—this allows the two ends of the waveform to be sewn together by circular wrap. If you read out one value per sample, what would be the frequency of the waveform? The answer is f = fs/n, where n is the increment. For a 1024-point wave at 44.1 kHz sample rate, table is 43.066 Hz. If you have a sawtooth waveform in the table, it would have a table frequency of 43.066 Hz.
