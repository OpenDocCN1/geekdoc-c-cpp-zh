# ## 12.8 CDXSynthVoice Object

CDXSynth is similar to the rest of the synth projects; the majority of the plug-in object code operates the same way as others. The CDXSynthVoice object handles the rendering and few other choices specific to CDXSynth. Table 12.6 shows the member variables, and Table 12.7 shows the member functions. Most of the member functions are familiar by now; notice the overrides when initializing the output.


# ### Constructor

The constructor just initializes the oscillator pointers to our four wavelet or quasi bandlimited oscillators and clears the four feedback variables (remember we only use one of them in this synth).

# ### initGlobalParameters()

This function is nearly identical to the rest of the synthesizers; call the base initialize any global parameters; we have the new feedback values. The LFO is forced to 1.0 in case there is no control.

# ### initializeModMatrix()

This function creates and sets up the matrix rows using Table 12.4—these are all for routing the LFO to either the amplitude modulation or vibrato for each oscillator, and are all disconnected by default. The code for the complete list. When the LFO is used to modulate the oscillator amplitude, it is far to the destination DEST_OSC_OUTPUT_AMP, which is a attenuator on each oscillator. This is amplitude modulation (AM) that is linear and not in dB, although you could modify it to do so. When the LFO is used for vibrato, it modulates the same destination as usual: DEST_OSC1_FO, DEST_OSC2_FO, etc.
