## init()

Accepts the length in samples as the argument and dynamically declares then clears buffer.

```cpp
void CDDelayLine::init(int nDelayLength) {
    // --- save for later
    m_nBufferSize = nDelayLength;

    // --- delete if existing
    if(m_pBuffer) {
        delete m_pBuffer;
    }

    // --- create
    m_pBuffer = new double[m_nBufferSize];

    // --- flush buffer
    memset(m_pBuffer, 0, m_nBufferSize*sizeof(double));
}
```

## resetDelay()

Flushes old data from delay line and resets the index values to top; then it cooks variables in case anything changed since last run.

## cookVariables()

Convert the delay time to an offset between read and write index. Remember that the read index is behind the write index, so the index is subtracted. We need to check if we have gone past the beginning of the array and wrap around the other end if needed.

```cpp
void CDDelayLine::setDelay_mSec(double dmSec)
{
    // --- save
    m_dDelay_ms = dmSec;

    // --- cook
    cookVariables();
}
```

```cpp
void CDelayLine::cookVariables()
{
    // --- calculate fractional delay
    m_dDelayInSamples = m_dDelay_ms*((double)m_nSampleRate/1000.0);

    // --- subtract to read index
    m_nReadIndex = m_nWriteIndex - (int)m_dDelayInSamples;

    // --- the check and wrap BACKWARDS if the index is negative
    if(m_nReadIndex < 0)
        m_nReadIndex += m_nBufferSize; // amount of wrap
}
```

## readDelay()

This function finds the two samples that surround the interpolated value we desire based on the fractional delay in samples. Then the two samples are fetched and the interpolation is applied following Figure 13.4. Notice how the fractional component is extracted from the total delay value by subtracting the integer part.

```cpp
double CDDelayLine::readDelay()
{
    // -- Read the output of the delay at m_nReadIndex
    double yn = m_pBuffer[m_nReadIndex];

    // -- Read the location ONE BEHIND at y(n-1)
    int nReadIndex_1 = m_nReadIndex - 1;
    if(nReadIndex_1 < 0)
        nReadIndex_1 = m_nBufferSize-1;

    // -- get y(n-1)
    double yn_1 = m_pBuffer[nReadIndex_1];

    // -- get fractional component
    double dFracDelay = m_dDelayInSamples - (int)m_dDelayInSamples;

    // -- interpolate: (0, yn) and (1, yn_1) by dFracDelay
    return dLerp(0, 1, yn, yn_1, dFracDelay);
}
```

## readDelayAt()

Similar to readDelay(), but reads from any location in the buffer. It must calculate its own read index as not to disturb the object variables. Otherwise, it does the same operation of interpolating the data.

```cpp
double CDDelayLine::readDelayAt(double dmSec)
{
    // --- local variables
    double dDelayInSamples = dmSec*((float)m_nSampleRate)/1000.0;

    // -- subtract to make read index
    int nReadIndex = m_nWriteIndex - (int)dDelayInSamples;

    // --- wrap if needed
    if (nReadIndex < 0)
        nReadIndex += m_nBufferSize; // amount of wrap

    // -- Read the output of the delay at m_nReadIndex
    double yn = m_pBuffer[nReadIndex];

    // -- Read the location ONE BEHIND yn at y(n-1)
    int nReadIndex_1 = nReadIndex - 1;
    if(nReadIndex_1 < 0)
        nReadIndex_1 = m_nBufferSize-1;

    // -- get y(n-1)
    double yn_1 = m_pBuffer[nReadIndex_1];

    // --- get the fractional component
    double dFracDelay = dDelayInSamples - (int)dDelayInSamples;

    // -- interpolate: (0, yn) and (1, yn_1) by the amount dDelay
    return dLerp(0, 1, yn, yn_1, dFracDelay);
}
```

## writeDelayAndInc()

Writes a value into the current write location, then increments both the read and write indexes and checks for wrap.

```cpp
void CDelay::writeDelayAndInc(double dDelayInput)
{
  // --- write to the delay line
  m_pBuffer[m_nWriteIndex] = dDelayInput; // external feedback sample

  // --- increment the pointers and wrap if necessary
  m_nWriteIndex++;
  if(m_nWriteIndex >= m_nBufferSize)
    m_nWriteIndex = 0;

  m_nReadIndex++;
  if(m_nReadIndex >= m_nBufferSize)
    m_nReadIndex = 0;
}
```

## processAudio()

This function reads the delay at the current location using readDelay() and then writes the incoming value into it using writeDelayAndInc().

```cpp
bool CDelay::processAudio(double* pinput, double* poutput)
{
  // --- read output
  *poutput = m_dDelayInSamples == 0 ? *pinput : readDelay();

  // --- write to the delay line
  writeDelayAndInc(*pinput);

  return true;
}
```

## 13.4 The CStereoFX Object

The CStereoFX object combines two of the CDelay objects into four algorithms:

- norm: normal stereo delay
- tap1: multi-tap delay variation 1
- tap2: multi-tap delay variation 2
- pingpong: ping-pong delay

The object is responsible for initializing and maintaining the underlying line objects. It also implements methods that the GUI uses to update these underlying objects. Finally, it implements the four modes of operation. Table 13.3 shows the CSTereoDelayFX variables, and Table 13.4 shows the member functions. The object is fairly straightforward.

The delay ratio is interesting. This allows you to set the left and right delay times like the K Wavestation. In these products, the user selects from a list of pre-defined ratios to set up the scaling of the delay time. One channel gets the full delay time, while the other gets a fraction of it. The delay ratio controls this fraction. Rather then implement and decode a table of ratios, we implement a continuous control adjustable from -0.9 to +0.9 as follows for the normal and ping-pong delays:

If ratio is negative:
- left delay is abs(ratio)*(total delay time)
- right delay is total delay time

If ratio is positive:
- left delay is total delay time
- right delay is ratio*(total delay time)

If ratio is zero:
- ratio is 1:1, so left and right delays are both the total delay time (identical)

For the multi-tap variations, the control behaves slightly differently, adjusting the time of the secondary tap as a ratio of the primary tap.

If ratio is negative:
- left secondary tap is abs(ratio)*(total delay time)
- right secondary tap is total delay time (1.0 – abs(ratio))*(total delay time)

If ratio is positive:
- left secondary tap is total delay time (1.0 – abs(ratio))*(total delay time)
- right secondary tap is abs(ratio)*(total delay time)

If ratio is zero:
- left secondary tap = 0 mSec
- right secondary tap = 0 mSec
