As the pulse width changes, so the DC offset of the waveform—at 50% pulse width the DC offset is zero. In Figure 5.23 (e) and (g) you can see what the output should look like.

When the pulse width is less than 50%, the waveform is shifted up to reduce the DC offset. It is also scaled in amplitude. Likewise it is shifted down and slightly scaled when the width is greater than 50%. Failure to do this will result in a potentially massive DC offset in your signal.
