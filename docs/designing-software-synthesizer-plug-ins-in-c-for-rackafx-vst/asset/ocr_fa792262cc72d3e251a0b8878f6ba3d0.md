# 2.31 Using the VSTGUI Drag-and-Drop Interface

Open the VSTGUI editor, you first compile your synth in debug mode in Visual Studio. Then, copy .vst3 file into the VST3 folder and open it. Create a new track with your plug-in and open the GUI (views from client to client). If you are using the GUI-less template, you will see a black box for the GUI that ships with the projects. Right-click on the GUI and choose “Open Editor” from the menu. You can get more information and help from the VST SDK documentation, the VSTGUI website and http://www.willinkle/synthbook/
