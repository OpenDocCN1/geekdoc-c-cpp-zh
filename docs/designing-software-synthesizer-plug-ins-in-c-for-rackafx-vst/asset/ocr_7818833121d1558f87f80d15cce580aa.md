One way to use the joystick is to simply move it around in real-time while you hold a note or multiple notes. The output is a mix of the sources. As you move the joystick, the sound evolves as the mix ratios change, always totalling 1.0 so that no clipping occurs. As you move the joystick, the vector EG amplitude value for each source. It's a near perfect trick, but you use a playing-hand to move the joystick. A more interesting and useful feature of vector synths is the ability to program the joystick in a path. Each time you trigger a new note, the joystick moves along the path you've assigned. The path consists of a set of vertices and timing values between each as shown in Figure 11.9. Each pair of vertices forms a segment. In this case, the path starts at vertex 0 and makes its way to vertex 1 in second, then on to vertex 2 in 0.75 seconds, and so on, until it stops at vertex 4. Therefore, segment 1 lasts 1 second and 2 is 0.75 seconds.

As Stanley Jungfield (1986) notes in the ProphetVS manual, setting short durations in the segment times to induce quicker playing in the music, while long settings invite the musician to play sustaining notes. The author notes that a vector is defined as something that has both a magnitude and a direction. The vector path dictates the direction of the joystick, which controls the instantaneous mix.
