Notice how the clutter is removed; there are no intermediate variables or variables to pass between objects. In fact, there are no more arguments on the functions! It is very clean and streamlined. In addition, the same code can be used repeatedly for many different patches since the patching information is coded inside the modulation matrix. Our rendering functions no longer need to know or handle the details of the patch routing.

The modulation matrix is implemented as a C++ object. The matrix actually consists of three components:

- an array of Source registers
- an array of Destination registers
- an array of pointers to modMatrixRow structures called the matrix core

The source and destination registers are double values, so the sources and destinations are simply arrays of doubles. The modulation sources will write their outputs into predefined locations in the source array. The destinations will read their values from predefined locations in the destination array.

The job of the modulation core is to take values from the source array, optionally transform them, scale them by their range and intensity variables, then accumulate the values into locations in the destination array.

The matrix core is the array of pointers to the matrix rows that define each modulation routing. The core is created dynamically and have get/set functions so that a single core may be shared with multiple matrices.

Figure 8.3 shows the modulation core; it is a fixed array full of modMatrix pointers and NULL pointers indicating that no rows exist. The size of the matrix core is equal to the number of no-NULL rows.

Figures 8.4–8.6 show the sequence of operations for modulation via the modulation matrix. The operations can be broken into three phases:

Phase 1: the modulators write their outputs into the Sources array (MIDI modulations will arrive via MIDI messages that we apply)

Phase 2: the modulation matrix loops through its array, extracting values from the Sources array, transforming, scaling, and accumulating them into the Destinations array

Phase 3: the synth components read their modulation values from the Destinations array

Figure 8.3: the matrix core contains either matrix row pointers or NULL; this matrix would have a size of eight (8) since it has eight non-NULL rows.

## Creating Rows

In the modulation matrix, you create all the rows at startup time; you add a row for every possible modulation even if some modulations are turned off by default. Another option is to create a matrix that can dynamically grow and remove rows on the fly. This opens up many potential traps and pitfalls, especially since both the processing and GUI threads need to access it. By creating a fixed matrix, we don't have those problems. You only need to set the bEnable flag for each row when you create the rows; default modulation rout are enabled while optional routings are disabled. In Section 8.11 we will experiment with turning rows on and off to let the user configure the patch from the GUI. Although you can create the rows yourself, we added a helper function in syncfunctions.h to create rows for you. This function is straightforward and self-explanatory.

```cpp
enum transform {
TRANSFORM_NONE = 0,
TRANSFORM_UNIPOLAR_TO_BIPOLAR,
TRANSFORM_BIPOLAR_TO_UNIPOLAR,

TRANSFORM_INVERT_MIDI_NORMALIZE,
TRANSFORM_MIDI_TO_BIPOLAR,
TRANSFORM_MIDI_TO_PAN,
TRANSFORM_MIDI_TO_SWITCH,
TRANSFORM_MIDI_TO_ATTENUATION,
TRANSFORM_NOTE_NUMBER_TO_FREQUENCY,
```

```cpp
struct modMatrixRow {
    // --- index of source
    UINT uSourceIndex;

    // --- index of destination
    UINT uDestinationIndex;

    // --- default to 1.0 in case no GUI
    double* pIntensity; // "Control" in MMA
    double* pModRange; // "Scale" in MMA

    // --- transform on Source
    UINT uSourceTransform;

    // --- enables or disables by row
    bool bEnable;
};
```

```cpp
inline modMatrixRow* createModMatrixRow(UINT uSource, UINT uDestination, double* pIntensity, double* pRange, UINT uTransform, bool bEnable) {
    modMatrixRow* pRow = new modMatrixRow;
    pRow->uSourceIndex = uSource;
    pRow->uDestinationIndex = uDestination;
    pRow->pIntensity = pIntensity;
    pRow->pModRange = pRange;
    pRow->uSourceTransform = uTransform;
    pRow->bEnable = bEnable; // enable on/off

    return pRow;
}
```
