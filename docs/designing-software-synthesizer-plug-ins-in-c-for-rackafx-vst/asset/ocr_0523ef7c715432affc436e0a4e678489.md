Each synth will receive the CC sources listed in Table 3.2.

If you receive these messages, VST3 requires the use of a MIDI Map, via the interface IMIDimap. The idea is that you create a GUI with controls for parameters, and you map a CC—say, Expression—to one of your parameters, such as Filter Cutoff Frequency. The mod wheel is always mapped to LFO amplitude by default. And the volume control is usually mapped to the output level. The IMIDimap interface consists of only one function that you override, getMIDIControllerAssignment(); The host queries you to find out which MIDI control messages to map to your GUI controls, which in turn underlying parameters in the synth. It queries with controller index values 0 to 129, by setting the index of the GUI parameter you want to control. A controller may only be linked to one parameter—this sets up a problem for any kind of advanced synth plug-in; you can't re-write the MIDI map (source) to more than one destination. In addition, you can re-write the MIDI map on the fly.

A simple solution is to create dummy GUI parameters for the MIDI messages you want to receive. You don't intend for the user to see them on the final GUI. Then, you map these MIDI controller messages to your dummy parameters. During the process() function call, these parameters are extracted as if they were coming from the GUI. Having trapped the messages as parameter changes, you may route them as you please. Figure 3.5 shows the flow of information. You can see the roundabout manner in which the CC messages finally get delivered to the Processor as parameters. A fundamental drawback is that the Parameter value is normalized between 0 and 1. The MIDI channel information is lost, so you cant know the original CC channel. The channel information is also lost using the default Stenberg method as well.

A helper function called doUIControl() handles parameter changes. It gets called in the process() function, which receives the events in its input argument. The MIDI control changes arrive along with the GUI controls for processing.
