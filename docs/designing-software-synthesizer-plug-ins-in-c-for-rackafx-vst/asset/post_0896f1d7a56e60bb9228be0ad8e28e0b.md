
## CStereoFX Continuous Parameters

| Control Name (units) | Type | Variable Name (VST3, RAFX) | Low/Hi Default * | VST3/AU Index |
|---|---|---|---|--|
| Delay (ms) | double | m_dDelayTime_mSec | 0 / 2000 / 0 | DELAY_MS |
| Feedback (%) | double | m_dFeedback_Pct | -100 / 100 | DELAY_FEEDBACK_PCT |
| Delay Ratio | double | m_dDelayRatio | -0.9 / 0.9 | DELAY_RATIO |
| Delay Mix | double | m_dWetMix | 0 / 1 | DELAY_MIX |

* low, high and default values are #defined for VST3 and AU in SynthParamLimits.h for each

## CStereoFX Enumerated Parameters (Unit)

| Control Name | Variable Name | enum String | VST3/AU Index |
|---|---|---|--|
| Delay Mode | m_uDelayMode | norm,tap1,tap2,pingpong | DELAY_FX_MODE |
