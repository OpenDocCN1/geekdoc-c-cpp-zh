# 9.3 Portamento

Many synths feature a portamento or glide. With this effect,, triggered notes will not start at the MIDI pitch, but will glide smoothly up or down from the previously triggered note. The user controls the glide time. The pitch moves in an exponential manner as it does during normal modulation. It is ideal to someone using the pitch bend wheel or joystick—as they move the control, the pitch changes exponentially in a continuous or gliding. All the synths in this book will have built-in. The CVoice object is going to handle every bit of that, so you won't have to re-code anything.

During portamento, you calculate the number of seconds from the start and end pitches. The plug-in tracks the last MIDI pitch frequency it receives the MIDI messages. The portamento counter increment value is calculated in the update() function that we use. The equation is the same as the counter used in the LFO and Quasi Bandlimited oscillators.
