# 6.10 Envelope Implementation

The EG can be modeled as a Finite State Machine (FSM) with the following states:

+   - OFF
- ATTACK
- DECAY
- SUSTAIN
-RELEASE
- SHUTDOWN (optional)

The EG starts in the OFF state. A note on event advances the FSM into the ATTACK state, and output begins begins. When the output of the EG reaches or crosses the sustain level, the FSM advances to the SUSTAIN state, where the EG simply outputs the current level that the user sets. A note on event advances the FSM into the RELEASE state, where the output begins its final descent until it reaches or crosses zero. The FSM moves into the OFF state. If a note event occurs in any of the states, the FSM goes into the RELEASE state. If the EG is shut down (reset-to-zero), the FSM moves into the SHUTDOWN state, where short linear taper is applied to shut off the output.
