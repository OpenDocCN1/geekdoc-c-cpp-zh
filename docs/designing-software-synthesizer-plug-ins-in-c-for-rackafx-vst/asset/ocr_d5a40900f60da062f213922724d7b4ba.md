The second kind of control you need to implement will provide the user with a list of items which they will select only one. For example, you might have a control where the user picks a filter type from list (LPF,HPF,BPF) as you saw in [Table 2.8], how you declare this in the Controller's initialize() function where you load strings into the Parameter object. The VGUI component that handles these kinds of string-based parameters is called COOptionMenu. We provide you with a set of templates that combine a text label and an option menu into one cluster; these are designated "OMG" (Option Menu Group) and consist of:

+   * ContentView: a container with no PNG file associated with it
* CTextLabel: this label has a transparent background
* COOptionMenu: the drop-down list of items
* All of the menu groups are 75x42 (width x height in pixels) so you can stack two together in the same space as one knob group
