Calculating the offset $x_o$ is different for each segment. It is the value that is added or subtracted from the iterative multiplication in the form:

```
$y(n) = x_o + b_y(n-1) \ y(n-1) = $ last EG output \quad (6.7)$
```

These two values for the coefficient and offset are all set so that the initial value is correct for each segment. They are:

```
$x_s(attack) = (1+attackTCO)(1-b_{attack}) \ x_s(decay) = (sustain-decayTCO)(1-b_{decay}) \ x_s(release) = -releaseTCO(1-b_{release}) \quad (6.8)$
```

These two values for the coefficient and offset are all that that are needed to generate the exponential segment. Since the segments often over or under-shoot their target values, we can use this trigger mechanism to move through the segments of the envelope generator.

# 6.8 Biased Envelope Generator Output

The EGs in Figure 6.21 will work fine for controlling the time amplitude of our notes. The envelope starts and ends at a value of 0.0. If this EG is used to modulate the pitch of an oscillator or the cutoff frequency of a filter, it might not get the desired effect. For example the EG is used to alter the pitch of an oscillator with a maximum offset of 2 semitones. The EG would start at 0.0, so no pitch is applied. Then the note would go two sharps, as the EG advances through the attack. During the decay the pitch would fall to the sustain level and remain sharp. Only at the end of the release segment would the note's pitch become correct. In this case, the switch would be playing out of tune. It's worth noting that on some values, this is the standard mode of operation. Pitch EGs and Filters often use a biased EG. The sustain level is subtracted from the output so that there is no modulation. In the case of a Pitch EG, the note would start flat, then go sharp, then drop to pitch during the sustain segment. After release, the pitch would flat. Setting non-zero start end values is an option to keep the note in pitch at these extremes. The biased EG is shown in Figure 6.22.

# 6.9 Envelope Generator Intensity Controls and Connections

Many features an additional control placed between the EG and the target value it modulates. The control is usually labeled intensity and usually has a range of [-1,+1]. The intensity controls scale and, if negative, invert the output of the EG. This changes the patch depends on how the user controls are set. Suppose the normal biased EG is used to filter the cutoff frequency, and the user controls the filter cutoff position as shown in Figure 6.23. The intensity controls may the apparent setting of the user–the control does not move, but it is the center of operation for the EG. In Figure 6.23(a) the intensity is set to +1, and at the end of the attack, the cutoff frequency will have to the maximum value. With the intensity +0.5, the cutoff moves the same thing in the opposite direction, causing the cutoff frequency to decrease as center attack increases. What if the user had placed the control near the top of the range in Figure 6.23(a)? The answer is that the filter would try to go above its maximum value to the maximum value. Likewise for negative intensity values the filter's lower limit acts as the floor, and we clamp the lower end to it.
