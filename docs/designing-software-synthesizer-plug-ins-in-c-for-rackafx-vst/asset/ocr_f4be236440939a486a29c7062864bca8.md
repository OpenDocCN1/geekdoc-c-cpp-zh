positive feedback gain of -1.0 instead of subtracting.

In this circuit, the output of the integrator y is ultimately the output of the lowpass filter. The input into the integrator u(n) = (x(n) - y(n)), so the equation becomes

```
$y = gu(n) + s(n)$
$y = gx(n) - y(n)) + s(n)$
$y = gx(n) - gy(n) + s(n) \quad (4.22)$
```

This appears problematic as y(n) appears on both sides of the equation since we have a delay-less loop between input and output. Zavalish's algebraic solution allows ignoring the fact that discrete time output y(n) appears on both sides of the equation and asserting that the loop can be resolved since the g and s terms are fixed at any time in n. Therefore, Equation 4.22 could be thought of as an instantaneous response equation. Dropping the discrete time n (for convenience) and separating variables results in Equation 4.23.

```
$y = g(x-y) + s \quad (4.23)$
```

Then, apply some algebra:

```
$y = g(x-y) + s$
$y + gy = gx + s$
$y = \frac{gx+s}{1+g} \quad (4.24)$
```

This equation is once again version of y = gx + s and can be found by separating the terms in the numerator and factoring as:

```
$y = \frac{\frac{g}{1+g}x + \frac{s}{1+g}}{1+g} \quad (4.25)$
```

Replacing the two quotients with G and S yields:

```
$y = \frac{\frac{G}{1+G}x + \frac{S}{1+G}}{1+g}$
let:
G = \frac{g}{1+g}$
$S = \frac{s}{1+g}$
then:
$y = Gx + S \quad (4.26)$
```

It was the linear relationship y = gx + s that allows the delay-less loop to be resolved in the input/output equation, so now we need to alter the block diagram to remove that delay path. Evaluating the input v to the summing node of the integrator reveals the new modified structure. It is relatively easy to show that (Zavalanish, 2012):

```
$v = g(x-y) = g(x-Gx-S) = g\frac{x-s}{1+g}$
$= (x-s)\frac{g}{1+g}$
$= G(x-s) \quad (4.27)$
```
