
Second order filters can be synthesized from any second order block diagram containing scalar multipliers, summers and integrators. Interestingly, there are many analog block diagrams that produce the same transfer function. Historically, analog filtering books categorize and list the pros and cons of using different structures. Lindquist’s ‘Active Network Design with Signal Filtering Applications’ tabulates scores of different filter structures, equations and block diagrams. Some of the are more sensitive to errors in the filter components (the real world, non-ideal values of the R, L’s or Cs). Others allow the cutoff or the Q of the filter to be controlled by a single gain factor. In analog design, choosing the proper structure simplifies the problem at hand, so there isn’t necessarily an algorithm that everyone agrees on. However, there is a structure that is especially popular with audio designers called the State Variable Filter or SVF. It is also known as the Kerwin-Huisman-Newcomb (KNH) filter, after its inventors. One of the interesting features of this filter topology is that it directly implements the four-mother filters, the second order LPF, HPF and BPF. The BPF can be calculated by summing the LPF and HPF outputs. Figure 4.19 shows the block diagram of the SVF filter that you can find in just about any analog filter theory book. The derivation of the transfer function from y_LP is done later in the Chapter and produces the standard LPF function; you could also start with this function and work your ways backwards to this diagram.

## Resolving Delay Loops: Modified Method

Next, let's look at some generic examples involving delay-loops to see how more (img/b42d0dca53f4a889d8162d55f7c8c05d_236_1.png) complex structures can be realized using Modified Method. With it, you can easily find the filter structure that resolves the delay-loop. For a single loop filter, the process can be applied swiftly. Recursive filters will use one of the three forms shown in Figure 22. The box marked "Any Network" can be anything from a short, to a simple multiplier, to a complex network that includes at least one delay-path; if there is a processing function in the feed-forward path, it is shown as a generic function of the input f(u). In this notice generic examples, the variables labeled G and S likewise—represent any coefficient multiplier.

Modified Method describes the technique for the block diagram in Figure 22 (a) and with K = 1 so that the feed-forward path is a short circuit. We modify the technique (Pirinkle, 2014) to accommodate the situations where there is something meaningful in the feed-forward path, either a constant gain or function of the loop input f(u). You can find the full derivation at http://www.pirinkle/synthbook/. This modified method can be applied to any filter in the box and is named the Modified Method. Both methods produce the same results and structures. We often found Zavalishin's basic idea is to split the algorithm/block diagram into two parts—one that depends only on the previous samples and not the passing value of the current output y, and the other that depends on the input summed something that depends on the current output y. These are combined together in an equation that runs the delay-loop an infinite number of times in a single sample period. With simple algebra, it reduces down to a very manageable simple difference equation. The structure is synthesized by inspection of the equation or the value of u loop input.

![](img/b42d0dca53f4a889d8162d55f7c8c05d_237_0.png)

For a single loop system, the five-step process is:

- 1. Disconnect the loop by severing the input point at the node u so that the output of the summer and to the loop are open; insert 0.0 into the feed-forward path, around the feedback loop, and into the summer, forming a temporary u₀(n). This includes any processing that occurred in the loop.
- 2. This step is modified to accommodate processing in the forward forward path. If there is nothing except a short in the feed-forward path, y₀(n) = u(n) and the Modified Method is used. If there is only a gain K in the forward path, y₀(n) = Ku(n). However, if there is processing that includes samples in the forward path, then you form the temporary y₀(n) = u(n) through the filter (or series or parallel filters). If the filters use only the linear difference equations, y(n) will have two components: y₀ is the part that depends on the only loop input u₀(n) and yS(n) is the part that depends on the past samples so y₀(n) = y₀(n) + yS(n).
- 3. Find the overall gain coefficient X by creating a delay-free structure that is the original filter structure with all delay elements removed/disconnected and apply an input of 1.0 into the loop with the filter input disconnected; the gain elements are multiplied together.
- 4. The final difference equation is found with Equation 4.39, and it reveals the modified structure by inspection; remember that each delay-loop will be relocated to the output of one or more delay elements in the overall filter structure.

> y(n) = \frac{y_0(n)}{1-X} + y_S(n) \quad (4.39)

- 5. When implementing the filter, we would like to solve for u(n), the input loop value. We can then push that value through the processing blocks. This value will also help derive the final structure.
