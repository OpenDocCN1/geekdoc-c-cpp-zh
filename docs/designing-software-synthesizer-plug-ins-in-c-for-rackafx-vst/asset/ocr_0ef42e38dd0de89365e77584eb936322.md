# initGlobalParameters()

This function is nearly identical to the one in MiniSynthVoice; the operation is the same—call the base class, and then initialize the sub-components (oscillators and filters) and intensity values (these are same as MiniSynth).

# initializeModMatrix()

This function creates and sets up the modulation rows using Table 10.5; it is identical to MiniSynth, except it lacks the LFO for pulse width routing.

# setSampleRate()

Here you only need to call the base class.

# prepareForPlay()

In prepareForPlay() you just call the base class then reset().

# update()

The update() function is simple in DigiSynthVoice—call the base class, then do any voice specific initializations; there are none to do here, but we leave the verification of global parameters in case you want to modify the object.

# reset()

In reset() you just call the base class first, then zero the portamento time.
