## 11.9 AU 中的矢量摇杆

对于 AU 合成器，我们创建了另一个自 NSControl 的自定义控件类，名为 WPTrackPad。接口和实现位于 WPTrackPad.h 和 WPTrackPad.cpp 中。你不需要了解任何操作细节，因为它是完全封装的。该对象的工作方式非常简单——当你点击对象的框架时，它会跟踪鼠标的位置并将屏幕坐标转换为 [-1,+1] 范围内的 (x,y) 坐标。与 VST 类似，它不是菱形，而是将菱形旋转 45 度后的方形。摇杆的位置通过从四个顶点绘制的简单线条所示：![](img/b42d0ca53f4a88d162d55f7c0749_0.png)

WPTrackPad 的声明如下。只有一个名为 getControlCoordsX:Y: 的成员方法，它返回范围 [-1,+1] 内的 (x,y) 坐标。其他变量用于维护鼠标位置。knobScale 变量留供以后使用。

## 将摇杆控件添加到你的插件中分为三个部分。

```objc
@interface WPTrackPad : NSControl
    // --- 这些是原始位置 -1 到 +1
    CGSize currentPosition; // 当前位置
    CGSize mouseDownPosition; // 鼠标按下位置

    // --- 鼠标按下位置
    CGSize mouseDownLocation;

    // --- 鼠标点
    NSPoint mousePoint;

    // --- 默认值为 1.0
    float knobScale;

    // --- 获取鼠标的 XY 坐标
    -(void)getControlCoords:(float*)x Y:(float*)y;
