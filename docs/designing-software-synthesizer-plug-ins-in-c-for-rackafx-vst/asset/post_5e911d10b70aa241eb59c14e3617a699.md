## 2.8 Designing the User Interface

In the Prototype Phase each project starts with a GUI table that lists all interface controls and underlying parameters they control. In RackAFX, each control is automatically connected to a variable that you define. RackAFX writes the code for you. In VST3 and AU, you must manually define each of your controls programmatically. In RackAFX, you use the designer. When you create a new project or open an existing one and the compiler has started, you will be able to add controls to set up or alter it. All the synth projects contain three types of controls:

- continuous controls—values that are continuously adjustable float, double or int types
- enumerated—these controls present the user with a set of strings; select one of these strings at a time
- on/off—a special case of enumerated where the enumeration is fixed to only two values, OFF and ON

An example of a continuous control is a volume control in dB. A slider continuously adjusts a floating point variable that controls the amplitude. An example of enumerated is a GUI element that lets the user select filter type from a list of strings like "HPF", "LPF", and "BPF". The reason we call it enumerated is the list is formed from an enumeration as:

```
enum (LPF, HPF, BPF);
```

![](img/b42d0dca53f4a889d816255f7c8c05d_44_0.png)

Figure 2.7: The New Project dialog is where you setup your C++ object that will become your project. In the enumeration, LPF is assigned the value 0, HPF is 1, etc. In VST3 and AU, you use a “string” to define the controls with a zero-based value. UINT is also #defined so that you can match this code (Apple uses Uint2 instead). In RackAFX, the 40 sliders use the LCD controls may be either continuous or enumerated types. The enumerated types support up to 256 strings, though it is unlikely you will ever need that. In addition there are four sets of radio buttons of which each can hold an enumeration up to eight strings.

For each project, you will be given a Table 2.6. For RackAFX projects, you can ignore the last column that lists the index value, which only pertains to AU. This table has all the GUI controls, limits, defaults, variable names and values that you will attach to the controls. In this table you can see two columns Variable Type and Variable Name. The fundamental types are float, double and enumerated UINT. The Volume and Octave controls ultimately generate numerical values that the user sees on the GUI and have minimum or maximum Limit and default values. A control may also have no units ("" or empty string). The Cutoff control has no "volt/octave" which means this control is logarithmic. Note the Octave control delivers values since the octaves are selected.
