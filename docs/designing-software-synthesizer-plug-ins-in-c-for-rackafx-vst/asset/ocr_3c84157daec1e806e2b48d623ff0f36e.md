There are several rules that must be obeyed for the Fourier series to hold true. The signal to be decomposed must:

+   - be continuous; no discontinuities or glitches
- be periodic
- have been in existence for all time until now
- remain in existence all time

The first limitation is not an issue for sampled signals that have been pass low filtered; the filtering would remove discontinuities. However, when there is a big one—must be periodic. If the signal is quasi-periodic or not periodic at all, like noise? Fourier answers with that the Fourier integral. It states that a quasi or non-periodic signal can be represented as a sum of harmonics; however, the harmonics not necessarily be mathematically related. As before, there might be an infinite number of mathematically related harmonics, but there also might be an infinite number of harmonics in the order ones. Fourier replaced the summation with an integral—the mathematical way of describing this uncountable number of harmonics:

```
$F_n=\frac{1}{2\pi}\int_{-\infty}^{\infty}f(t)e^{-in\omega t}dt \quad (1.7)
```

You can safely ignore the $1/2\pi$ constant. Here, the $F(\omega)$ term represents the harmonic amplitude for any frequency $\omega$
