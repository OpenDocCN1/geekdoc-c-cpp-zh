{
    // get the bits
    UINT b0 = EXTRACT_BITS(uPNRegister, 1, 1); // 1 - b0
    UINT b1 = EXTRACT_BITS(uPNRegister, 2, 1); // 2 - b1
    UINT b27 = EXTRACT_BITS(uPNRegister, 28, 1); // 28 - b27
    UINT b28 = EXTRACT_BITS(uPNRegister, 29, 1); // 29 - b28

    // form the XOR
    UINT b31 = b0^b1^b27^b28;

    // form the mask OR with the register to load b31
    if(b31) {

        // shift one bit to right
        uPNRegister >>= 1;

        // set the b31 bit
        uPNRegister |= b31;

        // convert the input into a floating point number
        // to a range of 0 to +2.0

        // shift down to form a result from -1.0 to +1.0
        fOut -= 1.0;
    }
}

## 5.20 Waveable Oscillators

A Waveable Oscillator is a table-based system for creating periodic signals. A buffer is pre-loaded with one cycle, minus one sample of. The waveform can be mathematical (sin, cos, pulse, square, triangle, etc.) or a recorded signal. The idea is that you read through the table and output samples from it. Consider a table of 1024 samples consisting of one cycle of sinusoid, one sample shown in Figure 5.33.

The table is indexed with the value i, which starts at 0; the last entry in the table is at i = 1023, the sample just before the waveform starts over.

Suppose you are at i = 0, during each sample, you read out one value and advance to the next. At the end of the buffer, you wrap around and start all over. You can now see the table stores one cycle but not exactly—this allows the two ends of the waveform to be sewn together by circular wrap. If you read out one value per sample, what would be the frequency of the waveform? The answer is fs/n, where n is the increment. For a 1024-point wave at 44.1 kHz sample rate, table is 43.066 Hz. If you have sawtooth waveform in the table, it would have frequency of 43.066 Hz.
