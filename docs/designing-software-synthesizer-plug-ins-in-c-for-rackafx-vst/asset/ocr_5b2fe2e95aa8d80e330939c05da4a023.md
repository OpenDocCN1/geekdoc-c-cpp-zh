MIDI 1–16. The upper nibble is the message whose upper bit is always 1. For data bytes, the lower seven bits encode the data information. This provides 128 different values encoded from 0 to 127. A MIDI message consists of at least one status byte and zero or more data bytes. The status byte is always the first in the message. It determines the number of data bytes that will follow. This way, the receiving device knows how to interpret future data bytes.

# 3.2 Channel Voice Messages

The Channel Voice messages contain the most important information that we need. These are listed in Table 3.1.

Let's examine each message.

# 0x8n—Note Off

The note offmessage encodes the MIDI note number and the velocity with which the key was released, most keyboards do not offer this release-velocity option. The note number and velocity are interpreted the same way as for note on messages below. Interestingly you can transmit a note off message by sending a note on message with a velocity of 0. This is common because it is part of another scheme running status, which is a way of compressing data when the status bytes are the same.
