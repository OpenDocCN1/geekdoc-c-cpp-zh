## 2.45 The Event Listeners

The object is more complicated, but mainly because our synths have so many controls (most are 30–40 or so) and we need to confirm to an event callback scheme. We will need IBOutlets for each control group. Next, we need IBActions to act as action handlers. Rather than write a separate handler for each control, we implement one two, for the knob and for the option menu controls. We also set the controls so that they store the index of the parameter. With this, we can make the handlers very short.

We also need some way of communicating with our “buddy” Audio Plug-in. The communication will need to go both ways—when the user moves controls, we need to notify the plug-in, and when a user uses a preset or changes the state of the plug-in, we need to update our controls accordingly. These are done with an Event Listener Callback scheme.

To set up the Event Listening system, you need to implement some methods and call some AU functions. First we need to implement a method that the host will query as what kind of events we want to support. The events consist of:

- parameter changes: the user moves controls and changes a parameter
- gestures: these consist of mouse clicks and movements
- property changes: a property such as reverb tail time or your support of a Cocoa GUI has changed

For our synths, we only care about the parameter changes, so we set the event type using a constant and call AUEventListenerAddEventType to register it.

```objc
(void)addListeners
{
    if (buddyAU) {
        // --- create the event listener
        // and tell it the name of our Dispatcher function
        // EventListenerDispatcher
        verify_noerr(AUEventListenerCreate(EventListenerDispatcher, self,
            CFRunLoopGetCurrent(),
            kCFRunLoopDefaultMode, 0.05,
            0.05,
            &EventListener));

        // --- start with first control 0
        AudioUnitEvent aEvent;
        // --- parameter 0
        AudioUnitParameter parameter = (buddyAU, 0,
            kAudioUnitScope_Global, 0);

        // --- set the parameter de-fact
        aEvent.mParameter = parameter;
        // add it
        AUEventListenerAddEventType(EventListener, &aEvent);

        // parameters 1
        for (int i=1; i<NUMBER_OF_SYNTH_PARAMETERS; i++) {
            aEvent.mParameterID = i;
            // add it
            AUEventListenerAddEventType(EventListener, &aEvent);
        }
    }
}
```

```objc
(void)removeListeners
{
    if (EventListener) {
        verify_noerr(AUEventListenerDispose(EventListener));
        // clear our pointers
        EventListener = NULL;
        buddyAU = NULL;
    }
}
```
