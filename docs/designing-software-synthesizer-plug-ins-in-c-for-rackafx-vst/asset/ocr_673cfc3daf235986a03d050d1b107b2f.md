# 10.7 Audio File Location

Our sample-based synths
go to require either single
samples or folders, and the plug-in needs to know where these files are located. Some options
hardcoding the location, using an installer to write the location in a secret file or the registry, or using some other
method of letting the DLL know the sample file/folder location. An easy way to solve this problem without the need
of registering the registry files is to place the files/folders in the same directory as the DLL (or if AU)
or in a preset sub-directory of this folder. This reason is in both Windows and MacOS, you can query the OS to
 the location of the DLL/component, regardless of the location of the application that is using it.

All sample-based synths in this book will use the DLL or component factor to store samples. The samples themselves
 be in sub-directories of two central folders called /Samples and /MultiSamples.

Finding the DLL/Component factor is so, open the software and use PlugIn->Open Folders to place the ..Plugins folder

- VST3; this is the same as the VST folder you setup in your VST3 client
- AU: ~Library/Audio/Plug-Ins/Components
