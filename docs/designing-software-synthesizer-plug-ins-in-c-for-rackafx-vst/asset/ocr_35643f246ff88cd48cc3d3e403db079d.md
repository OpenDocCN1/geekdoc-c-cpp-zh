# Diamond: Hard Sync sawtooth Oscillator

Brand's original approach to create the MinBLE method was actually doing sync synthesis to develop rich and deep harmonics. In hard sync, one oscillator is designated as the master, and the other is the slave. The two oscillators run at different frequencies with the slave always running a higher rate. The output is from the slave oscillator. When the master's modulo rolls over, it re-triggers the slave module to start over. With a chopped waveform. Figure 5.5 shows the output of two-hard sawtooth waves with the master f0 = 500 Hz and the slave f0 = 1200 Hz. The arrows show the point where the slave module controller has been reset. The spectrum is rich with harmonics, modulating the slave oscillator with a LFO a commonly used and very interesting output.
