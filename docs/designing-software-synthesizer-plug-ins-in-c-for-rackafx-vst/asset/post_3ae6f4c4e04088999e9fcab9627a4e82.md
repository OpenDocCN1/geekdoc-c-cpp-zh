## 2.27 VST3 Processor Initialization

In the VSTSynthProcessor.cpp file you handle the initialization of the plug-in, beginning with the constructor. For VST3 plugins, the first line of the constructor calls the method setControllerClass() and passes the Controller's GUID for the argument declaring the Controller it is paired with. This is part of the underlying COM component and you don't need to worry about it, just make sure your Processor components always call this in the constructor.
