An issue with serialization is versioning—if you release your plug-in to the public and then revise it to add more parameters, you will need to update the serialization code and implement it in a way that doesn't crash the new file structure will be different. This is usually done by writing a version number as the very first value in the file. Then, when you read the file you can use that version number to figure out the sequence of variables in the file. The version number is a 64-bit integer and it is defined in the Processor.cpp file. We will read this value first, then use it if we need to—you dont really worry about versioning until you release your plug-in to the public. You will see an example of versioning in Chapter 13.
