The term $T_{13}T_{45}$ in the numerator is a cascade of first order LPFs (LPF1 and LPF2) and represents the forward path. The term $T_{45}T_{63}$ in the denominator represents a second order BPF in the feedback path consisting of LPF2 and HPF1. All filters have the same cutoff frequency $f_c$ and are said to be synchronously tuned. This results in a BPF with a Q of 0.5 in the feedback branch. By adding this signal back with the input cascade of LPFs, the Q is either emphasized (high feedback) or de-emphasized (low feedback), and the value of K determines this amount of feedback and thus the Q of the filter. This conceptual diagram is shown in Figure 7.12.

We can extract the gain, cutoff frequency and Q from the transfer function as:

```
$H_0 = K = K1K2$$
$$Q_0 = \frac{1}{\sqrt{R_cR_cC_c}} = \frac{1}{(1-K1K3)R_c+R_c}} \(7.9)$
```

For a normalized filter with $R_1C_1 = R_2C_2 = 1$

```
$Q = \frac{1}{2-2K1} \(7.10)$
```

Let $K_1 = 1.0$, self-oscillation occurs when $K_2 = 2.0$ and $Q$ goes to infinity, which is the value for our model. Also notice that $H_0 = K$, we need to normalize the output at $1/K$ to keep the overall filter gain at $1.0$. In the original filter, the feedback into $C_2$ can be set to $0.0$, resulting in a critically damped LPF with $Q = 0.5$. The problem is that when $K = 0$ there is no feedback gain through our model. So we can let $K$ vary a very small, non-zero value to emulate the zero feedback condition. In our $K$ varies from $0.1$ to $2.0$.

Like the Oberheim SEM filter, high resonance can cause the filter to clip and distort. As the resonance approaches self-oscillation, the gain at becomes excessive and in excess of 60 dB (a factor of 1000).
