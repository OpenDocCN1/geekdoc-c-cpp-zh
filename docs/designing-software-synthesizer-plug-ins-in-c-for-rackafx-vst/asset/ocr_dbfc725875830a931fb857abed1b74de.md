# Note
Events, Control Changes and Rendering

The rest of the VST functionality is contained in the process() method. For an audio effect, you receive a buffer of audio input samples, process them and then write them out to an output buffer; the input and output buffers are the same size. For synthesizers, you only write to the output buffer—there is no input. The size of the output buffer is not guaranteed to remain constant, so you cannot hard-code some aspects of the process() method. Cubase tends to use buffers that are 1/100 size rate or 10sec in length. The important thing to note is that the MIDI event and control information is time-aligned with the buffer so that the events and control changes that happened during time-slice are delivered to the process() method along with the buffers.
