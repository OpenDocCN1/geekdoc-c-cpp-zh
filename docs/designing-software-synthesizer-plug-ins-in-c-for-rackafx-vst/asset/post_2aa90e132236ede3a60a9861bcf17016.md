PM

Phase modulation is implemented slightly between the two oscillator objects. The QCBLimitOscillator use the modulo counter and increment it not only the一来 but to fashion the output waveform. The modulo goes from 0.0 to 1.0 during one cycle of the waveform, therefore the current modulo output represents a phase value of 0 to 2π radians. This is shown in Figure 12.19.

Therefore, we can catch the instantaneous phase of the oscillator by offsetting the current value of the modulo counter.

In DXSynth, the index of phase modulo, which is also the phase deviation, is given as a multiple of 2π radians. Experimenting with a DX100 revealed the maximum phase deviation to be 8.0π radians. In DXSynth the phase deviation is given as a value from 0.0 to 4.0, according to Chowings' iMAX range of 0 to 4. When applied to a bipolar sinusoidal oscillator, it produces a phase deviation from -8.0π to +8.0π. Thus a phase deviation of +1.0 means a shift equal to complete waveform or +2π radians.

So, if we add a value of 1.0 to the current modulo value, we shift the phase forward by 2π radians. If we subtract 1.0, we are shifting backwards by 2π radians. The COscillator object has a phase modulation variable and a set() function for it. So, phase modulation is implemented as an offset to the modulo counter. Because the offset can be greater than 1, we have to wrap the increment value multiple times until it falls inside the modulo interval of [0..1]. This code is QCBLimitOscillator's dooscillator() method.
