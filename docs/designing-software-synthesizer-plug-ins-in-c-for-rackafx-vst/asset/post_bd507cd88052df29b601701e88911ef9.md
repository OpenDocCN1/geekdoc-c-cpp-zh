However, an inexpensive and flexible way to generate many different sawtooth waveforms is to alter the shape of the initial sawtooth ramp using a nonlinear function with the waveshaping you saw in Chapter 4 and let BLEP/PolyBLEP handle the discontinuity.

- pBLETable: pointer to the BLEP table of choice
- dTableLen: length of BLEP table
- dPointsPerSide: number of points per side of the discontinuity (N) to correct
- binterpolate: flag for enabling interpolation; default is false (disabled)

```cpp
inline double dBLE_N(const double dBLETable, double dTableLen,
double dModulo, double inc, double dHeight,
bool bRisingEdge, double dPointsPerSide,
bool binterpolate = false)
```

```cpp
// return value
double BLEP = 0.0;

// t = the distance from the discontinuity
double t = 0.0;

// --- find the center of table (discontinuity location)
double dTableCenter = dTableLen/2.0 - 1;

// LEFT side of edge
// -1 < t < 0
for(int i = 1; i <= (UINT)dPointsPerSide; i++)
{
    if(dModulo > 1.0 - (double)i*dinc)
    {
        // --- calculate distance
        t = (dModulo - 1.0)/(dPointsPerSide*dinc);
    }

    // calculate residual index location
    float fIndex = (1.0 + t)*dTableCenter;

    // --- truncation
    if(binterpolate)
        dBLEP = pBLETable[(int)fIndex];
    else
    {
        float frac = fIndex - int(fIndex);
        dBLEP = dLerp(0, pBLETable[(int)fIndex], pBLETable[(int)fIndex+1], frac);
    }

    // --- subtract for falling, add for rising
    if(bRisingEdge)
        dBLEP ~ -1.0;
    return dBLEP*dHeight;
}
// RIGHT side of discontinuity
// 0 < t < 1
for(int i = 1; i < (UINT)dPointsPerSide; i++) {
    if(dModulo((double)i)*dinc) {
        // calculate distance
        t = dModulo/(dPointsPerSide*dinc);
        // calculate residual index location
        float index = t*dTableCenter + (dTableCenter + 1.0);
        // truncation
        if(binterpolate)
            dBLEP = pBLETable[(int)index];
        } else {
            float frac = index - int(index);
            if((int)index+1 > dTableLen)
                dBLEP = dLinInterp(0, 1, pBLETable[(int)index], pBLETable[0], frac);
            } else {
                dBLEP = dLinInterp(0, 1, pBLETable[(int)index], pBLETable[(int)index+1], frac);
            }
        }
    } // subtract for falling, and for rising edge
    if(bRisingEdge)
        dBLEP ~ -1.0;
    return dBLEP*dHeight;
} // no BLEP residual
return 0.0;
```

Another option is to perform one-sided saturation on the modulo value prior to or during the conversion to bipolar. This produces another set of waveforms using the "fat sawtooth," which also resembles the imperfect analog sawtooth waveforms from our synth shown in Figure 5.18 (a). This is done with the following code:

```cpp
// wave shape the module, then convert bipolar
trivial_saw = 2.0*(tanh(sat*SawModule)/tanh(sat)) - 1.0;
```
