If we can describe the first sinusoid as e^{jwt} then the delayed version is e^{jwt(t-n)}. Because at time t=0, the first sinusoid starts, and its complex value is e^{j0}. At time t n samples, the second sinusoid starts. Its complex value must be the same as this first starting point, e^{j0}. The only way this will happen is if we modify the exponent as e^{jwt(t-n)}, so when t=n, the result is e^{j0}. Looking at the e^{jwt(t-n)} term and remembering the polynomial behavior of the example, we can write the following:

```
e^{jwt(t-n)} = e^{jwt}e^{-jnwt}
```

The delayed signal equals the original signal e^{jwt} multiplied by e^{-jnwt}-this is really interesting. Even more amazing is that the multiplication is devised of the dependent variable. You can see that we let the real part of s be 0 (that is, σ=0) then e^{-snT} becomes e^{-jn} where n is the number of samples delayed and T is the sample interval. Normalizing so that T=1 (meaning a 1 Hz sample rate), the two terms are synchronous; e^{-sn} becomes e^{-jn}. Therefore, multiplying a signal by z^{-n} delays it by n samples.

The z-Transform converts a sampled signal or function whose variable is samples-in, nT into a signal or function whose variable is the complex variable z=a+jb.

It might look daunting at first, but you can quickly learn the Laplace and z-transform of block diagrams by inspection using just a few rules. We will discuss this further in Chapter 4.

# 1.13 Aliasing

In our oscillator (and some filter) designs, we will be fighting against aliasing. In a digital audio system with input and output, aliasing occurs if you do not properly limit the input signal. A consequence of sampling a signal is that its spectrum is replicated up and down the frequency axis. This is shown in Figure 1.22 where a properly bandlimited signal is sampled at some rate fs.
