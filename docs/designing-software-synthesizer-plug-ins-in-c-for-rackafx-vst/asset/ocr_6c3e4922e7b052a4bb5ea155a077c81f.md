# setLFODestination()

In setLFODestination you decode the index of the operator and then manipulate its modulation matrix source values. You set the m_uModSourceAmp and/or m_uModSourceFo to the appropriate LFO output destination in a giant switch/case statement. If the user selects none, then you set both to DEST_NONE. This is done on each operator independently (DEST_OSC1_OUTPUT_AMP and DEST_OSC1_FO go with Operator 1, while DEST_OSC2_OUTPUT_AMP and DEST_OSC2_FO go with Operator 2, etc.)
