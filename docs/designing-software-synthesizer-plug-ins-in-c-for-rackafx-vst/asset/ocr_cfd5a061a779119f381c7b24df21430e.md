# 7.18 The CDodeLadderFilter Object

Theode Ladder filter is the most complex of the group. The multiple feedback paths complicate the design and increase the complexity of the block diagram, as well as the VA one-pole filter object that will implement each stage. Therefore this model is optional; feel free to skip it over, as it adds one more filter—another fourth order LPF. This model uses four one-pole filter elements to implement the four filtering stages. The same four Filter overrides will also be implemented. Figure 7.52 shows the class diagram for the CDodeLadderFilter.

# CDodeLadderFilter Member Variables

Refer to Figures 7.40 and 7.44 to see there are four sub-filters: LPF1, LPF2, LPF3 and LPF4, as well as coefficients SG1, SG2, SG3, and SG4. We will make the member variables of the object. The filters are declared as member objects of type CVAOnePoleFilter and named m_LPF1, m_LPF2, m_LPF3 and m_LPF4.
