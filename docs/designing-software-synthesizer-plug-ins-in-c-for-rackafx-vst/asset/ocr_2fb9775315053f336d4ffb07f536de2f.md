The normal BLEP function processing two points is ideal, except for the calculation of the residual value. The BLEP function looks up value from a table using interpolation if it is enabled. Each table is 4096 points in length. The first half from index 0 to 2047 contains the BLEP residual for the points on the left of the discontinuity, while the right half from index 2048 to 4095 contains the BLEP residual for the points on the right of the discontinuity.
