## 2.41 实现 Cocoa 视图对象

合成器项目的 GUI 均实现为 Cocoa 类。要使用 Cocoa，你需要创建两组文件：一个视图工厂（view factory）和一个主 GUI 视图（main GUI view）。在合成器项目中，工厂始终命名为 `ViewFactory`（例如 `MiniSynthFactory`），视图命名为例如 `MiniSynthView`。这两个对象封装在标准的 `.h` 和 `.m` 文件中。当你告诉宿主机支持 Cocoa 接口时，你回复视图工厂的名称。当框架初始化工厂对象时，它会传递指向 Audio Unit 插件的指针。工厂加载视图对象并将其传递给 AU。你就可以与 Audio Unit 建立通信，以便传输控制更改信息。工厂与视图之间的关系在 Interface Builder 中设置。所有合成器的 NIB 文件均命名为 `CocoaView.NIB`。图 2.45 显示了两者在 InterfaceBuilder 中是如何连接的。

NIB 文件的所有者（Owner）设置为 `ViewFactory`，视图通过引用输出（Referencing Outlet）连接。由于它们在 IB 中连接，因此视图会在 NIB 反序列化时加载，工厂不需要显式地初始化然后加载子视图。视图上的所有控件都通过引用输出（IBOutlets）和发送动作（Sent Actions，即 IBactions）连接到它。动作动作不连接到工厂，只连接到视图。

图 2.47：IB 中的 MiniSynth Cocoa 视图。

书中的每个合成器都有种类的控件：一种显示连续控制（如旋钮或滑块），另一种显示菜单或字符串列表（这些列表是带索引的）。我们自定义设计了两种控件：一个旋转旋钮和一个选项菜单组。旋转控件类型为 `WPRotaryKnobXY`，选项组为 `WOptionMenuGroupXY` 对象，其中 XY 是两个字母的缩写（MS = MiniSynth, DX = DXSynth）。正如我们讨论过的，Cocoa 有一个扁平命名空间，你需要工厂、视图以及任何自定义视图。在 IB 中，从调板中拖入一个视图对象到视图中，然后将其类设置为 `WKnob` 或 `WOption`。然后连接一个输出和一个动作来使用该控件。这在图 2.46 中所示。
