When programming CVectorPathGenerator object, you have the choice of using joystick coordinates, the literal coordinate system from the Prophet-VS/Wavestation and what RackAFX uses, or you can program with the rotated coordinates; these are easy-to-remember locations, this is actually simple and just your choice. # Programming

Both versus in this chapter use the now familiar CVoice derived objects to handle the voice choirs. Both declare a static member of type CVectorPathGenerator named m_VPG. Programming requires a set of function calls to one function named setProgramStep.

```
void CVectorPathGenerator::setProgramStep(int nIndex, float fX, float fY, float fTimeToNextStep_mSec, bool bJoystickCoords)
```

The arguments are:

+   - nIndex: the zero-based index of the step (path vertex) you are adding
- fX and fy: the (x,y) coordinate of the new vertex
- fTimeToNextStep_mSec: the segment transition time to the next vertex
- bJoystickCoords: true if you are using your lyrical coordinates, if you are using the rotated version
