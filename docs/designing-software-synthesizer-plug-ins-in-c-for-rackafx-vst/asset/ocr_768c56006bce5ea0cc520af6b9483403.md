# ## 0Cn—Program Change

The Program Change message transmits a single value between 0 and 127, which selects a patch numerically 1 to 128 on a synth. We will trap and identify this message in our synths but not use it until you forge ahead and build your own multi-program synth.

# ## 0Dn—Channel Aftertouch

Channel Aftertouch is similar to Aftertouch but is not transmitted separately for each note. Instead, it is transmitted globally and to all notes on a particular channel. Since it is a less expensive option, many more controllers implement it instead Polyphonic Key Pressure.

# ## 0Ex—Pitch Bend

The Pitch Bend Message is a special kind of Voice Message because of the way it is decoded. It is usually generated with a joystick or wheel. Pitch bend dectoded uses two data bytes to encode a bipolar value with 0 in the center (no pitch bend). Positive pitch bend values indicate an increase in pitch (sharp) while negative values indicate a drop in pitch (flat). Most synthesizers feature a pitch bend range of at least one octave while +/- 4 octaves. If only one data byte was used to transmit the value, your ear would hear the bend as a series of discrete bumps in pitch rather than smooth and continuous change. Smooth transitions are accomplished using two data bytes, each contributing 7 bits to a 14-bit value resulting in 16,384 values—enough to produce smooth bends. The first data byte encodes the LSB and the second MSB of this 14-bit word as shown in Figure 3.

MIDI 1.0 specifies pitch bend as a bipolar range of values with:

+   * 0x00 00 = most negative (flat) pitch bend
* 0x00 64 = center (0)
* 0x7F 7F = most positive (sharp) pitch bend

For calculations it is easier to convert this into a bipolar value, so that 0 applies no pitch change. The 16,384 values are then spread across a bipolar range of -8192 to +8191 or -1.0 to +0.999.
