For all platforms, the core audio rendering is the same. Compare with the code in the last chapter (here only new code is bold):

- the EG's based output is now connected to both the filter cutoff and the oscillator pitch modulation inputs
- the EG to filter modulation is direct; there is no intensity control
- the EG to oscillator modulation has an intensity control
- we need to check for filter key-tracking and force the filter's cutoff to modulated value if needed
- the filter processing happens between the oscillator and DCA blocks

```cpp
void CMoogLadder::reset() {
  // flush everything
  m_LPF1.reset();
  m_LPF2.reset();
  m_LPF3.reset();
  m_LPF4.reset();
}
```

It is important to notice how the modulation calculations work. In every case, the equation comes down to:

```
mod = (intensity) (range) (modulator output)
```

```cpp
void CMoogLadder::setControl(double dQControl) {
  // maps dQControl - 1->10 to K = 0 - 4
  m_dK = (4.0)*(dQControl - 1.0)/(10.0 - 1.0);
}
```

In some cases the intensity and range may be 1.0, but the equation is universal. We will exploit it when we design the modulation matrix in the next Chapter.
