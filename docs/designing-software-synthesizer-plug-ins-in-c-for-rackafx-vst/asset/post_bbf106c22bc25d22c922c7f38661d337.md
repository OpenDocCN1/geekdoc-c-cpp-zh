The term $T_{13}T_{45}$ in the numerator is a cascade of first order LPFs (LPF1 and LPF2) and represents the forward path. The term $T_{45}T_{63}$ in the denominator represents a second order BPF in the feedback path consisting of LPF2 and HPF1. All filters have the same cutoff frequency $f_c$ and are said to be synchronously tuned. This results in a BPF with a Q of 0.5 in the feedback branch. By adding this signal back with the input cascade of LPFs, the Q is either emphasized (high feedback) or de-emphasized (low feedback), and the value of K determines this amount of feedback and thus the Q of the filter. This conceptual diagram is shown in Figure 7.12.

We can extract the gain, cutoff frequency and Q from the transfer function as:

```
$H_0 = K = K1K2$$
$$Q_0 = \frac{1}{\sqrt{R_cR_cC_c}} = \frac{1}{(1-K1K3)R_c+R_c}} (7.9)$
```

For a normalized filter with $R_1C_1 = R_2C_2 = 1$

```
$Q = \frac{1}{2-2K1} (7.10)$
```

Let $K_1 = 1.0$, self-oscillation occurs when $K_2 = 2.0$ and $Q$ goes to infinity, which is the value for our model. Also notice that $H_0 = K$, we need to normalize the output at $1/K$ to keep the overall filter gain at $1.0$. In the original filter, the feedback into $C_2$ can be set to $0.0$, resulting in a critically damped LPF with $Q = 0.5$. The problem is that when $K = 0$ there is no feedback gain through our model. So we can let $K$ vary a very small, non-zero value to emulate the zero feedback condition. In our $K$ varies from $0.1$ to $2.0$.

Like the Oberheim SEM filter, high resonance can cause the filter to clip and distort. As the resonance approaches self-oscillation, the gain at becomes excessive and in excess of 60 dB (a factor of 1000).

To mitigate this, Korg engineers played diode clipping circuit in the feedback loop. The circuit is similar to the diode clipping faults used in effects boxes and processors. This clipping produces the limiting function but also adds its soft clipping distortion, and the Karg35 filters are known for their outputs at high resonance settings. In our Virtual Analog model of the Karg35, we use VA blocks with the LPF and HPF components in a delay-less feedback loop. The addition of the nonlinear processing (NLP) of the feedback loop causes a very tuning drift, however it is negligible as long as we use a clipping function. Figure 7.13 shows the nonlinear model. Note that the NLP is placed before LPF2; this is because of way the conceptual bandpass filter works in the feedback loop. LPF2 forms half of this bandpass filter, and the signal needs to be saturated to the loop and thus prior to this.

## 7.5 Karg35 HPF Model

The Karg35 HPF circuit results from analog method of converting a LPF to HPF by grounding the input and driving the ground (Lindquist, 1977). When this is applied to the Sallen-Key topology, the resulting HPF has only 6 dB/octave of rolloff instead of 12 dB. Stinchcombe (2006) derived the resulting analog transfer function that revealed a BPF in parallel with the second order caused the first order rolloff phenomenon. By starting with Sallen-Key HPF topology and adding a parallel BPF in the HPF input section, we can achieve the same result. Figure 7.18 shows the block diagram of the Sallen-Key

img/b42d0dca53f4a889d8162d55f7c8c05d_400_1.png

HPF with the parallel BPF to the input path and the NLP in the feedback loop. However, we can greatly simplify this by creating another hybrid flow graph HPF in the feedforward path and a second order BPF in the feedback loop, resulting in the signal flow graph and block diagram in Figure 7.19. Not bound to the analog circuit, we can synthesize hybrid version in code. We can also derive the resulting function and show that it is identical to the conceptual model (Pyrkle, 2013). Like the LPF, the HPF analog filters can be derived from the signal flow graph. The bandpass filter (first) in parallel with the order highpass filter (second) and the gain, cutoff and Q values.

For a normalized filter $R_1C_1 = R_2C_2 = 1$

```
$$\frac{KT_{C2}}{1-K} = \frac{sR_{C1}R_{C2}}{(sR_{C1}R_{C2}+(s(1-K)R_{C1}+R_{C2})+1)(sR_{C1}R_{C2}+(s(1-K)R_{C1}+R_{C2})+1)}$$
```

Letting $K_1 = 1.0$, self-oscillation occurs when $K_2 = 2.0$, which is the value for our model. Since $H_{\omega} = \frac{1}{\sqrt{R_{C1}R_{C2}}} = K$ we will need to normalize the output to $1/K$ to keep the filter gain at $1.0$. Like the LPF, the block K can be set to $0.0$ so that none of the bandpass signal is added to the input path. With $K=0$ there is no forward gain through the filter. So, we can let $K$ on a very small non-zero minimum value. In our emulation, it varies from $0.01$ to $2.0$.

```
$Q = \frac{\sqrt{R_{C1}R_{C2}}}{(1-K1K2)R_{C1}+R_{C2}}$ (7.13)
```

```
$Q = \frac{1}{2-K1K2}$ (7.14)
```
