# # 6.4 Note Off Modes

The release or sustain may get triggered before the EG has entered the sustain point represented by the "NOTE OFF" arrows in Figure 6.13. In this event, we use the last EG output as the starting point, and then descend the release or sustain segment from that. For our analog EG, this means that the release time will be longer if the note is released at a level above the sustain point and shorter if released below, as shown in Figures 6.13(c) and (d). This also tends to sound natural for many types of patches. In Figure 6.13(a) we can see the importance of the concept that the release time is the decay time from scale to 0.0, as the note is above the sustain level.
