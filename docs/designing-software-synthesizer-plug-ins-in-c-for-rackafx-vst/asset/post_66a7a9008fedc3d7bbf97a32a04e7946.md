rand(NULL);

## 5.17 Pseudo Random Noise (PN Sequence) Oscillator

Pseudo random noise (PN) generators create a noise-like output that is flat. The random noise generation function is:

```
float fNoise = (float)rand() / 32767.0 - 1.0;
```

The algorithm for PN sequence is:

- start with a 32-bit register initialized to any value
- on each sample period form the result:
$b31 = b0\oplus b1\oplus b27\oplus b28$;
- shift the register to the right
- load the MSB (b31) with the calculated value

The XOR operation produces a binary 1 when the two inputs are different. The scale-ing formulas for each:

| Word Length | Formula |
|---|---|
| 8 | $h_0 = b_0\oplus b_1\oplus b_2\oplus b_3$ |
| 16 | $h_4 = b_0\oplus b_1\oplus b_4\oplus b_7$ |
| 24 | $h_8 = b_0\oplus b_1\oplus b_8\oplus b_{11}$ |
| 32 | $h_{12} = b_0\oplus b_1\oplus b_{12}\oplus b_{15}$ |
| 64 | $h_{16} = b_0\oplus b_1\oplus b_{16}\oplus b_{31}$ |
