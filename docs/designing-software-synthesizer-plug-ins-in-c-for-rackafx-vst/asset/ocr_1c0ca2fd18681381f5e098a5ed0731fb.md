There are some important restrictions on wavetable. The CAniSynthVoice swaps out table pointers as the active cell changes. The oscillator's index values are not altered during the swap. Therefore it is imperative that the wavetable adhere to the following rules (note: you can use single-samples or multi-samples).

+   - all tables must be the length in samples
- all tables should hold one cycle of a waveform and hold the same number of cycles per table
- if the number of cycles per table is more than one, you will need to alter the tuning equation
- the quality of the synthesis is directly related to the quality of the wavetable
- arrangement of the table rows (aka AniMoog's timbres) is also an important consideration
