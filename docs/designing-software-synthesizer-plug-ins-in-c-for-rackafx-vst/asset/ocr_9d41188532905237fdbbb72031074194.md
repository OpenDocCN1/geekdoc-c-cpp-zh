The outer container is called a view. VSTGUI uses a C++ object named CViewController to represent it. The CViewController object has an attribute that allows you to put it with a background. If you use PNG files, your skins can be transparent or partially transparent. Inside of the outer container, you can see some blocks labeled Osc, Filter, etc. these contain groupings of controls. If you look at the screenshots of the actual GUIs, you will see that the blocks also have a skin, with rounded corners and a dark area at the top for a label. In fact, these are CViewContainers with a PNG file used for the skin. They are referenced by the location of their origins (upper left) relative to their outer container. Figure 2.30 shows the corner-coordinates of these columns. They all have the same y-coordinate of 5 units (positive). The x-coordinates reveal the columnar view containers must be 85 units wide, thus the progression of 5, 90, 175, 260, etc. There are two (or three for DXSynth) rows of controls on the right, which always has the same coordinate locations. These rows are 110 pixels in height the progression of 5, 115, for the y-coordinate.

This layout of CViewContainers in Figure 2.29 is the same for the five synth projects: NanoSynth, MiniSynth, DigiSynth, VectorSynth and AniSynth use this same format, making it easy to copy the project files.
