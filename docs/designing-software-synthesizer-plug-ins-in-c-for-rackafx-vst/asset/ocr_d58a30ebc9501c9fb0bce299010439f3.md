The first four rows are fairly self-explanatory—we want to map Velocity to the DCA velocity input, the Pitch Bend we

These are not the only routings—you can get very clever and expressive here. For example, you could add a row
that lets MIDI Velocity alter the cut-off frequency so that the cutoff moves up with increasing key velocity. Using the
MIDI note as a modulation source is extremely popular as well. The last two routings are more advanced
