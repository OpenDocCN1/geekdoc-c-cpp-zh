You need to fill the Slider Properties with the proper values. You will notice that uControlID is 0 for this slider. This is the ID that will link the slider to a variable. You cannot edit this cell. Start with the Control Name and "Volume" (no quotes). Hit advance to the next cell, then set the Units to "dB". The next cell is one of the most important—it is the data type for the variable that will be linked; with choices from a drop-down list. You can select the data type with the mouse, or you just type the first letter (e.g. "d" for double) while the box is highlighted. The linear and log (arithmetic) sliders move with these offsets, and you could use a log control for volume if needed. However, for some synth frequency controls as the cutoff frequency for a filter, you want to choose the volt/octave option. This will make the control in a 2N fashion (i.e. in octaves), which is how synth work when using this taper (NOTE: in VST3/AU this volt/octave is called "Logarithmic Scale"). If you realize a mistake or left something out, just right-click in the slider box and fix the problem. You can also remove the slider by clicking the button on the Properties Window, and you can copy the settings of another slider with the Copy Existing Slider Control drop-down list.

As you add, edit or remove controls from the main UI, you will notice that RackAFX will flash to the compiler and as it writes the code for you. You might use this flashing as a signal that the code update is synchronized. If you don't like it, minimize the compiler and the flashing will not occur. There is a special check-box in View->Preferences to start the compiler for this reason (Visual Studio 2008 only; Microsoft removed the ability later).

You will see the note frequently in the code as a reminder that can be cut out for easy reading. Aside from the plug-in functions discussed in Chapter 2, you will see more commented areas of code. This is the portion of the .h file that RackAFX modifies when you add, edit or delete controls. There are other properties of code that have interesting hex symbols (0x1A7F...), do not edit the code contained between them. RackAFX writes C++ code for you. You will have to be careful not to alter RackAFX C++ code in any way.

### 2.12 Placing Controls Inside the LCD Control

![](img/b42d0dca53f4a889d8162d557c8c05d_49_0.png)Figure 2.10: Configuring the radio button group is simple as the slider control.

In the upper right of the RackAFX UI is a control that represents an alpha wheel, LCD monitor view, and knob. During the design of your project,'ve noticed that the LCD is used to give you feedback about the state of your project and computer. However, it can also be used as a GUI control just like the other sliders. The LCD allows you to store up to 1024 continuous sliders inside. Anything setup with a normal slider will work as well as the LCD embedded, and the GUI Designer lets you pick one on your custom GUI. There are several uses for the control:

- it's a way to store the continuous controls
- if you run out of sliders, you can put 1024 more of them in the LCD
- you can use enumerated controls to create a set of presets or other global functions or configurations—we will use this extensively for global parameters in the synths such as pitch band range, and it will tidy up the GUI by using controls in a small preset
