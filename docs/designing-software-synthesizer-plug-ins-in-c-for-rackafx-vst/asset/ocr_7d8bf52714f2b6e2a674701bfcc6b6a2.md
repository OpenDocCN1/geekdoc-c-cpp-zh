# Voice Mode

# struct noteRegion

In DigiSynth m_uVoiceMode variable has four choices, shown in Table 10.4. Figure 10.12 shows the arrangement for split and layer modes. In split mode, some notes overlap, in layer mode, some velocities overlap. In these cases, oscillators are mixed.

```
{
  // --- note range of the Region
  UINT uMIDINoteLow;
  UINT uMIDINoteHigh;

  // -- velocity range of the Region
  UINT uMIDiVelocityLow;
  UINT uMIDiVelocityHigh;
}
```
