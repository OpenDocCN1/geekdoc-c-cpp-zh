In early analog systems, there were three signals generated when the user pressed a key on the keyboard: a pitch control voltage (CV) that corresponds to the pitch of the note, and two control signals the trigger and gate identified on and off events. The trigger is a digital pulse representing the start of a note event. The gate changes on the same edge as the trigger but stays for the duration of the note event. Therefore, in this 1 = ON logic, the trigger’s rising edge represents the note on and the gate’s falling edge represents the note off.
