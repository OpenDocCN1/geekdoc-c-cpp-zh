# Resolving Delay-Less Loops: Zavalishan's Method

When working with Zavalishan's method, you can either solve for the output y or solve for u, the input to
loop. In either case, you synthesize the filter structure by examining the resulting equations in exactly the same
or as the Modified Härm method—by inspection. Zavalishan's method is more of an algebraic approach. You
or may not find it easier than the Modified Härm method.

In this first example it is trivial to solve for u, but as the filters become more complex, solving for u usually leads to
a more complicated realization than solving for the output y. For the rest of the book, we will be solving for this
input value not only to synthesize the block diagram but also to facilitate the coding. You can also cross-check your
 using the Modified Härm method to both input u and output y.
