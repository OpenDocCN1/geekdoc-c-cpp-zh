# Instructions

In this example, if the players don't click that link, they don't go to the "Pass Out" passage. But maybe you don't want to give them that choice. Instead, you want to force them to go to the "Pass Out" passage when $fear hits 4.

For that, we can use a different macro called goto. Goto takes the players to a new passage automatically. They don't get the chance to click a link—they're just shown the new passage. That works perfectly for what we want to do! Let's change that conditional statement and add it after the "if: $fear is >= 2."

```
(if: $fear is 4)[(goto: "Pass Out")]
```

Now, when the players enter this passage and their $fear is 4, they'll be taken to a new passage—“Pass Out” Unlike with links, you'll have to create this passage manually. But that now—and make sure you capitalize, otherwise the game won't know where to go!

Let's make a quick edit to the "Pass Out" passage so the players get some information about what happened. Remember, they didn't get a link displayed to them, and they don't see passage titles! Add the following to the Pass Out passage:

You awake, dazed and confused, just outside the Abandoned Field.

After this, include a link to the "Abandoned Field" passage so they can get back into the game! Also, let's reset their fear—otherwise it will just keep going on! It makes sense to have them reset so they can make different choices. To reset, set the $fear variable to 0 here. It will overwrite whatever the current $fear value is and make it zero. The player is starting fresh and unaraid after passing out!

Again, test your game out. Try approaching the house and heading back to the field a number of times until you trigger the macro to make yourself pass out. Watch the fear variable as you do this to see how it goes up and then resets to zero (hopefully!).
