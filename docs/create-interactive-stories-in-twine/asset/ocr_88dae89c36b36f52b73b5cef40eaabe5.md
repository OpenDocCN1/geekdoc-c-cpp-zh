# TWINE GAMES:
WIND IT UP

Twine is a tool that allows you to create digital interactive fiction games that can be shared with the world. Creating Twine games will draw from many of the skills you developed making your analog (or nondigital) interactive fiction. As far as gameplay, Twine falls somewhere between CYOP games and Parsely games. Interactions in Twine are often selecting between a series of choices—like CYOP games—but you can use many of the open-ended gameplay and requirements from Parsely, as well.
Every activity in this chapter will require a computer and Twine, unless otherwise noted.

# Let's Take a Tour

+   5–10 minutes

Before you can get started with Twine, you'll need to either download or open the program online. You can find the Twine program at http://twinery.org. There, you can download the program for Windows, macOS or Linux, depending on the computer you are using. All these activities will be based on Twine 2, so you'll want to download the latest version available that starts with a 2. You can also create your game online, which will work on any computer.
