# Showing Some New Text

10-15 minutes

Now that we are using variables to accumulate fear, we need to do something with that fear. To do this, we can use something called a conditional statement that tells Twine the following: if $fear is a certain value, then do something. The basic structure of the if conditional statement is as follows:

```
(if: $variable is value)[do this]
```

If the value is a number, you can just put that number there. If it's text, then you need to put it in quotations—remember?

+   - (if $fear is 5)
- (if $belly is "bloated")
