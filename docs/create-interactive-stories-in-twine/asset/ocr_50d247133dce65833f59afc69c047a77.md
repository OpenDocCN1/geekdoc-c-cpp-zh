# Revisiting a Few Old Friends

5–10 minutes Idea sheet, pencil

# Activity Overview

Much of the planning work you did for creating your CYOP game is still a great way to approach designing a Parsely game. In fact, many of these activities will help you no matter what stage of the design process you're taking on!

# Instructions

Go back through the starting CYOP design process–the first six activities–to create a new story for your Parsely game.
If you don't want to start over–instead using the same design you used for your CYOP game–that’s part of the beauty of designing these stories. You can use whatever you want as your starting point!

# The Format

Parsely games have a different format than the CYOP game that we designed earlier. In a Parsely game, the focus is more on building an explorable space for the players and there is a lot less actual writing. Because someone else will be running your game, the writing approach is not the same. You are writing instructions for the player to be able to run your game, with information broken between two elements: a map and a narrative sheet.
The following two activities will introduce these elements that will allow you to create a playable Parsely game!
