# On Display

5–10 minutes

# Activity Overview

The display macro is a way to show the entire contents of a passage inside another passage. This can be useful if you have a piece of text that you want to reuse throughout your story!

# Instructions

Instead of having to retype the text, each time when you want to use it in passages, you can put it in its own separate passage. Then, whenever you want to pull up that text, you can use the display macro.

```
(display: "passage name")
```

One example of this could be if there is a song or poem that keeps recurring in the story. Place it in a passage titled “Poem,” and whenever you want to call it up, use the display macro. Easy!
