Now, edit the passage and title it "Variables"—since that's what it's going to hold. We also need to do one very important thing: give the passage a special tag. We haven't used a tag before, but they usually don't impact the game. They're just a way for you to organize or sort your passages. There are a few tags that interact with Twine, and the startup tag is one of them. tell Twine to read this passage first, before running your starting passage. That means Twine will know the variables you introduce and set in the passage. That way, when you use them later, Twine will already know about them!

In the tag section, click the add tag button and type “startup.” Now we just need to set our variables. We’re going to use a new macro called set, and it looks like this:

```
(set: $fear to value)
```

In one of our earlier examples, we could create a variable for a player name. We could set the player name to none to start, and give the player an opportunity to enter his or her own name later on. That would look like this:

```
(set: $classname to "none")
```

Because the $classname variable is some text, it needs to be in quotations. Twine will read anything inside quotation marks as text, and treat it accordingly.

We’re going to use numbers to track how afraid our players are. The starting value of their fear will be zero. Every time something scary happens, we’ll add 1 to that number. The higher number, the more scared they are. We’ll set our $fear variable like this:

```
(set: $fear to 0)
```

# Showing Some New Text

-15 minutes

Now that we are using variables to accumulate fear, we need to do something with that fear. To do this, we can use something called a conditional statement that tells Twine the following: if $fear is a certain value, then do something. The basic structure of an if statement is as follows:

```
(if: $variable is value)[do this]
```

If the value is a number, you can just put that number there. If it's text, then you need to put it in quotations—remember?

- (if $fear is 5)

- We will add two fear conditionals to the "Front of the House" passage. One will show some text, and the other will use a new macro called goto. You don't know what that means yet—but I promise we'll go over it!

Go to the story map and edit the “Front of the House” passage. Below the line you set the $fear variable, let's add a new line that will show text if $fear is 2:

```
(if: $fear is 2)[You shiver in fear]
```

This statement says that when the players come to this passage, if the variable $fear is exactly 2, then it will show the text “You shiver in fear” exactly where this line is. Even though that sounds pretty cool, I think we need to make a few changes. First, we need to change the part “is 2.” As it is, this statement says that if $fear is exactly 2, then the phrase will be shown. That also means though, if $fear is 3, it won't. But I want the phrase to show because the player is still afraid. Instead of using “is,” we can also use other operators that give us some more options. Here are some of the operators you can use in IF statements:

- is the variable is same as the value
- > if the variable is greater than the value
- >= if the variable is greater than or equal to the value
- < if the variable is less than the value
- <= if the variable is less than or equal to the value

Since the player will still be afraid above a level of 2, edit the conditional statement so it tells Twine that if the variable $fear is greater than or equal to 2, the statement will be displayed:

```
(if: $fear >= 2)[You shiver in fear]
```

The other thing to change is where the text is showing. It doesn't make sense there at the bottom! So we need to move it to where it will make more sense. We'll also need to move the where we add 1 to fear.

When Twine runs a passage, it will run from the top to the bottom. We want the statement adding-1 to the variable to come first. After all, as soon as the players enter the scary area, they're going to get scared! No need to wait. Move the set and if macros before the link to go to the field passage. With all that done, test it out! Start the game from the beginning. Head to the front of the house, go back to the field, and go to the front of the house again. Your conditional should have triggered, and the second time you went to the front of the house, you should see the new line added to the passage!
