# # Instructions

The interface is similar no matter which platform you end up using. For this book, we are going to be using the web-based interface. There are also several story formats you can use. For this book, we'll be using the default story format for Twine 2: Harlow. You don't have to do anything to pick this format—once you download and get started, that will already be selected.

So let's begin tour of Twine! I will be your guide. When you first launch Twine, you'll see the story page.
