# Instructions

Now it's your turn! Edit your starting passage and try a few different styles out. Remember, you'll need to put the proper characters on both sides of the text you want to change. If you wind up seeing the characters (like the tilde or the slashes) you are trying to use to change the text, that means you made a mistake. Luckily, that's easy to fix. If so, go back and edit the passage. Take a close look and try to fix what went wrong. This is called debugging an error. With everything in good order, press the play icon at the bottom to test out and see how your new styles look!

You'll also notice that writing a game in Twine uses a lot of natural language. You write how you would normally write, and add some extra bits to adjust it to the game. That is what is great about using Twine to create digital interactive fiction games. You can just write and add a few elements that make them look and play great!
