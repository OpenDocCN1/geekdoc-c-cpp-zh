# Rotate

Our last text macro is super cool. Once you've got it figured out, you will be able to actually turn the text like the hands of a clock. The number you put in is the amount (in degrees) that it will twist!

I started (text-rotate:45)[falling...]

45 will tip the text down like this:

![](bbox=[0.151, 0.323, 0.763, 0.426])

90 will have it go perpendicular, or straight down:

![](bbox=[0.151, 0.506, 0.763, 0.61])

You can play around with the number to get it to where you want it to be!
