
# TWINE GAMES: WIND IT UP

Twine is a tool that allows you to create digital interactive fiction games that can be shared with the world. Creating Twine games will draw from many of the skills you developed making your analog (or nondigital) interactive fiction. As far as gameplay, Twine falls somewhere between CYOP games and Parsely games. Interactions in Twine are often selecting between a series of choices—like CYOP games—but you can use open-ended gameplay from Parsely as well. Every activity in this chapter will require a computer and Twine, unless otherwise noted.

# Let's Take a Tour

5–10 minutes

Before you can get started with Twine, you'll need to either download or open the program online. You can find the Twine program at http://twinery.org. There you can download the program for Windows, macOS or Linux, depending on the computer you are using. All these activities will be based on Twine 2, so you'll want to download the latest version available. You can also create your game online, which will work on any computer.

# Create Stories in Twine
The interface is similar no matter which platform you end up using. For this book, we are going to be using the web-based interface. There are also several formats you can use. For this book, we'll be using the default story format for Twine 2. You don't have to do anything to pick this format—once you download and get started, it will already be selected. So let's begin the tour of Twine! I will be your guide. When you first launch Twine, you'll see the story page.

![](img/71_0.png)
![](img/71_1.png)

If you look out to the left, you will see the list of stories you are working on. Since this is going to be your first story, you won't see any stories here. But as you start working on them you can find them here! The right window is the story menu where you'll be able to start a new story, load one you are working on, archive a story to save it for later, or change the format you are working with. You will need to start your first story, so click on the green button to create it. This is a big moment!

![](img/72_0.png)
![](img/72_1.png)

You'll be asked to name your story. If you're working on a story you have already started, you should have a title in mind. If this is a fresh story, feel free to give it a new name! You will always be able to change it later, so don't worry about that. Go ahead and give it a name and click the green “Add” button. Your game should open in a new tab with the name of the story in the tab.

![](img/73_0.png)

If you go back to the first tab and refresh the page, you should now see your story listed in the area on the left like this: Welcome to the start of your first Twine interactive fiction game! Easy so far, right?

# Passages

10–15 minutes

Passages are the main blocks of Twine. They are the containers that hold your story. As you know, they represent locations, and they connect to each other.

![](img/76_0.png)

# This is the first story.

To open the edit screen, double click on the passage. You should see three parts:

- **Title**: This is the name of the passage. It is not displayed to the player. Instead, it’s there to help you know what the passage contains.
- **Tags**: These are little labels that you can attach to your passages. Usually, they just help you group or categorize your passages.
- **Body**: This is where you will put your story. The story goes here. The little bits of code that make it interactive also go here.

You'll probably notice a green icon in the upper left of the passage. This is the story start. When your game launches, it will start with this passage. You can change which passage is the start if you need to, but for now, just leave it.

Go ahead and give it a name and click the green “Add” button. Your game should open in a new tab with the name of the story in the tab.
