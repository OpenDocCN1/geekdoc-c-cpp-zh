# # Will You Vary Me?

10–15 minutes

#  Activity Overview

Now we're getting somewhere! Well, in a kitchen inside a spooky house, at least. Because this is shaping up to be a spooky story, maybe we can track how scared the players get based on the choices they make and places they go in the game.

To do this, we need to use something called a variable. A variable is a name we give to information. That information changes—or is variable—depending on what we tell the game to do. The variable name can be anything, but it's usually best to give it a name that tells us what information the variable has. Makes sense!

# Instructions

In Twine, variables have a $ at the start of their names, like this:

```
$variablename
```

For example, you could have a variable for the player's character name and call it $playername or $charactername. You could also use a variable to keep track of what has happened, what something is called, how much the player has of something, or how many times something has happened. There are a lot of interesting things you can do with variables in Twine! We can't cover all of them in this book, but you'll master a few to give yourself a good foundation.

First things first, we need to create a variable to track how afraid the player is. I think a good variable name would be $fear.
