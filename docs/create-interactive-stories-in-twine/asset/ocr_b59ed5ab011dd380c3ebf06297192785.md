# # Activity Overview

Besides just showing some text when a variable reaches a certain value, we can also make other things happen. As you're probably noticing, Twine opens the door to a lot of possibilities! You can have a link appear after a variable reaches a certain value:

```
(if: Sfear is 4) [[Your heart pounds wildly->Pass Out]] ]
```

That statement will show the link "Your heart pounds wildly" to the players on this passage when Sfear is at the number 4. If the players click the link, they will be taken to a passage titled "Pass Out." This use of variables to reveal links is an important tool. It can be very useful to show progression through a game!
