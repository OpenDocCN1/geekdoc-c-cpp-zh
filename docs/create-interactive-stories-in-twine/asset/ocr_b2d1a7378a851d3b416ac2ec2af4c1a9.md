# Activity Overview

When we were building the CYOP game, one of the things we used was a loopback to a decision point. This allowed players to make a wrong choice, but not to start all the way back at the beginning of the game again. But the players were still presented with the same choice and can only choose to make a different one, hoping to move forward this time.

In a Parsely game, you can have players run around a bit to get past obstacles or move forward in the game. They may head south to a freshly dug mound of dirt. To dig that dirt up, they need the shovel, which is only found up north.
