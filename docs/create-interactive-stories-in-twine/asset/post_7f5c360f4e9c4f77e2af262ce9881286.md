# A Little More Style

10–15 minutes

# Activity Overview

In the last section, you saw that you can change the style of the text. But there are more ways that you can change text to accent or emphasize elements in your story. Here are a few other cool macros you can use!

# Instructions

These new styles will all go inline with the text you want to affect. The text you put in the hook section will be changed.

# Font

The font macro will allow you to change the font used on a section of text. The font needs to be recognized and used by web browsers, so you can't go too crazy with the font you pick. But that still leaves a lot of cool options! For example, you might want to use the Courier New font to create a newspaper headline, like this:

I picked up the paper and read the headline.

```
Warning: danger of a TSUNAMI!!!
```

# Color

This macro will let you change the font color of a section of text. Maybe you want to use a different color to emphasize a word or phrase, or maybe you just love the way a color looks. You can use basic color names, like green, red, or blue, or a hex code with the macro.

I ate the very, very (color: red)[hot] pepper.

and

I ate the very, very (color: #ff0000)[hot] pepper.

Both of these macros will create the same effect:

```
I ate the very, very hot pepper.
I ate the very, very hot pepper.
```

# Background

You can also change the background color behind text. Just like with changing font color, you can use basic color names or hex codes.

(background: red)[This should be on a red background.]

```
This should be on a red background.
```

# Transition

Twine also has the ability to add a little pizzazz to your text with transition macros. These cause the text to briefly animate when the passage loads. It can be pretty cool!

- Suddenly I realized (transition: "dissolve")[I wasn't alone!]
- This causes the hook to fade in.
- Suddenly I realized (transition: "shudder")[I wasn't alone!]
- This causes the hook to shake back and forth
- Suddenly I realized (transition: "pulse")[I wasn't alone!]
- This causes the hook to pulsate briefly.

# Text-Style

This is another way to do some of the styling we covered earlier—but with more options. You can make standard style changes like bold, italics, and striethrough. But you can also create some cool effects for your text: flip it backwards, upside down, or make it shudder and shake. Unlike transitions—which happen once as the text is loaded—text-style continues while the passage is being read. For example:

Suddenly the (text-style: "upside-down")[room] flips.

# Whoa—Where Did Come?

10–15 minutes

# Activity Overview

There may be times that you want to alert something in the game. There are two macros you can use: alert and prompt.

# Instructions

The alert macro is similar to the prompt, but it will show the player what they set. Like the alert, you can put it in your passage. The structure is:

(alert: "text")

:

(alert: "What's your name?")

![](img/3760f220c9ee3ac581049b311bdc3cc4_120_0.png)

The prompt macro allows you to get information from the player. The structure is:

(prompt: "What's your name?")

An example of this:

(prompt: "What's your name?")

One example of this is to be the is:

(prompt: $name, "Nameless One")

# On Display

5–10 minutes

# Activity Overview

The display macro is a way to show the entire contents of a passage inside another. This can be useful if you have a piece of text you want to reuse!

# Instructions

Instead of having to retype the text, each time you want to use it, you can put it in its own passage. Then, whenever you want to call it up, you can use the display macro.

```
(display: "passage name")
```

One example of this could be if there is a song or poem that keeps recurring in the story.

# Heads and Feet

10–15 minutes

# Activity Overview

You were introduced to one special passage tag earlier: the startup tag. We used it for variables that we were using in the game; it told Twine to read that before doing anything else. There are a few other special passage tags you can use in Twine. Two passage tags that you should be aware of are header and footer.

Header and footer passages will display and run on every passage. The header runs at the top of the passage, while the footer will run at the bottom. Like the “startup” passage, to create a header or footer passage, you’ve got to make a new passage and use the appropriate tag.

If you put text in the passage, it’ll show up on every passage either at the top or bottom of the page. You can also include macros! If you do, they’ll run every time the page loads.

# Instructions

Think back to the game we made. Remember when we had that conditional check for fear? That only run if you entered the front of the house. But it would make more sense if the player’s fear level was constantly being checked, every time a passage was loaded. You could move the conditional statements that checked the fear level:

```
(if: $fear >= 2)[You shiver in fear.](if: $fear is 4)(goto: “Pass Out")
```

put it into a footer. Then, every time a player goes to a new page, Twine will check to see what or her fear level is and run the hook if the fear is high enough. This is a much better way to have consequences for players who got too scared!
