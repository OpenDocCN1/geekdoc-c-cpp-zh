# About the Author

An expert in games in education, Brian Mayer writes on the subject for many publications and has coauthored one book for the American Library Association, Libraries Got Game: Aligned Learning through Modern Board Games. He is also the author of the game Freedom–The Underground Railroad, which is a collaborative game that covers the difficult topic of slavery. Freedom has been named the Board Game of the Year, the Most Innovative Game, the Cooperative Game of the Year, and the Best Thematic Game. In addition to writing and designing games, Mayer speaks nationally at school library, education, and gaming conferences on the value of modern games in education.
