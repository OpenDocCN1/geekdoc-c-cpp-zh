
# Instructions

In this example, if the players don't click that link, they don't go to the "Pass Out" passage. But maybe you don't want to give them that choice. Instead, you want to force them to go to the "Pass Out" passage when $fear hits 4.

For that, we can use a different macro called goto. Goto takes the players to a new passage automatically. They don't get the chance to click a link—they're just shown the new passage. That works perfectly for what we want to do! Let's change that conditional statement and add it after the "if: $fear is >= 2."

```
(if: $fear is 4)[(goto: "Pass Out")]
```

Now, when the players enter this passage and their $fear is 4, they'll be taken to a new passage—“Pass Out.” Unlike with links, you'll have to create this passage manually. But that now—and make sure you capitalize, otherwise the game won't know where to go!

Let's make a quick edit to the "Pass Out" passage so the players get some information about what happened. Remember, they didn't get a link displayed to them, and they don't see passage titles! Add the following to the Pass Out passage:

You awake, dazed and confused, just outside the Abandoned Field.

After this, include a link to the "Abandoned Field" passage so they can get back into the game! Also, let's reset their fear—otherwise it will just keep going on! It makes sense to have them reset so they can make different choices. To reset, set the $fear variable to 0 here. It will overwrite whatever the current $fear value is and make it zero. The player is starting fresh and unared after passing out!

Again, test your game out. Try approaching the house and heading back to the field a number of times until you trigger the macro to make yourself pass out. Watch the fear variable as you do this to see how it goes up and then resets to zero (hopefully!).

# Take Note!

For all these tests, I'm having you use the links we created to go back and forth between the field and the front of the house. That's because using game elements continues to move the game forward.

Earlier, I mentioned the back arrow that is displayed in the upper left corner. This arrow steps back a turn, which can be a problem when you are trying to build up a value in a variable, like fear!

Test again and use the back arrow to go back to the field and see what happens to the $fear variable. It will drop 1 because you took a step back and never added the 1 to $fear from when you entered the “Front of the House” passage.

# If-Else-If

15–20 minutes

# Activity Overview

With a title should come a reward! And so we come to our last activity showcasing the tools of Twine. Now that there are three possible titles, else how about if the old woman gives the players a reward based on which they have?

# Instructions

To accomplish this, we're going to extend the conditional statement to include two new macros: else and if-if. This format looks like:

```
(if: $title is "The Lame")[a]
(else-if: $title is "The Balloon Slayer")[b]
(else)[c]
```
