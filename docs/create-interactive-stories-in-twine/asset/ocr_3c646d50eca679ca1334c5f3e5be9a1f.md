# # Activity Overview

Okay, so that was underwhelming, I admit. But hey, you've got to start somewhere, right? Close the tab that opened up with the game, and let's get back to the story grid!

I think this story game is missing some, well, story. So let's add some! You saw from the last activity that anything you type will show up as a part of your game. You don't have to do anything special—just type it.

You may want to add some extra styling and bling, though. There are some styles that you can add by simply adding a few characters around the text you want to change:

+   - **bold** can be added with two single apostrophes on both ends:
  - oLook at my "bold statement"
- *Italics* can be added with two forward slashes on both ends:
  - OI //really, really// like your hair.
- ~~Strikethrough~~ can be added with two tildes on both ends:
  - OI really, ~~hate~~ like your hair.
- *Superscript* can be added using two carets on both ends:
  - OIts the worst, like 1000^^2^^
