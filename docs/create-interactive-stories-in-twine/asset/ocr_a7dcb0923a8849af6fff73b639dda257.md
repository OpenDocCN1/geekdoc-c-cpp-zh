If you look out the bus to your left, you will see the list of stories that you are working on. Since this is going to be your first story, you won't see any stories here (duh). But as you start working on them, you can find them here!

Out the right window is the story menu where you'll be able to start a new story, load one you are working on, archive a story to save it for later, or change the program format you are working with. You will need to start your first story, so click on the green button to create it. This is a big moment!

![](bbox=[0.345, 0.345, 0.655, 0.673])

You'll be asked to name your story. If you're working on a story you have already started, you should have a title in mind. If this is a fresh story, feel free to give it a new name! You will always be able to change it later, so don't worry about that.
