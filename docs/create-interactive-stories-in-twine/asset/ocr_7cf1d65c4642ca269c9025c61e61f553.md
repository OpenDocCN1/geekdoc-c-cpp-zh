Prompt is similar to the alert macro, but it works with the set macro, and it will let the player set the value for a variable. Like the alert pop-up, Twine will show the player a browser pop-up box with text–but it'll also have a text entry box. The prompt macro has spaces for two pieces of text. The first text in the macro will be what displays above the text entry box, telling the player what to put in the box. The second text in the macro is what will be the default entry in the text box. The player can change that and write his or her own entry! The structure is like:

+   (set: $variable to prompt: "what to put in the box", "default text")

A great example to allow players to set their player names would be as follows:

+   (set: $name to prompt: "What's your name?", "Nameless One")

The best place to put this would be in your starting passage. Then, you can use the $name variable in your story to use whatever the player set as his or her name. This will create a personalized experience for the player!
