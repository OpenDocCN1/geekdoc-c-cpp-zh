# Take Note!

For all these tests, I'm having you use the links we created to
go back and forth between the field and the front of the house.
That's because using game elements continues to move the game
forward.

Earlier, I mentioned the back arrow that is displayed in the
upper left corner. This arrow steps back a turn, which can be a
problem when you are trying to build up a value in a variable,
like fear!

Test again and use the back arrow to go back to the field and
see what happens to the $fear variable. It will drop 1 because you
took a step back and never added the 1 to $fear from when you
entered the “Front of the House” passage.
