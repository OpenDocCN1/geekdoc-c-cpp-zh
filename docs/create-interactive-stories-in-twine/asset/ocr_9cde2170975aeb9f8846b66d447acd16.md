# Running the Game

20–25 minutes Idea sheet, paper, pencil

# Activity Overview

Here we are: the final Parsely activity. Here, you're going to learn how to have fun running the game, making it an awesome experience for everyone involved. Parsely games are meant to have an exciting, explorative feel with a bit of tongue-in-cheek fun when it comes to how well everything runs.

As I mentioned, Parsely is modeled after games that are run on computers—old computers—that didn't have sophisticated ways of understanding (or parsing—get it?) what the players are inputting. That is an important thing to keep in mind when the game is being run!
