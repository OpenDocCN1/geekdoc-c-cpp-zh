# # Cleaning Up

5–10 minutes

# ## Activity Overview

I hope you're ready—it's nearly time to start building your game!
First, you need to clear out anything that might have popped up as you were exploring the Twine interface.

My first story

# ## Instructions

Luckily, Twine has covered us! To open the options menu on the grid page, click on the story's name in the menu on the bottom. From there, click “Select All Passages.” Any of the passages you created will be highlighted blue. Now just click the delete key to remove anything you may have accidentally created. This is a powerful tool you can use at any point during your design process to help clean things up.
