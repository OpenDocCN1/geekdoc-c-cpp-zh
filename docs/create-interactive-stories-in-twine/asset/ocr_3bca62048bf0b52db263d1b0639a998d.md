# Getting Published

10–15 minutes

# Activity Overview

Congratulations! You have just created a very short and very silly—but also very fun–Twine game. Now you need to share it with the world! Well, maybe just share it with your friends.

# Instructions

When you're all finished with a game in Twine, you'll need to publish the game to a file, which you can then share and use to play the game. Twine will publish the game to an .html file, which is a web page that can be displayed in a browser.

Make one last check of the game we've been making to ensure everything works and there aren't any broken links or dead ends. Once you're satisfied, click on the story's title on the story map page. The very bottom left link will give you the option to Publish to File.

![](bbox=[0.263, 0.643, 0.737, 0.813])

Click this link, and Twine will save your game wherever your browser saves files. It shouldn't take long for Twine to create the file. When that's done, open the file and play your game!
