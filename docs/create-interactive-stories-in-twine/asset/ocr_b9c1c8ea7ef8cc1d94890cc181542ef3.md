Later, when the players discover the chest in the basement, you can state in the rules:

+   - The chest is finely crafted, with an ornate lock. The chest will only open with the small ornate key found in the study.

In this example, you can see a few things. First, there's a clue that the key goes to the lock by the repeated use of the word ornate. This could be helpful if the players have several keys, to let them know which key to use on the lock. Second, remember to use italics to denote something for the person running the game to take note of—but not to read out loud.

Using all these tips, write up the rules for the obstacle you created in the previous activity. Also, revise the rules you wrote earlier for your first few locations and make any adjustments you might need.
