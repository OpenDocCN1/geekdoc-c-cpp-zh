Uh oh. Now we have a problem. The choice our players have in the story is now the name of a location. And it doesn't really sound right!

In Twine, you can create links that display something different than the name of the passage they're going to. That would be a great help here, so let's make that change! To do that, we're going to need to use a hyphen and greater-than character together. This makes an arrow: "->". And that means the format will be [[Text shown to player->passage title]].

You can create new passages using this format, the same way we did earlier. Any time you create a link to a passage that doesn't exist, Twine will automatically create that passage for you. It's very helpful!

Staying inside the square brackets, we need to add the text we want the reader to see and the arrow before the passage link. Let's keep the same text we had before. So go ahead and change the link so it looks like this:

[[Approach the House->Front of the House]]
