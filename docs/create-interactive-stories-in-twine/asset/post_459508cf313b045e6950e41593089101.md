# What's in a Name?

15–20 minutes

## Activity Overview

As of right now, our choices and our passages mostly have the same name – with the exception of the starting passage. But having passages with the same names as choices may not always make sense. Sometimes, you may want passages to represent locations rather than choice results.

For example, right now when you start in the field, you can choose between going to the front of the house or around back. From a mapping approach, it may make more sense to have those be the locations that players can keep coming back to rather than choice results.

# Changing Text with Links and Clicks

You can also create clickable links in your story that do other things besides moving the reader on to the next passage. You can use them to reveal new information, shift, or change what is shown to the reader.

These changes are done with macros. That word might be scary in computer science, but it's just a piece of code that tells Twine to do something special.

Here are some examples of macros you can use:

- Link: `(link:"text shown")[target]`
  This is like a regular link, but it uses a macro to define the text.
- Link reveal: `(link-reveal:"text shown")[hidden text]`
  This adds text to the page when clicked.
- Variable: `(set: $variable = "value")`
  This allows you to store and change information, like the player's name.
- Conditional: `(if: $variable == "value")[show this]`
  This shows text only if a certain condition is met.
