
# Saving and Loading Games

15–20 minutes

## Activity Overview

By now, you probably have a pretty great game in the works, with twists and turns and a few horrible endings for careless players. Maybe your game is a tough one, and you want to give your players the ability to save their games rather than having to start all the way back from the beginning. Twine will let you do that!

## Instructions

This–the last activity!–will show you how to set your Twine story up so that players can save and load a game. Twine will use your browser to save a player's progress. There are two components to making this happen. The first bit of code will create a link titled Save Game that, when clicked, will save the current state of the game in Slot A. This includes which passages have been visited and any variables that were set.

```
(link:"Save Game")[(if:(save-game:"Slot A")][Game saved!])
```

It will also give a "Game Saved!" message to let the player know the game was saved. This code will only keep one active save. If the player saves the game a second time, it will overwrite the last save. The second bit of code is to load the last saved game.

```
(link:"Load Game")[(load-game:"Slot A")]
```

The code creates a link titled Load Game that, when clicked, will load the last game saved in Slot A. You can change the name of the save game from Slot A to anything you want—just be sure to change it in both the save and load game code! How often and where to place the save and load code will depend on how you want to make this available to your players.

- If you want them to always be able to save and load, then you could put it in a footer passage, so it will always show at the bottom of the game.
- If you wanted to create checkpoints, you could put load code in a footer passage and only put the save game code in select passages that you want the players to be able to save. This way, the players will always be able to load their games, but they will only be able to save in select locations!

To start, try just putting the save and load code in a footer passage to make sure it's working. Then, decide how you want to use the functionality and make the changes you need!

# GLOSSARY

**action words** In Parsely games, verbs that allow players to advance the story.

**branch** The part of an interactive fiction story where a decision point leads to two different story paths.

**choose your own path** A style of story where the reader makes certain decisions that affect the outcome of the tale.

**conditional statement** In coding, a statement that checks whether certain conditions are met to determine what operation it executes.

**decision points** Areas in an interactive fiction story where the reader has to choose one or more options that have different outcomes.

**inline** In programming, describing code on the same line or without any breaks.

**interactive fiction** The general term for stories and other media in which the audience has some form of interaction with the outcome.

**interface** The form of a system or software that presents information to a user.

**iterative** Referring to the process of repeating something to improve it.

**links** In Twine, the connections between different passages and the way they are connected.

**loop** A series of decision points that only lead to each other and do not advance the story.

**macros** Sections of code that combine multiple instructions into one command.

**operators** Symbols that are used to indicate a mathematical or coding operation.

**Parsely** A pen-and-paper interactive fiction platform that is inspired by early text-based computer games.

**passages** In Twine, the boxes that contain all the text and code of a story.

**publish** To make a program or other piece of media available publicly.

**save point** An option given in some forms of interactive fiction that allows players to return to a previous point in the story; also called a restore point.

**styles** Different ways of displaying text, include bold, italic, etc.

**Twine** A free-to-use software that is used to create interactive fiction using passages, links, and coding.

**variable** Something that can change or exist in several states.
