Go to the story map and edit the “Front of the House” passage. Below the line you set the $fear variable, let's add a new line that will show text if $fear is 2:

(if: $fear is 2)[You shiver in fear]

This statement says that when the players come to this passage, if the variable $fear is exactly 2, then it will show the text “You shiver in fear” exactly where this line is. Even though that sounds pretty cool, I think we need to make a few changes. First, we need to change the part “is 2.” As it is, this statement says that if $fear is exactly 2, then the phrase will be shown. That also means, though, if $fear is 3, it won't. But I would want the phrase to show, because the player is still afraid. Instead of using “is,” we can also use other operators that give us some more options. Here are some of the operators you can use in IF statements.

+   * is if the variable is the same as the value
* > if the variable is greater than the value
* >= if the variable is greater than or equal to the value
* < if the variable is less than the value
* <= if the variable is less than or equal to the value

Since the player will still be afraid above a level of 2, edit the conditional statement so it tells Twine that if the variable $fear is greater than or equal to 2, the statement will be displayed:

(if: $fear >= 2)[You shiver in fear]

The other thing to change is where the text is showing. It doesn't make sense there at the bottom! So we need to move it to where it will make more sense. We'll also need to move the macro where we add 1 to fear.
