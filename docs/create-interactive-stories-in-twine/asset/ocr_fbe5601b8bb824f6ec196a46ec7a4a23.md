# Linking Back

10–15 minutes

# Activity Overview

So, as cool as it is, stepping back is not ideal. It actually undoes a turn, and as we get deeper into building games, that can cause problems. So let's add to our story and also create a link to go back to our starting passage.

# Instructions

Open up the passage titled "Approach the House" and type this out:

> You begin to approach the house but something seems ... //off/. The wind whistles in the abandoned field around the house. Maybe it's the holes in the porch, or the old shoe hanging from the light. But you would feel a whole lot better finding a different way inside the house.

```
[[Start]]
```

You may have noticed that, after you put in the first set of double square brackets, the titles of your other passages showed up. This makes it easier to get the naming correct. If the passage title is misspelled, Twine will instead create a brand new passage with the new spelling. That is why giving your passages simple titles will help! Try playing the game again now and see how you can move between passages.
