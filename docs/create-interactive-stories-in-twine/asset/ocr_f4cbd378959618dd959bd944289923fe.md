# # Whoa—Where Did That Come From?

10–15 minutes

# Activity Overview

There may be times that you want to have something pop out from the game to either alert the players or to get some information from them. There are two macros you can use to do that: alert and prompt.

# Instructions

Alert will allow you to create a browser pop-up that will sit over the game and display some text, with an "OK" button to dismiss the message. No matter where you put this macro in your passage, it will pop up first first when the players come to the passage. The general structure is very simple:

```
(alert:text to be displayed")
```

An example:

```
(alert:You are about to enter the final countdown. Ba da da dum")
```
