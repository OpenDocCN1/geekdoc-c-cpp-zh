# ## VISIT

The **National Videogame Arcade**, Nottingham, houses thousands of video games, runs clubs and encourages hands-on experience of game-making.

The **Retro Computer Museum**, Leicester, is full of old gaming consoles. It holds gaming and computing events with access to retro computer equipment, and hosts educational visits and tours.
