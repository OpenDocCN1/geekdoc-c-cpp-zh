This piece of code uses variables to give each cell a number. It works like this. There are 24 columns. Each cell on the bottom row (0) is given its number by multiplying the row number (0) by 24 and then adding its column number.

Let's work out the cell number of the green cross on our grid: 0 (row number) x 24 = 0; 0 + 0 (column number) = 0, so the cell number is '0'.
