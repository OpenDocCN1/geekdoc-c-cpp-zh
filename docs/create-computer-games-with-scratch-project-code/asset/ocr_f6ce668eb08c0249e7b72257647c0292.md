# Try It

What if you want to use a different ball or add a second ball to your game? Choose a new ball sprite. Copy the code from your original ball by right-clicking on each code block and selecting 'duplicate'. Drag the duplicate code onto the new sprite. The blocks may appear on top of each other so you might need to tidy them up.

Delete the original ball and just use your new one, or try using two balls. It's much harder! We added the Earth to our space-themed Paddleball. Open paddleball2.sb2 to try out this version.
