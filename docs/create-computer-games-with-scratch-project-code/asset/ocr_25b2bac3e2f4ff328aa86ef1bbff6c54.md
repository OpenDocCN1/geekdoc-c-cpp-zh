Do you already know the basics of using Scratch? This book will help you take those skills and build on them to create action-packed computer games that you can even play with your friends! Using ready-made blocks of code, have a go at simple projects to develop your Scratch knowledge and have fun getting creative. You can use the code as it is, play around with it or use it as inspiration - it’s up to you!

Project Code is a series of books that supports the National Curriculum in the important STEAM skill of computer coding.
