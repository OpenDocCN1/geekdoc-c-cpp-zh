# # ALL ABOUT COMPUTER GAMES

Do you like computer games? Perhaps you like puzzles, action games or adventure games. Have you ever wondered how people write computer games? You can create games yourself using a program called Scratch.

# ## Planning your computer game

Before you write a computer game you need to decide a few things. What kind of game do you want to write? What will the aim of the game be? Will your game have characters? What will the characters do?

Once you have a plan, Scratch helps you create games easily using pieces of **code**, called coding blocks. The blocks can be arranged to create different kinds of programs, such as games.
