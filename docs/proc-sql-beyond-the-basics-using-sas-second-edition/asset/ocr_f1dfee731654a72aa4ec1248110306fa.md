# Table 9.1: Debugging Process Steps and Tasks

| Debugging Step | Task Description |
|---|---|
| Problem Identification | 1. Determine if a bug exists in the code.
2. Determine what the problem is by playing detective.
3. Describe why the problem is a bug.
4. Determine what the code should do.
5. Determine what the code is doing. |
| Information Collection | 1. Collect user comments and feedback.
6. Collect personal observations and symptoms.
7. Review SAS log information.
8. Collect test case(s) that highlight the problem.
9. Capture environmental information (for example, system settings, operating environment, external elements, etc.). |
| Problem Assessment & Classification | 1. Develop a theory about what caused the problem.
10. Review the code.
11. Classify the problem into one of the following categories:
    - Requirements problem
    - Syntax error
    - CPU problem
    - Memory problem
    - Storage problem
    - I/O problem
    - Logic problem |
| Problem Resolution | 1. Propose a solution.
12. Describe why the solution will fix the problem.
13. Verify that the solution will not cause additional problems.
14. Fix the problem by implementing the solution. |
| Validate Solution | 1. Verify whether the problem still exists.
15. Verify whether the problem can be recreated or reproduced.
16. Determine whether other methods can cause the same problem to occur.
17. Verify that the solution does not cause other problems. |
