In the next example, the numeric column MANUNUM has its length changed (or redefined) from 3 bytes to 4 bytes using the LENGTH statement in a DATA step. To avoid truncation or data problems, you should verify that a column that has a shorter length can handle existing data. Because PROC SQL does not produce any notes or warnings if numeric values are truncated, you need to know your data.

# DATA Step Code

```
DATA MANUFACTURERS;
LENGTH MANUNUM 4 .;
SET MANUFACTURERS;
RUN;
```
