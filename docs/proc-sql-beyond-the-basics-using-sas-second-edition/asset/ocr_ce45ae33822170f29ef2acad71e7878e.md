# SQL Code

```
PROC SQL;
    SELECT prodname, prodtype,
        products.manunum, manuname
    FROM PRODUCTS FULL JOIN MANUFACTURERS
        ON products.manunum =
            manufacturers.manunum;
QUIT;
```

1 The full join specification preserves all of the rows in the left table (PRODUCTS) as well as all of the rows in the right table (MANUFACTURERS) even when there are no matching rows.
