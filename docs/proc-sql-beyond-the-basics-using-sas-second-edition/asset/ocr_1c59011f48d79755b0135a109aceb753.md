# SQL Code

```
PROC SQL DOUBLE NUMBER OUTOBS=1;
  SELECT *
    FROM PRODUCTS
    WHERE PRODTYPE='Software';
RESET NODOUBLE NONUMBER OUTOBS=MAX;
  SELECT *
    FROM PRODUCTS
    WHERE PRODTYPE='Software';
QUIT;
```
