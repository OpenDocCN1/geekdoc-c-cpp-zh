When the entire query is executed, SQL first evaluates the inner query (or subquery) within the outer query’s WHERE clause. It executes the inner query the same way as if it were a standalone query. It searches the MANUFACTURERS table for any row where the manufacturer name equals the character string Global Comm Corp, and then pulls the MANUNUM value for this row. SQL then substitutes the derived MANUNUM value of 210 from the inner query inside the predicate of the main query (outer query). As a result of this substitution, the SQL query looks identical to the query mentioned previously.

```
PROC SQL;
SELECT invnum, INVOICE.manunum, custnum, invqty, invprice, prodnum
FROM INVOICE,
(SELECT manunum
FROM MANUFACTURERS
WHERE manuname = 'Global Comm Corp')
WHERE INVOICE.manunum = MANUFACTURERS.manunum;
QUIT;
```

# Result of Inner Query

```
PROC SQL;
SELECT *
FROM INVOICE
WHERE manunum = 210;
QUIT;
```

① PROC SQL evaluates the inner query within the outer query’s WHERE clause to search for the manufacturer number for manufacturer Global Comm Corp.

② The resulting query after substituting the derived manufacturer number value from the inner query evaluates to a single value, and is then executed as the main (outer) query.
