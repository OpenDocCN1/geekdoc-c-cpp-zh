# SAS Log Results

```
PROC SQL NOPRINT;
    SELECT MANUNAME
        INTO :MANUNAME SEPARATED BY '  '
            FROM MANUFACTURERS
                WHERE UPCASE(MANUCITY)='SAN DIEGO';
QUIT;
NOTE: PROCEDURE SQL used:
        real time            0.00 seconds

%PUT &MANUNAME;
Global Comm Corp  Global Software  San Diego PC Planet
```

In the next example, a similar list that contains manufacturers from San Diego is created. But instead of separating each name with two blanks as in the previous example, a comma is used instead.

# SQL Code

```
PROC SQL NOPRINT;
    SELECT MANUNAME
        INTO :MANUNAME SEPARATED BY ', '
            FROM MANUFACTURERS
                WHERE UPCASE(MANUCITY)='SAN DIEGO';
QUIT;
%PUT &MANUNAME;
```

# Using Automatic Macro Variables to Control Processing

Three automatic macro variables that are supplied by SAS are assigned values during SQL processing to provide process control information. SQL users can determine the number of rows processed with the SQLOBS macro variable, assess whether a PROC SQL statement was successful or not with the SQLRC macro variable, and identify the number of iterations the inner loop of an SQL query processes with the SQLLOOPS macro variable.
