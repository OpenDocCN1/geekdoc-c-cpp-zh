# SQL Code

```
PROC SQL;
    SELECT PRODNUM,
           PRODNAME,
           PRODTYPE,
           SUBSTR(PRODTYPE,1,4)
    FROM PRODUCTS
    WHERE PRODCOST > 100.00;
QUIT;
```

# Phonetic Matching (Sounds-Like Operator =*)

A technique for finding names that sound alike or have spelling variations is available in the SQL procedure. This frequently used technique is referred to as phonetic matching and is performed using the Soundex algorithm. In Joe Celko’s popular book SQL for Smarties: Advanced SQL Programming (Morgan Kaufman, 1999, pages 83-87), he traced the origins of the Soundex algorithm to the developers Margaret O’Dell and Robert C. Russell in 1918. Developed before the first computer, clerks often used the algorithm to manually search for similar sounding names.

Although not technically a function, the sounds-like operator "=*" searches and selects character data based on two expressions: the search value and the matched value. Anyone that has looked for a last name in a local telephone directory is quickly reminded of the possible phonetic variations.
