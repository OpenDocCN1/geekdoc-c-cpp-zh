# SQL Code

```
PROC SQL;
    UPDATE PRODUCTS
        SET PRODCOST = PRODCOST - (PRODCOST * 0.2)
            WHERE UPCASE(PRODTYPE) = 'LAPTOP';

    SELECT *
        FROM PRODUCTS;
QUIT;
```
