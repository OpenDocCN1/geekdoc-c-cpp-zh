# SQL Code

```
PROC SQL;
    SELECT MANUNAME,
           MANUSTAT,
           CASE
               WHEN MANUSTAT = 'CA' THEN 'South West'
               WHEN MANUSTAT = 'FL' THEN 'South East'
               WHEN MANUSTAT = 'TX' THEN 'Central'
               WHEN MANUSTAT = ' ' THEN 'Missing'
               ELSE 'Unknown'
           END AS Region
    FROM MANUFACTURERS;
QUIT;
```
