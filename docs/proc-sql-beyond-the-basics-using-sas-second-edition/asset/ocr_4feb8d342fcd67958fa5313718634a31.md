Let’s look at another subquery example that uses the comparison operator < (less than). A summary function specified in an inner query forces a single row result. In the next example, the subquery uses the AVG summary (aggregate) function to determine which products (based on their invoice quantities) were purchased in lower quantities than the average product purchase.

# SQL Code

```
PROC SQL;
SELECT prodnum, invnum, invqty, invprice
FROM INVOICE
WHERE invqty <
(SELECT AVG(invqty)
FROM INVOICE);
QUIT;
```

# Result of Inner Query

```
PROC SQL;
SELECT prodnum, invnum, invqty, invprice
FROM INVOICE
WHERE invqty < 4.285714;
QUIT;
```

① PROC SQL evaluates the inner query within the outer query’s WHERE clause to produce an average invoice quantity.
