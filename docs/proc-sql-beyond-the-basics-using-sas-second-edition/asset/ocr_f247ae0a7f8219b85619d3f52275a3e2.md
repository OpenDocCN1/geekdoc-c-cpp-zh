The next example illustrates the use of the OR logical operator to select software products or products that cost more than $300.00.

# SQL Code

```
PROC SQL;
    SELECT PRODNAME,
        PRODTYPE,
        PRODCOST
    FROM PRODUCTS
        WHERE PRODTYPE = 'Software' OR
            PRODCOST > 300;
QUIT;
```
