the LEFT function to left align a character expression while inserting a comma “,” and blank between the columns.

# SQL Code

```
PROC SQL;
    SELECT LEFT(TRIM(MANUCITY) || ", " || MANUSTAT)
        FROM MANUFACTURERS;
QUIT;
```

# Results

|  |
|---| 
| Houston, TX |
| San Diego, CA |
| Miami, FL |
| San Mateo, CA |
| San Diego, CA |
| San Diego, CA |

The next example illustrates how character data can be right aligned using the RIGHT function.

# SQL Code

```
PROC SQL;
    SELECT RIGHT(MANUCITY)
        FROM MANUFACTURERS;
QUIT;
```

# Results

|  |
|---| 
| Houston |
| San Diego |
| Miami |
| San Mateo |
| San Diego |
| San Diego |
