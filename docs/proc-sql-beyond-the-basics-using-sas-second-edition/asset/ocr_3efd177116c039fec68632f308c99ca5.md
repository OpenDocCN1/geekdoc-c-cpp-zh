```
PROC SQL;
SELECT prodnum, prodname, prodtype, prodcost
FROM PRODUCTS
OUTER UNION CORR
SELECT prodnum, prodname, prodtype, prodcost
FROM PRODUCTS;
QUIT;
```

The OUTER UNION operator with the CORR keyword concatenates and overlays the results of both queries.
