# Software Used to Develop the Book's Content

SAS®9.3 was used to develop all content for this book.

# Example Code and Data

You can access the example code and data for this book by linking to its author page at http://support.sas.com/lafler. Then, look for the cover thumbnail of this book, and select Example Code and Data to display the SAS programs that are included in this book.

For an alphabetical listing of all books for which example code and data is available, see http://support.sas.com/bookcode. Select a title to display the book’s example code.

If you are unable to access the code through the website, send an e-mail to saspress@sas.com.
