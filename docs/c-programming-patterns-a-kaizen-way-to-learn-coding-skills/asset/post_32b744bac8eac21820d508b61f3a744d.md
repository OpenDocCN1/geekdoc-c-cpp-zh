
**Column Level Repetitive Action**

条件：lower_limit <= col <= upper_limit；upper_limit >= num >= lower_limit

| row | lower_limit (col) | upper_limit (col) | upper_limit (num) | lower_limit (num) |
|---|---|---|---|---|
| 1 | 1 | totalRows - row | 2*row - 1 | row |
| 2 | 1 | totalRows - row | 2*row - 1 | row |
| 3 | 1 | totalRows - row | 2*row - 1 | row |
| 4 | 1 | totalRows - row | 2*row - 1 | row |
| 5 | 1 | totalRows - row | 2*row - 1 | row |

So the upper_limit of col & num variables are generalised. The lower_limit & upper_limit are consistent for all the rows. It's now generalised for any number of rows.

So our loop-condition for space count on each row using variable col becomes;

| loop-condition | lower_limit <= col <= upper_limit |
|---|---|
| Mathematical expression | 1 <= col <= (totalRows – row) |
| Syntax | `for (col = 1; col <= (totalRows - row); col++)` |

So our loop-condition for printing numbers on each row using variable num becomes;

| loop-condition | upper_limit >= num >= lower_limit |
|---|---|
| Mathematical expression | row <= num <= (2*row - 1) |
| Syntax | `for (num = 2*row - 1; num >= row; num--)` |

So it has two repetition process one for printing spaces and second for printing numeric values. It means require 2 inner for-loops (nested for – loops).

## NumberPatternBBB1.c

```c
#include <stdio.h>
int main() {

    int totalRows = 5;  //number of rows to display

    // Row level Repetitive Action :
    for( int row = 1 ; row <= totalRows ; row ++ ) {

        // Column level Repetitive Action :
        // 1)Move cursor in the same row. 2)print character

        // spaces to be printed before printing numbers
        for( int col = 1 ; col <= (totalRows - row) ; col++ ) {
            printf("  ");
        }

        for( int num = ( 2*row - 1 ) ; num >= row ; num-- ) {
            // added extra space for clarity in output.
            printf( "%d ", num );
        }

        printf("\n");// moves control to the next line

    }

    return 0;
}
```

## Alternative solution

Let's devise a solution by merging two inner for-loops into single by introducing the if-else construct.

We can directly get the idea from the for-loop condition of the both the inner for-loops. It's either printing space or number. Number starts with the formula (2*row - 1) and decreases till it reaches the row value. The lower_limit is an initialization part and need to do it only once.

If we take care of initialisation and step-decrementing part then the loop-condition can be converted into the if-condition.

### NumberPatternBBB2.c

```c
#include <stdio.h>
int main() {
    int totalRows = 5; //number of rows to display
    // Row level Repetitive Action :
    for ( int row = 1; row <= totalRows; row++ ) {
        // Column level Repetitive Action :
        // 1)Move cursor in the same row. 2)print character
        // spaces to be printed before printing numbers
        int num = 2 * row - 1;// horizontal movements
        // spaces to be printed before printing numbers
        for ( int col = 1; col <= ( totalRows ); col++ ) {
            if ( col <= ( totalRows - row ) ) {
                printf( " " );
            } else if ( num >= row ) {
                // added extra space for clarity in output.
                printf( "%d ", num );
                num = num - 1;
            }
        }
        // move control to the next line
        printf( "\n" );
    }
    return 0;
}
```
