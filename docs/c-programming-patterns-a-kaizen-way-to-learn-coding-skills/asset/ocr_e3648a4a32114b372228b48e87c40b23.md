| loop-condition | lower_limit <=col<= upper_limit |
| Mathematical expression | 1<= col <= totalRows + 4 |
|  | 1<= col <= totalRows + ( totalRows - 1 ) |
|  | 1<= col <= ( 2*totalRows - 1 ) |
| Syntax | for( col = 1 ; col <= ( 2* totalRows - 1 ) ; col++ ) |

We are now able to generalised using variable totalRows.

for totalRows = 5 , the col <= 9 ( 2*5 - 1 )

for totalRows = 4 , the col <= 7 ( 2*4 - 1 )

for totalRows = 3 , the col <= 5 ( 2*3 - 1 )

for totalRows = 2 , the col <= 3 ( 2*2 - 1 )

for totalRows = 1 , the col <= 1 ( 2*1 - 1 )

So this generalisation for total columns as per given rows holds valid.
