# Arrays

Till now we had deal with variables which deals only with single data. In short;

| Relationship between variable and data |
|---|---|---|
| Variable | one – to – one | Data |

It is also possible to have relationship between variable and data as one-to-many, which means one variable can able to hold many data or group of data. Such type of variables specially known as array variables.

| Relationship between array variable and data |
|---|---|---|
| Array Variable | one – to – many | Data1 |
| | | Data2 |
| | | Data3 |
| | | Data4 |

We too can initialize array variable like we used to initialize a normal variable by considering it's data-type. For example, 5 different numeric scores can be given as;

```
int student_scores[5] = { 70, 50, 40, 56, 72 };
```

student_scores → Represents an array variable of size 5 and gets initialized with 5 different score values separated by commas. Each value is an owner of it's position value commonly known as index value/position. So the group of same data type values can be represented by an array variable. In general, values of an array are also referred as elements of an array.

Array name and index value combination is used to access specific data among the group.

> Array name along with different index values are like different variables and each containing data.

| Array name ⇨ | student_scores |
| First index ⇨ | 0 | 70 |
| | 1 | 50 |
| | 2 | 40 |
| | 3 | 56 |
| Last Index ⇨ | 4 | 72 |

+   - 1st element ⇨ student_scores[0] ⇨ 70
+   - 2nd element ⇨ student_scores[1] ⇨ 50
+   - 3rd element ⇨ student_scores[2] ⇨ 40
+   - 4th element ⇨ student_scores[3] ⇨ 56
+   - 5th element ⇨ student_scores[4] ⇨ 72
