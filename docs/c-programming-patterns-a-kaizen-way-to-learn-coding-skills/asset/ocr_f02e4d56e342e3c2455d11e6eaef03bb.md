# Access the values of an array

In order to refer to any stored value in an array, we need to use array's name along with index of that array. Let's try to understand bit more from the given array declarations, how values are stored in arrays.

```
```c
    char bookTitle[20];

    float bookWeight[20]; // in Kg

    int bookPages[20];
```
```

| C | bookTitle[0] | .5 | bookWeight[0] | 370 | bookPages[0] |
| P | bookTitle[1] | .73 | bookWeight[1] | 421 | bookPages[1] |
| ........ |  | ........ |  | ........... |  |
| ........ |  | ........ |  | ........... |  |
| ........ |  | ........ |  | ........... |  |
|  | bookTitle[18] | .54 | bookWeight[18] | 355 | bookPages[18] |
|  | bookTitle[19] | .64 | bookWeight[19] | 423 | bookPages[19] |
| Each 1 byte sized data |  | Each 4 bytes sized data |  | Each 2 bytes sized data |  |

The character string constants are given by enclosing it in quotes as shown by the following given example.

```
```c
// Case1
char bookTitle[20] = “C pointers”;

// Case2
char bookTitle[20] = {'C',' ','p','o','i','n','t','e','r','s','\0'}
```
```

**Case1:** C automatically adds the NULL(ASCII 0 or '\0') character after the last character in a string.
**Case2:** C doesn't automatically adds null-terminated character('\0') at the end. The coder has to explicitly place it as it's last element.
