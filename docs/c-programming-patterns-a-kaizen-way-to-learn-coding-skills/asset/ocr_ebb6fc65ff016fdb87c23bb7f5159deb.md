Logical NOT: Return true when A is false or just opposite, returns false when it is true.

| A | !A | Please note that true/false values are also known as boolean values or truth values. |
|---|---|---|
| true | false | |
| false | true | |

Let, there are two variables, a = 10 and b=5.Please observe the column “Result”.

| Logical operator | Expression | Result |
|---|---|---|
| && | (a > 7) && (b < 7) | (true) && (true) is true |
| || | (a > 7) || (b < 3) | (true) || (false) is true |
| ! | !(a == b) | !(false) is true |
