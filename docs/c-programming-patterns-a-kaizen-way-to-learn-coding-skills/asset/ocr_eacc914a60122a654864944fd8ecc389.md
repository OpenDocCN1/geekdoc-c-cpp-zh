# ExerciseYBB: Alphabet B

|  | col=1 | col=2 | col=3 | col=4 | col=5 |
|---|---|---|---|---|---|
| row=1 | 1,1* | 1,2* | 1,3* | 1,4* | 1,5* |
| row=2 | 2,1 | 2,2 | 2,3 | 2,4 | 2,5 |
| row=3 | 3,1 | 3,2 | 3,3 | 3,4 | 3,5 |
| row=4 | 4,1 | 4,2 | 4,3 | 4,4 | 4,5 |
| row=5 | 5,1 | 5,2 | 5,3 | 5,4 | 5,5 |
| row=6 | 6,1 | 6,2 | 6,3 | 6,4 | 6,5 |
| row=7 | 7,1* | 7,2* | 7,3* | 7,4* | 7,5* |

In order to draw alphabet B let start it by putting * characters in the first row and the last row. The equivalent logical conditions will be using logical condition row==1 and row ==7.

The logical condition becomes

(row==1)|| (row==7)

Now we need to put * characters in the second column and the last column. So adding (col==2) and (col==5) logical conditions using OR (||) logical operator means more * characters are to be added in the following boxes. The updated logical conditions can be shown as the following:

(row==1)|| (row==7)|| (col==2)||(col==5)

|  | col=1 | col=2 | col=3 | col=4 | col=5 |
|---|---|---|---|---|---|
| row=1 | 1,1* | 1,2* | 1,3* | 1,4* | 1,5* |
| row=2 | 2,1 | 2,2* | 2,3 | 2,4 | 2,5* |
| row=3 | 3,1 | 3,2* | 3,3 | 3,4 | 3,5* |
| row=4 | 4,1 | 4,2* | 4,3 | 4,4 | 4,5* |
| row=5 | 5,1 | 5,2* | 5,3 | 5,4 | 5,5* |
| row=6 | 6,1 | 6,2* | 6,3 | 6,4 | 6,5* |
| row=7 | 7,1* | 7,2* | 7,3* | 7,4* | 7,5* |

Adding one more condition (row ==4). One issue with this logical condition is that

we don't want * character in the (row == 4) especially in the box with value pair (4, 1).

|  | col=1 | col=2 | col=3 | col=4 | col=5 |

We apply logical AND (& &) conditional operator to select less data. In our case we need to select one * character less in the (row == 4) to complete the middle part of the alphabet B.
