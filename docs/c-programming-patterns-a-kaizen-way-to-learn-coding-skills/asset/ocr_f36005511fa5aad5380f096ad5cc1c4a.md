# Programming Patterns Using String functions and Arrays

We will now re-implement some of the patterns just using single for-loop and we know that these were already implemented using nested loop (one for-loop within another for-loop). It can be done simply by using in-built string methods which are included in the string functions library header given as follows;

```
#include <string.h>.
```

Pattern A1

# StringPatternA1.c

```
#include <stdio.h>
#include <string.h>
int main() {
    int totalRows = 5; // number of rows to display
    char line[44]={" "}; // initialize with blank string.
    // Column level Repetitive Action :
    for( int row = 1 ; row <= totalRows ; row ++ ) {
        strcat( line , "* " ); // append strings
        // Print string and move cursor to the next row
        printf("%s\n",line);
    }
    return 0;
}
```
