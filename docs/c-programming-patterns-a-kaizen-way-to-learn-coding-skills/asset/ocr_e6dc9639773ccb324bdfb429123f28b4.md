So, we can use row variable to make it consistent given as follows.

| Column level Repetitive Action |  |  |  |  |  |  |
|---|---|---|---|---|---|---|
| row | lower_limit <= col_sp <= upper_limit |  |  | lower_limit <= col_num <= upper_limit |  |  |
|  | lower_limit | upper_limit | default | upper_limit | lower_limit | default |
| 5 | 1 | 0 | totalRows - row | 1 | 5 | row |
| 4 | 1 | 1 | totalRows - row | 1 | 4 | row |
| 3 | 1 | 2 | totalRows - row | 1 | 3 | row |
| 2 | 1 | 3 | totalRows - row | 1 | 2 | row |
| 1 | 1 | 4 | totalRows - row | 1 | 1 | row |

The lower_limit of col_sp variable is same for all the rows .The upper_limit of col_num variable is same for all the rows. It means the upper_limit of col_sp & col_num variables are generalised for any number of rows. So our inner for-loop condition for printing space characters becomes;

| loop-condition | lower_limit <= col_sp <= upper_limit |
|---|---|
| **Mathematical expression** | 1 <= col_sp <= (totalRows – row) |
| **Syntax** | `for( col_sp = 1; col_sp <= (totalRows – row); col_sp++ )` |

So our inner for-loop condition for printing numeric characters becomes;

| loop-condition | lower_limit <= col_num <= upper_limit |
|---|---|
| **Mathematical expression** | 1 <= col_num <= row |
| **Syntax** | `for( col_num=1; col_num <= row ; col_num ++ )` |
