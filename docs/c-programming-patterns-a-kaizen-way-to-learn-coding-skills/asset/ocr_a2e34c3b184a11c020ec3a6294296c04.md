If we observe it is following even-odd rule. For even value of row, means when row value is a multiple of 2, we need to print zero's or otherwise. If we try we can generalise 0 or 1 in terms of row variable. Let’s try to generalise columns **upper_limit** and **values_repeated** by expressing in terms of available variables.

| row | values_repeated | Column level Repetitive Action | lower_limit | upper_limit |  |  |
|---|---:|---|---:|---:|---|---:|
|  | default | 1 |  | default | 1 |  |
| 1 | 1 | row%2==1 | 1 | 1 | row | 1 |
| 2 | 0 | row%2==0 | 1 | 2 | row | 0 0 |
| 3 | 1 | row%2==1 | 1 | 3 | row | 1 1 1 |
| 4 | 0 | row%2==0 | 1 | 4 | row | 0 0 0 0 |
| 5 | 1 | row%2==1 | 1 | 5 | row | 1 1 1 1 1 |

For all the rows, the value prints exactly the number of times the upper_limit of col value.

So the *upper_limit* of col variable is generalised to **row** variable.

The *lower_limit* & *upper_limit* are consistent for all the rows.

It’s now generalised for any number of rows.

We can now define column level *for-loop* which is for every row value.

| **Elements of Column level _for-loop_** |  |
|---|---|
| *min_val* | 1 |
| *max_val* | row |
| *variable_name* | col |
| statement(s) | `printf("%d ", row);` |

Also, printing 0 or 1 can be given by checking the if-condition (row%2==1) or (row%2==0).
