# *Convert Logical Conditions to Simple Picture*

In this form of simple exercises, we need to express logical conditions by carefully selecting the appropriate boxes as per the logical condition and marking those boxes with * character. Each box is represented by unique combination of (row, col) value pair. Please check the given exercises to understand how the selection of boxes are done using the given conditions.

# **ExerciseYB1: Express Logical condition: (row == col) in the following 8X8 box.**

The condition **(row == col)** requests that please search those (row, col) value pairs in the given **8X8 box** where **row value and column value will be equal**. We can notice that on the diagonal of square the value of row and col is equal. **Just to get attention easily, boxes are marked with thick borders where row and col values are equal.**

| row=2 | 2,1 | 2,2 | 2,3 | 2,4 | 2,5 | 2,6 | 2,7 | 2,8 |
| row=3 | 3,1 | 3,2 | 3,3 | 3,4 | 3,5 | 3,6 | 3,7 | 3,8 |
| row=4 | 4,1 | 4,2 | 4,3 | 4,4 | 4,5 | 4,6 | 4,7 | 4,8 |
| row=5 | 5,1 | 5,2 | 5,3 | 5,4 | 5,5 | 5,6 | 5,7 | 5,8 |

So as per rule of the game we should put * character on those boxes where **row and col values are equal.**

Removing other (row, col) value pairs where **row and col values are not equal** to indicate that considered logical condition doesn’t select them. It simply means that only those boxes were chosen and marked with * character that matches the given logical condition.
