## About Final Exam

Give exam whenever you can spend at least 2 to 3 hours.

There is no upper limit for time and it is open-book exam.

**Your target should be to execute the program correctly in a single chance, giving the matching output.**

## FINAL EXAM — PROVE YOUR WORTH

![](img/67765455776ddeb6395161cd553ecd87_394_0.png)

Write a generalized logic so that it should be able to satisfy at least three different inputs which will basically either ZOOM-IN (print smaller-sized watch) or ZOOM-OUT (print bigger-sized watch).

- **Question A** → Solve it using nested-loop.
- **Question B** → Solve it using functions. Write functions to reuse the logic so that no repeated logic should be possible.
- **Question C** → Solve it using in-built C library String functions and array(s).
- **Question D** → Solve it using C pointers.
- **Question E** → Solve it using recursive function calls.
