# Approach to solution

Learning the approach to find a generalised solution for different input values of **total number of rows** is the actual practice about programming logic.

We need to generalise the non-repeating numeric pattern of the column **max_val** using the available variables. The variables are row & totalRows=5.

| Row level Repetitive Action | Expected Output |
|---|---|
| Variable : row | |
| Column level Repetitive Action | |
| Variable : col | |
| Row | min_val | max_val | Expected Output |
| 1 | 1 | 1 | * |
| 2 | 1 | 2 | * * |
| 3 | 1 | 3 | * * * |
| 4 | 1 | 4 | * * * * |
| 5 | 1 | 5 | * * * * * |

The numeric pattern of the column **max_val** matches exactly the every value of **row**. So all the numeric pattern can be expressed in <u>row</u> variable.

Column level Repetitive Action

| | | | |
|---|---|---|---|
| Variable : row | | | |
| loop-condition( Variable : col ) | | | |
| min_val | max_val | | |
| | default | 1 | |
| Row | min_val | max_val | Expression |
| 1 | 1 | 1 | row |
| 2 | 1 | 2 | row |
| 3 | 1 | 3 | row |
| 4 | 1 | 4 | row |
| 5 | 1 | 5 | row |

Now, **max_val** has the same expression and it is consistent for every value of **row**. We can now define column level ***for-loop*** which is same for every row value.

Elements of Column level for-loop

| | |
|---|---|
| min_val | 1 |
| max_val | row |
| variable_name | col |
| statement(s) | `printf("*");` |
