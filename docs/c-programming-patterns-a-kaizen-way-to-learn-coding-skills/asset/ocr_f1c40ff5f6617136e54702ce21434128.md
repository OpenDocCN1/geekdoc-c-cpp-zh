# Alternative solution

Let's device a solution by merging two inner for-loops into single by introducing the if-else construct.

We can directly get the idea from the for-loop condition of the both the inner for-loops. It's either printing space or number. Number starts with the formula (2*row - 1) and decreases till it reaches the row value. The lower_limit is an initialization part and need to do it only once.

If we take care of initialisation and step-decrementing part then the loop-condition can be converted into the if-condition.

# NumberPatternBBB2.c

```
#include <stdio.h>
int main() {
    int totalRows = 5; //number of rows to display
    // Row level Repetitive Action :
    for ( int row = 1; row <= totalRows; row++ ) {
        // Column level Repetitive Action :
        // 1)Move cursor in the same row. 2)print character
        // spaces to be printed before printing numbers
        int num = 2 * row - 1;// horizontal movements
        // spaces to be printed before printing numbers
        for ( int col = 1; col <= ( totalRows ); col++ ) {
            if ( col <= ( totalRows - row ) ) {
                printf( " " );
            } else if ( num >= row ) {
                // added extra space for clarity in output.
                printf( "%d ", num );
                num = num - 1;
            }
        }
        // move control to the next line
        printf( "\n" );
    }
    return 0;
}
```
