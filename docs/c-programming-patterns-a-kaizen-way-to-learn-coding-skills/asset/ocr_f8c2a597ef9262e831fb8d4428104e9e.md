# THE FRAMEWORK FOR IMPROVING LOGIC BUILDING SKILLS.

![](bbox=[0.2, 0.2, 0.8, 0.55])

The steps need to follow are in a specific order which are given as follows;

| Step | Activity |
|------|----------|
| 1. | Select the pattern picture. |
| 2. | Create the Logic Trace Table by seeing the pattern picture. |
| 3. | Extract the logical expression(s) from Logic Trace Table. |
| 4. | Implementing the program using logical expression(s). |
| 5. | Execute the program and check program’s output to match selected pattern picture. |

Note: If step 5 goes wrong, need to repeat step2 to step5.
