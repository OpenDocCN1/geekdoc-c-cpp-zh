# Any pre-requisite?

No prior experience in any programming language is required. If you have any, it is good and this is optional as we are not dealing much of the syntactical technical matter. We only need very minimal language’s features to practice programming exercises in order to cultivate interest and confidence in programming. We are majorly dealing with two main technical concept.

+   a) Conditional statements (If-statement, if-else statement)

+   b) Looping construct— just *for-loop*.

Programming syntax of *conditional statements* and *for-loop* of C resembles with many other programming languages like C, C#, C and C++. After learning from this book they can easily experiment in programming language of their interest.

One of the common quality of highly successful people are as soon as they acquire information, their speed of implementation is very fast. This quality helps them to be stay ahead in the competition. The best thing to **compete with ourself and try to** break our own record.

# About the book

All the material presented here is only meant for action, a practical to do sessions. We are not covering C as a language but programming logic as a subject using C programming languages’ syntax. This book is not a product of guesswork. This book is outcome of experiments conducted among college students in order to improve their logic building skills or to learn programming from the scratch but in a quick way.

The learner has to practice the approach mentioned in the book for logic building skills related to 2-dimensional simple picture based exercises. Practice exercises are arranged in an increasing challenging way and motivates to refine programming skills continuously in a step by step manner. The solved exercises gives the complete idea and unsolved problems urges to apply logical concept. So, it is going to be YOU versus YOU in an interesting way.

Two major requirement are expected from every learner which are as follows:

+   a) Intention that you want learn programming

+   b) Need to spend some time consistently and it depends how much quickly you want to become a confident programmer. **Don’t break the learning pattern at least for 3 months, spend at least minimum 20 - 30 minutes daily.** Just follow this course of action step by step, you will surely get substantial grip in the programming.

It’s up to you afterwards to explore new horizons in programming or software development. I can only promise an excellent start in a short period of time regarding your journey of learning a programming logic. *So let’s start the journey of learning.*
