
## Operators

Some special keyboard characters are used as operators in programming to denote frequent mathematical operations like addition, subtraction, comparing two numeric values and many such operations. We can categorize operators as per their purpose. In short, it’s a simulation of simple school maths calculation activities but using programming. These simple mathematical operations are very much common in our daily life and play a major role in dealing daily business or transactions. Such calculation based activities with accuracy and many such related activities are very much common in our daily routine.

### Arithmetic Operators

| Operator | Arithmetic Operation Description |
|---|---|
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| % | Modulus (Remainder on division) |
| ++ | Increment |
| -- | Decrement |

For example, simple **addition operation** using “+” operator can be given as follows:

```c
int intNum1 = 6;
int intNum2 = 4;
int intResult = intNum1 + intNum2;
```

We know that assignment operator (=), at a time we can store a single value in a variable. So in the considered example, **intNum1** will store the value 6 & **intNum2** will store the value 4.

Finally, **intResult** will store the result value of addition of **intNum1** and **intNum2** as addition operator (+) is applied between these two variables.

| Variable Declaration | Memory Address | Memory Content |
|---|---:|---|
| int intNum1; | 1221 | Nil |
| int intNum2; | 1222 | Nil |
| | 1223 | |
| int intResult; | 1234 | Nil |

| Variable Assignment | Memory Address | Memory Content |
|---|---:|---:|
| int intNum1 = 6; | 1221 | 6 |
| int intNum2 = 4; | 1222 | 4 |
| | 1223 | |
| int intResult = intNum1 + intNum2; | 1234 | 10 |

### Exercise 3. Demonstrate basic arithmetic operations using arithmetic operators.

`ArithmeticOperationsInteger.c`

```c
#include <stdio.h>

int main() {

    int intNum1 = 6, intNum2 = 4;

    int intResult = -999; // initialize with unexpected value


    printf("Integer numbers: ");

    printf("\nintNum1 = %d, intNum2 = %d", intNum1, intNum2 );


    printf("\n\n");

    printf("Operations | Operator | Expression | Result\n");
    printf("-------------------------------------------\n");


    printf("Add       | +        | ");
    intResult = intNum1 + intNum2;
    printf("%d + %d   |  %d\n", intNum1, intNum2, intResult );


    printf("Subtract  | -        | ");
    intResult = intNum1 - intNum2;
    printf("%d - %d   |  %d\n", intNum1, intNum2, intResult );


    printf("Multiply  | *        | ");
    intResult = intNum1 * intNum2;
    printf("%d * %d   |  %d\n", intNum1, intNum2, intResult );


    printf("Divide    | /        | ");
    intResult = intNum1 / intNum2;
    printf("%d / %d   |  %d\n", intNum1, intNum2, intResult );

    // Just use a second percent(%) sign to
    // output the percent(%) sign!!!
    printf("Remainder  | %%       |  ");
    intResult = intNum1 % intNum2;
    printf("%d  %%  %d      |  %d\n", intNum1, intNum2, intResult );

    return 0;
}
```

**Output**

Integer numbers: intNum1 = 6, intNum2 = 4

| Operations | Operator | Expression | Result |
|---|---|---|---|
| Add | + | 6 + 4 | 10 |
| Subtract | - | 6 - 4 | 2 |
| Multiply | * | 6 * 4 | 24 |
| Divide | / | 6 / 4 | 1 |
| Remainder | % | 6 % 4 | 2 |

### Exercise 4. Write a program showing value changes using incrementing & decrementing operator.

`IncrementDecrementOperators.c`

```c
#include <stdio.h>

int main() {
    int value = 100;

    printf("Given values.\n");

    printf("value = %d\n\n", value );

    printf("Incrementing 3 times\n");

    value++;

    value++;

    value++;

    printf("Result = %d\n\n", value );

    printf("Decrementing 2 times\n");

    value--;

    value--;

    printf("Result = %d\n", value );

    return 0;
}
```

**Output**

```text

Incrementing 3 times
Result = 103

Decrementing 2 times
Result = 101
```

### Comparison Operators

The comparison result of two values either will be true or false and these values are also known as boolean values and truth values. This feature is of very much importance since it will help to make decision in terms of true or false. The computer memory is based on 1(true) or 0(false) value called as bit value. Every data in computer is a combination of one's and zero's called bit pattern.

Different value or data means different bit pattern.

| Operator | Comparison Operation Description |
|---|---|
| == | Equal |
| != | Not Equal |
| < | Less than |
| <= | Less than or equal |
| > | Greater than |
| >= | Greater than or equal |

Using comparison operators we can compare two numeric values. The following example shows the use of comparison operators using numeric values.

| Operator | Operand1 (Operator) Operand2 | Result |
|---|---|---|
| == | 4 == 4 | true |
| == | 4 == 10 | false |
| != | 6 != 4 | true |
| != | 4 != 4 | false |
| < | 6 < 10 | true |
| < | 6 < 6 | false |
| <= | 6 <= 6 | true |
| <= | 10 <= 6 | false |
| > | 6 > 6 | false |
| > | 10 > 6 | true |
| >= | 4 >= 6 | false |
| >= | 10 >= 6 | true |

We can also test the above results by storing the input values in variables and then applying comparison operators one by one.

Philosophically, true and false are the only two perfect answers in this world. While developing logic based on these perfect answers in a program we are required to do decision making. Specially, this feature allows flexibility in handling various different logical conditions in a program.

Sense and sensibility of this particular feature is a core of any good programmer.

**So please, pay your special attention.**

Let's verify the results using comparison operators on operands 4, 6 and 10.

```c
#include <stdio.h>

int main() {

    int four = 4;
    int six = 6;
    int ten = 10;
    // initialize with unexpected value to check if
    // comparison result is get executed or not.
    int isResult = -999;

    printf("*** Comparison Operators ***\n");
    printf("*** boolean result values[1 means true, 0 means false] ***");
    printf("\n\n");

    printf("equal ( == ) \n");
    isResult = ( four == four );
    printf("%d   ==   %d   |   %d\n", four, four, isResult );

    isResult = ( four == ten );
    printf("%d   ==   %d   |   %d\n", four, ten, isResult );
    printf("----------------------------------------------------------\n");

    printf("not equal ( != ) \n");
    isResult = ( four != four );
    printf("%d   !=   %d   |   %d\n", four, four, isResult );

    isResult = ( four != ten );
    printf("%d   !=   %d   |   %d\n", four, ten, isResult );
    printf("----------------------------------------------------------\n");

    printf("less than ( < )\n");
    isResult = ( six < six );
    printf("%d  <  %d  |  %d\n", six, six, isResult );

    isResult = ( six < ten );
    printf("%d  <  %d  |  %d\n", six, ten, isResult );
    printf("-----------------------------------------\n");

    printf("less than or equal ( <= ) \n");
    isResult = ( six <= six );
    printf("%d  <=  %d  |  %d\n", six, six, isResult );

    isResult = ( ten <= six );
    printf("%d  <=  %d  |  %d\n", ten, six, isResult );
    printf("-----------------------------------------\n");

    printf("greater than ( > )\n");
    isResult = ( six > six );
    printf("%d  >  %d  |  %d\n", six, six, isResult );

    isResult = ( ten > six );
    printf("%d  >  %d  |  %d\n", ten, six, isResult );
    printf("-----------------------------------------\n");

    printf("greater than or equal ( >= )\n");
    isResult = ( four >= six );
    printf("%d  >=  %d  |  %d\n", four, six, isResult );

    isResult = ( ten >= six );
    printf("%d  >=  %d  |  %d\n", ten, six, isResult );

    return 0;
}
```
