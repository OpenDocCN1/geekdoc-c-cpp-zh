
## COLUMN LEVEL REPETITIVE ACTION

Let’s consider two attributes rows and columns of a 2-dimensional pattern as variables;

row → variable type of integer to store integer value one at a time and represents row number between 0 and 4.

col → variable type of integer to store integer value one at a time and represents column number between 1 and 5.

spaces → variable type of integer to store integer value one at a time and represents space character at column number between 1 and 5.

totalRows → variable type of integer to store integer value for total number of rows.

The condition (col >= (**totalRows - row**)) gives the minimum limit, a starting point from which it will start printing star(“*”) character(s) till the maximum value of variable col which is (**totalRows + row**).

The if-condition can be given for between the range of values (**totalRows - row**) and (**totalRows + row**) using the **comparison and logical operators** as:

If ( col >= ( **totalRows - row** ) && col <= ( **totalRows + row** ) )

We already know that:

variable row = 0,1,2,3,4 or

row = 0,1,2,3,4, **totalRows - 1**

variable col = 1,2,3,4,...,9 or

col=1,2,3,4,..., ( **totalRows + row** )

## Why the maximum value of variable col is kept dynamic?

We know that the printing star("*") character(s) will continue till the maximum value of variable col which is (totalRows + row).

We are not worried about the spaces when printing of all the star("*") character(s) gets completed in a row.

It makes sense to restrict the column level looping to the point where the maximum number of printing of star("*") characters reached.

## Why the minimum value of variable col is kept 1?

It makes sense to start the col=1,2... from the value 1, since we have to print space characters before actual printing of star("*") characters required to start at the column level looping.

We can eliminate the logical AND(&&) condition which is ( col <= ( totalRows + row ) ) in the if-condition to print the star("*") characters.

It’s already planned to consider this logical AND(&&) condition as the loop-condition already been taken into the column level inner for-loop.

So the if-condition will now reduce to the following:

```
If ( col >= (totalRows - row ) )
```

We can summarise it all as:

| Prints a star character when condition is True for every value of variable col |  |  |  |  |  |
|---|---|---|---|---|---|
| col=1 | col=2 | col=3 | col=4 | ................... | col=(totalRows + row) |
| If ( condition( col >= (totalRows - row) ) is True )<br>Print star character<br><br>Else<br><br>Print space character |  |  |  |  |  |

We generalised the non-repeating numeric pattern of the column max_val into an expression.

We can now define column level for-loop which is same for every row value.

| Elements of Column level for-loop |  |
|---|---|
| min_val | 1 |
| max_val | totalRows + row |
| variable_name | col |
| statement(s) | printf("*"); |

## Row Level Repetitive Action

The following statements had been repeated 5 times (total number of rows).

**Column level for-loop for printing star characters** // *inner for-loop*

```
printf("\n" );// Move cursor to the next row
```

We have assigned unique value to each row starting from 0 till 4.

Let's execute the following program.

## PatternE1.c

```c
#include <stdio.h>
int main() {
    int totalRows = 5; // total number of rows to display
    // Row level Repetitive Action :
    // Action1.Executes Column level Repetitive Action
    // Action2.Move cursor to next row.
    for (int row = 0; row < totalRows; row++) {
        // Column level Repetitive Action :
        // Action1.Move cursor in the same row
        for (int col = 1; col <= (totalRows + row); col++) {
            if (col >= (totalRows - row)) {
                // Action2.prints star "*" character
                printf("* ");
            } else {
                // Action3.prints space " " character
                printf(" ");
            }
        }// inner for-loop
        printf("\n");// Move cursor to the next row
    }// outer for-loop
    return 0;
}
```
