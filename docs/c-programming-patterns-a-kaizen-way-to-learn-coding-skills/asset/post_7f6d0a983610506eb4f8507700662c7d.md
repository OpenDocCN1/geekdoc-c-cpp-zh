Let the `firstNum` and `secondNum` be the two variables declared in the `main()` method.

Let the variables `firstNum` and `secondNum` be having data values 9 and 10 respectively.

## Call by Value

In this type of method call, the data value of a variable will be passed as an argument.

![](img/67765455776ddeb6395161cd553ecd87_356_0.png)

Whenever there is a method call, every method will have its own individual stack frame. Hence, when we execute the following program, each method `main()` and `swap()` will maintain a separate stack frame.

```c
#include <stdio.h>

void swap(int, int );// function prototype

int main() {

    // local variables: firstNum, secondNum

    int firstNum = 9, secondNum = 10;

    printf( "*** Before swap() method call ***\n");

    printf( "[firstNum = %d | secondNum = %d]\n", firstNum, secondNum );

    printf( "----------------------------------------------------\n");

    // actual arguments:firstNum, secondNum

    swap( firstNum, secondNum );

    printf( "----------------------------------------------------\n");

    printf( "*** After swap() method call ***\n");

    printf( "[firstNum = %d | secondNum = %d] ", firstNum, secondNum );

    return 0;

}
```

```c
// formal parameters : firstNo and secondNo
void swap(int firstNo, int secondNo) {
    printf("Start swap() : ");
    printf("firstNo = %d | secondNo = %d \n", firstNo, secondNo );
    // local variable: emptyVar
    int emptyVar = 0 ;
    emptyVar = firstNo;
    firstNo = secondNo;
    secondNo = emptyVar;
    printf("End  swap() : ");
    printf("firstNo = %d | secondNo = %d\n", firstNo, secondNo );
}
```

## Output

```
*** Before swap() method call ***
[firstNum = 9 | secondNum = 10 ]
---------------------------------
Start swap() : firstNo = 9 | secondNo = 10
End  swap() : firstNo = 10 | secondNo = 9
---------------------------------
*** After swap() method call ***
[firstNum = 9 | secondNum = 10]
```

## Points to Remember

- Local variables can easily transfer or manipulate data among themselves within their individual method's stack frame.

The method swap() exchanges the data between its first method parameter and its second method parameter. It is shown in the output of program which is as follows;

```
Start swap() : firstNo = 9 | secondNo = 10

End  swap() : firstNo = 10 | secondNo = 9
```

![](img/67765455776ddeb6395161cd553ecd87_357_0.png)

- Local variables of a particular method has scope/visibility limited to their individual method's stack frame only. The local variables(firstNum, secondNum) of main() method are completely unknown to swap() method's stack frame. Similarly, the local variables(firstNo, secondNo) of swap() method are completely unknown to main() method's stack frame. The swap() method is called by the main() method. The actual parameters as a data are passed in the swap() method call. This means that the data of actual parameters(firstNum, secondNum) are copied to the equivalent individual formal parameters(firstNo, secondNo).

The values of formal parameters (**firstNo**, **secondNo**) which got exchanged within the **swap()** method call by using temporary variable, has no impact on the local variables(**firstNum**, **secondNum**) of the **main()** method. This can be confirmed by observing the specific part of output of this program which is as follows;

*** Before swap() method call ***
[firstNum = 9 | secondNum = 10 ]

*** After swap() method call ***
[firstNum = 9 | secondNum = 10]

## Conclusion:

*One method's stack frame is completely blind about local variables which are present on another method's stack frame.*

## Understanding the Concept of Pointers

The concept of pointers can be easily understood by using analogies. The method's stack frame is like a home. So, stack frames are very much like homes where family members of one home don't know anything about the family residing within another home, maintaining a complete secrecy with each other. Hence, the family members are like local variables.

## Analogies to understand the concepts: -

| Concept | Analogy |
|---|---|
| Method's stack frame | Home |
| Local variables are those variables which are available in their respective method's stack frame. | Family members (M1, M2, M3, M4). **Suppose family members (M1, M2,M3,M4) are available in their home.** |
| These local variables holds data. | **On a very broader level, the information which each family member is holding regarding anything is similar to what data means to a variable.** |
| Local variables can transfer or manipulate data/information among each other. | Family members **can share information among each other.** |
| Every local variable has a **unique memory address location.** | Every family member has a **unique mobile number.** |
| We write programming instructions using local variables in order to achieve a well-defined targeted output. | They can help each other in order to complete a well-defined task. This overlaps with the intention with which any method or function is written. |

Let's suppose that one of the family member M4 is interested to talk to his/her friend who is living at a distance far away from his/her place. One of the commonest way with which they can connect to each other is through mobile phones. The mobile number uniquely identifies a person and helps in connecting each other through mobile phones.

Every byte in a memory has a unique address value associated with it. So this makes sense that every variable declared has a unique memory address associated with it. This idea of uniqueness of memory address location matches with the idea of uniqueness of a mobile number. In this way, the concept of memory addresses resembles very much with the concept of mobile numbers. Consider an activity of taking an appointment of a doctor using a contact number remotely and meeting a doctor personally. In both the cases accessing a doctor differs. ## Call by Reference

In certain situations of programming requirement accessing data using memory address using pointer variable is favoured than accessing data directly using local variable. Let’s assume there are many methods in a program. Many methods in a program can access the latest content/data of a particular variable by referring to the memory address of a variable with the help of a pointer variable. This particular variable is local to the main() method and whose data may get regularly updated in many methods. In case, suppose many methods on different occasions needed a latest updated value of this particular main() method’s local variable. We know that in call by value functional call strategy, the called method works on the copy of the variable’s data passed via formal arguments. When the execution of called method ends it has no impact on the values of variables which are passed as actual arguments.

## How to update the values of actual arguments whose values got changed in a called method?

If there is a single variable, a called method may return a value and callee method will update it with the returned value. If more than one variable is to be updated, we may return many values using an array variable. Now, without returning any value(s) from calling method, how to update callee method’s local variables values. So the trick will be, a pointer variable should be used for each method parameter instead of normal variable. We need to pass the memory location of a variable instead of passing the copy of the value of a variable as already done in the call by value functional call strategy. This way many methods can get access to the most updated data of a particular variable which might got changed many times by different methods in a program.
