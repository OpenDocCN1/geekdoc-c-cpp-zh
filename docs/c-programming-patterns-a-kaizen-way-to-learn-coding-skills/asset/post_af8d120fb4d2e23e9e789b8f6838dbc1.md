
Let's execute the following program.

## PatternH2_1.c
```
#include <stdio.h>
int main() {
    int totalRows = 4; //number of rows to display

    // Row level Repetitive Action :
    // Executes Repetitive Action at Column level and
    // then Move control to  next row.
    for (int row = 1; row <= (2 * totalRows - 1); row++) {
        //1st half : Column level Repetitive Action :
        if (row <= totalRows) {
            for (int col = 1; col <= (totalRows + row - 1); col++) {
                if (col >= (totalRows - row + 1)) {
                    printf("* ");
                } else {
                    printf("  ");
                }
            }//inner for-loop_1
        }
        // 2nd half : Column level Repetitive Action :
        if (row > totalRows) {
            for (int col = 1; col <= (3 * totalRows - row - 1); col++) {
                if (col >= (row - totalRows + 1)) {
                    printf("* ");
                } else {
                    printf("  ");
                }
            }//inner for-loop_2
        }
        printf("\n");// Move cursor to next row.
    }// outer for-loop

    return 0;
}
```

Let's try to simplify program further by simplifying the <u>if-conditions</u> and loop-condition <u>expressions</u>.

For example, let's analyse the following expression when **col** is a variable which <u>**starts from value 0.**</u>

When variable col=5,6,..., will have the values, which means the logical condition to cover these values can be expressed as **col >= ( 4 + 1 ) or col > 4**, both means the same.

Similarly,

The variable **col=0,1,2,3** when contains the values, means col <= ( 4 – 1 ) or col < 4 ,both means the same.

In the same way the <u>**if-conditions**</u> and loop-condition <u>*expressions*</u> can be simplified.

The <u>**if-condition**</u> gives the minimum limit, a starting point for which program will start printing start("*") character(s) till the maximum value of variable col given by the <u>**loop-condition**</u>.

Let's consider;

- **colMin →** variable *type of integer* to store integer value of column , a starting point from which program will start printing start("*") character.
- **colMax →** variable *type of integer* to store integer value of column , a maximum value till program will stop printing star("*") character(s).

| Variable : row | if-conditions | |
|---|---|---|
| | Variable : colMin | |
| | **default** | **1** |
| row <= totalRows | col >= ( totalRows – row + 1 ) | col > ( totalRows – row ) |
| row > totalRows | col >= ( row – totalRows + 1 ) | col > ( row – totalRows ) |

| Variable : row | loop-conditions | |
|---|---|---|
| | Variable : colMax | |
| | **default** | **1** |
| row <= totalRows | col <= ( totalRows + row – 1 ) | col < ( totalRows + row ) |
| row > totalRows | col <= ( 3 * totalRows – row – 1 ) | col < ( 3 * totalRows – row ) |

Using variables **colMin & colMax** we can merge the two inner-loops by dynamically assigning these expression to these variables.

We can use if-else statement to update the variables **colMin & colMax** dynamically which are as follows.

```
if ( row <= totalRows ){

        colMin = ( totalRows - row );

        colMax = ( totalRows + row );
}else{

        colMin = ( row - totalRows );

        colMax = ( 3 * totalRows - row );

}
```

Further, we can use variables **colMin & colMax** in inner *for-loop*.

In this way, we can try merging two *inner for-loops* into *single inner for-loop*.

So, let's update our previous program with these changes and executes the program.

```
PatternH2_2.C

#include <stdio.h>
int main() {

    int totalRows = 5; //number of rows to display
    int colMin = 0;// column position to start printing "*"
    int colMax = 0;// column position to stop printing "*"

    // Row level Repetitive Action :
    // Action1.Executes Column level Repetitive Action
    // Action2.Move cursor to next row.
    for (int row = 1; row <= (2 * totalRows - 1); row++) {

        if (row <= totalRows) {
            colMin = (totalRows - row);
            colMax = (totalRows + row);
        } else {
            colMin = (row - totalRows);
            colMax = (3 * totalRows - row);
        }

        //Column level Repetitive Action :
        for (int col = 1; col < colMax; col++) {
            if (col > colMin) {
                printf("* ");
            } else {
                printf(" ");
            }
        }//inner for-loop

        printf("\n");// Move cursor to next row.
    }// outer for-loop

    return 0;
}
```
