# Approach to solution

The variables are row & totalRows=5. We need to generalise the non-repeating numeric pattern of the column max_val using these remaining variables.

The numeric pattern (1 to 5) of the column max_val matches exactly the every value of <u>row</u>. Hence, it can be expressed in row variable.

| 3 | 3 | 1 | 3 | row | 3 | * * * |
| 4 | 4 | 1 | 4 | row | 4 | * * * * |
| 5 | 5 | 1 | 5 | totalRows | 5 | * * * * * |

We need find the generalised expression for the maximum value of row variable also.

There are still non-repeating numeric values in the column max_val of the col variable.
