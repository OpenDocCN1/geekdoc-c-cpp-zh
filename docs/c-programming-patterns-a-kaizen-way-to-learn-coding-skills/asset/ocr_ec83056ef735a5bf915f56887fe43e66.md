So our outer for-loop condition becomes ;

| loop-condition | lower_limit <=row< upper_limit |
| Mathematical expression | 0 <= row < totalRows |
| Syntax | for( row = 0; row < totalRows; row++) |

So our inner for-loop condition becomes ;

| loop-condition | lower_limit <=col< upper_limit |
| Mathematical expression | (totalRows - row) <=col< 2* (totalRows - row) |
| Syntax | for(col=(totalRows - row);col<2*(totalRows - row);col++ ) |
