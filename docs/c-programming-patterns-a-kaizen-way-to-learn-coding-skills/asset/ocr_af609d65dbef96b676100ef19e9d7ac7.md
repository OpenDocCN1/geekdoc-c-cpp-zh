In order to output a 2-dimensional simple picture using a programming logic, it is required to know how to print a character horizontally and vertically. More is the complexity of the 2-dimensional picture, more challenging it will become to extract the programming logic and this is how it will force a learner to **"how to think like a programmer?"**. You can expect programming will be in a thrilling way, just like a puzzle solving exercises. Prior to programming 2-dimensional pictures simple or complex, let do some basic required fundamental programming related to it. We can now start learning programming logic simply by trying to print a text repeatedly, a simple text <u>horizontally in the same</u> <u>line</u> or <u><b>vertically</b></u> in every line.

***Exercise 1.*** Printing text "Word:" in the same line.

```
**PrintInSameLine.c**

```c
#include <stdio.h>

int main() {

    printf("Word: ");

    printf("Word: ");

    printf("Word: ");

    return 0;

}
```
```

```
**Output**

```
Word: Word: Word:
```
```

***Exercise 2.*** Let's try to output "Word:" three times in every line.

```
**PrintInEveryLine.c**

```c
#include <stdio.h>

int main() {

    printf("Word: \n");

    printf("Word: \n");

    printf("Word: \n");

    return 0;

}
```
```

```
**Output**

```
Word:
Word:
Word:
```
```
