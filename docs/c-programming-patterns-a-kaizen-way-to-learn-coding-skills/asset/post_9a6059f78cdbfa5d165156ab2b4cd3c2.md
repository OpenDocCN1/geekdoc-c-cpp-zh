## NumberPatternEEE.c

```c
#include <stdio.h>
int main() {
    int totalRows = 5; //number of rows to display
    int num;
    // Row level Repetitive Action :
    for ( int row = 1; row <= totalRows; row++ ) {
        num = 2 * row - 1;
        // Column level Repetitive Action :
        for ( int col = 1; col <= ( 2 * totalRows - 1 ); col++ ) {
            // calculates position to print numeric character
            if ( col >= ( ( totalRows - row ) + 1 ) &&
                col <= ( ( totalRows + row ) - 1 ) ) {
                // print a number with a single space
                if ( col < totalRows ) {
                    printf( "%d ", num );
                    num = num - 1;
                } else if ( col >= totalRows ) {
                    printf( "%d ", num );
                    num = num + 1;
                }
            } else {
                printf( "  " );// print 2 spaces
            }
        }// inner loop
        // Move to next row
        printf( "\n" );
    }// outer loop
    return 0;
}
```

## Arrays

Till now we have dealt with variables that deal only with single data. In short:

| Relationship between variable and data | | |
|---|---|---|
| Variable | one – to – one | Data |

It is also possible to have a relationship between variable and data as one-to-many, which means one variable can hold many data or a group of data. Such type of variables are specially known as array variables.

| Relationship between array variable and data | | |
|---|---|---|
| Array Variable | one – to – many | Data1 |
| | | Data2 |
| | | Data3 |
| | | Data4 |

We can also initialize an array variable like we used to initialize a normal variable by considering its data type. For example, 5 different numeric scores can be given as:

```c
int student_scores[5] = { 70, 50, 40, 56, 72 };
```

`student_scores` represents an array variable of size 5 and gets initialized with 5 different score values separated by commas. Each value is an owner of its position value commonly known as index value/position. So the group of same data type values can be represented by an array variable. In general, values of an array are also referred to as elements of an array.

Array name and index value combination is used to access specific data among the group.

> Array name along with different index values is like different variables, each containing data.

| Array name ⇨ | student_scores | |
|---|---|---|
| First index ⇨ | 0 | 70 |
| | 1 | 50 |
| | 2 | 40 |
| | 3 | 56 |
| Last Index ⇨ | 4 | 72 |

- 1st element ⇨ student_scores[0] ⇨ 70
- 2nd element ⇨ student_scores[1] ⇨ 50
- 3rd element ⇨ student_scores[2] ⇨ 40
- 4th element ⇨ student_scores[3] ⇨ 56
- 5th element ⇨ student_scores[4] ⇨ 72

## Access the values of an array

In order to refer to any stored value in an array, we need to use the array’s name along with the index of that array. Let’s try to understand a bit more from the given array declarations, how values are stored in arrays.

```c
    char bookTitle[20];

    float bookWeight[20]; // in Kg

    int bookPages[20];
```

| Character array (char bookTitle[20]) | Float array (float bookWeight[20]) | Int array (int bookPages[20]) |
|---|---|---|
| bookTitle[0] = 'C' | bookWeight[0] = 0.5 | bookPages[0] = 370 |
| bookTitle[1] = 'P' | bookWeight[1] = 0.73 | bookPages[1] = 421 |
| ........ | ........ | ........... |
| ........ | ........ | ........... |
| ........ | ........ | ........... |
| bookTitle[18] | bookWeight[18] = 0.54 | bookPages[18] = 355 |
| bookTitle[19] | bookWeight[19] = 0.64 | bookPages[19] = 423 |
| Each 1 byte sized data | Each 4 bytes sized data | Each 2 bytes sized data |

The character string constants are given by enclosing them in quotes, as shown by the following given example.

```c
// Case1
char bookTitle[20] = "C pointers";

// Case2
char bookTitle[20] = {'C',' ','p','o','i','n','t','e','r','s','\0'};
```

**Case1:** C automatically adds the NULL (ASCII 0 or '\0') character after the last character in a string.
**Case2:** C doesn’t automatically add a null-terminated character ('\0') at the end. The coder has to explicitly place it as its last element.

## Accessing array elements using array’s index value

### ArrayWithLooping.c

```c
#include <stdio.h>
int main() {
    // array initialization
    char name[20] = "Mr. Always Right";
    int ages[5] = { 10, 20, 30, 40, 50};
    float weight[5] = {23.27, 32.14, 37.45, 60.74, 47.25};
    long distance[5] = {1234567L, 4335454L, 98767567L, 4354321L,555588889L};
    int size = -1;// size of an array

    printf(" Accessing char array element using array's index value.\n");
    for( int index = 0 ; name[index] != '\0' ; index ++){
        printf(" %c | ", name[index]);
    }

    printf("\n\n Accessing int array element using array's index value.\n");
    // finding size of array using C language's sizeof() operator.
    size = sizeof( ages ) / sizeof( int );
    for( int index = 0 ; index < size ; index++){
        printf(" %d | ", ages[index]);
    }

    printf("\n\n Accessing float array element using array's index value.\n");
    // finding size of array using C language's sizeof() operator.
    size = sizeof( weight ) / sizeof( float );
    for( int index = 0 ; index < size ; index++){
        // This means total 5 digits will be used to print this float number
        // and 2 digits after decimal point.
        printf(" %5.2f | ", weight[index]);
    }

    printf("\n\n Accessing long array element using array's index value.\n");
    // finding size of array using C language's sizeof() operator.
    size = sizeof( distance ) / sizeof( long );
    for( int index = 0 ; index < size ; index++){
        // print long digit number using format specifier ld.
        printf(" %ld | ", distance[index]);
    }
    return 0;
}
```

## Pointers And Memory Matters

Pointers are famously known as address variables, as their only purpose is to store the memory address of a data, not the data itself. Pointer variable's name starts with asterisk (*) character. For example:

```c
data_type *dataPointer ;
int *intPtr; // pointer variable of type integer data-type
```
