The lower_limit & upper_limit are become consistent for all the rows. The lower_limit is generalised to row and upper_limit is generalised to (2*row - 1).These logical expressions are such that on commonly applying for all rows and columns helps to give matching output.

So our Conditioning becomes;

| loop-condition | lower_limit <=col<= upper_limit |
| Mathematical expression | row <= col <= (2*row - 1) |
| Syntax | for( col = row ; col <= 2*row - 1 ; col++ ) |
