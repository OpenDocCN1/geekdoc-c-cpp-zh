So the upper_limit of col variable is generalised to (totalRows + 1 - row).

The lower_limit & upper_limit are consistent for all the rows. It's now generalised for any number of rows. So our if-condition becomes;

| if-condition | lower_limit &lt;=col&lt;= upper_limit |
| --- | --- |
| Mathematical expression | 1 &lt;= col &lt;= ( (totalRows +1) - row ) |
| Syntax | if( col &gt;= 1 &amp;&amp; col &lt;= ( totalRows + 1 - row ) ) |
