Let's try to solve this pattern using a 1-dimensional array. We know that array is a continuous memory block which needs to declare earlier before it's use. For example our array will be;

| strings[44] | | | | | | | | | | | | |
| position | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 | ..... | 44 |
| Character | | | | | | | | | | ..... | .... |

```
char strings[44] = { " " }; // continuous block of memory allocated.
Moreover, the following printing statement prints horizontally all the content of an array in a single chance.
printf("%s", strings );
```

Hence for every row we need to print the array but with modification in the contents of this array. Basically we will re-use the same array and print its contents.

## Two main observations are as follows:

- a) If we initialize this array with space, then logic to dynamically print spaces will not be required.
- b) Only we need to track of putting the star(*) characters at an appropriate places. The count goes on increasing till row=5 and goes on decreasing. Initially we need to fill the array with star(*) characters to complete the first half triangle and then need to decrease star(*) characters to generate the reverse triangle.

Let's try to implement program based on our fact-findings.

```c
Pattern1HByArray.c:
#include <stdio.h>
#include <stdlib.h>
int main() {

        char strings[44] = { "" };
        int totalRows = 5; // number of rows to display
        int MAX_COLUMNS = 2 * totalRows - 1;
        int midIndex = totalRows - 1; // since array index start at 0;
        int count = 0;

        // initializing array with spaces
        for ( int col = 0; col < MAX_COLUMNS; col++ ) {
                strings[col] = ' ';
        }

        // Column level Repetitive Action :
        for ( int row = 1; row <= MAX_COLUMNS; row++ ) {

                // filling array using '*' char at specific positions.
                if ( row == 1 ) {
                        strings[midIndex] = '*';
                } else if ( row <= totalRows ) {
                        count = count + 1;
                        strings[midIndex - count] = '*';
                        strings[midIndex + count] = '*';
                } else {
                        // for second-half portion
                        strings[midIndex - count] = ' ';
                        strings[midIndex + count] = ' ';
                        count = count - 1;
                }
                // Print string and move cursor to the next row
                printf( " %s\n", strings );
        }
        return 0;
}
```

## Programming Pattern Using Pointer

In most of the cases related to arrays, memory remains unused. The C library does provide a facility to allocate memory as per our exact memory allocation demands. Such dynamic memory allocation functions are declared in the <stdlib.h> header. For example;

```
int totalRows = 5;

char *charPtr;

charPtr = (char *)malloc( sizeof(char) * (totalRows + 1) );
```

malloc or memory allocation method is used to dynamically allocate a single large block of memory with the given specified element_count and data-type. In this example data-type is char and elements are 5 and require 1 more extra byte of memory for string termination by NULL. So in total it will be (totalRows + 1) and this suggests (1 * 6 or 6 ) bytes of memory block.

| 6 bytes | byte | byte | byte | byte | byte | byte |
|---|---|---|---|---|---|---|
| Index | 0 | 1 | 2 | 3 | 4 | 5 |
| Address | 1024 | 1025 | 1026 | 1027 | 1028 | 1029 |

charPtr will hold the address of the first element in the allocated memory block.

```
// string is made null-terminated at 6th byte after
// allocating characters in first 5 bytes.

*( charPtr + 5 ) = '\0';
```

In general;

```
dataType *dataTypePtr = (dataType *)malloc( sizeof(dataType) * count );
```

If the memory is insufficient, then allocation will fail and will return a NULL pointer.

```
// checking if memory block allocated or not.
if ( charPtr == NULL) {
    printf("malloc failed.\n");
    exit(0); // terminate the program.
}
```

In order to de-allocate the allocated memory, we can use method free from <stdlib.h> header.

```
// freeing the allocated memory
free( charPtr );
```
