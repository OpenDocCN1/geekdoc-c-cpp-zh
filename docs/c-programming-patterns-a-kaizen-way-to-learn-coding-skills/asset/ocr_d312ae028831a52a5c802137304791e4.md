# Art of Applying Logical Conditions

Logical conditions are the defence mechanism of working features of any software application. Most of the bugs/errors which occurred are due to the improper handling of logical condition(s). It mostly consists of logical or comparison operators. One of the most important element of programming logic is to apply logical conditions. It controls the flow of program similarly like how road traffic control system works. Road traffic control system logically distributes the crowd by conditionally allows or stops the portion of the crowd directing towards a particular road. Similarly, logical conditions in a program allow only certain set of programming statements to be get executed.

If that road side traffic control system doesn't work accordingly, then instead of maintain peaceful driving it may create traffic jams and road accidents. Similarly, wrong logical conditions gives unpredictable results if gone unnoticed.

Logical conditions are similar like road signs. Those road signs are got some meaning. They are been used based on some specific purpose and directly influences the traffic. In a similar way we will try to understand how logical conditions influences the output of the program which will help to improve our logical thinking capabilities.

We will use a simple version of scratch pad to verify our logical conditions manually. It may remind you of cross-words puzzle box. Let us take similar kind of box consists of 8 rows and 8 columns. For representing rows and columns we can take two variables named as row and col respectively.

Variable row → denotes values of row=1, 2,3,4,5,6,7,8.

Variable col → denotes values of col=1, 2,3,4,5,6,7,8.

Each one box is recognised by (row, col) value pair. So value pair (1, 1) means 1st row and 1st column.

**Rule of the game:** *Where ever logical condition matches, need to put character * in a small box.*

All (row, col) value pairs represent the total information or data. It has 8 rows and 8 columns which makes total 64 (row, col) value pairs. So, when logical conditions are mapped into this box we will select correct (row, col) value pairs from the total available 64(row, col) value pairs. Applying different logical conditions means manually selecting (row, col) value pairs matching each logical condition. This type of very simple observation based exercises will helps us to understand how logical condition works at the very core level.
