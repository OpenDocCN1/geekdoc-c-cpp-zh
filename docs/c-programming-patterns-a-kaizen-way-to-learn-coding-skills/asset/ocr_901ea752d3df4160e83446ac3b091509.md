We can express column max_val of col variable in terms of row variable and part of the expression follows a multiple of 2 but for row values greater than 5 or totalRows.

It has condition when to increment the multiple of 2 or not. The condition is handled by conditional statements mostly by if-statement or if-else-statement or if-elseif-else .This we need to handle using such conditional statement by declaring another integer variable ,for example;

int count ; // counter to increment the multiple of 2.

We can give if-statement something like the following by incrementing the value of count variable when row value crosses the totalRows value which is value 5,the initial total number of rows.

```
if( count > totalRows){
    count = count + 1; // Increment the count value by 1.
}
```
