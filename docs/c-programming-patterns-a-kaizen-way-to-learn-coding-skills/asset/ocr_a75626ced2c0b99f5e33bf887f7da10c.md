# Stack and function calls

Stack literally means arranging items on top of another. A pile of books as shown in the picture is an example of stack. If we want a book from this stack, we need to start removing book from the top and then get the actual one. This is called last-in-first-out or in short LIFO method. Stack is a memory area in a RAM where data are added and removed in LIFO style. When a method is called, data stored in a variable(s) push into the top of the stack and data pop-out or get removed when the execution of called function ends.
