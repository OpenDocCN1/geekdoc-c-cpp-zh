## COLUMN LEVEL REPETITIVE ACTION

| Row level Repetitive Action (row) | Column level Repetitive Action: lower_limit | Column level Repetitive Action: upper_limit | Expected Output |
| --- | --- | --- | --- |
| 1 | 1 | 5 | 1 2 3 4 5 |
| 2 | 1 | 4 | 1 2 3 4 |
| 3 | 1 | 3 | 1 2 3 |
| 4 | 1 | 2 | 1 2 |
| 5 | 1 | 1 | 1 |

The lower_limit has same numeric value expression for the rows. It’s consistent for all the rows. Likewise we need to come up with such a consistent expression for *upper_limit* which should suit any number of rows.

The considered variables are row, totalRows = 5. Let's try to generalise using these variables.

**Column level Repetitive Action: if-condition (lower_limit <= col <= upper_limit)**

| row | lower_limit | upper_limit | 1 | 2 | 3 |
| --- | --- | --- | --- | --- | --- |
| 1 | 1 | 5 | totalRows | (totalRows + 1) - 1 | (totalRows + 1) - row |
| 2 | 1 | 4 | totalRows - 1 | (totalRows + 1) - 2 | (totalRows + 1) - row |
| 3 | 1 | 3 | totalRows - 2 | (totalRows + 1) - 3 | (totalRows + 1) - row |
| 4 | 1 | 2 | totalRows - 3 | (totalRows + 1) - 4 | (totalRows + 1) - row |
| 5 | 1 | 1 | totalRows - 4 | (totalRows + 1) - 5 | (totalRows + 1) - row |

So the upper_limit of col variable is generalised to (totalRows + 1 - row).

The lower_limit & upper_limit are consistent for all the rows. It's now generalised for any number of rows. So our if-condition becomes:

| if-condition | lower_limit <= col <= upper_limit |
| --- | --- |
| Mathematical expression | 1 <= col <= ((totalRows + 1) - row) |
| Syntax | if( col >= 1 && col <= ( totalRows + 1 - row ) ) |

## NumberPatternCC1.c

```c
#include <stdio.h>
int main() {
    int totalRows = 5; //number of rows to display
    // Row level Repetitive Action :
    for ( int row = 1; row <= totalRows; row++ ) {
        // Column level Repetitive Action :
        // Action1.Move cursor in the same row
        // Action2.print character
        // spaces to be printed before printing numbers
        for ( int col = 1; col <= totalRows; col++ ) {
            if ( col >= 1 && col <= ( totalRows + 1 - row ) ) {
                printf("%d ", col);
            } else {
                printf("  ");
            }
        }// inner for-loop
        printf("\n");// move control to the next line
    }// outer for-loop
    return 0;
}
```

The inner for-loop's lower_limit matches with the if-condition's lower_limit.


We can safely neglect the lower_limit in if-condition as it will become redundant condition, since already been taken care in inner for-loop.

Hence, our final if-condition can be given as:

| if-condition | lower_limit <= col <= upper_limit |
| --- | --- |
| Mathematical expression | col <= ((totalRows + 1) - row) |
| Syntax | if( col <= (totalRows + 1 - row) ) |

## NumberPatternCC3.C

```c
#include <stdio.h>
int main() {

    int totalRows = 5; //number of rows to display

    // Row level Repetitive Action :
    for ( int row = 0; row < totalRows; row++ ) {

        // Column level Repetitive Action :
        // Action1.Move cursor in the same row

        // spaces to be printed before printing numbers
        for ( int col = 1; col <= totalRows; col++ ) {

            } else {
                printf( "  " );
```
