# ForLoopIncrement.C

```
```c
#include <stdio.h>

int main() {

    for ( int counter = 1 ; counter <= 5 ; counter ++ ){

        printf("%d\n",counter);//print to console

    }

    return 0;

}
```
```

# Output

```
```
1
2
3
4
5
```
```

Case b: Changing the *loop-condition* counter <= 5 to counter < 5, and let's see the result.
