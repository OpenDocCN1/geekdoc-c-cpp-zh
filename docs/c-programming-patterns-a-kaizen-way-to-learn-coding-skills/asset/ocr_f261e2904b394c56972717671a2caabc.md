# Staircase.c

```
#include <stdio.h>
#include <string.h>
int main() {
    char string[44] = "Programming";
    char spaces[20] = {" "};
    for( int index = 0 ; string[index]!='\0' ; index++) {
        strcat( spaces , " " ); // append strings
        char ch = string[index] ;
        printf("%c",ch);
        printf("%s%s%s",spaces, spaces);
        // Print last char and move cursor to the next row
        printf("%c\n",ch);
    }
    return 0;
}
```

Exercise1: Rewrite the program Staircase.c without using strcat() method.

The first step will be to write the logic trace table with appropriate row & columns.

From the analysis of logic trace table, a programmer can be able to find out generalised way to get the solution to print series of "_" characters. A different character could also be taken like "*" , "=" or "#" in case you didn't get the count.
