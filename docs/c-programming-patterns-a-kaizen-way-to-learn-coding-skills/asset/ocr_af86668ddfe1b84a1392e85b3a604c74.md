# Programming Pattern Using Pointer

In most of the case related to arrays, memory remains unused. The C library does provides a facility to allocate memory as per our exact memory allocation demands. Such dynamic memory allocation functions are declared in the <stdlib.h> header. For example;

```
int totalRows = 5;

char *charPtr;

charPtr = (char *)malloc( sizeof(char) * (totalRows + 1) );
```

malloc or memory allocation method is used to dynamically allocate a single large block of memory with the given specified element_count and data-type. In this example data-type is char and elements are 5 and require 1 more extra byte of memory for string termination by NULL. So in total it will be (totalRows + 1) and this suggests (1 * 6 or 6 ) bytes of memory block.

| 6 bytes | byte | byte | byte | byte | byte | byte |
|---|---|---|---|---|---|---|
| Index | 0 | 1 | 2 | 3 | 4 | 5 |
| Address | 1024 | 1025 | 1026 | 1027 | 1028 | 1029 |

charPtr will hold the address of the first element in the allocated memory block.

```
// string is made null-terminated at 6th byte after
// allocating characters in first 5 bytes.

*( charPtr + 5 ) = '\0';
```

In general;

```
dataType *dataTypePtr = (dataType *)malloc( sizeof(dataType) * count );
```

If the memory is insufficient, then allocation will fail and will returns a NULL pointer.

```
// checking if memory block allocated or not.
if ( charPtr == NULL) {
    printf("malloc failed.\n");
    exit(0); // terminate the program.
}
```

In order to de-allocate the allocated memory, we can use method free from <stdlib.h> header.

```
// freeing the allocated memory
free( charPtr );
```
