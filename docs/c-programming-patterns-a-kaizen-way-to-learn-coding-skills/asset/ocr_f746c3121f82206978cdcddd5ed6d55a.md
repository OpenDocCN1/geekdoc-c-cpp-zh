# # Pattern1B

Our programming job is to output this simple picture-based pattern on a part of the computer screen as shown in the following. Our approach will be considering computer screen as a combination of rows and columns containing small boxes. We can consider the computer screen as a combination of (row, column) numeric value paired boxes spread all across the screen. Each box is treated as a resident of just a single character only. We also know that the complete pattern can be easily expressed as a collection of selected (row, column) numeric value pairs.

# ## Analysis of output

We can know exact location of each “*” character by knowing it’s unique (row, column) numeric combination on the computer screen.

| | Col=1 | Col=2 | Col=3 | Col=4 | Col=5 |
|---|---|---|---|---|---|
| Row=1 | \* (1,1) | \* (1,2) | \* (1,3) | \* (1,4) | \* (1,5) |
| **Row=2** | **\* (2,1)** | \* (2,2) | \* (2,3) | \* (2,4) |  |
| Row=3 | \* (3,1) | \* (3,2) | \* (3,3) |  |  |
| Row=4 | \* (4,1) | \* (4,2) |  |  |  |
| Row=5 | \* (5,1) |  |  |  |  |

(2, 1) means character “*” at **second row** and **first column** in the table.

For example, for a numeric pair(2,1), the value 2 represents row number and the value 1 represents a column number. This is the actual measure by which we are able to identify a “*” character clearly at that particular location on the computer screen.
