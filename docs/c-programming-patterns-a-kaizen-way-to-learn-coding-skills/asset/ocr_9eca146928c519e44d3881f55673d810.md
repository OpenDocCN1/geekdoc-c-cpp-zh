```
#include <stdio.h>
// function prototype
void swap(int, int);

int main() {
    // local variables:
    firstNum, secondNum
    int firstNum = 9;
    int secondNum = 10;
    // actual arguments:
    // firstNum, secondNum
    swap(firstNum, secondNum);

}

void swap(int firstNo, int secondNo) {
    // local variable: emptyVar
    int emptyVar = 0 ;
    emptyVar = firstNo;
    firstNo = secondNo;
    secondNo = emptyVar;
}
```

After function call swap(), the program control tries to execute the programming instructions of the function swap().
void swap(int firstNo, int secondNo) {

When program control reaches the following variable declaration given as shown by the pointed arrow;
int emptyVar;
The variable emptyVar is pushed into the stack represented by memory address 1016 and data can be any garbage value(?). The variable emptyVar is now at the top of the stack.
When the following statement/instruction gets executed;
int emptyVar = 0 ;
The data of the variable emptyVar represented by memory address 1016 is gets updated with the value 0.
As per logic implemented in swap() method, the data between variables firstNo and secondNo should get exchanged or swapped.
