
## ROW LEVEL REPETITIVE ACTION

The same following statements had been **repeated 5 times** (total number of rows).

**Column level for-loop** // *inner for-loop*

```text
printf("\n"); //Move cursor to the next row
```

We can observe from the pattern that the total number of rows are 5.

We have assigned a **unique value to each row** starting from 1 till 5. So, it’s an easy task now.

The minimum and maximum value can be given for the *for-loop* as:

*min_val = 1* & *max_val* = 5 or totalRows

Let’s consider:

**row** → variable *type of integer* to store integer value one at a time and represents row number between 1 and 5 (totalRows). The **totalRows** has initially been assigned the value 5.

Outer *for-loop* starts at row=1 & will repeat till row <= **totalRows**.

| Elements Of Row Level *for-loop* | |
|---|---|
| *min_val* | 1 |
| *max_val* | totalRows |
| *variable_name* | **row** |
| statement(s) | **Column level for-loop**<br>//Move cursor to the next row<br><br>**printf("\n");** |

We got everything related to *for-loop* for row level repetition.

Let's execute the following program.

### PatternB1_1.c

```c
#include <stdio.h>

int main() {

    int totalRows = 5; //number of rows to display

    // Row level Repetitive Action :
    // Action1.Executes Column level Repetitive Action
    // Action2.Move cursor to next row.
    for( int row = 1 ; row <= totalRows ; row++ ) {

        // Column level Repetitive Action :
        for(int col = 1 ; col <= (totalRows +1) - row ; col++) {
            // Action1.Move cursor in the same row
            // Action2.print "*" character
            printf("* ");
        }
        printf("\n");// Move cursor to the next row
    }

    return 0;
}
```

### Output

```text

* * * *
* * *
* *
*
```

## Alternative solution3

We have to use the remaining variables row & **totalRows=5** to find the generalised expression for the column **max_val**.

The following table is the one that we already got from the **trace table** in the very beginning.

**Column level Repetitive Action**

| Variable : row | loop-condition (Variable : col)<br>min_val | loop-condition (Variable : col)<br>max_val |
|---|---|---|
| | | default |
| 1 | 1 | 5 |
| 2 | 1 | 4 |
| 3 | 1 | 3 |
| 4 | 1 | 2 |
| 5 | 1 | 1 |

If we observe the numeric pattern for row **[1, 2, 3, 4, and 5]** is the **reverse** of the numeric pattern of the column **max_val** **[5, 4, 3, 2, and 1]**.

If we just reverse the counter of the row variable it will match exactly the values of the column **max_val** **[5, 4, 3, 2, and 1]**. It simply means instead of using the **incrementing for-loop** for the row variable we need to replace it with the **decrementing for-loop** for the row variable.

Reversing the flow of values for the variable row can be given as follows:

**Column level Repetitive Action**

| Variable : row | loop-condition (Variable : col)<br>min_val | loop-condition (Variable : col)<br>max_val |
|---|---|---|
| | | default |
| 5 | 1 | 5 |
| 4 | 1 | 4 |
| 3 | 1 | 3 |
| 2 | 1 | 2 |
| 1 | 1 | 1 |

**Column level Repetitive Action**

| Variable : row | loop-condition (Variable : col)<br>min_val | loop-condition (Variable : col)<br>max_val |
|---|---|---|
| | | default |
| 5 | 1 | row |
| 4 | 1 | row |
| 3 | 1 | row |
| 2 | 1 | row |
| 1 | 1 | row |

Now the numeric pattern of variable row and column **max_val** matches exactly.

So, **max_val** can be expressed in variable row.

So, **max_val** is consistent for every value of **row**. Now, we are in a good position to go for the *for-loop* since *for-loop* requires **one minimum** and **one maximum value or an expression**.

We can now define column level **decrementing for-loop**.

It starts at the value of variable **row** and will repeatedly decrease till **col** value becomes **1**.

### Elements of Column level decrementing for-loop

|  |  |
|---|---|
| *max_val* | row |
| *min_val* | 1 |
| *variable_name* | col |
| **Loop condition** | col >= 1 |
| statement(s) | `printf("* ");` |

### ROW LEVEL REPETITIVE ACTION
