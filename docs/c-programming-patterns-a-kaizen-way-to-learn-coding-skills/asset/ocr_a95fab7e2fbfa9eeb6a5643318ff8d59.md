# Programming Patterns

All Programming patterns can be considered 2-dimensional pictures. Mostly whether the output is seen on a Desktop/Web/Mobile Application, it is 2 dimensional. For this reason, we select simple, picture based problems to address common programming logic issues. Moreover, programmers who are proficient in solving two dimensional problems in programming are also capable of solving three dimensional problems, e.g., related to game programming. The main reason to select exercises based on pictorial patterns is that it clearly validates programmer’s logic. The mismatching output forces learner to think for appropriate reason.

Repetitively working on programming logic to get the matching output greatly helps in perfecting the visualization of programming logic. It is a kind of reverse engineering, and we will see how it really works to improve programming skills. These exercises make learners alert, involved, self-motivated, and, most importantly, teaches them good amount of patience. These exercises are designed to create curiosity in the learner’s mind. The programmer’s imagination should work in a direction to trap the programming logic; this will make programming an interesting job. In a typical software development workplace, one programmer has to understand another’s programming. So a programmer can learn from the work of other programmers. In all cases, some mastery over visualization of programming logic will definitely help to understand other programmer’s programs. So practising visualization of programming logic should be the prime focus for any beginner programmer. Looping is the only hardest thing in a program. Mastering the flow of control in nested loops are enough to boost the confidence of beginner programmers.

In a nutshell, beginner’s confidence in programming capabilities has a direct relation with low/average/high level of visualization of programming logic.

What we will be learning is a simple maths based approach to visualize the program logic. This technique requires a level of practice. The more we practice the more refined will be our imagination to trap the programming logic.

Just by practising nested loops along with correct sense of applying logical conditions, a novice programmer can immensely build self-confidence.

Only one quality, that is, having patience to stick to work ethics, can lead a learner to become talented in his/her field. The chosen set of exercises naturally help learners in that direction.
