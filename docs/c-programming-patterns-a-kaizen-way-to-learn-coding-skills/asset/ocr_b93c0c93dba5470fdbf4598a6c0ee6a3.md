# Comparison Operators

The comparison result of two values either will be true or false and these values also known as boolean values and truth values. This feature is of very much importance since it will help to make decision in terms of true or false. The computer memory is based on 1(true) or 0(false) value called as bit value. Every data in computer is a combination of one's and zero's called bit pattern.

Different value or data means different bit pattern.

| Operator | Comparison Operation Description |
|---|---|
| == | Equal |
| != | Not Equal |
| < | Less than |
| <= | Less than or equal |
| > | Greater than |
| >= | Greater than or equal |

Using comparison operators we can compare two numeric values. The following example shows the use of comparison operators using numeric values.

| Operator | Operand1(Operator) Operand2 | Result |
|---|---|---|
| == | 4 == 4 | true |
| == | 4 == 10 | false |
| != | 6 != 4 | true |
| != | 4 != 4 | false |
| < | 6 < 10 | true |
| < | 6 < 6 | false |
| <= | 6 <= 6 | true |
| <= | 10 <= 6 | false |
| > | 6 > 6 | false |
| > | 10 > 6 | true |
| >= | 4 >= 6 | false |
| >= | 10 >= 6 | true |

We can also test the above results by storing the input values in a variables and then applying comparison operators one by one.

Philosophically, true and false are the only two perfect answers in this world. While developing logic based on these perfect answers in a program we are required to do decision making. Specially, this feature allows flexibility in handling various different logical conditions in a program.
