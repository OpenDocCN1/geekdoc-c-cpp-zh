Col = 1, 2, 3... 9

Col = 1, 2, 3... (10 -1)

Col = 1, 2, 3... (2*5 - 1)

Col = 1, 2, 3... (2* totalRows -1)

Hence we expressed upper_limit of col variable as (2* totalRows -1) in a generalised form.
