UPWARD GROWING STACK

```
#include <stdio.h>
// function prototype
void swap(int, int );
int main() {
    // local variables:
    firstNum, secondNum
    int firstNum = 9;
    int secondNum = 10;
    // actual arguments:
    // firstNum, secondNum
    swap( firstNum, secondNum );
    return 0;
}
```

```
void swap(int firstNo, int secondNo) {
    // local variable: emptyVar
    int emptyVar = 0 ;
    emptyVar = firstNo;
    firstNo = secondNo;
    secondNo = emptyVar;
}
```

When swap() method's execution gets completed, the stack-frame of swap() method will pop-out or get removed from the stack memory area.

Finally, when main() method's execution gets completed, the stack-frame of main() method will also pop-out or get removed from the stack memory area. Now, stack memory will have no stack-frames available for their execution. The stack memory area is emptied and ready to reuse for next program's execution.
