From the previous solution, we already had that generalised condition for printing spaces and using that generalised condition we can put all in the following table.

| Row level Repetitive Action |
| Variable : row | Column level Repetitive Action |
| | Variable : col |
| | Printing space character(s) | Printing star character(s) |
| | min_val | max_val | | min_val | max_val |
| | | default | 1 | | |
| 1 | 1 | 4 | totalRows -row | 5 | 5 |
| 2 | 1 | 3 | totalRows -row | 4 | 5 |
| 3 | 1 | 2 | totalRows -row | 3 | 5 |
| 4 | 1 | 1 | totalRows -row | 2 | 5 |
| 5 | 0 | 0 | totalRows -row | 1 | 5 |

The Column level for-loop runs between the col variable's value 1 to 5.

The condition (totalRows - row ) gives the maximum limit starting from 1 to which it will print space character(s).

So, we can easily use if-else statement for our situation for filtering and printing the space and star characters.
