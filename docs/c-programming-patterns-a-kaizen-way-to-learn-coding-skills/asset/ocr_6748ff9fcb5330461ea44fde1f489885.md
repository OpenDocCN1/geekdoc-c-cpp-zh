We can eliminate the logical AND(&&) condition( col <= (2 * totalRows - row) ) in the if-condition. This logical AND(&&) condition already been taken care as the loop-condition in the column level inner for-loop.

So the if-condition will now reduce to If ( col >= row ).We can summarise it all as;

| Prints a star when condition is True for every value of variable col |  |  |  |  |  |
|---|---|---|---|---|---|
| col=1 | col=2 | col=3 | col=4 | ....................................... | col= (2 * totalRows - row) |
| **If ( condition=( col >= row ) is True)**<br><br>**Print star character**<br><br>**Else**<br><br>**Print space character** |  |  |  |  |  |

We generalised the non-repeating numeric pattern of the column max_val into an expressions.

We can now define column level *for-loop*.

| *Elements of Column level for-loop* |  |
|---|---|
| min_val | 1 |
| max_val | (2 * totalRows - row) |
| variable_name | col |
| statement(s) | `printf("*n");` |
