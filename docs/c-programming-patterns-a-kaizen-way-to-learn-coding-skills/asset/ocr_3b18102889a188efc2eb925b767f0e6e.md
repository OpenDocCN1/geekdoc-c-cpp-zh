# *Alternative solution3*

We have to have to use remaining variables row & **totalRows=5** to find the generalised expression for the column **max_val**.

The following table is the one that we already got from the **trace table** in the very beginning.

| Column level Repetitive Action |
|---| 
| Variable : row | loop-condition( Variable : col ) |
| | min_val | max_val |
| | | default |
| 1 | 1 | 5 |
| 2 | 1 | 4 |
| 3 | 1 | 3 |
| 4 | 1 | 2 |
| 5 | 1 | 1 |

If we observe the numeric pattern for row **[1, 2, 3, 4, and 5]** is **reverse** of the numeric pattern of the column **max_val** **[5, 4, 3, 2, and 1]**.

If we just reverse the counter of row variable it will match exactly the values of the column **max_val** **[5, 4, 3, 2, and 1]**.It simply means instead of using the **incrementing for-loop** for the row variable we need to replace it with the **decrementing for-loop** for the row variable.

Reversing the flow of values for the variable row. It can be given as follows:

| Column level Repetitive Action |
|---| 
| Variable : row | loop-condition( Variable : col ) |
| | min_val | max_val |
| | | default |
| 5 | 1 | 5 |
| 4 | 1 | 4 |
| 3 | 1 | 3 |
| 2 | 1 | 2 |
| 1 | 1 | 1 |

| Column level Repetitive Action |
|---| 
| Variable : row | loop-condition( Variable : col ) |
| | min_val | max_val |
| | | default |
| 5 | 1 | row |
| 4 | 1 | row |
| 3 | 1 | row |
| 2 | 1 | row |
| 1 | 1 | row |

Now numeric pattern of variable row and column **max_val** matches exactly.

So, **max_val** can be expressed in variable row.

So, **max_val** is consistent for every value of **row**. Now, we are in good position to go for the *for-loop* since *for-loop* requires **one minimum** and **one maximum value or an expression**.
