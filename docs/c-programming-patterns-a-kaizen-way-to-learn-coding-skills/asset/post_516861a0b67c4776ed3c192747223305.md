
The following are the two versions of column level for-loop printing star ("*") character(s).

**Column level for-loop_1** for printing star characters // *inner* for-loop

**Column level for-loop_2** for printing star characters // *inner* for-loop

We can summarise it as:

| Prints a star for every value of variable row |
| --- |
| row = 1 |
| row = 2 |
| row = 3 |
| row = 4 |
| row = totalRows |
| .............. |
| row = (2 * totalRows - 1) |

```text
If condition (col <= totalRows) is True
    Print star character using Column level for-loop_1
Else
    Print star character using Column level for-loop_2
```

Flowchart: Diamond `col <= totalRows` — branch `True` → oval `Print star character using for-loop_1`; branch `False` → oval `Print star character using for-loop_2`

We can now define these two column level for-loops.

### Elements of Column level for-loop_1

| Element | Value |
| --- | --- |
| min_val | 1 |
| max_val | totalRows |
| variable_name | col |
| statement(s) | `printf("*");` |

### Elements of Column level for-loop_2

| Element | Value |
| --- | --- |
| min_val | 1 |
| max_val | 2 * totalRows - row |
| variable_name | col |
| statement(s) | `printf("*");` |

We have assigned a unique value to each row starting from 1 to 9. We can represent value 9 as (2 * 5 - 1). The variable **totalRows** is initially assigned the value 5.

So, we can generalise the maximum limit of the **row** variable using the variable. Let's consider:

**row** → variable of type *integer*, stores one integer value at a time, and represents the row number between 1 and (2 * **totalRows** - 1).

We have logically divided row level repetition *for-loop* into two parts due to two different versions of the *column level for-loop*.

### Elements of Row Level Repetitive for-loop (rows 1 to totalRows)

| Element | Value |
| --- | --- |
| min_val | 1 |
| max_val | totalRows |
| variable_name | row |
| statement(s) | Column level for-loop_1 for printing star characters<br>`printf("\n");` // Move cursor to the next row |

### Elements of Row Level Repetitive for-loop (rows totalRows + 1 to 2 * totalRows - 1)

| Element | Value |
| --- | --- |
| min_val | totalRows + 1 |
| max_val | 2 * totalRows - 1 |
| variable_name | row |
| statement(s) | Column level for-loop_2 for printing star characters<br>`printf("\n");` // Move cursor to the next row |

Since we got all the details related to the considered for-loops, we can summarise this related information with the help of a flowchart.

Let's execute the following program.

## PatternG1.c

```c
#include <stdio.h>
int main() {

    int totalRows = 5; // number of rows to display

    for (int row = 1; row <= (2 * totalRows - 1); row++) {

        if (row <= totalRows) {
            for (int col = 1; col <= row; col++) {
                printf("* ");
            }
        } else {
            for (int col = 1; col <= (2 * totalRows - row); col++) {
                printf("* ");
            }
        }
        printf("\n");
    }
    return 0;
}
```

The *inner for-loop 1* and *inner for-loop 2* differ only in the maximum limit value of the **col** variable.

It will be better if we capture the maximum limit of the **col** variable in a different variable.

Then we will be in a position to use only one inner for-loop for the complete column level repetition.

Let's update the previous program using a single inner for-loop.

## PatternG2.c

```c
#include <stdio.h>
int main() {
    int totalRows = 5; // number of rows to display
    int colMax = 0; // defines the maximum limit for col variable.

    // Row level Repetitive Action :
    // Action1. Executes Column level Repetitive Action
    // Action2. Move cursor to next row.
    for (int row = 1; row <= (2 * totalRows - 1); row++) {
        // sets the maximum limit of the inner for-loop
        if (row <= totalRows) {
            colMax = row;
        } else {
            colMax = (2 * totalRows - row);
        }

        // Column level Repetitive Action :
        // Action1. Move cursor in the same row
        // Action2. prints star "*" character
        for (int col = 1; col <= colMax; col++) {
            printf("* ");
        } // inner for-loop
        printf("\n"); // Move cursor to next row.
    } // outer for-loop

    return 0;
}
```

## Output

```text
*
* *
* * *
* * * *
* * * * *
* * * *
* * *
* *
*
```

We can express the column max_val of the col variable in terms of the row variable, and part of the expression follows a multiple of 2, but only for row values greater than 5 or totalRows.

There is a condition for when to increment the multiple of 2 or not. This condition is handled by conditional statements, mostly by an if-statement, if-else-statement, or if-elseif-else. This needs to be handled using such a conditional statement by declaring another integer variable, for example:

```c
int count; // counter to increment the multiple of 2.
```

We can use an if-statement something like the following, incrementing the value of the count variable when the row value crosses the totalRows value, which is 5, the initial total number of rows.

```c
if (row > totalRows) {
    count = count + 1; // Increment the count value by 1.
}
```

Now we can use variable **count** to generalise the column **max_val** of the **col** variable.

Also, we could try to express the maximum value of the **row** variable in terms of **totalRows**, which is as:

row = 1, 2, 3, ..., 9 or 1, 2, 3, ..., (10 - 1) or 1, 2, 3, ..., (2*5 - 1) or 1, 2, 3, ..., (2 * **totalRows** - 1)

Let's implement these observations as a different program.

## PatternG3.C

```c
#include <stdio.h>
int main() {

    int totalRows = 5; // number of rows to display
    int count = 0; // counter to increment the multiple of 2.

    // Row level Repetitive Action :
    // Action1: Executes Column level Repetitive Action
    // Action2: Move cursor to next row.
    for (int row = 1; row <= (2 * totalRows - 1); row++) {
        // increment count only when row value is greater
        // than the total number of rows.
        if (row > totalRows) {
            count = count + 1;
        }

        // Column level Repetitive Action :

        // Action1: Move cursor in the same row
        // Action2: Prints star "*" character
        for (int col = 1; col <= row - 2*count; col++) {
            printf("* ");
        } // inner for-loop

        printf("\n"); // Move cursor to next row.
    } // outer for-loop

    return 0;
}
```
