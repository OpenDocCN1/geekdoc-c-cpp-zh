If we build our programming logic giving conditions around set1 of printing numbers and printing spaces, then in the last else-part will take of set2 of printing numbers.

By putting a condition we need to switch the expression of **lower_limit** or **upper_limit** depends upon the value of row variable.

### Print numbers(set 1)

```text
lower_limit variable : lw_lt_num

if(row == 0){
    lw_lt_num = ( totalRows - 1 )
}else{
    lw_lt_num = ( totalRows - row )
}
```
