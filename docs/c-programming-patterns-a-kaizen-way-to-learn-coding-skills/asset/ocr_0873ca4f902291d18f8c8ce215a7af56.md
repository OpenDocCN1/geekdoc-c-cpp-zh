So, we can safely neglect lower_limit in the if-condition as it is already been taken care by it's own for-loop's starting value. Hence, our final if-condition will be,

| If-condition | lower_limit <=col<= upper_limit |
|---|---|
| **Mathematical expression** | col <= ((totalRows +1) – row ) |
| Syntax | col <= ( totalRows + 1 - row ) |

If we need to print something after some space(s), then in that case putting program logic to print space(s) make some sense. The other way round will not be a sensible exercise.

#include <stdio.h>
int main() {

    int  totalRows = 5;  //number of rows to display

    for( int row = 1; row <= totalRows ; row ++ ) {

        // numbers to be printed before printing spaces
        for(int col = 1; col <= totalRows   ; col++) {

            int upper_limit = ( totalRows + 1 - row );

            if( col >= 1 &&  col <= upper_limit ) {
                printf( "%d " , upper_limit );
            }else {
                printf( "  " );
            }
        }//inner loop

        printf("\n");// moves control to the next line
    }// outer loop

    return 0;

}
