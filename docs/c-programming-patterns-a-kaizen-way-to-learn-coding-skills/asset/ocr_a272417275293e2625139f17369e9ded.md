void swap(int firstNo, int secondNo) {

    printf("firstNo = %d | secondNo = %d \n", firstNo, secondNo );

# *Points to Remember*

+   - Local variables can easily transfer or manipulate data among themselves within their individual method's stack frame.

The method swap() exchanges the data between it's first method parameter and it's second method parameter. It is shown in the output of program which is as follows;

```
Start swap() : firstNo = 9 | secondNo = 10

End  swap() : firstNo = 10 | secondNo = 9
```

![](bbox=[0.35, 0.98, 0.65, 0.0010500000000000002])

+   - Local variables of a particular method has scope/visibility limited to their individual method's stack frame only. The local variables(firstNum, secondNum) of main() method are completely unknown to swap() method's stack frame. Similarly, the local variables(firstNo, secondNo) of swap() method are completely unknown to main() method's stack frame. The swap() method is called by the main() method. The actual parameters as a data are passed in the swap() method call. This means that the data of actual parameters(firstNum, secondNum) are get copied to the equivalent individual formal parameters(firstNo, secondNo).
