
## CallByReference.c

```c
#include <stdio.h>

// function prototype
void swap(int*, int*);

int main() {
    // local variables: firstNum, secondNum
    int firstNum = 9;
    int secondNum = 10;

    printf("*** Before swap() method call ***\n");
    printf("[firstNum = %d | secondNum = %d ]\n", firstNum, secondNum );
    printf("------------------------------------------------\n");
    // memory address value of local variables are passed.
    swap( &firstNum, &secondNum );

    printf("------------------------------------------------\n");
    printf("*** After swap() method call ***\n");
    printf("[firstNum = %d | secondNum = %d ]", firstNum, secondNum );
    return 0;
}

// formal parameters : firstNo and secondNo
void swap(int* firstNo, int* secondNo) {
    printf("Start swap() : ");
    printf("firstNo = %d | secondNo = %d \n", *firstNo, *secondNo );
    // local variable: emptyVar
    int emptyVar = 0 ;
    emptyVar = *firstNo;
    *firstNo = *secondNo;
    *secondNo = emptyVar;
    printf("End   swap() : ");
    printf("firstNo = %d | secondNo = %d \n", *firstNo, *secondNo );
}
```

### Output

```text
*** Before swap() method call ***
[firstNum = 9 | secondNum = 10 ]

------------------------------------------------

Start swap() : firstNo = 9 | secondNo = 10

End  swap() : firstNo = 10 | secondNo = 9

------------------------------------------------

*** After swap() method call ***
[firstNum = 10 | secondNum = 9]
```

## Points to Remember

- Pointer variables can easily manipulate data directly, just by knowing address of a particular variable and so method's stack frame will not be any dependencies. The method `swap()` exchanges data between its first method parameter and its second method parameter using pointer variables. The output of program is as follows;

  ```text
  Start swap() : firstNo = 9 | secondNo = 10

  End swap() : firstNo = 10 | secondNo = 9
  ```

- The actual parameters are passed this time in the `swap()` method call is as a memory address location. This means that the memory address values of actual parameters(&firstNum, &secondNum) are get stored into the equivalent individual formal pointer variable parameters(int* firstNo, int* secondNo). Moreover, the data type of pointer variables(int* firstNo, int* secondNo) of `swap()` method are compatible with (firstNum, secondNum), the data type of `main()` method's local variables. *The data type compatibility is unavoidable constraint when a memory address of a particular variable is assigned to the particular pointer variable.*
- The pointer variables(int* firstNo, int* secondNo) exchanged the data within the `swap()` method by using temporary variable. The pointer variable can update another variable's content by accessing that variable's memory location. This way pointer variables(int* firstNo, int* secondNo) of `swap()` method made a direct impact on the values of local variables(firstNum, secondNum) which belong to the `main()` method. This can be confirmed by observing the specific part of output of this program which is as follows;

  ```text
  *** Before swap() method call ***
  [firstNum = 9 | secondNum = 10 ]

  *** After swap() method call ***
  [firstNum = 9 | secondNum = 10]
  ```

## Conclusions:

- The address operator ampersand (&) is a must to determine address of a variable which can have basic data-type like ( int, float, long). So the pointer variable which is made to point the memory address of another variable must have the same data type.
- Use asterisk(*) indirection operator to get the value stored in the particular memory location pointed to by a specific pointer variable.
- The memory address of an array data-type is the memory address of a first element in an array.
- The memory address of an array can be determined by its name and which is same as the memory address of a 1st element in an array.

Let's verify these facts by implementing an example.

## PointerAddressValues.c

```c
#include <stdio.h>
int main() {
    int *intPtr = NULL;// pointer variable of type int.
    int intVal = 10;
    int intArr[5] = { 10, 20, 30, 40, 50 };

    // address operator & is a must for a pointer
    // to point to basic data-type.
    intPtr = &intVal; // assign intVal's address to intPtr.
    printf(" Address of &intVal = %p \n", &intVal );
    printf(" Address of intPtr = %p \n", intPtr );
    printf(" Address of *intPtr = %d | intVal = %d\n\n", *intPtr, intVal );

    printf(" Address of &intArr  = %p \n", &intArr );
    printf(" Address of intArr[0] = %p \n", &intArr[0] );
    printf(" Address of intArr   = %p \n", intArr );

    // Variable's name of array data-type for a pointer
    // to point to array data-type.
    intPtr = intArr;
    printf(" Address of intPtr after pointing to array  = %p \n", intPtr );

    return 0;
}
```

### Output

```text
Address of &intVal = 0061FF28
Address of intPtr = 0061FF28
Address of *intPtr = 10 | intVal = 10

Address of &intArr = 0061FF14
Address of intArr[0] = 0061FF14
Address of intArr   = 0061FF14
Address of intPtr after pointing to array  = 0061FF14
```

## Accessing array elements using pointers

*Array is treated as a pointer to its first element* in memory. Hence, we can use pointer to access elements of an array. The pointer and the array should be of same data-type. The following program is a re-implementation of the program WithLooping.c using pointer variables.

## PointerInLooping.c

```c
#include <stdio.h>

int main() {
    // array initialization
    char name[20] = "Mr.Always Right";
    int ages[5] = { 10, 20, 30, 40, 50};
    float weight[5] = {23.27, 32.14, 37.45, 60.74, 47.25};
    long distance[5] = {1234567L, 4335454L, 98767567L, 4354321L,555588889L};
    int size = -1;// size of an array

    // pointer declarations
    char *charPtr;
    int *intPtr;
    float *floatPtr;
    long *longPtr;

    printf(" Accessing char array element using char pointer.\n");

    // assigns the starting address of char array to the char pointer.
    charPtr = name ;

    for( int index = 0 ; name[index] != '\0'; index ++){
        // using asterisk(*) indirection operator to print the array's element.
        printf(" %c |", *charPtr);
        charPtr ++ ;
    }

    printf("\n Accessing int array element using int pointer.\n");

    // assigns the starting address of int array to the int pointer.
    intPtr = ages;

    // finding size of array using C language's sizeof() operator.
    size = sizeof( ages ) / sizeof( int );

    for( int index = 0 ; index < size ; index++){
        // using asterisk(*) indirection operator to print the array's element.
        printf(" %d | ", *intPtr);
        intPtr ++ ;
    }

    printf("\n Accessing float array element using float pointer.\n");

    // assigns the starting address of float array to the float pointer.
    floatPtr = weight;

    // finding size of array using C language's sizeof() operator.
    size = sizeof( weight )/ sizeof( float );

    for( int index = 0 ; index < size ; index++){

        // using asterisk(*) indirection operator to print the array's element.
        // total 5 digits to print float number and 2 digits after decimal point.

        printf( "%5.2f | ", *floatPtr);
        floatPtr ++ ;
    }

    printf("\n Accessing long array element using long pointer.\n");

    // assigns the starting address of long array to the long pointer.
    longPtr = distance;

    // finding size of array using C language's sizeof() operator.
    size = sizeof( distance )/ sizeof( long );

    for( int index = 0 ; index < size ; index++){

        // using asterisk(*) indirection operator to print the array's element.
        // print long digit number.
        printf( "%ld | ", *longPtr);
        longPtr ++ ;
    }
    return 0;
}
```

### Output

```text
Accessing char array element using char pointer.
M | r | . | A | l | w | a | y | s |  | R | i | g | h | t |

Accessing int array element using int pointer.
10 | 20 | 30 | 40 | 50 |

Accessing float array element using float pointer.
23.27 | 32.14 | 37.45 | 60.74 | 47.25 |

Accessing long array element using long pointer.
1234567 | 4335454 | 98767567 | 4354321 | 555588889 |
```
