# COLUMN LEVEL REPETITIVE ACTION

Let’s consider two attributes rows and columns of a 2-dimensional pattern as variables;

**row** → variable _type of integer_ to store integer value one at a time and represents row number between 1 and 5.

**col** → variable _type of integer_ to store integer value one at a time and represents column number between 1 and 5.

**totalRows** → variable _type of integer_ to store integer value for total number of rows.
