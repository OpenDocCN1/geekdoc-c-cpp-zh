ProblemSPG1: In the program StringPatternG1.c, the star “*” characters are printed quite closed to each other. In order to get better formatted output suppose an extra space is added as shown in the following program by arrow mark, the output doesn’t came as per our expectation.

What modifications in the following program should be applied so that we should able to get the expected output.

# StringPatternG1.c

```
#include <stdio.h>
int main() {
    int totalRows = 5; // number of rows to display
    int index = -1; // array's index to be incremented by 1.
    char line[44]={""}; // initialize with blank string.

    for( int row = 1; row <= ( 2 * totalRows - 1 ); row++ ) {
        // Column level Repetitive Action :
        // expanding array by filling it up using '*' char.
        if ( row <= totalRows ) {
            line[++index] = '*';
            // Extra space added so to get better formatted output.
            line[++index] = ' ';
        } else {
            // replacing '*' char from the end of the array by space.
            // decrement index only when row > totalRows
            line[index--] = ' ';
        }
        // Print string and move cursor to the next row
        printf("%s\n",line);
    }
    return 0;
}
```
