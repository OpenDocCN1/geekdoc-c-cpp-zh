Let's consider following variables which are type of integer to store integer value one at a time.

- totalRows → variable type of integer to store integer value for total number of rows.

## Approach to solution

The variables are row & totalRows=5. We need to generalise the non-repeating numeric pattern of the column max_val using these remaining variables.

The numeric pattern (1 to 5) of the column max_val matches exactly every value of <u>row</u>. Hence, it can be expressed in row variable.

The numeric pattern of the column max_val of variable col matches exactly values (1 to 5) of row.

So that specific part of the numeric pattern can be expressed in row variable.

The condition (col >= 1) gives a starting point from which it will start printing star("*") character(s) till the value of variable row reaches (totalRows).

The variable col then starts decreasing, which is captured in the expression (2*totalRows − row).

So in this case, there is not one but two generalised expressions for values of the variable col. This indicates that we need to use two separate for-loops for the variable col.
