The values of formal parameters (**firstNo**, **secondNo**) which got exchanged within the **swap()** method call by using temporary variable, has no impact on the local variables(**firstNum**, **secondNum**) of the **main()** method. This can be confirmed by observing the specific part of output of this program which is as follows;

*** Before swap() method call ***
[firstNum = 9 | secondNum = 10 ]

*** After swap() method call ***
[firstNum = 9 | secondNum = 10]

# Conclusion:

*One method's stack frame is completely blind about local variables which are present on another method's stack frame.*
