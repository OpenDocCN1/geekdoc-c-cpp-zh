## Logical Operators

It also returns either *true* or *false* value like in the case of any comparison operator expression. We can combine many more such expressions which could be based on comparison operators. If there are many more conditions to be considered we usually use logical operators. Usage of these operators is quite common and plays a very important role in writing programs. Every programmer must have very much clear idea about usage of these operators. It will be worth if any new learner spent some extra time experimenting with these operators. Following are the different types of logical operators.

| Operator | Logical Operation Description |
|---|---|
| `&&` | Logical AND |
| `||` | Logical OR |
| `!` | Logical NOT |

### Logical AND
Returns **true** only in a case when **compulsory both A and B are true** else false. More we add AND condition using `&&` operator in a logical expression, less the size of data we get out of total data. It usually applied in a situation to get specific data or data of lesser range or size.

| A | B | A&&B |
|---|---|---|
| ***true*** | ***true*** | ***true*** |
| true | false | false |
| false | true | false |
| false | false | false |

### Logical OR
Returns **false** only in a case when **compulsory both A and B are false** else true. More we add OR condition using `||` operator in a logical expression, more it increases the size of data as a output result. So it is used to get broader range of data.

| A | B | A || B |
|---|---|---|
| true | true | true |
| true | false | true |
| false | true | true |
| ***false*** | ***false*** | ***false*** |

A and B are usually true/false value or comparison operator based expression(s) which either returns result in true or false value. This is shown with the following example.

### Logical NOT
Return true when A is false or just opposite, returns false when it is true.

| A | !A | Please note that true/false values are also known as boolean values or truth values. |
|---|---|---|
| true | false | |
| false | true | |

Let, there are two variables, a = 10 and b = 5. Please observe the column “Result”.

| Logical operator | Expression | Result |
|---|---|---|
| && | (a > 7) && (b < 7) | (true) && (true) is true |
| || | (a > 7) || (b < 3) | (true) || (false) is true |
| ! | !(a == b) | !(false) is true |

## Art of Applying Logical Conditions

Logical conditions are the defence mechanism of working features of any software application. Most of the bugs/errors which occurred are due to the improper handling of logical condition(s). It mostly consists of logical or comparison operators. One of the most important element of programming logic is to apply logical conditions. It controls the flow of program similarly like how road traffic control system works. Road traffic control system logically distributes the crowd by conditionally allows or stops the portion of the crowd directing towards a particular road. Similarly, logical conditions in a program allow only certain set of programming statements to be get executed.

If that road side traffic control system doesn't work accordingly, then instead of maintain peaceful driving it may create traffic jams and road accidents. Similarly, wrong logical conditions gives unpredictable results if gone unnoticed.

Logical conditions are similar like road signs. Those road signs are got some meaning. They are been used based on some specific purpose and directly influences the traffic. In a similar way we will try to understand how logical conditions influences the output of the program which will help to improve our logical thinking capabilities.

We will use a simple version of scratch pad to verify our logical conditions manually. It may remind you of cross-words puzzle box. Let us take similar kind of box consists of 8 rows and 8 columns. For representing rows and columns we can take two variables named as row and col respectively.

Variable row → denotes values of row=1, 2,3,4,5,6,7,8.

Variable col → denotes values of col=1, 2,3,4,5,6,7,8.

Each one box is recognised by (row, col) value pair. So value pair (1, 1) means 1st row and 1st column.

### Rule of the game
Wherever logical condition matches, need to put character * in a small box.

All (row, col) value pairs represent the total information or data. It has 8 rows and 8 columns which makes total 64 (row, col) value pairs. So, when logical conditions are mapped into this box we will select correct (row, col) value pairs from the total available 64(row, col) value pairs. Applying different logical conditions means manually selecting (row, col) value pairs matching each logical condition. This type of very simple observation based exercises will help us to understand how logical condition works at the very core level.

We can practice to write logical conditions manually first using simple picture based exercises like alphabets of very simple structure.

Yes, of course we can verify all these logical conditions by writing programs also which will be our next level of learning. For your information, each logical condition can be verified easily by writing program using **nested loops**. Working with nested loops will be our next major step in learning. It will force us to think what could be the possible accurate logical condition.

Since it's based on simple maths and common sense, so verifying manually these logical conditions won't be difficult.
