# Exercise 2.3. Printing “Word:” in every line and use of “\n” (single line break character).

# PrintInEveryLine3.c

```
```c
#include <stdio.h>

int main() {

    printf("Word:\n");
    printf("Word:\n");
    printf("Word: ");
    return 0;
}
```
```

# Output

```
```text
Word:
Word:
Word:
```
```

# Exercise 2.4. Printing “Word:” in every line and in different ways.

# PrintInEveryLine4Ways.c

```
```c
#include <stdio.h>

int main() {
    //1st way to print to console
    printf("Word:\n");
    //2nd way to print to console
    printf("Word:");printf("\n");
    //3rd way to print to console
    printf("\n");printf("Word: ");
    //4th way to print to console
    printf("\nWord: ");
    return 0;
}
```
```

# Output

```
```text
Word:
Word:

Word:
Word:
```
