This pattern is a special case of NumberPatternFF and is about printing of alphabets instead of numbers. Every character what we see in keyboard whether it is alphabets, numbers or other special character has a unique code which is basically a number. So every character even the numbers also internally represented by a numeric value called Unicode. We can use in-built typecasting feature of C to get the alphabets from Unicode values. It is used to convert variable of one data-type to another. For example;

```
// typecasting - converting integer data-type to char data-type
int unicode = 65;
char alpahabet = (char)unicode;
```
