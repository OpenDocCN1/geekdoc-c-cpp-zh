#include <stdio.h>
int main() {
    int totalRows = 5; //number of rows to display
    int lw_lt_num, lw_lt_spaces, up_lt_spaces;
    int numSet1;
    int numSet2 = 0;

    // Row level Repetitive Action :
    for ( int row = 0; row < totalRows; row++ ) {
        // Column level Repetitive Action :
        for ( int col = 1; col <= ( 2 * totalRows - 1 ); col++ ) {
            // switching to lower_limit or upper_limit
            // logical expressions
            if ( row == 0 ) {
                lw_lt_num = ( totalRows - 1 );
                lw_lt_spaces = 0;
                up_lt_spaces = -1;
            } else {
                lw_lt_num = ( totalRows - row );
                lw_lt_spaces = ( totalRows - row + 1 );
                up_lt_spaces = ( totalRows + row - 1 );
            }

            if ( col <= lw_lt_num ) {
                numSet1 = col;
                printf( "%d ", numSet1 );
                // updating numSet2 when numSet1 reached
                // it's maximum value
                if ( col == lw_lt_num ) {
                    numSet2 = numSet1;
                }
            } else if ( col >= lw_lt_spaces &&
                col <= up_lt_spaces ) {
                printf( " " );// 2 spaces
            } else {
                // first row where no space is required to print.
                if ( row == 0 &&
                    col == totalRows ) {
                    numSet2 = totalRows;
                }
                printf( "%d ", numSet2 );
                numSet2 = numSet2 - 1;
            }
        }// inner loop

        printf( "\n" );// Move cursor to the next row
    }// outer loop

    return 0;
}

## If-else Shortcut

Short-cut in any matter is a special case to be applied in a specific situation. Not only in subject of programming people unknowingly confuse themselves simply by the fact that they choose a special case and tried to apply it commonly. Even in choice of words, two words may give almost similar meaning and when we actually apply those in different situations then only we will be in a position to explore it’s true potential meaning.

The shortcut to if-else option is there in almost every programming language which is also known as **ternary operator** and is given by the symbol (:).

## When to apply if-else shortcut

The ternary operator is a sort of syntactic sugar for if-else statements usually applied in a situation where both **if-block** and **else-block** assign different value to the same result variable. For example, let’s suppose that if-else statement is something like the following:

| If-else statement | If-else shortcut or ternary operator (:) |
|---|---|
| `If( condition){`<br>&nbsp;&nbsp;&nbsp;&nbsp;`result = one_value;`<br>`}else{`<br>&nbsp;&nbsp;&nbsp;&nbsp;`result = other_value;`<br>`}` | `result = (condition)? one_value : other_value ;` |
| Simple if-else can be easily replaced by the use of **if-else shortcut** represented by the one liner **ternary operator**. In such situations only it makes true sense to use ternary operator to increase code readability. | • Two outcome result values are possible which are separated by a symbol colon (:).<br>• If **condition** is **true**, then *one_value* will get assigned to the variable result.<br>• If **condition** is **false**, then *one_value* will get assigned to the variable result. |

In the program **NumberPatternFF.c** we can use ternary operator to improve that part of source code readability.

| Separate if-else |
|---| 
| if(row == 0){\n  lw_lt_num = ( totalRows - 1 );\n}else{\n  lw_lt_num = ( totalRows - row );\n} |
| if(row == 0){\n  lw_lt_spaces = 0;\n}else{\n  lw_lt_spaces = ( totalRows - row + 1 );\n} |
| if(row == 0){\n  up_lt_spaces = -1;\n}else{\n  up_lt_spaces = (totalRows + row - 1 );\n} |
| Many If-else combined in single if-else |
| if(row == 0){\n  lw_lt_num = ( totalRows - 1 );\n  lw_lt_spaces = 0;\n  up_lt_spaces = -1;\n}else{\n  lw_lt_num = ( totalRows - row );\n  lw_lt_spaces = ( totalRows - row + 1 );\n  up_lt_spaces = ( totalRows + row - 1 );\n} |
| Equivalent If-else shortcut or ternary operator (?) expressions |
| lw_lt_num = (row == 0)? ( totalRows - 1 ) : ( totalRows - row ); |
| lw_lt_spaces = (row == 0)? 0 : ( totalRows - row + 1 ); |
| up_lt_spaces = (row == 0)? -1 : (totalRows + row - 1 ); |

In most of the cases it makes hard to read the conditions and associated evaluation expressions. In some cases, a proper formatting of nested ternary operators may help but still code implemented will not be very easy read for junior level programmers atleast.

In my opinion It is better to avoid nested ternary operators.
