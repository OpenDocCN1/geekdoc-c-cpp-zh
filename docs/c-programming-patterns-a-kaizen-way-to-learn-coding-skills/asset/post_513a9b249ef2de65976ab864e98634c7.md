
So it has two repetition processes: one for printing spaces and the second for printing numeric values.

It means we require 2 inner for-loops and 1 outer loop for iterating rows. The relation between row value and upper limit for inner for-loops for spaces and numbers.

The lower_limit for spaces & num variable has the same numeric value expression for all the rows.

It's consistent for all the rows. Likewise we need to come out with such a consistent expression for upper_limit for which it should suit any number of rows.

The other remaining variables are row & totalRows=5. Let's try to generalise using these variables.

| Row level Repetitive Action | Column level Repetitive Action: lower_limit <= col_sp <= upper_limit (lower_limit) | Column level Repetitive Action: lower_limit <= col_sp <= upper_limit (upper_limit) | Column level Repetitive Action: lower_limit <= col_sp <= upper_limit (default) | Column level Repetitive Action: lower_limit <= col_num <= upper_limit (lower_limit) | Column level Repetitive Action: lower_limit <= col_num <= upper_limit (upper_limit) | Expected Output |

Now the upper_limit of col_sp variable related inner for-loop is generalised, same expression on all the rows. The lower_limit of col_num variable related inner for-loop is not generalised as not having same expression on all the rows.

Since the lower_limit of col_num variable values matches with row variable values. So, we can use row variable to make it consistent given as follows.

| Row level Repetitive Action | Column level Repetitive Action: lower_limit <= col_sp <= upper_limit (lower_limit) | Column level Repetitive Action: lower_limit <= col_sp <= upper_limit (upper_limit) | Column level Repetitive Action: lower_limit <= col_sp <= upper_limit (default) | Column level Repetitive Action: lower_limit <= col_num <= upper_limit (lower_limit) | Column level Repetitive Action: lower_limit <= col_num <= upper_limit (upper_limit) | Column level Repetitive Action: lower_limit <= col_num <= upper_limit (default) |

The lower_limit of col_sp variable is the same for all the rows. The upper_limit of col_num variable is the same for all the rows. It means the upper_limit of col_sp & col_num variables are generalised for any number of rows. So our inner for-loop condition for printing space characters becomes;

| loop-condition | lower_limit <= col_sp <= upper_limit |
|---|---|
| **Mathematical expression** | 1 <= col_sp <= (totalRows - row) |
| **Syntax** | `for( col_sp = 1; col_sp <= (totalRows - row); col_sp++ )` |

So our inner for-loop condition for printing numeric characters becomes;

| loop-condition | lower_limit <= col_num <= upper_limit |
|---|---|
| **Mathematical expression** | 1 <= col_num <= row |
| **Syntax** | `for( col_num=1; col_num <= row ; col_num ++ )` |

### NumberPattern1D.c

```c
#include <stdio.h>
int main() {

    int  totalRows = 5;  //number of rows to display

    for( int row = totalRows ; row >=1 ; row -- ) {

        // spaces to be printed
        for( int col = 1; col <= ( totalRows - row ); col++ ) {
            printf("  ");
        }

        // row value to be printed
        for( int num=1; num<= row ; num++ ){
            printf("%d ", row);
        }// inner for-loop

        printf("\n");// moves control to the next line
    }// outer for-loop
    return 0;
}
```
