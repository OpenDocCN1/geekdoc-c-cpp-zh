# Learning logic building skills by guessing – A tedious strategy

The usual and common way to learn programming is just by randomly experimenting with it. This takes much more time to learn programming as it required hell lot of practice. No doubt it has advantages especially if we want to explore the api/in-built libraries or features of a programming language. This particular style of learning, by guessing logic of a program may act as a killer of interest in the programming subject itself for beginners. This way it takes more time to learn programming and for some percentage of people it is an interesting way. **Everyone can't make a good guess in every subject area and there is no such specific way of guessing that anybody can utilize it as a standard practice.** With this guessing strategy to learn programming, will actually add more difficulties to a person who couldn't able to make a good guess or even awkward guessing. Whenever the imagination regarding programming doesn't flow, the person's mind just goes blank. So It should not be a surprise if that person is good or smart in other activities and may lack in patience or find programming very hard to learn. This is not in question about programming as a subject, it could happen with any type of learning. The ground reality is that if imagination and thought process doesn't flow for a person who trying to learn something, it just doesn't go into the head.

Learning to program by guessing is a switch off to many beginners. Since it doesn't reflect any standard way of learning. Instead, I liked to introduce a systematic approach to learn programming based on simple maths and common sense. That approach has dealt in depth at different levels of difficulties to properly learn programming logic and covered in the next section **programming patterns.**

In order to do programming in patterns the person has to know for-loop and applying logical condition well. Looping are the hardest. Nested loop challenges us to think logically in two different directions at the same time to output a pattern and any pattern is a 2-dimensional simple picture. These type of activities stimulates logical thinking. While learning programming if learner gets confusions or doubts, it is a good sign. It suggests that learner's thought process and imagination become active and platform is getting ready to acquire the skill of programming. It does happen many times that clearing one doubt opens the door for further knowledge in many different areas. So doubt basically works like a surprise knowledge capsule to be explored. A learner just needs to keep patience in order to try to resolve that specific doubt or confusion in a systematic way not by guessing. So whenever we get any doubt, we just need to think that we got one more chance to improve intelligence. Clearing doubts are just a part of an iterative way of refining our logical skills.

Obviously, learning will not last longer and productive if it is not supported by a systematic approach. A person who is somewhat good in developing programming logic usually struck lesser when required to deal with harder subjects of programming. This book is all about developing program's logical skills. It doesn't matter if someone is initially a big zero in it. The content in this book surely can help a person who is ready to make an honest attempt and will eventually become interested in programming. The exercises are designed in a way to naturally suit any new learner in increasing order of difficulty. Some exercises are specially included only for the purpose of giving surprise to the learner to think out of the box.

*Good programming logic is not just the basics, for programmers, it's the key to confidence.*
