# Points to Remember

+   - Pointer variables can easily manipulate data directly, just by knowing address of a particular variable and so method's stack frame will not be any dependencies. The method `swap()` exchanges data between it's first method parameter and it's second method parameter using pointer variables. The output of program is as follows;
+   
+   ```
+   Start swap() : firstNo = 9 | secondNo = 10
+   
+   End swap() : firstNo = 10 | secondNo = 9
+   ```
+   - The actual parameters are passed this time in the `swap()` method call is as a memory address location. This means that the memory address values of actual parameters(&firstNum, &secondNum) are get stored into the equivalent individual formal pointer variable parameters(int* firstNo, int* secondNo). Moreover, the data type of pointer variables(int* firstNo, int* secondNo) of `swap()` method are compatible with (firstNum, secondNum), the data type of `main()` method's local variables. *The data type compatibility is unavoidable constraint when a memory address of a particular variable is assigned to the particular pointer variable.*
+   - The pointer variables(int* firstNo, int* secondNo) exchanged the data within the `swap()` method by using temporary variable. The pointer variable can update another variable's content by accessing that variable's memory location. This way pointer variables(int* firstNo, int* secondNo) of `swap()` method made a direct impact on the values of local variables(firstNum, secondNum) which belong to the `main()` method. This can be confirmed by observing the specific part of output of this program which is as follows;
+   
+   ```
+   *** Before swap() method call ***
+   [firstNum = 9 | secondNum = 10 ]
+   
+   *** After swap() method call ***
+   [firstNum = 9 | secondNum = 10]
+   ```

# Conclusions:

+   - The address operator ampersand (&) is a must to determine address of a variable which can have basic data-type like ( int, float, long). So the pointer variable which is made to point the memory address of another variable must have the same data type.
+   - Use asterisk(*) indirection operator to get the value stored in the particular memory location pointed to by a specific pointer variable.
+   - The memory address of an array data-type is the memory address of a first element in an array.
+   - The memory address of an array can be determined by it's name and which is same as the memory address of a 1st element in an array.
