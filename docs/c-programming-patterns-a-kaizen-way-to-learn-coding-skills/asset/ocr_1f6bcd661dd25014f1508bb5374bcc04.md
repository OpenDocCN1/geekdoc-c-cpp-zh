On observing alphabet C and trying to fit into the box we can start putting * characters in the first row. So logical condition will be **row==1**.

Now we need to put * characters in the first column.

|  | col=1 | col=2 | col=3 | col=4 | col=5 |
|---|---|---|---|---|---|
| row=1 | 1,1* | 1,2* | 1,3* | 1,4* | 1,5* |
| row=2 | 2,1 | 2,2 | 2,3 | 2,4 | 2,5 |
| row=3 | 3,1 | 3,2 | 3,3 | 3,4 | 3,5 |
| row=4 | 4,1 | 4,2 | 4,3 | 4,4 | 4,5 |
| row=5 | 5,1 | 5,2 | 5,3 | 5,4 | 5,5 |
| row=6 | 6,1 | 6,2 | 6,3 | 6,4 | 6,5 |
| row=7 | 7,1 | 7,2 | 7,3 | 7,4 | 7,5 |

The equivalent logical condition for the first column will be (**col==1**) condition.

Using logical OR (||) conditional operator to combine logical conditions and it becomes
**(row==1)||(col==1)**
