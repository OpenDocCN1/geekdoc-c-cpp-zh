We know that a variable represents a memory location. The variables **row**, **col** and **totalRows** are local to the **main()** method. Whenever the program gets executing, it initialize these local variables and they are pushed into the **stack** memory area. These local variables which are on the **stack** are readily available to the machine code and are directly accessible. This machine code can't directly access the memory locations of a **heap** memory area. This short-coming can be overcome by using pointer variable which basically contains only one type of data and that is memory location. Pointer variable also resides in the stack memory area like other variables. The following programming instruction suggests that the pointer variable **intPtr** is not pointing to any memory location and a simple way to initialize any pointer variable before it's actual usage.

```
```c
int *intPtr = NULL; // pointer variable initialized to NULL.
```
