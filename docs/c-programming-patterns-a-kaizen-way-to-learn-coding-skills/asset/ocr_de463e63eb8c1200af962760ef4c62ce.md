This way we can represent particular logical condition by filling small boxes with * character.

|  | col=1 | col=2 | col=3 | col=4 | col=5 | col=6 | col=7 | col=8 |
|---|---|---|---|---|---|---|---|---|
| row=1 | 1,1* |  |  |  |  |  |  |  |
| row=2 |  | 2,2 * |  |  |  |  |  |  |
| row=3 |  |  | 3,3* |  |  |  |  |  |
| row=4 |  |  |  | 4,4* |  |  |  |  |
| row=5 |  |  |  |  | 5,5* |  |  |  |
| row=6 |  |  |  |  |  | 6,6* |  |  |
| row=7 |  |  |  |  |  |  | 7,7* |  |
| row=8 |  |  |  |  |  |  |  | 8,8* |

So the meaning of logical condition now took the visual form. The expression of logical condition get transformed into the simple picture drawn using * characters. This help us to understand how filtering/selection of data takes place using logical condition.
