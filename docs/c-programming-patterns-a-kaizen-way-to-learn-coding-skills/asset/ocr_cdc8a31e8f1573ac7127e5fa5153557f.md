# Approach to solution

We need to generalise the non-repeating numeric pattern of the column max_val using the available variables. We can use variable totalRows. Variable totalRows has been assigned the value 5 as the total number of rows.

| Column level Repetitive Action |
|---|
| Variable : row | loop-condition( Variable : col ) |
|  | min_val | max_val |
|  |  | default | 1 |
| 1 | 1 | 5 | totalRows |
| 2 | 1 | 4 | totalRows - 1 |
| 3 | 1 | 3 | totalRows - 2 |
| 4 | 1 | 2 | totalRows - 3 |
| 5 | 1 | 1 | totalRows - 4 |

Again non-repeating numeric values are there. We can express max_val 2nd time as follows.

| Column level Repetitive Action |
|---|
| Variable : row | loop-condition( Variable : col ) |
|  | min_val | max_val |
|  |  | default | 1 | 2 |
| 1 | 1 | 5 | totalRows | (totalRows +1) - 1 |
| 2 | 1 | 4 | totalRows -1 | (totalRows +1) - 2 |
| 3 | 1 | 3 | totalRows - 2 | (totalRows +1) - 3 |
| 4 | 1 | 2 | totalRows - 3 | (totalRows +1) - 4 |
| 5 | 1 | 1 | totalRows - 4 | (totalRows +1) - 5 |

Part of column max_val's expression followed the same numeric value pattern as row.

| Column level Repetitive Action |
|---|
| Variable : row | loop-condition( Variable : col ) |
|  | min_val | max_val |
|  |  | default | 1 | 2 | 3 |
| 1 | 1 | 5 | totalRows | (totalRows +1) - 1 | (totalRows +1) - row |
| 2 | 1 | 4 | totalRows -1 | (totalRows +1) - 2 | (totalRows +1) - row |
| 3 | 1 | 3 | totalRows - 2 | (totalRows +1) - 3 | (totalRows +1) - row |
| 4 | 1 | 2 | totalRows - 3 | (totalRows +1) - 4 | (totalRows +1) - row |
| 5 | 1 | 1 | totalRows - 4 | (totalRows +1) - 5 | (totalRows +1) - row |

Further we can express it in terms of totalRows & row variables.

Now, max_val has the same expression and it is consistent for every value of row.

We can now define column level for-loop which is for every row value.

| Elements of Column level for-loop |
|---|
| min_val | 1 |
| max_val | (totalRows +1) - row |
| variable_name | col |
| statement(s) | printf("%s"); |
