# Understanding the Concept of Pointers

The concept of pointers can be easily understood by using analogies. The method's stack frame is like a home. So, stack frames are very much like homes where family members of one home doesn't know anything about the family residing within another home, maintaining a complete secrecy with each other. Hence, the family members are like local variables.

# Analogies to understand the concepts: -

| Concept | Analogy |
|---|---|
| Method's stack frame | Home |
| Local variables are those variables which are available in their respective method's stack frame. | Family members (M1, M2, M3, M4).
**Suppose family members (M1, M2,M3,M4) are available in their home.** |
| These local variables holds data. | **On a very broader level, the information which each family member is holding regarding anything is similar to what data means to a variable.** |
| Local variables can transfer or manipulate data/information among each other. | Family members **can share information among each other.** |
| Every local variable has a **unique memory address location.** | Every family member has a **unique mobile number.** |
| We write programming instructions using local variables in order to achieve a well-defined targeted output. | They can help each other in order to complete a well-defined task. This overlaps with the intention with which any method or function is written. |

Let's suppose that one of the family member M4 is interested to talk to his/her friend whose is living at a distance far away from his/her place. One of the commonest way with which they can connect to each other is through mobile phones. The mobile number uniquely identifies a person and helps in connecting each other through mobile phones.

Every byte in a memory has a unique address value associated with it. So this makes sense that every variable declared has a unique memory address associated with it. This idea of uniqueness of memory address location matches with the idea of uniqueness of a mobile number. In this way, the concept of memory addresses resembles very much with the concept of mobile numbers. Consider an activity of taking an appointment of a doctor using a contact number remotely and meeting a doctor personally. In both the cases accessing a doctor differs. The doctor or medical staff has to maintain the state of each appointment The contact number or any other reference value like national identification number or unique appointment number can be used instead.
