ExerciseGB3.Printing row iteration and column iteration values as (row, col) as shown in the following output

(1,1) (1,2) (1,3) (1,4) (1,5)
(2,1) (2,2) (2,3) (2,4) (2,5)
(3,1) (3,2) (3,3) (3,4) (3,5)
(4,1) (4,2) (4,3) (4,4) (4,5)
(5,1) (5,2) (5,3) (5,4) (5,5)

# ForLoopCoordinateRepresentation.c

```
#include <stdio.h>

int main() {
    int TOTAL_ROWS = 5;
    int TOTAL_COLUMNS = 5;

    for( int row = 1 ; row <= TOTAL_ROWS ; row ++ ) {
        for( int col = 1 ; col <= TOTAL_COLUMNS ; col ++ ) {
            printf("(%%d,%%d) ", row, col);
        }

        // moves the control to the next line and
        // prints next row iteration value

        printf("\n");
        printf("\n");
    }

    return 0;
}
```
