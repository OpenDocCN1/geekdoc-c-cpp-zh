The *upper_limit* value is based on how many times the value repeated in a particular row.

The *lower_limit* of col variable has the same numeric value expression for every value of row. It’s consistent for all the values rows. Likewise we need to come out with such a consistent expression for upper_limit which should suit any number of rows using available variables. The variables are row & totalRows=5.

Moreover, the repeated values in column appears alternatively in row. It seems we can establish a relationship between appearing of 0 or 1 value with the row value.
