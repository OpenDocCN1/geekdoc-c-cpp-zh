The lower_limit of col variable has the same numeric value expression for every value of row. It's consistent for all the values rows.

Likewise we need to come out with such a consistent expression for upper_limit which should suit any number of rows.

The other remaining variables are row & totalRows=5. Let's try to generalise using these variables.

For all the rows, the row value prints exactly the number of times the upper_limit of col value.

| Column level Repetitive Action |
|---|---|---|---|
| row | lower_limit | upper_limit | |
|  |  | default | 1 |
| 1 | 1 | 1 | row |
| 2 | 1 | 2 | row |
| 3 | 1 | 3 | row |
| 4 | 1 | 4 | row |
| 5 | 1 | 5 | row |

So the upper_limit of col variable is generalised to row variable.

The lower_limit & upper_limit are consistent for all the rows. It's now generalised for any number of rows.

We can now define column level for-loop which is for every row value.

| Elements of Column level for-loop |
|---|---|
| min_val | 1 |
| max_val | row |
| variable_name | col |
| statement(s) | printf("%d ", row); |
