# Analysis of output

In general, three repetitive action takes place.

+   a) Printing of alphabets starting from A in incrementing order.
+   b) Printing of spaces
+   c) Printing of alphabets in decrementing order and it's upper limit will start from last updated incremented value.

So in an increment value order of Unicode we can get alphabets. We can verify this from following program which prints all 26 alphabets, capital or small along with Unicode.

| Capital Alphabets | Unicode | Small Alphabets | Unicode |
|---|---|---|---|
| A | 65 | a | 97 |
| B | 66 | b | 98 |
| ...... | ...... | .... | .... |
| Z | 90 | z | 122 |

# UniCodeToAlphabets.c

```
#include <stdio.h>
int main() {
    printf("Alphabets and it's equivalent unicode.\n" );
    printf("----------------------------------------\n");
    for ( int cnt = 0; cnt < 26; cnt++ ) {
        int unicodeCap = ( 65 + cnt );
        int unicodeSmall = ( 97 + cnt );
        printf("%c = %d | ", unicodeCap,unicodeCap);
        printf("%c = %d\n", unicodeSmall,unicodeSmall);
    }
    return 0;
}
```
