## Preface

> EVEN THE GREATEST WAS ONCE A BEGINNER.
> DON'T BE AFRAID TO TAKE FIRST STEP.
>

Developing a fertile ground for visualisation of programming logic should be the prime focus for an absolute beginner. Unfortunately this perspective is almost alien not only to most of the beginners. You are invited to learn programming using more of common sense. It will going to start with something very simple so as to naturally adapt to any beginner. Leaving the basic programming part learner will get countable experience, how to deep dive to decode programming logic. In simple terms:

**Programming = Programming Logic + features/API of programming language.**

Skill of designing program's logic is required irrespective any programming language. Without this skill, a programmer can't be called a programmer. Programming logic is the core of a programming. If someone is really interested in coding, better first get improved in logic building skills. This will make learners more comfortable and interested to learn advanced topics of programming language. Solve pattern based problems because it will improve the visualization of logic. After some level of practice based on the formulated approach mentioned in this guide book, a learner's mind will work like a mini-debugger. A learner not only could able to visualize the flow of data, but also able to easily relate how different variables are taking values at different point of execution of code. If a problem asked in the interview or anywhere else, then we should able to get the logic correctly and in a single chance, instead of playing with guessing. For example consider the following case;

![](img/67765455776ddeb6395161cd553ecd87_4_0.png)

The programmer should able to write a generalized solution, so that based on input he/she able to generate a wrist-watch of customized sizes. A logic to output mentioned wrist-watch is full of twists and not an easy cake even for 1-2 year experienced programmers. The fundamental intention is that we should have a clear view how to architect a programming logic without entering into the amazon of guessing or rather involve in **playing a trial-error kung-fu**. Please check your ability solve this problem when you are done with this book. Do ask this problem in your study circle and see with what different ideas people try to solve this problem, do observe their approach. You may learn one or more new things. You may also able to coach one or more things. Some IT companies do see qualities of coaching in a candidate.

In the learning of any subject when the visualization and thought process becomes active then only it will turn out to be actually learning. Not only the person will be able to understand the concept but also able to apply the concept naturally. Programming is not about downloading algorithms and memorizing programming logic in our mind. It is about applying the approach to solve the problems. Practicing approach by solving exercises mentioned in this book, in general improves coding skills.

Patterns are 2-dimensional data output and whether a desktop/mobile or web based applications, there also mostly it deals with 2-dimensional data output. Practice with different patterns helps in developing visualization of logic. This way it builds good foundation and will surely help when a person actually work on real-time application. Following are just few of them and better to practice with many possibilities.

![](img/67765455776ddeb6395161cd553ecd87_5_0.png)

Learning programming with such simple picture based problems surely helps in improving coding skills. If the wrong logical condition is applied, so is the non-matching output. This is also a learning, since in different occasion of solving a problem we may need such type of logical condition. So, failures will become our lessons. Learning in this way makes learning interesting and force us to put efforts being fully focused. So, in this way it helps in logic building.

On the other hand, learning using mathematical based problems like prime numbers and other similar kind of problems doesn't create much of interest. Furthermore, on practical ground such mathematical based exercises are just boredom on steroids for most of the non-programmers or beginners.

In my opinion pattern-based problem gives lot many reasons to think logically in different directions and to work on it. The improvement in building logical skills coupled with interest is much more higher than any other approach. In general, it suits all learners whoever like to invest some consistent time. I had experimented this with lot many students and I found that this is, the most interesting way to learn programming quickly.

This approach is faster, better and easier way to improve coding skills if followed a proper approach and not by applying dozens of guesswork to solve a particular problem. Otherwise, a person will somewhat get improved in guessing and not in finding the approach to solve a particular problem, which is basically against the very definition of an algorithm.

If pattern based problems are not handled properly it reveals logical weaknesses of a programmer and this the main reason whether at school level, beginners at college level or junior level interviews, the pattern based problems appear commonly. This book explains the approach to solve any pattern based problems and in general, it basically teaches how to get the logic right.

With insufficient logic building skills, the efforts on learning algorithms or advance topics of programming will be like actual talking to Gorilla, it will not be productive. This stuff is unique which I discovered accidentally during my teaching career. It is proven formula devised after experimenting with students. It formulated keeping in mind what suit best for students to learn quickly and correctly with zero reservation for memorizing program's logic. I was supposed to teach programming to complete beginners in a very less time of 2-3 months. I did some experiments and devised a plan and that plan was a great success. The results and response was amazingly nice. This book is the explanation of that approach which can definitely help a student, irrespective of their preferred learning style. This unique approach to learn programming logic, not only fast, but also with lots of enthusiasm. It layouts an approach based on common sense so that practically anyone can learn programming and interestingly from the very minimal technical topics. This book is a guide for teachers as well to hand over control on the programming to students with confidence and passionately. The approach is so adaptive that is well suited even for school going kids. So those parents who are struggling to teach programming to their kids can also refer this.

If you are struggling to learn or teach programming and you don’t like to waste your time searching YouTube and other resources, here is the chance to learn quickly. Will you...?

After completing this book you will be in a better position to make good use of other resources.

Programming is a kind of mental aerobics which teaches us to keep focus, nourishes good amount of patience, discipline and forecasting. If you observe these are some of the main qualities of an achiever.

Programming is for everybody and not just an academic exercise.

Happy learning!!!
