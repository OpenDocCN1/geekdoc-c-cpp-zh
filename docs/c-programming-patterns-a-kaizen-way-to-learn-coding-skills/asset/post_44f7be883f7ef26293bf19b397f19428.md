## Writing our own functions

Till now we have used many times the concept of generalised expression based on variable(s) to represent hard-coded values. We can still go ahead to generalise programming logic too. One of major advantage of **function with input parameter(s)** is that it helps to achieve different types of output by reusing the same programming logic.

Writing functions are a very sensible idea that suggests how we can encapsulate different programming logics differently so that repetition of same piece of programming logic should not happen in other parts of the programs. Before we apply this concept we need to understand the commonly used syntax of a function in a class with **main method** which is as follows:

```
return_type methodName( parameter1, parameter2,...){

    //programming logic

}
```

Where *parameter1, parameter2...* are the input(s) that a function may require and passing parameters in function is optional. The **return_type** is void if it is not returning any value or may return (int,char,..etc) using the return keyword. Since our main method is static, so just to keep technical stuff easy our method **printPattern** too using **static** keyword and moreover it is a part of object-oriented programming, which is out of scope of this book. For the following three different types of output we can use the same **printPattern method**, encapsulating a common programming logic. The **printPattern** will print different pattern due to the differences in input parameters.
