# Convert Simple Picture to Logical Conditions

We will do some exercises by trying to get logical conditions from an English alphabets of very simple nature drawn using * character. We may consider 7 rows and 5 columns box. We have to select only those pair of (row, col) values which are helpful to make a required alphabet. We will be putting logical condition only for those (row, col) value pairs that are matching * characters.

We will use logical OR (||) conditional operator to add more data. In our case we need to add some more of * characters to complete one more part of the alphabet A. Now we need to put * characters in the first column and the last column. So adding **(col==1)** and **(col==5)** logical conditions using **OR (||)** logical operator means more asterisk (*) characters are to be added in the following boxes.
