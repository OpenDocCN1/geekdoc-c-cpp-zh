## NumberPatternEE.c

```c
#include <stdio.h>
int main() {
    int totalRows = 8; //number of rows to display
    // Row level Repetitive Action :
    for ( int row = 1; row <= totalRows; row++ ) {
        //repetition count (2* totalRows  - 1) happens column-wise
        int num = row;
        // Column level Repetitive Action :
        // Action1.Move cursor in the same row
        // Action2.print character
        for ( int col = 1; col <= ( 2 * totalRows - 1 ); col++ ) {
            if ( col >= ( ( totalRows - row ) + 1 ) &&
                col <= ( ( totalRows + row ) - 1 ) ) {
                if ( col < totalRows ) {
                    // 1st half triangle
                    printf( "%d", num );
                    num = num - 1;
                } else if ( col >= totalRows ) {
                    // 2nd half triangle
                    printf( "%d", num );
                    num = num + 1;
                }
            } else {
                printf( "  ");
            }
        }//end inner for - loop
        printf( "\n" );// move control to the next line
    }// end outer for-loop
    return 0;
}
```

### Analysis of output

In general, three repetitive actions take place.

- a) Printing of numbers starting from 1 in incrementing order.
- b) Printing of spaces.
- c) Printing of numbers in decrementing order and its upper limit will start from last updated incremented value.

For the upper_limit of variable **space** at **row = 0**, the value will be (2 * 0 - 1) or -1. The lower_limit value of variable **space** at **row = 0** is also 0, so the loop-condition (0 < -1) will fail and no space will get printed. This holds true even for loop-condition (1 < -1).

Hence, we are in a position to get generalised expression for lower_limit and upper_limit.

| loop-condition | lower_limit <= space <= upper_limit |
|---|---|
| **Mathematical expression** | 1 <= space <= (2 * row - 1) |
| Syntax | `for ( space = 1 ; space <= ( 2 * row - 1 ) ; space++ )` |

This time somehow we are able to generalise the expressions otherwise we need to follow if-else condition as we did for the variable **numDec** using temporary variable **ul_numDec**.
