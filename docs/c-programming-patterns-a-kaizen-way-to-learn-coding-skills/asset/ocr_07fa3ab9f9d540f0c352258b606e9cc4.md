**Space ➔ space is also a character like any other character. If a character or a text is displayed on the screen after a blank area or gap, it means that many space character has to be print before printing any other character(s) afterwards.**

| Steps for pattern generation | Computer Screen |
|---|---|
| **For row = 1** Print space " " **4 times** in the same 1ˢᵗ row. Print star "*" **once** in the same 1ˢᵗ row then move to the next row number 2. | (image: dotted grid with column numbers 1–9 across the top and row numbers down the left; one `*` in row 1, column 5; cells at the start of row 1 outlined; blue arrow points to row 2) |
| **For row = 2** Print space " " **3 times** in the same 2ⁿᵈ row. Print star "*" **2 times** in the same 2ⁿᵈ row then move to the next row number 3. | (image: dotted grid; two `*` symbols in row 2, columns 4 and 5; first three cells of row 2 outlined; blue arrow points to row 3) |
| **For row = 3** Print space " " **2 times** in the same 3ʳᵈ row. Print star "*" **3 times** in the same 3ʳᵈ row then move to the next row number 4. | (image: dotted grid; three `*` symbols in row 3, columns 3, 4, and 5; first two cells of row 3 outlined; blue arrow points to row 4) |
| **For row = 4** Print space " " **1 time** in the same 4ᵗʰ row. Print star "*" **4 times** in the same 4ᵗʰ row then move to the next row number 5. | (image: dotted grid; four `*` symbols in row 4, columns 2, 3, 4, and 5; first cell of row 4 outlined; blue arrow points to row 5) |
| **For row = 5** Print space " " **0 times** in the same 5ᵗʰ row. Print star "*" **5 times** in the same 5ᵗʰ row then move to the next row number 5. | (image: dotted grid; five `*` symbols in row 5, columns 1 through 5; grid shows row 6; blue arrow points to row 6) |

**Let's convert these steps into C program.**

| Description | C statement |
|---|---|
| Move to the next row | `printf("\n")` |
| Move to the next (row, col) position and print space " " character in the same row | `printf(" ")` |
| Move to the next (row, col) position and print star "*" character in the same row | `printf("*")` |
