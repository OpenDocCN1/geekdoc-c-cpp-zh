# StatementIf.c

```
#include <stdio.h>

int main() {
    int ageOfCitizen = 80;
    if( ageOfCitizen >= 60 ) {
        printf("Age group - Senior Citizens.");
    }

    return 0;
}
```

# Output

Age group - Senior Citizens.
