# Let's convert steps into C program.

| Use of C in-built method | |
|---|---|
| Move cursor to the next row. | `printf("\n");` |
| On the computer screen each movement will be a character sized step in a forward direction from left hand side to right hand side in the same row. When cursor moved to the next (row, column) required position, then print space " " character. | `printf(" ");` |
| On the computer screen each movement will be a character sized step in a forward direction from left hand side to right hand side in the same row. When cursor moved to the next (row, column) required position, then print star "*" character. | `printf("*");` |

These programming statements are expected to get repeated many times in the program. Hence we need to use these statements within for-loop for printing characters after calculating the required (row, column) position. Finding the generalized logical expression using available variables to calculate the (row, column) position for printing logic pattern is the main brainy stuff in such exercises. We can easily confirm our logical expression by observing the output of a pattern. If outputted pattern doesn't match, then the learner can work upon to get the correct output. This way it helps in refining and building the skill of the program's logic.
