# What purpose does logic trace table solve?

> Simplicity is the key to brilliance.
> 
> - Bruce Lee

It's a simple trick to train novice programmer's mind on logical thinking. It's main purpose is to apply thinking in more structured manner to get programming logic. It is a simple table structure meant to derive the logical expression. The table structure basically gives clarity about relationship among the variable parameters.

In my opinion, without taking help of logic trace table structure, most of the novice programmer will find it difficult to think clearly in terms of building logic of a program. The clear thinking to find logical expression is a process which can be improved with a little bit of practice. Unless and until a person is able to put his/her understanding in a simplified way, it means that the person had not really understood the concept.

# What is the importance of logical expression?

Programming logic is a brain behind program. It is made up of logical expression(s).So, at the very core level it is a logical expressions when executed helps in decision making. Most of the time it is applied in condition of looping, in decision structures like if-condition, if-elseif condition.
