## COLUMN LEVEL REPETITIVE ACTION

Total maximum of 9 columns are needed to print the bottom of pattern.

| Row level Repetitive Action | | | Expected Output |
| :--- | :--- | :--- | :--- |
| row | Column level Repetitive Action | | |
| | ( lower_limit <= col <= upper_limit) | | |
| | lower_limit | upper_limit | |
| 1 | 5 | 5 | 1 |
| 2 | 4 | 6 | 2 2 2 |
| 3 | 3 | 7 | 3 3 3 3 3 |
| 4 | 2 | 8 | 4 4 4 4 4 4 4 |
| 5 | 1 | 9 | 5 5 5 5 5 5 5 5 5 |

The lower_limit & upper_limit ,both are not consistent for all the rows. We need to come out with consistent expressions for both upper_limit and lower_limit which should suit for n number of rows.

The other remaining variables are row, totalRows=5.

Let’s try to generalise using these variables.

## Column level Repetitive Action

| row | lower_limit value | lower_limit expr | lower_limit formula | upper_limit value | upper_limit expr | upper_limit formula |
|---|---|---|---|---|---|---|
| 1 | 5 | totalRows | totalRows +1 - 1 | 5 | totalRows | totalRows +1 - 1 |
| 2 | 4 | totalRows -1 | totalRows +1 - 2 | 6 | totalRows + 1 | totalRows + 2 - 1 |
| 3 | 3 | totalRows -2 | totalRows +1 - 3 | 7 | totalRows + 2 | totalRows + 3 - 1 |
| 4 | 2 | totalRows -3 | totalRows +1 - 4 | 8 | totalRows + 3 | totalRows + 4 - 1 |
| 5 | 1 | totalRows -4 | totalRows +1 - 5 | 9 | totalRows + 4 | totalRows + 5 - 1 |

## Column level Repetitive Action

| row | lower_limit value | lower_limit formula | upper_limit value | upper_limit formula |
|---|---|---|---|---|
| 1 | 5 | totalRows +1 - row | 5 | totalRows + row - 1 |
| 2 | 4 | totalRows +1 - row | 6 | totalRows + row - 1 |
| 3 | 3 | totalRows +1 - row | 7 | totalRows + row - 1 |
| 4 | 2 | totalRows +1 - row | 8 | totalRows + row - 1 |
| 5 | 1 | totalRows +1 - row | 9 | totalRows + row - 1 |

The lower_limit & upper_limit are consistent for all the rows. It’s now generalised for any number of rows to print numeric value. So our if-condition becomes

| if-condition | lower_limit <=col<= upper_limit |
|---|---|
| Mathematical expression | (totalRows +1 - row) <= col <= (totalRows + row - 1) |
| Syntax | if( col >= ( ( totalRows - row ) + 1 ) && col <= ( ( totalRows + row ) - 1 ) ) |

When the if-condition satisfied, it will print the row value at that position at a particular row or else will print space character. Since we know that the total maximum of 9 columns are needed to print the bottom of pattern. The for-loop condition is given as;

| loop-condition | lower_limit <=col<= upper_limit |
|---|---|
| Mathematical expression | 1<= col <= 9 |
| Syntax | for( col = 1 ; col <= 9 ; col++ ) |

The *upper_limit* of col variable of inner for-loop which is a **value 9** is required to be generalised.

The hard-coded values in logical condition makes program to be fail for different input values. Somehow, it has to be generalised using variables considered for program.

| loop-condition | lower_limit <=col<= upper_limit |
|---|---|
| Mathematical expression | 1<= col <= totalRows + 4 |
|  | 1<= col <= totalRows + ( totalRows - 1 ) |
|  | 1<= col <= ( 2*totalRows - 1 ) |
| Syntax | for( col = 1 ; col <= ( 2* totalRows - 1 ) ; col++ ) |

We are now able to generalised using variable totalRows.

Let’s try to verify the upper limit for total columns which we will display for each row

for totalRows = 5 , the col <= 9 ( 2*5 - 1 )

for totalRows = 4 , the col <= 7 ( 2*4 - 1 )

for totalRows = 3 , the col <= 5 ( 2*3 - 1 )

for totalRows = 2 , the col <= 3 ( 2*2 - 1 )

for totalRows = 1 , the col <= 1 ( 2*1 - 1 )

So this generalisation for total columns as per given rows holds valid.

## NumberPattern1E.C

```c
#include <stdio.h>
int main() {

    int totalRows = 5; //number of rows to display

    for ( int row = 1; row <= totalRows; row++) {

        // repetition happens ( 2 * totalRows - 1 ) times for columns

        for ( int col = 1; col <= ( 2 * totalRows - 1 ); col++ ) {

            if ( col >= ( ( totalRows - row ) + 1 ) &&
                col <= ( ( totalRows + row ) - 1 ) ) {

                // row value to be printed
                printf( "%d ", row );

            } else {

                // spaces to be printed
                printf( "  " );

            }

        }// end  inner for - loop

        printf( "\n" );// moves control to the next line

    } // end  outer for - loop

    return 0;

}
```
