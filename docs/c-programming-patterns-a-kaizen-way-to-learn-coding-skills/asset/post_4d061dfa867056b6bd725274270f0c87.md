### Exercise6B.1

For every single value of outer for-loop in an iteration, inner for-loop executes completely. The complete execution of inner for-loop is treated like an execution of a normal statement. Unless and until inner for-loop get executed completely, the outer for-loop next iteration won't happen. The following program gives the demonstration of printing the value of columns vertically for every single row value.

**ForLoopEveryRowAllColumns.c**

```c
#include <stdio.h>

int main() {

    int TOTAL_ROWS = 3;
    int TOTAL_COLUMNS = 3;

    for( int row = 1; row <= TOTAL_ROWS ; row ++ ) {

        for( int col = 1; col <= TOTAL_COLUMNS ; col ++ ) {

            printf( "Row = %d |  Col = %d\n" , row, col);

        }

        printf("------------------------------\n");

    }

    return 0;

}
```

**Output**

```text
Row = 1 | Col = 1
Row = 1 | Col = 2
Row = 1 | Col = 3
------------------------------
Row = 2 | Col = 1
Row = 2 | Col = 2
Row = 2 | Col = 3
------------------------------
Row = 3 | Col = 1
Row = 3 | Col = 2
Row = 3 | Col = 3
------------------------------
```

## How to verify logical conditions?

Let's verify the logical condition of the alphabet M captured in 7 rows and 5 columns given as :

(col==1)||(col==5)||( ((row==col)||(row+col ==6) ) && row<=3 )

**VerifyAlphabetM.c**

```c
#include <stdio.h>

int main() {
    int TOTAL_ROWS = 7;
    int TOTAL_COLUMNS = 5;
    int condition; //logical condition variable
    for ( int row = 1; row <= TOTAL_ROWS; row++) {
        for ( int col = 1; col <= TOTAL_COLUMNS; col++) {
            condition = (col == 1) || (col == 5) ||
                ( ((row == col) || (row + col == 6)) && row <= 3 );
            // space(s) are used just to show formatted output.
            if (condition) {
                printf("* "); // single space
            } else {
                printf("  ");// double space
            }
        }
        printf("\n");// Move cursor to the next row
    }
    return 0;
}
```

**Output**

```text
*   *
* *  *
* *  *
*   *
*   *
*   *
*   *
```
