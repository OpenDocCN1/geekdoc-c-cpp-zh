# Logical Operators

It also returns either *true* or *false* value like in the case of any comparison operator expression. We can combined many more such expressions which could be based on comparison operators. If there are many more conditions to be considered we usually use logical operators. Usage of these operators are quite common and plays a very important role in writing programs. Every programmer must have very much clear idea about usage of these operators. It will be worth if any new learner spent some extra time experimenting with these operators. Following are the different types of logical operators.

| Operator | Logical Operation Description |
|---|---|
| `&&` | Logical AND |
| `\|\|` | Logical OR |
| `!` | Logical NOT |

**Logical AND:** Returns **true** only in a case when **compulsory both A and B are true** else false. More we add AND condition using `&&` operator in a logical expression, less the size of data we get out of total data. It usually applied in a situation to get specific data or data of lesser range or size.

| A | B | A&&B |
|---|---|---|
| ***true*** | ***true*** | ***true*** |
| true | false | false |
| false | true | false |
| false | false | false |

**Logical OR:** Returns **false** only in a case when **compulsory both A and B are false** else true. More we add OR condition using `\|\|` operator in a logical expression, more it increases the size of data as a output result. So it is used to get broader range of data.

| A | B | A \|\| B |
|---|---|---|
| true | true | true |
| true | false | true |
| false | true | true |
| ***false*** | ***false*** | ***false*** |
