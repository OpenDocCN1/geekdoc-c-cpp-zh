## PatternB3.c

```c
#include <stdio.h>

int main() {

    int totalRows = 10; //10 rows to display

    // Row level Repetitive Action :
    // Action1. Executes Column level Repetitive Action
    // Action2. Move cursor to next row.
    for( int row = totalRows ; row >=1 ; row-- ) {

        // Column level Repetitive Action :
        for(int col = row; col >= 1 ; col--) {
            // Action1. Move cursor in the same row
            // Action2. print "*" character
            printf("* ");
        }
        printf("\n"); // Move cursor to the next row
    }

    return 0;
}
```

We can know exact location of each “*” character by knowing it’s unique (row, column) numeric combination on the computer screen.

(2, 4) means character “*” at **second row** and **fourth column** in the table.

For example, for a numeric pair(2,4), the value 2 represents row number and the value 4 represents a column number. This is the actual measure by which we are able to identify a “*” character clearly at that particular location on the computer screen.

**Space ➔ space is also a character like any other character. If a character or a text is displayed on the screen after a blank area or gap, it means that many space character has to be print before printing any other character(s) afterwards.**

## Approach to solution

The variables are **row** & **totalRows**=5.

We need to generalise the non-repeating numeric pattern of the column **max_val**. The numeric pattern of the variable col’s column **max_val** matches exactly the every value of **row**. So all the numeric pattern of variable col’s column **max_val** can be expressed in row variable.

Let’s try to use variable **totalRows** to generalise the variable **spaces**’s column **max_val**.

| Row level Repetitive Action |  |  |  |  |  |
|---|---|---|---|---|---|
| Variable : row | **Column level Repetitive Action** |  |  | Variable : col |  |
|  | Variable : spaces |  |  |  |  |
|  | **min_val** | **max_val** |  | **min_val** | **max_val** |
|  |  | default | 1 |  |  |
| 1 | 1 | 4 | totalRows - 1 | 1 | row |
| 2 | 1 | 3 | totalRows - 2 | 1 | row |
| 3 | 1 | 2 | totalRows - 3 | 1 | row |
| 4 | 1 | 1 | totalRows - 4 | 1 | row |
| 5 | 0 | 0 | totalRows - 4 | 1 | row |

Part of variable **spaces** column **max_val**’s expression follows the same numeric value pattern as **row**.

Further we can express it in terms of totalRows & row variables.

| Row level Repetitive Action |  |  |  |  |  |
|---|---|---|---|---|---|
| Variable : row | **Column level Repetitive Action** |  |  | Variable : col |  |
|  | Variable : spaces |  |  |  |  |
|  | **min_val** | **max_val** |  | **min_val** | **max_val** |
|  |  | default | 1 |  |  |

| 2 | 1 | 3 | totalRows - row | 1 | row |
| 3 | 1 | 2 | totalRows - row | 1 | row |
| 4 | 1 | 1 | totalRows - row | 1 | row |
| 5 | 0 | 0 | totalRows - row | 1 | row |

We generalised the non-repeating numeric pattern of the column **max_val** into an expressions.

We can now define column level *for-loop* which is printing spaces for every row value.

## ROW LEVEL REPETITIVE ACTION

**Column level for-loop** for printing space characters //  **inner for-loop**

**Column level for-loop** for printing star characters //  **inner for-loop**

```
printf("\n"); // Move cursor to the next row
```

We have assigned **unique value** to each row starting from 1 till 5. So, it’s an easy take now.

The minimum and maximum value can be given for the **for-loop** as;

*min_val = 1*  &  *max_val = 5* or totalRows

Let’s consider;

**row** → variable **type_of_integer** to store integer value one at a time and represents row number between 1 and 5(totalRows). The **totalRows** has initially assigned the value 5.

Outer **for-loop** starts at row=1 & will repeat till row <= **totalRows**.

We got everything related to **for-loop** for row level repetition.
