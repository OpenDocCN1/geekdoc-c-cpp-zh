Let's try to solve this pattern using a 1-dimensional array. We know that array is a continuous memory block which needs to declare earlier before it's use. For example our array will be;

| strings[44] | | | | | | | | | | | | |
| position | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 | ..... | 44 |
| Character | | | | | | | | | | ..... | .... |

```
char strings[44] = { " " }; // continuous block of memory allocated.
Moreover, the following printing statement prints horizontally all the content of an array in a single chance.
printf("%s", strings );
```

Hence for every row we need to print the array but with modification in the contents of this array. Basically we will re-use the same array and print it's contents.

# Two main observations are as follows:

+   a) If we initialize this array with space, then logic to dynamically print spaces will not be required.
+   b) Only we need to track of putting the star(*) characters at an appropriate places. The count goes on increases till row=5 and goes on decrease. Initially we need to fill the array with star(*) characters to complete the first half triangle and then need to decrease star(*) characters to generate the reverse triangle.
