# *Alternative solution*

Since the column values need to split clearly between printing spaces and numbers. We can try to do this using if-else condition construct.

# NumberPattern2D.c

```
#include <stdio.h>
int main() {

    int totalRows = 5; //number of rows to display

    for ( int row = totalRows; row >= 1; row-- ) {

        for ( int col = 1; col <= ( totalRows ); col++ ) {

            if ( col <= ( totalRows - row ) ) {

                // spaces to be printed
                printf("  " );

            } else {

                // row value to be printed
                printf("%d ", row );

            }

        }// inner for-loop

        printf("\n" );// moves control to the next line

    }// outer for-loop

    return 0;
}
```

```
5 5 5 5 5
  4 4 4 4
    3 3 3
      2 2
        1
```
