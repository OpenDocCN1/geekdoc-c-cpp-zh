So that specific part of the numeric pattern can be expressed in row variable.

The condition (col >=1) gives a starting point from which it will start printing star(“*”) character(s) till the value of variable row reaches (totalRows).

The variable col then start decreases which is captured in the expression (2*totalRows − row).

So in this case, there is not the one but two generalised expressions for values of the variable col. This indicates that we need to use two separate for-loop for the variable col.
