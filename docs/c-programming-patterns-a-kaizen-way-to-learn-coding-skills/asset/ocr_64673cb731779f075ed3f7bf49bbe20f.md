We need to put * characters in the first row. So matching logical conditions will be (row==1). We need to find a relationship among highlighted boxes as it suggests one of the arm of alphabet K.

The highlighted boxes which are represented by (row, col) value pairs as (4,1),(3,2),(2,3),(1,4).

If we pay little bit of attention we can observe that if we add row value/number to column value/number, we will get value 5 consistently.

(4,1),(3,2),(2,3),(1,4) ➔ (4+1),(3+2),(2+3),(1+4) ➔ (5),(5),(5),(5).

We need to verify if this holds true for other row+col value combinations or not. Let check by adding each row+col value for every box represented by (row, col) value pair. All row+col value are as follows and highlighted where row+col=5.

(1+1=2) (1+2=3) (1+3=4) **(1+4=5)** (1+5=6)  
(2+1=3) (2+2=4) **(2+3=5)** (2+4=6) (2+5=7)  
(3+1=4) **(3+2=5)** (3+3=6) (3+4=7) (3+5=8)  
**(4+1=5)** (4+2=6) (4+3=7) (4+4=8) (4+5=9)  
(5+1=6) (5+2=7) (5+3=8) (5+4=9) (5+5=10)  
(6+1=7) (6+2=8) (6+3=9) (6+4=10) (6+5=11)  
(7+1=8) (7+2=9) (7+3=10) (7+4=11) (7+5=12)

Now row + col = 5 holds true in other than our considered boxes. So our guess now becomes valid which uniquely identifies or selects the considered value pairs. This how we do selection of in general data by applying condition. In this case boxes with (row, col) combination are selected. Hence our next logical condition becomes (row+col == 5).
