# Recursion: Repeat without looping

In *for-loop*, the same piece of code which is enclosed in for-loop’s code block gets repeated until the condition to repeat it becomes false. We can able to get similar kind of affect using function and function calls. We know that a function can call other function(s) as not to repeat the same piece of code or set of programming instructions again and again. In case, if we do the opposite and repeat the same piece of code again and again by calling the same function then this process is known as **recursion** and function is known as **recursive function**. Moreover, like in most of repetitive processing we tried to maintain a **terminating condition** so that after which it should stop working. Similarly, we are required to give a terminating condition in order to end the motion of recursive function calls. You need to maintain a simple format to write recursive function which is given as follows;

```
recursiveFunction( startValue, parm1,param2,...){
    1.Write terminating condition which is just opposite to how you write
    loop-condition /update-condition in a for-loop
    2. Write your programming logic.
        Pass all the required variables as parameters ( parm1, param2,... ) in this functional
        call which are used in writing programming logic.
    3.recursiveFunction( nextValue, parm1,param2...);
}
```

Let’s implement a recursive function call program to print number in ascending order.

# RecursiveLoopIncrement.c

```
#include <stdio.h>

/* function declaration */
void loopInc(int counter, int totalRows);

int main() {
    // number of rows
    int totalRows = 10;
    // recursive function call to print number in an incremental order
    loopInc( 1, totalRows );
    return 0;
}

void loopInc(int counter, int totalRows) {
    // terminating condition
    if ( counter > totalRows ) {
        return;
    }
    // programming logic
    if ( counter <= totalRows ) {
        printf( "%d\n", counter );//print to console
    }
    // tail recursive call
    loopInc( counter + 1, totalRows );
}
```
