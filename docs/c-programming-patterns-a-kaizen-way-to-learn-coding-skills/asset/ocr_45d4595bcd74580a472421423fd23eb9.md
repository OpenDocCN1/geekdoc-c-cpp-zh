# We can see few different styles of alphabet L.

![](bbox=[0.07, 0.1, 0.45, 0.23])

What possible thoughts shall cross our mind if we try to fit each different style of alphabet L in an 8 rows and 8 column box using **\* character**. Different styles of alphabet means different pictures and each will have different set of **{row, col}** value pairs.

![](bbox=[0.07, 0.34, 0.93, 0.43])

It's obvious that we can't get pixel perfect picture by using \* character. The most important point we need to understand is that **different pictured output mean different logical conditions**. These set of pictures are somewhat advanced to start with it in order to learn to apply logical conditions.

We can surely start with something so simple that even school going kids can't make any excuse that they can't learn programming. We will pick something which will be so easy and familiar to most of us. We will consider English alphabets of very simplest structure shown in the following examples.

Drawn alphabets are A, C and D using \* character.

![](bbox=[0.07, 0.69, 0.93, 0.84])

Let's go back to old school days and try to recollect our learning experiences with the English alphabets. We were trained by our teachers, parents and others to write alphabets and they taught us in some logical way to write alphabets. The total logic applied to write one alphabet differs from another alphabet. Since the total structure of every alphabet is different we have chance to practice different kind of logical conditions.
