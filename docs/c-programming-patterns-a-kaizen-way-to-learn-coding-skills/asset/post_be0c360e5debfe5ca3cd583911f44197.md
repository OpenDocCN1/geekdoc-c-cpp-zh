## **COLUMN LEVEL REPETITIVE ACTION**

| **Row level Repetitive Action** | **Column level Repetitive Action** |  | **Expected Output** |
|---|---|---|---|
| *row* | *upper_limit >=col>= lower_limit* |  |  |
|  | lower_limit | upper_limit |  |
| 1 | 1 | 5 | 5 4 3 2 1 |
| 2 | 1 | 4 | 4 3 2 1 |
| 3 | 1 | 3 | 3 2 1 |
| 4 | 1 | 2 | 2 1 |
| 5 | 1 | 1 | 1 |

The lower_limit has same consistent expression as numeric value for the all the rows.

Likewise, we need to come out with such a consistent expression for upper_limit which should suit any number of rows.

The available variables are row & totalRows=5. Let’s try to generalise using these variables.

| Column level Repetitive Action |
|---|---|---|---|---|---|
| row | If-condition( upper_limit >=col>= lower_limit) | | | | |
| | lower_limit | upper_limit | | | |
| | | | 1 | 2 | 3 |
| 1 | 1 | 5 | totalRows | totalRows +1 - 1 | totalRows +1 - row |
| 2 | 1 | 4 | totalRows - 1 | totalRows +1 - 2 | totalRows +1 - row |
| 3 | 1 | 3 | totalRows - 2 | totalRows +1 - 3 | totalRows +1 - row |
| 4 | 1 | 2 | totalRows - 3 | totalRows +1- 4 | totalRows +1 - row |
| 5 | 1 | 1 | totalRows - 4 | totalRows +1- 5 | totalRows +1 - row |

The lower_limit & upper_limit are become consistent for all the rows. The upper_limit is generalised to (totalRows + 1 – row). This logical expression is such a formula, commonly applied on all rows and columns which in turn helps to give matching output.

So our If-condition becomes;

| if-condition | upper_limit >=col>= lower_limit |
|---|---|
| Mathematical expression | 1 <= col <= ( (totalRows +1) – row ) |
| Syntax | if( col >= 1 && col <= (totalRows + 1 - row) ) |

## NumberPatternDD1.c

```
#include <stdio.h>
int main() {
    int totalRows = 5; //number of rows to display
    // Row level Repetitive Action:
    for ( int row = 1; row <= totalRows; row++ ) {
        // Column level Repetitive Action:
        // Action1.Move cursor in the same row
        // Action2.print numeric character
        // spaces to be printed before printing numbers
        for ( int col = totalRows; col >= 1; col-- ) {
            if ( col >= 1 && col <= ( totalRows + 1 - row ) ) {
                printf( "%d ", col );
            } else {
                printf( "  " );
            }
        }// inner for-loop
        printf( "\n" );// Moves control to the next line
    }// outer for-loop
    return 0;
}
```

The lower_limit in if-condition becomes an extra condition as inner for-loop's loop-condition (col >= 1) already taking care of it.

| if-condition | `upper_limit >= col >= lower_limit` |
|---|---|
| Mathematical expression | `col <= (totalRows + 1 - row)` |
| Syntax | `if( col <= (totalRows + 1 - row) )` |

## NumberPatternDD3.c

```c
#include <stdio.h>
int main() {

    int totalRows = 5; //number of rows to display

    // Row level Repetitive Action :
    for ( int row = 0; row < totalRows; row++ ) {

        // Column level Repetitive Action :
        // Action1.Move cursor in the same row
        // Action2.print character

        // spaces to be printed before printing numbers
        for ( int col = totalRows; col >= 1; col-- ) {

            if ( col <= ( totalRows - row ) ) {
                printf( "%d ", col );
            } else {
                printf( "  " );
            }
        }

        // move control to the next line
        printf( "\n" );
    }

    return 0;
}
```
