The following exercises are showing **different ways of single line break in the output.**

# **Exercise 2.1.** Printing "Word: " in every line and use of `printf("\\n")` (single line break).

# PrintInEveryLine1.c

```
```c
#include <stdio.h>

int main() {

        printf("Word: ");

        printf("\\n");

        printf("Word: ");

        printf("\\n");

        printf("Word: ");

        return 0;
}
```
```

# Output

```
```text
Word:
Word:
Word:
```
```

# **Exercise 2.2.** Printing "Word: " in every line and use of "\\n" (single line break character).

# PrintInEveryLine2.c

```
```c
#include <stdio.h>

int main() {

        printf("Word: ");

        printf("\\nWord:");

        printf("\\nWord:");

        return 0;
}
```
```

# Output

```
```text
Word:
Word:
Word:
```
