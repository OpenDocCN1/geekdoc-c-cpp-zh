# Stack frame for main()

| ? | secondNum | |
| 1004 | | |
| 9 | firstNum | |
| 1000 | | |

UPWARD GROWING STACK

When the following statement/instruction gets executed;
int firstNum = 9;

The data of the variable firstNum represented by memory address 1000 is gets updated with the value 9.
When program control reaches variable declaration as;
int secondNum

The variable secondNum is pushed into the stack represented by memory address 1004 and where data can be any garbage value(?).

In the assignment operation given as follows;
int secondNum = 10;

The left side of = represent a memory location ( 1004 )
The right side of = represents data on that memory location ( 10 )
