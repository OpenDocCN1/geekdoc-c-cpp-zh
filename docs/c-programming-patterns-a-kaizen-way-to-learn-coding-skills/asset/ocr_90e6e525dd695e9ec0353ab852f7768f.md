# Pointers And Memory Matters

Pointers are famously known as address variables as their only purpose is to store memory address of a data not the data itself. Pointer variable's name starts with asterisk(*) character. For example;

```
data_type *dataPointer ;
int *intPtr; // pointer variable of type integer data-type
```

| CONCEPTUAL LAYOUT OF A POINTER VARIABLE |
|---|---|---|---|
| data-type | *pointer_variable_name | = | Memory Address of a variable matching data-type |
| | | | Memory Address of pointer_variable_name |
