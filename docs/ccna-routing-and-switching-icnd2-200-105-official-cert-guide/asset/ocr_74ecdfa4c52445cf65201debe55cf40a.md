To support IPv6, a working group created a new version of RIP, called *RIP Next Generation* (RIPng), with the name chosen in reference to the *Star Trek* TV series. (Yep.) (Cisco often refers to this protocol today as RIP for IPv6.) To date, RIPng support in IOS has not gone through a similar transformation to include address families.

Table K-4 summarizes the names of the protocols for easier review and study. This book discusses the more classic configuration options, and does not discuss address family configuration in any detail.
