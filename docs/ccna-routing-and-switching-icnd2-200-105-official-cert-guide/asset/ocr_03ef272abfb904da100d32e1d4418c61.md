Split horizon is difficult to learn by reading words, and much easier to learn by seeing an example. Figure 9-6 continues the same example as 9-5, but focusing on R1’s RIP update sent out R1’s S0/0 interface to R2. This figure shows R1’s routing table with three light-colored routes, all of which list S0/0 as the outgoing interface. When building the RIP update to send out S0/0, split-horizon rules tell R1 to ignore those light-colored routes, because all three routes list S0/0 as the outgoing interface. Only the bold route, which does not list S0/0 as an outgoing interface, can be included in the RIP update sent out S0/0.
