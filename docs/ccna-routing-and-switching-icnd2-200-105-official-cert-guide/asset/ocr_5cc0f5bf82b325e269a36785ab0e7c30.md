The extended **ping** and **traceroute** commands give you a lot of power to sit at a router CLI and test the reverse route used by the hosts on the connected LANs. For a brief review here, the extended IPv6 options on the router ping and traceroute commands let you test routes back to the correct source subnet. For instance, in Figure 22-12, an extended ping from R1 to PC2’s IPv6 address tests the forward route to PC2. However, if the extended ping uses R1’s G0/0 interface as the source, this command also tests the reverse route back to PC1’s IPv6 subnet.
