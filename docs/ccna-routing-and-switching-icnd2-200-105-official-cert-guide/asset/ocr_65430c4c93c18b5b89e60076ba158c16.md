# Single-Area Configuration on the Three Internal Routers

The configurations on the three internal routers in this example review ICND1-level single-area OSPF configuration. In a multiarea OSPF design, the configuration on any internal routers—routers for which all interfaces connect to a single area—looks like a single-area configuration because all the interfaces are placed into one area.

Example 23-1 begins the example with R2’s complete IPv6 configuration, including OSPFv3. In other words, all the commands needed on R2 to add IPv6 support are in the example. Note that for OSPFv3 in particular, the example shows the following actions, as highlighted in the example:

+   1. Creates an OSPFv3 process with process ID 2
+   2. Defines the OSPFv3 RID explicitly as 2.2.2.2
+   3. Enables OSPFv3 process 2 on two interfaces, putting both in area 23

**Example 23-1**  *IPv6 and OSPFv3 Configuration on Internal Router R2*

```
ipv6 unicast-routing
!
interface GigabitEthernet0/0
 mac-address 0200.0000.0002
 ipv6 address 2001:db8:1:23::2/64
 ipv6 ospf 2 area 23
!
interface serial 0/0/1
 ipv6 address 2001:db8:1:12::2/64
 ipv6 ospf 2 area 23
!
 ipv6 router ospf 2
 router-id 2.2.2.2
```
