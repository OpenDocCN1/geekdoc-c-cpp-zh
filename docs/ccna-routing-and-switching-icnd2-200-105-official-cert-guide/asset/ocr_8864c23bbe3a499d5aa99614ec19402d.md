As an example of a Trap, suppose that Router 1’s G0/0 interface fails, as shown at Step 1 of Figure 26-3. With Traps configured, the router would send an SNMP Trap message to the NMS, with the Trap message noting the down state of the G0/0 interface. Then, the NMS software can send a text message to the network support staff, pop up a window on the NMS screen, change to red the color of the correct router icon on the graphical interface, and so on.
