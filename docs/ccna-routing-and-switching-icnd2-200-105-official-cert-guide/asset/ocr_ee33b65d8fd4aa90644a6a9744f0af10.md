**Figure 21-2** _Host IPv4 Settings Compared to What the Settings Should Match_

As numbered in the figure, these steps should be followed to check the host’s IPv4 settings:

+   1. **Step 1.** Check the host’s list of DNS server addresses against the actual addresses used by the users.
+   2. **Step 2.** Check the host’s default router setting against the router’s LAN interface configuration, for the ip address command.
+   3. **Step 3.** Check the subnet mask used by the router and the host; if they use a different mask, the subnets will not exactly match, which will cause problems for some host addresses.
+   4. **Step 4.** The host and router should attach to the exact same subnet—same subnet ID and same range of IP addresses. So, use both the router’s and host’s IP address and mask, calculate the subnet ID and range of addresses, and confirm they are in the same subnet as the subnet implied by the address/mask of the router’s ip address command.
