Table 15-5 Chapter 15 EXEC Command Reference

| Command | Description |
|---|---|
| show interfaces tunnel number | Displays the status of a tunnel interface. |
| show interfaces dialer number | Displays the status of a dialer interface. |
| show interfaces virtual-access number | Displays the status of a virtual-access interface. |
| show interfaces virtual-access number configuration | Displays the configuration that IOS builds for a virtual-access interface based on a dialer interface. |
| show pppoe session [interface type number] | Displays a few lines of status output about each PPPoE session (or if listed, only those sessions on a particular interface). |
