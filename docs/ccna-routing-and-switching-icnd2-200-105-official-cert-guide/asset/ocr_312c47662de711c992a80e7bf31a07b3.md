While PPPoE configuration has enough detail to be a challenge, PPPoE verification has a few more challenges because of how PPPoE works internally in IOS. Before reviewing a bunch of command output, it helps to get an idea about those internals. So, consider the ideas in Figure 15-26. The figure shows the two familiar interfaces from the configuration section, namely, a dialer interface and Ethernet interface. It adds two boxes for discussion:

**PPPoE Session:** A reference to the IOS internal process that performs the PPPoE work and keeps status variables for the PPPoE control protocols

**Virtual-Access Interface:** Another logical interface, dynamically created by IOS once the PPPoE session is up and working, and bound to the dialer interface
