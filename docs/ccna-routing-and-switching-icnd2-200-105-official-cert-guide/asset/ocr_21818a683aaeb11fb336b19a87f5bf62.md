# Table 9-2  Interior IP Routing Protocols Compared

| Feature | RIPv2 | EIGRP | OSPFv2 |
|---|---|---|---|
| Metric is based on | Hop count | Bandwidth and delay | Cost |
| Sends periodic full updates | Yes | No | No |
| Sends periodic Hello messages | No | Yes | Yes |
| Uses route poisoning for failed routes | Yes | Yes | Yes |
| Uses split horizon to limit updates about working routes | Yes | Yes | No |
| Address to which messages are sent | 224.0.0.9 | 224.0.0.10 | 224.0.0.5, 224.0.0.6 |
