If R1 had been configured with preemption for that previous scenario, R1 would have taken over from R2 when R1’s interface came back up. Example 20-5 shows exactly that. Before the output in Example 20-5 was gathered, the network had been put back to the same beginning state as at the beginning of Example 20-4, with R1 active and R2 as standby. Within Example 20-5, R1’s interface is shut down, then configured with preemption using the standby 1 preempt command, enabling preemption. Then, after enabling the interface again, R1 takes over as HSRP active, as shown at the bottom of the example’s show standby brief command from R2. That output now shows the local router’s state as Standby, and the active as 10.1.1.9 (R1).
