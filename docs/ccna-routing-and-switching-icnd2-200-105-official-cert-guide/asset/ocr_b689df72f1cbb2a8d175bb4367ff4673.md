# ## RSTP Port Roles

RSTP adds two port roles to STP: the alternate port and the backup port. Example 3-14 repeats an excerpt from the **show spanning-tree vlan 10** command on switch SW3 to show an example of the alternate port role. SW3 (as shown earlier in Figure 3-8) is not the root switch, with Gi0/1 as its root port and Gi0/2 as an alternate port.
