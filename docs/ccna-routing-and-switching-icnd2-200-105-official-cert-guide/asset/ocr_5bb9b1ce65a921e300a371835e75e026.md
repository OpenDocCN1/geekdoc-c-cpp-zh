PAP configuration differs from CHAP configuration in a couple of ways. First, PAP uses the similar **authentication ppp** command instead of the **authentication ppp chap** command. Then, PAP configures the sent username/password pair much differently than CHAP. A router defines the username/password pair it will send using the **ppp pap sent-username** command, configured as an interface subcommand. One set, the other router receives that username/password pair, and compares those values with its various **username password** global commands.
