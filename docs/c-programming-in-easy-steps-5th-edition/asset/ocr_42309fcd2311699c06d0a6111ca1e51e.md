# Inserting page components

Visual Studio provides a two-part window to insert interface components into a UWP app. This comprises a **Design** view of the components and a **XAML** view for the XAML code:

![](bbox=[0.118, 0.185, 0.192, 0.249])

+   1. Open **Solution Explorer** then double-click on **MainPage.xaml** – to launch the two-part window

![](bbox=[0.399, 0.299, 0.601, 0.454])

+   2. See that by default, the **Design** view displays a blank canvas in **Portrait** mode

![](bbox=[0.394, 0.527, 0.691, 0.699])

![](bbox=[0.118, 0.711, 0.209, 0.771])

Explore these buttons to change the magnification and grid characteristics.

+   3. Click the adjacent button in **Design** view to change the blank canvas to **Landscape** mode

![](bbox=[0.304, 0.826, 0.695, 0.839])

![](bbox=[0.118, 0.851, 0.209, 0.909])
