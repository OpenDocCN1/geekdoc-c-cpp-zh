# Importing program assets

In order to have a XAML **<Image>** component display a graphic, an image file first needs to be added to the project’s **Assets** folder. It can then be assigned to a **Source** attribute of the **<Image>** tag:

![](bbox=[0.118, 0.196, 0.19, 0.246])

Universal

+   1. Open **Solution Explorer**, then right-click on the **Assets** folder and choose **Add** from the context menu.

+   2. Now, choose **Existing Item** from the next context menu – to open an **Add Existing Item** dialog box.

![](bbox=[0.347, 0.349, 0.653, 0.494])

+   3. In the **Add Existing Item** dialog, browse to the location of an image then select the file and click the **Add** button.

![](bbox=[0.3, 0.543, 0.7, 0.662])

![](bbox=[0.118, 0.674, 0.208, 0.733])

An image for display may be in any popular file format – such as **.bmp**, **.gif**, **.jpg**, **.png**, or **.tif**.

+   4. In **Solution Explorer**, the selected image file now appears in the project’s **Asset** folder.

+   5. Select the Image component in **Designer** view, then click **View**, **Properties** to reveal its properties.
