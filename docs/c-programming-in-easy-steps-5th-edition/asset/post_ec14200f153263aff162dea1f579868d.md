
## Making abstract data types

An Abstract Data Type (ADT) represents a concept, rather than a tangible object, and is always the base class for other classes. A base class can be made into an ADT by initializing one or more of its methods with zero. These are known as “pure virtual methods” and must always be overridden in derived classes.

![](img/bf8dbdfb89042fadbaa73b4160c74bac_141_0.png)

**adt.cpp**

1. Start a new program by specifying the C++ library classes to include, and a namespace prefix to use.

```cpp
#include <iostream>
using namespace std;
```

2. Declare a base ADT class named `Shape`, containing three pure virtual methods.

```cpp
class Shape
{
    public:
        virtual int getArea() = 0;
        virtual int getEdge() = 0;
        virtual void Draw() = 0;
};
```

3. Declare a derived class named `Rect`, containing two private variables.

```cpp
class Rect : public Shape
{
    private:
        int height, width;
};
```

4. In the derived class declaration, insert a public constructor and destructor.

```cpp
public:
    Rect(int initWidth, int initHeight)
    {
        height = initHeight;
        width = initWidth;
    }

    ~Rect();
```

![](img/bf8dbdfb89042fadbaa73b4160c74bac_141_1.png)

It is illegal to create an instance object of an ADT—attempting to do so will simply create a compiler error.

5. In the derived `Rect` class declaration, declare three public methods to override the pure virtual methods declared in the `Shape` base class.

```cpp
int getArea() { return height * width; }
int getEdge() { return (2 * height) + (2 * width); }

void Draw()
{
    for (int i = 0; i < height; i++) {
        for (int j = 0; j < width; j++) {
            cout << "x";
        }
        cout << endl;
    }
}
```

6. Declare a `main` method containing a final **return** statement and creating two instances of the derived `Rect` class—to represent a Square and a Quadrilateral shape.

```cpp
int main()
{
    Shape* pQuad = new Rect(3, 7);
    Shape* pSquare = new Rect(5, 5);
    // Add more statements here.
    return 0;
}
```

![](img/bf8dbdfb89042fadbaa73b4160c74bac_142_0.png)

![](img/bf8dbdfb89042fadbaa73b4160c74bac_142_1.png)

7. In the `main` method, insert calls to each method, then save, compile, and run the program to see the output.

```cpp
pQuad->Draw();
cout << "Area is " << pQuad->getArea() << endl;
cout << "Perimeter is " << pQuad->getEdge() << endl;

pSquare->Draw();
cout << "Area is " << pSquare->getArea() << endl;
cout << "Perimeter is " << pSquare->getEdge() << endl;
```

![](img/bf8dbdfb89042fadbaa73b4160c74bac_142_2.png)

![](img/bf8dbdfb89042fadbaa73b4160c74bac_142_3.png)

A base class need only contain one pure virtual method to create an Abstract Data Type.

## Building complex hierarchies

It is sometimes desirable to derive an ADT from another ADT to construct a complex hierarchy of classes. This provides great flexibility and is perfectly acceptable, provided each pure method is defined at some point in a derived class.

![](img/bf8dbdfb89042fadbaa73b4160c74bac_143_0.png)

**hierarchy.cpp**

1. Start a new program by specifying the C++ library classes to include, and a namespace prefix to use.

```cpp
#include <iostream>
using namespace std;
```

2. Declare a base ADT class named `Boat`, containing a variable and accessor method together with one pure virtual method.

```cpp
class Boat
{
    protected:
        int length;
    public:
        int getLength() { return length; }
        virtual void Model() = 0;
};
```

3. Declare an ADT class (derived from the `Boat` class) named `Sailboat`—also containing a variable and accessor method together with one pure virtual method.

```cpp
class Sailboat : public Boat
{
    protected:
        int mast;
    public:
        int getMast() { return mast; }
        virtual void Boom() = 0;
};
```

4. Declare a regular class (derived from the `Sailboat` class) named `Laser`, in which all members will allow public access.

```cpp
class Laser : public Sailboat
{
    public:
};
```

![](img/bf8dbdfb89042fadbaa73b4160c74bac_143_1.png)

The `Boat` class has properties common to any boat, whereas the `Sailboat` class has properties specific to boats that have sails.

5. In the `Laser` class, insert a call to its constructor method to assign values to the variables in each class from which this class is derived—and call the destructor method.

```cpp
Laser() { mast = 19; length = 35; }
~Laser();
```

6. In the `Laser` class, define the pure virtual methods declared in each class from which this class is derived.

```cpp
void Model() { cout << "Laser Classic" << endl; }
void Boom() { cout << "Boom: 14ft" << endl; }
```

7. Declare a `main` method containing a final **return** statement and creating an instance of the derived class on the bottom tier of the hierarchy.

```cpp
int main()
{
    Laser* pLaser = new Laser;
    // Add more statements here.
    return 0;
}
```

8. In the `main` method, insert calls to each defined method.

```cpp
pLaser->Model();
cout << "Length: "
     << pLaser->getLength() << "ft" << endl;
cout << "Height: "
     << pLaser->getMast() << "ft" << endl;
pLaser->Boom();
```

9. Save, compile, and run the program to see the output.

## Isolating class structures

The source code for each example program in this book is generally contained in a single **.cpp** file to save space, but in reality OOP programs are often contained in three separate files:

- **Header .h file**—contains only class declarations.
- **Implementation .cpp file**—contains class definitions to implement the methods declared in the header file, which is referenced by an **#include** directive.
- **Client .cpp file**—contains a **main** method that employs the class members declared in the header file, which is also referenced by an **#include** directive.

![](img/bf8dbdfb89042fadbaa73b4160c74bac_145_0.png)

The client file is sometimes referred to as a “driver” file.

For example, a sum calculator program might comprise three files named **ops.h** (a header file declaring operation classes), **ops.cpp** (an implementation file defining the operation methods), and **sum.cpp** (a client file calling the various operations).

When compiling **sum.cpp**, the compiler incorporates the included header file and implementation file into the program. It first translates the header file and implementation file into a binary object file (**ops.o**), then it translates the header file and client file into a second binary object file (**sum.o**). Finally, the linker combines both object files into a single executable file (**sum.exe**).

![](img/bf8dbdfb89042fadbaa73b4160c74bac_145_1.png)

![](img/bf8dbdfb89042fadbaa73b4160c74bac_145_2.png)

Using an **#include** directive to reference a header file works in a similar manner to using an **#include** directive to reference a standard C++ library.

Isolating class structures in separate “modular” files has the advantage of improving portability and makes code maintenance easier by clearly identifying the purpose of each file.

To have the compiler combine all three source code files into a single executable file, it is only necessary to explicitly specify the **.cpp** files in the compiler command—an **#include** directive ensures the header file will also be recognized.

For example, with the statement `#include "ops.h"` in both **ops.cpp** and **sum.cpp**, the command to compile the example described below need not specify the **ops.h** header in the compiler command, but is simply:

```bash
c++ ops.cpp sum.cpp -o sum.exe
```
