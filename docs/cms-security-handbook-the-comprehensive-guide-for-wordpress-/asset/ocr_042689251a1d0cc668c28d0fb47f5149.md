Also, take the time to read and understand the documentation that came with the hardware and software products. If it says something to the effect of “*here’s the current password,*” then you can be sure the password is a default. Be sure to check the *database, administrative interface*, and any other passwords that give you control over the CMS site. If they are not difficult to guess, then change them.
