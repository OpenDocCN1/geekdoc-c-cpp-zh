provide you with a complete solution. With it, you can back up and restore an entire Drupal site. You can store the backup on a remote FTP server or Amazon S3, or e-mail your backup.

One particular feature that is especially useful is the capability to use AES encryption to protect your backup files.

# Requirements

The requirements for backup and restoration depend on the Drupal version you are using. The Files module requires the server to have PEAR and Archive_Tar installed.

This method has been tested with MySQL and Apache. Other environments are not covered in this book.

# Configuration

Follow the normal Drupal procedure for installing and enabling the modules.

> **NOTE** If you are not familiar with Drupal module installation, see `http://drupal.org/documentation/install/modules-themes`.

Portions of this module require cron to be run. Log in to cPanel and locate the Cron Job button. Click it and select Standard. The Standard Cron Manager page opens, as shown in Figure 6-16.
