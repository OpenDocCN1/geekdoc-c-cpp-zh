```
~~~
# RPM packages drop log rotation information into this directory
include /etc/logrotate.d

# no packages own wtmp and btmp -- we'll rotate them here
/var/log/wtmp {
    monthly
    create 0664 root utmp
        minsize 1M
    rotate 1
}

/var/log/btmp {
    missingok
    monthly
    create 0600 root utmp
    rotate 1
}
# system-specific logs may also be configured here.
~~~
```

This code instructs the system to wake up and rotate access logs weekly, and to only keep a rolling four weeks of logs. Each week, it is to compress the log file using the date as the suffix. Finally, the system is to create a new log. The rest of the log configuration file instructions handle the system's internal needs. The last line is in place to allow for other configuration options:

```
~~~
# system-specific logs may also be configured here.
~~~
```

> > **NOTE** The # sign in the configuration indicates a comment. The sign can appear anywhere in the file, as long as it's the first thing in the line.

# sample logrotate configuration file

/var/log/messages {
