# Updating Your Server

Updating your server may very well be a task your host has taken care of for you. Hosts such as Rochen.com handle the operating systems upgrades for you. Other hosts may handle it differently. If you are tasked with updating your operating system, then the update process is simple in most cases.

At the command prompt type `yum update` (for RedHat/Fedora/CentOS distributions of Linux). This will grab most of the patches necessary to keep your server running optimally and securely.
