# Requirements

Overall, if Zope is running after your install, then you have met all the requirements you need to do a basic Plone backup. Scripts are available to automate the backup and make it much easier than doing it manually. The main requirement you will need is the capability to log in to your server via SSH and use the tar and mv commands.

# Configuration

No configuration is required for the simple backup method described here.

# Backups

Plone stores its essential data in a few files. The idea is to back up the following files:

```
```text
/var/filestorage/Data.fs
/var/blobstorage
/products
```
```
