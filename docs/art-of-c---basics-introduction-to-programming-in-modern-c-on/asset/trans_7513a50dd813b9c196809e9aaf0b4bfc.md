### 类类型 (class)

#### 引用类型

定义为类的类型是*引用类型*。在运行时，当你声明引用类型的变量时，该变量包含值null，直到你显式地使用new运算符创建类的实例，或者给它赋一个兼容类型的对象（该对象可能在别处创建），如下例所示：

```
//Declaring an object of type MyClass.
MyClass mc = new MyClass();

//Declaring another object of the same type, assigning it the value of
//the first object.
MyClass mc2 = mc;
```

当对象创建时，会在托管堆上为该特定对象分配足够的内存，而变量仅持有指向该对象位置的引用。托管堆上的类型在分配时以及由CLR的自动内存管理功能（即*垃圾回收*）回收时都需要额外的开销。然而，垃圾回收也经过了高度优化，在大多数场景下，它不会造成性能问题。

#### 声明类

类通过使用class关键字后跟一个唯一的标识符来声明，如下例所示：

```
[access modifier] class identifier
public class Customer
{
    // Fields, properties, methods and events go here...
}
```

class关键字前是访问级别。因为此用例中使用了public，所以任何人都可以创建此类的实例。类名跟随class关键字。类名必须是有效的C#标识符。定义的其余部分是类体，其中定义了行为和数据。类上的字段、属性、方法和事件统称为类成员。

#### 创建对象

尽管类（class）和对象（object）有时可以互换使用，但它们是不同的事物。类定义了一种对象类型，但它本身不是对象。对象是基于类的具体实体，有时被称为类的实例。

可以通过在new关键字后跟对象所基于的类名来创建对象，如下所示：

```
Customer object1 = new Customer();
```

当创建类的实例时，对象的引用会传回给程序员。在上一个示例中，object1是基于Customer的对象引用。此引用指向新对象，但不包含对象数据本身。事实上，你可以创建对象引用而不创建任何对象：

```
Customer object2;
```

我们不推荐创建此类不引用对象的对象引用，因为试图通过此类引用访问对象会在运行时失败。但是，可以此类引用指向对象，方法要么是创建新对象，要么是将现有对象赋值给它，如下所示：

```
Customer object3 = new Customer();
Customer object4 = object3;
```
这段代码创建了两个对象引用，它们都指向同一个对象。因此，通过object3对对象所做的任何更改都会反映在随后使用object4时。因为基于类的对象是通过引用访问的，所以类被称为引用类型。

#### 类继承

类完全支持继承，这是面向对象编程的基本特征。当你创建一个类时，你可以继承自任何未定义为sealed的其他类，其他类也可以继承你的类并覆盖类的虚方法。此外，你可以实现一个或多个接口。

继承通过使用派生（derivation）来实现，这意味着类通过从其继承数据和行为的基类进行声明。通过在派生类名后附加冒号和基类名称来指定基类，如下所示：

```
public class Manager : Employee
{
    // Employee fields, properties, methods and events are inherited
    // New Manager fields, properties, methods and events go here...
}
```
当类声明了基类时，它继承基类的所有成员，构造器除外。

与C++不同，C#中的类只能直接继承自一个基类。然而，由于基类本身可能继承自另一个类，因此类可能间接继承多个基类。此外，类可以直接实现一个或多个接口。

类可以被声明为抽象的（abstract）。抽象类包含具有签名定义但没有实现的抽象方法。抽象类不能被实例化。它们只能通过实现了这些抽象方法的派生类来使用。相比之下，密封类（sealed）不允许其他类从其派生。

类定义可以分布在不同的源文件中。

### const 关键字 (const)

你使用const关键字来声明常量字段或常量局部变量。常量字段和局部变量不是变量，且不可修改。常量可以是数字、布尔值、字符串或null引用。不要创建表示你预期会随时变化的信息的常量。例如，不要使用常量字段来存储服务价格、产品版本号或公司的品牌名称。这些值可能随时间变化，并且由于编译器会传播常量，使用你的库编译的其他代码必须重新编译才能看到这些变化。

#### 备注

常量声明的类型指定该声明引入的成员的类型。常量局部变量或常量字段的初始化器必须是一个可以隐式转换为目标类型的常量表达式。

常量表达式是可以在编译时完全求值的表达式。因此，引用类型常量的可能值只有string和null引用。

常量声明可以声明多个常量，例如：

```csharp
public const double X = 1.0, Y = 2.0, Z = 3.0;
```
常量声明中不允许使用static修饰符。

常量可以参与常量表达式，如下所示：

```csharp
public const int C1 = 5;
public const int C2 = C1 + 100;
```

> readonly关键字与const关键字不同。const字段只能在字段声明时初始化。readonly字段可以在声明时或在构造器中初始化。因此，根据使用的构造器不同，readonly字段可以具有不同的值。此外，虽然const字段是编译时常量，但readonly字段可用于运行时常量，例如此行代码：public static readonly uint l1 = (uint)DateTime.Now.Ticks;
