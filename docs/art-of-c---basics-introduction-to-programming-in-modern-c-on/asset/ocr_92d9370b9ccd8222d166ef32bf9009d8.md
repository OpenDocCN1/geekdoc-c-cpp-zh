member `intM` to `internal`. In this case, you can instantiate the class, but you cannot access the internal member.

```
// Compile with: /target:library
public class BaseClass
{
    internal static int intM = 0;
}
```

```
// Assembly2_a.cs

public class TestAccess

    static void Main()
    {
        var myBase = new BaseClass(); // Ok.
        BaseClass.intM = 444; // CS0117
    }
}
```

# ## Is Operator (`is`)

The `is` operator checks if the result of an expression is compatible with a given type, or (starting with C# 7.0) tests an expression against a pattern.

# ### Pattern matching with `is`
