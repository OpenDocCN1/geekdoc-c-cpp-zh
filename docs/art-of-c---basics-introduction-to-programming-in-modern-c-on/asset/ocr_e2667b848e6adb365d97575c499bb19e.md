# 6.2. Code Reading - Check If the Given Year is a Leap Year

leap-year/LeapYear2.cs

```
```
namespace Example;

    static class LeapYear2 {
        internal static bool IsLeapYear(int year) {
            if (year % 400 == 0) {
                return true;
            } else if (year % 100 == 0) {
                return false;
            } else if (year % 4 == 0) {
                return true;
            } else {
                return false;
            }
        }
    }
```
```

And, the third implementation:

leap-year/LeapYear3.cs

```
```
namespace Example;

    static class LeapYear3 {
        internal static bool IsLeapYear(int year) {
            if (year % 4 == 0 && year % 100 != 0 || year % 400 == 0) {
                return true;
            } else {
                return false;
            }
        }
    }
```
```
