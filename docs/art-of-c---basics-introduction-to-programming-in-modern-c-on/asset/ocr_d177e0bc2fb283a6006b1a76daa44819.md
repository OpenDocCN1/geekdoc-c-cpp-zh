These preceding member declarations typically do not contain a body.

An interface member may declare a body. This is called a *default implementation*. Members with bodies permit the interface to provide a *default* implementation for classes and structs that don't provide an overriding implementation.

In addition, an interface may include:

+   - Constants
- Operators
- Static constructor
- Nested types
- Static fields, methods, properties, indexers, and events
- Member declarations using the explicit interface implementation syntax.
- Explicit access modifiers (the *default* access is *public*).

Interfaces may not contain instance state. While static fields are permitted, instance fields are not permitted in interfaces. Instance auto-properties are not supported in interfaces, as they would implicitly declare a hidden field. This rule has a subtle effect on property declarations.
