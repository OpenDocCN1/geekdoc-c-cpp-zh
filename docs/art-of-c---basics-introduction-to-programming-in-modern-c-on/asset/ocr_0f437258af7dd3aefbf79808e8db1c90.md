Here's an alternative type definition, `RPoint`, using `record class` for representing points in a two dimensional space.

euclid-distance/RPoint.cs (lines 3-21)

```
public record RPoint(float X, float Y) : IPoint, IComparable<RPoint> {  public float Radius() => (float)Math.Sqrt(X * X + Y * Y);  public int CompareTo(IPoint? other) => other is RPoint rp ? CompareTo(rp) : 1;  public int CompareTo(RPoint? other) => other is null ? 1 : (Radius() - other.Radius()) switch {     < 0 => -1,     > 0 => 1,     _ => 0, };  public static bool operator >(RPoint left, RPoint right) => left.Radius() > right.Radius();  public static bool operator <(RPoint left, RPoint right) => left.Radius() < right.Radius();  public static bool operator >=(RPoint left, RPoint right) => left.Radius() >= right.Radius();  public static bool operator <=(RPoint left, RPoint right) => left.Radius() <= right.Radius();  public IPoint Copy() => Copy((0, 0));  public IPoint Copy((float, float) delta) => new RPoint(X + delta.Item1, Y + delta.Item2);}
```

In fact, the (abstract) notion of a "point" can be encapsulated as follows, using `interface`. An interface in C# defines a set of "behaviors", but not "data".
