*leap-year/Program.cs*

```
```
using Example;

var isLeapYear = LeapYear1.IsLeapYear;

var years = new[] { 1900, 1984, 2000, 2022 };
foreach (var year in years)
{
  var ans = isLeapYear(year);
  Console.WriteLine($"Is {year} a leap year? {(ans ? "Yes" : "No")}");
}
```
