public readonly struct SNumeral {
    public static readonly SNumeral One = new(1);

    private readonly ushort number;

    public SNumeral(long number) => this.number = number switch {
        >= Constants.MIN and <= Constants.MAX => (ushort)number,
        _ => throw new ArgumentOutOfRangeException($"Roman numerals are between {Constants.MIN} and {Constants.MAX}"),
    };

    public SNumeral(string repr) =>
        number = NumeralHelper.Validate(repr) ?
        NumeralHelper.FromNumeralString(repr) :
        throw new ArgumentException($"Invalid Roman numeral: {repr}");

    public override string ToString() =>
        NumeralHelper.ToNumeralString(number);

    public override int GetHashCode() => number.GetHashCode();

    public override bool Equals(object? obj) => obj is SNumeral snum
        && number == snum.number;

    public static bool operator ==(SNumeral l, SNumeral r) =>
        l.Equals(r);

    public static bool operator !=(SNumeral l, SNumeral r) =>
        !l.Equals(r);
}

roman-numerals/NumeralHelper.cs (lines 5-9)

```csharp
static class NumeralHelper {
    private static Regex RnRx = new(
        @"^M{0,3}(CM|CD|D?C{0,3})(XC|XL|L?X{0,3})(IV|IV|V?I{0,3})$",
        RegexOptions.Compiled | RegexOptions.IgnoreCase);

    internal static bool Validate(string repr) => RnRx.IsMatch(repr);
}
```

The `Validate()` helper method that does the roman numeral validation uses the "regular expressions". We will not discuss the regular expressions in this book. They are supported pretty much across all different programming languages, and their uses are more or less the same.

If you are not familiar with regular expressions, then you can ignore this part. Or, you can look up the .NET reference manual on the Web.

roman-numerals/NumeralHelper.cs (lines 11-30)

```csharp
internal static ushort FromNumeralString(string repr) {
    var number = 0;
    
    char p = '\0';
    foreach (var c in repr) {
        number += c switch {
            'M' or 'm' => (p == 'C' || p == 'c') ? (1000 - 2 * 100) : 1000,
            'D' or 'd' => (p == 'C' || p == 'c') ? (500 - 2 * 100) : 500,
            'C' or 'c' => (p == 'X' || p == 'x') ? (100 - 2 * 10) : 100,
            'L' or 'l' => (p == 'X' || p == 'x') ? (50 - 2 * 10) : 50,
            'X' or 'x' => (p == 'I' || p == 'i') ? (10 - 2 * 1) : 10,
            'V' or 'v' => (p == 'I' || p == 'i') ? (5 - 2 * 1) : 5,
            'I' or 'i' => 1,
            _ => 0
        };
        p = c;
    }
    
    return (ushort)number;
}
```

```csharp
internal static string ToNumeralString(ushort number) {
    var sb = new StringBuilder();

    while (number > 0) {
        if (number >= 1000) {
            sb.Append(number switch {
                >= 3000 => "MMMM",
                >= 2000 => "MMM",
                _ => "M",
            });
            number %= 1000;
        } else if (number >= 100) {
            sb.Append(number switch {
                >= 900 => "CM",
                >= 800 => "DCCC",
                >= 700 => "DCC",
                >= 600 => "DC",
                >= 500 => "D",
                >= 400 => "CD",
                >= 300 => "CCC",
                >= 200 => "CC",
                _ => "C",
            });
            number %= 100;
        } else if (number >= 10) {
            sb.Append(number switch {
                >= 90 => "XC",
                >= 80 => "LXXX",
                >= 70 => "LXX",
                >= 60 => "LX",
                >= 50 => "L",
                >= 40 => "XL",
                >= 30 => "XXX",
                >= 20 => "XX",
                _ => "X",
            });
            number %= 10;
        } else {
            sb.Append(number switch {
                >= 9 => "IX",
                >= 8 => "VIII",
                >= 7 => "VII",
                >= 6 => "VI",
                >= 5 => "V",
                >= 4 => "IV",
                >= 3 => "III",
                >= 2 => "II",
                _ => "I",
            });
            number = 0;
        }
    }
    return sb.ToString();
}
```

These two static methods, FromNumeralString() and ToNumeralString(), implement conversions from a number (ushort) to its Roman numeral string representation, and vice versa. They can be implemented in a number of different ways.

In this example, we use the most straightforward implementations. The readers are encouraged to go through these two methods to see if they make sense.

The idea is the same as, or very similar to, that from one of the earlier lessons, in which we converted numbers between two different bases, e.g., 10 and 32 (Base 32 numbers). The Roman numerals have a rather unique system of representing numbers unlike the number systems that we currently use.

The constants that are common to all four types are included in this small static class, for convenience. Normally, these constants would have been a part of a type definition, but in this example they are shared across four distinct types (which are essentially identical to one another other than the implementation details).
