# # 1.3. Code Reading - A New C# Project

One can use the IDEs like Microsoft's Visual Studio or JetBrains Rider for developing C# programs. Although it is not strictly necessary, most IDEs, and the <code>dotnet</code> CLI tool, use the “projects” to manage the C# programs, and their library dependencies, etc.

We will use the <code>dotnet new</code> command to create a project in this lesson. For example,

```
dotnet new console
```

This command (in an empty folder) creates a “console app” project. .NET supports a few different languages such as F# and Visual Basic, but C# is the default, and the above command, without any options, creates a C# project.
