Regardless of which the Boolean value is specified, it needs to appear in parentheses. This Boolean is the condition of the conditional statement.

Always put curly braces around the result of the if clause, even if there's only one command. If you leave off the curly braces and add another command as part of the if statement, it's easy to forget the curly braces. Get in the habit of using curly braces for the if clause to avoid problems later on.

Suppose you want to determine whether someone has a discount and give them a message that they are eligible for the discount.

You can do this with an if statement. You write if, followed by parentheses and your Boolean expression: It will be true if the age is less than 18 or equal to 65. Then you write your commands, starting with curly braces, and then our output: You're eligible for a discount!

Then, the after will be followed by the Boolean value is true; that is, the command that follows the if statement only executes if Boolean value evaluates to true.

If there's just a simple command to execute, then you can write that command, just like any other.

If you run this program and enter a valid age, such as 10 or 70, you'll get the message printed out. If you enter some other age, such as 45, you won't.

+   There are 3 ways to write this:
1 It could be written right after the parentheses on the same line.
2 It could be written on the next line. If this is done, it is common to indent the command from 2 to 4 spaces. Indenting this is a way of showing (to people) the command only gets executed if the if statement is true.
3 Probably the most option is to put curly braces around the command, the computer does read the curly braces, and what they mean is everything inside of the curly braces counts as the thing to do if the Boolean is true. That way, you can have lots of commands—not just one—executed when the Boolean is true. When doing this, it is again to indent each of the commands that should be executed to show they're only encountered when the Boolean is true. The closing of curly braces is commonly put on a new line, indented.

int age;
cout << "Enter your age: ";
cin >> age;
if (age < 18) || (age >= 65) {
cout << "You're eligible for a discount!" << endl;
}
