# // LISTS AND ITERATORS

While these 4 containers work for adding
and removing new elements at the ends,
 you want to insert or delete elements at
arrary points, then a container called a list is
particularly useful.

An iterator is a new type that you can use for
variables. When you declare an iterator,
you first get the container (such as a vector
of integers or a list of floats) that it will iterate
over, then ::; and then the keyword iterator.
This defines the type of variable you're
declaring.

But to understand how to use lists, you
need to understand iterators.

You've encountered the idea of iterating
through a vector. You usually have some index,
so as i, that you put in a for loop let
take from 0 to 1 less than the vector
length. So, you can access element 0, then 1
then 2, and so on, until the end of the vector.

For example, in Program 22_4, you declare
a vector of integers where you push 3 values
to the back: 10, 20, and 30 (c).

An iterator is a more general form of that
index. It works like a pointer to the element in
a container.

Next, you can create an iterator that can iterate
over a vector of integers using my_iterator.
So, you write <int>::my_iterator my-
iterator (12). When, you can think of this as
being like a pointer to an element of a vector
of integers.

To use an iterator, you would start at the
beginning of the vector and then access
element element until you reached the
. For a container, you can get a begin
iterator, which points to the first element.
You can increment the iterator so that it goes
the next element, then the one after that, and
so on, all the way through. You can
stop when you reach the end, which will be
after the last element in the container.

You initialize this by assigning the iterator
to the beginning of the container. For your
vector, and for many other containers, the
member function begin return an iterator
at the first element in the container. In the code,
you write my_iterator = v.begin() (13).

There's also an end function associated with\most containers, and it indicates a value after
t last element in the container. In other
words, there's not an element at the "end";
is not pointing to the last element, but instead
to some part of memory that you don't care

about, other than to know you're no
longer in the container. So, in your code, you'nngo going as long as you're not at the end.
So, you write while (my_iterator) != v.end
() (14).
