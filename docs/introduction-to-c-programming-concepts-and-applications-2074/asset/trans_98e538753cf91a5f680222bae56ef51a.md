

你可以使用 size 来遍历向量的所有元素，就像你遍历数组元素的方式一样。

对于每个值，你输出向量的元素，就像你对数组所做的那样。你写 cout << v[i] << " " 。然后跟上一个空格。现在你不输出 endl，所以所有元素会出现在同一行。只有在循环结束时才流式输出 endl (15)。

```
// Program 8_7
// Printing all vector contents using size
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<float> v;
    v.push_back(10);
    v.push_back(20.0);
    for (int i = 0; i < v.size(); i++) {
        cout << v[i] << " ";
    }
    cout << endl;
}
```

在 Program 8_7 中，你声明了一个 float 向量（浮点值），然后 push_back 3 个不同的浮点值 (B)。因此，你应该有一个大小为 3 的向量。

要输出向量的内容，你创建一个循环 (c)。你使用一个索引 i，它将被初始化为 0，只要它小于向量的大小。因此，在这种情况下，因为向量大小为 3，它应该具体取 0、1 和 2。

输出显示 3 个值：你 push 进向量的 3 个值，按你 push 的相同顺序。

## // VECTOR SIZE INITIALIZATION

```
// Program 8_8
// Vector size initialization
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    cout << "Initial vector: ";
    for (int i = 0; i < v.size(); i++) {
        cout << v[i] << " ";
    }
    cout << endl;
}
```

尽管向量的大小可以改变，你可以在创建时指定向量的初始大小，就像对数组所要求的那样。要做到这一点，你在向量名称后立即在括号中放入你想要向量具有的大小。注意这里你使用的是括号，而不是像数组中那样的方括号。

因此，如果你想要一个名为 v 的 float 向量，大小为 3，你可以这样声明它：vector<int>(3)。这将创建一个包含 3 个元素的向量，它们都将被初始化为 0。

当你运行 Program 8_8 时，你会看到，确实，向量有 3 个元素，它们都被初始化为值 0。

向量还有另一种可以用来初始化它们的方法。想象一下，如果你想要一个包含 1000 个元素的大向量，并且你希望它们全部具有某个初始值，比如 10。一个选项是使用大括号并在其中放入 1000 个值。那会是输入的巨大痛苦！

```
vector<int> v(3, 10);
```

这个例子展示了你创建一个大小为 3 的向量，所有元素都初始化为 10。输出向量验证了它确实按预期工作。

以下行声明了一个名为 accounts 的 float 向量，初始大小为 4：

```
vector<float> accounts(4);
```

如果你想要向量用每个账户余额 $100 初始化，你会通过写以下行来更改初始化：

```
vector<float> accounts(4, 100.0);
```

回想一下，你可以通过指定用大括号括起来的初始元素集来初始化数组。你可以在声明向量时做同样的事情。在声明之后，你想要在你之后使用大括号，现在向量就用这些值初始化了。

现在运行 Program 8_9，你声明一个 int 向量 v 并通过添加 = {1, 2, 3} 来初始化它。这将导致向量有 3 个元素，值分别为 1、2 和 3。注意你不需要显式设置向量大小；当你打印出向量时，你会看到它确实有 3 个元素，值分别为 1、2 和 3。

现在你有一个 2 参数值，括号中有 2 个值。第一个是大小 4，第二个是要初始化为的值，100。

这被称为构造函数函数——在变量首次声明时调用以初始化变量的函数。因为它是一个函数，所以有括号和可能的 arguments。对于现在，只需认为构造函数提供了一种很好的初始化向量的方法。

## // VECTOR RESIZING

向量的一个不错特性是它们可以改变大小。你已经看到了一种这样做的方法——使用 push_back 成员函数。当你使用它时，你在向量的末尾添加一个元素，使其大小增加 1。

当你调用 resize 时，如果新大小大于旧大小，则会创建新元素并用值 0 初始化它们。如果新大小小于旧大小，则向量的最后元素将被移除。

另一种调整向量大小的方法是使用成员函数 resize。要调整名为的向量的大小，通过一个点，通过对 resize 的调用。你可以给出一个参数，即你想要向量的新大小。

Program 8_11 是调整向量大小的示例。在声明一个名为的向量之后，你在该向量上调用 resize，参数为 5。这将导致向量大小变为 5 而不是 0。并且在调整大小后，你打印出向量元素，之后看到 5 个元素，每个值都为 0。

// Program 8_12
// Vector resizing and initializing
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v(3);
    v.resize(5, 1);
    cout << "Vector resized : ";
    for (int i = 0; i < v.size(); i++) {
        cout << v[i] << " ";
    }
cout << endl;
}

// Program 8_11

cout << "Vector resized : ";

```

resize 函数还有另一个版本，接受 2 个参数 (Program 8_12)。就像初始化构造函数可以接受 1 个参数，只指定大小，或 2 个参数，第一个指定大小，第二个指定元素的初始值，你在这里有同样的情况。

这个例子有两个部分：首先，你创建一个初始大小为 3 的向量。因为你没有指定任何初始值，该向量将有 3 个元素，每个值都为 0。
接下来，你有一个命令 v.resize(5,1)，它将向量大小调整为 5。并且向量的新元素将被初始化为值 1。因此，当你打印向量的元素时，你会看到 5 个元素，前 3 个值为 0，最后 2 个值为 1。

## // PERFORMING OUT-OF-BOUNDS CHECKS

就寻址整体数据结构内部的单个元素而言，向量可以像数组一样使用。你已经看到几个使用方括号访问单个元素的例子。在最后几个打印元素的循环中，你都用方括号访问了元素。

但有一个问题你必须小心避免访问数组元素：数组越界错误，当你访问未分配给数组或向量的元素时会发生。

当你使用 at 而不是方括号时，它会自动检查数组的边界。如果你尝试访问不应存在的元素，你将得到一个异常，即错误代码。如果在这个情况下出现异常，程序就会停止。如果你访问不应该的内存，让设置不应该的内存值，并且不会打印出你的内存值包含无意义的内容。

使用方括号访问向量的元素与数组的工作方式完全相同——好的一面和坏的一面。好的一面是它高效，你可以直接访问下一个元素。因为所有数据都分配在一个连续的内存块中，所以计算机可以高效地处理它。

在 Program 8_13 中，你有一个向量已用 3 个元素初始化，值分别为 1、2 和 3。然而，在你打印元素的循环中，你正在打印 v[3] 和 v[4]，它们实际上不存在。

```
// Program 8_13
// Vector ERROR indexing out of bounds
#include <iostream>
#include <vector>
using namespace std;

int main() {
  vector<int> v = {1, 2, 3};
  for (int i = 0; i < 5; i++) {
    cout << v.at(i) << " ";
  }
  cout << endl;
}
```

就像数组一样，代码让你这样做；没有什么能阻止你这样做。但当你运行代码时，谁知道你会得到什么？通常，那些不存在的元素将具有内存位置中留下的任何值，你无法保证那是什么！

但对于向量，有一种方法可以避免此错误发生：不要使用方括号访问元素，你可以使用成员函数 at。

```
#include <vector>
```

要使用此方法，你使用向量名称，后跟一个点，然后在括号中放入你想要访问的元素编号。这基本上是之前代码，但现在你使用 .at 和括号，而不是方括号，来访问元素。

当你运行此代码时，你会得到 3 个元素的输出。你有一个 for 循环，在其中尝试打印从 0 到 4 的每个元素，从一个大小为 3 的向量。打印元素 0、1 和 2 都没问题。然而，当你尝试打印 v[3] 时，它将越界。因为你使用的是 at 函数而不是方括号，程序将在这一点停止。它将以异常代码退出。
