Having choices opens up possibilities, and conditionals are ways to make choices in programs. They offer a way of saying: “If this set of conditions is met, then do this.” These choices allow you to have much more interesting and varied programs. In order for you to have a conditional, though, you need a way of specifying what a condition is. And to do this, you need a way of saying that a value can be true or false. A variable defined as being true or false is Boolean, named for George Boole, who developed a way to simplify logic.

# // BOOLEAN VARIABLES

You already know that you can have variables of an integer type and variables of a floating-point decimal type. You can also have logic variables that are Boolean type. In C++, you can declare these variables to be of bool, with a value of either true or false.

In this example, there are 2 Boolean variables: one called test_true that you initialize to the value true and one called test_false that you initialize to the value false.

Although there are 2 keywords—true and false—C++ ultimately reads them as just the 2 possible values of a single bit.

When your program runs, the true value gets output as 1, and the false value gets output as 0.

true and false are defined keywords in C++.

```cpp
// Program 3_1
// Illustrating Boolean values
#include <iostream>
using namespace std;

int main() {
    bool test_true = true;
    bool test_false = false;
    cout << "test_true is: " << test_true << endl;
    cout << "test_false is: " << test_false << endl;
}
```

# Program 3_2

One thing to think about is that a Boolean variable can only take 2 values: true or false. In a computer, a bit can also have 2 values: 1 or 0. So once your code has been compiled into a set of machine instructions, those variables declared as Booleans could be stored in 1 bit. And you'll use a 1 to represent true and a 0 to represent false.

The operations you can do on Boolean variables are also different. You don't add, subtract, multiply, or divide. Instead, for Booleans, there are 3 main operations: and, or, and not. They work in the same way that you might see in a logic course.

> Notice that you put ! before the Boolean value that you want to be not.

There are no true or false values, just 0 or 1. C++ interprets any value that is not 0 as true. In Program 3_2, the variable test_true is assigned the value true. But when you print out, you see that the variable has the value 1—that is, true.

In Program 3_3, you have 2 variables, with raining being true and windy being false. If you take raining and windy, you get the opposite values for each one—that is, false and true, respectively. The not operation flips the Boolean value: true becomes false, and false becomes true.

In C++, you use ! to represent not. For example, !raining means "not raining" and !windy means "not windy". The and operation is used when you have two different Boolean values—say, x and y. In logic, if you say "x and y," then that statement is true.

# // Program 3_3
// Any non-zero value is interpreted as true
// Using ! (not) to reverse Boolean value
#include <iostream>
using namespace std;

int main() {
    bool test_true = true;
    bool test_false = false;
    cout << "test_true is: " << test_true << endl;
    cout << "test_false is: " << test_false << endl;
}

#include <iostream>
using namespace std;

int main() {
    bool raining = true;
    bool windy = false;
    cout << "raining is: " << raining << endl;
    cout << "windy is: " << windy << endl;
    cout << "Not raining is: " << !raining << endl;
    cout << "Not windy is: " << !windy << endl;
}

> Be careful to use ampersands to indicate and; you use only one, that's known as bitwise and, and that's not what you want. The or operation takes 2 Boolean values, but it is true if either one of them is true. It's also true if both are true. In C++, or is represented with ||.

# // COMPARISON OPERATORS

One of the most common ways of determining a Boolean is true or false is with comparison operators. When you compare 2 values in C++, the result is a Boolean—either true or false. You can assign the result of the comparison to a Boolean variable, such as by writing TeamWinner = (Team1Points > TeamPoints). Or you can use a comparison in a Boolean expression, such as by writing (heartrate > 100) || (respiration > 30).

Program 3_7 shows several comparisons. You have two variables, Team1Points and TeamPoints, initialized to some values—in this case, 17 and 20, respectively. You can compare to see if Team1Points is less than Team2Points using <. The answer is true, and the output will show a 1. The same is true if you use a less-than-or-equal-to (<=) comparison. You can also make a greater-than (>) or greater-than-or-equal (>=) comparison. In this case, the answer will be false, because TeamPoints is not greater than, or greater than equal to, TeamPoints.

```cpp
// Program 3_7
// Comparisons: less than/greater than to give a Boolean result
#include <iostream>
using namespace std;

int main() {
    int Team1Points = 17, Team2points = 20;
    cout << (Team1Points < Team2points) << endl;
    cout << (Team1Points <= Team2points) << endl;
}
```

You often want to see if two things have the same value or don't have the same value. For this, you need equality and inequality operators:
- To check whether things are equal, use ==.
- To check for inequality, use !=.

```cpp
// Program 3_9
// Illustrating comparisons to create a Boolean value
#include <iostream>
using namespace std;

int main() {
    int age;
    cout << "Enter your age: ";
    cin >> age;
    bool eligible_for_discount;
    eligible_for_discount = (age < 18) || (age >= 65);
    cout << eligible_for_discount << endl;
}
```

Let's say that you're operating a business and want to give a discount to anyone under 18 or anyone who is 65 or older. After reading an age, you can set a Boolean variable, eligible_for_discount, using this:
```cpp
eligible_for_discount = (age < 18) || (age >= 65);
```

This Boolean variable eligible_for_discount will be true either if the age is less than 18 or the age is greater than or equal to 65—otherwise, it will be false.

# # CONDITIONAL STATEMENTS

The real power of Boolean values and expressions comes when you get them into conditional statements. A common term for a conditional statement is an if-then-else statement. The simplest form is the if-then statement. A conditional statement starts with the keyword if. Next, in parentheses, is a single Boolean value. The Boolean value could come in many forms. It could be a simple value, such as true or false, but the value is more likely to be given by a Boolean variable—or even a Boolean expression, made up of comparisons and Boolean operations.

```cpp
if (true) // simple Boolean value
if (isFreezing) // Boolean variable
if ((age < 18) || (age >= 65))
// Boolean expression
```
