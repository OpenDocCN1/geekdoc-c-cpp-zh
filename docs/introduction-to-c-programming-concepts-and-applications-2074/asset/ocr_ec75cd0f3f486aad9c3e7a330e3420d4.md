# C++ Loops and Iteration

Programmers use loops to get the computer to do one of the things it's best at and that people tend to dislike—mere repetition. Loops make it possible to repeatedly execute the same code over and over. There are 2 main types of loops: the basic while loop and the for loop, which is a compact way to make the while loop happen a set number of times.

# WHILE LOOPS

This is for computing a balance from a loan where there is interest accumulated and payments made.

You begin by initializing the status to a $1000 balance, each period you incur interest of 5% and make a payment of $100 (14).

Then, you check to see if you have a balance (11). If you do, you incur, adding the interest onto the balance (12), by making a payment (13). You increase a count on how many payments have been made, which is just (14). And you print out what the balance after that payment is made (15).

That's only for 1 payment. Obviously, you're going to need more than 15 payments to pay off the loan, so you can repeat that if statement over and over. You'd have to copy and paste code for each payment you wanted. If you do this, you will need more than 15 payments—which more than 100 lines of code—to pay off the loan.
