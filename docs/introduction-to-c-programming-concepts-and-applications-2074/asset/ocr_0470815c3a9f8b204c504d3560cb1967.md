One to think about this is that Boolean variable can only take 2 values: true or false. In a computer, a bit can also have 2 values: 1 or 0. So once your code has been compiled into a set of machine instructions, those variables declared as Booleans could be stored in 1 bit. And you'll use a 1 to represent true and a 0 to represent false.

The operations you can do on Boolean variables are also different. You don't add, subtract, multiply, or divide. Instead, for Booleans, there are 3 main operations: and, or, and not. They work in the same way that you might see in a logic course.

> Notice that you put ! before the Boolean value that you want to be not.

There are no true or false values, just 0 or 1. In C++ interprets any value that is not 0 as true. In Program 3_2, the variable test_true is assigned the value 2. But when you print out, you see that the variable has the value 1-that is, true.

In Program 3_3, you have 2 variables, with raining being true and windy being false. If you take raining and !windy, you get the opposite values for each one—that is, false and true, respectively.

The not operation flips the Boolean value: true becomes false, and false becomes true.

In C++, you use ! to represent not. For example, !raining means "not raining" and !windy means "not windy".

The and operation is used when you have two different Boolean values—say, x and y. In logic, if you say "x and y," then that statement is true
