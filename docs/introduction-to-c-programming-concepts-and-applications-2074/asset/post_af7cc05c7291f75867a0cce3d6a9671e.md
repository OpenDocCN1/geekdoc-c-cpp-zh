## // STACKS

If you want to keep track of a set of actions so that you can undo back to any point, you can do this using a very basic container adapter that provides one of the most basic operations in computing. This is the stack, which is called a LIFO (last, first out) structure. It means that the last thing you put on the stack is the first thing that comes out of it.

In this Program 22_1, notice that you #include stack at the beginning of the program (4).

Then, in your main program, you declare a stack, s. Because the stack is a generic container, you have to give it a particular type—in this case, the integer type. So, you write stack and then int in angle brackets, and then you give the name of the stack variable, in which this case is s (8).

```
// Program 22_1
// Stack example
#include <iostream>
#include<stack>
using namespace std;
int main() {
stack<int> s;
s.push(10);
s.push(15);
s.push(20);
while (!s.empty()) {
cout << s.top() << endl;
s.pop();
}
```

In C++, you can declare a stack of some particular type and perform one of a few operations. There are 4 main operations that you need to get just about everything you need with a stack:

- - push adds a new element to the top of the stack.
- top is used to see what element is on top of the stack.
- pop removes the top element from the stack (whatever it is),
- empty returns a Boolean value that tells you whether or not the stack is empty.

> Remember that the angle brackets are the way of specifying a particular type—the type that will replace the template in the class definition.

Once by pushing 3 values onto the stack: 10, 15, and 20; that is, you use the member push function and push the values 10, 15, and 20 as arguments. This will create a stack that has 10 first so it's on the bottom, 15 on top of that, and 20 on top of that (a).

For each iteration of the while loop, you do 2 things. First, you top whatever is on top, using the top member function to access that top element (13), then reducing the size of the stack by 1, use the pop command (14).

Like most classes in the STL, there are also a few other functions defined, such as a size function giving the size of the stack, but these 4 are the only ones you need on a regular basis.

Next is a loop that continues as long as the stack is not empty. You use is.empty() as the condition for the while loop (12).

And if you run this code, you see the numbers printed off in reverse order.

## // QUEUES

An alternative container adaptor gives you a FIFO (first, first out) data structure. This is called a queue, and it's much like the stack, but instead of the last thing being the one you can access, it's the first thing in. Queues used to represent any sort of process where the first thing into the line is the first thing you want out.

You can push the numbers 10, 15, and 20 into the queue (b), just like you pushed into the stack, and you can have a loop that continues as long as the queue isn't empty (12).

Inside the loop, you'll print the element at the front by using the front function and outputting q.front() (13). Then, remove that front element by calling pop (14).

- It has 4 operations, like the stack did:
* push adds an element to the end of the queue.
* front tells you which element is in the front of the line (analogous to top from the stack commands).
* pop removes the element at the front of the queue.
* empty tells you if the queue is empty or not.

And you see that the elements came off in the same order you put them in.

In addition to the stack, and queue, another container is the deque (short for double-ended queue).

A deque works a lot like a vector. It's just instead of having push_back and pop_back, it has push_front and pop_front, too. It has basically all the operations that a vector has. You can get the size using size or make it empty using clear. You can access elements using square brackets with the element number or using the at command that you can guarantee you're not reading or writing past the end of the allocated memory.

In Program 22_2, notice that you now #include queue at the beginning (4).

In the main body of the code, you declare a queue, where the type that you want the queue to hold is an integer. So, you write queue<int> and then the name of the queue, which in this case is q (8).

But it's less efficient than a vector, and there is rarely an instance where you all the extra functionality that a deque provides.

```
// Program 22_2
// Queue example
#include<iostream>
#include<queue>
using namespace std;
int main() {
    queue<int> q;
    q.push(10);
    q.push(15);
    q.push(20);
    while (!q.empty()) {
        cout << q.front() << endl;
        q.pop();
    }
}
```
