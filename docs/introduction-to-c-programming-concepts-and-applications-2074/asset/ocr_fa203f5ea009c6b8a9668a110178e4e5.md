Although computers were originally developed to deal mainly with numbers, it quickly became obvious that representing text, including letters and punctuation, was just as important. You've been using text for output in many of your count statements, and you've seen ways of putting text in double quotes and then streaming that text to the console. The term for text like this—a collection of letters, numbers, punctuation, spaces, etc., all string together—is string.

# // STRING VARIABLES AND LITERALS

Up now, you've been using string literals—specified values of some type. Just like you can have variables let you store and manipulate Boolean values, you would also like to have variables let you store and manipulate strings. To do this, you use a new type of variable—the string. String variables are the main way you use and manipulate text data.

Unlike int, float, and bool, a string is not a built-in language type. To have a string type, you're going to bring in a new library, the string library. Once you've done that, you can declare string variables, just like you declare other types.

Think of a literal as being in contrast to a variable. A variable can potentially be any value of a certain type; a literal is some specific value.

If you have a variable x and a line of code like x = 5, x is a variable while 5 is a literal. If you stream 3.14 to cout, you're streaming a floating-point value. Or, if you assign 3.14 to a floating-point variable f, then you're printing a variable.
