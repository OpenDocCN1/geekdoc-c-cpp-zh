```
// Program_10_4
// Use of the eof function in a while loop
#include <fstream>
#include <iostream>
#include <string>
using namespace std;

int main() {
    fstream my_file;
    my_file.open("GroceryList.dat");
    string s;
    while (!my_file.eof()) {
        cout << s << endl;
    }
    my_file.close();
}
```

The eof function is helpful in a while loop. You set up a loop that continues until the end-of-file, where the eof function returns true (a). This loop will read every string from a file and output it to the console.

Whether you are checking the while for the first time or completing an iteration of the loop, you're always trying to read a string before checking EOF. If you fail to read a string, that is is EOF true when you check.

Note that the eof-file is not true when you read the last line in the file; it will still be false after reading that item. Only after you've tried to read again and there's nothing left to read will eof be true.

Notice that while loop is basically for loop. Where you read an initialization step, where you read one string; with a condition, making that eof is false; each iteration of the loop, you read one more string.

So, in Program 10_4, notice that you to read a string from the file before you get to the while loop; then you read a string again as the last thing inside the loop (b).

So, you can write this using a for loop (c), which describes how the loop behaves in one statement.
