You can use the size to loop through all the elements of a vector, in the same way you would loop through the elements of an array.

For each value, you output the element of the vector, just like you would have done for an array. You write cout << v[i] << " " . Then it is followed by a space. Now you do not output an endl, so all elements will appear on the same line. Only at the end of the loop do you stream an endl (15).

```
// Program 8_7
// Printing all vector contents using size
#include <iostream>
#include <vector>
using namespace std;

int main() {
    float v;
    v.push_back(10);
    v.push_back(20.0);
    for (int i = 0; i < v.size(); i++) {
        cout << v[i] << " \;
    }
    cout << endl;
}
```

In Program 8_7, you declare a vector of floats (floating-point values) and then push_back 3 different floating-point values (B). So, you should have a vector of size 3.

To output the contents of the vector, you create a loop (c). You use an index i that will be initialized to 0 as long as it is less than the size of the vector. So, in this case, because the vector is size 3, it should take on—specifically, 0, 1, and 2.

The output shows 3 values: the 3 you pushed into the vector, in the same order you pushed them.

# // VECTOR SIZE INITIALIZATION

```
// Program 8_8
// Vector size initialization
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    cout << "Initial vector: " \;
    for (int i = 0; i < v.size(); i++) {
        cout << v[i] << " " \;
    }
    cout << endl;
}
```

Although the size of vectors can change, you can specify a vector's initial size at the time of creation, like were required to do for an array. To do this, you put the size you want the vector to have in parentheses right after the name of the vector. Note that you use parentheses here, not square brackets, like in an array.

So, if you want a vector of floats named v of size 3, you can declare it by writing vector<int>(3). This will create a vector of 3 elements, which will all be initialized to 0.

When you Program 8_8, you will see that, indeed, the vector has 3 elements and they are all initialized to the value 0.
