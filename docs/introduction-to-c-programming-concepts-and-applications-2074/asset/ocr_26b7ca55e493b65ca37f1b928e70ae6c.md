So, implementing the gameboard class itself is just a matter of
declaring a class and creating a few pure virtual functions. Because
you're not providing any implementation of those functions in this
class, there's nothing more to define.

But according to the definition of your virtual function, you are
sosed to be passing in a connect4_move pointer; it's supposed
to a gamemove pointer! However, gamemove on its own doesn't
have the specific member functions you need, as getting the
column number. So, what you need is a connect4_move pointer and
what you implement is a gamemove pointer.

```
class gameboard {
public:
  virtual void print_board()=0;
  virtual int check_winner()=0;
  virtual void take_turn(gamemove+)=0;
};
```

To get from the gamemove pointer to the connect4_move pointer,
y can simply convert your gamemove to a connect4_
move pointer, just like you would other type conversions: You then,
every can be called like you'd done.

Let's consider one of the implementations. The connect4_
board implements the board for playing Connect 4. The
operations provided here mirror those of the Connect 4 game that
was developed in lecture 15. In fact, the code is almost identical
in many places, with the only differences being that you can use
member variables for the board and the number of rows and
columns, rather than passing information through parameters.

```
void take_turn(gamemove+) {
  take_turn(connect4_move+);
}
```

Notice that you have a routine, take_turn, which has a parameter
at a connect4_move pointer. The routine is itself
straightforward; it uses the accessor functions provided in the
connect4_move class to get the player who make the move and the
column and updates board appropriately.
