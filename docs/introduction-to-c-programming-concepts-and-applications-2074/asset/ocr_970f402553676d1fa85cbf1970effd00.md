# // RANDOM NUMBERS

Suppose you want to develop a guessing game in which the computer picks numbers and the user has to guess the number picked.

To do this, you need a function that lets you get a random number. Random number generation is actually a tricky problem—it's nearly impossible to generate truly random numbers with a deterministic computer—but the key is to use pseudorandom numbers, which seem like random numbers and are just useful for most applications.

In this case, C++ has 2 standard libraries that will generate numbers. One of them is called random, but it's complicated to use. An easier-to-use library is the C Standard Library, cdblib, which includes the widely used function rand, which does not take any arguments and returns an integer. The integer will be some number between O and maximum-possible random number.

```
int main() {
    int x = rand();
    cout << "The random number is " << x << endl;
n}
```

To generate a random number, you have a simple program that you can generate by #including the cdblib header. Then, you can use the function rand, with no arguments, in the code to give you an integer.

| // Program 6_8 |

When you have #includes, the library file you're including is in brackets < >. An alternative to this is to use quotation marks. The code works exactly the same.

If you run Program 6_7, you will see that a random number is generated.

You can generate more random numbers by calling the rand function multiple times. Every time you get a new integer. In Program 6_8, 3 random numbers are generated.

Generally, the convention is to use brackets for things that are in the C++ Standard Library and quotation marks for other libraries or files you're using.

```
int main() {
    int x = rand();
    cout << "The random number is " << x << endl;
    cout << "Here is another random number: " << rand() << endl;
}
```
