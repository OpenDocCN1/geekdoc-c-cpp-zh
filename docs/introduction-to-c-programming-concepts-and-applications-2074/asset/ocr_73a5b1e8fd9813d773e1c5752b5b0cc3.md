There's not much need for comments in small pieces of code compared to how important they are in bigger programs. But getting in the habit of including comments to explain code will help whenever you do end up writing somewhat larger programs.

```
// Program 1_9
*****************************************************************/
/* Our First Program! */
*****************************************************************/
#include <iostream>
using namespace std;

/* About to start the main program */
int main()
{
    cout << "Hello, World!" << endl; // This is a single line comment
}
```

A comment could be for people who didn't write the code but come along later and understand it, or it can help tell your future self what you had in mind for each part of the code.

In C++, there are 2 ways of writing comments. The first is one you begin the comment with a double forward slash (//), which is a way of indicating everything from that point on one line that is a comment.

The other type opens and closes with /* and */. This type of comment is helpful if you want to write multiline comments. It begins with /* and continue until you closed by /, even if there's a multiline comment anywhere you wish by using this format. You could also modify your original program to make the initial comment use this format.

You often use example to create visual block separation at the beginning of a program. Note in this example that you have a few lines of just asterisks, providing a visual block of comments at the beginning of the program.

And you often use a comment to describe what's coming next. For example, you might put a comment right before the main part of the program, showing what part is about to do.
