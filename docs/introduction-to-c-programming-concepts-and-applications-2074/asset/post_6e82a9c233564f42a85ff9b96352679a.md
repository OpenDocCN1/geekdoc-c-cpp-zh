
# // PREDEFINED KEYWORDS

A keyword is a word defined in the C++ language itself. These are often automatically recognized by your IDE and presented to you in a color distinct from the surrounding code. The list here includes C++ keywords that are commonly used but not complete (see the Predefined Variable Types below, for example). For a more complete list, consult an online reference such as cppreference.com.

# break

When encountered inside of a loop, immediately stops the execution of the loop and jumps to the first statement following the loop.

# catch

Designates the commands to be executed in response to an exception generated in a preceding try block.

# else

Designates the commands to follow if an if condition evaluates to false.

# class

Used to define a class. The general format is class class_name {/** class description */ };

# extern

Indicates that the definition for a function or class will be provided outside of the current file.

# const

Indicates that a variable will not change values; particularly useful for passing by const reference.

# for

Loop designator provides a compact way of specifying all loop control in one place. The keyword is followed by parentheses containing 3 clauses separated by semicolons; an initialization clause executed before the first iteration, a conditional check at the beginning of each possible iteration, and an update clause to indicate what should change with each iteration. Alternatively, the parentheses can contain variable and container to iterate over, separated by a colon; the variable will take on each value from the counter.

# continue

When encountered inside of a loop, immediately stops the execution of that iteration of the loop and begins the next iteration (if any).

# delete

Frees up dynamically allocated memory that was previously allocated with new.

# friend

Designates that a function defined outside a class should have access to a class's members as though it were part of the class.

# if

Identifies the start of a condition. The keyword is followed by parentheses containing a Boolean (the condition), and there are any commands to execute if the condition is true and, optionally, an else clause.

# return

Specifies the value to return from a function.

# static

Indicates a variable that should persist across multiple calls of a function. Static variables will maintain their value from the previous call to function on subsequent calls rather than allocating a new variable with each function call.

# namespace

Designates a namespace to be used when creating classes or functions or, when coupled with using, when referring to a class or function.

# struct

An alternative to a class. Traditionally used for grouping member variables, it now provides the same functionality as a class.

# new

Allocates new memory dynamically (on the heap).

# operator

Used to designate an operator that will be overloaded.

# try

Designates a section of code that should be executed but that might generate exceptions. Exceptions are handled by code in a catch block.

# private

Indicates subsequent class member variables and functions should be private (accessible within that class only).

# typedef

Defines a new name to be used for a type; allows a user to use more compact and meaningful type names.

# protected

Indicates subsequent class member variables and functions should be protected (accessible to a class and its derived classes).

# using

Indicates a namespace to be used by default so that namespaces do not need to be specified explicitly for every command.

# public

Indicates subsequent class member variables and functions should be public (accessible to anything).

# virtual

Indicates that a function in a class can be defined more specifically in derived (children) classes.

# void

A type indicating no information; commonly used to specify the return type for functions that do not need to return a value.

# while

Loop designator. The keyword is followed by a conditional in parentheses and then by commands to be executed repeatedly, as long as the conditional evaluates to true at the beginning of the loop.

Predefined commands are commonly used commands (e.g., as part of the C++ Standard Library) that are not actually part of the C++ language itself.

begin

A member function of a container returning an iterator pointing to the first element in a container. Calling .begin() on the container will return the iterator.

# eof

Member function for finding whether you have encountered the end of a file. Only when you have tried to read something past the end of the file will .eof() return true.

# cin

A source (obtained by using #include<iostream>) for streaming console input (input typed in the user).

# failbit

A particular exception that is thrown when a file is opened incorrectly.

# cout

A destination (obtained by using #include<iostream>) for streaming console output (output to be printed in the console window).

# find

An algorithm (obtained by using #include<algorithm>) for performing a linear search through a container (such as an array or vector). It takes an iterator to a beginning and ending iterator and an element value to find. It returns an iterator to the first position where a matching element is found or the ending iterator is not found. Likewise, there is a .find() member of the string class for finding a substring within string (the substring is the only parameter, returning string::npos if nothing is found).

# end

A member function of a container returning an iterator pointing to the position after the last element of a container. Calling .end() will return the iterator. Typically, you use this by incrementing the iterator until it reaches .end(), indicating that you have reached the end of the container.

# getline

A function that takes 2 parameters: an input stream and a string. A line (such as \n) is read from the stream.

# sort

An algorithm (obtained by using #include<algorithm>) for sorting vectors or arrays. It takes a beginning and ending iterator.

# lower_bound

An algorithm (obtained by using #include<algorithm>) for performing a binary search on sorted elements. It takes a beginning and ending iterator and returns an iterator to the first element that is greater than or equal to the value.

# string::npos

A value used to compare with the end of a string, indicating that the item was not found.

These are some of the commonly used types. Some are built-in C++ keywords, and others are classes.

// PREDEFINED VARIABLE TYPES

# auto

Automatically determines the data type based on how the value is assigned. This is useful for avoiding long type descriptions.

# double

Floating-point number that has double the precision of the float. C++ keyword.

# bool

Boolean. The value 0 is false; any other number is interpreted as true. C++ keyword.

# float

Floating-point number (standard length). C++ keyword.

# fstream

A file stream, used for reading or writing to files. #include<fstream>.

# char

A single character. Can also be interpreted as a small integer. Pronounced "char." C++ keyword.

Integer over the range ... -2, -1, 0, 1, 2 .. C++ keyword.

# // CONTAINER TYPES

Containers are data structures that hold several variables of the same type. Each container supports certain types of operations on its elements. They are included in the C++ Standard Template Library (STL). Each of these is templated and is declared by specifying one or more variable types that it will contain. These are some of the commonly used containers, but the STL contains several. Each of these containers is accessed using some #include command for the preprocessor.

# deque<type>

Doubly ended queue. Can easily add to or remove from beginning or end. Must #include<deque>.

# forward_list<type>

Stores data in a (ingly linked) list. Compared to a list, it is somewhat more efficient for most operations, but it is highly inefficient to access the end of the list or to go backward through the list. Must #include<forward_list>.

# list<type>

Stores data in a (doubly linked) list. Easy to add or delete at any point in the list, but no indexing is supported. Must #include<list>.
