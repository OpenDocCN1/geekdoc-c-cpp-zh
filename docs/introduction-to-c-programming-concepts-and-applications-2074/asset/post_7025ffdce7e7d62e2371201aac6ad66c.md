## INCREMENTING VARIABLES

Any time you make an assignment, you want to first evaluate the code on the right side and then, once you know the value, assign the resulting value to the left side. In example, a line has been added that you might encounter if you were adding extra butter, or other fat, to the recipe (13). It's still fat, so you don't need a new variable. Instead, the line of code is `fat_grams = fat_grams + 1`.

The way to think about this is that you first evaluate the right side, substituting in the value of any variables. In this case, you start with the value of `fat_grams` at 15, so the right side of this statement evaluates to `15 + 1`, or 16. Then assign that value, 16, to the variable on the left. It turns out that the variable that the new value is again `fat_grams`, but that's not a problem—you've already figured out the value to use on the right side.

The result is the value stored in the variable `fat_grams` has been increased by 1.

That operation—where you take a value of a variable, add something to it, and then assign the result back to the original—is fairly common. You often want to modify a value rather than assign a totally new value.

In fact, modifying existing variables like this is such a common operation that C++ has a shorthand way of writing this operation.

```
1 // Program 2_10
2 // Using a variable name on both sides of the assignment statement
3 #include<iostream>
4 using namespace std;
6 int main() {
7 int carb_grams;
8 int protein_grams;
9 int fat_grams;
10 carb_grams = 30;
11 protein_grams = 5;
12 fat_grams = 15; // First we assign a value of 15
13 fat_grams = fat_grams + 1; // Evaluate right side first, then assign to left
14 int calories;
15 calories = 4 * carb_grams + 4 * protein_grams + 9 * fat_grams;
16 cout << "There are " << calories << " calories in this dish" << endl;
17 }
```

The way this is done with the notation +=. For example, when you have += set to 1, it's doing exactly what you saw—takes the current value of the variable, adds the amount 1 on the right side to it, and stores the new result as the value of the variable.

An more compact way you can express incrementing is with the ++ operator. C++ also lets you write the increment operator before the variable name, but these methods don't always mean the same thing. Putting ++ after the variable—example, x++ means that you increment the value to something new after doing the parts of the command. In your code, you can write:

```
fat_grams += 1; // Add 1 to the value currently stored in variable
```

So, printing x++ gives the initial value of 1. In general, the variable is increased by whatever the amount on the right side is. If you have money, you end up with 100. Now you know where the language C++ gets its name! In the case of C++, it's the next value after C. This also works for multiplication. If you have rabbits, then num_abbits *= 3 to increment to a new value of the variable.

So, you have three ways to write the same line of code, and all do the same thing:

- fat_grams = fat_grams + 1
- fat_grams += 1
- fat_grams++

## MATHEMATICAL FUNCTIONS

Let's say you have 2 variables, a and b, and they're assigned the values 7 and 3. Notice that you can stream an expression like a+b directly to output. This kind of line is executed first, and the result is what's output. How does this work when division doesn't occur evenly? For example, what happens if you divide 7 by 3? Only the remainder—not the quotient—when one number is divided by another.

When C++ sees division by 2, it does integer division, meaning that it returns only the quotient, with no remainder. Because 3 goes into 7 twice, the result is In Program 2_18, the first cout line will output the quotient. The second cout line, where you stream a%b, will output the remainder, 1, which is the remainder of 7 divided by 3.

In this case, output works as you'd expect:

- a+b is 10
- a-b is 4
- a*b is 21
- a/b is 2
