# # SETTING DEFAULT PARAMETERS

There's one more way that you can provide functions with the same name but different parameters sets: You can specify a default value for one or more of the parameters. If, when the function is called, the corresponding argument is left out of the call, you will use the default parameter instead.

To do this, you just set an initializing value for the appropriate parameter, assigning some value inside the parentheses. When it is done this way, assignment is understood by the compiler as one to be used if the corresponding parameter is not provided.

On the other hand, if you call it just a string parameter, such as World, then times has the default value, so the string is printed just once.

If there are multiple default parameters, then arguments from the function are all assigned to parameters from left to right (the first argument is assigned to the first parameter, etc.). You can't have some parameter in the middle assigned a default value; once one is assigned, everything after it must also be default.

Suppose you want to create a function, called printmultiple, to print out a string multiple times. Let printmultiple take the string to print and the number of times to print it. The function does not need to return a value to the place it called from, so you'll have a void type.

Default parameters are commonly used to control how a function works when there's a normal, or common, way to do something set as the default but you want to let the programmer have the option of selecting some other behavior needed.

If someone doesn't have many to print the string, you might choose to have a default number, such as 1. If so, your header would look something like line 7. So, there are 2 parameters: an int for the number of times, and an int called times, which has a default value of 1.

```
// Program 13_5
// Using a Default Parameter
#include <iostream>
#include <string>
void printmultiple(string s, int times = 1) {
    for (int i = 0; i < times; i++) {
        cout << s << endl;
    }
}
int main() {
    printmultiple("Hello", 5);
    printmultiple("World");
}
```

If you call the function with both parameters—for example, Hello and 5—will you get the string Hello printed out 5 times.

> Setting default parameters is an alternative to overloading a function by specifying different signatures.
