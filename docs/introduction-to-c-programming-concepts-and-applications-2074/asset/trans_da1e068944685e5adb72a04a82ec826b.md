## // TEMPLATES AND CONTAINERS

基本上模板是一种说法的手段，即一个类的成员变量，或一个函数的参数，不是特定类型而是某种通用类型。因此，类或函数不只适用于一种特定类型，可以用于匹配某些类型的任何类型。当你实际想要使用特定类或函数时，模板就会采用。

例如，vector 是一个模板类。它允许你存储任何类型对象的列表，但要使用它，你必须创建一个存储特定类型的 vector。因此，尽管 vector 被称为一个类，但它实际上是一个更通用的容器，能够容纳各种不相关的类。

在普通英语中，generic 通常意味着“不特别”甚至“不好”，但在编程中，generic 意味着你在“概括”某个概念或想法。

```
vector<int> v1;
vector<float> v2;
vector<string> v3;
vector<my_class> v4;
```

角括号，如在声明 vector 时使用，用来指定类或函数将采用的特定实例。角括号中指定的类型是替换模板在整个类或函数中的类型。
