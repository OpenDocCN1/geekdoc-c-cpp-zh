```
class car {
protected:
    float base_price;
    string model_name;
public:
    car() {
        base_price = 20000.0;
        model_name = "Generic1";
    }
    car(float price, string name) {
        base_price = price;
        model_name = name;
    }
    void print_info() {
        cout << "The model " << model_name << " costs " << base_price << endl;
    }
};
```

Imagine you're a car dealer. You'll have a general class to keep track of cars, and then from that, you'll derive classes that represent the more specific cars.

In this case, you'll have a base car class that contains 2 members: base_price and model_name ().

You'll also have a base for the SC300 model car (m), which inherits from the car class. That will have 3 member variables that are Booleans whether or not the car has various add-on features to that car, as performance or entertainment package.

Each of these classes will also have constructors. For the car class, there will be a default constructor for a generic model car and a constructor allowing the base price and name to be set (n).

For the SC300 class, the constructor will take parameters whether or not the various options are ordered. We will call the car constructor with the base price for the SC300 and the model name for the SC300 and then will set the appropriate Booleans (o).

```
class SC300 : public car {
protected:
    bool performance_package;
    bool entertainment_package;
    bool safety_enhancements;
public:
    SC300(bool p, bool e, bool s) : car(35000.0, "SC300") {
        performance_package = p;
        entertainment_package = e;
        safety_enhancements = s;
};
```
