# // INDEXING INTO AN ARRAY

One of the things that makes arrays feasible is that you can use a variable to represent the individual index.

Suppose you create a small array named a with 5 elements, and you assign values of 10, 20, 30, 40, and 50 to them. Then, you create an integer i that you initialize to 3, and you print out a[i].

The ability to index into an array by using a variable that contains the index gives you the ability to easily address all the elements of the array looping through it.

For example, you can set all of the elements to initial values. Suppose you were playing a 4-person game and wanted to have the same amount of money in the begin—$200 (Program 7_3).

```
int main() {
int a[5];
a[0]=10;a[1]=20;a[2]=30;a[3]=40;a[4]=50;
int i = 3;
cout << a[i] << endl;
}
```

You first create an array. You could write int player_money[4](7), which would declare an array named player_money with 4 elements.

Then, you would loop over the indices (9). In this case, you can use a for loop to iterate over the elements from 0 to 3. You use i to keep track of the index.

The output is the value that you assigned to a[3], which was 40.

When you access a single element of the array—by listing the array name and putting the particular element in square brackets—you are said to indexing into the array. In other words, you are accessing array elements using the index of an element.

Within that loop, you could set player_money[i] to 200 (10), indicating that player has $200. Because you loop over all 4 indices, you have initialized 4 elements.

Besides initializing, you can loop over the elements to print them (a).
