# // HOW CODE AND LIBRARIES ARE COMPILED IN C++

A library typically consists of 2 parts: a header file and an implementation file. You can think of the header file as the interface for the library. The header file basically makes a few definitions and declarations says, "Here is where in the library how it can be accessed." But it doesn't necessarily contain the details of how the things in the library are actually implemented.

The library can be compiled into an object file, which is machine instructions. But these machines can't be run on their own. Because no main function is defined in the library, it doesn't have any commands that just executed on their; instead, there are instructions waiting to be used by some other program.

Your main program gets compiled into its own object file. But this new object file does not have the actual implementation of the stuff in the library. These commands are in the other object file—the library's object file.

When people write their own files, the header file will typically have the extension .h. You might also use the extension .hpp where the pp is added to show that the header is part of c++ (plus). For standard headers, you don't worry about any extension, because it's automatically implemented. You just write iostream, not iostream.

Next is your program—the one that you want to actually use of the library. This is where you'll define main. functionality is available and how to use it. To get access to that library's functionality, it #include the library's header file.

So, after all the compilation is, there's one more step: the linker, which the main program's object file to create an executable file. The executable file now has all the information from the program file and from the library file, and it can thus be run on its own.

# Compiler

The details of how library is implemented in the implementation file, which will contain C++ code and will have a .cpp extension. If the file is just standard C code, it might only have a .c extension. The implementation file has all the details of how the things are declared in the header file and will usually #include the header file at the beginning.

Note that a library does not actually contain a main function. The library is not going to contain code that is run as the main program itself; it just going to contain functions that can be used by the main program.
