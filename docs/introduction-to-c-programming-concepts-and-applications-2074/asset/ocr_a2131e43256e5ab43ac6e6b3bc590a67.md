The error will list something like 2:18: error: missing terminating >. The 218 is telling you that an error was detected on line 2 of the 18th character—that's the character removed. The missing terminating > character tells you you're missing. The error should give you clues exactly what prevented your program from running successfully. Different websites' may have different error messages.
