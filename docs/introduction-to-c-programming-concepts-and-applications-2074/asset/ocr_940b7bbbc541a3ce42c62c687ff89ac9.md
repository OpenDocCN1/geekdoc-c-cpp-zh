Vectors and strings are objects, and they have functions, such as push_back and size that "belong" to them. So, variables of type fstream are called objects because they also include their functions.

The longer version of the command also asks you to specify how you want to work with that particular file—to read or write. If you're just reading, it's straightforward to open the my_file object: my_file.open("Test"). Writing to a file that the computer can have a few interpretations:

out with trunc or ate, any existing data in the file will be overwritten.

app means that you're going to write output to the file but only after whatever's already there. Nothing gets erased or deleted.

To create a fstream object, you just declare it like other variables. You can choose the type, fstream, along with the object name—in this case, my_file.

trunc means that you should delete whatever is already in the file and start writing from scratch. You can only use trunc if out is specified, and they are combined with a vertical bar { }.

To actually use the file, you need to link up the object name that's in your program with some file that's on your computer. You do this using an open command. A simple version of the open command, but in most cases, it's better to use the longer version.

+   You can leave everything in the file that's ever one character at a time.
You can leave everything in place and everything you added onto the end.
You can delete everything that's already there and start writing to an empty file.

ate writes at the end of the file, using the same effect as app but with some freedom to move around the file you've written in one place. ate should also be enabled with out, | between.
