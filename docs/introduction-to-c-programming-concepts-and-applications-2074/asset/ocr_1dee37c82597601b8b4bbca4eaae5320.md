```
// Program 12_3
// Multiple parameter types
#include <iostream>
using namespace std;

float average(float a, float b) {
    return (a + b) / 2.0;
}

int average(int a, int b) {
    return (a + b) / 2;
}

int main() {
    cout << "The average of 10 and 35: " << average(10, 35) << endl;
}
```

In this variation, you have the original average function that takes 2 floats (c). You also create another version that takes 2 integers. It returns an integer instead of a float. In this case, you'll call integer division in the interior; because the parameters are integers and you divide by 2, not 2.0, you'll have an integer division (d).

If you call the function with 2 integers, the compiler will match it with the function signature that has 2 integers. Because it is an exact match, that is the function will use it. There won't be any ambiguity because there's nothing left to be converted. So, in this case, with 2 integers, 10 and 35, gives an integer result, rather than the floating-point result 22.5.

# VARIABLE TYPES IN C++

![](bbox=[0.055, 0.485, 0.505, 0.595])

For a computer, each variable is a way to interpret bits in memory—a group of 1s and 0s that get interpreted to mean an integer or a floating-point number, for example. Each variable has some size of memory that it is taking.

+   INTEGERS
char
short int
int
long int
long long int

In C++, you can specify, to a degree, how many bits are used to represent numbers. The more bits are used, the larger the number that can be represented. For integers, that means that you can represent larger integers. For floating-point numbers, that means that you can use more digits of precision and can represent both larger and smaller numbers.

For integers, you have several options, ranging from a char (a single character) all the way up to a long int. The exact sizes of integers aren't specified, but you do know that a long int has at least many as a long int, which has at least many as an int, and so on. Choosing larger integers lets you represent larger numbers, but at the cost of more memory to store values.

+   FLOATS
float
double
long double

Similarly, floats have a longer version, the double, and an even longer version, the long double.
