# // CREATING CLASSES

You declare a class in a similar way to how you declare a function. It'll typically be defined outside of the main function, closer to the top of the program.

Once you have a class, you can declare objects as instances of the class, just like you would have any other variable.

Variables are typically declared inside of functions, including main.

In Program 16_1 on page 176, you've declared a class named vending_machine by writing class vending_machine {}; Obviously, there's nothing in the class at this time; so it's useful. But this gives you the ability to declare objects of type vending_machine.

Now you can declare 2 vending machines, called lobby_machine and break_room_machine. All you do to declare them is to write the following:

+   - vending_machine lobby_machine;
- vending_machine break_room_machine;

Next, you have curly braces, which group the definition of the class all together. At the end of the curly braces will be a semicolon. This is one of the few times you need to add a semicolon after curly classes.

# // SORTING DATA IN CLASSES

A class is going to contain, inside of itself, a set of variables and functions called member variables and member functions. The class is a way of grouping of all variables and member functions—encapsulating them. So, when you create a new object of that type, you're also creating a bunch of subordinate variables defined by that class but with values specific to each object. Basically, those sub-variables "belong" to the object as its member variables.

For vending machines, one of the things you wanted to store is the price of the item that the machine sells. So, inside of the class definition, you will create a floating-point member variable price. Before you declare the member variable, you write the line public:. This means that the member variable can be seen outside the class. You declare this in a similar way as you would declare any other variable: the name of the member variable, and a semicolon.
