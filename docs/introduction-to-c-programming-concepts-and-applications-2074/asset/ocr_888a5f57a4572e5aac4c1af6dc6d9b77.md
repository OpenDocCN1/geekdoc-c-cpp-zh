# 08 Vectors for Safe and Flexible Data Storage

As you've learned, arrays are one way of handling large amounts of data. They can be efficient, but they have some issues. First, there is the possibility of arrays going out of bounds. Also, you need to know the size of the array at the time you declare; this is a problem if you don't know how much space you need. As an alternative to arrays, C++ offers vectors, which address many of the annoying about arrays. Vectors also offer a sampling of some of the other features that make C++ such a useful language, including object-oriented programming and templates.

# // USING VECTORS

Program 8_2 on the following page creates a vector with 3 elements, which has the values 1, 2, and 3, and then prints those values out.

That to use a vector, you have to #include the vector library—which is part of C++s Standard Template Library and is included in all C++ installations. This will give you access to what is called the vector class; it is going to let you make vectors, not just arrays.

This would have been easy to do with an array, but this program illustrates some similarities and differences between arrays and vectors.

> Note that a C++ vector is not a mathematical vector.
