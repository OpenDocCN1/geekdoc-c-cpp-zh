From your browser, you will be choosing a website that is interactive.

Some of the works well are shown, but a search for "Online C++ Compiler" or "Interactive C++ Compiler" will turn up others.

There's one pitfall to watch for: Use only sites that support interactive mode. If you're going to use a browser-based compiler that's not on the list, make sure it supports interactive mode when executing a program.

How can you tell?

Here is some code that's interactive. It's a version of Hello, World! that also takes input. If you run this in the browser, an interactive mode will prompt you for your name, you can then type in:

But if you only see a box, often labeled stdin (short for standard input), where you type input separate from you see output, that probably not a good sign.

On a site that's not interactive, you would have to enter all input beforehand; it would not be possible for a user to reply to a question and have the program compute a result.

Be able to run the program and then interact with the output—to get data when prompted.

```cpp
// Interactive Hello, World! Program
#include <iostream>
#include <string>
using namespace std;
int main() {
    string username;
    cout << "What's your name? ";
    cin >> username;
    cout << "Howdy, " << username << "!" << endl;
}
```

Feel free to select whichever site you find easy and intuitive to use, but note that cpp.sh is especially simple and clean.

OnlineGDB is more powerful; it offers an online debugger, which many interactive sites lag.
