
# C++ Loops and Iteration

Programmers use loops to get the computer to do one of the things it's best at and that people tend to dislike—mere repetition. Loops make it possible to repeatedly execute the same code over and over. There are 2 main types of loops: the basic while loop and the for loop, which is a compact way to make the while loop happen a set number of times.

An easy way to program exactly what you want is with a while loop. It's like an if statement that keeps getting repeated as long as the if condition is true—in other words, while the condition is true.

When the program comes to the while statement, it first checks the condition, just like it did with the if statement. In this case, the condition is still that the balance is greater than. As long as that true, everything in the curly braces while executed—even something inside the braces the condition no longer true.

The part of the while loop inside the curly braces is called the body of the loop. Every time you go through the body of the loop, it is called iteration of the loop.

You need to make only one small change to program the functionality you want: Just change the if to while word. And if you run the program now, you'll get the exact output you would have had repeating the if statement 15 times.

For example, even though the balance on the last payment, becomes negative, you continue to execute the remaining lines. The balance becomes negative when you subtract the payment. But you still execute the remaining lines in the curly braces: numpayments++ and the cout statement to print the payment.

When the condition is no longer true, you skip the lines in the braces and go to the next line after the while statement. If there are no lines after the loop ends, the whole program ends at that point.

But there's one particular pattern of specifying the number of loops that's common, so there's a more compact way of writing a specific number of loops, called a for loop.
