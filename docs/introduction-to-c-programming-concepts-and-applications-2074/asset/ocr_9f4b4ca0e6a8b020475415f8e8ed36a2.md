There are a few limitations of programming in a browser:

>> There's no guarantee of reliability: The website could go down briefly at any time.

>> Some browser compilers will not let you create and store your files on your computer. On those websites, reading and writing files would not be possible.

>> There's no security or privacy. The browser is not running on your machine; it's compiling and running on some other machine. You should not enter sensitive or proprietary information into this system.

Remember any program in the browser window is not being saved, so it's up to you to make sure your code is not lost.

Still, a web interface is the simplest way to try out a program and see the results. The browser is an easy way for you to do 90% of what's in this course.

Whenever you have programs you type into the browser, you should also copy and paste the program into a document on your computer.

Saving in plain text is best, because that won't introduce extraneous information and formatting that a word processor might add. If you save your file with a .cpp extension at the end, then that's a signal that it's C++ code.
