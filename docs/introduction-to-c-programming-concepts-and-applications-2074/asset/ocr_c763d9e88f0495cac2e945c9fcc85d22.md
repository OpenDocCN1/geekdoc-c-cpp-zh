Notice that a queue is used to keep track of the names. The loop continues indefinitely, and in each iteration of the loop, you read in a string. if it is next, then you push the item at front (and remove that item). Otherwise, you just add the name onto the queue.

+   a Queue, This is an example of a FIFO ordering, which is what queues are best used for.

```
#include<iostream>
#include<queue>
#include<string>
using namespace std;

int main () {
    queue<string> names;
    string s;
    cout << "Enter a name, or type \\next" to get the next person to see" << endl;
    while(true) {
        cin >> s;
        if (s=="next") {
            cout << ""The next person to see: " << names << endl;
        } else {
            names.pop();
            names.push(s);
        }
    }
}
```
