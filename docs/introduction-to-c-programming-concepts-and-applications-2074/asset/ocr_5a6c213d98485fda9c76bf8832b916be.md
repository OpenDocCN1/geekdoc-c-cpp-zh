The main part of the class is the ask_question member function. This is to be the function to have the computer ask the question in that node—either to guess the answer or asking a question to narrow down choices.

If it is a node with a final, you'll make a guess of what you think the player is thinking of. You output your guess, which is the text variable (d).

You next ask the user to give a question to distinguish your incorrect guess from the thing the user was thinking of (h). The question gets read in an answer line, which is not just one line. Use the getline command to read the question.

The ask_question function will return true if the computer wins the game–the function will guess the answer–or false if it doesnt. The function has 2 parts: one if it's a node with a final and one if it's a node to ask another question.

You then read an answer from the user (e). If the answer is Yes, it means you have the correct thing, so you return true, and the game is over (f). If your guess was not correct, you need to update your decision tree. You first find out what the person was thinking of. This is how to become a new answer node (g).

Remember from lecture 9 that getline first reads any leftover carriage return that have come after entering a variable as an entire line, so you have to call getline twice: once to get the new line from pressing Enter after typing the name of the thing the user was thinking of, and another line will read in the new variable as the user wrote.
