## // 字符串变量和字面量

到目前为止，你一直在使用字符串字面量——某种类型的指定值。就像你可以使用变量来存储和操作布尔值一样，你也希望使用变量来存储和操作字符串。为此，你使用一种新的变量类型——string。字符串变量是你使用和操作文本数据的主要方式。

与 int、float 和 bool 不同，string 不是内置语言类型。为了拥有 string 类型，你需要引入一个新的库，string 库。一旦你这样做了，你就可以声明字符串变量，就像声明其他类型一样。

把字面量看作与变量相对。变量可能具有某种类型的任何值；字面量是某个特定值。

如果你有一个变量 x 和一行代码 x = 5，x 是变量而 5 是字面量。如果你将 3.14 流式传输到 cout，你正在流式传输一个浮点值。或者，如果你将 3.14 分配给浮点变量 f，那么你就是在打印一个变量。

string 库是标准 C++ 库之一，因此你可以访问它，#include string。一旦你这样做了，你就可以声明字符串变量，就像声明其他类型一样。

最后，你输出，流式传输字符串变量的值是 cout，就像你会流式传输字符串字面量一样。

当你将输入流式传输到字符串时，流只会取下一个单独的项目并将其放入变量中。单独的项目由空白分隔——即空格、制表符和换行符。因此，当你输入 John Keys 时，流式传输操作将其视为 2 个不同的字符串：一个值为 Keys。只有第一个字符串 John 被流式传输到变量。

```
// Program 9_3
// A greeting program handling first and last names
#include <iostream>
#include <string>
using namespace std;

int main() {
    string firstname, lastname;
    cout << "What's your name? (Enter first name and last name) ";

```

你可以使用 cin 流式传输数据，但如果想读取更长的文本，例如带空格和标点符号的句子？有一个名为 getline 的函数在 string 库中定义，你可以这样做。

```
// Program 9_5
// Using getline
#include <iostream>
#include <string>
using namespace std;
int main() {
    string username;
    cout << "What is your name? ";
    getline(cin, username);
    cout << "Howdy, " << username << "!" << endl;
}
```

记住，你可以通过在线参考 cplusplus.com 查找 string 库中的内容。

要使用 getline，你进行函数调用：使用函数名后跟括号，其中包含函数的参数。对于 getline，我们想要使用 2 个参数：源（控制台 cin）和你想要保存函数调用结果的变量的标识符（string 类型的变量）。

让我们使用 getline 修改 Hello, World! 程序。

在这段代码中，所有命令都与之前相同，只是输入命令不同。不是从 cin 流式传输到 username，你而是使用 getline 函数。你编写命令 getline(cin, username); 它将整行输入读取到字符串 username 中。

## // 字符串操作

在程序 9_6 中，你有 3 个字符串——名为 s1、s2 和 s3——并将字符串 Happy 分配给 s1，将字符串 Birthday 分配给 s2。

这意味着加法操作 + 对于 2 个字符串的工作方式与对于 2 个数字不同。+ 运算符被重载，这意味着它有不止一种含义，具体取决于输入的类型。

在程序 9_8 中，你有一个字符串 s，你将其初始化为值 Happy。然后你有一行：s += "Birthday";

然后你有 s3 = s1+s2。换句话说，你正在添加 2 个字符串以得到第三个字符串。

当你运行时，你会得到一个连接的字符串 HappyBirthday，中间没有空格。Birthday 已被追加到原始字符串 Happy。基本上，你取字符串中的值并对右侧执行 + 操作，将结果放回原始变量中。但字符串的 + 定义为连接，因此 2 个字符串被连接，结果被放在 s 中。

如果你运行此程序，输出 s3 会给你一个字符串 HappyBirthday，单词之间没有空格。基本上，s3 由第一个字符串 Happy 形成，并将下一个字符串 Birthday 粘在末尾。这称为连接。你已将字符串 s1 和 s2 连接形成 s3。

运算符重载是为不同类型定义行为的常见做法。

> + 不总是意味着加法。
各种运算符的含义取决于它们所操作的事物的类型。

在前一个程序的另一个变体中，而不是字符串 Happy 和 Birthday，你将 s1 分配字符串 3，将 s2 分配字符串 4。

```
// Program 9_6
// Adding strings
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s1, s2, s3;
    s1 = "Happy";
    s2 = "Birthday";
    s3 = s1 + s2;
    cout << s3 << endl;
}
```

```
// Program 9_8
// Adding a string
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "Happy";
    s += "Birthday";
    cout << s << endl;
}
```

请记住 s1 和 s2 是字符串。分配给 s1 的 3 不是数字 3；它是一个字符串，其中只有一个字符数字 3。同理，当你添加分配的 4 时，你得到连接，因此 s1 和 s2 相加的结果是连接它们的字符串。结果不是真正的数字 34；它是字符串 34。
