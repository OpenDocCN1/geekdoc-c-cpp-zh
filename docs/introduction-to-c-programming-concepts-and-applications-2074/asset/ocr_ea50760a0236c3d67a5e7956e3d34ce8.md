With pseudorandom number generation, we have to initialize the numbers with a seed value, which can be any number, and the numbers produced very random—you can't tell they're related to the seed. If you start with the same seed, you will always get the same sequence of random numbers every time you call rand.

Program 6_9 shows what the code will look like with a different seed, the seed used is 3. If you run the code with different seeds, you'll get different sequences of numbers.

There's a library called ctime that will give you the current time.

In Program 6_10, the ctime library has included-Which gives you access to a function, time(), that will give you a current time. The time function takes one argument, which you should set to 0. The time function will give a different value at every time, based on the current clock time.

You can adjust this by setting the seed, which is done with a function call in one argument: the seed value to be used. After calling srand, call to rand will be generated based on that seed value. If you give the same seed, you will get the same sequence of pseudorandom numbers.

Notice that the sequence you get for a seed of 3 is very different from that for a seed of 4, which would be very different from a seed of 5, and so on.

If you want something even more random, you can choose a seed without having to specify a number. A common way of doing this is to use the current time as the seed value, even though the numbers are not truly random, no one is going to be able to guess the actual digits of time.

If you run this code, you'll get a different sequence of numbers every time you run. Because the actual time in the computer is changing every second, the time function will give you a different value at time, every time you run the program, you have a different seed.
