Using 2-dimensional arrays can be useful if you have data that come in a 2-dimensional grid. Multidimensional arrays can also be useful when you have something that is easy to index in 2 different ways.

Regardless of how you use one-dimensional or multidimensional arrays, there is one issue to be particularly careful of: array bounds.

In Program 7_11, you have an array my_array of size 3, and set the values of the 3 elements in 10, 20, and 30.

```
// Program 7_10
// A 2D array initialized
#include <iostream>
using namespace std;

int main() {
    double accounts[5][3];
    int i, j;
    for (i = 0; i < 5; i++) {
        for (j = 0; j < 3; j++) {
            accounts[i][j] = 50.0;
        }
    }
    cout << endl;
    cout << "accounts: " << accounts[i][j] << endl;
    return 0;
}
```

```
// Program 7_11
// ERROR in output to array out of bounds
#include <iostream>
using namespace std;

int main() {
    int my_array[3];
my_array[0] = 10;
my_array[1] = 20;
my_array[2] = 30;
    for (int i = 0; i < 4; i++) {
        cout << my_array[i] << endl;
    }
}
```

You have a loop that's designed to print out the values of an array, but instead of outputting 3 values, you make a mistake and have the loop to print 4 values instead. If you look for the loop, the index i will take on 0, 1, 2, and 3, because the condition is i4.

Because 0, 1, and 2 are part of the array and you just set values for all, they should be fine. But what happens when you try to print my_array[3]?
