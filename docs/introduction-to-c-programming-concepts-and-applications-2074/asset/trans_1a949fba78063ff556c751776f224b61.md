## // 变量声明

计算机的主要工作内存由许多位置组成，每个位置只能存储 1 或 0。然而，程序员不会用机器语言编写。

因此，编程语言让你取内存中的一小部分，0s，并用于自己的目的。这部分内存称为 **变量**。把变量想象成一个可以容纳不同值的盒子——也就是说，你可以随时更改它。

在 C++ 中，为了使用变量，你必须先声明它。换句话说，你向计算机编写程序指令说：“我想为我自己使用而预留一个内存盒作为变量。” 这个操作——说你想要一个特定变量——称为 **变量声明**。

### 命名变量的规则

+   名称以字母开头。除字母外，也可以用下划线字符开头，但你不应该这样做，因为它通常为编译器中更高级的系统编程中出现的特殊类型保留。

+   对于名称的其余部分，你可以使用字母、下划线字符或数字。

+   C++ 中有一些特殊词，通常称为 **关键字** 或保留词，用于其他用途，因此你不能使用它们。例如，你不能将变量命名为 **namespace** 或 **using**。还有一些预定义标识符，如 **main**，声明它们是可能的，但你应避免在自己的变量名中使用它们。

**变量名** 是你用来引用内存盒的名称。这个变量名通常称为标识符，因为它标识了你所引用的内存盒。当你在程序中使用 `carb_grams` 时，你指的是那个内存盒——更具体地说，是该内存盒中包含的值。

如果必须用二进制的 1 和 0 来写，那将是一件很痛苦的事——如果你必须写 1 和 0。

每个变量声明需要两件事：一个 **类型** 和一个 **名称**。例如，你可以声明一个名为 **year** 的整数变量。代码为 `int year;` 其中 `int` 是 integer 的缩写——任何计数数字，如 0、1 或 12。

你获得以可理解形式编写变量的能力的方式是通过变量类型。当你声明一个变量时，你首先告诉计算机该变量的类型。

在卡路里计算程序中，行 `int carb_grams` 提供了声明变量所需的信息：类型（**int**）和变量名（**carb_grams**）。

## // 变量赋值

让我们回到原始的卡路里计算程序（第 18 页的程序 2_1）。在声明类型和名称之后，你可以看到有 3 个赋值（d）。每一行都有左侧的相同名称、等号和右侧的值。

赋值是用等号写的，但它并不意味着两件事相等。它意味着右侧的东西被赋给左侧的变量。这就是为什么在阅读代码行时最好说“gets”或“assigned”而不是“equals”。

当你第一次声明一个变量时，最好为变量设置一个初始值。事实证明这很容易：你可以将变量声明与赋值结合起来。

```
int carb_grams = 30;
int protein_grams = 5;
int fat_grams = 15;
```

这是任何赋值语句的一般形式。当执行此代码时，左侧的变量——被放入盒子。它替换盒子中已有的任何其他值。

如果在赋值运算符的右侧看到一个变量，你可以认为那里意味着“这个值持有。”

首先，你有一个变量声明，声明了一个名为 carb_grams 的整数变量的内存盒。

接下来，当你声明一个名为 protein_grams 的整数变量时，同样会发生这种情况。

变量赋值：
<variable name> = <value>
carb_grams = 10;

你声明了一个名为 fat_grams 的整数变量。

> 请记住变量的值会变化；它们不会被困在第一次赋给它们的值上。这就是等号表示赋值，而不是永久相等的原因。在以后某个时间，你可以为盒子分配一个新值，替换旧值。
