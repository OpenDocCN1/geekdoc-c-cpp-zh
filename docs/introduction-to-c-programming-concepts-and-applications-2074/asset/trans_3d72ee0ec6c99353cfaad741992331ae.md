

# C++ 循环与迭代

程序员使用循环来让计算机执行它最擅长而人们往往不喜欢的事情——单纯的重复。循环使得可以反复执行相同的代码。主要有 2 种循环类型：基本的 while 循环和 for 循环，后者是一种紧凑的方式，可以让 while 循环按设定的次数发生。

## WHILE 循环

这是用于从贷款计算余额的，其中有利息累积和付款。

你首先将状态初始化为 $1000 的余额，每个期间你会产生 5% 的利息并支付 $100（14）。

然后，你检查是否还有余额（11）。如果有，你会产生利息，将利息加到余额上（12），通过付款（13）。你增加已付款次数的计数，这只是（14）。并且你打印出付款后的余额（15）。

这仅适用于 1 次付款。显然，你需要不止 15 次付款来还清贷款，所以你可以反复重复那个 if 语句。你必须为每次想要的付款复制粘贴代码。如果你这样做，你将需要不止 15 次付款——这将超过 100 行代码——来还清贷款。

```
int main() {
  float balance = 1000.0;
  float payment = 100.0;
  float interest = 0.05;
  int numpayments = 0;
  if (balance > 0.0) {
    balance += interest;
    balance -= payment;
    numpayments++;
    cout << "Balance is: " << balance << endl;
  }
}
```

用 while 循环编程你想要的确切内容是一种简单的方法。它就像一个 if 语句，只要 if 条件为真就一直重复——换句话说，只要条件为真。

当程序遇到 while 语句时，它首先检查条件，就像它对 if 语句所做的那样。在这种情况下，条件仍然是余额大于。只要为真，while 语句中的大括号内的所有内容都会被执行——即使在条件不再为真时，大括号内也有内容。

while 循环中大括号内的部分称为循环体。每次你遍历循环体时，就称为循环的迭代。

你只需要对程序做一个很小的改动来获得你想要的功能：只需将 if 改为 while 这个词。现在如果你运行程序，你会得到与重复 15 次 if 语句完全相同的输出。

例如，即使在最后一次付款时余额变为负数，你仍会继续执行剩余的行。当你减去付款时，余额变为负数。但你仍然执行大括号内的剩余行：numpayments++ 和用于打印付款的 cout 语句。

当条件不再为真时，你跳过大括号内的行并转到 while 语句之后的下一行。如果循环结束后没有行，整个程序就在那时结束。

```
11 if (balance > 0.0) {
```

```
11 while (balance > 0.0) {
```

在执行完大括号内的内容后，你会重新评估条件。毕竟，在循环结束时，事情已经改变，所以也许余额不再为正。如果条件仍然为真，那么你会再次执行大括号内的所有内容。这可以无限期地继续。

while 循环的一种不太常见的变体称为 do while，条件检查在循环末尾并带有分号。总的来说，唯一的区别是程序现在被迫进行第一次迭代。这在你知道至少需要遍历一次循环时很有帮助。

sentinel 是一个你通常不会遇到的刻意不寻常的值，它是一个你用来识别何时正在处理“常规”数据的数值。银行账户中的负余额可以作为 sentinel，前提是你不允许透支。你可以使用 sentinel 来帮助识别何时是退出循环的时候。如果 sentinel 值导致，循环将被跳过。

很有可能你会在程序的某个时刻不小心创建一个无限循环。这是一个常见的陷阱，很容易在编写循环条件时出现，因此最好尽早弄清楚在发生时如何跳出。

如果条件永远不会变为假，那么每次评估条件时它都是真的，所以循环会永远重复。这就是无限循环。

例如，如果 Program 5_5 保持打印连续的数字，从 1 开始；请注意条件是大于 0，这总是为真。如果你运行此程序，循环将永远继续，直到你做一些特别的事情来停止它。

你可以通过强制类型转换一个值来做到这一点，这是一种将一种类型的值转换为另一种类型的方法。为此，你有两个选择：你可以在你想要转换的值前面加上要在括号中指定的新类型，或者你可以声明新类型然后放置要转换的值。无论哪种方式，你都会在可能的情况下将值转换为另一种类型。

通常，你停止程序的方式取决于你的系统。你的 IDE 将有一个按钮或其他东西来导致它停止；或者其他情况下，你可以按 Ctrl+C，这将调用程序“中断”并停止。在最坏的情况下，你可能不得不通过关闭正在运行程序的窗口来实际停止整个系统。

## FOR 循环

循环对于计算机程序的许多方面都很有用。只要你有大量数据需要处理，你很可能就会使用循环来遍历所有数据片段。但指定循环次数的一种特定模式很常见，因此有一种更紧凑的写法来指定特定次数的循环，称为 for 循环。

在第一次迭代结束时，新的余额被计算出来，付款次数增加到 1。这与条件进行比较，并且仍然小于 5，如果你进行另一次迭代。

**Program 5_12** 是对之前贷款余额计算代码的轻微变化。循环不再基于余额为正，而是基于付款次数。

这将继续进行到 4。打印出第 4 次付款的结果后，你计算新的余额并将 numpayments 更新为 5。因此，当语句的条件为时，numpayments 不再大于 5。所以，你得到的结果从 0 到 4。

付款 0 次后的余额：1000
付款 1 次后的余额：950
付款 2 次后的余额：897.5
付款 3 次后的余额：842.375
付款 4 次后的余额：784.494

此循环将进行固定次数的付款。它有一个变量 numpayments 来跟踪已付款次数；使用付款次数作为其条件；并在每次循环迭代中增加付款次数。请注意，条件是付款次数小于 5。

让我们看看这个循环的所有工作原理。你在循环开始前初始化一个变量。那就是 numpayments，你将其设置为 0（10）。你有一个关于该变量的条件检查。在这种情况下，numpayments 小于 5（11）。并且你在每次迭代中更新变量，你递增 numpayments（15）。

打印出哪些付款？第一个是什么，最后一个是什么？

```
cout << "Balance " << balance << endl;
cout << "Payment " << payment << endl;
balance += balance * interest;
balance -= payment;
umpayments++;
```

你在此情况下打印出的第一个是 0 次付款后——换句话说，初始余额。这是因为变量从 0 开始，而在 while 条件之后做的第一件事就是打印结果。

这是一种非常常见的组织循环的方式。你初始化一个变量，你的循环条件依赖于该变量，并且你在每次迭代中更新该变量。
