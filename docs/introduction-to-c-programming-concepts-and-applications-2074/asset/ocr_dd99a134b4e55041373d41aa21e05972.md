The forward_list is very similar, but you can only call push_front, or insert after an element. In this code, you push your instructions in reverse order because they're getting onto the front of the list (h).

Then, you have an iterator that is set to the second element (i). When you call insert_t at point, you insert your instruction after the second element (16).

So, printing the list gives you your instructions. Notice that the peanut butter is getting onto the jelly, because the insertion would always come after the element you were pointing to.

Iterators can also make your use of vectors and data structures powerful by using the for in a new way. If a class can be iterated through, you can form a special for loop. You can set up a for loop that has a variable that takes the value of each element in a container. The for loop will iterate from beginning to end, and the variable will take on each value

The syntax for this is to write for and then, in parentheses, 2 items separated by a colon. The first of these is the variable type and the variable name. When you use this type of function, the variable is only going to be

    forward_list<string> instructions;
    instructions.push_front("Put two halves together");
    instructions.push_front("Put on jelly");
    instructions.push_front("Get bread");
    forward_list<string>::iterator insert_spot;
    insert_spot = // Refers to first element
    insert_spot++; // Refers to second element
    instructions.insert_after(insert_spot, "Put on peanut butter");
    for (auto iter = instructions.begin(); iter != instructions.end(); ++iter) {
        cout << *iter << endl;
    }
}
