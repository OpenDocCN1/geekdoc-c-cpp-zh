## // STRING VARIABLES AND LITERALS

Up now, you've been using string literals—specified values of some type. Just like you can have variables let you store and manipulate Boolean values, you would also like to have variables let you store and manipulate strings. To do this, you use a new type of variable—the string. String variables are the main way you use and manipulate text data.

Unlike int, float, and bool, a string is not a built-in language type. To have a string type, you're going to bring in a new library, the string library. Once you've done that, you can declare string variables, just like you declare other types.

Think of a literal as being in contrast to a variable. A variable can potentially be any value of a certain type; a literal is some specific value.

If you have a variable x and a line of code like x = 5, x is a variable while 5 is a literal. If you stream 3.14 to cout, you're streaming a floating-point value. Or, if you assign 3.14 to a floating-point variable f, then you're printing a variable.

The string library is one of the standard C++ libraries, so you have access to it, #include string. And everything in string falls in the namespace, so using namespace std at the beginning means you don't have to list the namespace explicitly.

Finally, you output, streaming the value of the string variable is cout, just like you would have streamed out a string literal.

```
// Program 9_3
// A greeting program handling first and last names
#include <iostream>
#include <string>
using namespace std;

int main() {
    string firstname, lastname;
    cout << "What's your name? (Enter first name and last name) ";
    cin >> firstname >> lastname;
    cout << "Howdy, " << firstname << " " << lastname << "!" << endl;
}
```

You can stream in data with cin, but what if you want to read in a longer piece of text, such as a sentence with spaces and punctuation? There is a function called getline that is defined within the string library that you do this.

```
// Program 9_5
// Using getline
#include <iostream>
#include <string>
using namespace std;
int main() {
    string username;
    cout << "What is your name? ";
    getline(cin, username);
    cout << "Howdy, " << username << "!" << endl;
}
```

## // STRING OPERATIONS

In Program 9_6, you have 3 strings-named s1, s2, and s3—and assign the string Happy to s1 and the string Birthday to s2.

This means that the addition operation, + works differently for 2 strings than it does for 2 numbers. The + operator is overloaded, which means it has more than one meaning, depending on the types of the input.

In Program 9_8, you have a string, s, that you initialize to the value Happy. You then have a line: s += "Birthday";

Then, you have a s3 = s1+s2. In other words, you are adding 2 strings to get a third string.

When you run this, you'll get a concatenated string, HappyBirthday, with no space in between. The Birthday has been appended to the original string, which was Happy. Basically, you took the value in the string and performed a + operation on the right side, putting the result back in the original variable. But + for strings is defined as concatenation, so the 2 strings were concatenated and the result was placed in s.

If you run this program, outputting s3 gives you a string HappyBirthday, with no space between the words. Basically, the s3 was formed by the first string, Happy, and sticking the next string, Birthday, onto the end. This is called concatenation. You have concatenated the strings s1 and s2 to form s3.

Operator overloading is a common practice for defining behavior between different types.

> A + does not always mean addition.
The meaning of various operators changes depending on the type of thing they are operating on.
