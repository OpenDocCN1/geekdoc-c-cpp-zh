# // BOTTOM-UP DESIGN

The idea of bottom-up design is to take existing things you know how to do and combine them into something new. Then, you could use that to do something you work up the hierarchy, using individual functions as building blocks.

In this simple example you might use in a word processor, you have a function, pos_first, that lets you find the first occurrence of some word in a string (f). And you have another function, replace_string, that lets you replace one section of a string with a different string (g). You can look at these functions and realize that you can use them to replace the first occurrence of one word with another. So, you would create a new function, search_and_replace, that will replace larger string (h).
