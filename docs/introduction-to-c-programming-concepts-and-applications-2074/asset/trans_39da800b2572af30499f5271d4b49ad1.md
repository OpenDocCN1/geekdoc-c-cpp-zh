## MAPS

The **map** is a way to associate one value, called a key, with any other of any type. map comes in 2 variants: the standard **map** and the **unordered_map**. The difference between them is that a **map** can be iterated through in order from least to greatest, whereas an **unordered_map** is faster to use.

```
// Program 23
// Map example - animal shelter
#include <iostream>
#include <string>
#include <map>

using namespace std;

int main() {
    map<string, int> animals;
    animals["cat"] = 12;
    animals["dog"] = 23;
    animals["rabbit"] = 2;

    cout << "Which animal do you want to count? ";
    cin >> whichanimal;

    if (animals.count(whichanimal) > 0) {
        cout << "There " << whichanimal << " in the shelter." << endl;
    } else {
        cout << "That animal is not in the shelter." << endl;
    }
}
```

Sometimes you'll hear a map referred to as a dictionary, because it provides a way to associate an "entry"—that is, the key—with its "definition," or value.

## TEMPLATED FUNCTIONS

In addition to containers, the STL also offers a set of standalone functions that can be called with a wide range of argument types. These are called **templated functions**, because they are not just defined for a single type or set of types but can take on a wide range of types.

An **algorithm** can be thought of as a set of steps to follow to handle data or accomplish some other task.

The point of the **algorithm** library is not to provide functions you couldn't create on your own, but instead to provide reliable, efficient implementations using commonly algorithms that can be applied across a wide variety of data types.

The STL **algorithm** library contains more than 80 templated functions, each implementing some algorithm. Templated functions can take a range of various types of input parameters. The STL **algorithm** library's functions fall into categories ranging from simple minimum and maximum computation from modifying sequences.

These templated functions are all contained in the STL **algorithm** library, so to use any of them, you just #include **algorithm**.

Three of the most common templated functions in the STL are **find**, **sort**, and **lower_bound**.

Algorithms describe the critical functionality of most major computer programs, from operating systems to search engines—all the types of programs that C++ tends to be used for.

## FIND

find takes 3 parameters: a starting iterator, an ending iterator, and a value to search for. It returns an iterator: either pointing to the first occurrence that matches the value being searched for, or, if the value is not in the container, then it returns the iterator.

Often, find is used to find all values in some container. It works by searching through the container and examining every element one by one to see if a value is present.

Suppose you have a list of ages of participants in some study and want to allow a user to check whether certain ages participated. Notice that algorithm is #included.

In this case, you use a vector of integers, named ages, the ages of the participants. Notice that some ages, such as 21 and 22, are repeated.

Then, you have an infinite loop which will continually ask the user age to search for.

In the loop, you use the find function to try to find the particular age the person entered. In ages.begin, which is an iterator pointing to the beginning of the ages vector, and ages.end, which is an iterator pointing past the end of the ages vector. The third parameter is the value you're searching for in this case, the iterator the user enters.

find will return an iterator. If the value entered is found, then the iterator will not be pointing to the end iterator. So, you can verify that the age was found, and for proof, print the value that the iterator is pointing to. If the value was not found, then the iterator will point to the end iterator, so you output that the value was not found.

```
// Program 23_8
// Find example
#include<iostream>
#include<vector>
#include<algorithm>
using namespace std;

int main() {
    vector<int> ages = { 23, 21, 18, 22, 21, 19, 20, 19, 27, 22 };
    iterator findval = find(ages.begin(), ages.end(), age);
    cout << "I have a list of ages of participants." << endl;
    while (true) {
        cout << "What age do you want to find?" << endl;
        findval = find(ages.begin(), ages.end(), age);
        if (findval != ages.end()) {
            cout << "Found: " << findval << endl;
        } else {
            cout << "not found" << endl;
        }
    }
}
```
