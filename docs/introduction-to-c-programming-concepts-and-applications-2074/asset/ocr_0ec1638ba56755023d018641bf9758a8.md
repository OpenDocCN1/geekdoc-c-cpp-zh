Once you have your IDE, it's time to try writing and running a program in the IDE. Find the IDE you installed on your system and start it up.

When you start the IDE, the first thing you'll need to do is create a new project. The project will hold all the C++ files that you are creating to generate different programs throughout this course.

Setting up a new project is a little different in Visual Studio and Xcode.

+   In Visual Studio, you will create a new project, selecting Empty Project when you have a chance.

+   On a Mac, you'll need to select it for your operating system (Mac OS X), that you want a command-line tool, and you want a C++ project.

In both IDEs, you'll need to pick a name for your project; make it something descriptive, such as "GreatCoursesLecture!

Once a project is created, you'll need to have an actual C++ project that will hold your program.

In Visual Studio, you'll need to "add a new item" to your project, and that new item will be a C++ file. You get to choose the name of the C++ file.

In Xcode, the file will be provided automatically and will have the name "main.cpp"; you just find the file listed under the project folder and click on it.

Once that's done, you'll be able to enter your Hello, World! program, or whatever code you want to write. When your code is entered, it's time to compile and run.

In Visual Studio, you do this by selecting Start Debugging or Without Debugging from the Debug menu. After the first time running, you'll also be able to click the green arrow labeled Windows Debugger.

In Xcode, you'll just hit the Build and Run arrow near the top left.

When this happens, you should get the Hello, World! output to a window that pops up. In the Mac version, that window will appear at the bottom right of the Xcode window.

In Visual Studio, a new window will pop up, but it will disappear as soon as the program is over. To keep that window open so you can actually see what's output, you'll want to add one small line to your code: system ("pause"); Be sure to add it as the last line before the final call. This system-command basically says "pause the system until you hits a key" and will keep the window open for so you can see the output.

Just to see what happens, you might want to make an unintentional error in your code. For example, leave the c off of your cout. That should cause a compiler error, and you will see how your IDE identifies and reports the error to you.

Now you're ready to develop your programs in your IDE. 🔸
