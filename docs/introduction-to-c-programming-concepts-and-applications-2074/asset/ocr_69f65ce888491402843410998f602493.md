Although at is certainly a safer way to access elements of a vector, it has a downside: Every time you try to access an element with at, the computer is going to check the bounds of the array to try to something you shouldn't, every time you access an element is going to be a bit slower.

For most programmers, this is not a big deal; the program runs plenty fast, and the microseconds taken to check a value are insignificant. But for applications performance is critical—where there are going to be millions of attempts to access array or vector elements—checking the bounds each time could be a significant factor. So, the usage of square brackets versus at is not consistent.
