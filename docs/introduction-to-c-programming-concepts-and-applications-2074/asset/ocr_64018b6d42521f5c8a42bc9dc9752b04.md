In the savings_account class, there's a private member variable, interest_rate (58). Remember that for classes, if you dont declare it as public, private, or protected, it's assumed to be private. But just to be clearly, let's explicitly declare it private by putting private: beforehand.

You also have two public methods that might want to invoke from outside the class: begin_account and generate_interest. Like the checking_account, these access the protected function set_account and the protected balance that are inherited from the bank_account().

If you then, in main code, want to work with some individual accounts, you can declare both checking_account and a savings_account object for that. In this case, you have accounts named Holmes_checking and Holmes_savings, and you can call any of the public methods on them. So, you can call begin_account and savings_account class. You can deposit and withdraw from the checking_account or generate_interest on the savings_account. Or you can call update_owner and print_account, functions that were defined in the base class bank_account.

```
private:
    double interest_rate;
public:
    void begin_account(long int num, double amt, double rate) {
        set_account(num, amt);
        interest_rate = rate;
    }
    void generate_interest() {
        balance = balance + interest_rate;
    }
}
int main() {
    checking_account Holmes_checking;
    savings_account Holmes_savings;
    Holmes_checking.begin_account(1122233, 100.0);
    Holmes_checking.update_owner(09988877, "Sherlock Holmes", "221B Baker St., London");
    Holmes_savings.begin_account("Sherlock Holmes", "221B Baker St., London", 50.0, 0.3);
    Holmes_savings.update_owner(09988877, "221B Baker St., London");
    Holmes_checking.deposit(50.0);
    Holmes_checking.withdraw(25.0);
    Holmes_savings.generate_interest();
    Holmes_checking.print_account_info();
    Holmes_savings.print_account_info();
}
```

All of this runs fine. Within any class, you are accessing only functions and variables that were either defined in that class or were public or protected properties from an ancestor. From outside of the class, you are only accessing public properties of the class.

But there are several things you would not be allowed to do. You could not access a private member of the class, and you could not access any private member function from outside the class.
