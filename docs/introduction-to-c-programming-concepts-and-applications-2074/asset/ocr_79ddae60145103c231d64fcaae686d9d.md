When talking about a vector, unlike say "vector" of some type, such as "vector" of "floats." And these can be thought of the type of the variable.

Unlike an array, you don't specify a size for vectors. One of the interesting features of vectors is that they can grow in size as you need them. Initially, when you declare a vector like this—it has no elements in it. In this example, you add elements to the vector and it will increase in size as you do.

Notice that there's something different about these function calls. You have the name of the vector, which is Vector, and then the function call. You do not just call the function by itself; the name of the vector comes before the function call.

The next 3 lines (a) show one of the common ways of adding data to a vector. You use a function called push_back to add a new element at the end of the vector (in other words, it gets pushed onto the back of the vector). And that will have whatever value is argument.

This is an example of a member function—in this case, push_back—which "belongs" to the particular variable. The period is used to say "The first thing." The second part is part of the first thing. belongs to Vector; the push_back function is part of the vector named Vector. And this push_back is going to push the value at the back of vector, and nowhere else.

When you get to the first line, you'll add a 1 onto the end of the vector. Because the vector started with no elements, after that line, it will have the value 1. The second line will add an element with value 2 onto the end of the vector. And the third push_back will add a third element to the vector—one with a value of 3.

The last line in our program is output line. You'll stream values to count: Vector[0], and Vector[2], separated by spaces. Notice that you are adding the elements of the vector using the same notation as you had for an array: an index you want in square brackets.

```
// Program 8_2
// Example of a vector
#include <iostream>
#include <vector>
using namespace std;

int main() {
  vector<int> Vector;
  Vector.push_back(1);
  Vector.push_back(2);
  Vector.push_back(3);

  cout << Vector[0] << " " << Vector[2] << endl;

}
```
