This slightly more complex program has 3 different lines of code in the main program—the program lines that begin just below the int main. All 3 of these lines are nearly identical; they print out some text. Each one prints out on a different line. The first says, *Howdy, John!* The next one says, *Are you ready to learn C++*, and the final says, *Let's get started...*

Each output also includes an end-of-line character.

Commands are executed in sequential order. When you have a series of commands, like the 3 count statements you have, the program will handle each of them in sequence—the order specified. So, if you consider a program as being a series of commands, then running the program is executing these commands in order.
