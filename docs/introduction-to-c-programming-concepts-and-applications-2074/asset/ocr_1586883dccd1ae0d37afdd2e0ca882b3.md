Notice that the private variable points is initialized to 0. The number member function will return the value of points, so the first output line will state that the points are initially 0. The increasepoints member function increases the points by the argument value, which is 10 in case. Thus, the next line of output is 10. Finally, the givebonus member function will increase the points by 500, increasing points by 500 more, so the final output line will output the value 510.
