## // OVERLOADING FUNCTIONS

This is one way to write a function that returns the average of 3 numbers.

What if you want to modify this function? What if you really wanted the average of 2 numbers or wanted to handle averages of 4 numbers?

```
 // Program 13_1
// Function review: function to average 3 numbers
#include <iostream>
using namespace std;

float average(float a, float b, float c) {
    return (a + b + c) / 3.0;
}

int main() {
    cout << "The average of 10, 35, and 17 is: " << average(10, 35, 17) << endl;
}
```

you can create 2 new functions, each with the same name, but with different numbers of parameters. This approach is called function overloading—creating more than one implementation with the same name.

You'll create version of average that has just 2 parameters: a and b. Everything is basically the same; you just return the two parameters by 2.0 (a).

You'll also create a version of average that has 4 parameters, a and d. Again, the function is basically the same, with just one parameter and the average computing the sum of 4 parameters by 4.0 (b).

When you call average, you can call it with 2, 3, or 4 parameters. The compiler will call the appropriate function, whether it's one of 2, 3, or 4 parameters.

Notice when you overload a function, it makes sense to use the same name for all the variations; you don't want to overload functions when the variations will have very different names.

The function's header defines the function signature, which is the name of the function but also the number and types of parameters the function defines by name

take in. When there is a call to a function, the compiler will match the call to the function signature—one that has the right name, number of parameters, and the right types of parameters. The names don't matter in the signature; it's just their number and types.

In the Program 13_2, you have a function named average that takes 2 floating-point parameters, another function named average takes 3 floating-point parameters, and another function named average takes 4 floating-point parameters. These function implementations are all distinct from each other.

While the signature includes the function name and the number of parameters, it does not include the return type. So, it's not possible to overload by having 2 functions of the same name returning different types—for example, returning a string and returning a float.

However, you can convert one type to another when a function is called. If you call a function with parameters that don't exactly match the signature they can be automatically converted to one that match the signature—such as converting integers to floats—that only works if there's one possible matching signature.

```
// Program 13_2
// Multiple parameter options
with different function signatures
#include <iostream>
using namespace std;
float average(float a, float b) {
    return (a + b) / 2.0;
}
float average(float a, float b, float c) {
    return (a + b + c) / 3.0;
}
float average(float a, float b, float c, float d) {
    return (a + b + c + d) / 4.0;
}
int main() {
    cout << "The average of 10, and 35: " << average(10, 35) << endl;
    cout << "The average of 10, 35, and 17: " << average(10, 35, 17) << endl;
    cout << "The average of 10, 35, 17, and 21: " << average(10, 35, 17, 21) << endl;
}
```

No 2 functions are allowed to have the same signature, because the compiler needs to be able to distinguish between functions.
