## // CHAR-TYPE VARIABLES

字符串基本上由一个字符的数组或向量组成。字符是一个字母、数字、标点、空格等，每个都有其自己的内置类型。

在 C 中，字符串基本上是一个数组。在 C++ 中，虽然其基础仍然是一个数组，但你可以使用具有许多类似向量的选项的字符串。

你不需要 #include 任何库即可访问它。类型是 char。

程序 9_9 是一个使用 char 类型变量的非常基础的程序。请注意，你不需要 #include 任何特殊库来使用 char；你只需要 iostream 即可将输出到控制台。

```
// Program 9_9
// char type
#include <iostream>
using namespace std;
int main() {
char testchar;
testchar = 'a';
cout << testchar << endl;
}
```

在 C 和 C++ 中，字符用单引号 (' ) 括起来，并且里面只能有一个字符。字符串使用双引号 ("")。

注意：单引号和双引号应为基本的标准引号。如果你使用一个词来编写代码，它经常会“帮助”将这些引号更改为花体引号——这不是同一回事，并且会在你的程序中导致错误。

你通过编写 testchar; 声明一个名为 testchar 的 char 类型变量；你可以为 testchar 分配一个值——在这种情况下为 a。当 testchar 被流式传输到输出时，a 会打印到屏幕上。

C++ 中，字符串基本上是由 chars 组成的向量。这与 C 中处理字符串的方式不同，C 基本上使用一个 char 数组，并在末尾加上一个额外的空字符——ASCII 0——来标记字符串的结束。

即使在 C++ 中，字符串字面量仍然像 C 风格的字符串。因为你不能添加数组，所以你不能添加字符串。

在 C 和 C++ 字符串中，字符串中的特定字符都可以使用方括号访问。由于 C++ 字符串像向量一样操作，我们拥有向量相对于数组的所有优势。

例如，回忆一下 at 成员函数允许你访问特定字符并检查是否超出数组边界。

你也有能力获取字符串的大小，就像获取向量的大小一样。更易于以字符串的长度而不是大小来思考，因此也提供了 length 命令。

字符串可以很好地相互比较。你可以检查两个字符串是否相等。这意味着每个字符都要检查是否匹配。检查两个字符串是否不相等也是同样的道理。

比较字符串是按字母顺序排序的基础。因为大写字母在 ASCII 中排在小写字母之前，所以 "Zebra" 在比较字符串时会在 "apple" 之前。

比较小于或大于有点棘手。这实际上涉及考虑 ASCII 字符是否在之前或之后。要根据 ASCII 表比较一个字符串是否在另一个字符串之前，比较将按字符进行，以找到第一个不匹配的字符。如果一个字符串中第一个不匹配字符的 ASCII 值更大，则该字符串为“更大”。

字符串还有其他有用的成员函数：

- empty 返回一个布尔值，如果且仅当字符串为空——即不包含任何字符时为真。
- find 接受另一个字符串作为参数。它返回该第一个字符串在给定字符串中出现的位置，
- substring 函数接受两个参数；第一个是起始位置，第二个是长度。它返回一个新字符串，即旧字符串的一部分。它将是起始于起始位置且长度为指定长度的部分。
- replace 函数允许用另一个字符串替换字符串的一部分。
