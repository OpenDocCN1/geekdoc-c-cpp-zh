
Because a program is not too useful until it is linked with the library, the linking phase is usually combined with the compiling phase. In fact, when people talk about compiling, they usually mean "compile and link."

The libraries are usually already compiled in advance. The standard C++ libraries are installed automatically when you install the C++ compiler. If you create your own library, you'll compile that part of them, too.

## THE C++ STANDARD LIBRARY

The first libraries to be aware of are standard set of files that are included with every C++ installation. These libraries are collectively called the C++ Standard Library, and there are around 50 of them. All these libraries are the ones to rely on when you have whatever you want to do. Just write a #include near the top of your program, putting the library name inside the angle brackets.

C++ basically grew out of C, C++ libraries have been inherited from C. And C was, and still is, used for several applications, so many libraries were developed for C, including some standard C libraries, such as one for math. C++ still provides access to all of these libraries, which are named "c__", where the "_" is the name of the C library.

The standard C++ libraries provide a lot of functionality for you to make of. There are dozens of functions located in the math library.

The website cplusplus.com gives clear explanations for lots of functions, including all the standard C library headers.

Try following the Reference link on the site to find more about a specific topic. Or just try a search engine; the first second item in the search results may take you to the same location.

In the case of this code, you're going to use the cmath library. To do this, you'll #include cmath. This will take the header file, cmath, and put all that header information into your code. One of the things cmath will give you access to a square root function, sqrt, which you can use in your program.

Inside those parentheses, there will often be arguments, which are values that you will be giving to the function. In the case of computing a square root, you need one number to take the square root of. So, you need to have one argument: the number to take the square root.

In this case, you print out the square root of 2.0, which is 1.41421.

When you write code and want a function to happen, you write the function name and parentheses, along any arguments you need to give it. This is referred to as a function call, and it is said that you are calling or invoking the function. It means that when you get to that part of the code, you execute the code corresponding to that function. Remember, not every function needs arguments; some perform operations without requiring them. But regardless, they'll still have parentheses.

This is the first time you've really used a function in your code. When you use a function, there are 2 key parts: a function name and parentheses that come after it.

In the square root example, you have a function for computing the square root, and the name is sqrt. After the function name there will always be a pair of parentheses.

If the function is designed to compute some value, that value is called by the value computes. It is said that the function has returned a value. For the square root function, you will have a floating-point value–the value of the square root–returned. Whenever you encounter a function call, if there is a return value, you can think of the function call as just being replaced by the value of the function.

```cpp
// Program 6_4
// Using cmath (and iostream)
#include <iostream>
#include <cmath>
using namespace std;

int main() { 
  cout << sqrt(2.0) << endl;
}
```

Notice that the square root function occurs in the middle of an output statement. The value that is returned from the function is output.

The square root function, like all functions, is not defined in C++ all by itself. To access it, you need to get it from the cmath library, which includes a variety of math functions, such as power function (pow), trigonometric functions, and exponential and logarithmic functions.

Suppose you want to develop a guessing game in which the computer picks numbers and the user has to guess the number picked.

To do this, you need a function that lets you get a random number. Random number generation is actually a tricky problem—it's nearly impossible to generate truly random numbers with a deterministic computer—but the key is to use pseudorandom numbers, which seem like random numbers and are just useful for most applications.

In this case, C++ has 2 standard libraries that will generate numbers. One of them is called random, but it's complicated to use. An easier-to-use library is the C Standard Library, rand, which includes the widely used function rand, which does not take any arguments and returns an integer. The integer will be some number between 0 and maximum-possible random number.

```cpp
int main() {
    int x = rand();
    cout << "The random number is " << x << endl;
}
```

You can tell others, people who understand pseudorandom number generation have implemented ways of getting these numbers for you.

To generate a random number, you have a simple program that you can generate by #including the cdblib header. Then, you can use the function rand, with no arguments, in the code to give you an integer.

### Importing C++ Functions

With pseudorandom number generation, we have to initialize the seed, which is the starting point. If you give the same seed, you will always get the same sequence of numbers.

Notice that the sequence you get for a seed of 3 is very different from that for a seed of 4, which would be very different from a seed of 5, and so on.

```cpp
// Program 6_9
// Random Number generation
example with seed (new seed)
#include <iostream>
#include <cstdlib>
using namespace std;

int main() {
  srand(3); // Set the seed for
the pseudorandom sequence
  int x = rand();
  cout << "The random number is " << x << endl;
}
```
