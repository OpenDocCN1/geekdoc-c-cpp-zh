There are several generic tasks and ideas—that are very widely applicable—that work well with templates.

The most common of these generic concepts are available to programmers through the Standard Template Library (STL), which is a library—a collection of templates and functions that can be included in your program. It's in the sense that there is a clearly defined set of what is expected to be provided in the library. And uses templates, meaning that provides generic container structures and algorithms.

The STL is likely all you'll need for generic programming; you will probably rarely find that you want to write your own templates classes or functions.

The vector class is an example of a container, and it's just one of several generic containers that are provided in the STL.

Vectors are also great at letting you access an element at a specific point in the vector. This is referred to as random access because you can access any point at random; you do not have to access them in a particular order. A vector is not good at inserting a new element at the beginning, or somewhere in the middle, of an vector.

Containers are classes that collect several instances of some type in a way that allows operations to be performed very efficiently.
