
// Program_10_4
// Use of the eof function in a while loop
#include <fstream>
#include <iostream>
#include <string>
using namespace std;

int main() {
    fstream my_file;
    my_file.open("GroceryList.dat");
    string s;
    while (!my_file.eof()) {
        cout << s << endl;
    }
    my_file.close();
}

eof 函数在 while 循环中很有用。你设置一个循环，直到到达文件末尾，此时 eof 函数返回 true (a)。该循环会从文件中读取每个字符串并将其输出到控制台。

无论你是第一次检查 while 还是完成循环的一次迭代，你总是尝试在检查 EOF 之前读取一个字符串。如果你未能读取一个字符串，那就是你在检查时 EOF 是否为 true。

请注意，eof-file 在读取文件中的最后一行时并不是 true；在读取该项之后它仍然为 false。只有在你尝试再次读取并且没有剩余内容可读时，eof 才会为 true。

请注意 while 循环基本上是 for 循环。你读取一个初始化步骤，在其中读取一个字符串；有一个条件，使 eof 为 false；每次循环迭代，你再读取一个字符串。

因此，在 Program 10_4 中，请注意你需要在进入 while 循环之前先从文件中读取一个字符串；然后在循环内部的最后一步再次读取一个字符串 (b)。

因此，你可以使用 for 循环 (c) 来编写它，这用一条语句描述了循环的行为。

## // STRING STREAMING

C++，流式传输的概念意味着任何使数据流入或流出某物的方式。这意味着有其他不涉及文件或控制台的流式传输方式。

你对 stringstream 进行的输入输出数据将被写入或从其中存储的字符串中读取。

特别是，你也可以对字符串变量进行流式传输和流式传输。这让你可以将数据存储在字符串中，类似于将数据存储在文件中，而无需在操作系统上实际放置文件。它让你避免在输入结束时请求哨兵值。

因此，如果你要从 stringstream 流式传输数据，你需要为其提供一些初始值。换句话说，你需要告诉 stringstream：“这是一个要使用的起始字符串。”有一个内置命令 str，用于指定你想要用作默认值 的字符串。

// Program 10_8
// Using a stringstream for input
#include <sstream>
#include <iostream>
#include <string>
using namespace std;

int main() {
    string stringreader;
    stringreader.str("Apple Banana Cherry");
    string first_word;
    stringreader >> first_word;
    cout << "The first string read was: " << first_word << endl;
}

你可以通过使用操作创建字符串并像你想要的那样写入文件。你也可以从字符串流式传输，处理字符串中的数据，就像你处理文件中的数据一样。

Program 10_8 是一个简短的程序，从字符串中读取一个词。请注意你在开头包含 <sstream (3)。

你声明的类型是此 stringstream 类型变量，变量名为 wordreader (9)。

要对字符串进行输入输出，你需要一种新的类型来包装 stringstream。它是一种将字符串链接到你一直在使用的 stringstream 操作的变量类型。

你有一个这种新类型的变量，并且需要用某个特定字符串对其进行初始化。在本例中，你用字符串 Apple Banana Cherry 初始化 wordreader (10)。

要声明和使用这种新类型的变量，你需要包含 sstream 库以提供“链接”来存储特定字符串。这就是文件流“链接”到特定文件的方式，但 stringstream 也存储特定字符串。就像你需要写入或读取文件一样，你对 fstream 进行输入输出，当你想要从字符串读取或写入时，你对 stringstream 进行输入输出。

流式传输的一般形式无论你使用 cin 从控制台获取输入，使用 fstream 从文件获取项目，还是使用 stringstream 从字符串获取项目都不会改变。因此，假设你想要获取第一个词。你可以从 wordreader 流式传输到 first_word (12)。这将读取 wordreader 持有字符串中的第一个项目。换句话说，直到第一个空格的文本被读取，然后分配给 first_word——在本例中为 Apple。你的输出验证了 Apple 就是分配给 first_word 的内容。

注意模式：

+   fstream 用于与控制台的输入输出
+   fstream 用于文件
+   sstream 用于字符串

// Program 10_7
// Averaging values in a file
#include <fstream>
#include <iostream>
#include <string>
using namespace std;

int main() {
    fstream bank_file("balances.txt", fstream::in);
    float f;
    float total = 0.0;
    int num_vals = 0;
    for (bank_file; !bank_file.eof(); bank_file >> f) {
        total += f;
        num_vals++;
    }
    bank_file.close();
    cout << "The average was " << total / num_vals << endl;
}
