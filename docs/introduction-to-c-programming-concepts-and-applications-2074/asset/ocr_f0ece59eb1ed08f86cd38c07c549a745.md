Data is more than just a single value, and you often want to keep track of multiple types of data at the same time, when different data values are all tied together.

In Program 7_8, you have 2 parallel arrays which are used to store a data. The 3 arrays will store a year, a month, and a day. The arrays to size up to 100, you can assign a data by assigning the day, month, and year to the elements of the 3 arrays, assuming they have the same index.

The method of doing this is parallel arrays. You create multiple arrays, each having one different type of data. And you tie these together by making sure that the same index in each array refers to the same item. So, if you have an array to store low temperature, then element 20 in both arrays refers to the same day. You can get the low and high for that just by using that index.

You can also have array of arrays, or multidimensional arrays. You can declare a 2-dimensional array by declaring a variable name with 2 sets of brackets, with a value inside.

Suppose you want to keep track of 5 people, each of whom has 3 bank accounts: an account, a savings account, and a credit card account. So, you would want an array that is 5 elements long. Each of those elements would be an array of length 3. So, overall it is 5 by 3. You could declare this by the statement double accounts[5][3] as in Program 7_8. The name of the 2-dimensional array is accounts.

```
// Program 7_8
// Parallel Arrays
#include <iostream>
using namespace std;

int main() {
    int year[100];
    int month[100];
    int day[100];

    //January 1, 2000
year[0] = 2000;
month[0] = 1; day[0] = 1;
//February 12, 2007
year[1] = 2007;
month[1] = 2; day[1] = 12;
}
```
