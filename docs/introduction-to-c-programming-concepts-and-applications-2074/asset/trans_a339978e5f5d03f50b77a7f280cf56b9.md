## THE C++ STANDARD LIBRARY

首先需要了解的是随每个 C++ 安装一起提供的一组标准文件。这些库统称为 C++ 标准库，大约有 50 个。所有这些库都是你在想要做某事时可以依赖的。只需在程序顶部写一个 #include，并在尖括号内放入库名即可。

C++ 基本上是从 C 发展而来的，C++ 库继承自 C。而 C 当时并且现在仍被用于多种应用，因此为 C 开发了许多库，包括一些标准 C 库，例如数学库。C++ 仍然可以访问所有这些库，它们被命名为 "c__"，其中 "_" 是 C 库的名称。

标准 C++ 库为你提供了大量可用的功能。数学库中包含数十个函数。

网站 cplusplus.com 对大量函数提供了清晰的解释，包括所有标准 C 库头文件。

尝试在该网站上点击 Reference 链接以了解有关特定主题的更多信息。或者只需尝试搜索引擎；搜索结果中的第一第二项可能会带你到同一位置。

在这种情况下的代码中，你将使用 cmath 库。要做到这一点，你需要 #include cmath。这将把头文件 cmath 的所有头信息放入你的代码中。cmath 提供的东西之一是平方根函数 sqrt，你可以在程序中使用它。

在这些括号内，通常会有参数，即你将提供给函数的数值。在计算平方根的情况下，你需要一个要开平方的数字。所以，你需要一个参数：要开平方的数字。

在这种情况下，你打印出 2.0 的平方根，即 1.41421。

当你编写代码并希望某个函数执行时，你写下函数名和括号，以及你需要提供的任何参数。这被称为函数调用，据说你正在调用或调用该函数。这意味着当执行到代码的该部分时，你执行与该函数对应的代码。记住，并非每个函数都需要参数；有些函数在不需要它们的情况下执行操作。但无论如何，它们仍然会有括号。

这是你在代码中真正使用函数的第一次。当你使用函数时，有 2 个关键部分：函数名及其后面的括号。

在平方根示例中，你有一个用于计算平方根的函数，名称为 sqrt。函数名后面总会有一对括号。

如果函数设计为计算某个值，该值称为由值计算。它被称为函数返回了一个值。对于平方根函数，你将有一个浮点值——平方根的值——被返回。每当你遇到函数调用时，如果有返回值，你可以认为函数调用只是被函数的值所替代。

```cpp
// Program 6_4
// Using cmath (and iostream)
#include <iostream>
#include <cmath>
using namespace std;

int main() { 
  cout << sqrt(2.0) << endl;
}
```

请注意，平方根函数出现在输出语句的中间。从函数返回的值被输出。

平方根函数与所有函数一样，并不是单独在 C++ 中定义的。要访问它，你需要从 cmath 库获取它，该库包含各种数学函数，例如幂函数 pow、三角函数以及指数和对数函数。

## RANDOM NUMBERS

假设你想开发一个猜数字游戏，其中计算机挑选数字，用户必须猜出所选的数字。

在标准 C++ 库中，如果存在的话，搜索“ C++ random ”的网络搜索可以是最快的方式来识别相关的库函数。

| // Program 6_7 |
| // Random Number generation example |
| #include <iostream> |
| #include <cstdlib> |
| using namespace std;|

要做到这一点，你需要一个函数来获取随机数。随机数生成实际上是一个棘手的问题——用确定性计算机生成真正随机的数字几乎是不可能的——但关键是使用伪随机数，它们看起来像随机数，并且对大多数应用都很有用。

在这种情况下，C++ 有 2 个标准库可以生成数字。其中一个称为 random，但使用起来很复杂。更易于使用的库是 C 标准库 rand，它包含广泛使用的函数 rand，该函数不接受任何参数并返回一个整数。该整数将在 0 到最大可能的随机数之间。

```cpp
int main() {
    int x = rand();
    cout << "The random number is " << x << endl;
}
```

你可以告诉其他人，了解伪随机数生成的人已经为你实现了获取这些数字的方法。

要生成随机数，你有一个简单的程序，可以通过 #including cdblib 头文件来生成。然后，你可以在代码中使用函数 rand，不带参数，以给你一个整数。

| // Program 6_8 |
| Generating multiple random numbers |
| #include <iostream> |
| #include <cstdlib> |
| using namespace std;|

当你有 #includes 时，你正在包含的库文件在括号 < > 中。对此的一种替代方法是使用引号。代码的工作方式完全相同。

如果你运行 Program 6_7，你会看到生成了一个随机数。

你可以通过多次调用 rand 函数来生成更多随机数。每次你都会得到一个新的整数。在 Program 6_8 中，生成了 3 个随机数。

通常，惯例是为 C++ 标准库中的内容使用括号，为你使用的其他库或文件使用引号。

```cpp
int main() {
    int x = rand();
    cout << "The random number is " << x << endl;
}
```

### Importing C++ Functions

对于伪随机数生成，我们必须初始化种子，即起点。如果你给出相同的种子，你将始终得到相同的数字序列。

请注意，你对种子 3 获得的序列与种子 4 的序列非常不同，而种子 4 与种子 5 的序列也非常不同，依此类推。

```cpp
// Program 6_9
// Random Number generation
example with seed (new seed)
#include <iostream>
#include <cstdlib>
using namespace std;

int main() {
  srand(3); // Set the seed for
the pseudorandom sequence
  int x = rand();
  cout << "The random number is " << x << endl;
}
```

有一个名为 ctime 的库，它可以让你访问 如果你想要更随机的东西，你可以选择一个种子而无需指定数字。一种常见的方法是使用当前时间作为种子，即使数字不是真正随机的，没有人能够猜出时间的实际数字。

如果你运行此代码，每次运行你都会得到不同的数字序列。因为计算机中的实际时间每秒都在变化，time 函数每次运行程序时都会给你一个不同的值，每次运行程序时你都有一个不同的种子。
