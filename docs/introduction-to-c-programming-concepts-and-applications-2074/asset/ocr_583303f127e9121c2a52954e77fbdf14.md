The initial step to follow is to convert the outline of the program into comments. Then, in later stages, you would fill in the code corresponding to each comment. The root gives the overall purpose of the program and can be placed at the beginning of the program. The other steps will take place in main. In the following code, the higher levels of the hierarchy are specified with *** ***/, while lower levels use // comments. The blank lines show where code will be written.
