## // TEMPLATES AND CONTAINERS

Basically templates are a way of saying that a class's member variables, or a function's parameters, are not of a specific type but instead of some generic type. So, rather than the class or function working only for one specific type, it can be used for any types that match some type. When you actually want to use a specific class or function, then the template will take on.

For example, the vector is a templated class. It lets you store a list of any type of object, but to use it, you have to create a vector that stores some particular type. So, although vectors have been referred to as a class, are really a more general container capable of holding a variety of unrelated classes.

In ordinary English, the term generic often means "not special" or even "not good," but in programming, the generic means that you are "generalizing" some concept or idea.

```
vector<int> v1;
vector<float> v2;
vector<string> v3;
vector<my_class> v4;
```

The angle brackets, as used when declaring vectors, are used to specify what particular instance of a class or function will take on. The type's specified in the angle brackets is the type that replaces the template throughout the class or function.
