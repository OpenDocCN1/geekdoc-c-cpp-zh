Everything will be the same about, except that the member interest_rate must be set in each constructor. The default constructor just sets this member variable to 0.0 after calling the default bank_account constructor (t). The other constructor takes 5 parameters and 4 of those as arguments to the bank_account constructor.

When you are defining a constructor in a derived class child, you probably need to make use of the constructor in the parent class to fully initialize an object. In particular, if the instances have any private member variables, you'll initialize those by using the parent's constructor, because the derived class cannot access variables itself.
