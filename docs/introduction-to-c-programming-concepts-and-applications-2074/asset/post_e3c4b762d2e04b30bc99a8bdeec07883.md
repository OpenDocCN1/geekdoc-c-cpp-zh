# Exercise 2 Solution

If you run the code, you find that even people who should have gotten a discount got a message meant for those who didn't and that everyone received the same cost, $75.50. Why did that happen?

When you get to the **else** statement, because there were no curly braces, only the first command after the **else** applied to the **else** clause. The other lines—second **cout** and setting **price** to **7.5**—will run for every situation. The fact that they're indented doesn't matter to the computer; they need to be in curly braces if they only apply to the **else**.

This is the type of mistake that happens easily, even to experienced programmers, when people aren't careful to put curly braces around their **if** clauses.

# // THE STRUCTURE OF A C++ PROGRAM

It's often helpful to start a program with some header comment—what might give some information about the purpose of the program (1, 2).

The include is by far the most commonly used, but there are a few other preprocessor commands, all starting with #:

- `#include` statements can bring in new lines of code.
- `#define` statements can modify code.
- `#ifdef` statements (short for if) can choose lines of code.

The next line is pound-include `#include` line (3). The pound sign (#) is used to designate special commands that are given to the **compiler**, which is what will translate your program into machine instructions.

```cpp
// Program 4.1
// Hello, World! program
#include <iostream>
using namespace std;
int main() {
    cout << "Hello, World!" << endl;
}
```

When a compiler looks at a program that it needs to process, it first identifies any lines that have #. These lines are processed as special instructions to the compiler; these are called **preprocess commands**, because they take place before processing the rest of the code.

The include is a way of saying, "There is another file that contains any additional functions. Bringing file into this file gives you access to any functions in that file."

For example, `#include <iostream>` gets you access to input and output functionality, like **cin** and **cout**.

The includes that you usually begin your program with import files to give you additional functionality. These files are used from the C++ standard libraries, which are installed with C++ and therefore are available whenever you need them.

The next line is the **using namespace** command. A namespace is a grouping of various functions together. By saying **using namespace**, you are indicating which group of functions you're using. In this case, the `std` (short for *standard*) namespace. A way to think of a namespace is a special name that needs to be added to the beginning of commands.

There are big projects that require this way of working. There might even multiple namespaces, because different groups on a project often create namespaces. But it can be a pain to keep `std::` before each command. So, `using namespace` lets you say, "I'm using the standard namespace."
