## // 向量：动态内存分配的替代方案

向量是一种在不需要使用指针或 new 和 delete 的分配和析构命令的情况下间接在堆上分配数据的方法。工作隐藏在向量类内部。

获取更多。它分配双倍的内存量，将所有数据复制到这块新内存中，并删除旧内存。现在它有更多的内存可以使用，所以在内存填满之前应该会更久。这个过程可以一直持续，只要向量的数据不断增加。
