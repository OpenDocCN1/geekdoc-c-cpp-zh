You can actually declare variables outside of the main routine! These are called global variables, and they are in scope for the entire program—in every function.

That said, it's much better practice to use local variables, that is, use variables declared in the current function and pass information between functions through return values. That you can see what is going into and coming out of a function by looking at the header. ♦

```
1 // Program 12_11
2 // Use of a global variable
3 #include<iostream>
4 using namespace std;
5
6 int a;
7
8 void my_function() {
9
10  a++;
11 }
12 int main() {
13  a = 1;
14  cout << "Before the function call, the
value of a is: " << a << endl;
15  my_function();
16  cout << "After the function call, the value
of a is: " << a << endl;
17 }
```

```
1 // Program 12_12
2 // Use of local variables only
3 #include<iostream>
4 using namespace std;
5
6 void my_function(int& x) {
7 x++;
8 }
9
10 int main() {
11  int a = 1;
12  cout << "Before the function call, the
value of a is: " << a << endl;
13  my_function(a);
14  cout << "After the function call, the value
of a is: " << a << endl;
15
16 }
```
