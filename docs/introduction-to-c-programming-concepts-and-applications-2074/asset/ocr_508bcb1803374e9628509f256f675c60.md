The name of the constructor function should just be the class name. And the default constructor should have no parameters. If you also access the inventory using the number_remaining accessor function (b), you see that there are 100 items in the machine. The constructor was what set that value to 100.

Inside the curly braces, you have all the default values you want to set (a). The price, credit, and money_collected levels are all set to 0.0. The inventory level is set to a default level of 100. You'll output a message whenever you create a new vending machine this constructor is run (19).
