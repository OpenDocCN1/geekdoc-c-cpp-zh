# // FILE STREAMING

Whenever a program is reading or writing to a file, it always involves 3 steps:

+   1 Opening the file.
2 Reading from or writing to a file.
3 Closing the file.

You're going to need to use a library called `fstream` (which is short for *streaming*) that gives you the tools to write to a file.

Like you were able to use `stream` console input and output `iostream`, now you'll stream and from files using `fstream`.

Once you have the `fstream` library, you can create objects of the type `fstream`.

An `object` can be thought of being like a variable, and you basically use the words `object` and `variable` interchangeably. You use terminology to "declare an object" or "initialize an object" just like you do for variables, such as integers.

But using the term `object` actually implies a little more than you've learned about variables, because an object can store more than one piece of data and has functions that "belong" to it.
