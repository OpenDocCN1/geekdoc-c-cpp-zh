So, you would create a new function, search_and_replace, that will replace larger string (h).

Bottom-up design is a great way to add features to a piece of software. When you have a product that can already do one thing and then have a new idea that integrates with it, you can create a new software product that incorporates an additional feature.

Bottom-up designs tend to focus on what is possible with what you have, rather than the top-down philosophy of how a particular problem is solved. As a result, bottom-up implementations tend to be useful in a wider range of applications.
