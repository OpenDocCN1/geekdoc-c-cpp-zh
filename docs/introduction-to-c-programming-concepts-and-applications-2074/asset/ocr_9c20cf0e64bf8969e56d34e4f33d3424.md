# 1 START A PROJECT

+   - Select "Start a New Project" from the first window
- From Visual Studio, go to -> New -> Project.
- Select Empty Project.
- Enter a Name for the project, then Create.

# 1 START A PROJECT

+   - Select "Create a new Xcode project"
- Pick Mac OS X from the ribbon at the top of the "Choose template box.
- Select Command Line Tool and press Next.
- Enter a name for the project (such as "HelloWorldProject").
- IMPORTANT: Select C+ as the type (which is Swift).
- Choose an Organization Identifier (such as your initials), then press Next.
- Optional, create a folder for your programs (such as "C++ project folder"), then press Create.

# 2 CREATE A C++ FILE

+   - Go to Project -> Add New Item.
- Select "C++ file" (with .cpp extension).
- Enter a Name for the file (e.g., "Hello.cpp"); then click Add.

# 3 WRITE YOUR PROGRAM

+   - Enter your Hello, World! program into the window.

# 2 CREATE A C++ FILE

+   - Look at the left panel of the project folder and click on "main.cpp.
- A window will pop up with a default Hello, World! program in it.

# 4 BUILD AND RUN THE PROGRAM

+   - Go to Debug -> "Start debugging"
- OR Go Debug -> "Start without debugging"
- Hit the F5 key
- Click the green arrow titled Local Windows Debugger.

# 3 WRITE YOUR PROGRAM

+   - Delete code displayed by default.
- Type your Hello, World! program.

# 5 OUTPUT OUTPUT AREA

A window will pop up, showing the Hello, World! output. You can dismiss this by pressing any key inside it.

> NOTE: Visual Studio 2017 (used during the development of this course) required to include system("pause"); at the end of your code in order to keep the output window open. If you're running any older version of Visual Studio, system("pause"); right before the final closing brace in every program you write to make the output window stay.

# 4 BUILD AND RUN THE PROGRAM

+   - Click the arrow to the left of the window OR Go to Project -> Build; then go to Project -> Run.

# 5 OUTPUT OUTPUT AREA

+   - An All Output area should appear in the lower right of the Xcode Window.
- This should have the output results: Hello, World!
