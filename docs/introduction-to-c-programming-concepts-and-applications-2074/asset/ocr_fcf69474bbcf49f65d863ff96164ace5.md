# // COMPARISON OPERATORS

One of the most common ways of determining a Boolean is true or false is with comparison operators.

When you compare 2 values in C++, the result is a Boolean—either true or false.

You can assign the result of the comparison to a Boolean variable, such as by writing TeamWinner = (Team1Points > TeamPoints).

Or you can use a comparison in a Boolean expression, such as by writing (heartrate > 100) || (respiration > 30).

Program 3_7 shows several comparisons. You have 2 variables, Team1Points and TeamPoints, initialized to some values—in this case, 17 and 20, respectively (7).

You can compare to see if Team1Points is less than Team2Points using < (8). The answer is true, and the output will show a 1. The same is true if you use a less-than-or-equal-to (<=) comparison (9).

You can also make a greater-than (>) or greater-than-or-equal (>=) comparison (11). In this case, the answer will be false, because TeamPoints is not greater than, or greater than equal to, TeamPoints.

```
// Program 3_7
// Comparisons: less than/greater than to give a Boolean result
#include <iostream>
using namespace std;
int main() {
    int Team1Points = 17, Team2points = 20;
    cout << (Team1Points < Team2points) << endl;
    cout << (Team1Points <= Team2points) << endl;
    cout << (Team1Points >= Team2points) << endl;
}
```

You can assign the result of a comparison to a Boolean variable. In the snippet of code, there is a water_temp variable and Boolean variables can be created: is_freezing and is_boiling. These are set by comparing water_temp to 32° and 212° Fahrenheit. In this example, the temperature 35.3 is neither, so both comparisons will return false, and thus Boolean values are false.

```
float water_temp = 35.3; // Fahrenheit
bool is_freezing = (water_temp < 32);
bool is_boiling = water_temp >= 212;
```
