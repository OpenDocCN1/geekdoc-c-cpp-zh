Let's figure out how you would write a function that counts the number of words in a string.

One option is to take the string and turn it into a stringstream. Then, you could read individual strings from the stringstream until you reached the end. If you counted how many times you could read a word from the stringstream, that would be the number of words in the original string.

To implement this, you'll create a stringstream (18)—initialized to the string that was an input parameter, str_to_count (8).

Then, you declare 2 variables. The integer count will keep track of how many words you read from the stringstream, so you initialize it to 0 (11). You'll create a string variable named word to hold each word you read out (12).

Next, you'll have a while loop that continues as long as you haven't reached the end of the stringstream (g). Inside the loop, you'll read a new word and increment count. This will keep happening as long as the loop's condition is—that is, ss still has nothing.

Finally, you return the count (18).

In the main program, you can call the function word_count with a string argument (23) and you'll get back the number of words that are in string.

```
// Program 12_6
// A more complete function: counting words in a string
#include<iostream>
#include<string>
#include<sstream>
using namespace std;
int word_count(string str_to_count) {
    // Turn the string into a stringstream
    stringstream ss(str_to_count);
    int count = 0;
    string word;
    // Count the number of individual words by reading from the stringstream
    while (ss.eof()) {
        ss >> word;
        count++;
    }
    return count;
}
int main() {
    string s = "This is a string that has eight words.";
    cout << "There are " << word_count(s) << " words in the string." << endl;
}
```
