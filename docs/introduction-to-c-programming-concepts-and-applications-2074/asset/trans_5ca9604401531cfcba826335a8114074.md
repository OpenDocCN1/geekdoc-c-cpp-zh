要定义它，你需要在声明 jet 时指定 jet 从 airplane 继承 : public airplane。然后，在类内部，你必须只声明新的变量 numengines。

```
class jet : public airplane {
public:
int numengines;
};
```

这些命令是有效的：

```
commercialplane.weight = 10000.0;
commercialplane.numengines = 4;
privateplane.weight = 3000.0;
```

而这个不是：

```
privateplane.numengines = 4;
```

因为 jet 继承自 airplane，jet 具有 numengines 和 weight 变量，因此对 commercialplane 的所有赋值都是有效的。然而，airplane 没有 numengines 变量，所以 privateplane 是一个 airplane 对象，而不是 jet 对象，尝试为该变量赋值是无效的。

另外，请注意所有变量都是 public，可以从类外访问。如果任何变量是 private 或 protected，则相应的命令将不被允许。

面向对象设计的一个关键原则是多态性，它指的是类可以采取多种不同形状的想法。为了理解这个概念，你需要一个具有继承的类层次结构——基本上是一个被特化为多个子类的超类。想法是超类，即层次结构中更高层的类，可以采用其任何一个子类的特定形式；也就是说，超类可以有许多不同的形状，每一个都是整体类的一个例子。

## // A CLASS HIERARCHY

多态性的重要部分是你可以在层次结构最高层在有意义的地方定义操作——基本上，你尽可能在顶级超类上定义一个操作。然后，该操作的实际实现可能在层次结构中的任何位置定义。每个子类都可能有不同的执行该操作的方式，但它们都会执行它。当你引用某个类时，任何属于该类的东西，包括任何后代类，都可以满足要求。

继承可以通过从基类继承特性而不是在所有派生类中重复它们来节省编码。但也许继承的更重要特性是它支持让层次结构中较低的类满足在较高层次结构中定义的要求。

类层次结构的想法意味着当你使用某个类时，该函数也可以使用其任何后代类。然而，事情不能反过来工作：你不能要求一个更专业的类并传入更通用的超类。

在这段代码中，它实现了上一讲的层次结构，你定义了一个基 product 类并从中派生 cup 和 plate (a)。然后，从 cup 派生 measuring_cup 和 drinking_cup (b)。在这种情况下，每个成员都是一个 product。cup 有一个批发价 (8) 和一个零售价 (9)。

假设你想创建一个函数，将商品按 10% 降价。你可能想要一个函数来给出售价。因此你可以编写一个名为 sale_price 的函数，它返回一个浮点数表示价格。它将有一个参数，即 product。并且它将返回产品零售价的 90% (c)。

然后，你可以在代码中创建非常具体的对象。在这种情况下，你有一个 plastic_cup，它是 measuring_cup 的实例，以及一个 coffee_cup，它是 drinking_cup 的实例 (d)。measuring_cup 和 drinking_cup 都派生自 product 类，你可以毫无困难地对它们两者调用 sale_price 函数 (54, 55)！

这是实现多态性的直接方法之一。当你从基类继承时，你会自动获得基类所拥有的一切。换句话说，基类的后代将拥有基类的成员变量和函数，因此任何后代都可以用作该基类的替代。

这使得可以扩展现有类以提供更多功能。你可以添加一些你可能想要的额外功能，同时保留你喜欢的类的所有内容。

```

#include<iostream>
using namespace std;

class product {
public:
    float wholesale_cost;
    float retail_cost;

    float profit_per_item() {
    return retail_cost - wholesale_cost;
};
```

```
class plate : public product {
public:
    float diameter;
};
```

```
class cup : public product {
public:
    float volume;
    string color;
};
```

```
class measuring_cup : public cup {
public:
    bool has_merments;
    int num_gradations;
};
```

```
class drinking_cup : public cup {
public:
    bool has_lid;

    float sale_price(float p) {
    return retail_cost * 0.9;
};
```

```
int main() {
    measuring_cup plastic_cup;
    plastic_cup.wholesale_cost = 10.0;
    plastic_cup.retail_cost = 20.0;
    drinking_cup coffee_cup;
    coffee_cup.wholesale_cost = 5.0;
    coffee_cup.retail_cost = 10.0;

    cout << "The plastic cup cost: " << plastic_cup.profit_per_item() << endl;
    cout << "to purchase the plastic cup for: " << plastic_cup.wholesale_cost << endl;
    cout << "to purchase the coffee cup for: " << coffee_cup.wholesale_cost << endl;
    cout << "The sale price will be: " << sale_price(plastic_cup) << endl;
    cout << " and " << sale_price(coffee_cup) << " respectively." << endl;
}
```
