# // VARIABLE ASSIGNMENTS

Let's go back to the original program for counting calories (Program 2_1 on page 18). After your declarations of type and name, you can see that there are 3 assignments (d). Each of these lines has the same name on the left, an equal sign, and value on the right.

Assignment is written with a equal sign, but it does not mean that 2 things are set equal to each other. It means that the thing on the right is assigned to the variable on the left. That's why it's better to say "gets" or "assigned" instead of "equals" when you read a line of code out.

When you first declare a variable, it's a good idea to set an initial value to be in the variable. It turns out that this is easy to: You can combine the variable declaration with assignment.

```
int carb_grams = 30;
int protein_grams = 5;
int fat_grams = 15;
```

This is the general form for any assignment statement. When this code is executed, the variable on the left side–is placed into the box. It replaces any other value already in that box.

Variables wouldn't do much good if you ever use the value they hold. When you see a variable on the right side of the assignment operator, you can think of what's there as meaning "this value holds."

First, you have a variable declaration, declaring a box of memory for an integer variable named carb_grams.

Next, the same thing happens when you declare an integer variable for protein_grams.

Variable Assignment:
<variable name> = <value>
carb_grams = 10;

And you declare an integer variable for fat_grams.

> Remember that variables can vary in value; they aren't stuck with the first value they are assigned. This is why the equal symbol means assignment, not permanent equality. At later time, you can assign a new value in the box, replacing the old one.

So, at this point, you have 3 integer areas of memory with 3 different names.

![](bbox=[0.065, 0.638, 0.22, 0.735])

Next, you assign the 30 to carb_grams. This means that the box of memory for carb_grams now contains the number 30.

So, if you have a line like carb_grams = 10, that means that the box of memory you call the variable carb_grams will have the value 10 assigned inside it.

Then, you assign 5 to protein_grams, so that variable now holds the value 5.
