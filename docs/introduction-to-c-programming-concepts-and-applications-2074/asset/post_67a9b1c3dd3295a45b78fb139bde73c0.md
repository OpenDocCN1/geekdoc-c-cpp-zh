
## // INITIALIZING ARRAY

You can also initialize arrays directly.

If you have an array of size 5 but only initialize it with 2 values—suppose you don't know the size of the other teams—then the first 2 elements of the array are initialized.

Program 7_5 has an array declaration that you might use if you were keeping track of numbers of people on various teams in a competition. The array team_members is declared to have size 5. To initialize it, you can specify the initial values that you want the elements to be a set of 5 values separated by commas and enclosed in curly braces. In this, you initialize the array to have values 5, 6, 4, 5, and 4.

```
int team_members[5] = { 5, 6 };
```

When you run this program, the for loop iterates through all the members and the cout prints out for each of the 5 elements in the order you specified.

When you have array elements that aren't specified, they are often initialized to the value 0 by default. It's better to explicitly set any values that you want to be initialized so that you know what's in the memory locations you might access.

When you print out the values of the first 5 elements, you see that the first 2 elements have the values 5 and 6, as specified. The last 3 elements all have the value 0.

Finally, you can declare an array without specifying if you initialize it with a set of values. In the code below, the my_array is declared with an indeterminate size, where you initialize it with a set of 5 values. But so, this implicitly defines the array to be of size 5, and that all the values are set correctly.

+   // Program 7_5
// Array Initialization
#include <iostream>
using namespace std;
int main() {
    int team_members[5] = { 5, 6, 4, 5, 4 };
    for (int i = 0; i < 5; i++) {
        cout << team_members[i] << endl;
    }
}

Data is more than just a single value, and you often want to keep track of multiple types of data at the same time, when different data values are all tied together.

The method of doing this is parallel arrays. You create multiple arrays, each having one different type of data. And you tie these together by making sure that the same index in each array refers to the same item. So, if you have an array to store low temperature, then element 20 in both arrays refers to the same day. You can get the low and high for that just by using that index.

Regardless of how you use one-dimensional or multidimensional arrays, there is one issue to be particularly careful of: array bounds.

In Program 7_11, you have an array my_array of size 3, and set the values of the 3 elements in 10, 20, and 30.

```
// Program 7_10
// A 2D array initialized
#include <iostream>
using namespace std;

int main() {
    double accounts[5][3];
    int i, j;
    for (i = 0; i < 5; i++) {
        for (j = 0; j < 3; j++) {
            accounts[i][j] = 50.0;
        }
    }
    cout << endl;
    cout << "accounts: " << accounts[i][j] << endl;
    return 0;
}
```

```
// Program 7_11

}
```

You have a loop that's designed to print out the values of an array, but instead of outputting 3 values, you make a mistake and have the loop to print 4 values instead. If you look for the loop, the index i will take on 0, 1, 2, and 3, because the condition is i < 4.

Because 0, 1, and 2 are part of the array and you just set values for all, they should be fine. But what happens when you try to print my_array[3]?
