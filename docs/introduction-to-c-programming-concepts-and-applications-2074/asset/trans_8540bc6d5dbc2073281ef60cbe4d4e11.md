>> 解引用迭代器——也就是说，像指针一样，你获取迭代器所指事物的值。在本例中，你输出它。因此，第一次循环时，你查看的是向量的第一个元素，即 18，所以 18 被输出。

C++ 中有一个特性可以让你不用写很长的 vector<int>::iterator。你只需使用 auto，编译器就会自动推断所需的变量类型。

计算机科学家将 C++ 列表称为链表。每个元素都存在内存中，并不一定与列表中的下一个元素相邻。每个元素都有一个指向列表中下一个元素的指针，而双向链表还有一个指向前一个的指针。

你实际上可以在其他上下文中使用 auto，来获取自动变量的类型而不是指定它。它仍然具有固定的大小类型，但简化了程序员的工作。

在非常罕见的情况下，迭代器不能被解引用。

因此，如果你在某个元素处，很容易到达下一个元素，在双向链表中，也很容易回到上一个元素。你可以很容易地看到任何迭代器都会从第一个到最后一个结束。

发生的另一件事是对于每个迭代器都保证可行的操作：递增。这就是你用于递增索引值的 ++。在迭代器之后写 ++ 是可以的：它会移动到容器中的下一个元素。

在 Program 22_7 中，你创建了一个包含 3 个元素 10、20 和 30 的向量（8）。然后你声明了一个名为 iter 的迭代器（9）。你将其设置为 begin 并递增一次，使 iter 成为向量中的下一个元素（d）。你可以为向量调用插入命令，传入 iter 和你想要插入的值。因此，40 在第二个元素之前被插入（12）。

```
// Program 22_7
// Insertion on a vector
#include <iostream>
#include<vector>
using namespace std;
int main() {
vector<int> v = { 10, 20, 30 };
vector<int>::iterator iter = v.begin(); // Iterator is at first element
iter++; // Now at second element
v.insert(iter, 40);
for (int i = 0; i < v.size(); i++) {
cout << v[i] << endl;
}
}
```

因此，在这种情况下，你有一个循环使迭代器遍历容器中的每个元素，并将其打印出来。

当你打印出向量的内容时，你会看到元素按顺序排列，正如预期的那样。

从容器中删除数据也有类似的过程。

这种遍历容器如向量的方式非常常见，不难看到一个语句从容器的开头开始并迭代到结尾。因为迭代器通常只为此定义，你会遍历容器的元素，所以通常将声明放入循环本身。

迭代器对于指定在容器中插入或删除数据的例程很重要。

对于向量和 deque 这样的容器来说，插入和删除并不是很高效；有另一种容器在处理插入和删除方面要好得多：列表，相关的是 forward list。

但列表不允许你直接 deque 到中间的某个元素。

列表的优势在于你可以非常轻松地插入到其中。如果你向向量中插入东西，你可能不得不复制大量信息，因为你基本上要将现有元素向下滑动一个位置。

对于列表来说，你只需要拿要添加的新事物并更新几个指针。同样，合并 2 个列表是一项非常快速的任务，而 deque 则需要复制其中一个列表。

当你输入 *list* 时，你得到一个双向链表。**forward list** 给你一个单向链表，并且只允许在列表的前端推送。并且插入发生在迭代器所指元素之后。

假设你有一个列表的列表，用于制作花生酱果酱三明治。请注意在 Program 22_8 中你在开头 #include **list**（5）。List 是模板化的，所以你创建一个名为 **instructions** 的 *list*，类型为 *string*（9）。

你可以使用 **push_back** 和 **push_front** 将元素添加到列表的前面或后面，就像你对 deque 所做的那样。在本例中，制作三明治有 3 个步骤（e）。

```
// Program 22_8
// List example, including insertion
#include<iostream>
#include<string>
#include<list>
using namespace std;

int main() {
  instructions.push_back("Get bread");
  instructions.push_back("Put jelly");
  instructions.push_back("Put two halves together");
  list<string>::iterator insert_pos;
  insert_spot = instructions.begin(); // Refers to first element
  insert_spot++; // Refers to second element
  instructions.insert(insert_spot, "Put peanut butter");
  for (auto iter = instructions.begin(); iter != instructions.end(); ++iter)
    cout << *iter << endl;
}
```

如果你允许一个重要步骤，例如添加花生酱，你可以插入到其中的元素。你可以创建一个迭代器并递增它以引用第二个元素（f）。然后，在该点调用 **insert** 将在第二个元素之前插入一个新元素（16）。

你也可以使用迭代器循环并按顺序打印出结果元素。请注意，你放在第二位的指令——**peanut butter**——出现在正确的位置（g）。

forward_list 非常相似，但你只能调用 push_front，或在元素之后插入。在此代码中，你以相反的顺序推送指令，因为它们被添加到列表的前面（h）。

迭代器还可以通过以新的方式使用 for 来增强你对向量和数据结构的使用。如果一个类可以通过迭代，你可以形成一个特殊的 for 循环。你可以设置一个 for 循环，其变量取容器中每个元素的值。for 循环将从开头迭代到结尾，变量将取每个值

此语法是写 for，然后在括号中写用冒号分隔的 2 个项目。其中第一个是变量类型和变量名。当你使用这种类型的函数时，变量只会

```
// Program 22_9
// Forward_list example, including insertion
#include<iostream>
#include<string>
#include<forward_list>
using namespace std;

int main() {
    forward_list<string> instructions;
    instructions.push_front("Put two halves together");
    instructions.push_front("Put on jelly");
    instructions.push_front("Get bread");
    forward_list<string>::iterator insert_spot;
    insert_spot = // Refers to first element
    insert_spot++; // Refers to second element
    instructions.insert_after(insert_spot, "Put on peanut butter");
    for (auto iter = instructions.begin(); iter != instructions.end(); ++iter) {
        cout << *iter << endl;
    }
}
```

作用域仅限于循环，如果将其仅声明为语句的限制不是问题。

请注意，如果你愿意，可以为类型使用 auto。但是，如果你要操作容器的元素，则应使类型为引用。

在类型和变量名之后，有一个冒号，然后是你要遍历的容器的名称。

Program 22_10 是你制作花生酱果酱三明治的步骤。

在第 19 行，你有一个 for 语句。容器由字符串组成，所以你将有一个新值——step，在本例中——是字符串类型。你将操作 instructions 的元素，所以你将 step 声明为字符串引用，而不是仅仅字符串。然后，有一个冒号后跟容器名称 instructions。

然后，你可以再次遍历 instructions 的元素，这次打印结果。for(auto step : instructions)——表示你要遍历整个容器，step 将在每次迭代时引用 instructions 的元素（19）。

在循环内部，当你打印值时，你会看到它们被之前的循环更改了（20）。

没有循环，你可以用 step 做任何你想做的事，它将引用列表本身的元素。因此，在本例中，你将 step: 添加到每个元素的开头（16）。在循环的第一次迭代中，然后将值 Step: 添加到 instructions 元素的开头。循环结束时将其添加到所有元素。

```
// Example of for-each statement

int main() {
    list<string> instructions;
    instructions.push_back('Get bread');
```
