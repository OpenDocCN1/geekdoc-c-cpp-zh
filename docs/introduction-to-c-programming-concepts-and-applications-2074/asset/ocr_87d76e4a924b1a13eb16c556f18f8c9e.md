# // ASSIGNING VECTORS

Another feature that offer't not part of arrays is the ability to copy them.

Instead, if you use vectors, this works out fine (Program 8_16). You create 2 vectors of ints a and b, and initialize a to have 3 elements, with values 1, 2, and 3. Then you have a command, b = a, which copies a to b. Now b has 3 elements itself and the values of the elements are the same as a. When you print out the elements of the vector b, you see that they have the same values as a.

In Program 8_16_a, you create 2 integer arrays of size 3 named a and b. In this case, a is initialized with values 1, 2, and 3.

You might like to be able to make b have the same values as a-essentially copy a into b. If you try to write a line b = a, you'll get a compilation error. You are not allowed to assign arrays like that.

Going forward, you'll be relying on vectors as your data structure of choice for storing large amounts of data.

```
// Program 8_16_a
// ERROR - Attempting to assign arrays is not allowed
#include <iostream>
using namespace std;

int main() {
    int a[3] = {1, 2, 3 };
    int b[3];
    b = a;
}
```

```
// Program 8_16
// Assigning vectors
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> a = {1, 2, 3 };
    vector<int> b;
    b = a;
    for (int i = 0; i < b.size(); i++) {
        cout << b[i] << " ";
    }
    cout << endl;
}
```
