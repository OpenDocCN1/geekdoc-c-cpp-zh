// Inheritance member functions

```
#include<iostream>
#include<string>
using namespace std;

int main() {
    class product {
public:
    float wholesale_cost;
    float retail_cost;
    float profit_per_unit() {
        return retail_cost - wholesale_cost;
    }
};

    class plate : public product {
public:
    float diameter;
};

    class cup : public product {
public:
    float volume;
    string color;
};

    class measuring_cup : public cup {
public:
    bool metricunits;
    int num_gradations;
};

    class measuring_cup_plastic_cup : public measuring_cup {
    plastic_cup.wholesale_cost = 0.10;
    plastic_cup.retail_cost = 0.30;
    plastic_cup.volume = 100.0;
    plastic_cup.color = "";
    plastic_cup.metricunits = true;
    plastic_cup.num_gradations = 10;

    cout << "The plastic cup costs " << plastic_cup.wholesale_cost << endl;
    cout << "to purchase and sells for " << plastic_cup.retail_cost << endl;
    cout << "We made a profit of " << plastic_cup.profit_per_unit() << endl;
}
    return 0;
}
```

And, as you'd expect from a hierarchy, can have more than one derived class from the same base class. For example, in addition to a `measuring_cup`, in Program 19_3, it's been defined as a subclass of `cup`, with one more member variable: Boolean whether it has a lid or not (f).

You're not confined to inheriting member variables; you inherit member functions.

Say your product class had a member function named `profit_per_unit`. It would be simple, returning the difference between the retail and wholesale prices (g).

Then, if you have an object of some derived type, like a `measuring_cup`, you can call it just like you would for the base class. In this example, you have a `measuring_cup` named `plastic_cup`, and you call `plastic_cup.profit_per_unit` to get the profit (h).

Inheritance only goes one way—from the parent to the child. A superclass does not have access to the member variables and functions of the subclasses, and sibling classes don't have access to each other's variables.
