The way this is done with the notation +=. For example, when you have += set to 1, it's doing exactly what you saw—takes the current value of the variable, adds the amount 1 on the right side to it, and stores the new result as the value of the variable.

An more compact way you can express incrementing is with the ++ operator.

C++ also lets you write the increment operator before the variable name, but these 2 methods don't always mean the same thing.

The value of 1999 ++ will be 2000.

Putting ++ after the variable—example, x++means that you increment the value to something new after doing the parts of the command were already there.

In your code, you can write fat++.

In general, the variable is increased by whatever the amount on the right side is. So, the line you see, fat_grams += 1, is doing the same thing as the line before:
fat_grams = fat_grams + 1.

All 3 work the same: The value in fat_grams is increased by 1. And because one gram of fat is 9 calories, you end up with 9 more calories than the previous result—284 of 275.

This works for for multiplication. If you have money in the bank and withdraw $100, you have money_bank -= 100.0.

> Now you know where the language C++ gets its name! The "++" means the next increment above the previous value. In the case of C++, it's the next language after C.

This also works for multiplication. If you have rabbits, then you soon try to multiply your number-in other, num_rabbits *= 3.

Putting ++ before the variable—example, ++xmeans that you increment to a new value of the variable before doing other parts of the command.

These compact operators can take any number, but the most common is increasing a variable by the number 1.

So, in this code, printing ++x will print the new, updated value of 2.

Think about counting: If you have a number, you usually count by 1, increasing each number by 1 each time. That you're incrementing the variable.

Just like that, there's also --, which will decrement by 1. If you used 1 less gram of fat in your recipe usual then you could decrease fat_grams -- and end up with 9 fewer calories—266 instead of 275.
