// Vector size

#include <iostream>

#include <vector>

using namespace std;

int main() {

vector<int> v;

cout << "Initial size is: " << v.size() << endl;

v.push_back(1);

v.push_back(3);

cout << "Later size is: " << v.size() << endl;

}

You can use vectors very much like arrays. You can assign values to individual elements, access the elements using variable indices, and so on.

Because vectors can change in size as you add additional elements, you would like to have a way to find out the size of the vector at any given time. Unfortunately, there's a function to find the size of.

You now have 2 output lines in which you output the initial size and the later size of the vector. In each case, to get the size of v, v.size(). This will be the size of the vector.

Let's create a vector of ints whose name is v. Like the push_back function for adding elements to the end of a vector, the function for finding the size of a member function of the vector class—that is, it "belongs" to a vector. That means that you need to write the name of the vector, then period and the name of the function. In this case, the function name size, and it doesn't take any arguments.

Your first output occurs after declaring the vector. So you output saying that the initial size is 0. The second output command comes after the 3 push_back commands. The size of the vector has increased with each of the push_back commands, and when you output the size, you indeed find the later size is 3.
