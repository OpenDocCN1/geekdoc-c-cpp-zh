Pairs are especially common when using priority queues, because you often need to have 2 pieces of information: some value that you are using to determine priority and the actual object associated with that value.

Suppose you wanted to have a priority queue where you were putting people out from oldest to youngest. Then, you could associate a pair where the first element was age and the second element was the person. The largest age will always be first.

You can use the following when writing code:

+   * push adds elements to the priority queue.
* pop removes the top element.
* size gets the size of the priority queue.
* empty returns if the priority queue is empty or not.

Consider Program 23_5. A priority queue is contained within the queue library, so you include queue(5) to create a pair type that contains an integer and string (8). The integer will be the age, and the string will be the person's name.

When you declare a priority_queue of person. The first element of a person is the age, the highest-priority element in we will be the greatest age. The priority queue is named pq(11).

```
// Program 23_5
// Priority Queue example
#include <iostream>
#include <string>
#include <queue>
using namespace std;

int main() {
    priority_queue<pair<int, string>> pq;
    pq.push(make_pair(16, "Jack"));
    pq.push(make_pair(16, "Jill"));
    pq.push(make_pair(19, "Joe"));
    pq.push(make_pair(17, "Jessica"));
    cout << "The oldest person in the group is: " << pq.top().second << endl;
    cout << "The next oldest person in the group is: " << pq.top().second << endl;
}
```
