#include <iostream>

float average(float a, float b) {
    return (a + b) / 2.0;
}

int average(int a, int b) {

}

}

In this variation, you have the original average function that takes 2 floats. You also create another version that takes 2 integers. It returns an integer instead of a float. In this case, you'll call integer division in the interior; because the parameters are integers and you divide by 2, not 2.0, you'll have an integer division.

If you call the function with 2 integers, the compiler will match it with the function signature that has 2 integers. Because it is an exact match, that is the function will use it. There won't be any ambiguity because there's nothing left to be converted. So, in this case, with 2 integers, 10 and 35, gives an integer result, rather than the floating-point result 22.5.

In C++, you can specify, to a degree, how many bits are used to represent numbers. The more bits are used, the larger the number that can be represented. For integers, you have several options, ranging from a char to a long int. The exact sizes of integers aren't specified, but you do know that a long long int has at least as many as a long int, which has at least as many as an int, and so on. Similarly, floats have a longer version, the double, and an even longer version, the long double.

When passing parameters, remember that the different types are actually different. And that means if a function you call it with a different type, it often needs to perform a conversion in order to match the specific signature. Some of these type conversions can be very tricky.

One way to get around this is to make sure you call with floating-point numbers. Any time you write a floating-point literal, you can append an f to the number to indicate that the number should be treated as a float:

## SETTING DEFAULT PARAMETERS

There's one more way that you can provide functions with the same name but different parameters sets: You can specify a default value for one or more of the parameters. If, when the function is called, the corresponding argument is left out of the call, you will use the default parameter instead.

To do this, you just set an initializing value for the appropriate parameter, assigning some value inside the parentheses. When it is done this way, assignment is understood by the compiler as one to be used if the corresponding parameter is not provided.

On the other hand, if you call it just a string parameter, such as World, then times has the default value, so the string is printed just once.

If there are multiple default parameters, then arguments from the function are all assigned to parameters from left to right. You can't have some parameter in the middle assigned a default value; once one is assigned, everything after it must also be default.

Suppose you want to create a function, called printmultiple, to print out a string multiple times. Let printmultiple take the string to print and the number of times to print it. The function does not need to return a value to the place it called from, so you'll have a void type.

Default parameters are commonly used to control how a function works when there's a normal, or common, way to do something set as the default but you want to let the programmer have the option of selecting some other behavior needed.

If someone doesn't have many to print the string, you might choose to have a default number, such as 1. If so, your header would look something like line 7. So, there are 2 parameters: a string called s, and an int called times, which has a default value of 1.

// Program 13_5
// Using a Default Parameter
#include <iostream>
#include <string>
void printmultiple(string s, int times = 1) {
    for (int i = 0; i < times; i++) {
        cout << s << endl;
    }
}
int main() {
    printmultiple("Hello", 5);
    printmultiple("World");
}

If you call the function with both parameters—for example, Hello and 5—you will get the string Hello printed out 5 times.

> Setting default parameters is an alternative to overloading a function by specifying different signatures.

## USING REFERENCES

References allow you to share information without making needless copies.

A reference is a way of describing a particular variable. Normally, when you define a variable, it gets its own box of memory. If you do something to that box of memory, such as assign a value to it, it's not going to affect any other box.

The same thing b is to a. This means that b is going to refer to the exact same box of memory as a. When you print out the values of a and b, both show up as 1.

With a reference, though, you don't create a new box of memory for your variable. Instead, you use an alias that refers to that memory. Basically, your variable becomes another name for some box of memory that already exists; anything you do to that new variable must affect the original memory;

You can assign a new value, 2, to a. When you do so, the value changes in that box of memory. When you print out both a and b now, both show up as 2.

The way you specify a reference is by putting an ampersand (&) after the type when you declare it. Then you initialize your new variable to refer to some other variable.

The same thing happens if you assign a new value, 3, to b. The box of memory b refers to has its value changed to 3. Printing out the values of a and b indicates both have the value 3.

// Program 13_7
// Reference example
#include <iostream>
using namespace std;
int main() {
    int a = 1;
    int &b = a;
    cout << a << " " << b << endl;
    a = 3;
    cout << a << " " << b << endl;
}

First, create a variable, a, that you initialize to a value of 1.

Next, create a variable, b, that is a reference to an integer. So, you must make this reference to something; you can't just leave it there,

The most common way references are used is calling functions. That's you can declare any of the parameters in a function to be a reference. This means that the parameter will not be a copy of the argument that comes in; it'll be a reference to the argument so the reference parameter will be like changing the original.

The term used to describe this is passing by reference. This is distinguished from what you previously did, which is when you pass by value, you're copying the value of the argument into the new box of memory set up for the parameter. When you pass by reference, you don't copy anything; you just let the parameter refer back to a shared variable of input.
