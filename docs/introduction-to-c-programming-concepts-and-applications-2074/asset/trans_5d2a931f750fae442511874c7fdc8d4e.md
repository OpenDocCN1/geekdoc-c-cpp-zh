## // 测验答案

对于棋盘评估函数，一个简单的方法就是取玩家 2 的棋子数量减去玩家 1 的棋子数量。当玩家 2 表现更好时（棋子更多），分数会更高；当玩家 2 表现更差时（棋子更少），分数会更低。

请注意，如果你了解游戏策略，还有其他方法可以改进棋盘评估。例如，角落通常比其他方格更有价值，因为它们不会被翻转。而且边缘方格，即距离角落 2 格的方格，持有起来比其他方格稍有价值。

下面是一个可能的实现。请注意，这将是 revers_board 类的公共成员。因此，它将可以访问 board 成员变量。

```
int get_board_score() {
int i, j;
int totalscore = 0;
for(i=0;i<8; i++) {
  for(j=0;j<8; j++) {
    if (board[i][j] == 1) {
      totalscore -= 1;
    } else if (board[i][j] == 2) {
      totalscore += 1;
    }
  }
}
return totalscore;
}
```

该函数只是遍历棋盘上的所有方格，并跟踪一个计数器，对于玩家 1 的每个棋子出现次数减少 1，对于玩家 2 的每个棋子出现次数增加 1。

## 术语表

### abstract class

包含纯函数的类。它定义了一个通用类别的类，其他类可以从中派生。不能创建抽象类的实例。 (L20)

### array

包含若干相同类型变量的连续内存块。数组一次性分配，单个变量（**元素**）通过**索引**访问。 (L7) 更现代和 C++ 的做法是使用 **vector**。

### accessor function

提供从类中读取信息的批准通道。允许其他函数访问成员变量。调试时设置断点也很有用。 (L16)

### array out-of-bounds error

尝试访问超出已分配内存的数组元素时出现的错误。当数组索引为负数或大于数组的最大大小时就会发生这种情况。 (L7) 这可能是一个重大的安全漏洞。

### algorithm

为完成某项任务而遵循的一组精确规则。通常用伪代码描述，然后转换为实际代码。 (L22, L23, L24)

### artificial intelligence

让计算机表现得好像在做出智能选择和决策一样。 (L24)

### append

在现有项目末尾添加内容。追加操作常用于写入文件时，在文件末尾添加额外数据，或将一个字符串添加到另一个字符串末尾。 (L9, L10)

### associative container

将两个或多个数据类型关联在一起的容器。示例包括 pairs、tuples 和 maps。 (L23)

### attribute

参见 **member variable**。

### arguments

函数调用中给出的值；每个参数与函数内部的**参数**相对应，并且参数在函数内取参数的值。 (L12)

### binary search

通过检查中间点然后在剩余的 2 个半部分之一中搜索来在已排序的值列表中搜索的过程。 (L23) 与 **iterative search** 对比。

### binary tree

每个节点最多有两个子节点的树。 (L18)

### call (aka function call)

导致函数使用指定的任何参数执行的命令。函数通过写出其名称后跟包含要传递给函数的任何参数的括号来调用。 (L6)

### Boolean

用于条件和逻辑表达式的真或假值。布尔值可以是特定的真或假值，布尔变量可以取真或假值；布尔逻辑运算符。 (L3)

### casting a value

参见 Type casting。

### Boolean operator

参见 logical operator。

### class

将数据与操作（成员变量）（成员函数）结合在一起的编程结构。每个类都是程序员定义的新类型变量。 (L16)

### bottom-up design

通过组合更简单的部分来创建更大、更复杂的程序。通常，新函数是通过组合对现有函数的调用创建的。 (L15)

### comparison operator

用于比较两个不同值的运算符，其结果为布尔值。常见的比较有大于（>）、大于等于（>=）、小于（<）、小于等于（<=）、等于（==）和不等于（!=）。 (L3)

### breakpoint

调试时，程序执行停止的点。 (L11)

### compile

将代码转换为机器指令的过程。代码编译为调试模式或发布模式。 (L4) 另见 preprocessor commands and separate compilation。

### bug

程序中的错误导致其失败、运行时崩溃或产生错误输出。调试程序是编程的常见部分。 (L4, L14)

### C++ Standard Library

随每个 C++ 安装一起包含的标准约 50 个库文件集。本课程中使用的库包括 iostream、cmath、cstdlib、vector、string、fstream 和 algorithm 等。 (L6)

### concatenation

将两个字符串一个接一个组合；字符串相加的结果。 (L9)

### concrete class

为所有定义函数提供实现细节的类；你可以从具体类创建对象。 (L20)

### debugger

帮助分析程序的工具，允许程序员逐行逐步执行程序并在程序运行时检查内存。 (L1, L11)

### console

程序的默认输入和输出源，通过命令 **cout** 到达。 (L1)

### declaration of a variable

声明变量类型的语句，后跟变量名。这为变量分配内存并将变量名与内存关联。 (L2)

### constant reference

参见 **passing by reference**。

### default constructor

不带参数的构造函数。默认构造函数在没有参数声明对象时使用。如果类未定义默认构造函数，将自动为其创建一个。 (L17)

### constructor

在类中定义、在变量（**对象**）首次声明时调用以初始化变量的函数。 (L8, L10, L17)

### default parameter

当函数参数被赋予一个值以防函数调用时未对应该参数提供参数时使用。列表中只能是最右边的参数可以是默认值。 (L13)

### container

可用于存储和操作各种类型数据的模板类。示例包括 vectors、lists、queues 和 priority queues。STL 定义了几个容器。 (L22)

### debug

从程序中删除错误。这可以通过识别可重复的错误、缩小错误位置、隔离失败原因、修复修复后的代码并检查代码的任何类似部分来系统地完成。 (L4, L11, L14)

### dereferencing a pointer

访问指针中保存的内存地址中的内容。语法为 **\*y** 或 **y[0]**（对于对象）或 **y->**（对于对象的成员变量或函数）。 (L18)

### destructor

在函数或类被移除内存时调用的特殊函数。 (L18)

### debug mode

编译器设置添加了额外的指令，使调试器能够在代码上运行。 (L11) 与 **release mode** 对比。
