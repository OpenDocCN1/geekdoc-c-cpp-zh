# POINTER ERRORS

Pointers are notorious for how many errors they can cause in programs. Pointer errors can be easy to make and really difficult to find when debugging. Yet there are cases when you need to use pointers:

+   - when you are reading in an unknown amount of data,
- when you need a lot of memory but the operating system, as it often does, has limited the amount that can be used on the stack.

Then, you need to allocate memory dynamically.

# // DYNAMIC MEMORY ALLOCATION

Now that you have pointers, you can start to perform dynamic memory allocation.

The **new** command creates a new object on the heap and returns a pointer to that object. To use the **new** command, you must write followed by the type that you want to allocate. If there is a second constructor, in addition to the default constructor, you can invoke it by putting parentheses the arguments you want to pass to the constructor in parentheses.

If you want to allocate some of an object, you allocate an array on the heap. When you allocate an array, then after the variable name, you put brackets with the size of the array you want inside.

When the array form of **new** is used, the default constructor is called for each of the elements.

Data stays on the heap until it is explicitly deallocated. Once you are done whatever memory you allocated, you need to explicitly free it. Unlike the stack memory is automatically freed when a function completes, heap memory stays allocated until the end of the program-unless you free it.

To free memory on the heap, you use the **delete** command. You must use **delete** and give a pointer to what you want to delete. The allocated object will be deleted from memory.

If you allocate an array, you have to instead use **delete[]** to delete the entire array that was allocated.

One other thing that's useful when setting up a default variable is a null pointer.

Sometimes, you have a pointer but don't want to point to anything in particular; you just have to use it later. In this case, you can set the pointer to be the value **NULL**. The null pointer does not point to any usable memory location, but it functions as a special value you can have the program check when no what is needed.
