
Sorting can be useful not for ordering things in a neat way, but also as a way of making subsequent computations faster. If you'll be doing several searches for elements, then having the elements in a sorted order lets you use a binary search.

The STL provides a sort function that will take a container like a vector or list and put it in sorted order. sort takes in a starting iterator and an ending iterator and sorts everything in between.

Say you have a vector, v, with several elements in basically random order (9). For later comparison, you print out the elements of the original vector in order, showing that they were in some unsorted order (g).

Then, you sort the vector by calling the sort algorithm, with v.begin and v.end as your starting and ending iterators (15).

After that, if you print out the elements of v, you see that they are indeed now in sorted order (h).

```
/* SORT */
// Program 23_11
// Sorting example
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
vector<int> v = { 4, 5, 9, 1, 15, 12, 3, 5, 7, 11, 14, 2, 9 };
cout << "Before sorting: ";
for (auto& iter : v) {
  cout << iter << " ";
}
cout << endl;
sort(v.begin(), v.end());
cout << "After sorting: ";
for (auto& iter : v) {
  cout << iter << " ";
}
cout << endl;
}
```

For a large list—say one with a million elements—binary search with lower_bound will be much faster than an iterative find. So, the up-front cost of sorting the elements one time can easily be outweighed by the time savings on the later searches.

## /* LOWER_BOUND */

STL also provides a binary search function lower_bound, which repeatedly searches over range by examining whether the thing being looked for is in the upper or lower half of the range.

For example, Program 23_12 works just like the code you used for find, but you have to first sort the vector (15). Then, you call lower_bound just like you called find (16).

If the search finds the element, then you get an iterator pointing to the first occurrence. If it doesn't find the element, it points to the next-largest element it finds. In this example, if you search for the value 25, it doesn't find that instead returns it found 27—the next-largest value in the list.

```
// Program 23_12
// Lower_bound example — using binary search
#include<iostream>
#include<vector>
#include<algorithm>
using namespace std;

int main(){
 vector<int> ages = { 23, 21, 18, 22, 21, 19, 20, 23, 27 };
 vector<int>::iterator findval;
 int autofind;
 cout << "What age do you want to find? ";
 cin >> autofind;
 sort(ages.begin(), ages.end());
 findval = lower_bound(ages.begin(), ages.end(), autofind);
 if (findval != ages.end()) {
  cout << "Found : " << *findval << endl;
 } else {
  cout << autofind << " not found" << endl;
 }
}
```
