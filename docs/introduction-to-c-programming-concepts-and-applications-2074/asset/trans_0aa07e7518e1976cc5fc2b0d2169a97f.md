谈论向量时，不像“向量”之类的某种类型，例如“向量”之“浮点数”。并且这些可以被视为变量的类型。

与数组不同，你不需要为向量指定大小。向量的有趣特性之一是它们可以根据需要增长。最初，当你像这样声明一个向量时——它里面没有任何元素。在此示例中，你向向量添加元素，它会在你添加时增加大小。

注意这些函数调用有些不同。你有向量的名称，即 Vector，然后是函数调用。你不仅仅单独调用函数；函数调用前加上向量的名称。

接下来的 3 行 (a) 显示了向向量添加数据的常见方法之一。你使用一个名为 push_back 的函数在向量末尾添加新元素（换句话说，它被推到向量的后面）。并且它将具有作为参数的任何值。

这是一个成员函数——在这种情况下是 push_back——它“属于”特定的变量。句点用于表示“第一件事”。第二部分是第一件事的一部分。属于 Vector；push_back 函数是名为 Vector 的向量的一部分。并且这个 push_back 将把值推到向量的后面，而其他地方则不会。

当你到达第一行时，你将在向量末尾添加一个 1。因为向量最初没有元素，在那行之后，它将具有值 1。第二行将在向量末尾添加一个值为 2 的元素。第三个 push_back 将向向量添加第三个元素——一个值为 3 的元素。

我们程序中的最后一行是输出行。你将流式传输值以计数：Vector[0]，和 Vector[2]，用空格分隔。注意你正在使用与数组相同的记法来添加向量的元素：你想要的索引在方括号中。

```

#include <iostream>
#include <vector>
using namespace std;

int main() {
  vector<int> Vector;
  Vector.push_back(1);
  Vector.push_back(2);
  Vector.push_back(3);

}
```

## // Program 8_6

// Vector size

#include <iostream>

#include <vector>

using namespace std;

int main() {

vector<int> v;

cout << "Initial size is: " << v.size() << endl;

v.push_back(1);

v.push_back(3);

cout << "Later size is: " << v.size() << endl;

}

你可以用向量像使用数组一样使用。你可以为单个元素赋值，使用变量索引访问元素，等等。

因为向量可以在你添加额外元素时改变大小，你希望有一种方法在任何给定时间找到向量的大小。不幸的是，有一个函数可以找到大小。

你现在有 2 个输出行，在其中输出向量的初始大小和后面的大小。在每种情况下，要获取 v 的大小，v.size()。这将是向量的大小。

让我们创建一个名为 v 的 int 向量。像用于在向量末尾添加元素的 push_back 函数一样，用于查找大小的函数是向量类的成员函数——也就是说，它“属于”一个向量。这意味着你需要写出向量的名称，然后是句点和函数名称。在这种情况下，函数名称是 size，并且它不接受任何参数。

你的第一个输出在声明向量之后发生。所以你输出说初始大小是 0。第二个输出命令在 3 个 push_back 命令之后出现。向量的大小随着每个 push_back 命令而增加，当你输出大小时，你确实发现后面的大小是 3。
