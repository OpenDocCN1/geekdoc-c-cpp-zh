# Bibliography

A variety of C++ are available, but many of them assume that the reader is already familiar with some other programming language, and are truly aimed at novice programmers. C++ books tend to fall into 2 categories. Some basically present C programming and then present the additional features that C++ provides as an add-on. A few present a C-centric view of programming and still provides. The references recommended here all fail in these second category, while as a whole aim to fall between these two ends of the spectrum,

Lippman, Stanley B., Josie Lajoie, and Barbara Moo. C++ Primer. 5th ed. Addison-Wesley Professional, 2012.

This book provides an extensive coverage of C++, including many smaller details of the language. It provides suggested exercises in most sections to help you practice the topics. Compared to the previous book, it tends to have greater focus on the details of how C++ works and less emphasis on general programming methodology. Note that this edition does not cover C++ features beyond C++, but most programmers will not need the features of the newer releases.

In books to teach how to use C++, there are also language references, which can be considered close to a dictionary or encyclopedia and are useful to look up details of language syntax and behavior, standard library references, etc. Although there are printed language references, for general purposes, the online sources work just as well and are easy to tend today.

Stroustrup, Bjarne. A Tour of C++, 2nd ed. Addison-Wesley Professional, 2018.

This is a short book that gives a brief overview of the features of C++, it will be valuable to those who are already familiar with other programming language and are interested in learning about some of the keys and ideas in C++. It is not a complete reference, nor is it a good book for someone learning to program, but it will be helpful to experienced programmers.

The first two in reference are all recommended, and which both may move something quickly for novice programmers, they are both designed to be useful for those first learning to program. The third book is a recommendation for those who already know programming and just want an idea of how particular C++ is used. Next are 2 online references, which are mainly recommended for language reference. Finally, a book on general software design is recommended, though it would be most useful to use while already programming.

www.cplusplus.com.

This website includes a good language reference, a reference for all the standard C++ libraries, including the STL; and some more basic tutorials and articles. There is also one discussion forum.

en.cppreference.com.

This is just a language and standard library reference, but it is extensive and complete. It includes features from the most recent editions of C++ as well as planned releases of C++ (clearly labeled).

Stroustrup, Bjarne. Programming Principles and Using C++, 2nd ed. Addison-Wesley Professional, 2014.

Ousterhout, John. A Philosophy of Software Design. Yamken Press, 2018.

This book is worth to be a textbook by the creator of C++. It gives a thorough coverage of the language and includes information about software development, not just the language itself. It is best used if you are willing to read through chapters in a linear order, rather than jumping to a particular topic, because some of the topics are based on earlier discussions and sometimes earlier code is intentionally presented with errors or inadequate approaches that are fixed.

This book describes the process of software design without regard to it specific language and without reference any particular paradigm. It is filled with extremely useful advice and is helpful for those who are experienced programmers. Novice programmers or those with little experience may not find the suggestions contained it as meaningful but can get wise advice from the book.
