# // STRING STREAMING

C++, the concept of streaming means any way of making data flow into or of something. This means that there are other ways to stream that do not involve files or the console.

Data that you stream in and out of the stringstream will be written to or read from the string that is stored inside.

In particular, you can also stream to and from string variables. This lets you store data in a string, similar to the way you'd store data in a file without having to actually put a file on the operating system. It lets you avoid nagging for sentinel values when they've finished their input.

So, if you're going to stream data out of a stringstream, you need to give it some initial value. In other words, you need to tell the stringstream: "This is a starting string to use." There's a built-in command, str, for specifying the string that you want to use as the default value under.

```
// Program 10_8
// Using a stringstream for input
#include <sstream>
#include <iostream>
#include <string>
using namespace std;

int main() {
    string stringreader;
    stringreader.str("Apple Banana Cherry");
    string first_word;
    stringreader >> first_word;
    cout << "The first string read was: " << first_word << endl;
}
```

You can create a string by using operations and write to a file like you would like to do. You can also stream from a string, processing the data in a string, like you would do the data from a file.

Program 10_8 is a short program that reads in one word from a string. Notice that you include <sstream at the beginning (3).

The type of you declare is this stringstream-type variable, and the variable name is wordreader (9).

To stream in and out of strings, you'll need a new type to wrap a stringstream. It is a type of variable that links a string to the stringstream operations you've been using.

You have a variable of this new type and need to initialize it with some particular string. In this case, you initialize wordreader with the string Apple Banana Cherry (10).

To declare and use this new type of variable, you'll need to include the sstream library to provide a "link" to store a particular string. This is how the file stream "links" to a particular file, but the stringstream also stores a particular string. And just like you need to write or read a file you stream in and out of a fstream, when you want to read or write from a string, you stream in and out of a stringstream.

The general form for streaming doesn't change whether you are using cin to get input from the console, fstream to get an item from a file, or stringstream to get an item from a string. So, suppose you want to get a first word. You can stream from wordreader into first_word (12). This will read the first item from whatever string wordreader holds. In other words, the text until the first space is read, and then it is assigned to first_word—in this case, Apple. Your output verifies that Apple is what has been assigned to first_word.

Notice the pattern:

+   fstream is for input/output with the console

+   fstream is for files

+   sstream is for strings
