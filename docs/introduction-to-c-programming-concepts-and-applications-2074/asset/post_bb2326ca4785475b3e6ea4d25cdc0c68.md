### / PAIRS /

The simplest of the associative containers is the pair. There are many times you want a very simple structure that just joins 2 things together. For example, you might be keeping track of people and want a person to have an age and a name. The pair provides a quick and easy way of joining 2 items into structure.

A pair takes 2 templated types: the type of the first item and the second of the second item. When there are 2 or more types needed for a template, they are separated by commas within the angle brackets.

To declare a pair of age and name

```
// Program 23_1
// Pair example
#include <iostream>
using namespace std;
int main() {
    pair<int, string> p;
    p.first = 45;
    p.second = "John";
    cout << p.second << " years old." << endl;
}
```

So, in Program 23_2, you could create a new type, that is just a pair of integer and a string by writing typedef pair<int, string> person This lets you declare variables of type person, they'll be integer-string pairs (7).

```
// Program 23_2
// Using typedefed to create a new name for a type
#include<iostream>
#include<string>
using namespace std;

typedef pair<int, string> person;
int main() {
    pair p = make_pair("John");
    cout << p.second << " years old." << endl;
}
```

You could also make your own class by combining specific types, and one advantage of doing that over pair is that the class would give you an indication of the intention of the class. You can get around this by using a typedef, which is giving a new name for a type. The syntax is to use typedef, the actual type, and then the name you want to use refer to that type.

While this lets you a more descriptive name overall, accessing the member variables is still going to be done with first and second (12), and there's not an easy way to extend this if you ever wanted something.

Another command available for a pair is make_pair, which takes in 2 arguments and returns a pair of those two arguments. It can be a useful way of using elements in one statement rather than with 2 separate assignments (11).

For example, if you didn't like using int and second to call integers numbers, you could write typedef int number and then could declare things of type number–they'd still be integers.


### / TUPLES /

If you want to group more than 2 items together, you can use a tuple, which lets you group any number of different objects together. You just list those in the angle brackets. You also have a make_tuple command, which is similar to make_pair.

The downside of a tuple is that you have a simple first and second to access individual elements. There, there's a function named get that has a real form: You have to put the element of the tuple in angle brackets after. In the parentheses, afterward you put the tuple name. That will give you to that element of the tuple.

Suppose you're running a business where you're letting people buy on credit and want to keep track of their name, how many purchases they make, and how much they owe.

In this case, you'd want to create a tuple storing 3 types: string for the name, integer for the number of purchases, and a double that can hold decimal values for the amount owed.

The tuple can be named customer to make it more descriptive (8). Then, you can use this type, customer, to declare a variable, c.

You'll have a make_tuple command that you can use to make an instance of that tuple type. Here, the tuple says John made 3 purchases and owes you $100 (12).

You can then use a count to access the elements. For the first element, you get<0>(c) outputs John. Then, get<1>(c) gives you 3 purchases, and get<2>(c) gives you 100.0 (a).

The function can also assign values to the elements or manipulate them. Because it returns a value, you can do anything to the result of get that you would have done to the element. In this code, you are incrementing the second element, indicating one more purchase, and increasing the third element $50 (b).

```
// Program 21_4
// Tuple example - extended
#include <iostream>
#include <string>
#include <tuple>
using namespace std;
typedef<string, int, double> customer;
int main() {
    customer c;
    c = make_tuple("John", 3, 100);
    cout << get<0>(c) << " "\nhas made " << get<1>(c) << " "\npurchases and owes $" << get<2>(c) << " "\n endl;
    cout << get<0>(c) << " "\nhas made " << get<1>(c) << " "\n endl;
}
```

### /* PRIORITY QUEUE */

The priority queue only takes one type in, so it's not associative, but it's often used with associative containers like pairs or tuples.

The idea of a priority queue is that you want to insert items into the container and then pull them out in order from greatest to smallest. The values of a priority queue are the priority, or how important that element is. So, each element at the front of the queue should be the one with the greatest

priority. Each time you pull an element out of the queue, it will be the highest-priority element in the container.

To create an instance of a priority queue, you give a single data type. For a priority queue to work, this data type must have a less-than comparator defined; and how elements are compared to find which is largest. If you want to have a priority queue of your own type, make sure it has defined.

When using priority_queue with a pair or a tuple, the comparison is based on comparing the first element, and if they are equal, the second. For a tuple, this continues with the remaining elements. Either way, the comparison is already defined so that you don't have to explain a less-than comparator.
