## // OBJECT-ORIENTED PROGRAMMING

There were "pure" object-oriented languages before C++, and there have been languages developed after C++, such as Java, that only allow object-oriented programming. By contrast, C++ lets you use both procedural and an object-oriented style. And compared to other languages that offer some of both, such as Python, C++ has a very complete set of object-oriented features. It enables you to program in a strict object-oriented style if you want to.

When you use object-oriented programming, your development is centered around the creation of what are known as classes, which presents an overall way of organizing the computations in a program, where objects are particular instances of classes.

The feature of classes that is perhaps the most useful part of object-oriented programming is encapsulation.

## // SORTING DATA IN CLASSES

A class is going to contain, inside of itself, a set of variables and functions called member variables and member functions. The class is a way of grouping of all variables and member functions—encapsulating them. So, when you create a new object of that type, you're also creating a bunch of subordinate variables defined by that class but with values specific to each object. Basically, those sub-variables "belong" to the object as its member variables.

For vending machines, one of the things you wanted to store is the price of the item that the machine sells. So, inside of the class definition, you will create a floating-point member variable price. Before you declare the member variable, you write the line public:. This means that the member variable can be seen outside the class. You declare this in a similar way as you would declare any other variable: the name of the member variable, and a semicolon. In this case, that's float price;

This means that a vending machine contains a member variable, sometimes called an attribute, named price. Every object of type vending_machine will have this sub-variable inside of it.

To access this member variable—the sub-variable that is included inside of an instance of the vending_machine class—just use the object name, followed by a period, followed by the variable: object.member_variable.

So, if you've declared an instance of a machine, such as the variable lobby_machine, this is a vending object. To access the price member variable inside of the lobby_machine, you write lobby_machine.price.

At the beginning of Program 16_3_a, you have your class definition. This declares a vending_machine type that's available to the entire program. In this case, the class contains just one member variable: price (b).

When you execute the first line of the code in main(13), it will create a new object lobby_machine (13). That will be an instance of the class vending_machine, and that instance will contain its own member variable inside, named price.

```
// Program 16_3_a
// Vending Machine example 1 - one member variable
#include <iostream>
using namespace std;

class vending_machine {
public:
    float price;
};

int main() {
    vending_machine lobby_machine;
    vending_machine break_room_machine;

    lobby_machine.price = 1.00;
    break_room_machine.price = 2.25;

    cout << "The prices are: " << lobby_machine.price << " and " << break_room_machine.price << endl;
}
```

The next line creates another new object, named break_room_machine(14). Again, it will be an instance of the class vending_machine, meaning that it also has its own variable inside named price.

Likewise, when you assign a new object of 2.25 to the break_room_machine, that will assign the price variable in that object. The price is not shared between the 2 instances of vending_machine. Each instance—each its own price variable (17).

Then, you assign a price of $1 to the lobby_machine. You write lobby_machine.price, which means you are referring to the price variable within the object lobby_machine. You assign the value 1.00, which stores 1.00 in that variable object (16).

When you print out lobby_machine.price and break_room_machine.price, you are printing the values from 2 different variables.
