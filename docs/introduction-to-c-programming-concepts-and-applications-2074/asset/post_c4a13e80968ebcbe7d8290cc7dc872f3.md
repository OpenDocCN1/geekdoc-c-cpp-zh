
## dynamic memory allocation
Allocating memory while the program is running in a location known as the heap or the free store (L18). Dynamic memory allocation is useful when the memory needed might not be known in advance. Contrast with static memory allocation.

## execute
To cause a computer to perform some set of machine instructions; can refer to a program, a function, or any part of code (L1).

## element

## expression
One particular variable within an array or vector of variables. An array or vector will usually contain many elements, which can be accessed by an index into the array (L7).

A combination of literals, variables, and function calls combined with operators that evaluates to some value (L2).

## encapsulation

## friend function/operator
An object-oriented programming approach for wrapping all related data and functions together in one. A class is an example of encapsulating member functions and member variables (L16).

Working to give a function or operator defined outside a class access to the member variables inside that class. Works by placing a signature for the function inside the class definition. (L17).

## function

## error
Any problem encountered when writing or executing a program. This can include bugs like syntax errors and logic errors as runtime errors (such as array out-of-bounds errors) that can be caught with exceptions. (L14).

A group of operations and commands that can be executed as a group; way of conceptually separating one from everything else. Functions can be called within other parts of a program. Defining a function requires a function header and a function body (L6, L12). See also member function (including accessor function) and mutator function stub function.

## exception

## function body
Causes a function to exit when an exceptional case, typically a runtime error, is encountered. Referred to as "throwing an exception" or "raising an exception." (L14; L19).

The set of commands that is executed when a function is called. The body is defined within curly braces following the function header. (L12).

## executable file

## function call
A file of machine instructions created by a linker that has all the needed information from program files and library files and can be run on its own. (L6).

See call.

## function header
Contains all of the information needed for the black box of the function to interact with the larger program: the return type, the name of the function, and the parameter list (contained in parentheses). (L12)

## identifier
See variable name.

## function overloading
Using the same function name but taking different parameters to get different behavior. (L13) Compare with operator overloading. An alternative to function overloading is using default parameters.

## index
An integer that identifies a particular element of an array or a vector. The first element has index 0, the second element has index 1, and so on. (L7)

## indexing into an array/vector
Accessing elements of the array/vector using a variable that contains the index of the element. This is done by specifying the array/vector name, followed by square brackets containing the index of the desired element. (L7, L8)

## generic programming
See template.

## global variable
A variable whose scope is the whole program. Global variables are generally discouraged, because understanding the entire program, rather than just part of it. (L12) Contrast with local variable.

## information hiding
A programming technique for managing complexity of code in which details of a function (or class) is hidden from the portion of code using that function (or class). The code calling it is unaware of how the function works, and a function is unaware of how it is being used by the code calling it. (L16, L19)

## header file
A file, usually with a .h extension, that describes the interface for a library. Header files are included (via #include) in order to gain access to the functions, classes, and variables provided by it. (L6, L15)

## inheritance
A hierarchical approach in object-oriented programming to allow new offspring classes (aka class derived, derived classes, or subclasses) to make use of (aka inherit) member variables or functions already defined in an ancestor class (aka parent class, base class, or superclass). (L19)

## heap
Memory that holds data not known ahead of time but assigned by dynamic memory allocation during execution (L18). Contrast stack.

## initialize
Specifying a value for a variable or object when it is first declared. Objects can be initialized using a constructor. (L12)

## integrated development environment (IDE)
A computer program that makes coding easier. This typically includes a text editor to write code, a graphical interface to allow code to be compiled and executed easily, a debugger, and other tools. Free IDEs for C++ include Microsoft's Visual Studio Community and Apple's Xcode. (L1, L11)

## literal
A specific value written in code. Literals can be assigned to variables or can be used in an expression. (L9) Contrast with variable.

## local variable
A variable whose scope is the current function. It can be accessed within that function but not outside it. (L12) Contrast with global variable.

## iterative search
A process for searching through a list of values by examining element one by one. The list is generally not in sorted order. (L23)

## logical operator (aka Boolean operator)
An operator used to perform logical operations on Booleans, such as (&&), or (||), and not (!). (L3)

## iterator
A more general form of an index. Iterators are a general way of accessing elements in generic containers, which might not have an integer index. (L22)

## loop
A programming construct for repeating a set of commands. A while loop repeats as long as a condition is true. A for loop makes it easier to understand how the loop works by putting initialization, condition, and update all in one place. (L5)

## library
A set of classes, functions, and variables written externally to a program. A library can be accessed by including its header file in a program. See also (L6) C++ Standard Library.

## map (aka dictionary)
An associative container that pairs a key, or entry, with a value. (L23)

## linker
A program run automatically after the compiler that combines the machine instructions from a compiled program with machine instructions from libraries. (L6)

## member function (aka method or operation)
A function defined as part of a class. Can be public, private, or protected. (L8; L16)

## list
A data structure in which items are kept in order one after the other. Items can be inserted or removed in the middle of a list accessed by an index. (L22)

## member variable (aka attribute)
A variable defined as part of a class. Can be public, private, or protected. (L16; L19)

## memory leak
An error in programs caused by dynamically allocating memory in a way that reassigns a pointer but leaves the memory allocated with no way to access or free it. (L18)

## operator
A symbol used to perform an operation on one or 2 variables. A unary operator (such as +, -, * or /) will operate on just one element. A binary operator (such as +, -, *, /) will have 2 elements, or operands: one just before the operator and one immediately afterward. (L2, L7)

## modulus operation
Gives the remainder after division. Expressed using the % operator. (L2, L6)

## operator overloading
Method for defining different behavior of operators depending on the types of operands. For example, + can mean addition for numbers or concatenation for strings. Operators can be overloaded to define behavior for new classes. (L9, L17)

## multidimensional array
An array of arrays. (L7)

## mutator function
A member of a class that can be used to modify a member variable. Mutator functions can provide good places to set breakpoints during debugging. (L16)

## output
The result of the program, generally as indicated by what is printed in the console. (L1)

## namespace

## overloading
A way of helping distinguish one library's functions from another, even if both libraries use the same function names. (L15)

Providing different implementations of a class or operator depending on the type(s) it is working with. (L9, L13, L17) See all function overloading and operator overloading.

## object

## pair
An instance of a class. An object is effectively a variable whose type is class. An object contains variables and functions that belong to it. (L10, L16)

An associative container that allows 2 different data types to be combined into a single structure. (L23)

## object-oriented programming (OOP)

## parallel arrays
A method of software development that is centered on creating classes and objects. Principles of encapsulation, inheritance, and polymorphism are commonly used. (L1, L16, L17, L20)

A method of keeping track of multiple values for the same entity by using multiple arrays or vectors. The index indicates which element is referred to, and the values for that entity are indexed into each of the arrays using the same index. (L7) An alternative to using a class.
