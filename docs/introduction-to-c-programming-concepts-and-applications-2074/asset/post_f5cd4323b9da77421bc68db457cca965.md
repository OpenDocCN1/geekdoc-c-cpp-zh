
## CONCEPTUAL SEPARATION

Let's figure out how you would write a function that counts the number of words in a string.

One option is to take the string and turn it into a stringstream. Then, you could read individual strings from the stringstream until you reached the end. If you counted how many times you could read a word from the stringstream, that would be the number of words in the original string.

To implement this, you'll create a stringstream — initialized to the string that was an input parameter, str_to_count.

Then, you declare 2 variables. The integer count will keep track of how many words you read from the stringstream, so you initialize it to 0. You'll create a string variable named word to hold each word you read out.

Next, you'll have a while loop that continues as long as you haven't reached the end of the stringstream. Inside the loop, you'll read a new word and increment count. This will keep happening as long as the loop's condition is — that is, ss still has something.

Finally, you return the count.

In the main program, you can call the function word_count with a string argument and you'll get back the number of words that are in string.

// Program 12_6
// A more complete function: counting words in a string
#include<iostream>
#include<string>
#include<sstream>
using namespace std;
int word_count(string str_to_count) {
    // Turn the string into a stringstream
    stringstream ss(str_to_count);
    int count = 0;
    string word;
    // Count the number of individual words by reading from the stringstream
    while (ss.eof()) {
        ss >> word;
        count++;
    }
    return count;
}
int main() {
    string s = "This is a string that has eight words.";
    cout << "There are " << word_count(s) << " words in the string." << endl;
}

### Program 12_7

// A more complete function: counting words in a string, alternative
#include<iostream>
#include<string>
#include<sstream>
using namespace std;

int wordCount(string str_to_count) {
    // count number of spaces
    int count = 0;
    for (int i = 0; i < str_to_count.size(); i++) {
        if (str_to_count[i] == ' ') {
            count++;
        }
    }
    // Number of words is one more than number of spaces
    return count + 1;
}

int main() {
    string s = "This is a string that has eight words";
    cout << "There are " << wordCount(s) << " words in the string." << endl;
}

That isn't the only way you could implement that function. Another option would be to count the spaces between words. If you can assume that there's just one space in each word, then the number of words in the string will be just more than the number of spaces in the string.

To implement this function, you'll first declare a count variable and a variable i.

Then, you'll loop through all the characters of the string, one by one, letting i take on one less than the string length.

You'll check each character to see if it is a space. If so, you'll increment count.

Finally, you'd return count+1, remembering that there will be one less space than the number of words.

In terms of the main function that calls the word_count function, it is exactly the same as before.

There's actually a problem with this implementation. If you just count the spaces, you'll count extra words when you have double spaces.

You can make a small change — to verify that both the character is a space and the one before it was not a space — to fix this. In this way, if there are a bunch of spaces together, the first one when counting for a word.

This illustrates one of the main benefits of functions: the conceptual separation. That in the main routine, you didn't need to worry about how the function was written; you just call it to word_count and expect it to give you a result. You could have 2 different implementations of the function, but they'd look exactly the same when they were called.

But you have to be careful when you don't write the functions that count hidden assumptions — such as the single space between words — that would make the function behave differently than expected.

// Program 12_8
// A more complete function: counting words in a string,
// alternative handling multiple spaces
#include <iostream>
#include <string>
#include <sstream>
using namespace std;

int word_count(string str_count) {
    // Count number of spaces
    int count = 0;
    for (i = 0; i < str_count.size(); i++) {
        if (str_count[i] == ' ' && str_count[i - 1] != ' ') {
            count++;
        }
    }
    // Number of words is one more than number of spaces
    return count + 1;
}

int main() {
    string s = "This is a string that has eight words.";
    cout << "There are " << word_count(s) << " words in the string." << endl;
}

## SCOPE

The last thing to keep in mind when writing your own functions is the idea of scope, which is actually relevant for almost all of programming. Scope refers to the range in which a variable is defined. If a variable is defined in part of a program, it's said to be "in scope"; if it's not defined in a part of a program, it's said to be "out of scope".

In the way you've usually thinking about programs so far, a variable is in scope as soon as it is declared, and it stays that until the end of the program. You can't use it before you declare it, and once it's declared, it can be used in the rest of the program.

But that's not actually the case. In reality, scope works the way out: A variable is in scope only within its own section (denoted by curly braces) of the program.

In Program 12_ERROR_1, notice the variable a is declared inside the main body of the main function, so it is scope throughout main. But by declaring a variable b, the body of a loop is in scope only within that body of the loop. Each loop generates a new variable, because the previous one's scope ends as soon as it reaches the end of the loop. So, when you try to print b outside the loop, you'll get a compiler error that tells you the variable is out of scope.

Notice that the variables that are defined in the main routine are not inside inside the black box of another function you might create. For example, Program 12_ERROR_2 will give an error when compiling. The variable a is defined in the main function, so a is in scope. But when you try to use a variable inside another function, it will be out of scope.

// Program 12_ERROR_1
// Scope Error: b is only defined inside the while loop
#include<iostream>
using namespace std;
int main() {
    int a = 3;
    while (a > 0) {
        int b = 10;
        a -= b;
    }
    cout << b << endl;
}

#include<iostream>
using namespace std;
void demo_func() {
    cout << a << endl;
    return;
}
int main() {
    int a = 3;
    demo_func();
}

One of the nice things scoping is that you can reuse variable names in places without causing conflicts.

In Program 12_10, notice that you have the variable balance declared in the main function that is used to refer to an account balance. You also have another named balance declared in the function calculate_loan, this time referring to a remaining loan balance.

What happens here is that there are two sections of memory: the main function's section of memory and a section of memory for calculate_loan, each of which has a named balance. When you are in the main routine, anytime will refer to its variable balance, and when you're in calculate_loan, you'd be referring to its variable balance.

So, the output that the main routine always shows that the value of balance is 75, both before and after the function call. Meanwhile, the output statement in calculate_loan shows that the value of balance is 475.

// Program 12_10
// Same variable names in different scopes
#include<iostream>
using namespace std;
float calculate_loan(float principal, float payment) {
    float balance = principal - payment; // Remaining balance of loan after payment
    cout << "Inside the function, the value of the loan balance is: " << balance << endl;
    return balance;
}

int main() {
    float balance = 100.0; // Set up a variable to keep track of account balance
    float loan_principal = 500.0;
    float loan_payment = 25.0;
    Now use that to pay a loan
    balance = loan_payment;
    cout << "Before the function call, the value of the account balance is: " << balance << endl;
    loan_principal = calculate_loan(loan_principal, loan_payment);
    cout << "After the function call, the value of the account balance is: " << balance << endl;
}
