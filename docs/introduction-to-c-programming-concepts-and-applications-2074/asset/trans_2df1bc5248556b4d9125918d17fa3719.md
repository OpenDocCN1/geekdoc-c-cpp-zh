程序 6_13 是之前代码的修改版，将生成 1 到 100 范围内的随机数。如果你多次运行，你会看到你得到的是随机数，都在 1 到 100 的范围内。

```
// Program 6_11
// Random Number generation within range 0-99
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main() {
 srand(time(0)); // Set the seed for the pseudorandom sequence
 int x = rand() % 100; // Modulus 100 means between 0 and 99
 cout << "The random number is " << x << endl;
}
```

```
// Program 6_13
// Multiple random numbers in range of 1 to 100
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main() {
 srand(time(0)); // Set the seed for the pseudorandom sequence
 int x = rand() % 100 + 1;
 cout << "The random number is " << x << endl;
 cout << "Here is another random number: " << (rand() % 100) + 1 << endl;
 cout << "... and another: " << (rand() % 100) + 1 << endl;
}
```

如果你想要随机数从 1 到 100 而不是 0 到 99，只需在取模后加 1 即可。

```
int x = rand() % 100 + 1; // Adding 1 to change [0-99] to [1-100]
```
