```
// Program 5_21
// New variable name inside loop
#include <iostream>
using namespace std;

int main() {
    int j;
    int j = 1;
    for (i = 1; i < 4; i++) {
        int j = 500;
        cout << "In loop: " << i << " " << j << endl;
    }
}
```

declare it j, when the loop body is executed, j gets declared again. So, you create a new box, named j, and initialize it to 1. Later in the loop body, you increment j, so it'll have the value 2, then the loop body ends. At this point, the memory is destroyed; there's no more j available.

The next time you go through the loop, you create the variable j and initialize it to 1. So, every it's printed out, the value will show up as 1.

To get a static from around one iteration to the next inside a loop, you can declare a static variable inside the loop. If you put the static in front of the declaration, it says you want to declare a variable and that declaration lasts even when it goes out of scope. So, if you come back to this variable in the part of the code later, you'll have access to it.

Declaring a variable inside a loop sets aside new memory for that variable, even if it has the same name as a variable outside the loop. When the loop ends, that new memory is destroyed, but the original variable remains.

| static int j = 1;

In this case, the variable j is created the first time you enter the loop body. Each time you go through the body in the future, that line is skipped, and you don't destroy the box named j at the end of the loop. So, every time you encounter the j++ line, it will increment j, and new value will stick around its next iteration.
