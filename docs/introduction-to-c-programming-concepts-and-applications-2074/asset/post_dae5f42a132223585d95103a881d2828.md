
# // YOUR FIRST PROGRAM

There's a very long-standing tradition in computer science that the first program you develop—in any language—is a Hello, World! program, which is just a program that displays the message *Hello, World!* to the user.

Here's what a Hello, World! program looks like in C++.

You set up an IDE and the program into the IDE's editor window. When you tell the IDE to run the program, it will compile the program and then run the executable that the compiler produces. The result of the program is a line of *output* that prints out the *Hello, World!*

```cpp
// Program 1_1
// Our first program!
#include <iostream>
using namespace std;

int main() {
	cout << "Hello, World!" << endl;
}
```

> In programming terms, the word **print just means** "display" or "show".

A selection of programs will be shown in this guide. To view all programs discussed in this course, go to TheGreatCourses.com/CPlusPlus.

> Curly braces are a critical part of C++ programming that date all the way back to a predecessor language in the 1960s called BCPL—and before that how you write a set in mathematics, such as the set {1,2,3}.

The first lines you'll see are comment lines (a). Comments are ways of giving notes about the code, but they do not affect what the code actually does.

The next line has **int main** and then a pair of parentheses (c). This is part of the code that marks the beginning of the program—main part. It lets the computer know that this is where the code to run begins.

The next few lines are header information (b). The **#include** line gives you access to a **stream** of input and output. The **namespace** line makes it easier for you to write code.

Next, you'll see a pair of curly braces (d), which group a set, or block, of commands together. In this case, the curly braces are grouping all the commands inside the **main** part of the program.

Finally, you have your actual line of code giving a command (e). This is the line of code that tells the computer specifically what you want to do. It is the output of **Hello, World!** This statement is important; the rest of the program is the same as in other programs. One statement is the key line that does something specific.

First, notice the line that begins with the word **cout**, which is an expression "console output". The **console** means that there's going to be output, and the output will be going to the console—it is to the default output area. In an IDE, the default output area may be an output pane within the main window, or it might pop up a new window if you're running the code in a browser. It will show you the result in that window you're running.

The next thing that gets streamed to the output is the word **endl**, which is a way of saying "end line" for output. If you don't include **endl**, then the next line'll be printed out immediately after the first one; you include **endl**, so that the next thing to be printed will come at the beginning of the next line.

- The only times you don't have a semicolon; for a few special cases:
- **#include** line isn't a command that you want to perform as part of the program but rather a command to the compiler that translates the code to machine instructions
- the braces around **main** are not a command but rather a way of grouping commands

Next is what looks like a double-less-sign. This is the output **stream operator (<<)**. The less-signs as arrows pointing in the direction that the information is flowing. In this case, you have something that you want to print, so that you're printing will flow toward the console output. Notice there are 2 stream operators on one, which shows that different items are streamed in: The thing to the left will reach the console output before the thing to the right.

> The **endl** indicates an end of line what is output, not necessarily the end of a line of code.

Finally, a semicolon appears at the end of the line of code. In C++, the semicolon indicates that you've reached the end of a line.

Any time you finish with an individual command, it will need to have a semicolon at the end.

Unlike other languages, the order and spacing of your C++ code doesn't matter. You can put instructions of code on one line with no space after the semicolons, or you spread a single instruction over multiple lines. The compiler basically ignores everything as it converts the program to machine instructions. Instead, you separate one command from another by using the semicolon to mark the end of a statement.

> Just as a period ends a sentence in English, a semicolon ends a statement in C++.

Just like a sentence you can write across more than one line—or you can have 2 sentences on the same written line—a statement in C++ can go across more than one line, or you can have more than one C++ statement in the same written line. It's the semicolon, not just moving to a new line, that ends a statement.

After the stream operator is the text that you actually want to output. Notice that the text you want is enclosed in a pair of quotation marks. You have to use quotation marks to identify text in your code; otherwise, the letters will be misinterpreted by the compiler. The words **Hello** and **World**, with punctuation—a command and appear inside the quotation marks.

Comments can be anything that helps people understand what the code is for. Comments are skipped entirely by the compiler; when a compiler sees a double slash, it reads what follows as a comment. While processing code, it skips over, all the way to the end of the line. So, including comments is purely to help people reading the code.

There's not much need for comments in small pieces of code compared to how important they are in bigger programs. But getting in the habit of including comments to explain code will help whenever you do end up writing somewhat larger programs.

```cpp
// Program 1_9
*****************************************************************/
/* Our First Program! */
*****************************************************************/
#include <iostream>
using namespace std;

/* About to start the main program */
int main()
{
    cout << "Hello, World!" << endl; // This is a single line comment
}
```

A comment could be for people who didn't write the code but come along later and understand it, or it can help tell your future self what you had in mind for each part of the code.

In C++, there are 2 ways of writing comments. The first is one you begin the comment with a double forward slash (//), which is a way of indicating everything from that point on one line that is a comment.

The other type opens and closes with /* and */. This type of comment is helpful if you want to write multiline comments. It begins with /* and continue until you closed by /, even if there's a multiline comment anywhere you wish by using this format. You could also modify your original program to make the initial comment use this format.

You often use example to create visual block separation at the beginning of a program. Note in this example that you have a few lines of just asterisks, providing a visual block of comments at the beginning of the program.

And you often use a comment to describe what's coming next. For example, you might put a comment right before the main part of the program, showing what part is about to do.

This is pretty simple program; the real work of the program is all done in one line.

This slightly more complex program has 3 different lines of code in the main program—the program lines that begin just below the int main. All 3 of these lines are nearly identical; they print out some text. Each one prints out on a different line. The first says, *Howdy, John!* The next one says, *Are you ready to learn C++*, and the final says, *Let's get started...*

Each output also includes an end-of-line character.

Commands are executed in sequential order. When you have a series of commands, like the 3 count statements you have, the program will handle each of them in sequence—the order specified. So, if you consider a program as being a series of commands, then running the program is executing these commands in order.

```cpp
// // Program 1_10
// A longer program, giving a greeting
#include <iostream>
using namespace std;

 main() {
    cout << "Howdy, John!" << endl;
    cout << "Are you ready to learn C++?" << endl;
    cout << "Let's get started..." << endl;
}
```
