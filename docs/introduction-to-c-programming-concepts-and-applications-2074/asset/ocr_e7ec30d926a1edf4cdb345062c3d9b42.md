The next line is the **using namespace** command. A namespace is a grouping of various functions together. By saying **using namespace**, you are indicating which group of functions you're using. In this case, the `std` (short for *standard*) namespace. A way to think of a namespace is a special name that needs to be added to the beginning of commands.

There are big projects that require this way of working. There might even multiple namespaces, because different groups on a project often create new namespaces to distinguish their code. But it can be a pain to keep `std::` before each command for a small project where the scope of the `using namespace` is clear. So, the line `using namespace std` lets you say, "Unless specify otherwise, I'm using the standard namespace." And because this is a C++ command, not a command to the preprocessor, and ends with a semicolon.
