# // 文件流

每当程序读取或写入文件时，始终涉及 3 个步骤：

+   1 打开文件。
2 从文件读取或向文件写入。
3 关闭文件。

你将需要使用一个名为 `fstream` 的库（是 *streaming* 的缩写），它为你提供写入文件的工具。

就像你能够使用 `stream` 控制台输入和输出 `iostream` 一样，现在你将使用 `fstream` 从文件流式传输和流式传输到文件。

一旦你有了 `fstream` 库，你就可以创建类型为 `fstream` 的对象。

一个 `object` 可以被认为就像一个变量，你基本上可以互换使用 `object` 和 `variable` 这两个词。你使用“声明对象”或“初始化对象”的术语，就像你对变量、例如整数所做的那样。

但使用 `object` 这个术语实际上意味着比你所了解的变量多一点，因为一个对象可以存储多于一个数据片段，并且有“属于”它的函数。
