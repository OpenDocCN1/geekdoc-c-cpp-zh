Vectors have another method that can be used to initialize them. Imagine that you wanted a large vector with 1000 elements and you wanted all of them to have some initial value, say 10. One option would be to use curly braces with 1000s inside it. That would be a huge pain to type!

For vectors, though, you have a way of initializing all of the elements to some particular value. To do this, you declare the vector, then the number of elements, followed by a comma, and then the value that you want each of the elements to have:

```
vector<int> v(3, 10);
```

This example shows you creating a vector of size 3 with all elements initialized to 10. Outputting the vector verifies that, indeed, works as expected.

The following line declares a vector of floats named accounts starting size 4:

```
vector<float> accounts(4);
```

If you wanted a vector to be initialized with a balance of $100 in each account, you would change the initialization by writing the following line:

```
vector<float> accounts(4, 100.0);
```

Recall that you could initialize an array by specifying an initial set of element enclosed in curly braces. You can do the same thing with vectors when you declare them. After the declaration, you want you in curly braces, and now the vector is initialized with those values.

Now Program 8_9, you declare a vector of ints v and initialize it by adding = {1, 2, 3}. This will cause the vector to have 3 elements, valued 1, 2, and 3. Notice that you do not have to set the size vector explicitly; when you print out the vector, you see that, indeed, it has 3 elements, with values 1, 2, and 3.

Now you have a 2-argument value with 2 values in the parentheses. The first is the size, 4, and the second is to initialize everything to, 100.

This is called a constructor function—function that's called to initialize a variable when it's first declared. Because it's a function, there are parentheses and possibly arguments. For now, just think of the constructors providing a nice way to initialize your vectors.
