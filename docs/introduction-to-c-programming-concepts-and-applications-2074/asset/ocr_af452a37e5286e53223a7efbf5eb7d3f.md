# // INITIALIZING ARRAY

You can also initialize arrays directly.

If you have an array of size 5 but only initialize it with 2 values—suppose you don't know the size of the other teams—then the first 2 elements of the array are initialized.

Program 7_5 has an array declaration that you might use if you were keeping track of numbers of people on various teams in a competition. The array team_members is declared to have size 5. To initialize it, you can specify the initial values that you want the elements to be a set of 5 values separated by commas and enclosed in curly braces. In this, you initialize the array to have values 5, 6, 4, 5, and 4.

```
int team_members[5] = { 5, 6 };
```

When you run this program, the for loop iterates through all the members and the cout prints out for each of the 5 elements in the order you specified.

When you have array elements that aren't specified, they are often initialized to the value Ø by default. It's better to explicitly set any values that you want to be initialized so that you know what's in the memory locations you might access.

When you print out the values of the first 5 elements, you see that the first 2 elements have the values 5 and 6, as specified. The last 3 elements all have the value Ø.

Finally, you can declare an array without specifying if you initialize it with a set of values. In the code below, the my_array is declared with an indeterminate size, where you initialize it with a set of 5 values. But so, this implicitly defines the array to be of size 5, and that all the values are set correctly.

+   // Program 7_5
// Array Initialization
#include <iostream>
using namespace std;
int main() {
    int team_members[5] = { 5, 6, 4, 5, 4 };
    for (int i = 0; i < 5; i++) {
        cout << team_members[i] << endl;
    }
}

```
int my_array[] = { 5, 6, 4, 5, 4 };
```

On the other hand, if you just tried to declare an array with no size, you'd get a compiler error. Only when the array is initialized to something with a known size is it OK to leave the square brackets empty.
