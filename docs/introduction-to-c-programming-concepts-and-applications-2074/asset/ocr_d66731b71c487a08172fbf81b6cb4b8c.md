# // STRING OPERATIONS

In Program 9_6, you have 3 strings-named s1, s2, and s3—and assign the string Happy to s1 and the string Birthday to s2.

This means that the addition operation, + works differently for 2 strings than it does for 2 numbers. The + operator is overloaded, which means it has more than one meaning, depending on the types of the input.

In Program 9_8, you have a string, s, that you initialize to the value Happy. You then have a line: s += "Birthday";

Then, you have a s3 = s1+s2. In other words, you are adding 2 strings to get a third string.

When you run this, you'll get a concatenated string, HappyBirthday, with no space in between. The Birthday has been appended to the original string, which was Happy. Basically, you took the value in the string and performed a + operation on the right side, putting the result back in the original variable. But + for strings is defined as concatenation, so the 2 strings were concatenated and the result was placed in s.

If you run this program, outputting s3 gives you a string HappyBirthday, with no space between the words. Basically, the s3 was formed by the first string, Happy, and sticking the next string, Birthday, onto the end. This is called concatenation. You have concatenated the strings s1 and s2 to form s3.

Operator overloading is a common practice for defining behavior between different types.

> A + does not always mean addition.
The meaning of various operators changes depending on the type of thing they are operating on.

In another variation of the previous program, instead of the strings Happy and Birthday, you assign s1 the string 3 and s2 the string 4.

```
// Program 9_6
// Adding strings
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s1, s2, s3;
    s1 = "Happy";
    s2 = "Birthday";
    s3 = s1 + s2;
    cout << s3 << endl;
}
```

When you add 2 together, the output is 3. Why?

| 10 | s1 = "3"; |
| 11 | s2 = "4"; |
| 12 | s3 = s1 + s2; |

```
// Program 9_8
// Adding a string
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "Happy";
    s += "Birthday";
    cout << s << endl;
}
```

Keep in mind that s1 and s2 are strings. The 3 that is assigned to s1 is not the number 3; it is a string that has just a single character digit, 3, inside of it. Likewise, when you add the assigned 4, you get concatenation, so the result of adding s1 and s2 is to concatenate their strings. The result is not really the number 34; it's the string 34.
