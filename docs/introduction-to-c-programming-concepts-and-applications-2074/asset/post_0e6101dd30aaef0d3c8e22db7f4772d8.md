Society today generates massive amounts of data, including records of digital transactions, social media posts, and information from sensors and devices spread everywhere. In order to handle that large amount of data, we need a way to store it. And we need to be able to store not just a few variables, but dozens, or hundreds, or thousands. Frankly, there’s a solution—in fact, more than one—for handling as much data as you have. Two methods for storing data are arrays, which were part of C, and vectors, which were an improvement of C++.

### // STORING VARIABLES IN MEMORY

Let’s say you want to store one variable. You declare a variable, and that creates a "box" with that name that stores in memory. If you want to store a second variable, you declare a second variable, which gets a new box in memory.

An array is a collection of some number of variables. All the variables will have the same type, and all will be referred to using the same name, with a separate way of identifying each individual variable.

After the array name, you have a pair of square brackets, which let you specify the size of the array, or the number of elements in the array. In this case, you’re using an array of size 20.

If you wanted to allocate many variables—say 20 of them—it would be possible to declare 20 different variables. Instead, it would be easier to say, "I want a set of 20 variables"—and that is what an array does.

To declare an array of variables, you still start with the type of variable you want. Program 7_1 on page 77, it’s an integer.

In mathematics, vectors and matrices are described using square brackets. Because an array is similar to a vector or in matrix, it makes sense square brackets are used for them, too.

You then have the name of the array, which is test_array. It wouldn’t be practical to name all the variables with names, so you would refer to the entire group—the entire array—by one name.

// Program 7_1

// Declaring array

#include <iostream>

using namespace std;

int main() {

test_array[20];

test_array[0] = 10;

test_array[1] = 20;

test_array[2] = 25;

}

In memory, these 20 "boxes" are all set aside in one block—one block right after another.

After the array has been declared—that is, after that long stretch of boxes has been set aside in memory—you can refer to each individual box as a separate variable. To do this, you will again use square brackets, containing a number, after the name. The first box will be 0, the second one will be 1, etc. You refer to a box by the array name and then, in square brackets, the box number.

Why do you start the numbering 0 instead of 1? The short answer is it's a little more efficient than starting with 1.

In Program 7_1, you are assigning values of 10, 20, and 25 to the first 3 boxes in the array. Notice that you can assign values to them, and you can refer to values inside them, just like with other variables.

Generally, the whole array is referred to as the variable. In other words, even though the array is made up of many different "boxes", which you could think of as many different individual variables, you will generally be able to refer to the entire array—the entire collection of boxes—as one thing, so it makes sense to call it a variable.

The individual boxes are called the elements, which are the component variables of the overall array variable.

The number identifying an element is called the index.

To refer to an element of an array, the common phrase used is sub which can be thought of as short for subscript and then the index number.

### // INDEXING INTO AN ARRAY

One of the things that makes arrays feasible is that you can use a variable to represent the individual index.

Suppose you create a small array named a with 5 elements, and you assign values of 10, 20, 30, 40, and 50 to them. Then, you create an integer i that you initialize to 3, and you print out a[i].

The ability to index into an array by using a variable that contains the index gives you the ability to easily address all the elements of the array looping through it.

For example, you can set all of the elements to initial values. Suppose you were playing a 4-person game and wanted to have the same amount of money in the begin—$200 (Program 7_3).

```
int main() {
int a[5];
a[0]=10;a[1]=20;a[2]=30;a[3]=40;a[4]=50;
int i = 3;
cout << a[i] << endl;
}
```

You first create an array. You could write int player_money[4], which would declare an array named player_money with 4 elements.

Then, you would loop over the indices. In this case, you can use a for loop to iterate over the elements from 0 to 3. You use i to keep track of the index.
