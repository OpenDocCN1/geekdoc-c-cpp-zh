Both the car class and the derived SC300 class will have 2 functions: one giving the price (27, 63) and other prints information about the vehicle (23, 45). For the car class, the price is just the base price, and the only one prints the model name and price. For the SC300, the price is determined based on which optional packages are included, and the output will be more complicated.

If you create a generic car, using the default constructor for the car, and call the print_info function it will call the version defined in the car class (p). If you create an SC300 class and call print_info, you will be calling the print_info function defined in the SC300 class—not the one in the car class (q).

This is still not "full" polymorphism. All you are doing here is letting subclasses about redefining of functions; a complete version of polymorphism comes from the superclass, where a single function from the superclass is created that takes on different forms in the subclasses.
