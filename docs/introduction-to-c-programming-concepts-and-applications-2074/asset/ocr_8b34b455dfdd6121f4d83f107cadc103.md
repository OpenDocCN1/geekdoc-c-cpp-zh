While it may be possible to use either loop, there is a clear better choice in each case:

+   - while. This will repeat an unknown number of times, until some condition is reached. That is typical of a while loop.

+   - for. You know a specific number of times you want the loop to run, so this is generally done using a for loop.

+   - for. You want to loop over each of the values in the range, and because there is a specific range, a for loop is more appropriate.

+   - while. You will repeat some unknown number of times until some condition is met. This is more commonly handled by a while loop.

This program has 2 nested loops. The outer for loop varies i on 0, 2, 4, 6, and 8 because it is initialized to 0, continues only as i is less than 10, and increases by 2 each time. In the inner while loop, j takes values starting at i and keeps dividing by 2. This continues until j is 1. Notice that the output occurs after j is divided by 2, so, as long as j begins with a value greater than 1, the final output will be 1. So, our output is:

2
4
1
6
1
4
2
1

Here is the most straightforward way:

```
#include<iostream>
using namespace std;

int main() {
int i;
for (i=10; i > 1; i--) {
cout << i << endl;
}
}
```

> >> When i has the value 0, the inner loop is never run.

> >> When i has the value 2, then j gets the value 2; the loop is run for iteration, which j becomes 1; and one output is: 1.

> >> When i has the value 4, then j gets the value 4, then mem, 1. The outputs are twice, first after j gets the value 2 and then again i gets the value 1.

> >> Likewise, when i has the value 6, then j will have the value 6, then 3 (remember that this is integer division). So, again, 2 lines are output: one j is 3 and when j is 1.

> >> Finally, when i has the value 8, j will take values on 8, 4, then 2, 1. Thus, there will be 3 lines output, for the values of j equal to 4, 2, and 1.

Remember that the initialization (i=10) is the first item in parentheses of the for loop, the condition (i > 1) is the second term in the parentheses, and the update (i--) is the the last term in the parentheses.
