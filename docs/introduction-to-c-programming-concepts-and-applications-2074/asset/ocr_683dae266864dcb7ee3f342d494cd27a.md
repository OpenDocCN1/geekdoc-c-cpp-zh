# PSEUDCODE

Remember to start by writing pseudocode, giving an outline of what you want the program to do.

+   - Generate a random number
- Get a user's initial guess
- Repeat until the user guesses the right value
    - Repeat if too high or too low
    - Get another guess
- User guessed it - report how many tries.

Next, you use the pseudocode outline and convert it into the code. You will make each of the steps a comment within `main`, testing the code after each step is coded. Then fill in the parts of the program one by one.

For someone just starting, the amount of information in these libraries may feel a bit overwhelming. So, if you want to look at library functions, start with a header for something that sounds simple and focus on one or 2 functions, trying to understand them. Once you get started, you might look at the libraries `string`, `complex`, `ctime`, and `stack`.

For more, you can search for lists of "open source C++ libraries" available on the Web. On the home page for cppreference.com, there is a link for Non-ANSI/ISO Libraries that's a list of unofficial libraries that are available for a variety of applications.
