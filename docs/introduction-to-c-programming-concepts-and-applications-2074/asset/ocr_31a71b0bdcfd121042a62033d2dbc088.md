However, a pointer also defines the type of thing that the address it contains.

There are a few ways to dereference pointers.
The most basic way is to use * in front of the pointer name.

When you write [0], you are getting the value stored at the address the pointer is referring to. And, if you write [1], you mean the thing stored in memory past the pointer is referring to.

A pointer is declared much like any other variable, but there is some syntax to use it.

In Program 18_1, you create an integer, x, that gets assigned the value 3 (8). This integer is a static variable.

So, Program 18_2 works identically to Program 18_1. The only difference is instead of writing *y, you write y[0] (11, 12).

+   >> To create a pointer, you list the type of thing you're pointing to but then include * (commonly read "star") to indicate that this variable is to contain an address where there's some of that.

Then, you create a new variable, y, that is a pointer to integer (9). The pointer is not set to anything initially.

+   >> Once you've declared a pointer, you can assign it a particular memory address. To get the memory address of variable, you put & in front of the variable's name. Think of the address as being GPS coordinates.

You assign the address of x (10). In other words, y points to x.

+   >> Once you declare and you assigned a memory address, you can get the thing that it is pointing to—the thing that is at memory address—in a process known as dereferencing the pointer.

When you output *y, you are outputting the value that y is pointing to. In this case, where it's pointing the value 3, you output 3 (11).

If you have a pointer to an object—but only that—way to dereference pointers. You can access member variables or public member functions using ->, which looks like an arrow, so it's known as the arrow operation.

In the next line, you are assigning a value, 5, to the integer pointed to y. So, the memory location that y is pointing to will get the value 5. This is the same memory location used by x (12).

This is the same as if you dereferenced the pointer and then used a [] to access the member variable or function.

So, when you print out the value of x, you see that x has the value 5 (13).

```
// Program 18_1
// Pointer example using *
#include <iostream>
using namespace std;

int main() {
    int x = 3;
    int *y = &x;
    cout << *y << endl;
    *y = 5;
    cout << x << endl;
}
```
