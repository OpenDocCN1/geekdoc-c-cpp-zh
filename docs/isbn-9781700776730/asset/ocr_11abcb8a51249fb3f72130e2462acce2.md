# Comments

All text between // and the end of the line is considered a comment. The comment automatically terminates at the end of the line.

```
// This is a comment

int num;      // This is another comment
```

Note that this is one of the exceptions to the rule that the compiler ignores white space. In this case, the carriage return \n line feed white space character defines the end of the comment.

For multi-line comments we can still use:

```
/*
int x;
int y;
int z;
*/
```

Comments may also be nested within /* */. This allows you to comment out comments:

```
// /*
int x;
int y;
//  */
```

or you could say:

```
/*  // */ int x;
```
