
```cpp
int main() {
    Distance d1, d2;

    cout << "Enter Distance values: ";
    cin >> d1 >> d2;
    cout << "d1 = " << d1 << endl;
    cout << "d2 = " << d2 << endl;
    Distance d3(11, 25);
    cout << "d3 = " << d3 << endl;
    return 0;
}
```

This program asks for two distance values from the user, and then prints these values and another value that was initialized in the program. Note that the input and output operators, respectively, are passed by reference to an istream and ostream object as their left operand which allows successive input or output operators to be concatenated. For example:

```cpp
cout << "d1 = " << d1 << "d2 = " << d2;
```

Here, each parenthetical sub-expression returns the stream object as the outermost expression. Because of the design of istream, an input or output operators must be friend functions and take arguments of your user-defined type and the same stream object as a return value you can have expressions of the form:

```cpp
cout << d1;
```

Why couldn't we define the overloaded operator as a member function of Distance? If we did, it would be very confusing to the programmer and readers of the program because the member function of output operator declares only one ostream object. Therefore it is better to use friend functions.

## Updated Distance Class

```cpp
// dist4.h
#ifndef DIST4
#define DIST4

#include <iostream>

using namespace std;

class Distance {
private:
    int feet;
    float inches;
    void normalize();

public:
    Distance();
    Distance(float f);
    Distance(int ft, float in);
    Distance& operator+=(const Distance& d);
    friend Distance operator+(const Distance& d1, const Distance& d2);
    friend Distance& operator>>(istream& is, Distance& d);
    friend ostream& operator<<(ostream& os, const Distance& d);
};

#endif
```

```cpp
// dist4.cpp
#include <iostream>
#include "dist4.h"

Distance::Distance() {
    feet = 0;
    inches = 0;
}

Distance::Distance(float f) {
    feet = (int)f;
    inches = (f - (int)f) * 100;
}

Distance::Distance(int ft, float in) {
    feet = ft;
    inches = in;
    normalize();
}

void Distance::normalize() {
    while (inches >= 1200) {
        inches -= 1200;
        feet++;
    }
}

Distance& Distance::operator+=(const Distance& d) {
    feet += d.feet;
    inches += d.inches;
    return *this;
}

Distance operator+(const Distance& d1, const Distance& d2) {
    int ft = d1.feet + d2.feet;
    float in = d1.inches + d2.inches;
    return Distance(ft, in);
}

istream& operator>>(istream& is, Distance& d) {
    cout << "Enter feet: ";
    is >> d.feet;
    cout << "Enter inches: ";
    is >> d.inches;
    d.normalize();
    return is;
}

ostream& operator<<(ostream& os, const Distance& d) {
    os << d.feet << "' " << d.inches / 100.0 << "'";
    return os;
}
```

## Overloading the Array Subscript Operator []

The subscript operator [] is normally used to index arrays. In fact, the subscript operator is a binary operator that requires two arguments. For example:

```
p = x[i];

[] : operator
x : first argument
i : second argument
```

The subscript operator actually performs a useful function, it hides pointer arithmetic for us! For example, if we have the following array:

```cpp
char name[20];
```

and we execute a statement such as:

```cpp
ch = name[12];
```

The [] operator directs the assignment statement to add 12 to the base address of the array name to locate the data stored in this memory location.

```cpp
ch = name[12] implements pointer arithmetic: *(name + 12)
```

You can overload the array subscript operator [] to provide array-like access to a class's data members, even though that data might be stored as individual members. Let's overload the [] operator for a class that stores four integer values as separate data members.

```cpp
// parray.h
#ifndef _PARRAY_H
#define _PARRAY_H

class PseudoArray {
private:
    int value0, value1, value2, value3;
public:
    PseudoArray(int v0, int v1, int v2, int v3);
    int operator[](int i);
};

#endif
```

```cpp
// parray.cpp
#include "parray.h"

PseudoArray::PseudoArray(int v0, int v1, int v2, int v3) {
    value0 = v0;
    value1 = v1;
    value2 = v2;
    value3 = v3;
}

int PseudoArray::operator[](int i) {
    switch (i) {
        case 0: return value0;
        case 1: return value1;
        case 2: return value2;
        case 3: return value3;
        default: return -1;
    }
}
```

```cpp
// parry.cpp
#include <iostream>
#include "parray.h"

using namespace std;

int main() {
    PseudoArray pa(10, 20, 30, 40);
    cout << "pa[0]: " << pa[0] << endl;
    cout << "pa[1]: " << pa[1] << endl;
    cout << "pa[2]: " << pa[2] << endl;
    cout << "pa[3]: " << pa[3] << endl;
    return 0;
}
```
