
```
int* ptr1 = new int[5];
int** ptr2 = new int*[8];
...
delete [] ptr1;
delete [] ptr2;
```

The brackets are required to tell the compiler to expect an array of objects on the heap. This has that important ramifications when you need to delete an array of user-defined objects.

So the rule is: If you used brackets in `new`, then use brackets in `delete`. If you didn't use brackets in `new`, then don't use brackets in `delete`.

Note: If the contents of a pointer given to `delete` contains the value zero or `null`, it is perfectly permissible since this situation is guaranteed not to do anything harmful.

In the following example, the user is asked to enter string data from the keyboard. The input is captured into a buffer area of some fixed length, after which it is copied onto the heap. Note that exactly the amount of heap space is allocated to store each string. After all strings have been entered, they are printed and their heap space released via `delete`.

The key data element is `ptr`, which is a pointer-to-pointer so that the array of pointers needed to keep track of strings can grow dynamically on the heap.

```cpp
// Dynamic Memory Allocation

#include <iostream>
#include <string.h>

using namespace std;

void input(char**& ptr, int& counter);
void output(char** ptr, int counter);
void release(char** ptr, int counter);
```

```cpp
int main() {
  char** pptr = 0;
  int counter = 0;
  input(ptr, counter);
  output(ptr, counter);
  release(ptr, counter);
  return 0;
}
```

```cpp
void input(char** pptr, int& counter) {
  const int MAX = 256;

  cout << "Enter string: ";
  char buf[MAX];
  // End input with Ctrl-D
  while (!(cin >> buf).eof()) {
    // Get actual amount of space
    char* temp = new char[strlen(buf) + 1];
    strcpy(temp, buf);
    // Array of pointers grows dynamically
    char** temp_pptr = new char*[counter+1];
    for (int i = 0; i < counter; ++i) {
      temp_pptr[i] = pptr[i];
    }
    temp_pptr[counter++] = temp;
    // Release old space for old pointers
    delete []pptr];
    // Update pointer to current array of pointers
    pptr = temp_pptr;
    cout << "Next string: ";
  }
}
```

```cpp
void output(char** pptr, int counter) {
  const char QUOTE = "'";

  if (counter > 0) {
    cout << "\nstrings:\n";
    for (int i = 0; i < counter; ++i) {
      cout << QUOTE << pptr[i] << QUOTE << '\n';
    }
  } else {
    cout << "Empty list\n";
  }
}
```

```cpp
void release(char** pptr, int counter) {
  for (int i = counter - 1; i >= 0; --i) {
    delete []pptr[i]];
  }
  delete []pptr];
}
```

# Pointer Traps

Pointer variables give the programmer great flexibility, but they can lead to difficult to find and correct errors in your programs. We will examine the common problems and give hints about how to avoid them.

Let's assume the following type and variable declarations:

```cpp
int *first = NULL;
int *second;
int *third;
int num = 4;
```

We also assume that the following code has been executed:

```cpp
second = new int;
*second = 2;
```

# Dereferencing NULL

It is an error to dereference NULL. This is the safest error to make, since the system will usually catch the error at run time.

```cpp
cout << *first << endl; // Error, first is NULL
```

It is just as much a problem to dereference NULL with the -> operator in the case that your type is a class or struct. A NULL pointer does not point to anything. Dereferencing obtains the pointer points to.

# Dangling Pointer

It is an error to dereference a pointer that has not been correctly given a value. This error will probably cause an eventual crash, but usually after running incorrectly for a while.

```cpp
cout << *third << endl; // Error, third has no value
```

Interestingly, something will be printed most likely. If this happens to have a value that looks to the running program like a valid pointer we will get the contents of a few memory locations interpreted as an int, independently of what they actually contain.

It is far worse to say:

```cpp
*third = 3;      // Serious error - changing a random memory location
```

A pointer can get a valid value by assigning it NULL, or another pointer known to be valid. You can assign it the result of calling operator new. You can also get a valid pointer.
