# Accessing Static Data Members

Now suppose you want to read or modify a static data member. You can access a static data member just like any other data member:

```
// word5.h

#ifndef WORD5_H
#define _WORD5_H

class Word {
private:
    char *buf;
    static int wordCount;
public:
    Word(char *s);
    int getCount();
};

#endif
```

```
// word5.cpp

#include <string.h>
#include "word5.h"

int Word::wordCount = 0;

Word::Word(char *s) {
    buf = strdup(s);
    wordCount++;
}

int Word::getCount() {
    return wordCount;
}
```
