We can now declare and use a Derived class object:

```
int main() {
    Derived d(10, 2);

    cout << "value = " << d.getValue() << endl;
    return 0;
}
```

Note that the getValue() member function from the Derived class gets called here and returns the product of the two values used to initialize the object. The above code generates the output:

value = 20

# Accessing Member Function with Pointers

Let's now declare a Base class pointer and call the getValue() member function for the addressed object:

```
int main() {
    Base *bptr = new Base(10);
    cout << "value = " << bptr->getValue() << endl;
    return 0;
}
```

The output generated by the above code is:

value = 10

which is expected.

We can now declare a pointer to a Derived class object and call the replacement getValue() member function defined in the Derived class.
