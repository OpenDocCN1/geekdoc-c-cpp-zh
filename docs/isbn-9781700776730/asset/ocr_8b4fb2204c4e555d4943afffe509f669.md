Type, compile and execute the following C++ program:

```
// ok2.cpp - uses flush member function with cout

#include <iostream>
#include <stdio.h>

using namespace std;

int main() {
    // turn on buffered output for cout
    cout.unset(ios::unitbuf);

    printf("Print this first.\n");
    cout << "Print this second.\n\";
    cout.flush();
    printf("Print this third.\n");
    cout << "Print this last.\n\";
    cout.flush();
    return 0;
}
```

For our example, we display individual strings separately on different lines. To do this, we must append '\n' (newline) characters to each string. Since we're also mixing calls to printf() in our program, we must also insert the flush manipulator. To save programming time, we can use the endl manipulator and calls the flush manipulator.
