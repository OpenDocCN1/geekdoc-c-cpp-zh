# Release 2

```
char *first, *last;
char fullname[100];

if (strlen(first) + strlen(last) + 1 > 100)
  error();
  strcpy(fullname, first);
  strcat(fullname, ".");
  strcat(fullname, last);
```

See if you can figure out why Release 2 crashes before reading further.

# Why Release 2 Crashes

A user caused Release 2 to abort by using a fullname longer than 100 characters.

# Release 3

We try doing it dynamically:

```
char *first, *last;
char *fullname;

fullname = malloc(strlen(first)+strlen(last)+1);
strcpy(fullname, first);
strcat(fullname, ".");
strcat(fullname, last);
```

See if you can figure out why Release 3 crashes before reading further.

# Why Release 3 Crashes

Release 3 crashed at random times in random places, apparently unrelated to our subroutine.

An extensive debugging effort finally catches it: we are allocating one byte too little memory. Look closely at the malloc() declaration.
