# String Variables and Constants

Consider the following C++ program:

```
#include <iostream>
using namespace std;

const int MAX = 50;

int main() {
    char buf[MAX];

    cout << "Enter a string: ";
    cin >> buf;
    cout << "You entered: " << buf;
}
```

What happens if the user enters a string that is longer than the array used to hold it? Simple. We overwrite memory. So how do we avoid buffer overflow? We can tell the >> operator to limit the number of characters it places in the array:

```
#include <iostream>
#include <iomanip>

using namespace std;

const int MAX = 50;

int main() {
    char buf[MAX];

    cout << "Enter a string: ";
    cin >> setw(MAX) >> buf;
    cout << "You entered: " << buf;
}
```

The program uses the setw() manipulator to specify the maximum number of characters the input buffer can accept. The user may type more characters, but the >> operator will not insert them into the array. Actually, one character fewer than the number specified is inserted, so there is room in the buffer for the terminating null character.

Note: The extraction operator (>>) considers a space to be a terminating character. Thus a string is delimited by a space and anything typed after a space is thrown away.
