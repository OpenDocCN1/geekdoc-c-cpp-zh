```
// distrv2.cpp

#include <iostream>
#include "dist2.h"

using namespace std;

int main() {
    Distance d1, d2, d3;

    d1.getDist();
    d2.getDist();
    d3.addDist(d1, d2);

    cout << endl;

    cout << "d1 = " << endl
    d1.showDist();
    cout << endl << endl;

    cout << "d2 = " << endl
    d2.showDist();
    cout << endl << endl;

    cout << "d3 = " << endl
    d3.showDist();
    cout << endl << endl;
}
```

The two distances to be added, d1 and d2, are supplied as arguments. Note that the syntax for arguments that are objects is the same as that for arguments that are simple data types like int. The object name is supplied as the argument.

Since addDist() is a member function of class Distance, it can access private data in any Distance object supplied as an argument. Thus, it has access to the data members of d1 and d2.

When a member function is called, with or without an argument, it is given access to only one object, the object that called it. In our example, we called:

```
d3.addDist(d1, d2);
```
