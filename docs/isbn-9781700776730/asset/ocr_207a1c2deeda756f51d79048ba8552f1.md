In multiple inheritance, a derived class receives all the inheritable properties from all of the listed base classes. If a name conflict occurs, such as the same name appearing in more than one base class (i.e., two base classes declaring a member function or data member with the same name), the name is not overridden in a derived class, it's use would be an error, even if members private or have different sets of parameters.

The fix would be to use the scope resolution operator to specify which one you intend to use:

```
class A {
public:
    int a;
    void foo();
};
class B {
private:
    int a;
    void foo(int);
};
class C : public A, public B {
};
int main() {
    C myObj;

myObj.foo();      // error - ambiguous
myObj.foo(5);     // error - ambiguous
myObj.a = 3;      // error - ambiguous
myObj.A::foo(); // OK
myObj.A::a = 3;   // OK
    return 0;
}
```
