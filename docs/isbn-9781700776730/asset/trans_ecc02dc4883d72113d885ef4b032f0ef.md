

```cpp
#include <iostream>

using namespace std;

class Base {
public:
    Base();
    ~Base();
};

class Derived : public Base {
protected:
    char *pBuf;
public:
    Derived();
    ~Derived();
};

Base::Base() {
    cout << "Base::Base()" << endl;
}

Base::~Base() {
    cout << "Base::~Base()" << endl;
}

Derived::Derived() : Base() {
    pBuf = new char[100];
    cout << "Derived::Derived()" << endl;
}

Derived::~Derived() {
    delete[] pBuf;
    cout << "Derived::~Derived()" << endl;
}

int main() {
    Base *pObject = new Derived();
    delete pObject;
    return 0;
}
```

输出:
Base::Base()
Derived::Derived()
Base::~Base()
```

实例化了一个派生类对象并将地址存储为指向其基类的指针：

注意，Derived 类的析构函数没有被调用。因此，内存泄漏者可能会导致缓冲区 pBuf 泄漏，因为它在 Derived 构造函数中分配。要修复这个问题，只需将 Base 类的析构函数声明为虚函数，如下：

```cpp
class Base {
public:
    Base();
    virtual ~Base();
};
```

修改后，程序输出将为：

```
Base::Base()
Derived::Derived()
Derived::~Derived()
Base::~Base()
```

现在 Derived 类的析构函数被调用，Derived::pBuf 被删除了。

# 结论

现在你已经看到了许多大学级 C++ 程序员用于实现内存泄漏的实用技巧。如果你使用上述策略，就不需要自己发明它们了。毕竟，代码复用是 C++ 的核心所在。一个提示：这些内存泄漏场景是由于对 C++ 的使用不当而可能产生的。它们并不是语言的固有属性。因此，当你的应用程序在地球另一端的客户处耗尽内存时，你可能无法成功地将责任归咎于 C++。
