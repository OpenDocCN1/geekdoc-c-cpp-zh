variable, you must do the following:

| Data Type | Default Value | Default Value |
|---|---|--|
| byte | float | 0.0 |
| byte | double | 0.00 |
| short | decimal | 0.0m |
| ushort | bool | false |
| int | char | \u0000 |
| uint | string | null |
| long | 0L | null |
| unsigned | | |

Variable declarations should be formatted as follows:

```
data_type name = initial_value;
```

Here are some samples of valid variable declarations:

```
int year = 2000;
```

```
string = yearname;
```

```
char = test;
```

It is important to end every C# statement with a semicolon. The results of your programs will be undesirable and/or unexpected if you forget to add a single semicolon.

The Value Assigning Process

A variable in C# can be assigned a value just like any other computer language. You must use the equals sign in this process called "value assignment". It is called the "assignment operator" by programmers. On the left side, write the name of the variable. On the right side, write the value you want to assign. See examples below:

```
test = x;
```

```
yourname = "John Doe";
```

How to Initialize a Variable

In coding, "initialization" refers to assigning a value to a variable.

When you declare a variable, you will set the "initial value".
