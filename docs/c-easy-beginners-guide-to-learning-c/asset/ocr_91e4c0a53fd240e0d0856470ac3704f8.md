There are different kinds of literals

The following literals are supported in C#:

+   - Real
- Integer
- String
- Character
- Boolean

The following literals will be discussed in detail:

Real

Real literals contain a sign (e.g., + or -), a prefix, a suffix, and a decimal point. Double, float, and decimal values should all be represented by this kind of literal. The real literal in C# is written as an exponent. You can apply the following suffixes to real literals: F - This suffix represents float values.

D – Double values are indicated with this suffix.

M – Decimal values are indicated by this letter.

E – Exponential values should be written in this manner. An integer multiplied by 104 is "e4".
