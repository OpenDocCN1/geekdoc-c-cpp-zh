# Real Type – Decimals

As these programs use decimal arithmetic to represent numbers, they support "decimal arithmetic". This approach has the advantage that it maintains its accuracy regardless of the value being used.

C# represents this kind of real number with the "decimal" data type. It is 128 bits long and accurate to the 29th decimal place. Programmers use these due to their excellent financial calculations (e.g., payments, taxes, interest, etc.).

# Integers

There are eight subtypes of this data type:

SBYTE - A signed 8-bit integer. Therefore, it has a 256-value maximum (i.e., 28). Sbytes can also be positive or negative.

BYTE - This subtype consists of unsigned 8-bit integers. It is almost the same as sbyte. A byte cannot be negative.

SHORT – These are 16-bit signed integers.

INT – The most popular C# data type. These data types are popular because they are compatible with 32-bit processors and are large enough for typical calculations. They are signed integers of 32 bits.

UINT – This is 32-bit unsigned integers. Thus, it must be positive.

LONG – This is a 64-bit integer. Whether it is positive or negative is important.

ULONG – Like "long" integers. However, "ulong" may only receive positive values.

# Strings

Strings are sets or sequences of characters. Whenever you declare values of this data type in C#, you must use the keyword "string" (i.e., a keyword). The "string" part must be enclosed in quotation marks. Various operations can be performed on strings using this language (e.g., concatenation, character replacement, character search, etc.).
