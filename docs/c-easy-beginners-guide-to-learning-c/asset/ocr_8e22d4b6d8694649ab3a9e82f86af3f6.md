Analyze the following example:

```
int a = 100;
if (a != 50)
{
    Console.WriteLine("The variable is not equal to 50");
}
else
{
    Console.WriteLine("The variable is equal to 50");
}
```

You can interpret this code as if a != 50, the console will print: "The variable is not equal to 50". On the other hand, if a = 50, the console will show: "The variable is equal to 50".
