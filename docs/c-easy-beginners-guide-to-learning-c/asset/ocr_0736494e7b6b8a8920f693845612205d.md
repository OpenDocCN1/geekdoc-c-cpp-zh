# Methods – The Basics

For most programmers, methods are core aspects of any program. Methods can solve problems, accept user inputs (known as parameters), and produce results.

Methods complete their tasks by representing the data conversions done by the program. Additionally, methods are the areas where the actual processes are completed. This is why C# programmers consider methods as the basic units of any computer program.
