# The Proper Formatting of Codes

Code formatting allows you to indent methods within class definitions. The Tab key on your keyboard can be used to format source codes in C# so that you can use any number of tab characters.

Within the method definition, you should indent its contents.

Under the class or method it belongs to, place an opening brace (i.e. {). As well, if it is the only character in the line, it will be the most effective. The closing brace (i.e. {) must be aligned vertically with the opening brace.

It is recommended that all class names begin with an uppercase letter.

It would be best if you named your variables in lowercase.

Your method names should start with an uppercase letter.

Codes written within another code are indented.
