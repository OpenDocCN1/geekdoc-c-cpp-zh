
# Variables

Changeable data can be stored, retrieved, and modified with variables. Variables are essential to the storage and processing of information as a programmer.

## What Characterizes Variables

The characteristics of a variable are:
- Name (also called "Identifier")

### Type of data

Store information of value (also called value). A variable is a name given to a section of computer memory. Values are stored and can be accessed by computer programs. Your computer's working memory (or stack) or dynamic memory is where variables can be stored.

Because their data resides within the program's stack, character types, booleans, and integers are called value types. By contrast, strings, arrays, and objects are termed "reference types" since they do not contain values. Rather, they serve as identifiers of the location of where the data is stored in computer memory.

## Choosing a Variable Name

Variables must be named before they can be used. Variable names serve as identifiers: they help the program locate and specify the variable. In C#, you have complete freedom in naming variables. In C#, you must follow some rules for naming variables as in any other language. Here are the rules:
- Underscore (i.e., "_"), letters, and numbers can be used to name variables.
- A number cannot be used to begin a name. In this case, FirstSample is valid, whereas 1Sample is not.
- You cannot name variables with C# keywords. You can prevent compilation errors with this simple rule. Using keywords for your variables is possible if you use the "@" symbol (e.g., @bool, @int, @char, etc.).

## Declaring variables

It is a good idea to declare variables before using them. In order to declare a variable, you must do the following:

- 1. Type the variable's data type (for example, char)
- 2. Specify the variable name (for example, sample).
- 3. Initialize the variable. Choosing this step is completely up to you.

| Data Type | Default Value | Default Value |
|---|---|---|
| byte | float | 0.0 |
| byte | double | 0.00 |
| short | decimal | 0.0m |
| ushort | bool | false |
| int | char | \u0000 |
| uint | string | null |
| long | 0L | null |
| unsigned | | |

Variable declarations should be formatted as follows:

```
data_type name = initial_value;
```

Here are some samples of valid variable declarations:

```
int year = 2000;
```

```
string yearname = "";
```

```
char test = 't';
```

It is important to end every C# statement with a semicolon. The results of your programs will be undesirable and/or unexpected if you forget to add a single semicolon.

## The Value Assigning Process

A variable in C# can be assigned a value just like any other computer language. You must use the equals sign in this process called "value assignment". It is called the "assignment operator" by programmers. On the left side, write the name of the variable. On the right side, write the value you want to assign. See examples below:

```
test = x;
```

```
yourname = "John Doe";
```

## How to Initialize a Variable

In coding, "initialization" refers to assigning a value to a variable.

When you declare a variable, you will set the "initial value".

The lines starting with a forward slash (i.e., //) are considered "comments". The purpose of comments in programming is to make the code easier to read. Language compilers ignore these lines. This means comments will not interfere with your program's functionality.

## Values and References

There are two types of C# data: value types and reference types.

In an executable program, a value type exists. In addition, the value type contains the value entered by the programmer. Booleans, Characters, and Integers comprise value types. By contrast, strings, arrays, and objects are termed "reference types" since they do not contain values. Rather, they serve as identifiers of the location of where the data is stored in computer memory.
