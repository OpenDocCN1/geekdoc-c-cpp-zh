The Switch-Case Statement\Programmers use a switch-case statement in situations where the possible answers are numerous. Here is the syntax of a switch-case statement:

```
switch (selector)
{
    case first_integer:
        statements;
        break;
    case second_integer:
        statements;
        break;
    default:
        statements;
        break;
}
```
