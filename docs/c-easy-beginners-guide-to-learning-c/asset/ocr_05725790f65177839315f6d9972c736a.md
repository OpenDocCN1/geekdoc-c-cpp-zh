# Method Declarations

In C#, you need to declare methods inside a class. Additionally, you are not allowed to

"nest" methods (i.e., write a method inside the body of another method). The perfect example for this is Main(), the method you have used multiple times. The code given below will illustrate this:

```
class DeclaringMethods
{
  static void Main()
{
    System.Console.WriteLine("Hi C#!");
  }
}
```
