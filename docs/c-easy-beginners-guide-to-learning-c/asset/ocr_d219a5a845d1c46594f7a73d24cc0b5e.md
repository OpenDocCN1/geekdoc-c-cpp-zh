"&&" – This operator is called "Logical AND" by programmers. When both operands are true, it will give you "true".

"||\ – It is called the "Logical OR" operator. When both operands are true, you will get true.

"!" – By using this "Logical Negation" operator, an operand is reversed.

You can use these operators in the code:

![](bbox=[0.118, 0.317, 0.158, 0.367])

```
class Test
{
  static void Main()
{
    bool x = true, y = false;

    System.Console.WriteLine(x && y);
    System.Console.WriteLine(x || y);
    System.Console.WriteLine(!x);
    System.Console.WriteLine(x ^ y);

    // A good example is shown here.
  }
}
```

After compiling and running this code, the following results will be displayed: Arithmetic Operators
