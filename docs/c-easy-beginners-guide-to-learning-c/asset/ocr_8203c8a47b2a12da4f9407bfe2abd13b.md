# Console.Read Method

Console.Read and Console.ReadLine differs significantly. First of all, Console.Read only reads a single character, whereas Console.ReadLine reads the entire expression. Secondly, Console.Read does not return the accepted input but rather a code. The output can be utilized as an ordinary character if you do any of the following: Convert the output to a character

Convert the result to a character using Convert.ToChar

Note: The user must press "Enter" to make Constant.Read read a character. The program will transfer the input to the standard string's buffer and invoke the console upon pressing this key.Read method.

See the example below:

```
class UsingRead
    static void Main()
    {
        int codeRead = 0;
        do
        {
            codeRead = Console.Read();
            if (codeRead != 0)
            {
                Console.Write((char)codeRead);
            }
        } while (codeRead != 10);
    }
```

# How to Read a Number

C# programs do not directly read numbers. By using the console.ReadLine method, the inputs needs to be converted into numbers. It is known as parsing to convert strings to different data types. In the C# language, this is supported by all primitive data types.
