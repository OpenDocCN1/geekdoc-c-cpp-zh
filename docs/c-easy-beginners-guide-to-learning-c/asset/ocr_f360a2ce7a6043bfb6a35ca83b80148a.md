# C# Programming Requires These Things

You need two things to write programs in C#-a text editor (e.g., Notepad) and
the .NET framework. Text editors make it easy to write and edit code. On
the other hand, you will compile and execute your programs with the .NET
framework.

The .NET framework is what?

As a framework, .NET is used to create and run programs. .NET is a built-
framework for almost all Windows systems.

In this case, Microsoft's modern operating systems will allow you to use your
computer without installing any software.

Installing the .NET framework is required on old Windows operating
systems.

```
HelloCSharp.cs
class HelloCSharp
{
    static void Main()
{
        Console.WriteLine("Hello C#!");
    }
}
```

Before reading the rest of this book, please make sure your computer has
.NET installed. You will not be able to compile and run the sample programs
later if you do not have these prerequisites.

# The Text Editor

For writing, editing, and saving source codes, you should use a text editor.
Almost every computer comes a text editor installed. If you do not want
to download additional programs, it is possible to use "Notepad" (the default
text editor of a Windows computer).
