Different types of data can be displayed on the user's screen using the Console.WriteLine method. Each data type is built into the Console class.

In contrast to console.WriteLine, the latter simply displays the information inside the parentheses where the former prints the value inside the parentheses and adds a newline character. The use of a console.WriteLine in your code is analogous to hitting the "Enter" key after showing the message (i.e., The cursor will move to the next line).
