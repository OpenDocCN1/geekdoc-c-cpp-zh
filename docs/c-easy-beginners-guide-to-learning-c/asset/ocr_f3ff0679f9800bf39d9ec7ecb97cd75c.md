0X (e.g., 0XA6F2) – This prefix can indicate a hexadecimal value.

U (e.g., 119U) – Associated with unsigned integer (uint) and unsigned long (ulong) values.

L (e.g., 360L) – This suffix indicates that the value is "long".

The integer literal will be tagged as an "int" in C# if there is no suffix on the literal. There is no case difference between the letters L, U, and X.

# String

String values should be represented by this literal. On the other hand, literals are characters enclosed in a pair of double quotes (e.g., "sample").

It is important to note that you can create quoted (or verbatim) strings in C# by using the "@" symbol. Programmers commonly use such strings to name files.
