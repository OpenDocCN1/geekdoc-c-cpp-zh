# # C# Conditional Statements

You will learn how conditional statements work in C# in this chapter. Conditions are code blocks that allow you to perform a series of actions based on conditions. This guide will help you learn C# in just seven days if you read it carefully.

# ## Operators

C# comparison operators are discussed in this section. You can use these operators to set conditions for your conditional statements.

The Comparison Operators

To compare values of the same type in C#, you can use different operators. Here are some examples:

+   <

+   >

+   <=

+   >=

+   !=

+   ==

In addition to these operators, you may also use the following to compare C# expressions (e.g., two integers, two variables, two constants, etc.). Each of these operators will always return a Boolean value. Examine the following examples:

```
int height = 170;
Console.WriteLine(height < 180); // This will give you “true”.
```

```
string gender = "Male";
Console.WriteLine(gender == "Female"); // This will give you “false".
```
