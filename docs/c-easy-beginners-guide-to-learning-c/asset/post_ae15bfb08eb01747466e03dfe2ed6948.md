The syntax given above consists of the following parts:

- The conditional statement's body – This can be a single statement or group of statements. If you are using multiple statements, enclose them inside a pair of curly braces.
- The "else" keyword is a C# keyword that triggers the "else" clause.
- The else clause's body is identical to the conditional statement's body (see above).

When working on an if-else statement, the computer program analyzes the value within the parentheses. The value needs to be Boolean (i.e., either true or false).

If "true", the program will execute the conditional statement's body and ignore the "else" clause. If the value is false, however, the program will run the else statement's body.

## Nested Statements

In some cases, you need to write an "if" statement inside another "if" statement. Programmers refer to this process as "nesting". That means you are "nesting" a conditional statement by writing it inside another conditional statement clause points to the "if" clause that comes before it. This simple rule can help you analyze nested statements, which can be extremely complex. According to experts, you should not create more than three levels of nested statements. If you need to use four or more conditional structures, export them to a different method. The code given below will show how nested "if" statements work:

```csharp
int a = 10;
int b = 20;

if (a > b)
{
    Console.WriteLine("a is greater than b");
}
else
{
    if (a < b)
    {
        Console.WriteLine("a is less than b");
    }
    else
    {
        Console.WriteLine("a is equal to b");
    }
}
```

## Switch-Case Statement

Programmers use a switch-case statement in situations where possible answers are numerous. Here is the syntax of a switch-case:

```csharp
switch (selector)
{
    case first_integer:
        statements;
        break;
    case second_integer:
        statements;
        break;
    default:
        statements;
        break;
}
```

Selectors are expressions that return usable values (i.e., values you can compare). The "switch" keyword compares the selector's value against the "cases". If the value of the selector matches a case, the statements assigned to that case run. However, if there is no match, the program will execute the default statement. Important Note: Make sure that cases have unique values. If two or more cases share the same value, your program will produce undesirable results. As you can see, each case has a "break" clause which terminates the body of the case to which it belongs. C# requires you to add this "break" clause to the end of your switch-case statement if you want to keep your codes readable.

## While Loop

This is the simplest loop statement in C#. Its syntax is:

```csharp
while (assigned_condition)
{
  loop_body;
}
```

In this syntax, "assigned_condition" is an expression that produces a Boolean value. This condition dictates how many times the "body" will run. The "body", on the other hand, is the statement (or group of statements) that you want to execute. The diagram given below will illustrate how loops work:

When working on a "while" loop, a C# program checks the value of the Boolean expression. If the value is "true", the program will run all the statements within the loop's body. Then, the program will check the expression to see its value. If the value is true, the program will rerun the loop's body and go back to the first step (i.e., the expression's value). This process will go on until the Boolean expression evaluates to false. Once this happens, the program will process the code blocks after the loop. Important Note: Your C# program will not run the while loop's body if the Boolean expression is false. Thus, your loop statements will never be executed if the Boolean value is false when you launched the program.

The following example will illustrate how loops work:

```csharp
int timer = 10;

while (timer >= 0)
{
    System.Console.WriteLine("Time remaining: " + timer);
    timer--;
}
```

## The Break Operator

You can use "break" (a C# operator) to exit a loop prematurely. Programmers use this operator if they do not want to wait for the loop's natural termination. A loop will end once it encounters a break operator. This situation forces the program to jump to the code fragments after the loop. In C#, you can only use this operator inside the loop's body. That "break" will only work while the loop is running.

## Do-While Loop

A do-while loop is almost identical to a while loop. The only difference between these loops are that the former analyzes the Boolean value after running the loop's body. Thus, you can rest assured that your codes will run at least once, even if the Boolean expression is false. Here is the syntax of the do-while loop:

```csharp
do
{
  statements;
} while (Boolean expression)
```

If the condition evaluates to true, the program will execute the loop's body again and perform the "value inspection". This process will go on until the condition becomes false. Thus, your codes might run forever if your assigned condition always evaluates to true.
