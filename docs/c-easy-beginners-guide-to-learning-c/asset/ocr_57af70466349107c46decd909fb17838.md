Operators that operate on binary numbers are called binary operators. All information in the IT world is represented as a sequence of zeroes and ones. This means that if you wish to become a successful programmer, you must master binary operators.

Binary operators function similarly to logical operators. Although binary and logical operators utilize different inputs, they perform the same operations. When using a logical operator, Boolean values are used to determine the result. Binary operators, on the other hand, work with numbers expressed as binary digits. The following are examples of binary operators you will encounter while working with C#:

"&" - This is known as "Binary AND". Both operands must have "1" at the same position/s.

"^" - This operator is sometimes called "Binary Exclusive OR". Where two values differ, it places a "1" there.

The binary operator "OR" is represented by this "|" symbol. It indicates which operand/s have "1".

"~" - Binary values are negated by this operator. The value of a variable is reversed just like "!".

"<<" - The operator is called "Binary Left Shift". A binary number is shifted left by this operation. You should assign a value to this movement (e.g., 4 << 3, 4 << 2, etc.).
