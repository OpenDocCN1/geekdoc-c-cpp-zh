Using the console commands

You can change the active directory by using the command cd name_of_directory.

The following command will take you to the Users folder in C::

cd:\Users

dir – This command allows you to view the files contained in an active directory.

rmdir name_of_directory – You can delete a directory using this command. The command rmdir Sample, for example, deletes all files within the directory named "Sample".

mkdir name_of_directory – It allows you to create a new directory in the active directory. When you run mkdir John inside the Users directory, a folder named "John" will be created.

type_name_of_file – The contents of an existing file can be viewed by using this command. To see what is inside a .cs file, you might type "type HelloCSharp.cs".

# Standard I/O

For UNIX computers, Standard I/O is a mechanism. Special devices handle input and output.

A cursor will appear on the console when a program waits for the user to provide information. When this happens, the system is in "waiting mode".
