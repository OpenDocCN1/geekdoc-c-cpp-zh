# The Conversion of Data Types

It is generally the case that operators work with similar types of arguments. However, the C# language gives you a wide range of data types to use for various situations. Whenever you operate on variables that have different types, you must convert one of those variables first. You can do this implicitly or explicitly in C#.

The conversion of "objects" to "strings" will need to be verified during program execution. By doing so, you ensure the values should be used as strings.

Validation of "string" values is not necessary when converting to "object" values. That is because the "string" type is one of the "object" types. It is possible to convert strings to their "parent" classes without losing data or getting errors.

When you convert int to long values, you will not have to perform any verification.

All possible values of the "int" type can be represented in the "long" data type. Data transformations cannot produce errors because of this.

A "double" value is converted to a "long" value using validation. Your data may be lost, depending on the values you are working with.
