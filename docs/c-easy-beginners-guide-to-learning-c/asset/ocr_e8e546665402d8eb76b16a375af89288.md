# Type of data

Store information of value (also called value). A variable is a name given to a section of computer memory. Values are stored and can be accessed by computer programs. Your computer's working memory (or stack) or dynamic memory is where variables can be stored.

Because their data resides within the program's stack, character types, booleans, and integers are called value types. By contrast, strings, arrays, and objects are termed "reference types" since they do not contain values. Rather, they serve as identifiers of the location of where the data is stored in computer memory.

# Choosing a Variable Name

Variables must be named before they can be used. Variable names serve as identifiers: they help the program locate and specify the variable. In C#, you have complete freedom in naming variables. In C#, you must follow some rules for naming variables as in any other language. Here are the rules:
 underscore (i.e., "_\_"), letters, and numbers can be used to name variables.
A number cannot be used to begin a name. In this case, FirstSample is valid, whereas 1Sample is not.

You cannot name variables with C# keywords. You can prevent compilation errors with this simple rule. Using keywords for your variables is possible if you use the "@" symbol (e.g., @bool, @int, @char, etc.).
