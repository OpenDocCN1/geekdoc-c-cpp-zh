# # C# Language Operators

The operators of C# will be discussed in this chapter. You will learn how these operators work and use them in your source codes by reading this material.

# ## Basics of Operators

Operators process objects and data types. Operands and inputs are processed to produce results. Special characters (such as "", \+", "*", etc.) are used as operators in C#. It is also possible to execute the C# code with three different operands.

# ## Operators of Different Types

According to C# programmers, there are three types of operators:

Assignment Operator

C# requires an equals sign (i.e., =) for assigning values. To assign a value, you need to use the following syntax:

```
name_of_operand = expression, literal, or second_operand
```

Several examples are given below:

Using the assignment operator cascades (using the operator multiple times within one expression) in C#. Therefore, if you create multiple variables of the same data type, you will not enter multiple equal signs. Here are some examples:

```
int d = 1, e = 2, f = 3;
string hi = "Good Morning.", bye = "Farewell.", thanks = "Thank you.";
```
