# Write Code by Remembering These Rules

C# – Case-sensitive programming language

The case is essential in this language. When typing C# code, you must be careful to capitalize all letters. The three objects "power," "power," and POWER in C# are considered separately.

Note: This rule is essential to remember. All C# program elements (e.g., variables, constants, classes, etc.) must follow this rule.

Format your document correctly

If you want your code to be more readable, you should add tabs, spaces, and newlines. Your source codes will be much more structured if you use these characters, which are not interpreted by the C# compiler.

The HelloCSharp code: for example, might benefit from having the newlines removed. An alternative might be to remove the tab characters.
