Programmers refer to these data types as "primitive types" since they are built into the C# programming language. Let us look at each type individually:

# Boolean

Declaring this type of data in C# requires the keyword "bool" (i.e., a keyword). As a boolean value, a value can either be "true" or "false". By default, Boolean values in C# are set to "false". Logic statements are stored in this data type by programmers.

# Characters

Single characters can be stored in this data type. You must use "char" (i.e., another C# keyword) to declare this type. Use apostrophes to separate your "char" values (e.g., "I'").

# Objects

Data in C# is classified as objects by programmers. A .NET object is essentially the parent of other data types. The "object" keyword is required during the declaration of this data type, which may accept any value from other data types.

A computer object is an address that points to a location in your computer's memory.
