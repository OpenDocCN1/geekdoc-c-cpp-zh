
# Console.Read Method

Console.Read and Console.ReadLine differs significantly. First of all, Console.Read only reads a single character, whereas Console.ReadLine reads the entire expression. Secondly, Console.Read does not return the accepted input but rather a code. The output can be utilized as an ordinary character if you do any of the following:

- Convert the output to a character
- Convert the result to a character using Convert.ToChar

Note: The user must press "Enter" to make Console.Read read a character. The program will transfer the input to the standard string's buffer and invoke the console upon pressing this key method.

See the example below:

```csharp
class UsingRead
    static void Main()
    {
        int codeRead = 0;
        do
        {
            codeRead = Console.Read();
            if (codeRead != 0)
            {
                Console.Write((char)codeRead);
            }
        } while (codeRead != 10);
    }
}
```

# String Concatenation

C# prohibits programmers from operating on strings.

You cannot perform arithmetic operations on actual words (e.g., fish - dog, power * humans, land/people, etc.). C#, however, allows you to concatenate (i.e., combine) multiple string objects. Use the "+" symbol to add to your strings. The following example explains how to do this.

```csharp
string gadget = "smartphone";
string example = "I use my " + gadget + "to access " + "the internet.";
Console.WriteLine(example);
```

If you execute that code, the console will display this:

I use my smartphone to access the internet.

# The Logical Operators

There are some logical operators in C#. Programmers use these operators to construct Boolean (also known as "logical") statements. Listed below are the logical operators in detail:

### The AND and OR Operators

You can only use the logical AND (i.e., &&) & logical OR (i.e., ||) operators on expressions that involve Boolean values. The logical AND operator will give you “true" if both of the operands are true. For example:

```csharp
bool sample = (1 < 2) && (10 == 10);
```

The expression will be true because one is less than 2, and 10 is equal to 10. Programmers refer to the logical AND operator as a "short-circuit operator" since it produces quick results without performing unnecessary analyses. This evaluation ends immediately if it is false. Due to the false operand, the expression can no longer be true.

The logical OR (i.e., ||) operator, on the other hand, will give you true if at least one of your operands evaluates to true. For instance:

```csharp
bool sample = (1 < 2) || (10 == 10);
```

The expression will be true because one is less than 2, or 10 is equal to 10. Programmers refer to the logical OR operator as a "short-circuit operator" since it produces quick results without performing unnecessary analyses. This evaluation ends immediately if it is true. Due to the true operand, the expression can no longer be false.

# The XOR and Negation Operators

The XOR operator (i.e., ^) returns true only if exactly one of the operands is true. If both are true or both are false, it returns false. This is used when you want two conditions to differ. For instance:

```csharp
bool sample = (1 < 2) ^ (10 == 10);
```

The expression will be false because both operands are true.

The negation operator (i.e., !) reverses the Boolean value to which it is attached. For instance:

```csharp
bool sample = !(1 < 2);
```

The expression will be false because one is less than two.

# The If Statement

The syntax of an if statement is:

```csharp
if (the conditional expression)
{
  The statement's body;
}
```

As you can see, this syntax has three different parts:

- The "if" clause – This part indicates the start of the "if" statement.
- The Boolean expression – This part can hold a logical expression or a variable that holds Boolean data. Unlike C, C# does not accept integer expressions for its conditional statements.
- The statement's body – You need to enclose this part using a pair of curly braces. C# allows you to place multiple statements inside this section.

The program will run the statement's body if the Boolean expression evaluates to true. If the evaluation is false, the program will ignore the statement's body and control the next code blocks. The example below will show you how statements work:

```csharp
Console.WriteLine("Please enter a number.");
int number1 = int.Parse(Console.ReadLine());

int number2 = 0;
if (number1 > number2)
{
    Console.WriteLine("C# is an excellent programming language.");
}
```

This code requires the user to provide a number. If the user's input is higher than zero, the program will print "C# is an excellent programming language." in the command prompt.

Important Note: You may omit the curly braces if the body of your conditional statement is just a single line. Check the example below:

```csharp
int x = 10;
if (x > 0)
    System.Console.WriteLine("This variable holds a positive number.");
```
