### What is the Process?

There are three parts to this sample program:

- 1. The definition of the class;

This program starts by defining a class called HelloCSharp in the first line. Class definitions are usually divided into two sections: (1) the name of the class and (2) its description. On the third line of the program, you will find the method definition. This is the Main() method. Every C# program starts with this() method. It would be best if you use the following syntax:

```csharp
class HelloCSharp{static void Main()}{System.Console.WriteLine("Hello C#!");}

    static void Main(){
        System.Console.WriteLine("Hello C#!");
    }
}
```

Putting in the Main() method incorrectly will cause your program to crash.

## Write Code by Remembering These Rules

### C# – Case-sensitive programming language

The case is essential in this language. When typing C# code, you must be careful to capitalize all letters. The three objects "power," "power," and POWER in C# are considered separately.

Note: This rule is essential to remember. All C# program elements (e.g., variables, constants, classes, etc.) must follow this rule.

### Format your document correctly

If you want your code to be more readable, you should add tabs, spaces, and newlines. Your source codes will be much more structured if you use these characters, which are not interpreted by the C# compiler.

The HelloCSharp code: for example, might benefit from having the newlines removed. An alternative might be to remove the tab characters.

In terms of compiling and executing the last two examples, everything works fine.

The complexity of an analyzable, modifiable, understandable, and maintainable script is high.

It would be best if you formatted your codes in all of your programs. That way, you can guarantee that your codes are readable.

## The Proper Formatting of Codes

Code formatting allows you to indent methods within class definitions. The Tab key on your keyboard can be used to format source codes in C# so that you can use any number of characters.

Within the method definition, you should indent its contents.

## Types of Classes

Each C# program consists of at least one class definition. In programming, class definitions are typically inside separate files corresponding to the class names. File extensions should also include ".cs".

## C#: Additional Information

C# is an advanced, modern, multipurpose, and object-oriented language. The language is similar in many ways to C, C++, and Java. C# offers a simplified syntax and more accessible.

Data types and class definitions are contained in one or more .cs files. To generate executable code (i.e. files ending in .dll or .exe), these .cs files need to be compiled.

## C# Programming Requires These Things

You need two things to write programs in C#-a text editor (e.g., Notepad) and the .NET framework. Text editors make it easy to write and edit code. On the other hand, you will compile and execute your programs with the .NET framework.

### The .NET framework is what?

As a framework, .NET is used to create and run programs. .NET is a built-framework for all Windows systems.

In this case, Microsoft's modern operating systems will allow you to use your computer without installing any software.

Installing the .NET framework is required on old Windows operating systems.

For writing, editing, and saving source codes, you should use a text editor. Almost every computer comes a text editor installed. If you do not want to download additional programs, it is possible to use "Notepad" (the default text editor of a Windows computer).
