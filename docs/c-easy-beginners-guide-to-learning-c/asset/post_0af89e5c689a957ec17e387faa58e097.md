
"&&" – This operator is called "Logical AND" by programmers. When both operands are true, it will give you "true".

"||" – It is called the "Logical OR" operator. When both operands are true, you will get true.

"!" – By using this "Logical Negation" operator, an operand is reversed.

You can perform math operations using these operators. The following operators are included in this category:

- "+" - This operator can be used to add two values (e.g. int x = 1 + 1)

In your code, you can use the "-" operator to do subtraction. It subtracts the value of the right operand from the left operand (for example, int x = 2 - 1)

- "*" The "*" operator allows you to multiply two operands (for example, int r = 6 * 6)

In C#, you can divide numbers using the "/" operator. The "/" operator divides the left-hand operand by the right-hand operand.

The increment operator "++" is called the "increment operator". By using this operator, an operand is incremented by one. These operators work on only one operand, as opposed to the ones discussed above. The operator may also be written before or after the operand. (For example, 99++, 1++, ++5, etc.)

A "-" operator is the exact opposite of an increment symbol. It decreases the value of the operand by one. It can be written before or after the operand being modified.

```csharp
int a = 5;
int b = 5;
int c = 10;
```

Operators that operate on binary numbers are called binary operators. All information in the IT world is represented as a sequence of zeroes and ones. This means that if you wish to become a successful programmer, you must master binary operators.

Binary operators function similarly to logical operators. Although binary and logical operators utilize different inputs, they perform the same operations. When using a logical operator, Boolean values are used to determine the result. Binary operators, on the other hand, work with numbers expressed as binary digits. The following are examples of binary operators you will encounter while working with C#:

- "&" - This is known as "Binary AND". Both operands must have "1" at the same position/s.

- "^" - This operator is sometimes called "Binary Exclusive OR". Where two values differ, it places a "1" there.

- The binary operator "OR" is represented by this "|" symbol. It indicates which operand/s have "1".

- "~" - Binary values are negated by this operator. The value of a variable is reversed just like "!".

- "<<" - The operator is called "Binary Left Shift". A binary number is shifted left by this operation. You should assign a value to this movement (e.g., 4 << 3, 4 << 2, etc.).

## Comparison Operators

These operators allow you to compare the values inside two operands. Each of these operators gives a Boolean value as the final output. Here are the comparison operators of the C# language:

- "===" – This is the Equality operator. It checks whether the two operands are equal (e.g., x == y)

- ">" – This operator checks whether the left-operand's value is greater than that of the right-hand operand (e.g., x > y)

- "<" – This operator compares the values of the two operands. It will give you "true" if the left-operand's value is less than that of the right-hand operand (e.g., y < x).

- ">=" – With this operator, you can determine whether the value of the left-hand operand is greater than or equal to that of the right-hand operand.

- "<=" – This operator will give you true if the value of the left-hand operand is less than or equal to that of the right-hand operand.

- "!=" Use this operator to check the equality of two operands. If the values are not equal (e.g., x != y).

## Conditional Operator

C# users refer to "?" as the conditional operator. This operator uses the result of a Boolean expression to determine which states should be processed. This is called the "ternary operator" because it works on three operands.

The syntax of this operator is:

```csharp
first_operand ? second_operand : third_operand;
```

Here is how it works: If "first_operand" is true, the program will return "second_operand". If "first_operand" is false, the program will return "third_operand".

## The Conversion of Data Types

It is generally the case that work with similar types. However, the C# language gives you wide range of data types. Whenever you operate on different types, you must convert one first. You can do this implicitly or explicitly.

There are some restrictions regarding the changing of data types in C#. The language supports the following type conversions:

### Explicit Conversion

If there is a risk of information loss, use this conversion. The fractional portion of floating-point values will disappear when you convert them to integer values (i.e., you will lose information). The conversion of a wide-range type to a narrow-range type may also result in data loss (e.g., long to int, double to float, etc.). You can complete the conversion by using the "type" operator. See the examples below:

```csharp
class Example
{
    double yourDouble = 2.1d;
    System.Console.WriteLine(yourDouble);

    long yourLong = (long)yourDouble;
    System.Console.WriteLine(yourLong);

    yourDouble = 2e9d;
    System.Console.WriteLine(yourDouble);

    int yourInt = (int)yourDouble;
    System.Console.WriteLine(yourInt);
}
```
