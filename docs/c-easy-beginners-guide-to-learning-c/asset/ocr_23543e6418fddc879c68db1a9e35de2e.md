# I/O Devices

Some programs accept Non-keyboard input. Creating programs in C# that use text files, barcode readers, microphones, and other data input sources are possible. Programs can also send their output to a screen, a hard drive, or a printer.

# System.Console

Text-based information can be read, displayed, or formatted using the system.Console class. Data entry and data visualization are three of the most popular attributes of the system.Console class. Console.In, Console.Out, Console.Error are these attributes.

Data display, information reading, and error reporting are made possible by these attributes. They can be directly used in C#. There are other methods and attributes in the system.Console that has the potential to assist you in I/O operations.

Note: Program streams can be modified in the C# language. Use the following methods to do this: Console.SetOut (for the Output stream), Console.SetIn (for the Input stream), and console.SetError (for the Error stream).

# Console Input

Computers have a console for entering information when programming languages are used.

For example, the C# language uses "Console.In" to control its input stream.
Using Console.In directly is not necessary. There are two methods in the Console class (i.e., Console.ReadLine and Console.Read) that work with Console.In. These methods allow you to read data from your command prompt.
