The following example will illustrate how loops work:

```
int timer = 10;

while (timer >= 0)
{
    System.Console.WriteLine("Time remaining: " + timer);

    timer--;
}
```

If you compile and execute this code, your command prompt will print this data: **The Break Operator**

You can use "break" (a C# operator) to exit a loop prematurely. Programmers use this operator if they do not want to wait for the loop's natural termination. A loop will end once once it encounters a break operator. This situation forces the program to jump to the code fragments right after the loop.

In C#, you can only use this operator inside the loop's body. That "break" will only work while the loop is running.
