# Values and References

There are two types of C# data: value types and reference types.

In an executable program, a value type exists. In addition, the value type contains the value entered by the programmer. Booleans, Characters, and Integers comprise the Value Type category. After a program has completed executing its code, the memory assigned to these types will become available. When you close your program, the variables in the Main() method will be emptied.

Alternatively, a reference type stores an address in the program's stack (i.e., a reference). It points to a value located somewhere on the stack. Reference types essentially assign dynamic memory while they are declared. When the program no longer needs them, they free up some memory.
