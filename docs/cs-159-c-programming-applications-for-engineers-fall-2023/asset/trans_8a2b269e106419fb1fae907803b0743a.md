## 以下程序用于第 #1–#2 题

```c
#include <stdio.h>
int makeCalc(int, int);
int main()
{
  int n = 4;
  int a;
  int result = 1;
  while(n > 2)
  {
    a = n--;
    result = makeCalc(a, result);
  }
  printf("result: %d\n", result);
  printf("a: %d n: %d\n", a, n);
  return(0);
}

int makeCalc(int a, int result)
{
  do
  {
    result *= a--;
  }while(a > 1);
  return(result);
}
```

- 1. 以上程序生成的第一行输出是以下哪项？
  - A) result: 24
  - B) result: 144
  - C) result: 288
  - D) 以上皆非。

- 2. 以上程序生成的第二行输出是以下哪项？
  - A) a: 2 n: 1
  - B) a: 2 n: 2
  - C) a: 1 n: 1
  - D) 以上皆非。

- 3. 以下哪项陈述表明程序员为给定的重复过程选择了错误的循环结构？
  - A) 代码在 while 循环之前和内部立即重复。
  - B) 循环控制变量被初始化为导致循环控制表达式求值为真的值；该值随后立即被丢弃。
  - C) for 循环未包含所有三个表达式。
  - D) 以上皆是。
