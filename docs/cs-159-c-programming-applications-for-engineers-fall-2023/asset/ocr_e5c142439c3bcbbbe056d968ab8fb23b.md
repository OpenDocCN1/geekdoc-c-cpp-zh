# The Structure of a C Program

Special instructions to the preprocessor that tell it how to prepare your program for compilation.

Declaration of "objects" that will be visible (usable) to all parts of the program.

**Course Standard:** Variables will **NEVER** be acceptable as global.

The final section represent the functions. A C program is made up of one or more functions, one of which must be named `main`.

**Course Standard:** The two sections of a function **MUST** not overlap!

Additional functions will be introduced in chapter 4.
