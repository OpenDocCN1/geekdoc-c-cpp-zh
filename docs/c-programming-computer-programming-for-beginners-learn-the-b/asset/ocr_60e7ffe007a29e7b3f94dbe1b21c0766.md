# Declaring an Interface

An interface can be declared with the interface keyword. In fact, it has similarities with the declaration of a class. By default, the interface statements will be public. The following example demonstrates how an interface is declared.

```
public interface ITransactions
{
	// interface members
	void showTransaction();
	double getAmount();
}
```
