# Understanding the Null Coalescing Operator (??)

This is a special operator that is used with nullable reference types and value types. The operator can be used for the conversion of an operand to the datatype of a different nullable value type operand as long as the implicit conversion is feasible. When the first operand’s value is null, the operator will return the second operand’s value. Otherwise, the first operand’s value will be returned.
