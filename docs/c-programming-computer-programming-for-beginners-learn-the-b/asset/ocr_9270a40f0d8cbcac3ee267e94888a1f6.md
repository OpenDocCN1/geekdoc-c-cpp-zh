# Assigning Values to the Array

It is possible to assign values to individual elements of the array. In order to do so, the index number of the element needs to be used. The following example illustrates this.

```
double[] balance = new double[10];
```

```
balance[0] = 4500.0;
```

Values can also be assigned to the array when it is being declared.

```
double[] balance = { 2340.0, 4523.69, 3421.0 };
```

It is also possible to create and initialize the array at the same time.

```
int [] marks = new int[5] { 99, 98, 92, 97, 95 };
```

If you want, you can exclude the array’s size.

```
int [] marks = new int[] { 99, 98, 92, 97, 95 };
```
