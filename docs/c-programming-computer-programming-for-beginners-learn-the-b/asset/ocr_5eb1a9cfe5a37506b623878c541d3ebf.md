# Declaring Arrays

In C#, if you wish to declare an array, you will have to make use of the following syntax.

```
datatype[] arrayName;
```

Each of the elements the syntax has been discussed as follows.

+   - the datatype is used in order to specify the datatype of the elements that will be present in the array.
+   - [] specifies the array’s rank. The rank of an array defines the size of the array.
+   - arrayName is the name of this array.
