# The Common Data Types

There are a wide variety of data types used in C#. Of course, some of them will be used more often than other when you start programming in earnest. As a result, it will benefit you greatly if you start learning about the most widely used data types. Here are some of them to help you get started.

**Bool:** This is one of simplest data types available as it represents Boolean value. As such, it can have only two values, either true or false. It is important to understand this type, especially when using logical operators such as the ‘if’ statement. By default, its value is false.

**Byte:** This data type represents an 8-bit integer that is unsigned. It has a range of 0 to 255 when it comes to storing numbers. By default, the value of this data type is 0.
