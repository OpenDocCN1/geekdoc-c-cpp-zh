### 接口简介

接口可以定义为一种语法契约，所有继承该接口的类都必须遵循它。接口定义契约的“什么”部分。派生类将定义语法契约的“如何”部分。

接口将定义作为其成员的方法、属性和事件。另一点需要注意的是，接口只包含成员的声明。定义成员的责任交给派生类。因此，它确保了存在一个可供派生类遵循的标准结构。
