```
{
    Int number = 0;
    do
    {
        Console.WriteLine(number);
        number = number + 1;
    } while (number < 10)
    Console.ReadLine();
}
}
```

On running this program, you will see the numbers being displayed from 0 to 9. Once the number becomes 10 or more than 10, the program will exit the loop sequence. As you can see, the do loop functions in a similar manner to the while loop but checks the condition after the execution of a sequence.
