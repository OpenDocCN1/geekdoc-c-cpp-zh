The condition will only be true when the number is less than 10. Once the number becomes 10, the condition becomes false. After all, ten is not less than 10. As you can see, the condition of the while loop is checked before the program enters the loop sequence. Once the number turns 10, the condition becomes false, and the while loop sequence is not executed.
