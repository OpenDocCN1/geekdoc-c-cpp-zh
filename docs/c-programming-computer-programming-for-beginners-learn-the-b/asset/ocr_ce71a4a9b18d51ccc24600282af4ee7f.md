```
Int number = 0;
while (number < 10)
{
    Console.WriteLine (number);
    number = number + 1;
}
    Console.ReadLine ();
}
}
}
```

When you run this code, you will find that the program lists a sequence of numbers in the console starting at 0 and ending at 10.

Of course, the variable number is first defined as 0. Every time the loop is executed, the variable is incremented by 1. You can see this happening in this statement:

```
number = number + 1
```
