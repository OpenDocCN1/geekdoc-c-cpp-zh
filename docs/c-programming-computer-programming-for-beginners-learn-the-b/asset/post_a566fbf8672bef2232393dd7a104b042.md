## How to Pass Parameters to a Method?

If you call a method that has parameters, the parameters will have to be passed to the method. There are three ways that you can pass parameters to a method. We will take a look at each of them in turn.

Passing the parameters by their value is the default mechanism when parameters need to be passed to a method. In this case, a new storage location will be created for each of the value parameters when the method is called. Then, the values of the original parameters will be copied into them. Any changes made to the parameter while inside the method is not going to affect the argument.

Take a look at the example given below.

```
using System;

            int temp;

            temp = x; /* save the value of x */
            x = y;   /* put y into x */
            y = temp; /* put temp into y */
        }
        static void Main(string[] args)
        {
```
