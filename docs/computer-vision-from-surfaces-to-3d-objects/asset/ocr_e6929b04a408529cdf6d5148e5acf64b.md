# Surface Matching

Given two surfaces \(S_1,S_2\) embedded in \(\mathbb{R}^3\), we want to find a good matching \(f:S_1\to S_2\), which minimizes the distortion between them. It is generally difficult to match the surfaces directly in \(\mathbb{R}^3\). As shown in Figure 4.13, we compute two conformal mappings \(\phi_i:S_i\to\mathbb{D}, i=1,2\), \(\mathbb{D}\) is the canonical unit disk. Then we can find a mapping \(\bar f:\mathbb{D}\to\mathbb{D}\), which induces \(f\):

\[f = \phi_2^{-1} \circ \bar f \circ \phi_1 \tag{4.39}\]
