# ▶ Listing 6: Creating an Array in the Structure

```
```cpp
#include <iostream.h>

struct ArrStruct
{
        int MyArr [2];
        char MyChar [2];
};

int main ()
{
        ArrStruct as;
        as.MyArr[0] = 45;
        as.MyArr[1] = 63;

        as.MyChar[0] = 'K';
        as.MyChar[1] = 'S';

        cout<<"First element of Integer Array is: "<< as.MyArr[0];
        cout<<"\n"<<"Second element of Integer Array is: "<<as.MyArr[1];

        cout<<"\n"<<"First element of Char Array is: "<< as.MyChar[0];
        cout<<"\n"<<"Second element of Char Array is: "<< as.MyChar[1];

        return 0;
}
```
```

```
Output:

```text
First element of Integer Array is: 45
Second element of Integer Array is: 63
First element of Char Array is: K
Second element of Char Array is: S

```

In Listing 6, you see two arrays, MyArr and MyChar are created in the structure named, ArrStruct. In the main() function an object (as) is created of the ArrStruct structure. This object is used to access the elements of arrays declared within the structure. The elements of the arrays are assigned to certain values and then displayed on the screen by using their index value.
