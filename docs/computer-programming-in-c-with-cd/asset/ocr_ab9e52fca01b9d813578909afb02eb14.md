In Listing 20, String is a class that has the str variable, which is a pointer type character variable. In the String class, we declare the following:

+   - `String()`: Represents a default constructor using the new operator allocating memory to the str variable
+   - `String(char *s)`: Represents a parameterized constructor using the new operator allocating memory to the str variable
+   - `~String()`: Represents a destructor using the delete operator releasing memory from the str variable

In the main() function, three objects, object1, object2, and object3 of the String class are created. The object1 and object2 objects invoke the String(char *s) constructor and the respective message. However, object3 invokes the String()constructor and does not display any character string stored in the str variable. The String() destructor is invoked three times corresponding to each object of the String class.

Let’s now explain how to invoke a constructor and destructor of a class globally.

# Invoking Global Constructor and Destructor

The objects of a class can be defined as global, within a program, with the help of global variables. The global object gets created before entering into the main() function and destroyed after the main() function exits. This creation and destruction of the global object is done by invoking the global constructors and global destructors. Listing 21 shows how to invoke a global constructor and a global destructor (you can find this example in the GlobalConsDest.cpp file on the CD in the code\chapter6 folder):

# Listing 21: Invoking Constructor and Destructor of a Class Globally

```
#include<iostream.h>
class ConsDesCall
{
public:
  ConsDesCall()
  {
    cout<<"Constructor called"<<endl;
  }
  ~ConsDesCall()
  {
    cout<<"Destructor called"<<endl;
  }
}
```
