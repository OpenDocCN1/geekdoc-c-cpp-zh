# Creating the Nested if Statements

The if statements are said to be nested when they contain other if statements within them. The control of program goes into the inner if statement when the outer if statement is evaluated to be true. The following is the syntax to create nested if statements:

```
```cpp
if(conditional expression1)
{
    // Statement1 to be executed in case the conditional expression1 is true;
    if(conditional expression2)
    {
        // Statement2 to be executed in case the conditional expression2 is true;
    }
}
```
