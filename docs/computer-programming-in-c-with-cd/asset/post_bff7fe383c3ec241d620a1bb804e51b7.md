## Floating Point Types

We already know that floating point numbers are represented by the float and double data types. These data types are used to represent numbers along with decimal values. The data types can also have an exponent, which means 10 to the power of any number. For example, 2e2 = 2 x 10 ^ 2, where e represents 10, that is, an exponent. The exponent in the float data type can have the maximum value of 10 ^ 38 while exponent in the double data type can have a value of 10 ^ 308. The difference between the float and double data types is that the float data type can represent a maximum of 7 digits (single precision) after the decimal, while the double data type can represent 15 digits (double precision). Table 5 lists the characteristics (such as data type representation, width) of the float and double data types:

| Data Type | Representation | Width (bytes) | Range |
|---|---|---|---|
| float | Single precision floating point number | 4 | 3.4e +/- 38 |
| double | Double precision floating point number | 8 | 1.7e +/- 308 |

The following code snippet shows the declaration of the floating point type variable:

```cpp
float x=3.458f;
```

In the preceding code snippet, a float type variable, x, is declared and initialized. In the same way, you can use double data types with variables, as shown in the following code snippet:

```cpp
double x, y;
```

In the preceding code snippet, the x and y variables are of the double type.

## The void Data Type

The void data type is a data type that does not return any value. For example, a void data type used with a function specifies that the function does not return any value. It is also used with functions to represent an empty argument list. The following code snippet shows the use of the void data type:

```cpp
void add(void);
```

In the preceding code snippet, the add function has a void parameter, which means that it does not pass any parameter.

When the void data type is used with a pointer, the pointer can point to any variable that is not declared with the const or volatile keyword. A void pointer can be converted into another type of data pointer. You need to cast the void pointer into another type to dereference a void pointer, as shown in the following code snippet:

```cpp
void *a;
int *x;
x=a; // not valid in C++, needs to cast
x=(int *)a;
```

In the preceding code snippet, the void pointer a is dereferenced by type casting it into the int data type.

## Class

A class is a user-defined data type, which makes C++ an object-oriented language. A class consists of data (variables) and code (functions) that work on the data. Both the data and code are collectively called the members of a class. All the members of a class are private by default, which means that the members of a class are accessible within the same class and cannot be accessed by any other class. You can declare a class as public to allow its members to be accessible outside the class. Private and public are access specifiers that specify the scope of variables, methods, and classes.
