In Listing 48, the compiler invokes the operator+(int j) member function when it encounters the following code snippet:

```cpp
obj1+1000;
```

The operator+(int j) function has an argument of integer type, that is, j, in which a value 1000 is passed by value. However, a problem arises when you write the preceding code snippet as the following code snippet:

```cpp
1000+obj1;
```

In the preceding code snippet, the operator+() member function would not be invoked. It is because the object on the left of the operator invokes the overloaded member function. The operator+() function is a member function of the class and the this pointer is passed to it. The solution to this problem is to use a friend function. In friend functions, the this pointer is not passed (as they are not members of the class). Therefore, by using friend functions, you can specify the order of arguments in either order while overloading an operator. Listing 49 shows the use of a friend function to add objects and built-in data types (you can find this example in the Object_BuiltIn_FriendAddition.cpp file on the CD in the code\chapter6 folder):

### Listing 49: Adding Objects and Built-In Data Types Using Friend Functions

```cpp
#include<iostream.h>

class ObjectValueTest
{
    int i;
public:

    ObjectValueTest():i(100)
    {
    }
    ObjectValueTest(int t):i(t)
    {
    }

    int display()
    {
        return i;
    }
    friend ObjectValueTest& operator+(int, ObjectValueTest&);
    friend ObjectValueTest& operator+(ObjectValueTest&, int);
};

ObjectValueTest& operator+(int j, ObjectValueTest& x)
{
    x.i=x.i+j;
    return x;
}

ObjectValueTest& operator+(ObjectValueTest& y, int k)
{
    y.i=y.i+k;
    return y;
}

void main()
{
    ObjectValueTest obj1,obj2(10),obj3(20);
    cout<<"The initial value in first object: "<<obj1.display()<<endl;
    cout<<"The initial value in second object: "<<obj2.display()<<endl;
    cout<<"The initial value in third object: "<<obj3.display()<<endl;
    1000+obj1;
    obj1+1000;
    cout<<"The final value in first object: "<<obj1.display()<<endl;
    cout<<"The final value in second object: "<<obj2.display()<<endl;
    cout<<"The final value in third object: "<<obj3.display()<<endl;
}
```

**Output:**

```text

The initial value in second object: 10
The initial value in third object: 20
The final value in first object: 2100
The final value in second object: 10
The final value in third object: 20
```

Listing 49 uses two friend functions to overload the + operator, so that the + operator can operate with an integer value on either side of the operator.

## Overloading of Relational Operators

Relational operators are binary operators that require two operands for comparison. The result of a relational operation is a boolean value that can be either true or false. Overloading of relational operators <, >, <=, >=, ==, and != requires a similar technique as the one used in overloading of a binary arithmetic operator. Overloading of a relational operator also accepts an object on its right side as a parameter and the object on the left side is passed by the this pointer. Listing 50 compares the length stored in two objects of a class by using the > operator (you can find this example in the GreaterThanOperatorOverload.cpp file on the CD in the code\chapter6 folder):

### Listing 50: Overloading of the Greater Than (>) Operator

```cpp
#include<iostream.h>

class Distance
{
    int length;
public:
    Distance(int);
    void operator>(Distance);
};

Distance::Distance(int a)

void Distance::operator>(Distance d)
{

    {
        cout<<length<<" is greater than "<<d.length;

    else

    }
}

}
```

## Using Type Operator for Type Conversion

In C++, you can also overload a datatype, such as int, float. The overloading of a data type is also called overloading of a type operator. The following syntax is used to overload a type operator:

```cpp
className::operator typename ()
{
    ...
    ...
}
```

The return type of the operator function that overloads a type operator is the same as the type operator. Listing 51 shows an example of type conversion using type operator (you can find this example in the TypeConversion.cpp file on the CD in the code\chapter6 folder):

### Listing 51: Overloading of a Type Operator

```cpp
#include<iostream.h>

class TypeConverter
{
    int num, total, percentage;
public:
    TypeConverter(int, int);
    operator int()
    {
        percentage = num * 100 / total;
        return percentage;
    }
};

TypeConverter::TypeConverter(int n, int t)
{
    num = n;
    total = t;
    percentage = 0;
}

int main()
{
    TypeConverter tcv(45, 500);
    cout<<"The result of the 'operator int()' type operator is: ";
    cout<<tcv.operator int()<<"\n";
    return 0;
}
```
