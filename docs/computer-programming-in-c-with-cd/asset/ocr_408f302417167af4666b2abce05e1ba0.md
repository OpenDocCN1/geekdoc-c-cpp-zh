Q4. What are library functions and linkers in C++?

Ans. Library functions are predefined C++ functions that simplify a programmer's task. For example, if a programmer wants to create a program to calculate the length of a string, then the programmer needs to write the code. On the other hand, in C++, the strlen() function is a library function used to calculate the length of the specified string. Using library functions in C++ programs, you can simplify the work and reduce the chance of errors in your programs.

In C++, library functions are stored in various other files that must be included in your C++ program. For example, to use the cout object, you need to include the iostream.h header file in your C++ program. Now, link this file with source code to produce an executable file. The process to link the header file with the source code is done by linkers. Compilers that are used to generate executable file from source code also have linkers, which links the source code with header files.
