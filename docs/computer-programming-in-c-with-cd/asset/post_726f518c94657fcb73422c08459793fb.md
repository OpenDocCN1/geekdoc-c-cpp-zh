
**▶ Listing 7: Creating Inline Functions Outside a Class**

```cpp
#include<iostream.h>

class MyClass
{
  int x,y,z;
  public:
  void getData();
  void displayData();
};
inline void MyClass :: getData()
{
  cout<<"Enter any two numbers";
  cin>>x>>y;
  z=x+y;
}
inline void MyClass :: displayData()
{
  cout<<"The sum of two numbers is="<<z<<endl;
}

int main()
{
  MyClass o;
  o.getData();
  o.displayData();
  return 0;
}
```

```text

The sum of two numbers is=45
```

In Listing 7, the getData() and displayData() functions of the MyClass class are defined as inline functions outside the class specification. The definition of these functions are exclusively using the inline keyword.

An inline function is treated as a normal function in the following situations:

- An inline function is a recursive function.
- An inline function contains static variables.
- An inline function contains the return statement and the return type of the function is void. Note that a function that is having its return type as void can have the return statement to transfer a control back to the caller function.
- An inline function contains a loop construct, switch, or goto statement that returns a value.

Let’s now learn the difference between inline functions and macros.

## Difference between Inline Functions and Macros

Similar to an inline function, macro is another kind of function that makes a C++ program compact, but itself is expanded by the C++ compiler. A macro contains a sequence of code, which is replaced by the C++ compiler by generating the actual machine code for the program. One of the disadvantage of using a macro is that it takes more memory as compared to a function. However, a macro takes less time for execution.

Listing 8 shows the use of a macro as well as an inline function in a class (you can find this example in the MacroAndInline.cpp file on the CD in the code\chapter6 folder):

**▶ Listing 8: Using a Macro and an Inline Function in a Class**

```cpp
#include<iostream.h>

#define cube1(num) num*num*num        //Creating a macro
/* Creating an inline function */
inline int cube2(int x)
{
return (x*x*x);
}
int main()
{
cout<<"cube1 (5) ="<<cube1(5)<<endl;          //Calling macro
cout<<"cube1 (5+10) ="<<cube1(5+10)<<endl;    //Calling macro
cout<<"cube2 (5) ="<<cube2(5)<<endl;          //Calling inline function
cout<<"cube2 (5+10) ="<<cube2(5+10)<<endl;    //Calling inline function
return 0;
}
```

**Output:**

```text
cube1 (5) =125
cube1 (5+10) =115
cube2 (5) =125
cube2 (5+10) =3375
```

In Listing 8, we are creating a macro, cube1, using the #define preprocessor directive; and an inline function, cube2, using the inline keyword. In the main() function, the calling of the cube1(5) and cube1(5+10) macros displays the result as 125 and 115, respectively. However, the calling of the cube2(5) and cube2(5+10) inline functions displays the result as 125 and 3375, respectively.

Note that the result of the cube1(5) macro and the cube2(5) inline function is same and that is 125. However, the result of the cube1(5+10) macro and the cube2(5+10) inline function is different, that is, 115 and 3375, respectively. This is because, the cube1(5+10) macro is evaluated as 5+10*5+10*5+10; whereas, the cube2(5+10) inline function is evaluated as 15*15*15.

You are advised to use an inline function, instead of a macro, because of following reasons:

- The invocation of a macro does not perform the type-checking; whereas, the calling of an inline function performs the type-checking
- A macro cannot use the return keyword; whereas, an inline function can use the return keyword

## 6.6 Working with Constructors and Destructors

Constructor and destructor are special member functions of a class that are used to initialize or de-initialize the member variables, respectively, of a class. When you create an object of a class, you need to allocate memory to the object. However, the allocation of memory does not ensure the initialization of the member variables within the object. The member variables within a class cannot be initialized at the time of declaring a class. For example, the initialization of the member variables in the following code snippet is invalid:

```cpp
class GreatestNumber
{
  int variable=10;
  int variable=20;
};
```

The problem of not initializing a member variable at the time of declaring a class can be overcome by writing an initialization function in a class that assigns initial values to each member variable. This initialization function can be invoked when an object is created. Listing 9 shows an initialization function (you can find this example in the InitializeFunction.cpp file on the CD in the code\chapter6 folder):

**▶ Listing 9: Creating an Initialization Function**

```cpp
#include<iostream.h>

class GreatestNumber
{
  private:
    int variable1, variable2, variable3;
  public:
    void initialize();
    void greaterNum();
    void displayNum();
};
void GreatestNumber::initialize()
{
    variable1=10;
    variable2=20;
}
void GreatestNumber::greaterNum()
{
    if(variable1>=variable2)
        variable3=variable1;
    else
        variable3=variable2;
}
void GreatestNumber::displayNum()
{
    cout<<"The greatest number is:"<<variable3<<endl;
}

int main()
{
    GreatestNumber gnObject1;
    gnObject1.initialize();
    gnObject1.greaterNum();
    gnObject1.displayNum();
    return 0;
}
```

**Output:**

```text
The greatest number is:20
```

In Listing 9, the gnObject1 object of the GreatestNumber class has to call a member function, initialize(), to initialize the data members, variable1 and variable2. The only drawback of this approach is that if the user forgets to invoke the initialization function, the program operates on an object that has member variables with meaningless values (junk characters). It is because, when a variable is declared within a class, it just stores some junk characters (meaningless values) within it.

C++ offers a solution to this problem. While designing a class, you can include a special member function within the class that is executed whenever an object of the class is created. Such functions are called constructors. Constructors are the member functions of a class and are invoked when an instance of the class, to which they belong, is created. The distinguishing features of constructors are that they have the same name as that of the class.

Destructors, on the other hand, deinitialize the objects when they are destroyed. A destructor is automatically invoked when an object of a class goes out of scope. Therefore, a programmer is relieved of the task of clearing the memory space occupied by a data member every time an object goes out of scope.

Let’s explain how to declare and use a constructor in a class.

### Declaring and Using Constructors

A constructor is a special member function that allocates the memory and initializes the objects of its class. A constructor is distinct from other member functions of the class, as it has the same name as its class. It does not include a return type (not even void), as in case of a function. It executes automatically when a class is instantiated (object is created). Listing 10 shows the declaration of a constructor in a class (you can find this example in the SimpleConstructor.cpp file on the CD in the code\chapter6 folder):

**Listing 10: Creating a Constructor in a Class**

```cpp
#include<iostream.h>

class NumberInitialization
{
  int x,y;
  public:
  NumberInitialization()
  {
    cout<<"Constructor calling"<<endl;
    x=1;
    y=2;

    cout<<"x="<<x<<endl;
    cout<<"y="<<y<<endl;
    cout<<"Program Over\n";
  }
};

int main()
{
  NumberInitialization n1;
  //Constructor invoked
  return 0;
}
```

```text
Constructor calling
```
