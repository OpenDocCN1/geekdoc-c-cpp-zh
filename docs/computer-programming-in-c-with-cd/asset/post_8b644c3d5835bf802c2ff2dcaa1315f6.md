
## Q7. What is the concept of overloading in C++?

Ans. When you perform more than one task by using the same function or operator, it is known as overloading. If you specify more than one definition for a function name or an operator in the same scope, you have overloaded that function name or operator.

When you call an overloaded function name or operator, the compiler determines the most appropriate function or operator to be used. The compiler compares the argument types that you have used to call the function or operator with the argument types specified in the function or operator definitions. The process of selecting the most appropriate overloaded function or operator is called overload resolution.

In C++, you can overload the following:

- A function
- A constructor
- An operator

## Q8. What is a function signature?

Ans. A function signature is a combination of the following:

- The number of parameters in the function.
- The data types of the parameters.
- The order of the data types of the parameters.

Note that the return type of a function is not a part of the function signature.

## Q9. What is function overloading?

Ans. Function overloading is the process of using the same name for two or more functions. Each redefinition of a function must use different function signatures. In function overloading, when you have multiple functions with the same name, the compiler identifies the function based on the parameters passed to the function.

## Q10. How the data members of an object can be initialized dynamically by using constructors?

Ans. In C++, object's data members can be dynamically initialized during runtime, even after their creation. The dynamic initialization of the data members of an object is performed by using overloaded constructors. It provides flexibility of using different forms of data at runtime depending upon the user's need.

## Q11. What is operator overloading?

Ans. Operator overloading means to use an operator to operate on the objects of a user-defined data type, such as a class or a structure, but not on the constant or variable values. The compiler identifies an overloaded operator itself when it (the compiler) finds that the data type of an operand is a user-defined data type. If the data type of an operand is a built-in data type, then the compiler performs the normal operations.

An operator can be overloaded by defining a function for it. A function that is preceded by the operator keyword is called an operator function. An operator function redefines a particular operator so that it performs a specific operation when it is used with the object of a class. The syntax to overload an operator is:

```cpp
return_type class_name::operator operator_symbol(argument_list)
{
    // body of the operator function
}
```

In the preceding syntax, the operator_symbol is an operator that can be any valid operator, such as +, -, *, /, <<, >>. The following code snippet shows an example of the operator function:

```cpp
int operator +(int a, int b)
{
    return a+b;
}
```

## Q12. What is a local class?

Ans. A class declared within a function definition is called a local class. A local class definition can use the type names, enumerations, and static variables of the function within which the local class is defined.

## Q2. What is the output of the following program?

```cpp
#include <iostream.h>

class Printer2;
class Printer1 {
    int printing;

public:
    Printer1() {
        printing = 0;
    }
    void set_print(int status) {
        printing = status;
    }
    friend int inuse(Printer1 object1, Printer2 object2);
};

class Printer2 {
    int printing;

public:
    Printer2() {
        printing = 0;
    }
    void set_print(int status) {
        printing = status;
    }
    friend int inuse(Printer1 object1, Printer2 object2);
};

int inuse(Printer1 object1, Printer2 object2)
{
    if(object1.printing || object2.printing) return 1;
    else return 0;
}

int main()
{
    Printer1 p1;
    Printer2 p2;
    if(!inuse(p1, p2))
        cout << "Printer 1 and 2 are idle\n";
    cout << "Setting Printer 1 to printing...\n";
    p1.set_print(1);
    if(inuse(p1, p2))
        cout << "Now, Printer 1 in use\n";
    cout << "Turn off Printer 1...\n";
    p1.set_print(0);
    if(!inuse(p1, p2))
        cout << "Printer 1 and 2 are idle\n";
    cout << "Turn on Printer 2...\n";
    p2.set_print(1);
    if(inuse(p1, p2))
        cout << "Now, Printer 2 in use\n";
    return 0;
}
```

Ans. Output of the preceding program is as follows:

```text
Printer 1 and 2 are idle
Setting Printer 1 to printing...
Now, Printer 1 in use
Turn off Printer 1...
Printer 1 and 2 are idle
Turn on Printer 2...
Now, Printer 2 in use
```
