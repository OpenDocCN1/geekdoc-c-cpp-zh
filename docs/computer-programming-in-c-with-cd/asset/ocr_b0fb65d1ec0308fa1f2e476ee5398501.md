Q5. How can we allocate memory to the pointer variable at run time?

Ans. Pointer in C++ can also be used for allocating memory to a variable at run time. When we allocate memory to a variable at run time, it is called dynamic memory allocation. Dynamic allocation allows you to use memory when it is needed. The new operator is provided by C++ to allocate memory dynamically. For example, let’s see the following code snippet:

```
int *MyInt = new int;
```

In the preceding code snippet, the MyInt is a pointer variable to which the memory is allocated by using the new operator.

Q6. Explain the process of de-allocating the memory of a pointer variable at run time.

Ans. Similar to allocating memory to the pointer variable at run time, we can also de-allocate memory of the pointer at run time. For this, C++ provides the delete operator. However, the delete operator can only release the memory of a pointer to which the memory is provided by using the new operator. For example, let’s consider the following code snippet:

```
delete   MyInt;
```

In the preceding code snippet, the `delete` keyword is followed by the name of the pointer variable that is `MyInt`, to release the memory occupied by the pointer variable `MyInt`.

Q7. What are arrays? How pointers can be used to work with arrays?

Ans. An array is a collection of variables of similar data type that are stored adjacent to each other in a memory. At the time of creating an array, you must specify its size, which implies the number of variable, an array can store. You can access individual element of an array by using their index number. The index number is also known as subscript number. The index number of each element of an array is one less than its actual place in the array. For example, if you want to access the fifth element of an array, the index number should be 4.

Pointers can also be used for referencing an array. When pointer deals with arrays, they store the address of a single element of an array at a time. Using pointer, you can also access and change the value of an array element.

Ans. C++ allows arithmetic operations on pointer variables. They are mainly used for fast and accurate manipulation of addresses assigned to the variables of an array.
