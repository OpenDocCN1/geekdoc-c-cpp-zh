## 6.14 Declaring and Using Static Variables and Functions

In C++, a data member (variable) or a member function of a class can be declared static, by using the `static` keyword. When you declare a data member or a member function of a class as static, they belong to the class only, and not to the objects of the class. This means that when a variable is declared as static in a class, the instances (objects) of the class share the same copy of that variable. In addition, a static function can be invoked simply with the class name (without using class's object).

Some important points to be considered before declaring the static members within a class are as follows:

- Static members are allocated, regardless of their scope, as soon as the execution of a program starts.
- Static members are de-allocated at the end of a program execution.
- During the execution of a program, the static members retain their values stored in them.
- Static members of a class must be re-declared outside the class (globally).
- Static data members can be accessed directly by static member functions only; otherwise, they are accessed by using the Scope Resolution Operator.
- Static members are created only once, when the execution of a program starts, and they are shared among all the objects (obj1, obj2, *ptr) of the class.
- Static functions can only use static data members or local variables.

The static members of a class can be categorized into two types— static data member and static member function.

### Declaring and Using Static Variables

When you declare a data member (or a variable) of a class as static, the C++ compiler allocates only one memory location for that data member. If more than one object of a class is initiated, all objects share the same memory location for that data member. The condition, sharing same memory location by multiple objects of a class, is very useful when you want the objects to share some specific data or provide a way of communication among them.

Static data members of a class are also known as class variables, because their content does not depend on any object. These variables are used to maintain the values that are common to the entire class.

The following code snippet shows the declaration of the StaticDataMembers class, which has a static variable y and a normal variable x having the class scope. Declaring a static variable means that the value retained by the variable y is shared by all the objects of the StaticDataMembers class. As x is not a static variable, the value retained in the variable x varies in the objects of the StaticDataMembers class.
