> > *The return type is not a part of the signature of a function. Therefore, the following occurrences are not valid in a class:*
> >
> > `void DisplayData();`
> > `char DisplayData();`
> >
> > *In other words, the DisplayData() function is not overloaded, as the return types of this function are different.*

In function overloading, when you have multiple functions with the same name, the compiler identifies the function based on its parameters. Listing 38 shows how to implement function overloading in a class (you can find this example in the FunctionOverload.cpp file on the CD in the code\chapter6 folder):

# ### ▶ Listing 38: Overloading of a Function in a Class

```
```cpp
#include<iostream.h>

class Arithmetic
{
public:
    void calc(int x)
    {
        cout<<"The area of the square is:"<<x*x<<endl;
    }
    void calc(int a, int b)
    {
        cout<<"The area of the rectangle is:"<<a*b<<endl;
    }
    void calc(int l, int b, int h)
    {
        cout<<"The volume of the cuboids' is:"<<l*b*h<<endl;
    }
};

int main()
{
    Arithmetic ar;
    ar.calc(10,20,30);
    ar.calc(45);
    ar.calc(50,70);
    return 0;
}
