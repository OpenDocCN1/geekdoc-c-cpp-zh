# Enumeration

An *enumeration* consists of a set of named integer constants. It allows you to name the values that a variable can take. For example, suppose you want to work with the days of the week (Sunday, Monday, Tuesday, and so on), but you do not want to refer to them with integers, such as 0, 1, 2, but instead give them real names. You can do this with an enumeration. The following code snippet lists a set of symbolic names:

```
```
enum day
{
        Sunday,
        Monday,
        Tuesday,
        Wednesday,
        Thursday,
        Friday,
        Saturday
} ;
```
```

Now, when you create a variable of the day type, you can assign it values from the list of possible values specified by you, as shown in the following code snippet:

```
```cpp
#include <iostream.h>
int main( )
{
        enum day {
                Sunday,
                Monday,
                Tuesday,
                Wednesday,
                Thursday,
                Friday,
                Saturday
        };
        enum day today = Friday;
        .
        .
        .
}
```
