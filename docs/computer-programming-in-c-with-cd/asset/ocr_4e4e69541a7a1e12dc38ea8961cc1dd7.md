# ### Increment (++) and Decrement (-) Operators

The pointer variable works as an index pointing the address of the variable. When the variable stored is of integer type, it consumes 4-bytes in memory. When we apply increment (++) operator, then the pointer variable points the next element after a 4-bytes gap. When the data is of a double, float, or a character type, then index is moved according to their size. You can use the decrement (--) operator to move at the previous element of an array.

# ### Addition (+) and Subtraction (-) Operators

The addition (+) operator increases the value of a pointer by size of the specified data type and moves the pointer variable to point to the specified element. The subtraction (-) operator decreases the value of a pointer by the size of the specified data type and moves the pointer variable to point to the specified element.

# ### The * Operator

The * operator is used before the pointer variable to retrieve the value of the variable. At the time of performing arithmetic operations on a pointer, the size of the data type used with a pointer variable is also taken into consideration. Let's consider an example where a pointer ptr is storing a reference of a float type array named arr containing 5 elements. Let's say, the first element of the array arr is at the memory location 2000. When the pointer ptr is incremented by using ++ operator, then the address of the pointer is incremented by four bytes instead of one byte, as the size occupied by a float data type is 4 bytes.
