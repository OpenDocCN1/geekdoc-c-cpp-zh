Pointers are variables that store the reference of other variables. When we declare a variable, the computer system allocates a memory space to the newly created variable. Using pointer, we can handle the physical location of computer's memory where the address of the variable resides. The size and type of address depends on the nature of the variable.

Consider a situation where you want to store the data of all the students for a school. For this, you are required to store the students' data in an array of student type. However, in this case, the number of students can vary from school to school. Therefore, you cannot initialize the array of student type with the assumption of a fixed number. In such a case, you can use a pointer variable of student type that can be initialized dynamically at run time and can store data according to the number of students in a particular school. In this way, pointers can be used to create applications that take memory according to user requirement and runs faster as comparing to applications without pointers.

### 4.1 Managing Memory by Using Pointers

When we create a variable in C++, we generally need to work with value stored in the variable. We are unaware about the memory location of the variable where the value is stored. However, in C++, if we need to work with its memory location of a variable, we use a special type of variable that is a pointer variable. Pointers are variables that store address of another variable. By using a pointer variable, you can directly access the value stored in the other variable, which it (pointer variable) points to. The data type of the pointer variable depends on the data type of that variable, whose address is stored in it. For example, y is an integer variable, which holds 10, so that the pointer variable x will also be of integer type.

Using pointers, you can easily process the array elements, by moving to different memory locations at run time. As soon as a variable is declared, the operating system allocates an appropriate amount of memory. The memory is allocated to the variable by using the new operator at run time and then the address is stored in the pointer variable, which references it. When the memory is no longer needed, it should be de-allocated with the help of the delete operator. The allocation and de-allocation is discussed later in this chapter. #### Getting Variable Address with the & Operator

When you declare a variable, it occupies a space in the memory. This occupied space has a unique address. C++ provides a reference or address of operator (&) to obtain the memory address occupied by the variable. The following code snippet shows how to declare and initialize a variable:

```cpp
int x=10;
```

In the preceding code snippet, a variable, x, of integer type is declared and initialized with the value, 10. Assume that variable x has occupied a space in the system memory with the name specified as AX01.

Now, if you write the following statement using the & operator in a C++ program:

```cpp
cout<<&x;
```

It displays the result as AX01.
