The `endl` manipulator is defined in the `iostream.h` header file and manipulators, such as `setw()`, `setprecision()`, and `setfill()` are defined in `iomanip.h` header file. Let’s discuss each of these manipulators one by one.

# Using the endl Manipulator

The `endl` manipulator displays the output on a new line. The `endl` manipulator sends a newline character to the output stream. Listing 6 shows the use of `endl` manipulator (you can find this example in the `endlManipulator.cpp` file on the CD in the code\chapter2 folder):

# ▶ Listing 6: Using the endl Manipulator

```
```cpp
#include<iostream.h>

int main()
{
  cout<<"Hello";
  cout<<"World";
  cout<<endl;
  cout<<"Hello"<<endl;
  cout<<"World";

  return 0;
}
```

**Output:**

```text
HelloWorld
Hello
World
```
```

In the output of Listing 6, you can see that the HelloWorld string is displayed on the screen in a single line when the `endl` manipulator is not used with the `cout` object; whereas, the cursor moves to the next line and the output is displayed in a new line when the `endl` manipulator is used with the `cout` object.

# Using the setw() Manipulator

The `setw()` manipulator accepts an integer parameter and sets the width of each item in the output stream. The characters are right-justified, by default, within the given width. Once an output is displayed using the `<<` operator, the width is reset to 0.
