In Listing 37, the display() member function of class A is a virtual function. When a virtual function is inherited, its virtual nature is also inherited. The virtual nature of a function means that the function exists only conceptually, and does not have a real existence. Therefore, a virtual function is a member function of a base class that may be redefined in the derived classes. In addition, a virtual function in a base class ensures that the compiler invokes the redefined virtual function of the corresponding derived class, even if you have called the function with a pointer or reference to a base class. A class that declares or inherits a virtual function is called a polymorphic class.

A virtual function cannot be global or static because, by definition, a virtual function is a member function of a base class and relies on a specific object to determine which implementation of the function is called. You can declare a virtual function to be a friend of another class.

Note that when a function is declared as virtual in a base class, you can access this function directly by using the :: operator. This is because, the :: operator suppresses the call to the function implementation of the derived class and calls the function implementation defined in the base class.
