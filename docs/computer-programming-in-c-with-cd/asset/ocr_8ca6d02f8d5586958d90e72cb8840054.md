# **Listing 29: Using the new and delete Operators with a Pointer Object**

```
#include<iostream.h>

class ABC
{
int num1;
//private data member
public:
int num2;
//public data member
void setValue(int);
void displayValue();
};
void ABC::setValue(int p)
{
num1=p;
}
void ABC::displayValue()
{
cout<<"num1 = "<<num1<<endl;
cout<<"num2 = "<<num2<<endl;
}
void main()
{
ABC *ptr;
// Creating a pointer object
ptr= new ABC();
//pointer object is assigned
ptr->setValue(44);
ptr->num2=76;
ptr->displayValue();
delete ptr;
}

Output:

num1 = 44

num2 = 76
```

In Listing 29, the ABC class is created, which has one private member, num1, and three public members, num2, setValue(), and displayValue(). The setValue() and displayValue() functions are defined outside the ABC class by using the :: operator. In the main() function, ptr is declared as a pointer object of the ABC class.
