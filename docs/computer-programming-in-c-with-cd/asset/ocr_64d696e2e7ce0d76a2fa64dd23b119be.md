Q7. What is the concept of overloading in C++?

Ans. When you perform more than one task by using the same function or operator, it is knows as overloading. If you specify more than one definition for a function name or an operator in the same scope, you have overloaded that function name or operator.

When you call an overloaded function name or operator, the compiler determines the most appropriate function or operator to be used. The compiler compares the argument types that you have used to call the function or operator with the argument types specified in the function or operation definitions. The process of selecting the most appropriate overloaded function or operator is called overload resolution.

In C++, you can overload the following:

+   - A function
+   - A constructor
+   - An operator

Q8. What is a function signature?

Ans. A function signature is a combination of the following:

+   - The number of parameters in the function.
+   - The data types of the parameters.
+   - The order of the data types of the parameters.

Note that the return type of a function is not a part of the function signature.

Q9. What is function overloading?

Ans. Function overloading is the process of using the same name for two or more functions. Each redefinition of a function must use different types of function signatures. In function overloading, when you have multiple functions with the same name, the compiler identifies the function based on the parameters passed to the function.

Q10. How the data members of an object can be initialized dynamically by using constructors?

Ans. In C++, object's data members can be dynamically initialized during runtime, even after their creation. The dynamic initialization of the data members of an object is performed by using overloaded constructors. It provides flexibility of using different forms of data at runtime depending upon the user's need.

Q11. What is operator overloading?

Ans. Operator overloading means to use an operator to operate on the objects of a user-defined data type, such as a class or a structure, but not on the constant or variable values. The compiler identifies an overloaded operator itself when it (the compiler) finds that the data type of an operand is a user-defined data type. If the data type of an operand is a built-in data type, then the compiler performs the normal operations.
