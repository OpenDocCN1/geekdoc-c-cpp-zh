# ■ Using Pointer to Pointer

As stated earlier, a pointer is a variable that contains memory address of another variable. However, a pointer may contain the memory address of another pointer. For example, there is an integer variable `MyInt` and two integer pointer variables `MyIntP1` and `MyIntP2`. The integer pointer `MyIntP1` points to the memory address of `MyInt` variable and the integer pointer `MyIntP2` points to the memory address of `MyIntP1`, then the integer pointer `MyIntP2` should be termed as a pointer to pointer.
