## The #undef Directive

The #undef directive is used where a defined macro needs to be undefined. When a macro is followed by the #undef directive, the macro becomes undefined and will be removed from the system. For example, suppose that you create a macro named PI by using the #define directive for a specific purpose in a C++ program, and after the purpose is achieved, you want to undefine the PI macro. In that case, the PI macro needs to be followed by #undef directive. The following code snippet shows the undefined PI macro:

```cpp
#undef PI
```

Now, all occurrences of the PI macro in the C++ program evaluate to false.

## The #include Directive

The #include directive is a frequently used preprocessor directive in C++. It is used to include files, such as header files, in a C++ program. This directive simply causes the entire content of a specified file to be inserted into the source code of the program. You can include a file in a C++ program in two ways, as shown in the following code snippet:

```cpp
#include <filename>
#include "filename"
```

In the preceding code snippet, the `< >` bracket and the `" "` quotation marks around the file name are used to specify the path where the C++ compiler will search for the specified file. The `< >` brackets around the file name makes the compiler search for the file in the predefined list of directories in C++. If the `" "` quotation marks are used around the file name, the compiler will search the specified file in the current directory as well as specified list of directories. The path of the predefined list of directories is specified at time of installing C++ IDE or compiler. The following code snippet shows how to include the iostream.h file in the C++ program:

```cpp
#include <iostream.h>
```

You can also include the iostream.h file by using the following code snippet:

```cpp
#include "iostream.h"
```

In the preceding code snippets, `.h` specifies that `iostream.h` is a header file. In this way, we can include a header file in C++ program. You can also include other files that are required to execute your C++ program. For example if you want to include an existing C++ file (say abc.cpp) you can use the following code snippet:

```cpp
#include "abc.cpp"
```

The code for including files in C++ program will be the same as the preceding one, except for the file name.

## Directives used in Conditional Compilation

In C++, we are provided with several conditional compilation directives, such as the #if, #ifdef, #ifndef, #elif (else if), #else, and #endif. They allow certain portions of a program to be selectively compiled or ignored based on the condition specified in the C++ program.

The #if directive is used to test whether an expression against the macro name evaluates the statements written in the #if block. The #if, #else, and #elif work in coordination with each other similar to the if-else statement. The following code snippet explains the concept of the #if directive:

```cpp
int main()
{
    #if <macro name> < condition>
    Statement 1;
    #else
    Statement 2;
    #endif
}
```

According to the preceding code snippet, the compiler first tests the macro name against the specified condition and if the condition evaluates to true, then the statement 1 executes else the statement 2 will execute.

The #ifdef directive checks the existence of the macro followed by the #ifdef directive. In case the macro exists, then the statements written in the #ifdef block executes; otherwise, the compiler generates an error. The #ifdef usually works in coordination with the #else, #endif directives. The following code snippet shows the implementation of the #ifdef directive:

```cpp
int main()
{

    #ifdef <macro_name>
    Statement1;
    #endif
}
```

In the preceding code snippet, the #ifdef directive checks the existence of the macro_name macro. If the specified macro exists, the statement1 statement is executed, and if the specified macro does not exist, an error message is displayed.

Suppose you have defined a macro named count and want to use it in your C++ program; however, at the time of using the macro, you are not sure whether the macro count is defined or not. In this case, you can use the #ifndef directive to check whether the macro exists or not, as shown in the following code snippet:

```cpp
int main()
{

    #ifndef <macro_name>
    #define <macro_name> <value>
    #endif
}
```

In the preceding code snippet, if the specified macro does not exist, you can define the macro. On the other hand, if the specified macro exists, the macro is used and the program is executed.

## Operators in C++

Operators are symbols that are used to perform operations, such as addition, subtraction, multiplication, or division based on the values stored in various variables. We discuss the operators in C++ under the following categories:

- Unary Operators
- Binary Operators
- Shift Operators
- Ternary Operators
- Special Operators

First, let’s discuss the unary operators present in C++.

### Unary Operators

The operators that work on a single operand are called Unary operators. The operand on which a unary operator works can either be a constant or a variable. Table 6 lists the unary operators:

**Table 6: Unary Operators in C++**

| Operator | Name | Associativity |
|---|---|---|
| `-` | Unary minus | None |
| `++` | Increment | None |
| `--` | Decrement | None |
| `!` | Unary Not | None |
| `~` | Bitwise complement | None |

In case the - operator is used to subtract the values of two variables, then the - operator is categorized as a binary operator; however, when the -- operator is used to decrease the value of a single variable, then this operator is categorized as a unary operator.

The ++ and -- operator were introduced in C to create incrementing and decrementing values. The ++ operator increments its operand by one number, and the -- operator decrements its operand by one. For example, if a variable holds the 0 value, then after you execute the ++variable, the variable will hold the value 1.

The ++ and -- operators can be either *postfix* operators (used like this: value++) or *prefix* operators (used like this: ++value). When used as postfix operators, they are executed *after* the rest of the statement, and when used as prefix operators, *before* the rest of the statement.

When any variable is subjected to ++ or -- operator as prefix operator, then the value stored in the variable is either first increment or decrement depending on the operator used on the variable. If you display the value stored in the variable then you will get the output affected by the operator. However, when ++ and -- works as postfix operator on a variable and that variable is displayed, then the value of the variable will remain same for the first instance. Now, if you again display the variable, then you will see the incremented or decremented value depending on the operator used on the variable.
