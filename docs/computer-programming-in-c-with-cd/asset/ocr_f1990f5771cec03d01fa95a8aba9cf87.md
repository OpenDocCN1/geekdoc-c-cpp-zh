```
int Arr1[] = {1,2,3,4,5};
```

In the preceding code snippet, the size of the Arr1 array is not specified, as it will be defined by compiler automatically according to the number of elements of the array.

Note that unlike other programming languages, C++ does not show any error message when you try to execute a program in which an illegal index value is accessed. For example, if you have declared an array with size 5 and you try to access the 10ᵗʰ element, it will not cause any compile-time error, rather the program will compile and execute without error. Listing 1 shows a program that access array elements by using illegal index value (you can find the ArrayIndex.cpp file on the CD in the code/chapter3 folder):

# ▶ Listing 1: Accessing Array Element with an Illegal Index Value

```
#include<iostream.h>
int main()
{
  int marks[5]={50,60,70,80,90};
  for(int i=0;i<10;i++)
  {
    cout<<marks[i];
    cout<<endl;
  }
  return 0;
}
```

# Output:

```
50
60
70
80
90
1245080
4244509
1
14098852
14101928
```

In Listing 1, the main() function contains the marks[] array with size 5, while the program tries to access marks[0] to marks[9]. While accessing array values, the program displays output up to 5ᵗʰ index as expected after that when the program tries to access the array element exceeding the length of array, the runtime exception occurs. This runtime exception conveys the compiler to access values that do not exist in the memory, which results in displaying garbage values.
