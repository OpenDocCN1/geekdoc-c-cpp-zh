Q8. What do you understand by recursive function?

Ans. To minimize the repetition of code in a function, you can write a function that calls itself. The situation in which a function calls itself is called recursion and that function is called a recursive function. This function is called repeatedly, unless the code included in the body of function terminates the chain of calls by implementing a condition within an if statement. You can use a recursive function with the if statement within the body of function.

Q9. What is inline function?

Ans. Inline functions are those functions created with the *inline* keyword. The use of the inline function enables the compiler to copy the code from the function definition to the code of calling program, which prevents the program from creating a separate set of instructions in memory. This results in less overhead for the compiler and helps in faster execution of the program.

Q10. Explain the strcmp() function.

Ans. The `strcmp()` function takes two strings as parameter and compares these strings. The strcmp() function returns an integer value indicating the relationship between the strings. A zero value indicates that both strings are equal. A value returned from strcmp() function, which is greater than zero, indicates that the first character that does not match has a greater value in string1 than in string2. A value less than zero indicates that the first character that does not match has lesser value in string1 than in string2.

Q11. Explain the strlen() function.

Ans. The `strlen()` function is used to find the length of a string. It takes one string as an argument to count number of characters in the string.

Q12. Explain the strcpy() function.

Ans. The `strcpy()` function is used to copy the content of first string to second string. You have to pass two strings as an argument of the strcpy() function to copy first string to second string.

Q13. What happens when a variable is declared with the static keyword?

Ans. When a variable is declared as `static`, it means that the variable is allocated in memory when the function (containing static variable) starts execution. As soon as the function terminated, it destroys all it variables but not the static variable. This helps the function to preserve the value of its variable between various function calls during the program execution.

Q14. What happens when a variable is declared with the const keyword?

Ans. As the name suggests, the `const` keyword specifies that a variable once declared and initialized cannot be changed. It is used where you do not want to change the value of the variable within a program.
