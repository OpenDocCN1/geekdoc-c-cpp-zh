In Listing 5, the Base and Derived classes are created, where the Derived class is inherited from the Base class. The Base class has the MyFuncB() function and the Derived class has the MyFuncB() and MyFuncD() functions. The MyFuncB() function is present in the Base class as well as in the Derived class, and the Derived class overrides the functionality of the MyFuncB() function.

In the main() function, an object, d, of the Derived class is created. The d object invokes the MyFuncB() and MyFuncD() functions of its own class between the Main Program started and Main Program ended statements.

Now, besides overriding the base class functions, it is also possible that a derived class may begin its existence with a copy of its base class members. The reason is: a derived class inherits the variables and member functions of its base class, but not the constructor or destructor from its base class. When an object of the derived class is created, it automatically invokes the default constructor and destructor of its base class.
