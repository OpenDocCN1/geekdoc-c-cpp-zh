## Creating an Array of Pointer Objects

You can create an array of pointer objects, where each pointer object points to an individual class object. The syntax to declare an array of pointer objects is:

```cpp
<class_name> *pointer_name [array_size];
```

An example of declaring an array of pointer objects is:

```cpp
Employee *ptremp[10];
```

In the preceding example, ptremp refers to an array of pointer objects of the Employee class, where the size of the array is 10.

## 7.11 Implementing Static and Dynamic Binding

In C++, you can implement polymorphism through function overloading, operator overloading and dynamic binding by using virtual functions. Dynamic binding is the practical implementation of the concept of dynamic polymorphism. Before explaining dynamic binding, let’s explain polymorphism and dynamic polymorphism. The phenomenon in which something appears in more than one form is called polymorphism. Polymorphism can be subdivided into two forms: static polymorphism and dynamic polymorphism. This section concentrates on dynamic polymorphism, which is applied in C++ when a derived class overrides a function declared in a base class.

Dynamic polymorphism refers to an entity changing its form, depending on the role or context in which the entity will be used. This concept may be treated as analogous to a chameleon changing its color under different circumstances. A function is said to exhibit dynamic polymorphism when it exists in more than one form. The matching of a function call, by the C++ compiler, with the correct function definition at run time is called `dynamic binding`. However, to implement dynamic binding, the concept of virtual functions is important.

Let’s learn the following topics in the context of static and dynamic binding:

- Static or early binding
- Dynamic or late binding and virtual functions
- Difference between static and dynamic binding
- Pure virtual functions
- Abstract classes
- Virtual destructors

### Implementing Static or Early Binding

Binding refers to the act of associating an object or a class with its member. Listing 34 shows an example of binding (you can find the Binding.cpp file on the CD in the Code\Chapter7 folder):

### Listing 34: Implementing Binding

```cpp
#include <iostream.h>

{

    void display()
    {
        cout << "Class A" << endl;
    }
};

{
public:
    void display()
    {
        cout << "Class B" << endl;
    }
};

{
public:

    }

**Output:**

```

In Listing 34, the obj object of class A is created and the display() member function is invoked, as given in the following code snippet:

```cpp
A obj;
obj.display();
```

In the preceding code snippet, no ambiguity arises for the C++ compiler, as it knows the reference of the display() function is of the A class.

If the object of a class is of a pointer type, then again there is no problem for the compiler to invoke the member function of that class, as shown in the following code snippet:

```cpp
A *PtrObj;
PtrObj = new A;
PtrObj->display();
```

In the preceding code snippet, the compiler needs to associate the display() function to a particular class. Again, there is no ambiguity. The compiler associates the function to class A, based on the type of the PtrObj pointer object.
