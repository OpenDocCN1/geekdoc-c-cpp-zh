## Creating the Nested if Statements

The if statements are said to be nested when they contain other if statements within them. The control of program goes into the inner if statement when the outer if statement is evaluated to be true. The following is the syntax to create nested if statements:

```cpp
if(conditional expression1)
{
    // Statement1 to be executed in case the conditional expression1 is true;
    if(conditional expression2)
    {
        // Statement2 to be executed in case the conditional expression2 is true;
    }
}
```

In the preceding syntax, conditional expression1 is first tested and in case it evaluates to true, statement1 gets executed and the control of program passes to the inner if statement. Statement2 gets executed in case conditional expression2 of the inner if statement is true. Listing 13 shows how to create nested if statements (you can find this example in the ifStatement2.cpp file on the CD in the code\chapter2 folder):

### Listing 13: Creating Nested if Statements

```cpp
#include<iostream.h>

int main()
{
    double num;
    cout<<"Enter a number"<<endl;
    cin>>num;
    if(num!=0)
    {
        if(num>0)
            cout<<"The result="<<(1/num)<<endl;
        else
            cout<<"The result="<<(-1/num)<<endl;
    }

    return 0;
}
```

**Output:**

```text
Enter a number
3
The result=0.333333
```

In Listing 13, the outer if statement evaluates whether or not the value supplied at run-time is equal to zero. In case, the value supplied at run-time is not zero, then the outer if statement evaluates to true and the control of the program goes to the inner if statement. The inner if statement then further evaluates whether or not the number is greater than zero. If the number is greater than zero, then a result showing the division of 1 by that number gets displayed. However, if the number is less than zero, then the control passes to the else clause and the result showing the division of -1 by that number gets displayed on the console screen.

You can also define multiple statements within an if statement. Listing 14 shows how to define multiple statements within an if statement (you can find this example in the ifStatement3.cpp file on the CD in the code\chapter2 folder):

### Listing 14: Showing Multiple Statements within the `if` Statement


**Output:**

In Listing 14, the program prompts you to enter a number. The if statement verifies the conditional expression. If the condition is true, the statements within the braces are executed.

If the braces are not used and the if condition is true then the C++ compiler will execute only the immediate next statement to the if statement.

## Using the if-else Ladder

An entire sequence of the `if-else` statements occurs one after another, is called an `if-else` ladder. Listing 15 demonstrates how an `if-else` ladder works (you can find this example in the `if-elseStatement2.cpp` file on the CD in the code\chapter2 folder):

### Listing 15: Using the `if-else` Ladder

```cpp
#include<iostream.h>
int main()
{
    char alphbt;
    cout<<"Enter an alphabet"<<endl;
    cin>>alphbt;
    if(alphbt=='a')
        cout<<"It is a vowel"<<endl;
    else if(alphbt=='e')
        cout<<"It is a vowel"<<endl;
    else if(alphbt=='i')
        cout<<"It is a vowel"<<endl;
    else if(alphbt=='o')
        cout<<"It is a vowel"<<endl;
    else if(alphbt=='u')
        cout<<"It is a vowel"<<endl;
    else
        cout<<"It is not a vowel"<<endl;
    return 0;
}
```

**Output:**

```text
Enter an alphabet
e
It is a vowel
```

In Listing 15, you can see that the character supplied at run-time is tested successively across the multiple `if-else` statements until a match is found.

The program created by using `if-else` ladders is difficult to read and maintain as program becomes more complex to understand. C++ provides switch statements to overcome these difficulties and complexities in understanding a program, which is discussed next.

## Using the switch Statement

A `switch` statement is a conditional statement that tests a value against different values. If the value is matched, the corresponding group of statements is executed. A switch statement begins with the `switch` keyword that is followed by a value expression in the parenthesis (). It is a combination of multiple case labels that must be separated by the `break` statement. Every case label contains a constant value that is matched against the value, which is specified in the `switch` expression. If the value is matched, the statements of that case label are executed. In addition, you can specify the `default` label, which is executed when the value, which is specified in the `switch` expression, does not match with the given case labels. The syntax to use switch statement is:

```cpp
switch(expression)
{
    case value1: statement1;
    break;
    case value2: statement2;
    break;
    case value3: statement3;
    break;
    .
    .
    .
    default: default_statement;
}
```

**Output:**

```text
Enter an alphabet
i
It is a vowel
```

In Listing 16, the value supplied by you at run-time is stored in an `alphabet` variable. This variable is used as a parameter to the switch clause and is compared against the various constants in the case labels. Statements following the case label are executed whose constant is equal to the value of the expression in the switch statement. In Listing 16, case `'i'` is executed. The default label is executed in case none of the case labels matches with the value stored in the switch expression.
