**Q5.** Write a program to compute sum of n number by using for loop (n can be any integer number supplied by the user at run time). Use separate function by using pointer to get the result. In our case user has entered 50 for the value of n.

**Ans.**

```
#include <iostream.h>

void sumOfn (int *num)
{
    *num = (*num * (*num+1))/2;
}
int main()
{
    int *sum, n1, n=0;
    cout<<"Enter the value of n: ";
    cin>>n;
    n1 = n;
    sum = &n;
    sumOfn (sum);
    cout<<"Sum of "<<n1<<" number is: "<<n;
    return 0;
}
```

**Output:**

Enter the value of n: 50
Sum of 50 number is: 1275
