
## Calling a Function

The function, which is declared and defined in a C++ program, can be invoked anywhere in the program. Invoking or calling a function in C++ is achieved by using the function name with a pair of parentheses and providing the list of arguments (if any) within the parenthesis. If a function returns some value, a variable of the same data type must be used to receive the value when the function is invoked. In case, you are required to display the returning value, you can also use the `cout` object without retrieving the value in any other variable. The following code snippet shows how to call a function:

```cpp
largest = maximum(i,j);
```

In the preceding code snippet, the maximum(i, j) method is called, which is defined in the *Defining a Function* section. The i and j parameters are passed in maximum() function as function parameters. The maximum(i, j) function also returns a value, which is stored in the integer variable, largest. The complete program, which includes declaring a function prototype, defining a function, and then calling a function, is shown in Listing 9 (you can find the Func4.cpp file on the CD in the code/chapter3 folder):

### Listing 9: Declaring, Defining, and Calling a Function

```cpp
#include <iostream.h>
int main()
{
    int i, j, largest;
    int maximum(int a, int b); // function prototype
    cout<<"Enter the value of i: ";
    cin>>i;
    cout<<endl;
    cout<<"Enter the value of j: ";
    cin>>j;
    cout<<endl;
    largest = maximum(i,j); // calling a function
    cout<<"The value that is greater between "<<i<<" and "<<j<<" is :"<<largest;
    return 0;
}
// Defining a function
int maximum(int a, int b)
{
    int temp=0;
    if(a > b)
        temp = a;
    else
        temp = b;
    return temp;
}
```

**Output:**

```
Enter the value of i: 5
Enter the value of j: 10
The value that is greater between 5 and 10 is: 10
```

In Listing 9, we have defined the prototype of the maximum() function inside the main() function by using the int maximum(int a, int b); statement. Then we have accepted two numbers from the user and called the maximum() function with these two numbers. The value returned by the maximum() function is stored in another integer variable, largest, by using the largest = maximum(i,j); statement. Finally, the value of the largest variable is displayed. You can also see that the maximum() function is defined outside the main() function.

## Passing Arguments to a Function

In C++, the arguments of a function are used to initialize the parameters of a function definition. Argument can be a variable, a constant or an expression. When you pass the arguments to a function, you must remember that the number of arguments and types of arguments must be the same as the parameters in the function definition. When you pass argument while calling a function, it is known as actual argument and when you pass argument while defining a function, it is known as formal argument. Listing 10 shows passing arguments to the sub() function. In Listing 10, value1 and value2 are actual arguments of the calling function sub(value1, value2), and num1 and num2 are formal arguments of defining the void sub(int num1, int num2) function. You can find the Func5.cpp file on the CD in the code/chapter3 folder:

### Listing 10: Passing Arguments to a Function

```cpp
#include <iostream.h>
void sub(int num1, int num2) // Arguments num1 and num2 are formal arguments
{
    int num3;
    num3 = num1 - num2;
    cout<<"The subtraction of two numbers is : "<<num3;
}
int main()
{
    int value1, value2;
    cout<<"Enter value1 :";
    cin>>value1;
    cout<<endl;
    cout<<"Enter value2 :";
    cin>>value2;
    cout<<endl;
    sub(value1, value2); //value1 and value2 are actual arguments of sub()
    return 0;
}
```

**Output:**

```
Enter value1 :8
Enter value2 :5
The subtraction of two numbers is : 3
```

In Listing 10, two integer values are accepted from the user and stored in the variables value1 and value2, respectively. Then, the `value1` and `value2` are passed as arguments to the `sub()` function. The sub() function subtracts the value of value2 variable from the value of value1 variable and displays the result to the user.

## Returning a Value from a Function

Returning a value from a function means that a function must return a value. The returning value can be int, float, char, or an array. It means that when a function is called, the body of function is executed and after completing execution, the function returns a value. The following is the syntax for returning a value from a function:

```text
<return_type> <function-name>(<argument>)
{
    return <variable_name> or value;
}
```

In the preceding syntax, `return_type` is any data type, such as char, int, and an array. The return statement must be specified at the end of the function body before the closing brace of defining a function. When a function returns a value, its data type must be same as in function prototype. Listing 11 shows how the `sub()` function returns a value. You can find the Func6.cpp file on the CD in the code/chapter3 folder:

### Listing 11: Function Returning a Value

```cpp
#include <iostream.h>
int sub(int num1, int num2)
{
    int num3;
    num3 = num1 - num2;
    return num3;  // function returns a value
}

int main()
{
    int value1, value2, value3;
    cout<<"Enter value1 :";
    cin>>value1;
    cout<<endl;
    cout<<"Enter value2 :";
    cin>>value2;
    cout<<endl;
    value3 = sub(value1, value2); // function call
    cout<<"The subtraction of two number is :"<<value3;
    return 0;
}
```

**Output:**

```
Enter value1 :7
Enter value2 :2
The subtraction of two number is :5
```

In Listing 11, the `sub()` function is defined that takes two integer variables as argument and returns the difference between them. In the `main()` function, the integer values are accepted from the user (value1 and value2) and passed as arguments to the `sub()` function. The value returned by the `sub()` function is stored in the value3 variable and displayed to the user.

It is also possible to create a function that does not return a value after execution using the void keyword. Let's discuss function returning void in the following section.

## Describing Function Returning void

In a program, if you want a function not to return any value, you can use the void keyword as the function return type. A function that does not return any value is called a function returning void. The function terminates without the return statement at the end of function body and the execution of program is transferred to the next statement of calling function. Listing 12 shows defining a function (convert()) by using the void keyword. You can find the Func7.cpp file on the CD in the code/chapter3 folder:

### Listing 12: Returning void from a Function

```cpp
#include <iostream.h>
void convert(float cel) // function definition with void
{
  float fahrenheit;
  fahrenheit = (cel*9)/5 + 32 ;
  cout<<"The equivalent temperature in fahrenheit is :"<<fahrenheit;
}

int main()
{
  float celsius;

  cout<<"Enter Celsius :";
  cin>>celsius;
  cout<<endl;
  convert(celsius); // function call
  return 0;
}
```

**Output:**

```
Enter Celsius :33.56
The equivalent temperature in fahrenheit is :92.408005
```

In Listing 12, the convert(float cel) function is defined with the return type as void, which implies that when this function terminates it will not return any value to the caller program. This is the reason; you can see that the return statement is not used at the end of the function.
