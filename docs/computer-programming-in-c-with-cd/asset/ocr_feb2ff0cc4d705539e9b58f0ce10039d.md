The following are the basic components of C++:

+   - Keywords
+   - Identifiers
+   - Comments
+   - Constants
+   - Variables
+   - Data types
+   - Preprocessor directives
+   - Operators

Let’s discuss these components one by one.

# Keywords

When we create a C++ program, we declare variables with the names specified by us. These variable name should not conflict with the terms that C++ has reserved for its own use. The reserved names in C++ are known as keywords. Table 1 lists these keywords:

**Table 1: The Keywords of C++**

|  |  |  |  |
|---|---|---|---|
| asm | auto | volatile | while |
| bool | break | case | catch |
| char | class | const | const_cast |
| continue | default | delete | do |
| double | dynamic_cast | else | enum |
| except | explicit | extern | false |
| finally | float | for | friend |
| goto | if | inline | int |
| long | mutable | namespace | new |
| operator | private | protected | public |
| register | reinterpret_cast | return | short |
| signed | sizeof | static | static_cast |
| struct | switch | template | this |
| throw | true | try | type_info |
| typedef | typeid | typename | union |
| unsigned | using | virtual | void |
