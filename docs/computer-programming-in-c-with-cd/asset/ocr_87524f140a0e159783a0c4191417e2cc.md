# ▶ Listing 4: Using the `gets()` and `puts()` Functions

```
```c
#include <stdio.h>

int main()
{
    char student_name1[] = "John";
    char student_name2[] = "Alex";

    clrscr();
    puts("Name of 1st student:");
    puts(student_name1);
    puts("Name of 2nd student:");
    puts(student_name2);
    putchar('\n');
    puts("Enter a new name for the 2nd student");
    gets(student_name2);

    putchar('\n');
    puts(student_name1);
    puts(student_name2);

    return(0);
}
```
```

```
**Output:**

```text
Name of 1st student
John
Name of 2nd student
Alex
Enter a new name for the 2nd student
Marc
John
Marc
```
```

> The New name of the 2nd student only accepts five characters. Entering more than five characters may vary the output.

In Listing 4, the `puts()` function prints a string, `Name of 1st student:`, to the console screen. The value stored in the `student_name1` array is printed using the `puts()` function. Another string, `Name of 2nd student:`, is printed along with the value stored in the `student_name2` array, using the `puts()` function. The program prompts you to enter a new name for the 2nd student. The entered value gets stored in the `student_name2` array using the `gets()` function.
