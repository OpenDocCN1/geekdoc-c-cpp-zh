# ▶ Listing 9: Using the `setfill()` Manipulator

```
```cpp
#include<iostream.h>
#include<iomanip.h>
int main()
{
  int x;
  int y;
  cout<<"Calculating sum of two numbers"<<endl<<endl;
  cout<<"Enter two numbers"<<endl;
  cin>>x;
  cin>>y;
  cout<<"Output before using setfill():"<<endl;
  cout<<"sum of two numbers"<<endl;
  cout<<setw(6)<<x+y<<endl;
  cout<<endl;
  cout<<"Output after using setfill():"<<endl;
  cout<<"sum of two numbers"<<endl;
  cout<<setw(6)<<setfill('^')<<x+y<<endl;

  return 0;
}
```
```

# Output:

```
```text
Calculating sum of two numbers

Enter two numbers
5
6
Output before using setfill():
sum of two numbers
     11

Output after using setfill():
sum of two numbers
^^^^^11
```
```

In Listing 9, the program prompts you to enter two numbers. These numbers get stored in the `x` and `y` variables, respectively. The sum of these two numbers is first shown with space at its left side, because the output is displayed without using the `setfill()` manipulator. This sum is again shown, but this time the output has replaced the space with `^` character because now the output is using the `setfill()` manipulator. The `setfill()` manipulator sets the `^` character in place of the whitespaces.

> The `iomanip.h` header file should be included in a program in order to use the `setfill()` manipulator.
