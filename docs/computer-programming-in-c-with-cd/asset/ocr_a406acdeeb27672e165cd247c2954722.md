# Character Type

The character data type is used to represent a single character enclosed within single quotes. This data type follows the Unicode character set to represent the characters that can be uniquely identified by a processor. Unicode is a standard character set that supports all the characters used in of various international languages. Table 4 lists the range of the char data type:

**Table 4: Range of the Character Data Type in C++**

| Data Type | Representation | Width (bytes) | Range |
|---|---|---|---|
| char | Character | 1 | Signed: -128 to 127<br>Unsigned: 0 to 255 |

The following code snippet shows the declaration of the character type variable:

```
~~~cpp
char ch = 'B';
~~~
```

In the preceding code snippet, the ch variable is declared and initialized with the value B. While initializing the character type variable, you must remember to enclose the character within single quotes. The char data type can hold one character, such as a letter, digit, or punctuation mark. These characters are stored in computer memory in form of American Standard Code for Information Interchange (ASCII) value. As the ASCII value of B is 66, the value stored in the ch variable will be 66.

> > ASCII values are used all over the world to represent the various symbols used in computers.
