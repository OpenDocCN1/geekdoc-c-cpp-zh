## Using Pointers with Structure

You can use pointers with structure to store the address of a structure variable. This pointer can be used to initialize and access structure variables. Moreover, you can create multiple pointers for a structure that can be used independently to each other, which implies that each structure pointer can store and access different value to the structure elements without affecting the values defined by other structure pointers. Let’s consider a structure consisting of two integer members, such as quantity and price.

This can be declared using the following code snippet:

```cpp
struct bucket
{
    int quantity;
    int price;
};
```

Now, you create and initialize the structure variables, bucket1 and bucket2 and access the members of structure by using the dot (.) operator, as shown in the following code snippet:

```cpp
bucket1.quantity = 1000;
bucket1.price = 10;
bucket2.quantity = 2000;
bucket2.price = 20;
```

▲ Figure 3: Representation of Structure Variables bucket1 and bucket2

In Figure 3, you see that there are two variables, bucket1 and bucket2 of the bucket structure. Both these variables initialize the structure variable with different values without affecting the values of other structure variable.

Listing 9 shows the declaration and accessing of structure variable using the dot (.) operator (you can find the DotOperator.cpp file on the CD in the code\chapter5 folder):

**Listing 9:** Declaring and Accessing Variables of the Structure using the Dot (.) Operator

```cpp
#include <iostream.h>

struct bucket
{
        int quantity;
        int price;
};                          //declaring a structure
int main()
{
    bucket bucket1;                 // declaring a structure variable
    bucket bucket2;                 //declaring a structure variable
    bucket1.quantity = 1000;
    bucket1.price = 10;
    bucket2.quantity = 2000;
    bucket2.price = 20;
    cout<<"printing quantity of bucket1:"<<bucket1.quantity<<endl;
    cout<<"printing price of bucket1:"<<bucket1.price<<endl;
    cout<<"printing quantity of bucket2:"<<bucket2.quantity<<endl;
    cout<<"printing price of bucket2:"<<bucket2.price<<endl;
    return 0;
}
```

While declaring a structure variable (bucket1), composite memory is allocated that is equal to the size of all the members together. You can declare a pointer variable of structure types to store the memory address of the structure variable. You can now declare two pointer variables ptr1 and ptr2 of the bucket structure as:

```cpp
bucket *ptr1,*ptr2;
```

Now, assign the address of structure variable bucket1 and bucket2 to the structure pointer variable ptr1 and ptr2 as:

```cpp
ptr1 = & bucket1;
ptr2 = & bucket2;
```
