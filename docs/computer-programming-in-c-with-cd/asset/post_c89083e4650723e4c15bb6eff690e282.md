A program always takes data as input, processes the data, and generates the required output. This flow of data in a program is known as Input/Output (I/O). In a programming language, the conditional and iteration statements are used to control the execution of program; this is known as flow control. A conditional statement specifies a condition to execute a block of code in a program and iteration statement repeatedly executes a block of code until the condition evaluates to true. Suppose you want to display the name of the students whose marks are more than 50 percent. In this case, you can use a conditional statement when you specify a condition to display the name of only those students who have more than 50 percent marks. On the other hand, you can use the iteration statement in a situation where you want to display the numbers from 1 to 100. In this case, instead of entering all the numbers, you can use the iteration statements, so that all the numbers are displayed without entering them one by one.

In this chapter, you learn about data input functions, such as `getchar()`, `scanf()`, `gets()` to input data from keyboard and data output functions, such as `putchar()`, `printf()`, `puts()` to display data on screen. This chapter describes about manipulators, such as `endl`, `setw`, `setprecision`, and `setfill`, to display the formatted data on your screen. You also learn about various conditional statements, such as if, if-else, nested if; various iteration statements, such as while loop, do-while loop, for loop, nested loop; and also jump statements, such as break, continue, and goto. ### 2.1 Exploring Data Input and Output Processes

In a program, data input and output are two important processes that are used to accept input details and display the information after processing these details, respectively. The input and output functions, such as `getchar()`, `putchar()`, `gets()`, `puts()`.

```cpp
scanf("%c%d", &ch, &i);
```

In the preceding syntax, the characters received from keyboard are stored in variables (ch, i) corresponding to the addresses of variables obtained using the & operator. These characters are stored as character and integer values according to the specified formats (%c and %d) in the ch and i variables, respectively. Table 1 lists some of the commonly-used format specifiers:

**Table 1: Some of the Commonly Used Format Specifiers**

| Format Specifier | Type |
|---|---|
| %i | int |
| %d | int (decimal) |
| %c | char |
| %f | float |
| %lf | double |
| %s | string |

The printf() function prints a string or a value stored in a variable to the console screen according to the specified format. For example, we can use printf() function for displaying string data in two ways. The first way is to pass a string data within the printf() function and the second is to print the string data stored in the str variable. The following example shows the use of the printf() function:

```cpp
printf("Test string"); // Example 1

printf("%s",&str); // Example 2
```

In the first example, the printf() function takes string as a parameter and prints the specified string in the console screen. On the other hand, in the second example, the printf() function takes two parameters. The first parameter is the string format specifier (%s), which tells the compiler to print string data on the console screen and the second parameter is the address of the variable, str, where the string data is stored in the memory.
