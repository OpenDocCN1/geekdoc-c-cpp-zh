# ▶ Listing 8: Using Union

```
```cpp
#include <iostream.h>
int main()
{
    union one_union
    {
        double double_variable;
        double double_variable2;
    } ;
    one_union union1;
    union1. double_variable = 3.14159 ;

    cout << "union1.double_variable =“ << union1.double_variable << endl;
    cout << "union1.double_variable2 =“ << union1.double_variable << endl;

    return 0;
}
```
```

```
```text
union1.double_variable =3.14159
union1.double_variable2 =3.14159

```

As the members of a union point to the same location in memory, modifications in the value of one member affect the other members.
