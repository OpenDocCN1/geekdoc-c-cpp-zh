## Using Pointers with Character Strings

In C++, a string is nothing but an array of characters ending with a null character `\0`. When you create a character pointer variable to reference a string in C++, the character pointer variable contains the address of first character of the string. Since, the string is internally represented as an array; we can access the individual character of that string by using a pointer. Listing 9 shows an example to understand the concept of accessing a string by using a pointer (you can find the StringPointer.cpp file on the CD in the code\chapter4 folder):

### ▶ Listing 9: Performing Operations on String Using Pointers

```cpp
#include<iostream.h>
int main()
{
  char *str="HELLO";  //declare character pointer referencing to a string
  cout<<*str<<endl;   //print element at the first element’s address
  cout<<str<<endl;    //print whole string starting from the first element
  str++;
  cout<<*str<<endl;   //print element at the shifted position
  cout<<str;          //print whole string starting from the shifted position
  return 0;
}
```

**Output:**

```text
H
HELLO
E
ELLO
```

In Listing 9, string `HELLO` is internally represented as an array of string consisting of individual characters as elements. Pointer `str` initially points to the first element of the array. If we increase `str` variable by 1 by using `++` operator, then `str++` represents the next element in the array, that is E. In addition, the elements can be referenced as `*(str)`, `*(str +1)` and so on. The array representation of string is shown in Figure 5:

## ■ **Exploring Dynamic Array**

As stated earlier, the new and delete operators are used to allocate and de-allocate memory to the pointers. The pointers to which you can allocate and de-allocate memory using these operators are called Dynamic array. For example, consider the following code snippet that allocate memory to the integer array arr by using the new operator, and de-allocate memory by using the delete operator:

```cpp
int* arr = new int[10]; // for creating and initializing array at run time.

delete[] arr; // for de-allocating memory assigned to the arr array.
```

Generally, dynamic arrays are preferred in comparison of static arrays (general arrays) because of the following benefits:

- The memory to static array is allocated at compile time, whether it is used in the program or not. On the other hand, the memory to dynamic array is allocated while executing the statement (declaring dynamic array) at run time by the program.
- The static array holds memory throughout the program execution and the memory allocated to static array cannot be released until the program terminates. On the other hand, you can release the memory allocated to dynamic array at any time during program execution, whenever the array is not required further in the program.
