# Using Recursion

Sometimes, you write a block of code within a function that executes repeatedly to perform a task. To minimize this repetition, you can write a function, which calls itself. The situation, in which a function calls itself, is called recursion and that function is called a recursive function. This function is called repeatedly, unless the code included in the body of function terminates the chain of calls by implementing a condition within the `if` statement. The following is the syntax for recursive function:

```
```cpp
void recursion(arguments)
{
    statements1
    if (condition)

    recursion(arguments)
    statements2
}
```
```

In the preceding syntax, the recursion is name of the recursive function that has specific set of statements including the `if` statement. After the `if` statement, this recursive (recursion) function is called.
