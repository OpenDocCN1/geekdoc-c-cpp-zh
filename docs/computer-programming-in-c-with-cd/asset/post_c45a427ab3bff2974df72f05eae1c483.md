## Overloading of Increment (++) Operators

When the increment (++) operator is used with a built-in data type, the prefix notation (for instance, ++x) causes the variable (x) to be incremented first before it is used in an expression. Whereas, the postfix notation of increment operator (for instance, x++) causes the value to be incremented after the value is used in an expression.

Overloaded increment operator has two versions. First version takes no arguments, is invoked when the compiler invokes the prefix notation of increment operator with the object of a class. While the second version, takes an argument of int type, is invoked when the compiler invokes the postfix notation of increment operator with the object of a class. Listing 43 shows the increment (++) operator overloading in the PrePostIncrement class (you can find this example in the IncrementOverload.cpp file on the CD in the code\chapter6 folder):

### Listing 43: Overloading of Increment (++) Operator

```cpp
#include<iostream.h>

class PrePostIncrement
{
    int i;
public:
    PrePostIncrement(int j)             //Constructor with integer parameters
    {
        i=j;
    }
    void operator ++()                  //prefix increment overloading
    {
        ++i;
        cout<<"Incremented value of 'i' by prefix overloaded function : "<<i<<endl;
    }
    void operator ++(int p)             //postfix increment overloading
    {
        i++;
        cout<<"Incremented value of 'i' by postfix overloaded function : "<<i<<endl;
    }
};

void main()
{
    PrePostIncrement pp(8);
    pp++;                               //post increment
    ++pp;                               //pre increment
}
```

**Output:**

```text
Incremented value of 'i' by postfix overloaded function : 9
Incremented value of 'i' by prefix overloaded function : 10
```

In Listing 43, when the compiler encounters the ++pp statement, it invokes the void operator ++() function; whereas, it invokes the void operator ++(int p) function when it encounters the pp++ statement. The function void operator ++() performs pre increment in the object and the function void operator ++(int p) performs post increment in the object.

> All postfix unary operators take a dummy integer as their parameter.

## Overloading of Unary Operator Returning Object

You can overload an operator that returns an object of a class. This means that you can use the following code snippet in the main() function of a class:

```cpp
Object1--Object2;
```

Listing 44 shows overloading of minus operator returning object (you can find this example in the UnaryOptReturnObject.cpp file on the CD in the code\chapter6 folder):

### Listing 44: Overloading of a Unary Operator Returns an Object

```cpp
#include<iostream.h>
class NegativeNumberShow
{
    int num1,num2;
public:
    NegativeNumberShow (){}
    NegativeNumberShow (int i,int j)
    {
        num1=i;
        num2=j;
    }
    friend NegativeNumberShow operator -(NegativeNumberShow);
    void disp()
    {
        cout<<"The value of 'num1' is :"<<num1<<endl;
        cout<<"The value of 'num2' is :"<<num2<<endl;
    }
};
NegativeNumberShow operator -(NegativeNumberShow n)
{
    NegativeNumberShow tmp;
    tmp.num1=-n.num1;
    tmp.num2=-n.num2;
    return tmp;
}
int main()
{
    NegativeNumberShow n1(10,200),n2;
    cout<<"Before calling of unary minus operator"<<endl;
    n1.disp();
    cout<<"Indirect calling of unary minus operator"<<endl;
    n2=-n1;
    n2.disp();
    cout<<"Direct calling of unary minus operator"<<endl;
    n2=operator -(n2);
    n2.disp();
    return 0;
}
```

**Output:**

```text
Before calling of unary minus operator
The value of 'num1' is :10
The value of 'num2' is :200
Indirect calling of unary minus operator
The value of 'num1' is :-10
The value of 'num2' is :-200
Direct calling of unary minus operator
The value of 'num1' is :10
The value of 'num2' is :200
```

In Listing 44, NegativeNumberShow is a class that has a friend operator function of the NegativeNumberShow type. The prototype of the operator function is declared in the NegativeNumberShow class, as shown in the following code snippet:

```cpp
friend NegativeNumberShow operator -(NegativeNumberShow);
```

Note that the argument that is passed in the operator function is NegativeNumberShow and not NegativeNumberShow &. This is because the operator function generates or returns a newly created object using the values of an object, which is passed as an argument. Therefore, the following code snippet assigns the n2 object with all the negative values of the n1 object:

```cpp
n2=-n1;
```

In the preceding code snippet, however, the values stored in the n1 object do not get affected. Moreover, the following code snippet reassigns the n2 object:

```cpp
n2=operator -(n2);
```
