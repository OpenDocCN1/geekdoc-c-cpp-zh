The operator + (int j) function has an argument of integer type, that is, j in which a value 1000 is passed by value. However, a problem arises when you write the preceding code snippet as the following code snippet:

```
    1000+obj1;
```

In the preceding code snippet, the operator +() member function would not be invoked. It is because; the object on the left of the operator invokes the overloaded member function. The operator +() function is a member function of the class and the this pointer is passed to it. The solution to this problem is to use a friend function. In friend functions, the this pointer is not passed (as they are not members of the class). Therefore, by using friend functions, you can specify the order of arguments in either way while overloading an operator. Listing 49 shows the use of a friend function to add objects and built-in data types (you can find this example in the Object_BuiltIn_FriendAddition.cpp file on the CD in the code\chapter6 folder):

# Listing 49: Adding Objects and Built-In Data Types Using Friend Functions

```
    #include<iostream.h>

    class ObjectValueTest
    {
        int i;
    public:

        ObjectValueTest():i(100)
        {
        }
        ObjectValueTest (int t):i(t)
        {
        }

        int display()
        {
            return i;
        }
        friend ObjectValueTest& operator + (int, ObjectValueTest&);
        friend ObjectValueTest& operator + (ObjectValueTest&, int);
    };
    ObjectValueTest& operator + (int j, ObjectValueTest& x)
    {
        x.i=x.i+j;
        return x;

    }
    ObjectValueTest& operator + (ObjectValueTest& y, int k)
    {
        y.i=y.i+k;
        return y;
    }
```
