In standard UNIX, compilers that can be used to compile a C++ program are CC or g++, and you only need to pass the name of the file or files you want to compile to the compiler on the command line. The following code snippet shows how a C++ file is passed on the command line to compile the file:

```
```text
%g++ hello.cpp
```
```

Generally, the C++ library is linked with a C++ program when the program is compiled, but in some versions you may be required to explicitly link the C++ library with the C++ program. Consider the following code snippet to explicitly link the C++ library with a C++ program:

```
```text
%g++ hello.cpp -lg++
```
```

The preceding code snippet converts the hello.cpp file into a new file, hello.o, and then *links* it with the C++ standard libraries to add the code needed to support C++. The result is a file named a.out, which is an executable file and can be run, as shown in the following code snippet:

```
```text
%a.out
```
```

This is the process for compiling a C++ program on the UNIX platform. Now, let’s learn how to compile a C++ program in DOS.

In DOS, the process to compile a C++ program is command-based. For example, in Borland C++, the compiler is named bcc32.exe, and it is unpacked into a directory named bin. The files included in the C++ code, such as iostream, are put into a directory named include, and the C++ library objects are put into a directory named lib. If you have unpacked everything in a directory named c:\bcc, your command line shows the following statement:

```
```text
C:\cpp>c:\bcc\bin\bcc32 -I c:\bcc\include -L c:\bcc\lib hello.cpp
Borland C++ 5.5 for Win32 Copyright (c) 1993, 2000 Borland
hello.cpp:
Turbo Incremental Link 5.00 Copyright (c) 1997, 2000 Borland
```
```

In the preceding statement, we use the -I *switch* to indicate to the compiler the path of the include files, and the -L switch to indicate the C++ library files.

> > You use compiler switches such as -I or -L on the command line to customize the behavior of your compiler; check your compiler’s documentation to see the command line switches available to it.
