However, instead of calling the member function of the Y class, the C++ compiler always invokes the member function of the X class. Besides static binding, there is another mechanism in which a function call is made at runtime, called dynamic binding. Let’s take this up in the next section.

# Implementing Dynamic or Late Binding using Virtual Functions

In some situations, when we write programs in C++, the type of the object or pointer may not be known at the time of compilation. For example, there may be a requirement where a list of employee needs to be created. Depending on the request of the department and the kind of employees required, the net salary of the employees needs to be calculated. In such a scenario, the number of employees and their department are not fixed, and such values are provided at the time of execution. This means, in such situations, the binding of a function to a class is done during the run time, and this process is known as dynamic binding or late binding.
