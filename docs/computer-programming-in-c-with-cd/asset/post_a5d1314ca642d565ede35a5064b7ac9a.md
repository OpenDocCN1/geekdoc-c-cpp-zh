In C++, pure virtual functions are used to create abstract classes. A class containing one or more pure virtual functions is called an `abstract class`. For example, an abstract class can be created as shown in the following code snippet:

```cpp
class A{
public:
    virtual void display() = 0;
};
```

In the preceding code snippet, the display() function is a pure virtual function, which is initialized with zero. Note that a function declaration cannot have both a pure specifier and a definition. For example, the compiler does not allow the following expression:

```cpp
class A {
public:
    virtual void display() { } = 0;
};
```

Listing 40 shows how a pure virtual function makes a class as an abstract class (you can find the AbstractBase.cpp file on the CD in the Code\Chapter7 folder):

### ▶ Listing 40: Creating an Abstract Class

```cpp
#include <iostream.h>

class Polygon
{
    protected:
        int width, height;
    public:
        void setup (int first, int second)
        {
            width = first;
            height = second;
        }
        virtual int area() = 0;
};

class Rectangle: public Polygon
{
    public:
        int area()
        {
            return (width * height);
        }
};

class Triangle: public Polygon
{
    public:
        int area()
        {
            return (width * height / 2);
        }
};

int main ()
{
    Rectangle rectangle;
    Triangle triangle;
    Polygon * ptr_polygon1 = &rectangle;
    Polygon * ptr_polygon2 = &triangle;
    ptr_polygon1->setup(2,2);
    ptr_polygon2->setup(2,2);
    cout << ptr_polygon1->area () << endl;
    cout << ptr_polygon2->area () << endl;
    return 0;
}
```

Output:

```
4
2
```

In Listing 40, area() is a pure virtual function that makes the Polygon class an abstract base class. However, you should remember that by adding a pure virtual function to the base class, you are forced to add or override the same function to any derived class.

Some restrictions while using an abstract class are as follows:

- An abstract class cannot be used as a parameter type while creating a constructor or a function
- An abstract class cannot be used as a return type of a function
- An abstract class cannot be used for explicit conversion of data type
- An abstract class cannot be instantiated, although you can declare pointers and references of an abstract class

The following code snippet shows some examples of these restrictions:

```cpp
class A {
    virtual void f() = 0;
};
class B : A {
    virtual void f() { }
};
A g();                         // Error: class A is an abstract class
void h(A);                      // Error: class A is an abstract class
A& i(A&);

int main()
{
    A a;                    // Error: Class A is an abstract class
    A* pa;
    B b;
    A(b);                   // Error: Class A is an abstract class
    return 0;
}
```

In the preceding code snippet, class A is an abstract class. The compiler neither allows the A g() or void h(A) function declarations nor the declaration of an object of class A. Virtual member functions are inherited. A class derived from an abstract base class becomes abstract unless you override each pure virtual function of the base class in the derived class. For example, in the following code snippet, the compiler does not allow the creation of an object of the B class, as B is an abstract class:

```cpp
class A {
public:
    virtual void f() = 0;
};

class B : public A {
    void g();
};
int main() {
    B obj;        /*This line gives a compile error, as we cannot create an
                   instance of abstract class*/
    return 0;
}
```

In the preceding code snippet, within the main() function, the compiler does not allow you to create an object of class B because this is an abstract class and it inherits the pure virtual function, f(), from class A. Creating an instance of an abstract class generates a compile time error. An abstract class is basically used as a base class only.

> You can derive an abstract class from a non-abstract class, and override a non-pure virtual function with a pure virtual function.

## Creating Virtual Destructors

As you know, destructors are usually used to deallocate memory and perform cleanup tasks for a class object and its class members when the object is destroyed. When both, the base and derived classes, have destructors, the order of the execution of destructors is given as follows:

- 1. Derived class destructor
- 2. Base class destructor

Now, consider an exceptional case when you create a base class pointer. As you know, you can pass a derived class object to a base class pointer, when the base class pointer expects a base class object. However, in this condition, the destructor of the derived class is not invoked.

Listing 41 shows that the destructor of only base class is invoked and not of a derived class (you can find the BaseDestructorInvocation.cpp file on the CD in the Code\Chapter7 folder):

### ▶ Listing 41: Invoking a Base Class Destructor Only

```cpp
#include <iostream.h>

class Base
{
    public:
        Base(){ cout<<"Constructor: Base"<<endl;}
        ~Base(){ cout<<"Destructor : Base"<<endl;}
};

class Derived: public Base
{
    public:
        Derived(){ cout<<"Constructor: Derived"<<endl;}
        ~Derived(){ cout<<"Destructor : Derived"<<endl;}
};

void main()
{
    Base *b = new Derived(); /*Pointer object not invokes the derived class destructor*/
    delete b;
}
```

Output:

```
Constructor: Base
Constructor: Derived
Destructor : Base
```

In Listing 41, the constructors are called in the order, base- to- derived classes; however, the destructor of the derived class is not called at all. In this situation, you can use virtual destructors. By making the destructor of base class as virtual, you can invoke the destructors of both, the base and derived classes, in the order, derived- to- base classes.

Listing 42 shows how to code a virtual destructor in a base class (you can find the VirtualDestructor_Base.cpp file on the CD in the Code\Chapter7 folder):

### ▶ Listing 42: Creating a Virtual Destructor in a Base Class

```cpp
#include <iostream.h>

class Base
{
    public:
        Base()
        {
            cout<<"Constructor: Base"<<endl;}
        virtual ~Base(){ cout<<"Destructor : Base"<<endl;}  //virtual destructor
};
class Derived: public Base
{
    public:
        Derived(){ cout<<"Constructor: Derived"<<endl;}
        ~Derived(){ cout<<"Destructor : Derived"<<endl;}
};

void main()
{
    Base *b = new Derived();
    delete b;
}
```

Output:

```
Constructor: Base
Constructor: Derived
Destructor : Derived
Destructor : Base
```

It is important to note that you cannot declare a pure virtual destructor, as shown in the following code snippet:

```cpp
virtual ~Base()=0;     //error
```

However, you can declare a virtual destructor with an empty body, as shown in the following code snippet:

```cpp
virtual ~Base(){}
```

> *It is not necessary for a class to have a virtual destructor if it has virtual functions, or vice versa.*
