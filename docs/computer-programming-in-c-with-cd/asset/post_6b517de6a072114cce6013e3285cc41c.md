
It is used to send the text to the cout object so that the text can be displayed. In C++, one operator can perform several different tasks.

You notice that we used the << operator twice in the same line of code. The << operator is used the second time to send the endl keyword to the cout object. The endl keyword is an iostream *manipulator*, which is used to control the actions of the cout object. In Listing 2, the endl manipulator is used to move the control to the next line.

![](img/8a6886c00caa6a1651a6c0e62bff341f_24_0.png)

> The endl manipulator is discussed in Chapter 2, Working with Input/Output and Flow Control.

At the end of the cout statement, there is a semicolon (;). This semicolon acts as a terminator, much like a period at the end of a sentence. The last statement in the main() function is `return 0`. The return statement is used to return a value to a function in a C++ program; however, using 0 with the return keyword indicates program termination.

## Compiling a Program

After a program is created, you must compile it to run it. The actual details of compiling the C++ code depend on the compiler. In this section, we look at the process of compiling a C++ program in various operating systems, such as UNIX and DOS.

In the *C++ Integrated Development Environment* (IDE), a C++ program is created as a part of a *project*, which is compiled by using menu items, such as Make, Build, or Build All. Such IDE packages create different types of programs for you, such as those that might run in DOS, or as a dynamic link library, or as a Web application. In C++, the details of the compilation process are compiler-specific.

In standard UNIX, compilers that can be used to compile a C++ program are CC or g++, and you only need to pass the name of the file or files you want to compile to the compiler on the command line. The following code snippet shows how a C++ file is passed on the command line to compile the file:

```text
%g++ hello.cpp
```

Generally, the C++ library is linked with a C++ program when the program is compiled, but in some versions you may be required to explicitly link the C++ library with the C++ program. Consider the following code snippet to explicitly link the C++ library with a C++ program:

```text
%g++ hello.cpp -lg++
```

The preceding code snippet converts the hello.cpp file into a new file, hello.o, and then *links* it with the C++ standard libraries to add the code needed to support C++. The result is a file named a.out, which is an executable file and can be run, as shown in the following code snippet:

```text
%a.out
```

This is the process for compiling a C++ program on the UNIX platform. Now, let’s learn how to compile a C++ program in DOS.

In DOS, the process to compile a C++ program is command-based. For example, in Borland C++, the compiler is named bcc32.exe, and it is unpacked into a directory named bin. The files included in the C++ code, such as iostream, are put into a directory named include, and the C++ library objects are put into a directory named lib. If you have unpacked everything in a directory named `c:\bcc`, your command line shows the following statement:

```text
C:\cpp>c:\bcc\bin\bcc32 -I c:\bcc\include -L c:\bcc\lib hello.cpp
Borland C++ 5.5 for Win32 Copyright (c) 1993, 2000 Borland
hello.cpp:
Turbo Incremental Link 5.00 Copyright (c) 1997, 2000 Borland
```

In the preceding statement, we use the -I *switch* to indicate to the compiler the path of the include files, and the -L switch to indicate the C++ library files.

![](img/8a6886c00caa6a1651a6c0e62bff341f_25_0.png)

> You use compiler switches such as -I or -L on the command line to customize the behavior of your compiler; check your compiler’s documentation to see the command line switches available to it.

After compiling a C++ program, you need to debug the program to check and remove the errors.

## Debugging a Program

It may happen that a program you create does not compile successfully because of bugs. You have to first remove those bugs from the program in order to successfully compile and run the program. The process of removing bugs from a program is known as debugging. A program can be run after it has been successfully debugged.

## Running a Program

The execution of a compiled program depends on the operating system of your computer. In Windows, you enter the name of the executable file, such as hello, on the command line, omitting the .exe extension if there is one, and press the Enter key to start the program.

In UNIX, the name of the executable file can be a.out, which you should enter in the command line to run the program.

IDE-based C++ compilers, such as Microsoft Visual C++, should include a Run or Execute menu item to run the compiled program.

![](img/8a6886c00caa6a1651a6c0e62bff341f_26_0.png)

> If your program does not terminate normally and appears to be stuck, press the Ctrl+C keys in combination to terminate the program, or select the appropriate menu item (such as Stop Running) from the IDE you are using to develop C++ programs.

Sometimes, it may happen that when you run a C++ program, the window on which the output is displayed appears for a short time and closes immediately before you get a chance to look at it properly. If you have this problem, then add the cin.get() method at the very end of the main() function, but before the return statement. By adding the cin.get() method, the output window waits until you press a key, such as the Enter key, after which the program terminates.

## 1.4 Exploring the Basic Components of C++

Before writing a program, you must have good knowledge of the basic fundamentals of the language you are using. The fundamentals of the C++ language involve understanding its basic program structure (already discussed in the Process Flow of *C++ Programs* section), and the tokens and keywords reserved by the language. Apart from this, you should know how to make a program more readable by adding comments.

Tokens, keywords, and comments are some of the basic components used by C++. Tokens include keywords, identifiers, constants, operators, and special symbols, such as preprocessor directives and operators. The elements that are predefined in the C++ library and are meaningful for the C++ compiler are known as tokens. In C++, tokens are separated by white space that includes blanks, tabs, and new lines.

The following are the basic components of C++:

- Keywords
- Identifiers
- Comments
- Constants
- Variables
- Data types
- Preprocessor directives
- Operators

Let’s discuss these components one by one.
