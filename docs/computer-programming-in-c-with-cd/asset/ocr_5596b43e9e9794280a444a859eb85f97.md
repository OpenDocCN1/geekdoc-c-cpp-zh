# Assignment Operators

The assignment operator is a basic operator and is represented as =. You use the = operator to assign a literal value or the value in another variable to a variable. Listing 15 shows the use of the = operator (you can find the AssignmentEx.cpp file on the CD in the code/chapter1 folder:

# ▶ Listing 15: Using Assignment Operator

```
#include <iostream.h>
int main()
{
    int value = 12;
    cout << "The value = " << value << endl;
    return 0;
}
```

# Output:

```
The value = 12
```

In C++, you can perform multiple assignments in the same statement (this works because the assignment operator itself returns the assigned value). Listing 16 shows the implementation of the concept of multiple assignments (you can find the MultiAssEx.cpp file on the CD in the code/chapter1 folder):

# ▶ Listing 16: Performing Multiple Assignments

```
#include <iostream.h>
int main()
{
    int value1, value2, value3;
    value1 = value2 = value3 = 12;
    cout << "First value = " << value1 << endl;
    cout << "Second value = " << value2 << endl;
    cout << "Third value = " << value3 << endl;
    return 0;
}
```

# Output:

```
First value = 12
Second value = 12
Third value = 12
```
