# Linked List using the Structure and Pointer

Linked list is a type of data structure that consists of a collection of item in a linear manner. The basic idea behind a linked list is the inclusion of items that contain the pointer to point to the list of the same type.

Let’s create a structure which consists of two data fields (quantity and price) and a pointer of the previous structure type for holding the address of the next node. The node represent an item of a linked list. The following code snippet shows the structure of the linked list:

```
struct node
{
    int quantity;
    int price;
    node *next;
};
```
