# Structure

In C++, a structure is a user-defined data type that allows you to define a data construct, which helps to store the variables of different data types. For example, suppose you want to store the first character of the name as well as the age of a person. For this, you can create your own data structure using structures in C++. These data structures are used to create new data types to declare variables.

In the following code snippet, we create a structure named person:

```
struct person
{
    char first_name;
    int age;
};
```

In the preceding code snippet, the person structure is defined containing char and int type variables. Now, the following code snippet shows how a structure is used as data type to declare variables:

```
#include <iostream.h>
int main()
{
    struct person
    {
        char first_name;
        int age;
    };
    person ralph;
    .
    .
    .
}
```

In the preceding code snippet, ralph is a variable name whose data type is person. You can access the members of a structure by using the dot (.) notation.
