# ▶ Listing 31: Showing Operator Precedence

```
```cpp
#include <iostream.h>
int main()
{
    double value;
    value= 12 + 24 / 6;
    cout << "The value= " << value << endl;
    return 0;
}
```
```

Output:

```
```text
The value = 16
```
```

In Listing 31, we are trying to add 12 and 24 and then divide the sum by 6 to get 36 / 6 = 6. However, the output of the Listing 31 is not as per our expectation. In fact, C++ sets up a very clear precedence of operators, which means that if it finds two operators at the same level in statement (that is, not enclosed in parentheses or braces), it will execute the operator with the higher precedence first. As it happens, the / operator has higher precedence than the + operator, so in the preceding expression, first, 24 is divided by 6; next, the result is added to 12, which gives the value as 16. To get the desired result, you have to indicate the compiler about the order in which the operators have to be evaluated. For this purpose, you can use parentheses to group the operations you want to execute first.

Listing 32 shows the use of parenthesis to produce the desired output (you can find the ParenthesesEx.cpp file on the CD in the code/chapter1 folder):

# ▶ Listing 32: Using Parentheses

```
```cpp
#include <iostream.h>
int main()
{
    double value;
    value = (12 + 24) / 6;
    cout << "The value = " << value << endl;
    return 0;
}
```
```

Output:

```
```text
The value = 6
```
```

In Listing 32, the parenthesis around 12 + 24 ensures that the addition operation is performed first and thereafter, their sum is divided by 6.
