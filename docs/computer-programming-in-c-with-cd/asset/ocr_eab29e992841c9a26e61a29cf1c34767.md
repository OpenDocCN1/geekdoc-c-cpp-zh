Q29: Define a class worker with following specification:

+   - private member of a class worker
+     - wno integer
+     - wname 25 characters
+     - hrwrk, wgrate float (Hours worked & wgrate per hour)
+     - totwage float (hrwrk*wgrate)
+     - calcwg() -a function to find hrwrk * wgrate with float return type
+   - public member of class worker
+     - In_data()- a function to accept value wno, wname, hrwrk, wgrate
+       and invoke calcwg() to calculate totwage
+     - Out_data()- A function to display all the data member on screen

(Mumbai University, May 2009)

Ans:

```
```cpp
class worker
{
private:

int wno;
char wname [25];
float hrwrk, wgrate;
float totwage;

float calcwg()
{
totwage= hrwrk * wgrate;
return totwage;
}

public :

void In_data()
{
cin>> wno>>wname>>hrwrk>>wgrate;
calcwg() ;
}
void Out_data()
{
cout<< wno<< wname <<hrwrk<< wgrate<<totwage;
}// A function to display all the data member on screen
};
