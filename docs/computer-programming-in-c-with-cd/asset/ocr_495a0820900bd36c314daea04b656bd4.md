In Listing 1. Vehicle is a base class and Car is a derived class of the Vehicle class. The derived Car class contains all the information included in the Vehicle base class, such as weight of vehicle and number of wheels, as well as its own information, such as passenger load.

While the Vehicle base class can be used to declare objects, such as trucks, cars, bicycles, or any other vehicle, the Car class can only be used to declare an object of type Car, such as Maruti Zen, Santro, and Tata Indica. The Car class is therefore more restrictive and specific than the Vehicle class and the Vehicle class is more general than the Car class.

After learning how to implement inheritance, let’s discuss the types of derivations in C++ in the next section.

# 7.4 Explaining Various Types of Derivations

In C++, member accessibility depends on the use of access specifiers (public, private, and protected). These access specifiers not only grant the permission to access the members of a class outside the class, but also define the scope of accessing the members of a base class with the objects of a derived class. In other words, access restrictions can be imposed not only within a class but also while deriving the class. A derived class, which inherits from a base class, should use any one of the following access specifiers:

+   - `private`: When a base class is specified as private, all its members remain private in the base class and are not inherited by derived class and the public and protected members of the base class become private members of the derived class.
+   - `protected`: When a base class is specified as protected, all private members of the class remain private in the base class. In addition, protected members remain protected, but the public members of the base class become protected members of the derived class.
+   - `public`: When a base class is specified as public, all private members of a base class remain private in the base class, and protected members remain protected, and public members remain public in the derived class.
