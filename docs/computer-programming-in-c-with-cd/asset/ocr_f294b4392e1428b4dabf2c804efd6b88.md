Inheriting the attributes of a class allows code reusability, which means that there is no need to rewrite code, which is already available to implement the functionality of the inherited class. This feature of C++ makes it easy to manage large programs. Moreover, in OOP the different objects of a class are independent to each other, which imply that the changes in one object do not affect the functionality of other objects.

# 1.2 History of C++

Bjarne Stroustrup at the AT & T Bells laboratory developed an enhancement of C named *C with classes* in 1979. Later on 1983, it was renamed to C++ and is used internally in AT & T. C++ is derived from the C language. The concepts of OOP were implemented in the C language, and then C developed into an OOP language called C++. In fact, C++ is also known as a superset of the C language, because C++ includes all the functionalities of the C language. Bjarne Stroustrup called it C with Classes, which was later changed to C++. The ++ sign of C++ denotes the increment operator of the C language and is appended in C to emerge a new name, C++, as C++ is derived from the C language.

C++ was developed to create easily manageable and reusable programs. The C language was popular before the development of C++ and was considered a very good programming language at that time. However, managing long programs in the C language was a problem since all the functions in a C program are interrelated and the changes made in one function affect the performance of other functions. In such as scenario, it was not easy for a programmer to find out the function in which a problem had occurred. This was why a need for a new programming language was felt, a programming language in which the fragments of the program code worked independently so that a program could be managed easily.
