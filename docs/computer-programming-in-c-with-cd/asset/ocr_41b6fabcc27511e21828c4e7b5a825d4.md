```cpp
#include <iostream.h>

# **The Boolean Data Type**

Boolean type variables are variables that are declared as boolean type and have either a true or false value. You can declare a boolean type variable by using the bool keyword. The true or false values are stored as integers 0 and 1, respectively. Listing 6 shows how to declare a boolean type variable (you can find the BooleanEx.cpp file on the CD in the code/chapter1 folder):

# **Listing 6: Using the bool Keyword**

```
```cpp
#include <iostream.h>

int main()
{
    bool a = true;
    cout << "The value of the a boolean type variable is:" <<a;
    return 0;
}
```
```

**Output:**

The value of the a boolean type variable is:1

> > *The bool data type is compiler specific. Therefore, it may happen when you compile the code given in Listing 6, the compiler generates error.*

In Listing 6, a boolean type variable is declared and the true value has been assigned to it. Moreover, the boolean type value of a variable is displayed.
