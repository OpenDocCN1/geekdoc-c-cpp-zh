# ■  Short Questions/Answers

Q1. Explain the relationship between pointers and Memory management.

Ans. When we declare a variable, we do not consider its memory location in the system. It is the task of operating system to allocate an appropriate amount of memory and keep track of such memory location. At times, when we need to use the memory address of a variable, we use a special type of variable that is a pointer variable. By using a pointer variable, we can directly access the memory address of a variable as well as its value to which it (pointer variable) points to. Moreover, we also allocate and de-allocate memory to the pointer dynamically for the optimum use of available memory. The data type of the pointer variable depends on the data type of that variable, whose address is stored in it.

Q2. How can we retrieve the memory address of a variable in C++?

Ans. In C++, when we declare a variable, the variable occupies some space in the memory. Each memory location has a unique address associated with it. In C++, you can obtain this memory address by using a reference or address of (&) operator. For example, if you need to access the memory address of an integer variable, called X. Then, you have to write the &X statement, where X is the variable name that is preceded by the & operator.

Q3. How can we access or modify the value of a variable by using pointers in C++?

Ans. To create and use the pointer, there are two basic steps. Firstly, we declare a pointer variable and then we store the address of a variable in it. Once the memory address of a variable is assigned to the pointer variable, you can directly access the value of that variable by using the * operator. The * operator is also known as the dereference operator. The dereference operator (*) accesses the data stored in the variable pointed by the pointer variable. For example, if MyInt is an integer variable and MyPointer is a pointer that points to the memory address of the MyInt variable, then you can use the *MyPointer pointer to access and change the value of MyInt variable.
