# ▶ Listing 7: Creating Inline Functions Outside a Class

```
```cpp
#include<iostream.h>

class MyClass
{
  int x,y,z;
  public:
  void getData();
  void displayData();
};
inline void MyClass :: getData()
{
  cout<<"Enter any two numbers";
  cin>>x>>y;
  z=x+y;
}
inline void MyClass :: displayData()
{
  cout<<"The sum of two numbers is="<<z<<endl;
}

int main()
{
  MyClass o;
  o.getData();
  o.displayData();
  return 0;
}
```
```

**Output:**

```
```text
Enter any two numbers19
26
The sum of two numbers is=45
```
```

In Listing 7, the getData() and displayData() functions of the MyClass class are defined as inline functions outside the class specification. The definition of these functions are exclusively using the inline keyword.

An inline function is treated as a normal function in the following situations:

+   - An inline function is a recursive function.
+   - An inline function contains static variables.
+   - An inline function contains the return statement and the return type of the function is void. Note that a function that is having its return type as void can have the return statement to transfer a control back to the caller function.
