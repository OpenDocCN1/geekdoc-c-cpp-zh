expression. Whereas, the postfix notation of increment operator (for instance, x++) causes the value to be incremented after the value is used in an expression.

Overloaded increment operator has two versions. First version take no arguments, is invoked when the compiler invokes the prefix notation of increment operator with the object of a class. While the second version, takes an argument of int type, is invoked when the compiler invokes the postfix notation of increment operator with the object of a class. Listing 43 shows the increment (++) operator overloading in the PrePostIncrement class (you can find this example in the IncrementOverload.cpp file on the CD in.. the code\\chapter6 folder):

# ▶ Listing 43: Overloading of Increment (++) Operator

```cpp
#include<iostream.h>

class PrePostIncrement
{
int i;
public :
    PrePostIncrement(int j)             //Constructor with integer parameters
    {
        i=j;
    }
    void operator ++()                  //prefix increment overloading
    {
        ++i;
        cout<<"Incremented value of 'i' by prefix overloaded function : "<<i<<endl;
    }
    void operator ++(int p)             //postfix increment overloading
    {
        i++;
        cout<<"Incremented value of 'i' by postfix overloaded function : "<<i<<endl;
    }
};

void main()
{
    PrePostIncrement pp(8);
    pp++;                               //post increment
    ++pp;                               //pre increment
}

Output:

Incremented value of 'i' by postfix overloaded function : 9
Incremented value of 'i' by prefix overloaded function : 10
