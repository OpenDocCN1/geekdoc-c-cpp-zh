
The basic format to create a class in C++ is similar to the format for creating a structure in C language. In other words, a class in C++ is an evolution of the structures in C. The only difference between a structure in C and a class in C++ is that a class not only contains data but also functions. C++ also supports structures that we discuss in the next section. The syntax to declare a class is:

```cpp
class class_name
{
    // members of a class
};
```

In the preceding syntax,

- `class`: Refers to a keyword used to create a class
- `class_name`: Refers to the name of the class

The class name can be any logical name, which should reflect the information stored in the class. For example, a class name Invoice should contain invoice-related information. The class name Invoice now becomes a new data type identifier, which can be used to create an instance (object) of the Invoice class.

An instance of a class is called an object, which is created by using the name of the class, and has its unique identity in a C++ program. The process to create the objects of a class is called class instantiation. When an object is created, some part of the memory is allocated to the object. The syntax to create the objects of a class is:

```cpp
class_name obj_name;
```

In the preceding syntax,

- `class_name`: Refers to the class name
- `obj_name`: Refers to the name of the object that you want to create

You can also create multiple objects of a class in a single statement by using the following syntax:

```cpp
class_name obj_name1, obj_name2, obj_name3;
```

Objects can also be created by placing the name of the objects just after the class definition:

```cpp
class class_name
{
    // data and code
} obj_name, obj_name1;
```

In this way, objects are created in C++.

## Structure

In C++, a structure is a user-defined data type that allows you to define a data construct, which helps to store the variables of different data types. For example, suppose you want to store the first character of the name as well as the age of a person. For this, you can create your own data structure using structures in C++. These data structures are used to create new data types to declare variables.

In the following code snippet, we create a structure named person:

```cpp
struct person
{
    char first_name;
    int age;
};
```

In the preceding code snippet, the person structure is defined containing char and int type variables. Now, the following code snippet shows how a structure is used as data type to declare variables:

```cpp
#include <iostream.h>
int main()
{
    struct person
    {
        char first_name;
        int age;
    };
    person ralph;
    .
    .
    .
}
```

In the preceding code snippet, ralph is a variable name whose data type is person. You can access the members of a structure by using the dot (.) notation. Listing 7 shows the usage of (.) to access the members of a structure (you can find the STRUCTEX.CPP file on the CD in the code/chapter1 folder):

### ▶ Listing 7: Storing and Displaying Data in a Structure

```cpp
#include <iostream.h>
int main()
{
    struct person
    {
        char first_name;
        int age;
    };
    person ralph;

    ralph.first_name = 'R';
    ralph.age=39;

    cout << "The first character of person’s name is " <<
    ralph.first_name<<endl;
    cout << "The age of the person is " << ralph.age <<endl;
    return 0;

}
```

### Output:

```text
The first character of person’s name is R
The age of the person is 39
```

In Listing 7, the first character and age values are assigned in the person data structure. Then, these values are accessed and displayed.

Using this construct, you can create your own advanced data structures and treat them almost as you would a simple data structure. Structures are discussed in detail in *Chapter 5, Structures and Unions.*

## Union

*Union* is also a user-defined data type that helps you create a new data construct in which all members share the same memory location. Its declaration is syntactically similar to structures. The following code snippet shows the use of the union keyword:

```cpp
union one_union
{
    double double_variable;
    double double_variable2;
};
```

In the preceding code snippet, a union named one_union with two double variables, double_variable and double_variable2, are declared. The following code snippet shows how to create the union1 variable of the one_union type:

```cpp
#include <iostream.h>
int main( )
{
    union one_union
    {
        double double_variable;
        double double_variable2;
    };
    one_union union1;
    union1.double_variable = 3.14159;
    .
    .
    .
}
```

In the preceding code snippet, we create a variable, union1, of the one_union type and initialize it with the value 3.14159. In the one_union union, two variables, double_variable and double_variable2, are declared. Now, when these variables are accessed by using the union1 variable, both the union1.double_variable and union1.double_variable2 variables point to the same data in the memory. Listing 8 provides the code to access and display the values of the union1.double_variable and union1.double_variable2 variables (you can find the UnionEx.cpp file on the CD in the code/chapter1 folder):

### ▶ Listing 8: Using Union

```cpp
#include <iostream.h>
int main()
{
    union one_union
    {
        double double_variable;
        double double_variable2;
    } ;
    one_union union1;
    union1.double_variable = 3.14159;

    cout << "union1.double_variable = " << union1.double_variable << endl;
    cout << "union1.double_variable2 = " << union1.double_variable2 << endl;

    return 0;
}
```

### Output:

```text
union1.double_variable =3.14159
union1.double_variable2 =3.14159
```

As the members of a union point to the same location in memory, modifications in the value of one member affect the other members.

## Enumeration

An *enumeration* consists of a set of named integer constants. It allows you to name the values that a variable can take. For example, suppose you want to work with the days of the week (Sunday, Monday, Tuesday, and so on), but you do not want to refer to them with integers, such as 0, 1, 2, but instead give them real names. You can do this with an enumeration. The following code snippet lists a set of symbolic names:

```cpp
enum day
{
    Sunday,
    Monday,
    Tuesday,
    Wednesday,
    Thursday,
    Friday,
    Saturday
};
```

Now, when you create a variable of the day type, you can assign it values from the list of possible values specified by you, as shown in the following code snippet:

```cpp
#include <iostream.h>
int main( )
{
    enum day {
        Sunday,
        Monday,
        Tuesday,
        Wednesday,
        Thursday,
        Friday,
        Saturday
    };
    enum day today = Friday;
    .
    .
    .
}
```
