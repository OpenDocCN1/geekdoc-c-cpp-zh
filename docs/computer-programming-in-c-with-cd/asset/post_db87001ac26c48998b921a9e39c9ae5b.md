## Short Questions/Answers

**Q1. What are the features of OOP?**

**Ans.** OOP is a programming paradigm used to create reliable and reusable programs. OOP helps a programmer to create a modular program, which consists of reusable code that can easily be used to create other programs.

Some important features of OOP are:

- **Encapsulation:** Binds the class members (variables and methods) together and protects them from accessing by the other classes. In C++, encapsulation is implemented using a construct called class. An instance of a class is known as object, which is used to invoke various functions in a program.
- **Data Abstraction:** Hides the data, which is not required by a user to perform some specific function. In C++, class is used to implement abstraction. It is one of the most powerful features of OOP.
- **Inheritance:** Acquires the properties of one class into the other class. Inheritance is used to implement code reusability implies using the code written in one program in another program without rewriting the code. In C++, inheritance is implemented using classes. In order to achieve inheritance a class (subclass) uses the code written in another class (superclass) and creates a class hierarchy. In C++, inheritance can be used in two forms- single inheritance and multiple inheritance. In single inheritance, a subclass can inherit only one superclass. However, in multiple inheritance, a subclass can inherit more than one superclass. In multiple inheritance, a subclass inherits multiple superclasses and can use the code written in those superclasses. C++ supports both single and multiple inheritance.
- **Polymorphism:** Allows using many functions with the same name. In C++, polymorphism is implemented by using function overloading, operator overloading, and dynamic binding (virtual functions).
- **Message Passing:** Allows communication among objects in a C++ program. During object communication, messages are passed in functions, and this process is known as message passing.

**Q2. What are the advantages of OOP?**

**Ans.** OOP has many advantages. The noteworthy are as follows:

- Provides a modular programming approach that helps in reducing program complexity
- Helps build secure programs by using encapsulation and abstraction
- Uses existing classes and therefore saves a programmer's time in building a new application
- Creates new objects from an already existing class easily; therefore, upgrading a small application to a large application is also easy
- Creates applications quickly
