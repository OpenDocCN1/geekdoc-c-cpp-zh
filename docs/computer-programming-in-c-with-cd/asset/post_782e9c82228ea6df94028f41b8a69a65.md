## Describing Call by Value and Call by Reference

Calling a function in C++ can be achieved in two ways – call by value and call by reference. In call by value, the copies of variables are passed to the function; and in call by reference, the memory addresses of variables are passed to the function.

Call by value means that the value of argument is passed to a function, where value is assigned to a new variable in memory before being passed to the function. For example, the following code snippet shows a function call with call by value:

```cpp
int num1=5;
int num2=7;
swap(num1, num2);
```

In the preceding code snippet, two integer variables, `num1` and `num2`, are assigned the values 5 and 7. Then, these variables (`num1` and `num2`) are passed to the `swap()` function. The `swap()` function has prototype as shown in the following code snippet:

```cpp
void swap(int a, int b);
```

In the preceding code snippet, when the `swap()` function is called, it creates new variables `a` and `b` of int data type and then assigns the values 5 and 7 respectively.

Listing 14 shows an example of a function by using call by value. You can find the Func9.cpp file on the CD in the code/chapter3 folder:

### Listing 14: Demonstrating Call by Value

```cpp
#include <iostream.h>

int main()
{
    void swap(int, int);
    int num1=40, num2 = 60;

    cout<<"Main: Before Swap num1 = "<<num1<<" and num2 = "<<num2<<endl;
    swap(num1, num2);

    cout<<"Main: After Swap num1 = "<<num1<<" and num2 = "<<num2<<endl;
    return 0;
}
void swap(int a, int b)
{
    cout<<"Swap: Before Swap a = "<<a<<" and b = "<<b<<endl;
    int c;
    c = a;
    a = b;
    b = c;
    cout<<"Swap: After Swap a = "<<a<<" and b = "<<b<<endl;
}
```

Output:

```cpp
Main: Before Swap num1 = 40 and num2 = 60
Swap: Before Swap a = 40 and b = 60
Swap: After Swap a = 60 and b = 40
Main: After Swap num1 = 40 and num2 = 60
```

In Listing 14, the value of `num1` and `num2` variables, after execution of the `swap()` function, remains unchanged because when the `swap()` function is called, the copies of `num1` and `num2` are passed to the variables, `a` and `b`. The changes that are made to the values of `a` and `b` variables inside the `swap()` function are actually made to the copies of `num1` and `num2` variables. No changes have been made to the actual `num1` and `num2` variables. Therefore, after calling the `swap()` function, the value of `num1` and `num2` remains unchanged.

The second technique of passing argument to a function is call by reference. In this technique, you can pass arguments to a function in two ways: using pointers and using references. In both ways, the actual original object is passed into the function, and not a copy is created within the scope of the function. When you pass arguments to a function using pointer, you use the `*` operator; while using a reference, you use the `&` operator. Using the `&` operator, the address of variable is passed to a function. For example, the following code snippet shows passing of arguments to the `swap()` function by reference:

```cpp
int main()
{
    void swap(int & , int &);
    int num1=40, num2 = 60;
    cout<<"Main: Before Swap num1 = "<<num1<<" and num2 = "<<num2<<endl;
    swap(num1, num2);
    cout<<"Main: After Swap num1 = "<<num1<<" and num2 = "<<num2<<endl;
    return 0;
}
void swap(int &a, int &b)
{
    cout<<"Swap: Before Swap a = "<<a<<" and b = "<<b<<endl;
    int c;
    c = a;
    a = b;
    b = c;
    cout<<"Swap: After Swap a = "<<a<<" and b = "<<b<<endl;
}
```

In the preceding code snippet, the `swap()` function is called by reference. When the `swap()` function is called, it does not create new variables called `a` and `b`, instead the variables `a` and `b` refer to the memory location of variables `num1` and `num2`. Now, any changes made by the `swap()` function are actually made to the memory address of the `num1` and `num2` variables. Therefore, these changes are made to the actual `num1` and `num2` variables.

As we have said, another way to pass arguments to a function is using the `*` operator. The function definition of the `swap()` function is:

```cpp
void swap(int *a, int *b)
```

An example of using the `*` operator for passing arguments to a function is shown in Listing 15. You can find the Func10.cpp file on the CD in the code/chapter3 folder:

### Listing 15: Demonstrating Call by Reference

```cpp
#include <iostream.h>

int main()
{
    void swap(int *, int *);
    int num1=40, num2 = 60;

    cout<<"Main: Before Swap num1 = "<<num1<<" and num2 = "<<num2<<endl;
    swap(&num1, &num2);

    cout<<"Main: After Swap num1 = "<<num1<<" and num2 = "<<num2<<endl;
    return 0;
}

void swap(int *a, int *b)
{
    cout<<"Swap: Before Swap a = "<<*a<<" and b = "<<*b<<endl;
    int c;
    c = *a;
    *a = *b;
    *b = c;
    cout<<"Swap: After Swap a = "<<*a<<" and b = "<<*b<<endl;
}
```

Output:

```cpp
Main: Before Swap num1 = 40 and num2 = 60
Swap: Before Swap a = 40 and b = 60
Swap: After Swap a = 60 and b = 40
Main: After Swap num1 = 60 and num2 = 40
```

In Listing 15, after calling the `swap()` function, the values of the `num1` and `num2` variables are changed because when the `swap()` function is called, the compiler does not create new variables as in case of call by value. The addresses of the `num1` and `num2` variables are passed by using the `&` operator and the value is accessed by using the `*` operator in the `swap()` function. In the `swap(&num1, &num2)` function, the addresses of the `num1` and `num2` variables are passed as arguments and the swapping of values is done on the same memory location of the `num1` and `num2` variables. Therefore, after calling `swap()` function, the values of `num1` and `num2` are changed.
