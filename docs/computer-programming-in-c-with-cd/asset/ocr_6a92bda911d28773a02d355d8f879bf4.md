# 7.6 Invoking Constructors and Destructors of Base and Derived Classes

As we know constructors are used to initialize the data members of a class and allocate the required memory to the data members. Destructors, on the other hand, are used to de-initialize the data members. Now, the question arises, what happens when the base as well derived classes have their own constructors and destructors? Are the constructors and destructors of the base class are overridden? In such a case, remember that a derived class does not require a constructor or destructor as long as the base class has a default constructor and destructor. However, if the base class has a constructor with one or more parameters, then it is mandatory for the derived class to have a constructor with parameters and to pass the arguments to the base class constructor explicitly. In the application of inheritance, usually objects of the derived class instead of the base class are created.
