## Operator Associativity

Operators are associated in an expression either on the left or right of the expression; in C++, this is called associativity. When several operators of the same level are used in an expression, then the C++ compiler executes the operators on the basis of their associativity. For example, as multiplication and division associate left to right, in the expression 12/6 * 4, therefore in this case, the C++ compiler will apply the left hand operator first. ## Streams in C++

A stream is a sequence of bytes that can either serve as the source from which the input data can be obtained or a destination to which the output data can be sent. The stream that serves as the source from which the data is taken is known as the input stream and the destination stream, that is, the stream to which the data is sent, is known as the output stream. In other words, a C++ program retrieves the bytes from an input stream and inserts the bytes into the output stream.

Now, let's discuss the following topics to gain insight knowledge about the streams in C++:

- The ios member functions
- Manipulators

### The ios Member Functions

The ios member functions are used to format the output of a C++ program. These ios member functions are stored in the ios class, which provides basic support for formatted as well as unformatted input and output operations. The noteworthy ios member functions are as follows:

- The width() function
- The precision() function

Now, let's discuss each of them in detail.

### The width() Function

The width() function is used to specify the width of the field required to display an output. This function is stored in the iostream header file; therefore, you need to include this header file in your program to use the width() function.
