# **Q7.** What is the output of the following program?

```
```cpp
#include <iostream.h>

class MyClass {
    int a;
protected:
    int b;
public:
    int c;
    MyClass(int n, int m) {
        a = n;
        b = m;
    }
    int geta() {
        return a;
    }
    int getb() {
        return b;
    }
};

int main()
{
    MyClass object(10, 20);
    object.c = 30;
    cout << object.geta() << ' ';
    cout << object.getb() << ' ' << object.c << '\n';
    return 0;
}
```
```

**Ans.** Output of the preceding program is as follows:

```
```text
10 20 30
```
