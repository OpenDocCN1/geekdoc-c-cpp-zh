## Creating Nested Structure

A structure within a structure is known as a nested structure. It means that the member of a structure can also be a structure variable of another structure. Now, consider the following example to illustrate nested structure, which contains groups of data members, such as day, month, and year into date structure as follows:

```cpp
struct date
{
    int day;
    int month;
    int year;
};
```

This date structure can be nested structure of the employee structure as shown in following code snippet:

```cpp
struct employee
{
    char name[30];
    int age;
    float salary;
    date join_date;
};
```

In the preceding code snippet, the variable of the date structure (join_date) is created as a member of the employee structure. In other words, we can say that the date structure is nested inside the employee structure. The data member hierarchy of both the structures - date, and employee is shown in Figure 1:

In Figure 1, you see that the structure employee, is the main structure that takes instance of the date structure as its member. In this case, you can say that the date structure is nested inside the employee structure.

## Creating Structure inside the Function

Now, you are familiar with the structures that are created globally so that they can be accessed from any place within the program code. However, sometimes you may require that a structure should be used by a specific function or part of the C++ program. For this, you need to create the structure inside the function body. For example, you want to create a structure called My_Structure that can be accessed with the function called My_Function. Now, write the following code snippet to create such a structure:

```cpp
void My_Function ()
{

    struct My_Structure          //declaring structure
    {
        int new_age;
        char name[20];
    };                          // end of structure
    My_Structure ms;            //creating instance of structure within the
                                // function body
    ms.new_age = 25;            // initializing structure member.
    ms.name[0] = 'D';
    ms.name[1] = 'h';
    ms.name[2] = 'e';
    ms.name[3] = 'e';
    ms.name[4] = 'r';
    ms.name[5] = 'a';
    ms.name[6] = 'j';
}                               // end of the function
```

In the preceding code snippet, you have created a function My_Function and a structure My_Structure inside it. You have also created the instance of the My_Structure structure inside the My_Function function and initialized the structure members.
