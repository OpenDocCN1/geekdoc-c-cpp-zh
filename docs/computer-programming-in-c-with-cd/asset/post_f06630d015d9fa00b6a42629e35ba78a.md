The number of arguments in both types of functions (member functions and friend functions) is different, because of the this pointer. The object that is used to invoke the member function is passed implicitly (using the this pointer), and therefore is available for the member function. However, this is not the case with the friend function, as it is not a part of class declaration.

Table 1 describes syntaxes to overload unary and binary operators either as a member function or as a friend function of a class:

| Syntax | Description |
|---|---|
| `ClassName operator −();` | Overloads a unary operator as a member function of a class |
| `ClassName operator +( ClassName);` | Overloads a unary operator as a friend function of a class |
| `friend ClassName operator −( ClassName);` | Overloads a binary operator as a member function of a class |
| `friend ClassName operator +( ClassName, ClassName);` | Overloads a binary operator as a friend function of a class |

Note that although operator overloading enhances the functionality of an operator, it does not change its syntax. The following are the restrictions that must be followed while overloading an operator:

- It is not possible to change the precedence of execution for operators
- It is not possible to create new operators
- It is not possible to change the number of operands

Table 2 describes operators that cannot be overloaded:

**Table 2: Operators Cannot Be Overloaded**

| **Operator** | **Description** |
|---|---|
| `.` | The direct member selection operator |
| `.*` | The de-reference pointer to class member operator |
| `?:` | The conditional operator |
| `::` | The scope resolution operator |
| `sizeof` | The sizeof operator |

Table 3 lists operators that should not be overloaded, because they destroy the meaning of the built-in operators:

**Table 3: Operators Not To Be Overloaded**

| **Operator** | **Description** |
|---|---|
| `&&` | The AND logical operator |
| `\|\|` | The OR logical operator |
| `,` | The comma operator |

Some important points that must be followed when performing operator overloading are:

- Only existing operators can be overloaded.
- The overloaded operators must have at least one operand, that is of user-defined type.
- You cannot change the meaning of an operator. It means, you cannot redefine the addition operator (`+`) to subtract one value from the other.
- Overloaded operators follow the syntax rules of the original operators that cannot be overridden.
- You cannot use friend functions to overload certain operators. Table 4 lists the operators that cannot be overloaded with friend functions:

**Table 4: Operators that Cannot Be Overloaded with Friend Functions**

| **Operators** | **Description** |
|---|---|
| `=` | Assignment operator |
| `()` | Function call operator |
| `[]` | Subscripting operator |
| `->` | Class member access operator |

## Overloading of Unary Operators

Overloading without explicit arguments to an operator function is known as unary operator overloading. Listing 41 shows the overloading of minus (-) operator (you can find this example in the UnaryOperator.cpp file on the CD in the code\chapter6 folder):

### Listing 41: Overloading of Minus (-) Operator as a Member Function

```cpp
#include<iostream.h>

class NegativeNumberShow
{
  int num1,num2;
public:
  void operator -();
  NegativeNumberShow(int,int);
  void disp();
};
void NegativeNumberShow::operator -()
{
  num1=-num1;
  num2=-num2;
}
NegativeNumberShow::NegativeNumberShow(int i,int j)
{
  num1=i;
  num2=j;
}
void NegativeNumberShow::disp()
{
  cout<<"The value of 'num1' is :"<<num1<<endl;
  cout<<"The value of 'num2' is :"<<num2<<endl;
}

int main()
{
  NegativeNumberShow n(2,27);
  n.disp();
  -n;
  n.disp();
  return 0;
}
```

```text
Output:

The value of 'num1' is :2
The value of 'num2' is :27
The value of 'num1' is :-2
The value of 'num2' is :-27
```

In Listing 41, the operator function is a member function of the NegativeNumberShow class, and has no parameter. The minus (-) operator is overloaded by using the following code snippet:

```cpp
void operator -();
```

The preceding code snippet creates a prototype of the operator function -() in the NegativeNumberShow class. Note the use of the operator keyword. The operator function is initialized outside the class using the :: operator, as shown in the following code snippet:

```cpp
void NegativeNumberShow::operator -()
{
    num1=-num1;
    num2=-num2;
}
```

The statements in the following code snippet call the operator function:

```cpp
NegativeNumberShow n(2,27);
-n;
...
```

In the preceding code snippet, the C++ compiler understands the -n; expression as the n.operator -(); expression.

With friend functions, however, unary operators take one reference argument (the object of the relevant class). Listing 42 shows the overloading of minus(-) operator, where operator function is a friend function having an argument (you can find this example in the UnaryFriendOperator.cpp file on the CD in the code\chapter6 folder):

### Listing 42: Overloading of Minus(-) Operator As a Friend Function

```cpp
#include<iostream.h>
class NegativeNumberShow
{
    int num1,num2;
public:
    NegativeNumberShow (){}
    NegativeNumberShow (int i,int j)
    {
        num1=i;
        num2=j;
    }
    friend void operator -(NegativeNumberShow &n);
    void disp()
    {
      cout<<"The value of 'num1' is :"<<num1<<endl;
      cout<<"The value of 'num2' is :"<<num2<<endl;
    }
};
void operator -(NegativeNumberShow &n)
{
  n.num1=-n.num1;
  n.num2=-n.num2;
}
int main()
{
  NegativeNumberShow n(2,27);
  n.disp();
  -n;
  n.disp();
  return 0;
}
```
