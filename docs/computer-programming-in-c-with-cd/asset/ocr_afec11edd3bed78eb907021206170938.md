# Special Operators

Special operators are used to perform operations such as calculating the size of variables, accessing global variables, in C++. The special operators available in C++ are:

+   - The sizeof operator
+   - The comma operator
+   - The Scope Resolution operator (SRO)
+   - Dereferencing operators
+   - Memory Management operators

# The sizeof Operator

The sizeof operator determines the number of bytes used by an object or raw data types (such as int, char, short) in memory. The operand may be a variable, a constant or a data type qualifier. The sizeof operator is normally used to determine the length of arrays and structures when their size are not known to the programmer. It is also used to allocate memory space dynamically to variables during the execution of a program.
