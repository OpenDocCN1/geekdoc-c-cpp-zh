In the preceding syntax, `class` is a keyword that is followed by the name of a class, ClassName. The `class` keyword indicates that the ClassName class is an abstract data type, which specifies the type and scope of its members. The body of a class is enclosed within the curly braces followed by a semicolon at the end of the class declaration. The following code snippet shows the specification of a class called Student:

```
#include<iostream.h>

/* the declaration of a class */
class Student
{
// body of a class
};
```

The following are the rules that must be followed while naming a class:

+   - A class name must begin with a letter, which may be followed by a sequence of letters or digits (0-9) or _. The first character in a class name cannot be a digit.
+   - The name of a class must not contain any embedded space or symbol, such as ? - + ! @ # % ^ & * ( ) [ ] { } . comma (,) : ; " ' ` / and \. However, an underscore (_) can be used wherever a space is required.
+   - A keyword cannot be used for a class name. For example, you cannot declare a class called `class`.

A class name must follow certain naming conventions or guidelines. These guidelines are as follows:

+   - The name of a class should be meaningful. For instance, the class names, such as Animal, Employee, or Account are meaningful. However, the class names, such as wxz and _gggnn are meaningless.
+   - The name of a class should ideally be a noun. For instance, the name of a class related to students can be Student and the name of a class related to various geometrical shapes can be Shape.
+   - If the name of a class contains more than one word and does not use underscores, the first letter of every word should be in upper case. For example, the name of a class storing the marks obtained by students can be StudentScoreCard and the name of a class storing the salary composition can be SalaryComponents.
