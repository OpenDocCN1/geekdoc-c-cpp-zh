However, in the case of destructor, this order is reversed, that is, the destructor of the derived class is executed first and then the destructor of the base class is executed.

## 7.7 Creating Container Classes

A container class is an object holder for other classes. It represents an indirect way of inheriting the properties of one class into another class. This means that an object of a container class is a collection of several other objects. The purpose of creating a container class is to hold multiple instances of another class. The syntax to create a container class is:

```cpp
class Class_Name
{
};
class ContainerClass_Name
{
Class_Name object_name;
};
```

In the preceding syntax, ContainerClass_Name represents the name of a container class that contains the declaration of the object_name object of the Class_Name class.
