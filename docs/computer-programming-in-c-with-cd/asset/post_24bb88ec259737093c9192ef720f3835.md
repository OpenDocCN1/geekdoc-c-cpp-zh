## 7.8 Explaining the Forms of Inheritance

In inheritance, a derived class may itself be a base class from which other classes can be derived. This process allows the reusability of code. There is no specific limit on the number of classes that may be derived from one another. In addition, more than one class can be inherited from a single base class. Therefore, based on the level of a base class and the number of base and derived classes, inheritance is classified into the following forms:

- Single inheritance
- Multilevel inheritance
- Hierarchical inheritance
- Multiple inheritance
- Hybrid inheritance

Let's discuss these forms one by one in the following sections, starting with single inheritance.

A form of inheritance where a derived class is inherited from one base class is called single inheritance, as shown in Figure 2:

```cpp
#include<iostream.h>
class A
{
protected:
    int a;
};
class B:public A
{
    int b;
public:
    void display()
    {
        a=10;
        b=20;
        cout<<"Base class variable calling"<<endl;
        cout<<"Value in variable a="<<a<<endl;
        cout<<"Derive class variable calling"<<endl;
        cout<<"Value in variable b="<<b<<endl;
    }
};
int main()
{

    obj.display();
    return 0;
}
```

```text
Value in variable a=10
Derive class variable calling
Value in variable b=20
```

In Listing 14, class B is the only class that is inherited from class A. The A class has a protected variable, called a; while the B class has a private variable, b, and a public function, display(). Within the main() function, an object, obj, of class B is created, which invokes the display() function.
