## 2.2 Working with Conditional Statements

A conditional statement is a control statement that allows you to choose between two or more execution paths in a program. Conditional statements cause a program to execute a block of code after evaluating a given conditional expression. If the conditional expression comes out to be true, the accompanying block of code is executed; otherwise, the block of code is bypassed. The following is the list of the conditional statements supported by C++:

- if statement
- if-else statement
- Nested if statements
- if-else ladders
- switch statement
- Nested switch statement

Let’s now discuss these statements in detail.

### Using the if Statement

The `if` statement executes code depending on whether or not an expression is true or false. The code following the conditional expression is executed only if the expression in the `if` statement is evaluated to be true; otherwise, the program control passes to the next statement.

The following is the syntax of the `if` statement:

```cpp
if(conditional expression)
<Statements to be executed when conditional expression evaluated to true>;
```

When conditional expression returns false value, the control of the program goes to the next statement skipping the current statement, which should be executed when condition expression returns true value. Listing 11 shows an example to use the `if` statement (you can find this example in the `ifStatement.cpp` file on the CD in the `code\chapter2` folder):

### Listing 11: Using the `if` Statement

```cpp
#include<iostream.h>

int main()
{
  int age;
    cout<<"Enter your age"<<endl;
    cin>>age;
  if(age<18)
    cout<<"You are not eligible to vote"<<endl;
  if(age>=18)
    cout<<"You are eligible to vote"<<endl;

  return 0;
}
```

### Output 1: When the value supplied is less than 18

```text
Enter your age
17
You are not eligible to vote
```

### Output 2: When the value supplied is greater than or equal to 18

```text
Enter your age
24
You are eligible to vote
```

In Listing 11, the value supplied at run-time is set in a variable, named `age`. The statement following the first `if` statement gets executed (Output 1) when the conditional expression (`age<18`) evaluates to true. In case the age supplied at run-time is greater than or equal to 18, the statement following the second `if` statement gets executed (Output 2).

### Using the if-else Statement

Using the `if-else` statement, a block of code is executed if the condition is true and another block of code is executed if the condition is false. This means that the `if` clause is executed when the condition is true, and the `else` clause is executed when the condition is false. The following is the syntax of the `if-else` statement:

```cpp
if (conditional expression)
//Statement1 to be executed in case conditional expression is true;

else
//Statement2 to be executed in case conditional expression is false;
```

In the preceding syntax, when the condition specified after the `if` statement is true, then Statement1 is executed; otherwise, Statement2 is executed.

Listing 12 shows the use of the `if-else` statement as a better alternative than using multiple if statements (you can find this example in the `if-elseStatement.cpp` file on the CD in the `code\chapter2` folder):


In Listing 12, the value supplied at run-time is set in a variable, named age. The statement following the `if` statement gets executed when the conditional expression (age<18) evaluates to true. In case the conditional expression (age<18) evaluates to false, the statement following the `else` clause gets executed.
