### Q4. What are library functions and linkers in C++?

Ans. Library functions are predefined C++ functions that simplify a programmer's task. For example, if a programmer wants to create a program to calculate the length of a string, then the programmer needs to write the code. On the other hand, in C++, the strlen() function is a library function used to calculate the length of the specified string. Using library functions in C++ programs, you can simplify the work and reduce the chance of errors in your programs.

In C++, library functions are stored in various other files that must be included in your C++ program. For example, to use the cout object, you need to include the iostream.h header file in your C++ program. Now, link this file with source code to produce an executable file. The process to link the header file with the source code is done by linkers. Compilers that are used to generate executable file from source code also have linkers, which links the source code with header files.

### Q5. What are tokens in C++?

Ans. The elements that are predefined in the C++ library and are meaningful for the C++ compiler are known as tokens. In C++, tokens are separated by white spaces, which include blanks, tabs, and new lines. Tokens that are available in C++ are:

- Keywords: Predefined or reserved terms used in C++.
- Identifiers: Names of the variables, functions, constants, and classes given by a programmer.
- Comments: Not executed by the compilers. Mostly comments are written for describing the code.
- Constants: Fixed values that cannot be changed.
- Variables: Stores and represents specific type of information within a program.
- Data types: Specifies the type of a variable according to the value a programmer wants to store.
- Preprocessor Directives: Helps you perform operations such as including header files in a C++ program so that you can utilize the functions stored in header files.
- Operators: Symbols that are used to perform operations, such as addition, subtraction, multiplication, or division on the values stored in various variables.

### Q6. What are the various categories of constants?

Ans. Constants in C++ are fixed values that cannot be modified. The constants in C++ can be divided into the following major categories:

- Integer Constants: Consists of digits only, no fractional data. The size of an integer constant depends on the integer data type used with the variable name.
- Floating Point Constants: Consists fractional data and can also contain exponents. The floating point constants are also known as real constants.
- Character Constants: Contains single character enclosed in single quotes.

### Q7. What do you mean by data types? What are the main categories of data types in C++?

Ans. Data types are a very important part of any programming language, as you cannot even declare variables without them. The term data type is used to specify the type of variable, which means we have to specify that what kind of data a variable will store. ### Q9. What do you mean by User-Defined data types?

Ans. In C++ you can create and use your own data types; these data types are known as user-defined data types. Some C++ keywords, such as struct and union are used to create user-defined data types. The following are the user-defined data types that you can create in C++:

- **Class:** Consists of data (variables) and code (functions) that work on the data.
- **Structure:** Allows defining a data construct, which helps store variables of different data types.
- **Union:** Creates a new data construct in which all members share the same memory location.
- **Enumeration:** Allows you to provide a name to the values that a variable of that type can take.

### Q10. What do you mean by derived data types?

Ans. The data types that can be created from existing data types are known as derived data types. The following are the derived data types that are available in C++:

- **Arrays:** A collection of data storage locations, each of which holds the same type of data.
- **Pointers:** A variable that stores the memory address of another variable. A pointer is similar to other variables in C++ and needs to be declared before being used.

### Q11. What are preprocessor directives?

Ans. Preprocessor directives help you perform operations such as including header files in a C++ program so that you can utilize the functions stored in header files and define constants. Preprocessor directives are handled before the code is passed to the C++ compiler. The C++ compiler includes a preprocessor that handles preprocessor directives before the C++ compilation process starts. The following are the allowed preprocessing directives in standard C++:

- `#define`: Defines a macro/token
- `#elif`: Represents the else-if directive that works similar to the else-if statement
- `#else`: Represents the else directive and works similar to the else statement
- `#error`: Produces compile-time error messages
- `#if`: Represents the if directive which works similar to the if statement
- `#ifdef`: Represents the if-defined directive used to test the existence of a macro
- `#ifndef`: Represents the if-not-defined directive
- `#include`: Helps to include a file in the C++ program
- `#line`: Represents the current line directive
- `#pragma`: Represents the special function that runs before the rest of the code
- `#undef`: Undefines the defined macro

### Q12. What do you mean by operators in C++?

Ans. Operators are symbols that are used to perform operations, such as addition, subtraction, multiplication, or division based on the values stored in various variables. The various operators in C++ are:

- **Unary Operators:** The operators that work on a single operand are called Unary operator. The operand on which a unary operator works can be a constant or variable.
- **Binary Operators:** The operators that work on two operands are called binary operators. Some of the binary operators are Arithmetic operators, Assignment operators, Arithmetic Assignment operators, Relational operators, Logical operators, and Bitwise operators.
- **Shift Operators:** Shift operators are used to shift the bit pattern to left or right the operand. The operand should be an integral value. C++ supports right shift (`>>`) and left shift (`<<`) operators.
- **Ternary Operators:** The C++ operator that works as an alternative of the if-else statement is known as ternary operator. It is known as ternary operator because it works on three operands.
- **Special Operators:** There are some operators that are used to perform operations such as calculating the size of variables, accessing global variables, are known as special operators. The special operators in C++ are the sizeof operator, the comma operator, the scope resolution operator (SRO), dereferencing operators, and memory management operators.

### Q13. What do you mean by stream?

Ans. A stream is a sequence of bytes that either serves as the source from which the input data can be obtained or a destination to which the output data can be sent. The stream that serves as source from which the data is taken is known as input stream and the destination stream, to which the data is sent is known as output stream. In other words, a C++ program retrieves the bytes from an input stream and inserts bytes to the output stream.
