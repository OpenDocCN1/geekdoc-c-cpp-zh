# ▶ Listing 14: Showing Multiple Statements within the `if` Statement

```
```cpp
#include<iostream.h>
void main()
{
    int num;
    cout<<"Enter number: ";
    cin>>num;
    if(num<50)
    {
        int less=50-num;
        cout<<"The number is less than 50"<<endl;
        cout<<"You have to increase the number by " <<less<< " to make it 50";
    }
}
```
```

**Output:**

```
```text
Enter number: 40
The number is less than 50
You have to increase the number by 10 to make it 50
```
```

In Listing 14, the program prompts you to enter a number. The if statement verifies the conditional expression. If the condition is true, the statements within the braces are executed.

If the braces are not used and the if condition is true then the C++ compiler will execute only the immediate next statement to the if statement.
