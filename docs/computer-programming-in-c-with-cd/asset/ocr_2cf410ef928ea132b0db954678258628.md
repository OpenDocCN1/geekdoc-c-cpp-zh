Note that the result of the cube1(5) macro and the cube2(5) inline function is same and that is 125. However, the result of the cube1(5+10) macro and the cube2(5+10) inline function is different, that is, 115 and 3375, respectively. This is because, the cube1(5+10) macro is evaluated as 5+10*5+10*5+10; whereas, the cube2(5+10) inline function is evaluated as 15*15*15.

You are advised to use an inline function, instead of a macro, because of following reasons:

+   - The invocation of a macro does not perform the type-checking; whereas, the calling of an inline function performs the type-checking
+   - A macro cannot use the return keyword; whereas, an inline function can use the return keyword

# 6.6 Working with Constructors and Destructors

Constructor and destructor are special member functions of a class that are used to initialize or de-initialize the member variables, respectively, of a class. When you create an object of a class, you need to allocate memory to the object. However, the allocation of memory does not ensure the initialization of the member variables within the object. The member variables within a class cannot be initialized at the time of declaring a class. For example, the initialization of the member variables in the following code snippet is invalid:

```
class GreatestNumber
{
  int variable=10;
  int variable=20;
};
```
