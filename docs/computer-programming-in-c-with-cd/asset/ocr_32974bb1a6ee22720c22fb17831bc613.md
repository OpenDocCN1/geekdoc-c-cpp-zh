A prototype of the Time class is declared, because the forward reference of this class is passed in the declaration of the displayDateTime() function of the Date class. Note that the forward reference of a class means using a class before defining it. The C++ compiler generates a syntax error when it finds such a forward reference. Therefore, you must declare a prototype of the Time class before using its reference in the displayDateTime() friend function.
