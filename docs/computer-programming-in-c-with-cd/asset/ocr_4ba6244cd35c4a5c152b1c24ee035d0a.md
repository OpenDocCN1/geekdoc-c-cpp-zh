# 4.4 Returning Pointers from a Function

We know that a function can only return a single value. However, it can return multiple values by using pointers. We have to declare pointers as return type of a function, so that the function can return multiple values. However, the function can return a pointer variable only when the function must use a pointer variable and initialize this pointer variable to reference an array element inside its body structure. We know that a pointer variable contains the address of first element of an array. Therefore, a function returns the address of first element of an array, so that we can easily access and perform manipulation with the rest of the elements. As the address of the second element of an array can be easily accessed by incrementing the index value of the first element of an array. Listing 13 shows a program to demonstrate a function that returns an array (you can find the `ReturnPointer.cpp` file on the CD in the `code\chapter4` folder):
