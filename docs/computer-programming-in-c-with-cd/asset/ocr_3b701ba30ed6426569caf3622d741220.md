# Overloading of Unary Operators

Overloading without explicit arguments to an operator function is known as unary operator overloading. Listing 41 shows the overloading of minus (-) operator (you can find this example in the UnaryOperator.cpp file on the CD in the code\chapter6 folder):

# Listing 41: Overloading of Minus (-) Operator as a Member Function

```
#include<iostream.h>

class NegativeNumberShow
{
  int num1,num2;
public:
  void operator -();
  NegativeNumberShow(int,int);
  void disp();
};
void NegativeNumberShow::operator -()
{
  num1=-num1;
  num2=-num2;
}
NegativeNumberShow::NegativeNumberShow(int i,int j)
{
  num1=i;
  num2=j;
}
void NegativeNumberShow::disp()
{
  cout<<"The value of 'num1' is :"<<num1<<endl;
  cout<<"The value of 'num2' is :"<<num2<<endl;
}

int main()
{
  NegativeNumberShow n(2,27);
  n.disp();
  -n;
  n.disp();
  return 0;
}
```
