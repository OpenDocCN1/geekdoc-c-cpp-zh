Apart from accessing value stored in the referenced variable, a pointer can also set the data in the variable that it points to. Listing 3 shows how to set a value of a variable by using pointer (you can find the `AssignValue.cpp` file on the CD in the `code\chapter4` folder):

# ▶ Listing 3: Assigning Value to the Variable Using Pointer

```
#include <iostream.h>
void main()
{
  int var,*ptr; //declaring an integer and integer pointer variable
  ptr = &var;// assign the address of the variable to pointer variable
  *ptr= 2; //dynamically store value to the variable referenced by pointer variable
  cout<<"The value set to the variable var using the pointer variable is:"<<*ptr;//printing the value
}
```

**Output:**

The value set to the variable var using the pointer variable is:2

In Listing 3, we have assigned a reference of variable `var` to the pointer variable `ptr` using the reference operator (&). The variable `var` that is pointed by the pointer variable `ptr` is assigned with a value 2. The value of variable `var` is displayed on the screen using the pointer variable `ptr`.
