## Declaring and Using Destructors

In C++, you can destroy an object if it is not needed by using destructors. A destructor is another special member function of a class. It is invoked to destroy an object of a class. The destructor function has the same name as that of the class name but is prefixed by a tilde (~) symbol. The tilde symbol distinguishes it from a constructor of the same class. Listing 19 shows how to declare a destructor within a class (you can find this example in the SimpleDestructor.cpp file on the CD in the code\\chapter6 folder):

### Listing 19: Declaring a Destructor

```cpp
#include<iostream.h>

class NumberInitialization
{
  int x,y;
  public:
  NumberInitialization();  //constructor prototype
  ~NumberInitialization(); //destructor prototype
};
NumberInitialization::NumberInitialization()
{
  cout<<"Default constructor calling"<<endl;
  x=1;
  y=2;
  cout<<"x="<<x<<endl;
  cout<<"y="<<y<<endl;
}
NumberInitialization::~NumberInitialization()
{
    cout<<"Destructor calling"<<endl;
    x=0;
    y=0;
    cout<<"x="<<x<<endl;
    cout<<"y="<<y<<endl;
}
int main()
{
    NumberInitialization n1;
    cout<<"Program Over\n";
    return 0;
}
```

### Output:

```text
Default constructor calling
x=1
y=2
Program Over
Destructor calling
x=0
y=0
```

If an object is local and non-static variable, the destructor is called when the function in which the object is defined is about to terminate. However, if an object is static and global variable, the destructor is called before the program terminates. Moreover, when a program is interrupted using the `exit()` function call, the destructors are called for all the objects that exit at that time.

![](img/8a6886c00caa6a1651a6c0e62bff341f_377_0.png)

> *A destructor can be called explicitly, as shown in the following code snippet:*
>
> ```cpp
> n1.~NumberInitialization();       // Explicit destructor invocation
> ```

However, a destructor need not be invoked explicitly as the system automatically invokes it when an object goes out of scope.

Destructors have the following characteristics:

- The names of the destructors must be the same as that of their class name
- A destructor should have public access in the class declaration
- Destructors do not have return types, and therefore, cannot return values
- Destructors can be `virtual`
- There can be only one destructor in each class. This is because there is only one way to destroy an object.
- Destructors do not take arguments, therefore, they cannot be overloaded.

Let’s now explain how to invoke a constructor and destructor of a class globally.

## Invoking Global Constructor and Destructor

The objects of a class can be defined as global, within a program, with the help of global variables. The global object gets created before entering into the main() function and destroyed after the main() function exits. This creation and destruction of the global object is done by invoking the global constructors and global destructors. Listing 21 shows how to invoke a global constructor and a global destructor (you can find this example in the GlobalConsDest.cpp file on the CD in the code\chapter6 folder):

### Listing 21: Invoking Constructor and Destructor of a Class Globally

```cpp
#include<iostream.h>
class ConsDesCall
{
public:
  ConsDesCall()
  {
    cout<<"Constructor called"<<endl;
  }
  ~ConsDesCall()
  {
    cout<<"Destructor called"<<endl;
  }
};
ConsDesCall o1;
int main()
{
    cout<<"Main begins"<<endl;
    ConsDesCall o2;
    {
        cout<<"Inner block begins"<<endl;
        ConsDesCall o3;
        cout<<"Inner block ends"<<endl;
    }
    cout<<"Main ends"<<endl;
    return 0;
}
```

### Output:

```text
Constructor called
Main begins
Constructor called
Inner block begins
Constructor called
Inner block ends
Destructor called
Main ends
Destructor called
Destructor called
```

In Listing 21, the order of constructors and destructors, invoked with the creation of various instances of the ConsDesCall class, is explained as follows:

The object, o1, has global scope and its constructor is executed before the execution of the main() function begins. The object, o2, has function or local scope and its constructor is executed after the execution of the main() function begins. The object, o3, has block scope and its constructor is executed after the execution of the inner block begins. The destructor of the o3 object is invoked when the execution of the inner block ends. The destructor of the o2 object is invoked when the execution of the main() function ends. The destructor of the o1 object is invoked when the program ends, because the object is declared as a global variable.
