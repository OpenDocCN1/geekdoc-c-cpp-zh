+   - Compiler: Converts the source code of a program into an executable file. An executable file consists of the binary form of the source code. In other words, a compiler converts a C++ program into machine-readable format. Various compilers are available on the Internet for free download. The most commonly used C++ compilers are:
+     - The Turbo C/C++ compiler
+     - The Borland C++ compiler
+     - The Linux/Unix compiler, that is, the GNU C++ compiler
+   - Data types: Assigns a type to a variable to store particular data in it. For example, a variable of the data type int can only store an integer value in it.
+   - Identifier: Refers to the names that a programmer gives to variables, functions, constants, and classes.
+   - Operator: Refers to symbols, such as +, -, *, and /, which are used to perform the addition, subtraction, multiplication, or division operations, respectively.
+   - Function: Refers to a part of a program where the code is written to perform a specific task. A program may consist of many functions defined by a programmer.
+   - Preprocessor Directive: Allows you to include header files in a C++ program.
+   - Error: Refers to an unwanted condition, which interrupts program execution. Errors are of two types, a syntax error and a logical error. A syntax error occurs when you write something in a program, which the compiler is unable to read. For example, writing INT instead of int to declare a variable, which the compiler cannot understand. A C++ compiler can only detect syntax errors, not logical errors. A logical error is an error made by a programmer. For example, the programmer may be mistaken when they code to add two or more numbers that are to be multiplied. In this case, a compiler does not generate any error but the program’s output is not as per the requirements.

# C ++ Library Functions and Linkers

Library functions are predefined C++ functions that are used to simplify a programmer's task. For example, if the programmer wants to create a program to calculate the length of a string (in C), the programmer needs to write the code. On the other hand, the programmer can use the strlen() function in C++, which is a library function used to calculate the length of the specified string. Using library functions in C++ programs simplifies the work and reduces the possibility of errors. In C++, library functions are stored in various files that need to be included in a C++ program. For example, to use the cout object, you need to include the iostream.h header file in the C++ program. Now, link this file with the source code to produce an executable file. Linkers perform the process of linking the header file with the source code. Compilers that are used to generate executable files from the source code also have linkers, which link the source code with the header files.
