## 2.3 Working with Iteration Statements

Iteration statements or loops repeatedly execute a block of code based on a condition, as long as the condition evaluates to true. Once the conditional expression evaluates to false, the loop exits. After that, the control transfers to the next statement that follows the loop. The following are the iteration statements supported by C++:

- The while loop
- The do-while loop
- The for loop

Let’s now discuss about each of these statements in detail.

### Using the while Loop

A while loop executes statements until the condition with the while loop evaluates to true. Once the condition becomes false, the loop gets terminated. The following is the syntax of the while loop:

```cpp
while (conditional_expression)
{
    Statements to be executed;
}
```

In the preceding syntax, the `conditional_expression` is first tested. If the `conditional_expression` is true, the statements within the body of the `while` loop are executed. These statements are executed repeatedly until the `conditional_expression` is true. Whenever the `conditional_expression` evaluates to false, the loop gets terminated. Listing 18 shows the use of the `while` loop (you can find this example in the `whileloop.cpp` file on the CD in the `code\chapter2` folder):

**▶ Listing 18: Using the `while` Loop**

```cpp
#include<iostream.h>

int main()
{
    int value,factorial,temp;
    factorial=1;
    cout<<"Enter a number"<<endl;
    cin>>value;
    temp=value;

    while(temp>0)
    {
        factorial*=temp--;
    }
    cout<<value<<"!="<<factorial<<endl;
    return 0;
}
```

**Output:**

```text
Enter a number
4
4!=24
```

In Listing 18, the statement inside the `while` loop continues to execute until the value stored in the `temp` variable becomes zero. When the value stored in the `temp` variable becomes zero, then the `while` loop exits and displays the factorial of number (4).

The `while` loop can also be written without the braces. The `while` loop without braces can only execute the statement defined immediately next to the loop. Braces in the `while` loop is required to execute the multiple statements. ### Using the do-while Loop

The `do-while` loop executes a group of statements as long as the specified condition is true. If the condition becomes false, the flow of execution comes out of the `do-while` loop. As you know, the `while` loop is used to check the condition first and then the body of loop is executed. The `do-while` loop is used where the body of loop is executed first, then the condition is checked. The following is the syntax of the `do-while` loop:

```cpp
do
{
    statements;
} while(conditional_expression);
```

In the preceding syntax, the `statements` statement is followed by the `while` keyword and a conditional expression to be evaluated for a Boolean value. In case the evaluation returns true, the control goes back to the `do` keyword and continues until the evaluation becomes false. Listing 21 shows the use of the `do-while` loop (you can find this example in the `do-whileloop.cpp` file on the CD in the `code\chapter2` folder):

**▶ Listing 21: Using the do-while Loop**

```cpp
#include<iostream.h>

int main()
{
    int num;
    do{
        cout<<"Enter a number"<<endl;
        cin>>num;
    }
    while(num%2!=0);
    cout<<"It is an even number"<<endl;
    return 0;
}
```

**Output:**

```text
Enter a number
3
Enter a number
5
Enter a number
4
It is an even number
```

In Listing 21, the program prompts you to enter a number that gets stored in the `num` variable. The program evaluates whether or not the value stored in the variable is an even number. In case, the evaluation returns true, the control goes back to the `do` keyword and continues the execution of do-while loop until the evaluation becomes false.

The `do-while` loop can also be written without the braces. The simple `do-while` loop without braces can only execute the statement defined immediately next to the loop. Braces in the `while` loop is required to execute multiple statements. ### Using the for Loop

The for-loop iterates over a fixed number of times and consists of three parts, such as initialization, conditional expression, and post expression. The following is the syntax of the for-loop:

```cpp
for(initialization;conditional_expression;post_expression)
```

In the preceding syntax, the initialization initializes the variable with a value. The initialization part occurs once, which is followed by the conditional expression. If the conditional expression evaluates to false, then the statement following the for-loop is evaluated. If the conditional_expression evaluates to true, then the body of the for-loop is executed. The post_expression is used to increment or decrement a counter variable controlling a loop. The for-loop continues to execute until the conditional_expression evaluates to false.
