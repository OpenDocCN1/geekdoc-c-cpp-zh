# **Using the Automatic Storage Class**

The variable declared within a block or body of a function is known as automatic variable. The variable declared with the `auto` keyword is local to the block or function in which it is declared. Whenever you declare a variable within body of a function, by default, it is `auto`. For example, the following code snippet shows two ways of declaring an automatic variable:

```
```
int variable1;
auto int variable1;
```
```

In the preceding code snippet, both the declaration of the `variable1` variable is same. The lifetime of `auto` variable is available only within the body of function in which it is declared. Listing 28 shows an example of using the `auto` variable. You can find the `AutoVar.cpp` file on the CD in the code/chapter3 folder:

# **Listing 28: Using the auto Variable**

```
```cpp
#include <iostream.h>
int main()
{
    void function1();
    // calling function1()
    function1();
    return 0;
}
void function1()
{
    auto int var1=5; //auto
    cout<<"Value of var1 is :"<<var1;
}
```
