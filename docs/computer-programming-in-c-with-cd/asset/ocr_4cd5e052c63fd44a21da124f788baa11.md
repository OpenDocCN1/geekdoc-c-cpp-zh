# 6.12 Using the this Pointer

Every member function of a class, in C++, has an implicit pointer called `this`. The `this` pointer points to the object with which the member function is associated. A member function is always invoked containing the value of this pointer. The value of the `this` pointer is set to the address of the object for which it is called. Using the `this` pointer, any member function can find out the address of the object of which it is a member. The `this` pointer can also be used to access the data of the object to which the pointer points.
