## Short Questions/Answers

### Q1. Explain the relationship between pointers and Memory management.

Ans. When we declare a variable, we do not consider its memory location in the system. It is the task of operating system to allocate an appropriate amount of memory and keep track of such memory location. At times, when we need to use the memory address of a variable, we use a special type of variable that is a pointer variable. By using a pointer variable, we can directly access the memory address of a variable as well as its value to which it (pointer variable) points to. Moreover, we also allocate and de-allocate memory to the pointer dynamically for the optimum use of available memory. The data type of the pointer variable depends on the data type of that variable, whose address is stored in it.

### Q2. How can we retrieve the memory address of a variable in C++?

Ans. In C++, when we declare a variable, the variable occupies some space in the memory. Each memory location has a unique address associated with it. In C++, you can obtain this memory address by using a reference or address of (&) operator. For example, if you need to access the memory address of an integer variable, called X. Then, you have to write the &X statement, where X is the variable name that is preceded by the & operator.

### Q3. How can we access or modify the value of a variable by using pointers in C++?

Ans. To create and use the pointer, there are two basic steps. Firstly, we declare a pointer variable and then we store the address of a variable in it. Once the memory address of a variable is assigned to the pointer variable, you can directly access the value of that variable by using the * operator. The * operator is also known as the dereference operator. The dereference operator (*) accesses the data stored in the variable pointed by the pointer variable. For example, if MyInt is an integer variable and MyPointer is a pointer that points to the memory address of the MyInt variable, then you can use the *MyPointer pointer to access and change the value of MyInt variable.

### Q4. What is a pointer to pointer and how is it different from pointers we use generally?

Ans. A pointer is a variable that contains memory address of another variable. However, there can be situations when a pointer (let’s say x) contains the memory address of another pointer (let’s say y). In such a situation, the pointer (x) is called a pointer to pointer. Now, the difference between a pointer and a pointer to pointer is that a pointer contains memory address of a variable while pointer to pointer contains the memory address of another pointer.

### Q5. How can we allocate memory to the pointer variable at run time?

Ans. Pointer in C++ can also be used for allocating memory to a variable at run time. When we allocate memory to a variable at run time, it is called dynamic memory allocation. Dynamic allocation allows you to use memory when it is needed. The new operator is provided by C++ to allocate memory dynamically. For example, let’s see the following code snippet:

```
int *MyInt = new int;
```

In the preceding code snippet, the MyInt is a pointer variable to which the memory is allocated by using the new operator.

### Q6. Explain the process of de-allocating the memory of a pointer variable at run time.

Ans. Similar to allocating memory to the pointer variable at run time, we can also de-allocate memory of the pointer at run time. For this, C++ provides the delete operator. However, the delete operator can only release the memory of a pointer to which the memory is provided by using the new operator. For example, let’s consider the following code snippet:

```
delete MyInt;
```

In the preceding code snippet, the `delete` keyword is followed by the name of the pointer variable that is `MyInt`, to release the memory occupied by the pointer variable `MyInt`.

### Q7. What are arrays? How pointers can be used to work with arrays?

Ans. An array is a collection of variables of similar data type that are stored adjacent to each other in a memory. At the time of creating an array, you must specify its size, which implies the number of variables, an array can store. You can access individual element of an array by using their index number. The index number is also known as subscript number. The index number of each element of an array is one less than its actual place in the array. For example, if you want to access the fifth element of an array, the index number should be 4.

Pointers can also be used for referencing an array. When pointer deals with arrays, they store the address of a single element of an array at a time. Using pointer, you can also access and change the value of an array element.

### Q8. What are the increment and decrement operators? How they are used with pointers?

Ans. C++ allows arithmetic operations on pointer variables. They are mainly used for fast and accurate manipulation of addresses assigned to the variables of an array.
