## The Scope Resolution Operator (SRO)

SRO allows you to access the global variables in a C++ program in case the program contains local and global variables with the same names. Using `::` (the symbol representing SRO) indicates to the compiler that you want to access a global variable instead of a local variable with the same name. If you do not use `::`, the compiler gives preference to the local variable. Listing 29 shows the use of the global variable in a C++ program (you can find the ScopeEx.cpp file on the CD in the code/chapter1 folder):

### Listing 29: Using the `::` Operator

```cpp
#include <iostream.h>
int x = 5; // global variable

int main()
{
    int x = 6; // local variable
    cout << "Value of local variable x is " << x << endl;
    cout << "Value of global variable x is " << ::x << endl;
    return 0;
}
```

**Output:**

```text
Value of local variable x is 6
Value of global variable x is 5
```

## Memory Management Operators

Memory management is an essential part of a programming language. Occasionally, it is possible that the object you have created to store 100 elements, stores only 5 elements, implying that the memory allocated to rest of the elements is wasted. Memory should be allocated dynamically that is, at run time, which helps to reduce memory wastage so that other resources can use that memory. C++ provides the `new` and `delete` operators to manage memory.

The `new` operator is used to allocate memory to a variable at run time according its data type. This reduces the wastage of memory unnecessarily allocated to a variable. In case sufficient memory is not available for a variable, the operator returns null.

The `delete` operator frees the memory allocated to a variable. Listing 30 shows the use of the `new` and `delete` operators (you can find the NewDeleteEx.cpp file on the CD in the code/chapter1 folder):

### Listing 30: Using Memory Management Operators

```cpp
#include <iostream.h>
#include <stdlib.h>
int main()
{
    double *pi;
    pi = new double; // allocating memory
    if (pi == NULL)
    {
        exit(1);
    }
    else
    {
        *pi = 3.14159;
        cout << "The value of pi is " << *pi << endl;
    }
    delete pi; // freeing the memory
    return 0;
}
```

**Output:**

```text
The value of pi is 3.14159
```

## Operator Precedence in C++

The precedence of operators represents the sequence in which a compiler will execute the operators. Listing 31 shows operator precedence (you can find the OperatorPre.Exe.cpp file on the CD in the code/chapter1 folder):

### Listing 31: Showing Operator Precedence

```cpp
#include <iostream.h>
int main()
{
    double value;
    value = 12 + 24 / 6;
    cout << "The value = " << value << endl;
    return 0;
}
```

**Output:**

```text
The value = 16
```

In Listing 31, we are trying to add 12 and 24 and then divide the sum by 6 to get 36 / 6 = 6. However, the output of Listing 31 is not as per our expectation. In fact, C++ sets up a very clear precedence of operators, which means that if it finds two operators at the same level in a statement (that is, not enclosed in parentheses or braces), it will execute the operator with the higher precedence first. As it happens, the `/` operator has higher precedence than the `+` operator, so in the preceding expression, first, 24 is divided by 6; next, the result is added to 12, which gives the value as 16. To get the desired result, you have to indicate to the compiler the order in which the operators have to be evaluated. For this purpose, you can use parentheses to group the operations you want to execute first.

Listing 32 shows the use of parentheses to produce the desired output (you can find the ParenthesesEx.cpp file on the CD in the code/chapter1 folder):

### Listing 32: Using Parentheses

```cpp
#include <iostream.h>
int main()
{
    double value;
    value = (12 + 24) / 6;
    cout << "The value = " << value << endl;
    return 0;
}
```

**Output:**

```text
The value = 6
```

In Listing 32, the parentheses around 12 + 24 ensures that the addition operation is performed first and thereafter, their sum is divided by 6.
