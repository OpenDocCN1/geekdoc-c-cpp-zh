# Summary

This chapter begins by introducing C++ and then gives the history of C++. This is followed by a discussion on the C language so that the need of OOP is understood. In addition, the chapter explains why C++ is called a superset of C. You also learn about the terms that are commonly used in C++, and about library functions and linkers. This is followed by creating a program in C++.

While discussing the fundamentals of C++, the chapter explains the components such as keywords, identifiers, comments, and constants, which are used in C++ programs. The chapter also discusses the concepts of operator precedence, operator associativity, and streams in C++.
