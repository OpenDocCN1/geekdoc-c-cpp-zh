## 6.10 Working with Arrays in C++

An array is a collection of variables of a single data type stored in the adjacent memory (memory side by side) locations. An array can be declared of any data type, including struct. You can declare an array of variables in a class or declare an array of objects in the main() function. Let’s use array in a class definition.

### Using an Array in a Class

You can use an array in a C++ class as its member variable. The following code snippet shows how to declare an array in a class:

```cpp
class MyClass
{
int number[10];                         //Declaring an array
public:

void count();
void display();
};
```

In the preceding code snippet, we are creating an array, number[10], of integer type that can store a maximum of 10 numbers. In addition, the number array can be used for any operation in the count() and display() functions of the MyClass class.
