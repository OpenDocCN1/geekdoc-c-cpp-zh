```
data-type Array_Name [rows][columns];
```

In the preceding syntax, `data_type` is the type of data that the array stores. `Array_Name` is the name of array, and the rows and columns represent the number of elements that can be stored in the array. For example, the following code snippet declares a two-dimensional array:

```
int Arr2[2][3];
```

In the preceding code snippet, the Arr2 array is created with 2 rows and 3 columns, which can store 6 integer values. In case of two-dimensional array, the index value ranges from [0][0] to [row-1][column-1]. Therefore, the first element of the Arr2 array can be accessed by using Arr2[0][0] and the last element can be accessed by using Arr2[1][2]. The tabular representation of the Arr2 array is shown as follows:

| Arr2[0][0] | Arr2[0][1] | Arr2[0][2] |
|---|---|---|
| Arr2[1][0] | Arr2[1][1] | Arr2[1][2] |

Initializing a two-dimensional array is similar to initializing a one-dimensional array. The following code snippet shows the initialization of a two dimensional array:

```
int Arr2[2][3]={
    {2,4,6},
    {8,10,12}
};
```

In the preceding code snippet, the two-dimensional array is created by specifying both the dimensions. However, you can also initialize a two-dimensional array as shown in the following code snippet:

```
int Arr2[][3]={
    {2,4,6},
    {8,10,12}
};
```

In the preceding code snippet, rows of the array are not specified, this is specified by the compiler automatically according to number of rows initialized in the array. This is why, both initializations of the Arr2 array are same and correct as well.
