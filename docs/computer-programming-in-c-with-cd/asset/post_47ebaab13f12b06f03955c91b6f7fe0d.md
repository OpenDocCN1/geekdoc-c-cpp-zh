## Multiple Inheritance

```text
class B variable calling
value in variable b=20
class C variable calling
value in variable c=30
```

In Listing 18, A and B are the base classes of the C class. The member variables, a and b, of the A and B classes respectively, are inherited by class C. In the main() function, the object of the C class invokes the display() function of the C class.

When a class is inherited from more than one base class, the object of the derived class invokes the constructors of base classes as well as of its own class, in the order of base-to-derived. Listing 19 shows the order in which constructors are invoked in multiple inheritance (you can find the ConsOrder_MultipleInheritance.cpp file on the CD in the Code\Chapter7 folder):

### ▶ Listing 19: Invoking Constructors in Multiple Inheritance

```cpp
#include<iostream.h>
class A
{
public:
A()
{
    cout<<"Default Constructor of A class"<<endl;
}
~A()
{
    cout<<"Destructor of A class"<<endl;
}
};
class B
{
public:
B()
{
    cout<<"Default Constructor of B class"<<endl;
}
~B()
{
    cout<<"Destructor of B class"<<endl;
}
};
class C:public A, public B
{
public:
C()
{
    cout<<"Default Constructor of C class"<<endl;
}
~C()
{
    cout<<"Destructor of C class"<<endl;
}
};
int main()
{
    C obj;
    cout<<"Main Program"<<endl;
    return 0;
}
```

Output:

```text
Default Constructor of A class
Default Constructor of B class
Default Constructor of C class
Main Program
Destructor of C class
Destructor of B class
Destructor of A class
```

In Listing 19, three classes, A, B and C are created. Each class has its own pair of default constructor and a destructor. Class C is derived from the A and B base classes. The object, obj, of the C class invokes the constructors of all the classes in the order of inheritance, that is, the constructor of class A, then the constructor of class B, and then the constructor of class C is invoked. However, the destructors of these classes are invoked in just reversed order, that is, derived-to-base.

It is important to note that changing the order of inheritance affects the order of constructor and destructor invocation. Listing 20 shows how the order of constructor invocation is affected when the order of inheritance is changed (you can find the ConsOrderAffectInheritance.cpp file on the CD in the Code\Chapter7 folder).

This changed order of inheritance also affects the order of constructor invocation and of destructor invocation for all the three classes: A, B, and C. Now, the object of class C, within the main() function, invokes the constructor of class B first, then it invokes the constructor of class A, and then the constructor of the class C. However, the destructors are invoked in the opposite sequence, that is, the destructor of the class C is invoked first, then the destructor of class A is invoked, and finally, the destructor of class B.
