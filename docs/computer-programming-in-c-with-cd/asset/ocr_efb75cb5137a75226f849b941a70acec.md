# Floating Point Types

We already know that floating point numbers are represented by the float and double data types. These data types are used to represent numbers along with decimal values. The data types can also have an exponent, which means 10 to the power of any number. For example, 2e2 = 2 x 10 ^ 2, where e represents 10, that is, an exponent. The exponent in the float data type can have the maximum value of 10 ^ 38 while exponent in the double data type can have a value of 10 ^ 308. The difference between the float and double data types is that the float data type can represent a maximum of 7 digits (single precision) after the decimal, while the double data type can represent 15 digits (double precision). Table 5 lists the characteristics (such as data type representation, width) of the float and double data types:

| Data Type | Representation | Width (bytes) | Range |
|---|---|---:|---|
| float | Single precision floating point number | 4 | 3.4e +/- 38 |
| double | Double precision floating point number | 8 | 1.7e +/- 308 |

The following code snippet shows the declaration of the floating point type variable:

```
float x=3.458f;
```

In the preceding code snippet, a float type variable, x, is declared and initialized. In the same way, you can use double data types with variables, as shown in the following code snippet:

```
double x, y;
```

In the preceding code snippet, the x and y variables are of the double type.
