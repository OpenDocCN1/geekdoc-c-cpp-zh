Using the arithmetic operations on pointers, you can move back and forth in the address area referenced by a pointer variable. For this, to move ahead in the address area, the increment (++) operator is used and to move back, the decrement (--) operator is used.

The pointer variable works as an index pointing the address of the variable. When we apply increment (++) operator, then the pointer variable points the next element of an array and the decrement (--) operator is applied for the previous element.

**Q9.** What are addition and subtraction operators? How are they affected by the size of variable type?

**Ans.** The addition (+) and subtraction (-) operators increase and decrease the value of a pointer by specific number. Since increment and decrement operators are used to change the memory address one by one, the addition (+) and subtraction (-) operators are used to jump to specific memory at once. For example, if your pointer variable is currently referencing the first element of the array and you want to access fifth element, then you can add 4 to the pointer variable directly and access its fifth element. The addition (+) and subtraction (-) operators changes the value of a pointer according to the size of the specified data type. For example, when we apply addition (+) operator to an integer type pointer variable, then the pointer variable points to the next element after a 4-bytes gap. When the data is a double, float, or a character, then index is moved according to their size.

**Q10.** What is a dynamic array? Why a dynamic array is preferred over a static array in C++ programs?

**Ans.** Dynamic arrays are those arrays that receive or release memory dynamically at run time by using the *new* and *delete* operators. These operators are used to allocate and de-allocate memory to the pointers at run time, respectively.

Generally, dynamic arrays are preferred in comparison of static arrays (general arrays) because of the following benefits:

+   - The static array is assigned to the memory at compile time irrespective of their use in the program. This results in unnecessary use of memory. On the other hand, the memory to dynamic array is allocated when the statement (declaring dynamic array) is executed at run time by the program. Therefore, the memory is not occupied unnecessarily.
+   - The static array holds memory throughout the program execution and the memory allocated to the static array cannot be released until the program terminates. On the other hand, you can release the memory allocated to dynamic array at any time during program execution, whenever the array is not further required in the program. This results in optimum use of memory available.
