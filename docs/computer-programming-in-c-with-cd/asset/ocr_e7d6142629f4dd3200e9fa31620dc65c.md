# Passing Arguments to a Function

In C++, the arguments of a function are used to initialize the parameters of a function definition. Argument can be a variable, a constant or an expression. When you pass the arguments to a function, you must remember that the number of arguments and types of arguments must be the same as the parameters in the function definition. When you pass argument while calling a function, it is known as actual argument and when you pass argument while defining a function, it is known as formal argument. Listing 10 shows passing arguments to the sub() function. In Listing 10, value1 and value2 are actual arguments of the calling function sub(value1, value2), and num1 and num2 are formal arguments of defining the void sub(int num1, int num2) function.
