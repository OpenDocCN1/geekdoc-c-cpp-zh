this global variable can be accessed by other program. The extern variable is also known as external variable. The default value of an extern variable is zero. This variable is useful in a scenario where we divide one large program into different small programs and use external variable in each small program. The main advantage of using external variable is that the complexity of a program can be reduced by separating large program into small program and using external variable, which is shared by all the programs. The following code snippet shows the use of the extern variable in a C++ program:

```
```cpp
extern int variable_extern=10; //declaring and initializing variable_extern
void function_next(void);
int main()
{
    variable_extern--;
    cout<<variable_extern; //variable_extern = 9
    function_next();
    return 0;
}
void function_next(void)
{
    variable_extern--; //variable_extern = 8
    function_other();
}
```
```

In the preceding code snippet, the variable_extern variable is created as an extern variable by using the extern keyword. This extern variable is later used in another code snippet as follows:

```
```cpp
extern int variable_extern;
void function_other(void)
{
    variable_extern--; //variable_extern = 8
    cout<<variable_extern;
}
```
```

In the preceding code snippet, the variable_extern variable is changed to 8 and its value is displayed to the user. The variable_extern variable is defined as extern in the code-snippet just before the preceding code snippet.
