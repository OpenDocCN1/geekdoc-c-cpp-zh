## Creating a Pointer of Class Members

In C++, you can declare pointers of class members by using the ::* operator. The ::* operator is known as the pointer to a class member declaratory operator. The syntax to declare a pointer of a class variable is:

```cpp
<data_type> <class_name>::*<pointer_name>;
```

The syntax to declare a pointer to a member function of a class is:

```cpp
<return_type> (<class_name>::*<pointer_name>) ();
```

The following code snippet shows examples of declaring the pointers to class members:

```cpp
int ABC::*varp1;
//Declaring a pointer to a data member

void (ABC::*funcp)();
//Declaring a pointer to a member function
```

The syntax to initialize a pointer to a class member is:

```cpp
<pointer_name>=& <class_name> :: <membername>;
```

In the preceding syntax, note that the data type or return type of the <membername> and <pointer_name> expressions must be same.

The following code snippet shows the initialization of a pointer to a class member:

```cpp
varp1=&ABC::num2;
//Assigning a data member to a pointer
funcp=&ABC::displayValue;
//Assigning a member function to a pointer
```

You can also declare a pointer to a class member along with the name of an object of the class, to access the class members, by using the .* operator. The .* operator is also known as the dereferencing pointer to class member operator. The following code snippet shows the use of the .* operator:

```cpp
ABC obj;
obj.*varp1;
(obj.*funcp)();
```

In the preceding code snippet, obj is an object of the ABC class and it is used along with the .* operator to access the members of the same class.

In Listing 30, the ABC class is created with one private member, num1, and three public members, num2, ABC(), and displayValue(). In the main() function, the varp1 and funcp pointers are declared and assigned the num2 variable and the displayValue() member function of the ABC class. In addition, obj, an object of the ABC class, is used with the varp1 and funcp pointers to access the corresponding class members.

You can also use a pointer object of a class to declare pointers to class members. The following code snippet shows the use of a pointer object that is pointing to class members by using the ->* operator:


In the preceding code snippet, *ptr is a pointer object of the ABC class that is initialized with the reference of the obj object. Then, the ptr pointer object is used with the ->* operator to access the members of the ABC class.
