## 6.2 Working with Classes and Objects

The OOP model is based on the data types called classes. When you declare or create variables of a class, it is known as class instantiation. All the variables that are declared of a class data type are called objects. This means an object is an instance of a class. A class binds the variables and functions, which operate on the variables, into a single unit. The variables and functions enclosed in a class are called data members and member functions, respectively. Member functions define the permissible operations on the data members of a class.

Placing data and functions together in a single unit is the central theme of OOP. The programmers are entirely responsible for creating their own classes and can also have access to classes developed by the software vendors.

Classes are the basic language construct of C++ to create user-defined data types. A class resembles a structure with just one difference that its members in a structure are public by default; whereas all members of a class are private, by default.

You need to perform the following tasks to work with classes and objects in C++:

- Defining a Class
- Creating an Object
- Creating Data Members
- Using Access Specifiers
- Creating Member Functions

Let’s explain how to define a class in C++.

### Defining a Class

One of the prominent reasons to keep C++ in OOP-based languages is that it supports classes, which not only contain data members but methods. The methods, defined in a class, are a set of operations that can be performed on the data members of the class. They are also known as member functions of a class. A class, therefore, can be described as a collection of data members along with member functions. The following syntax is used to define a class:

```cpp
class ClassName        /* class is keyword and ClassName is the
                         name of the user-defined class */
{

private:
    private data members and methods

protected:
    protected data members and methods

public:
    public data members and methods
} [object_list];             // semicolon (;) is required here
```

In the preceding syntax, `class` is a keyword that is followed by the name of a class, ClassName. The `class` keyword indicates that the ClassName class is an abstract data type, which specifies the type and scope of its members. The body of a class is enclosed within the curly braces followed by a semicolon at the end of the class declaration. The following code snippet shows the specification of a class called Student:

```cpp
#include<iostream.h>

/* the declaration of a class */
class Student
{
// body of a class
};
```

The following are the rules that must be followed while naming a class:

- A class name must begin with a letter, which may be followed by a sequence of letters or digits (0-9) or _. The first character in a class name cannot be a digit.
- The name of a class must not contain any embedded space or symbol, such as ? - + ! @ # % ^ & * ( ) [ ] { } . comma (,) : ; " ' \` / and \. However, an underscore (_) can be used wherever a space is required.
- A keyword cannot be used for a class name. For example, you cannot declare a class called `class`.

A class name must follow certain naming conventions or guidelines. These guidelines are as follows:

- The name of a class should be meaningful. For instance, the class names, such as Animal, Employee, or Account are meaningful. However, the class names, such as wxz and _gggnn are meaningless.
- The name of a class should ideally be a noun. For instance, the name of a class related to students can be Student and the name of a class related to various geometrical shapes can be Shape.
- If the name of a class contains more than one word and does not use underscores, the first letter of every word should be in upper case. For example, the name of a class storing the marks obtained by students can be StudentScoreCard and the name of a class storing the salary composition can be SalaryComponents.

In C++, the `class` keyword is used to define a new class. However, you cannot define two different classes with the same name or define the same class twice, as you get a compilation error. The following code snippet shows an example to declare a class:

```cpp
class Account;
```

In the preceding code snippet, we are declaring the Account class, which is a prototype of a class. Note that the prototype of a class introduces the class's presence to the C++ compiler, before defining the class. Such declarations, however, are of limited utility; because the compiler does not know what this class contains.

### Creating an Object

The structure of an object is defined in its class definition. An object must be instantiated to use the services provided by its class. Instantiation is the process of creating objects of a class. The following syntax is used to define an object of a class:

```cpp
class <ClassName>
{
} <ObjectName>;
```

The following code snippet shows how to create an object of a class:

```cpp
#include<iostream.h>

/* Declaring and instantiating a class */
int main()
{
    class Student
    {
        // body of a class
    } object1;
    return 0;
}
//class is defined inside the main() function
```

Another way to define a class and to create an instance of a class is given in the following code snippet:

```cpp
#include<iostream.h>

/* Declaring and instantiating a class */
class Student
{
    // body of a class
};              //class is defined outside the main() function
int main()
{
    Student object1;
    return 0;
}
```

Both the preceding code snippets perform the same task, that is, to create an object, called object1, of the Student class.

You can also create more than one object of a class within a single statement. The following code snippet shows the creation of multiple objects of a class:

```cpp
#include<iostream.h>

class Student
{
    // body of a class
};
/* Creating more than one instance of a class */
int main()
{
    Student object1, object2, object3, object4;
    return 0;
}
```

Another way to create more than one object of a class is shown in the following code snippet:

```cpp
#include<iostream.h>

/* Creating multiple instances of a class */
int main()
{
class Student
{
    // body of a class
} object1, object2, object3, object4;
return 0;
}
```

Both the preceding code snippets perform the same task, that is creating multiple objects object1, object2, object3, and object4 of the Student class.

You can also create pointer type objects. A pointer is a variable that stores the memory address of any variable. A pointer object is initialized with the help of the new operator and is destroyed with the delete operator. The following code snippet shows the allocation and de-allocation of a pointer object of a class using the new and delete operators, respectively:

```cpp
#include<iostream.h>

class Student
{
    // body of a class
};

int main()
{
    Student *ptrObject=new Student;
    // perform the task with object
    delete ptrObject;
    return 0;

}
```

In the preceding code snippet, a pointer object, ptrObject of the Student class is created. The ptrObject object gets the memory by using the new operator and the same object gets destroyed by using the delete operator.

### Creating Data Members

You can store data in objects by creating data members. The following code snippet shows the declaration of data members inside a class:

```cpp
#include<iostream.h>

class Student
{
/* Declaring data members */
    char s_name[20];
    int s_roll_no, s_age, s_class;
    char father_name[20];
    int s_subject, s_marks;
};

int main()
{
    Student object1;
    return 0;
}
```

In the preceding code snippet, data members in classes are private by default. You can make data members in a class private, protected, or public by explicitly declaring them with the `private`, `protected`, and `public` keywords.
