### Short Questions/Answers

Q1. What is a structure? How is it different from an array?

Ans. A structure is a user-defined data type that contains more than one element, where each element can be declared with a different data type such as int, float, and char. The elements included in a structure are called members of the structure. On the other hand, an array is a collection of elements with similar data type. In other words, an array cannot have elements of different data types. For example, assume that you want to store information about an employee, such as name, age, salary, designation, and so on. All this information cannot be stored in a single array; however, you can easily store this information (employee) in a single structure.

Q2. How can you create structures in C++?

Ans. You can create a structure in C++ by declaring a structure with a structure name and different types of data members that can be stored in a structure. Next, you define structure variables for accessing data members of a structure.

You have to use the struct keyword just before the structure name. After specifying the structure name, the structure starts with the opening curly brace { and ends with the closing curly brace }. Further, a semicolon (;) must be placed after the closing curly brace. All the data members of a structure are specified between these braces.

Q3. Why do you create a variable of the structure? What are the types of variables you can declare for the structure? How can you create a variable?

Ans. First of all, you define a structure and its members by using the struct keyword. Once the structure is defined, the next step is to declare the structure variables, so that you can assign values to structure members and also use these values as and when required. A structure variable can be declared as global or as local. Declaring global variable implies that the scope of the structure variable is global, which can be used anywhere, throughout the C++ program. Generally, global variables are declared at the time of defining the structure. However, you can also declare structure variables as local variables, which implies that such local variables are accessible within the specific part of the program. For example, if you have created a structure variable inside the function of the C++ program, then it can be accessed within the function body only and will be termed as a local variable.

Q4. How can you access and initialize structure members in C++?

Ans. Every structure has some elements known as members of the structure, which are declared within the body of the structure. When you define a structure, you can define members with a unique variable name. You can use the dot (.) operator between structure variable name and structure element (member of structure) to access and initialize a structure element. The syntax of accessing a structure element is as follows:

```
structure_variable_name.structure_element;
```

In the preceding code snippet, the structure_variable_name is the variable of structure and the structure_element is the name of the structure member you want to access. Moreover, a dot (.) is placed between them so that the compiler can also understand the same.

Similarly, you can initialize structure elements by using the dot (.) operator as shown in the following code snippet:

```
employee_one.name = "Mohan";
employee_one.age = 22;
```

In the preceding code-snippet, employee_one is the variable of the structure as well as the name and age are the structure members, which are assigned the values Mohan and 22, respectively.

Q5. What is a nested structure?

Ans. A structure within a structure is known as a nested structure. It means that the member of a structure can also be a structure variable of another structure. For example, you have created a structure named Date with three integer variables day, month and year in it. Now you create another structure named Employee, with three variables of char, int and float type, respectively. Moreover, the Employee structure also contains a variable of the structure Date as its member. In this case, the structure Date is treated as a nested structure inside the Employee structure.

Q6. What do you mean by passing a structure to the function? Why is it required?

Ans. The variables that are created inside the function are called local variables. These local variables can be used with the function only. Moreover, a function can also use parameters that are passed by the caller program to execute the function. These parameters are used to interface between the function and the caller program. Generally, you pass variables as function parameters. However, it is not necessary and you can also pass structures as function parameters. Passing structure to a function means that you have to pass structure variable as an argument to a function. The structure variable passed to the function has access to all the elements of that structure, so that you can access and assign values to the structure member as and when required.

Q7. What do you mean by returning a structure from the function? Why is it required?

Ans. A function is a set of statements to perform a specific task. It takes some value (called argument) from the caller program as an argument and also returns some value to the caller program. You can also pass structure as an argument to the function. Using this argument, you can change values of the variables defined in the structure. Now, you want to access these values outside the function body. For this, you return the structure variable to the caller function by using the `return` keyword at the end of a function body.
