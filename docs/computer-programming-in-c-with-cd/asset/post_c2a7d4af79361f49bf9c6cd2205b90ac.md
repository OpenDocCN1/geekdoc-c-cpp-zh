## Creating Nested for Loop

A for loop contained in another for loop is called a nested for loop. In the nested for-loop, execution starts from the outer for-loop and the control then passes to the inner for-loop. The inner for-loop then continues execution till the condition of inner for-loop evaluates to true. Once inner for-loop is completed, the flow of execution is passed to outer for-loop to continue the next iteration and then once again the inner for-loop is executed. This implies that for each iteration of the outer loop, the inner loop is executed completely. Listing 24 shows the use of nested for loops (you can find this example in the forloop2.cpp file on the CD in the code\chapter2 folder):

**Listing 24: Nesting `for` Loop**

```cpp
#include<iostream.h>
int main()
{
    int x,y,sum;
    for(x=1;x<=2;x++)
    for(y=1;y<=2;y++)
    {
        sum=x+y;
        cout<<"x:"<<x<<endl;
        cout<<"y:"<<y<<endl;
        cout<<"Sum:"<<sum<<endl<<endl;
    }
    return 0;

}
```

**Output:**

```text
x:1
y:1
Sum:2

x:1
y:2
Sum:3

x:2
y:1
Sum:3
x:2
y:2
Sum:4
```

In Listing 24, the execution began with an outer `for-loop` in which the `x` variable is initialized to 1. Now, the execution enters into the inner `for-loop` where the `y` variable is set to 1. The sum of two numbers (`x` and `y`) gets printed.

The inner `for-loop` continues to execute until the condition, `y<=2`, becomes false. In this way, the inner for-loop is executed two times, with `y` changing its value from 1 to 2. Once the inner for-loop is completed, the execution goes to the outer for-loop and `x` is set to 2. This time, the inner for-loop is executed once again and the statements following this loop execute twice. In this way, the outer for-loop and inner for-loop are executed twice in the code.

## 2.4 Working with Jump Statements

Jump statements are the statements that transfer control from one part of the program to another. The following are the jump statements supported by C++:

- `break` statement
- `continue` statement
- `goto` statement

### Using the `break` Statement

The `break` statement is used to exit from loops and conditional statements. This statement is written in the form of a simple `break` keyword followed by a semicolon. The example shown in Listing 25 demonstrates an infinite loop displaying even numbers up to infinity. However, to ensure that code control remains with the user we have used a `break` statement to display only the first four even numbers. If we do not use the `break` statement, code goes into infinity loop, which raises an error at the time of termination. Listing 25 shows the use of the `break` statement (you can find this example in the `breakStatement.cpp` file on the CD in the `code\chapter2` folder):

**Listing 25: Using the `break` Statement**

```cpp
#include<iostream.h>
int main()
{
    int i=0;
    while(true)
    {
        i=i+2;
        if(i>10)
            break;
        cout<<i<<endl;
    }
    return 0;
}
```

**Output:**

```text
2
4
6
8
10
```

In Listing 25, the `break` statement is used stating that if the value of the `i` variable exceeds 10, then the loop breaks and the control comes out of the `while` loop. In this case, only first five even numbers are displayed before the control comes out of the loop.

### Using the continue Statement

The `continue` statement causes the current loop to quit iteration and begin the execution of the next iteration. In other words, the `continue` statement is used to skip the current iteration. Listing 26 shows the use of the `continue` statement (you can find this example in the `continueStatement.cpp` file on the CD in the `code\chapter2` folder):

**Listing 26: Using the continue Statement**

```cpp
#include<iostream.h>

int main()
{
    int i;
    for(i=2;i<=20;i=i+2)
    {
        if(i==6 || i==14)
        {
            continue;
        }
        cout<<i<<endl;
    }
    return 0;
}
```

**Output:**

```text
2
4
8
10
12
16
18
20
```

In Listing 26, first ten even numbers are shown, excluding 6 and 14 from the result. This is done with the help of the continue statement inside an if condition, which gets executed in case the value of i variable becomes either 6 or 14. In the output of Listing 26, even numbers are shown successfully until the value of i becomes 6 or 14. When the value of i becomes 6, the control of execution quits from the current loop and returns back to the for loop. The next iteration then displays the remaining even numbers till the value of i becomes 14. Then the control of execution again quits the current loop and returns back to the for loop. The next iteration displays the remaining even numbers.
