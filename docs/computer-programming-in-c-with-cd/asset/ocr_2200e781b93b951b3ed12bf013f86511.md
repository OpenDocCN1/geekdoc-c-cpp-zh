In Listing 24, the execution began with an outer `for-loop` in which the `x` variable is initialized to 1. Now, the execution enters into the inner `for-loop` where the `y` variable is set to 1. The sum of two numbers (`x` and `y`) gets printed.

The inner `for-loop` continues to execute until the condition, `y<=2`, becomes false. In this way, the inner for-loop is executed two times, with `y` changing its value from 1 to 2. Once the inner for-loop is completed, the execution goes to the outer for-loop and `x` is set to 2. This time, the inner for-loop is executed once again and the statements following this loop execute twice. In this way, the outer for-loop and inner for-loop are executed twice in the code.

+   - `continue` statement
+   - `goto` statement
