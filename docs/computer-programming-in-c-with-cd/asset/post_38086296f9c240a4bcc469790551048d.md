Let’s start discussion with one-dimensional array.

## One-dimensional Array

In C++, one-dimensional array is a structured collection of elements that can be accessed individually by specifying the position of an element with a single index value. For example, when we declare array[10], the index value of elements in the array are array[0], array[1], ..., array[9]. The following is the syntax to declare a one-dimensional array:

```cpp
data_type Array_Name [count];
```

In the preceding syntax, `data_type` describes which type of data is stored in each element of the array and `count` indicates the size of the array. The size of array specifies the number of array element in the array. A value of the `count` must be greater than 0 to create an array. The index value of a one-dimensional array ranges from 0 to count-1. For example, when you declare a one-dimensional array of 10 elements, the index value of such array ranges from 0 to 9. The one-dimensional arrays are also called linear arrays. This is because, the one-dimensional array stores data in a sequential order. The following code snippet shows how to declare a one-dimensional array:

```cpp
int roll[50];
```

When the C++ compiler compiles the preceding code snippet, it creates an array called roll, which can store 50 elements; each element is capable of holding one int value. In other words, the roll array has 50 elements and their data-type is int. An example of using one-dimensional array is shown in Listing 3 (you can find the Array2.cpp file on the CD in the code/chapter3 folder):

### ▶ Listing 3: Creating One-dimensional Array

```cpp
#include <iostream.h>
int main()
{
  int array[5];
  int index, temp;
  for(index=0; index<5; index++)
  {
    cout<<"Enter the value of array["<<index<<"]: ";
    cin>>array[index];
  }
  cout<<"The values you enter are: ";
  for(index=0; index<5; index++)
  {
    cout<<array[index]<<", ";
  }
  cout<<endl;
  // sorting an array
  for (int i=0; i<5; i++)
  {
      for(int j=0; j<=i; j++)
      {
          if(array[i] < array[j])
          {
              temp = array[i];
              array[i] = array[j];
              array[j] = temp;
          }
      }
  }
  cout<<"After sorting values are: ";
  for(index=0; index<5; index++)
  {
      cout<<array[index]<<" ";
  }
  return 0;
}
```

**Output:**

```text
Enter the value of array[0]: 23
Enter the value of array[1]: 45
Enter the value of array[2]: 11
Enter the value of array[3]: 24
Enter the value of array[4]: 77
The values you enter are: 23, 45, 11, 24, 77,
After sorting values are: 11, 23, 24, 45, 77,
```

In Listing 3, the array[5] is a one-dimensional array, which is used to store elements in this array. After storing elements in array[5], we sort these elements in ascending order and display the final sorted elements.

Apart from creating one-dimensional array, you can also create arrays with more than one dimension. Let’s discuss two-dimensional arrays in the following section.

## Two-dimensional Array

An array with two dimensions is known as two-dimensional array (array[10][10]). In other words, the array, which can store values in a tabular format i.e. in the form of rows and columns, is called two-dimensional array. The one-dimensional arrays are linear arrays as they store data in a sequential order. On the other hand, the two-dimensional arrays are non-linear arrays because it stores data in the tabular form. In one-dimensional array, only one index value is used to declare and access the elements of the array; whereas in two-dimensional array, two index values are used to access the elements of the array. The following is the syntax to declare a two-dimensional array:

```cpp
data-type Array_Name [rows][columns];
```

In the preceding syntax, `data_type` is the type of data that the array stores. `Array_Name` is the name of array, and the rows and columns represent the number of elements that can be stored in the array. For example, the following code snippet declares a two-dimensional array:

```cpp
int Arr2[2][3];
```

In the preceding code snippet, the Arr2 array is created with 2 rows and 3 columns, which can store 6 integer values. In case of two-dimensional array, the index value ranges from [0][0] to [row-1][column-1]. Therefore, the first element of the Arr2 array can be accessed by using Arr2[0][0] and the last element can be accessed by using Arr2[1][2]. The tabular representation of the Arr2 array is shown as follows:

|  |  |  |
|---|---|---|
| Arr2[0][0] | Arr2[0][1] | Arr2[0][2] |
| Arr2[1][0] | Arr2[1][1] | Arr2[1][2] |

Initializing a two-dimensional array is similar to initializing a one-dimensional array. The following code snippet shows the initialization of a two dimensional array:

```cpp
int Arr2[2][3]={
    {2,4,6},
    {8,10,12}
};
```

In the preceding code snippet, the two-dimensional array is created by specifying both the dimensions. However, you can also initialize a two-dimensional array as shown in the following code snippet:

```cpp
int Arr2[][3]={
    {2,4,6},
    {8,10,12}
};
```

In the preceding code snippet, rows of the array are not specified, this is specified by the compiler automatically according to number of rows initialized in the array. This is why, both initializations of the Arr2 array are same and correct as well.

In case of one-dimensional array, loops are used to access its elements. In case of two-dimensional and three-dimensional array, the nested loops are used to access its individual elements. Listing 4 shows an example of accessing elements of two-dimensional array by using the nested for loop, (you can find the Array3.cpp file on the CD in the code/chapter3 folder):

### ▶ Listing 4: Creating Two-dimensional Array

```cpp
#include <iostream.h>
#include <string.h>

int main()
{
    int matrix[3][4];
    int i,j;
    for(i=0; i<3; i++)
    {
        for(j=0; j<4; j++)
        {
            cout<<"Enter the element of matrix["<<i<<"]["<<j<<"] :";
            cin>>matrix[i][j];
        }
    }

    cout<<endl;
    cout<<"The element of matrix are: "<<endl;
    for(i=0; i<3; i++)
    {
        for(j=0; j<4; j++)
        {
            cout<<matrix[i][j]<<"  ";
        }
        cout<<endl;
    }

    return 0;
}
```

**Output:**

```text

Enter the element of matrix[0][1] :6
Enter the element of matrix[0][2] :1
Enter the element of matrix[0][3] :5
Enter the element of matrix[1][0] :2
Enter the element of matrix[1][1] :7
Enter the element of matrix[1][2] :4
Enter the element of matrix[1][3] :2
Enter the element of matrix[2][0] :4
Enter the element of matrix[2][1] :3

3 6 1 5
```

In Listing 4, the two-dimensional array matrix[3][4] is created. Then two nested for loops are also created. The first for loop is used to accept values that are stored in the array elements. The second for loop is used to access and display these values of these elements.

## Three-dimensional Array

An array declared with three dimensions is called a three-dimensional array. In other words, the array of two-dimensional array can be said as three-dimensional array. The following is the syntax to declare a three-dimensional array:

```cpp
data_type Array_Name[dimension1][dimension2][dimension3];
```

In the preceding syntax, the `data_type` is the type of data that will be stored in the array, `Array_Name` is the name of the array, and the `dimension1`, `dimension2`, and `dimension3` are the three dimensions of the array. The three dimensions represent the number of elements that can be stored in the array. For example, the following code snippet shows declaration of a three dimensional array:

```cpp
int Arr3[2][2][2];
```

In the preceding code snippet, the `Arr3` array is a three-dimensional array that can store eight (2x2x2) integer values. In case of three-dimensional array, the index value ranges from `[0][0][0]` to `[dimension1-1][dimension2-1][dimension3-1]`. For example, first element of the Arr3 array declared in the preceding code snippet can be accessed by using `Arr3[0][0][0]` index and the last element of it can be accessed by using `Arr3[1][1][1]` index.

Initialization of the three-dimensional array is very similar to the initialization of the one-dimensional and two-dimensional arrays. The following code snippet shows the initialization of the Arr3 array declared in the preceding code snippet:

```cpp
int Arr3[2][2][2]={
                        {
                          {1,2},
                          {3,4},
                        },
                        {
                          {5,6},
                          {7,8},
                        }
                     };
```
