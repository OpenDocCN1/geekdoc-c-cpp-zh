## ➜ Arithmetic Operators

The arithmetic operators are used to perform basic operations, such as addition, subtraction, division, and multiplication. Table 7 lists all the arithmetic operators provided in C++:

**Table 7: Arithmetic Operators**

| Operator | Functionality | Associativity |
|---|---|---|
| `*` | Multiplication | Left to right |
| `/` | Division | Left to right |
| `%` | Modulus | Left to right |
| `+` | Addition | Left to right |
| `-` | Subtraction | Left to right |

The `*` operator is used to multiply values and the `/` operator is used to divide values. The `%` (modulus) operator calculates the remainder, for example, 10%3 = 1. The `+` operator adds two or more values and the `-` operator is used to subtract values. Listing 14 shows the use of all the arithmetic operators (you can find the ArithmeticEx.cpp file on the CD in the code/chapter1 folder):

### ▶ Listing 14: Using Arithmetic Operators

```cpp
#include <iostream.h>
int main()
{
    int x = 10, y = 3, sum, sub, div, mod, mul;
    sum = x + y;
    sub = x - y;
    div = x/y;
    mod = x%y;
    mul = x * y;
    cout << "Addition of " << x << " and " << y << " is : " << sum << endl;
    cout << "Subtraction of " << x << " and " << y << " is : " << sub << endl;
    cout << "Division of " << x << " and " << y << " is : " << div << endl;
    cout << "Modulus of " << x << " and " << y << " is : " << mod << endl;
    cout << "Multiplication of " << x << " and " << y << " is : " << mul << endl;
    return 0;
}
```

### Output:

```text
Addition of 10 and 3 is : 13
Subtraction of 10 and 3 is : 7
Division of 10 and 3 is : 3
Modulus of 10 and 3 is : 1
Multiplication of 10 and 3 is : 30
```

In Listing 14, we declared two variables: x and y and initialized them as 10 and 3, respectively. We performed all basic operations on x as well as y and stored their value in variables: sum, sub, mod, mul, and div.

In C++, you can perform multiple assignments in the same statement (this works because the assignment operator itself returns the assigned value). Listing 16 shows the implementation of the concept of multiple assignments (you can find the MultiAssEx.cpp file on the CD in the code/chapter1 folder):

### ▶ Listing 16: Performing Multiple Assignments

```cpp
#include <iostream.h>
int main()
{
    int value1, value2, value3;
    value1 = value2 = value3 = 12;
    cout << "First value = " << value1 << endl;
    cout << "Second value = " << value2 << endl;
    cout << "Third value = " << value3 << endl;
    return 0;
}
```

### Output:

```text
First value = 12
Second value = 12
Third value = 12
```

**Table 8: Arithmetic Assignment Operators**

| Operator | Meaning | Associativity |
|---|---|---|
| `%=` | Modulus assignment | Right to left |
| `&=` | Bitwise AND assignment | Right to left |
| `*=` | Multiplication assignment | Right to left |
| `/=` | Division assignment | Right to left |
| `^=` | Bitwise XOR assignment | Right to left |
| `|=` | Bitwise OR assignment | Right to left |
| `+=` | Addition assignment | Right to left |
| `-=` | Subtraction assignment | Right to left |
| `<=` | Less than equal to assignment | Left to right |
| `>=` | Greater than equal to assignment | Left to right |
| `<<=` | Left shift assignment | Right to left |
| `>>=` | Right shift assignment | Right to left |

Listing 17 shows the use of arithmetic assignment operators (you can find the ArithAssEx.cpp file on the CD in the code/chapter1 folder):

### Listing 17: Using Arithmetic Assignment Operators

```cpp
#include <iostream.h>

int main()
{
    int x=10, y=8, z=9;
    x *=2;
    y +=2;
    z -=2;
    cout << "x * 2 = " << x << endl;
    cout << "y + 2 = " << y << endl;
    cout << "z - 2 = " << z << endl;
    return 0;
}
```

### Output:

```text
x * 2 = 20
y + 2 = 10
z - 2 = 7
```

In Listing 17 the `*=`, `+=`, and `-=` arithmetic assignment operators have been used. The x, y, and z variables are declared in the program and initialized with the values 10, 8, 9, respectively. Then, the `*=2` arithmetic assignment operator is used with the x variable to multiply the value of x by 2. Similarly, the `+=` and `-=` arithmetic assignment operators are used with the y and z variables to add to and subtract from 2 in the respective variables.
