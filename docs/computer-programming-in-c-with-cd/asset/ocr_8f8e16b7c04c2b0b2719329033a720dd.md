+   - An inline function contains a loop construct, switch, or goto statement that returns a value.

Let’s now learn the difference between inline functions and macros.

# Difference between Inline Functions and Macros

Similar to an inline function, macro is another kind of function that makes a C++ program compact, but itself is expanded by the C++ compiler. A macro contains a sequence of code, which is replaced by the C++ compiler by generating the actual machine code for the program. One of the disadvantage of using a macro is that it takes more memory as compared to a function. However, a macro takes less time for execution.
