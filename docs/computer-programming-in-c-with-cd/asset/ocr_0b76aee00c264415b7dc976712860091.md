# Creating Nested Structure

A structure within a structure is known as a nested structure. It means that the member of a structure can also be a structure variable of another structure. Now, consider the following example to illustrate nested structure, which contains groups of data members, such as day, month, and year into date structure as follows:

```
struct date
{
    int day;
    int month;
    int year;
};
```

This date structure can be nested structure of the employee structure as shown in following code snippet:

```
struct employee
{
    char name[30];
    int age;
    float salary;
    date join_date;
};
```

In the preceding code snippet, the variable of the date structure (join_date) is created as a member of the employee structure. In other words, we can say that the date structure is nested inside the employee structure. The data member hierarchy of both the structures - date, and employee is shown in Figure 1:
