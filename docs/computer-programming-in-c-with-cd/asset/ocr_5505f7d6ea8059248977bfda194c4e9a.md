# Using Pointers with Character Strings

In C++, a string is nothing but an array of characters ending with a null character `\0`. When you create a character pointer variable to reference a string in C++, the character pointer variable contains the address of first character of the string. Since, the string is internally represented as an array; we can access the individual character of that string by using a pointer. Listing 9 shows an example to understand the concept of accessing a string by using a pointer (you can find the StringPointer.cpp file on the CD in the code\chapter4 folder):

▶ Listing 9: Performing Operations on String Using Pointers

```
#include<iostream.h>
int main()
{
  char *str="HELLO";  //declare character pointer referencing to a string
  cout<<*str<<endl;   //print element at the first element’s address
  cout<<str<<endl;    //print whole string starting from the first element
  str++;
  cout<<*str<<endl;   //print element at the shifted position
  cout<<str;          //print whole string starting from the shifted position
  return 0;
}
```

H
HELLO
E
ELLO
