int x;

Now, after understanding the declaration of int and short int type variables, let’s discuss the declaration of long int type variables. Long int type variables occupy twice the space as compared to the int type variables. The following code snippet shows the declaration of long int type variables:

```
//declaring long int type variables
long int x;
long int sum;
long int age;
```

In the preceding code snippet, the x, sum, and age variables of the long int type are declared. The int, short, and long type variables can also be declared unsigned, as shown in the following code snippet:

```
//declaring unsigned int, short, and long type variables
short unsigned int x;
unsigned int sum;
unsigned long int age;
```
