## Short Questions/Answers

### Q1. Define OOP.

Ans. OOP is a programming model that uses objects to design applications and computer programs. This programming model is based on four basic pillars, namely abstraction, encapsulation, inheritance, and polymorphism. An object is a combination of the data and procedures (sequences of instructions) that act on the data. In OOP, a group of objects that have common properties, operations, and behaviors is called a class. The classes developed for previous applications can be reused so that new applications can be developed faster with improved reliability and consistency of design. An OOP language designs programs around built-in data types and user-defined data types. You can define data types and data-type hierarchies so that you can describe any real entity, such as dogs, kingdoms, students in your application.

### Q2. What are the basic concepts of OOP?

Ans. Object-oriented programming (OOP) is a modular approach to computer program (software) design. The following basic concepts are included in OOP:

- Object: Represents a pattern (instance) of a class, for example, Maruti Zen and Tata Indica are objects and car is their class.
- Class: Defines the abstract characteristics of an object, such as attributes, fields or properties, and the behaviors of objects.
- Instance: Represents an object of a class, for example, triangles, quadrangles, pentagons, and hexagons are instances of the Polygon class.
- Method: Represents an object's abilities to perform a task.
- Message Passing: Represents interaction between two or more objects by sending and receiving messages.
- Abstraction: Represents essential characteristics of an object without including background details or explanations.
- Encapsulation: Refers to a feature of OOP that prevents access to non-essential details of a class. It is also referred to as data hiding, since it hides important but unnecessary details of an object or class from the user.
- **Inheritance:** Refers to a mechanism that allows a class to inherit properties from another class.
- **Polymorphism:** Refers to the ability of an object to exist in different forms.

### Q3. Explain objects by giving some examples.

Ans. An object is a pattern (instance) of a class. For example, Maruti Zen and Tata Indica are objects of the car class. An object represents a real world entity as well as a programming entity. Professors, doctors, and students are examples of real world entities; whereas, hardware and software components of a computer, constants, variables are examples of programming entities. An object has the following three main characteristics:

- It has a state
- It may or may not display a behavior
- It has a unique identity

### Q4. What is message passing in OOP?

Ans. In OOP, a program consists of a group of objects that communicate with each other by sending and receiving messages. A message is a request, which is sent by an object, to execute a procedure and to call a procedure in the receiving object that generates the result. Message passing is carried out by specifying the name of an object, the name of a function (or called message), and the information to be sent. The communication among objects can be possible as long as the objects exist.

### Q5. How encapsulation differs from abstraction in OOP?

Ans. Encapsulation is a feature of OOP that prevents access to non-essential details of a class. For example, when you switch on a television set, it displays the programs being telecast in the form of audio and video. You cannot see the actual complex process of the television, such as how the signals from the cable are being transformed into audio and video.

Abstraction, on the other hand, is the representation of essential characteristics of an object without including background details or explanations. You are unable to deal with the complexity of an object, so you generally tend to ignore non-essential details of the object and concentrate only on those details that are essential to our understanding or requirement. For instance, if you want to buy a television, you would typically pay attention to the size, ease of handling, color, its guarantee and warranty; however, you would not be interested in the gadgetry (internal part) inside it.

Moreover, the concepts of data abstraction and data encapsulation are supported in C++ by using the public and private keywords, respectively.

### Q6. What is a default constructor?

Ans. A default constructor is a constructor that either has no parameter, or has parameters with default values.
