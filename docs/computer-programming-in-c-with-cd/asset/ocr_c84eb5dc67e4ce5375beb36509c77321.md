**Table 1: Member Accessibility of Members of the Base and Derived Classes in Different Types of Derivations**

| Derivation | Code | Accessibility to the Derived Class Object: Private Members | Accessibility to the Derived Class Object: Protected Members | Accessibility to the Derived Class Object: Public Members |
|---|---|---|---|---|
| private | ```cpp
class Base
{
    int pv1;
protected:
    int pr1;
public:
    int pb1;
    void pbBaseFunc();
};
class Derived : private Base
{
    int pv2;
protected:
    int pr2;
public:
    int pb2;
    void pbDerivedFunc();
};
``` | pv1 and pv2 | pr1, pb1, pbBaseFunc(), and pr2 | pb2 and pbDerivedFunc() |

``` | pv1 and pv2 | pr1, pb1, pbBaseFunc(), and pr2 | pb2 and pbDerivedFunc() |

class Base

    int pv1;
