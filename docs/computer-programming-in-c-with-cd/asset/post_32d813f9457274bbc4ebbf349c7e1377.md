## Creating Inline Function

While creating and using functions in a C++ program, the control of execution is transferred to the function definition, when a function is called. Once the function finishes its execution, the control of execution is transferred to the calling program. This process consumes time and system resources, such as memory and registers. When you use this process for executing large functions, it does not affect the performance of the program; but when the function contains few lines of code, the performance of the program gets degraded. To avoid degrading the performance of the program, the inline functions are used. The use of the inline function enables the compiler to copy the code from the function definition to the code of calling program, which prevents the program from creating a separate set of instructions in memory. In other words, inline function avoids function call overhead by modifying the function body. This modified function body is then directly substituted to the function call. The following is the syntax for declaring inline function:

```cpp
inline return_type function_name(argumentlist)
{
    return ....;
}
```

In the preceding syntax, the inline function is very similar to a normal function. The only difference is that you have to mention the keyword `inline` before declaring a function. We can use inline function where we want to call a function more than once in a program. This saves the processing time and memory space as this function uses modified copy of function's body. Listing 20 shows how to define an inline function. You can find the Func15.cpp file on the CD in the code/chapter3 folder:

### ▶ Listing 20: Creating an Inline Function

```cpp
#include <iostream.h>

// an inline function definition
inline double square(double value)
{
    return value * value;
}

int main()
{
    double x, y;
    double z = 15.0;
    x = square(4.0);
    y = square(3.5 + 8.5);   // argument can be passed as expressions
    cout << "Square of 4 " << x << endl;
    cout<<"Square of (3.5 + 8.5) = " << y <<endl;
    cout << "Value of z = " <<z;
    cout << " and square is : "<< square(z++)<<endl;
    cout << "Now value of z = "<<z<<endl;
    return 0;
}
```

**Output:**

```text
Square of 4 = 16
Square of (3.5 + 8.5) = 144
Value of z = 15 and square is : 225
Now value of z = 16
```

In Listing 20, the `square()` function is defined as inline function to perform square of any number.

## Using String Library Functions

The string library functions are standard library functions that are used for manipulation of string. This includes reversing a string, copying a string, finding length of a string and concatenating of two strings. The following are some of the commonly used library functions among the various types of library functions:

- `strcmp()`
- `strcat()`
- `strrev()`
- `strcpy()`
- `strlen()`

Let’s discuss each of these functions in detail in the following section.

### The strcmp() Function

The `strcmp()` function takes two strings as parameters and compares these strings. The strcmp() function returns an integer value indicating the relationship between the strings. A zero value indicates that both strings are equal. A value returned from strcmp() function, which is greater than zero indicates that the first character that does not match has a greater value in string1 than in string2. A value less than zero indicates that the first character that does not match has a lesser value in string1 than in string2. An example of using the `strcmp()` function is shown in Listing 21. You can find the Func16.cpp file on the CD in the code/chapter3 folder:

### Listing 21: Using the strcmp() Function

```cpp
#include <iostream.h>
#include <string.h>
int main()
{
    char string1[] = "bat";
    char string2[] = "cat";
    int result = strcmp(string1, string2);
    if (result > 0)
    {
        cout << "string1 is greater than string2" <<endl;
    } else if (result == 0)
    {
        cout << "string1 is equal to string2" <<endl;
    } else if (result < 0)
    {
        cout << "string1 is less than string2" << endl;
    }
    return 0;
}
```

**Output:**

```text
string1 is less than string2
```

In Listing 21, the strcmp() standard library function is used to compare string1 to string2. The value of string1 is bat and the value of string2 is cat. Now, the values of these variables are compared by using the strcmp() function that returns an int value. This int value is then checked by using the if statement, whether the two strings are equal or not.
