Listing 28 shows an example of creating a pointer object of a class (you can find the PointerObject1.cpp file on the CD in the Code\Chapter7 folder):

# ▶ Listing 28: Creating a Pointer Object

```
```cpp
#include<iostream.h>
class ABC
{
int num1;
//private data member
public:
int num2;
//public data member
void setValue(int);
void displayValue();
};
void ABC::setValue(int p)
{
num1=p;
}
void ABC::displayValue()
{
cout<<"num1 = "<<num1<<endl;
cout<<"num2 = "<<num2<<endl;
}
void main()
{
ABC obj, *ptr;
// Creating a pointer as well as a normal object
ptr=&obj;
//pointer object is assigned
ptr->setValue(44);
ptr->num2=76;
(*ptr).displayValue();
}

Output:

num1 = 44
num2 = 76
```
```

In Listing 28, the ABC class is created, which has one private member, num1, and three public members, num2, setValue(), and displayValue(). The setValue() and displayValue() functions are defined outside the the ABC class by using the :: operator. In the main() function, obj and ptr are normal object and pointer object, respectively, of the ABC class. The reference of the obj object is assigned to the ptr object. The -> operator is used to access the members, setValue() and num2, and the displayValue() function of the ABC class is accessed by using the . operator.
