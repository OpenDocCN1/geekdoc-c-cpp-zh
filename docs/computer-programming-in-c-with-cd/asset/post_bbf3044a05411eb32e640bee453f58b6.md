
## 6.15 Overloading

When you perform more than one task by using the same function or operator, it is known as overloading. If you specify more than one definition for a function name or an operator in the same scope, you have overloaded that function name or operator.

When you call an overloaded function name or operator, the compiler determines the most appropriate function or operator to be used. The compiler compares the arguments that you have used to call the function or operator with the arguments specified in the function or operator definitions. The process of selecting the most appropriate overloaded function or operator is called overload resolution.

In C++, you can overload the following:

- A function
- A constructor
- An operator

Let’s learn how to overload each of these, one by one:

### Function Overloading

Function overloading is the process of using the same name for two or more functions. Each redefinition of a function must use different types of function signatures. A function signature consists of the following three parts:

- The number of parameters in the function. Consider the following declaration:

```cpp
void DisplayData(int a, int b);
void DisplayData(int a);
```

In the preceding declaration, the DisplayData() function is overloaded. The DisplayData() function appears in two forms. In the first form, the DisplayData() function takes two parameters while in the second form, it takes just one parameter.

- The data types of the parameters. Consider the following declaration:

```cpp
void DisplayData(int a);
void DisplayData(char a);
```

In the preceding declaration, the DisplayData() function is overloaded. This is because the data types of the parameters of the DisplayData() function are different.

- The order of the data types of the parameters. Consider the following declaration:

```cpp
void DisplayData(int a, float b);
void DisplayData(float a, int b);
```

In the preceding declaration, the DisplayData() function is overloaded. This is because the order of the data types in the parameters of the DisplayData() function are different.

> *The return type is not a part of the signature of a function. Therefore, the following occurrences are not valid in a class:*
>
> `void DisplayData();`
> `char DisplayData();`
>
> *In other words, the DisplayData() function is not overloaded, as the return types of this function are different.*

In function overloading, when you have multiple functions with the same name, the compiler identifies the function based on its parameters. Listing 38 shows how to implement function overloading in a class (you can find this example in the FunctionOverload.cpp file on the CD in the code\chapter6 folder):

**▶ Listing 38: Overloading of a Function in a Class**

```cpp
#include<iostream.h>

class Arithmetic
{
public:
    void calc(int x)
    {
        cout<<"The area of the square is:"<<x*x<<endl;
    }
    void calc(int a, int b)
    {
        cout<<"The area of the rectangle is:"<<a*b<<endl;
    }
    void calc(int l, int b, int h)
    {
        cout<<"The volume of the cuboids' is:"<<l*b*h<<endl;
    }
};

int main()
{
    Arithmetic ar;
    ar.calc(10,20,30);
    ar.calc(45);
    ar.calc(50,70);
    return 0;
}
```

**Output:**

```text
The volume of the cuboids' is:6000
The area of the square is:2025
The area of the rectangle is:3500
```

In Listing 38, there are three functions with the same name, calc. In the main function, when the calc function is invoked using an object, the compiler binds the call to the function depending upon the type and number of parameters. When the function calc(10,20,30) is called, the compiler checks for the function matching the parameter type, and then the call to the calc(int, int, int) function is invoked and output is displayed. Similarly, when the calc(45) and calc(50, 70) functions are called, the compiler invokes the void calc(int x) and void calc(int a, int b) functions, respectively.

In C++, object’s data members can be dynamically initialized during runtime, even after their creation. The dynamic initialization of the data members of an object is performed by using overloaded constructors. It provides flexibility of using different forms of data at runtime depending upon the user’s need.

### Operator Overloading

The concept of overloading a function or a constructor can be applied to operators as well. Operator overloading refers to provide additional meaning or functionalities to normal operators when they are applied to user-defined data types, such as structures and classes. The compiler identifies an overloaded operator itself when it (the compiler) finds the data type of the operand is a user-defined data type. If the data type of the operand is a built-in data type, then the compiler performs the normal operations. For example, consider the following code snippet:

```cpp
z = x + y;
```

In the preceding code snippet, the operation of addition (+) is valid if x, y, and z are instances of built-in data types. However, you can use the objects of a class in place of these built-in data types. This means that the + operator with the objects of a class is also valid. Operator overloading is one of the nicest features of C++, as it enables you to make the standard operators, such as +, -, >,++ to work with objects of your own classes.

An operator can be overloaded by defining a function for it. The function for the operator is declared by using the operator keyword. The syntax to overload an operator is:

```cpp
returntype classname:: operator operator_symbol(argument-list)
{
    // body of the operator function
}
```

In the preceding syntax, the operator_symbol is an operator that can be any valid operator, such as +,-,*,/,++ ,--,<,>. The operator symbol must be preceded by the operator keyword.

A function that is preceded by the operator keyword is called an operator function. An operator function redefines a particular operator so that it performs a specific operation when it is used with the object of a class. The following code snippet shows an example of the operator function:

```cpp
int operator +(int a, int b)
{
    return a+b;
}
```

In C++, an operator function can be either a member function or a friend function. The number of arguments taken by a member function of a class differs from the number of arguments taken by a friend function to overload a unary operator or a binary operator.
