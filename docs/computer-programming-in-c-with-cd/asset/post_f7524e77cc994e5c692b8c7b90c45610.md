
Q5. List the manipulators provided by the C++.

Ans. The following is the list of the manipulators:

- `endl`: Displays the output on a new line. The endl manipulator sends a newline character to the output stream.
- `setw()`: Accepts an integer parameter and sets the width of each item given to the output stream.
- `setprecision()`: Sets the number of digits to be shown after the decimal point.

Q6. What do you mean by conditional statement?

Ans. A conditional statement is a control statement that allows choosing between two or more execution paths in a program. Conditional statements cause a program to execute a block of code on evaluating a conditional expression. If the conditional expression comes out to be true, the accompanying block of code is executed and if it is false, the accompanying block of code is bypassed.

Q7. List the conditional statements supported by C++.

Ans. The following is the list of the conditional statements supported by C++:

- if statement
- if-else statement
- Nested if statements
- if-else ladders
- switch statement
- Nested switch statement

Q8. What do you mean by Iteration statement?

Ans. Iteration statements or loops repeatedly execute a block of code based on a condition. Once the conditional expression evaluates to false, the loop exits. After that, the control transfers to the next statement that follows the loop.

Q9. List the Iteration statements supported by C++.

Ans. The following is the list of the Iteration statements supported by C++:

- **while loop:** Executes statements in its body until a condition evaluates to true. Once the condition becomes false, the loop gets terminated.
- **do-while loop:** Executes the code at least once and then check the condition. It executes a group of statements as long as the condition is true. If the condition becomes false, the flow of execution comes out of the do-while loop.
- **for loop:** Iterates over a fixed number of times and consists of three parts, such as initialization, conditional expression, and post expression

Q10. What do you mean by the Jump statement? List the Jump statements supported by C++.

Ans. Jump statements are the statements that transfer control from one part of the program to another. The following are the jump statements supported by C++:

- break statement: Used to exit from loops and conditional statements
- continue statement: Used to quit iteration of the current loop and begin executing the next iteration
- goto statement: Used to perform an unconditional transfer of control to another statement in the code
- exit and abort statements: Used to end C++ programs

Q11. What is the difference between the break statement and the exit statement?

Ans. The break statement is used to exit from loops and conditional statements; whereas, the exit() function is used to end or terminate a C++ program. The exit() function also returns a value. If the return value is 0 or EXIT_SUCCESS, this indicates successful termination of the program, and if any other value or the constant EXIT_FAILURE is returned, this indicates an error.

Q12. What is the difference between the exit() function and abort() function?

Ans. The exit() and abort() functions are used to end C++ programs. The difference between exit() and abort() is that exit() allows the normal C++ runtime termination processing to take place, but abort() just stops the program immediately.
