# ## Hierarchical Inheritance

A form of inheritance where two or more derived classes are inherited from one base class is called hierarchical inheritance, as shown in Figure 4:

![](bbox=[0.287, 0.185, 0.773, 0.339])

▲ Figure 4: Displaying Hierarchical Inheritance

In Figure 4, class A is the base class of the B and C classes.

Listing 17 shows an example of hierarchical inheritance (you can find the HierarchicalInheritance.cpp file on the CD in the Code\Chapter7 folder):

```cpp
#include<iostream.h>

class A
{
protected:
 int a;
};
class B:public A
{
protected:
 int b;
public:
 void display()
 {
  a=10;
  b=20;
  cout<<"Class B Display method"<<endl;
  cout<<"Class A variable calling"<<endl;
  cout<<"Value in variable a="<<a<<endl;
  cout<<"Class B variable calling"<<endl;
  cout<<"Value in variable b="<<b<<endl<<endl;
 }
}
