# Creating Nested for Loop

A for loop contained in another for loop is called a nested for loop. In the nested for-loop, execution starts from the outer for-loop and the control then passes to the inner for-loop. The inner for-loop then continues execution till the condition of inner for-loop evaluates to true. Once inner for-loop is completed, the flow of execution is passed to outer for-loop to continue the next iteration and then once again the inner for-loop is executed. This implies that for each iteration of the outer loop, the inner loop is executed completely. Listing 24 shows the use of nested for loops (you can find this example in the forloop2.cpp file on the CD in the code\chapter2 folder):

# ▶ Listing 24: Nesting `for` Loop

```
#include<iostream.h>
int main()
{
    int x,y,sum;
    for(x=1;x<=2;x++)
    for(y=1;y<=2;y++)
    {
        sum=x+y;
        cout<<"x:"<<x<<endl;
        cout<<"y:"<<y<<endl;
        cout<<"Sum:"<<sum<<endl<<endl;
    }
    return 0;

}
```
