```
    A a;                    // Error: Class A is an abstract class

```

In the preceding code snippet, class A is an abstract class. The compiler neither allows the A g() or void h(A) function declarations nor the declaration of an object of class A. Virtual member functions are inherited. A class derived from an abstract base class becomes abstract unless you override each pure virtual function of the base class in the derived class. For example, in the following code snippet, the compiler does not allow the creation of an object of the B class, as B is an abstract class:

```
class A {
public:
    virtual void f() = 0;
};

class B : public A {
    void g();
};
int main() {
    B obj;        /*This line gives a compile error, as we cannot create an
                   instance of abstract class*/
    return 0;
}
```

In the preceding code snippet, within the main() function, the compiler does not allow you to create an object of class B because this is an abstract class and it inherits the pure virtual function, f(), from class A. Creating an instance of an abstract class generates a compile time error. An abstract class is basically used as a base class only.

> > You can derive an abstract class from a non abstract class, and override a non-pure virtual function with a pure virtual function.
