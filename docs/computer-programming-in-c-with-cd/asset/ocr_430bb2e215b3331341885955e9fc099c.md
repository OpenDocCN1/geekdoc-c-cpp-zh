Q9. According to the Fibonacci sequence, "The first two values in the sequence are 1 and 1. Every subsequent value is the sum of the two values preceding it." Write a program that prompts the user for n and prints the nth value of the Fibonacci sequence.

Ans.

```
~~~cpp
//Program to print nth term of Fibonacci series
#include<iostream.h>
void main()
{
    int i,j,k,n,o;
    cout<<"\n Give the value of n:-";
    cin>>n;
    i=1;j=1;
    for(o=1;o<=n-1;o++)
    {
        k=i+j;
        i=j;
        j=k;
    }
    cout<<"\nThe nth term is "<<i;
}
// end of program
~~~
```

The nth term is 34

Q10. Write a program to compute sum of n number using for loop (n can be any integer number supplied by the user at run-time).

Ans.

```
~~~cpp
#include<iostream.h>

void main()
{
    int n,sum=0;
    cout<<"Enter the value of n :";
    cin>>n;
    for(int i=0;i<=n;i++)
    {
        cout<<i<<endl;
        sum += i;
    }
    cout<<"Sum of "<<n<<" number is :"<<sum;
}
~~~
```
