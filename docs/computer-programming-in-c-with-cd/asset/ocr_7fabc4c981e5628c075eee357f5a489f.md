# ➜ Arithmetic Operators

The arithmetic operators are used to perform basic operations, such as addition, subtraction, division, and multiplication. Table 7 lists all the arithmetic operators provided in C++:

**Table 7: Arithmetic Operators**

| Operator | Functionality | Associativity |
|---|---|---|
| * | Multiplication | Left to right |
| / | Division | Left to right |
| % | Modulus | Left to right |
| + | Addition | Left to right |
| - | Subtraction | Left to right |

The * operator is used to multiply values and the / operator is used to divide values. The % (modulus) operator calculates the remainder, for example, 10%3 = 1. The + operator adds two or more values and the - operator is used to subtract values. Listing 14 shows the use of all the arithmetic operators (you can find the ArithmeticEx.cpp file on the CD in the code/chapter1 folder):

# ▶ Listing 14: Using Arithmetic Operators

```
```cpp
#include <iostream.h>
int main()
{
    int x = 10, y = 3, sum, sub, div, mod, mul;
    sum = x + y;
    sub = x - y;
    div = x/y;
    mod = x%y;
    mul = x * y;
    cout << “Addition of “ << x << “ and “ << y << “ is : “ << sum <<
    endl;
    cout << “Subtraction of “ << x << “ and “ << y << “ is : “ << sub <<
    endl;
    cout << “Division of “ << x << “ and “ << y << “ is : “ << div <<
    endl;
    cout << “Modulus of “ << x << “ and “ << y << “ is : “ << mod <<
    endl;
    cout << “Multiplication of “ << x << “ and “ << y << “ is : “ << mul <<
    endl;
    return 0;
}
```
