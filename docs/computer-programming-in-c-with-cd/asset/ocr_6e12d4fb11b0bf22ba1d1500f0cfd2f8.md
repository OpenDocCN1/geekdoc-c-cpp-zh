Q3. Which of the following function reads characters from the keyboard and stores them in variables according to specified formats?

+   A. `putchar()`
+   B. `scanf()`
+   C. `gets()`
+   D. `getchar()`

Ans. Option B is correct.

Q4. Which of the following function prints a string or a value stored in variable to the console screen followed by a new line?

+   A. `printf()`
+   B. `putchar()`
+   C. `scanf()`
+   D. `puts()`

Ans. Option D is correct.

Q5. Which of the following is used to control the format of input or output stream?

+   A. Manipulators
+   B. Conditional statements
+   C. Jump statements
+   D. Iteration statement

Ans. Option A is correct.

Q6. Which of the following manipulator is used to set the number of digits to be shown after the decimal point?

+   A. `setw()`
+   B. `endl`
+   C. `setprecision()`
+   D. `setfill()`

Ans. Option C is correct.

Q7. By using which of the following conditional statement, a statement is executed if the condition is true and another statement is executed if the condition is false.

+   A. `if`
+   B. `if-else`
+   C. `switch`
+   D. `if-else ladder`

Ans. Option B is correct.
