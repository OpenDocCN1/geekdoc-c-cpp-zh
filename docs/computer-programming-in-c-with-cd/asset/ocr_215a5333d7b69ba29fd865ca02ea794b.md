# ### Three-dimensional Array

An array declared with three dimensions is called a three-dimensional array. In other words, the array of two-dimensional array can be said as three-dimensional array. The following is the syntax to declare a three-dimensional array:

```
```
data_type Array_Name[dimension1][dimension2][dimension3];
```
```

In the preceding syntax, the `data_type` is the type of data that will be stored in the array, `Array_Name` is the name of the array, and the `dimension1`, `dimension2`, and `dimension3` are the three dimensions of the array. The three dimensions represent the number of elements that can be stored in the array. For example, the following code snippet shows declaration of a three dimensional array:

```
```
int Arr3[2][2][2];
```
```

In the preceding code snippet, the `Arr3` array is a three-dimensional array that can store eight (2x2x2) integer values. In case of three-dimensional array, the index value ranges from `[0][0][0]` to `[dimension1-1][dimension2-1][dimension3-1]`. For example, first element of the Arr3 array declared in the preceding code snippet can be accessed by using `Arr3[0][0][0]` index and the last element of it can be accessed by using `Arr3[1][1][1]` index.

Initialization of the three-dimensional is very similar to the initialization of the one-dimensional and two-dimensional arrays. The following code snippet shows the initialization of the Arr3 array declared in the preceding code snippet:

```
```
int Arr3[2][2][2]={
                        {
                          {1,2},
                          {3,4},
                        },
                        {
                          {5,6},
                          {7,8},
                        }
                     };
