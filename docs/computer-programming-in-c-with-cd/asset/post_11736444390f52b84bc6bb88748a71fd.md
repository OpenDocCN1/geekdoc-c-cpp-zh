## 6.12 Using the this Pointer

Every member function of a class, in C++, has an implicit pointer called `this`. The `this` pointer points to the object with which the member function is associated. A member function is always invoked containing the value of this pointer. The value of the `this` pointer is set to the address of the object for which it is called. Using the `this` pointer, any member function can find out the address of the object of which it is a member. The `this` pointer can also be used to access the data of the object to which the pointer points. Listing 32 shows an example of the `this` pointer (you can find this example in the UsingThis.cpp file on the CD in the code\chapter6 folder):

```cpp
return Calculate(a,b);
}
```

The sum() function adds the c object to a default object and returns the updated default object by using the following code snippet:

```cpp
return Calculate(a,b);
```

The preceding code snippet can be replaced by the following code snippet:

```cpp
return *this;
```

The modified definition of the sum() function is given in the following code snippet:

```cpp
Calculate Calculate::sum(Calculate c)
{
    a=a+c.a;
    b=b+c.b;
    return *this;
}
```

In the preceding code snippet, the this pointer refers to the same object of which the sum() function is a member, *this refers to the object pointed to by the this pointer. Note that the following code snippet returns the this object by value:

```cpp
return *this;
```

This is because the value of this pointer is different for every individual object, which is declared or created in a program.

## 6.13 Working with Friend Functions and Friend Classes

As you learned earlier, the private members of a class cannot be accessed from outside the class. However, at times, a programmer needs to create two or more classes to share a function, which can access the private members of these classes. In order to access the non-public members of a class, you need to use the friend keyword. This process of declaring the non-members functions or classes as friends is called as friend mechanism.

Let’s now see how to declare a friend function or class under the following heads:

- Defining a friend function
- [ ] Creating a friend function as a bridge between two classes
- [ ] Creating friend classes

### Defining a Friend Function

Functions that are defined outside a class but can still access the private members of the class are called friend functions. A non-member function cannot access the private data of a class. However, any non-member function may be declared a friend by a class so that the function may directly access the private variables and methods of the class objects. Listing 33 shows how to declare and use a friend function (you can find this example in the SimpleFriend.cpp file on the CD in the code\chapter6 folder):

### ▶ Listing 33: Declaring and Using a Friend Function

```cpp
#include<iostream.h>

class Calculate
{
    int x,y;
    public:

    void readData()
    {
        cout<<"Enter any two numbers"<<endl;
        cin>>x>>y;
    }
    friend void add(Calculate c);
};
void add(Calculate cal)
{
    cout<<"The sum of two numbers is:"<<cal.x+cal.y<<endl;
}
int main()
{
    Calculate calc;
    calc.readData();
    add(calc);
    return 0;
}
```

**Output:**

```text
Enter any two numbers
37
82
The sum of two numbers is:119
```

In Listing 33, add (Calculate c) is a global, non-member function that has been declared a friend of the Calculate class. The declaration of a friend function should be preceded by the `friend` keyword. The add() function is defined elsewhere in the program as a normal C++ function. Note that when you define a friend function, you do not need to use the `friend` keyword or the scope resolution operator. A function can be declared as a friend function in more than one class. A friend function, although not a member function, has full rights to access the private members of the class.

The member functions of one class can be friend functions of another class. Such member functions are defined by using the scope resolution operator, as shown in the following code snippet:

```cpp
class A
{
.
.
int display(c);
};
class B
{
.
.
friend int A::display(c)
.
.
};
```

In the preceding code snippet, the display(c) function is a member of class A and a friend of class B.

Some properties of friend functions are given as follows:

- Friend functions are not in the scope of the class in which they have been declared as friend. It means a friend function can be declared anywhere (in public, protected or private section) in the class.
- Since friend functions are not in the scope of the class, they cannot be called using the object of that class.
- A friend function can be invoked as other normal functions without the help of an object.
- Unlike member functions, a friend function cannot access the member names directly and have to use an object name and dot membership operator with each member name.
- Usually, a friend function has objects as arguments.
- Friend functions are non-members of a class, and therefore do not get the this pointer.

A friend function of one class can be a friend of one or more other classes also, and this type of friend function is known as global function.

### ■ Creating a Friend Function as a Bridge between Two Classes

A friend function can act as a bridge between two or more classes. A function, which is declared as a friend of two classes can access the data members of these classes. Listing 34 shows a function as a friend of two classes (you can find this example in the FriendOfTwoClasses.cpp file on the CD in the code\chapter6 folder):

### ▶ Listing 34: Creating a Function as a Friend of Two Classes

```cpp
#include<iostream.h>

class Time;        //Creating a prototype of a class
class Date
{
int day, month, year;

public:
void setValue(int a, int b, int c)
{
day=a;
month=b;
year=c;
}

friend void displayDateTime(Date,Time); //Creating prototype of a friend function
};
class Time
{
int sec;
public:
void setValue(int s)
{
sec=s;
}

friend void displayDateTime(Date,Time);
//Creating prototype of a friend function
};
void displayDateTime(Date dt,Time tm)
//Defining the friend function
{
int hour=tm.sec/3600;
int min=(tm.sec%3600)/60;
cout<<"Date : "<<dt.day<<" / "<<dt.month<<" / "<<dt.year<<endl;
cout<<"Time : "<<hour<<" : "<<min<<endl;
}
void main()
{
Date d;
Time t;
d.setValue(14,05,2009);
t.setValue(14000);
displayDateTime(d,t);
}
```

**Output:**

```text
Date : 14 / 5 / 2009
Time : 3 : 53
```

In Listing 34, we are creating two classes, Date and Time. The displayDateTime() function is declared as a friend function of the Date and Time classes. This function is defined outside the boundary of these two classes. Note that a prototype of the Time class is declared before defining the Date class. A prototype of the Time class is declared, because the forward reference of this class is passed in the declaration of the displayDateTime() function of the Date class. Note that the forward reference of a class means using a class before defining it. The C++ compiler generates a syntax error when it finds such a forward reference. Therefore, you must declare a prototype of the Time class before using its reference in the displayDateTime() friend function.
