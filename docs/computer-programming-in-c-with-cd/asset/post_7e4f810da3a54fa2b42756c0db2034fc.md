## Using gets() and puts() Functions

The gets() function reads a string from keyboard. This function stops reading the string only when you press the ENTER key from the keyboard. The gets() function is similar to the scanf() function. The only difference between the gets() and scanf() functions is that the gets() function can read multiple words, while the scanf() function only read the characters while newline character or space not come in a sentence. Listing 3 shows that the scanf() function cannot store string data of multiple words in a variable (you can find this example in the Function3.cpp file on the CD in the code\chapter2 folder):

### Listing 3: Using the `scanf()` Function

```c
#include<stdio.h>
int main()
{
    char msg[70];
    printf("Enter a message");
    scanf("%s",msg);
    printf("%s",msg);
    return 0;
}
```

```text
Output:

Enter a message
welcome to the plethora of learning
welcome
```

Listing 3 shows that the scanf() function does not read multiple words into an array. This is because when you enter a space after the word welcome, the scanf() function considers it as the end of string and do not consider any character typed after it. The gets() function in place of the scanf() function is used to overcome this problem of storing multiple words into an array.

## Using cout and cin Objects

C++ supports stream objects, such as `cin` and `cout` to handle input and output operations associated with the console devices (keyboard and console screen). A stream is a process of gathering data from keyboard and displaying data on the screen. The `cin` object reads the stream to the standard input device (keyboard). The `cout` object writes the stream to the standard output device (console screen). These stream objects (`cin` and `cout`) are defined in the `iostream.h` header file. The console based I/O operations are performed using `cin` and `cout` objects with the stream operators, such as `>>` and `<<`. The insertion (`<<`) operator is used to send a stream to the `cout` object so that the stream gets printed on the console screen. The extraction (`>>`) operator gets the stream from the keyboard. Listing 5 shows an example of `cout` and `cin` objects (you can find this example in the Function5.cpp file on the CD in the code\chapter2 folder):

### Listing 5: Using the `cout` and `cin` Objects

```cpp
#include <iostream.h>

int main()
{
  int num1,num2,num3;
  cout<<"Enter first number: ";
  cin>>num1;
  cout<<"Enter second number: ";
  cin>>num2;
  cout<<"Enter third number: ";
  cin>>num3;
  cout<<"The average calculated is: "<<(num1+num2+num3)/3;
  return 0;
}
```

```text
Output:

Enter first number: 5
Enter second number: 5
Enter third number: 5
The average calculated is: 5
```

In Listing 5, the `cout` object prompts you to enter first number with a string, `Enter first number:`. The number is then stored in the `num1` variable using `cin` object. You are prompted again to enter another number with a string, `Enter second number:` using the `cout` object. This number gets stored in the `num2` variable. You are prompted again to enter another number with a string, `Enter third number:` to store the value in the num3 variable. Now the program calculates the average of the three numbers that are stored in the variables (num1, num2, and num3). The result (average of these three variables) is displayed on the console screen.
