Q4. What is function prototype?

Ans. The signature of a function is called function prototype. In other words, the return type, function name, number and type of arguments passed to the function is collectively called the function prototype or function signature.

Q5. What is default argument in a function?

Ans. A default argument is a value that is supplied as a formal argument in a function declaration. It is not necessary to pass value for the default argument at the time of calling the function. If you pass the value for the default argument, the function is executed with the specified value; if you call the function without passing value for the default argument, it takes its default value. The default value is specified at the time of defining the program.

Q6. What is standard library function?

Ans. In C++ programming language, the commonly used functions are grouped together and provided with its compiler. The functions of related functionalities are grouped together in a single standard library, such as the cin and cout functions, that are grouped together in the iostream library. This group of related functions is called standard library. The functions of these standard libraries are called standard library functions. Once the functions are grouped in the standard library, you are not required to declare and define them again rather you can use them directly in your program. For using them, you have to include the reference of that library in your program.

Q7. What is function prototype and what does it provide to the compiler?

Ans. In a C++ program, you need to declare a function before providing the definition of the function. This declaration is known as declaring function prototype. In C++, a function prototype specifies function name, function parameters, type of parameters, and function return type, but does not have function body. The body of the function is defined elsewhere in the program. The function prototype directs the compiler about the structure of a function. Therefore, the compiler knows about the prerequisites to call and use the function.
