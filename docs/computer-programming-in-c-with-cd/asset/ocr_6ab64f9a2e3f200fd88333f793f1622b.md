An example of using the * operator for passing arguments to a function is shown in Listing 15. You can find the Func10.cpp file on the CD in the code/chapter3 folder:

# Listing 15: Demonstrating Call by Reference

```
```cpp
#include <iostream.h>

int main()
{
    void swap(int *, int *);
    int num1=40, num2 = 60;

    cout<<"Main: Before Swap num1 = "<<num1<<" and num2 = "<<num2<<endl;
    swap(&num1, &num2);

    cout<<"Main: After Swap num1 = "<<num1<<" and num2 = "<<num2<<endl;
    return 0;
}

void swap(int *a, int *b)
{
    cout<<"Swap: Before Swap a = "<<*a<<" and b = "<<*b<<endl;
    int c;
    c = *a;
    *a = *b;
    *b = c;
    cout<<"Swap: After Swap a = "<<*a<<" and b = "<<*b<<endl;
}
```
```

# Output:

```
```text
Main: Before Swap num1 = 40 and num2 = 60
Swap: Before Swap a = 40 and b = 60
Swap: After Swap a = 60 and b = 40
Main: After Swap num1 = 60 and num2 = 40
```
```

In Listing 15, after calling the swap() function, the value of the num1 and num2 variables is changed because when the swap() function is called, the compiler does not create new variable as in case of call by value. The addresses of the num1 and num2 variables are passed by using the & operator and the value is accessed by using the * operator in the swap() function. In the swap(&num1, &num2) function, the address of the num1 and num2 variable is passed as an argument and the swapping of values is done on the same memory location of the num1 and num2 variables. Therefore, after calling swap() function, the value of num1 and num2 is changed.
