# Short Questions/Answers

Q1. What do you mean by data input and output process?

Ans. The data input and output process in a program refers to the process of accepting and processing the input data, and generating the output based on the processed data. The input and output functions, such as `getchar()`, `putchar()`, `gets()`, `puts()`, `printf()`, and `scanf()` are defined in `stdio.h` header file for performing the I/O operations. C++ uses streams to handle I/O operations. Stream is used to maintain a flow of data from files, memory arrays, keyboard, console, and so on. C++ supports console-based stream handling and file-based stream handling. Stream objects, such as `cin` and `cout` are defined in `iostream.h` header file and are associated with console-based input and output operations.

Q2. List the data input output functions.

Ans. The following are the data input output functions:

+   - `getchar()`: Reads input data from the standard input device that is keyboard
+   - `putchar()`: Writes a character to the current position in the standard output
+   - `gets()`: Reads a string from keyboard and stores it in the buffer
+   - `puts()`: Prints a string or a value stored in a variable to the console screen followed by a new line
+   - `printf()`: Prints a string or a value stored in a variable to the console screen according to the specified format
+   - `scanf()`: Reads characters from the keyboard and stores them in variables according to specified formats

Q3. What do you mean by stream? What are the stream objects supported by C++?

Ans. A stream is a process of gathering data from keyboard and displaying it on the screen. C++ supports mainly two types of stream objects, `cin` and `cout`, to handle input and output operations associated with the console devices (keyboard and console screen). The `cin` object reads the stream to the standard input device (keyboard). The `cout` object writes the stream to the standard output device (console screen).

Q4. What is the difference between the `gets()` function and the `scanf()` function?

Ans. The `gets()` function reads a string from keyboard unless we press the Enter key. The `gets()` function is terminated on pressing the Enter key. The `scanf()` function reads characters from the keyboard and stores them in variables according to specified formats, which are known as format specifiers.

The major difference between the `gets()` and the `scanf()` functions is that the `scanf()` function stops reading the string data if the space is entered. While, you can use the `gets()` function to read the data and store it in the buffer.
