Q11: Write a function named SUMFUN() with argument X and N which return the sum of following series

X - X³/3! - X⁵/5! - X⁷/7! + X⁹/9! - X¹¹/11! +........ (Mumbai University, May 2009)

Ans:

```
float SUMFUN(float X, int N)
{

    float sum=0;
    float Term=X;
    int K=2;
    for (int I=1; I<=N; I++)
    {
        sum=sum + Term;
        Term=Term*X*X/(K*(K+1))*(-1);
        K=K+2;
    }

    return sum;
}
```
