Q15. What happens when a variable is declared with the extern keyword?

Ans. A variable declared with the extern can be globally accessed in a program and from other programs also. The extern keyword is used to declare a global variable in one program and this global variable can be accessed by other program. The extern variable is also known as external variable. This variable is useful in a scenario where a large program is divided into different small programs and external variable is used in each small program.
