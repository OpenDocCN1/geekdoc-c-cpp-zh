# Process Flow of C++ Programs

In the *C++ as a Superset of the C Programming Language* section, you noticed that the basic structure of a C++ program is similar to a C program. Further, terms, such as include and return, which are commonly used in C++, are also similar to the terms used in the C language. This means that writing a program in C++ is easier for those who are acquainted with the C language. Now, let’s learn how to write a C++ program and then compile and run the program.

# Writing a C++ Program

We have already written a simple C++ program in the *C++: Superset of C Programming language* section. Now, let’s understand the basic structure of that program, which is shown in the following code snippet:

```
```cpp
#include <iostream.h>

// Display a welcoming message.
int main() {
    cout << "Hello from C++." << endl;
    return 0;
}
```
```

In the preceding code snippet, all the keywords are in lowercase, which is the way C++ is designed. The very first line of the program includes a `#include` directive that is used to include the header file named iostream in the program. This is done because later in the code, we use the built-in cout C++ object to display the text from this program. The cout object is included in the iostream header file and we need to include this header file to use the cout object.

All preprocessor directives start with the # character, and the two commonly used preprocessor directives are:

+   - `#include`: Includes another file into the current file
+   - `#define`: Defines constant values that you can use in your code. (Although C++ is moving away from the #define preprocessor directive in favor of the const keyword)

![](bbox=[0.2282, 0.7291, 0.26, 0.7582])

> Not every C++ compiler supports the standard C++ header files, such as iostream; if you are using such a compiler, you should use the older syntax, `#include <iostream.h>`, instead of `#include <iostream>`.

Now, you are familiar with the process of using the cout object of the iostream header. This header is a modern standard C++ header file, and is a little different from the older, non-standard C++ and C header files. The difference is that the objects specified in the iostream header are the part of a special namespace named std (for standard).
