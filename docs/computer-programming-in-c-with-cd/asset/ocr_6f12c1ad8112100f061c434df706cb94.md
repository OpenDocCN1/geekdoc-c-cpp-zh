# Creating an Array of Pointer Objects

You can create an array of pointer objects, where each pointer object points to an individual class object. The syntax to declare an array of pointer objects is:

```
```cpp
<class_name> *pointer_name [array_size];
```
```

An example of declaring an array of pointer objects is:

```
```cpp
