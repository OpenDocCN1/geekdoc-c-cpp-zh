+   1. Virtual base class constructors, in the order of inheritance
+   2. Non virtual base class constructors, in the order of inheritance
+   3. Member objects constructors, in the order of declaration
+   4. Derived class constructors

However, the sequence of destructor invocation is the opposite of constructor invocation as far as these classes are concerned, which is as follows:

+   1. Derived class destructors
+   2. Member objects destructors, in the reverse order of declaration
+   3. Non virtual base class destructors, in the reverse order of inheritance
+   4. Virtual base class destructors, in the reverse order of inheritance

**Q8.** How a protected member of a class plays an important role in inheritance?

**Ans.** The protected access specifier enables the members of a class to be accessible or visible in the same class and in the derived classes of the class. A protected member of a class can be considered as a combination of private and public members. This means that a protected variable of a class is accessible within the member functions of the class, and is invisible outside the class. However, a protected variable is inherited by the derived class from its base class, and can be accessed by the member functions of the derived class.

**Q9.** Differentiate between private and public inheritance

**Ans.** In private inheritance, all the private members of a base class remain private in the base class, and all public and protected members of the base class become private members of the derived class. In public inheritance, all private members of a base class remain private in the base class, protected members remain protected in the derived class, and public members remain public in the derived class. Note that private members of a base class are never inherited to its derived classes.

**Q10.** What is a pure virtual function?

**Ans.** A virtual function with no body is called the pure virtual function. This is achieved by adding the notation =0 to the declaration of the virtual function. The following code snippet shows an example of declaring a pure virtual function, called displayResult():

```
virtual int displayResult() = 0;
```

**Q11.** Explain the concept of abstract class with an example.

**Ans.** In the real world, all objects cannot be modeled in the same manner. In fact, some classes are too abstract to exist by themselves. For example, if someone asks you to draw a shape, you will want to know the kind of shape. The term shape is an abstract concept; it could be a circle, a square, and so on. In C++, we create a base class as an abstract base class to represent an abstract concept. An abstract base class defines the properties that are common to other the classes derived from it. Therefore, we can say class that Shape is an abstract base class and Circle is one of its derived classes.
