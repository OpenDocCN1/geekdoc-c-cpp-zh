# Using String Library Functions

The string library functions are standard library functions that are used for manipulation of string. This includes reversing a string, copying a string, finding length of a string and concatenating of two strings. The following are some of the commonly used library function among the various types of library functions:

+   - `strcmp()`
+   - `strcat()`
+   - `strrev()`
+   - `strcpy()`
+   - `strlen()`

Let’s discuss each of these functions in detail in the following section.

# The strcmp() Function

The `strcmp()` function takes two strings as parameter and compares these strings. The strcmp() function returns an integer value indicating the relationship between the strings. A zero value indicates that both strings are equal. A value returned from strcmp() function, which is greater than zero indicates that the first character that does not match has a greater value in string1 than in string2. A value less than zero indicates that the first character that does not match has lesser value in string1 than in string2. An example of using the `strcmp()` function is shown in Listing 21.
