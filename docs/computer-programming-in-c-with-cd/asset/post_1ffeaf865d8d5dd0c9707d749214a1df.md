## Short Questions/Answers

Q1. What is array? How does it help programmers?

Ans. An array is a linear collection of variables of similar data type. The elements of an array are stored in the contiguous memory locations. It helps the programmers to avoid remembering and handling multiple variables. Instead of declaring and using multiple variables, programmers can use an array to store multiple data values of similar data type.

Q2. Define the types of array briefly.

Ans. There are three types of array mentioned as follows:

1. One-dimensional array: Contains only one dimension and declared as `array_name[size]`.
2. Two-dimensional array: Contains two dimensions and declared as `array_name[rows][column]`.
3. Three-dimensional array: Contains three dimensions and declared as `array_name[dimension1][dimension2][dimension3]`.

Q3. What is function and how many types of functions can be used in C++?

Ans. A function is a group of statements that performs a specific task when executed. The two types of functions supported in C++ are as follows:

1. Standard library function  
2. User-defined function

Q4. What is function prototype?

Ans. The signature of a function is called function prototype. In other words, the return type, function name, number and type of arguments passed to the function is collectively called the function prototype or function signature.

Q5. What is default argument in a function?

Ans. A default argument is a value that is supplied as a formal argument in a function declaration. It is not necessary to pass value for the default argument at the time of calling the function. If you pass the value for the default argument, the function is executed with the specified value; if you call the function without passing value for the default argument, it takes its default value. The default value is specified at the time of defining the program.

Q6. What is standard library function?

Ans. In C++ programming language, the commonly used functions are grouped together and provided with its compiler. The functions of related functionalities are grouped together in a single standard library, such as the cin and cout functions, that are grouped together in the iostream library. This group of related functions is called standard library. The functions of these standard libraries are called standard library functions. Once the functions are grouped in the standard library, you are not required to declare and define them again rather you can use them directly in your program. For using them, you have to include the reference of that library in your program.

Q7. What is function prototype and what does it provide to the compiler?

Ans. In a C++ program, you need to declare a function before providing the definition of the function. This declaration is known as declaring function prototype. In C++, a function prototype specifies function name, function parameters, type of parameters, and function return type, but does not have function body. The body of the function is defined elsewhere in the program. The function prototype directs the compiler about the structure of a function. Therefore, the compiler knows about the prerequisites to call and use the function.

Q8. What do you understand by recursive function?

Ans. To minimize the repetition of code in a function, you can write a function that calls itself. The situation in which a function calls itself is called recursion and that function is called a recursive function. This function is called repeatedly, unless the code included in the body of function terminates the chain of calls by implementing a condition within an if statement. You can use a recursive function with the if statement within the body of function.

Q9. What is inline function?

Ans. Inline functions are those functions created with the *inline* keyword. The use of the inline function enables the compiler to copy the code from the function definition to the code of calling program, which prevents the program from creating a separate set of instructions in memory. This results in less overhead for the compiler and helps in faster execution of the program.

Q10. Explain the strcmp() function.

Ans. The `strcmp()` function takes two strings as parameter and compares these strings. The strcmp() function returns an integer value indicating the relationship between the strings. A zero value indicates that both strings are equal. A value returned from strcmp() function, which is greater than zero, indicates that the first character that does not match has a greater value in string1 than in string2. A value less than zero indicates that the first character that does not match has lesser value in string1 than in string2.

Q11. Explain the strlen() function.

Ans. The `strlen()` function is used to find the length of a string. It takes one string as an argument to count number of characters in the string.

Q12. Explain the strcpy() function.

Ans. The `strcpy()` function is used to copy the content of first string to second string. You have to pass two strings as an argument of the strcpy() function to copy first string to second string.

Q13. What happens when a variable is declared with the static keyword?

Ans. When a variable is declared as `static`, it means that the variable is allocated in memory when the function (containing static variable) starts execution. As soon as the function terminated, it destroys all it variables but not the static variable. This helps the function to preserve the value of its variable between various function calls during the program execution.

Q14. What happens when a variable is declared with the const keyword?

Ans. As the name suggests, the `const` keyword specifies that a variable once declared and initialized cannot be changed. It is used where you do not want to change the value of the variable within a program.
