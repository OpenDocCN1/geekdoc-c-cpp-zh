# Passing Function Argument as const

When you declare a const variable, it means that you cannot change its value in a program. You can pass an argument to a function to perform specific task within the body of a function. You can also change the value of argument within body of a function. When you pass const variable as argument to a function, you cannot modify the original data of the const variable within the body of function. The compiler produces an error message Cannot modify a const object.
