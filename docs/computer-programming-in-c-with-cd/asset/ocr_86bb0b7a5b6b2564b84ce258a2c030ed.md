# # Introduction

Congratulations on buying the *Computer Programming in C++* book! This book contains comprehensive content on the various concepts of Object Oriented Programming (OOP) and C++ language. OOP is a programming model that uses objects and their interactions to design applications and computer programs. The OOP model is based on four basic pillars, namely abstraction, encapsulation, inheritance, and polymorphism. In OOP, objects represent real world entities, which have their own attributes. Earlier programming languages, for instance C, are based on procedural language, where programs often use branching statements and procedures to execute one or more set of instructions. OOP, however, is a modular approach to comprehend the design and functioning of a computer program. Each module in an OOP program is an object, which is a combination of the data and procedures that act on the data.

C++ is the first Object Oriented language, which has evolved from C. C++ implements the concept of objects in programming. Objects in an object oriented programming language are independent of each other, and changes in the functionality of one object do not affect the other objects. Therefore, it becomes easier to manage large programs created in C++.

Many companies are using C++, compared to C, to build applications that require syntactic convenience, compile time type-checking, memory allocation and initialization, and reuse of code through derivation. The IT industry has witnessed major corporations shifting from C to C++ for in-house programming.
