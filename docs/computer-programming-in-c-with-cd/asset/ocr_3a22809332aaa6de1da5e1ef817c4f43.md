# Using cout and cin Objects

C++ supports stream objects, such as `cin` and `cout` to handle input and output operations associated with the console devices (keyboard and console screen). A stream is a process of gathering data from keyboard and displaying data on the screen. The `cin` object reads the stream to the standard input device (keyboard). The `cout` object writes the stream to the standard output device (console screen). These stream objects (`cin` and `cout`) are defined in the `iostream.h` header file. The console based I/O operations are performed using `cin` and `cout` objects with the stream operators, such as `>>` and `<<`. The insertion (`<<`) operator is used to send a stream to the `cout` object so that the stream gets printed on the console screen. The extraction (`>>`) operator gets the stream from the keyboard. Listing 5 shows an example of `cout` and `cin` objects (you can find this example in the Function5.cpp file on the CD in the code\chapter2 folder):
