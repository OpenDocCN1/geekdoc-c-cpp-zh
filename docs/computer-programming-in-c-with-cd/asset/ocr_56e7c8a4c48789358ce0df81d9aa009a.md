# ## 6.14 Declaring and Using Static Variables and Functions

In C++, a data member (variable) or a member function of a class can be declared static, by using the `static` keyword. When you declare a data member or a member function of a class as static, they belong to the class only, and not to the objects of the class. This means that when a variable is declared as static in a class, the instances (objects) of the class share the same copy of that variable. In addition, a static function can be invoked simply with the class name (without using class's object).

Some important points to be considered before declaring the static members within a class are as follows:

+   - Static members are allocated, regardless of their scope, as soon as the execution of a program starts.
