It is also possible to create a function that does not return a value after execution using the void keyword. Let's discuss function returning void in the following section.

# Describing Function Returning void

In a program, if you want a function not to return any value, you can use the void keyword as the function return type. A function that does not return any value is called a function returning void. The function terminates without the return statement at the end of function body and the execution of program is transferred to the next statement of calling function.
