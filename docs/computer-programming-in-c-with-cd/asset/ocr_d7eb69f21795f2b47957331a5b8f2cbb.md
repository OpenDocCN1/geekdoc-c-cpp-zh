# **Streams in C++**

A stream is a sequence of bytes that can either serve as the source from which the input data can be obtained or a destination to which the output data can be sent. The stream that serves as the source from which the data is taken is known as the input stream and the destination stream, that is, the stream to which the data is sent, is known as the output stream. In other words, a C++ program retrieves the bytes from an input stream and inserts the bytes into the output stream.
