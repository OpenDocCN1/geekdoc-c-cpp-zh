+   - There can be only one destructor in each class. This is because there is only one way to destroy an object.
+   - Destructors do not take arguments, therefore, they cannot be overloaded.

You can use the constructor of a class to allocate memory by using the new operator and the destructor of a class to free the memory by using the delete operator.
