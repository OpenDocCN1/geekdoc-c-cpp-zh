We have covered how an address of a variable is obtained by using the & operator. Let’s now discuss how to declare pointers.

## Declaring Pointers

A pointer variable is declared as a normal variable. It stores the address of another variable of a particular data type. Therefore, it is necessary to specify the data type of a pointer variable while declaring it. For example, to store the address of the `int` variable, you need an integer pointer, as shown in the following code snippet:

```c
int x;
int *ptr;
ptr=&x;
```

In the preceding code snippet, a variable x of the int type is declared. A pointer variable ptr of the int type is also declared by using an asterisk (*) character. Then, we assign the address of the x variable into the integer pointer variable ptr.

The placement of the * character is not fixed while declaring a pointer variable. To declare a pointer variable, you can use either of the following code snippet:

```c
int *ptr;
```

or

```c
int * ptr;
```

or

```c
int* ptr;
```

However, a pointer declaration becomes invalid if it is declared in the following ways:

```c
int ptr*;
```

or

```cpp
*int ptr;
```

## Creating and Using Pointers

While creating a pointer, firstly you need to declare a pointer variable and then to store the address of another variable in it. A pointer variable can directly access the value stored in other variable by using the * operator as shown in the following code snippet:

```cpp
cout<< *ptr;
```

In the preceding code snippet, the * operator indicates the compiler to access and display the value stored at the memory location referenced by the ptr pointer variable.

The * operator is also known as the dereference operator. The dereference operator (*) accesses the data stored in the variable pointed by the pointer variable. The use of pointer variable can be understood with the help of the Figure 1, as follows:

In Figure 1, a pointer variable ptr is created that stores the address of the var variable by using the &var expression. The var variable is initialized with 1. The * operator used with ptr (*ptr) directs the compiler to access the data stored in the var variable by using the address of var variable. Listing 2 shows the use of the * operator (you can find the UsingPointer.cpp file on the CD in the code\chapter4 folder):

In Listing 2, a pointer variable named `ptr` is declared. The memory address of the variable `var` is accessed by using the `&` operator and is assigned to the pointer variable. The data stored in the variable `var` is accessed by using the `*ptr` expression.

Apart from accessing value stored in the referenced variable, a pointer can also set the data in the variable that it points to. Listing 3 shows how to set a value of a variable by using pointer (you can find the `AssignValue.cpp` file on the CD in the `code\chapter4` folder):

### Using Pointer to Pointer

As stated earlier, a pointer is a variable that contains memory address of another variable. However, a pointer may contain the memory address of another pointer. For example, there is an integer variable `MyInt` and two integer pointer variables `MyIntP1` and `MyIntP2`. The integer pointer `MyIntP1` points to the memory address of `MyInt` variable and the integer pointer `MyIntP2` points to the memory address of `MyIntP1`, then the integer pointer `MyIntP2` should be termed as a pointer to pointer. Listing 5 shows the creation of pointer to pointer variable (you can find the `PointerToPointer.cpp` file on the CD in the code\chapter4 folder):

**▶ Listing 5: Creating a Pointer to Pointer variable**

```cpp
#include <iostream.h>

int main ()
{
  int MyInt, *MyIntP1, **MyIntP2;
  MyInt = 50;
  MyIntP1 = &MyInt;
  MyIntP2 = &MyIntP1;

  cout<<"Value of MyInt is: "<<MyInt;
  cout<<"\n"<<"Memory Address of MyInt is: "<< MyIntP1;
  cout <<"\n"<<"Memory Address of MyIntP1 is: "<< MyIntP2;
  cout <<"\n"<<"Memory Address of MyIntP2 is: "<< &MyIntP2;

  cout<<"\n"<<"Value accessed using MyInt is: "<<MyInt;
  cout <<"\n"<<"Value accessed using MyIntP1 is: "<< *MyIntP1;
  cout <<"\n"<<"Value accessed using MyIntP2 is: "<< **MyIntP2;
  return 0;
}
```

**Output:**

```text
Value of MyInt is: 50
Memory Address of MyInt is: 0x0012ff68
Memory Address of MyIntP1 is: 0x0012ff64
Memory Address of MyIntP2 is: 0x0012ff60
Value accessed using MyInt is: 50
Value accessed using MyIntP1 is: 50
Value accessed using MyIntP2 is: 50
```

In Listing 5, you can see that an integer variable `MyInt` and two integer pointer variables `MyIntP1` and `MyIntP2` are declared. The `MyIntP1` is followed by single `*` operator, whereas, the `MyIntP2` is followed by two `*` operators (`**`) to indicate that the `MyIntP2` is a pointer to point the memory address of another pointer, that is `MyIntP1`. Moreover, in the output, you can see that the memory address of pointer `MyIntP1` (`0x0012ff64`) is different to the memory address of `MyIntP2` (`0x0012ff60`). However, when the value of these pointers is accessed, both of them have displayed the same value.
