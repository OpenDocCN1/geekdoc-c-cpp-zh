## Passing Function Argument as const

When you declare a const variable, it means that you cannot change its value in a program. You can pass an argument to a function to perform specific task within the body of a function. You can also change the value of argument within body of a function. When you pass const variable as argument to a function, you cannot modify the original data of the const variable within the body of function. The compiler produces an error message *Cannot modify a const object*. Listing 17 shows how compiler produces an error message when you modify const argument within the body of the adder() function (you can find the Func12.cpp file on the CD in the code/chapter3 folder):

## Using Recursion

Sometimes, you write a block of code within a function that executes repeatedly to perform a task. To minimize this repetition, you can write a function, which calls itself. The situation, in which a function calls itself, is called recursion and that function is called a recursive function. This function is called repeatedly, unless the code included in the body of function terminates the chain of calls by implementing a condition within the `if` statement. The following is the syntax for recursive function:

```cpp
void recursion(arguments)
{
    statements1
    if (condition)

    recursion(arguments)
    statements2
}
```

In the preceding syntax, the recursion is name of the recursive function that has specific set of statements including the `if` statement. After the `if` statement, this recursive (recursion) function is called.
