```
# ■  Accessing and Initializing Structure Elements

Every structure has some elements known as members of structure that are declared within the opening and closing curly braces of the structure (known as the body of the structure). When you define a structure, you have to provide a name to the structure variable to access it in the C++ program. You can use the dot (.) operator between the structure variable name and structure element (member of structure) to access and initialize a structure element. The syntax of accessing a structure element is as follows:

```
```cpp
structure_variable_name.structure_element;
```
```

The structure element (name), of employee structure, is accessed with the structure variable name (employee_one) in the following code snippet:

```
```cpp
employee_one.name;
```
```

Similarly, you can initialize the structure elements by using the dot operator (.) as shown in following code snippet:

```
```cpp
employee_one.name == "Mohan";
employee_one.age == 22;
```
