In Listing 33, add (Calculate c) is a global, non-member function that has been declared a friend of the Calculate class. The declaration of a friend function should be preceded by the `friend` keyword. The add() function is defined elsewhere in the program as a normal C++ function. Note that when you define a friend function, you do not need to use the `friend` keyword or the scope resolution operator. A function can be declared as a friend function in more than one class. A friend function, although not a member function, has full rights to access the private members of the class.

The Member functions of one class can be friend functions of another class. Such member functions are defined by using the scope resolution operator, as shown in the following code snippet:

```
class A
{
.
.
int display(c);
};
class B
{
.
.
friend int A::display(c)
.
.
};
```

In the preceding code snippet, the display(c) function is a member of class A and a friend of class B.

Some properties of friend functions are given as follows:

+   - Friend functions are not in the scope of the class in which they have been declared as friend. It means a friend function can be declared anywhere (in public, protected or private section) in the class.
+   - Since friend functions are not in the scope of the class, they cannot be called using the object of that class.
+   - A friend function can be invoked as other normal functions without the help of an object.
+   - Unlike member functions, a friend function cannot access the member names directly and have to use an object name and dot membership operator with each member name.
+   - Usually, a friend function has objects as arguments.
+   - Friend functions are non-members of a class, and therefore do not get the this pointer.

A friend function of one class can be a friend of one or more other classes also, and this type of friend function is known as global function.
