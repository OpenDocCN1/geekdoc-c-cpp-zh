
## 7.2 Using the protected Access Specifier

Apart from the `private` and `public` access specifiers, C++ also supports another important access specifier: `protected`. The access limit of the protected access specifier (within a class or from the objects of a class) is the same as that of the `private` access specifier. Protected members of a class, similar to the private members of a class, can be accessed within the class. Consider the following code snippet that explains all three visibility modes (`private`, `protected`, and `public`) within a class:

```
class A
{
private:
    int pv;        /*Not accessible outside the A class; but the
                     member functions of A class can access it*/

protected:
    int prot;      /*Not accessible outside the A class; but the
                     member functions of A class and B class can access it*/

public:
    int pb;        /*Accessible outside the A class any where*/

    void pbBaseFunc();
};
class B : public A
{
    void derivedFunc();
};
int main()
{
    B obj;
    obj.pb=10;
    return 0;
}
```

In the preceding code snippet, the pv variable is private to the A class and is accessible only to the members of the A class only. In other words, the pbBaseFunc() member function, which is a member of the A class, can access the pv variable directly. However, the member functions of the B class are not allowed to access the private members of the A class.

The prot variable is a protected data member that is accessible to other member functions of the A class and the member functions of the B class (a derived class of class A). However, the prot variable cannot be accessed by a member of any other class.

The pb and pbBaseFunc() members of class A are declared public. These members may be accessed directly by all the members of classes A or B, or by the objects of these classes.

A protected member can be considered a combination of a private and a public member. Similar to private members, protected members are accessible to the member functions of their class and are invisible outside the class. Similar to public members, protected members are inherited by derived classes and are also accessible to the member functions of the derived class.

## 7.3 Creating a Simple Program of Inheritance

The principle of inheritance is available with several modern programming languages and is handled slightly different in each language. C++ allows you to inherit all or some members of a base class in the derived class. You can modify the members of a base class in the derived class or add new members if some features are not available in the base class. Listing 1 shows an example of inheritance (you can find the SimpleInheritanceProgram.cpp file on the CD in the Code\Chapter7 folder):

- Listing 1: Showing a Simple Program on Inheritance

```cpp
#include<iostream.h>

class Vehicle {
    protected:
    int wheels;
    float weight;
    public:
    void initialize(int in_wheels, float in_weight)
    {
        /* initialize to any data desired */
        wheels = in_wheels;
        weight = in_weight;
    }
    int get_wheels(void)
    {
        /* get the number of wheels of this vehicle */
        return wheels;
    }
    float get_weight(void)
    {
        /* return the weight of this vehicle */
        return weight;
    }
    float wheel_loading(void)
    {
        /* return the weight on each wheel */
        return weight/wheels;
    }
};

class Car : public Vehicle {
    int passenger_load;

public:
    void initialize(int in_wheels, float in_weight, int people = 4)
    {
        passenger_load = people;
        wheels = in_wheels;
        weight = in_weight;
    }
    int passengers(void)
    {
        return passenger_load;
    }
};
int main()
{
    Vehicle autoobj;
    autoobj.initialize(3, 2000.0);
    cout << "The auto rickshaw has " << autoobj.get_wheels() << " wheel.\n";
    cout << "The auto rickshaw's wheel loading is " <<autoobj.wheel_loading()
    << " pounds on the single tyre.\n";
    cout << "The auto rickshaw weighs " <<autoobj.get_weight() << " pounds.\n";
    Car marutiZen;
    marutiZen.initialize(4, 3500.0, 5);
    cout << "The Maruti Zen carries " << marutiZen.passengers() << " passengers.\n";
    cout << "The Maruti Zen weighs " << marutiZen.get_weight() << " pounds.\n";
    cout << "The Maruti Zen's wheel loading is " <<marutiZen.wheel_loading()
    << " pounds per tyre.\n";

    return 0;
}
```

**Output:**

```text
The auto rickshaw has 3 wheel.
The auto rickshaw's wheel loading is 666.666687 pounds on the single tyre.
The auto rickshaw weighs 2000 pounds.
The Maruti Zen carries 5 passengers.
The Maruti Zen weighs 3500 pounds.
The Maruti Zen's wheel loading is 875 pounds per tyre.
```

In Listing 1, Vehicle is a base class and Car is a derived class of the Vehicle class. The derived Car class contains all the information included in the Vehicle base class, such as weight of vehicle and number of wheels, as well as its own information, such as passenger load.

While the Vehicle base class can be used to declare objects, such as trucks, cars, bicycles, or any other vehicle, the Car class can only be used to declare an object of type Car, such as Maruti Zen, Santro, and Tata Indica. The Car class is therefore more restrictive and specific than the Vehicle class and the Vehicle class is more general than the Car class.

## 7.4 Explaining Various Types of Derivations

In C++, member accessibility depends on the use of access specifiers (public, private, and protected). These access specifiers not only grant the permission to access the members of a class outside the class, but also define the scope of accessing the members of a base class with the objects of a derived class. In other words, access restrictions can be imposed not only within a class but also while deriving the class. A derived class, which inherits from a base class, should use any one of the following access specifiers:

- `private`: When a base class is specified as private, all its members remain private in the base class and are not inherited by derived class, and the public and protected members of the base class become private members of the derived class.
- `protected`: When a base class is specified as protected, all private members of the class remain private in the base class. In addition, protected members remain protected, but the public members of the base class become protected members of the derived class.
- `public`: When a base class is specified as public, all private members of a base class remain private in the base class, and protected members remain protected, and public members remain public in the derived class.
