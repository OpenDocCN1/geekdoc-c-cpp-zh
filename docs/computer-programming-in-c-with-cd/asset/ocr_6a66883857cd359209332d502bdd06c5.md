# One-dimensional Array

In C++, one-dimensional array is a structured collection of elements that can be accessed individually by specifying the position of an element with a single index value. For example, when we declare array[10], the index value of elements in the array are array[0], array[1], ..., array[9]. The following is the syntax to declare a one-dimensional array:

```
data_type Array_Name [count];
```

In the preceding syntax, `data_type` describes which type of data is stored in each element of the array and `count` indicates the size of the array. The size of array specifies the number of array element in the array. A value of the `count` must be greater than 0 to create an array. The index value of a one-dimensional array ranges from 0 to count-1. For example, when you declare a one-dimensional array of 10 elements, the index value of such array ranges from 0 to 9. The one-dimensional arrays are also called linear arrays. This is because, the one-dimensional array stores data in a sequential order. The following code snippet shows how to declare a one-dimensional array:

```
int roll[50];
```

When the C++ compiler compiles the preceding code snippet, it creates an array called roll, which can store 50 elements; each element is capable of holding one int value. In other words, the roll array has 50 elements and their data-type is int.
