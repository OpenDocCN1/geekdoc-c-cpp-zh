## Shift Operators

Shift operators are used to shift the bit pattern to either the left or right of the operand, wherein the operand is an integral value. C++ supports the right shift (>>) and left shift (<<) operators. The syntax to use Shift operators is:

```
Operand >> value // syntax for right shift
Operand << value // syntax for left shift
```

In the preceding syntaxes, operand refers to the number whose bits have to be shifted, and value is the number by which the bits of the operand will be shifted. If we perform left shift on an operand, then the bits are removed from the left side of its binary representation and corresponding 0's are added on the right side.

For example, if we have a number n whose binary representation is 0000 0000 0000 0101 and we have to perform left shift on this operand by 5, then the resultant binary representation of n will be 0000 0000 0000 1010 0000. The effect of shifting a variable to the left by one bit position is equivalent to multiplying the value by 2. If the initial value of n is 5, then shifting it by 5 bit position yields 5*32=160.

We have done left shift on n; right shift can also be performed on n. In case of right shift, the effect of shifting a variable to the right by one bit position is equivalent to dividing the value by 2. For example, 16 >> 2 shifts the number 16 right by two binary places, which is same as dividing it by 4, so the result of 16 >> 2 is 4. Listing 24 shows the use of the >> (right shift) operator (you can find the RightShiftEx.cpp file on the CD in the code/chapter1 folder):

**Listing 24: Using the Right Shift Operator**

```

{
    int x;
    x = 15;

    x = x >> 2;
    cout<<"The value of right shifted 2 times x variable is: "<<x<<endl;
    return 0;

Output:

The value of right shifted 2 times x variable is: 3
```

In Listing 24, an x variable is first declared and initialized with 15. Then, the value of the x variable is right shifted two times by using the right shift operator, and the value of the x variable is displayed on the screen.

## The Ternary Operator

Ternary operators are those C++ operators that work as an alternative of the if-else statement. They are called ternary operators because they work on three operands. The ternary operator is represented as ?:, which works according to the following syntax:

```
result = condition ? value1 : value2
```

According to the preceding syntax, if the condition evaluates to true, then the value of the result will be value1; else, the result value will be value2. The preceding syntax works similar to the following if statement:

```
if (condition)
{
    result = value1;
}
else
{
    result = value2;
}
```

Let’s discuss the ternary operator to understand its functionality. Listing 26 shows the use of the ternary operator (you can find the TernaryEx.cpp file on the CD in the code/chapter1 folder):

**Listing 26: Using the Ternary Operator**

```
#include <iostream.h>

int main()
{
    int x = 12, y = 10, result;
    result = x > y ? x : y;
    cout << "Two integers are " << x << " and " << y << endl;
    cout << "The larger of the two integers is " << result << endl;
    return 0;
}
```

Output:

```
Two integers are 12 and 10
The larger of the two integers is 12
```

In Listing 26, we have 2 variables, x and y, which are initialized with the values 12 and 10, respectively. Next, we apply a ternary operator to check which of the two variables is greater.

### The sizeof Operator

The sizeof operator determines the number of bytes used by an object or raw data types (such as int, char, short) in memory. The operand may be a variable, a constant or a data type qualifier. The sizeof operator is normally used to determine the length of arrays and structures when their sizes are not known to the programmer. It is also used to allocate memory space dynamically to variables during the execution of a program. Listing 27 shows the code to display the size of an integer variable and the raw types (you can find the SizeofEx.cpp file on the CD in the code/chapter1 folder):

**Listing 27: Using the sizeof Operator**

#include <iostream.h>

{

    cout << "The int type is " << sizeof (int) << " bytes long" << endl;

In Listing 27, we have used the sizeof operator to find out the size of the data type in bytes. In this program, we have declared a variable integer and initialized it with 4. The program displays the size of the various data types with the help of the sizeof operator.
