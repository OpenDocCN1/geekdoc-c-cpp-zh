# **Listing 24: Using the Right Shift Operator**

```
    #include <iostream.h>

    int main()
    {
        int x;
        x = 15;
        cout<<"The value of x is: "<<x<<endl;
        x = x >>2;
```

In Listing 24, an x variable is first declared and initialized with 15. Then, the value of the x variable is right shifted two times by using the right shift operator, and the value of the x variable is displayed on the screen.
