Now, you are familiar with some of the important concepts of C++, such as creating variables and using loops. The variables are used to store values of specific data type as and when required during the program execution. You can store only one value at a time in a variable. However, there can be situation when you are required to work with multiple values, which need to create multiple variables. Keeping track of too many variables is a difficult task and error prone too. In this situation, you can use arrays to store multiple values by using one variable name. An array is a collection of elements of similar data-type. For example, if you need to store roll number of 10 students, you need not to declare 10 integer variables, instead you can create an integer array of 10 elements, where each element can store different value.

At the time of developing a C++ program, you may require to execute certain set of statements repeatedly. Writing the same set of statements multiple times in a program makes it lengthy and difficult to understand. To avoid such problem, you can use functions in your program. Function is a group of statements under single name to perform specific task. Using function, you can break a large and complex program into several modules to make it simple and easy to understand.

In this chapter, you learn about arrays and its different types. Then, you learn about functions, which cover various related concepts, such as creating function, calling function, and passing parameters to the functions. Next, you discuss the scope of variable that defines the accessibility of the variable. Finally, you learn about the storage classes that define how long a variable can be used during program execution.
