
## Identifiers

An identifier is a name associated with a function or data object and is used to refer to that function or object. Before creating an identifier, you should keep the following points in mind:

- Identifiers must start with a letter or underscore, but starting an identifier with an underscore is not recommended because in C++, the identifiers starting with an underscore may be reserved for a compiler-specific keyword. For example, `_FILE_` is a predefined token, which is used to hold the current file name.
- Identifiers may consist of a letter, a number, and an underscore.
- Spaces are not allowed within identifiers.
- You cannot use a C++ keyword as an identifier name.
- Identifiers are case sensitive, that is, the words salary, Salary, and SALARY are three different identifiers.
- There is no limit to the length of an identifier. In other words, an identifier can be as long as you want it to be, as per your requirement.

Some examples of valid identifiers are Emp_sal and You_can_use_as_long_as_identifier_you_need.

## Comments

A comment is text in a program that is ignored by the compiler but is useful for programmers. Comments are used to make a program easy to read and understand. In addition, comments help programmers understand the working of the code in a program. Comments do not affect the working of a program. A comment may consist of the following information:

- The aim of the program.
- The name of the programmer and the date and time the program is created.
- The working of all the functions written in the program so that a programmer can easily understand them. This is important when the programmer needs to modify the program.

Comments in C++ are of the following two types:

- Single line comments: Start with a pair of forward slashes (`//`). The compiler considers all text followed by `//` as a comment and ignores that text. The following code snippet shows a single line comment:

  ```cpp
  #include <iostream.h>
  int main() {
  // This is a single line comment
  ...
  return 0;
  }
  ```

- Multi line comments: Start with a forward slash and an asterisk sign (`/*`) and end with an asterisk and forward slash (`*/`). The text you want to give as a comment is written between `/*` and `*/`. The following code snippet shows a multiline comment:

  ```cpp
  #include <iostream.h>
  int main() {
  /* This is
  a multi line
  comment */
  ...
  return 0;
  }
  ```

It is advisable to use multiline comments only for multiple-line comments rather than use `//` before every line.

## Constants

Constants in C++ are fixed values that cannot be modified. In C++, you declare a constant by using the const keyword. The syntax to declare a constant is:

```cpp
const <datatype> <constant_name>;
```

In the preceding syntax,

- `const`: Refers to the const keyword used to declare a constant
- `<datatype>`: Refers to the data type of a constant, implying the value the constant will hold
- `<constant_name>`: Refers to the name of the constant you want to declare

The constants in C++ can be divided in the following major categories:

- Integer constants
- Floating point constants
- Character constants

These constants are primary constants and apart from these, C++ also provides secondary constants, such as array, pointers, structure, union, and enum. These secondary constants are discussed in *Chapter 3, Working with Arrays and Functions* and *Chapter 4, Pointers*.

Now, let's discuss the three categories of constants in detail.

### Integer Constants

Integer constants are the constants that consist of only digits, no fractional data. The size of an integer constant depends on the integer data type used with the variable name. The rules to remember for integer constants are as follows:

- They must have at least one digit
- They must not have a decimal point
- They can be either positive or negative
- They must not have commas or blanks
- They must be within the range -32768 to +32767

The following code snippet shows the declaration of integer constants:

```cpp
const int num1 = 258; // positive integer constant
const int num2 = -256; // negative integer constant
```

In the preceding code snippet, the num1 constant holds a positive integer value and the num2 constant holds a negative integer value.

### Floating Point Constants

Floating point constants are the constants that consist of fractional data and can also contain an exponent. Floating point constants are also known as real constants. By default, floating point constants are of the double type but by appending f or F with a floating point constant, you are indicating to the compiler that the constant is of the float type. If you suffix the float constant with l or L, then the compiler treats the constant as a long double type. Now, let’s discuss the following two forms of floating point constants available in C++:

- Fractional
- Exponential

**Fractional Floating Point Constants**

Fractional floating point constants are the constants that consist of fractional values or values containing decimals. The following are the rules to be followed for fractional floating point constants:

- They must have at least one digit
- They must have a decimal point
- They can be either positive or negative
- They must not have commas or blanks

The following code snippet shows the declaration of fractional floating point constants:

```cpp
const float num1 = 98.74; // positive fractional floating point constant
const float num2 = -98.74; // negative fractional floating point constant
```

In the preceding code snippet, the num1 floating point constant contains a positive fractional value and the num2 floating point constant contains a negative fractional value.

**Exponential Floating Point Constants**

Exponential floating point constants are the constants that hold values that are either too small or too large. Floating point constants are represented in the following two parts in the exponential form:

- Mantissa: Represents the part before the letter e, where e represents the exponential notation used for scientific calculations
- Exponent: Represents the part after the letter e

The following are the rules for the exponential form of floating point constants:

- They must separate the mantissa and exponent parts with the letter e
- They can have either positive or negative values in the mantissa and exponent parts
- They must be within the range -3.4e38 to 3.4e38

The following code snippet shows the declaration of the exponential form of floating point constants:

```cpp
const float num1 = +3.2e-1; // positive exponential floating point constant
const float num2 = -3.2e-1; // negative exponential floating point constant
```

In the preceding code snippet, the num1 floating point constant contains a positive exponential value and the num2 floating point constant contains a negative exponential value.

### Character Constants

Character constants are the constants that have a single character enclosed within a single quote. Character constants are of type char. The following are examples of valid character constants:

```cpp
const char ch1 = 'f' // character constant
const char ch2 = 'g' // another character constant
```

In the preceding code snippet, ch1 and ch2 are character constants.

## Variables

A variable is an identifier used to store or represent some specific type of information within a program. In other words, a variable is a constant whose value may change in the program. A variable can be of integer, floating point, or character type. While declaring a variable, the name of the variable and the type of value it will hold is specified. The rules for variable names are as follows:

- They can be in a combination of alphabets, digits, or underscores
- They must have an alphabet as the first character
- They must not have commas or blanks
- They must not have a special symbol, except an underscore
