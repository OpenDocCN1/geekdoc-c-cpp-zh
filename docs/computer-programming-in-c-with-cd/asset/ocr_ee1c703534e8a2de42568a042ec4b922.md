If an object is local and non-static variable, the destructor is called when the function in which the object is defined is about to terminate. However, if an object is static and global variable, the destructor is called before the program terminates. Moreover, when a program is interrupted using the `exit()` function call, the destructors are called for all the objects that exit at that time.

![](bbox=[0.229, 0.644, 0.263, 0.671])

> > *A destructor can be called explicitly, as shown in the following code snippet:*
> >
> > ```cpp
> > n1.~NumberInitialization();       // Explicit destructor invocation
> > ```

However, a destructor need not be invoked explicitly as the system automatically invokes it when an object goes out of scope.

Destructors have the following characteristics:

+   - The names of the destructors must be the same as that of their class name
+   - A destructor should have public access in the class declaration
+   - Destructors do not have return types, and therefore, cannot return values
+   - Destructors can be `virtual`
