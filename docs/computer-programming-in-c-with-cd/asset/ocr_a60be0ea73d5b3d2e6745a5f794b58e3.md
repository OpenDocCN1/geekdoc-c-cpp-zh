The distinguishing features of constructors are that they have the same name as that of the class.

Destructors, on the other hand, deinitialize the objects when they are destroyed. A destructor is automatically invoked when an object of a class goes out of scope. Therefore, a programmer is relieved of the task of clearing the memory space occupied by a data member every time an object goes out of scope.

Let’s explain how to declare and use a constructor in a class.

# ## Declaring and Using Constructors

A constructor is a special member function that allocates the memory and initializes the objects of its class. A constructor is distinct from other member functions of the class, as it has the same name as its class. It does not include a return type (not even void), as in case of a function. It executes automatically when a class is instantiated (object is created).
