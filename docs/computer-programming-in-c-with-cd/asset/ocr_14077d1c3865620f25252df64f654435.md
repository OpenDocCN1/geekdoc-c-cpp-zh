By this, we can conclude that a derived class does not require a constructor as long as a base class has a default (no-argument) constructor. However, if the base class constructors have parameters, it is mandatory for the derived class to also have constructors with parameters. In addition, the derived class constructor passes values to the arguments of the base class constructor explicitly. When an object of a derived class is created, the constructor of the base class is executed first and then the constructor of the derived class is executed. However, in the case of destructor, this order is reversed, that is, the destructor of the derived class is executed first and then the destructor of the base class is executed.

# 7.7 Creating Container Classes

A container class is an object holder for other classes. It represents an indirect way of inheriting the properties of one class into another class. This means that an object of a container class is a collection of several other objects. The purpose of creating a container class is to hold multiple instances of another class. The syntax to create a container class is:

```
class Class_Name
{
};
class ContainerClass_Name
{
Class_Name object_name;
};
```

In the preceding syntax, ContainerClass_Name represents the name of a container class that contains the declaration of the object_name object of the Class_Name class.
