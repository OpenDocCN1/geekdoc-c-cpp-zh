+   - They can be either positive or negative
+   - They must not have commas or blanks
+   - They must be within the range -32768 and +32767

The following code snippet shows the declaration of integer constants:

```
const int num1 = 258; // positive integer constant
const int num2 = -256; // negative integer constant
```

In the preceding code snippet, the num1 constant holds a positive integer value and the num2 constant holds a negative integer value.

# Floating Point Constants

Floating point constants are the constants that consist of fractional data and can also contain an exponent. Floating point constants are also known as real constants. By default, floating point constants are of the double type but by appending f or F with a floating point constant, you are indicating to the compiler that the constant is of the float type. If you suffix the float constant with l or L, then the compiler treats the constant as a long double type. Now, let’s discuss the following two forms of floating point constants available in C++:

+   - Fractional
+   - Exponential

# Fractional Floating Point Constants

Fractional floating point constants are the constants that consist of fractional values or values containing decimals. The following are the rules to be followed for fractional floating point constants:

+   - They must have at least one digit
+   - They must have a decimal point
+   - They can be either positive or negative
+   - They must not have commas or blanks

The following code snippet shows the declaration of fractional floating point constants:

```
const float num1 = 98.74; // positive fractional floating point constant
const float num2 = -98.74; // negative fractional floating point constant
```

In the preceding code snippet, the num1 floating point constant contains a positive fractional value and the num2 floating point constant contains a negative fractional value.
