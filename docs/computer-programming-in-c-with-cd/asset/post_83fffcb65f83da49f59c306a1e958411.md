Now, besides overriding the base class functions, it is also possible that a derived class may begin its existence with a copy of its base class members. The reason is: a derived class inherits the variables and member functions of its base class, but not the constructor or destructor from its base class. When an object of the derived class is created, it automatically invokes the default constructor and destructor of its base class. Listing 6 shows the invocation of base class constructor and destructor from an object of a derived class (you can find the Base_ConsDes.cpp file on the CD in the Code\Chapter7 folder):

## ▶ Listing 6: Invoking the Constructor and Destructor of a Base Class through an Object of a Derived Class

```cpp
#include<iostream.h>

class Base
{
    public:
    Base()
    {
        cout<<"Base class constructor calling"<<endl;
    }
    ~Base()
    {
        cout<<"Base class destructor calling"<<endl;
    }
    void MyFuncB()
    {
        cout<<"Function of base class"<<endl;
    }
};
class Derived:public Base
{
    public:

    void MyFuncD()
    {
        cout<<"Function of derived class"<<endl;
    }
};
int main()
{
    Derived d;
    cout<<"Main Program started"<<endl;
    d.MyFuncD();
    cout<<"Main Program ended"<<endl;
    return 0;
}
```

### Output:

```text
Base class constructor calling
Main Program started
Function of derived class
Main Program ended
Base class destructor calling
```

In Listing 6, the Derived class is inherited from the Base class, and the Base class has a default constructor, destructor, and the MyFuncB() function. However, the Derived class has the MyFuncD() function only. In the main() function, an object, d, of the Derived class is created, which invokes the constructor of the Base class before executing any other statement of the main() function, as shown in the output of Listing 6. In addition, the d object invokes the destructor of the Base class after executing all the statements written in the main() function, including the following:

- The Main Program started statement
- The MyFuncD() function of the Derived class
- The Main Program ended statement

Now, what will happen when the derived class has its own constructor and destructor, but base class does not? In such a case, the object of derived class invokes the constructor and destructor of its own class, as the base class does not have any of these (constructor or destructor, or both). Listing 7 shows the invocation of a derived class constructor and destructor (you can find the Derived_ConsDes.cpp file on the CD in the Code\Chapter7 folder):

## ▶ Listing 7: Invoking the Constructor and Destructor of a Derived Class

```cpp
#include<iostream.h>

class Base
{

    public:

```

### Output:

```text

Main Program started
Function of derived class
Main Program ended
Derived class destructor calling
```

In Listing 7, the Derived class is inherited from the Base class. The Derived class has a default constructor, destructor, and the MyFuncD() function; however, the Base class has the MyFuncB() function only. In the main() function, an object, d, of the Derived class is created. The d object invokes the constructor of its own class, that is, the Derived class. Then, the Main Program started statement is called and the MyFuncD() function of the Derived class is invoked. Finally, the Main Program ended statement is called and the destructor of the Derived class is invoked.
