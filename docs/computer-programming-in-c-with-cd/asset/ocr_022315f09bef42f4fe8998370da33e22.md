# Using the continue Statement

The `continue` statement causes the current loop to quit iteration and begin the execution of the next iteration. In other words, the `continue` statement is used to skip the current iteration. Listing 26 shows the use of the `continue` statement (you can find this example in the `continueStatement.cpp` file on the CD in the `code\chapter2` folder):

# Listing 26: Using the continue Statement

```
#include<iostream.h>

int main()
{
    int i;
    for(i=2;i<=20;i=i+2)
    {
        if(i==6 || i==14)
        {
            continue;
        }
        cout<<i<<endl;
    }
    return 0;
}
```

**Output:**

2
4
8
