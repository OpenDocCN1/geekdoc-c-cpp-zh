## 4.2 Exploring Arrays with Pointers

Arrays are the linear collection of variables of similar data type. When an array is created in a program, its size is finite and can have n number of elements, where n is the size of the array. In addition, the elements of an array can be manipulated by using their index number. The index number is also known as subscript number. The index number of each element of an array is one less than its actual place in the array. For example, if you want to access the fifth element of an array, the index number should be 4. You can traverse through element-by-element in an array within its range by using the index value.

Pointers can also be used for referencing an array. When pointer deals with arrays, they store the address of an element of the array type variables. Let’s take an example, in which we have created an integer type array `arr` of 11 elements. The array is created by using the following code snippet:

```cpp
int arr[11];
```

Once the array is created, all the elements of the array are represented adjacent to each other in the memory, as shown in Figure 3:

![](img/8a6886c00caa6a1651a6c0e62bff341f_235_0.png)

Then, the address of the first element of this array can be represented by using the following code snippet:

```cpp
&arr[0]; // we have used address operator to denote the address of first element
```

Alternatively, any element of the array can be represented by using the following code snippet:

```cpp
&arr[i]; // for any element at the given index location denoted by i
```

Now, declare an integer pointer variable by using the following code snippet:

```cpp
int * ptr; // an integer pointer
```

After declaring the integer pointer variable, we can explicitly assign the address of the first element or any other element of array to the newly created pointer variable by using the following code snippet:

```cpp
ptr = &arr[0];               //ptr points to address of arr[0]
```

or,

```cpp
ptr = &arr[i]; // ptr points to the address of the element referenced by i
```

Moreover, you can also assign the address of first element of an array to a pointer variable, just by passing the name of array or we can say without specifying any index number by using the following code snippet:

```cpp
ptr = arr;                   //ptr points to address of arr[0]
```

In C++, you can use the array name as well as pointer to array to access and manipulate the values of array elements. However, the working of arrays and pointers is quite different. Since pointers are variables, which can be manipulated by using operators (+, -, ++, --); whereas, arrays being a linear collection of variables cannot be manipulated by using operations such as arr++, where arr is the name of the array. ### Using Pointer Arithmetic

C++ allows arithmetic operations on pointer variables. Pointer arithmetic is used to perform arithmetic operations on the memory address rather than simple variables. Arithmetic operations are mainly used for fast and accurate manipulation of addresses assigned by the variables including arrays. The main objective to perform arithmetic operations on pointers is to move back and forth in the address area referenced by a pointer variable.

Pointer arithmetic is useful when you want to access a sequence of values in an array. To do this, you need to add 1 to the pointer variable (referencing the array) to move from one value to the next. There are the following types of arithmetic operators, which are used in pointer arithmetic:

- Increment (++) and decrement (--) operators
- Addition (+) and subtraction (-) operators
- The * operator

### Increment (++) and Decrement (--) Operators

The pointer variable works as an index pointing the address of the variable. When the variable stored is of integer type, it consumes 4-bytes in memory. When we apply increment (++) operator, then the pointer variable points to the next element after a 4-bytes gap. When the data is of a double, float, or a character type, then index is moved according to their size. You can use the decrement (--) operator to move at the previous element of an array.

### Addition (+) and Subtraction (-) Operators

The addition (+) operator increases the value of a pointer by size of the specified data type and moves the pointer variable to point to the specified element. The subtraction (-) operator decreases the value of a pointer by the size of the specified data type and moves the pointer variable to point to the specified element.

### The * Operator

The * operator is used before the pointer variable to retrieve the value of the variable. At the time of performing arithmetic operations on a pointer, the size of the data type used with a pointer variable is also taken into consideration. Let's consider an example where a pointer ptr is storing a reference of a float type array named arr containing 5 elements. Let's say, the first element of the array arr is at the memory location 2000. When the pointer ptr is incremented by using ++ operator, then the address of the pointer is incremented by four bytes instead of one byte, as the size occupied by a float data type is 4 bytes.
