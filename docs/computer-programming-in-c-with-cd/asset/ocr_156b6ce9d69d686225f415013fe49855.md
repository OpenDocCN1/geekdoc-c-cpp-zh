Q7.  What is the output of the following program?

```
```cpp
#include<iostream.h>

void main()
{
    int n, sum = 0;
    int i=1;
    cout<<"Enter a number"<<endl;
    cin>>n;
    cout<<"The numbers are:"<<endl;
    do
    {
        cout<<i<<endl;
        sum +=i;
        i++;
    }while(i<=n);
    cout<<"Sum of 1 to "<<n<<" numbers are: "<<sum;

}
```
```

Ans.  Output of the preceding program is as follows:
