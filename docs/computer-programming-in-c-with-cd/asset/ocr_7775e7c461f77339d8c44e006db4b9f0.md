The basic format to create a class in C++ is similar to the format for creating a structure in C language. In other words, a class in C++ is an evaluation of the structures in C. The only difference between a structure in C and a class in C++ is that a class not only contains data but also functions. C++ also supports structures that we discuss in the next section. The syntax to declare a class is:

```
```cpp
class class_name
{
    // members of a class
};
```
```

In the preceding syntax,

+   - `class`: Refers to a keyword used to create a class
+   - `class_name`: Refers to the name of the class

The class name can be any logical name, which should reflect the information stored in the class. For example, a class name Invoice should contain invoice-related information. The class name Invoice now becomes a new data type identifier, which can be used to create an instance (object) of the Invoice class.

An instance of a class is called an object, which is created by using the name of the class, and has its unique identity in a C++ program. The process to create the objects of a class is called class instantiation. When an object is created, some part of the memory is allocated to the object. The syntax to create the objects of a class is:

```
```cpp
class_name obj_nam;
```
```

In the preceding syntax,

+   - `class_name`: Refers to the class name
+   - `obj_nam`: Refers to the name of the object that you want to create

You can also create multiple objects of a class in a single statement by using the following syntax:

```
```cpp
class_name obj_nam1, obj_nam2, obj_nam3;
```
```

Objects can also be created by placing the name of the objects just after the class definition:

```
```cpp
class class_name
{
    // data and code
} obj_nam, obj_nam1;
```
```

In this way, objects are created in C++.
