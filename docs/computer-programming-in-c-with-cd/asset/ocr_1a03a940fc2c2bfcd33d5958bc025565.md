# Union

*Union* is also a user-defined data type that helps you create a new data construct in which all members share the same memory location. Its declaration is syntactically similar to structures. The following code snippet shows the use of the union keyword:

```
```cpp
union one_union
{
    double double_variable;
    double double_variable2;
};
```
```

In the preceding code snippet, a union named one_union with two double variables, double_variable and double_variable2, are declared. The following code snippet shows how to create the union1 variable of the one_union type:

```
```cpp
#include <iostream.h>
int main( )
{
    union one_union
    {
        double double_variable;
        double double_variable2;
    };
    one_union union1;
    union1.double_variable = 3.14159;
    .
    .
    .
}
```
```

In the preceding code snippet, we create a variable, union1, of the one_union type and initialize union it with the value 3.14159. In the one_union union, two variables, double_variable and double_variable2, are declared. Now, when these variables are accessed by using the union1 variable, both the union1.double_variable and union1.double_variable2 variables point to the same data in the memory.
