```
int num1=5;
int num2=7;
swap(num1, num2);
```

In the preceding code snippet, two integer variable, num1 and num2, are assigned the values 5 and 7. Then, these variables (num1 and num2) are passed to the swap() function. The swap() function has prototype as shown in the following code snippet:

```
void swap(int a, int b);
```

In the preceding code snippet, when the swap() function is called, it creates a new variables a and b of int data type and then assigns the values 5 and 7 respectively.

Listing 14 shows an example of function by using call by value. You can find the Func9.cpp file on the CD in the code/chapter3 folder:

# ▶ Listing 14: Demonstrating Call by Value

```
#include <iostream.h>

int main()
{
    void swap(int, int);
    int num1=40, num2 = 60;

    cout<<"Main: Before Swap num1 = "<<num1<<" and num2 = "<<num2<<endl;
    swap(num1, num2);

    cout<<"Main: After Swap num1 = "<<num1<<" and num2 = "<<num2<<endl;
    return 0;
}
void swap(int a, int b)
{
    cout<<"Swap: Before Swap a = "<<a<<" and b = "<<b<<endl;
    int c;
    c = a;
    a = b;
    b = c;
    cout<<"Swap: After Swap a = "<<a<<" and b = "<<b<<endl;
}
```

Swap: Before Swap a = 40 and b = 60
Swap: After Swap a = 60 and b = 40
Main: After Swap num1 = 40 and num2 = 60
