# 7.9 Describing Some Problems While Implementing Multiple Inheritance

In C++, some ambiguities arise for the compiler while implementing multiple inheritance. For example, what happens when two base classes contain a function with the same name? The following code snippet shows this ambiguity, as the display() function is inherited from both the Myclass1 and Myclass2 classes:

```
class Myclass1
{
public:
    void display()
    {
        cout<<"My class 1"<<endl;
    }
};
class Myclass2
{
public:
    void display()
    {
        cout<<"My class 2"<<endl;
    }
};
class DerivedClass: public Myclass1,public Myclass2
{
    //Empty class
};
int main()
{
    DerivedClass obj;
    obj.display();
    // ambiguous for compiler

}
```

In the preceding code snippet, the obj object of the DerivedClass class invokes the display() function. However, in this situation the C++ compiler generates a compilation error, because the C++ compiler does not know whether to invoke the display() function from the Myclass1 or Myclass2 class. This problem arises because the DerivedClass class has received two copies of the display() function, from the Myclass1 and Myclass2 classes.
