# # Polymorphism

Polymorphism is the ability of an object to exist in different forms. The term polymorphism has been derived from the Greek words poly (many) and morphos (forms). In the context of OOP, polymorphism is the ability of a function to behave differently, depending on the context in which it is called.

Polymorphism can be generally classified into two categories, static polymorphism and dynamic polymorphism. Static polymorphism refers to an entity that exists in different physical forms at the same time. The concept can be understood by considering an example of a woman. A woman has to play the role of a wife, a mother, a sister, a daughter, and an executive at the same time.

Dynamic polymorphism refers to an entity that changes its form depending on the circumstances. For example, a chameleon changes its color at the sight of an approaching enemy. Figure 2 shows the hierarchy of polymorphism, as well as how to implement it in C++:
