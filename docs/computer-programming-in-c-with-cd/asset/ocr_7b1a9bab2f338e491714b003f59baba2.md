In Listing 39, the Calculator class has two constructors, Calculator() and Calculator(int a, int b), where one is a default constructor and other is parameterized constructor with two parameters. In the main() function, when the object of the Calculator class, cal1 is created, the default constructor, Calculator(), is invoked. This is because the cal1 object is created without passing any argument. However, the cal2 object and the cal3 pointer object invoke the parameterized constructor, Calculator(int a, int b), by passing two arguments.

Note that the pointer type object, cal3, is initialized (or allocated with memory) using the new operator; and the delete operator is used to deallocate the memory (release the memory), which is allocated by the new operator to the object. By deallocating the memory, the pointer object does not get deleted and the address value stored in it does not change.
