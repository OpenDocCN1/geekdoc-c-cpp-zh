`float`, `char`, and `double`. For creating a structure in C++, you have to follow two processes. They are:

- 1. Declare a structure with a structure name and different types of data members that can be stored in a structure.
- 2. Define structure variables for accessing data members of a structure.

A structure can be defined by using the `struct` keyword as given in the following code-snippet:

```cpp
struct employee          // structure declaration
{
    char name[20];       // an array of characters
    int age;             // an int age member
    float salary;        // a float salary member
    char designation[20]; // an array of characters
};
```

In the preceding code-snippet, the structure employee is defined with more than one variable of different data types, such as `int` and `float`. The structure name employee, is preceded by the `struct` keyword. The employee structure starts with the opening curly brace (`{`) and ends with a closing curly brace (`}`). It is noted that semicolon (`;`) must be followed after ending with the closing curly brace. All the data members of a structure are specified between these braces.

After defining the structure, the next step is to declare the structure variables. A structure variable can be declared either as global or as local. Declaring global variables of a structure is shown in the following code snippet:

```cpp
struct employee
{
    char name[20];
    int age;
    float salary;
    char designation[20];
} employee_one, employee_two;
```

In the preceding code snippet, employee is the name of structure; employee_one and employee_two are variables of employee type. Moreover, the scope of employee_one and employee_two variables is global, so that they can be used anywhere, throughout the program.

Now, let's declare local variables of a structure as shown in the following code snippet:

```cpp
struct employee
{
    char name[20];
    int age;
    float salary;
    char designation[20];
};

int main()
{
    employee employee_one, employee_two;
    return 0;
}
```

In the preceding code snippet, employee is a structure; and employee_one and employee_two are variables of employee type in the main() function. However, the scope of employee_one and employee_two variables is local, implying that these variables are accessible only within the main() function.

## Accessing and Initializing Structure Elements

Every structure has some elements known as members of structure that are declared within the opening and closing curly braces of the structure (known as the body of the structure). When you define a structure, you have to provide a name to the structure variable to access it in the C++ program. You can use the dot (.) operator between the structure variable name and structure element (member of structure) to access and initialize a structure element. The syntax of accessing a structure element is as follows:

```cpp
structure_variable_name.structure_element;
```

The structure element (name), of employee structure, is accessed with the structure variable name (employee_one) in the following code snippet:

```cpp
employee_one.name;
```

Similarly, you can initialize the structure elements by using the dot operator (.) as shown in following code snippet:

```cpp
employee_one.name = "Mohan";
employee_one.age = 22;
```
