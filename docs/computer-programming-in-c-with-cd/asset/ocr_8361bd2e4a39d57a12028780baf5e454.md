# Passing Structure to a Function

A function contains certain variables, known as local variables which can be used only with the function. Moreover, a function also uses parameters that are passed by the caller program to execute the function. These parameters are used to communicate between the function and the caller program. Generally, you pass variable as function parameters. However, it is not necessary, and you can also pass structures as function parameters, which implies that you are passing a structure variable as an argument to a function. The structure variable passed to the function has access to all the elements of that structure.
