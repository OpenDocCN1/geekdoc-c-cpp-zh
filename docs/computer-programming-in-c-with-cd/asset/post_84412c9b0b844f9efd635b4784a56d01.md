## Short Questions/Answers

- **Q1.** What is inheritance? Explain with an example.

  **Ans.** Inheritance is a mechanism that allows a class to inherit the properties and functionalities of another class. If class X inherits the properties and functionalities of class Y, then class X is said to be inherited from Y class. In this scenario, Y is called the superclass or base class of X, and X is called a subclass or derived class of Y. Inheritance enables you to form a hierarchy of classes.

  One important advantage of inheritance is that it allows the code of existing projects to be reused multiple times. This means that you can add additional features to an existing class without modifying it by deriving a new class from an existing class. In addition, you can define a subclass with unique features that are different from the features already defined in the corresponding superclass. In addition to its own features, the new class contains the features of the parent class. Some other advantages of inheritance in C++ are:

  - Inheritance reduces redundancy in code, as code is located at one place: in the base class.
  - It enables maintenance of code, as any change made to the base class automatically changes the behavior of its derived classes because they automatically inherit the new behavior.
  - It extends the functionality of a base class (or an existing class) by adding functions to the derived class.

- **Q2.** What are base and derived classes?

  **Ans.** In OOP, a class that inherits or derives features from another class is called a derived class and the class from which it is derived is called a base class. Inheritance is the property by which the objects of a derived class possess copies of the data members and member functions of the base class. The base class is actually a super class and a derived class, a subclass. Each instance of a derived class includes most of the features of the base class. Therefore, a derived class has a larger set of features than its base class. A derived class can, however, modify some or all the features of the base class. In C++, the basic syntax to inherit a new class (or derived class) from an existing class (or a base class) is as follows:

  ```
  class    <BaseClass>
  {
  //Add code
  };
  class    <DerivedClass> : <access_specifier> <BaseClass>
  {
  //Add code
  };
  ```

  In the preceding syntax, the base class and derived class are preceded by the class keyword. A derived class is declared by writing a class name after the class keyword. The derived class name is followed by the colon(:) symbol, the access specifier that indicates the type of derivation, and the base class from which the derived class is derived. The following code snippet shows an example of the base class and the derived class:

  ```
  class Dog: public Mammal
  ```

  In the preceding code snippet, Mammal is the base class and Dog is its derived class.
