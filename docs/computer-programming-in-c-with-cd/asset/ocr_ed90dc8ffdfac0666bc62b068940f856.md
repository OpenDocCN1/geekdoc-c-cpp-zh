# # Computer Programming in C++

The Computer Programming in C++ book helps you to understand the concepts of C++, the difference between C and C++, and basic fundamentals of object-oriented programming. This book is ideal for software developers who are looking forward to develop their career in the field of programming.

# ## In this book, you learn to:

+   - **Programming with C++:** History of C++, difference between C and C++, and fundamentals of C++
+   - **Input/Output, Data, and Flow Controls:** Data input and output processes, manipulators, conditional statements, iteration statements, and jump statements
+   - **Working with Arrays and Functions:** One, two, and three dimensional arrays; how to define and call functions; passing arguments to functions; returning values from functions; standard library functions; recursive functions; inline functions; scope of variables; and storage classes
+   - **Pointers:** Managing memory using pointers, creating and using pointer to pointer, handling memory at runtime with pointers, pointers with arrays, pointer arithmetic, dynamic arrays, passing pointers as function arguments, and returning pointers from a function
+   - **Structures and Unions:** Defining and using structures, nested structures, creating structure inside functions, passing structures to functions, returning structures from functions, arrays in structures, arrays of structures, structures with pointers, linked list, unions, and creating structures as union members
+   - **Object-Oriented Programming with C++:** Basic concepts of object-oriented programming, classes and objects, difference between C structures and C++ classes, data access methods, difference between inline functions and macros, constructors and destructors, local and nested classes, passing objects as function parameters, returning objects from functions, arrays in C++ classes, the const object, concept of the this pointer, friend functions and friend classes, static variables and functions, function overloading, constructor overloading, and operator overloading
+   - **About Inheritance:** Concept of base and derived classes, various types of derivations, overriding base class members, invoking constructors and destructors of the base and derived classes, container classes, various forms of inheritance, problems with multiple inheritance, pointer objects, and static as well as dynamic binding
