## Returning Structure from Function

So far you learned to pass a structure variable as an argument to the function. Using this argument, you can change the values of the variables defined in the structure. Now, suppose you want to access these values outside the function body. For this, you have to return a structure variable by using the `return` keyword at the end of a function body to the caller functions. When a function returns a structure variable, it must match with the return type of the structure, which is declared in the function body.

Now extend the example shown in Listing 4 to return the object of the structure from the function. Listing 5 shows the input() function that returns the structure variable new_product of the product structure (you can find the ReturnStructure.cpp file on the CD in the code\chapter5 folder):

### Listing 5: Returning Structure from a Function

## Creating an Array in a Structure

As known, a structure is a collection of elements of different data types. An element of a structure can be an array too. You can access the individual elements of an array declared within a structure by using the index value of the element. Listing 6 shows the declaration of an array as an element of the structure (you can find the StructureArrayElement.cpp file on the CD in the code\chapter5 folder):

### Listing 6: Creating an Array in the Structure

```cpp
#include <iostream.h>

struct ArrStruct
{
        int MyArr[2];
        char MyChar[2];
};

int main ()
{
        ArrStruct as;
        as.MyArr[0] = 45;
        as.MyArr[1] = 63;

        as.MyChar[0] = 'K';
        as.MyChar[1] = 'S';

        cout<<"First element of Integer Array is: "<< as.MyArr[0];
        cout<<"\n"<<"Second element of Integer Array is: "<<as.MyArr[1];

        cout<<"\n"<<"First element of Char Array is: "<< as.MyChar[0];
        cout<<"\n"<<"Second element of Char Array is: "<< as.MyChar[1];

        return 0;
}
```

**Output:**

```text
First element of Integer Array is: 45
Second element of Integer Array is: 63
First element of Char Array is: K
Second element of Char Array is: S
```

In Listing 6, you see two arrays, MyArr and MyChar are created in the structure named, ArrStruct. In the main() function an object (as) is created of the ArrStruct structure. This object is used to access the elements of arrays declared within the structure. The elements of the arrays are assigned to certain values and then displayed on the screen by using their index value.
