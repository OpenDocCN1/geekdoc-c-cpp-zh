# ### The strrev() Function

The `strrev()` function is used to reverse a string, which takes one string argument. An example of using the `strrev()` function is shown in Listing 23. You can find the Func18.cpp file on the CD in the code/chapter3 folder:

# ### Listing 23: Using the strrev() Function

```
```cpp
#include <iostream.h>
#include <string.h>
int main()
{
    char string1[20];
    cout<<"Enter string :";
    cin>>string1;
    strrev(string1); //reverse string1
    cout<<"The reverse string of string1 = "<<string1;
    return 0;
}
```

# ### The strcpy() Function

The `strcpy()` function is used to copy the content of first string to second string. You have to pass two strings as an argument of the `strcpy()` function to copy first string to second string. An example of using the `strcpy()` function is shown in Listing 24. You can find the Func19.cpp file on the CD in the code/chapter3 folder:

# ### Listing 24: Using the strcpy() Function

```
```cpp
#include <iostream.h>
#include <string.h>

int main()
{
    char string1[20], string2[20];
    cout<<"Enter string :";
    cin>>string1;
    strcpy(string2, string1); //copy content of string1 to string2
    cout<<"The copied string1 is = "<<string2;
    return 0;
}
