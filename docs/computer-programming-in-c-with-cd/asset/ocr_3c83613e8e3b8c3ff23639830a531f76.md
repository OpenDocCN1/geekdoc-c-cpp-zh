An operator can be overloaded by defining a function for it. A function that is preceded by the operator keyword is called an operator function. An operator function redefines a particular operator so that it performs a specific operation when it is used with the object of a class. The syntax to overload an operator is:

```
```cpp
returntype classname:: operator operator_symbol(argument-list)
{
// body of the operator function
}
```
```

In the preceding syntax, the operator_symbol is a operator that can be any valid operator, such as +,*, /,+,<<,<>. The following code snippet shows an example of the operator function:

```
```cpp
int operator +(int a, int b)
{
    return a+b;
}
```
```

**Q12. What is a local class?**

Ans. A class declared within a function definition is called a local class. A local class definition can use the type names, enumerations, and static variables of the function within which the local class is defined.
