# Creating Customized Manipulator

In addition to all the pre-defined manipulators, you can also create your own manipulators in C++. Listing 10 shows how to define you own manipulator and use it in your program (you can find this example in the `customManipulator.cpp` file on the CD in the `code\chapter2` folder):

# Listing 10: Creating a Custom Manipulator

```
    #include<iostream.h>

    ostream & greet (ostream & output)
    {
        return output <<"Welcome, ";
    }

    void main()
    {
        char x[10];
        cout<<"Enter your name: ";
        cin>>x;
        cout<<greet<<x;
    }
```

Output:

```
    Enter your name: user
    Welcome, user
```

In Listing 10, you have created a custom manipulator, named as `greet`, which returns the output `Welcome`. Then, a program is created in which the `x` variable is declared, which stores a maximum of 10 character values. When you execute this program, you are prompted to the string, `Enter your name:`. The entered name gets stored in the `x` variable by using the `cin` object and then displays the name along with the output of the `greet` manipulator.
