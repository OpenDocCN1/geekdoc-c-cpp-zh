Inheritance is an important feature of Object-Oriented Programming (OOP). It is a mechanism in which one class acquires the properties and functionalities of another class. For example, a class, such as Dog, inherits features, such as eye color and hair color from the mammal class. A class that inherits or derives the features from another class is called a derived class or sub class and the class from which it is derived is called a base class or super class. Inheritance enables you to reuse the code of an existing program in a new C++ program. You can also modify the code of the existing program if the program does not fulfill the requirements of the new project.

In C++, when a class is derived from a base class, the base class is specified by using an access specifier, which is any one of the following keywords:

- public
- protected
- private

On the basis of access specifiers, there are exactly three types of derivation in C++, which includes private derivation, protected derivation, and public derivation. An access specifier appears before the name of a base class and applies only to that base class. Access specifiers control the accessibility or visibility of the members of the base class in the derived classes. If the name of the base class is specified by using the virtual keyword, the base class is referred to as a virtual base class. You can also inherit a class from multiple base classes, separated by commas. This type of inheritance is known as multiple inheritance.

In this chapter, you learn about the mechanism of inheritance by using base and derived classes, and the protected access specifier. You also learn about the three types of derivations: private, protected, and public, and how a derived class overrides the members of the base class. In addition, you learn about the order in which constructors and destructors are invoked when inheritance is implemented as well as about container classes. The chapter also discusses different forms of inheritance, such as single inheritance, multiple inheritance, and multilevel inheritance. It explains the problems that arise for a compiler when multiple inheritance is implemented. Next, you learn how to create and use pointer objects of base and derived classes to access their members. The chapter concludes with a description of the concept of binding and the implementation of dynamic binding with the concepts of virtual functions, pure virtual functions, and abstract classes.

### 7.1 Exploring the Concept of Base and Derived Classes

As mentioned earlier, a class that inherits or derives its features from another class is called a derived class, and the class from which it is derived is called a base class. The base class is also called a super class, and a derived class is called a subclass.

An instance of a derived class includes most of the features of the base class. Therefore, a derived class may contain a larger set of features than its base class. A derived class can modify some or all the inherited features of the base class. Figure 1 shows the relationship between a base class (Car) and a derived class (Maruti Zen):

![](img/8a6886c00caa6a1651a6c0e62bff341f_471_0.png)

▲ Figure 1: Displaying Relationship between Base Class and Derived Class

In Figure 1, the derived class, Maruti Zen, inherits various features, such as `no_of_tyres`, steering, and `no_of_lights`, of the base class, Car, and also has its own features, such as autolock and ac. The arrow in Figure 1 represents the direction of inheritance; that is, Car is the base class and Maruti Zen is the derived class. The direction of the arrow from the derived class towards the base class represents that the derived class is able to access the features of the base class; and not vice-versa.

Some advantages to create and use base and derived classes in C++ are:

- Reduces redundancy in code, as code is located at one place, that is, in the base class.
- Enables you to easily maintain the source code. This is because any change made to the base class is automatically reflected in the behavior of its derived classes; since these classes automatically inherit the new behavior.
- Extends the functionality of a base class (or an existing class) by adding functions to the derived class.

In C++, the basic syntax to inherit a new class (or a derived class) from an existing class (or a base class) is:

```cpp
class <BaseClass>
{
...
};
class <DerivedClass> : <access_specifier> <BaseClass>
{
...
};
```

In the preceding syntax, the base and derived classes are preceded by the `class` keyword. A derived class is declared by specifying the name of the base class after the name of the derived class and the access specifier. The derived class name is followed by the colon (`:`) symbol. The access specifier (`public`, `private`, or `protected`) indicates the type of derivation or inheritance.

The following code snippet shows an example of a derived class and a base class:

```cpp
class Dog: public Mammal
```

In the preceding code snippet, Dog refers to a derived class that is derived from the base class, Mammal.

Types of derivation are discussed later in the *Explaining Various Types of Derivations* section of the chapter. For now, always use `public` access specifier to inherit a derived class from a base class. The base class must be declared before inheriting a derived class from it; otherwise, you get a compilation error.

Now, let’s discuss the protected access specifier, which plays a prominent role in inheritance.
