Q12. What do you mean by operators in C++?

Ans. Operators are symbols that are used to perform operations, such as addition, subtraction, multiplication, or division based on the values stored in various variables. The various operators in C++ are:

+   - **Unary Operators:** The operators that work on a single operand are called Unary operator. The operand on which a unary operator works can be a constant or variable.
+   - **Binary Operators:** The operators that work on two operands are called binary operators. Some of the binary operators are Arithmetic operators, Assignment operators, Arithmetic Assignment operators, Relational operators, Logical operators, and Bitwise operators.
+   - **Shift Operators:** Shift operators are used to shift the bit pattern to left or right the operand. The operand should be an integral value. C++ supports right shift (`>>`) and left shift (`<<`) operators.
+   - **Ternary Operators:** The C++ operator that works as an alternative of the if-else statement is known as ternary operator. It is known as ternary operator because it works on three operands.
+   - **Special Operators:** There are some operators that are used to perform operations such as calculating the size of variables, accessing global variables, are known as special operators. The special operators in C++ are the sizeof operator, the comma operator, the scope resolution operator (SRO), dereferencing operators, and memory management operators.

Q13. What do you mean by stream?

Ans. A stream is a sequence of bytes that either serves as the source from which the input data can be obtained or a destination to which the output data can be sent. The stream that serves as source from which the data is taken is known as input stream and the destination stream, to which the data is sent is known as output stream. In other words, a C++ program retrieves the bytes from an input stream and inserts bytes to the output stream.
