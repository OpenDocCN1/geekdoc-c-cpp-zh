C++ is a popular Object-Oriented Programming (OOP) language that has evolved from the C language. Earlier, the C language was used to create computer programs. However, there were several problems with programming in C. One of the problems was that various functions in a C program were linked with each other and if an error occurred in any one of them, it became difficult for a programmer to locate the function and rectify the error. Another problem with the C language was that the code written in one program could not be used for another program. In addition, there were also security-related concerns in the C language. As the data was globally shared, it could easily be accessed by any function in a program and any modification in that data affected the functioning of the entire program. C++, which is an object oriented language, emerged as a solution for these problems.

This chapter introduces the features of OOP in C++ and also discusses the C++ language, its history, features and advantages. In this chapter, you also learn about the C++ as the superset of the C programming language and explore the basic components of the C++ language.

# 1.1 | Introduction to C++

C++ implements the concept of objects in the programming world. An object in the real world can be any entity that has its own attributes. For example, a pen is a real world entity, which has attributes, such as shape, color, and durability. There are various types of pens, such as Reynolds and Rotomac; however, not all of these pens are the same. These pens have their own attributes. Now, if we want to relate these pens to the programming world, they would be known as the objects of the pen class. An object can inherit some of the class attributes, though it also has its own attributes. For example, every pen should have a color and a shape; therefore, color and shape become the attributes of the pen class. Now, the color and shape of a pen may vary from pen to pen; therefore, color and shape becomes the attributes of the type of pen that is the object of the pen class.
