# Font or Font Family?

Keep in mind the difference between a font and a font family. A font family is a series of fonts with similar appearance, such as Times. A font refers to a specific version—Times normal, Times bold, Times italic, Times bold italic, and so on.

```
Code 5.2 Styles added to font-properties.css—Two separate typefaces are applied to the page
/** font-properties.css **/
body { font-family: Constantia, Georgia, "Times New Roman", serif; }
h1, h2, h3, h4, h5, h6, .byline {
font-family: Corbel, Helvetica, Arial, sans-serif; }
h2 .chaptertitle {
font-family: Corbel, Helvetica, Arial, sans-serif; }
```
