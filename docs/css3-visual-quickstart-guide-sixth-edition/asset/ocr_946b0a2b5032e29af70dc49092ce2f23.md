Insert a space and then enter a value to indicate how much you want to increase the count for each instance. The default is 1, but you can increase the count by any desired value.

Again, be very careful when using counter-reset because it can hamper accessibility. In fact, the example I use here is not really very good from the standpoint of universal accessibility. Shame on me!
