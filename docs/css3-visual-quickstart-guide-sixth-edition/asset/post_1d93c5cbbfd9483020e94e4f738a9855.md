## HTML and UTF Character Encoding

In Chapter 5, you used special HTML- and UTF-encoded characters. These are generally harder to find on your keyboard or may not be included in a particular font you are using. To ensure that they are properly represented, you should use the code presented in this appendix when adding the characters to your Web document.
