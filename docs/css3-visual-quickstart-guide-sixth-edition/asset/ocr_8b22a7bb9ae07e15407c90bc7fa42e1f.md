**Color stop**—The values of two or more colors at a particular point along the gradient with values separated by spaces. You should include at least two values (otherwise you’ll get a solid color), but you can follow them with as many values as you want. These may include any color value type as shown in Table 71, including transparent colors using RGBA or HSLA, and an optional percentage or length value to set where the color should be positioned along the gradient axis, such as **green 67%**: **rgba(221,160,221)**.

There's more than one way to create the same gradient.

At its simplest, a linear gradient can be two color values with the default angle at 270°, the start stop at 0%, and the end stop at 100%:

```
```css
linear-gradient(navy, gold);
```
```

This is the same as:

```
```css
linear-gradient(270deg, rgb(0,0,128),
· rgb(255,215,0));
```
```

```
```css
linear-gradient(to bottom, navy,
· gold);
```
```

```
```css
linear-gradient(to top, gold, navy);
```
```

```
```css
linear-gradient(#008 0%, #ffd700
· 100%);
```
```

```
```css
linear-gradient(180deg, gold 0%,
· navy 100%);
```
```

All of these values produce the same gradient.
