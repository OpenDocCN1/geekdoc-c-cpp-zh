# # Aligning Text Vertically

Using the **vertical-align** property, you can specify the vertical position of one inline element relative to the elements above or below it ➊. This means that the **vertical-align** property (Table 6.9) can be used only with inline tags and table tags—that is, tags without a break before or after them, such as the anchor (<a>), image (<img>), emphasized text (<em>), strong text (<strong>), and table data (<td>) tags.

# ## To define vertical alignment:

+   1. Add the vertical align property to your rule. Type **vertical-align** in the declaration list, followed by a colon (:) (Code 6.8).
+   
+   vertical-align:
