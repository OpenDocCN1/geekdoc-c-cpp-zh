# # Reading This Book

For the most part, the text, tables, figures, code, and examples should be self-explanatory. But you need to know a few things in advance to understand this book.

# ## CSS value tables

Each section that explains a CSS property includes a quick-reference table of the values that the property can use, as well as the browsers compatible with those values ①. Table I.4 lists the browser icons and abbreviations used in this book.

| Icon | Abbreviation | Browser |
| :--- | :--- | :--- |
| IE | IE | Microsoft Internet Explorer |
| FF | FF | Mozilla Firefox |
| Op | Op | Opera |
| Sa | Sa | Apple Safari |
| Ch | Ch | Google Chrome |

# ### Text-Overflow Values

| Value | Browser Support |
| :--- | :--- |
| clip | ◇ 9 ● ● ● ● ◇ |
| ellipsis | ◇ ● ● ● ● ◇ |
| inherit | ◇ ● ● ● ◇ |

A diamond indicates support with browser extension (-moz-, -webkit-, -o-, or -e-).

A circle indicates browser support.

A blank entry indicates no support.

If a number is added, indicates support is recent since that version.

① The property tables show you the values available with a property, the earliest browser version in which the value is available, and with which version of CSS the value was introduced.
