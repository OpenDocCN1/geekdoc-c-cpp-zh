# # Getting Started

For this chapter, we'll be using our Chapter 5 content from Alice's Adventures in Wonderland (Code 9.1). The HTML imports the final CSS from Chapters 5, 6, 7, and 8, as well as a new file you will be building in this chapter, ui-generatedcontent-properties.css. I've also converted all quote markings within paragraphs to use the «q» tag, allowing us to specify the quote style for different languages. Technically, this is how all quotations other than block quotes should be tagged, but it's rare to see them used.
