While it is possible to include the background image size and clip in the shorthand, the browser support for this is spotty at best. I recommend keeping these as separate declarations.

# 8. Add gradients to backgrounds.

```
background: rgb(153,153,153);
background: -webkit-linear-gradient(top, rgba(0,0,0,0), rgba(0,0,0,1));
background: -moz-linear-gradient(top, rgba(0,0,0,0), rgba(0,0,0,1));
background: -ms-linear-gradient(top, rgba(0,0,0,0), rgba(0,0,0,1));
background: -o-linear-gradient(top, rgba(0,0,0,0), rgba(0,0,0,1));
background: linear-gradient(to top, rgba(0,0,0,0), rgba(0,0,0,1));
```

Add the default background color, which will be used by browsers that do not understand gradients, and then add the gradient property for all of the browsers. Finally add the official CSS3 version at the bottom. Browsers will use whichever version applies to them.

> TIP The ability to place graphics behind any element on the screen is a very powerful design tool for Web pages, especially when using the CSS Sprite technique, where a single background image can be used for different dynamic states. See Chapter 14 for more information.

> TIP The default state for an element's background is none, so the parent element's background image and/or color will show through unless the background color or background image is set for that child element.

> TIP A fixed background can be particularly effective if you're using a graphic background in your layout to help define the layout grid.
