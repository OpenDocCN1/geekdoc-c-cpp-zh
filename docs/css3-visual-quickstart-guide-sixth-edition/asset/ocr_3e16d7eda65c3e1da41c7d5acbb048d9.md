# Using HTML5 Structure Now

I'll let you in on a little secret: You can use the HTML5 syntax to structure your Web pages and combine it with CSS3 (or older versions of CSS). HTML5 is implemented on most current browsers (including Internet Explorer), and you should start using it now.

Although CSS can be applied to any version of HTML in use today—including XHTML1 and HTML 4.01—I'll be using HTML5 throughout this book. This book is by no means an exhaustive resource of HTML5.
