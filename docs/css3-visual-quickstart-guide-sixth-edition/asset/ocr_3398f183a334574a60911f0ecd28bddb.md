# To set the style properties of individual HTML tags:

+   1. Add the style property to the HTML tag. Type style= in the HTML tag to which you want to apply styles (Code 3.1) <h1 style=

+   2. Add your CSS declarations in a comma-separated list. In quotes, type your style declarations in the format property: value, using a semicolon (;) and separating individual declarations. Be sure to close the declaration list with quotation marks. "color:red;"
