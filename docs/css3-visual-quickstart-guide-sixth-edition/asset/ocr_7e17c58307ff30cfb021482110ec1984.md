# # Controlling Overflowing Content

When an element is clipped or when the parent element's width and height are less than the area needed to display everything, some content is not displayed (A). The overflow property allows you to specify how this cropped content is treated.

Overflow for the width or height can be controlled independently using overflow-x and/or overflow-y.
