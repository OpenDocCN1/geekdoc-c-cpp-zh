# # Putting It All Together

Code 5.11 shows the final results for font-properties.css. It brings together the Web fonts at the top (they must always be placed at the top of the CSS file or <style> tag), and then the styles and weights are listed. Wherever possible, font values have been combined into the font shorthand property.
