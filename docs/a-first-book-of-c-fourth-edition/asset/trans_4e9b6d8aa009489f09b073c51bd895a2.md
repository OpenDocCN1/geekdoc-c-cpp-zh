## 11.（程序）海伦公式用于计算边长分别为 a、b 和 c 的三角形的面积 A，公式为

A = √[s(s - a)(s - b)(s - c)]

其中

s = (a + b + c)/2

编写、测试并执行一个函数，该函数从调用函数接受 a、b 和 c 的值作为参数，然后计算 s 和 |s - a| + |s - b| + |s - c| 的值。如果此量为正，则函数计算 A。如果此量为负，则 a、b 和 c 不能构成三角形，函数应设置 A = -1。函数应返回 A 的值。通过向函数传递各种数据并验证返回值来测试该函数。
