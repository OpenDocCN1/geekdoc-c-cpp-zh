# Point of Information

**List Application Considerations**

Vectors are the preferred list type when you need random access to objects but don’t need many insertions or deletions. The reason is that an index value can be used to go directly to the object being accessed. Insertions and deletions require modifying the underlying array supporting the vector and can be costly in terms of the overhead needed to perform these operations when many insertions and deletions are required.

Because the only way to get to an object in the middle of a list is by traversing all the objects before it or by traversing objects from the back of the list toward the object in the middle, attempts at random access tend to be costly in terms of access time. Therefore, a list is the preferred list type when many object insertions and deletions need to be made and object access tends to be sequential.

Finally, if you need to store only primitive data types, such as integers or double-precision values, a simple array should be your first choice.
