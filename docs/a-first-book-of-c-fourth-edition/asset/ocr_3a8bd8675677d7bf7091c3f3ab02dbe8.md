# ## 1.1 什么是机器学习

机器学习是人工智能的一个分支，它使计算机能够从数据中学习并做出决策，而无需明确编程。

机器学习算法通过从大量数据中识别模式来构建数学模型，并使用这些模型进行预测或决策。

+   - 监督学习
+   - 无监督学习
+   - 强化学习

监督学习是最常见的机器学习类型，它使用标记数据训练模型。

| 类型 | 描述 | 示例 |
|------|------|------|
| 分类 | 预测类别 | 垃圾邮件检测 |
| 回归 | 预测数值 | 房价预测 |

> > 机器学习是让计算机自动学习的技术。
