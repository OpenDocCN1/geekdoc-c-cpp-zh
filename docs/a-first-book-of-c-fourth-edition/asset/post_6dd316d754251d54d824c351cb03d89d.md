
## 3.2 数据链路层

数据链路层是OSI参考模型中的第二层，介于物理层和网络层之间。数据链路层在物理层提供的服务的基础上向网络层提供服务，其最基本的服务是将源自网络层来的数据可靠地传输到相邻节点的目标机网络层。为达到这一目的，数据链路必须具备的功能主要有：封装成帧、差错控制、流量控制等。

数据链路层的协议数据单元是数据帧。数据帧是一种包含完整目的地址和源地址的数据包，其结构通常包括帧头、数据部分和帧尾。帧头包含目的地址和源地址等控制信息，数据部分承载上层传递下来的数据，帧尾则包含用于差错检测的校验码。

数据链路层的主要功能包括：封装成帧、透明传输、差错检测和流量控制。封装成帧是指发送端在数据前后分别添加首部和尾部，构成一个帧；透明传输是指无论数据是什么样的比特组合，都应当能够在链路上传送；差错检测用于检测在传输过程中产生的误码；流量控制则用于控制发送方的发送速率，使其不超过接收方的接收能力。

数据链路层协议较多，常见的有以太网协议、PPP协议、HDLC协议等。以太网协议是目前应用最广泛的局域网数据链路层协议，它定义了帧格式、寻址方式和冲突检测机制等。PPP协议主要用于点对点链路，如拨号上网和宽带接入等场景。HDLC协议是一种面向比特的链路层协议，广泛应用于广域网中。

The list class has no method for returning any object except the first and last objects. Instead, to access an internal object, the list must be traversed from one end, and all objects before the one you’re accessing must be removed from the list. Technically, when an item is removed in this fashion, it’s referred to as "popping" the object from the list. Generally, to make sure removed objects aren’t lost, a copy of the list is made, either as a complete list or an object-by-object list as each object is removed, or popped.

### Point of Information

**List Application Considerations**

Vectors are the preferred list type when you need random access to objects but don’t need many insertions or deletions. The reason is that an index value can be used to go directly to the object being accessed. Insertions and deletions require modifying the underlying array supporting the vector and can be costly in terms of the overhead needed to perform these operations when many insertions and deletions are required.

Because the only way to get to an object in the middle of a list is by traversing all the objects before it or by traversing objects from the back of the list toward the object in the middle, attempts at random access tend to be costly in terms of access time. Therefore, a list is the preferred list type when many object insertions and deletions need to be made and object access tends to be sequential.

Finally, if you need to store only primitive data types, such as integers or double-precision values, a simple array should be your first choice.
