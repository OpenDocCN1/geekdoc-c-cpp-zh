# Point of Information

# Storage Classes

Variables of type auto and register are always local variables. Only non-static global variables can be declared by using the extern keyword. Doing so extends the variable's scope into another file or function.

Making a global variable static makes the variable private to the file in which it's declared. Therefore, static variables can't use the extern keyword. Except for static variables, all variables are initialized each time they come into scope; static variables are initialized only once, when they're defined.

{
