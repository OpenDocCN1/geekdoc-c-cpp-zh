# Program 8.8

```
#include <iostream>
#include <new>
using namespace std;

int main()
{
    int numgrades, i;

    cout << "Enter the number of grades to be processed: ";
    cin >> numgrades;

    int *grades = new int[numgrades];  // create the array

    for(i = 0; i < numgrades; i++)
    {
        cout << "  Enter a grade: ";
        cin >> grades[i];
    }
    cout << "\nAn array was created for " << numgrades << " integers\n";
    cout << "  The values stored in the array are:";
    for (i = 0; i < numgrades; i++)
        cout << "\n  " << grades[i];
    cout << endl;

    delete[] grades;   // return the storage to the heap
                     // the [] is required for array deletions

    return 0;
}
```

Notice in Program 8.8 that the delete operator is used with braces where the new operator was used previously to create an array. The delete[] statement restores the allocated block of storage back to the free storage area (the heap) while the program is running.¹ The only address delete requires is the starting address of the dynamically allocated storage block. Therefore, any address returned by new can be used subsequently by delete to restore reserved memory back to the computer. The delete operator doesn't alter the address passed
