> Besides being an improved version of C, the distinguishing characteristic of C++ is its support of object-oriented programming. Central to this object orientation is the concept of a class, which is a programmer-defined data type. Objects are created from classes.
> 
> This chapter explores the implications of allowing programmers to define their own data types by using classes. Additionally, you see how to construct classes and create objects from them. As you'll see, the construction of a class is based on variables and methods. What C++ provides is a unique way of combining these two elements into a self-contained, cohesive unit from which objects can be created.
