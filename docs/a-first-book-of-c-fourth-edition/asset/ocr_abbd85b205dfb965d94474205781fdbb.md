Because only the starting address of vals is passed to `findMax()`, the number of elements in the array need not be included in the declaration for vals.⁴ In fact, generally it’s advisable to omit the array size from the function header. For example, this more general form of `findMax()` can be used to find the maximum value of an integer array of arbitrary size:

```
int findMax(int vals[], int NUMELS)   // find the maximum value
{
    int i, max = vals[0];

    for (i = 1; i < NUMELS; i++)
        if (max < vals[i])
            max = vals[i];

    return max;
}
```

The more general form of `findMax()` declares that the function returns an integer value. The function expects the starting address of an integer array and the number of elements in the array as arguments. Then, using the number of elements as the boundary for its search, the function’s `for` loop causes each array element to be examined in sequential order to locate the maximum value.
