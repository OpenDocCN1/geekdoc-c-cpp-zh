The first loop, controlled by the value of i, is called the outer loop. The second loop, controlled by the value of j, is called the inner loop. Notice that all statements in the inner loop are contained in the boundaries of the outer loop, and a different variable is used to control each loop. For each trip through the outer loop, the inner loop runs through its entire sequence. Therefore, each time the i counter increases by 1, the inner for loop executes completely and goes through four values (j takes on the values 1 to 4), as shown in Figure 5.7.
