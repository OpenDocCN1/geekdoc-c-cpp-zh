Either expression can be used to locate the member. For example, the following expressions are equivalent:

```text
(*pt).idNum       can be replaced by pt->idNum
(*pt).payRate     can be replaced by pt->payRate
(*pt).hours       can be replaced by pt->hours
```

Program 16.5 shows passing a structure’s address and using a pointer with the new notation to reference the structure directly. The name of the pointer parameter declared in Program 16.5 is, of course, selected by the programmer. When calcNet() is called, emp’s starting address is passed to the function. Using this address as a starting point, structure members are accessed by including their names with the pointer.
