# 2.3 Variables and Declarations

All integer, floating-point, and other values used in a program are stored in and retrieved from the computer's memory. Conceptually, locations in memory are arranged like the rooms in a large hotel, and each memory location has a unique address, like room numbers in a hotel. Before high-level languages such as C++, memory locations were referenced by their addresses.
