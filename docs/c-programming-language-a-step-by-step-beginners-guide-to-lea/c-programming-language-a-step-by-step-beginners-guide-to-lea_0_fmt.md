那么到底什么是 identifier?

在编程语言中，用于定位变量、函数或其他由用户定义内容的符号就叫做标识符。它们通常以字母或下划线开头，随后跟零个或多个数字字符，例如 `abc`、`her`、`name30_a40c9`、`ret`、`Val`、`_temp` 等等。注意不能包含如 `@`、`%`、`£` 这类标点，同时大小写敏感，意味着 lower case 与 uppercase 被视为完全不同，比如`learner`和`Learner`是两个独立名称。

关于白空格用法解析如下：完全空白的行会被自动忽略，然而这并不局限于单纯的空白，还包括换页（`\n`）、制表（`tab`）及注释部分。实际上起到分隔语句元素的作用，使得编译器可以准确理解每个组成部分的意义。表达式`int main`只有通过 whitespace 才能区分出关键词类型声明。举例来说，`dessert = cream + candy;` //获取全部甜点，在赋值号两侧加或不添加入皆可，并不会影响解释器对其理解，请根据易读性自行裁量即可，务必保证整体语义清晰不发生歧义。

# Chapter 6: Making Decisions In C++

## if 语句

在 `if` 语句的这种形式中，选定的表达式从阶梯的顶部开始向下逐步测试，并在此过程中尝试验证当前条件。只有当条件符合预期时，才会执行相关的语句。

值得注意的要点：

*   在 C 语言中，只有非零或非空的值才被视为真（`true`）。因此，对于零值甚至空值的情况，程序会自动返回假（`false`）的结果。
*   `if`语句内可以包含一个不使用花括号（`{}`）括起来的单条语句。

请参见此示例：

```c
if (condition) {
```

## 循环分类导引

### 第一种：`while`循环（当型循环）

只要给定的前提还在保质期内，就持续推动后续模块能量溢出通道连接；**先验检查通过了再来实施核心体内容**；违反时就立即举办葬礼，谢幕离席，退票赔钱报警走人，就是这个意思哈。

典型格式长这样：

```
while (condition) {
    statement; // 也可以放好几份
}
```

### 第二种：`for`循环（常用于已知循环次数）

常用于已知多少遍，得了结清账的场景。初始化仅一次性发生，紧接着`measurement`入选考核，有没有误设为`false`，命中后就掰碎列表放弃返还；要是取了`nonzero`亦即代表OK，绿灯亮，并用枷锁捆扎好区块零件顺利投放上线。后面还会刷新有关的增量算式，习惯了这一串齿轮啮合旋转沉降，抵达燃料耗尽陨灭安宁。最后摘录示范模板供参考背诵，搭车回家吃饭咯啦啦啦~

```
for (initializer; terminal check; increment) {
    change body; // 此处也可容纳更多叙意大于一
}
```

### 第三种：`do...while`循环

此循环的工作方式与`while`循环几乎相似，但有一个区别。它的主体甚至在检查测试表达式之前就被执行了。只有在初次执行之后，才会对测试表达式进行评估。如果测试表达式被证明为真，则`do...while`循环的主体将再次被执行。重复过程会一直持续到测试表达式返回零（`0`）值（即变为假）为止。

以下是`do...while`循环的语法格式：

```c
do {
    statement;
} while (condition);
```

你需要留意语句的位置——它不像其他循环那样位于末尾，而是恰好在开头；在条件之前。理由是什么？如前所述，`do...while`循环的主体必须至少执行一次。
