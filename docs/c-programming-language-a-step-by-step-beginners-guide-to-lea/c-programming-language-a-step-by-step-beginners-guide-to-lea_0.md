`C 程序设计`将为您介绍最常用的编程语言之一——也是多年来衍生众多其他版本的基础。“无论您是初学程序员还是想了解各类计算机程序背后运行机理的用户”都是一本极好的书 。在本教程中你将理解:**编写条件语句 ,表达式甚至命令等行为如何高效组织以及相关编译执行并返回有用结果而非报错消息**.此外还能详尽知道所需要的数据类型及其呈现方式.说得更简单些 ——这个起步课程足以使刚接触者们迅速熟悉这套流行世界已久的 `World`.
