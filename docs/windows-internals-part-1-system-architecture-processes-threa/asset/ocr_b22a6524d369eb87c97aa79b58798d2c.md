# TABLE 7-16 Registry virtualization flags

| Flag | Meaning |
| REG_KEY_DONT_VIRTUALIZE | This specifies whether virtualization is enabled for this key. If the flag is set, virtualization is disabled. |
| REG_KEY_DONT_SILENT_FAIL | If the REG_KEY_DONT_VIRTUALIZE flag is set this specifies that a legacy application that would be denied access performing an operation on the key is granted MAXIMUM_ALLOWED rights to the key (any access the account is granted) instead of the application requested. If this flag is set, it implicitly disables virtualization as well. |
| REG_KEY_RECURSE_FLAG | This determines whether virtualization flags will propagate to the child keys (subkeys) of this key. |
