# EXPERIMENT Viewing handle access masks

Process Explorer can show the access mask associated with open handles. Follow these steps:

+   1. Open Process Explorer.

+   2. Open the View menu, choose Lower Pane View, and select Handles to configure the lower pane to show handles.

+   3. Right-click the column headers of the lower pane and choose Select Columns to open the dialog box shown here:

![](bbox=[0.198, 0.266, 0.658, 0.449])

+   4. Select the Access Mask and Decoded Access Mask check (the latter is available in 16.10) and click OK.

+   5. Select Explorer.exe and look at the lower pane handles. Each handle has an access mask, indicating the access granted using this handle. To help interpreting the bits of the access mask, the decoded access mask column shows a textual representation of the access masks for many types of objects:

![](bbox=[0.198, 0.609, 0.658, 0.755])

Notice there are access rights (for example, READ_CONTROL and SYNCHRONIZE) and specific ones (for example, KEY_READ and MODIFY_STATE). Most of the specific ones are shortened versions of the actual definitions in the headers (for example, MODIFY_STATE instead of EVENT_MODIFY_STATE, TERMINATE instead of PROCESS_TERMINATE).
