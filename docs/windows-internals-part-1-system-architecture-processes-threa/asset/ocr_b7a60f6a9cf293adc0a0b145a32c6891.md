Although this experiment will not provide a complete picture of the internal steps we've described, you'll be able to see several parts of the system in action, notably prefetch and Superfetch, image-file execution options and other compatibility checks, the image loader mapping.

We will look at a very simple executable—Notepad.exe—and launch it from a Command Prompt window (Cmd.exe). It is important that we look at both operations inside Cmd.exe and those inside Notepad.exe. Recall that all the user-mode work is performed by CreateProcessInternal, which the parent process calls before the kernel has created a new process object.

To set things up correctly, follow these steps:

+   1. Add two filters to Process Monitor: one for Cmd.exe and one for Notepad.exe. These are the only processes you should include. Be sure you don't have currently running instances of these two processes so that you know you're looking at the right events. The filter window should look like this:

![](bbox=[0.193, 0.359, 0.646, 0.577])

+   2. Make sure event logging is disabled (open the File and select Capture Events) and then start the command prompt.

+   3. Enable logging (opening the File menu and click the magnifying glass icon on the toolbar) and type Notepad and press Enter. On a typical Windows system, you should see anywhere between 500 and 3,500 events appear.

+   4. Stop capture and hide the Sequence and Time of columns so that you can focus your attention on the columns of interest. Your window should look similar to the one shown in the screenshot.
