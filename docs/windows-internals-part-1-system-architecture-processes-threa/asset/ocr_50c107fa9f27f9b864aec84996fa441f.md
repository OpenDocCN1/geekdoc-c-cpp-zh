Most drivers dispatch routines to handle only subset of possible major function codes, including create (open), read, write, I/O control, power, Plug and Play, system control (for WMI commands), cleanup, and close. File-system drivers are an example of a driver type that often fills in most or all of its dispatch points with functions. In contrast, a simple USB driver would probably fill in the routines needed for open, close, read, write, and sending I/O controls. The I/O manager sets any dispatch points that a driver needs to fill to its Iop1DeviceRequest, which completes the IRP with an error status indicating that the major function in the IRP is invalid for that device.

+   **Minor function** This is used to augment the major function code for some functions. For example, IRP_MJ_READ (read) and IRP_MJ_WRITE (write) have no minor functions. But Plug and Power IRPs have a minor IRP write code that specializes the general major code. For example, the Plug and IRP_MJ_PnP code is too generic; the exact instruction is given by the minor function, such as IRP_MN_START_DEVICE, IRP_MN_REMOVE_DEVICE, and so on.

+   **Parameters** This is a monstrous of structures, each of which validates for a particular major function code or a combination of major/minor codes. For example, a read operation (IRP_MJ_READ), the Parameters Read structure holds information on the request, such as the buffer size.

+   **File object Device Object** These point to the associated FILE_OBJECT and DEVICE_OBJECT for this I/O request.

+   **Completion routine** This is an optional function that a driver can register with the IoSetCompletionRoutine(Ex) Ddl, to be called when the IRP is completed by a lower layer driver. At that point, the driver can look at the completion status of the IRP and do any needed post-processing. It can even undo the completion (returning the special value STATUS_MORE_PROCESSING_REQUIRED from the function) and resend the IRP (perhaps with modified parameters) to the device node—even a different device node—again.

+   **Context** This is an arbitrary value set with the IoSetCompletionRoutine(Ex) call that is passed, as is, to the completion routine.
