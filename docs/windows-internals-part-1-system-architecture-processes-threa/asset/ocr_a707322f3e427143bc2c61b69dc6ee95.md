token for a network logon. After the access token successfully created, Lsass duplicates the token, creating a handle that can be passed to Winlogon, and closes its own handle. If necessary, the logon operation is audited. At this point, Lsass returns to Winlogon along with a handle to the access token, LUID for the logon session, and the profile information, if any, that the authentication package returned.

# EXPERIMENT: Listing active logon sessions

As long as at least one token exists with a given logon LUID, Windows considers the logon session to be active. You can use the LogonTools from Sysinternals, which uses the LsaumerateLogonSessions function (documented in the Windows SDK) to list the active logon sessions:

```
C:\WINDOWS\system32>logonsessions
```
