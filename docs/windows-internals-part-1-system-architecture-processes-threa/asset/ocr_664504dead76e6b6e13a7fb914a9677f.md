# Device-stack driver loading

How does the PnP manager find the corrects as part of building the device stack? The registry has this information scattered in three important keys (and their subkeys), shown in Table 6-7 (Note that CCS is for CurrentControlSet).

TABLE 6-7 Important keys for plug-and-play driver loading
| Registry Key | Short Name | Description |
| --- | --- | --- |
| HKLM\System\Enum | Hardware key | Settings for known hardware devices |
| HKLM\System\Control\Class | Class key | Settings for device types |
| HKLM\System\Control\Services | Software key | Settings for drivers |

When a bus performs device enumeration and discovers a new device, it creates a PDO to represent the existence of the physical device that has been detected. Next, it informs the PnP manager by calling IoInvalidateDeviceRelations (documented in the WDK) with the BusRelations enumeration and the PDO, notifying the PnP manager that a change on its bus has been detected. In response, the PnP manager asks the bus (through an IRP) for the device identifier.

The identifiers are bus-specific; for example, a USB device identifier consists of an ID VID (ID) for the hardware vendor and a device ID (PID) that the vendor assigned to the device. For a PCI device, a similar vendor ID is required, along with a device ID, to identify the device within a vendor (plus some optional components; the WDK for more information on device ID formats). Together, these IDs form Plug and calls a device ID. The PnP manager asks the driver for an instance ID to hit different instances of the same hardware. The instance ID can describe either bus-relative location (for example, the USB port) or a globally descriptor (for example, a serial number).

The device ID and instance ID are combined to form a device ID (DIID), which the PnP manager uses to locate the device's key under the Registry key shown in Table 6-7. The subkeys that have the key form <Enumerator>\<Device ID>\<Instance ID>, where the enumerator is a bus driver, the device ID is a unique identifier for a type of device, and the instance ID identifies different instances of the same hardware.
