# EXPERIMENT: Looking at a driver registered I/O routines

The ldobj kernel debugger command can list the fast I/O routines that a driver registers in its driver object. Typically, however, only file-system drivers have use for I/O routines—although there are exceptions, such as network protocol drivers and bus filters. The output shows the fast I/O table for the NTFS file-system driver:

```
lkd> dr0 \filesystemntfs 2
Driver object (fffc404b2bf8f10) is for:
\FileSystemNTFS
DriverEntry:       ffff80e5663a030
DriverStartIo:    00000000
DriverUnload:     00000000
AddDevice:        00000000

```
