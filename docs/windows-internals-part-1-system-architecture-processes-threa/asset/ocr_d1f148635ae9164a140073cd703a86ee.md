# Security identifiers

Instead of using names (which might or not be unique) to identify entities that perform actions in a system, Windows uses security identifiers (SIDs). Users have SIDs, as do local and domain groups, local computers, domain members, and services. A SID is a variable-length numeric value that consists of a SID structure revision number, a 48-bit identifier value, and a variable number of 32-bit subauthority or relative identifier (RID) values. The authority value identifies the agent that issued the SID, and this agent is typically a Windows local system or domain. Subauthority identify trustees to the issuing authority, and RIDs are a simple way for Windows to create unique SIDs based on a common base SID. Because SIDs are long and Windows takes to generate truly random values within each SID, it is virtually impossible for Windows to issue the same SID twice on machines or domains anywhere in the world.

When displayed textualy, each SID carries an prefix, and its various components are separated with hyphens like so:

```
S-1-5-21-1463437245-122412800-86342198-1128
```

In this SID, the revision number is 1, the authority value is 5 (the Windows security authority), and four subauthority plus one RID (1128) make the remainder of the SID. This SID is a domain SID, but a local computer on the domain would have a SID with the same revision number, identifier authority value, and number of subauthority.

When you install Windows, the Windows Setup program issues the computer SID. Windows assigns local-account SIDs to accounts based on the source computer's SID and has a RID at the end. RIDs for accounts and groups start at 1000 and increase in increments of 1 for each new user or group. Similarly, Domain Controller Promote (Dcpromo.exe), the utility to create a new Windows domain, reuses the computer SID of the being promoted to domain controller and creates a new SID for the computer if it is demoted. Windows issues to new domain accounts SID that are based on the domain SID and have an appended RID (starting at 1000 and increasing in increments of 1 for each new user or group). A RID of 1028 indicates that the SID is the twenty-ninth SID inside the domain.

Windows issues SIDs that consist of a computer or domain SID with a predefined RID to many defined accounts and groups. For example, the RID for the Administrator account is 500, and the RID for the guest account is S01. A computer's local Administrator account, for example, has the computer SID as its base with the RID of 500 appended to:

```
S-1-5-21-13124455-12541255-62235125-500
```

Windows also defines a number of built-in local and domain SIDs to represent well-known groups. For example, a SID that identifies all and accounts (except anonymous users) is the Everyone SID: S-1-1-0. Another example of a group that a SID can represent is the Network group, which is the group that represents users who have logged on to a machine from the network. The Network group SID is S-1-5-2.
