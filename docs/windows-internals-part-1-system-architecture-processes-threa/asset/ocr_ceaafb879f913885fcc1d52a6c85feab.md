# # Plug-and-play driver installation

If the PnP manager encounters a device for which no driver is installed, it relies on the user-mode PnP manager to guide the installation process. If the device is detected during the system boot, a devnode is defined for the device, but the loading process is postponed until the user-mode PnP manager starts. (The user-mode PnP manager service is implemented in Pnpmgr.dll host in a standard Svchost instance.)

The components involved in a driver installation are shown in Figure 6-42. Dark-shaded objects in the figure correspond to components generally supplied by the system, whereas lighter-shaded objects are those in a driver installation files. First, a bus informs the PnP manager of a device it enumerates using a Device ID (1). The PnP manager checks the registry for the presence of a corresponding driver function, and when it doesn't find one, it informs the user-mode PnP manager (2) of the new device by its Device ID. The user-mode PnP manager tries to perform an automatic install without user intervention. If the installation process involves the posting of dialog boxes that require user interaction and the currently logged-on user has administrator privileges, the user-mode PnP manager launches the Rund32.exe application (the same application that has classic.cpl Control Panel utilities) to execute the Hardware Installation Wizard (3) (%SystemRoot%\System32\Devnew.dll). If the currently logged-on user doesn't have administrator privileges (or no user is logged on) and the installation requires user interaction, the user PnP manager defers the installation until a privileged user logs on. The Hardware Installation Wizard uses Setup.ini and Cfgmgr32.dll (configuration manager) API functions to locate INF files that contain drivers that are compatible with the detected device. This process might involve having the user insert media containing a vendor INF, or the wizard might locate a suitable INF in the driver store (%SystemRoot%\System32\DriverStore) that contains drivers that ship with Windows or others that are downloaded through Windows Update.
