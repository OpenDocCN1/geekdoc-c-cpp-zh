## User-mode debugging

The tools can also be used to attach to a user-process and to examine/or change process memory. There are two options attaching to a process:

Note that dt does not show substructures (structures within structures) by default. To show substructures, use the -r or -b switches. For example, using one of these switches to display the kernel interrupt shows the format of the _LIST_ENTRY stored in the InterruptList (see the documentation for the exact differences between the -r and -b switches).

```
1kd> dt nt!_INTERRUPT -r
+0000 Type : Int2b
+0002 Size : Int2b
+0008 InterruptList : _LIST_ENTRY
  +0000 Flink : Ptr64 _LIST_ENTRY
    +0000 Flink : Ptr64 _LIST_ENTRY
    +0008 Blink : Ptr64 _LIST_ENTRY
  +0008 Blink : Ptr64 _LIST_ENTRY
    +0000 Flink : Ptr64 _LIST_ENTRY
    +0008 Blink : Ptr64 _LIST_ENTRY
```

The dt command even lets you see the level of recursion of structures by appending to the -r switch. The following example means one level of recursion:

```
1kd> dt nt!_INTERRUPT -r1
```
