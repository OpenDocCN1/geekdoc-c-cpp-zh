# Conclusion

The I/O system defines the model of I/O processing on Windows and performs functions that are common or required by more than one driver. Its chief responsibilities are to create IRPs and send the packets through various drivers, returning results to the caller when an I/O is complete. The I/O manager locates various drivers and devices using I/O system objects, including driver and device objects. The Windows I/O system operates asynchronously to achieve high performance and provides both synchronous and asynchronous I/O capabilities to usermode applications.
