# TABLE 7-11 Privileges (continued)

| Privilege | User Right | Privilege Usage |
| --- | --- | --- |
| SeLoadDriverPrivilege | Load and unload device drivers | Checked by the NtLoadDriver and NtUnloadDriver functions. |
| SeLockMemoryPrivilege | Lock pages in memory | Checked by NtVirtual, the kernel implementation of VirtualLock. |
| SeMachineAccountPrivilege | Add workstations to the domain | Checked by the Security Account on a domain controller when creating a machine account in the domain |
| SeManageVolumePrivilege | Perform volume maintenance tasks | Enforced by file system drivers during a volume operation, which is required to perform disk-checking and defragmenting activities. |
| SeProfileSingleProcessPrivilege | Profile process | Checked by Superfetch and the prefetcher requesting information for an individual process through the NtQuerySystemInformation API. |
| SeRelabelPrivilege | Modify object label | Checked by the SRM when the integrity of an object owned by another user, or attempting to restore the integrity of an object higher than that of the caller's token. |
| SeRemoteShutdownPrivilege | Force shutdown from a remote system | Winlog checks that callers of the InitiateShutdown function have this privilege |
| SeRestorePrivilege | Restore files and directories | This privilege allows NTFS to grant the following access to any file or directory, regardless of the security descriptor's: WRITE_DATA, WRITE_OWNER, ACCESS_SYSTEM_SECURITY, FILE_GENERIC_WRITE, FILE_ADD, FILE_ADD_SUBDIRECTORY, and DELETE. Note that when opening a file for restore, the caller must specify the FILE_SEMANTICS flags. Also corresponding access to registry keys using RegSaveKey |
| SeSecurityPrivilege | Manage auditing and security log | Required to access the SACL of a security descriptor and read and clear the security event log | |
| SeShutdownPrivilege | Shut down the system | Checked by NtShutdownSystem and NtErrorHandler, which presents a system error dialog box on the interactive console |
| SeSyncAgentPrivilege | Synchronize directory service data | Required to use the LDAP directory service the holder to read all objects and properties in the directory, regardless of the protection on the objects and properties |
| SeSystemEnvironmentPrivilege | Modify environment variables | Required by NtSystemEnvironmentValue and NtQuerySystemEnvironmentValue to read environment variables using the hardware abstraction layer (HAL) |
| SeProfilePrivilege | Profile system performance | Checked by NtCreateProfile, the function used to perform profiling of the system. This is used by the Kernel prof tool, for example. |
| SeSystemtimePrivilege | Change the system time | Required to change the time or date. |
