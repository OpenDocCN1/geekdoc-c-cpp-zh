To get more process details, click the Details tab. Or, right-click a process and choose Go to Details to switch to the Details tab and select that specific process.

> The Windows 7 Task Manager's Processes tab is roughly equivalent to Windows 8+ Task Manager's Details tab. The Windows 7 Task Manager's shows top-level visible and not processes per se. This information is now contained in the Processes of the Windows 8+ Task Manager.
