# Local Security Policy

![](bbox=[0.1248, 0.0735, 0.8712, 0.4865])

**Figure 7-33** Appocker and SRP policies coexist in the same binary (AppIdSvc.dll), which runs within an SvHost process.

The AppID requests a registry change notification to monitor changes under that key, which is written by either a GPO or the Appocker UI in the Local Security Policy MMC snap-in. When a change is detected, the AppID service triggers a user-task (AppIDPolicyConverter.exe), which then translates them into binary format ACES and SDDL strings, which are audited by both the user-mode and kernel-mode AppID and AppL components. The task stores the translated rules under HKLM\SYSTEM\CurrentControlSet\Control\Srp\Gp. This key is writable only by System and Administrators, and it is read-only for authenticated users. Both user-mode and kernel-mode AppID components read the translated rules from the registry. The service also monitors the local machine trusted certificate store, and it invokes a user-mode (AppCertStoreCheck.exe) to reverify the certificates at least once per day and whenever there is a change to the certificate store.
