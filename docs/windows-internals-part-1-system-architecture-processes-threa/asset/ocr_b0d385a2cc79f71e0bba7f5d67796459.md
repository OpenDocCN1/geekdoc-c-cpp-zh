If you're using the latest Windows 10 SDK, the updated version of WinDbg will include an intuitive hyperlink under the PEB address, which you can click to automatically execute both the .process command and the !peb command.

The PEB in the user-mode address space of the process it describes. contains information needed by the loader, the heap manager, and other Windows components that need to access it from user mode; would be too expensive to expose all information through system calls. EPROCESS and KPROCESS structures are accessible only from kernel mode. The important fields of the PEB are illustrated in Figure 3-4 and are explained in more detail later in this chapter.
