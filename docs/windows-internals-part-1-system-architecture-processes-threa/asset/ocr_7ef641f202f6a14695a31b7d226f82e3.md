# EXPERIMENT: Viewing the system power capabilities and policy

You can view a computer's system power capabilities using the !ipocaps kernel debugger
command. Here's the output of the command when running on an x64 Windows 10 laptop:

```
1kd> !ipocaps
PopCapacities @ 0ffff8035a8ce60
Misc Supported Features: PwrButton SlButton L3 S4 S5 HiberFileWalk
VideoDim
Processor Features: Thermal
Disk Features:
Battery Features:
Battery 0 - Capacity: 0 Granularity: 0
Battery 1 - Capacity: 0 Granularity: 0
Battery 2 - Capacity: 0 Granularity: 0
Wake Caps:
Ac Online Wake: Sx
Soft Lid Wake: S4
RTC Wake: Sx
Min Device Wake: Sx
Default Wake: Sx
```

The Misc. Supported Features lines that, in addition to S0 (fully), the system
supports system power states of S3, S4 and S5 (it doesn't implement S1 or S2) and has a valid
hiberation file to it can save memory when it hibernates (state S4).

The Power Options page, which you open by selecting Power Options in the Control Panel,
lets you configure various aspects of the system's power policy. The exact properties you can
figure on the system's power capabilities.
