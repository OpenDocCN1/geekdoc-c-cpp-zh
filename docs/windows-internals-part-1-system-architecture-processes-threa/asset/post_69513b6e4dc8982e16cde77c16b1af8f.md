# EXPERIMENT: Launching a program at low integrity level

When you elevate a program, by using the Run as Administrator option or because the program is requesting it, the program is explicitly launched at high integrity level. However, it is also possible to launch a program at low integrity level using PsExec from Sysinternals:

+   1. Launch Notepad at low integrity level using the following command:
   c:\psexec -l notepad.exe

+   2. Trying a file (such as one of the XML files) in the %SystemRoot%\System2 directory. Notice that you can browse the directory and open any file contained within it.

+   3. In Notepad, open the File menu and choose New.
