# Physical memory limits

Now that you've learned how Windows keeps track of physical memory, we'll describe how much of it can actually support. Because most systems access more code and data than can fit in physical memory physical memory is essentially a window into the code and data used over time. The amount of memory can therefore affect performance when data or code that a process or the operating system needs is not present, the memory manager must bring it in from disk or remote storage.

Besides affecting performance, the amount of physical memory affects other resource limits. For example, the amount of non-paged pool is backed by physical memory, thus obviously constrained by physical memory. Physical memory also contributes to the system virtual memory limit, which is the sum of the size of physical memory plus the configured size of all paging files. Physical memory can also indirectly limit the number of processes.

Windows support for physical memory is dictated by hardware limitations, licensing, operating system structures, and driver compatibility.
