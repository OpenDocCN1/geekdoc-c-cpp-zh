When expanded, the CPU tab displays information about per-process CPU usage, just like Task Manager. The CPU tab also includes a separate display of services and their associated CPU usage and average. Each service-hosting process is identified by the service group it is hosting. As Process Explorer, selecting a process (by clicking its associated check box) will display a list of named handles opened by the process, as well as a list of modules (such as DLLs) that are loaded in the process address space The Search Handles box can be used to search for processes which have opened a handle to a given resource name.

The Memory tab displays the same information that one can obtain with Task Manager, but it is organized for the entire system. A memory bar graph displays the current utilization of physical memory into either hardware-reserved, in-use, modified, standby, or free memory. See Chapter 5 for an example of these means of terms.

The Disk tab, on the other hand, displays per-file information for I/O in a way that makes it easy to identify the most-accessed, the most-written, or the most-read files on the system. The results can be further filtered by process.

The Network tab displays the active network connections, the processes they own, and how much data is going through. Information makes it possible to see background activity that might be hard to detect otherwise. In addition, it shows the TCP connections that are active on the system, organized by process, with data such as the remote and local port address and packet latency. Finally, it displays a list of listening ports, allowing an administrator to see which services or applications are currently waiting for connections on a given port. The protocol and firewall policy for each port and process is also shown.
