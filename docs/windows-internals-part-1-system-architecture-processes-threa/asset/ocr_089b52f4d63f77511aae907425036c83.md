To create this hierarchy, processes should be added to jobs from the root job. Here are a set of steps to create this hierarchy:

+   1. Add process P1 to job 1.
2. Add process P1 to job 2. This creates the first nesting.
3. Add process P2 to job 1.
4. Add process P2 to job 3. This creates the second nesting.
5. Add process P3 to job 2.
6. Add process P4 to job 1.

# EXPERIMENT: Viewing the job object

You can view job objects with the Performance Monitor tool. (Look for the Job Object and Object Details categories.)You can view unnamed jobs with the kernel debugger !job or dt nt!_exe commands.

To see whether a process is associated with a job, you can use the kernel debugger !process command or Process Explorer. Follow these steps to create and view an unnamed job:

+   1. From the command prompt, use the run command to create a process running the command prompt (cmd.exe). For example, type runas /user:<domain>\<username> cmd.

+   2. You will be prompted for your password. Enter your password, and a Command Prompt window will appear. The Windows service that executes run commands creates an unnamed job to contain all processes (so that it can terminate these processes at logout).

+   3. Run Process Explorer, using the Options menu, choose Choose Colors, and check the Jobs entry. Note that the Cmd.exe process and its child Host.exe process are highlighted as part of a job, as shown here:
