# Examining memory usage

The Memory and performance-counter categories provide access to most of the details about system and process memory utilization. Throughout this chapter, we'll include references to specific performance counters that contain information related to the component being described. We've included relevant examples and experiments throughout the chapter. One word of caution, however: Different utilities vary and sometimes inconsistent or confusing names when describing memory information. The following experiment illustrates this.
