In addition to including the documentation, the WDK contains header files (in particular, ntdkh.h, wdm.h) that define key internal data structures and constants as interfaces to many internal system routines. These files are useful when exploring Windows internal data structures with the kernel debugger although the general layout and content of these structures are shown in this book, detailed field-level descriptions (such as size and data types) are not. A of these data structures—such as object dispatcher headers, wait blocks, events, mutants, semaphores and so on—are, however, fully described in the WDK.

If you want to dig into the I/O system and driver model what is presented in this book, read the WDK documentation—especially the Kernel-Mode Driver Architecture Design Guide and Kernel-Mode Driver Reference manuals. You may also find useful Programming the Windows Driver Model, Second Edition by Walter有意 (Microsoft Press, 2002) and Developing Drivers with the Windows Driver Foundation by Penny Orrell and Guy Smith (Microsoft Press, 2007).

# Sysinternals tools

Many experiments in this book use freeware tools that you can download from Sysinternals. Mark Russovich, coauthor of this book, wrote most of these tools. The most popular tools include Process Explorer and Process Monitor. Note that many of these tools utilize the installation and execution of kernel-mode device drivers and thus require administrator, or elevated, privileges—although some of them can run with limited functionality and output on a standard, non-elevated, user account.

Because the Sysinternals tools are updated frequently, make sure you have the latest version. To be notified of tool updates, you can follow the Sysinternals Site Blog (an RSS feed). For a description of all the tools, a description of how to use them, and case studies of problems solved, Windows Sysinternals Administrator’s Reference by Mark Russovich and Aaron Margis (Microsoft Press, 2011). For questions and discussions on the tools, use the Sysinternals Forums.
