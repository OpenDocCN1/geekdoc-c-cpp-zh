# EXPERIMENT: Displaying type information for kernel structures

To display the list of kernel structures whose type information is included in the kernel symbols, type dt nt!* in the kernel debugger. A sample partial output is shown here. (ntknlmp is the internal file name of the 64-bit kernel. For more details, see Chapter 2.)

```
kd dt nt!**
tknlmp!_SYSTEM_TIME
tknlmp!_NT_PRODUCT_TYPE
tknlmp!_ALTERNATIVE_ARCHITECTURE_TYPE
tknlmp!_KUSER_SHARED_DATA
tknlmp!_ULARGE_INTEGER
tknlmp!_TP_POOL
tknlmp!_TP_CLEANUP_GROUP
tknlmp!_ACTIVATION_CONTEXT
tknlmp!_TP_CALLBACK_INSTANCE
tknlmp!_TP_CALLBACK_PRIORITY
tknlmp!_TP_CALLBACK_ENVIRONMENT_V3
tknlmp!_TEB
```

You can also use the dt command to search for specific structures by its wildcard lookup capability. For example, if you are looking for the structure of an interrupt object, you could type dt nt!*"interrupt*:

```
kd dt nt!*"interrupt**
tknlmp!_INTERRUPT_MODE
tknlmp!_INTERRUPT_POLARITY
tknlmp!_PEP_ACPI_INTERRUPT_RESOURCE
tknlmp!_INTERRUPT
tknlmp!_UNEXPECTED_INTERRUPT
tknlmp!_INTERRUPT_CONNECTION_DATA
tknlmp!_INTERRUPT_VECTOR_DATA
tknlmp!_HT_INTR_INFO
tknlmp!_INTERRUPT_REMAPPING_INFO
```

You can use dt to format a specific structure as shown next (the debugger treats structures as insensitive):

```
kd dt nt!*KINTERRUPT
+0000 Type : Int2B
+0002 Size : Int2B
+0008 InterruptList : _LIST_ENTRY
+0018 ServiceRoutine : Ptr64 unsigned char
+0020 MessageServiceRoutine : Ptr64 unsigned char
+0028 MessageIndex : Uint48B
+0030 ServiceContext : Ptr64 Void
+0038 SpinLock : Uint8B
+0040 TickCount : Uint8B
+0048 ActualLock : Ptr64 Uint8B
+0050 DispatchAddress : Ptr64 void
+0058 Vector : Uint48B
+005c Irq : Uchar
```
