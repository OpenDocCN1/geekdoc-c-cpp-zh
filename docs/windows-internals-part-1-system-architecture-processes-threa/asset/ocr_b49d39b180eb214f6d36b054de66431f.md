# EXPERIMENT: Examining the CSR_THREAD

You can dump the CSR_THREAD structure with the dt command in the kernel-mode debugger
while the debugger context is set to a Csross. Follow the instructions in the experiment
Examining the CSR_PROCESS” in Chapter 3 to perform this operation. Here is an example
from Windows 10 x64 system:

```
kd> dt cssrl_csr_thread
+0x000 CreateTime      : _LARGE_INTEGER
+0x008 Link             : _LIST_ENTRY
+0x018 HashLinks       : _LIST_ENTRY
+0x028 ClientId        : _CLIENT_ID
+0x038 Process          : Ptr64_CSR_PROCESS
+0x040 ThreadHandle     : Ptr64 Void
+0x048 Flags            : Uint4B
+0x04C ReferenceCount   : Int4B
+0x050 ImpersonateCount  : Uint4B
```

The W32THREAD structure, illustrated in Figure 4-5, is analogous to the data structure of
W32PROCESS, but it is applied to threads this structure contains useful information for the GDI
subsystem (brushes and Device Context attributes) and DirectX, as well as for the User Mode Point
Driver (UMPD) framework that vendors end up to use user-mode printer drivers. Finally, it contains a
rendering state useful for desktop compositing and anti-aliasing.

# Birth of a thread

t main function) creates a new thread. The request filters down to the Windows executive, where the
process manager allocates space for a thread object and calls the kernel to initialize the thread control
