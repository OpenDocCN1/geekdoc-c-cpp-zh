# The CFG bitmap

As we saw earlier, forcing the process to iterate through a list of function calls for every instruction would not be practical. Instead of an algorithm that requires linear time O(n), performance requirements dictate that an O(1) algorithm be used instead—one where constant lookup time should be used, regardless of how many functions are present in the table. This constant lookup time should be as small as possible. A clear winner of such a requirement would be an array indexable by the get-function's address, which is an indication of whether it is valid or not (such as a simple BOOL). With 128 TB of addresses, such an array would itself have to be 128 TB size(BOOL), which is an unacceptable storage size—bigger than the address space itself. How can we do?
