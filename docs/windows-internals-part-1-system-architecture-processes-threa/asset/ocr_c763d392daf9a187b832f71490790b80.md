# EXPERIMENT: Viewing the prioritized standby lists

You can use Process Explorer to look at the size of each standby paging list by opening the System Information dialog box and selecting the Memory tab:

![](bbox=[0.176, 0.155, 0.693, 0.518])

On the recently started x86 system in this experiment, there is about 9 MB of data cached at p0, about 47 MB at p1, 68 MB at p2. The following shows what happens when we use the Testlimit from Sysinternals to commit and touch as much memory as possible:

```
C:\Tools\Sysinternals>Testlimit.exe
```

![](bbox=[0.176, 0.673, 0.693, 0.836])

Note how the lower-priority standby lists were listed first (shown by the repurposed count) and are now much smaller, while the higher lists still contain valuable data.
