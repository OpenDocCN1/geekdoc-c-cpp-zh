The only definitive way to know what access a particular user or group will to have an object (other than that user or a member of the group try to access the object) is to use the Effective Access tab of the dialog box that is displayed when you click the Advanced button in the Properties dialog box. Enter the name of the user or group you want to check and the dialog box shows you which permissions they are allowed for the object.
