In this example, the Desktop Window Manager (dwm.exe) process has a handle open to a device created by the kernel service driver (kccd.sys). You can look at a specific file object in the kernel debugger by first identifying the address of the object. The following command reports information on the highlighted handle (handle value 0xD4) in the preceding screenshot, which is in the dwm.exe process that has a process ID of 452.

1kd> !handle 452

