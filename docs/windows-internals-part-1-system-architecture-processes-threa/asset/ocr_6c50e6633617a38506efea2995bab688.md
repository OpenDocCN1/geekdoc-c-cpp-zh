We would like to identify a physical page involved in the allocation of virtual address space done by TestLimit-d option. RAMMap does not give an indication about which virtual allocations are associated with RAMMap's VirtualAlloc/free calls. However, we can get a good hint of this through the VMMap tool. Using RAMMap on the same process, we find the following:

![](bbox=[0.238, 0.198, 0.856, 0.465])

In the lower part of the display, we find hundreds of allocations of process private data, each 1 MB in size and with 1 MB committed. These match the size of the allocations done by TestLimit in the preceding screenshots. Note the starting virtual address, 0x310000.
