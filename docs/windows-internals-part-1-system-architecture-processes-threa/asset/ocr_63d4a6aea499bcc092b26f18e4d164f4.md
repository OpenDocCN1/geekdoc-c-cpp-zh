# Loaded module database

The loader maintains a list of all modules (DLLs as well as the primary executable) that have been loaded by a process. This information is stored in the PEB—namely, in a structure identified by Ldr and called PE_LDR_DATA. In the structure, loader maintains three doubly linked lists, containing the same information but ordered differently (by load order, memory location, or initialization order). These lists structures called loader data table entries (LDR_DATA_TABLE_ENTRY) that store information about each module.
