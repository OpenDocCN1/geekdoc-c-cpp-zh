After initializing cache, ReadyBoost intercepts all reads and writes to local hard disk volumes (C:\ for example) and copies any data being read or writing into the cache file that we created. There are exceptions—for example, data that hasn't been read in a long while or data that belongs to a 2:1 Volume Snapshot. Data stored on the cached drive is compressed and typically a 4 GB cache file will contain 8 GB of data. Each block is encrypted as it is written using Advanced Encryption Standard (AES) encryption with a randomly generated per-boot key to guarantee the privacy of the data in the cache if the device is removed from the system.

When ReadyBoost sees reads that can be satisfied from the cache, it services them from there. However, because hard disks have better sequential read access than flash memory, it lets reads that are part of sequential patterns go directly to the disk if the data is in the cache. Like-wise, when reading the cache, if I/Os must be done, the on-disk cache will be read instead.

One disadvantage of depending on flash memory is that the user can remove it at any time, which means the system can never solve critical data on the media. (As you've seen, always goes to the secondary storage first.) A related technology, ReadyDrive, covered in the next section, offers additional benefits and solves this problem.

# ReadyDrive

ReadyDrive is a Windows feature that takes advantage of hybrid hard disks (H-HDDs). An H-HDD is a disk embedded with NVRAM. Typical H-HDDs have between 50 MB and 512 MB of cache.

Under ReadyDrive, the drive's flash memory does not act as an automatic, transparent cache, as does the RAM cache common on most hard drives. Windows uses ATA-8 commands to define the disk data to be held in the flash memory. For example, Windows saves boot data to the cache when the system shuts down, allowing for faster restarting. It stores portions of hibernation file data in the cache when the system hibernates so the subsequent resume is faster. Because the cache is enabled even when the disk is spun down, Windows can use the flash memory as a disk-write cache, which avoids spinning up the disk when the system is running on battery. Keeping the disk spindle turned off can save much of the power consumed by the disk drive under normal usage.

Another consumer of ReadyDrive is SuperFetch. It offers the same advantages as ReadyBoost with enhanced functionality; such as not requiring an external flash device and having the ability to work persistently. Because the cache is on the actual hard drive, a user typically cannot remove while the computer is running, the hard drive controller doesn't have to worry about the data disappearing and can avoid making writes to the actual disk using the cache.
