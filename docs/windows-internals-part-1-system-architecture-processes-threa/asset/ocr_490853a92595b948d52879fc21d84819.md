In splitting functions across discrete files, two objectives are achieved. First, this allows applications to link only with the API libraries that provide the functionality they need. Second, if Microsoft were to create a version of Windows that did not support, localization (say, a non-user-facing, English-only embedded system), it would be possible to simply remove the sub-DLL and modify the API set schema.
