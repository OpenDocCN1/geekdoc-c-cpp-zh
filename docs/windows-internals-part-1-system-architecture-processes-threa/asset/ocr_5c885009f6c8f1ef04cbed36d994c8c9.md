# EXPERIMENT Querying system virtual address usage
(Windows 10 and Server 2016)

You can look at the current and peak usage of each system virtual address type using the kernel debugger. The global variable MivisState (of type MI_VISIBLE_STATE) provides information available in the public symbols. (The example is on x86 Windows 10.0)

+   1. To get a sense of the data provided by MivisState, dump the structure with:
```
1kd: dt ntl_mi_visible_state poi(nt!MivisState)

+0048 SessionWList : _LIST_ENTRY : 0x9136460 - 09a172060
+0050 SessionBitmap : 0x82ec03a0 _RT_BITMAP
+0054 PagedInfo : _MM_PAGED_POOL_INFO
+0070 MaximumNonPagedPoolInPages : 0x80000
+0074 SizePagedPoolInPages : 0x7fc00
+0078 SystemPteInfo : _MI_SYSTEM_PTE_TYPE
+0xb0 NonPagedPoolCommit : 0x3272
+00b4 BootCommit : 0x186d

+   2. Notice the arrays with 15 elements each, corresponding to the system virtual address types from Table 5-8. Here are the SystemVaTypeCount and SystemVaType-Count peaks:

```
1kd: dt ntl_mi_visible_state poi(nt!mivisibleistate) -a SystemVaTypeCount
