#  Monitoring pool usage

The memory performance counter has separate counters for the non-paged pool and paged pool (both virtual and physical). In addition, the Poolmon utility (in the DKI Tools directory) allows you to monitor the detailed usage of non-paged and paged pool. When you run Poolmon, you should see a display like the one shown in Figure 5-7.

![](bbox=[0.156, 0.413, 0.843, 0.647])

Any highlighted lines you see represent changes to the display. You can disable the highlighting feature by typing / or press any to re-enable highlighting. Type ? while Poolmon is running to bring up its help screen. You can configure pools you want to monitor (paged, non-paged, or both) and the sort order. For example, pressing the **P** key until only nonlocal allocations are shown, and then the **D** key to sort by the Diff (differences) column, you can find what kind of structures are most numerous in non-paged pool. Also, the command-line options shown, which allow you to monitor specific tags (or every tag but one). For example, poolmon -1CM will monitor only CM tags (allocations from the configuration manager, manages the registry). The columns have the meanings shown in Table 5-6.
