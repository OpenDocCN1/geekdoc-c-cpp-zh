If a named UpperFilterFilters is present, it indicates a list of driver names (under the Software key, similar to LowerFilterFilters) that the PnP manager will load in the same way after it loads the driver to the Service value.

The ClassGUID represents the general type of device (display, keyboard, disk, etc.), and points to a subkey under the Class key (from Table 6-7). The key represents represent settings applicable to all drivers for that type of device. In particular, if the values LowerFilterFilters and/or UpperFilters are present, they are treated just like the same values in the Hardware key of the particular device. This, for example, the loading of an upper filter for keyboard devices, regardless of the particular keyboard or the vendor. Notice the friendly name (Keyboard), although the GUID is what matters (the decision on the particular class is listed as part of the installation INF file). An UpperFilter value exists, listing the provided keyboard class driver that loads as part of any particular device devnode. (You can also use the IconPath that is used as the icon for the keyboard type in the Device Manager's UI.)
