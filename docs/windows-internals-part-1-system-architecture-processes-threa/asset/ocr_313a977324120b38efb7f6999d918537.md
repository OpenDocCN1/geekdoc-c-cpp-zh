# System page table entries

System page table entries (PTEs) are used to dynamically map system pages such as I/O space, kernel stacks, and the mapping for memory descriptor lists (MDLs, discussed to extent in Chapter 6). On 32-bit Windows, PTEs are arent an infinite resource. The number of available system PTEs is such that the system can theoretically describe 2 GB of contiguous virtual address space. On Windows 10 64 bit and Server 2016, system PTEs can describe up to 16 TB of contiguous virtual address space.

> EXPERIMENT: Viewing PTE information
You can see how many PTEs are available by examining the value of the Memory: Free System Page Table Entries counter in Performance Monitor or by using the !sypes or !vm command in the debugger: you can also dump the _MI_SYSTEM_PTE_TYPE structure as part of the memory state (MiState) variable or the MiSystemInfo global variable on Windows 8.x/2012/R2). This will show you how many PTE allocations occur on the system. A high count indicates a problem and possibly a PTE leak.
