# Symmetric multiprocessing

Multitasking is the OS technique for sharing a single processor among multiple threads of execution. When a computer has more than one processor, however, it can execute multiple threads simultaneously, whereas a multitasking OS only appears to execute multiple threads at the same time, a multiprocessing OS actually does it, executing one thread on each of its processors.

As mentioned at the beginning of this chapter, one of the key design goals for Windows was that it had to run well on multiprocessor computer systems. Windows is a symmetric multiprocessing (SMP) OS. as well as user threads can be scheduled to run on any processor. Also, all processors share just one memory space. This model contrasts with asymmetric multiprocessing (ASMP), in which the OS selects one processor to execute OS kernel code while other processors run only user code. Windows also supports four types of multiprocessor systems: multicore, simultaneous multi-threaded (SMT), heterogeneous, and non-uniform memory access (NUMA). (For a complete, detailed description of the scheduling support for these systems, see the section on thread scheduling in Chapter 4, "Threads.")

SMT was first introduced to Windows by adding support for Intel's Hyper-Threading Technology, which provides two logical processors for each physical core. Newer AMD processors under the Zen micro-architecture implement a similar SMT technology, doubling the logical processor count.
