To add a new page file, Control panel uses the internal NtCreatePagingFile system service defined in Ntdll.dll (This requires the CreatePageFilePrivilege). Page files are always created as noncompressed files, if they are created in them. Their names are PageFile.sys (except some special ones described in the next section). To keep page files from being deleted, a handle is duplicated into the System process so that even when the creating process closes the handle to the new page file, a handle is nevertheless open to it.

# The swap file

In the UWP apps world, when an app goes to the background—for example, it is minimized—the threads in that are suspended so that the process does not consume any CPU. The physical memory used by the process can potentially be reused for other processes. If memory pressure is high, the private working set (physical memory used by the process) may be swapped out to disk to allow the physical memory to be used for other processes.

Windows 8 added another page file called a swap file. It is essentially the same as a normal page file but is used only for UWP apps. It's created on SKUs only if at least one normal page file was created (the normal method). Its name is SwapFile.sys and it resides in the system root partition—for example, C:SwapFile.sys.
