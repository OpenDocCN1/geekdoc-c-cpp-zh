# TABLE 7-5 Security descriptor flags

| Flag | Meaning |
| --- | --- |
| SE_OWNER_DEFAULTED | This indicates a security descriptor with a default owner identifier (SID). Use this bit to find all the objects that have default owner permissions set. |
| SE_GROUP_DEFAULTED | This indicates a security descriptor with a default group SID. Use this bit to find all the objects that have default group permissions set. |
| SE_DACL_PRESENT | This indicates a security descriptor that has a DACL. If this flag is not set, or if this flag is the NULL, the security descriptor allows full access to everyone. |
| SE_DACL_DEFAULTED | This indicates a security descriptor with a default DACL. For example, if an object does not specify a DACL, the object receives the default DACL from the access token of the creator. This flag can affect how the system treats the DACL with respect to access control entry (ACE) inheritance. The system ignores this flag if the SE_DACL_PRESENT flag is not set. |
| SE_SAC_PRESENT | This indicates a security descriptor that has a system control list (SAC). |
| SE_SAC_DEFAULTED | This indicates a security descriptor with a default SAC. For example, if an object does not specify a SAC, the object receives the default SAC from the access token of the creator. This flag can affect how the system treats the SAC with respect to ACE inheritance. The system ignores this flag if the SE_SAC_PRESENT flag is not set. |
| SE_DACL_UNTRUSTED | This indicates that the DACL pointed to by the security descriptor was provided by an untrusted source. If this flag is set and a compound ACE is encountered, the system will validate valid SIDs for the server IDs in the ACEs. |
| SE_SERVER_SECURITY | This requests that for the object protected by the security server ACL on the input ACL, regardless of its source (explicit or default), is by replacing all the GRANT ACEs with compound ACEs granting the current server access. This flag is meaningful only if the object is impersonating. |
| SE_DACL_AUTO_INHERIT_REQ | This requests that for the object protected by the security descriptor automatically populate the DACL to existing objects. If the provider supports automatic inheritance, the DACL is propagated to existing child objects, and the SE_DACL_AUTO_INHERIT bit in the security descriptors of the parent object and child objects is set. |
| SE_SAC_AUTO_INHERIT_REQ | This requests that for the object protected by the security descriptor automatically propagate the SAC to existing child objects. If the provider supports automatic inheritance, the SAC is propagated to existing child objects, and the SE_SAC_AUTO_INHERIT bit in the security descriptors of the parent object and child objects is set. |
| SE_DACL_AUTO_INHERITED | This indicates a security descriptor in which the DACL is set up to support automatic propagation of inheritable ACEs to existing child objects. The system sets this bit when it performs the automatic inheritance algorithm for the object and its existing child objects. |
| SE_SAC_AUTO_INHERITED | This indicates a security descriptor in which the SAC is set up to support automatic propagation of inheritable ACEs to existing child objects. The system sets this bit when it performs the automatic inheritance algorithm for the object and its existing child objects. |
| SE_DACL_PROTECTED | This prevents the DACL of a security descriptor from being modified by inheritable ACEs. |
| SE_SAC_PROTECTED | This prevents the SAC of a security descriptor from being modified by inheritable ACEs. |
