> Note Windows 8 and Server 2012 are limited to 16 TB of address space. This is because of Windows implementation limits, described in Chapter 10 of the sixth edition of Windows Internals Part 2. These, 8 TB is per process and the other 8 TB is used for system space.

Thirty-bit images with large address space receive an extra benefit while running on 64-bit Windows (under WoW64). Such an image will actually receive all 4 GB of user address space available. After all, if the image can support 3 GB pointers, 4 GB pointers should not be different, because unless the switch from 2 GB to 3 GB, there are no additional bits involved.
