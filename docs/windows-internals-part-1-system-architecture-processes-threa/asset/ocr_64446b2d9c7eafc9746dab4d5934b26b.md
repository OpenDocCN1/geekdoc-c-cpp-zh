The data structures maintained by the memory manager that describes mapped sections are shown in Figure 5-32. These structures ensure that data from mapped files is consistent regardless of the type of access (open file, mapped file, and so on). For each open file (represented by a file object), there is a single section object pointers structure. This structure is the key to maintaining consistency for all types of access as well as to providing caches. The section object pointers structure points to one or two control areas. One control area is used to map the file when it is accessed as a data file and the other is used to map the file when it is run as an executable file. A control area in turn points to section structures that describe the mapping information for each section of the file (read-only, read/write, and so on). The control area also points to a segment structure allocated in page pool, which in turn points to the prototype PTEs used to map to the actual pages mapped by the section object.
