# TABLE 3-8 Decision tree for stage 1 of CreateProcess

| If the Image... | Create State Code | This Image Will Run... | ...and This Will Happen |
|---|---|---|---|---|
| Is an MS-DOS application with an .exe, .com or .pif extension | PsCreateFailOnSectionCreate | Ntvdm.exe | CreateProcessInternal restarts stage 1. |
| Is a Win16 application | PsCreateFailOnSectionCreate | Ntvdm.exe | CreateProcessInternal restarts stage 1. |
| Is a Win64 application on a 32-bit system (or a PPC, MIPS, or Alpha binary) | PsCreateFailMismatch | N/A | CreateProcessInternal will fail. |
| Has a Debugger value with another name | PsCreateFailName | Name specified in the Debug value | CreateProcessInternal restarts stage 1. |
| Is an invalid or damaged Windows extension | PsCreateFailExeFormat | N/A | CreateProcessInternal will fail. |
| Cannot be opened | PsCreateFailOnFileOpen | N/A | CreateProcessInternal will fail. |
| Is a command procedure with a .bat or .cmd extension | PsCreateFailOnSectionCreate | Cmd.exe | CreateProcessInternal restarts stage 1. |

Specifically, the decision tree that CreateProcessInternal goes through an image as follows:

+   - If it's x86 32-bit Windows, and the image is an MS-DOS application with an .exe, .com or .pif extension, a message is sent to the Windows subsystem to check whether an MS-DOS support port (Ntvdm.exe, specified in the HKLM\SYSTEM\CurrentControlSet\Control\WOW\registry value) has already been created for this session. If a support process has been created, it is used to run the virtual DOS machine (VDM) process to run the new image). Then CreateProcessInternal restarts. If a support process hasn't been created, the image to be run as Ntvdm.exe and CreateProcessInternal restarts.
- If the file runs a .bat or .cmd extension, the image to run becomes Cmd.exe, the Windows command prompt, and CreateProcessInternal restarts at stage 1. (The name of the batch file is passed as the second parameter to Cmd.exe after the / switch).
- For an x86 Windows system, if the image is a Win16 (Windows 3.1) executable, CreateProcessInternal must decide whether a new VDM process must be created to run or whether it should use the default session-wide VDM process (which might not have been created). The CreateProcess flags CREATE_SEPARATE_wOW_VDM, and CREATE_SHARED_wOW_VDM control this decision.
