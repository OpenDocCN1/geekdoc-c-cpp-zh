The CSR_THREAD, illustrated in Figure 4-4 is analogous to the data structure of CSR_PROCESS, but it's applied to. As you might recall, this is maintained by each Csrs process within a session and identifies the Windows subsystem threads running within. CSR_THREAD stores a class keeps for the thread, various flags, the client ID (thread ID and process ID), and a copy of the thread's creation time. Note that threads are registered with Csrs when they send their first message to Csrs, typically by using some API that notifying Csrs of some operation or condition.
