# KMDF object model

The KMDF object model is object-based

Also unlike the implementation of kernel objects, which all refer to and isolated objects, KMDF objects are all part of a hierarchy—most objects are bound to a parent. The root object is the WDFDRIVER object, which describes the actual driver. The structure and meaning is analogous to the DRIVER_OBJECT structure provided by the I/O manager, and all KMDF structures are children of it. The next most important object is WDFDEVICE, which refers to a given instance of a detected device on the system, which must have been created with WdfDeviceCreate. Again, this is analogue to the DEVICE_OBJECT structure that’s used in the WDM model and by the I/O manager.
