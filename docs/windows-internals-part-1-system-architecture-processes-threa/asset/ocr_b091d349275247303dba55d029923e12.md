Several fields are for several PFN types, but others are specific to a given type of PFN. The following fields appear in more than one PFN type:

+   * **Address** This is the virtual address of the PTE that points to the page. Also, since PTE addresses will always be aligned on a 4-byte boundary (8 bytes by 64-bit systems), the lower-order bits are used as a locking mechanism to serialize access to the PFN entry.
* **Reference count** This is the number of references to this page. The reference count is increased when a page is added to a working set and/or when the page is locked in memory for I/O (for a device driver). The reference count is decremented when the share count becomes 0 or when pages are unlocked from memory. When the share count becomes 0, the page is no longer owned by a working set. Then, if the reference count is zero, the PFN database entry that describes the page is updated to add to the page, standby, or modified.
* **Type** This is the type of page represented by this PFN. (Types include active/valid, standby, modified-no-write, free, zeroed, bad, and transition).
* **Flags** The information contained in flags is shown in Table 5–20.
* **Priority** This is the priority associated with this PFN, which will determine on standby list it will be placed.
