# TABLE 7-11 Privileges (continued)

| Privilege | User Right | Privilege Usage |
|---|---|---|
| SeBackupPrivilege | Back up files and directories | Causes NTFS to grant the access to any file or directory, regardless of the security descriptor that's present: READ_CONTROL, ACCESS_SYSTEM_SECURITY, FILE_GENERIC_READ, and FILE_TRAVERSE. Note that when performing a backup, the caller must specify the FILE_FLAG_BACKUP_SEMANTICS flag. Also allows access to registry keys when using RegSavekey. |
| SeChangeNotifyPrivilege | Bypass traverse checking | Used by NTFS to allow permissions on intermediate directories of a multiprocessed directory lookup. Also by by file system for notification of changes to the file system. |
| SeCreateGlobalPrivilege | Create global objects | Required for a process to create section and symbolic objects in the directories of the object manager that are assigned to a different session than the caller. |
| SeCreatePagefilePrivilege | Create a pagefile | Checked by NtCreateFile, which is the function used to create a new pagefile |
| SeCreatePermanentPrivilege | Create permanent shared objects | Checked by object when creating a permanent object (one that doesn't get deallocated when there are no references to it). |
| SeCreateSymbolicLinkPrivilege | Create symbolic links | Checked by NTFS when creating symbolic links on the file system with the CreateSymbolicLink API. |
| SeCreateTokenPrivilege | Create a token object | NtCreateToken, the function that creates token object, checks for this privilege |
| SeDebugPrivilege | Debug programs | If the caller has this privilege, the manager allows access to process or thread using OpenProcess or OpenThread, regardless of the process or thread security descriptor (except for protected processes). |
| SeEnableDelegationPrivilege | Enable computer and user accounts to be trusted for delegation | Used by Active Directory services to delegate authenticated credentials. |
| SeImpersonatePrivilege | Impersonate a client after authentication | The process manager checks for when this thread wants to use impersonation and the token represents a different user than that of the thread's process. |
| SeIncreaseBasePriorityPrivilege | Increase scheduling priority | Checked for this process and is required to raise the priority of a process. |
| SeIncreaseQuotaPrivilege | Adjust memory quotas for a process | Enforced when changing a process's working set thresholds, a process paged and nonlocal quotas, and a process CPU quota. |
| SeIncreaseWorkingSetPrivilege | Increase a process working set | Required to call SetWorkingSetSize to increase the minimum working set. This indirectly allows the process to lock up to the minimum working set of memory using Virtual Lock. |
