# Priority boosts for CPU starvation

Imagine the following situation: A priority 7 thread is running, preventing a priority 4 thread from receiving CPU time. However, a priority 11 thread is waiting for some resource that the priority 4 thread has locked. Because the priority 7 thread in the middle is eating up all the CPU time, the priority 4 will never run long enough to finish whatever it's doing and release the resource blocking the priority 11 thread. This scenario is known as priority inversion.
