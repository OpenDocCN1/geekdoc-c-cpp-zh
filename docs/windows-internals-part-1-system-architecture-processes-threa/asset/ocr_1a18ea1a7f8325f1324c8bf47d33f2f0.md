# EXPERIMENT: Using pageheap

In this experiment, you'll turn on pageheap for Notepad.exe and see its effects.

+   1. Run Notepad.exe.
2. Open Task Manager, click to the Details tab, and add the Commit Size column to the display.
3. Notice the commit size of the notepad instance you just launched.
4. Run Gflags.exe, located in the folder where Debugging Tools for Windows is installed (requires elevation).
5. Click the Image File tab, type notepad.exe. Then press the Tab key. The various check boxes should be selected.
6. Select the Enable Page Heap check box. The dialog box should look like this:

![](bbox=[0.19852, 0.41335, 0.61345, 0.7463500000000001])

+   8. Click Apply.
9. Run another instance of Notepad. (Don't close the first one).
10. In Task Manager, compare the commit size of both notepad instances. Notice that the second instance has a much larger commit size though both are empty notepad processes. This is due to the extra allocations that pageheap provides. Here's a screen- from 32-bit Windows 10:
