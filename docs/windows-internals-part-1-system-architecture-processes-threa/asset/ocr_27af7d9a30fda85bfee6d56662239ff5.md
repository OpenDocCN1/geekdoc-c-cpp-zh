| Field | Offset (bytes) | Size (bytes) | Description |
| --- | --- | --- | --- |
| SIZE | 0 | 8 | Size of enclave in bytes; must be power of 2 |
| BASEADR | 8 | 8 | Enclave base address must be naturally aligned to size |
| SSFRAMISE | 16 | 4 | Size of one SSA frame in bytes (including XSAVE, pad, GPR, and MISC) |

| ISVSN | 258 | 2 | Enclave identifier |

The first thing MiCreateEnclave allocates the Address Window Extension (AWE) information that A APIs also utilize. This is because of AWE functionality, an enclave allows user-mode application to directly access physical pages (that is, the physical pages that are EPC pages based on the detection described). Anytime a user-mode application has direct control over physical pages, AWE data structures and locks must be used. This data is stored in the AweInfo field of the EPROCESS structure.

Next, MiCreateEnclave calls MiAllocateEnclaveVAD to allocate an enclave-type VAD describing the virtual memory. This VAD has the VAD flag (as all VADs) but also an enclave flag, to differentiate it from a true VAD. Finally, as part of VAD allocation, this is where the user-mode address for enclave memory is (if not explicitly specified in the original CreateEnclave call).

The next step in MiCreateEnclave is to acquire an enclave page regarding the enclave size or initial commitment. This is because, by Intel's SGX documentation, all enclaves require at least a one-page control structure to be associated with them. MiGetEnclavePage is used to obtain the required allocation list described, and extracts one page as needed. The returned page is mapped using a system PTE stored as part of the enclave VAD; the MiInitializeEnclave function returns the related PFN data structure and marks it ActiveAndValid.

There are no actual bits that would help you differentiate enclave PFN from any other region of memory (such as non-paged pool). This is where the enclave AVL tree comes into play, and MI_PFN_IS_ENCLAVE is a function that the kernel uses whenever it needs to check if a PFN is indeed describing an EPC region.
