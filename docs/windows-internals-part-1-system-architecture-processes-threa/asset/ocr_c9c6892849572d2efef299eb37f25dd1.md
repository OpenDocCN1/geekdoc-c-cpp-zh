13. If a job list was supplied (using an attribute) and this is the first thread in the process, then the process is assigned to all of jobs in the job list.

14. The thread is ready for execution by calling KeReadyThread. It enters the deferred ready state. (See Chapter 4 for more information on thread states.)

# Stage 5: Performing Windows subsystem–specific initialization

Once CreateUserProcess returns with a success code, the necessary executive process and thread objects have been created. CreateProcessInternal performs various operations related to Windows subsystem–specific operations to finish initializing the process.

+   - checks are made for whether Windows allow the executable to run. These checks include validating the image version in the header and checking whether Windows certification has blocked the process (through a group policy). On specialized editions of Windows Server 2012 R2, as Windows Storage Server 2012 R2, additional checks are made to see whether the application imports any disallowed APIs.

+   - If restriction policies apply, a restricted token is created for the new process. Afterward, the application-compatibility database is queried to see whether an entry exists in the registry or system application database for the process. Compatibility shims will not be applied at this point; the information will be stored in the PEB the initial thread starts executing (stage 6).

+   - CreateProcessInternal calls some internal functions (for non-protected processes) to get SxS information (see the section "DLL name resolution and redirection" in this chapter for more information on side-by-side) such as manifest files and DLL redirection paths, as well as other information such as whether the media on the EXE resides is removable and installer flags. For immersive processes, it also returns version information and target platform from the package manifest.

A message to the Windows subsystem is constructed based on the information collected to be sent to Csrss. The message includes the following information:

+   - Path name and SxS path name
- Process and thread handles
- Section handle
- The access token handle
- Media information
- AppCompat and shim data
- Immersive process information
- The PEB address
- Various flags as whether it's a protected process or whether it is required to run elevated
