# 1. Launch IoPriority.exe.

2. In the dialog box, under Thread 1, check the Low Priority check box.

3. Click the Start I/O button. You should notice a significant difference in speed between
two threads, as shown in the following screenshot:

![](bbox=[0.212, 0.187, 0.526, 0.273])

> Note If both threads run at low priority and the system is relatively idle, their
throughput will be roughly equal to the throughput of a single normal I/O priority
in this example. This is because low-priority I/Os are not artificially throttled or
or otherwise hidden if there isn't any competition from higher-priority I/O.

4. Open the process in Process Explorer and look at the low I/O priority thread to see
triorities:

![](bbox=[0.212, 0.477, 0.526, 0.785])

5. You can also use Process Monitor to track IO Priority reads from I/Os and look at your I/O priority\hint. To do so, launch Process Monitor, configure a filter for IoPriority.exe, and repeat the
experiment. In this application, each thread reads from a file name _File_concatenated
with the thread ID.
