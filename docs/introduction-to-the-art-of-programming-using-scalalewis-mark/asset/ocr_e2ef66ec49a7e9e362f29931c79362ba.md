# Call Stack

![](bbox=[0.2, 0.2, 0.8, 0.73])

**FIGURE 15.1:** This shows the call stack for the function count which prints the numbers counting up. When you call the function with 5, it calls itself with 4 before doing anything else. This calls itself with 3 and so on down to 0. The call with 0 does nothing but return. It returns back into the call to count(1) that does the print and continues on back up the stack.
