13. The Mandelbrot set is a famous fractal in the complex plane discovered by Benoit Mandelbrot. A web search will provide you with lots of information on this beautiful structure. Part of what is so remarkably about the Mandelbrot set is that it has such a simple definition, but contains infinite complexities. The set is defined as the points, \textit{c}, in the complex plane for which the equation \( z_{n+1} = z_n^2 + c \), where \( z_0 = 0 \), gives a bounded sequence.

In practice, if the value of \(|z|\) ever goes beyond 4, the sequence will diverge. So programs to explore the Mandelbrot set count the number of iterations to reach that point and assign a color based on how many iterations it takes. Because the points in the set itself will never diverge, there has to be some maximum number of iterations at which point you simply say it is in the set.

For this project you will write a GUI program that displays the Mandelbrot set. You have a view on the set with minimum and maximum values in the real and complex axes. Allow the user to zoom in by clicking.
