If you have a function that tells you what color to draw for a particular ray, you can do reflection by recursively calling that function with the reflected ray and combining that color with the color of the reflecting surface. How much of each goes into the color depends on the fractional reflectivity of the object.
+   
+   For this project you will give your objects colors, but you still will not worry about lighting. So when a ray hits an object, it gets the full color of that object unless the object is reflective. If it has reflectivity $R$ then it gets $(1-R)$ of the color of that object and $R$ of the color from the reflected ray. To add colors you need to be able to build your own colors and get the components out of colors. The `java.awt.Color` class has methods called `getRed`, `getGreen`, and `getBlue` that return the amount of each primary in a color. The values are `Ints` in the range of 0-255 inclusive. You can also make a new `Color` object by calling `new Color(red: Int, green: Int, blue: Int)`. The values passed in must be in the same range or you'll get an error.
+   
+   To calculate reflection, you need the unit-normal vector for the surface you are reflecting off of. For a plane this is easy as the normal is the same everywhere. For a sphere, this is the vector from the center to the point of intersection. In both cases, you want it normalized. If you have that, the direction of the reflected ray is given by

```
$\vec{r}_{reflected} = \vec{r} - 2(\vec{r} \cdot \vec{n}) \vec{n}$,
```

where $\vec{r}$ is the direction of the incoming ray and $\vec{n}$ is the unit normal. The unit normal will also be significant for calculating lighting in a later project.
