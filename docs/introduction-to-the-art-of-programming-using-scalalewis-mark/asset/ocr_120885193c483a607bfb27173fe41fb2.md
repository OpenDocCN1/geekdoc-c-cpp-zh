# 32.3 Heapsort

Any priority queue implementation can be turned into a sort. Simply add all the elements to the queue and remove them. They will come off in sorted order. Insertion sort is roughly what you get if you do this with a sorted array or linked list. The priority queue described in the above aside gives something like a bucket sort.
