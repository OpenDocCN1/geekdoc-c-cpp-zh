## 目标与范围

本系列涵盖计算的传统领域，以及相关的技术领域，如软件工程、人工智能、计算机工程、信息系统和信息技术。该系列将收录面向本科生和研究生的教材，通常遵循专业学会制定的全球课程标准。编辑希望鼓励新颖而富有想象力的想法和提案，并热衷于帮助和鼓励新作者。编辑欢迎以下提案：对计算各方面提供开创性和富有想象力的视角；在新的令人兴奋的背景下呈现主题；为新兴领域如多媒体、安全和移动系统提供机会；捕捉计算新兴领域的最新发展和应用；以及涉及为计算提供支持的主题，如数学、统计学、生命科学和物理科学以及商业。
