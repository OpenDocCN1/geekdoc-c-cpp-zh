- After software is released, the continued work on it for enhancements and further bug fixes is called **maintenance**.

- **UML** stands for Unified Modeling Language and it is a standard for a number of diagram types that are used for the software development process. This chapter introduced two of them.

- The **Use-Case Diagram** is a style of diagram used during analysis to help consider the ways in which users and other outside entities interact with the software.

- A **Class Diagram** is a diagram that shows a rough sketch of major code groupings like `classes`, `objects`, and `traits` as well as relationships between them.

- This chapter also introduced a project that will be used through the rest of the book. It also begins the analysis and design of that project.
