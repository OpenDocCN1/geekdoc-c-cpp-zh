另一个需要注意的事情是不要过度使用多线程。为每个线程创建许多线程而每个线程的工作量很小只会减慢程序速度。创建太多线程甚至可能消耗足够的资源使机器瘫痪。使用 Actor.actor 等东西很容易创建线程，但在你使用它时需要考虑自己在做什么。过度使用线程还可能导致极难调试的竞态条件。适当使用 java.util.concurrent 中的线程安全集合可以极大地帮助解决这个问题。
