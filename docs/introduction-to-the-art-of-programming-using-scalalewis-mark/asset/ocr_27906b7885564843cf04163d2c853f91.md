Every point in the Mandelbrot corresponds to one of these Julia sets. The equation for a quadratic polynomial looks much like that for the Mandelbrot set, z_{n+1} = z_n^2 + c with c being a fixed value and z_0 being the point in the plane you are calculating for. By contrast, the Mandelbrot set used a different c value for each point and z_0 = 0 so z_1 = c.
