At this point, our textures are completely set up, and we're ready to launch our kernel. However, when we're reading from textures in the kernel, we need to use special functions to instruct the GPU to route our requests through the texture unit and not through standard global memory. As a result, we can no longer simply use square brackets to read from buffers; we need to modify blend_kernel () to use tex1Dfetch () when reading from memory.

Additionally, there is another difference between using global and texture memory that requires us to make another change. Although it looks like a function, tex1Dfetch () is a compiler intrinsic. And since texture references must be declared globally at file scope, we can no longer pass the input and output buffers as parameters to blend_kernel () because the compiler needs to know at compile time which textures tex1Dfetch () should be sampling.
