What do we mean by identification? It is when we say that two semantically unique items are the same as each other in all respects. This is done via the verb is. We cite here five examples:

- (a). He is an idiot.
- (b). She is a bitch.
- (c). This Honda is this BMW.
- (d). This carbonara is this pasta.
- (e). This Parisian holiday is this Cuban holiday.
