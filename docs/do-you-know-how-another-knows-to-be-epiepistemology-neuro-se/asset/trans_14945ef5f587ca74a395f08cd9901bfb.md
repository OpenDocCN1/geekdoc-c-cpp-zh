生活中关系中的所有项目都因元素之间的动词而相连。因此，所有关系都是通过其动词而形成的共轭关系。我们同意 HM 和 FV 的观点，即，如果且当关系被良好地共轭时，它将是一个良好形成的关系。正式地，一个共轭关系可以这样表达：

```
y = f(x).
```

上述方程用英文句子表达为：

Y 是 X 的函数。

然而，在形式逻辑中，共轭关系也被称为：

*肯定前件*。

什么是肯定前件？它是这样一种关系：“如果 A 为真，则 B 为真。这些可能的句子变体示例有：

- 当 x，则 y。
- 如 x，则 y。
- 无论 x，则 y。

- 当你努力学习，那么你可能会获得高分。
