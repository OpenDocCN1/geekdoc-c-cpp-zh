| Differentiation Mode | Semiring Type | Time Complexity |
|---|---|---|
| Symbolic | (Expr v) ⋈ (Expr v) | O(N^2) |
| Forward Mode | d ⋈ (Dense v d) | O(N x V) |
| Forward Mode | d ⋈ (Sparse v d) | O(N x V) |
| Reverse Mode | d ⋈ (d -> Sparse v d) | O(N x V) |
| Reverse Mode | d ⋈ (d -> Cayley (Sparse v d)) | O(N x log V) |
| Reverse Mode | d ⋈ (d -> STCayley v d) | O(N x V) |

Fig. 5. The successive refinements of the semiring type, with their corresponding differentiation modes and time complexity, for an expression of N nodes in V variables.

```
autodiff :: (Ord v, Semiring d) => (v -> d) -> Expr v -> Map v d
autodiff var e = snd (go var e) one zero where
  go :: (Ord v, Semiring d)
  => (v -> d) -> Expr v -> (d, d -> Map v d -> Map v d)
  go var (Var v) = (var v, \d -> \m -> insertWith (⊕) v d m)
  go var Zero = (zero, \d -> \m -> m)
  go var One = (one, \d -> \m -> m)
  go var (Plus e1 e2) = let (f, df) = go var e1
                        (g, dg) = go var e2
                        in (f ⊕ g, \d -> \m -> df d (dg d m))
  go var (Times e1 e2) = let (f, df) = go var e1
                         (g, dg) = go var e2
                         in (f ⊗ g, \d -> \m -> df (d ⊗ g) (dg (d ⊗ f) m))
```

Fig. 6. Fully inlined AD code based on the d ⋈ (d -> Cayley (Sparse v d)) semiring.

Finally, we get the resulting monadic definition for reverse-mode AD.

```
reverseADm :: ((x v, Semiring d)
=> (v -> d) -> Expr v -> d ⋈ (d -> STCayley v d)
reverseADm = abstractD
```

We use this efficient version of reverse-mode AD on example₂ as follows:

```
> (abs_ ⊙ abs_ ⊙ ... ⊙ tan^n) (reverseADm (x -> 5) example₂)
(x -> 170)
```
