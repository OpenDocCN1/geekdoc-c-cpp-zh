By now you can probably guess how we are going to print a multiplication table: we'll call `printMultiples` repeatedly with different arguments. In fact, we are going to use another loop to iterate through the rows.

```
int i = 1;
while (i <= 6) {
    printMultiples(i);
    i = i + 1;
}
```

First of all, notice how similar this loop is to the one inside `printMultiples`. All I replaced the print statement with a function call. The output of this program is

| 1 2 3 4 5 6 |
| 2 4 6 8 10 12 |
| 3 6 9 12 15 18 |
| 4 8 12 16 20 24 |
| 5 10 15 20 25 30 |
| 6 12 18 24 30 36 |

which is a (slightly sloppy) multiplication table. If the sloppiness bothers you, replacing the spaces between columns with tab characters and see what you get.
