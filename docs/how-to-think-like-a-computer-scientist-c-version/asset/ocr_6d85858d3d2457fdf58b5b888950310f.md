endl is a special symbol that represents the end of a line. When you send an endl to cout, it causes the cursor to move to the next line of the display. The next time you output something, the new text appears on the next line. 

Like all statements, the output statement ends with a semi-colon (;). There are a few things you should notice about the syntax of this programming. First, C++ uses squiggly-braces { } to group things together. In this case, the output statement is enclosed in squiggly-braces, indicating that it is inside the definition of main. Also, notice that the statement is indented, which helps to show visually which lines are inside the definition.

At this point you would now sit down in front of a computer and compile and run this program. The details of how to do that depend on your programming environment, but from now on in this book I will assume that you know how to do it. As mentioned, the C++ compiler is a real stickler for syntax. If you make any errors when you type in the program, chances are that it will not compile successfully. For example, if you miss iostream, you might get an error message like:

```
hello.cpp: iostream: No such file or directory
```

There is a lot of information on this line, but it is presented in a dense format that is not easy to interpret. A friendly compiler might say anything like:

> Line 1 of the source code file named hello.cpp, you tried to include a header file named iostream.h. I didn't find anything with that name, but I did find something named iostream.h. Is that what you meant, by any chance?

Unfortunately, few compilers are so accommodating. The compiler is not really smart, and in most cases the error message you get is only a hint about what is wrong. It will take some time to gain familiarity in interpreting compiler messages.

Nevertheless, the compiler can be a useful tool for learning the syntax rules of a language. Starting with a working program (like hello.cpp), modify it in various ways and see what happens. If you get an error message, try to remember what the message says and what caused it, if you see it again in the future you will know what it means.
