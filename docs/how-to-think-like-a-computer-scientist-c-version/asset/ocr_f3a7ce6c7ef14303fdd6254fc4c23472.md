we have written a prototype, we are in a good position to evaluate the design
and improve it.
What are some of the problems with the existing code?

+   1. We did not know ahead of time how to make the distance matrix, so
we chose an arbitrary number (50) and made it a fixed size. It would
better to allow the distance matrix to expand in the same way as a Set
does. The ammatrix class has a function called resize that makes this
possible.
