The first line initializes the elements of the histogram to zeroes. That way, when we use the increment operator (++) inside the loop, we know we are starting from zero. Forgetting to initialize counters is a common error.

# 10.12 Random seeds

If you run the code in this chapter a few times, you might have noticed that you are getting the "random" values every time. That's not very random!

One of the properties of pseudandom number generators is that if they start from the same place they will generate the same sequence of values. The starting place is called a seed; by default, C++ uses the same seed every time you run the program.

While you are debugging, it is often helpful to see the same sequence over and over. That way, when you make a change to the program you can compare the output before and after the change.

If you want to choose a different seed for the random number generator, you can use the srand function. It takes a single argument, which is an integer between 0 and RAND_MAX.

For applications, like games, you want to see a different random sequence every time the program runs. A common way to do that is to use a library function like getofday to generate something reasonably unpredictable and unpredictable, like the number of milliseconds since the last tick, and use that number as a seed. The details of how to do that depend on your development environment.

# 10.13 Glossary

**vector:** A named collection of values, where all the values have the same type, and each value is identified by an index.

**element:** One of the values in a vector. The [] operator selects elements of a vector.

**index:** An integer value or value to indicate an element of a vector.
