### 15.1 Streams

To get input from a file or output to a file, you have to create an ifstream object (for input files) or an ofstream object (for output files). These objects are defined in the header file fstream.h which you have to include.
A stream is an abstract object that represents the flow of data from a source like the keyboard or a file to a destination like the screen or a file.

We have already worked with two streams: cin, which has type ist, cout, which has type ofstream. cin represents the flow of data from the keyboard to the program. Each time the program uses the >> operator or the getline function, it removes a piece of data from the input stream.
Similarly, the program uses the << operator on an ostream, it adds a datum to the outgoing stream.

### 15.2 File input

To get data from a file, we have to create a stream that flows from the file into the program. We can do that using the ifstream constructor.

```cpp
ifstream infile ("file-name");
```

The argument for this constructor is a string that contains the name of the file you want to open. The result is an object named infile that supports all the operations as cin, including >> and getline.

```cpp
int x;
apstring line;

infile >> x;           // get a single integer and store in x
getline(infile, line); // get a whole line and store in line
```

If we know how much data is in a file, it is straightforward to write a loop that reads the file and then stops. More often, we want to read the entire file, but don't know how big it is.
There are member functions for ifstream that check the status of the input stream; they are called good, eof, fail and bad. We will use good to make sure the file was opened successfully and eof to detect the "end of file.". Whenever you get data from an input stream, you don't know whether the attempt succeeded until you check. If the return value of eof is true we have reached the end of the file and we know that the last attempt failed. Here is a program that reads lines from a file and displays them on the screen:

```cpp
apstring filename = "...";
ifstream infile(filename.c_str());

if (infile.good() == false) {
    cout << "Unable to open the file named " << filename << endl;
    exit(1);
}
```

```cpp
while (true) {
    getline(infile, line);
    if (infile.eof()) break;
```

The function c_str() converts an apstring to a native C string. Because the ifstream constructor accepts a C string as an argument, we have to convert the apstring.

Immediately after opening the file, we invoke the good function. The return value is false if the system could not open the file, most likely because it does not exist, or if you do not have permission to read it.

The statement while(true) is an idiom for an infinite loop. Usually there will be a break statement in the loop so that the program does not run forever (although some programs do). In this case, the break statement allows us to exit the loop as soon as we detect the end of file.

It is important to exit the loop between the input statement and the output statement, so when getline fails at the end of the file, we do not output the invalid data in line.

### 15.3 File input

Sending output to a file is similar. For example, we could modify the program to copy lines from one file to another.

```cpp
ifstream infile("input-file");
ofstream outfile("output-file");
```

```cpp
if (infile.good() == false || outfile.good() == false) {
    cout << "Unable to open one of the files." << endl;
    exit(1);
}
```

```cpp
while (true) {
    getline(infile, line);
    if (infile.eof()) break;
    outfile << line << endl;
}
```
