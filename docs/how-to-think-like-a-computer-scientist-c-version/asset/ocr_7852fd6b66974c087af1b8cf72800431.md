Furthermore, in mathematics, a statement of equality is true for all time. $a = b$ now, then $a$ will always equal $b$. In C++, an assignment statement can make two variables equal, but they don't have to stay that way!

```
int a = 5;
int b = a;      // a and b are now equal
a = 3;           // a and b are no longer equal
```

The third line changes the value of a bit it does not change the value of b, and so they are no longer equal. In many programming an alternate symbol is used for assignment, such as <- or :=, to avoid confusion. Although assignment is frequently useful, you should use it with caution. If variables are changing constantly in different parts of the program, it can make the code difficult to read and debug.

# 6.3 The while statement

Using a while statement, we can rewrite countdown:

```
void countdown(int n) {
    while (n > 0) {
        cout << n << endl;
        n = n-1;
    }
    cout << "Blastoff!" << endl;
}
```

You can almost read a while statement as if it were English. What this means is, "n is greater than zero, continue displaying the value of n and then reducing the value of n by 1. When you get to zero, output the word 'Blastoff!'
