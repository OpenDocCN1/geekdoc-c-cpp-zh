By searching for the quotation marks in a line of input, we can find
 beginning and end of each city name. Searching for special characters like
potation marks can be a bit awkward, though, because the quotation mark
is a special character in C++, to identify string values.

If we want to find the first appearance of a quotation mark, we have to write
some like this:

```
int index = line.find(\'");
```

The argument here looks like a mess, but it represents a single character, a
double quotation mark. The outermost single-quotes indicates that this is a
value, as usual. The backslash (\) indicates that we want to treat
t character literally. The sequence \\' represents a quotation mark; the
\' represents a single-quote. Interestingly, the sequence \ represents
a single backslash. The first backslash indicates that we should take the second
backslash seriously.
