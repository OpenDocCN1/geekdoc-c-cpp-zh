
low-level language: A programming language that is designed to be easy for a computer to execute. Also called “machine language” or “assembly language."

portability: A property of a program that can run on more than one kind of computer.

formal language: Any of the languages people have designed for specific purposes, like representing mathematical ideas or computer programs. All programming languages are formal languages.

natural language: Any of the languages people speak that have evolved naturally.

interpret: To execute a program in a high-level language by translating it one line at a time.

compile: To translate a program in a high-level language into a low-level language, all at once, in preparation for later execution.

object code: The output of the compiler, after translating the program.

executable: Another name for object code that is ready to be executed.

bug: An error in a program.

## 2.1 More output

As I mentioned in the last chapter, you can put as many statements as you want in main. For example, to output more than one line:

```cpp
#include <iostream.h>
```

```cpp
// main: generate some simple output

void main ()
{
    cout << "Hello, world." << endl; // output one line
    cout << "How are you?" << endl; // output another
}
```

As you can see, it is legal to put comments at the end of a line, as well as a line by themselves.

The phrases that appear in quotation marks are called strings, because they are made up of a sequence (string) of letters. Actually, strings can contain any combination of letters, numbers, punctuation marks, and other special characters.

It is often useful to display the output from multiple output statements all on one line. You can do this by leaving the first endl:

```cpp
void main ()
{
    cout << "Goodbye, " << endl;
    cout << "cruel world!" << endl;
}
```

In this case the output appears on a single line as Goodbye, cruel world! Notice that there is a space between the word "Goodbye," and the second quotation mark. This space appears in the output, so it affects the behavior of the program. Spaces that appear outside of quotation marks generally do not affect the behavior of the program. For example, I could have written:

```cpp
void main ()
{
    cout<<"Goodbye, ";
    cout<<"cruel world!"<<endl;
}
```

This program would compile and run just as well as the original. The breaks at the ends of lines (newlines) do not affect the program's behavior, so I could have written:

```cpp
void main(){cout<<"Goodbye, ";cout<<"cruel world!"<<endl;}
```

That would work, too, although you have probably noticed that the program is getting harder and harder to read. Newlines and spaces are useful for organizing your program visually, making it easier to read the program and locate syntax errors.

## 2.2 Values

A value is one of the fundamental things—like a letter or a number—that a program manipulates. The only values we have manipulated so far are the string values we have been outputting, like "Hello, world." You identify string values are enclosed in quotation marks.

There are other kinds of values, including integers and characters. An integer is a whole number like 1 or 17. You can output integer values the same way you output strings:

```cpp
cout << 17 << endl;
```

A character is a letter or digit or punctuation mark enclosed in single quotes, 'a' or '5'. You can output character values the same way you:

```cpp
cout << 'a' << endl;
```

This example outputs a single squiggly-brace on a line by.

It is easy to confuse different types of values, like "5", '5' and if you pay attention to the punctuation, it should be clear that the first is a string, the second is a character and the third is an integer. The reason this distinction should become clear soon.

## 2.3 Variables

One of the most powerful features of a programming language is the ability to manipulate **variables**. A variable is a named location that stores a value.

Just as there are different types of values (integer, character, etc.), there are different types of variables. When you create a new variable, you have to declare what type it is. For example, the character type in C++ is called **char**. The following statement creates a new variable named **fred** that has type char.

```cpp
char fred;
```

This kind of statement is called **declaration**.

The type of a variable determines what kind of values it can store. A **char** variable can contain characters, and so no surprise that **int** variables can store integers.

There are several types in C++ that can store string values, but we are going to skip that for now (Chapter 7).

To create an integer variable:

```cpp
int bob;
```

where bob is the arbitrary name you made up for the variable. In general, you will want to make variable names that indicate what you plan to do with the variable. For example, if you saw these variable declarations:

```cpp
char firstName = 'a'; // give firstName the value 'a'
hour = 11;         // assign the value 11 to hour
minute = 59;      // set minute to 50
```

## 2.5 Outputting variables

This program creates two integer variables hour and minute, and a character variable colon. It assigns appropriate values to each the variables and then uses a series of output statements to generate the following:

```cpp
cout << hour;
cout << colon;
```

The output is:

When we talk about "putting a variable," we mean outputting the value of the variable. To output the name of a variable, you have to put it in quotes. Example: cout << "hour";

As we have seen before, you can include more than one value in a single output statement, which can make the previous program more concise:

```cpp
int hour, minute;
char colon;
```

```cpp
hour = 11;
minute = 59;
colon = ':';
```

```cpp
cout << "The current time is " << hour << " hour " << colon << " minute" << endl;
```

On one line, this program outputs a string, two integers, a character, and the special value endl. Very impressive!

## 2.6 Keywords

A few seconds ago, I said that you can make up any name you want for your variables, but that's not quite true. There are certain words that are reserved by the compiler to parse the structure of your program, and if you use them as variable names, it will get confused. These words, keywords, include int, char, var, endl and many more.

The complete list of keywords is included in the C++ Standard, which is the official language definition adopted by the International Organization for Standardization (ISO) on September 1, 1998. You can download a copy electronically from:

http://www.ansi.org/

Rather memorize the list, I would suggest that you take advantage of a feature provided in many development environments: code highlighting. As you type, different parts of your program should appear in different colors. For example, keywords might be blue, strings red, and other color black. If you type a variable name and it turns blue, watch out! You might get some strange behavior from the compiler.
