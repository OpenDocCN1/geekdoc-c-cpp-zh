## 5.3 Composition

As you should expect by now, once you define a new function, you can use it as part of an expression, and you can build new functions using existing functions. For example, if someone gave you two points, the center of the circle and a point on the perimeter, and asked for the area of the circle?
Let's say the center point is stored in the variables xc and yc, and the perimeter point is in xp and yp. The first step is to find the radius of the circle, which is the distance between the two points. Fortunately, we have a function, does that.

```cpp
double radius = distance (xc, yc, xp, yp);
```

The second step is to find the area of a circle with that radius, and return it.

```cpp
double result = area (radius);
return result;
```

Wrapping that up in a function, we get:

```cpp
double fred (double xc, double yc, double xp, double yp) {
    double radius = distance (xc, yc, xp, yp);
    double result = area (radius);
    return result;
}
```

## 5.5 Boolean values

The types we have seen so far are pretty big. There are a lot of integers in the world, and even more floating-point numbers. By comparison, the set of characters is even smaller. Well, there is another type in C++ that is even smaller. It is called boolean, and the only values in it are true and false. Without thinking about it, we have been using boolean values for the last couple of chapters. The condition inside an if statement or a while statement is a boolean expression. Also, the result of a comparison operator is a boolean value.

```cpp
if (x == 5) {
  // doing something
}
```

The operator == compares integers and produces a boolean value.
The values true and false are keywords in C++, and can be used anywhere a boolean expression is called for. For example,

```cpp
while (true) {
  // loop forever
}
```

is a standard idiom for a loop that should run forever (or until it reaches a return or break statement).

## 5.6 Boolean variables

As usual, for every type of value, there is a corresponding type of variable. In C++ the boolean type is called bool. Boolean variables work just like the other types:

```cpp
bool fred;
fred = true;
bool testResult = false;
```

The first line is a simple variable declaration; the second line is an assignment, and the third line is a combination of a declaration and as assignment, called an initialization.
As I mentioned, the result of a comparison operator is a boolean, so you can store it in a bool variable

```cpp
bool evenFlag = (n%2 == 0); // true if n is even
bool positiveFlag = (x > 0); // true if x is positive
```

and use it as part of a conditional statement later

```cpp
if (evenFlag) { cout << "n was even when I checked it" << endl;
}
```

A variable used in this is called a flag, since it flags the presence or absence of some condition.

## 5.7 Logical operators

There are three logical operators in C++: AND, OR and NOT, which are denoted by the symbols && || and !. The semantics (meaning) of these operators are similar to their meaning in English. For example x > 0 && x < 10 is true only if x is greater than zero AND less than 10.

evenFlag || n3 == 0 is true if either of the conditions is true, that is, if evenFlag is true OR the number is divisible by 3.

Finally, the NOT operator has the effect of negating or inverting a bool expression, so !evenFlag is true if evenFlag is false; that is, if the number is odd.

Logical operators often provide a way to simplify nested conditional statements. For example, how would you write the following code:

```cpp
if (x > 0) {
    if (x < 10) {
        cout << "x is positive single digit." << endl;
    }
}
```

## 5.8 Bool functions

Functions can return bool values just like other type, which is often convenient for hiding tests inside functions. For example:

```cpp
bool isSingleDigit(int x) {
if (x >= 0 && x < 10) {
    return true;
} else {
    return false;
}
}
```

## 5.9 Returning from main

Now that we have functions that return values, I can let you in on a secret. main is not really supposed to be a void function. It's supposed to return an integer:

```cpp
int main ()
{
    return 0;
}
```

The usual return value of main is 0, which indicates that the program succeeded at whatever it was supposed to. If something goes wrong, it is common to return -1, or some other value that indicates what kind of error occurred.
