# PIC 微控制器的编程与定制指南








Brian W. Kernighan 和 Dennis M. Ritchie 编写的这本解释 C 语言语言的经典教材，在大学和学院中见过的学生人数多于任何其他书籍。尽管这本书最初是为一门编程课程编写的，但其文字简洁、犀利且易于理解。这本书我可能拥有过五份，其中几本已经磨损了，还有一叠书在我的办公室里越堆越高。

## 推荐的 PIC 微控制器网站

当我遇到问题时，这里是我会尝试的网站列表，用以寻找他人做法的答案。其中大多数网站专门针对 PIC16F84（以及 PIC16C84），但你也可以从这些网站获取有用的信息、代码和电路。这个列表仍然有效，尽管它在不断更新。

正如我所写的，这里大约有 1000 个关于 PIC 微控制器的网页，包含了各种应用程序、代码片段、程序员和其他信息。为了方便你的搜索，我包含了一些具有独特信息或应用，或者拥有其他网站链接的网站。

我自己的网站包含了关于 PIC 微控制器以及其他设备和主题的链接信息：

www.myke.com

Bob Blick 的网站有一些有趣的 PIC 微控制器项目，与平庸的项目大不相同：

www.boblick.com

Scott Dattallo 有高度优化的 PIC 微控制器数学算法。如果你在寻找 PIC 微控制器的数学函数，这里是最佳去处：

www.dattalo.com/technical/software.html

除了快速的 PIC 微控制器程序，Scott 还编写了一些运行在 Linux 下的 GNU 通用工具。关于这些工具的更多信息可以下载：

www.dattalo.com/gnupic/gpsim.html

www.dattalo.com/gnupic/gpasm.html


Marco Di Leo 的 PIC Corner 有一些有趣的应用程序，包括关于微控制器网络以及将其用于加密：

http://members.tripod.com/~mdileo/

在 Dontronics 首页，Don McKenzie 展示了关于 PIC 微控制器的丰富信息以及其他电子产品。这里有很多指向其他网站的有用链接，它是 SimmStick 的首页：

www.dontronics.com/

在 Fast Forward Engineering 首页，Andrew Warren 展示了关于 PIC 微控制器的有用信息和一个非常有问答页面：

http://home.netcom.com/~fastwd/

Steve Lawther 的 PIC 微控制器列表有很多 PIC 微控制器（以及其他控制器）项目：

http://www.worldcompuser.com/homepages/steve_lawther/ucindex.htm

Eric Smith 的 PIC Page 有一些有趣的项目和代码示例供学习：

www.brouhaha.com/~eric/pic/

Rickard 的 PIC-Wall 是一个很好的网站，有一个基于 PIC 微控制器的复合视频游戏生成的设计：

www.efd.lth.se/~e9gr/pic.html

PicPoint 有许多优质项目供选择，包括为任何想要建立自己的 PIC 微控制器网页的人免费提供 5 MB 的资源：

www.picpoint.com/

MicroTronics 提供程序员和应用评测：

www.eedevl.com/index.html
