
受保护的访问说明符与私有类似，但有一个例外——它还允许访问派生类（子类或子类）。该说明符对于实现继承至关重要，在继承中，派生类继承基类的属性和行为。下面是一个简短示例：

```cpp
#include <iostream>

// Base class with protected access specifier
class Vehicle {
    protected:
        // Protected data member
        int speed;
};

// Derived class inheriting from the base class
class Car : public Vehicle {
    public:
        // Accessing protected member from the derived class
        void setSpeed(int newSpeed) {
            speed = newSpeed;
        }

        // Displaying speed from the derived class
        void displaySpeed() const {
            std::cout << "Current speed: " << speed << " mph." << std::endl;
        }
};

int main() {
    // Creating an object of the derived class
    Car myCar;
    myCar.setSpeed(60);

    // Displaying speed using a public member function
    myCar.displaySpeed();

    return 0;
}
```

在此示例中，speed 数据成员在 Vehicle 基类中是受保护的。Car 派生类可以访问和操作该成员。

理解 C++ 中的访问说明符对于设计遵循封装和数据隐藏原则的类至关重要。公有成员构成与外部世界交互的接口，私有成员仅限于类本身，而受保护成员允许在继承上下文中进行受控访问。正确使用访问说明符有助于提高代码清晰性、可维护性以及面向对象设计的整体完整性。

## 访问器与修改器（Getter 和 Setter）

访问器和修改器，通常称为 getter 和 setter，是面向对象编程中用于管理类内私有数据成员的访问和修改的重要组成部分。本节探讨访问器和修改器的重要性，强调它们在维护封装、控制数据完整性以及促进与类成员进行正确交互方面的作用。

### 访问器：安全地获取私有数据

访问器通常称为 getter 方法，提供了一种受控方式，用于从类外部获取私有数据成员的值。通过将数据访问封装在成员函数中，类可以确保外部代码以受控且一致的方式与数据交互。请考虑以下示例：

```cpp
#include <iostream>

// Class with private data and accessor
class Person {
private:
    // Private data member
    std::string name;

public:
    // Accessor (getter) for the private data member
    std::string getName() const {
        return name;
    }

    // Member function to display information
    void displayInfo() const {
        std::cout << "Person's name: " << name << std::endl;
    }
};

int main() {
    // Creating an object of the Person class
    Person individual;

    // Accessing private data through an accessor
    std::string personName = individual.getName();

    // Displaying information using a public member function
    individual.displayInfo();

    return 0;
}
```

在此示例中，getName 访问器允许外部代码安全地获取私有数据成员 name 的值。这种受控访问确保 Person 对象的内部状态不会被直接操纵。

### 修改器：安全地修改私有数据

修改器通常称为 setter 方法，提供了一种受控方式来修改私有数据成员的值。通过将数据修改封装在成员函数中，类可以强制执行约束和验证规则，确保内部状态的完整性得以维持。请考虑以下示例：

```cpp
#include <iostream>

// Class with private data and mutator
class BankAccount {
private:
    // Private data member
    double balance;

public:
    // Mutator (setter) for the private data member
    void setBalance(double newBalance) {
        // Validation: Ensuring non-negative balance
        if (newBalance >= 0) {
            balance = newBalance;
        } else {
            std::cout << "Invalid balance value." << std::endl;
        }
    }

    // Member function to display balance
    void displayBalance() const {
        std::cout << "Current balance: $" << balance << std::endl;
    }
};

int main() {
    // Creating an object of the BankAccount class
    BankAccount myAccount;

    // Modifying private data through a mutator
    myAccount.setBalance(1000.0);

    // Displaying information using a public member function
    myAccount.displayBalance();

    return 0;
}
```

在此示例中，setBalance 修改器允许外部代码在受控条件下修改私有数据成员 balance 的值。该修改器包含验证逻辑，以确保余额非负。

### 访问器和修改器的优点

访问器和修改器的使用有助于 C++ 中的封装和数据隐藏原则。访问器提供了一种安全且受控的方式来获取私有数据，防止外部代码直接访问。另一方面，修改器确保对私有数据的修改遵循指定的规则和约束，维护内部状态的完整性。

通过采用访问器和修改器，类可以对外部交互暴露定义良好的接口，同时保留其实现细节的封装。这些实践增强了 C++ 中面向对象设计的代码可维护性、可读性以及整体健壮性。

## 用于访问控制的友元函数

在 C++ 中，友元函数提供了一种突破传统访问控制屏障的机制，允许非成员函数访问类的私有成员和受保护成员。本节探讨友元函数的概念、语法及其应用，强调 C++ 中封装与灵活性之间的平衡。

### 使用友元函数突破访问屏障

友元函数在类声明中使用 friend 关键字声明。与成员函数不同，友元函数不绑定到类的特定实例，并且可以在不违反封装的情况下访问私有成员和受保护成员。这允许外部函数与类的内部实现紧密协作，在保持数据隐藏原则的同时提供一定程度的灵活性。

```cpp
#include <iostream>

// Forward declaration of the class
class MyClass;

// Friend function declaration
void displayValue(const MyClass& obj);

// Class definition
class MyClass {
private:
    int privateValue;

public:
    // Constructor to initialize private data member
    MyClass(int val) : privateValue(val) {}

    // Friend function definition
    friend void displayValue(const MyClass& obj);
};

// Friend function implementation
void displayValue(const MyClass& obj) {
    // Accessing private data member using the friend function
    std::cout << "Private value: " << obj.privateValue << std::endl;
}

int main() {
    // Creating an object of the class
    MyClass myObject(42);

    // Invoking the friend function to display private data
    displayValue(myObject);

    return 0;
}
```

在此示例中，displayValue 函数被声明为 MyClass 类的友元，使其能够直接访问私有数据成员 privateValue。

虽然友元函数提供了一种将访问扩展到传统边界之外的方式，但应谨慎使用它们。过度使用友元函数可能会损害封装并导致代码可维护性降低。最好在外部函数需要深入访问类内部实现的情况下使用友元函数，例如出于优化或兼容性原因。
