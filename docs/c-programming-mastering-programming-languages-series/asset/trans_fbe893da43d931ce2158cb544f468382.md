## 处理运行时错误和异常

C++ 编程书的“调试与故障排除”模块向开发者介绍了题为“处理运行时错误和异常”的关键章节。本节探讨了管理 C++ 程序执行期间可能出现的意外错误的复杂性，强调使用异常处理机制来增强程序的健壮性。

```cpp
// Example: Exception Handling in C++
#include <iostream>

int main() {
    try {
        int divisor = 0;
        int result = 10 / divisor;  // Division by zero will throw an exception
        std::cout << "Result: " << result << std::endl;
    } catch (const std::exception& e) {
        std::cerr << "Exception caught: " << e.what() << std::endl;
    }

    return 0;
}
```

### C++ 中的异常处理

提供的代码片段演示了 C++ 中异常处理的基本概念。这里，try 块包围可能抛出异常的代码，相应的 catch 块捕获并处理该异常。在此例中，尝试除以零会触发异常，该异常被捕获并处理，从而防止程序崩溃，并允许优雅地恢复错误。

```cpp
// Example: Custom Exception Class
#include <iostream>
#include <stdexcept>

class CustomException : public std::runtime_error {
public:
    CustomException(const std::string& message) : std::runtime_error(message) {}
};

int main() {
    try {
        throw CustomException("Custom exception message");
    } catch (const CustomException& e) {
        std::cerr << "Custom Exception caught: " << e.what() << std::endl;
    }

    return 0;
}
```

### 自定义异常类

开发者经常创建自定义异常类，以提供关于错误的更具上下文特定信息。在此示例中，自定义异常类 CustomException 派生自 std::runtime_error，允许开发者抛出和捕获带有定制错误消息的异常。自定义异常类增强了代码可读性，并使开发者能够传达有关所遇问题的精确细节。

```cpp
// Example: Handling Multiple Exceptions
#include <iostream>
#include <stdexcept>

int main() {
    try {
        // Code snippet for handling multiple exceptions
        throw std::logic_error("Logic error occurred");
    } catch (const std::logic_error& le) {
        std::cerr << "Logic Error caught: " << le.what() << std::endl;
    } catch (const std::exception& e) {
        std::cerr << "Generic Exception caught: " << e.what() << std::endl;
    }

    return 0;
}
```

### 处理多个异常

C++ 支持以分层方式处理多种类型的异常。该示例演示了先捕获特定的 std::logic_error 异常，然后捕获更通用的 std::exception。这种方法允许开发者创建分层的异常处理策略，先处理特定错误场景，再诉诸更通用的错误处理机制。

“处理运行时错误和异常”一节提供了关于 C++ 健壮错误处理能力的重要见解。通过使用 try-catch 块、自定义异常类以及处理多个异常，开发者可以创建能够优雅管理运行时错误的弹性程序，从而提高其 C++ 代码的可靠性和可维护性。
