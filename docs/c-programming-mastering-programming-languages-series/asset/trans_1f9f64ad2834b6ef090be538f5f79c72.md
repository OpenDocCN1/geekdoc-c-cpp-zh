### for 循环的语法与功能

C++ 中的 for 循环尤其擅长管理具有明确结构的迭代。其语法包含三个基本组成部分：初始化语句、终止条件和递增或递减语句。以下是一个用于计算前五个自然数之和的 for 循环示例：

```cpp
#include <iostream>

int main() {
    // Calculating the sum of the first five natural numbers using a for loop
    int sum = 0;

    for (int i = 1; i <= 5; ++i) {
        sum += i;
    }

    // Displaying the calculated sum
    std::cout << "Sum of the first five natural numbers: " << sum << std::endl;

    return 0;
}
```

在此示例中，for 循环初始化循环控制变量 (i)，指定终止条件 (i <= 5)，并在每次迭代后递增该变量。

## 嵌套循环与循环优化

在 C++ 编程领域，嵌套循环的概念涉及将一个循环集成到另一个循环中。本节探讨嵌套循环的语法、应用和优化策略，阐明它们如何高效处理 C++ 程序中的复杂迭代和多维结构。

### 嵌套循环的语法与应用

嵌套循环提供了一种处理多维数据结构或在更广泛上下文中执行重复任务的机制。外层循环通常控制较高层次的结构，而内层循环管理较低层次的结构。考虑以下示例，其中使用嵌套循环创建星号图案：

```cpp
#include <iostream>

int main() {
    // Creating a pattern of asterisks using nested for loops
    for (int i = 1; i <= 5; ++i) {
        for (int j = 1; j <= i; ++j) {
            std::cout << "* ";
        }
        std::cout << std::endl;
    }
    
    return 0;
}
```

在此示例中，外层循环管理行，内层循环控制每一行中星号的打印。随着 i 增加，每一行中的星号数量也增加，从而形成三角形图案。
