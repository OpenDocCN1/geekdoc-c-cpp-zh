## try-catch 块与抛出异常

异常处理是 C++ 中的关键机制，用于在程序执行期间优雅地管理意外情况。本节重点介绍 try-catch 块的使用以及异常的抛出，全面理解这些构造如何协同工作以增强 C++ 代码的健壮性。

### try-catch 块：构建异常处理结构

try-catch 构造是 C++ 异常处理的基础。可能抛出异常的代码被包含在 try 块中。如果 try 块内发生异常，控制权将转移到相应的 catch 块，并在其中实现错误处理逻辑。这种结构允许开发者将正常代码执行与错误处理代码分离，从而促进更清晰、更可维护的代码。

```cpp
#include <iostream>

int main() {
    try {
        // Code that may throw an exception
        throw std::runtime_error("An exception occurred!");
    } catch (const std::exception& e) {
        // Catch block handling the exception
        std::cerr << "Exception caught: " << e.what() << std::endl;
    }
    return 0;
}
```

在此示例中，在 try 块内显式抛出了 std::runtime_error 异常。通过 catch (const std::exception& e) 指定的 catch 块通过打印错误消息来处理该异常。这种关注点分离使代码更具可读性和可维护性。

### 抛出异常：发出错误信号

异常使用 throw 关键字抛出，允许开发者发出异常情况的信号。抛出的对象可以是任何类型，通常派生自 std::exception 类以实现标准化错误处理。抛出异常是在检测到错误或意外条件时采取的主动操作，允许将控制权受控地转移到 catch 块。

```cpp
#include <stdexcept>

void processInput(int value) {
    if (value < 0) {
        // Throwing an exception for negative input
        throw std::out_of_range("Input must be non-negative");
    }
    // Process the input if it is valid
}

int main() {
    try {
        // Attempting to process input
        processInput(-5);
    } catch (const std::exception& e) {
        // Handling the exception
        std::cerr << "Exception caught: " << e.what() << std::endl;
    }

    return 0;
}
```

在此示例中，当输入为负数时，processInput 函数会抛出 std::out_of_range 异常。main 函数捕获并处理该异常，防止其进一步传播。

理解 try-catch 块与抛出异常之间的相互作用对于 C++ 中有效的异常处理至关重要。这些构造提供了一种结构化且系统化的方法来管理错误，使代码更具韧性，并促进健壮软件的开发。开发者应审慎使用这些特性，以确保在健壮的错误处理与保持代码清晰之间取得平衡。

## 处理多个异常

C++ 中有效的异常处理不仅限于管理单一类型的异常。本节深入探讨处理多个异常的技术和最佳实践，使开发者能够面对多样化的错误场景创建更具韧性且适应性更强的代码。

### 捕获多种异常类型

C++ 允许 catch 块处理多种异常类型，从而在应对不同错误条件时提供灵活性。通过指定多个 catch 块，每个块关联一种不同的异常类型，开发者可以根据所抛出异常的特定性质定制其错误处理逻辑。

```cpp
#include <iostream>
#include <stdexcept>

void processInput(int value) {
    try {
        if (value < 0) {
            throw std::out_of_range("Input must be non-negative");
        } else if (value % 2 == 0) {
            throw std::invalid_argument("Even numbers not allowed");
        }
        // Process the input if it is valid
    } catch (const std::out_of_range& e) {
        std::cerr << "Out of Range Exception: " << e.what() << std::endl;
    } catch (const std::invalid_argument& e) {
        std::cerr << "Invalid Argument Exception: " << e.what() << std::endl;
    }
}

int main() {
    try {
        processInput(-5);
    } catch (const std::exception& e) {
        std::cerr << "Exception caught: " << e.what() << std::endl;
    }
    return 0;
}
```

在此示例中，processInput 函数可能会针对负数输入抛出 std::out_of_range 异常，或针对偶数抛出 std::invalid_argument 异常。相应的 catch 块分别处理这些异常，从而允许定制错误消息和响应。

### catch-all 块：处理未知异常

为了提供处理未知或意外异常的 catch-all 机制，开发者可以使用不指定异常类型的 catch 块。这个 catch-all 块确保任何未被前面块捕获的异常都得到处理，防止程序突然终止。

```cpp
#include <iostream>
#include <stdexcept>

void processInput(int value) {
    try {
        if (value < 0) {
            throw std::out_of_range("Input must be non-negative");
        } else if (value % 2 == 0) {
            throw std::invalid_argument("Even numbers not allowed");
        }
        // Process the input if it is valid
    } catch (const std::out_of_range& e) {
        std::cerr << "Out of Range Exception: " << e.what() << std::endl;
    } catch (const std::invalid_argument& e) {
        std::cerr << "Invalid Argument Exception: " << e.what() << std::endl;
    } catch (...) {
        std::cerr << "Unknown Exception Caught" << std::endl;
    }
}

int main() {
    try {
        processInput(-5);
    } catch (const std::exception& e) {
        std::cerr << "Exception caught: " << e.what() << std::endl;
    }

    return 0;
}
```

这里，带有 catch (...) 的 catch-all 块处理任何未被前面 catch 块显式捕获的异常，确保更优雅地处理未预见的错误。

在 C++ 中处理多个异常使开发者能够创建健壮的软件，能够智能地响应各种错误场景。通过为不同异常类型使用 catch 块并纳入 catch-all 机制，开发者可以增强应用程序的韧性，并为用户和维护者提供更具信息量的反馈。
