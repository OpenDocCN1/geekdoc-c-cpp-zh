## 析构函数：对象销毁前的清理任务

析构函数由波浪号（~）后跟类名表示，在对象即将被销毁时被调用，无论是对象离开作用域还是被显式删除。析构函数可用于执行清理任务，例如释放已分配的资源或关闭文件。请考虑以下示例：

```cpp
#include <iostream>

// Class definition with a destructor
class ResourceHolder {
private:
    int* resource;

public:
    // Constructor to allocate resources
    ResourceHolder() : resource(new int) {
        std::cout << "ResourceHolder object created." << std::endl;
    }

    // Destructor to release allocated resources
    ~ResourceHolder() {
        delete resource;
        std::cout << "ResourceHolder object destroyed." << std::endl;
    }
};

int main() {
    // Creating an object of the ResourceHolder class
    ResourceHolder myResource;

    // Object goes out of scope, triggering the destructor
    return 0;
}
```

在此示例中，ResourceHolder 类在其构造函数中分配资源，并在析构函数中释放资源。当 myResource 对象在 main 函数中离开作用域时，析构函数会自动被调用，从而确保正确清理。

## 构造函数重载与默认构造函数

C++ 支持构造函数重载，允许一个类拥有多个参数列表不同的构造函数。此外，一个类可以拥有默认构造函数，即不带参数的构造函数。当创建对象时未提供显式初始化值，就会调用默认构造函数。

理解构造函数和析构函数对于管理 C++ 中对象的生命周期至关重要。构造函数确保对象以明确定义的状态开始，而析构函数则有助于在对象销毁前完成清理任务。这些概念在资源管理中起着关键作用，并有助于提升面向对象 C++ 程序的整体健壮性。

## 公有、私有和受保护访问说明符

访问控制是面向对象编程的基本方面，用于控制类成员的可见性和可访问性。C++ 提供三种访问说明符——公有、私有和受保护——来定义类中成员的作用域。本节探讨这些访问说明符的重要性及其对封装、数据隐藏和继承的影响。

### 公有访问说明符：面向外部的接口

C++ 中的公有访问说明符允许从类外部访问类成员。声明为公有的成员构成接口，外部代码可通过该接口与类的对象交互。请考虑以下示例：

```cpp
#include <iostream>

// Class with public access specifier
class Circle {
public:
    // Public data member
    double radius;

    // Public member function
    double calculateArea() const {
        return 3.14 * radius * radius;
    }
};

int main() {
    // Creating an object of the Circle class
    Circle myCircle;
    myCircle.radius = 5.0;

    // Accessing public members from external code
    double area = myCircle.calculateArea();
    std::cout << "Area of the circle: " << area << std::endl;

    return 0;
}
```

在此示例中，Circle 类有一个公有数据成员 radius 和一个公有成员函数 calculateArea()。外部代码可以直接访问和操作这些成员。
