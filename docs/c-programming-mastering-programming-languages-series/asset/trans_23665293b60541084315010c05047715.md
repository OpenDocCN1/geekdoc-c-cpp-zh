

“C++ 编程”模块“结构体和联合体”中的“定义和使用结构体”部分介绍了 C++ 中一个基础概念，使开发者能够创建自定义的复合数据类型。结构体（structs 是 structures 的简称）提供了一种将不同数据类型封装并组织在同一名称下的方法。

### 结构体定义和声明语法

在 C++ 中，使用 `struct` 关键字声明结构体，后跟结构体名称以及一个包含其成员的代码块。每个成员可以是不同的数据类型，从而允许开发者创建灵活且内聚的数据结构。

```cpp
#include <iostream>

// Struct Definition
struct Person {
    // Members of the Struct
    std::string name;
    int age;
    double height;
};

int main() {
    // Struct Declaration and Initialization
    Person john;
    john.name = "John Doe";
    john.age = 25;
    john.height = 1.75;

    // Accessing Struct Members
    std::cout << "Name: " << john.name << ", Age: " << john.age << ", Height: "
              << john.height << " m" << std::endl;

    return 0;
}
```

这里，`Person` 结构体封装了个人的详细信息，例如姓名、年龄和身高。

### 初始化和访问结构体成员

可以使用点（`.`）运算符访问结构体成员。在上面的示例中，创建了一个名为 `john` 的 `Person` 结构体实例，并为其初始化了特定值。随后，访问并显示结构体的各个成员。

### 使用结构体组织数据和实现封装

结构体在将相关数据组织成内聚单元方面发挥着重要作用，有助于增强代码的可读性和可维护性。结构体通过将相互关联的变量分组在一起实现封装，降低命名冲突的风险，并为数据提供清晰的结构。

```cpp
#include <iostream>

// Struct Definition
struct Point {
    // Members of the Struct
    double x;
    double y;
};

int main() {
    // Structs for Data Organization and Encapsulation
    Point origin = {0.0, 0.0};

    // Accessing Struct Members
    std::cout << "Coordinates: (" << origin.x << ", " << origin.y << ")" << std::endl;

    return 0;
}
```

在此示例中，`Point` 结构体封装了 `x` 和 `y` 坐标，从而简洁地表示二维空间中的一个点。

理解如何定义和使用结构体是每一名 C++ 程序员的基础。结构体支持创建自定义数据类型，能够增强代码的组织性、封装性和可维护性，因此是掌握 C++ 编程过程中至关重要的主题。

## 结构体成员和初始化

在“C++ 编程”的“结构体和联合体”模块中，“结构体成员和初始化”部分深入讲解了定义、初始化和使用 C++ 结构体成员的各种细节。结构体是创建自定义数据类型的基本构建块，深入理解其成员对于熟练进行 C++ 编程至关重要。

### 声明结构体成员

在 C++ 中，结构体成员在结构体定义内部声明，需要为每个成员指定数据类型和名称。例如，考虑表示几何点的结构体：

```cpp
#include <iostream>

// Struct Definition with Members
struct Point {
    double x; // X-coordinate
    double y; // Y-coordinate
};

int main() {
    // Struct Initialization
    Point origin = {0.0, 0.0};

    // Accessing Struct Members
    std::cout << "Coordinates: (" << origin.x << ", " << origin.y << ")" << std::endl;

    return 0;
}
```

在此示例中，`Point` 结构体包含两个成员：`x` 和 `y`，分别表示二维空间中一个点的坐标。

### 成员初始化和访问

可以在声明结构体实例时初始化结构体成员，示例中的 `origin` 实例就是如此。访问结构体成员时使用点（`.`）运算符，这为获取结构体的特定组成部分提供了清晰的语法。

### 成员默认初始化

C++ 允许使用默认值初始化结构体成员，从而确保即使在实例化时没有显式设置成员，它们也具有预定义的值。

```cpp
#include <iostream>

// Struct Definition with Default Member Initialization
struct Rectangle {
    double length = 0.0;
    double width = 0.0;
};

int main() {
    // Struct Initialization with Default Values
    Rectangle square;

    // Accessing Struct Members
    std::cout << "Length: " << square.length << ", Width: " << square.width << std::endl;

    return 0;
}
```

在这种情况下，定义了一个 `Rectangle` 结构体，并为 `length` 和 `width` 设置了默认值。当创建 `square` 这样的 `Rectangle` 实例且未进行显式初始化时，系统会自动为其分配默认值。

理解如何声明、初始化和访问结构体成员，是有效进行 C++ 编程的基础。这些知识使开发者能够创建灵活且组织良好的数据结构，是掌握 C++ 语言复杂特性的关键技能。

## 联合体简介

在“C++ 编程”的“结构体和联合体”模块中，“联合体简介”部分介绍了一种独特且灵活的数据结构，即联合体。与结构体一样，联合体允许开发者创建自定义数据类型，但联合体具有与结构体不同的特征。

### 联合体的声明和语法

在 C++ 中，使用 `union` 关键字声明联合体，后跟联合体名称以及一个包含其成员的代码块。与可以包含多个不同数据类型成员的结构体不同，联合体同一时间只能有一个活动成员。这一特性使联合体适用于不同类型的数据共享同一内存空间的场景。

```cpp
#include <iostream>

// Union Definition
union Data {
    int integerData;
    double doubleData;
    char charData;
};

int main() {
    // Union Initialization
    Data myUnion;

    // Accessing Union Members
    myUnion.integerData = 42;
    std::cout << "Integer Data: " << myUnion.integerData << std::endl;

    myUnion.doubleData = 3.14;
    std::cout << "Double Data: " << myUnion.doubleData << std::endl;

    myUnion.charData = 'A';
    std::cout << "Char Data: " << myUnion.charData << std::endl;

    return 0;
}
```

在此示例中，`Data` 联合体包含三种不同数据类型的成员：`integerData`、`doubleData` 和 `charData`。但是，在任意时刻只能有其中一个成员处于活动状态。

### 共享内存空间和联合体的使用场景

联合体的主要优势在于能够让不同成员共享同一内存空间。当不同数据类型需要使用同一内存位置表示时，这一特性尤其有用，可以优化内存使用。

例如，在嵌入式系统或内存受限的场景中，可以使用联合体在有限的内存占用范围内存储和操作不同类型的数据。

### 注意事项和限制

虽然联合体提供了灵活性，但开发者在使用时必须谨慎。联合体不像结构体那样具有成员封装这一内在特性，修改一个成员可能会影响对其他成员的解释。此外，如果需要让多种类型的数据同时共存，联合体可能并不适用。

“联合体简介”部分帮助读者从基础上理解联合体这一 C++ 专用数据结构。掌握联合体后，程序员便能够高效管理共享内存空间，并在 C++ 程序中做出是否使用这一独特特性的明智决定。

## 结构体和联合体的区别

“C++ 编程”的“结构体和联合体”模块包含一个重要部分，用于阐明结构体与联合体之间的差异。虽然这两种数据结构都支持创建自定义类型，但理解它们之间的区别对于针对具体编程场景选择合适的工具至关重要。

### 内存分配和数据组织

结构体和联合体在成员内存分配方式上的差异十分显著。在结构体中，每个成员都拥有独立的内存空间，结构体的总大小是其各个成员大小之和。这确保每个成员都保留自己的内存空间。

```cpp
#include <iostream>

// Struct Definition
struct Point {
    double x;
    double y;
};

int main() {
    // Struct Initialization
    Point myPoint;

    // Memory Size of the Struct
    std::cout << "Size of Point struct: " << sizeof(myPoint) << " bytes" << std::endl;

    return 0;
}
```
