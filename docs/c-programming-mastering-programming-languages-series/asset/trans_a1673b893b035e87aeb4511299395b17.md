
与传统编程在运行时执行代码不同，TMP 利用模板在编译阶段执行计算。这种强大的技术将模板转化为元编程的手段，使代码本身成为在编译期进行程序化计算的工具。

```cpp
// Example: Compile-time Factorial Calculation using Template Metaprogramming
template <int N>
struct Factorial {
    static const int value = N * Factorial<N - 1>::value;
};

template <>
struct Factorial<0> {
    static const int value = 1;
};
```

### 使用 TMP 进行编译期计算

在此示例中，模板元程序在编译期计算一个数的阶乘。'Factorial' 模板递归地将输入 'N' 乘以 'N-1' 的阶乘。当 'N' 为 0 时，基准情形终止递归并将 'value' 设为 1。

```cpp

    return 0;
}
```

在 main 函数中，利用该模板元程序在编译期计算 5 的阶乘。随后将结果打印到控制台。这展示了 TMP 在编译阶段执行复杂计算的能力，为开发者提供了一种基于编译期常量生成代码的机制。
