### 调试技术简介

《C++ 编程》一书中的“调试与故障排除”模块以一个基础章节“调试技术简介”开始。调试是开发者不可或缺的技能，使他们能够有效识别并纠正代码中的问题。本节介绍维护和提升 C++ 程序质量所必需的关键调试概念、策略和工具。

```cpp
// Example: Adding Debugging Statements
#include <iostream>

int main() {
    int x = 5, y = 0;

    // Adding debugging statements to trace the program flow
    std::cout << "Before division: x = " << x << ", y = " << y << std::endl;

    // Debugging by adding print statements
    if (y != 0) {

```

### 添加调试语句

一种常见的调试技术是在代码中有策略地插入打印语句，以输出变量值或特定消息。在提供的示例中，在执行除法运算之前，添加了调试语句来打印 x 和 y 的值。这有助于开发者跟踪程序流程，并在关键操作前后识别潜在问题。

```cpp
// Example: Using Breakpoints in IDE
#include <iostream>

int main() {
    int x = 5, y = 0;

    // Setting breakpoints in the IDE to pause execution and inspect variables
    std::cout << "Before division: x = " << x << ", y = " << y << std::endl;

    // Using breakpoints to inspect variables during runtime
    if (y != 0) {
        int result = x / y; // Set a breakpoint here
        std::cout << "Result of division: " << result << std::endl;
    } else {
        std::cerr << "Error: Cannot divide by zero." << std::endl;
    }

    return 0;
}
```

### 在 IDE 中使用断点

集成开发环境（IDE）提供强大的调试工具，包括断点。开发者可以在代码的特定行设置断点，暂停程序执行以检查变量值，并逐行单步执行代码。这允许在运行时不同阶段详细检查程序状态。

```cpp
// Example: Utilizing Assertions
#include <cassert>

int main() {
    int x = 5, y = 0;

    // Utilizing assertions to check for conditions during runtime
    assert(y != 0 && "Error: Cannot divide by zero.");

    // Performing division after assertion
    int result = x / y;
    return 0;
}
```

### 使用断言

断言对于强制检查程序状态的假设非常宝贵。在此示例中，使用断言在继续执行除法之前检查 y 是否非零。如果断言失败，将显示错误消息，清晰指示问题所在。

“调试技术简介”一节为 C++ 编程中的有效调试奠定基础。从加入调试语句、利用断点到使用断言，开发者获得识别并解决问题的基本技能，确保其 C++ 应用程序的健壮性和可靠性。
