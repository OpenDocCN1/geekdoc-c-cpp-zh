### Try-Catch 块：处理异常

try-catch 块是 C++ 异常处理的核心。可能抛出异常的代码会被放置在 try 块中，相应的错误处理代码则放置在 catch 块中。当 try 块中抛出异常时，控制流会转移到适当的 catch 块，使程序能够优雅地处理异常。

```cpp
#include <iostream>

int main() {
    try {
        // Code that may throw an exception
        throw std::runtime_error("An exception occurred!");
    } catch (const std::exception& e) {
        // Catch block handling the exception
        std::cerr << "Exception caught: " << e.what() << std::endl;
    }
    return 0;
}
```

在此示例中，`std::runtime_error` 异常在 try 块中被显式抛出，并在相应的 catch 块中被捕获，随后执行错误处理逻辑。

### 抛出异常：发出错误信号

使用 `throw` 关键字可以显式抛出异常。它表示发生了异常情况，使程序能够跳转到适当的 catch 块进行处理。抛出的对象可以是任意类型，但通常会派生自 `std::exception` 类，以实现标准化的错误处理。

```cpp
#include <stdexcept>

void processInput(int value) {
    if (value < 0) {
        // Throwing an exception for negative input
        throw std::out_of_range("Input must be non-negative");
    }
    // Process the input if it is valid
}

int main() {
    try {
        // Attempting to process input
        processInput(-5);
    } catch (const std::exception& e) {
        // Handling the exception
        std::cerr << "Exception caught: " << e.what() << std::endl;
    }

    return 0;
}
```

在这里，如果输入值为负数，`processInput` 函数就会抛出 `std::out_of_range` 异常。随后，该异常会在 `main` 函数中被捕获并处理。
