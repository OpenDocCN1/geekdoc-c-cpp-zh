## Lambda 表达式简介

Lambda 表达式与 C++11 特性模块中的“Lambda 表达式简介”部分全面概述了 C++11 引入的最强大特性之一：Lambda 表达式。Lambda 表达式提供了一种简洁且富有表现力的方式来定义匿名函数，从而增强 C++ 代码的可读性和灵活性。

```cpp
// Example: Basic Lambda Expression
#include <iostream>

int main() {
    // Lambda expression to square a number
    auto square = [](int x) {
        return x * x;
    };

    int result = square(5);
    std::cout << "Square of 5: " << result << std::endl;

    return 0;
}
```

## 基本 Lambda 表达式

在所示示例中，Lambda 表达式用于定义一个对整数求平方的匿名函数。由 [] 表示的 Lambda 语法允许在 main() 作用域内创建一个紧凑的函数。auto 关键字用于推断 Lambda 的返回类型。这种简洁形式简化了小型、可复用函数的创建，而无需显式函数声明。

```cpp
// Example: Lambda Expression with Capture Clause
#include <iostream>

int main() {
    int multiplier = 2;

    // Lambda expression capturing an external variable
    auto multiplyBy = [multiplier](int x) {
        return x * multiplier;
    };

    int result = multiplyBy(5);
    std::cout << "Result of multiplication: " << result << std::endl;

    return 0;
}
```

## 带捕获子句的 Lambda 表达式

此示例介绍了 Lambda 表达式的捕获子句，支持捕获外部变量。[multiplier] 部分按值捕获变量 multiplier，使其可在 Lambda 内访问。此特性提供了一种强大的机制，用于创建灵活且上下文感知的函数。

Lambda 表达式提供简洁的语法，使其特别适用于简短的一次性函数。它们可用于各种场景，例如算法、回调函数和事件处理。此外，Lambda 表达式促进了 C++11 引入的更广泛范式转变，强调现代且富有表现力的编程构造。开发者可以利用 Lambda 表达式提高代码可读性、减少样板代码，并拥抱引入 C++ 语言的函数式编程方面。

## Lambda 捕获与函数类型

Lambda 表达式与 C++11 特性模块中的“Lambda 捕获与函数类型”部分探讨 Lambda 表达式的高级方面，深入研究捕获变量和理解函数类型的细微之处。这些知识对于在 C++ 中充分发挥 Lambda 表达式的威力至关重要。

```cpp
// Example: Lambda Capture by Reference
#include <iostream>

int main() {
    int counter = 0;

    // Lambda expression capturing counter by reference
    auto increment = [&counter]() {
        counter++;
    };

    increment();
    std::cout << "Counter value: " << counter << std::endl;

    return 0;
}
```

## 按引用捕获的 Lambda

在此示例中，Lambda 表达式使用 & 符号按引用捕获 counter 变量。这意味着在 Lambda 内对 counter 的任何修改都会影响 Lambda 作用域外的原始变量。理解捕获模式（按值还是按引用）对于防止程序中出现意外副作用至关重要。

```cpp
// Example: Lambda with Mutable Keyword
#include <iostream>

int main() {
    int count = 0;

    // Lambda expression with mutable keyword
    auto incrementAndPrint = [count]() mutable {
        std::cout << "Before increment: " << count << std::endl;
        count++;
        std::cout << "After increment: " << count << std::endl;
    };

    incrementAndPrint();

    std::cout << "Outside lambda: " << count << std::endl;

    return 0;
}
```

在 C++03 中，开发者通常使用字面量 0 或 NULL 来表示空指针，这可能导致潜在的歧义。C++11 引入 nullptr 关键字来显式表示空指针，从而增强代码清晰度并防止意外行为。此示例演示了在处理指针的函数中使用 nullptr。

```cpp
// Example: Range-based for Loop
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers = {1, 2, 3, 4, 5};

    // Range-based for loop to iterate over elements
    for (int num : numbers) {
        std::cout << num << " ";
    }

    return 0;
}
```
