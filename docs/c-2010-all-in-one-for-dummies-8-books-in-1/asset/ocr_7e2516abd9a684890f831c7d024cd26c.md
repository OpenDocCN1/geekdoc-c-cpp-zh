The value represents the total principal after the number of years elapsed, assuming simple interest compounded annually. For example, the value of $1,234 at $3,561.94 after nine years.

Most of the values show two decimal places for the cents in the amount. Because trailing zeros aren't displayed in all versions of C#, some may show only a single digit—or even no digit—after the decimal point. Thus,12.7 may be displayed. If so, you can fix the problem using the special formatting characters described in Chapter 3 of this mini-book. (C.#2 and 4 later appear to show trailing zeros by default.)
