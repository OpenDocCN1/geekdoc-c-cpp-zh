# 140 Iterating through a Directory of Files

The DumpHex() method is a little tricky only because of the difficulties in formatting the output just right.

DumpHex() starts up by opening file. A FileInfo contains information about the file—it doesn't open the file. DumpHex() gets the full name of the file, including the path, and opens a FileStream in read-only mode using that name. The catch block throws an exception if FileStream can't read the file for some reason.

DumpHex() then reads through the file, 10 bytes at a time. It displays every hexadecimal format as a single line. Every 20 lines, it pauses until the user presses Enter. We use the modulo operator, % to accomplish that task.

Vertically, a console window has room for 25 lines by default. (The user can change the window's size, of course, allowing more or fewer lines.) That means you have to pause every 20 lines or so. Otherwise, the data streams off the top of the screen before you can read it.

The modulo operator (%) returns the remainder after division. Thus (line % 20) == 0 is true when line 20, 40, 60, 80—you get the idea. This is valuable, in all sorts of looping situations where you want to perform an operation only so often.

DumpBuffer writes each member of a byte array using the X2 format control. X2 sounds like the name of a secret military experiment, it simply means "display a number as two hexadecimal digits."

The range of a byte is 0 to 255, or two digits per byte.
