# 216 Defining a Class and an Object

Computer science models the world via structures that represent concepts or things in the world, such as bank accounts, tic-tac-toe games, customers, game boards, documents, and products. Analysts say that “a class maps from the problem into the program.” For example, your problem might be to build a traffic simulator that models traffic patterns for the purpose of building streets, intersections, and highways. (I really want to build traffic simulators that can fix the intersections in front of you)

Any description of a problem concerning traffic would include the vehicle in its solution. Vehicles also have a top speed that must be figured into the equation. They also have a weight, and some of them are clunkers. In addition, vehicles stop and go vehicles. Thus, as a concept, vehicle is part of the domain.

A C# traffic-simulator program would necessarily include the class Vehicle, which describes the relevant properties of a vehicle. The C# Vehicle would have properties such as TopSpeed, weight, and isClunker.

Because the class is central to C# programming, the rest of Book II spelunks the ins out of classes in much more detail. This chapter gets you started.

# Defining a class

An example of the class Vehicle may appear this way:

```
public class Vehicle {
    public string model;      // Name of the model
    public string manufacturer; // Ditto
    public int numOfDoors;      // The number of doors on the vehicle
    public int numOfWheels;     // You get the idea.
}
```

A class definition begins with the words public class, followed by the name of the class — in this case, Vehicle.

Like all in C#, the name of the class is case sensitive. C# doesn't enforce any rules concerning names, but an unofficial rule holds that the name of a class starts with a capital letter.

The class name is followed by a pair of open and closed braces. The members of a class are variables that make up the parts of the class. In this example, class Vehicle starts with the member string model, which contains the name of the model of the vehicle. If the vehicle were a car, its name could be Trooper II.
