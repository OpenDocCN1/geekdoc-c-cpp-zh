# # Recognizing the other file types

I am you get the idea at this point on ASPX markup file. There are ASPX files that have markup, and there are ASPX, CS files that have C# code. That's the core of the ASP.NET model.

If you have done any Web development before, you know that there are other files that get used. Lots of other files get used, in fact.

Visual Studio has a place for nearly all those other files. Table 2-1 is a breakdown of some those files, what they are, and how they are accessed.

| Table 2-1 | Web Application File Types |
| --- | --- |
| File Type | What It Does | How Visual Studio Handles It |
| Stylesheets (.css files, usually) | Controls how the page looks. For CSS, check out HTML and CSS For Dummies. | Visual Studio has a fantastic CSS handler. I like it more than the supposedly better ones from Blend. |
| JavaScript Files | Handles client-side activity. | Now that Microsoft supports AJAX, JavaScript(the J in AJAX) is suddenly a lot more important. IntelliSense is supported now, as well as real debugging. |
