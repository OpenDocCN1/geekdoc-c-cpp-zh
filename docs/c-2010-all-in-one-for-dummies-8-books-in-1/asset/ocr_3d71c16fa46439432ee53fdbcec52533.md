The two main types of attacks to be concerned about for a Web Forms application are SQL Injection and script exploits.

# SQL Injection attacks

A SQL Injection attack happens when a hacker enters a line of SQL code into an input field to query a database in a form on a Web page (such as the username and password text boxes in a login form). Malicious SQL causes the database to act in an unexpected way or to allow the hacker to gain access to, alter, or damage the database.

# Understanding SQL Injection

The best way to understand how a hacker uses a SQL Injection is to see an example. For instance, a Web page has code that accepts a Product ID from the user in text and returns product details about the Product ID the user entered. The code on the server would look like this:

```
// getProductID from user
string ProductID = TextBox.Text;
// get information from the database
string selectString = "SELECT * FROM Items WHERE ProductID = \
    "' + ProductID + "';";
SqlCommand cmd = new SqlCommand(selectString, conn);
conn.Open();
SqlDataReader myReader = cmd.ExecuteReader();
// Process results
myReader.Close();
conn.Close();
```

Normally, a user enters the appropriate information into the text box. But a cracker attempting a SQL Injection attack would enter the following string into textBox:

```
"FOOBAR'; DELETE FROM Items; --"
```

The SQL code that would be run by your code would look like this:

```
SELECT * FROM Items WHERE ProductID = 'FOOBAR'; DELETE FROM
Items;--
```

The SQL Server executes some code you didn't expect; in this case, the code deleted everything in the Items table.
