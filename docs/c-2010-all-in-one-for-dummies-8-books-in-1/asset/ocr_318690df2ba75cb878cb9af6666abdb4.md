The "length process" doesn't do much. The duration variable for 2000 iterations — a few seconds at runtime, which is more than enough for this demo. The next, method computes an "update interval" of 200 iterations by dividing the overall duration into them. Then the loop ticks off for each one, it checks whether it's time to update the user interface. Most times the loop, no update occurs. But whenever the if condition is true, the method invokes the DoProgressCallback instance that was passed to the updateProgress parameter. Modulo expression, i % update Interval, comes out with only a 0 remainder, satisfying the condition, every 200 iterations.
