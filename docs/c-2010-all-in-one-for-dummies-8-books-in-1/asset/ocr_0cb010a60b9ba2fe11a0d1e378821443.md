As I explain in the section "Declaring Numeric Constants," later in this chapter, fixed values such as also have a type. By default, a simple constant as 1 is assumed to be an int. Constants other than an int must be marked with their variable type. For example, 123U is an unsigned integer, uint.

Most integer variables are called signed, which means they can represent negative values. Unsigned integers represent only positive values, but you get twice the range in return. As you can see from Table 2-1, the names of unsigned integers start with a u, while the signed types generally do not have a prefix.

You don't need any unsigned integer versions in this book.
