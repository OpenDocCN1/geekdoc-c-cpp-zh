# Iterating days of the month: A first example

The following define from the IteratorBlocks provides an iterator that steps through the months of the year:

```
//GetEnumerator -- Here's the iterator. See how it's invoked
// In Main() with foreach.
public System.Collections.IEnumerator GetEnumerator()
{
    foreach (string month in months)
    {
        yield return month;
    }
}
```

Here's part of a Main() method that iterates this collection using a loop:

```
// Instantiate a MonthDays 'collection' class.
MonthDays md = new MonthDays();
// Iterate it.
foreach (string month in md)
{
    Console.WriteLine(month);
}
```

This extremely simple collection class is based on an array, as KeyedArray is an array whose items are strings. When a client iterates this, the collection's iterator block delivers strings by one. Each string contains the name of the month (in sequence), with the number of days in the month tacked on the string. It is useful, but, is simple — and different!
