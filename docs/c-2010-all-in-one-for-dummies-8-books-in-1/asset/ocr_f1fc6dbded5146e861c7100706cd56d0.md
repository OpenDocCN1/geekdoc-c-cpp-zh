# StringBuilder: Manipulating Strings More Efficiently

Building strings out of a bunch of shorter strings can cost you an arm and its elbow. Because a string, after it's created, can't be changed — as I say at the beginning of this chapter. This example doesn't track 'ly' onto string:

```
string s1 = "rapid";nstring s2 = s1 + "ly"; // s2 = rapidly.
```

It creates a new string composed of the combination. (s1 is unchanged). Similarly, other operations that may modify a string, such as Substring() and Replace(), do the same.

The result is that each operation on strings produces another string. Suppose you need to concatenate 1000 strings into one huge. You're going to create a new string for each concatenation:

```
string[] listOfNames = ... // 1000 pet names
string s = string.Empty;
for(int i = 0; i < 1000; i++) {
    s += listOfNames[i];
}
```
