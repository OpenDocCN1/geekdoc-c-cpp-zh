# 342 Looking at a Program that CAN_BE_USED_AS an Example

A class implements the Comparable<T> interface by implementing a CompareTo() method. Notice that CompareTo() takes an argument of type T, a type you supply when you instantiate the interface for a particular data type — as in this example:

```
class SoAndSo : Comparable<SoAndSo> // Make me comparable.
```

It seems a little Darwin, but you could say that one Student object is "greater than" another Student object if his grade-point average is higher. (Okay, either a better student or a better apple-polisher — It doesn't matter.)

Implementing the CompareTo() method implies that the objects have a sorting order. If one student is "greater than" another, you must be able to sort the students from "least" to "greatest." In fact, most collection classes (including arrays but not dictionaries) supply a Sort() method something like this:

```
void Sort(Comparable<T> objects) {
```

This method sorts a collection of objects that implement the Comparable<T> interface. It doesn't even matter which class the objects belong to. For example, they could be Student objects. Collection classes such as arrays or List<T> could even sort this version of Student:

```
// Student -- Description of a student with name and grade
class Student : Comparable<Student>, IDisplayable
{
    // Constructor -- initialize a new student object.
    public Student(double grade)
        Grade = grade;
    public double Grade { get; private set; }
    // Implement the Comparable<T> interface:
    public int CompareTo(Student other)
    {
        // Compare another object (in this class, Student objects) and
        // Decide which one comes after the other in the sorted order.
        Student rightStudent = other;
        
        // Compare the current Student (call her 'left') against the other
        // student (call her 'right').
        Student leftStudent = this;

        // Now generate -1, 0 or 1 based on the Sort criteria (the student's
        // grade). I could use class Double's CompareTo() method instead.
        {
            if (rightStudent.Grade < leftStudent.Grade)
                return -1;
        }
}
```
