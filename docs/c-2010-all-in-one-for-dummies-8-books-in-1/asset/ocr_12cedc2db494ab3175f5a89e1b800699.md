Even though WPF still supports the direct event handler wire up (for the OnClick event), WPF introduces a much better mechanism for responding to user events. It significantly reduces the amount of code you have to write and add testability to your application. Traditional event handling is all contained in the code-behind for your form, which is extremely difficult to test in an automated fashion.

Software patterns have been around for a long time, for the forefront by the classic Design Patterns: Elements of Reusable Object-Oriented Software by Erich Gamma, Richard Helm, Ralph Johnson, and John Vissides commonly referred to the "Gang of Four." Software has evolved and many new patterns have been developed over the years. One of the most effective user interface patterns developed for WPF is the Model-View-ViewModel pattern (commonly referred to as ViewModel). Using the ViewModel pattern in your applications will improve reuse, testability, readability, maintainability, and most of the other "ilities" as well.

# Commanding Attention
