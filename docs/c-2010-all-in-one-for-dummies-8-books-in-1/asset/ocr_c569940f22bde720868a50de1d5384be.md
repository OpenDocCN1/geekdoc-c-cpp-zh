Before entering the while loop, the program declares a variable year, which initializes it to 1. This will be the "current year" — that is, this number changes each year as the program loops. If the year number contained in year is less than the total duration contained in duration, the principal for "this year" is calculated by interest based on the previous year. The calculated principal is output along with the current-year offset.

The statement decimal.Round() rounds the calculated value to the near-fraction of a cent.

The key to the loop lies in the last line within the block. The statement year = year + 1; increments year by 1. If year begins with the value 3, its value will be 4 after this expression. This increment moves the calculations from one year to the next.

After the year has been incremented, control returns to the top of the loop, where the value year is compared to the requested duration. In the sample run, if the year is less than 10, the calculation continue. After being incremented times, the value of year becomes 11, which is greater than 10, and program control passes to the first statement after the while loop—

Most loops follow this basic principle of incrementing a count until it exceeds a previously defined value.

The counting variable year in CalculateInterestTable be declared and initialized before the while loop in which it is used. In addition, the year variable must be incremented, usually as the last statement within the loop. As this example demonstrates, you have to look ahead to see which variables you need. This pattern is easier to use after you've written a few while loops, like I have.
