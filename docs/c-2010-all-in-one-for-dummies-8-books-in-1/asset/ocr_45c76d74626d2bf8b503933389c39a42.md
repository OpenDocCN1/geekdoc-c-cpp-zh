```
// IsAllDigits -- Return true if all characters
// in the string are digits.
public static bool IsAllDigits(string raw)
{
    // Get rid of any benign characters at either end;
    // if there's nothing left, you don't have a number:
    string s = raw.Trim(); // Ignore white space on either side.
    if (s.Length == 0) return false;
    // Loop through the string;
    for(int index = 0; index < s.Length; index++)
{
        // A nondigit indicates that the string probably isn't a number.
        if (Char.IsDigit(s[index]) == false) return false;
    }
    // No digits found; it's probably okay.
    return true;
}
```

The method **IsAllDigits** first removes any white space at either end of the string. If nothing is left, the string is blank and cannot be an integer. The method loops through each character in the string. If any of these characters turns out to be a nondigit, the method returns *false*, indicating that the string is probably not a number. If this method returns *true*, the probability is high that the string can be converted into an integer successfully.
