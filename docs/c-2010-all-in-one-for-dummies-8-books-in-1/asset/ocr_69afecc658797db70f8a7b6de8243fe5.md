When you click the little triangle next to the # node, you see the General panel (which is the default view) and then the other panels you can use:

+   - Tabs: This section is for people who are obsessive about the tabbing of their source code. The Tabs panel determines how many spaces make up a tab, and Visual Studio should insert them automatically.

+   - Formatting: Formatting in C# is in-depth. Generally, C# coders are a little pernisense about the look of their code. Visual Studio does a lot of work to help make your code look the way you want, but you have to tell it what to do. Options for formatting include:

+   - Automatic formatting

+   - Indentation

+   - Newlines

+   - Spacing

+   - Wrapping

IntelliSense: The most interesting field is the list of characters that "commit" an IntelliSense selection. By typing one of these characters, you select the highlighted IntelliSense menu. Usually, I just use dot (.) but there are many more options, and I have no idea!

# Neat stuff

I provide a canonical list of the options that I always forget are in, but that I have to use frequently. Right now, they probably won't make a lot of sense, but you may remember them when you need them.

+   - To implement a new source control provider, first install the package (for instance, Turtle for CodeP's SVN implementation, or Team System) and then go to Source Control in Options to pick the one you want to use. Just one at a time!

+   - Many people recommend you store your projects in a short file path, like c:\Projects. You can change where you store projects in the Projects and Solutions section in the options dialog box.
