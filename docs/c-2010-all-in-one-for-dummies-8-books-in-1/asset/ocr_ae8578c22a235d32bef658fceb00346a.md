# Table 3-1 Format Specifiers Using String.Format()

| Control | Example | Result | Notes |
| --- | --- | --- | --- |
| C — currency | {0:C} of 123456 | $123.45 | The currency sign depends on the Region setting. |
| | {0:C} of -123456 | ($123.45) | (Specify Region in Windows control panel). |
| D — decimal | {0:D5} of 123 | 00123 | Integers only. |
| E — exponential | {0:E} of 12345 | 1.2345E+002 | Also known as scientific notation. |
| F — fixed | {0:F2} of 123456 | 123.46 | The number after the F indicates the number of digits after the decimal point. |
| N — number | {0:N} of 12345678 | 12,345.79 | Adds commas and rounds off to nearest tenth. |
| | {0:N1} of 12345678 | 123,456.8 | Controls the number of digits after the decimal point. |
| | {0:N0} of 12345678 | 123,457 | |
| X — hexadecimal | {0:X} of 123 | 07B | 7B = 123 decimal (integers only). |
| {0:...} | {0:.000} of 12.3 | 012.30 | Forces a 0 if a digit is not already present. |
| {0:...} | {0:#.##} of 12.3 | 12 | Forces the space to be left blank; no other field can encroach on the three digits to the left and two digits after the decimal point useful for maintaining point alignment. |
| | {0:##.0} of 0 | 0.0 | Combining the # and zeros space to be allocated by the # and forces at least one digit to appear, even if the number is 0. |
| {0:# or 0%} | {0:##.%} of .1234 | 12.3% | The % sign displays the number as a percentage (multiplies by 100 and adds the % sign). |
| | {0:##.%} of .0234 | 2.3% | |
