+   - Convert: This method obtains values from the data source and molds them to the form to be displayed to the user onscreen.

+   - ConvertBack: This method does the opposite — it takes the value from the user interface and molds it into a form the data source expects.

It is important to note that with these methods you are not held to the data type as the value being bound. For instance, your data source property bound can be a Date type and the Convert method can still return a string to the user interface.

To demonstrate this feature, create a new WPF application called BindingSample3. This project is a dashboard application that can show the status of servers on the network. In project you implement two user controls, RedX and GreenCheck. You also create a value converter BooleanConverter that converts a Boolean value to display the RedX control and controls a True value to display the Green control. These values indicate whether the server is available.

A user control is a collection of reusable XAML. It can be made up of any number of elements and is implemented with the same rules as when you implement a normal Window (for instance, you have only one root element). You can also define properties (including dependency properties?) on your controls.
