To help you differentiate between seemingly unrelated classes using the same operator, C# extends all classes from the common base class object. That is, any class that doesn't specifically inherit from another class inherits from the class object. Thus the following two statements declare classes with the same base class — object — and are equivalent:

Sharing the common base class of object provides for this generic method:

```
public class Test{
    public static void GenericMethod(object o)
    {
        MyClass mcl = o as MyClassI;
        if(mcl != null)
        {
            // Use the converted object mcl.
        }
    }
}
```

GenericMethod() can be invoked with any type of object. The as keyword can dig the MyClassI pearls from the object oysters. The generic I'm referring to is not the kind covered in Book I.
