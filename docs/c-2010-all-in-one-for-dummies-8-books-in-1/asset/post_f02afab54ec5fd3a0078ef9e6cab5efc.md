
# Defining the Start Page

The start page is the first page you see when you use Visual Studio. It consumes an RSS feed from Microsoft news related to the kind of development, as you use Visual Studio when you installed the software. Often, people change roles and the RSS feed no longer apply to their work. This is a problem.

The solution is the Start Page News field. You can pick any RSS feed you are interested in using for your Start Page content. If you like Microsoft Developer content, you can choose Scott Hanselman's feed for your Start Page. If you are interested in security, you can use the feed at www.semf.net. Alternatively, you can set it to nothing. You're in charge.

# Keyboard commands

The most useful settings in the Options box are the Keyboard settings. This is where you make Visual Studio feel like Emacs through the use of keyboard mappings.

Keyboard mappings are combinations you use to run commands without clicking your mouse. For example, one commonly mapping is Ctrl-C, which copies material in the same way as clicking the Edit menu and then clicking Copy. Many developers feel that keyboard commands makes the development experience faster and easier.

![](img/36596fb11aa4233d5cab0d6ddd1d82e8_544_1.png)

The keyboard settings essentially enable you to select keyboard commands for any menu selection in Visual Studio. Apply the Following Additional Keyboard Mapping Scheme drop-down list enables the key mappings to be different, if you happen to like the mappings of other development environments.

# Language

Language, I don't mean the Internationalization setting to change the display language of Visual Studio if you have additional language packs installed (although that is neat). I am talking about the programming languages you work with Visual Studio. The Languages option is where you can provide settings for each of these programming languages.

# Neat stuff

I provide a canonical list of the options that I always forget are in, but that I have to use frequently. Right now, they probably won't make a lot of sense, but you may remember them when you need them.

# Using Snippets

- Specify which browser you are coding your HTML for in the Text Editor / HTML / Validation section of the Options box.

- Set up automatic Forms Data binding in the Designer for custom controls (that you have bought or built) in the Windows Forms Designer / UI Customization section of the Options box.

- If you are one of those people who think table names should not be pluralized, you can turn off that behavior in the Data Designer in the Database Tools / O/R Designer section of the Options box.

- You can teach Visual Studio to open a file with a given extension in a certain file editor using the Text Editor / File Extension section of the Options panel.

Snippets are little bits of pre-coded logic that are meant to help you remember how to perform some standard code functions in various languages. VB, for instance, you might not remember to read from a file, so there is a snippet for that. In C#, you may want to implement a getter and setter, so there is a snippet for that.
