# Using Snippets 525

The Snippet element is where the work is done. In the cw.snippet example there are two elements in Snippet: Declarations and Code. Declarations declares the variables, and Code is what gets inserted. Within these, these statements are:

+   - The Literal element describes a variable that will be used in the creation of the snippet.

+   - In this case, Function tries to get the simplest version of the System. Console namespace gives the current constraints, and ID names SystemConsole.

+   - The Code element specifies the language and then puts the actual code in place.

If you want to make your own snippet, I suggest that you start with one of the samples provided in the Visual Studio install. You can just start from scratch — if you wish, you can create an XML file and give it .snippet extension — but I think these things are best done iteratively.

# Deploying snippets

To deploy a snippet of your, use the Code Snippets Manager. The manager is found on Tools menu and looks like the one shown in Figure 3-3.

![](bbox=[0.235, 0.543, 0.563, 0.753])

Figure 3-3: The Code Snippets Manager.

![](bbox=[0.885, 0.693, 0.965, 0.853])

Adding a new snippet is fairly simple. After you create your snippet file, click the Import button, and select the .snippet file. It is placed in the selected folder, so make sure you have the snippet highlighted.

The Add and Remove buttons in the Manager refer to directories, not files. Use them to make new snippet folders. The Search Online feature just searches for IntelliSense Code Snippets.
