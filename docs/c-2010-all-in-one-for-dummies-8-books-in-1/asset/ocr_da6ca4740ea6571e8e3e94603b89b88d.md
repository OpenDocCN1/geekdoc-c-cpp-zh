# 736 Making an ASMX Service

+   1. Open Visual Studio and click on New Project.
 The New Project dialog box appears.
2. In Installed Templates under the Visual C# node, select Web.
3. In the box to the right, click ASP.NET Web Service Application.
4. Change the Name to ANewService and the Solution to Book77Chapter2.
5. Click OK.

An example is shown in Figure 2-1.

This process generates a project that has all the right references for a Web service in ASMX and gives you a sample file to start with.

# Analyzing the file setup

Note that although Service1.asmx file (and the usual code-behind) is created, the markup file has only one line in it:

```
<@ WebService Language="C" CodeBehind="Service1.asmx.cs" Class="ANewService.Service1" %>
```

This is design. Nothing in the markup file. All the magic is in the code-behind.
