# What's the object?

Defining a Vehicle design isn't the same task as building a car. Someone has cut some metal and turned some bolts before anyone can drive an actual vehicle. A class object is declared in a similar (but not identical!) fashion to declaring an intrinsic object such as an int.

The term object is used universally to mean a "thing". Okay, that isn't helpful. For an int is an int object. A vehicle is a Vehicle object. We are a reader object. I am an author object—okay, forget that one.

![](bbox=[0.117, 0.547, 0.203, 0.61])

The following code snippet creates a car of class Vehicle:

```
Vehicle myCar;
myCar = new Vehicle();
```

The first line declares a variable myCar of type Vehicle, just like you can declare a somethingInstanceOf int.(The class is a type, and all C# objects are defined as classes.) The new Vehicle() command creates a specific object of type Vehicle and stores the location into the variable myCar. This has nothing to do with the age of myCar. (My could qualify for an antique license if it were so lucky) The operator creates a new block of memory in which your program can store the properties of myCar.

![](bbox=[0.117, 0.847, 0.203, 0.91])
