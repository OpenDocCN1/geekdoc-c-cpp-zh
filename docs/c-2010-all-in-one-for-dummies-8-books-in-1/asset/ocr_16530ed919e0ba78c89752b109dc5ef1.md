I learned a new phrase yesterday at DevLink: convention over configuration. You could build software the most people use, rather than provide 10,000 options to change the way it works. I think Visual Studio gives you some of each, but you have to push the balance to the convention yourself.

# Setting Options

The dialog box can be found by choosing the Tools:Options menu item, and shows a whole lot like Figure 3-1. It is generally designed to set Boolean type options like Show or Provide That or to change paths to where Visual Studio will store files.

The details are all well known, but my goal is to introduce the other things that the options provide. I start with adjustments to your environment and describe the remarkable language options, and then I explore some neat feat.

# Environment

The Environment section is where you begin in the Options dialog box. Sections here include the front details of code-editing settings, key mappings, and the RSS feed settings for the Start page.

The Font and Colors settings will probably be of interest only when you need them for a presentation. Sixteen points is the size of choice for most speakers, including myself. There are a number of "code friendly" fonts out there, and this is where you select them.
