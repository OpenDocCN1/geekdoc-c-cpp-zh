# Hacking the Project Types

Throughout the book, I recommend that you not start with a blank screen. Click New Project and select a project type in order to get some basic set to start with. In C:\Program Files (x86)\Microsoft Visual Studio 10.0\Common7\IDE, find the files that make all the magic project types work.
