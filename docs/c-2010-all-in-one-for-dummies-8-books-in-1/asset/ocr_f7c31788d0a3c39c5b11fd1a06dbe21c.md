# Editing, Validating, Converting, and Visualizing Your Data 585

In this example, you will display the model and code of a Car object (the DataContext) in TextBox controls. This enables you to edit the values of the Car properties. You will also use a TwoWay binding mode so that changes made from the user interface will be reflected in the Car object, and any changes to the Car from code-behind will be reflected in the user interface.
