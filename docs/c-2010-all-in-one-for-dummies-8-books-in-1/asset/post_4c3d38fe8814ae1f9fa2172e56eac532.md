# Basics of WPF

In addition to XAML for layout, all the examples shown can be done exclusively in code. “Shenanigans!” say? No, it’s true. Fixed Row/Column sizing is specified by assigning a number to Width property of ColumnDefinition or RowDefinition. Assigning Auto or * is more complicated, with the Width property of type GridLength.(See Listing 2-12).

## Listing 2-12: Setting Auto and Star Sizing in Code

```csharp
// Set to Auto sizing
column1 = new ColumnDefinition();
column1.Width = new GridLength(1, GridUnitType.Auto);
// Set to Star sizing
column2 = new ColumnDefinition();
column2.Width = new GridLength(1, GridUnitType.Star);
```

For the full example (and many more), refer to the MSDN here: http://msdn.microsoft.com/en-us/library/windows/grid.aspx

In addition to the Panels already discussed, there are four special Layout Panels. As they are extremely specialized, I won’t cover them in great detail:

- TabPanel: Handles the layout of items on a TabControl.
- ToolbarPanel: Handles the layout of items in a Toolbar.
- OverflowPanel: Handles the layout of the controls that overflow from a Toolbar.
- VirtualizingStackPanel: Used for large amounts of data binding. Renders only the visible items.
- InkCanvas: panel accepts digital ink input. Used for scenarios like signatures with Tablet PCs.

# Exploring XAML Controls

A significant number of controls ship out of the box with Visual Studio 2010 (and more vendor-supplied controls are available for purchase). This section covers the more commonly used controls. I prefer to divide the available controls into three categories:

 Display-only controls
- Basic input controls
- List-based controls

All the controls in this section are bindable to data (see Chapter 3 in this book) and modifiable through code.

## Display-only controls

Four focus on displaying information to the user:

- Image: The Image control displays images (of type .bmp, .gif, .ico, .jpg, .png, and .tiff). To preserve the aspect ratio, set the Width or Height, but not both. Additionally, the DecodeWidth should be set to the same size as the Width. This will cause the rendering engine to scale the image appropriately, potentially saving a significant amount of memory.

Listing 2-13 shows how XAML to load an image that shows a color wheel. Only the Width and DecodeWidth are set. The resulting Window is shown in Figure 2-14.

## Listing 2-13: Image Control

```xml
<Image Grid.Row="0" Grid.Column="0" Width="256" >
  <Image.Source>
    <BitmapImage DecodeWidth="256" UriSource="/Images/1460_PaintPalette_256x256.png" />
  </Image.Source>
</Image>
```

- TextBlock and Label: Both the TextBlock and the Label controls are designed to provide text or other content to the user with a few distinctions. The TextBlock control is designed to be the-weight "little brother" to the Label, deriving directly from UIElement.

The Label control provides modifier capability and also derives from ContentControl, which opens up additional possibilities. Placing an underscore (_) before a letter enables the (_) modifiers. To provide an underscore in the Label, use a double underscore. In XAML, since the underscore is used because an ampersand would break the XAML. The Target attribute specifies the control to receive focus when the access modifier is keyed. You have to use a Binding expression, which is covered in Chapter 3.

Both the TextBlock and Label controls are illustrated in Listing 2-14 and Figure 2-15.

## Listing 2-14: TextBlock and Label

```xml
<Grid Row="0" Grid.Column="0" Margin="5,0"
HorizontalAlignment="Right" Text="TextBlock_"/>
<TextBox Row="0" Grid.Column="1" Margin="5,0"
HorizontalAlignment="Stretch"/>
<Grid Row="1" Grid.Column="0" Margin="5,0"
HorizontalAlignment="Stretch">
  HorizontalContentAlignment="Right" Content="_Label_
Content: Target="Binding ElementName=SampleTextBox!"/>
<TextBox Name="SampleTextBox" Grid.Row="1" Grid.Column="1"
Margin="5,0" HorizontalAlignment="Stretch" />
</Grid>
```

In the sample, the "L" in the Label content is the access modifier and the double underscore adds an underscore character to the rendered output.
