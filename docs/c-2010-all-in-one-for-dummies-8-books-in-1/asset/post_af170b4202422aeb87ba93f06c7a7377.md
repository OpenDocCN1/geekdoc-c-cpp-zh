    public static int _nextAccountNumber = 1000;

        _accountNumber = ++_nextAccountNumber;

# IS_A versus HAS_A — I'm So Confused

The IS_A relationship between SavingsAccount and BankAccount is the fundamental IS_A relationship. In the following sections, I will show why, and then show you what the alternative, the HAS_A relationship, would look like.

The IS_A relationship is demonstrated by the following Program code:

```csharp
public class Program
{
    // Add this:
    public static void Deposit(BankAccount ba, decimal pay)
    {
        ba.Deposit(pay);
    }
    // Create a bank account and display it.
    BankAccount ba = new BankAccount();
    ba.InitBankAccount(1000);
    ba.Deposit(100);
    Console.WriteLine("{0}*", ba.BankAccountString());
    // Now a savings account
    SavingsAccount sa = new SavingsAccount();
    sa.InitSavingsAccount(12.58);
    sa.AccumulateInterest();
    Console.WriteLine("{0}*", sa.ToSavingsAccountString());
    // Wait for user to acknowledge the results.
    Console.WriteLine("Press Enter to terminate...");
    Console.ReadLine();
}
```

# Gaining access to BankAccount using containment

The SavingsAccount class could have gained access to the members of BankAccount in a different way, as shown in the following code, where the keys are shown in bold:

```csharp
// A bank account that draws interest
public class SavingsAccount {
    // Notice the underscore: this isn't
    // the SavingsAccount class.

    public BankAccount _bankAccount; // Notice this, the contained BankAccount.
    public decimal _interest;
    // Input the rate expressed as a
    // rate between 0 and 100
    public void initSavingsAccount(BankAccount account, decimal interestRate) {
        _bankAccount = account;
        _interest = interestRate / 100;
    }
    // AccumulateInterest Invoke once per period.
    public void updateInterest() {
        _bankAccount.Balance += _bankAccount.Balance * _interest;
    }
    // Deposit Any positive deposit is allowed.
    public void deposit(decimal amount) {
        // Delegate to the contained BankAccount object.
        _bankAccount.Deposit(amount);
    }
    // You can draw any amount up to the
    // balance; return the amount withdrawn.
    public double withdraw(decimal withdrawal) {
        return _bankAccount.Withdraw(withdrawal);
    }
}
```

In this case, the SavingsAccount contains a data member _bankAccount (as opposed to inheriting from BankAccount). The _bankAccount object contains the balance and account information needed by the savings account.
