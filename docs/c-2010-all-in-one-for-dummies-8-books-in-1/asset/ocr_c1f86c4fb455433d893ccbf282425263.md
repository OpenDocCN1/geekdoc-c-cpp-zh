```
//DescendingEvents - This is a "named iterator."\n// Also demonstrates the yield break keyword
// See how it's invoked in Main() with foreach.
public System.Collections.IEnumerable DescendingEvents(int top, int stop)
{
    // Start at nearest even number.
    if (top % 2 != 0) // If remainder after top / 2 isn't 0
        top--;
    // Iterate from top down to nearest above stop.
    for (int i = top; i >= stop; i -= 2)
    {
        if (i < stop)
            break;
        // Return the next even number on each iteration.
        yield i;
    }
}
```

DescendingEvents() method takes two parameters (a handy addition), which set the upper limit of even numbers that you want to start from and the lower limit you want to stop. The first even number generated will equal top (if odd, the nearest even below it). The last even number will equal the value of the stop parameter (if stop is odd, the nearest even above it). The method does not return an int, however; it returns the IEnumerable. It still contains a yield statement to return one number and then waits until the next time it's invoked from foreach. That's where it is yielded.

This example shows another collection with no underlying collection - such as StringChunks, mentioned earlier in this chapter. Note that this one is computed - the method "yield" returns a value rather than a hard-coded value. That's another way to implement a complex collection. (You can also retrieve items from a data source or Web service.) And, finally, the example shows that you can collect it with any way you like: instead of or by steps of one, for example.

An iterator needn't be finite, either. Consider the following iterator, which delivers a new number as long as you request them:

```
public System.Collections.IEnumerable PositiveIntegers()
{
    for (int i = 0; ; i++)
    {
        yield i;
    }
}
```
