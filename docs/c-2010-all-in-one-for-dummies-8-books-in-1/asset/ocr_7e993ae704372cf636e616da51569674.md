The first note in MainWindow.xaml is that the namespace for the local assembly (BindingSample) was added to the Window by the namespace definition in the Window tag with the prefix local). This enables you to instantiate classes that are defined in the current assembly in XAML.

In the Window resources, we initialized an instance of BooleanToIconConverter, which is available to you through the local namespace.

```
<local:BooleanToIconConverter x:Key='BooleanToIconConverter' />
```

The next Window resource is a data template. This template provides a way to look at the data associated with a server's current status. This data template is defined as follows:

```
<DataTemplate x:Key='ServerTemplate'>
  <BorderBrush='Blue' Margin='3' Padding='3'
    BorderThickness='2' CornerRadius='5' Background='Beige'>
```
