# A brief summary of the available project categories

The following list describes the project types listed in the New Project dialog in Visual Studio. These kinds of finished programs are ones you can make using the installed templates.

+   * Windows Projects: Windows projects in Visual C# are programs that compile into a running program, like Microsoft Word, or Visual Studio itself. The projects include

+   * Forms Application: The classic "program." Compiles into a program that runs with its own window and with a red box (with the little X in it) to exit. This is the original Windows Program style, gradually being replaced by Windows Presentation Foundation.

+   * Class Library: Makes a DLL when you're all done. This is the basis of the .NET Framework, and COM before. It's used to make blocks of reusable code.

+   * WPF Application: The new "program." Also compiles into an EXE, but uses a new interface format called Windows Presentation Foundation. I cover this in depth in Book V.

+   * WPF Browser: Just like a WPF application but runs in Internet Explorer. This is not a Silverlight application; or XNAP application for XML Browser Application. It has a smaller set of available user interface tasks but is still powerful.

+   * Console application: These EXEs are designed to be run from a command prompt.

+   * WPF Custom Control Library: This is a way to make actual controls that appear in the toolbox that you can use in your WPF applications.

+   * Empty Project: Just what it sounds like — a project that's empty, poetic. It's used to build a program when you don't have a template.

+   * Windows Services: These programs appear in the Services control panel. Didn't know you could make with .NET? You aren't alone. It's a powerful feature that few people know. Windows Services are essentially terminate-and-resident, or TSR, programs. (Remember those from your DOS days? They stay in memory.) Check out the article on the topic at csharpfummies.net.
