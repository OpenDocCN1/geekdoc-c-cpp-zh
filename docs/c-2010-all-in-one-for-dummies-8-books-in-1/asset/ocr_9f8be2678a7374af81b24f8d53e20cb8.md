# Calculating Leap Years: DateTime

```
DateTime thisYear = new DateTime(2011, 1, 1);
b isLeapYear = DateTime.IsLeapYear(thisYear.Year);
```

The result for 2011 is false, but for 2012, it's true. (For now, don't worry
out that first line of code, which uses some things you haven't gotten to yet.)

With the DateTime data type, you can do something like 80 different
operations, such as just out the month; get the day of the week; add
days, hours, minutes, seconds, milliseconds, months, or to a given
date: get the number of days in a given month; subtract two dates.

The following sample lines use a convenient property of DateTime called
Now to capture the present date, and one of the numerous
DateTime methods that let you convert one into another:

```
DateTime thisMoment = DateTime.Now;
int hourFromNow = thisMoment.AddHours(1);
```

You can also extract specific parts of a DateTime:

```
int year = DateTime.Now.Year; // For example, 2007
DayOfWeek dayOfWeek = DateTime.Now.DayOfWeek; // For example, Sunday
```

If you print out that DayOfWeek object, it prints like "Sunday".
And you can do here many manipulations of DateTimes:

```
DateTime date = DateTime.Today; // Get the date part.
TimeSpan span = thisMoment.TimeOfDay; // Get just the time part.
TimeSpan duration = new TimeSpan(1, 0, 0, 0); // Specify duration in days
DateTime throwsFromNow = thisMoment.Add(duration);
```

The first two lines extract portions of a DateTime in.
The next two lines add a duration to a DateTime. A duration, or amount
of time, from a moment in time: you specify durations with the
TimeSpan class, and moments with DateTime. The third line sets up a
TimeSpan of three days, zero hours, zero minutes, and two seconds.
The fourth line adds the three-day duration to the DateTime representing right
now, resulting in a new DateTime whose component is greater than
than the day component for it.

Subtracting one DateTime from another DateTime (or a TimeSpan from
DateTime) returns a DateTime:

```
TimeSpan duration = new TimeSpan(1, 0, 0); // One hour later.
// Since today goes 12:00:00 AM (midnight), the following gives 1:00:00 AM:
DateTime hourAfterMidnight = DateTime.Today.Add(duration);
Console.WriteLine("After midnight: " + hourAfterMidnight);
DateTime midnight = hourAfterMidnight.Subtract(duration);
Console.WriteLine("An hour before 1 AM is " + midnight + ");
```
