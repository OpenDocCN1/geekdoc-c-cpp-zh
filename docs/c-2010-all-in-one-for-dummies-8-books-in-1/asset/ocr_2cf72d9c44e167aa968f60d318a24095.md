# The Wrap Panel

The Wrap Panel automatically wraps overflow content onto the next line(s). This is different than how typical toolbar works, where overflow items are hidden when there isn't enough room to show them. Figures 2-3 and 2-4 show the same content controls from the Stack (a mixture of buttons and a text block) in a Wrap Panel. The first Window has enough room to show all the UIElements, and the second shows the wrapping of elements because of a lack of room. The XML for the Wrap Panel sample is in Listing 2-3.

Figure 2-3:
Wrap Panel (wide form).

![](bbox=[0.235, 0.308, 0.533, 0.403])

Figure 2-4:
Wrap Panel (narrow form).

![](bbox=[0.235, 0.433, 0.333, 0.528])

Note even with the Wrap Panel, if the container can't hold the widest item (the last button in the example), some clipping will take place.

# Listing 2-3: Wrap Panel XAML

```
<WrapPanel>
  <Button Content="A Button"/>
  <Button Content="Another Button"/>
  <TextBlock Text="This is a text block"/>
  <Button Content="Short"/>
  <Button Content="Really Long Button Label"/>
</WrapPanel>
```

# The Dock Panel

The Dock Panel uses attached properties (introduced in Chapter 1 of this minibook) to "dock" UIElements. (See Figure 2-5 and Listing 2-4) An important thing to remember that child elements are docked in XAML order, which means if you have two items assigned to the left side (through DockPanel.Dock="left"), the first Element as it appears in the XAML the far left wall of the Panel, followed by the next item.
