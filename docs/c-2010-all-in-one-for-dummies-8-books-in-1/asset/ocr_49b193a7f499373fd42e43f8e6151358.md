Starter programs are reasonably sophisticated. In fact, you'll be amazed at how much capability the App Wizard can build on its own, especially for graphical programs.

# Creating the source program

To start Visual Studio, choose Start:All Programs:Microsoft Studio 2010:Microsoft Studio 2010.

Complete these steps to create your C# console app:

+   1. Open Visual Studio 2010 and click the New Project icon, shown in Figure 1-1.

Visual Studio presents with lots of icons representing the different types of applications you can create, as shown in Figure 1-2.

+   2. In this New Project window, select Visual C# — and under it, Windows — in the Project Types pane; otherwise Visual Studio may create something awful like a Basic or Visual C++. Then click the Console Application in the Templates pane.

Visual Studio requires you to create a project before you start writing C#. A project is a folder in which you throw all the files that go into making your project. It has a set of configuration files that help the compiler do its work. When you tell your compiler to build (compile) the program, it sorts through the project to find the files it needs in order to re-create the executable program.

+   3. The default name for your first application is ConsoleApplication, but change this time to Program1 by typing in the Name field.
