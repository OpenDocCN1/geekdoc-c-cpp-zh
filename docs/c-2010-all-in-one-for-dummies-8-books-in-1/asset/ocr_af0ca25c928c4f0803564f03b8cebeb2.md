# Setting up a sample database schema

To get started, direct your browser to www.microsoft.com/sqlserver/2005/en/us/express-starter-schemas.aspx. If this URL doesn't work, search the web for SQL Server 2008 sample schema and find the near-east Microsoft link. It should get you.

This page shows two sample listings — sample applications and sample schemas. The sample applications are full-blown applications that show complete-to-end implementation of data-driven software built using .NET. Some are in C#, some are in Visual Basic. The sample schemas are databases only and are designed for database administrators to practice getting experience in handling the system.

Any of the sample schemas will work. If you want the same as I use in the examples here, choose the Asset Management schema. Other options may be a better fit for the work you're doing. They include
