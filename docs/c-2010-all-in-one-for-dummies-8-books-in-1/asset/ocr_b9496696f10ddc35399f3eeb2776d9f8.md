+   5. Press F1 one more time.

The program executes to the breakpoint in MyObject, as shown in Figure 5-3 by the yellow arrow. How did you reach this point? The last call in Main() invoked the constructor for MyObject. But before that constructor begins to execute, C initializes the static data member in class Object. That member is of type MyObject, initializing it means invoking its constructor—which lands you at the breakpoint. (Without the breakpoint, you wouldn't see the debugger stop there, although the constructor would indeed execute, as you could confirm by checking to ensure that the constructor's message shows up in the console window).
