You often face the problem of breaking up a string or inserting some substring into the middle of another. Replacing one character with another is most easily handled with the Replace() method, like this:

```csharp
string s = "DangerNoSmoking";
s = s.Replace(' ', '!');
```

Replacing all appearances of one character (in this case, a space) with another (an exclamation mark) is especially useful when generating separated strings for easier parsing. However, the more common and difficult case involves breaking a single string into substrings, manipulating them, and then recombining them into a single, modified string.

```csharp
                // character in the middle missing.

            }
        }
```

## Let's Split() that concatenate program

The RemoveWhiteSpace program demonstrates the use of the Concat and IndexOf() methods; however, it doesn't use the most efficient approach. As usual, a little examination reveals a more efficient approach using our old friend Split(). You can find the program containing this code — now in another example of a method — on the Web site RemoveWhiteSpaceSplit. The method that does the work is shown here:

![](img/36596fb11aa4233d5cab0d6ddd1d82e8_90_0.png)

```csharp
// RemoveWhiteSpace -- The RemoveSpecialChars removes every
// occurrence of the specified characters from the string.
// Note: the rest of the program is not shown.
public static string RemoveChars(string input, char[] targets)
{
    // Split the input string using the
    // characters as delimiters.
    string[] substrings = input.Split(targets);

    // output will contain the eventual output.
    string output = "";

    // Loop through the substrings.
    foreach(string subString in substrings)
    {
        output = String.Concat(output, subString);
    }
    return output;
}
```

This version uses the Split() method to break the input string into a set of substrings, using the characters to be removed as delimiters. The delimiter is not included in the substrings created, which has the effect of removing the character(s). The logic here is much simpler and less error-prone.

The foreach loop in the second half of the program puts the pieces back together using Concat(). The output from the program is unchanged.

## Formatting Your Strings Precisely

The String class also provides the Format() method for formatting output, especially the output of numbers. In its simplest form, Format() allows the insertion of string, numeric, or Boolean input in the middle of a string format. For, consider this call:

```csharp
string myString = String.Format("{0} times {1} equals ({2})", 2, 5, 2);
```

The first argument to Format() is known as the format string — the quoted string you see. The {n} items in the middle of the format string indicate that the n-th argument following the format string is to be inserted at that point. {0} refers to the first argument (in this case, the value 2), {1} refers to the next (that is, 5), and so on.

This returns a string, myString. The resulting string is

```
"2 times 5 equals 10"
```
