# Assigning Multiple catch Blocks

I mention earlier in this chapter that you defined your custom exception types. Suppose that you defined a CustomException class. (I describe this process in the article "Creating Your Own Exception Class") which you can consider the catch clause used here:

```
public void SomeMethod()
  try {
    SomeOtherMethod();
  } catch (CustomException ce) {
}
```

What if SomeMethod() had thrown a simple Exception or another non-CustomException type of exception? It would be like trying to catch a football with a baseball glove — the catch does not match the throw.

![](bbox=[0.143, 0.733, 0.219, 0.803])

Fortunately, C# enables the program to define numerous catch clauses, each designed for a different type of exception. Assuming that this is the right place to handle the other exceptions, you can tack on one another.

Don't be alarmed by my use of the word numerous. In practice, you don't many catch blocks in one place.
