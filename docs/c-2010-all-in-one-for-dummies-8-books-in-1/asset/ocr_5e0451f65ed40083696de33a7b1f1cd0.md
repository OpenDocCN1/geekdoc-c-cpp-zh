Normally, you don't include the boldfaced comments. If you did, the listings would grow rather complicated because of all the numbers and letters. In practice, those types of comments aren't necessary if the methods are well thought out and their names clearly express the intent of each one.

Part 1 calls the method InputData() to input the three variables the program in order to create the table: principal, interest, and duration. Part 2 displays these three variables for verification just as earlier versions of the program do. Part 3 outputs the table via the method OutputInterestTable().

From the bottom and working upward, the OutputInterestTable() method contains an output loop with the interest rate calculations. This loop is the same one used in the inline, nonmethod CalculateInterestTable The advantage of this version, however, is that when writing this section of code, you don't need to concern yourself with any details of inputting or verifying data. When writing this, think of it this way: "Given the numbers—principal, interest, and duration—output an interest table," and thats it. After you're done, you can return to the line that called the OutputInterestTable() method and continue from there.
