After prompting the user for what the program expects, the program creates
an empty sentence string called sentence. From there, the program
ent an infinite loop.

The controls while true and for(;;) loop forever, or at least
ough for some internal return or to break out. The two loops
are equivalent, and in practice, you'll see both. (Looping is covered in
Chapter 5 of this minibook.)

BuildASentence prompts the user to enter a line of text, which the pro-
gram reads using the Readline() method. Having read the line, the pro-
gram checks whether it is a terminator using the boldfaced lines in
the preceding example.

The termination section of the program defines an array of strings called
terms and a bool quitting, initialized to false. Each member of
the array is one of the strings you're looking for. Any of these strings
cause the program to quit faster than a programmer forced to write COBOL.
