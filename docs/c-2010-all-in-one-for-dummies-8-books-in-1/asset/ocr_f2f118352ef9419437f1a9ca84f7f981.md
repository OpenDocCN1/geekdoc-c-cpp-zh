# 764 Changing a WCF Service to Use ReST

There isn't a binding in the WCF Configuration tool for the ReST binding, however, we have to do it another way. Just follow these steps:

+   1. Open the Web.config for the service.

There should be binding information in there from the SOAP service built in Chapter 3. Leave that there.

+   2. Add the list config for the custom POST binding under the ServiceModel section.

It is the first code in Listing 4-1.

+   3. Add the Service information into the Service section. It is the second bold code in Listing 4-1.

# Listing 4-1: The ReST Service Implementation

```
<xml version="1.0" encoding="utf-8"?>
<configuration>
  <system.web>
    <compilation debug="true" targetFramework="4.0/>
    <assemblies>
      <add assembly="System.Data.Entity, Version=4.0.0.0, Culture=neutral, PublicKeyToken=b7ac56c1934e089" />
    </assemblies>
    </compilation>
  </system.web>
  <system.serviceModel>
    <bindings>
      <customBinding>
        <binding name="postBinding">
          <textMessageEncoding messageVersion="None" />
          <httptransport />
        </binding>
      </customBinding>
    </bindings>
    <services>
      <service name="SHARPService.Registration">
        <clear/>
        <endpoint address="http://localhost" binding="basicHttpBinding" name="SHARPService.IRegistration" useHttp="Explicit" />
        <identity>
          <certificateReference storeName="My" storeLocation="LocalMachine" x509Fingerprint="FindByBySubjectDistinguishedName="/ />
        </identity>
        <endpoint address="http://localhost" binding="wsDualBinding" name="SharpDual" contract="SHARPService.IRegistration" />
      </service>
      <service name="SHARPService.Registration">
      <host>
        <baseAddresses>
          <add baseAddress="http://localhost" />
        </baseAddresses>
      </host>
      </service>
    </services>
  </system.serviceModel>
</configuration>
```
