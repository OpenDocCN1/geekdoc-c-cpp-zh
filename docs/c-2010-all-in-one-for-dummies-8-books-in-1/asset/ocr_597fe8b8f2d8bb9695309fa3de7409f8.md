Why not use the dynamic type here? Clearly we could have just double for this. Using of dynamic made the program easier to create. Try changing the array to an array of double, like this:

```
Double[] array = new Double[11];
```

Hey, look at that: Now the Readline doesn't work. We'll just cast it to a double. Nope, can't that; we have to use TryParse. You get the picture Static types are hard to code with. Dynamic types are easier to code with.

What's the other side of this? Well, obviously, if the user enters a string, she gets a runtime error, and if we statically type everything, then we can trap that much easier mistake, and handle right on user input.
