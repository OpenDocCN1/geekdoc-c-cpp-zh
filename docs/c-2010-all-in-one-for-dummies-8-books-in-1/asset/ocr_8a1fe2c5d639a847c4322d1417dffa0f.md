Note: The distinction between static and nonstatic methods is important. I cover part of that in this chapter and continue in more detail in Chapter 4 of this minibook with a focus on nonstatic, or instance, methods.

To invoke a instance — method, you need an instance of the class. To invoke a static — class, you may call the class name, not an instance. The following code snippet snips a value to the object data member anInt and the class, or static, method staticInt:

![](bbox=[0.143, 0.263, 0.228, 0.335])

```
Example example = new Example(); // Create an instance of Class.
example.anInt = 1; // Initialize instance member through instance.
example.staticInt = 2; // Initialize class method through class.
```

The following snippet defines and accesses InstanceMethod() and ClassMethod() in almost the same way:

```
Example example = new Example(); // Create an instance.
example.InstanceMethod(); // Invoke the instance method
// with that instance.
ClassMethod(); // Invoke the method with the class.
// The following lines don't compile:
example.ClassMethod(); // Can't access class methods via an instance.
example.InstanceMethod(); // Can't access instance methods via a class.
```

Every instance of a class has its own, private copy of instance methods. But all instances of the same class have the same class members — both data members and methods — and their values.

![](bbox=[0.143, 0.554, 0.228, 0.626])

The expression InstanceMethod() passes control to the code contained within the method. C# follows an almost identical process for Example.ClassMethod(). Executing the lines just shown (after commenting the last two lines, which don't compile) generates this output:

```
this is an instance
this is a class method
```

After a method completes execution, it returns control to the point where it was called. That is, control moves to the next statement after the call.

The bit of C# code in the two sample methods does nothing more than write a silly string to the console, but methods generally perform well (and sometimes complex) operations such as calculate sines, concatenate two strings, sort an array of strings, or surprisingly email your URL to Microsoft (not really).
