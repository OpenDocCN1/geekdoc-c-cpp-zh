```
double doubleValue = 10.0;

```

All conversions to and from a decimal requires a cast. In fact, all numeric types can be converted into all other numeric types through the application of a cast. Neither nor string can be converted directly into any other type.

Built-in C# methods can convert a number, character, or Boolean into its string equivalent, so to speak. For example, you can convert the value true into the string "true"; however, you cannot consider this change a direct conversion. The bool true and the string "true" are completely different things.

# Letting the C# Compiler Infer Data Types

So far in this book — so far in this chapter — when you declared a variable, you always specified its data type, like this:

```
int i = 5;
string s = "Hello C#";
double d = 1.0;
```

You're allowed to overload some of that work onto the C# compiler, using the var keyword:

```
var i = 5;
var s = "Hello C# 4.0";
var d = 1.0;
```

Now the compiler infers the data type for you — it looks at the stuff on the right side of the assignment to see what the left side is.

For what it's worth, Chapter 3 of this minimax shows how to calculate the type of an expression the ones on the right side of the assignments in the preceding example. Not that you need to do that — the compiler mostly does for you. For example, when you have an initializing expression like this:

```
var x = 3.0 + 2 - 1.5;
```

The compiler can figure out that x is a double value. It looks at 3.0 and 1.5 and sees that they're of type int, which the compiler can convert implicitly to a double for the calculation. All of the additions in x's initialization expression end up as doubles. So the inferred type of x is double.

But now, you can simply use the magic word var and supply an initialization expression, and the compiler does the rest:

```
var aVariable = <initialization expression here>;
```
