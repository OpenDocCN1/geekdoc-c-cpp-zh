# 36 What's a Value Type?

When written out with Console.WriteLine, the last line in this example
places the two phrases on separate lines, like this:

```
This is a line
and so is this
```

A string is not a counting type. A string is also not a value-type — no
"string" that exists that's intrinsic (built in) to the processor. Only one of the
common operators works on string objects: The + operator concatenates
two strings into one. For example:

```
string s = "this is a phrase"
* and so is this;
```

These lines of code set the string variable s equal to this character string:

```
"this is a phrase and so is this"
```

The string with no characters, written "" (two double quotes or sometimes a null string),
is a valid string, called an empty string or a null string.
A null string ("") is different from a null char ('\0') and from a string
containing any amount of space, even one (" ").

I like to initialize strings using the String.Empty value, which means the
same as " and is less prone to misinterpretation:

```
string mySecretName = String.Empty; // Property of the String type
```

By the way, all the other types in this chapter are value types. The
string type, however, is not a value type, as I explain in the following
section. Chapter 3 of this minibook goes into much more detail about the
string type.

# What's a Value Type?

The variable types that I describe in this chapter are of fixed length — again
with the exception of string. A fixed-length variable always occupies the
same amount of memory. So if you assign a = b, C can transfer the
value of b into a without taking extra measures to handle variable-
length types. This characteristic is why types of variables are called
value types.

The types int, double, and bool, and their derivatives (like unsigned
int) are intrinsic types built right into the processor. The intrinsic
value types plus decimal are also known as value types because variables
store the actual data. The string is neither — because the variable\actually stores a sort of "pointer" to the string's data, called a reference. The
data in the string is actually off in another location.
