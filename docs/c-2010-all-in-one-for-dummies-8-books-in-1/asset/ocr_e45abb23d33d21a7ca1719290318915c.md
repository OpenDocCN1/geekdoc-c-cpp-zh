# Explicit type conversion — the cast

Imagine what happens if C# was wrong about implicit conversion and the programmer wanted to perform integer multiplication?

You can change the type of any value-type variable by using the cast operator. A cast consists of a type enclosed in parentheses and placed immediately in front of the variable or expression in question.

The following example uses the * int operator:

```
int aInt = 10;
double aDouble = 5.0;
int result = aInt + (int)aDouble;
```

The cast of aDouble to an int is known as an explicit demotion or downcast. The conversion is explicit because the programmer explicitly declared it. (Duh).

You can make an explicit conversion between any two value types, it's up or down the promotion ladder.

Avoid implicit type conversion. Make any changes in value types explicit by using a cast. Doing reduces the possibility of error and makes code much easier for humans to read.
