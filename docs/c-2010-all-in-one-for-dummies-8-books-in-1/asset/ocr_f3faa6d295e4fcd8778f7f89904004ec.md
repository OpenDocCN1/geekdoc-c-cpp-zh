About now, if you are anything like me, you have to be thinking: "This is a good thing. How!!" I hear you, you trust me. For the time being, you can blame COM.

You see, COM was mostly constructed using C++, which has a variant type. In C++, you could declare a variable to be dynamic, like this:

VARIANT newCourse;

It worked like the dynamic type, except C# wasn't invented yet. Anyway, because a lot of the objects in COM used Variant out parameters, it was really tough to handle Interop using .NET.

Because Microsoft Office is mostly of COM objects, and it isn't going to change any time soon, and Microsoft wants us all to be Office developers one day, we have the dynamic type.

With a dynamic type, though, we are golden once again, with this code:

