# Using the Trim() and Pad() methods

I show earlier to use Trim() and its more specialized variants,
TrimFront() and TrimEnd(). Here, I discuss another common method for formatting output. You can use the Pad methods, which add characters to either end of a string to extend the string to some predetermined length. For example, you may add spaces to the left or right of a string to left-right justify, or you can add " characters to the left of a currency number, and so on.

The small AlignOutput program uses Trim() and Pad() to trim and justify a series of names:
