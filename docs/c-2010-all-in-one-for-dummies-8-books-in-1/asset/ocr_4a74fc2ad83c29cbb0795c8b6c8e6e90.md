After this code, unique() excludes its own items in queue (1, 3, 5, 7, and 9) and also excludes items in queue that aren't in unique (0, 2, 4, 6, 8, and 17). You end up with 11, 13, and 15 in unique.

Meanwhile, the next code segment uses the SymmetricExcept() method to create the opposite result from IntersectWith(). Whereas intersection uses only the overlapping items. SymmetricExceptWith() gives you the items in both lists that don't overlap. The UniqueToSet your items ending up contains 5, 3, 11, and 10:

```
Console.WriteLine("Finding just the non-overlapping items in two lists:");
Stack<int> stackOne = new Stack<int>(new int[] { 1, 2, 3, 4, 5, 6, 7, 8 });
Stack<int> stackTwo = new Stack<int>(new int[] { 2, 4, 6, 7, 8, 10, 12 });
HashSet<int> nonoverlapping = new HashSet<int>(stackOne);
// the other collects items that are in one collection but not
nonoverlapping. SymmetricExceptWith(stackTwo);
foreach(int n in nonoverlapping)
{
    Console.WriteLine(n.ToString());
    Console.WriteLine("Press Enter to terminate...");
    Console.Read();
}
```

My use of stacks is a bit unorthodox because I add members at time rather than push each one, and I remove a bunch at a time rather than pop each one. These operations — pushing and popping — are the correct ways to interact with a stack.

Notice that the HashSet<...> methods demonstrate are void methods — they don't return a value. The results are reflected in the hash set on which you call these methods: nonoverlapping in the preceding code example.

We found the benefit of UnionWith() and IntersectWith() a bit awkward at first I wanted a new result, with the original (input) sets remaining the same when I applied these methods. In Book II we met (I'm happy to report) the new LINQ query operators, which added versions of these methods to return a whole new set. When would you use HashSet<>? Any time you're working with or more collections and want to find items as the overlap — or create a collection that contains two other collections or exclude a group of items from a collection — sets can be useful. Many of the HashSet<T> methods can relate sets and other collection classes. You can do more with sets of course, so look up the term HashSet<T> in Help and play with HashSetExample.
