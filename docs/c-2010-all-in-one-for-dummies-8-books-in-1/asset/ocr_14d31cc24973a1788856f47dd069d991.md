# Building code based on outside data

The more powerful use of T4 is to reference outside data to set up code templates. This can be metadata about a project like supporting files that need to be referenced, or direct data like the previous project Web site example.

Let's look at project metadata for a moment. MVC4WOF is an open source project that I participate in, and it uses this metadata in the form of contract files to generate code. (Check it out at New .www.mvc4wpf.com.)

In a classic example of an automation pattern, MVC4WPF's New Dialog box (see Figure 4-1) checks with the user to get the contract (in the form of an interface) that is being referenced for the given Model, View, or Controller generated.

This allows T4 to parse through the interface, grab pertinent information, and add to the result file.
