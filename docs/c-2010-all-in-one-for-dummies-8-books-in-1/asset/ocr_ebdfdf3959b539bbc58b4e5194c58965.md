Main() in this case creates a BankAccount object with an initial balance of $200 and then withdraws $100. Main() repeats the trick with a SavingsAccount object. When Main() withdraws money from the base class, BankAccount.Withdraw() performs the function call with great abound. When Main() withdraws $100 from the savings account, the method SavingsAccount.Withdraw() takes on the $1.50.

Notice that the SavingsAccount.Withdraw() method uses BankAccount.Withdraw() rather than manipulate the balance directly. If possible, let the base class maintain its own data members.
