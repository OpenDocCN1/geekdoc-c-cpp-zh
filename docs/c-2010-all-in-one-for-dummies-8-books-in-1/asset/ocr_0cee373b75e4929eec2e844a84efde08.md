The program reads the principal from the user. If the principal is negative, the program outputs an error message and quits. If the principal is not negative, control passes to the else clause, where the program continues executing.

The interest rate has been improved in this example. Here, the program requires an interest rate that's nonnegative (a mathematical law) and less than a maximum rate (a judiciary law—I can only wish that credit cards had an interest rate limit). If this statement uses the compound test:

```
if (interest < 0 || interest > maximumInterest)
```

This statement is true if interest is less than 0 or greater than maximumInterest. Notice that I declare maximumInterest at the top of the program rather than hard-code it as a constant number. Hard-coding refers to using values directly in your code, rather than creating a constant to hold them.

Define important constants at the top of your program. Giving a constant descriptive name (rather than just a number) makes it easy to find and easier to change. If the constant appears times in your code, you will have to make only one change to change all references.
