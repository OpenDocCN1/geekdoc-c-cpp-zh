Let's add a label to MainWindow.xaml that displays the purpose of the
String we defined in our Resources. Just follow these steps:

+   1. Open MainWindow.xaml.

+   2. Between the Grid tags, define a grid with a single row and single
column by adding the following XAML markup:

```
<Grid>
  <Grid.ColumnDefinitions>
    <ColumnDefinition />
  </Grid.ColumnDefinitions>
  <Grid.RowDefinitions>
    <RowDefinition />
  </Grid.RowDefinitions>
</Grid>
```

Each column and row is defined by the ColumnDefinition
and RowDefinition element within the Grid.
ColumnDefinitions and Grid.RowDefinitions properties,
respectively. If you add more columns, you simply add
another ColumnDefinition element to the Grid.ColumnDefinitions
Property Entity. The same goes for rows: add an additional
RowDefinition element to the Grid. RowDefinitions Property Entity.

+   3. Directly below the Grid.RowDefinitions Property entity, create a
tabel using the following XAML:

```
<x:Name="lblPurpose" Content="StaticResource Purpose" />
FontSize="25" Grid.Row="0" />
```

This instantiates a WPF Label object accessible to the code-
behind (MainWindow.cs) using the variable lblPurpose.
The Content contains the text that is to be displayed in the
label; in this case, we use the Application Resource that we defined
the preceding section by retrieving it using its key value, which
The Label is rendered with a font size of 25 units and it is
located in the grid in first row and first column.

WOW! That line of XAML really packs quite the punch! Let's review some
what is going on there:

+   x:Name: This attribute assigns a variable to the object being cre-\ated by the XAML tag. This enables you to use the object from thencode-behind file. In this case, the variable name of the label being
instantiated is lblPurpose.

+   Content: The value assigned to this attribute can be of any type.
By default, you can assign a string value and it will render as you would
th a standard label would render. In the WPF reality, Content can be
composed of: a string, an image, an instance of user control, a
text box, and so forth. For more, see Chapter 2 of this minibook.
