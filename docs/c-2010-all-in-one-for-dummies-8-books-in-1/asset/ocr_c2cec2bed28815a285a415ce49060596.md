# New feature: Initializing an object without a constructor

Suppose that you have a little class to represent a Student:

```
public class Student {
    public string Name { get; set; }
    public string Address { get; set; }
    public double GradePointAverage { get; set; }
}
```

A Student has three public properties, Name, Address, and GradePointAverage, which specify the student's basic information.

Normally, when you create a new Student, you have to initialize its Name, Address, and GradePointAverage properties like this:

```
Student randal = new Student();
randal.Name = "Randall Spar";
randal.Address = "123 Elm Street, Truth or Consequences, NM 00000";
randal.GradePointAverage = 3.5;
```

(Yes, Virginia, there is a Truth or Consequences, New Mexico. My nephew Randall was born there.)

If Student had a constructor, you could do something like this:

```
Student randal = new Student();
("Randall Spar", "123 Elm Street, Truth or Consequences, NM 00000", 3.5);
```

Sadly, however, Student lacks a constructor, unlike the default in C# which initializes automatically — which takes no parameters.

In C# 3.0 and later, you can simply that initialization with something that looks suspiciously like a constructor — well, sort of:

```
Student randal = new Student()
{ Name = "Randall Spar";
  Address = "123 Elm Street, Truth or Consequences, NM 00000";
  GradePointAverage = 3.5;
}
```
