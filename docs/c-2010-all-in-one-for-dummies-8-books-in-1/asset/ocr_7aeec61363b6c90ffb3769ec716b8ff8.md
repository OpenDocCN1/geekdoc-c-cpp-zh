# Putting Your Classes into Class Libraries

The simplest definition of a class library project is one whose classes contain no Main() method. Can that definition be correct? Can the existence of Main() distinguishes class library from an executable. C# libraries are much easier to write and use than similar libraries were in C or C++.

The following sections explain the basic concepts involved in creating your own class libraries. Don't worry; C# does the heavy lifting. Your end of it is quite simple.

Even the free Visual# 2010 Express Edition can now create class libraries. It needed to use a small hack to make it work.

# Creating the projects for a class library

You can create the files for a new class library project and its driver in either of two ways:

+   * Create the class library project first and then add the driver project to its solution. You might take this approach if you were writing a standalone-class library assembly. I describe how to create the class library project in the next section.
* Create a driver program first and then add one or more library projects to its solution. Thou might first create the driver program as a console application or a graphical Windows Forms (or Windows Presentation Foundation) application. Then you would add class library projects to that solution.

# Creating a stand-alone class library

If your purpose is to develop a stand-alone class library that can be used in various other programs, you can create a solution that contains a class library project from scratch — here's how it is:

+   1. Create a new project.

+   2. When you pick the template to base it on in the New Project dialog box, select Class Library (rather than, Console Application).
