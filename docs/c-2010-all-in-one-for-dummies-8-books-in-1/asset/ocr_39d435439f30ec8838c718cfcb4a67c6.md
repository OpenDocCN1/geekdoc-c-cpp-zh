The default place to store this file is somewhere in your Documents directory. Maybe because I'm difficult (or maybe I'm writing a book), I like to put programs where I want to go, not necessarily where Visual Studio wants them. To simplify working with this, you can change the default program location. Follow these steps to make that:

+   a. Choose Tools:Options.

The Options box opens.

+   b. Choose Projects and Solutions:General.

+   c. Select the new location in the Projects Location field, and click OK.

(I recommend C:\#Programs for this book.)

You can create the new directory in the Projects Location dialog at the same time. Click the folder icon with a small sunburst at the top of the box. (The directory may already exist if you've installed the examples from the Web.

You can see the Options box in Figure 1-3. Leave the other fields in the project settings alone for now. Read more about customization of Visual Studio in book.

# 4. Click the OK button.

After a bit of whirring and chatter, Visual Studio generates a named file .cs. If you look in the window labeled Explorer, you see some other files; ignore them for now. If Solution Explorer is not visible, check View::Solution Explorer.

C source files carry the extension .cs. The name Program is the default assigned name for the program file.
