# Performing Logical Comparisons — Is That Logical?

C# provides a set of logical comparison operators, as shown in Table 4-2. These operators are logical comparisons because they return either or a false value of type bool.

| Table 4-2 Logical Comparison Operators |
| Operator | Operator Is True If |
| a == b | a has the same value as b |
| a > b | a is greater than b |
| a >= b | a is greater or equal to b |
| a < b | a is less than b |
| a <= b | a is less than equal to b |
| a != b | a is not equal to b |

This is an example that involves a logical comparison:

```
int m = 5;
int n = 6;
bool b = m > n;
```

This example assigns the value false to the variable b because 5 is greater than 6.
