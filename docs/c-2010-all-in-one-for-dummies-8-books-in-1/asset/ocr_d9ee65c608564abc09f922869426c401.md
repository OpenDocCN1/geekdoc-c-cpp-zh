# Breaking Down the Projects

All there is left to do after you have run the setup program and set your default settings is to start on a project and get your fingers dirty. All proj-jects (expect maybe one or two) in the first two minibooks were Console applications, meaning they are meant to be run at the command prompt. There are a lot more projects available.

Notice three main kind of projects in the Visual Studio New Project dialog box.

+   * Windows projects are client applications that compile into EXEs and run on your computer. Microsoft Word is a Windows application.

+   * Web projects make Sites and require a Web server to run. (A Web server is included with Visual Studio for development purposes.) Microsoft.com is an example of a Web application.

+   * Special projects include things like setup projects (projects that build setup programs) and database projects (projects that give a framework for databases). They are usually used with Windows or Web applica-tion. The Setup.exe you run in the preceding section to install Visual Studio is an example of these special project — a setup project.

# Exploring the New Project dialog box

Let's start with a breakdown of the New Project dialog box, shown in Figure 1-2. This screen is an important part of the usability of Visual Studio. You can open it by clicking the New Project link on the setup page.

The section of the dialog box to the far left is a tree-view selector, similar to the one in Outlook. You have three options — Recent Templates, Installed Templates, and Online templates. Installed Templates is selected. These templates, as Visual Studio calls them, are project types.

Within the selector is a WPF style tree viewer. Instead of maples and oaks, this tree has all the project categories described in upcoming sec-tions of this chapter.

If you click, for the Visual C option in the tree view, all the proj-ects for Visual C# appear in the window just to the right. If you click one of the suboptions, just those project types — for Visual C#—appears.

To specify version of the .NET Framework you would like to develop for, you can use the drop-down list just above the project list that says .NET Framework 4.0. To change the sorting options, use the Sort By: drop-down list directly to the right. One more step to the right and you can change your view options.
