# 384 Putting Your Classes into Class Libraries

If you need to give the library project the same name as another project or even the main project, you can distinguish it by appending the suffix Lib, as in MyConversionLib.

![](bbox=[0.156, 0.217, 0.497, 0.343])

If the project you're adding is intended to stand on its own and be usable by other programs, use the side-by-side approach.

The ClassLibrary example in this section (like most examples in this book) takes the all-in-folder approach. The point is that although the folders don't have to be in the same place, putting them can be convenient.

The task of selecting the location is independent of adding the new project directly to the ClassLibrary solution. The two project folders can be in the same solution while still being located in different places.
