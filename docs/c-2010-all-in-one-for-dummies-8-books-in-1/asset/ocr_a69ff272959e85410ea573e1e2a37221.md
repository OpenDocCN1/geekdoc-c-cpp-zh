# Looping Around the Iterator Block 151

You can use iterator blocks for a host of other chores, too, as I show you in the next example.

The best approach to iteration now uses iterator blocks. When you write a collection class -- and the need still exists for custom collection classes such as KeyList and PriorityQueue -- you implement an iterator block in your code rather than implement the IEnumerator interface. Users of that can simply iterate the collection with foreach. I walk through it a piece at a time, to show you several variations on iterator blocks.

Every example in this section is part of the IteratorBlocks example on this book's Web site:

```
// IteratorBlocks -- Demonstrates using C# 2.0 iterator
// block approach to writing collection iterators
using System;
namespace IteratorBlocks
class IteratorBlocks
{
    //Main Demonstrate five different applications of
    // iterator blocks.
    static void main(string[] args)
    {
        // Instantiate a MonthDays "collection" class.
        MonthDays md = new MonthDays();
        // Iterate it.
        Console.WriteLine("Stream of months:\n");
        foreach (string month in md)
        {
            Console.WriteLine(month);
        }

        // Instantiate a StringChunks "collection" class.
        StringChunks sc = new StringChunks();
        // Iterate it; it puts each chunk on its own line.
        Console.WriteLine("\nstream of string chunks:\n");
        foreach (string chunk in sc)
        {
            Console.WriteLine(chunk);
        }
        // And this iteration puts it all on one line.
        Console.WriteLine("\nstream of string chunks on one line:\n");
        foreach (string chunk in sc)
        {
            Console.Write(chunk);
        }

        // Instantiate a YieldBreak "collection" class.
        YieldBreak yb = new YieldBreak();
        // Iterate it; but stop after 13.
        Console.WriteLine("\nstream of primes:\n");
        foreach (int prime in yb)
        {
            Console.WriteLine(prime);
        }
}
```
