The following code (excerpted from the example) shows how to instantiate a new, empty list for the string type. In other words, this list can hold only strings:

```
// List<T>: note brackets plus parentheses in
// List<T> declaration; T is a 'type parameter',\n// List<T> is a 'parameterized type'.
List<string> names = new List<string>();
list.Add("one");
list.Add(3);
list.Add(new Student("Du Bois")); // Compiler error!
```

You add items to a List<T> by using its Add() method. The preceding snippet successfully adds one string to the list, but then it runs into trying to add an integer and then a Student. The list was instantiated for strings, so the compiler rejects both attempts.

The next code fragment instantiates a completely new list for int and adds two values to the list. Afterward, the foreach loop iterates the int list, printing the outs:

```
// Instantiate for int.
List<int> list = new List<int>();
list.Add(3);                                // Fine.
list.Add(4);
Console.WriteLine("Printing list:");
foreach (int i in list) // foreach just works for all collections.
    Console.WriteLine("int i " + i + "");
```

The following bit of code instantiates a new list to hold Students and adds two students with Add() method. But notice the array of Students, which I add to the list using AddRange() method. AddRange() lets you add an array (or almost) any collection to the list, all at once:

```
// Instantiate for Student.
List<Student> studentList = new List<Student>();
student1 = new Student("Vigi");
student2 = new Student("Finch");
studentList.Add(student1);
studentList.Add(student2);
students[0] = new Student("Fox");
studentList.AddRange(students); // Add array to List.
Console.WriteLine("number of students in list = " + studentList.Count);
```
