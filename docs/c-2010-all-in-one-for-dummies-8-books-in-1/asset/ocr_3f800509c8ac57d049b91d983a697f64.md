# 672 Data Binding

+   1. In the Chapter 3 Web project that we have been adding pages with controls to, right-click and choose Add New and then Class.

I named my class Show.

+   2. Click OK, and then put this simple data class in there. This class is just for example — it could be a database or a data class or an Entity Framework model.

```
using System;
namespace Chapter_3 {
    public class Show {
        public int ID { get; set; }
        public String ShowTitle { get; set; }
        public String EpisodeTitle { get; set; }
        public DateTime ScheduledTime { get; set; }
        public int Channel { get; set; }
    }
}
```

+   3. Open the Text.aspx in the Chapter 3 project.

+   4. Double-click the design surface to get the code-behind.

If any code already appears in the Page.Load, you can delete it.

+   5. Add code to the Page.Load, to make a Mock Object.

In a real project, you would get this object from the database or the server layer. For this example, I just use mock code:

```
protected void Page_Load(object sender, EventArgs e) {
    Show show = new Show { ID = 1, Channel = 5, EpisodeTitle = "ASP.NET Databinding", ScheduledTime = new DateTime(2009, 4, 12, 12, 0, 0), ShowTitle = "The C# Show" };
    Page.DataBind();
}
```
