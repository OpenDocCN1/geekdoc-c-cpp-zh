Notice the Balance property in BankAccount, which has a public getter but a protected setter. Using protected here prevents us from outside outside BankAccount but permits using the protected setter in subclasses, which occurs in SavingsAccount.AccumulateInterest, with Balance on the left side of the assignment operator.
