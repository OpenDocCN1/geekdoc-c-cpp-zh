# Consuming

All there is left to do is use it.

As one would expect, setting up service reference for a WCF service is a lot like setting up a reference for an ASMX service. You still right-click and select Add Service Reference, you still get the dialog box in Figure 3-9, and you still can reference the service easily in your code.

Two things to remember:

+   - The file extension you are looking for is `.svc`.
- The binding you use is abstracted away from you.

The filename thing is workable, but the binding is important. Keep in mind that the selecting of a binding is invisible to the developer, but it has a significant impact on functionality and especially performance. The decision of which to use is not to be made lightly; it should be done only after much research and needs analysis.
