# How to publish an event

When the publisher decides something worthy of publishing to all sub-
scribers, it raises (sends) the event. This situation is analogous
to a real newspaper putting out the Sunday edition.

To publish the event, the publisher would have code like this one of
its methods (but see the later section "Recommended to raise your
events")

```
NewEditionEventArgs e = new NewEditionEventArgs(args to constructor here);
NewEdition(this, e); // Raise the event -- 'this' is the publisher object.
```

Or for the Button event, though this is hidden in class Button:

```
EventArgs e = new EventArgs(); // See next section for this topic.
Click(this, e);                                 // Raise the event.
```

In each of these examples, you must set up the necessary arguments — which
differ from event; some events need to pass a lot of info. Then
you raise the event by "calling" its name (like invoking a delegate):

```
eventName(argumentList); // Raising an event (distributing the newspaper)
NewEdition(this, e);
```
