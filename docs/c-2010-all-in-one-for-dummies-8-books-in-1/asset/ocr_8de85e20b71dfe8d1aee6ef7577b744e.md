# Coding in Code View

Really, what would you do in Code View? Nothing, that’s what!

There is a lot to the Code Viewer in Visual Studio. Fact is, this is where you will spend 75 percent of your time, and boy, you will be glad that it works well.

Code Viewer has two primary tools:

+   * **The Code Viewer itself:** The first is the screen on which you edit the code — the Code Viewer.
* **Auxiliary windows:** The second are the little auxiliary windows that do a lot of useful things that do not directly relate to the code.
