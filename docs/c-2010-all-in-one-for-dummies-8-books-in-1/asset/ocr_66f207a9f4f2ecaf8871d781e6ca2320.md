Still, C packs a fair amount of power into the System.Drawing classes. Though these classes are somewhat primitive in some areas, and they might cause you to have to write a few more lines of code than you would, there isn't much that these classes can't do with sufficient work.

The drawing capability provided by the .NET Framework is divided into four logical areas by the namespace designed by Microsoft. All the general drawing capability is in the System.Drawing namespace. Then there are specialized namespaces:

+   - System.Drawing.2D has advanced vector drawing functionality.
- System.Drawing.Imaging is mostly about bitmap graphic formats, like .bmp and .jpg files.
- System.Drawing.Text deals with advanced typography.

In this chapter, I focus on the base namespace and cover only the basics of drawing in C#. (Discussing every aspect of drawing could easily fill an entire book.
