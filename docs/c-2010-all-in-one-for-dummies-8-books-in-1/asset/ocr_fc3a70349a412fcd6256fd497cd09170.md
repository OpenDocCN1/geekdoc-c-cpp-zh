The Directory class gives the user a set of methods for manipulating directories. The FileInfo class provides methods for moving, copying, and deleting files, among other tasks.

Stepping through Collections

The program creates a list of all files in the specified directory by calling GetFileList(). This method returns an array of FileInfo objects. Each FileInfo object contains information about a file — for example, the filename (with the full path to the file, FullName, or without the path), the creation date, and the last modified date. Main() iterates through the list of files using your old friend, the foreach statement. It displays the name of each file and passes the file to the DumpHex() method for display to the console.

At the end of the loop, it allows the programmer to gaze at the output from DumpHex().

The GetFileList() method begins by creating an FileInfo list. This is the one entry in the returns of an event.

Here's a neat trick to remember when calling Get...List(): If an error occurs, it displays an error message and returns a zero-length list.

![](bbox=[0.133, 0.533, 0.203, 0.643])

Be careful about returning a reference to an object. For instance, do not return a reference to one of the underlying queues wrapped in a PriorityQueue class, unless you want to invite leaks with those queues through the reference instead of using your class methods, that is. That's a ticket to a corrupt, unpredictable queue. But GetFileList() doesn't expose the hazards of one of your classes, so it's okay.

GetFileList() then creates a DirectoryInfo object. As its name implies, a DirectoryInfo object contains the same type of information about a directory that a FileInfo object does about a file: name, rank, and serial-number-type stuff. However, the DirectoryInfo object has access to thing that FileInfo doesn't: a list of the files in the directory, in the form of a FileInfo array.

As usual, GetFileList() wraps the directory and file-related code in a big block. The catch at the end traps any errors that are generated. Just to embarrass you, the further catch blocks the name of the directory (which probably doesn't exist, because you entered it incorrectly).
