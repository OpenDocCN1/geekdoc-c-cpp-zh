Checking to see if PropertyChanged is not null essentially means we are checking to see if anyone is listening (subscribed) to the PropertyChanged event.

10. Now you need to modify the Set methods in each of the public properties on the Dax object to call the NotifyPropertyChanged helper method each time the property value has changed. Edit the public properties like this:

```
public string Make
  get { return _make; }
  set {
    if (_make != value)
      _make = value;
      NotifyPropertyChanged("Make");
    }
  }
```

```
public string Model
  get { return _model; }
  set {
    if (_model != value)
      _model = value;
      NotifyPropertyChanged("Model");
    }
  }
```
