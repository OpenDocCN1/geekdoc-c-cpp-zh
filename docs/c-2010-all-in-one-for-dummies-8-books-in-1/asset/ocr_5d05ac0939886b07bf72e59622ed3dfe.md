# Converting some more temperatures

Here's the formula for converting Fahrenheit to Celsius temperatures using floating-point variables:

```
double celsius = (fahr - 32.0) * (5.0 / 9.0)
```

# Examining some limitations
oflo-point variables

You may be tempted to use floating-point variables all the time because they solve the truncation problem so nicely. Sure, they use a bit more memory. Memory is cheap these days, so why not? Floating-point variables also have limitations, which I discuss in the following sections.

# Counting

You can't use floating-point variables as counting numbers. C structures need to count (as 1, 2, 3, and so on). You know that 1.0, 2.0, and 3.0 are counting numbers just well as 1, 2, and 3, but C doesn't know that. For example, given the accurate limitations of floating-points, how does C know you aren't actually saying 1.0000001?

Whether you find argument convincing, you can't use a floating-point variable when counting things.

# Counting numbers

You have to be careful when counting floating-point numbers. For example, 12.5 may be represented as 12.500001. Most people don't care about little extra bit on the end. However, the computer takes things extremely literally. To C#, 12.500000 and 12.500001 are not the same numbers.
