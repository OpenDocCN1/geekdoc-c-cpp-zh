# An example

You can see how the for loop works in this example:

```
// Here is one C# expression or another.
a = 1;
// Now loop for awhile.
for(int year = 1; year < duration; year = year + 1)
{
    . . body of code . .
}
// The program continues here.
a = 2;
```

Getting into
Program Flow

Assume that the program has executed the a = 1; expression. Next, the program declares the variable year and initializes it to 1. Then the program compares year to duration. If year is less than duration, the program of code within the braces is executed. After encountering the closed brace, the program jumps back to the top and executes the year = year + 1 clause before sliding back over the year < duration comparison.

The for variable is undefined outside the scope of the for loop. The loop's scope links the header as well as body.

# Why do you need another loop?

Why do you need the for loop if C# has an equivalent while loop? The short answer is that you don't—the for loop doesn't bring anything to the table that the while loop cannot already do.

However, the sections of the for loop exist for convenience — and clearly establish the three parts that every loop should have: the setup, exit criteria, and increment. Not only is this loop easier to read, but it's also easier to get right. (Remember that the most common mistakes in a while loop are forgetting to increment the counting variable and failing to provide the proper exit criteria.)

Beyond any sort-and-dance justification that I may make, the most important reason to understand the for loop is that it's everyone uses — and (along with its cousin, foreach) is the one that uses 90 percent of the time when you are reading other people's code.

The for loop is designed so that the first expression initializes a counting variable and the last section increments it; however, the C# language does not enforce any such rule. You can do anything you want in these two sections — however, you will be advised to do anything but initialize and increment the counting variable.
