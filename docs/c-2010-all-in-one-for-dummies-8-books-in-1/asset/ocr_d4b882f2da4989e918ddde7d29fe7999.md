If you want to convert the first character in a string to uppercase?
The following rather convoluted code will do it (but you can see a better
in the last section of this chapter):

```
string name = "chuck";
string properName =
    Char.ToUpper(name[0]).ToString() + name.Substring(1, name.Length - 1);
```

The idea in this is to extract the first char in name (that's
name[0]), convert it to a one-character string with ToString(), and then
treack on the remainder of name after removing the old lowercase first char-
 with Substring().

You can tell whether a string is uppercase or lowercased by using this
scary-looking statement:

```
if (string.Compare(line.ToUpper(CultureInfo.InvariantCultureCulture),
     line, false) == 0) ... // True if line is all upper.
```

Here the Compare() method is comparing an uppercase version of line
to itself. There should be no difference if line is already uppercase.
You can puzzle over the CultureInfo.InvariantCulture gizmo in Help,
'cause I'm not going to explain it. For "Is it all lowercase," stick a stick to (!)
operator in front of the Compare() call. Alternatively, you can use a loop,
as in the next text.

# Looping through a String

You can access individual characters of a string in a foreach loop. The fol-
lowing code through the characters and writes each to the console
just another (roundabout) to write out your string:

```
string favoriteFood = "cheeseburgerers";
foreach(char c in favoriteFood)
{
    Console.Write(c); // Could do things to the char
}
Console.WriteLine();
```

You can use that to solve the problem of deciding whether favorite-
Food is all uppercase. (See the previous section for about case).
