    for(int index = 0; index < numBytes; index++)

## Getting hex

Like binary numbers (0 and 1), hexadecimal, or "hex", are fundamental to computer programming. In base 16, the digits are 0 through 9 and A, B, C, D, E, F — A=10, B=11...F=15. To illustrate (using the zero-x prefix to indicate hex):

0x2A = 42 decimal; 2*16 + A*1 (where A=10)

Alphabetic digits can be uppercase or lowercase: C is the same as c. It's weird, but quite useful, especially when you're debugging or working close to the metal with memory contents.

```text
0xD = 13 decimal
0x10 = 16 decimal; 1*16 + 0*1
```

### Stepping through Collections

The program creates a list of all files in the specified directory by calling GetFileList(). This method returns an array of FileInfo objects. Each FileInfo object contains information about a file — for example, the filename (with the full path to the file, FullName, or without the path), the creation date, and the last modified date. Main() iterates through the list of files using your old friend, the foreach statement. It displays the name of each file and passes the file to the DumpHex() method for display to the console.

At the end of the loop, it allows the programmer to gaze at the output from DumpHex().

The GetFileList() method begins by creating a FileInfo list. This is the one entry returns of an event. Here's a neat trick to remember when calling GetFileList(): If an error occurs, it displays an error message and returns a zero-length list.![](img/36596fb11aa4233d5cab0d6ddd1d82e8_164_1.png)

Be careful about returning a reference to an object. For instance, do not return a reference to one of the underlying queues unless you want to invite leaks with those instead of using your class, is. That's a ticket to corrupt. GetFileList() then creates a DirectoryInfo object. As its name implies, DirectoryInfo object contains the same type of information about a directory: name, rank, and serial-number-type stuff. However, the DirectoryInfo object has access to the files in the directory, in the form of an array. As usual, GetFileList() wraps the directory and file-related code. The DumpHex() method is a little tricky because of the difficulties in formatting the output just right. It displays every hexadecimal format as a single line. Every 20 lines, it pauses until the user presses Enter.
