This equation works just for some values. For example, 41 degrees Fahrenheit is 5 degrees Celsius.\Correct, Mr. Davis,” says Stephen’s sixth-grade teacher.

Okay, try a different value: 100 degrees Fahrenheit. Working through the equation, 100-32 is 68, 68 times % is 33. “No,” she says, “The answer is 37.78.\ Even that’s wrong because it’s 37.777... with the 7 repeating forever, but I don’t push the point

An int can represent only integer numbers. The integer equal of 37.78 is 37. This losing off of the fractional part of a number to get it into an integer variable is called truncation.

Truncation is not as much as rounding. Truncation loses off the fractional part. Goodbye. Rounding picks the closest integer value. Thus, truncating 1.9 results in 1. Rounding 1.9 results in 2.

For temperatures, 37 may be enough. It’s not like you wear short-sleeve shirts at 37.7 degrees pull on a sweater at 32 degrees. But integer truncation is unacceptable for many, if not most, applications.

Actually, the problem is much more than. An int cannot handle the ratio it always yields the value 0. Consequently, the equation in this example calculates celsius as 0 for all values of fahr. Even I admit it’s unacceptable.
