# Algorithm A-1: Conjugate gradient algorithm

```
Input: SPD matrix A, vector b, and left preconditioner L, termination criterion \(\epsilon\)
Output: Vector x such that \(Ax \approx b\)
r = b - Ax
while ||r|| >= \(\epsilon\) do
    z = L^{-1}r
    \(\rho = (r, z)\)
    if First iteration then
        p = z
    else
        p = z + \frac{\rho}{\rho'}p
    q = Ap
    \alpha = \rho/(p, q)
    x = x + \alpha p
    r = r - \alpha q
    \rho' = \rho
```
