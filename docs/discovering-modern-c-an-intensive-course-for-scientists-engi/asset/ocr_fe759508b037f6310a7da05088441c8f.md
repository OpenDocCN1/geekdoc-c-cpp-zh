The following small program using GLAS [29] will serve as a case study:

```
#include <glas/glas.hpp>
#include <iostream>

int main()
{
  glas::dense_vector< int > x( 2 );
  x(0) = 1; x(1) = 2;

  for (int i= 0; i < 3; ++i)
    std::cout << x(i) << std::endl;

  return 0;
}
```

Running the program in gdb yields the following output:

```
> gdb myprog
1
2
hello: glas/type/continuous_dense_vector.hpp:85:
T& glas::continuous_dense_vector<T>::operator() (ptrdiff_t) [with T = int]:
Assertion ‘i<size_’ failed.
Aborted
```
