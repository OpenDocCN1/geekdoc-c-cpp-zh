# 4.2.2.5 Using a Distribution

Distributions are parameterized with a random number generator, for instance:

```
default_random_engine re(random_device{}());
normal_distribution<> normal;
```

```
for (int i = 0; i < 6; ++i)
    cout << normal(re) << endl;
```
