# ## 4.2.2.4 Distribution Overview

As mentioned before, the distribution classes map the unsigned integers to the parameterized distributions. Table 4-2 summarizes the distributions defined in C++11. Due to space limits, we used some abbreviated notations. The result type of a distribution can be specified as an argument of the class template where 1 represents an integer and a real type. When different symbols are used in the constructor (e.g., n) and the describing formula (e.g., μ), we denoted the equivalence in the precondition (like m ≡ μ). For consistency’s sake, we used the same notation in the log-normal and the normal distribution (in contrast to other books, online references, and the standard).

| Name | Preconditions | Distributions Defaults | Result |
| :--- | :--- | :--- | :--- |
| uniform_int_distribution<IntType=a, b> | a <= b | p(x|a,b) = 1/(b-a+1) | (0, max) | [a, b] <= N |
| uniform_real_distribution<RealType=a, b> | a <= b | p(x|a,b) = 1/(b-a) | (0.0, 1.0) | [a, b] <= R |
| bernoulli_distribution(p) | 0 <= p < 1 | P(b|p) = { p if b = true; 1-p if b = false } | 0.5 | {true, false} |
| binomial_distribution<IntType=t, p> | 0 <= p <= 1 and 0 <= t | P(i|t,p) = (t choose i) * p^i * (1-p)^(t-i) | (1, 0.5) | N |
| geometric_distribution<IntType=p> | 0 < p < 1 | P(i|p) = p(1-p)^i | 0.5 | N |
| negative_binomial_distribution<IntType=k, p> | 0 < p < 1 and 0 < k | P(i|k,p) = (k+i-1 choose i) * p^k * (1-p)^i | (1, 0.5) | N |
| poisson_distribution<IntType=m> | 0 <= m == mu | P(i|mu) = e^(-mu) * mu^i / i! | 1.0 | N |
| exponential_distribution<RealType=lambda> | 1 < l == lambda | p(x|lambda) = lambda * e^(-lambda * x) | 1.0 | x > 0 <= R |
| gamma_distribution<RealType=alpha, RealType=beta> | 0 < a == alpha and 0 < b == beta | p(x|alpha, beta) = (1 / (beta^alpha * Gamma(alpha))) * x^(alpha-1) * e^(-x/beta) | (1.0, 1.0) | x > 0 <= R |
| weibull_distribution<RealType=a, b> | 0 < a and 0 < b | p(x|a,b) = (b/a) * (x/a)^(b-1) * exp(-(x/a)^b) | (1.0, 1.0) | x > 0 <= R |
| extreme_value_distribution<RealType=a, b> | 0 < b | | (0.0, 1.0) | R |
| | | | (continues) |
