# B.2.2 Debugging with Graphical Interface: DDD

More convenient than debugging on the text level is using a graphical interface like DDD (Data Display Debugger). It has more or less the same functionality as gdb and in fact it runs gdb internally (or another text debugger). However, we can see our sources and variables as illustrated in Figure B-1.

The screen shot originates from a debugging session of vector.unroll_example2.cpp from Section 5.4.5. In addition to the main window, we see a smaller one like that in Figure B-2, usually on the right of the large window (when there is enough space on the screen). This control panel lets us navigate through the debug session in a way that is easier and more convenient than text debugging. We have the following commands:

+   - **Run**: Start or restart the program.
+   - **Interrupt**: If our program does not terminate or does not reach the next break point, we can stop it manually.
+   - **Step**: Go one step forward. If our position is a function call, jump into the function.
