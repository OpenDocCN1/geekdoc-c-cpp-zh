# # TIMELINE

+   - **1912** — Alan Turing is born.

+   - **1934** — Turing graduates from King's College.

+   - **1938** — Turing graduates from Princeton University.

+   - **1939** — World War II begins.

+   - **1945** — World War II ends.

+   - **1950** — Turing develops the Turing test.

+   - **1952** — Turing loses his security clearance after being convicted of a crime for being homosexual.

+   - **1954** — Turing dies.

+   - **2009** — Britain's prime minister officially apologizes to Turing.

+   - **2013** — Queen Elizabeth II formally pardons Turing.
