By studying captured German intelligence, Turing also learned that the Enigma machine would never encipher a letter as itself. It would always be a different letter in a scrambled message. The Germans made their machine work this way on purpose, thinking it would make the messages harder to unscramble. But knowing a letter would never be coded as itself was a clue that Turing used to create cribs.
