# # GLOSSARY

+   - **cryptography**: the science of encoding or decoding information
+   - **deciphered**: turned code into normal text
+   - **enciphered**: turned normal text into code
+   - **fellow**: a scholar who works at a college

+   - **probability**: how likely something is to happen
+   - **statistics**: the scientific study of large amounts of numerical data
