[853–870] 如果 HTTP 请求成功，我们仍需检查 IPP 状态。我们在消息中搜索 Content-Length 属性。HTTP 标头关键字不区分大小写，因此小写和大写字符都需要检查。如果缓冲区空间不足，我们就调用 readmore，它会使用 realloc 扩大缓冲区。由于缓冲区地址可能改变，我们需要调整 cp，使其指向缓冲区中的正确位置。
