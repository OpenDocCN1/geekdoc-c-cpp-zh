本章详细检查了两个完整的程序：一个将打印作业发送到网络打印机的打印排队守护进程，以及一个可用于向排队守护进程提交打印作业的命令。这给了我们一个机会，看到我们在前几章中描述的许多特性在实际程序中的使用：线程、I/O 多路复用、文件 I/O、读取目录、套接字 I/O 和信号。
