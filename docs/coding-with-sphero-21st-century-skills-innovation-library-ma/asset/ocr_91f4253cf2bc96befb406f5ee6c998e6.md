# # A Sensitive Robot

A Sphero robot uses **sensors** to keep track of the way it moves. It can tell how fast it is going and in which direction it is moving. It knows if it hits another object or if it is falling through the air. You can use Sphero’s sensors to program it to react in different ways.

# ## Sphero’s Inventors

Inventors Ian Bernstein and Adam Wilson have always loved making robots. They teamed up in 2010 to create Sphero. They built the robot because they wanted to create something fun to control with their smartphones.
