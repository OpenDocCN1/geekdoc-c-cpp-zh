The preprocessor variable __MIC__ is defined when the code is targeted at a MIC device but not otherwise. Here it is used to ensure that the length of the array used to determine bandwidth to memory does not overflow on the Phi.

Table 7.2 reports bandwidth to memory for the AVX host and the Phi. The Phi realizes higher bandwidth by utilizing a wide interface to memory consisting of 16 channels. For estimating bandwidth, one byte copied is counted as two, a byte read and a byte written. The copy bandwidth appears to suffer on both the AVX host and the Xeon Phi because of write-back caching. The read bandwidth on the Phi is far short of the theoretical peak.9
