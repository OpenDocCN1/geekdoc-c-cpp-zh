# Balanced matrix partitions

If an m × n matrix is stored in column-major order, with a leading dimension
to column size in the array[], the (i,j)th entry of the matrix is a[i+j*m]. In
row-major order, the (i,j)th entry is a[j+i*n]. If the matrix is transposed and
stored in column-major order, the (j,i)th entry of the transposed matrix would be
at[j+i*n]. On a single computer, transposing a matrix is equivalent to switching
from column-major order to row-major order.
