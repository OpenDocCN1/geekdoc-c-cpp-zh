# A simple OpenMP program

The two OpenMP parallel regions, in the program that will be listed shortly, alternately call the following functions:

```
void addone(void *arg){
  long *p = (long *)(arg);
  *p += 1;
}

void addtwo(void *arg){
  long *p = (long *)(arg);
  *p += 2;
}
```

The functions receive a pointer to a long cast to void *, dereference it, and then add 1 or 2 to the long location. It would course be simpler to add 1 and 2 directly without having to call functions that work through pointers. The OpenMP parallel regions invoke these functions to preserve a close analogy to the Pthread implementations. The Pthread implementations also use these two functions.

Here is the OpenMP program with two parallel regions.

```
void ompmaster(long *list, int nthreads, int count){
  for(int i=0; i < count/2; i++){
    #pragma omp parallel
      num_threads(nthreads)
      default(list)
      {
        int j = omp_get_thread_num();
        addone((long *)(list+j));
      }
    #pragma omp parallel
      num_threads(nthreads)
      default(none)
      shared(list)
      {
  }
```
