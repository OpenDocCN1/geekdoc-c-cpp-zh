The class FastTrans is similar to Transpose in many ways, although there are some changes. In the private section, two new items appear: sender and rcvd_list. These are used by the member function transpose() to order sends and keep track of receives.

In the public section, the member functions postsend() and postrecv() take the argument q. The send and receive requests are no longer initiated simultaneously. The member function transpose() orders sends and receives to overlap network activity with processor activity.
