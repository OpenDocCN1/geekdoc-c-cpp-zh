The sources leibniz.c and logeries.c include the header aitken.h with a different intent. Their intent is to obtain license to make calls to the functions aitken() and aitkenExtrapolate().

The header file acts as an interface, and it is natural, as well as typical, to include comments in it about the functions declared in it and about what those functions do. In this book, there are few comments in the code listings. The comments are instead found in the text.

The function aitken() (line 3) applies one step of Aitken transformation (1.1) to the array seq1[..len-1] and leaves the result in the array seq2[..len-3]. The function aitkenExtrapolate() (line 4) applies the Aitken transformation repeatedly to the array seq1[..len-1] while using seq2[] as scratch space, until only one or two numbers are left. One of the remaining numbers is returned as the extrapolated value.

At the beginning of aitken.h and, at the end, three lines (1, 2, and 6) begin with the special character #. These lines are directives to the macro preprocessor, of the initial phases of compilation. Sources are manipulated textually by the preprocessor

The source file leibniz.c includes aitken.h using a #include directive. The compiler is issued leibniz.c, the initial processing stage handles the #include directive. When processing, the file aitken.h is opened by the preprocessor. The first directive in file (#ifdef line 1) asks the preprocessor to check whether a name is already defined. If aitkenJuly09DVsfe is not defined, the line (#define directive) asks splices in all the text between the second and last lines of aitken.h (lines 3 to 5) into the source file that includes the "aitken.h" directive. The splicing into leibniz.c is done at the point where the #include directive was issued.

However, if such a name is already defined (the header file was included by an earlier directive), it skips everything until it sees a #endif directive (line 6); in this case, it would be skipping the entire aitken.h file.

Using #ifndef, #define, and #endif directives ensures that if a directive to include the same header file issued by the same source file, the second directive has no effect.
