# 2.3. Building programs using GNU Make

```
void array_in(double *v, int size, const char* fname);
```

The functions are defined in utils.cpp. Most of the declarations are self-explanatory.
The function array_max() takes the absolute values of n entries of v and returns
tmaximum. The function array_out() interprets v as an m x n matrix in column-major order and outputs it to a file. These functions are used for testing and timing.
Another function is declared in utils.hs and defined in utils.cpp. This is the following:

```
void verify_dir(const char *dir);
```

This uses Linux system calls to verify whether dir is already present, and if not, it creates such a directory. Linux system calls are declared in the header file unistd.h. A basic familiarity with system calls is of much value in programming.\nPrograms must be tested as extensively as possible. Although details of testing are normally omitted, we give a single example here, to illustrate how some of the modules in utils/ are used and partly to set up system calls of recursive make.
