# Offloading to multiple MIC devices

On systems with multiple MIC devices, the host may offload parts of the computation to each device and keep a portion to itself. The most natural way to do that is to split an array v[] to each MIC device.
The offload syntax for splitting an array across several devices is uncomplicated. However, the correspondence is set up between host and MIC pointers is a little subtle. The opening fragment of the function leibniz4() is as follows:

```
void leibniz4(){
    int mic;
    mic_init(mic);
    long n = 11*1000*1000*800;
    long nbytes = n*8;
    double* v = (double *)_mm_malloc(nbytes, 64);
    leibniz_init(v, n);
}
```

Here sum[] is an array with many entries as the number of MIC devices. Each MIC device will leave its part of the sum in one of the entries of the array.
