# Chapter 7. Special Topic: The Xeon Phi Coprocessor 499

Each core of the Xeon Phi implements the AVX-512 instruction set (see table 3.1), which is yet to make its way into mainline x86 computers. The AVX-512 instruction set is an enhancement of the AVX2 instruction set used in mainline x86 computers. The AVX-512 instruction set features 512-bit ZMM registers, twice the size of YMM registers in AVX/AVX2.

In addition, each core of the Xeon Phi has a hardware thread picker. During each cycle, the thread picker picks one of four or fewer threads mapped to any particular core. The thread picker prefers to schedule in round-robin fashion and never picks the same thread in two successive cycles. Therefore, the natural number of threads to use (on a 61-core Phi) in OpenMP programs is $4 × 61 = 244$ and not 61, as we explain in section 7.1.

Section 7.1 also explains how to run programs on the Phi in native. In native mode, one can log onto the Phi device like any computer and run programs on it we can. In the beginning days, the native mode is not very stable, but when it can be a great convenience. Many OpenMP programs can be made to run on the Phi with no changes besides compiling with the -mmic flag.

Another way to run programs on the device is in the offload mode. This mode, which has been perfectly stable from the beginning, requires modifications to the C/C++ source. New syntax is used to send parts of the computations to the Phi devices. The offload mode is the topic of section 7.2.

Section 7.3 discusses two main examples. The first example is the Fast Fourier Transform (FFT). For $n=8,192$, the Phi is not as fast as its AVX host. However, already for $n=2.7$ GHz AVX host (see table A.1 for the full name of the machine). For $n=2^{28}$, the AVX host is eight times faster, suggesting that the MKL library is not yet optimized for the Phi.

As discussed in chapter 3, the most important optimizations for scientific algorithms are the FFT optimizations. The second example in section 7.3 is a discussion of instruction pipeline optimizations for matrix multiplication. We show how to write a program that gets nearly 50% of the peak floating point capability of a Phi device. The discussion brings out some features of the AVX-512 instruction set that are not found in the SSE2 instruction set used in chapter 3. However, not all the techniques in that chapter can be repeated. The discussion only goes far enough to indicate that the application of those techniques would result in a matrix multiplication routine that reaches 85% of peak bandwidth like Intel's MKL library.
