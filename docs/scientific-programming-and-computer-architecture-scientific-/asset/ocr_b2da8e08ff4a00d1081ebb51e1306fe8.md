There are 32 ZMM registers, each of them 64 bytes or 512 bits wide. The Phi supports all the general-purpose registers such as %rdi, %rdx, and %rax. The thread register file is replicated for each of the four threads on any coprocessor core.

Figure 7.4 is a more detailed depiction of the Xeon Phi pipeline. The thread picker picks one of four threads every cycle. The next stage in the pipeline executes instructions. Instructions that use general-purpose registers are sent to either the U- or V-pipe. Both these pipes are part of the Vector Processing Unit (VPU) extension of the coprocessor core. The U-pipe can execute all instructions except a few. Notice that the Add/Mul unit of the U-pipe has four cycle latency, which is the same as the number of threads. So if each issues an Add/Mul instruction every cycle in round-robin scheduling, that one can be kept busy. Because the V-pipe is separate from the U-pipe, the coprocessor core can issue two vector instructions in the same cycle.
