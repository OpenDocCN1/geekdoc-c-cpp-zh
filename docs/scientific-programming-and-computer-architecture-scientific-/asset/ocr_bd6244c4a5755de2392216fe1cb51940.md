# 3.2.2 Loop unrolling

A program to compute the nth partial sum of the Leibniz series follows:

```
//sum of first n terms of 4(1-1/3+1/5-1/7+1/9-...)
double leibniz(long int n){
    long i;
    double ans;
    for(i=0; i < n; i++)
        if(i==0)
            ans = 4.0;
        else if(i%2==1)
            ans -= 4.0/(2.0*i+1);
        else
            ans += 4.0/(2.0*i+1);
    return ans;
}
```

This function will run for large values of n, such as $n=10^9$ or $10^{10}$. With $n=10^9$, the partial sum is generated in a few seconds.

Normally, if a program is compiled with optimizations turning on, the resulting code can be two to three times faster. This speedup is not only because the compilers are clever, which they sometimes are, but also because the unoptimized code can be long and roundabout.
