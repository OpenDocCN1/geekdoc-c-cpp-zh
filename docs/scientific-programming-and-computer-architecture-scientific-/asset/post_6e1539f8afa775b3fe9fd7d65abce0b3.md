Object-oriented programming can be done in plain C as well as using function pointers. However, it becomes far more laborious. Object-oriented techniques do not really come up in this book, although we use templates on this occasion in chapter 8. Therefore, we include the following basic example of a template function:

```cpp
template<class Num> Num sum(*arr, int len){
  Num ans;
  ans = 0;
  for(int i=0; i < len; i++)
    ans += arr[i];
  return ans;
}
```

In this function, Num is a generic class or type. It can stand for int or double or some user-defined class that overloads the operator += and supports addition. If the template is instantiated by setting Num to a user-defined class, it must also support the empty constructor (line 2) as well as assignment to zero (line 3).

A template function may be invoked as shown below.

```cpp
int x[5] = {1, 2, 3, 4, 5};
cout<<"1" + 5 << " = "<<sum(x, 5)"<<endl;
double y[5] = {6, 7, 8, 9, 10};
cout<<"6" + 10 << " = "<<sum(y, 5)"<<endl;
```

A template function is called just like an ordinary function as evident from the invocations of sum() on lines 2 and 4. Because x[] is an array of ints, the C++ compiler replaces the generic type Num by int to generate code for a new function. On line 2, sum(x,5) invokes that function. However, sum(y,5) on line 4 invokes a quite different function generated by replacing Num by double.

## 1.3.2 Aitken transformation in C++

The source files Aitken.cpp, Leibniz.cpp, and Logseries.cpp contain the C++ implementation of the Aitken transformation and its application to the Leibniz and log series. The listing below is one of the C++ header file Aitken.hh.

```cpp
1 #ifndef AitkenAugust09DVjli
2 #define AitkenAugust09DVjli
3 #include "Vector.h"
4 void Aitken(const Vector& seq1, Vector& seq2);
5 void Aitken(Vector& seq);
6 double Aitken(const Vector& seq, int printflag=0);
7 #endif
```

This header file declares three functions, two of which have the same name. The function name Aitken is overloaded, with (v,w), where v and w are both Vectors. After the call, the const in the first declaration guarantees that v is not changed. The use of const simplifies the documentation of this function. The other way to make the function call takes the name Aitken(v). In this later use, the transformed sequence overwrites the original data, and the last entries are set to 0. We can get away with using the same name for different functions because the compiler can tell them apart by looking at the list of arguments.

Although there is just one declaration for Aitken() (line 6), it can be called with one or two arguments. If we call it in the form Aitken(v), the compiler interprets the call as Aitken(v, 0). The declaration of Aitken() (line 13) gives its second parameter as int printflag=0, indicating to the compiler that the second argument assumes the default value of 0 if it is omitted. We can also call it in the form Aitken(v,1), where the value of the second argument is explicitly given as 1. Usually it is best to use the default argument facility only for the last argument.

The function Aitken transforms the sequence repeatedly until the sequence has only one or two numbers. The function Aitken(Vector& seq1) listed below performs a single transformation of the sequence.

```cpp
1 void Aitken(Vector& seq1){
2 int len = seq1.getSize();
3 for(int i=0; i < len-2; i++)
4   double a = seq1(i);
5   double b = seq1(i+1);
6   double c = seq1(i+2);
7   seq1(i) = a - (b-a)*(b-a)/(a-2*b+c);
8   }
9   seq1(len-2) = 0;//invalid entries
10  seq1(len-1) = 0;
11 }
```

Entries of the Vector object seq are accessed on lines 4, 5, 6, 9, and 10. Each one of these accesses is resolved using the overloaded function call operator and is not a simple array look-up.

The function AitkenE() listed below is defined in the source file Aitken.cpp. It uses the shadowing capability of the Vector class. It repeatedly transforms the sequence, and each transformation is effected using a call to Aitken() on line 13.

```cpp
1 double AitkenE(const Vector& seq, int printflag){
2   int len = seq.getSize();
3   Vector myseq(len);
4   myseq = seq;
5   Vector v;
6   v = myseq;
7   int n = len;
8   if(n==0)
9     n--;
10  if(printflag==1)
11    n--;
12    for(int i=0; i<n; i++){
13      Aitken(v);
14      v = myseq;
15    if(printflag==1)
16      printseq(v);
17  }
18  int index = len-1;
19  return v(index);
20 }
```
