```
echo 1 > /proc/sys/vm/drop_caches

One look at /proc/meminfo after this command to verify that the page cache has indeed been cleared.

The latencydisk() function defined below reads a single double from a given position in a file and returns it. The idea is to use 100 files each of 1 GB to make the total file size in the order of 100 GB, and then read a double-precision number at a random location in a random file.¹10 As result, the actual measurement of latencies makes a large number of calls to latencydisk() and the code for which is now

```
