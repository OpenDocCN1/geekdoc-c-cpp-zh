# 7.2.3 Summing the Leibniz series

We will discuss four different programs to sum[] All four programs initialize the array v[] to terms of the series $1-1/3+1/5-\dots$ and then scale each term by $4^{1/3}$ three times before summing the series. Together the programs explore nearly all the off syntax one needs. Work is offloaded using the offload directive. Communication between the host and the Phi device is controlled using in, out, inout, or copy clauses.

Each program works as follows. To begin, the array v[] is initialized with entries of the series $1-1/3+1/5-\dots$ on the host using leibnitz_init() defined above. Subsequently, three calls are made to hostmic_scale(), also defined above, and a single call to hostmic_sum(), which was too defined above.

The three calls to hostmic_scale() and the one to hostmic_sum() may be on either the host or Phi device. Each call to hostmic_scale() multiplies the terms of the series by $4^{1/3}$, and the effect of three calls is to multiply by 4. The call to hostmic_sum() will then return an approximation to $\pi$.

In leibniz1(), the three calls to hostmic_scale() and the call to hostmic_sum() are all offloaded to the Phi device. The syntax in this case is the simplest.

The function leibniz2() is similar, except for one difference. When the master encounters a typical offload region, such as the offload region leibniz1(), it blocks until the Phi device exits the offload region. In leibniz2(), we show syntax that allows the master to offload without blocking and then wait for the offload region to complete. That type of syntax is essential to make the Phi coprocessor and the host in parallel.

The function leibniz3() exhibits facilities for communication between the host and the Phi coprocessor in considerable detail. In this detail, the first two scalings are done on the Phi device and the third scaling on the host. The sum is computed on the Phi device.

Finally, the function leibniz4() shows how multiple Phi devices may be used in parallel. In offload directives, syntax such as v:length(n) is used to offload v[0,...,len-1] to the coprocessor. Parallelism between Phi devices is facilitated by the syntax v[offset, offset+1,...,offset+len-1] which offloads to the coprocessor.
