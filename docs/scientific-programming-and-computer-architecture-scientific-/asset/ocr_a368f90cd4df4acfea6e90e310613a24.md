```
for(int i=0; i < n-1; i++){
  a[i+1] = b[i] + c[i];
  b[i] = a[i];
}
```

carries the RAW dependence.

**Exercise 3.2.17.** Explain why the following loop

```
for(int i=1; i < n; i++){
  a[i] = b[i]+c[i];
  d[i] = a[i-1];
}
```

carries the RAW dependence. Rewrite the loop so that there is no loop-carried dependence.

```

```

explain why the inner and outer loops carry dependencies. Visualize the computation graphically and how to transform the loop nest so the inner loop carries no dependence.
