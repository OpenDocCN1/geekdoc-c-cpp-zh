### 6.4.2 Send and receive

Every network interface comes to sending and receiving data. We use the following function for sending data:

```
int block_send(int sockfd, void *buf, int len){
    int total_sent = 0;
    int num_sends = 0;
    while(total_sent < len){
        int ns = send(sockfd, buf, len-total_sent, 0);
        buf = (char *)buf+ns;
        total_sent += ns;
        num_sends += 1;
    }
    return num_sends;
}
```

This function sends len bytes out of the buffer buf]. Where the data sent to is determined by the socket file descriptor sockfd (line 1). To send data in the form of TCP/IP packets, the Linux kernel needs the IP address of the destination as well as the port numbers at the source and the destination. The sending and receiving applications cannot be identified without the port number. Although the socket file descriptor sockfd is a mere int, the Linux kernel can use it to look up the IP address of the destination as well as the port numbers at the source and the destination. The information is hidden from the application program, although there are ways to get hold of it. The manner in which the socket file descriptors are set up is described later.

The function block_send uses the Linux system call send() (line 5). The first argument is the socket descriptor, the second argument is the buffer, and the third argument is the number of bytes to be sent. The final argument is a flag, which is given as 0 on line 5. Other flag values such as MSG_MORE may be used to alter socket behavior. The send() may not transmit all the data. It returns the number of bytes transmitted and -1 on error. (lines 4 through 9) repeatedly calls send() until all the data has been sent.

### 6.4.3 Server

The server starts by opening a socket and then binding it to a port.

```
const char* PORTNUM="28537";

int bindport(const char* portnum){
  struct addrinfo hint;
  hint.ai_family = AF_UNSPEC;
  hint.ai_socktype = SOCK_STREAM;
  hint.ai_flags = AI_PASSIVE;
  struct addrinfo *list;
  getaddrinfo(NULL, portnum, &hint, &list);
  int socket = socket(list->ai_family, list->ai_socktype, list->ai_protocol);
  bind(socket, list->ai_addr, list->ai_addrlen);
  int backlog=10;
  listen(socket, backlog);
  int yes = 1;
  setsockopt(socket, SOL_SOCKET, SO_REUSEADDR, &yes, sizeof(int));
  return socket;
}
```
