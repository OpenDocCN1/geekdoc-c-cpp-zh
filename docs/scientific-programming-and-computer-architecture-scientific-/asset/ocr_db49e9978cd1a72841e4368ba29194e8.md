The number of columns (ncols) is equal to the number of columns owned by the current process of rank p. It is calculated using fstN() outside the for-loop. The number of rows to be sent to the process of rank q is equal to the number of rows of the transposed matrix assigned to the process of rank q. It is calculated inside the loop body using fstM(). The calculation of the index into the send buffer matches that in the member function copyTosbuf(), as it must for correctness.
The send buffer was allocated using new[]. The send buffer is registered using Infiniband Verb by the Open MPI implementation during the first invocation of the member function postsend(). The memory gets deregistered only at the end of the program.

# Receiving data

The member functions of the Transpose class for receiving data closely parallel the member functions for sending. The member function postrecv() parallels postsend().

```
void Transpose::postrecv(){
    long ncols = fstM[p-1]-fstM[p];
    for(long q=0; q < P; q++){
        long nrows = fstN[q+1]-fstN[q];
        long rbufferindex = ncols*fstN[q];
        int count = nrows*ncols;//MPI cant do long
        int tag = 0;
        MPI_Irecv(recvbuf+rbufferindex,count,MPI_DOUBLE,
                  q, tag,MPI_COMM_WORLD, rreqlist+q);
    }
}
```
