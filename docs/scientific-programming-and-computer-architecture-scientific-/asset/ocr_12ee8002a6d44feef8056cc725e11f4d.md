All transfers between DRAM memory and the processors are in cache line multiples. A cache line is 64 bytes or 512 bits on most x86 computers. Thus, a cache line is big enough to hold 8 doubles or 16 ints. The cache lines are aligned in memory to begin at addresses whose last 6 bits (that 2⁶ = 64) are zero.
