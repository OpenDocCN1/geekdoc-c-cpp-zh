# 2.1. Mixed-language programming

The names extrapolatesum and partialsum have changed to extrapolatesum (line 8) and partialsum_ (line 15) in the object files. Fortran names are typically changed by appending an underscore at the end. The name aitkenextrapolate_ (line 7) is undefined and has to be resolved using another object file. All the other undefined names are introduced by the Intel Fortran compiler and are resolved using standard libraries by the Fortran linker.

Unlike in C or Fortran, the transmutation of names in C++ is quite extensive. The command nm Aitken. produces output that is much more complicated. We show only the part of output.

```

0000000000000350 T _Z6AitkenRK6VectorRS_

None of the names in Aitken.cpp can be easily recognized. The transmutation of names in C++ follows involved rules and is called name mangling. We can use the command nm --demangle Aitken to get names in a form that is easily recognizable.

```

2 0000000000000350 T Aitken(Vector const, Vector&)
