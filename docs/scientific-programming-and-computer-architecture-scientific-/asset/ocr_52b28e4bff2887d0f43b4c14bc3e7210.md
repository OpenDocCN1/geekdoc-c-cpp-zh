# Segmentation fault caused by overwriting return address

The second run we look at also seg faults, but in a quite different manner, as we will
see.

```
void run2() {
    long *list = new long[2000];
    for(int i=0; i < 2000; i++)
        list[i] = i;
    f1(list, 2000);
    delete[] list;
}
```
