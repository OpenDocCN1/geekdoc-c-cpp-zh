All the MPI processes must participate in the creation of an object of class LustreFile. If all the processes create a class object as in

Lustrefile lustrerank, nprocs, dir, fname, totalsize)

there will of course a separate LustreFile object on each process. To exercise the functionality of this class, the objects must match across all the processes. In particular, the directory, file name, and total size must be identical in all the MPI processes.
The total size is the number of doubles stored in the ente file. The class constructor calculates the number of doubles in the local view of each process. The local size is the same in all MPI processes except possibly the last (of rank nprocs-1). An alternative, and possibly useful, interface to the class might be for each process to call the constructor with the local size of the file. The constructor can then compute the total size using a reduction operation.
This constructor does not create the file. The file is created when the member setstripe() is invoked.
