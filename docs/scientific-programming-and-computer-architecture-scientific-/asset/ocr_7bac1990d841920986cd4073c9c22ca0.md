# 6.4. The Internet

```
const char* PORTNUM="28537";
```

To begin with, the server opens a socket to this port and marks the socket for listening.

```
int bind2port(const char* portnum){
  struct addrinfo hint;
  hint.ai_family = AF_UNSPEC;
  hint.ai_socktype = SOCK_STREAM;
  hint.ai_flags = AI_PASSIVE;
  struct addrinfo *list;
  getaddrinfo(NULL, portnum, &hint, &list);
  int socket = socket(list->ai_family,
list->ai_socktype,
list->ai_protocol);
  bind(sock2port, list->ai_addr, list->ai_addrlen);
  int backlog=10;
  listen(sock2port, backlog);
  int yes = 1;
  setsockopt(sock2port, SOL_SOCKET, SO_REUSEADDR,
  &yes, sizeof(int));
  return sock2port;
}
```

On line 5, the ai_flags hint of hint is given as AI_PASSIVE to indicate that the socket will accept connections from any Internet address. The getaddrinfo() call on line 7 uses the hint to prepare another struct addrinfo object. The second argument to getaddrinfo() is the service. It can be a character string like "http" or "ssh" or it can be a character string representing a port number as "28537".

Various fields of list are assigned when opening the socket (lines 8, 9, 10). Because of the hint was set up, we will get a TCP socket.

The socket is bound to a port on line 11. The type of the second argument to bind() is const struct sockaddr*. The port to which the socket is bound is obtained from the struct second argument points to. The fact that the socket accepts connections from any Internet address is indicated within the same struct. It is possible to set that struct explicitly and do away with the hint and getaddrinfo(), but the getaddrinfo() interface we have used is much cleaner.
