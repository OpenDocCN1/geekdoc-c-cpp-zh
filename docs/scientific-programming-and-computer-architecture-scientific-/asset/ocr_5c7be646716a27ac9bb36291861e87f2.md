Table 5.1: Overhead (in cycles) of the parallel construct on three different computers. The full names of the machines, see table A.1 of the appendix.

```
void parallelA(int threads, StatVector& stats) {
    Timestamp clk;
    clk.tic();
    #pragma omp parallel \
    num_threads(threads)
    default(none)
    {
        dummy();
    }
    double cycles = clk.toc();
    stats.insert(cycles);
}
```

Every call of parallelA() enters and exits from a parallel region. The master thread times the entire parallel region and inserts the cycle count into the stats object on line 11. The parallel region consists of a single call to dummy() on line 8. As its name suggests, dummy() does nothing. Its definition

```
void dummy(){}
```

is stashed in a separation unit to force the compiler to generate a function call in the parallel region. The statistics of entering and exiting the parallel region are accumulated in the stats object after a large number of calls to parallelA().

Several points emerge from table 5.1. The cost is much worse than the median cost (or the cost—median and mean are approximately equal). The median or cost of a parallel region is in the thousands of cycles. The worst cost is of the order of millions of cycles.
