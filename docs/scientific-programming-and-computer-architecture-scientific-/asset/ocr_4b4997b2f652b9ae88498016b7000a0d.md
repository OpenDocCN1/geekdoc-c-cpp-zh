The earlier function mult600x200x3000() assumes that the array[] stores a $200 \times 300$ matrix in packed format. The math is thought of 250 matrices of dimension $200 \times 12$ next to each other. The function packB() packs a submatrix of B[], which is in column-major format, into B[].
