This kernel is assumed to be launched with two-dimensional thread blocks in a two-dimensional grid. The size of the thread block is assumed to be SQRTT x SQRTT. On the K20, we take SQRTT to 32 = √1024 because 1024 is the maximum number of threads in a block.

The matrix dimension N is assumed to be divisible by SQRTT. The grid is assumed to be N/SQRTT x N/SQRTT. The total number of threads is equal to $N^2$. A natural map from indices to entry of the $N \times N$ matrix C. The mmult_gmem() calculates the indices of $(i, j)$ of the thread map and then updates the corresponding entry of the matrix C[] given to a different thread for updating.

The syntax for this kernel using two-dimensional thread blocks and grids is shown in the listing below. Multiple dimensions are specified using dim3 objects.

```
double mmult(*A, double *B, double *C, int N){
    assert(SQRTT*SQRTT==THINBLK);
    assert(N%SQRTT==0);

    dim3 grid(N/SQRTT, N/SQRTT);
    dim3 tblk(SQRTT, SQRTT);

    dhmem<double> dhA(N*N);
    dhmem<double> dhB(N*N);
    dhmem<double> dhC(N*N);
    for(int i=0; i<N*N; i++){
        dhA.host()[i] = A[i];
        dhB.host()[i] = B[i];
        dhC.host()[i] = C[i];
    }

    dhA.hostTodevice();
    dhB.hostTodevice();
    dhC.hostTodevice();

    mmult_gmem<<<grid, tblk>>>(dhA.device(),
        dhB.device(), dhC.device(), N);
```
