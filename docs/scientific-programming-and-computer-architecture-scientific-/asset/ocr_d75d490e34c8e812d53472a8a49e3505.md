This is not the longest C++ listing in this book, but it may be the hardest to decipher.
To help decipher this program, we turn to figure 8.4. Each submatrix CC as the submatrices of the thread block is SQRTT x SQRTT matching the dimensions of the thread block. Because the grid is of dimension N/SQRTT x N/SQRTT, we may assume that each submatrix CC belongs to a certain thread block. The entries of CC are further split between the threads in the thread block.
The kernel mmut_smem() thinks of updating the CC in block terms:

```
CC=+ A1 + B1 + A2 + B2 + ... + An x Bn
```

where n = N/SQRTT.
