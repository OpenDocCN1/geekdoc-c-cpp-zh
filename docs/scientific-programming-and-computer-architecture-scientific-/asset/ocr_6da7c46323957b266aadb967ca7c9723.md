In a function that calls aitken() from some other source file, we may have declared two arrays using double s[100], t[100]. Those two arrays will correspond to segments of memory each declared to 100 doubles (see figure 1.4). As we have noted, s[0]...s[99] and t[0]...t[99] are names of double locations, which make up those segments of memory. In contrast, s and t have values of type double * but are not names of any locations in memory. If a call is made

```
aitken(s, t, 100);
```

it has this following effect. The function parameters seq1 and seq2 are names of locations that can hold double *. The values of s and t are copied to the locations in memory whose names are seq1 and seq2, respectively (see figure 1.4). The value of seq1[17] is the same as the value of s+17. seq[17], which is exactly the same as *(seq1+17), is another name for the memory location s[17]. Thus, we see that by indexing into seq1 and seq2 as seq1[0]...seq1[99] and seq2[0]...seq2[99], we may refer to any entry in the arrays s and t defined by the caller (see figure 1.4).
