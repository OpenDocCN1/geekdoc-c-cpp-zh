The call to `cudaMalloc()` on line 3 looks somewhat like a call to `malloc()` to allocate memory. A noticeable difference is that whereas `malloc()` returns the pointer to allocated memory, `cudaMalloc()` returns an error code. The first argument of `cudaMalloc()` is an address, and the location that address points to is altered to respond to allocated memory. In the case of `malloc()` or `new[]` (line 6), the memory allocated is obtained from the operating system. In the case of `cudaMalloc()`, the memory allocated must be obtained from the graphics device. These definitions are inside the class, is why the names of the constructor and the destructor are not qualified using `template<Class type> dhstmem::`.
