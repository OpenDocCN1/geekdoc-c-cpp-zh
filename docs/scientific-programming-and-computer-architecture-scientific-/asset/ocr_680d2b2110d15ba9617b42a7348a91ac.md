This for-loop implements matrix transpose block by. In a large problem, most blocks are $B \times B$, but the block sizes are adjusted using iib and jjb at the edges of matrix. The outermost loop is parallelized using OpenMP. Matrix transpose with blocking was discussed in chapters 4 and 5. The choice of $B = 50$ for the block size here influenced by that earlier discussion.
