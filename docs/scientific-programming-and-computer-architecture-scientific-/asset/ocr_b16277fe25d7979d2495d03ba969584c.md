# Parallel regions in plain C

The first implementation of parallel regions we consider make minimal use of Pthreads. Most of it is in plain C.

The following global definitions are the basis of the C implementation of parallel regions:

```
typedef void (*fnlist_t[threads])(void *);
typedef void *arglist_t[threads];
volatile fnlist_t fnlist;
volatile arglist_t arglist;
volatile long work_count[threads];
volatile long done_count[threads];
```

This code defines two types, fnlist and arglist, and four variables. Here threads, whose definition is not shown, is a const equal to the number of threads. For example, threads is 3 if the number of threads is 3.

The type fnlist_t is an array (of size threads) of pointers to functions with a single argument of type void * returning void. The syntax for such complex types can be gotten right with a little trial and error. The type arglist_t is an array of (size threads) pointers to void.
