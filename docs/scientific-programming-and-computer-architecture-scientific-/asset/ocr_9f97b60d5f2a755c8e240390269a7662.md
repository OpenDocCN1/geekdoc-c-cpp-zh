# 2.3. Building programs using GNU Make

A rules.mk file for the module utils/ written along the same lines looks like:

```
saved := $(D)
D := $(R)/utils
$(D)CFLAGS := $(CFLAGS) -fPIC
```

```
$(D)/%.o: $(D)/%.cpp
$(CPP) $(<) $(CFLAGS) -o $$ -c $$
```

```
$(D)/utils.o: $(D)/utils.cpp
$(D)/Table.o: $(D)/Table.cpp
```

```
D := $(saved)
```

A Makefile in linking/linalg builds the executable to test the LU solver looks as follows.

```
1 include ../.root.mk #define R, CPP, CFLAGS
2 D := $(R)/linking/linalg
3 LIBS := = -mkl=sequential
4
5 %.exe:
6 $(CPP) -o $$ $(filter %.,,$) $(LIBS)
7
8 include rules.mk
9 include $(R)/utils/rules.mk
10
11 test_lusolve.exe: $(D)/test_lusolve.o $(D)/lusolve.o
12 $(R)/utils/utils.o $(R)/utils/Table.o
```

The root.mk file included on line 1 defines the variables R, CPP, and CFLAGS. It is similar to the makevars.mk file described above.
The rules.mk file included on line 8 brings the pattern rules and dependencies that govern object files and sources in the present linking/linalg module. The pattern rules for the utils/ module are brought in using an include directive on line 9. The latter include directive uses an absolute path name.
