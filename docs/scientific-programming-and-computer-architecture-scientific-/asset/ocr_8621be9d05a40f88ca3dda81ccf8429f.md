Table 4.3 reports measurements of latency using two different techniques. In "mwalk", the array FourPages[] is evicted from cache by writing to some other large array (line 13). In "clflush", the array is evicted using the CLFLUSH instruction (line 16). When the number of pages is 32 or less, the "mwalk" figure is noticeably higher. That appears to be because writing to some other array to evict FourPages[] from cache implies write-backs of that array when FourPages[] is used to measure latency. The write-backs are likely to cause row switching in a bank.^5
