# 8.1.3 Timing CUDA kernels

The simplest programs have much to teach us as long as we time them carefully. Therefore, we are looking at mechanisms to time kernels that run on the graphics coprocessor.

We use the following class to time the graphics processor. The private data members of the class are shown in full. For the public member functions, the interface is shown, and the definitions will be given later.

```
class hstTimer{
private:
    cudaEvent_t start, stop;
public:
    hstTimer(){...};
    -hstTimer(){...};
    void tic(){...};
    float toc(){...};
}
```

The private members are two events named start and stop. The events will be "sent" to the graphics processor to record the time on the graphics processor and will be relayed back to the host.

To time a piece of code, we can use the class as follows:

```
hstTimer hclk;
hclk.tic();
[code]
float tms = hclk.toc()();
```
