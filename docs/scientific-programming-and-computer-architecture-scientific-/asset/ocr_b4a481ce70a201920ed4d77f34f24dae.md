The CPP and Fortran sources for the Aitken iteration define functions with similar names. The main point of section 2.1.1 is that the same name maps to a different name in the object file depending on whether the source is C, C++, or Fortran. Once this point is understood, making C, C++, and Fortran work together becomes much simpler. The mapping is most straightforward in C, where names are unchanged from sources to object files. In Fortran, the mapping is a little more complicated. In C++, the mapping is a great deal complicated.
