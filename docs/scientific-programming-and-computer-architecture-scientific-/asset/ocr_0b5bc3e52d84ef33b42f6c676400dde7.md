The function ff0() is always called by f0(), and f0() defines a0 using long a0[1000]. To begin with, the entries of the array a0[] are set to zero. The pointer list is located dynamically, and the entries of list[] are not stored on the stack.

The usefulness of list[] lies in being able to generate controlled illegal accesses into a0[]. For example, if list[] is the sequence 0,-1,...,1000, locations of lower addresses than a0 are accessed. If list[] is the sequence -500,...,-1000, locations with addresses lower than a0 are accessed by skipping 500 locations. If list[] is the sequence 1000,...,1999, then a thousand locations with addresses higher than a0, and just beyond the legal limit of the array a0[], are accessed.

The chief purpose of f0(), whose definition is given below, is to call ff0(), which it at the end.

```
void f0(long *list, long n){
    a0[1000];
    printf("a0 (in f0) = %p\n", a0);
    printf("pid (in f0) = %ld\n", getpid());
    ff0(a0, list, n);
}

```

The array a0[] is allocated on the stack and takes up 8000 bytes. Because of the modifications made to the Linux kernel, getpid() will print the start and end of the vm area of the stack. The array list[0..n-1] specifies entries of a0[] that will be modified by the call to ff0().
