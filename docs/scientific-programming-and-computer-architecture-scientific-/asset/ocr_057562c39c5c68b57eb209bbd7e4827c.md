There is a base difference between data members and member functions. Suppose v is a Vector object. v.size, v.data, and v.owner refer to the data items packaged inside v. Contrast, v.norm() applies the member function norm() (line 25) with the class object v as its target.

The member exist within the namespace defined by the class. Each class defines a namespace. The Vector class defines the eponymous namespace Vector::. If we want to refer to a member function such as norm() outside the scope of the class (the scope here is from lines 1 through 28), the name must be given as Vector::norm().

For example, we may define the member function norm() in a compilation unit and outside the scope of the class Vector as
