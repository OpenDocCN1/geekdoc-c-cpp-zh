Figure 5.4: The stack resulting from an invocation of run1() from main(), just after call to ff0(). Notice that the stack grows leftward beginning with main(), the first function to be called and which calls run1(), which calls ff0().

This function defines the array a1[] and claims 8 MB on the stack.
The key to remember is that the arrays a0[] and a1[] are both allocated on the user stack-a0[] by the function f0() and f1(). The arrays a0[] and a1[] are defined to have 10^3 and 10^6 entries, respectively.

# Segmentation fault caused by illegal virtual address

We begin exercising the stack with the following function:

```
void run1(){
    long *list = new long[5000];
    for(int i=0; i < 5000; i++)
        list[i] = i;
    f0(list, 5000);
    delete[] list;
}
```

The stacking of function calls is shown in figure 5.4. Figure 5.4 shows a0 between f0 and run1, with f0 to its left, because the array a0[] is defined after run1() calls f0() but before f0() calls ff0().
