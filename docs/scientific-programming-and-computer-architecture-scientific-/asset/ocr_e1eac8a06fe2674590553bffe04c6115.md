# 6.3. MPI examples

# Persistent exchange

In persistent communication as described here, user processes secure memory using the MPI library (or even a facility such as `malloc()` or `new[]`—that is not recommended). Send and receive request objects are initialized using memory secured from the MPI library. Sends and receives are initiated by the same request objects. The termination of the data transfer is also verified using the request objects.

The Exch C++ class, which will be described, is an interface for persistent exchange of data between two hosts. The usage of C++ conforms to earlier practice in this book. The C++ class is mainly a convenient interface that reduces burden on the programmer's memory. Class constructors and destructors are convenient for setting up and tearing down persistent communication between MPI processes. The Exch class is as follows:

```
class Exch {
private:
    double *sendbuf;
    double *recvbuf;
    int bufsize;
    MPI_Request req1;
    MPI_Request req2;
    Timestamp clk;
public:
    Exch(int rank, int nprocs, int bufsize);
    -Exch();
    void post();
    double wait();
    int getbufsize(){return bufsize;}
    double *getsendbuf(){return sendbuf;}
    double *getrecvbuf(){return recvbuf;}
};
```

The class constructor (line 10) takes the MPI rank and the total number of MPI processes as its two arguments. Its third and last argument is the buffer size (line 10).
