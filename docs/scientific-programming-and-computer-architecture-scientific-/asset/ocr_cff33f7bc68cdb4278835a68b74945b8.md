Lines 4 to 7 issue the cpuid instruction with i = 0, 1,... For each value of i, cpuid returns information about a different cache. It signals that there are no more caches by putting zeros in the last four bits of %eax. On line 8, (eax&0xF) extracts the last four bits of eax using a bitwise operation with the hexadecimal number 0xF. If cpuid has signaled that there are no more caches, line 9 uses break to exit the loop. Lines 10 to 22 extract information about the cache.

When the cpuid was used for a 2 GHz SSE2 machine (see table A.1 for the names of the machines), it reported 32 KB of L1 instruction cache, 32 KB of L1 data cache, and 12.6 MB of L3 cache. On a 2.2 GHz AVX machine, the L3 cache is 20 MB. On a 3.6 GHz AVX2 machine, the L3 cache is 4 MB. These are some of the machines we use for timing programs.
