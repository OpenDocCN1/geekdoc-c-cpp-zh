The cyclic pattern is also a simple one, but it allows us to examine how well the network bandwidth holds up when there are many communicating agents on the network. We will find that it holds up quite well.

The Cycle class follows:

```
class Cycle{
private:
    double *sendbufl, *sendbufr;
    double *recvbufl, *recvbufr;
    int bufsize;
    MPI_Request sreq1, sreq2;
    MPI_Request rreq1, rreq2;
    Timestamp clk;
public:
    Cycle(int rank, int procs, int bufsize);
    -Cycle();
    void post();
    double wait();
    double *getsendbufl(){return sendbufl;}
    double *getsendbufr(){return sendbufr;}
    double *getrecvbufl(){return recvbufr;}
    double *getrecvbufr(){return recvbufr};
};
```

This class has an interface similar to the Exch class. The difference is that it has send and receive buffers to communicate with the process to its left as well as the process to its right.

To time cyclic exchange, the send and receive requests are posted using post()
