## The const qualifier

The following definition is contained in the first few lines of Vector.hh (but omitted from earlier listings):

```cpp
const double PI = 3.1415926535897932384e+00;
```

Because the definition of PI is qualified using const, any attempt to change the value of PI is illegal. If a user attempts to change the value of PI, the compiler will catch the error.

The Vector class is equipped with member functions output() and input() to facilitate output to files and input files. Definition of the member function input() begins as follows:

```cpp
void input(const char* fname){...}
```

Here the extra argument fname (file name) is a pointer to a char (character). In C and C++, a char is a single byte with ascii encoding. Strings are arrays of characters terminated by '\0' or equivalently the value of 0. If a string is a pointer to a char, its length need not be passed explicitly. The convention for terminating strings determines its length.

A pointer holds an address which points to some data. Prefixing the const qualifier to the declaration or definition of a pointer implies that the data does not change, but the pointer may change. So if it is illegal to change fname[]='M' within the body of the function, but it is illegal to save char c; fname = &c;

Suppose we want to initialize a vector of 20 using data stored in a file named init.dat in the current directory. The data in the file must be a sequence of 20 (or the extra values are ignored) values separated by whitespace. The following code does:

- 1 char fname[9]={'i','n','i','t','.','d','a','t','\0'};
- 2 Vector v(20);
- 3 v.input(fname);

In line 1, the number 9, which gives the length of the array, can be omitted by the compiler can use the initializing sequence to determine the length. The usage below is much more convenient.

```cpp
Vector v(20);
v.input("init.dat");
```

We are allowed to pass "init.dat" as an argument explicitly because the first argument of the member function input() is of the type const char * and not just char *.

Use of const qualified references is illustrated by the member function add().

```cpp
void add(const Vector& v)...{...}
```

Here the const qualifier indicates that add() will read entries of v but not change them. The target will be changed when v is added to it. The usage of the const qualifier in the member function norm() is different.

```cpp
double norm(){...}
```

This function returns the ∞-norm of its target vector (largest magnitude of an entry of the vector). Therefore, if it is called v.norm(), the returned value is the ∞-norm of v. The const qualifier specifies that the member function will not change its target. Any attempt to change the entries of v inside the definition of norm() is illegal.

The const protections can be easily broken using shadows. inside the definition of the member function add(), for example, we can say

```cpp
Vector w(v);
```

and go on modify the entries of v.

## The -> operator

Suppose we define an array of pointers to Vector as

```cpp
Vector *v[100];
```

Each entry may be made to point to a Vector and we want to print the norm of each. The following syntax will not do:

```cpp
for(int i=0; i < 100; i++)
cout<<v[i].norm()<<endl;
```

The problem is here that *v[i] is a pointer and not a Vector. The correct syntax is as

```cpp
for(int i=0; i < 100; i++)
cout<<(*v[i]).norm()<<endl;
```

The parentheses in (*v[i]).norm() are needed because * dereferencing has lower precedence than the . operator. This usage occurs often enough that there is a special operator that combines dereferencing and selection. It may be used as follows:

```cpp
for(int i=0; i < 100; i++)
cout<<v[i]->norm()<<endl;
```

The element selection through pointer -> occurs frequently in the context of linked lists, trees, and graphs. Consider the struct

```cpp
struct node{
  double val;
  struct node *next;
};
```

A struct is a package of data items. Here the two data items of struct node are val and a pointer to the next. The pointer next is a link from one node to the next. A series of nodes may be chained together to form a linked list.

Figure 1.6 shows a linked list with each node pointing to the next. The variable list points to the beginning of the list. The next pointer of the last node is set to NULL.

The following function finds the length of a linked list:

![](img/2ae76787eef1fc62652846e2a52af15e_69_0.png)

```cpp
int len(struct node *llist){
    int len = 0;
    while (llist != NULL){
        llist = llist->next;
        len++;
    }
    return len;
}
```

## Abstraction features of C++

The C++ language has a number of powerful features to bring programming closer to ideas and concepts intrinsic to the problem domain. Classes that arise later are all defined, provide a single service, and do not use these features. The Vector class defined above attempts to capture the abstract notion of vectors. C++ has a number of abstraction features beyond the basic class mechanism we have studied++ supports object-oriented programming through inheritance of classes, multiple inheritance, and virtual and pure virtual functions. On many occasions, a single problem morphs into multiple instances, each of which has its own features while sharing a great deal in common with other instances. Object-oriented programming is the best way to tackle such problems.
