These four volatile variables are used by the worker threads to communicate
with the manager. The manager thread sets fnlist[tid] and arglist[tid]
to tell the thread of identifier tid which function it should execute and what argument
be passed to it. For example, fnlist[tid] is set to addone to ask the worker
thread with identifier tid to execute the addone() function earlier in this
section.

The manager thread uses the array entry work_count[tid] to tell the worker
thread of identifier tid how many units of work have been assigned to it
beginning. The worker thread uses done_count[tid] to tell the manager how many
units of work it has completed.

Making the four arrays used for communication between the manager thread and
the workers ensures that every single reference generates a load or store
instruction. In particular, the compiler will not assign any of these items to a register,
which would get in the way of communication between the manager and the workers.

Every thread created using pthread_create() begins execution with a function
that takes a pointer as its argument and returns a pointer. The worker thread begin
ext with the following function:

```
1 void *worker(void *arg){
2     int tid = *((int *)arg);

5         if(work_count[tid]==done_count[tid]+1{
6             (*fnlist[tid])(arglist[tid]);
7             asm volatile("mfence");

9 }

```
