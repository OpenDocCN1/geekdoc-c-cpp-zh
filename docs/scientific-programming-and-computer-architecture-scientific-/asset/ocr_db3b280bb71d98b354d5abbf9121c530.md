BlockDivide() partitions $n$ items between $P$ processes. The partitioning is stored in the array fst[]. The number of items that each process gets would be exactly equal to the quotient $Q=n/P$ (line 2) if the remainder $R=n-QP$ (line 3) were zero. If $0, 1, \dots, n-1$ are the $n$ items, items $i$ assigned to process $p$ lie in the interval fst[p] $\le i <$ fst[p+1]. Equivalently, the assignment to process $p$ begins in **fst[p]**.nThe for-loop on lines 5 and 6 assigns $Q$ items to each of the first $R$ processes. The remaining $P-R$ processes are assigned $Q$ items by the for-loop on lines 7 and 8.

It must be noted that fst[] is an array with $P+1$ entries, although there are only $P$ processes. The entry **fst[P]** always gets set to $n$.
