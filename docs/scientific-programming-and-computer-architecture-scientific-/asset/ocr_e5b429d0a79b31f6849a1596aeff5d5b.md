In this policy, the write is propagated to DRAM memory. Yet another alternative is to propagate writes that modify the L1 cache to L2 cache but not to DRAM.

An implication of the write back policy is that cache lines in DRAM memory may become invalid. The same cache line may be stored in the L1 or L2 caches of multiple processor cores. If one of them write to its, the cache lines in other processor becomes invalid. The cache controller on each processor has to "snoop" on the traffic in the other processors to maintain a coherent cache.

As a consequence of the write back policy, a single write instruction can trigger two DRAM accesses. Consider a write instruction of the type movq %rax, %rdi. If the word (8 bytes) that %rdi points to is not in cache, the cache line must be brought in triggering the first DRAM access. Future instructions that read and write from the same cache line will be served without accessing DRAM. However, a second DRAM access is triggered when the cache line is evicted. In contrast, if all operations a cache line is subjected to reads, there is no need for the second DRAM transfer.

# 4.1.3 Physical memory and virtual memory

Virtual memory is implemented by the operating system and the processor hardware working in concert. Its main purpose is to prevent processes from interfering with each other's memory. A single process will have only part of the DRAM memory for itself. The part of the DRAM memory that is available to a specific process is determined only when the process is loaded and can change as it runs.

Virtual memory is an illusion that simplifies programming, compilation, and linking in addition to keep programs from interfering with each other. As the program runs, the memory addresses generated by a program are automatically mapped to physical addresses in the DRAM memory. So, for example, if a program issues an instruction such movq %rax, %rdi, the address in %rdi is a virtual address. During execution, the page tables are consulted by the hardware to map that address to a physical address. A separate map is maintained for each process to keep the processes from interfering with each other. The map is typically hierarchical and stored in multiple page tables. Page tables are the essence of virtual memory.
