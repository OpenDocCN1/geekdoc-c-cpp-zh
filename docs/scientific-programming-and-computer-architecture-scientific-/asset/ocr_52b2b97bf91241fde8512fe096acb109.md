# 2.3.2 Targets, prerequisites, and dependency graphs

Dependencies are fundamental to make. Figure 2.3 shows that each object depends on a single source and a header. Typically, the dependency is on multiple header files, unlike the simple situation shown in the figure. Each executable in turn depends on multiple object files.

The first purpose of a Makefile is to capture the dependency graph between headers, sources, object files, and executables. Each object in the dependency graph is typically a file in figure 2.3. All files that have incoming edges in the dependency graph are targets. The incoming edges indicate that a target file must be built using some of other files. Those other files are the prerequisites. The targets may reappear as prerequisites, as is the case for all the object files in figure 2.3.

If a target either does not exist or is out of date, make takes upon itself to create a file corresponding to the target.
