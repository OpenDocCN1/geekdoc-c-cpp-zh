# 7.3.2 Matrix multiplication

Algorithms that are capable of approaching the theoretical peak are not many. These
alg must involve a great number of arithmetic operations relative to the data
they access. In addition, their structure must permit hiding the cost of multiple
accesses of the same data item. numerical linear algebra is the main source of
such algorithms.

The number of arithmetic operations in $C = C + AB$, where $A, B, C$ are $n \times n$
matrices, for large $n$, a great number of arithmetic operations are carried out for every byte
is accessed. It is true that every one of $A, B$, or $C$ is involved in $n$ operations,
we may hide the cost of memory accesses, as shown in chapter 4.

Even if the cost of memory accesses is ignored, writing a microkernel that achieves
peak performance, with all the data items in L1 cache, can be a formidable
challenge. It requires knowledge of the register set as well as the instruction pipeline.
In this section, we look at a small part of the Xeon Phi's instruction set$^{12}$ and
write a microkernel that achieves 45% of the peak floating throughput. Although
this microkernel falls short of the best possible by a factor of 2, it still gives a good
understanding of the Xeon Phi's architecture, why it can be so fast, and why it is so
hard to write programs that approach its top speed. Difficulty in approaching peak
floating throughput is characteristic of all modern architectures. Later we turn
to Intel's MKL library, which achieves 85% of the peak floating throughput.
