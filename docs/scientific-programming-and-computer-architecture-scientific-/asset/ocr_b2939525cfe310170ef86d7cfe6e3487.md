# Chapter 1. C/C++: Review

The function Aitken() uses shadows instead of creating new Vectors of different lengths repeatedly. After each invocation of Aitken(v) on line 13, v is made a shadow of itself, with the last two entries dropped, on line 14.

Object files are produced from Aitken.cpp, Leibniz.cpp, and Logseries.cpp using the icpc compiler with the -c option. The linking command builds the executable.

```
icpc -c Aitken.o
icpc -c Leibniz.o Leibniz.o Aitken.o
icpc -o Leibniz.exe
```

The executable Logseries.exe is built similarly. Instead of icpc, we may use g++ or pgCC, and the compilation and linking syntax shown here does not change.
