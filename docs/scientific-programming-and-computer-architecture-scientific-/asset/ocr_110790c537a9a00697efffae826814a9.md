# 4.1. DRAM and cache memory

![](bbox=[0.218, 0.153, 0.739, 0.369])

Figure 4.4: Each diamond in this figure stands for a bit. DDR technology doubles the data rate by transferring a bit at both the rising and falling edges of the clock signal.

Almost all DRAM in use today is double data rate (DDR), and it has been that way for a long time. DDR was a major advance in DRAM technology. In earlier technology, a single bit of data was pushed out to a single pin (connected to a single line of the data bus) during one period of the clock signal. DDR initiates a data transfer during the rising edge as well as the falling edge of the clock (see figure 4.4). Two bits of data are pushed out in a single period of the clock, doubling the bandwidth.

DDR memory is often advertised to be DDR3 or DDR5 and so on. The numerical suffixes of 3 or 5 give the prefetch length. When $m+n$ address bits are set to a bank of $2^m$ arrays, the DRAM outputs not $2^n$ data bits, with 1 bit for each array, which $2^n$ bit word corresponding to the $m+n$ address as well as $2^3$ words correspond to 8 consecutive addresses, including the one that was sent to it. The assumption is here that when a program asks for a certain word, it will probably ask for the next word. When $2^3$ words are sent to the memory controllers, the memory controllers may be able to serve multiple load/store instructions while triggering a single DRAM access. This technique improves peak bandwidth assuming sequential, nearly sequential, data access.
