There is a bit of new syntax here. On line 2, the colon introduces the member initializer list. The only entry of that list is dim(dimi), where dim is a data item in the class object being constructed and dim is an argument to the constructor. Saying dim(dim) is equivalent to calling the constructor of the class that dim belongs to dim as the argument. Because dim is an int, which is a basic type, it is equivalent to saving dim=dim at the beginning of the function. On lines 4 and 5, A and ipiv are allocated using the new operator (instead of malloc()). The for-loop copies the input matrix to A[].

The member functions of the class LU_Solve are declared within namespace LU_Solve introduced by the class definition. When the member functions are defined externally, their names must be qualified using LU_Solve:: as the constructor above. The names of the other three member functions are similarly qualified in isolve.cpp.
