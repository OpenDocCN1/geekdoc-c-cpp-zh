on. The order in which the FFT operations are applied may also be determined and saved here.

The class destructor is defined as follows:

```
fft_mkl::fft_mkl() {
    DftiFreeDescriptor(&handle);
}
```

The definition of the fft_mkl class is now complete.

The C language has a facility for defining functions with a variable number of arguments. An example of such a function is printf(). The first argument to printf() is a format string, and the types and number of the subsequent arguments depend on the format string. Like printf, the MKL function DftiComputeForward() uses the varargs facility to handle both in-place and out-of-place transforms.
