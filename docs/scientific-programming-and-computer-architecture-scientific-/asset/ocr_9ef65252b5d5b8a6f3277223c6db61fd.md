The definition Vector v(20) invokes the constructor on line 6. This constructor will make v.data point to 20 doubles, set v.size to 20, and set v.owner=1, making v the owner of its data.

The body of the for-loop has v(i)=i. When we say f(x) in C/C++, f() is a function being applied to x. Here we say v(i), but v is a class object not a function being applied to i. However, thanks to operator overloading, the compiler interprets v(i) as v.operator()(i)—words, the member function operator()(i) is applied to the target with i as the sole argument. The member function on line 16 is called. This member function will look at v.data, and return a reference to it. Thus, when we say v(i)=i, the ith of the Vector object v gets set to i. At the end of the for-loop, the values of v are 0, ..., 19.

At the definition W1, w2; the Vector objects w1 and w2 are created using the empty constructor (line 5). This empty constructor sets w1.size to 0, w1.data to NULL, w1.owner to 0, and likewise for w2. Neither w1 nor w2 owns any data. To begin with, their sizes of zero.

When we say shadow(v, 0, 10), the member function defined on line 12 gets invoked. Its effect is to set v.data to v and w1.size to 10. However, w1.owner remains 0 because the data is owned by v. The Vector w1 is a shadow of the first 10 entries of v. Likewise, after w2.shadow(v, 10, 10), w2.data is set to v.data+10, and w2 becomes a shadow of 10 through 19 of v.

When we say add(v), the member function add() (line 19) is invoked with w1 as the target and w2 as its argument. This member function verifies that its target and its argument are vectors of the same size and adds w2 to w1, by entry.
