The task of creating the file is left to the process of rank 0. The rank 0 removes the file if it is already present. On line 4, the character string cmd[] is constructed. On line 5, the library function system() (it is declared in stdlib.h) invokes the shell and executes the command. The command for striping is composed as a string on lines 6, 7, and 8. If we want 50 stripes and a stripe size of 4,000 MB, the command is

```
```
lfs stripetype --size 4000 M --count 50 <filename>
```
```

Such a command is issued through the shell on line 9. It creates a new file. Although the process of rank 0 is the only one to handle striping, all the processes must call the member function stripe(). The barrier at the end (line 10) ensures that none of the processes returns before file creation is complete. The barrier is essential for ensuring that none of the processes attempts to access the file before it is created.

The member functions write() and read() invoke write_mpi() and read_mpi() as follows:

void LustreFile::write(double *v){
long disp = 8*rank*(totalsize/nprocs);

}

void LustreFile::read(double *v){
long disp = 81*rank*(totalsize/nprocs);
char famex[200];
sprintf(fnamex, "%s/%s", dir, filename);
read_mpi((void*)v, 81*localsize, famex, disp);
}
