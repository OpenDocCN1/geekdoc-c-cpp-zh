The function blocktrans() listed below implements matrix transpose block by block. The block size is $B \times B$, and $B$ is defined as a const int (definition is not shown). The matrix dimensions are assumed to be divisible by $B$. The function blocktrans() uses a set of loops.

```
void blocktrans(double *restrict a, double *restrict b,
    int m, int n){
    assert(m%B==0)&&(n%B==0));
    for (int i=0; i < m; i+=B)
        for (int j=0; j < n; j+=B)
            for (int ii=0; ii < B; ii++)
                for (int jj=0; jj < B; jj++)
                    b[j+jj+(i+ii)*n] = a[i+ii+(j+jj)*m];
}
```

When functions such as blocktrans(), it helps to think directly in terms of the for-loop construct of C/C++.
The loop variable i defined on line 4 steps through the rows of the $m \times n$ matrix stored in the array a[] in steps equal to the block size B. The loop ii defined on line 6 steps through the B rows of a block of rows. i+ii is the index—relative to the $m \times n$ matrix—of ii within the block of B from i to i+B-1. Similarly, j+jj is the index—relative to the matrix a[] as a whole—of column jj within the block of B columns from j to j+B-1. The loop body of blocktrans(), which is comprised of the single statement

```
b[j+jj+(i+ii)*n] = a[i+ii+(j+jj)*m];
```

corresponds to the b[j+i*n]=a[i+m]; which comprises the loop body of easytrans().
It is significant that the block size B is a const int. Knowledge of the numerical value of B allows the compiler to optimize better.
