The assignment of pages to page frames can be enforced through some kind of initialization routine. An example follows:

```
void init_manycore(double *list, long len, int nthreads){
    #pragma omp parallel for \
    num_threads(nthreads)
    default(none) \
    shared(list, len, nthreads)
    for(long i=0; i < len; i++)
        list[i] = 0.0;
}
```

This initialization routine must be called soon after the array list[] is allocated and before any access of any entry of the array. The initialization may not be doing anything useful. The point is that the array is split between the threads, and each thread initializes the memory it is most likely to use.

The first time an entry of list[] that begins a page (the address at page beginning is 0 module the page size, which is typically 4096), there is a page fault. The page fault handler typically finds a page frame in memory that is near the thread that triggered the fault.³

> ³In principle, first-touch allocation depends on assumptions about C/C++ memory management. The key assumption is that the memory that is returned by malloc() exists in virtual memory
