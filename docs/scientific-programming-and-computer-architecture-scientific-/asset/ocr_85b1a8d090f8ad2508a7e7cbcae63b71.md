The two fields of the Infiniband data packet that follow the payload are invariant Cyclic Redundancy Checksum (CRC) and variant CRC. CRC error detection/correction is calculated using polynomial arithmetic. The invariant CRC is 32 bits and the variant CRC is 16 bits. Certain fields of the data packet may change when it travels from source to destination. The invariant CRC refers only to the fields that do not change. The variant CRC is generated and verified at the link layer. If a packet has an error that cannot be fixed, it is silently dropped at the destination.

Infiniband packets have additional fields. If a network is so large that it uses routers, in addition to switches, each packet includes a global router header (GRH) right after the local router header and before the transport header. High-performance computing networks (or maybe all) in use today are built without routers, and the global router header is absent from their Infiniband data packets.

Remote Direct Memory Access (RDMA) is a notable feature of Infiniband technology. RDMA may enter into or read from the memory of a remote computer on the network. RDMA request packets, which initiate an RDMA read, and the very first RDMA packet write into include an extended RDMA transport header (RETH). This header occurs right after base transport header. It is 16 bytes long.—a 64-bit virtual address, a 32-bit remote key, and a 32-bit field that gives the size in bytes of the RDMA transfer.

Acknowledgment (ACK) packets include the 4-byte acknowledgment extended transport header. The same packet may carry both an ACK header and payload, and thus serves a double purpose. For example, on an RDMA read, the very first packet carries an ACK header acknowledging the request and some of the remotely read data in its payload. The very last packet doubles up the same name. The first and last packets in a sequence are marked in the base transport header.

High-performance computing networks are built using switches and are currently not large enough to need routers. One consequence, we have already mentioned, the absence of the global routing header from the data packets. Another consequence is that an Infiniband data packet always follows the same path through the switches from a source to a given destination.
