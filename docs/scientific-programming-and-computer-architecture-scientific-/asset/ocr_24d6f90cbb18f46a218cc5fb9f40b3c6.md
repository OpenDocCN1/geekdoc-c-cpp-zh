The member function copyToSendbuf() copies localMN[] to the send buffer.

```
void Transpose::copyToSendbuf(double *localMN){
  long ncols = fN[p+1] - fN[p];
  for(long q=0; q < P; q++){
    long nrows = fM[q+1] - fM[q];
    long sbufindex = ncols * fM[q];
    long localindex = fM[q];
    long lda = M;
    transposew(localMN+localindex, lda,
    nrows, ncols,
    sendbuf+sbufindex);
}
```

On line 2, ncols is initialized to the number of columns of the M × N matrix stored locally. The local MPI process has rank p, where the for-loop variable q (line 3) loops over the ranks of all the P processes. The number of rows of the block matrix to be sent by the current process of rank p to the process of rank q is calculated on line 4 using fM[]. The index into the send buffer is equal to the total number of entries to be sent to processes with rank less than q (line 5). The index into localMN is simply equal to the index of the entry in the first column that gets to the process of rank q. The row number of that entry is equal to fM[q] (line 7). The call to the transpose function (lines 9 through 11) extracts the submatrix to be sent from the current process of rank p to the process of rank q by adding localindex to localMN and setting lda to M.
