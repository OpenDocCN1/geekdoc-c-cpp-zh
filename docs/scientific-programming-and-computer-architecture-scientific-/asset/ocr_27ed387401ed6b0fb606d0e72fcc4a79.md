The name supplied through the constructor is used for naming intermediate data files as well as the output. This class can show the plot, save an eps file, or save a Python script for generating the plot.

The Linux operating system provides a system call to open pipes to shell commands. For example

FILE *pypipe = popen("python", "w");\ opens a pipe to Python. We can treat this pipe as a file and write commands to be executed by Python as if we were writing to a file. For example, the following program fragments the sine function:

```
printf(pypipe,"import numpy as np\n");
printf(pypipe,"from matplotlib import pyplot as plt\n");
printf(pypipe,"x = np.linspace(-5.0, 5.0, 500)\n");
printf(pypipe,"plt.plot(x, np.sin(x))\n");
printf(pypipe,"plt.show()\n");
```

When the pipe is no longer needed, it may be closed using pclose(). The PyPlot class is implemented using pipes.
