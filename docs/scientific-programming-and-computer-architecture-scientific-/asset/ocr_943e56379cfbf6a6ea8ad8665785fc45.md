# 3.1. Overview of the x86 architecture

The reader may find it a little puzzling that “double” (or “long”) is used for 32-bit operands and “quad” for 64-bit operands. A word in the original 8086 machine of 1978 was 16 bits. Thus, double words are 32 bits and quad words are 64 bits, as a result of a choice made long ago.

# Getting started

For our first assembly program, we begin with the following simple C code:

```
#include <stdio.h>
int main(){
    int x, y, z;
    x = 1;
    y = 2;
    z = 3;
    printf("The sum of %d and %d is %d \n", x, y, z);
}
```

It is compiled using

```
gcc -S -O3 add.c
```

The -S flag tells the compiler to generate assembly only and leave it in the file add.s. Optimization is turned on with the -O3 flag so that the compiler generates cleaner code.

Below is a listing of the addtwo. assembly code. The listing is a cleaned version of the code generated by the compiler. In particular we removed some code at the bottom to an error handler.

```
1 .file "addtwo.s"
2 .section .mydata,"aMS",@probits,1
3 .LCO: "The sum of %d and %d is %d\n"
4 .string
5 .text
6 .globl main
7 .type main, @function
8 main:
9 movl $3, %ecx
```
