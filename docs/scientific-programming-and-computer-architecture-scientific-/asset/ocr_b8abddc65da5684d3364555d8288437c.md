The dimension of the matrix stored on each processor node is $dim1 \times dim2$ (lines 4 and 5). The matrix is stored in arrays a[] and b[] (line 6). In each step of Jacobi, the entries of b[] are computed using the entries of a[

Figure 6.8 shows the data layout assumed by the Jacobi2D class. Although the matrix in each node is only $dim1 \times dim2$, the actual matrix stored is $dim1 \times (dim2+2)$. The leftmost column is a copy of a column to the left and the rightmost column a copy of the column to the right, as shown in the figure. Both the arrays a[] and b[] are of length $dim1 \times (dim2+2)$. Thus, during any single Jacobi iteration, a processor node can update all its $dim2$ columns using data stored on it.
