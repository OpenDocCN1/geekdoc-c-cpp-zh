The matrices A[], B[], and C[] are copied into dhstm objects (lines 4 through 8) and then copied to device memory (9, 10, and 11). The cuBLAS function implements $C = \alpha AB + \beta C$. The parameters $\alpha$ and $\beta$ are set to 1 (lines 13 and 14).

In the call to the library function cublasDgemm, the first argument is the handle initialized by the constructor (line 19). The arguments on n 20 specify that neither A nor B needs to be transposed. Line 21 specifies that all the matrices are $N \times N$. The leading dimensions of all three matrices are given as $N$ (lines 23, 24, and 26).
