It is a bad idea to allocate large data structures statically.⁴ More generally, we can make room for an m × n matrix as follows:

```
a = (double *)malloc(m*sizeof(double));
```

We must remember to say free(a) when the memory is no longer needed.
Here come to the distinction between column-major and row-major storage.
In column-major storage, the (i,j)th entry of a[] is accessed as

```
a[i*j];
```

Here 0 i < m and 0 j < n. The column-major format is used by Fortran, BLAS, and LAPACK. In row-major storage, the (i,j)th entry of a[] is accessed as

```
a[i*n+j];
```

There is a natural way to approach the distinction between column-major format and row-major format. To access the entries of a[] in the order of storage, we may use code as follows column-major format.

```
for(int j=0; j < n; j++)
for(int i=0; i < m; i++)
  a[i + j*m] = ...
```
