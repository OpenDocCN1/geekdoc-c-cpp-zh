

# 6.3. MPI 示例

`read_mpi()` 函数与 `write_mpi()` 的区别在于它是以读取而非写入模式打开文件（见第 6 行），并且在第 21 行使用的是读取函数而不是写入函数。

`write_mpi()` 和 `read_mpi()` 这两个函数几乎逐行匹配，仅在两个处存在不相同，一些程序员可能会认为这两个函数反映了这种并行性。可以通过传递一个标志位来指示函数应该是写入还是读取，从而将这两个函数合并为一个，从而节省代码行数。但在两个相隔很远的地方使用标志位会破坏代码的流，并使其变得难以阅读。C++ 语言提供了诸如继承和模板等更结构化的设施来避免代码膨胀，尽管这些内容可能超出了作者的领域范畴。`write_mpi()` 和 `read_mpi()` 之间的并行性是语法上的，而非语义上的。向文件写入和从文件中读取是不同的操作。保持函数分离的优点在于优先考虑逻辑而非形式。

典型的配置可能有数百个处理器节点、数十个对象存储目标和一个元数据服务器。德克萨斯先进计算中心（Texas Advanced Computing Center）的 Lonestar 系统拥有超过 1000 个处理器节点和 90 个对象存储目标。其 Lustre 文件系统的总容量为 1 PB（拍字节）。还存在容量为该 10 倍的 Lustre 文件系统。

可以使用 `lfs getstripe` 命令获取 Lustre 文件的条带数（stripes）。对于一个 2 TB 的文件，`lfs getstripe` 产生了如下输出：

```
lmm_stripe_count: 50
lmm_stripe_size: 1048576
lmm_stripe_offset: 15
objxdid objid group
15 57347983 0x36b0f8f 0
```

| 9 | 56348442 | 0x35bcf1a | 0 |
| 65 | 45034528 | 0x2af2c20 | 0 |
| 4 | 56025829 | 0x35d6e2e5 | 0 |

该文件有 30 条带，这意味着它分布在 50 个对象存储目标上。条带大小为 $2^{20}$ 字节即 1 MB，这是 Lustre 默认的条带大小。如果条带大小为 1 MB，则第一个 1 MB 存储在第一个对象目标上（此处 `obidx` 为 15），下一个 1 MB 存储在下一个目标上（此处 `obidx` 为 9），依此类推。可以使用 `lfs stripe` 命令来设置条带数。下面的 C++ 类 `LustreFile` 是一个用于条带化的简单接口：

```
class LustreFile{
private:
    char dir[200];
    char fname[200];
    int rank;
    int nprocs;
    long totalsize;
    long localsize;
public:
    LustreFile(int rank, int nprocs, const char *dir, const char *fname);
    void stripe(int count, int stripes);
    void printinfo();
};
```

# 第 6 章 特别专题：网络与消息传递

创建文件的任务留给 rank 0。rank 0 在文件存在时将其删除。在第 4 行，构建字符字符串 `cmd[]`。在第 5 行，库函数 `system()`（它在 `stdlib.h` 中声明）调用 shell 并执行命令。条带化的命令在第 6、7、8 行组合。如果我们想要 50 个条带且条带大小为 4000 MB，命令为：

```
lfs stripetype --size 4000M --count 50 <filename>
```

此类命令在第 9 行通过 shell 发布。它创建一个新文件。虽然只有 rank 0 进程处理条带，但所有进程都必须调用成员函数 `stripe()`。第 10 行的屏障（barrier）确保在文件创建之前没有任何进程返回。屏障对于确保没有进程在文件创建之前尝试访问它至关重要。

```cpp
void LustreFile::stripe(int count, int stripes) {
    if(rank==0) {
        char cmd[200];
        sprintf(cmd, "rm %s/%s", dir, fname);
        system(cmd);
        sprintf(cmd, "lfs stripetype --size %dM --count %d %s/%s", stripes, count, dir, fname);
        system(cmd);
    }
    MPI_Barrier(MPI_WORLD);
}
```

成员函数 `write()` 和 `read()` 如下调用 `write_mpi()` 和 `read_mpi()`：

```cpp
void LustreFile::write(double *v) {
    long disp = 8*rank*(totalsize/nprocs);
    char famex[200];
    sprintf(fnamex, "%s/%s", dir, fname);
    write_mpi((void*)v, 8*localsize, famex, disp);
}

void LustreFile::read(double *v) {
    long disp = 81*rank*(totalsize/nprocs);
    char famex[200];
    sprintf(fnamex, "%s/%s", dir, fname);
    read_mpi((void*)v, 81*localsize, famex, disp);
}
```
