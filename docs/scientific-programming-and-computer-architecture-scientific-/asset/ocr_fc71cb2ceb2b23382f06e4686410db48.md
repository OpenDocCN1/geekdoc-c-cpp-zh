# Plotting in C/C++ programs

Plots and pictures that show output and display data can make programs less cryptic and clarify what is going on. A picture can be worth a thousand lines of code.

Plotting libraries are not part of the C/C++ languages for a good reason. Although plotting is very helpful, it is too high level of an activity and far removed from the view of the machine that the C language offers.
