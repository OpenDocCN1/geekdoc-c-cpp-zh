# 6.4.4 Client

The client mirrors the server in some ways but differs in others. The client begins by establishing a connection with the server.

```
1 int connect2server(const char *server,
2 const char *portnum){
3 struct addrinfo hint;
4 memset(&hint, 0, sizeof(hint));
5 hint.ai_family = AF_UNSPEC;
6 hint.ai_socktype = SOCK_STREAM;
7 struct addrinfo *list;
8 getaddrinfo(server, portnum, &hint, &list);
9 int sock2server = socket(list->ai_family,
10 list->ai_socktype,
11 list->ai_protocol);
12 connect(sock2server, list->ai_addr,
13 list->ai_addrlen);
14 freeaddrinfo(list);
15 return sock2server
16 }
```

The argument server (line 1) is the name of machine on which the server is running. It could be login.univ.edu, for example. The hint specifies a TCP connection (line 6) but not the address family. The call to getaddrinfo() on line 7 gives the name of the server (as in the program for printing IP addresses) but also specifies a port number. The specified port number is the second argument to this function. It opens a TCP socket on lines 9, 10, and 11. The socket sock2server is connected to the server on lines 12 and 13 using the system connect(). There is some subtlety in the ways connections are established and terminated over the Internet that is not discussed here.

The system call connect() is the client-side counterpart of accept(). The second argument to connect() is of type const struct sockaddr*.
