# 5.2.3 Matrix transpose

The function blocktransx() defined below is similar to the one defined in chapter
4. This definition differs by allowing the matrix stored in the array[] to have a
leading dimension greater than the number of rows.

```
void blocktransx(double *restrict a, double *restrict b,
    int l1db, int m, int n)
    assert((m%B==0)&&(n%B==0));
    for(int i=0; i < m; i+=B)
        for(int j=0; j < n; j+=B)
            for(int ii=0; ii < B; ii++)
                for(int jj=0; jj < B; jj++)
                    b[j+jj+(i+ii)*l1db] = a[i+ii+(j+jj)*m];
}
```
