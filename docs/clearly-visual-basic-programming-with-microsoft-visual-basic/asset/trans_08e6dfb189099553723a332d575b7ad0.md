

## 关键术语

- **GetLowerBound 方法**—返回一个整数，表示数组中的最小下标
- **GetUpperBound 方法**—返回一个整数，表示数组中的最大下标
- **二维数组**—一种数组，其元素由两个数字的唯一组合标识：行下标和列下标
