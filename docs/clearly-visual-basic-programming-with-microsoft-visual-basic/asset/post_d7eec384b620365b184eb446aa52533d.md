## SUMMARY

- Each element in a two-dimensional array is identified by a unique combination of two subscripts: a row subscript and a column subscript. The subscripts appear in parentheses after the array’s name. You list the row subscript first, followed by a comma and the column subscript.
- The first row subscript in a two-dimensional array is 0. The first column subscript also is 0.
- When declaring a two-dimensional array, you provide either the highest row and column subscripts or the initial values.
- The number of rows in a two-dimensional array is one number more than its highest subscript. Likewise, the number of columns is one number more than its highest column subscript.
- You refer to an element in a two-dimensional array using the array’s name followed by the element’s row and column subscripts, which are separated by a comma.
- You use both an outer loop and a nested loop to access each element in a two-dimensional array. One loop controls the row subscript and the other loop controls the column subscript.
- An array’s GetLowerBound and GetUpperBound methods return the lowest subscript and highest subscript, respectively, in the array.
