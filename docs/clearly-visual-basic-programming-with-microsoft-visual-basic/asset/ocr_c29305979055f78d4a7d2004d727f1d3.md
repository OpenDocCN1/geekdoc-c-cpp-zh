+      b. only *how* to calculate something

+      d. entering the output items, then processing the input items, and then displaying, printing, or storing the output items
+   4. In a flowchart, the ________ symbol is used to represent an instruction that gets information from the user.
+      a. enter
+      b. input/output
+      c. process
+      d. start/stop

+      a. one column for each input item and one column for each output item
+      b. one column for each input item and one column for each processing item
+      c. one column for each processing item and one column for each output item
+      d. one column for each input item, one column for each processing item, and one column for each output item
