# # CLOCK APPLICATION

A clock uses nested repetition structures to keep track of the time. For example, consider a clock's hour and minute hands only. The minute hand is controlled by the inner (nested) loop, whereas the hour hand is controlled by the outer loop. The minute hand on a clock moves one position, clockwise, for every minute that has elapsed. After the minute hand moves 60 positions, the hour hand moves one position, also clockwise. The minute hand then begins its journey around the clock again. Figure 16-3 shows the logic used by a clock's hour and minute hands. Notice that the entire nested loop is contained within the outer loop; this must be true for the loop to be nested and for it to work correctly.

```
~~~
1. repeat for hours from 0 through 23 in increments of 1
    repeat for minutes from 0 through 59 in increments of 1
        move minute hand 1 position, clockwise
    end repeat
    move hour hand 1 position, clockwise
end repeat
~~~
```
