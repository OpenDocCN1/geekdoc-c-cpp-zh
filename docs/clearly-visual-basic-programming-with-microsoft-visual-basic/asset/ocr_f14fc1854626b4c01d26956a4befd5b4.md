# KEY TERMS

**GetLowerBound method**—returns an integer that represents the lowest subscript in an array

**GetUpperBound method**—returns an integer that represents the highest subscript in an array

**Two-dimensional array**—an array whose elements are identified by a unique combination of two numbers: a row subscript and a column subscript
