It's a common programming practice to include one or more comments in a procedure. A **comment** is a message to the person reading the code and is referred to as **internal documentation**. Many programmers use comments to document a procedure's purpose, as well as to explain various sections of the procedure's code. Comments make the code more readable and easier to understand by anyone viewing it. You create a comment in Visual Basic by placing an apostrophe (') before the text that represents the comment. The computer ignores everything that appears after the apostrophe on that line. Although it is not required, some programmers use a space to separate the apostrophe from the comment itself, and they follow the comment with a blank line.
