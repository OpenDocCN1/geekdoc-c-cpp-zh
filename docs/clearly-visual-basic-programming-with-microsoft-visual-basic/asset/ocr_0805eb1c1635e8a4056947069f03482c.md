# KEY TERMS

**Multiline property**—the text box property that specifies whether the text can span more than one line in the control

**ReadOnly property**—the text box property that specifies whether the contents of the text box can be edited by the user

**ScrollBars property**—the text box property that indicates whether scroll bars appear on the control; used in conjunction with the Multiline property
