Type **`Dim records = From employee In EmployeesDataSet.tblEmploy _`** and press **Enter**. Type **`Where employee.Last_Name.ToUpper Like strSearch & "**" _`** and press **Enter**, then type **`Select employee`** and press **Enter**. (If a jagged line appears below records in the Dim statement, click Tools on the menu bar, then click Options. Expand the Projects and Solutions entry, then click VB Defaults. Change Option Strict to Off.)
+   4. The LINQ statement merely selects the records and assigns them to the records variable. To view the records in the interface, you need to assign the contents of the records variable to the BindingSource object's DataSource property. By doing this, the label controls bound to the BindingSource object will display the appropriate data. Click the **blank line** below the ' display the records comment, then type **`TblEmployBindingSource.DataSource = records`** and press **Enter**.
