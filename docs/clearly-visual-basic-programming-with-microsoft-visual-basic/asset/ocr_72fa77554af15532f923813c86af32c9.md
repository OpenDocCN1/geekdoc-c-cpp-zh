Figure 12-26 shows the basic syntax of the Trim method and includes examples of using the method. In the syntax, *string* typically is either the Text property of a control or the name of a String variable. When the computer processes the Trim method, it makes a temporary copy of the *string* in memory, and then performs the necessary trimming on the copy only. In other words, the method does not remove any spaces from the original *string*. To remove the spaces from the original *string*, you must assign the result of the Trim method to the *string*, as shown in Example 2.
