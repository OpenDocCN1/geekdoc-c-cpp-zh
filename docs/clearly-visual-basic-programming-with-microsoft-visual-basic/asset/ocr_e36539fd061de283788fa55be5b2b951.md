# USING THE INDEXOF METHOD

| Syntax | Purpose |
|---|---|
| `string.IndexOf(subString[, startIndex])` | searches a string to determine whether it contains a specific sequence of characters, and then returns an integer that indicates the starting position of the characters within the string |

**Example 1**
`strMessage = "Visual Basic is fun!"`
`intIndex = strMessage.ToUpper.IndexOf("FUN")`
assigns the number 16 to the intIndex variable
[index 16]

**Example 2**
`strMessage = "Visual Basic is fun!"`
`intIndex = strMessage.IndexOf("is", 7)`
assigns the number 13 to the intIndex variable
[index 13]

**Example 3**
`strMessage = "Visual Basic is fun!"`
`intIndex = strMessage.IndexOf("S")`
assigns the number -1 to the intIndex variable, because the strMessage variable does not contain an uppercase letter S
