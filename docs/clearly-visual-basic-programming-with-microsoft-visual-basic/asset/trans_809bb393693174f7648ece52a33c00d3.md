## 总结

- Microsoft Access 创建的数据库是关系数据库。关系数据库可以包含一个或多个表。每个表包含字段和记录。
- 关系数据库中的数据可以按任意顺序显示，并且可以控制要查看的信息量。
- 大多数表包含唯一标识每条记录的主键。
- 要访问数据库中存储的数据，首先将应用程序连接到数据库。这样做会创建一个数据集，其中包含表对象和字段对象等对象。
