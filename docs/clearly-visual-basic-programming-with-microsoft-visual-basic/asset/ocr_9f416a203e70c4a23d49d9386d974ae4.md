To sort a one-dimensional array in descending order, you first sort the values in ascending order, and then use the Array.Reverse method to reverse the array elements. The method’s syntax is Array.Reverse(arrayName). When an array is sorted in descending order, the first element in the array contains the largest value and the last element contains the smallest value.
