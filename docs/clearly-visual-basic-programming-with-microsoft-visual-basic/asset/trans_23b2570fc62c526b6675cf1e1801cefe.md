

- **过程级变量**——在过程中声明的变量；具有过程作用域
- **作用域**——变量在应用程序代码中被识别的区域
- **字符串**——用双引号括起来的文本
- **ToString 方法**——用于将数值变量的内容转换为文本的方法；同时也会格式化该数字
- **TryParse 方法**——用于将文本转换为数值数据类型
- **变量**——应用程序运行期间其内容可以更改的内存位置
