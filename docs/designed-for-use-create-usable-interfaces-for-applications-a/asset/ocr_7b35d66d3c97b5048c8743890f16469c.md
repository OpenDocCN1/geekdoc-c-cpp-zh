# Takeaway Points

+   - Warning people before they do something potentially dangerous doesn’t work, because people ignore these warnings.
+   - Instead, allow people to undo their actions so that they can revert accidents.
+   - If it is not technically possible for you to offer undo, at least delay the potentially dangerous action so that people can prevent it from happening even after issuing the command.
