If the information is not particularly important, don't show it. If it is important but no immediate action is required, show the information in a way that does not interrupt your users. For example, you could use a nonmodal,⁶ nonintrusive way of alerting them. Here's how HP's webOS shows new messages to the user:

![](bbox=[0.138, 0.36, 0.736, 0.66])

When a new message arrives, the small black strip with a little message icon slides up from the bottom of the screen. Touching the strip shows some more information about the message. Touch the message itself, and it opens inside its app.

6. If it's nonmodal, it doesn't prevent the user from doing something else. For more about modes, see Chapter 20, Modes, on page 175.
