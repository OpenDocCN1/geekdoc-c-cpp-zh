# 20.1 Nonobvious Modes

In *The Humane Interface* [Ras00], Jef Raskin explains that “modes are a significant source of errors, confusion, unnecessary restrictions, and complexity in interfaces.”

Modes are confusing when people do not realize what mode they are in—in other words, when they are nonobvious. The Caps Lock key, for example, indicates that it is active with a small light that is easily overlooked.

Another example of a nonobvious mode is the currently active tool in an image editor:

Since people may not realize what mode the user interface is in, their actions may create unexpected results. Logging in doesn't work properly, or the image editor creates a circle when the user wants to create a rectangle.

Modes should be obvious even if the user doesn't remember having activated them. For example, if you select the Open File menu command in Mac OS X, a modal dialog box opens. This mode is obvious to the user immediately after he has selected Open File, but if he then goes to get a cup of coffee and comes back to his computer five minutes later, he may not immediately realize that the computer is still in the Open File mode.
