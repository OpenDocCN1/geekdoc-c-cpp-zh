# Have Opinions Instead of Preferences

If you're are not sure about a specific design choice, it's always easiest to leave it up to the user. When Mac users minimize windows into the Dock, some probably want it to elegantly flow into the Dock. Others may prefer their windows to just zoom away, linearly scaling down. So, why not give them both?

![](bbox=[0.13, 0.51, 0.77, 0.82])
