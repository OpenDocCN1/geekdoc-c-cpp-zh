# What’s the Technique?

Basically, you invite people, observe them while they use your product, and use information from these tests to make your product better.

# Why Is This a Good Idea?

Doing usability tests of any kind gives you great insight into where your user interface has problems.

In addition to that, even if you want to focus on doing remote usability tests, you should start by doing some in-person tests to get a feel for how to run usability tests in general.
