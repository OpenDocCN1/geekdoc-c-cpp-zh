The execution of the command "ss -lf" displays listening sockets. We may collect more scientific statistics, for instance by also specifying -t for TCP, -u for UDP, -d for DCC, and -x for Unix domain sockets. By combining the options, we define a command that collects listening sockets of each type of connection, such as "ss -lt", "ss-lu", "ss-ld", "ss-hw", and "ss-lx". The first command ("ss -lt") may also be specified as "ss -tf" or "ss -l". Likewise, others combinations may be represented using these alternative names. If the options -t, -u, -d, -w, and -x are adopted, the respective commands display established or connected. We also have to collect information of connections that are listening, using the option -a. As example, the execution of "ss -a -f" displays a portion of data similar to the following.
