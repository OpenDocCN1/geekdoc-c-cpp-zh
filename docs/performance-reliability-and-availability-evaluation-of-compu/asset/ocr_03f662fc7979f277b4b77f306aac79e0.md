# 112 Performance Reliability, and Availability Evaluation of Computational Systems

Let $E(\Phi(l_1, \mathbf{X}(t))) = R_s(l_1, \mathbf{X}(t))$, and $E(\Phi(l_0, \mathbf{X}(t))) = R_s(l_0, \mathbf{X}(t))$, then

$R_s(t) = R_i(t) 	imes R_s(l_1, \mathbf{X}(t)) + (1 - R_i(t)) 	imes R_s(l_0, \mathbf{X}(t))$.

Therefore

$R_s(t) = R_i(t) 	imes R_s(l_1, \mathbf{X}(t)) + R_s(l_0, \mathbf{X}(t)) - R_i(t)R_s(l_0, \mathbf{X}(t))$.

$R_s(t) = R_i(t) 	imes R_s(l_1, \mathbf{X}(t)) - R_s(l_0, \mathbf{X}(t)) + R_s(l_0, \mathbf{X}(t))$.

As $I_i^B = \partial R_s(t)/\partial R_i(t)$ (see 18.9.2), we have

```
$I_i^B = \frac{\partial R_s(t)}{\partial R_i(t)} = R_s(l_1, \mathbf{X}(t)) - R_s(l_0, \mathbf{X}(t)). \quad (18.9.3)$
```
