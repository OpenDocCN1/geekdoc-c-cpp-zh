# Command free

The command free uses the /proc/meminfo file to report the amount of free and used memory (both RAM and swap on the system) as well as buffers used by the kernel. The command “free” with option -m presents the memory data in megabytes, such as

| total | used | free | shared | buff/cache | available |
|---|---|---|---|---|---||
| Mem | 2013 | 1173 | 241 | 25 | 598 | 570 |
| Swap | 974 | 61 | 913 | | | |

The first row would seem to say that system has 2013 MB of memory, 1173 MB used, and 241 MB free. This is because the Linux management system stores metadata recently accessed areas of the disk in buffers. Examples of metadata are permissions and the contents of a directory. Likewise, caches store recently accessed files. As areas store transient content, they are considered available for use.

+   * The total amount of memory that can be used by the applications.
* used - Memory, which is used = total – free – buffers – cache
* free - Unused memory.
* buff/cache - The combined memory used by buffers and cache.
* available - An estimate of the amount of memory available for new applications, without swapping.

> ¹⁰RAM (Random Access Memory) swap space is referred to as virtual memory. In Linux, the swap space is a disk area that contains pages when RAM fills up, and more space is required.

> ¹¹The exibyte (symbol EiB) is 2⁶⁰ bytes. The exibyte is approximately equal to 1.15 exibytes (EB).
