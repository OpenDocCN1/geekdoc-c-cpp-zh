The CTMC rate matrix

$Q = \begin{pmatrix} 0 & 0 & 0 & \mu & 0 \\ \lambda_{sb} & \delta-\mu-\lambda_{sb} & \mu & \delta & \lambda_{sb} \\ 0 & \lambda_{op} & -\lambda_{op}-\lambda_{sb} & 0 & 0 \\ \lambda_{op} & 0 & \mu & -\mu-\lambda_{op} & 0 \\ \lambda_{op} & 0 & \mu & 0 & -\mu-\lambda_{op} \end{pmatrix}$

The steady-state availability is calculated summing up the steady-state of the operational states, that are 2, 1, and 1'. Therefore,

$A = \pi_2 + \pi_1 + \pi_{1'}$.

Solving $\Pi \cdot Q = 0$, $\sum \pi_i = 1$, we get

```
$A = \frac{\delta (\mu + \lambda_{op} + \lambda_{sb}) + \lambda_{op}\lambda_{sb} + (\mu + \lambda_{sb})^2}{\delta (\lambda_{op}^2 + \lambda_{op}(\mu + \lambda_{sb}) + \mu (\mu + \lambda_{sb}) + (\mu + \lambda_{op})(\lambda_{op}\lambda_{sb} + \lambda_{sb}^2))}$.
```

The availability represented in the number of nines #9s = $-log(1 - A)$, and the downtime in a $T$ is

```
$DT = UA \times T$.
```

Thus,

```
$DT = \frac{\lambda_{op} (\lambda_{op} + \lambda_{sb}) + \lambda_{op}\lambda_{sb} + (\mu + \lambda_{sb})^2}{\delta (\lambda_{op}^2 + \lambda_{op}(\mu + \lambda_{sb}) + \mu (\mu + \lambda_{sb}) + (\mu + \lambda_{op})(\lambda_{op}\lambda_{sb} + \lambda_{sb}^2))} \times T$,
```

where $UA=1$. Figure 21.26 shows the reliability model of the system depicted in Figure 21.24. This model has three states: 2, 1', and 0. State 2 denotes that both servers are operational. The primary server processes the workload, and the spare server is in standby mode. Therefore, in state 2, the spare server fails; in such a case, the system transitions to state 1' with a rate of $\lambda_{sb}$. It is worth mentioning that state 1' is still operational because the failed server is not the one that is processing. In state 1', two events are possible. First, the spare server may be repaired, which takes the system back to state 2 with a rate of $\mu$. The second possible event is the failure of the primary server. Such an event takes the system from state 1' to state 0 with a rate of $\lambda_{op}$. In state 0, the system is in failure. In state 2, the primary server may also fail. If it does, the system transitions to 0 with a rate of $\lambda_{op}$ and fails to deliver the required service.

```
$Q = \begin{pmatrix} -\lambda_{op}-\lambda_{sb} & \lambda_{sb} & \lambda_{op} \\ \mu & -\mu-\lambda_{op} & \lambda_{op} \\ 0 & 0 & 0 \end{pmatrix}$.
```

Therefore, the system reliability may be estimated by solving

```
$\frac{d\Pi(t)}{dt} = \Pi(t) \cdot Q$,
```

where $\Pi(t) = (\pi_2(t), \pi'_1(t), \pi_0(t))$ and $\pi_2(t) + \pi'_1(t) + \pi_0(t) = 1$ through the expression

```
$R(t) = \pi_2(t) + \pi'_1(t)$.
```

## 21.7 ACTIVE-ACTIVE REDUNDANCY

Consider the system depicted in Figure 21.29. These servers share the workload processing that arrives at the system; that is, both servers are active and processing. The system is considered available as long as at least one server is processing. However, if both servers are operational, the processing capacity is higher than if only one server is operational.

Assume the times to failure of both servers are independent and identically distributed according to an exponential distribution with a rate λ. Also, consider that the time to repair a server is exponentially distributed with a rate μ. Hence, CTMC shown in Figure 21.6 can be adopted as a simple availability model of active-active configuration considering only one repair facility. Likewise, the CTMC shown in Figure 21.4.b is an availability model when considering an unlimited number of repair facilities. For both models, the active-active configuration availability is estimated by

> $A = \pi_2 + \pi_1.$

The availability expressions for both cases are represented by Expression 21.2.2 (one repair facility) and Expression 21.2.1 (unlimited repair facilities). They are shown here again for the sake of clarity. The availability of the active-active servers when considering only one repair facility

> $A = \frac{\mu(2\lambda + \mu)}{2\lambda^2 + 2\lambda\mu + \mu^2},$

and the availability when considering an unlimited repair facility

> $A = \frac{\mu(2\lambda + \mu)}{(\lambda + \mu)^2}$.
