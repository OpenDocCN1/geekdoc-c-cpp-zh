# Performance, Reliability, and Availability of Computational Systems

Now, let assume a non-repairable KoN system with i.i.d. components' time to failure that are exponentially distributed with rate $\lambda$. The system reliability is then calculated by

```
$R(t) = \sum_{i=K}^{N} \binom{N}{i} e^{-i\lambda t}(1-e^{-\lambda t})^{N-i}. \quad (18.5.40)$
```

The system mean time to failure is

```
$MTTF = \int_{0}^{\infty} R(t)dt.$
```

```
$MTTF = \int_{i=K}^{N} \binom{N}{i} e^{-i\lambda t}(1-e^{-\lambda t})^{N-i} dt.$
```

```
$MTTF = \sum_{i=K}^{N} \binom{N}{i} \int_{0}^{\infty} e^{-i\lambda t}(1-e^{-\lambda t})^{N-i} dt.$
```

Let $u=1-e^{-\lambda t}$, then $e^{-\lambda t}=1-u$, $e^{-(i-1)\lambda t}=(1-u)^{i-1}$, and $du=\lambda e^{-\lambda t}dt$. Therefore

```
$MTTF = \frac{1}{\lambda} \sum_{i=K}^{N} \binom{N}{i} \int_{0}^{1} e^{-(i-1)\lambda t}(1-e^{-\lambda t})^{N-i} \lambda e^{-\lambda t} dt.$
```

As $t=0, u=0$, and $t\to\infty, u=1$, then

```
$MTTF = \frac{1}{\lambda} \sum_{i=K}^{N} \binom{N}{i} \int_{0}^{1} (1-u)^{i-1} u^{N-i} du,$
```

which leads to to

```
$MTTF = \frac{1}{\lambda} \sum_{i=K}^{N} \frac{N}{i}. \quad (18.5.41)$
```
