The first line shows that 265 calls were monitored. Of those calls, 264 were primitive. The program execution time was 3.504s, considering a resolution of 3 decimal places. The next line informs that the lines were ordered by their cumulative time (cutime). It is worth noting that function slow took 3.002s and medium took 0.502s. When there are two numbers in the column (for example, 2/1), the function is recursive. The second value is the number of primitive calls, and the first is the total number of calls. When the function is not recursive, these two values are the same, and only one number is shown.

The memory profiler Python module gives support to program memory usage deterministic profiling. The best way to use it is with a decorator named @profile (a hook), which is added to the Python code. Each decorator should be included before the definition of each Python profiler. When the command-line

> python -m memory_profiler program.

a memory profile related to the program memory.py is generated on the standard output, which could be redirected to the file. As an example, consider the Program 8. The original program was modified by including decorators @profile (in red) before each user-function definition.
