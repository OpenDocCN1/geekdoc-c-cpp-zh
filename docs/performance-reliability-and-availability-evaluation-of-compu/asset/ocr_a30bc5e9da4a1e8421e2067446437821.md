After compiling the modified C source code and linking the corresponding object file with the object file obtained from the assembly code, we get a new executable file. Assume the address of the assembly function is 3100030H, and its final address is 310261H. The program was executed. As already shown above, its execution lasted 1680ms. The time interruption service is executed every 0.1ms (timer clock period). Hence, the program is interrupted every 0.1ms for executing the time interruption service. Before changing the instruction pointer address, when the program is interrupted the address of the next instruction is stored onto the system stack; then the first address of the time interruption service is stored in the instruction pointer register. Hence, the time interruption service is executed.

At the end of the interruption service, the program's execution is resumed by recovering the program's next instruction address from the stack. This process continues during the period the computer is functioning. As the program in execution is interrupted every 0.1ms for processing interruption service, this service is an interesting location to insert a few instructions to check the program's interrupted address.
