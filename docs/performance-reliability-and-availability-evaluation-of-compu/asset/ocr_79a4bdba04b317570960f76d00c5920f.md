# 18.8 PATHS AND CUTS

Consider a coherent system represented by a RBD, and its set of components $CS=\{b_1, b_2\}$. A **path** $P$ is a set of components (blocks), $P \subseteq CS$, if operational connects the source node $(S)$ to the target node $(T)$. Otherwise stated, a path set $P$ is a set of components by functioning which ensures the system is functioning.

The vector state $X_P$ that represents the path $P$ is a denoted path vector. In other words, $X_P$ is called a path vector if $\Phi(X_P) = 1$. A path vector is called minimal if $\Phi(Y) = 0$ for every $Y < X$. The corresponding set of components $P$ is called a **minimal path** (minpath). In a series system of $n$ components, there is only one minimal path set, and each is composed of every component of the system. In the other, in a parallel system with $n$ components, there are $n$ minimal paths, each set formed by only one component.

Assume the RBD depicted in Figure 18.22.a. The set of blocks $B=\{b_1, b_2\}$, represented by its respective vector $X_B=(1, 1, x_3, x_4, x_5)$, is a path, since $x_1=1$ and $x_2=1$, $\Phi(X_B)=x_1=x_2=1$.

The set $B'=\{b_1, b_2, b_4\}$, and respective state vector $X_{B'}=(1, 1, x_3, 1, x_5)$, also leads to $\Phi(X_{B'})=1$; thus $B'$ is also a path. However, $B'$ is not minimal. Observe that $X_B < X_{B'}$ and $\Phi(X_B)=1$; hence not minimal. However, for every $Y < X_B$, $\Phi(Y)=0$; thus minimal.
