If the time to failure of every component is identically distributed according to an exponential distribution with rate $\lambda$, and if the time to repair of every component is also identically distributed and follows an exponential distribution with rate $\mu$, the components'steady-state availability is

```
$A_i = \frac{\mu}{\lambda + \mu}$
```

Therefore, the system S steady-state availability is

```
$A = 1 - \left(1 - \frac{\mu}{\lambda + \mu}ight)^n \quad (18.5.19)$
```

Hence

```
$A = 1 - \left(\frac{\lambda}{\lambda + \mu}ight)^n \quad (18.5.20)$
```

and the system unavailability is

```
$UA = \left(\frac{\lambda}{\lambda + \mu}ight)^n \quad (18.5.21)$
```

Consider a system composed of two parallel components with time to fail exponentially with rates $\lambda_1$ and $\lambda_2$. The system reliability is

```
$R(t) = 1 - (1 - e^{-\lambda_1 t})(1 - e^{-\lambda_2 t})$
```

The MTTF of this system is obtained from

```
$MTTF = \int_0^{\infty}R(t)dt = \int_0^{\infty}(1 - e^{-\lambda_1 t})(1 - e^{-\lambda_2 t})dt$
```

```
$MTTF = \int_0^{\infty}(e^{-\lambda_1 t} + e^{-\lambda_2 t} - e^{-(\lambda_1 + \lambda_2)t})dt.$
```

```
$MTTF = \int_0^{\infty}e^{-\lambda_1 t}dt + \int_0^{\infty}e^{-\lambda_2 t}dt - \int_0^{\infty}e^{-(\lambda_1 + \lambda_2)t}dt.$
```

```
$MTTF = \frac{1}{\lambda_1} + \frac{1}{\lambda_2} - \frac{1}{\lambda_1 + \lambda_2} . \quad (18.5.22)$
```
