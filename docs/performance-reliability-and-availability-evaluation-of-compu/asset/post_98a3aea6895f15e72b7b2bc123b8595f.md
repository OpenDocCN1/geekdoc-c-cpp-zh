# 302 Performance, Reliability, and Availability Evaluation of Computational Systems

The capacity-oriented availability is computed using

```
$COA = \frac{E{\#V_U\} + E{\#W_U\} + E{\#V_U\} + E{\#W_U\} + E{\#V_U\}}{N \times M}$
```

**Example 22.8.3.** Suppose we have a system composed of five similar physical servers ($N=5$), whose time to failure and time to repair are exponentially distributed with mean equal to $MTTF_S=810h$ and $MTTR_S=20h$. Each server hosts $M=8$ virtual machines. Their time to failure and time to repair are also to be exponentially distributed with means equal to $MTTF_U=1000h$ and $MTTR_U=0.05h$. The SPN representing this system is depicted in Figure 22.4. The numeric analysis using the Mercury tool by applying the Gauss-Seidel iterative method. The state-space was 100,000. The average number of virtual machines alive was $ANMA=39.03179$, and the capacity-oriented availability $COA=0.97579$. Considering the system available if at least one $V$ is operational, its availability was $\#V=8$.

Figure 22.25 and Table 22.25 show the availability for a system with $N=5$ servers and each server hosting $M=4$ VMs when considering the system available for $K$ out of 20 VMs, for $K=\{10, 11, 12, \dots, 20\}$.

**Figure 22.25** $A = P(\#V_1U + \#V_2U + \#V_3U + \#V_4U + \#V_5U \geq K) \times K \in \{10, 11, 12, \dots, 20\}$.

Such modeling approach would benefit from modeling coloured stochastic Petri nets [170, 478] due to its regularity. However, the adoption of such class of SPN would not reduce the state-space size. Therefore, the two-level SPN strategy is better since the number of states generated is significantly smaller.

The model presented in Figure 22.26 is the two-level SPN availability model of the system studied above. Figure 22.26a is a higher-level model which allows calculating the probability of having $i \in \{0, 1, 2, \dots, N\}$ servers available ($PISA$).
