Solving $\Pi \cdot Q = 0$, $\sum \pi_i = 1$, we get

```
$A = \frac{\delta (\mu + \lambda_{op} + \lambda_{sb}) + \lambda_{op}\lambda_{sb} + (\mu + \lambda_{sb})^2}{\delta (\lambda_{op}^2 + \lambda_{op}(\mu + \lambda_{sb}) + \mu (\mu + \lambda_{sb}) + (\mu + \lambda_{op})(\lambda_{op}\lambda_{sb} + \lambda_{sb}^2))}$.
```

The availability represented in the number of nines #9s = $-log(1 - A)$, and the downtime in a $T$ is

```
$DT = UA \times T$.
```

Thus,

```
$DT = \frac{\lambda_{op} (\lambda_{op} + \lambda_{sb}) + \lambda_{op}\lambda_{sb} + (\mu + \lambda_{sb})^2}{\delta (\lambda_{op}^2 + \lambda_{op}(\mu + \lambda_{sb}) + \mu (\mu + \lambda_{sb}) + (\mu + \lambda_{op})(\lambda_{op}\lambda_{sb} + \lambda_{sb}^2))} \times T$,
```

where $UA=1$. Figure 21.26 shows the reliability model of the system depicted in Figure 21.24. This model has three states: 2, 1', and 0. State 2 denotes that both servers are operational. The primary server processes the workload, and the spare server is in standby mode. Therefore, in state 2, the spare server fails; in such a case, the system transitions to state 1' with a rate of $\lambda_{sb}$. It is worth mentioning that state 1' is still operational because the failed server is not the one that is processing. In state 1', two events are possible. First, the spare server may be repaired, which takes the system back to state 2 with a rate of $\mu$. The second possible event is the failure of the primary server. Such an event takes the system from state 1' to state 0 with a rate of $\lambda_{op}$. In state 0, the system is in failure. In state 2, the primary server may also fail. If it does, the system transitions to 0 with a rate of $\lambda_{op}$ and fails to deliver the required service.

```
$Q = \begin{pmatrix} -\lambda_{op}-\lambda_{sb} & \lambda_{sb} & \lambda_{op} \ \mu & -\mu-\\lambda_{op} & \lambda_{op} \ 0 & 0 & 0 \end{pmatrix}$.
```

Therefore, the system reliability may be estimated by solving

```
$\frac{d\Pi(t)}{dt} = \Pi(t) \cdot Q$,
```

where $\Pi(t) = (\pi_2(t), \pi'_1(t), \pi_0(t))$ and $\pi_2(t) + \pi'_1(t) + \pi_0(t) = 1$ through the expression

```
$R(t) = \pi_2(t) + \pi'_1(t)$.
```
