# Linpack_Bench

```
{
    dtemp = dx[i] * dy[i] ]
    + dx[i+1] * dy[i+1]
    + dx[i+2] * dy[i+2]
    + dx[i+3] * dy[i+3]
    + dx[i+4] * dy[i+4];
}

return dtemp;
}
/********************************************************************************/
int dgefa ( double a[], int lda, int n, int ipvt[]) )
/********************************************************************************/
```

Purpose:

DGEFA factors a real general matrix.

Modified:

16 May 2005

Author:

C version by John Burkardt.

Reference:

Jack Dongarra, Cleve Mover, Jim Bunch and Pete Stewart,
LINPACK User's Guide,
SIAM, (Society for Industrial and Applied Mathematics),
3600 University City Science Center,
Philadelphia, PA, 19104-2688.
ISBN 0-89871-172-X

Parameters:

Input/output, double A[LDA+N].
 input, the matrix to be factored.
On output, an upper triangular matrix and the multipliers
used to obtain it. The factorization can be written
A=L*U, where L is a product of permutation and unit lower
tangular matrices, and U is upper triangular.

Input, int LDA, the leading dimension of A.

Input, int N, the order of the matrix A.

Output, int IPVT[N], the pivot indices.
