Another related concept is the non-dimensional resolution, which is defined as

```
$r_{ND} = \frac{1}{2^n-1}, \quad (23.1.4)
```

which for a measurement system with large $n$, it may be approximated by

```
$r \sim \frac{1}{2^n}. \quad (23.1.5)
```

As a simple example, consider a timer, whose clock frequency is specified as $f_1=1kHz$. Hence, the clock period is $T_c=1ms$. If the number of bits of the timer is $n=8$, the maximal event duration that could be measured by the timer maximal supported is, $2^n-1=2^8-1=255$, multiplied by the clock cycle ($T_c$); $255 \times 1ms=255ms$. Therefore, the shortest time that could be measured by the timer in this configuration is (see Equation 23.1.3)

```
$r_D = \frac{255ms}{2^8-1} = 1ms.
```

Now, consider the timer is configured on a different scale. In this new scale, the clock frequency is specified as $f_2=500Hz$. Hence, the clock period $T_c=2ms$. As the number of bits of the timer is $n=8$, the maximal event duration that the timer could measure is $255 \times 2ms=510ms$. However, the shortest time that this timer could measure in this configuration is

```
$r_D = \frac{510ms}{2^8-1} = 2ms.
```
