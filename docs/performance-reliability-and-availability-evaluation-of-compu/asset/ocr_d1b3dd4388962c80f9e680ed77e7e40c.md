**Exercise 26.** The Script 12 below collects one hundred-sized sample of memory utilization using the command `free`. The delay between measures is sixty seconds. At each collect, capture the total memory used and the free memory in megabytes. The script produces a rx file organized in columns.

# Algorithm 12 Memory Collection Script - Exercise 26

```
free -m | awk 'NR=1{printf "%s \%s\n", $2, $3}' >> memfree.txt;
for i in (1..100)
do
  free -m | awk 'NR=2{printf "%d \%d\n", $2, $3}' >> memfree.txt;
  sleep 60
```
