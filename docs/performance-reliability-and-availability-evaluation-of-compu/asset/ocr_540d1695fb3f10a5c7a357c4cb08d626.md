# Fanban

Fanban is a Java open-source performance workload creation, and execution framework [134]. Fanban has two major, the Fanban Driver Framework and the Fanban Harness. The Fanban Driver Framework is an API-based framework that aims at developing workload generators. The stochastic model adopted to simulate users' behavior. It is implemented by adopting a distributed architecture that allows distributing the workload generators to multiple machines. Fanban Harness is a mechanism for supporting implementing servers that deal with the transaction requests submitted by Fanban drivers. Fanban Harness also supports implementing servers for non-Fanban workload generators.

Fanban infrastructure provides built-in support for servers such as Apache HTTPD, Java System Web, Portal and Mail Servers, Oracle RDBMS, Memcached. It also provides a web interface for execution control, queuing, statistics and data analysis, and viewing results.

Fanban allows us to vary the workload scale by providing load variation files to a run at submission time. This feature, coupled with the runtime reporting, allows us to monitor the response times and stability as the loads varies.
