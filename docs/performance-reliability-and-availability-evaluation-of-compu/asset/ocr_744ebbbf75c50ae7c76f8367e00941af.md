# Confidence Interval for the Mean and Rate of Exponentially Distributed Data

As the exponential distribution plays a very important role in performance and reliability modeling, this section presents a parametric method for estimating the parameter and its expected value. Assume a random variable $T$ follows an exponential distribution with parameter $\lambda$; thus its density function is $f_T(t) = \lambda e^{-\lambda t}$. Also consider the ordered failure time $\{t_1, t_2, ... t_n\}$ and $Y = t_1 + t_2 + ... + t_n$, where each $t_i$ is a time value assigned to a random variable $T_i$, where every $T_i$ is independent and identically distributed according to $f_T(t) = \lambda e^{-\lambda t}$. Therefore $Y = \sum_{i=1}^n T_i$ is a gamma distribution with parameters $n$ and $\lambda$. The second parameter of the gamma distribution is a rate; not then, multiplying $Y$ by a constant changes the same shape and rate by that constant [207, 254, 461]. We choose to multiply by $\lambda$;

```
$$W = 2\lambda Y$$
```

and

```
$$W = 2\lambda (T_1 + T_2 + ... + T_n). \quad (25.3.41)$
```

Thus,

```
$$W = 2n\lambda\overline{T}, \quad (25.3.42)$
```

where $\overline{T} = (\sum_{i=1}^n T_i)/n$. The random variable $T$ is distributed according to $Gamma(n, \lambda)$. Hence, the random variable $W = 2n\lambda\overline{T}$ is distributed according to $Gamma(n, \lambda/(2\lambda)) = Gamma(n, 1/2),$ that is

```
$$W = 2n\lambda\overline{T} \sim Gamma(n, \frac{\lambda}{2\lambda})$$\n$$$W = 2n\lambda\overline{T} \sim Gamma(n, \frac{1}{2}).$$
```

Since

```
$$Gamma(n, \frac{1}{2}) = \chi^2_{2n}.$$
```

then,

```
$$W = 2n\lambda\overline{T} \sim \chi^2_{2n}. \quad (25.3.43)$
```
