The **reliability importance**, also called **Birnbaum importance** (B-Importance) of a component $i$ at time $t$ is defined by the partial derivative of the system reliability concerning the component $i$'s reliability.

$I_i^B(t) = \frac{\partial R_s(t)}{\partial R_i(t)} \quad (18.9.2)$.

We omit $t$ whenever the context is clear; that we may write $I_i^B$. Consider the structure function represented by 18.3.6; that is

$\Phi(\mathbf{X}(t)) = x_i(t) \times \Phi(1_i, \mathbf{X}(t)) + (1 - x_i(t)) \times \Phi(0, \mathbf{X}(t)).$

As

$R_s(t) = P(\Phi(\mathbf{X}(t)) = 1) = E(\Phi(\mathbf{X}(t))).$

then

$R_s(t) = E(x_i(t) \times \Phi(1_i, \mathbf{X}(t)) + (1 - x_i(t)) \times \Phi(0, \mathbf{X}(t))).$

$R_s(t) = E(x_i(t) \times \Phi(1_i, \mathbf{X}(t))) + E((1 - x_i(t)) \times \Phi(0_i, \mathbf{X}(t))).$

Assuming the components are independents, we get

$R_s(t) = E(x_i(t)) \times E(\Phi(1_i, \mathbf{X}(t))) + E((1 - x_i(t)) \times E(\Phi(0_i, \mathbf{X}(t))).$

$R_s(t) = R_i(t) \times E(\Phi(1_i, \mathbf{X}(t))) + (1 - R_i(t)) \times E(\Phi(0, \mathbf{X}(t))).$

Let $E(\Phi(l_1, \mathbf{X}(t))) = R_s(l_1, \mathbf{X}(t))$, and $E(\Phi(l_0, \mathbf{X}(t))) = R_s(l_0, \mathbf{X}(t))$, then

$R_s(t) = R_i(t) \times R_s(l_1, \mathbf{X}(t)) + (1 - R_i(t)) \times R_s(l_0, \mathbf{X}(t))$.

Therefore

$R_s(t) = R_i(t) \times R_s(l_1, \mathbf{X}(t)) + R_s(l_0, \mathbf{X}(t)) - R_i(t)R_s(l_0, \mathbf{X}(t))$.$

$R_s(t) = R_i(t) \times R_s(l_1, \mathbf{X}(t)) - R_s(l_0, \mathbf{X}(t)) + R_s(l_0, \mathbf{X}(t))$.$

As $I_i^B = \partial R_s(t)/\partial R_i(t)$ (see 18.9.2), we have

$I_i^B = \frac{\partial R_s(t)}{\partial R_i(t)} = R_s(l_1, \mathbf{X}(t)) - R_s(l_0, \mathbf{X}(t)). \quad (18.9.3)$

The reliability importance of each component is

$I_i^B = \frac{\partial R_s(t)}{\partial R_i(t)} = \frac{R_1(t) \times R_2(t) \times R_3(t)}{\partial R_1(t)} = R_2(t) \times R_3(t)$.

$I_2^B = \frac{\partial R_s(t)}{\partial R_2(t)} = \frac{R_1(t) \times R_2(t) \times R_3(t)}{\partial R_2(t)} = R_1(t) \times R_3(t)$.

Therefore, the reliability importance of each component $I_1^B = 0.837$, $I_2^B = 0.855$, and $I_3^B = 0.883$ (see Figure 18.30). Therefore, in series configurations, the less reliable component is the one that is most important with respect to the reliability importance.

**Example 18.9.3.** The RBD depicted in Figure 18.29.b is composed of blocks in parallel. The system reliability is $R_s(t) = 1 - (1 - R_1(t))(1 - R_2(t))(1 - R_3(t))$. The reliability importance of each component is

$I_1^B = \frac{\partial R_s(t)}{\partial R_1(t)} = (1 - R_2(t))(1 - R_3(t))$.$

$I_2^B = \frac{\partial R_s(t)}{\partial R_2(t)} = (1 - R_1(t))(1 - R_3(t))$.$

$I_3^B = \frac{\partial R_s(t)}{\partial R_3(t)} = (1 - R_1(t))(1 - R_2(t))$.$

Considering the reliability of blocks $b_1, b_2$ and $b_3$ at $R_1(t) = 0.95, R_2(t) = 0.93,$ and $R_3(t) = 0.9$, the reliability importance of each component is $I_1^B = 0.007, I_2^B = 0.005,$ and $I_3^B = 0.035$. Hence, in parallel structures, the most reliable component is the one that is least important. This result confirms the intuition, since in parallel structures, the system will only fail when all components fail. A parallel system is as strong as its weakest component.
