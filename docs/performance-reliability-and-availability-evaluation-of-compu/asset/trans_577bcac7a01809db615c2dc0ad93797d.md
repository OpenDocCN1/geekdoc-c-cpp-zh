

# 计算系统的性能、可靠性与可用性评估

错误（Error）是系统组件（系统基底）的一种状态，可能会导致后续失效（图16.2）。当错误未被包含、到达系统接口并改变系统时，就会发生失效。故障（Fault）是导致错误基底的事件 [31]。一个带有故障但能交付其指定功能的系统是容错的；即使存在存在故障的情况下，系统也不会发生失效。

总结来说，故障会导致错误基底。错误可以在系统中传播，因为一个组件的输出可能是其他组件的输入。如果错误基底未被包含，它就会传播到系统接口并导致失效。

→ 故障 → 错误 → 失效 → 故障 → ...

图 16.2 故障、错误与失效序列。

例如，考虑一个空调开关触点卡在开启状态；即它始终独立地处于开关开启位置。因此，我们在操作开始时就已经失效了（开关处于开启位置），但尚未产生错误。然而，如果我们把开关位置切换到关闭，故障会导致一个错误（如果没有被包含），这反过来会导致功能故障（失效），因为开关触点没有关闭，空调没有启动。

硬件故障可以从几个方面进行分类。故障可以是激活的或休眠的；否则就是休眠的。关于持续时间，故障可以是永久性的、瞬态或间歇性的。永久故障是指组件停止服务。一个例子是烧毁的白炽灯。瞬态故障导致组件一段时间内运行异常，但之后组件会完全恢复。另一方面，间歇性故障不会消失。它们在休眠和激活之间震荡。电气连接松动是间歇性故障的一个例子。故障还可以分为良性和恶性。仅导致组件停止服务的故障称为良性故障。恶性故障会产生看似合理但错误的输出。例如，假设飞机上的高度计器向一个组件报告 2000 米的高度，而向另一个组件报告 1200 米的高度 [218]。

编程 Bug（故障）会导致错误状态。例如，假设一个函数被认为是用来计算三维空间的值，但由于编程 Bug，它只计算了相应空间的三二部分。这个 Bug（故障）只有在执行特定函数时才会在错误状态（错误）下运行，如果错误状态未被包含，它将传播并产生失效。值得提到的是，软件 Bug可能是恶性的或非恶性的，而非恶性 Bug 可能由意外、经验或能力不足引起。标准

# 可靠性基础

消除软件故障的标准方法是在运行期间发现并消除软件 Bug（调试）。这种方法的成本远比在开发或测试阶段避免或消除故障要高昂得多。然而，如果失效无法重现，诊断并确认导致观测到的失效的底层故障就会变得不确定。软件测试适用于处理在特定情况下一致产生结果的故障。测试人员将此类故障称为波尔虫（Bohrs），引用了尼尔斯·玻尔的原子模型 [164, 439]。然而，当测试人员在类似条件下无法重现失效时，调试有时会导致失效，但可能无法触及故障。例如，多线程程序中的同步不足会根据“线程”时机和操作系统的调度产生竞态条件。只有当操作系统调度线程时，才会发生失效，在不重现故障和导致失效的情况下，使用调试过程将是不确定的。故障可能会促使软件系统表现出不受控且持续非确定的行为。软件开发者可能会将此类故障命名为曼德尔虫（Mandelbugs，引用了分形分析领域的著名研究人员）。文献也将此类故障称为海森堡虫（Heisenbugs），引用海森堡的不确定性原理 [439]。

由于海森堡虫类似于非确定性行为，重新执行失败的操作通常会导致成功。然而，当满足特定的内部条件时，失效可能会暴露。在许多情况下，在经历失效后重新启动或重启计算机对于防止未来的失效是有价值的。尽管如此，此类操作（软件再生）仅在失效率随运行时间增加时才有效。许多连续运行长时间的软件系统往往由于失效率增加而表现出性能和可靠性的下降。这种现象被称为软件老化 [439]。

如所述，服务失效定义为交付的服务偏离正确服务时发生的事件。运行模式是根据规范交付服务的系统行为。另一方面，服务偏差的不同表现形式是系统的失效模式 [352]。失效模式可以通过领域、感知和后果来表征（见图 1.6）。失效领域区分了内容失效和时间失效。当交付的服务信息偏离规范中的定义时，发生内容失效。当信息交付的时间偏离了时间规范时，发生时间失效。用户对失效的感知使我们将其区分为一致和不一致。当错误的服务被系统用户一致地感知到时，发生内容失效，而当系统用户以不同方式感知失效时，属于不一致失效。

现在，考虑随机变量 $T$ 为在给定 $t=0$ 时系统处于 $X(t)=1$ 的情况下到达状态 $X(t)=0$ 的时间。随机变量 $T$ 代表系统 $S$ 的失效时间，$F_T(t)$ 是其累积分布函数（CDF），$f_T(t)$ 是相应的密度函数（DF）。图 16.4 显示了这些函数。因此

$F_T(0) = 0$ 且 $\lim_{t\to\infty} F_T(t) = 1,$

$f_T(t) = \frac{dF_T(t)}{dt} \quad (16.2.1)$

其中 $f_T(t) \geq 0$ 且 $\int_0^{\infty} f_T(t)dt = 1$。

系统 $S$ 在时间 $t$ 内未失效的概率是系统的**可靠性**（$R(t)$）。在这里，可靠性（称为生存性）与累积分布函数互补（见图 16.5）。也就是说，$F_T$ 是**不可靠性**函数（$UR(t)$）。可靠性正式定义为：

$P(T > t) = R(t) = 1 - F(t), \quad (16.2.2)$

$R(0) = 1$ 且 $\lim_{t\to\infty} R(t) = 0$。
