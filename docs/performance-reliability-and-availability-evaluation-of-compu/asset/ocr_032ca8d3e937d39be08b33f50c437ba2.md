# Workload Characterization

The 2D graphics test checks vectors, bitmaps, fonts, text, PDF rendering, how fast, scalable vector graphics are displayed, zoomed and rotated, and other GUI elements.
The 3D suite graphics tests consists of

+   - a full screen $1920 \times 1080, 8	imes$ anti-aliasing, and methods for generating water as well as ground on the height above the water;
- a full screen $1920 \times 1080, 8	imes$ anti-aliasing, using geometry shader;
- a full screen $1920 \times 1080, 4	imes$ anti-aliasing, unordered transparency technique, and Tessellation technique used to produce terrain;
- a full screen $3840 \times 2160, 2	imes$ anti-aliasing, compute shader for bloom and warp effect with support for multi-GPU, and multithreading.

Finally, the **Disk suite** exercises the mass storage units.

+   - sequential readings;
- sequential writings;
- random reading and writing in files assuming $32 KB$ blocks with a queue depth of 20; and
- random reading and writing in files assuming $2 KB$ blocks with a queue depth of 1.

After running the tests, the PerformanceTest provides an overall PassMark rating. Users have provided their performance results to the company's benchmark website that stores their results. Such results are available to users, to cover many systems and different processor types [472]. Besides the standard test suites, PassMark also provides advanced tests that exercise CPU, memory, disk, graphics functions, network and internet, and GPU (Graphical Processor Unit).

# 3DMark and PCMark

The FutureMark benchmark is a set of benchmarks implemented by FutureMark Corporation, founded in 1997. Regardless of the company's acquisition and merging, two of the most well-known benchmarks that are part of their product line are 3DMark and PCMark. PCMark evaluates the system and 3DMark is centered on the graphics features. 3DMark focuses on rendering graphics and consists of a set of tests that generate a set of specific scores, such as graphics test score, physics test score, combined test score, which are then adopted to compose the 3DMark score by combining these specific scores using a weighted harmonic mean.
