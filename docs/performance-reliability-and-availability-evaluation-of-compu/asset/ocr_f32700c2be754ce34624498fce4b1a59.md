# 25.3.2 METHOD OF MOMENTS

This section introduces the method of moments to estimate parameters of probability distributions. Let us use $\mu_k = E(X^k)$ as the $k^{th}$ moment about the origin of a random variable $X$, if it exists, and consider $m_k = (\sum_{i=1}^n x_i^k)/n$ as the $k^{th}$ moment about the origin of a data sample.

The method of moments is based on matching the sample moments with the corresponding distribution moments.
