### SIMILAR MACHINES WITH SHARED REPAIR FACILITY

As the previous section, assume a system of $M$ similar servers installed in a set of racks as shown in Figure 21.4. Consider the time to failure of each server is independent and exponentially distributed with a rate of $\lambda$. Now, however, suppose there is one repair facility, and the time to repair is exponentially distributed with a rate of $\mu$.

The CTMC depicted in Figure 21.48 is an availability model of such a system. State $M$ denotes a system with $M$ servers. If one server fails, the system transitions to $M-1$ at a rate of $M\lambda$. The failed server may be repaired, so the system transitions back to state $M$ with a rate of $\mu$, or a second server may fail, transitions the system to $M-2$ with a rate of $(M-2)\lambda$. Similar behavior is seen for the following states. In state 0, there is no available server; hence, the only possible event is repair, which transitions the system to state 1 with a rate of $\mu$ since there is one repair facility.

The state probabilities are obtained by finding a solution to the system of equations $\Pi \cdot Q = 0, \sum_{i} \pi_i = 1$. The algebraic solution for the steady-state probability of state $k, k = M-j, j \in \{0, 1, \dots, M\}$, is

```
$$\pi_k = \frac{M!\lambda^{M-k}\mu^k}{\sum_{i=0}^{M} \frac{M!\lambda^{M-i}\mu^i}{(M-i)!}} \quad (21.9.1)$
```

The availability is $A = 1 - \pi_0$, then

```
$A = 1 - \frac{M!\lambda^M}{\sum_{i=0}^{M} \frac{M!\lambda^{M-i}\mu^i}{(M-i)!}} \quad (21.9.2)$
```
