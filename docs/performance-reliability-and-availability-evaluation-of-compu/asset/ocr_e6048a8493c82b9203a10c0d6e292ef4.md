# Uniform Distribution

Let $T$ be a random variable uniformly distributed with parameters $a$ and $b$ that specify the time of failure of a specific system class. The test to failure of a sample of size $n$ collected from a population distributed according to $T$. As the uniform distribution has two parameters, the expressions of the first two moments about the origin can be obtained. The obtained moments they are readily available:

```
$\mu_1 = \frac{a+b}{2}.$
```

```
$\mu_2 = \frac{1}{3}(a^2+ab+b^2).$
```
