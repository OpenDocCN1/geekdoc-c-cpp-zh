# 244 Performance, Reliability, and Availability Evaluation of Computational Systems

If we are interested in quantifying not whether the probability of the system is available but to provide a figure of processing capacity that is available, the capacity-oriented availability (COA) could be an interesting metric [95, 437]. The capacity-oriented availability is represented by the mean number of available resources, mnar=\sum_{i=1}^n \pi_i$, (in this case, servers) normalized by the total number of resources (in this case servers). Therefore, consider a system with $n$ equivalent servers; the capacity oriented availability can be formalized by

```
COA = \frac{\sum_{i=1}^n \pi_i}{n}
```

where $\pi_i$ is the probability of $i$ servers being, and the constant $n$ is the total number of servers. For the case shown in Figure 21.29, we have

```
COA = \frac{2 \times \pi_2 + \pi_1}{2}
```

which leads to

```
COA = \frac{\mu(\lambda + \mu)}{2\lambda^2 + 2\lambda\mu + \mu^2}
```

when considering only one repair facility. The COA, when considering two or more repair facilities,

```
COA = \frac{\mu}{\lambda + \mu}
```

COA is a performability (performance + dependability) metrics since it combines the system processing capacity with availability.
Assume each server $i$ (resource) sustains a throughput $tp_i$. Such a throughput may have been obtained through measurement, a performance model, or a specification. The average throughput - ATP 0 (another performance metric) is the weighted sum of throughputs in the system 0. Consider a system with $n$ resources (servers). Each server is able to sustain a throughput $tp_i$. The throughput could be in transactions per time units, MIPS, FLOPS, Qph etia al. More formally:

```
ATP = \sum_{i=1}^n i \times tp_i \times \pi_i.
```

**Example 21.7.1.** Consider the system depicted in Figure 21.29. The constant failure rate of each server is $\lambda = 10^{-7}h^{-1}$, and the constant repair rate is $\mu = 10^{-1}h^{-1}$. If only one repair facility is available, we have $A=0.99999$ and $COA=0.999$. If throughput delivered by the server is $tp = 1.2 \times 10^6$ $tph$, $tp^8 = 2.3976 \times 10^6$ $tph$, the mean throughput provided by the system is $2 \times tp \times \pi_2 + tp \times \pi_1 = 2.3976 \times 10^6$ $tph$.
