The CTMC depicted in Figure 21.53.a is an availability model of the system shown in Figure 21.52. The state $S0$ denotes the two web servers, and the database-server is operational. In this state, two web-server may fail, which takes the system to states $S1$ with a rate of $2\lambda_{ws}$ or the database-server may fail. In such a case, the system transitions to $S3$ with a rate of $\lambda_{db}$ in which the system becomes unavailable. In state $S1$ (the system is available), three events may occur. First, the web server may be repaired. This takes the system back to $S0$ with a rate of $\mu_{ws}$. The second possible event is a failure on the second web-server, which takes the system to state $S2$ with a rate of $\lambda_{ws}$, and the system becomes unavailable. The third event is the database repair which takes the system to state $S4$ with a rate of $\mu_{db}$, and the system also becomes unavailable. The following states work likewise. The set of available states is $\{S0, S1\}$. Therefore, the system availability is obtained through

$A = \pi_{S0} + \pi_{S1}$.
