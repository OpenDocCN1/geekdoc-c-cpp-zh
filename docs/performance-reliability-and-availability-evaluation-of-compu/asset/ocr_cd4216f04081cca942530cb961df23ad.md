The RBD shown in Figure 18.1 is composed of three blocks, $b_1, b_2$, and $b_3$. The RBD has two minimal paths. They are $MP_1 = \{b_1, b_2\}$ and $MP_2 = \{b_1, b_3\}$. Each minimal path is depicted by the respective logical function:

```
$\Psi_{MP_1} = b_1 \wedge b_2$,
```

```
$\Psi_{MP_2} = b_1 \wedge b_3$.
```

The set $MP_1^c$ is represented by the logical function

```
$\Psi_{MP_1^c} = b_1 \wedge \overline{b_2} = b_1 \vee \overline{b_2}$.
```

The set $MP_1^c \cap MP_2^c$ are also represented by the logical function

```
$\Psi_{MP_1^c \cap MP_2^c} = (\overline{b_1} \vee \overline{b_2}) \wedge (b_1 \wedge \overline{b_3})$.
```

```
$\Psi_{MP_1^c \cap MP_2^c} = (\overline{b_1} \wedge b_1 \wedge \overline{b_3}) \vee (\overline{b_2} \wedge b_1 \wedge \overline{b_3})$.
```

Using transformation rules shown in Table 18.3, from $b_i$, we get $x_i$ and from $\overline{b_i}$ we get $1-x_i$. As $E(x_i) = p_i$ and $E(1-x_i) = 1-p_i = q_i$, we have

```
$P(MP_1) = P(\Psi_{MP_1}) = p_1 p_2$.
```

```
$P(MP_1^c \cap MP_2^c) = P(\Psi_{MP_1^c \cap MP_2^c}) = q_2 p_1 p_3$.
```

Therefore

```
$P(MP_1 \cup MP_2) = P(MP_1) + P(MP_1^c \cap MP_2)$
```

```
$P(MP_1 \cup MP_2) = p_1 p_2 + q_2 p_1 p_3$.
```

Let $p_1 = p_2 = p_3 = 0.9$; then $P(MP_1 \cup MP_2) = 0.891$.
