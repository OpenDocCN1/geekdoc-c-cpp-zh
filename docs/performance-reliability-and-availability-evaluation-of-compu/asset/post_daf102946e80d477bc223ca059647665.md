# K-of-N

A system that is operational at least $K$ out of $N$ components is called a $K$-of-$N$ structure. A series system is, therefore, an $N$-of-$N$ structure, whereas parallel composition is a $1$-of-$N$ structure. Redundancies are represented by $K$-of-$N$ structures like bridges, delta and star arrangements have been represented by RBD; nevertheless such structures can only be represented if components are replicated in the model. Consider a data center with ordered set of $N$ similar servers, where $X_N = (x_1, x_2, ..., x_n)$ denotes the data center state, and $x_i$ represents the state of server $i$. Servers are observed during period. At the end of the period, each server can be in one of two states, operational ($x_i = 1$) or failed ($x_i = 0$). Assume the data center is considered operational if $K$ out of $N$ servers are operational.

Exactly $K$ out of $N$ servers are operational, the data center is considered operational. One possible outcome $(X_N)$ is when servers $1, 2, ..., k$ are operational, and servers $k+1, k+2, ..., n$ have failed. This outcome is depicted by $X_N = (x_1, x_2, ..., x_{k-1}, x_k, x_{k+1}, ..., x_n)$. $X_1 = (1, 1, ..., 1, 0, ..., 0)$.

Let $Y_1 = \sum_{i=1}^N x_i$ be the total number of operational servers observed in outcome $X_1$. Therefore, if $P(x_i = 1)$ is the probability of server $i$ being operational, the probability of having exactly $K$ out of the $N$ servers operational is

$P(Y_1 = K) = \prod_{i=1}^K P(x_i = 1) \times \prod_{i=K+1}^n P(x_i = 0)$.

If the mean time to failure of the system's components is i.i.d., then

$P(Y_1 = K) = P(x = 1)^K \times P(x = 0)^{N-K}$.

If $P(x = 1)$ is the component's reliability $(R_c(t))$, and $P(x = 0)$ is the component's unreliability $(UR_c(t))$, then

$P(Y_1 = K) = R_c(t)^K \times UR_c(t)^{N-K}$.

Thus,

$P(Y_1 = K) = R_c(t)^K \times (1 - R_c(t))^{N-K}$.

# Reliability Block Diagram

The outcome observed is one of many possible outcomes $(X_N)$ that represent precisely $K$ out of $N$ servers in an operational state ($Y = K$). The total number of outcomes with exactly $K$ out of $N$ is $\binom{N}{K}$. Therefore 

$P(Y = K) = \binom{N}{K} R_c(t)^K \times (1 - R_c(t))^{N-K}$

As the system is operational if $K$ or more servers are operational, the system reliability is obtained by

$R(t) = \sum_{i=K}^N \binom{N}{i} R_c(t)^i \times (1 - R_c(t))^{N-i}$. (18.5.30)

Likewise, the steady-state and the instantaneous availabilities are calculated.

$A = \sum_{i=K}^N \binom{N}{i} A_c \times (1 - A_c)^{N-i}$, (18.5.31)

$A(t) = \sum_{i=K}^N \binom{N}{i} A_c(t)^i \times (1 - A_c(t))^{N-i}$, (18.5.32) where $A_c(t)$ is the steady-state and instantaneous availability.
