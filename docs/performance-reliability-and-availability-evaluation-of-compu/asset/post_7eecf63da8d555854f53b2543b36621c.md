### Normal Distribution

Consider $T$ a random variable normally distributed with parameters $\mu$ and $\sigma$, representing the time to failure of a class of devices. Assume a sample of size $n$ was collected from a population that follows normal distribution; sort the sample in ascending order such that $S = \{t_1, t_2, ..., t_n\}$, where $t_1 < t_2 < ... < t_i < ... < t_n$.

The first step in this process consists of normalizing the times of the sample $S$, generating another ordered list $S_n = \{z_1, z_2, ..., z_n\}$, where

$$z_i = \frac{t_i - \mu}{\sigma}.$$

Now plot the points $(t_i, z_i)$. If the data is normally distributed, the plot would present a linear correlation between the two data sets. Applying a linear regression, we get $y = \hat{\alpha}x + \hat{\beta}$, we have the intercept $\hat{\beta} = \frac{\mu}{\sigma}$ and the angular coefficient $\hat{\alpha} = \frac{1}{\sigma}$. Therefore, the estimates of $\sigma$ and $\mu$ are

$$\hat{\sigma} = \frac{1}{\hat{\alpha}} \quad (25.3.4)$$
and
$$\hat{\mu} = -\hat{\beta} \times \hat{\sigma}. \ (25.3.5)$$
