If $S_1$ is processing the workload and $S_2$ fails, not is lost, since $S_2$ is not processing the transactions (see Figure 22.18.d). Hence, it may be repaired and return to standby mode. Nevertheless, while $S_1$ is processing the workload, if so, the web-server and the database-server should be started (see Figure 22.18.b). This process takes a while, but the delay is shorter than the time required to start a cold-standby server as depicted in the previous section (see Figure 22.18.c).

The availability model depicted in Figure 22.15 is somewhat similar to the cold-standby model depicted in represented by places $S2O$ and $S2D2$, transitions $F22$ and $R22$, and their respective arcs. The other features are equal to the cold-standby model represented in Figure 22.15. The steady-state system availability is estimated through

```
$A = P\(#S1U = 1)OR(#S2U = 1)\} \quad (22.6.1)
```

This expression is equivalent to

```
$A = P\(#S1U + #S2U) > 0\\} \quad (22.6.2)
```

which was presented in the previous example. The instantaneous availability is computed through $A(t) = P\(#S1U = 1)OR(#S2U = 1)\}(t)$
