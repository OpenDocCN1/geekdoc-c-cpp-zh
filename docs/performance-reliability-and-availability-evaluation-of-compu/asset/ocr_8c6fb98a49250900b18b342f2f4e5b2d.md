**Figure 22.26** Two-level SPN Availability Model.

The average number of virtual machines alive (ANVMA) is obtained using

```
ANVMA = \sum_{j=1}^{M_j} \sum_{i=1}^{N} j \times P\#UP_v = j} \times P\#UP = i, (22.8.3)
```

in Mercury-like notation. The capacity-oriented availability is computed from

```
COA = \frac{\sum_{j=1}^{M_j} \sum_{i=1}^{N} j \times P\#UP_v = j} \times P\#UP = i}{N \times M} (22.8.4)
```

Likewise, the probability of having at least K out of N \times M virtual machines alive (PKooOM) is obtained from

```
PKooOM = \sum_{k=1}^{M_j} k P\#UP_v = j} \times P\#UP = i. (22.8.5)
```
