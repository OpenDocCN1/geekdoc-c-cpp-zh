# 25.2.2 GROUPED COMPLETE DATA METHOD

Assume the set of computers in a reliability test specifies that an inspection should be carried out every day to find failed computers. Therefore, the' failure times are placed in intervals of twenty-four hours. A sort of failure data is grouped, as already mentioned at the beginning of the chapter. This introduces a method for lifetime analysis of grouped and complete data; that is, the time of failure of the computers is not lost, and the time to failure of every computer in the test is available.

Now the observation time was subdivided into intervals, where $t_1, t_2, ..., t_k$ are the are times that represent the end of the respective time interval. Hence, $t_1 < t_2 < ... < t_k$. Let $n$ be the number of observed computers at the beginning of the test, and $n_i$ be the number of surviving computers at the end of interval $i$, $i \in \{1, 2, 3, ..., k\}$ (see Figure 25.5). Therefore, the reliability estimate at $t_i$ can be calculated through

```
\hat{R}(t_i) = \frac{n_i}{n}, \quad (25.2.17)
```
