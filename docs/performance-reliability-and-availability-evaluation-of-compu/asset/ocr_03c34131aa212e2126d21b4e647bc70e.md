Execute the requested commands deployed to get the CPU usage, the server's memory usage, and the network states. The respective commands are stored files formatted in columns.

```
> dstat -c > dstat_cpu_dump.txt
> dstat -m > dstat_mem_dump.txt
> dstat -n > dstat_net_dump.txt
```

Execute the command below to obtain process states using the CPU and stats of process using the memory. The content of the files is formatted in columns.

```
> dstat -c --top-cpu > dstat_top_cpu_dump.txt
> dstat -d --top-mem > dstat_top_mem_dump.txt
```

The command below collects some internal and external plugins to get information about top CPU, top memory, and latency processes.

```
> dstat --top-cpu-adv --top-mem --top-latency
```

The command-below collects a sample of the stats described above every thirty seconds of one-hundred entries and it is in a file.

```
> dstat --top-cpu-adv dstat --top-mem --top-latency 30 120
>> top_dump_cpu_mem_lat.txt
```
