# 18.3 LOGICAL STRUCTURE FUNCTIONS

This section presents the logical and the structure functions.

# Logical Function

Assume a system $S$ represented by a RBD with set of $n$ components (blocks) $CS = \{b_i\}$, $|CS| = n$. The system state is described through a **logical function** of its components. The logical function is evaluated as whenever a least number of components is operationally enabled to perform the intended functionality. More formally, let us define $n$ Boolean variables $BS = \{s_i\}$, $i = 1...n$, each representing the state of each component. Each variable is defined by

```
$$s_i = \begin{cases} F & \text{if } b_i \text{ has failed.} \ T & \text{if } b_i \text{ is operational.} \end{cases}$$$
```
