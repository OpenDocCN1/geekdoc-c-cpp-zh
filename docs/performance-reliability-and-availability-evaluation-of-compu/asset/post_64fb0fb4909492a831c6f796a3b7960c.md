Table 20.4 shows the respective structure variables and the structure function evaluation. Here, it is important to remember that a Boolean variable $b_i$ implies $x_i = 0$, and $b_i$ corresponds to $x_i = 1$ (see rules presented in Table 18.3).

Assume the MTTFs and the MTTRs of each component are depicted in Table 20.5. The steady-state availability of each component is calculated by $A_i = MTTF_i/(MTTF_i+MTTR_i)$. Table 20.6 shows the events that evaluates the structure function $\Phi(X)$ to one, and the respective availability or unavailability of component in each specific event (state).

Consider we are interested in the system steady-state availability. For each state in which $\Phi(X) = 1$, we multiply the probability – (un)availability of each component. If the state of a component $j \in \{S_1, S_2, NAS_1, NAS_2\}$ is $x_j = 0$, we consider the unavailability $(p_j = P(x_j = 0))$. On the other hand, we consider the availability $(p_j = P(x_j = 1))$ for $j \in \{s_1, s_2, nas_{s1}, nas_{s2}\}$ is $x_j = 1$.

The components' availability are $A_{s1} = 0.98812, A_{nas1} = 0.99681, A_{s2} = 0.98946, A_{nas2} = 0.99681.$ For state $(0,0,1,1)$ – Event $E_3$, we have $UA_{s1} \times UA_{nas1} \times A_{s2} \times A_{nas2} = 0.01188 \times 0.00319 \times 0.98946 \times 0.99681 = 0.00004$ (Table 20.6). The availability to the other basic events (states) are shown in Table 20.6. Summing up the availability of the component $P(i)$, we obtain the steady-state availability $0.99979$.

**Example 20.2.2.** Let us have a system composed of three identical components, $C_1, C_2,$ and $C_3.$ Each of these components can be operational ($x_i = 1$) or in failure ($x_i = 0$), $i \in \{1,2,3\}.$ Table 20.7 shows all possible states of each component. If these components are arranged in series, the respective structure function is only evaluated to 1 for the state $X=(1,1,1).$ This is shown in Column $\Phi_S(X)$. If components are arranged in parallel, the respective structure function is evaluated to 1 for all states except $X=(0,0,0).$ This is shown in Column $\Phi_P(X).$ For a 2oo3 system, the structure function is evaluated to 1 for states $(0,1,1), (1,0,1), (1,1,0),$ and $(1,1,1).$ Column $\Phi_{2oo3}(X)$ of the Table 20.7 shows this function.

Consider the computation of the system reliability of the system. As the components are identical, $R_0(t) = R_1(t) = R_2(t)$. Hence, in Table 20.8, the probabilities related to each component are $p_i = R(t)$ or $p_i = UR(t)$ depending on whether $x_i = 1$ or $x_i = 0, i \in \{0, 1, 2\}$. The system reliability for the parallel system is calculated by multiplying the probabilities (reliabilities or unreliabilities) of components of each line in which $\Phi(X) = 1$ and summing the probabilities of the lines.
