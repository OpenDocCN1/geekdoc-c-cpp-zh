We can also find traffic in a range of ports by using the option portrange, for instance `tcpdump port 21-23`. It is worth mentioning that the port numbers are divided into three ranges, the well-known ports, the registered ports, and the dynamic or private ports [404]. The well-known ports are also known as system ports ports range from 0 through 1023. Some important system ports are depicted in Table 23.

Options can be combined using the logical operators such as and, or not to create more filters. For example, the command `sudo tcpdump -ni any -c10 src`
