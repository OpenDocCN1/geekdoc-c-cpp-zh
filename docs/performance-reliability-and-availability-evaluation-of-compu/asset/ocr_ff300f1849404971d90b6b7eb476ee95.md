The structure-function of each subsystem described can be obtained by applying the transformation rules shown in Table 18.3. The reliability and the steady-state availability can, be obtained from the structure functions. Therefore, the hard-server reliability expression is

$R_{HW}(t) = R_{MB}(t) 	imes R_{NC}(t) 	imes R_{VC}(t) 	imes R_{DC}(t) \times$\nnR_D(t) \times (1 - (1 - R_{S1}(t)) \times (1 - R_{S2}(t)))$

$i \in \{as, dbs\}$. Let us consider the time to failure of each hardware server to be exponentially distributed with $\lambda_{MB} = 1.6667 \times 10^{-5} f/h, \lambda_{NC} = 2 \times 10^{-5} f/h, \lambda_{VC} = 2.2222 \times 10^{-5} f/h, \lambda_{DC} = 1.8181 \times 10^{-5} f/h, \lambda_{D} = 2.8571 \times 10^{-5} f/h, \lambda_{S1} = 3.3333 \times 10^{-5} f/h$. Therefore, the reliability of the hardware server is expressed by

$R_{HW}(t) = e^{-\lambda_{MB}t} \times e^{-\lambda_{NC}t} \times e^{-\lambda_{VC}t} \times e^{-\lambda_{DC}t} \times e^{-\lambda_{D}t} \times$\n(1 - (1 - e^{-\lambda_{S1}t}) \times (1 - e^{-\lambda_{S2}t}))$,

Therefore,

$MTTF_{HW} = \int_{0}^{\infty} R_{HW}(t)dt = 8587.49491.$

The application server availability is expressed by

$A_{as} = A_{HW_{as}} \times A_{OS_{as}} \times A_{VMMM} \times A_{VM1} \times (1 - (A_{A1})) \times (1 - (A_{A2})) \times$\nA_{VM2} \times (1 - (A_{B1})) \times (1 - (A_{B2}))$.
