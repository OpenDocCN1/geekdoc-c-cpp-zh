# Lifetime Data Analysis 531

Information Technology Consulting Corporation (ITIC) has provided reliability data of mainstream server manufacturers, operating systems, and virtualization platforms. The ITIC 2020 Global Server Hardware, Server OS Reliability Report the systems’ reliability by weighing metrics and policies such as (1) automated and manual patch management, (2) Tier 1, Tier 2, and Tier 3 help calls, (3) inherent OS reliability, (4) inherent server availability, (5) unavailability due to planned outages and upgrades, (6) security issues, (7) human error, (8) server virtualization reliability, (10) vendor technical services, (11) understaff information technology departments, (12) servers’ hardware aging, (13) integration and interoperability features [186, 457].

Electronic Parts Reliability Data (ERPD) document presents failure rates on electronic components from historically observed empirical on the field. Data comprised in this document presents average failure rates and the respective confidence intervals. The failure rate was obtained by combining varying failure rates on similar parts from various sources [127]. Likewise, the Noneelectronic Parts Reliability Data (NPRD) document provides failure rates on diverse electrical, mechanical, electromechanical, and microwave parts based on observed failed fields [314].

Backblade is a cloud storage and data backup company. Backblade has providing reliability data of its storage systems and devices [33]. The approach adopted by Backblade is to take a daily snapshot of each operational storage device of its datacenters. This snapshot includes basic information along with statistics relating to that drive. All of the drive snapshots for a given day are collected into a “CSV” format file. The initial row of each column names, and the additional rows are the actual data. The columns record the data collection date, serial numbers, manufacturer-assigned serial numbers of the drives, capacities, and if the device is functional or in failure. Backblade makes these datasets freely available, and they can be accessed on the Internet.

A final warning is needed when using reliability data from sources mentioned above and others. Failure rate combines many inherent parameters that may drastically modify the most basic figures over which predictions are to be assessed. Therefore, failure rates as primary parameters should be adopted from those sources with caution. Here, it is prudent to state that in many circumstances, reliability estimates from models that data should be assessed:

+   * as approximations of the reliability, the design is qualified in the field,
* to produce relative comparisons to support decisions, and
* as a basis for contractual requirements.

Hence, a relevant recommendation is to adopt a conservative view of data provided by manufacturers, companies-consorta, general data sources.
