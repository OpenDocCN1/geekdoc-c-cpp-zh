Data errors occur when the data are transferred or stored. Information redundancy is a mechanism that aims at tolerating such errors. Many information redundancy strategies are based on coding. Codes allow data correctness, and even correction [218]. The most common codes used in data storage are parity codes, Hamming codes, checksum, and cyclic codes. Coding is a well-established research area, and many textbooks on this topic are available.

**RAID 0** stripes data evenly across two or more disks, without parity information or redundancy. Here, when one disk fails, the system fails RAID 0 is non-faulttolerant. RAID 0 is normally used to increase performance. Increasing the number of disks supports superior I/O performance since more data can be transferred simultaneously. Figure 17.9 shows a RAID structure composed of two disks (Disk 0 and Disk 1), with its specific controller. The set of data blocks (chunks) is distributed to the disks, where the blocks $A_1, A_3, A_5$, and $A_7$ are stored in Disk 0, and the blocks $A_2, A_4, A_6$, and $A_8$ are stored in Disk 1. Each data set, that is $A_1$ and $A_2$, $A_3$ and $A_4$, $A_5$ and $A_6$, and $A_7$ and $A_8$, are called stripes. As the structure is composed of two disks, it is possible to write blocks in one disk while performing read-operations in the other disk. Hence, an n-disk RAID 0 array appears as a single disk with a data rate n times higher than the single-disk. The reliability, may decrease in comparison to a single disk since more than one disk is required to store the same set of data.

**RAID 1** mirrors the set of data in two or more disks (at least two disks are required). For instance, when the disk array is composed of two disks, data is stored twice by writing them to both the disk (or set of disks) and a mirror disk (or set of mirror disks). RAID 4 stripes across two or more disks and adds a dedicated parity disk. RAID 4 tolerates one disk failure in an array of disks. Hence, RAID 4 requires at least three disks to be implemented. If a data disk fails, the RAID controller uses the remaining data disks and the parity disk to recover the missing data on the fly.
