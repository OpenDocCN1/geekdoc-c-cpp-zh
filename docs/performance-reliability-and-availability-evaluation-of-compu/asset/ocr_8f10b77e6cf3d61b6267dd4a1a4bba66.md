# Command pstree

The command pstree displays all running processes as a tree. The tree is rooted either the pid specified in the command line, or if no pid is specified, init⁸ if pid is omitted. If a user name is specified, all process trees are rooted at processes by that user are shown. The command pstree supports many options. For an example, the execution of the following command line "pstree -p". The option p includes the process identification (pid) of each process in the tree of processes.
