# 一个 2oo5 MTTF

$MTTF = A + B + C + D$.

$MTTF = \int_{0}^{\infty} 10e^{-2\lambda t}(1-e^{-\lambda t})^3 dt + \int_{0}^{\infty} 10e^{-3\lambda t}(1-e^{-\lambda t})^2 dt+$

$\int_{0}^{\infty} 5e^{-4\lambda t}(1-e^{-\lambda t}) dt + \int_{0}^{\infty} e^{-5\lambda t} dt$.

首先考虑 A:

$A = \int_{0}^{\infty} 10e^{-2\lambda t}(1-e^{-\lambda t})^3 dt$.

令 $u = 1 - e^{-\lambda t}$，则 $e^{-\lambda t} = 1 - u$，且 $du = \lambda e^{-\lambda t} dt$。

$A = \frac{10}{\lambda} \int_{0}^{\infty} e^{-\lambda t}(1-e^{-\lambda t})^3 \lambda e^{-\lambda t} dt$.

当 $t = 0, u = 0$ 且 $t \to \infty, u = 1$ 时，

$A = \frac{10}{\lambda} \int_{0}^{1} (1-u)^3 du$.

$A = \frac{10}{\lambda} \left( \int_{0}^{1} u^3 du + \int_{0}^{1} u^4 du \right)$

$A = \frac{10}{\lambda} \left( \frac{1}{4} + \frac{1}{5} \right)$

$A = \frac{1}{2\lambda}$。

现在考虑 B:

$B = \int_{0}^{\infty} 10e^{-3\lambda t}(1-e^{-\lambda t})^2 dt$.

682 计算系统的性能可靠性与可用性评估

令 $u = 1 - e^{-\lambda t}$，则 $e^{-\lambda t} = 1 - u，$e^{-2\lambda t} = (1-u)^2$，且 $du = \lambda e^{-\lambda t} dt$。因此

$B = \frac{10}{\lambda} \int_{0}^{\infty} e^{-2\lambda t}(1-e^{-\lambda t})^2 \lambda e^{-\lambda t} dt.$

当 $t=0, u=0$ 且 $t \to \infty, u=1$ 时，

$B = \frac{10}{\lambda} \int_{0}^{\infty} (1-u)^2 u^2 du = \frac{1}{3\lambda}$。

现在取 C:

$C = \int_{0}^{\infty} 5e^{-4\lambda t}(1-e^{-\lambda t}) dt.$

令 $u=1-e^{-\lambda t}$，则 $e^{-\lambda t} = 1-u，$e^{-3\lambda t} = (1-u)^3$，且 $du = \lambda e^{-\lambda t} dt$。因此

$C = \frac{5}{\lambda} \int_{0}^{\infty} e^{-3\lambda t}(1-e^{-\lambda t}) \lambda e^{-\lambda t} dt.$

当 $t=0, u=0$ 且 $t \to \infty, u=1$ 时，

$C = \frac{5}{\lambda} \int_{0}^{1} (1-u)^3 u du = \frac{1}{4\lambda}$。

现在取 D:

$D = \int_{0}^{\infty} e^{-5\lambda t} dt = \frac{1}{5\lambda}$。

因此

$MTTF = \frac{1}{2\lambda} + \frac{1}{3\lambda} + \frac{1}{4\lambda} + \frac{1}{5\lambda} = \frac{77}{60\lambda} \frac{1}{\lambda} \sum_{i=2}^{5} \frac{1}{i}$。
