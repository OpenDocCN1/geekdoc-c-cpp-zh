# Fault Tree

If $R_i(t) = E(x_i(t)), i \in \{S_1, S_2, S_3\}$, then

```
$R(t) = E(1 - ((1 - x_{S_1}(t)) \times (1 - x_{S_2}(t)) \times (1 - x_{S_3}(t)))$,
```

which leads to

```
$R(t) = 1 - ((1 - R_{S_1}(t)) \times (1 - R_{S_2}(t)) \times (1 - R_{S_3}(t)))$. (19.2.10)
```

For a system with $n$ parallel components, we have

```
$R(t) = 1 - \prod_{i=1}^{n} (1 - R_i(t))$. (19.2.11)
```

If $R_i(t) = R_c(t)$, then

```
$R(t) = 1 - (1 - R_c(t))^n$. (19.2.12)
```

As $MTTF = \int_{0}^{\infty} R(t) dt$, and if all components are identically distributed according to an exponential distribution with rate $\lambda$, then we obtain (18.5.25)

```
$MTTF = \frac{1}{\lambda} \sum_{i=1}^{n} \frac{1}{i}$. (19.2.13)
```

For components with different failure rates, see 18.5.23.\nAssuming the system components can be repaired and that the steady-state availability of the component $i$ is $A_i$, the steady-state system availability is calculated by

```
$A = 1 - \prod_{i=1}^{n} (1 - A_i)$. (19.2.14)
```

If $A_i = A_c$, then

```
$A = 1 - (1 - A_c)^n$. (19.2.15)
```

As $A_i = MTTF_i / (MTTF_i + MTTR_i)$, then

```
$A = 1 - \prod_{i=1}^{n} (1 - \frac{MTTF_i}{MTTF_i + MTTR_i})$. (19.2.16)
```

```
$A = 1 - \prod_{i=1}^{n} (\frac{MTTR_i}{MTTF_i + MTTR_i})$. (19.2.17)
```
