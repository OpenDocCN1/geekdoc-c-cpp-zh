# 23.4 COUNTERS AND TIMERS

Since the most fundamental metrics in a computer-based system is event-counting, the most basic measuring tool in a computer's performance measurement is a counter. A counter measures the number of events that occurred in a period $T$ (see Figure 23.3). Two typical implementations of counters are usually available: hardware counters and software counters.
