# Structure Function

The system may also be described by the respective structure function of its components. The structure function of the system $S$ is evaluated to one whenever at least the minimal number of components is operational. More formally, let us define a set of Bernoulli random variables $XS=\{x_i\}, i=1...n$, where each variable represents the state of each component $i$. Each variable is defined as in 18.2.1. Consider $X=(x_i)$ is a vector of the random variables of the set $XS$, and its cardinality is $|XS|=n$. The structure function that represents the operational mode depicted by the RBD is defined by

$\Phi(X) = \begin{cases} 0 & \text{if } S \text{ has failed.} \ 1 & \text{if } S \text{ is operational.} \end{cases}$ (18.3.3)

If the system has more than one operational mode, structure functions should be specified for representing each operational mode. Thus, if system is operational for a particular mode does not mean it is also operational for another operational mode.

Now, assume the RBD depicted in Figure 18.1. This system is operational if $b_1$, and $b_2$ or $b_3$ are in state. The set of random variables that describes the states of the blocks of this RBD is $XS=\{x_1, x_2, x_3\}$, and the vector $\mathbf{X}=(x_3, x_2, x_1)$, $|XS|=3$. Table 18.2 shows the enumeration of the set vectors and the respective structure function.

All we have to do is examine the Column $\Phi(X)$ of the enumeration Table 18.2 for any rows where the output is "1", and write the products that would give a value of "1" given input conditions. The obtained function is

$\Phi(X) = ((1-x_3) \times x_2 \times x_1) + (x_3 \times (1-x_2) \times x_1) + (x_3 \times x_2 \times x_1).\$$

Doing some algebra, we get

$\Phi(X) = x_1 \times (1-x_2) \times (1-x_3).$
