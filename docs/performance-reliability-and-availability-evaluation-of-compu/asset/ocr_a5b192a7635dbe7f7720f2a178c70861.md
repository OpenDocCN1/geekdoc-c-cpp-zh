# Bridge

A bridge structure is a non-series-parallel configuration of blocks. In standard RBD, blocks are unidirectional, the block's left-hand side is its input and the block's right-hand side is its output. The bridge structure, has a bidirectional block. Figure 18.21 shows a bridge configuration, represented by source and target nodes (S and T), and the set of blocks CS = {b1, b2, b3, b4, b5}. The blocks b1, b2, b4, and b5 are unidirectional, but b3 is bidirectional. The system represented by this bridge is operational if at least the following sets of blocks are operational: {b1, b2}, {b4, b5}, {b1, b3, b5}, and {b1, b3, b4, b5}.

The bridge structure can be decomposed into two standard RBDs by conditioning on block b3. applying 18.3.6, we have

```
Φ(X) = x3 × Φ(13, X) + (1 - x3) × Φ(03, X).
```
