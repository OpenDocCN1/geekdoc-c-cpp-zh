Now, we configure the client and the server to test UDP traffic. We configured it as a server using the following Powershell command

> > iperf -s -il -u

As can be seen, -s defines it as a server, -il defines the output interval as 1s, and the option -u defines the UDP traffic. The client computer (Linux machine) configured to execute the command line

> > iperf -c 192.168.61.1 -il -t60 -u 1000M
