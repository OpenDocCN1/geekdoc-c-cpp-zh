Example 24.3.4. Assume a simple online bookstore system where customers (clients) access the bookstore services deployed in a data center information technology (IT) infrastructure. The customer starts interacting using his/her credentials, which are stored in the bookstore database. Next, the data center load balancer delivers the respective transactions on the specific web-server. Next, the web-server accesses the database-server for data transactions. Finally, the application server interprets the request, returns the required data to the bookstore business logic, and delivers it to the customer.
