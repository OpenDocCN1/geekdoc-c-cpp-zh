- -Gprocess_name displays processes whose command names include the string process_name.
- -h displays all activities horizontally on a single line.
- -I indicates, in multiprocessing systems, that processes' related utilization processors should be divided by the number of processors.
- -p {pid1,pid2,...,pidn|SELF|ALL} selects processes for which statistics are to be reported, where pid is the process identification number. - -R reports realtime priority and scheduling policy information. The following values may be displayed:
- UID, USER, PID - already described - and
- prio is the realtime priority of the process,
- policy is the scheduling policy of the process, and
- Command is the command name of the process.
- -r reports page faults and memory utilization. When reporting statistics for an individual process, the following values may be displayed:
- UID, USER, PID - already described - and
- minft/s is the number of faults the process has per second, which have not required loading memory pages from disk.
- maift/s is the number of faults the process has per second, which have required loading memory pages from disk.
- VSZ is the virtual memory utilization of the entire process (Kbytes),
- RSS is the non-swapped physical memory used by the process (Kbytes).
- %MEM is the process currently used share of available physical memory.

# Performance, Reliability, and Availability Evaluation of Computational Systems

- UID is the real user identification number of the process that is being monitored together with its children,
- USER is the name of the real user owning the process that is monitored together with its children,
- PID is the identification number of the process that is being monitored together with its children,
- minflt-nr is the number of faults made by the process and its children during the interval,
- majflt-nr is the number of faults made by the process and all its children during the interval, and
- Command is the command name of the process and its children.
- -s reports the stack utilization. The following values may be displayed:
- UID, USER, PID - already described - and
- StSize is the amount of memory reserved for the process as a stack (Kbytes).
- StRef is the amount of memory used as a stack (Kbytes).
- Command is the command name of the process.
- -T [TASK|CHILD|ALL] specifies what has to be monitored by the pidstat command. The keyword indicates individual processes. The keyword CHILD indicates statistics are related to processes and their children. The keyword ALL indicates that the statistics are reported for all individual processes and their children.
- -t displays statistics for threads associated with selected processes. This option adds the following values to the reports:
- TGID is the identification number of the thread group leader and
- TID is the identification number of the thread being monitored.
- -U username displays the real name of the processes instead of the UID. If the username is specified, only processes belonging to the user are displayed.
- -u reports processor utilization. When reporting statistics for individual processes, the following values may be displayed:
- UID, USER, PID - already described - and
- %user is the processor utilization by the process at the user level. This field does not include time running a virtual processor.
- %system is the processor utilization by the process at the system level.
- %guest is the processor utilization by the process in a virtual machine (virtual processor).
- %CPU is the processor utilization by the process. Multiprocessor systems, the processor utilization related to the processes is divided by the number of processors (cores) if option -l is set on the command line,
- CPU is the processor number to which the process is attached, and
- Command is the command name of the process.
- When reporting global statistics (-T All) for processes and their children, the following values are displayed:
- UID is the real user identification number of the process together with its children,
- USER is the name of the real user owning the process together with its children,
- PID is the identification number of the process together with its children,
- usr-ms is the number of milliseconds spent by the process and its children at the user level during the interval of time, without including time spent running a virtual processor,
- system-ms is the number of milliseconds spent by the process and its children at the system level (kernel) during the interval of time,
- guest-ms is the number of milliseconds spent by the process and its children in a virtual machine (virtual processor), and
- Command is the command name of the task which is being monitored together with its children.
- -V prints the version.
- -v reports the values of:
- UID, USER, PID - already described - and
- threads is the number of threads,
- fd-nr is the number of file descriptors,
- Command is the command name.
