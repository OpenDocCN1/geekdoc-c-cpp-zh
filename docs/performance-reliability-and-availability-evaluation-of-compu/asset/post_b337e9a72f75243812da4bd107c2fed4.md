Assume the program execution time on a given computer is about 2s. Consider that the assembly function is responsible for a tiny portion of such a duration. Also assume the computer system timer-interruption period is $T_c = 100\mu s$. We guess that the time to execute the assembly function ($T_e$) is shorter than $T_c$ or about the same order. Hence, using the computer to measure the time required to execute the function `func_assembly()` would deliver a larger relative quantization error.

Therefore, we require to multiple-sampling and statistics to estimate $T_e(T_c)$. For doing so, we modify our main function in the C module for automatically executing the original code many times; let us say n. Hence, the modified main function may be implemented as the Program List 6, where the original main code is inserted into a loop with the number of iterations equal to $k=9340$. Hence, using this new version of the program, the assembly function is executed 9340 times, and the execution time of the new version of the program is about $9340\times2s=18680s (\approx 5.19h)$. Let us also know the addresses of every function and variable of the program. This memory map would be obtained by analyzing the object file. When the program's execution is resumed by popping up the interrupted address and storing it in instruction pointer. When the program execution finishes, program addresses were recorded in memory. Therefore, the ratio between total number of program interruptions (due to time service) is

$\tilde{p} = \frac{m}{n} = \frac{9,340,000}{186,800,000} = 0.05.$

As the execution of the new version (modified) of the program last $T = 16880s$, the time estimated within the code related to the assembly function is

$\tilde{T}_{me} = \tilde{p} \times T = 0.05 \times 16880s = 934s.$

As $T_{me}$ is the system spent executing code related to assembly function considering 9340 program's execution, the time spent in assembly function code due to one program's execution is estimated by

$\tilde{T}_e = \frac{\tilde{T}_{me}}{n} = \frac{934}{9340} = 0.1ms = 100ms.$

## Performance Measuring

It is worth comparing the point estimate of the event duration, $T_e = 100ms$, and the timer interruption period, $T_r = 100\mu s$, which constrains the resolution of direct measurement system, not supporting direct measuring of a short event. The confidence interval of time to execute such a short event may be obtained by applying one of the two methods introduced in Section 6.3 or the approach discussed in Section 6.5. Here, we adopted the method depicted in Section 6.3.2. Using such a method, we calculated the confidence interval for execution time of the `func_assembly()` (the event of interest) considering a degree of confidence of $1-\alpha=95\%$.

Therefore, we should carry out the following steps:

- First, check if there is no evidence to refute the normal distribution as a suitable approximation to the binomial distribution. The following steps must have a fixed number of repetitions ($k = 9340$).
- The procedure must have a fixed number of repetitions.
- Repetitions should be independent. We assume they are independent.
- Each repetition should have all results classified into two categories.

Then, execute the next steps:

- Find the critical value, $Z^* (Z_{\alpha/2})$. Let us adopt $\alpha = 0.05$. Thus, $Z^* = 1.96$.
- Calculate the error interval, $\varepsilon = Z_q \sqrt{\frac{\hat{p}\hat{q}}{n}}$. For this case, $\hat{p} = 0.05, \hat{q} = 0.95$ and $n = 186,800,000$. Therefore, $\varepsilon = 1.96 \times \sqrt{\frac{0.05 \times 0.95}{186,800,000}} = 31.25 \times 10^{-6}$.
- Find $p \in (\hat{p}-\varepsilon, \hat{p}+\varepsilon)$. Thus, $(0.0499, 0.05442)$.
- Find $T_e \in (\hat{p}-\varepsilon) \times \frac{T}{X}, (\hat{p}+\varepsilon) \times \frac{T}{X}$. Hence, $T_e \in (99.97, 100.03)$ with $95\%$ confidence.

The main drawback of this approach is the time required to execute the experiment. In this case, the program's execution time, considering the 9340 iterations, was about $5.19h$. However, we do not have a timer with a resolution that supports the direct measurement of such a short time, and thus is a suitable strategy.
