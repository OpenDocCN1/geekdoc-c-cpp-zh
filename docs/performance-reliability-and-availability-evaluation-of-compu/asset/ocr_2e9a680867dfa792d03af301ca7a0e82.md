Some components in a system may be more critical than others when defining whether the system is in an operational or failed state. For instance, a component in a series system is at least necessary as any other component. Hence, measures of components in the system are useful tools for planning and improving system dependability.

A critical path for component i is a state vector (1, X) that $\Phi(1,X) = 1 and $\Phi(0,X) = 0$. It is worth stressing that the state above is equivalent to $\Phi(1|X) = 1$. In others, given the states of the other components, the system is operational and only if component i is operational [352]. A critical path is the set of components that are operational in a critical path vector.
