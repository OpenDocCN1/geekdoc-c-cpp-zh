Hence,

$$\ln(\mu, \sigma | t_1, t_2, \dots, t_n) = $$

$$\ln(\frac{1}{\sigma\sqrt{2\pi}} e^{\frac{(t_1-\mu)^2}{2\sigma^2}}) + \ln(\frac{1}{\sigma\sqrt{2\pi}} e^{\frac{(t_2-\mu)^2}{2\sigma^2}}) + \dots + \ln(\frac{1}{\sigma\sqrt{2\pi}} e^{\frac{(t_n-\mu)^2}{2\sigma^2}})$.

Let us use one of these terms above, for instance,

$$\ln(\frac{1}{\sigma\sqrt{2\pi}} e^{\frac{(t_1-\mu)^2}{2\sigma^2}});$$

hence,

$$\ln(\frac{1}{\sigma\sqrt{2\pi}} e^{\frac{(t_1-\mu)^2}{2\sigma^2}}) = \ln(\frac{1}{\sigma\sqrt{2\pi}}) + El(\frac{(t_1-\mu)^2}{2\sigma^2}}).$$

Thus,

$$\ln(\frac{1}{\sigma\sqrt{2\pi}} e^{\frac{(t_1-\mu)^2}{2\sigma^2}}) = \ln((2\pi\sigma^2) - \frac{1}{2}) - \frac{(t_1-\mu)^2}{2\sigma^2}}.$

$$\ln(\frac{1}{\sigma\sqrt{2\pi}} e^{\frac{(t_i-\mu)^2}{2\sigma^2}}) = \ln((2\pi\sigma^2) - \frac{1}{2}) - \frac{(t_i-\mu)^2}{2\sigma^2}}.$

$$\ln(\frac{1}{\sigma\sqrt{2\pi}} e^{\frac{(t_i-\mu)^2}{2\sigma^2}}) = \frac{1}{2}\ln(2\pi) - \frac{1}{2}\ln(\sigma) - \frac{(t_i-\mu)^2}{2\sigma^2}}.$

$$\ln(\frac{1}{\sigma\sqrt{2\pi}} e^{\frac{(t_i-\mu)^2}{2\sigma^2}}) = \frac{1}{2}\ln(2\pi) - \ln(\sigma) - \frac{(t_i-\mu)^2}{2\sigma^2}}.$
