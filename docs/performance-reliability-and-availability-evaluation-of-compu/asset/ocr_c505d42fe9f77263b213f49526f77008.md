# 20.7.4 ESARY-PROSCHAN METHOD

This section presents the Esary-Prochan method for estimating probabilities bounds [345] [224]. Assume a system composed of $l$ minimal paths and $m$ minimal cuts. A minimal path is functional if all of its components work; thus, if one component of a minimal path fails, the minimal path fails. Let $ho_i$ be the success probability (reliability or availability) of the minimal path $MP$.

Consider a parallel system with independent components. In such a system, the minimal paths do not share components. As a parallel system, the system only fails if all minimal paths fail; hence the failure probability (unreliability or unavailability) is $Q=\prod_{i=1}^{l}(1-ho_i)$. For a more general system, however, the components; the failure probability is usually higher than $\prod_{i=1}^{l}(1-ho_i)$. Therefore, $\prod_{i=1}^{l}(1-ho_i)$ is a failure probability lower bound.

```
$U = 1-\prod_{i=1}^{l}(1-\rho_i) \qquad (20.7.1)$
```

a success probability upper bound. Now consider the minimal cuts. Applying a similar argument, we obtain a success probability (reliability or availability) lower bound:

```
$L = \prod_{j=1}^{m}(1-\gamma_j), \qquad \qquad (20.7.2)$
```

where $\gamma_j$ is the failure probability of the minimal cut $MC_j$.

Let us assume the bridge model shown in Figure 20.10.a. As already seen, this bridge has four minimal paths, $MP_1=\{c_1,c_2\}$, $MP_2=\{c_4,c_5\}$, $MP_3=\{c_1,c_3,c_5\}$, and $MP_4=\{c_2,c_3,c_4\}$, and four minimal cuts, $MC_1=\{c_1,c_4\}$, $MC_2=\{c_2,c_5\}$, $MC_3=\{c_1,c_3,c_5\}$, and $MC_4=\{c_2,c_3,c_4\}$. Here $ho_1=p_1p_2$, $ho_2=p_4p_5$, $ho_3=p_1p_3p_5$, $ho_4=p_2p_3p_4$; $\gamma_1=(1-p_1)(1-p_4)$, $\gamma_2=(1-p_2)(1-p_5)$, $\gamma_3=(1-p_1)(1-p_3)(1-p_5)$, and $\gamma_4=(1-p_2)(1-p_3)(1-p_4)$. Therefore,

```
$U = (1-\rho_1) \times (1-\rho_2) \times (1-\rho_3) \times (1-\rho_4)$
```

and

```
$L = (1-\gamma_1) \times (1-\gamma_2) \times (1-\gamma_3) \times (1-\gamma_4)$.
```

For $p_1=p_2=p_3=p_4=p_5=0.9$, we have $U=0.997349$ and $L=0.978141$.
