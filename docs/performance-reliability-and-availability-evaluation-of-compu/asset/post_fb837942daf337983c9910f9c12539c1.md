## 21.12 COMMON CAUSE FAILURE

As already mentioned in Section 18.7, Common Cause Failures (CCF) are one of the reasons why the reliability and availability models of a system may dangerously underestimate the probability of failure. CCFs occur when multiple components fail due to common causes, such as impact, vibration, temperature, power failure, and improper maintenance.

Consider a system composed of two identical servers (see Figure 21.8 and Figure 21.9). A server may fail due to the failures of its components. Assume the server failure is constant and $\lambda$. The server may be repaired with a constant rate of $\mu$. Let consider that only one repair facility is available. An external event may occur and results in failures in all servers at the same time. This external event occurs with a constant rate of $\lambda_c$, which is denoted the common failure rate. The CTMC depicted in Figure 21.54 is an availability model of such a system and takes into account common cause failure.

![](img/2d1450514bb14a0cdf0eb5048614afab_285_0.png)

**Figure 21.54** Two Web-Servers and Common Cause Failure – Availability Model.

The rate matrix is



```
$Q = \left(\begin{array}{ccc} -\mu & \mu & 0 \\ \lambda+\lambda_c & -\lambda-\lambda_c & \mu \\ \lambda_c & 2\lambda_c & -2\lambda-\lambda_c \end{array}\right)$
```

The availability can be obtained from

```
$A = 1 - \pi_{s0}$
```

which, solving the system of equations $\Pi \cdot Q = 0, \sum_{vi} \pi_i = 1$ and doing some algebra, we obtain

```
$A = \frac{\mu(2\lambda + \lambda_c + \mu)}{2\lambda + \lambda_c + \mu}$
```

The availability may also be expressed in number of nines by

```
$s = -\log(\pi_0)$
```

The downtime in a period $T$ can be estimated from

```
$DT = \pi_{s0} \times T$
```

Figure 21.55.a and Figure 21.55.b show the availability and the respective number of nines as functions of the failure rate $\lambda_c$, assuming $\lambda=1.24 \times 10^{-3}h^{-1}$ and $\mu = 5 \times 10^{-2}h^{-1}$.
