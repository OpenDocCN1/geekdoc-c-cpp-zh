# 18.6 SYSTEM REDUNDANCY AND COMPONENT REDUNDANCY

Consider a system $S$ formed by two components, $a$ and $b$, in series (see Figure 18.25.a). Assume the reliability of each component $R_a(t)$ and $R_b(t)$, respectively. Therefore, the reliability is $R_S(t) = R_a(t) \times R_b(t)$. We are interested in increasing the reliability by redundancy. Two alternative solutions are devised, $S_1$ and $S_2$. $S_1$ (system redundancy) consists of replicating the original system $S$ in parallel with $S'$. The system $S'$ is composed of blocks $a'$ and $b'$, which are equivalent to $a$ and $b$, respectively. Figure 18.25.b shows this composition. The system $S_1$ reliability is

$R_{S1}(t) = 1 - (1 - R_a(t))(1 - R_b(t))$

which leads to

$R_{S1}(t) = R_a(t) + R_b(t) - R_a(t)R_b(t)$.

$S_2$ consists of replicating the component $a$ with $a'$, and the component $b$ with $b'$. It is worth noting that $a$ is equivalent to $a'$, and $b$ is equivalent to $b'$. Therefore, each component of the original system $S$ is configured in parallel with an equivalent component (component redundancy). Figure 18.25.c shows this. The system $S_2$ reliability is

$R_{S2}(t) = (1 - (1 - R_a(t))^2)(1 - (1 - R_b(t))^2)$.
