# Lifetime Data Analysis 587

In order to find the parameter $\lambda$ that maximizes $L(\lambda, t_1, t_2, ..., t_n)$, set

```
$$\frac{\partial Ln(L(\lambda | t_1, t_2, ..., t_n))}{\partial \lambda} = 0$
```

and solve for $\lambda$. Therefore

```
$$\hat{\lambda} = \frac{n}{\sum_{i=1}^n t_i} (25.3.27)$
```

**Example 25.3.10.** Consider the experiment introduced in Example 25.3.1, in which fifty routers ($n = 50$) were observed in an accelerated reliability test. The time to failure of each device recorded in Table 25.10. The exploratory analysis did not rule out the exponential distribution as a possible fit to represent the time to failure. Using Equation 25.3.27 to estimate $\lambda$, we get

```
$$\hat{\lambda} = \frac{50}{\sum_{i=1}^{50} t_i} = 1.054 \times 10^{-3} h^{-1}$.$
```

As $D_{cal} = 0.091$ and $D_{critical,5\%} = 0.1921$ ($D_{cal} < D_{critical,5\%}$), the KS test fails to reject the exponential distribution with $\lambda = 1.054 	imes 10^{-3} h^{-1}$ to represent the reliability data with 95% degree of confidence.

# Geometric Distribution

Consider a sample $\{x_1, x_2, ..., x_n\}$ of independent measures, collected from a geometrically distributed population with true but unknown parameters $p, 0 \le p \le 1$. The geometric distribution is a discrete random variable, the likelihood function is the joint probability mass function (pmf). The pmf of a geometric random variable is

```
$$p(x,p) = p(1-p)^{x-1}, \quad 0 \le p \le 1, \quad x = 1, 2, 3, ...$
```

Thus, the likelihood function is

```
$$L(p|x_1, x_2, ..., x_n) = \prod_{i=1}^n (1-p)^{x_i-1}$.$
```

```
$$L(p|x_1, x_2, ..., x_n) = p^n \prod_{i=1}^n (1-p)^{x_i-1}$.$
```

```
$$L(p|x_1, x_2, ..., x_n) = p^n (1-p)^{\sum_{i=1}^n x_i-n}$.$
```

Now, take $Ln(p|x_1, x_2, ..., x_n))$ hence

```
$$Ln(p|x_1, x_2, ..., x_n) = Ln(p^n (1-p)^{\sum_{i=1}^n x_i-n})$.$
```

```
$$Ln(p|x_1, x_2, ..., x_n) = Ln(p^n) + Ln((1-p)^{\sum_{i=1}^n x_i-n})$.$
```

```
$$Ln(p|x_1, x_2, ..., x_n) = n \ln p - (n + \sum_{i=1}^n x_i) \ln(1-p)$.$
```
