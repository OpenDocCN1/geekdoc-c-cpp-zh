# 19.2 BASIC COMPOSITIONS

This section introduces the basic compositions used when representing a system through an FT. These compositions are referred to as the basic gates considered in the model, that is, $AND$, $OR$, or $KooN$ gates.

# OR Gate

Assume a system is composed of a hardware server, an operating system, and a program application (see Figure 19.4.a). If either component fails, the system fails. Hence, the system can be represented by the full tree shown in Figure 19.4.c, since Figure 19.4.b also represents the system when failure $\overline{HW}$, $\overline{OS}$, or $\overline{AP}$ occurs. The RBD depicted in Figure 19.4 represents the system operational as long as the three components ($HW, OS$, and $AP$) are functional, and a series block diagram represents such a behavior.

Let us obtain the reliability from the logical function. Consider the name of each component is also adopted to represent the logical variables. Hence, let us define the Boolean variable as $B = (\overline{HW} \vee \overline{OS} \vee \overline{AP})$.

```
$\Psi(B) = \overline{HW} \vee \overline{OS} \vee \overline{AP}$.$
```

If we negate both sides of the above equation, we get

```
$\Psi(B) = \overline{\overline{HW} \vee \overline{OS} \vee \overline{AP}}$.$
```

```
$\Psi(B) = HW \wedge OS \wedge AP$.
```

then
