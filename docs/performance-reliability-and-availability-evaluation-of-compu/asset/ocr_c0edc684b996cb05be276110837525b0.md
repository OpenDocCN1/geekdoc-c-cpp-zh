# 314 Performance, Reliability, and Availability Evaluation of Computational Systems

The steady-state system availability is calculated through the expression

```
$A = P\#SOK = 1\$\quad (22.10.1)
```

the unavailability is obtained

```
$UA = 1 - P\#SOK = 1\$\quad (22.10.2)
```

and the downtime in the period $T$ is calculated from

```
$DT = (1 - P\#SOK = 1)\times T\$\quad (22.10.3)
```
