# ### Algorithm 15 CPU Utilization Considering the State Classes Using Command iostat - Exercise 29

```

  >> iostat_cpu_utilization.txt;

  iostat | awk 'NR=4{printf "%.2f\t%.2f\t%.2f\t%.2f\t%.2f\t%.2f\t%.2f\n", $2,$3,$4,$5,$6,$7}'
  >> iostat_cpu_utilization.txt;
  sleep 60;
done
```
