# Command /usr/bin/time

The /usr/bin/time command is used to calculate how long a given command takes to execute. It is useful to measure the execution time of scripts and commands. The analyst should be aware that most Linux shells have their built-in versions of the time command. For example, if the command `type "type time""` is executed in a bash shell, the display output is `time is a shell keyword`. On the other hand, if the command line `type /usr/bin/time` is run, the display output is `/usr/bin/time`. Likewise, executing `type time` in a z shell, the display output is `time is a reserved keyword`. Therefore, if one needs to use the GNU time command (`type /usr/bin/time`), the analyst must specify the full path to the time binary, which is usually `/usr/bin/time`. The command type `/usr/bin/time` has configuration options. Check man for details. The output format can be configured in a string specified with the `-f` /usr/bin/time string command, where command is the utility whose execution time is to be measured. The string is an ASCII string with specified keywords depicted by a letter preceded by the symbol %.
