This second part consists of a minimum of two lines. The first line shows the header, and the following lines provide the respective information for each process, where PID is the process ID. USER is the "effective" user who started the process. Linux assigns a real user ID and an effective user to processes. The latter allows a process acting on another user, such as a non-root user, to be elevated to root. PR shows the scheduling priority of the process from the perspective of the kernel. NI field shows the "nice" value of a process. The nice value affects the priority of a process. VIRT, RES, SHR and %MEM are related to memory consumption of the processes, VIRT is the total amount of memory consumed, and memory that have been swapped to the disk.
