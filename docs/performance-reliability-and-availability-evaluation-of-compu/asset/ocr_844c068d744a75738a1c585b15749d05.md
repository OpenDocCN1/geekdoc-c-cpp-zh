As $\Phi(\mathbf{X})$ is a Bernoulli random variable, we have

$$$E(\Phi(\mathbf{X})) = P(\Phi(\mathbf{X}) = 1).$$

Thus,

$$$P(\Phi(\mathbf{X}) = 1) = E\left(\prod_{i=1}^{n} x_iight).$$$$

Considering the components are independent, we have

$$$P(\Phi(\mathbf{X}) = 1) = E\left(\prod_{i=1}^{n} E(x_i)ight). \quad (18.5.1)$$$

If $E(x_i) = R_i(t)$ (component's $b_i$ reliability), then

$$$R_s(t) = P(\Phi(\mathbf{X}) = 1).$$$$

Therefore, the system reliability is

$$$R_s(t) = \prod_{i=1}^{n} R_i(t). \quad (18.5.2)$$$

If $E(x_i) = A_i(t)$ (component's $b_i$ instantaneous availability), then the system instantaneous availability is

$$$A_s(t) = \prod_{i=1}^{n} A_i(t). \quad (18.5.3)$$$

Similarly, if $E(x_i) = A_i$ (component's $b_i$ steady-state availability), then the system steady-state availability is

$$$A_S = \prod_{i=1}^{n} A_i. \quad (18.5.4)$$$
