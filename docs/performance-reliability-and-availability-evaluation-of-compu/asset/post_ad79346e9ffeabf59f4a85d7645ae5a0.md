- -h Provides a utilization report easier to read by a human.
- -k - Displays statistics in kilobytes per second.
- -m - Displays statistics in megabytes per second.
- -p - This option displays statistics for block devices and all their partitions that are used by the system.
- -s - Displays a short version of the report that should fit in 80 characters wide screens.
- -t - Prints the time for each report displayed.
- -V - Prints version number.
- -x - Displays extended statistics.
- -y - Omits first report with statistics since system boot.
- -z - Omits output for any devices for which there was no activity.

The processor report displays the processor header row followed by row of processor statistics. On multiprocessor systems, processors' statistics are calculated and averaged among all processors. The report has the following format:

- % user - Displays the percentage of processor utilization while executing the user level (application).
- % nice - Displays the percentage of processor utilization while executing the user level with nice priority.
- % system - Displays the percentage of processor utilization while executing the system level (kernel).
- % iowait - Displays the percentage of time that the processor (or processors) was idle due to a disk I/O requests.
- % steal - Displays the percentage of time spent in involuntary wait by the virtual processor (or processors) while the hypervisor is servicing another processor.
- % idle - Displays the percentage of time that the processor (or processors) was idle, and there is no disk I/O initiated from that processor.

For instance, if this command "iostat -t 5 3" is executed, the following data is displayed. This command states that the utility iostat should be executed three times; the interval between each execution is five seconds, and -t states that the current time each sample obtained should also be displayed (this is similar to what we have seen for vmstat).

tps represents the number of I/O requests to the device per second. Multiple logical requests can be combined into a single I/O request to the device. A transfer is of indeterminate size. Hence, a metrics only makes sense when comparing distinct measures, such as areq-sz, rare-sz, wareq-sz and dareq-sz. Blk_read/s (kB read, MB read/s) represents the amount of data read from the device in blocks read (kilobytes, megabytes) per second. Blocks sizes are equal to 512 bytes. Blk_wtrn/s (kB wtrn, MB wtrn/s) represents the amount of data written to the device expressed in a number of blocks per second. Blk_dscd/s (kB dscd, MB dscd) represents the amount of data discarded in a specified number of blocks read per second. Bl_read (kB read, MB read) is the total number of blocks read. Blk_wtrn (kB wtrn, MB wtrn) written, and Blk_dscd (kB dscd, MB dscd) is the total number of blocks discarded for discarded.

r/s represents the number of requests completed (after merges) per second for the device. Two requests can be merged if they are contiguous, w/s is the number of write requests completed (after merges) per second for the device, d/s denotes the number of discard requests completed (after merges) per second for the device, and f/s is the number of disks (flushes) completed (after merges) per second. sec (kB/s, MB/s) represents the number of disks. rsec (rkB/s, rMB/s) is the number of read, wsec (wkB/s, wMB/s) is the number of written, dsec (dkB/s, dMB/s) is the number of discarded. drqm/s is the number of discard requests per second. % rqrm is the percentage of merged, % wrqm is the percentage of write merged, % drqm is the percentage of discard merged. areq-sz is the average size, rare-sz is the average size, wareq-sz is the average size, and dareq-sz is the average size. await is the average time for I/O requests to be served, which includes the time spent waiting in the queue. r_await is the average time for reading requests issued to the device, which also includes the time waiting in queue. w_await is the average time for write requests issued to the device, which also includes the time spent waiting in the queue. d_await is the average time for discard requests issued to the device, which also includes the time spent in queue. f_await is the average time for flush requests issued to the device. The block layer executes flushes one at a time. aqu-sz is the average length of the requests that were issued to the device. %util is the percentage of elapsed time during which I/O requests were issued to the device (bandwidth utilization for the device). For requests serially to devices, the saturation occurs when this value is close to 100%.
