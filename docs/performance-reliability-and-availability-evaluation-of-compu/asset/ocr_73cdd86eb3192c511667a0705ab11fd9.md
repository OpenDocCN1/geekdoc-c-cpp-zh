# 166 Performance, Reliability, Availability Evaluation of Computational Systems

The structure functions are obtained from the logical functions, and the respective reliability and availability expressions are derived. The reliability can be calculated from

```
$R(t) = (1 - R_{M_3}(t)) \times R_{CM_3}(t) + R_{M_3}(t) 	imes R_{CM_3}(t),
```

$R_{M_3}(t)$ is the reliability of memory module $M_3$, $R_{CM_3}(t)$ is the reliability computed from the FT shown in Figure 19.23.a, and $R_{CM_3}(t)$ is the reliability calculated from the model shown in Figure 19.23.b.

```
$R_{CM_3}(t) = 1 - ((1 - R_{P_1}(t)) \times R_{M_1}(t)) \times (1 - R_{P_2}(t)) \times R_{M_2}(t))
```

and

```
$R_{CM_3}(t) = 1 - (1 - R_{P_1}(t)) \times (1 - R_{P_2}(t)),
```

$R_{P_1}(t), R_{P_2}(t), R_{M_1}(t)$, and $R_{M_2}(t)$ are the reliability of the processing unit $P_1$ and $P_2$, and of the memory module $M_1$ and $M_2$, respectively. The availability expression is obtained likewise.

```
$A = (1 - A_{M_3}) \times A_{CM_3} + A_{M_3} \times A_{CM_3},
```

$A_{M_3}$ is the availability of memory module $M_3$, $A_{CM_3}$ is the availability calculated from the FT shown in Figure 19.23.a, and $A_{CM_3}$ is the availability computed from the model shown in Figure 19.23.b.

```
$A_{CM_3} = 1 - ((1 - A_{P_1}) \times A_{M_1}) \times (1 - A_{P_2}) \times A_{M_2}))
```

and

```
$A_{CM_3} = 1 - (1 - A_{P_1}) \times (1 - A_{P_2}),
```

$A_{P_1}, A_{P_2}, A_{M_1}$, and $A_{M_2}$ are the availability of the processing unit $P_1$ and $P_2$, and of the memory module $M_1$ and $M_2$, respectively.

The MTTF and MTTR of each system component are shown in Table 19.3. The component's steady-state availability is $A_i = MTTF / (MTTF + MTTR)$, $i \in \{P_1, P_2, M_1, M_2, M_3\}$, the system steady-state availability is $A = 0.999913$ and the yearly downtime is $(1 - A) \times 525600$ minutes = $45.85$ minutes.
