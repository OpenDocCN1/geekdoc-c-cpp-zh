# 18.6 SYSTEM REDUNDANCY AND COMPONENT REDUNDANCY

Consider a system $S$ formed by two components, $a$ and $b$, composed in series (see Figure 18.25.a). Assume the reliability of each component $R_a(t)$ and $R_b(t)$, respectively. Therefore, the reliability is $R_S(t) = R_a(t) \times R_b(t)$. We are interested in increasing the reliability by adopting redundancy. Two alternative solutions are devised, $S1$ and $S2$. Solution (system redundancy) consists of replicating the original system. In this subsystem $S'$, equivalent to the original $(S)$, is composed in parallel with $S$. The system $S'$ is composed of blocks $a'$ and $b'$, which are equivalent to $a$ and $b$, respectively. Figure 18.25.b shows this composition. The system $S1$ reliability is

> $R_{S1}(t) = 1 - (1 - R_a(t)R_b(t))^2$

which leads to

> $R_{S1}(t) = R_a(t)R_b(t)(2 - R_a(t)R_b(t))$.

Solution $S2$ consists of replicating the component $a$ with $a'$, and the component $b$ with $b'$. It is worth noting that $a$ is equivalent to $a'$, and $b$ is equivalent to $b'$. Therefore, each component of the original system $S$ is configured in parallel with an equivalent component (component redundancy). Figure 18.25.c shows this composition.
