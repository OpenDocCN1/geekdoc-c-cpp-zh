Assume a system composed of $n$ components. In some cases, we may be interested in measuring how much the system reliability is affected by many changes in a parameter $p_i$. The system **reliability sensitivity** can be measured by

> $S_{p_i}^R = \frac{\partial R(t)}{\partial p_i} \quad (18.9.9)$

**Example 18.9.9.** Considering the system depicted in Figure 18.34, the reliability sensitivity with respect to the parameters $\lambda_{hw}, \lambda_{os}, \lambda_{a1}, \lambda_{a21}, \lambda_{a22},$ and $\lambda_{a3}$ are shown in the following.

```
$S_{hw}^R = \left(e^{t(\lambda_{a21}+\lambda_{a22})} + e^{t\lambda_{a3}}-1\right)e^{-t(\lambda_{hw}+\lambda_{a21}+\lambda_{a22}+\lambda_{a3})},$
```

```

```
