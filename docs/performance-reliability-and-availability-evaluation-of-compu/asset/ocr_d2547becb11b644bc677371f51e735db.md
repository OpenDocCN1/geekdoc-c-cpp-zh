We have seen that $Y \sim \chi_{2n}^2$, if $Y = \sum_{i=1}^n TTFi$, for each TTF distributed according to $f(t) = \lambda e^{-\lambda t}$. Likewise, if $D = \sum_{i=1}^n TTR_i$, for each TTR distributed according to $f(t) = \mu e^{-\mu t}$; hence $D \sim \chi_{2n}^2$. Therefore,

```
$$\rho = \frac{\hat{\lambda}}{\hat{\mu}} \sim F(2n,2n)$
```

where $F(2n,2n)$ is the Snedecor-F cumulative distribution function, and $f(2n,2n)$ is the respective density function. Since

```
$$\hat{\rho} = \frac{\hat{\lambda}}{\hat{\mu}} = \frac{\frac{n}{Y}}{\frac{n}{D}}$
```

then

```
$$\rho \in (\rho_{t,2n,1}, \hat{\rho}_u) = (f_{2n,2n,1,-\frac{\alpha}{2}}, f_{2n,2n,1},\frac{\alpha}{2}}), \quad (25.3.50)$
```

where $\alpha$ is the degree of significance,

```
$f_{2n,2n,1},\frac{\alpha}{2}} = \arg f(2n,2n,1,-\frac{\alpha}{2})$
```

and

```
$f_{2n,2n},\frac{\alpha}{2}} = \arg f(2n,2n,\frac{\alpha}{2})$
```
