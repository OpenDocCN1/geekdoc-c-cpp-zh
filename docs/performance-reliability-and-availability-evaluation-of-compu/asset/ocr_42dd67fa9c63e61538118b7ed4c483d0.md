# Reliability Block Diagram

If $x_1, x_2,$ and $x_3$ are identically distributed, then $x$ may represent them. Hence

$P_S = 3p(x)^2 - 2p(x)^3.$

If $p(x) = p$, then we have

$P_S = 3p^2 - 2p^3,$ \quad (18.5.35)

which is equal to expression 18.5.33.

If the component's time to failure is exponentially distributed with rate $\lambda$, the system reliability is

$R(t) = 3e^{-2\lambda t} - 2e^{-3\lambda t}.$ \quad (18.5.36)

As $MTTF = \int_{0}^{\infty} R(t) dt,$ then

$MTTF = \int_{0}^{\infty}(3e^{-2\lambda t} - 2e^{-3\lambda t}) dt = \frac{5}{6\lambda} = \frac{1}{\lambda}\sum_{i=2}^{3} \frac{1}{i}. \quad (18.5.37)

Since

$f(t) = -\frac{dR(t)}{dt},$

then the density functions is

$f(t) = 6\lambda e^{-2\lambda t} - 6\lambda e^{-3\lambda t}. \quad (18.5.38)

As the hazard function is

$h(t) = -\frac{dR(t)}{dt} \times \frac{1}{R(t)},$

then

$h(t) = \frac{6\lambda}{3-2e^{\lambda(-t)}} - \frac{6\lambda e^{\lambda(-t)}}{3-2e^{\lambda(-t)}}. \quad (18.5.39)

$\square$
