If MNR ~ 0 or if the analyst is not interested in detailing the MNR, and this delay is added to the respective MTTR, we have

```
$A = \frac{MTTF}{MTTF + MTTR} (16.2.18)$
```

Mean time between failures is MTBF = MTTF + MTTR = MTTF + MNR + MTTR (see Figure 16.9), and if MNR ~ 0, then MTBF = MTTF + MTTR. Since MTTF >> MTTR; thus MTBF >> MTTR, so

```
$A \approx \frac{MTBF}{MTBF + MTTR} (16.2.19)$
```

The instantaneous availability is the probability that the system is operational at $t$ ($X(t) = 1$ in Figure 16.8), that is

```
$A(t) = P(X(t) = 1) = E(X(t)), \ t \ge 0. (16.2.20)$
```

If repairing is not possible, the instantaneous availability, $A(t)$, is equivalent to reliability, $R(t)$.

If the system approaches steady-state stations as the time increases, that it is possible to estimate the long-term fraction of time the system is available.

```
$A = \lim_{t\to\infty} A(t), \ t \ge 0. (16.2.21)$
```
