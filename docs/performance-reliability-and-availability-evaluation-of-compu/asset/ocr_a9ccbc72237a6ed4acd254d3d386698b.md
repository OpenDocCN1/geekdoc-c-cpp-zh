The CTMC depicted in Figure 21.25 shows an availability model of the system depicted in Figure 21.24. This model is composed of five states, 2, 1D, 1', 1, and 0. State 2 denotes that the primary server is operational, and the spare server is in standby mode. In this state, either server may fail. If the primary server fails, the system transitions to 1D with a rate of $\lambda_{op}$.

On the other hand, if the spare server fails, the system transitions to 1' with a rate of $\\lambda_{ab}$. The time to repair is exponentially distributed with a rate of $\\mu$. Second, the primary server may also fail, which transitions the system to state 0, where the system is unavailable. In state 1D, the service delivered is also unavailable since the device takes time to boot the virtual machines. In this state, three events are possible: First, the primary server may be repaired, which takes the system back to state 2 with a rate of $\mu$.
