The system failure occurs when both servers fail or the network fails. For example, a server fails when its hardware fails, or its operating system or both application programs (A and B) fail. The fault tree shown in Figure 19.12 represents this system.

![](bbox=[0.125, 0.475, 0.875, 0.746])

**Figure 19.12** Server 1 and Server 2 – Fault Tree.

The logical function that represents the system failure

```
$$\Psi(B) = ((hw1 \vee \overline{os1} \vee (a1 \wedge b1)) \wedge (hw2 \vee \overline{os2} \vee (a2 \wedge b2))) \wedge nw$,
```

$B = (hw1, os1, a1, b1, hw2, os2, a2, b2, nw)$ is the Boolean vector.
