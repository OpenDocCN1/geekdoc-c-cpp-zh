# 21.6 WARM-STANDBY REDUNDANCY

The system in Figure 21.24 is composed of two servers, server 1 ($S_1$) and server 2 ($S_2$), in warm-standby redundancy. This system hosts virtual machines for processing the workload demanded from users on the internet. The primary server, $S_1$, is readily available and provides two virtual machines, $VM_1$ and $VM_2$. server 1 infrastructure is composed of its hardware (HW), the operating system (OS), a hypervisor (HP), the virtual machines. In normal operation, server 2 is in standby mode. It is not off. In standby mode, $S_2$ is turned on, and its operating system and hypervisor are functional. The virtual machines, however, are not deployed. When $S_1$ fails, two virtual machines are mounted in $S_2$, and the workload is assigned to them. Therefore, it is clear that the standby takes a time to start processing (switching time) the workload that was being in $S_1$ is required to Consider that the switching time is exponentially distributed with a rate of $\delta$. Assuming that when processing the workload, $S_2$'s components are equivalent to $S_1$'s components, and both MTTFs are equivalent. However, $S_2$'s MTTF, in standby mode, is higher than when it is operating due to its smaller number of components. It is worth mentioning that $S_2$ in standby mode has no virtual machine deployed.
