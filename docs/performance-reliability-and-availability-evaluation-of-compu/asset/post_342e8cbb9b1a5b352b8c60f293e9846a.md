## 19.2 BASIC COMPOSITIONS

This section introduces the basic compositions used when representing a system through an FT. These compositions are referred to as the basic gates considered in the model, that is, $AND$, $OR$, or $KNOT$ gates.

### OR Gate

Assume a system is composed of a hardware server, an operating system, and a program application (see Figure 19.4.a). If either component fails, the system fails. Hence, the system can be represented by the full tree shown in Figure 19.4.c, since Figure 19.4.b also represents the system when failure $\overline{HW}$, $\overline{OS}$, or $\overline{AP}$ occurs. The RBD depicted in Figure 19.4 represents the system operational as long as the three components ($HW, OS$, and $AP$) are functional, and a series block diagram represents such behavior.

Let us obtain the reliability from the logical function. Consider the name of each component is also adopted to represent the logical variables. Hence, let us define the Boolean variable as $B = (\overline{HW} \vee \overline{OS} \vee \overline{AP})$.

```
$\Psi(B) = \overline{HW} \vee \overline{OS} \vee \overline{AP}$.$
```

If we negate both sides of the above equation, we get

```
$\Psi(B) = \overline{\overline{HW} \vee \overline{OS} \vee \overline{AP}}$.$
```

```
$\Psi(B) = HW \wedge OS \wedge AP$.
```

then

```
$\Psi(B) = HW \wedge OS \wedge AP$.$
```

![](img/2d1450514bb14a0cdf0eb5048614afab_161_0.png)

**Figure 19.4** OR Gate.

The respective structure-function is obtained by applying the transformations shown in Table 18.3. Hence

$\Phi(X) = x_{hw} \times x_{os} \times x_{ap}$,

where $X = (x_{hw}, x_{os}, x_{ap})$, and $x_i$ is the respective structure variable.

As $R(t) = E(\Phi(X))$, then

```
$R(t) = R_{hw}(t) \times R_{os}(t) \times R_{ap}(t)$.
```

Therefore, the reliability for a system represented by an $OR$ gate with $i$ basic events is obtained by

```
$R(t) = \prod_{i=1}^{n} R_i(t)$.
```

If $R_i(t) = R_c(t)$, then

```
$R(t) = R_c(t)^n$.
```

If the time to failure of each basic event is exponentially distributed with rate $\lambda_i$, the reliability is

```
$R(t) = \prod_{i=1}^{n} e^{-\lambda_i t}$,
```

and as MTTF = $\int_{0}^{\infty} R(t)dt$, we get

```
$MTTF = \int_{i=1}^{n} e^{-\lambda_i t} dt$
```

```
$MTTF = \frac{1}{\sum_{i=1}^{n} \lambda_i}$ (19.2.4)
```

If $\lambda_i = \lambda$, then

```
$R(t) = e^{-n\lambda t}$ (19.2.5)
```

and

```
$MTTF = \frac{1}{n\lambda}$ (19.2.6)
```

Considering the system components can be repaired and that the component $i$'s steady-state availability is $A_i$, is obtained by

```
$A = \prod_{i=1}^{n} A_i$ (19.2.7)
```

If $A_i = A_c$, then

```
$A = A_c^n$ (19.2.8)
```

If the component $i$'s time to repair is exponentially distributed with rate $\mu_i$, then $A_i = \mu_i / (\lambda_i + \mu_i)$. Hence

```
$A = \prod_{i=1}^{n} \frac{\mu_i}{\lambda_i + \mu_i}$ (19.2.9)
```

The instantaneous availability is likewise obtained.

**Example 19.2.1.** Assume the time to failure of each component of the system shown in Figure 19.4.a is exponentially distributed with rate $\lambda_{hw} = 2.5 \times 10^{-5} f/h$, $\lambda_{os} = 5 \times 10^{-4} f/h$, and $\lambda_{ap} = 10^{-3} f/h$. The system reliability is

```
$R(t) = \prod_{i\in{hw,os,ap}} R_i(t) = e^{-\lambda_{hw}t} \times e^{-\lambda_{os}t} \times e^{-\lambda_{ap}t}$,
```

![](img/2d1450514bb14a0cdf0eb5048614afab_163_0.png)

**Figure 19.5** OR Gate - $R(t) \times t$.

since $R_i(t) = e^{-\lambda_i t}, i \in \{hw, os, ap\}$. Therefore,

$R(t) = e^{-(\lambda_{hw} + \lambda_{os} + \lambda_{ap})t}$. The system reliability in the interval $(0, 800h)$ is shown in Figure 19.5. The mean time to failure is

$MTTF = \int_{0}^{\infty} R(t) dt = \int_{0}^{\infty} e^{-\lambda_{hw}t} \times e^{-\lambda_{os}t} \times e^{-\lambda_{ap}t} dt = \frac{1}{\lambda_{hw} + \lambda_{os} + \lambda_{ap}} = 655.77h$.

### AND Gate

Assume a system is composed of three servers, $S_1, S_2$, and $S_3$ (see Figure 19.6.a). The system is faulty if all servers fail. Then, the system can be represented by the fault tree shown in Figure 19.6.c, since failure occurs if basic events $S_1, S_2$, and $S_3$ occur. The RBD depicted in Figure 19.6.b represents the system operational as long as at least one server ($S_1, S_2$, or $S_3$) is functional, and a parallel block diagram represents such behavior.

Let us obtain the reliability from the logical function. Assume the name of each component is also adopted to represent the logical variables. Thus, let us define the Boolean function as $B = (S_1, S_2, S_3)$. Therefore, the logical function that represents a failure is $\overline{B} = \overline{S_1} \wedge \overline{S_2} \wedge \overline{S_3}$.

Hence, negating both sides of the expression above, we obtain $B = S_1 \vee S_2 \vee S_3$. The respective structure-function is obtained by applying the transformations shown in Table 18.3. Hence

$\Phi(X) = 1 - ((1-x_1) \times (1-x_2) \times (1-x_3))$.

If $R_i(t) = E(x_i), i \in \{S_1, S_2, S_3\}$, then

```
$R(t) = 1 - ((1 - R_1(t)) \times (1 - R_2(t)) \times (1 - R_3(t)))$,
```

which leads to

```
$R(t) = 1 - \prod_{i=1}^{n} (1 - R_i(t))$. (19.2.10)
```

For a system with $n$ parallel components, we have

```
$R(t) = 1 - \prod_{i=1}^{n} (1 - R_i(t))$. (19.2.11)
```

If $R_i(t) = R_c(t)$, then

```
$R(t) = 1 - (1 - R_c(t))^n$. (19.2.12)
```

As $MTTF = \int_{0}^{\infty} R(t) dt$, and if all components are identically distributed according to an exponential distribution with rate $\lambda$, then we obtain

```
MTTF = \frac{1}{\lambda} \sum_{i=1}^{n} \frac{1}{i}$. (19.2.13)
```

For components with different failure rates, see 18.5.2. Assuming the system components can be repaired and that the steady-state availability of the component $i$ is $A_i$, the steady-state system availability is calculated by

```
$A = 1 - \prod_{i=1}^{n} (1 - A_i)$. (19.2.14)
```

If $A_i = A_c$, then

```
$A = 1 - (1 - A_c)^n$. (19.2.15)
```

As $A_i = MTTF_i / (MTTF_i + MTTR_i)$, then

```
$A = 1 - \prod_{i=1}^{n} (1 - \frac{MTTF_i}{MTTF_i + MTTR_i})$. (19.2.16)
```

```
$A = 1 - \prod_{i=1}^{n} (\frac{MTTR_i}{MTTF_i + MTTR_i})$. (19.2.17)
```

If $MTTF_i = MTTF$ and $MTTR_i = MTTR$, then

```
$A = 1 - \left(\frac{MTTR_i}{MTTF_i + MTTR_i}\right)^n$ (19.2.18)
```

If the time to repair of component $i$ is exponentially distributed with rate $\mu_i$, then $A_i = \mu_i / (\lambda_i + \mu_i)$. Hence

```
$A = 1 - \prod_{i=1}^n \frac{\mu_i}{\lambda_i + \mu_i}$ (19.2.19)
```

If $\lambda_i = \lambda$ and $\mu_i = \mu$, then

```
$A = 1 - \left(\frac{\mu_i}{\lambda_i + \mu_i}\right)^n$ (19.2.20)
```

The instantaneous availability is similarly obtained.
