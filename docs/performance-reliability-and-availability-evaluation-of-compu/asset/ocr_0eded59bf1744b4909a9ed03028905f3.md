# Entry /proc/net/ and netstat

The entry `/proc/net/` provides an instant summary of various networking parameters and statistics. Its pseudo-files describe aspects and status of parts of the system working layers, sockets, discuss, and communications between virtual and the desktop. These pseudo-files can be read by a text editor or cat command. Besides the pseudo-files, it contains subdirectories that hold pseudo-files related to protocols, devices status. One may also use the command netstat to obtain the content of these pseudo-files. The netstat 's most common options are:

+   -t, which shows only TCP connections,
- -u, which shows only UDP connections,
- -a, which depicts listening (waiting) sockets;
- -n, which displays the IP addresses, port numbers and user ids (no login names);
- -p, which lists the processes involved. It is valid only when netstat is executed as root,
- -c, which continuously refreshes the list of connections.
