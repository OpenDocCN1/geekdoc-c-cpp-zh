If MNR $\approx 0$ or if the analyst is not interested in detailing the MNR, and this delay is added to the respective MTTR, we have

$$A = \frac{MTTF}{MTTF + MTTR} (16.2.18)$$

Mean time between failures is $MTBF = MTTF + MTTR = MTTF + MNR + MTTR$ (see Figure 16.9), and if MNR $\approx 0$, then $MTBF = MTTF + MTTR$. Since $MTTF \gg MTTR$; thus $MTBF \gg MTTR$, so

$$A \approx \frac{MTBF}{MTBF + MTTR} (16.2.19)$$

The instantaneous availability is the probability that the system is operational at $t$ ($X(t) = 1$ in Figure 16.8), that is

$$A(t) = P(X(t) = 1) = E(X(t)), t \ge 0. (16.2.20)$$

If repairing is not possible, the instantaneous availability, $A(t)$, is equivalent to reliability, $R(t)$.

If the system approaches steady-state stations as the time increases, it is possible to estimate the long-term fraction of time the system is available.

$$A = \lim_{t\to\infty} A(t), t \ge 0. (16.2.21)$$

## Fundamentals of Dependability

Occasionally, we are required to estimate the system availability in a time interval $(0,t]$. The interval availability $A_t(t')$ is estimated by

$$A_t(t') = \int_{0}^{t'} A(t)dt. \quad (16.2.22)$$

Assume we are required to estimate if the system S is operational and if it can deliver a specified service capacity. Assuming the system has $n$ operational, functional units able to provide the provided service, the system may deliver the service in a full operational capacity, that is, when functional units are operational, or may still provide the service with smaller processing capacity when some functional units are out. Even when one functional unit is available, the system delivers the specified service but with the smallest operational capacity possible. The system availability considering the processing capacity, defined as the capacity-oriented availability (COA), is estimated by

$$COA = \frac{\sum_{i=1}^{n} i \times \pi_i}{n}, \quad (16.2.23)$$

where $\pi_i$ is the probability of $i$ functional units being operational. The system downtime (DT) in a given time period $T$ may be defined

$$DT = UA \times T, \quad (16.2.24)$$

$UA = 1 - A$ is the system unavailability. The system uptime (UT) in time period $T$ is defined by

$$UT = A \times T. \quad (16.2.25)$$

Availability may also be expressed as the number of nines:

$$n = -\log(UA). \quad (16.2.26)$$

Table 16.1 presents the steady-state availability, the respective number of nines, and the system downtime for a year of 365 days. Sometimes the MTTF (or MTBF) are confused with the expected lifetime. Let us discuss one example to highlight the differences. Assume 1000 devices. We monitored these devices for one year. During this period, we observed ten failures. Hence the failure rate was calculated as $10/1000 = 0.01$ per year. We considered the time to failure exponentially distributed, $MTTF = 100$ years. Now, consider that we monitored 1000 devices for one year, but only those that survived.

Let us consider a second example in which 1000-old devices are watched for one year. In this period, we observed ten failures. Here, the failure rate ($\lambda$) is estimated by $10/1000 = 0.01$ per year. Assume the time to failure is exponentially distributed; $MTTF$ is obtained, $MTTF = 1/0.01 = 100$ years. Therefore, it is clear that the MTTF is different from the expected lifetime since death rate increases so that expected lifetime reaches 80 years. Considering the results in Example 16.2.1, now assume $MTTR = 24h$ and calculate the steady-state availability.

$$A = \frac{MTTF}{MTTF + MTTR} = \frac{100}{100 + 24} = 0.806$$

The downtime (in hours) is

$$DT = (1 - A) \times T = (1 - 0.806) \times 720 = 139.68h.$$

## 16.3 IMPORTANT PROBABILITY DISTRIBUTIONS

This section discusses the specific probability distributions for reliability and availability. If the failure rate function is constant, $\lambda(t) = \lambda$, then the reliability is

$$R(t) = e^{-\int_{0}^{t} \lambda dt} = e^{-\lambda t}, \quad t \ge 0.$$

The constant failure rate implies no aging or wear-out effects. The probability that a running system will operate for the next period $T$ is equal to that of a brand new system operating for the same period $T$, since

$$R(t|T) = \frac{R(t+T)}{R(T)} = \frac{e^{-\lambda (t+T)}}{e^{-\lambda T}} = e^{-\lambda t} = R(t).$$

The result presented above shows that the only continuous random variable with the memoryless property is the exponentially distributed random variable. The CDF is

$$F_T(t) = 1 - e^{-\lambda t}, \quad t \ge 0,$$

the density function is

$$f_T(t) = \lambda e^{-\lambda t}, \quad t \ge 0,$$

and the cumulative failure rate function is

$$H(t) = \lambda \times t, \quad t \ge 0.$$

As $MTTF = \int_{0}^{\infty} R(t) dt$, the mean time to fail is

$$MTTF = \int_{0}^{\infty} e^{-\lambda t} dt = \frac{1}{\lambda}.$$

If the failure rate is constant, then a failure will never occur before a specified period, $t_0$; the exponential distribution with threshold would be adopted. Now, $t_0$ is the location parameter that shifts the distribution to the right. Therefore,

$$R(t) = e^{-\lambda (t-t_0)}, \quad t \ge 0,$$

$$F_T(t) = 1 - e^{-\lambda (t-t_0)}, \quad t \ge 0,$$

the density function is

$$f_T(t) = \lambda e^{-\lambda (t-t_0)}, \quad t \ge 0,$$

and

$$MTTF = t_0 + \frac{1}{\lambda}.$$

Considering a repairable system (see 16.8), if the time to restore ($D$) is also exponentially distributed, $M(t) = 1 - e^{-\mu t}$, where $\mu$ is the restore rate. Hence, using 16.2.16, the mean time to restore

$$MTTR = \int_{0}^{\infty} (1 - M(t))dt = \int_{0}^{\infty} e^{-\mu t} dt = \frac{1}{\mu}.$$

Using 16.2.18, we obtain steady-state availability

$$A = \frac{MTTF}{MTTF + MTTR} = \frac{100}{100 + 24} = 0.806$$

The downtime is

$$DT = (1 - A) \times T = (1 - 0.806) \times 720 = 139.68h.$$
