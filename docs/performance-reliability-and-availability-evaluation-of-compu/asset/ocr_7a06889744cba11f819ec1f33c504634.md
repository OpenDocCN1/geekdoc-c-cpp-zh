# Reliability Block Diagram

The outcome observed is one of many possible outcomes ($X_N$) that represent precisely $K$ out of $N$ servers in an operational state ($Y = K$). The total number of outcomes with exactly $K$ out of $N$ is $inom{N}{K}$. Therefore

```
$P(Y = K) = inom{N}{K} R_c(t)^K 	imes (1 - R_c(t))^{N-K}$
```

As the system is operational if $K$ or more servers are operational, the system reliability is obtained by

```
$R(t) = \sum_{i=K}^N inom{N}{i} R_c(t)^i 	imes (1 - R_c(t))^{N-i}$.  (18.5.30)
```

Likewise, the steady-state and the instantaneous availabilities are calculated.

```
$A = \sum_{i=K}^N inom{N}{i} A_c 	imes (1 - A_c)^{N-i}$,  (18.5.31)
```

```
$A(t) = \sum_{i=K}^N inom{N}{i} A_c(t)^i 	imes (1 - A_c(t))^{N-i}$,  (18.5.32)
```

where $A_c$ and $A(t)$ are the steady-state and instantaneous components' availability.

**Example 18.5.4.** Consider a system composed of 3 identical and independent components ($b_1, b_2, b_3$) that is operational if at least 2 out of 3 components are working properly. The success probability of each block is $p$ (reliability, availability or maintainability). This system can be considered as a single block (see Figure 18.17.a) where its success probability ($P_S$) is depicted

```
$P_S = \sum_{i=2}^3 inom{3}{i} p^i 	imes (1 - p)^{3-i} = 3p^2 - 2p^3$.  (18.5.33)
```

Figure 18.17 shows three representations of the $K$ out of $N$ structure, in this particular case a $2o3$ structure. The notation adopted in Figure 18.17.a uses a single block and allows representing KoN with identical components, the notation depicted in Figure 18.17.b allows blocks with distinct parameters. Figure 18.17.c represents the $2o3$ structure using replicated components.

The structure function of the KoN system is expressed by

```
$\Phi(X) = \begin{cases} 0 & 	ext{if } \sum_{i=1}^N x_i < K \ 1 & 	ext{if } \sum_{i=1}^N x_i \geq K \end{cases}$  (18.5.34)
```
