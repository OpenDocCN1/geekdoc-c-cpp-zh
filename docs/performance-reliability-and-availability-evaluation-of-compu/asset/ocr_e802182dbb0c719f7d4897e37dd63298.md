# Ungrouped and Complete Data

Consider a complete lifetime set of data. Also, assume that the times to failure are exact, which is ungrouped. The analysis of such a data set is a particular case of the Kaplan-Meier method in which $r_i=1$ and $c_i=0$ for $t_i$ (see Figure 25.13). In deed, every $t_i$ is a failure since there is no censoring. Therefore, the Equation 25.2.31 becomes

```
$n_{i+1} = n_i - 1.$
```
