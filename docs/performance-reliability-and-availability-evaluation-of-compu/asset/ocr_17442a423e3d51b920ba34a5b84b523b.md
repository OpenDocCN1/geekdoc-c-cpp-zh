In this context, “array” means a set of disks organized in a particular fashion to improve the performance and re-liability of data storage. A RAID system consists of two or more disks working in parallel. This technology is driven by many methods available for connecting disks, coding techniques, and read-and-write strategies. Many types of RAID have been developed, and will probably come out in the future. Here we introduce important RAID architectures.
