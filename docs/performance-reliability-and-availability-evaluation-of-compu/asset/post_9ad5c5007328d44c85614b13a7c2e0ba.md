## 164 Performance, Reliability, Availability Evaluation of Computational Systems

**Example 19.3.3.** Consider a computer system composed of two processor units ($P_1$ and $P_2$), each with its local memory ($M_1$ and $M_2$, respectively), and a shared memory ($M_3$). Figure 19.21 depicts this system.

![](img/2d1450514bb14a0cdf0eb5048614afab_180_0.png)

**Figure 19.21** Computer System - Local and Shared Memories.

The system is considered failed if $P_1$ or $M_1$ and $M_3$ fail, or $P_2$ or $M_2$ and $M_3$ fail. More formally, a failure is defined by $\Psi(P_1, P_2, M_1, M_2, M_3) = (P_1 \vee (M_1 \wedge M_3)) \wedge (P_2 \vee (M_2 \wedge M_3))$. The fault tree describing this failure mode is shown in Figure 19.22.

![](img/2d1450514bb14a0cdf0eb5048614afab_180_1.png)

**Figure 19.22** Fault Tree with Repeated Event.

It is worth noting that the basic event $M_3$ appears twice in this model. Models such as this FT may be evaluated by factoring on the repeated events. In this example,

we have one repeated event. Therefore, two conditions are possible, that is $M_3 = T$, representing a failure, or $M_3 = F$ that specifies the correct behavior of the module $M_3$. This strategy was we applied in the bridge structure in Section 18.5. Enumeration and summing of the disjoint product (see Chapter 20) may also be applied. The $FT$ depicted in Figure 19.23.a is a model conditioned to $M_3 = T$ (failure) and Figure 19.23.b presents the $FT$ conditioned to $M_3 = F$ (correct behavior).

**Figure 19.23** Factoring Repeated Event – Fault Trees.

The respective logical functions of each fault tree are

$\Psi_{CM_3}(P_1, P_2, M_1, M_2) = (\overline{P_1} \vee M_1) \wedge (\overline{P_2} \vee M_2)$

and

$\Psi_{CM_3}(P_1, P_2, M_1, M_2) = \overline{P_1} \wedge \overline{P_2}$

The structure functions are obtained from the logical functions, and the respective reliability and availability expressions are derived. The reliability can be calculated from

```
$R(t) = (1 - R_{M_3}(t)) \times R_{CM_3}(t) + R_{M_3}(t) \times R_{CM_3}(t),
```

$R_{M_3}(t)$ is the reliability of memory module $M_3$, $R_{CM_3}(t)$ is the reliability computed from the FT shown in Figure 19.23.a, and $R_{CM_3}(t)$ is the reliability calculated from the model shown in Figure 19.23.b.

```
$R_{CM_3}(t) = 1 - ((1 - R_{P_1}(t)) \times R_{M_1}(t)) \times (1 - R_{P_2}(t)) \times R_{M_2}(t))
```

and

```
$R_{CM_3}(t) = 1 - (1 - R_{P_1}(t)) \times (1 - R_{P_2}(t)),
```

$R_{P_1}(t), R_{P_2}(t), R_{M_1}(t)$, and $R_{M_2}(t)$ are the reliability of the processing unit $P_1$ and $P_2$, and of the memory module $M_1$ and $M_2$, respectively. The availability expression is obtained likewise.

```
$A = (1 - A_{M_3}) \times A_{CM_3} + A_{M_3} \times A_{CM_3},
```

$A_{M_3}$ is the availability of memory module $M_3$, $A_{CM_3}$ is the availability calculated from the FT shown in Figure 19.23.a, and $A_{CM_3}$ is the availability computed from the model shown in Figure 19.23.b.

```
$A_{CM_3} = 1 - ((1 - A_{P_1}) \times A_{M_1}) \times (1 - A_{P_2}) \times A_{M_2}))
```

and

```
$A_{CM_3} = 1 - (1 - A_{P_1}) \times (1 - A_{P_2}),
```

$A_{P_1}, A_{P_2}, A_{M_1}$, and $A_{M_2}$ are the availability of the processing unit $P_1$ and $P_2$, and of the memory module $M_1$ and $M_2$, respectively.

The MTTF and MTTR of each system component are shown in Table 19.3. The component's steady-state availability is $A_i = MTTF / (MTTF + MTTR)$, $i \in \{P_1, P_2, M_1, M_2\}$, the system steady-state availability is $A = 0.999913$ and the yearly downtime is $(1 - A) \times 525600$ minutes = $45.85$ minutes.

## 19.4 COMMON CAUSE FAILURE

This section shows how to model cause failures using FT. The example adopted here is the same as depicted in Section 18.7. Hence, assume a redundant system specified by subsystems ($s_1$ and $s_2$). These subsystems are represented by events $E_1$ and $E_2$. The system is considered in failure if both subsystems fail; thus a failure occurs when the expression $E_1 \wedge E_2$ is evaluated as true (see Figure 19.24.a). Consider the failure rates of both እንደሚ are equal and constant, $\lambda$. Now assume a percentage ($p$) of failures ($\lambda_{ccf} = p \times \lambda$) affect both subsystems (CCF). This event is represented by including a two-input OR gate, where the top event of the previous model (FT depicted in Figure 19.24.a) is one of its inputs, and the other event ($E_3$) represents the CCF. This model is shown in Figure 19.24.b. Therefore, a failure is represented by the expression $(E_1 \wedge E_2) \vee E_3$ evaluated to true.
