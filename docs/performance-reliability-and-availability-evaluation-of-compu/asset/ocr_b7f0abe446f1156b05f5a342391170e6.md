# Weibull Distribution

Assume $T$ random variable distributed according to a Weibull distribution with parameters $eta$ (scale)) and $\alpha$ (shape) representing the time to failure of class dependents. A time to failure ordered sample of size $n$ was obtained from a population that follows a Weibull distribution, $\mathcal{S} = \{t_1, t_2, ..., t_i, ..., t_n\}$, such that $t_1 < t_2 < ... < t_i < ... < t_n$.

The cumulative distribution function of $T$ is

```
F(t) = 1 - e^{-(t/\beta)^\alpha}

1 - F(t) = e^{-(t/\beta)^\alpha}
```

where $t \le 0, \beta \le 0$ and $\alpha > 0$. From the equation above we obtain

then

```
ln(1 - F(t)) = ln(e^{-(t/\beta)^\alpha})

ln(1 - F(t)) = -(t/\beta)^\alpha

-ln(1 - F(t)) = (t/\beta)^\alpha

ln(1) - ln(1 - F(t)) = (t/\beta)^\alpha
```
