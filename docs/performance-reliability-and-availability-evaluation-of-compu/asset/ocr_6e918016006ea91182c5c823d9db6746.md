Taking the derivative of $L(\hat{\lambda} \mid x_1, x_2, \dots, x_n))$ with respect to $\lambda$, we get

```
$$\frac{\partial}{\partial\lambda}\ln(L(\hat{\lambda} \mid x_1, x_2, \dots, x_n)) = \frac{\partial}{\partial\lambda}\left(\\sum_{i=1}^n x_i \ln\hat{\lambda} - n\ln\hat{\lambda} - n\ln\left(\\prod_{i=1}^n x_i!\right)\right),$$
```

```
$$\frac{\partial}{\partial\lambda}\ln(L(\hat{\lambda} \mid x_1, x_2, \dots, x_n)) = \frac{\sum_{i=1}^n x_i \ln\hat{\lambda}}{\partial\lambda} - \frac{n\ln\hat{\lambda}}{\partial\lambda} - \frac{n\ln\prodprod_{i=1}^n x_i!}{\partial\lambda},$$
```

Hence,

```
$$\frac{\partial}{\partial\lambda}\ln(L(\hat{\lambda} \mid x_1, x_2, \dots, x_n)) = \frac{\sum_{i=1}^n x_i}{\lambda} - n. \quad (25.3.31)$$
```

