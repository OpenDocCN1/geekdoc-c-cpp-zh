# Performance, Reliability, and Availability Evaluation of Computational Systems

If the TTFs and the TTRs of all components are identically distributed, then $A_i = MTTF/(MTTF + MTTR)$ for every component $b_i$. Hence, the system steady-state availability is

```
$A_S = \left(\frac{MTTF}{MTTF + MTTR}\right)^n. \quad (18.5.5)$
```

If the time to failure of every component is identically distributed according to an exponential distribution with rate $\lambda$, and the time to repair of every component is also identically distributed and follows an exponential distribution with rate $\mu$, the system's steady-state availability is

```
$A_S = \left(\frac{\mu}{\lambda + \mu}\right)^n. \quad (18.5.6)$
```

Suppose each component $b_i$ time to failure, $TF_i$, is exponentially distributed with rate $\lambda_i$. Hence the component $b_i$ reliability is

```
$R_i(t) = e^{-\lambda_i t}$.
```

Thus, the system $S$ reliability is

```
$R_S(t) = \prod_{i=1}^n e^{-\lambda_i t}. \quad (18.5.7)$
```

Hence

```
$R_S(t) = e^{-\sum_{i=1}^n \lambda_i t}, \quad (18.5.8)$
```

where $\lambda_{eq} = \sum_{i=1}^n \lambda_i$ is the equivalent failure rate, and as

```
$MTTF = \int_0^{\infty} R(t) dt$,
```

```
$MTTF = \int_0^{\infty} e^{-\sum_{i=1}^n \lambda_i t} dt.$
```

Therefore

```
$MTTF = \frac{1}{\sum_{i=1}^n \lambda_i}. \quad (18.5.9)$
```
