The activation energy is the threshold energy that the reactant(s) must gain before entering a transition state. Assuming $26.1.12$ represent failures in electro-electronic systems at two temperatures $T_1 > T_2$, we obtain:

```
$$\lambda_1 = F \times e^{\frac{E_a}{T_1}}$

and

```
$$\lambda_2 = F \times e^{\frac{E_a}{T_2}}$
```

Hence the ratio $\lambda_2/\lambda_1$ represents the acceleration rate due to the temperature difference; thus :

```
$$\frac{\lambda_2}{\lambda_1} = e^{(\frac{-E_a}{T_1} - \frac{E_a}{T_2})} = e^{-E_a \times(\frac{1}{T_1} - \frac{1}{T_2})}$
```

Therefore,

```
$$\lambda_1 = \lambda_2 \times e^{-E_a \times(\frac{1}{T_1} - \frac{1}{T_2})} \eqno (26.1.13)$
```

```
