To exemplify such systems, we have the rack of servers depicted in Figure 21.42; assume the number of servers is $N$, and each server hosts $M$ virtual machines. It is worth noting that this problem was already approached using CTMC in Section 21.8 and Section 21.9. Here, however, we represent this sort of systems using SPN. Two SPN models are presented to evaluate availability and capacity. The first is a monolithic SPN, a model that depicts the servers and their respective virtual machines. The second SPN represents systems using a two-level SPN; an SPN represents the servers, and an SPN depicts the virtual machines for each number of servers available. These strategies are similar to those introduced in Section 21.8.

Figure 22.24](https://example.com/fig2224.png) (Figure 22.24 shows an SPN that represents $N=5$ servers, and each server hosts $M$ virtual machines. This model calculating the availability of virtual machines alive, the average number of servers alive, as well as COA. Each server $S_i$ is represented by two places ($S_U$ and $S_D$), with transitions ($FS_i$ and $RS_i$), and the respective arcs. One place in $S_U$ represents the server, whereas one place in $S_D$ denotes the server $S_i$ in failure. The events that represent the failure occurrence in $S_i$) is depicted by transition $FS_i$, and the server is repaired by transition $RS_i$. The availability of virtual machines on $S_i$ is represented by the subnet depicted by places $V_U, V_D$, transitions $F_i, R_i$, and their respective arcs. It is worth mentioning the inhibitor arc from place $S_U$ to transition $F_i$. Transition $F_i$ is also guarded by $\#V_U>0$, and the weight of the transitions $(V_U, F_i), (F_i, D)$ are $\#V_U$. Transition $RV_i$ is guarded by $\#S_U=1$. The server semantics of transitions $FV_i$ and $RV_i$ (it is assumed a server has the capacity to startup its VMs in parallel) is $isss$ and the server semantics of $FS_i$ and $RS_i$ are $sss$. The immediate priorities are as well as their weights are equal.
