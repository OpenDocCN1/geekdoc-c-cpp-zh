In this new marking, another VM may fail, the server may fail, and the failed VM may rest. It is worth noting that the guard expression assigned to $RV_i(\#S_i = 1)$ is available. If the server $S_i$ fails, which is denoted by the firing of transition $FS_i$, one token is removed from $S_U$, and one is stored in $S_D$. This new marking enables the immediate transition $F_i$. As the immediate transitions have higher priority than the timed one, $F_i$ fires, and its firing removes all token from $V_U$ and stores the same number in place $V_D$. It is worth observing that in this marking, $F_i$ is disabled since its guard is evaluated to false because $\#V_U = 0$. The virtual machines of this server will only be enabled to restart when the server is repaired by the guard expression assigned to $RV_i(\#S_U = 1)$.
