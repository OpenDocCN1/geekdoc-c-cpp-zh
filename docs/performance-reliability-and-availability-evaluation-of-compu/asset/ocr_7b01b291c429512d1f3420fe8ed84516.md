Hence, RAID 1 offers read and write throughput comparable to that of a single drive. In case of a drive failure, data must be copied to a replacement drive to achieve fault tolerance again. The downside is the storage capacity efficiency (SCE) because effective storage capacity (SCE) is half of the total disk capacity (TDC) since all data is written twice. Thus considering disks with capacity DC, the efficiency is defined by

```
$SCE = \frac{ESC}{TDC} = \frac{TDC/2}{TDC} = 0.5, \quad \(17.1.1)$
```

$TDC = n \times DC,$ and $ESC = TDC/2$.
