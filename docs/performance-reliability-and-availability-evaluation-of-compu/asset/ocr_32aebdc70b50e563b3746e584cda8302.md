Now assume $\{t_1, t_2, \dots, t_n\}$ as independent data points collected from a population normally distributed with the unknown parameters $\mu$ and $\sigma$. Therefore,

```
$L(\mu, \sigma|t_1, t_2, \dots, t_n) = L(\mu, \sigma|t_1) \times L(\mu, \sigma|t_2) \times \dots \times L(\mu, \sigma|t_n)$
```

since the points are i.i.D.

```
$L(\mu, \sigma|t_1, t_2, \dots, t_n) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(t_1-\mu)^2}{2\sigma^2}} \times \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(t_2-\mu)^2}{2\sigma^2}} \times \dots \times \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(t_n-\mu)^2}{2\sigma^2}}$
```

Now, let us solve $L(\mu, \sigma|t_1, t_2, \dots, t_n)$ for the maximum likelihood for $\mu$ and $\sigma$. Hence, we have to calculate two derivatives of $L(\mu, \sigma|t_1, t_2, \dots, t_n)$, one with respect to $\mu$, and the other with respect to $\sigma$. Take

```
$$\frac{\partial L(\mu, \sigma|t_1, t_2, \dots, t_n)}{\partial\mu}} = 0$
```

and

```
$$\frac{\partial L(\mu, \sigma|t_1, t_2, \dots, t_n)}{\partial\sigma}} = 0$.
```

and solve for $\mu$ and $\sigma$.
