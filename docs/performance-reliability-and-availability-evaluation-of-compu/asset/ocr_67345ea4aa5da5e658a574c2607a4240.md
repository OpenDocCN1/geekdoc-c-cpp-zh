**Example 25.3.1.** Assume the reliability experiment described in Example 25.3.1, in which fifty routers ($n=50$) were observed in an accelerated reliability test. The times each router failed were recorded in Table 25.10 (complete data). The exploratory analysis does not allow us to reject the exponential distribution as a suitable probability distribution to represent this data set. The point estimate was obtained, $\lambda = 9.41 \times 10^{-4}h^{-1}$, and the KS goodness of fit test fails to reject the exponential distribution as suitable to represent the reliability data set with 95% degree of confidence.

We adopted Equation 25.3.4 to estimate the confidence interval for the exponential distribution parameter, $\lambda$, that is,

```
$\lambda \in \left(\frac{\chi^2_{2n,a/2}}{2\bar{T}}, \frac{\chi^2_{2n,1-(a/2)}}{2\bar{T}}\right)\n\lambda \in \left(\frac{74.22}{250948.46}, \frac{129.56}{250948.46}\right)\n\lambda \in (7.83 \times 10^{-4}h^{-1}, 1.37 \times 10^{-3}h^{-1}),
```

considering 95% degree of confidence. Adopting Equation 25.3.45, the confidence interval of the MTTF is estimated:

```
$MTTF \in \left(\frac{2\bar{T}}{\chi^2_{2n,1-(a/2)}}, \frac{2\bar{T}}{\chi^2_{2n,a/2}}\right)\nMTTF \in (732.06h, 1277.88h),
```

and the point estimate of the MTTF $=$ 948.46h.
