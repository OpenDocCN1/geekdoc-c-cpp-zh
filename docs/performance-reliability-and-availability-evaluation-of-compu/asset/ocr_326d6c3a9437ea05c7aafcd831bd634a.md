This section briefly presents the following measures of importance: structural measure, the Birnbaum (reliability) measure (and some variants), risk achievement, risk reduction, and the criticality. These measures are mainly dependent on two factors: the location of the component in the system, and the probability of the component being operational [103, 140, 224, 225].

In the system design, the importance measure may be adopted to analyze the system reliability. The reliability of a component may be enhanced by considering higher quality modules, by adopting redundancy, reducing the workloads, or by adjusting the maintainability. The component importance measure aims to support designers to spot components that should be enhanced and grade these components in order of importance. In the operational phase, the component importance may be adopted to support allocating maintenance to the most critical subsystems or components. These measures may also be considered to identify parts that should be improved or replaced with higher quality components.

First let introduce the concept of structural importance [47, 48]. The structural importance of component $i$ in a system measures the importance of the respective position $i$ in the system. This importance measure is useful in early design stages, mainly when data on reliability of components are unavailable.

Consider a system by an RBD with a set of $n$ components and the set of all possible states $SS (SS = (x_{ij})_{ij})$. The function $1_i(\mathbf{X})$ is an indicator function that is evaluated if the structure function is evaluated as for a specific state $\mathbf{X}$ and the component $i$ is operational. The function $0_i(\mathbf{X})$ is also an indicator function that is evaluated as if the structure function is evaluated as for one specific state $\mathbf{X}$ and the component $i$ failed.

```
$I_i : SS \rightarrow \begin{cases} 1 & \Phi(x_1, \dots, x_{i-1}, x_{i+1}, \dots, x_n) = 1, \ 0 & otherwise; \end{cases}$
```

and

```
$O_i : SS \rightarrow \begin{cases} 1 & \Phi(x_1, \dots, x_{i-1}, 0, x_{i+1}, \dots, x_n) = 1, \ 0 & otherwise. \end{cases}$
```

The vector $(x_1, \dots, x_{i-1}, 1, x_{i+1}, \dots, x_n)$ is also represented by $(1_i, \mathbf{X})$. Likewise, the vector $(x_1, \dots, x_{i-1}, 0, x_{i+1}, \dots, x_n)$ is also denoted by $(0_i, \mathbf{X})$ (see the structure function 18.3.6).

The structural importance of a component $i$ is defined by

```
$I_i^S = \frac{1}{2n-1} \sum_{j \in SS} (I_i(j) - O_i(j)), \quad (18.9.1)$
```
