# Workload Characterization

The line Total shows the number of connections (sessions), 20 connections, the total number of calls and replies, 20 each connection makes only one call - default, and the duration, 454ms. After that, we get the connection rate (in connections per second), the minimum, the average, the median, and the maximal, the standard deviation of the connection times. Then, we get the request rate (in requests per second), the request size in bytes, the reply rate (replies per second), the reply time, and subset data as in the previous examples.

The following sequences two hundred sessions, each session makes calls, and a timeout of 5s for each call is defined.

```
> httpperf --hog --server 172.217.30.36 --rate 600
--num-conns 200 --num-calls 30 --timeout 5
```
