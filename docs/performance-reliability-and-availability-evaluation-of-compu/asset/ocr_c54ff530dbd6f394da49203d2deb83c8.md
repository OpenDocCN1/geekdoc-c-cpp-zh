# Performance, Reliability, and Availability Evaluation of Computational Systems

The Dagun Distribution represents a continuous distribution defined over the interval $(0, \infty)$ with three positive parameters $p, a,$ and $b$. The parameters $p > 0$ and $a > 0$ are “shape parameters”, and the parameter $b > 0$ is a “scale parameter”. This distribution is also referred to as a Burr III distribution. The main motivation is that the hazard rate of this model is very flexible, according to the values of the parameters. For instance, considering $p = 0.5$ and $b = 2$, taking $a = \{1, 2, 4\}$, we have the following hazard plots shown in Figure 16.11.

```
$$F(t) = \left((\left(\frac{t}{b})^a+1\right)^{-p}, t \ge 0.\quad (16.3.55)$

Reliability:

```
$$R(t) = 1 - \left((\left(\frac{t}{b})^a+1\right)\right)^{-p}, t \ge 0.\quad (16.3.56)$
```

```
