Gamma Distribution: Assume $T$ is a gamma random variable with parameters $\alpha$ and $\beta$ that specifies the time to failure of a sample size of $n$ obtained from the distribution generated by $T$. As the given moment generating function, the first two moments of which should be obtained from the target distribution.

$M_T(t) = e(1-\beta)^{-\alpha}$.
(25.3.16)

Taking the first derivative of $M_T(t)$ in relation to $t$, and setting $t=0$, we get

$\mu_1 = \alpha\beta$.

Now, calculating the second derivative of $M_T(t)$ for respect to $t$, and setting $t=0$, we obtain

$\mu_2 = \alpha(\alpha+1)\beta^2$.

Now consider a sample from the population to calculate the first two moments about

$m_1 = \frac{\sum_{i=1}^n x_i}{n}$

$m_2 = \frac{\sum_{i=1}^{n} X_i^2}{n}$

then, let $\mu_1 = m_1$ and $\mu_2 = m_2$ as studied in this system. We get as,

$\hat{\alpha} = \frac{m_1}{\beta} \quad (25.3.17)$

and

$\hat{\beta} = \frac{m_2 - m_1^2}{m_1}$

## Poisson Distribution

Assume $X$ is a random variable distributed according to a Poisson distribution with parameters $\lambda$. As the Poisson distribution has only one parameter, we need only one moment. The Poisson first moment about the origin is $\mu_1 = \lambda$, and the first moment is given by $(\sum_{i=1}^n x_i)/n$, where $n$ is the sample size. Hence

$\hat{\lambda} = \frac{\sum_{i=1}^n x_i}{n}. (25.3.19)$

**Example 25.3.8.** Customers call a small center according to a Poisson distribution. The mean number of calls per hour is constant and equal to $\lambda$. The help center was monitored for one hundred hours ($n=100$ h), and the number of calls in each hour was recorded in Table 25.20. Applying Equation 25.3.19, we see that $\hat{\lambda} = (\sum_{i=1}^{100} x_i)/100 = 993/100 = 9.93$ calls per hour.
