**Example 18.9.5.** The RBD depicted in Figure 18.29.c is a parallel composition of two-blocks series structures. The system is composed of six blocks $\{b_{11}, b_{12}, b_{21}, b_{22}, b_{31}, b_{32}\}$. The system reliability is

```
$R_s(t) = 1 - ((1 - R_{11}(t)R_{12}(t)) \times (1 - R_{21}(t)R_{22}(t)) \times (1 - R_{31}(t)R_{32}(t)))$.
```

## Reliability Block Diagram

The reliability importance of each component is

```
$I_{11}^B = \frac{\partial R_B(t)}{\partial R_{11}(t)} = R_{12}(t)(1 - R_{21}(t)R_{22}(t))(1 - R_{31}(t)R_{32}(t)).
```

```
$I_{12}^B = \frac{\partial R_B(t)}{\partial R_{12}(t)} = R_{11}(t)(1 - R_{21}(t)R_{22}(t))(1 - R_{31}(t)R_{32}(t)).
```

```
$I_{21}^B = \frac{\partial R_B(t)}{\partial R_{22}(t)} = R_{22}(t)(1 - R_{11}(t)R_{12}(t))(1 - R_{31}(t)R_{32}(t)).
```

```
$I_{22}^B = \frac{\partial R_B(t)}{\partial R_{22}(t)} = R_{21}(t)(1 - R_{11}(t)R_{12}(t))(1 - R_{31}(t)R_{32}(t)).
```

```
$I_{31}^B = \frac{\partial R_B(t)}{\partial R_{31}(t)} = R_{32}(t)(1 - R_{11}(t)R_{12}(t))(1 - R_{21}(t)R_{22}(t)).
```

```
$I_{32}^B = \frac{\partial R_B(t)}{\partial R_{32}(t)} = R_{31}(t)(1 - R_{11}(t)R_{12}(t))(1 - R_{21}(t)R_{22}(t)).
```

Considering the reliability of blocks at a specific time $t$ is $R_{11}(t) = 0.95$, $R_{21}(t) = 0.94$, $R_{22}(t) = 0.93$, and $R_{32}(t) = 0.89$, respectively; the reliability importance of each component is $I_{11}^B = 0.0270115$, $I_{12}^B = 0.0272988$, $I_{21}^B = 0.0198025$, $I_{22}^B = 0.0137512$, and $I_{32}^B = 0.0272988$ (see Figure 18.33,a). The maximum reliability importance $MBI = 0.0272988$.

The normalized reliability measures $NI_{11}^B = 0.989474$, $NI_{12}^B = 1$, $NI_{21}^B = 0.717597$, $NI_{31}^B = 0.503729$, and $NI_{32}^B = 0.509389$ (see Figure 18.33,b). These results show that the most important block is the one with smallest reliability that belongs to the series structure that has the highest reliability, since it is a component of two-block structures. In such cases, we have a partial derivative of the system availability concerning the component $i$'s availability. Transient and steady-state availability may be considered:

```
$I_i^A = \frac{\partial A_s}{\partial A_i}$
```

**Example 18.9.6.** Assume a computational system composed of a hardware server ($hw$), an operational system ($os$), and three application programs ($a_1, a_2$, and $a_3$). The application program $a_2$ is composed of two modules, $a_{21}$ and $a_{22}$. This system is operational if application programs $a_1$, $a_2$, or $a_3$ are operational. The operational mode may be represented by the following function:

$\Psi(hw, os, a_1, a_{21}, a_{22}, a_3) = hw \wedge os \wedge a_1 \wedge ((a_{21} \wedge a_{22}) \vee a_3)$. The RBD shown in Figure 18.34 represents this system.

```

```
