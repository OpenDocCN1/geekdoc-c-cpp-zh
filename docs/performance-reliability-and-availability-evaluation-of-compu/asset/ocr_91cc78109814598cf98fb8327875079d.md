Setting the system time and date manually with the date command is not recommended since Linux platforms usually have the clock which is synchronized using the ntp or systemd-timesynced services. Nevertheless, if one needs to set the system time and date manually, the -set may be useful. For example, if one is required to set the date and time to 6:03 pm, May 29, 2020, one may type

```
> date --set="20200529 18:03".
```

The pidstat command is used for monitoring either specific processes (PID) or all processes managed by Linux. The basic syntax of this command is pidstat options delay count, where delay and count have the same meaning as shown for vmstat. The pidstat supports many configuration options. For a detailed view of these options, refer to man pidstat. If the command is executed without an explicitly defined option, only processors' activities are reported. Some important options are depicted below.

+   - C comm displays processes whose command name include the string comm.
- d reports input-output statistics, where
  - UID is the real user identification,
  - USER is the name of the real user owning the process,
  - PID is the identification number of the process,
  - kB_rd/s is the number of kilobytes the process read from disk per second,
  - kB_wr/s is the number of kilobytes the process has written to disk per second,
  - kB_ccwr/s is the number of kilobytes whose the process has canceled writing to disk,
