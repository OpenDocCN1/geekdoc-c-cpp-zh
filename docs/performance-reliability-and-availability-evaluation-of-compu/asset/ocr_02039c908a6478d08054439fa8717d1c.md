The probability that the system $S$ will be repaired by **maintainability**, $M(t)$. Thus

```
$P(D \le t) = F_D(t) = M(t) = \int_0^t f_D(t)dt. \quad (16.2.14)$
```

The **mean time to restore** (MTTR) is defined by

```
$MTTR = \int_0^\infty t f_D(t)dt. \quad (16.2.15)$
```

Let us define $UM(t) = 1 - M(t)$ (as $M(t) = F_D(t)$, $UM(t) = 1 - F_D(t)$ – complementary cumulative distribution function – CCDF). Hence

```
$f_D(t) = \frac{UM(t)}{dt}$
```

Thus,

```
$MTTR = \int_0^\infty \frac{UM(t)}{dt} \times t dt.$
```

Let $u = t$ and $dv = \frac{UM(t)}{dt}$, then $du = dt$ and $V = UM(t)$. Integrating, by we have

```
$MTTR = \left[UM(t)|_0^\infty - \int_0^\infty UM(t)dt\right].$
```

```
$MTTR = \int_0^\infty UM(t)dt,$
```

since at $t = 0$, $UM(0) = 0$ and $\lim_{t\to\infty} UM(t) = 0$. Therefore

```
$MTTR = \int_0^\infty (1-M(t))dt, \quad (16.2.16)$
```

which is often easier to compute than 16.2.15.
