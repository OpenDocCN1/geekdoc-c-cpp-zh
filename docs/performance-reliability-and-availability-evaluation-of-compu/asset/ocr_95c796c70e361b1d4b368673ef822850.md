The Expression 21.47 allows estimating the system reliability disregarding the probability of being in the uncovered (unsafe) state 1U.

$R_S(t) = \pi_2(t) + \pi_1(t).$

The MTTF can be calculated from

$MTTF = \int_{0}^{\infty} R(t) dt = \int_{0}^{\infty} (\pi_2(t) + \pi_1(t) + \pi_{IU}(t)) dt$,

or Equation 10.6.7, which leads to

$MTTF =$

$4\lambda^2(\beta + \lambda)^2 + \mu^2(\beta^2 + 2(3-2c)\lambda + (2c-5+7)\lambda^2) + \lambda\mu(\beta + \lambda)(5\beta + (13-8c)\lambda) / 2\lambda^2(-c-\mu + \lambda + \mu)(2\beta + \lambda) + \mu(\beta + (3-2c)\lambda)).$

Assuming $\lambda = 1.24 \times 10^{-3}h^{-1}, \mu = 2.5 \times 10^{-1}h^{-1}, \beta = 2h^{-1},$ and $c = 0.95$, the MTTF is $81994h$. Figure 21.19 shows the system reliability in the time interval $(0,100000h)$.
