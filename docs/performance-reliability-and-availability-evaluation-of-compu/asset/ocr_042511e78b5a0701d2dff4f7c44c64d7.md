Algorithm 23 Gamma Distribution Parameters’ Confidence Interval based on Semi-Parametric Bootstrap

```
1: nors = 1000, ss=100;
2: $\alpha = 0.1$;n3: $\gamma = 7.08$, $\hat{eta} = 304.99$;n4: palest = { $\gamma$, $\hat{eta}$ }. Table[FindDistributionParameters[RandomVariate[GammaDistribution[$\gamma$, $\hat{eta}$], GammaDistribution[$\gamma$, $\beta$], ParameterEstimator-\MethodOfMoments], nors]];
5: Print("degree of confidence =", N[1-\alpha$] - $\gamma$ $\in$, Quantile[$\gamma$, {$\alpha/2$, (1 - ($\$\alpha/2$))]);
6: Print("degree of confidence =", N[1-\alpha$] - $\beta$ $\in$, Quantile[$\beta$, {$\alpha/2$, (1 - ($\$\alpha/2$))]);
```

resample., the number of resampled samples is specified in nors. The command {$\gamma$, $\beta$} removes the symbols $\gamma$ and $\beta$ from the last palest. palest[[All,1], $\alpha/2$, (1 - ($\$\alpha/2$))] and Quantile[[All, 2]] find the quantile $\alpha/2$ and 1 - $\alpha/2$ for $\gamma$ and $\beta$, where $\alpha$ is the degree of significance.

Executing this Mathematica code an interval was generated for the distribution parameters. The confidence intervals obtained were $\gamma \in (5.6, 9.2)$ and $\beta \in (233.5h, 386.96h)$ with 90% degree of confidence.
