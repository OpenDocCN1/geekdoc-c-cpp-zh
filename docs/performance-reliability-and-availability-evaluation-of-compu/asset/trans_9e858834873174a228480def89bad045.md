由 SPN 模型翻译如下：

```
$tp_2 = P(p_1 > 0) \times \mu$
```

总吞吐量的计算公式为：

```
$tp = P(p_0 > 0) \times \lambda + P(p_1 > 0) \times \mu$
```

**示例 24.3.7.** 采用 $a = 5ts$，$\beta = 10ts$，$\lambda = 350ts$ 且 $\mu = 700ts$，并获得图 24.36 中 SPN 的稳态解，得到 $tp_1 = 233.3332, tp_2 = 233.3333,$ 以及 $tp = 466.6666$，作为示例 24.3.6 中 CTMC 计算的结果。值得注意的是，从生成的轨迹计算出的吞吐量 $\bar{tp} = 487.918ts$，这接近于考虑长度为 1000 个事务请求的 SPN 所得的值。
