# Performance Reliability, and Availability Evaluation of Computational Systems

CDF:

```
$F(t) = 1 - e^{-\left(\frac{t-\mu}{eta}ight)^a}, \quad t \geq \mu.$
```

Reliability:

```
$R(t) = e^{-\left(\frac{t-\mu}{eta}\right)^a}, \quad t \geq \mu.$
```

PDF:

```
$f(t) = \frac{\alpha e^{-\left(\frac{t-\mu}{\beta}\right)^\alpha} \left(\frac{t-\mu}{\beta}\right)^{\alpha-1}}{\beta}, \quad t \geq \mu.$
```

Mean time to failure:

```
$MTTF = \beta\Gamma \left(1 + \frac{1}{\alpha}\right) + \mu.$
```

**Example 16.3.3.** Consider a system with a hazard function equal to $\lambda(t) = bt^a, a > 0, b > 0$ (a monotonically increasing function). As the cumulative hazard function is $H(t) = \int_0^t \lambda(t) dt$, then

```
$H(t) = \frac{b}{a+1}t^{a+1}.$
```

If $a = \alpha - 1$, then

```
$H(t) = \frac{bt^\alpha}{\alpha}.$
```

If $b = \frac{\beta}{\alpha}$, then

```
$H(t) = \left(\frac{t}{\beta}\right)^\alpha.$
```

Therefore,

and

```
$R(t) = e^{-\left(\\frac{t}{\beta}\right)^\alpha},
```

```
$F(t) = 1 - e^{-\left(\\frac{t}{\beta}\right)^\alpha},
```

which is a Weibull distribution with parameters $\alpha, \beta$ and $\mu = 0$.
