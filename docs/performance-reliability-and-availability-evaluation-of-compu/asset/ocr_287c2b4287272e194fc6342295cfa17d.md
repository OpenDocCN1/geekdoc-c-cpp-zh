This problem is set up as a conditional probability of which the aim is to maximize the probability of obtaining our data given $\Theta$. Therefore, for a data sample of size n, mathematically, this looks like:

> $P(t_1, t_2, ...t_n \mid \Theta)$

The aim is to maximize this probability of observing our data as a function of $\Theta$. In other words, we want to find $	heta_1$ and $	heta_2$ values such that $P(t_1, t_2, ..., t_n \mid \Theta)$ is as high as it can possibly be.

We are used to $t$ being the independent variable. However, in this case $	heta_1$ and $	heta_2$ are the independent variable(s), and $t_1, t_2, ..., t_n$ are constant since the observed data do not change.

We know that the probability of multiple independent events is termed joint probability. We can treat each data point (observation) as one single event. If the events are i.i.d., we treat the observations of our data sample as a series of independent events, such that the joint probability:

> $P(t_1, t_2, ...t_n \mid \Theta) = P(t_1 \mid \Theta) P(t_2 \mid \Theta) ... P(t_n \mid \Theta),$

> $P(t_1, t_2, ...t_n \mid \Theta) = \prod_{i=1}^{n} P(t_i \mid \Theta).$
