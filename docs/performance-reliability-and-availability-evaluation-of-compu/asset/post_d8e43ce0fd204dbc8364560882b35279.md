## Weibull Distribution

Assume $T$ random variable distributed to Weibull distribution with parameters $\beta$ (scale) and $\alpha$ (shape) representing the time to failure of dependents. A time to failure sample of size $n$ was obtained from a population that follows Weibull distribution, $\mathcal{S} = \{t_1, t_2, \dots, t_n\}$, such that $t_1 < t_2 < \dots < t_i < \dots < t_n$.

The cumulative distribution function of $T$ is

$F(t) = 1 - e^{-(t/\beta)^\alpha}$

$1 - F(t) = e^{-(t/\beta)^\alpha}$

where $t \ge 0, \beta \ge 0$ and $\alpha > 0$. From the equation above we obtain

$\ln(1 - F(t)) = \ln(e^{-(t/\beta)^\alpha})$

$\ln(1 - F(t)) = -(t/\beta)^\alpha$

$-\ln(1 - F(t)) = (t/\beta)^\alpha$

$\ln(-\ln(1 - F(t))) = \alpha \ln(t) - \alpha \ln(\beta)$
