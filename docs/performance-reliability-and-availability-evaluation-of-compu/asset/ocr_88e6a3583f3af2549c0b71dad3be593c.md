Assume the inspection time is also exponentially distributed with a rate of $\mu_i$. The preventive repairing time is assumed to be a submultiple of the corrective maintenance, but also exponentially distributed with a rate of $\gamma\mu_i$, where $\gamma$ defines how much shorter the preventive repair in comparison with the corrective repair. The CTMC shown in Figure 21.50.c is an availability model of such a system with both corrective and time-based maintenance.

In state 0, two events are possible; first, the system may age and transition to state 1 with a rate of $\lambda$. The second event is the start of preventive maintenance. This event takes the system to state 9 with a rate of $\delta$. In state 0, the system has not aged; there will be an inspection but no repair. After the inspection, the system is taken back to state 0 with a rate of $\mu_i$. In state 1 (the system has already aged), two events are possible. First, the system may age and transition to state 2 with a rate of $\lambda$. Preventive maintenance may also begin. This takes the system to state 5 with a rate of $eta$. Then, the system is inspected, which transitions the system to state 8 with a rate of $\mu_i$, and then the preventive repair is carried out with a rate of $\gamma\mu_i$ and takes the system back to state 0. The following states and transition likewise. However, if the system reaches state 4 (a failure), the system is corrected (corrective maintenance) with a rate of $\mu$, which takes the system back to state 0. The system is available in all states except 4 and 8. Thus, solving the system of equations $\Pi Q = 0, \sum_{i} \pi_i = 1$, we obtain the steady-state system probabilities, and the availability is expressed by

> $A = 1 - \sum_{i\in\{4,8\}} \pi_i.$

Doing some algebra, we obtain

```
$A = \frac{\gamma\mu(\delta + 2\lambda)(\delta^2 + 2\delta\lambda + 2\lambda^2) + \gamma\mu_i(\delta + 2\lambda)(\delta^2 + 2\delta\lambda + 2\lambda^2) + \delta\mu_i(\delta^2 + 3\delta\lambda + 3\lambda^2)}{...} (21.10.1)$
```

**Example 21.10.1.** A system depicted in Figure 21.50.a, and consider the following rates: $\lambda = 2 \times 10^{-3} h^{-1}$, $\mu = 0.1 h^{-1}$, $\mu_i = 1 h^{-1}$, and $\delta = 1.428571 h^{-1}$, and the multiple $\gamma = 4$. The steady-state availability without preventive maintenance (calculated from the CTMC shown in Figure 21.50.b) is $A = 0.99502$. The yearly downtime in hours of $DT = T(1-A)$ where $T = 8760h$ is the number of hours in a year.

The steady-state availability taking into account the preventive maintenance provides an availability of $A=0.99626$ and the yearly downtime is $DT=32.76$. Figure 21.51 shows the availability in terms of the $\delta$, considering the interval $\delta \in (10^{-3} h^{-1}, 5 \times 10^{-3} h^{-1})$.
