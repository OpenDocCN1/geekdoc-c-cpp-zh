Solving $\Pi \cdot Q = 0, \sum_{i} \pi_i = 1$, we obtain

```
$A = \frac{\mu(\delta + 2\lambda) + 2\lambda(\delta + \lambda)}{2\lambda^2 + 2\lambda\mu + \mu^2} \quad (21.3.2)$
```

For $\lambda = 1.24 \times 10^{-3} h^{-1}, \mu = 2.5 \times 10^{-1} h^{-1}$ and $\delta = 240 h^{-1}$, we obtain $A = 0.999946, DT = (1-A) \times 525600$ minutes = 28.2919 minutes. Figure 21.14 is a reliability model of the hot-standby redundancy with non-zero switching delay. In state 2, both servers may fail. However, if the standby server fails, since it is not processing the workload, the service is not immediately interrupted. Transitions to state $1U$, is still an operational state. In such a state, the spare server may be repaired, or the main server may fail. If it fails, the system becomes unavailable. If the primary server fails in state 2, the system immediately transitions to state 0. It is worth observing that in both states, 2 and $1U$, there is a transition with rate $\lambda$ to state 0. The rate matrix is

```
$Q = \begin{pmatrix} -2\lambda & \lambda & \lambda \ \mu & -\lambda-\mu & \lambda \ 0 & 0 & 0 \end{pmatrix}$
```

From $Q$, we obtain (see the Matrix Structure 10.6.3).

```
$R = \begin{pmatrix} -2\lambda & \lambda \ \mu & -\lambda-\mu \end{pmatrix}$
```
