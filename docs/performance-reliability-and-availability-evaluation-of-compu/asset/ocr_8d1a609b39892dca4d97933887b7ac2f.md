# 21.5 COLD-STANDBY REDUNDANCY

Let us assume the system depicted in Figure 21.20. This system is composed of two routers configured in cold-standby. Router1 ($R_1$) is the primary device, whereas Router2 ($R_2$) is a spare unit. In normal operation, the arrival and departure traffic is routed by $R_1$, and Router$_2$ is offline. If $R_1$ fails, $R_2$ is switched on and assumes the traffic routing. Consider $R_1$ and $R_2$ are devices of the same brand, and assume the particular times for failure to be exponentially distributed with a rate of $\lambda$. The delay required after switching one of the spare device until it gets operational is also assumed to be exponentially distributed with a rate of $\delta$. The second failure is exponentially distributed with a rate of $\mu$. The time to repair the routers is exponentially distributed with a rate of Consider only one repair facility. It is also assumed that the router does not fail when switched off.

The CTMC presented in Figure 21.21 is an availability model of the system shown in Figure 21.21. This model is composed of four states, 2, 1D, 1', and 0. $R_1$ is operational and $R_2$ is turned off. The only event possible is a failure of the router $R_1$. It is worth mentioning that if the switched-off device does not fail. If $R_1$ fails, the system transitions to state 1D with a rate of $\lambda$. In state 1D, the system becomes unavailable unless the spare router, $R_2$, requires time to become operational. Additionally mentioned, this delay is exponentially distributed with a rate of $\delta$. From state 1D, two events are possible: $R_2$ can be switched on, and if it occurs, the system transitions from 1D to 1, which is an operational state, with a rate of $\delta$. The second possible event is the repair of $R_1$. If this happens, the system transitions back to state 2 with a rate of $\mu$. In state 1, $R_1$ may be repaired, and so, doing. It may also fail. When this occurs, the system transitions from state 1 to state 0 with a rate of $\lambda$. In state 0, the system is out of service; that is, both routers are out of order.
