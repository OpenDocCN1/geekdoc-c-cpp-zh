For each decorated function, memory usage information is given for each function's command. In this particular case, memory consumption for each command line is provided since we included decorators before the definition of function command load_1GB_of_data() (line 2), process_data() (line 5), modify() (line 9), mem() (line 12), and main() (line 21). The increment shows amount of memory each command of function consumes. Looking at line 28, we see that function-mem increments 22.871 MiB in memory usage, whereas process_data adds 104.675 MiB. In line 9, we have the function call load_1GB_of_data(). It is worth noting the increment only 0.137 MiB.
