Now assume a CTMC that represents the system failure (see Figure 21.3.a). This model has two states, $U$ and $D$, and only one transition. This transition represents the system failure, is, when the system is operational ($U$) may fail, and this event is represented by the transition from the state $U$ to state $D$, with failure rate $(\lambda)$. The rate matrix is shown in Figure 21.3.b. Solving$^4$

```
$$\frac{d\Pi(t)}{dt} = \Pi(t) \cdot Q,$
```

where $\Pi(t) = $(\pi_U(t), \pi_D(t))$ and $\pi_U(t) + \pi_D(t) = 1$, we obtain $\pi_U(t) = e^{-\lambda t}$ and $\pi_D(t) = 1 - e^{-\lambda t}$. The system reliability is

```
$R(t) = \pi_U(t) = e^{-\lambda t} \quad (21.1.5)
```

and the unavailability is

```
$UR(t) = \pi_D(t) = 1 - e^{-\lambda t}. \quad (21.1.6)
```

It is worth mentioning $UR(t) = F(t)$, where $F(t)$ is the cumulative distribution function of the time to failure (see Equation 16.2.2).
