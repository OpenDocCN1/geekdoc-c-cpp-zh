The reliability at $t$ can be calculated using the SPN shown in Figure 22.7.c through

```
$$$R(t) = P\{COK > 1\}(t).$$
```

Hence, the mean time to failure can be computed through

```
$$$MTTF = \int_{0}^{\infty} R(t)dt.$$
```

The capacity oriented availability may also be calculated using the availability model through

```
$$$COA = \frac{E\{COK\}}{2},.$$
```

where $E\{COK\}$ is the average number of servers available (ANSA).

Consider each server can sustain a throughput $tp$. The average throughput - ATP - is the weighted sum of throughputs. Consider a system with two servers, where each server can sustain a throughput $tp$. More formally:

```
$$$ATP = P\{COK = 1\} \times tp + P\{COK = 2\} \times 2tp,$$
```

which is equal to

```
$$$ATP = E\{COK\} \times tp.$$
```
