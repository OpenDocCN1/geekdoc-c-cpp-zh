# Performance, Reliability, Availability Evaluation of Computational Systems

Now, consider $B = (s_i)$ is a vector of the Boolean variables of the set $BS$, and its cardinality $|BS| = n$. The logical function that represents the operational mode depicted by the RBD is defined by

```
$$\Psi(\mathbf{B}) = \begin{cases} F & \text{if } S \text{ has failed.} \ T & \text{if } S \text{ is operational.} \end{cases} \quad (18.3.1)$
```

If the system performs more than one functionality (operation), logical functions should be defined for representing each functionality (**operational mode**). The meaning of an intended functionality must be specified and depends on the objective of the study. Hence, the system being operational for a particular functionality does not mean it is operational for another functionality.

Let us illustrate the concept. A system depicted by the RBD shown in Figure 18.1. This system is operational as a path that connects the source node to the target node. Hence, if $b_1$, $b_2$ and $b_3$ are in operational states, the system is operational. The set of Boolean variables describes the states of the blocks of this RBD $BS = \{s_1, s_2, s_3\}$, and the vector $\mathbf{B} = (s_3, s_2, s_1)$, $|BS| = 3$. Table 18.1 shows the enumeration of the whole set of vector, and evaluates the respective logical function.

# Table 18.1
State Enumeration - Logical Function

| $s_3$ | $s_2$ | $s_1$ | $\Psi(\mathbf{B})$ |
|---|---|---|---|
| F | F | F | F |
| F | F | T | F |
| F | T | F | F |
| F | T | T | T |
| T | F | F | T |
| T | F | T | F |
| T | T | T | T |

All we have to do is examine the Column $\Psi(\mathbf{B})$ of the enumeration in Table 18.1 for any rows where the output is “T”, and write the conjunction that would equal a value of “T” given those input conditions. The obtained function is

```
$$\Psi(\mathbf{B}) = (s_3\wedge s_2 \wedge s_1) \vee (s_3\wedge s_2 \wedge s_1) \vee (s_3\wedge s_2 \wedge s_1)$
```
