**Example 20.2.2.** Let us have a system composed of three identical components, $C_1, C_2,$ and $C_3.$ Each of these components can be operational ($x_i = 1$) or in failure ($x_i = 1$), $i \in \{1,2,3\}.$ Table 20.7 shows all possible states of each component. If these components are arranged in series, the respective structure function is only evaluated to 1 for the state $X=(1,1,1).$ This is shown in Column $\Phi_S(X)$. If components are arranged in parallel, the respective structure function is evaluated to 1 for all states except $X=(0,0,0).$ This is shown in Column $\Phi_P(X)$. For a 2oo3 system, the structure function is evaluated to 1 for states $(0,1,1), (1,0,1), (1,1,0),$ and $(1,1,1).$ Column $\Phi_{2oo3}(X)$ of the Table 20.7 shows this function.
