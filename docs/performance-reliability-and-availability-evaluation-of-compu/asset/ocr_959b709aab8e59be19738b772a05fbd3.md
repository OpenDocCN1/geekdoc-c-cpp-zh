# Redundancy

RAID 51 is implemented by mirroring (RAID 1) in an entire RAID 5 array (see Figure 17.14.a). RAID 51 also requires at least six disks and tolerates up to four disk failures. The storage capacity efficiency is specified by

```
SCE = \frac{ESC}{TDC} = \frac{(n-2)}{n}, \quad (17.1.6)
```

where $ESC = ((n-2)/2) \times DC$.
