# Performance, Reliability, and Availability Evaluation of Computational Systems

The MTTF is $\int_{0}^{\infty} R(t) dt = \int_{0}^{\infty}\sum_{i=1}^{n} p_i e^{-\lambda_i t} dt$, so

```
$MTTF = \sum_{i=1}^{n} \frac{p_i}{\lambda_i}; \quad \text{where } \sum_{i=1}^{n} p_i = 1.$
```

Applying 16.2.7, we get the hazard rate function

```
$\lambda(t) = -\frac{dR(t)}{dt} R(t)$
```

```
$\lambda(t) = \frac{\sum_{i=1}^{n} p_i e^{-\lambda_i t} / dt}{\sum_{i=1}^{n} p_i e^{-\lambda_i t}}$
```

```
$\lambda(t) = \frac{\sum_{i=1}^{n} p_i \lambda_i e^{-\lambda_i t}}{\sum_{i=1}^{n} p_i e^{-\lambda_i t}}; \quad \text{where } \sum_{i=1}^{n} p_i = 1 \text{ and } t \ge 0.$
```

# Erlang Distribution

Consider a device is subjected to hits that occur as a Poisson process with rate $\lambda_$. Assume this device fails after $k$ hits (increasing failure rate). This model leads to a reliability function that belongs to the gamma distribution with $k$ integer. The rate is the same for every hit, this gamma distribution is an Erlang distribution; otherwise, it is a hypoexponential distribution (see Chapter 2 and Section 13.3.8.3). The Erlang CDF is

```
$F(t) = 1 - \sum_{i=1}^{k} \frac{e^{-\lambda(t)i}}{i!}; \quad t \ge 0.$
```

The reliability is defined by

```
$R(t) = \sum_{i=1}^{k} \frac{e^{-\lambda(t)i}}{i!}; \quad t \ge 0.$
```

The density function is specified by

```
$f(t) = \frac{\lambda^k t^{k-1} e^{-\lambda(t)}}{(k-1)!}; \quad t \ge 0.$
```

The hazard function is

```
$\lambda(t) = \frac{\lambda^k t^{k-1} e^{-\lambda t}}{(k-1)!}; \quad t \ge 0.$
```
