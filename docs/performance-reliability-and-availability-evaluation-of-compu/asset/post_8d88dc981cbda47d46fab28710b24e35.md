# 18.7 COMMON CAUSE FAILURE

A common cause failure (CCF) is the result of events, concurrent with system events and local states, which lead to system failure. A common cause failure can be internal or external to the system and can act simultaneously on significant (if not all) components of a system. Therefore, a common cause fault is a major concern in many critical systems. Some typical common cause faults are external events such as power outages, storms, earthquakes, tsunamis, flooding, hurricanes, and lighting. For example, if a lightning strike hits a server rack, it can destroy all levels of redundancy at once.

The term common mode failure (CMF) is also frequent. CMF refers to coincident failures of the same mode; that failures that have an identical effect. On the other hand, hard implies the failures have the same underlying cause. It is possible for CMFs not to have a common cause and vice-versa. The models used in this section assess the cause of coincident failure, CCF will be used throughout [401].

Consider a redundant system of subsystems represented by two blocks in parallel ($b_1$ and $b_2$) (see Figure 18.27.a). Assume failure rate of both components are equal, constant. However, if a percentage ($p$) of failures ($\lambda_{ccf} = p \times \lambda$) affect both subsystems (CCF) and thus the redundancy, it is necessary to add a block ($b_3$) in series to represent the CCF (see Figure 18.27.b).

Assume $\lambda = 10^{-4}h^{-1}$. The MTT of the system depicted in Figure 18.27.a is $1500h$ and the system reliability at $t = 10000h = 0.6004$. If CCF is considered and its rate is equal to $\lambda_{ccf} = 10^{-5}h^{-1}$, the system’s MTT is $13419.91h$ and $R(10000h) = 0.5433$.

# 18.8 PATHS AND CUTS

Consider a coherent system represented by a RBD, and its set of components $CS=\{b_1, b_2\}$. A **path** $P$ is a set of components (blocks), $P \subseteq CS$, if operational connects the source node $(S)$ to the target node $(T)$. Otherwise stated, a path set $P$ is a set of components by functioning which ensures the system is functioning.

The vector state $X_P$ that represents the path $P$ is a denoted path vector. In other words, $X_P$ is called a path vector if $\Phi(X_P) = 1$. A path vector is called minimal if $\Phi(Y) = 0$ for every $Y < X$. The corresponding set of components $P$ is called a **minimal path** (minpath). In a series system of $n$ components, there is only one minimal path set, and each is composed of every component of the system. In the other, in a parallel system with $n$ components, there are $n$ minimal paths, each set formed by only one component.

Assume the RBD depicted in Figure 18.22.a. The set of blocks $B=\{b_1, b_2\}$, represented by its respective vector $X_B=(1, 1, x_3, x_4, x_5)$, is a path, since $x_1=1$ and $x_2=1$, $\Phi(X_B)=x_1=x_2=1$.

The set $B'=\{b_1, b_2, b_4\}$, and respective state vector $X_{B'}=(1, 1, x_3, 1, x_5)$, also leads to $\Phi(X_{B'})=1$; thus $B'$ is also a path. However, $B'$ is not minimal. Observe that $X_B < X_{B'}$ and $\Phi(X_B)=1$; hence not minimal. However, for every $Y < X_B$, $\Phi(Y)=0$; thus minimal.

The complementary notion of a path is termed a cut. A **cut** $C$ is a set of components, $C \subseteq CS$, if failed does not connect the source node $(S)$ to the target node $(T)$. In other words, a cut $C$ is a set of components of a system by failing causes the system to fail.

A cut vector $X_C$ is a vector that represents a cut $C$; $\Phi(X_C)=0$. A cut vector is called minimal if $\Phi(Y)=1$ for every $Y > X_C$. The corresponding set of components $C$ is called a **minimal cut** (mincut). In the series system, there are $n$ minimal cuts, each formed by one component. The minimal cut set of the parallel system is composed of all the components of the system.

Consider the RBD depicted in Figure 18.22.a: a cut, since B = {b1, b2}, represented by its respect vector $X_B = (0, x2, x3, 0, x5), since $x_1 = 0$ and $x_4 = 0$. $\Phi(X_B) = 1 - ((1 - x1) (1 - x2)) = 0$.

The B' = {b1, b2, b3}, represented by the state vector $X_B' = (0, 0, x3, 0, x5), is also a cut, since $x_1 = 0$, and $x_4 = 0$ leads to $\Phi(X_{B'}) = 0$. However, B is minimal, whereas B' is not. Observe that for $Y > X_B$, it does not ensure $\Phi(Y) = 0$. However, for $Y = (0,0,x3,1,xs), $Y > X_B$, $\Phi(Y) = 0$.

Example 18.8.1. The RBD depicted in Figure 18.1 has three paths and three cuts. The paths are P1 = {b1, b2, b3}, P2 = {b1, b2}, and P3 = {b1, b2, b3}. The paths P2={b1, b2} are minimal paths. The cuts C1={b1, b3}, C2={b2, b3}, and C3={b1, b2, b3} are minimal cuts.

Example 18.8.2. The RBD depicted in Figure 18.2 has two paths and two cuts. The paths are P1={b1, b2} and P2={b1, b2}. The cuts are C1={b1} and C2={b2}.

Example 18.8.3. The RBD depicted in Figure 18.3 has two paths and two cuts. The paths are P1={b1, b2, b3} and P2={b1, b3}. The cuts are C1={b1} and C2={b3}.
