tps represents the number of I/O requests to the device per second. Multiple logical requests can be combined into a single I/O request to the device. A transfer is of indeterminate size. Hence, a metrics only makes sense when comparing distinct measures, such as areq-sz, rare-sz, wareq-sz and dareq-sz. Blk_read/s (kB read, MB read/s) represents the amount of data read from the device in blocks read (kilobytes, megabytes) per second. Blocks sizes are equal to 512 bytes. Blk_wtrn/s (kB wtrn, MB wtrn/s) represents the amount of data written to the device expressed in a number of blocks per second. Blk_dscd/s (kB dscd, MB dscd) represents the amount of data discarded in a specified number of blocks read per second. Bl_read (kB read, MB read) is the total number of blocks read. Blk_wtrn (kB wtrn, MB wtrn) written, and Blk_dscd (kB dscd, MB dscd) is the total number of blocks discarded for discarded.

r/s represents the number of requests completed (after merges) per second for the device. Two requests can be merged if they are contiguous, w/s is the number of write requests completed (after merges) per second for the device, d/s denotes the number of discard requests completed (after merges) per second for the device, and f/s is the number of disks (partitions are not considered) flush requests completed (after merges) per second of disks.

sec/(kB, MB/s) represents the number of sectors (kilobytes, megabytes) read from, written to, or discarded for the device per second. rsec/s (kB, MB/s) is the number of sectors read from the device per second. wsec/s (wkB, wMB/s) denotes the number of sectors written to the device per second, and dsec/s (dkB, dMB/s) denotes the number of sectors discarded for the device per second. rqm/s is the number of merged I/O requests queued or being served by the device per second. rrqm/s is the number of merged read requests queued or being served by the device per second, and wrqm/s denotes the number of write requests queued or being served by the device per second.
