# 92 Performance, Reliability, and Availability Evaluation of Computational Systems

**Figure 18.17** 2oo03 Block - KoON K = 2, N = 3.

Considering the 2oo03 system represented by the RBD in Figure 18.17.c, the structure function is

$\Phi(\mathbf{X}) = 1 - (1 - x_1x_2)(1 - x_1x_3)(1 - x_2x_3)(1 - x_1x_2x_3)$.

$\Phi(\mathbf{X}) = x_1^3x_2^3x_3^3 + x_1^3x_2^3x_3^2 + x_1^2x_2^3x_3^2 + x_1^3x_2^2x_3^2 +x_1^2x_2^2x_3^3 - x_1^2x_2^2x_3^2 - x_1x_2^3x_3^2 - x_1^3x_2x_3^2 - x_1x_2^2x_3^2 - x_1^2x_2x_3x1 + +x_1x_1x_2^2x_3 + x_1x_2x_3 + x_1x_3 + x_2x_3$.

As $x_i^k = x_i$, we get

$\Phi(\mathbf{X}) = x_1x_2 + x_1x_3 + x_2x_3 - 2x_1x_2x_3$.

As the system success probability ($P_S$ - availability, reliability) is $P_S = E(\Phi(\mathbf{X}))$, then

$P_S = E(x_1x_2 + x_1x_3 + x_2x_3 - 2x_1x_2x_3)$.

$P_S = E(x_1x_2) + E(x_1x_3) + E(x_2x_3) - E(2x_1x_2x_3)$.

If $x_1, x_2$, and $x_3$ are independent, then

$P_S = E(x_1)E(x_2) + E(x_1)E(x_3) + E(x_2)E(x_3) - 2E(x_1)E(x_2)E(x_3)$.

$P_S = p(x_1)p(x_2) + p(x_1)p(x_3) + p(x_2)p(x_3) - 2p(x_1)p(x_2)p(x_3)$.
