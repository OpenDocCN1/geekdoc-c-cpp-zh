# Dstat Tool

dstat is a general-purpose system monitoring tool written in Python that contains many functionalities provided by iostat, vmstat, netstat, and mpstat [110, 111]. dstat provides information organized in columns and better formatted than previous tools and commands. dstat output is designed for being displayed on the screen in real-time. The output may also be exported to a CSV output
