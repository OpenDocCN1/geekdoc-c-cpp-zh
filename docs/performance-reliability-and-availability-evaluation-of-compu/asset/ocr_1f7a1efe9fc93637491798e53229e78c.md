# Constant Scaling

In many practical cases, simple constant scaling factors represent the environment’s dynamics that affect the fault events for reasonable value ranges. Hence, as the time to failure of an event in stress conditions may be estimated from

```
$TTFs = TTFo \times CF$,
```

where $CF$ is constant, the cumulative distribution function is obtained from

```
$F_s(t) = F_o\left(\frac{t}{CF}\right). \quad (26.1.3)
```

As $f(t) = dF(t)/dt$, then

```
$f_s(t) = \frac{1}{CF} \times f_o\left(\frac{t}{CF}\right). \quad (26.1.4)
```

As the hazard function (see Equation 16.2.6)

```
$\lambda(t) = \frac{f(t)}{R(t)} = \frac{f(t)}{1 - F(t)}$,
```

then

```
$\lambda_s(t) = \frac{\frac{1}{CF} \times f_o(\frac{t}{CF})}{1 - F_o(\frac{t}{CF})}$,
```

Therefore

```
$\lambda_s(t) = \frac{1}{CF} \times \lambda_o(t). \quad (26.1.5)
```

Thus, applying transformation factor $CF$ (constant), the Equations 26.1.3, 26.1.4, and 26.1.5 do not change their respective shapes. On the other hand, if the scaling factor $(AF, CF)$ is not constant, the shape of the distribution $TTFs$ may change with relation to the shape of the distribution $TTF_o.$.
