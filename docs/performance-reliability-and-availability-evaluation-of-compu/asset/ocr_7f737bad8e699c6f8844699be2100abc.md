# 174 Performance, Reliability, and Availability Evaluation of Computational Systems

For each state that leads to $\Phi(X)=1$, we multiply the probability - (un)reliability or the (un) availability of each component. If the state of a component $j$ is $x_j=0$, we consider the unreliability or the unavailability $P(x_j=0)=1-E(x_j).$ On the other hand, if the state of a component $j$ is $x_j=1$, we consider the reliability or the availability $p_j=P(x_j=1)=E(x_j)$.

We are interested in the system reliability at $t$. If the components' reliabilities at $t$ are $r_{c3}(t)=0.96, r_{c2}(t)=0.93, r_{c1}(t)=0.92, r_{c0}(t)=0.95$, when considering the state $(0,0,1,1)$, we have $ur_{c3}(t) 	imes ur_{c2}(t) 	imes r_{c1}(t) 	imes r_{c0}(t)=0.04 	imes 0.07 	imes 0.92 	imes 0.95=0.00245$ (see Table 20.2). Similarly, when considering the state $(0,1,1,1)$, we have $ur_{c3}(t) 	imes r_{c2}(t) 	imes r_{c1}(t) 	imes r_{c0}(t)=0.04 	imes 0.97 	imes 0.92 	imes 0.95=0.03251$. Summing the probabilities related to the other states are shown in Table 20.2. Summing the probabilities of the column $P(X)$, we have 0.94185.

**20.2.1.** A system is composed of two servers ($S_1$ and $S_2$), each with its network-attached storage device ($NAS_1$ and $NAS_2$). Figure 20.2.a shows this system. A system failure occurs when both servers their respective storage device fail. More formally, a failure is specified by

> $\Psi(B) = (\overline{s}_1 \vee \overline{nas}_1) \wedge (\overline{s}_2 \vee \overline{nas}_2)$

where $s_1, s_2, nas_1$, and $nas_2$ are Boolean variables, if evaluated as true a component failure; otherwise the component is operational. $B=(\overline{s}_1, \overline{s}_2, \overline{nas}_1, \overline{nas}_2)$ is Boolean vector.

Figure 20.2.b shows an FT that represents the system failure. Table 20.3 enumerates all states of the system and shows the respective evaluation of $\Psi(B)$ and $1-\Phi(X)$. In this table, $F$ implies the system is operational and $T$ represents a failure. Function $1-\Phi(X)$ can be obtained from $\Psi(B)$ by applying the rules shown in Table 18.3. It is worth noting that the basic events $\overline{s}_1, \overline{nas}_1, \overline{s}_2$, and $\overline{nas}_2$ denote the respective component failure.
