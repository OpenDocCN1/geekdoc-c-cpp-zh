# 20.4 REDUCTIONS

This section presents a set of Transformations that allows calculating the system probability (reliability or availability) by computing the respective probability of its subsystems and combining the individual results. The basic idea consists of calculating the probabilities of system components, then transforming the subsystems into single components, and adopting a procedure until the system is represented by one single component. Now, let us introduce a few reduction rules to support the evaluation process.

**Series Reduction** - Consider a series system represented by a RBD with $n$ components, $C_i=\{1, 2,...,n\}$.
