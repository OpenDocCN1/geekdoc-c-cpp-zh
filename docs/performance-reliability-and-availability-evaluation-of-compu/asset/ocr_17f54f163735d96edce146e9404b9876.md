It is worth noting that the first field in the command line specifies the minutes (00); the second field determines the hour (02); the third, fourth and fifth represent the day, month, and day of the week, respectively. The symbol * denotes any value. Instance, if the day has *, it defines that the command should be executed every day. In this particular case, the script /bin/tcpdumpscript.sh should be run every day, week at 02:00 AM.

# Algorithm 18 This script collects one hour of network traffic any interface of a computer. - Exercise 33

```
#!/bin/bash
/usr/bin/tcpdump -i any -w /tmp/any.pcap 2>&1 & 
PROCESS_ID=$!
sleep 3600
kill -15 $PROCESS_ID
if [ -f /tmp/any.pcap ]; then
tar -cvf /tmp/any.pcap.tar.gz /tmp/any.pcap
rm /tmp/any.pcap
fi
```

After collecting the traffic, uncompress the file any.pcap.tar.gz, and read it using the command tcpdump -r any.pcap.
