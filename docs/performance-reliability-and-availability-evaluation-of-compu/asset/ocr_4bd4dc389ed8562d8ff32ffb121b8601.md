# Modeling Availability, Reliability, and Capacity with CTMC

Now, consider the absorbing CTMC depicted in Figure 21.7.a. This CTMC is the reliability model of the system shown in Figure 21.4. State 2 denotes the system with two servers in operational condition, whereas state 1 represents the system with only one operational server. State 0 depicts a system with no operational server. In state 2 two servers are available; the transition rate from state 2 to 1 is $\lambda$. In state 1, the failed server may be repaired, which may fail, which takes the system back to state 2. The repair rate is $\mu$. In state 1, the second server may also fail, which takes the system to state 0, representing the system failure. The CTMC rate matrix is

```
$Q = egin{pmatrix} -2\lambda & 2\lambda & 0 \ \mu & -\lambda-\mu & \lambda \ 0 & 0 & 0 \end{pmatrix}$
```

![](bbox=[0.121, 0.355, 0.879, 0.676])

The reliability at $t$ is obtained by

$R(t) = 1 - \pi_0(t)$.

The mean time to failure can be calculated from

$MTTF = \int_{0}^{\infty} R(t) dt = \int_{0}^{\infty} (1 - \pi_0(t)) dt$.
