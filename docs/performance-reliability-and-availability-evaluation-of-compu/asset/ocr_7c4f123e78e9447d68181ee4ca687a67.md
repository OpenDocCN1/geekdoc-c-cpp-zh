```
printf "Linpack Results \n\" >> Linpack_result.txt;
for i in {1..100}
do
  Linpack >> Linpack_result.txt;
done
```

such that Linpack_result.txt is the file where the execution times and the float-point instructions per each of each execution was stored. This experiment was executed in a small Linux virtual machine deployed as a guest on a personal computer. The general format of the Linpack.result.txt text file is
