As $\hat{F}(t) = 1 - R(t)$, the failure time cumulative distribution function is estimated by

$$\hat{F}(t_i) = \frac{n - n_i}{n}; \quad (25.2.18)$

$n - n_i$ is the number of devices that has failed by $t_i$. Likewise, an estimate of the probability density function at $t_i$ is calculated by

$$\hat{f}(t_i) = \frac{\hat{F}(t_{i+1}) - \hat{F}(t_i)}{t_{i+1} - t_i} = \frac{\hat{R}(t_i) - \hat{R}(t_{i+1})}{t_{i+1} - t_i}\\n\hat{f}(t_i) = \frac{\frac{n_i}{n} - \frac{n_{i+1}}{n}}{t_{i+1} - t_i}\\n\hat{f}(t_i) = \frac{\frac{n_i - n_{i+1}}{n(t_{i+1} - t_i)}} \quad (25.2.19)$

Since $\hat{\lambda}(t_i) = \hat{f}(t_i)/\hat{R}(t_i)$, we get

$$\hat{\lambda}(t_i) = \frac{\frac{n_i - n_{i+1}}{n(t_{i+1} - t_i)}}{\frac{n_i}{n}} \quad (25.2.20)$

The mean time to failure can be estimated by

$$\MTTF = \frac{\sum_{i=0}^k t_i (n_i - n_{i+1})}{n}} \quad (25.2.21)$

$\bar{t}_i = (t_i + t_{i+1})/2, n_0 = n$, and $t_0 = 0$. The confidence interval for the MTTF can be estimated using nonparametric bootstrap (see Section 6.5) through the failure observed, so for each time the interval sample contains $(n_i - n_{i+1})$ equal $TTFs_i$, where $TTF_i = t_i(n_i - n_{i+1}), i \in \{0, 1, 2, \dots, k-1\}$.

A linear interpolation, as adopted in the previous section, may be used to estimate $\hat{R}(t_j)$ and $\hat{F}(t_j)$ at $t_j$, for $t_{i-1} < t_j < t_i, i \in \{1, 2, \dots, k\}$. Other interpolation methods may be applied.
