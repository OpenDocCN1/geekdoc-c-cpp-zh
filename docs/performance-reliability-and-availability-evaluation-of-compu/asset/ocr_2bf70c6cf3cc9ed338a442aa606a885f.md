# Command ss

The command `ss` is a tool used to dump sockets, `TCP UDP, DCCP, RAW, Unix domain sockets`, and the respective statistics what is provided by `netstat`. The standard syntax of the command is "ss options filter". Some of the important options supported by this command are depicted below. For a detailed view of all options, refer to `man ss`.

+   - -n does not resolve service names.
- -r tries to resolve numeric addresses/
- -a displays both listening and non-listening sockets.
- -l displays only listening sockets.
- -o shows timer information.
- -e shows detailed socket information.
- -m shows socket memory usage.
- -p shows process using socket.
- -i shows internal TCP information.
- -s prints summary statistics.
- -b shows socket BPF14 (It is allowed only for administrators).
- -4 displays only ipv4 sockets.
- -6 displays only ipv6 sockets.
- -0 displays packet sockets.
- -t displays TCP sockets.
- -u displays UDP sockets.
- -d displays DCCP sockets.
- -x displays Unix domain sockets.
- -f displays sockets of type family: unix, inet (ipv4, ipv6), netlink.

If the command `ss` without options is executed, it shows information about all TCP, UDP, and Unix socket connections regardless of the state they are. The command `ss -a` retrieves a list of both listening and non-listening ports.
