# Modeling Availability, Reliability, and Capacity with CTMC

The reliability mode is equal to the CTMC depicted in Figure 21.7.a. Hence, the reliability at $t$ is obtained

```
$R(t) = 1 - \pi_0(t),$
```

and the mean time to failure can be calculated from

```
$MTTF = \int_0^{\infty} R(t)dt = \int_0^{\infty}(1 - \pi_0(t))dt$
```

or using the method based on moments described in Section 10.6.1, which leads to

```
$MTTF = \frac{(\lambda + \mu)(4\lambda + \mu)}{2\lambda^2(2\lambda + \mu)}$
```
