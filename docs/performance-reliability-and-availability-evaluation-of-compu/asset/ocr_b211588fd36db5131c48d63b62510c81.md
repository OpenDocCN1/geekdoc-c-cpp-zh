# Bernoulli Distribution

Assume X is a random variable distributed according to a Bernoulli distribution with parameters $p$. As the Bernoulli distribution has only one moment, the origin is $\mu_1 = p$, and the sample first moment is given by $(\sum_{\text{\textasci}i=1}^n x_i)/n$, where $n$ is the sample size. Hence

```
$$\hat{p} = \frac{\sum_{\text{\textasci}i=1}^n x_i}{n} \quad (25.3.8)$
```

**Example 25.3.4.** A test was carried out in one hundred similar and independent devices. After the test, each device is either in an operational state ($x_i =1$) or in failure ($x_i = 0$). This sort of random experiment with two results is represented by a Bernoulli distribution. Table 25.16 shows the test results for each device i. Applying Equation 25.3.8, we get $\hat{p} = (\sum_{\text{\textasci}i=1}^{50} x_i)/50 = 44/50 = 0.88$.
