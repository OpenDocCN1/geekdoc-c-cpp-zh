The request time is $\lambda$ and $\mu$ depending on which state the workload simulator is. If the simulator is on *one*, the rate is $\lambda$. The sojourn time in states *one* is specified by $Exp(\beta)$. When a transaction type $tr_1$ is generated, the number of bytes transferred (bt) to the computer system is $N(2000, 500)$ (Normal distribution. $N(m, \sigma)$, $m$ is mean and $\sigma$ is the standard deviation). It is a cumulative time that starts at $gt=0$ and is incremented by the winning event (shortest event) assigned to $ta = F_\alpha^{-1}$ and $tb = F_\lambda^{-1}$ or $tb = F_\beta^{-1}$ and $tm = F_\mu^{-1}$.
