# Command mpstat

The mpstat command provides measures for each available processor as well as global average measures among all processors. The basic syntax of this command is mpstat [options] [delay] [count], where [delay] and [count] are specified as we have defined for vmstat and the main options are.

+   - V - Print version number then exit.
- -I keyword [...] — ALL - Possible keywords are CPU, SCPU, SUM. CPU reports the number of each individual interruption received per second by the processor or processors (sec/interrupts). SCPU reports the number of each individual software interrupt received per second by the processor or processors. SUM reports the total number of interrupts per processor. ALL keyword is equivalent to specifying all the keywords above.
- -P cpu [...] — ON - cpu is the processor number for which statistics are to be reported. Report 0 is the first report. ON indicates the report is for online processors. ALL indicates the report is for all processors.
- -A - This option is equivalent to specifying -u I - ALL

Executing the command "mpstat -P cpu dbs ns > output" generates the processor report log file (output) with ns samples with intervals between each sample of dbs seconds. For an example, consider "mpstat -P 0 5 > output". In this case, a report of processor 0 is generated.
