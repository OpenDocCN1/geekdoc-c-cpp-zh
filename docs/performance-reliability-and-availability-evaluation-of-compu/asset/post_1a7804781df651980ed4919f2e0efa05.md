The normalized reliability importance of a component can be weighed by the relative cost of that component in a system - **Reliability-Cost Importance**. Such weights allow the analyst to ponder not only the reliability importance of a component to the system’s reliability but also the financial aspect when designing a system [140]. This measure is obtained by

```
$NI_{i}^{CB} = NI_{i}^{B} \times (1 - \frac{c_i}{c_{sys}}),$
```

where $c_i$ is the cost of component $i$ and $c_{sys} = \sum_{ij} c_i$ is the system cost.

Similarly, the normalized reliability importance of a component can be weighed by the relative cost of that component in a system - **Availability-Cost Importance**. This measure may be represented by

```
$NI_{i}^{CA} = NI_{i}^{A} \times (1 - \frac{c_i}{c_{sys}})$,
```

Assume a system composed of $n$ components. In some cases, we may be interested in measuring how much the system reliability is affected by many changes in a parameter $p_i$. The system **reliability sensitivity** can be measured by

> $S_{p_i}^R = \frac{\partial R(t)}{\partial p_i} \quad (18.9.9)$
