**Example 20.3.1.** Let us study another system in which factoring helps the system probability. Consider the RBD shown in Figure 20.3. This RBD is more complex than simple series-parallel structures. Particular attention is needed to compound $C_2$ and $C_3$. These two components are bidirectional (see the bridge structure in Section 18.5). Let us first define the structure variables of each component $C_i$ by $x_i$, $i \in \{1, 2, 3, 4, 5, 6\}$.

**Figure 20.3** Non-Series-Parallel RBD.

The RBD shown in Figure 20.3 can be factored into two RBDs by, instance, first conditioning on the states of $C_2$. If $x_2 = 1$, the RBD depicted in Figure 20.3 is transformed into the RBD shown in Figure 20.4.a. On the other hand, if $x_2 = 0$, the RBD presented in Figure 20.3 is represented by the RBD depicted in Figure 20.4.b. The system function can, thus, be represented

$$\Phi(X) = x_2 \times \Phi(1_2, X) + (1 - x_2) \times \Phi(0_2, X)$$

The RBD shown in Figure 20.4.a is a simple series-parallel structure. The RBD shown in Figure 20.4.b, components $C_5$ and $C_6$ are in series; the probability of these two components is

$$\Phi(x_5, x_6) = p_5 \times p_6$$

Therefore,

$$\Phi(1_2, X) = (1 - (1 - p_1)(1 - p_5)) \times (1 - (1 - p_4)) \times (1 - (1 - p_3)(1 - p_6))$$

$$\Phi(0_2, X) = (1 - (1 - p_1)(1 - p_{56})) \times (1 - (1 - p_4)) \times (1 - (1 - p_3)(1 - p_6))$$

Consider $C_5$ and $C_6$ as one component ($C_{56}$) with probability $p_{56} = p_5 \times p_6$. Thus, the RBD depicted in Figure 20.4 is represented by a bridge structure. Using the solution presented in Section 18.5 for the bridge structure, we obtain

$$P(\Phi(X) = 1) = p_2 \times \Phi(1_2, X) + (1 - p_2) \times \Phi(0_2, X)$$

$$\Phi(1_2, X) = p_3 \times (1 - p_1) \times (1 - p_{56}) \times (1 - p_3) \times P(\Phi(02,3, X) = 1)$$

$$\Phi(0_2, X) = (1 - (1 - p_1)(1 - p_{56})) \times (1 - (1 - p_4)) \times (1 - (1 - p_3)(1 - p_6))$$

$$P(\Phi(02,3, X) = 1) = (1 - (1 - p_1p_4) \times (1 - p_5p_6p_7))$$

# Performance, Reliability, and Availability Evaluation of Systems

Many strategies can be adopted to reduce the system model to calculate its probability. First, one possibility is decomposing the original system model into modules (subsystems) and then applying the reduction to each module. As one extreme case, the modules can be represented by individual components. In the other extreme case, however, the system is decomposed into independent modules between these extremes. Another possibility is applying a possible reduction to a set of components, obtaining a resulting system model, and then continuing possible reductions until either a single component or a system specification to which a solution is already known.
