Now, let us consider an experiment in which $n$ devices are observed for a period of $T$ (Right-Censoring Type 1), but the devices may also be taken before the observation period and without failing (Left Censoring). The number of devices that failed during the observation is $r$; the number of devices that were still operating at the end of the observation period $(T)$ is $rc$ devices. The number of devices that were censored before the observation period is $lc$. Therefore, the total number of censored devices is $(rc+lc)$. In such a case, we are dealing with the multiplied reliability data. Therefore Equation 25.3.35 and Equation 25.3.36 may be adapted to estimate the distribution parameter:

$$\lambda = \frac{r}{\sum_{i=1}^{r} t_i + \sum_{j=1}^{lc} t_j + rc \times T}. \quad (25.3.39)$$

where $t_i$ is a time to failure, and $t_j$ is a left-censoring time. Thus, the estimate of the mean time to failure is

$$\overline{MTTF} = \frac{\sum_{i=1}^{r} t_i + \sum_{j=1}^{lc} t_j + rc \times T}{r}. \quad (25.3.40)$$

**Example 25.3.15.** Consider once again that sixty servers ($n=60$) were observed for a period $T=8000h$. The times to failure are assumed to be independent and identically distributed according to an exponential distribution. At the end of the observation period $(T)$, $r=49$ servers have failed, and seven were left-censored $(lc=7)-\delta=0$, that is, taken before presenting any failure. After the observation period, $rc=4$ servers were still operating (right-censoring). Thus, $(rc+lc)=11$ servers were censored. [Table 25.24](#) shows the times to failure $(\delta=1)$ of the forty-two servers failed and all that were censored.
Hence, as $r=49, \sum_{j=1}^{lc} t_j=16904.44h$ and $rc \times T=32000.00$.

$$\lambda = \frac{r}{\sum_{i=1}^{r} t_i + \sum_{j=1}^{lc} t_j + rc \times T} = \frac{49}{16904.44+32000.00} = 5.04 \times 10^{-4}h^{-1},$$

and

$$\overline{MTTF} = \frac{\sum_{i=1}^{r} t_i + \sum_{j=1}^{lc} t_j + rc \times T}{r} = \frac{1}{\lambda} = 1985.52h.$$

## Estimating Confidence Interval for Distribution Parameters Using Semi-Parametric

The previous sections presented three approaches for distribution point estimation. A reasonably general strategy can be adopted for estimating distribution confidence interval by adopting semi-parametric methods introduced in Section 6.3. The general steps of this strategy are shown in Method 22.

### Algorithm 22 Distribution Parameters' Confidence Interval on Semi-Parametric Bootstrap

- 1. Obtain a sample of $n$ independent measures from population distributed according to $F(t,\theta)$ ($f(t, \theta)$ - density function or $p(t, \theta)$ - probability mass function), $\theta = \{\theta_1, \theta_2, \dots, \theta_n\}$, where the values are unknown.
- 2. Obtain the distribution parameters point estimation, $\hat{\theta} = \{\hat{\theta}_1, \hat{\theta}_2, \dots, \hat{\theta}_n\}$, using one of the parametric methods introduced in this chapter.
- 3. Generate random variables using the distribution estimates, $\hat{\theta} = \{\hat{\theta}_1, \hat{\theta}_2, \dots, \hat{\theta}_n\}$, obtained in step 2, to generate resample of size $n$.
- 4. For each resample, calculate distribution parameters point estimates, $\hat{\theta}^l = \{\hat{\theta}_1^l, \hat{\theta}_2^l, \dots, \hat{\theta}_n^l\}$, using the same method adopted in step 2.
- 5. Repeat steps 3 and 4 times. a "big" number (say $m=100$ or $1000$).
- 6. For each $\theta_i$, sort the point estimates obtained in resamples, $\{\hat{\theta}_i^1, \hat{\theta}_i^2, \dots, \hat{\theta}_i^m\}$, in ascending order.
- 7. Considering the degree of confidence, $(1-\alpha)$, for each parameter $\theta_i$, determine the parameters $\alpha/2 \times 100\%$ and $(1-\alpha)/2 \times 100\%$. These values are the lower and upper limits of the parameter $\theta_i$ confidence interval.

### Algorithm 23 Gamma Distribution Parameters’ Confidence Interval on Semi-Parametric Bootstrap

```
1: nors = 1000, ss=100;
2: $\alpha = 0.1$;
3: $\gamma = 7.08$, $\hat{\beta} = 304.99$;
4: palest = { $\gamma$, $\hat{\beta}$ }. Table[FindDistributionParameters[RandomVariate[GammaDistribution[$\gamma$, $\hat{\beta}$], GammaDistribution[$\gamma$, $\beta$], ParameterEstimator->MethodOfMoments], nors];
5: Print("degree of confidence =", N[1-\alpha] - $\gamma$ $\in$, Quantile[$\gamma$, {$\alpha/2$, (1 - ($\alpha/2$))]);
6: Print("degree of confidence =", N[1-\alpha] - $\beta$ $\in$, Quantile[$\beta$, {$\alpha/2$, (1 - ($\alpha/2$))]);
```

resample., the number of resampled samples is specified in `nors`. The command $\{\gamma, \beta\}$ removes the symbols $\gamma$ and $\beta$ from the last `palest`. `palest[[All,1], $\alpha/2$, (1 - ($\alpha/2$))]` and `Quantile[[All, 2]]` find the quantile $\alpha/2$ and $1-\alpha/2$ for $\gamma$ and $\beta$, where $\alpha$ is the degree of significance.

Executing this Mathematica code an interval was generated for the distribution parameters. The confidence intervals obtained were $\gamma \in (5.6, 9.2)$ and $\beta \in (233.5h, 386.96h)$ with 90% degree of confidence.
