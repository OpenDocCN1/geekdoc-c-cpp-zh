The input/output device utilization report provides statistics on a physical device or partition. Block devices and partitions may be entered on the command line. If none is specified, the statistics for every device are displayed. Transfer rates are depicted in 1K blocks (default) for 512-byte blocks. The input/output device report displays the header followed by a row of input/output device statistics. The report may show the following items, depending on the options:
