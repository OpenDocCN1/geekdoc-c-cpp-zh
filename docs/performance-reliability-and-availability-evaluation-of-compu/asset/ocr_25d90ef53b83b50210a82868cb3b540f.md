**Exercise 13.** Adopt your programming language of choice and implement the workload- simulator specified by the model depicted in Figure 24.37, which represents a Markov Modulated Process. This process sends requests whose time of transactions, $tbt$, are specified by $Exp(\mu)$ (transaction time $tr_1$) and $Exp(\lambda)$ (transaction type $tr_2$). Request the request time is $\lambda$ and $\mu$ depending on which state the workload simulator is. If the simulator is on *one*, the rate is $\lambda$. The sojourn time in states *one* is specified by $Exp(eta)$. When a transaction type $tr_1$ is generated, the number of bytes transferred (bt) to the computer system is $N(2000, 500)$ (Normal distribution. $N(m, \sigma)$, $m$ is mean and $\sigma$ is the standard deviation). Similarly, when a transaction type $tr_2$ is submitted, the number of bytes transferred to the computer system is $W(2, 2000)$ (Weibull distribution. $W(s, f)$, $s$ is the shape parameter, and $f$ is the form parameter). Assume $\alpha = 2tps$, $eta = 8tps$, $\lambda = 500tps$, and $\mu = 700tps^9$. The simulator generates time of time-ordered event, where each event is represented by a record. A record is specified by a tuple $(i, tr, gt, bt, tr)$, where $i$ denotes the transaction instance, $tr$ is a first transaction, second, third..., $tr=1$ and $tr=2$, $gt$ denotes the global timeatat registered during the record generation. It is a cumulative time that starts at $gt=0$ and is incremented by the winning event (shortest event) assigned to $ta = F_\alpha^{-1}$ and $tb = F_\lambda^{-1}$ or $tb = F_eta^{-1}$ and $tm = F_\mu^{-1}$. The variable $bg$ is the number of bytes transferred in each transaction$^{10}$.
