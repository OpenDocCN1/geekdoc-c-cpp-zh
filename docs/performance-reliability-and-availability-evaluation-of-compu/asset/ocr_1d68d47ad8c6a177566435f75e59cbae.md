**Example 18.9.3.** The RBD depicted in Figure 18.29.b is composed of three blocks in parallel. The system reliability is $R_s(t) = 1 - ((1 - R_1(t)) \times (1 - R_2(t)) \times (1 - R_3(t)))$.

The reliability importance of each component

```
$I_1^B = \frac{\partial R_s(t)}{\partial R_1(t)} = (1 - R_2(t))(1 - R_3(t)).
```

```
$I_2^B = \frac{\partial R_s(t)}{\partial R_2(t)} = (1 - R_1(t))(1 - R_3(t)).
```

```
$I_3^B = \frac{\partial R_s(t)}{\partial R_3(t)} = (1 - R_1(t))(1 - R_3(t)).
```

Considering the reliability of blocks $b_1, b_2$ and $b_3$ at $R_1(t) = 0.95, R_2(t) = 0.93,$ and $R_3(t) = 0.9,$ the reliability importance of each component is $I_1^B = 0.007, I_2^B = 0.005,$ and $I_3^B = 0.0035$. Hence, in parallel structures, the most reliable component is the one that is most important with respect to the reliability importance. This result confirms the intuition, since in parallel structures, the system will only fail when all components fail, that is even when the most reliable component fails. A parallel system is as weak as its strongest component.
