# Bernoulli Distribution

Assume X is a random variable distributed according to a Bernoulli distribution with parameters $p$. As the Bernoulli distribution has only one moment, the origin is $\mu_1 = p$, and the sample first moment is given by $(\sum_{i=1}^n x_i)/n$, where $n$ is the sample size. Hence

$$\hat{p} = \frac{\sum_{i=1}^n x_i}{n} \quad (25.3.8)$$

**Example 25.3.4.** A test was carried out in one hundred similar and independent devices. After the test, each device is either in an operational state ($x_i = 1$) or in failure ($x_i = 0$). This sort of random experiment with two results is represented by a Bernoulli distribution. Table 25.16 shows the test results for each device $i$. Applying Equation 25.3.8, we get $\hat{p} = (\sum_{i=1}^{50} x_i)/50 = 44/50 = 0.88$.

Assume T is a normally distributed random variable with parameters $\mu$ and $\sigma$ that specify the time to failure of a class of computers. Assume a sample of size $n$ was collected from a population distributed according to T. The first two moments could be derived from the moment generating function: $M_T(t) = e^{\mu t + \frac{\1}{2}\sigma^2 t^2}. \quad (25.3.9)$

Taking the first derivative of $M_T(t)$ in relation to $t$, we obtain

$$\frac{dM_T(t)}{dt} = (\mu + \sigma^2 t)e^{\mu t + \frac{1}{2}\sigma^2 t^2}$$

then for $t = 0$, we get $\mu_1 = \mu$. Now calculating the second derivative of $M_T(t)$ for $t$, we obtain

$$\frac{d^2M_T(t)}{dt^2} = [\sigma^2 + (\mu + \sigma^2 t)^2]e^{\mu t + \frac{1}{2}\sigma^2 t^2}$$

then for $t = 0$, we get $\mu_2 = \sigma^2 + \mu^2$. Now consider the first two moments about the origin

$$m_1 = \frac{\sum_{i=1}^n x_i}{n}$$

and

$$m_2 = \frac{\sum_{i=1}^n x_i^2}{n}$$

Since $\mu_1 = \mu$ and $\mu_2 = \sigma^2 + \mu^2$, we obtain $\hat{\mu} = m_1$ and $\hat{\sigma} = \sqrt{m_2 - \hat{\mu}^2}$.
