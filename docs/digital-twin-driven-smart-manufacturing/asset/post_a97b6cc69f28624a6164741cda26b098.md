## 9.3 LIFECYCLE OF BIG DATA IN MANUFACTURING

The study about “lifecycle of big data in manufacturing” has been explored in the authors’ previous work [31]. Details in the study are introduced in this section. Data is a key enabler for smart manufacturing. However, data is not useful unless it is “translated” into concrete information content and context that can be directly understood by users [29]. Generally, the data needs to pass through multiple steps before concrete information can be obtained from it. The complete journey of data collection, transmission, storage, preprocessing, filtering, analysis, mining, visualization, and application can be referred to as the “data lifecycle” [30]. Manufacturing data is exploited at various points in the data lifecycle. As illustrated in Fig. 9.3, a typical manufacturing data lifecycle consists of data collection, transmission, storage, processing, visualization, and application [31].

### 9.3.1 Data Sources

In manufacturing, big data refers to the data generated from the product lifecycle, such as design, manufacturing, PHM, etc. [24], which are also featured with high volume, variety, velocity, variability, and value. Manufacturing data usually include the following aspects [31], as shown in Fig. 9.3.

- 1. Manufacturing site data, including (a) equipment data collected from smart factories using Industrial IoT technologies, with respect to the real-time performance, operating conditions, etc.; (b) material and product data collected from themselves and service systems, such as performance, inventory, context of use, etc.; and (c) environmental data (e.g., temperature, humidity, air quality, etc.).
- 2. Management data from manufacturing information systems and computer-aided systems, including the data generated from the design scheme, order dispatch, material distribution, production planning, marketing and sales, service management, finance, and so forth.
