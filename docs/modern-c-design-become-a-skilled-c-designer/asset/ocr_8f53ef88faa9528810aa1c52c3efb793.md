What lambdas do provide, however, is a compelling, concise syntax for the declaration of inline, anonymous functions. two very common use cases for lambdas are as predicates for stL algorithms and targets for C++11 asynchronous tasks. some have even argued that the lambda syntax is so compelling that there is no longer a need to write for loops in high-level code since they can be replaced with a lambda and an algorithm. personally, i find this point of view too extreme.

i n the alternative design to binary commands, you saw yet another use for lambdas. they can be stored in objects and then called on demand to provide different options for implementing algorithms. in some respects, this paradigm encodes a micro-application of the strategy pattern. to avoid confusion with the command pattern, i specifically did not introduce the strategy pattern in the main text. the interested reader is referred to Gamma et al [6] for details.
