# Figure 5-1. A minimal interface hierarchy

Referring to Table 2-2 in Chapter 2, you see that the complete interface for the UserInterface class consists of two event handling functions, postMessage() and stackChanged(), and oneUserInterface raised event,commandEntered(). Interestingly, theUserInterface class is a publisher, an observer, and an abstract user interface.

The two event handling functions, postMessage() andstackChanged(), are straightforward at the interface level. As we have done with previous observers, we will simply add these two functions to the public interface of theUserInterface class and create proxy observer classes to broker the communication by the publisher and the actual observer.
