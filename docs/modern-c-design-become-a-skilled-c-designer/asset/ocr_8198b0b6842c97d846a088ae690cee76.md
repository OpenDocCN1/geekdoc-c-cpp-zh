# Module Design for pdCalc

I chose to use implicit hiding in the design of pdCalc. For this project, I felt that the benefits of simplicity outweighed the complications necessary to use one of the other modes of module interface hiding. Which technique you choose for your own projects will naturally reduce to your personal preferences. Given the relatively small code base of pdCalc, the choice to use implicit hiding enables grouping classes by logic rather than along module boundaries. Furthermore, implicit hiding allows lumping several of the modules (e.g., command dispatcher, stack, and plugin management) into on e shared, back-end library.
