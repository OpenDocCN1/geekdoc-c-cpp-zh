Recall, however, that this error is generated in the CommandDispatcher, not in the tokenizer. Therefore, we need to modify the CommandDispatcher to not reject strings but instead to somehow place them on the stack. For now, we’ll assume that the stack can accept strings in addition to numbers. I’ll discuss the necessary modifications to the Stack class in the upcoming sections. Again, I’ll restrict our discussion to the command line interface. The only additional complication posed by the graphical user interface is providing a mechanism to input character strings in addition to numbers (perhaps a virtual keyboard to accompany the virtual numeric keypad).

Technically, we could allow any string to represent a variable. However, we are probably better served by restricting the allowable syntax to some subset of strings, possibly delimited by a symbol to differentiate variable names from commands.
