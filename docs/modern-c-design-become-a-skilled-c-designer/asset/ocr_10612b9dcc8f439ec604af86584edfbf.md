The above problem can be solved without object-oriented programming via function pointers and callbacks, albeit in a somewhat inelegant and cumbersome fashion. However, with the rise of object-oriented programming, specifically inheritance and polymorphism, the solution to the dependency problem was solved in a type-safe manner with language support. These techniques enabled the popularization of source code dependency inversion. Specifically, source code dependency inversion states that the main program defines an interface (e.g., the plugin interface we’ve studied in this chapter) to which all extensions must conform. Under this strategy, the extensions become subservient to the main program’s interface rather than the reverse. Hence, the main program can be extended via plugins without modifying, recompiling, or relinking the main program’s source code.
