Because we only need one LookAndFeel object in the calculator, the class is implemented as a singleton. A great question to ask is, “Why do we need this class at all?” The answer is that it gives us the opportunity to dynamically modify the appearance of the calculator based on the current environment, and it centralizes in memory access to the look-and-feel of pdCalc.
