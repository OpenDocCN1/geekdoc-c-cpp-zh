Therefore, we must add and implement this new function. In all likelihood, a modular implementation of the GUI would have already had a similar function somewhere in the GUI module, as this functionality was already required to create buttons for core commands. Therefore, implementation of theaddCommandButton() function might be as trivial as forwarding this call from the MainWindow to the appropriate internal GUI class, where the function may have already existed.
