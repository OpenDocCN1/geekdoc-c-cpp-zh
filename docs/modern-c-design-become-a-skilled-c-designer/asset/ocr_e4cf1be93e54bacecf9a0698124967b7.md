Since thedetach() method returns the observer in a unique_ptr, the publisher clearly relinquishes ownership of the observer’s memory by transferring it back to the caller.

The above implementation of the observer pattern explicitly enforces a design where the publisher owns its observers. The most natural way to use this implementation involves creating small, dedicated, intermediaryObserver classes that themselves hold pointers or references to the actual classes that should respond to an event. For example, from Chapter 2, we know that pdCalc’s user interface is an observer of theStack class.
