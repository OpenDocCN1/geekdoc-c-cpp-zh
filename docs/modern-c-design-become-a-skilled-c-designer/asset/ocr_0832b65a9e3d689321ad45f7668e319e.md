That is, in a typical UNIX or Linux system, no need exists to decorate symbols as an export or an import in shared library code because all symbols in a shared library are made publicly available to the calling program by the linker when the shared library is loaded. Compiler command line options can reverse the default visibility from public to private, if so desired, and symbols can be marked manually for either import or export analogously to a Windows build.
