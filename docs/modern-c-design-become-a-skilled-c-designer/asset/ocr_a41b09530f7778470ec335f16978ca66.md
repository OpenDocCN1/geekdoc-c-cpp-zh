# The guiTest Directory

It is difficult, in general, to test graphical user interfaces automatically. Only the Display class within the GUI is automatically tested in pdCalc’s unit tests. The two source files for testing the Display class,DisplayTest.h andDisplayTest.cpp, are found in the guiTestdirectory.

# The pluginsTest Directory

The pluginsTest directory contains the source files for testing the single plugin included with pdCalc, the hyperbolic functions and natural logarithm plugin. These tests are contained in the following two source files:HyperbolicLnPluginTest.h and HyperbolicLnPluginTest.cpp.
