Now, as an example, instead of declaring a Multiply class and instantiating a Multiplyobject, like
auto mult = new Multiply;
we create a BinaryCommandAlternative capable of multiplication, as in
auto mult = new
BinaryCommandAlternative{ "help msg", []
(double d, double f){ return d * f; } };

For completeness, I mention that because no classes further derive from BinaryCommandAlternative, we must handle help messages directly in the constructor rather than in a derived class. Additionally, as implemented, BinaryCommandAlternative only handles the binary precondition.
