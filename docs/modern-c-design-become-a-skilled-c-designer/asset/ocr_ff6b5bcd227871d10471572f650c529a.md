For completeness, I show the final user interface hierarchy in Figure 5-2. The class diagram illustrates the relationship between the CLI, the GUI, the abstract UserInterfaceclass, and the publisher interface. Remember that the inheritance between theUserInterface class and thePublisher class is protected, so a UserInterface (or subsequent derived class) cannot be used as a Publisher. As previously stated, however, the intent for the inheritances between the concrete CLI and GUI classes and the abstract UserInterface class are public, allowing an instantiation of either concrete type to be substituted as a UserInterface.
