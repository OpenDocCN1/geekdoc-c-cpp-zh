where u,v,w,v_, andm_ are now all part of classAImpl, which is both declared and defined only in the implementation file associated with classA. To ensureAImpl cannot be accessed by any other classes, we declare this implementation class to be a private class wholly defined withinA. Sutter and Alexandrescu [27] give a brief explanation of the advantages of the pimpl idiom. One of the main advantages is that by moving the private interface of classA fromA.h toA.cpp, we no longer need to recompile any code consuming classA when onlyA’s private interface changes. For large-scale software projects, the time savings during compilation can be significant.
