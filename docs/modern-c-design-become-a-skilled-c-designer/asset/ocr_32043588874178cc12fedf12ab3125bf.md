Therefore, plugin classes should not inherit from main application classes that have member variables defined in the base classes if these member variables are used in the main application. This follows since the main application’s compiler may use a different memory offset to a member variable than what was defined by the plugin’s compiler if each compiler uses different alignment. Fourth, due to name mangling variances across different compilers, exported interfaces must specify `extern "C"` linkage. The linkage requirement is bidirectional. Plugins should not call application functions without `extern "C"` linkage, nor should the application call plugin functions without `extern "C"` linkage.
