In general, the required implementation changes are straightforward. Uses of double are replaced with T, and the implementation itself is moved to the header file. Uses of the Stack class within pdCalc obviously must be refactored to use the generic rather than the non-templated interface.

The last part of the interface that requires modification is the five global extern "C" helper functions added in Chapter 7 for exporting stack commands to plugins. Because these functions must have C linkage, we cannot make them templates nor can they return the C++ complex type in place of a double. The first problem is not quite as dire as it may appear at first glance. While our goal is to make the Stack class generic and reusable, the stack’s plugin interface does not need to be generic.
