This interface extension, however, raises an interesting question. What does it mean to extend a module interface in C++, a language with no formal module definition?

# Module Interfaces

Until now, we have not rigorously defined a mechanism for implementing or describing modules. We have only loosely declared certain classes to be parts of certain modules (e.g., the CommandRepository being part of the command dispatcher module). But what does that really mean?
