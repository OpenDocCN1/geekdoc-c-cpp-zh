Remarkably few lines of code are necessary
to define a CommandPtr alias and to
implement a MakeCommandPtr() function
capable of invoking deallocate() instead of
delete. The code makes use of unique_ptr’s
delete object (see sidebar), which enables a
custom routine to be called to reclaim the
resource held by the unique_ptr when the
unique_ptr’s destructor is invoked. Let’s look
at the code:

```
inline void CommandDeleter(Command* p)
{
p->deallocate();
return;
}
```
