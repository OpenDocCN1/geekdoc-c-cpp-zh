# 8.2.1.2 Modifying the Stack

In Chapter 3, we originally designed the calculator’s stack to operate only on double precision variables. Clearly, this limitation means the Stack class must now be refactored in order to handle complex numbers. At the time, we questioned the logic of hard coding the target data type for the stack, and I recommended not designing a generic Stack class. My suggestion was, in general, to not design generic interfaces until the first reuse case is clearly established.
