Before concluding our discussion of the final StoredProcedure class, we should consider tokenization of the commands within the StoredProcedure class. The tokenization process for a StoredProcedure involves two steps. The stored procedure file must be opened and read, followed by the actual tokenization of the text stream. This process needs to be performed only once per StoredProcedure instantiation, at initialization. Therefore, the natural placement for tokenization is in the StoredProcedure’s constructor. However, placement of tokenization in the StoredProcedure’s constructor creates an inconsistency with pdCalc’s error handling procedure for commands. In particular, pdCalc assumes that commands can be constructed, but not necessarily executed, without failure.
