In Section 7.2.1, we first saw a version of MakeCommandPtr given by the following implementation:

```
inline void CommandDeleter(Command* p)
{
 p->deallocate(); return;
}
using CommandPtr =
std::unique_ptr<Command,
dec type(&CommandDeleter)>;
inline auto MakeCommandPtr(Command* p)
{
return CommandPtr{p, &CommandDeleter};
}
```
