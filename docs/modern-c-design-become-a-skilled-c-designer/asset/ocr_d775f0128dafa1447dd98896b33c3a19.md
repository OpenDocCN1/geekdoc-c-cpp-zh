Because I chose to use Qt for the graphic user interface framework for pdCalc (see Chapter 6), the Qt Test framework was a natural choice on which to build pdCalc’s unit test suite. Primarily, this choice does not add any additional library dependencies on the project, and the test framework is guaranteed to work on all platforms to which Qt has been ported. That said, any one of the many high quality C++ unit test frameworks would have sufficed equally well.

Personally, I find unit testing to be indispensable when programming even small projects. First and foremost, unit tests provide a means to ensure your code functions as expected. Second, unit testing enables you to see a module working correctly long before a user interface is developed.
