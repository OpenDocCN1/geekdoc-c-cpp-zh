```
void Command::deallocate()
```

For plugin commands, the override for the deallocate() has the same definition, only the definition appears in the plugin’s compiled code (say, in a base class used by commands in a particular plugin). Therefore, when deallocate() is invoked on a Command pointer in the main application, the virtual function dispatch ensures that delete is called from the correct compilation unit.
