# The plugins Directory

The plugins directory is a placeholder directory for the source code for plugins to pdCalc. It only includes one subdirectory, hyperbolicLnPlugin, which contains the source code for the hyperbolic functions and natural logarithm plugin developed in this book. The two source files in the hyperbolicPlugin directory areHyperbolicLnPlugin.h andHyperbolicLnPlugin.cpp. The source code implementing plugin loading and plugin management is all contained in the backend directory.

# The test Directory

The test directory is the home directory for all of the unit tests for pdCalc. This directory is simply a container for the following subdirectories, each of which tests the module corresponding to its name:testDriver,utilitiesTest,backendTest,cliT
