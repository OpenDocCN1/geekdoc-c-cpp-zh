Because it mediates events between the UI as a publisher and the CommandDispatcher as the target of the observer, theCommandIssuedObserver’s constructor takes a reference to aCommandDispatcherinstance, which it retains to call back to the command dispatcher when the UI raises acommandEntered()event. Recall that theCommandIssuedObserver will be stored by the UI in thePublisher’s event symbol table when the observer is attached to the event. The implementation ofnotifyImpl() is simply a dynamic cast of theEventData parameter to a specificCommandData instance followed by a call to CommandDispatcher’s commandEntered() function.
