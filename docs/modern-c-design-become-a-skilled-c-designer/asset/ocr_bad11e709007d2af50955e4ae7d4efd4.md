That is, the container is designed to be generic and reusable, but the interface for plugins does not require this flexibility since it is not reused once a data format for the calculator has been chosen.

Replacing the complex<double> representation in the C linkage interface to the stack is straightforward. We have several options. First, we could replace each double with a sequence of two doubles, one representing the real part and one representing the complex part. Of course, since a function cannot return two doubles, we would have to modify the functions returning a stack value to use pointer parameters in their argument lists to “return” complex values.
