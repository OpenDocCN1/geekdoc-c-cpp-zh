# Using the min/max, average, and sum Operators

There is not much to explain about operations; their names describe their functionalities. Because you have to handle the nullable value, each operator has a twin to handle the nullable value. I present them using a nullable operator in this section. Listing 4-32 shows how to get the maximum, minimum, and average of the student group, as well as the sum of their ages.

**LISTING 4-32** Finding the minimum, average, and sum of the students’ ages

```
let internal q1 = query {
    for student in db.Student do
        sumByNullable student.Age
}

printf("sum of student age = " + showResult [ q1])

let internal q2 = query {
    for student in db.Student do
        minByNullable student.Age
}

printf("youngest student age = " + showResult [ q12])

let internal q3 = query {
    for student in db.Student do
        maxByNullable student.Age
}

printf("oldest student age = " + showResult [ q13])

let internal q4 = query {
    for student in db.Student do
        averageByNullable(Microsoft.FSharp.Linq.float student.Age)
}

printf("average student age = " + showResult [ q14])

Execution result
sum of student age = 171
youngest student age = 20
oldest student age = 23
average student age = 21.375
```

> Note The **average** operation cannot be performed on an integer type. Instead, you need to use the *Nullable.float* type that is located in the *Microsoft.FSharp.Linq* module, which converts the *Nullable<int>* to *Nullable<float>.
