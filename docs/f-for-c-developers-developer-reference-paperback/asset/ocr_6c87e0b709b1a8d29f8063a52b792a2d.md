FIGURE 1-10 Defining a compile symbol

The INTERACTIVE compile symbol is a build-compile symbol. The code wrapped by this symbol will be included in the MSI execution but not in the project build process. Listing 1-19 provides an example. If you are trying to include code only during the project build, the COMPILED symbol by used, as shown in Listing 1-20.

LISTING 1-19 The INTERACTIVE symbol

```
#if INTERACTIVE

#r "System.Data"
#r "System.Data.Ling"
#r "FSharp.Data.TypeProviders"

endif
```

LISTING 1-20 The COMPILED symbol

```
#if COMPILED

printfn "this is included in the binary"

endif
```
