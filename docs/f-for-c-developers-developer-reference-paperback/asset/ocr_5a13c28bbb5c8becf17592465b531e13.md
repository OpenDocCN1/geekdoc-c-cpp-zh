You can easily change the Pascal triangle function to the BOPM, as shown in Listing 9-33.

**LISTING 9-33** The BOPM function

```
let blockIdx = new BlockDim()
let threadIdx = new ThreadIdx()

[ReflectedDefinition; GPU]
let bop: (a:CUDAPointer<float32>) (b:CUDAPointer<float32>) =
let u = 0.2f
let d = 1.f / u

let x = blockIdx.x
if x = 0 then
    b.Set(a.[x] * u, x)
else
    b.Set(a.[x - 1] * d, x)
()
```
