# Using Functions Related to Records

The F# record-related functions are shown in Listing 6-116. The sample code shows how to use reflection to check the type, get a record's fields, get a particular field, and make a record from an array.

LISTING 6-116 F# reflection on a record

```
Source code
open Microsoft.Sharp.Reflection

type Point2D = { x : float; y : float }
let point2Record = { Point2D.x = 1.; Point2D.y = 2. }

// check if it is a record type
FSharp.IsRecord(point2Record.GetType())

// get record fields
FShaderType.GetRecordFields(point2Record.GetType())

// get a record field
let fields = FSharpType.GetRecordFields(point2Record.GetType())
FSharpValue.GetRecordField(point2Record, fields.[1])

// make a record from an array
FSharpValue.MakeRecord(point2Record.GetType(), [|4.; 5. |])
```
