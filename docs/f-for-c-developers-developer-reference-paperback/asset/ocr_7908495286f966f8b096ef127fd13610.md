The pattern matching for a record needs to make sure the record is decomposed when performing the match. The match statement in Listing 6-49 matches any record with the listed records even when the type differs. The correct way to match the record is shown in Listing 6-50.

**LISTING 6-49** Match Record Sample I

```
type MyRecord = { X : int list; Y : string }
type MyRecord2 = { XX : int; YY : string; Z : int }

let rr = { X = [100; 200]; Y = "aa" }
let r0 = { X = [100; 200; 3]; Y = "aa" }
let r1 = { X = 11; YY = "bb"; Z = 9 }

match r1 with
    | rr -> "a"
    | _ -> "b"
```

Note A warning "This rule will never be matched" will be generated on the last line.
