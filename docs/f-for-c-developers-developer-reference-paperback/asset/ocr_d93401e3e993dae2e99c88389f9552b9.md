# LISTING 9-29 Generating code from functions decorated with the GPU attribute

```
let getCommonCode() = code.ToCode()

let getGPUFunctions() =
  let currentAssembly = Assembly.GetExecutingAssembly()
  let gpuMethods =
    currentAssembly.GetTypes()
    | List.OfArray
    | List.collect(fun t -> t.GetMethods() | List.OfArray)
    | List.filter(fun mi ->
      mi.CustomAttributes(typeof<GPUAttribute>, true).Length > 0)

  gpuMethods
  | List.map(fun mi -> (mi, Quotations.Expr.TryReflectedDefinition(mi)))
  | List.map(fun mi, (expr) -> (mi, expr))
  | List.map(fun mi, expr) ->
      sprintf "%\r\n %s \r\n"
      (getFunctionSignatureFromMethodInfo(accessExpr))

let tempFile = "temp1.cu"

let generateToFile() =
  let gpuCode = getGPUFunctions()
  let commonCode = getCommonCode()
  let allCode = String.Join("\r\n", commonCode :: gpuCode)
  System.IO.File.Delete(tempFile)
  System.IO.File.WriteAllText(tempFile, allCode)
```

The generated C code will not be able to execute on the GPU. You can use NVCC to compile the C code to a PTX file. The PTX file can be loaded and executed on the GPU. The PTX code is not an executable binary. Instead, the PTX file is compiled for a target GPU binary code at runtime. It is more like the assembly language on the GPU. The generated PTX file is shown in Listing 9-30.
