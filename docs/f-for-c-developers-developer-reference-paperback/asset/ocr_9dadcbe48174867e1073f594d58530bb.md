Check that a BST has only one child Usually one sequence from the traversal is not enough to reveal the binary tree intervals. The algorithm in this section is to determine if every node in the BST has only one child. All of the descendants of a node either be larger or smaller than the root. The following are steps to check each node in a loop:

+   1. Find the next child, and denote it as A.

+   2. Find the last pre-order node, which is the last element of the pre-order sequence, and denote it as B.

+   3. If both A and B are larger or smaller than the current node, then continue. Otherwise, return false.

The sample code is shown in Listing 7-27; a C# version is also provided. You might notice that the C# version breaks the loop in the middle when certain conditions are met. For#, it is not possible to break the loop in the middle. Inside, the F# version uses lazy evaluation as well as other seq functions to mimic the return/break functionality in the loop. The F# code can be read as preparation for all the data for the pre-order sequence, and then you can check whether any data is Diff. If the data meets the Diff criteria, the function returns FALSE. The sequence generation can move the code filtering and processing function out of the sequence-generation loop. I find that this can make the code more readable than the C# imperative version.
