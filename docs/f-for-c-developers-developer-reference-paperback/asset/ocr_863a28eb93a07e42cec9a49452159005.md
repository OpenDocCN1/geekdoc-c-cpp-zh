When looking at the code in Listing 2-46, some people will be scared because of a possible stack overflow exception. It seems that the code calls the get() function of property inside X a get() function. When you run the code, there is no stack overflow. When stepping into the code, you will find that the execution is going into the property defined in the class rather than the property in the interface. This identifier represents the Point2D type, which can be proved by positioning your pointer over the this—as you can see in Figure 2-1—so won't be a stack overflow exception. If you really want to a stack overflow, cast this to I2DLocation by using this : I2DLocation.
