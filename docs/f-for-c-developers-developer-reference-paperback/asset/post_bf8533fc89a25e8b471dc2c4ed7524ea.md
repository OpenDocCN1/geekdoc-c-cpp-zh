The computation expression creates a small region with its own language and maybe its own language of performing the computation. If you repeatedly write the same code, a computation expression is something that can be of great assistance.

## Using Computation Expression Attributes

If query and seq are both computation expressions, you might be wondering how other keywords such as where are defined. They are defined by using attributes. Let's start from a simple example, SimpleSequenceBuilder. Listing 6-99 shows a simple sequence builder and the code to which it will be translated. This is the starting point to show how to add customer operators as where.

### LISTING 6-99 Simple sequence builder

```fsharp
// define the sequence builder class
type SimpleSequence() = class
member this.For(seq<'a>, f:'a -> seq<'b>) =
    seq { for n in source do yield! n }
member this.Yield(n) = seq { yield n }
seq
```

let mySeq = SimpleSequence()
let r = mySeq { for i in 1..10 do yield i * i }

Translation result
let b = mySeq
b.For ([1..10], fun i -> b.Yield(i * i))

The where operation is introduced by the `CustomOperation` attribute, which is shown in Listing 6-100. The ProjectionParameter on the second parameter is useful to simplify the function function definition. Lacking this attribute, the where part in the computation expression has to be written as fun i -> explicitly. The ProjectionParameter is useful when there is a let binding between the customer operator and ForEach, like the one shown in Listing 6-101.

### LISTING 6-100 Using CustomOperation and ProjectionParameter attributes

```fsharp
type SimpleSequence2() = 
  member.For(source:seq<'a>, f:a -> seq<'b>) =
    seq (n in source yield! f n)
  member.Yield(n) = seq { yield n }
[CustomOperation('where')>=
  member.Where(source:seq<'a>, [ProjectionParameter])f:a -> bool) =
    source | Seq.Filter f
```

```fsharp
let mySeq2 = SimpleSequence2()
let r2 = mySeq2 {
  for i in 1..10 do
    where (i > 3)
}
```

```fsharp
Translation result
let b2 = mySeq2
b2.Where (b.For([1..10], fun i -> b.Yield(i)), fun i-> i)
```

### LISTING 6-101 ProjectParameter and let binding

```fsharp
let r3 = mySeq2 {
  for i in 1..10 do
    let j = i + 3
    where (i > 5 && j < 10)
}
```

```fsharp
Translation result

There are two properties in the CustomOperation attribute. The MaintainsVariableSpace property supports statements such as where i>5 & j<=10, like the one here:

```fsharp
where (i<5)
where (j<10)
```

The sample code is shown in Listing 6-102. The other property is the AllowIntoPattern. Like its name, it supports the syntax, as shown in Listing 6-103.

### LISTING 6-102 MaintainsVariableSpace in the CustomOperation attribute

```fsharp
type SimpleSequence() {
  member.For(source:seq<'a>, f:'a -> seq<'b'>) =
    seq { for n in source yield! n }
  member.Yield(n) = seq { yield n }
  [CustomOperation("where", MaintainsVariableSpace=true)]
  member.Where(source:seq<'a>, [ProjectionParameter])f:'a -> bool) =
    source | Seq.filter f
```

```fsharp
let mySeq3 = SimpleSequence()
let r4 = mySeq3
  for i in 1..10 do
    let j = i + 3
    where (j > 5)
    where (j < 10)
```

Translation result
let b4 = mySeq3
b4.Where(
  b4.For([1..10], fun i ->
      let j = i + 3
      b4.Yield(i, j)),
    fun (i, j) -> i > 5,
  fun (i, j) -> j < 10)
```

> Note the above code generate a warning, the warning can be eliminated by adding `| ignore` at the end.

type SimpleSequence() =

Other than the MaintainsVariableSpace property, there is another property named MaintainsVariableSpaceBinding, which can be used to pass the variable down the chain, a different way. The sample is shown in LISTING 6-104.

### LISTING 6-104 MaintainsVariableSpaceBinding in the CustomOperation attribute

```fsharp
type SimpleSequence5() =
  member.For(source:seq<'a>, f:'a -> seq<'b>) =
    seq { for n in source do yield! n }
  member.Return(n) = seq { yield n }
  [CustomOperation("", AllowIntoPattern=true, MaintainsVariableSpaceBinding=true)]
  member.Where(source:seq<'a>, [ProjectionParameter])f:'a -> bool) =
    source |> Seq.filter f
  member.Bind(value, count) = value
```

Certain properties on the CustomOperation introduce join-like operators. Listing 6-15 shows how to use the IsLikeJoin property.

### LISTING 6-105 UsingLikeJoin in a computation expression

```fsharp
type SimpleStringBuilder() =
  member.For(source : seq<'a>, body : 'a -> seq<'b>) =
    seq { for v in source do yield! body v }
  member.Yield(item:'a) : seq<'a> = seq { yield item }

  [CustomOperation("merge", IsLikeJoin = true, JoinConditionWord = "whenever")]
  member.Merge(src1:seq<'a>, src2:seq<'a>, ks1, ks2, ret) =
    seq { for b in src2 do
      if ks1 = ks2 then yield(ret a b)
    }
```

let mySeq = SimpleStringBuilder()

IsLikeJoin indicates that custom operation is similar to a join in a sequence computation, supporting two inputs and a correlation constraint. The expression in Listing 6-106 is translated into Listing 6-107.

### LISTING 6-106 Query code related to LikeJoin

```fsharp
myseq {
  for i in 1 .. 10 do
  merge j in [5 .. 15] whenever (i = j)
  yield j
}
```

### LISTING 6-107 Translated code from Listing 6-106

```fsharp
let b = myseq
b.For([1..10], [5..15]),
  (fun i -> i), (fun j -> j),
  (fun j -> b.Yield (j))
```

The computation expression is a big and advanced topic. Interested readers can refer to the latest F# language specification (http://research.microsoft.com/en-us/um/projects/fsharp/manual/spec.html) for more information.

### LISTING 6-108 Bank-system computation expression example

```fsharp
type Account<<Measure>'u>
  member val Balance = 0.0<_ with get, set
  member val PendingAmount = 0.0<_ with get, set

type Bank[<Measure>'u](account:Account<'u>) =
  member this.Yield () =
    account

  [CustomOperation("deposit")>
  member.Deposit(account:Account<'u>, v:float<'u>) : Account<'u> =
    account.PendingAmount <- account.PendingAmount + v
    account

  [CustomOperation("withdrawal")>
  member this.Withdraw(account:Account<'u>, v:float<'u>) : Account<'u> =
    account.PendingAmount <- account.PendingAmount - v
    account

  member this.Run(account:Account<'u>) =
  fun () ->
    let finalBalance = account.Balance + account.PendingAmount
```
