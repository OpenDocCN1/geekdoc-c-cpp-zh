# LISTING 2-39 Converting a number

```
C# conversion
int i = 5;
double d = (double)i

F# conversion
let i:int = 5
let d:double = double(i)
```

> > **Note** C# supports implicit conversion, which means that in C# you can assign an integer to a double without having to explicitly do the casting. The ability to deduce type and implicitly convert type can make development easier at earlier stages, but it introduces more chances to generate runtime errors. F# statically resolves the type and minimizes the runtime error by only allowing explicit type conversion.

The F# enum conversion is shown in Listing 2-40.

# LISTING 2-40 An enum conversion

```
type PixelColor =
| R = 0
| G = 1
| B = 2

// convert number to enum
let colorR : PixelColor = enum 0
let colorB = enum<PixelColor> 2
```
