# LISTING 7-19 Pre-order and post-order traversal

```
let rec preOrder visit tree =
match tree with
  | Node(value, children) ->
    visit value
    children
    > Seq.iter(preOrder visit)

let rec postOrder visit tree =
match tree with
  | Node(value, children) ->
    children
    > Seq.iter(postOrder visit)

let mutable result = []
let sum v =
  result sum @ [v]
preOrder sum (createTree())

result <- []
postOrder sum (createTree())
```

Execution result for post-order
