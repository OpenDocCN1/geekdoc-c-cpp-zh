let mySeq = { 1..10 }
let length = Seq.fold (fun acc n -> acc + n) 0I mySeq

# collect

The collect function applies a user-defined function to each element in the collection and joins results. One good application of this function is the LINQ SelectMany extension method. The SelectMany method flatten the hierarchy and returns all the elements in the second-level collection. The following sample first generates a list of lists and then combines all. See Listing 1-44.

# LISTING 1-44 The collect function

```fsharp
let generateListTo x = [0..x]

// generates lists [0:1]; [0;2]; [0;1;3]
let listOfLists = [1..3] |> List.map generateListTo

// concatenate the result
// seq [0; 1; 0; 2; 0; 1; 2]
let result = listOfLists |> Seq.collect (fun n -> n)
```

> Tip If you can use the built-in id function, the last line can be rewritten as Seq.collect id.

# append

This method takes two collections and returns a new collection where the first collection's elements are followed by the second collection's elements. The LINQ Concat function provides the same functionality. See Listing 1-45.

# LISTING 1-45 The append function

```fsharp
// the following concatenates two arrays and generates
// a new array that contains [1;2;3;4;5;6]
printf "%A" (Array.append [| 1; 2; 3|] [4; 5; 6])
```

# Math Operations

In addition to the transformation functions, F# provides a rich set of functions that perform mathematical operations on collections:

- **min and max**: The min and max functions are used to find the minimum or maximum value in a collection. These functions are just like the LINQ min and max functions. See Listing 1-46.

**LISTING 1-46** The min and max functions

```fsharp
let myList = [1..10]
let min = myList | List.min    // min is 1
let max = myList | List.max    // max is 10
```

**average**: The average function is used to get the mean of all elements in a collection. Because F# does not have implicit type conversion to float, the following code generates an int and does not support *DivideBy* operator, which means the operand must be transformed into a data type that supports divide, such as *float* or *float32*. See Listing 1-47.

**LISTING 1-47** the average function used with integer

```fsharp
let myList = [1..10]

// does not compile because int does not support "DivideBy"
let myListAverage = myList | List.average
```

You can use map to change the integer element into a *float* element. Again, the *float* is also a function that converts an integer to a *System.Double*. See Listing 1-48.

**LISTING 1-48** the average function in a float sequence

```fsharp
let myList = [1..10]

// the average is float type 5.5
let myListAverage = myList
    |> List.map float
    |> List.average
```

**sum**: The sum function returns the sum of elements in a collection. The *sum* result depends on the input sequence element type. The example in Listing 1-49 showcases this.

**LISTING 1-49** the *sum* function

```fsharp
let mySeq = seq { 1..10 }

// sum is 55
let result = mySeq | Seq.sum
```

# zip and zip3

The zip function combines two sequences into a sequence of pairs. The zip3 function, as its name suggests, combines three sequences into triples. The zip sample is shown in Listing 1-50. You can find a zip3 sample on MSDN (http://msdn.microsoft.com/en-us/library/ee370585.aspx).

LISTING 1-50 The zip function

```fsharp
let myList = [ 1 .. 3 ]
let myList2 = [ "a"; "b"; "c" ]

// the zip result is [(1, "a"), (2, "b"), (3, "c")]
let result = List.zip myList myList2
```

# sort

The sort function sorts the list using Operators.compare. If the original element's order is preserved, this is called a stable sort. The sort function on Seq and List are stable, while Array.sort is not a stable sort. See Listing 1-52.

LISTING 1-52 The sort function

```fsharp
let sortedList = List.sort [1; 8; -2]
// print out the sorted list, which is [-2; 1; 8]
printf "%A" sortedList
```

# Convert to Seq/List/Array

Each type of collection has its unique usage. It is common to convert one type to the other. It is easy to tell how to convert to a new type by looking at the functions. The sample code is shown in Listing 1-53.

- Seq.toList is used to convert a seq to a list.
- Seq.ToArray is used to convert a seq to an array.
- List.toSeq is used to convert a list to a seq.
- List.toArray is used to convert a list to an array.
- Array.toSeq is used to convert an array to a seq.
- Array.toList is used to convert an array to a list.

**LISTING 1-53** Some seq, list, and array examples

```fsharp
// define a sequence
let mySeq = { 1..5 }
// define a list
let myList = [1..5]
// define an array
let myArray = [| 1..5 |]
// convert seq to a list
let myListFromSeq = mySeq | Seq.toList
// convert seq to an array
let myArrayFromSeq = mySeq | Seq.toArray
// convert list to a seq
let seqFromList = myList | List.toSeq
// convert list to an array
let myArrayFromList = myList | List.toArray
// convert array to a seq
let mySeqFromArray = myArray | Array.toSeq
// convert array to a list
let myListFromArray = myArray | Array.toList
```

# Convert from Seq/List/Array

Unlike C#, which uses *from* prefix, F# uses *of* prefix to represent a function that converts one collection to another. See 1-54 for examples.

- Seq.ofList is used to convert a list to a seq.
- Seq.Array is used to convert an array to a seq.
- List.ofSeq is used to convert a seq to a list.
- List.Array is used to convert an array to a list.
- Array.ofSeq is used to convert a seq to an array.
- Array.toList is used to convert an array to a list.

**LISTING 1-54** Some seq, list, and array conversion

```fsharp
// define a sequence
let mySeq = { 1..5 }
// define a list
let myList = [1..5]
// define an array
let myArray = [| 1..5 |]
// convert list to a seq
let seqFromList = myList | List.ofSeq
// convert list to an array
let myArrayFromList = myList | List.Array
// convert seq to a list
let myListFromSeq = mySeq | Seq.ofList
// convert seq to an array
let myArrayFromSeq = mySeq | Seq.Array
// convert array to a seq
let mySeqFromArray = myArray | Array.ofSeq
// convert array to a list
let myListFromArray = myArray | Array.toList
```
