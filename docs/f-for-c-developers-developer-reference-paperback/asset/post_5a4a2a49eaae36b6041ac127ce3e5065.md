## LISTING 9-23 Functions for finding the return type and signature

```fsharp
open System
open System.Reflection
open Microsoft.Fsharp.Quotations
open Microsoft.Fsharp.Quotations.Patterns
open Microsoft.Fsharp.Quotations.DerivedPatterns
open Microsoft.Fsharp.Quotations.ExprShape

let rec getFunctionBody(exp:Expr) =
  match exp with
  | DerivedPatterns.Lambdas(c, callPattern) ->
    match callPattern
      | Patterns.Call(e, mi, exprList) ->
        match mi with
          | DerivedPatterns.MethodWithReflectedDefinition ->
            callPattern
          | Patterns.Sequential -> callPattern
          | _ -> callPattern
          | Patterns.Sequential -> exp
          | _ -> failwith(exp:Argument must be of the form <@ foo@")

let getFunctionNameAndReturn(expExpr) = 
  match expExpr with
  | DerivedPatterns.Lambdas(c, Patterns.Call(a, mi, b)) -> 
      Some(b, mi.ReturnType)
  | _ -> None

let getFunctionName(exp:Expr) = 
  match exp with
  | DerivedPatterns.Lambdas(c, Patterns.Call(a, mi, b)) -> 
      mi.Name
  | _ -> 
      failwith("Argument must be of the form <@ foo@")

let getFunctionTypes(exp:Expr) = 
  match getFunctionParameterAndReturn(exp) with
  | Some(expList, t) -> 
      let out = expList | List.map(fun n -> (n, n.Type))
      Some(out, t)
  | _ -> None

let getReturnType(exp:Expr) = 
  match getFunctionTypes(exp) with
  | Some(_, t) -> t
  | _ -> failwith("no return type")

let getGetAllType(exp:Expr) = 
  match exp with
  | Patterns.(_, _, _) -> mi.ReturnType
  | Patterns.Var n -> n.Type
  | Patterns.Sequential(var, e0, e1) -> getReturnType e1
  | Patterns.Value(v) -> v
  | Patterns.WhileLoop(e) -> typeof System.Void
  | Patterns.ForIntegerRangeLoop(var, e0, e1, e2) -> getReturnType e2
  | Patterns.IfThenElse(e0, e1, e2) -> typeof System.Void
  | _ -> failwith("not supported expr type")

let getFunctionSignature(exp:Expr) = 
  let template = "@extern \"__global__ void {0}\""

  let functionName = getFunctionName(exp)
  let parameters = getFunctionNameParameterAndReturn(exp)

  match parameters with
  | Some(exprList, _) ->
      let parameterNames =
        exprList
        |> Seq.Map (fun n ->
            if n.Type.IsAssignableFrom(typeof<CUDAPointer<float>>) then
              sprintf("double %s", (n.ToString()))
            else if n.Type.IsAssignableFrom(typeof<CUDAPointer<float32>>) then
              sprintf("float %s", (n.ToString()))
            else
              sprintf("%s %s", (n.Name), (n.Type)))
      String.Format(template, functionName, String.Join(", ", parameterNames))
  | None -> failwith("cannot get parameter and return type")
```

# F# Quotation on GPGPU

The goal for this section is to translate F# code in Listing 9-26 to CUDA code. The sample function is used to add two arrays, named *a* and *b*, and set the result to array *c*. The pascalTriangle function is used to compute Pascal values on a given line. The sample2 function demonstrates how the while statement is used to translate F# code to CUDA code.

CUDA uses an array of threads to process the data. So the code output, threadid is a translation that will be executed by many threads. Because of these, you can process many elements in an array simultaneously. More detailed information can be found in the NVIDIA documentation at http://www.nvidia.com/cuda-download/Getting_Started_CUDA_Training.pdf.

## LISTING 9-26 F# code for the translation to CUDA code

```cuda
let sample(a:CUDAPointer<float>, b:CUDAPointer<float>)(c:CUDAPointer<float>)
  let x = blockIdx.x
  c.Set(a[x] + b[x])

let pascalTriangle(a:CUDAPointer<float>, b:CUDAPointer<float>)(c:CUDAPointer<float>) =
  let x = blockIdx.x
  if x = 0 then
    b.Set(a[x], x)
  else
    b.Set(a[x] + b[x], x)

let sample2(a:CUDAPointer<float>, b:CUDAPointer<float>)(c:CUDAPointer<float>) =
  let x = blockIdx.x
  for j = 0 to x do
    c.Set(a[j] + b[j], x)
  let mutable i = 3
  while i < 8 do
    if i > 3 then
      c.Set(a[i] + b[i], x)
    else
      c.Set(a[i] + b[0], x)
    i <- i + 1
```

The generated code has two sections: the function that starts with the __device__ keyword, and the function with the __global__ keyword. The function with the __device__ keyword cannot be invoked from the host. The __global__ function can be invoked from the host. If you need to access the functionality in the __device__ function, there must be a __global__ function. The generated code is in the following format:

```cpp
#include "UDALibrary.h"
```

```cuda
__device__ void ff_0(float* a, float* b) {
    // some generated code

extern "C" __global__ void sample(float* a, float* b) {
    ff_0(a, b);
}
```

The code has three parts:

- Header file CUDibrary.h
- Generated __device__ function (ff_0) in the preceding code
- Generated __global__ function, which will be invoked from the host and call into the __device__ function ff_0
