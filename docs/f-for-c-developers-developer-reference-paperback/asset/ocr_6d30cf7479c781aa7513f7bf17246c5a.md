# Using Computation Expression Sample

Listing 6-108 demonstrates a bank system that makes deposits to withdrawals from an account. The computation expression creates a transaction with multiple deposit and withdrawal operations. The operation starts with the Yield method, which provides the account object for succeeding operations, such as deposit. The Deposit and Withdraw methods take two parameters. The first parameter is the account parameter, and the second is the amount parameter, which is passed by the user. The Run method is the last to be invoked. It returns a function unit<'Account> type.

LISTING 6-108 Bank-system computation expression example

```
type Account<<Measure>'u>
  member val Balance = 0.0<_> with get, set
  member val PendingAmount = 0.0<_> with get, set

type Bank[<Measure>'u](account:Account<'u>) =
  member this.Yield () = =
    account

  [CustomOperation("deposit")>
  member this.Deposit(account:Account<'u>, v:float<'u>) : Account<'u> = =
    account.PendingAmount <- account.PendingAmount + v
    account

  [CustomOperation("withdrawal")>
  member this.Withdraw(account:Account<'u>, v:float<'u>) : Account<'u> = =
    account.PendingAmount <- account.PendingAmount - v
    account

  member this.Run(account:Account<'u>) =
  fun () ->
    let finalBalance = account.Balance + account.PendingAmount
```
