# Pipe-backward operator

```
let f = x *= 2
let g = x + 5

// forwardPipeResult is 2^((3 + 5) = 16
let forwardPipeResult = f <|(g <|3)
```

> **Note** Pipe operators and composite operators do not affect function execution performance. You can choose either of them according to your preference.

If you are curious about how to allow a C# method to hook into the pipe operation, Listing 1-73 shows an example. The code takes an integer list as input, converts each item into a string, and joins them by "*" as a separator. String.Join has many overloaded functions, you will have to tell the compiler which overload format you prefer. We use FuncConvert.FuncFromTuple to convert the .NET function to a curved format, which is easier to work with when using the pipe operator.

**LISTING 1-73** Assigning a function and converting function to a curved format

```
let input = [ 1..10 ]

// assign.Join to join with the string*string list as function signature
let join : string*string -> string = System.String.Join

// convert join to curry format
let curryFormatJoin = FuncConvert.FuncFromTuple joined

input
|> List.map(fun number -> string(number)) // convert int to string
> curryFormatJoin("**") // join the list to a string using "*"
```

In functional programming, the function is a first-class citizen. Some readers might to explore mathematical operations with functions. The pipeline operator and the composite operator can be viewed as the *add* operation, which combines two functions. Listing 1-74 does not compile because you cannot compare two functions.
