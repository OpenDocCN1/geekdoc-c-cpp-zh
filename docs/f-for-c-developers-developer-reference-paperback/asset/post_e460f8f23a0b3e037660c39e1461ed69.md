
## LISTING 6-59 Multicase active pattern example

```fsharp
let (|FirstQuarter|SecondQuarter|ThirdQuarter|FourthQuarter)| (date:System.DateTime) =
    let month = date.Month
    match month with
    | 1 | 2 | 3 -> FirstQuarter month
    | 4 | 5 | 6 -> SecondQuarter month
    | 7 | 8 | 9 -> ThirdQuarter month
    | _ -> FourthQuarter month
```

```fsharp
let newYearResolution date =
    match date with
    | FirstQuarter -> printf "New resolution: lose 10 lbs this year!"
    | SecondQuarter -> printf "beef is good for summer BBQ?"
    | ThirdQuarter -> printf "maybe I should it?"
    | FourthQuarter -> printf "Mom's apple pie is wonderful!"
```

> Note: The underscore (_) in the second pattern match instructs the F# compiler to ignore the return value from the active pattern.

> Note: Active patterns cannot return more than seven possibilities. The code `(|A|B|C|D|E|F|G|H|I|J|K)| x = x` will generate a compile error.

## Using Parameterized Active Patterns

The active pattern is a special function. If it is a function, can it accept parameters? The answer is yes. Parameters for an active pattern can be included immediately after the active pattern label, but they must appear before the active pattern return value. Listing 6-60 shows how to parse a phone number and return all in phone number. The pattern string is the parameter and the out variable is used to store the return value from the active pattern.

## LISTING 6-60 Parameterized active pattern example

```fsharp
using System.Text.RegularExpressions

// define the parameterized active pattern
let (|RegexMatch||) (pattern:string)(input:string) =
    let regex = Regex(pattern).Match(input)
    if regex.Success then Some(List.tail [ for x in regex.Groups -> x.Value])
    else None

let parsePhoneNumber str =
    match str with
```

```fsharp
    | RegexMatch("(\d{3})-(\d{3})-(\d{4})") out -> System.String.Join("-", out)
    | _ -> "Not supported format"
```

```fsharp
// two statements below show 4251231234
parsePhoneNumber "425-123-1234"
parsePhoneNumber "425-123-1234"
parsePhoneNumber "4251231234" // returns Not supported format
```

```fsharp
// this format does not parse and shows "Not supported format"
parseNumber "4251234"
```

**Tip** The active pattern is a special function you can use to create a higher-order function and use it in a match expression. The `parseNumber` function can be rewritten as follows:

```fsharp
let Regex2 = RegexMatch("(\d{3})-(\d{3})-(\d{4})") 
let parseNumber str =
    match str with
    | RegexMatch out -> System.String.Join("", out)
    | Regex2 out -> System.String.Join("", out)
    | _ -> "Not supported format"
```

## Catching Exceptions

Listing 6-63 shows how to catch an exception in F#.

```fsharp
open System

let exceptionCatch() =
    try
        let a = 3 / 0 // divide zero exception
        printf "%d" a
    with
    | DivideZeroException -> printf "divided by zero"
```

> Note: Although `try...with` statement is similar to the `match` statement, it does not check for pattern completeness. With C#, if the exception is not caught, it will bubble up.

In addition to `try...with`, F# also supports `try...finally`. See Listing 6-64. F# does not provide `try...with...finally`. If finally is used to release resources, the statement can solve this without involving finally. If you require functionality similar to the `try...catch...finally` in C#, you can nest `try...with` within a `try` to achieve the same functionality, as shown in Listing 6-65.

## Throwing Exceptions

F# provides a shortcut to throw exceptions using `failwith`. Both of these functions generate a `System.Exception`. The `failwith` function takes a string as a parameter, and `failwith` takes a string format, like `printf`, to generate a more sophisticated error message. The sample code is shown in Listing 6-66. Note that listing contains a compile warning that can be ignored.

## LISTING 6-66 The failwith examples

```fsharp
open System
try
    failwith "this is an exception"
    with : Exception as e -> printf "the exception msg is %s" e.Message
try
    failwith "this is an exception generated at %A" DateTime.Now
    with _ as e -> printf "the exception msg is %s" e.Message
```

> Note: The last line can also be written with `e -> printf "the exception msg is %s" e.Message`

C# has a `throw` keyword that is used to throw an exception. What is the equivalent in F#? In F#, the `raise` and `reraise` functions can be used. Listing 6-67 shows how to raise a `System.Exception` and how to throw an exception in the section.

## LISTING 6-67 The raise exception

```fsharp
open System

try
    raise (Exception("raise exception"))
with _ -> printf "catch exception"

try
    raise (Exception("raise exception"))
with _ -> 
    printf "catch exception"
    reraise()
```

In the `failwith` and `raise` functions, F# provides three other shortcut functions to raise common exceptions. Listing 6-68 shows how to use these three shortcut functions:

- An invalid argument exception is thrown by using `invalidArg` with two string parameters.
- An invalid operation exception is thrown by using `invalidOp` with one string type parameter.
- An invalid format exception is thrown by using `invalidFormat` with two string parameters.

## LISTING 6-68 The invalidArg, invalidOp, and invalidFormat functions

```fsharp
// invalid argument exception
try
    invalidArg("message", "value")
with : ArgumentException as e -> printf "%s" e

// invalid operation exception
try
    invalidOp("message")
with : InvalidOperationException as e -> printf "%s" e

// invalid format exception
try
    invalidFormat("message", "value")
with : FormatException as e -> printf "%s" e
```

## Working with a Generic Invoke

The generic invoke (GI) function is a static member constraint. It is used to invoke a member on a type that has a specific signature. A sample GI function is shown in Listing 6-71. The function requires that the parameter be a type with a member name called `MyMethod` and has a function signature of `unit->int`. The GI function takes one parameter, which is the object `x`. The other samples in Listing 6-71 demonstrate how to pass additional parameters into the GI function, as a tuple. In the sample code, there is type information for the parameter, which is optional.

## LISTING 6-71 Generic invoke (GI) function example

```fsharp
// GI function takes one parameter
let inlineA (x : ^T) = (^T : (member MyMethod : unit -> int) x

// GI function takes two parameters
let inlineB (x : ^T) = (^T : (member CanConnectWithString : string -> int) (x, str))

// GI function takes three parameters
let inlineC (x : ^T) a b = (^T : (member Add : int -> int -> int) (x, a, b))

// GI function takes a tuple as a parameter
let inlineD (x : ^T) a b = (^T : (member Add : int * int -> int) (x, a, b))

// GI function takes a tuple and another as parameters
// c is float type that will go into MyFunction's second parameter
let inlineE (x : ^T) a b (c:float) =
    (^T : (member MyFunction : int * int -> float -> int) (x, a, b, c))
```
