You might be wondering where the public keyword is. Unlike class in C#, which is internal by default, the F# class is public by default. Ignoring the public keyword can save some typing. F# also supports using modules to group code. Table 2-1 lists all the accessibility modifiers that F# supports.

### TABLE 2-1 Accessibility modifier definitions

| Accessibility Modifier | Description |
|---|---|
| public | The public access indicates that the type, value, and function are accessible anywhere. |
| private | The private access modifier is the least-permissive access. Private members are accessible within the body of the class or the struct in which they are declared. The class field is private by default. |
| internal | The internal modifier is same as public if there is only one assembly. The internal types are not accessible from another assembly. It is public when accessed from the same assembly and when access from a different assembly. |

> Note F# does not support the protected keyword. F# honors protected visibility when the type is defined in a language that supports protected-level visibility. ## Defining a Property

Next we define a property using the member keyword. The property name is always prefixed with a self-identifier. The code in Listing 2-7 also uses this self-identifier. In C#, we can specify a different accessibility level for a property’s getter and setter functions. We can do do this in F# by private,,, or internal before the set or get. Listing 2-7 shows a sample of a.

### LISTING 2-7 Defining a property with the same accessibility modifier

```fsharp
// define a Point2D class
type Point2D() =
    // define field x
    let mutable x = 0.0

// define X property
member this.X with get() = x
    and set(v) = x <- v

Defining a property with a different accessibility modifier
// define a Point2D class
type Point2D() =
    // define field x
    let mutable x = 0.0

// define an X property
member this.X with get() = x
    and private set(v) = x <- v
```

C# has a shortcut definition for a property. In C# 3.0 and later, the auto-implemented property syntax was introduced. The property uses the auto-implemented property syntax. F# 3.0 also has this feature, as shown in Listing 2-8. The O in the line member Y = 0 with get, set is the initial value for the property, and this initial value also is responsible for indicating the variable type. When the initial value is O, the type is automatically inferred to be integer. The F# compiler generates a back-end field Y#, and it is decorated with the CompilerGenerateAttribute attribute.

### LISTING 2-8 An auto-implemented property

```fsharp
// define a Point2D class
type Point2D() =
    // define field x
    let mutable x = 0.0
    // define Y property
    member Y = 0 with get, set
```
