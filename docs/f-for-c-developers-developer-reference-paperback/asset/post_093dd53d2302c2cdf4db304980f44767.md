# exists and exists2

Seq, list, and array provide the same functions to check whether an element exists and to see whether two collections contain the same element at the same location. The exists function is used to check for a single element, and exists.2 is used for checking two collections. Listing 1-34 shows how to use Seq.exists and Seq.exists2.

# LISTING 1-34 The exists exists2 functions

```fsharp
let mySeq = seq { 1..10 }
let mySeq2 = seq { 10..-1..3 }
```

```fsharp
// if mySeq contains 3, which will make "fun n -> n = 3" return TRUE
if mySeq |> Seq.exists (fun n -> n = 3) then printf "mySeq contains 3"

// concise version to check if it contains numbers 3
if mySeq |> Seq.exists (= 3) then printf "mySeq contains 3"

// check if two sequences contain the same element at the same location
if Seq.exists2 (fun n1 -> n1 = n2) mySeq2 then printf "two sequences contain same element"
```

You might have trouble understanding the (= 3) in the code from the previous. Everything in F is a function, and the equal sign (=) is no exception. If you want to see the example definition, you can run the FSI. Listing 1-35. The definition is as follows:

```fsharp

```

This definition is a function that takes one argument and returns a function. 'a is nothing familiar. It is a type and will be determined by type inference which will be introduced later in this chapter. When an argument is provided to this function, it returns a new function. # fold

The fold function aggregates the collection into a single value. Its definition from MSDN shows that fold applies a function to each element of the collection and threads an accumulator argument through the computation. The LINQ Aggregate extension methods perform the functionality. Listing 1-42 shows an example that sums all elements in the sequence. LISTING 1-42 The fold function

```fsharp
let mySeq = { 1..10 }
let result = Seq.fold (fun acc n -> acc + n) 0 mySeq
printf "the sum of 1..10 is %d" result //sum = 55
```
