A* algorithm The A* (pronounced A star) algorithm is another graph algorithm. The graph is represented in a matrix, where 0 cannot be passed. There is an openList and a closedList. The openList keeps track of the unvisited nodes and the closedList nodes that have already been processed. The openList is started by the node cost. The node cost F is computed from two nodes: H and MoveCost. MoveCost is the move from previous nodes, while H is a heuristic cost that is an estimate from current node. The H only from your current location to particular destination. On the way to your destination, you have a feeling of whether next move is closer to or further from the destination. This is how the A* algorithm works. The H value is your estimate from your current location to destination; the value plays a role in your decision when making a move closer to your.

The algorithm starts from the openList with a starting point, and the TotalCost set to 0. During each iteration, the minimum TotalCost node is taken from the openList and denoted as the currentNode. The neighbor nodes are retrieved and put on the openList, as long as they are not visited and on the closedList. The MoveCost value of neighbor nodes is computed from the current node. If the cost is less than the current value, which means the current node is a better choice, the node's PreviousNode is set to currentNode and the MoveCost is updated accordingly.
