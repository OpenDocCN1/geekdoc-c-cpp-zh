# The IDisposable Interface

The Disposable interface is mainly used for releasing unmanaged resources. The garbage collector can automatically reclaim the memory for managed objects. However, garbage collection keys knowledge about the unmanaged resources, such as opened files or streams. By invoking the Dispose method, you have control over to release the unmanaged resources.
