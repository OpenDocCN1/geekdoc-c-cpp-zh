# Using the Tuple Pattern

A more complex pattern is the tuple pattern, which is used to match a value pair. Listing 6-40 implements the OR function. The first version lists all the values in the form of a tuple. The OR function returns FALSE when the two inputs are both FALSE. The simplified version implements this by using (_,), which can match anything. Note that the tuple can have more than two values. Listing 1-65 uses tuple to decompose a triple element in the list.

+   **LISTING 6-40** Tuple pattern

```
OR function with tuple pattern matching
let orFunction(x, y) =
match x, y
  | true, true -> true
  | true, false -> true
  | false, true -> true
  | false, false -> false

Simplified ORfunction2 with tuple pattern matching
let orfunction2(x, y) =
match x, y
  | false, false -> false
  | _, _ -> true
```

> Note The _, _ can be further simplified as _. The _, _ is used to match any tuple value, while _ is used to match any value.
