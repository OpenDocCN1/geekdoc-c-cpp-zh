**Note** dumpbin.exe is used to check the exported functions from CUDA BLAS. The cublas64_<version>.DLL is located in the <CUDA installation folder> C\bin. The result from dumpbin.exe can have two versions. For example, the cublasZdcal and cublasZdcal_2 functions are shown in the result. It is recommended that you use the function with _2 suffix.

There are several overloaded functions in the cuBLAS library. Because F# does not allow you to define the function with the same name, another module is needed to declare the function with the same name, as shown in Listing 9-16. Some of the 64-bit version functions are not listed. These functions are the same as in the 32-bit module.

# **LISTING 9-16** cuBLAS library in a different module
