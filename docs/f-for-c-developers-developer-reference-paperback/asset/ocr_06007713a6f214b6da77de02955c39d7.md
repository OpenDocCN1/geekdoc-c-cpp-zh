When debugging a multithreaded program, one of the techniques to use rost for assistance is the printf function. F# printf uses a different technique than Console.WriteLine. As previously mentioned, it does not lock the output stream. As a consequence, a call to printf-with using the lock function yields interleaving information. Listing 6-78 demonstrates how to write a printf with a lock.

+   LISTING 6-78 Using printfn with the lock function

```
let syncRoot = ref 0
lock(syncRoot) = ( fun -> printf "not interleaving printf")
```
