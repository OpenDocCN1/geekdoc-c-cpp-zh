## Permutations of a string 

Listing 7-36 shows how to get all permutations of a string. For example, the permutations of the string "abc" will be "abc", "acb", "bca", "bac", "cab", and "cba".

**String interleaving** String interleaving is a restricted permutation. An interleaved string of two strings keeps the order of the characters in the strings. If two given strings are "a" and "bc", "abc", and "bac" are valid interleaving results, but "cba" is not because the "cb" is in the wrong order. The code to implement string interleaving is shown in Listing 7-37.

### LISTING 7-37 String interleaving

```fsharp
open System
let ( AllEmpty | StrNotEmpty | Both ) (str0, str1) =
  let b0 = String.IsNullOrEmpty(str0)
  let b1 = String.IsNullOrEmpty(str1)
  match b0, b1 with
  | true, true -> AllEmpty
  | false, true -> StrNotEmpty
  | true, false -> StrNotEmpty
  | false, false -> Both

  let mutable result = []
  let add x =
    result <- result @ [x]

  let interleaving str0 str1 =
    let rec interleaving str0 str1 current =
      match str0, str1 with
      | AllEmpty _ -> ()
      | StrNotEmpty _ -> add (current+str1)
      | StrNotEmpty -> add (current+str0)
      | Both ->
        interleavingStrs (str0.Substring(1)) str1 (current + string str0.[0])
        interleavingStrs str0 (str1.Substring(1)) (current + string str1.[0])

    interleavingStrs str0 str1 ""
```

KMP Imagine you have two strings and that you want to find all occurrences of a target string. The KMP string search algorithm is an algorithm you can use to do this. The search complexity is O(n), where n is the length of the string. In addition to demonstrating the algorithm, the code also shows how to use an F# record, a type alias, and extension methods. Also note the use of a match statement in which the branching logic is implemented solely by 'when'; guards all patterns being '_'. The sample code is shown in Listing 7-38.

### LISTING 7-38 KMP string search algorithm

```fsharp
type List = System.Collections.Generic.List<int>

let kmp (w: string) =
  let t = List([1..w.Length])
  let mutable pos = 2
  let mutable cnd = 0
  t[0] <- -1
  t[1] <- 0

  while pos < w.Length do
    match pos cnd with
    | when w.[pos - 1] = w.[cnd]
      cnd <- cnd + 1
    | t.[pos] < cnd
      pos <- pos + 1
    | when cnd > 0 ->
      cnd <- t.[cnd]
    | ->
      t.[pos] <- 0
      pos <- pos + 1

  let t | List.ofSeq

type ResultType =
  { mutable Result : int; mutable Found : bool }
  with
    member this.SetFound(b) = this.Found <- b
    member this.SetResult(c) = this.Result <- c
    static member InitialValue = { Result = -1; Found = false }

  let kmpSearch(w:string) : int =
    let mutable m = 0
    let mutable i = 0
    let t = kmp w
    let v = ResultType.InitialValue
    while (i + m) < t.Length && not v.Found do
      if t.[i + m] = w.[m] then
        if i + m = t.Length - 1 then
          v.SetFound true
          v.SetResult i
        else
          m <- m + 1
      i <- i + 1
```

## Using the Graph Library

The graph library is used to implement a graph structure that contains nodes and edges (the formal definition of graph: a set of nodes connected by links). Each node has outgoing edges and an incoming collection. The graph operation is performed by the Graph class, which also maintains lists of all nodes (See Listing 7-9). This shows how flexible the F# library is. There are no constraints on the node ID. The type inference system will make sure everything is assigned the appropriate type.

```fsharp
type Graph() =
  let mutable nodes = []
  let mutable edges = []

  member this.Nodes = nodes
  member this.Edges = edges

  member this.CreateNode(id) =
    match this.FindNode id with
    | Some n -> n
    | None ->
      let node = Node(this, ID = id)
      nodes <- nodes @ [node]
      node

  member this.CreateEdgeFromID(from:string, to:string, id) =
    let fromNode = this.FindNode(from)
    let toNode = this.FindNode(to)
    match fromNode, toNode with
    | Some n0, Some n1 ->
      let edge = Edge(this, n0, n1, id)
      edges <- edges @ [edge]
      Some edge
    | _ -> None

  member this.FindNode(id) =
    nodes | List.Find(fun n -> n.ID = id)

  member this.FindEdge(id) =
    edges | List.Find(fun edge -> edge.ID = id)

  member this.RemoveEdge(edge: Edge) =
    edges <- List.Filter(fun e -> e <> edge)

  member this.RemoveNode(node: Node) =
    node.OutgoingEdges | List.iter(fun e -> this.RemoveEdge(e))
    node.IncomingEdges | List.iter(fun e -> this.RemoveEdge(e))
    nodes <- List.Filter(fun n -> n <> node)

type Node(g:Graph, ID:string) =
  let mutable incoming = []
  let mutable outgoing = []
  
  member this.ID = ID
  member this.IncomingEdges = incoming
  member this.OutgoingEdges = outgoing

  member this.AddIncomingEdge(edge: Edge) =
    incoming <- incoming @ [edge]
  member this.AddOutgoingEdge(edge: Edge) =
    outgoing <- outgoing @ [edge]

type Edge(g:Graph, from:Node, to:Node, ID:int) =
  member this.ID = ID
  member this.FromNode = from
  member this.ToNode = to
```
