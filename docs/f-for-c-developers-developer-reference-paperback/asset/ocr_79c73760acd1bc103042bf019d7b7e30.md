After clicking the Add button, the SQL type provider code is added. Along with the code, a reference to a crud assembly named FSharp.Data.TypeProviders is also added. This is where the provider resides. The generated code is shown in Listing 4-1. The connection string is highlighted, and all that you need to do to make this type provider work. The most convenient way to try a new feature is to use F# Interactive (FSI). Most of the samples in this chapter will use FSI as the default way to execute.

# LISTING 4-1 SQL type provider code

```
// The SqlDataConnection (LINQ-to-SQL) TypeProvider allows you to write code that
// uses a live connection to a database. For more information, please go to
// http://go.microsoft.com/fwlink/?LinkId=229209

module SqlDataConnection1

#if INTERACTIVE
#r "System.Data"
#r "System.Data.Linq"
#r "FSharp.Data.TypeProviders"
#endif

open System.Data
open System.Data.Linq
open Microsoft.FSharp.Data.TypeProviders
```

```
// You can use Server Explorer to build your ConnectionString.
type SqlConnection = Microsoft.FSharp.Data.TypeProviders.SqlSqlConnection<ConnectionString> ng = "@Data Source=(localDB)\v11.0;Initial Catalog=tempdb;Integrated Security=True",
let db = SqlConnection.GetDataContext()
```
