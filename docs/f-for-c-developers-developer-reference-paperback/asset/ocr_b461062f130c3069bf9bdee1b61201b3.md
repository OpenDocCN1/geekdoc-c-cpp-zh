The state machine reads the DGML file and generates a graph structure. MailboxProcessor is applied to process the message in an asynchronous way. The actual implementation defines two classes, as shown in Listing 5-43. The DGMLClass type represents the DGML file with a list of nodes and links defined in the file. The StateMachine inherits from DGMLClass. It adds MailboxProcessor to process the transition asynchronously and several method to set the transition functions. These two classes can be treated like a library that can process any DGML file.
