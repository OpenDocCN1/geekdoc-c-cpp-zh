# Using the Monte Carlo Simulation to Compute the \pi Value on a GPU

Other than using GPUs for array processing, you can also use them in simulations. In this section, you take a look at a small application designed to calculate the \pi using Monte Carlo simulation. The algorithm is used to count the random generated hit in two areas. The two areas are a square and, within it, a circle that touches each edge of the square. If you know that the radius of the circle is r, the area of the circle is $\pi r^2$. And the area of the square is $4r^2$. Imagine a large number of random hits in the area. The \pi value can be calculated from the number of hits in the circle area and the number of hits in the rectangle area.

![](img/63aaf94e22830ab98ce16c5946be8ef6_613_0.png)

FIGURE 9-10 Position of circle and rectangle in Monte Carlo simulation

cuRand library provides functions used to generate uniform numbers between 0 and 1. Instead of model shown in Figure 9-10, you can create a quarter of the circle whose computation involves \pi. The diagram is shown in Figure 9-11. The formula to compute \pi value from $area1$ and $area2$ is listed here:

```
$\frac{1}{4}\pi r^2 = \frac{\text{hit in area0}}{\text{hit in area1}}$
$\frac{\pi}{4} = \frac{\text{hit in area0}}{\text{hit in area1}}$
$\pi = \frac{\text{hit in area0}}{\text{hit in area1}} \times 4$
```
