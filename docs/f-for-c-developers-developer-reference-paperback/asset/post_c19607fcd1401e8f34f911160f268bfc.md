# What Changed

The sequence operation is very much like the LINQ operation, and these operations will be often used in the rest of this book.

The functional style is very different from the imperative style. Imagine presenting the problem of adding all odd numbers between 0 and 100 to a person without any formal computer background. Most likely, that would go about solving the problem in the same way that the functional approach presented. They would start finding all of the odd numbers and adding them up. This is simply a more straightforward approach that more closely resembles how people think about problems.
