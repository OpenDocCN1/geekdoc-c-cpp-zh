Note The Watch window in Microsoft Visual Studio does not support all these characters and keywords. It does not show C# keywords and special character variable names, but it does support view if these special characters and keywords are class members. The following two screenhots show how it works:

```
let f() =
  let else = "elie" = 99
  let end = 101
  let F# = 102
  let my value = 103
  let let = 103
```

type myClass() = class {
  member val "else" = with get, set
  member val "end" = with get, set
  member val "var" = with get, set
  member val "My Value" = with get, set
  member val "let" = with get, set
}
