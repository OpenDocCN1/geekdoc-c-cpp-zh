# LISTING 6-41 Using the tuple pattern to work with the Dictionary.TryGetValue function

```
let f x =
  let dict = System.Collections.Generic.Dictionary()
  dict.[0] <- "0"
  dict.[1] <- "1"

match dict.TryGetValue x with
| true, v -> sprintf("%%A mapped to %A") x v
| false, _ -> "cannot find"

printf("%%A" (f 0))
printf("%%A" (f 1))
printf("%%A" (f 2))
```

Execution result
"found 0 mapped to "0"
"found 1 mapped to "1"
"cannot find"
