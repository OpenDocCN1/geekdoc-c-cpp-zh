# Working with a Generic Invoke

The generic invoke (GI) function is a static member constraint function. It is used to invoke a member function on a type that has a specific signature. A sample GI function is shown in Listing 6-71. The functionA requires that the parameter be a type with a member name called MyMethod and has a function signature of unit->int. The GI function takes one parameter, which is the object x. The other samples in Listing 6-71 demonstrate how to pass additional parameters into the GI function, as a tuple. In the sample code, there is type information for the parameter, which is optional. This type information can help you identify parameters should be passed into the GI function. There is an interesting keyword named inline in the function, which makes the restriction happen. I will discuss it in the "inline Function" section.

LISTING 6-71 Generic invoke (GI) function example

```
// GI function takes one parameter
let inlineA (x : ^T) = (^T : (member MyMethod : unit -> int) x)

// GI function takes two parameters
let inlineB (x : ^T) = (^T : (member CanConnectWithString : string -> int) (x, str))

// GI function takes three parameters
let inlineC (x : ^T) a b = (^T : (member Add : int -> int -> int) (x, a, b))

// GI function takes a tuple as a parameter
let inlineD (x : ^T) a b = (^T : (member Add : int * int -> int) (x, a, b))

// GI function takes a tuple and another as parameters
// c is float type that will go into MyFunction's second parameter
let inlineE (x : ^T) a b (c:float) =
    (^T : (member MyFunction : int * int -> float -> int) (x, a, b, c))
```
