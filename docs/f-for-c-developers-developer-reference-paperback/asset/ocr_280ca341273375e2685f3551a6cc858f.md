# # Working with Type and Member Info

F# supports the typeof operator similar to C#. For example, typeof<int> returns a System.Int32 type. Because typeof always takes the type parameter as a type of object, F# introduces the typedef function to work with generic types. Listing 6-112 shows the difference between typeof and typedef.

Getting the type info enables you to invoke methods or access the properties of an object. Listing 6-113 shows how to use reflection to retrieve MethodInfo and invoke the method on a Student class.
