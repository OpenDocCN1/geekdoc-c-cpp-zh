> > **Note** A class hierarchy can be extended by adding new subclasses; however, the ndiscriminated union structure is closed and cannot be extended.

The DU introduces an interesting feature that is comparable to the class hierarchy. The *Shape* type
shown in Listing 6-30 can be viewed as an abstract base class, and the three union cases are three
subclasses derived from the base class.

Listing 6-33 shows how to use interface with the DU. One interesting point in this example is
that the different union case types are now unified by the interface. Different DU instances can now
be passed into a function that requires the *Shape* interface.

# **LISTING 6-33** DU with an interface

```
// define an interface
type IShape =
ababstract Area : double with interface

// DU with interface
type ShapeWithInterface =
| Circle of circle
| Triangle of double * double * double
| Rectangle of double * double
interface IShape =
| member this.Area =
| match with this
| Circle(r) -> r*r* System.Math.PI
| Triangle(a, b, c) ->
| let s = (a + b + c)/2
| sqrt(s, a) * (s - b) * (s - c)
| Rectangle(a, b) -> a * b
override this.toString() = "This is a ShapeWithInterface type"
```

```
let getArea2(shape:IShape) = shape.Area
getArea2(Circle(4.))
```
