# Convert from Seq/List/Array

Unlike C#, which uses a *from* prefix, F# uses an *of prefix to represent a function that converts from one collection to another. See List 1-54 for examples.

+   - Seq.ofList is used to convert a list to a seq
- Seq.Array is used to convert an array to a seq
- List.ofSeq is used to convert a seq to a list
- List.Array is used to convert an array to a list
- Array.ofSeq is used to convert a seq to an array
- Array.ofList is used to convert a list to an array

LISTING 1-54 Some seq, list, and array examples of conversion

```
let mySeq = { 1..5 }
let myList = [| 1..5 ]
let myArray = {|| 1..5 |}

// convert from list to a seq
let mySeqFromList = myList | Seq.ofSeq

// convert from an array to a seq
let mySeqFromArray = myArray | Seq.ofArray

// convert from a seq to a list
let myListFromSeq = mySeq | List.ofSeq

// convert from an array to a list
let myListFromArray = myArray | List.ofArray

// convert from a seq to an array
let myArrayFromSeq = mySeq | Array.ofSeq

// convert from a list to an array
let myArrayFromList = myList | Array.ofList
```

Of the three collection-related data structures discussed so far, sequence is likely the most interesting. A function that takes seq<T> as an input parameter works well with list, array, and map in F#. Additionally, if you expose seq to a C# project, a reference to Microsoft.FSharp.Core.dll will be required. Last, C#'s LINQ operations will work on sequences.
