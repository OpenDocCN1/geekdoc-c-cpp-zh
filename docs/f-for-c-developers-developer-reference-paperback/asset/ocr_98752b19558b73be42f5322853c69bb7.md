Listing 2-68 provides code that demonstrates how to use Event<T>, which is a simpler format. The underscore in the Event<T> definition is a placeholder that is used to inform the F# compiler to figure out the type information. If you compare these two Event implementations, they are different in the following:

+   - The Event<T> version is simpler.
- The Event<D, T> version adding FSharp.Core.dll as a reference. Otherwise, the compiler complains about not finding the type 'Microsoft.FSharp.Control.FSharpEventHandler1<T0> Event<D, T> does not need to reference to FSharp.Core.
- The sender value in MyHandler2 holds the sender instance, but MyHandler hides the information in the first element of the tuple.
