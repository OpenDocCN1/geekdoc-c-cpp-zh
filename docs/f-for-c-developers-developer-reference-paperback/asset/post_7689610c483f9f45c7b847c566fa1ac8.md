## Defining Method

A *method* is a function associated with a type. It can be called by a member method or a member function. If you define a property, you will not have any problem defining a method. In Listing 2-11, we define a *GetDistance* method. The *GetDistance* method needs to tell the compiler that your input parameter is a *Point2D* type. Type inference doesn't work in this case, we first access the property. The C# version of this is marked as virtual, and the code in Listing 2-11 is not a virtual. I will discuss how to define a virtual method in a later section.

## LISTING 2-11 Defining a member function

```
// define a Point2D class
type Point2D() =
    // define field x
    let mutable x = 0.0

    // define X property
    member this.X with get() = x
        and set(v) = x <- v

    // define Y property using an auto-implemented property
    member val Y = 0.0 with get, set

    // define a function to get the distance from the current point
    member this.GetDistance(point:Point2D) =
        let xDif = this.X - point.X
        let yDif = this.Y - point.Y
        let distance = sqrt (xDif**2 + yDif**2)
        distance
```

> Note The double star (**) operator is used to compute the exponential value of a given number, and the sqrt function is equivalent to *Math.Sqrt*.

Shipped with Microsoft Visual Studio 2010, C# introduced optional parameters and named parameter features. These two types of features are also available in F#. Listing 2-12 shows a C# version of *GetDistance* with optional parameters defined and its F equivalent. F# does not allow using default values after the parameter name; instead, it uses the *defaultArg* function. The *defaultArg* function takes the optional parameter as the first argument and the default value as a fallback value.

## LISTING 2-12 Using optional parameters

```csharp

{
    var xDif = this.X - x;
    var yDif = this.Y - y;
    var distance = Math.Sqrt(xDif * xDif + yDif * yDif);
    return distance;
}
```

```fsharp

## Defining a Static Method

We have converted the *field, property, and member* methods from C# to F#. We can now convert the static method *FromXY*. In C#, the *static* keyword is needed to define a static method. One approach to accomplishing this is to use a tuple, and another is to define two independent parameters. If you recall the design principle mentioned in the “Defining Tuples,” the “C# and F# Data Structures,” the tuple approach is a better choice because it requires both *x* and *y* to be passed. The F# code is shown in Listing 2-16.

## LISTING 2-16 Defining a method

```fsharp
// define a Point2D class
type Point2D() =
    // define field x
    let mutable x = 0.0

    // define X property
    member this.X with get() = x
        and set(v) = x <- v

    // define Y property using an auto-implemented property
    member val Y = 0.0 with get, set

    // define a function to get the distance from the current point
    member this.Distance(point:Point2D) =
        let xDif = this.X - point.X
        let yDif = this.Y - point.Y
        let distance = sqrt (xDif**2 + yDif**2)
        distance

    // define a static method to return a2D from (x,y) tuple
    static member FromXY(x:double, y:double) =
        let point = Point2D()
        point.X <- x
        point.Y <- y
        point
```

## Using Constructors

As a C developer, you might think that a constructor is nothing more than another function. If so, be prepared for something different. F# has two kind of constructors. One type is the primary constructor, whose parameters appear in parentheses after the type name. Whether or not you are surprised, realize that the set of parentheses after the type name is the parameter to the primary constructor! Another kind of constructor is an optional constructor, which starts with the new keyword. Any additional constructors must call the primary constructor.

That is a lot of information. Let's use the code in Listing 2-16 as a sample. F# treats all the code between the class name and first class member as initialization code. In the sample code, the let mutable x = 0.0 line of code is initialized when the class is created. If you put a printf statement after let and before any member function, you will see that the message is printed out.
