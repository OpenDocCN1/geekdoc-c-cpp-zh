# Exploring the HelloWorld Type Provider

If you understood the F# type-provider template in this section will be easy for you to follow. However, if any of the code type-provider example in the last section is not clear, the HelloWorld type provider example will provide some clarity. This type-provider example has five methods and five properties. Listing 5-3, which defines how users invoke the HelloWorld type provider, can be used to design and test the type provider.

**LISTING 5-3** HelloWorld type-provider script

```
# r @"\bin\Debug\HelloWorldTypeProvider.dll"

let assertFunction x =
    if not x then failwith "expression is false"

type T = Samples.ShareInfo.TPest.HelloWorldTypeProvider
let t = T()
asertFunction(t.Method1()) = 1
asertFunction(t.Method2()) = 2
asertFunction(t.Method3()) = 3
asertFunction(t.Method4()) = 4
asertFunction(t.Method5()) = 5
asertFunction(t.Property6) = "Property 6"
asertFunction(t.Property7) = "Property 7"
asertFunction(t.Property8) = "Property 8"
asertFunction(t.Property9) = "Property 9"
asertFunction(t.Property10) = "Property 10"
```

> Note In Listing 5-3, assert is the F# keyword to check for a TRUE/FALSE value, but it works only when the DEBUG symbol is defined. In the sample, a user-defined function named assert is used instead.

Create the Type Provider project using the Type Provider template with HelloWorldProvider as the project name. (See Figure 5-3.) The template, which can be downloaded from http://visualudiogallery.msdn.microsoft.com/43d0ff0d-1b9a-4581-a942-da85b6a83b9c, has four files created by default. The TypeProvider.fs file is the type-provider code will be placed.
