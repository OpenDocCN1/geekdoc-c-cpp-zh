# Separating Run Time and Design Time

The XML type provider shows how type providers handle design-time logic and run-time logic. Actually, design-time logic and run-time logic can be separated into different assemblies. The design-time DLL not only provides the design-time logic, it also inserts extra logic to change the final assembly's logic. Listing 5-45 shows the run-time DLL. The TypeProvider attribute is the key that indicates which DLL is the type-provider assembly.

> Note The run-time DLL and type-provider DLL should be located in the same folder.
