# In Closing

For C# developer, functional programming might not be a familiar concept. Chapter 1 to 3 introduced the imperative and object-oriented (OO) features. If you are planning to use F# in your project, do not have to dedicate three months to learning a new language from scratch. Instead, you can start to implement some from the material presented in Chapter 1 to 3. Chapter 4 to 6 introduced some F# features, such as type providers. Chapter 7 to 9 introduced a few F# applications. These chapters demonstrate how to solve complex problems using previous chapters.

Functional programming is not a silver bullet. F# is a language that provides both functional and OO features. Having knowledge in two areas is a perfect skill set for the C# developer to solve daily tasks efficiently. For example, LINQ feature in C#, which is a functional concept, attracts interest and dramatically changes the way developers write code. If you are curious and motivated to explore a new way, F# is a great candidate for further exploration.
