# Azure Blob Storage

The Azure blob service is used to store unstructured data whose size can be hundreds of gigabytes (GBs). A storage account can hold up to 100 TBs of blob data. The typical usage for blob storage is to store and share unstructured data as image, video, and audio files. You can also use it as a way to back up your data. Like the Azure Cloud queue service, it can be accessed anywhere using HTTP or HTTPS.
