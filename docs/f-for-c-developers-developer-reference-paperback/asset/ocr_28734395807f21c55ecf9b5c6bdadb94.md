# LISTING 4-52 Translating the latest news from English to Chinese with Microsoft Translator

```
// define the type provider
type Demographics = Microsoft.FSharp.Data.Providers.ODataService<ServiceUri = 
    "https://api.datamarket.azure.com/Gov/TravelAdvisoryService/"\let ctx = Demographics.GetDataContext()

// set the credentials
ctx.Credentials <- System.Net.NetworkCredential(<liveID>, <id>)

//get latest news
let latestNews = query {
for in ctx.LatestNewsFromFco
select (n.Title, n.Summary)
}

latestNews
| Seq.map fst // only leave title to translate
| Seq.map translate //translate from English to Chinese
| Seq.iter (fun n -> printf "%s" n)
```
