You get a prompt when you use the same code for UK embassies in the United States. The query does not return any results. It is hard to believe that the UK does not have at least one embassy in the country. The reason is that this query returns only part of the results. For performance reasons, it would not be a wise decision to query all at once. The query returns only one page of data for each query execution. The results shown in Listing 4-49 only include those from the first page of the data. This is a good time to use the skip operator to ignore the previously retrieved data and return the next page of the query results, as shown in Listing 4-50.

**LISTING 4-50** Finding all UK embassies or consulates in the United States using skip

```
// define the provider
type Demographics = Microsoft.FSharp.Data.Providers.ODataService-Uri = "https://api.datamarket.azure.com/uk.gov/TravelAdvisoryService"

let ctx = Demographics.GetDataContext()

// set the credentials
ctx.Credentials <- System.Net.NetworkCredential(<liveID>, <id>)

// query pages
let rec queryFunction(startPoint) =
    seq (
        // query the data source
        let q = query (
            for n in ctx.BritishEmbassiesAndHighCommissions do
                skip startPoint
                select (n.Title, n.OfficeHours) }
        if count < 0 then
            for item in q do
                yield item
        for item in queryFunction(startPoint + count) do
            yield item
    )

// print out the result
queryFunction(0)
|> Seq.filter(fun (title, _) -> title.Contains("United States"))
|> Seq.iter(fun (title, _) -> printfn "%s" title)
```
