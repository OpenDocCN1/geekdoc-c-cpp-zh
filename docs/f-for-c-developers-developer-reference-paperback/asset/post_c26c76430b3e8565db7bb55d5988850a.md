## Using Lazy Evaluation, Partial Functions, and Memoization

One of the functional programming features F# provides lazy evaluation or lazy computation. F# ships with a lazy keyword and a Lazy module that can be used to define lazy computations. The reason to use lazy evaluation is that the result is computed when it is needed. This can often improve performance.

The quickest way to define a lazy computation is to use the lazy keyword. Listing 6-126 shows a sample that demonstrates the syntax of the lazy keyword. From the execution result, you can see that the myLazyVariable has a type of Lazy<int>, where the int is the type from the expression (1+1). The actual value 2 is not created immediately.

- LISTING 6-126 The lazy syntax and sample

```fsharp
// lazy syntax variable = lazy ( expression )
let myLazy = lazy ( 1 + 1 )

// lazy variable with explicit type info
let a:Lazy<int> = lazy 1

Execution result
val myLazy : Lazy<int> = Value is not created.
val a : Lazy<int> = Value is not created.
```

When the computation value is needed, you can invoke the Force method. This causes the computation to be executed a single time. Additional calls to Force do not trigger the computation, but simply return the value that was computed during the first execution. Listing 6-127 shows how to use Force and how the variable state changes.

- LISTING 6-127 Force the computation on lazy

```fsharp
// define a lazy computation
let myLazy = lazy(1 + 1)
printf "myLazy is %A" myLazy

// force computation
let computedValue = myLazy.Force()
printf "computed value = %d" computedValue
printf "myLazy is %A" myLazy
```

Execution result

myLazy is 2
```

The lazy keyword is good at wrapping a value. For creating a lazy computation from a function, you can use Lazy.Create. Listing 6-128 computes the sum of a given number down to 0 using Lazy.Create.

## LISTING 6-128 Wrapping a function using Lazy.Create

```fsharp
// create a lazy computation from a function
let myLazy n = Lazy.Create (fun () ->
  let rec sum n =
    match n with
    | 0 -> 0
    | 1 -> 1
    | n -> n + sum (n - 1)
  sum n)

let lazyVal = myLazy 10
printf "%d" (lazyVal.Force())
```

> Note The preceding code can potentially cause a stack-overflow exception, because it is not recursive. The following code is a tail-recursive version, which won't cause a stack overflow.

```fsharp
let myLazy n = Lazy.Create (fun () ->
  let rec sum acc n =
    match n with
    | 0 -> acc
    | 1 -> acc + 1
    | n -> sum (acc + n) (n - 1)
  sum n)
```

Memoization is way to cache an intermediate result to speed up the computation. Memoization uses a lookup table such as Dictionary<TKey, TValue> to cache the intermediate computation result. Listing 6-13 shows the nonmemoization and memoization versions of Fibonacci code. For the performance data, you need to run "time" in FSI. From the execution result, the nonmemoization version takes much longer than the memoization version.

## LISTING 6-131 Memoization and memoization functions

```fsharp
// non-memoization version
rec fibonacci n =
match n
| 0 | 1 -> 1
| -> (fibonacci (n - 1)) + (fibonacci (n - 2))

// memoization version
rec fibonacci2=
let lookup = System.Collections.Generic.Dictionary<_, _>
fun n ->
match lookup.TryGetValue n with
| true, v -> v
| - ->
  let a =
    match n with
      | 0 | 1 -> 1
      | -> (fibonacci2 (n - 1)) + (fibonacci2 (n - 2))
  lookup.Add(n, a)
  a

## LISTING 6-132 A general memoization function

```fsharp
let mem f =
  let lookup = System.Collections.Generic.Dictionary<_, _>
fun n ->
  match lookup.TryGetValue n with
    | true, v -> v
    | _ ->
      let a = f n
      lookup.Add(n, a)
      a
```

```fsharp
let rec fibonacci3 = mem (fun n ->
  match n with
  | 0 | 1 -> 1
  | _ -> fibonacci3 (n - 1) + fibonacci3 (n - 2))
```

## LISTING 6-133 Memoization code template

```fsharp
let memorize wrapFunction =
  let cache = System.Collections.Generic.Dictionary<_, _>
  let rec x =
    match cache.TryGetValue x with
    | true, v -> v
    | false, _ ->
      let v = wrapFunction x
      cache.[x] <- v
      v
  x
```

let fib =
  memorize (
    fun F x ->
      if x < 2 then 1
      else f(x - 1) + f(x - 2)
  )
