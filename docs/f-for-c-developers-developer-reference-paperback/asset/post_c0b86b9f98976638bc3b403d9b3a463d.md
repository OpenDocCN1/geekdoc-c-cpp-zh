These are some of the Azure cloud queue operations used in the sample:

- Create a queue

```fsharp
let queueClient = storageAccount.CreateCloudQueueClient()
let queue = queueClient.GetQueueReference("myqueue")
queue.CreateIfNotExists()
```

- Add a message to the queue

```fsharp
let message = CloudQueueMessage("Hello, World")
queue.AddMessage(message)
```

- Peek at the message from the queue, and show the message as a string

```fsharp
let peekedMessage = queue.PeekMessage()
if (peekedMessage <> null) then
    let msg = queue.GetMessage()
    log msg.AsString("Information")
```

- Dequeue message

```fsharp
let msg = queue.getMessage()
queue.deleteMessage(msg)
```

To make this sample more interesting, I use a variable to specify the sleep time for the Thread.Sleep function. The sleep time is set dynamically by the current message count in the queue. If the message count is greater than 3, which means there are plenty of messages for the customer, the sleep time is increased by 100 ms. Otherwise, the sleep time is cut in half.
