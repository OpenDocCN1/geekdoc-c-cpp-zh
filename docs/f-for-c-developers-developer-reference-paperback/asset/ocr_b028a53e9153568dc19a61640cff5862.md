In Visual Studio, a DGML format file uses the representation of a graph. Listing 7-40 shows how to deserialize a graph from a DGML file using portable library functions. # LISTING 7-40 Deserializing from a DGML file

```
type DGMLReader(textReader:TextReader) =
let doc = XDocument.Load(textReader:TextReader)
let graph = Graph()
do
  let nodes = doc.Descendants() | Seq.filter(fun n -> n.LocalName = "Node")
  graphNodes =
  nodes | Seq.map(fun node -> graph.CreateNode(node.Attribute(XName.Get("Id"))))
)) | Seq.toList
let edges = doc.Descendants() | Seq.filter(fun n -> n.LocalName="Link")
edges | Seq.iteri(fun i edge->
  let fromNode = edge.Attribute(XName.Get("Source")).Value
  let toNode = edge.Attribute(XName.Get("Target")).Value
  ignore <| graph.CreateEdgeFromId(fromNode, toNode, i)
  )
  member this.Graph = graph
```
