
# Performing a merge sort

The merge sort is used to perform sorting in two stages:

- Divide the unsorted list into n sublists, each containing only one element
- Merge repeated sublists into new sublists until there is one remaining.

Listing 7-10 once again shows pattern matching. Note that in this section of the merge function, two cases have the same name but different data.

| | list, list |
| list, [] -> list |

One case is from list0, and the other is from list1. The pattern matching not only gives you the ability to decompose the data, but also the ability to unify the data as long as the cases have the same name.

# LISTING 7-10 Merging a sort sample

```fsharp
open System
// merge two list into one list
let rec merge list0 list1 =
    match list0, list1 with
    | [], [] -> []
    | [], list -> list
    | list, [] -> list
    | h0::t0, h1::t ->
        if h0 < h1 then
            [h0] @ merge t0 list1
        else
            [h1] @ merge list0 t

// merge sort algorithm function
let rec mergeSort list =
    match list with
    | [] -> []
    | [a] -> [a]
    | [a; b] -> [min a b; max a b]
    | _ ->
        let firstHalf =
            list
            | Seq.take(list.Length / 2)
            | Seq.toList
        let secondHalf =
            list
            | Seq.skip(list.Length / 2)
            | Seq.toList

        let sortedFirstHalf = mergeSort firstHalf
        let sortedSecondHalf = mergeSort secondHalf

        merge sortedFirstHalf sortedSecondHalf
```

# Merging two sorted arrays

You saw how to perform a merge sort on one array. This next algorithm (Listing 7-11) is used to perform a merge operation on two sorted arrays. The merge operation is performed in-place, taking advantage of the fact that in F#, array elements are automatically mutable.

LISTING 7-11 Merging two arrays

```fsharp
let (|Exhausted|_) i =
    if i < 0 then
        Some()
    else
        None i

let array1 = [| 1; 3; 4; 6; 9; 0; 0; 0; 0 |]
let array2 = [| 2; 3; 5; 8; 10 |]

let rec merge (i, j, k) =
    match i, j with
    | Exhausted, Exhausted -> ()
    | _, Exhausted -> ()
    | Exhausted, _ ->
        array1[k] <- array2[j]
        let i, j, k = i, (j - 1), (k - 1)
        merge(i, j, k)
    | _ ->
        if array1[i] > array2[j] then
            array1[k] <- array1[i]
            let i, j, k = (i - 1), (k - 1)
            merge(i, j, k)
        else
            array1[k] <- array2[j]
            let i, j, k = i, (j - 1), (k - 1)
            merge(i, j, k)

merge (4, 4, array1.Length - 1)
```

# Finding the maximum sum of an array

Listing 7-12 finds the largest sum of contiguous subarrays within a one-dimensional array of numbers. The Kadane algorithm is the typical solution for this problem. The execution result is 7. This sample again shows how to create F# code using the imperative programming style.

LISTING 7-12 Finding the largest sum of a contiguous subarray

```fsharp
let kadane data =
    let mutable maxV, max_currentPoint = 0, 0
    for i in data do
        max_currentPoint <- max 0 (max_currentPoint + i)
        maxV <- max maxV max_currentPoint
    maxV
```

If the array can be iterated as a cycle, you have to consider a second case where the maximum value is achieved through wrapping. Listing 7-13 solves this problem. The second case is used to find the range that affects the sum most. The rest of the array is a range that does not cross the boundary. If the sum of the range is greater than that, this is the result you are looking for.

LISTING 7-13 Finding the maximum sum in an array

```fsharp
let kadane data =
    let mutable maxV, max_currentPoint = 0, 0
    for i in data do
        max_currentPoint <- max 0 (max_currentPoint + i)

let kadaneCircle data =
    let mutable maxV, max_currentPoint = 0, 0
    for i in data do
        max_currentPoint <- max 0 (max_currentPoint + i)
        maxV <- max maxV max_currentPoint
    let sum = Seq.sum data
    let invertMax = 0 // placeholder for logic
    let kadaneValue = sum - invertMax
    max maxV kadaneValue
```

The median of two sorted arrays is another important attribute for a one-dimensional data set. The median is the value at which half of the array are below and half of the values are above. Listing 7-14 shows how to find the median from two arrays.

LISTING 7-14 Finding the median value from two arrays

```fsharp
let findMedian (list0:int list) (list1:int list) =
    let totalCount = list0.Length + list1.Length
    let rec findFunction (list0:int list) (list1:int list) count =
        if count > 1 then
            match list0, list1 with
            | [], [] -> fail "not possible, check empty"
            | head::tail, [] -> findFunction tail [] (count - 1)
            | [], head::tail -> findFunction [] tail (count - 1)
            | h0::t0, h1::t1 ->
                if h0 < h1 then
                    findFunction t0 (h1::t1) (count - 1)
                else
                    findFunction (h0::t0) t1 (count - 1)
        else
            match list0, list1 with
            | [], [] -> fail "not possible, check empty"
            | head::tail, [] ->
                let pre = head
                let now = list1[0]
                if totalCount % 2 = 0 then (float (pre + now)) / 2.0
                else float now
            | [], head::tail ->
                let pre = head
                let now = list0[0]
                if totalCount % 2 = 0 then (float (pre + now)) / 2.0
                else float now
            | h0::t0, h1::t1 ->
                if totalCount % 2 = 0 then (float (h0 + h1)) / 2.0
                else float (max h0 h1)

    if list0.IsEmpty && list1.IsEmpty then
        failWith "please input valid data"
    findFunction list0 list1 (totalCount / 2)

findMedian [1] [2; 4; 5; 6; 7; 8; 10]
```

> Note This sample uses a recursive function instead of a for/while loop. For some people, it is easy to understand, while others do not think it is so. The recursive function is very useful if you want to write code free free effects.

Here another way to get the medians from two arrays. If both medians are the same, you hit the jackpot and the median is the final result. If the median from array0, which is called median0, is smaller, the final result should be bigger and the search should continue on the elements equal to or greater than median0. If median is bigger, the search should continue on the elements equal to or smaller than median0, as you can see in Listing 7-15.

So let's get back to the question I presented the quick-sort sample in Listing 7-8: how do you decompose a data set in a customized way? The Median pattern used in Listing 7-15 decomposes the array into three parts:

- The left part, which contains all elements smaller than the median
- The median value
- The right part, which contains all elements greater than the median

# LISTING 7-15 Finding the median value from two sorted arrays (version 2)

```fsharp
let getMedian(list:float array) =
    let len = list.Length
    if len % 2 = 0 then
      (list.[len / 2 - 1] + list.[len / 2]) / 2.0
    else
      list.[len / 2]

let Median(list:float array) =
    let median = getMedian list
    let len = list.Length
    if len % 2 = 0 then
      (list.[0..len / 2], median, list.[len / 2..])
    else
      (list.[0..len / 2], median, list.[len / 2..])

let getMedianFromTwo(list0:float array) (list1:float array) =
    match list0, list1
    | [], [] -> 0.
    | [[a]], [[b]] -> (a + b) / 2.0
    | [[a0;..], [b0;..]] -> ((max a0 b0 + min a1 b1) / 2.0
    | Median(l0, m0, r0), Median(l1, m1, r1) ->
        if m0 = m1 then
            m0
        elif m0 < m1 then
            getMedianFromTwo r0 r1
        else //m0 > m1
            getMedianFromTwo l0 l1

let list0 = [1..; 4.; 7.; 8.; 9.; 10..]
let list1 = [2..; 4.; 6.; 7.; 9.; 10..]
let c = getMedianFromTwo list0 list1
```
