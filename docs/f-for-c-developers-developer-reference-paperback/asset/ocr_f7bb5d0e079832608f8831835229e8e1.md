LISTING 4-19 The *where* filter function performed on the client side

```
**where** filter function performed on the client side
let internal q3 = query
for n in db.Student
select n.Name

// filter on client side
let q2_2 = q3 | Seq.filter(fun n -> n.Length > 4)

showResult q3_2
```

Execution result
"Brent"
"Anita"
"Cathy"

Listing 4-20 is another example of filtering data on the client side. The code gives each element ID value and filters the results later according to this client-side-generated ID.

**LISTING 4-20** Filter based on a client-side-generated value

```
let internal myQuery = query {
for n in db.Student do
select n.Name

// filter on client side based on ID
let result =
myQuery
| Seq.map(fun i -> (i, n))
| Seq.filter(fun (i, n) -> i % 2 == 0)
| showResult
```

Execution result
(0, "Lisa"
(2, "Anita"
(4, "Cathy"
(6, "Zeoy"
(8, "John")

> **Note** The actual result you get might be different, depending on the targeted data storage.
