There is a subtle difference between NULL and None. First, F# classes and other reference objects do not accept NULL as a valid value. For example, the GetDistance function in Listing 2-16 cannot be passed NULL.

The fact that the F# function GetDistance cannot accept NULL as a parameter is not a bug. Actually, this is a carefully thought-out F# feature. Listing 6-12 shows how to check the user input in C# and F#. The C# code seems perfect until you realize that str can be null! So you have to first check that str != null and then perform the work. And this kind of error can be caught only at runtime. Many developers think about this error, but the errors are often missed. The person who implements read_string often assumes that the invoker should handle the NULL, and the compiler does not say anything if the NULL value is not being considered.
