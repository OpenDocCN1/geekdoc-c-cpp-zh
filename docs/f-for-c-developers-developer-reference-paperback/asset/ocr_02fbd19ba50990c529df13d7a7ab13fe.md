# TABLE 2-2 C# and F# constraints

| C# Constraint | F Constraint | Description |
|---|---|---|
| where T : struct | when T : struct | The type must be a value type. |
| where T : class | when T : not struct | The provided type must be a reference type. |
| where T : new() | when T : { new : unit -> 'a } | C# constraints requires the type to have a parameterless constructor and the new() constraint must be specified if there is another constraint. F# requires that the provided type have a default constructor. |
| where T : <base type name> | when T : type | The type argument must be derived from the specified base type. The type can be an interface. |
| where T : U | Not supported | The type argument supplied for T must be derived from the argument supplied for U. |
| Not supported | when T : null | The type needs to support the NULL value. |
| Not supported | when T or U : <member-signature> | At least one of the type arguments should have a member that has the specified signature. |
| Not supported | when T : enum<underlying-type> | The provided type must be an enum type that has the specified underlying type. |
| Not supported | when T : delegate<parameter-type,return-type> | The provided type must be a delegate type that has the specified arguments and return value. |
| Not supported | when comparison | The provided type must support comparison. |
| Not supported | when equality | The provided type must support equality. |
| Not supported | when T : unmanaged | The provided type must be an unmanaged. Unmanaged types are either primitive types (such as byte, byte, char, nativeint, unnativeint, float32, int16, uint16, int32, uint32, int64, uint64, or decimal), enumeration types, or a nongeneric structure whose fields are all unmanaged types.

> Note Unlike in C#, new -> does not need to be the last constraint.

F# handles the NULL value in a different manner, which will be discussed later. Therefore, the F# list, F tuple, function, F class, union type, and record type cannot be NULL. I will introduce the union and record types later. Listing 2-52 is the sample code that shows how NULL constraints are used. The general rule is if the type is from the Microsoft .NET Framework, the type always supports NULL. F# types do not support NULL unless specified.
