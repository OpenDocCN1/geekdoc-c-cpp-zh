```
Defining a CLimutable attribute in F# code
[-CLimutable]
type R =
{ X : int; Y : int }

// R2 does not have default constructor
type R2 =
{ X : int; Y : int }

C# code invoking the CLimutableService
var x = new R();
var x2 = new R2(0, 2);

```

Adding the default constructor not only enables support for XAML, but also makes the serialization story much easier. The Azure marketplace serialization example (shown in Listing 4-54) can be rewritten to a code as shown in Listing 6-29. The last line of the code uses structural comparison to make sure that the data is the same before and after the serialization.

# LISTING 6-29 Using a type provider in serialization

```
// define the type provider
type Demographics = Microsoft.FSharp.Data.TypeProviders.ODataService<ServiceUri = "https://api.datamarket.azure.com/Uk.Gov/TravelAdvisoryService/">
let ctx = Demographics.GetDataContext()

// set the credentials
ctx.Credentials <- System.Net.NetworkCredential(<liveID>, <id>)

// define a serializable record
[-CLimutable]
type NewsRecord = { Title : string; Summary : string }

// query the latest news
let latestNews = query {
for n in ctx.LatestTravelNewsFromCo
    select { NewsRecord.Title = n.Title; NewsRecord.Summary = n.Summary }
```

let news = latestNews |> Seq.ToArray
