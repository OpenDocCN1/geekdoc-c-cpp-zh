**Note** dumpbin.exe is used to check the exported functions from CUDA BLAS DLL. The cublas64_<version>.DLL is located in the directory <CUDA installation folder> C\common\bin. The result from dumpbin.exe can have two versions. For example, the cublasZdcal and cublasZdcal_2 functions are shown in the result list. It is recommended that you use the function with _2 suffix.

There are several overloaded functions in the cuBLAS library.
