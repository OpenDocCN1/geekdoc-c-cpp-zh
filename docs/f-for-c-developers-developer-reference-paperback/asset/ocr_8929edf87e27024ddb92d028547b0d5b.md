> Note The connect, query, and disconnect functions can be implemented as private functions in a class.

The class design is convenient for C# projects that need to reference the implementation of this design pattern in an F# project. However, the class is not necessary in an F#-only solution. Listing 3-27 shows how to use higher-order functions to implement the template pattern.

+   **LISTING 3-27** Template with a higher-order function

```
// connection, query, and disconnect functions
let connect(conStr ) = printf("connect using %s" conStr)
let query(queryStr) = printf("query with %s" queryStr)
let disconnect() = printf("disconnect")

// template pattern
let template(connect, query, disconnect) (conStr:string)(queryStr:string)=
connect(conStr)
query(queryStr)
disconnect()

// execute query
let queryFunction = template(connect, query, disconnect)

// execute the query
do queryFunction("<connection string>" "select * from tableA")
```
