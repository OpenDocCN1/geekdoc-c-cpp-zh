> Note Many items templates are listed in Figure 1-5. I'll introduce them later. For now, you need only an F# source file and an F# script file.

The primary difference between an F# source file and an F# script file is the build action. The F# source file is a file with an extension of .fs, its action is to Compile. The F# script file has an extension of .fs, and its build action is set to None, which causes it to go into the build process by default. No matter what file type you decide to use, you can always execute the code by selecting it and using the context (that is, right-click) menu option Execute Interactive. If you prefer coding, Alt+Enter is the shortcut key as long as the development profile is set to F#. This command stands for another menu option labeled Execute In Interactive. As its name suggests, the option is used to send one line of code to the FSI. The shortcut key for Execute Line Interactive is Alt+.

```
let mutable sum = 0.
for i in 1 to 100 do
    if i % 2 = 0 then
        sum <- sum + i
printf "sum of odd numbers from 0 to 100 is %d" sum
```
