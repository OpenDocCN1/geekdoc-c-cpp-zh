**Tip** The active pattern is a special function you can use to create a higher order function and use it in a match expression. The `parseNumber` function can be rewritten as follows:

```
let (Regex2|_) = (RegexMatch|_) "(\d{3})-(\d{3})-(\d{4})")
parseNumber str =
match str with
  | Regex2 out -> System.String.Join("", out)
  | Regex2 out -> System.String.Join("", out)
  | -> "Not supported format"
```

You might be wondering why I am introducing the active pattern if it is just a function in itself. If you combine the active pattern and pattern matching, the value of active pattern can be seen. The active patterns are part in the `match` statement, the `match` statement can make sure all the cases (data segments) are processes. If there is one case missing, there will be a compile-time warning generated.
