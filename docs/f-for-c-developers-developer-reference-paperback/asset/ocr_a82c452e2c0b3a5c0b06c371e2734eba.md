# Working with the And/Or Pattern and Pattern Grouping

The And/Or pattern combines two patterns with an AND/OR relationship. Listing 6-51 tests the point is on the axis using the AND pattern. All the patterns in the match list are OR-ed together; therefore, the OR pattern sample can be rewritten using pattern grouping, as shown in Listing 6-52.

# LISTING 6-51 And/Or pattern used to test a point

```
And pattern used to test a point
let testPoint2 point =
match point with
| x, y & 0 -> "original point"
| x, y & 0 -> "on x axis"
| x, y & _, 0 -> "on y axis"
| _ -> "other"
```

```
Or pattern
let testPoint3 point =
match point with
| x, y & (0, 0) -> "original point"
| x, y & (0, |, 0) -> "on x axis"
| _ -> "other"
```

# LISTING 6-52 Pattern grouping

```
let testPoint4 point =
match point with
| (x, y) & (0, 0) -> "original point"
| (x, y) & (0, _) -> (x, y) & (_, 0) -> "on x axis"
| _ -> "other"
```
