# LISTING 2-52 NULL constraints on some F# types

```
// generic type with NULL constraint
type MyClass<T> when 'T : null' () =
let a='T' = Unchecked.default<T>

// string array that can have NULL as a proper value
let b = MyClass<string>()

// sequence that can have NULL as a proper value
let b3 = MyClass<string> seq()

// string list that CANNOT have NULL as a proper value
let b2 = MyClass<string> list()

type MyRecord = { X : int; Y : string }
// record that CANNOT have NULL as a proper value
let b4 = MyClass<MyRecord>()

// .NET tuple as a constraint that can take NULL
let b5 = MyClass<System.Tuple<string,string>> ()

// string*tuple CANNOT have NULL
let b6 = MyClass<string*string> ()

// function int->int CANNOT have NULL
let b7 = MyClass<int->int> ()

type MyClass2() = class
end

// class My2 cannot be NULL
let b8 = MyClass<MyClass2>()
```

Listing 2-53 shows how to change the Point2D code to use generic constraints. Listing 2-54 shows how to define two type parameters in the generic type definition and how to use the *and* keyword to chain multiple constraints.

# LISTING 2-53 Generic constraints

```
// define a 2D location interface
type I2Location =
nabstract member X : float with get, set
abstract member Y : float with get, set

// define a IPoint2D interface
and IPoint2D =
inherit I2Location
abstract member GetDistance<'T when 'T : I2Location> : I2Location -> float
```
