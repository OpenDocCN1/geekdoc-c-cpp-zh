# LISTING 4-43 SQL union and intersection

```
SELECT * from Student
UNION
SELECT * from AnotherStudentTable

SELECT * from Student
INTERSECT
SELECT * from AnotherStudentTable
```

# LISTING 4-44 F# query union

```
let q0 = query { for student in db.Student select student.Name }
let q1 = query { for student in db.AnotherStudentTable do select student.Name }

// union two query results
q1.Union(q0)

// intersect two query results
q1.Intersect(q0)
```

SELECT student.Name,
