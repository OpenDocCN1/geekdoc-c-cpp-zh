# LISTING 6-64 Using try...finally

```
// try...finally sample
try
    <some exception thrown>
finally
    printf "ignore the exception and perform some clean up"
```

# LISTING 6-65 Implementing try...with...finally

```
// try...catch...finally
try
    try
        <some exception thrown>
    with _ -> printf "catch the exception"
finally
    printf "finally section executing..."
```

# Throwing Exceptions

F# provides a shortcut to throw exceptions using failwith or failwith. Both of these functions generate a System.Exception. The failwith function takes a string as a parameter, and failwith takes a string format, like printf, to generate a more sophisticated error message. The sample code is shown in Listing 6-66. Note that listing contains a compile warning that can be ignored.

# LISTING 6-66 The failwith and failwith examples

```
open System
try
    failwith "this is an exception"
    with : Exception as e -> printf "the exception msg is %s" e.Message
try
    failwith "this is an exception generated at %A" DateTime.Now
    with _ as e -> printf "the exception msg is %s" e.Message
```

> Note The last line can also be written with e -> printf "the exception msg is %s" e.Message
