# Exporting to Microsoft Excel

XML and JSON serialization are very useful to a programmer, but the result is definitely not for the average user. In Listing 4-55, I will show you how F# to write the cloud data into an Excel file. The sample retrieves the data from Azure, opens the Excel file, and inserts the title from cells B1 to B100 and the summary from cells C1 to C100.

**LISTING 4-55** Inserting the title and summary from Azure to Excel

```
open Microsoft.Office.Excel

// Run Excel
let app = new ApplicationClass(Visible = true)

// Create a new file, and get the 1 worksheet
let workbook = app.Workbooks.Add(xlWBATemplate.xlWorksheet)

// Note that worksheets are started from 1 not 0
let worksheet = (workbook.Worksheets[1] :? Worksheet)

// define the type provider
type Democrats = Microsoft.Sharp.Data.TypeProviders.ODataService<"https://api.datarket.azure.com/Uk/Gov/TravelAdvisoryService/">
let ctx = Democrats.GetDataContext()

// set the credentials
ctx.Credentials = System.Net.NetworkCredential(<liveID>, <id>)

// declare a Record class
type NewsRecord() =
    member val Title = System.String.Empty with get, set
    member val Summary = System.String.Empty with get, set

// query the latest news
let latestNews = query {
    for n in ctx.LatestTravelNewsFromFco do
    select (NewsRecord(Title = n.Title, Summary = n.Summary))
}
```
