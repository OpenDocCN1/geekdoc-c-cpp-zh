```
F# code
seq { 0..100 } //given data from 0 to 100
|> Seq.Filter (fun n -> n%2<>0) //data subset contains only odd number
|> Seq.sum //sum up
|> printfn "the sum of odd number from 0 to 100 is %A" //print out the result
```

When the F# code is shown side by side with C# equivalent, it is easy to tell that Seq.filter is a built-in function used to filter data and Seq.sum is a function to sum up the elements in a provided sequence. Because printfn, which originally needs two parameters, gets its second parameter from the pipe-forward operator (|>), it takes only one explicitly provided parameter.
