# LISTING 2-12 Using optional parameters

```
C# GetDistance with an optional parameter
// compute the distance to a given point
public double GetDistance(double x = 0, double y = 0)
{
    var xDif = this.X - x;
    var yDif = this.Y - y;
    var distance = Math.Sqrt(xDif * xDif + yDif * yDif);
    return distance;
}
```

```
F# GetDistance with an optional parameter
// define a function to get the distance from the current point
member this.GetDistance(?Value, ?Value) =
    // take the (xValue, yvalue) tuple and decide whether to use the default value
    let x, y = (defaultArg xValue, defaultArg yValue.)
    let xDif = this.X - x
    let yDif = this.Y - y
    let distance = sqrt (xDif**2 + yDif**2).
    distance
```

The optional parameter is exposed to a C# project, the C# project needs to reference Microsoft.Fsharp.Core.dll, which you can use to create the F# option types. See Listing 2-13.

# LISTING 2-13 Referencing the F# method with an optional parameter

```
F# code defining a method with an optional parameter
namespace MyClassNamespace

type MyClass() =
    member this.PrintValue(?value:int) =
        match value with
        | Some(n) -> printfn "value is %A" n
        | None -> printfn "sorry, no value"
```

```
C# code invoking an F# method with an optional parameter
static void Main(string[] args)
{
    var myClass = new MyClassNamespace.MyClass();

    myClass.PrintValue(new Microsoft.Fsharp.Core.FsharpOption<int>.None);
    myClass.PrintValue(new Microsoft.Fsharp.Core.FsharpOption<int>(1));
}
```
