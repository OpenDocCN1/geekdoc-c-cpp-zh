The generated random numbers result in a uniform distribution. If the random numbers de-need to be generated from a customized function, you can use an accept-rejection algorithm. This method is based on the observation that one can sample uniformly from the region under the graph of its density function. The algorithm works like this:

- Sample a point x from a distribution—for example, uniform distribution.
- Draw a line from x to the target function.
- Sample uniformly along this line starting from x. If the point is located outside the target function's distribution, reject it.

You can then use the filter to generate the agreed-upon value with the formula f(x), as shown in Listing 9-13.
