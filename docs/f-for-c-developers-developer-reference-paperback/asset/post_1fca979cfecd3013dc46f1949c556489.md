
## Dijkstra algorithm

The Dijkstra algorithm is another algorithm you can use to find the shortest path from a given point to all nodes in the graph. In Listing 7-45, the graph library is changed to host the shortest distance from the starting point.

# LISTING 7-45 Dijkstra algorithm

```
module DCMLGraph

open System

type Graph() =
  let mutable nodes = []
  let mutable edges = []

  member this.Nodes with get() = nodes
  member this.Edges with get() = edges
  member this.CreateNode(id) =
    match this.FindNode(id) with
      Some(n) -> n
      None ->
        let node = Node(this, ID = id)
        nodes <| [ node ]
  member this.CreateEdge(from, `to`:Node, id) =
    match this.FindEdge(id) with
      Some(edge) -> edge
      None ->
        let edge = Edge(this, `to`, ID = id)
        from.AddingOutgoing(edge)
        `to`.AddingIncoming(edge)
        edges <| [ edge ]
        Some edge
  member this.CreateEdgeFromID(from, `to`, id) =
    let fromNode = this.FindNode(from)
    let toNode = this.FindNode(`to`)
    match fromNode, toNode with
      Some(n1), Some(n2) -> this.CreateEdgeFrom(n0, n1, id)
      _ -> None
  member this.FindNode(id) =
    (nodes: List) |> Seq.find(fun n -> n.ID = id)
  member this.FindEdge(id) =
    (edges: List) |> Seq.find(fun edge -> edge.ID = id)
  member this.RemoveEdge(edge) =
    (edge.From).RemoveOutgoing(edge)
    (edge.To).RemoveIncoming(edge)
    edges <| edges | List.filter(fun n -> n <> edge)
  member this.RemoveNode(node) =
    node.OutgoingEdges |> node.IncomingEdges
    nodes <| nodes | List.filter(fun n -> n <> node)

Node(g) =
  let mutable incomingEdges = []
  let mutable outgoingEdges = []

member val ID = Unchecked.defaultof<> with get, set
member val Data = Unchecked.defaultof<> with get, set
member this.IncomingEdges with get() = incomingEdges
member this.OutgoingEdges with get() = outgoingEdges
member this.AddIncomingEdge(edge:Edge) = =
    if edge.ToNode is then
        incomingEdges <- incomingEdges |> List.append(edge)
member this.AddOutgoingEdge(edge:Edge) = =
    if edge.FromNode is then

let letters =
[

  '3', ['O', 'E', 'F']
  '4', ['A', 'G', 'H', 'I']

|> Map.OfList

let mutable currentState = ('0', -1)
let mutable result = System.Collections.Generic.List<>()

let output() =
  let char, times = currentState
  if times >= 0 then
    let l = letters.[char]
    let len = l.Length
    let c = l.[times%len]
    result.Add(c)
  else
    output()

let getInput (chs:char seq) =
  |> Seq.iter (fun ch ->
    let char, times = currentState
    if ch=char then
      currentState <- (ch, times+1)
    else
      output()
    currentState <- (ch, 0))

output()
result |> Seq.toList
```

**Shuffle algorithm** The algorithm in Listing 7-48 shuffles a sequence and generates a randomly shuffled list. In the algorithm code, it does not specify the type of the sequence. The use of an underscore (_) indicates the sequence element type can be inferred from the code usage.

**Reservoir sampling** Reservoir sampling is related to the processing of large amounts of data. The algorithm is another random-selection algorithm. The algorithm is trying to get N elements from a large data set, which is so big that it is not possible to hold it in memory. In the sample code, I will use a sequence as the incoming data.

The algorithm first tries to fill the result set with resultSize. Once the elements are successfully retrieved, the rest of the elements are selected randomly based on a uniform distribution from 0 to the current index. If the generated number is in the range of [0, resultSize], you can replace the result set's element with the new element, as shown in Listing 7-49.
