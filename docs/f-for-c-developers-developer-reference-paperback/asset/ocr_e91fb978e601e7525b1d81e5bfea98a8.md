# UsingAssemblyInfo

AssemblyInfo consists of all of the build options for the project, including the version, company name, GUID, compilers options, and other information. For a commercial application, this information is very important. Most of the file content consists of assembly-level attributes. The assembly-level attributes must be placed above a do binding. See Listing 2-69. You can use l69 to represent the ©. Additionally, as Visual Studio supports Unicode, you can actually put © in the string.

LISTING 2-69 AssemblyInfo

```
open System.Reflection
open System.Runtime.CompilerServices
open System.Runtime.InteropServices

// General information about an assembly is controlled through the following
// set of attributes. Change these attribute to modify the information
// associated with an assembly.
[assembly:AssemblyTitle("MyApp from XYZ Company")
[assembly:AssemblyDescription("MyApp")
[assembly:AssemblyConfiguration("\n[assembly:AssemblyCompany("XYZ Company")
[assembly:AssemblyProduct("MyApp")
[assembly:AssemblyCopyright("XYZ Company 2012. All rights reserved.")]
[assembly:AssemblyVisible(")]// Setting ComVisible to false make the types in this assembly not visible
// to COM components. If you need to access a type in this assembly from
// COM
```
