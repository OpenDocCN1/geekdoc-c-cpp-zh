
# 致谢

许多人为此书以及我完成写作的能力带来了决定性的影响。首先，我要感谢 Boost 社区贡献的这些令人惊叹的库。这些库和 Boost 社区的成员们（Booster）为 C++ 社区乃至整个软件行业带来了实实在在的改变。此外，还有很多人非常积极地支持了我的这项工作，我想在此对他们个人致以谢意。我难免会遗漏一些人：对于所有未提及的朋友，请接受我诚挚的歉意。感谢 Beman Dawes，你不仅开创了 Boost，还引荐我与 Addison-Wesley 合作。感谢 Bjarne Stroustrup，你提供了宝贵的指导，并指出了近乎完稿的稿件中重要的遗漏之处。感谢 Robert Stewart，你对本书进行了细致的技术和通稿编辑。Rob 让这本书变得更加连贯、易读和准确，而这一切都是在你的业余时间完成的！书中现存的技术错误应由我负责，而非 Rob。此外，Rob 在帮助读者即使作者偏离主题时也能保持阅读节奏方面，发挥了关键作用。感谢 Chuck Allison，你对我的写作目标给予了持续的鼓励和支持。感谢 David Abrahams 对此项工作的支持以及审阅方面的帮助。感谢 Matthew Wilson 对本书部分内容的审阅，以及你作为挚友的陪伴。感谢 Gary Powell 出色的审阅意见，以及你对这项事业非凡的热情。所有 Boost 库的作者都为这些库撰写了在线文档：没有这些绝佳的信息来源，撰写这本书几乎是不可能的。感谢你们所有人。许多 Boost 社区成员（Booster）以不同方式提供了帮助，特别要感谢那些审阅了本书各章节的人们。没有他们的帮助，关键要点将无法呈现，错误也会继续存在。Aleksey Gurtovoy、David Brownell、Douglas Gregor、Duane Murphy、Eric Friedman、Eric Niebler、Fernando Cacciola、Frank Griswold、Jaakko Järvi、James Curran、Jeremy Siek、John Maddock、Kevlin Henney、Michiel Salters、Paul Grenyer、Peter Dimov、Ronald Garcia、Phil Boyd、Thorsten Ottosen、Tommy Svensson 以及 Vladimir Prust，非常感谢你们！

特别感谢 Microsoft 公司和 Comeau Computing 为我提供了他们出色的编译器。

我还很荣幸与 Addison-Wesley 的两位优秀编辑共事。Deborah Lafferty 帮助我完成了所有初期工作，例如创建本书提案，并基本确保我处理好了许多此前并不了解的写作细节。Peter Gordon 在 Kim Boedigheimer 的得力协助下接手了本书的编辑工作，并带领它走向出版。此外，Lori Lyons 担任项目编辑，Kelli Brooks 担任文字编辑，也提供了进一步的协助。我要感谢他们所有人——是他们让这本书成为可能，并让它最终圆满完成。

多年来，朋友们和家人一直支持着我对 C++ 的痴迷；非常感谢你们始终在那里，始终相伴。

最后，衷心感谢我的妻子 Jeanette 和我们的儿子 Simon——我永远感激你们的爱和支持。我将永远竭尽全力，不负这份深情。
