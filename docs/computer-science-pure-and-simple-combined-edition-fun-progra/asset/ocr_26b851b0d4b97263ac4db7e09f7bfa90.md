# ## MicroWorlds Troubleshooting and Procedure Names

# ### Troubleshooting Guide

Make sure there are spaces between each word and between word and symbol, for example `colorunder = 15`

Make sure each procedure starts with **to** and ends with **end**.

Make sure there brackets [like these] around lists. List items are separated by spaces. For example:

```
setsh [horse1 horse2 horse3]
```

In the above example, note that the names **horse1**, **horse2**, and **horse3** contain no spaces. For words used as names or nouns (not procedure names, which are actions) make sure there are double-quote marks like this "**word**", or else put the words into a list with brackets. If the error message says "I don't know how to do word," then you have forgotten to label **word** as a noun by using either the quote marks or the brackets. So the computer thinks it is an action word. (Or perhaps **word** is a procedure name and you have forgotten to write the procedure **word**.)

If you can't figure out where the problem is in the program, insert some signal flags. Put lines into the code that show **OK** in several places. The program will print OK in the Command Center when it passes those spots. Then you will know where to concentrate your efforts, where it is not printing out. Remove these lines when you figure out the problem.

If your program isn't running right, it may be organized poorly. The logic of the sequence of things you are calling on the computer of. If necessary, look at the answers in the answer key.

If you use a built-in procedure by accident for one of your procedures or variable names, the program will not run.

If you get an error message about turtles, perhaps you forgot to hatch the turtles called for.

If you use a capital O instead of a zero (0), the program will not run.

If the error message says a procedure needs more inputs, concentrate on the line that calls that procedure and the one following, and look for the proper number of inputs and the proper number of opening and closing brackets.

If you run through this checklist and it still isn't working, try this: use **Cut** and **Paste** to move your code around the Procedures Page. This especially works if MicroWorlds is pretending not to see one of your procedures.
