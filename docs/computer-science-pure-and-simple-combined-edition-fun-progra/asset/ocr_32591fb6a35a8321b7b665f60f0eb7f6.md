to Main

```
cc
talkto "t1"
setsh [horse1 horse2 horse3]
repeat 20 [square]
end
```

If you have MicroWorlds EX, this won't work until you install the shapes horse1, horse2, and horse3 into your Shapes Center, as shown on page viii of this book.

This is a simple animation. It uses afresh (for set shape) and a list of turtle shapes. Now, every time the computer calls forward, it goes back to the shape list and picks the next shape. We have chosen shapes that are similar, but the legs are in different positions. Our square procedure calls to forward, and square is repeated, the computer keeps calling forward commands inside square and changing the shape according to the list. The result looks like a horse running. The shapes can be already given in MicroWorlds, or we can make them by clicking on a blank in the Shapes Center and using tools.
