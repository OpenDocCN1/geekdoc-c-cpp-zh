the number that we are going to make into a parameter instead of a “hard-coded” number is the 100 which is an input to random. It is this number that determines how much the direction of the turtle is changed. However, the number 50 is tied to 100. Remember, we had to subtract 50 from the result of 100 so that the turtle's heading could be changed by a positive or negative amount. How did we determine the number 50? It was half of 100, or half of the input to random. So we are going to divide our parameter in half.

We need to know how to divide one number by another number using Logo. A quick look in the Help Vocabulary shows us that divide is not there, but looking further turns up quotient, as shown below. You remember from your math class that quotient is a fancy word for the answer to a division problem.

quotient

quotient number1 number2

Reports the result of dividing number1 by number2. See /.

Example:

```
show quotient xcor 10
```
