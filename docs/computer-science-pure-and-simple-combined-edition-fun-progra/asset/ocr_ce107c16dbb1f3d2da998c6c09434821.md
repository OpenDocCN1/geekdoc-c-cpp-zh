What's that last line about? We are adding two numbers. One is the value stored in Var1, and the other is 15. Then we are printing the result. Your Command Center should say 20 50 35 35.

It is an excellent exercise to draw the jigsaw puzzle form of a line of instruction, especially before you run it. It can really help you learn what's going on. It is neat to see how the Logo procedures fit together with their inputs and outputs.

Try adding these lines to TestVar. Remember, sum has two inputs. Can you tell what they are doing?

```

```

# Talk like Logo

Another way to be sure you are understanding how a Logo instruction works is to "talk" your way through an instruction. I will do this one:

```
show sum 20 15
```

I am MicroWorlds Logo. I see the procedure show. This procedure tells me to take one input and put it on the Command Center. I need one input.

+   - I see the procedure sum. It has an output that I can use to satisfy my need for an input.
- first I need two inputs for sum before I can calculate the output.
- The inputs for sum are the two numbers 20 and 15.
- Now I have the output of sum, it is 35
- So now I can satisfy the input to show. I will put 35 on the Command Center.
