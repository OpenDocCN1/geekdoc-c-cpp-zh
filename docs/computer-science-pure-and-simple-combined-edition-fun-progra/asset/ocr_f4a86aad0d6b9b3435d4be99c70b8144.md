Here is mine:

```
launch [repeat 2000 [forward 3 direct readchar ] ]
```

Do you see how it works? Let's look at it from right to left. **Readchar** is taking one character of input from the keyboard. **Direct** is the procedure we make which needs one input (the keyboard character) and uses it to set the turtle's heading. Now, we have a little list of commands: go forward 3, then change the turtle's heading using **direct** and the keyboard input. We will repeat this little set of commands 2000 times, and we'll launch the whole process. This means that it will operate independently of other processes we might also launch.

Here's our version of **Main**. I have underlined the new code.

# to Main

+   - talk to turtle 1
- launch a process that repeats many times a call to go forward a little bit
- use readchar to collect info from the keyboard
- call direct, passing to it the information collected by readchar.
- launch [repeat 2000 [forward 3 direct readchar ] ]
