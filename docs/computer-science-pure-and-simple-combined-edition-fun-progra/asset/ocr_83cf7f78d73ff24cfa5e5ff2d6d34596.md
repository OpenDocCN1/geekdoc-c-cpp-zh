# Back to the Sandbox for Some Logic!

We need to construct a statement that means "it's not d, o, or g," that will be either true or false. So we need to look at these logical operators: and, not, and or.

Let's consider this Boolean statement (statement that is either true or false):

It is raining.

Let's use it like this:

```
(if it is raining) [take my umbrella].
```

If the Boolean statement in parentheses evaluates to true, then we take the action that follows. If it evaluates to false, we don't.
