# Using ycor

Way down at the bottom of the Index is **xcor** and **ycor**. **Ycor** looks like a very likely candidate, so let's look it up.

Go to Help, then Vocabulary

![](bbox=[0.3965, 0.16533, 0.66825, 0.31133])

On the left side of the page, you see an alphabet to help us look up the word we are interested in. Choose y.

![](bbox=[0.09125, 0.408, 0.17375, 0.44133])

+   - Stands for y coordinate. Reports the y coordinate of the current turtle.
- Given that there is a turtle on the page.
- See pos, sety, and m

This tells us that there is a built-in procedure **ycor** that has as an output the y coordinate (height on the screen) of the turtle. There is another procedure **sety** which takes a number as an input and presumably sets the y coordinate.
