# #19 Enhanced Wandering Turtle

In the exercise for the last lesson, we adjusted the smoothness of the line turtle is drawing. Do you remember how? We adjusted the input to random. Here’s an idea: why don’t change the program so that the user can more easily make that change? Let’s make the input to **random** into a variable. We can change its value by changing the number we pass to it from **Main**, just like we were doing by passing a value for `stepSize`.

# Decide on the Goal—Again

Our goal was to *slightly* change the direction the turtle is going and then take a step in that "direction." We will now enhance this goal.

New goal of **wander** : To change the direction the turtle is going, *based on a parameter to the procedure*. A parameter is a value passed to the variable. We already have one parameter, `stepSize`, passed from **Main**. We will call our new one *dizziness*. Our call to **wander** will be **wander 5**. Now it will be **wander 5 2**, for example. The first number goes into `stepSize` and the second number into `dizziness`.

![](bbox=[0.185, 0.395, 0.705, 0.605])

to **wander : :stepSize :dizziness** stores the 5 in `stepSize`, and the 2 in `dizziness`.

This new variable will make **wander** more flexible. The turtle will be able to move along, or less on track, and it will also be able to make more exaggerated turns, ending up going nowhere. We have to do is change the input numbers for **random**, which changes the input number for the **right** turn.
