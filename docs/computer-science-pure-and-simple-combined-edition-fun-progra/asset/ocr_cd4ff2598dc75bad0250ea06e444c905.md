# Pseudocode

We will work in this way: we will create pseudocode that solves our problem. Then we will translate lines of pseudocode into Logo, then test. We will build the program by doing this over and over, adding in features as we go.

Here's some pseudocode to start with:

```
to Main
;talk to turtle 1
;launch a process that repeats many times a call to go forward a little bit
;use readchar to collect info from the keyboard, and also
;call direct, passing to it the information collected by readchar
end
```

First, we will work on the first line of pseudocode. We'll need more information on launch. Do you remember the launch procedure from Book 1?

The Help vocabulary tells us about launch:

```
launch word-or-list-to-run
Runs the input as an independent parallel process. If the process is launched from the Command Center, the cursor reappears immediately. Use cancel, cancel the Cancel menu item, the Stop All menu item, or Ctrl+Break to stop the process. See also forever.
```

Example:

```
launch [glide 1000 1]
rt 90
lt 90
```
