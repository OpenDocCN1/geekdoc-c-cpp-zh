# #33 City III

Your City project should be working well now, except for the animations. Hatch four more turtles.
Let's write our animation for t2. Remember, this is how we set up an animation:

+   - Talk to that turtle. Show turtle (st); set heading (seth).
- Make your shapes if you want. Install them if you need to.
- Using shapeshape, or setsh, we give a list of shapes for a turtle to take, one after the other, for example, setsh [horse1 horse2]
- Next, we set up a shape that repeatedly calls forward. Each time forward is called, for example, repeat 10 [forward 3]
- Next, put in a pause to make the action more realistic. Use wait. For example, repeat 10 [forward 3 wait 1].

Use the shapes in the shape center (be scroll to see them all), change them, or create your own. To change or create a shape, double click on a shape or on a shape blank, and use the drawing tools. But will give you unique names. You can use two or three as action sequence. Here's how to create a shape that exists in order to paste it onto another shape blank and change it slightly: select the shape in the shape center (see a square around it). Hit control-c to copy it to the clipboard. Now select a shape blank. You see a square around it. Hit control-v to paste the shape. Double click on it to make your changes. You can change the shape's color using the fill bucket or a very fat line. If you are animating a vehicle, make its lights blink or change as it moves.

Now, to get each animation to work as an independent process, use launch. Launch works with repeat, like this:

```
talkto t2
launch [repeat 5000 [forward 3 wait 1]]
```

One more thing: we need to adjust setup to take into account the animating turtles. Add some lines to setup that do this:
;talk to t2, t3, t4 and t5,
;pull pen up, hide turtle
;set position at some starting point in your street. All these turtles can start at the same point.

And, don't forget to show turtle (st) in the animate procedure.

By the beginning of next class, get the animations to work, and finish the game. Draw a background, such as mountains or trees, using the drawing center tools.
