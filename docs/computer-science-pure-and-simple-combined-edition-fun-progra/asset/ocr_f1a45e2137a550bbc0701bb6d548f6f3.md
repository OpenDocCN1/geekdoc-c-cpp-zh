```
to Main
cc
talkto "t2"
setsh [dog1 dog2]
setsh 270
repeat 200
[walk 10 10]
talkto "t3"
setsh [skater1 skater2 skater3]
setsh 90
repeat 200
[walk 10 10]
end
```

When you try this program, you will see that the dog continues to do its thing properly, but the skater never moves. Perhaps the dog is walking too many times. Change your Main as follows:

```
to Main
cc
talkto "t2"
setsh [dog1 dog2]
setsh 270
repeat 5
[walk 10 10]
talkto "t3"
setsh [skater1 skater2 skater3]
setsh 90
repeat 200
[walk 10 10]
end
```

Try and let it run for a few minutes. First the dog correctly does its thing and then the skater does her thing. If you follow the lines in Main, this repeat procedure causes the program to run the following list of instructions [Walk 10 10] over and over and proceeds to the next line.

But what we really want is for a process to be launched making the dog walk and then for the program to continue to the next line and launch another process to make the skater, at the same time.
