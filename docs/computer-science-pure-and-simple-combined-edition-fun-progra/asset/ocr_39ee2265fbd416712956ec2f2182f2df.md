# #10 Logo Animation Using Variables

Now we will make use of our new knowledge of variables. First, type in the following. Save under
a new name. It should look like this:

```
====================
to Main
end
====================
to square
  repeat 4 [forward 50 right 90 wait 1]
end
to Start
  Main
end
```

Now it's time to add an action figure. I want you to add some lines to Main so it looks like this:

```
====================
to Main
  cc
  talkto "t1"
  setsh [horse1 horse2 horse3]
  repeat 20 [square]
====================
```

Put the horse1, horse2, and horse3 shapes into your Shape Center.
