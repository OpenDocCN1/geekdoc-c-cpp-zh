We now have a complete program! Main tells the computer what to do first, then next, and so on.
The procedures listed after Main tell the computer how to do the commands it doesn't know
already.

The first instruction in Main tells MicroWorlds to clear the Command Center. This is so we know
that any error messages we see are new ones. The next instruction in Main tells MicroWorlds which
turtle should perform the actions in the following instructions. It is not necessary to have that
instruction if there is only one turtle, but it improves the readability of our program, which is one of
gours.

The third line uses the built-in repeat which requires two inputs: a number and a list of instructions to repeat. We only have one instruction, so to make it a list you just put square brackets around it. We will be talking about lists later.

Try running your program by going to the Graphics Page and clicking your Start button. Now try
unning it in Presentation Mode by going to the View menu and clicking on Presentation Mode.
Then click the Start button. To get out of Presentation Mode, double-click on the black border.

One bit of house cleaning to. As this and other programs grow, your Procedures Page gets
very large. So do not waste time for procedures, you should keep them in alphabetical
order. To move around, highlight the whole procedure by putting the mouse button
down above it, holding it, and moving the cursor to the other side. Now go to the Edit menu,
and select cut. The lines seem to vanish. Really you have them on an invisible clipboard. Now
move the cursor where you want the lines to be, and from the Edit menu select paste. Presto,
the show up in the new spot! This cut and paste routine works in nearly all computer
applications. You can also use copy and paste if you want to make copies.

I usually do something special with Main to make it particularly easy to find, such as type double
