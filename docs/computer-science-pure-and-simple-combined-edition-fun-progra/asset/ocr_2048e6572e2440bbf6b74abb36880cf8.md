# Exercise

After you get the simplified program to work using the call to Main at the end of the loop (called a recursive call to Main), save your work. Now save it again in a different file, and see if you can get the program to loop using forever. Put that forever at the top of the series of steps in Main, with brackets [ ] around the steps. You will need to change two more things to provide a way to stop the loop, and the procedure animate. You will need to put the command stopall inside the animate procedure. If you find your program stuck in an infinite loop, press control-alt-delete keys at the same time to bring up a menu that allows you to shut down the MicroWorlds application and try again. After you play with it, put this exercise aside; it isn't the program we will move forward in the next lesson.
