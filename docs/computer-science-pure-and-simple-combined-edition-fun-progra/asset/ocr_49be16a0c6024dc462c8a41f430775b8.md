# #26 Race III

We're going to add some fun stuff to our game. Let's make a wild set of animations for winning.
Here's our requirement:

+   - When someone wins, nine turtles appear and run through animations, for example, a yellow ball to fire to a larger ball of fire to a largest ball of fire, and over again.
- Text appears announcing "You win!"
- When the animations are over and the user clicks Start, the game resets to original condition.

There's an easy way to take care of the multiple animations and the reset; we'll put the multiple animations on a different page. When someone wins, we go to that page. When someone clicks Start, we go back to Page1.

Here's how: Go to Page1. Under the Pages menu, select duplicate page. Now you have another page, Page2, that looks just like Page1. You can draw on it to make it somewhat different. You can add some text, such as "You win!!!" Hatch hatches all over the place. Keep track of how many you have. Go to the shapes center and make some shapes that go with your theme. You can copy digital pictures and paste them into the turtle shape blocks. Or you can make an explosion. Use the spray can and spray some red and yellow dots. For another shape, make the "explosion" bigger, and for a third, even bigger. You can also make a yellow disk. An animation could cycle through small to explosion to largest. Or the explosion could start small and get bigger, then repeat. Be sure to name your shapes so you can call them.

Remember how to set up an animation? Install shapes in your Shape Center if you need to. Talk to a particular turtle, an animation that isn't really moving, the turtle can move forward by a tiny amount each time, such as 0.01 turtle step (that's one-onehundredth of a turtle step).

Now you need to change win so it announces "You win," calls Page2, talks to a list of turtles (in brackets), sets shapes, and repeats a command to go forward a tiny amount. Test your new win by typing win in the Command Center from Page1. Does it work?

Now be sure to adjust setup that it goes back to Page1 to start the game over.

One more thing: on Page1 you can add a text box that says something like "This is a two-player racing game. Answer questions to win!"

Play your game! Use the Presentation Mode under the Gadgets menu. (To get out of Presentation Mode, click on the black surrounding area.)
