# 2.3 Keyword

# Concept

+   1. Keywords are the language specific, reserved and predefined words that cannot be used as the identifiers.

# Explanation

+   2. Every C# word is classified as either keyword or identifier.
+   3. All keywords have a fixed meanings and these meanings cannot be changed.
+   4. All keywords are lower-case.
+   5. for, do, while, break, case, if, else, int, char, public, class, union, try are some of the example of keyword.
+   6. A keyword is an essential element of a language definition.
+   7. If anybody wants to use keyword as the identifier then one has to use the "@" as the prefix of that keyword. For example, 'for' is a keyword if anybody wants to use it as identifier then one can do so by adding prefix @ to this like "@for".
+   8. C# has defined many keywords which are given listed in the following table :
