# 9. Declaring and using interface

Interface is declared using keyword ‘interface’. For using the interface it should be inherited as well as implemented in the deriving class.

# 10. Naming the interface

Interface types are usually named with a first letter I. There is no language-based constraint but it is a convention.

# Example

```
//Illustration of interface

using System;

interface IMedia
{
    void Publish();
}

class Book : IMedia
{
    public void Publish()
    {
        Console.WriteLine("This book is published now.");
    }
}

class InterfaceDemo
{
    static void Main()
    {
        IMedia midi = new Book(); // Create instance of class using interface reference.
        midi.Publish(); // Call method on interface.
    }
}
```

# Input

NIL

# Output

This book is published now.
