+   - A button is a control, which is an interactive component that enables users to communicate with an application. A button is something where user clicks to generate the command. When button is clicked, the code written for button gets executed. The text on the button, which defaults to "button1", can be changed. Anything suitable can be added here.
+   - The Button class inherits directly from the ButtonBase class. A Button can be clicked by using the mouse, ENTER key, or SPACEBAR if the button has focus.

# **Commonly used Button Properties**

| Property | Description |
|---|---|
| AutoEllipsis | Gets or sets a value indicating whether the ellipsis character (...) appears at the right edge of the control, denoting that the control text extends beyond the specified length of the control. (Inherited from ButtonBase.) |
| AutoSize | Gets or sets a value that indicates whether the control resizes based on its contents. (Inherited from ButtonBase.) |
| AutoSizeMode | Gets or sets the mode by which the Button automatically resizes itself. |
