```
int num1 = 101;

{

    Console.WriteLine("\nValue of num1 is greater than num2");
}
else
{
    Console.WriteLine("Inside the else block");
    Console.WriteLine("\nValue of num2 is greater than num1");
}

Console.WriteLine("\nOutside the if...else strucrure");
Console.ReadLine();
}
}
```

Input nil

Output

```
Inside the else block
Value of num2 is greater than num1
Outside the if...else structure
```

# 3.3. The if...elseif...else statement

# Concept

+   1. It is always legal in C# to nest if-else statements, which means one can use if or else if statement inside another if or else if statement(s).

# Explanation

+   2. The if...elseif...else statement is very useful in the case where user want to select a option from multiple options. In this type of statement 'if' is followed by one or more elseif statements and finally end with a else statement.
