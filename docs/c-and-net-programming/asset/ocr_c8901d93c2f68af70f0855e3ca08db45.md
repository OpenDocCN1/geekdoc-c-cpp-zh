+   - Even though any mobile application is written in Visual Basic .NET or C# .NET, and as such is managed code, one can still be able to incorporate functions and subroutines stored externally in dynamic link libraries (DLLs), including the Windows CE APIs. The .NET Compact Framework provides the data types and support for structures to allow easy use of functions from the Windows CE APIs into the application.

# **Some key features of CLR**

+   1. It employs CTS (Common Type System) to enable cross language support.

+   2. Uses JIT (Just In Time) Compiler to provide better performance.

+   3. Uses Garbage Collector for Memory Management.

+   4. Encapsulates Operating System features and exposes them as APIs, thereby making is simple to access OS level features.

+   5. It's Extensible, so that developers can write their own APIs to access Operating System features.

+   - Other native code files outside of the EE include NETCFAGL.dll for the GWES (Graphics, Windowing, and Events Subsystem) interface, which is the graphical user interface between the user, application, and the operation system, and CGACUTIL.exe for the Global Assembly Cache (GAC) manager.

+   5. **BCLs base class libraries :** The base class libraries are a subset of the full .NET Framework 1.0, providing roughly between 25 % to 30 % of the classes and functionality.

# **6. Platform specific class libraries : .NET Compact Framework Class Library**

+   - In order to create a robust programming environment for devices, the Compact Framework ships with a set of class libraries in assemblies organized into hierarchical namespaces similar to those found in the desktop Framework. However, there are four major differences between the class libraries shipped with the desktop Framework and those included in the Compact Framework.

+   - First, the Compact Framework libraries can rightly be thought of as a subset of the desktop libraries and, in fact, include just over 1,700 types, or roughly 25 % of the desktop Framework. Fig. 28.1.2 highlights the namespaces supported in the Compact Framework as a subset of those in the desktop Framework, where there is overlap. As a result, developers familiar with the desktop Framework should not expect all the functionality they are accustomed to.

+   - The .NET Compact Framework class library is a collection of reusable classes that tightly integrate with the common language runtime. Applications leverage these libraries to derive functionality.
