# 2. User Defined Exception

This type of exception is user generated, not system generated.

# Example - User define exception

```
Declare @val1 int;
Declare @val2 int;
BEGIN TRY
Set @val1=8;
Set @val2=@val1%2;
if @val1=1
Print 'Error Not Occur'
else
Begin
Print 'Error Occur';
Throw 60000,'Number Is Even',5
End

END TRY
BEGIN CATCH
Print 'Error Occur that is:'
Print Error_Message()
END CATCH
```

# Output

```
Error Occur
Error Occur that is:
Number Is Even
```

Here 60000 denotes the error number and 5 denotes the state to associate with the message.
