# 2. Destroying Threads

+   1. The **Abort()** method is used for destroying threads.
+   2. The runtime environment aborts the thread by throwing a **ThreadAbortException**. This exception cannot be caught and the control is sent to the *finally* block, if any.
+   3. Before invoking the Abort method it should made sure to check the thread’s **IsAlive** property.
+   4. Syntax

```
```csharp
If (Thread.IsAlive)
{
    Thread.Abort();
}
```
