# 6. If statement Syntax

```
if(Boolean expression)
{
Body of if statement
}
```

# Example

```
// Illustration of if statement
using System;
namespace CSharpSelection
{
class ifStatement
{
static void Main()
{
int num1 = 10;
int num2 = 12;
if (num1 < num2)
{
Console.WriteLine("Inside the if structure");
Console.WriteLine("\n Value of num1 is less than num2.");
}
Console.WriteLine("\nOutside the if strcuture");
Console.ReadLine();
}
}
}
```

Input Nil

# Output

Inside the if structure
Value of num1 is less than num2
Outside the if structure

/*In the above program the value of num1 is less than num2 so the condition of if statement will be true that is why statements present inside the body of if statement will be executed followed by the statements present outside the if block. */
