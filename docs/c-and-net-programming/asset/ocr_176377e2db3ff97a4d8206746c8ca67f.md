# 28.5.1.2 Packaging Step 2 - Creating Cabinet Files (CAB Files)

+   - Creating setups for a .NET Compact Framework application is similar to the approach used for other Windows applications. Application setups are delivered using cabinet files, more commonly referred to as "CAB" files, after their .cab file extension. CAB files serve two purposes namely,
+     1) They compress and store files so that they may be easily distributed;
+     2) They make sure that all of the files and settings required by an application are correctly handled.
+   - Once the project options are set, a CAB file can be created to deploy the application. VS .NET makes this easy by including a Build Cab File menu, accessible by right-clicking the project. Note that this process is different from that in the desktop Framework, where a deployment project that uses the Windows Installer can be added to the solution to package the application.
+   - When this option is invoked, VS .NET silently creates a .cab directory under the project directory on the developer's workstation. In this directory and within a directory identifying the build mode (Debug or Release) are placed a series of .cab files, each targeting a specific processor type, including ARM, ARM4, MIPS, SH3, and X86, and named accordingly, such as MyApplication_PPC_ARM.cab. To install the application on a device, the .cab file simply needs to be copied to the device and executed.

# Steps to create CAB file

The easiest way to create a CAB file for the application is to let Visual Studio .NET do all of the work. One of the features offered through Visual Studio .NET is a menu item within the IDE for generating CAB files.

# To build a CAB file for an application

+   1. Open the project of the application within Visual Studio .NET.
+   2. Select Release from the Solutions Configuration dropdown combo box.
+   3. On the Build menu, click Build CAB File.

Several command windows will be displayed briefly as the application is being built. When these windows are cleared then the CAB file is complete. It should be noted that there is no message or acknowledgement that is displayed to inform that the CAB file has been generated. After the last of the command windows is closed down, the user is taken back to the Visual Studio .NET interface indicating that CAB file work is done.
