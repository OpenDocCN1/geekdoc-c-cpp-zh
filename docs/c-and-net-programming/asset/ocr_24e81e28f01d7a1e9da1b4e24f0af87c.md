# 3.2.6 Miscellaneous Other Operators

# Concept

+   1. In C# there are several other operators which are used for performing language specific operations like type checking (operator type or operator 'is'), ternary conditional checking (operator ?), finding size of variable(operator sizeof), member access operator etc.

# Explanation

+   2. These operators are listed in below table.

| Operators | Description |
|---|---|
| ?: (Conditional operator) | Condition? x:y, If condition is true then return x otherwise return y. |
| . (access operator) | "." (dot) is used to access the member fields of methods of a class or object. |
| (type) Type conversion operator) | This operator is used to convert one data type to another data type. |
| 'sizeof' operator | Return the size of a data type. |
