# 9.1.2.4 Multiple Inheritance

In C# multiple inheritance is not supported for classes. That is one class can not inherit multiple classes. But one class is allowed to inherit single class and more than one interface. This is termed as multiple inheritance.

```
namespace MultipleInheritanceApplication
{
    interface IOP1
    {
        int Add(int n1, int n2);
    }
    interface IOP2
    {
        int Sub(int n1, int n2);
    }
    interface IOP3
    {
        int check_Even(int n1);
    }
    class Data_Operations : IOP1, IOP2, Ip3
```
