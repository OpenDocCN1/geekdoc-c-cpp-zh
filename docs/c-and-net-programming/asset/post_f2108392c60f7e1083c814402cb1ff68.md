
## 3. C# includes the following selection statements
- 1) If statement
- 2) If..else statement
- 3) If..elseif..else statement
- 4) Nested if statement
- 5) switch-case statement
- 6) nested switch-case statement

## 3.1. The if statement

### Concept
- 1. It allows the user to execute different path of logic on the basis of a given condition.

### Explanation
- 2. If statement is a most powerful decision making statement.
- 3. An if statement consists of a boolean expression followed by one or more statements.
- 4. If the condition is true the block of statements present in the body of if statement get executed and if condition is false then other set of statement after if structure get executed.
- 5. if statement Flowchart

![](img/3005a4307e6d8f3bb7e76eea28a92357_120_0.png)

### 6. If statement Syntax
```
if(Boolean expression)
{
Body of if statement
}
```

### Example
```
// Illustration of if statement
using System;
namespace CSharpSelection
{
class ifStatement
{
static void Main()
{
int num1 = 10;
int num2 = 12;
if (num1 < num2)
{
Console.WriteLine("Inside the if structure");
Console.WriteLine("\n Value of num1 is less than num2.");
}
Console.WriteLine("\nOutside the if structure");
Console.ReadLine();
}
}
}
```

Input Nil

### Output
Inside the if structure
Value of num1 is less than num2
Outside the if structure

/*In the above program the value of num1 is less than num2 so the condition of if statement will be true that is why statements present inside the body of if statement will be executed followed by the statements present outside the if block. */

## 3.2 The if.. else statement

### Concept
- 1. If..else statement contains the two blocks if block and else block.

### Explanation
- 2. An **if statement** can be followed by an optional **else statement**, which executes when the boolean expression is false.
- 3. When condition present in parenthesis of if statement is true then statements of if block are executed and if condition is false then statements of else block are executed.
- 4. if..else statement Flowchart

![](img/3005a4307e6d8f3bb7e76eea28a92357_122_0.png)

- 5. if..else statement Syntax
```csharp
if(Boolean expression)
{
    Body of if
}
else
{
    Body of else
}
```

### Example
```csharp
// Illustration of if-else statement

using System;
namespace CSharpSelection
{
    class ifelseStatement
    {
        static void Main()
        {
int num1 = 101;
int num2 = 121;
if (num1 > num2)
{
    Console.WriteLine("Inside the if block");
    Console.WriteLine("\nValue of num1 is greater than num2");
}
else
{
    Console.WriteLine("Inside the else block");
    Console.WriteLine("\nValue of num2 is greater than num1");
}

Console.WriteLine("\nOutside the if...else structure");
Console.ReadLine();
}
}
}
```

Input Nil

### Output
Inside the else block
Value of num2 is greater than num1
Outside the if...else structure

> /* In the above program num1 is not greater than num2 so condition get false, therefore, in this case else block will get executed followed by the statement present outside the if- else blocks */

## 3.3. The if...elseif...else statement

### Concept
- 1. It is always legal in C# to nest if-else statements, which means one can use if or else if statement inside another if or else if statement(s).

### Explanation
- 2. The if...elseif...else statement is very useful in the case where user want to select a option from multiple options. In this type of statement 'if' is followed by one or more elseif statements and finally end with a else statement.
- 3. The if...elseif...else statement Syntax
```
if(Boolean Expression)
{
Statements
..........
}
else if(Boolean Expression)
{
    Statements
    ........
}
else if(Boolean Expression)
{
    Statements
    ..........
}
.
.
else
{
    Statements
    ..........
}
```

### Example
```
// Illustration of ifelse-elseif statement
using System;
namespace CSharpSelection
{
    class ifelseifelseStatement
    {
        static void Main()
        {
            int num1 = 15;
            int num2 = 20;
            if (num1 == num2)
            {
                Console.WriteLine("num1 is equal to num2");
            }
            else if (num1 < num2)
            {
                Console.WriteLine("\nnum1  is less than num2");
            }
            else
            {
                Console.WriteLine("\nnum2 is greater than num1");
            }
            Console.ReadLine();
        }
    }
}
```

Input Nil

### Output
num1 is less than num2

/* In the above program the value of num1 is less than num2 so the condition present in parenthesis of 'else if' statement is true that is why the block of 'else if' will executed. */

## 3.4 The Nested if statement

### Concept
- 1. A nested if is an 'if' statement that is the target of another if or else statements.

### Explanation
- 2. When ‘if’ statement is used to do nesting of , ‘if..else if..else’ or ‘if..else’ or statements inside the other ‘if’ or ‘else if’ or ‘else’ statements that is known as nested if statements.

### 4. Nested if statement Syntax

```
if(Boolean expression)

........
if(Boolean expression)

..........

.....

{
..........
```

A nested if statement contains various structures like if.else statement inside if, if statement inside else etc.


Input Nil

So condition in outer if statement that is (num3>num1) is true so block of outer if statement will be executed and again the condition of inner if statement is also true so block of inner if statement will also be executed. */

## 3.5. The switch-case Statement

### Concept
- 1. The switch case statement is used for selection from multiple expressions like if..elseif..else statement but it is a better approach then if...elseif..if statement.

### Explanation
- 2. Switch statement contains a expression in its parenthesis which can be a number, a character or a string.
- 3. One switch statement is followed by several case statements.
- 4. The switch operator compares the expression to every value listed in the case labels in the body of the switch structure. If a match is found in a case label, the corresponding structure is executed (simple or complex). If no match is found, the default statement is executed (if one exists).
- 5. Switch-Case statement Flowchart

![](img/3005a4307e6d8f3bb7e76eea28a92357_128_0.png)

Fig. 4.2.4 Switch case statement

### 6. Switch-Case statement Syntax
```
switch(expression){
case constant1:
    statements
    .......
break;
case constant2:
    statements
    .......
break;
.
.
case constantN:
    statements
    .......
break;
default:
    statements
    .......
break;
}
```

- 7. Rules for switch-case statements
- 7.1. Expression present in parenthesis of switch statement must be char, byte, short, int, enum or String. Floating point value cannot be an expression.
- 7.2. Case constant must be compatible to the expression of the switch statement.
- 7.3. No case constant in one switch can have an identical value.
- 7.4. When the expression is equal to a case label, the statements following that case will execute until a break statement is reached.
- 7.5. Default is an optional statement which executed when expression does not match with any case label.

### Example
```csharp
// Illustration of Switch-case statement

using System;
namespace CSharpSelection
{
    class switchcaseStatement
    {
        static void Main()
        {
            int num1 = 2;
            switch (num1)
            {
                case 1:
                    Console.WriteLine("Value of num1 is 1");
                    break;
                case 2:
                    Console.WriteLine("Value of num1 is 2");
                    break;
                case 3:
                    Console.WriteLine("Value of num1 is 3");
                    break;
                case 4:
                    Console.WriteLine("Value of num1 is 4");
                    break;
                default:
                    Console.WriteLine("No match found");
                    break;
            }
            Console.ReadLine();
        }
    }
}
```
