# Q.8 What is the use of BinaryWriter and BinaryReader class ?

Ans. : BinaryWriter class is responsible for write primitive data types in binary to a stream and BinaryReader class is responsible for read primitive data types as binary value.

# Q.9 What is the difference between Peek () and Seek () ?

Ans. : Peek ( ) is used to Returns the next available character but does not consume it where as Seek ( ) is used to set the position within the current stream.
