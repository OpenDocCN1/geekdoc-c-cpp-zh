```
// Correct
public static const string ShippingType = "DropShip";
// Avoid
public static const string SHIPPINGTYPE = "DropShip";
```

8. Do not use Abbreviations. There are exceptions for certain abbreviations like abbreviations commonly used as names, such as Id, Xml, Ftp, Uri. It is consistent with the Microsoft's .NET Framework and prevents inconsistent abbreviations.

```
// Correct
UserGroup userGroup;
Assignment employeeAssignment;

// Avoid
UserGroup usrGrp;
Assignment empAssignment;

// Exceptional case
CustomerId customerId;
XmlDocument xmlDocument;
FtpHelper ftpHelper;
UriPart uriPart;
```

9. Do not use Underscores in identifiers. Exceptional case is when one may need to prefix private static variables with an underscore. It is consistent with the Microsoft's .NET Framework and makes code more natural to read. Also avoids underline stress of inability to visualize underscore.

```
// Correct
public DateTime patientAppointment;
public TimeSpan timeElapsed;

// Avoid
public DateTime patient_Appointment;
public TimeSpan time_Elapsed;
// Exceptional case
private DateTime _appointmentDate;
```

10. Do not explicitly specify a type of an enum or values of enums (except bit fields). It helps to avoid confusion when relying on actual types and values.

```
// Don'ts
public enum Alignment : long
{
    North = 10,
    East = 20,
    South = 30,
    West = 40
}
```
