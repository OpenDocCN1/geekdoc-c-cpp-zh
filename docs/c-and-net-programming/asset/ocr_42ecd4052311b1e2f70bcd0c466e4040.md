# 4.5 Miscellaneous Statements

# 4.5.1 Block Statement

# Concept

+   1. The block statement is used to group multiple segments of program which are logical related.

# Explanation

+   2. Block statement syntax

```
```csharp
{
}
```
```

# Example

```
```csharp
//illustration of block statement
namespace CSharpStatements
{ //Begin Statement
    class BlockStatement
    { // Begin Statement
        static void Main(string[] args)
        { //Begin Statement
            int num, power;
            num = 5;
            power = num * num;
            Console.WriteLine(power);
            Console.ReadLine();
        } // End Statement
    } // End Statement
} // End Statement
```
```

Input nil

# Output

25

# 4.5.2 Empty Statements

# Concept

+   1. Empty statement is used when there is no need to perform an operation where generally a statement is required.

# Explanation

+   2. It simply transfers control to the end point of the statement.
