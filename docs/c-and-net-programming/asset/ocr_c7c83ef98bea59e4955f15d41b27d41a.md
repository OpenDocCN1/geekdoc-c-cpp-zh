# Deconstruction

Individual members of a ValueTuple can be retrieved by deconstructing it. A deconstructing declaration syntax splits a ValueTuple into its parts and assigns those parts individually to newly created variables.

```
static void Main(string[] args)
{
    // change property names
    (int Aid, string FNm, string LNm) = GetCitizen();
}
static (int, string, string) GetCitizen ()
{
    return (Id:1, FName: "Ravi", LName: "Wani");
}
```

# 'var' can be used instead of explicit data type names.

```
static void Main(string[] args)
{
    // use var as datatype
    (var CId, var CFName, var CLName) citizen = GetCitizen();
}
static (int, string, string) GetCitizen()
{
    return (Id:1, FName: "Ravi", LName: "Wani");
}
```

ValueTuple also allows "discards" in deconstruction for the members that are not going to be used.
// using discard _ (a underscore symbol) for the unused member LNm
(var Aid, var FNm, _) = GetCitizen();

# Two Marks Questions with Answers

Q.1 What are differences between system.stringbuilder and system.string ?

Ans.: The main differences between system.stringbuilder and system.string are :

+   - system.stringbuilder is a mutable while system.string is immutable.
+   - Append keyword is used in system.stringbuilder but not in system.string.

Q.2 What are tuples in .Net ? How many elements a tuple can hold ?

Ans.: A tuple is a fixed-size collection that can have elements of either same or different data types. The user must have to specify the size of a tuple at the time of declaration just like arrays.
