# 3. To use regex for email validation

For validating multiple emails, following regular expressions can be used. Emails are separated by using delimiter ','

^((\w+[.+_]?\w+)*@\w+[.-]?\w+)*\.\w+[.-]?\w+)*\s*[,|;]{0,1}\s*)+$
To use delimiter ';' below pattern would be used,
^((\w+[.+_]?\w+)*@\w+[.-]?\w+)*\.\w+[.-]?\w+)*\s*[;]{0,1}\s*)+$
and to use both delimiter ',' and ';' then below can be used,
^((\w+[.+_]?\w+)*@\w+[.-]?\w+)*\.\w+[.-]?\w+)*\s*[,|;]{0,1}\s*)+$
