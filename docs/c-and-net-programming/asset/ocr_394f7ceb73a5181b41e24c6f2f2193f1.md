# 7. Assemblies provide better code management and maintenance.

When **Componentization is used**, if a code change is required one need to change the component code and compile it. There is no need to change all the reference of code for minor change. This saves lot of maintenance time.

# 26.1.4 Providing High Security to Assembly

Security can be provided to assembly with the help of **File Signing Tool, signcode.exe**. It attaches a publisher's digital signature to assembly.

**Assembly can be signed with both Strong Name Tool and the File Signing Tool.**

When both Strong Name Tool and the File Signing Tool it should made sure that Strong Name Tool is used before using the File Signing Tool.

# 26.1.5 Assembly Manifest

+   1. Assembly Manifest contains the metadata for the assembly.
+   2. Assembly Manifest contains
+      - Name and Version Information of Assembly.
+      - Files (or Resource) that are made up the assembly.
+      - Set of permissions required for the assembly to run properly.
+      - And few other details depends on assembly.
+   3. Use of Assembly Manifest

When the Common Language Runtime (CLR) loads an assembly, it first reads the manifest to get the information regarding assembly.

# 26.1.6 PE Files (Portable Executable (PE) File) Format

# Concept

The Portable Executable (PE) format is a file format for executables, object code, and DLLs, used in 32-bit and 64-bit versions of Windows operating systems so as to load and execute the file by Windows.
