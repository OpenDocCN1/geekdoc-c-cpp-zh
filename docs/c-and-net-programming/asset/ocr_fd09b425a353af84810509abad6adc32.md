8. Do use implicit type var for local variable declarations except for primitive types (int, string, double, etc) for which predefined names can be used. It avoids mess, particularly with complex generic types. Type is easily detected with Visual Studio tooltips.

```
```csharp
var stream = File.Create(path);
var customers = new Dictionary();

// Exceptional case
int fileId = 250;
string timeLog;
bool isIssued;
```
```

9. Do use noun or noun phrases to name a class as it is easy to remember.

```
```csharp
public class Book
{
}

public class BookPublisher
{
}

public class BookAuthor
{
}
```
```

10. Do prefix interfaces with the letter I. Interface names are noun (phrases) or adjectives.

This goes consistent with .NET framework.

```
```csharp
public interface IDimension
{
}

public interface IDimensionGroup
{
}

public interface ICollection
{
}
```
```

11. Do name source files according to their main classes. This makes sense as files are alphabetically sorted and partial classes remain adjacent which is consistent with the Microsoft practices. Exceptional case is, file names with partial classes reflect their source or purpose, e.g. designer, generated, etc.

```
```csharp
// Located in Log.cs
public partial class Log
{
    //...
}
// Located in Log.processed.cs
```
