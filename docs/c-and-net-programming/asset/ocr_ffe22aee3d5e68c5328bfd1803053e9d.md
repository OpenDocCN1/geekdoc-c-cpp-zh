# SQL server - What happens when exception occurred in SQL server ?

+   - In SQL Server, whenever an exception occurred, it displays the exception message and then continues the program execution. That is it display the error part and continues further which should not happen.

# Exception handling in SQL Server

+   - Handling exceptions in a programming language needs stopping the abnormal termination and allowing the statements which are not related to the error to execute but handling an error in SQL Server means stopping the execution of the statements which are related to the error.
+   - With the introduction of Try/Catch blocks in SQL Server 2005, the error handling in the SQL server is now very much similar to programming languages like C#.
