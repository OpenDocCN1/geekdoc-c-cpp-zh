# ## 7.1 Structures

# **Concept**

In C#, a structure is a value type user defined data type that can contain different members as variable, method, properties etc.

# **Explanation**

+   1. Structures are value type and they are stored on the stack memory.
+   2. Structure helps to make a single variable hold related data of various data types.
+   3. The struct keyword is used for creating a structure.
+   4. Structures are used to represent a record.
+   5. For using structure it should be defined first and then used. Following steps are taken to use the structure in the program.

# ### 5.1 Defining a structure

To define a structure, ‘struct’ statement is used. The struct statement defines a new data type, with more than one member.

# **Syntax**

```
struct structure_name
{
data-member 1;
data-member 2;
data-member 3;
.
.
}
```

# **Example**

```
struct Book
{
        public string title;
        public string author;
        public string subject;
        public int book_id;
};
```
