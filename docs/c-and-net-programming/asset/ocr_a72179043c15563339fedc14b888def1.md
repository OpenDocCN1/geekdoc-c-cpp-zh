# 6. Switch-Case statement Syntax

```
Switch(expression){
case constant1:
    statements
    .......
break;
case constant2:
    statements
    .......
break;
.
.
case constantN:
    statements
    .......
break;
default:
    statements
    .......
break;
}
```
