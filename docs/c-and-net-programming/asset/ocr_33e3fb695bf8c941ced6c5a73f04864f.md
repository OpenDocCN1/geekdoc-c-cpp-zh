```
# Parsing the attributes

An attribute of type XmlNodeType.Attribute, can be parsed in the fashion shown above. More elegantly however, when an XmlNodeType.Element type is found, one can iterate through attributes using XmlTextReader.MoveToNextAttribute :

```
```csharp
case XmlNodeType.Element:

Console.Write("<" + reader.Name);
while (reader.MoveToNextAttribute())
{
Console.WriteLine(reader.Name+" = "+reader.Value);
}
break;
```
```

Now, if it is fed in this XML:

```
```xml
<book first="1" second="2">Programming</foo>
```
```

The output is,

```
```xml
<book first="1" second="2">Programming</book>
```
```

Earlier, the attributes were ignored, and output was,

```
```xml
<book>Programming</book>
```
```

Note that, if an element does not contain any attributes, the loop is never started. This means that there is no need to first check to see whether there are attributes. The number of attributes on a node can be found using the AttributeCount property.
```
