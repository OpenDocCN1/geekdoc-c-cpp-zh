# CAB File Output

Output from this CAB-building process is stored in a directory located under application's directory. The individual CAB file can be found under the subdirectory \bin\release. At this point, appropriate CAB file can be copied to the target device, open up File Explorer on the device, tap on the CAB file and the application would be installed. It should be note that, for the application to be able to run, the .NET Compact Framework and, if required, SQL Server CE has to be installed on the device.

# 28.5.2 .NET Compact Environment - Application Deployment

After a Compact Framework application has been packaged into a .cab file, it must be deployed and installed on the device.

# 28.5.2.1 Techniques for Deploying Application

There are several techniques for deploying application, including using ActiveSync, a Web site, a storage card, a file share, and even creating an auto-updating application.

+   1. Using ActiveSync : This is most obvious option for deploying a Compact Framework application is to allow the application to be installed when the device is cradled using the ActiveSync software typically used to synchronize files and e-mail. To do so, the application must be registered with the ActiveSync Application Manager installed on the desktop machine. This process is relatively simple; it requires creating a custom setup executable that invokes the Application Manager on the workstation with ActiveSync installed and passing it an .ini file that contains information about the application to install.
+   
+   2. Using a Web Site : The second option for deploying and installing a Compact Framework application is to use a Web site. Using this option, an organization could create Internet or intranet site that contains links to the various .cab files created for the application. This option has the benefit of not requiring the device to be cradled in order to install software. When a user navigates to the Web page using Pocket Internet Explorer, user can tap on the required .cab file. The resulting dialog allows the file to be downloaded and opened. Opening the file after download is equivalent to executing the .cab file on the device and will cause the application to be installed. It should be noted that, regardless of how the .cab file reaches the device, the installation software on the device automatically deletes the .cab file once the installation is complete. To prevent this from happening, the .cab file can be marked as read-only.
