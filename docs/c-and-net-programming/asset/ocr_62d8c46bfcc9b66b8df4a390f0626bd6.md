3. Creating a virtual directory by using IIS Manager

![](bbox=[0.1, 0.34, 0.96, 0.77])

Fig. 21.11.5 Web application virtual directory settings

3.1. In IIS Manager, expand the local computer and the Web site to which virtual directory is to be added.

3.2. Right-click the site or folder in which the virtual directory is to be created, click New, and then click Virtual Directory.

3.3. In the Add Virtual Directory dialog box, at least enter information in the Alias and Physical path and then click OK.

4. By default, Internet Information Server uses configuration from Web.config files in the physical directory to which the virtual directory is mapped, as well as in any child directories in that physical directory.
