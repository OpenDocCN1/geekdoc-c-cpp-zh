# ## 12. Nested try-catch

+   - The nesting of try catch blocks is supported in C#.
+   - In the nested try catch block, an exception will be caught in the catch block that follows the try block where an exception occurred.
+   - If there no inner catch block with appropriate exception type, then exception will flow to the outer catch block until it finds the appropriate exception filter. This advantage for inner try block that it can make use of catches of outer try block.
