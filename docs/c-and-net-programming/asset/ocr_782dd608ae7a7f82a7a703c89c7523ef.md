# 4.1 Default Constructor

A constructor without any parameters is called a default constructor that is default constructor does not take any parameters.

The limitation of default constructor is that every instance of the class will be initialized to the same values.

# Example

```
```csharp
using System;
namespace Constructors
{
class DefaultConstructor
{
int n1,n2;
public DefaultConstructor() //default contructor
{
n1 = 300;
n2 = 450;
}

public static void Main()
{
DefaultConstructor obj = new DefaultConstructor (); //an object is created , default
constructor is called
Console.WriteLine("Addition is : " + (obj.n1 + obj.n2));
}
}
}
```
```

# Input

# Output

Addition is : 750
