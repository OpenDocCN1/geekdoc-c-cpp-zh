# 6.1.2.5 Param Array

# Concept

While dealing with the method when it is not sure about the number of parameters of the method then Param array can be is used effectively.

# Explanation

Param array is used to pass unknown number of parameter to a method.

# Example

using System;

{
class Paramarray

static int multiply(params int[] numbers)

int product = 1;

product = product * n;
}
return product;
}
