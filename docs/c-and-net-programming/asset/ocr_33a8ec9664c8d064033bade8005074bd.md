# 10. Multiple catch blocks

+   - It is quite possible that a block of code raises multiple exceptions and hence there is a need of multiple catch blocks.
+   - Multiple catch blocks would help to segregate the exceptions and handle them in different ways individually.
+   - Multiple catch block with different exception types, would help to display the appropriate message to the user, depending upon the error and so the user that does not repeat the same mistake again.
+   - A multiple catch block with the same exception type is not allowed. It generates compile time error.
+   - A strong suggestion - Place more specific catch statement first and move down with more Generalized Exceptions.

# Syntax

```
try
{
    // statements causing exception, that may raise multiple exceptions.
}
catch( ExceptionName e1 )
{
    // Exception handling code
}
catch( ExceptionName e2 )
{
    // Exception handling code
}
catch( ExceptionName eN )
```
