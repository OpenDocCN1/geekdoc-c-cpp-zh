# 13.1.2.9 Pointers and Arrays

In C# array elements can be accessed by using pointer notations as shown in below program.

```
using System;
class DemoClass
{
    public unsafe void Method()
    {
        int[] iArray = new int[10];
        for (int cnt = 0; cnt < 10; cnt++)
        {
            iArray[cnt] = cnt * cnt;
        }
        fixed (int* ptr = iArray)
            Display(ptr);
        //Console.WriteLine(*(ptr+2));
        //Console.WriteLine((int)ptr);
    }
    public unsafe void Display(int* pt)
    {
        for (int itr = 0; itr < 14; itr++)
        {
            Console.WriteLine(*(pt + itr));
        }
    }
}
class UseDemo
{
    public static void Main()
    {
        DemoClass dc = new DemoClass();
        dc.Method();
    }
}
```

# 13.1.2.10 Pointers and Structures

The structures in C# are value types. The pointers can be used with structures if it contains only value types as its members. This is illustrated in below program.

```
using System;
struct DemoStruct
{
    public int n1;
```
