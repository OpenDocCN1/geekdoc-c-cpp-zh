# 5. Lvalue and Rvalue Expressions in C#:

+   5.1)There are two kinds of expressions in C#

+       5.1.1) **lvalue** - An expression that is an lvalue may appear as either the left-hand or right-hand side of an assignment.

+       5.1.2) **rvalue** - An expression that is an rvalue may appear on the right- but not left-hand side of an assignment.

+   5.2)Variables are lvalues and hence they may appear on the left-hand side of an assignment.

+   5.3)Numeric literals are rvalues and hence they may not be assigned and can not appear on the left-hand side.

+   5.4)Following is a valid C# statement :

```
    int no = 28;
```

But following is not a valid statement and would generate compile-time error:

```
    10 = 20;
```

# 6. Size of the variable

+   6.1)To get the exact size of a type or a variable on a particular platform, one can use the **sizeof** method.

+   6.2)The expression *sizeof(type)* yields the storage size of the object or type in bytes. Following is an example to get the size of *int* type on any machine,

```
    sizeof(int)
```
