| Operator | Description | Example |
|---|---|---|
| -= (subtract and assignment operator) | Subtract the value of right operand from the left operand and then assign the result to left operand. | x -= y; subtract the value of y variable from x variable and assign its result to x variable. |
| /= (divide and assignment operator) | It performs division by taking left operand as numerator and right operand as de-numerator and assigns the result to left operand. | x /= y; divide the value of y variable by value of x variable and assign its result to x variable. |
| *= (multiply and assignment Operator) | It performs multiplication between left operand and right operand and then assigns the result to left operand. | x *= y; multiply the value of y variable and x variable and assign its result to x variable. |
| %= (modulus and assignment operator) | It finds out the modulus of two operands and then assigns the result to left operand. | x %= y; find the modulus of values of x and y variables and then assign the result to x variable. |
