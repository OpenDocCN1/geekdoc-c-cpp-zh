+   3. **Enhanced Performance** - Generic has a performance advantage because it removes the possibilities of boxing and unboxing. Using value types with non-generic collection classes result in boxing and unboxing overhead when a value type is converted to reference type and vice-versa.

In the following example, the ArrayList class stores objects and the Add() method is defined to store some integer type argument. So an integer type is boxed. When the value from ArrayList is read using the foreach statement, unboxing occurs.

```
ArrayList obj = new ArrayList();
obj.Add(50);   //boxing-convert value type to reference type
int data= (int)obj[0]; //unboxing
foreach(int cnt in obj)
{
    Console.WriteLine(cnt);  // unboxing
}
```

Instead of using objects, a Generics type of the TestClass<T> class is defined as an int, so an int type is used inside the class that is generated dynamically from the compiler. Therefore boxing and unboxing no longer occurs as in the following;
