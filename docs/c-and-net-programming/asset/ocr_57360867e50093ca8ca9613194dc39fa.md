+   - The .NET Compact Framework types enables to accomplish a range of common programming tasks, including tasks such as interface design, leveraging XML, database access, thread management and file I/O.

# Some Key Class Libraries are,

+   1. Windows Form - For developing windows client application.
+   2. Base Classes - Enables advance features that is Threading, Network resources etc.
+   3. GDI - Basic support for GDI for building graphics.
+   4. Data and XML - Enables easy handling of Data and XML content.
+   5. Web Service - To enable development of web service clients.
