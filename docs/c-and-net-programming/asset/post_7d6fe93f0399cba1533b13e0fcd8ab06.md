## 20.5.7 ListBox
![](img/3005a4307e6d8f3bb7e76eea28a92357_635_0.png)

- Allows the user to select an item from a list of items.
- The ListBox control enables to display a list of items to the user that the user can select by clicking.
- In addition to display and selection functionality, the ListBox also provides features that enable to efficiently add items to the ListBox and to find text within the items of the list.
