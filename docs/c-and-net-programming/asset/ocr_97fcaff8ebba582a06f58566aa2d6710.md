# **Lambda Expression with Multiple Parameters**

For lambda expression parameters can be sent in the parenthesis.

Example

```
```
(per, inAge) => per.Age >= inAge;
```
```

# **Declare Local Variable in Lambda Expression Body**

A local variable can be declared in the expression body to use it anywhere in the expression body.

Example

```
```
exp =>
{
    int inAge = 18;
    Console.WriteLine("Lambda expression with local variable");

    return exp.Age >= inAge;
}
```
```

# **Assign Lambda Expression to Delegate**

The lambda expression can be assigned to Func<in T, out TResult> type delegate. The last parameter type in a Func delegate is the return type and rest are input parameters.

# **Example**

```
```
Func<Student, bool> isStudentTeenAger = s => s.st.age > 12 && s.st.age < 19;

Student sobj = new Student() { age = 19 };

bool isTeen = isStudentTeenAger(sobj);// returns false

The Func<> delegate in above code, converts to a function as shown below,
bool isStudentTeenAger(Student st)
{
    return st.Age > 12 && st.Age < 19;
}
