# Example

```
```csharp
// Illustration of do-while loop
using System;
namespace Iteration
{
class dowhileloop
{
static void Main()
{
int i=1;
do
{
Console.WriteLine(i);
Console.WriteLine("");
i++;
}while(i<=10);
Console.ReadLine();
}
}
}
```
```
