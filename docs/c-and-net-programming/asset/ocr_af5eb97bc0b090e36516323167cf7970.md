Ans. :

| Sr. No. | Class | Object |
|---|---|---|
| 1. | Class is the definition of an object | An object is an instance of a class. |
| 2. | It is a template of the object | A class does not become an object unless instantiated |
| 3. | It describes all the methods, properties, etc | An object is used to access all those properties from the class. |
