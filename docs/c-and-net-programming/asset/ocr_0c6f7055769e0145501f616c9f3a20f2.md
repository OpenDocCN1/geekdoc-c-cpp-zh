# Nested Tuple

C# allows to create a tuple into another tuple termed as nested tuple. .NET framework supports tuples with up to eight elements. Nested tuples are to be used when more than eight elements are to be added in the same tuple. The nested tuple is accessible by using the Rest property. To have a tuple with more than seven elements, the 8th element is used with the help of Rest property, to created nesting tuple objects.

```
var oddsdeci = new Tuple<int, int, int, int, int, int, int, Tuple<double, double, double>> (1,3,5,7,9,11,13, Tuple.Create(1.1,2.2,3.3)); //display complete tuple Console.WriteLine("{0}{1}{2} {3} {4} {5} {6} {7} {8} ", oddsdeci.item1, oddsdeci.item2, oddsdeci.item3, oddsdeci.item4, oddsdeci.item5, oddsdeci.item6, oddsdeci.item7, oddsdeci.Rest) //This outputs as below 1 3 5 7 9 11 13 1.1 2.2 3.3 //Also individual element of the 8th nested tuple can be accessed as below, Console.WriteLine("{0}{1}{2}", oddsdeci.Rest.Item1.Item1, oddsdeci.Rest.Item1.Item2, oddsdeci.Rest.Item1.Item3);
```

# Tuple Names

A 2-tuple is called a pair. A 3-tuple is called a triple. A 4-tuple is called a quadruple. A 5-tuple is called a quintuple. A 6-tuple is called a sextuple. A 7-tuple is called a septuple. Larger tuples are called n-tuples.

# Tuples in methods

A tuple can be handy when there is need to pass a data set as a single parameter of a method without using ref and out parameters. In code below method takes tuple as a parameter.

```
public void ParamTupleMethod(Tuple<string, string, int> tupleCustomer) { var cust = tupleCustomer; Console.WriteLine("Customer :{0}, Title:{1}, Year:{2},", cust.Item1, cust.Item2, cust.Item3); } //The following code calls the method having tuple as a parameter obj.ParamTupleMethod(new Tuple<string, string, int>("Ravindra", "Pune", 15820));
```
