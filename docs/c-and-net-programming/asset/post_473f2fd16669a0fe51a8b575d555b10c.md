## 2.4 Literals and Constants

### 2.4.1 Literals

### Concept

- 1. Literals are the way in which the values that are stored in variables are represented.
- 2. Literals are constant values used in the program.

### Explanation

- 3. Constants are fixed values. The constants refer to fixed values that the program may not alter during its execution.
- 4. Constants can be of any of the basic data types like an integer constant, a floating constant, a character constant, or a string literal. There are also enumeration constants as well.
- 5. Also, a variable can be declared as constant and its value cannot be changed during execution of the program. Literals are classified as follows,

### 2.4.2 Literal Types

### 1. Integer Literals

- a. An integer literal is a sequence of digits.
- b. Integer literals can be specified as the number without any fractions.
- c. Integer literal can be of type int, uint, long or ulong.
- d. To specify the uint, long and ulong, suffixes u/U, l/L and ul/UL are used respectively. No suffix is used for int.
- e. An integer literal can be hexadecimal, octal or decimal.
- f. To specify hexadecimal and octal integer literals, prefixes 0x/0X and o/O are used respectively. No prefix is used for decimal.

### Examples

```csharp
261079 // decimal
0xAD10 // hexadecimal
0576 // octal
67u // unsigned int
12ul // unsigned long
98L // long
25 // int
```

- g. Suffix type integer literals

| Suffix type | Character | Example |
|---|---|---|
| unsigned int | U | uint x = 100U; |
| long | L | long x = 100L; |
| unsigned long | UL | ulong x = 100UL; |
| float | F | float x = 100F; |
| double | D | double x = 100D; |
| decimal | M | decimal x = 100M; |

- h. Lowercase suffixes: One can specify lowercase suffixes, such as u, l, ul, f, d and m. But these are easier to confuse with numbers. The letter 'l' is sometimes seen as the number 1.

### Examples of lowercase suffixes

Lowercase suffix: `long x = 10000l;` // Is that 100001 or 10000l?
Uppercase suffix: `long x = 10000L;` // It's 10000L.

```csharp

        float f1 = 100.50F;

        // Use unsigned suffix.
        uint u1 = 1000U;
```

- d. A floating point Literal may be specified as four types.
