# 7. Creating OpenFileDialog dialogbox.

+   - Double click **OpenFileDialog** in toolbox which would add a menuStrip1 object to the from.
+   - Nothing else appears on the form, because the Dialog controls are hidden from view.
+   - The dialogbox can be renamed through Properties Window by Changing the **Name** of **openFIDlg**. The control on the form would change also.
