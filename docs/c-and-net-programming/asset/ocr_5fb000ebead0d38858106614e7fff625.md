# 2.7 Data Types

# Concept

+   1. The type of data that a variable contains is called Data Type (type). A Data Type is a classification of things that share similar type of qualities or characteristics or behavior.

# Explanation

+   2. C# is a strongly typed language, it is required to inform the compiler about which data types is used at the declaration of a variable or object.

+   3. There are two types of data type in C#
+      3.1) primitive types (or) predefined which are byte, short, int, float, double, long ,char, bool, DateTime, string, object etc..
+      3.2) non-primitive types (or) User Defined which are class, struct, enum, interface, delegate, array.
