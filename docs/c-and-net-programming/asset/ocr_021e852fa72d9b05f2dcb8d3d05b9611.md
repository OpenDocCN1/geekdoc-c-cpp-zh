# XAML Templates

A template describes the overall look and visual appearance of a control. For each control, there is a default template associated with it which gives the appearance to that control. In XAML, developer can easily create own templates so as to customize the visual behavior and visual appearance of a control. With templates, more parts of a control are accessed than in styles. Both the existing and new behavior of a control can be specified.

# XAML Animations and Transformations

Animations and transformations inside the Windows Runtime can improve XAML application by building interactivity and movement. Interactive look and feel can be integrated in XAML application by using the animations from Windows Runtime animation library. Animations are used,

+   - to enhance the user interface or to make it more attractive.
+   - to attract the attention of the user to a change.

# Content Property of Object

Each XAML object element is capable of displaying different content types. XAML provides a special property called Content that works to display the content of the element depending on the element capabilities. For example, a Content property of a Button can be a set to a string, an object, a UIElement, or even and container. However, the Content property of a ListBox is set using the Items property.

It should be noted that Some XAML object elements may not have the Content property available directly. It must be set through a property.

The code snippet below, creates a Button control and sets its Content property to a string "Hello XAML".

```
<Button Height="50" Margin="10,10,350,310" Content="Hello XAML" />
```

Here is an alternative way to set the Content property of a Button.

```
<Button Height="50" Margin="10,10,350,310">Hello XAML</Button>
```
