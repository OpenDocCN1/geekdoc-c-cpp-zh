# 8. Sealed methods

+   1. A sealed method overrides an inherited virtual method with the same signature.
+   2. A sealed method shall also be marked with the override modifier.
+   3. Use of the sealed modifier prevents a derived class from further overriding the method. The word further is the main aspect here.
+   4. Idea is that, a method must be virtual in base class. It must be later overridden in derived class. And at this point, once overridden it is sealed now, disallowing further overriding.

```
using System;

public class One
{
    public virtual void vmethod1()
    {
        Console.WriteLine("One.vmethod1");
    }

    public virtual void vmethod2()
    {
        Console.WriteLine("One.vmethod2");
    }
}

public class Two : One
{
    public override void vmethod1()
    {
        Console.WriteLine("Two.vmethod1");
    }

    public sealed override void vmethod2()
    {
        Console.WriteLine("Two.vmethod2");
    }
}
```
