4. Visual Studio Environment is an example of Multiple Document Interface (MDI) whereas notepad is an example of an SDI application. MDI applications often have a Window menu item with submenus for switching between windows or documents.

5. Any windows can be made MDI parent, by setting the IsMdiContainer property to True.

```
IsMdiContainer = true;
```

6. The following C# program shows a MDI form with two child forms. Create a new C# project, to get a default form Form1. Then add two more forms in the project (Form2, Form3). Create a Menu on the form and call these two forms on menu click event. If one want the MDI parent to auto-size the child form one can code as follows

```
form.MdiParent = this;
form.Dock = DockStyle.Fill;
form.Show();
```
