# 9.1.2.1 Single Inheritance

# Concept

In single inheritance as the name implies one single class (derived) derives another existing class (base).

# Example

```
//Illustration of single Inheritance
using System;
class Media
{
    public void Details()
    {
        Console.WriteLine("It has been published");
    }
}
class Book : Media //class Book is derived from class Media
```
