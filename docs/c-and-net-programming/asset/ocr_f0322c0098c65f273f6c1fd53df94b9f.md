3. DO use semantically (meaningwise) interesting names rather than language-specific keywords for type names.

4. Do use PascalCasing for class names and method names.

```
```csharp
public class BookProcess
{
    public void BookIssue()
    {
        //...
    }
    public void CalculatePenalty()
    {
        //...
    }
}
```
```

5. Do use camelCasing for method arguments and local variables.

```
```csharp
public class BookLog
{
    public void Issue(LogEntry logEntry)
    {
        int bookCount = logEntry.bookCount;
        // ...
    }
}
```
```

6. Do use PascalCasing for abbreviations which are 3 characters or more (2 chars are both uppercase) as it is consistent with the Microsoft's .NET Framework. The Caps would grab visually too much attention.

```
```csharp
HtmlHelper htmlHelper;
FtpTransfer ftpTransfer;
DSNControl dsnControl;
```
```

7. Do use predefined type names for data types instead of system type names like Int16, Single, UInt64, etc. This makes code more natural to read.

```
```csharp
// Correct
string bookName;
int nextIndex;
bool isIssued;

// Avoid
String bookName;
Int32 nextIndex;
Boolean isIssued;
```
