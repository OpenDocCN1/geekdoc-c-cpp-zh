# Example 1 Generic Class

```
public class GenericClass1<T>
{
    public T code;
    public void genericMethodShow(T name, T place)
    {
        Console.WriteLine("{0}", code);
        Console.WriteLine("Name: {0}", name);
        Console.WriteLine("Location: {0}", place);
    }
}
```

In above C# example, the generic class is created with one parameter (code) and method (genericMethodShow) using type parameter (T) as placeholder with an angle (<>) brackets.

Here, the angle (<>) brackets will indicate a GenericClass is generic and type parameter (T) is used to accept a requested type. The type parameter name can be anything like X or U or etc. based on our requirements.

Generally, while creating an instance of the class it is required to specify an actual type, then the compiler will replace all the type parameters such as T or U or X, etc. with specified actual type. In C#, the following is the example of creating an instance of a generic class.
