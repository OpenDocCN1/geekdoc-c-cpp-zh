## 20.5.7 列表框
![](img/3005a4307e6d8f3bb7e76eea28a92357_635_0.png)

- 允许用户从项目列表中选择一个项目。
- ListBox 控件能够向用户显示一个项目列表，用户可以通过单击进行选择。
- 除了显示和选择功能之外，ListBox 还提供功能，可高效地向 ListBox 添加项目并在列表的项目中查找文本。
