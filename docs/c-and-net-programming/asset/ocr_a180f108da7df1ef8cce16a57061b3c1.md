# Concept

In C# array is treated as object and inherited from the Array class. Array class is defined in the System namespace.

# Explanation

+   1. Various properties of the Array class are listed below.

| Properties | Description | Basic syntax |
|---|---|---|
| Length | Return the Length of an array. It returns 32-bit Integer value. | Arrayname.Length |
| LongLength | Return the Length of an array. It return 64-bit integer value. | Arrayname.LongLength |
| Rank | Return the rank or number of dimension of an array. It returns integer value. | Arrayname.Rank |
| IsFixedSize | Check whether the array is of fixed size or not. It returns Boolean value. | Arrayname.IsFixedSize |
| IsReadOnly | Check whether the array is Readonly or not. It return Boolean value. | Arrayname.IsReadOnly |
