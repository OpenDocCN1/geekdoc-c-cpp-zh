# 4. Continue statement syntax

```
continue;
```

# Example

```
//illustration of continue statement which stops the third iteration and starts the fourth iteration.
using System;
namespace CSharpJump
{
class continuestatement
{
static void Main()
{
int cnt;
for (cnt = 1; cnt <= 5; cnt++)
{
if (cnt == 3)
{
continue;
}
Console.WriteLine("" + cnt);
}
Console.ReadLine();
}
}
```
