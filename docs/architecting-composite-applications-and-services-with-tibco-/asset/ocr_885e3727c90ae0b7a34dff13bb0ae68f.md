Scaling client connections then requires creating a number of proxy EMS servers and configuring the client’s load balancing parameters to choose among them. In this pattern the queues must be defined as global and be routed between the servers. As with the topic pattern, the max_connections parameter should be set to limit the number of connections that a given proxy server will accept.
