# Partitioning JMS Message Load between Servers

When the volume of message traffic exceeds the capacity of a single JMS server, the traffic must be split between servers. The easiest way to do this is to move some destinations to another JMS server (Figure 11-3). This distributes the message traffic to the different servers.

# Planning for Future Partitioning

To facilitate the movement of destinations from one server to another, it is good practice to group related destinations and use a different JMS connection factory for each group (Figure 11-4). The structured names discussed in Chapter 8 provide a good basis for this organization.
