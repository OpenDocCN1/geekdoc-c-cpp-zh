# Using IP Redirectors to Distribute Load

A common way to distribute load that has requests being sent using a network-based protocol (e.g., TCP/IP) is to use an IP redirector (Figure 11-1). This is commonly done for HTTP and SOAP over HTTP requests. The IP redirector has a list of candidate service providers to which incoming requests can be directed. Some IP redirectors have mechanisms for determining the workload and status of the service providers, and they use this information when forwarding requests.

# Using JMS Queues to Distribute Load

Another common approach to distributing load is to send requests via a Java Message Service (JMS) queue (Figure 11-2). JMS queues deliver each message to exactly one subscriber—in this case one of the service providers. If you are using Enterprise Message Service as your JMS server, you need to make sure that the exclusive property for the queue is not set.
