# EMS Database-based Intra-Site Failover Pattern

An alternative approach is to use a database rather than a shared file system for the storage of undelivered messages (Figure 16-11). In this pattern there is no issue with file locking. However, storage and retrieval of messages in a database is generally slower than with a file system.
