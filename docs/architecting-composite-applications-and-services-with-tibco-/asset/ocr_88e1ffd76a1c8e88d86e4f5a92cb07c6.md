To determine the appropriate setting for Max Jobs, first determine the operating capacity of the ActiveMatrix BusinessWorks instance using the procedure described in Chapter 14. You will probably do some experimentation with the number of engine threads as part of that exercise. Then, while operating an engine steady-state at the operating capacity, observe the number of concurrent jobs. Note that if the engine is configured to run more than one type of job, you may want to run a mix of jobs at this point. Now observe the number of jobs running: This is your value for Max Jobs. Also observe the memory usage: This will tell you the amount of memory required to support running at the operating capacity.
