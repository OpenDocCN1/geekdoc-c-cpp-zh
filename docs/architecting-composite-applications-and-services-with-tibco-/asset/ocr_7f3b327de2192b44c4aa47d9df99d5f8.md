There is a third option: Make the shipments association a child of the root Get Order Details Response (Figure 9-12). Here the association between Shipment and Sales Order is represented by an embedded reference to Sales Order in Shipment. Whether or not the shipments information is required is now determined by the top-level data structure—Get Order Details Response. This is appropriate since that data structure is specific to the operation. Now you have a reusable representation for Sales Order and (most likely) one for Shipment as well.
