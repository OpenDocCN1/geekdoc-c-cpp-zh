Creating other representations for Sales Order is working against the goal of minimizing the number of representations of each entity. Thus it would be preferable (if it turns out to be practical) to use the same representation. Making the shipments association optional has the drawback that neither the sender nor recipient of the data structure can be sure whether the association is supposed to be present. This not only forces both parties to refer to the specification for the particular operation to determine whether the association should be present, but it also creates the possibility of run-time errors.
