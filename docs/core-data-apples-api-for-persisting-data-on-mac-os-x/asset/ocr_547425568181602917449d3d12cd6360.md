Once the DistributedCDClient project has been created, we need copy the PPDistributedProtocol.h file from the server into the project. Normally I would just reference the file directly from the server project so that both are using the same file, but the example has a copy in each project to prevent any errors in the referencing. Next we need create a new class called AppDelegate and add it to the project. Once the AppDelegate has been added to the project, we will need to configure the user interface.

Opening the MainMenu.xib file in Interface Builder, we will want to add a new NSObject to the xib and set its class to AppDelegate. We then need to bind the NSApplication delegate outlet to the AppDelegate. Next we need to add an NSArrayController to the xib and bind its content array to the AppDelegate with a model key of filteredObjects. Lastly, we need to add an NSTableView to the window, expanding it to take up the entire window and assigning the first column to the NSArrayController with a controller key of arrangedObjects and the model key path set to childCount. The second column’s value should also be set to the NSArrayController with a controller key of arrangedObjects and the model key path set to name. Once that is complete, we can close Interface Builder and open the AppDelegate.
