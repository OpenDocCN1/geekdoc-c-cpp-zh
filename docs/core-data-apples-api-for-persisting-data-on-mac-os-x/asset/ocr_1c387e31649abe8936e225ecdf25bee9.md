We do this so that we can pass it into the setStoresFastSyncDetailsAtURL:forPersistentStore: method further down. Next we build a path for the fast sync store to be written to. # NSPersistentStoreCoordinatorSyncing

As I mentioned in the fundamentals (Section 8.1, *Sync Services Fundamentals*, on page 141), Sync Services needs a callback to let our client know what is going on. To be completely accurate, we need both a callback and a protocol. The callback is used by Sync Services to let our application know that a sync is about to happen. The protocol allows us to listen in to that sync and answer questions as things go by. Our sync helper will implement that protocol named NSPersistentStoreCoordinatorSyncing.
