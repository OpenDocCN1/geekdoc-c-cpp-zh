Although this part of the -main performs all the work for the export, it is actually very quick. Since we are not writing anything to disk yet and the Recipe objects are already in memory, we are performing this section of code very quickly. This copy operation will duplicate not only the Recipe entity that we are exporting but all the other entities associated with that recipe. Once all the selected Recipe objects have been copied into the new NSManagedObjectContext, it is time to unlock the primary NSManagedObjectContext.
