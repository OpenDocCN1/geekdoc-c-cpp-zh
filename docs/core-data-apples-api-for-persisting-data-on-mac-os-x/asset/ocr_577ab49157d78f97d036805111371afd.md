# ### -disconnect Implementation

Whenever we shut down the client application, we want to shut down the timers, and we want to close the connection to the server. The -disconnect walks through each of the NSTimer references and invalidates them. Once all the timers are shut down, it then retrieves the NSConnection from the server proxy and invalidates it.
