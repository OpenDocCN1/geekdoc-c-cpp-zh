The -exportApproved: method is also quite brief. In this method we want to also close the sheet, but we want to then present an NSSavePanel as a sheet to the user so that they can tell us where to save the exported recipes. Since the NSSavePanel will be asynchronous as a sheet, we need to pass along the selected recipe’s NSManagedObjectID objects so that the callback can use them to do the actual export.

- (IBAction)exportApproved:(id)sender;
{
    [exportSheet orderOut:sender];
    [NSApp endSheet:exportSheet];

    NSArray *content = [exportArrayController content];
    NSPredicate *pred = [NSPredicate predicateWithFormat:@"selected == YES"];
    NSArray *filtered = [content filteredArrayUsingPredicate:pred];
    NSArray *exportIDs = [filtered valueForKeyPath:@"objectID"];

    NSSavePanel *savePanel = [NSSavePanel savePanel];
    [savePanel setExtensionHidden:YES];
    [savePanel setRequiredFileType:@"grx"];
    [savePanel setCanSelectHiddenExtension:NO];
}
