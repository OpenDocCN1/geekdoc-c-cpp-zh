# PERFORMANCE RESULTS

For our performance evaluation, we select six genome sequences with lengths ranging from 4.4 to 50 million base-pairs (see Figure 4.8), which are publicly available at the NCBI Nucleotide database. Runtimes are measured on a compute node with two Intel E5-2670 8-core 2.60 GHz CPUs and 64 GB RAM running Linux. This compute node is further equipped with four Intel Xeon Phi coprocessors (B1PRQ-5110P/5120D). We use the Intel C++ compiler and OpenMPI to compile and link our algorithm. The environment variable KMP_AFFINITY is set to “balanced,” since the “balanced” affinity more often gave us the best performance on the coprocessors through our evaluations.
