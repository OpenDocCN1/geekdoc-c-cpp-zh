# PME RECIPROCAL SPACE SUM WORK

Depending on the number of MPI tasks launched, either all or a fraction of the MPI tasks are given atoms for which to calculate the PME reciprocal space contribution. For example, a system of cellulose (408,609 atoms) distributes PME reciprocal space work to all MPI tasks; a smaller system would only distribute work to a fraction of the MPI tasks launched. However, as the PME reciprocal space sum is not offloaded to the coprocessor, offloading MPI tasks are restricted from being assigned PME reciprocal space work.
