# ABOUT THE REFERENCE APPLICATION

The DFT methods map the 3N-dimensional problems onto a coupled set of N three-dimensional problems using one-particle orbitals (bands) {Ψ}. The essence of the DFT methods are expressed as

```
E = min_{ {Ψ} } Σ_k w_k Σ_i Σ_j^N (S^k)^{-1}_{i,j} (Ψ^k_i)† Ĥ_k Ψ^k_i , (18.1)
```

where S^k_{i,j} = (Ψ^k_i)† · Ψ^k_j. The theory is all captured by the Hamiltonian operator Ĥ^k and a wide range of approximate forms to the exact Hamiltonian are used in real simulations. The only important information of this operator for our readers is that (i) it depends on {Ψ} under the constraint that the inverse of the overlap matrix Ŝ exists and (ii) we can compute Ĥ_k Ψ. The self-consistent nature of the solution results in iterative methods which update {Ψ} until the solution, the minimum energy, has been reached. The subscript k denotes the k-points introduced to handle the periodic boundary conditions of a crystalline system. To reduce computational cost, the selection of the k-points exploits the symmetry of the computational unit cell, where the weight w_k includes all the contributions from the equivalent k-points in the Brillouin zone of the simulation cell (see Figure 18.1 for an example).
