Note that the critical loop was vectorized, but that there are some vector function matching issues, which are highlighted in boldface in Figure 22.18.

The call to the Interpolator::Interpolate method has two parameters. The first parameter is a pointer to the instance of Interpolator class (this) and the second parameter is an input value. As the interpolator object is uniform and the data parameter is linear within the vectorized loop, the compiler is looking for (uniform,vector) version of the Interpolator::Interpolate() method. However, the compiler can only locate a (vector,vector) version of this method. As discussed previously, this results in inefficient machine code being generated.

## UNIFORM(THIS) CLAUSE

Similar to the C code example shown in Figure 22.8, this function parameter passing ambiguity is resolved by applying a uniform(this) clause to the declaration of the vector function as listed in Figure 22.19. In case of a multiple target architecture, this clause must be applied to all the “declare simd” pragmas.

These changes are reflected in the compiler vectorization report listed in Figure 22.20 showing that appropriate function version was called.
