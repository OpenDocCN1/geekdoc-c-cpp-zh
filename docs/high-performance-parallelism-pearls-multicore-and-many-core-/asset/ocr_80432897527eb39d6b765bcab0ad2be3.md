Assuming the data partition scheme of Figure 18.2, the computation for each MPI task can be simplified as shown in Figure 18.3. We make a further simplification by choosing N_band to be identical for each MPI task. This is not a requirement but is a common practice adopted by applications to load balance among the tasks. The details of what is involved in do_mpi are critical for the performance and the scalability. We assume that the applications have adopted the best solutions within their implementation.

```
1 void main()
2 {
3     int nband_tot=480;
4     int nband=nband_tot/mpi_tasks;
5     PWBands psi(nband);
6     PWBands* psi_remote=&psi;
7
8     for(int ip=0; ip<mpi_tasks; ++ip)
9     {
10        for(int i=0; i<nband; ++i)
11        {
12            fft(psi[i]);
13            compute_g(psi[i],psi_remote);
14            ifft(psi[i]);
15            compute_r(psi[i],psi_remote);
16        }
17        do_mpi(...); //visit all the remote bands
18    }
19 }
20
21 void compute_g(PWBand& me, PWBand* others)
22 {
23     const int i= me.id;
24     const int mband=others->size();
25     Matrix overlap(nband,mband);
26     for(int j=0; j<mband; ++j)
27         overlap(i,j)=dot(me,others[j]);
28     for(int x=0; x<nions; ++x)
29         do_more(me,x,others);//gemm,gemv,
30 }
```
