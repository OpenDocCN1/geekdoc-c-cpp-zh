# SUMMARY

The gap between scalar performance and vector performance is getting bigger over time; today the maximum gap is 16X with 512-bit wide vectors. Future architectures may increase vector width making the potential gap even larger. With such large gaps, proper vectorization is becoming mandatory for HPC codes.
