Our starting point for the model application employs MPI to parallelize over the entire set of bands. Taking advantage of the concurrent nature of the computations between MPI communications, we parallelize the loop over the local bands using OpenMP as shown in Figure 18.4. The computation per band can be abstracted as a series of computational kernels, such as FFT. There may be dependences between computational kernels. For instance, `compute_g` needs the result of the forward FFT of each band. Regardless of the complexity of the operations for a band, they can be executed in parallel using any number of OpenMP threads $N_{OMP}$. We use $N_{band} = nN_{OMP}$ where $n$ is an integer. This choice puts a constraint on $N_{tot}$ but does not affect the fidelity of the result or overall performance.
