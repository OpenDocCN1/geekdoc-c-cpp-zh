Note that the critical loop was vectorized, but that there are some vector function matching issues, which are highlighted in boldface in Figure 22.18.

The call to the Interpolator::interpolate method has two parameters. The first parameter is a pointer to the instance of Interpolator class (this) and the second parameter is an input value. As the interpolator object is uniform and the data parameter is linear within the vectorized loop, the compiler is looking for (uniform,vector) version of the Interpolate::interpolate() method. However, the compiler can only locate a (vector,vector) version of this method. As discussed previously, this results in inefficient machine code being generated.
