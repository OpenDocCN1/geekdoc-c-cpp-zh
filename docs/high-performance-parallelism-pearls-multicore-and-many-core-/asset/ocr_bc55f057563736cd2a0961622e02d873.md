the data alignment directives can be added before each loop in the source code. However, the data in the original arrays is not guaranteed to be aligned so we didn’t add alignment directives into data copying loops described earlier. This had a bigger effect of the code running on the processor than on the coprocessor. The processing time was reduced from 52.3 to 46.9 ms on the Intel Xeon Phi coprocessor and from 138.3 to 120.4 ms on the Intel Xeon processor.

# SUMMARY OF THE CODE OPTIMIZATIONS

Figure 3.12 shows processing times for different optimization stages, which are summarized in Figure 3.13. The overall speedup from the code optimization on an Intel Xeon E5-2670 processor was 2.8× compared to 3.5× on the Intel Xeon Phi 7120P coprocessor. The fact that the same code optimizations also improved CPU performance indicates that using the single source code for both processor and coprocessor is a good strategy. This reduces development costs as any programming work done to modernize WRF for coprocessors will also likely improve performance on legacy processors without requiring multiple code bases.
