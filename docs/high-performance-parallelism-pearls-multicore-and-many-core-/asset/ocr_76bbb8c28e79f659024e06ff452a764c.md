# FIGURE 12.3

High fidelity RF simulation via Monte Carlo path tracing. Comparison of signal loss predictions using RFRT and VPL (top), a classical ray-based RF simulation approach, against measured data from Rosslyn, VA (bottom). These data show that a Monte Carlo path tracing approach to RF modeling provides high fidelity results comparable to those produced by classical ray-based methods.
