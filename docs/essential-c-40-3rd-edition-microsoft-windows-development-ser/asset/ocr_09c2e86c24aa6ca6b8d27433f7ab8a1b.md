The problem in Listing 19.1 is a race condition, where multiple threads have simultaneous access to the same data elements. As this sample execution demonstrates, allowing multiple threads to access the same data elements likely undermines data integrity, even on a single-processor computer. To remedy this, the code needs synchronization around the data. Code or data synchronized for simultaneous access by multiple threads is thread-safe.
