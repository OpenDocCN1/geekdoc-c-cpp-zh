In this query expression, selection is assigned the collection of C# keywords but not contextual keywords. The query expression in this example includes a where clause that filters out the noncontextual keywords.

Developers familiar with SQL will notice that query expressions have a syntax that is similar to that of SQL so as to be familiar to the thousands of programmers who know SQL. In spite of the similarities, however, there are some obvious inconsistencies. The most notable of these is the fact that rather than starting an expression with select, as SQL so often does, C# query expressions begin with the contextual keyword from.
