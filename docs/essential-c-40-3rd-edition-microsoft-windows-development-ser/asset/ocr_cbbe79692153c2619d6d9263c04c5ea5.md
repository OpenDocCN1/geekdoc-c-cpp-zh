# TABLE 18.1: List of Available TaskContinuationOptions Enums* (Continued)

| Enum | Description |
| --- | --- |
| OnlyOnFaulted* | Specifies that the continuation task should be scheduled only if its antecedent threw an unhandled exception. This option is not valid for multitask continuations. |
| OnlyOnRanToCompletion* | Specifies that the continuation task should be scheduled only if its antecedent ran to completion. This option is not valid for multitask continuations. |
| ExecuteSynchronously | Specifies that the continuation task should be executed synchronously. With this option specified, the continuation will be run on the same thread that causes the antecedent task to transition into its final state. If the antecedent is already complete when the continuation is created, the continuation will run on the thread creating the continuation. |

* Indicates when to run the task.
