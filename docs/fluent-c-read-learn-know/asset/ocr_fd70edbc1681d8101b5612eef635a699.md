# # ROUTED COMMAND CLASSES

Now that you've seen that it's actually pretty easy to use routed commands, let's have a look at that scary class structure:

1 Here's the command.
ICommand is the minimum requirement, but most commands descend from RoutedUICommand.

2 To be a command source, the class needs to implement ICommandSource.

4 The CommandBinding itself is simple, and you've already used it.

3 The command target only applies to InputBindings.

5 Because CommandBindings is implemented so high up in the WPF hierarchy, it's available to most WPF objects.
