# PUT ON YOUR THINKING HAT

Here's a possible implementation of the chaotic method from the last exercise. Can you fix it?

```
public FixedDocument GetPrintableVersion(Integer servings)
{
//update servings & data
if (servings != this.Servings)
{
servingsModifier = this.Servings / servings;
foreach (RecipeItem ingr in Items)
{
ingr.Amount *= servingsModifier;
ingr.GetIngredientNutrition();
}
}

//create fixed document
FixedDocument fd = new FixedDocument();
fd.DocumentPaginator.PageSize = (96 * 8.5, 96 * 11);
PageContent pc = CreateFormattedRecipe();
fd.Pages.Add(pc);
return fd;
}
```

> servingsModifier contains the amount for a single serving.

> I'm cheating here because laying out a WPF FixedDocument is pretty verbose, and you don't need to understand it for the exercise. If you're interested, search for "WPF Document" in MSDN.
