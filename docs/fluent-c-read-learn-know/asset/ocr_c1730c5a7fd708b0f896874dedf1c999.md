# JUMP STATEMENTS

All of the control of flow commands we've examined so far rely (at least to some extent) on the evaluation of a Boolean expression. The jump commands that we'll consider next are unconditional. They just do it.

# JUMP COMMANDS

# GOTO

The goto command transfers control to a labeled statement.

# BREAK

The break command is used inside switch and iteration statements. It leaves the containing statement.

# CONTINUE

The continue command is used inside an iteration statement to return to the top of the loop.

# RETURN

The return command exits a method. We'll examine methods and the use of return in the next chapter.
