In C" and some other C-like languages, the jump statement (break in this example) is optional. Without it, execution "falls through" to the statements in the next clause. This can be convenient but it can also be a confusing and error-prone structure and C# doesn't support it.

You can, however, use a different jump statement to achieve the same thing. We'll see how to do that when we examine jump statements at the end of the chapter.
