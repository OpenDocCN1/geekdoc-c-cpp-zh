# ## WORDS FOR THE WISE

Professional bakers use a formula expressed in baker's percentages, with ingredients expressed as the percentage of flour (which is always 100%). Expressing a formula in this way tells the baker a lot about how the dough will behave and makes it easy to adjust the yield.
