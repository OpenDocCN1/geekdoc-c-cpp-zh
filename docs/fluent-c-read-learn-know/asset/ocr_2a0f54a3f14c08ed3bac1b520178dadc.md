# FITTING IT IN

You'll use .NET Platform components at both design-time and runtime.

The code you write will use the Framework Class Library, part of the .NET Framework.

You'll use a .NET tool, Visual Studio, to develop your applications.

Your applications may use .NET Platform servers like SQL Server for relational databases or Sharepoint for document management.

.NET applications run in the context of the Common Language Runtime, a key component of the .NET Framework.

The .NET Platform consists of the .NET Framework, Framework Tools and Framework Servers.
