# # SYNTAX & COMPILATION ERRORS

Remember that syntax errors are basically typos, and compilation errors are like grammatical errors. In truth, there aren't many errors that the Editor won't catch, and they're treated the same way, so you don't need to worry too much about the difference. These are probably the easiest kind of bug to spot and fix, so let's start by introducing one into our code. Delete the .ToString() from the MessageBox command. Visual Studio will underline the whole command with a red squiggly line, and if you hover the mouse over it, you'll see an Intellisense message:
