# ...AND BLOCKS

If you want to comment out several lines, you have two options. You can put double slashes in front of each line, or you can use a BLOCK COMMENT, which is delimited by a dash and an asterisk, like this:

```
/* A slash followed by an asterisk allows you to put a comment on multiple lines */
```

A slash followed by an asterisk (with no space in between) begin the comment.

An asterisk followed by a dash closes the comment.

Everything between /* and */ is ignored, including line breaks.

Block comments can even be embedded inside a line of code, but that can be confusing, so it's best to avoid things like this:

```
Messagebox.Show(/* Display the text */"Something");
```

# MAKE A NOTE

Block comments aren't used as often as they used to be, now that Visual Studio has a handy keyboard shortcut for commenting several lines: Select the lines you want to comment out, and press Ctrl+K, C. To uncomment the lines, select them and press Ctrl+K, U.

It's easy to remember: Ctrl+K is used for most editing shortcuts in Visual Studio, then "C" for comment and "U" for uncomment.
