The ValidateValueCallback is passed directly to the Register...() method:

```
Register(<name>, <propertyType>, <ownerType>,
new PropertyMetadata(...),
<ValidateValueCallback>);
```

Like the callback parameters to the PropertyMetadata constructor, the
ValidateValueCallback parameter of the Register...() method is a delegate, so you'll
need to create a new instance, and you'll almost always do it inside the method call:

```
Register(<name>, <propertyType>, <ownerType>,
new PropertyMetadata(...),
new ValidateValueCallback(<method>));
```

You can't skip the PropertyMetadata parameter the way you can the
PropertyChangedCallback, but you can use the default constructor:

```
Register(<name>, <propertyType>, <ownerType>,
new PropertyMetadata(),
new ValidateValueCallback(<method>));
```

> MAKE A NOTE
> 
> I'm using the basic Register() method for these examples, but the other
> versions work exactly the same way.
