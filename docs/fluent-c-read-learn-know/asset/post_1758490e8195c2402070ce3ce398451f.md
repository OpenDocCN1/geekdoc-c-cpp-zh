## PUT ON YOUR THINKING HAT

To get some practice with the if statement, try translating these situations into code:

- If x is greater than y, increment x; otherwise, set y equal to 12.
- If a is equal to 5, then set x equal to 5; otherwise, if x is equal to 12, set y equal to 21, or if it's not, set y equal to x.

## HOW'D YOU DO?

### If x is greater than y, increment x; otherwise, set y equal to 12.

```
if (x > y) {
    ++x;
} else {
    y = 12;
}
```

The braces aren't absolutely necessary here because there's only a single statement in each clause, but it's never a mistake to use them, and many programmers (including me) always use them.

### If a is equal to 5, then set x equal to 5; otherwise, if x is equal to 12, set y equal to 21, or if it's not, set y equal to x.

```
if (a == 5) {
    x = 5;
} else
    if (x == 12)
        y = 21;
    else
        y = x;
```

Did you find this one a little confusing? Not surprising: it is a little confusing.

If statements can be nested as deeply as you like, but they can be hard to keep track of. The switch statement that we'll look at next is sometimes a better option.

These braces are necessary, because the else clause contains multiple statements in a block. Best practice dictates that if you use braces in any clause of an if command, you should use them in all of the clauses.

In practice, I almost always include the braces, whether or not the clauses actually require them or not. It makes it easier to add additional statements to the clause later, and that happens more often than one might expect.

## THE SWITCH COMMAND

The switch statement compares the condition value to a series of constant values. When it works, it's much easier to understand than a complex if statement, but the downside is that the switch can only use constants for comparison, not variables or other expressions. That means you can't use a switch statement for expressions or to compare one variable to another.

You can have more than one case clause for a block of code. The block will be executed if the control value matches any constant value.

```
switch (<value>)
{
case <constant>:
[<constant>:]
<statement>
<jump command>
[case <constant>:]
<statement>
<jump command>
[default:]
<statement>
}
```

You must have at least one case clause, but you're not required to have more than one.

We'll examine jump commands later in this chapter. They transfer control to someplace other than the next statement.

The default case is optional, but a very, very good idea. This is the code that is executed if the conditional value doesn't match any of the specified case constants. It's a good place to catch any problems.

The statements within a switch block don't need to be wrapped in the braces that define a statement block.

The break command transfers control to the next executable line after the switch.

```
switch (x)
{
case 1:
case 3:
MessageBox.Show("1");
break;
case 2:
MessageBox.Show("2");
break;
default:
MessageBox.Show("Something else");
}
```

The cases in a switch command are executed in the order they're written, not in the order of the case values.

## THE PROS AND CONS

In many situations you have a choice between using an if or a switch. If the switch will work, it's almost always easier to understand, and you should use it. Compare these two examples

```
if (x == 1)
x++;
else
{
if (x == 2)
x += 2;
else
if (x == 3)
x += 3;
else
MessageBox.Show("Oops!");
break
}
```

```
switch (x)
{
case 1:
y++;
break;
case 2:
y += 2;
break;
case 3:
y += 3;
break;
default:
MessageBox.Show("Oops!");
break;
}
```

But because the switch statement requires a constant value to compare to the condition, and the comparison is always on the basis of equality, you can't always use it.

```
if (x==1)
x++;
if (x == 1) || (x == 3)
x += 3;
if (x < 3)
MessageBox.Show("Oops!");
```

Because you can only use a constant value once in a switch statement, repeating the (x==1) wouldn't be possible.

You can only use a switch to compare for equality, so this wouldn't be possible.

If a is equal to 3, set a to 5. If a is equal to 10, set a to 15. If a is equal to 0, do nothing. If a is equal to anything else, display a MessageBox.

if (x == 0)

    x--;

    x = 10;

You might have thought a switch would be better here, and it might have been, but a switch requires a constant (although not necessarily a number). C# won't let you use the variable y in a case clause.

## THE CONDITIONAL OPERATOR

There is one C# operator that we skipped when we examined operators in the last chapter. The Conditional Operator is roughly equivalent to an if-then-else command.

```
<condition> ? <trueValue> : <falseValue>
```

```
x == 1? "equal": "not equal";
```

These two code snippets both set msg to "hello":

```
Int32 x = 1;
String msg;
if (x == 1)
    msg = "hello";
else
    msg = "goodbye";
```

```
Int32 x = 1;
String msg;
msg = x == 1 ? "hello" : "goodbye";
```

For simple statements, the conditional operator is more concise, and once you get used to it, no harder to read.

The conditional operator is often called the TERNARY OPERATOR because it's the only operator that has three operands.

## ITERATION COMMANDS

The next category of control of flow commands is ITERATION STATEMENTS (also called LOOPS) that cause a block of code to be executed more than once. There are three categories of iteration statements: those that execute a statement block a specific number of times, those that execute a statement block zero or more times based on a Boolean expression, and those that execute a statement block for each element in a collection of elements. (We'll discuss the last category in Chapter II when we look at .NET Framework collection types.)

![](img/1dcd2af4ae4fa0eb5cf4ed5437ff121a_202_0.png)

The conditional iteration commands execute a loop either until or while a logical expression evaluates to true.

The for command is usually used to execute a loop a specified number of times, but it can be used conditionally.

We'll discuss the foreach command in Chapter II.
