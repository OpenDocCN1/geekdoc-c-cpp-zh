# # SAY HELLO

Ready to tackle some actual programming? Of course you are. In the next few pages we’ll create the traditional first program for every beginner, “Hello, World”. Here’s what we’ll need to do:

+   1. Create a Visual Studio project. A project is a container for your source code and related resources like connections to a database or resources that your application will use.

+   2. Use a Visual Studio designer to create some widgets (in this case some controls in a WPF window), and set their properties. Visual Studio provides several designers for creating your applications visually instead of in code.

+   3. Use the Visual Studio Code Editor to write some actual C# code. Unlike a simple text editor, the Code Editor provides a lot of features that make writing and managing your code simpler.

+   4. Run your application in debug mode, which helps you find any mistakes, from within Visual Studio.
