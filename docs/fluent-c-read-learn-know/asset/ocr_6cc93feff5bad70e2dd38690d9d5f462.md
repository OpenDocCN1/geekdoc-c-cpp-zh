# PUT ON YOUR THINKING HAT

Time to give your new Boolean expression-writing skills a whirl. Translate each of the questions below into a valid C++ expression. (Checking the operator tables isn't considered cheating.)

+   - Does x have the same value as y?
+   - Are both x and y true?
+   - Is only one of x or y true?
+   - Do x and y have different values?
+   - Is x bigger than y?
+   - Is either x or y true?
+   - Is y smaller than or equal to x?
