## PENS

![](img/1dcd2af4ae4fa0eb5cf4ed5437ff121a_702_0.png)

The WPF Pen is used to draw lines. I’m sure you’ll be relieved to know that it’s far less complex than the Brush. There’s only one class (although you could derive your own if you need to), and a few properties.

You can use any kind of brush to draw the Pen. We’ll use a gradient in the next exercise, but you can use solid brushes, images, whatever suits your purpose.

![](img/1dcd2af4ae4fa0eb5cf4ed5437ff121a_702_1.png)

- Flat
- Square
- Round
- Triangle

DashCap, StartLineCap and EndLineCap control the shape at the end of a line or dash. Unfortunately, you can’t define your own cap styles to display, for example, arrowheads. You have to choose one of the styles defined in the Pen.LineCap enumeration.

The LineJoin property controls what happens when a Pen turns a corner. Again, you can’t define your own; you must use a member of the Pen.LineJoin enumeration.

![](img/1dcd2af4ae4fa0eb5cf4ed5437ff121a_703_0.png)

Like the Colors class used for SolidColorBrush, the Framework defines a set of useful dash styles you can use.

![](img/1dcd2af4ae4fa0eb5cf4ed5437ff121a_703_1.png)

You can define your own dash styles. The Dashes collection of the DashStyle class contains a collection of Double values that represent a percentage of the Thickness of the Pen.

## TEXT DECORATIONS

In WPF, pens are primarily used when you’re defining graphic shapes, but you’ll also use them when you want to “decorate” text with an underline or strikethrough using the TextDecoration class that has a Pen as a property. The TextBlock is one control that exposes a TextDecorations collection, and we’ll use it to explore the properties of a Pen.

![](img/1dcd2af4ae4fa0eb5cf4ed5437ff121a_704_0.png)

The Location property determines where the decoration will be displayed.

TextDecorations is a collection, so your text can, for example, be displayed with both an underline and a strikethrough.

The PenOffset property moves the decoration up or down from its default position.

The TextDecorationUnit, used by both the PenOffsetUnit and PenThicknessUnit, allows you to determine how the PenThickness and PenOffset properties are interpreted.

## HOW'D YOU DO?

This one was a little trickier than our other examples because you were dealing with nested objects. Here's the XAML to set that initial gradient:

```
<TextBlock ... >
    <TextBlock.TextDecorations>
        <TextDecoration x:Name="Decoration">
            <TextDecoration.Pen>
                <Pen>
                    <Pen.Brush>
                        <LinearGradientBrush>
                            <GradientStop ... />
                            <GradientStop ... />
                            <GradientStop ... />
                        </LinearGradientBrush>
                    </Pen.Brush>
                </Pen>
            </TextDecoration.Pen>
        </TextDecoration>
    </TextBlock.TextDecorations>
</TextBlock>
```
