# COMPILED OR INTERPRETED?

Traditionally, languages are either compiled or interpreted. Both methods achieve the same result—the source code you write in a language like C# is translated into object code that can be understood by a specific CPU. The difference is when.

Compiled languages perform the translation at design-time, while interpreted languages translate at run-time.

![](bbox=[0.16, 0.27, 0.86, 0.52])

Every method starts with SOURCE CODE, the human-readable instructions you write.

Eventually, every method turns that source code into OBJECT CODE, the machine-readable instructions that are specific to a CPU.

> > **WORDS FOR THE WISE**
> >
> > DESIGN-TIME is when you're building the application.
> > Runtime is when the user is executing the application.
