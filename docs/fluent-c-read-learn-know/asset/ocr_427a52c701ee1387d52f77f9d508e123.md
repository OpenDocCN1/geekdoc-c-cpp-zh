# HOW'D YOU DO?

# If x is greater than y, increment x; otherwise, set y equal to 12.

```
if (x > y) {
    ++x;
} else {
    y = 12;
}
```

The braces aren't absolutely necessary here because there's only a single statement in each clause, but it's never a mistake to use them, and many programmers (including me) always use them.

# If a is equal to 5, then set x equal to 5; otherwise, if x is equal to 12, set y equal to 21, or if it's not, set y equal to x.

```
if (a == 5) {
    y = 5;
} else
    if (x == 12)
        y = 21;
    else
        y = x;
```

Did you find this one a little confusing? Not surprising: it is a little confusing.

If statements can be nested as deeply as you like, but they can be hard to keep track of. The switch statement that we'll look at next is sometimes a better option.

These braces are necessary, because the else clause contains multiple statements in a block. Best practice dictates that if you use braces in any clause of an if command, you should use them in all of the clauses.

In practice, I almost always include the braces, whether or not the clauses actually require them or not. It makes it easier to add additional statements to the clause later, and that happens more often than one might expect.
