# # SETUP DESIGNERS

Like any Project in Visual Studio, a Setup Project has a number of custom designers that help you build various components. As we've seen, the File-System Designer is displayed when Visual Studio first creates the project. The easiest way to display the other designers is from the toolbar that's displayed in the Solution Explorer when the Project is selected.

# ## PROJECT PROPERTIES

# ## FILE SYSTEM EDITOR

This is the designer that's shown in Step 7.

# ## REGISTRY EDITOR

This designer lets you install key value pairs in the Windows Registry. There aren't many situations where you'll need to do this but you can if you need to.

# ## FILE TYPE EDITOR

This designer lets you register file extensions so that they'll open this application when the user double-clicks a file with the specified extension, the way Word opens when you double-click a .doc file.

# ## USER INTERFACE EDITOR

You can't create a completely custom interface for a Setup Project, but this editor lets you control some of the characteristics of the Installation Wizard that your users will see, like background images and copyright text.

# ## LAUNCH CONDITIONS EDITOR

This editor lets you specify the conditions that must be met before running the installation program, such as the operating system version.

# ## CUSTOM ACTIONS EDITOR

This editor lets you specify components of your Solution that will be executed after the installation. You won't need to do this very often.
