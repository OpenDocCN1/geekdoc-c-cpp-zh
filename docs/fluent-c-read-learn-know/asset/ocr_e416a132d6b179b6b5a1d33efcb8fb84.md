# SEMI-ABSTRACT CLASSES

C# doesn't restrict you to “re-implement everything” (abstract) classes or “re-implement nothing” (concrete) classes. The virtual keyword allows (but doesn't require) a derived class to re-implement the method. This allows you to provide a default implementation of your methods. If the derived class doesn't redefine the method using the new or override keywords, the implementation provided by the base class is used.

The new and override keywords can be tricky. Here's how MSDN defines them:

+   - new is used to hide an inherited member from a base class member
+   - override is required to extend or modify the abstract or virtual implementation of an inherited member

Doesn't really tell you much, does it? What's the difference between “extend or modify” and “hide”?
