# # CHRONOLOGICAL DATA

What time is it? Unless you live in roughly the same part of the world as I do, it's not the same time for you as it is for me. And do you recognize daylight saving time where you live? How many hours between 3 pm and 4 am? The .NET Framework provides a set of classes to help you manipulate dates, times and time periods. (But I warn you, even with the excellent support the .NET Framework provides, handling dates and times is always tricky.)

![](bbox=[0.1, 0.28, 0.9, 0.75])

# DATETIME

The DateTime type represents an abstract date or time or both.

# DATETIMEOFFSET

The DateTimeOffset represents a particular date or time in a particular place.

# TIMESPAN

Timespan is the difference between two dates or times.

# CALENDAR

A Calendar represents the conventional division of dates, such as into years, months and days.

# TIMEZONEINFO

The TimeZoneInfo represents, as you might expect, a specific time zone.

We won't be discussing this one, because you don't need to work with them directly very often, but you should know they're there if you need them.
