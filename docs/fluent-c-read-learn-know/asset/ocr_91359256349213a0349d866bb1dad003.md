# # STATEMENT SYNTAX

In regular English, a sentence is some combination of nouns, verbs and modifiers set off with a period, exclamation point or question mark.

The C# equivalent of a sentence is a STATEMENT—some combination of declared elements, commands and expressions delimited by a semicolon. (C# doesn't have exclamation points, which is probably a good thing, and question marks mean a variable can be empty. We'll talk about that in Chapter 10.)

Both a sentence in English and a statement in C# can extend over multiple lines.

The rules for capitalization are different in C# and spoken English. We'll talk about them in the next section.

```
In English:
Something something
something
```

```
In C#:
something something
something;
```

The period marks the end of the sentence. The semicolon marks the end of the statement.

> “something something something” might not make sense, in which case the compiler (or your copy editor) will complain.

In English, paragraphs are set off by some typographical convention like an extra space or a tab at the beginning.

In C#, the equivalent of a paragraph is called a block, and it’s set off with braces (“{” and “}”).

```
In English:
Something something. Something
else.
Some other somethings.
```

```
In C#:
{
    something something;
    something else;
}
some other somethings;
```
