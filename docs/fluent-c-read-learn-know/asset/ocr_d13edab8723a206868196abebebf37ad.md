# ## NAMESPACES

We'll begin by looking at namespaces, the primary way of organizing types into logical groups in the .NET Framework, and how you can access and create them.

# ## THE OBJECT BROWSER

We've already used the Object Browser, but in this chapter we'll look at in much more detail—it's one of the best tools for finding your way around the class library.

# ## NUMERIC DATA

So far we've primarily used the Int32 class for storing numeric data, but the FCL provides almost a dozen (eleven, to be exact) types for storing different kinds of numeric data, which we'll examine here. We'll also take a quick look at the Math class, which provides support for trigonometric, logarithmic and other advanced mathematical functions.

# ## CHARACTER DATA

After we've finished looking at numbers, we'll look at text, specifically the String, Char and StringBuilder classes that let you store and manipulate character data.

# ## CHRONOLOGICAL DATA

Most people tend to think of dates and times as numbers, and it's true that they're often represented that way, but time is a tricky thing, and the FCL provides some types that make it, if not easy, at least easier to manipulate.
