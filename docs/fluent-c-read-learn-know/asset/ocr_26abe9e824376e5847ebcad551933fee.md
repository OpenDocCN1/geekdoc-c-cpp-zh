# HOW'D YOU DO?

Here are the details of the syntax, in case things didn't quite work out as planned...

```
using System.Speech.Synthesis;
```

Here's the general syntax of the using directive:

```
using [<alias> =] <namespace>;
```

# IN A NUTSHELL — THE USING DIRECTIVE

+   • You must add a namespace reference to the project before you can reference it in the using directive.

+   • The optional alias allows you to create a nickname for the namespace. You'll need to do this if you're using two (or more) namespaces that have types with the same name.

+   • Unlike almost everything else in C# and the .NET Framework, the using directive has FILE SCOPE: It doesn't apply to a type; it applies to a physical code file. If you split your class across multiple files using the partial modifier, you'll need to add the using directive to each of them.

+   • Although it doesn't begin with a hash sign, like #if or #define, this version of using really is a pre-processor directive, not a statement. C# has a using statement that tells the system to dispose of system resources when you're through with them. We'll look at that a little later in the book, when we explore building user interfaces with the Windows Presentation Foundation.
