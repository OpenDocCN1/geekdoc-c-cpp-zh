# EVENT TRIGGERS

If a property trigger is activated by a change in a property value, what do you suppose activates an event trigger? You don't get a gold star for guessing an event. Specifically, a RoutedEvent. There's another difference, as well. Event triggers only execute actions. Property triggers can execute actions via their EnterActions and ExitActions collections, but they're primarily used to set properties. The syntax for the two types of triggers is almost identical.

```
<Trigger Property="Property" Value="Value">
<Setters>
...
</Setters>
<EnterActions>
...
</EnterActions>
<ExitActions>
...
</ExitActions>
```

```
<EventTrigger RoutedEvent="Event">
<Actions>
...
</Actions>
<EnterActions>
...
</EnterActions>
<ExitActions>
...
</ExitActions>
```

Property triggers need a property name and a value. Event triggers only need an event name.

You don't need to specify the Setters or the Actions collection elements explicitly.

Both types of triggers include EnterActions and ExitActions collections that are, in fact, special kinds of event triggers, but they aren't meaningful for event triggers, and they'll be ignored.
