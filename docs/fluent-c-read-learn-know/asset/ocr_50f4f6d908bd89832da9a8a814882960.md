# # AN EXAMPLE...

In the last couple of chapters we've looked at some simple hierarchies for handling ingredients and components for Nell & Gordon's cafe. But you may have noticed something important has been missing the recipes themselves. Whether or not you've done much cooking, you've probably seen a recipe at some point. Most of them consist of a list of ingredients, and a list of steps to make the recipe. The number of steps and the number of ingredients varies from recipe to recipe—a soup recipe might have dozens of ingredients but only one step, while a classic baguette has four ingredients (flour, water, salt, and yeast) but a lengthy preparation method.

![](bbox=[0.49, 0.13, 0.91, 0.42])

Since we can't know in advance how many ingredients or steps are required in our recipe object, we need some way to treat those "sets" as a group—one or more instances of another object. In this chapter, we'll learn how to do that, using the objects that the .NET Framework provides for storing and manipulating sets of objects as a unit.
