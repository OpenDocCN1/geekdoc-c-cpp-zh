# THE CLASS DESIGNER WINDOW

We want to start with an empty diagram, so add a new item using any of the techniques you know, and choose Class Diagram from the dialog. You can call it whatever you like.

![](bbox=[0.532, 0.172, 0.911, 0.375])

After you add the Class Diagram to the Project, it should open in a tab like this:

![](bbox=[0.253, 0.448, 0.802, 0.792])

Just like the WPF Designer, you'll drag and drop on this surface.

You'll create class members in the Class Details pane.

Not all versions of Visual Studio have the same defaults, so if you don't see the Class Details at the bottom, choose Other Windows, Class Details from the View menu.
