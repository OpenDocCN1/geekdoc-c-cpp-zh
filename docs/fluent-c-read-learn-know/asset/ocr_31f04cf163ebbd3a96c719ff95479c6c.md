# A ROAD MAP

There are a bazillion classes in WPF, and it's easy to get lost without a map, but fortunately we have one in the WPF class hierarchy. Once you know where a given class sits on the tree, you know a lot about how the class works and what it does

All .NET classes descend from Object. All WPF classes descend from DependencyObject.

# DependencyObject

Implements the dependency property system

We'll talk about these dependency property system in the next chapter.

# Visual

WPF rendering support, clipping, coordinate transforms, bounding box calculations

# ContentElement

Content elements are displayed inside the elements that descend from Visual.

# UIElement

Animated properties, input events and commanding

# FrameworkElement

Framework-level layout system, logical tree, object lifetime events, style and resources, animation, binding

# FrameworkContentElement

FrameworkContentElement classes can contain mark-up tags (think of a single word in a sentence being in italic).
