# # CONDITIONAL LOOPS

The for command contains a Boolean expression that is used to determine whether the statement block will be executed. But in a classic for loop, the condition section only evaluates the control variable. If your condition is more complicated, it's usually clearer to use one of the two conditional iterations statements that are specifically designed for that purpose.

```
do
{
    <statement>;
} while (<condition>);
```

The braces are always required in do and while statements.

```
while (<condition>)
{
    <statement>;
}
```

You need a semicolon after the while at the end of a do statement, but not at the end of the while statement. Do you know why?

```
do
{
    MessageBox.Show(x.ToString());
    x++;
} while (x <= 5);
```

```
while (x <= 5)
{
    MessageBox.Show(x.ToString());
}
```
