# HOW'D YOU DO?

![](bbox=[0.09, 0.05, 0.2, 0.21])

Does x have the same value as y?

x == y

Be sure you used == not = here.
A single equals is the assignment operator, not the equality operator.

Are both x and y true?

x && y

Is only one of x or y true?

x ^ y

If you get this one wrong, look at the question again.
The exclusive or returns true if one and only one of the operands is true.

Do x and y have different values?

x != y

Is x bigger than y?

x > y

Are either x and y true?

x | y

Is y smaller than or equal to x?

y <= x
