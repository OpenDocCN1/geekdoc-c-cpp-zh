# HOW'D YOU DO?

Here are my choices. If you made different choices, you aren't necessarily wrong. There are very few absolute rules in programming. Remember, it depends on...it depends.

If a is equal to 3, set a to 5. If a is equal to 10, set a to 15. If a is equal to 0, do nothing. If a is equal to anything else, display a MessageBox.

```
switch (a)
{
    case 3:
        x = 5;
        break;
    case 10:
        x = 15;
        break;
    case 0:
        break;
    default:
        MessageBox.Show("smelling");
        break;
}
```

This was a tricky one. Did you get it right? There has to be at least one statement in the case clause, but the jump statement will do. You'll see lots of C# code with "empty statement". It seems odd at first, but it can be very convenient.

If x is equal to 0, increment x. If x is equal to 5, decrement x. If x is equal to y, set x to 10.

```
if (x == 0)
    x++;
if (x == 5)
    x--;
if (x == y)
    x = 10;
```

You might have thought a switch would be better here, and it might have been, but a switch requires a constant (although not necessarily a number). C# won't let you use the variable y in a case clause.
