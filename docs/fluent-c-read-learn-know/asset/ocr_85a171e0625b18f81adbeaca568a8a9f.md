# # CREATING STRUCTURES

Time to get our hands dirty and create a structure. We'll stub it out in the Class Designer and then complete the code in the Editor.

Create a new Class Library project. You can close the Class1.cs file that Visual Studio creates by default; we won't be using it.

Add a new Class Diagram to the project. From the Toolbox, drag a Struct onto the diagram pane. The Designer will display the New Struct dialog. It's almost identical to the New Class dialog we worked with in the last chapter. Change the name to FirstStructure and press the OK button.
