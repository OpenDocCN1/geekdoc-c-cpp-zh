Every WPF object has a CommandBindings property that inherits from UIElement, the base class for FrameworkElement.

![](bbox=[0.58, 0.05, 0.92, 0.38])

![](bbox=[0.17, 0.21, 0.38, 0.35])

UIElement.CommandBindings is a collection of CommandBinding objects.

![](bbox=[0.14, 0.42, 0.46, 0.62])

A CommandBinding sits between a Command and an object. Multiple CommandBinding objects can be registered for the same Command allowing the same command to be used in multiple places.

![](bbox=[0.17, 0.66, 0.4, 0.88])

A reference to the Command that is linked to the object is stored in the CommandBinding.Command property.

Commands implement the ICommand interface, which defines two methods and one event. We'll examine them in detail in a few pages, but basically CanExecute() tells WPF whether the command is currently available, while Execute() does...whatever the command does.
