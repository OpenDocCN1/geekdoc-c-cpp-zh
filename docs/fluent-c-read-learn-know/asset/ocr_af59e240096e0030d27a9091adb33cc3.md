# ROUTING STRATEGIES

Routed events can travel up or down the element tree, or they can behave more or less like a POCO event and go directly to a specific class. Events that start at the top of the tree and travel down are called tunneling events, those that start at the event source and move up are bubbling events, and the ones that don't travel at all are called direct events.

By convention, tunneling events are named . . . Preview<Event>.

Tunneling events start at the top of the tree and move down.

Bubbling events start at the event source and travel up the element tree.

Like POCO events, direct events don't travel at all.
