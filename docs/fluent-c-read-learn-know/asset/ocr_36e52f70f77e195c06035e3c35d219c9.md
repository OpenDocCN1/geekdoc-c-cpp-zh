# # BOXING & UNBOXING

You know that C# will implicitly cast any type to one of its ancestors or an interface that it or one of its ancestors implements. Sometimes this means converting a value type to a reference type and vice versa, a process called BOXING and UNBOXING. It can happen whenever you cast a value type to an interface or to the base class of all .NET Framework types, System.Object.

```
Int32 x = 5;
```

Int32 is a value type, so x is created and stored in the stack.

```
x = 5
```

Nothing happens on the heap.

```
x.ToString();
```

ToString() is a method declared by System.Object, so x needs to be boxed.

A new reference object is created in the stack.

```
x =
x = 5
```

And memory is allocated on the heap to store its value.

After the ToString() method has executed, the reference value is available for garbage collection.

```
x =
5
```

```
x = 5
```
