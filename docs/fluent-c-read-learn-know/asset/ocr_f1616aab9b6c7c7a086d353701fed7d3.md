# ADDING PARAMETERS

The Allocate() method is public and doesn't return a value, so the defaults for type and modifier are correct. But it does have two parameters: an Int32 called quantity and a Boolean called schedule. Click on the triangle just to the left of the method name in the Class Details pane to open the parameters list for the method, and then add the parameters:
