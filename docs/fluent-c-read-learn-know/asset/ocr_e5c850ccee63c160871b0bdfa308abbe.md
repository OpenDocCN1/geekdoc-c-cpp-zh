# .NET TYPES

Can inherit from other classes and implement interfaces

Cannot inherit from or be inherited by other structures, but can implement an interface

Contain only constants

+   - DESTRUCTORS

# STRUCTURES

+   - FIELDS
+   - PROPERTIES
+   - EVENTS
+   - METHODS

+   - INSTANCE
+   - CONSTRUCTORS
+   - DESTRUCTORS
