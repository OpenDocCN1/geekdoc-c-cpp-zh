# # FLOW CONTROLS

![](bbox=[0.1, 0.14, 0.42, 0.3])

A RichTextBox allows the text to be edited. It even exposes the conventional keyboard shortcuts like Ctrl+B for bold or Ctrl+I for italics. It even supports spellchecking.

![](bbox=[0.58, 0.23, 0.91, 0.42])

The FlowDocumentReader is the most versatile of the controls that will display flow content. It supports multiple viewing modes, and even the ability to search for text.

![](bbox=[0.14, 0.41, 0.45, 0.61])

The FlowDocumentPageViewer displays one page at a time, while the FlowDocumentScrollViewer displays its content at a single page with a scroll bar.

![](bbox=[0.58, 0.55, 0.91, 0.73])
