# # USING DIRECTIVES

The directive that's used most often is #if...#else...#endif, which controls what code is included based on whether a constant is defined. The #else clause is optional. It identifies the code that will be included if the constant isn't defined. You can define directive constants in the code, but the two that are used most commonly, DEBUG and TRACE, can also be controlled from the Project Properties Designer. Let's see how this works:

DEBUG and TRACE are defined by default in the debug build configuration. The build configuration is set on the Build tab of the Project Properties Designer.

![](bbox=[0.55, 0.25, 0.91, 0.45])

```
private void button1_Click(object sender,
    RoutedEventArgs e)
{
    #if (DEBUG)
        MessageBox.Show("Debug is defined.");
    #else
        MessageBox.Show("Debug isn't defined.");
    #endif
}
```

If DEBUG is defined, this is the code produced. It's just as though the other code weren't even there.

```
private void button1_Click(object sender, RoutedEventArgs e)
{
    MessageBox.Show("Debug is defined.");
}
```

If DEBUG isn't defined, this code is produced instead.

```
private void button1_Click(object sender, RoutedEventArgs e)
{
    MessageBox.Show("Debug isn't defined.");
}
```
