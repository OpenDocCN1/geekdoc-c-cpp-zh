# EXPLICIT ITERATION

The C# for command is most often used to execute a block of statements a specific number of times. But the syntax is quite flexible, and it can be used for other things.

The initialization section of the statement is usually a declaration statement. The variable declared here is called the CONTROL VARIABLE.

The condition section is a single Boolean expression. The statement block will be executed until this expression evaluates to false.

If the statement is false to begin with, the statement block will never be executed at all.

The loop section typically manipulates the control variable in some way.

```
for (<initialization>; <condition>; <loop>)
.statement>
```

```
for (Int32 x = 1; x <=5; x++)
MessageBox.Show("x = " + x.ToString());
```

The control variable defined in the initialization section is only accessible within the for statement itself, not outside it.
