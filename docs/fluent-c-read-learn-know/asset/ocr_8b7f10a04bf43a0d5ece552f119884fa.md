# REFERENCE SYNTAX

The C# keyword for passing a value by reference is ref. Both the method definition and the method call must use the keyword:

```
void DoSomething(ref Elephant x)
{
    y = new Elephant();
    x = y;
}
```

These must match.

```
DoSomething(ref MyPet);
```

This line works now,
because the change will
be preserved.
