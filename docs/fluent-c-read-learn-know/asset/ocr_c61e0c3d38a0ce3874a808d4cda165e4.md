# A REGISTRATION EXAMPLE

A call to one of the Register().O methods can get pretty dense, what with constructors embedded inside constructors. Here's a complete example:

Dependency properties are declared public, static and readonly.

The property name always ends with 'Property'.

```
public static readonly DependencyProperty TestProperty =
Register("TestDp",
typeof(String),
typeof(MainWindow),
new PropertyMetadata("nothing",
new PropertyChangedCallback(OnTestDpChanged),
new CoerceValueCallback(CoerceTestDp)),
new ValidateValueCallback(ValidateTestDp))
```

The first three arguments to the Register().O method are the name of the CLR property, the type of the CLR property, and the owning class.

The ValidateValueCallback constructor is the final argument to the Register()... O method (not the PropertyMetadata constructor).

The PropertyChangedCallback and CoerceValueCallback constructors are embedded in the PropertyMetadata constructor.

The first argument to the PropertyMetadata constructor is the default value.

Whew! Gives you a new appreciation for the value of Intellisense, doesn't it?
