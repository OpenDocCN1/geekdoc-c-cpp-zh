# # GOTO...WHEREVER

The goto statement gets a lot of bad press, and you will sometimes hear people say that it’s the sign of poorly designed code. I’ve even heard it said that it’s “evil” and its use should be avoided at all cost. That’s not entirely fair. It’s true that the goto statement is a heavy-handed tool, and like a chainsaw, you should use it with caution. But you wouldn’t trim a tree with a carving knife, and there are some situations (admittedly, only a few) where goto is an effective tool.

```
goto <label>;
```

In C#, a label is an identifier followed by a colon. The case xx: syntax of a switch command is an example, but you can create a label outside a switch using the same syntax.
