# HOW'D YOU DO?

A line of people is like a Queue.

A Rolodex is like a Dictionary, while a dictionary is like a Hashtable.

Don't worry too much if you get these two the other way around. The difference is a subtle one, and in practice not often critical.

A stack of dishes is like a Stack.

A check list is like an Array or ArrayList.
