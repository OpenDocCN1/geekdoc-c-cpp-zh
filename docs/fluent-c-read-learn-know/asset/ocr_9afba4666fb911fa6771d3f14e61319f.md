# # XML COMMENTS

Like Task List comments, XML comments are recognized by Visual Studio. They allow you to provide Intellisense support for the code that you write. XML comments can also be used to create documentation files and help files directly from your code.

You've already seen some XML comments, though you might not have noticed them. Visual Studio added them automatically when it created your project.

There are a dozen or so tags that have meaning in XML comments. Search MSDN for "Recommended Tag" for a lot.

XML comments begin with three slashes, and, like any XML around their elements with <tag>...</tag> pairs.

```
```csharp
namespace _05app01
{
/// <summary>
/// Interaction logic for MainWindow.xaml
/// </summary>
public partial class MainWindow : Window
{
public MainWindow()
{
InitializeComponent();
}
private void button1_Click(object sender, RoutedEventArgs e)
{
MessageBox.Show("Something");
}
}
}
```
```

The contents of an XML comment tag can span multiple lines, but each line must begin with the triple slash.
