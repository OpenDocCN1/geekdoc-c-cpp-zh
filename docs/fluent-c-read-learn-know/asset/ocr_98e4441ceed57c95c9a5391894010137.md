# THE CLASS LIBRARY, PART 2

The .NET Framework types we discussed in the last chapter manage single items of data, even though the structure of that data can be complex. In this chapter, we'll concentrate on the types that represent more than one element, and allow those elements to be manipulated as either a group or a single entity.

The types we've examined so far are like a single book. In this chapter, we'll look at the .NET Framework types that let you manipulate an entire bookcase.
