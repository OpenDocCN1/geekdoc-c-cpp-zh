But XAML isn't a programming language in the sense that C# and Visual Basic are, so there are some more steps to the process. Let's take a quick look at how the process works:

# WORDS FOR THE WISE

BAML stands for BINARY APPLICATION MARKUP LANGUAGE. To create the BAML, the XAML is parsed, tokenized and converted to binary format that's smaller and faster, to load than the original XAML. You should know about it exists, and how it fits into the application development process, but don't worry about the exact format or contents.
