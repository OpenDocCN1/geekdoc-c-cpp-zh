# ACCESS MODIFIERS

Statements that create things, like the class statement that defines a class and its members, take an ACCESS MODIFIER that controls their VISIBILITY, that is, what other code can create instances of them, reference them, and change their values. There are four levels of accessibility, from “whoever wants” to “nobody but me”. They’re shown in the table below.

| TYPES DECLARED WITH THIS KEYWORD | CAN BE ACCESSED BY |
| :--- | :--- |
| public | Any code |
| protected | The type that declares them, or by types that inherit from that type |
| private | The type that declares them |
| internal | The assembly in which they’re declared |
| protected internal | The type that declares them, types that inherit from that type, or the assembly in which they’re declared |

These two modifiers are only rarely used.

An assembly is roughly, an executable (.exe) or dynamic link library (.dll) that runs in the CLR. It’s actually a little more complicated than that, but you don’t need to worry about those details at this point.
