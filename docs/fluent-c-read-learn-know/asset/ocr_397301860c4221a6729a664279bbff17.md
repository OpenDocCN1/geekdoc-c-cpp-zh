# ADD EVENT HANDLERS

There are three ways to add an event handler for a RoutedEvent in WPF. You can do it in XAML (that's the easy way), you can do it using some C# syntactic sugar, or you can do it by calling the AddHandler() method (that's the most flexible). We'll try all three.

# ADD A HANDLER IN XAML

The events that are defined by an object are exposed as properties in XAML. To add a handler, you just set the property to the name of your handler. There's an example in the Window code on the previous page, but let's replace the Loaded event with the MouseDown event. You can do this either directly in the XAML, or in the Properties window. (Visual Studio will keep them synchronized.)

# ADD A HANDLER USING THE C# OPERATOR

Almost as easy as adding an event handler in code is to use the C# += operator. The only thing you have to remember is that you assign a RoutedEventHandler to the event, so you'll have to create one in the code. The basic syntax is:

```
<object>.<Event> += new RoutedEventHandler(<Method>);
```

You can create the RoutedEventHandler separately, but there's no real point.

Add our generic handler to the button1.Click event in the MainWindow() constructor, after the call to InitializeComponent().

# ADD A HANDLER USING ADDHANDLER()

The final method to add an event handler is by calling the AddHandler() method that's defined by the UIElement class. There are two overloads of the AddHandler() method:

```
<object>.AddHandler(<Event>, new RoutedEventHandler(<Method>));
or
<object>.AddHandler(<Event>, new RoutedEventHandler(<Method>, <HandledEventsToo>));
```

You need to use the name of the event identifier here, which is the one with 'Event' at the end of its name.

We explore that second overload in a bit. For now, use the first AddHandler() method to add our generic handler to the MouseDown event of the Listbox1 element.
