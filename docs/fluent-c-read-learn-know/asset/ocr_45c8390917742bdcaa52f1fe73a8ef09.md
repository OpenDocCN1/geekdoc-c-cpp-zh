# THE PROS AND CONS

In many situations you have a choice between using an if or a switch. If the switch will work, it's almost always easier to understand, and you should use it. Compare these two examples

```
if (x == 1)
x++;
else
{
if (x == 2)
x += 2;
else
if (x == 3)
x += 3;
else
MessageBox.Show("Oops!");
break
}
```

```
switch (x)
{
case 1:
y++;
break;
case 2:
y += 2;
break;
case 3:
y += 3;
break;
default:
MessageBox.Show("Oops!");
break;
}
```

But because the switch statement requires a constant value to compare to the condition, and the comparison is always on the basis of equality, you can't always use it.

```
if (x==1)
x++;
if (x == 1) || (x == 3)
x += 3;
if (x < 3)
MessageBox.Show("Oops!");
```

Because you can only use a constant value once in a switch statement, repeating the (x==1) wouldn't be possible.

You can only use a switch to compare for equality, so this wouldn't be possible.
