# BASE CONSTRUCTORS

You might have thought that the syntax for calling the constructor would look like this

```
public MyClass : MyBase
{
    MyClass()
    {
        base();
    }
}
```

![](bbox=[0.21, 0.18, 0.29, 0.25])

That's a reasonable guess, but in fact it more closely resembles the syntax for inheritance:

```
public MyClass : MyBase
{
    MyClass() : base()
    {
        //more code here
    }
}
```

If the constructor takes arguments, you put them within the parentheses, like any method call. (Constructors are, after all, just a special type of method.)
