# HOW'D YOU DO?

Are you surprised that you already knew how to implement a Structure? Well done!

```
public struct FirstStructure
{
    public FirstStructure(Int32 x, Int32 y)
    {
        this.X = x;
        this.Y = y;
    }

    public Int32 X {get; set;}
    public Int32 Y {get; set;}
}
```

Did you notice that in the Class Designer Toolbox the structure is called a “Struct”? (Of course you did.) The reason for that is that C# (largely for historical reasons) uses struct as the keyword for defining a structure:

```
[modifier] struct <name> [: interface]
```

```
public struct SecondStructure
```

Structures can implement interfaces, but it isn’t done very often, and should be done with care because of the boxing issues we’ll discuss later in this chapter.
