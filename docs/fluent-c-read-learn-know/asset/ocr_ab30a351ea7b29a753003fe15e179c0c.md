# Here's my version of the Button element.

```
<Button Grid.Column="1" Width="200" Height="50" Style="{StaticResource Wiggle}">
Transformed Button
<Button.RenderTransform >
<RotateTransform CenterX="100" CenterY="25" />
</Button.RenderTransform>
</Button>
```

This is the button content. Do you think it would have been clearer if I'd specified that explicitly? <Button.Content> Transformed Button </Button.Content>

Setting the default properties of the transformation saves some code in the event trigger, and also makes are that WPF creates the RenderTransform property.
