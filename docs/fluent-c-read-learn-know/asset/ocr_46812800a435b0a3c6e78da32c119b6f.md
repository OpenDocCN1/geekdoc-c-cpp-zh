# UNDER THE MICROSCOPE

Another useful property of the GridSplitter is ShowsPreview. ShowsPreview determines whether the rows or columns controlled by the GridSplitter are actually changed as the user drag it, or simply shows a preview of the change until the user releases the mouse.

ShowsPreview defaults to False, which is fine for most situations, but if there's a noticeable delay in updating the display, you'll probably want to change it to True.
