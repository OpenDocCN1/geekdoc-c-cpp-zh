# # ELEMENTS OF AN ANIMATION

Like most things, you create a WPF animation declaratively, which is a real bonus for those of us who don't really enjoy linear algebra. (Personally, I'd rather clean the oven.) The catch is that there are quite a few objects involved. We'll take them one at a time.

BeginStoryboard is just another TriggerAction like PlaySoundAction. It can contain a single instance of a Storyboard.

![](bbox=[0.1, 0.23, 0.85, 0.85])

A StoryBoard is a wrapper for a set of Timeline objects. The Storyboard defines the property that will be changed.

The MediaTimeline uses MediaPlayer to play sound and video.

The classes that derive from AnimationTimeline change a property.
