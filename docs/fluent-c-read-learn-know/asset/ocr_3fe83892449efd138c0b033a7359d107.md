# # ABSTRACT SYNTAX

![](bbox=[0.1, 0.16, 0.42, 0.32])

You can add an abstract class from the Class Designer, but you can't define abstract members. You have to do that in code.

![](bbox=[0.48, 0.24, 0.88, 0.52])

Where the Class Designer really comes into its own when working with abstract classes is in implementing the necessary members in their descendents. Simply right-click an inheriting class and choose Implement Abstract Class from the Intellisense menu.

As you might expect, the code for implementing an abstract class or abstract member looks very like the code for an interface. Only the signature is defined, without any implementation, marked with the abstract keyword.

```
```csharp
public abstract myClass
{
    public int myProperty {get; set;}
    public abstract int myAbstractProperty {get; set;}
    public abstract void DoSomething();
}
```
```

Abstract classes can contain concrete code. This is an auto-implemented non-abstract property.

Only the abstract keyword sets this property apart from the concrete version.

The compiler will complain if you try to put code in an abstract method declaration.
