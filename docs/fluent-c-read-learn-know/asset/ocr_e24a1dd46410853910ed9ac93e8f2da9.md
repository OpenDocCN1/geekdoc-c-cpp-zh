Write the statement that declares a single-dimension Array of Strings called Week that is initialized with the days of the week:

```
String[] DaysOfWeek = {"Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", "Sunday"};
```

Write the statement that sets the fourth element of week to “Hello”:

```
Week[3] = "Hello";
```

Weird, isn’t it? But the fourth element is referenced as 3, because the numeric value you provide is the offset from the first element, the fourth element is three past the first, and the first element is zero past the first. (Read that last bit again.)
