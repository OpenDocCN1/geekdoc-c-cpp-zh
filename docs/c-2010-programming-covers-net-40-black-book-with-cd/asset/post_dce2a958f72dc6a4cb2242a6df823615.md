## Working with Files

The .NET Framework provides a set of classes in the System.IO namespace to read, write, or manipulate files and directories. The System.IO namespace allows synchronous and asynchronous reading from and writing to data streams and files. These classes are used to perform various operations, such as opening, reading, moving, copying, and deleting files. Some of the classes provided by the System.IO namespace to work with files are as follows:

- FileStream
- StreamReader and StreamWriter
- BinaryReader and BinaryWriter
- File
- FileInfo
- Path

Let’s have a brief overview of these classes one by one.

### The FileStream Class

The FileStream class allows you to access files and work with them. You can create, open, and share files with the help of the constructors of the FileStream class. This class can open a file either synchronously or asynchronously. By default, the FileStream class opens the files synchronously. After opening or creating a file, you can pass an object of the FileStream class to the BinaryReader, BinaryWriter, StreamReader, and StreamWriter classes to work with the data in the file.

You can use the Seek() method of the FileStream class to navigate to any location in the file, which is called random access. The other form of file access is called sequential access. In sequential access, you just read or write the data to a file sequentially, i.e. one item after the other. The only difference between these types of access is that for random access, you can use the Seek() method by specifying a byte offset to navigate from the current position up to the end of the file.

### The StreamReader and StreamWriter Classes

You can use the StreamReader and StreamWriter classes to read and write data in files. The StreamReader class is derived from an abstract class called TextReader, which reads characters from a stream; and the StreamWriter class is derived from an abstract class called TextWriter, which writes characters to a stream. The StreamReader and StreamWriter classes are encoding sensitive; therefore, they can be used to read and write text in different encoded formats, such as UTF-8 and UTF-16. You can create an object of StreamReader and StreamWriter by passing a file name to their constructors.
