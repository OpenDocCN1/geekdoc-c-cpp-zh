# ## The Menu Control

The Menu control in WPF is derived from the abstract base class, MenuBase. You can use the Menu control to represent a Windows menu to hierarchically organize elements associated with commands and event handlers. The Menu control presents a list of items that specify commands or options for an application. For example, when you click an item on a menu, a submenu may open or a command may be carried out. The content properties of the Menu control are set by using the Items and ItemsSource properties.

The inheritance hierarchy of the Menu class is as follows:

```
System.Object
    System.Windows.Threading.DispatcherObject
        System.Windows.DependencyObject
            System.Windows.Media.Visual

                    System.Windows.FrameworkElement
                        System.Windows.Controls.Control
                            System.Windows.Controls.ItemsControl
                                System.Windows.Controls.Primitives.MenuBase

```
