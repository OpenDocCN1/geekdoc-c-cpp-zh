## WPF 中的几何图形

WPF 中的几何图形派生自抽象基类 Geometry。由 Geometry 类派生的类定义了 WPF 中的几何形状。Geometry 对象用于裁剪和渲染 2D 图形。在表 12.10 中，您了解了 WPF 中可用的不同 Shape 元素。其中之一是 Path 对象。Path 类能够绘制任何简单形状、形状组或更复杂的曲线。这些形状和曲线使用 Geometry 对象来描述。要使用 Path 类，首先需要创建 Geometry 类的对象，然后使用它来设置 Path 类的 Data 属性。Path 和 Geometry 类之间的基本区别在于，Geometry 类定义形状，而 Path 类允许您绘制该形状。实际上，Path 类使用 Geometry 类来描述其内容。Geometry 类的继承层次结构如下：

```
System.Object
    System.Windows.Threading.DispatcherObject
        System.Windows.DependencyObject
            System.Windows.Freezable
                System.Windows.Media.Animation.Animatable
                    System.Windows.Media.Geometry
```

Geometry 和 Shape 类可能看起来相似，因为它们都描述 2D 形状，但它们之间有一些重要区别。第一个区别是 Geometry 类继承自 Freezable 类，而 Shape 类继承自 FrameworkElement 类。Shape 对象更易于使用，而 Geometry 对象用途更广。因此，可以说 Geometry 类仅定义形状的几何图形，无法自行渲染。Geometry 类包含各种几何图形类，这些类可分为以下三类：

- 简单几何图形
- 路径几何图形
- 复合几何图形

这些类别将在下一节中讨论。

## 简单几何图形

简单几何图形类用于创建基本几何形状，例如直线、矩形和椭圆。基本上，一个简单几何图形类包括三个类，如下所示：

这些类。LineSegment 类在 PathFigure 对象中创建两点之间的直线，而 Polyline 类绘制一系列相连的直线。

- RectangleGeometry 类 — 表示二维矩形。RectangleGeometry 类使用 Rect 结构定义，该结构指定矩形的相对位置及其高度和宽度。您还可以通过设置矩形的 RadiusX 和 RadiusY 属性来创建圆角矩形。RectangleGeometry 和 Rectangle 类并不相同。区别在于它们各自使用的值。Rectangle 类仅接受 Height 和 Width 属性，而 RectangleGeometry 类接受四个属性，这些属性除了描述矩形的高度和宽度外，还描述其大小和位置。
- EllipseGeometry 类 — 表示圆或椭圆的几何图形。EllipseGeometry 类和 Ellipse 类并不相同。Ellipse 类具有 Fill、Stroke 和其他渲染属性，而 EllipseGeometry 类没有这些属性。EllipseGeometry 类定义椭圆的几何图形。

## 路径几何图形

路径几何图形使用 PathGeometry 和 StreamGeometry 类表示。这些类用于创建由弧线、曲线和直线组成的多个复杂图形。表 12.14 描述了路径几何图形类的功能：

| 表 12.14：路径几何图形类 |
| 类 | 说明 |
| PathGeometry | 绘制由弧线和曲线组成的复杂形状 |
| StreamGeometry | 绘制几何形状，是 PathGeometry 类的轻量级替代方案 |

PathGeometry 类用于定义可能由弧线、曲线、椭圆、直线和矩形组成的复杂形状。它还定义 PathFigure 对象的集合，每个 PathFigure 对象由一个或多个 PathSegment 对象组成。表 12.15 列出了不同类型的 PathSegment 对象：

| 表 12.15：PathSegment 对象的类型 |
| 段 | 说明 |
| ArcSegment | 在两点之间创建椭圆弧 |
| BezierSegment | 在两点之间创建三次贝塞尔曲线 |
| LineSegment | 在两点之间创建直线 |
| PolyBezierSegment | 创建一系列三次贝塞尔曲线 |
| PolyLineSegment | 创建一系列直线 |
| PolyQuadraticBezierSegment | 创建一系列二次贝塞尔曲线 |
| QuadraticBezierSegment | 创建二次贝塞尔曲线 |

PathFigure 类中的各线段会合并为单个几何形状，因为每个线段的终点都是下一个线段的起点。您可以通过设置 StartPoint 属性来指定第一条线段的绘制起点。PathGeometry 类的填充区域通过获取所有将 IsFilled 属性设置为 True 的 PathFigure 对象来定义。应用 FillRule 属性可确定封闭区域。

StreamGeometry 类和 PathGeometry 类一样，也定义几何形状。唯一的区别是 StreamGeometry 类是 PathGeometry 类的轻量级替代方案。StreamGeometry 类不支持数据绑定、动画或修改，这与 PathGeometry 类不同。
