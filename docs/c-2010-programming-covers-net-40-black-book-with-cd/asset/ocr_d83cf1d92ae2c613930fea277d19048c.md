# Storage for Assemblies

As already learned, shared assemblies are put in an assembly reservoir, called GAC, where all the assemblies that are supposed to be shared by a number of applications usually reside. Shared assemblies are uniquely identified with strong names (made up of information to identify an assembly). You can see all the assemblies installed in the GAC by using the GAC viewer, which is located in the <WinDrive>:<WinDir>\assembly directory; where <WinDir> is WINDOWS in Windows XP or Windows in Windows Vista or WinNT in Windows 2000. Apart from the list of assemblies, the assembly viewer also shows relevant information, such as the Global Assembly Name, Version, Culture, and the Public Key Token.

The other way to view all the shared assemblies in the GAC is through the .NET Framework 2.0 Configuration tool. Open the .NET Framework 2.0 Configuration tool from Control Panel→Administrative Tools→Microsoft .NET Framework 2.0 Configuration. Under the My Computer node, click the Assembly Cache folder. On the right pane, click the View List of Assemblies in the Assembly Cache link.

> NOTE
> The .NET Framework 2.0 Configuration tool is a Microsoft Management Console (MMC) snap-in used to manage and configure assemblies in GAC; and adjust code access security policy and remote services. It is not built-in under .NET Framework 4.0. To use this feature, you need to install the .NET Framework SDK. You can download the .NET Framework SDK from the http://microsoft.com/downloads site.
