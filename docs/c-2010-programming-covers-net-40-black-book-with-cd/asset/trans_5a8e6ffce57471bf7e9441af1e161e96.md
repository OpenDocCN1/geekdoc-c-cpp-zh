Visual Studio 2010 IDE 的“数据提示固定”功能用于跟踪变量或表达式，并在调试时查看这些变量和表达式的值。您可以通过单击提示右侧的固定按钮来固定变量，从而使用“数据提示固定”功能，如图 1.25 所示：

“数据提示固定”功能还允许您在固定变量后添加注释，如图 1.26 所示：

## 文件的单独关闭按钮

在 Visual Studio 2010 IDE 中，每个文件都提供了单独的关闭按钮。换言之，您可以单独关闭每个文件，而不会影响其他已打开的文件。

图 1.27 显示了一个带有关闭按钮的窗体：

![](img/e073a4882197be4ab61103cbe0bcb394_69_0.png)

图 1.27：显示每个窗体附带的关闭按钮

您也可以通过右键单击窗体并从上下文菜单中选择“关闭”选项来关闭窗体。

## 断点标签支持

Visual Studio 2010 支持断点标签功能，用于将两个或多个断点分组。断点是开发人员在程序中设置的临时暂停点，以便分阶段测试和调试程序。现在，让我们学习在各种代码行处设置断点，如图 1.28 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_69_1.png)

图 1.28：显示带有断点的代码

现在，从“调试”菜单中选择“窗口”→“断点”选项，或按 CTRL+ALT+B 组合键以打开“断点”窗口。

图 1.29 显示了“断点”窗口：

![](img/e073a4882197be4ab61103cbe0bcb394_70_0.png)

图 1.29：显示“断点”窗口

图 1.29 显示“断点”窗口中新增了一个名为“标签”的列。要添加断点标签，请右键单击断点名称，然后从上下文菜单中选择“编辑标签”选项。此时会打开“编辑断点标签”对话框，您可以通过单击“添加”和“确定”按钮来添加一个或多个断点标签。

图 1.30 展示了如何使用“编辑断点标签”对话框添加断点标签：

![](img/e073a4882197be4ab61103cbe0bcb394_70_1.png)

图 1.30：显示“编辑断点标签”对话框

在 Visual Studio 2010 IDE 中，您可以为断点分配一个或多个断点标签，如图 1.31 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_70_2.png)

图 1.31：显示将断点标签分配给断点名称

除了添加和标记断点外，“断点”窗口还允许您执行以下任务：

- 设置函数断点
- 设置地址断点
- 修改断点位置
- 删除断点
- 启用或禁用断点
- 指定断点筛选器
- 指定命中次数
- 指定断点条件
- 导入或导出断点
- 搜索断点列表

## 表 1.2：安装 Visual Studio 2010 的系统要求

| 硬件和软件 | 要求 |
|---|---|
| 硬盘 | 最低：5400 转/分钟（RPM）推荐：7200 RPM 或更高 |
| 媒体驱动器 | DVD-ROM |
| 显示器 | 最低：1024 × 768 显示推荐：1280 × 1024 显示 |
| 显卡 | 可在 1024 × 768 或更高分辨率显示下运行的 DirectX 9 显卡 |
| 鼠标 | Microsoft 鼠标或兼容的指点设备 |
