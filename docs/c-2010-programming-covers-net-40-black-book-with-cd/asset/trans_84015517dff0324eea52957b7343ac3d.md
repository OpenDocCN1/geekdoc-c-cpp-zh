

## DataList 控件

DataList 控件是一种数据绑定控件，它使用模板来显示数据。这些模板定义了要为项显示的控件和 HTML 元素。DataList 控件存在于 System.Web.UI.WebControls 命名空间中。DataList 控件的继承层次结构如下：

```
System.Object
    System.Web.UI.Control
        System.Web.UI.WebControls.WebControl
            System.Web.UI.WebControls.BaseDataList
                System.Web.UI.WebControls.DataList
```

可以使用表 26.6 中描述的模板来更改 DataList 控件的内容：

### 表 26.6：DataList 类的模板

| 模板名称 | 描述 |
|---|---|
| AlternatingItemTemplate | 为 DataList 控件中的交替单元格提供格式和内容。 |
| EditItemTemplate | 为 DataList 控件中要编辑的项提供格式和内容。 |
| FooterTemplate | 为 DataList 控件的页脚部分提供格式和内容；如果未定义，则不显示页脚部分。 |
| HeaderTemplate | 为 DataList 控件的页眉部分提供格式和内容；否则不显示页眉部分。 |
| ItemTemplate | 为 DataList 控件中的项提供格式和内容。它是必需模板。 |
| SelectedItemTemplate | 为 DataList 控件中当前选定的项提供格式和内容。 |
| SeparatorTemplate | 为 DataList 控件中分隔各项的分隔符提供格式和内容；否则不显示分隔符。 |

我们还可以配置 DataList 控件，使用户能够编辑或删除表中的记录，并且它可以水平或垂直地呈现其项。

## DetailsView 控件

DetailsView 控件是一种数据绑定控件，用于以表格格式显示关联数据源中的单条记录，其中表格的每一行代表记录的一个字段。DetailsView 控件使用 DataSourceID 属性来支持双向绑定；因此，它还支持插入、更新和删除操作。

DetailsView 控件存在于 System.Web.UI.WebControls 命名空间中。DetailsView 控件的继承层次结构如下：

```
System.Object
    System.Web.UI.Control
        System.Web.UI.WebControls.WebControl
            System.Web.UI.WebControls.BaseDataBoundControl
                System.Web.UI.WebControls.DataBoundControl
                    System.Web.UI.WebControls.CompositeDataBoundControl
                        System.Web.UI.WebControls.DetailsView
```

注意
行字段、行字段类型和字段类型与 DetailsView 控件中的字段相同。

DetailsView 控件的数据行是通过声明字段控件来创建的。表 26.9 显示了不同的行字段：

### 表 26.9：DetailsView 类的行字段类型

| 字段类型 | 描述 |
|---|---|
| BoundField | 将数据库中的字段值表示为文本。 |
| ButtonField | 表示 DetailsView 控件中的命令按钮。此外，你还可以使用自定义按钮控件（如“添加”或“删除”按钮）显示一行。 |
| CheckBoxField | 表示 DetailsView 控件中的复选框。你可以使用它来显示具有布尔值的字段。 |
| CommandField | 表示内置的命令按钮，用于在 DetailsView 控件中执行编辑、插入或删除等操作。 |
| HyperLinkField | 将数据库中的字段值表示为超链接。 |
| ImageField | 在 DetailsView 控件中显示图像。 |
| TemplateField | 根据定义的模板，表示 DetailsView 控件中一行的用户定义内容。你还可以创建自定义行字段。 |

表 26.10 列出了 DetailsView 类的重要属性：

### 表 26.10：DetailsView 类的重要属性

| 属性 | 描述 |
|---|---|
| AllowPaging | 获取或设置一个值，指示是否启用分页功能。 |
| AlternatingRowStyle | 获取对 TableItemStyle 对象的引用，该对象允许你设置 DetailsView 控件中交替数据行的外观。 |
| AutoGenerateDeleteButton | 获取或设置一个值，指示是否在 DetailsView 控件中显示用于删除当前记录的内置控件（如 GridView 控件）。 |
| AutoGenerateEditButton | 获取或设置一个值，指示是否在 DetailsView 控件中显示用于编辑当前记录的内置控件。 |
| AutoGenerateInsertButton | 获取或设置一个值，指示是否在 DetailsView 控件中显示用于插入新记录的内置控件。 |
| AutoGenerateRows | 获取或设置一个值，指示是否为数据源中的每个字段自动生成行字段并在 DetailsView 控件中显示。 |
| BackImageUrl | 获取或设置要在 DetailsView 控件背景中显示的图像的 URL。 |
| BottomPagerRow | 获取表示 DetailsView 控件中底部页导航行的 DetailsViewRow 对象。 |
