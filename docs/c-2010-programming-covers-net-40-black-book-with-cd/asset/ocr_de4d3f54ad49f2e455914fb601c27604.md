# Using the WrapPanel Control

The WrapPanel control is used to add child elements in a window in a sequential manner. You can add a WrapPanel control through the XAML code. Let’s create a WPF application named WrapPanelControl (available in the CD) and add the code to the MainWindow.xaml file, as shown in Listing 10.7:

# Listing 10.7: Showing the Code to Implement the WrapPanel Control

```
<Window x:Class="WrapPanelControl.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="350" Width="525">
    <Grid>
        <WrapPanel Background="SkyBlue">
            <Button Height="38" Width="81">Button1</Button>
            <Button Height="38" Width="81">Button2</Button>
            <Button Height="38" Width="81">Button3</Button>
            <Button Height="38" Width="81">Button4</Button>
            <Button Height="38" Width="81">Button5</Button>
            <Button Height="38" Width="81">Button6</Button>
            <Button Height="38" Width="81">Button7</Button>
        </WrapPanel>
    </Grid>
</Window>
```

In Listing 10.7, a simple UI is created using the WrapPanel control. The Button control, which is the child element of the WrapPanel control, is added on the window from left to right.

# Setting the Absolute Position of Controls

Absolute positioning in a WPF application is done with the help of the Canvas control. The Canvas control defines an area within which you can place child elements. You can add the Canvas control to a WPF application through the XAML code. Create a WPF application named CanvasControl (available in the CD) and add the code, shown in Listing 10.8, to MainWindow.xaml file:

# Listing 10.8: Showing the Code to Implement the Canvas Control

```
<Window x:Class="CanvasControl.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="350" Width="525">
    <Canvas Background="Beige">
        <Button Canvas.Left="88" Canvas.Top="117" Height="23" Name="myButton" Width="75">Hello!</Button>
        <Label Canvas.Left="69" Canvas.Top="50" Height="28" Name="myLabel" Width="120">Example of Canvas</Label>
    </Canvas>
</Window>
```

In Listing 10.8, a label named myLabel and a button named myButton is added to the window. The positions of both these controls are set by using the Canvas.Left and Canvas.Top properties. You can run the application by pressing the F5 key.
