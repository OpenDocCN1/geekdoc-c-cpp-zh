```
private void ShowFirstWindow_Click(object sender, RoutedEventArgs e)
{
    MainWindow mainwin = new MainWindow();
    mainwin.WindowState = WindowState.Normal;
    mainwin.Show();
}
```

In the preceding code snippet, an instance named mainwin of MainWindow is created. The WindowState property of mainwin is set to WindowState.Normal and then displayed using the Show() method.
