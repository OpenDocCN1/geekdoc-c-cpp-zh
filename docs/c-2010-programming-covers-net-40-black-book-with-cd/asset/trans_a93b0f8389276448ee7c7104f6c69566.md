

Sign Tool 命令的参数描述如下：

- **command** – 提供一个命令标志，用于指定要对文件执行的操作，例如 catdb、sign、signwizard、timestamp 和 verify
- **options** – 提供一个选项标志，用于修改命令标志，例如 catdb 选项（/d、/g、/u）、sign 选项（/a、/c、/d、/f）、timestamp 选项（/t）、verify 选项（/a、/ad、/r、/o）以及全局选项（/q、/v）
- **file_name** – 提供要签名的文件的位置

## 注意

> Windows NT、Windows Me、Windows 95 和 Windows 98 不支持 Sign Tool。

## 强名称

要理解强命名程序集的概念，你应该具备扎实的公钥加密知识。那么，让我们先通过一个例子来讨论公钥加密。想象一下，你有一对密钥，其中一把密钥锁上的东西只能用另一把密钥打开，反之亦然。两把密钥上都刻有你的名字。再想象一下，你的朋友也有一对类似的密钥，上面刻着他的名字。假设你们俩各自只复制了每对密钥中的一把，并互相交换。现在，如果你用他给你的那把密钥的副本锁住一条消息发送给你的朋友，除了他之外没有其他人能解开它，因为只有他拥有这对密钥中的解锁密钥。

在前面的例子中，被复制和分发的密钥称为公钥；而由自己妥善保管、不让他人知道的密钥则称为私钥。在这种锁定/解锁密钥对的安排下交换信息有两个目的——首先，它可以防止任何人窃听你的消息；其次，它让接收者确信该消息是由经过身份验证的一方发送的。

当你创建强名称密钥对文件时，sn.exe 实用工具会将唯一的公钥-私钥对写入生成的文件中。在 AssemblyInfo.cs 文件中提及该密钥文件，编译器会通过创建属于该程序集的所有文件的哈希来锁定程序集，防止其被进一步更改。然后编译器使用私钥对哈希进行签名。此私钥不会写入程序集，而只保存在密钥文件中。可以使用公钥对其进行验证，公钥会写入程序集，并且任何引用该程序集的应用程序都可以提取它。该公钥的初始部分（称为令牌）会写入引用它的客户端的程序集清单中。要对程序集进行任何更改，你需要提及包含私钥的密钥对文件，以便编译器能够更新哈希并再次签名。因此，你需要保护密钥对文件免受未经授权的访问。

强名称由以下组件组成：

- **简单名称** – 提供一个指定程序集名称的文本字符串。
- **公钥令牌** – 提供程序集的公钥值，并使用 AssemblyKeyFile 属性进行分配。
- **版本号** – 提供程序集的主版本号和次版本号，包括修订号和内部版本号。它使用 AssemblyVersion 属性进行分配。
- **区域性信息** – 提供有关区域性或语言的信息，用于本地化。你可以使用 AssemblyCulture 属性来分配程序集的区域性。
- **数字签名** – 使用程序集内容的哈希和私钥创建。

GAC 对其安装的所有程序集执行完整性检查。在将程序集放入 GAC 之前，你需要对程序集进行强命名。如果有未经授权的用户试图访问你的程序集，GAC 将检测到这种未经授权的访问，并且在缺少密钥对文件的情况下，不允许该用户更新哈希。

## 延迟签名

延迟签名是一种在程序集仍处于开发阶段时对其进行部分签名的技术。延迟签名可防止未经授权的用户篡改程序集。延迟签名的主要目的是保护和控制程序集的私钥，并且仅在开发过程中使用它。当你必须将程序集提供给其他内部开发人员或其他公司的开发人员以进行进一步增强时，此技术非常有用。这样，其他开发人员在没有密钥对文件的情况下将无法更改你的程序集。在这种情况下，开发人员可以使用延迟签名来更改程序集并对其进行测试。

## 使用强名称实用工具

强名称实用工具 (sn.exe) 有助于创建唯一的公钥-私钥对文件，这些文件称为强名称文件，并使用它们对程序集进行签名。强名称实用工具还提供用于密钥管理、签名验证和签名生成的选项。在命令提示符下键入以下代码片段以使用 sn 实用工具：

```
sn [-quiet][option [parameter(s)]]
```

表 33.7 列出了一些重要的 sn 实用工具开关：

## 程序集的存储

如前所述，共享程序集放在称为 GAC 的程序集存储库中，通常所有应由多个应用程序共享的程序集都驻留在此处。共享程序集使用强名称（由用于标识程序集的信息组成）进行唯一标识。你可以使用 GAC 查看器查看安装在 GAC 中的所有程序集，该查看器位于 <WinDrive>:<WinDir>\assembly 目录中；其中 <WinDir> 在 Windows XP 中是 WINDOWS，在 Windows Vista 中是 Windows，在 Windows 2000 中是 WinNT。除了程序集列表之外，程序集查看器还显示相关信息，例如全局程序集名称、版本、区域性和公钥令牌。
