# Building a Self-Updating Application

You can create a self-updating Web application by setting a few deployment options in the properties of the application. Let’s make the application, DeployTestClickOnce_SelfUpdate application (also available on CD) self-updating by performing the following steps:

+   1. Right-click the project name, DeployTestClickOnce_SelfUpdate in Solution Explorer and select the Properties option. The properties of the application are displayed.

+   2. Select the Publish tab and click the Updates... button, as shown in Figure 21.33:

![](bbox=[0.17, 0.21, 0.8, 0.56])

Figure 21.33: Displaying the Properties of an Application

The Application Updates dialog box appears (Figure 21.34).

+   3. Select the The application should check for updates checkbox to ensure that the application always checks for new updates, as shown in Figure 21.34:

![](bbox=[0.27, 0.64, 0.7, 0.91])

Figure 21.34: Setting the Updating Options for the Application
