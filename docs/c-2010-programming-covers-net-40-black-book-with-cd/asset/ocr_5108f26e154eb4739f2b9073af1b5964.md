# Server Explorer

There are various services available on a particular server. These services include event logging, messa queues, crystal report services, performance counters, other system services, and Database services, such as SQ Server. Server Explorer allows you to view the services available on a particular server. This window is powerful tool that helps you to work with databases in an easy way to use graphical environment. You can drag a service from the window onto a design surface, so that you can interact with this element programmatically your application.
