## DrawingBrush 类

DrawingBrush 类使用 Drawing 类绘制区域，Drawing 类可以包含形状、文本、视频、图像或其他绘图。Drawing 类描述了 DrawingBrush 类的可视内容，该内容会拉伸绘图以填充输出区域。使用画刷显示的绘图是使用 GeometryDrawing 元素定义的。您还可以通过设置 DrawingBrush 类的 Viewport 和 TileMode 属性来创建绘图的重复图案。您可以通过添加以下代码片段将 DrawingBrush 类应用于应用程序：

```
<DrawingBrush .../>
```

DrawingBrush 类的继承层次结构如下：

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Freezable
        System.Windows.Media.Animation.Animatable
          System.Windows.Media.Brush
            System.Windows.Media.TileBrush
              System.Windows.Media.DrawingBrush
```

DrawingBrush 类的显著属性在表 12.22 中列出：

## 表 12.22：DrawingBrush 类的属性

|---|---|
| AlignmentX | 获取或设置 TileBrush 基 tiles 中内容的水平对齐方式 |
| AlignmentY | 获取或设置 TileBrush 基 tiles 中内容的垂直对齐方式 |
| Drawing | 获取或设置描述 DrawingBrush 类内容的值 |
| Stretch | 获取或设置指定 TileBrush 类内容如何拉伸以适应其 tiles 的值 |
| TileMode | 获取或设置指定 TileBrush 如何填充要绘制的区域的值，如果基 tile 小于输出区域 |

| ViewboxUnits | 获取或设置指定 Viewbox 值是否与 TileBrush 内容的边界框相关，或值是绝对的值 |

| ViewportUnits | 获取或设置一个 BrushMappingMode 枚举，指定 Viewport 的值，即 TileBrush 基 tile 的大小和位置，是否相对于输出区域的大小 |

## ImageBrush 类

您可以使用 ImageBrush 类将图像加载到画刷中。您可以加载最常见的图像文件类型，包括 bmp、png、gif 和 jpeg 文件。ImageSource 属性用于显示 ImageBrush 类中使用的图像。默认情况下，图像会被拉伸以填充 ImageSource 属性中使用的区域。但是，您可以通过设置 TileBrush 类的 Stretch 属性来修改此行为，这会导致图像保持其纵横比。您可以通过设置 Viewport 和 TileMode 属性来创建图像的重复图案。您可以通过添加以下代码片段将 ImageBrush 类添加到应用程序中：

```
<ImageBrush .../>
```

```

## VisualBrush 类

VisualBrush 类使用可视对象绘制区域，并允许您获取元素的可视内容并用其填充区域。例如，您可以将窗口中按钮的外观复制到该窗口的某个区域中。这意味着您正在使用现有图像来创建重复图像。指定 VisualBrush 类的可视内容的另一种方法是创建新的 Visual 类并使用它来设置 VisualBrush 类的 Visual 属性。使用 VisualBrush 类，您还可以创建诸如反射之类的效果。您还可以通过将 Visual 属性设置为 MediaElement 控件来使用 VisualBrush 类显示视频。您可以通过添加以下代码片段将 VisualBrush 类添加到应用程序中：

```
<VisualBrush .../>
```

```

    System.Windows.DependencyObject

          System.Windows.Media.Brush

## Drawing 类
