The WCF programming model combines Web services, .NET remoting, distributed transactions, and message queues into a single service-oriented programming model for distributed computing. WCF runs in a sandbox (a security mechanism for running programs safely) and provides the enhanced security model to all the WCF applications. To support distributed computing, WCF is designed in accordance with Service-oriented architecture principles where services are used by clients. Services typically have a Web Services Description Language (WSDL) interface, which is used by the clients to utilize the services. WCF implements many advanced Web service standards, such as WS-Addressing, WS-ReliableMessaging, and WS-Security.

# Windows CardSpace

Windows CardSpace (WCS) is a client software that helps in sharing personal information on the Internet. It helps programmers in developing websites and software that are less prone to identity related attacks, such as phishing. WCS helps in reducing the problems of traditional online security mechanisms, as it employs a separate desktop and cryptographically strong authentication, instead using user name and password, for authentication purposes. It facilitates secure online transactions, such as online shopping, banking, and bill payment.

WCS only works with websites that accept the CardSpace logins. When you try to access the resources on the website, which accepts CardSpace, a CardSpace selection window appears. You can select the required card and access the resources on the website. You can create a card using the WCS utility that comes with .NET 4.0.
