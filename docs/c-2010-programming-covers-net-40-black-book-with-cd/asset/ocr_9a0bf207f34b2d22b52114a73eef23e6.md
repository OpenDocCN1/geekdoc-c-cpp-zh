# The Queue<T> Class

Similar to the Queue class, the Queue<T> class allows you to create collections of objects such that the object that is added first to the collection is retrieved first. The class hierarchy for this class is given as follows:

```
System.Object
System.Collections.Generic.Queue<T>
```

Table 32.25 lists the important property of the Queue<T> class:

| Table 32.25: Noteworthy Properties of the Queue<T> Class |
| Property | Description |
| Count | Retrieves the number of elements contained in the Queue<T> object |

Table 32.26 lists the important methods of the Queue<T> class:

| Table 32.26: Noteworthy Methods of the Queue<T> Class |
| Method | Description |
| Clear() | Removes all items from the Queue<T> object |
| Contains() | Ascertains whether or not an item is in the Queue<T> object |
| CopyTo() | Copies the Queue<T> object elements to an existing one-dimensional array |
| Dequeue() | Removes and returns an object from the beginning of the Queue<T> object |
| Enqueue() | Adds an object to the end of the Queue<T> object |
| Peek() | Returns an object from the beginning of the Queue<T> object without removing it |
| ToArray() | Copies the Queue<T> object elements to a new array |

# The HashSet<T> Class

The HashSet<T> class represents a set of values. A set is a collection that does not contain duplicate elements. In addition, it does not store elements in a particular order. The class hierarchy for this class is given as follows:

```
System.Object
System.Collections.Generic.HashSet<T>
```

Table 32.27 lists the important property of the HashSet<T> class:

| Table 32.27: Noteworthy Properties of the HashSet<T> Class |
| Property | Description |
| Count | Retrieves the number of elements contained in the HashSet<T> object |

Table 32.28 lists the important methods of the HashSet<T> class:

| Table 32.28: Noteworthy Methods of the HashSet<T> Class |
| Method | Description |
| Add() | Adds the specified item to the HashSet<T> object |
| Clear() | Removes all elements from the HashSet<T> collection |
| Contains() | Ascertains whether or not the HashSet<T> object contains the specified item |
