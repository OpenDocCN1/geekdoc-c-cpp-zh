# Using the HiddenField Control

When you add a HiddenField control on a Web page, the following code is added to the source code of the Web page:

```
```aspx
<asp:HiddenField ID="HiddenField1" runat="server" />
```
```

Now, let's create a Web application named HiddenFieldControl (also available in CD-ROM) to show the working of HiddenField control. You can add a HiddenField control to a Web page either by dragging and dropping it from the Standard tab of the Toolbox or by double-clicking it in the Toolbox. When you click the Button control in these applications, it displays the value stored in the HiddenField control in the Label control. Listing 14.8 shows the code of Default.aspx page for the HiddenField control:
