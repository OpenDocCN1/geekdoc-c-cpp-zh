```
number1 = 127;
number2 = 127;

try
{
    result = unchecked((byte)(number1 * number2));
    Console.WriteLine("Unchecked result: " + result);

    result = checked((byte)(number1 * number2));
    Console.WriteLine("Checked result: " + result);
}
catch (OverflowException exc)
{
    Console.WriteLine(exc);
}
finally
{
    Console.Write("\nPress ENTER to quit...");
    Console.ReadLine();
}
}
```

In Listing 3.16, you can see that we have taken two byte type variables number1 and number2 and assign the value 127 to both of them. In the try block, the result of multiplication of both the variables is stored in another byte type variable, result. As the multiplication of values stored in number1 and number2 variables exceeds the limit of the value that can be stored in the result variable; therefore, an exception occurs. In this case, the checked statement causes the overflow exception and displays the exception message; however, the unchecked statement does not cause any exception and displays the result.
