# PresentationCore

The PresentationCore component is implemented as the PresentationCore.dll assembly in .NET Framework 4.0. This component provides some of the most commonly used types and features of WPF 4.0. The classes and types offered by the PresentationCore component provide certain essential functionalities, such as properties, events, and messages in WPF 4.0. Note that the PresentationCore component does not provide data types for the UI of WPF 4.0 applications, as provided by the PresentationFramework component.

# WindowsBase

The WindowsBase component is implemented as the WindowsBase.dll assembly in .NET Framework 4.0. This component provides the fundamental WPF features, such as threading, type converters, and dependency properties. Some of these features can be accessed and used outside the WPF domain.

# MIL or Milcore

Milcore is an unmanaged component in WPF 4.0. Milcore interacts with DirectX and acts as a medium or interface between DirectX and CLR (and managed WPF components). Due to this interaction with DirectX, milcore allows the display of 2-D as well as 3-D graphical content in WPF 4.0 applications and also allows you to work with animations, render 3-D scenes, and much more. Milcore has a composition engine that uses the hardware and software rendering of DirectX for WPF 4.0 applications. Note that milcore is able to use DirectX for WPF applications only because it is an unmanaged component.

# The System.Windows.Threading.DispatcherObject Class

The DispatcherObject class exists in the System.Windows.Threading namespace to manage threads. WPF applications run with two threads—one for the UI and the other for the rendering, by default. The UI thread is the main executing thread that obtains inputs and events, while the rendering thread runs in the background.
