# Assembly Signing

There are two ways to sign an assembly in .NET Framework 3.5— by using a strong name and by using the SignTool.exe file, also called the Sign Tool. When you sign an assembly using a strong name, a public key encryption is added to the file containing the assembly manifest. Signing an assembly using a strong name provides an identity to the assembly and also verifies whether the name of the assembly is unique or not. On the other hand, signing an assembly using the Sign Tool provides a strong name and digital signature to the assembly. Sign Tool requires a publisher to show its identity to a third-party authority and get a certificate. This certificate is then embedded into a file that the administrator uses to find out whether or not to trust the code’s authenticity. An assembly signed using Sign Tool guarantees authenticity and integrity through digital signatures and certificates. In addition, Sign Tool also performs various functions, such as hash verification, strong naming, and signing to ensure that the assembly has not been tampered.

Sign Tool provides a command-line tool to digitally sign files and verify signatures in files. You can sign an assembly using the following command at the command prompt:

```
signtool [command] [options] [file_name]
```
