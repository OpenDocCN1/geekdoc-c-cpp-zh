## Types of Drawing Objects

在上一节中，你已了解到 Drawing 类中的 Drawing 对象可让你向应用程序添加几何形状、图像、文本和媒体。Drawing 对象用于高效绘制形状、位图、文本和媒体。你可以在创建剪贴画或使用 DrawingBrush 类进行绘画时使用 Drawing 对象。不同类型的 Drawing 对象描述如下：

- The GeometryDrawing class — 借助 Geometry 类及其属性、Pen 和 Brush 使你能够创建具有填充和轮廓的形状。Geometry 类描述形状的结构，Brush 属性描述形状的填充颜色，而 Pen 属性描述轮廓。
- The ImageDrawing class — 使你能够使用 DrawingBrush、DrawingImage 或 Visual 显示 ImageSource。ImageSource 属性指定要绘制的图像，而 Rect 属性指定每个图像的位置和大小。
- The GlyphRunDrawing class — 表示呈现 GlyphRun 对象的 Drawing 对象。GlyphRun 类包含字体细节，例如字形索引和各个字形位置。简单来说，要绘制文本，你使用 GlyphRunDrawing 和 GlyphRun 对象。
- The VideoDrawing class: 使你能够播放媒体文件。你可以使用 VideoDrawing 类和 MediaPlayer 类播放音频或视频文件。
- The DrawingGroup class — 使你能够将一组绘图组合为可作为单个绘图操作的集合。DrawingGroup 类还使你能够对其内容应用不透明度蒙版、变换、位图效果和其他操作。DrawingGroup 类的操作按以下顺序应用：OpacityMask、Opacity、BitmapEffect、ClipGeometry、GuidelineSet，然后是 Transform。

## The DrawingContext Class

DrawingContext 类使用 draw、push 和 pop 命令描述视觉内容。DrawingContext 类的对象从 DrawingGroup 对象获取，并使用 Image 控件显示。你可以使用 DrawingContext 类为 Visual 类或 Drawing 类填充视觉内容。DrawingContext 类不用于实时向屏幕绘制。你永远不能直接实例化 DrawingContext 类。然而，你可以从某些方法获取 DrawingContext 对象，例如 DrawingGroup.Open() 和 DrawingVisual.RenderOpen()。DrawingContext 类由向视觉添加图形细节的方法组成。你可以调用这些方法来绘制各种形状、应用变换或更改不透明度。你可以在表 12.27 中找到 DrawingContext 类的方法：

## 3-D Graphics

WPF 提供了一套与 2-D 绘图集成的 3-D 绘图，以创建具有视觉吸引力的布局、UI 和数据可视化。WPF 中的 3-D 实现允许开发人员在 XAML 和代码中绘制、变换和动画化 3-D 绘图。你可以组合 2-D 和 3-D 绘图来创建丰富的控件并增强应用程序界面的用户体验。在 WPF 中创建 3-D 绘图时使用最重要的类是 Viewport3D、Camera、Material 和 Light，你接下来将学习它们。

## The Viewport3D Class

在 WPF 中，如果你想使用 3-D 内容，你需要一个可以承载它的容器。容器是 Viewport3D 类，它位于 System.Windows.Controls 命名空间中。Viewport3D 类派生自 FrameworkElement 类；因此，你可以将 Viewport3D 类与元素一起放置。Viewport3D 类显示 3-D 内容，同时提供与 2-D 布局一致的属性，例如剪辑、高度、宽度和鼠标事件。Viewport3D 类有两个重要属性：Camera 和 Children。Viewport3D 类的 Camera 属性定义 3-D 场景中内容的视点，而 Children 属性保存你想要放置在场景中的所有 3-D 对象。照亮 3-D 场景的光源是 Viewport3D 类的对象。你可以通过添加以下代码片段将 Viewport3D 对象添加到你的应用程序中：

## The PerspectiveCamera Class

`PerspectiveCamera` 类表示透视投影相机。它以远处物体看起来更小的方式渲染场景。`PerspectiveCamera` 类派生自 `ProjectionCamera` 基类。它是 WPF 中最通用且最常用的相机。`PerspectiveCamera` 类指定 3-D 模型对象到 2-D 视觉表面的投影。使用 `PerspectiveCamera` 类描述的对象其侧面会向地平线上的一个点汇聚。更靠近相机的物体看起来更大，而离相机更远的物体看起来更小。你可以通过设置 `NearPlaneDistance` 和 `FarPlaneDistance` 属性来限制相机的范围。`NearPlaneDistance` 属性允许你指定近剪裁平面距相机的最小距离。另一方面，`FarPlaneDistance` 属性允许你指定远剪裁平面距相机的距离，这确保了太远的 3-D 对象不会包含在场景中。你可以通过添加以下代码将 `PerspectiveCamera` 对象添加到你的应用程序中：

## The OrthographicCamera Class

`OrthographicCamera` 类表示正交投影相机，并指定 3-D 模型到 2-D 视觉表面的正交投影。它指定位置、观看方向和向上方向。它还描述了一个视框，其各边是平行的，而不是像 `PerspectiveCamera` 类那样在地平线上汇聚到一点。`OrthographicCamera` 类会压平 3-D 对象，以便无论形状位于何处，精确的比例都得以保持。你可以通过添加以下代码片段将 `OrthographicCamera` 对象添加到你的应用程序中：
