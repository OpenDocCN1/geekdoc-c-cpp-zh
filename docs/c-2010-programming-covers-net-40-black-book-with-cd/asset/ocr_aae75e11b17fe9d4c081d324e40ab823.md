Ease of deployment – Provides easy deployment of applications. In most cases, to install an application, you need to copy the application, along with its components, on the target computer. .NET Framework provides the deployment of .NET applications in the form of assemblies, so that registry entries are not required to store information about components and applications.

# Overview of .NET Framework 4.0

The new version of .NET provides a framework that helps in designing portable, scalable, and robust applications. The applications developed in .NET Framework 4.0 can be executed in a distributed environment as the framework provides a computing platform in a managed environment.

.NET Framework 2.0 and 3.0, along with their service packs, form the foundation of .NET Framework 4.0. In other words, apart from few additional enhancements, the architecture of .NET Framework 4.0 mainly consists of components of .NET Framework 2.0, 3.0, and 3.5.

Figure 1.1: Displaying the Architecture of .NET Framework 4.0

As shown in Figure 1.1, .NET Framework 4.0 consists of the CLR, .NET Framework Base Class Library, Windows Forms, ASP.NET, Console, ActiveX Data Objects for .NET (ADO.NET), .NET Framework Class Library, Common Language Specification (CLS), Common Type System (CTS), and .NET languages, such as C# and Visual Basic.NET. Similarly, .NET Framework 4.0 comprises the Windows Workflow Foundation (WF), Windows Presentation Foundation (WPF), Windows Communication Foundation (WCF), and Windows CardSpace technologies. Finally, .NET Framework 4.0 has few additional components, such as Language Integrated Query (LINQ), ActiveX Data Object.NET (ADO.NET), Entity Framework and Data services, ASP.NET AJAX, new compilers for C#, Visual Basic, and C++. The components of .NET Framework 4.0 architecture are as follows:

+   - CLR
+   - CTS
+   - Metadata and assemblies
+   - .NET Framework class library
+   - Windows Forms
+   - ASP.NET and ASP.NET AJAX
+   - ADO.NET
+   - WF
