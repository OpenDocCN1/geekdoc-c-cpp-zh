# Flow Content Elements

In WPF, flow content elements provide building blocks to create flow content suitable for hosting in a FlowDocument. The Flow content elements can be categorized under two broad classes: Block and Inline. The classes derived from the Block class are used to contain objects, such as paragraphs and lists, while classes derived from the Inline class contain objects that are displayed in a document, such as linebreak and span. The Block and Inline classes are the abstract classes that are derived from the TextElement class. The inheritance hierarchy of the TextElement class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.ContentElement
        System.Windows.FrameworkContentElement
          System.Windows.Documents.TextElement
```
