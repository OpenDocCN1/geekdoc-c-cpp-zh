Let's first create a class library named FileAccessLib (on the CD-ROM) by performing the following steps:

+   1. Open the Visual Studio 2010 IDE and select File→New→Project to open the New Project dialog box. In the dialog box, select the Visual C# option in the Project types pane and the Class Library option in the Templates pane. Specify FileAccessLib as the name of the project, select an appropriate location, and click the OK button. The FileAccessLib library is created.

+   2. Open the Class1.cs file and add the code given in Listing 36.28:

# Listing 36.28: Code of Class1.cs file of the FileAccessLib Application

```
using System;
using System.Collections.Generic;
using System.Text;
using System.IO;
using System.Security.Permissions;

namespace FileAccessLib
{
public class Class1
{
public bool AccessFile(ref string FileText)
{
try
{
System.IO.FileStream fs = new
System.IO.FileStream("C:\\file.txt",
FileMode.OpenOrCreate, FileAccess.Write);
StreamWriter w = new StreamWriter(fs);
w.BaseStream.Seek(0, SeekOrigin.End);
w.WriteLine("Here is the file's text.");
w.Write("Here is more file text." +
System.Environment.NewLine);
w.WriteLine("And that's about it.");
w.Flush();
w.Close();
fs = new System.IO.FileStream("C:\\file.txt",
FileMode.Open, FileAccess.Read);
StreamReader r = new StreamReader(fs);
r.BaseStream.Seek(0, SeekOrigin.Begin);
FileText = "";
while (r.Peek() > -1)
{
FileText += r.ReadLine() +
System.Environment.NewLine;
}
r.Close();
return true;
}
catch //ex As Security.SecurityException
{
return false;
}
}
}
}
```

In Listing 36.28, a local file named file.txt is opened, changed, and then saved.

+   3. Open the AssemblyInfo.cs file of FileAccessLib application and add the following line of code:

```
[assembly: AllowPartiallyTrustedCallers()]
```

By adding this line of code, applications running with partial trust can call the FileAccessLib class library.
