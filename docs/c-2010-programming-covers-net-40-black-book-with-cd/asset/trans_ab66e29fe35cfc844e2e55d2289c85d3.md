# Visual Studio 2010 中的部署技术

Visual Studio 2010 提供了两种技术，即 Windows Installer 和 ClickOnce，用于部署基于 Windows 的应用程序。Windows Installer 技术创建安装程序文件（.msi），该文件用于分发应用程序进行部署。另一方面，ClickOnce 部署技术用于将应用程序发布到中心位置，用户可以从该位置安装或运行应用程序。在以下各节中，让我们了解这些技术。

# Windows Installer 部署技术

Windows Installer（也称为 Microsoft Windows Installer，MSI）是一种软件安装和配置服务，用于在 Windows 操作系统上安装、维护或删除软件应用程序。该服务包含它所安装的每个应用程序的信息。Windows Installer 服务在三个级别上验证应用程序：产品、功能和组件。产品级别包含作为产品用户可以安装的完整应用程序；功能级别包含产品的一个或多个功能；组件级别包含应用程序中逻辑相关的一个或多个文件。请注意，组件级别的文件可以是 .exe、.dll 或文本文件。

Windows Installer 允许您通过创建 Windows Installer 包来部署 Windows 和 Web 应用程序。安装程序包的扩展名为 .msi，包含应用程序、任何依赖文件、注册表项等。只需将该安装程序包复制到目标计算机上，即可将其分发给各种最终用户。最终用户随后可以运行安装程序包在其计算机上安装应用程序。安装应用程序后，最终用户可以从计算机的程序列表中运行该应用程序。
