# The Expander Control

The Expander control represents a control that displays a header with a collapsible window. You can set the content area of the Expander control to expand in one of the four directions: Down, Up, Left, and Right by using the ExpandDirection property. When the content area of the Expander control collapses, only the ExpanderHeader and its toggle button are visible.

The Expander control is represented by the Expander class. The inheritance hierarchy of the Expander class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.ContentControl
                System.Windows.Controls.HeaderedContentControl
                  System.Windows.Controls.Expander
```

You can add the Expander control to a WPF application by using the following code snippet:

```
<Expander>
  <!--Content-->
</Expander>
```

Table 10.28 describes the noteworthy properties of the Expander class:

# Table 10.28: Noteworthy Properties of the Expander Class

| Property | Description |
|---|---|
| ExpandDirection | Gets or sets the direction in which the expander window opens |
| IsExpanded | Gets or sets a value that indicates whether the Expander control to be displayed as expanded or collapsed |
