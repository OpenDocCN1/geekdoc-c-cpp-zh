## WCF Service Identity

WCF service identity is a value generated from WSDL for a service at design time. This value is transmitted to a client and the client uses it to authenticate the WCF service before calling any of its operation. On the other hand, a WCF service also authenticates a client's credentials before allowing access to its operations. The service identity is represented by the identity property of the EndpointAddress class. You can obtain the service identity by using the Service Model Metadata Utility tool (Svcutil.exe). Through this tool, a configuration file is generated automatically for the WCF service that contains the value of service's identity property. Table 19.5 shows each identity type along with its description:

| Table 19.5: Showing the WCF Service Identity |
|---|---| 
| Identity type | Description |
| Domain Name System (DNS) | Compares DNS specified in the credential of the WCF service with the value specified in the identity element |
| Certificate | Compares a Base64-encoded X.509 certificate value with a client |
| Certificate Reference | Enables you to specify a certificate name and location from where to retrieve the certificate |
| Rivest, Shamir and Adleman (RSA) | Specifies an RSA key value to compare with a client |
| User Principal Name (UPN) | Specifies the UPN under which a service is running |
| Service Principal Name (SPN) | Specifies the SPN associated with the service's account |

### Creating a Service Contract and Defining the Operations

A service contract defines the operations that a service can perform. The ServiceContractAttribute attribute is used with interfaces or classes to define a service contract. The methods that a service offers are defined through the OperationContractAttribute attribute. In a WCF service application, a file named IService.cs is automatically created, containing a service contract named IService. Replace the code of the IService service contract with the code given in Listing 19.5 to create a service contract:

Listing 19.5: Showing the Code of the IService.cs File

```
[ServiceContract]
public interface IService {
    [OperationContract]
    double SquareRoot(double Number);
    [OperationContract]
```

```
double CubeRoot(double Number1);
// TODO: Add your service operations here
}
```

In Listing 19.5, the methods that are offered by the service, such as SquareRoot and CubeRoot, are defined using the OperationContractAttribute attribute.

### Implementing the Service Contract

A class that implements a service contract is called a service type. The MyFirstWCFService application contains a file named Service.cs. In the Service.cs file, a class named Service implements the service contract which is defined in the IService interface. All the methods that are defined in the IService interface with the OperationContractAttribute attribute are implemented in the Service class, as shown in Listing 19.6:

Listing 19.6: Showing the Code of the Service.cs File

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Runtime.Serialization;
using System.ServiceModel;
using System.Text;
public class Service : IService {
public double SquareRoot(double Number1) {
    double Output = Number1 * Number1;
    return Output;
}
public double CubeRoot(double Number1) {
    double Output = Number1 * Number1 * Number1;
    return Output;
}
}
```
