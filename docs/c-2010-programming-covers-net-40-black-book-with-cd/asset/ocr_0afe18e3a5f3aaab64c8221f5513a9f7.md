# Reading Data

You can read all the element data and attribute values from an XML file. In addition, you can read data for single element by specifying the name of the element. Let's create an application, named ReadingXMLData (also available on the CD) to read the XML data.

Perform the following steps to create the ReadingXMLData application:

+   1. Create a Windows Forms application, named ReadingXMLData.
+   2. Add the authors.xml file in the bin\Debug folder of the ReadingXMLData application.
+   3. Add the following namespace in the Form1.cs file:
+      using System.Xml;
+   4. Add a list box and three button controls from the Toolbox to Form1.
+   5. Set the Text property of the buttons to Show All Elements, Show Last Names, and Show All Attributes, respectively.
+   6. Double-click the Show All Elements button and add the following code snippet:

```
private void button1_Click(object sender, EventArgs e)
{
    listBox1.Items.Clear();
    XmlReader xr = XmlReader.Create("authors.xml");
    while (xr.Read())
    {
        if (xr.NodeType == XmlNodeType.Text)
            listBox1.Items.Add(xr.Value);
    }
}
```

In the preceding code snippet, we have created a blank list box and an object of the XmlReader class by calling its Create() method and passing the name of the XML file (authors.xml) as a parameter to it. We have then traversed the nodes of the XML document by using the Read() method of the XmlReader object in a while loop. Inside the loop, we have compared its NodeType with the values from the XmlNodeType enumeration for each node. If it is a text node, we are adding the text value to the list box.

+   7. Double-click the Show Last Names button and add the following code snippet:

```
private void button2_Click(object sender, EventArgs e)
{
    listBox1.Items.Clear();
    XmlReader xr = XmlReader.Create("authors.xml");
    while (xr.Read())
    {
        if (xr.NodeType == XmlNodeType.Element && xr.Name == "au_lname")
            listBox1.Items.Add(xr.ReadElementString());
        else
            xr.Read();
    }
}
```

In the preceding code snippet, we have created a blank list box. After that, we have created an object of the XmlReader class by calling its Create() method and passing the name of the authors.xml file as a parameter to it. We have then traversed the nodes of the XML document by using the Read() method of the XmlReader object in a while loop. Inside the loop, we have checked if the current node is of type XmlNodeType.Element, and its name is au_lname. If it is, we add the text value for the element to the list box by using the ReadElementString() method of the XmlReader object. If not, we move to the next node by using the Read() method of the XmlReader object.
