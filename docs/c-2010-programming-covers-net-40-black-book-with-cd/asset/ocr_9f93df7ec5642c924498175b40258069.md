# Adding Rows and Columns to a Grid Through XAML

The In Depth section of this chapter explains that the Grid element (or control) is by default added to standalone WPF applications and XBAPs. As you may recall, the Grid element by default has only one cell, that is, one row and one column. If you want to vertically increase the number of cells in the grid, then you need to add more rows in the Grid element. You can also remove the rows in case there are superfluous rows. Similarly, to increase the number of cells horizontally in the Grid element, you need to add more columns. In this way, every row can have multiple columns.

Note that the changes you make in the XAML view is immediately reflected in the Design view and vice versa.

Now, let’s create a standalone WPF application named GridRowsColumns (also available in CD) by performing the following steps:

+   1. Create a new WPF Application, GridRowsColumns.

+   2. Add the following code snippet within the <Grid> and </Grid> tags in the MainWindow.xaml file:

```
<Grid.RowDefinitions>
  <RowDefinition Height="20"/>
  <RowDefinition Height="50"/>
  <RowDefinition Height="50*"/>
  <RowDefinition Height="50*"/>
</Grid.RowDefinitions>
```

In preceding code snippet, the Grid.RowDefinitions element is a child element of the Grid element. The Grid.RowDefinitions element has four child RowDefinition elements that define the four rows in the grid. The Height attribute of the RowDefinition elements is set to specify the height of each row. The height of the first row is 20 pixels and the second row is 50 pixels. The third and the fourth rows have a height of 50*, where the asterisk indicates the percentage of the remaining space in the grid.

+   3. Add the columns in the grid by using the following code snippet inside the <Grid> and </Grid> tags in the GridRowsColumns application:

```
<Grid.ColumnDefinitions>
  <ColumnDefinition Width="25"/>
  <ColumnDefinition Width="50"/>
  <ColumnDefinition Width="30*"/>
  <ColumnDefinition Width="50*"/>
</Grid.ColumnDefinitions>
```
