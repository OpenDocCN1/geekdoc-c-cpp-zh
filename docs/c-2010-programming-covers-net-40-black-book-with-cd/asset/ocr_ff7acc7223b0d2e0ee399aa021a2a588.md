# Handlers for Routed Events

As you have learned, routed events traverse through the element tree. They are raised and handled at the level of each element from the source element to the root element or vice versa. There is an entire range of routed events offered by WPF. You can easily and conveniently handle these routed events in the code-behind file. The syntax for event handlers of routed events is as follows:

```
public returnType eventHandlerName(object sender, RoutedEventArgs e)
{
    //event handling logic
}
```

In the preceding syntax:

+   - public, object, RoutedEventArgs — Represents the C# keywords.

+   - returnType — Represents the return type of the event handler.

+   - eventHandlerName — Represents the name of the event handler. It is recommended that the name of the event handler is of the form elementName_eventName, where elementName is the owner of the routed event and eventName is the name of the event.

+   - sender — Represents the latest sender of the event, that is, the element on which the event is raised most recently.

Note that the RoutedEventArgs class is the base class that provides information related to the raised routed event. For instance, the original source or element that raised the routed event is available through this class. You can also use any of the derived classes of the RoutedEventArgs class for more specific information about the routed event. Table 9.14 lists the noteworthy properties of the RoutedEventArgs class:

| Table 9.14: Noteworthy Properties of the RoutedEventArgs Class |
| Property | Description |
| Handled | Sets or retrieves a value that indicates the current state of handling of a routed event. If this property is set to true, then the event handling stops instantaneously. In case of paired events, if you have set the Handled property to true for a tunneling event, then the bubbling event does not appear. |
| OriginalSource | Retrieves the source or element that originally raised the routed event. The original source is determined by hit testing. |
| Source | Retrieves the source that raised the event. In most cases, OriginalSource and Source refer to the same element; however, the OriginalSource may be a more specific or nested element. |
| RoutedEvent | Sets or retrieves the routed event that is handled by the event handler method. |

> NOTE
> The event handler that you create is passed as an argument to the RoutedEventHandler delegate.

After you have added the event handler of a routed event in the code-behind file, you need to associate the handler with the appropriate event. You can do so by using various event attributes in the XAML file. You should note that the name of the attribute must be same as the name of the event. For example, the Click attribute of the Button element allows you to specify the event handler for the Click event in the XAML file, as shown in the following code snippet:

```
<Button Height="25" Width="75" Name="myButton" VerticalAlignment="Center" Click="myButton_Click">Button1</Button>
```

In the preceding code snippet, a method named myButton_Click() defined in the code-behind file is specified as the event handler for the Click event of myButton button.

Alternatively, you can associate the handler with the routed event in the code-behind file. For instance, the Click event of the myButton button is associated with the myButton_Click() method by using the += operator, as shown in the following code snippet:

```
myButton.Click += new RoutedEventHandler(myButton_Click);
```
