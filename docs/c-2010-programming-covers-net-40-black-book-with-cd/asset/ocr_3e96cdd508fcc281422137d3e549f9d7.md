# Using the fixed Statement

A fixed statement in a program prevents the garbage collector to relocate the variable. You can use the fixed statement only in an unsafe context, as the fixed statement sets a pointer to a managed variable and pins the variable during the execution of statement. Without the fixed keyword, pointers to managed variables are little use since garbage collection can relocate the variables unpredictably.
