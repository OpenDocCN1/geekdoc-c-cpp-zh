## The EntityDataSource Control

The EntityDataSource control helps you to connect with ADO.NET Entity Data Model (EDM) to perform various database operations, such as create, insert, remove, and update. When you add an EntityDataSource control to your ASP.NET page, the following line of code appears in the Source view page:

```
<asp:EntityDataSource ID="EntityDataSource1" runat="server"> </asp:EntityDataSource>
```

The inheritance hierarchy of the EntityDataSource control is as follows:

```
System.Object
  System.Web.UI.Control
    System.Web.UI.DataSourceControl
      System.Web.UI.WebControls.EntityDataSource
```
