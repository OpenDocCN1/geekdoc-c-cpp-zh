

## 标准查询运算符

标准查询运算符是构成 LINQ 模式的方法。这些运算符提供查询功能，包括过滤、投影、聚合和排序。LINQ 中的标准查询运算符是一个应用程序编程接口（API），它能够查询任何 .NET 数组或集合。你可以使用这些标准查询运算符对项目序列进行操作。

LINQ 中标准查询运算符分为两类：

- 操作类型为 IEnumerable<T> 的对象
- 操作类型为 IQueryable<T> 的对象

标准查询运算符在执行时间上有所不同。时间取决于它们是否需要返回单个值或值序列。返回单个值的方法会立即执行。返回值序列的方法会重新安排查询执行并返回一个可枚举对象。

表 27.1 列出了 LINQ 中使用的所有标准查询运算符：

| Operator | Description |
|---|---|
| Filtering Operator | Restricts the result set to contain those elements that satisfy a specific condition that are returned |
| Projection Operator | Transforms an object into a different type of new object |
| Sorting Operator | Changes the order of elements of sequence returned by the query |
| Join Operator | Combines collections |
| Grouping Operator | Puts the data into groups |
| Quantifier Operator | Checks whether an element of a sequence satisfies a condition |
| Partitioning Operator | Returns a subset of collection |
| Set Operator | Returns a result set which is in the form of a collection |
| Element Operator | Returns just one element |
| Aggregate Operator | Computes a single value from a collection |
| Conversion Operator | Converts the collection to an array |
| Generation Operator | Returns a new sequence of values |

这只是对 LINQ 中使用的标准查询运算符的简要描述。现在，让我们详细讨论这些运算符。

### Filtering Operators

过滤，顾名思义，是指过滤结果集的操作，使其仅包含满足指定给定条件的元素。where 子句用作 LINQ 中的过滤运算符。where 子句用于根据给定条件过滤序列。使用 where 子句与 LINQ 的语法如下：

```
public static IEnumerable<T> where<T>(
    this IEnumerable<T> source,
    Func<T, bool> predicate);
```

where 子句用于在查询表达式中指定从数据源返回哪些元素到查询表达式中。例如，你可以使用 where 子句过滤除小于 5 的数字之外的数字。你可以在本章的 Immediate Solutions 部分找到使用 where 子句的详细示例。

### Projection Operators

投影运算符用于将对象转换为不同类型的新对象。你可以使用投影运算符从每个对象构建不同类型的新对象。Select() 和 SelectMany() 方法是 LINQ 中使用的投影运算符。

Select() 方法对序列执行投影，并基于转换函数投影值。Select() 方法的功能使用 select 子句实现。LINQ 中的 select 子句执行的功能与 SQL 中的 Select 语句相同，它指定要检索哪些元素。例如，你可以使用 select 子句从字符串列表中的每个字符串投影第一个字母。使用 select 子句的语法如下：

```
public static IEnumerable<S> Select<T, S>(this IEnumerable<T> source,
Func<T, S> selector);
```

LINQ 中使用的第二种投影运算符是 SelectMany() 方法。它基于转换函数投影值序列，然后将它们组织成一个序列。SelectMany() 方法的功能使用 from 子句实现。使用 from 子句的语法如下：

```
public static IEnumerable<S> SelectMany<T, S>(
this IEnumerable<T> source,
Func<T, IEnumerable<S>> selector);
```

你可能想知道 Select() 和 SelectMany() 方法之间的区别。两种方法都用于从值源产生结果值。然而，区别在于结果值。Select() 方法用于为每个源值产生一个结果值。结果值是一个集合，其元素数量与查询相同。

相比之下，SelectMany() 方法产生一个包含来自查询的连接集合的单个结果。

### Sorting Operators

LINQ 中的排序运算符根据一个或多个属性排列序列的元素。这意味着要使用排序运算符，首先需要指定特定属性并对元素进行主要排序。然后需要指定第二个排序标准并在主要排序组内对元素进行排序。不同的排序运算符是 orderby、OrderByDescending、ThenBy、ThenByDescending 和 Reverse 子句。

排序功能是通过 orderby 子句实现的。排序可以是升序或降序。orderby 子句的默认行为是以升序对数据进行排序。如果你想以降序对数据进行排序，则需要使用 orderbydescending 子句。

使用 orderby 子句的语法如下：

```
public static OrderedSequence<T> OrderBy<T, K>(
this IEnumerable<T> source,
Func<T, K> keySelector);
```

同样，你可以使用 orderbydescending 子句以降序对字符串进行排序，如以下代码所示：

```
public static OrderedSequence<T> OrderByDescending<T, K>(
this IEnumerable<T> source,
Func<T, K> keySelector);
```

### Join Operators

LINQ 中的 Join 运算符用于将一个数据源中的对象与另一个数据源中共享公共属性的对象连接起来。Join 和 GroupJoin 子句充当 LINQ 中的 Join 运算符。Join 子句实现内连接，这是一种仅返回在其他数据集中有匹配的对象类型的连接。GroupJoin 子句基于键选择器函数连接两个序列并对结果进行分组。使用 Join 子句的语法如下：

```
public static IEnumerable<V> Join<T, U, K, V>(
this IEnumerable<T> outer,
IEnumerable<U> inner,
Func<T, K> outerKeySelector,
Func<U, K> innerKeySelector,
Func<T, U, V> resultSelector);
```

### Grouping Operator

LINQ 中的分组运算符用于将数据分组，以便每个组中的元素共享公共属性。group by 子句是 LINQ 中使用的分组运算符，它返回一个序列 IGrouping<TKey, TElement> 对象，其中包含与组键值匹配的零个或多个项目

使用 group by 子句的语法如下：

```
public static IEnumerable<IGrouping<K, T>> GroupBy<T, K>(
this IEnumerable<T> source,
Func<T, K> keySelector)
```

### Quantifier Operators

量化运算符如果序列的元素满足特定条件则返回布尔值。归类为量化运算符的子句有 Any、All 和 Contains。Any 子句确定序列中是否有任何元素满足条件。此子句枚举源序列并在任何元素满足条件时返回 True。源序列的枚举在结果已知后立即终止。如果参数为 null，则会抛出 ArgumentNullException 异常。使用 Any 子句的语法如下：

```
public static bool Any<T>(
this IEnumerable<T> source);
```

All 子句确定序列中的所有元素是否满足给定条件。此子句枚举源序列并在没有元素未能通过查询传递的测试时返回 True。All 子句对空序列返回 True 值。如果参数为 null，则会抛出 ArgumentNullException 异常。

使用 All 子句的语法如下：

```
public static bool All<T>(
this IEnumerable<T> source,
Func<T, bool> predicate);
```

Contains 子句确定序列是否包含指定的元素。Contains 子句检查源序列以确定它是否包含指定的元素。当找到匹配的元素时，Contains 子句返回结果。

Contains 子句的语法如下：

```
public static bool Contains<T>(
this IEnumerable<T> source,
T value);
```

### Partitioning Operators

LINQ 中的分区运算符用于将输入序列分为两个部分，而不重新排列元素，然后返回满足给定条件的其中一个部分的结果集。Take、Skip、TakeWhile 和 SkipWhile 子句被称为分区运算符。Take 子句获取序列中指定位置之前的元素。TakeWhile 子句根据指定的函数获取元素，直到元素不满足给定条件为止。
