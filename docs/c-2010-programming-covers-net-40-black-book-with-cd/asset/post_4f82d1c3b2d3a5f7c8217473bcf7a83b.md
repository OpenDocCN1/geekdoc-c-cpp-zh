In the MainWindow() method, the principal policy of the current application domain is set to the PrincipalPolicy.WindowsPrincipal. This causes users and user groups of the underlying Windows operating system user accounts to be the base for the current principal (user). A WindowsPrincipal object named winP represents the current principal on the current thread. Now, in the EditImage_Click event handler, a PrincipalPermission object named editPermission is defined with the required user name (identity) as Sanchita and the required role as a built-in user group Administrators.
