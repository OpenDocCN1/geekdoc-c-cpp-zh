To add the nodes of the TreeView control at design time, choose the Edit Nodes option from the Smart Tag of the TreeView Control. Once you click the Edit Node option, a TreeView Node Editor dialog box appears (shown earlier in Figure 15.3).

You can now add nodes by clicking the Add a root node button on the Toolbar of the TreeView Node Editor dialog box, as shown in Figure 15.7:

![](bbox=[0.269, 0.45, 0.801, 0.729])

You can now add root or parent nodes by clicking the first button (Add a root node), and the child nodes by clicking the second button (Add a child node). Set the Text property for the nodes under the Properties panel. After creating the navigation structure for the application, we have created six different TreeView controls, each one with different styles of formatting.
