# Support for Call Hierarchy

In Visual Studio 2010, the call hierarchy feature allows you to navigate the members from one level to another. These members are navigated through the Call Hierarchy window in the following ways:

+   - Call from — Navigates a member to the members that call it
+   - Call to — Navigates a member to the members that are called by it

The Call Hierarchy window is available in Visual C# and Visual C++ and displays the calls made to or from a method, property, or constructor. In addition to these calls, the call hierarchy also displays the implementations of an interface member and the members overriding the virtual and abstract members. You can open the Call Hierarchy window by right-clicking on a method, property, or constructor, and selecting the View Call Hierarchy option from the context menu
