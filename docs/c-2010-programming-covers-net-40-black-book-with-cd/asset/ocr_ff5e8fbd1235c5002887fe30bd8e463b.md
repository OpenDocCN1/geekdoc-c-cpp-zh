Perform the following steps to open an application configuration file and use it to configure the ASimpleClient application:

+   1. Open the .NET Framework 2.0 Configuration tool and open the My Computer→Applications→ASimpleClient.

+   2. Right click the Applications node and select the Add option from the context menu to display the Configure an Application dialog box, as shown in Figure 33.8:

![](bbox=[0.235, 0.165, 0.735, 0.43])

Figure 33.8: Showing the Configure an Application Dialog Box

+   3. Click the Other button. This opens the Add an Application dialog box.

+   4. Browse for the ASimpleClient.exe file in the Add an Application dialog box and click the Open button. This adds the ASimpleClient node in the .NET Framework Configuration 2.0 tool, as shown in Figure 33.9:

![](bbox=[0.115, 0.535, 0.845, 0.875])

Figure 33.9: Showing the ASimpleclient.exe Node
