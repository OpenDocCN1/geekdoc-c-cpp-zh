## 深入探讨

语言集成查询（LINQ）作为 .NET Framework 3.5 的新组件引入。其基本功能是通过使用类似于结构化查询语言（SQL）的语法，为 .NET Framework 添加原生的数据查询功能。LINQ 允许您定义查询数据源以生成所请求结果集的语句。

LINQ 是一种编程模型，用于提供一种一致的方法来获取和操作数据。在 C# 中，您可以直接在查询表达式中使用 LINQ，这些查询表达式用于从 LINQ 启用数据源查询和转换数据。例如，查询表达式可以从 SQL Server 数据库查询和检索数据，然后将输出显示为 XML 数据。这些查询表达式基于众多查询运算符，这些运算符实际上是一组关于查询如何处理的指令。查询运算符的设计方式类似于 SQL。LINQ 定义了一组查询运算符，用于查询和过滤数据。LINQ 与 SQL 的区别在于，与 SQL 不同，LINQ 中的查询表达式可用于与众多类型的数据交互，甚至是不属于关系数据库的数据。

在 .NET Framework 4.0 中，引入了一种用于编写高效和多线程查询的新编程模型，称为并行 LINQ（PLINQ）。PLINQ 是 LINQ to Objects 的并行实现。这意味着 PLINQ 将 LINQ 的标准查询运算符实现为扩展方法，并包含用于实现并行操作的附加运算符。因此，PLINQ 在使用声明性语法时提供类似的功能。

本章向您介绍 LINQ 的概念。您还将学习基本的 LINQ 查询，以及用于从数据源查询数据的查询运算符。您将学习如何从各种数据源检索数据，例如 LINQ to Object、LINQ to ADO.NET 和 LINQ to XML。此外，您还将学习 LinqDataSource 控件的使用，它是 ASP.NET 中使用的独立数据源控件。您还将学习 LINQ 中使用的扩展方法、匿名方法和 lambda 表达式。此外，您还将学习本版 .NET Framework 中随 LINQ 引入的新概念 PLINQ。

### 介绍 LINQ 查询

查询是从数据源检索所请求数据的表达式。LINQ 查询指定您希望从数据源检索的信息。LINQ 查询还可以执行其他功能，例如对检索到的数据进行排序和分组。LINQ 查询以声明性查询语法编写。您可以使用 LINQ 查询的各种子句是 from、where、orderby 和 select 子句。它们是可用于执行 LINQ 查询的预定义子句。

LINQ 查询的基本语法是 LINQ 查询表达式必须以 from 子句开头，并以 select 或 group 子句结束。此外，您可以使用 where 和 orderby 子句执行其他功能，例如检索数据。

以下是 LINQ 查询执行的三个基本步骤：

- 1. 获取数据源，该数据源可以是 SQL 数据库或 XML 文件
- 2. 创建查询
- 3. 执行 LINQ 查询

在您使用 LINQ 查询之前，需要了解以下基本概念：

- LINQ 查询中的数据源
- 延迟查询执行和立即执行
- LINQ 和泛型类型

让我们逐一详细探讨这些概念。

### LINQ 查询中的数据源

LINQ 查询中的数据源可以是数据结构、Web 服务、文件系统或数据库。LINQ 查询执行很简单，因为查询的语法和模式不会随着数据源的变化而变化。您可以使用 LINQ 与不同数据源的不同方式如下：

- 实现 IEnumerable<T> 接口以启用 LINQ to Objects 查询。
- 创建标准查询运算符方法，例如 Where() 和 Select()，以启用自定义 LINQ 查询。
- 为您的数据源创建提供程序，该提供程序实现 IQueryable<T> 接口以启用 LINQ 查询。实现此接口的提供程序以表达式树的形式接收 LINQ 查询（表达式树代表以树结构表示的代码，其中树的每个节点都是一个表达式）。
- 创建一个提供程序，该提供程序不仅启用查询，还启用插入、更新和删除操作。

当您使用 LINQ 在 ASP.NET 应用程序中检索数据时，数据源，例如 XML 文件或 Access 数据库并不重要。LINQ 查询的执行与数据的类型和原始数据源的结构无关。

LINQ 将数据源预览为 IEnumerable<T> 或 IQueryable<T> 集合。例如，在 LINQ to SQL 中，源数据作为 IEnumerable<XElement> 集合元素可见。在 LINQ to DataSet 中，源数据作为 IEnumerable<DataRow> 集合可见。

### 延迟查询执行和立即执行

LINQ 查询仅存储查询命令。当您在运行时定义 LINQ 中的查询时，查询不会运行。查询实际上在您请求数据时运行。因此，LINQ 查询的实际执行会推迟到您提出数据请求时为止。这种推迟实际执行的概念称为延迟查询执行。您可以使用 ForEach 语句检索 LINQ 查询结果。例如，在持续更新的数据库中，您可以创建一个检索最新数据的 LINQ 查询，并且可以在不同间隔重复执行它以每次检索不同的结果。

如果查询对一系列项目执行聚合函数，则查询必须首先遍历该范围。这称为立即执行。这些函数必须首先遍历源元素，然后显示结果。执行此类强制执行的子句是 Count、Max、Min 和 Average。与延迟执行不同，立即执行查询不需要显式的 ForEach 语句来返回结果。

如果将延迟查询执行与立即查询执行进行比较，则延迟查询执行优于立即查询执行。这是因为在延迟查询执行中，查询不保存结果，您可以随意多次执行它。您还可以通过单独的应用程序定期更新数据源。您可以在延迟查询执行中检索最新数据。这种功能在立即查询执行中是不可能的。

### LINQ 和泛型类型

LINQ 查询基于泛型类型，而泛型类型是在 .NET Framework 2.0 中引入的。泛型类型用于最大化代码重用、类型安全和性能。泛型类型最常见的用途是创建集合类。LINQ 中使用的泛型类型的两个基本概念是：

- 创建泛型集合类的实例，例如 List<T>，然后在 LINQ 查询中用列表保存的对象类型替换 T。例如，字符串列表表示为 List<String>，客户对象列表表示为 List<Customer>。泛型列表相对于将元素存储为 Objects 的集合具有许多优势。例如，如果您尝试将 Customer 添加到 List<String>，您会得到编译时错误。在这种情况下，使用泛型集合很容易，因为您不需要执行运行时类型转换。
- 使用 IEnumerable<T> 接口，该接口使泛型集合类能够通过使用 ForEach 循环进行枚举。例如，类型为 IEnumerable<Customer> 的 LINQ 查询变量意味着当查询执行时，它会产生零个或多个 Customer 对象的序列。
