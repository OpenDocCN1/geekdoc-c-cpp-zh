# Creating a Sealed Class

You can use the sealed keyword to create a sealed class. A sealed class cannot be used as a base class. In other words, a sealed class cannot be inherited. Now, let’s create an application named MySealedClass (also available on the CD) that shows how a class can be declared as sealed. Listing 5.2 shows the code of the MySealedClass application.

# Listing 5.2: Showing the Code of the MySealedClass Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MySealedClass
{
    sealed class MyClass
    {
        string fName;
        string lName;
        int Age;
        public void GetDetail()
        {
            Console.Write("Enter Your first Name:");
            fName = Console.ReadLine();
            Console.Write("Enter Your last Name:");
            lName = Console.ReadLine();
            Console.Write("Enter Your Age:");
            Age = int.Parse(Console.ReadLine());
        }
        public void ShowDetail()
        {
            Console.WriteLine(fName + " " + lName + " you are " + Age + " Years Old");
        }
    }
    // Following lines shows compiler error as Sealed class cannot be inherited
    /* class Derived : MyClass
    {
    }*/
    class MainClass {
        static void Main(string[] args) {
            MyClass obj = new MyClass();
            obj.GetDetail();
            obj.ShowDetail();
            Console.Write("\nPress ENTER to quit...");
            Console.ReadLine();
        }
    }
}
```

In Listing 5.2, we have created a sealed class, named MyClass, by using the sealed keyword. This class contains two methods, GetDetail() and ShowDetail(), to take the input from a user and show the details.
