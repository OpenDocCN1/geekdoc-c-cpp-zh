# The PerspectiveCamera Class

The `PerspectiveCamera` class represents a perspective projection camera. It renders the scene so that the objects that are far away appear smaller. The `PerspectiveCamera` class is derived from the `ProjectionCamera` base class. It is the most versatile and the most commonly used camera in WPF. The `PerspectiveCamera` class specifies the projection of a 3-D model object to a 2-D visual surface. The object described using the `PerspectiveCamera` class has their sides converge toward a point on the horizon. The objects that are closer to a camera appear larger, and the objects farther from the camera appear smaller. You can limit the range of a camera by setting the `NearPlaneDistance` and `FarPlaneDistance` properties. The `NearPlaneDistance` property allows you to specify a minimum distance from the camera of the near clip plane. On the other hand, the `FarPlaneDistance` property allows you to specify a distance from the camera of the far clip plane, which ensures that 3-D objects too far away are not included in the scene. You can add a `PerspectiveCamera` object to your application by adding the following code:

```
```xml
<PerspectiveCamera .../>
```
```

# The OrthographicCamera Class

The `OrthographicCamera` class represents an orthographic projection camera and specifies an orthogonal projection of a 3-D model to a 2-D visual surface. It specifies a position, viewing direction, and upward direction. It also describes a viewing box whose sides are parallel, instead of one whose sides meet in a point at the horizon, for instance the `PerspectiveCamera` class. The `OrthographicCamera` class flattens the 3-D objects so that the exact scale is preserved, no matter where a shape is positioned. You can add an `OrthographicCamera` object to your application by adding the following code snippet:

```
```xml
<OrthographicCamera .../>
```
