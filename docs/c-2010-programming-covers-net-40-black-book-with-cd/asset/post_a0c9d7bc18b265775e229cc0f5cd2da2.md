## The PasswordRecovery Control

The PasswordRecovery control is used to recover or reset the forgotten password of a user. This control does not display the password on the browser, but sends the password as an e-mail message to the e-mail address specified at the time of registration. This control also uses the Membership service to create or reset the password. The PasswordRecovery control has the following three views:

- UserName — Refers to the view that accepts the username of a user
- Question — Refers to the view that accepts the answer of the security question asked from the user.
- Success — Refers to the view that displays a message to the user, specifying that the retrieved password has been sent to the user.

To retrieve or reset passwords, you must set some properties of the ASP.NET Membership service. The PasswordRecovery control uses the following configuration of the Membership service settings for retrieving passwords:

- requiresQuestionAndAnswer — Allows a user to answer the security question, which was specified at the time of creating the user account, when set to True
- passwordFormat — Displays the password in an encrypted format, when set to Hashed
- enablePasswordRetrieval — Allows the Membership service to retrieve the password, when set to True
- enablePasswordReset — Allows the users to reset their passwords, when set to True
