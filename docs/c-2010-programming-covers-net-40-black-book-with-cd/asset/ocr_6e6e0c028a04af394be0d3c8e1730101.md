# The Stack Class

The Stack class follows the Last In First Out (LIFO) order. The item that is added last to a Stack object is read first. A Stack object is a LIFO container. When you add an item to the Stack object, it is called pushing the item onto the Stack object and when you remove an item from the stack object, it is called popping the item from the stack object. These operations are called push and pop because push adds an item and pop removes the item.

+   System.Object

# Table 32.7: Noteworthy Properties of the Stack Class

| Property | Description |
|----------|-------------|
| Count | Retrieves the number of elements present in the Stack object |
| IsSynchronized | Retrieves a value specifying whether or not the access to the Stack object is synchronized |
| SyncRoot | Retrieves an object that can be used to synchronize access to the Stack object |

# Table 32.8: Noteworthy Methods of the Stack Class

| Method | Description |
|--------|-------------|
| Clear() | Removes all the items from the Stack object |
| Clone() | Creates a copy of the Stack object |
| Contains() | Returns true if an item is in the Stack object |
| CopyTo() | Copies the Stack object items into a one-dimensional array at the specified index |
| GetEnumerator() | Returns an IEnumerator object for the Stack object |
| Peek() | Returns the item at the top of the Stack object without removing it |
| Pop() | Removes and returns the item at the top of the Stack object |
