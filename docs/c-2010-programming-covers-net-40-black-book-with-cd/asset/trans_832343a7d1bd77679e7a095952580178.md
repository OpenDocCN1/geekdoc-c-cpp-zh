## 创建多播委托

C# 提供了多播委托，它允许你将给定事件源的多个委托处理程序合并到一个单独的链表中。反过来，该链表可以在程序控制下直接调用，或通过触发事件机制间接调用。

使用多播委托的优点在于，你可以修改那些委托的输入。例如，如果你想跟踪分配给委托的事件链，可以递增一个计数器，并将其作为输入参数传递给委托处理程序。或者，如果你了解某些处理程序的处理方式，也可以直接绕过它们。

多播委托系统的核心是 Combine() 方法。此方法允许你创建在事件触发时要调用的委托链式链表。让我们创建一个名为 MultipleDelegates 的控制台应用程序（也可在 CD 中获取），它解释了创建多播委托处理程序的概念。清单 6.11 展示了 MultipleDelegates 应用程序的 Program.cs 文件的代码：
