
# Hosting WCF Services in Windows Services

Hosting a WCF service in a Windows service requires registering the application domain (AppDomain) that hosts a WCF service as a managed Windows service on a server so that Service Control Manager (SCM) controls the process lifetime of the WCF service. Now, let’s perform the following steps to host a WCF service in a Windows service:

- 1. Create a console application named WinServiceHost (also available on the CD ROM).
- 2. Right-click the name of the WinServiceHost application and select Add→New Item from the context menu. The Add New Item dialog box appears.
- 3. Select the WCF Service template and enter the name of the service as TimeService in the Name text box of the Add New Item dialog box.
- 4. Click the Add button to create the application. The TimeService.cs, ITimeService.cs, and App.config files are added to the WinServiceHost application. In addition, references to the System.ServiceModel and System.Runtime.Serialization classes are also included in the application.
- 5. Open the ITimeService.cs file and add the following code snippet in the ITimeService interface:
  [OperationContract]
  string GetCurrentTime();
- 6. Open the TimeService.cs file and add the following code snippet in the TimeService class:
  public string GetCurrentTime()
  {
      string CurrentTime = DateTime.Now.Hour + ":" + DateTime.Now.Minute + ":" + DateTime.Now.Second;
      return CurrentTime;
  }
- 7. Open the Add New Item dialog box again and add the Windows Service template in the WinServiceHost application. In our case, the name of the Windows service is Service1.cs, as shown in Figure 19.24:

8. Open the code view of the Service1.cs file (that contains the functionality for the Windows service) and add the code, shown in Listing 19.8, to host the WCF service (TimeService) in the Windows service (Service1):

## Listing 19.8: Showing the Code for the Service1.cs File

```
using System;
using System.Collections.Generic;
using System.ComponentModel;
using System.Data;
using System.Diagnostics;
using System.Linq;
using System.ServiceProcess;
using System.Text;
using System.ServiceModel;

namespace WinServiceHost
{
    public partial class Service1 : ServiceBase
    {
        public ServiceHost myHost;

        public Service1()
        {
            InitializeComponent();
            myHost = new ServiceHost(typeof(TimeService));
        }

        protected override void OnStart(string[] args)
        {
            myHost.Open();
        }

        protected override void OnStop()
        {
            myHost.Close();
        }
    }
}
```

In Listing 19.8, the using directive for referencing the System.ServiceModel namespace is included in the Service1.cs file. This namespace contains the ServiceHost class, which is responsible for hosting the WCF service (TimeService) in the Windows service (Service1). While creating an object (myHost) of the ServiceHost class, the constructor of this class takes the type of the WCF service as its argument. The myHost object is opened by calling the Open() method in the OnStart() method. Similarly, the myHost object is closed by calling the Close() method in the OnStop() method of the Windows service. This implies that when the Windows service starts, the WCF service opens; and when the Windows service stops, the WCF service also stops.

# Hosting WCF Services in IIS

When a WCF service is hosted in IIS, it automatically incorporates into ASP.NET. This enables you to use the inherent features of ASP.NET, such as process recycling, idle-time management, health monitoring, and activation. Let’s perform the following steps to host a WCF service in IIS:

1. Create a WCF service application named SimpleInterestService (also available on the CD) by using the WCF Service Application project template. The IService1.cs and Service1.svc.cs files are automatically created while creating the application
2. Open the IService1.cs file and add the following code snippet in the IService1 interface to declare the service contract:

```
[OperationContract]
double CalSimpleInterest(double p, double r, double t);
```

3. Open the Service1.svc.cs file and add the following code snippet in the Service1 class to implement the service contract:

```
public double CalSimpleInterest(double p, double r, double t)
{
    double sInterest = (p * r * t) / 100;
    return sInterest;
}
```

4. Host this WCF service in IIS by selecting the Project→SimpleInterestService Properties option from the menu bar to display the property page for the SimpleInterestService project.
5. Select the Web tab in the property page to view the Web-related properties of the project, as shown in Figure 19.30:

![](img/e073a4882197be4ab61103cbe0bcb394_1025_0.png)

Figure 19.30: Specifying the Option to Host the WCF Service in IIS

6. Select the Use Local IIS Web server radio button in the Servers section to host the WCF service on IIS.
7. Click the Create Virtual Directory button (Figure 19.30) to create a virtual directory for the WCF service. A message box appears after successfully creating virtual directory, as shown in Figure 19.31:

![](img/e073a4882197be4ab61103cbe0bcb394_1025_1.png)

Figure 19.31: Showing a Message Box Notifying the Successful Creation of a Virtual Directory

8. Click the OK button of the message box and close the SimpleInterestService property page.
