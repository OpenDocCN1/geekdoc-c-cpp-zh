# Delayed Signing

As discussed in the In Depth section, Delayed Signing is used to make changes in the assembly at a later stage. Using the sn.exe utility, you can skip signing the assembly with the private key and turn off the assembly’s verification. You can provide the public key to other developers to make changes in an assembly. After the developer completes the entire task with the assembly, the assembly’s verification is turned on and it is signed with the private key before deployment and distribution.

Now, to understand this concept, create a new class library project named DistAssembly (also available on the CD-ROM), and perform the following steps:

+   1. Add the code, shown in Listing 33.14, on the Class1.cs file:

# Listing 33.14: Showing the Code for the Class1.cs File

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace DistAssembly
{
    public class Class1
    {
        void Greeting()
        {
            System.Windows.Forms.MessageBox.Show("Unsigned Distributable Assembly Says Hi!");
        }
    }
}
```

Since the code returns a message box, add the System.Windows.Forms reference to this application.

> NOTE
> You need to add the reference of the System.Windows.Forms in the application.

+   2. Open the .NET command prompt with the Start→All Programs→Microsoft Visual Studio 2010→Visual Studio Tools→Visual Studio Command Prompt (2010) and change the directory to the DistAssembly folder. You need to first create a new and unique public–private key pair file for your assembly.

+   3. Type the following command at the command prompt:

```
sn /k TheKey.snk
```

The preceding command creates a new key pair file called TheKey.snk. If you do not want to give the key pair file containing both private and public keys, you can extract the public key from your key pair file using the sn utility by using the following command:

```
sn /p TheKey.snk ThePublicKey.snk
```

The public key is extracted to the file called ThePublicKey.snk.

+   4. Add the following line to the AssemblyInfo.cs file of our DistAssembly project:

```
[assembly: AssemblyKeyFile("../../ThePublicKey.snk")]
```

> NOTE
> You need to add the ThePublicKey.snk file in the application.

+   5. Build the assembly using Build→Build DistAssembly. You get the following error during compilation:
+   Error 1 Cryptographic failure while signing assembly 'D:\Black Books\C# 2010\Chapter 33\Code\DistAssembly\DistAssembly\obj\Debug\DistAssembly.dll' -- 'key file '../../ThePublicKey.snk' is missing the private key needed for signing' DistAssembly

This error is caused because you have still not set up the assembly to skip the private key signing process.
