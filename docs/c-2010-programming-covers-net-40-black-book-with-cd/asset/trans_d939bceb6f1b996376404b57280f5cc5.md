## ListView 控件

ListView 控件是一个数据绑定控件，用于显示来自关联数据源的数据。ListView 控件使开发人员能够使用模板和样式以任何格式显示数据。此控件提供出色的自定义和扩展功能。它为开发人员提供对呈现的 HTML 输出的控制，并提供添加新行和排序的支持。当你将 ListView 控件拖到 ASP.NET 页面时，页面的源视图中会出现以下代码：

```
<asp:ListView ID="Listview1" runat="server"></asp:ListView>
```

ListView 控件的继承层次结构如下：

```
System.Object
  System.Web.UI.Control
    System.Web.UI.WebControls.WebControl
      System.Web.UI.WebControls.BaseDataBoundControl
        System.Web.UI.WebControls.DataBoundControl
          System.Web.UI.WebControls.ListView
```
