## The ToolTip Control

A ToolTip control in WPF is a small pop-up window, which appears when a user hovers or places the mouse pointer over an element. For example, in a normal window, when you hover over the Close button, a ToolTip appears for a specified period of time. If the user moves the mouse pointer away from the button, the ToolTip disappears as the ToolTip control stops receiving focus. The content of the ToolTip control can contain text, images, shapes, or other visual content. The ToolTip control cannot have a parent control. This implies that you cannot add a ToolTip control inside another control.

The inheritance hierarchy of the ToolTip control is as follows:

```
System.Object
    System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
        System.Windows.Media.Visual
            System.Windows.UIElement
                System.Windows.FrameworkElement
                    System.Windows.Controls.Control
                        System.Windows.Controls.ContentControl
                            System.Windows.Controls.ToolTip
```

You can add a ToolTip control to a WPF application by using the following code snippet:

```
<ToolTip>
    <!-- Content -->
</ToolTip>
```

Table 10.22 describes the noteworthy properties of the ToolTip class:

### Table 10.22: Showing the Noteworthy Properties of the ToolTip Class

| Property | Description |
|---|---|
| CustomPopupPlacementCallback | Gets or sets the delegate handler method used to position a ToolTip control |
| HasDropShadow | Gets or sets a value that indicates whether the control has a drop shadow |
| IsOpen | Gets or sets a value that indicates whether the control is visible |
| Placement | Gets or sets the orientation of the ToolTip control when it opens. It specifies how the control behaves when it overlaps with the screen boundaries |
| PlacementRectangle | Gets or sets the rectangular area relative to which the ToolTip control is positioned when it opens |
| PlacementTarget | Gets or sets a control relative to which the ToolTip control is positioned when it opens |
| StaysOpen | Gets or sets a value that indicates whether an open ToolTip control remains open until a user clicks the mouse |

The ToolTip control cannot be added from the Toolbox. The control can be added in the application through the XAML code.

## The ContentControl Control

The ContentControl control in a WPF application is used to display content and has some predefined styles. This means that you cannot change the appearance of the control to a large extent. You can enhance the appearance of the ContentControl control by creating a new DataTemplate class. The ContentControl control has a Content property of the type Object.

The inheritance hierarchy of the ContentControl class is as follows:

## The Window Control

The Window control helps to create, configure, show, and manage the lifetime of a Window or dialog box. The WPF Window control consists of two areas: the client area and the non-client area. The client area hosts application-specific content and the non-client area hosts common controls, such as the Minimize, Maximize, and Close buttons. The Window control is added to the WPF application by default. The Window control in WPF is a root element and cannot be a part of the content of another element.

The inheritance hierarchy of the Window class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.ContentControl
                System.Windows.Window
```

You can add the Window control to a WPF application by using the following code snippet:

```
<Window>
  <!-- Content -->
</Window>
```

## The Frame Control

The Frame control in WPF supports content navigation. The basic purpose of the Frame control is to support navigation and display content. The Frame control can be hosted within other content as well as controls. You can navigate to a Web page using the Navigate() method of the Frame control. If you are using the Frame control to navigate to a Web page, then the browser control is used to display the content of the Web page. The life cycle of the navigation can be tracked through the following events: Navigating, Navigated, NavigationProgress, NavigationFailed, NavigationStopped, LoadCompleted, and FragmentNavigation. The type of event that is raised depends on the type of navigation performed by the user.

The inheritance hierarchy of the Frame class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.ContentControl
                System.Windows.Controls.Frame
```

You can add a Frame control to a WPF application by using the following code snippet:

```
<Frame>
  <!--Content -->
</Frame>
```

Table 10.25 describes the noteworthy properties of the Frame class:

### Table 10.25: Showing the Noteworthy Properties of the Frame Class

| Property | Description |
|---|---|
| BackStack | Returns an IEnumerable property to enumerate the entries in back navigation history. Back navigation history implies that you can go back from the current page to a previously viewed page |
| CanGoBack | Retrieves a value that indicates whether or not you can go back to the previous page |
