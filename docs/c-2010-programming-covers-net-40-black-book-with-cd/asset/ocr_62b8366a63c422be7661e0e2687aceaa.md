# Using the HashSet<T> Class

As discussed, the HashSet<T> class represents a set of values, where a set is a collection that contains no duplicate elements, and its elements are not in a particular order.

Let's create an application named GenericHashSetSample, also available on the CD-ROM, to learn how to create the HashSet<T> object and add elements to it. This application contains a sample user interface form with three buttons—Create and add 10 items, Union, and Intersection, and three ListBox controls.

Perform the following steps to create the GenericHashSetSample application:

+   1. Set the Text property of Form1 to Generic HashSet Sample in the GenericHashSetSample application.
+   2. Drag and drop three ListBox controls, a GroupBox, and three Button controls to the form.
+   3. Set the Text property of the GroupBox control to Noteworthy Operations and the Text property of button1 to Create and add 10 items to each set, button2 to Union, and button3 to Intersection.
