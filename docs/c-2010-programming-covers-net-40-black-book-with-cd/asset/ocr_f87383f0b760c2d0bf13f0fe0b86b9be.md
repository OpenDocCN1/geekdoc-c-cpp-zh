# The Border Control

The Border control in WPF is responsible for drawing a border, background, or both around a control. The Border control can have only one child element, which implies that at a time the Border control can apply a border or background to only a single element. In other words, you cannot apply the Border control to multiple child elements. You can display multiple child elements with the Border control by adding the Panel element within the parent Border control.

The inheritance hierarchy of the Border class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Decorator
              System.Windows.Controls.Border
```

You can add the Border control to a WPF application by using the following code snippet:

```
<Border>
  <!--Child elements-->
</Border>
```

| BorderThickness | Gets or sets the relative thickness of a Border control |
