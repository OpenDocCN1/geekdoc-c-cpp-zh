Notice that the Web service class declaration consists of three attributes. The first is WebService (which sets an XML namespace for the Web service) and the second is WebServiceBinding (which indicates the level of the standards of conformity that the Web service can maintain). These two attributes are applied only when you are calling a Web service using SOAP, and are not relevant in the case of ASP.NET AJAX. However, the third attribute ScriptService is much more important. This attribute allows your Web service to be called from a client-side scripting language, such as JavaScript, by using the JSON format. In the absence of this attribute, you will not be able to use ASP.NET AJAX enabled Web service.

# NOTE

By default, the ScriptService attribute is commented and you need to uncomment this attribute to create an ASP.NET AJAX enabled Web service.
