# Transforming 3-D Models

You can apply transformation on the 3-D models in the same way as you have applied on the 2-D model. The different types of transformations that you can apply to the 3-D model are: translate, scale, and rotate. These transformations are implemented by using the TranslateTransform3D, ScaleTransform3D, and RotateTransform3D classes. Transformation allows you to resize and re-orient the 3-D models without changing the base class that defines them. The 3-D transformation that you apply in a WPF application inherits from the Transform3D base class.
