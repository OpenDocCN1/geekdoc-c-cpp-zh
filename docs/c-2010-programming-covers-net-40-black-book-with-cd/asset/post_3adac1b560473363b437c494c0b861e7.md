
## The WrapPanel Control

The WrapPanel container control positions its child elements in a sequential order. The ordering of the child elements depends on the value of the Orientation property. The default value of the WrapPanel.Orientation property is set to Horizontal, which implies that the child elements are arranged from left to right. However, you can change the default behavior and arrange the child elements from top to bottom.

The WrapPanel control is represented by the WrapPanel class, which is derived from the Panel class. The inheritance hierarchy of the WrapPanel class is as follows:

+   System.Object
+   System.Windows.Threading.DispatcherObject
+   System.Windows.DependencyObject
+   System.Windows.Media.Visual
+   System.Windows.UIElement
+   System.Windows.FrameworkElement
+   System.Windows.Controls.Panel
+   System.Windows.Controls.WrapPanel

You can add a WrapPanel control to a WPF application by using the following code snippet:

```
<WrapPanel>
<!--child elements-->
</WrapPanel>
```

## Simple Controls

Simple controls are those controls which do not contain any child elements within them. You can customize the look of simple controls by adding templates. Examples of simple controls are TextBox, RichTextBox, PasswordBox, ScrollBar, ProgressBar, and Slider. Let's look at these controls in detail.

## The TextBox Control

The TextBox control is used to display or edit the unformatted text that usually appears in a window. For example, you can perform a spell check on the text in the TextBox control by setting the SpellCheck.IsEnabled property to True. By default, this property is set to False. When it is set to True, a red line appears under any misspelled word. By default, the TextBox control has a context menu, which appears when a user right-clicks inside the TextBox control. The context menu allows the user to perform the Cut, Copy, and Paste operations. You can also create a custom context menu to change the default options. The TextBox control can contain a single line or multiple lines. You can enter multiple lines as text in the TextBox control by setting the TextWrapping attribute to Wrap. This causes the text to move to a new line on reaching the end of the frame of the TextBox control. You can also set the AcceptsReturn attribute to True. This allows you to insert a new line by pressing the ENTER key on the keyboard. To view a scroll bar in a TextBox control, you can set its VerticalScrollBarVisibility and HorizontalScrollBarVisibility attributes to Visible. This adds a scroll bar to a TextBox control, when the text in the TextBox control reaches the end of the frame.

The TextBox control is represented by the TextBox class, which is derived from the TextBoxBase class. The inheritance hierarchy of the TextBox class is as follows:

```

        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.Primitives.TextBoxBase
                System.Windows.Controls.TextBox
```

You can add a TextBox control to a WPF application by using the following code snippet:

```
<TextBox>
<!--Text-->
</TextBox>
```

## The RichTextBox Control

The RichTextBox control, similar to a TextBox control, enables you to display or edit content, such as paragraphs, images, and tables. A TextBox control requires fewer resources than a RichTextBox control and is ideal when only plain text needs to be edited; whereas, the RichTextBox control is ideal when the user needs to edit formatted text, images, or tables. The RichTextBox control can perform all the functions of a TextBox control, as well as some additional functions, such as displaying fonts, colors, and links; loading text and images; and finding a specified file. You can also check the spellings of your content by enabling the SpellCheck property of the RichTextBox control. When this property is set to True, a wavy red line appears under the misspelled words. The SpellCheck property is enabled by setting its SpellCheck.IsEnabled property to True. Similar to a TextBox control, the RichTextBox control also has a context menu. It appears when a user right-clicks inside the control. The RichTextBox control includes basic editing commands similar to those in the TextBox control. However, unlike the TextBox control, the RichTextBox control includes formatting commands. The RichTextBox control implements the IInputElement interface, which includes the support for many editing commands.

However, the PasswordBox control does not support the clipboard feature, so you cannot perform the copy function. The most important difference between a TextBox control and a PasswordBox control is that the PasswordBox control uses a System.Security.SecureString object, which ensures that the text entered as a password in the PasswordBox control is kept confidential. The text is encrypted for privacy when it is in use, and deleted from memory when no longer needed. The key used to encrypt the string is a randomly generated code and is never written to the disk.

The SecureString class includes an on-demand disposal of the encrypted text. When you call the SecureString.Dispose() method, the password stored in the memory is overwritten.

## The ScrollBar Control

The ScrollBar control provides a scroll bar that has a sliding Thumb control whose position corresponds to a value. The ScrollBar control contains a Track control, which in turn contains a Thumb control and two RepeatButton controls. You can increase or decrease the Value property of the ScrollBar control by clicking any of the RepeatButton controls or by moving the Thumb control. The Thumb control enables a user to select a value on the ScrollBar control. The default range of values of the Value property is from 0 to 1.
