# Figure 17.21: Displaying the Files of the Silverlight Application, SilverlightWithASP, in Solution Explorer

As shown in Figure 17.21, there are two projects created in the Silverlight application. One project, SilverlightWithASP, is for the Silverlight content itself and the other project, SilverlightWithASP.Web, is the ASP.NET Web application that hosts the Silverlight content. The Silverlight application, SilverlightWithASP, has the App.xaml and App.xaml.cs files for working with the settings of the Silverlight application as a whole and the MainPage.xaml and MainPage.xaml.cs files for working with the UI of the Silverlight application.

The ASP.NET website project has two test pages created for the entire Silverlight application, SilverlightWithASP. Both these test pages (one .aspx and the other .html) are used to host the Silverlight application. The test pages have the same name as the Silverlight application suffixed with the text TestPage (Figure 17.21). Note that both the .aspx and the .html test pages are created by default. The .html test page largely contains the same code as the TestPage.html file of the Silverlight applications that are hosted in a single HTML page, that is, the .html test page has the code to create and initialize the Silverlight content. The .aspx test page contains the equivalent ASP.NET code of the .html test page. This .aspx test page is the first page that appears when users run the application. The Web application also has the web.config file that is an XML file used for storing the configuration of the website.
