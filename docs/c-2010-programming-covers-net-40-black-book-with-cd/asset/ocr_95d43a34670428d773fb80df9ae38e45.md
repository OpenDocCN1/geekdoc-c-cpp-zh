# Standalone WPF Applications

Standalone WPF applications are similar to Windows Forms applications that is, you can install standalone applications on the clients’ computers and view them in the Start menu. In this section, we explore the project template provided by Visual Studio 2010 to create standalone WPF applications. In addition, we learn about the different files used to create WPF applications. Finally, we explore the Window class, which are used to create windows for WPF applications.

# Project Template for Standalone WPF Applications

Visual Studio 2010 provides a project template to create standalone WPF applications. Perform the following steps to open the project template:

+   1. Click the Start → All Programs → Microsoft Visual Studio 2010 → Microsoft Visual Studio 2010 option. Visual Studio 2010 IDE opens.
+   2. Click the New Project link on Start Page or select the File → New → Project option. The New Project dialog box appears (Figure 9.8).
+   3. Select the Visual C#→Windows option from the Installed Templates pane (Figure 9.8).
+   4. Select the WPF Application template to create standalone WPF applications. Specify the name and location for the standalone WPF application and then click the OK button, as shown in Figure 9.8:
