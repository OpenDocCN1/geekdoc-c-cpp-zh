# Using the foreach Loop

The foreach loop allows an easy access to all the elements of an array. To understand the use of the foreach loop, let’s create an application in which you first need to create an array named bookTitles. After creating the array, you can access each and every element of that array using a foreach loop. Let’s create a console application named MyForeachLoop (also available on the CD) to show the use of foreach loop. Listing 3.8 shows the code of the MyForeachLoop application:

Listing 3.8: Showing the Code of the MyForeachLoop Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace MyForeachLoop
{
    class Program
    {
        static void Main(string[] args)
        {
            string[] bookTitles = new string[] { "Alice in Wonderland",
                "Pelican Brief",
                "Ignited Minds" };

            Console.WriteLine("The available book titles are: ");
            foreach (string i in bookTitles)
            Console.WriteLine("\t" + i);
            Console.Write("\nPress ENTER to quit...");
            Console.ReadLine();
        }
    }
}
```
