# Exploring Stored Procedures

Stored procedure is a precompiled set of SQL commands that are stored on a database. It is compiled once and used repeatedly by client applications without sending it to the database server. An example of creating a stored procedure in SQL Server 2008 is given in Listing 23.1:

# Listing 23.1: Creating a Stored Procedure in SQL Server 2008

```
CREATE PROCEDURE GetProductDetails
@ProductID int
AS
SELECT ProductID,ProductName,QuantityPerUnit,UnitPrice,UnitsInStock FROM Products WHERE ProductID=@ProductID
```

In Listing 23.1, a stored procedure, GetProductDetails, is created with one parameter of Integer type. This stored procedure gives the details of an item that includes ProductID, ProductName, QuantityPerUnit, UnitPrice, and UnitsInStock from the Products table based on a particular ProductID. You can execute the GetProductDetails stored procedure by using the following command:

```
EXECUTE GetProductDetails 3
```

> NOTE
> You can execute the GetProductDetails stored procedure by providing any other Product ID besides 3, such as 2 and 4.
