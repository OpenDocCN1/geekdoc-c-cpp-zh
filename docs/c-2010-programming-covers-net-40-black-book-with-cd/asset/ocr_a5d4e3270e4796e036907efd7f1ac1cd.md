You should set the LoadedBehavior property of the MediaElement control to Manual in order to interactively stop, pause, and play the media.

# Modes of Media Playback

You can use the MediaPlayer and MediaElement classes in two different modes; the independent mode and the clock mode. The mode is determined by the Clock property. If the Clock property is set to null, the media object is in the independent mode. If the Clock property is set to non-null, the media object is in the clock mode.
