# NOTE

> If you overload the comparison operators, they must be overloaded in pairs, such as if == is overloaded then != must also be overloaded. The reverse is also true, and the same rule applies to < and >, and for <= and >=.

# Indexer Overloading

In C#, an indexer is used to treat an object as an array. It is used to provide index to an object to obtain values from the object. Implementing an indexer requires you to use brackets ([ ]) with an object to get and set a value of the object. Indexers are declared as properties, with the difference that in case of indexers, you do not need to provide name to them. You need to use the this keyword to define an indexer.

The following code snippet shows how to define an indexer:

```
public string this[int Position]
{
    get
    {
        return MyData[Position];
    }
    set
    {
        MyData[Position] = value;
    }
}
```

In the preceding code snippet, the get property is used to retrieve the index of the MyData member, while the set property is used to assign an index to the member. You can also see that there is no name assign to the indexer.

Similar to any other data members, indexers can also be overloaded. The following code snippet shows how to overload an indexer:

```
public string this[int position]
{
    get
    {
        return myVar[position];
    }
    set
    {
        myVar [position] = value;
    }
}
```
