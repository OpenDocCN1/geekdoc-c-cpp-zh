## Controlling Storyboard Using Code-Behind Code

When you are controlling the Storyboard timeline through code, you must create a NameScope class for a FrameworkElement class to register the names of the objects to animate with the FrameworkElement class. To start an animation in code, you should use the BeginStoryboard property with an EventTrigger object. You can also use an event handler and the Begin() method of the Storyboard class. You can create the same effect as XAML through the code-behind code as well. Let’s create an animation in which you can control the Storyboard timeline through code. To do this, create a WPF application named Storyboard_Code (also available in CD) and add the code, given in Listing 12.30, to the MainWindow.xaml file:

### Listing 12.30: Adding a Button Using the XAML Code

```
<Window x:Class="Storyboard_Code.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="300" Width="300">
    <Grid>
        <Button Width="100" Name="button1" Click="button1_Click"
            HorizontalAlignment="Left" Margin="0,27,0,0" Height="29"
            VerticalAlignment="Top">Click to grow</Button>
    </Grid>
</Window>
```

The code in Listing 12.30 is the XAML code, which is used to add a Button named button1 to the application. The button1 control is animated in the code-behind file. Add the code, given in Listing 12.31, to the MainWindow.xaml.cs file:

### Listing 12.31: Animating a Button Control

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Windows;
using System.Windows.Controls;
using System.Windows.Data;
using System.Windows.Documents;
using System.Windows.Input;
using System.Windows.Media;
using System.Windows.Media.Imaging;
using System.Windows.Navigation;
using System.Windows.Shapes;
using System.Windows.Media.Animation;

namespace Storyboard_Code
{
    /// <summary>
    /// Interaction logic for MainWindow.xaml
    /// </summary>
    public partial class MainWindow : Window
    {
        public MainWindow()
        {
            InitializeComponent();
            NameScope.SetNameScope(this, new NameScope());
            this.RegisterName(button1.Name, button1);
        }
        private void button1_Click(object sender, RoutedEventArgs e)
        {
            DoubleAnimation myAnimation = new DoubleAnimation();
            myAnimation.From = 100;
            myAnimation.To = 300;
            myAnimation.AutoReverse = true;
            myAnimation.RepeatBehavior = RepeatBehavior.Forever;
            myAnimation.Duration = new Duration(TimeSpan.FromSeconds(2));
            Storyboard myStoryboard = new Storyboard();
            myStoryboard.Children.Add(myAnimation);
            Storyboard.SetTargetName(myAnimation, button1.Name);
            Storyboard.SetTargetProperty(myAnimation, new PropertyPath(Button.WidthProperty));
            myStoryboard.Begin(this);
        }
    }
}
```

The preceding code adds a Storyboard object to a Button control. This Button control is animated to grow as you click on it. When you run the application by pressing the F5 key on the keyboard, a Button control is added to the window. As you click on the Button control, it starts increasing in size. ## Using DoubleAnimation to Transform Controls

The DoubleAnimation class animates the value of the Double property between two target values over a specified duration. The animation updates the value of property over a period of time. You can create simple animation, such as moving a shape, as well as advance animations, such as enlarging a shape using the DoubleAnimation class. You can set the Storyboard.TargetProperty of the DoubleAnimation class to transform controls. Let's create an application to transform controls. To do this, create a WPF application named DoubleAnimation (also available in CD) and add the code, given in Listing 12.32, to the MainWindow.xaml file:
