# Support for Networking

Silverlight 3.0 contains classes to support networking and predefined sockets. It allows you to use various Hypertext Transfer Protocol (HTTP), eXtensible Markup Language (XML), Really Simple Syndication (RSS), and Representational State Transfer (REST) services. Furthermore, you can use an XML format to use the data and resources on other Web sites. Silverlight extends the cross-domain support for networking. You can also use Silverlight 3.0 for communication with sockets over standard network protocols, such as IPv4 and IPv6.

# Support for Higher Quality Video and Audio

Among the host of new features in Silverlight 3.0, the media enhancements that have been introduced are worth mentioning. Silverlight 3.0 introduces support for new audio and video formats, such as H.264, Advanced Audio Coding (AAC), and Moving Picture Experts Group (MPEG) 4. This in other words means that the MediaElement control within Silverlight can now play back H.264 encoded content.

In addition, Silverlight 3.0 includes support for live and on-demand Internet Information Services (IIS) 7 Smooth Streaming, full HD (720p+) playback, and raw audio or video (AV) pipeline. Furthermore, the raw AV pipeline is expected to enable the .NET developers to provide audio/video decoding that can be hosted in Silverlight outside the .NET Framework runtime environment.

> NOTE
> The Silverlight's MediaElement control is a rectangular control that is used to either play audio or display some video on its surface. You learn more about MediaElement control later in this chapter.

# Empowering Richer Experience

The support for perspective 3-D transformations in Silverlight 3.0 will enable the .NET developers and designers to create next generation engaging Web visuals containing new 3D graphics, animation features, hardware accelerated effects, and text improvements. Perspective transforms can be understood as transforms that you can apply on XAML elements to simulate a 3-D environment. You can bring about 3-D effects to controls in your Silverlight applications without writing a lot of code by using the attached property, called Projection, within a parent element. For instance, consider the following code snippet:

```
<Button Height="90" Content="Perspective Transform">
<Button.Projection>
<PlaneProjection RotationY="60"/>
</Button.Projection>
</Button>
```

In the preceding code snippet, the Button control is rotated to give it a perspective, with a 60 degree rotation on the Y axis.

> NOTE
> An attached property can be thought of as a global property that is used to provide some additional information to a control. These properties support XAML syntax and can be used to enable the child elements to inform the parent elements that how they will be represented in the UI.

Furthermore, the .NET developers and designers can now enrich the media experience of the users by implementing other graphic capabilities, such as pixel shader effects and animation effects. The pixel shader effects can be used to incorporate the built-in blur and drop shadow effects or you can even write your own effects in controls, such as a button.

> NOTE
> A pixel shader is a type of program that is used to calculate the color of individual pictures on screen. The pixel shader mostly executes on a graphics processing unit (GPU) and is written in a shading language called HLSL, which has syntax similar to C.
