## BinaryReader 和 BinaryWriter 类

BinaryReader 和 BinaryWriter 类以二进制格式（以 0 和 1 的形式）读取和写入数据，而不是文本。你可以使用 BinaryWriter 类的 Write() 方法将二进制数据写入文件。要读取二进制数据，可以使用 BinaryReader 类的 Read() 方法。然而，还有其他方法可用于读取数据，例如 ReadInt32() 和 ReadDouble()。例如，要读取 Int32 值，可以使用 BinaryReader 类的 ReadInt32() 方法；要读取 double 值，可以使用 ReadDouble() 方法，对于 Boolean 值，可以使用 ReadBoolean() 方法。

表 29.10 列出了 BinaryReader 类的一些重要方法：

| 表 29.10：显示 BinaryReader 类的方法 |

| Finalize() | 允许对象执行清理操作 |
| GetType() | 检索当前实例的类型 |
| Read() | 从输入流读取下一个字符 |
| ToString() | 返回表示当前对象的 String |

## File 类

File 类提供了用于处理文件的静态方法。它还有助于创建 FileStream 对象并获取和设置文件属性。你可以使用此类设置创建、写入和访问文件的日期和时间。

File 类提供了各种方法，列在表 29.12 中：

表 29.12：显示 File 类的方法

| 方法 | 描述 |
|---|---|
| AppendAllText() | 将指定的字符串追加到文件，或在文件不存在时创建文件。 |
| AppendText() | 创建一个 StreamWriter 对象，将 UTF-8 编码的文本追加到任何现有文件。 |
| Copy() | 将现有文件复制到某个新文件。 |
| Create() | 在指定路径创建文件。 |
| CreateText() | 创建或打开文本文件以写入 UTF-8 编码的文本。 |
| Decrypt() | 解密由当前账户使用 Encrypt() 方法加密的文件。 |
| Delete() | 删除指定的文件。 |
| Encrypt() | 加密文件，使只有加密该文件的用户才能解密它。 |
| Exists() | 确定指定的文件是否存在。 |
| GetAccessControl() | 检索 FileSecurity 对象，该对象进而封装指定文件的 ACL。 |
| GetAttributes() | 从指定路径检索文件的属性。 |

| GetLastAccessTime() | 获取指定文件或目录的最后访问日期和时间。 |

| Open() | 在指定路径打开 FileStream 对象。 |

## FileInfo 类

FileInfo 类提供了创建、复制、删除、移动和打开文件的方法。它还有助于创建 FileStream 对象。FileInfo 类的一些方法在你创建或打开任何文件时返回输入/输出（I/O）类型，可用于操作文件。需要注意的是，你不能继承 FileInfo 类。

FileInfo 类提供了各种方法，描述在表 29.14 中：

| 表 29.14：显示 FileInfo 类的方法 |
|---|---| 
| 方法 | 描述 |
| AppendText() | 创建一个 StreamWriter 对象，将文本追加到由 FileInfo 对象表示的任何现有文件 |
| CopyTo() | 将现有文件复制到某个新文件 |
| Create() | 创建文件 |
| CreateText() | 创建一个 StreamWriter 对象以在新文件中写入文本 |
| Decrypt() | 解密由当前账户使用 Encrypt 方法加密的文件 |
| Delete() | 永久删除文件 |
| Encrypt() | 加密文件，使只有加密该文件的账户才能解密它 |
| GetAccessControl() | 获取 FileSecurity 对象，该对象进而使用当前 FileInfo 对象封装指定文件的 ACL |
