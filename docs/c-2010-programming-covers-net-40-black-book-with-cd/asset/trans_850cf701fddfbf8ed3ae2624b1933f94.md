

## C# 2010 编程黑皮书

### 涵盖 .NET 4.0

《C# 2010 编程黑皮书》是你能找到的最全面的 C# 书籍。它包含了关于 C# 2010 所有概念基础的有用且深入的信息；同时，通过提供最合适的示例并附带完整解释，教你如何以编程方式实现每种语言概念。本书的这一版特别涉及一些新颖且高级的主题，包括 WPF、WCF、WF、ASP.NET AJAX、Silverlight 和 LINQ。这本关于 C# 2010 的独特书籍提供了比任何其他书籍都更多的 C# 覆盖内容；毫无疑问，本书的每个方面都物有所值。

### 本书将帮助你：

- 使用指针、委托和事件
- 使用 DLR
- 开发 Windows 应用程序
- 使用 Windows 控件
- 开发 WPF 应用程序
- 开发 Web 应用程序
- 使用 ASP.NET 4.0 控件
- 开发 ASP.NET AJAX 应用程序
- 开发 Silverlight 3 应用程序
- 创建 ASP.NET 4.0 Web 服务
- 创建 WCF 服务
- 部署 Windows 和 Web 应用程序
- 使用 ADO.NET 对象访问数据
- 使用 LINQ 和 PLINQ
- 开发工作流应用程序
- 使用 .NET 程序集
- 使用 MEF 和 Syndication Framework
