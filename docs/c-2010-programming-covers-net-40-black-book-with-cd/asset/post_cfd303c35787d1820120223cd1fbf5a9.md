## Improved Box Selection

The box selection feature allows you to select the text in a rectangular shape by using the ALT key. Visual Studio 2010 IDE provides the box selection feature with following enhanced capabilities:

- Text insertion – Inserts the new text in all selected lines
- Paste – Allows you to paste the contents of one box selection into another
- Zero-length boxes – Inserts a vertical selection of zero characters length to create a multi-line insertion point for new or copied text

## Support for Call Hierarchy

In Visual Studio 2010, the call hierarchy feature allows you to navigate the members from one level to another. These members are navigated through the Call Hierarchy window in the following ways:

- Call from — Navigates a member to the members that call it
- Call to — Navigates a member to the members that are called by it

The Call Hierarchy window is available in Visual C# and Visual C++ and displays the calls made to or from a method, property, or constructor. In addition to these calls, the call hierarchy also displays the implementations of an interface member and the members overriding the virtual and abstract members. You can open the Call Hierarchy window by right-clicking on a method, property, or constructor, and selecting the View Call Hierarchy option from the context menu

The Call Hierarchy window is shown in Figure 1.15:

![](img/e073a4882197be4ab61103cbe0bcb394_63_0.png)

Figure 1.15: Showing the Call Hierarchy of Delete Method

In Figure 1.15, the Call Hierarchy window shows the list of calls made to the Delete method as well as the calls made from the Delete method.

## IntelliSense Modes

In Visual Studio 2010, the IntelliSense feature of the Code Editor window provides the following two modes for the completion of statements:

- **Suggestion mode** – Suggests the classes and the members even before they are defined in the program. When you type the code in the Code Editor window using the suggestion mode of IntelliSense and commit the entry, the text you type is inserted into the program.

Figure 1.20 shows the suggestion mode of IntelliSense:

![](img/e073a4882197be4ab61103cbe0bcb394_65_1.png)

**Figure 1.20: Using the Suggestion Mode of IntelliSense**

- **Completion mode** – Provides a members list of classes and members with a highlighted entry. When you type the code in the Code Editor window using the completion mode of IntelliSense and commit the entry, the highlighted entry in the members list is inserted into the code.

Figure 1.21 shows the completion mode of IntelliSense:

![](img/e073a4882197be4ab61103cbe0bcb394_66_0.png)

**Figure 1.21: Using the Completion Mode of IntelliSense**

You can toggle between the suggestion mode and the completion mode by pressing the CTRL+ALT+SPACEBAR keys combination.

It means that if multiple monitors are connected to a single computer, then the IDE window can be moved from one monitor screen to another.
