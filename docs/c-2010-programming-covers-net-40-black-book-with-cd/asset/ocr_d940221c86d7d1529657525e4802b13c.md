# In Depth

Navigation controls allow users to navigate through the Web pages. For example, if your Web site is composed of multiple pages, you need navigation controls that help in making the navigation of pages easier. Navigation controls, such as the TreeView control, Menu control, and SiteMapPath control, make it simple to add page hierarchies, quick links, and provide advanced navigational capabilities to your application. The Navigation controls display data in a consistent manner, thereby enabling the users to comprehend the application structure. These Navigation controls are the most recently introduced controls, and provide several features, such as consistent and easily managed navigation, to developers as well as users.

In this chapter, we explored three Navigation controls - TreeView control, Menu control, and SiteMapPath control, and also discusses about the base class of each of these Navigation controls. This chapter also discusses about the various properties, methods, and events of the Navigation controls, and shows you the practical implementation of using these Navigation controls.

# Using the TreeView Class

The TreeView class enables you to manage the TreeView control. The TreeView class can be used to create a tree-based hierarchical structure in the Web page at runtime.

The class hierarchy of the TreeView class is as follows:

```
System.Object
  System.Web.UI.Control
    System.Web.UI.WebControls.WebControl
      System.Web.UI.WebControls.BaseDataBoundControl
        System.Web.UI.WebControls.HierarchicalDataBoundControl
          System.Web.UI.WebControls.TreeView
```

The TreeView class contains a Node property that can be used to create the nodes of the TreeView control. The Nodes collection contains the Add method that can be used to add a text item or a TreeNode object in the TreeView class. It can further have child nodes and consists of properties, such as ExpandAll and CollapseAll, which expand and collapse the tree view nodes. You can also insert check boxes against the nodes and obtain the selected information dynamically by using the TreeView class.

Table 15.1 lists the noteworthy properties of the TreeView class:

| Property | Description |
|---|---|
| Table 15.1: Noteworthy Properties of the TreeView Class | |
| AutoGenerateDataBindings | Obtains or sets a value that indicates whether the TreeView control automatically generates tree node bindings |
| CheckedNodes | Obtains a collection of TreeNode objects, which represent the nodes in the TreeView control that displays a selected check box |
| CollapseImageToolTip | Obtains or sets the ToolTip for the image that is displayed for the collapsible node indicator |
| CollapseImageUrl | Obtains or sets the Uniform Resource Locator (URL) to a custom image for the collapsible node indicator |
| DataBindings | Obtains a collection of TreeNodeBinding objects that define the relationship between a data item and the node to which the object is binding |
| EnableClientScript | Obtains or sets a value that indicates whether the TreeView control renders client-side script to handle expanding and collapsing events |
| ExpandDepth | Obtains or sets the number of levels that are expanded when a TreeView control is displayed for the first time |
| ExpandImageToolTip | Obtains or sets the ToolTip for the image that is displayed for the expandable node indicator |
