## 命令窗口

命令窗口帮助您执行各种操作，例如向项目添加、删除或修改新项。您可以通过选择“视图 → 其他窗口 → 命令窗口”或同时按下 CTRL+ALT+A 键来查看命令窗口。此窗口允许您直接在 Visual Studio 2010 IDE 中执行命令。命令窗口中的大于号 (>) 表示新行的提示。您可以使用向上箭头或 CTRL+向上箭头键向上滚动窗口，并使用向下箭头或 CTRL+向下箭头键向下滚动窗口。

```
>Debug.Print varMessage
```

(Or)

```
?> var
```

上述两个命令都显示变量 var 的值。问号 (?) 是 Debug.Print 命令的别名，用于计算任何表达式。因此，这两个命令返回相同的结果。现在，在命令窗口中输入以下命令，不带大于号 (>):

```
>immed
```

上述命令打开“立即”窗口，如图 1.72 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_99_0.png)

为了切换回命令窗口，在“立即”窗口中输入以下命令：

```
>cmd
```

## 基本 IDE 操作

Microsoft 在 Visual Studio 2010 的 IDE 中引入了各种开发工具。在本节中，您将学习可在 Visual Studio 2010 的 IDE 中执行以下基本操作：

- 创建新的 Windows 应用程序
- 将代码保存到工具箱
- 停靠窗口
- 在窗口之间切换
- 为项目指定 .NET Framework 版本
- 更改 IDE 字体和颜色
- 构建和调试项目

现在让我们详细讨论这些操作。

- 1. 单击“开始 → 所有程序 → Microsoft Visual Studio 2010 → Microsoft Visual Studio 2010”。Visual Studio 2010 IDE 打开。

## 在窗口之间切换

快捷键是执行特定任务或在按下时触发特定事件的特殊键（或键组合）。在 IDE 中，此类组合主要用于在窗口之间切换。以下是用于在 Windows 窗体设计器和代码编辑器之间切换的一些主要快捷键列表：

- 使用 F7 键在窗口之间切换
- 在打开两个窗口的情况下使用 TAB 键
- 双击 Windows 窗体设计器以从设计视图切换到代码视图
- 右键单击代码视图并选择“查看设计器”选项以从代码视图切换到设计视图
- 右键单击设计视图并选择“查看代码”选项以从设计视图切换到代码视图
- 选择“视图 → 代码”以从设计视图切换到代码视图
- 选择“视图 → 设计器”以从代码视图切换到设计视图

## 为项目指定 .NET Framework 版本

在 Visual Studio 2008 发布之前，每个 Visual Studio 版本仅支持特定版本的 .NET Framework。例如，Visual Studio 2003 支持 .NET Framework 1.1，Visual Studio 2005 支持 .NET Framework 2.0。然而，Visual Studio 2008 和 2010 设计为支持多目标功能，即 Visual Studio 2008 支持 .NET Framework 2.0、3.0 和 3.5；而 Visual Studio 2010 支持 .NET Framework 2.0、3.0、3.5 和 4。现在，当您使用 Visual Studio 2010 打开现有项目或创建新项目时，您可以选择可用的 .NET Framework 版本之一。IDE 会自动更新编译器和功能以匹配所选的 .NET Framework。请注意，当您打开在较早版本的 .NET Framework 中创建的项目时，Visual Studio 2010 会显示 Visual Studio 转换向导，该向导将使用较低版本的 Visual Studio 创建的项目升级到 Visual Studio 2010。
