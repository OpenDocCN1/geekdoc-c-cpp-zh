# Handling Events in Styles Using the EventSetter Class

In WPF, you can handle events to apply the styles on the controls using the EventSetter class. The EventSetter class constructor invokes the specific event handler in response to routed events, which is applied to all elements that reference the Style class. An EventSetter class invokes the specified event handler in response to an event. Let’s handle events using the EventSetter class. Create a WPF application named UsingEventSetter (available in the CD) and add the code, shown in Listing 10.28, to the MainWindow.xaml file:
