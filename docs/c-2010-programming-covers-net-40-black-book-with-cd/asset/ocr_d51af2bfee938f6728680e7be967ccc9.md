# Creating Connection Strings

Similar to previous versions, the .NET Framework 4.0 provides capabilities for working with connection strings. A connection string contains the initialization information that is passed as a parameter from the data provider to the data source. The connection string is different for each of the data provider available in .NET. The connection string is parsed during an attempt to open the connection. The DbConnectionStringBuilder is the base class for creating connection strings. It can be used to create, edit, read, and save a connection string to the configuration file. There are different connection strings for the different types of data sources. You can find a list of all the available providers for creating connection strings in Table 24.1:

| Table 24.1: Data Providers in .NET |
| Provider | Description |
| SQL Server Data Provider (System.Data.SqlClient) | Provides data access for Microsoft SQL Server version 7.0 or later |
| OLE DB Data Provider (System.Data.OleDb) | Provides data access for data sources using OLE DB |
| ODBC Data Provider (System.Data.Odbc) | Provides data access for data sources using ODBC |
| Oracle Data Provider (System.Data.OracleClient) | Provides data access for Oracle version 8.1.7 or later |
| EntityClient Provider (System.Data.EntityClient) | Provides data access for Entity Data Model (EDM) applications |

You can create a connection string for any data provider in Visual Studio 2010. Let’s create a connection string for Microsoft SQL Server by performing the following steps:
