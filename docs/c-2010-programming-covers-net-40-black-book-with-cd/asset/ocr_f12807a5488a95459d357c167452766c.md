# Using Inline Elements

Inline elements provide a base for all Inline flow content elements. Some Inline elements provided in WPF are LineBreak, Run, Span, Figure, Floater, and InlineUIContainer. Let’s create a WPF application named InlineElements (also available on the CD-ROM) to learn how to use Inline elements. Add the code given in Listing 11.15 to the MainWindow.xaml file of the InlineElements application:

# Listing 11.15: Showing the code for Using Inline Elements

```
```xml
<Window x:Class="InlineElements.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="MainWindow" Height="440" Width="350">
    <FlowDocumentReader Height="400">
        <FlowDocument FontSize="12" FontFamily="a">
            <Paragraph>
                <Bold>This is a bold Text.
                </Bold>
                <LineBreak/>
            </Paragraph>
            <Paragraph>
                <Italic>This is an Italic Text.
                </Italic>
            </Paragraph>
            <Paragraph>
                <Underline>This Text is underlined.
                </Underline>
            </Paragraph>
            <Paragraph>
                <Hyperlink>This is a Hyperlink.
                </Hyperlink>
            </Paragraph>
            <Paragraph>Example of Subscript: H
                <Run Typography.Variants="Subscript">20
                </Run>
            </Paragraph>
