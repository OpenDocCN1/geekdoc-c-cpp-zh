## Using the AutoCompleteBox Control

As you know that the AutoCompleteBox control is a new control in Silverlight 3.0 and is a combination of a text box and a drop-down list control. The AutoCompleteBox control was earlier included in the Silverlight Toolkit and displays a drop-down list that contains a list of all the possible values that match with the text that you enter in a text box. You can simply drag and drop an AutoCompleteBox control from Toolbox into your application to use the AutoCompleteBox control. In addition, you can change the default appearance of an AutoCompleteBox as well. Perform the following steps to use the AutoCompleteBox control in a Silverlight application:
