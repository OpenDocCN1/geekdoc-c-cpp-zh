# Uninstalling the Windows Service using Installutil.exe and Windows Installer

You may want to uninstall a Windows service if it is not running or does not perform the required operations. You can uninstall a service by using the following command at the Command Prompt of Visual Studio 2010:

```
installutil.exe MyWindowsService.exe /u
```

In the preceding command, the installutil.exe utility is used with the /u switch to uninstall the service named MyWindowsService.exe. The output of the preceding command is shown in Figure 20.26:

![](bbox=[0.18, 0.21, 0.83, 0.46])

Figure 20.26: Uninstalling the MyWindowsService.exe Service

Alternatively, you can uninstall the Windows service by using the Windows installer. To do so, right-click the setup project (ServiceDeployment) and select the Uninstall option from the context menu, as shown in Figure 20.27:

![](bbox=[0.22, 0.53, 0.79, 0.71])

Figure 20.27: Uninstalling the Windows Service Using the Windows Installer

The Windows Installer dialog box appears to confirm the uninstalling of the selected product. Click the Yes button to uninstall the service, as shown in Figure 20.28:

![](bbox=[0.33, 0.77, 0.67, 0.87])

Figure 20.28: Displaying the Windows Installer Dialog Box
