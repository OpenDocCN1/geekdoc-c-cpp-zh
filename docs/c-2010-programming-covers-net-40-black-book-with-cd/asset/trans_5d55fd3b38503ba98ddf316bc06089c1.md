# 输出窗口

输出窗口显示构建和执行应用程序的结果。要查看输出窗口，请选择“视图→输出”。打开输出窗口的另一种方法是同时按下 CTRL+ALT+O 键。

图 1.59 显示了输出窗口：

![](img/e073a4882197be4ab61103cbe0bcb394_89_0.png)

图 1.59：显示输出窗口

输出窗口显示以下功能输出：

- **构建** – 显示编译器和链接器的进度和错误消息
- **调试** – 显示调试器的输出

您可以在输出窗口工具栏上看到各种可用按钮。这些按钮的说明如下：

- **显示输出来自** – 显示输出窗格列表以查看程序的输出。输出窗格的一些示例有 构建、调试 和 约束验证。
- **在代码中查找消息** – 将插入点移动到代码编辑器窗口中包含所选构建错误的行的位置。
- **转到上一个消息** – 将插入点在代码编辑器窗口中移动到包含上一个构建错误的行的位置。
- **转到下一个消息** – 将插入点在代码编辑器窗口中移动到包含下一个构建错误的行的位置。
- **全部清除** – 从输出窗格中删除所有文本。
- **切换自动换行** – 在输出窗格中打开和关闭自动换行功能。打开时，超出查看区域的文本将在其后的行中显示。

# 设计器

设计器是 Visual Studio 中的区域，在此区域中设计 Windows 应用程序、Web 应用程序或 Windows 演示应用程序。设计器可用于在设计视图中定义组件和控件的行为或外观。Visual Studio 中的一些设计器如下：

- Windows 窗体设计器
- WPF 设计器
- Web 窗体设计器

让我们详细探讨每一个。
