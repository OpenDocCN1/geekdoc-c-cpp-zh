# Table 31.1: Noteworthy Public Methods of the Thread Class

| Name | Description |
|------|-------------|
| GetDomain() | Returns the current domain in which the current thread is running. |
| GetDomainID() | Returns a unique application domain identifier. |
| GetHashCode() | Returns a hash code for the current thread. |
| GetNamedDataSlot() | Looks up a named data slot. This method uses the fields that are marked with the ThreadStaticAttribute attribute. |
| Interrupt() | Interrupts a thread that is in the WaitSleepJoin thread state. |
| Join() | Blocks the calling thread until an executing thread terminates. |
| ResetAbort() | Resets the abort operation that is requested for the current thread. |
| Resume() | Resumes a suspended thread. |
| SetData() | Sets the data for the currently running thread. This method uses the fields marked with the ThreadStaticAttribute attribute. |
| SetProcessorAffinity() | Sets the processor affinity for a managed thread. The processor affinity determines the processors on which a thread runs. |
| Sleep() | Blocks the current thread for the specified number of milliseconds. It is an overloaded method. |
| SpinWait() | Causes a thread to wait the number of times defined by the iterations parameter. |
| Start() | Causes a thread to be scheduled for execution. It is an overloaded method. |
| VolatileRead() | Reads the value of a field. This value is visible to all the running processes. |
| VolatileWrite() | Writes a value to a field. This value becomes visible to all the running processes as soon as it is written. |

Table 31.2 lists the public properties of the Thread class:

# Table 31.2: Public Properties of the Thread Class

| Name | Description |
|------|-------------|
| CurrentContext | Obtains the current context in which a thread is executing |
| CurrentCulture | Obtains or sets the culture for a thread |
| CurrentPrincipal | Obtains or sets the principal for a current thread |
| CurrentThread | Obtains a current running thread |
| CurrentUICulture | Obtains or sets a user interactive culture to a thread |
| ExecutionContext | Obtains an object of the ExecutionContext class that contains information of the current thread |
| IsAlive | Obtains a value that indicates the execution status of the current thread |
| IsBackground | Obtains or sets a value indicating whether or not a thread is a background thread |
| IsThreadPoolThread | Obtains a value indicating whether or not a thread belongs to a thread pool |
| ManagedThreadId | Obtains a unique identifier for the current thread |
| Name | Obtains or sets the name of the thread |
| Priority | Obtains or sets a value indicating the scheduling priority of a thread |
| ThreadState | Obtains a value that indicates the states of the current thread |
