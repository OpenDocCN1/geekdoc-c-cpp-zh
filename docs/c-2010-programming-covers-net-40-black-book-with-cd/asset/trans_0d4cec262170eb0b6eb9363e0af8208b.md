Membership 类允许你为 ASP.NET 应用程序创建用户并管理这些用户。使用 Membership 类为 ASP.NET 应用程序创建的用户可以作为经过身份验证的用户访问该 ASP.NET 应用程序。Membership 类的层次结构如下：

## 即时解决方案

### 确定代码是否可验证为类型安全

正如你在本章的“深入探讨”部分所学到的，可能有一些代码无法通过验证过程。这可能是由于验证算法或所使用的语言编译器的限制。例如，.NET Framework 提供的 Visual C++ 编译器无法生成可验证为类型安全的代码。另一方面，C# 编译器能够生成可验证为类型安全的代码。让我们看看使用 Visual C++ 和 C# 开发的应用程序如何通过 PEVerify 工具进行验证。为此，让我们用 C# 创建一个名为 CSharpTestApp 的控制台应用程序，并将其存储在名为 PEVerifyApps（在 CD-ROM 上）的文件夹中。要创建 CSharpTestApp 应用程序，请执行以下步骤：

- 1. 通过选择“开始”→“所有程序”→Microsoft Visual Studio 2010→Microsoft Visual Studio 2010 打开 Visual Studio 2010 IDE。

- 2. 选择“文件”→“新建”→“项目”，这将显示“新建项目”对话框。在“新建项目”对话框中，在“项目类型”窗格中选择 Visual C# 选项，在“模板”窗格中选择“控制台应用程序”选项。此外，将应用程序名称指定为 CSharpTestApp，将位置指定为 PEVerifyApps 文件夹，然后单击“确定”按钮。随即创建 CSharpTestApp 应用程序。

- 3. 打开 CSharpTestApp 中的 Program.cs 文件，并添加一个名为 SimpleClass 的自定义类的代码。CSharpTestApp 应用程序中 SimpleClass 类的代码见清单 36.1：

### 清单 36.1：在 CSharpTestApp 应用程序中定义 SimpleClass 类

```

using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace CSharpTestApp

    class Program
    {
```

- 4. 编译该应用程序。

- 5. 使用 VC++ 创建一个名为 VCTestApp 的 CLR 控制台应用程序。

- 6. 在“解决方案资源管理器”中，展开“源文件”，然后双击 VCTestApp.cpp 文件将其打开。在 VCTestApp.cpp 文件中，定义一个名为 SimpleClass 的类，如清单 36.2 所示：

- 8. 通过选择“开始”→“所有程序”→Microsoft Visual Studio 2010→Visual Studio Tools→Visual Studio 2010 命令提示符打开 Visual Studio 2010 命令提示符。现在，在命令提示符中转到 CSharpTestApp.exe 的位置（在本例中为 PEVerifyApps\CSharpTestApp\CSharpTestApp\bin\Debug），然后键入以下命令：
