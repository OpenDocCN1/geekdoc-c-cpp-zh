## 深入探讨

考虑这样一种情况：一些工程师被给予专用工具，被告知要制造一辆豪华轿车。然而，由于没有适当的模型或设计，他们无法做到。类似于任何其他行业，在软件开发中也需要模型和适当的设计来开发应用程序。在开发软件应用程序时，主要遵循两种编程模型：过程式编程（POP）和面向对象编程（OOP）。

POP 基于将问题分解为模块、分别解决每个模块，然后将所有已解决的模块组合起来解决整个问题的概念。模块可以是包含代码块的方法。在 POP 模型中，您可以从另一个方法调用一个方法。这意味着这些方法相互依赖；从而使代码的重用变得困难。使用 POP 模型的语言有 COBOL、FORTRAN 和 C。

OOP 模型的引入是为了克服代码重用有限或无重用的困难。OOP 使用类和对象的概念来重用现有代码。类充当创建实例或对象的蓝图或模板。该蓝图或模板描述了类的所有对象的状态和行为。对象的行为和属性分别由方法和变量表示。在 OOP 中，您还可以创建接口，提供对象与外部世界交互的方式。接口是一组方法集合，其主体为空。在这两种（POP 和 OOP）模型中，OOP 被认为是最好的遵循方法，因为它遵循与现实世界对象相关的方法。

在本章中，您将学习 OOP 的基本基础，包括封装、继承、多态性和抽象。您还将学习接口、密封类、密封方法和扩展方法。在本章的立即解决方案部分，您将学习如何在 C# 程序中实现这些概念。

## 封装

封装是隐藏无关信息并仅向用户显示特定对象的相关信息的过程。让我们通过一个例子来理解封装的概念。当顾客去购买冰箱时，顾客会寻找冰箱的颜色、其功能和存储容量等因素；而其内部工作原理和布线系统则对顾客隐藏。公司不希望顾客篡改布线系统；因此，它将内部布线系统的细节隐藏在顾客之外。这种隐藏内部事实的过程称为封装。

就 OOP 而言，封装是将数据和类的成员打包的过程。它是隐藏类或对象的内部状态和行为以防止未经授权访问的方法。封装限制用户共享和操作数据；从而最大限度地减少数据损坏的机会。封装的优点如下：

- 提供一种保护我们数据免受未经授权访问的方式。为此，我们可以将数据定义为 public，我们可以将这些字段（例如数据成员、成员函数、属性或索引器）声明为 private。私有数据可以通过两种方式间接操作，首先是通过访问器和修改器方法，其次是通过命名属性。
- 通过仅向用户显示相关信息来提高代码的可维护性。
- 通过通过特定方法或属性访问类的私有成员变量来防止数据损坏。
- 将类的成员变量和函数绑定到单个单元：这也称为在类中封装数据成员和成员函数。

在 C# 2010 中，封装是通过在类中使用 private 访问说明符实现的。
