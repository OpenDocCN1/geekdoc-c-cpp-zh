The first control in the tab order has a TabIndex of 0, the next a TabIndex of 1, and so on. When you run the application, the first control is highlighted; when you press the TAB key, the focus moves to the second control in the tab order and when you press Tab again, the focus moves to the third control, and so on.

# NOTE

You can also set the TabIndex property of controls by adding the following code snippet in the Load event of Form1:

```
private void Form1_Load(object sender, EventArgs e)
{
    button1.TabIndex =1;
    button2.TabIndex =4;
    button3.TabIndex =2;
    button4.TabIndex =0;
    button5.TabIndex =3;
}
```
