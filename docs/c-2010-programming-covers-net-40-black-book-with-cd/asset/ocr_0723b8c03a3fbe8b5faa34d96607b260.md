Event handling is one of the most powerful built-in technologies in the .NET environment. Besides garbage collection, it is probably the single biggest reason that programmers use C# language. Therefore, you must consider event handling at the time you design your classes so that you do not need to go back and add the event handlers for the events.

# Firing an Event

Sometimes, it might be more convenient to fire an event manually. Suppose you need to handle a button’s click event when a user clicks the specific button. In this case, rather than handling the click event after a button has been clicked, you can also simulate the button’s click event by invoking a method manually. In other words, the click event would be handled even without the button being actually clicked.
