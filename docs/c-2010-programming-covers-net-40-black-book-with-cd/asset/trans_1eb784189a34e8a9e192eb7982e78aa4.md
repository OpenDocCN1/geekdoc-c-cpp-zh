## 3-D 模型

WPF 中的所有 3-D 建模程序都包含基本基元，例如三角形、点和线。基本的 3-D 基元是由形成单个 3-D 实体的顶点集合组成的。例如，由三个顶点定义的三角形。三角形中的三个点是共面的。你可以通过使用网格来构建更复杂的形状，网格是由组织成三角形形状的 3D 点或顶点集合组成的。当你在 WPF 中构建模型时，你首先通过构建基元或网格开始。构建复杂形状后，你可以使用这些基元或网格来创建所需的场景。你可以以 WPF 中的球体为例，它是由较小的三角形构建而成的。你也可以以简单的封闭图形三角形为例，它由三个顶点定义。ModelVisual3D 类表示包含 3-D 模型的视觉对象。它提供所有视觉对象共有的服务和属性。视觉对象的整个场景在单个 ModelVisual3D 类中定义，并包含 Model3DGroup 类。Model3DGroup 类允许开发人员对 3-D 模型进行变换或动画，就好像它们是单个模型一样。

Model3D 是表示通用 3-D 对象的抽象基类，并为 3-D 模型提供功能。要构建典型的 3-D 场景，你需要一些用于查看的对象和一些构成场景图的从 Model3D 类派生的对象。从 Model3D 类派生并有助于构建 3-D 场景的类是 GeometryModel3D 类和 MeshGeometry3D 类。

MeshGeometry3D 类提供三角形基元用于构建 3-D 形状或任何几何体。它允许开发人员通过指定 Positions 属性来指定位置和纹理坐标信息。配置 MeshGeometry3D 类后，你需要将其包装在 GeometryModel3D 类中。

WPF 中的建模几何体由 GeometryModel3D 类支持。GeometryModel3D 对象负责定义对象及其材质。GeometryModel3D 类只有三个重要属性，Geometry、Material 和 BackMaterial。Geometry 属性接受定义对象形状的 MeshGeometry3D 类。Material 属性获取或设置 GeometryModel3D 类的材质。同样，BackMaterial 属性也获取或设置应用于对象背面的材质。Material 和 BackMaterial 属性定义形状的表面。表面很重要有两个原因；首先，它定义了对象的颜色，其次，它定义了材质对光的响应方式。

## 3-D 模型的材质

当你创建 Geometry3D 对象时，你不仅应指定形状的顶点，还应指定其构成的材质。在 2-D 中，你使用 Brush 类来应用颜色和图案以使对象可见。然而，在 3-D 中，你需要应用纹理来覆盖表面，使网格看起来像 3D 对象。为了应用纹理，WPF 使用 Material 抽象类。WPF 包含以下三个材质类，它们都派生自 System.Windows.Media.Media3D 命名空间中的抽象 Material 类：

- DiffuseMaterial 类——指定应均匀地将画刷应用于模型。DiffuseMaterial 类允许将 2-D 画刷，例如 SolidColorBrush，应用于弥散光照 3-D 模型。它在所有方向上均匀地散射光。
- SpecularMaterial 类——创建光泽和突出显示的外观。它像镜子反射光一样反射光。SpecularMaterial 类指定应将画刷应用于模型，就好像模型表面是坚硬的，能够反射光线一样。你可以通过指定 SpecularPower 属性来设置纹理反射光的程度。
- EmissiveMaterial 类——通过产生自身光线来创建发光外观，该光线不会反射到场景中的其他对象。它允许你指定应用于纹理，就好像模型正在发出与画刷颜色相等的光一样。

你可以通过使用 MaterialGroup 类将多个材质应用于场景。例如，你可以选择使用 DiffuseMaterial 类将复杂纹理应用于网格，并也在同一网格上添加 SpecularMaterial 类的高光效果。MaterialGroup 类将这些材质视为单个纹理。你将在本章的 Immediate Solutions 部分了解有关如何为材质应用 Material 类的更多信息。

## 灯光

在场景中添加模型和材质后，你需要向场景中添加光源以使其可见。Light 类用于 WPF 中的光效，并且这些效果是针对对象单独计算的。它从一个对象反射的光不会反射到另一个对象。同样，无论放置在哪里，一个对象都不会在其上投射阴影。Light 类是用于在 WPF 中使用光线的抽象基类，它为在 WPF 中实现光线提供了以下四个类：

- DirectionalLight 类——照亮光线，例如远处光源。DirectionalLight 类照亮沿 Vector3D 指定的方向投影其效果的对象。DirectionalLight 类指定的光线来自一侧，你可以看到边缘和阴影。你可以以阳光为例来说明 DirectionalLight 类。
- AmbientLight 类——提供一种不自然的光，用散射光照亮场景。AmbientLight 类无论形状、位置或方向如何，都均匀地照亮对象。
- PointLight 类——从单个点开始向所有方向辐射光。PointLight 类具有位置，并从该位置指向光。场景中的对象根据其相对于光的位置和距离被照亮。PointLight 类的 Range 属性决定了模型无需被光照亮的距离。
- SpotLight 类——从单个点开始以锥形向外辐射光。SpotLight 类继承自 PointLight 类。InnerConeAngle 和 OuterConeAngle 属性指定光在锥形区域投影的面积。

## WPF 4.0 中的动画

WPF 中的动画允许你创建动态 UI。你可以使用动画应用不同的效果，例如放大图标或滚动文本。WPF 中的动画可以用多种方式用于增强应用程序。在 WPF 中，你可以创建动画并使其生效而无需编写一行代码，即你可以声明性地创建动画。例如，你创建一个使用计时器的应用程序，该计时器定期触发。当计时器触发时，你需要使用事件处理程序来计算与动画相关的细节。WPF 注意到你对窗口中元素所做的更改。然后它重新绘制新的窗口内容。WPF 通过托管代码和 XAML 包含高效的计时系统。

在 WPF 中，你通过将动画应用于其各个属性来为对象设置动画。例如，要使元素变大，你对其 Height 和 Width 属性进行动画。一个属性如果满足以下要求，则可以具有动画功能：

- 必须是依赖属性
- 必须属于继承自 DependencyObject 类并实现 IAnimatable 接口的类
- 必须是兼容的动画类型

System.Windows.Media.Animation 命名空间是 WPF 中所有动画的基础命名空间。在本节中，你将学习关于：

- 动画类型
- 动画基础
- 事件触发器和动画
- KeyFrames
