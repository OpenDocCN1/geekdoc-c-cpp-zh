You can host Silverlight content on any ASP.NET website using certain ASP.NET server controls. Note that the Silverlight content hosted in an ASP.NET website uses XAML for the UI, while the rest of the ASP.NET content uses standard HTML for UI. You can host Silverlight content in an ASP.NET Web application by creating a Silverlight application using the Visual Studio 2010 template and using an ASP.NET Web application to host it.

Now, let’s create a Silverlight 3.0 application and use a Web site to host the Silverlight content by performing the following steps:

+   1. Open the Visual Studio 2010 window and select File→New→Project, which displays the New Project dialog box.
+   2. Select Visual C# from the Installed Templates pane.
+   3. Select Silverlight from the Installed Templates pane and the Silverlight Application option from the middle pane of the New Project dialog box (Figure 17.19).
+   4. Enter an appropriate name and location for the Silverlight application in the Name text box and Location combo box, respectively. In our case, we have named the Silverlight application as SilverlightWithASP and entered the location as D:\Books\Black Book\C# 2010\Chapter 17\PracticeApplications (Figure 17.19).
+   5. Click the OK button, as shown in Figure 17.19:
