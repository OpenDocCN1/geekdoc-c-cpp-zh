# Thread Synchronization

Synchronization is the process of coordinating the events and tasks in such a way that all the tasks are completed without the interference and interruption of other tasks. If a task uses a single independent object, then there is no need to synchronize the task; however, if a task uses a shared object, you need to synchronize the tasks to avoid multiple requests for accessing and using the same object by different threads. To understand the concept of synchronization in a better way, let's take an example where you and your friend share the same remote control of a television. You want to watch the news channel and record news while your friend wants to watch a movie and record it. When it is your turn, you switch to news channel, and then your time slice also ends. Now, you continue from your last action and start recording and so on. What will be the result? Neither of you will be able to do your intended tasks. In C# programming, the same situation occurs with multiple threads that try to access a single shared resource (object). In such case, the tasks assigned to threads must be synchronized in a way to ensure that the object is used by one thread at a time.
