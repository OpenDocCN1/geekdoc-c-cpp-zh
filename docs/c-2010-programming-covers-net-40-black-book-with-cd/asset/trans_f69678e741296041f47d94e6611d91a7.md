## 使用 Fall-through Switch 语句

Fall-through switch 语句是一种 switch 语句，其中多个 case 被组合在一起，后跟一组语句和一个 break 语句。让我们创建一个名为 DaysInMonth 的控制台应用程序（也在 CD 上提供）来展示如何使用 switch 语句的 fall-through。清单 3.4 显示了 DaysInMonth 应用程序的代码：

### 清单 3.4：显示 DaysInMonth 应用程序的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace DaysInMonth
{
class Program
{
static void Main(string[] args)
{
string month;
Console.Write("Enter the Name of a Month: ");
month = Console.ReadLine().ToUpper();
switch (month)
{
case "JANUARY":
case "MARCH":
case "MAY":
case "JULY":
case "AUGUST":
case "OCTOBER":
case "DECEMBER":
Console.WriteLine(month + " has 31 days");
break;
case "APRIL":
case "JUNE":
case "SEPTEMBER":
case "NOVEMBER":
Console.WriteLine(month + " has 30 days");
break;
case "FEBRUARY":
Console.WriteLine(month + " has 28 or 29 days");
break;
default:
Console.WriteLine("You have entered an invalid month name");
break;
}
Console.Write("\nPress ENTER to quit...");
Console.ReadLine();
}
}
}
```

在清单 3.4 中，我们将天数相同的月份分组，例如一月和三月。保持所有产生相似输出的 case 在一起的原因是我们可以用一个 break 语句应用于它们。如果用户输入无效的月份名称，则会执行 default 语句。

## 使用 while 循环

C# 中的 while 循环用于在指定条件变为 true 之前重复一个过程。让我们创建一个名为 MyWhileLoop 的控制台应用程序（也在 CD 上提供）来展示如何使用 while 循环。清单 3.5 显示了 MyWhileLoop 应用程序的代码：

### 清单 3.5：显示 MyWhileLoop 应用程序的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MywhileLoop
{
    class Program
    {
        static void Main(string[] args)
        {
            // Example 1
            // An example of a simple while loop
            Console.WriteLine("Loop 1:");
            int i = 0;
            while (i < 5)
            {
                Console.WriteLine("I = {0}", i);
                i++;
            }
            // Example 2
            // A while loop with a boolean
            bool flag = false;
            i = 0;
            Console.WriteLine("\nLoop 2:");
            while (!flag)
            {
                if (i > 5)
                    flag = true;
                Console.WriteLine("I = {0}", i);
                i++;
            }
            // Example 3
            // A loop that will never execute
            Console.WriteLine("\nLoop 3: ");
            while (i <= 0)
            {
                Console.WriteLine("I = {0}", i);
                i++;
            }
            Console.Write("\nPress ENTER to quit...");
            Console.ReadLine();
        }
    }
}
```

清单 3.5 包含三个示例来展示 while 循环的使用。第一个示例是一个简单的 while 循环示例。在第二个示例中，while 循环使用一个布尔值进行操作，该布尔值根据变量的值进行设置。在第三个示例中，while 循环不会执行，因为 while 语句中指定的条件在第一次迭代执行之前就已满足。

## 使用 do...while 循环

do...while 循环的工作方式与 for 循环和 while 循环非常相似。do...while 循环不包含任何初始化语句，也不自动递增。与 while 循环不同，do...while 循环在循环末尾检查条件而不是在开头。因此，无论给定的条件是 true 还是 false，do...while 循环总是至少执行一次。让我们创建一个名为 MyDoWhileLoop 的控制台应用程序（也在 CD 上提供）来展示 do...while 循环的使用。

### 清单 3.6：显示 MyDoWhileLoop 应用程序的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyDoWhileLoop
{
    class Program
    {
        static void Main(string[] args)
        {
            // First, a simple do loop that
            // increments a counter
            int i = 0;
            Console.WriteLine("Loop 1:");
            do
            {
                Console.WriteLine("I = {0}", i);
                i++;
            }
            while (i < 5);
            // Next, the same case, but using a
            // boolean rather than an index
            i = 0;
            Boolean done = false;
            Console.WriteLine("\nLoop 2:");
            do
            {
                Console.WriteLine("I = {0}", i);
                i++;
                if (i > 5)
                    done = true;
            }
            while (!done);
            // Finally, a conditional that is true before
            // You get into the loop
            do
            {
                Console.WriteLine("Into Loop 3");
            }
            while (!done);
            Console.Write("\nPress ENTER to quit...");
            Console.ReadLine();
        }
    }
}
```

清单 3.6 包含三个示例来展示 do...while 循环的使用。在第一个示例中，do...while 循环在 while 语句中指定的条件为 true 时显示 i 变量的值。第二个示例包含一个检查布尔标志的 do...while 循环。在第三个示例中，while 语句中指定的条件为 false，但 while 循环仍然执行一次。
