# Sealed Classes and Sealed Methods

Sealed classes are classes that cannot be inherited. You can use the sealed keyword to define a class as a sealed class. A sealed class can contain sealed methods. Similar to the sealed classes, sealed methods are also defined using the sealed keyword. You should note that a derived class cannot override the sealed methods.

The following code snippet shows how to define a sealed class and sealed method:

```
sealed class MyClass
{
    ...//Data Members
    public void GetDetail()
    {
    }

    public sealed void ShowDetail() //sealed method
    {
    }
}
class MainClass
{
    //Instantiation of MyClass class
    //Method Calling
}
```

In the preceding code snippet, the sealed class, MyClass, is instantiated in the MainClass class. However, you attempt to derive a class from the MyClass class, as shown in the following code snippet:
    class DerivedClass : MyClass

# Extension Methods

Extension method is a method that helps you to extend a class without creating a new derived class or modifying the original class. It works as a static method, but is invoked with an instance of the extended class. The extension method can be any static method which uses the this keyword before its first parameter. Only class that has static members and implements the this keyword in the first parameter of a static method can use the extension methods. The following code snippet shows an example of extension method:

```
static class MyClass
{
    public static int MyExtensionMethod(this string Number)
    {
        ...//Method Body
    }
    public static int MyStaticMethod(string Number)
```
