# Project Requirements

The following are the basic software requirements for developing the Sports Website project:

+   - Microsoft Visual Studio 2010 Ultimate
+   - Microsoft SQL Server 2008
+   - AJAX Control Toolkit
+   - Microsoft Silverlight 3

In addition, you must be familiar with the following basic concepts of C# 2010 and ASP.NET 4.0:

+   - Database handling
+   - WebPart controls
+   - Event handling
+   - Validating the code
+   - Displaying messages
+   - MasterPage
+   - Silverlight
+   - AJAX

# SDLC of Sports Website Project

The software development life cycle (SDLC) is a series of sequential and logical steps taken to develop an enterprise application. The various phases of SDLC are designed to meet or exceed customer expectations and work effectively and efficiently in the current and planned Information Technology infrastructure. It should be adaptable to further requirement modifications.

SDLC generally entails the following phases:

+   - Requirement analysis
+   - Software design
+   - Development and testing
+   - Implementation and maintenance

Similar to any other application development project, the development of the Sports Website project also undergoes all the preceding listed phases. Let’s now discuss each of these phases one by one.

# The Requirement Analysis Phase

In the requirement analysis phase, you need to list all the requirements that must be fulfilled by the enterprise application. In other words, this phase must analyze all the goals and requirements of the proposed project. For example, the Sports Website project must:

+   - Allows the users to register themselves to the website
+   - Allow all the users to read the sports article
+   - Allow only the registered user to comment on the article
+   - Allow the registered users to recover their lost password or change their password
+   - Allow the users to view the list of available items
+   - Allow the users to purchase the available items online
+   - Allows the users to view the pictures of the sportspersons and download them on their computer

# The Software Design Phase

In the software design phase, you need to design the user interface as well as database of the project. In other words, the code to perform both front-end and back-end tasks is written in this phase. This phase of the Sports Website project is divided into two sections, user interface (UI) or the front-end design and the database or back-end design.
