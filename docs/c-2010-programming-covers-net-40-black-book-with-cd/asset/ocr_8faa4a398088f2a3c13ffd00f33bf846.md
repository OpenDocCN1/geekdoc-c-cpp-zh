To write to an event log, you can use the WriteEntry() and WriteEvent() methods. In these methods, you need to specify the event source of the event log using the Source property. These methods allow you to specify the messages that you want to display when a service starts, stops, or pauses.

> **NOTE**
> The Application event log is the default event log, that is, if you do not set the Log property, the entries are written to the Application event log.
> If you have an event log that is not needed very frequently, then it is advisable to pause or stop the event log for that duration. This enables you to save the memory and other resources captured by the event log.
