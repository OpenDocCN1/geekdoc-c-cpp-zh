## 使用 CreateUserWizard 控件

你在“深入”部分已学习到 CreateUserWizard 控件如何促进新用户的创建。要实现 CreateUserWizard 控件，让我们执行以下步骤：

创建一个名为 CreateUserWizardControl 的 Web 应用程序（也可在 CD 上获得），以演示如何使用 CreateUserWizard 控件。要创建该应用程序，首先向 Default.aspx 页面添加一个 CreateUserWizard 控件。然后，右键单击 CreateUserWizard 控件并从上下文菜单中选择 Auto Format 选项。接下来，选择 Classic 方案以使控件看起来更美观。

现在，打开 CreateUserWizardControl 应用程序的 Default.aspx 文件并用清单 16.4 所示的代码替换现有代码：
