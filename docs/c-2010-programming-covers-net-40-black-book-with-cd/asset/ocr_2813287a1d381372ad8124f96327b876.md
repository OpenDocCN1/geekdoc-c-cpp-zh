# The XPathDocument Class

You can use the XPathDocument class to enable faster processing of XML documents. The XPathDocument class has overloaded constructors, which takes the parameters of the file name of an XML document, TextReader object, XmlReader object, or Stream-based object. The XPathDocument class is very simple to use because it has only one XML-related method named CreateNavigator(), which can be used to create an instance of the XPathNavigator class.

# The XPathNavigator Class

The XPathNavigator class contains methods that are used to move and select elements from an XML document. Table 30.7 describes some methods of the XPathNavigator class:

| Table 30.7: Useful Methods of the XPathNavigator Class |
| Method name | Description |
| MoveTo() | Takes a parameter, which is an object of the XPathNavigator class. It is used to move the current cursor position to a new position, which is passed into the XPathNavigator object. |
| MoveToAttribute() | Moves to the named attribute. It takes the attribute name and namespace as its parameters. |
| MoveToFirstAttribute() | Moves to the first attribute in the current element. It returns true, if executed successfully. |
| MoveToNextAttribute() | Moves to the next attribute in the current element. It returns true, if executed successfully. |
| MoveToFirst() | Moves to the first sibling in the current node. It returns true, if executed successfully, otherwise returns false. |
| MoveToLast() | Moves to the last sibling in the current node. It returns true, if executed successfully. |
| MoveToNext() | Moves to the next sibling in the current node. It returns true, if executed successfully. |
| MoveToPrevious() | Moves to the previous sibling in the current node. It returns true, if executed successfully. |
| MoveToFirstChild() | Moves to the child of the current element. It returns true, if executed successfully. |
| MoveToId() | Moves to the element with the ID supplied as a parameter. For this method, you should have a schema for the document and the data type for the element must be of type Id. |
| MoveToParent() | Moves to the parent of the current node. It returns true, if executed successfully. |
| MoveToRoot() | Moves to the root node of the document. |

In addition to methods listed in Table 30.7, the XPathNavigator class has few more methods that are used to select elements from an XML document. These methods are Select(), SelectAncestors(), and SelectChildren(); and all of these methods return an XPathNodeIterator object. The Select() method takes an XPath expression as a parameter, while the other two methods take an XPathNodeType object as parameters.

# The XPathNodeIterator Class

The XPathNodeIterator class provides an iterator over a selected set of nodes. The properties defined by this class are as follows:

+   - Count — Represents the total number of nodes in the XPathNodeIterator object
+   - Current — Represents an XPathNavigator object pointing to the current node
+   - CurrentPosition — Represents the current position of the node in the form of an integer

The following are the methods defined by the XPathNodeIterator class:

+   - Clone() — Creates a new copy of the XPathNodeIterator object
+   - MoveNext() — Moves to the next node that matches the XPath expression, which has created the XPathNodeIterator object
