public delegate void ValueChangedEventHandler();
// This is the event itself
public event ValueChangedEventHandler Changed;
// This method is used to fire the event
protected virtual void OnChanged()
{
    if (Changed != null)
        Changed();
    else
        Console.WriteLine("Event fired. No handler!");
}
public EventTestClass(int nvalue) { SetValue(nvalue); }
public void SetValue(int nv)
{
    if (nValue != nv)
    {
        nValue = nv;
        // Fire the event
        OnChanged();
    }
}

# Chaining Events

Many programming languages use the concept of event handling to perform various actions, such as clicking of a Button control. C# for example, permits you to define an event handler for each event. The problem, however, is that most of the time you can define only a single event handler for each event. C# also allows you to implement multiple event handlers for a single event and let the event handling system manage all the events handlers by chaining them.
