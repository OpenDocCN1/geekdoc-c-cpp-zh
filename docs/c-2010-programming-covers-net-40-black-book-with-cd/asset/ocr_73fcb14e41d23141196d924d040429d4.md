# Table 29.4: Showing the Methods of Directory Class

| Methods | Description |
|---|---|
| Delete() | Deletes the specified directory |
| Exists() | Determines whether the given path refers to the directory that exists on a disk |
| GetAccessControl() | Returns the Windows Access Control List (ACL) |
| GetCreationTime() | Retrieves the creation date and time of a directory |
| GetCreationTimeUtc() | Retrieves the creation date and time of a directory in the Coordinated Universal Time (UTC) format |
| GetCurrentDirectory() | Retrieves the current working directory of an application |
| GetDirectories() | Retrieves the name of the subdirectories in a particular directory |
| GetDirectoryRoot() | Retrieves the root, volume or information for both volume and root, pertaining to a specified path |
| GetFiles() | Retrieves the name of files in a specified directory |
| GetFileSystemEntries() | Retrieves the name of all files and subdirectories in a specified directory |
| GetLastAccessTime() | Retrieves the specified file or directory's last accessed date and time |
| GetLastAccessTimeUtc() | Retrieves the specified file or directory's last accessed date and time in the UTC format |
| GetLastWriteTime() | Retrieves the date and time of the specified file or directory when it was last written |
| GetLastWriteTimeUtc() | Retrieves the specified file or directory's date and time when it was last written in the UTC format |
| GetLogicalDrives() | Retrieves the names of drives on a computer |
| GetParent() | Retrieves the parent directory of the specified path, which includes both absolute and relative paths |
| Move() | Moves a file or directory along with its content to a new location |
| SetAccessControl() | Implements ACL entries that are described by a DirectorySecurity object of the specified directory |
| SetCreationTime() | Sets the specified file or directory's creation date and time |
| SetCreationTimeUtc() | Sets the specified file or directory's creation date and time in the UTC format |
| SetCurrentDirectory() | Specifies current working directory for an application |
| SetLastAccessTime() | Sets the last accessed date and time of the specified file or directory |
| SetLastAccessTimeUtc() | Sets the specified file or directory's date and time when it was last accessed in the UTC format |
| SetLastWriteTime() | Specifies the directory's last written date and time |
| SetLastWriteTimeUtc() | Specifies the directory's last written date and time in the UTC format |

The DirectoryInfo class exposes the instance methods that help in creating, moving, and enumerating directories.

The inheritance hierarchy of the DirectoryInfo class is as follows:

```
System.Object
System.MarshalByRefObject
System.IO.FileSystemInfo
System.IO.DirectoryInfo
```
