# Image Metadata

Metadata describes the content or characteristic of the file. There is a different metadata associated with each image, but WPF imaging provides a uniform way of storing and retrieving metadata for each image. You can access the metadata of the image through the Metadata property of the BitmapSource object. The Metadata property returns a BitmapMetadata object that includes all the metadata information contained by the image. The BitmapMetadata object can be a single schema or a collection of schemas. The image metadata schemas supported by WPF imaging are Exchangeable Image File (Exif), tEXt (PNG Textual Data), image file directory (IFD), International Press Telecommunications Council (IPTC), and Extensible Metadata Platform (XMP).

If the BitmapMetadata object is exposed by a BitmapFrame object that is obtained by using the BitmapDecoder class, it is read-only by default. The mutable operations throw an exception. If the BitmapMetadata object is exposed by a BitmapFrame object that wraps another BitmapSource object, it is mutable on construction. You can use the GetQuery() and SetQuery() methods to construct and read metadata queries, respectively.

# Audio and Video

In this section, you learn two more areas of WPF, audio and video. WPF gives you the ability to play a wide variety of sound formats, which includes anything supported by the Windows Media Player. Similarly, WPF also supports the video format that includes the Moving Picture Experts Group (MPEG) and Windows Media Video (WMV) files. You can also integrate the audio and video into the rest of the WPF application. For example, you can use video and combine it with 3-D objects and animation. You can integrate the audio and video content in your application. WPF uses the MediaElement control for playing both video and audio.
