# In Depth

Graphics, in literal sense, means a visual presentation of designs, shapes, drawings, and text, which is often used to view particular information. Animation is the rapid display of the sequentially arranged graphics to create an illusion of movement. Multimedia includes a combination of text, audio, video, animation, and graphic contents. Windows Presentation Foundation (WPF) includes support for high quality Two-Dimensional (2-D) and Three-Dimensional (3-D) graphics, animation, and media features, which enable you to add graphics, transition effects, sound, and video to your applications. WPF provides advanced drawing and animation features that were previously available only for specialized libraries, such as Graphics Device Interface (GDI) and GDI+.

The versions prior to Visual Studio 2005 offered limited features to integrate graphics in Windows Forms. For example, in the earlier versions of Visual Studio, only primary colors were used with different shapes and graphic objects. With each successive release of Visual Studio, Microsoft has tried to successfully overcome this drawback. The integration of graphics in Windows Forms has now been extended to include the support for integrating multimedia, graphics, and animations in WPF. This integration has made it easier to build graphically rich and visually appealing user interface (UI) and content.

In this chapter, you learn about the graphics and multimedia features of Windows Forms and WPF. The In Depth section of this chapter describes the use of graphics in Windows Forms. In addition, the chapter describes the use of graphics, animation, and multimedia in WPF 4.0. In the Immediate Solutions section of this chapter, you learn about creating graphics in Windows Forms and creating graphics, animation, and multimedia in WPF. Let’s start with graphics in Windows Forms applications.

# Graphics in Windows Forms Applications

In Windows Forms applications, you might need to create simple shapes and other graphical objects. In such a case, you can use the graphics elements of Windows Forms which help to create a visually appealing application. In Windows Forms applications, GDI+ is used to create graphics, draw text, and manipulate graphical images. GDI is responsible for the integration of graphics in Windows Forms, and GDI+ is an advanced implementation of GDI. The basic use of GDI+ is to render graphical images on a form.

You can also use GDI+ on Web forms by displaying graphical images with the help of the Image Web server control. Note that you cannot use GDI+ directly on Web forms. In this section, you learn about:

+   - GDI+ managed class interface
+   - Basic GDI+ managed classes

# GDI+ Managed Class Interface

The core of the GDI+ functionality is the Graphics class. GDI+ consists of a set of base classes that are available to control the custom drawing on the screen. It is exposed through a set of classes deployed as managed code. This set of classes is collectively called the GDI+ managed class interface.

The GDI+ managed class interface is a part of .NET Framework. It provides an environment for building, deploying, and running XML Web services and other applications. It allows access to the underlying operating system functionality that provides 2-D vector graphics, imaging, and typography. The GDI+ managed class interface contains about 60 classes, 50 enumerations, and 8 structures. You can group the classes in the namespaces that make up the GDI+ managed class interface.
