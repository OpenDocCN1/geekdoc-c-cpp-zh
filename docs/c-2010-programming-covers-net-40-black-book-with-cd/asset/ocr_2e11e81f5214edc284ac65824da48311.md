# Table 37.5: Noteworthy Public Methods of DirectoryEntries Class

| Method | Description |
|--------|-------------|
| Add | Creates a new entry in a container |
| Find | Returns a member in the current collection |
| GetEnumerator | Returns an enumerator that iterates through a collection |
| Remove | Deletes a member from the current collection |

Noteworthy public properties of the DirectorySearcher class are shown in Table 37.6:

# Table 37.6: Noteworthy Public Properties of DirectorySearcher Class

| Property | Description |
|----------|-------------|
| Asynchronous | Obtains or sets a value that indicates if the search is performed asynchronously. |
| AttributeScopeQuery | Obtains or sets the LDAP display name of the distinguished name attribute to be searched. Only one attribute can be used for this type of search. |
| CacheResults | Obtains or sets a value indicating whether the result is cached on the client computer. |
| ClientTimeout | Obtains or sets the maximum amount of time that the client waits for the server to return results. If the server does not respond within this time, the search is aborted and no results are returned. |
| DerefoAlias | Obtains or sets a value indicating how the aliases of objects found during a search should be resolved. |
| DirectorySynchronization | Obtains or sets an object that represents the directory synchronization control to use with the search. |
| ExtendedDN | Obtains or sets a value that indicates the format of the distinguished names. |
| Filter | Obtains or sets a value indicating the LDAP format filter string. |
| PageSize | Obtains or sets a value indicating the page size in a paged search. |
| PropertiesToLoad | Obtains a value indicating the list of properties to be retrieved during the search. |
| PropertyNamesOnly | Obtains or sets a value indicating whether the search retrieves only the names of attributes to which values have been assigned. |
| ReferralChasing | Obtains or sets a value indicating how referrals are chased. |
| SearchRoot | Obtains or sets a value indicating the node in the AD hierarchy from where the search starts. |
| SearchScope | Obtains or sets a value indicating the scope of the search that is observed by a server. |
| SecurityMasks | Obtains or sets a value indicating which security access information for the specified attributes should be returned by the search. |
| ServerPageTimeLimit | Obtains or sets a value indicating the maximum amount of time the server should take to search an individual page of results. This is not the same as the time limit for the entire search. |
| ServerTimeLimit | Obtains or sets a value indicating the maximum amount of time the server spends in searching. If the time limit is reached, only entries that are found up to that point are returned. |
| SizeLimit | Obtains or sets a value indicating the maximum number of objects that the server returns in a search |
| Sort | Obtains or sets a value on the basis of which results are sorted |
