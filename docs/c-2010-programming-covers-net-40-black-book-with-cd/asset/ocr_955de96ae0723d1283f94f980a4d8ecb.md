# Using the Popup Control

There may be cases when you want to provide additional information or display some help information about something, such as a control or UI element in an application. In such cases, you can make use of the Popup control available in Silverlight 3.0. The Popup control displays the information in a bounded area on top of the other controls. The bounded area can be any UI control that is hosted as the child of the Popup control. Perform the following steps to learn how to use a Popup control:

+   1. Create a Silverlight application (hosted in a single HTML page) named PopUpHelpAppCS (available on the CD). Listing 17.11 shows the code for the MainPage.xaml file of the PopUpHelpAppCS application:
