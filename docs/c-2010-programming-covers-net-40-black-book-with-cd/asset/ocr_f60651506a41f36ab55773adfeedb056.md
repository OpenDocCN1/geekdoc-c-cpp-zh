# Creating an Anonymous Type

An anonymous type provides you an easy way to encapsulate a set of read-only properties into a single object without defining a new type. To see how to create an anonymous type, first create a new Console application, named MyAnonymousType (also available in the CD) and then replace the default code of the Program.cs file of the application with the code shown in Listing 4.23:

Listing 4.23: Showing the Code of the MyAnonymousType Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace MyAnonymousType
{
    class Program
    {
        static void Main(string[] args)
        {
            var product = new { Name = "Key Board", Price = 650 };
            Console.WriteLine("Product Details");
            Console.WriteLine("Name:" + product.Name);
            Console.WriteLine("Price: Rs." + product.Price);
            Console.Write("Press ENTER to quit...");
            Console.ReadLine();
        }
    }
}
```

In the highlighted line of Listing 4.23, we are defining a new anonymous type and also creating an object of that type with the name product. The type that we have defined has two variables, Name and Price.
