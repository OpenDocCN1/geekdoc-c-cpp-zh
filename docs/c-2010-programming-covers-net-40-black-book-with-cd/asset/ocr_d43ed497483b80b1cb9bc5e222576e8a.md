# Using Anonymous Authentication in ASP.NET

Anonymous authentication is enabled in IIS by default. This implies that a user trying to access a Web page of an ASP.NET application is treated as an anonymous user by IIS. For an anonymous user, IIS does not require any kind of credentials. Many websites and Web applications allow users to access a majority of the Web content anonymously, that is, without the need of any authentication.
