# New WPF text rendering stack

The new WPF text rendering stack has brought improvements to text rendering clarity, configurability, and support for international languages while rendering text. Moreover, users can now select from auto, aliased, grayscale or ClearType text rendering modes. Apart from these improvements, the text stack now includes support for the display-optimized character layout so that text with sharpness comparable to Win32/GDI text can be generated. Furthermore, the new WPF text rendering stack now supports fonts with embedded bitmaps to be used in place of smaller sized fonts.

# Improvements in XBAPs

You can now access a script object that enables you to communicate with a Web page containing an XBAP hosted in a Hypertext Markup Language (HTML) frame. In addition, you can now provide an XBAP with full trust permission while deploying it by modifying your project to enable this permission.

# WPF 4.0 Architecture

Although WPF 4.0 is a part of .NET Framework 4.0, it contains both managed and unmanaged components. Since the managed components of WPF 4.0 are based on the Common Language Runtime (CLR), they make use of the different features of CLR, such as cross-language integration, type safety and security, debugging and exception handling, and garbage collection. Most of the functionalities and features of WPF 4.0 are provided through managed components. In addition to managed components, WPF 4.0 contains an unmanaged component called the Media Integration Layer (MIL or milcore). Figure 9.6 shows managed and unmanaged components of WPF 4.0:
