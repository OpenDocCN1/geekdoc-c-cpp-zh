The operators are associated with either the expression on its left or the expression on its right, which is known as the associativity of the operator. Table 2.7 lists the precedence of the different operators in C#:

| Table 2.7: Showing the Operator Precedence |
| Operator | Associativity |
| (x), (x,y), f(x), a[x], x++, x--, new, typeof, sizeof, checked, unchecked | Left |
| + (unary), - (unary), ~, ++x, --x, (T)x | Left |
| *, /, % | Left |
| + (arithmetic), - (arithmetic) | Left |
| <<, >> | Left |
| <, >, <=, >=, is, as | Left |
| ==, != | Left |
| & | Left |
| ^ | Left |
| | | Left |
| && | Left |
| || | Left |
| ?: | Right |
| =, *=, /=, %=, +=, -=, <<=, >>=, &=, ^=, |= | Right |

In Table 2.7, the operators at the same level have equal precedence and are evaluated in the given order in an expression until and unless separated by the parenthesis.
