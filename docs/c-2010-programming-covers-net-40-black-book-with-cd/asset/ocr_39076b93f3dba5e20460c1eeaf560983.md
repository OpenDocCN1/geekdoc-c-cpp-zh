# Adding Decorations to the Text

In WPF, you can decorate the text by using the TextDecoration class. The TextDecoration class provides a set of static predefined text decorations. These predefined decorations include baseline, overline, and underline. Let's create a WPF application named TextDecorations (also available on the CD-ROM) to learn how to decorate the text. Listing 11.2 shows the code of TextDecoration application:

# Listing 11.2: Showing the Code to Add Decorations to Text

```
<Window x:Class="TextDecorations.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="240" Width="300">
<Grid Height="212" Width="259">
    <TextBlock TextDecorations="Strikethrough" FontSize="30" verticalAlignment="Top" Margin="0,126,0,0">
    <TextBlock FontSize="30" VerticalAlignment="Top">Susane</TextBlock>
    <TextBlock FontSize="30" VerticalAlignment="Top">Hello!!!!!
    <TextBlock.TextDecorations>
    <TextDecorationCollection>
    <TextDecoration PenThicknessUnit="FontRecommended">
    <TextDecoration.Pen>
    <Pen Thickness="2">
    <Pen.Brush>
    <LinearGradientBrush Opacity="0.5" StartPoint="0,0.5" EndPoint="1,0.5">
    <LinearGradientBrush.GradientStops>
    <GradientStop Color="Blue" Offset="0" />
    <GradientStop Color="Green" Offset="1" />
    </LinearGradientBrush.GradientStops>
    </LinearGradientBrush>
    </Pen.Brush>
    <Pen.DashStyle>
    <DashStyle Dashes="3"/>
    </Pen.DashStyle>
```
