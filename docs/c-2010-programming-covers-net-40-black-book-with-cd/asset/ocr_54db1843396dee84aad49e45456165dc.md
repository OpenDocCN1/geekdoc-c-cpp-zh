# The Command Window

The Command window helps you to perform various operations, such as adding, deleting, or modifying a new item to the project. You can view the Command window by selecting View → Other Windows → Command Window or by pressing the CTRL+ALT+A keys together. This window allows you to execute commands directly in the Visual Studio 2010 IDE. The greater than (>) symbol in the Command window represents the prompt for a new line. You can use the UP arrow or the CTRL+UP arrow keys to scroll up the window and use the DOWN arrow or the CTRL+DOWN arrow keys to scroll down the window.

```
>Debug.Print varMessage
```

(Or)

```
?> var
```

Both the preceding commands display the value of the variable var. The question mark (?) is an alias for the Debug.Print command and is used to evaluate any expression. Therefore, both the commands return the same result. Now, enter the following command in the Command window without the greater than sign (>):

```
>immed
```

```
>cmd
```

# The Help Viewer Window

The Help Viewer window provides links to information found in local Help based on the portion of the IDE that is currently in focus. It includes the usual Help menu with Contents, Index, and Search items. In addition, the Help Viewer window searches automatically for various things.
