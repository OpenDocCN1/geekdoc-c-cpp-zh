# Bubbling Events

Bubbling events refer to the events that originate on one element but are raised and possibly handled on all the parent elements up to the root element. In other words, bubbling events are raised from the child element to the root element in the order of their hierarchy. For instance, consider the code in Listing 9.7:

# Listing 9.7: Demonstrating the Traversal of a Bubbling Event

```
<Window x:Class="MyWpfApplication.MainWindow"
xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
Title="MainWindow" Height="350" Width="525"
MouseRightButtonUp="MouseRightHandler">
<Grid Name="grid1" MouseRightButtonUp="MouseRightHandler">
<Button Name="button1" Height="25" Width="75" Content="button1" Margin="100,10,100,220" MouseRightButtonUp="MouseRightHandler"/>
<Button Name="button2" Height="150" Width="150" Margin="0" MouseRightButtonUp="MouseRightHandler">
<Grid Name="grid2" Height="100" Width="100" MouseRightButtonUp="MouseRightHandler">
<TextBox Name="textBox1" Text="textBox1" Height="25" Margin="0,0,45,60" MouseRightButtonUp="MouseRightHandler"/>
<TextBox Name="textBox2" Text="textBox2" Height="25" Margin="45,60,0,0" MouseRightButtonUp="MouseRightHandler"/>
</Grid>
</Button>
<Button Name="button3" Height="25" Content="button3" Margin="100,220,100,10" MouseRightButtonUp="MouseRightHandler"/>
</Grid>
</Window>
```

In Listing 9.7, you can see that the MouseRightButtonUp event is associated with its handler MouseRightHandler in all the elements. The MouseRightButtonUp event is a bubbling routed event that is available to all the elements derives from the UIElement class. Whenever you right click any element, the MouseRightButtonUp event is raised on the source element and traverses to the root element.
