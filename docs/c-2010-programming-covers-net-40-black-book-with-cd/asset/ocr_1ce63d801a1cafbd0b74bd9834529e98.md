After adding the Installer1 class, you need to build the application to create a dll or executable (exe) file. After creating the dll or exe file, you can install your Windows service either by using the installutil.exe utility or Windows installer.

# # Installutil.exe

The installutil.exe utility is an installer tool that allows you to use the command-line statement to install and uninstall Windows services. It installs a Windows service by installing the dll files related to the service in a target computer. The installutil.exe utility installs the Windows service in a transactional manner, which implies that if an error occurs while installing the service or the installation fails due to any other reasons, the installutil.exe utility roll backs the entire installation of the service.

# # Windows Installer

The Windows installer creates a deployment package for your application and adds the dll of your project to this deployment package as a custom action. It uses setup projects to create Windows installer files (.msi), which are used to install Windows services using a setup wizard. When you start deploying your Windows service application, the deployment process identifies that the Installer1 class should run and launch the installation process of your installation component.
