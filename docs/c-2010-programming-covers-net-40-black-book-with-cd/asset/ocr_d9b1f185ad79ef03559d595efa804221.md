# ## Static Classes and Static Class Members

The static class and its members do not need any object to call them; rather, you can use the class name to access the data and member functions of the class directly. The static class and its members enable you to access the data and member functions of the class without creating an instance of the class. Static members do not need to be instantiated. You can use a static class if data or methods declared in the class do not depend on the behavior of an object. C# uses the static keyword to define a class and its members as static.

```
```csharp
static class employee
{
    public static int id;
}
```
