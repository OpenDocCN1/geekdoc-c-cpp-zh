### 深入探讨

在互联网和 Web 开发的初期，网站仅使用超文本标记语言（HTML）开发。仅使用 HTML 构建的网页内容大多是静态的。渐渐地，随着级联样式表（CSS）、可扩展超文本标记语言（XHTML）和 JavaScript 等其他新技术和语言的出现，现在可以为网页添加用户交互性和一定的动态效果。随着岁月的流逝，Adobe Flash 和 JavaFX 等其他一些技术为网页带来了新的交互维度，因为这些技术促进了动画和多媒体在网页中的使用。使用这些技术构建的网站极大地推动了电子学习和在线广告等各个商业领域的发展。然而，其中一些技术的部署成本高昂，性能参差不齐，并且与不同的编程技术的兼容性也不尽如人意。

为了克服早期技术（如 Adobe Flash）的局限性，以及日益增长的富互联网应用程序（RIA）需求，微软推出了 Silverlight。Silverlight 以前称为 Windows Presentation Foundation Everywhere（WPF/E），用于构建可在跨浏览器、跨平台和跨设备环境中运行的 Web 应用程序。Silverlight 受 Microsoft Windows 和 Apple Macintosh 系列操作系统以及流行的 Web 浏览器（如 Microsoft Internet Explorer、Mozilla Firefox 和 Apple Safari）的支持。

Silverlight 是一种基于 Web 的技术，允许 Web 设计人员和开发人员拓展 Web 应用程序开发的边界。它集成了桌面应用程序的丰富用户界面（UI）和其他 Web 语言（如 HTML 和 JavaScript）的透明性。Silverlight 允许您开发包含高保真多媒体内容和引人注目的视觉效果的 Web 应用程序。Web 设计人员和开发人员已经接受 Silverlight 来构建高质量的交互式 Web 应用程序。

在本章中，您将了解 Silverlight 的主要功能和架构。您还将学习如何安装 Silverlight 3.0 SDK 和开发人员运行时。本章还讨论了如何在 Visual Studio 2010 项目中整合 Silverlight 功能。此外，本章还描述了 Silverlight 与 ASP.NET 之间的关联。现在，让我们从 Silverlight 的主要功能开始。

### Silverlight 的主要功能

如前所述，Silverlight 以前被称为 WPF/E，因为它是 WPF 的一个子集，继承了 WPF 的许多功能。例如，Silverlight 支持可扩展应用程序标记语言（XAML）、二维矢量图形、动画和多媒体。但是，某些功能（如 WPF 的三维图形和硬件渲染）在 Silverlight 中不可用。您可能想知道 WPF 中的 XAML 浏览器应用程序（XBAP）与 Silverlight 之间的区别。两者之间的一个显著区别是，XBAP 只能在 Internet Explorer 和 Firefox 中运行，而 Silverlight 应用程序可以在多个 Web 浏览器中运行。其次，XBAP 要求用户计算机上安装有 .NET Framework，而 Silverlight 自行提供必要的组件，不需要 .NET Framework。第三，XBAP 可以访问完整的 WPF 功能，而 Silverlight 应用程序仅具有有限的 WPF 功能。

微软推出的第一个 Silverlight 版本是 Silverlight 1.0。该版本于 2007 年发布，基于 JavaScript 应用程序模型。您可以将 Silverlight 1.0 的功能整合到 .NET Framework 2.0 和 Visual Studio 2005 应用程序中。2008 年 10 月，发布了 Silverlight 1.0 的升级版，即 Silverlight 2.0，它受 Visual Studio 2008 Service Pack 1（SP1）支持。最新的 Silverlight 版本是 Silverlight 4.0。然而，Silverlight 3.0 完全受 Visual Studio 2010 支持，并且是本章使用的版本。

Silverlight 3.0 的开发模型与 Silverlight 2.0 相同，并提供各种创新功能，帮助 Web 开发人员和设计人员开发企业级 RIA 和网站。与以前的版本相比，Silverlight 3.0 有许多改进，这些改进有助于以更轻松、更快捷的方式开发网站。例如，Silverlight 3.0 提供对更高质量视频和音频的支持、增强的数据支持、改进的性能以及浏览器外功能。Silverlight 3.0 具有改进的编程模型、全面的 UI 框架，并支持 Deep Zoom 技术、二维图形、动画、多媒体和网络。现在，让我们了解一下 Silverlight 3.0 的这些主要功能。

### 改进的编程模型

Silverlight 技术支持 .NET Framework 编程模型，以便轻松开发 Silverlight 应用程序。它利用了 .NET Framework 的许多功能和特性，例如类型安全和异常处理。此外，Silverlight 还包含基类库中的许多类，并为您提供使用 I/O、集合和泛型以及线程的功能。您可以使用任何 .NET 语言（如 VB 和 C#）来开发 Silverlight 应用程序。您还可以使用其他动态语言，例如 IronPython 和 IronRuby。此外，您可以将 Silverlight 功能与现有的 ASP.NET Web 应用程序集成。您可以将 ASP.NET AJAX 和 Silverlight 结合起来，以充分利用这两种技术的优势。Silverlight 还支持语言集成查询（LINQ）到对象，这使您能够处理 Web 应用程序中的各种类型的数据。

请注意，Silverlight 与 HTML、JavaScript 和文档对象模型（DOM）以及 XAML 解析器无缝集成，为您提供同时使用 HTML、JavaScript 和 XAML 的功能。通过这种方式，Silverlight 为开发交互式且高质量的 Web 应用程序扩展了一个有凝聚力的平台。

### 全面的 UI 框架

Silverlight 拥有全面的 UI 框架，允许您使用预定义的控件、样式、主题和模板来设计 Web 应用程序的 UI。Silverlight 还提供各种控件和布局功能，以构建异常吸引人的 Web 应用程序。大多数控件和布局功能与 WPF 中可用的相同。例如，WPF 的 Grid、StackPanel、Calendar、Button、TextBox 和 RadioButton 控件在 Silverlight 中也可用。您还可以在 Silverlight 应用程序中使用样式和控件模板。此外，还有一些特定于 Silverlight 的附加控件，例如 MultiScaleImage。您还可以使用数据绑定和数据操作控件，例如 DataGrid。这些新控件是从头设计的，为 Web 应用程序增添了额外优势。这些预定义的 Silverlight 控件和布局功能可帮助您快速轻松地开发一些高端 Web 应用程序。您可以设置这些控件的属性以获得所需的效果。请注意，这些属性也可以使用 XAML 设置，XAML 是分离 Web 应用程序设计和代码的促进器。Visual State Manager 功能（适用于 Microsoft Expression Blend 软件，该工具允许您使用 Silverlight 设计 Web 应用程序的 UI）在 Silverlight 3.0 中也可用。使用 Visual State Manager 功能，您可以轻松修改现有的控件模板并创建新的控件模板。

接下来，让我们讨论 Silverlight 3.0 对 Deep Zoom 技术的支持。

### 对 Deep Zoom 技术的支持

Silverlight 3.0 包含一个称为 Deep Zoom 的功能，它允许您在应用程序中放大高分辨率图像。您可以使用 Deep Zoom 技术来交付令人难以置信的创意和独特交互式的 Web 应用程序。使用 Deep Zoom 技术，您可以轻松、快速、平滑地同时放大或缩小多张图像。通过使用 Silverlight 3.0 中提供的 MultiScaleImage 控件，您可以查看高度详细和精细的图像视图。

### 对二维图形、动画和多媒体的支持

Silverlight 内置了对在 Web 应用程序中使用二维矢量图形和动画的支持。您可以创建二维形状，例如矩形和椭圆、几何图形和画笔。您还可以变换和动画化形状和几何图形。此外，您可以通过使用情节提要、控制动画时间线和速度等方式，使您的 Web 应用程序具有动态效果。

Silverlight 在 Web 上对迷人的多媒体体验提供了广泛的支持。您可以在应用程序中包含 .jpeg 或 .png 图像，以赋予其有吸引力的 UI。此外，Silverlight 支持各种多媒体格式，例如 .wma、.wmv 和 .mp3，并具备一些用于播放多媒体内容的基本编解码器。您还可以在 Silverlight 中使用高清晰度（HD）质量视频（最高 720p）。
