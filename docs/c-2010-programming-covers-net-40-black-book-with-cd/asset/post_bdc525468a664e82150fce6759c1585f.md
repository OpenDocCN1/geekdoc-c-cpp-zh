If you try to assign another value to a constant and compile the program, will display an error stating that the left-hand side of an assignment must be a variable, property, or indexer.

Constants and variables can be accessed only within the specific scope. The scope of a variable determines the region within the program where the variable can be accessed and referenced. The scope is of two types, block and class. When you declare a variable within a code block, the variable gets a local scope or a block scope therefore, it is known as local variable. The variable having a local scope cannot be used outside a code block in which it is declared. If you declare a variable outside the code block (or before defining the Main() method), the variable is said to have a class scope and known as global variable. Such a variable can be used throughout the program. Listing 2.1 shows an example to illustrate the scope of variables:

### Listing 2.1: Showing an Example for the Scope of Variables

```
class Scope
{
public void Scope1()
{
    int i = 0;
    i = i + 1;
}
public void Scope2()
{
    Console.WriteLine(i);
}
}
```

In Listing 2.1, variable i is declared and initialized within the Scope1() method. Now when you try to access variable i outside the Scope1() method, a compile-time error occurs stating that the name i does not exist in the current context. This is due to the reason that the i variable is a local variable of the Scope1() method and can be accessed only within this method.

The class scope uses the access modifiers, such as private and public, to specify the scope of a variable. The private keyword makes a variable local to a class and specifies that the variable cannot be used and accessed outside the class in which it is declared. You can make the variable global in the class by declaring it as public. This makes the variable to be used in any class within the entire program. Listing 2.2 shows an example to understand the scope of a class:

### Listing 2.2: Showing an Example for the Scope of a Class

```
public class LocalScope1
{
    int i = 0;
}
public class LocalScope2
{
    void Scope()
    {
        Console.WriteLine(i);
    }
}
```

In Listing 2.2, you can see that the variable i is declared in class LocalScope1. If you attempt to access i outside the LocalScope1 class, the same compile-time error occurs stating that the name i does not exist in the current context. The error has occurred because the i variable is declared in the LocalScope1 class and is private by default. Therefore the variable cannot be accessed in the LocalScope2 class.

C# supports a rich and varied selection of data types, from built-in types, such as integers or strings, to user defined types, such as enumerations, structures, and classes. The C# language provides a rich set of built-in data types. When dealing with these data types, you must remember the following points:

- All variables, whether user-defined or intrinsic (built-in), can be used as objects anywhere in a program
- All variables in a program are automatically initialized to default values by the system when they are declared

In C#, variables are classified into the following three categories:

- Value types
- Reference types
- Pointer types

Let’s discuss these in detail.

## Value Types

### Struct Type

Struct types are a special form of classes having the properties of value types. As you know that the value types are stored on the stack; inherently the struct types are also stored on the stack. The struct types can be copied and created efficiently, since stacks are the efficient and convenient means of storing and accessing the types. The struct types encapsulate small group of related variables, such as the name, rollno, age, classname, and section of a student. They can contain constructors, methods, properties, operators, events, nested types, indexers, constants, and fields. While creating the struct type, you should remember that struct members cannot be declared as protected as they fail to support inheritance. Under the struct declaration, the fields can be initialized only when they are declared as const or static.

You can create struct types by using the struct keyword. When you create a struct object and assign it to variable, the variable holds the value of the struct object. You can also use a struct type as a nullable type by assigning a null value to it. Listing 2.3 shows how to create a struct type:

### Listing 2.3: Showing an Example of the Struct Type

```
public struct student
{
    string name;
    int rollno;            //fields
    int classname;
    int section;
    ...                    //methods
    ...                    //properties
}
```

In Listing 2.3, we have created a struct type named student and declared it as public. Within the struct body we have declared the members, such as name, rollno, classname, and section.

The struct types are divided into the following five categories:

- Integral type
- Floating-Point type
- Decimal type
- Boolean type
- Nullable type

Let's discus all these data types in brief in the subsequent sections.

### Integral Type

C# provides a set of basic data types, which are known as integral type. This set consists of the types, such as sbyte, byte, short, ushort, int, uint, long, ulong, and char. To know the size, ranges, and default values of these data types, refer to Table 2.2.

The integral types can be divided into two value types, signed and unsigned. Signed value types may contain negative or positive values and unsigned value types contain only positive values. Unlike C++, conversion between the two types usually requires an explicit cast.

### Floating-Point Type

The floating-point types are divided into two types – single and double. Single floats, similar to the float data type of C++, hold values up to 10^38. The double data types, also similar to the C++ double type, hold values up to 10^308. The floating-point types take the values in fractions. For example, if you declare a variable as float and assign a value 2 to this variable, the variable will store the value 2.0.

### Decimal Type

The other data type, Decimal, is equivalent to a long integer that behaves as if it is a floating-point number. Decimal values are intended to be used for computing monetary values or other calculations in which round off figure is not required. As compared to the floating-point type, the decimal type has more precisions and smaller range.

### Boolean Type

Booleans are simple true or false values. Unlike C++, they cannot be assigned to any other type, nor can they be used in any sort of computation. The result of an expression in C# is not a Boolean expression, unless you specifically assign it as true or false.

### Nullable Type

A programming language supports Nullable data types when dealing with databases or when a user does not want to assign a value to a variable of any data type. You can use different strategies to deal with null values, if programming language does not support Nullable data types. For example, you can use -1 to specify null value for integer variables. You can also use Boolean null indicators to specify null value for variables.
