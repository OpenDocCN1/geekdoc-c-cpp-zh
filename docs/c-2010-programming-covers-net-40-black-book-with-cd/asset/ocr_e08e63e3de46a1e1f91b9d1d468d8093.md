You can also create a new virtual directory for your Web applications. Let’s perform the following steps to create a new virtual directory for your Web application:

+   1. Select the Local IIS tab in the Choose Location dialog box (Figure 13.4).
+   2. Select the Default Web Site option in the Choose Location dialog box (Figure 13.4).
+   
+   When you select the Default Web Site option, two options are enabled: Create New Web Application and Create New Virtual Directory. These options are available at the top right-hand corner of the Choose Location dialog box.
+   
+   3. Click the Create New Virtual Directory button, as shown in Figure 13.4.

![](bbox=[0.255, 0.221, 0.84, 0.559])

**Figure 13.4: Selecting Option to Create Virtual Directory**

The New Virtual Directory dialog box opens, as shown in Figure 13.5.

+   4. Enter a name for the new virtual directory in the Alias name text box (Figure 13.5).
+   5. Enter a location, where you want to save the new virtual directory in the Folder text box (Figure 13.5).
+   6. Click the OK button, as shown in Figure 13.5:

![](bbox=[0.227, 0.658, 0.856, 0.825])

**Figure 13.5: Providing Name and Location of the New Virtual Directory**

The new virtual directory is added to the location provided by the Choose Location dialog box (Figure 13.6).
