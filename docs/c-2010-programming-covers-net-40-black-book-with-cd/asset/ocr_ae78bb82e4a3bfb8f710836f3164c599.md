# The GroupBox Control

The GroupBox control in WPF provides a titled container, with a border and a header, for graphical UI content.

The content property of the GroupBox control is Content and the header property of the GroupBox control is Header. You can add multiple controls inside the GroupBox control.

The inheritance hierarchy of the GroupBox class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.ContentControl
                System.Windows.Controls.HeaderedContentControl
                  System.Windows.Controls.GroupBox
```

You can add the GroupBox control to a WPF application by using the following code snippet:

```
<GroupBox>
  <!--Content -->
</GroupBox>
```

There are no noteworthy properties of the GroupBox class.

# The TabItem Control

The TabItem control in WPF is contained within the TabControl class. The header of the TabItem control, which is displayed on a window, can be added to the page using the Header property. The TabItem control represents the selectable item inside the TabControl control. The TabControl control can contain multiple TabItem controls; however, only one TabItem control in the TabControl control is visible at a time.

The inheritance hierarchy of the TabItem class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.ContentControl
                System.Windows.Controls.HeaderedContentControl
                  System.Windows.Controls.TabItem
```
