

## Pen 类

Pen 类定义了一个在 Windows Forms 中绘制线条和曲线的对象。Pen 由 System.Drawing 命名空间中包含的 System.Drawing.Pen 类表示。Pen 类绘制指定宽度和样式的线条。你需要指定线的厚度以及如何填充宽线内部的区域。例如，你可以使用 DashStyle 属性绘制多种类型的虚线。你可以用多种填充样式填充 Pen 类绘制的区域，例如使用纯色或纹理。Pen 类的继承层次结构如下：

```
System.Object
  System.MarshalByRefObject
    System.Drawing.Pen
```

## Brush 类

Brush 类用于填充图形形状的内部，例如矩形、椭圆、多边形和路径。你可以使用 Pen 类绘制形状的轮廓，并使用 Brush 类填充形状。Windows Forms 中可用的不同类型的画刷有 SolidBrush、HatchBrush、TextureBrush、LinearGradientBrush 和 PathGradientBrush。所有这些画刷都继承自 System.Drawing.Brush 类。这些画刷的描述列于表 12.6：

**Table 12.6: Description of the Brushes**

| Brush | Description |
| --- | --- |
| SolidBrush | Fills the shape with one solid color |
| HatchBrush | Fills the shape with a hatch style |
| TextureBrush | Fills the shape with a pattern stored in a bitmap |
| LinearGradientBrush | Fills the shape with color that changes gradually as you move across the shape |
| PathGradientBrush | Fills the shape with color which changes as you move from the center of a shape towards the edge |

Brush 类的继承层次结构如下：

```
System.Object
  System.MarshalByRefObject
    System.Drawing.Brush
```

## Windows Forms 中的 Color 结构

> **NOTE**  
> You must note that when you inherit from the Brush class, you must override the Clone() method.

Windows Forms 中的颜色基于四个组件。这三个组件是三种原色红色、绿色和蓝色；以及 alpha 组件，用于定义颜色的透明度。Color 结构表示 Windows Forms 中的颜色。它包含在 System.Drawing 命名空间中。你可以使用 FromArgb 方法和通过静态属性的 Color 实例创建自定义颜色。Color 结构包含 140 个命名颜色，它们源自静态属性。你可以创建一个初始化为其中一个命名颜色的 Color 值，如以下代码片段所示：

```
Color newColor = Color.Red;
```

Windows Forms 中 Color 结构的注目方法列于表 12.8：

**Table 12.8: Methods of the Color Structure**

| Method | Description |
| --- | --- |
| Equals | Checks if the specified object is equivalent to the Color structure |
| FromArgb | Creates a Color structure from a 32-bit ARGB value |
| FromKnownColor | Creates a Color structure from the specified predefined color |
| FromName | Creates a Color structure from the specified name of a predefined color |
| GetBrightness | Retrieves the brightness value for the specified Color structure |
| GetHashCode | Returns a hash code for the specified Color structure |
