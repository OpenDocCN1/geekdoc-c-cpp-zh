The Choose Default Environment Settings dialog box provides you with a list of Visual Studio environmen Depending upon the type of applications that you need to create in this IDE, you can select the appropria environment.

Table 1.3 lists various environmental settings provided by Visual Studio 2010:

Table 1.3: Visual Studio 2010 Predefined IDE Settings

| Settings | Description |
|---|---|
| General Development Settings | Configure the environment that matches with the earlier versions of the application. You should select this setting if you have to perform development in more than one language. |
| Project Management Settings | Configure the environment with menus, windows, and help for working with team projects. This setting provides various features, such as tracking work items, running reports, viewing shared documents, and managing team project builds. |
| Visual Basic Development Settings | Configure the environment to develop Visual Basic applications. It provides various features, which includes window layout, command menus, and keyboard shortcuts of Visual Basic commands. |
| Visual C# Development Settings | Configure the environment to develop Visual C# applications. It also provides various features, which includes window layout, command menus, and keyboard shortcuts of Visual C# commands. |
| Visual C++ Development Settings | Configure the environment to develop native and managed C++ applications. It also provides Visual C++ 6 style keyboard shortcuts along with other basic features. |
| Visual F# Development Settings | Configure the environment to use the Code Editor window for developing F# applications using # commands and tool windows. |
| Web Development | Configures the environment for developing Web applications and websites using commands and options for Web development. |
| Web Development (Code Only) | Configures the environment for developing Web applications and websites using text editor space and hiding tool bars, tool windows, and other non-essential user interfaces. |
