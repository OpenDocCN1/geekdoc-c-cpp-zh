
## C# 2010 Programming Black Book

### Covers .NET 4.0

C# 2010 Programming Black Book is the most comprehensive book you will find on C#. It contains useful and in-depth information on all the conceptual foundations of C# 2010; and at the same time, teaches you how to implement each language concept programmatically, by providing most appropriate examples with full explanations. This edition of the book particularly deals with some new and advanced topics including WPF, WCF, WF, ASP.NET AJAX, Silverlight, and LINQ. This unique book on C# 2010 provides more coverage of C# than any other book; no doubt, every aspect of the book is worth its price.
