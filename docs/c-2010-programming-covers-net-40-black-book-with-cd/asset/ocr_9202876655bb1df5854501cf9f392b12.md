paginated FixedDocument content, such as XpsDocument. The DocumentViewer class provides properties such as CanDecreaseZoom and CanGoToNextPage, to search and zoom the text.

The inheritance hierarchy of the DocumentViewer class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.Primitives.DocumentViewerBase
                System.Windows.Controls.DocumentViewer
```

The following code snippet shows how to add the DocumentViewer control to a WPF application:

```
<DocumentViewer>
  <!-- Document -->
</DocumentViewer>
```

The properties of the DocumentViewer class are listed in Table 11.10:

# Table 11.10: Showign the Properties of the DocumentViewer Class

| Property | Description |
|---|---|
| CanDecreaseZoom | Retrieves a value that indicates whether the DocumentViewer control can decrease the zoom of the text or not |
| CanGoToNextPage | Retrieves a value that indicates whether or not the viewer can move to the next page in the current document |
| CanGoToPreviousPage | Retrieves a value that indicates whether or not the viewer can go back to the previous page in the current document |
| CanIncreaseZoom | Retrieves a value that indicates whether the DocumentViewer control can increase zoom level or not |
| CanMoveDown | Retrieves a value that indicates whether the DocumentViewer control can move further down in a document |
| CanMoveLeft | Retrieves a value that indicates whether the DocumentViewer control can move further left in a document |
| CanMoveRight | Retrieves a value that indicates whether the DocumentViewer control can move to the right in a document |
| CanMoveUp | Retrieves a value that indicates whether the DocumentViewer control can move further up in a document |
| Document | Gets or sets a source object that performs the actual moving through pages |
| ExtentHeight | Retrieves the overall vertical height of the paginated document |
| ExtentWidth | Retrieves the overall horizontal width of the paginated document |
| FitToHeightCommand | Retrieves the command to adjust the height of a control in a window |
| FitToMaxPageAcrossCommand | Retrieves the command that retrieves the value defining the maximum number of page columns to be displayed |
| FitToWidthCommand | Retrieves the command that adjusts a page according to the width of a window |
| LogicalChildren | Retrieves an enumerator for the child control in the logical tree of the document viewer |
| MasterPageNumber | Retrieves the page number of the current master page |
| MaxPagesAcross | Gets or sets a value defining the maximum number of page columns to be displayed |
