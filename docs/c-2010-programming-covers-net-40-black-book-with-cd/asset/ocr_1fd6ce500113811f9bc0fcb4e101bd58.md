# Support for Discovery Behaviors

WS-Discovery is an Organization for the Advancement of Structured Information Standards (OASIS), which is used to dynamically discover the location of the WCF service endpoints by defining SOAP-based protocol. SOAP allows clients to examine the WCF service endpoints based on certain criteria to retrieve a list of the suitable candidates offering WCF services. The client can then select an endpoint from the discovered list and use it as a current runtime location of the WCF service endpoints.

# Improved REST Service Development

WFC 4.0 provides new features for building the RESTful web services (now referred as WCF WebHttp services) using WCF. A RESTful web service is a service based on HTTP protocol and REST principles. The REST principles are defined by three categories with respect to a Web service. As per the REST principles, a service:

+   - Can be accessed with a simple URI
+   - Supports MIME types
+   - Uses different HTTP methods

With the use of MIME types, different data formats, such as JavaScript Object Notation (JSON) and Extensible Markup Langague (XML), can be returned from the WCF service.

The WCF WebHttp service includes the following features:

+   - Support for automatic help page – Helps a consumer to understand the RESTful web service
+   - Simplified HyperText Transfer Protocol (HTTP) caching – Allows you to cache the responses of messages from WCF Web HTTP service operations
+   - Message format selection – Allows services to handle or return the messages in either the XML or JSON format
+   - REST-friendly exceptions – Transmits HTTP errors back to consumers by using a new class, WebFaultException<T>
+   - New Visual Studio project templates – Allows you to implement new project, control, and tools into your Visual Studio 2010 applications by using Extension Manager.

# Support for the Integration of WCF with WF

WCF 4.0 integrates with WF, which allows you to build distributed service-oriented applications. With the help of this integration, the developers can extend the reach of their workflows by using them with WCF endpoints. This implies that you can create WCF services that can easily transfer and persist data in and out of a workflow.

# Instancing Model of WCF Services

Every WCF service has an instancing model that controls the number of instances of a WCF service that can run at a time. The instancing model of WCF service contains a set of techniques, which are used to bind messages to a WCF service instance. Instance management is required to develop scalable and consistent service-oriented applications because the applications widely differ in their requirement for scalability, performance, throughput, transactions, and queued calls. The instancing model of WCF services is a server-side implementation model that should not be visible on the client-side. To hide the details of instancing model from client-side, WCF has introduced the concept of behavior, which is a local attribute of a service that does not affect WCF communication pattern.
