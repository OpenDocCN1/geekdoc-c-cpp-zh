### 深入了解

Microsoft ActiveX Data Objects .NET (ADO.NET)，是 Microsoft .NET Framework 的一部分，允许您的应用程序轻松地与基于文件和基于服务器的数据源通信。ADO.NET 库在 .NET Framework 中出现在 System.Data 命名空间下。ADO.NET 最重要的用途是与数据通信并为 .NET Framework 提供数据访问服务。它提供对各种类型数据的访问，例如 XML、关系型和应用程序数据。除数据访问外，它还支持创建前端数据库客户端和中间层业务对象。

ADO.NET 为诸如 SQL、XML 以及通过对象链接和嵌入数据库 (OLE DB) 和开放数据库连接 (ODBC) 访问的数据源提供一致的访问。它还将数据访问与数据操作分离，并为连接到数据库、执行命令和检索结果提供单独的数据提供程序。

在本章中，您将学习使用 ADO.NET 进行数据访问。您还将熟悉数据库及其各种组件。此外，您将学习基本的 SQL 语句。您还将学习 ADO.NET 架构及其各种组件。最后，您将学习 ADO.NET 实体框架。

### 了解数据库

数据库简单来说是指结构化信息的集合。它以有组织和结构化的方式存储信息，以便在需要时进行检索。随着时间的推移，数据库变得更加复杂；然而，其基本概念仍然很简单。例如，假设您是一名教师，需要为每位学生分配成绩。您可能会在纸上制作一个表格并在该表格中输入学生的成绩，并将其命名为学生表。在这个例子中，您已经创建了一个数据库——更具体地说，是纸上的数据库表。现在，您可以在计算机上制作类似的表格，让您能够轻松地对任意大小的表格进行排序、索引、更新和组织。

记录的集合，即记录的行，其中每一列都是一个字段，就构成了表。在最常见的形式中，数据库只不过是一个或多个表的集合。然而，还有另一种类型的数据库——关系型数据库。它之所以被称为关系型数据库，是因为关系型数据库被设置成使多个表中的数据能够相互关联。要使表具有关系性，您需要选择某些字段作为主键和外键。

表中的主键通常是最重要的——您可以通过主键区分包含重复值的记录，因为主键不包含重复值。外键通常代表另一个表中的主键，这使您能够以有组织的方式访问该表。例如，您可能会在学生表中添加一个名为 StudentID 的字段。相同的字段 StudentID 可能是学校注册数据库表中所有学生的主键。在我们的表中，StudentID 字段就是外键，允许我们指定注册表中的单个记录。

您可以使用结构化查询语言 (SQL) 与数据库中的数据进行协作，SQL 已在本书后面部分详细定义。您使用 SQL 设置查询，该查询应用于数据库时，通常会返回与您的 SQL 查询匹配的记录 DataSet。例如，您可以设置一个查询来获取所有获得 B 级或更好成绩的学生信息。您可以使用 SQL 执行诸如插入新记录、创建新表和获取 DataSet 等操作。

因此，您可以使用 SQL 过滤掉不需要的记录，然后对其进行操作。Visual C# 具有内置工具（查询生成器），允许您以可视方式创建 SQL 语句。

### 了解 SQL

SQL 是一种用于查询和修改数据以及管理数据库的标准交互式和编程语言。它旨在检索和管理关系数据库管理系统 (RDBMS) 中的数据、创建和修改数据库模式以及管理数据库对象控制。

我们学习使用一个包含名为 Customers 的表的数据库，该表保存客户 ID、地址和其他字段，以及一个名为 Orders 的表，该表保存客户订单的字段。这些表基于 Northwind 数据库。

让我们在下一节学习 SQL 的基础知识。

### SELECT 语句

您可以使用 SELECT 语句从表中获取字段。以下示例使用通配符字符 `*` 检索 Customers 表中的所有记录：

```
SELECT * FROM Customers
```

前面的示例返回一个 DataSet，其中包含 Customers 表中的所有记录。您还可以使用 SELECT 语句从表中选择特定字段，如以下示例所示：

```
SELECT CustomerID, Address, City FROM Customers
```

在前面的示例中，您可以从 Customers 表中检索 CustomerID、Address 和 City 字段。前面的示例返回一个 DataSet，其中包含 Customers 表中的所有记录，每个记录都有 CustomerID、Address 和 City 字段。

### WHERE 子句

在 SQL 中，您可以使用 WHERE 子句指定希望所有记录满足的标准。例如，要选择 Customers 表中 City 字段为 London 的所有记录，您可以执行以下语句：

```
SELECT * FROM Customers WHERE City = 'London'
```

WHERE 子句中可使用的其他运算符如下：

- `<`（小于）
- `<=`（小于或等于）
- `>`（大于）
- `>=`（大于或等于）
- `BETWEEN`
- `IN`
- `LIKE`

### LIKE 子句

在 SQL 中，LIKE 子句允许您使用通配符指定部分字符串。您可以从 Customers 表中选择 City 字段匹配通配符字符串 `Lo%` 的所有记录。这在以下 SQL 查询语句中显示：

```
SELECT * FROM Customers WHERE City LIKE 'Lo%'
```

前面的示例创建一个 DataSet，其中仅包含 City 字段包含以 Lo 开头的名称的记录，例如 Los Angeles 或 London。使用 `%` 通配符字符的三种可能组合如下：

- `Lo%` — 返回所有以 Lo 开头的项目，例如 London 或 Los Angeles。
- `%Lo` — 返回所有以 Lo 结尾的项目，例如 São Paulo。
- `%Lo%` — 返回字段值中任何位置包含 Lo 的所有项目，例如 Barcelona。

### DISTINCT 子句

有时数据库中表的字段可能包含重复值。例如，多个客户来自同一个城市，因此 City 字段的值相同。您可能希望查看所有代表的城市，而不重复。您可以使用 DISTINCT 子句避免重复，如以下 SQL 查询语句所示：

```
SELECT DISTINCT City FROM Customers
```

### 逻辑运算符

逻辑运算符用于在需要根据某些逻辑条件从数据库中检索记录时使用。让我们举一个例子，假设您只想检索城市既不是 Boston 也不是 York，并且 Fax 字段具有某些值（我们使用 IS NOT NULL 关键字来检查 Fax 字段是否包含任何值）的记录。可以使用以下语句检索所需的记录：

```
SELECT * FROM Customers WHERE City NOT IN ('Boston', 'York') AND Fax IS NOT NULL
```

您可以使用这些逻辑运算符连接 AND、OR 和 NOT 子句。使用 AND 表示两个子句都必须为真，使用 OR 表示其中任一可以为真，使用 NOT 将子句的值从真翻转为假，或从假翻转为真。

### ORDER BY 子句

您可以使用 SQL 语句对 DataSet 中的记录进行排序。您可以按 CustomerID 对 Customers 表的记录进行排序，如以下示例所示：

```
SELECT * FROM Customers ORDER BY CustomerID
```

您还可以使用 Desc 关键字按降序对记录进行排序：

```
SELECT * FROM Customers ORDER BY CustomerID Desc
```

> NOTE
> 如果您没有在 ORDER BY 子句中提供 Desc 关键字，它将默认按升序返回结果。

### GROUP BY 子句

SQL 的 GROUP BY 子句用于根据表的字段对某些记录进行分组。您可以使用 GROUP BY 子句按如下所示的 SQL 查询语句对记录进行分组：

```
SELECT OrderID, SUM(Quantity) FROM OrderDetails GROUP BY OrderID
```

在前面的示例中，我们按 OrderID 对它们进行分组。

### DELETE 语句

SQL 中的 DELETE 语句用于从表中删除记录。您可以使用 WHERE 子句与 DELETE 语句一起根据某些条件删除记录，如以下 SQL 查询语句所示：

```
DELETE FROM Customers WHERE City NOT IN ('Boston', 'York')
```

在前面的示例中，我们正在删除 Customers 表中 City 字段不包含值 Boston 或 York 的记录。

### UPDATE 语句

您可以使用 UPDATE 语句更新数据库。虽然 Visual C# 自动更新数据库，但值得注意的是，您也可以使用 SQL 更新数据库。这在以下 SQL 查询语句中显示：

```
UPDATE Customers SET City = 'Boston' WHERE City = 'York'
```

在前面的示例中，我们将所有当前城市为 York 的记录的城市更改为 Boston。

### 连接表

您可以使用 SQL 将数据库中的两个或多个表连接起来。例如，您可以处理关系型数据库。现在，您希望使用 Customers 表中的客户联系人姓名和 Orders 表中他们订购的商品 ID 创建一个新的 DataSet。关联这两个表的字段是 CustomerID，因此您可以按如下代码片段所示设置 SQL 查询：

```
SELECT Customers.ContactName, Orders.OrderID FROM Customers, Orders WHERE Customers.CustomerID = Orders.CustomerID
```

前面的代码片段确保您连接的每条记录中的 CustomerID 字段都匹配。您还可以执行内部连接，其中记录必须同时存在于两个表中，或外部连接，其中记录可以存在于任一表中。
