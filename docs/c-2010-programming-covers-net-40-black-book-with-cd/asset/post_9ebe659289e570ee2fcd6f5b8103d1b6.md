## Returning a Value from a Method

A method can return a value to the caller of the method. If the return type is void, then the method will not return any value. However, if the return type is other than void, such as int, double, or string, then the method can return a value using the return keyword. A statement with the return keyword compares the return type of the method with the return value and if they match, it returns a value to the caller method. To see how to accept the value returned by a method, first create a new Console application, named MyReturnValue (also available in the CD). Then replace the default code of the Program.cs file of the application with the code shown in Listing 4.12:

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyReturnValue
{
    class Program {
        static void Main(string[] args)
        {
            MyArea myarea = new MyArea();
            myarea.RectArea();
            Console.Write("\nPress ENTER to Quit..");
            Console.ReadLine();
        }
    }
    class MyArea {
        public double RectArea()
        {
            double Length, Breadth, RectangleArea;
            Console.Write("Enter the Length of Rectangle:");
            Length = double.Parse(Console.ReadLine());
            Console.Write("Enter the Breadth of Rectangle:");
            Breadth = double.Parse(Console.ReadLine());
            RectangleArea = Length * Breadth;
            Console.WriteLine("The Area of Rectangle is " + RectangleArea);
            return (RectangleArea);
        }
    }
}
```

In Listing 4.12, note that the return type of the RectArea method and the data type of the RectangleArea variable are the same (double). Therefore, the method returns a value of type double to the caller method.

## Creating a Partial Method

Partial methods are only allowed in partial types, such as classes and structs. A partial method consists of two parts. One part deals with defining the partial method and the other deals with implementing the partial method declaration. In case of partial methods, there can be at the most one defining declaration and one implementing declaration. A partial method must have a void return type. No access modifiers are allowed for declaring a partial method except for unsafe and static. Partial methods are private by default. To see how to create a partial method except for unsafe and static.

partial method, first create a new Console application, named MyPartialMethod (also available in the CD) by performing the steps given in the section, Creating a Namespace. Then replace the default code of the Program.cs file of the application with the code shown in Listing 4.13:

### Listing 4.13: Showing the Code of the MyPartialMethod Application

```csharp

using System.Collections.Generic;
using System.Linq;
using System.Text;

{
    class Program {
        static void Main(string[] args)
        {
            Account Acc = new Account();
            Acc.CalculateInterest();
            Acc.ShowInterest();
        }
    }
    partial class Account
    {
        double PrincipalAmount, InterestRate, Time, SimpleInterest;
        public void CalculateInterest()
        {
            Console.Write("Enter Principal Amount (P):");
            PrincipalAmount = double.Parse(Console.ReadLine());
            Console.Write("Enter Interest Rate (R):");
            InterestRate = double.Parse(Console.ReadLine());
            Console.Write("Enter Time Duration (T):");
            Time = double.Parse(Console.ReadLine());
        }
        partial void ShowAmount();
    }
    partial class Account
    {

        {
            double amount = PrincipalAmount + SimpleInterest;

        {
            SimpleInterest = (PrincipalAmount * InterestRate * Time) / 100;
            Console.WriteLine("SimpleInterest: " + SimpleInterest);
```
