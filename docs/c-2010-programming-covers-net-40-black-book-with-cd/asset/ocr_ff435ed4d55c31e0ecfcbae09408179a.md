+   - **Management Classes** – Enables the developers to browse and modify Windows Management Instrumentation (WMI) data and call methods
+   - **Management Events** – Enables the developers to register for WMI events
+   - **Message Queues** – Lists the message queues along with the messages that each queue contains on the selected server.
+   - **Performance Counters** – Lists the performance counters on the Microsoft Windows 2003 server Microsoft Windows 2000 server, or Windows NT version 4.0
+   - **Services** – Lists the services that exists on the selected Windows 2000 or Windows NT 4.0 server
+   - SharePoint Connections – Enables you to connect local SharePoint sites from the computer where applications are developed

The toolbar of Server Explorer contains the following buttons:

+   - Refresh – Refreshes Server Explorer and shows a list of the recently connected servers. If a particular server or its services have stopped, then its name is not reflected in Server Explorer.
+   - Stop Refresh – Allows you to stop the refresh process.
+   - Connect to Database – Enables developers to establish a connection to a database listed in Server Explorer through code.
+   - Connect to Server – Enables developers to connect to a running server process listed in Server Explorer.
+   - Add to SharePoint Connections – Adds a SharePoint connection from the computer where applications are developed.
