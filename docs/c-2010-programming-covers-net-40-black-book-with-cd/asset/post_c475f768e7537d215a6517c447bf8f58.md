## Using the Calendar and DatePicker Controls

As already discussed in the *In Depth* section of this chapter, you can select a date by using either of the Calendar or DatePicker control. Let’s now create a WPF application, named Calendar_and_DatePicker (available in the CD), to learn how to use the Calendar and DatePicker controls. To do this, add the code, shown in Listing 10.1, in the MainWindow.xaml file of the Calendar_and_DatePicker application:

```
Listing 10.1: Using the Calendar and DatePicker Control

```xml
<Window x:Class="Calendar_and_DatePicker.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="MainWindow" Height="350" Width="525">
    <Grid>
        <Calendar Height="170" HorizontalAlignment="Left" Margin="12,65,0,0"
                  Name="calendar1" VerticalAlignment="Top" Width="180"
                  SelectionMode="MultipleRange">
            <Calendar.BlackoutDates>
                <CalendarDateRange Start="5/1/2010" End="5/10/2010"/>
            </Calendar.BlackoutDates>
        </Calendar>
        <DatePicker Height="25" HorizontalAlignment="Left" Margin="240,65,0,0"
                    Name="datePicker1" VerticalAlignment="Top" Width="243" FirstDayOfWeek="Monday"
                    SelectedDateFormat="Long" />
        <Label Content="Calendar" Height="28" HorizontalAlignment="Left"
               Margin="73,12,0,0" Name="label1" VerticalAlignment="Top" FontWeight="Bold"
               FontStyle="Italic" />
        <Label Content="DatePicker" Height="28" HorizontalAlignment="Left"
               Margin="334,12,0,0" Name="label2" VerticalAlignment="Top" FontWeight="Bold"
               FontStyle="Italic" />
    </Grid>
</Window>
```
```

In Listing 10.1, we have added a Calendar control, in which we have specified a range of date that a user cannot select and changed the selection mode of the Calendar control to MultipleRange, which allows the user to select multiple ranges of date. ## Adding Controls through the XAML Code

You can add controls to a WPF application either through the XAML code or code-behind file. Let’s now learn to add some common controls to a WPF application through the XAML code. Create a WPF application named AddingControls_XAML (available in the CD) and add the code to the MainWindow.xaml file, as shown in Listing 10.2:

Listing 10.2: Implementing Controls through XAML Code

```
<Window x:Class="AddingControls_XAML.MainWindow"
xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
Title="MainWindow" Height="300" Width="300">
    <Grid>
        <Grid.RowDefinitions>
            <RowDefinition Height="29"/>
            <RowDefinition Height="27"/>
            <RowDefinition Height="71"/>
            <RowDefinition Height="135" />
        </Grid.RowDefinitions>
        <Grid.ColumnDefinitions>
            <ColumnDefinition Width="141"/>
            <ColumnDefinition Width="137" />
        </Grid.ColumnDefinitions>
        <Label FontSize="15">
            Login ID:
        </Label>
        <TextBox HorizontalAlignment="Right" Margin="0,0,-128,0" Name="Login" Width="128" />
        <Label FontSize="15" Grid.Row="1">
            Password:
        </Label>
        <TextBox Grid.Row="1" HorizontalAlignment="Right" Margin="0,0,-128,0" Name="Password" Width="128"></TextBox>
        <Button Margin="12,10,18,29" Name="Submit" Grid.Row="2">Submit</Button>
        <Button Grid.Row="2" Margin="14,10,21,29" Name="Clear" Grid.Column="1">Clear</Button>
    </Grid>
</Window>
```

In Listing 10.2, two Label controls, a TextBox control, and a Button control, are added to the window. You can run the application by pressing the F5 key.
