# Using a Message Box

As stated in the In Depth section, message boxes are suitable to display some information or confirm a particular action in WPF applications. Let’s create a standalone WPF application named DeleteItemConfirm (also available on the CD) by performing the following steps:

+   1. Create a new WPF Application, DeleteItemConfirm.

+   2. Add the following code snippet in the Grid element of the MainWindow.xaml file:

```
<Button Height="23" Margin="92,0,112,41" Name="DeleteButton" VerticalAlignment="Bottom" Click="DeleteButton_Click">Delete</Button>
```

A button is added to the Grid element, as shown in Figure 9.43:

+   3. Double-click the DeleteButton button in the Design view. The code-behind file, MainWindow.xaml.cs, of the DeleteItemConfirm application opens. In addition, the handler for the Click event of the DeleteButton button is included in the MainWindow class of the code-behind file. In the event handler, that is, the DeleteButton_Click() method, add the following code snippet:

```
MessageBoxResult myResult = MessageBox.Show("Are you sure you want to delete this item?", "Delete Item", MessageBoxButton.YesNo, MessageBoxImage.Question);
if (myResult.ToString() == "Yes")
    MessageBox.Show("Item deleted.");
```

In the preceding code snippet, you can see that an instance named myResult of the MessageBoxResult class is created. The myResult object holds the result of the user action, that is, the button that a user clicks. The message box is displayed to users by calling the Show() method of the MessageBox class. In this case, the Show() method takes four arguments. The first argument is the only mandatory argument and it refers to the textual message that appears in front of the users.
