# The ORDER BY Clause

You can order the records in the DataSet by using an SQL statement. You can order the records of the Customers table by CustomerID, as shown in the following example:

```
SELECT * FROM Customers ORDER BY CustomerID
```

You can also sort the records in descending order using the Desc keyword:

```
SELECT * FROM Customers ORDER BY CustomerID Desc
```

> NOTE
> If you are not providing the Desc keyword with the ORDER BY clause, it will, by default, return results in ascending order.

# The GROUP BY Clause

The GROUP BY clause of SQL is used to group some records according to the fields of the table. You can group records in SQL with the GROUP BY clause as shown in the following SQL query statement:

```
SELECT OrderID, SUM(Quantity) FROM OrderDetails GROUP BY OrderID
```

In the preceding example, we are grouping them by OrderID.

# The DELETE Statement

The DELETE statement in SQL is used to delete the records from a table. You can use the WHERE clause with the DELETE statement to delete the records on the basis of some conditions as shown in the following SQL query statement:

```
DELETE FROM Customers WHERE City NOT IN ('Boston', 'York')
```

In the preceding example, we are deleting the records from the Customers table whose City field does not contain the value Boston or York.

# The UPDATE Statement

You can use the UPDATE statement to update a database. Although Visual C# automatically updates databases, it is worth noting that you can also use SQL to update databases. This is shown in the following SQL query statement:

```
UPDATE Customers SET City = 'Boston' WHERE City = 'York'
```

In the preceding example, we are changing the City to Boston in all records where it is York at present.

# Joining Tables

You can join two or more tables in a database with SQL. For example, you can work with relational databases. Now, you want to create a new DataSet with customer contact names from the Customers table and the IDs of the items they have ordered from the Orders table. The field that relates these two tables is CustomerID, so you can set up the SQL query as shown in the following code snippet:

```
SELECT Customers.ContactName, Orders.OrderID FROM
Customers, Orders WHERE Customers.CustomerID =
Orders.CustomerID
```

The preceding code snippet ensures that the CustomerID field matches in each record you are joining.
You can also do inner joins, where records must be in both tables, or outer joins, where records can be in either table.
