Anonymous authentication needs to be enabled to allow any user to access the Default.aspx page of the AnonymousAuth website. The Anonymous authentication is already enabled in IIS, you only need to enable it in the ASP.NET application.

+   3. Open the web.config file of the application and change the settings of the <authentication> element, as given in the following code:
+   <authentication mode="None" />

With this setting of the mode attribute of the <authentication> element, users are treated anonymously in IIS as well as in the application.
