# Calling a Web Service from the Client

We can also call a Web service with the help of script files from clients. Perform the following steps to do so:

+   1. Open Visual Studio 2010 and create a Web application named `CallingWebService` (also available on the CD).
+   
+   2. After creating the Web application, add the code, shown in Listing 18.20, in the Default.aspx page of the CallingWebService Web application:

```
Listing 18.20: Code for the Default.aspx Page

```aspx
<%@ Page Language="C#" AutoEventWireup="true" CodeFile="Default.aspx.cs" Inherits="_Default" %>
<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">
<html xmlns="http://www.w3.org/1999/xhtml">
<head runat="server">
    <title></title>
</head>
<body>
    <form id="form1" runat="server">
        <div>
            <asp:ScriptManager runat="server" ID="ScriptManager1">
                <Services>
                    <asp:ServiceReference Path="~/WebService.asmx" />
                </Services>
                <Scripts>
                    <asp:ScriptReference Path="~/CallingWebService.js" />
                </Scripts>
            </asp:ScriptManager>
            <button id="btnMultiply" onclick="Multiply(2, 5); return false;">Multiply</button>
            <br />
            <br />
            <asp:Label ID="lblResult" runat="server" Text="Result"></asp:Label>
        </div>
    </form>
</body>
</html>
```
```

+   3. Create a Web service by right-clicking the name of the Web application in Solution Explorer and selecting the Add New Item option from the context menu to display the Add New Item dialog box.
+   
+   4. Select the Web Service template in the Add New Item dialog box and click the Add button. Doing this adds a Web service named WebService in the CallingWebService Web application.
+   
+   5. Add the code, shown in Listing 18.21, in the code-behind file of the WebService Web service:

```
Listing 18.21: Code for the Code-Behind File of the WebService Web Service

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Web;
using System.Web.Services;

/// <summary>
/// Summary description for WebService
/// </summary>
[WebService(Namespace = "WebService")]
[WebServiceBinding(ConformsTo = WsiProfiles.BasicProfile1_1)]
// To allow this Web Service to be called from script, using ASP.NET AJAX, uncomment the
// following line.
[System.Web.Script.Services.ScriptService]
```
