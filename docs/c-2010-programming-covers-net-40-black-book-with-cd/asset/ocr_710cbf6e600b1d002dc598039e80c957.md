# Properties Window

The Properties window in the WPF 4.0 Designer allows you to view and work with the properties of controls that are present in the Design view. In the Properties window, the names of the properties are listed on the left side, while the values of the properties are listed on the right side. At the very top of the Properties window in WPF Designer, you can see the class name, control name, and thumbnail image of the selected control.
