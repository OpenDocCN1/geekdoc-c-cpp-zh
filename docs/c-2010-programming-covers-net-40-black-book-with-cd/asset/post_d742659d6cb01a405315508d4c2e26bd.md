
## Using a Method with Parameters

Parameters provide a means of passing values to a method. In C#, you can pass a parameter to a method in four different ways: by value, using the ref keyword, using the out keyword, and using the params keyword. A parameter declared without any modifier is a value parameter. Now, create a new Console application, named MyMethodParameters (also available in the CD). Replace the default code of the Program.cs file of the application with the code shown in Listing 4.8:

### Listing 4.8: Showing the Code of the MyMethodParameters Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyMethodParameters
{
    class Program
    {
        static void Main(string[] args)
        {
            Amount Amt = new Amount();
            Amt.Balance(12000, 2000);
            Amt.GetData();
            Console.Write("\nPress ENTER to quit..");
            Console.ReadLine();
        }
    }
    public class Amount
    {
        double BalanceAmount;
        public void Balance(double TotalAmount, double Deductions)
        {
            BalanceAmount = TotalAmount - Deductions;
            Console.WriteLine("Your Current Amount is Rs: " + BalanceAmount);
        }
        public void Debit()
        {
            int DebitAmount = 0;
            Console.Write("Enter Amount:");
            DebitAmount = int.Parse(Console.ReadLine());
            BalanceAmount = BalanceAmount - DebitAmount;
            Console.WriteLine("Your Balance Amount is Rs.:" + BalanceAmount);
        }
        public void Credit()
        {
            int CreditAmount = 0;
            Console.Write("Enter Amount:");
            CreditAmount = int.Parse(Console.ReadLine());
            BalanceAmount = BalanceAmount + CreditAmount;
            Console.WriteLine("Your Balance Amount is Rs.:" + BalanceAmount);
        }
        public void GetData()
        {
            char Data;
            Console.WriteLine("----------------------------------------");
            Console.Write("Press (d) for Debit and (c) for Credit:");
            Data = char.Parse(Console.ReadLine());
            if (Data == 'd')
            {
                Debit();
            }
            if (Data == 'c')
            {
                Credit();
            }
        }
    }
}
```

In Listing 4.8, the Balance method of the Amount class has two parameters, TotalAmount and Deductions. These parameters are of double type and are assigned the values 12000 and 2000, respectively.

## Using a Method with Arguments

In C#, the params keyword allows you to specify a method parameter that takes a variable number of arguments. The params keyword has to occupy the last position in the method's list of formal arguments. Now, create a new Console application, named MyVariableArguments (also available in the CD) and replace the default code of the Program.cs file of the application with the code shown in Listing 4.9:

### Listing 4.9: Showing the Code of the MyVariableArguments Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyVariableArguments
{
    class Program
    {
        public static int GetSum(params int[] numbers)
        {
            int sum = 0;
            foreach (int num in numbers)
                sum += num;
            return sum;
        }
        public static void Main(string[] args)
        {
            Console.WriteLine("The Sum is:");
            Console.WriteLine(GetSum(1, 2, 3, 4, 5, 6, 7, 8, 9));
            Console.WriteLine(GetSum(2, 4, 6, 8));
            Console.WriteLine("\nPress ENTER to quit..");
            Console.ReadLine();
        }
    }
}
```

Listing 4.9 contains a method, GetSum, which takes variable number of arguments and prints their sum. Figure 4.11 shows the output of the MyVariableArguments application:

## Passing a Reference Argument to a Method

An important aspect in C++ as compared to Java is its ability to return multiple values from a given function or method. In Java, a function returns only a single value of a specific type. Parameters passed into a method of Java class are one-way only for simple types. You cannot pass an integer, for example, and have it modified by the method. C++, on the other hand, allows you to use two different methods for passing a variable by referencing it into a method or function. You can pass the address of a variable and treat it as a pointer in the method or function, or you can accept a reference to a variable and modify it in the method or function.

The following code snippet shows how to pass a reference argument:

```
int PassByPointer( int* x ) {
    *x = 3; }
int main(void) {
    int x = 10;
    PassByPointer(&x);
    // x is now 3 }
```

Alternatively, you can also pass a reference argument, as shown in the following code snippet:

```
int PassByReference( int& x ) {
    x = 3; }
int main(void) {
    int x = 10;
    PassByReference(x);
    // x is now 3 }
```

The problem with both these approaches is that they can abruptly hang a program. In the first approach, you need to pass a NULL pointer. Dereferencing the pointer can crash the program. Moreover, in both the approaches, the data is being modified inside the calling methods. This can lead to obscure errors, which are difficult to track down.

C# solves both these problems by providing the ref keyword. To pass a reference type parameter to a method you need to declare the method with the ref keyword. In addition, you must pass a variable in a method and specify that you are sending it by reference. In this way, both the developer of the method and the programmer using the method are protected. You cannot pass a NULL reference. Attempting to pass NULL to a reference argument results in a compile-time error. Now, create a new Console application, named MyReferenceArgument (also available in the CD) and replace the default code of the Program.cs file of the application with the code shown in Listing 4.10:

### Listing 4.10: Showing the Code of the MyReferenceArgument Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace MyReferenceArgument
{
    class Program
    {
        static void Main(string[] args)
        {
            int x = 10;
            Console.WriteLine("Before calling non-ref function, x = {0}", x);
            NonRefFunction(x);
            Console.WriteLine("\nAfter calling non-ref function, x = {0}", x);
            RefFunction(ref x);
            Console.WriteLine("\nAfter calling ref function, x = {0}", x);
            Console.Write("\nPress ENTER to quit.");
            Console.ReadLine();
        }

        static void NonRefFunction(int x)
        {
            Console.WriteLine("Top of NonRefFunction. X = {0}", x);
            x = x + 10;
            Console.WriteLine("Bottom of NonRefFunction. X = {0}", x);
        }

        static void RefFunction(ref int x)
        {
            Console.WriteLine("Top of RefFunction. X = {0}", x);
            x = x + 10;
            Console.WriteLine("Bottom of RefFunction. X = {0}", x);
        }
    }
}
```

In Listing 4.10, two code lines are highlighted. The first highlighted code line is the declaration of the NonRefFunction method, which accepts a value parameter, as shown in following code snippet:

```

{
    Console.WriteLine("Top of NonRefFunction. X = {0}", x);
    x = x + 10;
    Console.WriteLine("Bottom of NonRefFunction. X = {0}", x);
}
```

The second highlighted line is the declaration of the RefFunction method, which accepts a reference parameter, as shown in following code snippet:

```
static void RefFunction(ref int x)
{
    Console.WriteLine("Top of RefFunction. X = {0}", x);
    x = x + 10;
    Console.WriteLine("Bottom of RefFunction. X = {0}", x);
}
```
