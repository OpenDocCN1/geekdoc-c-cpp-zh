# Creating the TreeView Control

The TreeView control can be easily created in Visual Studio 2010 (VS 2010). For this, simply drag and drop the control onto the Web page. The TreeView control is available under the Navigation tab in the Toolbox of VS 2010.

> NOTE
> The applications in this chapter are created using the ASP.NET Empty Web Site template in the New Web Site dialog box. After creating the application, you need to add the Default.aspx page to the application.

We have used the TreeView control in the TreeViewControlCS example on the CD-ROM, as discussed in the In Depth section of this chapter. You can find the code for the Default.aspx page in Listing 15.1:

# Listing 15.1: Showing the Code for the Default.aspx Page

