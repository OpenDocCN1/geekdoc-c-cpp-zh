The CreateUserWizard control has a default collection of steps to gather user information. You can also add additional steps to the Wizard in order to collect additional user information. The following are some of the important components used to create steps of the CreateUserWizard control:

+   - CreateUserWizardStep – Contains the user interface and the logic for creating a new user. This is a pre-defined step.
+   - CompleteWizardStep – Displays the information whenever a user account is created successfully. This is a pre-defined step.
+   - Collection of WizardSteps – Refers to the collection of all the user-defined steps that are displayed during the process of creating a user. Only one step is displayed at a given time.
+   - Navigation Buttons – Allow users to go to the next and the previous steps in the CreateUserWizard control.
+   - SideBar – Lists all the WizardSteps steps; thereby, enabling users to randomly access any of the WizardSteps steps. This is an optional component.
+   - Header – Provides users with the information regarding each step. It is present at the top of the wizard. This is also an optional component.

You can simply drag-and-drop this control from the Toolbox to add it on a Web page.
