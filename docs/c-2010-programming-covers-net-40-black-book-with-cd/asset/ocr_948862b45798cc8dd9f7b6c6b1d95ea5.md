# Creating an Alias

You must have probably noticed by now that C# uses namespaces to logically arrange classes, structs, interfaces, enums, and delegates. The convention for these namespaces, such as System.Collections.Generic is to use a higher level, such as System, followed by one or more sublevels that define where the actual class is declared. This process can result in very long names and may require you to find if these names conflict with other general names that are already present at the sublevels. To avoid such problems, you can create alias and use it in your applications. After defining an alias for the long namespace string, you can then refer to that long string by the simple alias name. This makes dealing with complex namespaces much easier.
