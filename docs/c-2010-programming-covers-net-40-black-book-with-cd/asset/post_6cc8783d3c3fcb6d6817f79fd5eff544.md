## The TextBlock Control

The TextBlock control in WPF is responsible for providing flexible text support for applications. A TextBlock control is usually used with documents in WPF. The major properties of the TextBlock control are related to text and the presentation of text. You can add text content to a TextBlock control using the Text property.

The inheritance hierarchy of the TextBlock control is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.TextBlock
```

You can add the TextBlock control to a WPF application by using the following code snippet:

```
<TextBlock>
  <!--Inlines -->
</TextBlock>
```

## The ViewBox Control

The ViewBox control in WPF represents a content decorator that can stretch and scale a single child element to fill the available space in the ViewBox control of a WPF application. The ViewBox control can have only one child element. Adding more than one child element in the ViewBox control can cause the application to throw an ArgumentException exception at run time.

The inheritance hierarchy of the ViewBox class is as follows:

## The AccessText Control

The AccessText control represents an underscore that is used as an access key. For example, in the CTRL+C, C is the access key. If your text has multiple underscores, only the first one is converted into access key and the other underscores appear as normal text. You can use the AccessText control as a content host in a control style by setting the RecognizeAccessKey property in the ContentPresenter control.

## The VirtualizingStackPanel Control

In WPF, you can apply data binding to container controls. You can use the VirtualizingStackPanel control when you are binding items to the StackPanel control and there is not enough space to display all the items. The control arranges the content on a single line, horizontally or vertically. You can use the VirtualizingStackPanel control only when the items are data bound. If the items are not data bound, the control offers no advantage over a StackPanel control. The default value of the IsVirtualizing property of the VirtualizingStackPanel control is set to True. If the property is set to False, the control behaves similar to a normal StackPanel control.

The inheritance hierarchy of the VirtualizingStackPanel class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Panel
              System.Windows.Controls.VirtualizingPanel
                System.Windows.Controls.VirtualizingStackPanel
```

You can add a VirtualizingStackPanel control to a WPF application by using the following code snippet:

```
<VirtualizingStackPanel>
<!--Child elements -->
</VirtualizingStackPanel>
```

### Table 10.49: Noteworthy Properties of the VirtualizingStackPanel Class

| Property | Description |
|---|---|
| CanHorizontallyScroll | Retrieves or specifies a value that indicates whether a VirtualizingStackPanel can scroll in the horizontal dimension |
| CanVerticallyScroll | Retrieves or specifies a value that indicates whether content can scroll in the vertical direction |
| ExtentHeight | Retrieves a value that contains the vertical size of the extent |
| ExtentWidth | Retrieves a value that contains the horizontal size of the extent |
| HorizontalOffset | Retrieves a value that contains the horizontal offset of the scrolled content |
| ScrollOwner | Retrieves or specifies a value that identifies the container that controls the scrolling behavior in a VirtualizingStackPanel control |

The VirtualizingStackPanel control cannot be added from the Toolbox. You have to add this control in the application through the XAML code.

## The Calendar Control

The Calendar control of WPF is similar to the Calendar control of Windows Forms. This control allows you to select a date as well as to fire an event on the selection of the date. You can display the selected date on another control or validate the selected date. You can also customize the appearance of the Calendar control with the help of its Style property. The Calendar control also helps you to perform various tasks, such as specify the range of the date that is to be displayed by the Calendar control, select a specific range of date or multiple dates, and disable the selection of specific dates.

The inheritance hierarchy of the Calendar class is as follows:

```
System.Object
System.Windows.Threading.DispatcherObject
System.Windows.DependencyObject
System.Windows.Media.Visual
System.Windows.UIElement
System.Windows.FrameworkElement
System.Windows.Controls.Control
System.Windows.Controls.Calendar
```

You can add a Calendar control to a WPF application by using the following code snippet:

```
<sdk:Calendar .../>
```

| Property | Description |
|---|---|
| BlackoutDates | Retrieves a collection of dates that you do not want the user to select |
| DisplayDate | Retrieves or specifies the date to display on the Calendar control |
