# Basic IDE Operations

Microsoft has introduced various developmental tools in the IDE of Visual Studio 2010. In this section, you learn about the following basic operations that could be performed in the IDE of Visual Studio 2010:

+   - Creating a new Windows application
+   - Saving code on the Toolbox
+   - Docking the windows
+   - Switching between the windows
+   - Specifying the .NET Framework Version for Projects
+   - Changing the IDE font and color
+   - Building and debugging the projects

Let’s now discuss each of these operations in detail.

# Creating a New Windows Application

Perform the following steps to create a new Windows application:

+   1. Click Start → All Programs → Microsoft Visual Studio 2010 → Microsoft Visual Studio 2010. The Visual Studio 2010 IDE opens.
+   2. Click the New Project link on Start Page or select File → New → Project. The New Project dialog box appears (Figure 1.74).
+   3. Select Visual C# → Windows option from the Installed Templates pane and then select Windows Forms Application template from the middle pane. Enter a name, for instance FirstWindowsApplication in the Name text box.
