## 安全注意事项

在受信任的程序集允许部分受信任的调用方、发出链接请求或断言权限的情况下，安全性很可能会受到损害。任何恶意代码（在大多数情况下为不受信任的代码）都可能利用此类程序集来访问受保护的资源。只有在绝对必要时，才应使用免除限制的指令。为防止此类问题，应在程序集中实施其他检查，以确保能够检测和防范。

例如，可以使用强名称身份检查来标识调用方应用程序。在这种情况下，即使程序集断言了权限、允许部分受信任的调用方或对某个特定权限发出链接请求，也只有被标识的调用方才能使用该程序集。

假设您希望某个程序集的特定函数只能由具有某个强名称的应用程序调用，则可以在该函数上放置对该强名称身份的链接请求。例如，在 `FileAccessLib` 程序集中，您可以对强名称身份放置一个链接请求，该请求将标识直接调用方，并仅允许具有公司强名称的调用方访问，如下所示：

