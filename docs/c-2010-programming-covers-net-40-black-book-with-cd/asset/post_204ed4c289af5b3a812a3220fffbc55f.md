## The ComboBox Control

The difference between the two is that the ComboBox control has an additional Button control to display an item only if the control is clicked. The list is displayed or is hidden as the Button control expands and collapses. In its default state, the list is collapsed and shows only one item.

## The TreeView Control

The TreeView control in WPF is used to display items in a hierarchical manner. This control lists the items using the TreeViewItem control. Therefore, the TreeView control consists of a hierarchy of TreeViewItem controls. You can expand or collapse the TreeViewItem control by setting the IsExpanded property to True or False, respectively. When a user selects the TreeViewItem control, the Selected event occurs and the IsSelected property is set to True. When the user deselects the TreeViewItem control, the UnSelected event occurs and the IsSelected property is set to False. You cannot explicitly set the SelectedItem property, as it is a read-only property. You can use the SelectedValue and SelectedPathValue properties to assign a value to the SelectedItem property. The default view of the TreeView control places the control inside a StackPanel container control and adds a ScrollViewer control to it.

The inheritance hierarchy of the TreeView class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.ItemsControl
                System.Windows.Controls.TreeView
```

You can add the TreeView control to a WPF application by using the following code snippet:

```
<TreeView>
  <!-- Items -->
</TreeView>
```

## The TabControl Control

The TabControl control in WPF is derived from the Selector abstract base class. The TabControl control helps in arranging content in tabular form. This control consists of multiple TabItem controls that share the same screen space; however, only one TabItem control in the TabControl control is visible at a time. When a user selects the TabItem control, the content of the control becomes visible and the content of other TabItem objects is hidden.

## HeaderedItems Controls

HeaderedItems controls are used to display main, parent-level controls, or objects along with their child controls. HeaderedItems controls host header child elements and content that may or may not be a collection. The Header property labels the items of a control and the ItemsCollection property contains the items. The Header property specifies the label for the entire control and the individual child elements of the control. HeaderedItems controls inherit from the ItemsControl class. There are three WPF controls that can be grouped as HeaderedItems controls: MenuItem, ToolBar, and TreeViewItem.

Table 10.39 lists a brief description of these controls:

### Table 10.39: Headered Items Controls

| Control | Description |
|---|---|
| MenuItem | Represents a selectable item inside a Menu control |
| ToolBar | Provides a container for a group of commands or controls |
| TreeViewItem | Implements a selectable item in a TreeView control |
