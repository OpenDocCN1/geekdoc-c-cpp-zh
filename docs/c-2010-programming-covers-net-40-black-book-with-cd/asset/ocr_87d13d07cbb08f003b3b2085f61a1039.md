# Paging with DataAdapters

Paging in ADO.NET is the process of returning the results of a query in smaller subset of data or more specifically pages. You can use this practice for displaying results in small and easy to manage chunks. The DataAdapter provides a facility for returning only a page of data. The DataAdapter fills the DataSet with only the requested records. You need to use the startRecord parameter to return the first record in the page of data, and the maxRecords parameter for the number of records in the page of data. Let’s create an application, named PagingData (available in the CD-ROM), where you can apply paging of data with DataAdapters. Add a Button control and a DataGridView control and change Text property of the Button control to Load Page. Now, add the code, shown in Listing 24.7, on the Click Event of the Button control:

# Listing 24.7: Showing the Code for the Click Event of the Button Control

```
private void button1_Click(object sender, EventArgs e)
{
    int pageSize = 5;

    SqlConnection connection = new SqlConnection();
    connection.ConnectionString = "Data Source=umar-pc;Initial Catalog=Northwind;Integrated Security=True";
    connection.Open();
    string ordersSQL = "SELECT TOP " + pageSize + " * FROM Orders ORDER BY OrderID";
    SqlDataAdapter adapter = new SqlDataAdapter(ordersSQL, connection);
    DataSet DataSet = new DataSet();
    adapter.Fill(DataSet, "Orders");
    dataGridView1.DataSource = DataSet.Tables["Orders"];
}
```

When you run the application and click the Load Page button, you can see that only five records of the Order table are loaded.
