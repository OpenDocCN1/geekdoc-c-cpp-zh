The syntax to validate an Entity Model is:

```
EdmGen /mode:ValidateArtifacts /incsdl:<filename> /inmsl:<filename> /inssdl:<filename>
```

The EDM Generator tool provides five modes to perform specific functions, as listed in Table 22.8:

Table 22.8: Modes of the EDM Generator Tool

| Mode | Description |
|---|---|
| /mode:ValidateArtifacts | Requires at least one /inssdl or /incsdl argument. If /inmsl is specified, the /inssdl and /incsdl arguments are also required. You can specify this mode when you want to validate and display errors or warnings in the .csdl, .ssdl, and .msl files. |
| /mode:FullGeneration | Requires a /connectionstring argument and either a /project argument or /outsddl, /outsdl, /outmsdl, /outobjectlayer, /outviews, /namespace, and /entitycontainer arguments. This mode generates the .csdl, .ssdl, .msl, object layer, and view files by using the database information specified in the /connectionstring option. |
| /mode:FromSSDLGeneration | Requires the /inssdl argument and either a /project argument or the /outsddl, /outmsl, /outobjectlayer, /outviews, /namespace, and /entitycontainer arguments. This mode generates the .csdl and .msl files, source code, and views from the specified .ssdl file. |
