In C# 2010, many new features have been added to increase the productivity of developers. The following is the list of new features that are added to C# 2010:

### Support for Dynamic Data Type

The dynamic data type, introduced in C# 2010, allows you to assign data in a variable at runtime. You can define this data type by using the keyword, dynamic, in the code. A variable of the dynamic data type can be initialized by any type of data, such as numbers, float values, or string data. The following examples show the use of dynamic data types:

```
//Example 1
dynamic intvar = 10;
Response.write(intvar);

//Example 2
dynamic floatVar = 3.7;
Response.write(floatVar);

//Example 3
dynamic stringVar = "dynamicstring";
Response.write(stringvar);
```

As the dynamic keyword assigns the data at runtime; therefore, it can be used with COM or JavaScript, which have runtime properties.

### Named and Optional Arguments

In C# 2010, you can invoke methods of a class with named and optional arguments. These arguments are declared as normal arguments with the exception that they are initialized with default values. If you do not provide a value for an optional argument, it invokes its default value. You can manually invoke a named argument by passing a value by manually invoking its name.

The following code snippet shows an example of optional and named parameters:

```
static string Info(string name, string email = "kogent@xxx.com", string phone="0000000")
{
string msg = name + "\t" + email+"\t"+phone;
return msg;
}
static void Main(string[] args)
{
System.Console.WriteLine(Info("Charu")); //Line 1: Optional parameters are calling
System.Console.WriteLine(Info("Charu","charu@xxx.com")); //Line 2: Optional parameters are calling
System.Console.WriteLine(Info("Charu", phone: "8568487")); //Line 3: Named parameters are calling
}
```

In the preceding code snippet, a method, called Info is taking three parameters: name, email, and phone. The email and phone parameters are having default values and can work as optional parameters. The commented line, marked as Line 1, is passing the value of name parameter only; however, it shows the output as:

```
Charu    kogent@xxx.com    0000000
```

The email and phone are optional parameters, whose values may or may not be provided. In the next commented line, marked as Line 2, the values for name and email parameters are passed. The output of Line 2 is as follows:

```
Charu    charu@xxx.com    0000000
```

In the preceding example, phone number is an optional parameter and showing its default value, while values are provided for name and email parameters. Now, in the last commented line, marked as Line 3, the values for name and phone parameters are passed. The output of the Line 3 is as follows:

```
Charu    kogent@xxx.com    8568487
```

The preceding output shows default value for email and provides values of name and phone parameters. In this case, the name parameter is mandatory, email is optional, and phone is the named parameter.

### Access to Office Interop Objects

C# 2010 has introduced Office Interop objects that helps you to access the Application Programming Interface (API) objects. For example, you need to add the Microsoft.Office.Interop.Word and Microsoft.Office.Interop.Excel references to your program to access the features of Microsoft Word or Excel applications. The following example shows the directives that can be included to access the office API objects:

```
using Excel = Microsoft.Office.Interop.Excel;
using Word = Microsoft.Office.Interop.Word;
```
