# The StackPanel Control

The StackPanel container control positions the child elements as if they were on a stack and arranges them into a single line that can be oriented either vertically or horizontally. The vertical setting is the default setting, which you can change by using the Orientation property of the StackPanel control to Horizontal. This container control is typically used for small sections of a larger, more complex window. By default, the StackPanel control arranges the child controls from top to bottom, making each one as tall as necessary to display its content. All controls are stretched to the full width of the StackPanel control. If you widen a window, the StackPanel control widens as well, and the child controls stretch themselves to fit. The StackPanel control has its own HorizontalAlignment and VerticalAlignment properties. By default, both these properties are set to Stretch, and so the StackPanel control fills the container completely.

The StackPanel control is represented by the StackPanel class, which is derived from the Panel class. The inheritance hierarchy of the StackPanel class is as follows:
