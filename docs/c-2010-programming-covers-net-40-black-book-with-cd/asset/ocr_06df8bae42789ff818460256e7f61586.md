# Creating a New Web Site

In the In Depth section of this chapter, we mentioned that you can create a new Web site in Visual Studio 2010 using File System location, HTTP-based location, and FTP-based location. Let’s learn how you can create a Web site using these in the next sections.

# Using File System based Location

As you know, while creating a file system Web site, the files for the application are stored in a folder located either on a local computer or on a network computer. Let’s create a file system Web site using an application called FileSystemWebsite, also available in the CD-ROM. To do so, perform the following steps:

+   1. Click File→New→Web Site menu item. The New Web Site dialog box appears, as shown in Figure 13.14:

![](bbox=[0.25, 0.3, 0.76, 0.525])

Figure 13.14: Creating a Web site using File System

+   2. Select the ASP.NET Empty Web Site template and then select File System from the Web location drop-down list (Figure 13.14).

+   3. Type the path in the Location box where you want to create the Web site or select the location by clicking the Browse button. The Choose Location dialog box appears, as shown in Figure 13.15:

![](bbox=[0.27, 0.62, 0.73, 0.89])

Figure 13.15: The Choose Location Dialog Box with the File System Option Selected
