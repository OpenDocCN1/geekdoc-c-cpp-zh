# The UserControl Control

In WPF, the UserControl control provides an empty control, which can be used to create other controls. The use of the UserControl class as the base class provides a simple way to create custom controls. The UserControl control helps you to create controls, which can be used in multiple places within an application. For example, you can preload a ComboBox control with static items that you commonly use in every application. You cannot add a UserControl control to a WPF application with XAML code. Instead, you need to create a UserControl control in the code-behind file. The inheritance hierarchy of the UserControl control is as follows:

```
System.Object
    System.Windows.Controls.Control
        System.Windows.Controls.TemplateControl
            System.Windows.Controls.UserControl
```

You can add the UserControl to a WPF application by using the following code snippet:

```
<UserControl>
    <!--Content -->
</UserControl>
```

There are no noteworthy properties of the UserControl control.
