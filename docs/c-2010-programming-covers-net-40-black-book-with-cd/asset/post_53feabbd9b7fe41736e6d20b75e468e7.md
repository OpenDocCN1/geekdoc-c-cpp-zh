## Creating and Using UDTs

A user-defined object, as a CLR object, is implemented as a class in .NET Framework assembly. This class is created with the use of the SqlUserDefinedType attribute, so that the class is registered as a UDT. The SqlUserDefinedType attribute has the following properties:

- Format — Specifies the format of a type. It includes two pre-defined values, Format.Native and Format.UserDefined.
- MaxByteSize — Specifies the maximum size of a UDT in bytes. This property is specified only when the Format property is set to UserDefined.
- IsByteOrdered — Specifies how binary comparisons are performed on a UDT in SQL. It allows you to perform various tasks on columns with which the data type is bound. Some examples of these tasks are creating an index on the column, creating primary and foreign key constraints, and using the column with ORDER BY, GROUP BY, and PARTITION BY clauses. The default value of the IsByteOrdered property is set to false.
- ValidationMethodName — Specifies the method name that validates the instances of the UDT in the case of deserializing the data.
- IsFixedLength — Specifies the length of all the instances of a UDT. If this property is true, all the instances of the data type are of same length, in bytes. This property is specified only when the Format property is set to UserDefined.
- Name — Represents the name of the UDT.
