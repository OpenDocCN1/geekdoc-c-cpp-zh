## Creating Pointer to int Data Type

Pointers are the variables that hold the address of other variables of value types, such as int and char. Let’s create a Console application, named MyPointer (also available in the CD ), which shows how to create a pointer to int data type. Listing 6.1 shows the code of the Program.cs file of the MyPointer application:

### Listing 6.1: Creating Pointer to int Data Type

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyPointer {
class Program {
    unsafe static void Main(string[] args) {
        int Number = 100;
        int* MyPointer;
        MyPointer = &Number;
        {
        Console.WriteLine("The value of 'Number' is: "+Number);
        Console.WriteLine("The value of 'MyPointer' is: "+(int)MyPointer);
        Console.WriteLine("\n");
        Console.WriteLine("Press ENTER to quit.....");
        Console.Read();
        }
    }
}
```

In Listing 6.1, we have created an integer pointer MyPointer that holds the memory address of an integer variable named as Number.

## Dereferencing Pointers

Dereferencing a pointer means to access the value that is held by a pointer variable. Dereferencing of pointers is done through the de-referencer operator (*). As the address operator (&) returns the address of a variable, the de-referencer operator (*) returns the value, which is on the memory address held by the (&) operator. Let’s create a Console application, named Dereference (also available in the CD), which shows how to dereference pointers. Listing 6.2 shows the code of the Program.cs file of the Dereference application:

### Listing 6.2: Showing the Code of the Program.cs File

```

using System.Collections.Generic;
using System.Linq;
using System.Text;

```

```
{
    int Number = 100;
    int* MyPointer;
    MyPointer = &Number;
    Console.WriteLine("Old values:");
    Console.WriteLine("Number: " + Number);
    Console.WriteLine("MyPointer: " + (int)MyPointer);
    Console.WriteLine("*MyPointer: " + *MyPointer);
    *MyPointer = 50;
    Console.WriteLine("--------------------------");
    Console.WriteLine("New values:");
    Console.WriteLine("Number: " + Number);
    Console.WriteLine("MyPointer: " + (int)MyPointer);
    Console.WriteLine("*MyPointer: " + *MyPointer);
    Console.Read();
}
```

In Listing 6.2, you can see that the pointer variable *MyPointer holds the value, which is on the memory address held by &MyPointer.

## Using Pointers to Structures

The pointers can be used with a structure if the structure contains only value types as its members. Pointers can access the members of a structure by using the pointer operator (->). Let’s create a Console application, named PointersToStruct (also available in the CD), which shows how to use pointers to access structures. Listing 6.4 shows the code of the Program.cs file of the PointersToStruct application:

## Using Pointers to a Pointer

A pointer to a pointer variable holds the address of another pointer variable. Let’s create a Console application, named PointerToPointer (also available in the CD), which shows how to use a pointer to point another pointer. Listing 6.5 shows the code of the Program.cs file of the PointerToPointer application:

### Listing 6.5: Showing the Code of the Program.cs File

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace PointerToPointer
{
    class Program {
        unsafe static void Main(string[] args)
        {
            char FirstChar;
            char* SecondChar;
            char** ThirdChar;
            FirstChar = 'S';
            SecondChar = &FirstChar;
            ThirdChar = &SecondChar;
            Console.WriteLine("The value of FirstChar is: " + FirstChar);
            Console.WriteLine("The value of SecondChar is: {0}",(int)SecondChar);
            Console.WriteLine("The value of ThirdChar is: {0}",(int)ThirdChar);
            Console.WriteLine("\n");
            Console.WriteLine("Press ENTER to quit....");
            Console.Read();
        }
    }
}
```

In Listing 6.5, we have declared a variable FirstChar, a pointer variable SecondChar, and a pointer to a pointer variable ThirdChar of char type. The SecondChar variable holds the memory address of the FirstChar variable and the ThirdChar variable holds the memory address of the pointer variable SecondChar.
