## Using the Hashtable Class

如前所述，Hashtable 类允许你创建存储键值对的集合。使用 Hashtable 类，你可以通过与之关联的键检索对象。让我们创建一个名为 HashtableSample 的 Windows 窗体应用程序，也可在 CD-ROM 上获得，以了解 Hashtable 类的使用方法。该应用程序包含一个用户界面表单，其中有三个按钮--Create and add 10 items、ContainsKey 和 ContainsValue，以及一个 ListView 控件。

执行以下步骤以创建并向 Hashtable 对象添加元素：

- 1. 将 Form1 的 Text 属性设置为 Hashtable Sample。
- 2. 将 ListView、GroupBox 和三个 Button 控件拖放到表单上。
- 3. 将 GroupBox 控件的 Text 属性设置为 Noteworthy Operations，并将 button1 的 Text 属性设置为 Create and add 10 items，button2 设置为 Contains Key，button3 设置为 Contains Value。
- 4. 通过在属性窗口中点击 ListView 控件的 Columns 属性的省略号按钮 (...) 来向 ListView 控件添加列。ColumnHeader Collection Editor 对话框出现（图 32.8）。

5. 点击 Add 按钮向 ListView 控件添加一列。将该列的 Name 属性设置为 Key，Text 属性设置为 Keys。同样地，向 ListView 控件添加另一列，名称设为 Value，文本设为 Values，如图 32.8 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1536_0.png)

### Figure 32.8: Displaying the ColumnHeader Collection Editor Dialog Box

6. 点击 OK 按钮关闭 ColumnHeader Collection Editor 对话框（图 32.8）。

7. 将 ListView 控件的 View 属性设置为 Details。

8. 在 HashtableSample 应用程序的 Form1.cs 文件中添加 Listing 32.2 中给出的代码：

### Listing 32.2: Showing the Code of the Form1.cs File of the HashtableSample Application

```
using System;
using System.Collections.Generic;
using System.ComponentModel;
using System.Data;
using System.Drawing;
using System.Linq;
using System.Text;
using System.Windows.Forms;
using System.Collections;

namespace HashtableSample
{
    public partial class Form1 : Form
    {
        private Hashtable HTbl;
        public Form1()
        {
            InitializeComponent();
        }
        private void button1_Click(object sender, EventArgs e)
        {
            HTbl = new Hashtable(10);
            HTbl.Add(100, "white");
            HTbl.Add(101, "black");
            HTbl.Add(102, "blue");
            HTbl.Add(103, "yellow");
            HTbl.Add(104, "green");
            HTbl.Add(105, "red");
            HTbl.Add(106, "orange");
            HTbl.Add(107, "purple");
            HTbl.Add(108, "magenta");
HTbl.Add(109, "Brown");
LoadHshTable();
button2.Enabled = true;
button3.Enabled = true;
}
private void Form1_Load(object sender, EventArgs e)
{
    button2.Enabled = false;
    button3.Enabled = false;
}
private void LoadHshTable()
{
    listview1.Items.Clear();
    foreach (object obj in HTbl.Keys)
    {
        ListviewItem lItem = listview1.Items.Add(obj.ToString());
        lItem.SubItems.Add(HTbl[obj].ToString());
    }
}
private void button2_Click(object sender, EventArgs e)
{
string tempKey = Microsoft.VisualBasic.Interaction.InputBox("Enter the key to look up", "", "", -1, -1);
if (HTbl.ContainsKey(Convert.ToInt32(tempKey))) {
    MessageBox.Show("The hashtable contains the specified key");
}
else
{
    MessageBox.Show("The hashtable does not contain the specified key");
}
}
private void button3_Click(object sender, EventArgs e)
{
string tempKey = Microsoft.VisualBasic.Interaction.InputBox("Enter the value to look up", "", "", -1, -1);
if (HTbl.ContainsValue(tempKey))
{
    MessageBox.Show("The hashtable contains the specified value");
}
else
{
    MessageBox.Show("The hashtable does not contain the specified value");
}
}
}
```

在 Listing 32.2 中，使用 Add 方法向 Hashtable 类的对象添加键/值对。Add 方法接受两个参数，第一个为键，第二个为值。这两个参数可以是任何类型；并且无论将何种类型的数据添加到集合中，所有元素都以相同的方式添加到集合中。button1 的 Click 事件使用 Hashtable 类的 Add 方法向集合添加具有键/值对的元素。button2 的 Click 事件使用 ContainsKey 方法确定 Hashtable 对象是否包含特定键。如果 Hashtable 对象包含指定的键，则该方法返回 true；否则返回 false。同样，button3 的 Click 事件使用 ContainsValue 方法确定 Hashtable 对象是否包含特定值。该方法也返回 true 或 false 值。
