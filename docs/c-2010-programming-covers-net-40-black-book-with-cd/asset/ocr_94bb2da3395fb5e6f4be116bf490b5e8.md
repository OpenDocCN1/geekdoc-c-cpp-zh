+   - **Entity SQL** – Defines a common SQL based query language that is extended to express queries in terms of EDM concepts. It is supported by both the EntityClient and Object Services.
+   - **EntityClient** – Provides a gateway for the queries of the entity-level queries, which is queried through a common Entity SQL language.
+   - **Object Services** – Allows you to interact with a conceptual layer through a set of CLR classes. Object Services also provide support for Entity Framework by providing services, such as state management, identity resolution, and query building support.
+   - **LINQ to Entities** – Provides LINQ support for querying entities.
