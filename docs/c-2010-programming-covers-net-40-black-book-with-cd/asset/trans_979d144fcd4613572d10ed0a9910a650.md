## Toolbars

Visual Studio 2010 中的工具栏为开发人员提供了轻松访问 IDE 功能的途径。Visual Studio 2010 IDE 为开发应用程序所需任务的每个类别提供不同的工具栏，例如标准、布局、格式、调试和图像编辑器。标准工具栏是打开 Visual Studio 2010 时出现的默认工具栏，如图 1.53 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_82_1.png)

用户可以通过添加或删除按钮来自定义此工具栏。标准工具栏包含以下按钮：

- New Project — 创建新项目或新网站
- Add New Item — 存在于以下两个自解释的子类别中：
  - Add New Item — 在 Web 应用程序中添加新项，例如 Web 窗体和样式表
  - Add Existing Item — 在 Web 应用程序中添加本地系统中已有的项，例如图像
- Open File — 在 IDE 中打开 Web 项目、Windows 项目或任何其他 .NET 项目
- Save — 保存当前设计的窗体
- Save All — 保存对项目所做的所有更改
- Cut — 剪切对象或项，例如代码和控件
- Copy — 复制对象或项
- Paste — 粘贴剪切或复制的项
- Undo — 撤消在应用程序中进行的更改
- Redo — 通过单击标准工具栏的“撤消”按钮来撤消所做的更改
- Navigate Backward — 在应用程序内导航到之前访问的位置
- Navigate Forward — 在应用程序内导航到随后访问的位置
- Start Debugging — 调试代码
- Solution Configuration — 指定项目的配置
- Solution Platforms — 指定项目的平台
- Find in Files — 在项目中查找关键字
- Find — 在代码块中查找关键字
- Solution Explorer — 启动“解决方案资源管理器”
- Properties Window — 启动“属性”窗口以设置 Web 页面和控件的属性
- Object Browser — 启动“对象浏览器”窗口
- Toolbox — 启动“工具箱”窗口
- Start Page — 显示“开始”页面
- Command Window — 启动“命令”窗口
- Extension Manager — 使你能够从 IDE 查找和安装 Visual Studio 扩展

## Solution Explorer

在 Visual Studio 2010 中，“解决方案资源管理器”用于管理解决方案。解决方案是指包含一个或多个项目的容器。解决方案还包括项目相关的项和文件，例如类文件、图像、图标和用户控件。解决方案资源管理器列出解决方案名称、项目名称以及项目中使用的所有窗体和模块。开发人员只需双击此窗口中的名称即可打开特定文件。要重命名、复制或删除文件，你需要右键单击该文件并从出现的上下文菜单中选择所需的操作。

可以通过以下任一方式打开“解决方案资源管理器”：

- 从主菜单中选择 View→Solution Explorer
- 按 Ctrl+Alt+L 键

## The Class View Window

“类视图”窗口包含一个分层树视图，表示顶层节点的项目。它还显示与特定项目关联的类、方法和属性。你可以通过以下任一方式访问“类视图”窗口：

- 从主菜单中选择 View→Class View
- 按 Ctrl+Shift+C 键

图 1.56 显示了“类视图”窗口：

![](img/e073a4882197be4ab61103cbe0bcb394_85_0.png)

Figure 1.56: Displaying the Class View Window

如你在图 1.56 中看到的，“类视图”窗口分为以下两个窗格：

- Objects pane – 显示可扩展的符号树，其顶层节点表示项目。此分层视图指定代码内的符号结构。在“对象”窗格中选择对象会将其成员显示在“成员”窗格中。
- Members pane – 显示对象中存在的成员列表。

“类视图”窗口还包含一个工具栏，其中包含以下按钮：

- New Folder – 创建新文件夹或子文件夹，你可以将其符号或控件拖入其中，以便下次需要时轻松访问它们。
