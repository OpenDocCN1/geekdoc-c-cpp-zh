# The FixedPage Class

The FixedPage class provides the content for a high fidelity, fixed-format page within a fixed document. It automatically defines page breaks at the start and end of the content.

The inheritance hierarchy of the FixedPage class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Documents.FixedPage
```

The following code snippet shows how to add a FixedPage class to a WPF application:

```
<FixedPage>
  <!--Children-->
</FixedPage>
```

The properties of the FixedPage class are listed in Table 11.12:

| Table 11.12: Showing the Properties of the FixedPage Class |
| Property | Description |
| Children | Retrieves a collection of child elements of the FixedPage class. |
| ContentBox | Gets or sets the bounding rectangle of the content area. This area refers to the page within the margins. |
| DesiredSize | Retrieves the size of the fixed page, which is computed when implementing the layout behavior of controls. |
| PrintTicket | Gets or sets the setting of printing that is associated with the page which is going to be printed. |

# The PageContent Class

The PageContent class provides information about the FixedPage elements within the FixedDocument class. It does not require the loading of individual pages. The instance of the PageContent class is the only allowable child element of the FixedDocument class. The order of the PageContent elements within FixedDocument defines the page order. The Source dependency property of the PageContent class defines the URI of the corresponding FixedPage.

The inheritance hierarchy of the PageContent class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Documents.PageContent
```

The following code snippet shows how to add the PageContent class to a WPF application:

```
<PageContent>
  <!--Child-->
</PageContent>
```

The properties of the PageContent class are listed in Table 11.13:

| Table 11.13: Showing the Properties of the PageContent Class |
| Property | Description |
| LinkTargets | Retrieves a collection of the elements on a page that can be linked to other documents or other parts in the same document |
| Source | Gets or sets the URI of the FixedPage content data stream |
