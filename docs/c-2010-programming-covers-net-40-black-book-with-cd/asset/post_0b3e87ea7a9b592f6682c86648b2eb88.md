In C# 2010, exceptions can be handled by using the following two statements:

- The try...catch...finally statement
- The throw statement

Let’s discuss these statements in detail.

## The try...catch...finally Statement

C# provides three keywords for exception handling – try, catch, and finally. The try block encloses those statements that can cause exception; whereas, the catch block encloses the statements to handle the exception, if it occurs. Multiple catch blocks can exist for a single try block. All these catch blocks are used to handle different types of exceptions that are raised inside the try block. The statements enclosed in the finally block are always executed, irrespective of the fact whether an exception occurs or not. There can be only one finally block for a try block.

If any exception occurs in the try block, the program control directly transfers to its respective catch block and later on to the finally block. In C#, catch and finally blocks are not compulsory. In a program, a try block can contain one or multiple catch blocks, only a finally block, or both catch and finally blocks. If no exception occurs inside the try block, the program control is transferred directly to the finally block.

The following code snippet shows the use of the try...catch...finally statement:

```
try
{
    div = 100 / number;
}
catch (DivideByZeroException de)
{
    Console.WriteLine("Exception occured");
}
```
```
finally
{
Console.WriteLine("Result is : " +div);
Console.ReadLine();
}
```

In the preceding code snippet, when the statement inside the try block executes, the control may transfer to catch block depending upon the value of the number variable. Suppose, the value of the number variable is then DivideByZeroException is raised and the program control transfers to the catch block and executes the statements inside the catch block and after that the statements inside the finally block are executed. If value of the number variable is other than zero, then the program control is not transferred to the catch block is then directly transferred to the finally block and statements inside the finally block are executed.

## The throw Statement

The throw statement is used to raise an exception in case an error occurs in a program. In C#, it is also possible to throw an exception programmatically. You can use the throw keyword to throw an exception. The following code snippet shows an example of the throw statement:

```
try
{
throw new DivideByZeroException();
}
catch(DivideByZeroException e)
{
Console.WriteLine("Exception");
}
```

In the preceding code snippet, you can see that we have thrown a new DivideByZeroException explicitly.

## Checked and Unchecked Statements

Checked and unchecked statements are used to check the memory overflow exceptions. The checked keyword is used to check the overflow for integral-type arithmetic operations and conversions. Overflow occurs when the value of a variable exceeds the required original length of the variable. The unchecked keyword ignores the overflow-checking of the integral-type arithmetic operations and conversions. Arithmetic overflow exceptions are raised in a checked context; whereas, in case of unchecked context, arithmetic overflow is ignored and the program displays the truncated integers from the result.

The following code snippet shows an example of checked and unchecked statements:

```
byte number1, number2;
byte result;
number1 = 127;
number2 = 127;
try
{
result = unchecked((byte)(number1 * number2));
Console.WriteLine("Unchecked result: " + result);
result = checked((byte)(number1 * number2));
Console.WriteLine("checked result: " + result);
}
catch (OverflowException exc)
{
Console.WriteLine(exc);
}
```

In the preceding code snippet, you can see that the OverflowException class is used to catch the overflow exception.

## Using the if Statement

The if statement is the most commonly used conditional statement in computer programming. The statement inside the if block executes when the condition specified in the block is true; otherwise, the program control is transferred to the else statement and the statement inside the else block is executed. Let’s create a console application named MyIfStatement (also available on the CD) that shows the use of the if statement. Listing 3.1 shows the code of the MyIfStatement application:

### Listing 3.1: Showing the Code of the MyIfStatement Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyIfStatement
{
class Program
{
    static void Main(string[] args)
    {
        int year;
        Console.Write("Enter the year value (yyyy) :");
        year = Int32.Parse(Console.ReadLine());
        if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0)
            Console.WriteLine("The year {0} is a leap year ", year);
        else
            Console.WriteLine("The year {0} is not a leap year ", year);
        Console.Write("\nPress ENTER to quit...");
        Console.ReadLine();
    }
}
```

In Listing 3.1, you see that a user is prompted to enter the value of a year. Inside the if statement, a condition is defined to test whether or not the specified year is a leap year. If the condition is fulfilled, the program control transfers to the if block and displays that the year is a leap year; otherwise, the program control transfers to the else block and displays that the year is not a leap year.

## Using Nested if Statements

In case there is more than one condition to be evaluated in a program, you can use a set of nested if statements to evaluate the conditions. For example, if you wish to check the age, name, and gender of a student in your program, you can use nested if statements. Let’s create a console application named MyNestedIfStatement (also available on the CD) that shows the use of nested if statements. Listing 3.2 shows the code of the MyNestedIfStatement application:

### Listing 3.2: Showing the Code of the MyNestedIfStatement Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyNestedIfStatement
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Finding the Largest of Three Numbers\n");
            Console.Write("Enter the First Number:");
            int number1 = int.Parse(Console.ReadLine());
            Console.Write("Enter the Second Number:");
            int number2 = int.Parse(Console.ReadLine());
            Console.Write("Enter the Third Number:");
            int number3 = int.Parse(Console.ReadLine());
            Console.WriteLine("\n");
            if (number1 > number2 && number1 > number3)
                Console.WriteLine(number1 + " is the Largest Number");
            else
                if (number2 > number3)
                    Console.WriteLine(number2 + " is the Largest Number");
                else
                    Console.WriteLine(number3 + " is the Largest Number");
            Console.Write("\nPress ENTER to quit...");
            Console.ReadLine();
        }
    }
}
```

In Listing 3.2, a user is prompted to enter three numbers. In the first if statement, we check whether the first number is larger than the second and third numbers. If the condition satisfies, the program control transfers to the if block and executes the statements inside it. If the first if statement does not satisfy this condition, then the program control transfers to the else if statement and checks whether the second number is larger than the third number. If the else if statement satisfies the condition, the program control transfers to the else if block and executes the statements inside it. If both the statements do not satisfy the condition, the program control transfers to the else block and executes the statements inside it.

In this case (Figure 3.4), we have entered 89, 76, and 46 as first, second, and third numbers, respectively. It displays an output that 89 is the Largest Number.
