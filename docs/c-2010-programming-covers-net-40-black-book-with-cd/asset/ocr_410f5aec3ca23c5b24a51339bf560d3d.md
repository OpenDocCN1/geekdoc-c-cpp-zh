You can add a FlowDocumentReader control to your WPF application, as shown in the following code snippet

```
<FlowDocumentReader>
<!--Document-->
</FlowDocumentReader>
```

The properties of the FlowDocumentReader control are listed in Table 11.16:

# Table 11.16: Properties of the FlowDocumentReader Control

| Property | Description |
|---|---|
| CanDecreaseZoom | Retrieves a value that indicates whether the zoom level can be decreased or not |
| CanGoToNextPage | Retrieves a value that indicates whether or not the viewer can navigate to the next page in the current document |
| CanGoToPreviousPage | Retrieves a value that indicates whether or not the viewer can navigate to the previous page in the current document |
| CanIncreaseZoom | Retrieves a value that indicates whether or not the zoom level can be increased |
| Document | Gets or sets a FlowDocument that hosts the content to be displayed by FlowDocumentReader |
| IsPageViewEnabled | Gets or sets a value that indicates whether a page is available in the viewing mode |
| IsPrintEnabled | Gets or sets a value that indicates whether the Print routed command is enabled |
| IsScrollViewEnabled | Gets or sets a value that indicates whether Scroll is available as a viewing mode |
| IsTwoPageViewEnabled | Gets or sets a value that indicates whether TwoPage is available as a viewing mode |
| LogicalChildren | Retrieves an enumerator that can iterate through the child elements of FlowDocumentReader |
| MaxZoom | Gets or sets the maximum allowable zoom level for FlowDocumentReader |
| MinZoom | Gets or sets the minimum allowable zoom level for FlowDocumentReader |
| PageCount | Retrieves the current number of display pages for the content hosted by FlowDocumentReader |
| PageNumber | Retrieves the page number for the currently displayed page |
| Selection | Retrieves the selected content of FlowDocumentReader |
| ViewingMode | Gets or sets the viewing mode for FlowDocumentReader |
| Zoom | Gets or sets the current zoom level |
| ZoomIncrement | Gets or sets the zoom increment |

# The RichTextBox Control

The RichTextBox control allows you to modify its content. It is mainly used to edit formatted text, images, or tables. The RichTextBox control represents a rich editing control that operates on the FlowDocument object. This control supports a variety of editing commands, which are listed in Table 11.17:

# Table 11.17: Showing the Editing Commands of RichTextBox Control

| Editing Command | Key Gesture |
|---|---|
| AlignCenter | CTRL+E |
