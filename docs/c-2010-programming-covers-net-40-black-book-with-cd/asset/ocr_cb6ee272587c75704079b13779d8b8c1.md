# Performing Some Common Operations on Controls

Controls are an important part of any application. You can use a variety of controls, such as buttons, labels, and text boxes, to develop different types of applications. You can perform common operation on controls, such as hiding and displaying controls, disabling and enabling controls, specifying the tab order of controls, and moving and resizing controls. Let’s perform these operations in the following sections.

# Hiding and Displaying Controls

You can display and hide a control by setting the control’s Visible property to True and False, respectively. Perform the following steps to hide or display a control:

+   1. Create a Windows Forms application, named HideDisplayControls.
+   2. Add three Buttons to Form1, and modify the Text property of button1 to Click to Hide, and of button2 to Click to Display.
+   3. Modify the Text property of Form1 to Hide or Display a Control.
+   4. Add the following code snippet in the Click events of button1 and button2:
+   5. Press the F5 key to execute the HideDisplayControls application. Figure 8.39 shows a form with three button controls:

```
private void button1_Click(object sender, EventArgs e)
{
    button3.Visible = false;
}
private void button2_Click(object sender, EventArgs e)
{
    button3.Visible = true;
}
```
