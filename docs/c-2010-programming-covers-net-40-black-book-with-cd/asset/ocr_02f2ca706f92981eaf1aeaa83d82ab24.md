# Implementing Simple Data Binding in Windows Forms

As discussed in the In Depth section of this chapter, simple binding lets you display only one data element, such as a field’s value from a data table, in a control. In C#, you can simple-bind any property of a control to a data value. Let’s create an application in which you can use simple data binding to retrieve the data in the controls of a Windows Form. You should create a Windows Forms Application named SimpleBinding (also available on the CD) and add a Button control, four Label controls, and four TextBox controls to Form1. After adding the controls, change the text of the Button control to Move to Next Record. The text properties of the Label controls are also changed.

Table 25.1 lists the modified Text properties of the Label controls:

| Table 25.1: Text Properties of the Label Controls |

| label1 | Customer ID |
| label2 | Name of Company |
| label3 | Name of Customer |
| label4 | Contact Number |

Next, you need to bind the Text property of the TextBox control to the respective columns in the Customers table of the Northwind database.
