# Using the goto Statement

The goto statement allows the program control to transfer from one point to another. The transfer of program control is based on the labeled statements. Let's create a console application named MyLabeledStatement (also available on the CD) to show the use of the goto statement. Listing 3.11 shows the code of the MyLabeledStatement application:

# Listing 3.11: Showing the Code of the MyLabeledStatement Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace MyLabeledStatement
{
    class Program
    {
        static void Main(string[] args)
        {
            int x = 100, y = 4;
            int count = 0;
            string[,] myArray = new string[x, y];

            // Initialize the array:
            for (int i = 0; i < x; i++)
                for (int j = 0; j < y; j++)
                    myArray[i, j] = (++count).ToString();

            // Read input:
            Console.Write("Enter the Number to Search for:");

            // Input a string:
            string myNumber = Console.ReadLine();

            // Search:
            for (int i = 0; i < x; i++)
                for (int j = 0; j < y; j++)
                    if (myArray[i, j].Equals(myNumber))
                        goto Found;

            Console.WriteLine("The Number {0} is not Found.", myNumber);
```
