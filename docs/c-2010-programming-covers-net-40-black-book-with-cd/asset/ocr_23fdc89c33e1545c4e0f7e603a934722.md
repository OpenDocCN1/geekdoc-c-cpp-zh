Some elements and attributes used in the preceding code snippet are as follows:

+   - **Schema** — Refers to the root element of every XML schema. It indicates that the elements used in the schema have been extracted from `http://schemas.microsoft.com/ado/2006/04/edm`. This element consists of the following two attributes:
+     - **Namespace** — Refers to the top-level node in a schema that assigns a namespace which should be unique. The types defined in a schema are logically organized under the `Humanresource.SalarySchema` namespace.
+     - **Alias** — Refers to the attribute that can be used to shorten the name of a namespace in the rest of the schema, such as `Humanresource.SalarySchema`. For example, the Employee table can be shortened by using alias `Self`, which is declared for the namespace such as `Self.Employee`.

+   - **Using** — Refers to the element that is used to shorten the syntax while referring to types defined in a separate namespace. It consists of the following two attributes:
+     - **Namespace** — Specifies the external namespace
+     - **Alias** — Provides an alias for the namespace

+   - **Documentation** — Refers to the element in CSDL file of an EDM that provides information for using entities and associations declared in a schema. It has the following two subelements:
+     - **Summary** — Provides a brief description of the type. This attribute is optional.
+     - **LongDescription** — Includes a wide range of text information. This attribute is also optional.

> **NOTE**
> 
> *An empty Documentation element is also valid in the syntax of a CSDL file.*

+   - **EntityType** — Refers to the element that is used by EDM in a CSDL schema to specify an object in the domain of the application designed. It consists of the following attributes:
+     - **Key** — Specifies one or more properties of the entities as keys. It uniquely identifies instances of an entity for all operations and can be composed of more than one property.
+     - **Name** — Identifies the type in the Object Model designed.
+     - **NavigationProperty** — Declares a shortcut that is used to navigate to and from entities related by the Association type.
+     - **Property element** — Contains most of the information about entities used in an application.
+     - **Type** — Refers to the attribute of a property element that is set to `Guid` to specify a unique value for a key.

+   - **Association** — Refers to the element that specifies a logical relationship between entities in the EDM.

+   - **EntityContainer** — Refers to the element that is different from a Schema element even though the EntityContainer element is defined in a schema. The EntityContainer elements in a conceptual schema are mapped to the corresponding EntityContainer elements in the storage metadata. It also controls the scope of entities and associations in the object model that is defined.

+   - **AssociationSet** — Refers to the element that specifies an association in the class that is built from a conceptual schema. The object model, built from a conceptual schema, requires both programmable classes and storage structures to contain data for an application based on it. The attributes of the AssociationSet element are as follows:
+     - **AssociationSetMapping** — Connects the AssociationSet element defined in CSDL to the AssociationSet element in SSDL describing the storage structures
+     - **Name** — Specifies the name of a class in an object model built from the EDM
+     - **Extends** — Provide a means to add entities and associations to an existing schema
