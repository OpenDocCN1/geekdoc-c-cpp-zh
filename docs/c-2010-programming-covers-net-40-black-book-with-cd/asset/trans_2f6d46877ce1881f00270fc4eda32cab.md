

## 继承

使用面向对象编程最重要的原因是促进代码的重用并消除冗余代码。为了减少冗余，面向对象的语言支持继承。继承是通过一个类从另一个类派生属性的特性。从另一个类继承属性的类称为子类或派生类；而子类的属性所继承的类则称为父类或基类。父类在类层次结构中处于更高层级。类层次结构定义了类的逻辑结构，使得通用类位于类层次结构的顶部，而更专业的类位于较低层级。例如，Animal 类可以作为 Dog、Cow 和 Tiger 等多个派生类的基类。

继承有四种类型，分别是：

- 单继承 – 指继承中只有一个派生类和一个基类。这意味着派生类从单个基类继承属性。
- 层次继承 – 指从同一基类继承多个派生类的继承。
- 多层继承 – 指一个子类从一个类派生，而该类又从另一个类派生的继承。
- 多重继承 – 指一个子类从多个基类派生的继承。

C# 不通过类支持多重继承。要实现多重继承，需要使用接口。

### NOTE

> 接口是数据成员和成员函数的集合，但它只包含数据成员和成员函数的声明。你将在本章后面了解更多关于接口的内容。

## 继承与构造函数

构造函数是类的一个特殊方法，用于初始化同一类的成员。每当创建类的对象时，构造函数都会默认被调用。需要注意的是，派生类不能继承其基类的构造函数。所有派生类都有其默认构造函数。当你实例化一个派生类时，首先调用基类的构造函数，然后调用派生类构造函数。这样，基类的构造函数在派生类构造函数执行之前初始化基类的成员。让我们看一下以下代码片段，该片段展示了一个示例来解释构造函数的执行顺序：

```
class BaseClass
{
    public BaseClass()
    {
        Console.WriteLine("BaseClass constructor");
    }
}
class SubClass1 : BaseClass
{
    public SubClass1()
    {
        Console.WriteLine("SubClass1 constructor");
    }
}
class SubClass2 : SubClass1
{
    public SubClass2()
    {
        Console.WriteLine("SubClass2 Constructor");
    }
}
```

在前面的代码片段中，我们从 BaseClass 类派生 SubClass1 类，并从 SubClass1 类派生 SubClass 类。每个类都有其构造函数定义。因此，当实例化 SubClass2 类时，首先调用 BaseClass 类的默认构造函数，然后调用 SubClass1 类的构造函数，最后调用 SubClass2 类的构造函数。

## 密封类和密封方法

密封类是不能被继承的类。你可以使用 sealed 关键字将类定义为密封类。密封类可以包含密封方法。与密封类类似，密封方法也使用 sealed 关键字定义。你应该注意，派生类不能重写密封方法。

以下代码片段展示了如何定义密封类和密封方法：

```
sealed class MyClass
{
    ...//Data Members
    public void GetDetail()
    {
    }

    public sealed void ShowDetail() //sealed method
    {
    }
}
class MainClass
{
    //Instantiation of MyClass class
    //Method Calling
}
```

在前面的代码片段中，密封类 MyClass 在 MainClass 类中被实例化。然而，你尝试从 MyClass 类派生一个类，如以下代码片段所示：
    class DerivedClass : MyClass

## 扩展方法

扩展方法是一种方法，它帮助你在不创建新的派生类或修改原始类的情况下扩展一个类。它作为静态方法工作，但使用扩展类的实例进行调用。扩展方法可以是任何使用 this 关键字在其第一个参数之前的静态方法。只有具有静态成员并在其静态方法的第一个参数中实现 this 关键字的类才能使用扩展方法。以下代码片段展示了扩展方法的示例：

```
static class MyClass
{
    public static int MyExtensionMethod(this string Number)
    {
        ...//Method Body
    }
    public static int MyStaticMethod(string Number)
{
    ...//Method Body
}
class MainClass
{
    string Number = "100";
    int ext = Number.MyExtensionMethod();      // Line A
    int stat = MyClass.MyStaticMethod(Number);  // Line B
}
```

在前面的代码片段中，MyExtensionMethod() 方法是一个扩展方法，它默认使用 Number 变量的值来初始化 ext 变量。

扩展方法与静态方法之间的区别如下：

- 扩展方法在其第一个参数前包含 this 关键字；而静态方法在其参数声明中不包含 this 关键字。
- 当调用扩展方法时，不会传递使用 this 关键字声明的参数（参见前述代码片段中的 Line A）；而在调用静态方法时，必须传递所有参数。
- 扩展方法仅在静态类中定义，但静态方法不一定只能在静态类中声明。

## 多态

多态是面向对象编程的重要特性之一，用于表现出任何特定过程的不同形式。在多态的帮助下，你可以根据需要以多种方式使用一个过程。例如，你可以为计算几何图形面积制作一个过程，并使用相同的过程计算圆、三角形或矩形的面积，每个几何图形使用不同的参数。

多态的优点如下：

- 允许你在运行时通过基类引用调用派生类的方法
- 在一个类中提供方法的不同实现，这些实现通过相同的名称调用

多态有两种类型，讨论如下：

- 静态多态/编译时多态/重载
- 动态多态/运行时多态/重写

让我们详细讨论这些。

## 编译时多态/重载

当编译器编译程序时，它知道有关方法参数的信息，并据此在编译时本身将适当的方法绑定到对象。此过程也称为编译时多态或早期绑定。你可以通过重载的方法和运算符实现编译时多态。重载方法是具有相同名称但不同签名的那些方法，例如参数的数量、类型和顺序。编译时多态有以下三种类型：

- 方法重载
- 运算符重载
- 索引器重载

让我们详细讨论这些。

## 方法重载

方法重载是一个概念，其中方法根据传递给它的参数的数量和类型而表现。在方法重载中，你可以使用相同名称但不同签名定义许多方法。方法签名是方法名称与参数的数量、类型和顺序的组合。
