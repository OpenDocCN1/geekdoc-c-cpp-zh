# Installing the Windows Service Using Installutil.exe

To install the MyWindowsService service, you need to use the Installutil.exe utility. Open the Command Prompt of Visual Studio 2010 by clicking Start→All Programs→Microsoft Visual Studio 2010→Visual Studio Tools. Now right-click the Visual Studio Command Prompt (2010) option and select the Run as administrator option from the context menu. The Command Prompt for Visual Studio 2010 opens. Now, navigate to the Debug folder of your project, where MyWindowsService.exe exists and type the following command to begin the installation process:

```
installutil.exe MyWindowsService.exe
```
