using System.Linq;
using System.Text;
namespace Strings
{
    class Program

        {

            Console.ReadLine();
        }
    }
}

# Manipulating Strings

The System.String class provides a set of different methods to manipulate strings, such as changing the case of strings and adding two or more strings. Let’s take a case when you have two or more strings and you want to add them or you want a reverse of a particular string literal, or you want to find the length of a string. You can perform all these manipulations on strings by simply creating a string data type and using the dot operator (.) to get the string functionalities.
