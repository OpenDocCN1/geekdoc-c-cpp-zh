If you do not see the Properties window in the WPF Designer, then select View→Properties Window from the menu bar. You can also right-click the Design view and select Properties to display the Properties window or simply press the F4 key from the keyboard.

# Toolbox

The Toolbox offers several controls that you can use to design the UI of the WPF applications. You can drag the controls from the Toolbox and drop them onto the Design view. You can also drag and drop the controls onto the XAML view. The controls in the Toolbox of WPF Designer have three tabs:

+   - Common — Contains the controls that are more commonly used in WPF applications.
+   - Controls — Contains all the WPF controls.
+   - General — Contains some general controls, such as the Pointer and TreeView controls. Any custom controls that you create are placed under this tab.

> NOTE
> If the Toolbox is not visible, then you can select View→Toolbox from the menu bar or press CTRL+ALT+X from the keyboard.

Let’s now learn about the Document Outline window.

# Document Outline Window

The Document Outline window presents a hierarchical view of the UI of current WPF application. You can use it to select, remove, and navigate through the UI elements of the WPF application. The Document Outline window is not visible in the WPF Designer, by default. You can view the Document Outline window by selecting View→Other Windows→Document Outline from the menu bar or pressing CTRL+ALT+T from the keyboard. In addition, you can view the Document Outline window (shown in Figure 9.31) by right-clicking anywhere in the Design view and selecting Document Outline.
