# In Depth

A thread is a sequence of instructions that must be executed in a particular order to perform a specific task within a program. A program in execution is called a process and a thread can be a part of the executing program. A process executes in the operating system (OS); whereas, a thread executes within a process. Therefore, threads are also called as light-weight processes. One major difference between threads and processes is that processes are fully isolated from each other. It means that the functioning of one process does not affects the functioning of another process that is running in the OS. However, threads can share memory with other threads running in the same application. For instance, one thread can fetch data in the background, while another thread can simultaneously display the data as received by the first thread. The execution of a process starts with the Main() thread, which starts automatically, when a process executes; whereas, other threads need to be started by passing methods of the Thread class. If a process consists of more than one thread, it is termed as Multithreading. Multithreaded applications are capable of performing multiple tasks simultaneously, for example creating an application, downloading a movie, and listening music on the same OS. To ensure smooth running of threads in a multithreaded environment, you need to assign priority levels to threads on the basis of the tasks that they need to perform.

In this chapter, you learn about the Thread class and its methods and properties. Next, the chapter discusses the concept of multithreading that facilitates running of multiple tasks in a process at a time. You also learn about various priority levels that can be assigned to a thread. The chapter then proceeds to discuss various states of a thread. Finally, you learn how to synchronize threads in a multithreaded environment to avoid any deadlock situation.

# The Thread Class

In C#, a thread (the Main() thread) starts in a process created automatically by the Common Language Runtime (CLR) and the Operating System (OS). To enable threading in your C# program, you have to add the System.Threading namespace, as follows:

```
using System.Threading;
```

The Thread class is a class comprising various methods and properties that are used to create and control a thread, set its priority, and get its status. Table 31.1 lists some noteworthy public methods of the Thread class:

| Table 31.1: Noteworthy Public Methods of the Thread Class |
| Name | Description |
| Abort() | Terminates the current thread and raises a ThreadAbortException exception in the thread on which it is invoked |
| AllocateDataSlot() | Allocates an unnamed data slot on all the threads. This method uses fields that are marked with the ThreadStaticAttribute attribute for better performance. |
| AllocateNamedDataSlot() | Allocates a named data slot on all the threads. This method uses fields that are marked with the ThreadStaticAttribute attribute for better performance. |
| BeginThreadAffinity() | Informs a host that the managed code is about to execute a thread that depend on the current OS thread. |
| EndThreadAffinity() | Informs a host that the managed code has finished executing a thread that depend on the current OS thread. |
| FreeNamedDataSlot() | Eliminates the association between a name and a slot for all threads in the process. This method uses fields that are marked with the ThreadStaticAttribute attribute. |
| GetApartmentState() | Returns a value that indicates the status of an ApartmentState object. |
| GetData() | Retrieves a value from the current thread. This method uses fields that are marked with the ThreadStaticAttribute attribute. |
