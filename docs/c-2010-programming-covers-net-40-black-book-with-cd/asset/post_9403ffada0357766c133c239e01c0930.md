## Adding Rows and Columns to a Grid Through XAML

The In Depth section of this chapter explains that the Grid element (or control) is by default added to standalone WPF applications and XBAPs. As you may recall, the Grid element by default has only one cell, that is, one row and one column. If you want to vertically increase the number of cells in the grid, then you need to add more rows in the Grid element. You can also remove the rows in case there are superfluous rows. Similarly, to increase the number of cells horizontally in the Grid element, you need to add more columns. In this way, every row can have multiple columns.

Note that the changes you make in the XAML view are immediately reflected in the Design view and vice versa.

Now, let’s create a standalone WPF application named GridRowsColumns (also available on the CD) by performing the following steps:

- 1. Create a new WPF Application, GridRowsColumns.

- 2. Add the following code snippet within the `<Grid>` and `</Grid>` tags in the MainWindow.xaml file:

```
<Grid.RowDefinitions>
  <RowDefinition Height="20"/>
  <RowDefinition Height="50"/>
  <RowDefinition Height="50*"/>
  <RowDefinition Height="50*"/>
</Grid.RowDefinitions>
```

In the preceding code snippet, the Grid.RowDefinitions element is a child element of the Grid element. The Grid.RowDefinitions element has four child RowDefinition elements that define the four rows in the grid. The Height attribute of the RowDefinition elements is set to specify the height of each row. The height of the first row is 20 pixels and the second row is 50 pixels. The third and the fourth rows have a height of 50*, where the asterisk indicates the percentage of the remaining space in the grid.

- 3. Add the columns in the grid by using the following code snippet inside the `<Grid>` and `</Grid>` tags in the GridRowsColumns application:

```
<Grid.ColumnDefinitions>
  <ColumnDefinition Width="25"/>
  <ColumnDefinition Width="50"/>
  <ColumnDefinition Width="30*"/>
  <ColumnDefinition Width="50*"/>
</Grid.ColumnDefinitions>
```

In the preceding code snippet, the Grid.ColumnDefinitions element is a child element of the Grid element. The Grid.ColumnDefinitions element has four child ColumnDefinition elements that define the four columns in the grid. The Width attribute of the ColumnDefinition elements is set to specify the width of each column. The width of the first and second columns is 25 and 50 pixels, respectively. However, the width of the third and fourth columns is set to 30* and 50*, where the asterisk indicates the percentage of the remaining space in the grid.

Although the Design view immediately displays the rows and columns that you have added through the XAML code, let’s use four Button controls or elements to make it clearer to you.

- 4. Add the following code snippet inside the `<Grid>` and `</Grid>` tags to show the rows and columns through controls:

```
<Button Name="button1" Content="OK" Grid.Row="0" Grid.Column="0" Grid.RowSpan="2"/>
<Button Name="button2" Content="Yes" Grid.Row="2" Grid.Column="1"/>
<Button Name="button3" Content="No" Grid.Row="2" Grid.Column="3"/>
<Button Name="button4" Content="Cancel" Grid.Row="3" Grid.Column="2" Grid.ColumnSpan="2"/>
```

In the preceding code snippet, four Button elements named button1, button2, button3, and button4 are used. The button1 element appears in the first row and first column by setting the Grid.Row and Grid.Column attributes to zero. The Grid.Row and Grid.Column attributes indicate the row and column in which button1 appears. The Grid.RowSpan attribute is set to 2, which implies that button1 spans two rows. Similarly, button2 appears in the third row and second column, button3 appears in the third row and fourth column, and button4 appears in the fourth row and spans the third and fourth columns, as shown in Figure 9.41:
