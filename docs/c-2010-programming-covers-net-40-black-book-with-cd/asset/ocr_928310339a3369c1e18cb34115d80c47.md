Now, let’s look at some of the common attributes of the <provider> element that you need to set, while defining the <provider> element for ActiveDirectoryMembershipProvider. Table 36.19 lists the attributes of the <provider> element:

# Table 36.19: The Attributes of the <provider> Element

| Attribute | Description |
|---|---|
| connectionPassword | Specifies the password using which you can access the Active Directory data store. This attribute ensures that the user accessing the Active Directory data store is an authenticated user. |
| connectionStringName | Specifies the name of the connection string created in the <connectionStrings> element of the web.config file. This connection string allows you to perform create, update, get, and validate operations on the Active Directory data store. |
| connectionUsername | Specifies the user name using which you can access the Active Directory data store. This attribute ensures that the user accessing the Active Directory data store is an authenticated user. |

> Note
> If you set the connectionUserName attribute, make sure that a value for the connectionPassword attribute is also specified. Similarly, if you set the connectionPassword attribute, make sure that a value for the connectionUserName attribute is also specified.

The following code illustrates the configuration of ActiveDirectoryMembershipProvider:

```
<membership defaultProvider="ADMembershipProvider">
  <providers>
    <add
      name="ADMembershipProvider"
      type="System.Web.Security.ActiveDirectoryMembershipProvider, System.Web, Version=2.0.0.0, Culture=neutral, PublicKeyToken=b03f5f7f11d50a3a"
      connectionStringName="ActiveDirectoryCS"
      connectionUsername="<domainName>\administrator"
      connectionPassword="pass"/>
  </providers>
</membership>
```

# SqlMembershipProvider

The SqlMembershipProvider is used to store user credentials in an SQL Server data store. You need to first install an SQL Server membership data store and then configure SqlMembershipProvider to use SqlMembershipProvider in an ASP.NET application. An SQL Server membership data store is the one that is used to store user credentials. We will look at the details of installing the SQL Server membership data store and configuring SqlMembershipProvider in the subsequent topics.

# Installing the SQL Server Data Store

Log on to the computer with an account that has the administrative permissions to use the computer, such as administrative account, to install an SQL Server membership data store on a computer. After logging on to the system, run the aspnet_regsql utility on the Visual Studio 2010 Command Prompt and run it as administrator. The aspnet_regsql utility is used to install data stores for various features of ASP.NET, such as profiles, personalization, and membership. You need to understand its various options, which are as follows, to use the aspnet_regsql utility:

+   - -E—Facilitates authentication using the credentials of the currently logged on user
+   - -S—Specifies the name of the computer on which SQL Server data store is to be installed
+   - -A m—Generates tables and stored procedures required by SqlMembershipProvider

For example, you can use the following command to install a SQL Server membership data store on a computer:

```
aspnet_regsql.exe -E -S server -A m
```
