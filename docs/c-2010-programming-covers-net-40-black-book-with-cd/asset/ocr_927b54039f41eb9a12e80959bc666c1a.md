The WindowsPrincipal principal policy causes the user groups in the Windows operating system to be mapped as roles in .NET. A Windows principal object named winP is created on the current thread by using the CurrentPrincipal property of the Thread class. Next, a Windows identity object named winI is created through the Identity property of the winP object. Now, in the if statement, the Name property of the winI identity object is checked to see whether the current user is TestUser.
