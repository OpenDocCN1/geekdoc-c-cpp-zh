# The Window Control

The Window control helps to create, configure, show, and manage the lifetime of a Window or dialog box. The WPF Window control consists of two areas: the client area and the non-client area. The client area hosts application-specific content and the non-client area hosts common controls, such as the Minimize, Maximize, and Close buttons. The Window control is added to the WPF application by default. The Window control in WPF is a root element and cannot be a part of the content of another element.

The inheritance hierarchy of the Window class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.ContentControl
                System.Windows.Window
```

You can add the Window control to a WPF application by using the following code snippet:

```
<Window>
  <!-- Content -->
</Window>
```

Table 10.24 describes the important properties of the Window class:

| Table 10.24: Showing the Noteworthy Properties of the Window Class |
| Property | Description |
| AllowsTransparency | Gets or sets a value that indicates whether a window's client area supports transparency |
| DialogResult | Gets or sets the dialog result value, which is the value that is returned from the ShowDialog method |
| IsActive | Retrieves a value that indicates whether a control is active |
| Left | Gets or sets the position of a control's left edge, in relation to the desktop |
| OwnedWindows | Retrieves a collection of windows whose Owner property is set with a reference to another window |
| Owner | Gets or sets the relationship between the child Window control and the parent Window control |
| ResizeMode | Gets or sets the resize mode of a control |
| RestoreBounds | Retrieves the size and location of a window before the Window control is either minimized or maximized |
| ShowInTaskbar | Gets or sets a value that indicates whether a Window control has a task bar button |
| SizeToContent | Gets or sets a value that indicates whether a window will automatically size itself to fit the size of its content |
| Title | Gets or sets a title for a Window control |
| Top | Gets or sets the position of a Window control's top edge, in relation to the desktop |
| Topmost | Gets or sets a value that indicates whether a Window control appears above all the other Window controls |
| WindowStartupLocation | Gets or sets the position of a Window control when first displayed |
| WindowState | Gets or sets a value that indicates whether a Window control is restored, minimized, or maximized |
| WindowStyle | Gets or sets the border style of the Window control |
