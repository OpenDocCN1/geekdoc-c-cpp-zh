# Updating with DataAdapters

You can update a data source with the help of DataAdapter. The Update() method of the DataAdapter is called to resolve changes from the DataSet back to the data source. When you call the Update() method, the DataAdapter analyzes the changes that have been made and executes the command. When the DataAdapter encounters a change to a DataRow, it uses the UpdateCommand to process the change. You must note that the Update() method is performed on a row basis. When an application calls the Update() method, the DataAdapter examines the RowState property and executes the required INSERT, UPDATE, or DELETE statement for each row. Let’s create an application, UpdatingData (available in the CD-ROM), where you can update the data with DataAdapter. For this, you first need to add a Button and a DataGridView control to Form1. After that, you need to change the text property of the Button to Update Data and add the project data source to the DataGridView control through the wizard as shown in the section Creating a Connection to a Database of the chapter. After adding the data source, add the code, shown in Listing 24.8 on the Click event of Button control:

# Listing 24.8: Showing the Code for the Click Event of the Button Control

```
private void button1_Click(object sender, EventArgs e)
{
    employeesTableAdapter.Update(northwindDataSet);
}
```

As you have already learned that the employeesTableAdapter and the northwindDataSet are automatically generated when you create the data source connection through the wizard.

When you run the application, the original table is generated in the DataGridView control. You can add a whole new row in the DataGridView control while the application is running, and then click the Update Data button. The new data is added in the DataGridView control and data source. # Adding Multiple Tables to a DataSet

A single DataSet can contain multiple tables. You need to create a single DataSet and add different tables to different DataGridView controls in your application. Let’s create an application, named MultiTable (available in the CD-ROM), in which you can add multiple tables to your application with a single DataSet. Now, add two DataGridView controls and two labels to Form1. After that, change the text of both the Label controls to Order Details Table and Orders Table, respectively and add the code, shown in Listing 24.9, on the Load event of the Form1:

# Listing 24.9: Showing the Code for the Load Event of the Form1

```
private void Form1_Load(object sender, EventArgs e)
{
    SqlConnection connection = new SqlConnection();
    connection.ConnectionString = "Data Source=umar-pc;Initial Catalog=Northwind;Integrated Security=True";
```
