using System;

using System.ComponentModel;
using System.Data;
using System.Drawing;
using System.Linq;
using System.Text;
using System.Windows.Forms;
using System.Xml;
using System.Xml.Schema;

namespace ValidatingXMLData
{
    public partial class Form1 : Form
    {
        public Form1()
        {
            InitializeComponent();
        }

        private void button1_Click(object sender, EventArgs e)
        {
            XmlReaderSettings rs = new XmlReaderSettings();
            rs.Schemas.Add(null, "authors.xsd");
            rs.ValidationType = ValidationType.Schema;
            rs.IgnoreWhitespace = true;
            rs.ValidationEventHandler += new ValidationEventHandler(validation);
            XmlReader xr = XmlReader.Create("editAuthors.xml", rs);
            while (xr.Read())
            {
                if (xr.NodeType == XmlNodeType.Text)
                    listBox1.Items.Add(xr.Value);
            }
        }
        public void validation(object sender, ValidationEventArgs e)
        {
            MessageBox.Show(e.Message);
            Close();
        }
    }
}

在清单 30.4 中，我们创建了 XmlReaderSettings 类的对象。之后，我们通过调用 XmlReaderSettings 对象的 Schemas 集合的 Add() 方法，将 authors.xsd XML 架构文件添加到 XmlSchemaSet 对象中。然后，我们使用 ValidationType 枚举中的 Schema 值设置 XmlReaderSettings 对象的 ValidationType 属性。我们还将 XmlReaderSettings 对象的 IgnoreWhitespace 属性设置为 true。我们还通过调用其 Create() 方法创建了 XmlReader 类的对象，并将 XML 文件的名称（editAuthors.xml）作为一个参数传递给它。我们已将 editAuthors.xml 文件放置在项目的 bin 文件夹内的 debug 文件夹中，以便自动搜索 XML 文件的位置。

## Implementing DOM in .NET

XML 文档由节点集合和节点的属性组成。您可以通过修改节点或属性来修改 XML 文档的数据。System.Xml.XmlDocument 类用于实现 .NET Framework 的核心 XML DOM 解析器。您可以使用 DOM 模型实现通过执行各种任务来修改 XML 文档的数据，例如在文档中插入、删除或更新数据。

DOM 模型是通过使用 XmlNode 和 XmlNodeList 类实现的。XmlNode 类是一个抽象类，表示 XML 文档；而 XmlNodeList 类表示节点的有序列表。让我们使用 XmlDataDocument、XmlDocument、XmlNode、XmlNodeList、XmlElement 和 XmlAttribute 类来实现 DOM 模型以修改 XML 数据。这些类属于 System.Xml 命名空间。

在本节中，您将学习如何通过标签名查找元素并在 XML 文档中插入节点。为此，我们在以下各节中创建的应用程序中使用相同的 XML 文件 authors.xml。
