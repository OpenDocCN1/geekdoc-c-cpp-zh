# Creating User Using the Membership Class

You can create new users for a website or web application by using the Membership class. The Membership class also enables a developer to provide more functionality such as deleting a user and generating passwords. Now, let’s create a website and save it as Membership (on the CD-ROM). Now, let’s create the website by performing the following steps:

+   1. Open the Web site Membership and add a Web page, Default.aspx, in it.
+   2. Replace the code of the Default.aspx page with the code, given in Listing 36.22, to add the required controls for creating user using the Membership class:

**Listing 36.22:** Showing the Code for the Default.aspx Page
