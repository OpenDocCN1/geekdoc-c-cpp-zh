## The Page Class

Similar to a Web page in a Web site, a WPF page is the basic entity in an XBAP. The pages in XBAPs hold the content that is displayed to users. When you create an XBAP, a page is automatically included in it. In addition, when the XBAP runs, users can navigate to any page in the XBAP. A single XBAP page is an instance of the Page class. The class hierarchy of the Page class is:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Page
```

The Page class has various properties, methods, and events. Table 9.4 lists the noteworthy properties of the Page class:

| Property | Description |
|---|---|
| Content | Sets or retrieves the content of the page |
| Height | Sets or retrieves the height of the page |
| KeepAlive | Sets or retrieves a value that indicates whether the page is to be kept in the history after a user has navigated that page |
| LogicalChildren | Retrieves the enumerator of logical children of the page |
| Name | Sets or retrieves the name of the page |
| NavigationService | Retrieves the navigation service used by the host to control the navigation of the pages |
| ShowsNavigationUI | Sets or retrieves a value that indicates whether to display the navigation controls |
| Title | Sets or retrieves the title of the page |
| Width | Sets or retrieves the width of the page |
| WindowHeight | Sets or retrieves the height of the window that contains the page |
| WindowTitle | Sets or retrieves the title of the window that hosts the page |
| WindowWidth | Sets or retrieves the width of the window that contains the page |

The methods and events of the Page class are the same as that of the Window class.

## The Application Class

A WPF application, whether it is standalone or XBAP, is represented by an instance of the Application class. This class provides some of the essential functionalities to configure and run WPF applications. For instance, the Application class allows you to control the lifetime of a WPF application, work with command-line parameters and exit codes (values returned by the application to the underlying operating system when execution of the application ends), handle events and run-time exceptions, and track the navigation of WPF applications.

Note that the Application class is available in both forms, the XAML code and .NET language code, using the App.xaml and App.xaml.cs files, respectively. In XAML, the <Application> tag or element signifies the application, while in the code-behind file; the App partial class does the same. The class hierarchy of the Application class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.Application
```

Table 9.5 lists the noteworthy properties of the Application class:

| Property | Description |
|---|---|
| Current | Returns the current WPF application. |
| MainWindow | Sets or retrieves the main window of the WPF application. The first window that is created in the application is the main window, by default. |
| Properties | Returns a collection of application-specific properties. The Properties collection is not accessible through XAML. |
| ResourceAssembly | Sets or returns the assembly that offers the pack Uniform Resource Identifiers (URI) for application resources. |
| Resources | Sets or returns a collection of application-specific resources. |
| ShutDownMode | Sets or returns the condition that causes a call to the Shutdown() method. Depending on the value of the ShutdownMode enumeration, the application is shut down either implicitly or explicitly. |
| StartupUri | Sets or returns the UI that is displayed when an application starts. |
| Windows | Returns a collection of windows in the current application. |

Table 9.6 lists the noteworthy methods of the Application class:

| Method | Description |
|---|---|
| FindResource | Searches for a resource such as styles and brushes based on a key. |
| GetContentStream | Retrieves a stream of resources for the given content file that is accessible at a specified URI. |
| GetCookie | Retrieves a cookie from the given URI. |
| GetRemoteStream | Retrieves a stream of resource site of origin file located at the given URI. Origin files are those files that are independent of any executable WPF assembly. |
| GetResourceStream | Retrieves a stream of resources for a resource file located at the given URI. |
| LoadComponent | Loads an XAML file that exists at a particular URI. |
| OnActivated | Raises the Activated event for the application |
| OnDeactivated | Raises the Deactivated event for the application |
| OnExit | Raises the Exit event for the application |
| OnFragmentNavigation | Raises the FragmentNavigation event for the application |
| OnLoadCompleted | Raises the LoadCompleted event for the application |
| OnNavigated | Raises the Navigated event for the application |
| OnNavigating | Raises the Navigating event for the application |
| OnNavigationFailed | Raises the NavigationFailed event for the application |
| OnNavigationProgress | Raises the NavigationProgress event for the application |
| OnNavigationStopped | Raises the NavigationStopped event for the application |
| OnSessionEnding | Raises the SessionEnding event for the application |
| OnStartup | Raises the Startup event for the application |
| Run | Starts running a WPF application |
| SetCookie | Creates a cookie for a particular URI location |
| Shutdown | Shuts down a WPF application |

Table 9.7 lists the noteworthy events of the Application class:

| Event | Description |
|---|---|
| Activated | Occurs when the WPF application is the active application |
| Deactivated | Occurs when the WPF application is no longer the active application |
| DispatcherUnhandledException | Occurs when an unhandled exception is encountered in the application |
| Exit | Occurs immediately before the application shuts down |
| FragmentNavigation | Occurs when the navigator starts the navigation to a content part or fragment |
| LoadCompleted | Occurs while navigating to a particular content that is loaded, parsed, and has started with the rendering process |
| Navigated | Occurs when the desired content is located but not loaded |
| Navigating | Occurs when a new navigation begins |
| NavigationFailed | Occurs when an error is encountered while navigating |
| NavigationProgress | Occurs at regular intervals while navigating |
| NavigationStopped | Occurs when the navigation is stopped or a new navigation begins |
| SessionEnding | Occurs when the Windows (operating system) session ends by either logging off or shutting down |
| Startup | Occurs when the Run() method is called |
