## 创建和恢复书签

在本节中，我们创建一个工作流控制台应用程序，名为 BookmarkResume（也可在 CD 上获得）。在此应用程序中，我们创建和恢复一个书签。

执行以下步骤来创建 BookmarkResume 应用程序：

- 1. 创建一个工作流控制台应用程序，BookmarkResume。
- 2. 在 Program.cs 文件中添加以下命名空间：
- using System.Threading;
- 3. 在 Program 类的 Main() 方法中添加以下代码片段：

```
Variable<string> name = new Variable<string>
{
    Name = "name"
};

Activity wf = new Sequence
{
    Variables =
    {
        name
    },
    Activities =
    {
        new WriteLine()
        {
            Text = "Enter your name:"
        },
        new ReadLine()
        {
            BookmarkName = "YourName",
            Result = name
        },
        new WriteLine()
        {
            Text = new InArgument<string>((env) => "Hello, " + name.Get(env)+"\nYou are reading C# 2010 Black book")
        }
    }
};

AutoResetEvent syncEvent = new AutoResetEvent(false);

WorkflowApplication wfApp = new WorkflowApplication(wf);

wfApp.Completed = delegate(WorkflowApplicationCompletedEventArgs e)
{
    syncEvent.Set();
};

wfApp.Run();

wfApp.ResumeBookmark("YourName", Console.ReadLine());

syncEvent.WaitOne();
```

在前面的代码片段中，创建了一个使用 ReadLine 活动获取用户输入的工作流。ReadLine 活动还创建了一个书签 YourName，并等待书签被恢复。当主机进程收集输入数据并恢复书签时，工作流将被恢复，输入将在控制台上显示。

- 4. 在 Program 类中 Main() 方法外部添加一个 ReadLine 活动，通过编写以下代码片段：

```
public sealed class ReadLine : NativeActivity<string>
{
    [RequiredArgument]
    public InArgument<string> BookmarkName { get; set; }

    protected override void Execute(NativeActivityContext context)
    {
        context.CreateBookmark(BookmarkName.Get(context), new BookmarkCallback(OnResumeBookmark));
    }
    protected override bool CanInduceIdle
    {
        get { return true; }
    }
    public void OnResumeBookmark(NativeActivityContext context, Bookmark bookmark, object obj)
    {
        Result.Set(context, (string)obj);
    }
}
```

在前面的代码片段中，创建了一个 ReadLine 活动。此 ReadLine 活动创建 Bookmark 类的实例并等待书签被恢复。当 Bookmark 被恢复时，ReadLine 活动将数据分配给结果参数。

- 5. 在键盘上按 CTRL+F5 键组合运行 BookmarkResume 应用程序。运行应用程序时，它会提示输入你的姓名，如图 28.15 所示：
