# Converting Two Nullable Types

A non-nullable value type is implicitly converted to a nullable type of that value type. In addition, conversion takes place from a null literal to a nullable type. You can perform predefined and user-defined conversions on non-nullable value types and nullable forms of those value types. These conversions take place from A to B? and A? to B. The conversion from A? to B is an explicit conversion, which issues an exception, if the source value is null.
