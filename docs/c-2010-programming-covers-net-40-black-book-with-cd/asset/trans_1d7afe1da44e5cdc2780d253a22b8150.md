## 使用代码后置代码控制 Storyboard

当你通过代码控制 Storyboard 时间线时，必须为 FrameworkElement 类创建一个 NameScope 类，以便使用 FrameworkElement 类注册要动画对象的名称。要在代码中启动动画，应使用带有 EventTrigger 对象的 BeginStoryboard 属性。你也可以使用事件处理程序和 Storyboard 类的 Begin() 方法。你也可以通过代码后置代码创建与 XAML 相同的效果。让我们创建一个可以通过代码控制 Storyboard 时间线的动画。为此，创建一个名为 Storyboard_Code 的 WPF 应用程序（也在 CD 上提供）并将 Listing 12.30 中给出的代码添加到 MainWindow.xaml 文件中：

### Listing 12.30: 使用 XAML 代码添加按钮

```
<Window x:Class="Storyboard_Code.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="300" Width="300">
    <Grid>
        <Button Width="100" Name="button1" Click="button1_Click"
            HorizontalAlignment="Left" Margin="0,27,0,0" Height="29"
            VerticalAlignment="Top">Click to grow</Button>
    </Grid>
</Window>
```

Listing 12.30 中的代码是 XAML 代码，用于向应用程序添加一个名为 button1 的 Button。button1 控件在代码后置文件中进行动画处理。将 Listing 12.31 中给出的代码添加到 MainWindow.xaml.cs 文件中：

### Listing 12.31: 为按钮控件设置动画

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Windows;
using System.Windows.Controls;
using System.Windows.Data;
using System.Windows.Documents;
using System.Windows.Input;
using System.Windows.Media;
using System.Windows.Media.Imaging;
using System.Windows.Navigation;
using System.Windows.Shapes;
using System.Windows.Media.Animation;

namespace Storyboard_Code
{
    /// <summary>
    /// Interaction logic for MainWindow.xaml
    /// </summary>
    public partial class MainWindow : Window
    {
        public MainWindow()
        {
            InitializeComponent();
            NameScope.SetNameScope(this, new NameScope());
            this.RegisterName(button1.Name, button1);
        }
        private void button1_Click(object sender, RoutedEventArgs e)
        {
            DoubleAnimation myAnimation = new DoubleAnimation();
            myAnimation.From = 100;
            myAnimation.To = 300;
            myAnimation.AutoReverse = true;
            myAnimation.RepeatBehavior = RepeatBehavior.Forever;
            myAnimation.Duration = new Duration(TimeSpan.FromSeconds(2));
            Storyboard myStoryboard = new Storyboard();
            myStoryboard.Children.Add(myAnimation);
            Storyboard.SetTargetName(myAnimation, button1.Name);
            Storyboard.SetTargetProperty(myAnimation, new PropertyPath(Button.WidthProperty));
            myStoryboard.Begin(this);
        }
    }
}
```

前面的代码向按钮控件添加了一个 Storyboard 对象。当你点击它时，该按钮控件会被动画化以变大。当你通过键盘上的 F5 键运行应用程序时，一个按钮控件将被添加到窗口中。当你点击按钮控件时，它开始增大。输出显示在图 12.34 中：

## 使用 DoubleAnimation 转换控件

DoubleAnimation 类在指定持续时间内在两个目标值之间为 Double 属性设置动画。动画在一段时间内更新属性的值。你可以使用 DoubleAnimation 类创建简单的动画，例如移动形状，以及高级动画，例如放大形状。你可以将 DoubleAnimation 类的 Storyboard.TargetProperty 设置为转换控件。让我们创建一个用于转换控件的应用程序。为此，创建一个名为 DoubleAnimation 的 WPF 应用程序（也在 CD 上提供）并将 Listing 12.32 中给出的代码添加到 MainWindow.xaml 文件中：

### Listing 12.32: 使用 DoubleAnimation 类转换控件

```
<Window x:Class="DoubleAnimation.MainWindow"
xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
Title="MainWindow" Height="400" Width="400">
<Window.Resources>
<Style x:Key="WindowStyle" />
<Style x:Key="windowBackground" TargetType="{x:Type Window}">
<Style.Triggers>
<EventTrigger RoutedEvent="Window.Loaded">
<EventTrigger.Actions>
<BeginStoryboard>
<Storyboard RepeatBehavior="Forever">
<ColorAnimation From="LightBlue" To="DarkViolet"
Storyboard.TargetProperty="Background.Color"
Duration="0:0:10" Timeline.DesiredFrameRate="10"
AutoReverse="True" />
</Storyboard>
</BeginStoryboard>
</EventTrigger.Actions>
</EventTrigger>
</Style.Triggers>
</Style>
</Window.Resources>
<Window.Style>
<StaticResource ResourceKey="windowBackground"/>
</Window.Style>
<StackPanel>
<StackPanel HorizontalAlignment="Center" >
<Button Height="42" Width="207">Click to Show Text
<Button.Triggers>
<EventTrigger RoutedEvent="Button.Click">
<EventTrigger.Actions>
<BeginStoryboard>
<Storyboard>
<ParallelTimeline>
<DoubleAnimation Storyboard.TargetName="myBorder"
Storyboard.TargetProperty="RenderTransform.ScaleX" From="0"
To="1" Duration="0:0:3" AutoReverse="False" />
<DoubleAnimation Storyboard.TargetName="myBorder"
Storyboard.TargetProperty="Opacity" From="0"
To="1" Duration="0:0:3" AutoReverse="True" />
</ParallelTimeline>
</Storyboard>
</BeginStoryboard>
</EventTrigger.Actions>
</EventTrigger>
</Button.Triggers>
</Button>
<Border Width="300" Height="200" Name="myBorder" BorderBrush="Black"
BorderThickness="5" Opacity="0.5" Style="{StaticResource WindowStyle}">
<Border.RenderTransform>
<ScaleTransform ScaleX="0" ScaleY="1" CenterX="200" />
</Border.RenderTransform>
<TextBlock Width="300" Height="300" TextWrapping="wrap" FontSize="60"
TextAlignment="Center">
<TextBlock.Foreground>
<RadialGradientBrush GradientOrigin="0,0" Center="0.5,0.5"
RadiusX="1" RadiusY="1">
<GradientStop Color="LightPink" Offset="0.25" />
<GradientStop Color="DeepPink" Offset="0.5" />
<GradientStop Color="Pink" Offset="1" />
</RadialGradientBrush>
</TextBlock.Foreground>
Hello WPF
</TextBlock>
</Border>
</StackPanel>
</StackPanel>
</Window>
```

在 Listing 12.32 中，一个按钮控件被添加到窗口中。当你通过键盘上的 F5 键运行应用程序并点击按钮控件时，窗口上会出现一个 TextBlock 并带有滚动效果。这种效果是借助 DoubleAnimation 类的转换效果实现的。点击按钮控件后，代码的输出显示在图 12.35 中：

## 创建本地动画

你已经学会了如何使用 Storyboard 时间线通过 XAML 代码或代码后置文件的代码创建动画。有时你可以在不使用 Storyboard 对象的情況下创建动画。这种类型的动画称为本地动画。你可以使用 BeginAnimation 方法来应用无法在 XAML 代码中创建的本地动画。你可以在代码后置文件中创建本地动画。你应该在代码文件中添加 System.Windows.Media.Animation 命名空间以创建本地动画。让我们创建本地创建的动画。为此，创建一个名为 LocalAnimation 的 WPF 应用程序（也在 CD 上提供）并将 Listing 12.33 中给出的代码添加到 MainWindow.xaml 文件中：

### Listing 12.33: 创建本地动画

```
<Window x:Class="LocalAnimation.MainWindow"
xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
Title="MainWindow" Height="300" Width="300">
<Grid>
<Button Height="23" HorizontalAlignment="Left" Margin="25,31,0,0" Name="Button1" VerticalAlignment="Top" Width="91" Click="button1_Click">One Rotation</Button>
<Rectangle Margin="131,0,0,50" Name="rectangle1" Stroke="Black" Fill="Aqua" Height="66" VerticalAlignment="Bottom" HorizontalAlignment="Left" Width="72" />
<Button Height="23" HorizontalAlignment="Right" Margin="0,31,23,0" Name="button2" VerticalAlignment="Top" Width="75" Click="button2_Click">Forever</Button>
```
