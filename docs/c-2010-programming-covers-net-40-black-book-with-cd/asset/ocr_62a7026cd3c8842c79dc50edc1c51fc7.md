# Figure 37.4: Creating a New User

As shown in Figure 37.4, you can create a new user by entering the details in text boxes. When you click the Add button, the new created users are added to the Available Users list box. Now, select any existing user whose properties you want to update from the Available Users list box. The selected user’s property values are displayed in the appropriate text boxes. Since you cannot change the password, the password property is not visible for modification. Further, the user name is displayed in a read-only mode, since you cannot change the user name once created.
