# MenuStrip and StatusStrip Controls

The MenuStrip control represents the container control for containing the menu options of a form. The StatusStrip control displays the information about the object being viewed on the form. You can display the status of the application or the information about the object that is viewed on the Window. You can also learn about these controls in Bonus Chapter 5, Windows Forms Controls: ToolStrip, MenuStrip, ContextMenuStrip, StatusStrip, and Dialog Box Controls, on the CD. In this chapter, you learn about binding data from the data source to the control.

Let’s create a Windows Forms Application named MenuandStatusStrip (also available on the CD) and add a ListBox control, MenuStrip control, DataGridView control, a Button control, and a StatusStrip control. After adding the MenuStrip control, create two menus—File and Exit—as main menus. In addition, create OrderID, ProductID, Price, Quantity, and Discount as submenus of the File menu. Now, add the code provided in Listing 25.8 to the Form1.cs file, which is the code-behind file of your application:
