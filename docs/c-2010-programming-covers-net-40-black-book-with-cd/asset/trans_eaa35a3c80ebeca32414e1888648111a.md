## 枚举类型

枚举是使用 enum 关键字声明的用户定义整数数据类型。使用枚举，你可以定义一组命名的整型常量并将其赋给变量。例如，你可能有一个模拟交通灯的程序。交通灯有三种可能的状态——绿灯表示通行，黄灯表示准备停车，红灯表示停车。交通灯一次只能处于其中一种状态，这意味着交通灯一次只能是红、黄或绿。在这种情况下，你可以定义枚举类型变量并为其赋 3 个值。以下代码片段展示了如何创建枚举类型：

```
enum TrafficLight
{Red, Green, Yellow}
```

要使用枚举类型，你需要声明一个新枚举类型变量，如以下代码片段所示：

```
TrafficLight t1;
```

TrafficLight 枚举可以取三种值中的任意一个，Red、Green 和 Yellow；即枚举只能取在创建枚举类型时定义的值，如以下代码片段所示：

```
t1 = TrafficLight.Red;
t1 = TrafficLight.Green;
t1 = TrafficLight.Yellow;
```

枚举默认从第一个条目的 0 值开始。然而，你可以通过为第一个条目输入不同的值来修改此值，如以下代码片段所示：

```
enum TrafficLight
{
Red=1, Green, Yellow
}
```

## 引用类型

C# 还提供了作为引用传递给调用函数的类型，称为引用类型。引用对象的变量存储实际数据的引用。在引用类型中，对新副本所做的任何更改都会修改对象所引用的旧副本。引用类型使用堆来存储引用而不是实际数据。在 C# 中，堆称为托管堆，因为它管理和维护指向要分配下一个对象的地址的指针。最初，指针指向堆的基地址，当创建第一个引用时，内存会在基地址分配。当在应用程序中创建下一个对象时，垃圾收集器会在紧邻第一个对象之后的地址空间为其分配内存，并继续为所有新创建的对象分配内存。C# 提供了一些内置引用类型，如下所示：

- dynamic 类型 — 在运行时而不是编译时对 dynamic 类型变量进行类型检查。你可以在 dynamic 类型变量中添加任何类型的值。此类型类似于 object 类型；区别在于 object 类型变量的类型检查是在编译时执行的。以下代码片段展示了如何声明 dynamic 类型变量：

  ```
  dynamic dyn = 10;
  ```

- object 类型 — 使你能够将任何类型的值赋给 object 类型的变量。Object 是预定义 System.Object 类的别名。Object 类型是通用类型系统 CTS 中其他类型的终极基类，例如值类型、引用类型、预定义类型和用户定义类型。所有这些类型都是直接或间接从 object 类型派生的。Object 类型可以赋予任何其他类型的值，但在赋值前需要进行类型转换。当值类型转换为 object 类型时，该过程称为装箱，而相反地，当 object 类型转换为值类型时，该过程称为拆箱。以下代码片段展示了 object 类型的使用：

  ```
  object x;
  x=15; //boxing
  ```

  前述代码片段的第一行创建了一个 object 类型的变量 x，第二行将值 15 赋给 x 变量。将转换后的值赋给 object 类型的过程称为装箱

- string 类型 – 使你能够将字符串值赋给 string 类型的变量。String 类型是 System.String 类的别名。它是不变序列的 Unicode 字符，包含在双引号中。String 类型是直接从 object 类型派生的密封类类型。创建 string 类型的对象后，你无法更改其值。String 类型的值可以使用两种形式的字符串字面量进行赋值 – 引号和 @-引号。

  以下代码片段展示了如何为 string 类型赋值：

  ```
  string sname="C# 2010";
  ```

  在前述代码片段中，sname 是一个字符串变量，其值为 C# 2010。

  @-引号字符串字面量写在以 @ 字符为前缀的双引号内。这在以下代码片段中进行了说明：

  ```
  @"Kogent Learning Solutions Inc"
  ```

引用类型可以使用 class、interface 或 delegate 中的任何一个关键字声明。此外，引用类型还使用内置引用类型 – dynamic、object 和 string。让我们从 class 开始讨论这些关键字。

## 类

在 C# 中，所有类都是用户定义的数据类型，被视为对象。所有对象都派生自一个单一的基类，称为 System.Object。它将所有对象定义给系统并以相同的方式对待它们。当你将对象传递给函数时，你可以通过使用它们作为关键字来了解你正在处理的对象类型。

C# 中的所有应用程序都基于一个类。与 C++ 或 C 不同，你不能拥有一个独立运行的简单函数。所有 C# 控制台应用程序都包含一个单一的静态方法，称为 Main。列表 2.4 显示了基本 C# 应用程序中类的代码：

### 列表 2.4：显示基本 C# 应用程序中的类

```
class Greetings
{
    static void Main()
    {
        System.Console.WriteLine("Hello world from C#");
    }
}
```

在列表 2.4 中，我们定义了一个名为 Greetings 的简单类，通常驻留在名为 Greetings.cs 的文件中。编译后，它形成一个名为 Greetings.exe 的可执行文件，可从命令行运行。此可执行文件从 System 命名空间获取 Console 对象并调用该对象的静态 WriteLine() 方法。此方法将字符串 Hello world from C# 作为输出返回到控制台设备。

## 接口

接口定义了一组可与任何类或结构相关的功能。C# 中的接口类似于 Java 中的接口，但在实现上更灵活。如果你熟悉 C++，则 C# 中的接口相当于 C++ 中的抽象基类。需要注意的是，你不能通过接口实例化对象。当你创建接口时，你定义了一组实现特定任务的功能。

你可以以与任何其他类类似的方式声明接口。然而，它使用 interface 关键字将其与其他类区分开来。接口的行为类似于包含方法声明的模板。这些方法本质上是抽象的，即方法体中没有方法的实现。实现特定接口的类需要使用该接口的所有方法；否则，编译器不会编译代码并引发错误。

你可以使用以下语法在 C# 中声明接口：

```
interface Interface_name
{
    //abstract method declarations in interface body
}
```

在前述语法中，interface 关键字声明了名为 Interface_name 的接口。接口将在第 5 章 C# 2010 中的面向对象编程中详细讨论。

## 委托

委托几乎等同于 C++ 或 C 中的函数指针。C# 包含两种对象——那些产生变化的对象和那些响应变化的对象。委托充当两种对象之间的隧道——将信息从一侧移动到另一侧。C# 委托是类方法，可以是静态或实例类方法。委托可以通过在所属对象中维护信息来跟踪其自身状态。

你可以使用 delegate 关键字创建委托，如以下代码片段所示：

```
public delegate int IntDelegate(int a);
```

简单的委托类型不是方法或函数。事实上，它是函数指针的定义。你不能直接使用委托；你需要将一个函数与其关联。

现在，让我们创建一个使用委托从外部源完成内部任务的类，如列表 2.5 所示：

### 列表 2.5：显示使用委托的类的代码

```
public delegate int IntDelegate(int a); //creating a delegate
class Calculator
{
    public static int SquareNum(int num)
    {
        return num * num;
    }
}
class DelegateUser
{
    static void Main(string[] args)
    {
        Console.WriteLine("Demonstrating a Simple Delegate");
        IntDelegate delObj = new IntDelegate(Calculator.SquareNum); /*initializing and calling a delegate */
        Console.WriteLine("The square of 5 is {0}", delObj(5));
        Console.ReadLine();
    }
}
```

在列表 2.5 中，我们创建了一个名为 IntDelegate 的委托。接下来，我们声明了一个类型为 IntDelegate 的变量 delObj，为其分配了新对象，并通过传递 Calculator 类的 SquareNum() 方法调用了委托。

## 指针类型

保存另一个类型的内存地址的变量称为指针。指针类型用作声明为指针的变量的数据类型。在 C# 中，指针类型提供的功能与 C 和 C++ 语言提供的功能相同。指针和引用都表示内存地址，但区别在于引用由垃圾收集器跟踪，而指针则不会。在保持引用上下文中的类型安全和安全性的同时，C# 使用委托而不是指针。然而，你可以使用 unsafe 关键字定义一个不安全上下文，在其中可以自由使用指针。指针类型可以使用以下语法声明：

```
type* identifier;
```

以下代码片段展示了如何创建指针变量：

```
char* c;
int*[] x;
```
