## Using Windows Forms to Create Dialog Boxes

In a GUI environment, dialog box is a type of window that enables a communication between a computer and its user. It can be used for conveying the information to the user, or prompting the user for a response, or both purposes. The simplest form, in which a dialog box appears, is an alert that displays a message and may require an acknowledgment that the message has been read. An alert may also require a decision as to whether or not an action should be proceed, by clicking the OK or Cancel button.

In this section, you learn to perform the following tasks:

- Creating a dialog box
- Reading data from dialog boxes
- Creating the Accept and Cancel buttons in dialog boxes

Let’s discuss these in detail.

## Retrieving Data from Dialog Boxes

Figure 8.28 shows Form2 along with controls and their modified properties:

![](img/e073a4882197be4ab61103cbe0bcb394_318_0.png)

- 4. Add the following code snippet in the Click event of button1 of Form2:

```
public void button1_Click(object sender, EventArgs e)
{
    Form1 frm = new Form1();
    if (frm.ShowDialog() == DialogResult.OK)
    {
        textBox1.Text = frm.textBox1.Text;
    }
}
```

In the preceding code snippet, the text of the textBox1 control of Form1 will be displayed in the textBox1 control of Form2.

## Creating Owned Windows Forms

An owned form is tied to a form that owns it. When you minimize the owner form, the owned form is also minimized. You can add an owned form to an owner form in an application by using the AddOwnedForm method, and remove it by using the RemoveOwnedForm method. Let’s create an application named WinOwnedForm, to learn how to create an owned Windows Form.

Perform the following steps to create an owned form:

- 1. Create a Windows Forms application, WinOwnedForm.
- 2. Add a button control, button1, to Form1
- 3. Modify the Text property of Form1 to Owner Form, and button1 to Display Owned Form, as shown in Figure 8.32:

![](img/e073a4882197be4ab61103cbe0bcb394_320_0.png)

- 4. Add another Windows Form, called Form2, to the WinOwnedForm application.
- 5. Add a Label control, label1, to Form2.
- 6. Modify the Text property of Form2 to Owned Form, and the Modifiers property of label1 to Internal, as shown in Figure 8.33:

![](img/e073a4882197be4ab61103cbe0bcb394_320_1.png)

7. Add the following code snippet in the Click event of button1 of Form1:

```
private void button1_Click(object sender, EventArgs e)
{
    Form2 OwnedForm1 = new Form2();
    this.AddOwnedForm(OwnedForm1);
    OwnedForm1.label1.Text = "This is an Owned form";
    OwnedForm1.Show();
}
```

8. Press the F5 key to run the application. The output appears, as shown in Figure 8.34:

![](img/e073a4882197be4ab61103cbe0bcb394_321_0.png)

Figure 8.34: Displaying the Output of WinOwnedForm Application

Figure 8.35: Displaying an Owned Form
