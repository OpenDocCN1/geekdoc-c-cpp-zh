# Lights

After adding model and material to the scene, you need to add a light source to the scene to make it visible. The Light class is used for the light effects in WPF and these effects are calculated for objects individually. It reflects from one object does not reflect off another object. In the same way, an object does not cast its shadow on another object, no matter where it is placed. The Light class is the abstract base class for using light in WPF, which provides following four classes for the implementation of light in WPF:

+   - The DirectionalLight class—Illuminates light, for instance a distant light source. The DirectionalLight class lights the object that projects its effect along a direction specified by the Vector3D. The light specified by the DirectionalLight class comes from one side and you can see the edges and shadow. You can take the example of sunlight in the context of the DirectionalLight class.
+   - The AmbientLight class—Provides an unnatural light that lights the scene with scattered light. The AmbientLight class lights the object uniformly regardless of the shape, location, or orientation.
+   - The PointLight class—Radiates light in all directions, beginning at a single point. The PointLight class has a position and they point the light from that position. The objects in the scene are illuminated depending on their position and distance with respect to the light. The Range property of the PointLight class determines the distance beyond which the models need not be illuminated by light.
+   - The SpotLight class—Radiates light outward in a cone style starting from a single point. The SpotLight class inherits from the PointLight class. The InnerConeAngle and OuterConeAngle properties specify the area of the projection of the light in the cone shaped area.

# Animation in WPF 4.0

Animation in WPF allows you to create dynamic UI. You can apply different effects using animation, such as growing icons or scrolling text. Animations in WPF can be used in many ways to enhance applications. In WPF, you can create animations and also put them into action without writing a single line of code, i.e., you can create animations declaratively. For instance, you create an application that uses a timer, which fires periodically. When the timer fires, you need to use an event handler to calculate the animation related details. WPF notices the change you have made to the elements in your window. It then repaints the new window content. WPF includes an efficient timing system through the managed code and XAML.

In WPF, you animate objects by applying animations to their individual properties. For example, to make an element grow, you animate its Height and Width properties. A property can have the animation capabilities if it meets the following requirements:

+   - Must be a dependency property
+   - Must belong to a class that inherits from the DependencyObject class and implements the IAnimatable interface
+   - Must be a compatible animation type

The System.Windows.Media.Animation namespace is the base namespace for all animations in WPF. In this section, you learn about:

+   - Types of animation
+   - Essentials of animation
+   - Event triggers and animation
+   - KeyFrames
