# Using the HyperLink Control

When you add a HyperLink control to a Web page (Default.aspx), it adds the following code to the source code of the Web page:

```
<asp:HyperLink ID="HyperLink1" runat="server">HyperLink</asp:HyperLink>
```

Let's create a Web application named HyperLinkControl (also available on the CD-ROM). In this example, we have set the NavigateUrl property of the Hyperlink control to http:\www.google.co.in Web page. Listing 14.7 shows the Default.aspx page for the HyperLink controls:
