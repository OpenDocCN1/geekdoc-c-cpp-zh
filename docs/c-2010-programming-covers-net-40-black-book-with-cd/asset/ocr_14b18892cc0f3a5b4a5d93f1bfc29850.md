# Using Multimedia in WPF 4.0

After graphics and animation, another rich way of conveying information is multimedia. It is that part of WPF which not only gives rich UI, but also conveys your message in a better way. Multimedia allows you to play both audio and video files in WPF. You can integrate multimedia with animations and create a graphically rich looking interface. You can create effects, such as placing a video window on a sipping 3-D cube. You have learned about multimedia in detail in the In Depth section of the chapter. You learn about the practical application and how to use multimedia in WPF in this section.
