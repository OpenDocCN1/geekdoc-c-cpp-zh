# Exploring Classes and Objects

Classes allow you to control all the functions that can be applied to a given set of data as well as how to access the data. Classes also give you the ability to extend a runtime environment and allow the developer to reuse the existing functionalities of the runtime environment. Suppose you need to create an object of a class, named student, in your program. To do so, you first need to create a Student class that contains all the functionalities or behaviors of any student and then use that class to create the objects as needed.

In this section, you explore the following:

+   - Syntax of a class
+   - Using methods as class members
+   - Access modifiers
+   - Using objects to access the class members
+   - Constructors and destructors
+   - Static classes and static class members, properties, and indexers

Let’s start with the syntax of a class first.

# Syntax of a Class

The basic syntax of the class structure is shown in the following code snippet:

```
class <className>
{
    <access-modifier> [static] <return-type> MethodName(<signature>);
    <access-modifier> [static] <variable type> variableName;
}
```

The basic syntax for declaring an object is shown in the following code snippet:

```
<className> <ObjectName> = new <className>();
```

You can also declare partial classes in your applications. The partial class is a class that enables you to specify the definition of a class, structure, or interface in two or more source files. All the source files, each containing a section of the class definition, combine when an application compiles. You may need a partial class when developers are working on large projects. A partial class distributes a class over multiple separate files, allowing developers to work on the class simultaneously. Using the partial keyword, you can declare a class as partial, as shown in the following code snippet:

```
public partial class student
{
    public void avgMarks() { }
}
public partial class student
{
    public void calrank() { }
}
```

The partial keyword specifies that other sections of the class, structure, or interface, are defined within the namespace.

# Methods as Class Members

Now that you are familiar with the importance of using classes, let’s move on to discuss members of a class—Class Methods and Class Variables. Members of a class are the elements that are declared in the class. The following code snippet shows the syntax to declare the members of a class (methods and variables):

```
class Square
{
    int side;
    public int area()
    {
        return ( side * side);
    }
}
```
