## FlowDocumentPageViewer 控件

FlowDocumentPageViewer 控件将 Flow 文档拆分为多个页面，并允许您以固定查看模式查看流内容。在固定查看模式下，在特定时刻只显示一个页面。当您使用 FlowDocumentPageViewer 控件显示 Flow 文档中的内容时，页面分为两个部分：内容区域和工具栏。内容区域显示由 Document 属性指定的 FlowDocument 的内容。工具栏进一步分为以下三个部分：

- **页面导航控件**——包含一个按钮，可分别使用向下箭头或向上箭头移动到下一页或上一页。它还包含当前页码和总页数的指示器。
- **缩放控件**——允许您通过单击加号或减号按钮来增加或减少缩放级别。它还提供了一个用于调整缩放级别的滑块。
- **搜索 TextBox 文本框**——帮助您查找包含内容的字符串。键盘快捷键 CTRL+F 也用于查找包含内容的字符串。

FlowDocumentPageViewer 控件的继承层次结构如下：

```
System.Object
    System.Windows.Threading.DispatcherObject
        System.Windows.DependencyObject
            System.Windows.Media.Visual
                System.Windows.UIElement
                    System.Windows.FrameworkElement
                        System.Windows.Controls.Control
                            System.Windows.Controls.Primitives.DocumentViewerBase
                                System.Windows.Controls.FlowDocumentPageViewer
```

FlowDocumentPageViewer 控件可以添加到 WPF 应用程序中，如以下代码片段所示：

```
<FlowDocumentPageViewer>
<!--Document-->
</FlowDocumentPageViewer>
```

## FlowDocumentReader 控件

FlowDocumentReader 控件结合了 FlowDocumentScrollViewer 和 FlowDocumentPageViewer 控件的功能。它允许您选择以可滚动模式还是页面查看模式阅读内容。当您使用 FlowDocumentReader 控件显示内容时，页面分为两个部分：内容区域和工具栏。内容区域显示由 Document 属性指定的 FlowDocument 的内容。工具栏分为以下几个部分：

- 查找按钮 — 允许您搜索文档的内容。如果 IsFindEnabled 属性设置为 False，则不显示“查找”按钮。
- 页面导航控件 — 包含一个用于移动到下一页或上一页的按钮。它还具有当前页码和总页数的指示器。
- 查看模式按钮 — 包含三种查看模式：页面模式、双页模式或滚动模式。可以根据需求和偏好选择其中任何一种模式。
- 缩放控件 — 允许您通过单击加号或减号按钮来增加或减少缩放级别。它还包括用于调整缩放级别的滑块。

> 注意
> FlowDocumentReader 控件的默认工具栏不包含“打印”按钮。

FlowDocumentReader 控件的继承层次结构如下：

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
System.Windows.Controls.Control
System.Windows.Controls.FlowDocumentReader
```

您可以将 FlowDocumentReader 控件添加到 WPF 应用程序中，如以下代码片段所示：

```
<FlowDocumentReader>
<!--Document-->
</FlowDocumentReader>
```

## RichTextBox 控件

RichTextBox 控件允许您修改其内容。它主要用于编辑格式化文本、图像或表格。RichTextBox 控件表示一种在 FlowDocument 对象上操作的富编辑控件。该控件支持多种编辑命令，如表 11.17 所示：

### 表 11.17：RichTextBox 控件的编辑命令

| 编辑命令 | 键手势 |
|---|---|
| AlignCenter | CTRL+E |
| AlignJustify | CTRL+J |
