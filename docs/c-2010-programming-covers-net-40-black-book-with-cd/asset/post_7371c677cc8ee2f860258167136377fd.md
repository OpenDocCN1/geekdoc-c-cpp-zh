
Silverlight 3.0 has the conventional controls, such as Button, TextBox, RadioButton, and ScrollBar and shape controls or elements, such as Ellipse, Rectangle, and Line. However, Silverlight 3.0 also offers some unique controls, such as Calendar, DatePicker, and TabControl. These controls assist you in giving a dynamic, interactive, and engrossing UI for your Silverlight-based Web applications. Silverlight 3.0 now includes most of the controls that used to be offered by the Silverlight runtime (plug-in) in its previous versions, such as Silverlight 2.0 or were a part of Silverlight SDK. In other words, it means that to use controls, such as DatePicker, GridSplitter, and TabControl, you had to reference the appropriate assemblies and namespaces. However, with Silverlight 3.0, you can simply drag and drop these controls into your Silverlight application interface and the appropriate assemblies and namespaces are automatically added to your Silverlight application.

Silverlight 3.0 includes some new controls, such as the MultiScaleImage control, which allows you to view and change the size and position of a multi-resolution image. The MultiScaleImage control has its prime use with the Deep Zoom technology. Silverlight 3.0 also incorporates the ToolTipService property for the Silverlight 3.0 controls, such as HyperlinkButton and Button controls. The ToolTipService property replaces the ToolTip control in Silverlight 2.0 Beta 1.

> NOTE
> The Silverlight 3.0 controls indirectly inherit the FrameworkElement class, which itself derives from the UIElement class. Therefore, the properties, methods, and events defined by the FrameworkElement class and its base class are available to the Silverlight controls.

## The Calendar Control

The Calendar control provides you with the facility to work with dates, days, months, and years. This control displays the years, months, and days to allow the users to select a particular date from the visible month or year. You can switch between months, years, or decades by using scroll arrows, specify the range of dates that are visible and selectable by the users, and hide a particular range of dates in the Calendar control. In addition, you can modify the look and feel of the Calendar control by manipulating the properties of the control. Figure 17.9 shows a Calendar control:

The Calendar control is an instance of the Calendar class, which exists in the System.Windows.Controls.dll assembly in the System.Windows.Controls namespace. The class hierarchy of the Calendar class is:

```
System.Object
  System.Windows.DependencyObject
    System.Windows.UIElement
      System.Windows.FrameworkElement
        System.Windows.Controls.Control
          System.Windows.Controls.Calendar
```

There are various properties that you can use to work with the Calendar class (or control). Most of these properties are dependencies and attached properties. Table 17.3 lists some of the noteworthy properties of the Calendar class:

Table 17.3: Noteworthy Properties of the Calendar Class
| Property | Description |
|---|---|
