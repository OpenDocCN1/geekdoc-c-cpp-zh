# Listing 33.4: Showing the Code for Setting the Probing Attribute

```
...
<assemblyBinding xmlns="urn:schemas-microsoft-com:asm.v1">
  <publisherPolicy apply="yes" />
  <probing privatePath="SubDir" />
</assemblyBinding>
...
```

In Listing 33.4, the application is configured to look for the referenced assembly in a subfolder called SubDir in the bin\Debug folder.
