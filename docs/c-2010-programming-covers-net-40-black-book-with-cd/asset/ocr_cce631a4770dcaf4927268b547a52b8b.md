Note that the margin lines appear only when the control is selected. You may notice in Figure 9.18 that only the Button control is selected and its top, and left margin lines appear. Instead, there is a small circle, called the margin stub, on the right and bottom edges of the Button control. The margin stub at the right and bottom edges indicate that the respective margins are set to zero, i.e. the margins are not set for the respective edges. If you click a margin stub, the margin is automatically set for that edge and the margin line appears. Similarly, if you click a margin line, then it changes to a margin stub.

The margins for a control are collectively accessed through the Margin property of the control. You can set the Margin property of a control in the Design view, XAML view, or code-behind file. You can set the Margin property in the Design view by selecting and dragging the control. You can also use the Properties window (discussed later in the chapter) to set the Margin property by typing the margin values. You need to provide the margin values in a clockwise manner starting from the left margin, that is, left, top, right, and bottom, as shown in Figure 9.19:
