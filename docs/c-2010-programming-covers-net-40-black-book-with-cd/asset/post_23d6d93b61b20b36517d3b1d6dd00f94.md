The Edit breakpoint labels dialog box opens, where you can add one or more break point labels by clicking the Add and OK buttons.

Figure 1.30 shows how to add a break point label using the Edit breakpoint labels dialog box:

![](img/e073a4882197be4ab61103cbe0bcb394_70_1.png)
