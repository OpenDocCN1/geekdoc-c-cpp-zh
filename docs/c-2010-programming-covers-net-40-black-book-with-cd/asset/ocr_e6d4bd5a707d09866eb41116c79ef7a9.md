# The FixedDocument Class

The FixedDocument class hosts a portable, high fidelity, and fixed-format document. It has read access for user text selection, keyboard navigation, and search facilities. The FixedDocument class is contained in the System.Windows.Documents namespace. The only allowed child element of FixedDocument class is the PageContent class.

The inheritance hierarchy of the FixedDocument class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.ContentElement
        System.Windows.FrameworkContentElement
          System.Windows.Documents.FixedDocument
```
