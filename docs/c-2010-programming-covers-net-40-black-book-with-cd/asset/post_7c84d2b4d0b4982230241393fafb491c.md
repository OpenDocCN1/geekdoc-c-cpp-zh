NOTE

In ASP.NET 4.0, the RadioButtonList and the CheckBoxList control has been improved. In the previous version of ASP.NET, you could specify the layout for the controls by specifying either of the following two values for the RepeatLayout property:

- Table: Specifies that the items are displayed in a table structure.
- Flow: Specifies that the items are displayed without a table structure. The markup code consists of the span element and the various items are separated by the br element.

Now, in ASP.NET 4.0, two new values can be specified for the RepeatLayout property:

- UnorderedList: Specifies that the items are displayed without a table structure. The markup code consists of the ul element which contains the li element.
- OrderedList: Specifies that the items are displayed without a table structure. The markup code consists of the ol element which contains the li element.

You should note that if you set the RepeatLayout property to either OrderedList or UnorderedList, you cannot use the RepeatDirection property. If you set the RepeatDirection property in such a situation, it will throw an exception at runtime.

You will learn about the usage of the new values of the RepeatDirection property in the Immediate Solutions section of the chapter.

## The ListBox Control

The ListBox control is a standard Web server control used to select one or more items from a list of items on a Web page at runtime. The inheritance hierarchy for the ListBox class is:

```
System.Object
  System.Web.UI.Control
    System.Web.UI.WebControls.WebControl
      System.Web.UI.WebControls.BaseDataBoundControl
        System.Web.UI.WebControls.DataBoundControl
          System.Web.UI.WebControls.ListControl
            System.Web.UI.WebControls.ListBox
```

You can use the Rows property of the ListBox control to specify the height of the control. To enable multiple item selection, you can set the SelectionMode property to ListSelectionMode.Multiple. You can find the selected item in a single-selection ListBox control with the help of SelectedItem and SelectedIndex properties. The SelectedItem property returns the selected item as a ListItem object, which supports Text, Value, and Selected properties. In multiple-selection ListBox control (which implies that we are selecting multiple items from a single ListBox control), the loop runs over the selected items in the ListBox controls and returns each selected item as a ListItem object by using the SelectedIndex property.

The ListBox class inherits the ListControl class; moreover, it does not have any non-inherited events. The ListControl class does not have any non-inherited methods either. Note that the Items property of the ListControl class returns a collection of ListItem objects, which you can use to access an item in a ListBox. | BorderWidth | Obtains or sets the border width for the control |
| Rows | Obtains or sets the number of rows displayed in the ListBox control |
| SelectionMode | Obtains or sets the selection mode of the ListBox control |
