# The StatusBar Control

The StatusBar control displays items and information in a horizontal bar. It is primarily used to display text and image indicators. You can divide the items in a StatusBar control by using the Separator control. You can display text, graphics, or other complex elements in a StatusBar control. The items in the StatusBar control are defined as StatusBarItem objects. The events that are defined on the StatusBarItem objects are raised when a user clicks the items in the StatusBar control. You cannot access the StatusBar control with the keyboard.

The StatusBar class represents the StatusBar control. The inheritance hierarchy of the StatusBar class is as follows:
