## 强命名程序集

强名称，如组件对象模型（COM）组件的全局唯一标识符（GUID），充当唯一标识程序集的 ID。正如前面所学，.NET 附带了一个名为 sn.exe 的命令行实用程序，可帮助为程序集创建唯一 ID。要使用 sn.exe 为程序集创建强名称，请执行以下步骤：

- 1. 通过选择 开始→所有程序→Microsoft Visual Studio 2010→Visual Studio 工具→Visual Studio 命令提示符（2010）打开 .NET 控制台窗口，并输入以下命令：
- sn -k AKey.snk

前面的命令在当前目录下创建了一个名为 AKey.snk 的强名称密钥对文件。

> NOTE
> Visual Studio 命令提示符（2010）将系统驱动器（C:）显示为当前目录。你无法在系统驱动器中创建强名称。更改当前目录，然后创建强名称。

- 2. 通过在解决方案资源管理器中右键单击应用程序名称并选择 添加→现有项，将 AKey.snk 文件添加到 SharedObject 应用程序中。

- 3. 在添加现有项对话框中选择该文件并单击 添加 按钮。

- 4. 打开 AssemblyInfo.cs 文件以提及我们刚刚创建的密钥对文件。此文件位于解决方案资源管理器的 Properties 文件夹中。

- 5. 如清单 33.6 所示，在 AssemblyKeyFile 属性中提及密钥对文件：

### Listing 33.6: Showing the Elements of the AssemblyInfo.cs File

```
[assembly: AssemblyKeyFile("AKey.snk")]
[assembly: AssemblyTitle("Sharedobject ")]
[assembly: AssemblyDescription("")]
[assembly: AssemblyConfiguration("")]
[assembly: AssemblyCompany("Kogent Learning Solutions Inc")]
[assembly: AssemblyProduct("Sharedobject")]
[assembly: AssemblyCopyright("Copyright © Kogent Learning Solutions Inc 2010")]
[assembly: AssemblyTrademark("")]
[assembly: AssemblyCulture("")]
```

在 AssemblyInfo.cs 文件中指定强名称密钥对文件允许编译器将强名称信息添加到你的程序集中。

> TIP
> 你也可以通过项目属性页下的 签名 选项卡创建并指定强名称。

## 创建共享程序集的新版本

让我们现在创建 SharedObject 类库的新版本并配置客户端应用程序在不重新编译的情况下使用此新版本。为此，你首先需要修改 Greeting 函数。清单 33.8 显示了修改 SharedObject 类库的 Greeting 函数的代码：

### Listing 33.8: Showing the Code to Modify the Greeting Function

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace SharedObject
{
    public class SharedObject
    {
        public string Greeting(string name)
        {
            return ("New SharedObject says Hi: " + name);
        }
    }
}
```

为了在 CLR 中反映新版本信息，你需要更新 AssemblyInfo.cs 文件。AssemblyInfo.cs 文件中的版本信息可以使用以下代码行更新：

```
[assembly: AssemblyVersion("1.1.0.0")]
```

创建 SharedObject 类库的新版本后，让我们现在学习如何在 ASimpleClient 应用程序中使用此新版本。
