

# 使用基于角色的安全性来验证和授权用户

如今，大多数现代操作系统都自带自己的安全系统，允许你验证用户。在许多情况下，底层操作系统的安全系统已足以满足你的 .NET 应用程序的安全需求。然而，在某些情况下，该安全系统可能无法为你的应用程序提供所需的安全级别。在这种情况下，你可以采用基于角色的安全性，为你的应用程序提供额外的安全保障。通过基于角色的安全性，你不仅可以保护整个应用程序，还可以保护应用程序中的各个类和方法。

让我们先了解一下 Windows 操作系统的安全基础设施是如何工作的，然后再了解基于角色的安全性在其中扮演的角色。为此，你需要创建两个应用程序——一个需要被保护的应用程序，另一个请求被保护的应用程序。你需要使用管理员账户创建被保护的应用程序，并设置权限，使其在特定 Windows 用户账户（例如 TestUser）下无法访问。然后，你需要在同一台计算机上使用被拒绝的用户账户创建请求应用程序，并尝试访问被保护的应用程序。你会注意到请求应用程序无法访问被保护的应用程序。

现在让我们在 Windows Vista 上使用管理员用户账户创建一个名为 MyLogo 的 WPF 用户控件库应用程序（可在 CD-ROM 上获得）。MyLogo 应用程序是需要被保护的应用程序。要创建 MyLogo 应用程序，请执行以下步骤：

- 3. 编译应用程序。在编译 MyLogo 应用程序后，你需要为一个或多个用户设置权限。请注意，Windows 操作系统使用访问控制列表（ACL）为所有文件、文件夹和其他资源设置权限。ACL 是用户列表及其对特定资源拥有的权限。

正如你在图 36.18 中看到的，当 TestUser 尝试访问 MyLogo 应用程序（即 MyLogo 程序集）时，不允许这样做。这是因为你拒绝了 TestUser 用户访问 MyLogo 程序集的所有权限。请注意，除了 TestUser 之外的任何用户都可以访问 MyLogo 应用程序，因此也可以更改 MyLogo 以及 Invoice 应用程序。假设还有另一个名为 DummyUser 的用户具有访问 Invoice 和 MyLogo 应用程序的权限。这意味着当 DummyUser 登录到你的计算机并尝试在 Invoice 应用程序中添加对 MyLogo 程序集的引用时，不会出现错误。

12. 在 Invoice 应用程序的 Form1.cs 文件中添加 Listing 36.4 中给出的代码：

## Listing 36.4: 添加代码以使用 MyLogo 应用程序

```
using System;
using System.Collections.Generic;
using System.ComponentModel;
using System.Data;
using System.Drawing;
using System.Linq;
using System.Text;
using System.Windows.Forms;
using System.Windows.Forms.Integration;

namespace Invoice
{
    public partial class Form1 : Form
    {
        public Form1()
        {
            InitializeComponent();
        }

        private void Form1_Load(object sender, EventArgs e)
        {
            ElementHost eh = new ElementHost();
            MyLogo.UserControl1 uc1 = new MyLogo.UserControl1();
            eh.Child = uc1;
            eh.Height = eh.Width = 30;
            panel1.Controls.Add(eh);
        }
    }
}
```

在 Listing 36.4 中，System.Windows.Forms.Integration 命名空间的 using 指令包含在 Invoice 应用程序中。在 Form1_Load() 方法中，创建了 ElementHost 和 MyLogo.UserControl1 的对象。ElementHost 对象 eh 的 Height 和 Width 属性被设置为 30，并且 UserControl1 对象 uc1 通过使用 Child 属性托管在 ElementHost 对象内部。最后，该对象被添加到 panel1 面板的 Controls 集合中。
