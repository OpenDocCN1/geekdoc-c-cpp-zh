# Transforming a Video in MediaElement

In WPF, you can transform the MediaElement control, which means that you can rotate the MediaElement control to display the video in the angle you need. You can use the TransformGroup class to apply the rotate and scale transformations on a MediaElement control using the RotateTransform or ScaleTransform class, respectively. Let’s create an application to apply a rotate transformation to the MediaElement control. You should create a WPF application named TransformingVideo (also available in CD) and add the code, given in Listing 12.53, to the MainWindow.xaml file:

Listing 12.53: Transforming Video in MediaElement

```
<Window x:Class="TransformingVideo.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="350" Width="525">
    <Grid>
        <MediaElement Source="d:\wmvfiles\Clip_1080_5sec_vc1_15mbps.wmv" Margin="41,0,27,36" Name="myMedia" LoadedBehavior="Manual">
            <MediaElement.LayoutTransform>
                <TransformGroup>
                    <RotateTransform Angle="400" />
                </TransformGroup>
            </MediaElement.LayoutTransform>
        </MediaElement>
        <Button Height="23" Margin="104,0,99,18" Name="button1" VerticalAlignment="Bottom" Click="button1_Click">Play</Button>
    </Grid>
</Window>
```

In Listing 12.53, the MediaElement control is added to the window. The MediaElement control is added to the application which is transformed using the RotateTransform class. A Button control is added to the application and the code is added on the Click event of the Button control for the media file to play.
