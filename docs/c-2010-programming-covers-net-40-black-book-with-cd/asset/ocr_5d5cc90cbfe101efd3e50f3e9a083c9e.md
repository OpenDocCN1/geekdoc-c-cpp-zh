# Figure 17.2: Displaying the Silverlight Project Templates in Visual Studio 2010

You can see that the Installed Templates pane has a Silverlight option and when you click this option, it offers you the three templates, Silverlight Application, Silverlight Class Library, and Silverlight Navigation Application (Figure 17.2). The Silverlight Application template allows you to create Web applications that incorporate Silverlight, while the Silverlight Class Library template allows you to create reusable libraries (.dll) of classes. The Silverlight Navigation Application template enables you to develop XAML page-based Web applications and navigate between different XAML pages of a Web application.

You can create Silverlight applications by specifying a name and location for the application in the New Project dialog box that appears when you select File→New→Project in the Visual Studio 2010 IDE.
