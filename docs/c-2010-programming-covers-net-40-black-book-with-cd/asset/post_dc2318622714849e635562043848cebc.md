### Listing 23.9: Showing the Code of the InsertPersonalDetailsTrg.cs File

```
using System;
using System.Data;
using System.Data.SqlClient;
using Microsoft.SqlServer.Server;
using System.Text.RegularExpressions;
public partial class Triggers
{
    // Enter existing table or view for the target and uncomment the attribute line
    [Microsoft.SqlServer.Server.SqlTrigger(Name = "InsertPersonalDetailsTrg", Target = "PersonalDetails_TBL", Event = "FOR INSERT")]
    public static void InsertPersonalDetailsTrg()
    {
        SqlTriggerContext triggContext = SqlContext.TriggerContext;
        if (triggContext.TriggerAction == TriggerAction.Insert)
        {
            var conn = new SqlConnection("Context Connection=true");
            var cmd = new SqlCommand();
            cmd.Connection = conn;
            cmd.CommandText = "SELECT UserName FROM INSERTED";
            conn.Open();
            string uname = (string)cmd.ExecuteScalar();
            conn.Close();
            if (!Regex.IsMatch(uname, @"([\w-]+\.)*?[\w-]+@[\w-]+\.([\w-]+\.)*?[\w]+$"))
            {
                throw new FormatException("Invalid user name");
            }
        }
```

```
else
    SqlContext.Pipe.Send("Trigger FIRED");
}
}
```

In Listing 23.9, we are creating a user-defined trigger, called InsertPersonalDetailsTrg, on a table, PersonalDetails_TB1, for INSERT operation. This trigger checks whether the provided user name for the UserName column of the PersonalDetails_TB1 table, is in the proper format or not. If the provided user name is in proper format then a message, Trigger FIRED, is displayed; otherwise, the Invalid user name message is displayed along with a runtime exception.

## Creating and Using User-Defined Aggregate Functions

In this section, you learn to create a user-defined aggregate function as a CLR object in .NET Framework. To do this, you need to add an aggregate function CLR object in SQL Server project. Let’s create a SQL Server project, named SqlServerProjectAgg (also available on CD), and add an Aggregate template, MyAgg_Total.cs, to it.

Perform the following steps to create the SqlServerProjectAgg project in Visual Studio 2010:

- 1. Open Microsoft Visual Studio 2010.
- 2. Create a Visual C# SQL CLR Database Project, named SqlServerProjectAgg.
- 3. Select an existing database connection or create a new one. In our case, we are selecting the existing database connection, charu-pc.Northwind.dbo.
- 4. Click the OK button. The SqlServerProjectAgg project is displayed in Visual Studio 2010.
- 5. Right-click the SqlServerProjectAgg project in Solution Explorer and select the Add→Aggregate option. The Add New Item- SqlServerProjectAgg dialog box opens (Figure 23.17).
- 6. Select the Aggregate template and either use the default name or enter a new name. In our case, we are entering the name, MyAgg_Total.cs, in the Name text box, as shown in Figure 23.17:

![](img/e073a4882197be4ab61103cbe0bcb394_1160_2.png)

Figure 23.17: Entering an Aggregate Name

7. Click the Add button (Figure 23.17). The MyAgg_Total.cs file is added to the SqlServerProjectAgg project.

8. Modify the code of the MyAgg_Total.cs file, as given in Listing 23.11:

### Listing 23.11: Showing the Code of the MyAgg_Total.cs File

```
using System;
using System.Data;
using System.Data.SqlClient;
using System.Data.SqlTypes;
using Microsoft.SqlServer.Server;

[Serializable]
[Microsoft.SqlServer.Server.SqlUserDefinedAggregate(Format.Native)]
public struct MyAgg_Total
{
    int total;
    public void Init()
    {
        total=0;
    }
    public void Accumulate(SqlInt32 Value)
    {
        total+=Value.Value;
    }
    public void Merge(MyAgg_Total Group)
    {
        total+=Group.total;
    }
    public SqlInt32 Terminate()
    {
        return new SqlInt32(total);
    }
}
```

In Listing 23.11, we are creating a user-defined aggregate function, called MyAgg_Total, which is made up of the Init(), Accumulate(), Merge(), and Terminate() contract methods. There is a variable, total, of int type, which is initialized in the Init() method. Next, the value of the total variable is added in the Accumulate() and Merge() methods. Finally, the value stored in the total variable is returned by the Terminate() method.

After creating an aggregate function as a CLR object, you can use it either directly in T-SQL or in .NET Framework 4.0. The following query is used to create an assembly, SqlServerProjectAgg, and an aggregate, MyAgg_Total, to invoke the created aggregate CLR object:
