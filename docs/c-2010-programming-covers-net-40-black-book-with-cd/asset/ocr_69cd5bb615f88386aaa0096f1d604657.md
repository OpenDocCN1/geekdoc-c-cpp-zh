# Figure 21.8: Displaying the Prerequisites Dialog Box

In Figure 21.8, you can see a list of available prerequisites for the deployment of applications. You must select the prerequisites that you want to install and then click the OK button to include the perquisites in the installer.

In Visual Studio 2010, the deployment tools have the capability to automatically detect the existence of components that are required for the execution of an application during installation and install a set of prerequisites for the successful execution of the application. This process is known as bootstrapping and performed by the bootstrapper component that installs the prerequisite components on a target computer by using the bootstrapper package. In addition, a bootstrapper package consists of a group of files and directories of manifest files that describe how the prerequisites are installed on a target computer.
