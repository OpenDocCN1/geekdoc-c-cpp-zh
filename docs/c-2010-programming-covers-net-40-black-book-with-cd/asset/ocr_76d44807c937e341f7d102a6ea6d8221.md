# Using the Set Operators

The Set operators in LINQ are used to perform the mathematical set-type operations on the sequences. There are four different types of Set operators used in LINQ, Distinct, Union, Intersect, and Except. You have already learned about them in the In Depth section of the chapter. In this section, you learn about the Intersect clause which returns the set intersection of the two source sequences. Let’s create an application in which you can use the Intersect clause.
