
- Back — Navigates to the previously selected items until you reach the first item.
- Forward — Navigates to the next item until you reach the most recently selected item.
- Class View Settings — Helps in making different settings using this tool. The various commands available in Class View Settings are as follows:
  - Show Base Types — Displays the base types in the Objects pane.
  - Show Project References — Displays a virtual folder that displays objects placed in the project references.
  - Show Hidden Types and Members — Displays hidden types in the Objects pane and hidden members in the Members pane.
  - Show Public Members — Displays public members for users who are using the classes.
  - Show Protected Members — Displays the protected members for the users who are extending the classes.
  - Show Private Members — Displays members of all accessibility levels for users who are implementing and using the classes.
  - Show Other Members — Displays members that do not fall in the categories of public, private, protected, or inherited
  - Show Inherited Members — Displays inherited members in the Members pane.
- View Class Diagram — Displays class details of the currently selected object. When you select an object in the Objects pane, you can get the class diagram by clicking this button in the toolbar.

## The Properties Window

The Properties window is used to view and modify the design-time properties and events of selected objects. This window also enables you to edit the properties of the controls that you add to forms. For example, to view and modify the properties of a form, open the designer and select the form. The Properties window can be opened in either of the following ways:

- By selecting View→Properties Windows from the main menu
- By pressing the F4 key

Figure 1.57 displays the Properties window of a form:

![](img/e073a4882197be4ab61103cbe0bcb394_86_0.png)

Figure 1.57: Displaying the Properties Window

If you want to view and modify the properties of other components, such as buttons or labels, then drag these components on the form and select the component whose properties you want to modify. When you select the appropriate component, the properties associated with that component are displayed in the Properties window. The properties displayed in the Properties window are different for different components or controls. In other words, the properties associated with a Button control are different from the properties associated with a Label or a Form control. Note that some properties in the Properties window appear in gray text. The properties appearing as gray are the read-only properties.

The Properties window also displays a toolbar containing various buttons. These buttons are explained, starting from left to right, as follows:

- Categorized – Enables you to group the properties of a control into categories. The properties are categorized depending upon the function that they perform in a control. For example, when you select a form in Solution Explorer and click the Categorized button on the toolbar, the Form properties are grouped into Accessibility, Appearance, Behavior, Data, Design, Focus, Layout, Misc., and Window Style categories.

- Alphabetical – Displays the properties of a control in the alphabetical order.

- Properties – Displays all the properties of a control.

- Events – Displays all the events of a control.

- Property Pages – Displays the Property Pages dialog box for the selected component. You can use the Property Pages dialog box to view and edit properties related to the configuration of the project.

## The Object Browser Window

The Object Browser window is used to examine and find out objects, such as namespaces, classes, structures, types, interfaces, and enums along with their members, such as properties, methods, events, variables, constants, and enums. The Object Browser window can be opened in either of the following ways:

- By selecting View→Object Browser from the main menu
- By pressing Ctrl+Alt+J keys

Figure 1.58 shows the Object Browser window:

![](img/e073a4882197be4ab61103cbe0bcb394_87_0.png)

Figure 1.58: Displaying the Object Browser Window

Figure 1.58 displays the following three panes of the Object Browser window.

- Objects pane – Displays the hierarchical structures, such as .NET Framework and COM components, namespaces, type libraries, interfaces, and classes. The top-level nodes in the Objects pane represent

components or namespaces available within the current browsing scope. To expand these nodes, click the (▸) symbol placed beside the node.

- Members pane — Displays the members of the item selected in the Objects pane. The Members pane contains members, such as properties, methods, events, constants, variables, and enum values.

- Description pane — Displays the description of the item selected in the object pane. The Description pane displays detailed information about an object or member that is currently selected.

The Object Browser window also contains the following buttons in its toolbar:

- Browse menu — Specifies the browsing scope of the Objects pane. You can either narrow the scope to the current solution or expand it to every available component. You can select the following options from the drop-down list:

- All Components — Displays objects in the entire .NET Framework, the current solution and its referenced components, and any other components by selecting Edit Custom Component Set
- .NET Framework 2.0 — Displays objects in the.NET Framework 2.0
- .NET Framework 3.0 — Displays objects in the.NET Framework 3.0
- .NET Framework 3.5 — Displays objects in the.NET Framework 3.5
- .NET Framework 3.5 Client Profile — Displays objects in the.NET Framework 3.5 client profile
- .NET Framework 4 — Displays objects in the.NET Framework 4.0
- .NET Framework 4 Client Profile — Displays objects in the.NET Framework 4.0 client profile
- Silverlight 3.0 — Displays objects that used in Silverlight technology
- My Solution — Displays objects in the current solution and its referenced components
- Custom Component Set — Displays objects in any components that you have added by selecting Edit Custom Component Set
- Edit Custom Component Set — Displays the Edit Custom Component Set dialog box which is used for defining the Custom Component Set browsing scope

- Search menu — Allows you to search objects within the Objects pane. The results are displayed in the Objects pane as a filtered list. You can refresh the entire Browse scope by clicking the Clear Search button.

- Toolbar buttons — Allow you to navigate within the Objects pane and the Members pane. These buttons are described as follows:

- Back — Navigates to the previously selected item until you reach the first item browsed.
- Forward — Navigates to the next selected item until you reach the most recent item browsed.
- Add to References in Selected Project in Solution Explorer — Inserts a reference to the selected component into the project that is currently selected in the Solution Explorer.

- Object Browser settings — Allows you to choose a particular view of the objects within the specified Browse scope and specifies which of the available objects will be displayed.

- View Namespaces — Displays logical namespaces.
- View Containers — Displays physical containers.
- Show Base Types — Displays base types in the Objects pane.
- Show Derived Types — Displays derived types in the Objects pane. This option is available only for C#.
- Show Hidden Types and Members — Displays hidden types in the Objects pane and hidden members in the Members pane.
- Show Public Members — Displays public members for users who are using the class.
- Show Protected Members — Displays the protected members for users who are extending the class.
- Show Private Members — Displays members of all the accessibility levels for users who are using the class.
