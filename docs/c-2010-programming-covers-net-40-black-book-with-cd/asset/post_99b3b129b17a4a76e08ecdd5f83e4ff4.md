## In Depth

When a Windows operating system starts, various services related to the operating system are also started automatically. These services are known as Windows services, which perform specific functions and do not require user intervention. Windows services do not have user interfaces or produce any visual output. In addition, these services run automatically in the background when you start your system. These services do not require you to log on to the system. Some examples of Windows services are server products, such as Microsoft Exchange, SQL Server, and other applications; for instance Windows date and time that sets the computer clock. When a Windows service starts, it creates a log entry in the event log indicating that it has started. The service also creates a log entry on a specified interval during the time in which it is running and finally when it is stopped.

Visual Studio 2010 enables you to create Windows services as applications and allows you to define the code that controls the actions to be taken when commands, such as start, pause, resume, and stop are sent to the service. You can create Windows service applications by using the ServiceBase, ServiceInstaller, ServiceProcessInstaller, and EventLog classes. In a Windows service application, you can also configure a service to start automatically when the operating system starts or configure it as manual to start the service manually. Since a Windows service does not have any interface, it cannot be debugged as any regular application, but debugged as a process. Moreover, you can install or uninstall a Windows service application from a target Windows by using the Installutil.exe utility or the Windows installer.

In this chapter, you learn about various classes to create Windows services in Visual Studio 2010 using the ServiceBase, ServiceInstaller, ServiceProcessInstaller, and EventLog classes. The ServiceBase class allows you to define the behavior of the Windows service and the commands, such as Start, Pause, and Stop. The ServiceInstaller and ServiceProcessInstaller classes are used to install Windows services and specific processes to the services, respectively. Next, the EventLog class is explained, which enables you to access the Windows event logs from Windows services. Finally, you learn to install and uninstall a Windows service by using Installutil.exe and Windows Installer.

Let’s start with the ServiceBase class.

## The ServiceBase Class

The ServiceBase class is the base class to create a Windows service. It is inherited from the Component class. The inheritance hierarchy of the ServiceBase class is as follows:

```
System.Object
    System.MarshalByRefObject
        System.ComponentModel.Component
            System.ServiceProcess.ServiceBase
```

The ServiceBase class provides various properties, methods, and commands to control the behavior of a Windows service. The commands that are given to a Windows service include Start, Pause, and Stop. These commands are handled by Service Control Manager (SCM) that acts as the central organizer of the Windows services.

Some important public properties of the ServiceBase class are listed in Table 20.1:

**Table 20.1: Noteworthy Public Properties of the ServiceBase Class**

| Property | Description |
|---|---|
| AutoLog | Specifies whether or not to record the Start, Stop, Pause, and Continue commands in the event log |
| CanHandlePowerEvent | Determines whether or not a Windows service can handle notifications of computer power status changes |
| CanHandleSessionChangeEvent | Determines whether or not a Windows service can handle session change events returned by a Terminal Server session |
| CanPauseAndContinue | Determines whether or not you can pause and resume a Windows service |
| CanShutdown | Determines whether or not a Windows service should be notified when the system is shutting down |
| CanStop | Determines whether or not a Windows service can be stopped |
| EventLog | Obtains an event log that you can use to write to the Application event log |
| ExitCode | Determines the exit code for a Windows service |
| ServiceName | Specifies the name of a Windows service |

Table 20.2 describes some noteworthy public methods of the ServiceBase class:

**Table 20.2: Noteworthy Public Methods of the ServiceBase Class**

| Method | Description |
|---|---|
| Dispose | Disposes of the resources used by the ServiceBase class |
| RequestAdditionalTime | Requests for additional time to complete a pending operation |
| Run | Registers the executable for a Windows service with SCM |
| ServiceMainCallback | Registers the command handler to Windows operating system and starts the corresponding Windows service |
| Stop | Stops the Windows service |

Let's now explore another class, ServiceInstaller.

## The ServiceInstaller Class

The ServiceInstaller class is used to install a Windows service application. This class is used to write the registry values associated with a Windows service to the HKEY_LOCAL_MACHINE\System\CurrentControlSet\Services registry key. A Windows service is identified by the name assigned to the ServiceName property of the ServiceInstaller class. You can install a Windows service by creating a project installer class that inherits from the Installer class.

The inheritance hierarchy of the ServiceInstaller class is as follows:

```
System.Object
  System.MarshalByRefObject
    System.ComponentModel.Component
      System.Configuration.Install.Installer
        System.Configuration.Install.ComponentInstaller
          System.ServiceProcess.ServiceInstaller
```

Table 20.3 describes some noteworthy public properties of the ServiceInstaller class:

**Table 20.3: Noteworthy Public Properties of the ServiceInstaller Class**

| Property | Description |
|---|---|
| Description | Specifies the description of a Windows service |
| DisplayName | Specifies the display name of a Windows service |
| ServiceName | Specifies the name used to identify a Windows service |
| ServicesDependedOn | Specifies the services that must be running in support of a main Windows service |
| StartType | Specifies the start type of a Windows service |

Table 20.4 describes the noteworthy public methods of the ServiceInstaller class:

**Table 20.4: Noteworthy Public Methods of the ServiceInstaller Class**

| Method | Description |
|---|---|
| CopyFromComponent | Copies the properties from an instance of ServiceBase to the ServiceInstaller class, when overridden |
| Install | Installs the associated Windows service |
| IsEquivalentInstaller | Determines whether or not two installers can install the same service |
| Rollback | Rolls back the service application information written to a registry by the installation process |
| Uninstall | Uninstalls a Windows service |

> NOTE
> While installing a Windows service, the EventLogInstaller class is automatically created to install the event log related to the particular service.

## The ServiceProcessInstaller Class

The ServiceProcessInstaller class is used to install specific processes in a Windows service. It also performs the tasks common to all services in an executable, such as providing system information and printing documents. Similar to the ServiceInstaller class, the ServiceProcessInstaller class is also used to write registry values related to the service in the computer where the service has to install. The ServiceProcessInstaller class also enables you to specify a particular user name and password, computer’s system account, a local or network service account, or a user account, on the Windows operating system under which the service should run.

The ServiceProcessInstaller class is inherited from the ComponentInstaller class. The inheritance hierarchy of the ServiceProcessInstaller class is as follows:

```
System.Object
  System.MarshalByRefObject
    System.ComponentModel.Component
      System.Configuration.Install.Installer
        System.Configuration.Install.ComponentInstaller
          System.ServiceProcess.ServiceProcessInstaller
```

Some noteworthy public properties of the ServiceProcessInstaller class are listed in Table 20.5:

**Table 20.5: Important Public Properties of the ServiceProcessInstaller Class**

| Property | Description |
|---|---|
| Account | Obtains the account type for a service |
| HelpText | Obtains the help text for service options |
| Password | Obtains the password for a user account |
| Username | Obtains the user account under which the service application runs |
