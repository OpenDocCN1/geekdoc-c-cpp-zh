

## 使用 Silverlight 控件

Silverlight 提供了大量控件，可用于定义 Silverlight 应用程序的外观和感觉。大多数控件与 WPF 相同，因此提供了与 Button、TextBox、Rectangle 和 ListBox 等控件相同的功能。不过，Silverlight 3.0 还提供了一些专属控件，为 Web 应用程序提供额外功能。现在，让我们学习如何在 Silverlight 3.0 中使用以下控件：

- Calendar 控件
- DatePicker 控件
- GridSplitter 控件
- HyperlinkButton 控件
- MediaElement 控件
- Popup 控件
- TabControl 控件
- AutoCompleteBox 控件
- DataPager 控件
- TreeView 控件

## 使用 Calendar 控件

正如你在本章“深入探讨”部分所学到的，Calendar 控件允许你查看并选择日、月和年。你还可以为 Calendar 控件设置样式。执行以下步骤，了解如何使用 Calendar 控件来满足你的需求：

1. 创建一个名为 BookTicketCalendarAppCS（可在光盘上找到）的新 Silverlight 3.0 应用程序。该应用程序包含三个日历（Calendar 控件），允许你查看两个特定日期之间的票务可用情况，然后选择你想要预订票务的所需日期。为此，应用程序中添加了六个 TextBlock、三个 TextBox、三个 Calendar 和五个 Button 控件。此外，还有五个 Rectangle 元素，它们使用 ImageBrush 元素填充了不同的图像。现在，让我们看看这些控件和 XAML 元素是如何在应用程序中使用的。

你还可以注意到清单 17.2 中有三个 Calendar 控件，分别名为 fromCal、toCal 和 selectCal。fromCal 和 toCal Calendar 控件指的是允许用户选择一系列日期来预订票务的日历。selectCal Calendar 控件允许用户选择预订票务的日期。请注意，这三个 Calendar 控件的不同属性已设置，如表 17.18 所示：

### 表 17.18：分析 BookTicketCalendar 应用程序中使用的 Calendar 控件的属性

| 属性 | 值 | 描述 |
|---|---|---|
| IsTodayHighlighted | True | 突出显示当前日期 |
| DisplayMode | Month（用于 fromCal 和 toCal） | 一次显示一年的日历 |
|  | Year（用于 selectCal） | 一次显示一个月的日历 |

除了这些属性之外，Calendar 控件的 SelectedDatesChanged 事件也与其处理程序（在代码隐藏文件中定义）相关联。
