## Animation Storyboard

A Storyboard is a container timeline that provides target information to the timelines that are contained by it. You can use a Storyboard timeline to group multiple animations, and it has the capabilities to control the playback of the animation. For example, you can pause or stop an animation, or change the beginning location of an animation. The most basic feature provided by the Storyboard class is its ability to point to a specific property and a specific element using the TargetName and TargetProperty properties. Therefore, you can say that the Storyboard timeline bridges the gap between your animation and the property you want to animate. A controllable Storyboard timeline can pause, resume, stop, seek, and also be removed in the animation. To make a Storyboard timeline controllable in XAML code, you can specify the Name property of the BeginStoryboard object that creates it. You can also make a Storyboard timeline controllable in code, by using the appropriate overload of the Storyboard.Begin() method and specify True to make it controllable. You can add a Storyboard timeline, by adding the following code snippet in your application:

```
<Storyboard>
<!-- Children -->
</Storyboard>
```

## Multimedia in WPF 4.0

In this section, you learn the multimedia features of WPF. The multimedia features allow you to integrate sound and video into your applications in order to enhance the user experience. WPF includes support for playing the audio and video files supported by Windows Media Player. It also allows you to play more than one media file together. ### WPF Images

Images in WPF are a core part of most applications. They include icons, backgrounds, and even parts of animations. In WPF, you can display, transform, or format the images. WPF imaging is designed to overcome the shortcomings of GDI and provide a new set of Application Programming Interfaces (APIs) to display and use images within the application. You can access the WPF imaging API in two ways, a managed component and an unmanaged component. The managed WPF imaging is available in the System.Windows.Media.Imaging namespace and the System.Windows.Media namespace. The managed component utilizes the unmanaged component to provide integration of the images with other WPF features, such as animation and graphics. The unmanaged component provides improved performance and security on the local image formats that include bitmap (BMP), Joint Photographic Experts Group (JPEG), Portable Network Graphics (PNG), Tagged Image File Format (TIFF), Microsoft Windows Media Photo, Graphics Interchange Format (GIF), and icons (.ico).

In WPF, the Image class represents the control that displays an image. You can load all the image types supported by WPF with the help of the Image control. The Stretch property of the Image control determines how the image is stretched to fill the image element. You can add the Image control to your application by adding the following code snippet:

```
<Image .../>
```
