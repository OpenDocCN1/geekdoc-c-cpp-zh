## 拉伸图像

你可以使用 Image 控件的 Stretch 属性来控制图像如何拉伸以填充容器。Stretch 属性的值为 None、Fill、Uniform 和 UniformToFill。如果 Stretch 属性设置为 None，则图像不会被拉伸。如果图像大于输出区域，则图像不会被裁剪。Fill 值会缩放图像以填充输出区域。在这种情况下，图像的纵横比可能不会被保留。Uniform 值会缩放图像，使其完全适合输出区域。在这种情况下，图像的纵横比会被保留。UniformToFill 值会缩放图像以完全填充输出区域。让我们在 Image 控件上使用 Stretch 属性。为此，创建一个名为 StretchingImages 的 WPF 应用程序（也在 CD 上提供）并向应用程序添加一个页面。现在将清单 12.43 中的代码添加到 Page1.xaml 文件中：

### 清单 12.43：使用 Stretch 属性

```xml

    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006"
    xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
    mc:Ignorable="d"
    d:DesignHeight="300" d:DesignWidth="300"

    <DockPanel>
        <Grid Margin="10" ShowGridLines="True" VerticalAlignment="Center" HorizontalAlignment="Center">

            <Border Grid.Column="0" Grid.Row="1" BorderThickness="3" BorderBrush="Black">
```

## 使用 MediaElement 类控制媒体播放

在 WPF 中，你也可以播放媒体文件。MediaElement 类用于在 WPF 中播放音频或视频内容。Uri 类用于指定你想要包含的媒体的路径。让我们使用 MediaElement 类创建一个应用程序。为此，创建一个名为 MediaElement 的 WPF 应用程序（也在 CD 上提供）并将清单 12.44 中的代码添加到 MainWindow.xaml 文件中：

### 清单 12.44：使用 MediaElement 类

```xml
<Window x:Class="MediaElement.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="300" Width="300">
    <Grid Background="AliceBlue">
        <MediaElement Margin="40,0,78,0" Name="mediaElement1" Source="D:\wmafiles\Ringtone 01.wma" LoadedBehavior="Manual" UnloadedBehavior="Stop" Height="120" VerticalAlignment="Top" />
        <Button HorizontalAlignment="Left" Margin="0,0,0,106" Name="button1" Width="75" Click="button1_Click" Height="23" VerticalAlignment="Bottom">Play</Button>
        <Button Margin="105,0,98,106" Name="button2" Click="button2_Click" Height="23" VerticalAlignment="Bottom">Stop</Button>
        <Button Margin="0,0,13,106" Name="button3" Click="button3_Click" Height="23" VerticalAlignment="Bottom" HorizontalAlignment="Right" Width="75">Pause</Button>
        <Label Height="28" HorizontalAlignment="Left" Margin="0,0,0,66" Name="label1" VerticalAlignment="Bottom" Width="120">volume</Label>
        <Slider Height="21" Name="slider1" VerticalAlignment="Bottom" ValueChanged="ChangeMediaVolume" Margin="66,0,62,73" />
        <Label Height="28" HorizontalAlignment="Left" Margin="0,0,0,47" Name="label2" VerticalAlignment="Bottom" Width="120">Speed</Label>
        <Slider Height="21" Margin="66,0,62,47" Name="slider2" VerticalAlignment="Bottom" ValueChanged="ChangeMediaSpeedRatio"/>
    </Grid>
</Window>
```

在清单 12.44 中，两个标签、三个按钮和两个滑块连同 MediaElement 控件一起添加到应用程序中。按钮用于播放、暂停和停止媒体。滑块用于控制音量和改变音乐的速度。为了控制 Button 控件和 Slider 控件的功能，你需要在 MainWindow.xaml.cs 文件中添加清单 12.45 中给出的代码：

### 清单 12.45：在 MainWindow.xaml.cs 文件中添加控制控件的代码

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Windows;
using System.Windows.Controls;
using System.Windows.Data;
using System.Windows.Documents;
using System.Windows.Input;
using System.Windows.Media;
using System.Windows.Media.Imaging;
using System.Windows.Navigation;
using System.Windows.Shapes;

namespace MediaElement
{
    /// <summary>
    /// Interaction logic for MainWindow.xaml
    /// </summary>
    public partial class MainWindow : Window
    {
        public MainWindow()
        {
            InitializeComponent();
        }

        private void button1_Click(object sender, RoutedEventArgs e)
        {
            mediaElement1.Position = TimeSpan.Zero;
            mediaElement1.Play();
        }

        private void button2_Click(object sender, RoutedEventArgs e)
        {
            mediaElement1.Stop();
        }

        private void button3_Click(object sender, RoutedEventArgs e)
        {
            mediaElement1.Pause();
            mediaElement1.Position = TimeSpan.FromSeconds(slider1.Value);
        }

        private void ChangeMediaVolume(object sender,
            RoutedPropertyChangedEventArgs<double> e)
        {
            mediaElement1.Volume = (double)slider1.Value;
        }

        private void ChangeMediaSpeedRatio(object sender,
            RoutedPropertyChangedEventArgs<double> e)
        {
            mediaElement1.SpeedRatio = (double)slider2.Value;
        }
    }
}
```

在清单 12.45 中，我们使用一个名为 mediaElement1 的 MediaElement 控件来播放音乐。mediaElement1 控件由 button1、button2 和 button3 控件控制。button1 控件播放音乐，button2 控件停止音乐，button3 控件暂停音乐。mediaElement1 控件使用 slider1 控件来增加或减少其音量，并使用 slider2 控件来增加或减少其播放音乐的速度比率。

当你通过键盘按下 F5 键运行应用程序时，你可以看到输出，如图 12.46 所示：
