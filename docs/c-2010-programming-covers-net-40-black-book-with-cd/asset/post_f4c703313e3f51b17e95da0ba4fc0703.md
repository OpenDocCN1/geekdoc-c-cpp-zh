## Inserting Nodes

You can also insert new element nodes in an XML document. Let’s create an application, named ShowingNodes (also available on the CD) to insert nodes in an XML document.

Perform the following steps to create the ShowingNodes:

- 1. Create a Windows Forms application, named ShowingNodes.

private void button1_Click(object sender, EventArgs e)

listBox1.Items.Clear();

xd.Load("authors.xml");
XmlElement newAuthor = xd.CreateElement("authors");
newAuthor.SetAttribute("au_id", "712-45-1867");
XmlElement lname = xd.CreateElement("au_lname");

newAuthor.AppendChild(lname);

Next, we call the Close() method of XmlTextWriter class for closing the file. ## Navigating and Transforming Data

You have already learned in the In Depth section that the System.Xml.XPath namespace contains classes to select a subset of elements based on element text values or attribute values. In addition, the classes contained in the System.Xml.XPath namespace perform fast iteration and selections on an XML document. Besides this, the System.Xml.Xsl namespace contains the classes that are used to perform XSL transformations in .NET Framework.

In this section, you learn how to navigate and transform the data of an XML document. To do so, we use the same XML file, authors.xml, in the applications created under the following sections.

### Navigating and Finding Elements by Attribute Values

You can navigate through different nodes of an XML document with the help of their attribute values. Let’s create an application, named XMLElementsNavigation (also available on the CD) navigate among different nodes of an XML document.

Perform the following steps to create the XMLElementsNavigation application:

- 1. Create a Windows Forms application, named XMLElementsNavigation.
- 2. Add the authors.xml file in the bin\Debug folder of the XMLElementsNavigation application.
- 3. Add the following namespace in the Form1.cs file:

```
using System.Xml;
using System.Xml.XPath;
```

- 4. Open the designer of the Form1 form and drag a list box and button from the Toolbox to the form.
- 5. Set the Text property of the button1 to Find Elements.

6. Double-click the button1 and add the following code snippet:

```
private void button1_Click(object sender, EventArgs e) {
    listBox1.Items.Clear();
    XPathDocument pd = new XPathDocument("authors.xml");
    XPathNavigator pn = ((IXPathNavigable)pd).CreateNavigator();
    XPathNodeIterator ni = pn.Select("/authorslist/authors[@au_id='409-56-7008']");
    while(ni.MoveNext())
    {
        XPathNodeIterator newni = ni.Current.SelectDescendants(XPathNodeType.Element, false);
        while(newni.MoveNext())
        {
            listBox1.Items.Add(newni.Current.Name + ": " + newni.Current.Value);
        }
    }
}
```

In the preceding code snippet, we have created a blank list box. Then, we have created an object of the XPathDocument class by passing it the name of the XML file (authors.xml) as a parameter. Note that the authors.xml file is already placed in the bin\Debug folder of the project, so the location of the XML file will be detected by the application automatically. Next, we have created an object of the XPathNavigator class by first casting the XPathDocument object to the IXPathNavigable interface and then calling the CreateNavigator() method of the IXPathNavigable interface.

After that, we have created an object of the XPathNodeIterator class by calling the Select() method of the XPathNavigator object. The Select() method returns all the authors elements for which the value of the attribute au_id is 409-56-7008. The nodes of the XML document are then traversed using the MoveNext() method of the XPathNodeIterator object in a while loop. Inside the loop, we have created an object of the XPathNavigator class, which is the child element of the current element. We have again traversed the nodes of the XML document by using the MoveNext() method of the XPathNodeIterator object in another while loop. Inside the loop, the text value for the element is added to the list box.
