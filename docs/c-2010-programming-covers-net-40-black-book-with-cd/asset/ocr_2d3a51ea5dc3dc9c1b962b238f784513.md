# The GridSplitter Control

The GridSplitter control is a Silverlight 3.0 control that allows the users to shift the rows and columns according to their requirements. With the GridSplitter control, users can move the rows and columns to accommodate the space between them. The GridSplitter control always adjusts an entire row or column and not just a single cell of the grid.
