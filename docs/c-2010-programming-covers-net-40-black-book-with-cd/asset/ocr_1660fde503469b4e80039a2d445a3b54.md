# The ListBox Control

The ListBox control in WPF is derived from the abstract base class, Selector. The ListBox control displays items from a list. All items in the ListBox control are visible by default. To make only the selected items visible, set the IsDropDown property to True. You can select more than one item at a time from the ListBox control by setting the SelectionMode property to Single, Multiple, or Extended. The Single value is the default value. The content properties of the ListBox control are Items and ItemsSource.

The inheritance hierarchy of the ListBox class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.ItemsControl
                System.Windows.Controls.Primitives.Selector
                  System.Windows.Controls.ListBox
```

You can add a ListBox control to a WPF application by using the following code snippet:

```
<ListBox>
  <!--Items -->
</ListBox>
```

# Table 10.34: Showing the Noteworthy Properties of the ListBox Class

|---|---|

| SelectionMode | Gets or sets the selection behavior for a ListBox control |
