When we work with EDM tools in an ASP.NET website, the entity connection string is saved in the web.config file; however, in a Windows application, the entity connection string is saved in the App.config file. The location of the metadata files is specified as metadata=res:///. Therefore, ensure that the Save entity connection settings in web.config as check box is selected and the value is specified (Figure 22.10); otherwise, the connections settings will not be saved.
