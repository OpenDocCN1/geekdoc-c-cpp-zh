Constructors and destructors are special methods that are present in every class. # NOTE

Class variables are also known as data members and class methods are also known as member functions or methods.

You can use parameters to pass values to a method. The syntax for passing parameters is shown in the following code snippet:

```
[modifiers] DataType ParameterName
```

C# 2010 has the following types of formal parameters:

+   Value parameter – Allows a method to assign values to the value parameter through arguments given in a method call. This type of assignment affects only the local storage location. It has no affect on the actual arguments being assigned in the method call. In addition, changes made to the parameter are local to the method; they are not passed to the calling method. Value parameters are default parameters. If you declare a parameter without any modifier, then it is considered as a value parameter. A value parameter is also known as the In parameter.

+   Reference parameter – Represents the same storage location, instead of creating a new storage location for the variable given as the argument in the method invocation. A parameter declared with a ref modifier is a reference parameter.

+   Output parameter – Represents the same storage location, instead of creating a new storage location for the variable given as the argument in the method invocation. A parameter declared with an out modifier is an output parameter. Every output parameter of a method must be assigned before the method returns the output. Output parameters are typically used in methods that produce multiple return values.

The use of the out modifier while defining and calling a method is shown in the following code snippet:

```
class usingout
{
    static void FirstMethod(out int x) // out modifier in method definition
    {
        x = 81;
    }
    static void Main()
    {
        int y; // No prior initialization
        FirstMethod(out y); // out modifier in method calling
        // value of y is 81
    }
}
```

In the preceding code snippet, the out modifier has been specified during method definition (static void FirstMethod(out int x)) as well as during method call (FirstMethod(out y)).
