# Inheriting a Class

Inheritance is one of the primary features of object oriented programming. It allows you to reuse the existing code. In the In Depth section, you have already learned that a class can inherit from another class. The class which allows inheritance of its common properties is known as a base or parent class and the class that inherits the properties of base class is known as a derived or child class. In Listing 5.1, the BaseClass class is the parent class and DerivedClass class is inheriting the features of BaseClass class therefore, it is the child class. Let create an application named MyInheritance (also available on the CD) to learn how to inherit a class. Listing 5.1 shows the code of MyInheritance application:

# Listing 5.1: Showing the Code of MyInheritance Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace MyInheritance
{
public class BaseClass
{
    public int DataMember;
    public void BaseClassMethod()
    {
        Console.WriteLine("I am a Base Class Method()");
    }
}
public class DerivedClass : BaseClass
{
    public void DerivedClassMethod()
    {
        Console.WriteLine("I am a Derived Class Method()");
    }
}
public class Program
{
    public static void Main(string[] args)
    {
        // Create a Base Class Object
        Console.WriteLine("I am accessing Base Class object:");
        BaseClass bc = new BaseClass();
        bc.DataMember = 1;
        bc.BaseClassMethod();
        // Create a Derived Class Object
        Console.WriteLine("");
        Console.WriteLine("I am accessing Derived Class object:");
        DerivedClass dc = new DerivedClass();
        dc.DataMember = 2;
        dc.BaseClassMethod();
        dc.DerivedClassMethod();
        Console.Write("\nPress ENTER to quit..");
        Console.ReadLine();
    }
}
}
```

In Listing 5.1, we have created three classes, BaseClass, DerivedClass, and Program. The DerivedClass class inherits the BaseClass class. This implies that the DerivedClass class inherits all the members of the BaseClass class. In the Program class, we have initialized these classes and invoke the methods.
