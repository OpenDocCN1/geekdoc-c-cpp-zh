# Listing 10.24: Showing the Code to Use DataTemplate

```
<Page
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:sys="clr-namespace:System;assembly=mscorlib">
    <Page.Resources>
        <DataTemplate DataType="{x:Type sys:Boolean}">
            <CheckBox IsChecked="{Binding Mode=OneWay}" />
        </DataTemplate>
    </Page.Resources>
    <ItemsControl Width="100" Height="100">
        <sys:Int32>30</sys:Int32>
        <sys:DateTime>12/16/1970</sys:DateTime>
        <sys:Boolean>False</sys:Boolean>
        <sys:Boolean>True</sys:Boolean>
        <sys:String>Hello</sys:String>
        <sys:Boolean>True</sys:Boolean>
    </ItemsControl>
</Page>
```

In Listing 10.25, each Boolean value is displayed as a CheckBox control, rather than as a True or False value. This is done using the DataType property of DataTemplate.
