# Specifying Access Characters for Controls

Access characters are those characters that are underlined in menu names or control labels. Let’s perform the following steps to learn how to specify access characters for controls:

+   1. Create a Windows Forms application named AccessCharacters.
+   2. Add a Button control, button1, to Form1.
+   3. Modify the Text property of Form1 to Access Characters Form.
+   4. Add the following code snippet in the Load and Click events of Form1 and buton1, respectively:

```
private void Form1_Load(object sender, EventArgs e)
{
    button1.Text = "&Print";
}
private void button1_Click(object sender, EventArgs e)

    MessageBox.Show("Alt+p is the shortcut key");
```
