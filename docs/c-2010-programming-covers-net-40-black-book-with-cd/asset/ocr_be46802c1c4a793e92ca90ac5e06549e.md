# Adding a Table or View

To add a table or view in an application, the following steps are performed:

+   1. Select the <Add a Table or View> option in the Mapping Details window. A drop-down list appears, displaying a list of tables and views (Figure 22.19).
+   2. Select the desired table or view, as shown in Figure 22.19:

![](bbox=[0.09, 0.17, 0.96, 0.4])

Figure 22.19: Adding a Table or View

In Figure 22.19, we have selected the Customers table. The Maps to Customers option is added to the Mapping Details window. There are two options under the Map to Customers tab, one is <Add a Condition> and another is Column Mappings, which contain all the columns of the table, as shown in Figure 22.20:

![](bbox=[0.19, 0.49, 0.84, 0.81])

Figure 22.20: Displaying the Mapping Details Window
