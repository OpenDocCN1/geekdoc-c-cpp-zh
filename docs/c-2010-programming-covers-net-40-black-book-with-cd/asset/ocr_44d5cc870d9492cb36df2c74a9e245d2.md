During the execution of the DBServer application, you need to select the WellKnown SingleTon radio button in the Service Type group, an appropriate channel and formatter sink provider, and click the Start Server button. This starts your host application. Click the Refresh button and select the type of channel in the Control Panel group. This returns the machine address at which the host application is running.

You can run more than one instance of the ClientActivatedClient application and connect them to the server. In the ClientActivatedClient application, select the appropriate channel and formatter sink provider and click the Connect button to connect the client with the server. Note that the channel and formatter sink provider selected in the ClientActivatedClient application should not differ from the channel and formatter sink provider selected in the DBServer application. When you click the Connect button, the client is connected to the host application. The Greeting button serves the same functionality as it has performed in the WellKnownSingleCallClient and WellKnownSingleTonClient applications. Clicking the Count button displays the number of clients connected to the object. Similarly, clicking the Climb the Cliff button calls the ClimbTheCliff() method of SharedObject assembly and returns the specified message as it comes out from the sleep mode. The Disconnect button disconnects the client from the host application.

> NOTE
> If you try to connect applications running across a network, you may face problems in getting your applications to perform certain operations. This is due to lack of permissions. To avoid it, you need to set the system security to allow these applications to function properly.
