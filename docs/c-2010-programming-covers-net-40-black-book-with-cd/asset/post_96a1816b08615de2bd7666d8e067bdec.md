## The FlowDocumentPageViewer Control

The FlowDocumentPageViewer control splits a Flow document into multiple pages and allows you to view flow content in a fixed viewing mode. In the fixed viewing mode, one page is displayed at a particular instance of time. When you display the content in a Flow document using the FlowDocumentPageViewer control, the page is divided into two parts: content area and toolbar. The content area displays the content of FlowDocument specified by the Document property. The Toolbar is further divided into the following three parts:

- **The Page Navigation control**—Includes a button to move to the next page or the previous page using the down arrow or the up arrow, respectively. It also includes indicators for current page number and total number of pages.
- **The Zoom control**—Enables you to increase or decrease the zoom level by clicking the plus or the minus button. It also provides a slider for adjusting the zoom level.
- **The Search TextBox text box**—Helps you find strings with content. The keyboard shortcut, CTRL+F, is also used to find the string with the content.

The inheritance hierarchy of the FlowDocumentPageViewer control is as follows:

```
System.Object

                System.Windows.UIElement
                    System.Windows.FrameworkElement
                        System.Windows.Controls.Control
                            System.Windows.Controls.Primitives.DocumentViewerBase
                                System.Windows.Controls.FlowDocumentPageViewer
```

The FlowDocumentPageViewer control can be added to a WPF application, as shown in the following code snippet:

```

</FlowDocumentPageViewer>
```

## The FlowDocumentReader Control

The FlowDocumentReader control combines the features of the FlowDocumentScrollViewer and FlowDocumentPageViewer controls. It lets you select whether to read content in a scrollable mode or page viewing mode. When you display the content using the FlowDocumentReader control, the page is divided into two parts: the content area and the toolbar. The content area displays the content of FlowDocument specified by the Document property. The toolbar is divided into the following parts:

- Find button — Enables you to search the content of a document. The Find button is not shown if the IsFindEnabled property is set to False.
- Page Navigation controls — Includes a button to move to the next page or the previous page. It also has indicators for the current page number and the total number of pages.
- Viewing mode buttons — Contains three viewing modes: Page Mode, Two Page Mode, or the Scroll Mode. Any one of the modes can be selected according to requirements and preferences.
- Zoom control — Enables you to increase or decrease the zoom level by clicking the plus or the minus button. It also includes a slider for adjusting the zoom level.

> NOTE
> The default toolbar of the FlowDocumentReader control does not include a Print button.

The inheritance hierarchy of the FlowDocumentReader control is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
System.Windows.Controls.Control
System.Windows.Controls.FlowDocumentReader
```

You can add a FlowDocumentReader control to your WPF application, as shown in the following code snippet

```

<!--Document-->
</FlowDocumentReader>
```

The RichTextBox control allows you to modify its content. It is mainly used to edit formatted text, images, or tables.
