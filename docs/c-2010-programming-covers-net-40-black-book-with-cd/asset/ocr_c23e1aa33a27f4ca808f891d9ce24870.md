# The ComboBox Control

The ComboBox control in WPF is derived from the abstract base class, Selector. The ComboBox control, similar to the ListBox control, displays a list of items. The difference between the two is that the ComboBox control has an additional Button control to display an item only if the control is clicked. The list is displayed or is hidden as the Button control expands and collapses. In its default state, the list is collapsed and shows only one item.

The inheritance hierarchy of the ComboBox class is shown as follows:

```
System.Object
    System.Windows.Threading.DispatcherObject
        System.Windows.DependencyObject
            System.Windows.Media.Visual
                System.Windows.UIElement
                    System.Windows.FrameworkElement
                        System.Windows.Controls.Control
                            System.Windows.Controls.ItemsControl
                                System.Windows.Controls.Primitives.Selector
                                    System.Windows.Controls.ComboBox
```

You can add a ComboBox control to a WPF application by using the following code snippet:

```
<ComboBox>
    <!--Items-->
</ComboBox>
```
