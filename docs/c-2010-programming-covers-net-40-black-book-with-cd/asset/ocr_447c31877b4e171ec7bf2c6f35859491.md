The subelements of the AssociationSet element are as follows:

+   - EntitySet – Specifies a type in the class that is built from the conceptual schema
+   - ReferentialConstraint – Specifies different roles of an association

> NOTE
> The syntax of CSDL is expressed in XML, but it is not XML Schema Definition (XSD) based.

# Storage Schema Definition Language

The storage metadata schema is a formal description of the database that persist data for an application based on EDM. It is the basis for mapping entities and associations described in a conceptual schema to the corresponding entities and associations defined in the storage model. A declaration of entities in SSDL is not different from a declaration of entities in CSDL. A basic difference between these two schemas lies in data types used in the declaration of entities. EDM is capable of mapping these different data types used in a storage metadata schema and a conceptual schema. The third type of XML file is MSL.

# Mapping Specification Language

MSL connects the data types declared in CSDL to the database metadata. This metadata preserves data for an application that uses the defined object model. The Namespace Name and EntityContainer Name tags declared in the CSDL schema identify entities and associations that are contained in the conceptual schema. The MSL syntax maps these entities and associations to store metadata in the SSDL file. Figure 22.2 shows the mapping of a conceptual model and a logical model:

The MSL file consists of the following elements:

+   - Mapping element – Specifies mapping between types defined by using CSDL and metadata in SSDL. The syntax of using a Mapping element is as follows:

```
<?xml version="1.0" encoding="utf-8"?>
<Mapping Space="C-S">
```

+   - EntityContainerMapping element – Maps the EntityContainer element declared in a conceptual schema to the EntityContainer element declared in the storage metadata schema. In the conceptual schema, an EntityContainer element is the specification for a class in a programming object model. In the metadata schema, an EntityContainer element is the designation for the database structures used by applications that are based on object models.

+   - EntitySetMapping element – Connects an EntitySet defined in CSDL to an EntitySet defined in SSDL.
