## 访问修饰符

访问修饰符有助于避免数据和方法与现有代码的混乱，并保护类的对象免受外部干扰。这些修饰符通过为数据和方法定义一定的访问范围以受限的方式进行访问来实现这一点。你可以用访问修饰符声明一个类及其每个方法。然而，每个方法只能包含一个修饰符。如果你在任何其他类之外声明一个类，则该类可以使用以下两个修饰符：

- public 修饰符
- internal 修饰符

另一方面，嵌套类可以使用以下五个修饰符：

- public 修饰符 – 允许在类内部和外部无限制地公开访问成员。
- internal 修饰符 – 允许内部访问成员。仅当前程序集可以访问这些成员。如果在定义它的程序集之外访问 internal 可访问级别的成员，则会生成错误。
- protected 修饰符 – 允许受保护地访问成员。你可以从声明它们的类或从声明它们的类的派生类访问 protected 成员。
- private 修饰符 – 允许私有地访问成员。私有成员具有最低的访问权限级别；你只能在类的主体中或声明它们的结构中访问它们。
- protected internal 修饰符 – 允许访问当前程序集、包含类以及从包含类派生的类的成员。

在某些情况下，程序员需要确保某些值在应用程序生命周期内保持不变。例如，对于计算任何化学公式，元素的原子值应保持不变。C# 有两种类型的字段 – 常量和只读 – 来解决这种情况。常量和只读字段有一些相似之处，但在某些方面是不同的。

常量与可在编译时访问的类相关联。这意味着你定义为常量的变量的值是在编译时计算的。常量的值一旦声明就不能更改。你可以使用 const 关键字声明变量为常量。

以下代码片段显示了常量的使用：

```
struct Atomicweight
{
    public const double Gold = 196.9;
    public const double Silver = 107.8;
}
```

在前面的代码片段中，金 (196.9) 和银 (107.8) 的原子量是编译时常量，因为它们的值始终保持不变，并且在运行时不会更改。

如前所述，常量通常在编译时声明；然而，如果你想在运行时使变量保持不变，可以指定 readonly 关键字，如以下代码片段所示：

```
class MyClass
{
    public readonly int Number1=10;
    public readonly int Number2=20;
}
```

在前面的代码片段中，Number1 和 Number2 变量的值分别在只读模式下设置为 10 和 20。

只读字段也与类或类的实例相关联。它们的值可以在类声明期间设置。你可以使用 readonly 关键字声明变量为只读。在你希望字段对同一类的不同对象具有不同的值，但要求字段的值在特定对象的整个生命周期内保持不变的情况下，优先使用只读变量而不是常量。

## 构造函数和析构函数

如果你曾在 C++ 或 Java 中工作过，你就熟悉构造函数和析构函数的概念。构造函数在对象首次创建时被调用。析构函数（或终结器）在对象最终被销毁并被垃圾回收时被调用。构造函数的名称与类名相同；而析构函数的名称由类名前加波浪号 (~) 组成。你可以使用构造函数初始化对象并设置任何参数。此外，你可以编写构造函数以接受参数。以下代码片段显示了名为 Foo 的类的构造函数和析构函数的示例：

```csharp

    int c;

        a = s;

    Foo(int I, string s) {

        c = I;
    }
    ~Foo() {}
}
```
