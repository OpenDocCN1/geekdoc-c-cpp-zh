
## Composite Geometry

The composite geometry classes include the GeometryGroup and CombinedGeometry classes. You can also create composite geometry by calling the static method Combine() of the Geometry class. The composite geometry classes and their functioning are listed in Table 12.16:

Table 12.16: Composite Geometry Classes

| Class | Description |
|---|---|
| GeometryGroup | Refers to a composite geometry objects |
| CombinedGeometry | Combines the area defined by two geometries |

The GeometryGroup class represents a composite geometry, inclusive of other Geometry objects. The GeometryGroup class creates a composite geometry from any number of geometry objects. You can use the FillRule property of the GeometryGroup class to specify how the geometries are combined.

The CombinedGeometry class on the other hand, represents a 2-D geometric shape defined by the combination of two Geometry objects. You can use the GeometryCombineMode property of the CombinedGeometry class to specify how the two geometries have to be combined. The values of GeometryCombineMode property can be set to: Union, Intersect, Exclude, or Xor.

## Brushes in WPF

In WPF, you can use brushes to apply background and foreground colors to elements. The brushes in WPF are used to paint various shapes. These brushes are derived from the Freezable base class and support change notification. For example, if you change a brush, the element that uses that brush repaints itself. The brushes in WPF are defined in the Brush class, which is defined in the System.Windows.Media.Brush namespace. The different types of brushes available in WPF are listed in Table 12.17:

Table 12.17: Brush Classes

| Class | Description |
|---|---|
| SolidColorBrush | Paints an area with a solid color |
| LinearGradientBrush | Paints an area with linear gradient |
| RadialGradientBrush | Paints an area with radial gradient |
| DrawingBrush | Paints an area with a drawing |
| ImageBrush | Paints an area with an image |
| VisualBrush | Paints an area with a visual object |

The inheritance hierarchy of the Brush class is as follows:

```

      System.Windows.Freezable

```

## The SolidColorBrush Class

The SolidColorBrush class defines the brush of a single color. It is used to fill graphics shapes, such as rectangle, ellipse, polygons, and paths with a single color. You can define solid color by setting the Background attribute to a string that defines a solid color. You can paint an area with a solid color by using the predefined system brush, such as Red, Blue, or Yellow. You can add a SolidColorBrush object to your application by adding the following code:

```
<SolidColorBrush .../>
```

The inheritance hierarchy of the SolidColorBrush class is as follows:

## The LinearGradientBrush Class

The LinearGradientBrush class is used to create a brush that paints an area with linear gradient, a gradually shaded fill that changes from one color to another. It applies a smooth color change to the elements, and creates a blended fill. The LinearGradientBrush class defines the StartPoint and EndPoint properties. They assign the 2-D coordinates for applying the linear gradient. The default value of the StartPoint property is 0, and the EndPoint property is 1, which creates a diagonal gradient. These properties allow you to select the point where the first color begins to change and the point where the color change ends with the final color. To create a gradient, you need to add the GradientStops property for each color and place each color in your gradient using the Offset value from 0 to 1. You can add a LinearGradientBrush object to your application by adding the following code snippet:

```
<LinearGradientBrush>
<!-- GradientStops -->
</LinearGradientBrush>
```

The inheritance hierarchy of the LinearGradientBrush class is as follows:

```

      System.Windows.Freezable
        System.Windows.Media.Animation.Animatable
          System.Windows.Media.Brush
            System.Windows.Media.GradientBrush
              System.Windows.Media.LinearGradientBrush
```

The noteworthy properties of the LinearGradientBrush class are listed in Table 12.20:

Table 12.20: Properties of the LinearGradientBrush Class

| Property | Description |
|---|---|
| ColorInterpolationMode | Gets or sets a ColorInterpolationMode enumeration that specifies how the gradient's colors are interpolated |
| EndPoint | Gets or sets the ending 2-D coordinates of the linear gradient |
| GradientStops | Gets or sets the brush's gradient stops |
| MappingMode | Gets or sets a BrushMappingMode enumeration that specifies whether the gradient brush's positioning coordinates are absolute or relative to the output area |
| SpreadMethod | Gets or sets the type of spread method that specifies how to draw a gradient that starts or ends inside the bounds of the object to be painted |
| StartPoint | Gets or sets the starting 2-D coordinates of the linear gradient |

## The RadialGradientBrush Class

The RadialGradientBrush class is similar to the LinearGradientBrush class, as it fills an area with a gradient fill. The difference lies on the way the gradient is applied. The RadialGradientBrush class fills the gradient which radiates out in a circular pattern starting from the center point. You can use the GradientOrigin property to identify the point where the first color in the gradient starts. The default value of the GradientOrigin property is 0.5, which represents the middle of the fill region. The gradient radiates out from the point in the GradientOrigin property, which is the starting point in a circular manner. The RadialGradientBrush class is a good choice for filling rounded shapes and creates lightening effect. You can add a RadialGradientBrush object to your application by adding the following code snippet:

```
<RadialGradientBrush>
<!-- GradientStops -->
</RadialGradientBrush>
```
