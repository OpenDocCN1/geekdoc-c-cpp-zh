

## TextEffect 类

TextEffect 类允许你为文本对象（如 TextBlock、TextElement 和 FlowDocument）添加文本效果，例如动画和克隆。TextEffect 类的对象帮助你将文本视为文本字符串中的一个或多个字符组。TextEffect 类的继承层次结构如下：

```
System.Object
    System.Windows.Threading.DispatcherObject
        System.Windows.DependencyObject
            System.Windows.Freezable
                System.Windows.Media.Animation.Animatable
                    System.Windows.Media.TextEffect
```

TextEffect 类的属性在表 11.7 中列出：

| Property | Description |
|---|---|
| Clip | Gets or sets the region to apply the text effect |
| Foreground | Gets or sets the Brush object to be applied on the text |
| PositionCount | Gets or sets the position in the text to which the text effect is applied |
| PositionStart | Gets or sets the starting position in the text to apply the text effect |
| Transform | Gets or sets the transformation that is applied to the text effect |

## BitMapEffect 类

BitMapEffect 类是一个抽象类，允许你对文本应用视觉效果，例如模糊、发光和投影。此类为你提供了一种简便且声明式的方式来增强文本的外观。它不支持部分信任执行；因此，应用程序必须具有完全信任权限才能使用 BitMapEffect。这意味着你需要拥有 UIPermission 来继承 BitMapEffect 类。UIPermission 类控制与用户界面的相关权限。BitMapEffect 类的继承层次结构如下：

```
System.Object
    System.Windows.Threading.DispatcherObject
        System.Windows.DependencyObject
            System.Windows.Freezable
                System.Windows.Media.Animation.Animatable

```

## WPF 4.0 文档

在 WPF 中，显示固定文本很容易，因为你可以在应用程序中使用 `TextBlock`、`Label` 和 `ContentControl` 控件。然而，要显示大量数据，例如报纸文章，这些控件并不是一个好的选择。当你使用 `TextBlock` 和 `Image` 元素组合文本和图像时，窗口调整大小时 `TextBlock` 和 `Image` 的内容无法正确对齐。为克服这些问题，WPF 引入了文档的概念来处理大量文本。此功能允许以易于阅读的方式显示大量内容，而与窗口大小无关。

WPF 中有两种文档：固定文档和流文档。固定文档类似于便携式文档格式（PDF）文档，因为其内容无法更改。流文档类似于超文本标记语言（HTML）文档，因为它使用标签创建。两种文档都允许你指定查看偏好，同时保持文档作者所期望的整体设计概念。这些文档位于 `System.Windows.Documents` 命名空间中。

## 固定文档

固定文档是排版完成且可直接打印的文档，其中所有内容的位置都是固定的。它们在逻辑上将有序的页面序列绑定在一起，形成单个、多页或固定布局文档。WPF 包含一种固定文档类型，它使用 Microsoft XML Paper Specification（XPS）标准以可扩展标记语言（XML）格式表示数字文档的电子表示。固定文档内容的显示由 `DocumentViewer` 控件支持。WPF 中的固定文档由 `FixedDocument` 类表示。让我们在以下章节中讨论 DocumentViewer 控件和 FixedDocument 类。

## DocumentViewer 控件

`DocumentViewer` 控件允许你以自定义方式显示固定文档。它由 `DocumentViewer` 类表示，该类表示可托管分页 FixedDocument 内容（如 XpsDocument）的文档查看控件。DocumentViewer 类提供 CanDecreaseZoom 和 CanGoToNextPage 等属性，用于搜索和缩放文本。

DocumentViewer 类的继承层次结构如下：

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.Primitives.DocumentViewerBase
                System.Windows.Controls.DocumentViewer
```

以下代码片段显示如何将 DocumentViewer 控件添加到 WPF 应用程序中：

```
<DocumentViewer>
  <!-- Document -->
</DocumentViewer>
```
