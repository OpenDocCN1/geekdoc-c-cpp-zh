# Operation Contract

The operation contract defines the methods that should be exposed to the external client. It provides the OperationContractAttribute attribute, which is used to tag every method that is a component of a service contract. Table 19.4 describes the properties of the OperationContractAttribute attribute:

**Table 19.4: Showing the Properties of the OperationContractAttribute Attribute**

| Property | Description |
|---|---|
| `Action` | Specifies the action that uniquely identifies an operation, and dispatches request messages to methods based on their actions. |
| `ReplyAction` | Sets the action name of the reply message. |
| `AsyncPattern` | Indicates that an operation is implemented or can be called asynchronously using a Begin/End method pair. |
| `IsInitiating` | Initiates an operation from a sequence of operations. The initiating operation starts a new session; whereas. |
| `IsTerminating` | Terminates an operation from a sequence of operations. The server ends the session with the terminating operation. |
| `IsOneWay` | Allows a client not to wait for a reply message. There is no direct way for the client to ensure whether the request is sent properly or not. |
| `Name` | Defines the name of an operation. |
| `ProtectionLevel` | Specifies whether a message should be signed, encrypted, or both. |
