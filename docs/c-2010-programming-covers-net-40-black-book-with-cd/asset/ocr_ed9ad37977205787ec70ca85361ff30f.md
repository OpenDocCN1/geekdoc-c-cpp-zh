# Using the WebService Class

Suppose you want to use common ASP.NET objects, such as Application, User, Session, and Context, in your Web service. What will you do in such a situation? Will you define these objects in your Web service and then use them? A better way to use these objects in your Web service is to inherit the class that implements the Web service from the WebService class.

The WebService class allows a Web service to access all the common ASP.NET objects as if they are the members of the class implementing the Web service. The WebService class resides in the System.Web.Services namespace and the System.Web.Services assembly. Now, let’s create a Web service that uses the WebService class.

Suppose you want your Web service to determine the name of the server on which the Web service is running. You can determine the name of the server by using the Server object which is a member of the WebService class. Therefore, you should create your Web service by deriving the class that implements the Web service from the WebService class.

Now, create a Web service, named WebServiceClass (available on the CD), and follow these steps:
