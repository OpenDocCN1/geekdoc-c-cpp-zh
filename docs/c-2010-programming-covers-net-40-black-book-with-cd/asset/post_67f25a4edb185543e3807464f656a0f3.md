## Exploring Classes and Objects

Classes allow you to control all the functions that can be applied to a given set of data as well as how to access the data. Classes also give you the ability to extend a runtime environment and allow the developer to reuse the existing functionalities of the runtime environment. Suppose you need to create an object of a class, named student, in your program. To do so, you first need to create a Student class that contains all the functionalities or behaviors of any student and then use that class to create the objects as needed.

In this section, you explore the following:

- Syntax of a class
- Using methods as class members
- Access modifiers
- Using objects to access the class members
- Constructors and destructors
- Static classes and static class members, properties, and indexers

Let's start with the syntax of a class first.

### Syntax of a Class

The basic syntax of the class structure is shown in the following code snippet:

```
class <className>
{
    <access-modifier> [static] <return-type> MethodName(<signature>);
    <access-modifier> [static] <variable type> variableName;
}
```

The basic syntax for declaring an object is shown in the following code snippet:

```
<className> <ObjectName> = new <className>();
```

You can also declare partial classes in your applications. The partial class is a class that enables you to specify the definition of a class, structure, or interface in two or more source files. All the source files, each containing a section of the class definition, combine when an application compiles. You may need a partial class when developers are working on large projects. A partial class distributes a class over multiple separate files, allowing developers to work on the class simultaneously. Using the partial keyword, you can declare a class as partial, as shown in the following code snippet:

```
public partial class Student
{
    public void avgMarks() { }
}
public partial class Student
{
    public void calRank() { }
}
```

The partial keyword specifies that other sections of the class, structure, or interface, are defined within the namespace.

### Methods as Class Members

Now that you are familiar with the importance of using classes, let's move on to discuss members of a class—Class Methods and Class Variables. Members of a class are the elements that are declared in the class. The following code snippet shows the syntax to declare the members of a class (methods and variables):

```
class Square
{
    int side;
    public int area()
    {
        return ( side * side);
    }
}
```

In the preceding code snippet, the Square class has a variable named side and a method named area. The side variable takes an integer value for the side of a square; whereas, the area method is used to calculate the area of the square.

Constructors and destructors are special methods that are present in every class. The constructor method initializes all the class members whenever you access the class, and the destructor method destroys them when the objects are not required anymore. Each class has its own constructor and destructor and they are called automatically when the instance of a class is created or destroyed.

**NOTE**

Class variables are also known as data members and class methods are also known as member functions or methods.

You can use parameters to pass values to a method. The syntax for passing parameters is shown in the following code snippet:

```
[modifiers] DataType ParameterName
```

C# 2010 has the following types of formal parameters:

- Value parameter – Allows a method to assign values to the value parameter through arguments given in a method call. This type of assignment affects only the local storage location. It has no effect on the actual arguments being assigned in the method call. In addition, changes made to the parameter are local to the method; they are not passed to the calling method. Value parameters are default parameters. If you declare a parameter without any modifier, then it is considered as a value parameter. A value parameter is also known as the in parameter.

- Reference parameter – Represents the same storage location, instead of creating a new storage location for the variable given as the argument in the method invocation. A parameter declared with a ref modifier is a reference parameter.

- Output parameter – Represents the same storage location, instead of creating a new storage location for the variable given as the argument in the method invocation. A parameter declared with an out modifier is an output parameter. Every output parameter of a method must be assigned before the method returns the output. Output parameters are typically used in methods that produce multiple return values.

The use of the out modifier while defining and calling a method is shown in the following code snippet:

```
class UsingOut
{
    static void FirstMethod(out int x) // out modifier in method definition
    {
        x = 81;
    }
    static void Main()
    {
        int y; // No prior initialization
        FirstMethod(out y); // out modifier in method calling
        // value of y is 81
    }
}
```

In the preceding code snippet, the out modifier has been specified during method definition (static void FirstMethod(out int x)) as well as during method call (FirstMethod(out y)).

        x++;

    {
        int y = 81;        // must be initialized
