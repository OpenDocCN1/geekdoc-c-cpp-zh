# Margin Lines and Margin Stubs

In WPF 4.0, the controls exist within the container controls, one of which is the Grid control that is automatically added to WPF applications when you create them. When you drag and drop the controls on the grid, you can change the distance, known as the margin, between a control and the grid. The margin is the distance from the edge of the control to the edge of the container control. If you have used, Grid as the container control, then margin is measured from the edge of the control to the nearest gridline. Each control has four margins – top, bottom, left, and right.
