# The <service> element

The <service> element contains the specifications of all the services that are hosted by applications. It consists of the following two attributes:

+   - name – Indicates the type that provides the implementation of a service contract. It is the combination of namespace and type name.
+   - behaviorConfiguration – Indicates the name of one of the <behavior> elements that is found in the <behaviors> element.

# The <endpoint> element

The <endpoint> element contains the following attributes:

+   - address – Indicates the URI of a service, which can be an absolute address or a relative address.
+   - Binding – Indicates a system-provided binding, such as WSDualHttpBinding, but can also specify a user-defined binding. The specified binding decides the transport protocol, security, and the encoding format used.
+   - bindingConfiguration – Contains a string that signifies the binding name of a binding, which is used when the instance of an endpoint is created.
+   - Contract – Signifies the interface that describes the contract by the name attribute of the <service> element.

# The <bindings> element

The <bindings> element consists of the specifications for all the bindings that an endpoint defined in any service can use. It contains one or more <binding> elements that have a name attribute. This attribute associates the binding with the endpoint specified in the bindingConfiguration attribute of the <endpoint> element.

# The <behaviors> element

The <behaviors> element acts as a container element for one or more <behavior> elements, which describe the behavior of the services. Each <behavior> element consists of a name attribute, which defines either a system-provided behavior or a custom behavior.

# Using the WCF Configuration Editor Tool

The WCF Configuration Editor tool, named Microsoft Service Configuration Editor, allows you to create or modify the configuration setting of your WCF service. It is a graphical tool through that you can use to manage the settings of WCF bindings, behaviors, and services. By using Microsoft Service Configuration Editor to modify or set the configuration information of your WCF services, you can save a lot of time as compared to that consumed while modifying the configuration file manually in the configuration files.
