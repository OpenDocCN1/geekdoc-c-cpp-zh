# Using the Hashtable Class

As already stated, the Hashtable class allows you to create collections that store pairs of keys and values. With the Hashtable class, you can retrieve objects using the keys associated with them. Let’s create a Windows Forms application named HashtableSample, also available on the CD-ROM, to understand the use of Hashtable class. This application contains a user interface form with three buttons--Create and add 10 items, ContainsKey, and ContainsValue, and one ListView control.
