# Transforming XML

You can transform an XML document into an HTML document by using an XSLT file. Let’s create an application, named TransformingXML (also available on the CD) to transform an XML document into an HTML document.

Perform the following steps to create the TransformingXML application:

+   1. Create a Windows Forms application, named TransformingXML.
+   2. Add the authors.xml file in the bin\Debug folder of the TransformingXML project.
+   3. Create and save an XSLT file, authors.xslt in the bin\Debug folder of the TransformingXML project
+   Listing 30.6 shows the code of the authors.xslt file:

# Listing 30.6: Showing the Code of the authors.xslt File

```
<?xml version="1.0" encoding="UTF-8" ?>
<xsl:stylesheet version="1.0" xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
<xsl:template match="/">
<html>
<head>
<title>Authors</title>
</head>
<body>
<table border ="1">
<xsl:apply-templates/>
</table>
</body>
</html>
</xsl:template>
<xsl:template match="authorslist">
<xsl:apply-templates select="authors"/>
</xsl:template>
<xsl:template match="authors">
<tr>
<td>
<xsl:value-of select ="au_lname"/>
</td>
<td>
<xsl:value-of select ="au_fname"/>
</td>
</tr>
</xsl:template>
</xsl:stylesheet>
```

+   4. Add the following namespaces in the Form1.cs file:

```
using System.Xml;
using System.Xml.Xsl;
```

+   5. Open the designer of the Form1 form and drag a Web browser and button from the Toolbox to it.
+   6. Set the Text property of the button1 to Generate HTML.
+   7. Double-click the button1 and add the following code snippet:

```
private void button1_Click(object sender, EventArgs e)
{
XslCompiledTransform ct = new XslCompiledTransform();
ct.Load("authors.xslt");
ct.Transform("authors.xml", "authors.html");
webBrowser1.Url = new Uri(AppDomain.CurrentDomain.BaseDirectory
+ "authors.html");
}
```
