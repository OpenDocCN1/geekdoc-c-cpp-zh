## Creating a Fixed Document

In WPF, Fixed documents serve as print-ready documents that can be distributed and printed easily. The Fixed documents use XML Paper Specification (XPS) to display their content. They are fixed paginated documents designed by Microsoft for read only purpose. You can also save a simple Word 2007 file as a fixed document by saving it as an XPS file. Perform the following steps to save a simple Word 2007 file as an XPS file:

1. Click the Office Button in the Word file that you want to save as an XPS document.
2. Click Save As→PDF or XPS.

The Word 2007 file will be published as an XPS file. XPS is not only a part of WPF; it is also integrated with Windows Vista. To view an XPS document in WPF, you need just one container named DocumentViewer. It includes controls to perform various tasks, such as searching and zooming the text of a document.
