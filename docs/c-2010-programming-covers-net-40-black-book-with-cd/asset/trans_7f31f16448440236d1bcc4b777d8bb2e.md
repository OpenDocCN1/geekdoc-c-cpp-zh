## 构建和调试项目

在 Visual Studio 中，当您创建新项目或网站时，它会自动成为解决方案的一部分。解决方案是一个或多个项目的顶层容器。项目是容纳源文件、文件夹以及其他项目相关项（如引用、窗体、类、模块和组件）的容器。当您构建解决方案时，执行构建操作的是项目。如果解决方案包含多个项目，您可以使用“生成”菜单独立或集体地构建这些项目。

“生成”菜单包含以下选项：

- 生成解决方案 – 仅编译自上次创建以来已修改的项目文件
- 重新生成解决方案 – 重新编译解决方案中存储的所有项目文件
- 清理解决方案 – 删除中间文件和输出文件，但不删除项目文件，可从中构建新的中间文件和输出文件实例
- 生成项目名称 – 仅构建解决方案中的所选项目
- 重新生成项目名称 – 重新编译解决方案中的所选项目
- 清理项目名称 – 删除输出文件，但不删除项目文件，可从中构建新的输出文件实例

## 第三节 – C# 2010 概述

Visual C#，通常称为 C#，是用于创建可执行程序的中间编程语言之一。它是一种面向对象的编程语言，结合了 C++ 的功能和效率、Java 的简洁和面向对象方法以及 Visual Basic 的创造性。与 Java 类似，C# 不使用多重继承和指针，但在运行时提供垃圾回收。此外，与 Java 相比，C# 包含有用的操作，如运算符重载、枚举、预处理器指令、指针和函数指针。它还支持属性的概念。C# 2010 已大幅改进，现在包含新的编译器功能、新语言结构和改进的调试技术。

在编程语言中，语句代表程序中的完整指令。C# 2010 语句由以下部分组成：

- 关键字 – 包括用于与语言（Visual C#）一起工作的预定义单词
- 运算符 – 包括用于执行操作（如加法、减法和乘法）的符号，如 +、- 和 *
- 变量 – 包括用于在程序中存储值的单词或字母
- 字面量 – 表示值，如整数或字符串。
- 常量 – 表示其值不可更改的变量

## 探索 C# 2010 的新功能

在 C# 2010 中，添加了许多新功能以提高开发人员的工作效率。以下是在 C# 2010 中添加的新功能列表：

- 支持动态数据类型

让我们逐一讨论这些新功能。

### 支持动态数据类型

在 C# 2010 中引入的动态数据类型允许您在运行时为变量分配数据。您可以使用代码中的关键字 dynamic 定义此数据类型。动态数据类型的变量可以由任何类型的数据初始化，例如数字、浮点值或字符串数据。以下示例显示了动态数据类型的用法：

```
//Example 1
dynamic intvar = 10;
Response.write(intvar);

//Example 2
dynamic floatVar = 3.7;
Response.write(floatVar);

//Example 3
dynamic stringVar = "dynamicstring";
Response.write(stringvar);
```

由于 dynamic 关键字在运行时分配数据；因此，它可与具有运行时属性的 COM 或 JavaScript 一起使用。

### 命名和可选参数

在 C# 2010 中，您可以使用命名和可选参数调用类的<|message|>方法。这些参数被声明为普通参数，唯一的区别是它们已用默认值初始化。如果您未为可选参数提供值，它将调用其默认值。您可以通过手动调用其名称并传递值来手动调用命名参数。

以下代码片段显示了可选和命名参数的示例：

```
static string Info(string name, string email = "kogent@xxx.com", string phone="0000000")
{
string msg = name + "\t" + email+"\t"+phone;
return msg;
}
static void Main(string[] args)
{
System.Console.WriteLine(Info("Charu")); //Line 1: Optional parameters are calling
System.Console.WriteLine(Info("Charu","charu@xxx.com")); //Line 2: Optional parameters are calling
System.Console.WriteLine(Info("Charu", phone: "8568487")); //Line 3: Named parameters are calling
}
```

在前面的代码片段中，一个名为 Info 的方法接收三个参数：name、email 和 phone。email 和 phone 参数具有默认值，可作为可选参数工作。注释为 Line 1 的行仅传递 name 参数的值；但是，其输出显示为：

```
Charu    kogent@xxx.com    0000000
```

email 和 phone 是可选参数，其值可以提供也可以不提供。在下一行注释为 Line 2 的行中，传递了 name 和 email 参数的值。Line 2 的输出如下：

```
Charu    charu@xxx.com    0000000
```

在前面的示例中，电话号码是可选参数并显示其默认值，而为 name 和 email 参数提供了值。现在，在最后注释为 Line 3 的行中，传递了 name 和 phone 参数的值。Line 3 的输出如下：

```
Charu    kogent@xxx.com    8568487
```

前面的输出显示了 email 的默认值并提供了 name 和 phone 参数的值。在这种情况下，name 参数是强制性的，email 是可选的，phone 是命名参数。

### 访问 Office Interop 对象

C# 2010 引入了 Office Interop 对象，可帮助您访问应用程序编程接口（API）对象。例如，您需要将 Microsoft.Office.Interop.Word 和 Microsoft.Office.Interop.Excel 引用添加到程序中以访问 Microsoft Word 或 Excel 应用程序的功能。以下示例显示了可包含以访问 Office API 对象的指令：

```
using Excel = Microsoft.Office.Interop.Excel;
using Word = Microsoft.Office.Interop.Word;
```
