

# 图 9.13：独立应用程序的 WPF 设计器

在图 9.13 中，你可以看到 WPF 设计器，它由一个窗口、一个类似窗体的结构组成，出现在 WPF 设计器的中央，就像 Windows 窗体出现在 Windows 窗体设计器中央一样。此外，WPF 设计器和 Windows 窗体设计器都有解决方案资源管理器、属性窗口和工具箱。两者之间的唯一区别是 WPF 设计器分为两个主要设计视图，即设计视图和 XAML 视图。其他设计器元素，例如拆分视图栏和标签导航器，可帮助你使用设计视图和 XAML 视图。我们先来探索设计视图。

## 设计视图

顾名思义，设计视图是你通过放置、拖动和调整大小以及操纵控件的外观来构建 WPF 应用程序的视觉方面或 UI 的区域。设计视图允许你以所见即所得（WYSIWYG）的方式快速轻松地构建 WPF 应用程序的 UI。

## 网格导轨、网格线和网格线指示器

网格导轨、网格线和网格线指示器与 WPF 的 Grid 元素或控件有关。当你创建 WPF 应用程序时，Grid 元素默认会添加到应用程序中。顾名思义，Grid 元素允许你将 WPF 应用程序表示为网格或晶格。整个网格由网格导轨包围，网格导轨分别在顶部和左侧水平和垂直延伸，如图 9.14 所示。

默认情况下，网格有一个行和一列；但是可以有多个行和列。你可以通过单击网格导轨上的所需位置来创建额外的行和列。当你单击网格导轨时，网格线和网格线指示器会相应出现（图 9.14）。如果你单击顶部的网格导轨，则会出现一条垂直网格线，将网格分为两列。同样，如果你单击左侧的网格导轨，则会出现一条水平网格线，将网格分为两行。你可以多次单击网格导轨以在网格中创建行和列。你可以通过移动出现在网格导轨上的三角形网格线指示器来控制行和列的高度和宽度。

> NOTE
> Grid 控件有一个名为 FlowDirection 的属性。此属性默认设置为 LeftToRight。但是，当此属性设置为 RightToLeft 时，会导致网格导轨出现在窗口的顶部和右侧。

## 缩放控件和适应视图按钮

你可以在设计视图左上角找到缩放控件和适应视图按钮。缩放控件允许你放大和缩小设计视图。你可以放大到 20 倍，缩小到 10%。你可以通过拖动缩放控件滑块向上或向下进行放大或缩小。当前缩放级别，在图 9.15 中为 80%，显示在缩放控件上方。

## 移动和调整大小手柄

你可以使用移动和调整大小手柄分别在设计视图中移动和调整控件大小。移动和调整大小手柄仅在选择控件时出现。请注意，移动手柄仅出现在某些选定控件上，例如 Grid 和 StackPanel。对于这些控件，移动手柄位于控件左上角，如图 9.16 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_361_0.png)

你只需单击并拖动移动手柄即可在设计视图中重新定位控件。你可以通过简单地选择并拖动它们来移动其他控件（移动手柄不出现的控件）。

当你选择一个控件时，你还可以看到其调整大小手柄。调整大小手柄出现在控件的四个角落作为方形框，如图 9.16 所示。你可以单击任意一个手柄并向外或向内拖动以调整控件大小。请注意，当你单击控件的任意一个调整大小手柄时，当前高度和宽度会以红色显示在控件的右侧和底部，如图 9.17 所示：

## 边距线和边距桩

在 WPF 4.0 中，控件存在于容器控件内，其中之一是 Grid 控件，当你创建它们时，该控件会自动添加到 WPF 应用程序中。当你在网格上拖放控件时，你可以更改控件与网格之间的距离，即边距。边距是从控件边缘到容器控件边缘的距离。如果你使用 Grid 作为容器控件，则边距是从控件边缘到最近网格线的距离。每个控件都有四个边距——顶部、底部、左侧和右侧。这些边距由从控件边缘伸出的四条直线表示，称为边距线，如图 9.18 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_362_0.png)

# 图 9.18：显示按钮控件的边距线和桩

请注意，边距线仅在控件被选中时出现。你可能会注意到在图 9.18 中，只有按钮控件被选中，并且其顶部和左侧边距线出现。相反，在按钮控件的右侧和底部边缘有一个小圆圈，称为边距桩。右侧和底部边缘的边距桩表示相应的边距设置为零，即未为相应边缘设置边距。如果你单击边距桩，则该边缘的边距会自动设置并且边距线会出现。同样，如果你单击边距线，则它会变为边距桩。

控件的边距通过控件的 Margin 属性统一访问。你可以在设计视图、XAML 视图或代码隐藏文件中设置控件的 Margin 属性。你可以在设计视图中通过选择并拖动控件来设置 Margin 属性。你也可以使用属性窗口（本章后面讨论）通过输入边距值来设置 Margin 属性。你需要以顺时针方式从左侧边距开始提供边距值，即左侧、顶部、右侧和底部，如图 9.19 所示：

## 对齐线

WPF 设计器中的 Snaplines 功能用于帮助你在 WPF 应用程序中对齐控件。只有当存在多个控件并且你希望以控件边缘相互对齐的方式对齐控件时，才会出现对齐线。对齐线显示为沿控件边缘的浅棕色线，如图 9.21 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_363_0.png)

在图 9.21 中，你可以看到在对齐线的一端显示了数字 69。此数字表示你想要对齐的控件边缘之间的距离。如果不想看到对齐线，可以在拖动或调整控件大小时按键盘上的 ALT。
