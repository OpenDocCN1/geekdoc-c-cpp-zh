# Summary

In this chapter, you have learned the deployment of Windows and Web applications in Visual Studio 2010. The chapter has begun with the exploring the Windows Installer and ClickOnce deployment technologies of Visual Studio 2010. Next, you have learned different editors and prerequisites required to run an application on a target computer. For instance, the File System editor enables you to add project outputs, shortcuts, and other files to a deployment project and specifies where these items will be installed on the target computer. You have also learned the XCopy deployment to deploy an application by copying its assembly files to a folder on a target computer. Finally, you have learned the deployment of Web applications using different technologies, such as Web deployment packages and One-Click publishing.

In the next chapter, you learn about the ADO.NET Entity Framework concept, which enables you to visually design models and mappings of databases, tables, and views related you applications in Visual Studio 2010.
