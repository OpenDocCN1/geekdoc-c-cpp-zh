# In Depth

Flow of a program defines the execution path of a program. Normally, a program is executed in a sequential manner. In case we want to change the flow of execution of a program, we can do so by using the control flow statements. We can use the control flow statements to change the execution path of a program under the following conditions:

+   - To execute specific blocks of code on the fulfilment of specific conditions
+   - To execute specific blocks of code on the non-fulfilment of specific conditions
+   - To execute specific blocks of code based on a specific value
+   - To execute specific blocks of code repeatedly as long as specific conditions are fulfilled.
+   - To transfer the program control from one block of code to another block of code

The control flow statements can change the program flow according to your requirements and needs. However, sometimes it may happen that although your program is logically correct and has been compiled successfully, it does not display the output according to the inputs provided by the user and terminates abruptly. Such a situation may arise due to an exception in your program. An exception is an event that occurs during the execution of the program that disrupts the normal flow of the program’s instruction. The try statement checks whether or not an exception has occurred.

In this chapter, you learn about the different types of control flow statements, such as selection statements, iteration statements, and jump statements. You also learn about exception handling. Finally, you learn about the checked and unchecked statements, which are used to check the memory overflow exceptions.

Let’s start by learning about control flow statements.

# Control Flow Statements

Sometimes, while programming, we need to change the flow of program control. Control flow statements are used to change the flow of execution of a program. In C# 2010, the control flow statements are divided into three categories, which are as follows:

+   - **Selection statements** — Executes a block of code only when a certain condition or a set of conditions is fulfilled
+   - **Iteration statements or loops** — Executes a specific block of code as long as a certain condition is fulfilled
+   - **Jump statements** — Transfers the program control from one block of code to another

Let’s discuss these control flow statements in detail, one by one.

# Selection Statements

Selection statements are the statements that cause the program flow to be changed when a certain condition is fulfilled. A condition is a Boolean expression, which is defined inside the parenthesis of a selection statement. This condition is checked before the execution of a block of code inside the selection statement. C# supports two types of selection statements:

+   - **if statement** — Allows you to test whether or not a certain condition is fulfilled. If the condition is fulfilled, the program control is transferred to the block of code that is inside the if statement; otherwise, the program control is transferred to another block of code.
+   - **switch statement** — Allows you to compare an expression with different values. When the expression is matched with some specific value, the program control is transferred to its corresponding block of code.
