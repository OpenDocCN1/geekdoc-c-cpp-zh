The integration of SQL Server 2008 with .NET Framework 4.0 CLR allows you to create a user-defined aggregate function in .NET Framework and make it accessible to Transact-SQL or other managed code. You can create a user-defined aggregate function as a CLR object by using the SqlUserDefinedAggregate attribute and aggregation contract methods. The SqlUserDefinedAggregate attribute is a class, which belongs to the Microsoft.SqlServer.Server namespace, and used to indicate that the current type should be registered as a user-defined aggregate. The aggregation contract methods include Init, Accumulate, Merge, and Terminate that are used to save the intermediate states of an aggregate function. In .NET Framework, a user-defined aggregate function is defined as a class, which is compiled and build to a CLR assembly, using an appropriate language compiler. Next, you need to register the assembly in SQL Server 2008 by using the CREATE ASSEMBLY statement. Finally, create a user-defined aggregate function that uses the CREATE AGGREGATE statement and the reference of registered assembly.
