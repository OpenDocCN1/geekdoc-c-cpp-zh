## The WebService Attribute

The WebService attribute is a member of the System.Web.Services namespace, and conveys information about a Web service, such as the name, description, and namespace of the Web service. The WebService attribute consists of the following three properties:

- Name – Defines a class name of the Web service used within the WSDL document. When a proxy uses the WSDL document and builds a proxy class, the name of the class generated corresponds to the name value of the Web service. This property allows overriding the default value.
- Description – Provides a brief description about the functions performed by a class, such as MyFirstWebservice, of the Web service.
- Namespace – Sets the XML namespace for the Web service, which is generally a URL. The reason for using a URL for setting the XML namespace of a Web service is that a URL is always unique.

For example,

```
[WebService(Name="CalculateInterest",Description="This class contains methods for calculating Simple Interest as well as Compound Interest and population of DataSet with the calculated Amount.", Namespace="http://www.InterestRate.com/")]
```

In the preceding example, the value of the Name property is defined as follows:

```
Name="CalculateInterest"
```

The value of the Description property is defined as follows:

```
Description="This class contains methods for calculating Simple Interest as well as Compound Interest and population of DataSet with the calculated Amount."
```

The value of the Namespace property is defined as follows:

```
Namespace="http://www.InterestRate.com/"
```

## The System.Web.Services.WebService Class

A Web service is inherited from the System.Web.Services.WebService class. The WebService class defines some common ASP.NET objects, such as Application, User, Session, and Context, so that you can use them directly in your Web service without redefining them.

The inheritance hierarchy for the WebService class is as follows:

```
System.Object
System.ComponentModel.MarshalByValueComponent
System.Web.Services.WebService
```

## The WebMethod Attribute

A Web service class can include one or more WebMethod attributes, which are accessible across the HTTP protocol. The WebMethod attribute consists of the following six properties:

- CacheDuration – Specifies the time (in seconds) for the response of the request sent by a client. It should be held in the cache of the system. Caching is disabled by default. The performance of the Web service can be improved by putting the response of the service in cache. For example,

```
[WebMethod(CacheDuration=30)]
```

In the preceding example, the value of the CacheDuration property of the [WebMethod] attribute is set to 30.
- BufferResponse – Allows the server to store the response produced by a Web service. After the whole response is stored, the response is transmitted to the clients, all at once. By default, the BufferResponse property is set to True. If the BufferResponse property is set to False, the response is transmitted to the client, as the response is constructed on the server.
- Description – Provides a brief description of the [WebMethod] attribute and this description becomes a part of the WSDL document.
- EnableSession – Enables the session state for a Web method. By default, this property is set to False.
- MessageName – Identifies the polymorphic methods within a class when working with overloaded Web methods.
- TransactionOption – Enables a Web method to act as a root object in the transaction. This means that the Web method can call other transaction-enabled objects, but it cannot be called by another object as a part of the transaction. This limitation exists because the HTTP protocol is stateless.

## Web Service Properties

A Web service consists of many properties, which are defined in the WebService class. This class does not have any public method or event, which is non-inherited. Table 18.4 lists the public properties of the WebService class:

Table 18.4: Public Properties of the WebService Class

| Property | Description |
|---|---|
| Application | Obtains the application object for the current HTTP request. |
| Context | Obtains the HttpContext object for the current request, which encapsulates all HTTP-specific context used by the HTTP server to process Web requests. |
| Server | Obtains the HttpServerUtility object for the current request. |

### Application Property

The Application property of the WebService class is used to obtain the application object for the current HTTP request. The syntax of this property is:

```
[BrowsableAttribute(false)]
public HttpApplicationState Application
{
    get;
}
```

Now, let’s take an example to show how the Application property obtains the application object for the current HTTP request. In this example, we show that the value of the Visit_Counter variable in the Application property obtains the application object and is incremented by 1 each time the browser calls a Web service. Listing 18.7 shows an example of the Application property:

### Listing 18.7: Example of the Application Property

```
<%@ WebService Language="C#" Class="Util"%>
using System.Web.Services;
public class Util: WebService
{
  [WebMethod(Description="Number of visits",EnableSession=false)]
  public int Visit_Counter () {
    if (Application["visit_counter"] == null)
    {
      Application["visit_counter"] = 1;
    }
    else
    {
      Application["visit_counter"] = ((int) Application["visit_counter"]) + 1;
    }
    return ((int) Application["visit_counter"]);
  }
}
```

You can use both the application state and the session state in your Web service. The application state is enabled throughout the session during which a Web service is accessed, whereas in the preceding listing, the session state is disabled for a Web method by setting the EnableSession property of the [WebMethod] attribute to False.

### Context Property

The Context property of the WebService class is used to obtain the HttpContext class for the current request that encapsulates all the HTTP-specific contexts, which the HTTP server uses to process Web requests. The syntax of this property is:

```
[BrowsableAttribute(false)]
public HttpContext Context
{
  get;
}
```

Listing 18.8 demonstrates how to get the request time on the server by using the Context property:

### Listing 18.8: Example of the Context Property

```
<%@ WebService Language="C#" Class="Util" %>
using System;
using System.Web.Services;
public class Util: WebService
{
  [WebMethod(Description="Get the Request Time on the Server",EnableSession=false)]
  public string GetTime()
  {
    return Context.Timestamp.TimeOfDay.ToString();
  }
}
```

The preceding example returns the time of the request on the server by using the Context property.
