## The Path Class

Path 类用于对包含文件或目录路径信息的 String 实例执行操作。Path 是一个字符串，它为你提供文件或目录的确切位置。路径并不总是必须仅指磁盘上的位置。路径格式主要取决于当前平台。因此，一些系统的路径以驱动器或字母名称开头，但这并不适用于所有系统。
在某些系统中，路径还包含文件扩展名，其中包含有关文件的信息。任何文件的扩展名格式都取决于平台。例如，一些系统将其文件扩展名限制为最多 3 个字符，而另一些系统则不限制。当前平台的性质还分析用于分隔路径元素的字符集以及不参与指定路径的字符集。

## File Compression

文件压缩是压缩文件的重要技术之一。你可以使用 GZipStream 类来压缩和解压缩文件。该类提供 gzip 数据格式，该格式使用某些行业标准算法进行文件压缩和解压缩，且不会丢失数据和信息。gzip 数据格式的算法可以扩展以使用其他压缩格式，例如 zip、rar 和 cab。

需要注意的是，文件大小超过 4GB 的文件不能使用 GZipStream 类进行压缩。所有写入扩展名为 .gz 的文件的压缩 GZipStream 对象都可以使用各种常见压缩工具（如 WinZip 和 Winrar）轻松解压缩。该类没有添加或提取文件的固有功能。
