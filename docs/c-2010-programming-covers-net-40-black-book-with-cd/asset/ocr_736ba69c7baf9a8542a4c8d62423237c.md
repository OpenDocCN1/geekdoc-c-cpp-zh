# Using the Slider Control

In WPF, as discussed in the In Depth section, you can add a Slider control to select from a range of values. This control is mainly used in media players. You can display the position of the tick marks on the Slider control by using the TickPlacement property. The TickPlacement and TickFrequency properties define the location of tick marks on the Slider control and the interval between them. The AutoToolTipPlacement property defines where the ToolTip control occurs. Let’s add a Slider control to a WPF application through the XAML code. Create a WPF application named SliderControl (available in the CD) and add the code, shown in Listing 10.12, to the MainWindow.xaml file:

# Listing 10.12: Showing the Code to Implement the Slider Control

```
<Window x:Class="SliderControl.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="350" Width="525">
    <Grid>
        <Slider Width="200" Orientation="Horizontal" HorizontalAlignment="Center"
                Minimum="1" Maximum="9" TickPlacement="Both"
                TickFrequency="3" AutoToolTipPlacement="TopLeft" AutoToolTipPrecision="5"/>
    </Grid>
</Window>
```
