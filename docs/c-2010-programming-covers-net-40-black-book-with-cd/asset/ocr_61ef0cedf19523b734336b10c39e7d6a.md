# Working with Directories

As discussed, directories act as a store house for files. They manage, organize, and store files. A basic file system may contain numerous directories. Files are organized in directories on the basis of their formats. The files having the same format are stored in a single directory. A directory can also contain another directory, which is the called subdirectory of the parent directory. The directories, along with their components, form a tree view or hierarchical structure. In C# 2010, you can work with the help of the DirectoryInfo class contained in the System.IO namespace. The DirectoryInfo class contains a variety of members that help you in creating, moving, deleting, copying and renaming directories.

Let’s start our discussion by checking the existence of a directory.
