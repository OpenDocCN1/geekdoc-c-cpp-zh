## Transforming Images

In WPF, you can transform images using the properties of the BitmapImage class. The different transformations that you can apply to a WPF image are rotating, converting, and cropping the image. You can crop an image either by using the Clip property or the CroppedBitmap property. If you want to display a portion of an image, you should use the Clip property and if you want to encode and save a cropped image, the CroppedBitmap property should be used.
