## In Depth

Windows Form is a graphical user interface (GUI) to build Windows client applications that use Common Language Runtime (CLR) for their execution. This GUI constitutes a part of Microsoft .NET Framework. You can create Windows Form applications in any language supported by CLR.

Prior to the introduction of Windows Forms, programmers had to perform the difficult and cumbersome task of manually writing thousands of lines of code for designing an application. Initially, the programmers chiefly relied on Microsoft’s C++-based Microsoft Foundation Class (MFC) library for coding their projects. However, MFC was soon replaced by Windows Forms, which provided an easy and ideal way to create applications. Windows Forms provide an easy and ideal way to create applications. Windows Forms act as containers that allow you to add different types of controls, such as Button, Label, and RichTextBox, to create Windows applications. You can also use Windows Forms to create message boxes and dialog boxes, to display messages and to accept user data, respectively.

A Windows Forms application allows you to design multiple forms to perform various tasks by using different controls and specifying their properties and events. For instance, you can create a Windows Forms application to accept the user data from one form and display the details on another using different set of controls.

In this chapter, you learn about Windows Forms. Next, you learn how to create Windows Forms and add controls to them. You also learn how to perform tasks, such as displaying or hiding the Minimize and Maximize buttons of forms, disabling and enabling Windows Forms, changing the title of a Windows Form, setting the border of a Windows Form, and creating multiple forms. You also learn how to create the always-on-top Windows Form as well as the owned Windows Form. In addition, the chapter describes some of the common operations that can be performed using controls. Finally, the chapter describes common mouse and keyboard events, including how to specify mouse cursor types for controls and forms.

## Exploring Windows Forms

A Windows Form, as you know, is a graphical user interface on which you can either display information, textual or graphical, to a user or take the input from the user in the form of text or images by using a variety of controls. The support for Windows Forms in C# 2010 is provided by the Form class of the System.Windows.Forms namespace. The Form class itself is derived from the Control class.
