# # In Depth

In the present scenario, Internet is emerging as the most widely-used medium for performing various tasks, such as exchanging data and information as well as conducting online shopping and bank transactions. Apart from the common people, most of the governmental organizations and business houses entirely depend on this medium for transmitting and receiving critical information and conducting their day-to-day business. All this information and data need to be secured against unauthorized access from illegal and malicious sources. Security is implemented in a website mainly through two processes, i.e. authentication and authorization. Authentication refers to the process of recognizing the identity of a user; whereas, authorization is the process of providing access to various resources, such as databases and printers, to the authenticated users.

Earlier, you need to write large pieces of code to create forms and user interfaces (UI) for authenticating the user, and displaying the desired page based on the roles or rights given to the user. However, creating such forms or user interfaces with the help of standard ASP.NET server controls is quite tedious and time-consuming. Microsoft realized the problem and developed a new series of server controls, called Login controls. To use Login controls in your website, you just need to drag-and-drop them on the Web form, which means there is no more need to write lengthy code in the code-behind file. Login controls helps you to ensure that only authenticated users are allowed to access your website. The Login controls have built-in functionality (called Membership service) for all the tasks related to authentication and authorization of users. Login controls were introduced with ASP.NET 2.0 and are also available with later versions of ASP.NET, such as 3.0, 3.5, and 4.0.

Web Parts controls in ASP.NET are set of controls that work together to enable you to create a Web page which an end user can modify by changing the appearance and behavior of the user interface. In other words, Web Parts controls enable you to build flexible websites that can be customized dynamically at run time. Web Parts are objects of a Web form on which users can perform multiple functions, such as open, close, minimize, or modify the content, behavior, or appearance of a Web Parts control, according to the requirements. Web pages with multiple Web Parts controls are created using Portal framework.

In this chapter, you learn about the login controls, such as Login, LoginView, LoginStatus, LoginName, CreateUserWizard, Password, and ChangePassword control. You also learn about Web Parts controls, such as WebPartManager, ProxyWebPartManager, WebPartZone, CatalogZone, and EditorZone controls.

# ## Introducing Login Controls

Authentication and authorization are two different functions, which are used to ensure a secure login of a user to a website. Authentication is the mechanism to identify a user while authorization is a mechanism to specify an access level for an authenticated user to access secured resources on the website. These mechanisms are implemented by a particular set of ASP.NET 4.0 controls known as login controls. The login controls provide an all-inclusive login solution for the users of a Web application. The login controls automatically interact with the ASP.NET membership service, validate the credentials of a user, and grant or deny access to the user (if the user is authenticated).

The Membership service is an important feature of ASP.NET that helps you in validating and storing user credentials. In order to authenticate users, the Login controls make use of the Membership service, in which each user is provided with a unique username and password. There is a default Membership provider that is configured automatically while using Login controls in a Web application. In other words, ASP.NET Membership service and Login controls work simultaneously to register and authenticate users. The Membership API can be described by using two new classes, Membership, and MembershipUser. The Membership class provides the Membership service on its own and also provides the functionality for creating users, validating users, and more. The MembershipUser class describes individual users and provides methods and properties for changing the passwords, and retrieving the last-login dates.
