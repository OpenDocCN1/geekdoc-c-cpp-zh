# Flow Documents

Flow documents are designed to provide the better display and readability of content to users. A Flow document automatically adjusts its content when a window is resized. It also provides advanced document features, such as viewing modes that optimize readability and the ability to change the size and appearance of fonts. The various advantages of Flow documents are as follows:

+   - Allows you to perform a full text search of the entire document.
+   - Provides you different options of page viewing mode, such as a single-page viewing mode, a two-page viewing mode, or a continuous scrolling viewing mode.
+   - Contains built-in page navigation control, which includes a button that helps you move to either the next page or the previous page. This control also provides indicators for the current page number and the total number of pages.
+   - Contains zoom controls that help increase or decrease the zoom level by clicking the plus or minus buttons, respectively. The zoom control also includes a slider for adjusting the zoom level.

The Flow documents contain the following components:

+   - Flow document controls
+   - Flow content elements

Let’s discuss these in details one by one.

# Flow Document Controls

Flow document controls are used to display the content of a Flow document. The appearance of the content in a Flow document depends on the object that is used to host the flow content. The different types of Flow document controls are as follows:

+   - FlowDocumentScrollViewer
+   - FlowDocumentReader
+   - FlowDocumentPageViewer
+   - RichTextBox

Among these, the FlowDocumentReader control, the FlowDocumentPageViewer control, and the FlowDocumentScrollViewer control are read-only controls.

# The FlowDocumentScrollViewer Control

The FlowDocumentScrollViewer control allows you to view the flow content in a continuous scrolling mode. It shows the entire document with a scroll bar and allows you to skim through the content when it exceeds the size of the display area. The scroll bar is not visible if the content fits into the size of the window. By default, a vertical scrollbar is always shown when you select the display as FlowDocumentScrollViewer. The horizontal scrollbar is visible, if the HorizontalScrollBarVisibilty property is set to True. The Flow document is the only allowable child element of the FlowDocumentScrollViewer control.
