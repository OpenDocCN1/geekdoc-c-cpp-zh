# The CheckBoxList Control

You can use a CheckBoxList control to display a number of check boxes at once as a column of check boxes. The CheckBoxList control exists within the System.Web.UI.WebControls namespace. This control is often useful when you want to bind the data from a data source to check boxes. The CheckBoxList control creates multiselection check box groups at runtime by binding these controls to a data source. The inheritance hierarchy of the CheckBoxList class is as follows:

```
System.Object
  System.Web.UI.Control
    System.Web.UI.WebControls.WebControl
      System.Web.UI.WebControls.BaseDataBoundControl
        System.Web.UI.WebControls.DataBoundControl
          System.Web.UI.WebControls.ListControl
            System.Web.UI.WebControls.CheckBoxList
```

Noteworthy public properties of the CheckBoxList class are listed in Table 14.18:

# Table 14.18: Noteworthy Public Properties of the CheckBoxList Class

| Property | Description |
|---|---|
| CellPadding | Obtains the distance between the border and data of the cell in pixels |
| CellSpacing | Obtains the distance between cells in pixels |
| RepeatColumns | Obtains the number of columns to display in the CheckBoxList control |
| RepeatDirection | Obtains a value that indicates, whether the control displays vertically or horizontally |
| RepeatLayout | Obtains the layout of the check boxes |
| TextAlign | Obtains the text placement for the check boxes within the group |
