## Using the Blocks and Inlines Properties of Flow Content Elements

You can use the Blocks and Inlines properties in WPF to add elements in a document programmatically. The Blocks property is used to add and remove items from BlockCollection. The Inlines property is used to add and remove items from InlineCollection. The Flow content elements supported by the Blocks property are: Figure, Floater, ListItem, Section, and TableCell. The Flow content elements supported by the Inlines property are: Bold, Hyperlink, Italic, Paragraph, Span, and Underline. Let's create a WPF application named Blocks_and_Inlines_Property (also available on the CD-ROM) to learn how to use the Blocks and Inlines properties. Add the code given in Listing 11.18 to the MainWindow.xaml file of the Blocks_and_Inlines_Property application:

```xml
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
Title="MainWindow" Height="140" Width="300">
```

After, adding the code, given in Listing 11.18, to MainWindow.xaml in which you are creating the FlowDocumentReader as the container, add the code given in Listing 11.19 to the MainWindow.xaml.cs file:

### Listing 11.19: Showing the Code for the MainWindow.xaml.cs File

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Windows;
using System.Windows.Controls;
using System.Windows.Data;
using System.Windows.Documents;

    /// </summary>

            Run First = new Run();

            Bold bold = new Bold();
```
