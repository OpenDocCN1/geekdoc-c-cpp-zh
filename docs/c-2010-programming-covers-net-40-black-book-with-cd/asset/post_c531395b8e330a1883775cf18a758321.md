## Using this Keyword

With the this keyword, you can access an instance of a class and use it with instance methods, instance constructors, and instance properties. Note that the this keyword cannot be used with static members because static members are accessed by a class and not by the instance of the class. To access the instance members of a class, use the this keyword followed by the dot (.) operator. ## Creating an Array of Objects
