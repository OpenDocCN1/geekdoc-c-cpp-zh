# DataTips Pinning

The DataTips Pinning feature of the Visual Studio 2010 IDE is used to track a variable or an expression and view the values of these variables and expressions at the time of debugging. You can use the DataTips Pinning feature by clicking the pin button at the right side of the tip to pin a variable, as shown in Figure 1.25:

![](bbox=[0.14, 0.185, 0.815, 0.42])

Figure 1.25: Showing the Pin Button

Figure 1.25 shows how to pin a variable. You can pin multiple variables in an application and even the sub-properties of a variable.

The DataTips Pinning feature also allows you to add your comments after pinning a variable, as shown in Figure 1.26:

![](bbox=[0.14, 0.505, 0.825, 0.765])

Figure 1.26: Adding the comments on a Pinned Variable

The values of the variable passed in the last debug session are also visible even when the debugging process has stopped (Figure 1.26).
