# Table 28.1: Control Flow Activities

| Activity | Description |
|---|---|
| DoWhile | Executes a workflow element at least once, even if a condition is not true |
| ForEach | Executes an action at least once for each value given in the Values collection |
| If | Executes workflows on the basis of the If-Then-Else condition |
| Parallel | Executes child activities simultaneously and asynchronously |
| ParallelForEach | Performs parallel execution of an embedded statement for each element present in a collection |
| Pick | Executes workflows on the basis of event-based control flow |
| PickBranch | Shows an alternate path of execution in a Pick activity |
| Sequence | Executes other activities in a sequential order |
| Switch | Selects one statement from a number of statements to execute, on the basis of the value of an expression |
| While | Executes a workflow element when a condition is evaluated to true |

Table 28.2 describes the flowchart activities

# Table 28.2: Flowchart Activities

| Activity | Description |
|---|---|
| Flowchart | Executes the contained activities by using the common model of flowchart |
| FlowDecision | Represents a FlowNode element that acts as a conditional node |
| FlowSwitch <T> | Represents a FlowNode element that implements a switch construct with one expression of an activity’s type and an individual outcome for each match |

Table 28.3 describes the messaging activities

# Table 28.3: Messaging Activities

| Activity | Description |
|---|---|
| Send | Represents an activity that sends a message |
| SendReply | Represents an activity that sends a response to a received message |
| Receive | Represents an activity that receives a message |
| ReceiveReply | Represents an activity that receives a reply |

Table 28.4 describes the runtime activities

# Table 28.4: Runtime Activities

| Activity | Description |
|---|---|
| Persist | Represents an activity that requests for the persistency of a workflow |
| TerminateWorkflow | Represents an activity that terminates the current running instance of a workflow |

Table 28.5 describes the primitives activities

# Table 28.5: Primitives Activities

| Activity | Description |
|---|---|
| Assign | Represents an activity that assigns a value to a variable declared in a workflow |
| Delay | Represents an activity that executes a workflow after a specific time period |
