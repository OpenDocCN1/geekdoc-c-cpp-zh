+   1. Open the Visual Studio 2010 IDE and select File→New→Web Site to open the New Web Site dialog box. In the dialog box, select the ASP.NET Web Site option and specify Roles as the name of the website, and click the OK button.

+   2. Open the web.config file and add the following line of code under the <system.web> tag:

```
<roleManager enabled = "true" />
```

The preceding line of code enables role manager of a website. The role manager eases the task of managing roles and performing role-based authorization in your application. You can also perform the same function through Web Administration Tool (WAT). Under the Security tab of the Web Site Administration Tool, enable RoleManager (for more details on WAT, refer Chapter 16, Login and Web Parts Controls in ASP.NET 4.0). It will automatically add the preceding line of code into the web.config file.
