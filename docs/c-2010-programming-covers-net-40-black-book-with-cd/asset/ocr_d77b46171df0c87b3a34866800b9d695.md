```
<Window x:Class="UsingTriggers_SettingValue.MainWindow"
```

# Performing Actions using Triggers

In WPF, you can use a DataTrigger trigger to change a property in an application based on the value of the property. The working of the DataTrigger trigger is similar to that of the PropertyTrigger trigger. The only difference between the two is that the DataTrigger trigger applies property values or performs actions when the bound data meets a specified condition. Let’s perform actions using the DataTrigger trigger. Create a WPF application named UsingTriggers_PerformingActions (available in the CD) and add the code, shown in Listing 10.31, to the MainWindow.xaml file:

# Listing 10.31: Showing the Code for Using Triggers

```
<Window x:Class="UsingTriggers_PerformingActions.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    xmlns:c="clr-namespace:UsingTriggers_PerformingActions"
    Title="DataTrigger Sample" Width = "320" Height = "400" >
    <Window.Resources>
        <c:PlacesData x:Key="PlacesData"/>
        <Style TargetType="ListBoxItem">
            <Style.Triggers>
                <DataTrigger Binding="{Binding Path=State}" value="INDIA">
                    <Setter Property="Foreground" value="Red" />
```
