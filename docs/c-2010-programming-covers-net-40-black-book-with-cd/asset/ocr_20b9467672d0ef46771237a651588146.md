# The ContentControl Control

The ContentControl control in a WPF application is used to display content and has some predefined styles. This means that you cannot change the appearance of the control to a large extent. You can enhance the appearance of the ContentControl control by creating a new DataTemplate class. The ContentControl control has a Content property of the type Object.

The inheritance hierarchy of the ContentControl class is as follows:

```
System.Object
System.Windows.Threading.DispatcherObject
System.Windows.DependencyObject
System.Windows.Media.Visual
System.Windows.UIElement
System.Windows.FrameworkElement
System.Windows.Controls.Control
System.Windows.Controls.ContentControl
```

You can add the ContentControl control to a WPF application by using the following code snippet:

```
<ContentControl>
<!--Content-->
</ContentControl>
```

Table 10.23 describes the important properties of the ContentControl class:

# Table 10.23: Properties of the ContentControl Class

|---|---|
| Content | Gets or sets the content of a ContentControl control |
| ContentTemplate | Gets or sets the data template used to display the content of a ContentControl control |
| HasContent | Retrieves a value that indicates whether a ContentControl control contains content |
