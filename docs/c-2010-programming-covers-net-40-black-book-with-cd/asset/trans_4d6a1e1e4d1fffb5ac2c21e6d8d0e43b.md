
有时，你需要创建一个指针来调用外部函数（即类外部的函数）。通过指针调用外部函数的问题在于，指针指向一块内存，而该内存可能被垃圾回收或在内存中移动。在这种情况下，C# 提供了 `fixed` 语句，允许你在调用指定的外部函数之前将指针固定在内存中。以下代码片段展示了如何使用 `fixed` 语句：

```
unsafe {
int[] x = new int[10];
fixed(int *p = &x)
{
    CallAFunctionWithAPointer(*p);
}
```

正如你在上述代码片段中所见，`fixed` 关键字将指针固定在内存中，直到你调用 `CallAFunctionWithAPointer()` 函数为止。固定指针只是一个临时步骤，因为你无法永远将指针固定在内存中——锁定仅在 `fixed` 关键字包围的块的起始花括号和结束花括号之间生效。

## 声明指针

如你所知，指针是保存另一个变量内存地址的变量。在 C# 中，你可以声明指针来保存值类型（如 `int`、`char` 或 `double`）的内存地址。声明指针的语法如下：

```
<type> * <pointer_name>
```

上述语法中使用的表达式的描述如下：

- 值类型 —— 指定值数据类型，如 `int`、`char` 或 `double`。
- 解引用运算符 —— 向编译器指明该运算符之后的变量是指针变量。它用星号（*）符号表示。
- 指针名 —— 指定指针变量的名称。

现在让我们通过一个示例来了解如何声明指针变量：

```
int *MyPointer
```

上述声明创建了一个名为 `MyPointer` 的指针变量，它指向一个整数类型的内存地址。语法 `*MyPointer` 表示位于 `MyPointer` 变量所持有的内存地址处的类型。因此，我们可以将整数值赋给 `*MyPointer`，如下所示：

```
*MyPointer=100
```

在上述代码片段中，`*MyPointer` 指针变量并不指向整数值 100；实际上，它保存的是存储整数值 100 的内存地址的起始四个字节。与指针上下文相关的另一个重要符号是 `&` 运算符。它返回其后面变量的内存地址。以下代码片段向你展示如何通过指针存储变量的地址：

```
int Number=100;
int *MyPointer;
MyPointer=&Number;
```

从上述代码中，我们可以得出结论：`MyPointer` 变量保存的是 `Number` 变量值所存储的内存地址，而 `*MyPointer` 是位于 `MyPointer` 变量所持有的内存地址处的整数值。

指针也可以指向数组的元素，如下面的代码片段所示：

```
int *MyPointer;
int MyArray[50];
MyPointer=MyArray[20];
```

在上述代码片段中，`MyPointer` 变量指向 `MyArray` 数组的第二十一个元素（数组索引从 0 开始）。

## 对指针执行算术运算

你可以像对任何其他变量一样对指针执行算术运算。然而，对指针执行算术运算与对其他变量执行这些运算有所不同。例如，你不能对指针执行减法运算。表 6.1 显示了在非安全上下文中可以应用于指针的不同类型的运算符/关键字：

| 表 6.1：应用于指针的运算符/关键字 |
| 运算符/关键字 | 类型 | 含义 |
| * | 解引用 | 执行指针间接引用 |
| & | 地址 | 获取变量的内存地址 |
| -> | 指针 | 通过指针访问结构体的成员 |
| [] | 索引 | 表示指针变量所指向的索引 |
| +,- | 加法和减法 | 表示对指针类型执行加法和减法运算符 |
| ++,-- | 递增和递减 | 表示对指针类型执行递增和递减运算符 |
| ==,!=,<,>,<=,>= | 比较 | 表示对指针类型执行比较和相等运算符 |
| fixed | 固定 | 临时固定变量以查找其地址 |
| stackalloc | 堆栈分配 | 直接在堆栈上分配 C# 数组 |

对指针执行的操作如下：

- 加法和减法 —— 在整数值和指针变量之间执行加法或减法运算；但是，不能在两个指针变量之间执行加法或减法运算。考虑以下代码片段，其中展示了如何将两个指针相加：

```
MyPointer= MyPointer1 + MyPointer2; //Error
```

上述代码片段会生成错误，因为你正在将两个指针变量 `MyPointer1` 和 `MyPointer2` 相加。

然而，可以将整数值添加到指针变量。考虑以下代码片段，其中指针变量 `MyPointer` 与一个整数值相加：

```
MyPointer= MyPointer + 4;
```

现在，在上述代码片段中，如果指针变量 `MyPointer` 在加法之前指向数组的第五个元素，那么在加上 4 之后，它将指向数组的第九个元素。类似地，如果执行 `MyPointer= MyPointer - 4;`，则将指向数组的第一个元素。

如果对两个指针变量执行减法运算，结果是这两个指针变量所持有的地址之差。以下代码片段展示了两个指针的减法：

```
int MyArray[10];
int *MyPointer1, *MyPointer2;
int *MyPointer1 = MyArray + 2;
int *MyPointer2 = MyArray + 5;
MyPointer2= MyPointer2 - MyPointer1;
```

在上述代码片段中，你可以看到在减法之后，指针变量 `MyPointer2` 的值变为 3。

- 递增和递减 —— 指递增或递减指针变量的值。递增和递减运算符可以使用 `++` 和 `--` 符号来实现。例如，如果 `MyPointer` 指针引用 `MyArray` 数组的第三个元素，那么 `MyPointer++` 引用 `MyArray` 数组的第四个元素，而 `MyPointer--` 引用 `MyArray` 数组的第二个元素。

- 比较 —— 使用比较运算符（如 `==`、`!=`、`<`、`>`、`<=` 和 `>=`）对任意两个指针进行比较。
- 赋值 —— 将另一个指针的值或 `null` 赋给指针变量。

## 转换指针

指针转换是指将指针类型的变量转换为另一种数据类型。在 C# 中，指针转换包括以下转换：

- 将指针类型转换为 `void*` 类型
- 将任何空类型指针转换为任何指针类型

此外，在非安全代码中还提供了以下显式指针转换：

- 将任何指针类型变量转换为另一个指针类型变量
- 将 `sbyte`、`byte`、`short`、`ushort`、`int`、`uint`、`long` 或 `ulong` 类型的指针变量转换为任何其他指针类型变量

当你将一种指针类型转换为另一种时，指针的实际值不会改变。这意味着转换后指针所表示的地址保持不变。指针转换应遵循这样一个概念：将一个指针类型（如 `Type1`）转换为另一个类型（如 `Type2`）。进一步地，将 `Type2` 转换为另一个类型（如 `Type3`），那么 `Type1` 应该与 `Type3` 兼容。这个概念称为“正确对齐”，它在本质上是可传递的。让我们通过一个示例来了解指针转换，如下面的代码片段所示：

```
char MyChar = 'A';
char* CharPointer = &MyChar;
void* VoidPointer = CharPointer;
int* IntPointer = (int*)VoidPointer;
int i = *IntPointer;    // undefined
*IntPointer = 121212;   // undefined
```

在上述代码片段中，`VoidPointer` 指针正在访问 `CharPointer` 指针，而 `IntPointer` 指针正在访问 `VoidPointer` 指针。

## 委托

委托是一种特殊的对象类型，其中包含方法的详细信息而非数据。在 C# 中，委托是类类型的对象，用于调用在创建时封装到其中的方法。委托可用于持有对任何类的方法的引用。它携带三条重要信息——它所调用的方法的名称、该方法的参数（如果有），以及该方法的返回值（如果有）。

在以下小节中，你首先学习如何创建和使用委托。然后，你将了解多播委托、协变和逆变。此外，你还会了解带有委托的匿名方法。

## 创建和使用委托

假设你需要创建一个程序，该程序需要诸如学生信息之类的数据，以便将其显示在网站上。可以通过调用方法检索此数据，而无需在编译时知道要调用哪个方法。在这种情况下，你需要创建一个委托对象，并在该委托对象中封装对该方法的引用。在你的程序中创建和使用委托有以下四个步骤：

- 声明委托
- 定义委托方法
- 创建委托对象
- 调用委托对象

### 声明委托

可以使用以下语法声明委托：

```
Access-modifier delegate return-type delegate-name(parameter-list);
```
