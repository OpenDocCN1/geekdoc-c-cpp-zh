The BlockCollection class represents a class of Block elements. The child elements of the BlockCollection class in a FlowDocument are Section, ListItem, TableCell, Floater, and Figure. This class can only be created inside an element that owns BlockCollection, such as FlowDocument. It cannot be instantiated directly and has no default or overloaded constructor. You cannot create an instance of this class in XAML. You can use and create an instance of the BlockCollection class in the code-behind file.

The inheritance hierarchy of the BlockCollection class is as follows:
