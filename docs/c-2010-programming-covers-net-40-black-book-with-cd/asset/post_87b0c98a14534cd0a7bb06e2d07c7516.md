As each and every operator in C# has its own value within an expression; therefore, C# provides them a precedence level that permits the C# compiler to execute the expression in a specific order. With a large set of operators in C#, you can use many of them simultaneously in an expression to perform required calculations. However, the use of two or more operators may result in conflict of the operator precedence, i.e. which operation is performed first. For this purpose, C# associates the precedence with each operator to define the evaluation order of the expression having these operators. Operator precedence is a set of rules that specifies the order in which the compiler evaluates an expression. The operators are associated with either the expression on its left or the expression on its right, which is known as the associativity of the operator. Table 2.7 lists the precedence of the different operators in C#:

| + (arithmetic), - (arithmetic) | Left |

In Table 2.7, the operators at the same level have equal precedence and are evaluated in the given order in an expression until and unless separated by the parenthesis.
