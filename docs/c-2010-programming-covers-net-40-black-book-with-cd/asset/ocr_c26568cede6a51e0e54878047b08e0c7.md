# The EntityDataSource Control

The EntityDataSource control helps you to connect with ADO.NET Entity Data Model (EDM) to perform various database operations, such as create, insert, remove, and update. When you add an EntityDataSource control to your ASP.NET page, the following line of code appears in the Source view page:

```
<asp:EntityDataSource ID="EntityDataSource1" runat="server"> </asp:EntityDataSource>
```

The inheritance hierarchy of the EntityDataSource control is as follows:

```
System.Object
  System.Web.UI.Control
    System.Web.UI.DataSourceControl
      System.Web.UI.WebControls.EntityDataSource
```

Noteworthy properties of the EntityDataSource class are listed in Table 26.44:

| Table 26.44: Noteworthy Properties of the EntityDataSource Class |
| Property | Description |
| AutoGenerateOrderByClause | Gets or sets a value that indicates whether the EntityDataSource control dynamically creates an Order By clause based on values in the OrderByParameters collection |
| AutoGenerateWhereClause | Obtains or sets a value that indicates whether the EntityDataSource control dynamically creates a Where clause based on values defined in the WhereParameters collection |
| AutoPage | Obtains or sets a value that indicates whether the EntityDataSource control supports navigation through sections of the data at run time |
| AutoSort | Obtains or sets a value that indicates whether the EntityDataSource control supports sorting of the data at run time |
| BindingContainer | Allows you to get the control that contains data binding for this control. (Inherited from Control) |
| ChildControlsCreated | Allows you to get a value that indicates whether the child controls have been created for a server control. (Inherited from Control) |
| ClientID | Allows you to get the server control identifier generated by ASP.NET. (Inherited from DataSourceControl) |
| ClientIDSeparator | Allows you to get a character value representing the separator character used in the ClientID property. (Inherited from Control) |
| Context | Allows you to get the HttpContext object linked with the server control for the current Web request. (Inherited from Control) |
| ContextTypeName | Obtains or sets the name of the type of data that contains the property whose value has the data that you want to retrieve |
| Controls | Gets a ControlCollection object that represents the child controls for a specified server control in the UI hierarchy. (Inherited from DataSourceControl) |
| DesignMode | Gets a value indicating whether a control is being used on a design surface. (Inherited from Control) |
| EnableDelete | Obtains or sets a value that indicates whether data records can be deleted through the EntityDataSource control |
| EnableInsert | Obtains or sets a value that indicates whether data records can be inserted through the EntityDataSource control |
| EnableTheming | Gets a value indicating whether this control supports themes. (Inherited from DataSourceControl) |
