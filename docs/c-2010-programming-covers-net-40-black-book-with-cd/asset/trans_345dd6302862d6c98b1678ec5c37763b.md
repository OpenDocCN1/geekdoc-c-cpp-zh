

## 表 16.17：WebPartManager 类的值得注意的方法

| 方法 | 描述 |
|--------|-------------|
| OnWebPartMoving | 生成 WebPartMoving 事件，指示 WebPartZoneBase 区域中的 Web 部件控件正在移动过程中。 |
| OnWebPartsConnected | 在 Web 部件控件之间建立连接后生成 WebPartsConnected 事件。 |
| OnWebPartsConnecting | 在两个 Web 部件控件之间建立连接时生成 WebPartsConnecting 事件。 |
| OnWebPartsDisconnected | 在 Web 部件控件之间的连接终止后生成 WebPartsDisconnected 事件。 |
| OnWebPartsDisconnecting | 生成 WebPartsDisconnecting 事件，表示 WebPartZoneBase 区域中的两个 Web 部件控件即将终止连接。 |
| OpenFile | 检索用于读取文件的流。文件路径指定为参数。 |
| RaiseBubbleEvent | 提供子控件的事件的来源和信息给其父控件。 |
| RegisterClientScript | 允许 WebPartManager 控件提供用于个性化功能的客户端脚本，例如在网页中拖拽 Web 部件控件。 |
| RemovedControl | 允许服务器控件从 Control 对象的 Controls 集合中移除。 |
| Render | 重写 Control.Render (HtmlTextWriter 方法，使得 WebPartManager 控件被阻止渲染任何内容。 |
| RenderChildren | 将服务器控件的子控件的内容提供给 HtmlTextWriter 对象，该对象写入要在客户端上呈现的内容。 |
| RenderControl | 显示服务器控件的内容，如果启用了跟踪，则存储与跟踪相关的信息。 |
| ResolveAdapter | 检索负责渲染指定控件的控件适配器。 |
| ResolveClientUrl | 获取要在其上运行网站的目标浏览器所使用的 URL。 |
| ResolveUrl | 转换 URL，使其可在请求客户端上使用。 |
| SaveControlState | 为 WebPartManager 控件存储与状态相关的数据。您可以通过请求包含 WebPartManager 控件的网页来恢复数据。 |
| SaveCustomPersonalizationState | 存储 WebPartManager 控件为网页维护的自定义个性化状态数据，以便在每当重新加载网页时重新加载此数据。 |
| SaveViewState | 存储服务器控件视图状态中的更改。此方法仅保存当网页回发到服务器时发生的更改。 |
| SetDesignModeState | 设置控件的设计时数据。 |
| SetPersonalizationDirty | 设置一个标志，指定 WebPartManager 控件的自定义个性化数据是否已更改。 |
| SetRendererMethodDelegate | 分配一个事件处理程序委托，以将服务器控件的内容提供给父控件。 |
| SetSelectedWebPart | 设置 SelectedWebPart 属性的值，使其等于当前选定的 Web 部件控件的值。 |
| ToString | 返回表示当前对象的 String 值。 |
| TrackViewState | 允许跟踪 WebPartManager 控件的视图状态数据中的更改。要启用跟踪，该方法调用基础的 Control.TrackViewState() 方法。 |

WebPartManager 类的值得注意的属性列于表 16.18：

## 表 16.18：WebPartManager 类的值得注意的属性

| 属性 | 描述 |
|----------|-------------|
| Adapter | 检索用于 WebPartManager 控件的浏览器特定适配器。 |
| AppRelativeTemplateSourceDirectory | 检索或指定包含 WebPartManager 控件的网页或对象的应用程序相对虚拟目录。 |
| AvailableTransformers | 检索可用于在服务器控件之间创建 Web 部件连接的 WebPartTransformer 对象的集合。 |
| BindingContainer | 检索包含 WebPartManager 控件的数据绑定属性的服务器控件。 |
| ChildControlsCreated | 检索一个值，指示服务器控件的子控件是否已创建。 |
| ClientID | 使您能够使用由 ASP.NET 生成的服务器控件标识符。 |
| ClientIDSeparator | 检索一个字符值，表示 ClientID 属性中使用的分隔符字符。 |
| CloseProviderWarning | 检索并指定一条警告消息，当用户关闭充当连接中其他服务器控件的提供程序的服务器控件时显示该消息。 |
| Connections | 检索对网页上当前连接集的引用。 |
| Context | 检索引当前 Web 请求的 HttpContext 对象。HttpContext 对象封装了请求信息，例如访问网站的用户和计算机。 |
| Controls | 检索网页上 WebPartZoneBase 区域中包含的所有 Web 部件、服务器或用户控件的集合。 |
| DeleteWarning | 检索并指定一条自定义警告消息，当服务器控件被删除时显示。 |
| DesignMode | 检索一个值，指示服务器控件是否在设计图面上使用。 |
| DisplayMode | 检索或指定包含 Web 部件控件的网页的显示模式。 |
| DisplayModes | 检索与 WebPartManager 控件关联的只读模式下的显示模式集。 |
| DynamicConnections | 检索网页上存在的动态连接的集合。 |
| EnableClientScript | 检索或设置一个值，指定包含 WebPartManager 控件的网页上是否启用客户端脚本。 |
| EnableTheming | 检索一个值，确定网页上是否启用主题。 |
| EnableViewState | 检索或指定一个值，指示服务器控件是否将其视图状态及其包含的任何子控件的视图状态持久保存到请求客户端。 |
| Events | 检索 WebPartManager 控件的事件处理程序列表。 |
| ExportSensitiveDataWarning | 检索或设置警告消息文本，当用户从 Web 部件控件导出敏感数据时显示该消息。 |
| HasChildViewState | 检索一个值，指示当前服务器控件的子控件是否已保存视图状态设置。 |
| ID | 检索或设置 Web 服务器控件的标识符。 |
| IdSeparator | 检索用于分隔 WebPartManager 控件的子控件的控件标识符的字符。 |
| Internals | 检索对 WebPartManagerInternals 类的引用，该类用于合并和分离在 WebPartManager 类中实现的一组方法。 |
| IsChildControlStateCleared | 检索一个值，指示 WebPartManager 控件的子控件是否拥有控制状态，该状态保存特定于控件的信息，这些信息在回发时对于发送到服务器至关重要。 |
| IsCustomPersonalizationStateDirty | 检索一个值，指示是否已进行任何影响 WebPartManager 控件的页面级个性化细节的个性化更改。 |
| IsTrackingViewState | 检索一个值，指示服务器控件是否正在保存对其视图状态的更改。 |
| IsViewStateEnabled | 检索一个值，指示 WebPartManager 控件是否启用了视图状态。 |
| LoadViewStateByID | 检索一个值，指示是否可以通过 ID 而不是索引加载 WebPartManager 控件的视图状态。 |
| NamingContainer | 检索对 Web 服务器控件的命名容器的引用，以便为每个 Web 服务器控件创建唯一的命名空间。 |
| Page | 检索对包含 WebPartManager 控件的网页实例的引用。 |
| Parent | 检索对网页控件层次结构中服务器控件的父控件的引用。 |
| Personalization | 检索对包含个性化网页所需数据的对象的引用。 |
| SelectedWebPart | 返回对当前选定的 Web 部件或服务器控件的引用。 |
| Site | 返回有关容器控件的信息，该容器控件在 Design 视图中修改时存储当前控件。 |
| SkinID | 获取或设置空字符串，以确保用户无法将任何外观应用于 WebPartManager 控件。 |
| StaticConnections | 返回对网页上定义为静态连接的所有 WebPartConnection 对象的集合的引用。 |
