# Chapter 20: Windows Services

**Tip**  
You can also click the Start link, displayed in the left-side of the service list, to start the service.

After the service is started, the status of the service changes to Started, as shown in Figure 20.24:

![](bbox=[0.158, 0.178, 0.86, 0.294])

**Figure 20.24: Showing the MyService Windows Service As Started**

**NOTE**  
A problematic Windows service can make your computer unusable, so be careful while creating Windows services. Until you are sure that a Windows service is working the way you want it to, it is a good idea to keep its start mode as *Manual*, so it does not start automatically when you reboot your system.

To stop the service, right-click MyService in the SCM manager and select Stop from the context menu. Now you can check whether the entries of our service have been made to its event log from the Event Viewer, as shown in Figure 20.25:

![](bbox=[0.158, 0.466, 0.858, 0.802])

**Figure 20.25: Showing the Entries of the MyService Service in the Event Log**

**NOTE**  
You can open the Event Viewer window by clicking Start → Control Panel → Administrative Tools → Event Viewer.
