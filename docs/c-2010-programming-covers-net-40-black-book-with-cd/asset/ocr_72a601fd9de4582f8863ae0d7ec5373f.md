# The System.Web.UI.Page Class

Any Web page requested from a server hosting .NET Framework, whether it contains .NET code or HTML text, is actually based on the System.Web.UI.Page class. All Web pages are inherited from the System.Web.UI.Page class. Here is the class hierarchy for the Page class (note that the Control class here is the ASP.NET Control class, not the Windows application’s Control class):

+   - System.Object
+   - System.Web.UI.Control
+   - System.Web.UI.TemplateControl
+   - System.Web.UI.Page

You can find the important public properties of the Page class in Table 13.5:

| Property | Description |
|----------|-------------|
| Application | Gets an Application object |
| Cache | Gets the Cache object |
| ClientTarget | Gets or sets a value that allows you to override the detection of browser capabilities automatically and handles page rendering for specific browsers |
| Controls | Obtains a ControlCollection object representing child controls |
| EnableViewState | Obtains a value indicating whether the page maintains its view state and the view state of any server controls it contains |
| ErrorPage | Specifies an error page's URL in case there are unhandled page exceptions |
| ID | Specifies an identifier for a specific instance of the Page class |
| IsPostBack | Indicates whether a page is being loaded in response to a client postback, or if it is being loaded and accessed for the first time |
| IsValid | Indicates if a page validation was successful |
| Request | Gets the current HTTP Request object |
| Response | Gets the current HTTP Response object |
| Server | Gets the current Server object |
| Session | Gets the current Session object |
| Trace | Obtains the TraceContext object for the current Web request |
| User | Gets data about the user |
| Validators | Gets a collection of the validation controls in a page |
