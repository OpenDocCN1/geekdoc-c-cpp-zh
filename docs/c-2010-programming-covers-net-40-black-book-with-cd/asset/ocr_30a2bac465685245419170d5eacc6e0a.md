You can create struct types by using the struct keyword. When you create a struct object and assign it to variable, the variable holds the value of the struct object. You can also use a struct type as a nullable type by assigning a null value to it. Listing 2.3 shows how to create a struct type:

# Listing 2.3: Showing an Example of the Struct Type

```
public struct student
{
    string name;
    int rollno;            //fields
    int classname;
    int section;
    ...                    //methods
    ...                    //properties
}
```

In Listing 2.3, we have created a struct type named student and declared it as public. Within the struct body we have declared the members, such as name, rollno, classname, and section.

The struct types are divided into the following five categories:

+   - Integral type
+   - Floating-Point type
+   - Decimal type
+   - Boolean type
+   - Nullable type

Let's discus all these data types in brief in the subsequent sections.

# Integral Type

C# provides a set of basic data types, which are known as integral type. This set consists of the types, such as sbyte, byte, short, ushort, int, uint, long, ulong, and char. To know the size, ranges, and default values of these data types, refer to Table 2.2.

The integral types can be divided into two value types, signed and unsigned. Signed value types may contain negative or positive values and unsigned value types contain only positive values. Unlike C++, conversion between the two types usually requires an explicit cast.

# Floating-Point Type

The floating-point types are divided into two types – single and double. Single floats, similar to the float data type of C++, hold values up to 10^38. The double data types, also similar to the C++ double type, hold values up to 10^308. The floating-point types take the values in fractions. For example, if you declare a variable as float and assign a value 2 to this variable, the variable will store the value 2.0.

# Decimal Type

The other data type, Decimal, is equivalent to a long integer that behaves as if it is a floating-point number. Decimal values are intended to be used for computing monetary values or other calculations in which round off figure is not required. As compared to the floating-point type, the decimal type has more precisions and smaller range.

# Boolean Type

Booleans are simple true or false values. Unlike C++, they cannot be assigned to any other type, nor can they be used in any sort of computation. The result of an expression in C# is not a Boolean expression, unless you specifically assign it as true or false.

# Nullable Type

A programming language supports Nullable data types when dealing with databases or when a user does not want to assign a value to a variable of any data type. You can use different strategies to deal with null values, if programming language does not support Nullable data types. For example, you can use -1 to specify null value for integer variables. You can also use Boolean null indicators to specify null value for variables.
