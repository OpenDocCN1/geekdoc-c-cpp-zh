

Silverlight 3.0 具有常规控件，例如 Button、TextBox、RadioButton 和 ScrollBar，以及形状控件或元素，例如 Ellipse、Rectangle 和 Line。然而，Silverlight 3.0 还提供了一些独特的控件，例如 Calendar、DatePicker 和 TabControl。这些控件可以帮助你为基于 Silverlight 的 Web 应用程序提供动态、交互性和引人入胜的 UI。Silverlight 3.0 现在包含了以前版本中由 Silverlight 运行时（插件）提供的控件，例如 Silverlight 2.0，或是 Silverlight SDK 的一部分。换句话说，这意味着要使用 DatePicker、GridSplitter 和 TabControl 等控件，你必须引用适当的程序集和命名空间。但是，使用 Silverlight 3.0，你只需将这些控件拖放到你的 Silverlight 应用程序界面中，适当的程序集和命名空间就会自动添加到你的 Silverlight 应用程序中。

你应该注意，前述表格中 XAML 元素示例列提供的语法可能会根据添加到你的 Silverlight 应用程序中的命名空间而改变。例如，如果 xmlns:my="clr-namespace:System.Windows.Controls;assembly=System.Windows.Controls" 命名空间被添加到你的应用程序中，那么控件将以 my 作为前缀添加。

Silverlight 3.0 包含了一些新控件，例如 MultiScaleImage 控件，它允许你查看和更改多分辨率图像的大小和位置。MultiScaleImage 控件的主要用途是与 Deep Zoom 技术配合使用。Silverlight 3.0 还为 Silverlight 3.0 控件，例如 HyperlinkButton 和 Button 控件，整合了 ToolTipService 属性。ToolTipService 属性取代了 Silverlight 2.0 Beta 1 中的 ToolTip 控件。

> NOTE
> Silverlight 3.0 控件间接继承 FrameworkElement 类，而 FrameworkElement 类本身派生自 UIElement 类。因此，FrameworkElement 类及其基类定义的属性、方法和事件都可用于 Silverlight 控件。

## 日历控件

Calendar 控件为你提供了处理日期、天、月和年的功能。该控件显示年份、月份和日期，以便用户从可见的月份或年份中选择特定日期。你可以通过使用滚动箭头在月份、年份或十年之间切换，指定用户可见和可选择的日期范围，并在 Calendar 控件中隐藏特定日期范围。此外，你可以通过操作控件的属性来修改 Calendar 控件的外观和感觉。图 17.9 显示了一个 Calendar 控件：

图 17.9：在十年显示模式下显示日历控件

Calendar 控件是 Calendar 类的一个实例，该类存在于 System.Windows.Controls.dll 程序集的 System.Windows.Controls 命名空间中。Calendar 类的类层次结构为：

```
System.Object
  System.Windows.DependencyObject
    System.Windows.UIElement
      System.Windows.FrameworkElement
        System.Windows.Controls.Control
          System.Windows.Controls.Calendar
```

你可以使用各种属性来处理 Calendar 类（或控件）。其中大多数属性是依赖属性和附加属性。表 17.3 列出了 Calendar 类的一些值得注意的属性：

表 17.3：Calendar 类的值得注意的属性
| Property | Description |
|---|---|
| BlackoutDates | Sets or retrieves the list of dates that cannot be selected |
| DisplayDate | Sets or retrieves a particular date that is displayed |
| DisplayDateEnd | Sets or retrieves the last date that is displayed |
| DisplayDateStart | Sets or retrieves the first date that is displayed |
| DisplayMode | Allows you to display the Calendar control in months, years, or decades |
| FirstDayOfWeek | Sets or retrieves the first day of the week |
