# Handling Events

The types of events we have been dealing with until now are handled on the server, not in the browser. However, waiting for events to be handled on the server can be a tedious process. Therefore, you can also add scripting to your Web pages that can support client-side events. Usually, we will stick with server-side code in our Web applications, but you can also let the browser handle some events on the client-side.
