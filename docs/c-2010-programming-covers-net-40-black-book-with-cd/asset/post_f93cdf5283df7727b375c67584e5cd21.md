## Geometries in WPF

The geometries in WPF are derived from the abstract base class, Geometry. The classes that derive from the Geometry class define geometric shapes in WPF. The Geometry objects are used for clipping and rendering 2-D

graphics in WPF. In Table 12.10, you learned about the different Shape elements available in WPF. One of them was the Path object. The Path class has the ability to draw any simple shape, group of shapes, or curves that are more complex. These shapes and curves are described using the Geometry object. To use the Path class, you first need to create an object of the Geometry class and then use it to set the Data property of the Path class. The basic difference between the Path and Geometry classes is that the Geometry class defines a shape and the Path class allows you to draw that shape. The Path class actually uses the Geometry class to describe its content. The inheritance hierarchy of the Geometry class is as follows:

The Geometry and Shape classes might look similar to you as they both describe 2-D shapes, but there are certain important differences between them. The first difference being that the Geometry class inherits from the Freezable class while the Shape class inherits from the FrameworkElement class. The Shape objects are more readily usable and the Geometry objects are more versatile. Therefore, you can say that, the Geometry class simply defines the geometry of a shape and cannot render itself. The Geometry class consists of various classes of geometries, which can be grouped into three categories, given as follows:

- Simple geometry
- Path geometry
- Composite geometry

These categories are discussed in the section ahead.

## Simple Geometry

The simple geometry classes are used to create basic geometric shapes such as lines, rectangle, and ellipse. Basically, a simple geometry class includes three classes, given as follows:

classes. The LineSegment class creates a line between two points in a PathFigure object and the Polyline class draws a series of connected straight lines.

- The RectangleGeometry class — Represents a 2-D rectangle. The RectangleGeometry class is defined with the Rect structure, which specifies the relative position of the rectangle and also its height and width. You can also create a rectangle with rounded edges by setting the RadiusX and RadiusY properties of the rectangle. The RectangleGeometry and Rectangle classes are not the same. The difference lies in the values that each takes. The Rectangle class takes only the Height and Width properties while the RectangleGeometry class takes four properties that describe Size and Location of a rectangle along with Height and Width.

- The EllipseGeometry class — Represents the geometry of a circle or ellipse. The EllipseGeometry class and the Ellipse class are not the same. The Ellipse class has a Fill, Stroke, and other rendering properties which the EllipseGeometry class lacks. The EllipseGeometry class defines the geometry of an ellipse.

## Path Geometry

A path geometry is represented by using the PathGeometry and StreamGeometry classes. These classes are used to create multiple complex figures composed of arcs, curves, and lines. Table 12.14 describes the functioning of the classes of a path geometry:

| Table 12.14: Path Geometry Classes |
| Class | Description |
| PathGeometry | Draws a complex shape that is composed of arcs and curves |
| StreamGeometry | Draws a geometric shape and is a light-weight alternative to the PathGeometry class |

The PathGeometry class is used to define complex shapes that may be composed of arcs, curves, ellipses, lines, and rectangles. It also defines a collection of PathFigure objects and each of the PathFigure objects is composed of one or more PathSegment objects. The different types of PathSegment objects are listed in Table 12.15:

| Table 12.15: Types of PathSegment Objects |
| Segment | Description |
| ArcSegment | Creates an elliptical arc between two points |
| BezierSegment | Creates a cubic Bezier curve between two points |
| LineSegment | Creates a line between two points |
| PolyBezierSegment | Creates a series of cubic Bezier curve |
| PolyLineSegment | Creates a series of lines |
| PolyQuadraticBezierSegment | Creates a series of quadratic Bezier curve |
| QuadraticBezierSegment | Creates a quadratic Bezier curve |

The segments within the PathFigure class are combined into a single geometric shape, as the end point of each segment is the start point of the next segment. You can specify the point from which the first segment is drawn by setting the StartPoint property. The filled area of the PathGeometry class is defined by taking all the PathFigure objects that have their IsFilled property set to True. The FillRule property is applied to determine the enclosed area.

The StreamGeometry class also defines geometric shapes, for instance the PathGeometry class. The only difference is that the StreamGeometry class is a light-weight alternative to the PathGeometry class. The StreamGeometry class does not support data binding, animation, or modification as the PathGeometry class.
