# Creating WCF Services

You have learned about WCF services in the In Depth section. Now, you learn how to create a WCF service. Let’s perform the following steps to create a WCF service:

+   1. Open Microsoft Visual Studio 2010.
+   2. Select File→New→Web Site to open the New Web Site dialog box.
+   3. Select Visual C# language from the Installed Templates section (Figure 19.8).
+   4. Select the WCF Service template from the list of templates in the New Web Site dialog box, as shown in Figure 19.8:

![](bbox=[0.205, 0.283, 0.77, 0.585])

Figure 19.8: Showing the New Web Site Dialog Box

+   5. Select File System from the Web location drop-down list.
+   6. Enter the name of the WCF service as MyFirstWCFService (also available on the CD) along with the location in the combo box of the New Web Site dialog box (Figure 19.8).
+   7. Click the OK button (Figure 19.8).

A new WCF service with the name MyFirstWCFService has been created.

# Creating a Service Contract and Defining the Operations

A service contract defines the operations that a service can perform. The ServiceContractAttribute attribute is used with interfaces or classes to define a service contract. The methods that a service offers are defined through the OperationContractAttribute attribute. In a WCF service application, a file named IService.cs is automatically created, containing a service contract named IService. Replace the code of the IService service contract with the code given in Listing 19.5 to create a service contract:

Listing 19.5: Showing the Code of the IService.cs File
