
However, all COM properties do not fulfill the preceding conditions. For instance, the Excel.Range property has a get accessor that requires a range parameter. To access the Excel.Range property, you need to use the get_Range() method in the following code snippet:

```
var newexcelApp = new Excel.Application();
...
Excel.Range rangeinexcel = newexcelApp.get_Range("A1", Type.Missing);
```

In C# 2010, you can access the Excel.Range Range property, as shown in the following code snippet:

```
var newexcelApp = new Excel.Application();
// ...
Excel.Range rangeinexcel = newexcelApp.Range["A1"];
```

You need to give two arguments to assign a value to the Value property of the Excel.Range object. To do this, you need to either use the set_Value() method or a different property, Value2. The following code snippet shows how to assign values to the value property of the Range object:

```
rangeinexcel.set_Value(Type.Missing, "Range_Name");
// Or
rangeinexcel.Value2 = "Range_Name";
```

You can also set the values of the Value property of the Excel.Range object as follows:

```
rangeinexcel.Value = "Range_Name";
```

The preceding code snippet shows how to set the values of the Value property by using indexed parameters.

## Section IV – Snapshot of .NET Related Technologies

C# 2010 integrates a set of coordinated technologies that helps in reducing the complexity of developing, deploying, and managing applications. These technologies help in building stable and secure websites. This book discusses the following C# 2010 related technologies:

- WPF
- LINQ
- ADO.NET Entity Framework
- ASP.NET AJAX
- Silverlight
- ASP.NET Web Services
- WCF Services
- WF
- MEF and Managed Add-In Framework (MAF)

### WPF

The WPF technology supports various media, such as text, images, audio, and video, and allows you to work with two-dimensional (2-D) as well as three-dimensional (3-D) graphics. All the design-related elements in WPF applications are processed by DirectX. WPF supports XAML language that allows designers to easily and quickly define the elements for the UI of applications. Application developers can then use the UI elements defined using XAML to specify the application logic in the code-behind files in any of the .NET languages, such as C#.

Chapter 9, Introducing Windows Presentation Foundation, describes architecture, class hierarchy, and application model of WPF. In this chapter, you also learn to use XAML in WPF, WPF properties, and WPF events.

### LINQ

LINQ is a component of .NET Framework 4.0. The basic function of LINQ is to add native data-querying capabilities to .NET Framework using syntax similar to SQL. LINQ allows you to define statements that interrogate a data source to yield a requested result set. In addition, it allows you to obtain and manipulate the data in a consistent manner.

Chapter 27, LINQ Queries, discusses the basic LINQ queries and the query operators used to query data from data source. You also learn to retrieve the data from various data sources, such as LINQ to Object, LINQ to ADO.NET, and LINQ to XML.

### ADO.NET Entity Framework

ADO.NET Entity Framework is designed to support data-centric applications and services, and provides a platform for programming against data that raises the level of abstraction from the logical relational level to the conceptual level.

Chapter 22, ADO.NET Entity Framework, discusses features and components supported by Entity Framework, such as Entity Data Model, Object Services, Entity SQL, Client provider, and mapping between conceptual and storage schema.

### ASP.NET AJAX

ASP.NET AJAX is an approach that works on the concept of Page Update rather than Page Replacement. The ASP.NET AJAX provides two ways to developers to build rich Web applications, server-centric and client-centric. The server-centric development approach enables a part of the Web page to be refreshed without posting the entire page to the server. This is done by using the UpdatePanel server control. The client-centric approach allows developers to use control extenders to add pre-defined client-side behavior to the new and existing ASP.NET controls. The extenders use a block of JavaScript code to add new and enhanced capabilities to ASP.NET.

Chapter 7 of CD, Developing ASP.NET AJAX Applications, discusses ASP.NET AJAX along with its components and ASP.NET technology that uses the AJAX approach for Web development.

### Silverlight

Silverlight is a Web-based technology that allows Web designers and developers to stretch the boundaries of Web application development. It is an integration of the rich user interface of desktop applications and the transparency of other Web languages, such as HTML and JavaScript. Silverlight allows you to develop Web applications that contain high-fidelity multimedia content and eye-catching visual effects. Web designers and developers have already embraced Silverlight for building high-quality interactive Web applications.

Chapter 17, Developing Rich-Interactive Applications with Silverlight 3, discusses the main features and architecture of Silverlight.

### ASP.NET Web Services

A Web service is an entity that can be programmed to provide a particular functionality to any number of applications over the Internet. The functionality provided by the Web service can be used by any application, irrespective of the programming language in which the application is created or the hardware platform and operating system on which the application is running. A Web service does not have any user interface. It just provides specific services to its consumers.

Chapter 18, ASP.NET Web Services, discusses how to create and deploy a Web service.

### WCF Services

WCF is a set of .NET technologies that is used to develop and deploy services on Windows. It acts as a platform for creating and distributing connected applications. In addition, it provides a unified framework for rapidly building service-oriented applications.

Chapter 19, Working with Windows Communication Foundation, discusses the layered architecture of the WCF as well as the features of WCF. This chapter also covers the important aspects of addresses, bindings, contracts, hosting, and security with WCF.

### WF

The WF technology provides a standard way of adding workflow to an application. WF is used as a tool to graphically build the workflow. After a workflow has been defined, an application can be built around that definition to support business process.
