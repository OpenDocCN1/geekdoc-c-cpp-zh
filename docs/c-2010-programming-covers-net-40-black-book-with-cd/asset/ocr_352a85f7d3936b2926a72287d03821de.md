# Saving Code on the Toolbox

Visual Studio 2010 provides you with the facility to save your code snippets in the Toolbox for reuse. Let’s perform the following steps to store a piece of code on the Toolbox using example created earlier, FirstWindowsApplication.

+   1. Double-click on the Windows Forms designer. The Code Editor opens with the code of the Load event of the form.
+   2. Enter the following code snippet in the Load event of the form to display a message box:
+   3. Select the code to be reused, and drag the selection onto the desired tab of the Toolbox, as shown in Figure 1.76:

```
private void Form1_Load(object sender, EventArgs e) {
    MessageBox.Show("Welcome to Visual C# 2010");
}
```

![](bbox=[0.195, 0.285, 0.785, 0.525])

Figure 1.76: Dragging the Code from Code Editor to Toolbox

A line marks the code newly added in the Toolbox. You can rename the newly added item in the Toolbox by right-clicking on the item and selecting the Rename option from the context menu. Now when the item is displayed in the edit mode, type a new name for the item, say Welcome Message, and then press the Enter key. The newly added item is displayed in the Toolbox, as shown in Figure 1.77:

![](bbox=[0.195, 0.615, 0.79, 0.865])

Figure 1.77: Displaying the Newly Added Item in Toolbox

The code snippets are added in the Toolbox. Now just like adding any other control on the designer, you can simply drag and drop these snippets to the Code Editor window.
