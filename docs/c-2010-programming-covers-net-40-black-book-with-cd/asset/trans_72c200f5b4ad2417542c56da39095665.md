

- 可扩展性 – 减少数据库的流量并节省资源，从而提高数据库满足用户需求的效率。ADO.NET 在使用数据集时有助于可扩展性。所有数据库操作都是在数据集上执行，而不是在数据库上执行。

- 以 XML 格式传输数据 – 使用 XML 将数据从数据库传输到数据集，并从数据集传输到另一个组件。XML 是 ADO.NET 中用于传输数据的标准格式。您也可以使用 XML 文件作为数据源，并将其中的数据存储到数据集中。

- 通过数据命令与数据库交互 – 指定数据库操作是通过执行数据命令来完成的。所有对数据库的操作，例如检索、修改或更新数据，都是使用数据命令执行的。数据命令要么是结构化查询语言（SQL）语句，要么是存储过程。

## WF

WF 是微软推出的一项技术，它为在 Windows 上构建基于工作流的应用程序提供了一种编程模型。它包括活动、工作流运行时、工作流设计器和规则引擎。WF 在 Framework 3.0 中引入，我们在 Framework 3.5 和 4.0 版本中看到了很多改进。WF 最重要的特性是它提供了业务流程代码与实际实现代码之间的分离。WF 由以下几部分组成：

- Activities – 从开发者处接收一些参数，执行其操作，然后流程转移到下一个活动。活动可以通过编写代码轻松创建，也可以通过从其他活动创建，例如 Code 或 IfElse 活动。

- Workflow Designer – 通过在工作流模型中放置活动来设计工作流。工作流设计器的一个有趣特性是它可以在任何 Windows Forms 应用程序中重新托管。

- Workflow Runtime – 执行工作流中的活动。它是一个轻量级且可扩展的引擎，驻留在 .NET 进程内，使开发人员能够将工作流带入从 Windows Forms 应用程序到 ASP.NET 网站或 Windows 服务的任何事物。

- Rules Engine – 允许为工作流以及任何 .NET 应用程序启用声明式、基于规则的开发。

WF 在集成它的任何应用程序中遵循分层架构。

## WPF

微软的 WPF（以前代号为 Avalon）为构建应用程序提供了基础，并清晰地分离了用户界面和业务逻辑。WPF 有助于构建包含文档、媒体、二维和三维图形、动画以及类似 Web 的特征的界面。它有助于创建具有令人惊艳用户体验的 Windows 客户端应用程序。您可以使用 WPF 创建独立和浏览器托管的应用程序。WPF 应用程序的一些示例是 Yahoo Messenger、New York Times Reader 和 Contoso Healthcare Sample Application。WPF 引入了可扩展应用程序标记语言（XAML），这是一种基于 XML 的语言，用于设计基于 WPF 的应用程序的界面。甚至微软也推出了 Expression Studio，它使用 XAML 为任何基于 Web 或 Windows 的应用程序开发用户界面。

## WCF

WCF（以前代号为 Indigo）是微软在 .NET Framework 3.0 中引入的新技术之一，用于构建和运行连接系统。WCF 是一种面向服务的用于开发应用程序的技术。面向服务的设计导致在服务和客户端之间运行的分布式系统。如果您熟悉 Web 服务、远程处理、分布式事务和消息队列等概念，那么理解 WCF 会更容易，因为它是一种增强技术，用于以更少的时间提供相同的功能并具有更好的特性。

基于 WCF 的应用程序与任何进程都是互操作的，因为它们通过 Simple Object Access Protocol（SOAP）消息进行通信。当 WCF 进程与非 WCF 进程连接时，它使用基于 XML 的编码用于 SOAP 消息，但当它与另一个 WCF 进程连接时，SOAP 消息被编码为二进制格式。WCF 使用可插拔编码系统，这允许程序员编写自己的编码器。随着 .NET Framework 3.5 的发布，JavaScript Object Notation（JSON）被发布，它支持向 WCF 的序列化格式。JSON 有助于 WCF 服务端点处理来自 AJAX 驱动的网页的服务请求。

与以前技术相比，WCF 的增强功能如下：

- 合并 Web 服务、远程处理、分布式事务和消息队列等技术于一处并减少开发时间
- 包含许多强大的企业功能
- 轻松与其他技术集成以提高互操作性

WCF 架构由以下五个层组成：

- Application — 指 WCF 架构的第一层，表示应用程序的位置。
- Contracts — 包含服务、数据和消息契约以及绑定和策略。Contracts 层为您提供有关消息系统不同特性的信息。消息系统涉及从一端到另一端发送和接收消息。
- Service Runtime — 提供有关运行时发生的不同行为的信息。此层加载所有服务。
- Messaging — 提供有关处理消息时所需的不同通道的信息。此层处理需要通信的消息内容。
- Activation and Hosting Services — 指 WCF 架构的最后一层。在此层中，任何服务都可以使用 IIS 或 Windows Activation Service 进行托管。服务也可以手动部署为可执行形式。
