In C#, variables are classified into the following three categories:

+   - Value types
+   - Reference types
+   - Pointer types

Let’s discuss these in detail.

# Value Types

Value types are variables that can be assigned a value directly. They are derived from System.ValueType and have a special behavior in Common Language Runtime (CLR). The value types and their content are stored at the same location in memory. The default values of value types are stored on stack. Table 2.2 lists the available value types in C# 2010:

Table 2.2: Showing the Value Types In C# 2010

|---|---|---|---|
| bool | Represents a Boolean value | True or False | false |
| byte | Represents 8-bit unsigned integer type | 0 to 255 | 0 |
| char | Represents single 16-bit Character type, a char value is a Unicode character | U+0000 to U+ffff | '\0' |
| decimal | Represents 128-bit Precise decimal type with 28-29 significant digits | (-7.9 x 10^28 to 7.9 x 10^28) / (10^0 to 28) | 0.0M |
| double | Represents 64-bit Double-precision floating-point type | ±5.0 x 10^-324 to ±1.7 x 10^308 | 0.0D |
| float | Represents 32-bit Single-precision floating-point type | -3.4 x 10^38 to +3.4 x 10^38 | 0.0F |
| int | Represents 32-bit signed integer type | -2,147,483,648 to 2,147,483,647 | 0 |
| long | Represents 64-bit signed integer type | -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807 | 0L |
| sbyte | Represents 8-bit signed integer type | -128 to 127 | 0 |
| short | Represents 16-bit signed integer type | -32,768 to 32,767 | 0 |

The value types are divided into the following categories:

+   - Struct type
+   - Enum type

Let’s discuss these in detail.

# Struct Type

Struct types are a special form of classes having the properties of value types. As you know that the value types are stored on the stack; inherently the struct types are also stored on the stack. The struct types can be copied and created efficiently, since stacks are the efficient and convenient means of storing and accessing the types. The struct types encapsulate small group of related variables, such as the name, rollno, age, classname, and section of a student. They can contain constructors, methods, properties, operators, events, nested types, indexers, constants, and fields. While creating the struct type, you should remember that struct members cannot be declared as protected as they fail to support inheritance. Under the struct declaration, the fields can be initialized only when they are declared as const or static.
