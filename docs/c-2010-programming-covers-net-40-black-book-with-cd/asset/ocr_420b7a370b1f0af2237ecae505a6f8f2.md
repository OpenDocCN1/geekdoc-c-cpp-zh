# Creating a Simple Silverlight Application

Silverlight provides you with the functionality to develop high-end Web applications that host multimedia and animations. As you have learned in the In Depth section, Silverlight applications are hosted in a Web page. Perform the following steps to create a simple Silverlight 3.0 application:

+   1. Open the Visual Studio 2010 IDE and select File→New→Project. The New Project dialog box appears.
+   2. Select Visual C# →Silverlight from the Installed Templates pane in the New Project dialog box.
+   3. Select Silverlight Application from the middle pane.
+   4. Specify the name of the application as SimpleSilverlightAppCS (available on the CD) and the appropriate location for the application.
+   5. Click the OK button, which displays the New Silverlight Application dialog box.
+   6. Select the Host the Silverlight application in a new Web site option
+   7. Click the OK button. Listing 17.1 shows the code for the MainPage.xaml file of the SimpleSilverlightApp application:
