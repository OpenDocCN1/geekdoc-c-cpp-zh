# Table 38.1: The Articles Table

| Column Name | Data type | Allow Nulls | Description |
|---|---|---|---|
| ArticleID | int | No | Represents unique IDs for articles |
| AddedDate | datetime | No | Represents the date on the which the article was added |
| AddedBy | varchar(200) | No | Represents the name of the sports person who has added the article |
| Title | varchar(200) | No | Represents the title of the article |
| Abstract | varchar(4000) | Yes | Refers to the starting few lines of an article that are displayed with the list of articles |
| Body | ntext | No | Represents the full content of the article |
| ImageUrl | varchar(50) | Yes | Specifies the name or location of the image representing the article |
