# Using Dynamic Layout of Controls

When you design a WPF application, you must decide how to position the controls on the window. This is done by either absolute or dynamic positioning of the controls. Dynamic positioning of controls is done with the help of the Grid, DockPanel, WrapPanel, StackPanel, and UniformGrid controls. These container controls can be combined with other controls as child elements.

# Using the DockPanel Control

The DockPanel control defines an area where you can arrange the child elements either vertically or horizontally. You can add the DockPanel control through the XAML code. Let’s add the DockPanel control to a WPF application. Create a WPF application named DockPanelControl1 (available in the CD) and add the code, shown in Listing 10.5, to the MainWindow.xaml file:

Listing 10.5: Showing the Code to Implement the DockPanel Control

```
<Window x:Class="DockPanelControl1.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="350" Width="525">
    <Grid>
        <DockPanel LastChildFill="True">
            <Border Height="30" Background="Pink" DockPanel.Dock="Top">
                <TextBlock> 1st DockPanel</TextBlock>
            </Border>
            <Border Height="30" Background="SkyBlue" DockPanel.Dock="Top">
                <TextBlock> 2nd DockPanel</TextBlock>
            </Border>
            <Border Height="70" Background="Lavender" DockPanel.Dock="Bottom">
                <TextBlock> 3rd DockPanel</TextBlock>
            </Border>
            <Border Height="200" Width="100" Background="SeaGreen" DockPanel.Dock="Left">
            </Border>
            <Border Height="100" Background="BlueViolet" DockPanel.Dock="Right">
            </Border>
        </DockPanel>
    </Grid>
</Window>
```

In Listing 10.5, a simple UI is created using the DockPanel control. The position of the DockPanel control is set by using the DockPanel.Dock property. You can run the application by pressing the F5 key.
