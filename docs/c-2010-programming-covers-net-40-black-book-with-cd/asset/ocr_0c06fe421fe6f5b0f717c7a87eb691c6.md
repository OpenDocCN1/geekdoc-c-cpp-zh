# Using Block Elements

As stated in the In Depth section, Block elements provide a base for all block-level flow content elements. The different block-level elements are: Paragraph, Section, List, ListItem, Table, and BlockUIContainer. The block-level elements help you in creating the structure of the flow documents by dividing the content into paragraphs, sections, and tables. Let’s create a WPF application named BlockElements (also available on the CD-ROM) to learn about creating the Flow document using Block elements. Add the code given in Listing 11.14 to the MainWindow.xaml file of the BlockElements application:
