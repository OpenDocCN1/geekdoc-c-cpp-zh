You can add a StackPanel control to a WPF application by using the following code snippet:

```
<StackPanel>
<!--child elements-->
</StackPanel>
```

Table 10.7 describes the noteworthy properties of the StackPanel class:

| Property | Description |
|---|---|
| CanHorizontallyScroll | Gets or sets a value that indicates whether a StackPanel control can scroll in the horizontal direction |
| CanVerticallyScroll | Gets or sets a value that indicates whether a StackPanel control can scroll in the vertical direction |
| ExtentHeight | Gets a value that contains the vertical size of the extent |
| ExtentWidth | Gets a value that contains the horizontal size of the extent |
| HorizontalOffset | Gets a value that contains the horizontal position of the scrolled content |
| Orientation | Gets or sets a value that indicates how the child elements are stacked within the StackPanel control |
| ScrollOwner | Gets or sets a value that identifies the control controlling the scrolling behavior in the StackPanel control |
| VerticalOffset | Retrieves a value that contains the vertical position of the scrolled content |
| ViewportHeight | Retrieves a value that contains the vertical size of the content of the control |
| ViewportWidth | Retrieves a value that contains the horizontal size of the content of the control |

> NOTE
> You can select either a StackPanel or DockPanel control to stack child elements; however, these two container controls do not always produce the same result. The order in which you place the child elements affects the size of the child elements in a DockPanel control but not in a StackPanel control.
