# Passing an Object as an Argument to a Method

As mentioned earlier, this keyword refers to the current instance of a class. You can also use it to pass an object as an argument to a method belonging to another class. To see how to pass an object as an argument to a method, first create a new Console application, named MyObjectArgument (also available in the CD) and replace the default code of the Program.cs file of the application with the code shown in Listing 4.11:

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace MyObjectArgument
{
	class Program
	{
		static void Main(string[] args)
		{
			// your code here
		}
	}
}
```
