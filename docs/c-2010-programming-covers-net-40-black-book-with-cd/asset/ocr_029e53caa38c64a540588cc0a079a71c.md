5. Add the code given in Listing 1.1 to the Program.cs file of your application:

# Listing 1.1: Creating Hello World Program

```
namespace HelloWorld
{
class Program
{
    public static void Main(string[] args)
    {
        System.Console.WriteLine("Hello World");
        System.Console.ReadLine();
    }
}
}
```

Listing 1.1 shows a standard C# application that simply prints the literal string Hello World to the console output device.

In this application, you can see that the entire program is wrapped in the namespace HelloWorld statement. This namespace contains a class called Program, which in turn contains a method called Main(). The Main() method must be declared as static, as it does not require any object for calling.

Note that the program given in Listing 1.1 can also be written by including the using statements, which are used to import namespaces in your applications, as follows:

```
using System;
```

The preceding example uses the WriteLine() method of the Console class, which is placed inside the System namespace in the .NET Framework library. However, in our application, we have used the fully qualified name of the WriteLine() method, System.Console.WriteLine(); instead of using the using statement to import the System namespace.
