    }

### Using Impersonation in ASP.NET Applications

Impersonation in ASP.NET is a process in which an ASP.NET application poses as an anonymous or authenticated user to gain access to a resource on the Web server. Impersonation is helpful when the account (NETWORK SERVICE in IIS 7.5 by default) under which the ASP.NET application runs does not have the necessary permissions to access the resource. The application can access the resource by impersonating as a Windows user that has the necessary permissions. In ASP.NET, you can implement impersonation either in the web.config file or through code by using the WindowsIdentity.Impersonate() method. Now, let's demonstrate

```
DirectoryInfo directory = new DirectoryInfo(@"D:\MyFolder");
FileInfo[] files = directory.GetFiles("*.*");
foreach (FileInfo f in files)
{
    ListBox1.Items.Add(f.FullName);
}
}
```

In the preceding code, directives to the System.IO and System.Security.Principal namespaces are added. In the Page_Load() method, the value of HttpContext.Current.User.Identity.Name property is displayed in Label1. When the user clicks Button1, Label2 displays the impersonated account, i.e. the account under which the ImpersonationCS application runs. This account is retrieved from the Name property of the WindowsIdentity object that is returned by the WindowsIdentity.GetCurrent() method. The GetCurrent() method returns the current Windows user. The DirectoryInfo and FileInfo classes are used to retrieve and display the names of the files in the MyFolder folder. The file names are displayed in ListBox1.

3. Open the web.config file in the Impersonation application to enable impersonation in the web.config file. Add the following code in the `<system.web>` element:
   `<identity impersonate="true"/>`

In this code, the `<identity>` element is added to the web.config file. The impersonate attribute of the `<identity>` element is set to true, allowing the application to impersonate a Windows user. The Windows user that the application impersonates is determined at run time, that is, when a user passes the authentication in IIS. To configure impersonation in IIS, open the IIS Manager, select the Impersonation application in the Connections pane, and double-click the Authentication feature option in the middle pane. Now, ensure that the ASP.NET Impersonation option is enabled. This option may be automatically enabled if impersonation is already enabled in the web.config file.
