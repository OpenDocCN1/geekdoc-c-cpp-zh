## Animating Geometries

There are different types of geometry in WPF, such as Simple Geometry, Path Geometry, and Composite Geometry. You can apply animation to the different types of geometry to create a visually appealing application in WPF. Let’s create an application with animating geometries. To do this, create a WPF application named AnimatingGeometry (also available in CD) and add the code, given in Listing 12.38, to the MainWindow.xaml file:

## Listing 12.38: Using Animation for Geometry

```
<Window x:Class="AnimatingGeometry.MainWindow" xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation" xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml">
Title="MainWindow" Height="300" Width="300">
<Canvas>
    <Path Fill="Pink" Stroke="Black" StrokeThickness="5">
        <Path.Data>
            <EllipseGeometry x:Name="MyGeometry" Center="200,200" RadiusX="25" RadiusY="50" />
        </Path.Data>
        <Path.Triggers>
            <EventTrigger RoutedEvent="Path.Loaded">
                <BeginStoryboard>
                    <Storyboard>
                        <PointAnimation Storyboard.TargetName="MyGeometry" Storyboard.TargetProperty="Center" From="200,200" To="50,50" Duration="0:0:2" AutoReverse="true" RepeatBehavior="Forever"/>
                    </Storyboard>
                </BeginStoryboard>
            </EventTrigger>
        </Path.Triggers>
    </Path>
</Canvas>
</Window>
```

In Listing 12.38, the EllipseGeometry class is used to add an ellipse shape in the application that is moved using animation. When you run the application by pressing the F5 key on the keyboard, the ellipse shape starts moving from the point specified in the From property to the point specified in the To property. The speed of the movement is determined by the Duration property. The output is shown in Figure 12.40:

## Using Animation with 3-D Models

The topics until now dealt with animation in 2-D model. You can also apply animations to the 3-D models in WPF. Animating a 3-D model in WPF gives your 3-D application a rich look. You can apply different animations on the 3-D model. One way of animating a 3-D model is to animate the camera. You can also use the Rotation3DAnimation class to animate a 3-D model. The Rotation3DAnimation class applies the rotation effect on the 3-D model.

### Animating Cameras

In WPF, you can animate the camera using the Point3DAnimation and Vector3DAnimation classes to animate the Position and LookDirection properties of the PerspectiveCamera class. The Point3DAnimation class animates the value of the Point3D property using the linear interpolation between the start and the end values. The Vector3DAnimation class animates the value of the Vector3D property. Let’s create an application of animating the camera of the 3-D model. To do this, create a WPF application named AnimatingCamera (also available in CD) and add the code, given in Listing 12.39, to the MainWindow.xaml file:
