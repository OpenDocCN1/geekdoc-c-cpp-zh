# Conversion Operators

The Conversion operators convert a collection to an array. A Conversion operator changes the type of input objects. The different Conversion operators are ToSequence, ToArray, ToList, ToDictionary, ToLookup, OfType, and Cast.

The ToSequence clause simply returns the source argument by changing it to the IEnumerable<T> collection. The ToArray clause enumerates the source sequence and returns an array containing the elements of the sequence. The ToList clause enumerates the source sequence and returns a List<T> class containing the elements of the sequence. The ToDictionary clause lists the source sequence and evaluates the keySelector and elementSelector functions for each element to produce the element key and value of the source sequence. The ToLookup clause implements one-to-many dictionary that maps the key to the sequence of values. The OfType clause allocates and returns an enumerable object that captures the source argument. The Cast clause also allocates and returns an enumerable object that captures the source argument.

The syntax of the ToList clause is as follows:

```
public static List<T> ToList<T>(
    this IEnumerable<T> source);
```

# Generation Operators

The Generation operators, which are DefaultIfEmpty, Empty, Range, and Repeat, help in creating a new sequence of values. The DefaultIfEmpty clause replaces an empty collection with a default single collection. The Empty clause refers to an empty collection. The Range clause generates a collection that contains a sequence of numbers. The Repeat clause generates a collection that contains at least one repeated value.

The syntax of the Range clause is as follows:

```
public static IEnumerable<int> Range(
    int start,
    int count);
```

The Range clause throws an ArgumentOutOfRangeException exception if the count of the collection is less than 0.

The syntax of the Empty clause is as follows:

```
public static IEnumerable<T> Empty<T>();
```

The Empty clause caches a single empty sequence of the given type.

# Zip Operator

The Zip operator is a new operator introduced in LINQ in ASP.NET 4.0, which helps in combining two collections into one. It uses the Zip() method to merge the two sequences, which are identical in length, into one. The Zip() method uses the order of elements to combine the elements from two given sequences. This implies that the Zip() method takes an element from the first source and an element from the second source, which is at the same location, and returns a combined type.

The syntax of the Zip() method is as follows:

```
public static ParallelQuery<TResult> Zip<TFirst, TSecond, TResult>(
    this ParallelQuery<TFirst> first,
    ParallelQuery<TSecond> second,
    Func<TFirst, TSecond, TResult> resultselector
)
```
