## 探索 Visual Studio 2010 IDE

Visual Studio 2010 Ultimate IDE 用于开发不同类型的 .NET 应用程序，例如 Windows Forms 应用程序、Web 应用程序和移动应用程序。此 IDE 由 Visual Studio 2010 支持的所有编程语言共享。Visual Studio .NET 2010 支持的语言示例有 Visual Basic、Visual C#、Visual F# 和 Visual C++。Visual Studio 2010 Ultimate IDE 包含用于开发和调试 .NET 应用程序的大多数重要窗口、菜单和工具栏。
