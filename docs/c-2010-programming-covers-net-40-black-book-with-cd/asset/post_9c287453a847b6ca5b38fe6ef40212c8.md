## WPF 4.0 Documents

In WPF, displaying the fixed text is easy as you can use the `TextBlock`, `Label`, and `ContentControl` controls in your application. However, to display a large amount of data, such as a newspaper article, these controls are not a good choice. When you combine text and image using `TextBlock` and `Image` elements, the content of the `TextBlock` and `Image` is not properly aligned when the window is resized. To overcome these issues, WPF introduced the concept of Documents to work with large text. This feature allows the display of a large amount of content in an easy to read way, irrespective of the size of the window.

There are two kinds of documents in WPF: Fixed documents and Flow documents. A Fixed document is similar to a Portable Document Format (PDF) document as its content cannot be changed. A Flow document is similar to a Hyper Text Markup Language (HTML) document as it is created using tags. Both documents allow you to specify viewing preferences, while maintaining the overall design concepts as intended by the author of the document. These documents are located in the `System.Windows.Documents` namespace.

## Fixed Documents

Fixed documents are typeset and ready-to-print documents, where the positioning of all the content is fixed. They logically bind ordered sequence of pages together into either single, multi-page, or fixed-layout documents. WPF includes a single type of Fixed document, which uses Microsoft XML Paper Specification (XPS) standard to represent electronic representation of digital documents in an Extensible Markup Language (XML) format. The display of Fixed document content is supported using the `DocumentViewer` control. Fixed documents in WPF are represented by the `FixedDocument` class. Let’s discuss the DocumentViewer control and the FixedDocument class in the following sections.

## The DocumentViewer Control

The `DocumentViewer` control allows you to display a Fixed document in a customized manner. It is represented by the `DocumentViewer` class, which represents a document viewing control that can host paginated FixedDocument content, such as XpsDocument. The DocumentViewer class provides properties such as CanDecreaseZoom and CanGoToNextPage, to search and zoom the text.
