# Creating an Enumeration

Enumeration is a user-defined value type. It is a strongly typed constant that allows you to assign symbolic names to integral values. The phrase strongly typed means that enumeration of one type cannot be assigned to enumeration of another type even though the values of their members are same. You can assign only legitimate values to the enumerations that make your code easy to maintain. While assigning an acceptable range of values to enumeration, if you try to assign the value that is out of the acceptable range in the other part of the code, an error occurs. As enumerations are value type, they cannot inherit or be inherited from one enumeration to another. Note that the enumerations are created using the enum keyword, which is an alias for the System.Enum class.
