## Controlling Storyboards Interactively

Storyboard in WPF is the container timeline that provides the object and its property information for its animations. To animate a property using Storyboard timeline, you should create an animation for each property that you want to animate and also create a Storyboard object that contains animations. As you have already learned in the In Depth section of the chapter, a controllable Storyboard can start, stop, pause, resume, seek, stop, and removed. You can control a Storyboard timeline either through the XAML code and the code-behind code.

### Controlling Storyboard Using the XAML Code

The common practice of controlling a Storyboard timeline is through the XAML code. To start a Storyboard timeline in XAML, you can use the BeginStoryboard property and an EventTrigger object. The BeginStoryboard property starts the Storyboard timeline. An EventTrigger object helps you to implement the animation started by the BeginStoryboard property. Let's create an application to control the Storyboard timeline through the XAML code. To do this, create a WPF application named Storyboard_XAML (also available in CD) and add the code, given in Listing 12.29, to the MainWindow.xaml file:
