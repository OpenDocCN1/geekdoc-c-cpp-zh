# The TabControl Control

The TabControl control in WPF is derived from the Selector abstract base class. The TabControl control helps in arranging content in tabular form. This control consists of multiple TabItem controls that share the same screen space; however, only one TabItem control in the TabControl control is visible at a time. When a user selects the TabItem control, the content of the control becomes visible and the content of other TabItem objects is hidden.

The inheritance hierarchy of the TabControl class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.ItemsControl
                System.Windows.Controls.Primitives.Selector
                  System.Windows.Controls.TabControl
```

You can add the TabControl control to a WPF application by using the following code snippet:

```
<TabControl>
  <!--Items -->
</TabControl>
```
