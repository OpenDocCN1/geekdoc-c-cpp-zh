This application contains a user interface form with three buttons--Create and add 10 items, ContainsKey, and ContainsValue, and one ListView control.

Perform the following steps to create and add elements to the Hashtable object:

- 1. Set the Text property of Form1 to Hashtable Sample.
- 2. Drag and drop a ListView, a GroupBox, and three Button controls to the form.
- 3. Set the Text property of the GroupBox control to Noteworthy Operations and the Text property of button1 to Create and add 10 items, button2 to Contains Key, and button3 to Contains Value.
- 4. Add columns to the ListView control by clicking the ellipse button (...) of the Columns property of ListView control in the Properties window. The ColumnHeader Collection Editor dialog box appears (Figure 32.8).

5. Click the Add button to add a column to the ListView control. Set the Name property of the column to Key and Text property to Keys. Similarly, add another column to the ListView control with the name as Value and text set to Values, as shown in Figure 32.8:

### Listing 32.2: Showing the Code of the Form1.cs File of the HashtableSample Application

```
using System;
using System.Collections.Generic;
using System.ComponentModel;
using System.Data;
using System.Drawing;
using System.Linq;
using System.Text;
using System.Windows.Forms;
using System.Collections;

namespace HashtableSample
{
    public partial class Form1 : Form
    {
        private Hashtable HTbl;
        public Form1()
        {
            InitializeComponent();
        }
        private void button1_Click(object sender, EventArgs e)
        {
            HTbl = new Hashtable(10);
            HTbl.Add(100, "white");
            HTbl.Add(101, "black");
            HTbl.Add(102, "blue");
            HTbl.Add(103, "yellow");
            HTbl.Add(104, "green");
            HTbl.Add(105, "red");
            HTbl.Add(106, "orange");
            HTbl.Add(107, "purple");
            HTbl.Add(108, "magenta");
HTbl.Add(109, "Brown");
LoadHshTable();
button2.Enabled = true;
button3.Enabled = true;
}
private void Form1_Load(object sender, EventArgs e)
{
    button2.Enabled = false;
    button3.Enabled = false;
}
private void LoadHshTable()
{
    listview1.Items.Clear();
    foreach (object obj in HTbl.Keys)
    {
        ListviewItem lItem = listview1.Items.Add(obj.ToString());
        lItem.SubItems.Add(HTbl[obj].ToString());
    }
}
private void button2_Click(object sender, EventArgs e)
{
string tempKey = Microsoft.VisualBasic.Interaction.InputBox("Enter the key to look up", "", "", -1, -1);
if (HTbl.ContainsKey(Convert.ToInt32(tempKey))) {
    MessageBox.Show("The hashtable contains the specified key");
}
else
{
    MessageBox.Show("The hashtable does not contain the specified key");
}
}
private void button3_Click(object sender, EventArgs e)
{
string tempKey = Microsoft.VisualBasic.Interaction.InputBox("Enter the value to look up", "", "", -1, -1);
if (HTbl.ContainsValue(tempKey))
{
    MessageBox.Show("The hashtable contains the specified value");
}
else
{
    MessageBox.Show("The hashtable does not contain the specified value");
}
}
}
```

In Listing 32.2, the Add method is used to add key/value pairs to an object of the Hashtable class. The Add method takes two parameters, first for the key and the second for the value. Both these parameters can be of any type; and regardless of the type of the data added to the collection, all the elements are added to the collection in the same way. The Click event of button1 uses the Add method of the Hashtable class to add elements that have a key/value pair to the collection. The Click event of button2 uses the ContainsKey method to determine whether or not the Hashtable object contains a specific key. This method returns true if the Hashtable object contains the specified key; otherwise, it returns false. Similarly, the Click event of button3 uses the ContainsValue method to determine whether the Hashtable object contains a specific value or not. This method also returns a true or false value.
