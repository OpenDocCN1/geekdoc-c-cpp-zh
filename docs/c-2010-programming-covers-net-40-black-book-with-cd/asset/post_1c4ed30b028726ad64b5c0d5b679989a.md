## Working with Entity Data Model Designer

ADO.NET Entity Data Model Designer works with an .edmx file that is an encapsulation of the CSDL, the SSDL, and the MSL files. This .edmx file is created and added to our project after the creation of EDM. We can make changes to the EDM through the .edmx file by using ADO.NET Entity Data Model Designer. ## Creating an Association by Using the Association Control

Associations define relationships between entity types. Associations are bidirectional and each participating entity in the association is referred to as an End. Let's perform the following steps to form an association between the Customers and Contact entities:

1. Create another entity in the WorkingEntitiesCS application and name it Contact.
2. Now, to form an association between the Customers and Contact entities, right-click anywhere on the designer window and select the Add → Association option from the context menu. The New Association dialog box appears (Figure 22.27).
3. Enter a name for the association in the Association Name field (Figure 22.27). In this case, we have named the association CustomersContact.
4. Select values for both entities from the Multiplicity drop-down lists (Figure 22.27). In this application, we create One to Many multiplicity between the Customers and Contact entities.
5. Enter the values in the Navigation Property field for both the entities (Figure 22.27).
6. Click the OK button, as shown in Figure 22.27:
