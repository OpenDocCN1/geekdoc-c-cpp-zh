# PropertiesToLoad

The PropertiesToLoad part specifies the properties that should be loaded into the cache as well as returned to the caller. By default, the path and the name of the object are returned.

# SearchScope

The SearchScope part defines the depth of a search. In other words, it specifies the start and end of a search. The SearchScope part contains the following attributes:

+   - SearchScope.Base – Starts searching from the base object and returns only one object as the result.
+   - SearchScope.OneLevel – Starts searching from the child collection of the base object. It searches the immediate children of the specified base.
+   - SearchScope.Subtree – Searches the complete tree, implying the entire subtree including the search base is searched.
