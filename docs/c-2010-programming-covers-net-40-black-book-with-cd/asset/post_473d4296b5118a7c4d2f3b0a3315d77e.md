### The UniformGrid Control

The UniformGrid container control arranges the content in the Grid control in such a way that the cells in the grid remain the same size. When you add different controls on the UniformGrid control, all the controls get arranged in a grid pattern. The cells in the UniformGrid control adjust to accommodate different controls.

The UniformGrid control is represented by the UniformGrid class, which is derived from the Panel class. The inheritance of the UniformGrid class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Panel
              System.Windows.Controls.Primitives.UniformGrid
```

You can add the UniformGrid control to a WPF application by using the following code snippet:

```
<UniformGrid>
  <!--child elements-->
</UniformGrid>
```

Table 10.3 describes the noteworthy properties of the UniformGrid class:

Table 10.3: Showing the Noteworthy Properties of the UniformGrid Class

| Property | Description |
|---|---|
| Columns | Gets or sets the number of columns in a Grid control |
| FirstColumn | Gets or sets the number of blank cells in the first row of a Grid control |
| Rows | Gets or sets the number of rows in a Grid control |

### The Canvas Control

The Canvas control is the simplest container control that supports absolute positioning of its child controls by using the coordinates that are relative to the Canvas control. When you place a control in the Canvas control, you must specify one horizontal property and one vertical property to specify the starting position of the child control inside the Canvas control. This control is the only container control that has no built-in layout of its own. By default, the Height and Width properties of the Canvas control are set to zero.

To position a child control on the Canvas control, you need to set its Canvas.Top, Canvas.Left, Canvas.Right, or Canvas.Bottom property.

The Canvas control is represented by the Canvas class, which is derived from the Panel class. The inheritance hierarchy of the Canvas class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Panel
              System.Windows.Controls.Canvas
```

You can add a Canvas control to a WPF application by using the following code snippet:

```
<Canvas>
  <!--child elements-->
</Canvas>
```

### The StackPanel Control

The StackPanel container control positions the child elements as if they were on a stack and arranges them into a single line that can be oriented either vertically or horizontally. The vertical setting is the default setting, which you can change by using the Orientation property of the StackPanel control to Horizontal. This container control is typically used for small sections of a larger, more complex window. By default, the StackPanel control arranges the child controls from top to bottom, making each one as tall as necessary to display its content. All controls are stretched to the full width of the StackPanel control. If you widen a window, the StackPanel control widens as well, and the child controls stretch themselves to fit. The StackPanel control has its own HorizontalAlignment and VerticalAlignment properties. By default, both these properties are set to Stretch, and so the StackPanel control fills the container completely.

The StackPanel control is represented by the StackPanel class, which is derived from the Panel class. The inheritance hierarchy of the StackPanel class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Panel
              System.Windows.Controls.StackPanel
```

You can add a StackPanel control to a WPF application by using the following code snippet:

```
<StackPanel>
  <!--child elements-->
</StackPanel>
```

Table 10.7 describes the noteworthy properties of the StackPanel class:

| Property | Description |
|---|---|
| CanHorizontallyScroll | Gets or sets a value that indicates whether a StackPanel control can scroll in the horizontal direction |
| CanVerticallyScroll | Gets or sets a value that indicates whether a StackPanel control can scroll in the vertical direction |
| ExtentHeight | Gets a value that contains the vertical size of the extent |
| ExtentWidth | Gets a value that contains the horizontal size of the extent |

| VerticalOffset | Retrieves a value that contains the vertical position of the scrolled content |
| ViewportHeight | Retrieves a value that contains the vertical size of the content of the control |
| ViewportWidth | Retrieves a value that contains the horizontal size of the content of the control |
