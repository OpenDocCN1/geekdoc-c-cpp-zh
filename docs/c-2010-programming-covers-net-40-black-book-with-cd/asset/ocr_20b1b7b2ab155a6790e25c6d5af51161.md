# Understanding Bookmark Activities

In WF 4.0, a bookmark is a mechanism that enables an activity to wait for an input without interrupting a workflow thread. When an activity signals that it is waiting for the input from a user, it can create a bookmark. A bookmark is created by using the BookmarkOptions class. This class provides the following bookmark types:

+   - None — Refers to a bookmark that is expected to be resumed exactly once. This is the default bookmark type.
+   - MultipleResume — Refers to a bookmark that can be resumed multiple times.
+   - NonBlocking — Refers to a bookmark that might never be resumed.

A bookmark can be resumed by writing the code outside a workflow using a method of the ResumeBookmark class.
