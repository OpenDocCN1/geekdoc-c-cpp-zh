

## WrapPanel 控件

WrapPanel 容器控件按顺序放置其子元素。子元素的顺序取决于 Orientation 属性的值。WrapPanel.Orientation 属性的默认值设置为 Horizontal，这意味着子元素从左到右排列。但是，你可以更改默认行为，使子元素从上到下排列。

WrapPanel 控件由 WrapPanel 类表示，该类派生自 Panel 类。WrapPanel 类的继承层次结构如下：

+   System.Object
+   System.Windows.Threading.DispatcherObject
+   System.Windows.DependencyObject
+   System.Windows.Media.Visual
+   System.Windows.UIElement
+   System.Windows.FrameworkElement
+   System.Windows.Controls.Panel
+   System.Windows.Controls.WrapPanel

可以使用以下代码片段将 WrapPanel 控件添加到 WPF 应用程序中：

```
<WrapPanel>
<!--child elements-->
</WrapPanel>
```

## 表 10.8：WrapPanel 类的显著属性

| 属性 | 描述 |
|---|---|
| ItemHeight | 获取或设置一个值，该值指定 WrapPanel 控件内所有项的高度 |
| ItemWidth | 获取或设置一个值，该值指定控件内所有项的宽度 |
| Orientation | 获取或设置一个值，该值指定子内容的排列方式 |

## 简单控件

简单控件是不包含任何子元素的控件。你可以通过添加模板来自定义简单控件的外观。简单控件的示例包括 TextBox、RichTextBox、PasswordBox、ScrollBar、ProgressBar 和 Slider。让我们详细了解这些控件。

## TextBox 控件

TextBox 控件用于显示或编辑通常出现在窗口中的无格式文本。例如，你可以通过将 SpellCheck.IsEnabled 属性设置为 True 来对 TextBox 控件中的文本执行拼写检查。默认情况下，此属性设置为 False。当设置为 True 时，任何拼写错误的单词下都会出现红色线条。默认情况下，TextBox 控件有一个上下文菜单，当用户在 TextBox 控件内单击鼠标右键时，该菜单会出现。上下文菜单允许用户执行剪切、复制和粘贴操作。你也可以创建自定义上下文菜单来更改默认选项。TextBox 控件可以包含单行或多行文本。你可以通过将 TextWrapping 属性设置为 Wrap，在 TextBox 控件中输入多行文本。这会导致文本在到达 TextBox 控件框架末尾时换行。你也可以将 AcceptsReturn 属性设置为 True。这允许你通过键盘上的 ENTER 键插入新行。要在 TextBox 控件中查看滚动条，你可以将其 VerticalScrollBarVisibility 和 HorizontalScrollBarVisibility 属性设置为 Visible。当 TextBox 控件中的文本到达框架末尾时，这会向 TextBox 控件添加滚动条。

TextBox 控件由 TextBox 类表示，该类派生自 TextBoxBase 类。TextBox 类的继承层次结构如下：

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.Primitives.TextBoxBase
                System.Windows.Controls.TextBox
```

可以使用以下代码片段将 TextBox 控件添加到 WPF 应用程序中：

```
<TextBox>
<!--Text-->
</TextBox>
```

## RichTextBox 控件

RichTextBox 控件与 TextBox 控件类似，使你能够显示或编辑内容，如段落、图像和表格。TextBox 控件比 RichTextBox 控件需要更少的资源，并且仅需要编辑纯文本时是理想的选择；而 RichTextBox 控件在用户需要编辑格式化文本、图像或表格时是理想的选择。RichTextBox 控件可以执行 TextBox 控件的所有功能，以及一些附加功能，例如显示字体、颜色和链接；加载文本和图像；以及查找指定文件。你还可以通过启用 RichTextBox 控件的 SpellCheck 属性来检查内容的拼写。当此属性设置为 True 时，拼写错误的单词下会出现波浪形红色线条。通过将 SpellCheck.IsEnabled 属性设置为 True 来启用 SpellCheck 属性。与 TextBox 控件类似，RichTextBox 控件也有一个上下文菜单。当用户在控件内单击鼠标右键时，该菜单会出现。RichTextBox 控件包含与 TextBox 控件类似的基本编辑命令。但是，与 TextBox 控件不同，RichTextBox 控件包含格式设置命令。RichTextBox 控件实现 IInputElement 接口，该接口支持许多编辑命令。

| AlignLeft | CTRL+L |
| AlignRight | CTRL+R |
| Backspace | BACKSPACE |

| DeleteNextWord | CTRL+DELETE |
| DeletePreviousWord | CTRL+BACKSPACE |
| EnterLineBreak | SHIFT+ENTER |
| EnterParagraphBreak | ENTER |
| MoveToDocumentEnd | CTRL+END |
| MoveToDocumentStart | CTRL+HOME |

PasswordBox 控件的方法与 TextBox 控件的方法类似，例如 Clear()、Paste() 和 SelectAll() 方法。但是，PasswordBox 控件不支持剪贴板功能，因此无法执行复制功能。TextBox 控件和 PasswordBox 控件之间最重要的区别是，PasswordBox 控件使用 System.Security.SecureString 对象，这确保在 PasswordBox 控件中作为密码输入的文本保持机密。文本在使用时会加密以保护隐私，不再需要时会从内存中删除。用于加密字符串的密钥是随机生成的代码，并且永远不会写入磁盘。

SecureString 类包含对加密文本的按需处置。当你调用 SecureString.Dispose() 方法时，存储在内存中的密码将被覆盖。

PasswordBox 控件由 PasswordBox 类表示。PasswordBox 类的继承层次结构如下：

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.PasswordBox
```

可以使用以下代码片段将 PasswordBox 控件添加到 WPF 应用程序中：

```
<PasswordBox .../>
```

## ScrollBar 控件

ScrollBar 控件提供一种滚动条，其中包含一个滑动的 Thumb 控件，其位置对应一个值。ScrollBar 控件包含一个 Track 控件，该控件又包含一个 Thumb 控件和两个 RepeatButton 控件。你可以通过单击任意 RepeatButton 控件或移动 Thumb 控件来增大或减小 ScrollBar 控件的 Value 属性值。Thumb 控件使用户能够在 ScrollBar 控件上选择一个值。Value 属性的默认值范围是从 0 到 1。
