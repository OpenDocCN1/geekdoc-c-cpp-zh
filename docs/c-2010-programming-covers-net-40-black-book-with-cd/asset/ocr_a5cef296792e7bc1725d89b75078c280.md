# Using a Parameterized Constructor in a Class

The C# programming language allows you to create parameterized constructors in a class. A constructor of a class that accepts some arguments is called a parameterized constructor. To see how to create a parameterized constructor in a class, first create a new Console application, named MyParamConstructor (also available in the CD) and then replace the default code of the Program.cs file of the application with the code shown in Listing 4.14:

# Listing 4.14: Showing the Code of the MyParamConstructor Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyParamConstructor
{
    class Program
    {
        static void Main(string[] args)
        {
            MySampleClass Obj1 = new MySampleClass();//No Parameter
            MySampleClass Obj2 = new MySampleClass("Martin");// One Parameter
            MySampleClass Obj3 = new MySampleClass("Martin", 26);//Two Parameters
            Console.Write("\nPress ENTER to Quit...");
            Console.ReadLine();
        }
    }
    public class MySampleClass
    {
        public MySampleClass()//constructor without Parameter
        {
        }
        public MySampleClass(String Name)//Constructor with One Parameter
        {
            Console.WriteLine("Name is:" + Name);
            Console.WriteLine("----------------");
        }
        public MySampleClass(String Name, int Age)//Constructor with two Parameters
        {
            Console.WriteLine("Name is:" + Name);
            Console.WriteLine("Age is:" + Age);
        }
    }
}
```

In Listing 4.14, we use three constructors, the first without any parameters, the second with one parameter, and the third with two parameters. Figure 4.16 shows the output of MyParamConstructor application:
