# Using Dynamic Resources

As explained in the In Depth section of the chapter, there are two types of resources: static and dynamic. The major difference between the two is that static resource is loaded at compile time and dynamic resource is loaded at run time. Let's use a dynamic resource in a WPF application. Create a WPF application named DynamicResources (available in the CD) and add the following code to MainWindow.xaml file, as shown in Listing 10.21:

Listing 10.21: Showing the Code to Implement Dynamic Resources

```
<Window x:Class="DynamicResources.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="350" Width="525">
    <Grid>
        <StackPanel>
            <StackPanel.Resources>
                <SolidColorBrush x:Key="myBrush" Color="Red"/>
            </StackPanel.Resources>
            <Label Foreground="{DynamicResource myBrush}">Hello</Label>
            <Button Background="{DynamicResource myBrush}">DynamicResource</Button>
            <Button Background="{DynamicResource {x:Static SystemColors.ControlBrushKey}}">MyButton
            </Button>
        </StackPanel>
    </Grid>
</Window>
```

Listing 10.21 adds a Label control and two Button controls to the window. You can see that a single SolidColorBrush reference is made and passed on to the Label control and to one of the Button controls. The second Button control takes the default system color. When you move the mouse pointer over the Button control, which has the color referenced in SolidColorBrush, the Button control also takes the system color.
