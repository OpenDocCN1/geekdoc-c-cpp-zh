## 从方法返回一个值

方法可以向调用该方法的代码返回一个值。如果返回类型为 void，则方法不会返回任何值。但是，如果返回类型不是 void，而是 int、double 或 string 等，则方法可以使用 return 关键字返回一个值。包含 return 关键字的语句会将方法的返回类型与返回值进行比较，如果两者匹配，则将值返回给调用方法。要了解如何接收方法返回的值，首先创建一个名为 MyReturnValue 的新控制台应用程序，也可在 CD 中找到。然后用第 4.12 节清单中显示的代码替换该应用程序的 Program.cs 文件的默认代码：

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyReturnValue
{
    class Program {
        static void Main(string[] args)
        {
            MyArea myarea = new MyArea();
            myarea.RectArea();
            Console.Write("\nPress ENTER to Quit..");
            Console.ReadLine();
        }
    }
    class MyArea {
        public double RectArea()
        {
            double Length, Breadth, RectangleArea;
            Console.Write("Enter the Length of Rectangle:");
            Length = double.Parse(Console.ReadLine());
            Console.Write("Enter the Breadth of Rectangle:");
            Breadth = double.Parse(Console.ReadLine());
            RectangleArea = Length * Breadth;
            Console.WriteLine("The Area of Rectangle is " + RectangleArea);
            return (RectangleArea);
        }
    }
}
```

在第 4.12 节清单中，注意 RectArea 方法的返回类型与 RectangleArea 变量的数据类型相同，都是 double。因此，该方法向调用方法返回 double 类型的值。

## 创建部分方法

部分方法仅允许在部分类型中，例如类和结构体。部分方法由两部分组成。一部分处理部分方法的定义，另一部分处理部分方法声明的实现。对于部分方法，最多只能有一个定义声明和一个实现声明。部分方法必须具有 void 返回类型。声明部分方法时不允许使用访问修饰符，除 unsafe 和 static 外。部分方法默认是私有的。要了解如何创建部分方法，首先创建一个名为 MyPartialMethod 的新控制台应用程序，也可在 CD 中找到，通过执行“创建命名空间”一节中给出的步骤。然后用第 4.13 节清单中显示的代码替换该应用程序的 Program.cs 文件的默认代码：

### Listing 4.13: Showing the Code of the MyPartialMethod Application

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyPartialMethod
{
    class Program {
        static void Main(string[] args)
        {
            Account Acc = new Account();
            Acc.CalculateInterest();
            Acc.ShowInterest();
        }
    }
    partial class Account
    {
        double PrincipalAmount, InterestRate, Time, SimpleInterest;
        public void CalculateInterest()
        {
            Console.Write("Enter Principal Amount (P):");
            PrincipalAmount = double.Parse(Console.ReadLine());
            Console.Write("Enter Interest Rate (R):");
            InterestRate = double.Parse(Console.ReadLine());
            Console.Write("Enter Time Duration (T):");
            Time = double.Parse(Console.ReadLine());
        }
        partial void ShowAmount();
    }
    partial class Account
    {
        partial void ShowAmount()
        {
            double amount = PrincipalAmount + SimpleInterest;
            Console.WriteLine("Total Amount: " + amount);
        }
        public void ShowInterest()
        {
            SimpleInterest = (PrincipalAmount * InterestRate * Time) / 100;
            Console.WriteLine("SimpleInterest: " + SimpleInterest);
            ShowAmount();
            Console.Write("\nPress ENTER to Quit..");
            Console.ReadLine();
        }
    }
}
```

## 在类中使用参数化构造函数

C# 编程语言允许你在类中创建参数化构造函数。接受某些参数的类的构造函数称为参数化构造函数。要了解如何在类中创建参数化构造函数，首先创建一个名为 MyParamConstructor 的新控制台应用程序，也可在 CD 中找到，然后用第 4.14 节清单中显示的代码替换 Program.cs 文件的默认代码：

### Listing 4.14: Showing the Code of the MyParamConstructor Application

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyParamConstructor
{
    class Program
    {
        static void Main(string[] args)
        {
            MySampleClass Obj1 = new MySampleClass();//No Parameter
            MySampleClass Obj2 = new MySampleClass("Martin");// One Parameter
            MySampleClass Obj3 = new MySampleClass("Martin", 26);//Two Parameters
            Console.Write("\nPress ENTER to Quit...");
            Console.ReadLine();
        }
    }
    public class MySampleClass
    {
        public MySampleClass()//constructor without Parameter
        {
        }
        public MySampleClass(String Name)//Constructor with One Parameter
        {
            Console.WriteLine("Name is:" + Name);
            Console.WriteLine("----------------");
        }
        public MySampleClass(String Name, int Age)//Constructor with two Parameters
        {
            Console.WriteLine("Name is:" + Name);
            Console.WriteLine("Age is:" + Age);
        }
    }
}
```

在第 4.14 节清单中，我们使用了三个构造函数，第一个没有参数，第二个有一个参数，第三个有两个参数。图 4.16 显示了 MyParamConstructor 应用程序的输出：
