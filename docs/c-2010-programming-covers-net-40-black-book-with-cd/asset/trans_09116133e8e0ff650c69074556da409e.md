要在 C# 2010 中创建访问 AD 对象的应用程序，您需要执行以下任务：

- 指定绑定路径以在应用程序和 AD 之间建立连接
- 创建新对象，例如用户
- 修改 Active Directory 对象
- 在 AD 中搜索对象

## 指定绑定路径

将应用程序与 AD 连接的过程称为绑定。您需要提供绑定字符串以将应用程序与 AD 绑定。绑定字符串的示例如下所示：

```
LDAP://192.168.1.95/CN=Users, DC=sql, DC=local
```

绑定字符串必须包含以下项目：

- 协议 – 标识 ADSI 提供程序的详细信息，以提供访问目录服务的接口
- 服务器名称 – 标识域控制器的名称
- 端口号 – 标识服务器进程的名称
- 对象的 Distinguished name – 标识您想要访问的对象的名称
- 用户名和密码 – 标识被允许访问 AD 的用户
- 身份验证类型 – 标识加密的需求

## 创建新对象

您可以为用户、计算机、打印机和联系人创建 AD 对象。DirectoryEntry 和 DirectoryEntries 类用于创建新对象。可以通过 DirectoryEntry 的 Children 属性访问 DirectoryEntries 的对象，如以下代码片段所示：

```
DirectoryEntry de = new DirectoryEntry("LDAP://192.168.1.95");
DirectoryEntries users = de.Children;
```

可以使用 DirectoryEntries 类提供的方法在集合中添加、删除和搜索对象，如以下代码片段所示：

```
DirectoryEntry user = users.Add("CN=John Doe", "user");
```

您可以使用 Properties 属性的 Add() 方法向 AD 对象添加属性，如以下代码片段所示：

```
user.Properties["company"].Add("Any company");
user.Properties["department"].Add("Sales");
```

添加的属性应在用户对象的架构中存在。如果属性在架构中不存在，您会得到一个 COMException 异常，显示消息：“The specified directory service attribute or value does not exist.”

您需要刷新缓存以将数据写入 AD，如以下代码片段所示：

```
user.CommitChanges();
```

## 修改 Active Directory 对象

要修改 AD 对象的属性值，您可以使用各种方法，例如 Add()、Remove() 和 RemoveAt()。Add() 方法用于向属性添加新值，而 Remove() 和 RemoveAt() 方法用于从属性中删除特定值。您还可以使用 PropertyValueCollection.Clear() 方法清除属性的值。

以下代码片段显示了如何修改用户 Steve 的属性——company 和 department：

```
DirectoryEntry entry = new DirectoryEntry("LDAP://192.168.1.95");

string a = null;
entry.Path = "LDAP://192.168.1.95/CN=" + a + ",CN=Users,DC=sql, DC=local";
entry.Username = "administrator@sql.local";
entry.Password = "kogenta321";
if (entry.Properties.Contains("company"))
{
    entry.Properties["company"][0] = textBox3.Text;
}
else
{
    entry.Properties["company"].Add(textBox3.Text);
}
if (entry.Properties.Contains("department"))
{
    entry.Properties["department"][0] = textBox4.Text;
}
else
{
    entry.Properties["department"].Add(textBox4.Text);
}
entry.CommitChanges();
```

## 在 Active Directory 中搜索对象

DirectorySearcher 类用于在 AD 中搜索对象值。要搜索对象值，您需要在 DirectorySearcher 类的构造函数中定义四个重要部分，分别是：

- SearchRoot
- Filter
- PropertiesToLoad
- SearchScope

让我们逐一讨论这些部分。

### SearchRoot

DirectorySearcher 类构造函数中的 SearchRoot 部分指定搜索应开始的基础节点。默认节点是根域。SearchRoot 类从此域开始搜索。SearchRoot 类与 DirectoryEntry 对象的 Path 属性一起使用。

### Filter

Filter 部分定义在 AD 中搜索对象的标准。标识筛选器的字符串应括在括号中。搜索筛选器包含名称、运算符和值。在编写搜索筛选器中的搜索表达式时，您还可以使用 `<=`、`=`、`>=`、`&` 和 `|` 运算符。

### PropertiesToLoad

PropertiesToLoad 部分指定应加载到缓存中以及返回给调用者的属性。默认情况下，返回对象的路径和名称。

### SearchScope

SearchScope 部分定义搜索的深度。换句话说，它指定搜索的开始和结束。SearchScope 部分包含以下属性：

- `SearchScope.Base` – 从基对象开始搜索并仅返回一个对象作为结果。
- `SearchScope.OneLevel` – 从基对象的子集合开始搜索。它搜索指定基的直接子项。
- `SearchScope.Subtree` – 搜索完整的树，意味着整个子树包括搜索基都被搜索。

## Immediate Solutions

为了维护网络对象的安全，您需要授权和验证用户帐户。您需要执行以下步骤在 AD 中创建新的用户帐户：

1. 单击 开始→管理工具→Active Directory 用户和计算机。Active Directory 用户和计算机管理单元打开。
2. 在您想要创建新用户的林中右键单击 Users 节点。在此例中，我们右键单击了 dreamtechpress.net 林。New Object - User 向导打开。
3. 在 First name、Last name 和 User logon name 文本框中提供名字、姓氏和用户登录名。
4. 单击 Next 按钮。
5. 分别在 Password 和 Confirm password 文本框中为用户提供密码。默认情况下选中 User must change password at next logon 复选框。
6. 单击 Next 按钮。创建新用户。
7. 单击 Finish 按钮完成过程。

- [ ] 您必须是 AD 中 Account Operators 组、Domain Admins 组或 Enterprise Admins 组的成员，或您必须被授予适当的权限。
- [ ] 您必须确保密码是字母、数字和一些特殊字符的组合。
- [ ] 您也可以复制任何先前创建的用户帐户。
- [ ] 具有与已删除帐户相同名称的新用户帐户不会授予已删除帐户的权限和组成员身份。您需要手动为用户帐户分配权限和成员身份。

接下来，让我们学习如何在 AD 中创建用户组。

您可以使用 Active Directory 用户和计算机管理单元在 AD 中创建组。执行以下步骤创建组：

1. 打开 Active Directory 用户和计算机管理单元。
2. 右键单击您想要创建组的域、OU 或容器，并从上下文菜单中选择 New→Group。New Object - Group 对话框打开。
3. 在 Group name 框中为组提供名称。该名称会自动出现在 Group name (pre-Windows 2000) 框中。
4. 从 Group type 组中选择组类型。在 Group type 组中，提供以下选项：
   - Security—为一组用户、计算机和其他组提供对共享资源（如文件或打印机）的安全访问
   - Distribution—指一组用户或计算机，它们使用电子邮件应用程序，例如 Microsoft Exchange，向组的其他成员发送电子邮件。您可以使用 Security 组同时用于资源访问和电子邮件分发。如果您仅为电子邮件分发创建组，您应使用 Distribution 组。
5. 从 Group scope 组中选择组的范围。在 Group scope 组中，提供以下选项：
   - Domain local—指用于授予资源权限的组。域本地组在域命名上下文中定义。您可以包含来自域的任何安全主体。
   - Universal—指用于在林中授予资源权限的组。通用组在林命名上下文中定义。您可以包含来自域或林中另一个域的任何安全主体。
