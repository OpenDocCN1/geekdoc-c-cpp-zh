+   - **Show Other Members** – Displays members that do not fall in the categories of public, protected private, or inherited.
+   - **Show Inherited Members** – Displays inherited members in the Members pane.
+   - **Show Extension Members** – Displays extension members in the Members pane.

# The Output Window

The Output window displays the result of building and executing applications. To view the Output window select View→Output. An alternate way of opening the Output window is to press the CTRL+ALT+O keys together.

Figure 1.59 displays the Output window:

![](bbox=[0.14, 0.26, 0.91, 0.39])

Figure 1.59: Displaying the Output Window

The Output window displays the output of the following functions:

+   - **Build** – Displays progress and error messages from the compiler and linker
+   - **Debug** – Displays output from the debugger

You can see various buttons available on the Output window toolbar. The description of these buttons is given as follows:

+   - **Show output from** – Displays the list of output panes to view the output of a program. Some examples of output panes are Build, Debug, and Constraint Validation.
+   - **Find Message in Code** – Moves the insertion point to the line that contains the selected build error in the Code Editor window.
+   - **Go to Previous Message** – Moves the insertion point in the Code Editor window to the line that contains the previous build error.
+   - **Go to Next Message** – Moves the insertion point in the Code Editor window to the line that contains the next build error.
+   - **Clear All** – Removes all texts from the Output pane.
+   - **Toggle Word Wrap** – Toggles the Word Wrap feature on and off in the Output pane. When turned on, the text that extends from the viewing area is displayed on the line that follows it.
