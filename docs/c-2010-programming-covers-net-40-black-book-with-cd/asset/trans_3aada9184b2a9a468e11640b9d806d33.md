

# 第 6 章：指针、委托和事件

在前面的语法中，access-modifier 是控制委托可访问性的修饰符，可以是 public、private、protected 或 internal。delegate 关键字表示声明属于一个委托，return-type 是委托的返回类型。delegate-name 是委托的名称，可以是任何有效的 C# 标识符，而 parameter-list 是委托所接受的参数列表。

使用前面的语法，我们可以按如下方式声明一个名为 Compute 的委托：

```
public delegate void Compute(int x, int y);
```

尽管声明委托的语法与声明方法（无方法体）的语法相似，但委托实际上代表一种类类型。由于委托代表一种类类型，它可以在任何可以定义类的位置声明——在类之外或类之内。委托类型是隐式密封的；因此，不可能从委托类型派生出新的类型。

## 定义委托方法

委托方法是指其签名（参数的数量和类型以及返回类型）与委托签名完全匹配的任何方法。它可以是静态方法也可以是实例方法。我们可以按如下方式定义一个名为 Add() 的静态方法，使其封装到 Compute 委托中：

```
public static void Add(int a, int b)
{
    Console.WriteLine("Sum = {0}", a + b);
}
```

类似地，我们也可以按如下方式定义一个名为 Subtract() 的实例方法，使其封装到 Compute 委托中：

```
public void Subtract(int a, int b)
{
    Console.WriteLine("Difference = {0}", a - b);
}
```

## 创建委托对象

你可以使用以下语法创建委托对象：

```
Delegate-name object-name = new delegate-name(expression);
```

在前面的语法中，delegate-name 是之前声明的委托的名称，其对象将被创建；object-name 是委托对象的名称；expression 是你希望封装到委托对象中的内容，可以是方法的名称或委托类型的对象。如果将方法或委托类型的对象传递给其构造函数，其签名应与委托的签名完全匹配；否则你会收到编译时错误。

使用前面的语法，你可以创建 Compute 委托的一个对象，名为 cmp1，以保存对（静态）Add() 方法的引用，如下所示：

```
Compute cmp1 = new Compute(DelegateTest.Add);
```

类似地，你可以创建 Compute 委托的另一个对象，名为 cmp2，以保存对（实例）Subtract() 方法的引用，如下所示：

```
DelegateTest dt = new DelegateTest();
Compute cmp2 = new Compute(dt.Subtract);
```

## 调用委托对象

委托对象的调用方式与方法的调用方式相同。以下代码片段显示了声明委托对象的语法：

```
Delegate-object(argument-list)
```

在前面的语法中，delegate-object 是被调用对象的名称；argument-list 是分配给封装在委托对象中的方法的参数的值列表。当委托对象被调用时，它反过来调用封装在委托对象中的方法。

如果委托的返回类型为 void，我们在前述语法中括号对之后添加分号。另一方面，如果委托具有除 void 以外的返回类型，我们将前述语法作为赋值语句的右侧来调用 Compute 委托的对象 cmp1 和 cmp2，如下所示：

```
cmp1(30, 20);
cmp2(30, 20);
```

## 使用委托进行多播

到目前为止我们创建的每个委托对象都保存对单个方法的引用。然而，委托对象可以保存对多个方法的引用并调用它们。这种委托对象称为多播委托或可组合委托。你可以使用重载的 += 运算符将一个以上的方法封装到单个委托对象中。你创建的每个委托对象默认维护一个调用列表，即封装到委托对象中的方法的列表。多播委托的调用列表由多个方法组成，这些方法按添加到多播委托的顺序被调用。只有满足以下两个条件的委托对象才能作为多播委托：

- 委托的返回类型为 void
- 委托的任何参数都不是输出参数（使用 out 关键字声明的参数）

你将在《即时解决方案》的“创建多播委托”部分学习如何创建多播委托。

## 探索协变和逆变

协变允许你创建由类和派生类使用的委托方法。逆变允许你创建更通用的委托方法，可用于更多类。这些特性在 C# 中引入是为了在匹配委托方法与委托签名时提高灵活性。灵活性意味着委托能够应对程序中不同类或事件的能力。通常，传递给委托的方法必须具有与委托相同的返回类型和签名。然而，协变允许你使用具有派生返回类型的方法作为委托。考虑以下代码片段，它定义了一个委托：

```
delegate object GetData(TextBox control);    //defining a delegate
```

前面的语句定义了一个委托 GetData。协变允许 GetData 委托指向任何接受 TextBox 参数的方法，而不考虑其返回类型，因为所有 .NET 类都继承自 System.Object 类。因此，GetData 委托可以指向方法 GetcontrolText，因为 .NET Framework 的 String 类型继承自 System.String 类，如以下代码片段所示：

```
string GetControlText(TextBox control)    // GetControlText is the method to
{                                        //which the GetData delegate points.
    return control.Text;
}
```

与协变类似，逆变允许你使用具有派生参数的方法作为委托。这意味着逆变使委托能够指向其参数为委托签名中出现参数的基类型的方法。在前面的代码片段中，我们创建了 GetData 委托。以下代码片段显示 GetData 委托指向 GetTag() 方法：

```
object GetTag(Control ctr)
{
    return ctr.Tag;
}
```

在前面的代码片段中，逆变使 GetData 委托能够指向接受 Control 或 Object 值 的 GetTag() 方法，因为这些类型是委托签名中指定的 TextBox 类的基类型。

## 使用委托探索匿名方法

正如你所知，在 C# 1.0 中，委托可以使用命名方法声明。现在，为了使用未命名方法声明委托，C# 2.0 引入了匿名方法的概念。匿名方法允许你实例化一个委托并创建一个代码块，该代码块作为委托参数传递给委托。当委托被调用时，此代码可以被执行。以下代码片段显示了如何定义命名方法：

```
// Declaring a delegate:
delegate void Delg(int a);

// Defining a named method:
void func(int n)
{
}
// Instantiating the delegate using the named method as a parameter:
Delg d = obj.func;
```

在前面的代码片段中，我们通过使用命名方法 func 作为参数来实例化委托 Delg。现在考虑以下代码片段，我们使用匿名方法实例化委托：

```
// Declaring a delegate
delegate void Delg(int a);

// Instantiating the delegate using an anonymous method
Delg d = delegate(int n) { };
```

在前面的代码片段中，我们通过消除为实例化委托而创建单独方法的需要来减少编码开销。结果，代码可用性和代码可维护性得到增强。

匿名方法使你能够将代码块作为委托参数传递。在调用委托时，你需要在内联定义匿名方法，而不是作为类成员。你只能将匿名方法传递给具有委托类型参数的方法。以下代码片段显示了如何将匿名方法作为委托参数传递：

```
void function()
{
    System.Threading.Thread th = new System.Threading.Thread
    (delegate()
    {
        System.Console.Write("Hi !");
        System.Console.WriteLine("How are u!");
    });
    th.Start();
}
```

在前面的代码片段中，我们创建了一个线程，该线程在不创建额外的委托方法的情况下执行其代码。启动线程的代码块作为委托参数传递。此代码块充当匿名方法，使你无需编写单独的委托方法。在使用匿名方法时，你需要注意以下几点：

- 不要在匿名方法中使用不安全代码。
- 不要使用将控制转移到匿名块之外的语句，例如 goto、break 或 continue。即使这些语句在匿名方法内部转移程序控制，你也不能在匿名方法之外使用这些语句。
- 不要使用匿名方法访问外部作用域的 ref 或 out 参数。作用域包含匿名方法声明的变量或参数被称为匿名方法的外部作用域。

## 事件

事件是一个委托类型的类成员，用于由对象或类向其他对象提供通知，表明事件已发生。事件本身是由用户或计算机生成的动作。在 C# 中，你可以使用事件使对象获知另一个对象或条件的当前状态。event 关键字可用于声明事件，如以下语法所示：

```
Access-modifier event type event-name;
```
