
Sometimes, you need to create a pointer to call an external function (which is external to a class). The problem with calling an external function through a pointer is that the pointer points to a block of memory, which can be garbage collected or moved in memory. In such cases, C# provides the fixed statement that allows you to pin a pointer in memory until you call the specified external function. The following code snippet shows how to use the fixed statement:

```
unsafe {
int[] x = new int[10];
fixed(int *p = &x)
{
    CallAFunctionWithAPointer(*p);
}
```

As you can see in the preceding code snippet, the fixed keyword pins the pointer in memory until you call the CallAFunctionWithAPointer() function. Fixing a pointer is a temporary step, as you cannot fix a pointer in memory forever – the lock stays in place only between the starting and closing braces of the block, which is surrounded by the fixed keyword.

## Declaring Pointers

As you know that pointer is a variable that holds the memory address of another variable. In C#, you can declare pointers to hold the memory address of value types, such as int, char, or double. The syntax for pointers declaration is as follows:

```
<type> * <pointer_name>
```

The description of the expressions used in the preceding syntax is as follows:

- value type — Specifies the value data type, such as int, char, or double.
- de-reference operator — Specifies the compiler that the variable succeeding this operator is a pointer variable. It is denoted by the asterisk (*) symbol.
- pointer_name — Specifies the name of the pointer variable.

Let's now take an example to know how to declare a pointer variable:

```
int *MyPointer
```

The preceding declaration sets up a pointer variable named as MyPointer, which points to the memory address of an integer type. The syntax *MyPointer refers to the type located at the memory location, which is held by the MyPointer variable. Therefore, we can assign an integer value to *MyPointer as follows:

```
*MyPointer=100
```

In the preceding code snippet, the *MyPointer pointer variable does not point to the integer value 100; in fact, it holds the starting four bytes of the memory address where the integer value 100 is stored. Another important symbol used with the context of pointers is the & operator. It returns the memory address of the variable that follows it. The following code snippet shows you to store the address of the variable through pointers:

```
int Number=100;
int *MyPointer;
MyPointer=&Number;
```

From the preceding code, we can conclude that the MyPointer variable holds the memory address where the value of the Number variable is stored and *MyPointer is an integer value located at the memory address held by the MyPointer variable.

Pointers can also point to the elements of an array, as shown in the following code snippet:

```
int *MyPointer;
int MyArray[50];
MyPointer=MyArray[20];
```

In the preceding code snippet, the MyPointer variable points to the twenty-first element of the MyArray array (the array index starts from 0).

## Performing Arithmetic Operations on Pointers

You can perform arithmetic operations on the pointers similar to any other variable. However, performing arithmetic operations on pointers is different from performing these operations on other variables. For example you cannot perform the subtraction operation on pointers. Table 6.1 shows the different types of operators/keywords that can be applied to a pointer in unsafe context:

| Table 6.1: Operators/ Keywords Applied on Pointers |
| Operator/Keyword | Type | Meaning |
| * | Dereferencer | Performs pointer indirection |
| & | Address | Obtains the memory address of the variable |
| -> | Pointer | Accesses a member of a struct through a pointer |
| [] | Index | Represents index pointed to by a pointer variable |
| +,- | Addition and Subtraction | Represents the addition and subtraction operators to pointer types |
| ++,-- | Increment and Decrement | Represents the increment and decrement operators to pointer types |
| ==,!=,<,>,<=,>= | Comparison | Represents comparison and equality operators to pointer types |
| fixed | Fixed | Fixes a variable temporarily to find its address |
| stackalloc | Stackalloc | Allocates C# arrays directly on the stack |

The operations that are performed on pointers are as follows:

- Addition and Subtraction — Performs addition or subtraction operation between an integer value and pointer variable; however, addition or subtraction operations cannot be performed between two pointer variables. Consider the following code snippet that shows the code to add the two pointers:

```
MyPointer= MyPointer1 + MyPointer2; //Error
```

The preceding code snippet generates an error as you are adding two pointer variables MyPointer1 and MyPointer2.

However, an integer value can be added to a pointer variable. Consider the following code snippet, in which pointer variable MyPointer is added to an integer value:

```
MyPointer= MyPointer + 4;
```

Now in the preceding code snippet, if the pointer variable MyPointer points to the fifth element of an array before addition, then after adding 4, it points to the ninth element of an array. Similarly, subtracting 4 from (MyPointer= MyPointer - 4;) points to the first element of the array.

In case, we perform subtraction operation on two pointer variables, the result is the difference of addresses held by both the pointer variables. The following code snippet shows the subtraction of two pointers:

```
int MyArray[10];
int *MyPointer1, *MyPointer2;
int *MyPointer1 = MyArray + 2;
int *MyPointer2 = MyArray + 5;
MyPointer2= MyPointer2 - MyPointer1;
```

In the preceding code snippet, you can see that after subtraction, the value of the pointer variable MyPointer2, becomes 3.

- Increment and Decrement — Refers to incrementing or decrementing the value of the pointer variable by The increment and decrement operator can be implemented using the ++ and -- symbol. For example, if the MyPointer pointer refers to the third element of the MyArray array, then MyPointer++ refers to the fourth element of the MyArray array and MyPointer-- refers to the second element of the MyArray array

- Comparison—Makes comparison between any two pointers by using comparison operators, such as ==, !=, <, >, <=, and >=.
- Assignment—Assigns the value of another pointer or null to a pointer variable.

## Converting Pointers

Pointer conversion means to convert a pointer type variable to another data type. In C#, pointer conversion includes the conversions, which are as follows:

- Converting pointer type to void* type
- Converting any null type pointer to any pointer type

Additional to this, following explicit pointer conversions are also available in an unsafe code:

- Converting any pointer type variable to another pointer type variable
- Converting sbyte, byte, short, ushort, int, uint, long, or ulong type pointer variables to any other pointer type variable

When you convert one pointer type to another, the actual value of the pointer does not change. It means that after conversion, the address denoted by the pointer remains the same. Pointer conversion should follow a concept where a pointer type, such as Type1 is converted to another type, such as Type2. Further, Type2 is converted to another type, such as Type3, then Type1 should be compatible to Type3. This concept is called Correctly Aligned, which is transitive in nature. Let’s take an example to know about the pointer conversions, as shown in the following code snippet:

```
char MyChar = 'A';
char* CharPointer = &MyChar;
void* VoidPointer = CharPointer;
int* IntPointer = (int*)VoidPointer;
int i = *IntPointer;    // undefined
*IntPointer = 121212;   // undefined
```

In the preceding code snippet, the VoidPointer pointer is accessing the CharPointer pointer and the IntPointer pointer is accessing the VoidPointer pointer.

## Delegates

A delegate is a special type of object that contains the details of a method rather than data. In C#, a delegate is a class type object, which is used to invoke a method that has been encapsulated into it at the time of its creation. A delegate can be used to hold the reference to a method of any class. It carries three important pieces of information—the name of the method on which it makes calls, the arguments (if any) of this method, and the return value (if any) of this method.

In the following sections, first you learn to create and use delegates. Then, you learn about multicast delegates, covariance, and contravariance. Further, you learn about anonymous methods with delegates.

## Creating and Using Delegates

Suppose you need to create a program that requires data, such as student information, to display it on a website. This data can be retrieved by calling a method without having to know at compile time which method is to be invoked. In this case, you need to create an object of delegate and encapsulate a reference to that method inside the delegate object. Following are the four steps to create and use a delegate in your program:

- Declaring a delegate
- Defining delegate methods
- Creating delegate objects
- Invoking delegate objects
