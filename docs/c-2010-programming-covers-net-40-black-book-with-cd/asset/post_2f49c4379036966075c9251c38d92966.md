## The Chart Control

The Chart control enables you to present complex data in a simpler way. It helps you to analyse the data in a easier way with the help of charts. When you drag a Chart control to the page, the following code appears in the Source view of the page:

```
<asp:Chart ID="Chart1" runat="server">
  <series>
    <asp:Series Name="Series1">
    </asp:Series>
  </series>
  <chartareas>
    <asp:ChartArea Name="ChartArea1">
    </asp:ChartArea>
  </chartareas>
</asp:Chart>
```

The inheritance hierarchy of the Chart control is as follows:

```
System.Object
  System.Web.UI.Control
    System.Web.UI.WebControls.WebControl
    System.Web.UI.WebControls.BaseDataBoundControl
    System.Web.UI.WebControls.DataBoundControl
    System.Web.UI.DataVisualization.Charting.Chart
```
