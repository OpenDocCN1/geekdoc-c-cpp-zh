The Task List window also displays syntax errors and other errors that are normally encountered during coding.
The Task List window toolbar contains the following controls:

+   - User Tasks — Enters the tasks directly into the Task List
+   - Comments — Enters the tasks as comments within your code
+   - Create User Task — Adds a new line to the User Tasks pane of the Task List with a cleared check box in the completed column and an editable field in the description column

# The Error List Window

The Error List window shows the syntax errors, noted by the IntelliSense feature, of your program. When you edit and compile code, the errors, warnings, and messages produced are displayed in the Error List window. You can open the file where the error has occurred by double-clicking on any error message entry. To open the Error List window, selecting View → Error List or press the CTRL+ \ , E keys together.

The Error List toolbar, shown in Figure 1.61, consists of the following buttons:

+   - Errors — Displays the number of errors in the list
+   - Warnings — Displays the number of warnings in the list
+   - Messages — Displays the number of messages in the list

The Error List window also contains the following user interface (UI) elements:

+   - Category — Displays a list of the type of error list entry
+   - Default Order — Displays the order number in which an entry was generated
+   - Description — Displays the description of the error, warning, or message entry
+   - File — Shows only the file name or the full path of the file along with the file name
+   - Line — Shows the line number in the code where the error occurred
+   - Column — Shows the column number in the line where the error occurred
+   - Project — Shows the project name in which the error occurred
