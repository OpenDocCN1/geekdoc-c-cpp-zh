# Creating a Shared Assembly

To create a shared assembly, you first need to create a class library, called SharedObject and a Windows application called ASimpleClient (also available on the CD-ROM). Even though the application ASimpleClient is itself an assembly, this section mainly focuses on the SharedObject class library to understand the concepts related to assemblies.

Perform the following steps to create the SharedObject class library:

+   1. Open Microsoft Visual Studio 2010 and select New→Project from the main menu. This opens a New Project dialog box.
+   2. Select the Class Library template from the list of templates (Figure 33.4).
+   3. Enter the name of the application as SharedObject in the Name text box, and location of the application in the Location combo box (Figure 33.4).
+   4. Select the Target Framework of the application to .NET Framework 2.0, as shown in Figure 33.4:
