+   - Polymorphism — Allows polymorphism, which means the derived class can override a base class indexer.
+   - Uniqueness — Provides a signature that uniquely identifies an indexer.
+   - Non-Static — Indexers cannot be static. If you declare an indexer as static, the compiler generates an error.

In many aspects, indexers are similar to properties. However, there are some differences between the two. Table 5.2 shows the differences between Properties and Indexers:

| Table 5.2: Difference between Properties and Indexers |
| Parameters for Difference | Property | Indexer |
| Identification | Allows identification by its name
Allows methods to be called as if they were public data members | Allows identification by its signature
Allows elements of an internal collection or an object to be accessed by using an array notation on the object itself |
| Access | Allows access through a simple name | Allows access through an index |
| Type | Uses static or an instance member | Uses an instance member only |
| Get Accessor Parameters | Provides no parameters to the get accessor of a property | Provides the same formal parameter list as the indexer |
| Set Accessor Parameters | Contains the implicit value parameter | Contains the same formal parameter list as the indexer, in addition to the value parameter |

After discussing namespaces, classes, and objects, let’s proceed to learn about structs.

# Exploring Structs

Primarily offered for backward compatibility with C++ programmers, the struct statement creates a structure of elements. All elements of a structure are private by default, and a structure initializes its elements to the default value for each data type if none is specified. In C#, one big difference between structures and classes is that a structure is created on a stack; whereas, a class is created on a heap. In this section, you learn about the syntax of a struct and access modifiers for structs.

# Syntax of a Struct

The syntax of a struct is similar to that of a class, with the main difference being that a struct is a value type and a class is a reference type. Therefore, a struct does not refer to an object on a heap.

The following code snippet shows the syntax of a struct:

```
[attributes] [modifiers] struct identifier [:interfaces]
{
    body[;]
}
```

The terms used in the syntax can be described as follows:

+   - attribute — Holds additional declarative information. It is optional.
+   - modifier — Allows modifiers, such as new, static, virtual, abstract, and override to be used in a struct. It also allows access modifiers, such as public, internal, and private to be used in a struct. This is also optional.
+   - struct — Refers to the keyword that is mandatory while creating a struct. An identifier that represents the name of the struct must follow the struct keyword.
+   - interface — Contains the interface list, separated by commas. It is optional.
+   - body — Contains all the member declarations.
