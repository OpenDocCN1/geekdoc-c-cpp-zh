# Working with an Event Source

When you talk about events, the equation always has two sides. First, an event source pays attention to firing events and then detects the timing when an event should be fired. Second, the event handler deals with receiving the information that an event has fired and then verifies the information that the event is present. However, to fit into the .NET Framework, an event should provide certain basic information in the form of event arguments that allow it to work with other languages in the environment, such as Visual Basic .NET.
