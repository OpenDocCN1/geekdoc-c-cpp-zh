# Breaking a Loop

While using loops in your program, sometimes you need to break a loop without finishing the task that is being performed inside that loop. You can break a loop by using any of the following three methods:

+   - Using the break statement to terminate a loop immediately
+   - Using a secondary condition, for instance goto statement that jumps to a label to break a loop
+   - Terminating a loop by processing the required number of elements or changing the status of a variable
