1. Create a WCF service application named SimpleInterestService (also available on the CD) by using the WCF Service Application project template. The IService1.cs and Service1.svc.cs files are automatically created while creating the application

2. Open the IService1.cs file and add the following code snippet in the IService1 interface to declare the service contract:

```
[OperationContract]
double CalSimpleInterest(double p, double r, double t);
```

3. Open the Service1.svc.cs file and add the following code snippet in the Service1 class to implement the service contract:

```
public double CalSimpleInterest(double p, double r, double t)
{
    double sInterest = (p * r * t) / 100;
    return sInterest;
}
```

4. Host this WCF service in IIS by selecting the Project→SimpleInterestService Properties option from the menu bar to display the property page for the SimpleInterestService project.

5. Select the Web tab in the property page to view the Web-related properties of the project, as shown in Figure 19.30:

![](bbox=[0.16, 0.36, 0.88, 0.67])

Figure 19.30: Specifying the Option to Host the WCF Service in IIS

6. Select the Use Local IIS Web server radio button in the Servers section to host the WCF service on IIS.

7. Click the Create Virtual Directory button (Figure 19.30) to create a virtual directory for the WCF service. A message box appears after successfully creating virtual directory, as shown in Figure 19.31:

![](bbox=[0.33, 0.73, 0.7, 0.86])

Figure 19.31: Showing a Message Box Notifying the Successful Creation of a Virtual Directory

8. Click the OK button of the message box and close the SimpleInterestService property page.
