# Custom Dependency Properties

Even though WPF has a whole gamut of dependency properties that is exposed through different WPF classes, you may need to create your own dependency properties, known as custom dependency properties. You can implement any kind of WPF functionality to create custom dependency properties. For example, you can create dependency properties if you want to use animations, styles, and data binding on the property.

Note that you can create a dependency property only for a class that directly or indirectly inherits the DependencyObject class. The DependencyProperty class is then instantiated to create a dependency property identifier (name of the dependency property). The dependency property then needs to be registered with the WPF property system using the Register() method of the DependencyProperty class. While registering the dependency property with the WPF property system, you can specify its property metadata and the validation, coerce value, and property changed callbacks.

After registering the dependency property, it is wrapped with a CLR property that uses the GetValue() and SetValue() public methods. Note that although the dependency properties are accessed as traditional CLR properties in both XAML and code-behind file, you can also directly access the GetValue() and SetValue() methods in the code-behind file.
