## 改进的框选

框选功能允许你使用 ALT 键以矩形形状选择文本。Visual Studio 2010 IDE 提供了框选功能，具有以下增强功能：

- 文本插入 – 在所有选定的行中插入新文本
- 粘贴 – 允许你将一个框选内容粘贴到另一个框选
- 零长度框 – 插入零字符长度的垂直选择，以创建用于新文本或复制文本的多行插入点

## 支持调用层次结构

在 Visual Studio 2010 中，调用层次结构功能允许你从一个级别导航到另一个级别的成员。这些成员通过调用层次结构窗口以以下方式导航：

- 调用自 — 将成员导航到调用它的成员
- 调用至 — 将成员导航到被它调用的成员

调用层次结构窗口在 Visual C# 和 Visual C++ 中可用，并显示对方法、属性或构造函数所做的调用或来自该调用。除了这些调用之外，调用层次结构还显示接口成员的实现以及重写虚成员和抽象成员的成员。你可以通过右键单击方法、属性或构造函数并从上下文菜单中选择 View Call Hierarchy 选项来打开调用层次结构窗口

调用层次结构窗口如图 1.15 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_63_0.png)

图 1.15：显示 Delete 方法的调用层次结构

在图 1.15 中，调用层次结构窗口显示了对 Delete 方法所做的调用列表以及从 Delete 方法发出的调用。

## IntelliSense 模式

在 Visual Studio 2010 中，代码编辑器窗口的 IntelliSense 功能为语句完成提供了以下两种模式：

- **建议模式** – 即使在程序中尚未定义，也会建议类和成员。当你使用 IntelliSense 的建议模式在代码编辑器窗口中输入代码并提交条目时，你输入的文本会被插入到程序中。

图 1.20 显示了 IntelliSense 的建议模式：

![](img/e073a4882197be4ab61103cbe0bcb394_65_1.png)

**图 1.20：使用 IntelliSense 的建议模式**

- **完成模式** – 提供类和成员的成员列表，其中包含高亮条目。当你使用 IntelliSense 的完成模式在代码编辑器窗口中输入代码并提交条目时，成员列表中的高亮条目会被插入到代码中。

图 1.21 显示了 IntelliSense 的完成模式：

![](img/e073a4882197be4ab61103cbe0bcb394_66_0.png)

**图 1.21：使用 IntelliSense 的完成模式**

你可以通过按 CTRL+ALT+SPACEBAR 键组合在建议模式和完成模式之间切换。
