# Creating Owned Windows Forms

An owned form is tied to a form that owns it. When you minimize the owner form, the owned form is also minimized. You can add an owned form to an owner form in an application by using the AddOwnedForm method, and remove it by using the RemoveOwnedForm method. Let’s create an application named WinOwnedForm, to learn how to create an owned Windows Form.

Perform the following steps to create an owned form:

+   1. Create a Windows Forms application, WinOwnedForm.
+   2. Add a button control, button1, to Form1
+   3. Modify the Text property of Form1 to Owner Form, and button1 to Display Owned Form, as shown in Figure 8.32:
