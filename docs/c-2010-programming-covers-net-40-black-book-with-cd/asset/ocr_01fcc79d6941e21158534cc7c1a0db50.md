# MEF and MAF

MEF is a new technology that provides a new library to the .NET Framework 4.0. It extends a composable system with the components that are deployed by third parties. MAF technology is at a slightly higher-level than MEF, as it emphasizes the extension isolation as well as assembly loading and unloading.

In Appendix D of CD, Introducing MAF and MEF Frameworks, you learn about exports, imports, composable parts, contracts, catalogs, containers, and export providers. It also describes Add-in Model and pipeline segments and how to discover, activate, and deploy add-ins.
