## In Depth

Typography and documents are two essential components of Windows Presentation Foundation (WPF). Using typography, you can apply different styles to your text, such as displaying special characters, adding decorations to the text, manipulating, wrapping, trimming, and transforming the text, and applying the blur effect to the text. WPF also provides various typography classes, such as TextDecoration, Typography, RotateTransform, and TextEffect, to apply different typographic features to the text. These features include rendering text and supporting the OpenType font. The document component allows you to create flexible and well-formatted text. This component is located in the System.Windows.Documents namespace. In WPF 4.0, there are two types of documents, Fixed documents and Flow documents. Fixed documents are typeset and ready-to-print documents, where the positioning of all the content is fixed. They are represented by the FixedDocument class and their content is displayed using the DocumentViewer control. Flow documents are designed to provide the better display and readability of content to users. The content of a Flow document is automatically adjusted when the window in which it is displayed is resized. In WPF 4.0, the major rich document features include creating, viewing, managing, and printing documents.

In this chapter, you learn about typography and its features. You also learn about some important classes used to apply typography features to the text. Next, you learn about documents available in WPF 4.0, including Fixed and Flow documents. The implementation of all the concepts discussed in the In Depth section is shown in the Immediate Solutions section.

Let’s start by learning about typography.

## Typography and its Features

WPF supports rich presentation of text, termed as Typography, to display text on a screen. Typography is the art of designing and decorating text using various classes, such as RotateTransform, ScaleTransform, SkewTransform, TextEffect, and BitmapEffect. In WPF, typography uses Microsoft ClearType, which is a software technology developed by Microsoft to improve the readability of text on Liquid Crystal Display (LCDs), such as flat panel monitors, laptop screens, and Pocket PC screens. The major typographic features in WPF include improved quality and performance of text rendering, OpenType typography support, enhanced font support, and the new text application programming interfaces (APIs). In WPF 4.0, typography provides the following features:

- Rendering text using Microsoft ClearType
- Support for the OpenType font format and international fonts
- Enhanced text Application Programming Interfaces (APIs)

Now, let’s discuss these features of typography, in detail.

### Rendering Text using Microsoft ClearType

In WPF, text is rendered using the Microsoft ClearType technology that includes various enhancements, such as sub-pixel positioning, y-direction antialiasing, and hardware acceleration. ClearType uses sub-pixel rendering to enhance the clarity and readability of text. It increases the sharpness of the tiny details in text display; thereby, making it easier for you to work on your computers for long duration without actually straining your eyes. The y-direction antialiasing feature of ClearType provides better resolution on both the x-axis and y-axis of the text. This feature smoothes the sharp edges of text that detract the readability of the text. ClearType also provides the hardware acceleration feature that increases the performance of the system by reducing the Central Processing Unit (CPU) load and system memory requirements.

### Support for the OpenType Font Format and International Fonts

The OpenType font format developed jointly by Microsoft and Adobe is an extension of the TrueType font format. It provides a rich collection of advanced typographic features, such as stylistic alternates and swashes. Swashes are decorative elements associated with calligraphy. They are used in short phrases, such as event announcements. In WPF, typography supports enhanced international text fonts by providing the following features:

- Automatic line-spacing in all writing systems
- Language-guided line breaking and hyphenation
- Support for international text

> NOTE
> TrueType fonts offer the highest possible quality of text on computer screens and printers.

### Enhanced Text Application Programming Interfaces

In WPF 4.0, you can use the text APIs while including the text in your application. These APIs provide common User Interface (UI) controls, such as Label, TextBlock, and TextBox, to enable you to easily interact with text. You can also use the RichTextBox and PasswordBox controls in your application for more advanced and specialized text handling. You can also perform text manipulation with the help of various classes, such as TextRange, TextSelection, and TextPointer provided by the text APIs.

The text APIs also allow you to directly draw text in your application using the DrawText method of the DrawingContext object. You need to create a FormattedText object to use the DrawText method. The FormattedText object allows you to draw multi-line text so that you can format each character of the text individually. In addition, you can create custom text layout by using the TextFormatter object and other types in the System.Windows.Media.TextFormatting namespace.

## Important Classes of Typography

In WPF, there are some important classes that support typography and its features. These classes are vital elements used to apply the typography features to the text. This enables you to improve the quality of text and enhance the font style. The important classes of typography are as follows:

- The TextDecoration class
- The Typography class
- The Transform class
- The TranslateTransform class
- The RotateTransform class
- The ScaleTransform class
- The SkewTransform class
- The TextEffect class
- The BitmapEffect class

Let's discuss each of these classes in detail and look at their features and properties.

### The TextDecoration Class

The TextDecoration class is used to decorate the text. There are four types of text decorations available in WPF: underline, baseline, strikethrough, and overline. The TextDecoration class is derived from the Animatable class that helps in applying animated effects to the text.

The inheritance hierarchy of the TextDecoration class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Freezable
        System.Windows.Media.Animation.Animatable
          System.Windows.TextDecoration
```

The following code snippet shows how to add the TextDecoration class to a WPF application:

```
<TextDecoration .../>
```

### The Typography Class

The Typography class provides access to a rich set of OpenType typography properties. It helps in applying a consistent style to all the text. You can easily create documents in WPF using the OpenType font by setting the properties of typography in markup or code. The Typography object exposes the set of features that the OpenType font supports.

The inheritance hierarchy of the Typography class is as follows:

```
System.Object
System.Windows.Documents.Typography
```
