# Understanding Generics

Generics can be defined as a technique with which you can delay the specification of the type of one or more programming elements in a class or method, until the time of using that class or method. In generics, instead of specifying the data type of the parameters, labels are defined, which can later be replaced by the data type that is specified at the time of using the generic method or class. Let’s understand the concept of generics by considering the following code snippet:

```
public class MyGenericCollection<Tp>
{
  private Tp[] Arr;
  public MyGenericCollection(int Size) {
    Arr = new Tp[Size + 1];
  }
  public Tp GetItems(int index) {
    return Arr[index];
  }
  public void SetItems(int index, Tp value) {
    Arr[index] = value;
  }
}
```

In the preceding code snippet, we have declared a class called MyGenericCollection with a label called Tp. Later in the definition, we have also declared an array of type Tp. Now in the following code snippet, we have specified an integer for label Tp which, at runtime, replaces all occurrences of Tp in the class definition with an integer:

```
MyGenericCollection<int> MGColInt;
```

With Tp replaced by an integer, the MyGenericCollection class now makes the Arr array integer type. You can also define methods that are generic in nature, as shown in the following code snippet:

```
public string Sum<T>(T val1, T val2)
{
  ...
}
```

In the preceding code snippet, we have declared a generic method named Sum, which contains two parameters val1 and val2 of T type. When you call a generic method, you need to pass the values for these parameters.

The following code snippet shows the use of the Sum() method:

```
private void button3_Click(object sender, System.EventArgs e)
{
  Arithmetic objA1 = MGColA.Items[0];
  Arithmetic objA2 = MGColA.Items[1];
  Person objP1 = MGColP.Items[0];
  Person objP2 = MGColP.Items[1];
  TextBox1.Text = Sum(objA1, objA2);
  TextBox2.Text = Sum(objP1, objP2);
}
```

# Generic Collection Classes in .NET

.NET provides a number of classes to create a generic collection. Generic classes are substitute of collection classes and are strongly typed. The methods contained in these classes provide different functionalities, such as sorting of elements, reversing the order of elements, and searching a particular element in the contained elements. Generic classes also allow you to make generic collections of key/value pairs. These key/value pairs allow you to add, sort and search elements. Some of the generic collection classes are as follows:

+   - The List<T> class
+   - The LinkedList<T> class
+   - The SortedList<TKey, TValue> class
