## 类型转换

在编写 C# 应用程序时，你经常需要执行一个典型的任务，即将一种数据类型转换为另一种数据类型。对于这种类型的转换，需要使用类型转换。类型转换有两种形式：隐式转换和显式转换。

### 隐式转换

隐式转换是由编程语言以类型安全的方式执行的转换。例如，将整数转换为浮点数就是隐式完成的，如以下代码片段所示：

```
int I = 123;
Single s = I;
```

| 转换方法 | 说明 |
|---|---|
| ToBoolean | 如果可能，将类型转换为布尔值 |
| ToByte | 将类型转换为字节 |
| ToChar | 如果可能，将类型转换为单个字符（Unicode） |
| ToDateTime | 将类型（主要是整数和字符串）转换为日期时间结构 |
| ToDecimal | 将类型（浮点数或整数）转换为十进制值 |
| ToDouble | 将几乎任何类型安全地转换为 double 类型 |

### 显式转换/类型转换

当借助某些预定义函数将一种数据类型显式转换为另一种数据类型时，称为显式转换。请注意，在执行显式转换时，由于这种转换是强制性的，因此存在数据丢失的可能性。以下代码片段演示了如何显式转换数据类型：

```
Single s = 123.45f;
int I = (int)s;
```

在转换数据类型时，你应该知道要转换的数据类型是否能够转换为目标类型。表 2.5 列出了 C# 允许从“从”列中的数据类型显式转换为“到”列中的数据类型：

| short | sbyte、byte、ushort、uint、ulong 或 char |
| ushort | sbyte、byte、short 或 char |
| int | sbyte、byte、short、ushort、uint、ulong 或 char |
| uint | sbyte、byte、short、ushort、int 或 char |

显式转换数据类型可能会导致精度丢失或抛出意外异常。因此，在执行类型转换时，你应该始终小心谨慎。

## 装箱和拆箱

装箱和拆箱是 C# 类型系统中使用的两个重要概念。它们用于在 C# 的两大数据类型（值类型和引用类型）之间建立联系。所有值类型都存储在栈上，但在某些情况下，它们需要作为堆上的引用。由于引用类型存储在堆上，因此你可以将值类型转换为引用类型。这种转换称为装箱。

## 第 2 章：C# 基础

当值类型转换为基对象或接口时，就需要进行装箱。公共语言运行时（CLR）将值类型转换为引用类型。CLR 在堆上分配内存，然后将值类型实例复制到该内存中。装箱是一个昂贵的过程，因为它将对象从栈复制到堆，这需要大量的处理器周期以及堆上的空间。使用装箱的另一个缺点是，同一个对象在内存中的两个不同位置出现，这可能导致相互矛盾的状态。

拆箱是将对象类型或接口的实例转换回值类型的过程。这是通过使用拆箱显式完成的。以下代码片段演示了如何隐式完成装箱，而拆箱则必须通过使用类型转换显式完成：

```
int y = 123; //一个值类型
object obj = y; //装箱是隐式的
int z;
z = (int) obj; //拆箱是显式的（使用类型转换来拆箱）
```
