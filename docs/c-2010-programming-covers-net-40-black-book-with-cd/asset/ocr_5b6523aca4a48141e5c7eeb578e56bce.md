| Table 9.11: Highest to Lowest Precedence for Dependency Properties |
| Input | Description |
| Theme Styles | Applies the value that is set through the default theme styles. In the default styles, values set through triggers have higher precedence than those set through the Setter property of the default style. |
| Inherited Values | Applies the value that is set through the property value inheritance, that is, the value is inherited from the parent element. |
| Values from Metadata | Applies the value that is set through the property metadata of the dependency property. |

Let’s take an example to demonstrate how the precedence of values of a dependency property works. Consider the code given in Listing 9.5:

# Listing 9.5: Demonstrating the Precedence of Dependency Property Values

```
<window x:Class="PrecedenceDependencyProperty.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="300" Width="300">
    <Window.Resources>
        <Style TargetType="Button">
            <Setter Property="Background" Value="Green"/>
            <Style.Triggers>
                <Trigger Property="IsMouseOver" Value="True">
                    <Setter Property="Background" Value="Red"/>
                </Trigger>
            </Style.Triggers>
        </Style>
    </Window.Resources>
    <Grid>
        <Button Name="button1" Height="25" Margin="50" Content="Button1" Background="Orange" VerticalAlignment="Top"/>
        <Button Name="button2" Height="50" Margin="20" Content="Button2" VerticalAlignment="Center"/>
    </Grid>
</Window>
```

In Listing 9.5, you can see the XAML code for a standalone WPF application named PrecedenceDependencyProperty. The window of the application has a style resource that applies on all the buttons in the application. In the style resource, the dependency property Background of the buttons is set to Green. The style resource also has a trigger that causes the Background property to be set to Red whenever you place the mouse over a button.

As you can see from Listing 9.5, the grid has two buttons named button1 and button2. The Background property of button1 is set to Orange. Since a locally set value has higher precedence than style resources; therefore, the Background property of button1 is Orange and not Green. However, button2 does not have the Background property directly set as a local value; therefore, it takes Green as its effective value. In addition, when you place the mouse over button2, the Background property of button2 is set to Red. This is because the style trigger that is defined in the style resource has higher precedence than the style setter (to set Background=Green).
