# The FlowDocumentPageViewer Control

The FlowDocumentPageViewer control splits a Flow document into multiple pages and allows you to view flow content in a fixed viewing mode. In the fixed viewing mode, one page is displayed at a particular instance of time. When you display the content in a Flow document using the FlowDocumentPageViewer control, the page is divided into two parts: content area and toolbar. The content area displays the content of FlowDocument specified by the Document property. The Toolbar is further divided into the following three parts:

+   - **The Page Navigation control**—Includes a button to move to the next page or the previous page using the down arrow or the up arrow, respectively. It also includes indicators for current page number and total number of pages.
+   - **The Zoom control**—Enables you to increase or decrease the zoom level by clicking the plus or the minus button. It also provides a slider for adjusting the zoom level.
+   - **The Search TextBox text box**—Helps you find strings with content. The keyboard shortcut, CTRL+F, is also used to find the string with the content.
