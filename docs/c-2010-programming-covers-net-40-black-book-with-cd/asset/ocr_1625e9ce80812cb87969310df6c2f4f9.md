Table 10.15 describes the noteworthy properties of the Slider class:

# Table 10.15: Showing the Noteworthy Properties of the Slider Class

| Property | Description |
|---|---|
| AutoToolTipPlacement | Gets or sets whether a tooltip containing the current value of the control is displayed at the time of pressing the Thumb control |
| AutoToolTipPrecision | Gets or sets the number of digits that are displayed to the right side of the decimal point representing the value of the Slider control that is to be displayed in a tooltip |
| DecreaseLarge | Retrieves a command that decreases the value of a control by the same amount as that of the LargeChange property |
| DecreaseSmall | Retrieves a command that decreases the value of a control by the same amount as that of the SmallChange property |
| Delay | Gets or sets the time in milliseconds for the RepeatButton control to wait, before executing a command to move the Thumb control. |
| IncreaseLarge | Retrieves a command that increases the value of a control by the same amount as that of the LargeChange property |
| IncreaseSmall | Retrieves a command that increases the value of a control by the same amount as that of the SmallChange property |
| Interval | Gets or sets the time in milliseconds when a user clicks the RepeatButton control of the Slider control |
| IsDirectionReversed | Gets or sets the direction for increasing the value of the Slider control |
| IsMoveToPointEnabled | Gets or sets a value that indicates whether or not the Thumb control of a Slider control moves immediately to the location of the mouse click |
| IsSelectionRangeEnabled | Gets or sets a value that indicates whether the Slider control displays a selection range |
| IsSnapToTickEnabled | Gets or sets a value that indicates whether the Thumb control is automatically moved to the closest tick mark by the Slider control |
| MaximizeValue | Retrieves a command that sets a Slider control's current value to maximum |
| MinimizeValue | Retrieves a command that sets the Slider control's current value to minimum |
| Orientation | Gets or sets the orientation of the control |
| SelectionEnd | Gets or sets the largest value of a specified selection for the control |
| SelectionStart | Gets or sets the smallest value of a specified selection for the control |
| TickFrequency | Gets or sets the interval between tick marks on the control |
| TickPlacement | Gets or sets the position of tick marks with respect to the Track control of a Slider control |
| Ticks | Gets or sets the positions of the tick marks to be displayed on the control |
