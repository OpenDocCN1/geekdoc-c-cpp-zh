## The AutoCompleteBox control

The AutoCompleteBox control is a new control in Silverlight 3.0 and provides a text box where the users can input some data and a drop-down list that displays possible matches as the users type a word or character in the text box. Using the AutoCompleteBox control, users can select an appropriate item from the drop-down list to complete their input in the text box rather than typing the entire word. For instance, if an AutoCompleteBox control contains the names of the days, Monday, Tuesday, Wednesday, and Thursday and a user enters T in the text box, then a drop-down list appears displaying the days, Tuesday and Thursday. ## The DataPager Control

The DataPager control is also a new control introduced with Silverlight 3.0. You can use a DataPager control when you have a large collection of data and it is not possible to display the entire data in a single page. The DataPager control is used to represent the necessary UI for paging through a data collection. You can bring about paging capabilities to a data collection that implements the IPagedCollectionView interface as the data source. The IPagedCollectionView interface contains the definition of methods and properties to provide paging capabilities to a collection of data. For instance, you can use the DataPager control with the ListBox control in a Silverlight application to page through the data being displayed in the ListBox control. ## The TreeView Control

Yet another interesting control that has been introduced with Silverlight 3.0 is the TreeView control that used to be a part of Silverlight 2.0 Toolkit. A TreeView control has a structure similar to that of a tree and can be used to display hierarchical data in the form of nodes. A node that contains child nodes in a TreeView control can be collapsed and expanded as well. You can click on any node of a TreeView control to collapse it or expand the node to reveal its child nodes. The TreeView control is a specialized ItemsControl, which means that you can populate the TreeView control with some content by either setting its Items or ItemsSource properties.
