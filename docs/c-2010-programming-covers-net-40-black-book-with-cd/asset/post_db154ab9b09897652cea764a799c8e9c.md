# XCopy Deployment

To deploy a Web application by using the XCopy deployment technique, open the Run dialog box from the Start menu of Windows. Type cmd in the Open text box of the Run dialog box and then click the OK button. This step opens the command prompt, where you need to type the following command:

```
xcopy /I /S c:\inetpub\wwwroot\DeploymentTestWebSetup d:\MyWebApp
```

In the preceding command, the source folder named DeploymentTestWebSetup exists in the c drive and the destination folder named MyWebApp exists in the d drive. When you execute this command, all the files and folders within the DeploymentTestWebSetup folder are deployed to the targeted folder. The /I parameter
allows the XCopy command to create the destination folder if it does not exist. Figure 21.45 shows the output of the preceding command:

![](img/e073a4882197be4ab61103cbe0bcb394_1094_0.png)

# Deploying an XBAP Application Using Windows Installer

XBAPs are the compiled applications, which you can host on the Web browser. These hosted applications run in a partially trusted security environment; therefore, they are restricted to use only limited resources of the computer. The compilation of XBAPs results in the creation of three files—ApplicationName.exe, ApplicationName.xbap, and ApplicationName.exe.manifest and the deployment require these three files to be deployed.

You can deploy an XBAP application using either the XCopy or the Windows Installer deployment technique.
