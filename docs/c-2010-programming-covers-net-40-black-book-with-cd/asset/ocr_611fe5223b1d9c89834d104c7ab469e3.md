If you want to view and modify the properties of other components, such as buttons or labels, then drag these components on the form and select the component whose properties you want to modify. When you select the appropriate component, the properties associated with that component are displayed in the Properties window. The properties displayed in the Properties window are different for different components or controls. In other words, the properties associated with a Button control are different from the properties associated with a Label or a Form control. Note that some properties in the Properties window appear in gray text. The properties appearing as gray are the read-only properties.

The Properties window also displays a toolbar containing various buttons. These buttons are explained, starting from left to right, as follows:

+   Categorized – Enables you to group the properties of a control into categories. The properties are categorized depending upon the function that they perform in a control. For example, when you select a form in Solution Explorer and click the Categorized button on the toolbar, the Form properties are grouped into Accessibility, Appearance, Behavior, Data, Design, Focus, Layout, Misc., and Window Style categories.

+   Alphabetical – Displays the properties of a control in the alphabetical order.

+   Properties – Displays all the properties of a control.

+   Events – Displays all the events of a control.

+   Property Pages – Displays the Property Pages dialog box for the selected component. You can use the Property Pages dialog box to view and edit properties related to the configuration of the project.

The Object Browser window can be opened in either of the following ways:

+   By selecting View→Object Browser from the main menu
