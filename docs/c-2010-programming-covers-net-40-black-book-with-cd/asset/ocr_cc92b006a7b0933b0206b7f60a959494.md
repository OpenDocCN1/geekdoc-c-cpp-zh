# Declaring Variables

As discussed, variables are used to store values. Variables are of two types, input and output. Input variables are used to take input from a user; whereas, output variables are used to store output results and display data to the user. Now, to understand the declaration of variables, let's create a new C# 2010 Console application named DeclaringVariable (also available on the CD-ROM). Perform the following steps to create the DeclaringVariable application and declare variables in it:

+   1. Open Visual Studio 2010 IDE by clicking Start → All Programs → Microsoft Visual Studio 2010 → Microsoft Visual Studio 2010.

+   2. Select File → New → Project on the menu bar. The New Project dialog box appears, as shown in Figure 2.1:
