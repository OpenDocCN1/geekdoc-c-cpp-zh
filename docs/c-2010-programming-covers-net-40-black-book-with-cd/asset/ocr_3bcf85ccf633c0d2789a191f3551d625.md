# Improved Application Compatibility and Deployment Support

The applications that are developed in the earlier versions of .NET Framework are supported in this version. This implies that the new version of .NET Framework is compatible even with the applications developed in the earlier version of .NET Framework. You can run an application developed in the older version of .NET Framework by specifying the target version of .NET Framework at the time of compilation. You can also run an application created in the older version of .NET Framework by specifying the supported runtime in the application configuration file by using the <supportedRuntime> element.

The following features introduced in the .NET Framework 4.0 provide an improved deployment support:

+   - .NET Framework Client Profile — Improves the deployment process by providing a fast deployment of Windows forms, console, or WPF applications.
+   - In-Process Side-by-Side Execution — Helps in loading and starting multiple versions of .NET Framework. The Component Object Model (COM) components run with the .NET Framework, they were developed in.

# Dynamic Langauage Runtime

The DLR feature is introduced in .NET Framework 4.0 to implement dynamic languages, such as Python and Ruby. This implies that the DLR is a runtime environment that adds services to the CLR to implement dynamic languages.

The purpose of DLR is not only to enable the dynamic languages to run on the .NET Framework but also to provide them with the advantage of .NET interoperability. A new System.Dynamic namespace has been added in.NET Framework to support the DLR functionality. The advantages of DLR are as follows:

+   - Implements dynamic features in the statically-typed languages, such as C# and Visual Basic (VB), so that these languages can also create dynamic objects
+   - Enables interoperation between statically-typed languages and dynamic languages, so that the objects that are implemented in one language can easily be used by other languages
+   - Helps the developers to concentrate on the specific language features as the developers do not have to create code generators
