# Calling WCF Services with ASP.NET AJAX

As learned earlier, you can call a WCF service with ASP.NET AJAX. An ASP.NET WCF service that consists of the functionality of ASP.NET AJAX is known as the ASP.NET AJAX-enabled WCF service. To learn how to call a WCF service with ASP.NET AJAX, you need to perform the following steps:

+   1. Create an ASP.NET AJAX-enabled WCF service
+   2. Call WCF services from client-side scripts

Let’s perform these steps, one by one.

# Creating an ASP.NET AJAX-Enabled WCF Service

.NET Framework allows you to create an ASP.NET AJAX-enabled WCF service. Perform the following steps to create an ASP.NET AJAX-enabled WCF service:

+   1. Create a Web site, named MyAjaxEnableWCFService (also available on the CD-ROM).
+   2. Select the AJAX-enabled WCF Service template and enter the name of the service in the Name text box. In this case, we have entered OperationService.svc.
+   3. Click the Add button to add the service in the website, as shown in Figure 19.43:
