## Support for Networking

Silverlight 3.0 contains classes to support networking and predefined sockets. It allows you to use various Hypertext Transfer Protocol (HTTP), eXtensible Markup Language (XML), Really Simple Syndication (RSS), and Representational State Transfer (REST) services. Furthermore, you can use an XML format to use the data and resources on other Web sites. Silverlight extends the cross-domain support for networking. You can also use Silverlight 3.0 for communication with sockets over standard network protocols, such as IPv4 and IPv6.

## Support for Higher Quality Video and Audio

Among the host of new features in Silverlight 3.0, the media enhancements that have been introduced are worth mentioning. Silverlight 3.0 introduces support for new audio and video formats, such as H.264, Advanced Audio Coding (AAC), and Moving Picture Experts Group (MPEG) 4. This in other words means that the MediaElement control within Silverlight can now play back H.264 encoded content.

In addition, Silverlight 3.0 includes support for live and on-demand Internet Information Services (IIS) 7 Smooth Streaming, full HD (720p+) playback, and raw audio or video (AV) pipeline. Furthermore, the raw AV pipeline is expected to enable the .NET developers to provide audio/video decoding that can be hosted in Silverlight outside the .NET Framework runtime environment.

> NOTE
> The Silverlight's MediaElement control is a rectangular control that is used to either play audio or display some video on its surface. You learn more about MediaElement control later in this chapter.

## Empowering Richer Experience

The support for perspective 3-D transformations in Silverlight 3.0 will enable the .NET developers and designers to create next generation engaging Web visuals containing new 3D graphics, animation features, hardware accelerated effects, and text improvements. Perspective transforms can be understood as transforms that you can apply on XAML elements to simulate a 3-D environment. You can bring about 3-D effects to controls in your Silverlight applications without writing a lot of code by using the attached property, called Projection, within a parent element. For instance, consider the following code snippet:

```
<Button Height="90" Content="Perspective Transform">
<Button.Projection>
<PlaneProjection RotationY="60"/>
</Button.Projection>
</Button>
```

In the preceding code snippet, the Button control is rotated to give it a perspective, with a 60 degree rotation on the Y axis.

> NOTE
> An attached property can be thought of as a global property that is used to provide some additional information to a control. These properties support XAML syntax and can be used to enable the child elements to inform the parent elements that how they will be represented in the UI.

Furthermore, the .NET developers and designers can now enrich the media experience of the users by implementing other graphic capabilities, such as pixel shader effects and animation effects. The pixel shader effects can be used to incorporate the built-in blur and drop shadow effects or you can even write your own effects in controls, such as a button.

> NOTE
> A pixel shader is a type of program that is used to calculate the color of individual pictures on screen. The pixel shader mostly executes on a graphics processing unit (GPU) and is written in a shading language called HLSL, which has syntax similar to C.

You can also use animation effects, such as spring and bounce, on controls in your Silverlight application. In addition, you can also define an animation using your own mathematical functions now.

## Improving Rich Internet Application Productivity

As stated earlier, you know that using Silverlight, you can build RIAs that are visually appealing and interactive as well. The deep linking feature enables you to bookmark a page within an RIA.

## Enhanced Data Support

In Silverlight 3.0 applications, you can now look forward to element to element binding, which is also known as, element data binding. The element to element binding feature allows you to bind a property of an element to the property of some other element. You can use the element binding feature by simply including the ElementName property in a binding expression, as shown in the following syntax:

```
Text="{Binding Value, ElementName=SizeSlider}"
```

Silverlight 3.0 also enables Search Engine Optimization (SEO) by using server-based business objects with ASP.NET controls and site maps. In Silverlight 3.0, the business objects are supported on both client and server. In addition, Silverlight 3.0 enables the users to perform operations, such as loading, sorting, and filtering the server side data.

> NOTE
> SEO is a technique of improving a Web site by bringing about certain amendments in it so that the ranking of the Web site increases in search engines, such as Google. This technique helps in maximizing the number of users accessing a particular Web site.

## Improved Performance

The improvement in the performance of Silverlight 3.0 applications is attributed to the following features:

- Assembly caching – Enables the caching of assemblies locally on the client’s machine. In other words, it means that you need not include all the Silverlight assemblies to create an application package by compiling your Silverlight 3.0 applications, as you can use the Silverlight assemblies from the client’s machine.
- Binary XML – Helps in increasing the speed at which data can be exchanged between the client and the server by allowing the compression of communication with the server.
- Local connection – Enables two Silverlight applications being hosted within the same ASP.NET or HTML test pages to communicate with each other on the client-side itself so that the messages need not be sent back and forth between the client and the server. The Silverlight 3.0 applications are able to communicate with each other because of a new API called LocalConnection that has been introduced in Silverlight 3.0. For instance, a DataGrid control in a Silverlight application can communicate with a ListBox control in another Silverlight application.

## Out of Browser Capabilities

The out of browser capability introduced with Silverlight 3.0 enables the Silverlight applications to be run either within or outside a Web browser. In other words, it means that the users can install a Silverlight application on their system and run it outside any browser. You can indicate that a Silverlight application will run outside the browser by making some changes in the AppManifest.xml file of the Silverlight application, as shown in the following code snippet:

```
<Deployment xmlns="http://schemas.microsoft.com/client/2007/deployment" xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml" >
<Deployment.Parts>
</Deployment.Parts>
<Deployment.OutOfBrowserSettings>
<OutOfBrowserSettings.ShortName="Out of Browser Silverlight Application">
<OutOfBrowserSettings.WindowSettings>
<WindowSettings Title=" Out of Browser Silverlight Application" />
</OutOfBrowserSettings.WindowSettings>
<OutOfBrowserSettings.Blurb>Comments of my Silverlight Application</OutOfBrowserSettings.Blurb>
</OutOfBrowserSettings>
</Deployment.OutOfBrowserSettings>
</Deployment>
```

> NOTE
> You can find the AppManifest.xml file within the Properties folder of a Silverlight application.
