# Changing the Direction of the Flow Content

In WPF, you can use the FlowDirection property to change the direction of the flow content. The FlowDirection property gets or sets the relative direction for the flow of the content within a Block element. The default value of the FlowDirection property is LeftToRight. Let’s create a WPF application named ChangingDirection_FlowContent (also available on the CD-ROM) to learn how to change the direction of a flow content. For this, add the code given in Listing 11.16 to the MainWindow.xaml file of the ChangingDirection_FlowContent application:

# Listing 11.16: Showing the Code for the MainWindow.xaml File of ChangingDirection_FlowContent

```
<Window x:Class="ChangingDirection_FlowContent.MainWindow"
xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
Title="MainWindow" Height="160" Width="400">
<FlowDocumentPageViewer>
<FlowDocument>
<Paragraph FlowDirection="LeftToRight">This text is from left to right.
</Paragraph>
<Paragraph FlowDirection="RightToLeft">This text is from right to left
</Paragraph>
</FlowDocument>
</FlowDocumentPageViewer>
</Window>
```

In Listing 11.16, we have added two text lines with different direction. The first line has the default direction and the second line is in the RightToLeft direction. The output of Listing 11.16 is shown in Figure 11.15:

# Adding a Table in a Flow Document

In WPF, a Table is a block-level element that provides a grid-based presentation of text consisting of columns and rows. Columns are represented by TableColumn elements and rows are represented by TableRow elements. Within a Flow document, the Table element supports various features, such as pagination, column reflow, and content selection. The TableColumn element does not host any content; it just defines columns. The TableRow element must be hosted in the TableRowGroup element that defines the grouping of rows in the Table element.

Let’s create a WPF application named AddingTable (also available on the CD-ROM) to learn about creating a table. Add the code shown in Listing 11.17, to the MainWindow.xaml file of the AddingTable application:

# Listing 11.17: Showing the Code for the MainWindow.xaml File of the AddingTable Application

```

xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
Title="MainWindow" Height="300" Width="350">
<FlowDocumentReader>
<FlowDocument>
<Table>
<Table.Columns>
<TableColumn/>
<TableColumn/>
```
