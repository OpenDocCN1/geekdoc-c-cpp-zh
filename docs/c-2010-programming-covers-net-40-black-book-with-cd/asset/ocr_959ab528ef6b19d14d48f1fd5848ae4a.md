| Term | Definition |
|------|------------|
| alias | Refers to an attribute of the Schema element in Conceptual Schema Definition Language (CSDL) and Storage Metadata Schema Definition Language (SSDL) schemas. |
| association | Defines the relationship between entity types in a Framework. |
| association set | Refers to a logical container for instances of associations of the same type. |
| base type | Refers to a parent type or super type in the EDM from which the derived types inherit some of their properties. |
| command tree | Refers to a common programmatic representation of all Entity Framework queries that are composed of one or more expressions. |
| complex object | Refers to an instance of a complex type that exists within an object context. |
| constraint | Restricts the possible values of a property and makes sure that the values are valid. |
| container | Refers to a logical grouping of entity and association sets. |
| concurrency | Defines a process that allows multiple users to access and change shared data at the same time. Entity Framework implements an optimistic concurrency model. |
| direction | Refers to the asymmetrical nature of some associations. A direction is specified with the FromRole and ToRole attributes of a NavigationProperty or ReferentialConstraint element in a schema. |
| end | Refers to a participating entity in an association. |
| conceptual schema definition language (CSDL) | Refers to an Extensible Markup Language (XML)-based language that is used to define the entity types, associations, entity containers, entity sets, and association sets of a conceptual model. |
| conceptual model | Refers to an abstract specification for the entity types, associations, entity containers, entity sets, and association sets in the domain of an application built on an EDM. |
| entity | Refers to a concept in the domain of an application from which a data type is defined. |
| EntityClient | Refers to a storage-independent ADO.NET data provider that contains classes such as EntityConnection, EntityCommand, and EntityDataReader. It works with Entity SQL and connects to storage-specific ADO.NET data providers such as SqlClient. |
| entity set | Refers to a logical container for entities of a given type and its subtypes mapped to tables in a database. |
| Entity SQL | Refers to a storage-independent dialect of SQL, which works directly with conceptual entity schemas and supports EDM features such as inheritance and relationships. |
| entity container | Specifies entity sets and association sets that are implemented in a specified namespace. |
| EntityType | Refers to a specification for a data type that includes a named set of properties and represents a top-level item in a data model. |
| key | Refers to an attribute of an entity type that specifies which property or a set of properties is used to identify unique instances of the entity type. |
| mapping specification language (MSL) | Refers to an XML-based language that is used to map items defined in a conceptual model to items in a storage model. |
