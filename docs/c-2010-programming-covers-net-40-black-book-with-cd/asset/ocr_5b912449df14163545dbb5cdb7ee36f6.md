# Using the Blocks and Inlines Properties of Flow Content Elements

You can use the Blocks and Inlines properties in WPF to add elements in a document programmatically. The Blocks property is used to add and remove items from BlockCollection. The Inlines property is used to add and remove items from InlineCollection. The Flow content elements supported by the Blocks property are: Figure, Floater, ListItem, Section, and TableCell. The Flow content elements supported by the Inlines property are: Bold, Hyperlink, Italic, Paragraph, Span, and Underline.
