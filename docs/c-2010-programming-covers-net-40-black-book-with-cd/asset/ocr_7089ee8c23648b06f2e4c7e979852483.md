# The Path Class

The Path class is used to perform operations on String instances that contain file or directory path information. Path is a string that provides you the exact location of a file or directory. It is not mandatory that path the always refers to only a location on the disk. The path format depends mostly on the current platform. Therefore, some systems paths start with a drive or letter name, but this is not true for all the systems.
In some systems, path also contains file extension that contains information regarding files. The extension format for any file is platform dependent. For instance, some systems limit their file extensions up to 3 characters, while others do not. The nature of the current platform also analyzes the character sets that are used to separate the elements of a path and the character sets that do not play any role in specifying the paths.

Table 29.16: Showing the Methods of Path class
