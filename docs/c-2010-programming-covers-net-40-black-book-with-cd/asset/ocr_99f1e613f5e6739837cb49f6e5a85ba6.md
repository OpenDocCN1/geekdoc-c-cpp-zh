DynamicHoverStyle—Sets the style properties of the individual MenuItem property that is currently selected. In other words, it can be set for the selected MenuItem while you hover your mouse over a MenuItem property. It also includes properties such as ItemSpacing, HorizontalPadding, and VerticalPadding.

# Using the SiteMapPath Class

The SiteMapPath class displays a set of text or image hyperlinks that enable the users to easily navigate a Web site.
