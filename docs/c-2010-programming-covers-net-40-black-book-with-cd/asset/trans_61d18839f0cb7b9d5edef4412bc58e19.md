

**表 16.36：ConnectionsZone 类的显著属性**

| 属性 | 描述 |
| --- | --- |
| NewConnectionErrorMessage | 获取或设置在创建新连接时发生错误时在连接 UI 中显示的消息字符串。 |
| NoExistingConnectionInstructionText | 获取或设置当与 WebPart 控件关联的现有连接不存在时，连接 UI 主体中包含的文本。 |
| NoExistingConnectionTitle | 获取或设置当与 WebPart 控件关联的现有连接不存在时，连接 UI 的标题文本。 |
| ProvidersInstructionText | 获取或设置当连接已存在时，连接 UI 的提供程序部分中包含的说明性文本。 |
| ProvidersTitle | 获取或设置当连接已存在时，连接 UI 的提供程序部分上方的标题文本。 |
| SendText | 获取或设置连接 UI 中提供程序名称之前出现的文本。该提供程序将数据发送给使用者。 |
| SendToText | 获取或设置连接 UI 中在提供程序发送数据的使用者名称之前出现的文本。 |

> **注意**
>
> 所有 Web Parts 控件都位于 Default.aspx 页面的 `<form>` 元素内部。然而，有些 Web Parts 控件不能单独使用，需要与特定的控件配合使用。例如，LayoutEditorPart 或 BehaviorEditorPart 控件如果没有 `<form>` 元素中的 EditorZone 控件就无法使用。

现在你对 Login 和 Web Parts 控件有了良好的掌握，让我们继续进入下一节，即 Immediate Solutions，学习如何在你的 ASP.NET 4.0 应用程序中使用 Login 和 Web Parts。

## Immediate Solutions

### 使用 Login 和 LoginView 控件

你在本章的 In Depth 部分详细学习了 Login 和 LoginView 控件。现在，让我们执行以下步骤来实现这些控件：

- 创建一个名为 LoginandLoginViewControls 的网站（也在 CD 上提供）。

> **注意**
>
> 本章中的应用程序使用 New Web Site 对话框中的 Empty Web Site 模板创建。创建应用程序后，你需要向应用程序添加 Default.aspx 页面。

- 现在，打开 LoginandLoginViewControls 网站的 Default.aspx 文件，并用 Listing 16.1 所示的代码替换现有代码：

**Listing 16.1: Code of Default.aspx File**

```aspx
<%@ Page Language="C#" AutoEventWireup="true" CodeFile="Default.aspx.cs" Inherits="_Default" %>

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">

<html xmlns="http://www.w3.org/1999/xhtml">
<head runat="server">
<title>Login and LoginView Controls Example</title>
</head>
<body>
<form id="form1" runat="server">
<h1>C# 2010 Black Book</h1>
<br />
<asp:LoginView ID="LoginView1" runat="server">
<LoggedInTemplate>
<br />
<font color="navy">welcome!!! You have successfully logged in.</font>
</LoggedInTemplate>
<AnonymousTemplate>
<strong>You are not logged in. Please Login.<br /></strong>
<br />
<asp:Login ID="Login1" runat="server" BackColor="#FFE0C0" BorderColor="ControlText" BorderPadding="4" BorderStyle="Solid" BorderWidth="1px" Font-Names="Garamond" ForeColor="#333333">
<TitleTextStyle BackColor="Maroon" Font-Bold="True" Font-Size="0.9em" ForeColor="White" />
<LoginButtonStyle BackColor="White" BorderColor="#0000C0" BorderStyle="Solid" BorderWidth="1px" Font-Names="Verdana" ForeColor="#284E98" />
<InstructionTextStyle Font-Italic="True" ForeColor="Black" />
</asp:Login>
</AnonymousTemplate>
</asp:LoginView>
<br />&nbsp;
</form>
</body>
</html>
```
