void richTextBox_ContextMenuOpening(object sender, ContextMenuEventArgs e)
{
    RichTextBox rtb = sender as RichTextBox;
    if (rtb == null) return;
    ContextMenu contextMenu = rtb.ContextMenu;

## Graphics in Windows Forms Applications

In Windows Forms applications, you might need to create simple shapes and other graphical objects. In such a case, you can use the graphics elements of Windows Forms which help to create a visually appealing application. In Windows Forms applications, GDI+ is used to create graphics, draw text, and manipulate graphical images. GDI is responsible for the integration of graphics in Windows Forms, and GDI+ is an advanced implementation of GDI. The basic use of GDI+ is to render graphical images on a form.

You can also use GDI+ on Web forms by displaying graphical images with the help of the Image Web server control. Note that you cannot use GDI+ directly on Web forms. In this section, you learn about:

### GDI+ Managed Class Interface

The core of the GDI+ functionality is the Graphics class. GDI+ consists of a set of base classes that are available to control the custom drawing on the screen. It is exposed through a set of classes deployed as managed code. This set of classes is collectively called the GDI+ managed class interface.

The GDI+ managed class interface is a part of .NET Framework. It provides an environment for building, deploying, and running XML Web services and other applications. It allows access to the underlying operating system functionality that provides 2-D vector graphics, imaging, and typography. The GDI+ managed class interface contains about 60 classes, 50 enumerations, and 8 structures. You can group the classes in the namespaces that make up the GDI+ managed class interface.
