# Using the RadioButtonList Control

When you add a RadioButtonList control on a Web page (Default.aspx), it adds the following code to the source code of the Web page:

```
<asp: RadioButtonList runat="server"></asp: RadioButtonList>
```

Let’s create a Web application named RadioButtonListControl (also available on the CD-ROM). In this example, we have placed one RadioButtonList control on the Web page showing book titles. The item attached to the RadioButtonList control appears in the Label control whenever you select it. In this application, we have retrieved data in the RadioButtonList control from the CategoryName field of the Categories table of the Northwind database.
