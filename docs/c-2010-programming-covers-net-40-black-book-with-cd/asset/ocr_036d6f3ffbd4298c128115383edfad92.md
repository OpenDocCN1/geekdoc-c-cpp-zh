# Inserting Nodes

You can also insert new element nodes in an XML document. Let’s create an application, named ShowingNodes (also available on the CD) to insert nodes in an XML document.

Perform the following steps to create the ShowingNodes:

+   1. Create a Windows Forms application, named ShowingNodes.
+   2. Add the authors.xml file in the bin\Debug folder of the ShowingNodes application.
+   3. Add the following namespace in the Form1.cs file:
+      using System.Xml;
+   4. Open the designer of the Form1 form and drag a list box and a button from the Toolbox to it. Set the Text property of the button1 to Show Elements.
+   5. Double-click the button1 and add the following code snippet:

```
private void button1_Click(object sender, EventArgs e)
{
listBox1.Items.Clear();
XmlDocument xd = new XmlDocument();
xd.Load("authors.xml");
XmlElement newAuthor = xd.CreateElement("authors");
newAuthor.SetAttribute("au_id", "712-45-1867");
XmlElement lname = xd.CreateElement("au_lname");
lname.InnerText = "del Castillo";
newAuthor.AppendChild(lname);
XmlElement fname = xd.CreateElement("au_fname");
fname.InnerText = "Innes";
newAuthor.AppendChild(fname);
xd.DocumentElement.AppendChild(newAuthor);
XmlTextWriter tr = new XmlTextWriter("newAuthors.xml", null);
tr.Formatting = Formatting.Indented;
xd.WriteContentTo(tr);
tr.Close();
XmlNodeList nl = xd.GetElementsByTagName("au_lname");
foreach (XmlNode node in nl)
listBox1.Items.Add(node.InnerText);
}
```

In the preceding code snippet, we have first made the list box blank. After that, we have created an object of the XmlDocument class and then loaded the XML file, authors.xml, in the XmlDocument object from the disk. Now, create a new authors element by calling the CreateElement() method of XmlDocument object, add data to this element, and finally append the authors element to the XmlDocument object.
