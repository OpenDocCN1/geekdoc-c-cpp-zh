

# 在 Windows 服务中托管 WCF 服务

在 Windows 服务中托管 WCF 服务需要在服务器上将托管 WCF 服务的应用程序域（AppDomain）注册为受管理的 Windows 服务，以便服务控制管理器（SCM）控制 WCF 服务的进程生命周期。现在，让我们执行以下步骤在 Windows 服务中托管 WCF 服务：

- 1. 创建一个名为 WinServiceHost 的控制台应用程序（也在 CD ROM 上提供）。
- 2. 右键单击 WinServiceHost 应用程序的名称并从上下文菜单中选择 Add→New Item。Add New Item 对话框出现。
- 3. 选择 WCF Service 模板并在 Add New Item 对话框的 Name 文本框中输入服务的名称为 TimeService。
- 4. 单击 Add 按钮创建应用程序。TimeService.cs、ITimeService.cs 和 App.config 文件被添加到 WinServiceHost 应用程序中。此外，对 System.ServiceModel 和 System.Runtime.Serialization 类的引用也被包含在应用程序中。
- 5. 打开 ITimeService.cs 文件并在 ITimeService 接口中添加以下代码片段：
  [OperationContract]
  string GetCurrentTime();
- 6. 打开 TimeService.cs 文件并在 TimeService 类中添加以下代码片段：
  public string GetCurrentTime()
  {
      string CurrentTime = DateTime.Now.Hour + ":" + DateTime.Now.Minute + ":" + DateTime.Now.Second;
      return CurrentTime;
  }
- 7. 再次打开 Add New Item 对话框并在 WinServiceHost 应用程序中添加 Windows Service 模板。在我们的例子中，Windows 服务的名称为 Service1.cs，如图 19.24 所示：

8. 打开 Service1.cs 文件的代码视图（包含 Windows 服务功能）并添加代码，如 Listing 19.8 所示，以在 Windows 服务 Service1 中托管 WCF 服务（TimeService）：

## Listing 19.8: Showing the Code for the Service1.cs File

```
using System;
using System.Collections.Generic;
using System.ComponentModel;
using System.Data;
using System.Diagnostics;
using System.Linq;
using System.ServiceProcess;
using System.Text;
using System.ServiceModel;

namespace WinServiceHost
{
    public partial class Service1 : ServiceBase
    {
        public ServiceHost myHost;

        public Service1()
        {
            InitializeComponent();
            myHost = new ServiceHost(typeof(TimeService));
        }

        protected override void OnStart(string[] args)
        {
            myHost.Open();
        }

        protected override void OnStop()
        {
            myHost.Close();
        }
    }
}
```

在 Listing 19.8 中，引用 System.ServiceModel 命名空间的 using 指令包含在 Service1.cs 文件中。该命名空间包含 ServiceHost 类，负责在 Windows 服务 Service1 中托管 WCF 服务（TimeService）。在创建 ServiceHost 类的对象（myHost）时，该类的构造函数以 WCF 服务的类型作为其参数。通过在 OnStart() 方法中调用 Open() 方法打开 myHost 对象。同样，通过在 Windows 服务的 OnStop() 方法中调用 Close() 方法关闭 myHost 对象。这意味着当 Windows 服务启动时，WCF 服务打开；当 Windows 服务停止时，WCF 服务也停止。

要使用 Windows 服务，您需要在计算机上安装它。为此，您需要在应用程序中先添加安装程序。

# 在 IIS 中托管 WCF 服务

当 WCF 服务托管在 IIS 中时，它会自动集成到 ASP.NET 中。这使您能够使用 ASP.NET 的固有功能，例如进程回收、空闲时间管理、健康监控和激活。让我们执行以下步骤在 IIS 中托管 WCF 服务：

1. 使用 WCF Service Application 项目模板创建一个名为 SimpleInterestService 的 WCF 服务应用程序（也在 CD 上提供）。在创建应用程序时，IService1.cs 和 Service1.svc.cs 文件会自动创建
2. 打开 IService1.cs 文件并在 IService1 接口中添加以下代码片段以声明服务契约：

```
[OperationContract]
double CalSimpleInterest(double p, double r, double t);
```

3. 打开 Service1.svc.cs 文件并在 Service1 类中添加以下代码片段以实现服务契约：

```
public double CalSimpleInterest(double p, double r, double t)
{
    double sInterest = (p * r * t) / 100;
    return sInterest;
}
```

4. 通过从菜单栏中选择 Project→SimpleInterestService Properties 选项来在 IIS 中托管此 WCF 服务，以显示 SimpleInterestService 项目的属性页。
5. 在属性页中选择 Web 选项卡以查看项目的 Web 相关属性，如图 19.30 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1025_0.png)

Figure 19.30: Specifying the Option to Host the WCF Service in IIS

6. 在 Servers 部分中选择 Use Local IIS Web server 单选按钮以在 IIS 上托管 WCF 服务。
7. 单击 Create Virtual Directory 按钮（图 19.30）为 WCF 服务创建虚拟目录。成功创建虚拟目录后会出现消息框，如图 19.31 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1025_1.png)

Figure 19.31: Showing a Message Box Notifying the Successful Creation of a Virtual Directory

8. 单击消息框的 OK 按钮并关闭 SimpleInterestService 属性页。
