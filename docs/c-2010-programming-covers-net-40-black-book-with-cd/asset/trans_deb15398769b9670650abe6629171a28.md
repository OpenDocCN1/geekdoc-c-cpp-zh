## AccessDataSource 控件

AccessDataSource 控件是一个数据源控件，允许 Web 服务器控件访问 Microsoft Access 数据库。此控件不支持连接字符串，但此控件的 DataFile 属性允许您指定要用于访问数据的 Access 文件（.mdb 文件）。当您向 ASP.NET 页面添加 AccessDataSource 控件时，以下代码行会出现在页面的源视图中：

```
<asp:AccessDataSource ID="AccessDataSource1" runat="server"></asp:AccessDataSource>
```

AccessDataSource 控件不允许您提供用户名和密码来访问数据。如果您需要使用受密码保护的 Access 数据库，请选择 SqlDataSource 控件来访问数据库。AccessDataSource 控件的继承层次结构如下：

System.Object
  System.Web.UI.Control
    System.Web.UI.DataSourceControl
      System.Web.UI.WebControls.SqlDataSource
        System.Web.UI.WebControls.AccessDataSource
