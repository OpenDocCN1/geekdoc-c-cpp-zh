.NET also provides several general-purpose collection classes that you can use to make collections of any data type. Let’s learn about these classes in detail.

## Collection Classes in .NET

.NET Framework provides you a variety of collection classes, which are available in the System.Collections namespace, to serve various purposes, such as allocating memory dynamically to elements and accessing a list of items on the basis of an index. These classes basically create collections of objects of the Object class, which is the base class for all the data types in C#. Some of the most useful collection classes defined in the System.Collections namespace are as follows:

- ArrayList
- Hashtable
- SortedList
- Stack
- Queue
- BitArray

Now, let’s discuss these collection classes in detail.

## The ArrayList Class

While using arrays, the main problem that arises is that their size always remains fixed by the number that you specify when declaring the array. In addition, you cannot add items in the middle of an array. The solution to these problems is the use of the ArrayList class. Similar to an array, the ArrayList class allows you to store and manage multiple elements. However, with the ArrayList class, you can add and remove items from a list of array items from a specified position, and then the array list automatically resizes itself accordingly. The ArrayList class also allows you to dynamically allocate the memory to the array list as well as add, search, and sort items of the list. An array list can also store items of different data types.

> NOTE
> An ArrayList object accepts null as a valid value and allows duplicate elements.

## The Hashtable Class

The Hashtable class is similar to the ArrayList class but it allows you to access items by a key. Each item in a Hashtable object has a key/value pair. The key is used to access the items in a collection and each key must be unique; whereas, the value is the value stored in an array. Typically, the keys are short strings or integers. Using the Hashtable class, you can add and retrieve items to and from a collection.

**NOTE**  
A key cannot be null, but a value can be.

The class hierarchy of the Hashtable class is given as follows:

```

    System.Collections.Hashtable
```
