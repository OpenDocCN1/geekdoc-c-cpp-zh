## 探索类和对象

类允许你控制可应用于给定数据集的所有功能以及如何访问数据。类还使你能够扩展运行时环境，并允许开发人员重用运行时环境的现有功能。假设你需要在程序中创建一个名为 student 的类对象。为此，你首先需要创建一个包含任何学生的所有功能或行为的 Student 类，然后使用该类根据需要创建对象。

在本节中，你将探讨以下内容：

- 类的语法
- 使用方法作为类成员
- 访问修饰符
- 使用对象访问类成员
- 构造函数和析构函数
- 静态类和静态类成员、属性和索引器

让我们首先从类的语法开始。

### 类的语法

类结构的基本语法如下面的代码片段所示：

```
class <className>
{
    <access-modifier> [static] <return-type> MethodName(<signature>);
    <access-modifier> [static] <variable type> variableName;
}
```

声明对象的基本语法如下面的代码片段所示：

```
<className> <ObjectName> = new <className>();
```

你还可以在应用程序中声明分部类。分部类是一种允许你在两个或多个源文件中指定类、结构或接口定义的类。所有包含类定义各部分的源文件在应用程序编译时合并。当开发人员从事大型项目时，你可能需要分部类。分部类将类分布到多个独立文件中，允许开发人员同时处理该类。使用 partial 关键字，你可以将类声明为分部类，如下面的代码片段所示：

```
public partial class Student
{
    public void avgMarks() { }
}
public partial class Student
{
    public void calRank() { }
}
```

partial 关键字指定类、结构或接口的其他部分在命名空间内定义。

### 方法作为类成员

现在你已经熟悉了使用类的重要性，让我们继续讨论类的成员——类方法和类变量。类成员是在类中声明的元素。下面的代码片段显示了声明类成员（方法和变量）的语法：

```
class Square
{
    int side;
    public int area()
    {
        return ( side * side);
    }
}
```

在前面的代码片段中，Square 类有一个名为 side 的变量和一个名为 area 的方法。side 变量为正方形的边长取整数值；而 area 方法用于计算正方形的面积。

构造函数和析构函数是每个类中都存在的特殊方法。每当你访问类时，构造函数方法会初始化所有类成员，而当不再需要对象时，析构函数方法会销毁它们。每个类都有自己构造函数和析构函数，它们在类的实例被创建或销毁时自动调用。

**注释**

类变量也称为数据成员，类方法也称为成员函数或方法。

你可以使用参数将值传递给方法。传递参数的语法如下面的代码片段所示：

```
[modifiers] DataType ParameterName
```

C# 2010 具有以下类型的形参：

- 值参数——允许方法通过方法调用中给出的参数为值参数赋值。这种赋值仅影响局部存储位置。它对方法调用中分配的实际参数没有影响。此外，对参数所做的更改是方法局部的；它们不会传递给调用方法。值参数是默认参数。如果你在声明参数时没有任何修饰符，则它被视为值参数。值参数也称为内参数。

- 引用参数——表示相同的存储位置，而不是为方法调用中作为参数给出的变量创建新的存储位置。用 ref 修饰符声明的参数是引用参数。

- 输出参数——表示相同的存储位置，而不是为方法调用中作为参数给出的变量创建新的存储位置。用 out 修饰符声明的参数是输出参数。方法的每个输出参数都必须在方法返回输出之前赋值。输出参数通常用于产生多个返回值的方法。

在定义和调用方法时使用 out 修饰符，如下面的代码片段所示：

```
class UsingOut
{
    static void FirstMethod(out int x) // out modifier in method definition
    {
        x = 81;
    }
    static void Main()
    {
        int y; // No prior initialization
        FirstMethod(out y); // out modifier in method calling
        // value of y is 81
    }
}
```

在前面的代码片段中，在方法定义（static void FirstMethod(out int x)）和方法调用（FirstMethod(out y)）中都指定了 out 修饰符。

在方法定义和方法调用中使用 ref 修饰符，如下面的代码片段所示：

```
class UsingRef
{
    static void SecondMethod(ref int x) // ref modifier in method definition
    {
        x++;
    }
    static void Main()
    {
        int y = 81;        // must be initialized
        SecondMethod(ref y);    // ref modifier in method calling
```
