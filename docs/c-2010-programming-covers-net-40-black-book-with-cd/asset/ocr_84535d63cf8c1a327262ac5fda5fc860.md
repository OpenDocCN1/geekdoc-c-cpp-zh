# Figure 1.66: Displaying the WPF Designer

The Designer window allows you to make changes in the XAML file of your application. In other words, the changes made in the Designer window are automatically reflected in the XAML file.

The WPF Designer window provides the following features:

+   - Zoom Control – Controls the size of the design surface. You can zoom from 10% to 20%.
+   - Fit In View – Specifies the size of the design surface of an available screen in the Design view.
+   - Grid Rails – Manage rows and columns in a Grid control. This feature allows you to create and delete the columns and rows as well as adjusting their relative widths and heights.
+   - Gridlines – Control the height and width of the Grid’s columns and rows by using gridlines.
+   - Gridline Indicators: Indicates the heights or widths of the nearby columns or rows.
+   - Move Handle – Helps in dragging the controls to the desired place on the designer.
+   - Resize Handles – Resize the selected control by clicking and dragging a resize handle.
+   - Margin Lines – Specify the space between the edge of the control and the edge of its container. You can set the margins of the control by clicking its margin lines.
+   - Margin Stubs – Set the margin distance of the selected control to the corresponding edge of the container by clicking the margin stub.
+   - Snaplines – Helps in the alignment of controls relatively.

# The Web Forms Designer

The Web Forms designer is a designer that enables you to make changes in the controls, markup, and script of the Web Forms. This designer helps in creating ASP.NET Web applications with different views of your pages and provides tools, such as the Toolbox and the Properties window for creating and editing the page elements.

Visual Studio 2010 has three views: Design, Split. and Source views in the Web Forms Designer. These views are described as follows:

+   - Design view – Displays Web pages, master pages, HTML pages, and user controls using the What You See Is What You Get – WYSIWYG view. This view allows you to add controls in the Web Form and set their properties.
