
## Using the PasswordBox Control

The PasswordBox control is a special kind of Textbox control, which displays the text entered by the user in an encrypted format. Let’s add a PasswordBox control to a WPF application through the XAML code. Create a WPF application named PasswordBoxControl (available in the CD) and add the code, shown in Listing 10.10, to the MainWindow.xaml file:

### Listing 10.10: Showing the Code to Implement the PasswordBox Control

```
<Window x:Class="PasswordBoxControl.MainWindow"
xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
Title="MainWindow" Height="350" Width="525">
<Grid>
<Border Background="PeachPuff" CornerRadius="25"/>
<Label Height="28" HorizontalAlignment="Left" Margin="10,10,0,0" Name="label1" VerticalAlignment="Top" Width="120">Enter your Name</Label>
<Label Height="28" HorizontalAlignment="Left" Margin="10,48,0,0" Name="label2" VerticalAlignment="Top" Width="120">Enter Password</Label>
<TextBox Height="23" HorizontalAlignment="Right" Margin="0,12,14,0" Name="textBox1" VerticalAlignment="Top" Width="120" />
<PasswordBox HorizontalAlignment="Right" Margin="0,53,14,0" Name="passwordBox1" Width="120" Height="23" VerticalAlignment="Top" MaxLength="10" PasswordChar="*"/>
<Button Height="23" Margin="84,0,119,103" Name="button1" VerticalAlignment="Bottom">Submit</Button>
</Grid>
</Window>
```

In Listing 10.10, a PasswordBox control is added to the window. You can set the maximum number of characters to enter in the PasswordBox control by using the MaxLength property of the control. You can change the characters that appear in the PasswordBox control by setting the PasswordChar property. By default, a black dot appears in the box (*); however, you can also change this setting. In our case, the character of the PasswordBox control is set to an asterisk (*). Now, run the application by pressing the F5 key.

## Creating a Scrollable Area in a WPF Application

In WPF, you can create a scrollable area by using the ScrollViewer and ScrollBar controls. These controls are mainly used to enable scrolling of the content in the window. You can add a ScrollViewer control in a WPF application when your content is more than the size of the window. The ScrollViewer control allows you to scroll through the entire content of the window. You can create a vertical scrolling area by setting the VerticalScrollBarVisibility property and a horizontal scrolling area by setting the HorizontalScrollBarVisibility property. Let’s add a ScrollViewer control to a WPF application through the XAML code. Create a WPF application named ScrollableArea (available in the CD) and add the code, shown in Listing 10.11, to MainWindow.xaml file:

### Listing 10.11: Showing the Code to Implement the ScrollViewer Control

```
<Window x:Class="ScrollableArea.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="350" Width="525">
    <Grid>
        <ScrollViewer HorizontalScrollBarVisibility="Auto"
                      VerticalScrollBarVisibility="Auto">
            <Rectangle Width="400" Height="400" Fill="Red"/>
        </ScrollViewer>
    </Grid>
</Window>
```

In Listing 10.11, a Rectangle control is added to the WPF application, the height and width of which is more than the size of the window. You can therefore add a ScrollViewer control to scroll to the area that is not visible. You can run the application by pressing the F5 key.
