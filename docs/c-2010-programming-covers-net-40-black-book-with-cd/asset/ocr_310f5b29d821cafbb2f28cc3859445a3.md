# Building and Debugging the Projects

In Visual Studio, when you create a new project or website, it automatically becomes a part of a solution. A solution is a top hierarchy container of one or more projects. Projects are the containers that hold source files, folders, and other project-related items, such as references, forms, classes, modules, and components. When you build a solution, it is the project that undergoes the build operation. In case, a solution has multiple projects, you can build the projects either independently or collectively using the Build menu.

The Build menu contains the following options:

+   - Build Solution – Compiles only those project files that have been modified since last created

+   - Rebuild Solution – Recompiles all the project files stored in the solution
