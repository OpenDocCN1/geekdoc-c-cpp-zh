In this example, you explore the capabilities of C# reflection by creating an application that can search a given assembly for a given method name. Any class that contains a method of this name is printed on the console screen for the users to view. It is much more convenient to search for full texts in this application than search for the same within the source code for the assembly. In many cases, you do not have access to the source code for the assembly. The CLR is a good example of an assembly in which you have only binary access. The VerifyClassMethod.cs example in the CD shows the application source code.
