## 使用嵌套 for 循环

循环嵌套是指在一个循环内部创建另一个循环，例如在一个 for 循环内部再嵌套一个 for 循环。让我们创建一个名为 MyNestedForLoop 的控制台应用程序（也在 CD 上提供），它展示了使用多维数组的嵌套 for 循环的使用。清单 3.9 显示了 MyNestedForLoop 应用程序的代码：

清单 3.9：显示 MyNestedForLoop 应用程序的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace MyNestedForLoop
{
    class Program
    {
        static void Main(string[] args)
        {
            int[,] firstMatrix = new int[2, 2];
            int[,] secondMatrix = new int[2, 2];
            int[,] sumMatrix = new int[2, 2];
            int i, j;
            Console.WriteLine("Enter the Elements of the First 2X2 Matrix:");
            for (i = 0; i < 2; i++)
            {
                for (j = 0; j < 2; j++)
                {
                    firstMatrix[i, j] = int.Parse(Console.ReadLine());
                }
            }
            Console.WriteLine("Enter the Elements of the Second 2X2 Matrix:");
            for (i = 0; i < 2; i++)
            {
                for (j = 0; j < 2; j++)
                {
                    secondMatrix[i, j] = int.Parse(Console.ReadLine());
                }
            }
            Console.WriteLine("The Sum of the Matrices is:");
            for (i = 0; i < 2; i++)
            {
                for (j = 0; j < 2; j++)
                {
                    sumMatrix[i, j] = firstMatrix[i, j] + secondMatrix[i, j];
                    Console.Write(+sumMatrix[i, j] + " ");
                }
                Console.WriteLine("");
            }
            Console.Write("\nPress ENTER to quit...");
            Console.ReadLine();
        }
    }
}
```

在清单 3.9 中，我们定义了三个多维数组，名称为 firstMatrix 和 secondMatrix。我们使用了两个 for 循环，外层和内层，来读取 firstMatrix 数组的元素，以及两个 for 循环来读取 secondMatrix 数组的元素。外层 for 循环读取行的元素，内层 for 循环读取列的元素。

## 创建无限循环

无限循环是一种无法隐式终止的循环。无限循环可用于您希望语句或一组语句被执行无限次的情况。在无限循环中，您无需指定终止条件。让我们创建一个名为 MyInfiniteLoop 的控制台应用程序（也在 CD 上提供），它展示了如何创建无限循环。清单 3.10 显示了 MyInfiniteLoop 应用程序的代码：

清单 3.10：显示 MyInfiniteLoop 应用程序的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyInfiniteLoop
{
    class Program
    {
        static void Main(string[] args)
        {
            int counter;
            for (counter = 0; ; counter++)
            {
                Console.WriteLine("I Stuck in a Loop");
            }
        }
    }
}
```

在清单 3.10 中，我们没有在 for 循环中指定任何条件；因此，它将执行无限多次。
