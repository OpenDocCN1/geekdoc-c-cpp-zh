## The MenuItem Control

The MenuItem control in WPF represents the selectable menu items contained in the Menu control. The menu classes, Menu and ContextMenu, include the items of the MenuItem control. The content properties of the MenuItem control are Items and ItemsSource. The header property of the MenuItem control is Header. The MenuItem control can have submenus, which are made up of objects within the ItemsCollection property of the MenuItem control. The default value of the HorizontalAlignment property of a MenuItem control is set to Stretch.

## The ToolBar Control

The ToolBar control in WPF is a container for a group of controls, usually Button and Separator elements. You can place the ToolBar control inside a ToolBarTray control, which arranges the ToolBar controls according to the available space. The ToolBar control usually contains buttons to invoke commands. You can use the Band and BandIndex properties to position the ToolBar control in the ToolBarTray control. The ToolBar control uses the ToolBarPanel property to determine the layout of items on the ToolBar control and the ToolBarOverflowPanel property to determine the layout of items that do not fit on the ToolBar control.

## The Border Control

The Border control in WPF is responsible for drawing a border, background, or both around a control. The Border control can have only one child element, which implies that at a time the Border control can apply a border or background to only a single element. You can display multiple child elements with the Border control by adding the Panel element within the parent Border control.
