## Sharing Data Across Web Services

Suppose you want to create a Web application that needs to access two Web services, TypeSharingWebService1 and TypeSharingWebService2, to execute the business logic. The TypeSharingWebService1 Web service obtains the first name, middle name, and last name of an employee who uses the Web application, and the TypeSharingWebService2 Web service retrieves and updates employee details by adding the employee ID and designation, and displays it on the Web application. As the operations of the TypeSharingWebService2 Web service depend on the output of the TypeSharingWebService1 Web service, both the Web services need to share data of similar data type.

Let’s create the two Web services, named TypeSharingWebService1 and TypeSharingWebService2, to understand how data can be shared among Web services. We also create a Web application that can access both the Web services to perform its tasks.
