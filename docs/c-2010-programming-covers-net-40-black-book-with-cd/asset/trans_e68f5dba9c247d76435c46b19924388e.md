## 深入探讨

通用语言运行时（CLR）为 .NET Framework 代码提供执行环境。在 Visual Studio 中，在 CLR 上运行的代码称为托管代码。CLR 提供执行程序所需的各种函数和服务。这些服务的示例包括即时（JIT）编译、内存管理、线程管理、类型安全和异常处理。此 CLR 运行时功能也集成在 SQL Server 2008 中，这为开发人员提供了更大的灵活性来开发代码。SQL Server 2008 中集成的 CLR 功能允许您使用 C# 等托管语言在 .NET Framework 中创建 CLR 对象，例如存储过程和触发器，并通过在 SQL Server 2008 中创建程序集来在外部使用这些对象。您可以通过导入 Microsoft.SqlServer.Server 命名空间在 .NET Framework 中创建 CLR 对象。

在本章中，您将了解 CLR 在 SQL Server 2008 中的集成。本章首先介绍 SQL Server 2008 中的 CLR 主机。接下来，您将了解 Microsoft.SqlServer.Server 命名空间以及该命名空间中可用的类、接口和枚举。您还将了解各种 CLR 对象，例如存储过程、触发器、聚合函数、用户定义函数（UDF）和用户定义类型（UDT）。然后，您将了解如何在 SQL Server 2008 中处理可扩展标记语言（XML）数据。在本章的即时解决方案部分，您将学习如何在 .NET Framework 中创建和使用不同的 CLR 对象及其在结构化查询语言（SQL）中的使用。

让我们从 .NET 运行时在 SQL 中的托管开始。

### .NET 运行时托管

SQL Server 2008 提供了一个 CLR 集成功能，根据该功能，它可以托管 .NET Framework 4.0 的 CLR。CLR 集成功能使您能够以托管代码创建存储过程、触发器、UDF、UDT 和用户定义聚合，这提供了内存管理、线程同步和管理、异常处理、类型安全和调试服务的优势。

默认情况下，SQL Server 2008 中的 CLR 集成功能处于禁用状态，您可以使用 sp_configure 存储过程的 clr enabled 选项启用它。使用以下查询在 SQL Server Management Studio 中启用 CLR 集成功能：

```
sp_configure 'clr enabled', 1
GO
RECONFIGURE
GO
```

# NOTE

要禁用 CLR 集成功能，将 clr enabled 选项设置为 0。

SQL Server 2008 作为 CLR 的主机，为执行代码定义了一些权限级别。这些权限级别如下所示：

- SAFE – 仅允许本地数据访问和内部计算。SAFE 权限是最严格的权限，不允许访问外部系统资源，例如文件、网络、环境变量或注册表。以 SAFE 权限执行代码的程序集无法访问这些外部系统资源。
- EXTERNAL_ACCESS – 允许访问外部系统资源，例如文件、网络、环境变量或注册表。
- UNSAFE – 允许从 SQL Server 无限制地访问内部和外部资源。以 UNSAFE 权限执行的程序集执行的代码也可以是未托管代码。

您可以通过在服务器中创建程序集来使用 SQL Server 2008 中的程序集。使用以下命令在 Management SQL Server Studio 中创建程序集：

```
CREATE ASSEMBLY myassem FROM 'D:\black Books\C# 2010\Chapter 23'
WITH PERMISSION SET=SAFE
```

在前面的命令中，使用指定的名称、路径和权限创建了一个程序集。在 Visual Studio 2010 中，您可以使用当前项目的属性中的 Database 选项卡设置程序集的权限，如图 23.1 所示：

接下来，让我们学习存储过程。

### 探索存储过程

存储过程是存储在数据库中的预编译 SQL 命令集。它只编译一次，然后被客户端应用程序重复使用，而无需将其发送到数据库服务器。在 SQL Server 2008 中创建存储过程的示例在列表 23.1 中给出：

#### 列表 23.1：在 SQL Server 2008 中创建存储过程

```
CREATE PROCEDURE GetProductDetails
@ProductID int
AS
SELECT ProductID,ProductName,QuantityPerUnit,UnitPrice,UnitsInStock FROM Products WHERE ProductID=@ProductID
```

在列表 23.1 中，使用一个整数类型的参数创建了一个存储过程 GetProductDetails。此存储过程根据特定的 ProductID 从 Products 表中提供项目的详细信息，包括 ProductID、ProductName、QuantityPerUnit、UnitPrice 和 UnitsInStock。您可以使用以下命令执行 GetProductDetails 存储过程：

```
EXECUTE GetProductDetails 3
```

> NOTE
> 您可以通过提供除 3 之外的其他产品 ID，例如 2 和 4，来执行 GetProductDetails 存储过程。
