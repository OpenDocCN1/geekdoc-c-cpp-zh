
## The Pen Class

The Pen class defines an object to draw lines and curves in Windows Forms. Pens are represented by the System.Drawing.Pen class contained in the System.Drawing namespace. The Pen class draws a line of specified width and style. You need to specify how thick the line should be and how to fill the area inside a wide line. For example, you can use the DashStyle property to draw several kinds of dashed lines. You can fill the area drawn by the Pen class with a variety of fill styles, for instance using a solid color or a texture. The inheritance hierarchy of the Pen class is as follows:

```
System.Object
  System.MarshalByRefObject
    System.Drawing.Pen
```

## The Brush Class

The Brush class is used to fill the interiors of graphical shapes, such as rectangles, ellipses, polygons, and paths. You can draw the outline of the shape using the Pen class and fill the shape using the Brush class. The different types of brushes available in Windows Forms are SolidBrush, HatchBrush, TextureBrush, LinearGradientBrush, and PathGradientBrush. All these brushes inherit from the System.Drawing.Brush class. The descriptions of these brushes are listed in Table 12.6:

**Table 12.6: Description of the Brushes**

| Brush | Description |
| --- | --- |
| SolidBrush | Fills the shape with one solid color |
| HatchBrush | Fills the shape with a hatch style |
| TextureBrush | Fills the shape with a pattern stored in a bitmap |
| LinearGradientBrush | Fills the shape with color that changes gradually as you move across the shape |
| PathGradientBrush | Fills the shape with color which changes as you move from the center of a shape towards the edge |

The inheritance hierarchy of the Brush class is as follows:

```
System.Object
  System.MarshalByRefObject
    System.Drawing.Brush
```

## Color Structure in Windows Forms

> **NOTE**  
> You must note that when you inherit from the Brush class, you must override the Clone() method.

The colors in Windows Forms are based on four components. These components are the three primary colors red, green, and blue; and the alpha component, which is used to define the transparency of the color. The Color structure represents the colors in Windows Forms. It is contained in the System.Drawing namespace. You can create a custom color by using the FromArgb method and a Color instance through a static property. The Color structure contains 140 named colors, which are derived from the static properties. You can create a Color value initialized to one of the named colors, as shown in the following code snippet:

```
Color newColor = Color.Red;
```
