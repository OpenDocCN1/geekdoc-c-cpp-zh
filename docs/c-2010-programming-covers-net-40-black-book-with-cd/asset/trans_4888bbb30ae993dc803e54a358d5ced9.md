using System.Text;
namespace Arraysizeanddimension
{
    class Program
    {
        public static void PrintArray(int[] arr)
        {
            for (int i = 0; i < arr.Length; ++i)
                Console.WriteLine("OneDArray Row {0} = {1}", i, arr[i]);

        public static void PrintArrayRank(int[,] arr)
        {
            Console.WriteLine("PrintArrayRank: {0} dimensions", arr.Rank);

### 深入探讨

程序的流程定义了程序的执行路径。通常，程序是按顺序执行的。如果我们想改变程序的执行流程，可以通过使用控制流语句来实现。我们可以在以下条件下使用控制流语句来改变程序的执行路径：

- 在满足特定条件时执行特定代码块
- 在不满足特定条件时执行特定代码块
- 基于特定值执行特定代码块
- 只要满足特定条件，就重复执行特定代码块。
- 将程序控制从一个代码块转移到另一个代码块

控制流语句可以根据您的要求和需要改变程序流程。然而，有时可能会发生，尽管您的程序在逻辑上是正确的并且已成功编译，但它并不会根据用户提供的输入显示输出并突然终止。这种情况可能是由于程序中的异常引起的。异常是在程序执行期间发生的事件，它会破坏程序指令的正常流程。try 语句检查是否发生了异常。

在本章中，您将学习不同类型的控制流语句，例如选择语句、迭代语句和跳转语句。您还将学习异常处理。最后，您将学习 checked 和 unchecked 语句，它们用于检查内存溢出异常。

让我们开始学习控制流语句。

### 控制流语句

有时，在编程时，我们需要改变程序控制的流程。控制流语句用于改变程序执行的流程。在 C# 2010 中，控制流语句分为三类，分别是：

- **选择语句** — 仅当满足某个条件或一组条件时才执行代码块
- **迭代语句或循环** — 只要满足某个条件就执行特定代码块
- **跳转语句** — 将程序控制从一个代码块转移到另一个代码块

让我们逐一详细讨论这些控制流语句。

### 选择语句

选择语句是当满足某个条件时导致程序流程发生变化的语句。条件是一个布尔表达式，定义在选择语句的括号内。在选择语句内部代码块执行之前会检查此条件。C# 支持两种类型的选择语句：

- **if 语句** — 允许您测试某个条件是否得到满足。如果条件得到满足，程序控制将被转移到 if 语句内部的代码块；否则，程序控制将被转移到另一个代码块。
- **switch 语句** — 允许您将表达式与不同的值进行比较。当表达式与某个特定值匹配时，程序控制将被转移到其对应的代码块。

让我们详细讨论这些语句。
