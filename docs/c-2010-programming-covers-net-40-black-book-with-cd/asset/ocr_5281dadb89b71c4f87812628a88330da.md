# Content Controls

Content controls are designed to contain a single nested element. These controls help you to add content to a control. Examples of content controls include Button, Label, RadioButton, CheckBox, ListBoxItem, StatusBarItem, ScrollViewer, ToolTip, ContentControl, Window, Frame, NavigationWindow, and UserControl.

Table 10.16 gives a brief description of content controls:

Table 10.16: Showing the Content Controls

| Control | Description |
|---|---|
| Button | Responds to user input from the mouse or keyboard |
| Label | Represents a text label for a control |
| RadioButton | Represents a button that can be checked but not cleared until you select another RadioButton control |
| CheckBox | Represents a control that the user can select and clear |
| ListBoxItem | Represents a selectable item in a ListBox control |
| StatusBarItem | Represents an item in a StatusBar control |
| ScrollViewer | Represents a scrollable area on the Window control |
| ToolTip | Represents a control that creates a pop-up window, which displays information of a control |
| ContentControl | Represents a control with minimum content |
| Window | Provides the ability to create, configure, show, and manage the lifetime of Windows and dialog boxes |
| Frame | Represents a control that supports navigation |
| NavigationWindow | Represents a window that supports content navigation |
| UserControl | Provides a simple way to create a control |

Let’s now look at these content controls one by one in detail.

# The Button Control

The Button control of WPF is similar to the Button control used in Windows Forms. It is a basic user interface (UI) component, which raises the ButtonBase.Click event when a user clicks on it. You can also insert text or images in a Button control.
