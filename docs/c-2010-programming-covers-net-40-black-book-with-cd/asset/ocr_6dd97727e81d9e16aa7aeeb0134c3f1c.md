+   5. Type the following command to compile the Class2.cs file:

+   7. Type the following command in the Visual Studio Command Prompt (2010):
+   `al Class1.netmodule Class2.netmodule SimpleClient.netmodule /main:SimpleClient.SimpleClient.Main /out:MultiFileAssembly.exe /target:exe`

The multifile assembly technique is useful in cases where you have a lot of classes. When you have externally compiled modules, such as class1.netmodule, class2.netmodule, and SimpleClient.netmodule, the assembly load time is radically reduced as these modules are loaded only when they are needed. Therefore, the actual assembly’s size becomes very small.
