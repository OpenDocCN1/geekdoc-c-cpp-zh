# The BitArray Class

The BitArray class is used to manage an array of the binary representation using the values, 1 and 0, where 1 stands for True and 0 stands for False. A BitArray object is resizable, which is helpful in case if you do not know the number of bits in advance. You can access items from the BitArray collection class by using an integer index. Indexes used in this collection start from zero.

The class hierarchy of the BitArray class is given as follows:

```
System.Object
System.Collections.BitArray
```

Table 32.11 lists the important properties of the BitArray class:

| Table 32.11: Noteworthy Properties of the BitArray Class |
| Property | Description |
| Count | Retrieves the number of elements contained in the BitArray object |
| IsReadOnly | Retrieves a value specifying whether or not the BitArray object is read-only |
| IsSynchronized | Retrieves a value specifying whether or not the access to the BitArray object is synchronized |
| Item | Retrieves or sets the value of the bit at a specific position in the BitArray object |
| Length | Retrieves or sets the number of elements in the BitArray object |
| SyncRoot | Retrieves an object that can be used to synchronize access to the BitArray object |

Table 32.12 lists the important methods of the BitArray class:

| Table 32.12: Noteworthy Methods of the BitArray Class |
| Method | Description |
| And() | Performs the bitwise AND operation on the items in the current BitArray object against the corresponding items in the specified BitArray object. |
| Clone() | Creates a copy of the BitArray object. |
| CopyTo() | Copies the BitArray object items into a one-dimensional array at the specified index. |
| Get() | Retrieves the value of the bit at a specified index in the BitArray object. |
| GetEnumerator() | Returns an enumerator that iterates through the BitArray object. |
| Not() | Inverts all the bit values in the current BitArray object, so that elements set to true are changed to false, and vice-versa. |
| Or() | Performs the bitwise OR operation on the items in the current BitArray object against the corresponding items in the specified BitArray object. It returns true if one or both operands are true and returns false if both operands are false. |
| Set() | Sets the bit at a specified position in the BitArray object to the specified value. |
| SetAll() | Sets all bits in the BitArray object to the specified value. |
| Xor() | Performs the bitwise exclusive OR operation on the items in the current BitArray object against the corresponding items in the specified BitArray object. It returns true if one of the operand is true and returns false if both operands have the same Boolean value. |

> NOTE
> To perform the bitwise exclusive OR (Xor) operation, the length of both the BitArray objects should be the same.
