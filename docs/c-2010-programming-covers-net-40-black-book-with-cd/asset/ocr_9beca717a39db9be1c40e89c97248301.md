# Exploring the Microsoft.SqlServer.Server Namespace

The Microsoft.SqlServer.Server namespace provides various classes for the integration of CLR of .NET Framework 4.0 in SQL Server 2008. You can use these classes to create stored procedures, triggers, UDT, and UDF. Using the SqlContext class, you can identify whether current executing code is running in the SQL Server database engine process. The SqlContext class also provides the caller’s context when you use a stored procedure or function, or fire a trigger. Table 23.1 lists the classes provided by the Microsoft.SqlServer.Server namespace:

Table 23.1: Classes Provided by the Microsoft.SqlServer.Server Namespace
| Class | Description |
|---|---|
| InvalidUdtException | Throws in case the SQL Server detects an invalid UDT |
| SqlContext | Returns the caller’s context that is provided by the objects of the SqlPipe, SqlTriggerContext, and WindowsIdentity classes |
| SqlDataRecord | Returns a row of data along with its metadata |
| SqlFacetAttribute | Provides a UDT with additional information that can be used in Transact-SQL |
| SqlFunctionAttribute | Specifies a method definition of a user-defined aggregate and works as a function in SQL Server |
| SqlMetaData | Retrieves metadata information from SqlDataRecord objects |
| SqlMethodAttribute | Specifies the data access properties of a method or property of a UDT |
| SqlPipe | Returns the result to a caller by a stored procedure |
| SqlProcedureAttribute | Specifies a method definition in an assembly, which acts as a stored procedure in SQL Server |
