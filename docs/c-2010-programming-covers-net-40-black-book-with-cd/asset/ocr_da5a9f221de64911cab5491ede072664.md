# Using the TabControl Control

You have learned in the In Depth section of this chapter that the TabControl control can be used to group multiple controls in one or more tabs. Every tab occupies the same UI area and therefore, facilitates the maximum utilization of the UI of an application. Perform the following steps to use the TabControl control:

+   1. Create a Silverlight application named StudentRecordsAppCS (available on the CD) that is hosted in a .aspx page to see how you can use the TabControl control.

+   2. Add the TabControl control in the MainPage.xaml file. Listing 17.13 shows the code for the MainPage.xaml file of the StudentRecordsAppCS application:

# Listing 17.13: Showing the Code for the MainPage.xaml File

```
<UserControl xmlns:my="clr-namespace:System.Windows.Controls;assembly=System.Windows.Controls" x:Class="StudentRecordsAppCS.MainPage" xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation" xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml" xmlns:d="http://schemas.microsoft.com/expression/blend/2008" xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006" mc:Ignorable="d" d:DesignHeight="450" d:DesignWidth="600">
<Grid x:Name="LayoutRoot" Background="OldLace">
<TextBlock Text="Student Records" Margin="10,10,0,0" HorizontalAlignment="Center" Foreground="Purple" FontSize="24" Fontweight="Bold"/>
<my:TabControl Height="315" Width="550" Background="Lavender" Foreground="Purple" TabStripPlacement="Left">
<my:TabItem Header="Howard, Ron" Foregrounds="Purple" FontWeight="Bold" FontSize="18">
<my:TabItem.Content>
<Canvas>
<TextBlock Text="Student ID: KS231" />
```
