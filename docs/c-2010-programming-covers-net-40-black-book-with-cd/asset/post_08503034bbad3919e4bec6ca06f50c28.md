## Using Triggers

You can use triggers in a WPF application to change the look and feel of the controls dynamically. A good example of this is when you move the mouse pointer over a button, the button changes its color. In WPF, you can easily do this by using the XAML code. Triggers have been discussed in detail in the In Depth section of the chapter. In this section, you learn the practical implementation of triggers.

### Setting the Value of Properties using Triggers

You can easily change the look and feel of controls in WPF using the PropertyTriggers trigger. You can change the look of controls by changing their font, color, and opacity level. You can assign a trigger by using the IsMouseOver or IsKeyboardFocused property. Let’s set the property of a TextBox control using triggers. Create a WPF application named UsingTriggers_SettingValue (available in the CD) and add the code to the MainWindow.xaml file, as shown in Listing 10.30:

Listing 10.30: Showing the Code for Implementing a Trigger

```
<Window x:Class="UsingTriggers_SettingValue.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="350" Width="525">
    <Window.Resources>
        <Style x:Key="ChangeStyle" TargetType="{x:Type TextBox}">
            <Setter Property="Background" Value="LightPink"/>
            <Setter Property="FontSize" Value="10"/>
            <Style.Triggers>
                <Trigger Property="IsMouseOver" Value="True">
                    <Setter Property="Background" Value="Blue"/>
                    <Setter Property="FontSize" Value="25"/>
                </Trigger>
            </Style.Triggers>
        </Style>
    </Window.Resources>
    <StackPanel>
        <TextBox Width="300" Style="{StaticResource ChangeStyle}"/>
        <TextBox Width="350" Style="{StaticResource ChangeStyle}"/>
    </StackPanel>
</Window>
```

In Listing 10.30, two TextBox controls are added to the window. The size of the text in the first TextBox control is set to 10. As you move the mouse pointer over the TextBox control, the color of the control changes to blue and the size of the text in the TextBox control changes to 25. This is because we have used triggers in the code. You can run the application by pressing the F5 key.
