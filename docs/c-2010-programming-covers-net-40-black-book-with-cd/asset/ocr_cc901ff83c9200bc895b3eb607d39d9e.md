# Strong Naming the Assembly

Strong names, such as the globally unique identifiers (GUIDs) with component object model (COM) components, act as an ID that uniquely identifies an assembly. As learned earlier, .NET ships with a command-line utility called sn.exe, which helps in creating a unique ID for the assembly. To create the strong name for the assembly by using sn.exe, perform the following steps:

+   1. Open a .NET console window by selecting Start→All Programs→Microsoft Visual Studio 2010→Visual Studio Tools→Visual Studio Command Prompt (2010) and type the following command:
+      sn -k AKey.snk

The preceding command creates a strong name key pair file called AKey.snk in the current directory.

> NOTE
> The Visual Studio Command Prompt (2010) displays system drive (C:) as the current directory. You cannot create a strong name in the system drive. Change the current directory and then create the strong name.

+   2. Add the AKey.snk file in the SharedObject application by right-clicking the name of the application in the Solution Explorer and select Add→Existing Item.

+   3. Select the file in the Add Existing Item dialog box and click the Add button.

+   4. Open the AssemblyInfo.cs file to mention the key pair file we have just created. This file is available in the Properties folder in the Solution Explorer.

+   5. Mention the key pair file in the AssemblyKeyFile attribute, as shown in Listing 33.6:

# Listing 33.6: Showing the Elements of the AssemblyInfo.cs File

```
[assembly: AssemblyKeyFile("AKey.snk")]

[assembly: AssemblyTrademark("")]
```

Specifying a strong name key pair file in the AssemblyInfo.cs file allows the compiler to add strong name information to your assembly.

> TIP
