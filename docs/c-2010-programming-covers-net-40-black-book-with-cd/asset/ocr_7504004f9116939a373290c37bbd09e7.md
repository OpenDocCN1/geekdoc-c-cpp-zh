# # Accessing Resources from Code

Let's now learn to access the resources from code in a WPF application. Create a WPF application named AccessingResources (available in the CD) and add the code, shown in Listing 10.19, to the MainWindow.xaml file.

# Listing 10.19: Showing the Code to Access Resources in the MainWindow.xaml File

```
```xml
<Window x:Class="AccessingResources.MainWindow"
 xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
 xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
 Title="MainWindow" Height="350" Width="525">
 <Grid>
 <StackPanel Name="MyStackPanel">
 <StackPanel.Resources>
 <LinearGradientBrush x:Key="MyBrush" StartPoint="0.5,0" EndPoint="0.5,1">
 <GradientStop Offset="0.0" Color="LightPink"/>
 <GradientStop Offset="0.2" Color="Pink"/>
 <GradientStop Offset="0.7" Color="Darkorchid"/>
 </LinearGradientBrush>
 </StackPanel.Resources>
 </StackPanel>
 </StackPanel>
 <Button Name="Button1" Width="250" Height="100" Click="Button1_Click" />
 </Grid>
</Window>
```
```

The preceding code adds a Button control to window. To access the resource through the code, you need to add the code given in Listing 10.20 to the MainWindow.xaml.cs file. To do so, add the code given in Listing 10.20 to the MainWindow.xaml.cs file.

# Listing 10.20: Accessing Resources from Code

```
```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Windows;
using System.Windows.Controls;
using System.Windows.Data;
using System.Windows.Documents;
using System.Windows.Input;
using System.Windows.Media;
using System.Windows.Media.Imaging;
using System.Windows.Navigation;
using System.Windows.Shapes;
using System.Windows.Controls;
namespace AccessingResources
{
 // <summary>
 // Interaction logic for MainWindow.xaml
 // </summary>
 public partial class MainWindow : Window
 {
 public MainWindow()
 {
 InitializeComponent();
 }
 private void Button1_Click(object sender, RoutedEventArgs e)
 {
 Control button = sender as Control;
 button.Background = button.FindResource("MyBrush") as Brush;
 }
 }
}
```
