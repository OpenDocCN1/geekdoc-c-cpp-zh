## 使用 Stack 类

Stack 类允许您创建集合，其中对象像堆栈一样堆叠，使得最后添加到集合中的对象最先被检索。让我们创建一个名为 StackSample 的 Windows 窗体应用程序，也可在 CD-ROM 上获得，以了解 Stack 类的使用。该应用程序包含一个示例用户界面窗体，其中有三个按钮——Create and add 10 items、Push 和 Pop，以及一个 ListBox 控件。

按照以下步骤创建 StackSample 应用程序：

- 1. 在 StackSample 应用程序中将 Form1 的 Text 属性设置为 Stack Sample。
- 2. 将 ListBox、GroupBox 和三个 Button 控件拖放到窗体上。
- 3. 将 GroupBox 控件的 Text 属性设置为 Noteworthy Operations，并将 button1 的 Text 属性设置为 Create and add 10 items，button2 设置为 Push，button3 设置为 Pop。
- 4. 在 Form1.cs 文件中添加清单 32.4 中给出的代码以创建 Stack 对象并向其添加元素：

## 清单 32.4：显示 StackSample 应用程序的代码

```
using System;
using System.Collections.Generic;
using System.ComponentModel;
using System.Data;
using System.Drawing;
using System.Linq;
using System.Text;
using System.Windows.Forms;
using System.Collections;
namespace StackSample
{
public partial class Form1 : Form
{
    private Stack S;
    public Form1()
    {
        InitializeComponent();
    }
    private void button1_Click(object sender, EventArgs e)
    {
        S = new Stack(10);
        S.Push("white");
        S.Push("black");
        S.Push("blue");
        S.Push("Yellow");
        S.Push("Green");
        S.Push("Red");
        S.Push("Orange");
        S.Push("Purple");
        S.Push("Magenta");
        S.Push("Brown");
        LoadS();
        button2.Enabled = true;
        button3.Enabled = true;
    }
    private void Form1_Load(object sender, EventArgs e)
    {
        button2.Enabled = false;
        button3.Enabled = false;
    }
    private void LoadS()
    {
        listBox1.Items.Clear();
        object[] objArr = S.ToArray();
        for (int i = 0; i < S.Count; i++)
        {
            listBox1.Items.Add(objArr[i]);
        }
    }
    private void button2_Click(object sender, EventArgs e)
    {
        S.Push(Microsoft.VisualBasic.Interaction.InputBox("Enter the value for the item to be pushed.", "", "", -1, -1));
        LoadS();
    }
    private void button3_Click(object sender, EventArgs e)
    {
        MessageBox.Show(S.Pop().ToString(), "Item Popped.");
        LoadS();
    }
}
}
```

在清单 32.4 中，使用了 Push 和 Pop 方法向 Stack 对象添加和删除元素。button1 的 Click 事件创建了一个 Stack 对象 S。该对象使用 Push 方法填充了 10 个元素。button2 控件的 Click 事件也使用 Push 方法在运行时添加新元素。此外，button3 的 Click 事件使用 Pop 方法从 Stack 对象中删除一个元素。
