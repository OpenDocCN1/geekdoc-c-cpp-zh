# Creating a Class

You can create a class using the class keyword, followed by the class name. A class is similar to a container that may have data members (variables, constants, or fields), member functions (methods, properties, events, indexers, operators, instance constructors, destructors, static constructors), and other classes. A class also supports inheritance, which is a mechanism in which a derived class extends a base class. You will learn more about inheritance in Chapter 5, Object-Oriented Programming in C# 2010. To see how to create a new class in an application, first create a new Console application, named MyClass.
