# ItemsControl Control

The ItemsControl controls display a collection of items and do not have the Content or Header properties. Controls that are grouped as ItemsControl contain a collection of items. The ItemsControl controls include the following controls: Menu, ContextMenu, ListBox, ComboBox, ListView, TreeView, TabControl, and StatusBar.

Table 10.30 lists a brief description of ItemsControl controls:

| Table 10.30: List of ItemsControl Controls |
| Control | Description |
| ContextMenu | Represents a pop-up menu that enables a control to display the functionalities specific to the context of the control |
| StatusBar | Represents a control that displays items and information in a horizontal bar |
| Menu | Represents a control to hierarchically organize controls |
| ListBox | Contains a list of selectable items |
| ComboBox | Represents a control with a drop-down list |
| ListView | Represents a control that displays a list of items |
| TreeView | Represents a control that displays hierarchical data in a tree structure with items that can expand and collapse |
| TabControl | Represents a control that contains multiple items sharing the same space on the screen |

# The ContextMenu Control

The ContextMenu control represents a pop-up menu that enables a control to display the functionality that is specific to the context of the control. You can display a context menu by right clicking the mouse. The ContextMenu control is derived from the abstract base class, MenuBase. Each ContextMenu control is specific to the control it is attached to. Whenever you right-click a TextBox control, you see a ContextMenu control with the Cut, Copy, and Paste options. The ContextMenu control is different from other ItemControls controls, as it is contained within another control and creates a menu in the form of a pop-up.

The ContextMenu control is represented by the ContextMenu class. The inheritance hierarchy of the ContextMenu class is as follows:

