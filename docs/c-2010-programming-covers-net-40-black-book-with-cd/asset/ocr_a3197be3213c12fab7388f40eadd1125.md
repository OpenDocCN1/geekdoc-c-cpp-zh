# The TreeView Control

The TreeView control in WPF is used to display items in a hierarchical manner. This control lists the items using the TreeViewItem control. Therefore, the TreeView control consists of a hierarchy of TreeViewItem controls. You can expand or collapse the TreeViewItem control by setting the IsExpanded property to True or False, respectively. When a user selects the TreeViewItem control, the Selected event occurs and the IsSelected property is set to True. When the user deselects the TreeViewItem control, the UnSelected event occurs and the IsSelected property is set to False. You cannot explicitly set the SelectedItem property, as it is a read-only property. You can use the SelectedValue and SelectedPathValue properties to assign a value to the SelectedItem property. The default view of the TreeView control places the control inside a StackPanel container control and adds a ScrollViewer control to it.

The inheritance hierarchy of the TreeView class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.ItemsControl
                System.Windows.Controls.TreeView
```

You can add the TreeView control to a WPF application by using the following code snippet:

```
<TreeView>
  <!-- Items -->
</TreeView>
```
