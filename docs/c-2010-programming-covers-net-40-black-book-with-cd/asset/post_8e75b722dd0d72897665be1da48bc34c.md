## Retrieving Values using a Read-Only Property

A read-only property is a property that has a get accessor but does not have a set accessor. This means that you can retrieve the value of a variable using a read-only property but you cannot assign a value to the variable. To see how to retrieve values using read-only properties, first create a new Console application, name MyReadonlyProperty (also available in the CD) and then replace the default code of the Program.cs file of the application with the code shown in Listing 4.21:

Listing 4.21: Showing the Code of the MyReadonlyProperty Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyReadonlyProperty
{
    public class PropertyHolder
    {
        private int someProperty = 0;
        public PropertyHolder(int propval)
        {
            someProperty = propval;
        }
        public int SomeProperty
        {
            get
            {
                return someProperty;
            }
        }
    }
    public class PropertyTester
    {
        public static void Main(string[] args)
        {
            PropertyHolder propHold = new PropertyHolder(5);
            Console.WriteLine("Property Value: " + propHold.SomeProperty);
            Console.Write("\nPress ENTER to Quit..");
            Console.ReadLine();
        }
    }
}
```

Listing 4.21 shows how to implement the read-only property. The PropertyHolder class has the SomeProperty property, which implements only a get accessor and leaves out the set accessor. The PropertyHolder class has a constructor, which accepts the int parameter. The Main() method of the PropertyTester class creates a new PropertyHolder object named propHold. The propHold object uses the constructor of the PropertyHolder class that takes a parameter of type int, whose value is set to 5. You cannot set the value of the SomeProperty property as it is read-only.
