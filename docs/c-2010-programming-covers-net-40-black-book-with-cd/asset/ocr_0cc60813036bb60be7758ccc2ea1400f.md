Earlier, you had to write complex ForEach loops that specified how to retrieve data from a collection. In such a scenario, you can easily use LINQ to Objects to write declarative code that describes what you want to retrieve. LINQ to Objects is more beneficial because of the following specific reasons:

+   - Helps in filter multiple conditions as they are more concise and readable
+   - Provides powerful filtering, ordering, and grouping capabilities with the use of minimum application code
+   - Gets easily ported to other data sources with little or no modification

In simple terms, you can say that the more complex operation you want to perform on data, the more benefit you get by using LINQ to Objects instead of the traditional iteration techniques. The following are the concepts you need to know to use LINQ to Objects:

+   - Strings
+   - Reflections
+   - File directories

Let’s discuss about each of them in detail.

# Strings

LINQ is used to query and transform strings and collections of strings. It is particularly useful with semi-structured data in the text files. You can easily combine the LINQ queries with traditional string functions as well as query functions. In LINQ to Objects, you can easily query, analyze, and modify the large text. You just need to break them into smaller strings by using the Split() method. You can split the source text into words, paragraphs, or any other criteria, and then perform additional splits if they are required by your query. You can also use the IsMatch() method in the where clause of the LINQ query. You can then use the LINQ query to use or modify your regular expression.

# Reflections

The .NET Framework class library uses the concept of reflection to examine the metadata in the .NET assembly and create collections of types and members. The use of reflection in LINQ helps you to retrieve metadata about methods that match the specified search criteria. For example, you can run a query that retrieves the names of all the methods in an assembly that return enumerable type, such as arrays. The System.Reflection namespace is used to use reflection in LINQ.

# File Directories

Another attached feature in LINQ is the use of file directories. The following are the various functions that you can perform by using the file directories in LINQ:

+   - Use the file directory feature to find all the files that have a specified file name extension in a specified directory tree.
+   - Perform advance grouping and sorting operations on a list of files and folders.
+   - Retrieve the total number of bytes used by all the files in a specified folder and its subfolder.
+   - Compare the contents of two folders. You can query for a Boolean value that specifies whether the two files are identical or not. You can also query for the intersection to retrieve the files in both the folders. The FileComparer class is used to perform these functions of the file directory.
+   - Use the FileInfo object to retrieve the size (in bytes) of the largest file.
+   - Query for the files that are saved in multiple places in a file directory with the same name.
+   - Query about the content of all the files in a specified directory.
