ASP.NET has a FormsAuthenticationModule class that facilitates the implementation of Forms authentication. A FormsAuthenticationModule object is responsible for searching the authentication ticket, redirecting the users to the login page, and authenticating the users. This object allows you to set the HttpContext.User property to the identity with which a user logs in. The identity of an authenticated user is represented by a FormsIdentity object. You can use the FormsIdentity object with the GenericPrincipal object to implement role-based security with Forms authentication.

The FormsAuthenticationModule class uses another class—FormsAuthentication to manage the process of Forms authentication. This class has various properties and methods that you can use to specify the login page, redirect users to and from the login page, authenticate users, and create authentication cookies. | CookieDomain | Returns the name of the domain of the authentication cookie. |
