# Adding Tool Tips to Controls

You can specify tool tips for controls and set their text by using the ToolTip property. By default, tool tip is blank. Let’s take use example to set a tool tip Click on the Button control. To do so, select the Button control in the Design view and in the Properties window, set its ToolTip property to Click. When you execute the application by pressing the F5 key, the output is displayed, as shown in Figure 13.38:

# Specifying Access Characters for Controls

Access characters make it possible to select controls from the keyboard by using the ALT key. Suppose, in the application, if you want to make the W in the Welcome button’s caption an access character, just press the ALT+W keys and click the button. To give a Button control an access character, you set its AccessKey property as W. When you press the access characters, the Click event of the button executes and the Click event handler is called.
