## Using the Path and PathGeometry Classes

In WPF, the Path class enables you to draw complex curves and shapes. To use the Path class, you first create an object of the Geometry class and use it to set the Data property of an object of the Path class. The FillRule property specifies how the intersecting areas are combined and it works with either the PathGeometry or GeometryGroup object. There are two values of the FillRule property, EvenOdd and NonZero. If you specify the EvenOdd value, the alternate area is filled. The NonZero value fills the whole area specified in the GeometryGroup or PathGeometry object with the specified color. The PathGeometry object is made up of one or more figures, which is represented by the PathFigure class. Each figure is made up of one or more segments, which is defined by the PathSegment class. Let's use the Path and PathGeometry classes to see the application of the FillRule property. To do this, create a WPF application named UsingPath (also available in CD) and add the code, given in Listing 12.7, to the MainWindow.xaml file:

```

Title="MainWindow" Height="300" Width="300">
<Grid>
<Path Stroke="Black" StrokeThickness="2" Fill="LightBlue">
<Path.Data>
<GeometryGroup FillRule="Evenodd">
<PathGeometry>
<PathGeometry.Figures>
```
