## NavigationWindow 控件

NavigationWindow 控件派生自 Window 类，并设计为支持内容导航。您可以通过将 NavigationWindow 控件的 Source 属性设置为所需内容的通用资源标识符（URI）来导航内容。只要页面处于导航模式，您也可以跟踪导航过程中引发的事件。在导航期间引发的一些事件有 Navigating、Navigated、NavigationProgress、NavigationFailed、NavigationStopped、LoadCompleted 和 FragmentNavigation。引发的事件类型取决于用户执行的导航类型。可以通过调用 RemoveBackEntry 属性来删除导航历史记录。

NavigationWindow 类的继承层次结构如下：

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.ContentControl
                System.Windows.Window
                  System.Windows.Navigation.NavigationWindow
```

您可以通过使用以下代码片段将 NavigationWindow 添加到 WPF 应用程序中：

```
<NavigationWindow>
    <!--Content -->
</NavigationWindow>
```

表 10.26 描述了 NavigationWindow 类的显著属性：

| 属性 | 描述 |
|---|---|
| BackStack | 检索一个 IEnumerable 属性，用于枚举 NavigationWindow 控件的后向导航历史记录中的条目 |
| CanGoBack | 检索一个值，指示后向导航历史记录中是否至少有一个条目 |
| CanGoForward | 检索一个值，指示前向导航历史记录中是否至少有一个条目 |
| ForwardStack | 检索一个 IEnumerable 属性，用于枚举 NavigationWindow 控件的后向导航历史记录中的条目 |
| NavigationService | 检索 NavigationWindow 用于为其内容提供导航的方法、属性和事件 |
| SandboxExternalContent | 获取或设置一个值，指示 NavigationWindow 控件是否在部分信任安全沙箱中隔离外部 XAML 内容 |
| ShowsNavigationUI | 获取或设置一个值，指示 NavigationWindow 控件是否显示其导航历史记录 |

NavigationWindow 控件无法从工具箱中添加。您可以通过 XAML 代码将其添加到应用程序中。

## UserControl 控件

在 WPF 中，UserControl 控件提供一个空控件，可用于创建其他控件。将 UserControl 类用作基类提供了一种简单的方法来创建自定义控件。UserControl 控件帮助您创建可在应用程序中的多个位置使用的控件。例如，您可以预先加载一个 ComboBox 控件，其中包含您在每个应用程序中常用的静态项。您无法使用 XAML 代码将 UserControl 控件添加到 WPF 应用程序中。相反，您需要在代码隐藏文件中创建 UserControl 控件。UserControl 控件的继承层次结构如下：

```
System.Object
    System.Windows.Controls.Control
        System.Windows.Controls.TemplateControl
            System.Windows.Controls.UserControl
```

您可以通过使用以下代码片段将 UserControl 添加到 WPF 应用程序中：

```
<UserControl>
    <!--Content -->
</UserControl>
```

UserControl 控件没有显著属性。

## 标题内容控件

标题内容控件是包含 Header 和 Content 属性的控件。Header 属性由文本值组成，而 Content 属性由单个内容项组成。标题内容控件继承 Content 属性自 ContentControl 控件并定义 Header 属性，用于为控件提供标题。标题内容控件包括以下控件：Expander、GroupBox 和 TabItem。

表 10.27 描述了所有标题内容控件的简要说明：

## 表 10.27：标题内容控件

| 控件 | 描述 |
|---|---|
| Expander | 表示一个控件，该控件显示一个标题和一个包含内容的折叠窗口。 |
| GroupBox | 表示一个控件，该控件显示一个框架。此控件可以将一些控件组合在一起并在框架内显示它们。 |
| TabItem | 表示 TabControl 控件内的可选择项。 |

## Expander 控件

Expander 控件表示一个控件，该控件显示一个标题和一个可折叠窗口。您可以使用 ExpandDirection 属性将 Expander 控件的内容区域设置为在四个方向之一中展开：Down、Up、Left 和 Right。当 Expander 控件的内容区域折叠时，只有 ExpanderHeader 及其切换按钮可见。

Expander 控件由 Expander 类表示。Expander 类的继承层次结构如下：

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.ContentControl
                System.Windows.Controls.HeaderedContentControl
                  System.Windows.Controls.Expander
```

您可以通过使用以下代码片段将 Expander 控件添加到 WPF 应用程序中：

```
<Expander>
  <!--Content-->
</Expander>
```

表 10.28 描述了 Expander 类的显著属性：

## 表 10.28：Expander 类的显著属性

| 属性 | 描述 |
|---|---|
| ExpandDirection | 获取或设置展开器窗口打开的方向 |
| IsExpanded | 获取或设置一个值，指示 Expander 控件应显示为展开还是折叠 |

## GroupBox 控件

GroupBox 控件的内容属性为 Content，GroupBox 控件的标题属性为 Header。您可以在 GroupBox 控件内添加多个控件。

```
          System.Windows.FrameworkElement

              System.Windows.Controls.ContentControl

                  System.Windows.Controls.GroupBox
```

您可以通过使用以下代码片段将 GroupBox 控件添加到 WPF 应用程序中：

## TabItem 控件

TabItem 控件在 WPF 中包含在 TabControl 类中。TabItem 控件的标题，该标题显示在窗口上，可以使用 Header 属性添加到页面。TabItem 控件表示 TabControl 控件内的可选择项。TabControl 控件可以包含多个 TabItem 控件；然而，在 TabControl 控件中一次只有一个 TabItem 控件可见。

TabItem 类的继承层次结构如下：

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.ContentControl
                System.Windows.Controls.HeaderedContentControl
                  System.Windows.Controls.TabItem
```
