+   - Comparison—Makes comparison between any two pointers by using comparison operators, such as ==, !=, <, >, <=, and >=.
+   - Assignment—Assigns the value of another pointer or null to a pointer variable.

# Converting Pointers

Pointer conversion means to convert a pointer type variable to another data type. In C#, pointer conversion includes the conversions, which are as follows:

+   - Converting pointer type to void* type
+   - Converting any null type pointer to any pointer type

Additional to this, following explicit pointer conversions are also available in an unsafe code:

+   - Converting any pointer type variable to another pointer type variable
+   - Converting sbyte, byte, short, ushort, int, uint, long, or ulong type pointer variables to any other pointer type variable

When you convert one pointer type to another, the actual value of the pointer does not change. It means that after conversion, the address denoted by the pointer remains the same. Pointer conversion should follow a concept where a pointer type, such as Type1 is converted to another type, such as Type2. Further, Type2 is converted to another type, such as Type3, then Type1 should be compatible to Type3. This concept is called Correctly Aligned, which is transitive in nature. Let’s take an example to know about the pointer conversions, as shown in the following code snippet:

```
char MyChar = 'A';
char* CharPointer = &MyChar;
void* VoidPointer = CharPointer;
int* IntPointer = (int*)VoidPointer;
int i = *IntPointer;    // undefined
*IntPointer = 121212;   // undefined
```

In the preceding code snippet, the VoidPointer pointer is accessing the CharPointer pointer and the IntPointer pointer is accessing the VoidPointer pointer.

# Delegates

A delegate is a special type of object that contains the details of a method rather than data. In C#, a delegate is a class type object, which is used to invoke a method that has been encapsulated into it at the time of its creation. A delegate can be used to hold the reference to a method of any class. It carries three important pieces of information—the name of the method on which it makes calls, the arguments (if any) of this method, and the return value (if any) of this method.

In the following sections, first you learn to create and use delegates. Then, you learn about multicast delegates, covariance, and contravariance. Further, you learn about anonymous methods with delegates.
