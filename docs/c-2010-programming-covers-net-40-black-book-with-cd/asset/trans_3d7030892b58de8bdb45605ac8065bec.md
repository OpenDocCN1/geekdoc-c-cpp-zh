## 接口

接口是一组数据成员和成员函数，但它并不实现它们。接口被引入是为了向类提供多重继承的特性。多重继承是 OOP 的特性，它允许一个类从多个类继承。接口中定义的方法没有实现，它们只指定它们将接受的参数和它们将返回的值的类型。接口始终在类中实现。实现接口的类需要实现接口的所有成员。

在 C# 中，接口的实现比任何其他语言都更灵活。C# 中的接口相当于抽象基类。这意味着你不能通过接口实例化对象，但你可以为实现接口的类提供一组功能。接口可以具有与类相同的访问修饰符，例如 public 和 private。让我们在 C# 中声明和实现接口的上下文中学习以下概念：

- 接口的语法
- 接口的实现
- 接口与继承

让我们从接口的语法开始

## 接口的语法

接口的声明方式与类相同，但唯一的区别是类使用 class 关键字声明；而接口使用 interface 关键字声明。接口表现得像包含方法声明的模板。这些方法本质上是抽象的，因为它们的主体中没有代码。如前所述，实现接口的类必须实现其所有方法；否则，会发生错误。你可以使用以下语法声明接口：

```
interface <InterfaceName>
{
    //Abstract Method Declarations in Interface Body
}
```

考虑以下创建了两个名为 MyFirstInterface 和 MySecondInterface 的接口的代码片段：

```
interface MyFirstInterface
{
    void MyFirstMethod();    //Abstract Method in Interface Body
}
interface MySecondInterface
{
    void MySecondMethod();  //Abstract Method in Interface Body
}
```

在前面的代码片段中，MyFirstInterface 和 MySecondInterface 接口都包含一个名为 MyFirstMethod() 和 MySecondMethod() 的抽象方法。这两种方法都是 void 并且不返回任何值。

## 接口的实现

要在程序中实现多重继承，你需要使用接口。实现接口类似于继承类。以下代码片段显示了如何实现接口：

```
class ImplementInterface : MyFirstInterface, MySecondInterface
{
    static void Main()
    {
        ImplementInterface ABC = new ImplementInterface();
```
```
MyFirstInterface I1 = (MyFirstInterface)ABC;
MySecondInterface I2 = (MySecondInterface)ABC;
I1.MyFirstMethod();
I2.MySecondMethod();
}
public void MyFirstMethod()
{
    Console.WriteLine("Call  MyFirstMethod() ");
}
public void MySecondMethod()
{
    Console.WriteLine("Call  MySecondMethod() ");
}
```

在前面的代码片段中，ImplementInterface 类实现了 MyFirstInterface 和 MySecondInterface 接口。MyFirstInterface 接口包含一个方法 MyFirstMethod()，而 MySecondInterface 接口包含一个方法 MySecondMethod()，两者都不返回任何值。如前面的代码片段所示，我们在实现接口的类中编写方法的主体。

## 接口与继承

当接口由基类实现时，则基类的派生类会自动继承接口的方法。你可以通过将派生类的对象类型转换为接口本身来初始化接口的对象。考虑以下代码片段以更清楚地理解接口和继承的概念：

```
interface MyInterface
{
void ShowData();
}
class MyBaseClass:MyInterface //Implements MyInterface
{
public void ShowData()
{
//Method Body
}
}
class MyDerivedClass:MyBaseClass //Inherits MyBaseClass
{
public new void ShowData()
{
//Method Body
}
}
class MainClass
{
...
MyDerivedClass dc=new MyDerivedClass()
dc.ShowData();
MyInterface inter=(MyInterface) dc;
inter.ShowData();
}
```

在前面的代码片段中，声明了一个接口 MyInterface，包含 ShowData() 方法。一个基类 MyBaseClass 实现了 MyInterface 接口。接下来，一个派生类 MyDerivedClass 继承了 MyBaseClass 类。现在，在 MainClass 类中，声明并初始化了 MyDerivedClass 类的一个实例 dc。最后，dc 对象被类型转换为 MyInterface 接口的 inter 对象并用于调用 ShowData() 方法。

## 继承一个类

继承是面向对象编程的主要特性之一。它允许你重用现有代码。在 In Depth 部分，你已经了解到一个类可以从另一个类继承。允许其通用属性被继承的类被称为基类或父类，而继承基类属性的类被称为派生类或子类。在 Listing 5.1 中，BaseClass 类是父类，DerivedClass 类继承了 BaseClass 类的特性，因此它是子类。让我们创建一个名为 MyInheritance 的应用程序（也在 CD 上提供）来学习如何继承一个类。Listing 5.1 显示了 MyInheritance 应用程序的代码：

### Listing 5.1: Showing the Code of MyInheritance Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace MyInheritance
{
public class BaseClass
{
    public int DataMember;
    public void BaseClassMethod()
    {
        Console.WriteLine("I am a Base Class Method()");
    }
}
public class DerivedClass : BaseClass
{
    public void DerivedClassMethod()
    {
        Console.WriteLine("I am a Derived Class Method()");
    }
}
public class Program
{
    public static void Main(string[] args)
    {
        // Create a Base Class Object
        Console.WriteLine("I am accessing Base Class object:");
        BaseClass bc = new BaseClass();
        bc.DataMember = 1;
        bc.BaseClassMethod();
        // Create a Derived Class Object
        Console.WriteLine("");
        Console.WriteLine("I am accessing Derived Class object:");
        DerivedClass dc = new DerivedClass();
        dc.DataMember = 2;
        dc.BaseClassMethod();
        dc.DerivedClassMethod();
        Console.Write("\nPress ENTER to quit..");
        Console.ReadLine();
    }
}
}
```

在 Listing 5.1 中，我们创建了三个类，BaseClass、DerivedClass 和 Program。DerivedClass 类继承了 BaseClass 类。这意味着 DerivedClass 类继承了 BaseClass 类的所有成员。在 Program 类中，我们初始化了这些类并调用方法。

## 创建密封类

你可以使用 sealed 关键字创建密封类。密封类不能用作基类。换句话说，密封类不能被继承。现在，让我们创建一个名为 MySealedClass 的应用程序（也在 CD 上提供），它展示了如何将类声明为密封。Listing 5.2 显示了 MySealedClass 应用程序的代码。

### Listing 5.2: Showing the Code of the MySealedClass Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MySealedClass
{
    sealed class MyClass
    {
        string fName;
        string lName;
        int Age;
        public void GetDetail()
        {
            Console.Write("Enter Your first Name:");
            fName = Console.ReadLine();
            Console.Write("Enter Your last Name:");
            lName = Console.ReadLine();
            Console.Write("Enter Your Age:");
            Age = int.Parse(Console.ReadLine());
        }
        public void ShowDetail()
        {
            Console.WriteLine(fName + " " + lName + " you are " + Age + " Years Old");
        }
    }
    // Following lines shows compiler error as Sealed class cannot be inherited
    /* class Derived : MyClass
    {
    }*/
    class MainClass {
        static void Main(string[] args) {
            MyClass obj = new MyClass();
            obj.GetDetail();
            obj.ShowDetail();
            Console.Write("\nPress ENTER to quit...");
            Console.ReadLine();
        }
    }
}
```

在 Listing 5.2 中，我们使用 sealed 关键字创建了一个名为 MyClass 的密封类。该类包含两个方法 GetDetail() 和 ShowDetail()，用于从用户获取输入并显示详细信息。
