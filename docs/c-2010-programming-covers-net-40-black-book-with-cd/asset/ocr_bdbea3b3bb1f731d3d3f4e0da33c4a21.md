The .NET Framework in Silverlight component also enables you to easily access data and services at remote locations through Windows Communication Foundation (WCF). In addition, you can use HTTP objects, cross-domain HTTP requests, RSS feeds, JavaScript Object Notation (JSON), and Simple Object Access Protocol (SOAP) services in Silverlight applications.

# The Core Presentation Framework

The core presentation framework is a component in Silverlight that offers the features and services for designing the UI of Silverlight applications through controls, styles, templates, 2-D vector graphics, animations, and multimedia. This component also allows you to incorporate user input and interactivity through various input devices, such as mouse and keyboard. It also allows you to bind data with various controls, and specify the UI layout of the Silverlight applications. Moreover, you can also manage the digital rights of the multimedia content used in your Silverlight applications through this component. The XAML parser for processing the XAML content in Silverlight applications is also provided by the core presentation framework.

# Silverlight Applications in Visual Studio 2010

You can create Silverlight applications by using a text editor, such as Notepad. However, various tools, such as Visual Studio 2010, Expression Studio, and ComponentOne Studio, provide an efficient and quick means of creating Silverlight applications as these tools include the essential files and functionality by default. Among these tools, Visual Studio 2010 is an ideal choice for both designers and developers of Silverlight based applications. Note that Silverlight facilitates .NET designers and developers to effortlessly coordinate with each other to build strikingly attractive and compelling Web applications.

Using the Visual Studio 2010 IDE, you can easily create Silverlight 3.0 applications. In Visual Studio 2010, when you select File→New→Project from the menu bar, notice that the templates to create Silverlight 3.0 applications are already available. However, if you try to create a Silverlight application, you get an error saying that the Silverlight developer runtime is not installed on your system. To create Silverlight 3.0 applications, you need to install the Silverlight 3 SDK and the Silverlight 3 developer runtime. You can get the Silverlight 3 SDK from http://www.microsoft.com/downloads/details.aspx?displaylang=en&FamilyID=d09b6ecf-9a45-4d99-b752-2a330a937bc4 and the Silverlight 3 developer runtime from http://go.microsoft.com/fwlink/?LinkID=143433.

> NOTE
> If you use Visual Studio 2010 to develop Silverlight 3.0 applications then you can just drag and drop the Silverlight controls from Toolbox to the Silverlight application interface as you do while creating Windows, WPF, or ASP.NET Web applications.

After you have installed the Silverlight 3 SDK and Silverlight 3 developer runtime, open Visual Studio and select File→New→Project from the menu bar. The New Project dialog box will appear.
