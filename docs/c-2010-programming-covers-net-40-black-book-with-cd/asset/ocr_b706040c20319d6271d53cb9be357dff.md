+   - NodeTemplate—Applies on all the nodes in the hierarchy, irrespective of their node type.
+   - CurrentNodeTemplate—Sets the appearance of the node corresponding to the current page displayed. CurrentNodeTemplate takes precedence over the NodeTemplate.
+   - RootNodeTemplate—Sets the appearance for the root node of the site hierarchy. RootNodeTemplate takes priority over NodeTemplate and CurrentNodeTemplate. This means that if the current page is the root page according to the site hierarchy, then only RootNodeTemplate will be used for the root node.
+   - PathSeparatorTemplate—Uses to separate the nodes with a separator between the nodes that are currently rendered on the Web page. It replaces the PathSeparator text value in your application.
