# Compressing Files in .NET Framework

In .NET, the System.IO.Compression namespace provides various classes, such as DeflateStream and GZipStream, to compress files. The DeflateStream class uses the Deflate algorithm and provides various methods and properties to compress as well as decompress files. The GZipStream class also uses the Deflate algorithm for compressing files; however, it can be extended to use other data compression formats. To use these classes, you need to initialize them using the existing streams, such as FileStream objects and StreamReader classes. The default stream is mostly FileStream object. In addition to this, you need to specify whether the stream is used for compression or decompression.
