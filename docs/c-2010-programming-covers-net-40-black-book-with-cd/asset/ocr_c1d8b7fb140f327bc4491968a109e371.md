# Table 10.45: Noteworthy Properties of the TextBlock Class

| Property | Description |
|---|---|
| Inlines | Retrieves an InlineCollection class containing the Inline elements that comprise the contents of a TextBlock control |
| IsHyphenationEnabled | Gets or sets a value that indicates whether automatic hyphenation of words is enabled or disabled |
| LineStackingStrategy | Gets or sets the mechanism by which a line box is determined for each line of text within a TextBlock control |
| Padding | Gets or sets a value that indicates the thickness between the boundaries of the content area and the content displayed by a TextBlock control |
| Text | Gets or sets the text contents of a TextBlock control |
| TextAlignment | Gets or sets a value that indicates the horizontal alignment of text content in a TextBlock control |
| TextDecorations | Gets or sets a TextDecorationCollection control that contains the effects to apply to the text of a TextBlock control |
| TextEffects | Gets or sets the effects to apply to the text content in a TextBlock control |
| TextTrimming | Determines how the text is trimmed when the content overflows the content area |
| TextWrapping | Determines how a TextBlock control should wrap the text |

# NOTE

> The functioning of the Label and TextBlock controls is the same in most respects. The only difference between the two is in the amount of text these controls can display. A TextBlock control can display a large amount of text as compared to a Label control.
