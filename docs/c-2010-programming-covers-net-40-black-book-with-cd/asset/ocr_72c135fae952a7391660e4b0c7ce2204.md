# Using the RadioButton Control

When you add a RadioButton control on a Web page (Default.aspx), it adds the following code to the source code of the Web page:

```
<asp:RadioButton ID="RadioButton1" runat="server" />
```

Let's create a Web application named RadioButtonControl (also available on the CD-ROM). In this example, we have placed five RadioButton controls on the Web page showing car names.
