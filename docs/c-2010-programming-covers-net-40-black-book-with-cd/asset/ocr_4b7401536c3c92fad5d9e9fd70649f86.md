# Enumerating Registered Channels

Registering a channel creates a tunnel between the client system and the server system. When the channel is registered, all the communication takes place through this channel. A channel can be an HTTP channel, a TCP channel, or a custom channel. The following code snippet shows how to register a TCP channel in the DBServer application:

```
ChannelServices.RegisterChannel(new TcpChannel(), false);
```

In the preceding code snippet, we have used the RegisterChannel() method to register a TCP channel. This method takes two parameters, an object of the channel and a Boolean value that specifies whether to keep protocol security settings on or off for your calls. In our case, the second parameter is set to False.

You can create an enumeration of all the registered channels by using the RegisteredChannels() method of the ChannelServices class, as shown in the following code snippet:

```
foreach (IChannelReceiver chan in ChannelServices.RegisteredChannels)
{
    lbServces.Items.Add(chan.ChannelName);
}
```

To retrieve the channel name and the URI list associated with the channel, as shown in the following code snippet:

```
IChannelReceiver chan =
(IChannelReceiver)ChannelServices.GetChannel(System.Convert.ToString(lbServces.SelectedItem));
string strDesc = null;
foreach (string UriName in ((ChannelDataStore)chan.ChannelData).ChannelUris)
{
    strDesc += UriName + System.Environment.NewLine;
}
TextBox1.Text = strDesc;
TextBox1.Text += "Priority : " + chan.ChannelPriority.ToString();
```

# Unregistering a Channel

If you have registered a channel and want to unregister it later so that you can make use of the other channels, you can easily unregister a channel, as shown in the following code snippet:

```
if (lbServces.SelectedItems.Count > 0)
{
    IChannelReceiver chan=
    (IChannelReceiver)ChannelServices.GetChannel(System.Convert.ToString(lbServces.SelectedItem));
    ChannelServices.UnregisterChannel(chan);
    chan.StopListening(null);
    ListServices();
    txtStatusBar.Text = "disconnected";
}
```

# Registering Objects

As discussed in the In Depth section, the remotable objects are of three types—SingleCall, Singleton, and CAO. You can register a SingleCall object by using the RegisterWellKnownServiceType() method of the RemotingConfiguration class, as shown in the following code snippet:

```
RemotingConfiguration.RegisterWellKnownServiceType(
    typeof(Sharedobject.Sharedobject), "HiServerApp/HiServer", WellKnownObjectMode.SingleCall);
```

You can register a Singleton object by using the RegisterWellKnownServiceType() method of the RemotingConfiguration class, as shown in the following code snippet:

```
RemotingConfiguration.RegisterWellKnownServiceType(typeof(Sharedobject.Sharedobject), "HiServerApp/HiServer", WellKnownObjectMode.Singleton);
```
