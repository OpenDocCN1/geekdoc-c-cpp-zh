In Listing 31.3, you can see that the FirstThread thread starts its execution and the FirstFunction() method generates a random number at every iteration, which is considered as the slept time of the thread. When the FirstThread thread reaches the total slept time of 200 milliseconds, then the program control is transferred to the Suspend() method, causing the thread to suspend for an infinite amount of time.
