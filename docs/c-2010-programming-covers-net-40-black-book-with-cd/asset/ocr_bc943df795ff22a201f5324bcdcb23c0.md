# ## Color Structure in Windows Form

> > **NOTE**  
> > You must note that when you inherit from the Brush class, you must override the Clone() method.

The colors in Windows Form are based on four components. These components are the three primary colors red, green, and blue; and the alpha component, which is used to define the transparency of the color. The Color structure represents the colors in Windows Form. It is contained in the System.Drawing namespace. You can create a custom color by using the FromArgb method and a Color instance through a static property. The Color structure contains 140 named colors, which are derived from the static properties. You can create a Color value initialized to one of the named colors, as shown in the following code snippet:

```
Color newColor = Color.Red;
```

The noteworthy methods of the Color structure in Windows Form are listed in Table 12.8:

**Table 12.8: Methods of the Color Structure**

| Method | Description |
|---|---|
| Equals | Checks if the specified object is equivalent to the Color structure |
| FromArgb | Creates a Color structure from a 32-bit ARGB value |
| FromKnownColor | Creates a Color structure from the specified predefined color |
| FromName | Creates a Color structure from the specified name of a predefined color |
| GetBrightness | Retrieves the brightness value for the specified Color structure |
| GetHashCode | Returns a hash code for the specified Color structure |
| GetHue | Retrieves the hue-saturation-brightness value, in degrees, for the specified Color structure |
| GetSaturation | Retrieves the hue-saturation-brightness value for the specified Color structure |
| ToArgb | Retrieves the 32-bit ARGB value of the specified Color structure |
| ToKnownColor | Retrieves the KnownColor value of the specified Color structure |
| ToString | Converts the Color structure to a human-readable string |

The noteworthy properties of the Color structure are listed in Table 12.9:

**Table 12.9: Properties of the Color Structure**

| Property | Description |
|---|---|
| A | Retrieves the alpha component value of the Color structure |
| B | Retrieves the blue component value of the Color structure |
| G | Retrieves the green component value of the Color structure |
| IsEmpty | Specifies whether the Color structure is uninitialized |
| IsKnownColor | Retrieves a value indicating whether the specified Color structure is a predefined color |
| IsNamedColor | Retrieves a value indicating whether the specified Color structure is a named color or a member of the KnownColor enumeration |
| IsSystemColor | Retrieves a value indicating whether the specified Color structure is a system color |
| Name | Retrieves the name of the Color structure |
| R | Retrieves the red component value of the Color structure |
