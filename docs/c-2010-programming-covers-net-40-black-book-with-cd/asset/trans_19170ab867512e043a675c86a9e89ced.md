## 使用 DataTemplate 更改控件内容的显示

在 WPF 中，您可以使用 DataTemplate 模板来更改控件的数据类型的显示方式。这是通过使用 DataTemplate 模板的 DataType 属性完成的。该属性获取或设置在应用程序中需要使用 DataTemplate 模板的类型。例如，可能存在一种情况，您希望使用一个模板同时显示布尔值和字符串值。在这种场景下，DataType 属性非常有帮助。让我们使用 DataType 属性来更改控件的数据类型的显示方式。创建一个名为 UsingDataTemplate_ChangeAppearance 的 WPF 应用程序（可在 CD 中获得）并将代码添加到 MainWindow.xaml 文件中，如清单 10.24 所示：

**清单 10.24：显示使用 DataTemplate 的代码**

```xml
<Page
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:sys="clr-namespace:System;assembly=mscorlib">
    <Page.Resources>
        <DataTemplate DataType="{x:Type sys:Boolean}">
            <CheckBox IsChecked="{Binding Mode=OneWay}" />
        </DataTemplate>
    </Page.Resources>
    <ItemsControl Width="100" Height="100">
        <sys:Int32>30</sys:Int32>
        <sys:DateTime>12/16/1970</sys:DateTime>
        <sys:Boolean>False</sys:Boolean>
        <sys:Boolean>True</sys:Boolean>
        <sys:String>Hello</sys:String>
        <sys:Boolean>True</sys:Boolean>
    </ItemsControl>
</Page>
```

在清单 10.24 中，每个布尔值都显示为 CheckBox 控件，而不是显示为 True 或 False 值。这是通过 DataTemplate 的 DataType 属性实现的。

## 使用 ControlTemplate

ControlTemplate 模板指定可跨多个控件实例共享的控件结构。让我们在 WPF 应用程序中使用 ControlTemplate。创建一个名为 UsingControlTemplate 的 WPF 应用程序（可在 CD 中获得）并将以下代码添加到 MainWindow.xaml 文件中，如清单 10.26 所示：

**清单 10.26：显示实现 ControlTemplate 的代码**

```xml
<Window x:Class="UsingControlTemplate.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="MainWindow" Height="350" Width="525">
    <Window.Resources>
        <Style x:Key="ButtonStyle" TargetType="{x:Type Button}">
            <Setter Property="Template">
                <Setter.Value>
                    <ControlTemplate>
                        <Grid>
                            <Grid.RowDefinitions>
                                <RowDefinition Height="2*"/>
                                <RowDefinition Height="*"/>
                            </Grid.RowDefinitions>
                            <Rectangle RadiusX="4" RadiusY="8" Margin="2">
                                <Rectangle.Fill>
                                    <LinearGradientBrush StartPoint="0,0" EndPoint="0,1">
                                        <GradientStop Offset="0" Color="LightBlue"/>
                                        <GradientStop Offset="0.5" Color="Gold"/>
                                        <GradientStop Offset="1" Color="PaleGreen"/>
                                    </LinearGradientBrush>
                                </Rectangle.Fill>
                            </Rectangle>
                        </Grid>
                    </ControlTemplate>
                </Setter.Value>
            </Setter>
        </Style>
    </Window.Resources>
    <StackPanel>
        <Button Name="Button1" Height="41" />
        <Button Name="Button2" Height="41" />
        <Button Name="Button3" Style="{StaticResource ButtonStyle}" Height="71">TemplateButton</Button>
    </StackPanel>
</Window>
```

清单 10.26 向窗口添加了三个 Button 控件。未对前两个 Button 控件应用样式；而 ControlTemplate 模板应用于第三个按钮。通过按 F5 键运行应用程序。
