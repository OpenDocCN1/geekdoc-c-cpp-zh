# The SolidColorBrush Class

The SolidColorBrush class defines the brush of a single color. It is used to fill graphics shapes, such as rectangle, ellipse, polygons, and paths with a single color. You can define solid color by setting the Background attribute to a string that defines a solid color. You can paint an area with a solid color by using the predefined system brush, such as Red, Blue, or Yellow. You can add a SolidColorBrush object to your application by adding the following code:

```
<SolidColorBrush .../>
```

The inheritance hierarchy of the SolidColorBrush class is as follows:

```

```

# The LinearGradientBrush Class

The LinearGradientBrush class is used to create a brush that paints an area with linear gradient, a gradually shaded fill that changes from one color to another. It applies a smooth color change to the elements, and creates a blended fill. The LinearGradientBrush class defines the StartPoint and EndPoint properties. They assign the 2-D coordinates for applying the linear gradient. The default value of the StartPoint property is 0, and the EndPoint property is 1, which creates a diagonal gradient. These properties allow you to select the point where the first color begins to change and the point where the color change ends with the final color.
