
## Paging with DataAdapters

Paging in ADO.NET is the process of returning the results of a query in smaller subset of data or more specifically pages. You can use this practice for displaying results in small and easy to manage chunks. The DataAdapter provides a facility for returning only a page of data. The DataAdapter fills the DataSet with only the requested records. You need to use the startRecord parameter to return the first record in the page of data, and the maxRecords parameter for the number of records in the page of data. Let’s create an application, named PagingData (available in the CD-ROM), where you can apply paging of data with DataAdapters. Add a Button control and a DataGridView control and change Text property of the Button control to Load Page. Now, add the code, shown in Listing 24.7, on the Click Event of the Button control:

### Listing 24.7: Showing the Code for the Click Event of the Button Control

```
private void button1_Click(object sender, EventArgs e)
{
    int pageSize = 5;

    SqlConnection connection = new SqlConnection();
    connection.ConnectionString = "Data Source=umar-pc;Initial Catalog=Northwind;Integrated Security=True";
    connection.Open();
    string ordersSQL = "SELECT TOP " + pageSize + " * FROM Orders ORDER BY OrderID";
    SqlDataAdapter adapter = new SqlDataAdapter(ordersSQL, connection);
    DataSet DataSet = new DataSet();
    adapter.Fill(DataSet, "Orders");
    dataGridView1.DataSource = DataSet.Tables["Orders"];
}
```

When you run the application and click the Load Page button, you can see that only five records of the Order table are loaded. ## Updating with DataAdapters

You can update a data source with the help of DataAdapter. The Update() method of the DataAdapter is called to resolve changes from the DataSet back to the data source. When you call the Update() method, the DataAdapter analyzes the changes that have been made and executes the command. When the DataAdapter encounters a change to a DataRow, it uses the UpdateCommand to process the change. You must note that the Update() method is performed on a row basis. When an application calls the Update() method, the DataAdapter examines the RowState property and executes the required INSERT, UPDATE, or DELETE statement for each row. Let’s create an application, UpdatingData (available in the CD-ROM), where you can update the data with DataAdapter. For this, you first need to add a Button and a DataGridView control to Form1. A single DataSet can contain multiple tables. You need to create a single DataSet and add different tables to different DataGridView controls in your application. Now, add two DataGridView controls and two labels to Form1. After that, change the text of both the Label controls to Order Details Table and Orders Table, respectively and add the code, shown in Listing 24.9, on the Load event of the Form1:

### Listing 24.9: Showing the Code for the Load Event of the Form1

```
private void Form1_Load(object sender, EventArgs e)
{
    SqlConnection connection = new SqlConnection();
    connection.ConnectionString = "Data Source=umar-pc;Initial Catalog=Northwind;Integrated Security=True";
    connection.Open();
    DataSet ds = new DataSet();

    SqlDataAdapter dap = new SqlDataAdapter("select * from [Order Details]", connection);
    dap.Fill(ds, "[Order Details]");
    dataGridView1.DataSource = ds.Tables["[Order Details]"];

    SqlDataAdapter dap1 = new SqlDataAdapter("select * from Orders", connection);
    dap1.Fill(ds, "Orders");
    dataGridView2.DataSource = ds.Tables["Orders"];
}
```

## Using DataReader Work with Databases

You can retrieve the data in Windows application by using DataReader instead of DataAdapter. You can use the ExecuteReader to retrieve the rows from a data source. The Read() method of DataReader is used to obtain a row from the data source. There are different DataReaders for different data sources. For example, OleDbDataReader provides a way of reading forward only stream of data rows from OLE DB data provider. The SqlDataReader provides a way of reading forward only stream of data rows from an SQL Server data source. Let's create an application, named UsingDataReader (available in the CD-ROM), in which you can retrieve data from a data source using DataReader. For this, you first need to add Button, Label, TextBox, and ListBox controls to Form1. After adding the controls to Form1, change the text property of the Label control to Enter Text to Find, and the text property of the Button control to FIND.

Now, add the code, shown in Listing 24.11, on the Click event of the Button control:

### Listing 24.11: Showing Code for the Click Event of the Button Control

```
private void button1_Click(object sender, EventArgs e)
{
    SqlDataReader rdr = null;
    SqlConnection con = null;
    SqlCommand cmd = null;
    try
    {
        string ConnectionString = "Data Source=umar-pc;Initial Catalog=Northwind;Integrated Security=True";
        con = new SqlConnection(ConnectionString);
        con.Open();
        string CommandText = "SELECT FirstName, LastName" + " FROM Employees" + " WHERE (LastName LIKE @Find)";
        cmd = new SqlCommand(CommandText);
        cmd.Connection = con;
        cmd.Parameters.Add(new SqlParameter("@Find", System.Data.SqlDbType.Nvarchar, 20, "LastName"));
        cmd.Parameters["@Find"].Value = textBox1.Text;
        rdr = cmd.ExecuteReader();
        listBox1.Items.Clear();
        while (rdr.Read())
        {
            listBox1.Items.Add(rdr["FirstName"].ToString() + " " + rdr["LastName"].ToString());
        }
    }
    catch (Exception ex)
    {
        MessageBox.Show(ex.Message);
    }
    finally
    {
        if (rdr != null)
            rdr.Close();
        if (con.State == ConnectionState.Open)
            con.Close();
    }
}
```

NOTE
You need to modify the value of the ConnectionString property according to your computer configuration. You need to add the System.Data.SqlClient namespace in the Form1.cs file.
