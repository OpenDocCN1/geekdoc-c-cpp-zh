can be executed by a delegate, when it is called. The following code snippet shows how to define a named method:

```
// Declaring a delegate:
delegate void Delg(int a);

// Defining a named method:
void func(int n)
{
}
// Instantiating the delegate using the named method as a parameter:
Delg d = obj.func;
```

In the preceding code snippet, we have instantiated the delegate, Delg, by using the named method, func, as parameter. Now consider the following code snippet, where we instantiate the delegate using the anonymous method:

```
// Declaring a delegate
delegate void Delg(int a);

// Instantiating the delegate using an anonymous method
Delg d = delegate(int n) { };
```

In the preceding code snippet, we have minimized the coding overhead by eliminating the need for creating a separate method for instantiating a delegate. As a result, the code usability and code maintainability are enhanced.

Anonymous method enables you to pass a code block as a delegate parameter. You need to define an anonymous method in-line and not as a class member, while invoking a delegate. You can pass the anonymous method to only the method that has a delegate type parameter. The following code snippet shows how to pass the anonymous method as a delegate parameter:

```
void function()
{
    System.Threading.Thread th = new System.Threading.Thread
    (delegate()
    {
        System.Console.Write("Hi !");
        System.Console.WriteLine("How are u!");
    });
    th.Start();
}
```

In the preceding code snippet, we have created a thread that executes its code without creating an additional delegate method. The code block for starting the thread is passed as a delegate parameter. This code block acts as the anonymous method, which prevents you from writing a separate delegate method. You need to keep the following points in mind while working with anonymous methods:

+   - Do not use unsafe code in an anonymous method.

+   - Do not use statements that transfer the control outside the anonymous block, such as goto, break, or continue. Even if these statements transfer the program control inside the anonymous method, you cannot use these statements outside the anonymous method.

+   - Do not access the ref or out parameter of an outer scope using the anonymous method. The variables or parameters whose scope contains the anonymous method declaration are said to be in the outer scope of the anonymous method.

# Events

An event is a delegate type class member that is used by an object or a class to provide a notification to other objects that an event has occurred. Event, in itself, is an action that is generated by a user or a computer. In C# you can use events to keep objects notified of the current state of another object or condition. The event keyword can be used to declare an event, as shown in the following syntax:

```
Access-modifier event type event-name;
```
