A DataTemplate template describes the visual structure of a data object. This template is particularly useful when you are binding an Items control, such as a ListBox control, to an entire collection. Let's use a DataTemplate template in a WPF application. Create a WPF application named UsingDataTemplate (available in the CD) and add the following code to the MainWindow.xaml file, as shown in Listing 10.27:

    Title="MainWindow" Height="350" Width="525">
    <Window.Resources>
        <XmlDataProvider x:Key="myTasks" XPath="Tasks/Task">
