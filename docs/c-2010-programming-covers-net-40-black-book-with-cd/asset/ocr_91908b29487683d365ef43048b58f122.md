# Validating and Retrieving a User

We can validate the credentials of a user by using the membership feature in ASP.NET 4.0. The Membership.ValidateUser() method is used to validate the credentials of a member. This method takes the username and password as parameters and returns true, if the credentials are correct. You can also retrieve the information of a user by using the Membership.GetUser() method. We create a website and save it as ValidateUser (on the CD-ROM). Now, let’s create the website by performing the following steps:

+   1. Open the web.config file and add the following line of code:
+   <authentication mode="Forms"/>
+   2. Open the Web application and add two Web forms and name them as Default.aspx and Login.aspx.
+   3. Open the Source mode of the Default.aspx page and add the code, given in Listing 36.24, to add the required controls for the application:

# Listing 36.25: Showing the Code for the Code-Behind File of the Default.aspx Page

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Web;
using System.Web.UI;
using System.Web.UI.WebControls;
using System.Web.Security;
public partial class _Default : System.Web.UI.Page
{
    protected void Page_Load(object sender, EventArgs e)
    {
        Label1.Text = Convert.ToString(Membership.GetUser(User.Identity.Name));
    }
    protected void LinkButton1_Click(object sender, EventArgs e)
    {
        FormsAuthentication.SignOut();
        Response.Redirect("login.aspx");
    }
}
```
