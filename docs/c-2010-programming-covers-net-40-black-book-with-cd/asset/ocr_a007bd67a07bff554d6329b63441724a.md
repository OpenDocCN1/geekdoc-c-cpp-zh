# Creating a LINQ to SQL Application

LINQ to SQL is the component of .NET Framework that provides infrastructure for managing relational data as objects. You can retrieve the SQL data using LINQ. LINQ to SQL translates the SQL queries into an object model and sends them to database for execution. Let’s create an application, LINQtoSQL (available on the CD), in which you can work with LINQ to SQL.

# NOTE

> The applications in this chapter are created using the ASP.NET Empty Web Site template in the New Web Site dialog box. After creating the application, you need to add the Default.aspx page to the application.

Perform the following steps to create a LINQ to SQL application:

+   1. Right-click the application in Solution Explorer and select the Add New Item option from the context menu. This opens the Add New Item dialog box.
+   2. In this dialog box, select the LINQ to SQL Classes template and rename the file as MyClasses.dbml. Default name for the LINQ to SQL class is DataClasses.dbml.
+   3. Click the Add button, as shown in Figure 27.3:
