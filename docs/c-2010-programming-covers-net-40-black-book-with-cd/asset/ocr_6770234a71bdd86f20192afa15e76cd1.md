# Configuring Probing Settings Manually

If you already have the configuration file for Displayer.exe, that is, Displayer.exe.config, just place the highlighted information under the assemblyBinding tag to set probing configuration, as shown in Listing 33.15:

# Listing 33.15: Setting the Probing Property

```
<?xml version="1.0"?>
<configuration>
  <runtime>
    <gcConcurrent enabled="true" />
    <assemblyBinding xmlns="urn:schemas-microsoft-com:asm.v1">
      <publisherPolicy apply="yes"/>
      <probing privatePath="SubDir" />
    </assemblyBinding>
  </runtime>
</configuration>
```

TIP
You can add more than one search path separated with semicolons, such as SubDir; NewBin; MySub: for probing.

Try to run the Displayer application again, and click the Call Display button. You can see that the probing setting has taken effect now.

# Configuring Codebase Setting for Signed Assemblies

In this section, we use the SharedObject.dll assembly to add the codebase settings. Now, create a folder, called AnotherGAC, in any of the hard drives, say E. Move SharedObject.dll version 1.0.0.0 to this folder. Create another folder, NewGAC, in the E drive and move SharedObject.dll version 1.1.0.0 to this folder. Remove both versions of SharedObject.dll from the GAC.

Now, if you run ASimpleClient, an error is displayed regarding the missing configuration files, which implies that the application needs assembly look-up configuration to find the files. Let’s now see how the codebase settings handle a situation similar to this. We again explore this by using the configuration tool as well as manually.

# Using Configuration Tool to Configure Codebase Setting

Similar to configuring the probing setting, you can also configure the codebase setting in your application using the configuration tool. To configure the application, you need to add the application as well as the assembly to the configuration tool. Now, perform the following steps to add the application and assemblies to the tool:

+   1. Open the .NET Framework 2.0 Configuration tool and right click the Applications node.
+   2. Select the Add option from the context menu to display the Configure an Application dialog box.
+   3. Click the Other button and browse for ASimpleClient.exe and then click the Open button. This will add the ASimpleClient node in the .NET Framework Configuration 2.0 tool.
+   4. Right click the Configured Assemblies node under ASimpleClient and select the Add option.
+   5. Select the Choose an assembly from the list of assemblies this application uses radio button on the Configure an Assembly dialog box, and then click the Choose Assembly button.
+   6. Select SharedObject from the list, and then click the Select button.
+   7. Click the Finish button. This adds the assembly to the Configured Assemblies folder of our client application and opens the SharedObject Properties dialog box.

Now that the application and the assembly that need to be configured have been added to the tool, we can configure the codebase setting for them by performing the following steps:

+   1. Right click the SharedObject assembly that you have in Configured Assemblies folder of ASimpleClient and select the Properties option to display the SharedObject Properties dialog box, if it is not open already.
+   2. Select the Codebases tab.
