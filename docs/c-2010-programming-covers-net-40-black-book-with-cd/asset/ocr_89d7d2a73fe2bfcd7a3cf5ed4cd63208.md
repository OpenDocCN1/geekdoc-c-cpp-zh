The Registry editor is divided into two panes—the left pane is referred to as the Navigation pane containing hierarchical list of registry hives and the right pane is referred to as the Detail pane displaying the description of the registry hives. A registry hive is a collection of keys, sub keys, and values. You can add custom keys and values and set some properties for the sub keys and values in the Registry editor.

# File Types Editor

The File Types editor establishes association between files and applications. For example, when you double-click the file having the .doc extension, it opens in MS Word. To view the File System editor, click View→Editor→File Types. The File Types editor appears, as shown in Figure 21.3:

![](bbox=[0.271, 0.493, 0.804, 0.741])

To establish the association, all you need to do is just associate file extensions with your application and specify the actions allowed for each file type.

# User Interface Editor

The User Interface editor specifies properties for a set of predefined dialog boxes. It is helpful when you want to add extra information that is displayed during the installation process. The User Interface editor is divided into two sections, Install and Administrative Install. The Install section contains the dialog boxes that are displayed when the user runs the installer; whereas the Administrative Install section contains the dialog boxes that are displayed when the system administrator uploads the installer to a network location.
