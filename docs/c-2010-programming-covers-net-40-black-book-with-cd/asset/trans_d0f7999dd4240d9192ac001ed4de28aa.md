

## System.Windows.Media.Visual 类

System.Windows.Media.Visual 类是用于 WPF 应用程序中渲染元素的基类。Visual 类提供了与渲染相关的功能，例如裁剪、变换和边界框计算。您可以裁剪元素的区域，对元素应用变换，或验证某个点是否位于给定边界内。

Visual 类通过在 milcore 中生成一种树状结构，即合成树，作为托管 WPF 组件与非托管 milcore 组件之间的链接。您在 WPF 应用程序中使用的每个视觉元素可能对应于合成树中的零个或多个合成节点。每个合成节点都有各种外观相关属性和用于渲染元素的特定渲染指令。合成节点一次遍历一个，并在节点上执行渲染指令以合成并显示元素。请注意，合成树和节点只能通过消息协议访问。

WPF 使用保留模式渲染系统，即完整的合成树由 milcore 组件缓存。这意味着当任何合成节点发生变化时，只有更改才会被传达给 milcore 组件。这确保了屏幕的重绘更快且更优化。请注意，合成节点使用画家算法进行渲染，其中较远的节点先渲染，位于前方的节点后渲染。使用此算法，更容易、更快地渲染复杂而精细的视觉效果，例如半透明或透明视觉效果。

## System.Windows.UIElement 类

System.Windows.UIElement 类提供了在 WPF 4.0 应用程序中实现基本功能的 API。例如 WPF 元素的布局和事件。您可以使用 UIElement 类的属性和方法来操作 WPF 应用程序中视觉元素的布局。UIElement 类引入了一种易于使用且灵活的布局模型。

灵活的布局模型包含两个阶段，即 Measure 和 Arrange。您可以在 Measure 阶段确定 WPF 应用程序中 UI 元素的大小。元素的大小可以根据其他元素的大小和位置而被确定多次。在 Arrange 阶段，元素的最佳位置被确定。WPF 中的灵活布局模型使元素更容易改变其大小和位置，并为元素提供动态布局。UIElement 类还为 WPF 应用程序提供对事件、输入和命令绑定的支持。

> NOTE
> Visual 和 UIElement 类由 PresentationCore 程序集提供。

## System.Windows.FrameworkElement 类

System.Windows.FrameworkElement 类是 UIElement 类与 WPF 框架级实现元素之间的接口（您直接在 XAML 或代码隐藏文件中使用的元素）。FrameworkElement 类不仅包含 UIElement 类提供的功能，还提供额外的功能来增强 WPF 应用程序。FrameworkElement 类具有各种属性，可帮助您在 WPF 应用程序中对 WPF 框架级视觉元素统一灵活地应用布局和样式。它还提供支持以树的形式指定不同的视觉元素、动画和故事板、数据绑定以及事件。

FrameworkElement 类有多个派生类，允许您处理控件、多媒体和 3-D 内容。一些继承 FrameworkElement 类的类包括 Control、Panel 和 Shape 类。现在，让我们逐一探索这些类。

## System.Windows.Controls.Control 类

与 Windows Forms 类似，WPF 也有几个预定义的 UI 元素称为控件。大多数 WPF 控件都派生自 System.Windows.Controls.Control 类。例如，Label、Button、RadioButton 和 GroupBox 控件都派生自 Control 类。此类提供了多个属性来为控件添加背景和前景、视觉效果、边框和样式，以及更改字体。

除了用于操作控件外观的大量属性外，Control 类还为相同任务提供控件模板。控件模板（ControlTemplate 类的实例）定义了相应控件的外观、呈现和行为。您可以创建或修改控件模板以适当地更改控件的外观。

## System.Windows.Controls.Panel 类

在 WPF 4.0 中，您使用的所有控件都必须包含在面板中，面板是一种容器控件，可容纳其他控件。面板允许您调整面板包含的控件的布局和尺寸。所有面板都派生自 System.Windows.Controls.Panel 类。一些继承 Panel 类的面板包括 Grid、Canvas 和 StackPanel。

您可以根据需要使用特定面板。例如，您可以使用 Grid 面板以网格形式排列子控件，或使用 StackPanel 面板以直线水平或垂直放置子控件。面板继承 Panel 类的各种属性，以允许您更改包含或子控件的排列。属性可帮助您更改子控件的高度和宽度，适当对齐控件，并以分层方式放置控件。

> 要了解有关控件和面板的更多信息，请参阅第 10 章，使用 WPF 4.0 控件、资源、样式、模板和命令。

## System.Windows.Shapes.Shape 类

WPF 4.0 为开发 WPF 应用程序提供了广泛的 2-D 绘图支持。WPF 应用程序中经常使用的 2-D 绘图元素之一是形状。在 WPF 4.0 中，形状派生自 System.Windows.Shapes.Shape 类。Shape 类有多个派生类，例如 Ellipse、Line、Rectangle 和 Polygon，用于在 WPF 应用程序中绘制和操作不同形状。您可以使用 Shape 类的属性执行诸如用不同颜色填充形状、为形状添加轮廓或边框以及拉伸形状等活动。您将在第 12 章《在 Windows Forms 和 WPF 中使用图形和多媒体》中了解更多关于形状的内容。

## System.Windows.ContentElement 类

System.Windows.ContentElement 类存在于 PresentationCore 程序集中，并提供了一些iOS 核心级功能来处理 WPF 应用程序的内容。它负责内容的样式和呈现。它还提供诸如鼠标和键盘输入、可聚焦元素以及指示流内容各种更改的事件等功能。此外，它还提供了多个属性、方法和事件来处理动画和文本内容。

## 独立 WPF 应用程序

独立 WPF 应用程序类似于 Windows Forms 应用程序，即您可以将独立应用程序安装在客户端计算机上并在“开始”菜单中查看。本节我们将探讨 Visual Studio 2010 提供的项目模板，用于创建独立 WPF 应用程序。此外，我们还将了解用于创建 WPF 应用程序的不同文件。最后，我们将探讨用于创建 WPF 应用程序窗口的 Window 类。
