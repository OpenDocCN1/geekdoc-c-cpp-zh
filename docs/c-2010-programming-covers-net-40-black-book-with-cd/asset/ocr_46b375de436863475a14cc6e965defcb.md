# Using the Partitioning Operators

The Partitioning operators are useful to navigate easily in the application through your query. The Take and Skip clauses are the Partitioning operators used in LINQ. The Skip clause skips the specified number of elements from the input sequence starting from the beginning of the sequence, and returns the rest of the sequence. The Take clause returns the specified number of elements from the input sequence, from the beginning of the sequence. Let’s create an application in which you can use the Partitioning operators.
