# The ScaleTransform Class

The ScaleTransform class scales an object in the 2-D, x-y coordinate axes. You can use the ScaleTransform class to stretch or shrink the text horizontally or vertically. The ScaleX and ScaleY properties of the ScaleTransform class specify how much an object can be stretched or shrunk along the x-axis and y-axis, respectively. The inheritance hierarchy of the ScaleTransform class is as follows:

The SkewTransform class is mainly used to create the illusion of 3-D depth in a 2-D text. It stretches the coordinate space in a non-uniform manner.
