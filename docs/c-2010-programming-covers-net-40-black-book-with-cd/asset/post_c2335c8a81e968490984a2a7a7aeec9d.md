## Let's now learn about the synchronization

## Thread Synchronization

Synchronization is the process of coordinating the events and tasks in such a way that all the tasks are completed without the interference and interruption of other tasks. If a task uses a single independent object, then there is no need to synchronize the task; however, if a task uses a shared object, you need to synchronize the tasks to avoid multiple requests for accessing and using the same object by different threads. To understand the concept of synchronization in a better way, let's take an example where you and your friend share the same remote control of a television. You want to watch the news channel and record news while your friend wants to watch a movie and record it. When it is your turn, you switch to news channel, and then your time slice also ends. Now, you continue from your last action and start recording and so on. What will be the result? Neither of you will be able to do your intended tasks. In C# programming, the same situation occurs with multiple threads that try to access a single shared resource (object). In such case, the tasks assigned to threads must be synchronized in a way to ensure that the object is used by one thread at a time.

## Suspending a Thread

Unlike the Sleep() method, which pauses a thread for a specified amount of time, the Suspend() method permanently pauses a thread until it is resumed by the user. It means that the Suspend() method causes a thread to sleep for an infinite amount of time. The ThreadSuspend application (also available on the CD), shown in Listing 31.3, illustrates how to suspend a thread:

### Listing 31.3: Showing the Code of the ThreadSuspend Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading;
namespace ThreadSuspend
{
class Program
{
    static Thread FirstThread;
    static void Main(string[] args)
    {
        FirstThread = new Thread(FirstFunction);
        FirstThread.Name = "First Thread";
        FirstThread.Start();
        Console.WriteLine("Thread Started...\n");
        Thread.Sleep(200);

        //Suspending the FirstThread thread
        FirstThread.Suspend();
        Console.WriteLine("\nThread Suspended...");
    }
    public static void FirstFunction()
    {
        int number = 1;
        for (; number <= 25; number++)
        {
            int time = new Random().Next(25, 50);
            Console.WriteLine("{0} Slept for: {1} milliseconds", FirstThread.Name, time.ToString());
            Thread.Sleep(time);
        }
    }
}
}
```

In Listing 31.3, you can see that the FirstThread thread starts its execution and the FirstFunction() method generates a random number at every iteration, which is considered as the slept time of the thread. When the FirstThread thread reaches the total slept time of 200 milliseconds, then the program control is transferred to the Suspend() method, causing the thread to suspend for an infinite amount of time.
