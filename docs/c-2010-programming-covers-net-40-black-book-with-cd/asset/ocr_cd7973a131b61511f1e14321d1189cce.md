The authentication modes that are available for ASP.NET applications are:

+   - Anonymous authentication
+   - Windows authentication
+   - Forms authentication
+   - Passport authentication

Note that except for the passport authentication, all other authentication modes are supported by IIS 7.5 as well as ASP.NET. To allow authentication at the IIS-level, you need to use the IIS Manager and specify the desired authentication. If you want to allow authentication in the ASP.NET application, then you need to use an authentication provider. An authentication provider refers to the code module that contains the essential code to perform the desired authentication. ASP.NET offers authentication providers for Windows, Forms, and passport authentication; there is no authentication provider for anonymous authentication.

Now, let’s learn about these authentication modes one by one.

# Anonymous Authentication

Users that request an ASP.NET Web resource (for example, a Web page) are authenticated by default as anonymous users, that is, users with any random identity. When the users are authenticated as anonymous users, the process is referred to as anonymous authentication. In this type of authentication, credentials (user name and password) are not required to authenticate the user. This implies that any user attempting to access a Web resource is automatically authenticated, which is why anonymous authentication is useful when you want your ASP.NET application to be available to all the users or when you want better performance. Anonymous authentication provides least security and therefore, you need to be judicious about authenticating anonymous users for your ASP.NET applications.
