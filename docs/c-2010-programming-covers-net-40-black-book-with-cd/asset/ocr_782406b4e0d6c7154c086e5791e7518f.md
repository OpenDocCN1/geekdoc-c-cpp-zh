# Introducing Web Parts Controls

Web Parts controls refer to a set of controls that enable users to personalize their websites dynamically at runtime. With the help of these controls, users can personalize Web pages according to their preference by altering the content, behavior, and appearance of the Web pages. The changes made by one user can be applied either for a particular user or for all users of the website. Following activities can be performed through the Web Parts control:

+   Personalization of content – With the help of Web Parts control, you can personalize the content of a Web page, such as adding more content, removing existing content, or hiding content.

+   Personalization of page layout – Changing the appearance, behavior, or properties of a Web Parts control and drag it to a different zone or region on a Web page.

+   Connection creation – Maintaining connections between two Web Parts controls through a Web Parts control.

+   Exporting and importing of controls – Importing or exporting a Web Parts control along with its appearance settings and data to other Web pages to reduce re-configuration at the user end.

+   Personalization of site-level settings – Setting the site-level settings and giving accessibility rights to selected users based on their roles. This action could be performed only by an authenticated user.

Here, you learn about the display modes of a Web page that has Web Parts controls. You also learn about the individual Web Parts controls – WebPartManager, ProxyWebPartManager, WebPartZone, CatalogZone, and EditorZone controls. Let’s begin with the display modes of a Web Parts page.
