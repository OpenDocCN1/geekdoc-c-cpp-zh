# The RadioButtonList Control

The RadioButtonList control displays data as a column of radio buttons and provides you with an easy way to display a single selection in the radio button group. The RadioButtonList control exists within the System.Web.UI.WebControls namespace. One useful aspect of this control is that the list of radio buttons can be generated at runtime through data binding. To determine the item which is selected in a RadioButton control, you can test the SelectedItem property of the list. You can also determine the index of the selected item with the SelectedIndex property. The inheritance hierarchy of the RadioButtonList class is as follows:

```
System.Object
    System.Web.UI.Control
        System.Web.UI.WebControls.WebControl
            System.Web.UI.WebControls.BaseDataBoundControl
                System.Web.UI.WebControls.DataBoundControl
                    System.Web.UI.WebControls.ListControl
                        System.Web.UI.WebControls.RadioButtonList
```

The RadioButtonList class is also inherited from the ListControl class. Noteworthy public properties of the RadioButtonList class are listed in Table 14.20:

| Table 14.20: Noteworthy Public Properties of the RadioButtonList Class |
| Property | Description |
| CellPadding | Obtains or sets the distance between the border and the contents of the table cell in pixels |
| CellSpacing | Obtains or sets the distance between the table cells and the radio buttons in pixels |
| RepeatColumns | Obtains or sets the number of columns to display in the RadioButtonList control |
| RepeatDirection | Obtains or sets the direction in which the radio buttons within the group are displayed |
| RepeatLayout | Obtains or sets the layout of radio buttons within the group |
| TextAlign | Obtains or sets the text alignment for the radio button caption |

NOTE

In ASP.NET 4.0, the RadioButtonList and the CheckBoxList control has been improved. In the previous version of ASP.NET, you could specify the layout for the controls by specifying either of the following two values for the RepeatLayout property:

+   - Table: Specifies that the items are displayed in a table structure.
+   - Flow: Specifies that the items are displayed without a table structure. The markup code consists of the span element and the various items are separated by the br element.

Now, in ASP.NET 4.0, two new values can be specified for the RepeatLayout property:

+   - UnorderedList: Specifies that the items are displayed without a table structure. The markup code consists of the ul element which contains the li element.
+   - OrderedList: Specifies that the items are displayed without a table structure. The markup code consists of the ol element which contains the li element.

You should note that if you set the RepeatLayout property to either OrderedList or UnorderedList, you cannot use the RepeatDirection property. If you set the RepeatDirection property in such a situation, it will throw an exception at runtime.

You will learn about the usage of the new values of the RepeatDirection property in the Immediate Solutions section of the chapter.
