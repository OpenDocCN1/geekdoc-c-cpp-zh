# FTP

FTP enables you to not only store but also code your applications, which reside on a server. For that, you must have the credentials to attach to the FTP server and permissions to read and write to the FTP location. You can also use the FTP features, such as exchanging and manipulating files over any Transfer Control Protocol (TCP).
