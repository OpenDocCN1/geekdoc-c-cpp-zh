# The TreeView Control

Yet another interesting control that has been introduced with Silverlight 3.0 is the TreeView control that used to be a part of Silverlight 2.0 Toolkit. A TreeView control has a structure similar to that of a tree and can be used to display hierarchical data in the form of nodes. A node that contains child nodes in a TreeView control can be collapsed and expanded as well. You can click on any node of a TreeView control to collapse it or expand the node to reveal its child nodes. The TreeView control is a specialized ItemsControl, which means that you can populate the TreeView control with some content by either setting its Items or ItemsSource properties.
