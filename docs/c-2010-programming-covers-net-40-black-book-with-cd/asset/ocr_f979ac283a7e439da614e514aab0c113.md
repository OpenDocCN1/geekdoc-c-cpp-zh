# Hosting WCF Services in Windows Services

Hosting a WCF service in a Windows service requires registering the application domain (AppDomain) that hosts a WCF service as a managed Windows service on a server so that Service Control Manager (SCM) controls the process lifetime of the WCF service. Now, let’s perform the following steps to host a WCF service in a Windows service:

+   1. Create a console application named WinServiceHost (also available on the CD ROM).
+   2. Right-click the name of the WinServiceHost application and select Add→New Item from the context menu. The Add New Item dialog box appears.
+   3. Select the WCF Service template and enter the name of the service as TimeService in the Name text box of the Add New Item dialog box.
+   4. Click the Add button to create the application. The TimeService.cs, ITimeService.cs, and App.config files are added to the WinServiceHost application. In addition, references to the System.ServiceModel and System.Runtime.Serialization classes are also included in the application.
+   5. Open the ITimeService.cs file and add the following code snippet in the ITimeService interface:
+   [OperationContract]
+   string GetCurrentTime();
+   6. Open the TimeService.cs file and add the following code snippet in the TimeService class:
+   public string GetCurrentTime()
+   {
+       string CurrentTime = DateTime.Now.Hour + ":" + DateTime.Now.Minute + ":" + DateTime.Now.Second;
+       return CurrentTime;
+   }
+   7. Open the Add New Item dialog box again and add the Windows Service template in the WinServiceHost application. In our case, the name of the Windows service is Service1.cs, as shown in Figure 19.24:
