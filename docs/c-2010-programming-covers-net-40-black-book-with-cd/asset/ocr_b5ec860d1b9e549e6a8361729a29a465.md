# Using the PasswordBox Control

The PasswordBox control is a special kind of Textbox control, which displays the text entered by the user in an encrypted format. Let’s add a PasswordBox control to a WPF application through the XAML code. Create a WPF application named PasswordBoxControl (available in the CD) and add the code, shown in Listing 10.10, to the MainWindow.xaml file:

# Listing 10.10: Showing the Code to Implement the PasswordBox Control

```
<Window x:Class="PasswordBoxControl.MainWindow"
xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
Title="MainWindow" Height="350" Width="525">
<Grid>
<Border Background="PeachPuff" CornerRadius="25"/>
<Label Height="28" HorizontalAlignment="Left" Margin="10,10,0,0" Name="label1" VerticalAlignment="Top" Width="120">Enter you Name</Label>
<Label Height="28" HorizontalAlignment="Left" Margin="10,48,0,0" Name="label2" VerticalAlignment="Top" Width="120">Enter Password</Label>
<TextBox Height="23" HorizontalAlignment="Right" Margin="0,12,14,0" Name="textBox1" VerticalAlignment="Top" Width="120" />
<PasswordBox HorizontalAlignment="Right" Margin="0,53,14,0" Name="passwordBox1" Width="120" Height="23" VerticalAlignment="Top" MaxLength="10" PasswordChar="*"/>
<Button Height="23" Margin="84,0,119,103" Name="button1" VerticalAlignment="Bottom">Submit</Button>
</Grid>
</Window>
```

In Listing 10.10, a PasswordBox control is added to the window. You can set the maximum number of characters to enter in the PasswordBox control by using the MaxLength property of the control. You can change the characters that appear in the PasswordBox control by setting the PasswordChar property. By default, a black dot appears in the box (*); however, you can also change this setting. In our case, the character of the PasswordBox control is set to an asterisk (*). Now, run the application by pressing the F5 key.
