# Configuration of WCF Services

You can configure a WCF service by using the configuration files, which contain the configuration information of WCF services in the XML format. The XML elements inside these files allow you to modify the configuration details, such as the endpoint address of the WCF service, on machine-by-machine basis. WCF also includes some system-defined elements that allow you to rapidly select the most fundamental features for a WCF service. When you deploy your WCF service, the configuration files provide you the flexibility of presenting the endpoint and service behavior data. You can change the configuration of the WCF service using the web.config file or the WCF Editor Configuration tool.

# Using the web.config File

You can use either the web.config or app.config file to configure WCF services. The choice of the configuration file (web.config or app.config) to configure WCF services depends on the hosting environment that you select for your WCF service. If your hosting environment is IIS, you can use the web.config file, and if your hosting environment is other than IIS, use the app.config file. Listing 19.4 shows the major elements of the web.config file:

# Listing 19.4: Showing the Major Elements of the web.config File

```
<system.serviceModel>
  <services>
    <service>
      <endpoint/>
    </service>
    <service>
      <endpoint/>
    </service>
  </services>
  <bindings>
    <binding>
      <!--system-provided binding or a custom binding-->
    </binding>
    <binding>
      <!--system-provided binding or a custom binding-->
    </binding>
  </bindings>
  <behaviors>
    <behavior>
      <!--system-provided behavior or a custom behavior-->
    </behavior>
    <behavior>
      <!--system-provided behavior or a custom behavior-->
    </behavior>
  </behaviors>
</system.ServiceModel>
```

The <bindings> and <behaviors> elements are optional.
