# Using the DetailsView Control

Now, let’s use a DetailsView control to display the data from a database by performing the following steps:

+   1. Create an application and save it as DetailsViewControl (available on the CD).
+   2. Drag and drop DetailsViewControl on the Design view of the Default.aspx page and select the New data source option from the Choose Data Source drop-down list, as shown in Figure 26.60:

![](bbox=[0.275, 0.064, 0.795, 0.4])

Figure 26.59: Displaying the Output of the DataListControl Application

![](bbox=[0.205, 0.533, 0.83, 0.725])

Figure 26.60: Selecting the Data Source

The Configure Data Source Wizard appears.

+   3. Create a connection of the DetailsView control with the database. In this case, we are creating the connection with the Products table of the northwnd database.

# NOTE

> You can refer to the GridViewControl application for the steps of creating connection with the database.

+   4. Click the Smart Tag of the DetailsView control and select the Auto Format link. The AutoFormat dialog box appears which can be used to apply colorful layout on the DetailsView control.
+   5. Select the Slate option from the Select a scheme pane and click the OK button.
+   6. Select the Enable Paging check box to provide paging in the control.
