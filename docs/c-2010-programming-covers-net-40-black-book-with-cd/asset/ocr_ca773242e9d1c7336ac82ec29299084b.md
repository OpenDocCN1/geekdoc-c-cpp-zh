You can see from Figure 9.14 that the Design view itself has several UI elements that assist you in quickly designing WPF applications. For instance, it contains Zoom control to zoom in or out of the Design view, move and resize handles to appropriately position and resize the controls, and margin lines to set the margins of a control. Let’s briefly go through the elements of the Design view.

# Grid Rails, Gridlines, and Gridline Indicators

The grid rails, gridlines, and gridline indicators pertain to the Grid element or control of WPF. When you create a WPF application, a Grid element is by default added to the application. As the name suggests, the Grid element allows you to represent the WPF application as a grid or lattice. The entire grid is enclosed by grid rails that span horizontally and vertically on the top and left respectively, as shown in Figure 9.14.

By default, the grid has one row and one column; however, there can be multiple rows and columns. You can create additional rows and columns by clicking the desired positions on the grid rails. When you click the grid rails, gridlines and gridline indicators appear accordingly (Figure 9.14). If you click the grid rail on the top, then a vertical gridline appears dividing the grid into two columns. Similarly, if you click the grid rail on the left, then a horizontal gridline appears dividing the grid into two rows. You can click the gridrails as many times as you want to create rows and columns in the grid. You can control the height and width of the rows and columns by moving the gridline indicators that appear as triangles on grid rails.

> NOTE
> There is a property named FlowDirection for the Grid control. This property, by default, is set to LeftToRight. However, when this property is set to RightToLeft, it causes the grid rails to appear on the top and right of the window.

# Zoom Control and Fit in View Button

You can find the Zoom control and the Fit in View button at the upper-left corner of the Design view. The Zoom control allows you to zoom in and zoom out the Design view. You can zoom in up to 20x and zoom out up to 10%. You can zoom in or out by dragging the Zoom control slider up or down. The current zoom level, which in Figure 9.15 is 80%, can be seen on top of the zoom controls.
