## 禁用和启用 Windows 窗体

你可以设置 Windows 窗体的各种属性来在应用程序中执行操作。例如，你可以设置属性来启用或禁用 Windows 窗体。这可以通过使用窗体的属性窗口来完成，也可以通过在代码编辑器窗口中编写代码来完成。图 8.6 显示了如何使用属性窗口来启用或禁用 Windows 窗体：

![](img/e073a4882197be4ab61103cbe0bcb394_304_1.png)

# 图 8.6：显示 Windows 窗体的属性窗口

要禁用 Windows 窗体，你需要在窗体的属性窗口中将 Enabled 属性设置为 False。同样，你可以通过将 Enabled 属性设置为 True 来启用已禁用的 Windows 窗体。默认情况下，Windows 窗体的 Enabled 属性为 True。

让我们创建一个名为 DisableEnableWindowsForm 的 Windows 窗体应用程序。向 Form1 添加一个按钮控件，并将其 Text 属性更改为 Click Me to Disable this Form 文本，如图 8.7 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_305_0.png)

# 图 8.7：显示 DisableEnableWindowsForm 应用程序的设计视图

在 button1 的 Click 事件中添加以下代码片段，使用其 Enabled 属性禁用 DisableEnableWindowsForm 应用程序的 Form1：

```
private void button1_Click(object sender, EventArgs e)
{
    this.Enabled = false;
}
```

现在，当你单击 Click Me to Disable this Form 按钮时，窗体将被禁用，如图 8.8 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_305_1.png)

# 图 8.8：显示已禁用的 Windows 窗体

## 设置 Windows 窗体的边框

你可以通过在属性窗口中设置 FormBorderStyle 属性或在代码编辑器窗口中编写代码来设置 Windows 窗体的边框。FormBorderStyle 属性的可能值在表 8.4 中给出：

表 8.4：窗体边框样式

| 值 | 描述 |
|---|---|
| Fixed3D | 指定固定的三维边框 |
| FixedDialog | 指定厚实的固定对话框样式边框 |
| FixedSingle | 指定固定的单线边框 |
| FixedToolWindow | 指定不可调整大小的工具窗口边框 |
| None | 不为窗体指定边框 |

表 8.4：窗体边框样式

| 值 | 描述 |
|---|---|
| Sizable | 指定可调整大小的边框 |
| SizableToolWindow | 指定可调整大小的工具窗口边框 |

图 8.11 显示了使用 FormsBorderStyle 属性的 Fixed3D 值将 Windows 窗体的边框更改为 Fixed3D：

![](img/e073a4882197be4ab61103cbe0bcb394_307_0.png)

图 8.11：更改窗体的边框样式

以下代码片段显示了如何设置 Windows 窗体的边框样式：

```
private void Form1_Load(object sender, EventArgs e)
{
    this.FormBorderStyle = FormBorderStyle.Fixed3D;
}
```

在前面的代码片段中，我们将 Form1 的边框样式更改为 Fixed3D 样式（图 8.11）。你可以在 CD 提供的 FormBorder 应用程序中找到更改 Windows 窗体边框的代码。

## 指定 Windows 窗体的初始位置

你可以使用窗体的 StartPosition 属性来指定窗体在屏幕上的初始位置。FormStartPosition 枚举的值被分配给 StartPosition 属性。FormStartPosition 枚举的值在表 8.5 中给出：

表 8.5：FormStartPosition 枚举的值

| 值 | 描述 |
|---|---|
| CenterParent | 在其父窗体的边界内为窗体提供居中位置 |
| CenterScreen | 使用 Size 属性指定的窗体尺寸为窗体提供居中位置 |
| Manual | 使用其 Location 和 Size 属性确定窗体的起始位置 |
| WindowsDefaultBounds | 为窗体提供 Windows 界面的默认位置以及 Windows 的默认边界 |
| WindowsDefaultLocation | 为窗体提供 Windows 界面的默认位置以及窗体的 Size 属性的尺寸 |

你可以通过使用 Form1 的属性窗口来设置所有这些位置，如图 8.13 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_308_0.png)

图 8.13：显示 Windows 窗体的属性

你也可以通过在 Form1_Load 事件中编写代码来设置 Windows 窗体的初始位置，如以下代码片段所示：

```
private void Form1_Load(object sender, EventArgs e)
{
    this.StartPosition = FormStartPosition.CenterParent;
}
```

在前面的代码片段中，我们将窗体的位置设置为 CenterParent。
