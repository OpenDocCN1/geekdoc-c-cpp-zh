# The MediaElement Control

In some cases, you may want to include a media file and play it in an application. In such cases, you can include the media in the current project; however, you also need the functionality to play the media. Silverlight offers the MediaElement control that provides such functionality. The MediaElement control allows you to add media in the Silverlight applications. You can use the MediaElement control to add video or audio or both in the application. The MediaElement control provides you with a rectangular area to display the video or play the audio. Note that this rectangular area does not have any buttons to play, pause, or stop the playback of the media. However, you can use the properties, methods, and events of the MediaElement class to define the functionality to manipulate the playback of the media in the MediaElement control.
