# About this book

This book consists of seven parts, which are as follows:

+   - Part I – .NET Framework 4.0 and Visual Studio 2010 – Describes the essentials and basic concepts of .NET Framework 4.0 and Visual Studio 2010.

+   - Part II – C# Programming Language – Describes the fundamental concepts of C# language, such as variable declaration, flow controls, exception handling, and dynamic datatype.

+   - Part III – Windows Forms and Windows Presentation Foundation (WPF) – Describes the fundamentals of Windows Forms and WPF and how to create their applications

+   - Part IV – ASP.NET 4.0 and Silverlight – Explains how to create Web applications and websites using ASP.NET and Silverlight technologies

+   - Part V – Services and Deployment – Explains how to create various types of services, such as Web services and WCF services, and how to deploy applications in Visual Studio 2010

+   - Part VI – Interacting with Database in C# 2010 – Explains how to create SQL objects, such as stored procedures and triggers in .NET Framework and how to access data from a database in .NET applications including ADO.NET and LINQ
