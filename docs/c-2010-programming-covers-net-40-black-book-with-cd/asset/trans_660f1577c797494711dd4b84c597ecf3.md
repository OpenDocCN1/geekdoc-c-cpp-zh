### 在 MediaElement 中转换视频

在 WPF 中，你可以转换 MediaElement 控件，这意味着你可以旋转 MediaElement 控件以按所需角度显示视频。你可以使用 TransformGroup 类，通过 RotateTransform 或 ScaleTransform 类分别对 MediaElement 控件应用旋转和缩放转换。让我们创建一个应用程序来对 MediaElement 控件应用旋转转换。你应该创建一个名为 TransformingVideo 的 WPF 应用程序（也在 CD 上提供）并将 Listing 12.53 中给出的代码添加到 MainWindow.xaml 文件中：

**Listing 12.53:** 在 MediaElement 中转换视频

```
<Window x:Class="TransformingVideo.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="350" Width="525">
    <Grid>
        <MediaElement Source="d:\wmvfiles\Clip_1080_5sec_vc1_15mbps.wmv" Margin="41,0,27,36" Name="myMedia" LoadedBehavior="Manual">
            <MediaElement.LayoutTransform>
                <TransformGroup>
                    <RotateTransform Angle="400" />
                </TransformGroup>
            </MediaElement.LayoutTransform>
        </MediaElement>
        <Button Height="23" Margin="104,0,99,18" Name="button1" VerticalAlignment="Bottom" Click="button1_Click">Play</Button>
    </Grid>
</Window>
```

在 Listing 12.53 中，MediaElement 控件已添加到窗口中。MediaElement 控件已添加到应用程序中，该控件使用 RotateTransform 类进行转换。Button 控件已添加到应用程序中，并在 Button 控件的 Click 事件上添加了代码以播放媒体文件。Button 控件的 Click 事件代码在 Listing 12.54 中给出：

### In Depth

自 .NET Framework 1.0 发布以来，Microsoft 一直在持续努力开发和改进 ASP.NET，该技术是 .NET Framework 的一部分，用于构建丰富的 Web 应用程序。此次首发在构建网站时，相较于使用服务器端脚本引擎 Active Server Pages (ASP) 的旧 Microsoft 技术，带来了根本性的变化。尽管 ASP.NET 相较于 ASP 具有许多优势，但由于其复杂性和构建应用程序所需的知识，新程序员发现开始使用 ASP.NET 存在困难。

在 2002 年首次发布后，名为 .NET 1.1 的另一个版本的 .NET Framework 与 Visual Studio 2003 一起发布。大多数人认为此版本只是首次发布的服务包，尽管它在框架和开发环境方面也有新的改进。

后来在 2005 年 11 月，Microsoft 发布了 Visual Studio 2005，其中集成了 ASP.NET 2.0。再次，Microsoft 在此版本中做出了大幅改进，并降低了初始版本的复杂性。此新版本具有许多新的向导和控件，减少了构建应用程序所需的代码量，从而提高了生产力。

现在，Microsoft 的最新发布是 ASP.NET 4.0，其中包含用于创建基于 Web 的应用程序的新功能。

本章探讨 ASP.NET 4.0 的新功能、ASP.NET 的生命周期、其编译过程、ASP.NET 4.0 编码模型以及 ASP.NET Web 页面的语法。

让我们开始探索 ASP.NET 4.0，从其新功能开始。

### New Features in ASP.NET 4.0

ASP.NET 4.0 于 2010 年 4 月 12 日与 Visual Studio 2010 一起发布。它使用与 ASP.NET 3.5 相同的引擎，并具有一些附加功能。ASP.NET 4.0 简化了构建网站的过程，使其比以往更容易。现在让我们讨论添加到 ASP.NET 4.0 的以下新功能：

- ASP.NET 核心服务
- ASP.NET Web 表单
- 动态数据
- ASP.NET 图表控件
- Microsoft AJAX 功能
- 对基于 MVC 的 Web 应用程序的支持
- 改进的 CSS 能力

### ASP.NET Core Services

ASP.NET 4.0 核心服务包括输出缓存和会话状态存储等功能。ASP.NET 核心服务的优点如下：

- **web.config 文件的重构** – 规定在此版本的 ASP.NET 中，web.config 文件的主要配置元素已移至 machine.config 文件。这意味着在此新版本的 ASP.NET 中，web.config 文件为空或仅包含一些基本代码，该代码指定应用程序所针对的 Visual Studio Framework 版本。这是因为随着 ASP.NET 中 AJAX、路由和与 IIS 7.0 集成等新功能的加入，配置或启动新 Web 应用程序的过程变得困难。因此，主要配置设置已移至 machine.config 文件，以便应用程序可以继承设置并无困难地运行。
- **输出缓存** – 使你能够配置一个或多个输出缓存提供程序。ASP.NET 中的输出缓存功能使开发人员能够将控件和 HTTP 响应的生成输出存储在内存中。这非常有帮助，因为在后续 Web 请求的情况下，内容可以从输出中检索。然而，输出缓存功能在 ASP.NET 的早期版本中并不实用，因为在服务器重负载的情况下，用于输出缓存的内存可能会影响功能
