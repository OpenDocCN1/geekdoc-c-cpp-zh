## 深入解析

在上一章中，您已经学习了如何创建Web应用程序。现在，让我们来讨论Web窗体控件。Web窗体控件被设计为类似于标准的Windows窗体控件。这些控件用于设计任何Web应用程序的界面，例如，当您访问Google网站时，您会在文本框中输入搜索查询，而文本框就是一种控件。ASP.NET提供了一套标准控件，可用于开发Web应用程序。您可以从Visual Studio集成开发环境（IDE）的“工具箱”中访问所有这些控件。只需将这些控件拖放到Web窗体上的任意所需位置即可轻松使用它们。根据其执行的任务，这些控件被分组到称为“选项卡”的不同类别下。例如，用于验证数据的控件放置在“验证”选项卡下，用于登录网站的控件放置在“登录”选项卡下。类似地，用于常见用途的控件放置在“标准”选项卡下，称为标准控件。所有这些控件都属于Control类。Web服务器控件基于WebControl类，而WebControl类又基于Control类。换句话说，WebControl类是从Control类派生的。

在本章中，您将学习文本框、标签、超链接、HiddenField、RadioButton和CheckBox等不同的服务器控件。

让我们首先了解Control类。
