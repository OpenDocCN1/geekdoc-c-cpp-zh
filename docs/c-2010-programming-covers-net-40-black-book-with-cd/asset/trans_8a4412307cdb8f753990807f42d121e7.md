## Obtaining Member Information from a Class

如果您有权访问包含一个或多个类的程序集，您可以找出该类中包含的方法和属性。此信息很有用，例如，如果您有一个包含您想要使用的类的 DLL，但您不确定如何使用它们。使用反射技术和方法，您可以检查程序集中的每个类并了解您需要了解的有关该类的任何信息。实际上，唯一无法完成的任务是检索软件开发人员在编写类时创建的原始注释。

在本节中，我们使用 ObtainMemberInformation.cs 和 EventTestClass.cs 文件（已在清单 34.2 中给出）来展示一个简单的程序，该程序使用反射来检查类的成员和方法。您可以看到 C# 在实现反射方面是一致的。您只需调用 Get<> 例程，其中 <> 是您感兴趣的反射信息部分，无论是方法、属性还是参数。此例程返回一个 <>Info 对象数组，其中包含有关该类型中每个单独元素的进一步信息。请注意，所有返回的信息都可以通过 for...each 循环访问。

## Listing 34.3: Showing the Code for Obtaining Member Information from a Class

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Reflection;
namespace ObtainMemberInformation
{
    class Program
    {
        static void Main(string[] args)
        {
            if (args.Length > 0)
                ShowClasses(args[0]);
            Console.ReadLine();
        }
        public static void ShowMethods(Type t)
        {
            MethodInfo[] methods = t.GetMethods();
            foreach (MethodInfo m in methods)
            {
                Console.WriteLine("\nMethod Name: {0}", m.Name);
                Console.WriteLine("Return Type: {0}", m.ReturnType);
            }
        }
        public static void ShowProperties(Type t)
        {
            PropertyInfo[] props = t.GetProperties();
            foreach (PropertyInfo p in props)
            {
                Console.WriteLine("\nProperty Name: {0}", p.Name);
                Console.WriteLine("Type: {0}", p.MemberType);
            }
        }
        public static void ShowClasses(string name)
        {
            Assembly assembly = Assembly.LoadFrom(name);
            if (assembly != null)
            {
                // Get the classes from the assembly
                Type[] typeArray = assembly.GetTypes();
                Console.WriteLine("Assembly Name: {0}", name);
                foreach (Type type in typeArray)
                {
                    if (type.IsClass)
                    {
                        Console.WriteLine("Class: {0}", type.FullName);
                        ShowMethods(type);
                        ShowProperties(type);
                    }
                }
            }
        }
    }
}
```
