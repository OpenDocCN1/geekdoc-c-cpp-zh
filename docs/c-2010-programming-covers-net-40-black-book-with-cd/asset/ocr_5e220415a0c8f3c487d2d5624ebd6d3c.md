The ProgressBar control has indicators that display the position of the attached operation in progress so that one can calculate how long it will take for the operation to complete. By default, the ProgressBar control shows a green pulse that moves from left to right until the attached operation is completed.

The ProgressBar control is represented by the ProgressBar class. The inheritance hierarchy of the ProgressBar class is as follows:

# The Slider Control

The Slider control allows a user to select from a range of values by moving the Thumb control. A good example of a Slider control is the volume control in a media player. You can set the volume in the media player by dragging the Thumb control on the slider bar. You can drag the control either from left to right to increase the volume or from right to left to decrease the volume. The Slider control is an interactive control. You can adjust the value of a Slider control by using the Thumb control.

The Slider control is represented by the Slider class. The inheritance hierarchy of the Slider class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
```
