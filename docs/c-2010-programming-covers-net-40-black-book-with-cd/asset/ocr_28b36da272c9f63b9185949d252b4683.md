# Calling the WCF Service

In the previous sections, you have learned about different hosting options through which you can host your WCF service. If you use your WCF service on the client-side, you can use the Svcutil.exe tool that generates proxy classes to call WCF services. To call a WCF service, you need to create and configure a client. With the help of this client you can call the operations of the WCF service. Now, let’s first learn about creating the WCF client.

# Creating a WCF Client

A WCF client is an application that calls a WCF service. Let’s perform the following steps to create a WCF client:

+   1. Open Microsoft Visual Studio 2010.
+   2. Select File→New→Web Site to open the New Web Site dialog box.
+   3. Select the ASP.NET Web Site template from the Templates section of the New Web Site dialog box, and enter the name of the website, MyFirstWCFClient (also available on the CD), and its location in the Web location combo box.
+   4. Click the OK button to create a new WCF client, as shown in Figure 19.36:
