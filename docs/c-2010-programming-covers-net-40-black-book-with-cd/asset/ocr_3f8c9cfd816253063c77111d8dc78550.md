# Table 2.6: Showing the Operators in C#

| Category | Operators | Description |
|---|---|---|
|  | --x | Decreases the value of its operand (x) by 1. It first decreases the value of x by 1 and then assigns the decreased value to it. |
|  | true | Returns the Boolean value true, indicating an expression satisfies the specified condition. |
|  | false | Returns the Boolean value true, indicating an expression does not satisfy the specified condition. |
|  | & | Returns the address of its operand. |
|  | sizeof | Returns the size of value types in bytes. |
| Multiplicative | * | Computes the product of its operands. |
|  | / | Computes the division of its operands by dividing the first operand by the second operand. |
|  | % | Computes the remainder of its operands after dividing the first operand by the second. |
| Additive | + | Computes the sum of its operands. |
|  | - | Computes the difference of its operands. |
| Shift | << | Shifts its first operand left by a number of bits specified by the second operand. The number of bits should be an integer value. |
|  | >> | Shifts its first operand right by a number of bits specified by the second operand. The number of bits should be an integer value. |
| Relational and type testing | < | Finds out whether the first operand is less than the second operand. It returns true if the condition satisfies; otherwise, it returns false. |
|  | > | Finds out whether the first operand is larger than the second operand. It returns true if the condition satisfies; otherwise, returns false. |
|  | <= | Finds out whether the first operand is less than or equal to the second operand. It returns true if the condition satisfies; otherwise, it returns false. |
|  | >= | Finds out whether the first operand is larger than or equal to the second operand. It returns true if the condition satisfies; otherwise, it returns false. |
|  | is | Checks the compatibility of a variable with a given type. |
|  | as | Converts a value to a given reference type. |
| Equality | == | Checks whether the two expressions are same or not. It returns true if the expressions are equal; otherwise, it returns false. |
|  | != | Checks whether the two expressions are same or not. It returns true, if the expressions are not equal; otherwise, it returns false. |
| Logical AND | & | Computes the logical AND of its Boolean operands. For integral operands, & compares the corresponding bits of two integrals and computes the logical bitwise AND of the operands. It returns true if and only if both its operands are true. |
| Logical XOR | ^ | Computes the logical exclusive-OR of its Boolean operands. It returns true if only one of its operands is true. |
