# Table 1.4: Tabs Displayed in Toolbox for Windows Forms Projects

| Tab | Description |
|---|---|
| Components | Contains components that do not have a user interface, such as the Timer and the ErrorProvider components. |
| Printing | Contains controls that help in providing printing capabilities to your Windows Forms projects. |
| Dialogs | Contains controls that help you in using common dialog boxes in your application, such as the SaveFileDialog, FolderBrowserDialog, and FontDialog controls. |
| WPF Interoperability | Contains a control that can be used to host a WPF element. |
| Reporting | Contains controls for providing reporting services, such as crystal report. |
| Visual Basic PowerPacks | Contains a component that allows you to print a duplicate copy of a form as it appears on the screen. |
| General | Represents an empty tab to which you can store your controls by dragging and dropping them from your projects.. |

> NOTE
> You can extend Toolbox by adding third-party components to it, which can later be used into your programs.

The Toolbox is docked on the left-side of the IDE; however, if it is not visible, you can access the Toolbox from the View menu or press the CTRL+ALT+X keys to open it.

# Solution Explorer

In Visual Studio 2010, Solution Explorer is used to manage a solution. The solution refers to a container containing one or more projects. A solution also consists of project-related items and files, such as class files, images, icons, and user controls. Solution Explorer lists the solution name, the project name, and all the forms and modules that are used in the project. A developer can open a particular file just by double-clicking its name from this window. To rename, copy, or delete a file, you need to right-click on the file and select the desired action from the context menu that appears.

Solution Explorer can be opened in either of the following ways:

+   - By selecting View→Solution Explorer from the main menu
+   - By pressing Ctrl+Alt+L keys
