
然而，并非所有 COM 属性都满足前述条件。例如，Excel.Range 属性的 get 访问器需要范围参数。要访问 Excel.Range 属性，你需要使用以下代码片段中的 get_Range() 方法：

```
var newexcelApp = new Excel.Application();
...
Excel.Range rangeinexcel = newexcelApp.get_Range("A1", Type.Missing);
```

在 C# 2010 中，你可以访问 Excel.Range 的 Range 属性，如下面的代码片段所示：

```
var newexcelApp = new Excel.Application();
// ...
Excel.Range rangeinexcel = newexcelApp.Range["A1"];
```

要为 Excel.Range 对象的 Value 属性赋值，需要提供两个参数。为此，你需要使用 set_Value() 方法或另一个属性 Value2。以下代码片段演示了如何为 Range 对象的 Value 属性赋值：

```
rangeinexcel.set_Value(Type.Missing, "Range_Name");
// Or
rangeinexcel.Value2 = "Range_Name";
```

还可以按如下方式设置 Excel.Range 对象的 Value 属性值：

```
rangeinexcel.Value = "Range_Name";
```

上述代码片段演示了如何使用索引参数设置 Value 属性值。

## 第 IV 部分 – .NET 相关技术概览

C# 2010 集成了一组协调技术，有助于降低开发、部署和管理应用程序的复杂性。这些技术有助于构建稳定且安全的网站。本书将讨论以下与 C# 2010 相关的技术：

- WPF
- LINQ
- ADO.NET Entity Framework
- ASP.NET AJAX
- Silverlight
- ASP.NET Web Services
- WCF Services
- WF
- MEF and Managed Add-In Framework (MAF)

### WPF

WPF 技术支持多种媒体，例如文本、图像、音频和视频，并允许你处理二维（2-D）以及三维（3-D）图形。WPF 应用程序中与设计相关的所有元素均由 DirectX 处理。WPF 支持 XAML 语言，该语言允许设计人员轻松快速地定义应用程序 UI 的元素。然后，应用程序开发人员可以使用通过 XAML 定义的 UI 元素，在代码隐藏文件中以任何 .NET 语言（如 C#）指定应用程序逻辑。

第 9 章“介绍 Windows Presentation Foundation”描述了 WPF 的体系结构、类层次结构和应用程序模型。在本章中，你还将学习如何在 WPF 中使用 XAML、WPF 属性和 WPF 事件。

### LINQ

LINQ 是 .NET Framework 4.0 的一个组件。LINQ 的基本功能是使用类似于 SQL 的语法向 .NET Framework 添加本机数据查询功能。LINQ 允许你定义语句来查询数据源，以生成所需的结果集。此外，它还允许你以一致的方式获取和操作数据。

第 27 章“LINQ 查询”讨论了基本的 LINQ 查询以及用于从数据源查询数据的查询运算符。你还将学习如何从各种数据源（如 LINQ to Object、LINQ to ADO.NET 和 LINQ to XML）检索数据。

### ADO.NET Entity Framework

ADO.NET Entity Framework 旨在支持以数据为中心的应用程序和服务，并提供了一个针对数据进行编程的平台，该平台将抽象级别从逻辑关系级别提升到概念级别。

第 22 章“ADO.NET Entity Framework”讨论了 Entity Framework 支持的功能和组件，例如 Entity Data Model、Object Services、Entity SQL、Client provider 以及概念架构和存储架构之间的映射。

### ASP.NET AJAX

ASP.NET AJAX 是一种基于页面更新而非页面替换概念的方法。ASP.NET AJAX 向开发人员提供了两种构建富 Web 应用程序的方式：以服务器为中心和以客户端为中心。以服务器为中心的开发方法允许刷新网页的一部分，而无需将整个页面回发到服务器。这是通过使用 UpdatePanel 服务器控件实现的。以客户端为中心的方法允许开发人员使用控件扩展器向新的和现有的 ASP.NET 控件添加预定义的客户端行为。扩展器使用一段 JavaScript 代码为 ASP.NET 添加新的和增强的功能。

随书光盘的第 7 章“开发 ASP.NET AJAX 应用程序”讨论了 ASP.NET AJAX 及其组件，以及使用 AJAX 方法进行 Web 开发的 ASP.NET 技术。

### Silverlight

Silverlight 是一种基于 Web 的技术，允许 Web 设计人员和开发人员突破 Web 应用程序开发的界限。它集成了桌面应用程序的丰富用户界面和其他 Web 语言（如 HTML 和 JavaScript）的透明度。Silverlight 允许你开发包含高保真多媒体内容和富有视觉冲击力的视觉效果的 Web 应用程序。Web 设计人员和开发人员已经采用 Silverlight 来构建高质量交互式 Web 应用程序。

第 17 章“使用 Silverlight 3 开发富交互式应用程序”讨论了 Silverlight 的主要功能和体系结构。

### ASP.NET Web Services

Web 服务是一个实体，可以通过编程方式在 Internet 上向任意数量的应用程序提供特定功能。Web 服务提供的功能可以被任何应用程序使用，无论该应用程序使用何种编程语言创建，也无论其运行在何种硬件平台和操作系统上。Web 服务没有任何用户界面。它只是向其使用者提供特定服务。

第 18 章“ASP.NET Web Services”讨论了如何创建和部署 Web 服务。

### WCF Services

WCF 是一组用于在 Windows 上开发和部署服务的 .NET 技术。它充当创建和分发互联应用程序的平台。此外，它还为快速构建面向服务的应用程序提供了统一框架。

第 19 章“使用 Windows Communication Foundation”讨论了 WCF 的分层体系结构以及 WCF 的功能。本章还介绍了 WCF 在地址、绑定、协定、托管和安全性等方面的重要内容。

### WF

WF 技术提供了一种向应用程序添加工作流的标准方法。WF 用作以图形方式构建工作流的工具。定义工作流后，可以围绕该定义构建应用程序以支持业务流程。
