# Using the EnableDecompression Property

Suppose that the Web server from which a Web service client requests for a Web service, supports compression (a technique used to minimize the size of data [or a file] by applying encoding). As the Web server supports compression, the Web service client receives a response to the request in the form of compressed data. Therefore, to understand the response of the Web server, the Web service client has to decompress (a technique used to convert the compressed data [or file] to its original form by decoding) the response.

This can be done with the EnableDecompression property, which, if set to True, enables the Web service client to decompress the data.

Likewise, decompression is disabled by setting the EnableDecompression property to False. This allows the Web service client to receive the response from the Web server in the original format.
