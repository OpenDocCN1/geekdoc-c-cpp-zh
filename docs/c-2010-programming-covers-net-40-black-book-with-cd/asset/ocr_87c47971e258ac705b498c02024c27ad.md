# Table 1.2: System Requirements for Installing Visual Studio 2010

| Hardware and Software | Requirements |
|---|---|
| Hard disk | Minimum: 5400 Revolutions Per Minute (RPM)
Recommended: 7200 RPM or higher |
| Media drive | DVD-ROM |
| Display | Minimum: 1024x 768 display
Recommended: 1280x 1024 display |
| Video card | DirectX 9 video card that runs at 1024 x 768 or higher-resolution display |
| Mouse | Microsoft mouse or compatible pointing device |

After fulfilling the specified requirements, let’s perform the following steps to install Visual Studio 2010 Ultimate:

+   1. Insert the DVD-ROM of Visual Studio 2010 Ultimate in the DVD-ROM drive. The AutoPlay window appears.
+   2. Click the Run autorun.exe option. The Microsoft Visual Studio 2010 Setup dialog box opens, as shown in Figure 1.34:
+   3. Click the Install Microsoft Visual Studio 2010 link (Figure 1.34). The Microsoft Visual Studio 2010 Ultimate message box appears, as shown in Figure 1.35:
