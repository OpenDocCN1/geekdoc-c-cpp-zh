The in keyword is used for contravariance to treat an array as a wider derived type. The following code snippet shows how contravariance is used:

```
public interface IComparer<in T>
{
    int Compare(T x, T y);
}
// Types can be treated as more derived
IComparer<object> objComp = GetComparer();
IComparer<string> strComp = objComp;
```

Note that a generic type parameter that is not marked covariant (out) or contravariant (in) is invariant.
