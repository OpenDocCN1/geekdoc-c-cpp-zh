## 让我们现在学习同步

## 线程同步

同步是在这样一种方式下协调事件和任务，使得所有任务都能在不受到其他任务干扰和中断的情况下完成。如果一个任务使用的是单个独立对象，则无需同步该任务；然而，如果一个任务使用的是共享对象，则需要同步任务，以避免不同线程对同一对象进行多次请求访问和使用。为了更好地理解同步的概念，让我们举一个例子：你和你的朋友共享同一个电视遥控器。你想看新闻频道并录制新闻，而你的朋友想看电影并录制它。当轮到你时，你切换到新闻频道，然后你的时间片也结束了。现在，你从上次的操作继续并开始录制，等等。结果会怎样？你们两人都无法完成各自的预期任务。在 C# 编程中，多个线程尝试访问单个共享资源（对象）时也会出现同样的情况。在这种情况下，必须以一种方式同步分配给线程的任务，以确保对象一次只被一个线程使用。

## 让线程休眠

让线程休眠意味着延迟其执行一段时间。Thread 类的 Sleep() 方法会导致当前执行的线程暂时暂停指定的时间。Sleep() 方法接受一个以毫秒为单位的时间作为参数，表示你希望暂停线程的时间。

清单 31.2 显示了 ThreadSleep 应用程序的代码（也可在光盘上获得），展示了如何让线程休眠：

### 清单 31.2：显示 ThreadSleep 应用程序的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading;
namespace ThreadSleep
{
class Program {
    static void Main(string[] args)
    {

## 挂起线程

与使线程暂停指定时间的 Sleep() 方法不同，Suspend() 方法会永久暂停线程，直到用户恢复它为止。这意味着 Suspend() 方法会导致线程无限期地休眠。ThreadSuspend 应用程序（也可在光盘上获得），如清单 31.3 所示，说明了如何挂起线程：

### 清单 31.3：显示 ThreadSuspend 应用程序的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading;
namespace ThreadSuspend
{
class Program
{
    static Thread FirstThread;
    static void Main(string[] args)
    {
        FirstThread = new Thread(FirstFunction);
        FirstThread.Name = "First Thread";
        FirstThread.Start();
        Console.WriteLine("Thread Started...\n");
        Thread.Sleep(200);

        //Suspending the FirstThread thread
        FirstThread.Suspend();
        Console.WriteLine("\nThread Suspended...");
    }
    public static void FirstFunction()
    {
        int number = 1;
        for (; number <= 25; number++)
        {
            int time = new Random().Next(25, 50);
            Console.WriteLine("{0} Slept for: {1} milliseconds", FirstThread.Name, time.ToString());
            Thread.Sleep(time);
        }
    }
}
}
```

在清单 31.3 中，你可以看到 FirstThread 线程开始执行，并且 FirstFunction() 方法在每次迭代时生成一个随机数，该随机数被视为线程的休眠时间。当 FirstThread 线程达到总休眠时间 200 毫秒时，程序控制转移到 Suspend() 方法，导致线程无限期挂起。
