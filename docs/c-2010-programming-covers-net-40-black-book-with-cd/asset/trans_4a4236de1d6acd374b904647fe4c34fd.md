

## 使用画刷

在本章的“深入探讨”部分，你已经了解了 WPF 中可用的画刷类型。在本节中，你将学习如何使用不同的画刷来使 WPF 应用程序具有丰富的外观。如你所知，WPF 中有五种类型的画刷，例如 LinearGradientBrush、RadialGradientBrush、ImageBrush、DrawingBrush 和 VisualBrush。你将进一步详细了解所有画刷的用法。

### LinearGradientBrush 和 RadialGradientBrush

LinearGradientBrush 类用于使用线性渐变绘制区域；而 RadialGradientBrush 类用于使用径向渐变绘制区域。你可以使用 GradientStop 对象来指定渐变中的颜色及其位置。

让我们将 LinearGradientBrush 和 RadialGradientBrush 类添加到应用程序中。为此，创建一个名为 Linear_RadialBrush 的 WPF 应用程序（也可在 CD 中找到），并将清单 12.8 中给出的代码添加到 MainWindow.xaml 文件中：

**清单 12.8：使用 LinearGradientBrush 和 RadialGradientBrush 类**

```
<Window x:Class="Linear_RadialBrush.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="300" Width="300">
<Grid>
<Ellipse Name="ellipse1" Stroke="OrangeRed" HorizontalAlignment="Right" Width="96" Height="96" VerticalAlignment="Top" Margin="0,8,19,0">
<Ellipse.Fill>
<LinearGradientBrush StartPoint="0,0.5" EndPoint="1,0.5">
<GradientStop Color="OrangeRed" Offset="0.0"/>
<GradientStop Color="Orange" Offset="0.25"/>
<GradientStop Color="Yellow" Offset="0.75"/>
<GradientStop Color="MediumVioletRed" Offset="1"/>
</LinearGradientBrush>
</Ellipse.Fill>
</Ellipse>
<Rectangle Margin="9,103,0,17" Name="rectangle2" Stroke="Thistle" HorizontalAlignment="Left" Width="103" StrokeThickness="4">
<Rectangle.Fill>
<RadialGradientBrush GradientOrigin="1,1" Center="1,1" RadiusX="1" RadiusY="1">
<RadialGradientBrush.GradientStops>
<GradientStop Offset="0.09" Color="Yellow"/>
<GradientStop Offset="0.25" Color="Green"/>
<GradientStop Offset="0.5" Color="Red"/>
<GradientStop Offset="1.25" Color="Blue"/>
</RadialGradientBrush.GradientStops>
</RadialGradientBrush>
</Rectangle.Fill>
</Rectangle>
<Polygon Points="10,110 60,11 110,110" Stroke="IndianRed" StrokeThickness="4" Canvas.Left="150" Canvas.Top="150" Margin="0,-9,0,9" Fill="IndianRed"></Polygon>
</Grid>
</Window>
```

在清单 12.8 中，使用 LinearGradientBrush 和 RadialGradientBrush 类为形状着色。正如你在代码中所见，两种画刷中的颜色都是使用 GradientStop 类描述的。区别体现在画刷的输出中。当你按键盘上的 F5 键运行应用程序时，将得到输出，如图 12.12 所示：

### ImageBrush

ImageBrush 类使用图像绘制区域。ImageBrush 的 ImageSource 属性用于绘制该区域。让我们将 ImageBrush 类添加到应用程序中。为此，创建一个名为 ImageBrush 的 WPF 应用程序（也可在 CD 中找到），并将清单 12.9 中给出的代码添加到 MainWindow.xaml 文件中：

**清单 12.9：使用 ImageBrush 类**

```
<Window x:Class="ImageBrush.MainWindow"
xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
Title="MainWindow" Height="300" Width="300"
xmlns:PresentationOptions="http://schemas.microsoft.com/winfx/2006/xaml/presentation/options"
xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006"
mc:Ignorable="PresentationOptions">
    <Grid>
        <StackPanel>
            <Rectangle Width="100" Height="100" Stroke="Red" StrokeThickness="4">
                <Rectangle.Fill>
                    <ImageBrush Stretch="uniformToFill" ImageSource="D:\pictures\DE-wp3.jpg" PresentationOptions:Freeze="True" />
                </Rectangle.Fill>
            </Rectangle>
            <Rectangle Width="200" Height="100" Stroke="Black" StrokeThickness="2" Margin="50,50,20,20">
                <Rectangle.Fill>
                    <ImageBrush Stretch="Fill" ImageSource="D:\pictures\DE-wp3.jpg" PresentationOptions:Freeze="True" TileMode="Tile"/>
                </Rectangle.Fill>
            </Rectangle>
        </StackPanel>
    </Grid>
</Window>
```

> **注意：** 你需要更改应用程序中指定的文件路径。

在前面的代码中，图像以不同的视图和模式添加到应用程序中。当你按键盘上的 F5 键运行应用程序时，将得到输出，如图 12.13 所示：

### DrawingBrush 和 VisualBrush

DrawingBrush 类使用形状、图像和文本绘制区域。VisualBrush 类使用可视元素绘制区域，该可视元素可以包括 Button、Page 或 MediaElement。让我们将 DrawingBrush 和 VisualBrush 添加到应用程序中。为此，创建一个名为 Drawing_VisualBrush 的 WPF 应用程序（也可在 CD 中找到），并将清单 12.10 中给出的代码添加到 MainWindow.xaml 文件中：

**清单 12.10：使用 DrawingBrush 和 VisualBrush 类**

```
<Window x:Class="Drawing_VisualBrush.MainWindow"
xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
Title="MainWindow" Height="350" Width="525">
<Grid>
<Button Name="button1">
<Button.Background>
<DrawingBrush>
<DrawingBrush.Drawing>
<GeometryDrawing Brush="Firebrick">
<GeometryDrawing.Geometry>
<GeometryGroup>
<EllipseGeometry RadiusX="50" RadiusY="12"/>
<EllipseGeometry RadiusX="45" RadiusY="10"/>
<EllipseGeometry RadiusX="30" RadiusY="7"/>
<EllipseGeometry RadiusX="20" RadiusY="5"/>
</GeometryGroup>
</GeometryDrawing.Geometry>
</GeometryDrawing>
</DrawingBrush.Drawing>
</DrawingBrush>
</Button.Background>
</Button>
<Rectangle Margin="79,83,76,83" Name="rectangle1" Stroke="Gold">
<Rectangle.Fill>
<VisualBrush>
<VisualBrush.Visual>
<StackPanel Background="Antiquewhite">
<TextBlock FontSize="10pt" Margin="3">
Hello!!!!
</TextBlock>
</StackPanel>
</VisualBrush.Visual>
</VisualBrush>
</Rectangle.Fill>
</Rectangle>
</Grid>
</Window>
```

> **注意：** 在 WPF 应用程序中，你可以将应用程序的根元素更改为 Page。

当你按键盘上的 F5 键运行应用程序时，将得到输出，如图 12.14 所示：

**图 12.14：** 使用 DrawingBrush 和 VisualBrush 类

### 更改画刷的平铺大小和图案

你可以使用 WPF 中 TileBrush 类的 TileMode 属性来创建图案。TileMode 属性使你可以指定 TileBrush 对象的内容如何重复以填充输出区域。你可以将 TileMode 属性设置为 Tile、FlipX、FlipY 或 FlipXY。TileBrush 类的 TileMode 属性对于 ImageBrush、VisualBrush 和 DrawingBrush 类也同样适用。你还应该设置 TileBrush 类的 Viewport 属性来创建平铺。让我们创建一个应用程序并更改画刷的平铺大小和图案。为此，创建一个名为 TileSize_Pattern_Brush 的 WPF 应用程序（也可在 CD 中找到），并向应用程序添加一个页面。现在，将清单 12.11 中给出的代码添加到 Page1.xaml 文件中：

**清单 12.11：应用 TileMode 属性**

```
<Page x:Class="TileSize_Pattern_Brush.Page1"
xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006"
xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
xmlns:PresentationOptions="http://schemas.microsoft.com/winfx/2006/xaml/presentation/options"
mc:Ignorable="PresentationOptions"
Background="White" Margin="15">
    <Page.Resources>
        <GeometryDrawing x:Key="Tilesize" Geometry="M0,0 L50,0 0,50Z" Brush="Aquamarine" PresentationOptions:Freeze="True" >
            <GeometryDrawing.Pen>
                <Pen Thickness="2" Brush="PalevioletRed" MiterLimit="0" />
            </GeometryDrawing.Pen>
        </GeometryDrawing>
    </Page.Resources>
    <StackPanel HorizontalAlignment="Center">
        <Rectangle Height="96" Name="rectangle1" Stroke="Black" Width="222">
            <Rectangle.Fill>
                <DrawingBrush TileMode="None" Drawing="{StaticResource Tilesize}" />
```
