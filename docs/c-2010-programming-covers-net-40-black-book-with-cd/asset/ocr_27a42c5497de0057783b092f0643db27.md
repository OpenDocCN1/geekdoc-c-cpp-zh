# Creating Multiform Windows Applications

Suppose that you have designed your application with an introductory form to welcome the user, a data entry form to get data from the user, a summary form to display the data analysis results, and a logon form to connect to the Internet. Now, you have to use or send the data of one form to another, for instance the data entered in a data entry form is required in data analysis summary form. In such cases, you can create Windows Forms applications that contain multiple forms.

Perform the following steps to create multiform application, named MultiForm:

+   1. Create a Windows Forms application, named MultiForm.

+   2. Modify the Text property of Form1 to First Form, as shown in Figure 8.14:
