### DeclarativeCatalogPart 控件

DeclarativeCatalogPart 控件是与 CatalogZone 控件配合使用的三个控件之一（另外两个控件是 PageCatalogPart 和 ImportCatalogPart）。此控件用于修改网页的功能。当网站处于 CatalogDisplayMode 模式时，此控件会显示 Web 部件控件和其他服务器控件的列表。用户可以将此目录中的控件添加到网页上。

DeclarativeCatalogPart 控件是 DeclarativeCatalogPart 类的对象。您可以通过将控件从工具箱拖放到 Default.aspx 页面的设计视图中的 CatalogZone 控件上，将 DeclarativeCatalogPart 控件添加到 Default.aspx 页面。在向网页添加 DeclarativeCatalogPart 控件时，请确保网页包含 CatalogZone 控件。

图16.13 显示了在设计视图中 CatalogZone 控件内的 DeclarativeCatalogPart 控件：

![](img/e073a4882197be4ab61103cbe0bcb394_816_0.png)

您还可以通过在 `Default.aspx` 页面的 `<form>` 元素中使用以下代码来添加 DeclarativeCatalogPart 控件。

```aspx
<asp:CatalogZone ID="CatalogZone1" runat="server">
    <ZoneTemplate>
        <asp:DeclarativeCatalogPart ID="DeclarativeCatalogPart1" runat="server">
        </asp:DeclarativeCatalogPart>
    </ZoneTemplate>
</asp:CatalogZone>
```

DeclarativeCatalogPart 控件是使用 .NET Framework 类库中的 DeclarativeCatalogPart 类创建的。此类位于 System.Web.UI.WebControls.WebParts 命名空间中。

该类的继承层次结构如下：

```text
System.Object
    System.Web.UI.Control
        System.Web.UI.WebControls.WebControl
            System.Web.UI.WebControls.Panel
                System.Web.UI.WebControls.WebParts.Part
                    System.Web.UI.WebControls.WebParts.CatalogPart
                        System.Web.UI.WebControls.WebParts.DeclarativeCatalogPart
```

现在，让我们识别使用 DeclarativeCatalogPart 类声明 DeclarativeCatalogPart 控件的语法。

声明 DeclarativeCatalogPart 控件的语法如下：

```text
DeclarativeCatalogPart control_DeclarativeCatalogPart;
```

您可以创建一个由一个或多个服务器控件组成的用户控件，并将其添加到 DeclarativeCatalogPart 控件中。为此，您必须将 DeclarativeCatalogPart 类的 WebPartsListUserControlPath 属性设置为该用户控件的路径，这比直接添加服务器控件更可取，因为您可以通过使用同一个用户控件在网站的多个页面上显示 Web 部件控件的目录。当用户控件中的 Web 部件控件被修改时，与该用户控件关联的所有目录都会由 DeclarativeCatalogPart 控件自动更新。
