# Using the Web Service

You need to create an ASP.NET Web application that accesses the Web service to use the Web service. You need to generate a proxy class for the Web service to allow a Web application to access the Web service. A proxy class is a local copy of the class that represents a Web service. You can generate a proxy class for a Web service by adding a Web reference to the website.
