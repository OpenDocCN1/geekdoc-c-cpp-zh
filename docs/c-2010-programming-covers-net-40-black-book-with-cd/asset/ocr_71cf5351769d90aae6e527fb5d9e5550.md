# Setting the Styles of Controls

While working with a Web page in Design view, very often you require to make minor changes in some part of the Web page, such as styling a piece of text, applying a border to an element, or aligning an image. In such a case, you need to create an inline style sheet for the elements that need to be styled. In this section, let’s learn how to style the <h1> element of a Web page. To do so, perform the following steps:

+   1. Open the Default Web page of the FileSystemWebsite application in the Design view. Select the <div> element and select the Format→New Style menu item. The New Style dialog box appears, as shown in Figure 13.36:

![](bbox=[0.285, 0.313, 0.742, 0.642])

+   2. Select the Selector drop-down list which is at the top of the dialog box and select the inline style option. This option ensures that the new style is applied as an inline style to the <div> element.

+   3. Now apply a setting for a style according to your choice and when you finish, click the OK button. In the Source view of the Default Web page, you can see the style applied to the <div> element, as shown in Listing 13.9:
