## Transform Classes

In WPF, with the help of typography, you can apply transformations to the text. For example, you can rotate, scale, skew, or transform the text. You can use the Transform classes to transform the text. These classes also simplify the use of various drawings in the text. The most commonly used Transform classes are as follows:

- TranslateTransform class
- RotateTransform class
- ScaleTransform class
- SkewTransform class

Let’s discuss these classes in detail.

### The TranslateTransform Class

The TranslateTransform class moves the text in 2-dimensions, i.e. the x-y coordinate system. This implies that you can move the text from the actual position by changing its x-y coordinate in the code. The TranslateTransform class is useful for moving elements inside controls that do not support absolute positioning. For example, you can apply the TranslateTransform class on the text which is inside any container control, as container controls do not support absolute positioning of text. The TranslateTransform class displaces the text by the amount that has been mentioned in the x-y coordinate system.

The inheritance hierarchy of the TranslateTransform class is as follows:

```

          System.Windows.Media.GeneralTransform
            System.Windows.Media.Transform
              System.Windows.Media.TranslateTransform
```

### The RotateTransform Class

The RotateTransform class rotates the text by a specified angle about the points CenterX and CenterY. It rotates the text clockwise to a specified point in a 2-D x-y coordinate. You can either take the default center point of the text to rotate it, or you can specify any other point as your center point. The default value of CenterX and CenterY is 0.
