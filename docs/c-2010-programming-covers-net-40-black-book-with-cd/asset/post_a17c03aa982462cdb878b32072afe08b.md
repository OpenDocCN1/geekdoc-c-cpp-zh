## Creating an Inheritance by Using the Inheritance Control

The Inheritance tool permits one type to be derived from another type, but the source and target ends must be different. Suppose we have another entity named Vendor and we want both the Vendor and Customers entities should be inherited from the Contact entity. In this case, the Contact entity is the Base type, and the Vendor and Customers entities are called derived types. For this, set the Contact entity as base type for the Vendors and Customers entities in the Base Type field from their respective Properties windows.

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Web;
using System.Web.UI;
using System.Web.UI.WebControls;
using NewPublisherModel;

public partial class _Default : System.Web.UI.Page
{
    private NewPublisherEntities2 PublisherContext;

    protected void Page_Load(object sender, EventArgs e)
    {
        PublisherContext = new NewPublisherEntities2();
    }

    protected void DropDownList1_SelectedIndexChanged(object sender, EventArgs e)
    {
        Int32 AuthorID = Convert.ToInt32(DropDownList1.SelectedValue);
        var BookDetails = from bookD in PublisherContext.Books
                          where bookD.Author.AuthorID == AuthorID
                          select new
                          {
                              BookName = bookD.Title,
                              Pages = bookD.Pages,
                              ISBN = bookD.BookISBN
                          };
        GridView1.DataSource = BookDetails;
        GridView1.DataBind();
    }
}
```

In the preceding code, the DropDownList1_SelectedIndexChanged event contains the code to bind the GridView1 control to the DropDownList1 control. The Page_PreRenderComplete event contains the code that calls the DropDownList1_SelectedIndexChanged event when a page is prerendered. The prerender event binds the GridView control with the drop-down list beside Author Name when a page is loaded.
