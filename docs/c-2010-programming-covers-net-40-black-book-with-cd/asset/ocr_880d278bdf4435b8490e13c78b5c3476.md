# Working with Drives

The System.IO namespace provides you the DriveInfo class to work with drives. This class provides you various properties that help you to retrieve the information pertaining to drive letter, file system, drive type, drive state, and free space in drives. Now, let’s create a new Windows Forms application, named WorkingWithDrive (also available on the CD) and perform the following steps to learn how to work with drives:

+   1. Add a ListBox control and fifteen Label controls from the Toolbox to the Form designer.
+   2. Change the Text property of eight Label controls to Drive List, Drive Type, File System, Drive State, Total Space, Total Free Space, Available Free Space (User), and Volume label, respectively, as shown in Figure 29.1:
