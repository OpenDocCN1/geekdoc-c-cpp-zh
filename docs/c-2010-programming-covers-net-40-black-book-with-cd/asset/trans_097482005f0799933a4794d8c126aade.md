.NET 还提供了几个通用集合类，可用于创建任何数据类型的数据集合。让我们详细了解这些类。

## .NET 中的集合类

.NET Framework 在 System.Collections 命名空间中为你提供了多种集合类，以满足各种目的，例如动态分配元素内存以及基于索引访问项目列表。这些类基本上创建了 Object 类对象的集合，而 Object 类是 C# 中所有数据类型的基类。System.Collections 命名空间中定义的一些最有用的集合类如下：

- ArrayList
- Hashtable
- SortedList
- Stack
- Queue
- BitArray

现在，让我们详细讨论这些集合类。

## ArrayList 类

在使用数组时，出现的主要问题是其大小始终固定为你在声明数组时指定的数字。此外，你无法在数组中间添加项目。解决这些问题的方案是使用 ArrayList 类。与数组类似，ArrayList 类允许你存储和管理多个元素。然而，使用 ArrayList 类，你可以从指定的位置添加和删除数组项目的列表中的项目，然后数组列表会自动相应地调整大小。ArrayList 类还允许你动态分配数组列表的内存，以及添加、搜索和排序列表的项目。数组列表还可以存储不同数据类型的项目。

> NOTE
> ArrayList 对象接受 null 作为有效值并允许重复元素。

## Hashtable 类

Hashtable 类与 ArrayList 类类似，但它允许你通过键访问项目。Hashtable 对象中的每个项目都有一个键/值对。键用于访问集合中的项目，每个键必须是唯一的；而值是存储在数组中的值。通常，键是短字符串或整数。使用 Hashtable 类，你可以向集合添加和检索项目。

**NOTE**  
键不能为空，但值可以为空。
