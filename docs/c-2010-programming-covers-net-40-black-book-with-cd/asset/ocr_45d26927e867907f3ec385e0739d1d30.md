# The PasswordRecovery Control

The PasswordRecovery control is used to recover or reset the forgotten password of a user. This control does not display the password on the browser, but sends the password as an e-mail message to the e-mail address specified at the time of registration. This control also uses the Membership service to create or reset the password. The PasswordRecovery control has the following three views:

+   - UserName — Refers to the view that accepts the username of a user
+   - Question — Refers to the view that accepts the answer of the security question asked from the user.
+   - Success — Refers to the view that displays a message to the user, specifying that the retrieved password has been sent to the user.

To retrieve or reset passwords, you must set some properties of the ASP.NET Membership service. The PasswordRecovery control uses the following configuration of the Membership service settings for retrieving passwords:

+   - requiresQuestionAndAnswer — Allows a user to answer the security question, which was specified at the time of creating the user account, when set to True
+   - passwordFormat — Displays the password in an encrypted format, when set to Hashed
+   - enablePasswordRetrieval — Allows the Membership service to retrieve the password, when set to True
+   - enablePasswordReset — Allows the users to reset their passwords, when set to True

The PasswordRecovery control is provided by the PasswordRecovery class. The following code snippet shows the class hierarchy of the PasswordRecovery class:

```
System.Object
System.Web.UI.Control
System.Web.UI.WebControls.WebControl
System.Web.UI.WebControls.CompositeControl
System.Web.UI.WebControls.PasswordRecovery
```

The PasswordRecovery class contains various methods, properties, and events that are used to work with the PasswordRecovery control.

Table 16.10 lists the noteworthy methods of the PasswordRecovery class:

| Table 16.10: Noteworthy Methods of the PasswordRecovery Class |
| Method | Description |
| OnAnswerLookupError | Raises the AnswerLookupError event when users' answers do not match with the answer stored in the website database |
| OnSendingMail | Raises the SendingMail event when the user is verified and the recovered password is sent to the user |
| OnSendMailError | Raises the SendMailError event when an e-mail message cannot be sent to the user |
| OnUserLookupError | Raises the UserLookupError event when the entered username does not match with any username stored in the website database |
| OnVerifyingAnswer | Raises the VerifyingAnswer event before the users' answers are sent to the Membership service provider to recover the forgotten password |
| OnVerifyingUser | Raises the VerifyingUser event after submitting the username but before sending it to the Membership service provider for verification |
