By specifying the values for each of these fields, we can create a CSDL function import entry in a stored procedure. Now, let’s see how to modify the mappings of database objects by using the Mapping Details window.

# Using the Mapping Details Window

The Mapping Details window enables us to view and edit the mappings in the EDM. We can access this window by selecting the Entity Types option in the Model Browser window. The Mapping Details window shows the mappings of the selected entity objects in the Model Browser window, as shown in Figure 22.17:

![](bbox=[0.085, 0.236, 0.845, 0.47])

Figure 22.17: Displaying the Entity Mapping Details Window

The following functions can be performed through the Mapping Details window:

+   - Modifying mappings of entities
+   - Adding a table or view
+   - Adding a condition

# Modifying Mappings of Entities

To modify the mapping of an entity in an application, the following steps are performed:

+   1. Select the Category name whose mappings you want to change from the Column Mappings folder.
