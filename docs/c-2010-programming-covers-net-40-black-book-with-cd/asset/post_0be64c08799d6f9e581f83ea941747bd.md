## Design View

As the name suggests, the Design view is the area where you build the visual aspect or UI of a WPF application by placing, dragging and resizing, and manipulating the appearance of controls. The Design view allows you to easily and quickly build the UI of the WPF application in a What You See Is What you Get (WYSIWYG) manner.

## Grid Rails, Gridlines, and Gridline Indicators

The grid rails, gridlines, and gridline indicators pertain to the Grid element or control of WPF. When you create a WPF application, a Grid element is by default added to the application. As the name suggests, the Grid element allows you to represent the WPF application as a grid or lattice. The entire grid is enclosed by grid rails that span horizontally and vertically on the top and left respectively, as shown in Figure 9.14.

By default, the grid has one row and one column; however, there can be multiple rows and columns. You can create additional rows and columns by clicking the desired positions on the grid rails. When you click the grid rails, gridlines and gridline indicators appear accordingly (Figure 9.14). If you click the grid rail on the top, then a vertical gridline appears dividing the grid into two columns. Similarly, if you click the grid rail on the left, then a horizontal gridline appears dividing the grid into two rows. You can click the gridrails as many times as you want to create rows and columns in the grid. You can control the height and width of the rows and columns by moving the gridline indicators that appear as triangles on grid rails.

> NOTE
> There is a property named FlowDirection for the Grid control. This property, by default, is set to LeftToRight. However, when this property is set to RightToLeft, it causes the grid rails to appear on the top and right of the window.

## Zoom Control and Fit in View Button

You can find the Zoom control and the Fit in View button at the upper-left corner of the Design view. The Zoom control allows you to zoom in and zoom out the Design view. You can zoom in up to 20x and zoom out up to 10%. You can zoom in or out by dragging the Zoom control slider up or down. The current zoom level, which in Figure 9.15 is 80%, can be seen on top of the zoom controls.

You can move and resize the controls in the Design view by using the move and resize handles, respectively. The move and resize handles appear only when you select the control. Note that the move handle appears only for some selected controls, such as the Grid and StackPanel. For these controls, the move handle is located at the upper-left corner of the control, as shown in Figure 9.16:

## Margin Lines and Margin Stubs

In WPF 4.0, the controls exist within the container controls, one of which is the Grid control that is automatically added to WPF applications when you create them. When you drag and drop the controls on the grid, you can change the distance, known as the margin, between a control and the grid. The margin is the distance from the edge of the control to the edge of the container control. If you have used, Grid as the container control, then margin is measured from the edge of the control to the nearest gridline. Each control has four margins – top, bottom, left, and right. These margins are represented by four straight lines, called margin lines, emerging from the edges of the control, as shown in Figure 9.18:

![](img/e073a4882197be4ab61103cbe0bcb394_362_0.png)

# Figure 9.18: Displaying the Margin Lines and Stubs for a Button Control

Note that the margin lines appear only when the control is selected. You may notice in Figure 9.18 that only the Button control is selected and its top, and left margin lines appear. Instead, there is a small circle, called the margin stub, on the right and bottom edges of the Button control. The margin stub at the right and bottom edges indicate that the respective margins are set to zero, i.e. the margins are not set for the respective edges. If you click a margin stub, the margin is automatically set for that edge and the margin line appears. Similarly, if you click a margin line, then it changes to a margin stub.

The margins for a control are collectively accessed through the Margin property of the control. You can set the Margin property of a control in the Design view, XAML view, or code-behind file. You can set the Margin property in the Design view by selecting and dragging the control. You can also use the Properties window (discussed later in the chapter) to set the Margin property by typing the margin values. You need to provide the margin values in a clockwise manner starting from the left margin, that is, left, top, right, and bottom, as shown in Figure 9.19:

## Snaplines

The Snaplines feature in WPF Designer is used to assist you in aligning the controls in WPF applications. A snapline appears only when there is more than one control and you want to align the controls in such a manner that the edges of the controls are aligned to each other. A snapline appears as a light brown line along with the edges of controls, as shown in Figure 9.21:

![](img/e073a4882197be4ab61103cbe0bcb394_363_0.png)

In Figure 9.21, you can see that at one end of the snapline, the number 69 is displayed. This number represents the distance between the edges of the controls that you want to align. In case you do not want to see the snaplines, you can press ALT from the keyboard while dragging or resizing the control.
