the PasswordBox control are similar to those of the TextBox control, such as the Clear(), Paste(), and SelectAll() methods. However, the PasswordBox control does not support the clipboard feature, so you cannot perform the copy function. The most important difference between a TextBox control and a PasswordBox control is that the PasswordBox control uses a System.Security.SecureString object, which ensures that the text entered as a password in the PasswordBox control is kept confidential. The text is encrypted for privacy when it is in use, and deleted from memory when no longer needed. The key used to encrypt the string is a randomly generated code and is never written to the disk.

The SecureString class includes an on-demand disposal of the encrypted text. When you call the SecureString.Dispose() method, the password stored in the memory is overwritten.

The PasswordBox control is represented by the PasswordBox class. The inheritance hierarchy of the PasswordBox class is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Control
              System.Windows.Controls.PasswordBox
```

You can add a PasswordBox control to a WPF application by using the following code snippet:

```
<PasswordBox .../>
```

# The ScrollBar Control

The ScrollBar control provides a scroll bar that has a sliding Thumb control whose position corresponds to a value. The ScrollBar control contains a Track control, which in turn contains a Thumb control and two RepeatButton controls. You can increase or decrease the Value property of the ScrollBar control by clicking any of the RepeatButton controls or by moving the Thumb control. The Thumb control enables a user to select a value on the ScrollBar control. The default range of values of the Value property is from 0 to 1.
