# The Class View Window

The Class View window contains a hierarchical tree view representing projects at the top-level node. It also displays the classes, methods, and properties associated with a particular project. You can access the Class View window by using either of the following ways:

+   - By selecting View→Class View from the main menu
+   - By pressing Ctrl+Shift+C keys

Figure 1.56 shows the Class View window:

Figure 1.56: Displaying the Class View Window

As you can see in Figure 1.56, the Class View window is divided into the following two panes:

+   - Objects pane – Displays an expandable tree of symbols whose top-level nodes represent projects. This hierarchical view specifies the symbolic structure within your code. Selecting an object in the Objects pane displays its member in the Members pane.
+   - Members pane – Displays the list of members present in the object.

The Class View window also contains a toolbar, containing the following buttons:

+   - New Folder – Creates a new folder or subfolder into which you can drag symbols or controls to easily access them the next time they are required.
