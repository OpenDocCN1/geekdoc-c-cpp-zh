# Deploying a Windows Application Using Windows Installer

To deploy a Windows application, you need to create a Windows Installer file (.msi file) by using Setup and Deployment projects in Visual C# 2010. All you need to do is to transfer the .msi file to a target computer running Windows operating system, and double-click the .msi installer file. Let’s create an .msi file for the application named DeploymentTest (which is also available on CD). DeploymentTest is a simple Windows Forms application that has two Label controls, two TextBox controls, and a Button control on the Form1 form. Modify the Text property of Label and Button controls and the Form1 form, as shown in Figure 21.11:

![](bbox=[0.24, 0.26, 0.78, 0.6])

Figure 21.11: Displaying the Design of the DeploymentTest Application

You need to add the following code snippet in the Click event of the Button control:

```
private void button1_Click(object sender, EventArgs e)
{
    textBox2.Text = textBox1.Text;
}
```

In the preceding code snippet, the content of the one TextBox control, textbox1, is copied to the second TextBox control, textbox2.

Now, perform the following tasks to create an installer file of the DeploymentTest application and deploy it on another computer:

+   1. Creating an installer file
+   2. Adding shortcuts to user desktop or user programs menu
+   3. Deploying an application on a target computer
