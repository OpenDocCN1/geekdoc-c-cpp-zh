# What’s New in Collections and Generics?

In .NET Framework 4.0, a new namespace, named System.Collections.Concurrent, has been introduced in collections and a class, named SortedSet<T>, has been introduced in generics.

The System.Collections.Concurrent namespace provides several thread-safe collection classes. These classes should be used in place of the corresponding types in the System.Collections and System.Collections.Generic namespaces whenever multiple threads are accessing the collection concurrently.
