# Verifying that a Class Contains a Method

If you are writing a scripting language that allows the use of C# objects, you need to verify that a given class contains a method before you allow the scriptwriter to create a script by using that method. After all, if the method does not exist, it does not make any sense to call it. This enables you to validate the method without waiting to run the application.
