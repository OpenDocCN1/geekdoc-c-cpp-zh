根据您选择的宿主应用程序，可能会有其他文件自动添加到项目中。通常，您使用 Visual Studio 2010 中的预定义项目模板。现在，让我们从托管 Silverlight 应用程序的 ASP.NET 和 HTML 文件开始，详细讨论每个文件。

## ASP.NET 和 HTML 宿主页（测试页）

每当您创建一个 Silverlight 应用程序时，您都需要一个页面来托管该 Silverlight 应用程序。在 Visual Studio 2010 中，您可以选择将 Silverlight 应用程序托管在简单的 HTML Web 页面或 ASP.NET Web 应用程序中。在 Visual Studio 2010 中，当您选择 ASP.NET Web 应用程序项目来托管 Silverlight 应用程序时，ASP.NET Web 应用程序会自动添加到 Silverlight 应用程序中。ASP.NET Web 应用程序包含两个测试页，即 ASP.NET 和 HTML 测试页，由默认创建用于整个 Silverlight 应用程序。换句话说，这意味着 ASP.NET 和 HTML 页面是用于托管您的 Silverlight 内容的测试页。ASP.NET 和 HTML 测试页可用于在应用程序开发期间测试 Silverlight 应用程序的 XAML 内容。此外，它们具有与 Silverlight 应用程序相同的名称，后缀为 TestPage。

HTML 测试页（即 .html 测试页）很大程度上包含与托管在单个 HTML 页面中的 Silverlight 应用程序的 TestPage.html 文件相同的代码。这意味着 HTML 测试页包含创建和初始化 Silverlight 应用程序的代码。ASP.NET 测试页（即 .aspx 测试页）包含 HTML 测试页的等效 ASP.NET 代码。此外，ASP.NET 测试页是默认启动页，因为它是用户运行 Silverlight 应用程序时出现的第一个页面。您可以在解决方案资源管理器中找到 ASP.NET 和 HTML 测试页，如图 17.7 所示：

## JavaScript 辅助文件

`Silverlight.js` 是一个 JavaScript 辅助文件，提供对 Silverlight 应用程序中 UI 元素和对象的编程访问和逻辑。它是提供创建和初始化 Silverlight 内容功能、验证用户计算机上是否安装了 Silverlight 以及检查用户计算机上安装的 Silverlight 版本的主要文件。由于 `Silverlight.js` 文件依赖于浏览器实现，因此细节可能因 Silverlight 版本而异；因此，您应定期从 MSDN Code Gallery 检查 `Silverlight.js` 的更新版本。

`Silverlight.js` JavaScript 辅助文件定义了一个新的命名空间 `Sys.Silverlight`，其中包含 `createObject()` 和 `createObjectEx()` 方法。`createObject()` 和 `createObjectEx()` 方法在托管 Silverlight 应用程序的 ASPX 或 HTML 页面中创建和初始化 Silverlight 内容。两种方法具有相同的功能，并具有多个参数，其值从 `<object>` 或 `<embed>` 标签中获取。请注意，`<object>` 和 `<embed>` 标签也是由这两种方法生成的。`createObject()` 和 `createObjectEx()` 之间的区别在于，只有 `createObjectEx()` 将所有参数打包到 JSON 字典中。

## XAML 文件

与 WPF 应用程序类似，Silverlight 应用程序的设计和 UI 通过 XAML 定义。如前所述，每个 Silverlight 应用程序都有几个 XAML 文件，例如 `App.xaml`、`App.xaml.cs`、`MainPage.xaml` 和 `MainPage.xaml.cs`，它们定义了 Silverlight 应用程序的 UI 和基本行为。`App.xaml` 和 `App.xaml.cs` 文件代表应用程序，而 `MainPage.xaml` 和 `MainPage.xaml.cs` 文件代表应用程序的 UI。`App.xaml` 文件是一个 XAML 文件，包含应用程序级信息和设置。`App.xaml` 文件的默认内容如下所示：

```xml
<Application xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             x:Class="SampleSilverlightApplication.App">
  <Application.Resources>
  </Application.Resources>
</Application>
```

在前面的代码片段中，您可以看到只有一个名为 `Application` 的元素。`Application` 元素具有 `xmlns`、`xmlns:x` 和 `x:Class` 属性。`xmlns` 属性指的是用于处理 Silverlight 3.0 应用程序的默认命名空间。Silverlight 3.0 的默认命名空间是 http://schemas.microsoft.com/winfx/2006/xaml/presentation，它提供了处理 Silverlight 控件和类型的功能。`xmlns:x` 属性指的是提供 XAML 本身的类型和类的命名空间。请注意，每当您使用在默认 Silverlight 命名空间中未定义但在 XAML 命名空间中定义的<|message|>
