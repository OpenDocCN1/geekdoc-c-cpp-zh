The syntax to validate an Entity Model is:

```
EdmGen /mode:ValidateArtifacts /incsdl:<filename> /inmsl:<filename> /inssdl:<filename>
```

The EDM Generator tool provides five modes to perform specific functions, as listed in Table 22.8:

**Table 22.8**: Modes of the EDM Generator Tool

| Mode | Description |
|---|---|
| /mode:ValidateArtifacts | Requires at least one /inssdl or /incsdl argument. If /inmsl is specified, the /inssdl and /incsdl arguments are also required. You can specify this mode when you want to validate and display errors or warnings in the .csdl, .ssdl, and .msl files. |
| /mode:FullGeneration | Requires a /connectionstring argument and either a /project argument or /outcsdl, /outssdl, /outmsl, /outobjectlayer, /outviews, /namespace, and /entitycontainer arguments. This mode generates the .csdl, .ssdl, .msl, object layer, and view files by using the database information specified in the /connectionstring option. |
| /mode:FromSSDLGeneration | Requires the /inssdl argument and either a /project argument or the /outcsdl, /outmsl, /outobjectlayer, /outviews, /namespace, and /entitycontainer arguments. This mode generates the .csdl and .msl files, source code, and views from the specified .ssdl file. |
| /mode:EntityClassGeneration | Requires the /incsdl argument and either a /project argument or the /outobjectlayer argument. The /language argument is optional. This mode creates a source code file that contains the classes generated from the .csdl file. |
| /mode:ViewGeneration | Requires the /inssdl, /incsdl, /inmsl, and either the /project or /outviews arguments. The /language argument is optional. This mode creates a source code file that contains the view generated from the .ssdl, .csdl, and .msl files. |

Table 22.9 lists the noteworthy options of the EdmGen.exe tool:

**Table 22.9**: Options for the EdmGen.exe Tool

| Option | Description |
|---|---|
| /p[roject]:<string> | Specifies the project name to be used with the EdmGen.exe tool. By default, a project name is used as a namespace. The project name is also used for the names of EDM files and the name of view generation source file. |
| /c[onnectionstring]:<connection string> | Specifies a connection string that is required to connect to the data source. |
| /incsdl:<file> | Specifies a .csdl file or a directory that contains a .csdl file. We can use this argument multiple times if we want to specify more than one directory or .csdl files. It is mostly used during entity class or view generation. |
| /refcsdl:<file> | Is required when we refer to another .csdl file from the source .csdl file. This argument can be specified multiple times. |
| /inmsl:<file> | Specifies an .msl file or the location of .msl files. We can use this argument multiple times if we want to specify more than one directory or .msl files. It is mostly used during entity class or view generation. This is required in situations such as when the conceptual model is split. |
| /inssdl:<file> | Specifies the .ssdl file or a directory where the .ssdl file is located. |
| /outcsdl:<file> | Specifies the name of the .csdl file that will be created by the EdmGen.exe tool. |
| /outmsl:<file> | Specifies the name of the .msl file that will be created by the EdmGen.exe tool. |
| /outssdl:<file> | Specifies the name of the .ssdl file that will be created by the EdmGen.exe tool. |
| /outobjectlayer:<file> | Specifies the name of the source code file that contains the objects generated from the .csdl file. |
| /outviews:<file> | Specifies the name of the source code file that contains the views that were generated. |
| /language:[VB\|CSharp] | Specifies the language for the generated source code files. By default, the language is C#. |
| /namespace:<string> | Specifies the namespace we want to use. The namespace is set in the .csdl file when running the /mode:FullGeneration or /mode:FromSSDLGeneration mode. The namespace is not used when running the /mode:EntityClassGeneration mode. |
| /entitycontainer:<string> | Specifies the name used to apply to <EntityContainer> element in the generated EDM files. |
