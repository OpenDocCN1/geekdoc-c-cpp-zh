# Figure 1.68: Displaying Server Explorer

In Server Explorer, you can view and retrieve information from all the databases you are connected to. For example, you can view the information about all the database tables, views, stored procedures, and functions in this window. Server Explorer provides access to a number of resources. Using Server Explorer, you can view and manipulate data links, database connections, and system resources on any server, which is connected to the network. Some of the tasks that you can perform in Server Explorer are opening the data connections and commands, logging on to servers and displaying their databases and system services, viewing information about the available Web services, creating data connections to SQL Servers and other databases, storing database projects and references, and interacting with data resources by creating data components in your Visual Studio projects.

A node can be defined as a group of various subnodes that are used to perform specific functions in an application. There are three primary nodes in the Server Explorer, which are described as follows:

+   - Data Connections — Specifies a top-level node that lists the data connections added by a user to the server. You can make data connections of different databases, including Oracle databases running on UNIX or Microsoft Windows Operating Systems.
+   - Servers — Specifies a top-level node that contains a list of the currently connected servers. You can create new components by dragging the nodes from the Servers node onto Visual Studio Designer. The various child node types available in Servers node are described as follows:
+     - Crystal Reports Services — Lists the available Crystal Reporting options
+     - Event Logs — Lists the available event logs on the Microsoft Windows 2003 server, Microsoft Windows 2000 server, or Windows NT version 4.0
