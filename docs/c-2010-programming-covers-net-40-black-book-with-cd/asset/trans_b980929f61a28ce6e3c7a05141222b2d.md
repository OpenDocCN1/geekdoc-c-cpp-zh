## 操作文件

.NET Framework 在 System.IO 命名空间中提供了一组类，用于读取、写入或操作文件和目录。System.IO 命名空间允许同步和异步地从数据流和文件中读取和写入。 这些类用于执行各种操作，例如打开、读取、移动、复制和删除文件。 System.IO 命名空间提供的用于操作文件的一些类如下：

- FileStream
- StreamReader 和 StreamWriter
- BinaryReader 和 BinaryWriter
- File
- FileInfo
- Path

让我们逐一简要概述这些类。

### FileStream 类

FileStream 类允许您访问文件并对其进行操作。您可以使用 FileStream 类的构造函数创建、打开和共享文件。此类可以同步或异步打开文件。默认情况下，FileStream 类同步打开文件。打开或创建文件后，您可以将 FileStream 类的对象传递给 BinaryReader、BinaryWriter、StreamReader 和 StreamWriter 类，以便处理文件中的数据。

您可以使用 FileStream 类的 Seek() 方法导航到文件中的任何位置，这称为随机访问。另一种文件访问形式称为顺序访问。在顺序访问中，您只需按顺序读取或写入文件中的数据，即一个接一个。 这两种访问类型的唯一区别是，对于随机访问，您可以使用 Seek() 方法通过指定字节偏移量从当前位置导航到文件末尾。

### StreamReader 和 StreamWriter 类

您可以使用 StreamReader 和 StreamWriter 类在文件中读取和写入数据。StreamReader 类派生自名为 TextReader 的抽象类，该类从流中读取字符；StreamWriter 类派生自名为 TextWriter 的抽象类，该类向流中写入字符。StreamReader 和 StreamWriter 类对编码敏感；因此，它们可用于以不同的编码格式（如 UTF-8 和 UTF-16）读取和写入文本。您可以通过将文件名传递给其构造函数来创建 StreamReader 和 StreamWriter 的对象。
