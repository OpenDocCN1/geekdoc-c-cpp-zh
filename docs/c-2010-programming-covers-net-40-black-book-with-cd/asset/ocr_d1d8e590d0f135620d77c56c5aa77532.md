# Designing the Back-end Database

The database of this project acts as the back-end to store information, such as details of the articles, article comments, item details, and user details. This project uses Microsoft SQL Server 2008 to create the database for the Sports website, named as Sports. The tables used in the Sports database are as follows:

+   - Articles
+   - Comments
+   - Items
+   - Items_Categories
+   - Photos
+   - OrderDetails

Let’s look at the details of these tables.

> **NOTE**
> 
> Apart from the mentioned tables, you find some tables in the database prefixed with the aspnet_ keyword, such as aspnet_Applications and aspnet_Membership, are created automatically by the Login control using the membership service.
