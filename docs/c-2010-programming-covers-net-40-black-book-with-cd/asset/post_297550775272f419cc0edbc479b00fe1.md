## Working with Typography

Typography helps in formatting and presenting text in user-defined manner. As discussed earlier in the In Depth section, you can apply different effects to your text and transform your text, by using different typography classes. In this section, you learn to perform the following tasks:

- Display special characters
- Add decorations to the text
- Manipulate the text
- Wrap the text
- Trim the text
- Transform the text
- Add animations using the TextEffect element
- Add shadows to the text
- Apply the blur effect to the text

Let’s perform these tasks one by one.

### Displaying Special Characters

In WPF, if you want to display some symbols, such as <, >, and &, you cannot write them directly in your application, because these symbols are already assigned to perform a specific task. In this case, you need to use special characters in your application to display the symbols. Now, let’s create an application named SpecialCharacters (also available on the CD-ROM) to learn how to display special characters. For this, add the code, shown in Listing 11.1, to MainWindow.xaml:

### Listing 11.1: Showing the Code to Display Special Characters

```
<Window x:Class="SpecialCharacters.MainWindow"
xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
Title="MainWindow" Height="200" Width="300">
<Grid Height="263">
<TextBox Height="23" Margin="0,13,53,0" Name="textBox1" verticalAlignment="Top">
&lt;lt; is the Less than symbol.
</TextBox>
<TextBox Height="23" Margin="0,50,53,0" Name="textBox2" verticalAlignment="Top">
&gt;t; is the Greater than symbol.
</TextBox>
<TextBox Margin="0,87,53,152" Name="textBox3">
&amp; is the Ampersand symbol.
</TextBox>
<TextBox Height="23" Margin="0,0,53,107" Name="textBox4" verticalAlignment="Bottom">
&quot;Representing the Double Quote&quot;
</TextBox>
</Grid>
</Window>
```

### Manipulating the Text

In WPF, manipulation includes changing the numeral style, capital style, and variants of the text. The manipulation in the text is performed with the help of the OpenType font. By using the Capitals feature of OpenType font, you can set a typographical form that render text in capital-styled glyphs. The different types of capital styling formats that OpenType supports are: Small capitals, Petite capitals, Titling, and Capital Spacing. The OpenType font also supports features to be used with the numerical values in text. For example, OpenType supports the slashed and stacked styles for the fractional values. Let’s create a WPF application named ManipulatingTypography (also available on the CD-ROM) to learn how to manipulate text. Listing 11.3 shows the code of ManipulatingTypography:

### Listing 11.3: Showing the Code for Manipulating Text

```
<Window x:Class="ManipulatingTypography.MainWindow" xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation" xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml" Title="MainWindow" Height="100" Width="300">
<TextBlock FontFamily="P" FontSize="18" Typography.Fraction="Normal" IsHitTestVisible="True" Height="30">
<Run Typography.Capitals="AllSmallCaps">WATER</Run> = H<Run Typography.Variants="Subscript">2</Run>O (3/4 OF LAND)
</TextBlock>
</Window>
```

### Wrapping the Text

In WPF, when text is typed inside a TextBlock control, the text appears in a continuous line. However, you can use the TextBlock.TextWrapping property to display the text in the next line when it reaches right edge of the TextBlock control. Possible values for this property are WrapWithOverflow, NoWrap, and Wrap. By default, the value of this property is set to NoWrap. Let’s create a WPF application named TextWrapping (also available on the CD-ROM) to learn how to wrap the text. For this, add the code given in Listing 11.4 to MainWindow.xaml of TextWrapping:

### Listing 11.4: Showing the Code to Wrap the Text

```
<Window x:Class="TextWrapping.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="120" Width="300">
    <Grid>
        <TextBlock FontFamily="Century Gothic" FontSize="15" FontWeight="Bold"
            TextAlignment="Left" TextWrapping="Wrap">
            This is an example of text wrapping in a TextBlock. The text appears as
            in the next line.
        </TextBlock>
    </Grid>
</Window>
```

In Listing 11.4, we have added some text to the TextBlock control and set the TextWrapping property to Wrap. The output of Listing 11.4 is shown in Figure 11.4:

### Trimming the Text

In WPF, you can trim the text when it goes beyond the length of the container by using the TextTrimming property. This property takes any of the three values: None, CharacterEllipsis, and WordEllipsis. Table 11.25 lists the values of the TextTrimming property:

### Table 11.25: Showing the List of the TextTrimming Property Values

| Members | Description |
|---|---|
| None | Does not trim the text |
| CharacterEllipsis | Trims the text at the character boundary and draws an ellipsis in place of the remaining text |
| WordEllipsis | Trims the text at the word boundary and draws an ellipsis in place of the remaining text |
