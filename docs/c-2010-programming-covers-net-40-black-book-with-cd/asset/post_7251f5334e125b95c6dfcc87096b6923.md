## In Depth

A file is one of the mediums to store information in proper format and design. In C#, all the files should be properly handled to prevent the loss of information stored in them. File handling includes reading data from files, writing data to them, copying and moving files from one location to another, renaming, and deleting files. To handle files, you can use the System.IO namespace in your applications. This namespace provides various classes, such as FileStream, StreamReader, StreamWriter, BinaryReader, BinaryWriter, FileInfo, DriveInfo, Directory, and DirectoryInfo, to work with files. For example, you can use the FileStream class to read and write data into files either synchronously or asynchronously. The StreamReader and StreamWriter classes allow you to read and write text data in a stream, which refers to a flow of characters in a file. In addition to reading and writing the text data, you can also read and write binary data by using the BinaryReader and BinaryWriter classes. The FileInfo class allows you to create, open, move, copy, and delete files. While working with files, you often need to work with directories and drives, as files are stored in directories in a hierarchical format. You can use the Directory and DirectoryInfo classes to perform operations on directories, such as creating, moving, copying, renaming, and deleting directories.

In this chapter, you learn about the System.IO namespace, including the classes provided by it. You also learn how to retrieve information about a drive. Further, you learn how to work with directories and files in .NET. Finally, you learn about file compression. In the Immediate Solutions section, you learn how to implement these concepts in your applications.

The most commonly used classes in this namespace are FileStream, BinaryReader, BinaryWriter, StreamReader, and StreamWriter. ## Working with Drives

Before we start exploring drives in C#, let’s first examine few terms that are quite often used while working with drives. A list of some of these terms is given as follows:

- Drive letter — Represents the name provided by a user to the different logical drives of a system. To provide the name to a drive, you can use the Name property. This property helps you provide alphabetical identifiers, such as C:\, D:\, and E:\, to drives.
- Drive state — Specifies the state of a drive, such as whether the drive is in the ready state or not. You can use the IsReady property to determine the state of a drive. If you query a drive that is not in the ready state, an exception occurs.
- Drive type — Refers to the type of drive that is attached with your system. You can use the DriveType property to determine the type of drive. A drive can be of the CD-ROM, FIXED, UNKNOWN, NETWORK, NOROOTDIRECTORY, Random Access Memory (RAM), or REMOVABLE type. The values for all these types are specified in the DriveType enumeration. This enumeration defines the constants for drive types. Different members of the DriveType enumeration are as follows:
  - Unknown — Represents an unknown drive type
  - NoRootDirectory — Represents a drive that does not have a root directory
  - Removable — Represents a drive that is removable in nature, such as Floppy Disk Drive or Universal Serial Bus (USB) Flash Drive
  - Fixed — Represents a drive that is a fixed disk, and cannot be removed
  - Network — Represents a drive that is accessed through network
  - CD-ROM — Represents a drive that is optical in nature, such as CD or DVD ROM
  - RAM — Represents a drive that is Random Access Memory (RAM) disk
- Volume label — Helps in setting or retrieving the name of a drive. The length of the label is based on the type of operating system. For example, New Technology File System (NTFS) allows a volume label of up to 32 characters long. You can set a volume label of a drive with the help of the VolumeLabel property of the DriveInfo class. Note that if you enter Null as your drives volume label, no exception occurs because the VolumeLabel property allows Null values.
- File system format — Specifies the name of the file system provided to a drive, such as NTFS or FAT. NTFS is the most standard file system of Windows NT. It is supported by all the later versions of Windows, such as Windows 2000, Windows XP, Windows Server 2003, and Windows Vista. On the other hand, the FAT file system is supported by almost all the existing operating systems, mainly the computers for personal usage.
- Free space on drive—Represents the free space available on a drive. You can use AvailableFreeSpace property to calculate the amount of available free space for the current user, bytes.

C# provides the DriveInfo class to retrieve the information contained in a drive. The DriveInfo class models the drive and provides methods and properties to obtain information about the available drives, the type of data they contain, their total capacity, and free space available on them. ## Working with Directories

Directories are the entities that act as a store house for files. C# provides two classes, Directory and DirectoryInfo, to work with directories. The Directory class is one of the most important classes for working with directories. This class exposes static methods that help in creating, moving, and enumerating directories and subdirectories. The Directory class is also used to set date and time information of when a directory was created and accessed. It is important to note that you cannot inherit the Directory class.

The inheritance hierarchy of the Directory class is as follows:

```
System.Object
System.IO.Directory
```
