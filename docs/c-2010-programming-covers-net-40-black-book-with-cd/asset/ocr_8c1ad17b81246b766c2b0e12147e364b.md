# Dependency Property Validation and Coercion Callbacks

WPF also offers validation callbacks that validate the value of the dependency properties. The validation callback can be called when the value of the dependency property is programmatically changed and the property metadata is overridden. Validation callbacks are suitable for checking if a particular value is within a particular range.

Validation callbacks are static methods that take a single object as its argument and return a Boolean value, which indicates the validity of the value. If the value is valid and acceptable to the dependency property, then true is returned; else false is returned. In case false is returned by the validation callback, an exception occurs. The ValidateValueCallback delegate takes the parameter of the validation callback, which denotes a validation callback for a dependency property. This delegate is, itself, provided as an argument when the dependency property is registered. The syntax of the validation callback method is as follows:

```
public static type validationCallbackMethod(object value)
{
    //validation logic
}
```

In the preceding syntax:

+   - public, static, object—Represents C# keywords
+   - type—Represents the type of the dependency property
+   - validationCallbackMethod—Represents the name of the validation callback method that is passed as an argument to the ValidateValueCallback delegate
+   - value— Represents the value that is to be validated

You can also coerce the values of the dependency properties to a particular value or a range of values through the coerce callbacks. You may also want that the value of a dependency property changes depending on the changes in some other properties. In such a case, you can use a property change callback along with the coercion callback. The coercion and changes in the dependency properties are implemented as static methods that are passed as arguments to the CoerceValueCallback and PropertyChangedCallback delegates, respectively, at the time of specifying the property metadata. Note that if the proposed value for coercion is not acceptable by the dependency property, then the callback method returns a special value called UnsetValue. In such a case, the proposed value is discarded and the property is set back to the original value.

The syntax of the coerce value callback method is as follows:

```
private static object coerceCallbackMethod(DependencyObject dObject, object value)
{
    //coercion logic
}
```

In the preceding syntax:

+   - private, static, object, DependencyObject—Represents the C# keywords
+   - coerceCallbackMethod—Represents the name of the coercion callback method that is passed as an argument to the CoerceValueCallback delegate
+   - dObject—Represents the owner of the dependency property
+   - value—Represents the value that is to be validated and then coerced

The syntax of the property changed callback method is as follows:

```
private static void propertyChangedMethod(DependencyObject dObject,
    DependencyPropertyChangedEventArgs eArgs)
{
    //property changed logic
}
```
