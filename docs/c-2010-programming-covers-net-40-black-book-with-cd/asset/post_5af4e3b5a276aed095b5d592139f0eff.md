## Converting a String Type to a Number Type

While creating C# applications, there are times when you need to convert input, which is in the form of textual data, into a numeric format so that computations can be performed on it. Some examples of such cases include reading lines from a text file and converting them into numbers and reading input from users using forms and then converting those input text strings into numbers so that they can be compared and used for calculations.

In C#, to convert a string to other data types, you can use the conversion functions built into the string class. Now, let’s create a new C# 2010 Console application, named StringToNumber (also available on the CD-ROM) by performing the steps given in the heading, Declaring Variables, earlier in this chapter.

### Listing 2.16: Showing the Code of the StringToNumber Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace StringToNumber
{
    class Program
    {
        static void Main(string[] args)
{
    string str1 = "123.45";
    string str2 = "123.00";
    // Converting both strings to floating-point numbers
    Single sngl1 = Convert.ToSingle(str1);
    Single sngl2 = Convert.ToSingle(str2);
    Console.WriteLine("Single 1 = {0}", sngl1);
    Console.WriteLine("Single 2 = {0}", sngl2);
    // Converting both strings to Double
    double x = Convert.ToDouble(str1);

}
```

In Listing 2.16, we have used the ToDouble() method of the Convert class to convert a string to integers or floating-point numbers. ## Converting Two Nullable Types

A non-nullable value type is implicitly converted to a nullable type of that value type. In addition, conversion takes place from a null literal to a nullable type. You can perform predefined and user-defined conversions on non-nullable value types and nullable forms of those value types. These conversions take place from A to B? and A? to B. The conversion from A? to B is an explicit conversion, which issues an exception, if the source value is null. Now, let’s create a new C# 2010 Console application, named NullableConversion (also available on the CD-ROM) by performing the steps given in the heading, Declaring Variables, to learn how to convert nullable types into non-nullable types. Add the code, shown in Listing 2.17, in the Program.cs file of the NullableConversion application to understand the nullable type conversion:

### Listing 2.17: Showing the Code for the Nullable Type Conversion

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace NullableConversion
{
    class Program
    {
        static void Main(string[] args)
        {
            int m = 123;
            //Assigning value of integer variable m to nullable integer variable
            int? a = m;
            Console.WriteLine("The value of a is " + a);
            //Assigning value of nullable integer variable to nullable double variable
            double? b = a;
            Console.WriteLine("The value of nullable double variable is " + b);
//Converting nullable double to nullable int and assigning the value to nullable integer variable
int? c = (int?)b;
Console.WriteLine("The value of nullable integer variable is " + c);
//Converting nullable int to integer type and assigning value to integer variable
int n = (int)c;
Console.WriteLine("The value of integer variable is " + n);
Console.ReadLine();
} }
```

In Listing 2.17, we have declared a variable, m, of integer data type and assigned a value of 123 to it, which is further assigned to the nullable variable a. The data types of both these variables are same; therefore, there is no need for type conversion. The code line double? b=a assigns the value of a to a nullable double variable b by implicitly converting its type. Note that when we assign the value of nullable variable b to the nullable integer variable c, explicit type conversion is required, because the double type cannot be implicitly converted to the integer type. Finally, we convert the nullable integer type to integer type. The output of Listing 2.17 is shown in Figure 2.14:

## Using the is and as Operators

The is operator checks whether an object is compatible with the given type or not and returns a Boolean result, i.e. either true or false. The object may either be of the same type or may be derived from that particular given type. The as operator converts the reference types explicitly into a specific type. If the reference type is compatible with the specified type, it performs successful conversion; otherwise, it returns the null value. Note that the as operator does not throw an exception. Let’s create a new C# 2010 Console application, named IsandAs (also available on the CD-ROM) by performing the steps given in the heading, Declaring Variables, to learn how to use the is and as operators.
