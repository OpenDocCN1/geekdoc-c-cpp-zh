## Using the while Loop

The while loop in C# is used to repeat a process until the specified condition becomes true. Let’s create a console application named MyWhileLoop (also available on the CD) that shows how to use a while loop. Listing 3.5 shows the code of the MyWhileLoop application:

### Listing 3.5: Showing the Code of the MyWhileLoop Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MywhileLoop
{
    class Program
    {
        static void Main(string[] args)
        {
            // Example 1
            // An example of a simple while loop
            Console.WriteLine("Loop 1:");
            int i = 0;
            while (i < 5)
            {
                Console.WriteLine("I = {0}", i);
                i++;
            }
            // Example 2
            // A while loop with a boolean
            bool flag = false;
            i = 0;
            Console.WriteLine("\nLoop 2:");
            while (!flag)

                    flag = true;
                Console.WriteLine("I = {0}", i);
                i++;
            }
            // Example 3
            // A loop that will never execute
            Console.WriteLine("\nLoop 3: ");
            while (i <= 0)

                Console.WriteLine("I = {0}", i);
                i++;
            }
            Console.Write("\nPress ENTER to quit...");
            Console.ReadLine();
        }
    }
}
```

Listing 3.5 contains three examples to show the use of the while loop. The first example is a simple while loop example. In the third example, the while loop is not executed because the specified condition in the while statement is met before the execution of first iteration.

## Using the do...while Loop

The working of do...while loop is quite similar to that of for loop and while loop. The do...while loop does not contain any initialization statement nor it is automatically incremented. Unlike the while loop, the do...while loop checks a condition at the end of the loop rather than at the beginning. As a result, the do...while loop is always executed at least once, irrespective of whether the given condition is true or false. Let’s create a console application named MyDoWhileLoop (also available on the CD) that shows the use of a do...while loop.

### Listing 3.6: Showing the Code of the MyDoWhileLoop Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyDoWhileLoop
{
    class Program
    {
        static void Main(string[] args)
        {
            // First, a simple do loop that
            // increments a counter
            int i = 0;
            Console.WriteLine("Loop 1:");
            do
            {
                Console.WriteLine("I = {0}", i);
                i++;
            }
            while (i < 5);
            // Next, the same case, but using a
            // boolean rather than an index
            i = 0;
            Boolean done = false;
            Console.WriteLine("\nLoop 2:");
            do
            {
                Console.WriteLine("I = {0}", i);
                i++;
                if (i > 5)
                    done = true;
            }
            while (!done);
            // Finally, a conditional that is true before
            // You get into the loop
            do
            {
                Console.WriteLine("Into Loop 3");
            }
            while (!done);
            Console.Write("\nPress ENTER to quit...");
            Console.ReadLine();
        }
    }
}
```

Listing 3.6 contains three examples to show the use of the do...while loop. In the first example, a do...while loop displays the value of the i variable till the condition specified in the while statement is true. The second example contains a do...while loop that checks a Boolean flag. In the third example, the condition specified in the while statement is false, but then also the while loop executes once.
