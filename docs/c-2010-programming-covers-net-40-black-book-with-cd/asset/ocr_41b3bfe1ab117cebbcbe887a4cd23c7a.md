# Toolbars

The Toolbars in the Visual Studio 2010 provide developers with an easy access to the features of the IDE. The Visual Studio 2010 IDE provides different toolbars, such as Standard, Layout, Formatting, Debug, and Image Editor for each category of tasks that are needed to develop an application. The Standard Toolbar is the default toolbar that appears when you open Visual Studio 2010, as shown in Figure 1.53:

![](bbox=[0.02, 0.58, 0.94, 0.62])

Users can customize this toolbar by adding or removing buttons from it. The Standard toolbar contains the following buttons:

+   New Project — Creates a new project or a new website
+   Add New Item — Exists in the following two subcategories that are self-explanatory in nature:
+   - Add New Item — Adds a new item, such as Web form and Style sheet in the Web application
+   - Add Existing Item — Adds an item that is already present in the local system in the Web application, such as images

+   Save — Saves the form that is currently designed

+   Copy — Copies the objects or items

+   Undo — Reverts the changes made in an application
+   Redo — Reverts the changes made in an application by clicking the Undo button of the Standard toolbar
+   Navigate Backward — Navigates to the previously visited location within the application

+   Solution Configuration — Specifies the configuration of a project
