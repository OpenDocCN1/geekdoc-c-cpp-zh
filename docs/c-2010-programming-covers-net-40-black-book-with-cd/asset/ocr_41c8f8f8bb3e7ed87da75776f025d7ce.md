# Creating Windows Services Applications

In Visual C# 2010, Windows services are created by using the ServiceBase class. To create a Windows service, you should override the OnStart or OnStop event handlers, which are called when the service starts or stops, respectively. You can also override the OnPause and OnContinue event handlers to handle events when the service is paused and resumed.

> Tip
> You can pause and resume a service by using the CanPauseAndContinue property of the ServiceBase class; by default, this property is set to False.

Let’s take the following broad level steps to create a Windows service:

+   1. Create a new Windows service project
+   2. Write to an event log
+   3. Add an installer to a Windows service application

# Creating a New Windows Service Project

In this section, you learn to create a Windows service application named MyWindowsService (also available on CD).

Perform the following steps to create the MyWindowsService application:

+   1. Open Visual Studio 2010 IDE.
+   2. Select File→New→Project. The New Project dialog box appears (Figure 20.1).
+   3. Select Visual C#→Windows from the Installed Templates pane and select the Windows Service template in the New Project dialog box (Figure 20.1).
+   4. Enter a project name and location for the project in the Name text box and Location combo box, respectively. In our case the project name is MyWindowsService and project location is D:\Black Books\C# 2010\Chapter 20\, as shown in Figure 20.1:
