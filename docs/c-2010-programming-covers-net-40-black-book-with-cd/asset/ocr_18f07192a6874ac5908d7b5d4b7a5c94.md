    dataGridView2.DataSource = ds.Tables[0];
}

# OLEDB Database

OLEDB is an Application Programming Interface (API) designed by Microsoft for accessing different types of data stored in different formats. It can be used to access Oracle, SQL Server, or even an Access file. In this section, you learn to connect to the Access database file by using OLEDB. In .NET 4.0, you can connect to the OLEDBDatabase (available in the CD-ROM) in which you can retrieve the data from the Access file in both ways. Now, perform the following steps to retrieve the data from the Access file in both ways.

+   1. Add a Button and two DataGridView controls to Form1, as we did in the preceding section.
+   2. Select the dataGridView1 control and click the Smart Tag to select the content for the dataGridView1 control.
+   3. Select the Add Project Data Source option from the Choose Data Source drop-down list in the Smart Tag of the dataGridView1 control. This opens the Data Source Configuration Wizard.
+   4. Select Database as the data source type and click the Next button to open the Choose a Database Model page.
+   5. Select Dataset as the Database Model in the Choose a Database Model page and click the Next button to open the Choose your Data Connection page.
