## 插入节点

您也可以在XML文档中插入新的元素节点。让我们创建一个名为ShowingNodes（也可在CD上获得）的应用程序来在XML文档中插入节点。

执行以下步骤来创建ShowingNodes：

- 1. 创建一个名为ShowingNodes的Windows窗体应用程序。
- 2. 将authors.xml文件添加到ShowingNodes应用程序的bin\Debug文件夹中。
- 3. 在Form1.cs文件中添加以下命名空间：
- using System.Xml;
- 4. 打开Form1窗体的设计器，从工具箱中拖拽一个列表框和一个按钮到窗体上。将button1的Text属性设置为Show Elements。
- 5. 双击button1并添加以下代码片段：

```
private void button1_Click(object sender, EventArgs e)
{
listBox1.Items.Clear();
XmlDocument xd = new XmlDocument();
xd.Load("authors.xml");
XmlElement newAuthor = xd.CreateElement("authors");
newAuthor.SetAttribute("au_id", "712-45-1867");
XmlElement lname = xd.CreateElement("au_lname");
lname.InnerText = "del Castillo";
newAuthor.AppendChild(lname);
XmlElement fname = xd.CreateElement("au_fname");
fname.InnerText = "Innes";
newAuthor.AppendChild(fname);
xd.DocumentElement.AppendChild(newAuthor);
XmlTextWriter tr = new XmlTextWriter("newAuthors.xml", null);
tr.Formatting = Formatting.Indented;
xd.WriteContentTo(tr);
tr.Close();
XmlNodeList nl = xd.GetElementsByTagName("au_lname");
foreach (XmlNode node in nl)
listBox1.Items.Add(node.InnerText);
}
```

在上述代码片段中，我们首先清空了列表框。之后，创建了一个XmlDocument类的对象，然后从磁盘加载XML文件authors.xml到XmlDocument对象中。现在，通过调用XmlDocument对象的CreateElement()方法创建一个新的authors元素，向该元素添加数据，最后将authors元素附加到XmlDocument对象。

通过传递新XML文件的名称newAuthors.xml，创建了一个XmlTextWriter类的对象。然后将XmlTextWriter对象的Formatting属性设置为Formatting.Indented，并通过传递该XmlTextWriter对象来调用XmlDocument的WriteContentTo()方法。接下来，调用XmlTextWriter类的Close()方法来关闭文件。我们还通过调用XmlDocument类的GetElementsByTagName()方法搜索所有标签名为au_lname的元素，并将这些元素添加到XmlNodeList类的集合中。最后，将所有标签名为au_lname的元素的数据添加到列表框。

6. 按F5键运行ShowingNodes应用程序。在输出中，当您单击Show Elements按钮时，所有标签名为au_lname的元素都会添加到列表框中，如图30.6所示：

## 导航和转换数据

您已经在深入探讨部分了解到，System.Xml.XPath命名空间包含一些类，可以根据元素文本值或属性值来选择元素的子集。此外，System.Xml.XPath命名空间中所包含的类可在XML文档上执行快速迭代和选择。除此之外，System.Xml.Xsl命名空间包含用于在.NET Framework中执行XSL转换的类。

在本节中，您将学习如何导航和转换XML文档的数据。为此，我们在以下各节创建的应用程序中使用相同的XML文件authors.xml。

### 根据属性值导航和查找元素

您可以借助属性值在XML文档的不同节点之间导航。让我们创建一个名为XMLElementsNavigation（也可在CD上获得）的应用程序，在XML文档的不同节点之间导航。

执行以下步骤来创建XMLElementsNavigation应用程序：

- 1. 创建一个名为XMLElementsNavigation的Windows窗体应用程序。
- 2. 将authors.xml文件添加到XMLElementsNavigation应用程序的bin\Debug文件夹中。
- 3. 在Form1.cs文件中添加以下命名空间：

```
using System.Xml;
using System.Xml.XPath;
```

- 4. 打开Form1窗体的设计器，从工具箱中拖拽一个列表框和一个按钮到窗体上。
- 5. 将button1的Text属性设置为Find Elements。

6. 双击button1并添加以下代码片段：

```
private void button1_Click(object sender, EventArgs e) {
    listBox1.Items.Clear();
    XPathDocument pd = new XPathDocument("authors.xml");
    XPathNavigator pn = ((IXPathNavigable)pd).CreateNavigator();
    XPathNodeIterator ni = pn.Select("/authorslist/authors[@au_id='409-56-7008']");
    while(ni.MoveNext())
    {
        XPathNodeIterator newni = ni.Current.SelectDescendants(XPathNodeType.Element, false);
        while(newni.MoveNext())
        {
            listBox1.Items.Add(newni.Current.Name + ": " + newni.Current.Value);
        }
    }
}
```

在上述代码片段中，我们创建了一个空列表框。然后，通过将XML文件（authors.xml）名称作为参数传递，创建了一个XPathDocument类的对象。注意，authors.xml文件已经放在项目的bin\Debug文件夹中，因此应用程序会自动检测到XML文件的位置。接下来，我们先将XPathDocument对象强制转换为IXPathNavigable接口，然后调用IXPathNavigable接口的CreateNavigator()方法，从而创建了一个XPathNavigator类的对象。

之后，通过调用XPathNavigator对象的Select()方法，创建了一个XPathNodeIterator类的对象。Select()方法返回属性au_id值为409-56-7008的所有authors元素。然后使用XPathNodeIterator对象的MoveNext()方法在while循环中遍历XML文档的节点。在循环内部，我们创建了一个XPathNavigator类的对象，它是当前元素的子元素。我们再次使用XPathNodeIterator对象的MoveNext()方法在另一个while循环中遍历XML文档的节点。在循环内部，元素的文本值被添加到列表框。

7. 按F5键运行XMLElementsNavigation应用程序。在输出中，当您单击Find Elements按钮时，所有具有指定属性值的元素都会添加到列表框中，如图30.7所示：

### 转换XML

您可以使用XSLT文件将XML文档转换为HTML文档。让我们创建一个名为TransformingXML（也可在CD上获得）的应用程序，将XML文档转换为HTML文档。

执行以下步骤来创建TransformingXML应用程序：

- 1. 创建一个名为TransformingXML的Windows窗体应用程序。
- 2. 将authors.xml文件添加到TransformingXML项目的bin\Debug文件夹中。
- 3. 在TransformingXML项目的bin\Debug文件夹中创建并保存一个XSLT文件authors.xslt
- 清单30.6显示了authors.xslt文件的代码：

#### 清单30.6：显示authors.xslt文件的代码

```
<?xml version="1.0" encoding="UTF-8" ?>
<xsl:stylesheet version="1.0" xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
<xsl:template match="/">
<html>
<head>
<title>Authors</title>
</head>
<body>
<table border ="1">
<xsl:apply-templates/>
</table>
</body>
</html>
</xsl:template>
<xsl:template match="authorslist">
<xsl:apply-templates select="authors"/>
</xsl:template>
<xsl:template match="authors">
<tr>
<td>
<xsl:value-of select ="au_lname"/>
</td>
<td>
<xsl:value-of select ="au_fname"/>
</td>
</tr>
</xsl:template>
</xsl:stylesheet>
```

- 4. 在Form1.cs文件中添加以下命名空间：

```
using System.Xml;
using System.Xml.Xsl;
```

- 5. 打开Form1窗体的设计器，从工具箱中拖拽一个Web浏览器和一个按钮到窗体上。
- 6. 将button1的Text属性设置为Generate HTML。
- 7. 双击button1并添加以下代码片段：

```
private void button1_Click(object sender, EventArgs e)
{
XslCompiledTransform ct = new XslCompiledTransform();
ct.Load("authors.xslt");
ct.Transform("authors.xml", "authors.html");
webBrowser1.Url = new Uri(AppDomain.CurrentDomain.BaseDirectory
+ "authors.html");
}
```
