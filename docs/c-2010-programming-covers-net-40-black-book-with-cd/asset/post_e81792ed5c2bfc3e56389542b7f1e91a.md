## Converting ADO.NET and XML Data

You already learned that ADO.NET provides some powerful features that are used to read and write XML documents. You can create an XML file with the data from an ADO.NET data source by first filling a DataSet object with the data from an ADO.NET data source and then calling the WriteXml() method of the DataSet object. The WriteXml() method has two overloaded forms, one of which takes a string with the file path and name, and the other takes one more parameter to specify the mode, which takes the value from an XmlWriteMode enumeration. One of the values of the XmlWriteMode enumeration is DiffGram, which specifies an XML document that contains data related to pre- and post-edit sessions.

In this section, you learn the conversion between ADO.NET data and XML data. Note that in the following section, we are using the Northwind database for displaying and accessing the SQL data. Let’s start the conversion of the ADO.NET data into XML data.

## Writing Data into a DiffGram

In this section, we are creating the WritingDataToDiffGram application (also available on the CD) to use a DiffGram for storing data before and after an edit session. This can be done by performing the following steps:

- 1. Create a Windows Forms application, named WritingDataToDiffGram.
- 2. Drag and drop a Web browser and a button control from the Toolbox.
- 3. Set the Text property of the button to Show Data.
- 4. Add the code given in Listing 30.8 to the Form1.cs file:

### Listing 30.8: Showing the Code of the Form1.cs File of the WritingDataToDiffGram Application

```
using System;
using System.Collections.Generic;
using System.ComponentModel;
using System.Data;
using System.Drawing;
using System.Linq;
using System.Text;
using System.Windows.Forms;
using System.Data.SqlClient;
using System.Xml;
namespace WritingDataToDiffGram
{
    public partial class Form1 : Form
    {
        public Form1()
        {
            InitializeComponent();
        }
        private void button1_Click(object sender, EventArgs e)
        {
            string str1 = "Data Source=.;Initial Catalog=Northwind;Integrated Security=True";
            SqlConnection con = new SqlConnection(str1);
            string str2 = "Select EmployeeID,FirstName,Title,HireDate from Employees";
            SqlDataAdapter da = new SqlDataAdapter(str2, con);
            DataSet ds = new DataSet("employeeslist");
            da.Fill(ds, "Employees");
            DataRow dr = ds.Tables[0].NewRow();
            dr["EmployeeID"] = 7;
            dr["FirstName"] = "King";
            dr["Title"] = "Sales Representative";
            ds.Tables[0].Rows.Add(dr);
            ds.WriteXmlSchema("employees.xdr");
            ds.WriteXml("employeesdiff.xml", XmlWriteMode.DiffGram);
            ds.AcceptChanges();
            webBrowser1.Url = new Uri(AppDomain.CurrentDomain.BaseDirectory + "employeesdiff.xml");
        }
    }
```

In Listing 30.8, the System.Data.SqlClient and System.Xml namespaces are added. We have assigned a connection string to a string variable to connect to the Northwind database. After that, we have created an object of the SqlConnection class by passing a string variable to it and assigning an SQL command to another string variable. We have also created an object of the SqlDataAdapter class by passing the string variable containing the SQL command and an object of the SqlConnection class to it. Then, we created an object of the DataSet class with the name employeeslist.

Next, the Fill() method of the SqlDataAdapter object is called by passing the DataSet object as one parameter and name of the data table as the second parameter to it. Then, we create a new row for the Employees data table and add data to it. A new row is added to the Rows collection of the Employees data table. A schema file, employees.xdr, is written by calling the WriteXmlSchema() method of the DataSet object. This schema file is used for reading data in the DiffGram.

Next, a DiffGram, employeesdiff.xml, is created by calling the WriteXml() method of the DataSet object and passing XmlWriteMode.DiffGram as a mode parameter to it. Then, the changes made are accepted by calling the AcceptChanges() method of the DataSet object. Finally, the data of the DiffGram is displayed on a Web browser.
