## Displaying the Life Cycle of a Page

An event is generated whenever a user interacts with a Web page. A group of events, known as page events, are automatically raised when a page loads in ASP.NET. When an event is generated, a Web site performs the appropriate task related to the generated event. When you send a request to the Web server for a particular page, the page runs through a series of events during its creation at the server and disposal at the client. This collection of events as whole is known as a page’s life cycle. As you are already know about page events, having read about them in the In Depth section of the chapter, we create a Web site called PageLifeCycle to display the life cycle of a Web page. ## Handling Events

The types of events we have been dealing with until now are handled on the server, not in the browser. However, waiting for events to be handled on the server can be a tedious process. Therefore, you can also add scripting to your Web pages that can support client-side events. Usually, we will stick with server-side code in our Web applications, but you can also let the browser handle some events on the client-side.
