# Snaplines

The Snaplines feature in WPF Designer is used to assist you in aligning the controls in WPF applications. A snapline appears only when there is more than one control and you want to align the controls in such a manner that the edges of the controls are aligned to each other. A snapline appears as a light brown line along with the edges of controls, as shown in Figure 9.21:

![](bbox=[0.275, 0.475, 0.79, 0.73])

In Figure 9.21, you can see that at one end of the snapline, the number 69 is displayed. This number represents the distance between the edges of the controls that you want to align. In case you do not want to see the snaplines, you can press ALT from the keyboard while dragging or resizing the control.
