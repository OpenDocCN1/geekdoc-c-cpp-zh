## EntityDataSource 控件

EntityDataSource 控件帮助您连接到 ADO.NET 实体数据模型（EDM）以执行各种数据库操作，例如创建、插入、删除和更新。 当您向 ASP.NET 页面添加 EntityDataSource 控件时，以下代码行出现在源视图页面中：

```
<asp:EntityDataSource ID="EntityDataSource1" runat="server"> </asp:EntityDataSource>
```

EntityDataSource 控件的继承层次结构如下：

```
System.Object
  System.Web.UI.Control
    System.Web.UI.DataSourceControl
      System.Web.UI.WebControls.EntityDataSource
```
