The error generated by the compiler indicates that the var keyword recognizes the value, operators, method assigned to it. Now, let's compile the same code snippet by replacing the var keyword with the dynamic keyword, as shown in the following code snippet:

```
class Program
{
    static void Main(string[] args)
```

In the preceding code snippet, the NonExistingFunction() method is called by the str variable, which is of the dynamic data type. In this case, the compiler does not check whether the method exists or not, as it is associated with the dynamic keyword. Therefore, the compiler does not raise any error and compiles the application successfully. The dynamic data type is very useful when the programmers want to allocate the data type of the variable at run time or to store the values generated by the program at runtime.

Let's now learn how to convert one data type into another.

# Converting the Data Types

In C#, the System.Convert class provides a complete set of methods for converting the data types. This class provides conversion in a language-neutral way to perform conversion in all the languages that support CLR. On the other hand, the objects of a dynamic data type can be easily converted into objects of non-dynamic data types without using the System.Convert class. A dynamic object is implicitly converted to a dynamic data type, which enables you to easily switch between dynamic data type and non-dynamic data type. Following code snippet shows how to convert a non-dynamic data type into a dynamic data type:

```
dynamic dynDouble = 5.46;
dynamic dynString = "test string";
dynamic dynBool = true;
dynamic dynToday = System.DateTime.Today;
```

In the preceding code snippet, we have declared four dynamic variables and assigned them a value for different types, such as double, string, bool, and Datetime. Similarly, you can also convert variables of dynamic data type to those of non-dynamic data type, as shown in the following code snippet:

```
double f = dynDouble;
string str = dynString;
bool check = dynBool;
DateTime date = dynToday;
```

In the preceding code snippet, values of the dynamic data type variables have been assigned to the double, string, bool, and DateTime variables.
