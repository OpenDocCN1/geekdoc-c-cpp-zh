# Using the do...while Loop

The working of do...while loop is quite similar to that of for loop and while loop. The do...while loop does not contain any initialization statement nor it is automatically incremented. Unlike the while loop, the do...while loop checks a condition at the end of the loop rather than at the beginning. As a result, the do...while loop is always executed at least once, irrespective of whether the given condition is true or false. Let’s create a console application named MyDoWhileLoop (also available on the CD) that shows the use of a do...while loop.
