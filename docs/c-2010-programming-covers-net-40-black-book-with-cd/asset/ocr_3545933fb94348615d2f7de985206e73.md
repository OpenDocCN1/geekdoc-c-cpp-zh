# Adding Shortcuts to User Desktop or User Programs Menu

After adding a setup project to your application, you can also define the shortcuts to be created on the user desktop or user program menu.

Figure 21.18: Displaying the Addition of the DeploymentTestSetup Project in the DeploymentTest Solution

![](bbox=[0.25, 0.06, 0.815, 0.325])

Let’s add a shortcut for the DeploymentTest application by performing the following steps:

+   1. Select Application Folder in the File System on Target Machine pane. Now, right-click the Primary output from the DeploymentTest (Active) option and select Create Shortcut to Primary output from DeploymentTest (Active) option from the context menu, as shown in Figure 21.19:

![](bbox=[0.22, 0.485, 0.835, 0.67])

Figure 21.19: Selecting the Create Shortcut to Primary Output from the DeploymentTest (Active) Option

This creates a shortcut within the same folder.

+   2. Modify the name of the newly created shortcut as per you choice. In our case, we have renamed it as DeploymentTestApplication, as shown in Figure 21.20:

![](bbox=[0.22, 0.745, 0.835, 0.91])

Figure 21.20: Displaying a New Shortcut Name-DeploymentTestApplication
