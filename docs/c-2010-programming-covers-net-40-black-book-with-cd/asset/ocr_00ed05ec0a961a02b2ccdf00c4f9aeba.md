# Chapter 36: Security in .NET 4.0

Anonymous authentication is the default authentication mode of IIS. You can see this default setting by opening the IIS Manager. To view the IIS Manager, open the Run dialog box of the Windows operating system, type inetmgr in the Open box, and click the OK button. The IIS Manager window opens, as shown in Figure 36.6:

![](bbox=[0.165, 0.122, 0.889, 0.484])

**Figure 36.6: Displaying the IIS Manager Window**
