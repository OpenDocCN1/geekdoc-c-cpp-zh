## The Menu Control

The Menu control is another Navigation control, which is also used to display site navigation information. The Menu control can, however, display the site structure vertically as well as horizontally. It can be used as a databound control, for example, binding the menu control to a SiteMapDataSource control. It can also retrieve the data to be displayed from the items that are added to the Items collection of the Menu control at runtime. The Menu control supports binding data with hierarchical data sources, such as XML files. You can also add the data items to the Menu control at runtime using the Items collection of the Menu control. The Menu control consists of one or more MenuItem objects displayed at different levels of hierarchy. Each MenuItem, in turn, consists of properties to set the style of the individual MenuItem. The Menu control contains two types of menus:

- Static menu – Refers to the type of menu that is displayed completely on the screen with all the menu options on the screen. The entire structure of the static menu, including the parent menu items and their submenus, is visible.
- Dynamic menu – Refers to the type of menu that contains a static part, which is displayed on the screen, as well as a dynamic part, which appears when the user passes the mouse pointer over the static part of the menu.

### Menu Display Properties

You can change the look of the Menu control by setting the following properties:

- **Orientation** – Means that you can set this property to horizontal to display the menu either at the top or at the bottom of the page. The default orientation value is Vertical.
- **StaticItemFormatString** – Means that you can set this property to display the value for the static menus.
- **DynamicItemFormatString** – Means that you can set this property to display the value for the dynamic menus.
- **StaticPopOutImageUrl** – Means that you can set the replacement image for StaticPopOutImage. This means that the menu items can be hovered over to display all of their child items. The default image will appear dynamically and continue to be used for menu items.

### Menu Styles

The Menu control supports various styles at different levels, such as on individual menu items and menu sublevels. You can set styles for all menu levels and menu items that appear as both statically and dynamically on a Web page. The following are the different style properties:

- **Static/DynamicMenuStyle** – Controls properties for all MenuItem properties. It also controls properties such as HorizontalPadding and VerticalPadding.
- **DynamicMenuItemStyle** – Controls the style of the individual MenuItem properties. It also includes style properties such as ItemSpacing, VerticalPadding, and HorizontalPadding.
- **DynamicSelectedStyle** – Sets the style of the individual nodes in the TreeView control that are currently selected. In other words, it can be described as a collection of style properties for the selected menu item. It also includes style properties such as HorizontalPadding, VerticalPadding, and ItemSpacing.
- **DynamicHoverStyle** – Sets the style properties of the individual MenuItem properties that are currently selected. In other words, it can be set for the selected MenuItem while you hover your mouse over a MenuItem. It also includes properties such as ItemSpacing, HorizontalPadding, and VerticalPadding.

### The SiteMapPath Control

The SiteMapPath control is also known as the breadcrumb Navigation control. Breadcrumb allows you to display the current page's context within the entire structure of a Web site. It also allows you to display links as a path back to the home page. It displays information regarding the user's current page along with the entire hierarchy of the pages, thereby enabling the user to navigate back to some other pages in the hierarchy.

However, the SiteMapPath control does not allow you to move forward from the current page to the next page deeper in the site hierarchy. The SiteMapPath control does not use the SiteMapDataSource control to display data. It relies on a SiteMapProvider to retrieve the data. The SiteMapProvider contains an XML file Web.sitemap, which contains URLs and other information about the pages to be displayed. The SiteMapPath control can be localized by adding attributes to the Web.sitemap file.
