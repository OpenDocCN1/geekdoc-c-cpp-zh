# HeaderedItems Controls

HeaderedItems controls are used to display main, parent-level controls, or objects along with their child controls. HeaderedItems controls host header child elements and content that may or may not be a collection. The Header property labels the items of a control and the ItemsCollection property contains the items. The Header property specifies the label for the entire control and the individual child elements of the control. HeaderedItems controls inherit from the ItemsControl class. There are three WPF controls that can be grouped as HeaderedItems controls: MenuItem, ToolBar, and TreeViewItem.

Table 10.39 lists a brief description of these controls:

# Table 10.39: Headered Items Controls

| Control | Description |
|---|---|
| MenuItem | Represents a selectable item inside a Menu control |
| ToolBar | Provides a container for a group of commands or controls |
| TreeViewItem | Implements a selectable item in a TreeView control |

# The TreeViewItem Control

The TreeViewItem control helps to display information in a hierarchical structure by using collapsible nodes. The content properties of the TreeViewItem control are Items and ItemsSource. The header property is Header. You can expand or collapse a TreeViewItem by using the IsExpanded property.
