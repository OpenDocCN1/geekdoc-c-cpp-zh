# Table 36.16: Attributes of the <forms> Element

| Attribute | Description |
|---|---|
| Timeout | Refers to the time (in minutes) for which the authentication cookie exists. The cookie expires after the time specified by this attribute elapses. The default value for this attribute is 30 (minutes). |
| Path | Refers to the path for storing the authentication cookie. The default value for this attribute is /, which refers to the root folder of the application. |
| requireSSL | Specifies whether a Secure Sockets Layer (SSL) connection is essential to pass the authentication cookie. The default value for this attribute is false. |
| slidingExpiration | Specifies whether the expiration time for the authentication cookie resets on every request in the same session. The default value for this attribute is false. |
| enableCrossAppRedirects | Specifies whether authenticated users can be redirected to Web pages in other Web applications. The default value for this attribute is false. |
| cookieless | Refers to when and how the authentication cookie is generated. This attribute can have either of the following values:
| UseUri | Indicates that cookies are not used at all. |
| UseCookies | Indicates that cookies are always used. |
| AutoDetect | Indicates that cookies are used only if the Web browsers support them. An attempt to use a cookie is through a probing mechanism. |
| UseDeviceProfile | Indicates that cookies are used only for Web browsers that support cookies. There is no probing mechanism for Web browsers that support cookies. This is the default value. |
| domain | Refers to an optional domain for the outgoing authentication cookie. The default value for this attribute is an empty string. |

The <forms> element can have a <credentials> element that allows you to specify the credentials of users when they are authenticated using Forms authentication. The <credentials> element has an attribute named passwordFormat. This attribute refers to the format for storing the passwords in an encrypted state. This attribute can take the following values:

+   - Clear – Indicates that the passwords are not encrypted; instead, they are stored as plain text
+   - SHA1 – Indicates that the passwords are encrypted using the SHA1 hash algorithm, which is the default value
+   - MD5 – Indicates that the passwords are encrypted using the MD5 hash algorithm

The <credentials> element can have three child elements: <clear>, <remove>, and <user>. Table 36.17 lists these three child elements along with their syntax:

# Table 36.17: Child Elements of the <credentials> Element

| Child Element | Description | Syntax |
|---|---|---|
| <clear> | Allows you to clear all the references of any inherited connection strings. These elements allow you to use only those connection strings created by the current user. | <clear/> |
| <remove> | Allows you to remove a reference of a particular user from the available credentials. | <remove name="userName"/> |
| <user> | Allows you to define the users for the Web application. | <user name="userName" password="password"/> |
