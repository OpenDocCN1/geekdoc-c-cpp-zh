# Creating Static Menus

The menus in ASP.NET 4.0 can be easily created by simply dragging and dropping the Menu controls from the Toolbox to the designer. You can find this application as MenuControlCS on the CD-ROM.

You can also add the Static Menus by double-clicking the Menu control in the Toolbox. The Menu control is added automatically to the designer. Click the Edit Menu Items in the list. A Menu Item Editor dialog box will appear. Insert nodes at different levels according to your requirements.
