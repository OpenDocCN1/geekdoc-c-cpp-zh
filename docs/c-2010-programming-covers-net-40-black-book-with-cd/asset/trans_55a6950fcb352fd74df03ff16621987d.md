## 使用扩展方法

正如你在“深入解析”部分所学到的，扩展方法可以在不创建新派生类或修改原始类的情况下扩展类。让我们创建一个名为 MyExtensionMethod 的应用程序（也可在光盘上获得）来学习如何使用扩展方法。

### 清单5.3：显示 MyExtensionMethod 应用程序的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace MyExtensionMethod
{
public static class MyClass
{
public static int MyExtensionMethod(this string Number)
{
return Int32.Parse(Number);
}
public static int MyStaticMethod(string Number)
{
return Int32.Parse(Number);
}
}
class MainClass
{
static void Main(string[] args)
{
string Number = "100";
int ext = Number.MyExtensionMethod(); // Line A
Console.WriteLine("The Output from MyExtensionMethod()");
Console.WriteLine(ext);
int stat = MyClass.MyStaticMethod(Number); // Line B
Console.WriteLine("");
Console.WriteLine("The Output from MyStaticMethod()");
Console.WriteLine(stat);
Console.Write("\nPress ENTER to quit...");
Console.ReadLine();
}
}
}
```

在清单5.3中，我们创建了两个方法：MyExtensionMethod() 和 MyStaticMethod()。MyExtensionMethod() 方法是一个扩展方法，其 string 类型参数 Number 前面有 this 关键字；而 MyStaticMethod() 静态方法的参数声明中则没有 this 关键字。在调用 MyExtensionMethod() 方法时，我们没有传递任何参数（参见清单5.3中的A行）；而在调用 MyStaticMethod() 方法时，我们传递了 Number 参数（参见清单5.3中的B行）。

## 使用访问器和修改器实现封装

正如你之前学到的，在 C# 中封装是通过使用 private 访问修饰符来实现的。在本节中，你将学习创建一个名为 Employee 的应用程序（也可在光盘上获得），以使用访问器和修改器来封装数据。访问器和修改器是用于获取和设置变量值的方法。

using System;

## 实现运算符重载

如前所述，运算符重载意味着通过将运算符用于对象来修改运算符的功能。当重载运算符时，你需要创建一个方法，该方法前面必须有 operator 关键字。在本节中，我们将创建两个应用程序，UnaryOperatorOverload 和 BinaryOperatorOverload（也可在光盘上获得），分别用于重载一元和二元运算符。

### 清单5.6：显示 UnaryOperatorOverload 应用程序的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace UnaryOperatorOverload
{
class UnaryOperator
{
    private int Number1;
    private int Number2;
    public UnaryOperator()
    {
    }
    public UnaryOperator(int number1, int number2)
    {
        Number1 = number1;
        Number2 = number2;
    }
    public void ShowData()
    {
        Console.WriteLine("The Numbers are: " +Number1 +" and " +Number2);
    }
    public static UnaryOperator operator -(UnaryOperator opr)
    {
        UnaryOperator obj = new UnaryOperator();
        obj.Number1 = -opr.Number1;
        obj.Number2 = -opr.Number2;
        return obj;
    }
}
class MainClass
{
    public static void Main()
    {
        UnaryOperator opr1 = new UnaryOperator (20, 30);
        Console.WriteLine("Before Operator Overloading");
        opr1.ShowData();
        UnaryOperator opr2 = new UnaryOperator();
        opr2 = -opr1;
        Console.WriteLine("----------------------------");
        Console.WriteLine("After Operator Overloading");
        opr2.ShowData();
        Console.Write("\nPress ENTER to quit...");
        Console.ReadLine();
    }
}
}
```

在清单5.6中，我们创建了一个类 UnaryOperator，它包含一个构造函数 UnaryOperator，用于初始化其两个变量。UnaryOperator 类还包含 ShowData() 方法，用于显示类变量的值，并重载 -（减号）运算符的功能。- 运算符通过使用 operator 关键字进行重载。接下来，在 MainClass 类的 Main() 方法中，使用 - 运算符来显示 UnaryOperator 类对象的负值。
