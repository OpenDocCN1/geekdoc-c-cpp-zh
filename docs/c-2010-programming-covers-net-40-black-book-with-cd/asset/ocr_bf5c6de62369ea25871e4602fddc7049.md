# Creating a Namespace

When you are creating a large number of classes, it is helpful to divide them into their own namespaces to help organize things. To create a namespace, you must use the namespace keyword followed by its name. Note that namespaces are always public, which means that the declaration of a namespace cannot include any access modifiers. Now, let’s create a new Class Library application, named MyNamespace (also available in the CD). Perform the following steps to create the MyNamespace application:

+   1. Click Start → All Programs → Microsoft Visual Studio 2010 → Microsoft Visual Studio 2010. This opens the Visual Studio 2010 IDE.
+   2. Click File → New → Project on the menu bar. This opens the New Project dialog box, as shown in Figure 4.1:

+   3. Expand the node labeled as Visual C# in the Installed Templates pane and then select Windows (Figure 4.1).
+   4. Select the Class Library template from the list of the templates (Figure 4.1).
