# Creating an Entity Data Model

An EDM can be created by using the ADO.NET Entity Data Model template. We can use this template to create C# projects. This template can be added to the Console Application, Windows Application, Class Library, ASP.NET Web Service Application, ASP.NET Web Application, or ASP.NET website projects. A single project can contain multiple Entity Data items, which might be generated from different databases or different tables within a database.
