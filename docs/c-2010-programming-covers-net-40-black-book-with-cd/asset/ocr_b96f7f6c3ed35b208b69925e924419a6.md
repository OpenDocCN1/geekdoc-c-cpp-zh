# The TextBlock Control

The TextBlock control in WPF is responsible for providing flexible text support for applications. A TextBlock control is usually used with documents in WPF. The major properties of the TextBlock control are related to text and the presentation of text. You can add text content to a TextBlock control using the Text property.

The inheritance hierarchy of the TextBlock control is as follows:

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.TextBlock
```

You can add the TextBlock control to a WPF application by using the following code snippet:

```
<TextBlock>
  <!--Inlines -->
</TextBlock>
```

Table 10.45 describes the noteworthy properties of the TextBlock class:

# Table 10.45: Noteworthy Properties of the TextBlock Class

| Property | Description |
|---|---|
| BreakAfter | Retrieves a line breaking condition that indicates how the current line of the text ends |
| BreakBefore | Retrieves a line breaking condition that indicates how the current line should break before the text ends |
| ContentEnd | Retrieves a TextPointer control to the end of the content in a TextBlock control |
| ContentStart | Retrieves a TextPointer control to the beginning of the content in a TextBlock control |
| FontFamily | Gets or sets the font size for a TextBlock control |
| FontStretch | Determines how the font should stretch in a TextBlock control |
| FontStyle | Gets or sets the font style for a TextBlock control |
| FontWeight | Gets or sets the font weight for a TextBlock control |
| Foreground | Gets or sets the color to apply to the text contents of a TextBlock control |
