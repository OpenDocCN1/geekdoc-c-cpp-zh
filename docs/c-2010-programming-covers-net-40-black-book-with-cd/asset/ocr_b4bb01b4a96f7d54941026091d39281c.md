# Creating a Thread

To learn how to create a thread, you need to first create an application. Open the Microsoft Visual Studio 2010 and create a Console Application, named as MyThread (also available on the CD). Now, open the Program.cs file of the MyThread application and add the following namespace to enable threading in your application:

```
using System.Threading;
```

Now, add the following line of code to the Main() method of the Program.cs file:

```
Thread FirstThread = new Thread(FirstFunction);
```

This creates a thread as FirstThread in the MyThread application. The FirstThread thread takes a method named as FirstFunction(), as an argument. Now, add the following code to the Program.cs file of the MyThread application to provide the definition of the FirstFunction() method:

```
public static void FirstFunction()
{
    for (int number = 1; number <= 5; number++)
    {
        Console.WriteLine("First Thread Displays: " + number);
    }
    Console.Write("\nPress ENTER to quit...");
    Console.ReadLine();
}
```

Now, the MyThread thread is created; however, it does not execute as it is not yet started. Let’s learn how to start a thread in the next section.

# Starting a Thread

To start a thread, you need to call the Start() method of the Thread class.

Listing 31.1 shows the complete code of the MyThread application, which shows how to create and start a thread:

# Listing 31.1: Showing the Code of the MyThread Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading; //Namespace required to enable threading
namespace MyThread
{
class Program
{
    static void Main(string[] args)
    {
        Thread FirstThread = new Thread(FirstFunction); //Code to create a thread
        Console.WriteLine("Threading Starts...\n");
        FirstThread.Start();//Starting the thread
    }
    public static void FirstFunction()
    {
        for (int number = 1; number <= 5; number++)
        {
            Console.WriteLine("First Thread Displays: "+number);
        }
        Console.Write("\nPress ENTER to quit...");
```
