# Listing 23.2: Creating a Trigger for the INSERT Operation

```
CREATE TRIGGER TestTrigger1
ON MyTable
AFTER INSERT
AS
INSERT INTO TestTable (col1) VALUES ('TestTrigger1 is fired');
```

In Listing 23.2, a trigger, TestTrigger1, is created on a user-defined table, MyTable. Whenever an INSERT operation is performed on the MyTable table, then the TestTrigger1 trigger is fired and a text value, TestTrigger1 is fired, is inserted in another user-defined table, TestTable.

As a stored procedure, a trigger also consists of procedural logic, which is stored at the database level. However, a trigger is specifically attached to a table, while a stored procedure is not. In addition, a stored procedure is explicitly executed or called, while a trigger is implicitly called and can also include a stored procedure for execution.

# Exploring User-Defined Aggregate Functions

In SQL, an aggregate function is a function that performs a calculation on a set of values and returns a single computed value. It summarizes the data in a table. SQL Server provides some built-in aggregate functions, such as SUM, MAX, and COUNT.

Let’s consider an example of the SUM aggregate function. Listing 23.3 shows a query to use the SUM aggregate function:

# Listing 23.3: Using the SUM Aggregate Function

```
USE Northwind;
GO
SELECT EmployeeID, SUM(Freight) As 'Total freight of ordered'
FROM dbo.Orders
WHERE EmployeeID IS NOT NULL
GROUP BY EmployeeID
ORDER BY EmployeeID;
GO
```

In Listing 23.3, the built-in aggregate function SUM is used to calculate the sum of the values stored in the Freight field of the Orders table in the Northwind database. Figure 23.2 shows the output of the query example given in Listing 23.3:
