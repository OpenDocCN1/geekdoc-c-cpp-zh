# Specifying the Initial Position of Windows Forms

You can use a form's StartPosition property to specify the initial position of a form on the screen. The values of FormStartPosition enumeration are assigned to the StartPosition property. The values FormStartPosition enumeration are given in Table 8.5:

Table 8.5: Values of FormStartPosition Enumeration

| Value | Description |
|---|---|
| CenterParent | Provides the center position to a form within the bounds of its parent form |
| CenterScreen | Provides the center position to a form with the specified dimensions of the form using the Size property |
| Manual | Determines the starting position of a form using its Location and Size properties |
| WindowsDefaultBounds | Provides the default location of the Windows interface to a form along with the default bounds of Windows |
| WindowsDefaultLocation | Provides the default location of the Windows interface to a form along with the dimensions of the Size property of a form |

You can set all these positions by using the Properties window of Form1, as shown in Figure 8.13:

You can also set the initial position of a Windows Form by writing the code in the Form1_Load event, as shown in the following code snippet:

```
private void Form1_Load(object sender, EventArgs e)

}
```
