# The WorkflowApplication Class

The WorkflowApplication class is used to host a single instance of a workflow. It belongs to the System.Activities namespace. The class hierarchy of the WorkflowApplication class is given as follows:

```
System.Object
System.Activities.Hosting.WorkflowInstance
System.Activities.WorkflowApplication
```

The WorkflowApplication class provides various methods to create and load workflow instances as well as to pause, resume, and terminate events of a workflow lifecycle. When you run a workflow by using the WorkflowApplication class, you must create an instance of the WorkflowApplication class and specify one or more lifecycle events in the workflow. Next, you must start the workflow by using the Run() method and wait until it finishes by using WaitOne() method. Consider the following code snippet:

```
AutoResetEvent autoEvent = new AutoResetEvent(false);
Activity myworkflow = new WriteLine
{
    Text = " WELCOME "
};
WorkflowApplication myWFApp = new WorkflowApplication(myworkflow);
myWFApp.Completed = delegate(WorkflowApplicationCompletedEventArgs e)
{
    autoEvent.Set();
};
myWFApp.Run();
autoEvent.WaitOne();
```

In the preceding code snippet, a workflow (myWFApp) is defined by using a WriteLine activity and then an instance of the WorkflowApplication class is created using the myWFApp workflow definition. The myWFApp workflow is started by calling the Run() method. The Completed event is handled, so that the host is notified when the workflow is complete. In addition, the AutoResetEvent is set to enable the host application to resume the execution of the workflow.

# The WorkflowServiceHost Class

The WorkflowServiceHost class supports multiple instances of workflows and allows sending and receiving messages. It belongs to the System.ServiceModel namespace. The WorkflowServiceHost class is used to configure and expose a workflow as service for use by client applications when you are not using Internet Information Services (IIS) or Windows Activation Services (WAS) to expose a service. The class hierarchy of the WorkflowServiceHost class is given as follows:

```
System.Object
System.ServiceModel.Channels.CommunicationObject
System.ServiceModel.ServiceHostBase
System.ServiceModel.Activities.WorkflowServiceHost
```
