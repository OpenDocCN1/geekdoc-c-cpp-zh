# Multiple Monitor Support

The multi monitor feature allows you to move the IDE windows, such as Toolbox, Output window, Properties window, or Solution Explorer to other locations, such as outside the IDE or other monitors of your computer system. It means that if multiple monitors are connected to a single computer, then the IDE window can be moved from one monitor screen to another.
