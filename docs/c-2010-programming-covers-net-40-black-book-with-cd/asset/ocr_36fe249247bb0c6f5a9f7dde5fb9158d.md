+   - System.Drawing.Imaging—Includes classes that support advanced GDI+ imaging.

+   - System.Drawing.Text—Includes classes that support advanced GDI+ typography operations. The classes in this namespace allow users to create and use collections of fonts.

+   - System.Reflection—Includes classes and interfaces that return information about types, methods, and fields. The System.Reflection namespace also has the ability to dynamically create and invoke types.
+   - System.Runtime.Remoting—Provides classes and interfaces that allow developers to create and configure distributed applications.
+   - System.Security—Includes classes that support the structure of the Common Language Runtime (CLR) security system.
+   - System.Runtime.Serialization—Contains classes that you can use for serializing and deserializing objects. Serialization is the process of converting an object or a graph of objects into a linear sequence of bytes for either storage or transmission to another location. Deserialization is the process of taking in stored information and recreating objects from it.
+   - System.Threading—Includes classes and interfaces that enable multithreaded programming.
+   - System.Web—Includes classes and interfaces that support browser/server communication. This namespace includes classes, such as the HTTPRequest class that provides information about HTTP requests; the HTTPResponse class that manages HTTP output to the client browser; and the HTTPServerUtility class that provides access to server-side utilities and processes.
+   - System.Web.Security—Includes classes that are used to implement ASP.NET security in Web server applications.
+   - System.Web.Services—Includes classes that allow you to build and use Web services, which are programmable entities on the Web server that the code can communicate with using standard Internet protocols.
+   - System.Windows.Forms—Includes classes for creating Windows-based forms that make use of user interface controls and other features available in the Windows operating system.
+   - System.Xml—Includes classes that support processing of XML.
