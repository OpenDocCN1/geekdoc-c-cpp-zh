# In Depth

A file is one of the mediums to store information in proper format and design. In C#, all the files should be properly handled to prevent the loss of information stored in them. File handling includes reading data from files, writing data to them, copying and moving files from one location to another, renaming, and deleting files. To handle files, you can use the System.IO namespace in your applications. This namespace provides various classes, such as FileStream, StreamReader, StreamWriter, BinaryReader, BinaryWriter, FileInfo, DriveInfo, Directory, and DirectoryInfo, to work with files. For example, you can use the FileStream class to read and write data into files either synchronously or asynchronously. The StreamReader and StreamWriter classes allow you to read and write text data in a stream, which refers to a flow of characters in a file. In addition to reading and writing the text data, you can also read and write binary data by using the BinaryReader and BinaryWriter classes. The FileInfo class allows you to create, open, move, copy, and delete files. While working with files, you often need to work with directories and drives, as files are stored in directories in a hierarchical format. You can use the Directory and DirectoryInfo classes to perform operations on directories, such as creating, moving, copying, renaming, and deleting directories.

In this chapter, you learn about the System.IO namespace, including the classes provided by it. You also learn how to retrieve information about a drive. Further, you learn how to work with directories and files in .NET. Finally, you learn about file compression. In the Immediate Solutions section, you learn how to implement these concepts in your applications.

Now, let’s start by learning about the System.IO namespace.

# The System.IO Namespace

In C# 2010, file handling is largely based on the System.IO namespace, which encloses a class library that supports string, character, and file manipulation. The most commonly used classes in this namespace are FileStream, BinaryReader, BinaryWriter, StreamReader, and StreamWriter. These classes include properties, methods, and events to create, copy, move, and delete files. Most important classes of the System.IO namespace are given in Table 29.1:

# Table 29.1: Showing the Classes of the System.IO namespace

| Class | Description |
|---|---|
| BinaryReader | Helps in reading the primitive data types in terms of binary values using certain specific encoding, such as Universal Time Format (UTF) including UTF-8 or UTF-16. |
| BinaryWriter | Helps in writing primitive data types in a binary form to a stream and also supports writing of strings using certain specific encoding. |
| Directory | Exposes the static methods that help in creating, moving and enumerating the directories and subdirectories. You cannot inherit this class. |
| DirectoryInfo | Exposes the instance methods to create, move, and enumerate directories and subdirectories. You cannot inherit this class. |
| DirectoryNotFoundException | Informs the user that a part of file or directory is missing. |
| DriveInfo | Provides information regarding the data of a drive. |
| File | Provides the static methods for creating, opening, moving, deleting, and copying files. In addition, it helps in creating the FileStream objects. |
| FileInfo | Provides the instance methods for creating, opening, moving, deleting, and copying files. Additionally, it helps in creating the FileStream objects. You cannot inherit this class. |
| FileFormatException | Raises an exception when the format of input data does not match the specified format of a file, such as File Allocation Tale (FAT) or New Technology File System (NTFS). |
