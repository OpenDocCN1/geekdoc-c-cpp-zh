# Type Conversions

While writing C# applications, you often need to perform a typical task; that is to convert one data type to another. For this type of conversion, type casting is used. Type Casting has two forms—implicit and explicit.

# Implicit Conversion

Implicit conversions are the conversions that are performed by the programming language, in a type-safe manner. For example, converting an integer to a floating-point number is done implicitly, as shown in the following code snippet:

```
int I = 123;
Single s = I;
```

C# introduces the notion of built-in conversions from type to type. Table 2.3 lists the built-in conversion methods in C#:

# Table 2.3: Showing the Conversion Methods

| Conversion method | Description |
|---|---|
| ToBoolean | Converts types to a Boolean value, if possible |
| ToByte | Converts types to a byte |
| ToChar | Converts types to a single character (Unicode), if possible |
| ToDateTime | Converts types (mostly integers and string) to date-time structures |
| ToDecimal | Converts types (floating point or integer) to decimal values |
| ToDouble | Converts virtually any type safely to a double type |
| ToInt16 | Converts specified type to a 16-bit signed integer |
| ToInt32 | Converts specified type to a 32-bit signed integer |
| ToInt64 | Converts specified type to a 64-bit signed integer |

| ToString | Converts virtually any type to a string |

| ToUInt32 | Converts virtually any type to an unsigned long |
