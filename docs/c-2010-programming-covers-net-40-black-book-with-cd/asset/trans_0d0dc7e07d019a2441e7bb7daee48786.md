## The Properties Window

Properties 窗口用于查看和修改所选对象的设计时属性和事件。此窗口还使你能够编辑添加到窗体中的控件的属性。例如，要查看和修改窗体的属性，请打开设计器并选择窗体。Properties 窗口可以通过以下任一方式打开：

- 通过从主菜单中选择 View→Properties Windows
- 通过按 F4 键

如果你想查看和修改其他组件的属性，例如按钮或标签，则将这些组件拖放到窗体上并选择要修改其属性的组件。当你选择适当的组件时，与该组件关联的属性将在 Properties 窗口中显示。Properties 窗口中显示的属性对于不同的组件或控件是不同的。换句话说，与 Button 控件关联的属性与与 Label 或 Form 控件关联的属性不同。请注意，Properties 窗口中的某些属性以灰色文本显示。显示为灰色的属性是只读属性。

Properties 窗口还显示包含各种按钮的工具栏。这些按钮从左到右解释如下：

- Categorized – 使你能够将控件的属性分组到类别中。属性根据其在控件中执行的功能进行分类。例如，当你在 Solution Explorer 中选择一个窗体并单击工具栏上的 Categorized 按钮时，Form 属性将被分组到 Accessibility、Appearance、Behavior、Data、Design、Focus、Layout、Misc. 和 Window Style 类别中。

- Alphabetical – 按字母顺序显示控件的属性。

- Properties – 显示控件的所有属性。

- Events – 显示控件的所有事件。

- Property Pages – 为所选组件显示 Property Pages 对话框。你可以使用 Property Pages 对话框来查看和编辑与项目配置相关的属性。

## The Object Browser Window

Object Browser 窗口用于检查和查找对象，例如命名空间、类、结构、类型、接口和枚举以及它们的成员，例如属性、方法、事件、变量、常量和枚举。Object Browser 窗口可以通过以下任一方式打开：

- 通过从主菜单中选择 View→Object Browser
- 通过按 Ctrl+Alt+J 键

![](img/e073a4882197be4ab61103cbe0bcb394_87_0.png)

图 1.58：显示 Object Browser 窗口

图 1.58 显示了 Object Browser 窗口的以下三个窗格。

- Objects pane – 显示层次结构，例如 .NET Framework 和 COM 组件、命名空间、类型库、接口和类。Objects 窗格中的顶级节点表示当前浏览范围内的组件或命名空间。要展开这些节点，请单击节点旁边的 (▸) 符号。

- Members pane — 显示在 Objects 窗格中选中的项目的成员。Members 窗格包含成员，例如属性、方法、事件、常量、变量和枚举值。

- Description pane — 显示在对象窗格中选中的项目的描述。Description 窗格显示有关当前选中的对象或成员的详细信息。

Object Browser 窗口还在其工具栏中包含以下按钮：

- Browse menu — 指定 Objects 窗格的浏览范围。你可以将范围缩小到当前解决方案或扩展到每个可用组件。你可以从下拉列表中选择以下选项：

- All Components — 显示整个 .NET Framework、当前解决方案及其引用的组件中的对象，以及通过选择 Edit Custom Component Set 选择的任何其他组件
- .NET Framework 2.0 — 显示 .NET Framework 2.0 中的对象
- .NET Framework 3.0 — 显示 .NET Framework 3.0 中的对象
- .NET Framework 3.5 — 显示 .NET Framework 3.5 中的对象
- .NET Framework 3.5 Client Profile — 显示 .NET Framework 3.5 客户端配置文件中的对象
- .NET Framework 4 — 显示 .NET Framework 4.0 中的对象
- .NET Framework 4 Client Profile — 显示 .NET Framework 4.0 客户端配置文件中的对象
- Silverlight 3.0 — 显示在 Silverlight 技术中使用的对象
- My Solution — 显示当前解决方案及其引用组件中的对象
- Custom Component Set — 显示通过选择 Edit Custom Component Set 添加的任何组件中的对象
- Edit Custom Component Set — 显示 Edit Custom Component Set 对话框，该对话框用于定义 Custom Component Set 浏览范围

- Search menu — 允许你在 Objects 窗格中搜索对象。结果将作为过滤列表显示在 Objects 窗格中。你可以通过单击 Clear Search 按钮刷新整个 Browse 范围。

- Toolbar buttons — 允许你在 Objects 窗格和 Members 窗格中导航。这些按钮描述如下：

- Back — 导航到之前选中的项目，直到到达浏览的第一个项目。
- Forward — 导航到下一个选中的项目，直到到达浏览的最新的项目。
- Add to References in Selected Project in Solution Explorer — 将所选组件的引用插入到 Solution Explorer 中当前选中的项目中。

- Object Browser settings — 允许你选择在指定的 Browse 范围内对象的特定视图，并指定将显示哪些可用对象。

- View Namespaces — 显示逻辑命名空间。
- View Containers — 显示物理容器。
- Show Base Types — 在 Objects 窗格中显示基类型。
- Show Derived Types — 在 Objects 窗格中显示派生类型。此选项仅适用于 C#。
- Show Hidden Types and Members — 在 Objects 窗格中显示隐藏类型，并在 Members 窗格中显示隐藏成员。
- Show Public Members — 为使用该类的用户显示公共成员。
- Show Protected Members — 为扩展该类的用户显示受保护的成员。
- Show Private Members — 为使用该类的用户显示所有访问级别的成员。
