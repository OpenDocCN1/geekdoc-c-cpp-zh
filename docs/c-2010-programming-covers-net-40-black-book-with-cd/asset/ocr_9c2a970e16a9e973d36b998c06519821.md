# Creating and Using UDFs

In this section, you learn to create a UDF as a CLR object in .NET Framework. To do this, you need to add a UDF CLR object in SQL Server project. Let’s create a SQL Server project, named SqlServerProjectUDF (also available on CD), and add a UDF, RectAreaFunction.cs, to it.

Perform the following steps to create the SqlServerProjectUDF project in Visual Studio 2010:

+   1. Open Microsoft Visual Studio 2010.
+   2. Create a Visual C# SQL CLR Database Project, named SqlServerProjectUDF.
+   3. Select an existing database connection or create a new one. In our case, we are selecting the existing database connection, charu-pc.MyData.dbo.
+   4. Click the OK button. The SqlServerProjectUDF project is displayed in Visual Studio 2010.
+   5. Right-click the SqlServerProjectUDF project in Solution Explorer and select the Add→User-Defined Function option. The Add New Item- SqlServerProjectUDF dialog box opens (Figure 23.19).
+   6. Select the User-Defined Function template and either use the default name or enter a new name. In our case, we are using the name, RectAreaFunction.cs, in the Name text box, as shown in Figure 23.19.
