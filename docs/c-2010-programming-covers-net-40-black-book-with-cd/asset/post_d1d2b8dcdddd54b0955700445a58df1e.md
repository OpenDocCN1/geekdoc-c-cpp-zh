## Modes of Media Playback

You can use the MediaPlayer and MediaElement classes in two different modes; the independent mode and the clock mode. The mode is determined by the Clock property. If the Clock property is set to null, the media object is in the independent mode. If the Clock property is set to non-null, the media object is in the clock mode. The default mode is the independent mode. You can control the media playback in the independent mode by using the media object control methods which are Play, Pause, Close, and Stop. You can control the media playback in the clock mode by using the control methods of the ClockController class. The ClockController object is obtained from the ClockController property of the MediaClock class. You cannot use the media object control methods in the clock mode. If you attempt to use the method, InvalidOperationException exception is thrown.

The MediaPlayer class is used in two different modes: independent mode and clock mode. In the independent mode, the MediaPlayer is same as an image and the media which is opened by the Open method drives the playback. In the clock mode, the MediaPlayer class can be combined with animation, and so it has the corresponding the Timeline and Clock classes attached to it. You should use the VideoDrawing class to display media loaded using the MediaPlayer class.

The MediaElement class can also be used in two different modes: independent mode, independent mode, the MediaElement object is similar to an image, and the Source URI can be directly specified. In the clock mode, the MediaElement object can be used with animation, and so have the Timeline and Clock classes.
