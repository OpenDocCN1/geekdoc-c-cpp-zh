## Writing to an Event Log

You can write to an event log with the help of the Windows service application by using the WriteEntry method of the EventLog class. Let's add the WriteEntry() method of the EventLog class in the Service1.cs code-behind file of the MyWindowsService application. Listing 20.1 shows the code of the Service1.cs file:

Listing 20.1: Showing the Code of the Service1.cs File

```
using System;
using System.Collections.Generic;
using System.ComponentModel;
using System.Data;
using System.Diagnostics;
using System.Linq;
using System.ServiceProcess;
using System.Text;
namespace MyWindowsService
{
    public partial class MyService : ServiceBase
    {
        public MyService()
        {
            InitializeComponent();
        }
        protected override void OnStart(string[] args)
        {
            EventLog.WriteEntry("Starting MyService");
        }
        protected override void OnStop()
        {
            EventLog.WriteEntry("Stopping MyService");
        }
    }
}
```

In Listing 20.1, we have entered the Starting MyService message and the Stopping MyService message by using the WriteEntry() method of the EventLog class in the OnStart() and OnStop() methods, respectively. The OnStart() and OnStop() methods specify the actions that you want to perform when the service starts and stops running, respectively. You can also specify actions when the service is paused or continued, or when you shut down the computer using the OnPause(), OnContinue(), and OnShutdown() methods, respectively.
