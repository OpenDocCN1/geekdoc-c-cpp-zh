# Creating Custom Web Parts

In addition to the default Web Parts controls that you used previously in the chapter, ASP.NET 4.0 also allows you to define your own custom Web Parts controls and use them in your website. The advantage of creating a custom control is that you can define its properties as per your requirements. The user can modify these properties at runtime in the same way the properties of predefined Web Parts controls are modified.

To demonstrate how custom controls are used, let’s perform the following steps:

+   1. Create a Web application named CustomWebPart (also available in the CD). The code of the CustomWebPart Web application is contained in the customcontrol.ascx file.
