# Table 20.11: Opening of SCM in Different Windows Versions

| Windows Version | Opening of the SCM Manager |
|---|---|
| Windows 2000 Professional | Right-click My Computer on the desktop and select the Manage option from the context menu to open the Computer Management window. Expand the Services and Applications node and select the Services entry. |
| Windows 2000 Server | Click Start→Programs→Administrative Tools→Services. |
| Windows XP Professional | Click Start→Control Panel→Administrative Tools→Services. |
