The following properties of the MouseEventArgs object are used to handle the mouse events:

+   - Buttons — Indicates which mouse button is pressed.
+   - Clicks — Indicates the number of times the mouse button is pressed and released.
+   - Delta — Indicates count of the number of detents the mouse wheel has rotated. A detent is the rotation of the mouse wheel by one notch.
+   - X — Indicates the x-coordinate of a mouse click.
+   - Y — Indicates the y-coordinate of a mouse click.

The Buttons property is set by the values of the MouseButtons enumeration, which are given as follows:

+   - Left — Indicates that the left mouse button is pressed
+   - Middle — Indicates that the middle mouse button is pressed
+   - None — Indicates that no mouse button is pressed
+   - Right — Indicates that the right mouse button is pressed
+   - XButton1 — Indicates that the first XButton is pressed
+   - XButton2 — Indicates that the second XButton is pressed

# Handling Keyboard Events

In C#, the following events are available to handle the keyboard events:

+   - KeyDown — Occurs when a key is pressed down while a control has focus
+   - KeyPress — Occurs when a key is pressed while a control has focus
+   - KeyUp — Occurs when a key is released while a control has focus

To handle the KeyDown and KeyUp events, event handlers take an argument of type KeyEventArgs. The KeyEventArgs type contains the following properties:

+   - Alt — Holds a value indicating whether the ALT key is pressed.
+   - Control — Holds a value indicating whether the CTRL key is pressed.
+   - Handled — Holds or sets a value indicating whether the event is handled.
+   - KeyCode — Holds the keyboard code for the KeyDown or KeyUp event.
+   - KeyData — Holds the keyboard data for the KeyDown or KeyUp event.
+   - KeyValue — Holds the keyboard value for a KeyDown or KeyUp event.
+   - Modifiers — Holds the modifier flags for the KeyDown or KeyUp event. This indicates which modifier keys (Ctrl, Shift, and/or Alt) are pressed.
+   - Shift — Holds a value indicating whether the Shift key is pressed.

To handle the KeyPress events, event handlers take an argument of type KeyPressEventArgs, which contains the following properties:

+   - Handled — Gets or sets a value indicating whether the KeyPress event is handled
+   - KeyChar — Holds the character corresponding to the key pressed
