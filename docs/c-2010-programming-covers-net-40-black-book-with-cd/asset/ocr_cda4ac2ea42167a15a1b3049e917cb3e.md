You can change the default range by setting the Maximum and Minimum properties, which are provided by the RangeBase class. The ScrollBar control derives from the RangeBase class, which in turn derives from the Control class. The ScrollBar control allows a user to scroll through an interface, if the content on the interface extends beyond the frame of the screen. The following are the two types of ScrollBar controls:

+   - The HorizontalScrollBar control — Controls the horizontal pane
+   - The VerticalScrollBar control — Controls the vertical pane

The Thumb class works along with the RangeBase class. The ScrollBar control is represented by the ScrollBar class. The inheritance hierarchy of the ScrollBar class is as follows:


# The ProgressBar Control

The ProgressBar control indicates the progress of an operation. It consists of a bar that is filled with color as the operation with which it is attached to progresses. This control is not user-interactive. The default operation of the ProgressBar control is to fill the ProgressBar bar from left to right.
