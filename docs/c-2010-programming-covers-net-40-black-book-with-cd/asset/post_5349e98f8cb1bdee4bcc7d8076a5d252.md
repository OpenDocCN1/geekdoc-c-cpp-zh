## Setting the Tab Order of a Control

Suppose your mouse stops working and you still want to access the Web site. How can you do that? Of course, you could use your keyboard. To make the controls on the Web page accessible through the keyboard, you must set the proper tab order for the controls by using the TabIndex property. The TabIndex property is the index of the current control in the tab order, which typically starts with 0. When a user presses the Tab key, the focus moves from one control to another in ascending order according to the tab index. In this section, we learn how to set a tab order for all the controls on the Default Web page. To do so, select a control from where you want the tab order to be set and open its properties in the Properties window. Now, set the TabIndex property of the control as 0 and the next control as 1, and so on. In this case, set the TabIndex of TextBox1 as 1, TextBox2 as 2, and finally for Button1 as 3. Normally, you never set a Tab key for the Label control. The Source view for the Default.aspx Web page is shown in Listing 13.8:
