
## Using Silverlight Controls

Silverlight offers numerous controls that you can use to define the look and feel of your Silverlight applications. Most of the controls are the same as WPF; therefore, provide the same functionality as provided by controls, such as Button, TextBox, Rectangle, and ListBox. However, Silverlight 3.0 also offers some exclusive controls to provide additional functionality for Web applications. Now, let’s learn how to work with the following controls in Silverlight 3.0:

- The Calendar control
- The DatePicker control
- The GridSplitter control
- The HyperlinkButton control
- The MediaElement control
- The Popup control
- The TabControl control
- The AutoCompleteBox Control
- The DataPager Control
- The TreeView Control

## Using the Calendar Control

As you have learned in the In Depth section of this chapter, the Calendar control allows you to view and select the days, months, and years. You can also style the Calendar control. Perform the following steps to see how you can use the Calendar control to meet your requirements:

1. Create a new Silverlight 3.0 application named BookTicketCalendarAppCS (available on the CD). This application has three calendars (Calendar controls) that allow you to see the availability of tickets between two particular dates and then select the desired date on which you want to book a ticket. For this, six TextBlock, three TextBox, three Calendar, and five Button controls are added to the application. In addition, there are five Rectangle elements that are filled with different images using the ImageBrush elements. Now, let’s see how these controls and XAML elements are used in the application.

In Listing 17.2, there are three TextBox controls named fromDateBox, toDateBox, and selectDateBox. These three TextBox controls have their IsReadOnly property set to True, which means that the users cannot directly enter or modify the text in these controls. There are three Button controls named fromIconButton, toIconButton, and selectIconButton. These three buttons contain three Image controls that refer to an image in the calIcon.png file. The file is added to the Silverlight project folder by using the Add Existing Item dialog box, which appears when you select the Silverlight project and select Project→Add Existing Item from the menu bar. The image in this file appears on all the three buttons. Note that these buttons have the Click event associated with the respective handlers. This implies that when a user clicks a button, the corresponding event handler is executed.

You can also notice three Calendar controls named fromCal, toCal, and selectCal in Listing 17.2. The fromCal and toCal Calendar controls refer to the calendars that allow the users to select a range of dates to book a ticket. The selectCal Calendar control allows the users to select a date for booking the ticket. Note that different properties of these three Calendar controls are set, as given in Table 17.18:

### Table 17.18: Analyzing the Properties of the Calendar Controls used in the BookTicketCalendar Application

| Property | Value | Description |
|---|---|---|
| IsTodayHighlighted | True | Highlights the current date |
| DisplayMode | Month (for fromCal and toCal) | Displays the calendar of one year at a time |
|  | Year (for selectCal) | Displays the calendar of one month at a time |

Apart from these properties, the SelectedDatesChanged event of the Calendar controls is also associated with their handlers (defined in the code-behind file).
