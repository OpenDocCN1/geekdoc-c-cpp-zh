## 为 Windows 窗体和控件指定鼠标光标

你可以使用 Cursor 属性在鼠标移动到控件上方时设置鼠标光标类型。正如你所知，Windows 窗体也是从 Control 类派生的；因此，光标类型也适用于窗体。你可以通过指定表 8.11 中给出的值来设置 Cursor 属性：

| 表 8.11：鼠标光标选项 |
| 常量 | 描述 |
| AppStarting | 指定箭头光标和等待光标的组合 |
| Arrow | 指定箭头光标 |
| Default | 指定默认光标，通常是箭头光标 |
| Hand | 指定手形光标，通常在悬停在网页链接上时使用 |
| Help | 指定帮助光标，即箭头和问号的组合 |
| HSplit | 指定当鼠标位于水平分隔条上方时出现的光标 |
| IBeam | 指定 I 形光标，用于显示鼠标单击时文本光标出现的位置 |
| No | 指定指示特定区域对当前操作无效的光标 |
| NoMove2D | 指定当鼠标不动时鼠标滚轮操作的光标；但是，窗口可以在水平或垂直方向滚动。 |
| NoMoveHoriz | 指定当鼠标不动时鼠标滚轮操作的光标；但是，窗口可以在水平方向滚动 |
| NoMoveVert | 指定当鼠标不动时鼠标滚轮操作的光标；但是，窗口可以在垂直方向滚动 |
| PanEast | 指定当鼠标移动且窗口向水平右方向滚动时鼠标滚轮操作的光标 |
| PanNE | 指定当鼠标移动且窗口向北/东方向滚动时鼠标滚轮操作的光标，这意味着水平向右或垂直向上方向 |
| PanNorth | 指定当鼠标移动且窗口垂直向上滚动时鼠标滚轮操作的光标 |
| PanNW | 指定当鼠标移动且窗口向北/西方向滚动时鼠标滚轮操作的光标，这意味着水平向左或垂直向上方向 |
| PanSE | 指定当鼠标移动且窗口向南/东方向滚动时鼠标滚轮操作的光标，这意味着水平向右或垂直向下方向 |
| PanSouth | 指定当鼠标移动且窗口垂直向下滚动时鼠标滚轮操作的光标 |
| PanSW | 指定当鼠标移动且窗口向南/西方向滚动时鼠标滚轮操作的光标，这意味着水平向左或垂直向下方向 |
| PanWest | 指定当鼠标移动且窗口向左水平滚动时鼠标滚轮操作的光标 |
| SizeAll | 指定四向光标 |
| SizeNESW | 指定双向对角线（北/东和南/西）光标 |
| SizeNS | 指定双向垂直（北/南）光标 |
| SizeNWSE | 指定双向对角线（西北/东南）光标 |
| SizeWE | 指定双向水平（西/东）光标 |
| UpArrow | 指定通常用于标识插入点的上箭头光标 |
| VSplit | 指定当鼠标位于垂直分隔条上方时出现的光标 |
| WaitCursor | 指定等待光标，通常为沙漏形状 |
