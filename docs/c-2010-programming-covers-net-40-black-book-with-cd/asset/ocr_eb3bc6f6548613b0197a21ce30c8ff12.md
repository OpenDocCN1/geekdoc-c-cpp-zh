# ScaleTransform3D

The ScaleTransform3D class is used to scale out a 3-D model by a specified vector with reference to the center point. You can specify the same value in the ScaleX, ScaleY, and ScaleZ properties, so that the 3-D model scales by the same value in the X, Y, and Z axis.
