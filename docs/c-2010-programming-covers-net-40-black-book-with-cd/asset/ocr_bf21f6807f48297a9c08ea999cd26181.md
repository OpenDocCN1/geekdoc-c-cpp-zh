# EDM Generator Tool

Entity Framework does not support compile-time validation of EDM files in ASP.NET website projects. ASP.NET website projects do not support pre-build events; validating entities in pre-build events can be a very time-consuming task. ADO.NET runtime validates the files when we run or debug the applications. The EdmGen.exe tool is installed in the .NET Framework directory, which is located in C:\Windows\Microsoft.NET\Framework\v4.0.30319. We can also access the EdmGen.exe tool from the Visual Studio command prompt by performing the following steps:

+   1. Click Start → All Programs→Microsoft Visual Studio 2010→Visual Studio Tools→Visual Studio Command Prompt (2010).
+   The Visual Studio 2010 command prompt opens with a default path, such as C:\Program Files\Microsoft Visual Studio 10.0\VC>. The general syntax of the EDM Generator tool is as follows:
+   EdmGen /mode:choice [options]
