# Using Windows Forms to Create Dialog Boxes

In a GUI environment, dialog box is a type of window that enables a communication between a computer and its user. It can be used for conveying the information to the user, or prompting the user for a response, or both purposes. The simplest form, in which a dialog box appears, is an alert that displays a message and may require an acknowledgment that the message has been read. An alert may also require a decision as to whether or not an action should be proceed, by clicking the OK or Cancel button.

In this section, you learn to perform the following tasks:

+   - Creating a dialog box
+   - Reading data from dialog boxes
+   - Creating the Accept and Cancel buttons in dialog boxes

Let’s discuss these in detail.

# Creating a Dialog Box

In this section, we are creating an application, named DialogBoxControl, to show how to create a dialog box. You can find the source code of the DialogBoxControl application on the CD.

Perform the following steps to create the DialogBoxControl application:

+   1. Create a Windows Forms application named DialogBoxControl.
+   2. Add a Label (label1), TextBox (textBox1), and two Buttons (button1 and button2) controls in Form1.
+   3. Modify the properties of controls given in Table 8.6:

Table 8.6: Modified Properties of Controls
| Control | Property Name | Property Value |
|---|---|---|
| Form1 | Text | My Dialog Box |
| Form1 | FormBorderStyle | FixedDialog |
| Form1 | ControlBox | False |
| Form1 | ShowInTaskbar | False |
| label1 | Text | Enter Your Text |
| textBox1 | Modifiers | Internal |
| button1 | Text | OK |
| button1 | DialogResult | OK |
| button2 | Text | Cancel |
| button2 | DialogResult | Cancel |

Table 8.7: DialogResult Enumerations
