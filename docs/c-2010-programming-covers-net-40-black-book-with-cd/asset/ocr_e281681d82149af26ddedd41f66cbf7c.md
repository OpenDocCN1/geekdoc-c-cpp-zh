# Docking the Windows

The docking feature allows you to move different windows, such as Solution Explorer and Properties from one edge of the IDE to another. Select Solution Explorer and drag it toward the middle of the IDE. A guide diamond appears, as shown in Figure 1.78:

![](bbox=[0.19, 0.155, 0.83, 0.455])

Figure 1.78: Displaying a Guide Diamond

In Figure 1.78, you see the four arrows of the diamond pointing toward the four sides of the IDE. Note that if you select a tool window, four additional arrows point to the four edges of the IDE. When the window that you are dragging reaches the location point where you want to dock it, move the pointer over the corresponding portion of the guide diamond, as shown in Figure 1.79:

![](bbox=[0.18, 0.545, 0.815, 0.875])

Figure 1.79: Displaying Destination Location Point as Shaded

Now, release the mouse button to dock Solution Explorer to the left-edge of the IDE.
