# Using the FileUpload Control

When you add a FileUpload control on a Web page, the following code is added to the source code of the Web page:

```
<asp:FileUpload ID="FileUpload1" runat="server" />
```

Now, let’s create a Web application named FileUploadControl (also available in CD-ROM) to show the working of the FileUpload control. You can add a FileUpload control to a Web page either by dragging and dropping it from the Standard tab of the Toolbox or by double-clicking it in the Standard tab of the Toolbox. In this case, we are using a FileUpload control to browse a file and upload it on the server using the SaveAs() method on the Click event.
