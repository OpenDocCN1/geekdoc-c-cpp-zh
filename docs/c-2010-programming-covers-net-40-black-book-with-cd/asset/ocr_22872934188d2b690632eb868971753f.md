# Enhanced Multi Targeting

The enhanced multi targeting feature of Visual Studio 2010 IDE helps you to run your applications in different frameworks, such as 2.0, 3.0, 3.5, and 4.0. This feature is useful when you want to run an application in any previous framework. The target framework can be selected using .NET Framework 4 dropdown list in the New Project dialog box, as shown in Figure 1.24:
