# Setting a Border of Windows Forms

You can set a border of a Windows Form by setting the FormBorderStyle property in the Properties window or by writing the code in the Code Editor window. The possible values of the FormBorderStyle property are given in Table 8.4:

Table 8.4: Form Border Styles

| Values | Description |
|---|---|
| Fixed3D | Specifies a fixed, three-dimensional border |
| FixedDialog | Specifies a thick, fixed dialog-style border |
| FixedSingle | Specifies a fixed, single-line border |
| FixedToolWindow | Specifies a tool window border that is not resizable |
| None | Does not specify a border for a form |
