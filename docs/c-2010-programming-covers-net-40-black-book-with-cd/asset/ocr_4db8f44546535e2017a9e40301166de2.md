# Creating Web Deployment Packages

A Web Application project can be deployed by creating a Web deployment package and installing that package on a target server. A Web deployment package is a compressed .zip file that stores the following information:

+   - **IIS settings** – Include the application pool, the authentication method, and error handling
+   - **Database scripts** – Perform the changes in the database and its structure
+   - **Debugging and connection string parameters** – Contain values that might need to be changed when the package is installed

In addition to the preceding information, the .zip file may include security certificates, Windows registry settings, and assemblies installed on the GAC of the target computer.

# Using the One-Click Publishing Feature

You can deploy a Web application remotely by using the one-click publish feature. For this, you need to open the Publish Web dialog box, by right-clicking a project in Solution Explorer and selecting the Publish option from the context menu. Figure 21.9 shows the Publish Web dialog box:

![](bbox=[0.285, 0.43, 0.685, 0.805])

Figure 21.9: Displaying the Publish Web Dialog Box

In the Publish Web dialog box, you can specify how and where Visual Studio 2010 deploys the application. You can also use one-click publish feature to deploy your application to a third-party hosting company. After configuring the publish settings in the Publish Web dialog box, you need to click the Publish button. Then the application is deployed on the destination computer. Note that, if the Publish button is clicked after an already deployed Web application, Visual Studio 2010 redeploys the application with the modified items in the application only.
