You can create a thread in your C# program by using the Thread class’s, which is passed in the ThreadStart delegate. The following syntax shows how to define the ThreadStart delegate:

```
public delegate void ThreadStart();
```

Let’s now look at the following code snippet to understand the syntax of the Thread class and the ThreadStart delegate to create and start a thread in a C# program:

```
class MyThreadClass
{
    static void Main()
    {
        //Creating an object of the Thread class
        Thread MyThread = new Thread(new ThreadStart(MyFunction));
        MyThread.Start();
    }
    static void MyFunction() {
        Console.WriteLine("This is my Thread");
        Console.ReadLine();
    }
}
```

In the preceding code snippet, you see that an object of the Thread class is created with the name MyThread and in the Thread class’s constructor the ThreadStart delegate is passed. The ThreadStart delegate indicates that the execution of the C# program should begin with the MyFunction() method. In this example, the MyThread thread executes the MyFunction() method at the same (or nearly same) time the Main() thread calls the MyFunction() method. The Start() method enables the MyThread thread to start.

In C#, you can also create a thread more conveniently by using the shortcut syntax for instantiating delegates, as shown in the following code snippet:

```
static void Main()
{
    Thread MyThread = new Thread (MyFunction);    // No need to explicitly use the
    MyThread.Start();                            //ThreadStart delegate
    ...
}
static void MyFunction()
{
    ...
}
```

In this case, the C# compiler automatically determines the ThreadStart delegate.

# Multithreading

The Multithreading feature enables you to have more than one execution path for your application at a time. You are already aware of Windows multitasking facilities, which allow you to perform more than one task at the same time. In multitasking, you can perform multiple tasks simultaneously, such as writing an article using MS-Word, listening a song in Win-dow Media Player (WMP), and downloading a movie using the Internet Download Manager. In the same way, you can use multithreading to execute different methods of a program simultaneously. Almost all the Windows applications use the concept of multithreading, such as MS-Word takes user input and displays it on the screen in one thread, while it continues to check spellings and grammatical mistakes in the second thread, and at the same time the third thread saves the document automatically at regular intervals. In the same way, WMP plays music in one thread, displays visualizations in the second thread, and takes user input in the third thread.
