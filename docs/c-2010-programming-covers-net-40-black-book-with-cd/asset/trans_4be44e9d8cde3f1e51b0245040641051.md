## Microsoft AJAX 功能

Microsoft AJAX 功能是在 ASP.NET 3.5 中引入的。然而，在 ASP.NET 4.0 中，该功能已得到增强，以帮助开发人员创建完全基于客户端的 AJAX 应用程序。ASP.NET 4.0 中 Microsoft AJAX 包含的各种新功能如下：

- jQuery – 指 jQuery 与 Web 表单和模型-视图-控制器 (MVC) 的集成。这意味着用于创建网站的 ASP.NET 模板包含开源 jQuery 库，其中包含以下三个文件：
  - jQuery-1.4.1.js – 指 jQuery 库的未压缩版本。
  - jQuery-1.4.1.min.js – 指 jQuery 库的压缩版本。这意味着该文件不包含代码中任何不必要的字符，从而减小文件大小并提高加载时间。
  - jQuery-1.4.1-vsdoc.js – 指 jQuery 库的 IntelliSense 文档文件。
- 内容分发网络 (CDN) – 有助于轻松地将 AJAX 和 jQuery 脚本添加到 Web 应用程序中。此外，CDN 提高了 AJAX 应用程序的性能。

## 对基于 MVC 的 Web 应用程序的支持

.NET Framework 4.0 和 Visual Studio 2010 包含 MVC 框架，它使 Web 应用程序的核心业务模型功能与界面特定应用程序的表示和控制逻辑分离。这种安排使得可以查看 Web 应用程序的同一数据模型的多个视图。在此架构下，数据（Model）和用户界面（View）彼此分离，因此用户界面的任何更改都不会影响数据库中的数据，反之亦然。

在 Visual Studio 2010 中，默认安装 ASP.NET MVC 2 版本。在 ASP.NET 4.0 中，对基于 MVC 的 Web 应用程序的支持有助于开发人员开发易于维护的标准 Web 应用程序。对 Web 应用程序中的 MVC 的支持消除了应用程序层之间的依赖关系。使用 ASP.NET MVC 创建的网站具有模块化架构。因此，开发人员可以处理网站的数据和逻辑，而设计师可以处理其呈现。

## 改进的 CSS 兼容性

层叠样式表 (CSS) 是 Web 应用程序的重要组成部分之一，因为它使网站的设计变得更容易、更快。Visual Studio 2010 中的网站已更新为包含改进的 CSS 2.1 标准。这些标准比 ASP.NET 的早期版本更强大，有助于保持 Web 应用程序及其 HTML 代码的完整性。在 Visual Studio 2010 中，ASP.NET 4.0 中引入了一组工具来创建、应用和管理样式。这些工具在以下点中提到：

- 应用样式窗口 – 使您能够创建、修改和应用样式。您还可以链接或删除外部 CSS。该窗口识别样式类型并显示样式是否在当前网页和当前选择中使用。
- 管理样式窗口 – 有助于在内部样式表中更改样式。您还可以使用它在样式表中更改或移动样式。
- CSS 属性窗口 – 显示当前在网页中使用的样式。它还显示样式的优先级顺序。CSS 属性窗口显示所有 CSS 属性的列表。它使您能够向现有样式添加更多属性并修改已设置的属性。此外，此窗口有助于您创建新的内联样式。
- 直接样式应用工具栏 – 使您能够应用基于类或基于 ID 的样式。它可以帮助您创建和应用新样式。它也可以用于删除基于类或基于 ID 的样式。它还控制生成的新样式。

您刚刚快速概述了 ASP.NET 4.0 的新功能。让我们现在看看各种类型的 ASP.NET 网站。

## 指定 Web 应用程序的位置

Web 应用程序开发完成后，需要存储在网络中的特定位置。之后，我们可以从该位置打开应用程序并对其进行操作。Visual Studio 允许您使用映射到 Internet Information Services (IIS) 服务器的虚拟目录创建 Web 应用程序，或在 IIS 服务器范围之外创建独立应用程序。Visual Studio 2010 允许您将 Web 应用程序存储在以下三个位置：

- 文件系统
- 超文本传输协议 (HTTP)
- 文件传输协议 (FTP)

### 文件系统

Visual Studio 允许您将 Web 应用程序或网站的文件保存在本地硬盘驱动器中的文件夹或本地局域网上的共享位置。这些网站称为文件系统网站，除非您创建 Internet Information Services (IIS) 虚拟目录，否则它们与任何 IIS 应用程序无关。您可以使用内置 Web 服务器运行这些网站，该服务器在运行时执行。内置 Web 服务器允许您运行 Web 应用程序，即使您的系统上未配置 IIS 服务器。您也可以通过在 Visual Studio 集成开发环境 (IDE) 中选择 New→Web Site 选项来验证内置 Web 服务器的存在。在 Windows 7 中，Web 应用程序的默认位置是 C:\Users\Avantika\Documents\Visual Studio 2010\Projects，如图 13.1 所示：
