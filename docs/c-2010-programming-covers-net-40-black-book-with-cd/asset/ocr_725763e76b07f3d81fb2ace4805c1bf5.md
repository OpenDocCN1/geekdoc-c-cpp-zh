# Menu Display Properties

You can change the look of the Menu control by setting the following properties:

+   - Orientation – Means that you can set this property to horizontal to display menu either at the top or at the bottom of the page. The default orientation value is Vertical.

+   - StaticItemFormatString – Means that you can set this property to display the value for the static menus.

+   - DynamicItemFormatString – Means that you can set this property to display the value for the dynamic menus.

+   - StaticPopOutImageUrl – Means that you can set the replacement image for StaticPopOutImage. This means that the menu items can be hovered over to display all of its child items. The default image will appear dynamically and continue to be used for menu items.

# Menu Styles

The Menu control supports various styles at different levels, such as on individual menu items, menu sub levels. You can set styles for all menu levels and menu items that appear as both statically and dynamically on a Web page. The following are the different style properties:

+   - Static/DynamicMenuStyle – Controls properties for all MenuItem property. It also controls properties such as HorizontalPadding and VerticalPadding.

+   - DynamicMenuItemStyle – Controls the style of the individual MenuItems property. It also includes style properties such as ItemSpacing, VerticalPadding, and HorizontalPadding.

+   - DynamicSelectedStyle – Sets the style of the individual nodes in the TreeView control that are currently selected. In other words, it can be described as a collection of style properties for the selected menu item. It also includes style properties such as HorizontalPadding, VerticalPadding, and ItemSpacing.
