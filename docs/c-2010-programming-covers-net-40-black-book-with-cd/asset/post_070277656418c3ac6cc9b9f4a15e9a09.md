## Working with ASP.NET AJAX Enabled Web Services

As you know, a Web service is a collection of one or more server-side methods, which a client can call and use in applications at any remote location. The client first sends a request to the server using the HTTP protocol to call a Web service. The process is quite similar to that followed when a Web page processes the postback event, except that the body of the HTTP protocol request consists of those arguments that are passed to the methods of the Web service. An instance of the Web service is then created and the code inside the Web method is executed, which returns the result; the instance is destroyed afterwards. The Web services that are not AJAX-enabled use the SOAP protocol to send a request to the server and get a response, but AJAX-enabled Web services use the JSON format for this purpose.

Perform the following tasks to work with ASP.NET AJAX-enabled Web services:

- Creating the ASP.NET AJAX-enabled Web service
- Calling the ASP.NET AJAX enabled Web service from script

### Creating the ASP.NET AJAX-Enabled Web Service

In ASP.NET AJAX, Web services are defined in the same way as a Web service without the AJAX functionality. As with any other ASP.NET Web service, the ASP.NET AJAX enabled Web service consists of two parts, an .asmx file, which acts a Web service endpoint and a .cs file, which contains the code for the Web service. Let’s perform the following steps to create an ASP.NET AJAX enabled Web service:

Notice that the Web service class declaration consists of three attributes. The first is WebService (which sets an XML namespace for the Web service) and the second is WebServiceBinding (which indicates the level of the standards of conformity that the Web service can maintain). However, the third attribute ScriptService is much more important. This attribute allows your Web service to be called from a client-side scripting language, such as JavaScript, by using the JSON format. In the absence of this attribute, you will not be able to use ASP.NET AJAX enabled Web service.

## Using the UpdatePanel Control with a Web Service

Now, let’s learn how to use the UpdatePanel control with a Web service, which is used to refresh the specified part of a Web page instead of refreshing the whole Web page.

The UpdatePanel control in ASP.NET enables you to make rich, client-centric ASP.NET AJAX enabled Web services. If you want your Web page to refresh certain selected parts without refreshing the whole page with a postback, you can use the UpdatePanel control. This type of page updating, where a small part of the Web page is updated instead of the whole page, is known as a partial page update. The UpdatePanel control is placed inside a ScriptManager control. You can have one or more UpdatePanel controls inside a ScriptManager control.

The UpdatePanel control is used to make the Web page more interactive. When you write a code to partially update a page, you require a thorough knowledge of JavaScript, but with the use of the UpdatePanel control, you can partially update a Web page without using any client-side script.
