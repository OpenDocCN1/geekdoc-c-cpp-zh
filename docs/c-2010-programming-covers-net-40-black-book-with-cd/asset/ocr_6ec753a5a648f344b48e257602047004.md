# ## Relationships between Code

In Visual Studio 2010, a new window, called Architecture Explorer is added for viewing the relationships between the different members of a solution or graph. The Architecture Explorer window displays the details of various objects, such as solution, project, and class. You can select the items contained in these objects and the methods or objects called by these objects.

You can access the Architecture Explorer window by either of the following ways:

+   - Select View→Architecture Explorer
+   - Press the CTRL+\ or CTRL+R keys combination
