# The ListBox Control

The ListBox control is a standard Web server control used to select one or more items from a list of items on a Web page at runtime. The inheritance hierarchy for the ListBox class is:

```
System.Object
  System.Web.UI.Control
    System.Web.UI.WebControls.WebControl
      System.Web.UI.WebControls.BaseDataBoundControl
        System.Web.UI.WebControls.DataBoundControl
          System.Web.UI.WebControls.ListControl
            System.Web.UI.WebControls.ListBox
```

You can use the Rows property of the ListBox control to specify the height of the control. To enable multiple item selection, you can set the SelectionMode property to ListSelectionMode.Multiple. You can find the selected item in a single-selection ListBox control with the help of SelectedItem and SelectedIndex properties. The SelectedItem property returns the selected item as a ListItem object, which supports Text, Value, and Selected properties. In multiple-selection ListBox control (which implies that we are selecting multiple items from a single ListBox control), the loop runs over the selected items in the ListBox controls and returns each selected item as a ListItem object by using the SelectedIndex property.

The ListBox class inherits the ListControl class; moreover, it does not have any non-inherited events. The ListControl class does not have any non-inherited methods either. Note that the Items property of the ListControl class returns a collection of ListItem objects, which you can use to access an item in a ListBox. Noteworthy public properties of the ListBox class are listed in Table 14.21:

Table 14.21: Noteworthy Public Properties of the ListBox Class

| Property | Description |
|---|---|
| BorderColor | Obtains or sets the border color of the control |
| BorderStyle | Obtains or sets the border style of the control |
| BorderWidth | Obtains or sets the border width for the control |
| Rows | Obtains or sets the number of rows displayed in the ListBox control |
| SelectionMode | Obtains or sets the selection mode of the ListBox control |

# The DropDownList Control

The DropDownList control displays the list of data as a drop-down list from which you can make a single selection. The DropDownList control exists within the System.Web.UI.WebControls namespace. You cannot select multiple items in this control because when you make a selection from the list, the list closes automatically. The the inheritance hierarchy for the DropDownList class is as follows:

```
System.Object
  System.Web.UI.Control
    System.Web.UI.WebControls.WebControl
      System.Web.UI.WebControls.BaseDataBoundControl
        System.Web.UI.WebControls.DataBoundControl
          System.Web.UI.WebControls.ListControl
            System.Web.UI.WebControls.DropDownList
```

The DropDownList class inherits the ListControl class and has no non-inherited methods or events. Noteworthy public properties of the DropDownList class are listed in Table 14.22:

Table 14.22: Noteworthy Public Properties of the DropDownList Class

| Property | Description |
|---|---|
| BorderColor | Obtains or sets the border color of the control |
