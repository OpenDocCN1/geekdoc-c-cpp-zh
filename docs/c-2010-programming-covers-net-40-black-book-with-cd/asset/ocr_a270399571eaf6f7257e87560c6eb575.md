# Creating a Delegate

You can use delegates to change the behavior of a program at runtime. Let’s create a Console application, named MyDelegate (also available in the CD). We also create a delegate that maintains account balances in an accounting system. The delegate declared in the MyDelegate application handles the credit and debit transactions in an account.
