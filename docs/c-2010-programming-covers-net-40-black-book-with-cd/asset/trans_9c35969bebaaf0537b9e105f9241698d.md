## 拆分视图栏

在 Visual Studio 2010 中，你可以同时使用设计视图和 XAML 视图。这得益于拆分视图栏（图 9.22），它显示了 WPF 设计器的拆分视图。拆分视图栏左侧有两个选项卡，分别对应设计窗格和 XAML 窗格；右侧有三个按钮。第一个选项卡对应设计窗格，允许你查看设计视图；第二个选项卡对应 XAML 窗格，允许你查看 XAML 视图。拆分视图栏上有一个“交换窗格”按钮，位于设计窗格和 XAML 窗格之间。单击“交换窗格”按钮后，设计视图和 XAML 视图会相互交换，也就是说，设计视图显示在底部，XAML 视图显示在顶部，如图 9.23 所示：

## 标记导航器

在 XAML 视图中，标记导航器允许你导航当前标记的父 XAML 标记或元素。标记导航器出现在 XAML 视图的底部。它显示当前选中的标记（以粗体显示）以及到该标记为止的层级结构，如图 9.26 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_366_0.png)

正如图 9.26 所示，Button 标记是 XAML 视图中当前选中的标记。其名称在标记导航器中以粗体显示。Button 标记的名称后面是超链接，这些超链接由正斜杠分隔，即 Window/Grid/Button，其中 Window、Grid 和 Button 都是超链接。这些超链接表示父标记或到当前选中标记为止的层级结构。如果将鼠标悬停在任一超链接上，会显示缩略图（图 9.26）。你可以单击任一超链接来选择该标记。例如，在图 9.26 中，如果单击 Grid 超链接，则会选中 Grid 标记。图 9.27 显示了选中的 Grid 标记：

## 工具箱

工具箱提供了多种控件，可用于设计 WPF 应用程序的 UI。你可以将控件从工具箱拖放到设计视图中，也可以将控件拖放到 XAML 视图中。WPF 设计器工具箱中的控件分为三个选项卡：

- “常用” — 包含 WPF 应用程序中较常用的控件。
- “控件” — 包含所有 WPF 控件。
- “常规” — 包含一些常规控件，例如 Pointer 和 TreeView 控件。你创建的任何自定义控件都会放在此选项卡下。

> 注意
> 如果工具箱不可见，可以从菜单栏选择“视图”→“工具箱”，或按键盘上的 CTRL+ALT+X。

## 文档大纲窗口

“文档大纲”窗口以层次结构视图呈现当前 WPF 应用程序的 UI。你可以使用它来选择、移除和导航 WPF 应用程序的 UI 元素。默认情况下，文档大纲窗口在 WPF 设计器中不可见。你可以通过从菜单栏选择“视图”→“其他窗口”→“文档大纲”，或按键盘上的 CTRL+ALT+T 来查看文档大纲窗口。此外，你还可以通过在设计视图中任意位置单击右键并选择“文档大纲”来查看文档大纲窗口（如图 9.31 所示）。图 9.31 显示了 WPF 应用程序在文档大纲窗口中的结构：

![](img/e073a4882197be4ab61103cbe0bcb394_368_0.png)

图 9.31：在文档大纲窗口中显示独立 WPF 应用程序的结构

在图 9.31 中，文档大纲窗口以自上而下的层次结构显示 WPF 应用程序 UI 的大纲或结构。在层次结构的最顶部显示根节点或根元素，即 Window 元素。Grid 元素位于 Window 元素之下，其子元素显示在 Grid 元素之下。在本例中，Grid 元素的子元素包括 RowDefinitions、ColumnDefinitions、Button 和 RadioButton 元素。
