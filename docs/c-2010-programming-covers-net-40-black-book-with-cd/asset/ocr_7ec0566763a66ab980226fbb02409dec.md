+   - Clean Solution – Deletes the intermediate and output files, except the project files, from which new instances of the intermediate and output files can be built
+   - Build project name – Builds only selected projects within a solution
+   - Rebuild project name – Recompiles the selected project within a solution
+   - Clean project name – Deletes the output files, except the project files, from which new instances of the output files can be built
