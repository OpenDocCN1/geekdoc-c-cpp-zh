# Table 33.1: Showing the Contents of an Assembly Manifest

| Assembly Manifest's Contents | Description |
|---|---|
| Culture | Represents information on the culture or language supported by an assembly. This information is used to designate an assembly. Assemblies that contain the resources having culture-specific or language-specific information are known as satellite assemblies. |
| Strong name information | Represents the public key issued by the publisher. |
| List of all files in the assembly | Represents the names of the files contained in an assembly. All the files of a particular assembly must be stored in the same directory in which the file containing the assembly manifest is stored. |
| Type reference information | Represents the information used at runtime to map a type reference to the file that contains its declaration and implementation. This is used for types exported from the assembly. |
| Information on referenced assemblies | Represents a list of assemblies that are statically referenced by any other assembly. Each reference includes the dependent assembly's name, its metadata (version, culture, and operating system), and public key. |
