# Adding Borders to Controls

As discussed in the In Depth section, the Border control helps to add a border or a background or both to a control. Let’s now learn to add a border to the Grid control in a WPF application through the XAML code.

Create a WPF application named AddingBorders (available in the CD) and add the code, shown in Listing 10.9, to MainWindow.xaml file:

# Listing 10.9: Showing the Code to Implement Borders to Controls

```
<Window x:Class="AddingBorders.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="350" Width="525">
    <Grid>
        <Border Background="Pink" BorderBrush="Black" BorderThickness="5" CornerRadius="30"/>
        <Button BorderBrush="Blue" Height="100" Width="100" BorderThickness="4" Background="Blueviolet"/>
    </Grid>
</Window>
```

In Listing 10.9, a Border control is added to the Grid and Button controls. The background and color of the Border control is set by the Background and BorderBrush properties, respectively. You can set the degree to which the corners of the borders are rounded by using the CornerRadius property. Run the application by pressing the F5 key.
