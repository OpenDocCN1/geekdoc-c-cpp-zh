**Figure 19.33: Enabling Directory Browsing for the SimpleInterestService Application**

14. Click the Enable link in the Actions pane to enable the browsing of the directories or folders of the `SimpleInterestService` application.

15. Open the `applicationHost.config` file located in the `C:\Windows\System32\inetsrv\config` folder and change the following values:

+   - In the `<section name="handlers" overrideModeDefault="Deny" />` section, change the value of the `overrideModeDefault` to `Allow`.
+   - In `<section name="modules" allowDefinition="MachineToApplication" overrideModeDefault="Deny" />`, change the value of the `overrideModeDefault` to `Allow`.
