## Using Nested for Loops

Nesting of loop means to create one loop inside another loop, such as a for loop inside another for loop. Let’s create a console application named MyNestedForLoop (also available on the CD) that shows the use of nested for loop with multidimensional arrays. Listing 3.9 shows the code of the MyNestedForLoop application:

Listing 3.9: Showing the Code of the MyNestedForLoop Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace MyNestedForLoop
{
    class Program
    {
        static void Main(string[] args)
        {
            int[,] firstMatrix = new int[2, 2];
            int[,] secondMatrix = new int[2, 2];
            int[,] sumMatrix = new int[2, 2];
            int i, j;
            Console.WriteLine("Enter the Elements of the First 2X2 Matrix:");
            for (i = 0; i < 2; i++)
            {
                for (j = 0; j < 2; j++)
                {
                    firstMatrix[i, j] = int.Parse(Console.ReadLine());
                }
            }
            Console.WriteLine("Enter the Elements of the Second 2X2 Matrix:");
            for (i = 0; i < 2; i++)
            {
                for (j = 0; j < 2; j++)
                {
                    secondMatrix[i, j] = int.Parse(Console.ReadLine());
                }
            }
            Console.WriteLine("The Sum of the Matrices is:");
            for (i = 0; i < 2; i++)
            {
                for (j = 0; j < 2; j++)
                {
                    sumMatrix[i, j] = firstMatrix[i, j] + secondMatrix[i, j];
                    Console.Write(+sumMatrix[i, j] + " ");
                }
                Console.WriteLine("");
            }
            Console.Write("\nPress ENTER to quit...");
            Console.ReadLine();
        }
    }
}
```

In Listing 3.9, we have defined three multidimensional arrays with the name firstMatrix and secondMatrix. We have used two for loops, outer and inner, to read the elements of the firstMatrix array as well as two for loops to read the elements of the secondMatrix array. The outer for loop reads the elements of rows and the inner for loop reads the elements of columns.

## Creating an Infinite Loop

An infinite loop is a loop that cannot be terminated implicitly. Infinite loops can be used in cases where you want a statement or a set of statements to be executed infinite number of times. In an infinite loop, you need not to specify a terminating condition. Let’s create a console application named MyInfiniteLoop (also available on the CD) that shows how to create an infinite loop. Listing 3.10 shows the code of the MyInfiniteLoop application:

Listing 3.10: Showing the Code of the MyInfiniteLoop Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyInfiniteLoop
{
    class Program
    {
        static void Main(string[] args)
        {
            int counter;
            for (counter = 0; ; counter++)
            {
                Console.WriteLine("I Stuck in a Loop");
            }
        }
    }
}
```

In Listing 3.10, we have not specified any condition in the for loop; therefore, it will execute infinite number of times.
