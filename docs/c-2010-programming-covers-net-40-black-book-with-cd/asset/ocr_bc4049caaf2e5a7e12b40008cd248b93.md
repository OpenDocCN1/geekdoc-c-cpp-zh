# 3-D Graphics

WPF provides a set of 3-D graphics that integrate with 2-D graphics in order to create visually appealing layout, UI, and data visualization. The 3-D implementation in WPF allows developers to draw, transform, and animate the 3-D graphics in both XAML and code. You can combine the 2-D and 3-D graphics to create rich controls and enhance the user experience of an application interface. The most important classes used in the creation of 3-D graphics in WPF are Viewport3D, Camera, Material, and Light, which you learn next.

# The Viewport3D Class

In WPF, if you want to work with 3-D content, you need a container that can host it. The container is the Viewport3D class, which is found in the System.Windows.Controls namespace. The Viewport3D class derives itself from the FrameworkElement class; and therefore, you can place the Viewport3D class with an element. The Viewport3D class displays 3-D content while providing properties consistent with the 2-D layout, such as clipping, height, width, and mouse event. There are two important properties of the Viewport3D class, Camera and Children. The Camera property of the Viewport3D class defines the lookout of the content on the 3-D scene and the Children property holds all the 3-D objects that you want to place in the scene.
