## Using the Dictionary<TValue> Class

The Dictionary<TValue> class allows you to create generic collections that store pairs of keys and values. You can retrieve the objects using the keys associated with them. Let’s create an application named GenericDictionarySample, also available on the CD-ROM, to understand the use of Dictionary<TValue> class. This application contains a sample user interface form with three buttons--Create and add 10 items, ContainsKey, and ContainsValue, and one ListView control.

Perform the following steps to create the `GenericDictionarySample` application:

- 1. Set the Text property of Form1 to Generic Dictionary Sample.
- 2. Drag and drop a ListView, a GroupBox, and three Button controls to the form.
- 3. Set the Text property of the GroupBox control to Noteworthy Operations and the Text property of button1 to Create and add 10 items, button2 to ContainsKey, and button3 to ContainsValue.
- 4. Add columns to the ListView control by clicking the ellipse button (...) of the Columns property of the ListView control in the Properties window. The ColumnHeader Collection Editor dialog box appears.
- 5. Click the Add button to add a column to the ListView control in the ColumnHeader Collection Editor dialog box. Set the Name property of this column to Key and the Text property to Keys. Similarly, add another column to the ListView control with the name as Value and text set to Values, and then click the OK button.

## Using the SortedDictionary<TKey, TValue> Class

The SortedDictionary<TKey, TValue> class is the sorted version of the Dictionary<TKey, TValue> class. All dictionary collections allow you to create pairs of keys and values, where the key is associated with the object and used to retrieve the object. However, with the SortedDictionary<TKey, TValue> class, when you add objects to the collection, they get added and arranged on the basis of the keys associated with them.

Let’s create an application named GenericSortedDictionarySample, also available on the CD-ROM, to understand the use of the SortedDictionary<TKey, TValue> class. This application contains a sample user interface form with three buttons--Create and add 10 items, ContainsKey, and ContainsValue, and a ListView control.

Perform the following steps to create the GenericSortedDictionarySample application:

- 1. Set the Text property of Form1 to Generic SortedDictionary Sample in the GenericSortedDictionarySample application.
- 2. Drag and drop a ListView, a GroupBox, and three Button controls to the form.
- 3. Set the Text property of the GroupBox control to Noteworthy Operations and the Text property of button1 to Create and add 10 items, button2 to ContainsKey, and button3 to ContainsValue.
- 4. Add columns to the ListView control by clicking the ellipse button (...) of the Columns property of ListView control in the Properties window. The ColumnHeader Collection Editor dialog box appears.
- 5. Click the Add button to add a column to the ListView control in the ColumnHeader Collection Editor dialog box. Set the Name property of this column to Key and the Text property to Keys. Similarly, add another column to the ListView control with the name as Value and text set to Values and then click the OK button.
