# Using the Copy Web Site Tool

The Copy Web Site tool is used to replace a final Web site with the previous Web site on a target server directly. It means you can open a folder on a target server, and then upload and download the files from the source Web site to the target Web site. The Copy Web Site tool synchronizes the files in both Web sites and keeps sites with updated files.

When the application files are copied from a source Web site to a target Web site, the Copy Web Site tool creates a file, named App_offline.htm, into the root directory of the target Web site. Till the App_offline.htm file exists, all requests to the Web site are redirected to this file. The App_offline.htm file shows a message to the clients that the Web site is being updated. After copying the application files, the Copy Web Site tool deletes the App_offline.htm file from the target Web site.

Some features of the Copy Web Site tool are given as follows:

+   - You can copy the .aspx and class files from a source server to a target server.
+   - You can open and copy files from any kind of Web site, such as Local IIS, Remote IIS, and File Transfer Protocol (FTP), supported by Visual Studio 2010.
+   - The synchronization feature of the Copy Web Site tool checks the files of both Web sites automatically and keeps them with the up-to-date versions of the files.
