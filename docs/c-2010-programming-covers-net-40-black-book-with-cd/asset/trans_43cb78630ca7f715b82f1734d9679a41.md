## 深入探讨

C# 是一种面向对象的编程语言，可帮助你在 Microsoft .NET 平台上开发安全、可靠且稳定的应用程序。C# 是一种编码量较少的语言，并且拥有丰富的图形用户界面（GUI）。它使你能在诸如 Visual Studio 2010 集成开发环境（IDE）之类的交互式且视觉功能强大的环境中开发应用程序。

要创建任何 C# 应用程序，你必须熟悉 C# 基础知识，例如标识符、关键字、变量、常量、表达式和运算符。

标识符是用户为了识别程序中的各种元素（如变量、常量和属性）而指定的名称。而关键字是预定义的词语，被保留用于执行特定任务。在创建 C# 应用程序时，你可以使用变量来存储某种类型的值。这些变量的值会随着程序的每次执行而变化。另一方面，常量与变量类似，但分配给常量的值不能更改。表达式是一组语言元素的组合，通过使用不同的运算符（例如算术运算符和逻辑运算符）来执行特定任务或计算。

在本章中，你将学习 C# 编程的基本概念，如标识符、关键字、变量、常量、表达式和运算符。你还将学习如何在应用程序中实现这些概念。

## 标识符和关键字

在 C# 中，标识符是赋予变量、常量或任何用户定义的编程元素的名称。标识符以字母或下划线开头，以字符结尾。C# 标识符区分大小写；这意味着变量名 sum、Sum 和 SUM 三者互不相同。对于标识符的命名约定，Microsoft 建议使用匈牙利命名法和 CamelBack 命名法。它表示标识符以首字母小写开头，随后标识符中的后续单词以大写字母开头，例如 myFirstProgram。

创建标识符时，你必须记住以下规则：

- 标识符必须以字母或下划线（_）开头
- 标识符可以包含字母、数字和下划线
- 标识符不能是保留字（C# 中的关键字）
- 标识符必须是完整的单词，不能包含任何空格

现在让我们来了解 C# 中的关键字。

关键字是保留字，其含义由 C# 编译器预先定义。换句话说，关键字是 C# 编译器保留用于特定任务的词语。你不能将关键字用作变量、方法和属性，因为它们已经被定义给编译器以执行特定的功能。如果你想将关键字用作标识符，请在关键字前面加上 @ 字符。C# 提供了一些在代码上下文中具有特殊含义的标识符，例如 get 和 set，但它们不是保留关键字。这些标识符被称为上下文关键字。表 2.1 列出了 C# 中可用的不同保留关键字和上下文关键字：

## 变量和常量

变量是表示内存中存储位置的标识符。它存储在程序执行期间可能更改的数字或字符串值。在程序执行期间，变量在不同时间可能取不同的值，但变量的名称始终保持不变。每个变量都有一种数据类型，该类型决定了你可以存储在变量中的值的类型。以下代码片段演示了如何声明变量并为其赋值：

```
int i;
i=15;
```

在上述代码片段的第一行中，我们通过指定数据类型 int 来声明一个名为 i 的整数类型变量。在第二行中，我们使用 = 运算符将值 15 赋给整数变量 i。

变量可以声明为局部变量或类变量。局部变量存在于类中给定方法的作用域内；而类变量存在于类的对象实例的整个生命周期内。类变量可以在类的任何方法中使用，并且可以是 public、private 或 protected。局部变量不能定义为 public 或 private，因为在定义它们的方法之外无法访问它们。

C# 还提供了静态类变量，可用于静态类方法。对于给定类的所有实例，只存在一个静态类变量实例。

变量可以是数组类型。以下代码片段演示了如何声明整数类型的数组：

```
int[] arr = new int[10];
```

const int x=100;
