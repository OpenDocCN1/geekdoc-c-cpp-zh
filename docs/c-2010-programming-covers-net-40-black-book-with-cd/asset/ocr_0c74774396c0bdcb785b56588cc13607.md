# The ListView Control

The ListView control is a data bound control used to display data from the associated data source. The ListView control enables a developer to display data in any format using templates and styles. This control provides excellent customization and extensibility features. It provides the developer with control on the rendered HTML output and provides support for adding new row, and sorting. When you drag the ListView control to the ASP.NET page, the following code appears in the Source view of the page:

```
<asp:ListView ID="Listview1" runat="server"></asp:ListView>
```

The inheritance hierarchy of the ListView control is as follows:

```
System.Object
  System.Web.UI.Control
    System.Web.UI.WebControls.WebControl
      System.Web.UI.WebControls.BaseDataBoundControl
        System.Web.UI.WebControls.DataBoundControl
          System.Web.UI.WebControls.ListView
```
