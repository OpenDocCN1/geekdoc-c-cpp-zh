## Using the Copy Web Site Tool

Copy Web Site 工具用于直接用先前的网站替换目标服务器上的最终网站。这意味着你可以打开目标服务器上的一个文件夹，然后从源网站上传和下载文件到目标网站。Copy Web Site 工具同步两个网站中的文件并保持网站使用更新后的文件。

当应用程序文件从源网站复制到目标网站时，Copy Web Site 工具会在目标网站的根目录中创建一个名为 App_offline.htm 的文件。只要 App_offline.htm 文件存在，所有对网站的请求都会重定向到该文件。App_offline.htm 文件向客户端显示网站正在更新的消息。复制完应用程序文件后，Copy Web Site 工具会从目标网站删除 App_offline.htm 文件。

Copy Web Site 工具的一些功能如下：

- 你可以从源服务器复制 .aspx 和类文件到目标服务器。
- 你可以打开并复制任何类型的网站的文件，例如 Visual Studio 2010 支持的本地 IIS、远程 IIS 和文件传输协议（FTP）。
- Copy Web Site 工具的同步功能会自动检查两个网站的文件并保持它们为文件的最新版本。

### Deploying a Windows Application Using Windows Installer

要部署 Windows 应用程序，你需要使用 Visual C# 2010 中的设置和部署项目创建一个 Windows 安装程序文件（.msi 文件）。你需要做的就是将 .msi 文件传输到运行 Windows 操作系统的目标计算机，并双击 .msi 安装程序文件。让我们为名为 DeploymentTest 的应用程序创建一个 .msi 文件（该应用程序也可在 CD 上获得）。DeploymentTest 是一个简单的 Windows 窗体应用程序，其 Form1 表单上有两个 Label 控件、两个 TextBox 控件和一个 Button 控件。修改 Label 和 Button 控件的 Text 属性以及 Form1 表单，如图 21.11 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1077_0.png)

**Figure 21.11: Displaying the Design of the DeploymentTest Application**

你需要在 Button 控件的 Click 事件中添加以下代码片段：

```csharp
private void button1_Click(object sender, EventArgs e)
{
    textBox2.Text = textBox1.Text;
}
```

在前面的代码片段中，一个 TextBox 控件 `textBox1` 的内容被复制到第二个 TextBox 控件 `textBox2`。

现在，执行以下任务来创建 DeploymentTest 应用程序的安装程序文件并将其部署到另一台计算机上：

1. Creating an installer file
2. Adding shortcuts to user desktop or user programs menu
3. Deploying an application on a target computer

### Adding Shortcuts to User Desktop or User Programs Menu
