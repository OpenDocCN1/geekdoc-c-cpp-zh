## 使用排版

排版有助于以用户定义的方式格式化和呈现文本。如本章“深入”部分所述，您可以使用不同的排版类对文本应用不同的效果并转换文本。在本节中，您将学习执行以下任务：

- 显示特殊字符
- 为文本添加装饰
- 操作文本
- 换行文本
- 修剪文本
- 转换文本
- 使用 TextEffect 元素添加动画
- 为文本添加阴影
- 对文本应用模糊效果

让我们逐一执行这些任务。

### 显示特殊字符

在 WPF 中，如果您想显示一些符号，例如 <、> 和 &，您不能直接在应用程序中编写它们，因为这些符号已被分配用于执行特定任务。在这种情况下，您需要在应用程序中使用特殊字符来显示符号。现在，让我们创建一个名为 SpecialCharacters 的应用程序（也可在 CD-ROM 上获得）来学习如何显示特殊字符。为此，将第 11.1 节中显示的代码添加到 MainWindow.xaml：

### 列表 11.1：显示用于显示特殊字符的代码

```
<Window x:Class="SpecialCharacters.MainWindow"
xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
Title="MainWindow" Height="200" Width="300">
<Grid Height="263">
<TextBox Height="23" Margin="0,13,53,0" Name="textBox1" verticalAlignment="Top">
&lt;lt; is the Less than symbol.
</TextBox>
<TextBox Height="23" Margin="0,50,53,0" Name="textBox2" verticalAlignment="Top">
&gt;t; is the Greater than symbol.
</TextBox>
<TextBox Margin="0,87,53,152" Name="textBox3">
&amp; is the Ampersand symbol.
</TextBox>
<TextBox Height="23" Margin="0,0,53,107" Name="textBox4" verticalAlignment="Bottom">
&quot;Representing the Double Quote&quot;
</TextBox>
</Grid>
</Window>
```

在列表 11.1 中，我们添加了四个文本框并使用特殊字符在文本框中显示符号。您可以通过按 F5 键运行应用程序。列表 11.1 的输出如图 11.1 所示：

### 为文本添加装饰

在 WPF 中，您可以使用 TextDecoration 类装饰文本。TextDecoration 类提供了一组静态预定义文本装饰。这些预定义装饰包括基线、上划线和下划线。让我们创建一个名为 TextDecorations 的 WPF 应用程序（也可在 CD-ROM 上获得）来学习如何装饰文本。列表 11.2 显示了 TextDecoration 应用程序的代码：

### 列表 11.2：显示用于为文本添加装饰的代码

```
<Window x:Class="TextDecorations.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="240" Width="300">
<Grid Height="212" Width="259">
    <TextBlock TextDecorations="Strikethrough" FontSize="30" verticalAlignment="Top" Margin="0,126,0,0">
    <TextBlock FontSize="30" VerticalAlignment="Top">Susane</TextBlock>
    <TextBlock FontSize="30" VerticalAlignment="Top">Hello!!!!!
    <TextBlock.TextDecorations>
    <TextDecorationCollection>
    <TextDecoration PenThicknessUnit="FontRecommended">
    <TextDecoration.Pen>

    <Pen.Brush>
    <LinearGradientBrush Opacity="0.5" StartPoint="0,0.5" EndPoint="1,0.5">

    <GradientStop Color="Green" Offset="1" />
    </LinearGradientBrush.GradientStops>
    </LinearGradientBrush>

    <DashStyle Dashes="3"/>
```

### 操作文本

在 WPF 中，操作包括更改文本的数字样式、大写样式和变体。文本的操作借助 OpenType 字体完成。通过使用 OpenType 字体的 Capitals 功能，您可以设置一种排版形式，以大写样式字形呈现文本。OpenType 支持的不同类型的大小写样式格式为：小型大写字母、微型大写字母、标题和大写间距。OpenType 字体还支持可与文本中的数值一起使用的功能。例如，OpenType 支持分数值的斜线和堆叠样式。让我们创建一个名为 ManipulatingTypography 的 WPF 应用程序（也可在 CD-ROM 上获得）来学习如何操作文本。列表 11.3 显示了 ManipulatingTypography 的代码：

### 列表 11.3：显示用于操作文本的代码

```
<Window x:Class="ManipulatingTypography.MainWindow" xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation" xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml" Title="MainWindow" Height="100" Width="300">
<TextBlock FontFamily="P" FontSize="18" Typography.Fraction="Normal" IsHitTestVisible="True" Height="30">
<Run Typography.Capitals="AllSmallCaps">WATER</Run> = H<Run Typography.Variants="Subscript">2</Run>O (3/4 OF LAND)
</TextBlock>
</Window>
```

### 换行文本

在 WPF 中，当文本键入到 TextBlock 控件中时，文本会以连续的行出现。但是，您可以使用 TextBlock.TextWrapping 属性在文本到达 TextBlock 控件的右边缘时将其显示在下一行。此属性的可能值为 WrapWithOverflow、NoWrap 和 Wrap。默认情况下，此属性的值设置为 NoWrap。让我们创建一个名为 TextWrapping 的 WPF 应用程序（也可在 CD-ROM 上获得）来学习如何换行文本。为此，将列表 11.4 中给出的代码添加到 TextWrapping 的 MainWindow.xaml：

### 列表 11.4：显示用于换行文本的代码

```
<Window x:Class="TextWrapping.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="120" Width="300">
    <Grid>
        <TextBlock FontFamily="Century Gothic" FontSize="15" FontWeight="Bold"
            TextAlignment="Left" TextWrapping="Wrap">
            This is an example of text wrapping in a TextBlock. The text appears as
            in the next line.
        </TextBlock>
    </Grid>
</Window>
```

在列表 11.4 中，我们向 TextBlock 控件添加了一些文本并将 TextWrapping 属性设置为 Wrap。列表 11.4 的输出如图 11.4 所示：

### 修剪文本

在 WPF 中，您可以使用 TextTrimming 属性在文本超出容器长度时修剪文本。此属性接受三个值中的任意一个：None、CharacterEllipsis 和 WordEllipsis。表 11.25 列出了 TextTrimming 属性的值：

### 表 11.25：显示 TextTrimming 属性值的列表

| 成员 | 描述 |
|---|---|
| None | 不修剪文本 |
| CharacterEllipsis | 在字符边界处修剪文本，并在剩余文本位置绘制省略号 |
| WordEllipsis | 在单词边界处修剪文本，并在剩余文本位置绘制省略号 |
