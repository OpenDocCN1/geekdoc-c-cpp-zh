# WCF Clients

A WCF client, also known as a WCF consumer, consists of a proxy that enables an application to communicate with a WCF service. To create a client application for a WCF service, you first need to obtain the service contract, binding, and endpoint address. After obtaining this information, you can create a WCF client, call the operations of the WCF service, and then finally close the client object.

You learn how to create a WCF client later in the Immediate Solutions section of this chapter.

# WCF Service Identity

WCF service identity is a value generated from WSDL for a service at design time. This value is transmitted to a client and the client uses it to authenticate the WCF service before calling any of its operation. On the other hand, a WCF service also authenticates a client's credentials before allowing access to its operations. The service identity is represented by the identity property of the EndpointAddress class. You can obtain the service identity by using the Service Model Metadata Utility tool (Svcutil.exe). Through this tool, a configuration file is generated automatically for the WCF service that contains the value of service's identity property. Table 19.5 shows each identity type along with its description:

| Table 19.5: Showing the WCF Service Identity |
| Identity type | Description |
| Domain Name System (DNS) | Compares DNS specified in the credential of the WCF service with the value specified in the identity element |
| Certificate | Compares a Base64-encoded X.509 certificate value with a client |
| Certificate Reference | Enables you to specify a certificate name and location from where to retrieve the certificate |
| Rivest, Shamir and Adleman (RSA) | Specifies an RSA key value to compare with a client |
| User Principal Name (UPN) | Specifies the UPN under which a service is running |
| Service Principal Name (SPN) | Specifies the SPN associated with the service's account |
