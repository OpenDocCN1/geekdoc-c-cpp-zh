## ChangePassword 控件

ChangePassword 控件允许用户更改其密码。此控件会先提示用户提供当前密码，然后再设置新密码。如果旧密码不正确，则无法设置新密码。此控件还便于向用户发送有关新密码的电子邮件。ChangePassword 控件由 ChangePassword 类提供。

以下代码片段显示了 ChangePassword 类的类层次结构：

```
System.Object
  System.Web.UI.Control
    System.Web.UI.WebControls.WebControl
      System.Web.UI.WebControls.CompositeControl
        System.Web.UI.WebControls.ChangePassword
```

ChangePassword 类包含各种方法、属性和事件。
