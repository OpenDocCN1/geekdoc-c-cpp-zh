int I = 123;
Single s = I;

When one data type is converted explicitly to another data type, with the help of some pre-defined functions, it is called explicit conversion. ## Boxing and Unboxing

Boxing and unboxing are important concepts used in the C# type system. They are used to create a link between the two major data types in C#—value type and reference type. All value types are stored in stack, but in some situations they need to be referenced as heap. As reference types are stored in heap; therefore, you can convert the value type into reference type. This conversion is called boxing.

## Chapter 2: C# Fundamentals

Boxing is required in situations when a value type is converted into a base object or an interface. The Common Language Runtime (CLR) converts the value type to reference type. CLR allocates memory on heap and then copies the value type instance to it. Boxing is an expensive process, since it copies an object from a stack to heap which requires a number of processor cycles as well as space on the heap. Another disadvantage of using boxing is that the same object appears at two different places in memory which can have contradictory states.

Unboxing is the process of converting an instance of object type or interface back to value type. This is done explicitly by using unboxing. The following code snippet shows how boxing is done implicitly; whereas unboxing has to be done explicitly by using type cast:

```
int y = 123; //a value type
object obj = y; //Boxing is implicit
int z;
z = (int) obj; //Unboxing is explicit (use of type cast to unbox)
```
