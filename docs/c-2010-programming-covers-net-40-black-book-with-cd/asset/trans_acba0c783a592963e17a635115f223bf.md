## 创建 Windows Forms 应用程序

在本节中，你将学习如何创建 Windows Forms 应用程序。执行以下步骤创建名为 FirstProject 的 Windows 应用程序：

- 1. 点击 开始→所有程序→Microsoft Visual Studio 2010→Microsoft Visual Studio 2010。Visual Studio 2010 IDE 打开。
- 2. 点击 开始页 上的 新建项目 链接或选择 文件→新建→项目。 新建项目 对话框出现（图 8.2）。
- 3. 从 已安装模板 窗格中选择 Visual C# 选项，然后从中间窗格中选择 Windows Forms Application 选项。在 名称 文本框中输入名称，例如 FirstProject。
- 4. 在 位置 文本框中输入应用程序的位置，例如 D:\Black Books\C# 2010\Chapter 8\，使用 浏览 按钮。确保在 解决方案 下拉菜单中选择了 创建新解决方案 选项，并且 FirstProject 文本出现在 解决方案名称 文本框中，如图 8.2 所示：

图 8.2：显示新建项目对话框

- 5. 点击 确定 按钮。FirstProject Windows Forms 应用程序在 Visual Studio 2010 IDE 中打开，如图 8.3 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_302_1.png)

每当你创建一个新的 Windows Forms 应用程序或项目时，某些文件和目录会自动创建。在我们的例子中，以下文件和目录与 FirstProject 应用程序一起创建：

- FirstProject.csproj – 指定 C# 项目
- AssemblyInfo.cs – 包含有关程序集和应用程序版本等一般信息
- Form1.cs – 包含窗体的代码
- Resources.resx – 指定基于可扩展标记语言（XML）的资源模板
- FirstProject.sln – 指定应用程序的解决方案文件，存储解决方案的配置
- Bin – 指定二进制可执行文件的目录
- Obj – 指定调试二进制文件的目录

所有这些文件和目录都是由 C# 2010 自动创建的。现在，让我们在 Form1.cs 文件中添加一些控件。
