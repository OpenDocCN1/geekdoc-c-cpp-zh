# Converting a Number Type into another Number Type

The task of converting numbers from one type to another is a complex task. Sometimes, you want to simply convert a given type to get only the whole number portion of it. If you convert one type to another in a non-type-safe manner, such as a direct cast, the compiler cannot verify that the types you are converting are legitimate versions of one another.
