## The Path Class

The Path class is used to perform operations on String instances that contain file or directory path information. Path is a string that provides you the exact location of a file or directory. It is not mandatory that path always refers to only a location on the disk. The path format depends mostly on the current platform. Therefore, some systems paths start with a drive or letter name, but this is not true for all the systems.
In some systems, path also contains file extension that contains information regarding files. The extension format for any file is platform dependent. For instance, some systems limit their file extensions up to 3 characters, while others do not. The nature of the current platform also analyzes the character sets that are used to separate the elements of a path and the character sets that do not play any role in specifying the paths.

## File Compression

File compression is one of the important techniques of compressing files. You can use the GZipStream class to compress and decompress files. This class offers the gzip data format, which uses certain industry standard algorithms for file compression and decompression without any loss of data and information. The algorithms of gzip data format can be extended to use other compression formats, such as zip, rar, and cab.

It is important to note that files larger than 4GB cannot be compressed using the GZipStream class. All the compressed GZipStream objects that are written to files with the extension .gz can be easily decompressed with the help of various common compression tools such as WinZip, and Winrar. This class does not have any inherent functionality to add or extract files.
