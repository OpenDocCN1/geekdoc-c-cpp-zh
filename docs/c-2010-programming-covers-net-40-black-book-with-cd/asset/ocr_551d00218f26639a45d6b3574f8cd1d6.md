# Creating and Using Triggers

In this section, you learn to create a trigger as a CLR object in .NET Framework. To do this, you need to add a Trigger CLR object in SQL Server project. Let’s create a SQL Server project, named SqlServerProjectTrg (also available on CD), and add a trigger, InsertPersonalDetailsTrg.cs, to it.

Perform the following steps to create the SqlServerProjectTrg project in Visual Studio 2010:

+   1. Open Microsoft Visual Studio 2010.
+   2. Create a Visual C# SQL CLR Database Project, named SqlServerProjectTrg, as shown in Figure 23.11:

![](bbox=[0.19, 0.22, 0.81, 0.52])

Figure 23.11: Creating the SqlServerProjectTrg Project

+   3. Select an existing database connection or create a new one. In our case, we are selecting the existing database connection, charu-pc.MyData.dbo, as shown in Figure 23.12:

![](bbox=[0.31, 0.58, 0.67, 0.85])

Figure 23.12: Selecting an Existing Database Connection

+   4. Click the OK button (Figure 23.12). The SqlServerProjectTrg project is displayed in Visual Studio 2010.
+   5. Right-click the SqlServerProjectTrg project in Solution Explorer and select the Add→Trigger option. The Add New Item- SqlServerProjectTrg dialog box opens (Figure 23.13).
