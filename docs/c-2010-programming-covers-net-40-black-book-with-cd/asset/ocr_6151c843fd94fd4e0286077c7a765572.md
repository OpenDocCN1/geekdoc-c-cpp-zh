# Using Objects in another Application Domain

You can use the CreateDomain() method of the AppDomain class to create objects in the domains, other than your application's default domain.

Let's perform the following steps to create an additional domain:

+   1. Add one more Button control to Form1 of the AppOne application whose text is set as Click the Access Object Created in the Secondary AppDomain.

+   2. Add the System.Reflection and System.Runtime.Remoting namespaces in the AppOne application:

+   3. Add the following code snippet in the Click event of the Button control, button3:

```
private void button3_Click(object sender, EventArgs e)
{
AppDomain SecondAppDomain = AppDomain.CreateDomain("Second AppDomain");
ObjectHandle objH=SecondAppDomain.CreateInstance("AppTwo", "AppTwo.AClassInAppTwo",
true, BindingFlags.CreateInstance, null, new object[]{" - " +
AppDomain.CurrentDomain.FriendlyName+ " says Hi! -"}, null, null, null);
object obj=objH.Unwrap();
((AppTwo.AClassInAppTwo)obj).ASimpleMethod();
}
```

+   4. Build the AppTwo application and copy the AppTwo.exe file in the Debug folder of the AppOne application.
