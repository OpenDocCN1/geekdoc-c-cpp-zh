## 页面类

与网站中的网页类似，WPF 页面是 XBAP 中的基本实体。XBAP 中的页面保存显示给用户的内容。当你创建一个 XBAP 时，会自动包含一个页面。此外，当 XBAP 运行后，用户可以导航到 XBAP 中的任何页面。单个 XBAP 页面是 Page 类的一个实例。Page 类的类层次结构为：

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.DependencyObject
      System.Windows.Media.Visual
        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Page
```

Page 类具有各种属性、方法和事件。表 9.4 列出了 Page 类值得注意的属性：

| 属性 | 描述 |
|---|---|
| Content | 设置或获取页面的内容 |
| Height | 设置或获取页面的高度 |
| KeepAlive | 设置或获取一个值，该值指示在用户导航该页面后是否将页面保留在历史记录中 |
| LogicalChildren | 获取页面的逻辑子项的枚举器 |
| Name | 设置或获取页面的名称 |
| NavigationService | 获取主机用于控制页面导航的导航服务 |
| ShowsNavigationUI | 设置或获取一个值，该值指示是否显示导航控件 |
| Title | 设置或获取页面的标题 |
| Width | 设置或获取页面的宽度 |
| WindowHeight | 设置或获取包含该页面的窗口的高度 |
| WindowTitle | 设置或获取托管该页面的窗口的标题 |
| WindowWidth | 设置或获取包含该页面的窗口的宽度 |

Page 类的方法和事件与 Window 类相同。

## 应用程序类

无论是独立的还是 XBAP 的 WPF 应用程序，都由 Application 类的一个实例表示。该类提供了配置和运行 WPF 应用程序的一些基本功能。例如，Application 类允许你控制 WPF 应用程序的生命周期、处理命令行参数和退出代码（应用程序执行结束时返回给底层操作系统的值）、处理事件和运行时异常，以及跟踪 WPF 应用程序的导航。

请注意，Application 类在两种形式中都可用，分别是使用 App.xaml 和 App.xaml.cs 文件的 XAML 代码和 .NET 语言代码。在 XAML 中，<Application> 标签或元素表示应用程序，而在代码隐藏文件中，App 部分类执行相同的功能。Application 类的类层次结构如下：

```
System.Object
  System.Windows.Threading.DispatcherObject
    System.Windows.Application
```

表 9.5 列出了 Application 类值得注意的属性：

| 属性 | 描述 |
|---|---|
| Current | 返回当前 WPF 应用程序。 |
| MainWindow | 设置或获取 WPF 应用程序的主窗口。默认情况下，应用程序中创建的第一个窗口是主窗口。 |
| Properties | 返回应用程序特定属性的集合。Properties 集合无法通过 XAML 访问。 |
| ResourceAssembly | 设置或返回提供应用程序资源包统一资源标识符（URI）的程序集。 |
| Resources | 设置或返回应用程序特定资源的集合。 |
| ShutDownMode | 设置或返回导致调用 Shutdown() 方法的条件。根据 ShutdownMode 枚举的值，应用程序要么隐式关闭，要么显式关闭。 |
| StartupUri | 设置或返回应用程序启动时显示的 UI。 |
| Windows | 返回当前应用程序中的窗口集合。 |

| OnExit | 引发应用程序的 Exit 事件 |
| OnFragmentNavigation | 引发应用程序的 FragmentNavigation 事件 |
| OnLoadCompleted | 引发应用程序的 LoadCompleted 事件 |
| OnNavigated | 引发应用程序的 Navigated 事件 |

| OnSessionEnding | 引发应用程序的 SessionEnding 事件 |
| OnStartup | 引发应用程序的 Startup 事件 |
| Run | 启动 WPF 应用程序的运行 |
| SetCookie | 为特定 URI 位置创建 cookie |
| Shutdown | 关闭 WPF 应用程序 |

表 9.7 列出了 Application 类值得注意的事件：

| 事件 | 描述 |
|---|---|
| Activated | 当 WPF 应用程序为活动应用程序时发生 |
| Deactivated | 当 WPF 应用程序不再是活动应用程序时发生 |
| DispatcherUnhandledException | 当应用程序中遇到未处理的异常时发生 |

| Navigating | 当新的导航开始时发生 |
| NavigationFailed | 当导航时遇到错误时发生 |
| NavigationProgress | 在导航期间以固定间隔发生 |
| NavigationStopped | 当导航停止或新的导航开始时发生 |
| SessionEnding | 当 Windows（操作系统）会话因注销或关闭而结束时发生 |
| Startup | 当调用 Run() 方法时发生 |
