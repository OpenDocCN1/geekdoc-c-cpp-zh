Part II of the chapter covers advanced technique: the runtime object method, which is employed in developing and building data-driven applications. Chapter 6 provides detailed discussions and analyses about three data insertion methods with Microsoft SQL Server 2019 database:

- 1. Using TableAdapter's DBDirect methods TableAdapter.Insert() method
- 2. Using the TableAdapter's Update() method to insert new records that have already been added to the DataTable in the DataSet
- 3. Using the Command object's ExecuteNonQuery()

This chapter is also divided into two parts: Methods 1 and 2 are related to Visual Studio.NET design tools and wizards are therefore covered in Part I. The third method relates to the runtime object and it is covered in Part II. Three real projects are used to illustrate how to perform the data insertion into the Microsoft SQL Server 2019 database. Some professional and practical data validation methods are also discussed in this chapter to confirm the data insertion actions.

- Chapter 7 provides discussions and analyses on three popular data updating and deleting methods with four real-world examples:

- 1. Using TableAdapter DBDirect methods such as TableAdapter.Update() and TableAdapter.Delete() to update and delete data again from the databases.
- 2. Using TableAdapter.Update() method to update and execute the associated TableAdapter properties such as UpdateCommand or DeleteCommand to save changes made for the table to the database.
- 3. Using the runtime object method to develop and execute the Command's ExecuteNonQuery() to update or delete data again directly.

This chapter is also divided into two parts: Methods 1 and 2 are related to Visual Studio.NET design tools and wizards are therefore covered in Part I. # 1.4 HOW THIS BOOK IS ORGANIZED AND HOW TO USE THIS BOOK

This book is designed for both college students who are new to database programming with C# and professional database programmers who have professional experience on this topic.

Chapters 2-4 provide the fundamentals on database structures and components, ADO.NET and LINQ components. Starting from Chapter 5, also including Chapters 6 and 7, each chapter is divided into two parts: the fundamental part and the advanced part. The data-driven applications developed with design tools and wizards provided by Visual Studio.NET which can be considered as the fundamental part, with lower coding loads and that they are more suitable to students or programmers who are new to the database programming with C#.NET. # 1.5 HOW TO USE SOURCE CODES AND SAMPLE DATABASE

All source in each project developed in this book are available, and all projects are categorized into the associated chapters that are located at the folder Class DB Projects that is under the Students folder located on the CRC Press ftp site: https://9781032334776. You can copy or download these folders into your computer and run each project as you like. To successfully run projects, the following conditions must be:

- Visual Studio.NET 2022 or higher must be installed on your computer.
- The database management system, Microsoft SQL Server 2018 Studio 18, must be installed on your computer.
- The sample database, CSE_DEPT.mdf, must be installed on your computer in the appropriate folders.
- To run the projects in Chapters 8 and 9, in addition to the conditions listed above, an Internet Information Services (IIS), as FrontPage Extension 2000 or 2002, must be installed in your computer. This works as a pseudo server for those projects.

All related teaching and learning materials, including the sample databases, example projects, homework solutions, faculty and student images as well as sample Windows forms and Web pages, can be found from the associated folders, Instructors or Students, located on the CRC Press ftp site, as shown in Figure 12.
