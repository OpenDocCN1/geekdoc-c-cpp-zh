As discussed in Section 8.6.2, to delete an original record from the Faculty table in our sample database is a very complicated and time-consuming process due to the primary and foreign keys relationships. To delete an original faculty member, not only is the faculty record in the Faculty table removed, but also records related to faculty member in all child tables are also deleted. Moreover, it would be a reversible process to recover that deleted record since it was deleted from the parent table, and then recover the records in the child tables.

To make this deleting action, we will delete a faculty record that was inserted in this section but not an original faculty record (the so-called original faculty member is a member that is created when the database is generated).

To perform that deleting action, select the faculty member, Smith Lane, from the Faculty Name combobox, and click the Delete button to delete it. Immediately, all textboxes and the faculty image box become blank, which means our data deleting action is successful.

To test and confirm that deleting action, go to the Faculty Name combobox, and one can find the faculty member, Smith Lane, has selected.

# 8.8 DEVELOP WEB QUERIES TO COURSE TABLE WITH LINQ TO SQL METHOD

We do not need to create any new Web project to perform any query over the Course table using the LINQ to SQL technique; instead, we can modify any of our Web projects, WebLINQSQL Project, to make it new WebLINQSQL Course Project. Perform the following operations to complete this modification and creation for our new Web project:

+   1) Open the Windows Explorer or File Explorer and locate the Web solution folder WebLINQSQL Solution in your local machine (C: Chapter 8).
2) Right-click on that solution folder and select the Copy item to copy that solution with the project, and paste that folder under the same location in your local machine, such as C: Chapter 8.
3) Rename both folders to WebLINQSQL_Course Solution and WebLINQSQL_Course Project, respectively.
4) Expand the new solution folder WebLINQSQL_Course Solution and click on the new project folder WebLINQSQL_Course_Project to open it in the File Explorer.
5) Change the following two files' names, WebLINQSQL Project.csproj and WebLINQSQL Project.csproj.user, to WebLINQSQL_Course_Project.csproj and WebLINQSQL_Course_Project.csproj.user.
6) Double-click on the new project WebLINQSQL_Course_Project.csproj to open it in the Visual Studio 2022.
