private void ProcessObject(ref WS_SQLInsert.SQLInsertRecord wsResult)
{
    if (wsResult.SQLInsertOK == true)
        FullListBox(ref wsResult);
    else
        MessageBox.Show("Course information cannot be retrieved: " + wsResult.SQLInsertError());
}
private void FullListBox(ref WS_SQLInsert.SQLInsertRecord sqlResult)
{
    int index = 0;
    //clean up the course listBox
    CourseList.Items.Clear();
    for (index = 0; index <= sqlResult.CourseID.Length - 1; index++)
{
        if (sqlResult.CourseID[index] != null)
            CourseList.Items.Add(sqlResult.CourseID[index]);
    }
}

+   A. First we need to check the member data SQLInsertOK to make sure whether the method is executed successfully or not. If it is, the method FullListBox() is called to fill all course_id from the returned instance to the list box control in our client form.
B. A warning message is displayed if any error was encountered during the execution of that Web method.
C. In the user-defined method FullListBox(), a local integer variable index is created and works as a loop count to continuously pick up course_id from the returned instance and add it to the list box control.
D. The list box control is cleared before any course_id can be added to it. This process is very important in displaying any course_id, otherwise any new course_id will be attached at the end of the original course_id in this control and the displaying result is messy.
E. A for() loop is used to continuously pick each course_id from the CourseID() array defined in our returned class SQLResult. One point is to note the upper bound or the length of this array. The length or size of array is 11. But the upper bound of this array is 10 since the index of this array starts from 0, therefore the upper bound of this array is equal to the length of this array minus by 1. As long as the content of the CourseID(index) is not Null, the remaining course_id is added to the list box control using the Add() method.
