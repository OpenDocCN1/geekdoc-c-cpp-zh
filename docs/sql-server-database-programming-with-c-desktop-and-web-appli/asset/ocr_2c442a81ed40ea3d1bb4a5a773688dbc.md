Therefore, we need to retrieve the faculty_id from the Faculty table based on the Faculty Name selected by the user-based method FindByClassName().
B. After a search the default system method FindByFaculty_id is executed to locate the desired DataRow from the Faculty table, and the desired DataRow is returned and assigned to the local variable FacultyRow.
C. The Delete() method of the Faculty is executed to delete the selected DataRow from the Faculty DataTable in the Dataset.
D. The TableAdapter.Update() is executed to update that DataRow from the Dataset to the row in the database.
