# 298 SQL Server Database Programming with C#

Performing the following operations to complete this solution-copying-pasting and modifying-process:

+   1) Open the Windows Explorer window and browse to our solution folder LINQSelect Solution.
One can find this solution and the project from the CRC Ftp site, exactly in a folder Class DB Projects Chapter 5 that is under the Students folder in that.
2) Right-click on folder and select the Copy item to copy to folder, then go to your machine and your desired folder, right-click on that folder and select the Paste item to paste that solution into your local folder.
3) Expand copied Solution folder and change the name to LINQSelect Solution and then the project name via Notepad under the renamed LINQSelectProject folder.
4) Open the project-file CSE_DEPT.csproj via a Notepad
5) On the opened file, go to the <RootNamespace> (line 9) and <AssemblyName>(line 10) tags, change the RootNamespace to LINQSelect_Project and the AssemblyName to LINQSelectProject, respectively.
6) Go to the File | Save menu to save this modified file and close this file.
7) In the Windows Explorer window, change the name of saved file to LINQSelectProject.csproj.
8) Now double-click on renamed file, LINQSelectProject.csproj, to open this project.
9) Expand the folder CSE_DEPT from the Solution Explorer window, and double-click on the file CSE_DEPT.designer.cs to open it. Browse to line 51 and change the project name to base:global:LINQSelect.Properties since we have to use the original reference for this project
10) Go to the Solution Explorer window, and right-click on the Login item to copy your code window. Change its namespace to LINQSelect_Project.
11) In the Solution Explorer window, expand the Login.cs and change its name on the top to the Login.designer.cs to open this Designer file.
12) Repeat steps 10 for all other files, Course.cs, Faculty.cs, Selection.cs and Student.cs, to change their names to LINQSelect_Project.
13) In the Solution Explorer window, double-click on the Program.cs to open it, and change its name to LINQSelect.
14) Now go to the Build | Build item to build our copied project to complete this copy-paste process.

Right-click the designer and select the item Show Methods Pane from the popup menu to create our desired procedure by dragging each of them from the Server Explorer to Methods pane in this Object Relational Designer since the procedure is considered as a method in LINQ to SQL.

We need to use two stored procedures, StudentInfo and StudentCourse. Drag each of them from the Server Explorer window and place them to the Methods pane one by one.
