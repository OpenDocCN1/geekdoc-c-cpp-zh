# 46 SQL Server Database Programming with C#

Perform the following operations to create our new project SQL Image Project:

+   1) Enter SQL Image Project into the Project name, and SQL Image Solution into the Solution name box, as shown in Figure 2-48. Select a desired local folder on your machine to save this project and click on the Create button to create this C# project.
2) The created project wizard is shown in Figure 2-49. Click on the Add Data Source link in the Data Sources located at the lower-left (if this window is not shown, go up to View | OtherWindows | Data Sources to open it), to open the Data Source Configuration Wizard to connect to our SQL Server 2019 Express database CSE_DEPT.
3) Keep the default Database and DataSet selection on the next two wizards and click on the Next buttons to continue to our database connection page.
4) Click on the Next Connection to set up a new database connection object.
5) On the chosen Data Source wizard, select Microsoft SQL Server item from the Data Source list, then Next.
6) The next wizard, Add Connection, is shown in Figure 2-50. Enter the full name of your database server, DESKTOP-JPURF\SQL2019EXPRESS, into the Server name box.
7) Click on the dropdown arrow on the Select or enter a database name box, and select your sample database CSE-DEPT from the list. Your finished Add Connection wizard should match one that is shown in Figure 2.50.
8) Click the Test Connection button at the lower-left corner to test this connection. A successful connection message should be displayed if this connection is fine. Close the message box and click on the OK button to continue.
9) On the next wizard, you can check the Show connection string checkbox to review this connection string, and we may need this connection string later. Click on the Next button to continue.
10) Click on the Next button again on the next wizard to save our connection string.
11) Now all data objects or components, including five tables in our sample database, CSE_DEPT, are displayed, as shown in Figure 2.51.
