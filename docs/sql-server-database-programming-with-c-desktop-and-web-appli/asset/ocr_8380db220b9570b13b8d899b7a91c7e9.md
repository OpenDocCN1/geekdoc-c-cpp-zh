# 5.4 QUERY AND DISPLAY DATA USING THE DATAGRIDVIEW CONTROL

Now we added a data source into our Visual C# 2022 project. Before we can develop this data-driven project, we want to show a popular, but tool provided by the Toolbox window, DataGridView. As we discussed this tool in Section 5.1.1.2, the DataGridView is a container and it can be used to bind data from your database and display the data in a tabular or grid format in your Visual C# forms.

To use this tool, we first need to add a new blank form to the SelectWizard Project, and name this new form DataGrid. Go to Project | Add Form (Windows Forms) to open the Add Item wizard, enter DataGrid.cs into the Name box and click the Add button.

Change the name of the Name added from DataGrid to DataForm, and the Text property from DataGrid to DataGrid Form. Keep the form selected, and then open the Data Source window (if it is not opened). You can view data from any table in your data source window. Two popular views are Full Table and Detail for specified columns.

Here we use the Faculty table as an example to illustrate how to use these two views.

# 5.4.1 VIEW THE ENTIRE TABLE

To view the full Faculty table, click the Faculty table from the Data Source window, click the drop arrow and select the DataGridView item. Drag the Faculty table to the DataGridForm, which is shown in Figure 5.33.

As you drag the Faculty table to the DataGridForm, a set of graphics is created and added into your form automatically, which includes the browsing rows, Addition, Delete and Save buttons. This set of controls is used to help you view data from the selected table. To make a full table, make sure to set the properties of the DataGridView, AutoSizeColumns and AutoSizeRows, to None (Figure 5.33). In this way, you can make all data display on this grid tool.

In addition to those graphical components, a set of design tools, also added to this project when you drag the Faculty table onto the DataGrid window. As we discussed these tools in Section 5.1.1, these tools are used to help users to effectively access, translate and manipulate data between the Visual C# project and the DataSet.
