private int CurrentFaculty()
{
    int result = 0; index;
    facultyTableAdapter.ClearBeforeFill(true);
    facultyTableAdapter.Fill(cSE_DEPTDataSet.Faculty);
    if (cSE_DEPTDataSet.Faculty.Count != 0)
    {
        ComboName.Items.Clear();
        for (index = 0; index < cSE_DEPTDataSet.Faculty.Count; index++)
            ComboName.Items.Add(cSE_DEPTDataSet.Faculty.Rows[index].ItemArray[1].ToString());
        ComboName.SelectedIndex = 0;
        return result;
    }
    else
        return result++;
}

# Data Inserting with Visual C#.NET

## 6.2.6.1 Configure the TableAdapter.Insert() and Build the Data Insertion Query

In order use the TableAdapter.Insert() method to access the database, we need first to configure the TableAdapter and build the Insert query. Perform the operations to build this Insert query:

1) Open the Data Source window by going to View | OtherWindows | Data Sources menu item.
2) On the opened window, click the Edit the DataSet with Designer button that is located at the second left on the Data Source window to open this Designer. Then rightclick on the item from the Faculty table and select the Add Query item from the popup menu to open the TableAdapter Query Configuration.
3) Keep the default selection, Use SQL statements, unchanged and click the Next button to go to the next wizard.
4) Select and check the INSERT item from this wizard we need to perform inserting new query, and then click the Next button.
5) Click the Query Builder to build our Insert query. The opened Query Builder is shown in Figure 6.9.
6) The default query statement is insert with our requirement we want to insert a new faculty record that contains information about faculty_name, office, college, email and fimage. Click on the OK button to go to the next wizard.
7) Click on the Next to confirm this query and continue to the next step.
8) Modify the query name from the default one to InsertFaculty and click on the Next button to go to the last wizard.
9) Click on the Finish to complete this query and close the wizard.

Immediately, you can find that a new query function has been added into the FacultyTableAdapter as the last item.
