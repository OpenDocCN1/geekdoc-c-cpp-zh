# Data Selection Query with Visual C#.NET

DataContext a connection class that is used to establish a connection between your project and your database. In addition to this connection role, the DataContext also provides the conversion function to convert or interpret operations of the Standard Query Operators for the entity classes to the SQL statements that can be run in databases.

The procedure to use LINQ to SQL to perform data actions against SQL Server database can be described in terms of the following sequence listed:

+   1) Add the System.Data.Linq.dll assembly to the project that will use LINQ to SQL by adding the reference System.Data.Linq
2) Create an entity for each data table using one of two tools: SQL/Metal or Object Relational Designer.
3) Add a connection to the selected database using the DataContext class or the derived class from the Data class.
4) Use LINQ to SQL to access the database to perform desired data actions.

As mentioned in Chapter 4, the difference between the SQLMetal and the Object Relational Designer is that the former is a console-based application, whereas the latter is a window-based application. This means that the SQLMetal provides a DOS-like template and the operations are performed by entering single command into a black-white window. The Object Relational Designer, by contrast, provides a GUI and allows users to draw-table-places by graphic icons into it. Obviously, the second method or tool is more convenient and easier than the first one.

# 5.17.1 Create a New Visual C# Project and Setup LINQ to SQL Environment

In this section, we will develop a new Visual C# 2022 project LINSelect Project and to illustrate how to perform the data query using the LINQ to SQL method step by step. Perform the following operational steps to create a new Visual C# Windows Forms app LINQSelect Project:

+   1) Launch Visual Studio 2022 by clicking its icon on the desktop or the task bar.
2) Click on the Continue without code link at the lower-right corner to open the standard Visual Studio window.
3) Go to the File | New | Project item to create the new C# project.
4) On the opened window, select the template, Windows Forms (.NET Framework) with C#, which is an on the left, and click to select this template. Then click on the Next to continue.
5) On the next window, Configure your new project, enter LINSelect into the Project name box, and LINSelect Solution into the Solution name box, respectively. Select your desired folder from the Location box to save this new project.
6) Click on the Create button to create this new project.

To save time, we can use and add five existing Windows Forms, Login.cs, Selection.cs, Faculty.cs, Student.cs and Course.cs, into this new project. Perform the following operations to complete these Forms additions:

+   1) On the opened project, go to the Solution Explorer and right click on the iconForm1.cs and select the Delete item to remove this file.
2) Right click on the LINSelect Project in the Solution Explorer window and select the Adding Item item to open the Adding Existing Item window.
3) Browse to the CRC fps ftp site, exactly to the folder Students\Windows Forms under that site, select the Login.cs by clicking its checkbox on the left.
4) Click on the Add button to add this Form into your project.
