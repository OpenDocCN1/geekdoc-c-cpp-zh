The last coding job is for the Faculty ID TextBox, exactly for the **TextChanged** event and its method of the Faculty TextBox. As we mentioned, in order to avoid multiple insertions of the same data, the **Insert** button should be disabled after one data insertion is completed. This **Insert** button should be enabled when the content of the Faculty ID TextBox is changed, which means that a different record is to be inserted into the database.
Double-click the Faculty ID TextBox from the Form window to open this method and enter the codes that are in Figure 6.36 into this method.
Now we are ready to run the project to test the codes we have developed to insert a new record into the **Faculty** data table in our sample database. Click on **Start** button to run the project, complete the login process and open the Form window. Enter the following data into the TextBox as a new record:

| Faculty ID: | W56788 |
| Faculty Name: | Steve Wang |
| Title: | Professor |
| Office: | MTC-311 |
| Phone: | 750-378-2258 |
| College: | University of Miami |
| Email: | swang@college.edu |

Click the **Insert** button to insert this new record into the **Faculty** table in the database. On the opened File dialog window, browse to the folder where all faculty images are stored. In fact, all faculty images are stored in a folder **Images\Faculty** under the **Students** folder located on the CRC file path refer to Figure 1-2 in Chapter 1). You can copy all faculty images from that folder and save them to a local folder in the user's machine. Now browse to that local folder and select a faculty image **Wang.jpg**, and click on the **Open** button.
Immediately, after that data insertion is successful! the **Insert** button is disabled. To check and validate this newly inserted record, two methods can be used: 1) use the **Select** button's Click method to try retrieve back that newly inserted record from our database, 2) open our sample database and verify the **Faculty** table to confirm this data insertion.
First let's use the **Faculty Name** combobox and click on its drop-down, one can find that the new inserted faculty member, **Steve Wang**, has been added into this box. Select it and click on the **Select** button to try to get that record back back. Immediately, all pieces of that new inserted information, including a selected faculty image, are displayed in this Faculty Form window, as shown in Figure 6.37.
