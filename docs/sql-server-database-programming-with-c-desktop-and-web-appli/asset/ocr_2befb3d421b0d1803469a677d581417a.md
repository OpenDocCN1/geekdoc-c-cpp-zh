action. Open the Form window with the Designer View and double-click on the **Delete** button to open its Click method. Then enter the codes that are shown in Figure 7.9 to this method. Let's take a look at this piece of code to see how it works.

+   **A.** All components and objects as well variables in this method are declared and created here. A button of the MessageBox class is created and we need to use these two buttons to confirm the data deleting. The *FactoryRow* is used to locate the DataRow in the Factory DataTable and it is used for the second deleting method. The variable Answer is an instance of DialogResult and is used to hold the returned value of calling the system method MessageBox.Show().*This variable can be replaced by an integer value if you like.

+   **B.** First, the method MessageBox.Show() is called to confirm that a deletion will be performed from the Factory data table.

+   **C.** If the return value of calling this MessageBox.Show() is **Yes**, meaning that the user has confirmed that this data deleting is fine, the data deletion will be performed in the next step.

+   **D.** If the user selects the first method, the TableDBDirect method, which function we built in Section 7.2.1 will be used to perform the data deleting from the Factory table in the database.

+   **E.** Execution of the result of this method is stored in the local variable *intDelete*. If the user selects the second method, TableAdapter Update Method, the associated codes that will be developed in the next section will be executed to delete data, first from the DataTable in the DataSet, and then from the data by executing the *Update()* method.

+   **G.** The return value of calling the Adapter.Delete() method or the Adapter.Update() method is stored in the local variable *intDelete*. The value of this returned data is equal to the number of deleted rows in the database or deleted Rows in the DataSet. A returned zero value means that no row has been deleted or that deleting failed. In this case, a warning message is displayed.
