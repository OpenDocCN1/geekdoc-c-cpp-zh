# ASP.NET Web Services

Based on Section 9.3.2 in this chapter, the complete procedure to build a Web service project can be summarized as:

+   1) Modify the default namespace to make it our own Web service namespace.
2) Add a new database connection string to the Web configuration file Web.config.
3) Create a customer base class to handle error-checking codes to protect our Web service class.
4) Create a customer returned class to hold all required information. This class is a derived class based on the base class above.
5) Add Web methods to our Web main service class to access our database.
6) Develop the detail codes for those Web methods to perform the Web services.
