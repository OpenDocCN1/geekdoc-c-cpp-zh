private void FillCourseReaderTextBox(SQLDataReader CourseReader)
{
    int intIndex;
    TextBox[] cbox = { txtCourseID, txtCourse, txtCredit, txtClass, txtSchedule, txtEnroll };
    while (CourseReader.Read())
    {
        for (intIndex = 0; intIndex <= CourseReader.FieldCount - 1; intIndex++)
            cbox[intIndex].Text = CourseReader.GetValue(intIndex).ToString();
    }
}

# 8.4.9.6 Coding for the User-Defined Method FillCourseReaderTextBox

On the opened page of the Course form, the codes that are shown in Figure 8.33 into the Course class to create this user-defined method.
Let's take a look at this piece of codes to see how it works.

- A. A counter **intIndex** and a textbox array **cbox**, are created. The former is used for a loop counter for the **for** loop to pick up each column from the **CourseReader**, and the latter as a data handler to receive each column and display it on the related textbox in the course page.
- B. A **while** and **for** loop are used to pick up all pieces of course-related information from the DataReader by one. The **Read()** method is used to set the Condition for the **while** loop. A returned true means that valid data is read out from DataReader, and a returned false means no valid data can be read out from DataReader, in other words, no data is available and all data has been read out. The **for** loop uses the **FieldCount**–1 as the termination condition since the index of the first column is 0, not, 1, in the DataReader. Each read-out data is converted to a string and assigned to the associated textbox in the textbox object control.
