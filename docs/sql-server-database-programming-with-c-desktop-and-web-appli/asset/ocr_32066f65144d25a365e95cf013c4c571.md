# 4.5.2 Operations on DataRow Using the Extension Methods

The LINQ to DataSet functionality is expressed primarily through the extension methods in the DataRowExtensions and DataTableClasses. In C#, you can call either of these methods as an instance method of any object of type . When you use instance method to call this method, omit the first parameter. The DataSet API has been extended with two new methods of the DataRow class, Field() and SetField(). You can use these to form Language-Integrated Query (LINQ) expressions and method queries against DataObjData. They are the recommended methods to use for accessing column values within Language-Integrated Query (LINQ) expressions and method queries.
In this section discuss how to access and manipulate column values using the extension methods provided by the DataRow class, Field() and the SetField() methods. These methods provide easier access column values for developers, especially regarding null values. The DataSet uses Value to represent null values, whereas LINQ uses the null type supported in .NET Framework 2.0. Using the pre-existing column accessor in DataSet requires us to cast the return object to the appropriate type. If a particular field in a DataRow is null, you must explicitly check for it before returning the value and implicitly casting it to another throws InvalidCastException.
The Field() method allows you to obtain the value of a column from the DataRow object and handles the casting of DBNull. In total, the Field() method has six different prototypes. The SetField() method has three prototypes, allows users to set a new value for a column from the DataRow object, including a nullable data type whose value is null.
