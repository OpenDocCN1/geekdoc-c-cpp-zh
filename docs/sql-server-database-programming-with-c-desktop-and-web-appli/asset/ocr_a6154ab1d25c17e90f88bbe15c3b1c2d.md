# 9.3 ASP.NET SERVICE PROJECT TO ACCESS SQL SERVER DATABASE

To create a new ASP.NET Web service project, perform the following operations:

+   1) Open the Windows Explorer or File Explorer to create a new folder Chapter 9 under your
root drive C.
2) Open the traditional Studio.NET and go to File | New | New | Project item.
3) On the opened New Project wizard, find WCF Service in the Search for templates box at
to the top to find and locate our desired WFC template. The search results are shown in
Figure 9.4.
4) Make sure to select the WCF Service Application with the C# icon in front of that item,
as shown in Figure 9.4, from the Templates list we need to create our Web service
project to be hosted in IIS. Then click on the Next.
5) Enter WebSelectProject in the ProjectName and WebServiceSelection into
the name box. Enter or select C:\Chapter 9 into the Location box, which is shown in
Figure 9.5.
6) Click on the Create button to create this new Web service project.
