Now if you try to open some other tables to this deleted student, such as Login and Course tables, you can find that all records related to that student in those tables have also been deleted. These deleted records used student_id as a foreign key in those tables, and all of the deleted records are shown in Figure 9.107.

It is highly recommended to recover the deleted records from tables since we will use the same input parameter later to delete this record again when we test our Web service project. One can use Server Explorer to find and recover the deleted records by one based on data we show in Figures 9.108–9.110.

An issue when dealing with the deleted student in the Student table shown in Figure 9.110 is that it is a parent table, and we must first do the recovery and then recover other deleted data in other tables since the student_id is a primary key in the Student table.
