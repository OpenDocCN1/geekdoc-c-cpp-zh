# 2.7.3 Third Normal Form (3NF)

A table is in third normal form if it is in 2NF and every non-key column is non-transitively dependent upon the primary key. In other words, all non-key columns are mutually independent, but at the same time they are fully dependent on the primary key.

Another way of stating this is in order to ensure that 3NF should not depend upon any non-key column. If column B depends upon column A, then A is said to functionally determine column B; hence the determinant. Another definition of 3NF is that the table should be in 2NF and the only determinants are candidate keys.
