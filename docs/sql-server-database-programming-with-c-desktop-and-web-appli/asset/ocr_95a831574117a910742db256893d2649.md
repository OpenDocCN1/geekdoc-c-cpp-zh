A. Two namespaces, System.Data and System.Data.OleDb, must be added to the namespace declaration of this project we need to use OleDb data components as DataAdapter, Command and Connection.

B. A LINQ to DataSet query using the Field() method via DataRow object. This query should return a complete data row from the Faculty table.
