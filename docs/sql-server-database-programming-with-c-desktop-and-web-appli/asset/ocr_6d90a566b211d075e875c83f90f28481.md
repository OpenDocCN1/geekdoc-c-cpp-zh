# DEVELOP THE CODES TO INSERT A NEW COURSE RECORD INTO THE COURSE TABLE

To insert a new course record into the Course in our sample database via the LINK to SQL method, we need to use the Insert button's click method. The function of this is: when the user enters six pieces of new information, such as course id, course title, credit, classroom and enrollment, in the six related textboxes on this Course page with a selected faculty member, and click on the Insert button, a new record will be inserted into our database.

Double-click on the Insert button in the Design View of the Course Web page to open this window method, and enter the codes that are shown in Figure 8.79 into. Let's take a closer look at these pieces of code to see how it works.

+   A. A local variable intInsert is first generated and it will be used to hold the running result of the ExecuteCommand() method.
B. Since there is no faculty name column and the only available column is faculty_id in the Course, we need to perform two queries to perform this data insertion; first query a matched faculty_id from the faculty table by a selected faculty name, and then perform a course insertion action based on faculty_id to the Course Table. The first query starts in B, where the Lambda expression (=) is used for this LINQ query (refer to Section 4.9.1 in Chapter 4 to get more details about that expression). The query criterion in Where clause selects the faculty name from the Comboname-box and must be converted from an object to a String type. The FirstOrDefault() method is used to select the first matched faculty_id, except only one or a single faculty_id available for that query.
C. The ExecuteCommand() is called to perform this data insertion with the selected faculty_id from the above query. One point is noted to be the parameter object part;
