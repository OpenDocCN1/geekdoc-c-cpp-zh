```
private void cmddUpdate_Click(object sender, EventArgs e)
{
    byte[] img = null;
    LogInForm logForm = new LogInForm();
    img = getFacultyImage();
    Faculty fl = logForm.cse_dept.Where(f => f.facultyID_id == txtFacultyID.Text).First();
    fl.faculty_name = txtFacultyName.Text;
    fl.title = txtTitle.Text;
    fl.office = txtOffice.Text;
    fl.phone = txtPhone.Text;
    fl.college = txtCollege.Text;
    fl.image = img;
    logForm.cse_dept.SubmitChanges();
    CurrentFaculty();
    logForm.Close();
}
```

FIGURE 3.78 The LINQ selection query for the update button click method.

**C.** A LINQ selection query is executed using the Standard Query Operator (SQO) method with the faculty_id as the query first. The First() method is used to return only the first matched record. It does not matter for our application since we have only one record that is associated with this specified **faculty_id**.

**D.** All seven columns, with the exception of the faculty_id, for the selected member are updated by using the updated value in the associated TextBox to each column in the *Faculty* table in our sample database. The collected faculty image is assigned to the fimage column in the *Faculty* table.

**E.** This data updating can really occur when the SubmitChanges() method is executed.
**F.** The Faculty Name ComboBox cleaned up and the user-defined method **CurrentFaculty()** to be built in the next section is executed to refresh the updated faculty members stored in control. The LogLogIn object **logForm** is closed since we no longer need it.
