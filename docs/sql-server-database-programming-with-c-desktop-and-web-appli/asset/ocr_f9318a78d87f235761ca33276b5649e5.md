The function of this is straightforward. Two local integer variables, pos and check, are generated. The former works as a loop counter and the latter as a returned to indicate the running status of execution of this method. A for loop is used to check each TextBox to see whether any of them are empty. If anyone is empty, which means the user may have forgot to fill it, the returned variable check is increased by 1 to indicate this. Otherwise a zero is returned to indicate that this method is executed successfully.
