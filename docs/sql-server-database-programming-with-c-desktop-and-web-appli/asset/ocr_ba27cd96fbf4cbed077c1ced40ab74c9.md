# 1.5 HOW TO USE SOURCE CODES AND SAMPLE DATABASE

All source in each project developed in this book are available, and all projects are categorized into the associated chapters that are located at the folder Class DB Projects that is under the Students folder located on the CRC Press ftp site: https://9781032334776. You can copy or download these folders into your computer and run each project as you like. To successfully run projects, the following conditions must be:

+   - Visual Studio.NET 2022 or higher must be installed on your computer.
- The database management system, Microsoft SQL Server 2018 Studio 18, must be installed on your computer.
- The sample database, CSE_DEPT.mdf, must be installed on your computer in the appropriate folders.
- To run the projects in Chapters 8 and 9, in addition to the conditions listed above, an Internet Information Services (IIS), as FrontPage Extension 2000 or 2002, must be installed in your computer. This works as a pseudo server for those projects.

All related teaching and learning materials, including the sample databases, example projects, home-work solutions, faculty and student images as well as sample Windows forms and Web pages, can be found from the associated folders, Instructors or Students, located on the CRC Press ftp site, as shown in Figure 12.
