# 1.6 INSTRUCTORS' AND CUSTOMERS' SUPPORT

The teaching materials for all chapters have been extracted and represented by a sequence of Microsoft Power Point files, one for each chapter. The interested instructors can find them from the folder TeachingPPT, which is located in a sub-folder Instructors at the CRC Press ftp site (https://www.routledge.com/9781032334776) and those instructor materials are available upon request from the book’s list on site (password protected).
