
以循环方式使用。每个 redo log 文件都通过日志序列号识别，并在每次重用日志时被覆盖。换句话说，当一个 redo log 文件满时，日志写入程序将移动到下一个 redo log 文件。当第二个文件满后，第一个文件就会被重用。
