```csharp
using System;
using System.Linq;
namespace SQLWebSelect_Project
{
    public partial class Student : System.Web.UI.Page
    {
        WebLINSQL_Project.CSE_DEPTDataContext cse_dep = new WebLINSQL_Project.CSE_DEPTDataContext();
        protected void Page_Load(object sender, EventArgs e)
        {
            if (IsPostBack)
            {
                CurrentStudent();
                ComboName.SelectedIndex = 0;
            }
            void CurrentStudent()
            {
                ComboName.Items.Clear();
                var student = (from s in cse_dep.Students
                               let fields = "student_name"
                               select s);
                foreach (var s in student)
                {
                    ComboName.Items.Add(s.student_name);
                }
            }
        }
    }
}
```

**FIGURE 8.85** Initialization codes for the student web page.

- A. A new field-level object of the DataContext class, c_des, is created first since we need to use this to connect our sample database to this Web project to perform the data actions. A point is that the name WebLNSQL_Project must be prefixed to that class that is generated in project.
- B. A user-defined method, CurrentStudent(), is executed to retrieve all current students' names from our sample database and display them in ComboName combobox control to allow users to select a desired student later. To avoid multiple displaying of retrieved members, an if selection structure is adopted to make sure that we are only displaying those current students in the combbox at the first time as this Web page is loaded, and will not display them each time as the server sends back refreshed Student page to the client.
- D. Inside the user-defined method, before we can update the combobox ComboName by adding current students to name, a cleaning job is performed to avoid the multiple adding and displaying of.
- E. A LINQ query is created and initialized with three clauses, from, let and select. The range variable is selected from the Student entity in our sample database. All current students (student_name) will be read back using the let clause and assigned to the query variable student.
- F. The LINQ query is executed to pick up all queried students' names and add them to the ComboName combobox control in our Student page.
