# 2.9.2 Create the Faculty Table

Right-click on the Tables folder to select the CSE_DEPT database and select the New→Table to open the view of a new table, which is in Figure 2.29.

For this table, we have columns: faculty_id, faculty_name, title, office, college, email and fimage. The data types for the columns are: faculty_id, faculty_name and office are varchar(50), and all other data types, except for the fimage column, can be text or varchar(50), as all of them are varying variables. For the column we selected the varchar(50) as the data type for the faculty_id that is a primary key for this table, but it does not work for the text. The finished-design of the Faculty table should show one that is in Figure 2.29.

Since we selected the faculty_id column as the primary key, click on row and then go to the Toolbar and select the Primary key control.

Now go to the File menu and select the Save Table..., and enter faculty into the box for the Choose Name as the name for this table, click OK to save this. Next to you first open the table by clicking on the dbo.faculty folder under the CSE_DEPT database in the Object Explorer, and then select Edit Top 20 Rows to edit this table.
