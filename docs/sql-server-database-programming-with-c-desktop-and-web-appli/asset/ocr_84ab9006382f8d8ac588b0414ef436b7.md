To make this connection active, right-click on our sample database and Refresh it. We expand our sample database and right-click on the Stored Procedure folders, and select the Add New Stored Procedure to open a new stored procedure wizard, which is shown in Figure 5.9b.

The default name for a new stored procedure is dbo.Procedure, which is located immediately after parameter list. The top default coding lines are used to create the parameters or parameter list. Under the keyword AS is used to create the SQL statements. We create our first stored procedure, the codes shown in Figure 5.90 into this procedure @UserName is our only input parameter to this stored procedure, and this procedure will return each pieces of information related to the selected database from the input student name. Don't forget to modify the stored procedure's name to [dbo].[StudentInfo]. Click on the Update Item on the upper-left corner, as shown in Figure 5.90, to save this stored procedure. Click on the Update Database on the bottom button to finish this saving process.

If everything is fine, an Update completed successfully should be displayed. Now if you go to reopen the Server Explorer window, expand our database connection folder and the Stored Procedures folders, our new stored procedure will not be displayed. Just, right-click on the Stored Procedures folder and select the Refresh item, and you can find our new stored procedure StudentInfo is there.
