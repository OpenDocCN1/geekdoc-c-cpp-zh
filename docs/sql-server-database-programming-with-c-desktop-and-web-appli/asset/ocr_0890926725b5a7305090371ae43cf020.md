# 7.2.3 Develop Codes to Update Data Using the TableAdapter.Update Method

Open the Update Click method if it is not opened and the codes that are shown in Figure 7.7 into this method, precisely into the else block. The codes we developed in the previous section have been highlighted by the gray background color.

Let's take a look at this piece of added codes how it works.

A. In order to select a selected row from the Faculty table in the DataSet, we first need to identify that row. Visual Studio.NET provides a default method, FindBy(), to do that. But that method needs a primary key as criterion to perform a query to locate the desired row from the table. Our primary key for the faculty table is faculty_id. To that faculty_id, we can use a query function FindFacultyByName() we built in Section 5.12 in Chapter 5 with the Faculty Name as criterion. One point to point in this function is that the parameter Faculty must be an old faculty in order to update the faculty, we must first find the old row based on the faculty_name. Therefore the combobox ComboName.Text is as the old faculty name.

B. After the faculty id, the default method FindFaculty_id() is executed to locate the desired row from the faculty table, and the desired data is returned and assigned to the local variable FacultyRow.

private void cmdUpdate_Click(object sender, EventArgs e)
    CSE_DEPTDataSet.FacultyRow FacultyRow;
    string strFrameID = null;
    int intUpdate = 0;
    byte[] bimage;
    if(ComboBox.Text == "TableAdapter Update method"
        bimage = getFacultyImage();
        intUpdate = facultyTableAdapter.Update(txtName.Text, txtTitle.Text, txtOffice.Text, txtPhone.Text, txtCollege.Text, txtEmail.Text, bimage, txtFrameID.Text);
    else {
        //TableAdapter Update method selected
        strFrameID = facultyTableAdapter.FindFacultyByName(ComboName.Text);
        FacultyRow = CSE_DEPTDataSet.FindFaculty_id(strFrameID);
        FacultyRow = UPdateFacultyRow(ref FacultyRow);
        this.Value = FacultyRow;
        facultyBindingsSource.Edit();
        intUpdate = facultyTableAdapter.Update(CSE_DEPTDataSet.Faculty);
    }
    if (intUpdate == 0)
        MessageBox.Show("Faculty Updating is failed!");
    else
        CurrentFaculty();
