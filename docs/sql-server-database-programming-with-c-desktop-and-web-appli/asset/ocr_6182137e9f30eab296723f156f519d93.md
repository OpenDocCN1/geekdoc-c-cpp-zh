The database used in this sample project, which was developed in Chapter 2, is SQL Server 2019 Express database since this is compatible with SQL Server 2018 database, and more importantly, it is free and can be easily downloaded from the Microsoft Knowledge Base. You can use any kind of database, such as Microsoft Access, SQL Server or Oracle, for this sample project. The only thing you need to do is to select the desired data source when and connect that data to your project.

Let's begin to develop this sample project with five forms.

# 5.2.1.1 The Login Form

Create a new C# Windows Forms App with the name **SelectWizardProject**. Open Visual Studio 2022 and perform the following operational steps:

+   1) Launch Studio 2022 by clicking its icon on the desktop or the task bar.
2) Click on the **Continue without code** link located at the lower-right corner to open the standard Visual Studio window.
3) Go to the **File | New | Project** scroll down the bar on the right until you find your desired template, **Windows Forms App (.NET Framework)** with **C#** as the one, on the left, as shown in Figure 5.14, click it to select this. Then click on the **Continue** to next.
5) On the next window, **Configure your project**, enter **SelectWizardProject** into the **Project name** box, and **SelectWizard Solution** into the **Solution name** box, respectively, as shown in Figure 5.15. Select your desired folder as the location from the **Location** box to save this project. In our case, use that location to save the new project.
6) Click on the **Create** button to create this new project.
