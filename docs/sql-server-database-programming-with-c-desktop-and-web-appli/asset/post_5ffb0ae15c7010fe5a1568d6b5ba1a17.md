## 9.3.4 Create A Base Class to Handle Error Checking for Our Web Service

In this section we want to create a parent or base class and use it to handle some possible errors or exceptions as our project runs. It is possible for some reasons that our requests cannot be processed and returned improperly. One of the most possible reasons for that is the security issue. To report any errors or problems that occur in the processing of requests, a parent or base class is a good candidate to perform those jobs.

- **Boolean SQLOK**: If the request is true; otherwise- **String SQLLError**: A string used to report the errors.

To create a base class in our new project, right-click on our new service project **WebServiceSelect** from the Solution Explorer window, and select the **Add | New Item**. Select the Class item from the left, and enter **SQLBase.cs** as the **Name** box for the name for this class. Then click **Add** to add this class to our project.
Double-click on the newly added class and enter the codes that are shown in Figure 15. These two data work together to report possible errors during the request.
