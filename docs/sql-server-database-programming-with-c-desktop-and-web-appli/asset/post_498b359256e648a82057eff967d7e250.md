## 4.4.1 LINQ and ArrayList

When using LINQ to query non-generic IEnumerable collections as ArrayList, you must explicitly declare the type of the range variable so to reflect the specific type of the objects in the collection. For example, if you have an ArrayList of Student objects, your clause in a query should look like this:

```csharp
var query = from Student s in arrList
```

By specifying the type of the range variable with Student, you are casting each item in the ArrayList to a Student.
The use of an explicitly created range variable in a query is equivalent to calling the Cast<TResult> method. CastResult throws an exception if the specific cast cannot be performed. CastResult and OfType are the two Standard Query Operator methods discussed in Section 4.1.3 and these two methods operate on non-generic IEnumerable collections.

using System;
using System.Collections;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace NonGenericLINQ
{
    public class Student
    {
        public string StudentName { get; set; }
        public int[] Scores { get; set; }
    }
    class Program
    {
        static void Main(string[] args)
        {
            List<Student> list = new List<Student>();
            list.Add(new Student { StudentName = "Svetlana Olenchenko", Scores = new int[] { 98, 92, 81, 60 } });
            list.Add(new Student { StudentName = "Claire O'Donnell", Scores = new int[] { 75, 84, 91, 39 } });

            list.Add(new Student { StudentName = "Cesar Garcia", Scores = new int[] { 97, 98, 85, 82 } });

            var query = from student in list where student.Scores[0] > 95
                        select student;

            foreach (Student student in query)
            {
                Console.WriteLine(student.StudentName + ": " + student.Scores[0]);
            }

            // Keep the console window open in debug mode.
            Console.WriteLine("Press any key to exit...");
            Console.ReadLine();
        }
    }
}

## 4.4.2 LINQ and Strings

LINQ can be used to query and transform strings and collections of strings. It is especially useful with semi-structured data in text files. LINQ queries can be combined with traditional string functions and regular expressions. For example, you can use the Split or Split() method to create an array of strings and then can use the IsMatch() method in the where clause of a LINQ query. You can use LINQ to query or modify the MatchCollection results returned by a regular expression.
You can analyze, and modify text blocks by splitting them into a queryable array of strings by using the Split(); You can split the source text into words, sentences, pages, or other criteria, and then perform additional splits if they are required in your query. Many different types of text files consist of a series of lines, with special formatting, such as tab- or comma delimited files or fixed-length lines. After read such a file into memory, you can use LINQ to query and modify the lines. LINQ queries also simplify the task of combining data from multiple sources.
