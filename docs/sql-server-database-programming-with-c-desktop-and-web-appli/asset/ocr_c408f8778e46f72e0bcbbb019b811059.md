For your convenience, we highlight important points and general methodology of this method as well as some keywords in using this method to perform the data actions against the databases.

As you know, ADO.NET provides different classes to help users to develop professional datriven applications using the different methods to perform specific actions such as inserting data, updating and deleting data. For the data insertion, two popular methods are widely used:

+   - Add new records in the desired data table in the DataSet, and then call the DataAdapter.Update() method to add the newly added records from the Table to the DataSet in the database.
- Build the INSERT command using the Command object, and then call the command's ExecuteNonQuery() to insert new records into the database. Or you can assign the built command object to the InsertCommand property of the DataAdapter and call the ExecuteNonQuery() using the InsertCommand property.

The first method is to use the so-called DataSet-DataAdapter method to build a data-driven application. DataSet and DataTables have different roles when they are implemented in a real application. Multiple DataTables can be embedded into a DataAdapter and each table can be filled, inserted, updated and deleted using the different properties of a DataAdapter such as the SelectCommand, InsertCommand, UpdateCommand or DeleteCommand when the DataAdapter's Update() is executed.

The Adapter will perform the associated operations based on the modifications you make for each table in the DataSet. For example, if you add new rows to a table, and then you call this Update() method this will perform an InsertCommand based on your modifications. The DeleteCommand will be used if you delete rows from the table and call this Update() method is relatively simple since you do not need to call specific methods such as the ExecuteNonQuery(). This simplicity has some limitations for your applications. For instance, you cannot access different data tables individually to perform multiple data operations.
