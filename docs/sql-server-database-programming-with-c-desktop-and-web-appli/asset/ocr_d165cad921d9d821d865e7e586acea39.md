protected void cmdUpdate_Click(object sender, EventArgs e)
{
    int intUpdate;
    intUpdate = c_dept.ExecuteCommand("UPDATE Course SET course = (0), credit = (1), classroom = (2), schedule = (3), enrollment = (4) WHERE course_id = (5)", txtCourse.Text, Convert.ToToInt16(txtCourse.Text), txtClassroom.Text, txtSchedule.Text, Convert.ToToInt32(txtEnrollment.Text), txtCourseID.Text);
    if (intUpdate == 0)
    {
        Response.Write("<script>alert('The data updating is failed)</script>");
    }
    else
    {
        ClearCourse();
    }
}

FIGURE 8.81 The codes for the update button method.

Open this method by double-clicking the Update button from the Design View of the Course Web page and enter the codes that are shown in Figure 8.81 in this method. Let's take a closer look at this piece of code to see how it works.

+   A. A local variable intUpdate is created and it acts as a holder to keep the returned updating result from the execution of the ExecuteCommand() method.
B. The data updating query string is generated with a format as we discussed in Section 8.7.4.3. Each specified dynamic parameter must be enclosed with a brace ({...}) and enumerated starting from 0.
C. The running result of ExecuteCommand() method, which is an integer, is assigned to our local variable intUpdate. If this value is zero, which means that no record has been updated and that data updating action is failed. A warning message is displayed to indicate that case.
