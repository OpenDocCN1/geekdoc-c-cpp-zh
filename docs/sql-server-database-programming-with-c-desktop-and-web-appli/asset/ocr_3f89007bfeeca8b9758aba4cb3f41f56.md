# 5.19 CHAPTER SUMMARY

The discussion on this chapter is to develop professional data-driven applications in the Visual C#.NET 2022 environment using different methods. The data query is the main topic of this chapter.
The first method is to use Design Tools and Wizards provided by Visual Studio 2022 and ADO.NET to build simple, powerful data queries; the second method is to use the runtime object method to build the powerful data queries. The third method is to use procedures to integrate multiple queries into a single function or procedure to simplify the query operations and speed up the query processes. The fourth method is to use LINQ to SQL method to simplify the data query and improve the query efficiency.

Comparably, the first method is simple, and it is easy to understand and learned by those students who are beginner to Visual C and databases. Methods that utilize a lot of powerful tools and wizards provided by Visual Studio.NET and ADO.NET to simplify the coding process, and most of the codes are auto-generated by the .NET Framework 4.7 and Visual C#.NET 2022 as the user uses those tools and perform data operations such adding new data, data binding and connecting to the source data. The shortcoming of that method is that lot of coding jobs are performed by the system behind the screen, so it is a little hard to allow users to have a clear picture of what is really happening. The most codes are generated by the system automatically in the specific locations, so it is not easy to translate and execute those codes in other platforms.

The third method, the runtime objects, allows users to dynamically create all data-related objects and perform associated data operations after the run runs. Because all objects are generated by the coding process, it is very easy to translate and execute this kind of projects in other platforms. This method provides a clear view for the codes and enables users to have a global and detail picture in how to control the development of the project with the codes based on the users’ idea and feeling. The shortcoming of this method is that lot of coding jobs may make the project complicated and it is hard to be accepted by the beginners.
