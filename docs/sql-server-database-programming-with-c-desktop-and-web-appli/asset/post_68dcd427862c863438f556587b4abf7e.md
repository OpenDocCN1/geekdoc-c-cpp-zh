## 5.2.1.4 The Course Form

This form is used to access the Course table in our data source to retrieve course information associated with a specific faculty member selected by the user. Recall, in Chapter 2, we developed a sample database CSE DEPT and the Course table is one of five tables in data. A one-to-many relationship exists between the Faculty and the Course table, which is connected by using a primary key faculty_id in the Faculty table and a foreign key faculty_id in the Course table. We will use this relationship to retrieve data from the Course based on the selected faculty_id in both tables.

To create this Course Form, go to Project | Add Form (Windows Forms) menu item to add the Add New Item wizard. Select the Form (Windows Forms) from the mid-list and enter Course.cs into the Name box at the bottom. Click on the Add button to add this to our current project. Then add the following objects and controls, which are shown in Figure 5.25, into this window.

You should set the Select button, cmdSelect, as the default by choosing this button from the Acceptproperty of the Course form. You also need to set the CenterScreen as the StartPosition property of the form.

The finished Course form should match one that is shown in Figure 5.26.
In this chapter, we use the Select and Back button to make data query from the Faculty table in our data source. The other buttons will be used in the following chapters.

## 5.2.1.5 Student Form

The Student form is used to collect and display student information, including the courses taken by the student. As mentioned in Section 5.1, the Student form needs two tables in the database; one is the Student table and the other one is the Course table. This is a typical example of using two tables for graphical interface (form).

![](img/d59a47501d0a20fc0460a49c469c6fb7_223_0.png)

FIGURE 5.26 The finished course form.

To create this Student Form, go to Project | Add Form (Windows Forms) menu item to add a new window form with name Student.cs. Add the following objects and controls, which are shown in Figure 5.27, into this form.

Make sure that you set up the following properties for controls and objects in this form:

- Make the Select button the default by selecting this button from the AcceptButton property of the Student form.
- Select CenterScreen from the StartPosition property of the form.
- Set the BorderStyle property of ListBox control, CourseList, to FixedSingle.

Also the courses that the student is reflected and displayed in the ListBox control, CourseList. Your finished Student form should show what is shown in Figure 5.28. Go to the File | Save All menu item to save all forms developed and built in these sections. All of these forms are stored in the folder Students\Windows Forms. If readers want to use those forms without building them, they can add them into their project directly by going to that site and inserting them one by one following the operations in next step.

## 5.2.1.6 Using Five Windows Forms Without Building

An easy way to use those five windows forms is to add those forms into your project directly. Perform the following operations to finish this process:

1. Create your new Windows Forms App (.NET Framework) C# project.
2. Right-click on your new C# project in the Solution Explorer view, and select the Add | Existing Item item to open the Add Existing Item window.
