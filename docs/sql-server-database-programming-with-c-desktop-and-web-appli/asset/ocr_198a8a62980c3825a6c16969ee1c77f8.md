3) Conceptual Design is transformed into a logical design by creating a roadmap of how the database will look before creating the database. The data model is identified; usually, it is the relational model. Define the tables (entities) and fields (attributes). Identify primary and foreign key for each table. Define relationships between the tables.

4) Physical Design – Develop data structures; specify file organization, and storage etc etc. Take into consideration the availability of various resources, including hardware and software. This phase overlaps with the implementation phase. It involves the programming of the database taking into account the limitations of the DBMS used.

5) Implementation – Choose the DBMS that will fulfill the user needs. Implement the physical design. Perform testing. Modifying if necessary or until the database functions satisfactorily.
