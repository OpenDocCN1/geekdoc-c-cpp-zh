# 4.4.3 LINQ and File Directories

Many file system operations are essentially queries and are therefore well-suited for the LINQ approach. Note that the queries for those file system are read-only. They are not used to change the contents of the original files or folders. This rule follows that queries should not cause any side-effects. In general, any code (including queries that perform create-update-delete operators) that modifies source data be kept separate from the code that queries the data.
