# 8.7.4.3 DataContext 类及其实现

正如第 4 章所述，`DataContext` 是所有映射到数据库连接的源。它跟踪你对检索实体所做的更改，并使用相同的对象实例表示多个实体。通常，`DataContext` 设计用于持续一个工作单元；但你的应用程序定义了。`DataContext` 的创建开销很小。
