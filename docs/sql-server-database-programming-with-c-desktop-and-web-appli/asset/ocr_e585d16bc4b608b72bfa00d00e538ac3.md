# 8.9.2 Develop the Codes to Insert a Student Record into the Student Table

In this section, we discuss how to insert a new student record into the **Student** table in our sample database by calling stored procedure connect to the LINQ to SQL technique. We need to use the **Insert** button's click method to perform this data insertion. As that button, a new record stored in seven textboxes and a selected student image are inserted into the **Student** table.

Recall in Exercise 5 in Chapter 6, a stored procedure dbo.InsertStudent should be generated for that exercise. Now let's create that stored procedure if that exercise is not performed or completed.

# 8.9.2.1 Create a User-Defined Stored Procedure dbo.InsertStudent

Open Visual Studio 2022 and Server explorer, connect and open our sample database and expand the **Stored Procedures** folder. If stored procedure, dbo.InsertStudent, cannot be found, we will need to create it. Perform the following operations to generate this stored procedure:

+   1) Right-click on the **Stored Procedure** folder and select the **Add New Stored Procedure** item to open the new procedure wizard.
2) Enter the codes shown in Figure 8.89 this into the body of that stored procedure.
3) Click on the **Update** icon, as shown in Figure 8.89, to save this stored procedure into our database.
4) Then click on the **Update Database** button to complete this saving action.

The codes for this stored procedure are straightforward and easily understood. The first eight pieces of input information are generated as a new student record to be inserted into the **Student** table.
