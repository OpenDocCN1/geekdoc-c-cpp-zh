Based on the data deleting sequence (1–4) listed in the last section, in order to delete a record from the Faculty table, one needs to perform four deleting operations in that sequence. Compared with those four deleting operations, the first one is the most difficult and for the reason for that:

To perform the first deleting operation, one must first find course_id that use the faculty_id as the foreign key from the Course table, and based on those course_id, one needs to delete all records that use those course_ids as the foreign keys of the StudentCourse table. To delete operations in sequences 3 and 4, they are very easy and each deleting operation needs only one querying. The conclusion for this discussion is: how can we find an easy way to complete the operation in sequence?

A odd solution to this is to use the Cascade option, as we did in Chapter 2, to perform the data deleting in a cascaded mode. This Cascade option allows the SQL Server database to perform deleting in sequence 1 as a Cascade is selected for relationships 4 and 5 listed above.

Now let's use a real example to illustrate how to use this Cascade option to simplify the data deleting operations, especially for the first deleting in sequence.
Perform the following operations in SQL Server Management Studio 18:

+   ) Go to Start | All Programs | Microsoft SQL Server Tools 18 | SQL Server Management Studio 18.
) On the Opened window, select the SQL Server Authentication mode to finish the login process by entering SMART and Hot2022 using username and password, and click on the Connect button to connect to our database.
) Expand the Databases folder, our sample database CSE DEPT, and the Tables folder to expand all five tables. Since we have interest on relationships 4 and 5, so just expand the dbo.StudentCourse table and the Keys folder to find all Keys we established in Section 2.9.4 in Chapter 2. Double click the key FK_StudentCourse_Course to open it, which is shown in Figure 8.47.

On the opened Foreign Key Relationships window, keep our desired key FK_StudentCourse_Course selected on the left pane, and then click the small icon before the item INSERT AND UPDATE Specification and you can find that a Cascade mode has been set for both Delete Rule and Update Rule items, which is shown in Figure 8.47.
