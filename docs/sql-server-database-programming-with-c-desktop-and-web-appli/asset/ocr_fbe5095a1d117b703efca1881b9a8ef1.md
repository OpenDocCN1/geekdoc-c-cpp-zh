```
private void CurrentFaculty()
{
    SqlDataReader sqlReader;
    SqlConnection conn = loginForm.SqlConnection;
    SqlCommand sqlCommand = new SqlCommand("SELECT faculty_name FROM Faculty", conn);
    sqlReader = sqlCommand.ExecuteReader();
    ComboBoxName.Items.Clear();
    while (sqlReader.Read())
{
        ComboBoxName.Items.Add(sqlReader["faculty_name"]);
    }
    ComboBoxName.SelectedIndex = 0;
    sqlReader.Close();
}
```

**FIGURE 6.31** The codes for the method CurrentFaculty().

+   - Before we retrieve all faculty names and add them into the combobox, **ComboBoxName**, we need to clean up that combobox to make it ready.
- A **while** loop is used with the **SqlReader.Read()** as its condition to scan and read out all faculty names by one, and add each of them into the combobox, **ComboBoxName**. An issue is that one can use the column name or the column index for the **SqlReader** object to get each faculty name.
- By setting the **SelectedIndex** property to, the first added faculty name can be selected as the default and one displayed in the top of the combobox.
- Finally the **SqlReader** is closed by using the **Close()** method.
