Performing the following operations to create our stored procedure dbo.UpdateFactorySP:

+   1. Expand our connected database and right-click on the Stored Procedures folder.
2. Select the Add New Stored Procedure item to open the Add Procedure window.
3. Enter the codes that are shown in Figure 7.33 into this new procedure.
4. Do not forget to change the procedure's name to dbo.UpdateFactorySP that is located at the top of this procedure.

Refer Section 2.9.2 in for the data types of these input parameters, and the data types of those input parameters should be identical with data types of the associated columns in the **Factory** table.
The functionality of this stored procedure is:

+   A. All input updated parameters are listed in this part. All those parameters' names must be identical with those in the user-defined method `UpdateParameters()` shown in Figure 7.31 in the last section.
B. The **Update** query is generated by assigning all parameters to the associated columns in the **Factory** table. The dynamic parameter @id is assigned to the WHERE clause as the updating condition or criterion.
C. If the updating query is executed successfully, a result is returned to indicate that case.

Click on the **Update** icon located at the upper-left corner, as shown in Figure 7.33, to save this stored procedure into our database. On an opened **Preview Database** updates, click on the **Update Database** button, a success updating message should be displayed in the **Data Operations** wizard located at the bottom.
