```
private void FillStudentReader(SqlDataReader StudentReader)
{
    int index;
    TextBox[] sTextBox = (TextBox[])txtID, txtStudentName, txtGPA, txtCredits, txtMajor, txtSchoolYear, txtEmail);
    while (StudentReader.Read())
    {
        for (index = 0; index <= StudentReader.FieldCount - 2; index++)
            sTextBox[index].Text = (string)StudentReader.GetValue(index).ToString();
        byte[] bimage = (byte[])StudentReader.GetValue("image");
        PictureBox.Image = Image.FromStream(new System.IO.MemoryStream(bimage));
    }
}
private void FillCourseReader(SqlDataReader StudentReader)
{
    int pos;
    CourseList.Items.Clear();
    while (StudentReader.Read())
    {
        for (pos = 0; pos <= StudentReader.FieldCount - 1; pos++)
            CourseList.Items.Add(StudentReader.GetValue(pos).ToString());
    }
}
```

**Figure 5.99** The codes for two user defined methods.

+   B. A **while** loop is then utilized to repeatedly pick each column queried from the **Student** table as the **Read()** method of the DataReader is, which means that a valid data column has been retrieved.
C. Inside the **while** loop, a **for** loop is used to conditionally pick the first seven columns (0–6), in which several pieces of matched information is involved, and assign them to TextBoxes in the Student Form via **sTextBox[]** array. Two points to be noted: 1) The upper bound of this **for** loop is **FieldCount – 2**, which is **8 – 2 = 6**, since the column count is 8 and the column number starts from 0, not 1. 2) To pick up each column, the system method **GetValue()** is used instead of **GetString()** to get columns, **gpa** and **credits** in the Student table are typed with Double and **int32**. Also a forced conversion, **ToString()**, is used to convert columns to String.
D. For the last column, which is a matched item, a forced conversion (**byte[])** is used to convert that object to byte type. Furthermore, it is used to convert an image and assign to the **Image** property of the Student box, **PhotoBox**, in the Student Form to be displayed.
E. The function of the method **FillCourseReader** is to pick up each matched row (**course_id**) from the filled Student table and add it to the CourseList listBox. First, a local variable **pos** is generated and it is used as a loop counter for **for** loop to pick up each matched row (**course_id**).
F. Prior to doing this action, the CourseList box is cleaned up.
G. A **while** loop is then utilized to repeatedly pick each row queried from the **StudentCourse** table as the **Read()** method of the DataReader is, which means that a valid data row has been retrieved.
H. Inside that **while** loop, a **for** loop is used to conditionally pick all matched rows (**course_id**) and add them to the CourseList box in the Student Form to display them.
