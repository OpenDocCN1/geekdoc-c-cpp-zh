Let's first discuss updating against the **Course** table for the SQL database. To update data against the Course data table, we do not need to add any new Forms and we will use the Course Form window as our interface. We need to perform the following steps to complete this data updating action:

+   1) Develop codes to update the course record.
2) Validate the data updating result.

First let us develop the codes for our data updating action.

# 7.4.3.1 Develop Codes to Update the Course Record
