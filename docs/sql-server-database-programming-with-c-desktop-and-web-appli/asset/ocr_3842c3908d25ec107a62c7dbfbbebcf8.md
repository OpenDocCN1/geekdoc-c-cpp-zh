# 1.2 WHO THIS IS FOR

This book is designed for students and software programmers who want to develop practical and commercial database programming with C# or Visual C#.NET and relational databases such as Microsoft SQL Server 2019. A foundational knowledge and understanding of C# and Visual Studio. NET IDE is assumed.

# 1.3 WHAT THIS BOOK COVERS

Nine chapters are included in this book. The contents of each chapter can be summarized as follows:

+   * Chapter 1 provides an introduction and summary of the whole book.
* Chapter 2 provides a detailed description and analysis of the structure and components about relational databases. Some key technologies in developing and designing databases are also given and discussed.
