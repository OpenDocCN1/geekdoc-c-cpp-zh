One point you need to note is that you can copy the content of the whole table from the Microsoft Word tables (Figures 2.3–2.4) to the associated data table in the Microsoft SQL environment. To make these copies and pastes, you must first select all rows from your Microsoft Word tables by highlighting them, and choose the **Copy** menu item. Next you must select a whole blank row from your destination table in the Microsoft SQL Server 2019 database, and paste copied rows by clicking on that row and then click the **Paste** item from the **Edit** menu item.
