| A | [WebMethod] public DataSet GetSQLSelectDataSet(string FacultyName)
{
SqlConnection sqlConnection = new SqlConnection();
SQLResult sqlResult = new SQLSelectResult();
SqlCommand command = new SqlCommand();
SqlDataAdapter facultyAdapter = new SqlDataAdapter();
DataSet dsFaculty = new DataSet();
int intResult;
string cmdString = "SELECT faculty_id, title, office, phone, college, fimage FROM Faculty " +
WHERE faculty_name = @facultyName";
SQLResult.SQLRequestError = true;
if (sqlConnection == null)
{
SQLResult.SQLRequestError = "Database connection is failed";
ReportError(sqlResult);
return null;
}
command.Connection = sqlConnection;
command.CommandType = CommandType.Text;
command.CommandText = cmdString;
command.Parameters.Add("@facultyName", SqlDbType.NVarChar).Value = FacultyName;
facultyAdapter.Command = command;
intResult = facultyAdapter.Fill(dsFaculty, "Faculty");
if (intResult == 0)
{
SQLResult.SQLRequestError = "No matched faculty found";
ReportError(sqlResult);
}
sqlConnection.Close();
command.Dispose();
facultyAdapter.Dispose();
return dsFaculty;
}

FIGURE 9.29 The modified method – GetSQLSelectDataSet().

**D.** The Fill method of the DataAdapter is executed to fill the Faculty table in our DataSet. This method will return an integer value stored in the local integer intResult indicating whether it is successful or not
**E.** If the returned value is zero, which means that no row has been retrieved from the Faculty table in our database and no row has been filled into the Faculty table in our DataSet dsFaculty. Therefore that data query is failed. An error message will be sent to our member data in this base class and that will be reported using the ReportError() method.
**F.** Otherwise, if the returned value is non-zero, way that at least one row has been retrieved and filled into the Faculty table in our DataSet, a cleaning job is performed to release all objects used for this Web method. Typically this returned value is equal to the number of rows that have been successfully retrieved from the Faculty table in our database and filled into our DataSet. In our application, this value should be equal to one since once only one record is returned from our sample database and filled into the Dataset.
**G.** Finally, the returned DataSet dsFaculty, exactly the Faculty table in this Dataset, is returned from the Web service.
