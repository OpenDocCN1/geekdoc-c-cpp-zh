To answer this question, we need to review the data source in the database. As you know, in our sampling database CSE_DEPT (exactly in our faculty data, it identifies a record on its primary key). In words, only those records with different primary keys can be considered as different records. So the solution to our question is: if the content of the TextBox that stores the primary key, in our case it is the txtfacityID who stores the faculty_id, is changed, then a new record will be inserted, and as this happened, the txtfacityID’s TextChanged method should be triggered to enable the Insert button.
