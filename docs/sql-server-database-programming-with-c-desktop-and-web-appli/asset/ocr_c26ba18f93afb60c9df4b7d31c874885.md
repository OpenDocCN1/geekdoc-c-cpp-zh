# 5.2.1.6 Using Five Windows Forms without Building Them

An easy way to use those five windows forms is to add those forms into your project directly. Perform the following operations to finish this process:

+   1) Create your new Windows Forms App (.NET Framework) C# project.
2) Right-click on your new C# project in the Solution Explorer view, and select the **Add | Existing Item** item to open the **Add Existing Item** window.
