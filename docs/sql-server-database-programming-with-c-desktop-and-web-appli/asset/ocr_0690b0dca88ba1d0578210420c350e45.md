# SQL Server Database Programming with C#

Four folders are created and added into the Solution Explorer window for this new project, they are (Figure 5.16):

+   * Properties: Contains all properties of the selected objects.
* References: Contains all namespaces of the system classes, methods and events.
* Form1.cs: Contains all files of the graphical user interface and resources. It is also called Form Object.
* C# Program.cs: Contains the entry point of the project.

Perform the following modifications to this form to make it project:

+   1) Change the name of the current Form File from Form1.cs to Login.cs by right-clicking on the Form1.cs folder from Solution Explorer window and select the Rename item from the popup menu, and change it typing Login (do not touch .cs) to that folder. Then click on the Window Form object to exit this naming.
A Message will be displayed when you do this name changing. Click on the Yes button to keep all related references to this object are also changed. The finished name changing of this object is shown in Figure 5.17.
2) Change the Window Form's object name from Login to Login by first clicking on the Window object, then go to the Name property on the Properties window, make sure that the A-Z button is selected, as shown in Figure 5.18, and change the Name by typing in the Name box.
3) Change the Text property of this Form window to CSE DEPT Login by going to Text property in the Properties window, and type this new into the Text box.

When you perform the 3) above, you may find that the Window Form object has already been renamed to Login. Yes, that is the second of change you made. In order distinguish this Window Form object with the Form File object Login.cs, we prefer to add After after the Login for the Window Form object to make its name as LoginForm.
Now add the following controls shown in Figure 5.19 into the LoginForm window.
