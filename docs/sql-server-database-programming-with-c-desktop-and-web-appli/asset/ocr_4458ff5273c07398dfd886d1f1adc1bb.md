Click the **DataSet** from the Template list and enter **CSE_DEPTDataSet.xsd** in the *Name* box as the name for this DataSet. Click on the **Add** button to add this DataSet to your project. Your finished Add New Item wizard should match one that is shown in Figure 4.37.

Next we need to select our data source for our new DataSet. Open the Server Explorer window and click on the arrow on the left of our Database Connection item if it has not been connected to it. Expand the **Tables** folder under that source, you can find all five tables, which is shown in Figure 4.38.

Open the DataSet by double-clicking the **CSE_DEPTDataSet.xsd** from the Solution Explorer window if it is not opened. Drag the **Facty** and the **Course** tables from the Server Explorer window and place them on the DataSet Designer. You can drag-place all tables if you like, but we only need to drag two of them. Except we only need to use the **Faculty** table in your project.

Now we have finished creating our typed DataSet and the connection to our data source. Next we need to perform the coding process to LINQ to DataSet to perform the query to this typed DataSet.

Before we develop and create our codes, we need to first add the **System.Data.SqlClient** package to our project to use it since we are using our sample database **CSE_DEPT**, which is built with Microsoft SQL Server 2019 Express, as the data source in this project. Perform the following operations to add this package to our project:

+   1. Go to the menu **Tools** | **NuGet Package Manager** | **Package Manager Console**.
2. In the Package Manager Console window at the bottom, type the command: `Install-Package System.Data.SqlClient` and press the **Enter** key on your keyboard.
3. Some Successful Installation messages are displayed on console window when it is done, which means the package has been successfully installed and added into our project, and we can use it.

Now double-click on the **C# Program.cs** from the Solution Explorer to open the code window of that file. Enter the codes that are shown in Figure 4.39 into this code window.
