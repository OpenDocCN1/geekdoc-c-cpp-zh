
## Introduction to ADO.NET

In the following sections, we will discuss the Entity Data Model and how to use these Entity Data Tools to create, build and develop the Entity Data Model and implement it in your actual data-driven applications.

First, let's take a closer look at the ADO.NET 3.5 Entity Data Model.

## 3.4.8.1 ADO.NET 3.5 Entity Data Model

ADO.NET 3.5 Entity Data Model (EDM) is a data model for defining application data as sets of entities and relationships with common runtime CLR type and storage structures that can be mapped. This enables developers to create data accesses by programming against a conceptual model instead of programming directly against a relational storage schema. The following tools are deigned to help you work with the EDM:

- The ADO.NET 3.5 Entity Data Model item is available for Visual C# project type, and ASP.NET Web Site and Web Application projects, launches the Entity Data Model Wizard.
- The Entity Data Model Wizard generates the EDM, which is encapsulated in an .edmx file. The wizard also adds a connection string to the App.Config or Web.Config file and configures a single-file generator to the conceptual model in the .edmx file. This single-file generator generates C# or VB code from the conceptual model defined in the .edmx file.
- The ADO.NET Data Model Designer provides visual tools to view and edit the EDM graphically. You can open an .edmx file to design and create entities and map entities to tables and columns.
- EdGen is a command-tool that can be used to also generate models, validate existing models, and perform other functions on your EDM metadata.

In the following sections we will provide a detailed discussion for each of these tools.

### 3.4.8.1.1 Entity Data Model Item Template

ADO.NET 3.5 Entity Data Model item template is the starting point for the Entity Data Model tools. The ADO.NET 3.5 Entity Data Model template is available for Visual C# and Visual Basic project types. It can be added to Console Application, Windows Application, Class Library, ASP.NET Web Service Application, ASP.NET Web Application, or ASP.NET Web Sites. You can add ADO.NET 3.5 Entity Data Model items to the project, with each item containing files that were generated from a different database and/or tables within the same.

When you add the ADO.NET 3.5 Entity Data Model item template to your project, Visual Studio:

- Adds references to the System.Data, System.Entity, System.Core, System.Security, and System.Runtime.Serialization assemblies if the project does not have them.
- Starts the Entity Data Model Wizard. The wizard is used to generate an Entity Data Model (EDM) from an existing database. The wizard creates an .edmx file, which contains the model information. You can use the .edmx file in the ADO.NET Entity Data Designer to view or modify the model.
- Creates a source code file that contains the classes generated from the conceptual model. The source code file is auto-generated, is updated when the .edmx file changes, and is compiled as part of the project.

Next let us consider the Entity Data Model Wizard.

### 3.4.8.1.2 Entity Data Model Wizard

The Data Model Wizard starts after you add an ADO.NET 3.5 Entity Data Model to your project. The wizard is used to generate an Entity Data Model (EDM). An .edmx file contains the model information. The ADO.NET 3.5 Entity Data Model Designer enables you to view and edit the mappings graphically.

You can select to create an empty model or generate the model from an existing database. Generating the model from an existing database is the recommended practice for this release of the EDM model.

The wizard also creates a source code file that contains the classes generated from the CSDL information encapsulated in the .edmx file. This code is auto-generated and updated when the .edmx file changes.

Depending on your selections, the wizard will help you with the following steps:

- Choosing the Model Contents: It is recommended that you select to generate the model from an existing database. The Wizard takes you step by step through the selection of the data source, database, and database objects to include in the EDM.
- Choosing the Database Connection: You can choose an existing connection from the list of connections or click New Database Connection to open the Connection Properties dialog box and create a new connection to the database.
- Choosing your Data Objects: You can select the tables, views, and stored procedures to include in the EDM.

Now let's consider the real part – ADO.NET 3.5 Entity Data Model Designer.

### 3.4.8.1.3 Entity Data Model Designer

The ADO.NET 3.5 Entity Data Model provides visual tools for the creation and editing of an Entity Data Model (EDM).
The ADO.NET Entity Data Model Designer includes the following components:

- A visual design surface for creating and editing the conceptual model. You can create, modify, or edit entities and associations.
- An Mapping Details window to view and edit mappings. You can map entity types or associations to database tables and browsers.
- An Entity Model Browser gives you a tree of the EDM.
- Toolbox controls to create entities, associations and inheritance relationships.

The ADO.NET 3.5 Entity Data Model Designer is integrated with the Visual Studio.NET 2008 components. You can view and edit information using the Properties window and errors are reported in the Error List.

## 3.4.8.2 Using the ADO.NET 3.5 Entity Data Model Wizard

In this section, we will use a project to illustrate how to use the Entity Data Wizard to connect to our database, create entity classes, to setup associations between entities and mapping relationships between entities and tables. Creating applications using the Entity Data Model (EDM) can be significantly simplified by using the Entity Data Model template and Entity Model Wizard. This section guides you through the following tasks:

- Create a new C# Windows-based application.
- Use the Entity Model Wizard to select a data source and generate an EDM from the CSE_DEPT database.
- Use the entities in this application.
- Create a new C# Windows-based project EDModel.

### 3.4.8.2.1 Create a new C# Windows-Based Project

Perform the following operational steps to create this project:

1) Open Visual Studio.NET 2022 and select **File | New | Project** items to open the new project wizard.
2) Select the **C#** as the project type and **Windows Forms App (.NET Framework)** as the Template for this project. Click on the **Next**.
3) Enter **EDModel** into the Project name box, and **EDM Solution** to the Solution name box. Select any folder in your machine as the **Location** to save this project (as shown in Figure 3.43). Then click on the **Create** button to create this project with a new solution.
4) Change the Text property of the Form to **Entity Data Model**.
5) Go to the Properties window and change the **StartPosition** property of the Form window to **CenterScreen**.
6) Add a Button control to the Form window and set its **Name** property to **cmdShow** and its **Text** property to **Show Faculty**. Set its **Style** to **Bold** and Size to 10.
