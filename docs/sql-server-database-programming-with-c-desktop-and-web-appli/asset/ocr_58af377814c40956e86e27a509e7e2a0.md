# 3.4.3.6 The Methods of the Command Class

In the last section, we discussed how to create an instance of the Command class and how to initialize the Parameters collection of a Command object by attaching Parameter to that Command. These steps are prerequisite to execute a Command. The actual execution of a Command object is to run one of the methods of the Command Class to perform the data queries or data actions. Four popular methods are widely used for data-driven applications and Figure 3.15 lists these methods.

As mentioned in the last section, the Command object is a Data Provider-dependent object, so four different versions of the Command object are developed and each version is determined by the Data Provider the user selected and in the application, such as the OleDbSqlCommand, SqlCommandSqlCommand an OracleCommand. Although each is dependent on the Data Provider, all methods of the Command object are similar in functionality and have the same roles in a data-driven application.

# 3.4.3.1 The ExecuteReader Method

The ExecuteReader() is a query method and it can be used to execute a read-out operation from a database. The most popular matched operation is to execute a SQL SELECT statement to return rows to a DataReader using this method. Depending on which Data Provider you are using, the different DataReader should be utilized as the receiver to hold the returned rows. Remember, the DataReader class is a read-only class and it can be used as a data holder. You cannot perform any data updating using the DataReader.
