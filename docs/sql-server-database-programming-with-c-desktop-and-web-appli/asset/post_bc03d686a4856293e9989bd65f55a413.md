# 8.3 WHAT IS ASP.NET AND ASP.NET 4.8?

ASP.NET is a programming framework built on the .NET Framework and is used to build Web applications. Developing ASP.NET Web applications in the .NET Framework is very similar to developing Windows-based applications. ASP.NET Web application is composed of many different parts and components, but the fundamental component of ASP.NET is the .NET Web Form. A Web Form is the page that users view in a browser and an ASP.NET Web application can contain one or more Forms.

The current version of ASP.NET is 4.8, which is combined with .NET Framework 4.8 to provide a professional and convenient way to help users build and develop a variety of data-driven applications in .NET programming languages. With the progression from ASP.NET 2.0, the features in ASP.NET 4.8 are additive, which means that the assemblies installed from the .NET Framework are still used by the 4.8 versions. In short, ASP.NET 4.8 does not change, take away or break any functionality, concepts, or code present in 2.0, but it simply adds new types of features and capabilities to the framework. Therefore, ASP.NET 4.8 is a minor upgrade from ASP.NET 2.0; that is, there are comparatively few new ASP.NET-specific features in the .NET Framework 4.8.

- Caching. Caching allows the application to store data to improve performance.

### 8.3.1 ASP.NET WEB STRUCTURE

When you run an ASP.NET application, the following folders are created:

- inputroot. The inputroot folder contains the root of the application.
- bin. The bin folder contains the compiled assemblies and DLL files.
- App_Data. The App_Data folder is used to store data files.
- App_Code. The App_Code folder contains source code that is automatically compiled.
- Content. The Content folder contains static files like images, CSS, and JavaScript.

### 8.3.2 ASP.NET EXECUTION MODEL

The following diagram describes the execution model of the ASP.NET Framework:

- Assembly files (.dll). All project is compiled into a single assembly file.
- AssemblyInfo.cs. This file is used to write general information, especially version and attributes, about the assembly.
- Global.asax. Global.asax file is used to handle application-level events.
- Configuration. Configuration files define the settings for the application.
- Caching. Caching allows the application to store data to improve performance.

When the client requests a Web page for the first time, the following events occur:

- The client browser gets a GET request to the server.
- The ASP.NET parser interprets the source code.
- Based on the interpreting result, ASP.NET will direct the request to the associated assembly file (.dll) if the code has compiled into the dll file. Otherwise, ASP.NET invokes the compiler to convert the code into dll format.
- Runtime loads and executes the Microsoft Intermediate Language (MSIL) codes and sends back the required Web page to the client.

For the second time when the user requests the Web page, no compiling process is needed, ASP.NET can directly call the dll file and execute the MSIL code.

### 8.3.3 WHAT HAPPENS WHEN A WEB APPLICATION IS EXECUTED?

The key point is that a Web Form is built and run on the server. When the user sends a request from the user's client browser to request that Web page, the server needs to build that form and send it back to the user's browser in the HTML format. Once the Web page is received by the client's browser, the connection between the client and the server is terminated.
