# 7.7 CHAPTER SUMMARY

Data updating and deleting queries are discussed in this chapter with a sample SQL Server database CSE_DET.

Four popular data updating and deleting methods are discussed and analyzed with real projects examples:

+   1) Using TableAdapter methods such as TableAdapter.Update() and TableAdapter.Delete() to update and delete data directly against the database.
2) Using TableAdapter.Update() method to update and execute the associated TableAdapter's properties as UpdateCommand or DeleteCommand to save changes for the table in the DataSet to the database.
3) Using the run time object to develop and execute the Command'method ExecuteNonQuery() to update or delete data again against the database.
4) Using LINQ to SQL query method to update and delete data against our sample Server database CSE_DET.

Both methods 1 and 2 need to use Visual.NET Design Tools and Wizards to create configurable adapters, build the associated queries using the Query Builder and call those queries from C#.NET applications.

The difference between methods 1 and 2 is that method 1 can be used to directly access the database to perform the task in a single step, whereas method 2 needs steps to finish the data updating or deleting. First, the data updating or deleting are performed to the associated tables in the DataSet, and then updated or deleted are updated to the tables in the database using the TableAdapter.Update() method.

This chapter is divided into two parts: Part I provides discussions on data updating and deleting using methods 1 and 2, or in other ways, using the TableAdapter.Update() and TableAdapter.Delete() methods developed in Visual.NET Design Tools and Wizards. Part II presents the data updating and deleting using the time object to develop command objects to execute the ExecuteNonQuery() method dynamically. Updating and deleting against our sample database using the stored procedure method and LINQ to SQL query method are also discussed in the second part.
