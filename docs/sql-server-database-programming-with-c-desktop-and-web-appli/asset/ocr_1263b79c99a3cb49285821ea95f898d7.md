# 9.4.3.2 Develop the Graphic User Interface for the Client Project

Perform the following modifications to our new client project:

+   1) Rename the Form Object from the default name Form1.cs to our desired name WinClient Form.cs.
2) Rename the Window Form object from the default name Form1 to our desired name CourseForm by modifying the Name property of the window form.
3) Rename the form from the default title Form1 to CSE_DEPT Course Form by modifying the Text property of the form.
4) Change the StartPosition property of the form window to CenterScreen.

To save time and space, we can use the Course form located in the project RTOUpdateDelete Project we developed in Chapter 7 as our graphic user interface. You can find this project from the folder ClassDB Projects\Chapter7\RTOUpdateDelete Solution is under the Students folder on the CRC ftp site to refer (Figure 1.2 in Chapter 1). Perform the following operations to add this Course into our new client project:

+   1) Open the project RTOUpdateDelete Project and the Course form window from the CRC ftp site.
2) Select all controls from that form by going to the item Edit | Select All and go to Edit | Copy menu item to copy all controls selected from this form window.
3) Return to our Windows-based client WinClientInsert Project, open our form window CourseForm and paste those controls we copied from step 2 into this form.
