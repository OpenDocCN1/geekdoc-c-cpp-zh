+   - Connection = loginForm.SqlConnection

The content of the CommandText must be equal the name of the stored procedure developed in the last step.

H. The unique input parameter to the stored procedure dbo.StudentCourseInfo is the StudentID, which is obtained from the first stored procedure and stored in the student ID textboxStudentID. This dynamic parameter must be added into the Parameters collection which is the property of the Class using the Add() method before the stored procedure can be executed. The initialized Command object cmdStudentCourse is then assigned to the SelectCommand property of another DataAdapter to make it ready in the next step.

I. The Fill method of the DataAdapter is called to fill the Course table, which is exactly to call our second stored procedure to fill the Student table.

J. If this is successful, the Count property should be greater than 0, which means that at least one row is filled into the Student table, and the user-defined method FillList() is called to fill the CourseList box in the Form with all courses (course_id) retrieved from the stored procedure. Otherwise, an error message is displayed if that operation is failed.

K. The Used object cmdStudentCourse is removed using the Dispose() method since we do not need it anymore.

L. If the user selects the DataReader Method, first we need to create two local objects, a Command object cmdStudentCourse_dr and a DataReader object cmdStudentReader. The former as an independent Command object to perform a query to the Student table via our second stored procedure to get all course_id by the selected student, and the later as a DataReader to get all retrieved course_id.
