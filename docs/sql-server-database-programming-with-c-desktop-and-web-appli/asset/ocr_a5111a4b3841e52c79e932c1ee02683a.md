We do not need to create any new Web application project to perform any query from the Student table; instead we can modify one of our previous Web application projects, WebLNSQL Project, to make it our new project WebSP_Student Project. Perform the following operations to complete this modification and for our new Web application project:

+   1. Open the Windows Explorer or File Explorer and locate the Web application solution WebLNSQL Solution in your local machine (C:\Chapter 8).
2. Right-click on that solution and select the Copy item to copy that solution with the project, and paste that folder under the same location in your machine, such as C:\Chapter 8.
3. Rename both folders to WebSP_Student Solution and WebSP_Student Project, respectively.
4. Expand the new solution folder WebSP_Student Solution and click on the new project folder WebSP_Student Project to open it in the File Explorer.
5. Change the following two names, WebLNSQL Project.csproj and WebLNSQL Project.csproj.user, to csproj, WebSP_Student Project.csproj and WebSP_Student Project.csproj.user.
6. Now double-click on the new project WebSP_Student Project.csproj to open it in the Visual Studio 2022.

A key point to be noted is that we changed the solution and projects' names, but the namespace is kept with no change because it would be a very complicated process if we changed the namespace from SQLSelect_Project to WebSP_Student_Project.
