The important difference between WCF and ASMX is that the WCF service will not do anything until you specify precisely how it is exposed to the outside world. An ASMX service will happily start talking to the world once you place the *.asmx file into an IIS directory. A WCF service will not talk to you until you tell it to do so, and how to do so.

# 9.2.3.6 WCF Visual Studio Templates

Visual Studio provides a set of WCF templates to help developers to build Web services and applications. In fact, WCF Studio templates are predefined and project items you can use in Visual Studio to quickly build WCF services and surrounding applications.
WCF Studio templates provide a basic class structure for service development. Specifically, these templates provide the basic definitions for service contract, data contract, service implementation, and configuration. You can use these templates to create a simple service with minimal code interaction, and well as a building block for more advanced services.
Two of the most popular templates are WCF Service Application template and WCF Service Library template.

When you create new Visual C# project using the WCF Web ServiceApplication template, the project includes the three major features:

+   1) Contract file (IService1.cs): The contract service is an interface that has WCF service attributes. This file provides a definition of a simple service to show you how to define your services, and includes parameter-based operations and a simple data contract sample. The default file is displayed in the code editor after creating a WCF service template.
2) Services file (Service1.svc): This file is an implementation for the class IService1 interface, and it implements the contract defined in the service contract.
3) Configuration file (Web.config): The configuration file provides the basic elements of a WCF service model with a secure HTTP binding. It also includes an endpoint for the service and metadata exchange.

The template automatically creates a Web Site that will be deployed to a virtual directory and hosts a service in it.
