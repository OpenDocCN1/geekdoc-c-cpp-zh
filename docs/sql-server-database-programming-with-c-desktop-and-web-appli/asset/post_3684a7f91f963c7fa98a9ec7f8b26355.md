# #7 Data Updating and Deleting with Visual C#.NET

In this chapter, we will discuss how to update and delete data against the databases. In general, many different methods are provided and supported by Visual C#.NET and .NET Framework to help users perform the data updating and deleting against the database. Among them, three popular methods are widely implemented:

- 1. Using TableAdapter DBD methods such as `TableAdapter.Update()` to update and delete data against the database.
- 2. Using `TableAdapter.Update()` and `TableAdapter.Delete()` to change the table in the DataSet to the database using associated properties like `SqlCommand` and `DeleteCommand`.
- 3. Using the run time method `NonQuery()` to directly update or delete data dynamically.

Methods 1 and 2 use Visual Studio Design Tools and Wizards to create TableAdapters, the associated queries using Query Builder, and call those queries from Visual#.NET. The difference between methods 1 and 2 is that method 1 can be used to directly access the database to perform the data updating and deleting in a single step, whereas method 2 uses two steps: first, the data updating or deleting are performed on the associated tables in the DataSet, and then updated or deleted data are updated to the database by executing the `TableAdapter.Update()` method.
