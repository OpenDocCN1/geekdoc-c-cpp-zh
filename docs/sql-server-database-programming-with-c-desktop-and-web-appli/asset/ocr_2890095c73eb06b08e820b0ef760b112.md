Let's have a look at the codes in this method to see how they work.

+   A. A DataObject is declared at the beginning of this method since we need to use it to perform the data extraction from the returned instance and the data addition to the list box control.

+   B. The list box CourseList is cleaned up before messy displaying of multiple course_id.

+   C. The TableObject is initialized by adding a new data table Course and is attached to the DataSet obj.

+   D. A foreach() is used to continuously pick up the first column that is the course_id from all returned rows, and add each of them to the list box control. One point to be noticed that the first column has an index value of 0, not 1 since the index starts from 0.

private void FillCourseDataSet(ref DataSet ds)
{
    DataTable CourseTable = new DataTable();
    CourseList.Items.Clear(); //clear up the listbox
    CourseTable = ds.Tables["Course"];
    foreach (DataRow CourseRow in CourseTable.Rows)
    {
        //the 1st column is course_id
        CourseList.Items.Add(CourseRow[0].ToString());
    }
}
