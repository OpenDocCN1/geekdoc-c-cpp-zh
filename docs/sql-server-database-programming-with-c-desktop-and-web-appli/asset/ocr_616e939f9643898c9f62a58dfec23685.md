**5.120** The codes for the constructor of the FacultyForm.

Let's have a closer look at this instance of code to be created and how it works.

+   An instance of the LogInfo class, **logform**, is created and the purpose of generating this instance is that we can use the global connection object **CSE_DEPTDataContext** we created in this class.

+   If we select the first method, **LINQ to SQL Method**, a standard LINQ query is adopted with an implicit typed variable **f** with data type. The Visual C# 2022 can automatically convert this **var** to any data type, in case it is a collection-table. An iteration variable **f** is used to iterate over the result of the query from the **Faculty** table. Then an SQL **SELECT** statement is executed with the **WHERE** clause.

+   The type of the queried faculty image via LINQ to SQL is **System.Data.Linq.Binary**. By assign this image to the faculty image control, **PhotoBox**, in this Faculty Form to display it, we need to convert it to the **System.Drawing.Image** in two steps: 1) convert that to a **byte[]** array, and 2) convert binary to the desired type, **System.Drawing.Image**. Here an intermediate variable **img** and an **as** operator are used. The latter works as an indicator to the data type of **f.image**.
