# 5.10 BIND DATA COLUMN TO THE ASSOCIATED CONTROLS IN FACULTY FORM

Open the Faculty Form window from the Solution Explorer window and perform the following data bindings.

+   1. Click the Faculty ID TextBox, txtFacultyID, to select it, then go to the Properties window to expand the DataBindings property, select the Text item and click its drop-down arrow.
Expand the following:

* Other Data Sources
  Project Data Sources
  CSE_DEPTDataSet
  Faculty
2. Select the faculty_id column from the Faculty table by clicking on it. In this way, we finish the binding to the control txtFacultyID on the Faculty Form and the faculty_id column in the Faculty table. As this data binding is finished, you can find that three instances are created and displayed under the form; CSE_DEPTDataSet, facultyBindingSource and facultyTableAdapter.
3. In a similar way, when you bind all other TextBoxes, txtFacultyName, txtTitle, txtPhone, txtCollege and txtEmail, in the Information GroupBox. One important point to be noted is when you bind the second TextBox, txtFacultyName, which will find a new object facultyBindingSource created under the DataBindings property. As discussed in Section 5.6, as soon as you finish the first data binding, a new data-binding source is created and you need to use this data-binding source to bind our txtFacultyName control and all other controls. Expand this binding and click on the faculty_name control to finish this binding. One example of this binding process is shown in Figure 5.53.
