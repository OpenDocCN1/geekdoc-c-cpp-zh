As mentioned, a new course record has been inserted into the database, the Insert button must be disabled to avoid a possible multi-insertion of the same record into the database. But as a new record is to be inserted into the database, this Insert button should be enabled. To distinguish between the existed and a new course record, the content of the Course ID textbox is a good candidate since it is a primary unique identifier for each course record, and therefore as the content of the Course ID textbox changed, each course_id changed, means that if a new course is to be inserted into the database, the Insert button should be enabled.

Another important point is making that the AutoPostBack property of the Course ID textbox is set to True to allow the server to send back a Changed event to the client when its content is changed.
