To use the second way to do this checking, open the Server Explorer window and click on the arrow on the left of our sample database to expand it. Then the **Tables** finder and click on the **Faculty** table, select the **Show Table Data** from the popup to open the **Faculty** table. You can find that the faculty member, **Steve Wang**, has been inserted into this table at the bottom line, as shown in Figure 6.18.

To insert a new record into the **Faculty** table with another method, the **TableAdapter** method, two ways can be adopted: the first one can insert a new faculty record but had better first remove that inserted faculty record from the **Faculty** table. To removing that in the Server Explorer window, on the Faculty table, right-click on the inserted faculty record, and select the **Delete** item. Then go to **File | Save All** menu to insert this change. One can run the project and select the method **TableAdapter Update** from the **Query Method** combobox,
