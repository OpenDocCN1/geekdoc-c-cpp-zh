# 9.3.4 Create A Base Class to Handle Error Checking for Our Web Service

In this section we want to create a parent or base class and use it to handle some possible errors or exceptions as our project runs. It is possible for some reasons that our requests cannot be processed and returned improperly. One of the most possible reasons for that is the security issue. To report any errors or problems that occur in the processing of requests, a parent or base class is a good candidate to perform those jobs. We name this base **SQLBase** and it has two member data:

+   * **Boolean SQLOK**: If the request is true; otherwise a False is set.
* **String SQLError**: A string used to report the errors or problems.

To create a base class in our new project, right-click on our new service project **WebServiceSelect Project** from the Solution Explorer window, then select the **Add | New Item** from the popup menu. Select the Class item from the *Visual C#* Template on the left, and enter **SQLBase.cs** as the **Name** box our new class name. Then click on the **Add** button to add this new class into our project.

Now double-click on this newly added class and enter the codes that are shown in Figure 9.15 within this class as the class member data.

Two public class member data, **SQLOK** and **SQLError**, are added to this new base class. These two data work together to report possible errors or problems during the request processing.
