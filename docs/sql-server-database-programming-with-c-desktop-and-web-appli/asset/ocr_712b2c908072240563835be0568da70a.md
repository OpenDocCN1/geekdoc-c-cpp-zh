# 5.4.2 VIEW EACH RECORD OR SPECIFIED COLUMNS

To view each record from the Faculty table, first delete the grid view tool from the Form by by right-clicking on that grid view tool and select Delete from the popup menu. Go to the Data Source window and click the Faculty table. Click the drop-down arrow and select the Detail item. Drag the Faculty tool from the Data Source to the Form window. All column headers in the Faculty table are displayed, which is shown in Figure 5.35.

Now click the Start button to run your project, and the first record in the Faculty table is displayed in this grid tool, which is shown in Figure 5.36.
