# 5.4 QUERY AND DISPLAY DATA USING THE DATAGRIDVIEW CONTROL

Now we added a data source into our Visual C# 2022 project. Before we can develop this data-driven project, we want to show a popular, but tool provided by the Toolbox window, DataGridView. As we discussed this tool in Section 5.1.1.2, the DataGridView is a container and it can be used to bind data from your database and display the data in a tabular or grid format in your Visual C# forms.

To use this tool, we first need to add a new blank form to the SelectWizard Project, and name this new form DataGrid. Go to Project | Add Form (Windows Forms) to open the Add Item wizard, enter DataGrid.cs into the Name box and click the Add button.

Change the name of the Name added from DataGrid to DataForm, and the Text property from DataGrid to DataGrid Form. Keep the form selected, and then open the Data Source window (if it is not opened). You can view data from any table in your data source window. Two popular views are Full Table and Detail for specified columns.

Here we use the Faculty table as an example to illustrate how to use these two views.

# 5.4.1 VIEW THE ENTIRE TABLE

To view the full Faculty table, click the Faculty table from the Data Source window, click the drop arrow and select the DataGridView item. Drag the Faculty table to the DataGridForm, which is shown in Figure 5.33.

As you drag the Faculty table to the DataGridForm, a set of graphics is created and added into your form automatically, which includes the browsing rows, Addition, Delete and Save buttons. This set of controls is used to help you view data from the selected table. To make a full table, make sure to set the properties of the DataGridView, AutoSizeColumns and AutoSizeRows, to None (Figure 5.33). In this way, you can make all data on this grid.

In addition to those graphical components, a set of design tools, also added to this project when you drag the Faculty table onto the DataGrid window. As we discussed these tools in Section 5.1.1, these tools are used to help users to effectively access, translate and manipulate data between the Visual C# project and the DataSet.

```
Application.Run(new LoginForm());
```
is located inside this Main() method. The startup object is defined by calling a method Run with LoginForm as the argument. To change the startup object for our current project, modify this argument from LoginForm() to DataGridViewForm(), which means that we want to change the constructor of the Dataform class to create a new instance of the DataGridView class, and start our project from this. Using this grid tool, you can not only view data from the faculty table, but also add new and delete data from the table by clicking the ( Add (+) or Delete (x) button to do that. Just add a new line in your table by clicking the Add you want to add data, or delete the data you want to delete by clicking the browsing arrow on the top of the window and then clicking the Delete button. You need to know that these modifications can only affect your data in the DataSet, it has nothing to do with data in your real database.

When you drag the Faculty table from the source window to the DataGridForm, what happened during this? Let's take a little more look at this issue. To do that, click the Close button to stop your project's running.

First, from the first view of the graphical interface, as we mentioned, five instances of design tools are created and have been added to this project. Second, from some view of the project codes, instructions have been automatically added into this project. Open the code window by right-clicking on it in the Solution Explorer and clicking the View Code item. Browse to the method DataGrid_Load() and you can find that line of instruction in here:

```
this.facultyTableAdapter.Fill(this.CSE_DeptDataSet.Faculty);
```

The functionality of this instruction is that the Fill() method, which belongs to the TableTableAdapter class, is to load data from the faculty table into the database in the DataSet, and furthermore into your DataGridView view. The Fill is a very powerful method and it performs an equivalent operation to that of a SQL SELECT statement. To make this clearer, open the Data Source window and right-click on any place inside that. Select the Edit DataSet to open the DataSet Designer Wizard. Right-click on the bottom line, in which the Fill() and the GetData() methods are shown, on the faculty table, and select the Configure item to open the TableAdapter Configuration Wizard. You will find that a complete SQL statement is already stated in here:

SELECT faculty_id, faculty_name, title, office, college, phone, Email, fimage FROM dbo.Faculty

This statement will be executed when the Fill() method is called by the facultyTable-Adapter as the DataGrid_Load() event runs when you start this project. The data returned from executing this statement will fill the grid view in the Faculty Form.
