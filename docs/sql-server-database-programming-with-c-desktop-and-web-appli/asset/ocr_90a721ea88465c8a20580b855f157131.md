# 9.4.4.3.6 Build the Codes for the Back Button's Click Method

The final coding is to build the Back Button's click method. When this button is clicked by the user, the client project should be terminated. Open this event method and enter the following codes into this client method to:

```
Response.Write("<script>window.close()</script>");
```

In this way, our page will be terminated when the script command close() is executed.
