The opened Course Form window, select the default name Ying Bai and click on the Select to load and fill all courses (course_id) by this faculty into the Table in our DataSet as the Course ListBox in this form.

The filled course_id are displayed in the Course ListBox, as shown in Figure 5.66.
Now let's go one step forward by clicking a course_id from the Course ListBox. Immediately, the detailed information about selected course, including the course id, course name, schedule, classroom, credits and enrollment, will be displayed in the Text boxes. This makes sense since those Text boxes have been bound to six columns in the Course table in our DataSet. When you click one course_id from the Course ListBox, you have effectively selected and pick up one course from the Course table. Recall that the ListBox is bound to the Course table in our DataSet when using the BindingSource we perform data binding in Section 5.12. For the selected course, six columns of record have been bound to six Text boxes in the Form, so the data will also be reflected on these six Text boxes. These relationships can be represented and illustrated by connections in Figure 5.67.

You can select the LINQ to DataSet Method to perform this query, and a same querying result will be without problem.
