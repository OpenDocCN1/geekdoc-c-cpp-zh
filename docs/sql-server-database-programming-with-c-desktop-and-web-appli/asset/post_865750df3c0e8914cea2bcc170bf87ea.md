```csharp
private void cmdInsert_Click(object sender, EventArgs e)
{
    byte[] image;
    int check = btInsert = 0;
    CSE_DEPTDataSet.AddRow newFacultyRow();
    CreateFacultyCollection();
    check = CreateFacultyCollection();
    if (check != 0)
    {
        MessageBox.Show("Please fill all textboxes...");
    }
    else
    {
        if (ComboMethod.Text == "TableAdapter Insert")
        {
            image = getFacultyImage();
            int intinsert = tableAdapter.Insert(txtFacultyID.Text, txtFacultyName.Text, txtTitle.Text, null, txtPhone.Text, txtCollege.Text, txtEmail.Text, image);
        }
        else
        {
            newFacultyRow = this_CSEDEPTDataSet.NewFacultyRow();
            InsertFacultyRow = newFacultyRow;
            CSE_DEPTDataSet.Faculty.Rows.Add(newFacultyRow);
            int intinsert = tableAdapter.Update(CSE_DEPTDataSet);
        }
        if (intinsert != 0)
        {
            // data insertion is successful
            UpdateFaculty();
            ClearFaculty();
            PhotoBox.Image = null;
            cmdInsert.Enabled = false;
        }
        else
        {
            MessageBox.Show("The data insertion is failed.");
            cmdInsert.Enabled = true; // enable the Insert button to allow the insertion
        }
    }
    RemoveFacultyCollection();
}
```

- **A.** We first need to declare an object of the **DataRow** class, **newFacultyRow**. Each DataRow object can be mapped to a row in a data table. We are using the DataSet to manage all data pages in this table, the DataSet must be prefixed before the **DataRow** object. In addition, we need to create a row in the **faculty** data table, as the **FacultyRow** is selected as the DataRow class.
- **B.** We next need to create an object of the **newFacultyRow** class.
- **C.** A user-defined method **InsertFaculty()** is called to add all pieces of faculty information about the new inserting faculty, which is stored in seven TextBoxes and a PhotoBox, into this new created DataRow. The codes and the function of this user-defined method are explained later. The method returns a completed DataRow that contains all the pieces of information about the new record. One point to be noted is that it is a reference parameter, ref newlyRow, is passed into the method, which means the address (not the value) of the object newlyRow is passed into the method, and any modification to it is permanent. We need this permanent property to keep our returned newlyRow updated.
- **D.** The completed DataRow is added to the Faculty in our DataSet. One point to be noted is that adding a new record into a data table in the DataSet is nothing to do with adding a new record into a data table. The data tables are only mappings of real data tables in the database. To add this we need to perform the next step.
- **E.** The TableAdapter's method Update() is executed to make this record added into the real database. As mentioned before, you can control the amount of data to be added into the database by passing different arguments. Here we want to add one new record into the Faculty, so a data table is the argument. This Update() returns an integer value to indicate whether this update is successful or not. The value of the returned integer is the number of rows that have been successfully added into the database. A returned value of zero means that this update is failed since no new row has been added into the database.
