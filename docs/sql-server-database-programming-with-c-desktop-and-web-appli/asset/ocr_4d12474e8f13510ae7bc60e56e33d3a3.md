We did this method in Sections 6.2.4 and 6.5.2 in Chapter 6 with two different methods, TableAdapter and SqlDataReader, now we are using LINQ to perform the data updating action, then we need to use SQO method to build that.

Let's have a closer look at this pieces of code to see how it works.

+   A. A LogInfof object **logForm** is declared first now built in its constructor to perform our data updating actions.
B. The **Faculty name** combo is cleaned up before we can add any current faculty member into it.
C. A SQO query is executed via a valid database connection to query all faculty records from the **Faculty** table.
D. A `foreach` loop is used to collect all current faculty names for the queried result obtained from the last query, and assign them to the Faculty Name combobox **ComboName** by adding them by one.
E. The SelectedIndex property of the **ComboName** combobox is set to zero to select the top faculty member as a default one.
F. Finally, the LogInfof object **form** is closed. The side-effect of this closing is to close the database connection, too.
