Let's have a look at this piece of code to see how it works.

+   A. A byte[] blmage object is declared first since we need to get an image to update the selected faculty's image with this data updating action.

+   B. Prior to updating a record in our database, we need to check whether an updated faculty image has been selected using this Update button is clicked by the user. This can be done by checking the HasFile property of the FileUpload class. If no faculty image has been selected, a warning message is displayed to remind the users to make that selection.

+   C. Otherwise, a user-defined method getFacultyImage() is called to get the selected faculty image to be updated in our sample database.

+   D. A data selection is executed using the Standard Query Operator with the faculty_id as the query criterion. The First() method is used to return only the first matched record. It does not matter to our application if we have only one record that is associated with this specific faculty_id.

+   E. An updated faculty record, which is stored in textboxes, the faculty_id textbox, and a selected faculty image, are updated by assigning each of to the related column in the Faculty instance in DataContext object c_dept.

+   F. This data updating can be reality performed only after a system method SubmitChanges() is executed.

+   G. The Faculty combo ComboName is cleaned up to be updated. Another user-defined method, CurrentFaculty(), is called to update all faculty names on that combbox.

+   H. The user-defined method deleteFaculty() is executed to clean all textboxes in the Faculty page to make it ready for a validation for that updating next.
