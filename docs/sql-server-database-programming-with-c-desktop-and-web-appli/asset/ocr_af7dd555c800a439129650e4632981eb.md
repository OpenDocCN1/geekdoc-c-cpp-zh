# 3.4.8.2.2 Generate the Entity Data Model Files

Perform the following operations to generate our Entity Data Model Wizard:

+   1) Right click our project **EDModel Project** from the Solution Explorer window and select the **Add** | **New Item** from the popup menu.

+   2) In the opened New Item wizard, select the item **ADO.NET Entity Data Model** from the Templates and enter **EDModel** in the **Name** box at the bottom. Your finished **Add New Item wizard** should match the one that is shown in Figure 3.45. Click on the **Add** button to add this component to our new project.

+   3) The Entity Data Model Wizard is opened with four options:
   a. EF Designer from database.
   b. Empty EF designer model.
   c. Code First model.
   d. Code from database.

Select the first **EF Designer from database** since we want to create this EDM from our sample database **CSE_DEPT**. Click on the **Next** button to continue.
