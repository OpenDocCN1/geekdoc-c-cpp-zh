# 9.4.4 Web-Based Client Project to Consume the Web Services

As we saw in Section 9.3.11, it can be found that there is no significant difference between developing a Web-based client application and a Windows-based client project to consume a service. As long as the service is referenced by the Web-based client project, one can access and call any method developed in the Web service to perform the desired queries via the Web-based client project. Visual Studio.NET will create the same document files, as the Discovery Map file and the WSDL file, for the client project no matter whether this is served by a Windows-based or a Web-based client application.

To save time and space, we can refer to one existing ASP.NET web application SQLWebInsert Project we developed in Chapter 8 and rename it as our new Web-based client project or create a new ASP.NET Web Application (.NET Framework) project and only create or add a new Course page.

# 9.4.4.2 Add a Service Reference and Modify the Web Form Window

Perform the following operations to add our web reference:

- 1. Open Studio.NET and our Web service WebClientInsert Project, and click on the IIS Express button to run it.
- 2. Copy the URL from the Address bar in our running Web service project.
- 3. Return to our Web project WebClientInsert Project.
- 4. Right-click on our project WebClientInsert Project from the Solution explorer, and select the item Add | Service Reference to open the Add Web Reference wizard.
- 5. Click on the Advanced button located at the lower-left corner of this window to open the Service Reference Settings wizard.
- 6. Click on the Add Reference button to open the Add Web Reference wizard.
- 7. Paste the URL from copy from step 2 the URL in the Add Web Reference window and click on the Arrow button to enable the Visual Studio.NET search and find it.
- 8. When the service is found, the name of our Web service is displayed in the right pane.
- 9. Alternately you can change the name for this Web Reference from localhost to any meaningful name as Web_SQLInsert. Click on the Add Reference button to add this to our new project.
- 10. Click the Close button from our Web service built-in Web interface window to close our Web page.
