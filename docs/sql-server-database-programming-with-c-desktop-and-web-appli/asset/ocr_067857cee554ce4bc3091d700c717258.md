As we did for the validation for the data updating in the last section, we do not need to create any new window to delete this, and we can use the Course Form, exactly use the **Select** button's Click method, perform this data validation.
Now let's test this data deleting function by clicking the **Start** button to run our project. As the project runs, complete the login process and open the Course Form by selecting the **Course Information** from the Selection Form, click on the **Select** button to retrieve and display all courses taught by the faculty member Ying Bai. Now try to delete one, **CSE-438**, from the Course table in our sample database. Select *course_id* from the CourseList and click on the **Delete** button.
Immediately that one can find that all information related to course is removed from all textboxes. Now click the **Select** button again to retrieve all courses taught by the faculty member Ying Bai, you can find that the course (course_id) **CSE-438** has been removed from the CourseList box.

Another way to check this deletion is to go to the Server Explorer window. Then click on the Course table and select **Show Table Data** item from the popup menu to open the **Course table**. You can find that our database nest, **CSE-438** has been deleted from this table.
In order to keep data, we prefer to recover this deleted record from the original data: Section 2.9.4.5 in Chapter 2, when a course record is deleted from the **Course table** (parent table), all records related to that course in the **Course and StudentCourse table** (child table) will also be deleted. A total of 2 records in our sample database is deleted from two tables:

+   - One course record **CSE-438** from the **Course table** (parent table)
- One student record **CSE-438** from the **Student table** (child table)
