To make this issue more clear, we can use the Login Form as an example. The first time the user sends a request to the server to start a login process, the server builds the Login Form and sends it back to the client in the HTML format. After that, the connection between the client and the server is saved. After the user received the Login Web page and entered the necessary login information, such as username and password, the user needs to send another request to the server to process these pieces of login information. After the server received and processed the login, if the server found that the information is invalid, the server needs to re-build the Login Form and send it back to the client with some warning message. Therefore, you can see how many round trips occurred between the client and the server as a Web application executed.

A good solution to reduce round trips is to make sure that all information from the client should be as correct as possible. In other words, try to make any validation as possible in the client side to reduce the burden of the server.

## 8.3.4 The REQUIREMENTS TO TEST AND RUN A WEB PROJECT

Before we start to create our real web project using the ASP.NET, we need the following requirements to test and run our project:

- 1) Server: To test and run our project, you need a Web server either on your local computer or on your network. By default, if you installed Visual Studio 2022 Community on your local computer, the IIS 10.0 has been installed on your local computer. This software allows your Web development tools to use Visual.NET to connect to the server to upload or download pages from the server.
- 2) In this, in order to make our real Web project simple and easy, we always use our local computer as a pseudo server. In other words, we always use the localhost, which is the IP name of our local computer, as our Web server to communicate with our browser to perform the data accessing and manipulating.

If you have not enabled the IIS on your computer, follow the following steps to enable this component on your computer:

- Start, then click Control Panel, and click on the Programs.
- Under the Programs and Features item, click on the link Turn Windows features on or off to open the Features wizard, as shown in Figure 8.4.
- Check the checkbox for the Internet Information Services item from the list to enable the IIS on your computer.
- To confirm this enabling function, expand this Internet Information Services item, and make sure that both items, Web Management Tools and World Wide Web Services, are enabled, too. This can be indicated with a selection mark for both checkboxes, as shown in Figure 8.4.
- Click the OK button to activate this IIS and close the Features wizard.
- The activation starts to enable this IIS on the next wizard, and a completion message is displayed when this is done. Just click the Close button to finish this enabling process. Finally close the Control Panel.

You may need to re-boot your computer to make this enabling function effect.
