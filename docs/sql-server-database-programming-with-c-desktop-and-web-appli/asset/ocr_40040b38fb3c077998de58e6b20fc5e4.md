We select the **user_name** column by clicking it. In this way, we finish the data binding and set up a connection between the **User Name** TextBox on the Login form and the **user_name** column in the LogIn data.

Well, is that easy? Yes. Perform the similar operations for the **Pass Word** TextBox to bind it with the **pass_word** column in the LogIn data. But one point you need to note is: When we perform the data binding for the **User Name** TextBox, there is no pre-built or default **BindingSource** object available because we have not performed any data binding, and the **User Name** is the first control you want to bind. After you finish the first binding, however, a new **BindingSource** object, **logBindingSource**, is created. You need to use this **BindingSource** object to handle all other data bindings for all controls on the LogIn form.

> When you perform the first data binding, there is no BindingSource object available since you have not performed any binding. You can browse to the desired data column and select it to finish this binding. Or, a new BindingSource object is created, and all the following data bindings should use that we created BindingSource to perform all data bindings.

Let us perform the data binding for the **Pass Word** TextBox now.

Click that **Pass Word** TextBox to select it, and then go to the Properties window to expand the **DataBindings** property, select the Text item and click the drop-down. You will find that a new BindingSource object, **logBindingSource**, is shown up (Figure 5.41). Expand this new object and select the **pass_word** column in the Log table by clicking it. The data binding for the **Pass Word** TextBox is done.
