# PART II DATA INSERTION WITH RUNTIME OBJECTS

Inserting into the database using the runtime object in Visual C#.NET environment. Compared with the methods we discussed in Part I, in Visual Studio.NET design tools and wizards are used to insert data into the database, the runtime object provides more sophisticated techniques to do this efficiently and conveniently, although a more complicated coding job is needed. Relatively the methods discussed in the first part are easy to learn and coding, but these methods have some limitations. First, each TableAdapter can only access the data table to perform data actions, as inserting into that table only. Second, each query function built by using the TableAdapter Query Configuration Wizard can only perform a single query, as data selection. Third, after the query function is built, no modifications can be made to that function dynamically, which means that the only times the query function can be modified are either before the project runs or after the project terminates. In other words, you cannot modify that query function during the project.
