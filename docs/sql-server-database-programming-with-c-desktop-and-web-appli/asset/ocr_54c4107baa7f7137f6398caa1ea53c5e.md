**ToArray (Conversion Purpose)**
This method converts a collection to an array. This method forces query execution.
The ToArray<TSource>(IEnumerable<TSource>) method forces immediate evaluation and returns a List<TSource> that contains the query results. You can append this method to your query in order to obtain a cached copy of the query results.
A piece of code using this operator is shown in Figure 4.16.

**ToList (Conversion Purpose)**
This method converts a collection to a List. This method forces query execution.
TheToList<TSource>(IEnumerable<TSource>) method forces immediate evaluation and returns a List<T> that contains the query results. You can append this method to your query in order to obtain a cached copy of the query results.
