if (sqlConnection == null)
{
sqlResult.SQLRequestError = "Database connection is failed";
ReportError(sqlResult);
return null;
}
command.Connection = sqlConnection;
command.CommandType = CommandType.Text;
command.CommandText = cmdString;
command.Parameters.Add("@facultyName", SqlDbType.NVarChar).Value = FacultyName;
facultyAdapter.Command = command;
intResult = facultyAdapter.Fill(dsFaculty, "Faculty");
if (intResult == 0)
{
sqlResult.SQLRequestError = "No matched faculty found";
ReportError(sqlResult);
}
sqlConnection.Close();
command.Dispose();
facultyAdapter.Dispose();
return dsFaculty;
}

# ASP.NET Web Services

The process of creating a web proxy class is equivalent to adding a Web reference to our Windows-based or Web-based application projects.

## 9.30.1 Create a Web Service Proxy

Basically, adding a Web reference to our Windows-based or Web-based applications is a search process. During this process, Visual Studio 2022 will try to find all Web services available to our applications. The following operations will be performed by Visual Studio 2022 during this process:

- 1) When looking for Web services from the local computer, Visual Studio will find all files that include a Web service page with .asmx extension, a WSDL file with .wsdl extension or a Discovery file with .disco extension.
- 2) Searching for Web services from the Internet, Visual Studio 2022 will try to find a UDDI file that contains all registered Web services with their associated documents.
- 3) When all available Web services are found, either from your local computer or from the Internet, you can select your desired Web services by adding them to the Web project as references. You can also opt each of them to look at the detailed description for each Web service and its Web methods. When you select the desired Web services, you can modify the name of the selected Web services as you want. The point is that even if the name of Web service is changed in the client side, the ASP.NET runtime can still use the original name of Web service as it is consumed.
- 4) As Web services have been referenced to the client project, a group of necessary files or documents are also created by Visual Studio 2022. These files include:
    - A. A Discovery file that provides the necessary SOAP interfaces for communications between the client project and the Web services.
    - B. A Discovery file that contains all available XML services on a Web server, and these Web services are obtained through a process called Web services Discovery.
    - C. A WSDL file that provides a detailed description and definition about Web services in an abstract manner.

To add a Web reference to our client project, we need first to create a client project. Open Visual Studio 2022 in the Administrator mode and create a new Visual C# Forms App (.NET Framework) or Windows-based project and name it WinClientSelectProject and add it in the folder C:\Chapter9. Now let's add a Web reference to our new project.

There are two ways to select the desired Web services and add it as a reference to our client project; one is to use the Browser provided by Visual Studio to find the desired Web service, and the other way is to copy and paste the desired service URL to the URL box in Add Web reference. In order to use the second way, you will need to first run the Web service, and then copy its URL and paste it to the URL box in which you have not deployed that Web service to IIS. If you did deploy Web service, you can directly type that URL into the Address box in this window.
