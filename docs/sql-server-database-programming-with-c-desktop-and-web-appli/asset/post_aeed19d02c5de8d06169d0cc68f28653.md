## 6.6.1 DEVELOP STORED PROCEDURES OF SQL SERVER DATABASE

Recall when we build our sample database CSE_DEPT in Chapter 2, there is no faculty name column in the Course table, and the only relationship existed between the Faculty and the Course tables are the faculty_id, which is a primary key in the Faculty table but a foreign key in the Course table.

As the project runs and the Course Form is shown, the user needs to insert new course data based on the faculty name, not the faculty ID. For this new course insertion, we need to perform two queries with two tables: first, we need to make a query to the Faculty table to get the faculty_id by the faculty name selected by the user; second, insert a new course record based on the faculty_id we obtained from our first query. These two queries can be combined into a single stored procedure.

Compared with the stored procedure, another solution to avoid performing two queries is to use a joined-table query to combine these two queries as de for the Course Form in Section 5.15.6 in Chapter 5. However, it is more flexible and convenient to use stored procedures to perform this kind of queries, especially when the queries are performed for multiple data tables.

Now let's develop our procedure to combine these two queries to complete the data insertion. The procedure is named dbo.InsertFacultyCourse.

On the opened Studio.NET, open the Server Explorer and click the arrow symbol that is next to the CSE_DEPT database folder to connect to this database if it was added to the Server Explorer before. Otherwise you right-click on the Connections folder to add and connect to our sample database. Refer to Section 5.3.1 in Chapter 5 for the detailed information of adding and connecting to our sample database.

Expand our connected database and right-click on the Stored Procedures folder, and select the Add New Stored Procedure item to open the Add Procedure Wizard. Enter the codes that are shown in 6.39 into this new procedure. Do not forget to change the procedure's name to dbo.InsertFacultyCourse.

The functionality of this stored procedure is:

- A. All input parameters are listed in this part. The @FacultyName is selected by the user from the ComboBox as the project, and all other input parameters should be entered by the user to the TextBox Box in the Course form.

### 6.6.2.2 Build the Codes for the Insert Click to Perform Data Insertion

Open the Insert button's Click by double-clicking on the Insert button from the Course Form window, and enter the codes that are shown in Figure 6.44. Let's take a look at those new codes to see how they work.

- A. Some local variables and objects are declared including two integer variables, check and intinsert, a query and a SqlCommand object. Two integer variables are used for running status holder to keep the running results for two methods, the user-defined methods, CheckCourseInfo(), and a system method ExecuteNonQuery(), to be called. The query string is used to query our stored procedure to perform this data insertion action. The SqlCommand object is a main object to perform this data insertion action.

- B. Two user-defined methods, InsertCourseInfo() and CheckCourseInfo(), are executed to perform the data-checking functions.

- C. If the result is fine, which means all TextBoxes have been filled with valid data, the SqlCommand object is initialized by assigning with appropriate values to the properties. One to be noted is the CommandType property, here StoredProcedure value must be assigned since we need to call a stored procedure to perform this data insertion function.

- D. Another user-defined method, InsertParameters() that will be built, is executed to fill the Parameters property of the SqlCommand object with a new course record to be inserted into our database. By passing-by-reference mode is used for that method since we want to make sure that all modifications to the passed parameters are permanent.

- E. The ExecuteNonQuery() method of the Class is executed to call the stored procedure to perform the new data insertion. The running result of this method is returned and assigned to one local variable intinsert.
