When you create new Visual C# database application project in the first time, the opened Data Windows is a blank one since you have no previous database connected to this new project. To add new data source or DataSet to this new project, you can click **Add New Data Source** link from the Data Sources window.

Once you click **Add New Data Source** link from the Data Sources to add a new data source, the Data Source Configuration Wizard will be displayed. You may use this wizard to select your desired database to connect with your new project.

# 5.1.2.2 Data Source Configuration Wizard

The opened **Data Source Configuration Wizard** is shown in Figure 5.4.

By using the Data Source Configuration Wizard, you can select your desired data source or database that will be connected to your new project. The Data Source Configuration Wizard supports three types of data sources. The first option, **Database**, allows you to select a data source from a database server on your local computer or on a network server. For this kind of data sources are Microsoft SQL 2017, SQL Server 2019, SQL Server 2019 or Oracle Database 18 XE. You also allows you to choose either an MDF SQL server database, a Microsoft Access .MDB or .ACCDB file. The difference between a SQL server and a SQL database is that the former is a complete database that integrates the database management system with data tables to form a body or package, but the latter is only a database file. The second option, **Service**, enables you to select a source that is located at a Web service. The third option, **Object**, allows you to bind your user interface to one of your database classes.

Click the **Next** button after you selected your desired source, and the next step in the Data Source Configuration Wizard allows you select your data model. Currently, only one model is available, which is DataSet. This means that you can set or build a DataSet to connect to your database and fill that DataSet with a data table, a data row, or a data column from the real database. That DataSet is only mapping to your real database and can be updated with any updating in your database. Select that DataSet model and click the **Next** button to continue.

The next wizard, **Choose Your Data Connection**, allows you to select an existing data connection or create a new connection to your data source, which is shown in Figure 5.5.
