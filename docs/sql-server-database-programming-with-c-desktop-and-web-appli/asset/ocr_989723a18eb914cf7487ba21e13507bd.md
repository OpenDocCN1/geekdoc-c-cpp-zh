# 6.6.1 DEVELOP STORED PROCEDURES OF SQL SERVER DATABASE

Recall when we build our sample database CSE_DEPT in Chapter 2, there is no faculty name column in the Course table, and the only relationship existed between the Faculty and the Course tables are the faculty_id, which is a primary key in the Faculty table but a foreign key in the Course table.

As the project runs and the Course Form is shown, the user needs to insert new course data based on the faculty name, not the faculty ID. For this new course insertion, we need to perform two queries with two tables: first, we need to make a query to the Faculty table to get the faculty_id by the faculty name selected by the user; second, insert a new course record based on the faculty_id we obtained from our first query. These two queries can be combined into a single stored procedure.

Compared with the stored procedure, another solution to avoid performing two queries is to use a joined-table query to combine these two queries as de for the Course Form in Section 5.15.6 in Chapter 5. However, it is more flexible and convenient to use stored procedures to perform this kind of queries, especially when the queries are performed for multiple data tables.

Now let's develop our procedure to combine these two queries to complete the data insertion. The procedure is named dbo.InsertFacultyCourse.

On the opened Studio.NET, open the Server Explorer and click the arrow symbol that is next to the CSE_DEPT database folder to connect to this database if it was added to the Server Explorer before. Otherwise you right-click on the Connections folder to add and connect to our sample database. Refer to Section 5.3.1 in Chapter 5 for the detailed information of adding and connecting to our sample database.

Expand our connected database and right-click on the Stored Procedures folder, and select the Add New Stored Procedure item to open the Add Procedure Wizard. Enter the codes that are shown in 6.39 into this new procedure. Do not forget to change the procedure's name to dbo.InsertFacultyCourse
