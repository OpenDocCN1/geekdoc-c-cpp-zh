# 4.8.4.2 XML Query Extensions

XML-specific query extensions provide you with the query operators you would expect when working in an XML tree structure. These XML-specific query extensions are analogous to the XPath axes. For example, the Elements(s) method is equivalent to the XPath (star) operator. The following sections describe each of the XML-specific query extensions in.

The Elements query return the child elements for each XElement in a sequence of XElements (IEnumerable<XElement>). For example, to get the child elements of each faculty in the faculty list, you could do the following:

```
foreach (XElement faculty in faculties.Elements("faculty").Elements())
{
    Console.WriteLine(faculty);
}
```
