# 9.4.3.5 Build the Codes in the SelectedSelectedIndex Method

The function of this piece of codes is that the detailed course information, such as the course name, schedule, classroom, credit and enrollment, will be displayed in the associated textbox control as the user clicked and selects one course_id from the list box. The main coding job is performed inside the SelectedSelectedIndex event method of the list box Course. Because when user clicks or selects a course_id from the list box, a SelectedChanged event is issued and is passed to the associated Selected() event method.

To pick up the detailed course information for a selected course_id, the method GetInsertCourse() in our service project WebServiceInsert is called, and this method returns an instance of the derived SQLInsertRecord to our client project. The detailed course information is stored in that returned instance.

The codes in this method are identical with those we did for the same event in our Windows-based client project. So we can copy those codes from and paste them into our current project with a few modifications.

Double-click on the list box CourseList from the Designer View of our client page to open the Selected() event method of the list box. Copy and paste those codes into our current Web-based project. The only modification is to change the Windows-based MsgBox() method to the Web-based script method alert(); Your finished Selected() event method is shown in Figure 9.90. The modified parts have been highlighted in blue.

Let's take a look at this piece of codes to see how it works.

+   A. Two instances, one for our service reference class WS_SQLInsert and the other is for our derived class SQLInsertRecord. These first instances work as a bridge between our client project and the Web methods developed in the Web service.
B. A local variable errMsg is declared and is used to hold the error message to displayed and reported later.
C. A Try-Catch block is used to call the method GetInsertCourse() with the selected course_id from the list box as the argument to perform this course information retrieving. The selected course_id is stored in the Text property of the CourseList control.
