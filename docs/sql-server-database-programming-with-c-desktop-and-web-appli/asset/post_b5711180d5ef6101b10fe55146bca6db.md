```csharp
private byte[] getFaceImage() {
    MemoryStream ms = new MemoryStream();
    OpenFileDialog dig = new OpenFileDialog();
    byte[] bimage = null;
    dig.Filter = "JPG Files (*.jpg)|*.jpg|All Files (*.*)|**";
    dig.Title = "Select the Faculty Image";
    if (dig.ShowDialog() == DialogResult.OK) {
        PhotoBox.Image = Image.FromFile(dig.FileName);
        PhotoBox.Image.Save(ms, PhotoBox.Image.Format);
        bimage = ms.ToArray();
    }
    return bimage;
}
```

FIGURE 6.35 The codes for the method getFaceImage().

Let's have a closer look at this piece of code to see how it works.

- A. Some local objects are first declared, including a MemoryStream class and an OpenFileDialog class objects, ms and dig. The former is used as an intermediate translation image array and the latter provides a File Dialog to enable users to select a faculty image to be inserted into our database. A byte[] array bimage is also generated and returned as an array since the only data type used to store an image in a SQL Server is byte.
- B. The OpenFileDialog class dig is initialized with the Filter and Title properties. The former is used to define the image type to be selected and the latter provides a title for the dialog.
- C. If the system ShowDialog() is executed successfully, it returns a constant, DialogResult.OK means the OpenFileDialog is opened and the user has selected a valid faculty image. First, that selected image is read out using the FromFile() method and assigned to the Image property of the Faculty Image control, PhotoBox, in the Faculty Form window, and that image is converted to the MemoryStream format and saved to the MemoryStream object ms the system method Save().
- D. Finally, converted image is further to be converted to a byte array via the ToArray() method.
- E. The converted image array is returned to the calling method.

# 6.6 INSERT DATA INTO THE SQL SERVER DATABASE USING STORE PROCEDURES

In this section, we discuss how to use stored procedures to perform data insertion actions. To save time and space, we can modify the project RTOInsert we built in the last section to create a new project RTOInsertSP to perform the data insertion using the stored procedures. We try to use the stored procedure method to insert a new record into the Table sample in our database to illustrate the operations using this method. Perform the following operations to modify it and make it our new project RTOInsertSP Project:

- 1. Open the Windows Explorer and create a new folder C:\Chapter 6 if you have not done so. Then copy the folder Class DB Projects\Chapter6\RTOInsert Solution that is located under the Students folder at the CRC press site. Then copy the entire solution RTOInsert to your new folder C:\Chapter 6.
- 2. Change the names of the solution and the project from RTOInsert Solution to RTOInsertSP Solution, and RTOInsert Project to RTOInsertSP Project.
- 3. Change the file name from RTOInsert Project.csproj to RTOInsertSP Project.csproj. Double-click on the RTOInsert Project.csproj to open this project.

On the opened project, perform the following modifications to get our desired project:

- 1. Go to RTOInsert Project Properties menu to open the property window. Change the Assembly name from RTOInsert Project to RTOInsertSP Project and the Default namespace from RTOInsert_Project to RTOInsertSP_Project.
- 2. Click on the Assembly Information button to open the Assembly Information window, change the Title and the Product to RTOInsertSP Project.
- Click on the OK to close this wizard.
- 3. Change the Startup object from RTOInsert_Project.Program to (Not set).
- 4. Go to the File | Save All menu item to save those modifications.
- 5. Now right-click on the Login.cs file in the Solution window and select the View Code to open the code window for this Login.cs class.
- 6. Change the namespace from the original RTOInsert_Project to our new namespace, RTOInsert_SP.
- 7. Open the Login.designer.cs file by double-clicking on it from the Solution Explorer (you need to expand the Login folder to find this).
- 8. Change the top line from the original namespace RTOInsert_Project to our current namespace, RTOInsert_Project.
- 9. Repeat steps 5–7 for all other files, such as Faculty.cs, Course.cs, Selection.cs and Student.cs, to change the namespaces for all of those files.
- 10. Open the main file, C# Program.cs, from the Solution Explorer by double-clicking on that file, and change its namespace to RTOInsertSP_Project.

Go to the File | Save All menu item again to save those modifications. Now you can build the project to confirm those modifications by going to the menu Build | Build. A ‘successful’ message will be displayed in the Output.
