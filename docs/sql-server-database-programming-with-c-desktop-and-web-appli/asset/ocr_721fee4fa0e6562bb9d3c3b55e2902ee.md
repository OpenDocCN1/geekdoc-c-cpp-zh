Qeries that perform aggregation functions over a source of elements first iterate over those elements. Examples of queries are Count, Max, Average, and First. These execute without an explicit foreach statement because the query itself must use foreach to return a result. Note that these types of queries return a single value, rather than an Enumerable collection. To force the execution of any query and cache its results, you can call the ToList<TSource> or ToArray<TSource> methods. You can also force execution by putting the loop immediately after the query expression. By calling ToList or ToArray you also cache all the data in a single collection object.

2. LINQ to ADO.NET (LINQ to DataSet, LINQ to SQL and LINQ to Entities)
3. LINQ to XML
