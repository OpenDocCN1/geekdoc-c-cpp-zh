# 5.15.6.2 Build the Codes for User-Defined Methods

In the opened Code Window of the Course Form, enter the codes shown in Figure 5.84 into this code window. Let's have a closer look at few codes to see how it works.

+   A. For the first method, FullCourseTextBox(), some local variables and objects are declared first, including a local integer variable pos that works as a loop counter, and a TextBox array cTextBox[] that works as a data holder to store all pieces of course information to be displayed in Six TextBoxes.
B. To check and get matched columns, two foreach loops are used. The outer loop is used to select the selected row and the inner loop is for each column. In fact, the outer loop can only run once while the inner loop, a total of 6 columns represented six pieces of course information should be checked and collected.
D. Each selected column is assigned to the related TextBox in the Course Form via a TextBox cTextBox[] and display each via the Text property. One point to be noted that the selected column, row[column], is an object and must be converted to a String via ToString(), and then assigned to the property.
E. The outer loop pos is updated for each loop to set a correct position for the TextBox to hold the retrieved and collected column.
F. For the second method, FillCourseReader(), some local variables and objects are declared first, including a local integer variable intIndex that works as a loop counter, and a TextBox cTextBox[] that works as a data holder to store all pieces of queried information to be displayed in Six TextBoxes.
G A while() loop is used with the loop condition as the Read() method of the DataReader. This means that the while() loop will be continued as long as the Read() method returns a true, which means that a valid column has been retrieved from the DataReader.
