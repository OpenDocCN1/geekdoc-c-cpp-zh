For example, to delete a record from the Faculty table in our application, one must first delete those records that are related to the data to be deleted in the Faculty table from the child table such as the Login and Course tables, and then one delete the record from the Faculty table. The reason for this deleting sequence is because the faculty_Id is a foreign key in the Login and the Course tables, but it is a primary key in the Faculty table. One must first delete with the foreign keys and then delete the data with the primary key from the database.
