The methods provided by the LINQ framework are Join and GroupJoin. These methods perform equi-joins or joins that match two data sources on equality of their keys. In relational database terms, Join implements an inner join, which is a type of join in which only objects that have a match in the other data source are returned. The GroupJoin method has no direct equivalent in relational database terms, but it implements a superset of inner joins and outer joins.
