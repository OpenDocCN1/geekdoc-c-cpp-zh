+   A. First a textbox fBox[] is generated to hold seven textboxes to be emptied via the for loop to clean this deleted record from part
B. A Command object and a local variable in this method are declared here. The integer variable intDelete is used to hold the returned value from calling this method of the ExecuteNonQuery() of the Command class.
C. The deleting query string is declared with the faculty_name as the query criterion.
D. The Command object is initialized using the Connection object, Command Type, CommandText and Parameters
E. After the Command object is initialized, the ExecuteNonQuery() method of the Command class is called to perform the data deleting action. This method will return an integer and is assigned to the local variable intDelete.
F. A cleaning is performed to release all objects in this deleting action.
G. The returned value from calling the ExecuteNonQuery() is exactly equal to the number of rows that have been deleted from our sample. If this value is zero, which means no row has been deleted or affected from our database and this deletion has failed, a warning message is displayed. Otherwise, a non-zero value is returned, which means at least one row in our database has been deleted from our database and this data deletion is successful.
