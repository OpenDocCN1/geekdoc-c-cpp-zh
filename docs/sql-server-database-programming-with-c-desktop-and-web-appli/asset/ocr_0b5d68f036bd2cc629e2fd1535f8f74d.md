```
CREATE PROCEDURE [dbo].[WebDeleteStudentSP]
@sName VARCHAR(50)
AS
DECLARE @sid int = (SELECT student_id FROM Student WHERE student_name = @sName)
DELETE FROM Student WHERE student_id = @sid
RETURN 0
```

# 9.5.2 Develop the Stored Procedure WebDeleteStudentSP

Open Studio.NET 2022 and Server Explorer, connect and expand our SQL Server database cept to find the Stored Procedures. Right-click on that folder and select the item **Add New Stored Procedure** from the popup menu to open the Add New Stored Procedure wizard.

Enter the code that @sName is in the parameter section with the related data type. A point to be noted is that the name of this input must be identical to one we use inside our Web method **SQLDeleteSP()**, except in step G in Figure 9.99.

Two queries are included in this procedure. The first one is to get the desired *student_id* based on the input student, and the second query is to delete the target stored record retrieved on the first query.

Click on the **Update** item and the **Update Database** button to save this stored procedure. In the Visual.NET environment. Right-click on our new stored procedure **WebDeleteStudentSP** from the Server Explorer and select **Execute** from the popup menu to open the Execute Stored Procedure wizard, which is in Figure 9.106. You may need to refresh the **Stored Procedures** folder to find this newly created stored procedure.

If the updated student record, Toney Black, we made in the last section has not been recovered, enter that student's name to the **Value** box. Otherwise, enter the student name, then click on the **OK** button to delete that record.

To confirm this deletion, open our database, the **Student** table, from the Server Explorer window. One can find that the student named **Toney Black** or **Tom Erica** has been deleted or removed from that table.
