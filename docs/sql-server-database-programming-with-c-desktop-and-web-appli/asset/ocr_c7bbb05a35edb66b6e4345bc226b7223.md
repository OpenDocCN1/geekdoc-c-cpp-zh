Now we need to bind six textbox controls in the Course Form to six columns in the Course data in the Dataset. Perform the following operational step to complete these bindings:

+   1) Keep the Course Form opened and select the Course ID TextBox from the Course Information GroupBox.
2) Go to the DataBindings property and expand the courseBindingSource object is in there for this project. Then you will find the drop-down arrow which is due to the above binding operation, Course listing.
3) Expand this courseBindingSource until you find the course_id column, which is shown in Figure 5.62c, and choose it by clicking the course_id column. a binding is set up between the Course ID TextBox in the Course form and the course_id column in the Course table in the Dataset.
4) In a similar way, finish the binding for all other five TextBox controls: Course, Schedule, Classroom, and Enrollment.

One point to be noted is the order in which to perform these bindings. You must first perform the binding for the CourseList control, and then the binding for the six TextBoxes.

Now we can answer the reason why we need to keep the default selections at the graph panel when we use the Query Builder (refer to Figure 5.60). The reason for this is that we need controls perform data binding for our six TextBox controls. In this way, each TextBox in the Course Form is bound with the associated data in the Course table in the Dataset. After this kind of binding is set, all columns in the Course table in the Dataset will be updated by the data columns in the Course table in the real database each time FillFacultyID() method is executed.
