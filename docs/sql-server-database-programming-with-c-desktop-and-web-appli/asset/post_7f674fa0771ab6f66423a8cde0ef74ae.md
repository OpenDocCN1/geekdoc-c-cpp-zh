## 5.7 DEVELOP CODE TO QUERY USING THE FILL() METHOD

Select Login.cs from Solution Explorer and click the View Designer to open its graphical interface. Double-click the login button to open its Click method.

First we need to remove the inside the Login_Load() method since this method performed a Fill() to fill the entire Table in our DataSet, but we do not need this function. Thus highlight the entire body (excluding the opening and ending parentheses), right-click on this part and select the Cut item to remove those codes. Then we need to create a local object self, which is an instance of SelectionForm, and the codes that are shown in Figure 5.42 into this.

Let's take a look at this piece of code to show how it works.

A new namespace is created by the Visual C# and the name of the namespace is equal to the name of our project, SelectWizard Project. By using the namespace technology, it is much easier to distinguish the different variables, methods, and events that have the same name but located at different places.

```csharp
namespace SelectWizard_Project
{
    public partial class LoginForm : Form
    {
        public LoginForm()
        {
            InitializeComponent();
        }
        private void Login_Load(object sender, EventArgs e)
        {
        }
        private void cmdLogIn_Click(object sender, EventArgs e)
        {
            SelectionForm self = new SelectionForm();
            loginInTableAdapter.Fill(this.DataSet("cSE_DEPTDataSet"),txtUserName.Text,txtPassword.Text);
            if (cSE_DEPTDataSet.Count == 0)
            {
                MessageBox.Show("No matched username/password found!");
                txtUserName.Clear();
                txtUserName.Focus();
                txtPassword.Clear();
            }
            else
            {
                this.Hide();
                self.ShowDialog();
                self.Close();
            }
        }
        private void cmdCancel_Click(object sender, EventArgs e)
        {
            Application.Exit();
        }
    }
}
```
