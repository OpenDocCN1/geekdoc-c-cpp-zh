# 5.2.1.4 The Course Form

This form is used to access the Course table in our data source to retrieve course information associated with a specific faculty member selected by the user. Recall, in Chapter 2, we developed a sample database CSE DEPT and the Course table is one of five tables in data. A one-to-many relationship exists between the Faculty and the Course table, which is connected by using a primary key faculty_id in the Faculty table and a foreign key faculty_id in the Course table. We will use this relationship to retrieve data from the Course based on the selected faculty_id in both tables.

To create this Course Form, go to Project | Add Form (Windows Forms) menu item to add the Add New Item wizard. Select the Form (Windows Forms) from the mid-list and enter Course.cs into the Name box at the bottom. Click on the Add button to add this to our current project. Then add the following objects and controls, which are shown in Figure 5.25, into this window.

You should set the Select button, cmdSelect, as the default by choosing this button from the Acceptproperty of the Course form. You also need to set the CenterScreen as the StartPosition property of the form.
