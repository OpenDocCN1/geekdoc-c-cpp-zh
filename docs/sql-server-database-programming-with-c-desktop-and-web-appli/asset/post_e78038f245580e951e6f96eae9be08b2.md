```csharp
using System;
using System.Linq;
namespace SQLWebSelect_Project
{
    public partial class Course : System.Web.UI.Page
    {
        WebLINQSQL_Project.CSE_DEPTDataContext c_dept = new WebLINQSQL_Project.CSE_DEPTDataContext();
        protected void Page_Load(object sender, EventArgs e)
        {
            if (IsPostBack)
            {
                CurrentFaculty();
                ComboName.SelectedIndex = 0;
            }
            void CurrentFaculty()
            {
                ComboName.Items.Clear();
                var faculty = (from fi in c_dept.Faculties
                              let fields = "Faculty_name"
                              select fi);
                foreach (var f in faculty)
                    ComboName.Items.Add(f.faculty_name);
            }
        }
    }
}
```

| WebLINQSQL_Course Project | cmdSelect_Click(object sender, EventArgs e) |

```csharp
protected void cmdSelect_Click(object sender, EventArgs e)
{
    var c_info = from ci in c_dept.Courses
                 join fi in c_dept.Faculties on ci.faculty_id equals fi.faculty_id
                 where (fi.faculty_name == ComboName.Text)
                 select ci;
    CourseList.Clear();
    foreach (var cid in c_info)
        CourseList.Items.Add(cid.course_id);
}
```

## 8.8.1.2 The Coding for this method

The function of this method is: when the user selects a desired faculty member from the Faculty Combobox and clicks the Select button, all course_id related to courses taught by the selected faculty member should be retrieved from the database and displayed in the list box CourseList on the page.

Double-click on the Select button from the Design View of the Course page to open its Click method, and enter the codes that are shown in Figure 8.76 into this method. Let's take a close look at these pieces of code to see how it works.

- An inner LINQ query is generated first to define the relationships between the Course and the Faculty tables in our sample database. As we know, there is no faculty_name column available in the Course table, and the only column related to the Faculty table is the faculty_id, which is a primary key in the Faculty table but a foreign key in the Course table. In order to get all matched course_id taught by the selected faculty member (faculty_name), an inner query is necessary. This kind of query joins two tables: Faculty and Course, and the faculty_id in both tables must be identical and the faculty_name must be equal to the selected faculty_name in the Faculty Name combobox in this page.

-. Prior to displaying queried course_id in the CourseList box, control must be cleaned to avoid possible multiple query results be displayed. The joined LINQ query is executed to pick up all matched course_id and add them into the CourseList box to display them in that.

Now let's handle the coding for the SelectedChanged event method of the course listbox to get back details for a selected course_id and display in six textboxes in this Course page.

## 8.8.1.3 The Coding for the SelectedChanged Method of the CourseList Box

The function of this method is: when the users click course_id from the list box CourseList, the detailed course information related to the selected course_id in the list box, as course id, course title, schedule, credit, classroom and enrollment, will be retrieved from the database and displayed in six textboxes on the Course page.

Double-click on the list box CourseList from the Design View of the Course Web form to open this event method, and edit the codes that are shown from Figure 8.77 into this. Let's take a look at this piece of codes to see how it works.

- A. A LINQ query is executed and initialized with three clauses: from, where and select. The range variable ci is selected from the Courses entity and all course details for the selected course_id will be read back using the sample database. The select clause is assigned to the query variable c_info.

- B. The LINQ query is executed to pick up each piece of course details and add each of them to the related textbox to display it in our Course page.

A point to note for this piece of codes is for two columns, credit and enrollment, in the Course table. The table is a flatter and the latter is intense. Thus, a system method ToString() must be used to convert them and then assign them to the related textbox.

| protected void CourseList_SelectedChanged(object sender, EventArgs e) {
  var c_info = from ci in c_dept.Courses

  select ci;

    txtCredit.Text = c.credit.ToString();
    txtClassroom.Text = c.classroom;

    txtEnroll.Text = c.enrollment.ToString();
  }
