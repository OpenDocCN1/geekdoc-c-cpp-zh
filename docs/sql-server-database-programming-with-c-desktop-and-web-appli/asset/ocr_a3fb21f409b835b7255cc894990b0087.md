# 6.6.2.3 Validate Data Insertion after the Course Insertion

To confirm or validate insertion we use the Select button, exactly the Select’s Click method to retrieve all courses, including that inserted course, taught by the selected member Ying Bai.
To do checking, just click on the Select button to retrieve all courses taught by that faculty and display them in the CourseList Box in this Course window. All courses taught by the selected faculty are displayed in the CourseList. The last item, CSE-668, is just the course added into the Course table for insertion.
