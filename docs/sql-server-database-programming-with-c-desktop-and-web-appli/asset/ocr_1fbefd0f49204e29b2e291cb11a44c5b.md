Let's discuss this piece of code step by step to see how it works.

+   A. The name of our stored procedure, `dbo.StudentCourseINTO`, must be declared first and the name must be identical to the name we used when we created our stored procedure in the Server Explorer environment.

+   B. All data components, including the Command, Adapter, DataTable and DataReader objects are defined here since we need to use them for this query.

+   C. The Command is initialized with suitable properties by the user-defined method `BuildCommand()`. The CommandType property must be `StoredProcedure` to indicate that this query is to execute a stored procedure. The CommandText property must be equal to the name of our stored procedure, `dbo.StudentCourseINTO`, which is stored in a string variable `strStudentCourse`.

+   D. The input parameter to the stored procedure is the student name, which is obtained from the **Student Name** combo. It should be added into the Parameters collection of the Command object. You need to note that the nominal name `@stdName` must be identical with the input parameter name defined in our stored procedure `dbo.StudentCourseINTO`. The real parameter is entered by the user as the project runs. The finished Command is assigned to the `SelectCommand` property of the DataAdapter, which will be used later to fetch `course_id` from the `Student` table.

+   E. If the user selects the **DataAdapter Method**, the `Fill()` method is called to fill the StudentCourse table with desired `course_id`.

+   F. If the property is greater than 0, which means that this fill is successful. The userdefined method `FillCourse()` is called to fetch the `course_id` into the CourseList listBox. Otherwise an error message is displayed to indicate this situation.

+   G. If the user selects the **DataReader Method**, the `ExecuteReader()` method is executed to invoke the DataReader to call our stored procedure.

+   H. If this is successful, the queried result should be stored in the DataReader with certain rows. The userdefined method `FillCourseReader()` is executed to return the `course_id` into the CourseList Box in that situation. Otherwise an error message is displayed if this call is failed.

+   I. The job is performed to release all objects used in this data query.
