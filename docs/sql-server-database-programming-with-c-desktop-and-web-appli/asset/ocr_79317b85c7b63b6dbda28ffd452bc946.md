# 1.4 HOW THIS BOOK IS ORGANIZED AND HOW TO USE THIS BOOK

This book is designed for both college students who are new to database programming with C# and professional database programmers who have professional experience on this topic.

Chapters 2-4 provide the fundamentals on database structures and components, ADO.NET and LINQ components. Starting from Chapter 5, also including Chapters 6 and 7, each chapter is divided into two parts: the fundamental part and the advanced part. The data-driven applications developed with design tools and wizards provided by Visual Studio.NET which can be considered as the fundamental part, with lower coding loads and that they are more suitable to students or programmers who are new to the database programming with C#.NET. Part II contains the runtime object method and covers a lot of coding details to perform the different data actions against the database; this method is more flexible and convenient to experienced programmers a lot of coding jobs is connected.

Chapters 8 and 9 give a full discussion and analysis about the developments and implementations of ASP.NET applications and Web services. These technologies are necessary for students and programmers who want to develop and build Web applications and Web services to access and manipulate data via Internet.
