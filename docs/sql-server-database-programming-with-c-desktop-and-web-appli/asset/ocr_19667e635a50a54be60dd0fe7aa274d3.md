# 8.4 DEVELOP ASP.NET WEB APPLICATION TO SELECT DATA FROM SQL SERVER DATABASES

Let's start a new ASP.NET Web application project SQLSelect to illustrate how to access and select data from the database via the Internet. Open the Visual Studio 2022 and click the Continue without code link.

Then go to the menu | New | Project to create a new ASP.NET Web application project. Open the new Template Framework, which is shown in Figure 8.5, select the template ASP.NET Web Application (.NET Framework) and click on the Next. Enter SQLSelectProject in the Project name box and SQLSelectSolution in the Solution name, and select a desired location to save this project. Then click on the Create to create this new Web application project.

On the next wizard, as shown in Figure 8.6, select the Web Forms template by clicking on it, and click on the Create to continue again.

You can place your project in any folder you like in your computer. In this case we place it in your folder C:Chapter 8. Click the OK button to create this new Web application project.

On the opened project, the default Web Form is named Default.aspx and it is located at the Solution Explorer window. This is the Web Form that works as a user interface in the server-side. Now let's perform some modifications to this form to make our Login page.
