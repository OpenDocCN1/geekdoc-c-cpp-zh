## SQL Server Database Programming with C#

Let's have a look at this piece of code to see how it works.

A. The joined table query string is declared at the beginning of this method. Here only one column the first column, course_id, is queried. The reason for this is that we need to use this course_id, not course name, as the identifier to pick each course's detailed information from the table when the user clicked and selected that course_id from the list box. The assignment operator is used for the WHERE clause in the definition of the query string, and it is required by SQL Server operation. For a more detailed discussion about the joined table query, refer to Section 5.1.

B. Some SQL data objects, as Command and DataReader, are created here. All of these objects are prefixed by the keyword Sql to indicate the SQL Server database.

C. The SqlCommand object is initialized with the connection string, command type and text parameter. The parameter name is identical with the dynamic parameter @name, which is defined in the query string and after the assignment in the WHERE clause. The parameter's value is the content of the name, which should be selected by the user later.

D. The ExecuteReader() of the Command class is executed to read back all courses (course_id) by the selected faculty and assigns them to the DataReader.

E. If HasRows property of the DataReader is true, which means at least one row has been retrieved from the database, the FillCourse() method is called to fill the list box.

F. Otherwise, the query failed and a warning message is displayed.

G. Finally, some cleaning jobs are performed to release objects used for this query.

Now let's take care of the coding for the user-defined method FillCourse(), which is shown in Figure 8.31. Open the code page of the Web form and enter the codes into this method into the class.

A. A local variable strCourse can be considered an intermediate variable used to temporarily hold the queried data from the table.

B. CourseList is cleared before it can be filled by the course_id.

C. A while loop is utilized to retrieve the first column for each row by GetString(0), whose index is 0 and value is the course_id. The data is first assigned to the intermediate variable strCourse, and then added into the list box using Add().

```sharp
private void FillCourse(SqlDataReader dataReader)
{
    string strCourse = string.Empty;
    CourseList.Items.Clear();
    while (dataReader.Read())
    {
        strCourse = dataReader.GetString(0); //1st column is course_id
        CourseList.Items.Add(strCourse);
    }
}
```

## 8.4.9.5 Coding for the SelectedChanged Method of List Box Control

Double-click the list control from View of the Web Form to open this event method, and then enter the codes that are shown in Figure 8.32 into this method. Let's take a closer look how this code works.

A. The query string is created with several columns: course_id, course, credit, schedule and enrollment. The criterion is course_id, which is selected by the user by clicking a valid course_id from the list box as the project runs.

B. Two SQL data objects are created and these objects are used to perform the data operations between the database and our project.

C. The SqlCommand object is initialized with the connection object, command type and text parameter. The parameter name is identical with the dynamic name @course, which is defined in the query string after the assignment in the WHERE clause. The parameter's value is the course_id selected by the user from the CourseList control box.

D. The Reader() method is executed to read back the detailed information for the selected course and assign it to the DataReader object, which means that at least one row data has been retrieved from the database.

E. If Rows property of the DataReader is true, the user-defined method FillCourseReaderTextBox() is called to fill those textboxes on the Course page.

F. Otherwise, this query failed and a warning message is displayed.

G. Finally, some cleaning jobs are performed to release objects used for this query.
