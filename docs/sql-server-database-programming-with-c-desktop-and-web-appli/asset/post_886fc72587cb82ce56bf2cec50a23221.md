Let's have a closer look at this piece of codes to see how it works.

- A. A Select query is created and performed to retrieve a course record to be deleted from the Course table. The query criterion is a specific course_id located at the Course ID textbox. Standard Query operator method Single() is used to retrieve back only a single course record.

- D Finally the user defined method ClearCourse() is executed to clean up all six textboxes in the Course page to enable check and confirm that data deletion action.
