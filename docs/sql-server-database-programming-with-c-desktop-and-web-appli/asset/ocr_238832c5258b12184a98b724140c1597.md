Two bound-control on the form, **txtUserName** and **txtPassword**, will be filled with the identical values stored in the Login table. It looks as if this does not make sense. In fact, we do not want to retrieve any column from the Login table; instead, we only want to find the matched items of username and password from the Login table. If we can find matched username and password, we do not care about the *faculty_id* and *student_id*. If no matched items can be found, this means that the login has failed and a warning message should be displayed.

![](bbox=[0.134, 0.506, 0.183, 0.538])

To check the username and password entered by the user from the data source, one can return a *Single Value Query for Data* for Login. But here in order to simplify this check, we use the Fill() method to fill four columns in a mapped data table in the DataSet. We can then check whether this Fill is successful. If it is, the matched data items have been found. Otherwise no matched items are found.

Before we go ahead with our coding, we need to point out the displaying style of password in the textbox control **txtPassword**. Generally, the password will be represented by a sequence of * when users enter it as process. To make this to your project, we need to set the **PasswordChar** property of the textbox control **txtPassword** to a star *.
Now is time for us to develop codes that are related to these objects we created in the previous steps, such as the **BindingSource** and **TableAdapter**, to complete the dynamic query. The operational sequence of the process is shown below:

+   1 When the process starts, the user needs to enter the username and password to two textbox controls, **txtUserName** and **txtPassword**.
2 To start this process, the user will click the Login button on the form to execute the Login click method.
3 The Login button click method will first create some local variables or objects that will be used for the data query and a new object for the next form.
4 Then the method will use the **FillUserNamePassword()** method to fill the Login form.
5 If this is successful, which means that the matched data items for username and password have been found from the Login table, the next window form, **SelectionForm**, will be displayed for the next operational step.
6 Otherwise, a warning message is displayed.
