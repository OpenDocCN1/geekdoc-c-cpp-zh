# 9.4.4.1 Create a New Web Application and Add a New Web Page

Open Visual Studio.NET and create a new ASP.NET Web Application (.NET Framework) C# project. Enter WebClientInsert Project and WebClientInsert Solution into the Projectname and Solution name boxes, of Chapter 9 in the Location box, and click the Create button to finish. On the new wizard, select the Web items from the list to create this new project.

To save time, we can use an updated Course page that is located at a folder Forms\Chapter 9 under the Students folder in the CRC fpt site (refer to Figure 1.2 in Chapter 1). To do, on the opened project window, right-click on our new WebClientInsert Project from the Solution explorer, and select the item Add | Existing Item to open the Add Existing Item wizard. Browse to the folder Forms\Chapter 9 that is under the Students folder under the CRC fpt site, select items Course.aspx, Course.aspx.cs and Course.aspx.designer.cs by checking them from the list and click on the Add button to add these items into our new Web application project.

# 9.4.4.2 Add a Service Reference and Modify the Web Form Window

Perform the following operations to add our web reference:

+   1. Open Visual Studio.NET and our Web service WebClientInsert Project, and click on the IIS Express button to run it.
2. Copy the URL from the Address bar in our running Web service project.
3. Return to our Web project WebClientInsert Project.
4. Right-click on our project WebClientInsert Project from the Solution explorer, and select the item Add | Service Reference to open the Add Web Reference wizard, which is shown in Figure 9.82.
5. Click on the Advanced button located at the lower-left corner of this window to open the Service Reference Settings wizard.
6. Click on the Add Reference button to open the Add Web Reference wizard, which is shown in Figure 9.82.
7. Paste the URL from copy from step 2 the URL in the Add Web Reference window and click on the Arrow button to enable the Visual Studio.NET search and find it.
8. When the service is found, the name of our Web service is displayed in the right pane, which is shown in Figure 9.82.
9. Alternately you can change the name for this Web Reference from localhost to any meaningful name as Web_SQLInsert in. Click on the Add Reference button to add this to our new project.
10. Click on the Close button from our Web service built-in Web interface window to close our Web page.
