**FIGURE 3.46** The finished connection properties wizard.

Five tables and connections between them are displayed in this view. On each table, two groups of entity properties are displayed, Scalar Properties and Navigation Properties. The first category contains all entities (mapped to columns in our physical table) and the second category contains all entities (mapped to related tables using the primary-foreign keys) in this database. The connections between each entity (mapped to data table) are called associations.

One can also open the (Text) Editor, **Table Mapping**, to get detailed mapping information for each table. For example, the detailed mapping for the **Faculty** table in this Designer View and right-click on the **Item Mapping** from the popup menu. An example of this Table mapping is shown in Figure 3.49.

In addition to those, an XML mapping file associated with our Entity Data Model **EDModel** is also created. To open this, right-click on new **EDModel.edm** from the Solution Explorer and select the item **Open With** to open the Open Wizard, which is shown in Figure 3.50. Select the item *XML Editor* and click the **OK** button to open this XML mapping file.

Now if you open your **App.config** by double-clicking **CSE_DEPENTITIES** we created from the Entity Data Model Wizard, you can find that our connection string, under the `<connectionStrings>` tag in this file.

At this point, we have finished creating our Entity Data Model, and we can use this model to build our Visual C# data-driven application to show readers how to make it work.
