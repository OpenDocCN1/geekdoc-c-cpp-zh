A piece of code using this operator is shown in Figure 4.8.
The OfType<T>(IEnumerable) method returns only elements in source that can be cast to T. To instead receive an exception if an element cannot be of type, use Cast<T>(IEnumerable).
The method is one of the few standard query methods that can be applied to a collection that has a non-parameterized type, such as an ArrayList. This is because OfType<TResult> extends the IEnumerable<T> type, can only be applied to collections that are based on the parameterized IEnumerable<T> type, but also to collections that implement IEnumerable.
By applying OfType<TResult> to a collection that implements IEnumerable, you gain the ability to query the collection using the Standard Query Operators. For example, specifying a type argument of Object to OfType<TResult> would return an object of type IEnumerable<Object> in C#, to which the standard query operators can be applied.

### OrderBy (Ordering Purpose)
This operator method is used to sort the elements of an input sequence in ascending order based on the keySelector. The output sequence will be an ordered one in a type of IOrderedEnumerable<T>. Both IEnumerable and IQuery classes contain this operator. An example of using this operator is shown in Figure 4.9.

```csharp
public static void OrderByEx()
{
    Pet[] pets = new Pet[] { new Pet { Name="Barley", Age=8 },
                             new Pet { Name="Boots", Age=4 },
                             new Pet { Name="Whiskers", Age=1 } };
    IEnumerable<Pet> query = pets.OrderBy(pet => pet.Age);
    foreach (var pet in query)
        Console.WriteLine("{0} - {1}", pet.Name, pet.Age);
}

// the running result of this piece of code is:
Whiskers - 1
Boots - 4
Barley - 8
```

# Select (Projection Purpose)

Both IEnumerable and IQueryable classes contain this operator method. This method is implemented by deferred execution. The immediate return value is an object that stores all the information that is required to perform the action. The query represented by this method is not executed until the object is executed either by calling its GetEnumerator method directly or by using foreach in Visual C#. This projection method transforms the function, selector, to produce one value for each value in the source sequence. If selector returns a value that is itself a collection, it is up to the consumer to traverse the subsequences manually. In such a situation, it might be better for your query to return a single coalesced sequence of values. To achieve this, use the SelectMany method instead of Select. Although SelectMany works similarly to Select before it is returned. In query syntax, a select in Visual C# clause translates to an invocation of Select. A where clause translates to an invocation of Where. A piece of example code of using this operator is shown in Figure 4.10.

# Where (Restriction Purpose)

Both IEnumerable and IQueryable classes contain this operator method. This method is implemented by deferred execution. The immediate return value is an object that stores all the information that is required to perform the action. The query represented by this method is not executed until the object is executed either by calling its GetEnumerator method directly or by using foreach in Visual C#. A piece of example code using this operator is shown in Figure 4.11. In query syntax, a where in Visual C# clause translates to an invocation of Where <TSource,IEnumerable<TSource>,Func<TSource,Boolean>>.

```csharp
List<string> fruits = new List<string>{"apple", "banana", "mango", "orange", "blueberry", "grape", "strawberry" };
IEnumerable<string> query = fruits.Where(fruit => fruit.Length < 6);
foreach (string fruit in query)
    Console.WriteLine(fruit);

// the running result of this piece of code is:
apple
mango
grape
```
