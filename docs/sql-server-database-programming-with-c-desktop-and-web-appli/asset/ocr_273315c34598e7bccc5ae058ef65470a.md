# Access Data in ASP.NET

Now let's start to develop the codes for the SelectedChanged event method of the list box control. The function of this method is: when the user clicks any course_id from the list box control, the detailed information related to the selected course_id in the list box such as title, schedule, credit, classroom and enrollment will be retrieved from the database and displayed in six textboxes on the Course page.

# 8.4.9.5 Coding for the SelectedChanged Method of the List Box Control

Double-click the list control from the View of the Web Form to open this event method, and then enter the codes that are shown in Figure 8.32 into this method. Let's take a closer look at this piece of code how it works.

+   A. The query string is created with several queried columns, as course_id, course, credit, classroom, schedule and enrollment. The criterion is course_id, which is selected by the user by clicking a valid course_id from the Listbox as the project runs.
B. Two SQL data objects are created and these objects are used to perform the data operations between the database and our project.
C. The SQLCommand object is initialized with the connection object, command type and text parameter. The parameter name will be identical with the dynamic nominal name @course, which is defined in the query string, after the assignment in the WHERE clause. The parameter's value is the course_id selected by the user from the CourseList control box.
D. The DataReader() method is executed to read back the detailed information for the selected course, and assign it to the DataReader object, which means that at least one row data has been retrieved from the database.
E. If the Rows property of the DataReader is true, the user-defined method FillCourseReaderTextBox() is called to fill those textboxes on the Course page.
F. Otherwise, this query is failed and a warning message is displayed.
G. Finally, some cleaning jobs are performed to release objects used for this query.

Next let's build the codes for our user-defined method FillCourseReaderTextBox() to fill six textboxes in the Course page with six columns from the sample table in our database.
