Next let test the deleting function. In order to avoid a complicated data recovering, we prefer not to delete any original faculty record. Refer to Section 7.2,6 to get more details for these relationships.

Now go to the Faculty Name combobox to select a faculty James David, which is not an original faculty record, but it was inserted in Section 6.8 in Chapter 6.
