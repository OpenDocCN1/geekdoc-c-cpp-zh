# 8.8.4 DEVELOP THE CODES TO DELETE A COURSE RECORD FROM THE COURSE TABLE

The function of this method is to delete an existing record from the Course table as this Delete button is clicked by the user. Double-click on the Delete button from the Design View of Course page to open its Click and enter the codes that are shown in Figure 8.83 into this method. Let's have a closer look at this piece of codes to see how it works.

+   - A Select query is created and performed to retrieve a course record to be deleted from the Course table. The query criterion is a specific course_id located at the Course ID textbox. The Standard Query operator method Single() is used to retrieve back only a single course record.
- The queried course record is placed into the deleting pool with a system method DeleteSubmit().
- The selected record from the Course table as well as the related records from the child table, are deleted by executing another system method SubmitChanges().n- Finally the user defined method ClearCourse() is executed to clean up all six textboxes in the Course page to enable check and confirm that data deletion action.
