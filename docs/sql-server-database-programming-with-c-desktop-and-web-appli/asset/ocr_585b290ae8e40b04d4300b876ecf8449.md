+   B. Prior to updating any data in our database, we need to check whether a valid or updating student has been selected if this **Update** button is clicked by the user. +   C. Otherwise use a method **getStudent()** is called to get the selected student image in updated database and stored in the local array.

+   D. Then the stored procedure, **updateStudentSP()**, which is built in the last set, is executed to update an existing student record and the updating student record. +   E. The user-defined method, **CurrentStudent()**, is called to update all students' names stored in the Student Name combo by retrieving them from the sample database after data updating. This action is necessary because we need to pick up the updated student's name to verify and confirm our data updating later.
