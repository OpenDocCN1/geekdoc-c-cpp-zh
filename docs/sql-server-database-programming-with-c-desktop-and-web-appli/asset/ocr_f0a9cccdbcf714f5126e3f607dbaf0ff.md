When a new project is created with the default windows being opened, which is shown in Figure 5.16, four windows are created and they are:

+   - Windows Form Designing: Contains Window Form object and Form File object.
- Toolbox window: Contains all tools and components to develop Visual C# application projects.
- Solution Explorer window: Contains all files and projects created and added into the current solution.
- Properties window: Contains all properties of the selected controls or objects.
