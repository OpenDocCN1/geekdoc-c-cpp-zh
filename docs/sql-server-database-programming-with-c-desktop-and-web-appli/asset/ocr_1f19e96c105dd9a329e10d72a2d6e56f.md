# 5.1.2 Data Design Wizards in the Data Source Window

Starting with Visual Studio 2005, two new Integrated Development Environment (IDE) features, the Data Sources Window and the Data Source Configuration Wizard, are added to help set up data access using the new classes, such as DataConnector and DataAdapter.

The Data Sources window is used to display the data sources or available databases in your project. You can use it to create a user interface (consisting of data-bound controls) by dragging items from the Data Sources window into Visual C forms in your project. Each item the Data Sources window has a drop-down control list where you can select the type of control to create by dragging it onto a form. You can also customize the control with additional controls, such as those that you have created.

A more detailed description on how to use the Data Sources window to develop a data-driven project is provided in Section 5.4.
