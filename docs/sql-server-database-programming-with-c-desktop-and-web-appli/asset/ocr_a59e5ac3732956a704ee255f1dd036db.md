To make the first column user_name as a primary key, click on the first row and then go to the Toolbar and select the Primary Key (displayed as a key tool). In this way, symbol of primary key is displayed on the left of this row, which is shown in Figure 2.26.

Before we can continue to finish this login table, we need to save and name this table. Go to File | Save Table_1 as the name for this new table. Enter login as the name for this new table. Click on the OK button to finish this saving. A new table, named db.login, is added into the new database through the Tables folder in the Object Explorer window.

To add data into this login table, right-click on the Tables (right-click on the Tables folder and select Refresh if you cannot find this login table) and select Edit Top 20 Rows from the popup menu. Enter all data shown in Figure 2.27 into this table. Also, you can copy all rows from Figure 2.27 and paste them to the login table.
