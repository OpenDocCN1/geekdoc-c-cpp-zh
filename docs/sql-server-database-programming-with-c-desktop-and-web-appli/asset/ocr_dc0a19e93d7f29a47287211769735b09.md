All faculty images are available and stored in the CRC Fps path it, in a folder Images\Faculty that is located under the Students on that site (refer Figure 1.2 in Chapter 1). One can copy those images and save them to a new folder for your local machine.

If this insertion is successful, the contents on all TextBoxes are cleaned up and the Insert button is disabled to avoid saving the same data into the database more than one time.

To check or confirm this insertion, two ways can be used; 1) use the Select button to retrieve inserted faculty, 2) open the faculty table via Server Explorer or Microsoft SQL Server Management Studio 18.
