# 2.3.1 Relational Data Model

A data model is a blueprint for developing a database. It describes the structure of the database and various data relationships and constraints on the data. This information is used in building tables, keys and defining relationships. The relational model implies that a user perceives the database as made up of rows or tuples and a column is called an attribute. It that all elements in the tables are represented correctly. In order to achieve these goals, designers use a range of tools. The most commonly used tool is the Entity-Relationship Model (ER).
