# 5.2.1 USER INTERFACE DESIGN

This project is composed of five forms, named LoginForm, Selection Form, Faculty Form, Student Form and Course Form. The project is designed to map a Computer Science and Engineering Department in a university, and allow users to scan and browse all information about the department, including faculty, courses taught by selected faculty, and courses taken by the associated student.

Each form, with the exception of the Selection Form, is associated with one or two data tables in a sample database, which was developed in Chapter 2. The relationship between each form and tables is shown in Figure 5.13.
