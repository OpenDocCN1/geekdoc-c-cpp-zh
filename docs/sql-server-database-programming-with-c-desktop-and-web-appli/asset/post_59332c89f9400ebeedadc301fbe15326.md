## 9.3.11.4 Modify the Codes in the Select Button Click Method

Replace all codes in this method with the following coding sequences:

A. First let's create three new instances:

- 1. wsSQLSelect for the proxy class of the Web Service
- 2. wsSQLResult for the class of our Web Service and wsSQLResult,
- 3. wsDataSet for our DataSet class

The coding for the first two objects, `wsSQLSelect` and `wsSQLResult`, can be represented by two lines, not four. But in order to make these lines shorter, we separate them in order to make these lines shorter, we separate them with the declaration and assignment in two lines. For those long lines because the proxy class is added into our current project; thus, our current project, which works as a namespace, must be prefixed for proxy class to enable to know and use it.

B. Create a local DataSet object wsDataSet and a string variable errMsg. The former is used to work as a DataSet and the latter is used to only show possible error message.

C. If the user uses the Object Method, a try...catch block is used to catch the first Web method GetSQLSelect() that we developed in our Web Service project with the faculty name as the input parameter. The returned object that itself carries queried firstly information is assigned to our local mapping object wsSQLResult if that calling is successful. Otherwise, an error message is displayed using the Write() method of the Response object of the server. D. The user-defined method **ProcessObject** is executed to assign the retrieved information to the textbox in our Web page to display it.

**E.** If the user selects the **Stored Procedure Method**, the associated web method **GetSelectList()**, which is developed in our service, is called via the instance of the Web reference class to perform the data query. The catch statement is used to collect any possible exceptions if any error occurred for this calling, and the error message is displayed using the Write method of the Response object of the server. Similarly, the user-defined method **ProcessObject** is executed to pick up all pieces of retrieved information from the object and displays them in the Web page.

**F.** If the user selects the **Dataset Method**, the web method **GetSqlClientData** is called through the instance of the Web reference class, and the method returns a Dataset that contains our desired firstly information. The catch block is used to collect any possible exceptions if any error occurred for this calling, and the error message is displayed using the Write method of the Response object of the server.

```csharp
protected void cmdSelect_Click(object sender, EventArgs args)
{
    WebClientSelectProject.WS_SQLSelect wsSQLSelect;
    wsSQLSelect = new WebClientSelectProject.WS_SQLSelect();
    WebClientSelectProject.WS_SQLSelect.SQLResult wsSQLResult;
    wsSQLResult = new DataSet(new DataSet());
    string errMsg;
    if (ComboMethod.Text == "Object Method")
    {
        try {
            wsSQLResult = wsSQLSelect.GetSQLSelect(ComboName.Text);
        } catch (Exception err)
        {
            errMsg = "Service is wrong: " + err.Message;
            Response.Write("<script>alert('" + errMsg + "')</script>");
        }
        ProcessObject(ref wsSQLResult);
    } else if (ComboMethod.Text == "Stored Procedure")
    {
        try {
            wsSQLResult = wsSQLSelect.GetSelectList(ComboName.Text);
        } catch (Exception err)
        {
            errMsg = "Service is wrong: " + err.Message;
            Response.Write("<script>alert('" + errMsg + "')</script>");
        }
        ProcessObject(ref wsSQLResult);
    } else
    {
        try {
            wsSQLResult = wsSQLSelect.GetSqlClientData(ComboName.Text);
        } catch (Exception err)
        {
            errMsg = "Service is wrong: " + err.Message;
            Response.Write("<script>alert('" + errMsg + "')</script>");
        }
        FillDataSet(ref wsSQLResult);
    }
}
```

```csharp
private void ProcessObject(ref WebClientSelectProject.WS_SQLSelect.SQLResult wsResult)
{
    string errMsg;
    errMsg = "Faculty information cannot be retrieved: " + wsResult.SQLRequest;
    if (wsResult.SQLRequest == true)
        FillDataObject(ref wsResult);
    else
        Response.Write("<script>alert('" + errMsg + "')</script>");
}
```
