## 9.4.2 DEVELOP FOUR WEB SERVICE METHODS

We try to develop or add four methods in our Web service project, two of them are used to insert the desired course information into our sample database and two of them are used to retrieve the inserted course record from the database to test the data insertion. One of latter methods is used to retrieve the detailed course information based on the course_id. The functions of these methods are described below:

- 1) Develop a Web method SetInsertSP() to call a stored procedure to perform a new course insertion.
- 2) Develop a Web method GetInsert() to retrieve the new inserted course information from the database using a joined query.
- 3) Develop a Web method InsertDataSet() to perform a data insertion using multi-query and return a DataSet that contains the updated Course table.
- 4) Develop a Web method InsertCourse() to retrieve the detailed course information based on the input course_id.

The reason we use two methods (1 and 3) to perform this data insertion is to compare them. As you, there is no faculty name column in the Course table and each course is related to an associated faculty table. In order to insert a course into the Course table, one must first perform a query to the Faculty table to get the default faculty_id from the selected faculty, and then one can perform an insertion query to insert a new course on faculty_id obtained from the first query. The first method combines these two queries into a stored procedure and the third method uses a DataSet to return the Course table to make this data insertion convenient.
Let's take care of building our methods.

```csharp
using System;
using System.Data;
using System.Data.SqlClient;
using System.Web.Services;

namespace WebInsertProject
{
    [WebServiceBinding]
    public class WebServiceInsert : WebService
    {
        [WebServiceMethod]
        public SQLInsertResult SetInsertSP(string FacultyName, string CourseID, string Credit, string Classroom, string Schedule, int Enroll)
        {
            string connectionString = "dbo.InsertCourse";
            SqlConnection connection = new SqlConnection(connectionString);
            SQLInsertBase sqlInsertBase = new SQLInsertBase();
            SqlCommand command = new SqlCommand();
            int intResult = 0;
            SQLInsertResult sqlInsertOK = true;
            connection.Open();
            if (connection == null)
            {
                SQLInsertResult.SQLInsertError = "Database connection is failed";
                ErrorReport(sqlInsertResult);
                return;
            }
            command.Connection = connection;
            command.CommandType = CommandType.StoredProcedure;
            command.Parameters.Add("@FacultyName", SqlDbType.Text).Value = FacultyName;
            command.Parameters.Add("@CourseID", SqlDbType.Char).Value = CourseID;
            command.Parameters.Add("@Credit", SqlDbType.Text).Value = Credit;
            command.Parameters.Add("@Schedule", SqlDbType.Text).Value = Schedule;
            command.Parameters.Add("@Classroom", SqlDbType.Text).Value = Classroom;
            command.Parameters.Add("@Credit", SqlDbType.Int).Value = Credit;
            command.Parameters.Add("@Enroll", SqlDbType.Int).Value = Enroll;
            intResult = command.ExecuteNonQuery();
            connection.Close();
            command.Dispose();
            if (intResult == 0)
            {
                SQLInsertResult.SQLInsertError = "Data insertion is failed";
                Report(sqlInsertResult);
            }
            return sqlInsertResult;
        }
    }
}
```
