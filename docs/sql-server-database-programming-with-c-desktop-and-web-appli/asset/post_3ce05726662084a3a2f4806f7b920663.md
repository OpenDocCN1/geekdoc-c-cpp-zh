First let's take care of the user-defined method FillFaculty(). The function of this method is to fill text boxes with pieces of queried information and display the queried image in this page. One significant difference in displaying an image between the Windows-based and Web-based application is that Image.Url property belongs to System.Web.Controls.Image, is utilized to access the matched faculty photo and only the name of image file is needed to display the associated image in the Web-based application. In the Windows-based application, System.Drawing must be used to display an image on the file's name.

```csharp
private void FillFaculty(SqlDataReader FacultyReader)
{
  int index;
  TextBox[] fbox = { txtFacultyID, txtName, txtPhone, txtCollege, txtEmail };
  while (FacultyReader.Read())
  {
    for (int index = 0; index < FacultyReader.FieldCount - 2; index++)
    {
      fbox[index].Text = FacultyReader.GetString(index);
      byte[] image = (byte[])FacultyReader["Image"];
      string img = Convert.ToBase64String(image);
      fbox.ImageUrl = String.Format("data:image/jpeg;base64,{0}", img);
    }
  }
}
```

## SQL Database Programming with C#

Let's have a closer look at this piece of codes to see how it works.

- A. A first counter intIndex is declared and it is used for the for loop to pick up each column retrieved from the Faculty table in our sample database.
- B. A textbox array box[] is generated to hold seven textboxes to be filled later via the for loop with seven columns stored in the DataReader.
- C. A while loop is executed as long as the Read() method is true, which means that a valid record is read out from the DataReader. This method will return false if no valid record is read out from the DataReader, which in this application, this while loop is executed one time since all data have been read only one row (one record) read out from the DataReader.
- D. A for loop is utilized to pick up each data column read out from the DataReader object, and assign each of them to the associated textbox control on the Faculty page via the textbox box[]. The index is used to identify each column from the DataReader. The terminal column number is equal to FieldCount – 2 since the last column (7) of the faculty table is a faculty image, fimage, which is an image object and cannot be counted. The 7 columns text information for a faculty record are arranged from column 0 to 6 (FieldCount = 7).
- E. Since the image is stored in the last column with a format of binary data, therefore we need to get and convert it to a byte[].
- F. Because there is no Picture object available in a Web page, we need to convert that image from a byte[] array to a 64-bit String, and assign it to the ImageUrl property of the Image object in the Faculty page: PhotoBack.
