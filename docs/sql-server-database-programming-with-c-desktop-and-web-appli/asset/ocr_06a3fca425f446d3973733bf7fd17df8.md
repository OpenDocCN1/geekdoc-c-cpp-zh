# Introduction to Collections.Integrated Query (LINQ)

```
System.Collections.ArrayList fruits = new System.Collections.ArrayList(2);
fruits.Add("Mango");
fruits.Add("Orange");
// ApplyOfType<T>()
IEnumerable<string> query = fruits.OfType<string>();
Console.WriteLine("Elements of type 'string':");
foreach (string fruit in query)
    Console.WriteLine(fruit);

// the running result of this piece of code is:
Elements of type 'string':
Mango
Orange
```

The OfType<T>(IEnumerable) method returns only elements in source that can be cast to T. To instead receive an exception if an element cannot be of type, use Cast<T>(IEnumerable).
 method is one of the few standard query methods that can be applied to a collection that has a non-parameterized type, such as an ArrayList. This is because OfType<TResult> extends the Iumerable<T> type, can only be applied to collections that are based on the parameterized Iumerable<T> type, but also to collections that implement IEnumerable.
By applying OfType<TResult> to a collection that implements IEnumerable, you gain the ability to query the collection using the Standard Query Operators. For example, specifying a type argument of Object to OfType<TResult> would return an object of type IEnumerable<Object> in C#, to which the standard query operators can be applied.
OrderBy (Ordering Purpose)
This operator method is used to sort the elements of an input sequence in ascending order based on the keySelector. The output sequence will be an ordered one in a type of IOrderedEnumerable<T>. Both Iumerable and IQuery classes contain this operator. An example of using this operator is shown in Figure 4.9.

```
public static void OrderByEx()
{
    Pet[] pets = new Pet { Name="Barley", Age=8 },
                  new Pet { Name="Boots", Age=4 },
                  new Pet { Name="Whiskers", Age=1 } };
    IEnumerable<Pet> query = pets.OrderBy(pet => pet.Age);
    foreach (pet in query)
        Console.WriteLine("{0} - {1}", pet.Name, pet.Age);
}

// the running result of this piece of code is:
Whiskers - 1
Boots - 4
Barley - 8
```
