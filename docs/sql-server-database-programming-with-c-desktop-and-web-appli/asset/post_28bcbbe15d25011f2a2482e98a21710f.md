This piece of code is very simple and straightforward. Each TextBox is added to the collection by using the Add() method with two parameters: **Key** and **Value**. The **Key** parameter works as an identifier for the object, and the **Value** parameter contains the content of the object – TextBox in this case. Both parameters are represented in a string format. In this way, each object, TextBox can be identified by its ID. Of course, each TextBox can also be identified by its index, but remember that the index starts from 0, not 1 since it is a .NET framework.

To check and validate all TextBoxes from the collection, the CheckFacultyCollection() method is executed. The codes for this method are shown in Figure 6.5.
Let's take a look at this piece of code to see how it works.

- A. We need to create an integer variable and initialize it to zero. The purpose of this variable is to hold the returned checking status of execution of this method and return this to the calling method.
- B. A foreach loop is executed to scan each TextBox stored in the FacultyCollection collection. A point is to noted that the data type of the variable or the iteration strCheck must be an IEnumerable|IEnumerable<T> (refer to Sections 4.2 and 4.4.2 in Chapter 4). Also the foreach of C# requires the type of the elements in the collection. Since each element is collected on Dictionary(Key, Value) is a Key/Value pair, the element type is not the type of Key or the type of Value. The element type is KeyValuePair(Key, Value). Since both Key and Value are in String format, therefore the string is used for both of the method strCheck.
- C. An If block is used to check whether TextBox is empty or not by using the Value of each TextBox. A message will be displayed if any TextBox is empty with the Key as the identifier. The variable is incremented by 1 if each TextBox is detected.
- D. Finally, the checking status variable is returned to the calling method.

To remove all TextBoxes from the collection, the RemoveFacultyCollection() method should be called, and the codes for this subroutine are shown in Figure 6.6.
The Key parameter of each TextBox is identified for each TextBox and the Remove() method is called to remove all TextBoxes from the collection object.
