One point to make this publishing process success is that otherwise a running error may be encountered when you try to do it since only the Administrator Mode has the authentication and power to do this publishing process. One can right-click on the Visual Studio icon and select the *Run as administrator* to open it as the administrator mode.

If for some reason, your service cannot be deployed or published successfully, you may need to go to https://www.microsoft.com/webdownloads/platform.aspx to download and install Web Platform Installer 5.0 (WebPI 5.0) provided by Microsoft to make sure that a valid and updated IIS is installed in your computer.
