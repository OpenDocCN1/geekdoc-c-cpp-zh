In order to avoid duplication in the coding process, we can modify two existing projects we developed in Chapter 6, RTOInsertProject and RTOInsertSPProject, to create new projects RTOUDeleteProject and SPOUDeleteProject used in this process. Let's connect on our first project, RTOUDeleteProject.

Open the Windows Explorer and create a new folder as C\Chapter 7 if you have not already done so. Then browse to the folder Class DB Projects\Chapter 6, which is located under the Students on the CRC Press ftp site. Copy the entire RTOInsert Solution and save it to the new folder C\Chapter7 we have created. Perform the following operations to make it our project:

+   1) Change the name of the project from RTOInsert Solution to RTOUDeleteSolution, and
2) Also change the RTOInsert Project.csproj to RTOUDeleteProject.csproj. Double-click on the RTOUDeleteProject.csproj to open this project.
3) Go to the menu item Project RTOUDeleteProject Properties to open the project's property window. Change the Assembly name and the Default namespace to RTOUDataProject and RTOUDeleteProject, respectively.
4) Click on the Assembly button to open the Assembly Information window, change the Title and the Product to RTOUDeleteProject. Click the OK button to hide this wizard.
5) Change the project name for all Windows classes, including Login.cs, Faculty, Course.cs, Selection.cs and Student.cs, as well as related Designer.cs files, from RTOInsertProject to RTOUDeleteProject using the Find and Replace box.
6) Double-click on the C# Project from the Solution Explorer to open it, and change the name to RTOUDelete_Project.

Go to the File | Save All to save these modifications. Click the Save, Overwrite and then the Save button again to save this project. Now we are ready to develop our codes on our new project to perform data updating and deleting actions.
