# Data Selection Query with C#.NET

The DataSet Designer allows us to edit the structure of the DataSet. As we discussed in Section 5.1.2,3, by using this Designer, you can configure an existing query, add a new query, and add a new column with a new key to database. The Add method allows us to add a new query with a SQL SELECT statement which returns a single value from the Solution

Open the Login form from the Solution explorer and open the Data Source window. Right-click on any place in that window and select the Edit DataSet with Designer. Next click the Login table and right-click on the last line of that, which contains our modified Filter:LoginUsernamePassword; which we built in the last section. Then Add Query to open the Tableadapter Configuration Wizard.

On the opened window keep the default selection Use SQL statements, click the Next and choose the SELECT which returns a single value ratio button. Click the Next button to go to the next window and click the Query Builder to build your query.

On the opened Query Builder wizard, perform the following operations to complete this single query:

+   1) Click the first row from the second pane to select.
2) Right-click on this row and select Delete from the popup to delete this row.
3) Go to the top panel and select the pass_word and user_name columns from the Login table by checking the checkboxes related to those columns.
4) Go to the second pane and uncheck the checkbox for the user_name column from the Output column since we do not want to use it as the output, but instead we need to use it as a criterion to filter query.
5) Still in the second pane, right-click on the Group By and select Delete from the popup to remove this Group By.
6) Type a mark '?' on the Filter field in the user_name column, and press the Enter key from your keyboard. Your finished Query Builder should match one that is shown in Figure 5.45.
