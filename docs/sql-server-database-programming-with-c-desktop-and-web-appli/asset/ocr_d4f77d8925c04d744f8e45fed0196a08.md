# 8.4.9 Create The Fourth User Interface — Course Page

To create a new Web page and add it into our project, go to the Solution Explorer and right-click our project **SQLWeb Project**, select **Add | New Item** from the popup menu to open the **Add New Item** window. On the opened window, select the *Web Form*, and enter *Course.aspx* into the **Name** box for our new page and click the **Add** button to add it to our project.

On the opened Web form, add the controls that can place a control in any position on the page as you like. Now try to use a technology to place a control to your desired position on the page window. The key element is the **Position** property for each control you added just as you did for your Windows-based application. In this *Course* page, we added two controls, one list box, six text boxes and five button controls. In order to locate these controls to the desired position of the page, you must use the **Format | Set Position** property to **Absolute** for all controls added to this page, with the exception of the label controls. This position is especially important to the ListBox control, although the second panel cannot be added into the correct location.

Another issue is the panel size and background color. As you add a new panel to the page, the background color of that panel is transparency, which means that you cannot see what you added next the panel. To see that, you need to define the size of the panel by performing the following steps:

+   1) Click the new added panel to select it and go to the **Property** window.
2) Set the **Height** and **Width** properties to the desired dimensions in pixels.
