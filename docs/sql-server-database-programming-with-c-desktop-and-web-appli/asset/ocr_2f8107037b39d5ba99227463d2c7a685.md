# 6.3.3 Create The Stored Procedure Using The TableAdapter Query Configuration Wizard

Open the Data Source by clicking the View | OtherWindows | Data Sources menu item, and then right-click on any location inside the Data Source window and select the Edit DataSet with Designer item from the popup to open this wizard. Right-click the item from the Course table and select the Add Query item from the popup to open the TableAdapter Query Configuration Wizard. Perform the following operations to build this query:

+   1) Check the New stored procedure radio since we want to create a new stored procedure to do the data insertion, and click the Next button to go to the next wizard.
2) Check the INSERT button and click Next to continue.
3) Click the Query Builder button on the opened wizard since we need to build a new query.
4) Click the OK button to the next wizard to confirm our built query function, which is shown in Figure 6.23.
