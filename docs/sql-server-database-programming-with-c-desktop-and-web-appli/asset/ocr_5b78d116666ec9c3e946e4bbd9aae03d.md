# Select (Projection Purpose)

Both Iumerable and IQueryable classes contain this operator method. This method is implemented by deferred execution. The immediate return value is an object that stores all the information that is required to perform the action. The query represented by this method is not executed until the object is executed either by calling its GetEnumerator method directly or by using foreach in Visual C#. This projection method transforms the function, selector, to produce one value for each value in the source sequence, source. If selector returns a value that is itself a collection, it is up to the consumer to traverse the subsequences manually. In such a situation, it might be better for your query to return a single coalesced sequence of values. To achieve this, use the SelectMany method instead of Select. # Where (Restriction Purpose)

Both Iumerable and IQueryable classes contain this operator method. This method is implemented by deferred execution. The immediate return value is an object that stores all the information that is required to perform the action. The query represented by this method is not executed until the object is executed either by calling its GetEnumerator method directly or by using foreach in Visual C#. In query syntax, a where in Visual C# clause translates to an invocation of Where <TSource,IEnumerable<TSource>,Func<TSource,Boolean>>.

List<string> fruits = new List<string>{"apple", "banana", "mango", "orange", "blueberry", "grape", "strawberry" };
