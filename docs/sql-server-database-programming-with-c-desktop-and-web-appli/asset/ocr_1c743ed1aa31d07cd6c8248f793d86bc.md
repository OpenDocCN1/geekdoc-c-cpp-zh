# #7 Data Updating and Deleting with Visual C#.NET

In this chapter, we will discuss how to update and delete data against the databases. In general, many different methods are provided and supported by Visual C#.NET and .NET Framework to help users perform the data updating and deleting against the database. Among them, three popular methods are widely implemented:

+   1. Using TableAdapter DBD methods such as `TableAdapter.Update()` and `TableAdapter.Delete()` to update and delete data against the databases.
2. Using `TableAdapter.Update()` method to update and execute the associated TableAdapter's properties such as `SqlCommand` and `DeleteCommand` to change the table in the DataSet to the table in the database.
3. Using the run time method to develop and execute the Command's method `NonQuery()` to update or delete data against the database directly.

Methods 1 and 2 use Visual Studio Design Tools and Wizards to create and configure TableAdapters, the associated queries using the Query Builder, and call those queries from Visual#.NET applications. The difference between methods 1 and 2 is that method 1 can be used to directly access the database to perform the data updating and deleting in a single step, whereas method 2 uses two steps to finish the data updating or deleting. In method 2, first, the data updating or deleting are performed on the associated tables in the DataSet, and then updated or deleted data are updated to the tables in the database by executing the `TableAdapter.Update()` method.

This chapter is divided into two parts: Part I discusses on data updating and deleting using methods 1 and 2, or in other words, using the `TableAdapter.Update()` and `TableAdapter.Delete()` methods developed in Visual Studio Design Tools and Wizards. Part II presents the data updating and deleting using the run time method by developing command objects to execute the `NonQuery()` method dynamically. Updating and deleting data using stored procedures and the LINQ to SQL are also discussed in this part.

When you have finished this chapter, you will be able to:

+   * Understand the working principle and structure on updating and deleting data against the database using the Visual Studio Design Tools and Wizards.
* Understand the procedures in how to configure the TableAdapter by using the TableAdapter Query Configuration Wizard and build the query to update and delete data against the database.
* Design and develop special procedures to validate data before and after data updating and deleting.
* Understand the working principle and structure on updating and deleting data against the database using the run-time method.
* Design and build stored procedures to perform the data updating and deleting.
* Design and build LINQ to SQL query to update and delete data.
