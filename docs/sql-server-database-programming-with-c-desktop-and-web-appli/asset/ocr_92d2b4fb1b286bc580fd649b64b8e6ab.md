We can build and run our Web project **WebLINSQL Project** to test the data query actions against our sample database.
On the opened Faculty page, select the faculty member **Ying Bai** from the **Faculty Name** combobox, and click on the **Select** button to try retrieve all information related to that faculty. The query result is shown in Figure 8.71.

To insert a new faculty into the **Faculty** table in our sample database, enter the following information into seven textboxes in the **Faculty** page:

| Faculty ID textbox: | S52877 |
| Faculty Name textbox: | Smith Lane |
| Title textbox: | Assistant Professor |
| Office textbox: | MTC-200 |
| Phone textbox: | 750-330-2288 |
| College textbox: | University of Kansas |
| Email textbox: | slain@college.edu |

Your finished faculty insertion page should match one that is shown in Figure 8.72.
Then click on the **Insert** button when you finish this data entry to all textboxes to perform this data insertion. A warning message is displayed to remind us to select a valid faculty image via the **FileUploadImage** component. To do that by clicking on the **Browse** button to browse to the folder **Images\Faculty** under the **Students** folder on the CRC fps site. One can copy those faculty images and save them into a folder on your local machine. Then select a desired faculty image, such as *Wang.jpg*, and click on the **Insert** button again to perform this data insertion.
