Performing the following operations to create a new Visual C# Windows Forms App project RTOSProject:

+   1. Launch Visual Studio 2022 by clicking its icon on the desktop or the task bar.
2. Click on the Continue without code link located at the lower-right corner to open the standard Visual Studio window.
3. Go to the File | Project item to select the Create new project wizard.
4. On the opened wizard, select the template, Windows Forms (.NET Framework) with C#, which is on the left, and click it to select it. Then click on the Next button to continue.
5. On the next wizard, Configure your project, enter RTOSProject into the Project name box, and RTOSSelection into the Solution name box, respectively. Select your desired folder as the location from the Location to save this new project.
6. Click on the Create to create this new project.

To save the time, we can add and five existing Windows Forms, Login.cs, Selection.cs, Factory.cs, Student.cs and Course, into this new project. Performing the following operations to complete these Forms additions:

+   1. On the newly opened project, go to the Solution Explorer window and right-click on the iconForm1.cs and select the Delete item to remove this file.
2. Right-click on the RTOS Project in the Solution Explorer and select the Add | Existing Item to open the Add Existing window.
3. Browse to the CRC Press ftp site, in the folder Students\Windows Forms under that site, select the Login.cs by clicking its checkbox on the list.
4. Click on the Add button to add this Form into our project.
5. Immediately, a new Login.cs is added into the Solution Explorer window. Wait a moment, this file will become a Login.cs folder with two subsidiary files, Login.designer.cs and Login.resx.
6. Repeat steps 2-5 to add the other four Forms by one by one. The point is that on each occasion you can add only one file. Otherwise, some exceptions or errors may be encountered.

Now we need to set and use the Login.cs as our starting object, and modify the namespaces in four files to enable our project to recognize them. Performing the following operations to complete this setup and namespaces modifications:

+   1. Right-click on the Login folder from the Solution Explorer window and select the View Code item to open the code for this Login.cs class file.
2. Change its namespace from the original SelectWizard_Project to our current namespace, RTOSSelect_Project.
3. Open the Login.designer.cs file by double-clicking it from the Solution Explorer window (you need to expand the original namespace SelectWizard_Project to our current namespace).
4. Change the top line from the original namespace SelectWizard_Project to our current namespace, RTOSSelect_Project.
5. Open the main file, Program.cs, browse to the Main() method that is the entry or starting point for our project. Replace the third coding line using Application.Run(new Form1()); with Application.Run(new LoginForm()).
