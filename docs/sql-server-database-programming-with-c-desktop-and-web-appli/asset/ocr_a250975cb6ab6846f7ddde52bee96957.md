# 7.2.2.2 The Codes Creations

The main coding process to perform this data updating is developed inside the Update button's Click method in the Faculty Form window. Open this method and enter the codes that are shown in Figure 7.6 into that.

Let's have a closer look at this piece of newly added codes to see how it works.

+   A. Some local variables and objects are declared first, including a FacultyRow object FacultyRow and it is used to store a new faculty to be updated in the faculty table, a string facultyID that is a holder to save the retrieved faculty ID based on the selected faculty. Both variables are for the TableAdapter Update data updating method. The integer variable intUpdate also as a holder to save the running status of execution of the UpdateFaculty() query method to perform a faculty record updating action. The byte[] array bmage is used to store a selected faculty image to be updated for a faculty record.
B. If the TableAdapt DBDirect Method is selected, a user-defined method getFacultyImage() built in Section 6.5.3 of Chapter 6 is executed to get an updated faculty image and then assigned to the byte[] array bmage.built method getFacultyImage() built in Section 6.5.3 of Chapter 6 is executed to get an updated faculty image and then assigned to the byte[] array bmage.
C. Then the query UpdateFaculty() built in Section 7.2.1 is used to perform this faculty record updating action based on eight pieces of faculty information stored in TextBoxes in the Faculty Form window and a selected faculty image. The running status of execution of query is returned and assigned to the local variable intUpdate that will be used.
D. If the TableAdapter Update Method is selected, we need to build the codes in the next section to perform that kind of data updating operation.
E. By checking the returned running status in the variable intUpdate, we can determine whether or not data updating is successful. If a zero value is returned, which means that some error has been encountered and the data updating is failed, a MessageBox with a warning message is displayed to indicate that case.
