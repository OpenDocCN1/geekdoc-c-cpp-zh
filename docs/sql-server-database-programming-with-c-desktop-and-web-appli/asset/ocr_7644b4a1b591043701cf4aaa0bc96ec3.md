# 8.5 DEVELOP ASP.NET WEB APPLICATION TO INSERT DATA INTO SQL DATABASES

In this section we discuss how to insert a new record into the SQL Server database via a Web Page. To do that, we can modify the project, SQLSelect Project, which we developed in the previous section, and make it our new Web application, SQLWebInsert Project.

Perform the following operations to make the project SQLWebSelect Project into our new Web application SQLWebInsert Project.

+   1. Open the Windows Explorer or File Explorer and locate the web application folder SQLSelectSelection in your local machine (C:\Chapter 8).
2. Right-click on that solution folder and select the Copy item to copy solution with the project, and paste that folder into the same location in your local machine, such as C:\Chapter 8.
3. Rename folders' names to SQLWebInsert Project and SQLWebInsert Project, respectively.
4. Expand the new solution folder SQLWebInsert Solution and click on the new project folder SQLWebInsert Project to open it.
5. Change the following two files' names, SQLWebSelectProject.csproj and SQLWebSelectProject.csprojuser, use to SQLWebInsertProject.csproj and SQLWebInsertProject.csprojuser.
6. Now double click on the new project SQLWebInsertProject.csproj to open it in the Visual Studio 2022.

A key point to note is that we changed the solution and the project's names, but the project's namespace is kept with no change because it would be a very complicated process if we changed the namespace from SQLSelect_Project to SQLWeb_Project.

# 8.5.1 DEVELOP THE CODES TO INSERT A NEW RECORD INTO THE FAC TABLE

To insert a new faculty record into the Faculty table in our sample database, we need to use the Insert button with its event method in the Faculty page. The functions of this Insert button and its event are:

+   1. To insert a new faculty record into the database, we need to enter seven pieces of information into textboxes in the Faculty page. The information includes the faculty_id, faculty name, title, office, college and email.
2. In addition to insert seven pieces of new faculty information, we may also need to insert a new faculty image with that name. Recalled in Section 8.4.7 when we created our Faculty page, a FileUpload component FileloadImage, which is represented by a combbox with a Browse button, is added to this page. The purpose of using this FileUploadimage is to allow users to browse and select a faculty image file from your computer as a new faculty image to be inserted into the database. If no new faculty image can be selected, the original faculty image should be selected and used as one.
3. After all information has been entered into all textboxes, you can click the Insert button to insert this new record into the Faculty table in our sample database via the Web page.
