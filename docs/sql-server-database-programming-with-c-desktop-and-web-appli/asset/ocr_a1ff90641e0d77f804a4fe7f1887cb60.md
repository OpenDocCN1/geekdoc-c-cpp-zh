As the Invoke button is clicked, a URL that contains the default namespace and the default HelloWorld method's name is activated, and a new browser window that is shown in Figure 9.12 is displayed. When the default method HelloWorld is executed, the main service page WebServiceSelect.asm sends a request to the IIS, and further, the IIS sends it to the ASP.NET runtime to process this request on URL.

The ASP.NET runtime will execute the HelloWorld method, return the returned data as a SOAP message, and send it back to the client. The returned message contains only a string object, exactly a string of "Hello World" for this method.

In this result, the version and the encoding of the used XML code is indicated first. The xml attributes are used to indicate the namespace by this String object contains only a string of "Hello World".

As discussed in the previous section, ASP.Net service did not provide any GUI, so the default web project is represented by the XML codes in some interfaces we have seen. This is because Web interfaces are only used and for the testing purpose for the default Web service. In a real application, no such Web interface will be provided and displayed.

Click the Close button that is located on the upper-right corner of the browser to close two browser pages. You may also click on the Stop button to stop this project.
