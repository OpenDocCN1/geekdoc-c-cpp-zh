# 8.4.1 Create the User Interface – Login Form

Right click this **Default** item and select **Rename** from the popup menu and change the name of Web Form to **Login.aspx** since we want to use this default page as our Login Page.

To open this page as a Web Form, right-click on the **Login.aspx** and select the **View Designer**. Three buttons are located at the bottom of this window: **Design**, **Split**, and **Source**. The Source button is used to open the Web form as author to open the Source file that basically is an HTML file containing the related codes for all controls you added to this Web Form in the HTML format. The Split button is used to divide the double window into two parts: Design view and Source view.

Compared with the controls in the code-behind, the difference between them is that the Source file is used to describe all controls you added to the Web form in Visual C#.NET code.

One point to be is the coding line inside the code: `<form id="form1" runat="server">`. This coding line indicates that this Web form will be run on the server at the start of the page.

Let's view the View Designer from the Solution Explorer to open the Design view of our web form.
Unlike the Windows-based application, by default the user interface in the Web-based application has no background color. You can modify the Web form by adding another Style Sheet and the form as you like. In addition, if you want to change some styles such as the header and footer of the form applied to all your pages, you can add a Master Page to do that. In this project, we prefer to use the default web as our user interface and each page in our project has its different style.
