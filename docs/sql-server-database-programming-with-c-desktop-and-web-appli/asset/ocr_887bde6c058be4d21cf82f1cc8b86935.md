Now we need to connect our SQL Server database CSE_DEPT to this project using the DataContext object. One can directly connect and open our sample database CSE_DEPT from the Server Explorer window or if it is already connected. Otherwise one must add a new connection to our sample database. CSE_DEPT, expand the Data Connections in the Server Explorer window, click on the data icon, and select the Refresh on the popup menu. This will expand the Tables node and we can find all of our data tables.

To create an entity class for each table, perform a drag-operation for each table. Starting from the Login table, drag it from the Server Explorer window and place it to the Design. By dragging the Login to the designer canvas, the source code for the Login entity class is created and added into the CSE_DEPT.cs file. Then you can use this entity class to access and manipulate data from the project to the sample database CSE_DEPT.

Perform similar drag-place operations to all other tables, and the finished designer is shown in Figure 5.114. The arrow between the tables is an association that is a new terminology used in LINQ to SQL, which represents the relationship between tables.

Now we can use these entity classes and the DataContext object to perform desired data actions against our sample database using LINQ to SQL technique.
