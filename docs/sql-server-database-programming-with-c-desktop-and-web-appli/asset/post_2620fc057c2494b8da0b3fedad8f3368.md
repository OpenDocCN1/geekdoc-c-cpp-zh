## 6 Data Inserting with Visual C#

In the previous chapter we spent a lot of time in the discussion and explanation of data query using different methods. In this chapter, we will concentrate on inserting data into the DataSet and the database. Inserting data into the DataSet or exactly inserting data into the tables in the DataSet is totally different from inserting data into the database. The former is to insert data into the mapping of table in the DataSet, and this insertion has nothing to do with the real tables in the database. The latter approach is to insert data into the tables in the real database.

ADO.NET provided a disconnected working mode for the database. This means that your data-driven applications will not maintain their connection with the database, and this connection may end after you setup your DataSet and load all data from the tables in the database into your mappings. The main reason for using this mode is to reduce the overhead of maintaining a large number of connections to the database and to improve the efficiency of data transferring between your applications and data sources.

In this chapter, we will provide two parts to show how to insert data into the database; inserting data into the database using Visual Studio.NET design tools and wizards is discussed in the first part, and inserting data into the database using run-time object method is shown in the second part.

When you have finished this chapter, you will:

- Understand the working principle and structure of inserting data into the database using Visual.NET design tools and wizards.
- Understand the procedures involved in configuring the TableAdapter object by using TableAdapter Wizard and building the query to insert data into the database.
- Design and develop special procedures to validate data before and after accessing the database.
- Understand the working principle and structure with regard to inserting data in the database using run-time object method.
- Insert data into the DataSet using LINQ and insert data into the database using LINQ to SQL queries.
- Design and build stored procedures to perform the data insertion.

## 6.1 INSERT DATA INTO A DATABASE

In general, there are many different ways to insert data into the database in Visual Studio.NET. Three methods are widely utilized:

- 1) Using the TableAdapter's DIRECT method, specifically such as TableAdapterInsert()
- 2) Using the TableAdapter.Update() method to insert new records that have already been added to the DataTable in the DataSet
- 3) Using the Command object with the ExecuteNonQuery() method

When using method 1, one can directly access the database and execute commands such as the TableAdapter.Insert(), TableAdapter.Update and TableAdapter.Delete() to manipulate data in the database without requiring DataSet or DataTable objects to reconcile changes in order to send updates to a database. As mentioned at the beginning of this chapter, inserting data into a table is different from inserting data into a table in the DataSet. If you are using a DataSet to store data in your applications, you need to use the TableAdapter.Update() method since the Update() method can trigger and send all changes (updates, inserts, and deletes) to the database.
