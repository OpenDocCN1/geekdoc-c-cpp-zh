Open the Course Form by right-clicking on the Solution Explorer and select the View Designer item. Double-click the Select button to see the codes shown in Figure 5.63. This method is straightforward.

- A. A TableAdapter object is created in the namespace Adapters.
- B. A local string facultyId is declared and it is used to hold the returned facultyid.
- C. If the returned facultyid is not an empty string, which means that a value facultyid has been obtained, we can continue to perform the following faculty queries based on this facultyid.
- D. If the user selected the TableAdapter Method to perform this query, the query we built in the DataSet, FillByID(), is called to Call the query in our DataSet using the dynamic parameter @Param which is replaced by our method facultyID.
