## 7.2.5 DEVELOP CODES TO DELETE DATA USING THE TABLE UPDATE

On the opened Code Window, exactly on the opened Delete Button's Click, of the Faculty Form window, add the codes that are shown in Figure 7.10 in the else block of method. The codes we developed in the previous section have been highlighted with the gray color as the background. Let's have a close look at this piece of new codes to see how it works.

- A. To find the DataRow to be deleted from the DataTable, a default system method FindByFaculty_id will be utilized. However, that needs to use the faculty_id as a criterion. Therefore, we need to retrieve the faculty_id from the Faculty table based on the Faculty Name selected by the user-based method FindByClassName().
- B. After a search the default system method FindByFaculty_id is executed to locate the desired DataRow from the Faculty table, and the desired DataRow is returned and assigned to the local variable FacultyRow.
- C. The Delete() method of the Faculty is executed to delete the selected DataRow from the Faculty DataTable in the Dataset.
- D. The TableAdapter.Update() is executed to update that DataRow from the Dataset to the row in the database.
