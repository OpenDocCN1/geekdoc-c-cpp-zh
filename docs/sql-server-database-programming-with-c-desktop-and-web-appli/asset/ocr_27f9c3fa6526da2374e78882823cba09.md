# 7.2.1 CONFIGURE THE TABLEAPTER AND BUILD THE DATA UPDATING AND DELETING QUERIES

Perform the following operational steps to build the data updating query:

+   1. Open the Data Source window and the TableAdapter Query Configuration Wizard by rightclicking on any place inside the Data Source window. Select the item DataSet with Designer from the popup menu.
2. On the opened wizard, go to the Faculty table, right-click on the last item in the Faculty table, and select Add Item from the popup menu.
3. Keep the default selection, using SQL statements, and click on the Next to go the next wizard.
4. Select and choose the UPDATE item from this wizard since we need to performing data query, then click on the Next again to continue.
5. Click the Query Builder button to open the Query Builder to build our updating query. The opened Query builder is shown in Figure 7.3.
6. Remove all columns from the faculty_id and faculty_name rows under the Filter and Or columns.
7. Uncheck the Set checkbox from the faculty_id row under the column Set, and enter question mark (?) to the faculty_id row under the column Filter, press the Enter key to the keyboard.
8. Change the name of the parameter @Param1 to @fid for the Filer column in the faculty_id row.
