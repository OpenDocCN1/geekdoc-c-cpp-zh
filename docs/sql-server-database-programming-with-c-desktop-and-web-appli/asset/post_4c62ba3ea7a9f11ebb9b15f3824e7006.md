```sql
CREATE PROCEDURE [dbo].[InsertStudent]
  @student_id varchar(50),
  @student_name varchar(50),
  @gpa float,
  @credits smallint,
  @major text,
  @schoolYear text,
  @email text,
  @image image

INSERT INTO Student (student_id, student_name, gpa, credits, major, schoolYear, email, image)
VALUES (@student_id, @student_name, @gpa, @credits, @major, @schoolYear, @email, @image);
```

## 8.9.2.2 The Coding for the Data Insertion Query

Double-click on **Insert** button from the Design View of Student page to open its click method, and enter the codes in Figure 8.90 into that method.
Let's have a closer look at that piece of code to see how it works.

- A. A `byte[]` **image** is declared first since we need to insert a new student image with this data insertion action layer.

- B. Prior to inserting any data into our database, we need to check whether a valid image has been selected if this **Insert** button is clicked by the user. ```csharp
protected void cmdInsert_Click(object sender, EventArgs e)
{
    byte[] image;
    if (FileUpload.HasFile)
    {
        Response.Write("<script>Select an image using FileUpload!</script>");
    }
    else
    {
        image = getStudentImage(txtStudentID.Text, txtStudentName.Text, 
                Convert.ToDouble(txtGPA.Text), Convert.ToInt16(txtCredits.Text), 
                txtMajor.Text, txtSchoolYear.Text, txtEmail.Text, image);
        CurrentStudent();
        ClearStudent();
    }
}
