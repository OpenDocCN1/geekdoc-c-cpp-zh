# 7.4.4 Delete Data for the Course Table in the SQL Server Database

In this section, we discuss how to perform data deleting for the Course table built in our sample database via the Course window in our project RTUpdateDelete Project built in the last section.

Let's concentrate our discussions on the method of deleting the Course table from the SQL Server database. To delete data as we do not need to add any new Windows Form and we can use the Course Form as the user interface with the help of the Delete button exactly the Delete's Click method, to perform this deleting action. We need to perform the following steps to complete this data updating action:

+   1) Develop codes to delete the course record.
2) Validate the data deleting result.

Now let's develop the codes to perform our data deleting action.
