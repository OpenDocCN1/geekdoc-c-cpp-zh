        {
            int pos = 0, check = 0;

                if (CourseInfo[pos] == String.Empty)
                {
                    check++;
                }
            }
            return check;

        {
            int index;
            TextBox[] cBox = {txtCourseID, txtName, txtSchedule, txtClassRoom, txtCredits, txtEnroll};
            for (index = 0; index < cBox.Length; index++)
                cBox[index].Text = "";
        }

# 6.7 CHAPTER SUMMARY

Four popular data insertion methods are discussed and analyzed with examples for our SQL Server 2019 database in this chapter:

- 1) Using the TableAdapter.Insert() method to insert data.
- 2) Using the TableAdapter.Update() method to insert new records that have been added into the DataTable in the DataSet.
- 3) Using the Command object's ExecuteNonQuery() method.
- 4) Using the stored procedures.

Method 1 is developed using the Visual Studio.NET design tools and wizards and allows users to directly access the database and the adapters, such as TableAdapter.Insert() and TableAdapter.Update(), to manipulate the data in the database. As we mentioned in the beginning of this chapter, inserting data into a table in a DataSet is different from inserting data into a table. If you use the DataSet to store data in your applications, you need to use the TableAdapter.Update() method which can trigger and set all changes to the database.

One good habit is to use the TableAdapter.Insert() method when your application uses objects to store data (for example, you are using TextBox to store your data), or when you need finer control over new records in the database.

Method 2 allows users to insert new data into a database with two steps. The first record should be added into the data table that is located in the DataSet.
