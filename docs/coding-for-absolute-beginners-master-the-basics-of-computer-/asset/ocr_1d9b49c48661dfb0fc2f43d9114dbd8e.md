# Syntax for creating simple table using CSS:

```
```html
<html>
<body>
<table class="Table" border = "1">
<tr>
    <th>First Name</th>
    <th>Last Name</th>
    <th>Marks</th>
</tr>
<tr>
    <td>John</td>
    <td>Harry</td>
    <td>40</td>
</tr>
</table>
</body>
</html>
```
```

![](bbox=[0.128, 0.483, 0.575, 0.571])
