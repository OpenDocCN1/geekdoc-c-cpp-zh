# # Text Transformation

```
~~~css
p.uppercase {
  text-transform: uppercase;
}
~~~
```

```
~~~css
p.lowercase {
  text-transform: lowercase;
}
~~~
```

```
~~~css
p.capitalize {
  text-transform: capitalize;
}
~~~
```

# # Text Indentation

```
~~~css
p
{
    Text-indent: 100px;
}
~~~
```

# # Letter Spacing

```
~~~css
h1 {
  letter-spacing: 3px;
}
~~~
```

```
~~~css
h2 {
  letter-spacing: -3px;

~~~
```
