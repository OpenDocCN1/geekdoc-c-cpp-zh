# Paragraph

For adding content, we need to include paragraphs in the HTML document.  
For example:

```
```html
<html>
<head>
<h1> heading </h1>
</head>
<body>
    <p> First Paragraph </p>
    <p> Second Paragraph </p>
</body>
</html>
```
```

Output:

# heading

First Paragraph

Second Paragraph
