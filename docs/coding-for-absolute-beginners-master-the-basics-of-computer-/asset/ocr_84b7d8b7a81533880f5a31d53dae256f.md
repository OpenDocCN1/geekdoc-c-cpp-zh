```
Return_type function_name(parameter list) {

```

Sample code for min() function:

```
int min(int num1, int num2) { //function declaration
    // local variable declaration
    int result;

    if (num1 < num2)
        result = num1;
    else
        result = num2;

    return result;
}
```
