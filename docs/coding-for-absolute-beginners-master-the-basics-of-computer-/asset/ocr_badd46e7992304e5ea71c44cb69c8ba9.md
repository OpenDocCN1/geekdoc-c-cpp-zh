# Union Operator

To combine the result of two or mode SELECT statements, the UNION operator is used for which each of the column must have similar data types. Moreover, the columns in the SELECT statement should be in the same order for both tables. The syntax for implementing UNION operator in SQL is defined as follows:

```
```sql
SELECT column_name FROM table1
UNION
SELECT column name FROM table2;
```
```

# GROUP BY

The SQL GROUP BY statement can be used to perform listing or numbering from the database table. Syntax for using GROUP BY statement in SQL is defined as follows:

```
```sql
SELECT column_name
FROM table_name
WHERE condition
GROUP BY column_name
ORDER BY column_name;
```
```

# ORDER BY

The ORDER BY statement in SQL is used to sort data in ascending or descending order. Syntax for implementing ORDER BY clause is defined as follows:

```
```sql
SELECT column_list
FROM table_name
WHERE condition
[ORDER BY column1, column2,] [ASC | DESC];
```
```
