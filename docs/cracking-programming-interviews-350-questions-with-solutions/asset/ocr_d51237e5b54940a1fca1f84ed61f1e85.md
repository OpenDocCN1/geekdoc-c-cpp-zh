Let us assume that two arrays xv and yv will hold the values of the pairs (x, y) satisfying x² + y² = r ∧ 0 ≤ y ≤ x. Furthermore, the pairs are to be generated in increasing order of their x-values, and a variable x is used to indicate that all pairs with x-value less than x have been generated. Thus, the first approximation to the invariant of the main loop of the program will be

P₁ : 0 ≤ i ∧ ordered(xv[0..i − 1]) ∧ the pairs (xv[j], yv[j]), 0 ≤ j < i, are all the pairs with x-value < x that satisfy x² + y² = r ∧ 0 ≤ y ≤ x.

P₁ is easily established using i ← 0 and x ← 0. If (xv[i], yv[i]) is a solution to x² + y² = r ∧ 0 ≤ y ≤ x, then

r = (xv[i])² + (yv[i])² ≤ 2 × (xv[i])²

Hence, all solutions (xv[i], yv[i]) to the problem satisfy r ≤ 2 × (xv[i])². We will write an initial loop to determine the smallest x satisfying r ≤ 2 × x², and the first approximation to the program is
