Algorithm 69 Partitioning a sequence
1: function PARTITION(a, l, r)
2:     p ← a[r]
3:     i ← l − 1
4:     for j ← l, r − 1 do
5:         if a[j] ≤ p then
6:             i ← i + 1
7:             swap(a[i], a[j])
8:         end if
9:     end for
10:    return i + 1
11: end function
```
```

*partition* always selects the last element a[r] in the sequence a[l..r] as the *pivot*: partitioning element. It partitions the sequence into four regions, some of which may be empty.

**Loop Invariant:**

+   - ∀x ∈ a[l..i] : x ≤ *pivot*
+   - ∀x ∈ a[i + 1..j − 1] : x ≥ *pivot*
+   - a[r] = *pivot*.

The fourth region is a[j..r − 1] which is yet to be evaluated.
Time complexity of *partition* is Θ(n) where n = r − l + 1
