## Question 159 — default argument and member function

Review the program.

```cpp
class A
{
public:
    void f(int i = 3);
    void g(int i, int j = 99);
};

void A::f(int i = 3)
{
}

void A::g(int i = 88, int j)
{
}
```

### Solution of Question 159

*void A::f(int i = 3) is ill-formed because default argument is already specified in class scope.*

*void A::g(int i = 88, int j) is ok, in this translation unit, A::g can be called with no argument.*

Except for member functions of class templates, the default arguments in a member function definition that appears outside of the class definition are added to the set of default arguments provided by the member function declaration in the class definition.

Default arguments for a member function of a class template will be specified on the initial declaration of the member function within the class template.

## Question 162 — explicitly defaulted functions

Is this program valid?

### Program 12.11: explicitly defaulted functions

```cpp
struct A
{
    constexpr A() = default;

    A(int a = 0) = default;

    void operator=(const A&) = default;
```

No. The compiler error is

```text
  is not constexpr
```

## Question 165 — deleted function and inline
