
## 1.11 Segment Problems

Segment problems involve the computation of a longest or shortest segment that satisfies a certain predicate, usually defined in terms of a given array.

### Longest Segments

Let $N \ge 0$ and let $X[0..N)$ be an integer array. We are interested in the length of a longest subsequence $[p..q)$ of $[0..N)$ that satisfies a certain predicate defined in terms of $X$. Examples of such predicates are :

- all elements are zero : $\forall i : p \le i < q : X.i = 0$
- the segment is left-minimal : $\forall i : p \le i < q : X.p \le X.i$
- the segment contains at most 10 zeros : $(\#i : p \le i < q : X.i = 0) \le 10$
- all values are different : $\forall i, j : p \le i < j < q : X.i \neq X.j$

### All Zeros

Let us solve the problem of determining the length of a longest segment of $X[0..N)$ that contains zeros only. It is about the simplest longest segment problem one can imagine. This problem can be re-stated as follows.

```text
1: N : int{N ≥ 0}
2: X : array[0..N) of int
3: r : int
4: r = (max p, q : 0 ≤ p ≤ q ≤ N ∧ (∀i : p ≤ i < q : X.i = 0) : q − p)
```

Our first step is the introduction of a name for $(\forall i : p \le i < q : X.i = 0)$. This does not only abbreviate the postcondition, but, more importantly, it enables us to find out which parts of the derivation are independent of the specific form of the predicate.

For $0 \le p \le q \le N$ we define $A.p.q$ by

$$A.p.q \equiv (\forall i : p \le i < q : X.i = 0)$$

Postcondition $R$ may then be written as

$$R : r = (\max p,q : 0 \le p \le q \le N \land A.p.q : q - p)$$

What can be said about predicate $A$? Its term, $X.i = 0$, does not depend on $p$ or $q$. It holds for empty segments, i.e.,

$$A.n.n \quad \text{for } 0 \le n \le N$$

Furthermore, $A$ is prefix-closed, i.e., if a segment satisfies $A$ then all prefixes of that segment satisfy $A$ as well. More formally,

$$A.p.q \Rightarrow (\forall i : p \le i \le q : A.p.i) \quad \text{for } 0 \le p \le q \le N$$

and $A$ is postfix-closed:

$$A.p.q \Rightarrow (\forall i : p \le i \le q : A.i.q) \quad \text{for } 0 \le p \le q \le N$$

Since the term, $X.i = 0$, in $A$ neither depends on $p$ nor on $q$, it does not matter whether we replace in $R$ the constant $0$ or the constant $N$ by a variable. We propose as invariants $P_0$ and $P_1$ defined by

$$P_0 : r = (\max p,q : 0 \le p \le q \le n \land A.p.q : q - p)$$

and

$$P_1 : 0 \le n \le N$$

For the initialization, we derive

$$
\begin{aligned}
&\max p,q : 0 \le p \le q \le 0 \land A.p.q : q-p \\
&= \max p,q : p = 0 \land q = 0 \land A.p.q : q-p \\
&= 0
\end{aligned}
$$

from which we infer that $P_0 \land P_1$ is initialized by $n \leftarrow 0$ and $r \leftarrow 0$. For an increase of $n$ by 1 we derive, assuming $P_0 \land P_1 \land n \neq N$,

$$
\begin{aligned}
&\max p,q : 0 \le p \le q \le n+1 \land A.p.q : q-p \\
&= \max(\max p,q : 0 \le p \le q \le n \land A.p.q : q-p,\ \max p : 0 \le p \le n+1 \land A.p.(n+1) : n+1-p) \\
&= r \max (\max p : 0 \le p \le n+1 \land A.p.(n+1) : n+1-p) \\
&= \{\text{distribute over max for a non-empty range, } A.(n+1).(n+1)\} \\
&\quad r \max (n+1 + (\max p : 0 \le p \le n+1 \land A.p.(n+1) : -p)) \\
&= r \max (n+1 - (\min p : 0 \le p \le n+1 \land A.p.(n+1) : p))
\end{aligned}
$$

leading to the introduction of integer variable $s$ and accompanying invariant

$$Q : s = (\min p : 0 \le p \le n \land A.p.n : p)$$

From $(\min p : 0 \le p \le 0 \land A.p.0 : p) = 0$, we infer that $s$ should be initialized at zero and we obtain a program of the following form:

```text
1: N ≥ 0 ∧ (∀n : 0 ≤ n ≤ N : A.n.n)
2: n ← 0
3: r ← 0
4: s ← 0
5: Invariant : P₀ ∧ P₁ ∧ Q
6: bound : N - n
7: while n ≠ N do
8:     establish Q(n ← n + 1)
9:     r ← r max (n + 1 - s)
10:    n ← n + 1
11: end while    ▷ r = ( max p,q : 0 ≤ p ≤ q ≤ N ∧ A.p.q : q - p)
```

This program leaves “establish $Q(n \leftarrow n + 1)$” as a subproblem. Since $A$ holds for empty segments, the range of the quantification in $Q$ is non-empty and $Q$ can be written as the conjunction of $Q_0$, $Q_1$, and $Q_2$, defined as

- $Q_0 : 0 \le s \le n$
- $Q_1 : A.s.n$
- $Q_2 : (\forall p : 0 \le p < s : \neg A.p.n)$

Since $A$ is prefix-closed, we have $\neg A.p.n \Rightarrow \neg A.p.(n+1)$ for $0 \le p < n$, and, hence

$$Q_2 \Rightarrow Q_2(n \leftarrow n + 1)$$

We have $Q_0 \Rightarrow Q_0(n \leftarrow n + 1)$ as well and we conclude

$$Q_0 \land Q_2 \land A.s.(n + 1) \Rightarrow Q(n \leftarrow n + 1)$$

The fact that $Q_2(n \leftarrow n + 1)$ is implied by $Q_2$ has another consequence. From

$$Q_2(n \leftarrow n + 1) \equiv (\forall p : 0 \le p < s : \neg A.p.(n + 1))$$

we infer

$$Q_2 \Rightarrow (\min p : 0 \le p \le n + 1 \land A.p.(n + 1) : p) \ge s$$

i.e., only values $p$ for which $s \le p \le n + 1$ have to be investigated. For $p = n + 1$, we know that $A.p.(n + 1)$ holds, so we usually start our investigations with the calculation of $A.p.(n + 1)$ for $s \le p \le n$.

We return to all zeros, for which $A.p.q \equiv (\forall i : p \le i < q : X.i = 0)$, and we compute $A.p.(n + 1)$ for $s \le p \le n$:

$$
\begin{aligned}
A.p.(n+1) &\equiv (\forall i : p \le i < n+1 : X.i = 0) \\
&\equiv (\forall i : p \le i < n : X.i = 0) \land X.n = 0 \\
&\equiv A.p.n \land X.n = 0
\end{aligned}
$$

Hence,

$$Q \land X.n = 0 \Rightarrow Q(n \leftarrow n+1)$$

and

$$X.n \neq 0 \Rightarrow (\forall p : s \le p \le n : \neg A.p.(n+1))$$

from which we infer, since $A.(n+1).(n+1)$ holds

$$X.n \neq 0 \Rightarrow Q(n \leftarrow n+1)(s \leftarrow n+1)$$

This leads to the following solution to all zeros:

### Algorithm 18 All Zeros Program

```text
1: n, s : int
2: n ← 0
3: r ← 0
4: s ← 0
5: while n ≠ N do
6:     if X.n == 0 then
7:         skip
8:     else if X.n ≠ 0 then
9:         s ← n + 1
10:    end if
11:    r ← r max (n + 1 - s)
12:    n ← n + 1
13: end while
```

Please note that we did not use the postfix-closedness of $A$.

## 1.12 Exponentiation

### Problem Description

Write a program that, given two fixed integers $X \ge 0$ and $Y \ge 0$, establishes $z = X^Y$.

### Solution

Let us define $0^0 = 1$. The program is to consist of a loop with the following invariant and bound functions:

- $P : 0 \le y \land z \times x^y = X^Y$.
- $t : y$

### Algorithm 20 Exponentiation Revisited

```text
1: 0 ≤ X ∧ 0 ≤ Y
2: x ← X
3: y ← Y
4: z ← 1
5: while 0 < y ∧ even(y) do
6:     y ← y / 2
7:     x ← x × x
8:     if 0 < y ∧ odd(y) then
9:         y ← y − 1
10:        z ← z × x
11:    end if
12: end while
                         ▷ z = X^Y
```

With the preliminary, nondeterministic version, the loop could iterate up to $Y$ times; in the final, deterministic version, the number of iterations is at most $1 + 2 \times \lceil \log Y \rceil$. The algorithm can be rewritten once more as

### Algorithm 21 Efficient Exponentiation

```text
1: 0 ≤ X ∧ 0 ≤ Y
2: x ← X
3: y ← Y
4: z ← 1
5: while 0 < y do
6:     while even(y) do
7:         y ← y / 2
8:         x ← x × x
9:     end while
10:    y ← y − 1
11:    z ← z × x
12: end while
                         ▷ z = X^Y
```

## 1.13 Searching two-dimensional sorted array

### Problem Description

Let us start analyzing the problem by looking at implied properties related to search space. This array has the following properties:

1. number of rows $m \ge 1$
2. number of columns $n \ge 1$
3. Entries in each row are ordered by $\le$, i.e., for $0 \le i < m$ && $0 \le j < n$:

   $$a[i][j] \le a[i][j+1]$$

   - $a_{11} \le a_{12} \le \cdots \le a_{1n}$
   - $a_{21} \le a_{22} \le \cdots \le a_{2n}$
   - $\vdots$
   - $a_{m1} \le a_{m2} \le \cdots \le a_{mn}$

4. Entries in each column are ordered by $\le$, i.e., for $0 \le i < m$ && for $0 \le j < n$:

   $$a[i][j] \le a[i+1][j]$$

   - $a_{11} \le a_{21} \le \cdots \le a_{m1}$
   - $a_{12} \le a_{22} \le \cdots \le a_{m2}$
   - $\vdots$
   - $a_{1n} \le a_{2n} \le \cdots \le a_{mn}$

Pictorial representation of two-dimensional sorted array is as follows:

![](img/78e1bff64796dccbf49e7c84b8201fb2_77_0.png)

With the properties above, we have to develop an efficient algorithm to find the position of a given integer $x$ in the array $a$, i.e., the algorithm should find $i$ and $j$ such that $x = a[i,j]$. By efficient we mean to minimize the number of comparisons as much as possible.

Let us treat the input array as some kind of a rectangular region.

The problem demands that the integer $x$ does exist somewhere in this region. Let us label this condition as *Input Assertion* or *Precondition*.

### Precondition (aka *Input Assertion*)

$$x \in a[0..m-1, 0..n-1]$$

i.e., $x$ is present somewhere in this rectangular region $a$.
