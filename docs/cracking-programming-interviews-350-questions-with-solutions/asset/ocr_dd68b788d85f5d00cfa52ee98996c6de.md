# *** Question 108    constexpr constructor

What is *constexpr constructor* ?

# Solution of Question 108

A constexpr specifier used in a constructor declaration declares that constructor to be a constexpr constructor.

+   - constexpr constructor is implicitly inline.
+   - each of its parameter types is a literal type or a reference to literal type.
+   - its function-body is not a function-try-block.
