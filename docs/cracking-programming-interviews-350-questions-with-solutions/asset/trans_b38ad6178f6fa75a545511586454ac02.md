## 问题 158 — 默认实参

这个程序的输出是什么？

### 程序 12.9：默认实参

```cpp
#include <iostream>

int a = 1;

int f(int i)
{
    return i;
}

int g(int x = f(a))
{
    return x;

void h()

    {
        int a = 3;

    }
```

## 问题 159 — 默认实参与成员函数

审查该程序。

```cpp
class A
{
public:
    void f(int i = 3);
    void g(int i, int j = 99);
};

void A::f(int i = 3)
{
}

void A::g(int i = 88, int j)
{
}
```

### 问题 159 的解答

*void A::f(int i = 3) 是非良构的，因为默认实参已在类作用域中指定。*

*void A::g(int i = 88, int j) 没问题，在这个翻译单元中，A::g 可以在不带实参的情况下调用。*

除类模板的成员函数外，出现在类定义之外的成员函数定义中的默认实参会添加到类定义中该成员函数声明所提供的默认实参集合中。

类模板成员函数的默认实参将在类模板内该成员函数的首次声明中指定。

## 问题 162 — 显式默认化函数

这个程序有效吗？

### 程序 12.11：显式默认化函数

```cpp
struct A
{
    constexpr A() = default;

    A(int a = 0) = default;

    void operator=(const A&) = default;
    ~A() throw(int) = default;
private:
    int i;
    A(A&);
};
A::A(A&) = default;
```

### 问题 162 的解答

否。编译器错误为

```text
explicit_default.cpp:3:5:
error: defaulted definition of default constructor
  is not constexpr
      constexpr A() = default;
      ^

explicit_default.cpp:5:5:
error: an explicitly-defaulted constructor cannot
have default arguments
    A(int a = 0) = default;
    ~~~~~~~~~~~~~

explicit_default.cpp:7:10:
error: explicitly-defaulted
copy assignment operator
must return 'A &'
void operator=(const A&) = default;

explicit_default.cpp:9:5:
error: exception specification of
explicitly defaulted
    destructor does not match the calculated one
    ~A() throw(int) = default;
    ^
4 errors generated.
```

- `constexpr A() = default;` 是非良构的，因为隐式的 `A()` 不是 `constexpr`

## 问题 165 — 已删除函数与 inline

这段代码有什么问题？

### 程序 12.14：已删除函数与 inline

```cpp
struct A
{
    A();
};

```

### 问题 165 的解答

```text
deleted.cpp:6:10:
```

## 问题 166 — 静态成员初始化作用域

这个程序的输出是什么？

### 程序 12.15：静态成员初始化作用域

```cpp
#include <iostream>

int a = 10;

struct X
{
    static int a;
    static int b;
};

int X::a = 20;
int X::b = a;

int main()
{
    std::cout << X::b << std::endl;
}
```

### 问题 166 的解答

它打印 *20*。

因为静态成员的初始化器位于该成员所属类的作用域中。

因此以下两者等价：

```cpp
int X::b = a;

int X::b = X::a;
```
