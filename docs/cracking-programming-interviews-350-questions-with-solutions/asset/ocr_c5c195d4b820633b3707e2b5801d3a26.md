# Algorithm 27 Saddleback Count - Correct Algorithm

```
function SADDLEBACK-COUNT(a[0..m-1, 0..n-1], x)
i ← 0
j ← n − 1
current_col_index ← j
count ← 0
while j ≤ n − 1 do
    if a[i, j] < x then
        i ← i + 1
    else if a[i, j] > x then
        j ← j − 1
    else if a[i, j] == x then
        current_col_index ← j
        while current_col_index ≥ 0 and
              a[i][current_col_index] == x do
            count ← count + 1
            current_col_index ← current_col_index − 1
        end while
        i ← i + 1
    end if
end while
return count
end function
```
