We proceed recursively with A′ exactly as with A because A′ is an almost complete array. Let us compute the size of A′. The initial A can be of any size but the size of A′ is uniquely determined by n. Let m = ⌊log₂ n⌋ + 1, that is, the number of bits necessary to represent n in binary (thus m is the number of rows in A). Let m′ = m − 1. The derived A′ is of size 2^{m′} − 1. The -1 comes from the fact that A′ has a missing number.
