# Solution of Question 30

Invocation of Base’s constructor as a base part of derived will look like:

```
Derived::Base db;
```

Following the same league, the call below is not legal

```
Base::Base b;
```

because Base::Base doesn’t name a type.

To achieve this, the following should be attempted:

```
struct Base::Base b1;
```
