# Solution of Question 106

A constexpr specifier used in the declaration of a function that is not a constructor declares that function to be a constexpr function.

+   - constexpr function is implicitly inline.
+   - it cannot be virtual
+   - its return type is a literal type or a reference to literal type
+   - each of its parameter types is a literal type or a reference to literal type
+   - its function-body is

```
```cpp
{ return constant-expression ; }
```
