## Question 70 static cast

What is *static_cast<T>(v)*?

### Solution of Question 70

*static_cast<T>(v)* is the result of converting the expression v to type T.

- If T is an lvalue reference type or an rvalue reference to function type, the result is an lvalue
- if T is an rvalue reference to object type, the result is an xvalue.
- otherwise, the result is a prvalue.
- The static_cast operator shall not cast away constness.
