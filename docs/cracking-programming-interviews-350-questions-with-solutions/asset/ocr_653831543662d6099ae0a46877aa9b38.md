1:  function PREPROCESS(A)
2:      A' ← [(σ(1), A[σ(1)]), (σ(2), A[σ(2)]), ..., (σ(n), A[σ(n)])], where
        A[σ(1)] ≤ ··· ≤ A[σ(n)] and σ is a permutation of {1, 2, ..., n}.
3:      for i ← 1 to n − 1 do
4:          B[i][1].element ← FIRST(A').element
5:          B[i][1].mass ← FIRST(A').mass
6:          slack ← 1/(n − 1) − FIRST(A').mass
7:          B[i][2].element ← LAST(A').element
8:          B[i][2].mass ← slack
9:          massLast ← LAST(A').mass − slack
10:         REMOVE(A', FIRST(A'))
11:         REMOVE(A', LAST(A'))
12:         ADDINORDER(A', (B[i][2].element, massLast))
13:     end for
14: end function

```

Line 1 creates a list $A'$ of tuples (element, mass) from the elements of the array $A$, where element $\in \{1,2,\ldots,n\}$, mass = $A[\text{element}]$, and the tuples in $A'$ are sorted on mass. This operation takes time $\Theta(n\log n)$. FIRST takes a list as argument and returns the element at the head of the list in time $\Theta(1)$. LAST likewise returns the last element in the list in time $\Theta(1)$. REMOVE takes as argument a list and an element in the list and removes the element from the list. This takes time $\Theta(n)$ if done using a linear scan. ADDINORDER inserts the given element in the given list such that the new list is sorted on mass. This also takes time $\Theta(n)$. Hence, in all, the preprocessing stage takes $\Theta(n^2)$ time.
