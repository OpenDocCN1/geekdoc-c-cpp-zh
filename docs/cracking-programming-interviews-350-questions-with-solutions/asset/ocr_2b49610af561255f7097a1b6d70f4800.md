This code doesn't get compiled. Compiler error is

```
auto1.cpp:4:1:
warning: 'auto' storage class specifier
is not permitted in
    C++11, and will not be supported in future
        releases
        [-Wauto-storage-class]
auto int r;
~~~~
auto1.cpp:4:10: error: illegal storage class on
file-scoped variable
auto int r;
         ^
1 warning and 1 error generated.
```

Another compiler gives the error below:

```
auto1.cpp:4:10: error: two or more data types in
declaration of ‘r’
 auto int r;
        ^
```

The type of

+   - x is int
+   - v is const int*
+   - u is const int
+   - y is double

Please note that auto is not a storage-class-specifier, hence the error on the line 4.
