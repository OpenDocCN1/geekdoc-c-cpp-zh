**Deducing-Conditional-Statement**  
**Deducing Conditional Statement**  Let us start with finding complement of the condition, i.e., search still continues. It is not that difficult to see that the complement should maintain the invariant and lead towards the result, i.e.,

$Invariant \land complement\text{-}of\text{-}condition \Longrightarrow Postcondition$

# Revisiting Postcondition

$(0 \leq i \leq m-1 \land 0 \leq j \leq n-1 \land x = a[i,j])$

As could be seen above, *Postcondition* consists of 2 parts¹:

+   1. $(0 \leq i \leq m-1 \land 0 \leq j \leq n-1 \land x = a[i,j])$  
+   2. $(i = m \land x \neq a)$

# Establishing Postcondition

To establish first part of postcondition, the complement of the condition can be $i < m$ and $x = a[i,j]$.

And to establish second part of postcondition, it can be $i = m$.

# Complement of condition

Putting together, this looks like:

$i = m \lor (i < m \land x \neq a[i,j])$

Let us take its complement again to reach to the condition, i.e., complement of the complement of the condition $\Longrightarrow$ condition.

# Condition

$(i \neq m \land (i \geq m \text{ or } x \neq a[i,j]))$

But this condition has to be evaluated only when the variant is true, i.e., only when $i \leq m$, because as discussed above

$Invariant \land complement\text{-}of\text{-}condition \Longrightarrow Postcondition$

So the condition can be simplified further to look like

$i \neq m \land (i = m \text{ or } x \neq a[i,j])$

¹ i.e. 2 disjunctions
