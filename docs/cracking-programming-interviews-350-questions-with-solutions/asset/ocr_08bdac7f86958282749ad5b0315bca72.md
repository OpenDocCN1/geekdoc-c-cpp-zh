# *** Question 60	 type of decltype((auto variable))

What is the type of the expression *decltype((x))*, where *x* is an auto variable?

# Solution of Question 60

Type of the expression *decltype((x))* is const x &, where *x* is an auto variable.

For example, in the following example:

# Program 8.51: type of decltype((x))

```
void func()
{
    float x, &r = x;
    [=]
    {
        decltype(x) y1;
        decltype((x)) y2 = y1;
        decltype(r) r1 = y1;
        decltype((r)) r2 = y2;
    };
}
```

the type of y1 is float, y2 is float const &, r1 is float & and r2 is float const &.
