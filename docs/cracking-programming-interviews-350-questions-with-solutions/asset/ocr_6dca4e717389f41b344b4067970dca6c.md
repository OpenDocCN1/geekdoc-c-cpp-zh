# ** Question 80    operator new

Explain the following expressions with respect to the operator new[](std::size_t, void*);

+   1. new T
+   2. new(10, ptr) T
+   3. new T[20]
+   4. new(2, ptr) T[5]

# Solution of Question 80

+   1. new T results in a call of operator new(sizeof(T)),
+   2. new(10, ptr) T results in a call of operator new(sizeof(T), 10, ptr),
+   3. new T[20] results in a call of operator new[](sizeof(T)*20 + x)
+   4. new(10, ptr) T[50] results in a call of operator new[](sizeof(T)*50 + y, 10, ptr).

Here, x and y are non-negative unspecified values representing array allocation overhead; the result of the new-expression will be offset by this amount from the value returned by operator new[].
