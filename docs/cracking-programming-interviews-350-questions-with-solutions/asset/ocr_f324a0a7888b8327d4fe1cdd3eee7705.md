# Algorithm 99 Decimal Period Length

```
1:  m ← 0
2:  r ← 1
3:  while m ≠ n + 1 do
        what remains from 1/n after the decimal point is moved m positions to the right and the integral part is discarded
4:      r ← (10 × r) mod n
5:      m ← m + 1
6:  end while
7:  c ← r
8:  r ← (10 × r) mod n
9:  k ← 1
10: while r ≠ c do
        r = (n + k + 1)th term of the same sequence
11:     r ← (10 × r) mod n
12:     k ← k + 1
13: end while
```
