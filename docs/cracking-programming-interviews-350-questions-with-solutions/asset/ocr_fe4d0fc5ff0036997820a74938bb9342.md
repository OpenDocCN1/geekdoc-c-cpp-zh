So we need to some suitable condition for handling increase of $i$ as well. We can try $i \leftarrow i + 1$ but this is only possible till $i < m$ and it can maintain the invariant only if the $x \notin a[i, 0..n]$, so we can think of additional condition being $j == n \implies j = 0$ to maintain the condition on the $i^{th}$ row.
