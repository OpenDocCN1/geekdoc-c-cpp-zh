# Program 8.20: Unqualified Name Lookup

```
```cpp
#include <iostream>
int a = 10;
namespace outer
{
    int a = 20;
    namespace inner
    {
        int a = 30;
        void func();
    } // namespace inner
} // namespace outer

void outer::inner::func()
{
    // int a = 40;
    std::cout << "a = " << a << std::endl;
}

int main()
{
    outer::inner::func();
}
```
```

Discuss how the declaration of the variable *a* is being looked up when trying to use it within definition of the function *func*.

# Solution of Question 19

The output is:

```
```text
a : 30
```
```

The following scopes are searched in the given order for a declaration/definition of the variable *a*:

+   1. The first is the outermost block scope of `outer::inner::func`, before the use of `a`, i.e., if line number 20 is commented out, then it is the first place where lookup is done. In this case the output will be 40.
+   
+   2. Next is the scope of the namespace `inner` (line number 11), as illustrated by the output being 30.
+   
+   3. Next is the scope of the namespace `outer`, i.e., if the line numbers 20 and 11 do not declare/define `a`, then due to line 7, the output will be 20.
