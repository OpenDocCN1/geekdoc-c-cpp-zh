# Program 1.25: Using Saddleback Count : Count of 6 should be 6

```
```cpp
#include "saddleback_count.hpp"
#include <iostream>

int main()
{
    TwoDimArray<4, 4> a = {
                              2, 2, 3, 5,
                              3, 4, 5, 6,
                              3, 5, 6, 6,
                              3, 6, 6, 9
                          };

    size_t count
        = saddleback_count<4, 4>(a, 6);

    std::cout << "Count of 6 is: "
              << count << std::endl;
}
```
```

This too prints : Count of 6 is: 3 which is wrong because it should print : Count of 6 is: 6.

As an astute reader, you can figure out that ordering of rows and columns plays a key role here. Saddleback search has to locate such an occurrence, more precisely, the occurrence with the smallest value of the row index and at the same time the occurrence with the smallest value of the column index as well.
