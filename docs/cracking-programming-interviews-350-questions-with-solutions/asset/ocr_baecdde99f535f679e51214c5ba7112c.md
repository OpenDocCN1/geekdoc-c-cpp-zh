# 1.15 Constant Time Range Query

# Problem

Describe an algorithm that, given n integers in the range 0 to k, processes its input and then answers any query about how many of the n integers fall into a range [a..b] in O(1) time. The algorithm should use Θ(n + k) preprocessing time.

# Solution

Compute the C array as is done in counting sort described below.

Counting sort assumes that each of the n input elements is an integer in the range 0 to k, for some integer k. When k = O(n), the sort runs in Θ(n) time.

The basic idea of counting sort is to determine, for each input element x, the number of elements less than x. This information can be used to place element x directly into its position in the output array.
