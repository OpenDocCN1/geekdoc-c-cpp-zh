# **Algorithm 22** Saddleback Search Algorithm

```
1. PreCondition : x ∈ a[0..m − 1, 0..n − 1]
2. PostCondition : 0 ≤ i ≤ m − 1 && 0 ≤ j ≤ n − 1 && x = a[i, j]
3. function SADDLEBACK-SEARCH(a[0..m-1, 0..n-1], x)
4.     i ← 0
5.     p ← m − 1
6.     q ← 0
7.     j ← n − 1
8.     Invariant : 0 ≤ i ≤ p ≤ m − 1 && 0 ≤ q ≤ j ≤ n − 1 && x ∈ a[i..p, q..j]
9.     while x ≠ a[i, j] do
10.        if a[i, j] < x then
11.            i ← i + 1
12.        end if
13.        if a[p, q] > x then
14.            p ← p − 1
15.        end if
16.        if a[p, q] < x then
17.            q ← q + 1
18.        end if
19.        if a[i, j] > x then
20.            j ← j − 1
21.        end if
22.    end while
23. end function
```
