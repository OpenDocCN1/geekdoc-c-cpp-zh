# Algorithm 73 Selecting a c-approximate median of X with O(n) complexity

```
1: function GET-C-APPROXIMATE-MEDIAN(X)
2:   n <- |X_0|
3:   l <- 1
4:   r <- 2n
5:   i <- 0
6:   while |X_i| >= C do
7:     Y_i <- MUT-AND-BOLT-E-HALVE(X_i)
8:     B <- BACK-TRACK(Y_i, i, Z)
9:     Z <- FIND-MISPLACED-ELEMENTS(Y_i, i, n/2^i)
10:    if i is odd then
11:      r <- ((l+r)/2)
12:    else
13:      l <- ((l+r)/2)
14:    end if
15:    i <- i + 1
16:    X_i <- Y_{i-1}[l, r] U Z U B
17:  end while
18:  return X_i
19: end function
```

# Algorithm 74 Back-Tracking

```

2:   if i <= 2 then
3:     return 0
4:   end if
5:   if i is even then
6:
    for any members of Z that are in the right half of Y find
    all members of all of the left fringes that are supported ex-
    clusively by these members of Z or other active elements.
    Put these candidate illicitly supported elements in B.
7:   else
8:
    for any members of Z that are in the left half of Y find all
    members of all of the right fringes that are supported ex-
    clusively by these members of Z or other active elements.

9:   end if
10:  return B
```
