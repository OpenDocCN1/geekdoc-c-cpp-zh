# Program 12.15: static member initialization scope

```
```cpp
#include <iostream>

int a = 10;

struct X
{
    static int a;
    static int b;
};

int X::a = 20;
int X::b = a;

int main()
{
    std::cout << X::b << std::endl;
}
```
```

# Solution of Question 166

It prints *20*.

Because an initializer for a static member is in the scope of the member's class.

Hence the following two are equivalent:

```
```cpp
int X::b = a;

int X::b = X::a;
```
