# ### Solution

```
~~~
Algorithm 94 Decimal Representation
1: base ← 1
2: while 10 × base ≤ n do     ▷ base is an integer power of 10 not exceeding n
3:     base ← base × 10
4: end while
5: k ← n                    ▷ base is a maximal power of 10 not exceeding n
6: while base ≠ 1 do         ▷ invariant relation: it remains to print k with the same number of digits as in base; base = 100...00
7:     print(k ÷ base)
8:     k ← k mod base
9:     base ← base ÷ 10
10: end while
11: write(k)                ▷ base = 1; it remains to write one digit k
~~~
```

Please note that this program assumes that n > 0. A typical mistake while solving this problem is that the numbers with zeros in the middle are printed incorrectly. The invariant relation mentioned above allows the case k < base; in this case, the decimal representation of k begins with zero.

# ### 6.18 Reverse Decimal Representation

# ### Problem Description

Write a program that prints the decimal representation of a positive integer n in reverse. (For n = 173, the program should print 371.)

# ### Solution

```
~~~
Algorithm 95 Reverse Decimal Representation
1: k ← n
2: while k ≠ 0 do ▷ invariant relation: it remains to print k reversed
3:     print(k mod 10)
4:     k ← k ÷ 10
5: end while
~~~
```
