# Algorithm 25 Saddleback Search Algorithm: Find All Occurrences

```
1: function SADDLEBACK-FINDALL(a[0..m-1, 0..n-1], x)
2:     i ← 0
3:     j ← n − 1
4:     current_col_index ← j
5:     List < Pair <rowindex, columnindex> > list_indices
6:     while j ≤ n − 1 do
7:         if a[i, j] < x then
8:             i ← i + 1
9:         else if a[i, j] > x then
10:            j ← j − 1
11:        else if a[i, j] == x then
12:            current_col_index ← j
13:            while current_col_index ≥ 0 and
14:                  a[i][current_col_index] == x do
15:                list_indices.insert(Pair<rowindex, columnindex>(i,
16:                    current_col_index))
17:                current_col_index ← current_col_index − 1
18:            end while
19:            i ← i + 1
20:        end if
21:    end while
22: end function
```

Key thing to notice here is how to start the next search after first occurrence is reported, say a[i, j] ?

If x is equal to a[i, j] for a given row index i and column index j, then it is obvious that these correspond to smallest values of row and column indices. Our algorithm developed for finding the first occurrence ends up traversing the path from the last most to first most in a given row, so all we need to do is to record this path and march towards the next row.
