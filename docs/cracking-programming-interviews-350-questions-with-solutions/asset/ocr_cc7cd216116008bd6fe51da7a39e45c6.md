```cpp
#include "saddleback_search_first.hpp"
#include <iostream>

int main()
{
    TwoDimArray<4, 4> a = {
                              2, 2, 3, 5,
                              3, 4, 6, 6,
                              3, 5, 6, 6,
                              3, 6, 6, 9
                            };

    Point p
        = saddleback_search_first<4, 4>(a, 6);

    std::cout << "6 is found at : a["
              << p.first << "]["
              << p.second << "]"
              << std::endl;
}
```
```

It prints:

> 6 is found at : a[1][2]

First part of this algorithm uses original saddleback search whose complexity is $O(n + m)$. Second part involves linear search in backward dimension in the given row $O(n)$. Hence time complexity of *Saddleback Search - Find First Occurrence* is $O(n + m)$. Please note that second part of this algorithm can be accomplished using binary search. We leave this as an exercise to the reader.
