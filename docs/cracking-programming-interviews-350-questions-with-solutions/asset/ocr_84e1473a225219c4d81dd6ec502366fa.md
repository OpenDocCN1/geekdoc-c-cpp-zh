# **Question 123**    using unnamed namespace

What is the output of the program?

Program 11.1: using unnamed namespace

```
#include <iostream>
namespace A
{
    namespace
    {
        int x;
        int y;
    }

    void func()
    {
        ++x;
    }
} // namespace A

int main()
{
    using namespace A;

    A::func();

    ++x;

    A::x++;

    ++y;

    std::cout << "x : " << x
              << "\ny : " << y
              << std::endl;
}
```

# Solution of Question 123

```
x : 3
y : 1
```
