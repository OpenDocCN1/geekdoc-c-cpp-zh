# 1.3. Unique 5-bit Sequences

$P_1$: $good(s) \land \neg good(s \mid 0) \land 5 \le |s| \land 0 \le s_n \le 00001A$. All good sequences $s$, $|s|$ are printed.

Sequence $s$ with $n$ bits could be represented by a bit array. However, it is better to represent $s$ by an integer array $c[4..n-1]$, where $c[i]$ is the decimal representation of the 5-bit subsequence of $s$ ending in bit $i$. Thus, we will maintain that part of the invariant of the main loop the assertion

$P_2$: $[i \le n \Rightarrow s[i] \le 36 \land c[i] = s[i-4] \times 2^4 + s[i-3] \times 2^3 + s[i-2] \times 2^2 + s[i-1] \times 2 + s[i]]$, for $4 \le i < n$

Further, in order to keep track of which 5-bit subsequence $s$ contains, we use a Boolean array $in[0..31]$:

$P_3$: $i: 0 \le i < 32 : in[i] = (i \in c[4..n-1])$

With this introduction, the program should be easy to follow.

# Algorithm 2  Unique 5-bit Sequence Program

```
```text
 1: n ← 5
 2: c[4] ← 0
 3: in[0] ← T
 4: in[1..31] ← F                         ▷ s = (0, 0, 0, 0)
 5: invariant: P₁ ∧ P₂ ∧ P₃ ∧ ¬good(s | 0)
 6: while c[4] ≠ 1 do
 7:     if n = 36 then
 8:         Print sequence s
 9:     else if n ≠ 36 then
10:         skip
11:     end if
12:     Change s to next higher good sequence:
13:     while in[((n − 1) × 2 + 1) mod 32] do       ▷ i.e. ¬good(s | 1)
14:         Delete ending 1's from s:
15:         while odd(c[n − 1]) do
16:             n ← n − 1
17:             in[c[n]] ← F
18:         end while
19:         Delete ending 0.
20:         n ← n − 1
21:         in[c[n]] ← F
22:     end while
23:     Append 1 to s:
24:     c[n] ← (c[n − 1] × 2 + 1) mod 32
25:     in[c[n]] ← T
26:     n ← n + 1
27: end while
