# Program 13.13: destructor

```
```cpp
#include <iostream>

struct B
{
    virtual ~B()
    {
        std::cout << "B::~B()" << std::endl;
    }
};

struct D : B
{
    ~D()
    {
        std::cout << "D::~D()" << std::endl;
    }
};

int main()
{
    D d;
    typedef B B1;

    B* bptr = &d;

    d.B::~B();

    bptr->~B();

    bptr->~B1();

    bptr->B1::~B();

    bptr->B1::~B1();
}
```

# Solution of Question 193

```
```
B::~B()
B::~D()
B::~D()
B::~B()
B::~B()
B::~D()
B::~B()
```

+   - `bptr->~B();` calls D’s destructor
