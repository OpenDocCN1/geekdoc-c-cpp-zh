$(1+1, 2+1, \ldots, k+1)$

which therefore has a sum equal to

$\frac{k(k+1)}{2}+1\times k$

And thus we observe that $N$ can be written as the sum of $k$ consecutive positive integers if and only if

$N-\frac{k(k+1)}{2}$

is a non-negative multiple of $k$.

So, here is the program:

# **Algorithm 47** Write as sum of consecutive positive numbers

```
1:  k ← 1
2:  e ← N − 1                         ▷ e = N − k(k+1)/2
3:  C ← 0
4:  while e ≥ 0 do
5:      if e mod k = 0 then
6:          C ← C + 1
7:      else if e mod k > 0 then
8:          skip
9:      end if
10:     k ← k + 1
11:     e ← e − (k + 1)
12: end while
13: print(C)
```
