# ## 2.20 Re-arranging an array

# ### Problem

An array a[1..n] and a threshold b are given. Rearrange the elements
of the array in such a way that all elements on the left of some bound-
ary do not exceed b whereas all elements on the right of the boundary
are greater than or equal to b. The number of operations should be
proportional to n.

# ### Solution

# **Algorithm 57 Re-arranging an array**

```
    1: function REARRANGE-ARRAY(a[1..n], b)
    2:     l ← 0
    3:     r ← n
    4:     Invariant : l ≤ r; a[1..l] ≤ b; a[r+1..n] ≥ b
    5:     while l ≠ r do
    6:         if a[l+1] ≤ b then
    7:             l ← l+1
    8:         else if a[r] ≥ b then
    9:             r ← r−1
    10:        else
    11:            swap(a[l+1], a[r])        ▷ a[l+1] > b; a[r] < b; l+1 < r;
    12:            l ← l+1
    13:            r ← r−1
    14:        end if
    15:    end while
    16: end function
```
