# Solution of Question 11

The following member functions definitions are implicitly generated by the compiler:

+   1. default constructor

```
A() : _str() { }
```

+   2. copy constructor

```
A(const A & a): _str(a._str) { }
```

+   3. move constructor

```
A(A&& a)
:
_str(static_cast<std::string&&>(a._str))
{ }
```

or,

```
A(A&& a)
:
_str(std::move(a._str)) { }
```

+   4. copy assignment operator

```
A& operator=(const A& a)
{
    _str = a._str;
    return *this;
}
```
