# Solution of Question 47

The hierarchy of values associated with an expression looks like:

![](bbox=[0.102, 0.111, 0.798, 0.302])

Figure 8.1: Expression Value Category Taxonomy

+   1. *lvalue*: This name came because earlier meaning was associated with its appearance in the left-hand side of an assignment.
+      - An *lvalue* designates a function or an object.
+      - If *ptr* is a pointer to an object or a function, then `*ptr` is an *lvalue* expression.
+      - The result of calling a function whose return type is an *lvalue* reference is an *lvalue*.
+   
+   2. *xvalue*: It stands for an *expiring value*.
+      - The result of calling a function whose return type is an *rvalue* reference is an *xvalue*.
+      - It refers to an object, usually near the end of its lifetime, so that its resources may be moved.
+   
+   3. *glvalue*: It stands for *generalized lvalue*. Thus it refers to either an *lvalue* or *xvalue*. glvalues can also have incomplete types.
+   
+   4. *rvalue*: This name came because earlier meaning was associated with its appearance in the right-hand side of an assignment.
+   
+      It is:
+      - an xvalue
+      - a temporary object
+      - a subobject
+      - a value that is not associated with an object.
+   
+   5. *prvalue*: It stands for *pure rvalue*, i.e., an rvalue that is not an xvalue.
