# ### Complexity

The regular algorithm requires $O(\log n)$ steps to eliminate elements with one pivot. Since we can generate $O(\log n)$ pivots at about the same time, we save a factor of $O(\log\log\log n)$ overall. The expected running time is reduced to $O\left(\frac{\log^2 n}{\log\log n}\right)$.
