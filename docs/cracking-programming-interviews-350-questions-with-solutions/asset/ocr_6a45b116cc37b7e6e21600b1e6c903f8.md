# 1.24 The problem of the most isolated villages

# Problem Description

We consider *n* villages (*n* > 1), numbered from 0 through *n* − 1; for 0 ≤ *i* < *n* and 0 ≤ *j* < *n*, a computable function *f*(*i*, *j*) is given, satisfying for some given positive integer *M*:

for *i* ≠ *j*: 0 < *f*(*i*, *j*) < *M*  
for *i* = *j*: *f*(*i*, *j*) = *M*

For the *i*th village, its isolation degree *id*(*i*) is given by

*id*(*i*) = minimum {*f*(*i*, *j*)}

Here *f*(*i*, *j*) can be interpreted as the distance from *i* to *j*; the rule *f*(*i*, *j*) = *M* has been added for the purpose of the above simplification.

We are requested to determine the set of maximally isolated villages, i.e. the set of all *k* such that

∀*h*: 0 ≤ *h* < *n*: *id*(*h*) ≤ *id*(*k*)

The program is expected to deliver this set of values as

*miv*(*miv.lob*), ..., *miv*(*miv.hib*)

Note that eventually all values 1 ≤ *miv.dom* ≤ *n* are possible.

A very simple and straightforward program computes the isolation degrees in succession and keeps track of their maximum value found thus far. On account of the bounds for *f*(*i*, *j*) we can take as the minimum of an empty set the value *M* and as the maximum of an empty set 0.
