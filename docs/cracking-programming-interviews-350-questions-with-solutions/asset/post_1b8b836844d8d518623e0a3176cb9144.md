## Question 126 namespace alias

What is namespace alias?

### Solution of Question 126

A namespace alias, say B, declares an alternate name for a given namespace, say A, like the following:

```cpp
namespace A {}
namespace B = A;
```

### Program 11.4: namespace alias

```cpp
#include <cassert>
namespace long_name_123456789
{
    int i = 10;
} // namespace long_name_123456789

namespace short_name1 = long_name_123456789;
int main()
{
    assert(short_name1::i ==
        long_name_123456789::i);
}
```

Please note that namespace alias is a synonym for the actual namespace, but when looking up a namespace-name in a namespace-alias-definition, only namespace names are considered.

## Question 131 using declaration and refer members

Review the code below.

### Program 11.12: using declaration and referring members

```cpp
void f();

namespace A
{
    void g();
}

namespace B
{
    using ::f;
    using A::g;
}

void h()
{
    B::f();
    B::g();
}
```

### Solution of Question 131

In namespace B, using ::f calls the global f. using A::g calls A’s g. In the function h(), B::f() calls the global f, B::g() calls A::g. In short, members declared by a using-declaration can be referred to by explicit qualification just like other member names and in a using-declaration, a prefix :: refers to the global namespace.

## Question 133 availability of using declaration

Review the code below.

### Program 11.14: availability of using declaration

```cpp

 2 {
 3     void f(int);
 4 }
 5

 7
```

### Solution of Question 133
