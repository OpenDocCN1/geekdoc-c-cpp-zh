+   1. \({Tr(i,j)}\; X \cdot swap(i,j);\; i \leftarrow i+1,\; j \leftarrow j+1\; {Tr(i,j)}\) as the mechanism to move the train to the right, and hence
+   2. \({Tr(i,j)}\; i \leftarrow i-1,\; j \leftarrow j-1;\; X \cdot swap(i,j)\; {Tr(i,j)}\) as the mechanism to move to the left;
+   3. \({Tr(i,j)\text{ and }i<j}\; i \leftarrow i+1\; {(X[i-1]\text{ is red})\text{ and }Tr(i,j)}\) as the procedure to uncouple a wagon at the left end of the train, and hence
+   4. \({Tr(i,j)\text{ and }(X[i-1]\text{ is red})}\; i \leftarrow i-1\; {i<j\text{ and }Tr(i,j)}\) as the procedure to couple a wagon at the left end.

With the abbreviations

\[
P(r): 0 \leq r < R\text{ and }(0 \leq k < r : X[k] \times M\text{ is red})
\]
\[
Q(j): j \leq h < N : X[h]\text{ is blue},
\]

the program, which is somewhat lavishly annotated is as follows:

# Algorithm 49 Butlerman's Reshuffling Problem

```
1:  i, j, r := 0
2:  i := N
3:  r := N
4:  {Tr(i, j)} ∪ {Q(j)} {0 ≤ i ≤ j ≤ N}
5:  while i ≠ 0 do                                      ▷ i > 0
6:      if X[i − 1] is red then
7:          i ← i − 1                                      ▷ See (4)
8:      else if X[i − 1] is blue then
9:          j ← j − 1
10:         j ← j − 1
11:         X := swap(i, j)                                ▷ See (2)
12:     end if
13:     {Tr(i, j)} ∪ {Q(j)} {i ≤ j ≤ N}
14: end while                                          ▷ Tr(i, j) and Q(j), and i = 0, hence j = R
15: r ← 0                                               ▷ {Tr(i, j)} ∪ {Pr(r)} {j = R − r + i} ∪ {i ≤ r × M}
16: while r ≠ R do ▷ r < R ▷ {Tr(i, j), j = R − r + i, i ≤ r × M}
17:     while j ≠ r × M do                         ▷ j < r × M, hence j < N
18:         X := swap(i, j)
19:         i ← i + 1
20:         j ← j + 1                              ▷ {Tr(i, j), see (1), j = R − r + i, i ≤ r × M}
21:     end while ▷ Tr(i, j) and j = R − r + i and r < R, hence Tr(i, j)
    and i < j, hence X[i] is red, i = r × M, P(r)
22:     i ← i + 1
23:     r ← r + 1                                  ▷ Tr(i, j), see (3), P(r), j = R − r + i, i ≤ r × M
24: end while                                      ▷ P(r) and r = R, hence Z
```
