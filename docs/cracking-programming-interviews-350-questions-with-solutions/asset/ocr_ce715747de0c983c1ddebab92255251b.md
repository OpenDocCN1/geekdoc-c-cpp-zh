The entity declared by a using-declaration should be known in the context using it according to its definition at the point of the using-declaration. Definitions added to the namespace after the using-declaration are not considered when a use of the name is made.

# **Question 134** using declaration and same functions

Review the code below.

Program 11.15: using declaration and same functions

```
    1 namespace B
    2 {
    3     void f(int);
    4     void f(double);
    5 }

# Solution of Question 134

Compiler error is:

```
    using8.cpp:19:5: error: call to 'f' is ambiguous
        f(1);
        ^
    using8.cpp:3:10: note: candidate function
        void f(int);
             ^
    using8.cpp:9:10: note: candidate function
        void f(int);
             ^
