# Solution of Question 12

In the first program, the output is *Inside_Base::Base(int)*

In the second program, the output is *Inside_Base::Base(int, int)*

In both of these programs, the class Derived's default constructor is implicitly defined, but this definition D() calls Base(int) in one case and calls Base(int, int) in another case.
