# STL style partitioning

Program 6.9: STL style implementation of partition

```
```cpp
#include <iostream>
#include <algorithm>

template <typename RandomIter>
RandomIter partition(RandomIter l,
                     RandomIter r)
{
    for (RandomIter j = l; j != r; j++)
    {
        if (*j <= *r)
        {
            std::iter_swap(l++, j);
        }
    }
    std::iter_swap(l, r);

    return l;
}
