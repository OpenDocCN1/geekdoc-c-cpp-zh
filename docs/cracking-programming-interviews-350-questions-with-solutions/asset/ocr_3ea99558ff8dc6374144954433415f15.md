# 1.23. The problem of the balanced segments

In checking the program below the reader is suggested to check the invariances of $P_1$, $P_2$, and $P_3$ in succession. One hint is given for the invariance of $P_3$.

```
~~~text
 1: n, d, m, M : int
 2: C(i): −N ≤ i ≤ N): array of int
 3: n ← 0; d ← 0; m ← −1; M ← 1; C(0) ← 0; r ← 0
 4: while n ∉ N do
 5:     if X(n) == 0 then
 6:         d ← d + 1
 7:     else if X(n) == 1 then
 8:         d ← d − 1
 9:     end if
10:     if m < d ∧ d < M then
11:         skip
12:     else if m == d then                 ▷ P₁(n + 1/n) ∧ P₂ ∧ P₃ ∧ m = d
13:         C(m) ← n + 1
14:         m ← m − 1                         ▷ P₃(n + 1/n)
15:     else if M == d then
16:         C(M) ← n + 1
17:         M ← M + 1
18:     end if
19:     n ← n + 1
20:     r ← r max (n − C(d))
21: end while
22: print(r)
~~~
```

# Hint

$$\operatorname{wp}\{C(m) = n + 1;\ m \leftarrow m - 1,\ P_3(n+1/n)\}$$
$$= \{P_3(n+1/n)\}$$

$$\operatorname{wp}\{C(m) = n + 1;\ k \leftarrow m - 1,\ P_3\}$$
$$= \{\text{definition of }P_3,\text{ and predicate calculus}\}$$

$P_3 \land m+1 =$ the minimum solution of $h: 0 \le h \land D(h)=m$

$$\Longleftrightarrow \{\text{from }P_2,\ (h: 0 \le h+1 \land D(h) \ne m)\}$$

$P_2 \land P_3 \land m+1 =$ the minimum solution of $h: n+1 \le h \land D(h)=m$

implies $P_2 \land P_3 \land m=d \land n+1$ is the minimum solution of $h: n+1 \le h \land D(h)=d$

$$\Longleftrightarrow \{\text{from }P_1(n+1/n),\ d=d(n+1)\}$$

$$P_1(n+1/n) \land P_2 \land P_3 \land m=d$$
