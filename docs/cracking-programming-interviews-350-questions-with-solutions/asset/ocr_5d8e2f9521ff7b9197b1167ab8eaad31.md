Because func is not a member of A, that’s why this is in error. To correct it, the program may be modified to look like:

# Program 8.36: declaration and nested namespace

```
#include <iostream>
namespace A
{
    namespace B
    {
        void func();
    } // namespace B

    using namespace B;
} // namespace A

using namespace A;
void B::func() {}
```

So qualifying with :: is strictly applicable to direct belonging of a member to that scope.
In this case, we can even drop the :: for defining it like:

# Program 8.37: declaration and nested namespace

```
#include <iostream>
namespace A
{
    namespace B
    {
        void func();
    } // namespace B

    using namespace B;
} // namespace A

using namespace A;
void func() {}
```
