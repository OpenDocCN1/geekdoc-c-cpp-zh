# Solution of Question 26

Modified program looks like

# Program 8.27: ADL

```
```cpp
#include <iostream>
namespace A
{
    struct B {};

    void func(B b)
    {
        std::cout << "A::func" << std::endl;
    }
} // namespace A
void func(A::B b)
{
    std::cout << "func(A::B)" << std::endl;
}

void test()
{
    A::B b1;

    extern void func(A::B);

    func(b1);
}

int main()
{
    test();
}
```
```

Now the output looks like

```
```text
func(A::B)
```
