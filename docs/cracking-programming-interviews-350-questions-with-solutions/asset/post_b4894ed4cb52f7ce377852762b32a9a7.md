## Question 16: scope of template parameters

Can a template parameter be used in the declaration of subsequent template parameters and their default arguments ?

### Solution of Question 16

Yes.

A template parameter can be used in the declaration of subsequent template parameters and their default arguments.

For example,

```cpp
1 template<typename T1, T1* ptr , typename T2 = T1>
2 struct A {};
3
4 template<typename T> void alloc_memory(T* ptr = new T);
```

Please note that a template parameter can be used also in the specification of base classes, like

```cpp
1 template<typename T>
2 struct Base {};
3
4 template<typename T>
5 struct Derived : Base<T> { };
6
7 template<typename T>
8 struct A : T { };
```

The use of a template parameter as a base class implies that a class used as a template argument must be defined and not just declared when the class template is instantiated.

### Program 8.20: Unqualified Name Lookup

```cpp

int a = 10;

{
    int a = 20;
    namespace inner
    {
        int a = 30;
        void func();
    } // namespace inner
} // namespace outer
```

Discuss how the declaration of the variable *a* is being looked up when trying to use it within definition of the function *func*.

### Solution of Question 19

The output is:

```text
a = 30
```

The following scopes are searched in the given order for a declaration/definition of the variable *a*:

- 1. The first is the outermost block scope of `outer::inner::func`, before the use of `a`, i.e., if line number 20 is commented out, then it is the first place where lookup is done. In this case the output will be 40.
- 2. Next is the scope of the namespace `inner` (line number 11), as illustrated by the output being 30.
- 3. Next is the scope of the namespace `outer`, i.e., if the line numbers 20 and 11 do not declare/define `a`, then due to line 7, the output will be 20.
