illustrates two ways that a named iterator can be used to obtain elements. One enumerates a range of elements given the endpoints. The other enumerates the elements beginning at the start of the sequence and ending at the specified stopping point.

```
// Use named iterators.
using System;
using System.Collections;

class MyClass {
    char ch = 'A';

    // This iterator returns the letters
    // of the alphabet, beginning at A and
    // stopping at the specified stopping point.
    public IEnumerable MyItr(int end) {
        for(int i=0; i < end; i++)
            yield return (char) (ch + i);
    }

    // This iterator returns the specified
    // range of letters.
    public IEnumerable MyItr(int begin, int end) {
        for(int i=begin; i < end; i++)
            yield return (char) (ch + i);
    }
}

class ItrDemo4 {
    static void Main() {
        MyClass mc = new MyClass();

        Console.WriteLine("Iterate the first 7 letters:");
        foreach(char ch in mc.MyItr(7))
            Console.Write(ch + " ");

        Console.WriteLine("\n");

        Console.WriteLine("Iterate letters from F to L:");
        foreach(char ch in mc.MyItr(5, 12))
            Console.Write(ch + " ");

        Console.WriteLine();
    }
}
```

The output is shown here:

```
Iterate the first 7 letters:
A B C D E F G

Iterate letters from F to L:
F G H I J K L
```
