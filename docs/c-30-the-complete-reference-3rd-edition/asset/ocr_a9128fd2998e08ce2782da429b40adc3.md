Notice that the handler is added using the += operator. Events support only += and -=. In this case, Handler() is a static method, but event handlers can also be instance methods. Finally, the event is fired as shown here:

```
// Fire the event.
evt.OnSomeEvent();
```

Calling OnSomeEvent() causes all registered event handlers to be called. In this case, there is only one registered handler, but there could be more, as the next section explains.
