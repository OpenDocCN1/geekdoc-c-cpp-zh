The conversion from int to Nibble allows a Nibble object to be assigned an int value. For example, in the program, the statement

```
a = 19;
```

works like this. The conversion operator from int to Nibble is executed. This causes a new Nibble object to be created that contains the low-order 4 bits of the value 19 (which is 3 because 19 overflows the range of a Nibble). This object is then assigned to a. Without the conversion operators, such expressions would not be allowed.

The conversion of Nibble to int is also used by the for loop. Without this conversion, it would not be possible to write the for loop in such a straightforward way.
