# For Further Study

C# 3.0: The Complete Reference is your gateway to the Herb Schildt series of programming books. Here are some others that you will find of interest.

For a carefully paced introduction to C#, try

+   - *C# 3.0: A Beginner's Guide*

To learn about Java programming, we recommend the following:

+   - *Java: The Complete Reference*
+   - *Java: A Beginner's Guide*
+   - *Swing: A Beginner's Guide*
+   - *The Art of Java*
+   - *Herb Schildt's Java Programming Cookbook*

To learn about C++, you will find these books especially helpful:

+   - *C++: The Complete Reference*
+   - *C++: A Beginner's Guide*
+   - *C++ From the Ground Up*
+   - *STL Programming From the Ground Up*
+   - *The Art of C++*
+   - *Herb Schildt's C++ Programming Cookbook*

If you want to learn about the C language, the foundation of all modern programming, the following title will be of interest:

+   - *C: The Complete Reference*
