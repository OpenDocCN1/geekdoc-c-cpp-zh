In the program, notice that when AreaPerPerson() is called, it is put on the right side of an assignment statement. On the left is a variable that will receive the value returned by AreaPerPerson(). Thus, after

`areaPP = house.AreaPerPerson();`

executes, the area-per-person of the house object is stored in areaPP.

Notice that the AreaPerPerson() now has a return type of int. This means that it will return an integer value to the caller. The return type of a method is important because the type of data returned by a method must be compatible with the return type specified by the method. Thus, if you want a method to return data of type double, then its return type must be type double.
