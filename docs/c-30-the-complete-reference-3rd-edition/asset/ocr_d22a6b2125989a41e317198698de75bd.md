```
// A form-based Windows Skeleton.
using System;
using System.Windows.Forms;

// WinSkel is derived from Form.
class WinSkel : Form {
    public WinSkel() {
        // Give the window a name.
        Text = "A Windows Skeleton";
    }
    // Main is used only to start the application.
    [STAThread]
    static void Main() {
        WinSkel skel = new WinSkel(); // create a form
        // Enable visual styles.
        Application.EnableVisualStyles();
        // Start the window running.
        Application.Run(skel);
    }
}
```

The window created by this program is shown in Figure 26-1. Let’s examine this program line-by-line. First, notice that both System and System.Windows.Forms are included. System is needed because of the STAThread attribute that precedes Main(). System.Windows.Forms supports the Windows Forms subsystem, as just explained.

Next, a class called WinSkel is created. It inherits Form. Thus, WinSkel defines a specific type of form. In this case, it is a minimal form.

Inside the WinSkel constructor is the following line of code:

```
Text = "A Windows Skeleton";
```

Text is the property that sets the title of the window. Thus, this assignment causes the title bar in the window to contain A Windows Skeleton. Text is defined like this:

```
public override string Text { get; set; }
```
