# The if-else-if Ladder

A common programming construct that is based upon the nested if is the if-else-if ladder.

It looks like this:

```
if(condition)
    statement;
else if(condition)
    statement;
else if(condition)
    statement;
    .
    .
    .
else
    statement;
```

The conditional expressions are evaluated from the top downward. As soon as a true condition is found, the statement associated with it is executed, and the rest of the ladder is bypassed.
