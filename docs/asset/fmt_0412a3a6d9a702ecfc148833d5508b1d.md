计数控制循环需要：

- 控制变量的初始值，
- 每次迭代中用于修改控制变量的增量（或减量），

考虑图 4.1，它显示了从 1 到 5 的数字。定义 `int counter = 1; // initialization` 命名了控制变量（`counter`），将其定义为整数，为其预留内存空间，并将其初始值设置为 1。

```c
// fig04_01.c
// 计数控制循环。
#include <stdio.h>
int main(void) {
    int counter = 1; // 初始化
    while (counter <= 5) { // 迭代条件
        printf("%d, ", counter);
        ++counter; // 增量
    }
    puts("\n");
}
```
