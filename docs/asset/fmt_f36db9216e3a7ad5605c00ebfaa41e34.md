我们现在准备好开发额外的方法来执行显式操作，例如矩阵加法和减法。注意，由于其本质，只有当两个矩阵具有相同的行数和列数时，才能与其他矩阵进行加法或减。因此，为了执行矩阵加法和减法，开发方法来重写两个 `m × n` 矩阵 `A` 和 `B` 的默认 `A+B` 将是有帮助的，其计算方法所示。

`C_{i,j} = (A+B)_{i,j} = A_{i,j} + B_{i,j}` 其中 `1 ≤ i ≤ m` 和 `1 ≤ j ≤ n`。

```csharp

    return m;
}

public static RMatrix operator +(RMatrix m1, RMatrix m2)

        throw new Exception("The dimensions of two matrices must be the same!");
```

矩阵乘法有两种形式。矩阵 `A` 与数字 `c` 的标量乘法通过将 `A` 的每一个元素乘以 `c` 来给出：

> `$cA = cA_{i,j}$`

虽然矩阵除法没有定义的定义，但你仍然可以将矩阵乘以一个分数标量（例如 `1/c`），这可以影响并收缩矩阵中的每一个元素。

> `$(1/c)A = (1/c)A_{i,j}$`

矩阵乘法的第二种形式是矩阵之间的相乘。两个矩阵 `A` 和 `B` 的矩阵乘积是另一个矩阵 `C`，其中 `C=AB`，其元素在形式上的定义如下。对于 `A ∈ R^{m × n}, B ∈ R^{n × p}`，那么 `(AB) ∈ R^{m × p}`，

> `$(C)_{i,j} = (AB)_{i,j} = \sum_{k=1}^{n} A_{i,k}B_{k,j}$`

对于每一对满足 `1 ≤ i ≤ m` 和 `1 ≤ j ≤ p` 的 `i` 和 `j`。由于这个定义，矩阵乘法不满足交换律，这意味着 `AB ≠ BA`。矩阵乘法可以通过如下方式实现。

```c
public static RMatrix operator * (RMatrix m1, RMatrix m2)
{
    if (m1.GetCols() != m2.GetRows)
    {
        throw new Exception("The numbers of columns of the " + 
        " first matrix must be equal to the number of " + 
        " rows of the second matrix!");
    }
    double tmp;
    RMatrix result = new RMatrix(m1.GetRows, m2.GetCols());
    for (int i = 0; i < m1.GetRows; i++)
    {
        for (int j = 0; j < m2.GetCols(); j++)
        {
            tmp = result[i, j];
            for (int k = 0; k < result.GetRows; k++)
            {
                tmp += m1[i, k] * m2[k, j];
            }
            result[i, j] = tmp;
        }
    }
    return result;
}
```

使用乘法并将向量视为 `n × 1` 矩阵，点积也可以写成：

`A^T · B`

其中 `A^T` 表示矩阵 `A` 的转置，通过以下任何等效操作创建：

- 将 `A` 的行写入 `A^T` 的列

- 将 `A` 的列写入 `A^T` 的行

- 通过其主对角线（从左上角开始）反射 `A`

在这种特定情况下，由于 `A` 是列矩阵，它的转置是一个 `1 × n` 矩阵。更正式地说，`n × m` 矩阵 `A` 的转置是 `m × n` 矩阵 `A_{ij}^T = A_{ji}`，对于 `1 ≤ i ≤ n, 1 ≤ j ≤ m`。

```c
RMatrix GetTranspose()
{
    RMatrix m = this;
    m.Transpose();
    return m;
}

void Transpose()
{
    RMatrix m = new RMatrix(nCols, nRows);
    for (int i = 0; i < nRows; i++)
    {
        for (int j = 0; j < nCols; j++)
        {
            m[j, i] = matrix[i, j];
        }
    }
    this = m;
}
```

`n × n` 方阵 `A` 的迹定义为其主对角线（从左上角到右下角）元素之和，在数学上可以表示为：

`tr(A) = a_{11} + a_{22} + … + a_{nn} = \sum_{i=1}^{n} a_{ii}`

其中 `a_{i,j}` 代表矩阵 `A` 的第 `i` 行第 `j` 列。等地，矩阵的迹是其特征值的和，使其相对于基的变化保持不变。在更高级的矩阵计算中，可能从矩阵的行或列中提取向量。其他情况可能交换矩阵的行或列。以下方法演示了如何执行此类操作。
