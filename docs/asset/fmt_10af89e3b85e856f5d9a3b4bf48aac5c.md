# 类与多形态项目

类声明的第一行被称为类头（class header）。它以单词 `class` 开头，后面跟着类的名称。命名的相同规则也适用于名称的命名。大多数程序员遵循类名以大写字母开头的习惯。这有助于在阅读代码时区分类名和变量名。

类头之后是一个左大括号。接下来，你编写类声明。这些是定义类的字段、属性和方法的语句。在类声明的末尾会出现一个右大括号。
