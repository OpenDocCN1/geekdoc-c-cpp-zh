
如果一个 JavaScript 程序是从头到尾编写且没有函数的，那么程序中定义的任何变量都可以在程序的任何地方使用。我们说这些变量具有全局作用域。

一旦引入了函数，情况就不同了。但在函数内部也可以声明变量。这些变量无法在函数外部使用；实际上，它们只在函数执行时存在。它们被认为具有局部作用域。考虑以下程序：

```javascript
function avg3(val1, val2, val3) {
  var average = (val1 + val2 + val3) / 3;
  return average;
}
var x = 3;
var y = 5;
var z = 7;
ans = avg3(x,y,z) + " " + average;
document.write(ans + " " + average);
```

`document.write`语句中对`average`的引用会导致错误。该变量在函数外部不存在。

此外注意，在函数内部，参数`val1`、`val2`和`val3`被视为局部变量，就像具有局部作用域的变量。

全局作用域变量可以在任何地方使用，甚至是在函数内部。但如果函数中声明的变量与全局作用域变量同名，则全局变量会被隐藏，只能使用局部变量。例如，考虑以下代码：

```
var boilTemp = 212;
var freezeTemp = 32;
```

```
function findWaterState(waterTemp) {
  var boilTemp = 100;
  if (waterTemp > boilTemp) {
    return "Steam";
  } else if (waterTemp < freezeTemp) {
    return "Ice";
  } else {
    return "Liquid Water";
  }
}
```

如果`waterTemp`等于20，它将与全局值`freezeTemp`进行比较并返回字符串"Ice"。但如果`waterTemp`等于150，将返回字符串"Steam"，因为将使用局部变量`boilTemp`而不是全局变量。

## Let 和 Const

最初，JavaScript中的所有变量都是使用`var`关键字声明的。ES-2015引入了两个替代关键字：`let`和`const`。

主要的区别在于，使用这两个关键字声明的变量可能具有块级作用域。也就是说，它们可以声明在大括号包围的语句块中，并且这种声明仅在该块内具有意义。例如，在以下语句中：

```
{
var a = 5;
let b = 7;
}
var first = a;
var second = b;
```

对`first`赋值没有，但对`second`赋值会导致错误，因为`b`在块外部不存在。

`const`关键字的作用与`let`相同，不同在于用`const`声明的变量必须在声明时赋值，并且在随后的作用域内不能再次赋值其他值。我们不能这样做：

```
const SQRT2 = 1.414;
SQRT2 = 1.5;
```

JavaScript中由`const`定义的变量并不在任何意义上都是常量，但该关键字通常用于定义具有简单数据类型的常量。按照惯例，此类常量通常使用全大字母命名，例如`PI`。

在变量提升方面，`let`和`const`也与`var`不同。

## 提升

当解释器读取JavaScript程序时，人们自然地期望解释器按照语句出现的顺序来处理它们。特别是，变量不应该在声明之前使用，函数似乎也不应该在定义之前被调用。

然而，在JavaScript中，解释器可以并且确实向前查看。我们已经知道函数可以定义在程序的任何地方，并且仍然可以在任何需要的地方使用。

问题出现在变量声明上。编写像这样的代码是完全合法的，尽管有点奇怪：

```
x = 3;
y = x;
var x;
```

这似乎行不起通，但它确实有效，因为JavaScript提供了一项名为“提升”的功能。由于作用域内的所有变量声明都会移动到开头，因此它的处理方式就像是这样：

```
var x;
x = 3;
y = x;
```

但重要的是，只有变量的声明会被提升，而不是它们的初始化或任何其他赋值。如果你写：

```
y = x;
var x = 3;
```

第一行将告标记为错误，因为`x`是未定义的。

在JavaScript中，在声明之前使用变量是合法的，但这是一个好主意吗？答案几乎总是否。最佳实践是始终在函数开头定义函数使用的变量，并在程序开头定义全局使用的变量。如果遵循了这一实践，提升就是必要的。

如果使用`let`或`const`定义变量，则不会发生提升。这些变量在以任何方式使用之前必须声明。

# 第 9 章：对象与方法

## 对象

我们现在已经介绍了JavaScript语言的大多数基本元素，并学习许多示例。到目前，我们的示例都是基于传统的编程风格，被称为过程化编程。在这种风格下，程序按步骤进行。

然而，还有另一种编程风格在现代软件开发中可能更为常见，被称为面向对象编程。在这种风格中，程序围绕“对象”而不是函数组织。对象是数据和函数集合。

例如，考虑一个代表汽车的对象：

```
var car = {
  make: "Toyota",
  model: "Corolla",
  year: 2020,
  start: function() {
    console.log("The car is starting...");
  }
};
```

在这个示例中，`make`、`model`和`year`是汽车的属性，而`start`是一个方法。我们可以使用点符号访问属性并调用方法：

```javascript
console.log(car.make); // 输出: Toyota
car.start(); // 输出: The car is starting...
```

面向对象编程允许我们创建复杂且可复用的对象，这使得我们的代码更有组织且更容易维护。在本章中，我们将探索如何在JavaScript中创建、使用和操作对象。

## 属性

我们知道JavaScript中的变量都有名称和值。对象的属性可以被视为变量，并通过键值对进行描述。例如：

```javascript
var library = {
  name: "Central Library",
  fiction: 1000,
  nonfiction: 500,
  open: true
};
```

这段代码是一个对象字面量。它定义了一个代表图书馆的对象，具有四个属性：它的名称、虚构和非虚构书籍的数量以及一个指示图书馆是否开放的布尔值。

引用特定属性有两种不同的方法；你可以使用点符号，也可以将属性名作为字符串放在方括号中：

```
library.fiction = 800;
or
library["fiction"] = 800;
```

每种表示法都有其优势，并且都被广泛使用。向对象添加新属性也是可能的，例如：

```javascript
library.address = "123 Main Street";
```

尽管该对象之前没有`address`属性，但该语句将添加它。

要从对象中删除属性，使用`delete`关键字：

```
delete library.open;
```

这完全从对象中删除了`open`属性。

除了这些像变量一样的属性外，对象可能还关联有方法。这些将在下面讨论。

我们使用字面量声明了图书馆对象：

```
var library = {
  name: "Central Library",
  fiction: 1000,
  nonfiction: 500,
  open: true
};
```

创建此类对象的另一种方法使用`new`关键字：

```
var library = new Object();
library.name = "Central Library";
library.fiction = 1000;
```

```javascript
library.nonfiction = 500;
library.open = true;
```

这两处声明的作用是相同的。当某些属性的值需要在稍后时间填充时，使用`new`关键字可能会很有用。然而，在大多数情况下，推荐使用字面量定义。

请注意，我们也可以通过像下面的语句声明一个空对象，并根据需要向对象添加属性：

```javascript
var library = {};
```

需要注意的是，如果将一个对象赋值给变量，该变量包含的是对对象的引用，而不是对象本身的拷贝。如果对变量进行了复制，那么该拷贝也是指向同一个对象的引用。如果我们写下：

```javascript
var lib2 = library;
```

那么`lib2`和`library`都指向同一个对象。如果我们接着写道：

```javascript
lib2.fiction = 1200;
```

`library.fiction`的值也会随之变为1200。

## 使用 for ... in 进行迭代

对于某些对象，我们希望对它的每个属性系统地执行某个操作。这可以通过类似于`for`循环的语句来实现，称为`for ... in`语句。

给定上述讨论的`library`对象，我们可以通过以下代码来显示它的每个属性：

```javascript
for (var prop in library) {
    document.write(prop + ":" + library[prop] + "<br>");
}
```

该循环的输出应该是：

- name: Central Library
- fiction: 1000
- nonfiction: 500
- open: true

尽管如此，通常迭代的顺序是无法保证的。

## 方法

在面向对象编程中，函数属于特定的对象。在JavaScript中，与对象关联的函数被称为方法。我们之前简带提到过这个术语，现在准备好给出JavaScript的一个核心原理：

在JavaScript中，所有函数都是方法。

大多数JavaScript方法都与特定的对象关联，在调用该方法时必须指定对象名称，例如`document.write()`。在不指定对象名称的情况下调用的方法被假设为全局对象的方法。

严格来说，方法就是属性。它们的名称是函数名，而值是函数定义的文本。如果我们想为`library`对象添加一个方法来计算书籍总数，我们可以写道：

```javascript
library.totalBooks = function () {
  return this.fiction + this.nonfiction;
}
```

这将定义一个名为`totalBooks`的属性，其值为上述的函数定义。这看起来非常直观，但关键字`this`指的是什么意思呢？答案是，任何语句中的`this`都指代该语句所属的对象。在这种情况下，该对象就是`library`，我们所表达的是表达式中的两个值是`library.fiction`和`library.nonfiction`。

## 一些预定义对象

JavaScript提供了较少的预定义对象。这里我们介绍两个重要的对象：`Date`和`Math`。

`Date`对象包含一个日期。日期内部上是一个数字，代表自1970年1月1日协调世界时UTC午夜为止的毫秒数。这个数字可以拆分为七部分：年、月、日、时、分、秒。

`Date`的每个组件都是数字。年份是完整的四位数，月份范围在0到11之间。其他值则直观易懂。

`Date`对象可以使用浏览器时区将完整日期表示为字符串：

> Sun Jan 26 2020 08:14:02 GMT-0500 (Eastern Standard Time)

此外，`Date`对象还拥有方法可以接收此类字符串并将其解析为七个组件。

要创建一个包含当前日期和时间的`Date`对象，你可以写道：

```javascript
var curDate = new Date();
```

要创建一个特定时间的`Date`对象，你可以为`new Date()`使用一个或多个参数。例如：

```javascript
var myDate = new Date(2020, 0, 26, 8, 14, 2); // 创建一个与上述字符串值相同的 Date 对象。也可以省略多五个后续值，它们将默认为零。
```

有特定的方法可以提取`Date`对象的任何部分：

```javascript
// 返回完整的四位年份
var year = myDate.getFullYear();
```

```javascript
// 返回月份 (0-11)
var month = myDate.getMonth();
```

```javascript
// 返回每月第几号 (1-31)
var dayOfMonth = myDate.getDate();
```

```javascript
// 返回星期几 (0-6, 0 = 星期日)
var dayOfWeek = myDate.getDay();
```

```javascript
// 返回小时 (0-23)
var hour = myDate.getHours();
```

```javascript
// 返回分钟 (0-59)
var minute = myDate.getMinutes();
```

```javascript
// 返回秒 (0-59)
var second = myDate.getSeconds();
```

```javascript
// 返回毫秒 (0-999)
var millisecond = myDate.getMilliseconds();
```

你还可以获取`Date`对象的原始值：

```javascript
var rawTime = myDate.getTime();
```

该方法的输出是自1970年1月1日协调世界时UTC午夜为止的毫秒数。可以使用`toString()`方法将此数字转换为字符串：

```javascript
var dateString = myDate.toString();
```

`Date`对象还拥有用于设置日期各个组件的方法：

```javascript
myDate.setFullYear(2021);
myDate.setMonth(5);
myDate.setDate(15);
myDate.setHours(10, 30, 0, 0);
```

## 读取和写入数组元素

数组的单个元素可以使用索引号进行读取或写入，索引从零开始：

```
var first = composers[0];
composers[3] = 'Debussy';
```

执行这段代码后，`first`包含字符串'Mozart'，而数组中的名称'Tchaikovsky'已更改为'Debussy'。

如果你尝试访问一个从未赋过值的数组元素会怎样？默认情况下，所有此类元素的值都是`undefined`。

```
var tooHigh = composers[5];
```

这会将变量`tooHigh`设置为`undefined`。

除了元素之外，数组还具有几个属性。其中一个属性提供数组的长度。这是数组中包含的元素个数，直到到具有值的最高元素为止。 由于数组索引从零开始，因此长度是已赋值的最高元素的索引加1。如果我们写道：

```
composerCount = composers.length;
```

那么`composerCount`的值将是5。

## 管理表格

数组对于存储数值表格非常有用。考虑第7章中计算并输出的阶乘表。我们在第6章中看到的循环结构可以配合数组使用，用于处理数组中直到某个限制的所有元素。对代码进行一些简单的更改就可以将表格存储在数组中。这里是`fact.js`的新版本：

```javascript
function factTable(formId) {
  // 获取限制值
  var limit = formId.textin.value;
  // 确保 limit 是有效数字
  if (limit >= 1) {
    // 初始化变量
    var val = 1;
    var fact = 1;
    var index = 0;
    var factTb = [];
    // 计算值并将其存储在数组中
    for (var count = 1; count <= limit; count++) {
      factTb[index++] = fact;
      fact = fact * ++val;
      if (fact > 9999999999999999) {
        break;
      }
    }
    // 现在构建输出字符串
    var result = "<pre>VALUE FACTORIAL\n";
    for (var i = 0; i < factTb.length; i++) {
      val = i + 1;
      fact = factTb[i];
      result += val + " " + fact + "\n";
    }
    result += "</pre>";
  } else {
    result = "Invalid limit!";
  }
  // 输出表格
  document.getElementById("textout").innerHTML = result;
}
```
