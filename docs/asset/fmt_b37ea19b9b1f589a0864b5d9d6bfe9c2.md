# Q10. 计算任意三角形面积的C程序

## 解决方案

```c
****************************************************
文件名：prog10.c
作者信息：Mr. x, 第一学期，计算机科学与工程专业，ABC工程学院
程序执行日期：31/7/2015
程序名称：计算任意三角形面积的C程序
****************************************************
#include <stdio.h>
#include <math.h>
#include <conio.h>

void main(void)
{
    float x, y, z;
    float s, area;
    clrscr();
    printf("Input the size of triangle:");
    scanf("%f%f%f", &x, &y, &z);
    s = (x + y + z) / 2;
    area = sqrt(s * (s - x) * (s - y) * (s - z));
    printf("The area of triangle is: %.3f", area);
    getch();
}
```

**输出：**

```text
Input the size of triangle: 2 3 4
The area of triangle is: 2.905
```

**解释：**

在这里用户输入三角形的边，然后将这些边相加并除以 2 存储在 `s` 中。然后应用公式 `area = sqrt(s * (s - x) * (s - y) * (s - z))`，最后打印面积。`math.h` 是用于数学运算的头文件。

## Q1. 计算等边三角形面积的C程序

### 解决方案

```c
************************************************
文件名：prog.c
作者信息：Mr. X, 第一学期，计算机科学与工程专业，ABC工程学院
程序执行日期：31/7/2015

#include <stdio.h>
#include <math.h>
#include <conio.h>

void main(void)
{
    float x;
    float area;
    clrscr();
    printf("Input the size of side of the equilateral triangle : ");
    scanf("%f", &x);
    area = (sqrt(3) / 4) * x * x;
    printf("The area of equilateral triangle is: %.3f", area);
    getch();
}
```

**输出：**

```text
Input the size of side of the equilateral triangle: 3
The area of equilateral triangle is: 3.897
```

**解释：**

等边三角形面积公式为：
`area = (√3)/4 * x^2`

## Q12. 计算直角三角形面积的C程序

### 解决方案

```c
*******************************************************************
文件名：prog12.c
作者信息：Mr. x, 第一学期，计算机科学与工程专业，ABC工程学院
程序执行日期：31/7/2015
程序名称：计算直角三角形面积的C程序
*******************************************************************

#include <conio.h>

void main()
{
    float x, y, z;
    clrscr();
    printf("Input the height and width of the right angled triangle:\n");
    scanf("%f%f", &x, &y);
    z = 0.5 * x * y;
    printf("The area of right angled triangle is: %.3f", z);

}
```

**输出：**

```text
Input the height and width of the right angled triangle: 3 2
```

在这里用户输入直角三角形的高度和宽，例如 3 和 2。计算直角三角形面积的公式为 `½ * 高 * 宽`。因此相乘后 `0.5 * 3 * 2 = 3`。

## Q13. 计算复利的C程序

### 解决方案

```c
************************************************
文件名：prog13.c
作者信息：Mr. x, 第一学期，计算机科学与工程专业，ABC工程学院
程序执行日期：31/7/2015
程序名称：计算复利的C程序
************************************************
#include <stdio.h>
#include <math.h>
#include <conio.h>

int main()
{
    float p, r, t, c;
    clrscr();
    printf("Input the principal amount:");
    scanf("%f", &p);
    printf("Input the rate of interest:");
    scanf("%f", &r);
    printf("Input the time period in year:");
    scanf("%f", &t);
    /* 计算复利 */
    c = p * (pow((1 + r / 100), t) - 1);
    printf("\n After calculation the compound interest is:%f", c);
    getch();
    return 0;
}
```

**输出：**

```text
Input the principal amount: 200
Input the rate of interest: 4
Input the time period in year: 2
After calculation the compound interest is:16.320000
```

## 示例：长度单位转换

```c
void main(void)
{
    float x;
    clrscr();
    float y, z;
    printf("Input the length in centimeter: ");
    scanf("%f", &x);
    y = x / 100.0;
    z = x / 100000.0;
    printf("The length in Meter is:%.2f\n", y);
    printf("The length in Kilometer is:%.2f\n", z);
    getch();
}
```

**输出：**

```text
输入厘米长度：100000
以米为单位的长度：1000.00
以公里为单位的长度：1.00
```

**解释：**

这里用户输入的长度为 100000。然后将该厘米除以 100 得到米，即 1000 米；再次将厘米转换为公里，除以 100000 得到公里。

# 变量、常量数据类型

## 4.1 引言

当一个人坐在椅子上时，它占据了一些物理空间。在编程概念中，当变量被声明时，它占据了一些逻辑空间。我们可以说变量是一个用于存储某些值的内存位置。也可以说变量是一个占位符，因为它持有某些内存。在程序执行的不同时刻，变量可以取不同的值。但在同一时刻，变量不能取多个值，而是单个值。程序员应该给变量一个名称，以便在程序中引用。

### 记忆技巧

尝试选择简单的变量名，以便于操作/实现。

## 4.2 变量的声明

变量的声明由两部分组成，即：数据类型和变量名。数据类型决定了变量将持有什么类型的值。它可以是整数类型、浮点类型、字符类型或双精度类型。变量名意味着程序员给出的名称（见第 3.4 节）。变量的声明是必要的。

```c
data-type variable_name;
```

## 4.3 变量的初始化

当程序员声明变量时，它会自动分配值。这些值取决于计算机，可能是正整数或负整数，或者是垃圾值或未初始化的值。当程序员给变量赋值某些值时，这就是变量的初始化。因此，变量初始化意味着给变量赋予值。

| 初始化语法 |
| :--- |
| `data-types variable_name = constants;` |

**示例：**

```c
int x = 20;
```

这里 20 是赋值给变量 `x` 的整数常量。变量 `x` 的逻辑表示如图所示。

## 4.4 变量命名规则

程序员不能为变量指定任意名称。变量名遵循 C 编译器遵循的某些特定规则和规定。变量是字母、数字和下划线的组合。条件如下：

### 表 4.1 变量的命名

| 序号 | 规则 | 示例 |
| :--- | :--- | :--- |
| 1 | 变量名可以以下划线 (`_`) 或字母（可以是小写或大写）开头。 | 示例：`_Total`; 或 `Total`; 或 `total`; 或 `TOTAL`; |
| 2 | 变量的长度不应超过 31 个字符。但许多编译器通常最大为 8 个字符。 | |
| 3 | 变量名对大小写敏感，即大写字母和小写字母是不同的。 | 例如，`number` 不等于 `NUMBER`。 |
| 4 | 不允许使用关键字，例如 `for`, `if`, `while`, `do`。 | 错误：`int for;` <br> 正确：`int student_id;` |
| 5 | 不允许出现空格/空白。 | 错误：`int student id;` <br> 正确：`int student_id;` |
| 6 | 不允许特殊字符，例如 `%`, `$`, `#`, `@`。 | 错误：`int #student_id;` <br> 正确：`int student_id;` |

**记忆要点**

从表 4.1 我们可以得出，变量名可以用小写或大写字母编写。但优秀的程序员总是倾向于使用小写字母。

**示例：用户输入的两个整数相加**

## 4.5 什么是常量？

常量是在程序执行过程中不会改变的固定值。

### 4.5.1 不同类型的常量

## 4.6 不同类型常量说明

### 4.6.1 数值常量

#### (A) 整数常量

整数常量是不带有任何小数部分/分数部分的常量（即无小数点）。整数常量有三种：十进制整数常量、八进制整数常量、十六进制整数常量。

*   十进制整数常量示例：`10`、`4`、`-20`、`+40`。
*   八进制常量由 0 到 7 的数字组成，并以零为前缀。示例：`050`, `0200`, `0567` 等。
*   十六进制常量是以 `0x`, `0X` 为前缀的数字序列，包含 `A` 到 `F` 的字母。`A` 的值为 10，`B`=11, `C`=12, `D`=13, `E`=14, `F`=15。
*   十六进制整数示例：`0X7`, `0X1E`。

#### (B) 实数常量

这些常量具有小数部分。它们也被称为浮点常量。
示例：`0.67`, `+234.9`。

### 4.6.2 字符常量

#### (A) 单字符常量

字符常量包含包含在单引号内的单个字符。示例：`'1'`、`'h'`、`'J'` 等。

#### (B) 字符串常量

字符串常量是通常包含在双引号内的字符序列。或者说，包含在双引号内的字符被称为字符串常量。这些字符可以是数字、字母、空格或特殊字符。示例：`"I LOVE MY INDIA"`、`"hello"` 等。

## 4.7 符号常量

符号常量是一组字符的替代名称。符号常量可以是字符常量、字符串常量或数值常量。

### 何时需要它？

当程序员想要多次使用一个常量时，可以为该值使用一个替代名称。例如，如果程序员要在程序的多个地方使用 π 值 3.14，那么他可以用 `PI` 或其他名称代替 3.14，并在程序的任何地方使用它。这种类型的常量被称为符号常量。

### 语法

```c
#define new_name constant_value
```

在上面的声明中，`new_name` 是该常量值替代项的符号名称，通常写为大写。`constant_value` 可以是数值、字符串或字符。

> **记忆要点**
> 在符号常量中，语句末尾不要加分号，例如：
> `#define new_name constant_value;`
> 因为 `#define` 不是语句，而是一个预处理器指令。

### 符号常量示例

```c
#define PI 3.14
```

上面的定义提高了可读性。

```c
/* 符号常量示例 */
#include <stdio.h>

#define NAME "habal"

void main()
{
    printf("%s", NAME);
}
```
