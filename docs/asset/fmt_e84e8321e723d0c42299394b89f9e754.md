## 20.1 拟合酶动力学（化学/生物工程）

### 背景

酶充当催化剂，加速活细胞内化学反应的速率。在大多数情况下，它们将一种化学物质（底物）转化为另一种（产物）。米凯尔斯-门滕方程常用于描述此类反应：

```
$v = \frac{v_m[S]}{k_m + [S]}$
```

其中 $v$ 是反应速率，$v_m$ 是最大反应速率，$[S]$ 是底物浓度，$k_m$ 是半饱和常数。与图 20.1 所示，该方程描述了一种随 $[S]$ 增加而趋于饱和的关系。图表说明半饱和常数对应于速率达到最大值一半的底物浓度。

尽管米凯尔斯-门滕模型提供了一个很好的起点，但它已经经过改进和扩展，以包含酶动力学的额外特征。一个简单的扩展涉及变构酶，其中分子在某一个位点的结合会增强后续分子在其他位点的结合。对于具有两个相互位点的情况，以下二阶版本通常会产生更好的拟合效果：

```
$v = \frac{v_m[S]^2}{k_m^2 + [S]^2}$
```

**图 20.1** 酶动力学米凯尔斯-门滕模型的两个版本。

![](img/1e955c450e467ba2327460e717e7b955_589_0.png)

**解答。** 方程 (20.1) 采用饱和增长速率模型（方程 17.14）的形式，可以通过对其取倒数来实现线性化（回顾方程 (17.17)）：

```
$1/V = 1/V_m + k_m/V_m * 1/[S]$
```

如果模型有效，则 $1/V$ 对 $1/[S]$ 的散点图应产生一条直线，截距为 $1/V_m$，斜率为 $k_m/V_m$。使用你的程序或软件软件包，你应该获得 0.1902 的截距和 0.16022 的斜率，且 $r^2=0.9344$。模型系数可以计算为 $V_m = 1/0.1902 = 5.2570$ 和 $k_m = 5.2570 * 0.16022 = 86.2260$，最佳拟合模型为：

```
$V = 5.2570 / (1 + 86.2260/[S])$
```

尽管 $r^2$ 的高值可能让人认为这个结果是可以接受的，但对系数的检查可能会引起怀疑。例如，最大速率（5.2570）远大于观测到的速率（0.36）。此外，半饱和常数（86.2260）远大于最大底物浓度（9）。

## 20.3 傅里叶分析（电气工程）

### 背景

傅里叶分析用于许多工程领域。然而，它在电气工程应用中作为信号处理被广泛采用。

1848 年，约翰·沃尔夫发明了一种通过计算太阳表面单个群组和黑子的数量来量化太阳活动的方法。他通过将群组数乘以 10 再加上单个黑子的总数来计算出一个数值，现在被称为“沃尔夫黑子数”。如图 20.6 所示，该数字的长度可以追溯到 1700 年。根据早期历史记录，沃尔夫确定周期长度为 11.1 年。尝试通过对图 20.6 的数据应用 FFT（快速傅里叶变换）来确认这一点。通过绘制频率随周期的图来确定周期。

**解。** 年份和黑子数的数据从网上下载并存储在制表符分隔的文件中：黑子数据可以加载到 MATLAB 中，并将年份和数字分配给同名的向量，

```matlab
>> load sunspot.dat
>> year=sunspot(:,1);
>> number=sunspot(:,2);
```

接下来，对黑子数向量应用 FFT。在得到第一个谐波后，确定 FFT 的长度 (n) 并计算功率和频率。

```matlab
>> y=number;
>> n=length(y);
>> power=abs(y(1:n)).^2;
>> nyquist=1/2;
>> freq=(1:n)/(n/2)*nyquist;
```
