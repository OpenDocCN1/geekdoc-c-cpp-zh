
我们可以使用字典的 `items` 方法，它允许使用 `for` 循环使用两个变量进行迭代，一个用于键，一个用于值。我们将结果作为元组返回：

```python
def unzip(d):
    ks = []
    vs = []
    for k, v in d.items():
        ks.append(k)
        vs.append(v)
    return (ks, vs)
```

例如：

```python
>>> unzip({1: 'one', 2: 'two'})

如果输入值 `t` 的类型是整数，我们返回它。否则，我们遍历 `t` 中的所有项，通过递归地应用 `sum_all` 函数本身来累加它们的和。

def sum_all(t):

  else:
    total = 0
    for x in t:

    return total
```
