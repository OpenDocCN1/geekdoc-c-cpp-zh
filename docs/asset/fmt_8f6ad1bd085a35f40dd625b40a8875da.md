# 示例 12.1 离散随机变量

设 `$X$` 是取值在 `[A, B]` 的离散随机变量。设 `a_1, a_2, …, a_n` 为 `$X$` 的结果，对应的概率为 `p_1, p_2, …, p_n`。`$X$` 的平均值或期望值为

`E(X) = a_1p_1 + a_2p_2 + … + a_np_n`。

为了找到 `$X$` 的方差，设 `Var(X) = E[(X - E(X))^2]`，

`Var(X) = (a_1 - E(X))^2p_1 + (a_2 - E(X))^2p_2 + … + (a_n - E(X))^2p_n`。

`$X$` 的标准差是 `sqrt(Var(X))`。掷骰子的结果为 `1, 2, 3, 4, 5, 6`，对应的概率为 `.3, .2, .2, .1, .1, .1`。计算 `$X$` 的均值和方差。

解答

`E(X) = (1)(.3) + (2)(.2) + (3)(.2) + (4)(.1) + (5)(.1) + (6)(.1) = 3.5`

`Var(X) = (1-3.5)^2(.3) + (2-3.5)^2(.2) + (3-3.5)^2(.2) + (4-3.5)^2(.1) + (5-3.5)^2(.1) + (6-3.5)^2(.1) = 2.91`

[标准差] = `sqrt(2.91) ≈ 1.71`。

# 12.2 连续随机变量

设 `$X$` 为取值在区间 `[A, B]` 的连续随机变量于`X$` 的概率密度函数 `f(x)` 定义在 `[A, B]` 上，具有以下性质：

(1) 对于 `A ≤ x ≤ B` `f(x) ≥ 0`。

(2) `∫_A^B f(x)dx = 1`。

`$X$` 的结果落在区间 `[a, b]` 内的概率由累积分布函数 `F(x)` 给出

`F(x) = ∫_A^x f(t)dt`

and `Pr(a ≤ X ≤ b) = F(b) - F(a)`。

如果 `B = ∞` 或 `A = -∞`，则积分是非积分。

1. 对于 `1 ≤ x ≤ 2`，设 `f(x) = 2/x^2`。

(a) 证明 `f(x)` 是 `1 ≤ x ≤ 2`上的概率密度函数。

(b) 设 `$X$` 为概率密度函数 `f(x)` 的随机变量。计算 `Pr(1 ≤ X ≤ 1.5)`。

解答

由于对于所有的 `1 ≤ x ≤ 2`，`f(x) ≥ 0`，只需证明

`∫_1^2 2/x^2 dx = [-2/x]_1^2 = -1 - (-2) = 1`。

`Pr(1 ≤ X ≤ 1.5) = ∫_1^{1.5} 2/x^2 dx = [-2/x]_1^{1.5} = -2/1.5 - (-2) = -4/3 + 2 = 2/3`。

# 12.3 期望值与方差

设 `$X$` 是取值在区间 `[A, B]` 的连续随机变量，并 `f(x)` 表示 `$X$` 的密度函数。`$X$` 的*期望值*或*均值*给出

`E(X) = ∫_A^B x f(x) dx`。

`$X$` 的方差是

`Var(X) = ∫_A^B [x - E(X)]^2 f(x) dx`。

我们还有

`Var(X) = ∫_A^B x^2 f(x) dx - E(X)^2`。设 `$X$` 为概率密度函数 `f(x) = 2/x` 对于 `1 ≤ x ≤ 2` 的随机变量。计算 `E(X)` 和 `Var(X)`。

解答

`E(X) = (1)(.3) + (2)(.2) + (3)(.2) + (4)(.1) + (5)(.1) + (6)(.1) = 3.5`

`Var(X) = (1-3.5)^2(.3) + (2-3.5)^2(.2) + (3-3.5)^2(.2) + (4-3.5)^2(.1) + (5-3.5)^2(.1) + (6-3.5)^2(.1) = 2.91`

# 12.4 指数分布与正态随机变量

具有指数密度函数的随机变量

`f(x) = k e^{-k x}, x ≥ 0`,

其中 `k > 0`，称为指数随机变量。对于指数随机变量，我们有

`E(X) = 1/k, Var(X) = 1/k^2`。

正态随机变量是具有正态密度函数的随机变量

`f(x) = 1/(σ sqrt(2π)) e^{-(x-μ)^2/σ^2}`,

其中 `μ > 0` 和 `σ > 0`。对于正态，我们有

`E(X) = μ, Var(X) = σ^2`。设 `$X$` 服从均值 `μ = 5` 和标准差 `σ = 2` 的正态分布。计算 `Pr(6 ≤ X ≤ 8)`。

解答

`z = (x-μ)/σ = (x-5)/2`,

当 `x = 6, z = 1/2`;而当 `x = 8, z = 3/2`。因此，

`Pr(6 ≤ X ≤ 8) = Pr(1/2 ≤ Z ≤ 3/2) = A(3/2) - A(1/2)`。借助附录表 1 的帮助，我们找到 `A(1.5) = .192` 和 `A(0.5) = .433`。因此，所需的概率是 `.433 - .192 = .241`。

## 12.5 泊松随机变量与几何随机变量

参数为 `λ > 0` 的泊松随机变量其结果为 `0, 1, 2, …,`，对应的概率为 `e^{-λ}, λ e^{-λ}, λ^2/2! e^{-λ}, …`。对于泊松随机变量，其均值为 `λ`，且满足：

`E(X) = λ`

`Var(X) = λ`

假设 `$X$` 服从均值为 `μ = 3` 的泊松分布。求 `X = 3` 的概率。

由于均值 `X = 3`，可知 `λ = 3`，则 `X` 为 3 的概率为

`p_3 = λ^3/(3·2) e^{-λ} = 3^3/6 e^{-3}=.224.`

参数为 `0 < p < 1` 的几何随机变量其结果为 `0, 1, 2, 3, …,`，对应的概率为 `1-p, p(1-p), p^2(1-p), …`。对于几何随机变量，其均值为

`E(X) = (1-p)/p`

`Var(X) = p/(1-p)^2`
