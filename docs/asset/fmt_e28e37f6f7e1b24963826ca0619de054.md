## 控制分类头 (Controlling the Classification Headers)

在许多情况下，没有必要在分类头中显示分类变量名。通常，只需分类值就足够。`DATALATTICE` 和 `DATAPANEL` 布局都支持 `HEADERDISPLAY` 选项。默认 `HEADERDISPLAY=NAMEVALUE` 显示变量名和值。你可以设置 `HEADERDISPLAY=VALUE` 只显示值，或设置 `HEADERDISPLAY=NONE` 隐藏头。

行头和列头是 `DATALATTICE` 布局特有的。默认 `COLUMNHEADERS=TOP`，你可以设置 `COLUMNHEADERS=BOTTOM` 或 `BOTH`。同样，`ROWHEADERS=RIGHT` 是默认设置，但你可以在 `ROWHEADERS` 选项上设置 `LEFT` 或 `BOTH`。可以使用 `DISPLAYSECONDARY` 选项更改行或列信息的位置。在此示例中，行头移动到左侧，轴信息移动到右侧。注意，还需要 `DISPLAY=NONE` 来移除左侧的默认轴信息。

```
layout datalattice rowvar=product_group /
rowdatarange=union
rowgutter=5px
rowheaders=left
headerlabeldisplay=value
columnaxisopts=(display=(tickvalues))
rowaxisopts=(display=none displaysecondary=(tickvalues)
linearopts=(tickvalueformat=dollar12.))
griddisplay=on offsetmin=0;
```

## 使用侧边栏

侧边栏用于对齐网格之外的信息。在下面的示例中，使用侧边栏显示图表标题，而不是使用 `ENTRYTITLE` 语句。使用侧边栏处理标题和注释信息的优势在于，侧边栏始终在网格本身上水平对齐，而不是相对于整个图表的宽度。当然，你必须指定属性（`TEXTATTRS` 选项）、对齐（`HALIGN=` 选项）和内边距（`PAD=` 选项）。将此示例中“标题”的默认居中与本章中通过 `ENTRYTITLE` 语句指定标题的类似示例进行比较。

此示例还使用侧边栏显示图例。图例可以放置在 `TOP`、`BOTTOM`、`RIGHT` 或 `LEFT` 任意侧边栏中。图例的对齐基于网格大小，而不是图表大小。

```sas
proc template;
define statgraph sidebar;
begingraph / designwidth=490px designheight=800px border=false;

layout datapanel class=(product division) / columns=2
columngutter=10px rowgutter=5px
headerlabelattrs=GraphLabelText(weight=bold)
rowaxisopts=(display=(ticks tickvalues))
columnaxisopts=(display=(ticks tickvalues)
offsetmin=0
linearopts=(tickvalueformat=dollar6. viewmax=2000
tickvaluelist=(500 1000 1500 2000)));
sidebar / align=top;
entry "Office Furniture Sales" /
textattrs=GraphTitleText(size=14pt) pad=(bottom=5px);
endsidebar;
sidebar / align=bottom;
discretelegend "actual" "predict";
endsidebar;

layout prototype;
barchart category=month response=actual /
orient=horizontal fillattrs=GraphData1
barwidth=.6 name="actual";
barchart category=month response=predict /
orient=horizontal fillattrs=GraphData2
barwidth=.3 name="predict";

endlayout;
endgraph;
end;
run;

proc sgrender data=sashelp.prdsale template=sidebar;
where country="U.S.A." and region="EAST" and
product in ("CHAIR" "DESK" "TABLE");
run;
```

通常情况下，当面板中创建的单元格数量大于模板定义的面板尺寸（行 × 列）时，`PROC SGRENDER` 过程会自动生成所需的面板图，以绘制数据中的所有单元格。然而，你可以指示模板仅创建一个面板，由 `PANELNUMBER=` 选项指定。此功能可用于控制面板的生成。

例如，前面的面板是用以下模板代码生成的，该代码使用 `NMVAR` 语句声明解析为数字的宏变量。`PANELNUMBER` 设置是指示生成哪个面板的指令。`ENTRYTITLE` 语句随面板的变化而改变。关于如何在运行时向模板传递信息的更多信息，请参见第 14 章第 327 页的“使用动态和宏变量创建灵活模板”。

```sas
proc template;
define statgraph panelgen;
nmvar PANEL TOTPANELS ROWS COLS YEAR;
begingraph;
entrytitle "Panel &PANEL of &TOTPANELS" /
textattrs=GraphFootnoteText;
layout datapanel classvars=(product division) /
rows=&ROWS columns=&COLS
panelnumber=&PANEL;
sidebar / align=top;
entry "Office Furniture Sales" /
textattrs=GraphTitleText;
endsidebar;
layout prototype;
barchart category=month response=actual /
orient=horizontal fillattrs=GraphData1
barwidth=.6 name="actual";
barchart category=month response=predict /
orient=horizontal fillattrs=GraphData2
barwidth=.3 name="predict";
endlayout;
endgraph;
run;
```

286 第 11 章 · 使用分类面板

现在已经定义了模板，需要一个宏来计算面板数量、执行相应次数的 `SGRENDER` 并初始化模板引用的宏变量。宏参数 `ROWS` 和 `COLUMNS` 允许不同的网格尺寸。

```sas
%macro panels(rows,cols,year=1994);
  %local div_vals prod_vals panels totpanels panelnumber;
  /* 查找分类器的唯一值数量 */
  proc sql noprint;
    select n(distinct division) into: div_vals from sashelp.prdsale;
    select n(distinct product) into: prod_vals from sashelp.prdsale;
  quit;
  /* 根据行和列计算面板数量 */
  %let panels=%sysevalf(&div_vals * &prod_vals / (&rows * &cols));
  %let totpanels=%sysevalf(ceil(&panels)); /*向上取整到下一个整数 */
  ods graphics / reset;
  ods html close;
  ods listing gpath="." image_dpi=200;
  %do panelnumber=1 %to &totpanels;
    ods graphics / imagename="Panel&panelnumber"
    width=%sysevalf(400*&cols)px height=%sysevalf(200*&rows)px;
    proc sgrender data=sashelp.prdsale template=panelgen;
    where country="U.S.A." and region="EAST" and year=&year;
    run;
  %end;
  ods listing close;
  ods html;
%mend;
```
