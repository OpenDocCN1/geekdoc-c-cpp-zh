
## 使用 Contacts

到此为止，我们已经读取并删除了联系人，还没有创建和更新联系人。为了实现这一点，我们将借用 Membership 应用程序的设计并添加一些功能。我们将添加一个按钮，根据表单数据创建一个联系人。我们还将添加一个按钮来执行单次编辑，同样为了简单起见。在原始练习中，顶部的电子邮件地址被用作 membership 的查找字段。这次，使用选择的 ID，用户在电子邮件字段中的任何条目将替换该 ID 的当前电子邮件。代码很长且冗余，但看到不同组件是如何连接的很重要。再次提醒，如果你作为一个新项目启动它，请确保在清单文件中放入权限。
