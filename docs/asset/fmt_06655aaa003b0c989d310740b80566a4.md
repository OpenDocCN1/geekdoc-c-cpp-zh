## 调试与异常处理

### Try-Except 块

这是处理异常或错误最简单的方法：

```python
1 (x,y) = (5,0)
2 try:
3     z = x/y
4 except ZeroDivisionError:
5     print("divide by zero")
```

你也可以通过以下方式检查异常代码：

```python
1 (x,y) = (5,0)
2 try:
3     z = x/y
4 except ZeroDivisionError, e:
5     z = e # 表示："<exceptions.ZeroDivisionError instance at 0x817426c>"
6     print(z) # 输出："integer division or modulo by zero"
```

要捕获通用错误，请尝试：

```python
1 import sys
2 try:
3     untrusted.execute()
4 except: # 捕获*所有*异常
5     e = sys.exc_info()[0]
6     write_to_page("<p>Error: %s</p>", s, e)
```

或者

```python
1 try:
2     do_some_stuff()
3 except:
4     rollback()
5     raise
6 else:
7     commit()
```

或者

```python
1 try:
2     do_some_stuff()
3 finally:
4     cleanup_stuff()
```

### 获取有用的异常信息

```python
1 (a,b,c) = d
```

Java 随后会提示：

```python
1 ValueError: unpack list of wrong size
```

你也可以尝试：

```python
1 try:
2     a, b, c = d
3 except Exception, e:
4     e.args += (d,)
5     raise
```

这绝对比冗长的 C 语言异常处理程序简单得多！

### PDB 调试器

对于移除系统中的 Bug，先尝试 PDB 方法——这被认为是最简单的 Java 调试器！

```python
>>> import pdb
>>> a="a string"
>>> pdb.set_trace()
--Return-
<stdin>(1)<module>()->None
(Pdb) p a
'a string'
(Pdb)
```

你可以通过输入 `cont` 继续执行。你也可以通过输入以下内容自动运行此程序：

```python
## 代码片段，包含在 'sitecustomize.py' 中
import sys

def info(type, value, tb):
    if hasattr(sys, 'ps1') or not sys.stderr.isatty():
        # 我们处于交互模式下，或者我们没有类似 tty 的
        # 设备，所以我们调用默认钩子
        sys._exceptionhooktype(value, tb)
    else:
        import traceback, pdb
        # 我们不在交互模式下，打印异常...
        traceback.print_exception(type, value, tb)
        print
        # ...然后在在事后模式下启动调试器。
        pdb.pm()

sys.exceptionhook = info
```
