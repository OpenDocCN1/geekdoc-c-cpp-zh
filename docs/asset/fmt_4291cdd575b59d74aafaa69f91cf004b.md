
### 变量定义

- `t_i`: 当前时间
- `S_k > S_n > S_o ... S_{mn}`: 可用的处理器速度
- `schedulable = 1`

### 调度算法

1. 如果 `ready_list != NULL`
2. 按升序对任务截止时间排序
3. 选择截止时间最早的任务 `τ`
4. 循环从 `S = S_mn` 到 `S_o`
5. 如果 `l_i/S <= d`，则
6. `t = t + l_i/S`
7. 对于每个未完成执行的任务 `τ`
8. 如果 `l_i/S_k <= d`，则
9. `t = t + l_i/S_k`
10. 其他
11. `schedulable = 0`
12. 跳出
13. endif
14. 如果 `schedulable = 1` 则
15. 在 `S` 处调度 `τ`
16. 跳出
17. endif
18. endif
