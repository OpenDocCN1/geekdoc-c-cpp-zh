## 创建事件

让我们创建一个名为 `Event` 的控制台应用程序，其中你发现一个简单的事件。该对象通过内部变量触发事件。每当这个内部变量变化时，事件源就会通知监听者。列表 6.15 显示了 `Event` 应用程序的 `Program.cs` 代码。

### 列表 6.15：Event 的代码

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading.Tasks;

namespace Event
{
    class EventTestClass
    {
        // 内部变量
        private int value;
        // 事件处理程序的委托类型
        public delegate void EventHandler(int value);
        // 事件本身
        public event EventHandler Changed;
        // 触发事件的方法
        protected virtual void onChanged(int value)
        {
            if (value != value)
            {
                value = value;
                // 如果有任何处理程序，则调用它们
                if (Changed != null)
                {
                    Changed(value);
                }
            }
        }
        // 设置值的方法
        public void SetValue(int value)
        {
            onChanged(value);
        }
    }

    class Program
    {
        static void Main(string[] args)
        {
            EventTestClass etc = new EventTestClass();
            // 注册处理程序
            etc.Changed += (int val) =>
            {
                Console.WriteLine("Value changed to: " + val);
            };

            etc.SetValue(3);
            etc.SetValue(5);
            etc.SetValue(5);

            Console.Write("\nPress ENTER to quit...");
            Console.ReadLine();
        }
    }
}
```

## 事件链

许多编程语言使用事件处理的概念来执行各种操作，例如点击按钮控件。然而，大多数你只能为每个事件定义一个处理程序。C# 还允许你为单个事件实现多个处理程序并将它们链起来。让我们创建一个名为 `ChainingEvents` 的控制台应用程序，解释为单个事件多个处理程序的概念。图 6.16 显示了 `ChainingEvents` 应用程序的 `Program.cs` 代码：

### 列表 6.16：ChainingEvents 应用程序的代码

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading.Tasks;

namespace ChainingEvents
{
    public class EventTestClass
    {
        // 计数
        private int value;
        // 事件处理程序的委托类型
        public delegate void ValueChangedEventHandler();
        // 事件本身
        public event ValueChangedEventHandler Changed;
        // 触发事件的方法
        protected virtual void onChanged()
        {
            value++;
            // 如果有任何处理程序，则调用它们
            if (Changed != null)
            {
                Changed();
            }
        }
        // 设置值的方法
        public void setValue(int value)
        {
            if (value != value)
            {
                value = value;
                onChanged();
            }
        }
    }

    class Program
    {
        static void Main(string[] args)
        {
            EventTestClass etc = new EventTestClass();
            // 注册第一个处理程序
            etc.Changed += () =>
            {
                Console.WriteLine("Handler 1: Value is " + etc.value);
            };
            // 注册第二个处理程序
            etc.Changed += () =>
            {
                Console.WriteLine("Handler 2: Value is " + etc.value);
            };

            etc.setValue(3);
            etc.setValue(5);
            etc.setValue(5);

            Console.Write("\nPress ENTER to quit...");
            Console.ReadLine();
        }
    }
}
```
