### 在`MediaElement`中转换视频

在 WPF 中，你可以转换`MediaElement`控件，这意味着你可以旋转`MediaElement`控件以按所需角度显示视频。你可以使用`TransformGroup`类，通过`RotateTransform`或`ScaleTransform`类分别对`MediaElement`控件应用旋转和缩放转换。让我们创建一个应用程序来对`MediaElement`控件应用旋转转换。你应该创建一个名为`TransformingVideo`的 WPF 应用程序（也在 CD 上提供）并将 Listing 12.53 中给出的代码添加到`MainWindow.xaml`文件中：

**Listing 12.53:** 在`MediaElement`中转换视频

```
<Window x:Class="TransformingVideo.MainWindow"

    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"

    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"

    Title="MainWindow" Height="350" Width="525">

    <Grid>

        <MediaElement Source="d:\wmvfiles\Clip_1080_5sec_vc1_15mbps.wmv" Margin="41,0,27,36" Name="myMedia" LoadedBehavior="Manual">

            <MediaElement.LayoutTransform>

                <TransformGroup>

                    <RotateTransform Angle="400" />

                </TransformGroup>

            </MediaElement.LayoutTransform>

        </MediaElement>

        <Button Height="23" Margin="104,0,99,18" Name="button1" VerticalAlignment="Bottom" Click="button1_Click">Play</Button>

    </Grid>

</Window>
```

在 Listing 12.53 中，`MediaElement`控件已添加到窗口中。`MediaElement`控件已添加到应用程序中，该控件使用`RotateTransform`类进行转换。`Button`控件已添加到应用程序中，并在`Button`控件的`Click`事件上添加了代码以播放媒体文件。`Button`控件的`Click`事件代码在 Listing 12.54 中给出：
