
- 在 `printf` 语句中对变量使用地址符 `&` 将导致运行时错误。
- 使用 `%[^n]` 读取空白字符。
- 在 `scanf` 函数调用中，始终为所有要读取的值提供与其相符的完整字段规范。
- 使用 `%o` 打印八进制整数，使用 `%x` 打印十六进制数。
- 使用 `L` 进行长双精度 `long double` 转换。
- 使用 `0` 标志使输出中出现前导零。
