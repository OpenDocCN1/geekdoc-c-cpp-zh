
## 图例布局控制

随着行数的增加，绘图区域会减小。在示例中，`DOWN=2` 意味着“将所有项目放在两行，并启动必要的列”。

```sas
layout overlay;
  scatterplot x=Height y=Weight / name="sp" group=age;
  discretelegend "sp" / title="Age" order=columnmajor down=2;
endlayout;
```

### 控制标签和项目的大小

要控制图例标签的大小，可以使用 `DISCRETELEGEND` 语句中的 `SIZE=` 选项。默认情况下，图例中项目（如标记、填充框和填充泡）的大小无论字体大小如何都保持固定。

当增大标签字体时，标签可能会与项目比例失调。你可以在 `DISCRETELEGEND` 语句中包含 `AUTOSIZE=TRUE`，使标记、填充框和填充泡的大小根据字体大小自动调整。`AUTOSIZE` 选项不影响线条项目。当 `AUTOSIZE=TRUE` 时，如果你更改标签字体，图例中的任何标记、填充框和填充泡将自动保留以与标签保持比例。

```sas
layout overlay;
  scatterplot x=Height y=Weight / name="sp2" group=age;
  discretelegend "sp2" / title="Age" valueattrs=(size=1pt) autosize=true;
endlayout;
```

## 从离散图例中添加和删除项目

### 向图例添加项目

你可以使用 `LEGENDITEM` 语句手动添加图中未出现的项目。这允许你为图表提供额外信息，或构建一个适用于多个图表的公共图例。`LEGENDITEM` 语句的语法如下：

```sas
LEGENDITEM TYPE=Entry NAME=LegendName / options;
```

你必须将 `LEGENDITEM` 语句放在模板定义语句和第一个布局语句之间的全局定义区域。`TYPE=Entry` 选项指定要添加到图例的类型。`Entry` 可以是以下之一：

- `LINE`
- `MARKER`
- `TEXT`

设置项目所需外观的选项，例如颜色、模式、字体等。关于 `LEGENDITEM` 语句请注意：

- 无论类型如何，你都可以为图例项目指定任何支持的属性集。但不适用于图例项目的属性集会被忽略。例如，在 `LEGENDITEM` 语句中，如果指定了 `TYPE=FILL` 和 `MARKERATTRIBUTES=( )`，会被忽略。
- 当 `TYPE=TEXT` 时，如果 `LEGENDITEM` 语句中没有指定 `TEXT=` 选项，默认使用空格。

这是一个 `LEGENDITEM` 示例，在按年龄分组的高度体重图图例中添加了项目 17。新项目使用红色填充星作为标记。

```sas
proc template;
  define statgraph additem;
    dynamic legenditem;
    begingraph;
    entrytitle "Height vs. Weight By Age";
    legenditem type=marker name="newitem" / label="17"
      lineattrs=(color=red)
      markerattrs=(symbol=starfilled color=red);
    layout overlay;
      scatterplot x=height y=weight / group=age name="height";
      discretelegend "height" "newitem";
    endlayout;
  endgraph;
run;

proc sgrender data=sashelp.class template=additem;
```

注意 `DISCRETELEGEND` 语句指定了每个 `SCATTERPLOT` 和 `LEGENDITEM` 语句中 `NAME=` 选项指定的名称。这会将新项目和自动生成的图图例合并为一个图例。在示例中，新项目 17 及其红色填充标记附加到图例现有项目中。你可以包含多个 `LEGENDITEM` 语句来向图例添加多个项目。

### 从图例中删除项目

要从图例中删除一个或多个项目，请使用 `DISCRETELEGEND` 语句上的 `EXCLUDE` 选项。`EXCLUDE` 指定要删除的项目标签如下：

```sas
EXCLUDE("itemLabel" "itemLabel" ...);
```

每个项目都包含在引号内，并且匹配数据值的格式化字符串。对于两个或多个项目，每个标签之间用空格分隔。字符串匹配区分大小写。这是一个从图例中删除组 13 和 15 的示例。

```sas
proc template;
  define statgraph order;
    begingraph;
    layout overlay;
      scatterplot X=Height Y=Weight / name="sp" group=age;
      discretelegend "sp" / title="Age" sortorder=ascendingformatted exclude="13" "15";
    endlayout;
  endgraph;
run;

proc sgrender data=sashelp.class template=order;
```

### 过滤由多个图表语句贡献的项目

当多个图表语句贡献图例时，你可以使用 `DISCRETELEGEND` 语句中的 `TYPE=` 选项仅包含特定类型的项目。你可以指定以下类型之一：

- `ALL`
- `LINE`
- `FILL`
- `LINECOLOR`
- `MARKERCOLOR`
- `FILLCOLOR`
- `LINEPATTERN`
- `MARKERSYMBOL`

注意：如果没有项目匹配 `TYPE=` 选项指定的类型，则在图中不会绘制图例。

这是一个示例，它在显示线条和标记的系列图中，仅在图例中包含标记项。

```sas
proc template;
  define statgraph plots;
    begingraph;
    entrytitle "Closing Price and Volume for 2002";
    layout overlay;
      seriesplot x=date y=close / group=stock name="plot1" display=all;
      discretelegend "plot1" / title="Stock" type=marker;
    endlayout;
  endgraph;
run;

proc sgrender data=sashelp.stocks template=plots;
  where date between '01JAN2002'd and '31DEC2002'd;
run;
```

## 将两个图表的图例项合并为一

你可以使用 `MERGEDLEGEND` 语句将两个分组图表的图例项合并到一个图例中。基本语法如下：

```sas
MERGEDLEGEND "graph1" "graph2" / options;
```

`MERGEDLEGEND` 使用的选项与 `DISCRETELEGEND` 语句使用的选项相似。以下是 `MERGEDLEGEND` 语句的限制条件：

- 必须提供恰好两个图表名称。
- 每个图表名称必须包含在引号中。
- 仅支持分组图表。
- 仅支持具有线条和标记叠加的图表。

在合并过程中，会比较两个图表的组值。图例指定的重复组值将合并为一个图例项，然后与唯一项合并为一个图例。如果项无法合并，SAS 日志中将出现以下警告信息：

> WARNING: MERGEDLEGEND statement does not reference two plots whose items can be properly merged. The legend will not be displayed.

如果你收到此消息，请验证两个参与的图表都是分组的，并且使用了线条和标记叠加。以下示例显示了一个系列图和一个散点图，并将它们合并为一个合并图例和一个离散图例，两者并排显示以便进行比较。

```sas
proc template;
  define statgraph plots;
    begingraph;
    entrytitle "Closing Price and Volume for 2002";
    layout overlay /
      xaxisopts=(griddisplay=on gridattrs=(color=lightgray pattern=dot))
      yaxisopts=(griddisplay=on gridattrs=(color=lightgray pattern=dot));
      seriesplot x=date y=volume / group=stock name="plot1";
      scatterplot x=date y=volume / group=stock name="plot2" yaxis=y2;
      discretelegend "plot1" "plot2" / title="Discrete Legend" across=2 down=1 valign=bottom order=columnmajor halign=left;
      mergedlegend "plot1" "plot2" / title="Merged Legend" sortorder=ascendingformatted across=1 valign=bottom halign=right;
    endlayout;
  endgraph;
run;

proc sgrender data=sashelp.stocks template=plots;
  where date between '01JAN2002'd and '31DEC2002'd;
run;
```

### 示例输出对比

| 离散图例 | 合并图例 |
| :--- | :--- |
| ○ IBM | ○ IBM |
| ○ Intel | ○ Intel |
| ○ Microsoft | ○ Microsoft |

在此示例中，`SERIESPLOT` 语句创建了按股票分组的收盘价系列图。`SCATTERPLOT` 语句创建了按股票分组的成交量散点图。注意两个图表都是分组的，并且 `MERGEDLEGEND` 语句中恰好使用了两个图表名称。如图所示，离散图例每个股票包含两个项，由于 `SORTORDER=AUTO`，每个图表的项按其出现的顺序排列。相反，合并图例每个股票仅包含一项（它是两个图表项的叠加）。你可以使用 `MERGEDLEGEND` 语句中的 `SORTORDER` 选项对合并图例中的项进行排序。在这种情况下，由于数据已经排序，`SORTORDER=ASCENDING` 和 `AUTO` 的效果相同。

## 创建全局图例

当使用多个离散图例时，可以使用 `LAYOUT LEGEND` 块将所有离散图例和合并图例合并为一个全局图例。全局图例有以下限制：

- 每个模板只允许一个 `LAYOUT LEGEND` 块。
- 必须在 `BEGINGRAPH/ENDGRAPH` 块中包含 `LAYOUT LEGEND`。
- 任何位于 `LAYOUT LEGEND` 块之外的 `DISCRETELEGEND` 或 `MERGEDLEGEND` 语句将被忽略。
- 全局图例只能单行或单列排列。
- 不支持 `CONTINUOUSLEGEND` 语句。

要将图例合并为全局，要在 `LAYOUT LEGEND` 中包含所有的 `DISCRETELEGEND` 和 `MERGEDLEGEND` 语句。生成的全局图例位于图表底部。可以使用 `TITLE=` 选项为全局图例添加标题。你也可以在每个 `DISCRETELEGEND` 或 `MERGEDLEGEND` 语句中使用 `TITLE=` 选项为离散图例添加标题。

## 图例裁剪处理

> 警告：带有 `DISPLAYCLIPPED=FALSE` 的 `DISCRETELEGEND` 语句正在被裁剪。图例将不会绘制。

要调查此问题，您可以在 `DISCRETELEGEND` 语句中指定 `DISPLAYCLIPPED=TRUE`，这将强制显示图例，以便您进行视觉检查。

```sas
discretelegend "sp" / title="Name" across=2 halign=right displayclipped=true;
```

在当前示例中，显而易见的是输出的高度不足以分两列显示标题和所有条目。可以通过以下任何方式解决此问题：

- 增加图表高度（`ODS GRAPHICS` 语句中的 `HEIGHT` 或 `BEGINGRAPH` 语句中的 `DESIGNHEIGHT=`）
- 重新定位图例并使用 `ACROSS=` 或 `DOWN=` 选项对其重新组织
- 如果您只想查看部分图例，则设置 `DISPLAYCLIPPED=TRUE`
- 缩小图例条目的字体大小（可能还有标题）

要更改图例条目的字体大小，请在图例语句中使用 `VALUEATTRS` 选项。要更改图例标题的字体大小，请使用 `TITLEATTRS` 选项。通常，图例条目显示为 9pt，图例标题显示为 10pt。以下示例缩小了图例文本的大小：

```sas
discretelegend "sp" / title="Name" across=2 halign=right valueattrs=(size=7pt) titleattrs=(size=8pt);
```

# 连续图例的功能

### 可以使用连续图例的图

连续图例将响应变量的数据范围映射到颜色范围。当指定启用绘图选项时，连续图例可用于以下图语句。

| 图语句 | 启用绘图选项 | 相关绘图选项 |
| :--- | :--- | :--- |
| `CONTOURPLOTPARM` | `CONTOURTYPE=` | `COLORMODEL=` `REVERSECOLORMODEL=` `NLEVELS=` `NHINT=` |
| `HEATMAPPARM` | `COLORRESPONSE=` | `COLORMODEL=` |
| `SCATTERPLOT` | `MARKERCOLORGRADIENT=` | `COLORMODEL=` `REVERSECOLORMODEL=` |
| `SURFACEPLOTPARM` | `SURFACECOLORGRADIENT=` | `COLORMODEL=` `REVERSECOLORMODEL=` |

等高线图提供了 `CONTOURTYPE=` 选项，您可以使用它来管理等高线的显示。

除了 `LINE` 和 `LABELEDLINE` 之外，所有支持等高的变体都有显示所需的 `Z=` 列值的图例。例如，以下代码生成了一个带有 `CONTOURTYPE=FILL` 的等高线图：

```sas
proc template;
  define statgraph contour;
    begingraph;
    entrytitle "CONTOURTYPE=FILL";
    layout overlay xaxisopts=(offsetmin=0 offsetmax=0) yaxisopts=(offsetmin=0 offsetmax=0);
      contourplotparm x=Height y=Weight z=Density / name="cont" contourtype=fill;
      continuouslegend "cont" / title="Density";
    endlayout;
  endgraph;
run;

proc sgrender data=sashelp.gridded template=contour;
  where height=53 and weight=225;
run;
```

如果将其更改为 `CONTOURTYPE=GRADIENT`，将得到如下输出：

对于 `FILL` 等高线，Z 变量被分成等大的值范围，每个范围分配了不同的颜色。连续图例显示值范围和相关的颜色，这是一个带有轴的长颜色条带。等高线选项 `NHINT=` 和 `NLEVELS=` 用于更改等高线的级别（范围）数量。`NHINT=10` 请求接近十个间隔，在图例中显示效果为“良好”。`NLEVELS=10` 强制使用十个级别。

```sas
contourplotparm x=Height y=Weight z=Density / name="cont" contourtype=fill nhint=10;
continuouslegend "cont" / title="Density";
```
