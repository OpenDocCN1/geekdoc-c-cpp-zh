# 排序

上一节讨论了搜索算法。在本节中，我们将讨论如何使用该算法对数组进行排序，该算法称为选择排序（selection sort）。

正如名称所示，在选择排序算法中，我们通过选择列表中的一个元素并移动到适当的位置来重新排列列表。该算法在列表中未排序部分找到最小元素的位置，并将其移动到未排序部分的顶部。第一次，我们在整个列表中定位最小的项。第二次，我们从列表的第二个元素开始在列表中定位最小项，以此类推。
