
# 简单的 3x2 网格

```sas
layout gridded / columns=3 rows=2 columnwidth=10 rowheight=10;

/* 独立图形语句定义单元格 1-3 */
boxplot x=sex y=age;
boxplot x=sex y=height;
boxplot x=sex y=weight;

/* overlay 块定义单元格 4-5 */
layout overlay;
  scatterplot y=weight x=height / group=sex name="scatter";
  pbsplineplot y=weight x=height;
  entry halign=right "Spline" / valign=bottom;
endlayout;

layout overlay;
  scatterplot y=weight x=height / group=sex;
  loessplot y=weight x=height;
  entry halign=right "Loess" / valign=bottom;
endlayout;

/* legend 定义单元格 6 */
discretelegend "scatter" / title="Sex";
endlayout;
```

在这种情况下，图例的高度和宽度小于默认的列和行尺寸，图例恰好放入了空单元格中。

## 定义基础布局

以下示例显示了一个非常简单的 `LATTICE` 布局：

```sas
proc template;
  define statgraph intro;
    begingraph;
      entrytitle "Two-Cell Lattice Layout";
      layout lattice;
        barchart category=age;
        scatterplot x=height y=weight;
      endlayout;
    endgraph;
  end;
run;

proc sgrender data=sashelp.class template=intro;
run;
```

![](img/a9ccb6123dee40d424cb295a3a99c16c_237_0.png)

在 `LATTICE` 布局中，每个图语句被认为是独立的并放在单独的单元格中。在没有提供网格大小的情况下，默认布局创建一个单列单元格，并为每个单元格分配相同的空间。网格的行数由布局块中独立图语句的数量决定。

## 设置网格维度

假设你需要一个包含五个图的网格。在编写代码之前，必须先确定要设置的网格维度（多少列多少行）以及是否允许存在空单元格。如果你不需要空单元格，则必须将网格限制为五个单元格，这为你提供了两种维度选择：五列一行或一列五行。

要指定网格大小，使用 `LAYOUT LATTICE` 语句中的 `ROWS=` 和 `COLUMNS=` 选项。可以通过以下方式使用这些选项来创建如下网格：

|---|---|---|---|---|---|

```sas
layout lattice / columns=5 rows=1;
```

如果你想要一列五行：

```sas
layout lattice / columns=1 rows=5;
```

## 添加单元格头

要在网格中添加单元格头，你必须指定一个 `CELL`，其中包含一个嵌套的 `CELLHEADER` 块，该块可以包含一个或多个 `ENTRY` 语句，也可以包含其他语句（例如，`DISCRETELEGEND`）。

```sas
/* cell blocks cells 1-3 */
cell;
  cellheader;
    entry "Spline Fit";
  endcellheader;
  layout overlay;
    scatterplot y=weight x=height;
    pbsplineplot y=weight x=height;
  endlayout;
endcell;

cell;
  cellheader;
    entry "Loess Fit";
  endcellheader;
  layout overlay;
    scatterplot y=weight x=height;
    loessplot y=weight x=height;
  endlayout;
endcell;
```

## 定义一个基础晶格

```sas
cell;
  cellheader;
    entry "Regression Fit";
  endcellheader;
  layout overlay;
    scatterplot y=weight x=height;
    regressionplot y=weight x=height;
  endlayout;
endcell;
endlayout;
```

![](img/a9ccb6123dee40d424cb295a3a99c16c_242_0.png)

你可以通过以下方式增强任何单元格头：

- 在 `CELLHEADER` 块中嵌套一个 `GRIDDED` 布局
- 在 `LAYOUT GRIDDED` 语句中设置 `BORDER=TRUE`
- 将 `ENTRY(s)` 添加到 `GRIDDED` 布局中

`GRIDDED` 布局填充了图表墙上方的单元格头空间，其边界与图表对齐良好。你可以通过将 `GRIDDED` 布局的背景设置为不透明并为其设置背景颜色来进一步增强单元格头。为了确保颜色与当前样式协调，你可以选择定义浅色背景色的几种样式元素之一，例如 `GraphHeaderBackground`、`GraphBlock` 或 `GraphAltBlock`。注意，某些样式定义将 `GraphHeaderBackground` 设置为与 `GraphBackground` 相同。对于 `LISTING` 和 `JOURNAL` 样式，背景为白色。

作为最后的增强，你可以将单元格头的文本颜色与图表中的视觉属性进行协调。例如，如果你在单元格中显示拟合结果，你可以让文本颜色与线条颜色匹配。`ENTRY` 语句中的 `TEXTATTRS` 选项可用于设置文本属性。`TEXTATTRS` 的默认设置派生自 `GraphValue` 样式元素。关于 `ENTRY` 语句的更多信息，请参见第 157 页第 7 章“更改图中的文本”。

以下代码增强了第一个单元格的单元格头块。类似的代码将用于增强其他两个单元格的头：

```sas
cellheader;
  layout gridded / border=true opaque=true backgroundcolor=GraphAltBlock;
    entry "Spline Fit" / textattrs=(color=GraphFit:contrastColor);
  endlayout;
endcellheader;
```

## 跨行或列创建统一轴

### 内部轴

默认情况下，`LATTICE` 布局中单元格的图表管理它们自己的轴，如下例所示：

```sas
proc template;
  define statgraph internalaxes;
    begingraph;
      entrytitle "Internal (cell-defined) Axes";
      layout lattice / columns=2 colgutter=5px;
        histogram mpg_city;
        histogram mpg_highway;
      endlayout;
    endgraph;
  end;
run;

proc sgrender data=sashelp.cars template=internalaxes;
run;
```

## 跨行或列创建统一轴

![](img/a9ccb6123dee40d424cb295a3a99c16c_244_0.png)

在此示例中，注意每个单元格的 X 轴和 Y 轴范围不同。当你希望方便比较单元格内容时，可以在网格跨行设置统一的轴比例，或跨列，或两者都设置。

### 统一轴范围

要在晶格的每行的 X 轴上设置统一比例，请使用 `LAYOUT LATTICE` 语句上的 `COLUMNDATARANGE=` 选项。同样，要在晶格的每行的 Y 轴上设置统一比例，请使用 `ROWDATARANGE=` 选项。这些选项接受以下值之一：

- `DATA`：为每个单元格独立缩放轴。这是默认值。
- `UNION`：找到行或列之间数据最小值和数据最大值，并将此范围应用于每个单元格。
- `UNIONALL`：找到所有单元格数据最小值和数据最大值，并设置此范围。

```sas
layout lattice / columns=2 colgutter=5px columndatarange=unionall rowdatarange=union;
  histogram mpg_city;
  histogram mpg_highway;
endlayout;
```

### 外部轴

#### 指定外部轴

每当使用行或列轴时，你可以将该行或列中的单个单元格替换为单个轴。

要将 X 轴外部化，使用以下语法：

```sas
columnaxes;
  columnaxis / options;
  <columnaxis / options>;
endcolumnaxes;
```

要将 Y 轴外部化，使用以下语法：

```sas
rowaxes;
  rowaxis / options;
  <rowaxis / options>;
endrowaxes;
```

在块内部，你应该根据网格中的列或行数指定相应的 `COLUMNAXIS` 或 `ROWAXIS` 语句。可选项是 `LAYOUT OVERLAY` 语句中的 `XAXISOPTS` 和 `YAXISOPTS`。你指定的选项在语句之间有所不同。

注意：当使用行或列外部轴时，该维度上的所有内部轴选项将被忽略。

以下代码将 Y 轴外部化：

```sas
layout lattice / columns=2 colgutter=5px columndatarange=unionall rowdatarange=union;
  histogram mpg_city;
  histogram mpg_highway;
  rowaxes;
    rowaxis / griddisplay=on;
  endrowaxes;
endlayout;
```
