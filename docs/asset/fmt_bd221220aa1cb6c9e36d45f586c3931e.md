
`System.Object`

`System.Activities.WorkflowInvoker`

您可以使用 `WorkflowInvoker` 类的 `Invoke()` 方法调用工作流或活动。以下代码片段显示了 `WorkflowInvoker` 类的 `Invoke()` 方法的使用：

```
Activity myworkflow = new WriteLine(Text = "WELCOME");

workflowInvoker.Invoke(myworkflow);
```

在前面的代码片段中，创建了一个 `WriteLine` 活动（`myWorkflow`）。然后，将 `myWorkflow` 活动作为参数传递给 `WorkflowInvoker` 类的 `Invoke()` 方法。

您可以通过使用输入参数列表将数据传递到工作流中，如以下代码片段所示：

```
Activity myworkflow = new WriteLine();

Dictionary<string, object> inputdata = new Dictionary<string, object>();

inputdata.Add("Text", " WELCOME ");

workflowInvoker.Invoke(myworkflow, inputdata);
```

在前面的代码片段中，创建了一个 `WriteLine` 活动，并且其 `Text` 参数的值由输入参数字典提供。您还可以通过其输出参数从工作流中获取数据。

## WorkflowApplication 类

`WorkflowApplication` 类用于托管单个工作流实例。它属于 `System.Activities` 命名空间。`WorkflowApplication` 类的类层次结构如下所示：

```
System.Object

System.Activities.Hosting.WorkflowInstance

System.Activities.WorkflowApplication
```

`WorkflowApplication` 类提供了各种方法来创建和加载工作流实例以及暂停、恢复和终止工作流生命周期的事件。当您使用 `WorkflowApplication` 类运行工作流时，您必须创建 `WorkflowApplication` 类的实例并在工作流中指定一个或多个生命周期事件。接下来，您必须使用 `Run()` 方法启动工作流，并使用 `WaitOne()` 方法等待其完成。请考虑以下代码片段：

```
AutoResetEvent autoEvent = new AutoResetEvent(false);

Activity myworkflow = new WriteLine
{
    Text = " WELCOME "
};

WorkflowApplication myWFApp = new WorkflowApplication(myworkflow);

myWFApp.Completed = delegate(WorkflowApplicationCompletedEventArgs e)
{
    autoEvent.Set();
};

myWFApp.Run();

autoEvent.WaitOne();
```

在前面的代码片段中，使用 `WriteLine` 活动定义了一个工作流（`myWFApp`），然后使用 `myWFApp` 工作流定义创建了 `WorkflowApplication` 类的实例。通过调用 `Run()` 方法启动 `myWFApp` 工作流。处理 `Completed` 事件，以便在工作流完成时通知主机。此外，设置 `AutoResetEvent` 以使主机应用程序能够恢复工作流的执行。

## WorkflowServiceHost 类

`WorkflowServiceHost` 类支持多个工作流实例并允许发送和接收消息。它属于 `System.ServiceModel` 命名空间。`WorkflowServiceHost` 类用于配置和公开工作流作为服务以供客户端应用程序使用，当您不使用 Internet Information Services (IIS) 或 Windows Activation Services (WAS) 来公开服务时。`WorkflowServiceHost` 类的类层次结构如下所示：

```
System.Object

System.ServiceModel.Channels.CommunicationObject

System.ServiceModel.ServiceHostBase

System.ServiceModel.Activities.WorkflowServiceHost
```

### 创建和恢复书签

在本节中，我们创建一个工作流控制台应用程序，名为 `BookmarkResume`（也可在 CD 上获得）。在此应用程序中，我们创建和恢复一个书签。

执行以下步骤来创建 `BookmarkResume` 应用程序：

- 1. 创建一个工作流控制台应用程序，`BookmarkResume`。
- 2. 在 `Program.cs` 文件中添加以下命名空间：
  - `using System.Threading;`
- 3. 在 `Program` 类的 `Main()` 方法中添加以下代码片段：

```
Variable<string> name = new Variable<string>
{
    Name = "name"
};

Activity wf = new Sequence
{
    Variables =
    {
        name
    },
    Activities =
    {
        new WriteLine()
        {
            Text = "Enter your name:"
        },
        new ReadLine()
        {
            BookmarkName = "YourName",
            Result = name
        },
        new WriteLine()
        {
            Text = new InArgument<string>((env) => "Hello, " + name.Get(env)+"\nYou are reading C# 2010 Black book")
        }
    }
};

AutoResetEvent syncEvent = new AutoResetEvent(false);

WorkflowApplication wfApp = new WorkflowApplication(wf);

wfApp.Completed = delegate(WorkflowApplicationCompletedEventArgs e)
{
    syncEvent.Set();
};

wfApp.Run();

wfApp.ResumeBookmark("YourName", Console.ReadLine());

syncEvent.WaitOne();
```

在前面的代码片段中，创建了一个使用 `ReadLine` 活动获取用户输入的工作流。`ReadLine` 活动还创建了一个书签 `YourName`，并等待书签被恢复。当主机进程收集输入数据并恢复书签时，工作流将被恢复，输入将在控制台上显示。

- 4. 在 `Program` 类中 `Main()` 方法外部添加一个 `ReadLine` 活动，通过编写以下代码片段：

```
public sealed class ReadLine : NativeActivity<string>
{
    [RequiredArgument]
    public InArgument<string> BookmarkName { get; set; }
    protected override void Execute(NativeActivityContext context)
    {
        context.CreateBookmark(BookmarkName.Get(context), new BookmarkCallback(OnResumeBookmark));
    }
    protected override bool CanInduceIdle
    {
        get { return true; }
    }
    public void OnResumeBookmark(NativeActivityContext context, Bookmark bookmark, object obj)
    {
        Result.Set(context, (string)obj);
    }
}
```
