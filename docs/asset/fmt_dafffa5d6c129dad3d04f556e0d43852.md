# 1.2 准备知识二：指数和科学计数法

许多工程和科学应用需要处理巨大的数字和极小的数字。例如，化学中使用的阿沃伽德常数值为 `6.022 × 10^23`，用于航空航天应用的通用引力常数值为 `0.000000000067428`。为了方便在计算机程序中输入这些数字，可以将它们写成更紧凑的形式，即指数计数法。同样，在进行验证目的的手算时，通常会使用一种称为科学计数法的等效表示法。

| 小数表示法 | 指数计数法 | 科学计数法 |
|---|---|---|
| 1625 | 1.625e3 | `1.625 × 10^3` |
| 63421 | 6.3421e4 | `6.3421 × 10^4` |
| .00731 | 7.31e-3 | `7.31 × 10^-3` |
| .000625 | 6.25e-4 | `6.25 × 10^-4` |

在表示法中，字母 `e` 代表“指数”。其后的数字代表 `10` 的幂。

### 使用科学计数法

- 规则 1：`10^n × 10^m = 10^(n+m)`
- 规则 2：`10^-n`

```
10^2 × 10^5 / 10^4 = 10^(2+5-4) = 10^3
```
