## 为控件指定访问字符

访问字符使您能够使用 `ALT` 键通过键盘选择控件。假设在应用程序中，如果您想将 Welcome 按钮标题中的 `W` 设为访问字符，只需按 `ALT+W` 键并单击该按钮即可。为 `Button` 控件指定访问字符，您将其 `AccessKey` 属性设置为 `W`。当您按下访问字符时，按钮的 `Click` 事件会执行并调用 `Click` 事件处理程序。

## 显示页面的生命周期

每当用户与网页交互时，就会生成一个事件。一组称为页面事件的事件会在 ASP.NET 中页面加载时自动触发。当事件生成时，网站会执行与生成事件相关的适当任务。当您向 Web 服务器发送对特定页面的请求时，页面在服务器端创建和客户端释放期间会经历一系列事件。这一整套事件集合称为页面的生命周期。正如您在阅读本章 In Depth 部分中关于页面事件的内容后所了解的那样，我们创建一个名为 `PageLifeCycle` 的网站来显示网页的生命周期。该网站项目也可在 CD-ROM 上找到。为此，请执行以下步骤：

- 1. 将以下代码添加到应用程序的 `Default.aspx.cs` 文件的代码隐藏文件中：

## 处理事件

到目前为止我们处理的事件类型是在服务器上处理的，而不是在浏览器中。然而，等待事件在服务器上处理可能是一个乏味的过程。因此，您也可以向网页添加脚本以支持客户端事件。通常，我们将在 Web 应用程序中坚持使用服务器端代码，但您也可以让浏览器在客户端处理一些事件。

你必须使用浏览器能够理解的脚本语言，因为你是在浏览器中处理事件，而不是在服务器上使用 Visual C#。

让我们创建一个名为 `HandlingClientEvents` 的新 Web 应用程序，以展示如何处理事件。此示例也可在 CD-ROM 上找到。在这种情况下，我们只是在 Web 表单中添加一个 `Button` 控件和一个 `TextBox` 控件，然后使用客户端 JavaScript 代码在按钮被点击时在文本框中显示文本。为此，请执行以下步骤：

- 1. 在应用程序的 Default Web 页面中添加一个 `Button` 控件和一个 `TextBox` 控件，然后为按钮设置 `Click Me` 标题。
- 2. 添加按钮的客户端 `Click` 事件的 JavaScript 代码，该事件在 HTML 中称为 `onClientClick`。为此，你可以使用主 Web 表单的代码设计器中的下拉列表框，就像为 Windows 控件添加事件处理程序一样。当你看到 Web 表单的 HTML 时，你就可以使用 IntelliSense 菜单为所选控件添加事件，例如按钮，如图 13.45 所示：
