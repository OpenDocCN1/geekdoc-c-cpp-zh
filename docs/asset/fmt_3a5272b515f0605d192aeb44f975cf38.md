### 顺序，顺序！

算法的步骤需要按照正确的顺序才能生效。算法中步骤的顺序被称为序列。

当我们写算法时，我们必须确保步骤顺序正确。例如，当我们穿衣服时，如果我们在穿袜子之前穿鞋，那就太蠢了！

### 循环

有时，我们需要计算机重复执行某项任务。我们把这些指令称为循环。当我们走路时，我们的脚在交替。当我们骑自行车时，我们的脚在转动。为了让计算机重复执行这些事情，我们可以使用循环。

数据鸭子

当有需要重复的操作或指令时，我们就使用循环。例如，为了让它穿过屏幕，我们在第10页让它“移动10步”。另一种方法是把指令放在循环中，如下：

```

移动10步
```

### 抉择，抉择！

有时候，计算机只有在满足特定条件时才执行某些操作。为了做到，它们使用“if 语句”（条件语句）来做决定。

例如，如果我们告诉数据鸭向右移动，我们需要确保它不会离开页面。

```
repeat 5 times
move 10 steps
If on edge of page, reverse direction
```

计算机需要对数据鸭今天应该穿什么做出决定。首先，它会检查天气。然后，它将查看一系列“if 语句”来决定做什么：

如果是晴天，告诉数据鸭戴上墨镜。

如果是雨天，告诉数据鸭带上伞。

如果是雪天，告诉数据鸭戴上冬帽。

### 寻找虫虫

算法非常有用，但有时它们无法正常工作，我们需要找出原因。算法的问题被称为“bug”（虫错误）。

当程序员阅读算法以寻找错误并修复它们时，这被称为“调试”（debugging）。错误可能是缺少了步骤，或者是步骤的顺序错了。

> 数据鸭

当计算机被发明时，它们是是巨大的！有一天，其中一台大机器无法工作了。当科学家将其拆开时，发现里面有一只蛾子（moth）！这就是我们使用“bug”这个词的原因。

## 记忆词汇

**animate**动画：让屏幕上的东西活起来。
**bug**：计算机程序中的错误。
**debugging**调试：寻找并移除计算机程序中的 bug 或错误。
**loop**循环：最后一步与第一步连接的重复步骤。
**memory**记忆：计算机中存储信息的方式。
**sequence**顺序：步骤遵循的特定顺序。
**variable**变量：可以改变或调整的东西。
