# DetailsView

`DetailsView` 控件是一种数据绑定控件，允许你一次查看一条记录。虽然 `GridView` 控件是查看数据集的优秀控件，但在许多场景下，你希望显示单个记录而不是整个集合。`DetailsView` 控件允许实现此操作，并提供了与 `GridView` 许多相同的数据操作和显示功能。
