## In Depth

线程是一系列必须按特定顺序执行的指令，以便在程序内执行特定任务。正在执行的程序称为进程，线程可以是正在执行程序的一部分。进程在操作系统（OS）中执行；而线程在进程内执行。因此，线程也被称为轻量级进程。线程与进程之间一个主要区别是，进程彼此完全隔离。这意味着一个进程的运行不会影响操作系统中运行的另一个进程的运行。然而，线程可以与同一应用程序中运行的其他线程共享内存。例如，一个线程可以在后台获取数据，而另一个线程可以同时显示由第一个线程接收到的数据。进程的执行从`Main()`线程开始，该线程在进程执行时自动启动；而其他线程需要通过传递`Thread`类的方法来启动。如果一个进程包含一个以上的线程，则称为多线程。多线程应用程序能够同时执行多个任务，例如在同一操作系统上创建应用程序、下载电影和收听音乐。为了确保线程在多线程环境中的顺畅运行，您需要根据线程需要执行的任务为线程分配优先级级别。

在本章中，您将学习`Thread`类及其方法和属性。接下来，本章讨论了多线程的概念，该概念促进了在进程中同时运行多个任务。您还将学习可以分配给线程的各种优先级级别。本章随后继续讨论线程的各种状态。最后，您将学习如何在多线程环境中同步线程以避免任何死锁情况。

你可以在C#程序中使用`Thread`类来创建线程，该类接收`ThreadStart`委托。下面的语法展示了如何定义`ThreadStart`委托：

```
public delegate void ThreadStart();
```

现在让我们来看下面的代码片段，以了解在C#程序中创建和启动线程的`Thread`类和`ThreadStart`委托的语法：

```
class MyThreadClass
{
    static void Main()
    {
        //Creating an object of the Thread class
        Thread MyThread = new Thread(new ThreadStart(MyFunction));
        MyThread.Start();
    }
    static void MyFunction() {
        Console.WriteLine("This is my Thread");
        Console.ReadLine();
    }
}
```

在前面的代码片段中，你可以看到使用名称`MyThread`创建了`Thread`类的一个对象，并且在`Thread`类的构造函数中传递了`ThreadStart`委托。`ThreadStart`委托表示C#程序的执行应从`MyFunction()`方法开始。在此示例中，`MyThread`线程在`Main()`线程调用`MyFunction()`方法的同时（或几乎同时）执行`MyFunction()`方法。`Start()`方法使`MyThread`线程开始。

在C#中，你也可以通过使用实例化委托的快捷语法更方便地创建线程，如下面的代码片段所示：

```
static void Main()
{
    Thread MyThread = new Thread (MyFunction);    // No need to explicitly use the
    MyThread.Start();                            //ThreadStart delegate
    ...
}
static void MyFunction()
{
    ...
}
```

在这种情况下，C#编译器会自动确定`ThreadStart`委托。
