
让我们进一步考虑 GAP 的对数空间可归约性。事实证明，许多对于经典类（如 `L`）完全的问题在 `≤_L` 下保持完全。这是因为很容易证明对于 P 完全的语言是 `≤_L` 但不是 P-完全的。见练习题。

虽然存在有趣的子复杂度，但它表明完全问题对于对数空间和 P 之间的任何确定性 P 空间边界都是完全的。Magen 和 Sudan 定义了所谓的 GAP 问题的“有界版本” [20]。对于此，如果每条边 `(i, j)` 都满足 `|i-j| ≤ m`，我们称 `G` 的带宽最多为 `m`。

## 5.3 P 的完全性问题

### 5.3.1 单位解析

我们首先证明在解析系统上的证明是 P-完全的。这实际上是上一节开始的主题的一部分，我们在上一节中证明了 2UNSAT 是 NLOG-完全的。也就是说，我们展示了一组与定理证明相关的问题，每个问题在我们的范式中都是完全的。

解析证明的基本概念很简单：如果 `C` 和 `C'` 是可解析的，则存在文字 `u` 使得 `u ∈ C` 且 `\bar{u} ∈ C'`。它们的结为 `C^u = (C ∪ C') \ {u, \bar{u}}`。该结的规则是

被称为消结规则（也称为湮灭规则或剪切规则），其中文字 `u` 和 `\bar{u}` 被消灭。单位子句（unit clause）是指包含一个文字的子句。如果 `C` 或 `C'` 中有一个是单位子句，我们称解式 `C'` 是 `C` 和 `C'` 的单位解式。如果 `C` 和 `C'` 都是单位子句，则解式为空子句，我们记作 `□`（不是空白符号，但上下文会使其变得很清楚）。空子句是不可满足的。设 `F` 为子句形式的 CNF 公式。从子句序列 `C_1, ..., C_m` 推导出一个子句 `C_m` 称为推导（相应地单位推导），其中每个 `C_i` 属于 `F` 或者是序列中之前两个子句的解式（相应地的单位解式）。关于消结的基本结论如下：

**消结定理。** 如果存在从 `F` 推导出 `□`，则 `F` 是不可满足的。

证明是一个练习题；我们在后续中不使用该定理。`P`-完全问题由 Jones 和 Laaser [2001] 引入。

### 3CNF 公式的单位消结法 (3UNIT)

- 给定：

属性：
- `C` 可以通过单位推导推导出。

我们证明 3UNIT 属于 `P` 类。考虑以下算法，它以一个 CNF 公式 `F` 为输入。如果 `□ ∈ F`，则我们接受它。假设否则。该算法维护三组子句集 `G`, `G'` 和 `H`。初始时，`G'` 为 `G`，包含 `F` 中所有单位子句，`H` 为 `F - G`。在一般，集合 `G` 将仅包含单位子句；但我们可以方便地将它们表示为文字。算法 `G ∩ G' = ∅`。算法执行以下操作：

当 `G ≠ ∅` 时：

1. 选择 `u ∈ G`。令 `G := G - {u}; G' := G' ∪ {u}`。

重要的是，在第 2 行中，子句 `C` 没有从 `H` 中移除（练习题解释了为了消结的正确性）。此外，我们可以一直接受直到生成空子句，但为了证明的需要，我们没有这样做。正确性：我们证明如果 `F ∈ 3UNIT`，则算法被接受。那么在第 3 行使用单位消结规则生成新的子句；`G ∪ G' ∪ H` 中的所有内容都源于原始公式 `F` 或从 `F` 单位推导出。因此，如果算法在第 2 行接受，则 `F` 属于 3UNIT。为了证明逆命题，假设

`C_0, C_1, ..., C_m`（其中 `C_m = □`）

是一个单位推导。我们将证明算法是正确的。需要注意步骤 3 是有限的，因为最多是 `F` 中文字的数量。循环的迭代次数最多为第 `i` 次迭代时 `G` 中文字的数量。`G_i'` 和 `H_i` 类似，并定义为；`E_i := G_i ∪ G'_i ∪ H_i`。同样地，`E_i ⊆ E_{i+1}`。断言：单位推导 (2) 中的 `C_i` 属于某些 `E_i`。特别是 `C_m = □` 出现在某个 `E_i` 中。我们的算法。

复杂度：如上述，循环的迭代次数相对于 `F` 的大小是线性的。由此如果 `F` 有 `k` 个文字，那么子句可能收缩成 `2^k` 个子句。但由于 `F` 是一个 3CNF 公式，新子句的数量与原始公式的数量成线性关系。这一步限制了每次迭代的时间。因此，3UNIT 的算法时间是多项式的。

### 5.3.2 路径系统

我们考虑一个第一个被证明对 P 是完全的的问题。它由 Cook [8] 发明，他将其公式化为 Savitch 定理（第2章）的抽象，并且一个众知的上下文语言属于 `DSPACE(log^2 n)`（见练习题）。

定义。路径系统是一个四元组 `(n, R, S, T)`，其中 `n > 0` 是整数，`R ⊆ [1..n] × [1..n]` 是 `[1..n]` 上的关系，`S` 和 `T` 是 `[1..n]` 的子集。对于每个 `u ∈ [1..n]`，节点 `u` 被称为*可达的*如果 `u ∈ S` 或 `u ∈ T` 或存在 `v` 使得 `(u, v) ∈ R`。如果 `S` 中的某个节点是可达的，则路径系统是*可求解的*。

### 路径系统可达性 (PSA)

给定：一个路径系统 `(n, R, T)`。

属性：系统是可求解的。

我们首先断言 PSA 属于 `P`：图灵接受器通过计算新节点集 `T_0, T_1, ...` 来接受。在初始阶段，它计算 `T_0 = T`。在阶段 `i ≥ 1`，它计算从 `T_{i-1}` 可达的新节点集 `T_i`。当没有更多新节点可达时停止。注意证明中的每个子句最多有 4 个文字。使用类似于证明 3SAT 完全的技巧，可以将这些替换为每个子句 3 个文字的子句。

## 5.4 PSPACE 的完全问题

### 5.4.1 字问题 (Word Problems)

扩展正则表达式的研究产生了高复杂性自然问题的丰富来源。Meyer 和 Stockmeyer [23, 32] 以及 Hunt [18] 是最早利用此类结果的人。给定一个字母表 `Σ`，`Σ` 上的扩展正则表达式要么是递归定义的字符串集合，要么是字母表 `Σ` 加上以下 9 个额外符号：

`λ, +, ·, ^, *, ¬, (`

假设这些符号不在 `Σ` 中。`Σ(λ)` 中的每个符号称为一个原子（atom）。`(Σ)` 上的扩展正则表达式要么是一个原子，要么递归地定义为以下形式之一：

`(α+β), (α · β), (α ∩ β), (α)^*, ¬(α)`

其中 `α` 和 `β` 是扩展正则表达式。每个表达式 `α` 表示一个语言 `(Σ, L(α))`，如下所示：如果 `α` 是原子 `a ∈ Σ ∪ {λ}`，则 `L(α)` 是包含单个单词 `a` 的语言；否则：

- 并集：`L(α+β) = L(α) ∪ L(β)`
- 拼接：`L(α · β) = L(α) · L(β)`
- 交集：`L(α ∩ β) = L(α) ∩ L(β)`
- 平方：`L(α)^2 = L(α) · L(α)`
- 克莱尼星：`L(α^*) = ⋃_{i:0} L(α)^i`
- 补集：`L(¬α) = Σ^* - L(α)`

注意，如果它被表示为不同字母表 `Γ` 上的表达式（前提是 `α` 中的所有原子都在 `Γ` 中），则它表示不同的语言；在实践中，上下文将明确指的是哪一个字母表，或者特定的字母表对讨论无关紧要。
