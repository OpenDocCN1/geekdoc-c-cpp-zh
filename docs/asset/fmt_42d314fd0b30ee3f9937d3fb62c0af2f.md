#### fseek 函数原型

`fseek` 的函数原型为

```c
int fseek(FILE *stream, long int offset, int whence);
```

其中 `offset` 是相对于 `whence` 的文件的字节数。正偏移量向前移动，负偏移量向后移动。参数 `whence` 为 `SEEK_SET`、`SEEK_CUR` 或 `SEEK_END`（均定义在 `<stdio.h>` 中），表示偏移开始的位置：

- `SEEK_SET` 表示从文件开始开始。
- `SEEK_CUR` 表示从当前位置开始。
- `SEEK_END` 表示从文件结束开始。
