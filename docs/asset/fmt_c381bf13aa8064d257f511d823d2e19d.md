# 教学方法

C++ 程序设计, 10e 包含了丰富的示例。我们强调程序并专注于构建良好的软件。

现场代码方法。书中充满了“现场代码”示例——大多数概念都在完整的 C++ 应用程序呈现，通过一次或多次执行显示程序输入和输出。
