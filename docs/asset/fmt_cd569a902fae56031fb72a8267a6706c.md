## 8.4. 虚函数的规则

- 虚函数不应该是静态的（static），并且必须是类的成员。
- 虚函数可以被声明为另一个类的友元（friend）。对象指针可以访问虚函数。
- 构造函数不能声明为虚函数，但析构函数可以声明为虚函数。
- 虚函数必须定义在类的公共（public）部分。
- 虚函数也可以返回值。
- 基类和派生类中虚函数的原型应该完全相同。
- 基类指针不能用于算术运算。
- 如果只有基类包含虚函数而派生类没有包含虚函数，则只创建基类的虚函数。
- 用于运算符重载的 `operator` 关键字也支持虚函数机制。

## 9.6. 使用模板冒泡排序

模板函数也可以用于排序。冒泡排序是最简单的算法，它通过在相邻元素顺序错误时反复交换它们来工作。

```cpp
#include<conio>
#include<iostream>
using namespace std;
template<class T>
void bubble(T a[], int n)
{
  int i, j;
  for(i=0;i<n-1;i++)
  {
    for(j=0;j<n-i-1;j++)
    {
      if(a[j]>a[j+1])
      {
        T temp = a[j];
        a[j] = a[j+1];
        a[j+1] = temp;
      }
    }
  }
}
int main()
{
  int a[]={5,1,4,2,8};
  int n=5;
  bubble(a,n);
  for(int i=0;i<n;i++)
    cout<<a[i]<<" ";
  return 0;
}
```

# 输出：

1 2 4 5 8 

## 9.7. 模板与宏的区别

模板与宏之间存在主要区别。模板是一种使函数独立类型的方法。宏仅仅是展开的字符串。区别在于：

+   (i) 模板是类型安全的；宏不是。
+   (ii) 在宏中很难发现错误。
+   (iii) 在变量增加或递减时，模板可以执行。
