虽然顺序是一种基本控制结构，但它不足以解决所有问题。有些问题需要从几个备选操作中选择一个，这意味着解决它们的程序将需要一种选择结构。在本章中，我们将讨论 C++ 提供的一种选择结构：`if` 语句。另一种选择结构 `switch` 语句将在第 8 章中介绍。

然而，对于某些问题，除了顺序和选择之外，还需要另一种控制结构，即能够重复执行一个或多个语句的结构——重复结构。我们将在本章的最后一部分讨论 C++ 中提供的两种重复结构：`for` 语句和 `while` 语句。

顺序、选择、重复是仅有的三种必需控制结构。理论计算机科学的一个基本结果表明，任何可由计算机程序解决的问题，都可以由仅由顺序、选择、重复结构组成的程序来解决。¹

> ¹ 这个定理通常归功于 Corrado Böhm 和 Giuseppe Jacopini 于 1966 年发表的一篇论文。

## 5.1 入门示例：空气质量指数（AQI）

### 5.1.2 问题

污染水平在城市中的三个地点测得，空气质量指数（AQI），也称为空气污染指数（API），是这三个读数的整数平均值。指数低于 50 ppm（百万分率）表示安全状态，而达到或超过 50 ppm（百万分率）则表示危险状态。² 城市的环境统计员希望有一个程序来计算这些空气质量指数，并确定相应的污染状态：安全还是危险。

> ² 这里我们考虑的是一个简化版的 AQI，它只有两个类别，但在实际中，通常不止两个。例如，我们将在第 8 章讨论具有多于两个备选方案的选择结构时看到，美国 AQI 有 6 个类别。

### 5.1.3 以对象为中心的设计

#### 5.1.3.1 行为

程序应在屏幕上显示一个提示，要求输入三个污染读数（百万分率）。然后，它从键盘读取这些值，并计算空气质量指数，即这些读数四舍五入到最接近整数的平均值。程序应在屏幕上显示空气质量指数，将其与分隔危险状态和安全状态的临界值进行比较，并显示相应的状态。

#### 5.1.3.2 对象

根据行为描述，我们可以识别出以下对象：

| 问题对象 | 软件对象 |  |  |
| --- | --- | --- | --- |
|  | 类型 | 种类 | 名称 |
| 屏幕 | 输出设备 | 变量 | `cout` |
| 提示 | 文本字符串 | 常量 | 无 |
| 键盘 | 输入设备 | 变量 | `cin` |
| 污染水平 | `double` | 变量 | `level1`, `level2`, `level3` |
| 空气质量指数 | `int` | 变量 | `index` |
| 临界值 | `int` | 常量 | `CUTOFF` |

#### 5.1.3.3 操作

同样，根据行为描述，我们有以下操作：

- i. 输出一个字符串（提示、描述性标签）

- ii. 从键盘读取实数值（`level1`, `level2`, `level3`）

- iii. 根据 `level1`、`level2`、`level3` 计算 `index`：将各水平相加，除以 3，再加 0.5 进行四舍五入

- iv. 在屏幕上输出一个数值（`index`）和一个字符串（污染状态）

#### 5.1.3.4 算法

下一步是将这些对象和操作组织成一个算法：

- 1. 定义常量 `CUTOFF`。

- 2. 向 `cout` 显示提示，要求输入三个污染水平。

- 3. 从 `cin` 读取三个实数值到 `level1`、`level2`、`level3`。

- 4. 计算 `index = (level1 + level2 + level3) / 3 + 0.5`。

> ³ 实数可以通过加 0.5 并截去小数部分来四舍五入到最接近的整数。一般来说，若要四舍五入到小数点后第 n 位，可乘以 10^n，加 0.5，截去小数部分，再除以 10^n。

- 5. 向 `cout` 输出一个描述性标签和 `index`。

- 6. 如果 `index < CUTOFF`，则向 `cout` 输出 `"Safe"`，否则输出 `"Hazardous"`。

示例 5.1 中的程序实现了上述算法。注意在 `index` 的计算中对平均污染读数进行了四舍五入。
