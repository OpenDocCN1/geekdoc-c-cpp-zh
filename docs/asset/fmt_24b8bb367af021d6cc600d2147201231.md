
## 练习 19.1-1 星期几

编写一个 C++ 程序，提示用户输入一个 1 到 7 之间的整数

以及 5，然后显示相应的工作日（周一、周二、周三、周四或周五）。如果输入的值无效，则必须显示错误信息。

## 解决方案

此 C++ 程序可以使用多分支决策结构（`multiple-alternative decision structure`）或 `case` 决策结构（`case decision structure`）来编写。让我们都尝试一下吧！

## 方法一——使用多分支决策结构

流程图如下。

![](img/6e4b8e11c2f26304087157218fda632f_287_0.png)

对应的 C++ 程序所示。

```cpp
#include <iostream>
using namespace std;
int main() {
int day;
cout << "Enter an integer between 1 and 5: ";
cin >> day;
if (day == 1) {
    cout << "Monday" << endl;
} else if (day == 2) {
    cout << "Tuesday" << endl;
} else if (day == 3) {
    cout << "Wednesday" << endl;
} else if (day == 4) {
    cout << "Thursday" << endl;
} else if (day == 5) {
    cout << "Friday" << endl;
} else {
    cout << "Invalid Number" << endl;
}
return 0;
}
```

## 方法二——使用 case 决策结构

```cpp
#include <iostream>
using namespace std;
int main() {
    int day;
    cout << "Enter an integer between 1 and 5: ";
    cin >> day;
    switch (day) {
        case 1:
            cout << "Monday" << endl;
            break;
        case 2:
            cout << "Tuesday" << endl;
            break;
        case 3:
            cout << "wednesday" << endl;
break;
case 4:
cout << "Thursday" << endl;
break;
case 5:
cout << "Friday" << endl;
break;
default:
cout << "Invalid Number" << endl;
}
return 0;
}
```

## 19.2 复习习题：判断对错

对以下每个陈述判断对（或错）。

- 1. `case` 决策结构用于扩展分支的数量。
- 2. `case` 决策结构可以一直代替多分支决策结构。
- 3. `case` 决策结构可以根据程序员的意愿具有任意数量的分支。
- 4. 在 `case` 决策结构中，最后一个语句或语句块 N + 1（出现在 C++ `default` 关键字下方）总是会被执行的。
- 5. 在 `case` 决策结构中，当之前的没有 `case` 都没有评估为真时，最后一个语句或语句块 N + 1（出现在 C++ `default` 关键字下方）会被执行。
- 6. 最后一个语句或语句块 N + 1，以及 `default` 关键字和对应的 `break` 语句是不省略的。
- 7. 在下面的 C++ 程序中，(a) {

```cpp
switch (a) {
case 1: x = x + 5; break;
case 2: x = x - 2; break;
case 3: x = x - 9; break;
default: x = x + 3; y++;
}
```

只有当变量 `a` 包含除 1、2 或 3 以外的值时，语句 `y++` 才会会被执行。

## 20.1 什么是嵌套决策结构？

嵌套决策结构是指嵌套在另一个决策结构内部的决策结构。这意味着一个决策结构可以嵌套（包含）另一个决策结构（后者变为嵌套决策结构）。反之，该嵌套决策结构也可以包含另一个，以此此类推。

嵌套决策结构的示例所示。

![](img/6e4b8e11c2f26304087157218fda632f_294_0.png)

它可以被重排为

![](img/6e4b8e11c2f26304087157218fda632f_295_0.png)

对应的 C++ 代码所示。

```cpp
if (x < 30) {
  if (x < 15) {
    y = y + 2;
  }
  else {
    y--;
  }
} else {
  y++;
}
```

```cpp
#include <iostream>
using namespace std;
int main() {
    int x;
    cout << "Enter a choice: ";
    cin >> x;
    if (x < 1 || x > 4) {
        cout << "Invalid choice" << endl;
    } else {
        cout << "Valid choice" << endl;
        switch (x) {
            case 1:
                cout << "1st choice selected" << endl;
                break;
            case 2:
                cout << "2nd choice selected" << endl;
                break;
            case 3:
                cout << "3rd choice selected" << endl;
                break;
            case 4:
                cout << "4th choice selected" << endl;
                break;
        }
    }
    return 0;
}
```

> 注意 `switch` 语句中缺少了 `default` 关键字。
