# 使用 SAS Sentiment Studio

Sentiment Analysis Studio 将反馈分为正面和负面并对其进行分类。Sentiment Analysis Studio 有三种模型：统计模型、规则模型和混合模型。混合模型是统计模型和规则模型的组合。在实践中，统计模型通常用作起点，因为它为不深入进行统计分析的经理提供了基准模型。
