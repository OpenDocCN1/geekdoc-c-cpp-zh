# IComparer<T> 接口

我们到为止学到的最重要的事情之一是，为了将类的实例作为字典的键，该类需要正确实现 `GetHashCode()` 和 `Equals(...)`。但如果我们想使用一个无法继承或更改的类，该怎么办？在这种情况下，`IComparer<T>` 接口为我们提供了帮助。

它定义了以下两个操作：

- `bool Equals(T obj1, T obj2)` - 如果 `obj1` 和 `obj2` 相则返回 `true`
- `int GetHashCode(T obj)` - 返回给定对象的哈希码
