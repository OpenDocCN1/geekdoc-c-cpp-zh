Microsoft .NET Framework 提供了一个配置编辑器工具，即 Microsoft Service Configuration Editor（Microsoft 服务配置编辑器），用于配置服务。要打开 Microsoft Service Configuration Editor，请选择“开始”→“所有程序”→“Microsoft Visual Studio 2010”→“Microsoft Windows SDK Tools”→“Service Configuration Editor”。此时会出现 Microsoft Service Configuration Editor，如图 19.10 所示：

要配置 WCF 服务，您需要指定服务绑定、终结点和服务行为。

### 指定服务绑定

您可以使用 Microsoft Service Configuration Editor 在服务的配置文件中指定绑定。让我们执行以下步骤，在 WCF 服务的 `web.config` 文件中指定绑定：

- 1. 在“配置”窗格中右键单击“绑定”文件夹，然后选择“新建绑定配置”选项，如图 19.12 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1015_0.png)

图 19.12：显示“新建绑定配置”选项

此时会打开“创建新绑定”对话框，提示您从绑定类型列表中选择一种绑定类型。在我们的示例中，我们将创建自定义绑定。

- 2. 在“创建新绑定”对话框中选择 `customBinding` 选项，如图 19.13 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1015_1.png)

图 19.13：显示“创建新绑定”对话框

现在，Microsoft Service Configuration Editor 中会出现一个新的 `customBinding` 窗格，其中包含各种配置选项。`customBinding` 窗格包含“绑定元素扩展位置”区域，该区域使您能够添加、移除和重新排序 `customBinding` 绑定的元素。默认情况下，此区域包含 `textMessageEncoding` 和 `httpTransport` 作为堆栈元素（绑定元素）。

- 3. 在 Microsoft Service Configuration Editor 的“绑定”节点中，移除 `textMessageEncoding` 绑定元素，并添加 `binaryMessageEncoding` 绑定元素。
- 4. 在“堆栈元素”字段下的顶部位置添加 `reliableSession` 绑定元素。绑定元素的顺序很重要，因为它反映了绑定元素在通道堆栈中的位置。
- 5. 将 `reliableSession` 绑定的名称设置为 `NetHttpBinding`，如图 19.14 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1016_0.png)

配置完自定义绑定后，您需要指定使用此自定义绑定的终结点。

```
using System.Collections.Generic;
using System.ComponentModel;
using System.Data;
using System.Drawing;
using System.Linq;
using System.Text;

using System.ServiceModel;
namespace SelfHostedService

    public partial class Form1 : Form
    {

        ServiceHost myServiceHost;
        private void Form1_Load(object sender, EventArgs e)
        {
            myServiceHost = new ServiceHost(typeof(UpperCaseService));
            button2.Enabled = false;
        }
        private void button1_Click(object sender, EventArgs e)
        {
            //Opening the ServiceHost object to listen to messages
            myServiceHost.Open();

            button1.Enabled = true;
            button2.Enabled = false;
        }
    }
}
```

# 在 Windows 服务中托管 WCF 服务

在 Windows 服务中托管 WCF 服务需要在服务器上将托管 WCF 服务的应用程序域（AppDomain）注册为受管理的 Windows 服务，以便服务控制管理器（SCM）控制 WCF 服务的进程生命周期。现在，让我们执行以下步骤在 Windows 服务中托管 WCF 服务：

- 1. 创建一个名为 `WinServiceHost` 的控制台应用程序（也在 CD ROM 上提供）。
- 2. 右键单击 `WinServiceHost` 应用程序的名称并从上下文菜单中选择 `Add→New Item`。Add New Item 对话框出现。
- 3. 选择 `WCF Service` 模板并在 Add New Item 对话框的 Name 文本框中输入服务的名称为 `TimeService`。
- 4. 单击 `Add` 按钮创建应用程序。`TimeService.cs`、`ITimeService.cs` 和 `App.config` 文件被添加到 `WinServiceHost` 应用程序中。此外，对 `System.ServiceModel` 和 `System.Runtime.Serialization` 类的引用也被包含在应用程序中。
- 5. 打开 `ITimeService.cs` 文件并在 `ITimeService` 接口中添加以下代码片段：
```

```
