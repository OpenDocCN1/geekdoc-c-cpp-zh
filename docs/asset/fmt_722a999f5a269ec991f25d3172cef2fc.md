## 3.2 链式法则与通用法则

链式法则：对 `f(g(x))` 求导时，首先对外层函数 `f(x)` 求导，并在结果中用 `g(x)` 替换 `x`，然后乘以内层函数 `g(x)` 的导数。符号表示为：
```
d/dx f(g(x)) = f'(g(x)) g'(x)
```

## 示例 3

作为链式法则的通用法则：使用链式法则计算 `f(g(x))` 的导数，其中 `f(x) = x^5` 且 `g(x) = x^3+9x`。
```
f'(x) = 5x^4,    g'(x) = 3x^2+9
f'(g(x)) = 5(g(x))^4 g'(x)
```

### 解

最后，根据链式法则，
```
d/dx f(g(x)) = f'(g(x)) g'(x) = 5(x^3+9x)^4 (3x^2+9)
```
