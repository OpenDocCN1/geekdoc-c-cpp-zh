## 5.3 解引用 (Dereferencing)

指针变量可以被认为是*通过指向另一个来引用它*。在 C 语言世界，很少听到有人谈论“引用”或“references”，但我提到它是为了让这个操作符的名字更容易理解一点。

当你指向一个指针（大致相当于“对变量的引用”）时，你可以通过*解引用*指针来通过指针使用原始变量。（你）可以将其想为“取消指向”指针，或者说叫 "de-pointing"。

回到我们的比喻，这看起来像是看一个家庭地址，然后去那栋房子。

现在，我说的“访问原始变量”是什么意思？嗯，如果你有一个名为 `i` 的变量，你有一个指向 `i` 的指针，你可以完全像使用原始变量一样使用解引用后的指针 `p`！

你有足够的知识来处理一个例子了。你最后需要知道的就是这一点：什么是解引用符？它实际上是间接操作符，因为你通过指针间接地访问值。它就是星号：`*`。现在，不要和之前在指针声明中使用的星号搞混了。它们是同一个字符，但在不同的语文中有不同的含义。

这里有一个完整的例子：

```c
#include <stdio.h>

int main(void) {
    int i;
    int *p; // 这不是解引用——这是一个类型 "int*"
    p = &i; // p 现在指向 i，p 持有 i 的地址
    i = 10; // i 现在是 10
    *p = 20; // p 指向的（也就是！）i 现在是 20！！
}
```

> 这可不仅如此！它还用于 `/* */` 注释、乘法以及带有长度数组的函数原型中！它们是一样的，但语境赋予了它不同的意义。

```c
printf("i is %d\n", i);    // 打印 "20"
printf("i is %d\n", *p);      // "20!" 解引用 p 和 i 相同！
```

记住 `p` 持有 `i` 的地址，正如你所看到的，我们在第 8 行对 `p` 进行了赋值。间接操作符告诉计算机使用指针指向的对象，而不是使用指针本身。通过这种方式，我们将 *p 转换成了 i 的某种形式的地址*。

当你把指针作为参数传递给函数时会发生什么？指针的副本会被放入它对应的变量中吗？你的汗水会达到顶点。还记得之前我胡乱每一个参数都是进入参数的，并且函数使用参数的副本吗？嗯，情况也是如此。这是你获取指针的函数。

但是，这是最巧妙的部分：我们会提前为该变量设置好指针……然后函数就可以解引用它的指针副本来回到原始变量！函数看不到那个变量，但它确实可以对该变量的指针进行解引用！

这类似于在纸上写下家庭地址，然后将其复制到另一张纸上。你现在有了两个指向它的指针，但它们都等同于让你到达房子本身。

在函数调用的情况下，副本之一存储在调用者作用域的指针变量中，另一个存储在函数参数的指针变量中。

示例！让我们重新回顾我们自己的 `increment()` 函数，但这次让我们让它实际上增加调用者中的值。

```c
#include <stdio.h>

void increment(int *p) // 注意它接受一个指向 int 的指针
{
    *p = *p + 1;      // 给 p 指向的变量加 1
}

int main(void)
{
    int i = 10;
    int *j = &i;      // 注意取地址符；将其转换为指向 i 的指针
    printf("i is %d\n", i);      // 打印 "10"
    printf("i is also %d\n", j);  // 打印 "10"
    increment(j);
}
```

好了！这里有几点需要看到……最不重要的是 `increment()` 函数接受一个 `int` 作为参数。我们在调用时通过使用取地址符将 `int` 变量 `i` 变为 `int *` 向其传递了一个 `int`。记住，指针持有一个地址，所以我们通过取地址符增加它们来创建指向变量的指针。

## 6.2 获取数组的长度

你不能……大概可以的。C 不记录这个信息³。你必须在另一个变量中单独管理它。

当我说“可以”时，我的实际上是指在某些情况下你可以的。有一个技巧可以在数组声明的作用域内获取数组的元素个数。但通常情况下，当你把数组传递给函数时，它并不起作用。

让我们来看这个。基本思想是取数组的大小，除以每个元素的大小来得到长度。例如，如果 `int/4` 是 32 字节，那么里面必须有容纳 8 个 `int` 的空间。

```c

```

```c
printf("%zu\n", sizeof(int)); // 48/4 = 12 个 int!
```

如果是 `char` 数组，那么 `sizeof` 就是元素的个数，因为 `sizeof(char)` 被定义为 1。对于其他任何类型，你必须除以每个元素的大小。

