### 深入探讨

数据绑定是指将 Windows 或 Windows Presentation Foundation（WPF）控件绑定到数据源的过程。这样做是为了让应用程序能够直接显示和访问存储在数据源中的数据。换句话说，绑定到数据源的控件会显示该数据源中存储的信息和数据。例如，要在 `ListBox` 控件中显示公司员工的姓名，你需要将此控件绑定到包含所需数据的表。在 Windows 窗体应用程序中，你不仅可以将控件绑定到数据源，还可以绑定到任何包含数据的编程构造。例如，你可以将控件属性绑定到值数组或 Excel 文件。这些控件属性可以绑定到数据源以从中检索数据。

除了 Windows 和 WPF 应用程序之外，你还可以在 Web 应用程序中将控件绑定到数据源。但是，在这种情况下，你需要创建 Windows Communication Foundation（WCF）数据服务，以将数据源中的数据信息连接到特定控件。WCF 数据服务（以前称为 ADO.NET 数据服务）随 `.NET Framework 4.0` 提供。ADO.NET 代表 ActiveX Data Object.NET，是一组用于访问和修改存储在关系数据库系统（RDBMS）中的数据的软件组件。

在本章中，你将了解数据绑定的概念，该概念用于在应用程序中从数据源访问数据。接下来，你将学习如何将数据绑定到 Windows 窗体控件。本章还将进一步讨论 Windows 窗体应用程序中的各种绑定类型：简单绑定和复杂绑定。接下来，你将学习在 WPF 应用程序中绑定控件的不同方法。本章还重点介绍了在 WPF 应用程序中实现数据绑定所需的 WCF 数据服务的创建。

### 数据绑定简介

如前所述，数据绑定是在应用程序用户界面（UI）和数据源之间建立连接的过程。这意味着如果你在控件中修改了数据，该更改也会反映在原始数据源中。换句话说，数据绑定是一个双向过程，数据源中的更改会反映在控件中，反之亦然。数据绑定是通过将需要访问数据的控件的属性绑定到数据源，在应用程序和数据库之间实现的。

通过数据绑定可以执行的一些任务包括：

- 导航数据 — 指根据特定的搜索条件从一条记录移动到另一条记录的过程。
- 输入数据 — 指在数据输入窗体中输入数据的过程。输入的数据随后会发送到与该数据输入窗体连接的数据库。例如，你可以使用 `TextBox`、`RadioButton`、`ListBox`、`Dropdownlist`、`ListBox` 和 `CheckBox` 控件输入数据。
- 创建主/从关系 — 指将多个表的数据以主从关系绑定在一起的过程。主从关系是表之间的一种关系，其中父表与其子表相关联。例如，你可能在 `ComboBox` 控件中显示 `Employees` 表中的员工姓名；但是，当选择其中一位员工时，该特定员工的详细信息会显示在 `DataGridView` 控件中。
- 执行数据查找 — 指查找表中与另一个字段相对应的某个字段的数据的过程。`ListBox` 控件通过使用 `ValueMember` 和 `DisplayMember` 属性支持这种类型的数据绑定。

### 绑定数据到 Windows 窗体控件

使用 Windows 窗体的数据绑定有助于你显示和更改数据源中的信息。你可以将 Windows 窗体绑定到任何类型的数据结构，例如数据库、文本文件或 Excel 文件。Windows 应用程序中有两种类型的数据绑定——简单数据绑定和复杂数据绑定。在简单数据绑定中，控件只能绑定到单个数据元素。例如，`TextBox` 或 `Label` 控件一次只能显示一条数据记录。在 C# 中，你还可以将控件的属性绑定到需要访问数据的数据源。另一方面，在复杂数据绑定中，你可以将控件绑定到数据库中的多条记录。例如，`DataGridView` 控件可以绑定到整个表，即可以通过 `DataGridView` 控件访问该表中存储的所有记录。

复杂数据绑定由以下属性组成：

- `DataSource` – 指定数据集，例如 `DataSet11`
- `DataMember` – 指定数据源中的数据成员，例如 `Northwind` 数据库中的 `Customers` 表
- `DisplayMember` – 指定由控件显示的表中的列或字段，例如 `Customers` 表中的 `CustomerID` 列
- `ValueMember` – 指定由控件属性返回的表中的列或字段的数据。

### 绑定数据到 WPF 控件

你可以通过使用应用程序的代码隐藏文件或可扩展应用程序标记语言（XAML）在 WPF 应用程序中实现数据绑定。与其他应用程序（如 Windows 窗体应用程序和 ASP.NET Web 应用程序）一样，WPF 也需要有数据绑定的目标和源。你可以选择 WPF 中控件的公共属性来绑定数据，这些属性包括其他控件的属性或任何数据源。绑定的目标可以被控件的公共属性访问，例如 `TextBox` 控件的 `Text` 属性。

在本节中，你将学习：

- WPF 应用程序中数据流的方向
- WPF 应用程序中可以访问数据的源
- 将数据绑定到 WPF 应用程序的不同方式

### WPF 中的数据流方向

WPF 数据绑定支持目标和源之间不同类型的绑定模式。绑定中的数据流可以是从目标到源，也可以是从源到目标。在 WPF 应用程序中绑定数据时，你应该指定数据绑定的模式。`Mode` 属性定义绑定模式，以确定源和目标之间数据流的方向。

以下是 WPF 中可用的四种绑定模式：

- `OneTime` 数据绑定 – 指数据从源流向目标的模式。这种类型的绑定仅在应用程序启动或数据源更改时发生一次。`OneTime` 数据绑定只能检索数据，但不能更新数据库中的数据。
- `OneWay` 数据绑定 – 指数据从源流向目标的模式。这种类型的绑定对于只读数据非常有用，因为无法从用户界面更改数据。WPF 中的 `OneWay` 数据绑定模式是默认的绑定模式。
- `TwoWay` 数据绑定 – 指数据双向移动的模式，即从源到目标以及从目标到源。在 `TwoWay` 数据绑定中，你可以在用户界面中对数据进行更改。使用 `TwoWay` 数据绑定在 UI 中所做的数据更改会反映在数据源中。
- `OneWayToSource` 数据绑定 – 指源属性根据目标属性所做的更改自动更新的模式。

接下来，让我们了解 WPF 应用程序中不同的数据源。

### WPF 中的数据绑定源

在数据绑定中，源是指获取数据的对象。WPF 支持四种类型的绑定源：公共语言运行时（CLR）对象、ADO.NET 数据、可扩展标记语言（XML）数据和 `DependencyObject`。让我们在以下各节中了解这些源。

## CLR 对象

在 WPF 应用程序中，你可以将控件绑定到 CLR 对象的公共属性或子属性。在 WPF 中使用 CLR 对象进行数据绑定时，需要实现 `INotifyPropertyChanged` 接口，该接口有助于更新目标和源属性值。你也可以使用 `UpdateTarget()` 方法在数据源发生更改时更新目标属性。

## ADO.NET

要将 WPF 应用程序绑定到 ADO.NET 对象，首先需要在数据库和应用程序之间创建连接。建立连接后，会创建一个适配器，该适配器执行结构化查询语言（SQL）语句以从数据库中检索记录。结果通过调用适配器的 `Fill()` 方法存储在 `DataSet` 对象的 `DataTable` 对象中。然后将该结果显示在 WPF 应用程序的控件中。你也可以在 WPF 应用程序中实现 `IBindingList` 接口以提供更改通知。`IBindingList` 接口提供功能以支持对数据源的复杂和简单数据绑定。

## XML

要将 XML 数据绑定到应用程序，需要在 WPF 应用程序中使用 `XmlDataProvider` 类。`XmlDataProvider` 类充当标记中的绑定源。当使用 `XmlDataProvider` 类时，应用程序中的数据以 XML 节点树的<|message|> 出现。你可以从应用程序中现有的 XML 文件访问数据，也可以使用 `<x:XData>` 标签创建新的 XML 文件。

## DependencyObject 类

你也可以将 WPF 应用程序与 `DependencyObject` 类绑定。`DependencyObject` 类在 WPF 应用程序中的主要功能是计算属性的值并提供有关这些值可能发生的任何更改的通知。你可以通过调用 `DependencyProperty` 类的 `Register()` 方法在 WPF 应用程序中注册依赖属性。

## WPF 中数据绑定的不同方式

在 WPF 中，你可以将控件与单个或一组数据对象绑定。根据应用程序中要检索数据的来源，你可以以多种方式将控件绑定到 WPF 应用程序：基于 XAML 的数据绑定和基于代码的数据绑定。现在，让我们详细讨论这两种方式。

## 基于 XAML 的数据绑定

当数据源是 XAML 文件时，则需要通过指定 `Binding` 属性将其绑定到 WPF 应用程序。`Binding` 属性声明一系列子句，其形式为 Name = Value 对，其中 Name 是 `Binding` 属性的名称，Value 是为该属性设置的值。`Binding` 属性必须附加到目标对象的特定依赖属性。以下代码片段显示了在 XAML 格式中使用 `Binding` 属性的基本语法：

```
<TextBox Text="{Binding Source={StaticResource myDataSource}, Path=Name}"/>
```

在前面的代码片段中，`TextBox` 的 `Text` 属性正在使用 `Binding` 属性。
