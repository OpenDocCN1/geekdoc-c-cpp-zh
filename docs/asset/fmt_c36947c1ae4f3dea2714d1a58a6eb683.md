
# 术语表

## A-C

**剪贴板**  内存中的预留区域，用于临时存放从应用程序或 Windows 资源管理器剪切或复制的内容。

**时钟周期**  系统时钟的一次跳动。

**云存储**  从云环境访问的存储。

**云**  通过互联网访问的计算环境。

**簇**  扇区的分组。一个簇中的扇区数量取决于文件系统和磁盘大小。

**CMOS 设置**  主板上内置的实用程序，允许用户调整某些低级配置设置。

**同轴电缆**  由实心铜芯和周围的绝缘护套组成的电缆；具有单铜芯，能够进行高频传输。

**解码器**  用于播放特定音频或视频格式的翻译文件。编码器/解码器的缩写。

**冷启动**  从关机状态启动计算机。

**色彩深度**  在特定显示模式下描述每个像素颜色的位数，例如 `16 位` 或 `32 位`。

**调色板**  点击与颜色相关的功能按钮时打开的颜色网格。

**柱状图**  使用垂直条形表示数值的图表。

**命令栏**  在 Windows 7 中，Windows 资源管理器中包含“组织”按钮的栏（该按钮可打开菜单），以及根据你正在查看的位置而变化的其他命令。在 Windows 8 中，当你右键点击 Windows 8 应用时，出现在应用顶部或底部的栏，提供了你可以点击以发布命令的按钮。

**命令行界面**  一种基于在命令提示符处输入文本的用户界面。

**注释**  插入文档的非打印备注，用于分享关于你正在编辑的文档的信息或观点。

**光盘**  一种用于存储音乐和数据的光学盘，容量可达 `900 MB`。

**压缩包**  包含一个或多个其他文件的压缩文件。

**压缩**  通过比原始文件更少的位编码来缩小数据文件大小的过程。

**计算机辅助设计**  使用计算机软件制作技术图纸的过程，这些图纸包含计算机的精确比例、模拟其纹理并以完整的三维细节显示它。

**耗材**  使用过程中必须进行更换的打印用品，如纸张和墨水。

**联系人**  Outlook 中存储人员联系信息的部分。

**连续的**  物理上相互相邻。

**Cookie**  网站放置在计算机上的小文件，存储用户与网站交互产生的信息。

**版权**  在有限时间内授予作品创作者的独占权利。

**核心**  一组共同工作的关键处理器组件（控制单元、算术逻辑单元和寄存器）。CPU 可能有多个核心。

**单页成本**  打印一页所需的耗材总成本，计算方法是用纸和墨水/碳粉/色带的成本除以在耗尽前产生的页数。

**裁剪**  从图片的一个或多个侧面切掉不需要的部分。

**光标**  也称为插入点，出现在文本框或其他可接受文本输入的区域的闪烁线条。

**网络欺凌**  使用计算机和互联网通过发表恶意言论来故意伤害或骚扰他人。

**柱**  读写头执行臂在单一位置上的所有轨道。

## D-F

**数据标签**  告知特定数据点确切数值的标签。

**数据挖掘**  从数据库中提取信息以确定某些事实或总结大量数据。

**数据点**  绘图数据中的单个点。

**数据系列**  代表用于创建图表的数据中的某行或一列的数据。

**数据表**  一个可选的表格，显示该图表所基于的数值表。

**数据库**  以结构化格式存储的数据集合，每个实例都存储相同的事实。数据库存储数据的方式让你能够快速搜索和定位数据。

**数据库管理系统**  一种帮助用户创建和管理数据库的应用程序。

**工作表视图**  在表格数据区域中以结构化网格或行和列形式显示的表格视图。

**解密**  反转文件的加密，使文件再次以原始形式出现。

**默认文件位置**  “另存为”和“打开”对话框默认开始的位置。

**默认网关**  路由器上连接到外部网络的端口。

**磁盘碎片整理**  重新定位磁盘上的碎片化文件，使其簇变得连续。

**拒绝服务攻击**  一种协调攻击，目标网站或服务被访问请求淹没，以至于完全过载。

**降序排序**  从 Z 到 A 的排序，或从大到小的排序。

**设计视图**  数据库对象的查看模式，允许你修改对象的结构和属性。

**桌面应用**  一种在桌面窗口中运行的传统样式 Windows 程序。

**桌面式电脑**  设置在桌子上且不移动的计算机，输入输出设备与系统单元分离。

**桌面出版**  帮助创建带有文本和图形的页面布局的软件。

**桌面**  Windows 7 界面，在该界面打开应用程序的窗口。也可以特指背景图像。

**详细查询**  显示数据集中所有记录的查询。

**设备驱动程序**  一个在操作系统和硬件设备之间翻译指令和消息的文件。

**设备管理器**  提供安装在 PC 上的设备详细信息的实用程序。

**对话框启动器**  功能区上某组右下角的图标；点击后可打开对话框或任务窗格。

**对话框**  响应选择命令而出现的窗口，提示用户希望如何执行该命令的信息。

**拨号调制解调器**  转换模拟和数字数据的设备，以便计算机数据可以通过模拟电话线发送。

**差异备份**  备份所有设置了存档属性文件的备份操作，但不更改该属性。

**数字相机**  以数字格式捕捉和存储图像的相机。

**数字投影仪**  接受计算机输入的投影仪。

**数字版权管理**  使用技术控制对受版权材料的访问。

**数字用户线路**  由电话公司提供的宽带互联网连接。

**数字多媒体光盘**  用于存储标准电影和数据的光盘，每侧层容量可达 `4.17 GB`。

**数字摄像机**  以数字格式捕捉和存储动态视频的摄像机。

**数字视觉接口**  将显示器连接到 PC 的数字端口。

**数字白板**  连接到计算机的白板，因此在板上写的任何内容都会保存到计算机上。

**数字化**  将东西从硬质副本转换为数字（计算机）形式。

**直接热敏打印机**  通过加热特殊涂层纸的某些区域使其变黑并形成图像。

**直接连接存储**  直接连接到其访问的计算机的存储。

**磁盘检查程序**  发现并修复磁盘存储系统中错误的软件。

**磁盘**  存储数据的一个或多个盘片。在指光学盘（DVD、CD）时拼写为 disc。

**显示适配器**  用于将操作系统指令传输到显示器的计算机组件。

**显示语言**  用户界面中命令和菜单显示的语言。

**显示器**  用于向人类用户提供输出的视频屏幕。

**发行版**  distribution 的缩写，一种开源内核（如 Linux）的封装集合，带有实用的插件和工具。

**抖动**  在图像中相邻放置彩色点，使其从远处看看起来是第三种颜色。

**DNS 服务器**  一种允许用户使用域名或 URL 而不是 IP 地址访问网站的命名系统。

**自动进纸器**  某些扫描仪的机械功能，允许无需用户干预即可连续扫描多页。

**域名系统**  一种允许用户使用域名或 URL 而不是 IP 地址访问网站的命名系统。

**域名**  用于识别互联网上实体的名称。

**加密狗**  近期被采用的一种光学计算术语，指为笔记本电脑等计算设备添加移动访问或 Wi-Fi 功能的 USB 插件。

**点每英寸**  图像质量的测量单位，指打印文件中一行（或一列）中彩色点的数量。打印输出可以具有不同的水平和垂直 dpi，尽管这并不常见。

**双数据速率随机存取存储器**  SDRAM 在每个时钟周期内执行两次操作。

**数位板**  一个平坦的矩形敏感表面，用户可以使用触写笔在上面画以创建屏幕艺术品。

**驱动器**  在磁盘上读写数据的机械组件。

**驱动程序**  设备与操作系统之间的软件接口。

**鼓筒**  激光打印机内部的旋转圆柱体，或者通过电荷形成页面图像的地方。

**双直插内存模块**  一种带有 DRAM 的小型矩形电路板，可插入主板的内存插槽中。

**双面打印**  在纸张的两面进行打印。

**动态 IP 地址**  临时分配给设备的 IP 地址。

**动态内存**  除非经过电刷新，否则不会保留其数据的内存。

## G-I

**教育软件**  用于教授或训练个人特定类型知识或技能的软件。

**电可擦除编程只读存储器**  可以用电擦除和编程的 ROM。

**电磁干扰**  附近的磁场通过电缆对电信号造成的的失真；由于附近电缆产生的磁场，导致数据在通过电缆时发生损坏。

**电子邮件**  一种通过邮件服务器交换信息的计算机系统。

**电子邮件应用程序**  辅助发送和接收电子邮件的软件。

**嵌入字体**  将文档中使用的字体与文档本身一起保存，以便在其他计算机上查看该文档的其他人员能够访问这些字体。

**加密**  打乱文件内容，使其在没有所需权限的情况下无法读取；改变数据呈现方式的过程，只有授权人员才能读取。

**最终用户许可协议**  应用程序所有者与想要安装和使用它的用户之间的法律协议。

**娱乐软件分级委员会**  一个为视频游戏设定标准并根据这些标准为游戏分配分级的组织。

**电子纸**  用于电子书阅读器的显示器技术，屏幕会保留图像，除非显示发生变化，否则不进行刷新。

**人体工程学键盘**  设计具有有助于减轻用户手部和腕压力功能的键盘。

**以太网**  当前局域网设备的主流标准。

**扩展插槽**  主板上的插槽，可以在其中安装扩展卡（小型电路板）。

**ExpressCard**  插入笔记本电脑外部可访问插槽的金属卡匣，用于增加系统容量，例如无线网络。

**企业外网**  企业为其客户、员工和业务伙伴建立的特殊网络，允许从办公室网络外部访问；它可能用于共享资产和其他非敏感项目。

**Facebook**  一种用于发布有趣的更新、网页链接和照片，以及与朋友聊天的社交网络。

**FaceTime**  安装在 iPhone 和 iPad 设备上的应用程序，用于在 Apple 设备所有者之间进行视频通话。

**FAT32**  用于 Windows 95、Windows 98 和 Windows 世纪版中的文件系统。FAT 代表文件分配表。

**收藏夹**  你频繁访问且可以轻松访问的网站或页面。

**光纤电缆**  使用玻璃纤束中的光脉冲传输数据的电缆。

**字段**  表格中的列，存储一种特定类型的信息，例如电话或姓名。

**文件资源管理器**  Windows 8 中的文件管理工具。

**文件扩展名**  文件名末尾的指示文件类型的代码。

**文件系统**  在卷上存储和管理文件的规则集，例如 NTFS 或 FAT32。

**文件**  存储在单个名称下的相关位组。

**句柄**  单元格选择器右下角的小矩形，用于拖动将选择扩展到其他单元格。

**填充**  背景颜色，例如单元格或图形对象中的。

**过滤**  根据你指定的标准隐藏某些记录；防止某些东西通过——在这种情况下是指内容。

**防火墙**  一种通过关闭不必要的服务和端口来阻止黑客访问计算机的软件；你计算机或网络上的安全屏障，控制允许哪些流量通过。

**网络喷口**  用户之间以敌对的方式互动。

**平版扫描仪**  在页面上具有用于扫描的大平面的面的扫描仪。

**文件夹树**  卷存储层次结构的图形化表示，带有文件夹和子文件夹的子级分支。

**文件夹**  用于将相关文件分组的逻辑组织单元。

**页脚**  每页底部包含一致或重复信息的区域。

**脚注**  关于引文来源的信息，用数字标记并出现在页面底部。

**外键**  与另一个表的主键具有关联的字段。

**外形**  电路板的大小和形状，例如主板。

**表单**  数据库辅助对象，通过呈现易于输入的表单来简化数据输入。

**格式化**  在卷上创建文件系统。

**公式**  在 Excel 中可以执行的命名计算。它可以引用其他单元格的值。

**公式栏**  工作表上方显示活动单元格内容的栏。如果活动单元格包含公式，公式显示在公式栏中，结果显示在单元格中。

**论坛**  基于网络的讨论建议分享网站。

**论坛主题**  论坛上的帖子及其所有评论。

**转发**  发送给原始发送者以外的人的消息副本。

**碎片**  簇不连续的文件。

**帧**  视频剪辑的静态图像。

**全备份**  备份所有文件并将其属性设置为关闭的备份操作。

**函数**  在 Excel 中可以执行的命名计算，例如 `AVERAGE` 或 `SUM`。

**定影器**  激光打印机内部的加热元件，熔化碳粉将其固定在纸上。

## G-L

**网关**  允许你连接到两个不同网络的连接器。

**通用公共许可证**  用于许多类型开源软件的许可，允许合法地复制和修改软件。

**吉赫**  十亿赫兹。

**全球定位系统**  一种通过与轨道卫星通信来确定当前位置并提供地图和路线的设备。

**图形用户界面**  一种图形环境下的用户界面，用户使用指向设备或触摸屏作为主要输入设备与之交互。

**图形**  允许你创建和处理视觉图像的软件。

**网格线**  每个单元格周围的线，根据设置可以显示或隐藏。

**组**  丝带选项卡中的命命名区域。

**协作软件**  帮助人们在物理上不在一起的情况下，在业务项目中协作并在团队环境中工作的软件。

**来宾账户**  一种特殊的 Windows 账户，权限极少，在没有计算机账户的用户启动计算机登录时提供。

**硬质拷贝**  文档的物理打印页或打印的照片；与软拷贝（电子副本）相反。

**机械硬盘驱动器**  一种带有集成磁盘盘组的机械驱动器，以磁性极性模式存储数据。

**硬盘**  一个使用机械或固态技术存储数据的密封金属盒。

**硬性分页符**  用户为了强制在某处分页而创建的分页符。

**硬重置**  一种设备重置，会清除所有自定义数据和设置，将设备软件恢复到出厂状态。

**硬件**  计算机系统的物理部分。

**页眉**  每页顶部的包含一致或重复信息的区域。

**散热器**  铜或铝块，可将热量从 CPU 等发热组件引开。当不与风扇配合时，统称为被动散热器。

**赫兹**  每秒一个周期，速度的测量单位。

**休眠**  一种节能模式，将 RAM 的内容保存到硬盘并关闭所有电源。当计算机唤醒时，它会将保存的数据读回 RAM，计算机无需完全重启。

**分级数据库**  一种从单一起始点或前提开始以树形父子关系组织数据的方法。所有记录都根据它们与树顶起始点的关系来显示。

**分级文件系统 Plus**  Mac OS X 使用的文件系统。

**高带宽多媒体接口**  一种用于将 HDTV 连接到设备（如计算机或家庭影院系统）的连接器。

**高清电视**  显示分辨率至少为 `1920 × 1080`（也称为 `1080p`）的电视。

**主页**  你首次启动网络浏览器时显示的页面。

**主页组**  对等点网络（如家庭或小型办公室）上的一组互信信任的小型计算机。

**热点**  一个可以供公众成员使用（免费或付费）的无线网络。

**HTTP (超文本传输协议)**  定义了信息如何通过网络编写和传输。

**HTTP 电子邮件账户**  一种设计用于网络界面的电子邮件账户，使用网络技术进行电子邮件管理。

**集线器**  交换器的原始版本，缺乏读取数据包地址并将其路由到相应端口的能力。

**色调**  所代表的颜色，如红色、绿色或蓝色。

**超链接**  指网页上另一个点的指针，你通过点击超链接访问它。
