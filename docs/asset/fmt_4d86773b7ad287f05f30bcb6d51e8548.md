## LAYOUT DATALATTICE 语句

本节中的示例使用 `LAYOUT DATALATTICE` 语句指定相同的分类变量：`DIVISION` 和 `PRODUCT`。请注意关于 `LAYOUT DATALATTICE` 语句的以下细节：

- 必须提供 `ROWVAR=` 或 `COLUMVAR=` 参数之一。两者都指定单个分类变量，允许你为图表指定一个或两个分类器。
- 在生成的图中，数据交叉点通过行或列标题进行识别。
- 默认列数等于 `COLUMVAR` 分类器的唯一值数量。
- 默认行数等于 `ROWVAR` 分类器的唯一值数量。

## 间隙 (Gutters)

为了节省空间，默认的 `DATAPANEL` 和 `DATALATTICE` 布局在面板单元格边界之间不留间隙。在某些情况下，这可能会导致单元格内容看起来过于拥挤。你可以通过 `COLUMNGUTTER=` 选项在所有单元格之间添加垂直间隙，并通过 `ROWGUTTER=` 选项在所有行之间添加水平间隙。如果没有指定单位，则假设为像素 (PX)。

```sas
layout lattice classvars=(var) / columns=3 rows=2 ;
columngutter=5 rowgutter=5 ;
layout prototype;
  plot statements ...
endlayout;
```

## 单元格大小

你可能认为单元格的大小可以随大随小。然而，GTL 对单元格的最小值有内部限制：100 像素乘以 100 像素。单元格大小是在处理所有标题、脚注和侧边栏内容后计算的。因此，如果设计中有额外的标题，将输出类似的日志信息，并产生更大的面板。

## 控制行或列的数据范围

分类面板展示的优势在于它可以方便在视觉上比较跨数据类别的相似图表。在下面的示例中，比较了飞镖、高夫和棒球的利润：

proc template;
define statgraph unionall;

designheight=400px;

entitle

layout datapanel
classvars=(product_group)/

barchart category=year response=profit /
stat=sum;
endlayout;
endlayout;
endgraph;
end;
run;

proc sgrender data=sashelp.orsales

默认情况下，面板中所有行的最小和最大数据范围被用于为出现在行中的轴建立相同的数据范围。列也是如此。设置这些默认值的选项是 `ROWDATARANGE=UNIONALL` 和 `COLUMNDATARANGE=UNIONALL`。在大多数情况下，这些设置简化了快速比较，因为每行的轴缩放比例是完全相同的。同样，列共享一个公共比例：刚才显示的图很好地展示了高夫产品提供的利润通常比飞镖或棒球多，但它在显示棒球利润的变化方面并不理想，因为这些利润相对于高夫利润太小了。

## 设置轴选项 (Setting Axis Options)

分类平面使用 `ROWAXISOPTS=(axis-opts)` 和 `COLUMNAXISOPTS=(axis-opts)` 来设置轴特征。所有轴类型（`LINEAR`、`DISCRETE`、`TIME`）都有可用选项，而 `OVERLAY` 布局中可用的轴选项较少。为了演示选项的使用，下面的示例隐藏了行标签，因为刻度已格式化为美元，因此不需要轴标签。添加标题并消除轴标签是为面板留出空间的好方法。轴刻度通常不需要，因此示例隐藏了它们。你可能注意到在条形图中条形没有接触轴，这是因为对轴应用了默认偏移以避免与相邻单元冲突。此示例通过设置 `OFFSETMIN=0` 覆盖了默认偏移，使条形接触轴。

```
layout datapanel classvars=(product_group) /
rowdatarange=union
columnaxisopts=(display=(tickvalues))
linearaxisopts=(tickvalueformat=dollar)
griddisplay=on offsetmin=0);
```
