## In Depth

Windows Presentation Foundation (`WPF`) 帮助你将设计视图与代码视图分离；从而允许你一次只处理一个视图。由于 `WPF` 基于所见即所得 (`WYSIWYG`) 原则，你的代码可以直接在设计视图中查看。`WPF` 中的应用程序借助 Extensible Application Markup Language (`XAML`) 设计。此语言还定义了 `WPF` 应用程序中控件的层次结构。你可以使用 `XAML` 添加控件并为其配备附加功能。在 `WPF` 中编程与在 Windows Forms 中编程非常相似。两者之间的唯一区别在于 `WPF` 设计视图的存在。`WPF` 中的控件是用户交互元素，派生自 `System.Windows.Control`、`Microsoft.Win32` 和 `System.Windows.Document` 命名空间。

本章描述了 `WPF` 中的控件和执行的功能。你还将了解 `WPF` 中使用的样式、模板和资源。此外，本章还讨论了触发器，控件需要触发器来响应命令。

## WPF 4.0 Controls

`WPF` 拥有丰富的控件集，其中一些控件与 Windows Forms 控件相似。Windows Forms 和 `WPF` 应用程序的控件在外观和行为上有所不同。你可以通过使用 `XAML` 代码修改 `WPF` 控件的外观。随着你在 `XAML` 视图中更改控件的 `XAML` 代码，`WPF` 控件的外观和行为会在设计视图中自动更改。在 `WPF` 应用程序中，控件的 `XAML` 代码以树视图显示。`WPF` 中控件的工作依赖于两个基类，即 `FrameworkElement` 和 `Control` 类。`Control` 类是派生自 `FrameworkElement` 类的公共基类。

`WPF` 提供了多个控件可供使用，例如 `Grid`、`TextBox` 和 `RichTextBox` 控件。`WPF` 中的每个控件都归类为以下类别之一：

- Container controls
- Simple controls
- Content controls
- Headered content controls
- Items controls
- Headered items controls
- Miscellaneous controls

让我们在以下各节中详细了解这些类别。

## Container Controls

`WPF` 中的容器控件包括 `Grid`、`UniformGrid`、`Canvas`、`DockPanel`、`StackPanel` 和 `WrapPanel` 控件。这些控件为子控件提供内置布局功能。子控件是放置在容器控件内部的控件。例如，在 `Grid` 控件中使用的 `Label` 控件是 `Grid` 控件的子控件。容器控件处理子控件的布局和定位。

## The Grid Control

最常见的容器控件是 `Grid` 控件。每当你向 `WPF` 应用程序添加新窗口时，默认情况下窗口会自动包含一个 `Grid` 控件。`Grid` 控件由一个单元格组成。你可以在 `Grid` 控件内部添加额外的行和列。`Grid` 控件中的子元素在显示区域中按列和行排列。`Grid` 控件也可以包含另一个 `Grid` 控件作为其子元素。

`Grid` 控件由 `Grid` 类表示，该类派生自 `Panel` 类。`Grid` 类的继承层次结构如下：

```
                        System.Windows.Controls.Panel

```

### The UniformGrid Control

`The UniformGrid` container control arranges the content in the `Grid` control in such a way that the cells in the grid remain the same size. When you add different controls on the `UniformGrid` control, all the controls get arranged in a grid pattern. The cells in the `UniformGrid` control adjust to accommodate different controls.

`The UniformGrid` control is represented by the `UniformGrid` class, which is derived from the `Panel` class. The inheritance of the `UniformGrid` class is as follows:

```
          System.Windows.FrameworkElement
            System.Windows.Controls.Panel
              System.Windows.Controls.Primitives.UniformGrid
```

### The Canvas Control

`The Canvas` control is the simplest container control that supports absolute positioning of its child controls by using the coordinates that are relative to the `Canvas` control. When you place a control in the `Canvas` control, you must specify one horizontal property and one vertical property to specify the starting position of the child control inside the `Canvas` control. This control is the only container control that has no built-in layout of its own. By default, the `Height` and `Width` properties of the `Canvas` control are set to zero.

To position a child control on the `Canvas` control, you need to set its `Canvas.Top`, `Canvas.Left`, `Canvas.Right`, or `Canvas.Bottom` property.

`The Canvas` control is represented by the `Canvas` class, which is derived from the `Panel` class. The inheritance hierarchy of the `Canvas` class is as follows:

```
System.Object

        System.Windows.UIElement
          System.Windows.FrameworkElement
            System.Windows.Controls.Panel
              System.Windows.Controls.Canvas
```

You can add a `Canvas` control to a `WPF` application by using the following code snippet:

```
</Canvas>
```
