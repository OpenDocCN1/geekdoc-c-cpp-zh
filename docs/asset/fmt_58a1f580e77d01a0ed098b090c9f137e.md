
# 术语表

## 虚拟文件夹 (virtual folder)
看起来像文件夹但在计算机文件系统中没有直接对应物的视图。

## 虚拟内存 (virtual memory)
通过将数据从内存中交换出并临时存储在硬盘上来模拟的内存。

## 虚拟屏幕键盘 (virtual onscreen keyboard)
屏幕上的键盘副本，用户可以点击或触摸以模拟打字。

## 虚拟专用网络 (VPN)
使用互联网等公共通信通道创建安全、私有通信隧道的方法。

## 病毒 (virus)
一种附加到可执行文件的恶意软件，在程序运行时会传播到其他文件。

## IP 电话协议 (VoIP)
一种基于 Web 的电话业务。最为人知的例子是 Skype。

## 语音识别软件 (voice recognition software)
识别与其数据库中的单词匹配的口语，将语音语言数字化。

## 卷 (volume)
一种被分配了标识字母的物理存储设备或其部分。有时与驱动器 (drive) 交替使用，但物理驱动器实际上可能包含多个卷。

## 广域网 (WAN)
跨越至少两个地理位置的网络；拥有两个或多个办公室的企业可能每个站点都有一个局域网 (LAN)，但使用广域网将它们全部连接到同一个网络。

## 热启动 (warm boot)
重启已经开启的计算机。

## 网页制作软件 (web authoring software)
帮助创建网站设计和内容的软件。

## 网页浏览器 (web browser)
用于访问网站并检索或上传信息的应用程序。通常称为浏览器。

## 网页 (web page)
一种为万维网格式化的文件。

## 网页服务器 (web server)
接收网页数据请求并通过互联网发送这些数据的服务器。

## Web 应用 (web-application)
下载到你的计算机并在网页浏览器中运行的软件。

## 摄像头 (webcam)
一种在运行时必须保持连接到计算机的数字摄像机。

## 所见即所得 (WYSIWYG)
应用程序中的一项功能，允许用户看到作品在分发给他人时（如打印或在线时）的准确样式。

## 白名单 (whitelist)
允许的邮件发送者列表；也称为安全列表。

## Wi-Fi 无线以太网 (Wireless Ethernet)
一种无线方式连接计算机和其他设备的方法。其技术标准为 IEEE 802.11。

## Wi-Fi 保护访问 (WPA)
一种提供 128 位加密密钥的无线加密形式。

## Wi-Fi 保护设置 (WPS)
某些无线接入点上的功能，允许用户将设备连接到受信的网络。

## 维基 (wiki)
一种任何人编辑的 Web 应用程序，通常具有信息性。

## 维基百科 (Wikipedia)
一本免费的在线百科全书。维基的一个例子。

## 窗口颜色 (window color)
窗口标题栏和边框的颜色。

## 窗口 (window)
显示内容的移动矩形块。

## Windows 8 应用
一种全屏运行并针对触摸使用优化的新型应用程序。

## Windows 体验指数 (Windows Experience Index)
一种根据五个关键测量值描述计算机运行 Windows 性能的数值评分。

## Windows Phone
设计为 SoC 平板的 Windows 版本。

## Windows RT
设计为平板电脑的 Windows 版本。

## Windows 更新 (Windows Update)
Windows 中的一项功能，自动下载并安装 Windows 以及某些 Microsoft 应用程序的更新。

## 有线等效安全 (WEP)
一种较旧且不安全的无线加密形式。

## 线框 (wireframe)
一种仅包含线条而未应用任何表面的 3D 矢量图形。

## 无线接入点 (wireless access point)
无线交换机。

## 无线键盘 (wireless keyboard)
以无线方式而非电缆连接到计算机的键盘。

## 无线鼠标 (wireless mouse)
以无线方式与收发器通信以连接计算机，因此不需要线缆。

## 路由器 (router)
管理无线网络上设备与具有直接访问互联网网络的计算机之间的连接。

## 文字处理器 (word processor)
用于创建或查看文本文档的程序。

## 字长 (word size)
CPU 同时能接受的输入位数。

## 工作簿 (workbook)
一个 Excel 数据文件，包含一个或多个工作表。

## 工作表 (worksheet)
工作簿中的选项签页，包含行和列的网格。

## 万维网 (WWW)
存储在公共访问服务器上的互联信息页面的网络。

## 蠕虫 (worm)
一种通过网络或互联网自我传播到其他计算机的恶意计算机程序。

## WPA2
Wi-Fi 保护访问的改进版本，通过 128 位或 256 位加密密钥提供更强的保护。

## 自动换行 (Wrap Text)
Word 等 Office 应用程序中的功能，允许您指定图形与任何相邻文本交互的方式。

## 处理器架构
- `x64`：Intel 平台的 64 位版本。
- `x86`：Intel 平台的 32 位版本。

## YouTube
一个用于发布和共享视频的社交网络。

## Zombie
僵尸网络用于进行 DoS 攻击的计算机。

## Zoom 控制
位于状态栏右侧的控件，用于调整数据显示的放大倍数。
