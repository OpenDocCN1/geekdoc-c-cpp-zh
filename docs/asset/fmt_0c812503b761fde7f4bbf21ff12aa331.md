
如果 `$action` 的值是 `"ASSEMBLE ORDER"`，结果是：
Perform activities for order assembly.
Perform activities for packing.
Perform activities for shipping.

## 默认值

`switch` 语句同样提供了一种在替代 `case` 都不匹配时执行操作的方法，这与 `if`、`elseif` 或 `else` 块中的 `else` 语句相同。
使用 `DEFAULT:` 语句作为 `switch` 的最后一个 `case` 语句（参见示例 4-12）。

示例 4-12. 使用 `DEFAULT:` 语句产生错误

```php
switch ($action) {
  case "ADD":
    echo "Perform activities for adding.";
    break;
  case "MODIFY":
    echo "Perform activities for modifying.";
    break;
  case "DELETE":
    echo "Perform activities for deleting.";
    break;
  default:
    echo "Error: Action must be either ADD, MODIFY, or DELETE.";
}
```

`switch` 语句还支持另一种替代语法，其中 `switch` 和 `endswitch` 关键字用于表征 `switch` 的开始和结束，而不是使用大括号 `{}`，如示例 6.13 所示。

示例 6.13. 利用 `endswitch` 结束 `switch` 定义

```php
switch ($action) {
  case "ADD":
    echo "Perform actions for adding.";
    break;
  case "MODIFY":
    echo "Perform actions for modifying.";
    break;
  case "DELETE":
    echo "Perform actions for deleting.";
    break;
  default:
    echo "Error: Action must be either ADD, MODIFY, or DELETE.";
endswitch;
```

你已经发现，可以让你的程序根据称为“表达式”的条件执行不同的代码。`switch` 语句为将表达式的值与各种可能的值进行匹配提供了一种合适的格式。

## 6.4 循环

由于你已经根据检查结果改变了 PHP 程序的流，你需要意识到，需要重新执行一次赋值，直到检查结果为 `FALSE`（假），这需要你使用**循环（LOOPING）**。代码循环每执行一次，被称为迭代。这对于某些基础任务非常有价值，例如通过循环返回的列来显示查询结果。PHP 提供了 `while`、`for` 和 `do ... while` 结构来执行循环。

每个循环结构都需要两个基本数据项。首先，停止循环的条件描述方式与 `if` 语句中的比较相似。其次，要执行的代码同样需要被指定在单行内或大括号内。一种逻辑错误是将依赖于执行代码以使循环停止的代码排除在循环之外，从而导致死循环。

你已经发现，可以根据条件让你的项目执行不同的代码。`switch` 语句为将表达式的值与各种可能的属性进行匹配提供了一个有利的安排。

当表达式评估为 `TRUE` 时，代码被执行。为了避免永远循环的死循环，你的代码应当使表达式最终变为 `FALSE`。当这种情况发生时，循环停止，执行继续到下一行代码，遵循逻辑循环。

### while 循环

`while` 循环接收表达式，后跟要执行的代码。

一个 `while` 循环的语法为：
`while (expression)`

```php
{
code to execute;
}
```

示例 6.14 展示了一个示例。

示例 4-14. 一个检查到 10 的 `while` 循环示例

```php
<?php
$num = 1;
while ($num <= 10){
    print "Number is $num<br/>";
    $num++;
}
print 'Done.';
?>
```

示例 4-14 输出这些：
- Number is 1
- Number is 2
- Number is 3
- Number is 4
- Number is 5
- Number is 6
- Number is 7
- Number is 8
- Number is 9
- Number is 10

Done.

在循环开始之前，变量 `$num` 设置为 1。这被称为实例化计数器变量。代码块每执行一次，通过语句 `$num++;` 将 `$num` 的值增加 1。在 10 次迭代后，评估 `$num <= 10` 变为 `FALSE`，然后循环停止并打印 Done。记住增加 `$num` 变量，因为 `while` 循环依赖它。要小心不要导致死循环。其负面影响是无法返回页面并在 Web 服务器上消耗大量的处理时间。

### do ... while 循环

`do ... while` 循环接收与 `while` 语句类似的表达式，但它将其放在最后。它的语法是：

```php
do {
code to execute;
} while (expression);
```

当你需要无论表达式值如何都至少执行一次代码时，这个循环很有帮助。例如，如图 6.15 所示，用这个循环检查到 10。

图 6.15. 使用 `do ...` 计数到 10

```php
<?php
$num = 1;
do {
echo "Number is ".$num."<br/>";
$num++;
} while ($num <= 10);
echo "Done.";
?>
```

案例 6.15 创建与示例 4-14 相同的结果；如果你将 `$num` 的值改为 11，循环的形式会有不同：

```php
<?php
$num = 11;
do {
echo $num;
$num++;
} while ($num <= 10);
?>
```

这产生了：循环上的代码显示 11，因为循环可靠地至少执行一次。通过之后，`while` 评估为 `FALSE`，导致执行退出 `do...while` 循环。

### for 循环

`for` 循环提供了与 `while` 循环相同的功能，尽管它们需要一个预定义的区域来更改计数器。它们的语法是：`for (初始化表达式; 条件表达式; 修改表达式){要执行的代码}`

```php
for ($num = 1; $num <= 10; $num++) {
    print "Number is $num<br/>";
}
```

这产生了：
- Number is 1
- Number is 2
- Number is 3
- Number is 4
- Number is 5
- Number is 6
- Number is 7
- Number is 8
- Number is 9
- Number is 10

```php
for ($counter<10;$counter++) {
  // 检查是否除以零
  if ($counter==0) {
    echo "跳过以避免除以零。<br>";
    continue;
  }
  echo "100/$counter ,100/$counter,<br />";
}?>
```

新的输出将按照如下顺序所示：
100/ - 3 - 33-33333333333
100/ - 2 - 50
100/ - 1 - 100
为了与除以零保持策略距离而跳过
100/1 100
100/2 50
100/3 33.33333333333
100/4 25
100/5 20
100/6 16.6666666667
100/7 14.2857142857
100/8 12.5
100/9 11.1111111111

注意，循环跳过了 `$counter` 值为零的情况，并依然继续处理下一个值。

我们现在已经涵盖了大部分主要的程序流语言结构。我们讨论了用于控制程序执行流的构建模块。表达式可以像 `TRUE` 或 `FALSE` 那样直接，也可以像使用本地运算符进行关系比较那样令人费解。与程序流结构结合的表达式（如 `if` 语句和 `switch`）使得决策变得简单。

我们还检查了 `while`、`do ... while` 和 `for` 循环。循环对于基础元素网页任务非常有帮助，例如在 HTML 表格中显示查询结果。

# 第 7 章：函数

为了编写不仅包含几页代码且具有良好体系以发挥价值的 PHP 程序，你必须对函数有深入的理解。函数让你无需在程序中反复编写相同的代码。函数的工作原理是为一组代码分配一个名为“函数名”的名称。随后，你通过调用该名称来执行代码。PHP 中有许多内置函数。例如，`print_r` 是一个函数，它能以易懂的英语而非代码打印变量周围的连贯数据。如果给定字符串、数字或浮点数，`print_r` 函数会打印属性本身。如果给定数组，属性将以键和组件的形式展示出来。对象也使用类似的格式。在 PHP 5.0 中，`print_r` 和 `var_export` 可以显示对象的保护和私有属性。

运行从 `aggregate_info` 到 `imap_ping` 再到 `pdf_open_image` 的数组。由于这类函数有很多，我们在本章中只需涵盖一些基础知识，尽管我们会提供足够的数据，让你在短时间内通过使用函数看起来像个专家。

你可以访问 `http://www.php.net` 查看完整的函数列表。
具体来说，我们将介绍以下内容：
- 如何创建一个函数、给它命名并执行该函数
- 如何向函数传递值并在函数中使用这些值
- 如何从函数返回值并在你的代码中应用它们
- 在尝试调用函数之前验证该函数是否存在

在编码时，何时可以将代码拆分为函数，这在很大程度上是一个主观的判断。毫无疑问，如果你发现自己在反复编写某几行代码，那么将这些代码封装成函数是非常明智的。这会让你的代码更易读，并且当你决定对这部分代码进行其他操作时，可以保护你无需进行多处改进，因为代码只需要修改一个处，而不是多个需要替换和更改的地方。
