### 2.4.4 合并

将两个数组合并为一个是一个重要的操作。图 2.9 显示了如何合并两个数组。

- 将一个数组复制到第三个数组。
- 将第二个数组元素追加到第三个数组。
- 结果数组包含两个数组的元素。

> 示例 2.9 编写一个程序合并两个数组。

```c
# include <stdio.h>
# include <conio.h>
void main()
{
    int j,k,s=0;
    int x[4]={1,2,3,4};
    int y[4]={5,6,7,8};
    int z[8];
    clrscr();
    printf("Array X: ");
    for(j=0;j<4;j++)
        printf("%d ",x[j]);
    printf("\nArray Y: ");
    for(j=0;j<4;j++)
        printf("%d ",y[j]);
    printf("\nArray Z: ");
    for(j=0;j<4;j++)
        z[s++]=x[j];
    for(j=0;j<4;j++)
        z[s++]=y[j];
    for(k=0;k<8;k++)
        printf("%d ",z[k]);
}
```

输出
Array X: 1 2 3 4
Array Y: 5 6 7 8
Array Z: 1 2 3 4 5 6 7 8

解释：
在上面的程序中，声明并初始化了数组 `x` 和 `y`。声明第三个数组 `z` 来存储合并后的元素。第一个循环将数组 `x` 的元素复制到 `z`，第二个循环将数组 `y` 的元素复制到 `z`。最后，打印数组 `z` 的元素。

## 2.5 排序

排序是将元素按照特定顺序（升序或降序）排列的过程。有很多排序算法。

> 示例 2.10 编写一个程序按升序排序数组。

```c
# include <stdio.h>
# include <conio.h>
void main()
{
    int i,j,temp;
    int a[5];
    clrscr();
    printf("输入五个元素: ");
    for(i=0;i<5;i++)
        scanf("%d",&a[i]);
    for(i=0;i<4;i++)
        for(j=i+1;j<5;j++)
        {
            if(a[i]>a[j])
            {
                temp=a[i];
                a[i]=a[j];
                a[j]=temp;
            }
        }
    printf("\nSorted array: ");
    for(i=0;i<5;i++)
        printf("%d ",a[i]);
}
```

输出
输入五个元素: 5 2 9 1 5
Sorted array: 1 2 5 5 9

解释：
在上面的程序中，使用简单的冒泡排序算法对数组排序。嵌套循环将每个元素与剩余元素进行比较，如果元素大于下一个元素，则进行交换。这个过程一直重复直到数组按升序排序。
