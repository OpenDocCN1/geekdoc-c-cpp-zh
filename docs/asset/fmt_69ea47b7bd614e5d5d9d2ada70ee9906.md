## 使用 ASP.NET AJAX 启用的 Web 服务

如你所知，Web 服务是一组一个或多个服务器端方法，客户端可以在任何远程位置调用并在应用程序中使用。客户端首先使用 HTTP 协议向服务器发送请求以调用 Web 服务。过程与 Web 页面处理回发事件时遵循的过程非常相似，只是 HTTP 协议请求的主体由传递给 Web 服务方法的参数组成。然后创建 Web 服务的实例并执行 Web 方法内部的代码，返回结果；之后实例被销毁。未启用 AJAX 的 Web 服务使用 SOAP 协议向服务器发送请求并获取响应，但 AJAX 启用的 Web 服务使用 JSON 格式用于此目的。

执行以下任务以使用 ASP.NET AJAX 启用的 Web 服务：

- 创建 ASP.NET AJAX 启用的 Web 服务

- 从脚本调用 ASP.NET AJAX 启用的 Web 服务

### 创建 ASP.NET AJAX 启用的 Web 服务

在 ASP.NET AJAX 中，Web 服务的定义方式与不带 AJAX 功能的 Web 服务相同。与任何其他 ASP.NET Web 服务一样，ASP.NET AJAX 启用的 Web 服务由两部分组成，一个 `.asmx` 文件，充当 Web 服务端点，以及一个 `.cs` 文件，其中包含 Web 服务的代码。让我们执行以下步骤来创建一个 ASP.NET AJAX 启用的 Web 服务：

1. 打开 Microsoft Visual Studio 2010 并从菜单栏中选择 `File→New→ Web Site` 选项并将应用程序命名为 `WebServiceCallApp`。

2. 在应用程序上右键单击后选择 `Add New Item` 选项。`Add New Item` 对话框打开。接下来，从 Visual Studio 2010 的中间模板中选择 `Web Service` 模板并将 Web 服务命名为 `TimeService`，然后单击 `Add` 按钮。代码隐藏文件 `TimeService` 和 Web 服务文件 `TimeService.asmx` 已添加到你的 Web 应用程序中。当你打开 `TimeService.asmx` 文件时，你会在其中找到以下单行代码：

```
<%@ WebService Language="C#" CodeBehind="~/App_Code/TimeService.cs" Class="TimeService" %>
```

代码隐藏类定义了一个名为 `TimeService` 的类，如以下代码所示：

```
[WebService(Namespace = "http://tempuri.org/")]
[WebServiceBinding(ConformsTo = WsiProfiles.BasicProfile1_1)]
// To allow this web service to be called from script, using ASP.NET AJAX, uncomment the following line.
// [System.Web.Script.Services.ScriptService]
public class TimeService : System.Web.Services.WebService {
    public TimeService () {
        //Uncomment the following line if using designed components
        //InitializeComponent();
    }
}
```

请注意，Web 服务类声明由三个属性组成。第一个是 `WebService`（为 Web 服务设置 XML 命名空间），第二个是 `WebServiceBinding`（指示 Web 服务可以保持的标准符合级别）。这两个属性仅在你使用 SOAP 调用 Web 服务时应用，在 ASP.NET AJAX 的情况下不相关。然而，第三个属性 `ScriptService` 更重要。此属性允许你的 Web 服务使用 JSON 格式从诸如 JavaScript 之类的客户端脚本语言调用。在没有此属性的情况下，你将无法使用 ASP.NET AJAX 启用的 Web 服务。
