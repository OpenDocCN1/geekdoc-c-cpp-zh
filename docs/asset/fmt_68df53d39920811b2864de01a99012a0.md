- 2. 自动存储类（`automatic`）变量的值在不同的函数调用之间持续。
- 3. 如果 CPU 寄存器不可用，则寄存器存储类（`register`）变量被视为静态存储类变量。
- 4. 寄存器类变量不能存储浮点数（`float`）值。
- 5. 如果我们尝试对浮点数变量使用寄存器存储类，编译器将抛出错误信息。

- 8. 静态变量的生命周期直到控制权保持在其定义的块内。
