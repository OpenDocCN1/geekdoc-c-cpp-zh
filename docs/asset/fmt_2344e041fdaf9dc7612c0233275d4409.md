```
    }

    j++;

}
```

注意使用 `while` 循环需要更多的代码，因为没有自动递增的值，但当你有一个无法使用数值条件的可用条件时，你需要 `while` 循环。

## If 语句

我们在上一节中对 `if` 语句介绍较少。`if` 语句在编程中非常常见，它是改变代码的一种。

首先，让我们来看 `if` 语句的set模板。

```
if (expression)

{

  // 当表达式为真时执行

}
```

我们已经看了一些例子，但让我们来看另一个。

```
int myNumber1 = 1;
int myNumber2 = 2;
if (myNumber1 == 2)
{
  Console.WriteLine("The variable equals the value of 2");
}
```

我们在之前的 `if` 语句使用了相同的代码来提供另一个例子。在这个例子中，我们给了 `if` 语句一些执行的代码。如果 `myNumber1` 等于 2，它会打印“The variable equals the value of 2”。由于 `myNumber1` 初始化为值 1，结果是 `if` 语句不执行括号内的代码。

一直为止，我们只看了带有一个条件的 `if` 语句，但 `if` 语句还允许将条件与 `else` 以及 `if-else` 语句结合。这两者都为你的代码增加了更多控制。让我们来看这种语句的模板。

```
if(expression)
{
// 当表达式为真时执行
}
else
{
// 当表达式不为真时执行
}
```

上述 `if-else` 语句提供了一个在 `if` 语句中的条件为假时执行替代代码的选项。

让我们来看与 `if-else` 结构工作的实际代码。

```csharp
int myNumber1 = 1;
int myNumber2 = 2;
if (myNumber1 == 2)
{
    Console.WriteLine("The variable equals the value of 2");
}
else
{
    Console.WriteLine("The variable does not equal 2");
}
```

我们在之前的 `if` 语句使用了相同的代码，但我们添加了 `else` 语句。与之前的 `if` 语句一样，这个默认为假。而不是直接跳过所有的 `if` 语句，`else` 语句默认执行。这一次，`if` 语句执行的结果是在控制台中显示“The variable does not equal 2”。

你还可以在 `else` 语句中添加一个 `if` 语句。这允许你在可以在一个 `if` 语句块中创建多个条件。让我们来看模板。

```
if (expression)
{
  // 当表达式为真时执行的语句
}
else if (expression)
{
  // 当表达式不为真时执行的语句
}
else
{
  // 当表达式不为真时执行的语句
}
```

请注意，我们仍然保留了带有两个条件的 `else` 语句。`else` 语句对于任何语句来说都是可选的。例如，你可以只保留上面模板中的两个 `if` 语句，而省略 `else` 语句。

现在，让我们来看一些使用该模板的实际代码。我们将使用与之前示例中相同的变量。

```
int myNumber1= 1;
int myNumber2 = 2;
if ( myNumber1 = 2)
{
  Console.WriteLine("The variable equals the value of 2");
}
else if ( myNumber1= 1)
{
  Console.WriteLine("The variable equals the value of 1");
}
else
{
  Console.WriteLine("The variable does not equal 2 or 1");
}
```

在这一语句中，我们在第一个块和 `else` 块中使用了相同的条件。如果你注意到，第一个块的评估结果为假。这次，我们有了一个 `else if` 语句。该语句有另一个条件待评估。这次，该条件为真。因此，执行了第二个块并跳过了 `else` 语句。上述语句的结果是在控制台上显示“The variable equals the value of 1”。

### Switch 语句

最后一种条件语句是 `switch` 语句。`switch` 语句与 `if` 语句类似，但它是对一个变量进行多个条件的评估。让我们先看看该语句的模板。

```
switch(expression) {
  case constant-expression :
    // 要执行的语句
    break;
  case constant-expression :
    // 要执行的语句
    break;
  default :
    // 要执行的语句
}
```

通过该语句，变量被设置为 `switch` 表达式的值，然后每个 `case` 语句将确定变量是否等于该值。让我们来看 `switch` 语句的运行。

```
int myNumber = 1;
switch (myNumber) {
  case: 1
    Console.WriteLine("Value is 1");
    break;
  case: 2
    Console.WriteLine("Value is 2");
    break;
  default:
    Console.WriteLine("Don’t know the value");
}
```

在上面的代码中，我们评估变量 `myNumber` 的值。我们将其初始化为 1，然后使用 `case` 语句遍历每个可能的值。因为我们知道值是 1，我们可以看到第一个 `case` 语句评估为真，然后在控制台上显示“Value is 1”。

`default` 语句类似于 `if` 块中的 `else` 语句。如果没有任何 `case` 语句的结果为真，则执行 `default` 语句。

`break` 语句用于退出 `case` 语句。如果你不添加 `break` 语句，下一个 `case` 将一直执行，直到代码到达 `default` 语句。只需记住，每个 `case` 语句都需要一个 `break` 来退出 `switch` 块。

我们在本章中学习了几个循环和 `if` 语句。理解代码的执行流非常重要，因为这些语句在包括 C# 在内的任何编程语言中都很常见。这些语句需要通过练习来理解代码的执行方式，因为每个语句都会改变工作流。使用这些语句在你自己的程序中练习代码流。

## 第 6 章：OOP 简介

目标：OOP 是 C# 程序主要的架构代码设计。本章涵盖了使用 OOP 概念进行 C# 编程的基础。

面向对象编程（OOP）与线性开发非常不同。OOP 使用组件的概念进行软件开发。它不是只是逐行编写代码并让每行执行到找到代码末尾，类（classes）的概念使用了按照类定义和调用的顺序来执行的组件。本章将帮助编码人员理解如何与 OOP 及其概念工作。

## 理解 OOP 基础

OOP 使用创建组合在一起以构建整个程序的各个部分的概念。这些部分被称为类（classes）。它们也被称为类对象。类代表了你程序的每个部分。

为了理解为什么类代表了程序的部分，请想象一下汽车。汽车有几个部分组合成一整辆汽车。每个部分单独来说都是没用的，但当它们组合在一起时，它们就创造了一台许多人无法制造的机器。

以汽车为例，你需要（除其他之外）发动机、方向盘和轮胎来组成一台汽车。没有这些组件，汽车就是没用的。类代表了汽车的这些部分。类包含了这些部分的所有属性，以及它们移动或停止汽车所需的任何操作。

在开始编程之前，你需要在编程之前对其进行设计。当你使用第三方绘图程序或你自己的草图和图纸来设计类时，无论你使用什么，布局程序并确定你的类如何表示程序的部分都是关重要的。在编码之前对程序进行设计，可以避免任何由于程序部分缺失而导致的错误。

在设计类时，你还应该确保每个属性和方法都能与类本身良好配合。例如，如果你有一个带有 `Customer`（客户）和 `Product`（产品）类的电子商务应用程序，你不会在 `Customer` 类中放置一个处理产品库存的方法。你会将产品库存放在 `Product` 类中，否则当你发现它在正确的类中不可用时，可能会意外创建两次相同的方法。

## 公共修饰符 (Public Specifier)

一旦你设计了类，就必须决定要让它们对程序的其他部分可用。我们将在下一节讨论如何创建类，但理解围绕它们的基础知识很重要。

`public` 修饰符告诉程序该类可以在程序的任何区域访问。让我们来看一个带有 `public` 修饰符的 `Customer` 类示例。

```
public class Customer {
    public Customer() { }
    public string first_name;
    public string last_name;
    public string phone;
}
```

在上面的 `Customer` 类中，注意类的第一个修饰符是 `public` 关键字。如果我们删除了 `public` 关键字，该类将对程序的其他部分不可用。

你还会注意到构造函数被设置为 `public`。我们将在下一节介绍构造函数的作用，但只需知道这对于程序的其他部分实例化该类并使用其属性和方法是必要的。它也也被设置为 `public` 的，但我们也可以将其设置为 `private`。`public` 修饰符允许程序的其他部分实例化该类。

为了向你展示示例，以下代码实例化了类并将其赋值给变量。

```
Customer cust = new Customer();
cust.firstLine = "John";
Console.WriteLine(cust.first_name);
```

## 私有修饰符 (Private Specifier)

与 `public` 修饰符一样，`private` 修饰符也是你类的一个选项。它将类从程序的其他部分隐藏起来。通过 `private` 修饰符，你无法从程序的其他部分调用该类。

让我们来看与上一节相同的代码，但我们改使用 `private` 修饰符。

```
private class Customer
```

```csharp
{
  private Customer() {
    public string first_name;
    public string last_name;
    public string phone;
  }
}
```

通过同一个类，我们将公共（public）访问符更改为私有（private）。现在，`Customer` 类对程序的其他部分是完全隐藏的。

让我们尝试像上一个节那样调用该类。看下面的代码。

```csharp
Customer cust = new Customer();
cust.first_name = "John";
Console.WriteLine(cust.first_name);
```

上面的代码将产生错误，提示该类被设置为私有。当你使用私有类时，你只能在它所属的作用域内使用它。大多数类都不会被设置为私有，因为它们无法在程序的其他地方使用。

## 将类设置为受保护（Protected）

最后一个重要的修饰符是受保护（protected）修饰符。这个并不常用，但偶尔也会使用。受保护类只允许当前类或任何子类使用属性和方法。

我们将介绍如何从父类派生子类，以及如何使用子类来扩展父类。只需记住，在设计程序时，对于受保护的类，只有子类可以使用它的方法和属性。

在随后的章节中，我们将涵盖更多 OOP 概念和类，以便你对代码进行更多练习。习惯 OOP 需要大量的大量的练习，但它是可以学习的并作为新程序员的一项宝贵工具。

# 第 7 章：类（Classes）

**目标：** 在上一章中我们讨论了 OOP，在本章中，我们将把这些概念应用于设计和构建类。

类是 OOP 的主要组件。类是组合在一起创建一个完整程序的对象。它们通常被称为对象或类对象。只要类是公共的，你就可以在代码的任何区域使用你的类对象。在本章中，我们将讨论如何创建一个类以及它的方法、属性和构造函数。

## 类类类

正如我们之前所说，类定义了应用程序的组件。在开始创建类之前，你应该画出一个设计图（通过绘图或线框图），以程序的视觉表示形式来解释你的程序。如果你忘记了某个类并需要重构代码，这比提前通过绘图软件设计好类要令你沮丧且耗时得多。

类是你的代码结构的构建块，因此在设计程序时，你应该理解创建程序时所需的每个部分。每一个部分都应该被考虑在内。

设计程序的良好方法是画出你的屏幕。对于每个屏幕，解释它的功能。当你理解了屏幕的工作方式后，你就能更好地理解你的类应该如何布局。

让我们先看一个描述客户的简单类。大多数应用程序都需要将“客户”概念作为应用程序的一个组件。让我们来看一个 `Customer` 类，它包含了客户的地址、姓氏和名字属性。

```csharp
public class Customer
{
    public Customer () {}
    public string first_name;
    public string last_name;
    public string phone;
}
```

注意，我们将公共修饰符设置为 public，以允许其他程序访问该类对象。类的每个属性也设置了 public 修饰符。这允许外部程序在整个程序中分配并检索它们的值。

构造函数是你在类对象中看到的第一个函数。构造函数是类的重要部分，因为它们允许外部方法实例化类，并使用属性和方法来操作数据。构造函数的名称与类名相同，且它永远没有返回类型。
