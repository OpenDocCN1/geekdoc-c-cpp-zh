## 引号

缺少引号是每个级别用户都会犯的常见错误。记住，例如输出到屏幕或写入文件的字符串需要引号。大多数编译器都会因为代码中缺少引号而报错。

## 变量初始化

C++ 变量默认不会初始化为零。这意味着如果你创建一个变量而不对其进行赋值，可能会得到一个从 0 到 18,466,744,073,709,511 之间的随机数，这在等式中很难处理。在创建变量时，给它一个初始值：

```cpp
#include <iostream>
using namespace std;
int main() {
  int x;
  x=0;
  cout << x;
}
```
