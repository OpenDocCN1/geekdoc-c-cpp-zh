```haskell
applySecond :: ∀ a b f. Apply f => f a -> f b -> f b
```

它接受一个 `Apply`，所有 `Monads` 都是 `Apply`，并且它会丢弃第一个的计算结果而保留第二个。这就是我们对 Lambda 所做的，我们忽略了第一个的结果而保留第二个。
