
## Step 7.15 根据 `CLAIM_SEGMENT_ID` 收集在步骤 7.14 中输出的记录

具体而言，对于具有相同 `CLAIM_SEGMENT_ID` 值的记录，代码会输出一条记录，其中包含的 `FROM_DT` 值等于该索赔集中最早的 `FROM_DT`，而 `THRU_DT` 值等于该索赔集中中最晚的 `THRU_DT`。如果记录属于情景 #4，代码将为该受益人输出多条记录。最后，代码通过计算每条输出记录中 `THRU_DT` 与 `FROM_DT` 之间的差值来计算住院时长（称为 `LOS`）。输出的分析文件 `UTL.SN_2010 STAY` 和 `UTL.HH_2010 STAY` 将保存为永久数据集，以备后之用。

```sas
/* STEP 7.15: COMBINE CLAIMS WITH OVERLAPPING SEGMENTS */
data util.&clmtyp.2010_stay_fnl(drop=begin_dos end_dos
claim_segment_id);
  retain thru_dt;
  set &clmtyp.2010_stay;
  by bene_id claim_segment_id;
  format from_dt thru_dt mmddyy10;
  if first.claim_segment_id then do;
    from_dt=begin_dos;
  end;
  if last.claim_segment_id then do;
    thru_dt=end_dos;
    los=thru_dt-from_dt;
    output;
  end;
run;
%mend;
%clm_loop2(&clmtyp=sn);
%clm_loop2(&clmtyp=hh);
%clm_loop2(&clmtyp=hs);
```

例如住院康复等服务。处理所有这些问题超出了本入门文本的范围，但对于读者来说，开始考虑这些问题并准备在研究工作中将其考虑内（或研究它们！）是至关重要的。相反，我们利用索赔数据集中的医疗保险支付变量（即医疗保险计划为服务提供者就（已提供的）服务所支付的金额）来确定医疗保险的成本。因此，当我们使用“成本”（cost）一词时，我们指的是医疗保险为该服务支付的费用，这等同于医疗保险的服务成本。

值得注意的是，医疗保险并非以相同的方式支付所有服务。自1984年以来，医疗保险已从收费标准和成本报销转向预付支付系统（PPS）。具体来说，简单来说：

- *承运人理赔按照收费标准支付。*
- 耐用医疗设备（DME）理赔使用分类收费标准进行支付。
- 如第7章所述，住院理赔可以预见性支付（使用住院预付支付系统，或 `IPPS`），也可以基于成本支付（例如，针对关键准入医院）。马里兰州的医院按费率委员会支付，因为它们没有参与 `IPPS`。
- 门诊理赔使用门诊预付支付系统（`OPPS`）支付。医疗保险 B 部分支付受益人接受的门诊服务费用。由于由于原因，住院数据中的理赔被称为“机构 B 部分”理赔。
- 技能护理设施理赔是预见性支付。针对 SNF 理赔的预付支付系统（PPS）是基于每个护理天数的预定费率计算的。
- 居家医疗机构理赔是预见性支付。家庭医疗的 PPS 是基于应用于每个 60 天家庭医疗护理疗程的预定费率。
- 临终关怀理赔按每日费率支付，该费率未考虑临终关怀期间特定一天所提供的服务水平。

为了掌握激励计划的成本结果，我们将编写算法对以下内容进行处理：

- *衡量医生诊所环境下的评估与管理（E&M）成本。*
- 衡量住院医院成本。
- 衡量总 A 部分成本（即与住院、技能护理设施 (SNF)、家庭医疗和临终护理服务相关的成本）。

### 关于支付标准化和风险调整的说明

一个重要的说明：在我们的示例项目中，我们计划跨地区比较支付。两个问题可能会这项工作变得困难：成本的区域差异以及基于患者严重程度的差异。

现在，是玩“好消息与坏消息”的时候了。好消息是针对这些挑战有解决方案！坏消息是这些解决方案的研究不幸超出了本书范围！当然，这并不能免作者详细描述一下支付标准化和风险调整！

支付标准化是一个术语，用于控制与患者护理无关的支付差异，即由工资率、生活水平和医院资本成本驱动的成本区域差异。风险调整是另一个术语，通过统计学方法保持患者的人口统计健康状况（严重程度）差异，以便进行成本和质量比较。所有这些是如何工作的？如果我们试图对成本差异得出结论，必须考虑到华盛顿的成本可能高于（例如）马里兰州的农村地区，仅仅是因为华盛顿大市的生活成本更高。一旦我们消除了华盛顿购买的商品和服务平均比马里兰州农村购买的贵30%这一事实，我们就可以对这些地区的医疗成本进行准确比较。

同样，重要的是控制某些提供者或提供者群体所看到的患者平均年龄比其他提供者看到的患者年长的这一事实。事实上，很容易想象这样的情况：患有并发症的老年患者手术后出现并发症的概率比健康的年轻患者高，导致需要更多服务。反过来这可能导致该受益人产生更高的成本。再次，支付标准和风险调整都是属于各自书籍的主题。我们不会在研究中使用这种方法，但了解它们的存在以及 CMS 对这两个主题都有方法论和模型是重要的。
