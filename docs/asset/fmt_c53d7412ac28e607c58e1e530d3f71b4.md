
# 函数指针与库函数

## 函数指针的赋值与初始化

类型为 `T` 的函数指针可以使用类型 `T` 的函数的地址或相同类型的指针进行赋值或初始化。要用函数的地址赋值或初始化函数指针，只需将合适且已知的函数的函数指示符（即函数名）放置在赋值运算符的右侧即可。在后续的语句中，函数 `sub` 的地址被赋值给函数指针 `str`：

```c
int sub(int,int);
int (*str)(int,int);
str = sub;
```

在后续语句中，函数指针 `str` 使用函数 `add` 的地址进行初始化：

```c
int add(int,int);
int (*atr)(int,int) = add;
```

关于函数指针赋值或初始化、函数初始化的重要要点如下：

- 在函数指针赋值或初始化时，必须已知函数指示符，即已声明或定义。
- 函数指示符隐式地引用函数的起始地址。然而，函数指示符前面可选地加上取地址运算符（`&`）以表示函数的地址。以下两个语句是等价的：

```c
int (*atr)(int,int) = add;
int (*atr)(int,int) = &add;
```

## 8.6 库函数

库函数或预定义函数是由他人已经开发好并供用户使用的函数。例如 `printf` 和 `scanf` 库函数。使用库函数涉及两个方面：

1. 库函数的声明
2. 库函数的使用

### 8.6.1 库函数的声明/头文件

我们已经见过用户定义函数在调用之前需要进行声明。库函数也是如此。库函数在调用之前需要进行声明。库函数的声明位于各自的头文件中。为了在程序文件中能够访问这些声明，需要包含相应的头文件。例如，`printf` 函数的原型（即函数声明）位于 `stdio.h` 头文件中。这就是为什么在调用 `printf` 函数之前要包含 `stdio.h`。如果在使用之前没有包含包含库函数声明的头文件，将出现“Prototype missing”（缺少原型）的编译错误。

### 8.6.2 库函数的使用

库函数的使用方法与用户定义函数相同，即通过使用函数运算符。下面列出了一些常用库函数的作用和用法。

## 可变参数函数

程序 8-31 中列出的代码以及可变参数函数的要点如下：

- 由于函数 `sum` 是“固定数量参数后跟可变数量参数”的函数，因此它声明为 `int sum(int no_of_arguments, ...)`。在声明可变参数函数时使用省略号 `(...)`。

**省略号的作用**：传递给可变参数函数的参数数量是不固定的。因此在声明可变参数时，无法列出函数调用期间可能传递给函数的所有参数的类型。这个问题的解决方案由省略号提供。在声明可变参数函数时，参数列表中使用了省略号 `(...)`。省略号 `(...)` 后面可以跟随零个或多个参数，且参数的类型是未知的。可变参数声明中的零个或多个参数会挂起类型检查。

`printf` 函数的原型/声明是 `int printf(const char *, ...)`。该原型表示 `printf` 函数中可以有一个或多个参数。第一个参数的类型是 `const char *`，后面的参数可以是任何类型。由于省略号 `(...)`，以下 `printf` 的用法是有效的：

```c
printf("Hello Readers");
printf("%d %s %c.", 1, "Hi", 'c');
```

- 可变参数函数是在头文件 `stdarg.h` 中的宏 `va_start`、`va_arg` 和 `va_end` 的帮助下开发的。因此需要包含头文件 `stdarg.h` 以使用这些宏。

头文件 `stdarg.h` 还声明了一个类型 `va_list`，存储宏 `va_start`、`va_arg` 和 `va_end` 需要的信息。在函数 `sum` 中声明了一个类型为 `va_list` 的变量 `ptr`。

宏 `va_start` 接受两个参数 `ptr` 和 `lastfix`。第一个参数 `ptr` 的类型是 `va_list`，`lastfix` 是传递给可变参数函数 `sum` 的固定参数 `no_of_arguments`，类型为 `int`。宏 `va_start` 将 `ptr` 设置指向传递给函数的第一个可变参数。

宏 `va_arg` 用于返回可变参数列表中的参数。第一次使用 `va_arg` 时，它返回列表中的第一个参数。每次后续使用 `va_arg` 时，它都会返回列表中的下一个参数。宏 `va_arg` 返回其第二个参数所指定的类型的值（例如，在程序 8-31 中列出的代码中为 `int`）。

在 `va_arg` 读取完所有参数后应调用宏 `va_end`。如果没有使用宏 `va_end`，程序可能会显示奇怪且未定义的行为。

调用 `va_start`、`va_arg` 和 `va_end` 的顺序应为：

1. `va_start` 必须在第一次调用 `va_arg` 或 `va_end` 之前调用。
2. `va_end` 应该在 `va_arg` 读取完所有参数后调用。

可变参数函数实际上具有固定数量的参数后跟可变数量的参数。省略号中只能有三个点，即 `(...)`。在省略号中使用三个以上的点会导致编译错误。使用宏的语法与使用函数的语法相似。

## 8.8 总结

1. 函数有助于将程序模块化为更小的简单部分。
2. 函数根据以下标准分类：(a) 谁开发函数以及 (b) 函数的参数和返回类型。
3. 根据开发函数的身份，它们被分为：(a) 用户定义函数和 (b) 库函数。
