
# 第 5 章：`'STRING'` 数据类型

## 5.2 `std::string` 运算符

### 索引运算符

索引运算符用于获取对象的单个字符，或为非 `const string` 对象的单个字符赋值。此处没有范围检查（请使用 `[]` 成员函数）。该运算符返回 `char &` 或 `const char &`。

```
object[3] = argument;
```

### 逻辑运算符

逻辑比较运算符可以应用于两个 `string` 对象或一个 `string` 对象和一个 C 字符串，以比较它们的内容。这些运算符返回 `bool` 值。支持 `==`、`!=`、`>=`、`<` 和 `<=` 运算符。排序运算符使用 ASCII 字符序列对其内容进行字典序比较。

```
object == object;            // true
object != (object + 'x');    // true
object < (object + 'x');     // true
```

### 流相关运算符

插入-提取运算符（参见 3.1.4）可将 `string` 对象插入到 `ostream` 中，提取运算符可从 `istream` 中提取 `string` 对象。提取运算符默认忽略所有空白字符，并从 `istream` 中提取所有连续的非空白字符。除了字符串字符数组，还可以提取 `string` 对象。示例：

```
cin >> object;
cout << object;
```

## 5.2.4 `std::string` 成员函数

`std::string` 类提供了许多成员函数。这些函数按字母顺序排列。当返回 `npos` 时，返回 `string::size_type`。

- `char &at(size_t opos)`：指定位置的引用。如果传递无效索引，将抛出异常。
- `append(InputIterator begin, end)`：将范围 `begin` 到 `end` 之间的字符添加到当前字符串。
- `append(const string& argument, size_type apos)`：将 `argument`（或子字符串）添加到当前字符串。
- `append(const char* argument, size_type apos)`：将 `argument` 的字符添加到当前字符串。
- `assign(size_t n, char ch)`：将 `ch` 赋值给当前字符串。
- `assign(const string& argument, size_type apos, size_type an)`：将 `argument`（或子字符串）赋值给当前字符串。
- `assign(size_t n, char ch)`：将 `ch` 赋值给当前字符串。
- `back()`：返回存储的最后一个字符的引用。
- `capacity()`：可以存储的字符数。
- `clear()`：删除字符串的内容。
- `compare(const string& argument)`：使用 ASCII 序列进行字典序比较。
- `compare(size_t opos, size_t on, string const& argument)`：当前字符串对象的子字符串与 `argument` 的比较。
- `compare(size_t opos, size_t on, string const& argument)`：当前字符串对象的子字符串与 `argument` 的比较。
- `compare(size_t opos, size_t on, char const* argument, size_type an)`：当前字符串对象的子字符串与 `argument` 的比较。
- `contains(argument)`：如果对象包含 `argument` 作为子字符串，则返回 `true`。
- `copy(char *argument, size_t on, size_type apos)`：将当前字符串的内容（部分）复制到 `argument`。返回实际复制的字符数。
- `empty()`：如果当前 `string` 对象不包含数据，则返回 `true`。

## 5.2 `std::string` 引用

- `string::iterator end()`：返回一个指向当前字符串对象最后一个字符之后位置的迭代器。对于 `const` 字符串对象，返回一个 `const_iterator`。
- `bool ends_with(argument) const`：如果对象的字符以 `argument` 结尾，则返回 `true`。参数可以是 `string`、`string_view`、`char` 或 NTBS。
- `string &erase(size_type pos, size_type len)`：删除存储在当前字符串对象中的信息子串。
- `string::iterator erase(iterator begin, iterator end)`：参数 `end` 是可选的。如果省略，则使用当前对象的 `end_mem_iterator` 返回的值。删除由 `begin` 和 `end` 迭代器定义的字符。返回 `begin` 迭代器，该迭代器指向最后一个被删除字符之后的位置。
- `size_t find(string const &argument, size_type apos) const`：返回当前字符串对象中找到 `argument` 所在的第一个索引。
- `size_t find(char argument, size_type apos, char an) const`：返回当前字符串对象中找到 `argument` 所在的第一个索引。当指定所有参数时，第一个参数必须是 `char const *`。
- `size_t find(char ch, size_type apos) const`：返回当前字符串对象中找到 `ch` 所在的第一个索引。
- `size_t find_first_of(string const &argument, size_type apos) const`：返回当前字符串对象中其字符匹配 `argument` 中任意字符的第一个索引。
- `size_type find_first_of(char const *argument, size_type apos, size_type an) const`：返回当前字符串对象中其字符匹配 `argument` 中任意字符的第一个索引。如果提供了 `apos`，它返回当前字符串对象中开始搜索 `argument` 扫描的第一个索引。如果省略，则完全扫描字符串对象。`an` 表示在搜索中应使用的 `char *argument` 的字符数。它定义了从 `argument` 开始处的一个子串。如果省略，则使用所有字符。
- `size_type find_first_of(char ch, size_type apos) const`：返回当前字符串对象中其字符等于 `ch` 的第一个索引。
- `size_t find_not_of(string const &argument, size_type apos) const`：返回当前字符串对象中其字符不匹配 `argument` 中任意字符的第一个索引。
- `size_type find_not_of(char const *argument, size_type apos, size_type an) const`：返回当前字符串对象中其字符不匹配 `argument` 中任意字符的第一个索引。`apos` 参数的处理方式与 `find_first_of` 相同。
- `size_t find_not_of(char ch, size_type apos) const`：返回当前字符串对象中其字符等于 `ch` 的第一个索引。
- `size_t find_last_of(string const &argument, size_type apos) const`：返回当前字符串对象中其字符匹配 `argument` 中任意字符的最后一个索引。
- `size_type find_last_of(char const *argument, size_type apos, size_type an) const`：返回当前字符串对象中其字符匹配 `argument` 中任意字符的最后一个索引。如果 `apos` 指向它，则指向当前字符串中开始搜索 `argument` 的最后一个索引（向当前对象的开头反向搜索）。如果省略，则完全扫描对象。如果 `an` 提供了它，则表示搜索中应使用的 `char *argument` 的字符数。它定义了从 `argument` 开始的一个子串。如果省略，则使用所有字符。
- `size_type find_last_of(char ch, size_type apos) const`：返回当前字符串对象中等于 `ch` 的最后一个索引。
- `size_t find_last_not_of(string const &argument, size_type apos) const`：返回当前字符串对象中其字符不匹配 `argument` 中任意字符的最后一个索引。
- `size_t find_last_not_of(char const *argument, size_type apos, size_type an) const`：返回当前字符串对象中其字符不匹配 `argument` 中任意字符的最后一个索引。
- `size_t find_last_not_of(char ch, size_type apos) const`：返回当前字符串对象中其字符不等于 `ch` 的第一个索引。
- `size_t find_last_not_of(char ch, size_type apos) const`：返回当前字符串对象中其字符不等于 `ch` 的第一个索引。
- `size_t find_last_not_of(char ch, size_type apos) const`：返回当前字符串对象中其字符不等于 `ch` 的第一个索引。
- `size_t find_last_not_of(char ch, size_type apos) const`：返回当前字符串对象中其字符不等于 `ch` 的第一个索引。
- `size_t find_last_not_of(char ch, size_type apos) const`：返回当前字符串对象中其字符不等于 `ch` 的第一个索引。
- `size_t find_last_not_of(char ch, size_type apos) const`：返回当前字符串对象中其字符不等于 `ch` 的第一个索引。

## 5.2.5 转换函数

提供了多种字符串转换函数，用于操作或产生 `std::string` 对象。这些函数按字母顺序列在下面。

- `void reserve(size_t request)`：将当前字符串对象的容量更改为至少 `request`。调用此函数后，`capacity()` 的返回值将至少为 `request`。对于较小的值，`capacity()` 返回的值将不被忽略。如果 `request` 超过了 `max_size()` 返回的值，则会抛出 `std::length_error` 异常（`std::length_error` 定义在 `<stdexcept>` 头文件中）。`reserve()` 具有精炼字符串容量的作用：当扩大容量时，会分配额外的内存，但程序无法立即使用。这可以通过字符串的 `at()` 成员在访问超出字符串长度但未超出容量的元素时抛出的异常来证明。
- `void resize(size_t size, char ch = 0)`：将当前字符串对象的大小调整为 `size` 个字符。如果字符串对象的大小调整为比当前大小更大的值，则额外的字符将初始化为 `ch`。如果减小到 `size` 个字符，则高索引将被截断。
- `size_t rfind(string argument, string_type pos) const`：在当前字符串中找到 `argument` 的最后一个索引。搜索从当前对象的偏移量向开头开始。
- `size_t rfind(char argument, string_type pos, string_type n) const`：在当前字符串中找到 `argument` 的最后一个索引。搜索从当前对象的偏移量向开头开始。参数指定了要查找的子字符串长度，从 `argument` 的起始开始。
- `size_t rfind(char ch, string_type pos) const`：在当前字符串中找到 `ch` 的最后一个索引。搜索从当前对象的偏移量向开头开始。
- `void shrink_to_fit()`：可选地将 `vector` 分配的内存减少到其当前大小。实现可以自由地忽略或优化此请求。为了保证“收缩以适应”操作，可以使用以下惯用法：

```cpp
string(stringObject).swap(stringObject)
```

- `size_t size() const`：返回存储在当前字符串对象中的字符数。此成员是 `length()` 的同义词。
- `bool starts_with(argument) const`：如果对象的字符范围以 `argument` 开头则返回 `true`。参数可以是 `string`、`string_view`、`char` 或 `NT`。
- `bool substr(string_type pos, string_type count) const`：返回当前字符串对象中从索引 `pos` 开始的最多字符的子字符串。
- `void swap(string &argument)`：当前字符串对象的内容与 `argument` 的内容交换。对于此成员，参数必须是字符串对象而不能是 `char const*`。
