## 14.2 二分法

第 14.1 节解释的求根程序适用于手动计算；然而，微小的修改可以使其更具系统性，并更容易适应计算机编程。这种改进后的计算技术被称为**二分法**。假设你已经知道 `a` 和 `b` 之间有一个根，即函数在该区间内符号发生了变化。根据假设，`a` 和 `b` 之间只有一个根，且函数在该区间内是连续的。

函数可能类似于图 14.2 中的草图。如果你定义 `x1 = a` 和 `x3 = b` 为区间的左右端点，并定义 `x2 = (x1 + x3)` 为中点，函数会在半区间内跨越 `x`轴。在图中，交叉发生在右侧，因此你用右半区间替换原有区间。因此：

`x2` 变为 `x1`。
`x3` 保持不变。
`x2` 重新计算值为 `1/2(x1 + x3)`。

再次，问题是“函数跨越哪个半区间的 `x`轴？”

## 数值方法

![](img/d5a225ca53b347501e86d72212077531_795_0.png)

**图 14.2** 在 `a` 和 `b` 之间有一个根的函数草图

在第二次确定左半部分或右半部分包含根之后，区间再次被左半区间或右半区间替换。此过程一直持续直到你将根缩小到预指定的精度。每一步使区间减半，因此在 `n` 次迭代后，包含根的区间大小为 `(b-a)/2^n`。如果你要求找到容差为 `δ` 以内的根（即 `|x-root| < δ`），迭代次数 `n` 可以由此方程确定：

$$\frac{b-a}{2^n} < \delta$$

例如，上一节示例中的初始搜索区间为 `(b-a)=0.1`。如果根的精度要求为 `δ=10^{-5}`，那么：

$0.1 < 10^{-5}$

$2^n > 10^4$

该方程可以如下求解出 `n`：

$n > \frac{\log(10^4)}{\log(2)} > 13$

因此，计算表明，在应用第 13 次区间减半程序后就达到了所需的精度。该方法被省略的唯一元素是计算机如何确定区间的哪一半包含轴交叉点。

## 第14章 二分法

为此，考虑在左侧评估的函数值 `f1 = f(x1)` 和在中点评估的函数 `f2 = f(x2)` 的乘积，所示：

| 如果 | 则 |
|---|---|
| `f1f2 > 0` | `f1` 和 `f2` 均为正或均为负。无论何种情况，`x1` 和 `x2` 之间都没有交叉，区间内没有根。 |
| `f1f2 < 0` | `f(x)` 在 `x1` 和 `x2` 之间符号发生了变化。在这种情况下，`x1` 和 `x2` 边界的区间内有一个根。 |

程序 14.1 使用以下方法寻找根：

```cpp
#include <iostream>
#include <cmath>
using namespace std;

// 二分函数
void bisection(double a, double b, double epsilon, int maxiter)
{
    int i; // 迭代计数
    double x1, x2, x3; // 左、右和中点
    double f1, f2, f3; // 在这些点评估的函数值
    double width; // 区间宽度
    double curwidth; // 区间宽度

    // 计算根
    x1 = a;
    x3 = b;
    f1 = f(x1);
    f3 = f(x3);
    width = (b - a);

    // 验证区间内是否存在根
    if (f1 * f3 > 0.0)
        cout << "\n区间内不存在根" << endl;
    else
      for (i = 1; i <= maxiter; i++) {
        // 寻找根所在的区间的哪一半
        x2 = (x1 + x3) / 2.0;
        f2 = f(x2);
        if (f1 * f2 <= 0.0) // 在左半区间
          curwidth = (x2 - x1) / 2.0;
          f3 = f2;
          x3 = x2;
        }
        else // 在右半区间
          curwidth = (x3 - x2) / 2.0;
          f1 = f2;
          x1 = x2;
        }
        if (curwidth < epsilon) {
          cout << "\n在 x = " << x2 << " 找到了根 ";
          cout << "经过 " << i << " 次迭代" << endl;
          cout << " 函数值为 " << f2 << endl;
          return;
        }
      }
    cout << "\n在 " << maxiter << " 次迭代后，未在收敛标准内找到根" << endl;
    return;
}

// 评估 f(x) 的函数
double f(double x)
{
  const double PI = 2*asin(1.0); // PI 的值
  return (exp(-x) - sin(0.5 * PI * x));
}

int main() {
    // 输出输入
    cout << "\n区间从 " << a << " 到 " << b << endl;
    cout << "收敛标准为 " << epsilon << endl;
    cout << "最大迭代次数为 " << maxiter << endl;
    // 获取数据
    cin >> a >> b >> epsilon >> maxiter;
    bisection(a, b, epsilon, maxiter);
    return 0;
}
```

## 14.3 二分法的改进

第 14.2 节描述的二分法提供了构建大多数求根方法的基础。这种暴力法在实践中很少用于几乎任何问题，因为存在更快速、更准确且仅略微更复杂的替代方法。二分法的任何改进都是基于尝试在每次迭代中使用尽可能多地关于函数行为的可用信息。在普通的二分法中，监控的函数唯一特征是其符号。因此，如果你正在寻找函数

`f(x) = e^x - sin(sqrt(x))`

的根，你将按照第 14.1 节描述的那样，通过沿 x 轴步进并观察函数符号的变化开始搜索，如下：

| i | f(x) |
| :--- | :--- |
| 0 | 2.0 |
| 1 | 1.33 |
| 2 | 0.75 |
| 3 | 0.29 |
| 4 | -0.05 |

二分法的下一步是将步长缩小一半；即 `x5=0.35`。根据前几个数字的幅度，你预期的根更接近 0.4 而非 0.3。通过使用函数值大小的信息而不仅仅是符号，你可以加快收敛。在这个例子中，你可能插值得到根约为

```
$\frac{0.29 - 0.0}{0.29 - (-0.05)} = \frac{f_3 - f_4}{f_3 - f_4} = 0.853$
```

距离 `x3=0.3` 到 `x4=0.4` 或 `x5=0.3853` 的距离。继续这种方式并在每一步进行插值，你将得到如下结果：

| i | f(x) |
| :--- | :--- |
| 3 | 0.29 |
| 4 | -0.05 |
| 5 | -0.0083 |
| 6 | -0.0013 |
| 7 | -0.00019 |
| 8 | -0.000028 |
| 9 | -0.000004 |

程序 14.1 中原始二分法代码的替代方案非常直观，并已纳入程序 14.2 中。然而，该程序中的 C++ 代码需要一些解释：

- 函数 `fx` 每个周期仅求值一次。如果函数非常复杂，因此计算开销很大，这种效率衡量标准通常是选择解法的决定性因素。
- 一种成功路径：搜索区间当前的比例大小——即（当前区间/原始区间）小于用户提供的收敛准则。如果是这样，程序寻找近似根的目标已经实现。不能保证该准则会导致 `f(x)` 的值足够“小”。但是，关键在于连续的迭代导致包含区间仅发生了微小变化，因此过程将继续，除非——
- 两条失败路径：如果迭代次数大于 `Imax`（程序员设置的最大迭代次数），则停止过程。此测试允许程序员指定尝试求解时所接受的最大成本。由于在错误截弦法和改进错误截弦法中迭代次数是不可预测的，因此这种方法是必不可少的。它也是防止构造问题时出现意外错误的一种预防措施，这些错误可能导致程序无限循环而找不到解。在任何有无限循环危险的程序中，都需要此类陈述。
- (2) 如果函数没有改变符号 `f_i × f_x > 0`，则停止过程。因为已知原始区间包含根，这种情况发生的唯一可能是由于错误。通常，错误出现在函数 `fx(x)` 的代码中；也就是说，你正在尝试寻找一个与预想函数不同的函数的根。
