
- (c) 函数 `f` 有一个唯一的根 `θ*`，且当 `θ ≠ θ*` 时，`A^T(θ)f(θ) ≠ 0`。此外矩阵 `A(θ*)` 非奇异。

在逐渐增强的假设下，ODE (4.15) 解满足：

- (i) 如果 (a) 成立，对于每个 `t` 和每个初始条件，

```
$$\frac{d}{dt}\partial_t = -A(\partial_t)[I + A(\partial_t)^T]^{-1}A^T(\partial_t). \quad (17)$$
```

- (ii) 如果额外满足 (b)

```
$$\lim_{t\to\infty} \partial_t^T\mathbf{f}(\partial_t) = 0. \quad (18)$$
```

- (iii) 如果 (a)-(c) 成立，(4.15) 是全局稳定的。

证明：(ii) 的结论源于链式法则和定义。(iii) 的结论源于李雅诺夫函数 `V(∂_t) = 1/2||f(∂_t)||^2`，并结合：

```
$$\frac{d}{dt}V(\partial_t) = -\mathbf{f}(\partial_t)^T A(\partial_t)[I + A(\partial_t)^T]^{-1}A^T(\partial_t)\mathbf{f}(\partial_t).$$
```

当 `∂_t ≠ θ*` 时，右侧非负。对于任何 `T > 0` 积分每一步：

```
$$V(\partial_T) = V(\partial_0) - \int_0^T \mathbf{f}(\partial_t)^T A(\partial_t)[I + A(\partial_t)^T]^{-1}A^T(\partial_t)\mathbf{f}(\partial_t)dt, \quad (19)$$
```

使得对于所有 `T`，`V(∂_T) ≤ V(∂_0)`。在强制假设下(4.15) 的解也是界的。令 `T → ∞`，从 (19) 得到界：

```
$$\int_0^{\infty} f(\partial_t)^T A(\partial_t) (I + A(\partial_t)^T)^{-1} A^T(\partial_t)f(\partial_t) dt \le V(\partial_0).$$
```

`∂_t` 的有界性和 `A` 的连续性意味着存在 `B(∂_0) < ∞`，使得 `∫_0^∞ γ_t dt ≤ B(∂_0) < ∞, γ_t def= ||A(∂_t)f(∂_t)||_2^2`。

函数 `f` 和 `A` 是 Lipschitz 连续的，有界性意味着 `γ_t` 满足引理 4.3 中的条件。因此 `lim_{t→∞} =0` 如所示。

接下来我们证明 (iii)。虽然根据命题 2.5，我们提供了另一个短证明的素材。(4.15) 的全局渐近稳定性要求解从每个初始条件收敛到 `θ*`，且 `θ_t` 在李雅诺夫意义上是稳定的。假设 (c) 结合 (ii) 得出 `lim_{t→∞} θ_t = θ*`。后者的充分条件通过考虑 `A_θ = ∇_θ Γ(θ)|_{θ=θ*}` 得到。如果其特征值位于 `ℂ` 中的严格左半平面，则在李雅诺夫意义上稳定 [1, 2]。

应用定义，得到 `A_θ = -[I+M]^{-1}M`，其中 `M = A(θ*)^T A(θ*) > 0`（记得假设 `A(θ*)`是非奇异的）。`A_θ` 的特征值与 `M` 的特征值重合，对于每个特征值-特征向量对，我们有：

```
$A_\theta v = \lambda_A v, \quad \lambda_A = -\frac{\lambda}{\varepsilon+\lambda} < 0.$
```

这建立了 `A_θ` 是 Hurwitz 的。

# 4.4 优化

我们转向损失函数 `Γ: ℝ^d → ℝ_+` 的最小化，我们想要计算全局最小值：

```
$$\theta^* \in \arg\min \Gamma(\theta).$$
```

本节包含了估计 `θ*` 的优化和 ODE 技术的简要综述。特别是，我们建立了最陡 ODE 收敛的条件：

```
$\frac{d\theta}{dt} = -\nabla\Gamma(\theta). \quad (4.20)$
```

这也被称为*梯度流*（gradient flow）。

记得向量 `θ_0 ∈ ℝ^d` 处的梯度 `∇Γ` 正交于等值集 `{θ ∈ ℝ^d : Γ(θ) = Γ(θ_0)}`，如图 4.1 所示。对于给定的时间 `t_0`，记 `θ_0 = θ_{t_0}, r_0 = Γ(θ_0)`，并根据 (2.28) 回想等值集的定义为

```
$S_\Gamma(r_0) = \{\theta \in \mathbb{R}^d : \Gamma(\theta) \le r_0\}$.
```

如果 `θ_0` 处的梯度不零，在所示所示，梯度流驱动解进入该集合内部：`Γ(θ_t) < r_0` 对于所有 `t > t_0`。特别是，每个下值集都是**吸收的**（absorbing）；一旦梯度流的解进入集合 `S_Γ(r_0)`，它永远不会离开。

### 4.4.1 凸性的作用

该术语在前面的章节中讨论过，但现在需要一个正式定义：

#### 凸性

- 集合 `S ⊂ ℝ^d` 是凸的，如果它包含了所有端点在 `S` 中的线段。也就是说，对于 `θ^0,θ^1 ∈ S` 和任何 `α ∈ (0,1)`，有 `(1-α)θ^0+αθ^1 ∈ S`。

- 域为 `S` 的函数 `Γ: S → ℝ` 被称为凸的，如果满足以下边界：对于任意一对 `θ^0,θ^1 ∈ S` 和 `ρ ∈ (0,1)`：

```
$$\Gamma((1-\rho)\theta^0+\rho\theta^1) \leq (1-\rho)\Gamma(\theta^0)+\rho\Gamma(\theta^1).\quad(4.23)$$
```

如果对于任何 `r ∈ ℝ` 下水平集 `S_Γ(r)` 是凸的（或空的），则它是准凸的。

凸函数始终是准凸的；当 `S = ℝ` 时，任何非递减函数都是准凸的，因为在这种情况下，对于每个 `r，S_Γ(r) = (-∞, a(r))`，其中 `a(r) = max{θ : Γ(θ) ≤ r}`（确保准凸性不需要连续性，但为了得到下水平集的这种表示需要连续性）。

以下描述具有更强的通用性：

**引理 4.5** 对于任意凸集 `S`，`Γ: S → ℝ` 是*凸的*当且仅当对于每个 `θ^0 ∈ ℝ^d`，存在一个向量 `v^0 ∈ ℝ^d` 满足

```
$$\Gamma(\theta) \geq \Gamma(\theta^0) + \langle v^0, \theta - \theta^0\rangle$$
```

(4.24) 的右侧被视为 `θ` 的仿函数，该边界意味着 `Γ` 的图始终位于仿函数的上方。向量 `v^0` 称为梯度。如果 `Γ` 在 `θ^0` 处可微，则唯一的 `v^0 = ∇Γ(θ^0)`。

还有几种条件：

- 当 `θ^1 ≠ θ^0` 时，不等式 (4.23) 是严格的，`Γ` 是*严格凸的*。

- 如果 `Γ` 是可微的，则对于常数 `δ_0 > 0`，它是强凸的：

```
$$\langle\nabla\Gamma(\theta) - \nabla\Gamma(\theta^0), \theta - \theta^0\rangle \geq \delta_0|\theta - \theta^0\|^2\quad \text{for all } \theta^0 \in S.\quad (4.25)$$
```

强凸性用于建立梯度流的良好性质。凸性和强凸性的值如下所示：

**命题 4.6** 假设 `Γ: ℝ^d → ℝ_+` 是*凸的*。那么对于给定的 `θ^0 ∈ ℝ^d`，

- (i) 如果 `θ^0` 是局部最小值，则它是全局最小值；
- (ii) 如果 `Γ` 在 `θ^0` 处可微且 `∇Γ(θ^0) = 0`，则是全局最小值；
- (iii) 如果 (i) 或 (ii) 任意一个成立，或者 `Γ` 是严格凸的，则 `θ^0` 是唯一最小值。

在温和条件下梯度流收敛。泛化见练习题 7。

**命题 4.7** 假设 `Γ` 是连续可微、凸的且吸收的，具有唯一的最小化点 `θ^0`。那么梯度流 (4.20) 全局渐近于唯一的平衡点 `θ^0`。如果 `Γ` 是强凸的，则收敛速率是指数级的：

```
|\theta_t - \theta^0\| \leq e^{-\delta_0 t}.\quad (26)
```

其中 `δ_0` 出现在 (25) 中。证明：我们采用 `V(θ) = 1/2|θ - θ^0|^2` 作为李雅诺夫函数。根据链式法则：

```
$$\frac{d}{dt}V(\theta_t) = \langle\nabla\Gamma(\theta_t), \theta_t - \theta^0\rangle.$$
```

凸性意味着 `Γ(θ^0) ≥ Γ(θ_t) + ⟨∇Γ(θ_t), θ_t - θ^0⟩`，给出：

```
$$\frac{d}{dt}V(\theta_t) \leq -[\Gamma(\theta_t) - \Gamma(\theta^0)] \leq 0,$$
```

当 `θ_t ≠ θ^0` 时，不等式是严格的。命题 2.5 意味着全局稳定性。

在强凸性下，我们有 `∇Γ(θ*) = 0`，得到更强的边界：

```
$$\frac{d}{dt}V(\theta_t) = -\langle\nabla\Gamma(\theta_t) - \nabla\Gamma(\theta^*), \theta_t - \theta^* \rangle \leq -\delta_0|\theta_t - \theta^*\|^2.$$
```

也就是说，`V(θ_t) ≤ -2δ_0 V(θ_t)`。这意味着对于任意 `t，V(θ_t) ≤ V(θ_0)exp(-2δ_0 t)`，建立了 (26)。

### 4.4.2 Polyak-Lojasiewicz 条件

在命题 4.7 中使用欧几里得范数定义李雅诺夫函数依赖于凸性。另一种方法是使用 Polyak-Lojasiewicz (PL) 不等式：对于 `μ > 0` 和所有的 `θ`，

```
$$\frac{1}{2}\|\nabla\Gamma(\theta)\|^2 \geq \mu|\Gamma(\theta) - \Gamma^*|.\quad (27)$$
```

我们在这里不假设 `Γ` 是凸的，也不假设存在优化器 `θ_∞`。

**定理 4.8** 如果 PL 不等式成立，则对于每个初始 `θ_0`，梯度流满足：

```
$$\Gamma(\theta_t) - \Gamma^* \leq e^{-mt}|\Gamma(\theta_0) - \Gamma^*.$$
```

如果 `Γ` 是吸收的，则解是有界的，`θ_t}` 的任何极限点 `θ_∞` 都是优化器：`V(θ_∞) = Γ*`。

证明：我们采用 (4.21) 中的第二种方案作为李雅诺夫函数：

```
$$V(\theta_t) = \frac{1}{2}|\Gamma(\theta_t) - \Gamma^*| \implies -\frac{1}{2}\|\nabla\Gamma(\theta_t)\|^2 \leq -\mu V(\theta_t).$$
```

这意味着期望的 `Γ(θ_t) - Γ* = V(θ_t) ≤ e^{-mt}V(θ_0)`。

如果 `Γ` 是吸收的，`θ` 的轨迹在集合 `S = {θ : V(θ) ≤ V(θ_0)}` 中演化。如果 `θ_∞` 是极限点，则 `θ_∞ = lim_{n→∞} θ_n`，其中 `t_n → ∞`。损失函数的连续性意味着最优性：`Γ(θ_∞) = Γ*`。

### 4.4.3 欧拉近似

梯度流 (4.20) 的标准欧拉近似被称为最速下降：

```
$$\theta_{k+1} = \theta_k - \alpha\nabla\Gamma(\theta_k). (4.28)$$
```

为了从每个初始条件收敛，我们假设目标函数是 `L`-平滑的（回 (4.22)）。这是证明定理 4.8 的这一后续定理中两个关键边界之一：

**定理 4.9** 假设 `Γ` 满足两个边界：`L`-平滑不等式 (4.22) 和 PL 不等式 (4.27)。在满足的情况下为 (4.28) 提供以下边界：

```
$$\Gamma(\theta_k) - \Gamma^* \leq (1 - \alpha\mu)^k|\Gamma(\theta_0) - \Gamma^*.$$
```

证明：将 `L`-平滑不等式应用于梯度下降 (4.28)，得到：

```
$$\Gamma(\theta_{k+1}) - \Gamma(\theta_k) \leq [\theta_{k+1} - \theta_k]^T\nabla\Gamma(\theta_k) + \frac{L}{2}\|\theta_{k+1} - \theta_k\|^2 = (-\alpha + \frac{L}{2}\alpha^2)|\Gamma(\theta_k) - \Gamma^*\|^2.$$
```
