### 深入详解

导航控件允许用户在网页之间进行导航。例如，如果您的网站由多个页面组成，您需要有助于简化页面导航的导航控件。导航控件，如 `TreeView` 控件、`Menu` 控件和 `SiteMapPath` 控件，可以轻松地添加页面层次结构、快速链接，并为您的应用程序提供高级导航功能。导航控件以一致的方式显示数据，从而使用户能够理解应用程序的结构。这些导航控件是最新推出的控件，并为开发人员和用户提供了多种功能，例如一致且易于管理的导航。

在本章中，我们探讨了三个导航控件——`TreeView` 控件、`Menu` 控件和 `SiteMapPath` 控件，并讨论了每个导航控件的基类。本章还讨论了导航控件的各种属性、方法和事件，并向您展示了使用这些导航控件的实际实现。

#### 使用 TreeView 类

`TreeView` 类使您能够管理 `TreeView` 控件。`TreeView` 类可用于在运行时在网页中创建基于树的分层结构。

`TreeView` 类的类层次结构如下：

```
System.Object
  System.Web.UI.Control
    System.Web.UI.WebControls.WebControl
      System.Web.UI.WebControls.BaseDataBoundControl
        System.Web.UI.WebControls.HierarchicalDataBoundControl
          System.Web.UI.WebControls.TreeView
```

`TreeView` 类包含一个 `Node` 属性，可用于创建 `TreeView` 控件的节点。`Nodes` 集合包含 `Add` 方法，可用于在 `TreeView` 类中添加文本项或 `TreeNode` 对象。它还可以有子节点，并包含诸如 `ExpandAll` 和 `CollapseAll` 之类的属性，用于展开和折叠树视图节点。您还可以在节点旁边插入复选框，并通过使用 `TreeView` 类动态获取所选信息。

### TreeView 控件

`TreeView` 控件用于以类似于 Windows 资源管理器的分层结构逻辑地显示数据。当您需要在网页上显示导航菜单以显示文件和文件夹时，可以使用此控件。您可以在树形结构中显示可扩展标记语言 (XML) 文档和数据库记录。要在运行时使用 `TreeView` 控件，您可以通过编程方式访问 `TreeView` Web 服务器控件。

`TreeView` Web 服务器控件用于创建基于树的分层结构、设置属性和填充节点。`TreeView` 控件由 `TreeView` 容器和 `TreeNode` 属性组成。树视图结构中可以存在多个节点，并且可以嵌套。`TreeNode` 属性具有一个 `Text` 属性，该属性显示节点的文本。

除了 `Text` 属性之外，`TreeNode` 还有一个 `Expanded` 属性，用于展开和折叠节点。此属性的默认值为 False。但是，如果将其设置为 True，则每次加载控件时都会以展开视图显示。

您可以从工具箱的“导航”选项卡直接访问 `TreeView` 控件。您只需双击工具箱中的 `TreeView` 控件，或将控件从工具箱拖到 `Default.aspx` 页面的“设计”视图中，即可将 `TreeView` 控件添加到您的网页。图 15.1 显示了将 `TreeView` 控件放置在 TreeView Control 示例的 `Default.aspx` 网页上时的默认树视图节点：
