## 转换图像

在 WPF 中，你可以使用`BitmapImage`类的属性来转换图像。你可以应用于 WPF 图像的不同转换是旋转、转换和裁剪图像。你可以使用`BitmapImage`类的`Rotation`属性旋转图像。你可以使用`FormatConvertedBitmap`类将图像转换为不同的像素格式，例如灰度。你可以使用`Clip`属性或`CroppedBitmap`属性裁剪图像。如果你想显示图像的一部分，应使用`Clip`属性，如果你想编码并保存裁剪后的图像，则应使用`CroppedBitmap`属性。让我们创建一个应用程序并执行不同的转换。为此，创建一个名为`TransformingImages`的 WPF 应用程序（可在 CD 上获得）并将清单 12.42 中的代码添加到`MainWindow.xaml`文件中：

### 清单 12.42：显示图像的转换

```
<Window x:Class="TransformingImages.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="400" Width="750">
<Grid>
    <Image Width="250" HorizontalAlignment="Left" VerticalAlignment="Top">
        <Image.Source>
            <TransformedBitmap Source="D:\pictures\ZA-wp1.jpg">
                <TransformedBitmap.Transform>
                    <RotateTransform Angle="180"/>
                </TransformedBitmap.Transform>
            </TransformedBitmap>
        </Image.Source>
    </Image>
    <Image Width="250" HorizontalAlignment="Right" VerticalAlignment="Top">
        <Image.Source>
            <FormatConvertedBitmap Source="D:\pictures\ZA-wp1.jpg" DestinationFormat="Gray4" />
        </Image.Source>
    </Image>
    <Image Width="302" Source="D:\pictures\ZA-wp1.jpg" HorizontalAlignment="Center" VerticalAlignment="Bottom" Margin="281,0,195,28" Height="140">
        <Image.Clip>
            <EllipseGeometry Center="100,70" RadiusX="100" RadiusY="60" />
        </Image.Clip>
    </Image>
</Grid>
</Window>
```

在清单 12.42 中，同一张图片以三种不同的方式进行转换。第一张图片使用`RotateTransform`属性进行旋转。第二张图片被转换为不同的像素格式。第三张图片使用`EllipseGeometry`类进行裁剪。当你通过键盘按下 F5 键运行应用程序时，你会得到输出，如图 12.44 所示：

## 拉伸图像

你可以使用`Image`控件的`Stretch`属性来控制图像如何拉伸以填充容器。`Stretch`属性的值为`None`、`Fill`、`Uniform`和`UniformToFill`。如果`Stretch`属性设置为`None`，则图像不会被拉伸。如果图像大于输出区域，则图像不会被裁剪。`Fill`值会缩放图像以填充输出区域。在这种情况下，图像的纵横比可能不会被保留。`Uniform`值会缩放图像，使其完全适合输出区域。在这种情况下，图像的纵横比会被保留。`UniformToFill`值会缩放图像以完全填充输出区域。让我们在`Image`控件上使用`Stretch`属性。为此，创建一个名为`StretchingImages`的 WPF 应用程序（也在 CD 上提供）并向应用程序添加一个页面。现在将清单 12.43 中的代码添加到`Page1.xaml`文件中：
