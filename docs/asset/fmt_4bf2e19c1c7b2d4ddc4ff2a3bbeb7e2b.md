
这个 `$s$` 被称为不等式的松弛变量（slack variable）。为了证明，观察到向量 `(x_1, …, x_n)` 满足原始不等式约束，当且仅当存在某个 `$s ≥ 0$` 使其满足新的等式约束时。

- 将等式约束转换为不等式很容易：将 `ax = b` 改写为 `ax ≤ b`，以及等价的约束对 `ax ≤ b` 和 `ax ≥ b`。
- 最后，处理符号不受限制的变量 `x`，我们执行以下操作：
    - 引入两个非负变量 `x^+, x^- ≥ 0`。
    - 在约束或目标函数中出现 `x` 的地方将其替换为 `x^+ - x^-`。

通过这种方式，`x` 可以通过适当调整新变量来取任何实值。更准确地说，原始 LP 中涉及 `x` 的任何可行解都可以映射到涉及 `x^+, x^-` 的新 LP 的可行解，反之亦然。

通过应用这些变换，我们可以将任何 LP（极大或最小化、包含不等式和等式、以及包含非负和不受限制的变量）归约为一种约束性更强的 LP，我们称之为标准形式（standard form），在标准形式中，变量都是非负的，约束都是等式，且目标函数需要最小化。

## 矩阵-向量记法

像 `x_1 + 6x_2` 这样的线性函数可以写成两个向量的点积

`c = (1/6)` 和 `x = (x_1, x_2)`

记作 `c · x` 或 `c^T x`。同样，线性约束可以编译成矩阵-向量形式：

$$
\begin{array}{rrc}
x_1 & \le & 200 \\
x_2 & \le & 300 \\
x_1 + x_2 & \le & 400
\end{array}
\Rightarrow
\begin{pmatrix}
1 & 0 \\
0 & 1 \\
1 & 1
\end{pmatrix}
\begin{pmatrix}
x_1 \\
x_2
\end{pmatrix}
\le
\begin{pmatrix}
200 \\
300 \\
400
\end{pmatrix}
$$
`A ≤ b`

这里矩阵 `A` 的每一行对应于 `x` 的一个点积，其值小于等于 `b` 对应行的值。换句话说，如果 `A` 的行是向量 `a_1, …, a_m`，那么陈述 `Ax ≤ b` 等价于

`a_i x ≤ b_i` 对于所有 `i = 1, …, m`。

有了这些约定，通用的 LP 可以表示为：

`max  c^T x`
`Ax ≤ b`
`x ≥ 0`.

例如，我们的第一个线性规划重写为：

`max  x_1 + 6x_2`
`x_1 ≤ 200`
`x_2 ≤ 300`
`x_1 + x_2 ≤ 400`
`x_1, x_2 ≥ 0`  ⇒  `min  -x_1 - 6x_2`
`x_1 + s_1 ≤ 200`
`x_2 + s_2 ≤ 300`
`x_1 + x_2 + s_3 ≤ 400`
`x_1, x_2, s_1, s_2, s_3 ≥ 0`

这个 `s` 被称为不等式的松弛变量。为了证明，观察到向量 `(x_1, …, x_n)` 满足原始不等式约束，当且仅当存在某个 `s ≥ 0` 使其满足新的等式约束时。

使用例如线性时间广度优先搜索在 `G^f` 中寻找 `s - t` 路径，如果不再有可以增加流量的此类路径，则停止。

让我们通过描述对这三个乘数（我们称它们为 `y_1, y_2, y_3`）的期望来研究这个问题。

| 乘数 | 不等式 |
| :--- | :--- |
| `y_1` | `x_1 ≤ 200` |
| `y_2` | `x_2 ≤ 300` |
| `y_3` | `x_1 + x_2 ≤ 400` |

首先，这些 `y_i` 必须是非负的，否则它们将不具备乘不等式的条件（将不等式乘以一个负数会使 `≤` 反向为 `≥`）。在进行乘法和加法之后，我们得到了边界：

`(y_1 + y_3)x_1 + (y_2 + y_3)x_2 ≤ 200y_1 + 300y_2`

我们希望左侧看起来像我们的目标函数 `x_1 + 6x_2`，使得右侧成为最优解的上界。为了实现这一点，我们需要 `y_1 + y_3 = 1` 且 `y_2 + y_3 = 6`。仔细一想，如果 `y_1 + y_2` 大于 1，那么得到的证明将更有说服力。因此，我们得到了一个上界：

`x_1 + 6x_2 ≤ 200y_1 + 300y_2 + 400y_3`  如果 `y_1 + y_3 ≥ 1` 且 `y_2 + y_3 ≥ 6`

我们可以很容易通过让这些值足够大来找到满足右侧不等式的 `y`，例如 `(y_1, y_2, y_3) = (5, 3, 6)`。但这些特定的乘数告诉我们，该线性规划 (LP) 的最优值至多为 `200·5+300·3+400·6=4300`，这界限太松了，没有意义。我们想要的是一个尽可能紧的边界，因此我们在满足上述不等式的情况下，最小化 `200y_1 + 300y_2 + 400y_3`。*这是一个新的线性规划*。

因此，找到能为原始 LP 提供最佳上界的乘数集，等同于求解一个新的 LP：

`200y_1 + 300y_2 + 400y_3`  受限于
`y_1 + y_3 ≥ 1`
`y_2 + y_3 ≥ 6`
`y_1, y_2, y_3 ≥ 0`

根据设计，这个对偶 LP 的任何可行值都是原始*原问题 (primal)* 的上界。如果我们以某种方式找到一对相等的原始和对偶可行值，那么它们一定是最优的。这里有这样一对值：

`原问题 (Primal) : (x_1, x_2) = (100, 300);`  `对偶 (Dual) : (y_1, y_2, y_3) = (0, 5, 1).`

它们的数值均为 1900，因此证明了彼此的最优性（图 7.9）。

令人惊讶的是，这不仅仅是一个幸运的例子，而是一个普遍现象。首先，上述构造方法——为每个原始约束创建一个乘数，为原始问题的每个变量在对偶问题中写一个约束，且其和要大于对应原始变量的目标系数；并优化任何由原始右侧项加权的乘数——可以在任何 LP 中执行，如图 7.10 所示，并且在更具一般性的图 7.11 中所示。第二张图有一个值得注意的补充：如果原始问题具有等式约束，那么对应的乘数（或对偶变量）不需要是非负的，因为方程在乘以负数时其有效性保持不变。因此，两个 LP 之间存在对称性，即矩阵 `A = (a_ij)` 用它的每一行定义一个原始约束，用每一列定义一个对偶约束。根据构造，对偶问题的任何可行解都是原始问题任何可行解的上界。

对偶性定理：如果一个线性规划有有界最优值，那么它的对偶问题也有最优值，而且它们的最值是重合的。当原始问题是表示最大流问题的 LP 时，可以给对偶问题赋予解释，说明对偶问题无非最小切问题（练习题 7.25）。流与切之间的关系只是对偶性定理的一个特定实例。事实上，该定理的证明可以从单纯形算法得出，就像最大流算法一样。
