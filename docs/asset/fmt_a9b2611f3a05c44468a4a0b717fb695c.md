## C.7.4 写一个程序，连续读取整数并将其存储在 `vector` 中。如果用户输入 `-1`，则停止。然后程序应该检查 `vector` 是否对称，即第一个元素的值等于最后一个元素，第二个元素的值等于倒数第二个，以此此类推。如果不对称，程序应该检查是否有重复的值，如果有，则终止。

```cpp
#include <iostream>
#include <vector>
using std::cout;
using std::cin;
using std::vector;
int main() {
    bool flag;
    int i, j, size;
    vector<int> v;
    while (1) {
        cout << "Enter number: ";
        cin >> i;
        if(i == -1) {
            break;
        }
        v.push_back(i);
    }
    size = v.size();
    flag = 1;
    for(i = 0; i < size/2; i++) {
        if(v[i] != v[size-1-i]) {
            flag = 0;
            break; /* 发现 vector 不对称。 */
        }
    }
    if(flag) {
        cout << "Symmetric\n";
    } else {
        cout << "Not symmetric with ";
        for(i = 0; i < size; i++) {
            for(j = i+1; j < size; j++) { /* 此循环检查是否存在另一个值为 v[i] 的元素。 */
                if(v[i] == v[j]) {
                    cout << "same values\n";
                    return 0; /* 发现有相同的值，程序终止。 */
                }
            }
        }
        cout << "different values\n";
    }
    return 0;
}
```

**注释：** 如果元素是奇数，代码仍然有效，因为中间元素没有与其他元素比较。

- a. 将其转换为正数（例如 `5`）。
- b. 反转其位（例如 `101` 变为 `11111111111111111111111010`）。
- c. 加 `1`（例如数字变为 `111111111111111111111111011`，这应该是输出值）。

```cpp
#include <iostream>
using std::cout;
using std::cin;
int main()
{
    int i, j, bits[32]; /* 此数组存储数字的 0 或 1 位。大小为 32，因为我们假设整数的大小 是 32。 */
    unsigned int num;
    int tmp;
    cout << "Number: ";
    cin >> tmp;
    if(tmp < 0)
    {
        tmp = -tmp;
        tmp++;
    }
    num = tmp; // 存储为正数。
    i = 0;
    /* 连续除以 2 并每个位存储在相应的 数组位置。 */
    while(num > 0)
    {
        bits[i] = num & 1;
        num >>= 1; // 等于 num /= 2;
        i++;
    }
```

## C.7.6 下面程序的输出是什么？

```cpp
#include <iostream>
int main()
{
    int i, a[] = {-1, 5, 7}, b[] = {5, 4, -1};
    for (i = 0; i < 3; i++)
        a[i]-b[2-i]++;
    for(--i; i >= 0; i--)
        std::cout << a[i] << '\n';
    return 0;
}
```

**答案：** 让我们追踪第一个循环的迭代：
- 第一次迭代（`i=0`），`a[0]-b[2] = -1-(-1) = 0`。
- 第二次迭代（`i=1`），`a[1]-b[1] = 5-4 = 1`。
- 第三次迭代（`i=2`），`a[2]-b[0] = 7-5 = 2`。

因此，`a[0]`, `a[1]`, 和 `a[2]` 分别变为 `0`, `6`, 和 `8`。在第二个循环中，`i` 先减减 变为 `2`。条件是 `a[i] != 0`。由于 `a[0]` 是 `0`，循环终止。

```cpp
{
```

```cpp
    for(i = 0; i < SIZE; i++)
    {
        cout << "\nEnter number: ";
        cin >> arr[i];
    }

    for(i = 1; i < SIZE; i++)
    {
        if(max_1 != arr[i])
        {
            max_2 = arr[i]; /* 我们将该值赋值给 max_2，以便与剩余元素进行比较。 */
            break;
        }

    {

        return 0;
    }
    /* 从第二个循环结束的地方继续执行循环。 */
```
