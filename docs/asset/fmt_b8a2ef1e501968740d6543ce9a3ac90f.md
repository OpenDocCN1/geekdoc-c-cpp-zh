要禁用 CLR 集成功能，将`clr enabled`选项设置为 0。

SQL Server 2008 作为 CLR 的主机，为执行代码定义了一些权限级别。这些权限级别如下所示：

- `SAFE` – 仅允许本地数据访问和内部计算。`SAFE`权限是最严格的权限，不允许访问外部系统资源，例如文件、网络、环境变量或注册表。以`SAFE`权限执行代码的程序集无法访问这些外部系统资源。
- `EXTERNAL_ACCESS` – 允许访问外部系统资源，例如文件、网络、环境变量或注册表。
- `UNSAFE` – 允许从 SQL Server 无限制地访问内部和外部资源。以`UNSAFE`权限执行的程序集执行的代码也可以是未托管代码。

您可以通过在服务器中创建程序集来使用 SQL Server 2008 中的程序集。使用以下命令在 Management SQL Server Studio 中创建程序集：

接下来，让我们学习存储过程。

## 探索存储过程

存储过程是存储在数据库中的预编译 SQL 命令集。它只编译一次，然后被客户端应用程序重复使用，而无需将其发送到数据库服务器。在 SQL Server 2008 中创建存储过程的示例在列表 23.1 中给出：

### 列表 23.1：在 SQL Server 2008 中创建存储过程

```
CREATE PROCEDURE GetProductDetails

@ProductID int

AS

SELECT ProductID,ProductName,QuantityPerUnit,UnitPrice,UnitsInStock FROM Products WHERE ProductID=@ProductID
```

在列表 23.1 中，使用一个整数类型的参数创建了一个存储过程`GetProductDetails`。此存储过程根据特定的`ProductID`从`Products`表中提供项目的详细信息，包括`ProductID`、`ProductName`、`QuantityPerUnit`、`UnitPrice`和`UnitsInStock`。您可以使用以下命令执行`GetProductDetails`存储过程：

```
EXECUTE GetProductDetails 3
```

> NOTE
> 您可以通过提供除 3 之外的其他产品 ID，例如 2 和 4，来执行`GetProductDetails`存储过程。

让我们在 .NET Framework 4.0 中创建和使用触发器。

## 探索触发器

触发器是一种特殊的存储过程，当您使用一个或多个数据修改操作`UPDATE`、`INSERT`或`DELETE`修改数据库表的数据时会被触发。请注意，触发器永远不会被调用或 executed, but it is fired automatically when data is modified in the associated tables. Listing 23.2 shows an example of creating a trigger in SQL Server 2008:

### Listing 23.2: Creating a Trigger for the INSERT Operation

```
CREATE TRIGGER TestTrigger1

ON MyTable

AFTER INSERT

AS

INSERT INTO TestTable (col1) VALUES ('TestTrigger1 is fired');
```

In Listing 23.2, a trigger, `TestTrigger1`, is created on a user-defined table, `MyTable`. Whenever an `INSERT` operation is performed on the `MyTable` table, then the `TestTrigger1` trigger is fired and a text value, TestTrigger1 is fired, is inserted in another user-defined table, `TestTable`.

As a stored procedure, a trigger also consists of procedural logic, which is stored at the database level. However, a trigger is specifically attached to a table, while a stored procedure is not. In addition, a stored procedure is explicitly executed or called, while a trigger is implicitly called and can also include a stored procedure for execution.

## Exploring User-Defined Aggregate Functions

In SQL, an aggregate function is a function that performs a calculation on a set of values and returns a single computed value. It summarizes the data in a table. SQL Server provides some built-in aggregate functions, such as `SUM`, `MAX`, and `COUNT`.

Let’s consider an example of the `SUM` aggregate function. Listing 23.3 shows a query to use the `SUM` aggregate function:

### Listing 23.3: Using the SUM Aggregate Function

```
USE Northwind;

GO

SELECT EmployeeID, SUM(Freight) As 'Total freight of ordered'

FROM dbo.Orders

WHERE EmployeeID IS NOT NULL

GROUP BY EmployeeID

ORDER BY EmployeeID;

GO
```
