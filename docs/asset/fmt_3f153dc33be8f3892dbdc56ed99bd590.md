```
private void button1_Click(object sender, EventArgs e) {
    listBox1.Items.Clear();
    XPathDocument pd = new XPathDocument("authors.xml");
    XPathNavigator pn = ((IXPathNavigable)pd).CreateNavigator();
    XPathNodeIterator ni = pn.Select("/authorslist/authors[@au_id='409-56-7008']");
    while(ni.MoveNext())
    {
        XPathNodeIterator newni = ni.Current.SelectDescendants(XPathNodeType.Element, false);
        while(newni.MoveNext())
        {
            listBox1.Items.Add(newni.Current.Name + ": " + newni.Current.Value);
        }
    }
}
```

在上述代码片段中，我们创建了一个空列表框。然后，通过将XML文件（`authors.xml`）名称作为参数传递，创建了一个`XPathDocument`类的对象。注意，`authors.xml`文件已经放在项目的`bin\Debug`文件夹中，因此应用程序会自动检测到XML文件的位置。接下来，我们先将`XPathDocument`对象强制转换为`IXPathNavigable`接口，然后调用`IXPathNavigable`接口的`CreateNavigator()`方法，从而创建了一个`XPathNavigator`类的对象。

之后，通过调用`XPathNavigator`对象的`Select()`方法，创建了一个`XPathNodeIterator`类的对象。`Select()`方法返回属性`au_id`值为`409-56-7008`的所有`authors`元素。然后使用`XPathNodeIterator`对象的`MoveNext()`方法在`while`循环中遍历XML文档的节点。在循环内部，我们创建了一个`XPathNavigator`类的对象，它是当前元素的子元素。我们再次使用`XPathNodeIterator`对象的`MoveNext()`方法在另一个`while`循环中遍历XML文档的节点。在循环内部，元素的文本值被添加到列表框。

## 转换 ADO.NET 和 XML 数据

你已经了解到 ADO.NET 提供了一些强大的功能，用于读写 XML 文档。你可以通过先使用 ADO.NET 数据源填充 `DataSet` 对象，然后调用 `DataSet` 对象的 `WriteXml()` 方法来创建包含 ADO.NET 数据源数据的 XML 文件。`WriteXml()` 方法有两个重载形式，其中一个接受包含文件路径和名称的字符串，另一个多一个参数用于指定模式，该模式的值来自 `XmlWriteMode` 枚举。`XmlWriteMode` 枚举的一个值是 `DiffGram`，它指定包含编辑会话前后相关数据的 XML 文档。
