# 11.5 检验理解的答案

- 1. 使用泰勒级数作为扩展泰勒多项式的定义：
```
f(x) = sin x,    f'(x) = cos x
f(0) = 0,        f'(0) = 1
f''(x) = -sin x, f'''(x) = -cos x
f'''(0) = 0,     f^{(4)}(x) = sin x
f^{(4)}(x) = sin x, f^{(5)}(x) = cos x
f^{(4)}(0) = 0,   f^{(5)}(0) = 1
```
因此，
```
sin x = 0 + 1x - 1/2! x^2 + 1/3! x^3 - 1/4! x^4 + 1/5! x^5 - ... = x - 1/2! x^2 + 1/3! x^3 - ...
```

- 2. 对问题 1 中的泰勒级数求导：
```
n d/dx sin x = d/dx (x - 1/2! x^2 + 1/3! x^3 - ...)
cos x = 1 - 2/2! x + 3/3! x^2 - ...
```
[注：我们使用了 `3/3! = 1/2!` 和 `5/5! = 1/4!` 的事实]

- 3. 在 `cos x` 的泰勒级数中将 `x` 替换为 `7x`，然后乘以 `x^3`：
```
cos x = 1 - 1/2! (7x)^2 + 1/4! (7x)^4 - ...
cos 7x = 1 - 7^2/2! x^2 + 7^4/4! x^4 - ...
x^3 cos 7x = x^3 (1 - 7^2/2! x^2 + 7^4/4! x^4 - ...) = x^3 - 7^2/2! x^5 + 7^4/4! x^7 - ...
```

- 4. `f(x)` 的泰勒级数中 `x^2` 的系数为 `f^{(5)}(0)/5!`。根据问题 3，该系数为 `-7^2/2!`。

# 第 11 章总结

## 关键术语与概念

### 11.1 泰勒多项式
为了近似函数 `f(x)` 在点 `a` 附近的值，可以使用阶数为 `n` 的泰勒多项式 `p_n(x)`。该多项式根据 `f` 在 `a` 处的值及其导数定义：
```
p_n(x) = f(a) + f'(a)/1! (x-a) + f''(a)/2! (x-a)^2 + ... + f^{(n)}(a)/n! (x-a)^n
```
因此，对于 `a` 附近的所有 `n` 值，`p_n(x)` 都近似 `f(x)`。该多项式在 `n → ∞` 时在 `a` 处的第 `n` 阶导数与 `f(x)` 一致。

- (a) 求 `f(x) = e^x` 在 `x=0` 处的泰勒多项式。
- (b) 使用二阶泰勒多项式近似 `e^2`。

### 11.2 牛顿迭代法
近似 `f(x) = e^{2x} - 3` 的第一个根。

假设 `r` 是函数 `f(x)` 的一个零点；即 `f(r) = 0`。在许多情况下，很难找到 `r` 的精确值。牛顿迭代法是寻找任意精度 `r` 近似值的方法之一。该算法由以下公式定义：
```
x_{n+1} = x_n - f(x_n)/f'(x_n)
```
`f(x) = e^{2x} - 3` 的解有两个正解：一个在 0 和 1 之间；另一个在 2 和 3 之间。

```
x_1 = x_0 - f(x_0)/f'(x_0) = 1 - (e^2-3)/(2e^2) = 1 - (1-3e^{-2})/2 ≈ 0.3581
x_2 = x_1 - f(x_1)/f'(x_1) = 0.3581 - (e^{2(0.3581)}-3)/(2e^{2(0.3581)}) ≈ 0.3588
x_3 = x_2 - f(x_2)/f'(x_2) = 0.3588 - (e^{2(0.3588)}-3)/(2e^{2(0.3588)}) ≈ 0.3588
```
**步骤 1** 使用 `f` 的图像或通过估计，选择一个靠近 `r` 的值 `x_0`。
**步骤 2** 在牛顿迭代法中使用 `x_0` 生成值 `x_1`。
**步骤 3** 使用公式计算 `x_2`。继续直到得到一个近似序列 `x_0, x_1, x_2, ...`，该序列通常会如预期般接近 `r`。因此，近似根为 `x ≈ 0.3588`。

### 11.3 无穷级数
无穷级数 `sum_{k=1}^{∞} a_k` 的和是其部分和 `S_n = sum_{k=1}^{n} a_k` 的极限。如果序列 `{S_n}` 收敛于极限 `L`，我们说该级数收敛于 `L`；否则级数发散。

### 11.4 正项级数
级数 `sum_{k=1}^{∞} a_k`（`a_k ≥ 0`）收敛当且仅当部分和序列 `{S_n}` 有界。比较判别法指出，如果对于所有 `k` 有 `0 ≤ a_k ≤ b_k`，且 `sum b_k` 收敛，则 `sum a_k` 收敛。

### 11.5 泰勒级数
幂级数是用 `x` 的幂次表示的级数，形式为 `sum_{n=0}^{∞} c_n (x-a)^n`。函数 `f(x)` 在 `x=a` 处的泰勒级数为：
```
sum_{n=0}^{∞} f^{(n)}(a)/n! (x-a)^n
```

## 核心术语与概念

泰勒级数是一种用于在 `x=0` 附近表示 `f(x)` 的特殊级数。

在点 `x=a` 处的泰勒表示可能与 `f(0)` 不同。在这种情况下，我们有泰勒级数：
```
f(x) = f(a) + f'(a)(x-a) + f''(a)/2! (x-a)^2 + ... + f^{(k)}(a)/k! (x-a)^k + ...
```
因此，
```
e^x = f(0) + f'(0)/1! x + f''(0)/2! x^2 + f'''(0)/3! x^3 + ... = 1 + x + x^2/2! + x^3/3! + ...
```

- 2. 使用 `e^x` 的泰勒级数展开求 `f(x)=e^x` 在 `x=0` 处的泰勒级数。
解：在 `e^u` 在 `u=0` 处的泰勒级数中，
```
e^u = 1 + u + u^2/2! + u^3/3! + ...
```
代入 `u=2x` 得到
```
e^{2x} = 1 + 2x + (2x)^2/2! + (2x)^3/3! + ... = 1 + 2x + 2x^2 + 4/3 x^3 + ...
```
