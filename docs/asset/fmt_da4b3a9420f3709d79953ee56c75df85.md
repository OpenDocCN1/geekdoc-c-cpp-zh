### 示例 9 位移与路程

一枚火箭垂直射入空中。发射后 `t` 秒时的速度为 `v(t) = -32t + 160` 英/秒。

- (a) 求火箭在 `0 ≤ t ≤ 8` 间内的位移。使用 `v(t)` 图像下的面积解释这一位移。
- (b) 求火箭在 `0 ≤ t ≤ 8` 时间段内的总路程。将这一路程解释为面积。

# 解 Solution

- (a) 令 `s(t)` 表示火箭在时间 `t` 时的位置（相对于初始位置）。所需的位移是 `s(8) - s(0)`，它是 `0 ≤ t ≤ 8` 区间位置的净变化。我们有：

```
$s(8) - s(0) = \int_{0}^{8} v(t)dt = \int_{0}^{8} (-32t + 160)dt = [-16t^2 + 160t]_0^8 = (-16(8^2) + 160(8)) = 256.$
```

因此，火箭在初始位置上方 256 英。区间 `[0, 8]` 积分值等于 `t` 轴上方由 `v(t)` 图像围成的面积 `A` 减去 `t` 轴下方的面积 `B`（图 15）。
