## 3.11 本地地控制

### 3.11.1 setlocale 函数

### 概要

```
#include <locale.h>
char *setlocale(int category, const char *locale);
```

## 描述

`setlocale` 函数选择合适的程序区域。`setlocale` 函数可以根据指定的类别和 `locale` 参数更改或查询程序的区域。类别值 `LC_ALL` 指代程序的整个区域；其他值仅程序区域的某部分。`LC_COLLATE` 影响 `strcoll` 和 `strftime` 函数；`LC_CTYPE` 影响字符处理函数；`LC_MONETARY` 影响 `localconv` 函数返回的货币信息；`LC_NUMERIC` 影响小数点和字符串转换函数；`LC_TIME` 影响 `strftime` 和 `wstrftime` 函数。

`locale` 值为 "C" 指明最小环境；`locale` 值为 "native" 指明特定区域的环境。可以传递实现定义的字符串作为第二个参数。

### 返回

如果 `locale` 给的是一个字符串指针且该选择可以满足，`setlocale` 返回与新区域对应类别关联的字符串指针。如果选择无法满足，`setlocale` 返回空指针且程序区域不改变。`locale` 为空指针将导致 `setlocale` 函数返回与当前程序区域的对应类别关联的字符串指针；程序区域不改变。`setlocale` 函数返回的指针使得后续使用该字符串值及其关联类别时可以恢复程序区域的该部分。指针指向的字符串不被程序修改，但可能会被后续的 `setlocale` 调用所覆盖。

在程序启动时，执行等同于

`setlocale(LC_ALL, "C");`

调用 `setlocale` 函数可能会与其他 `setlocale` 函数的调用或对受当前区域影响的函数的调用引入数据竞态。实现的行为应表现为没有库函数调用 `setlocale` 函数。

类型为 `char *` 的结构体成员是字符串指针，其中任何一个（小数点除外）都可以指向 `""`，表示该值在当前区域化中不可用或长度为零。除了 `grouping` 和 `mon_grouping` 外，字符串应在初始移动状态开始并结束。类型为 `char` 的成员是非负数，其中任何一个可以为 `CHAR_MAX`，表示该值在当前区域化中不可用。这些成员包括：

- `char *decimal_point`

用于格式化非货币数量的小数点字符。

- `char *thousands_sep`

- `char *mon_decimal_point`

用于格式化货币数量的小数点。

- `char *mon_thousands_sep`

- `char *negative_sign`

`grouping` 和 `mon_grouping` 的元素按照以下规则解释：

- `CHAR_MAX` 不再进行任何分组。

- `0` 前一个元素将重复地用于剩余的数字。

- `other` 该整数值是组成当前组的数字位数。将检查下一个元素以确定当前组之前的下一组数字的大小。

`p_sep_by_space`、`n_sep_by_space`、`int_p_sep_by_space` 和 `int_n_sep_by_space` 的值按照以下规则解释：

- `0` 货币符号和值之间没有空格分隔。

- `1` 如果货币符号和符号字符串相邻，则用空格将它们与值隔；否则，用空格将货币符号与值隔。

- `2` 如果货币符号和符号字符串相邻，则用空格将它们隔；否则，用空格将符号字符串与值隔。

- 对于 `int_p_sep_by_space` 和 `int_n_sep_by_space`，使用 `int_curr_symbol` 的第四字符代替空格。

- `6` `p_sign_posn`、`n_sign_posn`、`int_p_sign_posn` 和 `int_n_sign_posn` 的值按照以下规则解释：

- `0` 括号包裹数量和货币符号。

- `1` 符号跟在数量和货币符号之前。

- `2` 符号跟在数量和货币符号之后。

- `3` 符号紧跟在货币符号之前。

- `4` 符号紧跟之后。
