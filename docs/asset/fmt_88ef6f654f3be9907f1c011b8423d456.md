
# Wi-Fi 与无线网络技术

Wi-Fi 是 **wireless fidelity**（无线保真）的缩写。它是今天用于所有家庭和商业网络的网络技术的通用名称，通常以其标准编号称为：`IEEE 802.11`。每当你在家里、工作场所或咖啡馆、图书馆等公共场所使用无线网络访问互联网时，你都在使用 Wi-Fi。

**Wi-Fi 无线以太网**：一种无线连接计算机和其他设备的方法。它的另一个名称法是其技术标准 `IEEE 802.11`。

> **IEEE** 是电气电子工程师学会。它发布许多不同技术的标准。`IEEE 802.11` 是管理 Wi-Fi 的标准，但也有许多其他标准。例如，`1394` 是火线（FireWire）的标准，而 `802.15` 是蓝牙的标准（尽管没有人按其标准号称呼蓝牙）。

自最初开发以来，Wi-Fi 标准一直有不同的版本。今天流行的版本是 `802.11n`，它可以在室内最高 230 英尺或室外 840 英尺的范围内传输多达 600 Mbps 的数据。一个名为 `802.11ac` 的适配器最近已获得批准；到你读到这里时，它可能已经整合到你可以购买的网络设备中。`802.11ac` 的最大吞吐量为 1.3 Gbps，表 13.1 列出了不同的 Wi-Fi 标准及其速度和距离。

### 表 13.1 Wi-Fi 标准

| 标准 | 距离（室内/室外） | 速度 |
| --- | --- | --- |
| 802.11a | 115 英尺 / 390 英尺 | 54 Mbps |
| 802.11b | 115 英尺 / 390 英尺 | 11 Mbps |
| 802.11g | 125 英尺 / 460 英尺 | 54 Mbps |
| 802.11n | 230 英尺 / 860 英尺 | 高达 600 Mbps |
| 802.11ac | 230 英尺 / 860 英尺 | 高达 1.3 Gbps |

## 蓝牙

**蓝牙**是一种廉价的短距离网络技术，用于计算机到设备的连接，例如计算机到打印机或手机到耳机。

蓝牙是一种用于连接近距离内单个设备的无线技术。它最常用于将计算机连接到输入或输出设备。例如，你可能有一个与智能手机一起使用的蓝牙耳机，或者你可能有一个与笔记本电脑一起使用的蓝牙打印机。当设备在彼此范围内并使用软件对它们进行身份验证配对时，就形成了一个**个人局域网（PAN）**。当设备不再处于彼此范围内时，PAN 就停止。蓝牙的范围限制在 20 英尺，因此对于一般的无线网络（如在家庭或办公室与计算机共享 Internet 连接）来说并不是一种实际的技术。

### 配对蓝牙设备

要通过蓝牙连接设备，必须对它们进行配对。配对可以根据设备采取不同的形式。例如，一个设备可能会生成 PIN 码，而另一个设备可能会提示你输入该 PIN 以进行确认。显然，如果两个设备只有一个可以显示 PIN 码的显示屏，当然如此。对于没有显示器的设备（如蓝牙鼠标），你将有一个按钮可以临时发现它。按下该按钮（你可能需要按几秒钟），按照设备文档中的指示使其变为可发现状态，然后在你想要配对的设备屏幕上选择它。在 Windows 中，你可以通过控制面板访问蓝牙控制功能。

![蓝牙配对示意图](img/218567e51e5dac8e3e89ffff9d77da01_479_0.png)

## 红外线技术

**红外线技术**利用光波从设备向设备“发射”信息。大约十年前，红外线是连接外围设备的首选方法，但今天蓝牙已主要取代了它。然而，红外线仍用于大多数电视遥控器和其他家庭影院组件。红外线传输的主要缺点是两点之间必须有清晰的视线。红外连接的标准是 **IrDA**（红外数据协会的缩写，即创建和管理该标准的组织）。

**红外线**：一种较旧的无线通信类型，利用光波在附近的设备之间传递简单信息。

## 微波

**微波**是高频无线电波。微波系统允许两个位置通过高频频段进行无线连接，该频段远高于 Wi-Fi 或蓝牙使用的频率。两点可以相隔数英里（达 25 英里），但只要之间没有障碍物，它们就可以交换数据。微波技术不再像卫星系统那样被广泛使用，但它仍有特殊用途，例如军事力量在不支持有线的地区。视线对于微波通信至关重要。

## 网络硬件

网络连接需要硬件和软件。软件部分由操作系统处理；所有现代操作系统都包含网络支持。然而，并非所有计算机都包含网络硬件，某些网络硬件是独立于计算机的，因此你可能会发现自己在购买网络硬件。在接下来的章节中，你将学习一些网络设备。

安装网络的技术人员处于活跃的工作环境中。大多数 IT 专业人员整天坐在桌旁，安装人员经常在建筑的天花板和地下室爬行，布设电缆并安装天线。他们在机房里设置交换机和路由器，配置网络安全设置并确保网络硬件安装正确且运行良好。在网络领域，你至少需要高中毕业学历，再加上 `CompTIA Network+` 等技术认证。要了解更多关于 Network+ 认证的信息，请访问 <http://certification.comptia.org/getCertified/certifications/network.aspx>。

### 网络适配器

**网络适配器**使计算机连接到网络的硬件组件。

每个网络客户端设备（计算机、平板电脑、打印机等）都必须有一个网络适配器。网络适配器使计算机参与局域网。大多数台式机和笔记本电脑都内置了以太网适配器，笔记本电脑几乎总是包含内置无线适配器。

**网络接口卡 (NIC)** 是位于扩展卡上而非计算机主板的网络适配器。有时非正式地指任何网络适配器。

你可以通过操作系统的设置或控制面板配置设备的网络适配器。例如，你可以在平板电脑或智能手机上开启或关闭各种无线适配器。许多人在不使用这些适配器时会选择关闭它们以节省电量。

### 逐步操作：在设备管理器中检查网络设备

不确定电脑上是否安装了网络适配器？按照以下步骤进行查找：

1. 在 Windows 中，点击“开始”菜单和“控制面板”。
2. 点击“硬件和声音”。
3. 点击“设备管理器”。设备管理器窗口将打开。
4. 点击“网络适配器”左侧的箭头展开该类别。将显示可用的网络适配器。例如，在屏幕截图中，有四个网络适配器。你可以根据它们的名称推断它们支持什么种网络。
5. 双击名称中带有“Ethernet（以太网）”字样的网络适配器。这将打开“属性”框。
6. 点击对话框中的每个选项卡以查看其设置，然后点击“取消”。
7. 关闭设备管理器窗口，并关闭控制面板窗口。

![设备管理器中的网络适配器](img/218567e51e5dac8e3e89ffff9d77da01_482_0.png)

每个网络适配器都有一个硬件地址，称为 **MAC 地址**，它在全世界范围内都是唯一的。它也被称为物理地址，它是硬编码在适配器芯片内部的，无论使用何种网络，它都不会改变。低层网络软件使用 MAC 地址来确保数据传输到正确的设备。MAC 地址与特定的网络地址是独立的，例如 **IP 地址**（在第 15 章“网络基础”中介绍）。

## 交换机和集线器

**交换机**是一个为以太网局域网（LAN）中的所有计算机提供中央汇聚点的设备。每台电脑的网络适配器都通过电缆或无线方式连接到交换机。（蓝牙和红外无线网络不使用交换机，因为它们只将单个设备相互连接，而不是设备组。）交换机管理设备之间的数据。如果一个设备想向同一网络上的另一台设备发送内容，它会将请求发送到交换机，由交换机投递到正确的目的地。图 13.9 显示了一个有线网络的交换机，它有八个端口，你可以从网络适配器连接。无线交换机被称为**无线接入点（WAP）**。

**无线接入点（WAP）**：局域网内计算机参与网络的汇聚点。

![交换机连接局域网中的计算机](img/218567e51e5dac8e3e89ffff9d77da01_483_0.png)

*图 13.9 交换机连接局域网中的计算机。*

与早期版本的交换机（**集线器**）相比，交换机的网络性能要好得多。集线器在将消息发送到正确端口时，会将流量发送到每台电脑上的所有端口，让电脑忽略任何不是发送给自己的内容。交换机的一种原始版本缺乏读取地址并将其路由到相应端口的能力。

## 路由器

**路由器**执行交换机的所有功能，但还有一个额外优点：它可以将流量引导至局域网外部或内部。例如，假设你有两组计算机，每组都连接到一个交换机，并且你希望它们能够相互通信。如果你为每组使用一个路由器，路由器将能够传输另一组的数据包。每个路由器都有一个名为“默认网关”的输出端口，允许数据离开本地网络。当数据来自互联网时，路由器将其引导到请求它的计算机。用于路由的路由器类型可以引导进入局域网的流量。

## 网关、桥和重复器

**网关**这一术语有两个含义。在软件层面，正如你在之前的课程中学习的，网关可以连接不同的网络。在硬件层面，**网桥**是连接两个不同网络的设备。**重复器**接收并重传网络信号。重复器正如其名所示——重复网络信号。

## 网络电缆

有线通信介质由多种类型的电缆组成。这里是你可能会遇到的网络电缆类型。

### 双绞电缆

**双绞电缆**是通过相互缠绕的线对传输数据以减少电磁干扰（EMI）。大多数建筑中的电缆都是双绞电缆。它的名称源于电缆内部缠绕的线对。**电磁干扰（EMI）**是指电流通过电缆时由于附近的磁场导致的数据损坏。大多数双绞电缆是**非屏蔽双绞线（UTP）**。**屏蔽**是电缆中的一种可选金属层，用于减少来自外部源的 EMI。**屏蔽双绞线（STP）**包含这种额外的外层，用于在带有荧光灯管的天花板内布设电缆的环境中。

- **非屏蔽双绞线（UTP）**：一种没有防止外部 EMI 的外层电缆。
- **屏蔽双绞线（STP）**：一种具有防止外部 EMI 的外层电缆。

有不同类型的 UTP 电缆，它们具有不同数量的线并能以不同的速度可靠地传输数据。当你将电话连接到家庭或企业的插座时，你使用的是**第 3 类（Cat3）电缆**，它包含一或两对线（用于单线或双线系统）。电话电缆是 `RJ-11`（两线）或 `RJ-14`（四线）。用于以太网网络（家庭和企业中最常见的网络类型）的电缆是 8 线**第 5 类增强型（Cat5e）**，它可以传输高达 1000 Mbps 的数据（你可能在本章前面的以太网部分记忆过，这是 `1000BaseT` 以太网的最大速度）。它具有比电话电缆更宽的连接器，称为 `RJ-45` 连接器，如图 13.11 所示。

- **第 3 类（Cat3）**：用于电话系统的 UTP 电缆类型。
- **RJ-11**：用于单线 UTP 电话电线的连接器。
- **RJ-14**：用于双线 UTP 电话电线的连接器。
- **Category 5e (Cat5e)**：用于 `1000BaseT` 以太网的 UTP 类型。
- **RJ-45**：用于为以太网设计的 UTP 电缆的连接器。

![RJ-45 连接器](img/218567e51e5dac8e3e89ffff9d77da01_485_0.png)

### 同轴电缆

**同轴电缆**是一种用于电视连接的电缆；如果你使用的是有线宽带，它就是从墙到电缆调制解调器的电缆。和双绞电缆一样，它通过电传输数据。它比双绞线更贵，但它可以传输更多数据且速度更快。同轴电缆由中心的一单根铜线组成，周围包裹着绝缘层，外面有塑料外套。

![同轴电缆结构](img/218567e51e5dac8e3e89ffff9d77da01_486_0.png)

*图 13.12 同轴电缆中心有一个实心铜芯，周围包裹着绝缘层。*

### 光纤

你目前学的电缆是通过电信号传输数据的，而**光纤**则是沿着玻璃纤维通过光脉冲传输数据（见图 13.13）。每根光纤非常细——大约只有头发丝粗细。每根电缆包含数百根光纤，每秒可以传输数十亿比特。光纤通常用作网络骨干（核心部分），用于在互联网各个点之间移动大量数据。它可靠、快速且不受电磁干扰（EMI）的影响；它也很难被嗅探或破解，使得连接非常安全。然而，光纤在消费端并未广泛使用，因为它价格昂贵且难以安装和维护。它还不兼容大多数消费级网络设备。

# 理解并连接互联网

互联网最初是作为一种让研究机构和军方共享信息的方式。然而，现在它是全球最大、使用最广泛的网络，不仅被学校和政府使用，还被每个国家、每个行业的企业、非营利组织和个人使用。你可以使用互联网查询信息、发送和接收电子邮件、即时消息、上传和下载文件等等。你将在第 14 章“在线通信”和第 15 章“网络基础”中学习更多关于互联网的。

## 互联网结构

从结构上看，互联网是由路由器和服务器在多个点相互连接形成的网格，如图 13.14 所示。这使得互联网具有很强的容错性。如果任何一个路由器或服务器发生故障，网络流量会自动绕过故障点。

![互联网网状结构](img/218567e51e5dac8e3e89ffff9d77da01_487_0.png)

*图 13.14 网状网络不依赖于任何单点的激活状态；流量可以轻松绕过任何阻塞。*

在本章开始时，你学习了分组交换网络。互联网是一个分组交换网络，这意味着每条消息都会被分成多个数据包，每个数据包都会单独发送到网络中。当数据包到达目标计算机时，它们会被打开，数据会被重新组装成原始消息。在这种描述中，`message`（消息）是一个通用术语，可以指任何发送或接收的数据，例如显示网页的请求、你在在线表单中输入的信息或你发送的电子邮件。

## 互联网速度

互联网没有固定的速度。数据通过其经过的任何电缆以最快速度在互联网上传输，单个数据包在它的旅程的不同阶段可能会以不同的速度传输。互联网的核心是高容量、高速的数据通道，它们就像是数据的超级公路。这些通道形成了互联网的**骨干网**。**骨干网**主要由光纤组成，可以传输非常快的数据——达到光速！大型互联网服务提供商（ISP）拥有整层楼的服务器，这些服务器通过该骨干直接连接到互联网。从 ISP 到各个社区和企业，连接速度较低，因为这些地方使用的廉价铜质电缆传输数据的速率较低。某些 ISP 对不同的互联网连接速度收取不同的费用，并会对注册了较慢连接的客户限制连接速度（通常在宽带解调器处）。

**骨干网**：网络的核心连接路径，那里的连接速度很快，数据路径很宽。

你订阅的互联网服务有两个速度，都以每秒兆比特（Mbps）为单位。第一个是理论最大速度，这是你的 ISP 告诉你在理想条件下提供的速度。第二个是你的实际速度，会更低。

影响实际性能速度的因素包括：

- **互联网流量**：在一天中的高峰时，使用互联网的人较多，整体速度可能会变慢。
- **本地流量**：如果你是有线宽带，由于共享带宽（例如在家里同时播放多部电影），你的连接性能可能会受到影响。
