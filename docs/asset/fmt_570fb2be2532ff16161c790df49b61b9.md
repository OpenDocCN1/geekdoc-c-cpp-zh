## 10.6 继承

在这里，我们将介绍通过继承和虚方法支持多态的 C++ 编程语言特性。多态是指为同一个名称分配多个含义的能力。这是面向对象编程中的重要概念；它允许许多不同类型的对象赋值给单一类型的对象。因此，单一类型可以有多个含义。

继承提供了一种代码重用的机制。在 C++ 中，一个类可以继承另一个类的属性和方法。继承的类被称为派生类，被继承的类被称为基类。
