## 集合和泛型中的新增内容？

在 .NET Framework 4.0 中，在集合中引入了一个名为 `System.Collections.Concurrent` 的新命名空间，并在泛型中引入了一个名为 `SortedSet<T>` 的类。

`System.Collections.Concurrent` 命名空间提供了多个线程安全的集合类。当多个线程并发访问集合时，应使用这些类代替 `System.Collections` 和 `System.Collections.Generic` 命名空间中的相应类型。表 32.29 列出了 `System.Collections.Concurrent` 命名空间的重要类：

### 表 32.29：`System.Collections.Concurrent` 命名空间的重要类

| `BlockingCollection<T>` | 为线程安全集合提供阻塞和有界等功能 |
| `ConcurrentBag<T>` | 表示线程安全、无序的对象集合 |
| `ConcurrentDictionary<TKey, TValue>` | 表示可由多个线程并发访问的线程安全键值对集合。 |
| `ConcurrentQueue<T>` | 表示线程安全先进先出 FIFO 集合。 |
| `ConcurrentStack<T>` | 表示线程安全后进先出 LIFO 集合。 |
| `OrderablePartitioner<TSource>` | 表示将可排序数据源拆分为多个分区的一种特定方式。 |

| `Partitioner<TSource>` | 表示将数据源拆分为多个分区的一种特定方式。 |
