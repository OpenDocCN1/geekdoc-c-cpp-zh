# 条件编译

条件编译可以根据某些条件来包含文件或宏。这对于根据计算机使用的不同平台/硬件来定义参数非常有用。其格式如下：

```
#ifdef SAMPLE
<statement block 1>
#else
<statement block 2>
#endif
```

在 `#ifdef` 和 `#else` 之间的 `<statement block 1>` 只有在宏 `SAMPLE` 被定义时才会被编译，否则 `#else` 和 `#endif` 之间的 `<statement block 2>` 将被编译。

示例

```
#define MAXIMUM
#ifdef MAXIMUM
#define M 10
#define N 10
#else
#define M 3
#define N 3
#endif
```

当定义了 `MAXIMUM` 时，`M` 和 `N` 被赋值为 `10`，否则 `M` 和 `N` 被赋值为 `3`。
