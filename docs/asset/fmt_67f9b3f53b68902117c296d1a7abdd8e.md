当 WCF 服务托管在 IIS 中时，它会自动集成到 ASP.NET 中。这使您能够使用 ASP.NET 的固有功能，例如进程回收、空闲时间管理、健康监控和激活。让我们执行以下步骤在 IIS 中托管 WCF 服务：

[OperationContract]
double CalSimpleInterest(double p, double r, double t);
