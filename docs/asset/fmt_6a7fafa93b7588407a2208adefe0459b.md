
## 任务 6：为 OrderBy 语句构建 lambda 表达式

### 1. 定位任务
在任务列表中，找到 `BuildLambdaExpressionForOrderBy` 任务中的 `TODO - Create the type reference and ParameterExpression`，并双击该任务。该任务位于 `BuildLambdaExpressionForOrderBy` 方法中。

该方法的目的是构造一个指定数据检索顺序的表达式。此方法的参数是来自 `OrderByKey` 枚举的值。该枚举作为应用程序的一部分定义，包含以下值：`ByDate`、`ByTemperature`、`AppliedStress`、`ByDeflection` 和 `None`。下面的代码示例显示了该方法生成的 lambda 表达式的格式：

`item => item.Property`

在此示例中，`Property` 引用 `TestResult` 类型中对应于传递给方法的属性。如果用户没有指定排序键，此方法将返回 `null` 值。

### 2. 创建类型引用和 ParameterExpression
删除 `BuildLambdaExpressionForOrderBy` 方法中的 `TODO - Create the type reference and ParameterExpression` 注释，然后向方法添加代码，通过执行以下任务创建定义 lambda 表达式参数的 `ParameterExpression` 对象：

> **注意**：你需要创建一个指向 `TestResult` 对象的类型引用，且 lambda 表达式应该引用对象 `item`。

- 使用 `typeof` 操作符并传递 `TestResult` 对象作为参数创建一个名为 `testResultType` 的类型引用。
- 使用静态 `Expressions.Expression.Parameter` 方法创建一个名为 `itemBeingQueried` 的 `ParameterExpression` 对象。为该方法指定 `testResultType` 和一个包含文本 "item" 的字符串。

你的代码应该类似于下面的代码示例：

```cs
Expressions.Expression<Func<TestResult, ValueType>> BuildLambdaExpressionForOrderBy(OrderByKey orderKey)
{
    if (orderKey != OrderByKey.None)
    {
        // 创建定义 lambda 表达式参数的表达式。
        // 类型是 TestResult；lambda 表达式通过名称 "item" 引用它。
        Type testResultType = typeof(TestResult);
        Expressions.ParameterExpression itemBeingQueried =
            Expressions.Expression.Parameter(testResultType, "item");
        ...
    }
```


### 4. 评估 orderByKey 参数以确定属性
替换 `TODO - Evaluate the orderByKey parameter to determine the property` 注释以评估 `orderByKey` 参数。使用 `testResultType` 的 `GetProperty` 方法生成从指定项属性属性。下表列出了要使用的属性。

| orderKey 值 | testResult 属性 |
| --- | --- |
| ByDate | "Date" |
| ByTemperature | "Temperature" |
| AppliedStress | "AppliedStress" |
| ByDeflection | "Deflection" |

> **注意**：在 `BuildLambdaExpressionForOrderBy` 方法开头，一个条件语句防止在 `orderByKey` 参数值为 `OrderByKey.None` 时执行此代码；因此你不需要检查此值。

你的代码应该类似于下面的代码示例：

```cs

        // 如果用户选择了应力列，将属性对象设置为 AppliedStress。

        break;

        // 如果用户选择了挠度列，将属性对象设置为 Deflection。
        property = testResultType.GetProperty("Deflection");
        break;
```

### 7. 创建 OrderBy lambda 表达式

你的代码应该类似于下面的代码示例：

```cs

{
```
