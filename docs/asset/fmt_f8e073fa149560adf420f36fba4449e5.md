### 语法

```

  postfix-expression
  ++ unary-expression
  -- unary-expression
  unary-operator cast-expression
```

`unary-operator`: 属于

`&` `*` `+` `~` `!`

### 6.5.3.1 前缀加/减运算符

### 约束

前缀加运算符或减运算符的操作数应具有原子的、限定的或未限定的实型或指针类型，且应是一个可修改的左值（lvalue）。

### 语义

`++` 运算符的操作数的值加1。结果是操作数加1后的新值。表达式 `++E` 等于 `(E=1)`。有关加法运算符和复合赋值的讨论中包含了关于约束、类型、副作用、转换以及操作对指针的影响等信息。

前缀 `--` 运算符与前缀 `++` 运算符类似，不同在于操作数的值减1。

后引用：加法运算符 (`6.5.6`)，复合赋值 (`6.5.16.2`)。

### 6.5.3.2 地址和间接运算符

### 约束

`&` 运算符的操作数应是函数标识符、`[]` 运算符或一元运算符的结果，或者是一个指向对象的左值，该对象不是位域且未使用 `register` 存储类说明符声明。

`*` 运算符的操作数应具有指针类型。

### 语义

一元 `&` 运算符产生其操作数的地址。如果操作数的类型为“type”，则结果类型为“指向 type 的指针”。如果操作数是一元 `*` 运算符的结果，则该运算符和 `&` 都不被求值，结果就像两者都被省略一样，但对操作数的约束仍然适用，且结果不是一个初始值（ivalue）。同样，如果操作数是 `[]` 运算符的结果，则该运算符和一元 `*` 都不被求值，结果相当于删除了 `&` 运算符并将 `[]` 运算符改为 `+` 运算符。否则，结果是指向其操作数所指示的对象或函数的指针。

一元 `*` 运算符表示间接。如果操作数指向一个对象，则结果是指示该对象的左值。如果操作数的类型为“指向 type 的指针”，则结果类型为“type”。如果给指针分配了无效值，则一元 `*` 运算符的行为是未定义的^{102}

后引用：存储类说明符 (`6.7.1`)，结构和联合说明符 (`6.7.2.1`)。

### 6.5.3.3 一元算术运算符

### 约束

一元 `+` 或 `-` 运算符的操作数应具有算术类型；`~` 运算符具有整数类型；`!` 运算符具有标量类型。

### 语义

一元 `+` 运算符的结果是其（提升后的）操作数的值。整数提升在操作数上进行，结果具有提升后的类型。

一元 `-` 运算符的结果是其（提升后的）操作数的负值。整数提升在操作数上进行，结果具有提升后的类型。

`~` 运算符的结果是其（提升后的）操作数的按位取反（即结果中的每个位被置为 1，当且仅当转换后的操作数对应的位未被置位时）。整数提升在操作数上进行，结果具有提升后的类型。如果提升后的类型是无符号类型，表达式 `~E` 等于该类型中可表示的最大值减 `E`。

逻辑取反运算符 `!` 的结果：如果操作数的值不等于0，结果为 0；如果操作数的值等于0，结果为 1。结果类型为 `int`。表达式 `!E` 等于 `(0==E)`。

> 102) 因此，`*GE` 等于 `E`（即使 `E` 是空指针），且 `&E[E2]` 等于 `(E1)+(E2)`。`E` 始终是一个函数标识符或一元运算符的左值，`*GE` 是一个等于 `E` 的左值。`(T) P` 是一个与 `T` 兼容的左值。

解引用指针的无效值包括：空指针、与指向的对象类型未对齐的地址，以及对象生命周期结束后的地址。

### 6.5.3.4 sizeof 和 Alignof 运算符

### 约束

`sizeof` 运算符不应用于函数类型。`_Alignof` 运算符不应用于不类型。

### 语义

`sizeof` 运算符产生操作数的大小（字节数）。如果操作数是数组类型，结果是数组中元素的个数。如果操作数是变长数组，结果是实现定义的。如果操作数是函数类型，结果是未定义的。

`_Alignof` 运算符产生操作数的对齐要求。如果操作数是数组类型，结果是每个元素的对齐要求。如果操作数是变长数组，结果是实现定义的。如果操作数是函数类型，结果是未定义的。

## 6.5.4 运算符

### 语法

```
cast-expression:
  unary-expression
  ( type-name ) cast-expression
```

### 约束

除非类型名指定 `void` 类型，否则类型名应指定原子的、限定的或未限定的标量类型，且操作数应具有标量类型。

涉及指针的转换（`6.5.16.1` 约束允许的除）应通过显式转换指定。

指针类型不转换为任何浮点类型。浮点类型不转换为任何指针类型。

### 语义

在表达式前加上带括号的类型名会将表达式的值转换为指定的类型。这种构造称为强制转换¹104) 未指定转换的强制转换对表达式的类型或值没有影响。

如果表达式的值具有比强制转换指定的类型所需的更大的范围或精度（`6.3.1.8`），那么当表达式的类型与指定的类型相同时，强制转换指定了一种转换并移除了多余的范围和精度。

> 104) 强制转换不产生值。因此，转换为限定类型的强制转换与转换为该类型的未限定版本的效果相同。

## 6.5.5 乘法运算符

### 语法
```
multiplicative-expression:
cast-expression
multiplicative-expression * cast-expression
multiplicative-expression / cast-expression
multiplicative-expression % cast-expression
```

### 约束

每个操作数都应具有算术类型。`%` 运算符的操作数应具有整数类型。

### 语义

对操作数执行通常的算术转换。

二元运算符 `*` 的结果是操作数的乘积。

`/` 运算符的结果是第一个操作数除以第二个操作数的商；`%` 运算符的结果是余数。在这两种操作中，如果第二个操作数的值为零，则行为是未定义的。

当对整数进行除法时，`/` 运算符的结果是代数商，并舍弃任何小数部分.¹105} 如果商 `a/b` 是可表示的，则表达式 `(a/b)*b + a%b` 应等于 `a`；否则，`a/b` 和 `a%b` 的行为都是未定义的。

## 6.5.6 加法运算符

### 语法
```
additive-expression:
multiplicative-expression + multiplicative-expression
additive-expression - multiplicative-expression
```

### 约束

对于加法，两个操作数都应具有算术类型，或者一个操作数是指向完整对象类型的指针，另一个具有整数类型。（递增等同于加 1。）

对于减法，应满足以下条件之一：

- 两个操作数都具有算术类型；
- 两个操作数都是指向完整对象类型的限定或未限定版本的指针；或
- 左操作数是指向完整对象类型的指针，右操作数具有整数类型。

（递减等同于减 1。）

### 语义

如果两个操作数都具有算术类型，则对它们执行通常的算术转换。

二元运算符 `+` 的结果是操作数的和。

二元运算符 `–` 的结果是从第一个操作数减去第二个操作数得到的差。

对于这些运算符而言，指向不是数组元素的对象的指针的行为与指向长度为一的数组第一个元素的指针相同，该对象的类型即为数组的元素类型。

当表达式具有整数类型时，结果的类型为指针操作数的类型。如果指针操作数指向数组对象的元素，且数组足够大，则结果指向一个相对于原元素的偏移元素，使得结果元素和原始数组元素的下标之差等于该整数表达式。换句话说，如果表达式 `P` 指向数组对象的第 `i` 个元素，则表达式 `(P)+N`（等同于 `N+(P)`）和 `(P)-N`（其中 `N` 的值为 `n`）分别指向数组对象的第 `i+n` 个和第 `i-n` 个元素，前提是它们存在。此外，如果表达式 `P` 指向数组对象的最后一个元素，表达式 `(P)+1` 指向数组对象的最后一个元素；如果表达式 `Q` 指向数组对象的最后一个元素，表达式 `(Q)-1` 指向最后一个元素。如果指针操作数和结果指向同一个数组对象的元素，或者指向该对象最后一个元素之后，则求值不应产生溢出；否则，行为是未定义的。如果结果指向数组对象的最后一个元素之后，则不应被用作求值的一元 `*` 运算符的操作数。

当对指针进行减法时，两者都指向同一个数组对象的元素，或者指向该对象最后一个元素之后；结果是两个数组元素下标之差。结果的大小由实现定义，其类型（一种有符号整数类型）是 `<stddef.h>` 头文件中定义的 `ptrdiff_t`。如果结果在该类型的对象中不可表示，则行为是未定义的。换句话说，如果表达式 `P` 和 `Q` 分别指向数组对象的第 `i` 个和第 `j` 个元素，则表达式 `(P)–(Q)` 的值为 `i–j`，前提是该值在 `ptrdiff_t` 类型的 `int` 范围内。此外，如果表达式 `P` 指向数组对象的元素或其最后一个元素之后，且表达式 `Q` 指向同一个数组对象的最后一个元素，则 `((Q)+1)-(P)` 的值与 `-((Q)-(P)-((Q)+1))` 相同；如果表达式 `P` 越过了数组对象的最后一个元素，则该值为零，即使表达式 `(Q)+1)` 并没有指向数组对象的元素。106
