
输入两个浮点值：`5 4.8`
z 的值为：`9`

> **记忆提示**
> 当将一种类型转换为另一种数据类型时，最好将低数据类型转换为高数据类型，因为可以避免数据值的丢失。
> 当高数据类型转换为低数据类型时，数据会被截断。

## 5.4 优先级与求值顺序

当算术表达式没有括号时，它从左到右进行求值。

### 算术表达式演变步骤

1. 在第一轮中找到最高优先级并优先计算第一个。
2. 在第二轮中找到最低优先级并对其进行求值。

算术运算符有两个优先级级别。它们是：

| 表格 5.5 运算符优先级 |
| :--- |
| 最高优先级运算符：`*` `/` `%` |
| 最低优先级运算符：`+` `-` |

示例：

**第 1 轮：**

问：`X = 8 - 6 / 2 + 5 * 2 - 1`

**第 1 步：**
问：`X = 8 - 6 / 2 + 5 * 2 - 1`
从左到右查看表达式。由于在第一轮中的目标是找到优先级最高的运算符，即其中有两个运算符，即 `/` 和 `*`。由于这两个运算符的优先级相等，所以先出现的先被求值，即 `/` 运算符将先求值。
答：`X = 8 - 3 + 5 * 2 - 1`

**第 2 步：**
问：`X = 8 - 3 + 5 * 2 - 1`
答：`X = 9 - 3 + 10 - 1`

**第 2 轮：**

问：`X = 9 - 3 + 10 - 1`

**第 3 步：**
问：`X = 9 - 3 + 10 - 1`
答：`X = 6 + 10 - 1`

**第 4 步：**
问：`X = 6 + 10 - 1`
答：`X = 16 - 1`

**第 5 步：**
问：`X = 16 - 1`
答：`X = 15` (最终结果)

## 总结

1. 运算符是执行算术和逻辑操作的符号。
2. 运算符有不同类型，例如：算术、赋值、增/减、关系、逻辑、条件和特殊运算符。
3. 类型转换是指将一种数据类型临时转换为另一种数据类型。
4. 类型转换有两种类型：
   - (a) 隐式类型转换
   - (b) 显式类型转换
5. 隐式类型转换自动地将一种类型转换为另一种类型。
6. 显式类型转换强制地将一种类型转换为另一种类型。

# C语言中的输入和输出操作

## 6.1 引言

在编写一个完整的计算机程序时，需要三种基本操作。它们是读取数据（将数据作为输入）、处理数据以及写入数据（显示数据）。通常，在编写任何计算机程序时，数据都是通过键盘输入并显示在计算机屏幕上的。正如我们所见，在编程概念中，使用了两种重要的技术来为程序的变量提供数据。第一种是给变量赋值，第二种是使用 `scanf()`，它可以从键盘获取数据。对于显示输出，则使用 `printf()` 函数。

C 程序在语法中没有包含任何内置的输入或输出语句。因此，输入输出操作是通过使用 `scanf()` 和 `printf()` 函数完成的。有许多用于输入输出操作的函数被称为标准输入/输出库函数。这些函数是由编译器预定义的。如果程序员想使用标准 I/O 库的任何函数，他应该通过包含头文件 `stdio.h` 来实现，即必须包含 `#include <stdio.h>`。

在本章中，我们将展示不同的不随任何机器而改变的不同的 I/O 函数。

## 6.2 读取单个字符

`getchar()` 函数用于读取单个字符。该函数是 `scanf()` 函数的替代方案。

```c
/* 使用 scanf() 函数读取字符的示例 */
#include <stdio.h>

void main(void) {
    char m;
    printf("Search you\n");
    printf("if type in keyboard :");
    scanf("%c", &m);
    if (m == 'X')
        printf("Search Name");
    else
        printf("your name not find");
}
```

输出：
Search you
If type in keyboard: XSearch Name

使用 `getchar()` 函数读取字符的语法是 `变量 = getchar();`。在上面的声明中，`getchar()` 函数仅通过键盘读取单个字符作为输入，并将其赋值给变量。

示例：

```c
char ch;
ch = getchar();
```

```c
/* 使用 getchar() 函数读取字符的示例 */
#include <stdio.h>

void main(void) {
    char m;
    printf("Search you\n");
    printf("if type in keyboard :");
    m = getchar();
    if (m == 'X')
        printf("Search Name");
    else
        printf("your name not find");
}
```

输出：
Search you
If type in keyboard: XSearch Name

## 6.3 写入/显示单个字符

`putchar()` 是一个用于写入字符或在计算机屏幕上显示单个字符的函数。它是 `printf` 函数的替代方案。显示字符的语法是：`putchar(变量);`，其中变量是一个包含字符的字符。

```c
/* 使用 printf() 显示字符 */
#include <stdio.h>

void main(void) {
    char x;
    printf("Input a character:");
    scanf("%c", &x); /* 读取一个字符 */
    printf("The inputted character is:%c", x); /* 写入一个字符 */
}
```

输出：
Input a character:x
The inputted character is:x

```c
/* 使用 putchar() 显示字符 */
#include <stdio.h>

void main(void) {
    char x;
    printf("Input a character:");
    scanf("%c", &x); /* 读取字符 */
    printf("The inputted character is:");
    putchar(x); /* 写入字符 */
}
```

输出：
Input a character:
The inputted character is:
