### 10.2.2 typedef 和其他类型

## 11.1.3 指针减法

你可以从一个指针中减去一个值来获取更早的地址，就像我们之前对它们进行加法一样。

但我们可以减去两个指针来找到它们之间的差，例如，我们可以计算同一个数组内两个 `int*` 之间有多少个 `int`——如果指针指向任何无关的地方，将得到未定义行为。

记得 C 语言中的字符串是 `char*` 吗？让我们看看能否编写另一个 `strlen()` 的变体，利用指针减法来计算字符串的长度。

思路是，如果我们有一个指向字符串开头的指针，可以通过向前扫描 NUL 字符找到指向字符串结尾的指针。

如果我们有一个指向字符串开头的指针，并且计算出了字符串结尾的指针，我们只需要将两个指针相减即可得到长度！

#include <stdio.h>

```
int my_strlen(char *s)
{
    // 从字符串开始扫描
    char *p = s;

    // 直到找到 NUL 字符
    while (*p != '\0')
        p++;

    // 返回指针之间的差
    return p - s;
}
```

```
int main(void)
{
    printf("%d\n", my_strlen("Hello, world!")); // 打印 "13"
}
```

记住，你只能在指向同一个数组的指针之间使用指针减法。

> 或者字符串，它本质上是一个字符数组。有些奇怪的是，你也可以毫无问题地引用数组某部分的指针，并对其进行数学运算。当它在外面时，你无法对其求差值。

## 11.2 数组/指针等价性

我们终于准备好讨论这个了！我们已经看到了很多混合数组表示法的例子，但让我们来看数组/指针等价的基本公式：

```
a[b] == (a + b)
```

仔细研究它！这些等号是可以互换的！

我把它过度简化了，因为通过过度使用示例，`a` 和 `b` 都可能可能是表达式，在表达式复杂的情况下，我们可能需要更多的括号来强制执行操作顺序。

规范一如既往地是具体的，规定道（在 C1 §6.5.2.1）：

```
E1[2] 等同于 (*((E1)+2))
```

但如果表达式很复杂，这很难让你加括号，以确保你的所有路径都是正确的。

这意味着我们可以决定使用数组表示法还是指针表示法来处理数组或指针（假设它指向数组的某个元素）。

让我们同时使用数组和指针表示法来处理数组和指针：

```
#include <stdio.h>

int main(void) {
    int a[] = {11, 22, 33, 44, 55};

    int *p = a; // p 指向 a 的第一个元素 11

    // 使用多种方式打印数组 a 的元素：

    for (int i = 0; i < 5; i++)
        printf("%d\n", a[i]); // 使用 a 的数组表示法

    for (int i = 0; i < 5; i++)
        printf("%d\n", p[i]); // 使用 p 的数组表示法

    for (int i = 0; i < 5; i++)
        printf("%d\n", (a + i)); // 使用 a 的指针表示法

    for (int i = 0; i < 5; i++)
        printf("%d\n", (*p + i)); // 使用 p 的指针表示法
}
```

你可以看到通常如果你有一个数组变量，可以使用指针或数组表示法来访问元素。指针变量也是如此。一个很大的区别是，你可以修改指针指向不同的地址，但你不能对数组这样做。

### 11.2.1 函数调用中的数组/指针等价性


这意味着你可以将数组或指针传递给这个函数并使其正常工作！

## 11.3 void 指针

你已经见过在函数中使用的这个关键字，但这个完全无关。有时，拥有一个指向你未知类型对象的指针是有用的。请听我解释一会。这种情况基本上有两种情况：

- 函数将对某些字节进行操作。例如，`memcpy()` 从一个指针拷贝内存字节到另一个指针，但这些指针可以利用通过 `void*` 迭代的特性，无论其类型是什么。

- 另一个函数正在调用回调并传递数据。你知道数据的类型，但函数不知道。所以它传递了 `void*`——然后将其转换为你需要的类型。

内置的 `qsort()` 和 `bsearch()` 使用这种技术：`memcpy()` 从地址 `s1` 开始拷贝 `n` 字节内存到从地址 `s2` 开始的内存中。例如，我们用 `memcpy` 拷贝字符串（尽管 `strcpy()` 对于字符串更合适）：

```
#include <stdio.h>
#include <string.h>

int main(void)
{
  char s[] = "Goats!";
  char t[100];

  memcpy(t, s, 7); // 拷贝7个字节包括NUL终止符

  printf("%s\n", t); // "Goats!"
}
```

或者我们可以拷贝整数：

```
#include <stdio.h>
#include <string.h>

int main() {
    int a[] = {11, 22, 33};
    int b[3];

    memcpy(b, a, 3 * sizeof(int)); // 拷贝3个整数的字节

    printf("%d %d %d\n", b[0], b[1], b[2]); // 11 22 33
}
```

这很疯狂，对吧？

当我们运行它时，首先 `p` 指向 11。然后我们增加 `p`，它指向 22，然后再次，它指向 33。依此类推，它一直计数到 999 然后我们停止。

它也是一种解引用。

如果你仔细想想，这些规则是有道理的。所有这些操作都依赖于知道所指向的数据的大小，而对于 `void*`，我们并不知道指向的数据有多大——它可能是任何类型！

等一下——如果你不能对 `void*` 进行解引用，它对你还有什么用呢？

就像 `memcpy()` 一样，它可以帮助你编写可以处理多种类型数据的通用函数。但秘密在于，在深层，在使用之前，你会先将 `void*` 转换为另一种类型！

赋值也很简单：你只需要将其赋值给目标类型的变量即可。

```c
char a = 'X'; // 单个字符
void *p = &a; // p 指向 'X'
char *q = p; // q 也指向 'X'
```

```c
printf("%s\n", p); // 错误-无法对 void* 进行解引用
printf("%s\n", q); // 打印 "X"
```

让我们写一个自己的 `memcpy()` 来尝试一下。我们可以复制字节（char），并且知道字节数，因为它是传递进来的。

```c
void *my_memcpy(void *dest, void *src, int byte_count) {
    char *s = src, *d = dest;

    // 现在我们有了 char*s，可以对其进行解引用并复制
    while (byte_count--) {
        *d++ = *s++;
    }
    // 大多数这类函数都会返回目标地址，以万一
    // 对调用者有用。
}
```

就在开头，我们将 `void*` 拷贝到 `char*s`，这样我们就可以像使用 `char*` 一样使用它们。很简单。

然后在 `while` 循环中，我们递减 `byte_count` 直到它变为 (0)。记住，使用后自增时，表达式的值先被计算（供 `while` 使用），然后变量才递减。

在复制操作中，我们赋值 `*d = *s;` 来复制字节，但我们使用了后自增，这样在赋值完成后 `d` 和 `s` 都会移动到下一个字节。

最后，大多数内存和字符串函数都会返回目标指针的副本，以防调用者想要使用它。
