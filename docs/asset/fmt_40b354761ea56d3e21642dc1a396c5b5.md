
**注意**

`<bindings>`和`<behaviors>`元素是可选的。

WCF的`web.config`文件包含以下元素：

- `<Service>`
- `<endpoints>`
- `<binding>`
- `<behaviors>`

让我们详细讨论这些元素。

## `<service>`元素

`<service>`元素包含应用程序托管的所有服务的规范。它由以下两个属性组成：

- `name`——指示提供服务协定实现的类型。它是命名空间和类型名称的组合。
- `behaviorConfiguration`——指示`<behaviors>`元素中找到的某个`<behavior>`元素的名称。

## `<endpoint>`元素

`<endpoint>`元素包含以下属性：

- `address`——指示服务的URI，可以是绝对地址或相对地址。
- `Binding`——指示系统提供的绑定，例如`WSDualHttpBinding`，但也可以指定用户定义的绑定。指定的绑定决定使用的传输协议、安全性和编码格式。
- `bindingConfiguration`——包含一个字符串，表示绑定的绑定名称，在创建终结点实例时使用。
- `Contract`——通过`<service>`元素的`name`属性指示描述协定的接口。

## `<bindings>`元素

`<bindings>`元素包含任何服务中定义的终结点可以使用的所有绑定的规范。它包含一个或多个具有`name`属性的`<binding>`元素。该属性将绑定与`<endpoint>`元素的`bindingConfiguration`属性中指定的终结点关联起来。

## `<behaviors>`元素

`<behaviors>`元素充当一个或多个`<behavior>`元素的容器元素，这些元素描述服务的行为。每个`<behavior>`元素包含一个`name`属性，该属性定义系统提供的行为或自定义行为。

## 使用WCF配置编辑器工具

WCF配置编辑器工具名为`Microsoft Service Configuration Editor`，允许你创建或修改WCF服务的配置设置。它是一个图形工具，可用于管理WCF绑定、行为和服务设置。与手动修改配置文件相比，使用`Microsoft Service Configuration Editor`修改或设置WCF服务的配置信息可以节省大量时间。`Microsoft Service Configuration Editor`工具的界面如图19.6所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1009_0.png)

图19.6：展示`Microsoft Service Configuration Editor`工具

如图 19.6 所示，`Microsoft Service Configuration Editor`工具由三个窗格组成：`Configuration`、`Services`和`Tasks`。在`Configuration`窗格内，你可以找到以下六个节点：

- `Services` – 包含配置文件中当前显示的所有服务的信息。
- `Client` – 包含配置文件的客户端端点指定的信息。
- `Bindings` – 包含用于配置端点绑定的绑定信息。此节点显示配置文件中指定的所有绑定设置。
- `Standard Endpoints` – 包含可与服务一起使用的预定义端点列表。
- `Diagnostics` – 包含配置文件中指定的所有诊断设置的信息。使用此节点，你可以执行各种任务，例如打开或关闭性能计数器、启用或禁用 Windows Management Instrumentation (`WMI`)，以及配置 WCF 跟踪和消息日志记录。
- `Advanced` – 包含端点行为（由端点使用）、服务行为（由服务使用）、扩展（以名称/类型对形式存在，其中名称定义扩展的名称，类型实现扩展）以及托管环境的信息。

## WCF Clients

WCF 客户端，也称为 WCF 消费者，由一个代理组成，使应用程序能够与 WCF 服务通信。要为 WCF 服务创建客户端应用程序，首先需要获取服务契约、绑定和端点地址。获取这些信息后，你可以创建 WCF 客户端，调用 WCF 服务的操作，然后最后关闭客户端对象。

你将在本章的 Immediate Solutions 部分后面学习如何创建 WCF 客户端。

## WCF Service Identity

WCF 服务标识是在设计时从 WSDL 为服务生成的值。此值会传输给客户端，客户端在调用其任何操作之前使用它来验证 WCF 服务。另一方面，WCF 服务在允许访问其操作之前也会验证客户端的凭据。服务标识由`EndpointAddress`类的`identity`属性表示。你可以使用 Service Model Metadata Utility 工具 (`Svcutil.exe`) 获取服务标识。通过此工具，会自动为 WCF 服务生成一个配置文件，其中包含服务 `identity` 属性的值。表 19.5 显示了每种标识类型及其描述：

| Table 19.5: Showing the WCF Service Identity |
|---|---| 
| Identity type | Description |
| Domain Name System (DNS) | Compares DNS specified in the credential of the WCF service with the value specified in the identity element |
| Certificate | Compares a Base64-encoded X.509 certificate value with a client |
| Certificate Reference | Enables you to specify a certificate name and location from where to retrieve the certificate |
| Rivest, Shamir and Adleman (RSA) | Specifies an RSA key value to compare with a client |
| User Principal Name (UPN) | Specifies the UPN under which a service is running |
| Service Principal Name (SPN) | Specifies the SPN associated with the service's account |

### Creating a Service Contract and Defining the Operations

服务契约定义了服务可以执行的操作。`ServiceContractAttribute` 属性用于接口或类来定义服务契约。服务提供的 方法通过 `OperationContractAttribute` 属性定义。在 WCF 服务应用程序中，会自动创建一个名为 `IService.cs` 的文件，其中包含名为 `IService` 的服务契约。用 Listing 19.5 中给出的代码替换 `IService` 服务契约的代码以创建服务契约：

Listing 19.5: Showing the Code of the `IService.cs` File

```
[ServiceContract]

public interface IService {

    [OperationContract]

    double SquareRoot(double Number);

    [OperationContract]

```

```
double CubeRoot(double Number1);

// TODO: Add your service operations here

}
```

在 Listing 19.5 中，服务提供的 方法，例如 `SquareRoot` 和 `CubeRoot`，是使用 `OperationContractAttribute` 属性定义的。

### Implementing the Service Contract

实现服务契约的类称为服务类型。`MyFirstWCFService` 应用程序包含一个名为 `Service.cs` 的文件。在 `Service.cs` 文件中，一个名为 `Service` 的类实现了在 `IService` 接口中定义的服务契约。`IService` 接口中用 `OperationContractAttribute` 属性定义的所有 方法都在 `Service` 类中实现，如 Listing 19.6 所示：

Listing 19.6: Showing the Code of the `Service.cs` File

```
using System;

using System.Collections.Generic;

using System.Linq;

using System.Runtime.Serialization;

using System.ServiceModel;

using System.Text;

public class Service : IService {

public double SquareRoot(double Number1) {

    double Output = Number1 * Number1;

    return Output;

}

public double CubeRoot(double Number1) {

    double Output = Number1 * Number1 * Number1;

    return Output;

}

}
```
