## 任务 4：添加填充队列的方法

在构造函数下方，添加一个名为 `Populate` 的私有方法。该方法接受一个名为 `enumData` 的 `Queue<TItem>` 参数和一个名为 `tree` 的 `Tree<TItem>` 参数。它不应返回值。在方法中添加代码执行以下操作：

1. 如果参数 `tree` 的 `LeftTree` 属性不为 `null`，则递归调用 `Populate` 方法，将 `enumData` 参数和 `tree.LeftTree` 属性作为参数传递给方法。
2. 将参数 `tree` 的 `NodeData` 属性值加入 `enumData` 队列。
3. 如果参数 `tree` 的 `RightTree` 属性不为 `null`，则递归调用 `Populate` 方法，将 `enumData` 参数和 `tree.RightTree` 属性作为参数传递给方法。

此代码遍历树并顺序向队列填充每个项。你的代码类似于：

```csharp
private void Populate(Queue<TItem> enumData, Tree<TItem> tree)
{
    if (tree.LeftTree != null)
    {
        Populate(enumData, tree.LeftTree);
    }

    enumData.Enqueue(tree.NodeData);

    if (tree.RightTree != null)
    {
        Populate(enumData, tree.RightTree);
    }
}
```

## 任务 5：实现 IEnumerator<T> 和 IEnumerator 方法

4. 找到 `MoveNext` 方法。该方法不接受参数并返回一个布尔值。`MoveNext` 方法应确保内部队列已初始化，从内部队列检索下一个项并存储在 `currentItem` 属性中。如果操作成功，方法返回 `true`，否则返回 `false`。

5. 在 `MoveNext` 方法中，替换现有代码执行以下操作：
   - 如果 `enumData` 对象为 `null`，创建一个新的队列对象，然后调用 `Populate` 方法，将新队列对象和 `currentData` 成员作为参数传递调用。
   - 如果 `enumData` 对象包含任何值，从队列中检索第一个项，将其存储在 `currentItem` 成员中并返回布尔值。
   - 在方法末尾，返回布尔值 `false`。

你的代码类似于代码示例：

```csharp
bool System.Collections.IEnumerator.MoveNext()
{
    if (this.enumData == null)
    {
        this.enumData = new Queue<TItem>();
        Populate(this.enumData, this.currentData);
    }

    if (this.enumData.Count > 0)
    {
        this.currentItem = this.enumData.Dequeue();
        return true;
    }

    return false;
}
```

6. 找到 `Reset` 方法。该方法不接受参数，也没有返回值。此方法应将枚举器重置为初始状态。你可以通过使用 `Tree` 对象中的数据重新填充内部队列来实现这一点。

7. 在 `Reset` 方法中，将现有代码替换为调用 `Populate` 方法的代码，并将 `enumData` 和 `currentData` 成员作为参数传递给该方法。你的代码类似于下面的示例。

```csharp
void System.Collections.IEnumerator.Reset()
{
    Populate(this.enumData, this.currentData);
}
```
