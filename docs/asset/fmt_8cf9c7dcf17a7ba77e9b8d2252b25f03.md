## 在代码中创建方法

方法是类对程序数据执行的操作。方法本质上是类内部的函数。它们被称为类的“动词”。当对类执行操作时，就会使用方法。它可以是更改电话号码的方法。你可以设置一个方法从库存中减少商品（你会在 `Product` 类中创建一个名为 `DecrementInventory` 方法）。

方法的位置取决于你创建程序时的设计。无论方法名称是什么，注意设计中的重要部分。你总是将方法放在合适的类中。例如，你不会将 `DecrementInventory` 方法放在 `Customer` 类中，因为它与客户无关。糟糕的设计会对你的应用程序架构产生负面影响。

让我们看看类中的方法。我们提到一个允许用户更改电话号码的类方法。在客户类中的示例方法如下：

```csharp
public class Customer {
  public Customer () { }
  public void ChangePhone(string new_phone)
  {
    this.phone = new_phone;
  }
  public string first_name;
  public string last_name;
  public string phone;
}
```

我们在 `Customer` 类中添加了 `ChangePhone` 方法。如你所见，此方法接收 `new_phone` 变量。该变量获取客户电话号码并赋值给本地属性。再次注意，我们使用 `this` 指定来表示我们要赋值的是本地类变量而不是任何其他变量。当你将局部变量赋值给全局类变量且两者名称相同时，这一点尤为重要，正如我们在上面代码所示。

注意我们还添加了 `void` 修饰符。你指定方法返回值的类型。在这个示例中，没有返回内容，因此修饰符设置为 `void`。如果我们返回（例如）一个字符串值，我们将指定字符串返回类型而不是 `void` 关键字。

此外，注意我们将方法设置为 `public`。这意味着无论是否是子类，代码的其他任何部分都可以该方法。某些修饰符（如 `protected`）仅允许派生类使用该方法。我们希望代码的所有部分都能使用 `ChangePhone` 方法，因此我们将其保持为 `public`。如果我们将其设置为私有的，那么除了本地 Customer 类之外，其他类都无法使用该方法。

上述 `Customer` 类有三个属性。`first_name`、`last_name` 和 `phone` 变量都是 `Customer` 类的属性。

# 第 8 章
结构与枚举

**目标：** 结构（Structures）和枚举（Enum）是创建自定义数据类型的两种方式。本章将向你展示如何使用这两种数据类型来组织代码并使其更容易读。

我们在上一节中涵盖了类，类允许你创建自己的数据类型。结构和枚举是创建自定义数据类型的另外两种方式，但这些数据类型的工作原理与类不同。在使用结构和枚举时你会受到更严格规则的限制，并且它们用于你在类中看到的不同场景。在本章中，我们将查看这两种结构，并让你了解在 C# 程序中何时会使用它们。

## 为什么使用结构或枚举而不是类？

当你开始使用 C# 编程时，你可能想为一切都创建类。在这一章之前，我们一直推崇每个组件都应该是类的观点，但你可以使用枚举和结构处理程序中较小的组件。

例如，假设你有一个客户类型列表。每个类型在数据库中都有 0 到 3 的值。你可以为客户类型创建一个类，但也可以为这些值创建一个枚举。枚举为这些值提供了一个友好的名称，并存储一个整数来表示每个友好名称的编码值。

结构的作用与枚举类似。结构允许你包含不仅是整数值的内容。枚举用于整数值，而当你需要存储其他数据类型时，结构非常有用。例如，当你需要存储客户 ID 和类型的字符串值时，你可以为客户数据类型创建一个结构。你可能想在结构中存储与客户 ID 匹配的描述。你可以为此类型结构使用类，但有时当你只需要一两个属性来表示自定义数据类型时，类并不是必须的。

在本章中，我们将向你展示何时应该使用这些数据类型而不是构建整个类。在大多数情况下，你将使用类来定义你的应用程序，但在少数示例中，你不需要一个完整的类，而是一个小小的枚举或结构。

## 使用结构

结构与类最相似的东西。它们创建你自己的数据类型，但与类对象的定义略有不同。结构允许你创建一个自定义数据类型，该类型包含代码所需的任何数据类型的值的列表。

结构看起来像具有长属性列表的类，但你使用 `struct` 关键字来定义它们，而不是类定义。

让我们来看用于定义结构的模板。

```
struct structure_name
{
    public data_type name
    // 你需要的任何其他结构属性
}

结构括号内是属性。每个属性都应该设置为 `public`，否则你将无法访问它们。在类中，有理由不许可访问属性，但在结构中，你应该将它们设置为 `public`。你可以添加任意数量的结构属性，但当它变得太复杂时，有时选择类比使用结构更好。

## 创建枚举 (Enums)

枚举与结构体略有不同，但它们的设置方式相似。枚举只能存储整数值。当你有一组整数值，且不想在多个变量中静态地设置它们时，枚举就非常有用。例如，假设你想使用一个星期列表，并用从 0 到 6 的整数值表示它们。如果你不使用枚举变量而这样做，你就必须为你调用的每个函数创建变量。与其在每次需要处理星期几时创建七个变量，不如创建一个可以随时调用的枚举。枚举还允许你使用更易于识别的友好名称来表示这些值。

让我们来看创建枚举的模板语法。

```
enum enum_name
{
// 枚举变量的列表
}
```

使用枚举时，你使用 `enum` 关键字来表示你想创建一个枚举数据类型。在指定要创建枚举数据类型后，给你的枚举结构起一个名字。你可以给枚举起任何你喜欢的名字。枚举的命名规则与普通变量相同。

枚举括号内部是定义枚举所需的所有属性。让我们来看一个使用之前描述的“星期”枚举的真实世界示例。

```
enum Days { Sun, Mon, Tue, Wed, Fri, Sat };
```

注意，在枚举中，你不需要定义访问修饰符（specifier），也不需要声明任何数据类型。记住，枚举只持有整数数据类型，所以你不需要定义这些修饰符。它们默认都是公公开的，因此你不需要使用 `public` 修饰符。

当你定义一个枚举变量列表时，编译器会自动为每个变量赋值。除非你另有指定，否则第一个值始终为零。每个额外的变量会被赋予列表中的下一个数字。在这个示例中，第一个变量 `Sunday`，`Monday` 的值为 1，依此类推。

让我们看看你如何在代码中使用它。

```
class EnumProgram {
    enum Days { Sun, Mon, tue, Wed, thu, Fri, Sat };
    static void Main () {
        int monday = (int)Days.Mon;
        int friday = (int)Days.Fri;
        Console.WriteLine("Monday: {0}", monday);
        Console.WriteLine("Friday: {0}", friday);
    }
}
```

在上面的代码中，你可以看到枚举变量是如何返回值的。我们将值分配给两个整数变量。在上面的代码中，输出首先显示 Monday 的整数值，即 1。下一个输出值是 Friday，即 5。

你也可以重新分配枚举中设置的整数值。例如，假设你想让你所有的枚举值都从 1 开始，并分配从 1 到 7 的整数。让我们来看修改枚举值的代码。

`enum Days { Sun = 1, Mon, Tue, Wed, Thu, Fri, Sat };`

在上面的代码中，我们从值 1 开始整数赋值。在这种情况下，最后一个变量 `Sat` 的值不再是 6，而是 7。

你对枚举和结构体的需求可能没有对类那么频繁，但在许多不需要类定义带来的臃肿开销的场景下，它们是非常用的。我们向你展示了几个示例，当你设计程序时，你会发现它们在哪些地方有用。

# 第 9 章
## 继承 (Inheritance)

**目标**：类和面向对象编程（OOP）让你具备从父类派生类的能力。本章将解释类结构中的继承。

OOP 不仅仅是创建类和构建可以调用其他类的程序。你可以从父类派生子类，这样你就不需要为相似的对象重复代码。如果你没有良好的类设计，继承可能会变得复杂，因此本章试图解释继承以及你应该如何设置类结构以获得最佳的可扩展性代码。

## 理解基础继承

继承允许你从父类派生子类。考虑一下动物。如果你有一只狮子和一只鹦鹉，这两种动物都有非常不同的特征，但它们也有相似的特征。它们都是动物，但一种是鸟类，另一种是哺乳动物。如果你不使用继承，你就需要创建两个类从上到下地描述这两种动物。

通过继承，你可以创建一个描述动物基本特征的类，然后从主父类派生子类。例如，鸟类和狮子都有眼睛和脚。它们的眼睛和脚看起来可能不同，但仍然拥有。其他特征不同，但所有的狮子和鸟类都有脚。你可以创建一个定义脚和眼睛的父动物类，然后狮子和鸟类子类可以定义各自动物的特定特征。

继承的目的是为了使代码不再重复。如果没有它，你必须创建一个鸟类和狮子类来定义每种动物的眼睛和脚，这将导致冗余代码。当你创建冗余代码时，管理变得变得困难。当你创建了十个定义动物眼睛的类并需要更改该描述时，你需要修改所有十个类。这在你尝试扩展代码时留下了更多产生错误和问题的空间，而这正是你想要避免的。

并不是每个类都必须是父类或子类。你可以创建不派生自任何其他代码的独立类。你如何设计代码取决于你以及你想要创建程序的需求。

## 继承自父类

在创建子类之前，你需要先创建一个父类。由于我们使用动物作为示例父类，我们首先创建一个动物类，定义所有动物之间最基本的、共享的特征。

让我们来看一个动物类的示例。

```

    public string number_of_feet;
    public function breath()
    {
        return "Animals breathe air.";
