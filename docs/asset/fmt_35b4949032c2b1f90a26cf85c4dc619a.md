
这导致了另一个观察：

- (iv) 假设特征值 `λ` 满足 `|λ| = 1`（单位圆边界）。为了证明这一点，令 `v ∈ C^d` 为特征向量且 `λ = e^{iθ}`，其中 `0 < θ < π`。那么该链不是遍历的。

**定理 6.2 (遍历性的谱条件)** 假设 `λ1=1` 是唯一满足 `|λ| = 1` 的特征值。那么该链是遍历的。谱隙定义为 `1 - max{|lambda_i| : i ≥ 2}`。这通过归纳法证明。

## 6.4 随机前瞻

对于线性空间模型、`M/M/1` 队列以及有限状态马尔可夫链，我们确定了使得极限概率测度 `π` 满足条件 (6.6)：对于每个状态 `x ∈ X` 和 `S ∈ B(X)`，

> $$\lim_{k\to\infty} P^k(x,S) = \pi(S).$$

极限 `π` 是不变的，且在状态上满足

> $$\int_X(dx)\pi^k(x,S) = \pi(S), \quad S \in \mathcal{B}(X), k \ge 1.$$

这意味着 `π^k = π`。关于无限状态空间上不变测度的存在条件将在本章稍后部分介绍，并带有远比强的遍历定理。

不变测度的存在等价于过程 `X` 的稳态实现的存在。状态过程满足平稳性：`P{X(k) ∈ A_0, X(k+1) ∈ A_1, …, X(k+m) ∈ A_n}` 与 `k ≥ 0` 无，对于任何 `m ≥ 0` 和任何集合序列 `{A_0, …, A_m}`，每个均属于 `B(X)`。自然地，平稳实现对于每个 `k` 都满足 `X(k) ~ π`。虽然我们预计在现实世界中遇到真正的平稳性，但这种理想化对于算法的概念和分析是有帮助的。

### 6.4.1 Critic（评价）方法

强化学习中的“critic”一词是指值函数 `h`，它相对于单步成本函数 `c` 定义。一个例子是折扣成本：对于 `0 ≤ γ < 1`，

$$h(x) = E_x \left[\sum_{k=0}^{\infty} \gamma^k c(X(k))\right].$$

`TD(λ)` 学习引入于 20 世纪 70 代，用于获得折扣成本动态规划方程的近似解，基于时间差分的泛化，这是第一部分中 `TD` 学习算法的核心。随机设置马尔可夫链提供了新的工具和见解。例如，将看到 `TD(1)` 算法的最终输出解决了最小范数问题：

$\min\{||h-h'||_2^2 : h \in \mathcal{H}\}$

`H` 是我们寻求近似的函数类，范数相对于稳态定义：

$|\hat{h}-h||_2^2 = E[||\hat{h}(X(k))-h(X(k))||_2^2] \quad \text{当 } X(k) \sim \pi。(6.22)$

### 6.4.2 Actor（执行）方法

强化学习始于参数化族 `{P_θ : θ ∈ R^d}` 以及成本函数族 `{c_θ : θ ∈ R^d}`。“actor”方法旨在寻找参数 `θ* ∈ R^d`，使得平均成本 `η_θ = ∫ c(x)π_θ(dx)` 最小，其中 `π_θ` 在 `P_θ` 下不变。参见定理 6.8 估计 `η` 梯度的一种技术，使得 `θ ∈ R^d` 可以通过随机梯度下降估计。Actor-critic 方法结合了定理 6.8 和 (6.22)，以获得梯度的无模型无偏估计。

## 6.5 泊松方程

这个等式将在书中以多种形式出现：

$c + Ph = h + η. (6.23)$

它被称为泊松方程。函数 `c` 被称为激励函数，`η` 是常数，解 `h` 被称为相对值函数。建立 (6.23) 解的所加条件也意味着不变测度 `π` 存在，且 `η = π(c) = ∫∫ c(x)π(dx)`。在许多情况下，我们通过迭代或求逆获得解：

$h = \sum_{k=0}^{\infty} P^k \tilde{c}. (6.24)$

其中 `\tilde{c}(x) = c(x) - η`（相对值函数的一个理论依据）。(6.23) 的解不是唯一的：如果 `h` 是一个解，那么通过加上常数可以得到一个新的解。(6.23) 和 (6.24) 中的抽象概念基于 (6.9b)。对于有限状态空间模型，泊松方程变为：

$c(x) + \sum_{x'} P(x,x')h(x') = h(x) + η, \quad x ∈ X. (6.25)$

另一种等效表示是基于马尔可夫模型 (6.3) 的固定策略动态规划强化 (2.25)：

$h(x) = \tilde{c}(x) + E[h(F(x,N(k+1))]$。

这意味着与第 2.5.2 节和整个第 5 节讨论的样本路径公式：

$h(X(k)) = \tilde{c}(X(k)) + E[h(X(k+1)) | X(0), …, X(k)].$

泊松方程在后面的章节中起着核心作用：

- (i) 平均成本最优控制的相对值函数是特定泊松方程的解。
- (ii) 回想一下，泊松不等式是第 2.4.3 节中性能边界的基础（即关于值函数 `J`）。类似的不等式用于第 6.6 节，以获得稳态均值 `η` 以及相对值函数 `h` 的界。
- (iii) 中心极限定理 (CLT) 用于几乎每一个章节中算法的收敛速率。CLT 中的协方差矩阵可以用对 (6.23) 的解表示，其中 `c` 的选择取决于应用。CLT 的首次介绍是在第 6.7 节。
- (iv) 正如第 6.4 节所示，在某些控制应用中，我们有一转移核族 `{P_θ : θ ∈ R^d}`。将 `c: X → R` 解释为成本，我们希望在所有 `θ` 上最小化稳态平均成本 `η`。许多梯度下降近似都是基于第 6.8 节介绍的泊松方程和敏感性分析。
- (v) 第 6.8 节的主要结果之一是强化学习的 actor-critic 方法，这是第 10 节的主题。

第 6.3 节的概念提供了 `X` 为有限时 (6.23) 解的存在条件。第 3.2 节的讨论提供了第 6.3 节之外的 Perron–Frobenius 定理的早期介绍。

**定理 6.3 (泊松方程的光谱条件)** 假设 `X` 为有限，且满足定理 6.2 的假设。则有以下成立：

- (i) 函数 `h1 = ∑_{k=0}^∞ P^k c` 是 (6.23) 的解（记得 6.24）。
- (ii) 令 `x* ∈ R_+` 为满足 `π(s) > 0` 的函数，`v` 为满足 `P(x, x') ≥ s(x), x' ∈ X` 的函数，且 `P ≥ s ⊗ v`。那么泊松方程的解由 `h2 = G_{s,v}c` 给出，`G_{s,v} = ∑_{n=0}^∞ (P - s ⊗ v)^n = [I - (s ⊗ v)]^{-1}`。

## 6.6 Lyapunov 函数

在更紧凑的算子理论表示法中，这变为

```
$$PV ≤ V - c + \bar{η}. \quad (6.27)$$
```

与确定性情况一样，函数 `c` 通常被解释为状态空间上的代价函数。通常假设 `c(x)` 对于“大” `x` 来说很大（回想第 2.4 节中*强制性*的定义）。在这种情况下，泊松不等式意味着每当 `X(k)` 很大时，`V(X(k))` 就会减少。图 2.5 展示了一个确定性系统，图中说明中所指的集合为 `S={x : c(x) ≤ \bar{η}}`。

### 6.6.1 平均代价

令 `η(x)` 表示平均代价：

```
$$\eta(x) = \lim_{n \to \infty} \frac{1}{n} \sum_{k=0}^{n-1} E[c(X(k)) \mid X(0) = x].$$
```

使用算子理论表示法 (6.9b) 得到

```
$$\eta(x) = \lim_{n \to \infty} \frac{1}{n} \sum_{k=0}^{n-1} P^k c(x).$$
```

在 `η(x)` 的定义中，对 `x` 的依赖性以及使用“上上界”而非极限都是必要的，因为我们没有对 `X` 施加任何特定的结构。平均代价在泊松不等式 (6.27) 下允许稳定的界。这是命题 2.3 在马尔可夫设置下的扩展。

**命题 6.4** *假设 (6.27) 成立且处处 `V ≥ 0`。那么对于每个 `n ≥ 1` 和每个 `x ∈ X`，均满足以下瞬态界：*

```
$$\frac{1}{n} \sum_{k=0}^{n-1} P^k c(x) \leq \bar{\eta} + \frac{1}{n}V(x).$$
```

因此，平均代价满足界 `η(x) ≤ \bar{η}`。

*证明* 将 `P` 应用于等式两边得到 `P^2V ≤ PV - Pc + P\bar{η}`，由于 `η` 是常数，

```
$$P^2V \leq PV - Pc + \bar{\eta} \leq V - Pc + 2\bar{\eta}.$$
```

通过重复乘以 `P`，我们得出对于每个 `n`，

```
$$P^nV \leq V + n\bar{\eta} - \sum_{k=0}^{n-1} P^k c.$$
```

通过重新排列项并利用 `V ≥ 0` 的假设，我们得到了所需的结论。□

我们已经看到，在定理 6.3 的假设下，命题 6.4 给出的平均代价界对于有限空间马尔可夫链是紧的：我们可以取 `V = h + const.`，其中常数选择足够大使得 `V ≥ 0`。

Lyapunov理论的魅力在于不需要知道模型就可以性能界。这在下一个示例中得到了说明。

## 示例：标量线性状态模型

考虑标量模型，

```
X(k+1) = \alpha X(k) + N(k+1), \quad k \geq 0, \quad (6.28)
```

其中 `N` 是独立同分布的，均值为零且具有有限二阶矩 `σ_N^2`（不一定是高斯分布）。代价函数是二次的，`c(x) = 1/2 x^2`。
令 `V(x) = 1/2 κ x^2`，其中 `κ > 0`。我们随后有：

```
$PV(x) = E[V(X(k+1)) \mid X(k)=x]\\= \frac{1}{2}\kappa(\alpha x + N(1))^2\\= V(x) + \frac{1}{2}\kappa(\alpha^2 - 1)^2 + \frac{1}{2}\kappa\sigma_N^2., \quad (6.29)$
```

只要 `|α| < 1`，我们可以在 `V` 的定义中设置 `κ = (1-α^2)^{-1}`，以获得强制项 `η` 的泊松方程解：

```
$PV(x) = V(x) + \eta(x), \quad with \ \eta = \frac{1}{2}(1-\alpha^2)^{-1}\sigma_N^2., \quad (6.30)$
```

由命题 6.4 可知，对于每个 `x`，`η(x) ≤ Γ`。事实上，前面的步骤表明对于每个初始条件，`E[η(X(k))]` → `\bar{η}`，因此我们有等式：`η(x) = \bar{η}`。
如果 `N` 是高斯分布，那么当 `k → ∞` 时，`P^k(x, ·)` 收敛于高斯分布 `N(0, σ_η^2)`，其中 `σ_η^2 = (1-α^2)^{-2}σ_N^2`。

## 6.6.2 折扣代价

*长期来看，我们都会死掉。* 这句话归于约翰·凯恩斯（John Keynes），通常用于证明在最优控制中使用折扣的合理性。我认为这在大多数应用中是错误的。然而，折扣准则有时便于分析，并且在许多学科（特别是运筹学和经济学）中更受青睐。Lyapunov 界及其后果如 (6.4) 所示，表明稳态行为是良好的。特别是如果平均代价是有限的，通过 (6.27) 得到瞬态界。给定参数 `γ ∈ (0,1)`，初始条件 `x` 的折扣代价定义为和：

```
$h_{\gamma}(x) = \sum_{k=0}^{\infty} \gamma^k E[c(X(k)) \mid X(0)=x]. \quad (6.31)$
```

再次，这具有算子形式：

```
$h_{\gamma} = \sum_{k=0}^{\infty} \gamma^k P^k c., \quad (32)$
```

如果 `c` 是负值的，界 `h_γ(x) ≥ c`，使得折扣代价无偏的。再次得到 `h_γ` 的界：

```
$h_{\gamma} = c + \gamma Ph_{\gamma}. \quad (33)$
```

**命题 6.5** 若 (6.27) 成立且处处 `V ≥ 0`，则对于每个 `x` 和 `γ ∈ (0,1)`，`h_γ(x) ≤ V + \bar{η}(1-γ)^{-1}`。

*证明* 界 (6.27) 得到

```
$\gamma PV \leq V - g + \eta.$ (34)$
```

其中 `g = (1-γ)V + γ c` 是 Lyapunov 函数和代价函数的组合。对两边应用 `γ P` 得到：

```
$(\gamma P)^2V \leq \gamma PV - \gamma g + \gamma\bar{\eta}.$
```

然后使用 (34)，

```
$(\gamma P)^nV \leq V - \sum_{k=0}^{n-1} \gamma^k g + \sum_{k=0}^{n-1} \gamma^k \bar{\eta}.$
```

对于平均代价问题，通过 `g = (1-γ)V + γ c` 的归纳法得到：

```
$\sum_{k=0}^{\infty} \gamma^k P^k c(x) + (1-\gamma)V(x) \leq V(x) + \frac{\bar{\eta}}{1-\gamma}.$ (35)$
```

利用 `V ≥ 0` 的事实，我们可以去掉 (35) 左侧所有涉及 `V` 的项，得到：

```
$\sum_{k=0}^{\infty} \gamma^k P^k c(x) \leq V(x) + \frac{\bar{\eta}}{1-\gamma}.$
```（此处此处原文逻辑应为推导）通过从两边减去 `(1-γ)V(x)` 并将不等式除以 `γ`，得到界 `h_γ ≤ V + \bar{η}(1-γ)^{-1}`。

**示例 6.4.1** 代价 `c(x) = 1/2 x^2` 的线性状态模型折扣代价，泊松方程的解在 (30) 中得到。命题 6.5 给界 `h_γ ≤ V + \bar{η}(1-γ)^{-1}`，在这种情况下变为

```
$h_{\gamma}(x) \leq \frac{1}{1-\alpha^2}[x^2 + \frac{\sigma^2}{1-\gamma}]. (36)$
```

我们接下来计算 `h_γ` 以查看该界是否准确。为此，我们从动态规划方程 (33) 开始。令 `V(x) = A_γ + 1/2 κ x^2`，其中 `A_γ, κ_γ` 是待选的常数。从 (29) 得到：

```
$PV \leq \alpha^2 V + (1-\alpha^2)A_{\gamma} + \frac{1}{2}\kappa\sigma^2.$
```

乘以 `γ` 并向每边加上 `c` 得到：

```
$c+\gamma PV=c+\gamma(\alpha^2 V+(1-\alpha^2) A_{\gamma}+\kappa_{\gamma}),$
```

或者重新引入二次表达式：

```
$c(x)+\gamma PV(x)=\frac{1}{2}(1+\gamma^2\kappa_{\gamma})x^2+\frac{1}{2}(\kappa_{\gamma}\sigma_{N}^2+A_{\gamma}).$
```
