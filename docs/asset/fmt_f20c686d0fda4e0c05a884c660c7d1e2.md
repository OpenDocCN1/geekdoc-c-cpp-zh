## 1.3 基数

在讨论基数之前，我们必须回顾当我们说两个集合的“大小相同”时意味着什么。例如，考虑以下两个集合：

`{A, B, C}` `{cow, dog, cat}`

“错误”的答案是这两个集合都有三个元素——或者更准确地说，数元素个数到三是可以的，但并没有回到第一原理。为什么它们有三个元素？拥有三个元素意味着什么？“正确”的答案是它们之间存在一一对应关系——例如，`A ↔ cat`，`B ↔ cow`，且 `C ↔ dog`。它们有三个元素的原因是每个元素与某个表现出“三”的基础的集合一一对应。

### 定义 1.16

令 `N_k` 为前 `k` 个自然数 `{0, 1, 2, ..., k−1}`。如果存在某个自然数 `k` 的双射 `f: S → N_k`，则集合 `S` 是有限的。

## 计算的局限

### 定义 1.17

集合 `S` 是可计的，当且仅当存在射函数 `f: N → S`。集合 `S` 是无限的，当且仅当存在射函数 `f: S → N`。

乔治·康托尔 `Georg Cantor`，德国数学家，1845–1918 证明了无限有不同的大小。例如，自然数显然有无限多个，因为映射 `f(i) = i` 是一个射函数 `f: N → N`。

`0, 1, 2, 3, 4, 5, ...` 十进制

`0, 1, 10, 100, ...` 二进制

实数也有无限多个。即使在实数上的半开区间 `R[0, 1) = {x : 0 ≤ x < 1}` 中，也有无限个数字。

回想区间内的每个实数都有其小数展开形式 `0.1210...`

这些展开是无限的。就像 `1/5` 的小数或 `1/4` 的二进制展开一样，它们在某点之后全为零。某些如 `1/7` 具有循环模式，而某些如 `π/10` 完全没有模式。

## 1.4 计数论证与对角线法

许多集合具有相同的基数；它们之间存在一一对应关系。三个简单的例子是：

- `Z⁺` = 正整数 = `1, 2, 3, ...`
- `Z_{2n≥10}` = 从 `10` 开始的正整数 = `10, 11, 12...`
- 对应关系：`f(n) = n + 9`
- `Z⁺` = 正整数 = `1, 2, 3, ...`
- `Z_{even}` = 偶正整数 = `2, 4, 6, 8, ...`
- 对应关系：`f(n) = 2n`

# 集合论 ■ 9

`Z⁺` = 正整数 `1, 2, 3, ...`

`Z⁺ = Z⁺ × Z⁺ × Z⁺ = {(x, y, z) | x, y, z ∈ Z⁺}`

对应关系：按某种顺序列出三元组，例如，从 `n = 3` 开始。

- 列出所有和为 `n` 的元组 `n` 初始化为 `3` `(1, 1, 1) ↔ 1`
- 增加 `n`，列出所有和为 `n` 的元组：`n = 4` `(1, 1, 2) ↔ 2`
- `(1, 2, 1) ↔ 3`
- `(2, 1, 1) ↔ 4`
- `n = 5` `(1, 1, 3) ↔ 5`
- `(1, 2, 2) ↔ 6`
- `(1, 3, 1) ↔ 7`
- `(2, 1, 2) ↔ 8`
- `(2, 2, 1) ↔ 9`
- `(3, 1, 1) ↔ 10`
- `n = 6` `(1, 1, 4) ↔ 11`

等等。

注意这种良定义的顺序。所有和为 `n (n + 1)` 的数字都列在第一位为 `1` 的数字之前，它们列在以 `2` 开头的数字之前，以此类推；第二位也是如此。因此，当和 `n = 12` 时，第一批三元组是 `(1, 1, 10), (1, 2, 9) ... (10, 10), (2, 1, 9) ... (10, 1, 1)`。

任何良定义的顺序都可以生效——每一个三元组 `(r, s, t)` 将在枚举和为 `u = r + s + t` 的三元组时会在某一点被列举。因此该映射是满的。没有两个三元组对应同一个整数，因此它也是一一对应的且是双射。

集合 `1 = R(0, 1)` = 从 `0` 到 `1` 的实数，不包括 `0` 或 `1`。

集合 `2 = R` 所有实数。

对应关系：任何双射函数，例如 `f(x) = tan π(x - ½)` 或 `g(x) = (x - 1/2)/x(x - 1)`。

### 定理 1.18 康托尔

所有自然数集与实数集 `R[0,1)` 之间不存在一一对应。

证明并不困难。首先，让我们用二进制表示所有数字。其次，为了使二进制分数的表示是唯一的，我们需要不允许任何无限的 `1` 序列。例如，这两个数字表示完全相同的数字：

```
0.001111111... = 0.010000000...
```

## 计算的限性

并没有特殊的理由规定符号必须是连接的线段——考虑符号 `j` 或符号 `x`。也没有特殊的理由规定符号必须有一个定义良好的名称，否则我们将退沦为为每个符号命名。奇异、艺术性的字母表很难命名，因此也难以讨论和书。形式语言理论中的标准字母表由一组标准字符组成，可能带有如 `x` 或 `x'` 等修饰。在大多数课程和文本示例中，字母表很小。许多示例使用了字母表 `{0, 1}` 或 `{a, b, c}`。

字母表 `Σ` 上的字符串是来自 `Σ` 符号的有限序列。

字母表末尾附近的字母通常用作字符串名称 `u, v, w` 等。为了表示字符串中的符号，将使用 `σ` 有时使用 `τ`。

### 定义 2.3

字符串 `w` 的长度记作 `|w|`，是字符串 `w` 中包含的非唯一字符的数量。由于字符串是有限的，因此每个字符串都有定义的长度。

### 示例

- `w = abb = σ1σ2σ3`，属于 `Σ = {a, b, c}`, `σ1 = a, σ2 = σ3 = b`, `|w| = |abb| = 3`
- `u = bbbb`，属于 `Σ = {a, b, c}`, `|u| = |bbbb| = 4`
- `v = 1001111`，属于 `Σ = {0, 1}`, `|v| = 7`

注意：序列有不同的符号——通常使用的符号取决于该序列被用于数学课程、形式语言还是算法分析。

```
w = ababa 形式语言
w = (a, b, a, b, a) 算法分析
```

# 语言 ■ 15

任何字母表上最短的字符串是空字符串——一个没有任何字符的字符串。我们把空字符串表示为 `ε`——希腊字母 epsilon——尽管有些作者使用 `ε` 或 `λ` 代替它。它的长度为零，`|ε| = 0`。

字母表上没有最长的字符串。字符串可以是任何长度，只要它是有限的。

### 示例

考虑两个字母表 `Σ1 = {a, b, c}` 和 `Σ2 = {b, c, d}`。以下是同时属于 `Σ1` 和 `Σ2` 的字符串：

```
ε
bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb
bbcbcb
```

以下不是 `Σ1` 和 `Σ2` 的字符串：

```
abacabad d ∉ Σ1, a ∉ Σ2
```

可以使用指数来表示字符串内字符的重复或字符重复的次数。

### 示例

```
a^4b^5a^2 = aaaabbbbbaa
b^28 = bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb
0^5 = 00000
a^0 = ε
1^3 = 111 这是一个字符串操作，而不是算术！
```

### 定义 2.4

`Σ` 上的语言是 `Σ` 上字符串的集合。

### 示例

以下是字母表 `Σ = {0, 1}` 上的语言：

`L1 = {0, 01, 001, 0001, 00001, 000001}`

`L2 = {ε, 111111, 0000000000}`

`L3 = {ε}`

`L4 = {}`

无限语言由无数量的字符串组成。

### 示例

以下是字母表 `Σ = {a, b, c}` 上的语言——所有的 `L5` 都是无限的。

- `L1 = {w | w 以 b 开头}`
- `L2 = {w | w 以 c 开头或结尾}`
- `L3 = {w | w 包含偶数个 a}`
- `L4 = {w | w 不包含 c}`
- `L5 = {w | w 是 Scrabble 拼字游戏 词典中的单词} = {a, aa, aba, ba, baa, baba, bacca, cab ...}`

### 示例

以下是字母表 `Σ = {0, 1}` 上的语言：

`L1 = {1, 01, 001, 0001, 00001, ...}`

`L2 = {1, 010, 00100, 000100, ...}`

`L1 = {ε, 00, 0000, 000000,, ...}`

任何字母表 `Σ` 上最小的语言是 `L_∅ = {}`，它没有任何字符串。`L_ε = {ε}` 不同，后者是语言中恰好有一个字符串。

## 2. 字符串操作

字符串 `w = σ1σ2 ... σn` 的反转记作 `w^R` 通过将其字符按相反顺序排列获得，`w^R = σnσn-1 ... σ1`。注意长度是相同的，`|w| = |w^R|`。

### 示例

`(abc)^R = cbba`

`(00111)^R = 11100`

`(abba)^R = abba`

`ε^R = ε`

两个字符串 `u = σ1σ2 ... σn` 和 `v = τ1τ2 ... τm` 的拼接通过将 `v` 附加到 `u` 的末尾获得，有时记作 `uv`。长度 `|uv| = |u| + |v|`。

### 示例

考虑 `Σ = {0, 1}` 上的字符串：

`w = 000`

`x = 1`

`y = 010`

`z = ε`

那么：

`wx = 0001`

`xy = 110`

`yz = 010`

`zw = 000`

注意 `zw = w` 对于任何字符串 `w`。因此 `ε = w` 对于任何字符串 `w`。

可以使用指数来表示字符串与其自身的拼接，记作 `w^n`。

### 示例

考虑 `Σ = {a, b, c}` 上的字符串：

`w = ababa` 形式语言

`w = (a, b, a, b, a)` 算法分析

`a^4b^5a^2 = aaaabbbbbaa`

`b^28 = bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb`

`0^5 = 00000`

`a^0 = ε`

`1^3 = 111` 这是一个字符串操作，而不是算术！

## 计算限性

### 示例

设 `Σ1 = {0, 1, 2}, Σ2 = {a, b}, 0 → ab, 1 → ε, 2 → ba`，则 `h(0) = ab, h(1) = ε, h(2) = ba`：

```
00122 → ababbaba  h(00122) = ababbaba
110 → ab  h(110) = ab
202 → baabba  h(202) = baabba
ε → ε  h(ε) = ε
```

### 定义 2.6

字符串 `v` 和 `w` 的洗牌是形式为 `v_i1 w_j1 v_i2 w_j2 ... v_in w_jn` 的字符串集合，其中 `n ≥ 1` 且 `v = v1, ..., vn`, `w = w1, ..., wn`。`v_i` 和 `w_j` 是 `v` 和 `w` 的子串。

由于某些子串是 `ε`，这并不意味着两个字符串长度相同，或者字符是交替出现的。它意味着 `v` 和 `w` 的符号在它们洗牌后的任何字符串中都按顺序出现。
