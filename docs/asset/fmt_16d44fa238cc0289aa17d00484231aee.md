
```c
void *aligned_realloc(void *ptr, size_t size, size_t alignment, size_t old_size) {
    char *new_ptr = aligned_alloc(alignment, size);

    if (new_ptr == NULL) {
        return NULL;
    }

    size_t copy_size = old_size < size ? old_size : size; // 获取最小值

    if (ptr != NULL) {
        memcpy(new_ptr, ptr, copy_size);
    }

    free(ptr);

    return new_ptr;
}
```

注意，它总是会拷贝数据，从而消耗时间，而 `realloc()` 在可能的情况下会避免这一点。这几乎并不高效。除非为了避免需要重新分配自定义对齐的数据。

> http://www.open-std.org/jtc1/sc22/wg14/www/docs/summary.html#dr_460

# 第 13 章

## 作用域

作用域关于变量在什么上下文中可见的。

### 13.1 块作用域

这是几乎所有开发者定义的变量的作用域。它包含了其他语言可能称为“函数作用域”的内容，即在函数内部定义的变量。

基本规则是，如果你在一个由花括号分隔的块中声明了一个变量，那么该变量的作用域就是该块。

如果块内部还有另一个块，那么在内部块中声明的变量是该块的局部的，且在外部作用域中不可见。

一旦变量的作用域结束，该变量就无法再次被引用，你可以认为它的值已经进入了天空中的“大桶”¹。

一个带有嵌套作用域的示例：

```c
#include <stdio.h>

int main(void)
{
    int a = 12;           // 外部块局部，但在内部块中可见

    if (a == 12) {
        int b = 99;      // 内部块局部，在外部块中不可见

        printf("%d %d\n", a, b); // OK: "12 99"
    }

    printf("%d\n", a);      // OK，我们仍然在 a 的作用域内
    printf("%d\n", b);      // 非法，超出了 b 的作用域
}
```

> ¹https://en.wikipedia.org/wiki/Bit_bucket

#### 13.1.1 在何定义变量

另一个事实是，你可以在块内的任何地方定义变量——它们拥有该块的作用域，但在定义之前无法使用它们。

```c
#include <stdio.h>

int main(void)
{
    int i = 0;

    printf("%d\n", i);    // OK: "0"

    // printf("%d\n", j);    // 非法--在定义 j 之前无法使用 j

    int j = 5;

    printf("%d %d\n", i, j);    // OK: "0 5"
}
```

历史上，C 语言要求在块中的任何代码之前定义所有变量，但在 C99 标准中不再是这样了。

#### 13.1.2 变量隐藏

如果你在内部作用域中有一个与外部作用域中同名的变量，只要你运行在内部作用域中，内部作用域的变量就具有优先级。也就是说，在它的生命周期内，*隐藏*了外部作用域的那个。

```c
#include <stdio.h>

int main(void)
{
    int i = 10;

    {
        int i = 20;

        printf("%d\n", i);    // 内部作用域 i, 20 (外部 i 被隐藏了)
    }

    printf("%d\n", i);    // 外部作用域 i, 10
}
```

你可能注意到我在示例的第 7 行那里丢了一个块，而不是用一个 `for` 或 `if` 语句来启动它！这是完全合法的。有时开发者会想要将一组局部变量放在在一起以便快速处理。

### 13.2 文件作用域

如果你在块外部定义变量，它具有文件作用域，只要你在定义它之前使用它是不合法的。

### 13.3 循环作用域

如果你在循环中定义变量，它在循环的作用域内是有效的。

```c
#include <stdio.h>

int main(void)
{
    for (int i = 0; i < 5; i++) {
        printf("%d\n", i);
    }
    // printf("%d\n", i); // 非法，i 已经出了作用域
}
```

### 13.4 函数作用域

只要你在定义它之前使用它是不合法的。

### 14.2 字符类型

让我确认一下。`char` 实际上是一个数字，所以我们可以对它进行数学运算吗？

那么那些单引号里的常量字符，比如 'B' 呢？它是如何具有数值的呢？

#### 14.4.1 多少十位数？

这个关键问题是：“我可以在浮点类型中存储多少个有效十位数，以便在打印时能获得相同的十进制数字？”

| long double | LLD_DIG | 10 |
