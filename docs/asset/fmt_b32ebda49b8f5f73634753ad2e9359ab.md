
```
#include <stdio.h>
char *tmpnam(char *s);
```

#### 描述

`tmpnam` 函数生成一个有效的文件名，且与现有文件的名称不相同^{270} 该函数可能能够生成 `TMP_MAX` 个不同的字符串，但其中某些或全部可能已被现有文件占用因此无法使用。

> 270) 使用 `tmpnam` 生成的字符串创建的文件仅在与常规命名规则冲突的意义上是临时的。在使用结束且程序终止之前，仍需要使用 `remove` 函数来删除此类文件。

`tmpnam` 函数每次调用时都会生成不同的字符串。带有空指针参数调用 `tmpnam` 函数可能会彼此之间引入数据竞态。实现应表现为没有库函数调用 `tmpnam` 函数。

#### 返回

如果无法生成合适的字符串，`tmpnam` 返回空指针。否则，如果参数是空指针，`tmpnam` 函数将其结果留在内部状态并返回指向该对象的指针（后续调用 `tmpnam` 函数可能会修改该对象）。如果参数不是空指针，假设它指向一个至少有 `L_tmpnam` 个字符的数组；`tmpnam` 函数将其结果写入该数组并返回参数作为值。

#### 环境限制

`TMP_MAX` 的值至少为 25。

## 7.21.5 文件访问函数

### 7.21.5.1 fclose 函数

#### 摘要

```
#include <stdio.h>
int fclose(FILE *stream);
```

#### 描述

成功调用 `fclose` 函数会导致 `stream` 指向的流被刷新并关联的文件被关闭。流的任何未缓冲数据都会交付给主机环境以写入文件；任何未读取的缓冲数据都会被丢弃。无论调用是否成功，流都会与文件分离，且通过 `setbuf` 或 `setvbuf` 函数设置的任何缓冲区都会与流分离（如果是自动分配的，则会被释放）。

#### 返回

`fclose` 函数在流成功关闭时返回 0，如果检测到任何错误则返回 `EOF`。

### 7.21.5.2 fflush 函数

#### 概要

```
#include <stdio.h>
int fflush(FILE *stream);
```

#### 描述

如果 `stream` 指向一个输出流或最近操作不是输入的更新流，`fflush` 函数将导致该流 `stream` 的任何未写入的数据被交付给主机环境以写入文件；否则，其行为是未定义的。

如果 `stream` 为空指针，则 `fflush` 函数对所有上述定义行为的流执行此刷新操作。

#### 返回值

如果发生写入错误，`fflush` 函数会设置流的错误指示器并返回 `EOF`，否则返回 0。

前向引用：`fopen` 函数 (7.21.5.3)。

### 7.21.5.3 fopen 函数

#### 概要

```
#include <stdio.h>
FILE *fopen(const char * restrict filename,
const char * restrict mode);
```

#### 描述

`fopen` 函数打开由 `filename` 指向的字符串命名的文件，并将其与一个流关联。

参数 `mode` 指向字符串。如果该字符串是以下之一，则文件以指定的模式打开。否则，其行为是未定义的。²⁷¹¹

- `r` 以读取模式打开文本文件
- `w` 截断长度为零或创建文本文件用于写入
- `wx` 创建文本文件用于写入
- `a` 追加；或在文件末尾创建文本文件用于写入
- `rb` 以读取模式打开二进制文件
- `wb` 截断长度为零或创建二进制文件用于写入

> 如果字符串以上述序列之一开头，实现可能会可能会忽略剩余的字符，也可能使用它们来选择不同类型的文件（其中某些可能不符合 7.21.2 中的术语）。

- `ab` 创建二进制文件用于写入
- `append` 追加；在文件末尾打开或创建二进制文件用于写入
- `r+` 以更新模式打开文本文件（读和写）
- `w+` 截断长度为零或创建文本文件用于更新
- `w+x` 创建文本文件用于更新
- `a+` 追加；打开或创建文本文件用于更新，在文件末尾写入
- `r+b` 或 `rb+` 以更新模式打开二进制文件（读和写）
- `w+b` 或 `wb+` 截断长度为零或创建二进制文件用于更新
- `w+bx` 或 `wb+x` 创建二进制文件用于更新
- `a+b` 或 `ab+` 追加；打开或创建二进制文件用于更新，在文件末尾写入

以读取模式（`'r'` 作为 `mode` 参数的第一个字符）打开文件，如果文件不存在或不可读，则失败。

以独占模式（`'x'` 作为 `mode` 参数的最后一个字符）打开文件，如果文件已存在或可以创建，则失败。否则，文件将以独占（也称为非共享）访问创建，程度取决于底层系统对独占访问的支持。

以追加模式（`'a'` 作为 `mode` 参数的第一个字符）打开文件会导致后续对文件的所有写入操作都被强制置到当前文件末尾，无论中间调用了多少 `fseek` 函数。在某些实现中，用追加模式打开二进制文件（`'b'` 作为上述 `mode` 参数值列表中的第二个或第三字符）可能会初始将流的位置指针置于最后写入的数据之后，这是由于空字符填充。

当用更新模式（`'+'` 作为上述 `mode` 参数值列表中的第二个或第三字符）打开文件时，可以在关联的流上执行输入和输出。然而，在没有调用 `fflush` 函数或文件定位函数（`fseek`、`fsetpos` 或 `rewind`）的情况下，输出不应紧跟输入；在没有调用文件定位函数的情况下，输入不应紧跟输出，除非输入操作遇到文件末尾。在某些实现中，用更新模式打开（或创建）文本文件可能会打开（或创建）二进制流。

当流被全缓冲时，当且仅当可以确定它不是指向交互式设备。流的错误和文件指示器将被清空。

#### 返回值

`fopen` 函数返回指向控制流的对象的指针。如果操作失败，`fopen` 返回空指针。

前向引用：文件定位函数 (7.21.9)。

### 7.21.5.4 freopen 函数

#### 概要

```
#include <stdio.h>
FILE *freopen(const char * restrict filename,
const char * restrict mode,
FILE *restrict stream);
```

#### 描述

`freopen` 函数打开由 `filename` 指向的字符串命名的文件，并将 `stream` 指向的流与其关联。`mode` 参数的使用方法与 `fopen` 函数相同。

如果 `filename` 为空指针，则 `freopen` 函数尝试将流的模式更改为 `mode` 指定的模式，仿佛使用了与流关联的文件名。允许哪些模式更改（如果有）以及在什么情况下更改取决于实现。

`freopen` 函数首先尝试关闭与指定 `stream` 关联的任何文件。关闭失败将被忽略。流的错误和文件结束指示器将被清空。

#### 返回值

如果打开操作失败，`freopen` 返回空指针。否则，`freopen` 返回 `stream` 的值。

### 7.21.5.5 setbuf 函数

#### 概要

```
#include <stdio.h>
void setbuf(FILE * restrict stream,
char * restrict buf);
```

#### 描述

除了没有返回值外，`setbuf` 函数等同于调用了 `mode` 为 `_IOFBF` 且 `size` 为 `BUFSIZ` 的 `setbuf` 函数，或者（如果 `buf` 为空指针）`mode` 为 `_IONBF` 的调用。该函数的主要用途是更改标准流（`stderr`、`stdin` 或 `stdout`）关联的值。

`setbuf` 函数没有返回值。

前向引用：`setbuf` 函数 (7.21.5.6)。

### 7.21.5.6 setbuf 函数

#### 概要

```
#include <stdio.h>
int setbuf(FILE * restrict stream,
char * restrict buf,
int mode, size_t size);
```

#### 描述

`setbuf` 函数只有在流关联之后执行任何其他操作（失败的 `setbuf` 调用）之前可以使用。`mode` 参数决定流如何缓冲，如下：`IOBF` 使输入输出全缓冲；`IOBF` 使输入输出行缓冲；`BF` 使不缓冲。如果 `buf` 不是空指针，则可以使用它指向的数组代替缓冲区；否则由 `size` 决定数组。数组的内容是不确定的。

成功时返回 0，如果 `mode` 值无效或请求无法实现，则返回非零。

## 7.21.6 格式化输入输出函数

格式化输入输出函数的行为类似于在每个说明符之后有一个序列点。²274

### 7.21.6.1 fprintf 函数

#### 概要

```c
#include <stdio.h>
int fprintf(FILE * restrict stream,
const char * restrict format, ...);
```

#### 描述

`fprintf` 函数向 `stream` 指向的流写入内容，由 `format` 指向的字符串控制哪些后续参数用于输出。如果参数不足，其行为是未定义的。如果格式耗尽而仍有参数，多余的参数会被求值（如常），但会被忽略。`fprintf` 在遇到格式字符串结束时返回。

格式应是一个多字节字符序列，起始并结束于其初始位移状态。格式由零或多个指令组成：普通多字节字符（非 `%`），它们被原封不动地复制到输出流；以及转换规范，每个转换规范都会导致获取零或多个参数，如果适用，将它们转换为相应的转换说明符，并将结果写入输出流。

每个转换规范都由字符 `%` 引入。在 `%` 之后，按顺序出现：

- 零或多个标志（任意顺序），用于修改转换规范的含义。
- 一个最小字段宽度。如果转换值的字符少于字段宽度，则会在左侧（默认情况下）或右侧（如果给出了后文描述的调整标志）用空格填充到字段宽度。字段宽度取自星号 `*`（后文描述）或非负十进制整数。²275
- 可选精度给出 `d`、`o`、`u`、`x` 和 `X` 转换的最小位数、`a`、`A`、`E`、`f` 和 `F` 转换小数点后的位数、`g` 和 `G` 转换的最大有效数字，或写入的最大字节数用于 ...的转换。精度的形式为一个小数点 (.)，其后紧跟一个星号 `*`（后文描述）或一个可选的小数整数；如果仅指定了小数点，则精度被视为零。如果在任何其他转换指定符中出现精度，其行为是未定义的。
- 一个可选的长度修饰符，用于指定参数的大小。
- 转换指定符字符，用于指定要应用的转换类型。

如上所述，字段宽度、精度或两者都可以由星号 `*` 表示。在这种情况下，一个 `int` 类型参数提供字段宽度或精度。指定字段宽度、精度或两者的参数应（按该顺序）出现在要转换的参数（如果有的话）之前。负数字段宽度参数被视为 `-` 标志后紧跟一个正数字段宽度。负数精度参数被视为省略了精度。

标志字符及其含义含义如下：

- `-` - 转换结果在字段内左对齐。（如果未指定此标志，则右对齐。）
- `+` + 有符号转换的结果始终以加号或 减号符号开头。（如果未指定此标志，则仅在转换负值时以符号开头。） 276

如果有符号转换的首字符不是符号，或者有符号转换的结果没有字符，则在结果前加一个空格。如果空格标志和 `+` 标志同时出现，则忽略空格标志。

结果被转换为“另一种形式”。对于 `o` 转换，它会增加精度，且仅在必要时强制结果的第一位数字为 0（如果是 `x` 或 `(X)` 转换，非零结果将带有前缀 `0x` 或 `(0X)`）。对于 `a`, `A`, `e`, `E`, `f`, `F`, `g` 和 `G` 转换，浮点数转换的结果始终包含一个小数点字符（通常情况下，这些转换结果中只有在小数点后有数字时才会出现）。对于 `g` 和 `G` 转换，结果中的末尾零不会删除。对于其他转换，其行为是未定义的。

对于 `d`, `i`, `o`, `u`, `x`, `X`, `A`, `e`, `E`, `f`, `F`, `g` 和 `G` 转换，前零（在任何符号或基数指示之后）用于填充字段宽度，而不是转换无穷大或 NaN。如果 `0` 和 `-` 标志同时出现，则忽略 `0` 标志。对于 `d`, `i`, `o`, `u`, `x` 和 `X` 276，负零的所有浮点转换结果以及舍入为零的负值的结果包含一个减号。如果指定了精度，则忽略 `0` 标志。对于其他转换，其行为是未定义的。

## 7 长度修饰符及其含义为：

- `hh` 指定后续的 `d`, `i`, `o`, `u`, `x` 或 `X` 转换指定符适用于有符号 `char` 或 `unsigned char` 参数（该参数已根据整数提升进行了提升，但在打印之前其值将转换为 `signed char` 或 `unsigned char`）；或者后续的 `n` 转换指定符适用于指向 `signed char` 参数的指针。
- `h` 指定后续的 `d`, `i`, `o`, `u`, `x` 或 `X` 转换指定符适用于 `short int` 或 `unsigned short int` 参数（该参数已根据整数提升进行了提升，但在打印之前其值将转换为 `short int` 或 `unsigned short int`）；或者后续的 `n` 转换指定符适用于指向 `short int` 参数的指针。
- `L (ll)` 指定后续的 `d`, `i`, `o`, `u`, `x` 或 `X` 转换指定符适用于 `long int` 或 `unsigned int` 参数；后续的 `n` 转换指定符适用于指向 `long int` 参数的指针；后续的 `c` 转换指定符适用于指向 `wchar_t` 参数的指针；或者后续的 `s` 转换指定符适用于指向 `a`, `E`, `f`, `F`, 或 `G` 参数的指针；
- `LL (ll)` 指定后续的 `d`, `i`, `o`, `u`, `x` 或 `X` 转换指定符适用于 `long long int` 或 `unsigned long int` 参数；或者后续的 `n` 转换指定符适用于指向 `long long int` 参数的指针。
- `j` 指定后续的 `d`, `i`, `o`, `u`, `x` 或 `X` 转换指定符适用于 `intmax_t` 或 `uintmax_t` 参数；或者后续的 `n` 转换指定符适用于指向 `intmax_t` 参数的指针。
- `z` 指定后续的 `d`, `i`, `o`, `u`, `x` 或 `X` 转换指定符适用于 `size_t` 或相应的整数类型参数；或者后续的 `n` 转换指定符适用于指向 `size_t` 参数的指针。
- `t` 指定后续的 `d`, `i`, `o`, `u`, `x` 或 `X` 转换指定符适用于 `ptrdiff_t` 或无符号整数类型参数；或者后续的 `n` 转换指定符适用于 `ptrdiff_t` 参数。
- `L` 指定后续的 `a`, `E`, `f`, `g` 或 `G` 转换指定符适用于 `long double` 参数。

如果长度修饰符出现在上述以外的转换指定符，其行为是未定义的。转换指定符及其含义为：

- `d, i` `int` 参数被转换为 `.dd` 风格的有符号十进制。精度指定了出现的最小位数；如果转换后的值可以用较少的位数表示，则用前导零进行扩展。默认精度为 1。精度为零时转换零值没有字符。
- `o, u, x, X` `unsigned int` 参数被转换为 `.ddd` 风格的无符号八进制 (`o`)、无符号十进制 (`u`) 或十六进制表示 (`x` 或 `X`)；字母 `abcdef` 用于转换，`X` 转换使用字母 `ABCDEF`。精度指定了最小位数（类似于 `d, i`，但此处不补零）。默认精度为 1。精度为零时转换零值没有字符。
- `f, F` `double` 参数的浮点数被转换为 `.ddd` 风格的十进制表示，其中小数点后的位数等于精度。如果精度缺失，则取值为 6；如果精度为零且未指定 `#` 标志，则不出现小数点。如果出现小数点，则前面至少有一个数字。值被舍入到适当的位数。
- `g, G` `double` 参数的浮点数被转换为 `f` 或 `e` 风格，取决于转换的值和精度。令 $P$ 等于精度（非零，缺失则为 6，零则为 1）。那么，使用 `E` 风格的转换将指数为 $X$：

  - 如果 $P > X \ge4$，则使用 `f`（或 `F`）且精度为 $P-(X+1)$。
  - 否则，使用 `e`（或 `E`）且精度为 $P-1$。

最后，除非使用 `#` 标志，否则将删除结果小数部分的末尾零，如果没有剩余小数部分，则删除小数点。

区分类型为 **double** 的第$^{279}$ 值，但可以省略零；如果精度为零且未指定 # 标志，则出现小数点字符。字母 **abcdef** 用于转换，字母 **ABCDEF** 用于转换。A 转换产生一个用 **X** 和 **P** 代替 **x** 和 **p** 的数字。指数始终包含至少一个数字，以及表示 2 的十进制指数所需的任意数量数字。如果值为零，则指数为零。

表示无穷大（infinity）或非数字（NaN）的 **double** 参数将按照 **f** 或 **F** 转换说明符的样式进行转换。

如果不存在 1 长度修饰符，则 **int** 参数被转换为无符号字符（**unsigned char**），并写入生成的字符。

如果存在 1 长度修饰符，则 **wint_t** 参数的转换类似于没有精度的 **ls** 转换说明符，且参数指向 **wchar_t** 二元素数组的起始元素，其中第一个元素包含 **wint_t** 参数（用于 **lc** 转换说明符），第二个元素为空宽字符。

如果不存在 1 长度修饰符，参数应为指向字符类型数组的起始元素的指针。$^{280}$ 从数组中写入字符，直到遇到（但不包含）终止空字符。如果指定了精度，则写入的字节数不超过指定的字节数。如果未指定精度或精度大于数组大小，则数组应包含一个空字符。
