当此调用执行时，引用参数 `input`（图 18.4，第 21 行）成为 `cin` 的别名，引用数字 `number` 成为 `phone` 的别名。运算符函数将电话号码的三个部分读取到参数 `number` 所引用的 `PhoneNumber` 对象的 `areaCode`（第 24 行）、`exchange`（第 26 行）和 `line`（第 28 行）中。流操作符设置读取到每个字符串的字符限制。当参数指定的字符数（例如 `setw(3)` 表示读取三个字符）少于默认值时，将通过调用 `istream` 成员函数 `ignore`（图 18.4，第 23、25 和 27 行）跳过空格和连字符符，该函数会忽略输入流中指定数量的字符（默认为一个）。函数 `operator>>` 返回 `istream` 引用 `input`（即 `cin`）。这使得对 `PhoneNumber` 对象的输入操作可以与其他其他 `PhoneNumber` 对象或其他数据类型的输入操作进行级联。例如，程序可以在一个语句中如下输入两个 `PhoneNumber` 对象：

```cpp
cin >> phone1 >> phone2;
```

首先，表达式 `cin >> phone1` 通过非成员函数调用执行：

```cpp
operator>>(cin, phone1 );
```

此调用返回 `cin >> phone1` 值的引用，因此该表达式的返回部分被简单地解释为 `cin >> phone2`。这通过执行非成员函数调用完成：

```cpp
operator<<(cin, phone2 );
```

重载运算符应当模仿其内置对应运算符的功能——例如，`+` 运算符应该执行加法，而不是减法。避免过度或不一致地使用运算符重载，因为这可能导致程序晦涩且难以阅读。

## 重载流插入 << 运算符

流插入运算符函数（图 18.4，第 11-16 行）接收一个 `ostream` 引用（输出）和一个 `const PhoneNumber` 引用（`number`）作为参数，并返回 `ofstream` 引用。函数 `<<` 显示 `PhoneNumber` 类型的对象。当编译器看到表达式

```cpp
cout << phone
```

在图 18.4 的第 22 行中，编译器会生成非成员函数调用

```cpp
operator<<(cout, phone);
```

函数 `<<` 显示 `PhoneNumber` 类型的对象。

`(800) 555-1212`

`cin >> phone` 时，编译器会生成非成员函数调用

`operator>>(cin, phone);`
