头部 `<uchar.h>` 声明了处理 Unicode 字符的类型。

声明的类型为 `mbstate_t`（描述见 7.29.1）和 `size_t`（描述见 7.29.1）。

第一个元素由 `s` 指向的数组。最多存储 `MB_CUR_MAX` 字节。如果 `c16` 是宽字符，则存储一个空字节，其前面是任何恢复初始位移状态所需的位移序列；描述的最终状态为初始转换状态。

### Returns

`c16rtomb` 返回存储在数组中的字节数（包括任何位移序列）。当 `c16` 不是有效的宽字符时，会发生编码错误：该函数在 `errno` 中设置宏 `EILSEQ` 的值并返回 `(size_t) (-1)`；转换状态未指定。

## 7.28.1.3 `mbtorc32` 函数

### 语法概要

```
#include <uchar.h>

size_t mbtorc32(char32_t * restrict pc32,
const char * restrict s, size_t n,
mbstate_t * restrict ps);
```

### 描述

如果 `s` 为空指针，则 `mbtorc32` 函数等同于调用：

```
mbtorc32 (NULL, "", 1, ps);
```

在这种情况下，参数 `pc32` 和 `n` 的值被忽略。

如果 `s` 不是空指针，`mbtorc32` 函数将检查从 `s` 指向的字节开始最多 `n` 个字节，以确定完成下一个多字节字符所需的字节数（包括任何位移序列）。如果该函数确定下一个多字节字符是完整且有效的，它将确定对应宽字符的值，然后如果 `pc32` 不是空指针，它会将第一个（或唯一）字符的值存储在 `pc32` 指向的对象中。随后的调用将存储宽字符，而不消耗任何额外的输入，直到这些字符被存储完毕。如果对应的宽字符是空宽字符，则描述的最终状态为初始转换状态。

### Returns

`mbtorc32` 函数返回以下适用项中的第一个（取决于当前转换状态）：

- 如果接下来的 `n` 个或更少字节完成了对应空宽字符多字节字符（即存储的值）。
- 在 1 到 `n` 之间（包含），如果接下来的 `n` 个或更少字节完成了有效的多字节字符（即存储的值）；返回的值是完成多字节字符的字节数。
- `(size_t) (-3)`，如果之前的调用产生的后续字符已由本次调用消耗了输入字节。
- `(size_t) (-2)`，如果接下来的 `n` 个字节构成了一个完整（可能有效）的多字节字符，且所有 `n` 个字节均已处理（未存储任何值）；
- `(size_t) (-1)`，如果发生编码错误，此时 `n` 个或更少字节未构成完整有效的多字节字符（未存储任何值）；宏 `EILSEQ` 的值存储在 `errno` 中，转换状态未指定。

## 7.28.1.4 `c32rtomb` 函数

### 语法概要

```
#include <uchar.h>

size_t c32rtomb(char restrict s, char32_t c32,
mbstate_t * restrict ps);
```

### 描述

如果 `s` 为空指针，`c32rtomb` 函数等同于调用
`c32rtomb(buf, L'\0', ps)`
其中 `buf` 是一个内部缓冲区。

如果 `s` 不是空指针，`c32rtomb` 函数确定表示由 `c32` 给出的宽字符的多字节字符所需的字节数（包括任何位移序列），并将多字节表示存储在由 `s` 指向第一个元素的数组中。最多存储 `MB_CUR_MAX` 字节。如果 `c32` 是空宽字符，则存储一个空字节，其前面是任何恢复初始位移状态所需的位移序列；结果描述在初始转换状态中。

### Returns

`c32rtomb` 函数返回数组中存储的字节数（包括位移序列）。当 `c32` 不是有效的宽字符时，会发生编码错误：函数在 `errno` 中设置宏 `EILSEQ` 的值并返回 `(size_t) (-1)`；转换状态未指定。

当 `n` 至少具有 `MB_CUR_MAX` 宏的值时，这种情况仅当 `s` 指向冗余位移序列时（对于依赖状态的编码）。

## 7.29 多字节和宽字符工具 `<wchar.h>`

### 7.29.1 引言

头文件 `<wchar.h>` 定义了四个宏，声明了四个数据类型、一个标记以及许多函数。声明的类型为 `wchar_t` 和 `size_t`（见 7.19）；

```
mbstate_t
```
是一个数组外的完整对象，可以存储多字节字符序列与宽字符之间转换所需的状态；

```
wint_t
```
默认整数类型，可以存储对应扩展字符集成员的值，以及一个不对应扩展字符集的值（见 `EOF`）；以及

```
struct tm
```
被声明为一种不完整类型（内容见 7.27）。定义的宏有 `NULL`（见 7.19）；`WCHAR_MIN` 和 `WCHAR_MAX`（见 7.20）；以及展开为

```
EOF
```
为 `wint_t` 类型的常量表达式，其值不对应扩展字符集的任何成员。它被本节的多个函数接受（并返回），表示文件结束，即流中没有更多输入。

声明的函数分组如下：

- 执行宽字符、多字节字符或两者输入输出的函数；
- 提供字符串转换的函数；
- 执行通用字符串处理的函数；
- 用于字符串和时间转换的函数；以及
- 提供多字节与宽字符序列之间转换能力的函数。

本节函数的参数可能指向包含对应扩展字符集成员的 `wchar_t` 数组。此类值应根据指定的语义进行处理，如果此类值出现在 7.29.2 或 7.29.5 中函数的格式字符串中，是否发生编码错误未指定。除非另有说明，如果本节描述的函数的执行导致重叠对象之间的拷贝，则行为未定义。
