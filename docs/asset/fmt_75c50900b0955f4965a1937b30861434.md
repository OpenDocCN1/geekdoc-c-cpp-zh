
该问题将给出一组位于特定限制数学语言中的句子，判断其是否为真。我们需要定义该语言。

我们仅使用以下符号：

- 1. 变量 `$x, y, z, \dots$`，取值范围 `$\mathbb{N}$`。
- 2. 符号：`$=, < +$`
- 3. 常量：`$0, 1, 2, 3, \dots$`。

为了纪念证明其可判性的学者，我们称其为普斯格尔算术（Presburger Arithmetic）。

### 定义 5.88 一个项（term）是：
- 1. 如果 `t` 是变量或常量，那么 `t` 是项。
- 2. 如果 `t1` 和 `t2` 是项，那么 `t1 + t2` 是项。

### 定义 5.89 一个原子公式（Atomic Formula）是：
- 1. 如果 `t1, t2` 是项，那么 `t1 = t2` 是原子公式。
- 2. 如果 `t1, t2` 是项，那么 `t1 < t2` 是原子公式。

### 定义 5.90 普斯格尔公式（Presburger Formula）的定义类似于定义 WS1S 公式的方式，假设我们已经定义了原子公式。

`x < y + z` 为真吗？这是一个我们不知道 `x, y, z` 是什么的问题。但如果我们对所有变量进行量化，那么存在一个真值。例如：

```
(\exists x)(\exists y)(\exists z)[x < y + z]$ is true
```

```
(\exists x)(\exists y)(\forall z)[x < y + z]$ is true
```

`(∃x)(∀y)(∃z)[x < y + z] is true`

`(∃x)(∀y)(∃z)[x < y + z] is false`

`(∀x)(∃y)(∃z)[x < y + z] is true`

`(∀x)(∃y)(∀z)[x < y + z] is true`

`(∀x)(∀y)(∀z)[x < y + z] is false`

句子（sentence）是指所有变量都经过量化的公式。我们现在（终于！）可以定义我们的问题：给定一个普斯格尔算术中的句子 `$\phi$`，它是否为真？

- 普斯格尔证明了这个问题是可判定的。他的证明没有给出界限。
- 后来发现了一个涉及量词消除的证明。给定一个句子，我们可以找到一个少一个量词的等式。该算法将此问题置于 `DTIME(TOW₃(n))`。
- Fisher 和 Rabin 证明了存在常数 `c`，使得该问题需要的时间至少 `2^{cn}`。

### 定义 5.91 令 `$\Sigma$` 为有限字母表。令 `i ∈ ℕ`。一个 `i`-级教科书正则表达式（i-Textbook Regular Expression）定义为：

# 18. PRIMITIVE RECURIVE（原始递归）

我们将分阶段定义原始递归函数。

**Definition 5.93** `$PR_0$` 为以下函数：
1. `n, c ∈ ℕ`。则函数 `f(x1, …, xn) = c`。
2. `n ∈ ℕ` 且 `1 ≤ i ≤ n`。则函数 `f(x1, …, xn) = xi`。
3. `n ∈ ℕ` 且 `1 ≤ i ≤ n`。则函数 `f(x1, …, xn) = xi + 1`。

**Definition 5.94** 对于 `i ≥ 1`，以下函数在 `PR_i` 中：
1. 所有的 `h ∈ PR_{i-1}`。
2. `k, n ∈ ℕ`。令 `f ∈ PR_{i-1}` 其中 `f : ℕ^n`。令 `g ∈ PR_{i-1}` 其中 `g : ℕ → ℕ^n`。则 `f(g(x)) ∈ PR_i`。（注：此处原文逻辑略有跳跃，按字面翻译）
3. 如果 `$\alpha$` 是一个 `i`-tre exp 且 `n, k ∈ ℕ`，那么 `$\alpha^{TOW_i(n^k)}$` 是一个 `i`-tre exp。（此处原文应为 `f ∈ PR_i` 的递归定义）
4. `n ∈ ℕ`。令 `f ∈ PR_{i-1}` 其中 `f : ℕ^n`。令 `g ∈ PR_{i-1}` 其中 `g : ℕ → ℕ`。通过递归定义 `h`：
   ... `h ∈ PR_i`。（这是递归。）

**Definition 5.95** 一个函数是原始递归的（Primitive Recursive），如果它属于 `$\bigcup_{i=0}^{\infty} PR_i$`。

已知，对于所有 `i`，`DTIME(TOW_i(n))` 是原始递归的。

可以证明加法在 `PR_1`，乘法在 `PR_2`，幂运算在 `PR_3`，`$TOW_0(2)$` 在 `PR_4`。

更进一步地说，数学中遇到的几乎任何函数都是原始递归的。

显然 `EL ⊆ PRIMREC`。事实上 `EL ⊂ PRIMREC`。我们给出一个原始递归但非初等的例子。

`f ∈ PR_{i-1}` 其中 `f : ℕ^n`。令 `g ∈ PR_{i-1}` 其中 `g : ℕ → ℕ^n`。则 `f(g(x)) ∈ PR_i`。（组合）

令 `f ∈ PR_{i-1}` 其中 `f : ℕ → ℕ`。定义 `h(0) = c, h(n+1) = f(h(n))`。则 `h ∈ PR_i`。（递归）

我们将此称为实数理论（Theory of the Reals）。

- 2. 如果 `t1` 和 `t2` 是项，那么 `t1 + t2` 和 `t1t2` 是项。

## 示例 5.101 并集数据结构 (Data Structures for Union)

并查数据结构（Union-Find Data Structure）是一种支持集合集合的数据结构。查找操作包括：(1) FIND，给定一个元素 `x`，判断它是否在数据结构中，如果是，则替换；(2) UNION，给定两个集合，用它们的并集替换它们。人们可能会询问 FIND 消耗多少步，UNION 消耗多少步。这不是正确的问题。人们预见到会有很多 FIND 和 UNION。所以这里正确的问题是：执行 `n` 次操作需要多少时间？注意，其中一次操作需要很长时间，但随后只需要很快。Tarjan 和 Van Leeuwen [74] 表明这个问题 (1) 可以在 `Ω(α(n))` 时间内完成，(2) 需要 `Ω(A(n))` 时间，其中 `α(n)` 是阿克曼函数的反函数。这意味着该问题不能在 `O(n)` 内完成，但只需要比这多一点就能完成。我们感兴趣的是，阿克曼函数出现在了这个问题的分析中！

## Definition 5.107

1. `A ∈ Σ1`，如果存在 `B ∈ DEC`，使得
   $$A = \{x \mid (\exists y)[(x, y) \in B]\}$$
   该类通常被称为可枚举的 (c.e.) 或可递归的 (r.e.)。HALT 和 H10 都是 `Σ1`-完全的。因此，它们真的是同一个问题。
2. `A ∈ Π1`，如果 `$\bar{A} ∈ Σ1$`。
3. `A ∈ Σ2`，如果存在一个集合 `B ∈ DEC`，使得
   $$A = \{x \mid (\exists y)(\forall^P z)[(x, y, z) \in B]\}$$
4. `A ∈ Π2`，如果 `$\bar{A} ∈ Σ2$`。
5. `A ∈ Σ3`，如果存在一个集合 `B ∈ DEC`，使得
   $$A = \{x \mid (\exists y)(\forall^P z)[(x, y, z, w) \in B]\}$$
6. `A ∈ Π3`，如果 `$\bar{A} ∈ Σ3$`。
7. 可以定义 `Σ4, Π4, Σ5, …`。
8. 这些集合构成了所谓的“算术层级”（Arithmetic Hierarchy)。我们定义 `AH = \bigcup_{i=1}^\infty Σ_i = \bigcup_{i=1}^\infty Π_i`。

显然
`Σ1 ⊆ Σ2 ⊆ Σ3 ⊆ …`。
且
`Π1 ⊆ Π2 ⊆ Π3 ⊆ …`。
并且
`(\forall i)[Π_i ⊆ Σ_{i+1} 且 Σ_i ⊆ Π_{i+1}].`
