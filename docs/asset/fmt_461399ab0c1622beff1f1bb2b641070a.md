# 二次方程的根

二次方程是形式为 $ax^2 + bx + c$ 的方程，其中 $a$、$b$ 和 $c$ 是已知数字，且 $a \neq 0$。此类方程的根可以通过以下方式计算：

```
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
```

如果判别式 $b^2 - 4ac \geq 0$，则方程有实根。如果判别式小于 0，则没有实根。编写一个程序，要求用户输入 $a$、$b$ 和 $c$ 的值。它应该计算并显示方程是否有实根。如果有实根，它还应该显示这些根。
