
# C 语言编程基础指南

C 语言是一种用于创建计算机程序的流行且广泛使用的编程语言。程序员青睐 C 语言是因为它为程序员提供了最大的控制权和效率。

如果你是一名程序员，或者你对成为程序员感兴趣，学习 C 语言可以带来几个好处：

- 你将能够为许多平台读取和编写代码——从微控制器到最先进的科学系统，都可以用 C 编写。
- 考虑到 C 的性能和可移植性，几乎所有流行的跨平台编程语言和脚本语言（如 `C++`、`Java`、`Python`、`Objective-C`、`Perl`、`Ruby`、`PHP`、`Lua` 和 `Bash`）都是用 C 实现的，并大量借鉴了 C 的语法和函数。它们共享相似的运算符、表达式、循环语句、控制结构、数组、输入输出以及函数。此外，几乎所有语言都可以与 C 和 C++ 接口，以利用大量的现有 C/C++ 库。

在本文中，我们将贯穿整个语言，并教你如何从开始成为一名 C 程序员。

## 第一章 C 语言编程

### 什么是 C？

C 是一种计算机编程语言。这意味着你可以使用 C 为计算机创建一组供其遵循的指令。C 是目前使用的数千种编程语言之一。C 已经存在了几十年，并被广泛接受，因为它为程序员提供了最大的控制和效率。C 是一门容易学习的语言。它的风格比其他某些语言稍微晦涩一点，但你很快就能掌握。

C 是一种所谓的编译型语言。这意味着一旦你写好了程序，就必须通过 C 编译器运行它，将你的程序转换为计算机可以运行（执行）的可执行文件。C 程序是人类可读的形式，而编译器输出的可执行文件是机器可读可执行的格式。这意味着要编写和运行 C 程序，你必须拥有 C 编译器。

我们将从头开始，从一个极其简单的 C 程序开始，并在此基础上构建。我假设你使用 Linux 命令行并将 `gcc` 作为这些示例的环境；如果你不是这样，所有的代码仍然可以正常工作——你只需要理解并使用你所拥有的任何编译器即可。

`scanf` 函数允许你从标准输入接受输入，对我们来说通常是键盘。`scanf` 函数可以执行很多不同的操作，但除非使用最简单的方法，否则它通常是不可靠的。它不可靠是因为它不能很好处理人为错误。但对于简单的程序来说，它是足够且易用的。

`scanf` 最简单的应用如下：

```c
scanf("%d", &d);
```

程序将读取用户在键盘上输入的整数值（`%d` 用于整数，与 `printf` 相同，因此 `b` 必须声明为 `int`），并将该值存入 `b` 中。

`scanf` 函数使用与 `printf` 相同的占位符：

- `int` 使用 `%d`
- `float` 使用 `%f`
- `char` 使用 `%c`
- 字符字符串（稍后讨论）使用 `%s`

你必须在 `scanf` 中使用的变量前面加上 `&`。其原因在你学习指针后就会变得明朗。很容易忘记 `&` 符号，当你忘记它时，运行程序时几乎总是会崩溃。

通常情况下，最好像这里所示使用 `scanf` —— 即从键盘读取单个值。通过多次调用 `scanf` 来读取多个值。在任何实际程序中，你将改用 `gets` 或 `fgets` 函数来一次读取一行。然后你将“解析”该行以读取其值。你之所以这样做是为了你可以检测输入中的错误并根据你的需要对它们进行处理。

### 循环：一个示例

假设你想创建一个程序，打印华氏度到摄氏度的转换表。这可以通过 `for` 循环或 `while` 循环很容易实现：

```c
#include <stdio.h>

int main(void)
{
    int a = 0;
    while (a <= 100)
    {
        printf("%4d degrees F = %4d degrees C\n",
               a, (a - 32) * 5 / 9);
        a = a + 10;
    }
    return 0;
}
```

如果你运行这个程序，它将生成一个从 0 华氏度到 100 华氏度的数值表。输出如下：

- 0 degrees F = -17 degrees C
- 10 degrees F = -12 degrees C
- 20 degrees F = -6 degrees C
- 30 degrees F = -1 degrees C
- 40 degrees F = 4 degrees C
