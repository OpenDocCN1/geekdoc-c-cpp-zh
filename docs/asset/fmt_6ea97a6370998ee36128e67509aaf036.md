当 `.h` 第一次被 `#include` 时，标识符 `TIME_H` 尚未定义。在这种情况下，`#define define TIME_H` 且预处理器将 `.h` 头文件内容包含到 `.cpp` 文件中。如果再次 `#include` 头文件，`TIME_H` 已被定义，预处理器会忽略 `#ifndef` 与 `#endif` 之间的代码。尝试多次包含头文件（无意中）通常发生在可能包含其他头文件的大型程序中。
