## 使用 UpdatePanel 控件与 Web 服务

现在，让我们学习如何使用 `UpdatePanel` 控件与 Web 服务，该控件用于刷新 Web 页面的指定部分而不是刷新整个 Web 页面。

ASP.NET 中的 `UpdatePanel` 控件使你能够创建丰富的、面向客户端的 ASP.NET AJAX 启用的 Web 服务。如果你希望你的 Web 页面在回发时刷新某些选定部分而不刷新整个页面，你可以使用 `UpdatePanel` 控件。这种页面更新类型，其中 Web 页面的小部分被更新而不是整个页面，被称为部分页面更新。`UpdatePanel` 控件放置在 `ScriptManager` 控件内部。你可以在 `ScriptManager` 控件内拥有一个或多个 `UpdatePanel` 控件。

`UpdatePanel` 控件用于使 Web 页面更具交互性。当你编写代码以部分更新页面时，你需要对 JavaScript 有透彻的了解，但使用 `UpdatePanel` 控件，你可以在不使用任何客户端脚本的情况下部分更新 Web 页面。

执行以下步骤使用 `UpdatePanel` 控件：

1. 打开 Visual Studio 2010，然后选择 `File→New→Web Site` 选项并将应用程序命名为 `UsingUpdatePanelControl`（可在 CD 上获得）。
2. 在 Solution Explorer 中右键单击 `UsingUpdatePanelControl` 应用程序并选择 `Add New Item` 选项。`Add New Item` 对话框打开。
3. 从 Visual Studio 安装的模板中选择 Web Service 模板，将 Web 服务命名为 `WebService`，然后单击 `Add` 按钮。
4. 打开 Solution Explorer 中 `App_Code` 文件夹的 `WebService` Web 服务的代码隐藏文件并用创建 Web 服务的代码替换文件的现有代码，如 Listing 18.28 所示：
