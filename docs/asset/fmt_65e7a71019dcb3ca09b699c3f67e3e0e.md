设计用于计算机打印的支票包含固定数量的空格，计算机可以在其中打印金额。假设支票包含空白处，计算机应该在其中打印周薪工资单。如果金额很大，那么其中的九个空格将被填满——例如：

```

```

```
123456789
```

包含四个空白格。如果打印的支票带有空格，某人更容易更改支票金额。为了防止此类更改，许多支票打印系统会插入*leading asterisks*（前导星号）来保护金额，如下：

```
****99.87
123456789
```
