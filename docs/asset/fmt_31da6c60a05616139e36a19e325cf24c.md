*12-1;
*测试存储长度的一种方法是使用 length 函数，
它返回的是存储长度，与 LENGTH 函数相比，
LENGTH 函数返回的是字符字符串的长度，但不计算末尾的空格；
data storage;
length A $4 B $4 S $4;
Name = 'Goldstein';
AandB = A | B;
Cat = cats(A,B);
if Name = 'Smith' then Match = 'No';
else Match = 'Yes';
Substring = substr(Name,5,2);
L_A = length(A);
L_B = length(B);
L_Name = length(Name);
L_AandB = length(AandB);
L_Cat = length(Cat);
L_Match = length(Match);
L_Substring = length(Substring);
