### 3.2.7 sizeof 运算符

该运算符告诉你特定变量或数据类型在内存中所占用的空间（字节）。

更具体地说，它告诉你特定表达式（可能是单个变量）在内存中所占用的空间（字节）。

这在不同系统上可能不同，`char` 及其变体除外（它们总是 1 字节）。

这看起来可能并不有用，但我们会处处引用它，所以值得介绍。

由于它计算存储类型的字节数，你可能认为它会返回一个 `int`。或者……由于大小不能为负，可能是无符号整数？

事实是 C 有一种特殊的类型来返回 `sizeof` 的值。`size_t`，读作 "size tee"。众所它是一种无符号整数类型，可以容纳任何交给 `sizeof` 的对象的字节大小。

`size_t` 出现在许多传递或返回计数的地方。把它看作一个表示计数的值。

你可以将 `sizeof` 作为一个表达式：

```
int a = 999;
// %zu 是 size_t 类型的格式指定符
```

```
printf("%zu\n", sizeof(a)); // 在你的系统上输出 4
```

> size_t 是 type 的缩写。

```c
printf("%zu\n", sizeof(int)); // 在你的系统上输出 4
printf("%zu\n", sizeof(3.14)); // 在你的系统上输出 8
```

## 3.3.3 do-while 语句

现在我们已经掌握了 `while` 语句，让我们来看看它紧密相关的表兄弟 `do-while`。

它们基本上是相同的，区别在于如果循环条件在第一次通过时为假，`do-while` 会执行一次，而完全不执行。换句话说，在 `do-while` 中，检查是否执行块的测试发生在块的末尾。而在 `while` 中，它发生在块的开头。

让我们通过示例来看：

```c
// 使用 while 语句：
```

i = 10;

```c
// 这部分代码没有执行，因为 i 不小于 10:
while(i < 10) {
    printf("while: i is %d\n", i);
    i++;
}
```

// 使用 do-while 语句：

```c
i = 10;

// 这部分执行了一次，因为循环条件在
// 循环体之后才被检查：
```

```c
do {
    printf("do-while: i is %d\n", i);
    i++;
} while (i < 10);
```

```c
printf("all done!\n");
```

注意，在所有情况下，循环条件都是假的。因此在 `while` 中，循环失败，接下来的代码块永远不会执行。但在 `do-while` 中，条件是在代码块执行后才检查的，因此它至少执行一次。在这种情况下，它打印消息，增加 i，然后条件不通过，继续执行“All done!”的输出。

这个故事的道理是：如果你想让循环至少执行一次，无论循环条件如何，请使用 `do-while`。

# 第 3 章 变量与语句

```c
case 3:
printf("3\n");
break;
```

如果 x == 1，这个 switch 将命中 case 1，它会打印 1，但随后会继续执行下一行代码…… 结果又打印了 1！

最后，我们遇到了一个 break，于是跳出了 switch。

如果 x == 2，那么我们只命中了 case 2，打印 2，并正常执行了 break。

不写 break 被称为“穿透”（fallthrough）。

专家提示：在你打算进行穿透的地方，**务必**在代码中写上注释，就像我上面做的那样。这可以避免其他程序员疑惑你是否是故意那样这么做的。

事实上，这是 C 程序中引入 bug 的常见位置之一：忘记在 case 中放入 break。如果你不想滑入到下一个 case^10，就必须写上它。

早些时候提到过 switch 适用于整数类型——请保持这样。不要在其中使用浮点数或字符串类型。这里有一个“像漏洞一样”的例外：你可以使用字符类型，因为它们本质上也是整数。

```c
char c = 'b';
switch (c) {
case 'a':
printf("It's 'a\n");
break;
case 'b':
printf("It's 'b\n");
break;
case 'c':
printf("It's 'c\n");
break;
}
```

最后，你可以在 switch 中使用枚举，因为它们也是整数类型。关于这点的会在枚举章节详细介绍。

> ^10这被认为是非常危险的，以至于 Go 编程语言的设计者将 break 设置为默认值；如果你想进入下一个 case，必须显式地使用 Go 的 fallthrough 语句。

plus_one 之前的 `int` 表示返回值类型。

int main(void)

    j = plus_one(i); // “调用”
    printf("%i + 1 is %d\n", j);
}
```

## 4.1 值传递（Passing by Value）

我之前提到过，当你把一个参数传递给函数时，会创建该参数的副本并存储在对应的参数中。

如果参数是一个变量，那么该变量的值副本会被创建并存储在参数中。通常情况下，整个参数表达式会被求值并确定其值。该值被复制到参数中。

任何情况下，参数中的值都是它自己的。无论你在调用函数时使用了什么值或变量，情况都是如此。

{

}

{
    int i = 10;
    increment(i);
    printf("i == %d\n", i); // 这会打印什么？
}
```
