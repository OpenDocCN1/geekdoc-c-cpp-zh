## 第三节 – C# 2010 概述

Visual C#，通常称为 C#，是用于创建可执行程序的中间编程语言之一。它是一种面向对象的编程语言，结合了 C++ 的功能和效率、Java 的简洁和面向对象方法以及 Visual Basic 的创造性。与 Java 类似，C# 不使用多重继承和指针，但在运行时提供垃圾回收。此外，与 Java 相比，C# 包含有用的操作，如运算符重载、枚举、预处理器指令、指针和函数指针。它还支持属性的概念。C# 2010 已大幅改进，现在包含新的编译器功能、新语言结构和改进的调试技术。

在编程语言中，语句代表程序中的完整指令。C# 2010 语句由以下部分组成：

- 关键字 – 包括用于与语言（Visual C#）一起工作的预定义单词
- 运算符 – 包括用于执行操作（如加法、减法和乘法）的符号，如 `+`、`-` 和 `*`
- 变量 – 包括用于在程序中存储值的单词或字母
- 字面量 – 表示值，如整数或字符串。
- 常量 – 表示其值不可更改的变量

#### 支持动态数据类型

在 C# 2010 中引入的动态数据类型允许您在运行时为变量分配数据。您可以使用代码中的关键字 `dynamic` 定义此数据类型。动态数据类型的变量可以由任何类型的数据初始化，例如数字、浮点值或字符串数据。以下示例显示了动态数据类型的用法：

```
//Example 1
dynamic intvar = 10;
Response.write(intvar);

//Example 2
dynamic floatVar = 3.7;
Response.write(floatVar);

//Example 3
dynamic stringVar = "dynamicstring";
Response.write(stringvar);
```

由于 `dynamic` 关键字在运行时分配数据；因此，它可与具有运行时属性的 COM 或 JavaScript 一起使用。
