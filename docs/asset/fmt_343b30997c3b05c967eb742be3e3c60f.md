### 表 G.11 为无序关联容器定义的类型

| 类型 | 值 |
| --- | --- |
| `X::key_type` | `Key`，键的类型 |
| `X::key_equal` | `Pred`，一个二元谓词，用于测试两个类型为 `Key` 的参数是否等价 |
| `X::hasher` | `Hash`，一个一元函数对象类型，如果类型为 `Hash` 且 `k` 类型为 `Key`，则结果类型为 `std::size_t` |
| `X::local_iterator` | 与 `X::iterator` 相同类型的迭代器，但只能在单个桶（bucket）中使用 |
| `X::const_local_iterator` | 与 `X::const_iterator` 相同类型的迭代器，但只能在单个桶中使用 |
| `X::mapped_type` | `T`，关联数据的类型（仅适用于 `map` 和 `multimap`） |

除了表 G.10 之外，无序关联容器还需要表 G.12 所示的几个方法。在此表中，`x` 是无序关联容器类，`a` 是类型为 `x` 的对象，`b` 是类型为 `x` 的可能常量，`a_uniq` 是类型为 `unordered_set` 或 `unordered_map` 的对象，`a_eq` 是类型为 `unordered_multiset` 或 `unordered_multimap` 的对象，`h` 是类型 `hasher` 的值，`eq` 是类型 `key_equal` 的值，`n` 是类型 `size_type` 的值，`z` 是类型 `float` 的值。之前，`i` 和 `j` 是指向 `value_type` 元素的输入迭代器，`[i, j]` 是一个有效范围，`p` 和 `q` 是指向 `a` 的迭代器，`q` 和 `q1` 是指向 `a` 的可引用迭代器，`[q1, q2]` 是一个范围，`t` 是 `X::value_type` 的值（可能是一个对），`k` 是 `X::key_type` 的值。此外，`il` 是一个 `initializer_list<value_type>` 对象。

### 表 G.12 为 Sets、Multisets、Maps 和 Multimaps 定义的额外选项

| 操作 | 描述 |
| --- | --- |

## 无序关联容器 (C++11)

表 G.12 为 `Unordered Sets`、`Multisets`、`Maps` 和 `Multimaps` 定义的额外操作。

| 操作 | 描述 |
| --- | --- |
| `X(i, j, n, hf, eq)` | 构建一个包含至少 `n` 个桶的空容器，使用 `hf` 作为哈希函数，`eq` 作为相等性谓词，并插入 `[i, j]` 中的元素。如果省略 `eq`，则使用 `key_equal()` 作为键相等性谓词。如果 `hf` 也被省略，则使用 `hasher()` 作为哈希函数。如果 `n` 也省略，则使用未指定的桶数量 |
| `a(i, j, n, hf, eq)` | 构建一个包含至少 `n` 个桶的空容器 `a`，使用 `hf` 作为哈希函数，`eq` 作为相等性谓词，并插入 `[i, j]` 中的元素。如果省略 `eq`，则使用 `key_equal()` 作为相等性谓词。如果 `hf` 也被省略，则使用 `hasher()` 作为哈希函数。如果 `n` 也省略，则使用未指定的桶数量 |
| `b.hash_function()` | 返回 `b` 使用的哈希函数 |
| `b.key_eq()` | 返回构建 `b` 时使用的相等性谓词 |
| `b.bucket_count()` | 返回 `b` 中桶的数量 |
| `b.max_bucket_count()` | 返回 `b` 可能包含的桶数量的上界 |
| `b.bucket(k)` | 返回包含与 `k` 等效的项的桶索引 |
| `b.bucket_size(n)` | 返回索引为 `n` 的桶中的元素数量 |
| `b.begin(n)` | 返回指向索引为 `n` 的桶第一个元素的迭代器 |
| `b.end(n)` | 返回指向索引为 `n` 的桶的结束（past-end）元素的迭代器 |
| `b.cbegin(n)` | 返回指向索引为 `n` 的桶第一个元素的常量迭代器 |
| `b.cend(n)` | 返回指向索引为 `n` 的桶的结束（past-end）元素的常量迭代器 |
| `b.load_factor()` | 返回每个桶的平均元素数量 |
| `b.max_load_factor()` | 返回作为负载因子上限的值；如果负载因子超过此值，容器将增加桶的数量 |
| `b.max_load_factor(z)` | 可能会更改最大负载因子，使用 `z` 作为新值 |
