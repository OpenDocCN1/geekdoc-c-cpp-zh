The integration of SQL Server 2008 with .NET Framework 4.0 CLR allows you to create a user-defined aggregate function in .NET Framework and make it accessible to Transact-SQL or other managed code. You can create a user-defined aggregate function as a CLR object by using the `SqlUserDefinedAggregate` attribute and aggregation contract methods. The `SqlUserDefinedAggregate` attribute is a class, which belongs to the `Microsoft.SqlServer.Server` namespace, and used to indicate that the current type should be registered as a user-defined aggregate. The aggregation contract methods include `Init`, `Accumulate`, `Merge`, and `Terminate` that are used to save the intermediate states of an aggregate function. Table 23.5 describes the aggregation contract methods:

## Table 23.5: Aggregation Contract Methods

| Method | Description | Syntax |
|---|---|---|
| `Init()` | Initializes the computation of the aggregation function. It cleans up the data of previous computation and re-starts a new aggregate computation. The `Init()` method is used once for a set of values for which an aggregate function is used. | `public void Init(){}` |
| `Accumulate()` | Collects the aggregate values. The `Accumulate()` method is used once for each value in a group of values for which an aggregate function is used. Finally, create a user-defined aggregate function that uses the `CREATE AGGREGATE` statement and the reference of registered assembly.

## Exploring UDFs

`UDF` is a function that takes parameters, perform calculations, and return a result in the form of a single value or a result set. Functions can be divided into two categories, scalar functions and table-valued functions. These categories of functions are described as follows:

- Scalar functions — Returns a single value, such as numbers, floating points, Booleans, and strings
- Table-valued functions — Returns a set of rows from a table

Listing 23.4 shows an example of a UDF:

## Listing 23.4: Showing an Example of a UDF

```
CREATE FUNCTION RectArea(@RectLength decimal(4,1), @RectWidth decimal(4,1))
RETURNS decimal(8,2)
AS
BEGIN
RETURN ( @RectLength * @RectWidth )
END
```

In Listing 23.4, we are creating a UDF, `RectArea`, with two parameters, `RectLength` and `RectWidth`. The `RectArea` function is created to calculate the area of any item having the rectangular shape. Now, let’s use the `RectArea` UDF in a SQL query to create a table, as shown in Listing 23.5:

## Listing 23.5: Showing a Query to Create a Table Using a UDF

```
CREATE TABLE Papers
(
    PaperID int PRIMARY KEY,
    PaperLength decimal(4,1),
    PaperWidth decimal(4,1),
    PaperArea AS
        (
            dbo.RectArea(PaperLength, PaperWidth)
        )
)
```

In Listing 23.5, we are creating a table, named `Papers`, with four columns: `PaperID`, `PaperLength`, `PaperWidth`, and `PaperArea`. The `PaperArea` column is using the `RectArea` function, which is already created in T-SQL (given in Listing 23.4), to calculate the area of a paper in rectangular shape.

## Exploring UDT

`UDT` is a customized type, which is a collection of other data types, data values, or methods. In SQL, there are various built-in data types, such as Integer, Varchar, and Decimal. You can combine these built-in data types into groups to create customized type with specific capabilities. In SQL Server 2008, you can create a UDT by using the `sp_addtype` stored procedure. An example of UDT in SQL Server 2008 is given as follows:

```
EXEC sp_addtype StudentID 'CHAR(10)', 'NOT NULL'
```
