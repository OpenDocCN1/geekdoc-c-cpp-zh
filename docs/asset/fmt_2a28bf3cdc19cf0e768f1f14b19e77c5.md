# 前言

当人们看到一本标题中带有“统计计算”的书时，最可能的预期是对与数值分析有紧密联系的主题探讨。本文的陈述偏离了这种经典的重点，其目标是提供对统计计算的处理，为研究环境中的原始代码开发奠定基础。

统计方法论的进步现在与计算机的使用不可分割地联系在一起。新的方法论想法必须翻译成可用代码，并与竞争程序进行评估。

现代统计学家对计算需要了解什么？我们认为他们至少需要理解算法思维的基本原理。将数学问题转化为其计算类比是一项必须学习的技能。了解计算如何工作也是重要的，以避免或识别由例如有限精度算术引起的常见陷阱。

也许最基本的技能是提供一种与计算机通信手段——通过语言。然而，许多统计文本侧重于非特定语言的通用进展。我们认为，从翻译伪代码转换为实际执行计算并生成输出的内容中可以获益匪浅。C++ 和 R 的每一个方面都考虑了尽可能减少这一任务。

可以说，R 语言在统计研究方面是事实上的标准。R 是一种非常函数化的语言，恰好拥有内置工具可以执行一些标准以及非标准的统计计算。我们采取后观点，并主要关注描述 R 语言的函数和面向对象的特性。

我们认为，对于任何工作涉及方法论开发的统计学家来说，良好的 R 知识是必须的。我们还认为 R 并不适用于解决出现的所有计算问题；因此，使用 C++ 并不排除使用 R。

## 第一章

## 引言

定义 1.1. 计算统计学是针对统计学问题开发和应用计算方法。

计算统计学可以将统计学领域产生的数学问题，转换成可以使用计算机进行处理的形式。这种转换通常表现为*算法*的形式，它代表了为了提供所需的解决方案而必须进行的计算的逐步描述。

为了进行科学计算，需要“精通”一种有效的编程语言。对于统计学来说，R 提供了一种非常流行的语言。它提供了一种开源计算环境，与贝尔实验室开发的 S 语言有紧密联系。S 的商业实现以 S-Plus 的名称提供。

R 能够胜任这项工作。R 本身就是一种强大的语言，从我们定义的意义上，它非常适合解决许多计算统计学问题。

R 非常擅长它的设计初衷。但并不是所有的统计问题都可以使用 R 来解决。有很多编译语言可以作为 R 的补充，反之亦然。标准选择包括 C、C++、Fortran 和 Java。R 语言的大部分依赖于调用 C 代码，令人惊讶的是将 C 程序导入 R 是相对直接的。C++ 也是如此，且后者还有一个额外特性，即 R 本身具有面向对象的结构。因此，单独使用或结合使用 R 和 C++ 来为计算统计学提供计算机接口组件似乎是很自然的。这也是本文将遵循的路径。

## 2 编程范式

## 引言

计算机语言的目的是在用户和计算机之间提供一种“通信”的途径。创建此类途径有很多方法，每种语言在执行此任务的特定方式上会有不同。

计算机编程语言有时被归类为命令式或声明式。区别在于程序是指定了一系列要执行的语句序列，还是指定了一系列定义和要求序列，而不直接指定如何实现它们。命令式语言通常是过程化的，允许人们将过程构建为可执行语句，这些语句可以从程序中的各个点重复执行。过程化语言的示例有 C、C++、Java、COBOL 和 Fortran。

从历史上看，计算机编程始于使用以原生二进制格式指令给计算机的机器码。随后是汇编语言，它提供了带有快捷符号的特定二进制指令，通过汇编器翻译成机器码。过程化语言通过允许使用与程序所需动作相关的标准单词、短语和数学表达式来开发代码，提供了下一次重大进展。此类类型的语言使用编译器将命令翻译成计算机可以理解的二进制序列。

过程化编程将问题分解，允许使用标准单词、短语和数学表达式来开发代码。

### 1.2 面向对象编程

本节对面向对象编程 `OOP` 概念进行高级介绍。

OOP 的重点是创建类。类通过对其属性和行为的提供了概念的抽象描述。对于科学计算，“概念”通常代表一种数学运算，如求解方程组、生成随机数或寻找函数的最小值。

类的属性是它的成员和成员函数。方法通常属于原始数据类型。然而，它们在意义上也可以更具抽象性，即派自其他用户创建的类型或类。如前节所述，一个为成员赋予了值的类实例被称为对象。

类的行为取决于类方法，这些方法决定了它可以执行的操作类型以及对象被修改的方式。类成员可以被分类为私有、公共或受保护。私有标记的后果是此类成员和方法只能在类内部使用。成员和方法对外部函数和其他对象开放。受保护的类成员和方法对继承该类的派生类对象可用。

OOP 方法为我们提供了多种类型的多态。“多态性”一词意味着同一个事物有不同的形式。在 OOP 的语境下，这翻译为根据情况以不同方式作用或行为的函数和类。

作为函数参数或对象构造提供的数据类型。在 C++ 中，多态通过 1) 函数重载，2) 模板类和 3) 虚函数实现。

函数重载发生在存在多个同名但参数不同的函数时。在 C++ 中，我们可以利用这一机制创建乘法、矩阵标量乘法、矩阵-向量乘法等方法，这些方法通过通常用于标量乘法的 `*` 运算符调用。

“模板”一词代表了一种结构化的格式，可以用于用于重复的相似应用程序。面向对象编程中的类模板和函数模板的行为与模板的概念类似。“空白处”的作用由指定数据类型的参数承担。例如，使用此类输入/输出操作可以使其直接且恰当地适用于整数、浮点值、字符或字符字符串。从这个意义上说，模板提供了一族类或函数，其元素通过参数的可能值进行索引。

继承是面向对象语言的一种特性，允许从基类构建新类。新类或派生类继承基类的公共成员和方法，并在必要时对它们进行修改以产生多态行为。

到此为止，已经学习并描述了一些新词汇。后续章节的内容旨在为此处所描述的通用 OOP 概念提供一些深度。

## 1.3 展望

下一章从讨论计算机如何表示数字开始。计算机只有有限内存的这一事实给处理无理数带来了问题。精确存储需要无限的内存位置，因此有必要妥协并接受近似表示。这导致了对舍入误差以及使用浮点算术其他后果的讨论。

关于舍入误差的一点建议是“使用双精度并不要担心它”。这条建议的糟糕之处不在于使用“双精度”，这在大多数设置下无疑良好的做法。相反，问题在于认为增加精度可以解决所有的数值问题，并允许对整个舍入问题采取草率的态度。
