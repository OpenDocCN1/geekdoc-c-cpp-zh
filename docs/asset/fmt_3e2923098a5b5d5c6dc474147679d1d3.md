#include <stdio.h>

# 示例 10

一个使用指针的 C 程序，用于检查给定字符串是否为回文。

# 解决方案

我们知道，一个字符串如果从右向左读取生成的字符串相同，那么它就是一个回文。例如，

L I R I L

从右向左读 ---> 从右向左

同样注意，当字符串反转时，也会得到相同的字符串。

为了获取字符串的反转，使用指针指向字符串的最后一个字符。指针递减 1 以指向下一个字符。重复此过程，直到获得字符串的反转形式。

```c
#include <stdio.h>
#include <conio.h>
#include <string.h>
main() {
    char *st,*rst;
    int i,j;
    clrscr();
    /* 为字符串分配动态内存*/
    st = (char*)malloc(80);
    rst = (char*)malloc(80);
    printf("\n 输入一个字符串 : ");
    gets(st);
    /* 反转字符串的循环 */
    i = strlen(st) - 1;
    j = 0;
    while(i >= 0)
{
  *(rst+j) = *(st+i);
  j++;
  i--;
  *(rst+j) = '\0';
  if (strcmp(st,rst) == 0)
    printf("\n %s 是回文字符串",st);
  else
    printf("\n %s 不是回文字符串",st);
}
getch();
```

当执行此程序时，用户必须输入一个字符串。字符串被反转，结果经过比较并所示。
