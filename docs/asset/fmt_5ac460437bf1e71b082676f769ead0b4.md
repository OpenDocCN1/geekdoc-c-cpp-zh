## 使用 Enzyme 进行单元测试

`Enzyme`¹¹¹ 是 Airbnb 提供的一种测试工具，用于断言、操作和遍历你的 React 组件。你可以使用它进行单元测试，以补充你在 React 中的快照测试。

让我们看看如何使用 `enzyme`。你首先需要安装它，因为它没有随默认的 `create-react-app` 一起提供。它还带有一个在 React 中使用它的扩展。

## 命令行

```
npm install --save-dev enzyme react-addons-test-utils enzyme-adapter-react-16
```

现在，你需要将其包含在测试设置中并初始化它的 Adapter 以在 React 中使用。

### src/App.test.js

```javascript
import React from 'react';
import ReactDOM from 'react-dom';
import renderer from 'react-test-renderer';
import Enzyme from 'enzyme';
import Adapter from 'enzyme-adapter-react-16';
import App, { Search, Button, Table } from './App';

Enzyme.configure({ adapter: new Adapter() });
```

现在你可以在 `Table` 的 `"describe"` 块中编写第一个单元测试。你将使用 `shallow()` 来渲染你的组件，并断言 `Table` 有两个项目。

再次运行你的测试，查看测试是成功还是失败。它们应该是通过的。一旦你更改了 `App` 组件中渲染块的输出，快照测试就会失败。然后你可以决定是更新快照还是在你的 `App` 组件中进行调查。

基本上 `renderer.create()` 函数创建了你的 `App` 组件的快照。它进行虚拟渲染并将 DOM 存储在快照中。之后，当你最后一次运行快照时，该快照预计与之前的快照匹配。通过这样，你可以确保你的 DOM 保持不变，不会意外更改任何内容。
