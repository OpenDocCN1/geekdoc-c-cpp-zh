# 排序排序

```
PROC MEANS DATA=SAS-data-set
<options statistics>;

VAR variable(s);
RUN;
```

```
PROC SORT DATA=input-data-set
<OUT=output-data-set>;
BY <DESCENDING> by-variables;
RUN;
```

```
PROC FREQ DATA=SAS-data-set <options>;

RUN;
```
