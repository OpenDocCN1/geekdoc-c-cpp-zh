# 数值

将字符串转换为数值值。

C++11 提供了将字符串转换为数值值的八函数，如 `stoi`、`stol`、`stoul`、`stoll`、`stof`、`stod`、`stold` 和 `stoull`。这些函数都接收三个参数：

- 包含要转换字符的字符串。
- 指向 `size_t` 变量的指针，函数在此存储第一个未转换字符的索引。默认是空指针，在这种情况下函数不存储索引。
- 表示基数的 `int`，默认为 10。
