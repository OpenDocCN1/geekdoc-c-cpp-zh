# 小数的转换

- 0.250 乘以 2，得到 0.50。
- 0.50 乘以 2，得到 1.0。这里整数部分为 1。

注意，这个乘法过程持续持续直到小数部分变为 1 或达到所需的位数。将 0.4 转换为其二进制等值：

- 0.4 乘以 2，得到 0.8。
- 0.8 乘以 2，得到 1.6。整数部分为 1。
- 0.6 乘以 2，得到 1.2。整数部分为 1。
- 0.2 乘以 2，得到 0.4。整数部分为 0。
- 0.4 乘以 2，得到 0.8。
