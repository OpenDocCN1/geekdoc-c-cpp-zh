## 库

库在 C 语言中非常重要，因为 C 语言只支持它需要的最基础的功能。C 语言甚至不包含从键盘读取和写入屏幕的 I/O 函数。任何超出基础语言的内容必须由程序员编写。生成的代码块通常放在库中，以便于重复使用。我们已经见过了标准 I/O 即 `stdio` 库。标准库为标准 I/O、数学函数、字符串处理、时间操作等提供了标准支持。你可以在自己的程序中使用库将你的程序拆分成模块。这使得它们更容易被理解、测试和调试，同时也使得复用你编写其他程序的代码成为可能。

你可以轻松地创建自己的库。作为一个示例，我们将从之前的文章中取一些代码，并将其函数创建一个库。这是我们将开始的代码：

```c

int a[MAX];
int rand_seed = 10;

int rand(void)
/*
 * K&R 产生一个 0 到 32767 之间的整数随机数。
 */
{
    rand_seed = rand_seed * 11035245 + 12345;
    return (unsigned int)(rand_seed / 65536) % 32768;
}

int main(void)
{
    int i, t, x, y;
    /* 填充数组 */
    for (i = 0; i < MAX; i++)
    {
        a[i] = rand();
        printf("%d\n",a[i]);
    }
    /* 对数组进行冒泡排序 */
    for (x = 0; x < MAX-1; x++)
    {
        for (y = 0; y < MAX-x-1; y++)
        {
            if (a[y] > a[y+1])
            {
                t = a[y];
                a[y] = a[y+1];
                a[y+1] = t;
            }
        }
    }
    /* 打印排序后的数组 */
    printf("----------------------\n");
    for (i = 0; i < MAX; i++)
    {
        printf("%d\n",a[i]);
    }
    return 0;
}
```

## Makefiles

反复输入所有的 `gcc` 命令可能非常麻烦，特别是当你对代码进行大量修改且它有多个库时。`make` 工具解决了这个问题。你可以使用下面的 `makefile` 来替换上面的编译序列：

```
main: main.o util.o
    gcc -o main.o util.o
main.o: main.c util.h
    gcc -c -g main.c
util.o: util.c util.h
    gcc -c -g util.c
```

将此内容输入名为 `makefile` 的文件中，并输入 `make` 来构建可执行文件。注意，你必须在所有 `gcc` 行之前加上一个制表符 `tab`。八个空格是不够的——必须是制表符。所有其他行必须左对齐。

此 `makefile` 包含两种行。左对齐的行是依赖行。 以制表符前面的行是动作行，可以包含任何有效的 UNIX 命令。依赖行表示某些文件依赖于其他一组文件。例如，`main.o: main.c util.h` 表示文件 `main.o` 依赖于文件 `main.c` 和 `util.h`。如果这两个文件发生变化，应该执行后续的可行来重新生成 `main.o`。

注意，整个 `makefile` 生成的最终可执行文件是 `main`，位于 `makefile` 的第 1 行。`makefile` 的最终结果始终位于第 1 行，在这个 `makefile` 中，这表示文件 `main` 依赖于 `main.o` 和 `util.o`。如果其中任何一个发生变化，执行行 `gcc -o main.o util.o` 来重新生成 `main`。

可以在依赖行下方放置多行要执行的内容——它们都必须以制表符开头。一个大型程序可能有多个库和一个主程序。`makefile` 会自动重新编译由于更改而需要重新编译的所有内容。

如果你不在 UNIX 机器上工作，你的编译器几乎肯定具有等于 `makefile` 的功能。阅读你的编译器的文档以学习如何使用它。

## 指针基础

为了理解指针，将它们与普通变量进行比较会有帮助。

“普通变量”是内存中一个可以存储值的位置。例如，当你声明一个变量 `i` 为整数类型时，系统会为它分配四个字节的内存。在你的程序中，你通过名称 `i` 来引用该内存位置。在机器层级，一个位置有一个内存地址。对于你程序员来说，该地址上的四个字节被命名为 `i`，而这四个字节可以存储一个整数值。

指针是一个指向另一个变量的变量。这意味着指针持有另一个变量的内存地址。换句话说，指针在传统意义上并不持有值；相反，它持有另一个变量的地址。指针通过持有该变量地址的副本来“指向”另一个变量。

由于指针持有的是地址而不是值，因此包含两个部分。指针本身持有地址，而该地址指向一个值。这包含了指针本身和被指向的变量。在你不熟悉它之前，这个事实可能会让你感到困惑，但它会变得极其强大。

下面的示例代码展示了一个典型的指针：

```c
#include <stdio.h>

int main(void) {
    int i, j;
    int *p; /* 一个指向整数的指针 */
    p = &i;
    *p = 5;
    j = i;
    printf("%d %d\n", i, j, *p);
    return 0;
}
```

该程序中的第一个声明定义了两个名为 `i` 和 `j` 的普通整数变量。`int *p` 这一行声明了一个名为 `p` 的指针。这一行要求编译器：

## 指针：RAM 地址

声明一个变量 `p`，它是指向整数的指针。`*` 表示声明的是指针而不是普通变量。你可以创建任何种类型的指针：浮点型、结构体、字符等。只需使用 `*` 来表示你需要一个指针而不是普通变量即可。

`p = &i;` 这一行对你来说是非常明确的。在 C 语言中，`&` 被称为地址运算符。表达式 `&i` 的意思是“变量 `i` 的内存地址”。因此，表达式 `p = &i` 的意思是“将 `i` 的地址赋值给 `p`”。一旦执行此语句，`p` 就“指向”了 `i`。`p` 包含一个随机且未知的地址，这会导致段错误或类似的程序崩溃。

在上面的程序中，变量 `i`、`j` 和 `p` 已经被声明，但这三个变量都没有被初始化。一旦 `p` 指向 `i`，该内存位置就有两个名称。它仍然被称为 `i`，但现在也被称为 `p`。这就是 C 语言描述指针变量的两个部分的方式：`p` 是持有地址的位置，而 `*p` 是该地址指向的位置。因此，`*p=5` 意味着 `p` 指向的位置应该设置为 5。由于 `*p` 的位置也是 `i`，所以 `i` 也取了值 5。结果，`j = i` 将 `j` 设置为 5，`printf` 输出 `5 5 5`。

指针的主要特征是它的双部分性质。指针本身持有一个指向特定类型值的地址——即它所持有的地址所对应的值。在这种情况下，指针指针本身是 `p`。所指向的值是 `*p`。
