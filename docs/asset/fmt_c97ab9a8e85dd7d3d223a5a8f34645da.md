## 7.9. 交替时间比确定性时间更强大

我们分析了 `ACCEPT` 过程的复杂度。对于任意配置 `C`，令 `T_C` 为从 `C` 可达的配置集。定义 `depth(C)` 为最小的 `k`，使得存在 `T_C` 的一个前缀 `T'`，使得 `T'` 接受 `T'` 中的每条路径，且 `T'` 中每条路径的交替次数最多为 `k`。特别，如果 `x` 被 `M` 接受，则 `depth(C_0)` 最多为 `a(i)`，`C_0` 为初始配置。令 `W(k)` 为该过程在输入 `C` 时执行 `ACCEPT(C)` 所需的（交替）时间。则有：

```
W(k) = O(s) + max{log W(k-1)}
```

为了证明这一点，`C` 是一个 `MAX`（或 `MIN`）配置。那么 `O(s)` 是存在性（或全称性）选择从 `C` 可达的配置 `C'` 所需的时间；`log/s` 是判定 `REACH` 的时间；而 `W(k-1)` 是递归执行 `ACCEPT(C)` 所需的时间。很容易判断出在给定以下条件下 `W(k)` 有解：

```
W(k) = O(s + [k + log t/s])
```

定理得得结论。

## 7.9 交替时间比确定性时间更强大

本节证明了以下重要结果：

**定理 27。** 对于所有 `t`，`DTIME(t) <= ATIME(t/log t)`。

Tompa 和 Dyman [6] 通过引入 Hopcroft, Paul 和 Valiant [12] 的结果得到了这一结论，该结果显示了 `DTIME(t) <= DSPACE(t/log t)`。Adleman 和 Lui [1] 为 Hopcroft-Valiant 结果提供了一个有趣的证明。他们首次证明了在通用计算（多带图灵机）中，空间比时间更强大的资源。对于受限的计算模型，Paterson [17] 已经证明对于图灵机空间比时间更强大。定理 27 也是 Paul 和 Reisch 的结果，他们在定理中使用交替时间 `O(t log t / log log t)` 模拟了时间，除此之外，常规模型足够。

- (i) 没有从 `V_b`（“下方”节点）到 `V_a`（“上方”节点）的边。`G` 中所有跨越 `V_a` 和 `V_b` 的边都必须从上方指向下方。令 `G_a, G_b` 分别为由 `V_a, V_b` 诱出的子图。

- (ii) `V_b` 中的边数 `m_b` 满足：

```
m/(2 - log m) <= m_b <= m/(2 - log m) + d
```

为了证明这种划分存在，我们提供一种构造方法。从 `V_a` 为空集开始，不断向 `V_a` 中添加节点，直到 `G_a` 的边的顺序满足不等式（这是可能的），`V_a` 中每个新增的节点最多增加 `d` 条边。考虑三种情况：

**情况 1：** 假设目标节点 `i` 在 `V_a` 中。那么 `(G_a, i)` 的铺石树也是 `(G, i)` 的铺石树。该树的铺石时间至少为：

> `P(m - m_b) <= P(m/2 + m/log m)`

在其余情况下，假设 `i \in V_b`。

**情况 2：** 假设 `|B| < 2m/log m`。那么为 `(G, i)` 构造如下铺石树 `T`。`T` 根节点的铺石时间为 `B \cup {i}`。在根的每个节点 `u` 上，我们考虑两种可能性。如果失败节点是 `i` 中的 `u`，则我们构造一个铺石时间为 `P(m/2 + m/log m)` 的 `(G, i)` 铺石树。否则，失败节点是 `i_0`，我们归纳地构造一个铺石时间为 `P(m/2 - log m + d)` 的 `(G, i_0)` 铺石树。这得到了一个铺石时间至少为 `(G, i)` 铺石树：

> `2m/log m + P(m/2 + m/log m)`

**情况 3：** 假设 `|B| >= 2m/log m`。考虑一个铺石时间为 `P(m/2 - log m + d)` 的 `(G_b, i_0)` 铺石树 `T_b`。我们将 `T_b` 构造为 `(G, i)` 的铺石树；令 `u` 为 `T_b` 中改变节点 `i` 的任意叶子节点。根据 `T_b` 的定义，`i` 在 `G_b` 中的前驱包含在 `C(u)` 中。但 `G` 中可能存在不在 `G_b` 中的铺石：令 `X` 为 `u` 处的铺石集合，并为 `u` 创建 `|X| <= d` 个子节点。`u` 的每个子节点都有一个改变节点 `j \in V_a`。我们可以附加一个 `(G_a, j)` 的铺石树。注意 `G_a` 拥有 `m - m_b - |B| <= (m/2) - (log m)` 条边，至少有 `|B| >= 2m/log m` 条边。

## 7.9. 交替更多确定性时间

从 `V_a` 到 `V_b` 的边没有在 `G_a` 或 `G_b` 中被计算。因此，`T` 的铺石时间最多为 `P(m/2 - log m)`。这完成了对 `(G, i_0)` 铺石树的描述。该树的铺石时间等于 `T_b` 的铺石时间加上 `T` 的铺石时间，最多为 `2P(m/2 + m/log m) + d`。取这些情况的最坏情况，得到：

```
P(m) <= max{P(m/2 + m/log m) + 2m/log m, 2P(m/2 + m/log m) + d}
```

我们想要证明存在一个常数 `c`，使得对于 `m'`，`P'(m') <= cm'/log m'`。通过使 `c` 足够大，我们可以假设已经建立了对于 `m`。归纳地，我们有以下推导：

```
P(m/2 + m/log m) + 2m/log m = P(am) + 2m/log m （其中 a = 1/2 + 1/log m）
<= cm/log(am) + 2m/log m
<= cm/log(am) + (a log m - 2)/log m
<= cm(1 - 1/log m)/(log m - 1) + d
<= cm(log m - 2)/(log m - 1) + d
<= cm/log m
```

我们还有：

```
P(m/2 + m/log m) + d <= 2c/(m/log m - m/log m) + d
<= cm/(log(m/log m) - m/log m) + d
<= cm(1 - 1/log m)/(log m - 1) + d
<= cm/log m
```

现在我们可以证明主结论，即耗时为 `t` 的确定性 `M` 可以在 `O(t/log t)` 时间内模拟。应用该引理，我们可以回顾到使用阻塞因子 `B` 计算 `M` 时，图 `G` 有有界的入度。为了解决这个问题，我们可以在节点 0 处放置一个铺石，图的其他部分实际上是有界的。证毕。
