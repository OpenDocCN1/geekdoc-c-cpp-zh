# 自动字符到数值转换

当字符值被用于数值上下文时，SAS 会自动将其转换为数值值，例如：
- 赋值给数值变量
- 算术运算
- 与数值比较
- 接收数值参数的函数

`WHERE` 语句和 `WHERE=` 不执行任何自动转换。

# 自动字符到数值转换

自动转换 `informat` 会从不符合标准的字符值产生数值缺失值。

# `INPUT` 函数

`INPUT` 函数返回使用指定 `informat` 读取源时产生的值。

```sas
data conversions;
CV1='32000';
CV2='32000';
CV3='032008';
CV4='030508';
Var1=input(CV1,5.);
Var2=input(CV2,comma.);
Var3=input(CV3,date.);
Var4=input(CV4,ddmm.);
run;
```

如果你使用 `INPUT` 函数创建一个之前未定义的变量，该变量的类型和长度由 `informat` 定义。
