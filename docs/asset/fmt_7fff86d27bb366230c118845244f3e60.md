## 交互式控制 Storyboard

`Storyboard` 在 `WPF` 中是提供对象及其属性信息给其动画的容器时间线。要使用 `Storyboard` 时间线为属性设置动画，你应该为要设置动画的每个属性创建一个动画，并创建一个包含动画的 `Storyboard` 对象。正如你在本章的 `In Depth` 部分中已经学到的，可控的 `Storyboard` 可以开始、停止、暂停、恢复、查找、停止和移除。你可以通过 `XAML` 代码和代码后置代码控制 `Storyboard` 时间线。

### 使用 XAML 代码控制 Storyboard

控制 `Storyboard` 时间线的常见做法是通过 `XAML` 代码。要在 `XAML` 中启动 `Storyboard` 时间线，可以使用 `BeginStoryboard` 属性和 `EventTrigger` 对象。`BeginStoryboard` 属性启动 `Storyboard` 时间线。`EventTrigger` 对象帮助你实现由 `BeginStoryboard` 属性启动的动画。让我们创建一个通过 `XAML` 代码控制 `Storyboard` 时间线的应用程序。为此，创建一个名为 `Storyboard_XAML` 的 `WPF` 应用程序（也在 `CD` 上提供）并将清单 12.29 中的代码添加到 `MainWindow.xaml` 文件中：

### Listing 12.29: Controlling Storyboard through the XAML Code

```xml
<Window x:Class="Storyboard_XAML.MainWindow"
xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
Title="MainWindow" Height="300" Width="500">
    <Grid>
        <Ellipse Height="57" Margin="10,26,0,0" Name="Circle" Stroke="Black" VerticalAlignment="Top" HorizontalAlignment="Left" Width="70" Fill="Aqua"/>
        <Button HorizontalAlignment="Left" Margin="10,0,0,34" Name="Start" Width="75" Height="23" VerticalAlignment="Bottom">Start</Button>

        <Button Height="23" Margin="210,0,193,34" Name="Resume" VerticalAlignment="Bottom">Resume</Button>
        <Button Height="23" HorizontalAlignment="Left" Margin="355,0,0,34" Name="SkipToFill" VerticalAlignment="Bottom" Width="75">SkipToFill</Button>

                <PauseStoryboard BeginStoryboardName="BeginAnimation"/>
            </EventTrigger>

            </EventTrigger>
```
