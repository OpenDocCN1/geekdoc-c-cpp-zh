## Q2. 计算圆面积和周长的 C 程序

**解决方案：**

```
****************************************************************
FILE NAME: prog2.c
AUTHOR DETAILS: Mr. X, 1ST SEM, COMP.SC& ENGG., ABC COLLEGE OF ENGG.
DATE OF PROGRAM EXECUTION: 31/7/2015
NAME OF THE PROGRAM: c program to calculate the area and perimeter of a circle
****************************************************************
```

```c
#include <stdio.h>
#include <conio.h>
#define PI 3.14 /* symbolic constant */

void main(void)
{
    float x, y, z;
    clrscr();
    printf("Input the radius of circle:");
    scanf("%f", &x);
    y = PI * x * x;
    z = 2 * PI * x;
    printf("The area of circle is:%5f\n", y);
    printf("The perimeter of circle is:%5f\n", z);
    getch();
}
```

**输出：**

```text
Input the radius of circle: 2.0
The area of circle is: 12.56
The perimeter of circle is: 12.56
```

**解释：**

这里用户输入半径 2.0，然后应用公式计算面积，即 `3.14 * x * x`；计算周长的公式为 `2 * 3.14 * x`。这里声明了 `PI` 常量而不是直接使用 3.14，使用常量是为了避免重复输入 3.14。`PI` 被乘以两次，面积结果存储在 `y` 中，周长结果存储在 `z` 中，最后打印 `y` 和 `z` 获取结果。

## Q3. 计算矩形面积和周长的程序

```
****************************************************************
FILE NAME: prog3.c
AUTHOR DETAILS: Mr. X, 1ST SEM, COMP.SC ENGG., ABC COLLEGE OF ENGG.
DATE OF PROGRAM EXECUTION: 31/7/2015
NAME OF THE PROGRAM: c program to calculate the area and perimeter of a rectangle
****************************************************************
```

```c
#include <stdio.h>
#include <conio.h>

void main(void)
{
    float x, y, z, m;
    clrscr();
    printf("Input the length, breadth of a rectangle:");
    scanf("%f%f", &x, &y);
    z = x * y;
    m = 2 * (x + y);
    printf("The area of rectangle is:%5f\n", z);
    printf("The perimeter of rectangle is:%5f", m);
    getch();
}
```

**输出：**

```text
Input the length, breadth of a rectangle: 3.0 2.0
The area of rectangle is: 6.0
The perimeter of rectangle is: 10.0
```

**解释：**

用户通过 `scanf()` 函数输入长度存入变量 `x`，宽度存入变量 `y`。计算矩形面积的公式是长 * 宽，因此 `x` 乘以 `y`，结果存储在变量 `z` 中。然后计算周长，将长宽之和乘以 2，即 `2 * (x + y)`，结果存储在变量 `m` 中。最后打印 `z` 和 `m` 获取结果。

## Q7. 使用第三变量交换两个数字的 C 程序

**解决方案：**

```
****************************************************************
FILE NAME: prog7.c
AUTHOR DETAILS: Mr. X, 1ST SEM, COMP.SC& ENGG., ABC COLLEGE OF ENGG.
DATE OF PROGRAM EXECUTION: 31/7/2015
NAME OF THE PROGRAM: c program to swap/exchange two numbers using third variable
****************************************************************
```

```c
#include <stdio.h>
#include <conio.h>

void main(void)
{
    int x, y, z;
    clrscr();
    printf("Input the two integer numbers to be swapped:");
    scanf("%d%d", &x, &y);
    /* 使用第三变量交换的逻辑 */
    z = x;
    x = y;
    y = z;
    printf("After swapping/exchanging the two integer numbers are: %d %d", x, y);
    getch();
}
```

**输出：**

```text
Input the two integer numbers to be swapped: 5 6
After swapping/exchanging the two integer numbers are: 6 5
```

**解释：**

使用第三变量交换两个数字的逻辑：

```
Step 1: z = x;
Step 2: x = y;
Step 3: y = z;
```

假设 `x = 5`, `y = 6`, `z` 是第三变量，用于临时存储数据。
`z = x`，即 `x` 的值赋给 `z`，所以 `z = 5`。
`x = y`，即 `y` 的值赋给 `x`，所以 `x = 6`。
`y = z`，即 `z` 的值赋给 `y`，所以 `y = 5`。
应用该逻辑后，`x` 的值变为 6，`y` 的值变为 5。

## Q8. 不使用第三变量交换两个数字的 C 程序

**解决方案：**

```
****************************************************************
FILE NAME: prog8.c
AUTHOR DETAILS: Mr. X, 1ST SEM, COMP.SC& ENGG., ABC COLLEGE OF ENGG.
DATE OF PROGRAM EXECUTION: 31/7/2015
NAME OF THE PROGRAM: c program to swap two numbers without using third variable
****************************************************************
```

```c
#include <stdio.h>
#include <conio.h>

void main(void)
{
    int x, y;
    clrscr();
    printf("Input the two numbers to be swapped:\n");
    scanf("%d%d", &x, &y);
    /* 不使用第三变量交换的逻辑 */
    x = x + y;
    y = x - y;
    x = x - y;
    printf("After swapping/exchanging the numbers are: %d %d", x, y);
    getch();
}
```

**输出：**

```text
Input the numbers to swapped: 3 4
After swapping/exchanging the numbers are: 4 3
```

**解释：**

不使用第三变量交换两个数字的逻辑：

```
Step 1: x = x + y;
Step 2: y = x - y;
Step 3: x = x - y;
```

示例：`x = 3`, `y = 4`
Step 1: `3 + 4 = 7` (`x` 变为 7)
Step 2: `7 - 4 = 3` (`y` 变为 3)
Step 3: `7 - 3 = 4` (`x` 变为 4)
因此交换了 `x = 4` 和 `y = 3` 的值。
