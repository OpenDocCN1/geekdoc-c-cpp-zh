    get

    {

        return <var>;

    }

    set

```

}
```

在前面的代码片段中，需要注意的重要一点是 `value` 关键字。`value` 的类型与属性本身的类型相同，您可以在 `public <type> <PropertyName>` 行中找到它。在此行中，您正在定义属性的名称和属性的类型。请注意，属性的类型不必与内部成员变量的类型相同（在前面的列表中用 `<var>` 表示）。您可以在 `set` 和 `get` 函数中进行任何转换，以将值以特定格式传递到访问器中。

属性允许访问器的可访问性，并且还允许您使用匿名类型创建只读属性。

让我们首先详细讨论访问器的可访问性。

### Accessibility of Accessors

在 C# 中，访问器是属性的 `get` 和 `set` 部分。访问器的可访问性表示其访问属性成员的能力。以下代码片段展示了如何在类中的属性中声明访问器：

```
class MyProperty
{
private string name="Sumit";
public string Name
{
get{return name;}
set{name=value;}
}
}
```

在前面的代码片段中，`get` 和 `set` 访问器具有相同的可访问性级别。这意味着这两个访问器都是公共的，因为属性本身是公共的。在 C# 1.1 中，您不能单独更改 `get` 和 `set` 访问器的可访问性级别。然而，在 C# 2.0 及更高版本中，您可以单独指定属性中这些访问器的可访问性级别，如以下代码片段所示：

```
class MyProperty
{
private string name="Sumit";
public string Name
{
get{return name;}
protected set{name=value;}
}
}
```

在前面的代码片段中，由于属性 `Name` 本身是公共的，`get` 访问器也是公共的，因为它没有显式标记任何访问器修饰符。然而，`set` 访问器显式标记为 `protected` 访问修饰符。因此，您可以在整个程序中使用 `get` 方法，而只能在同一类或源类的子类内部使用 `set` 方法。这种方法称为非对称访问器可访问性。

现在，让我们讨论匿名类型。

### Anonymous Types

匿名类型提供了一种封装对象的只读属性的方式，而无需先显式定义类型。编译器按需生成类型名称，但该类型名称在源代码级别不可用。编译器推导属性类型以生成类型名称。换句话说，匿名类型创建无名结构类型，您可以将它们添加到集合中并使用 `var` 关键字访问这些结构类型。

匿名类型是包含一个或多个公共只读属性的类类型。不允许其他类型的类成员，例如方法或事件。您可以使用 `new` 关键字与对象初始化器一起创建匿名类型。

匿名类型是直接派生自对象的引用类型。如果两个或多个匿名类型具有相同数量和类型的属性且顺序相同，编译器将它们视为同一类型，并且它们共享相同的编译器生成的类型信息。

## Indexers

索引器是 C# 引入的一个新概念。索引器允许您将类用作数组，并使对象能够使用索引符号访问类的成员。换句话说，它们提供了一个索引来获取存储在对象中的值。以下代码片段展示了声明索引器的语法：

```
<access modifier> <Return Type> this [argument list]
{
    get
    { // code for get }
    set
    { //code for set }
}
```

在前面的代码片段中显示的语法中：

- 访问修饰符可以是 `Private`、`Public`、`Protected` 或 `Internal`。
- 返回类型可以是任何有效的 C# 数据类型，例如 `string` 或 `integer`。
- `this` 关键字表示对象属于当前类。
- 参数列表指定索引器的参数。C# 索引器必须至少有一个参数；否则，编译器会报错。C# 中的索引器允许您拥有多个参数，每个参数可以是不同类型。您可以通过在它们之间放置逗号来分隔这些参数。索引器的参数类型可以是 `int`、`enum` 或 `string`。这样的参数列表定义了索引器的签名。签名包括索引器中形式参数的数量、类型和顺序，因此有助于唯一标识一个索引器。同一类中的所有索引器应具有不同的签名。
- 语法中的 `get` 和 `set` 部分称为访问器。这些访问器的可见性或访问级别与它们所属的索引器相同。然而，您可以通过将 `set` 访问器的访问修饰符设置为 `protected`、`public`、`private` 或 `internal protected` 来限制 `set` 访问器的可见性。`get` 和 `set` 访问器的主体与方法主体相似。

以下代码片段展示了索引器的示例：

```
class Employee
{
    private string[] names;
    public Employee()
    {
        this.names = new string[8];
    }
    public string this[int i]
    {
        get
        {
            return this.names[i];
        }
        set
        {
            this.names[i] = value;
        }
    }
}
```

在前面的代码片段中，`[]` 运算符用于访问索引器。索引器以与属性相同的方式实现。

索引器具有以下附加功能：

- Inheritance — 允许继承，这意味着派生类可以继承基类索引器。然而，`virtual` 和 `override` 等修饰符在属性级别使用，而不是在访问器级别使用。
- 多态性 — 允许多态性，这意味着派生类可以重写基类索引器。
- 唯一性 — 提供唯一标识索引器的签名。
- 非静态 — 索引器不能是静态的。如果将索引器声明为静态，编译器会生成错误。

在许多方面，索引器与属性相似。然而，两者之间存在一些差异。表 5.2 显示了属性与索引器之间的差异：

| Table 5.2: Difference between Properties and Indexers |
| Parameters for Difference | Property | Indexer |
| Identification | Allows identification by its name Allows methods to be called as if they were public data members | Allows identification by its signature Allows elements of an internal collection or an object to be accessed by using an array notation on the object itself |
| Access | Allows access through a simple name | Allows access through an index |
| Type | Uses static or an instance member | Uses an instance member only |
| Get Accessor Parameters | Provides no parameters to the get accessor of a property | Provides the same formal parameter list as the indexer |
| Set Accessor Parameters | Contains the implicit value parameter | Contains the same formal parameter list as the indexer, in addition to the value parameter |

## Exploring Structs

主要为了与 C++ 程序员向后兼容，`struct` 语句创建了一个元素结构。结构的所有元素默认都是私有的，并且如果未指定，结构会将其元素初始化为每种数据类型的默认值。在 C# 中，结构与类之间最大的区别之一是结构是在栈上创建的；而类是在堆上创建的。在本节中，您将学习结构的语法以及结构的访问修饰符。

### Syntax of a Struct

结构的语法与类的语法相似，主要区别在于结构是值类型，而类是引用类型。因此，结构不会引用堆上的对象。

以下代码片段显示了结构的语法：

```
[attributes] [modifiers] struct identifier [:interfaces]
{
    body[;]
}
```

语法中使用的术语可以描述如下：

- `attribute` — 包含额外的声明性信息。它是可选的。
- `modifier` — 允许在结构中使用诸如 `new`、`static`、`virtual`、`abstract` 和 `override` 等修饰符。它还允许在结构中使用 `public`、`internal` 和 `private` 等访问修饰符。这也是可选的。
- `struct` — 指创建结构时必须使用的关键字。`struct` 关键字后必须跟一个表示结构名称的标识符。
- `interface` — 包含由逗号分隔的接口列表。它是可选的。
- `body` — 包含所有成员声明。

### Access Modifiers for Structs

您可以仅将 `public`、`private` 和 `internal` 访问修饰符应用于结构和结构成员定义。由于结构是隐式密封的，因此您不能在结构中使用 `protected` 和 `protected internal` 访问修饰符。这意味着结构不能是其他类的父类。需要注意的另一点是，与 C++ 不同，结构成员默认是私有的。

以下是结构的访问修饰符：

- `public` – 允许同一程序集或引用它的另一个程序集中的任何其他代码访问该类型或成员
- `private` – 允许同一结构中的代码访问该类型或成员
- `internal` – 允许同一程序集中的任何代码访问该类型或成员，但不允许来自另一个程序集
