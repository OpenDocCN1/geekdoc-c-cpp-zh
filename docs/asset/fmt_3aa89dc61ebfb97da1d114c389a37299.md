### 程序 2.17 总生存与无进展生存的双变量检验

```sas
proc iml;
  use _OUTDAT_DEPTEST;
  read all var(beta) into B;
  close;
  use _OUTDAT_COVBETA;
  read all var(logrank_os_event logrank_pfs_event) into
  close;
  C = I(2);
  Q = t(B) * t(C) * inv(C * V * t(C)) * C * B;
  p = 1 - probchi(Q, nrow(C));
  print Q;
quit;
```
