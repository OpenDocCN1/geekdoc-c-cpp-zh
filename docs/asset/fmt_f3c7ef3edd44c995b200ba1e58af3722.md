## 矩阵中的最大平台——示例

在下一个示例中，我们解决另一个有趣的问题：给定一个整数矩形数组（矩阵），我们的任务是找到元素和最大的 2x2 子矩阵并将其打印到控制台。

该问题的某种解决方案如下：

```csharp
class MaxPlatform2x2
{
    static void Main()
    {
        // 声明并初始化矩阵
        int[,] matrix = {
            { 0, 2, 4, 0, 9, 5 },
            { 7, 1, 3, 3, 2, 1 },
            { 1, 3, 9, 8, 5, 6 },
            { 4, 6, 7, 9, 1, 0 }
        };
        // 寻找 2x2 最大和平台
        long bestSum = long.MinValue;
        int bestRow = 0;
        int bestCol = 0;
        for (int row = 0; row < matrix.GetLength(0) - 1; row++)
        {
            for (int col = 0; col < matrix.GetLength(1) - 1; col++)
            {
                long currentSum = matrix[row, col] + 
                                  matrix[row+1, col] + 
                                  matrix[row, col+1] + 
                                  matrix[row+1, col+1];
                if (currentSum > bestSum)
                {
                    bestSum = currentSum;
                    bestRow = row;
                    bestCol = col;
                }
            }
        }
        // 打印结果
        Console.WriteLine("找到最大和位于 ({0}, {1}): {2}", bestRow, bestCol, bestSum);
    }
}
```

# 数组数组（Jagged Arrays）

在 C# 中，我们可以拥有数组的数组，我们称之为交错数组（jagged arrays）。

交错数组是数组的数组，或者说每一行都包含一个自己的数组，且该数组的长度可以与其他行的数组长度不同。

```csharp

jaggedArray[0] = new int[5];
```
