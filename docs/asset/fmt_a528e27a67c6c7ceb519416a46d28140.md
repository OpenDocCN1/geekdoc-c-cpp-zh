# 使用 GTL 注释设施创建轴对齐插入

## 图中的插入

插入通常是字符串或文本值，显示在图区域，以通信相关的统计数据、参数或其他信息。显示的信息可能来自

- 模板定义中的文本
- 在模板内使用表达式计算的值
- 通过动态或宏变量外部传递给插入的值
- 支持 `INSET=` 选项的语句指定的列

> （`DATALATTICE` 和 `DATAPANEL` 布局提供的选项（例如 `INSET=`）允许您在多单元格布局中构建和定位入口，而无需使用 `ENTRY` 语句。）

本章展示了向图表添加插入图的几种技术。假设您已经熟悉第 7 章“在图表中添加和更改文本”以及第 9 章“使用简单的多单元格布局”介绍的概念和技术。

## 使用 ENTRY 语句创建简单的插入图

可以使用 `ENTRY` 语句在大多数布局块中创建一个简单的插入图。

如果您在 2-D 叠加（overlay-type）类型的布局中创建入口，可以使用每个语句的 `AUTOALIGN=` 选项或 `HALIGN=` 和 `VALIGN=` 选项将文本定位在绘图区域。`HALIGN=` 和 `VALIGN=` 选项将文本置在绝对位置（例如 `HALIGN=LEFT` 和 `VALIGN=TOP`）。`AUTOALIGN=` 选项用于根据绘图区域内图形组件的放置进行动态定位。

例如，要在散点图和椭圆的叠加层上添加插入图，您希望文本出现在不会与标记点或椭圆冲突的位置（如果存在拥挤情况的话）。

```sas
begingraph;
entrytitle "One Line Inset";
layout overlay;
ellipse x=height y=weight / alpha=.1 predicted display=all;
scatterplot x=height y=weight;
entry "Prediction Ellipse ({unicode alpha} .1") / 
autoalign=auto;
endlayout;
endgraph;
```

### 创建文本表格形式插入图

插入图最常用的用途是在图表中显示统计表格。本节展示了如何构建此类基础表格。示例展示了如何让表格内容更具动态性，以及如何将表格集成到图表中。

构建表格的基本技术是在 `LAYOUT GRIDDED` 块中放置多个 `ENTRY` 语句。每个 `ENTRY` 语句变成网格的一个单元格。`ENTRY` 语句选项和布局选项用于进一步组织表格。

假设您想创建如下文本表格：

| N | 5203 |
|---|---|
| Mean | 119.96 |
| Std Dev | 19.98 |

创建表格的最简单技术是构建一个一列三行的表格。以下示例使用了三个 `ENTRY` 语句：每个语句对应表格中的行。统计名称在每行中左对齐，而统计值向右对齐。

```sas
layout gridded / columns=1 border=true;
entry halign=left "N" halign=right "5203";
entry halign=left "Mean" halign=right "119.96";
entry halign=left "Std Dev" halign=right "19.98";
endlayout;
```

另一种技术是创建一个两列三行的表格。这种方法将每个统计名称和值置于自己的单元格中。虽然这种技术需要六个 `ENTRY` 语句，但这种排列更灵活，因为每一列对齐可以独立设置。以下示例将每个 `ENTRY` 语句的文本左对齐：

| N | 5203 |
|---|---|
| Mean | 119.96 |
| Std Dev | 19.98 |

```sas
layout gridded / columns=2 order=rowmajor=true;
/* row 1 */
entry halign=left "N";
entry halign=left "5203";
/* row 2 */
entry halign=left "Mean";
entry halign=left "119.96";
/* row 3 */
entry halign=left "Std Dev";
entry halign=left "19.98";
endlayout;
```

`ORDER=ROWMAJOR` 意味着单元格水平填充，从第 1 列开始，然后是第 2 列，最后进入下一行。您应该按所示排列 `ENTRY` 语句。为表格添加额外的行。

当然，`LAYOUT GRIDDED` 语句允许您按列组织单元格，因此您可以使用 `ORDER=COLUMNMAJOR` 实现此效果。代码段通过垂直格式化单元格：填充第 1 行的第一个单元格，然后是第 2 行的第一个单元格，然后是第 3 行的第一个单元格，最后进入下一列。

```sas
layout gridded / rows=3 order=columnmajor=true;
/* column 1 */
entry halign=left "N";
entry halign=left "Mean";
entry halign=left "Std Dev";
/* column 2 */
entry halign=left "5203";
entry halign=left "119.96";
entry halign=left "19.98";
endlayout;
```

在两种情况下，每个语句都添加了 `HALIGN=LEFT` 选项以使其文本左对齐（默认值为 `HALIGN=CENTER`）。注意表格中的列宽由最长字符串决定。

以下示例说明了如何更改列对齐并使用 `COLUMNGUTTER=` 选项在列之间添加额外空间。`ENTRY` 语句添加了边框以显示文本边界。虽然示例中没有对齐，但 `LAYOUT GRIDDED` 语句提供了 `ROWGUTTER` 选项来添加行之间的间距。

| N | 5203 |
|---|---|
| Mean | 119.96 |
| Std Dev | 19.98 |

```sas
layout gridded / rows=3 order=columnmajor columngutter=5px;
/* column 1 */
entry halign=left "N" / border=true;
entry halign=left "Mean" / border=true;
entry halign=left "Std Dev" / border=true;
/* column 2 */
entry halign=right "5203" / border=true;
entry halign=right "119.96" / border=true;
entry halign=right "19.98" / border=true;
endlayout;
```

在开启边框的情况下，您应该注意到 `ENTRY` 文本之后有间距。该空间被称为填充（padding），可以通过 `ENTRY` 语句中的 `PAD=` 选项显式设置。`entry` 语句的默认填充值为 `PAD=(TOP=0 BOTTOM=0 LEFT=3 RIGHT=3)`。您可以根据需要进行调整。

## 定位插入图

如果在 2-D 叠加布局中使用文本表格作为插入图，可以使用 `LAYOUT GRIDDED` 语句的选项在父布局中定位表格。可以使用 `AUTOALIGN=` 选项自动定位插入图，以避免与散点、线和其他组件冲突。

或者，可以使用 `HALIGN=` 和 `VALIGN=` 选项进行绝对定位。组合值提供了九种可能的位置。使用 `HALIGN=` 和 `VALIGN=` 选项的缺点是它们不会尝试避免与其他组件冲突。

以下示例使用 `AUTOALIGN=` 选项将表格位置限制在绘图区域的一个角。

```sas
proc template;
define statgraph getset3a;
begingraph;
entrytitle "Auto-positioning the Inset Within the Plot Wall";
layout overlay;
histogram;
layout gridded / columns=1 border=true autoalign=(topleft topright);
entry halign=left "N" halign=right "5203";
entry halign=left "Mean" halign=right "119.96";
entry halign=left "Std Dev" halign=right "19.98";
endlayout;
endlayout;
endgraph;
end;
run;
proc sgrender data=sashelp.heart template=getset3a;
run;
```

### 定位插入图

在这种情况下，没有足够的空间在左上角显示插入图，因此使用了下一个位置，因为它没有冲突。使用不同的数据集，插入图可能会出现在左上角导致冲突，此时将使用冲突最少的位置。您可以为 `AUTOALIGN` 列表指定九个位置的顺序：`TOPLEFT`, `TOP`, `TOPRIGHT`, `LEFT`, `CENTER`, `RIGHT`, `BOTTOM` 和 `BOTTOMRIGHT`。对于“打开”不可预测的散点图，可以指定 `AUTOALIGN=` 以选择一个冲突最小的位置。

> **注意**：`AUTOALIGN=` 的设置在布局仅包含散点图时效果最好。当存在其他图类型时，`ENTRY` 文本可能会覆盖绘图区域中的图形元素。

#### 外部插入图

插入图不必放在图边界内部。接下来的示例在 `LATTICE` 模板的侧边栏中插入：

```sas
proc template;
define statgraph gset3b;
begingraph / pad=2px;
entrytitle "Positioning the Inset Outside the Plot Wall";
layout lattice;
layout overlay;
endlayout;
sidebar / align=right;
layout overlay / pad=(left=2px);
layout gridded / columns=1 border=true;
entry halign=left "N" halign=right "5203";
entry halign=left "Mean" halign=right "119.96";
entry halign=left "Std Dev" halign=right "19.98";
endlayout;
endlayout;
endsidebar;
endlayout;
endgraph;
end;
run;
ods html style=default;
proc sgrender data=sashelp.heart template=gset3b;
run;
```

## 在模板中使用计算出的值创建嵌入图

到目前为止的示例在编译后的模板中“硬编码”了统计值。硬编码统计值意味着，每当列值发生变化或你想使用不同的列进行分析时，都需要修改并重新编译模板代码。展示统计表的一种更具灵活的方法是按如下方式进行计算：

- 使用 GTL 函数计算所需的任何统计数据
- 使用动态变量作为模板中列名的占位符
- 在运行时初始化动态变量，使其解析为提供图表数据值的数据对象中的列名

GTL 提供了多个可以供你用来计算统计值的函数，包括与 `PROC SUMMARY` 统计关键字匹配的函数。GTL 函数始终指定在 `EVAL` 函数内部。要声明动态变量，请使用 `DYNAMIC` 语句。

以下示例使用 `DYNAMIC` 语句声明了一个名为 `VAR` 的变量，该变量在函数 `N`、`MEAN` 和 `STDDEV` 中使用，用于计算统计表中显示的统计数据：

```sas
proc template;
define statgraph graphset4a;
dynamic VAR;
begingraph;
entrytitle "带有计算值的双列嵌入图";
layout overlay;
histogram VAR;
layout gridded / rows=3 order=columnmajor border=true autoalign=(topleft);

/* 第 1 列 */
entry halign=left "N";
entry halign=left "Mean";
entry halign=left "Std Dev";

/* 第 2 列 */
entry halign=left eval(strip(put(n(VAR), 12.0)));
entry halign=left eval(strip(put(mean(VAR), 12.2)));
entry halign=left eval(strip(put(stddev(VAR), 12.2)));
endlayout;
endlayout;
endgraph;
end;
run;
proc sgrender data=sashelp.heart template=graphset4a;
dynamic VAR="mrw";
run;
```

- 动态 `VAR` 首先在 `HISTOGRAM` 语句中被引用，用于表示为直方图提供数值的变量。
- 动态 `VAR` 在每个指定统计表中统计值的 `ENTRY` 语句中再次被引用。每个 `ENTRY` 语句都使用 `EVAL` 函数来指定计算统计值的函数。
- 在每个 `ENTRY` 语句上，`STRIP` 函数会去除返回值的两端空格。第一个 `ENTRY` 语句上的 `PUT` 函数返回格式为 `12.0` 的统计值，接下来的两个 `PUT` 语句返回格式为 `12.2` 的值。

## 使用传递的值创建嵌入图

### 将数据导入模板的概述

当要在嵌入图中显示的统计数据无法在模板内计算时，你可以从过程创建一个输出，并使用动态变量或宏变量在运行时“导入”计算出的值。

下面的讨论说明了如何创建并调用宏，将数据集名称和变量名传递给编译过的 GTL 模板。为了理解此讨论，你应该阅读第 14 节“使用动态变量和宏变量创建灵活模板”。

- 第一个参数 `DSN` 传递数据集名称。
- 第二个参数 `VAR` 传递变量名。

调用时，该宏生成直方图和模型图。

### 从传递给模板的值创建嵌入图

- `LAYOUT GRIDDED` 语句构建了一个双列嵌入图，显示分析变量的描述性统计数据。宏变量 `NOBS`、`MEAN` 和 `STD` 将由宏体中的代码计算，并解析为数据中的观测值数量、平均值和标准差。

### 定义宏以初始化变量并生成图表
