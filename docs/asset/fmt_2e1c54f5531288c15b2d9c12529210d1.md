
## 4.1 HTTP 与互联网

关于互联网如何运作的一些基础知识，如果你最近没有为 Web 编写过程序，这些可能会有所帮助。超文本传输协议（`HTTP`）定义了站点页面如何在互联网上进行交换。`HTTP` 是在万维网上用于交换或传递数据的系统。它存在的独特意义在于提供一种发布、分发和恢复 `HTML` 页面的方法。万维网联盟（`W3C`）和互联网工程任务组（`IETF`）标准化了 `HTTP` 的开发，它们是连接客户端和服务器的请求-响应协议。起始点的客户端（通常是网络浏览器）被称为用户代理（`user agent`）。存储或构建资源以及 `HTML` 文档和图片的目标服务器被称为服务器（`server`）。在用户代理和服务器之间，可能存在代理（`proxies`）等中间节点。`HTTP` 客户端通过在远程主机的特定端口（默认端口 `80`）建立传输控制协议（`TCP`）连接来启动请求。监听该端口的 `HTTP` 服务器会等待客户端发送请求。

在接受请求后，服务器会返回一个状态行（例如“`HTTP/1.1 200 OK`”）以及自身的响应。根据状态的不同，该响应可以是文件、错误消息或其他数据。`HTTP` 构建在 `TCP` 之上，而 `TCP` 本身又构建在互联网协议（`IP`）之上。两者通常被称为 `TCP/IP`。组织化主机上的应用程序可以相互建立关联并在之后交换信息。该协议确保了信息从发送者到收集者的稳健传输。`TCP` 支撑了互联网许多最著名的应用，包括 Web、电子邮件和 Shell。

# 4.2 PHP 和 MySQL 在 Web 开发中的地位

`PHP` 是一种编程语言，设计用于在 Web（即服务器）上交互式地创建网页。与 `HTML` 不同，在 `HTML` 中 Web 程序使用标签和标记来创建页面，而 `PHP` 代码则运行在请求的页面和服务器之间，从而改变基础的 `HTML` 输出。

`PHP` 让开发变得简单，原因在于你所需的所有代码都包含在 `PHP` 框架内部。这意味着每当你坐下编写程序时，没有特殊的理由去重新评估代码；因为它自带了 Web 功能。虽然 `PHP` 对于 Web 应用程序非常出色，但它本身并不存储数据。为此，你需要一个数据库。`PHP` 工程师使用的数据库是 `MySQL`，它承担着涉及存储和恢复客户端数据的广泛认可的任务。`PHP` 可以轻松地访问 `MySQL`，且它们运行得良好。一个内置优势是 `PHP` 和 `MySQL` 运行在不同的 PC 类型和操作系统上，包括 `Mac OS`、基于 `Windows` 的 PC 和 `Linux`。将 `PHP` 和 `MySQL` 结合使用的多个元素对许多人来说是自然的：

- `PHP` 和 `MySQL` 协作良好：`PHP` 和 `MySQL` 在创建时就考虑了对方，因此易于使用。它们之间的编程接口配对合理。设计人员在开发 `PHP` 和 `MySQL` 接口时，这两者协作的想法并不是事后才想到的。
- `PHP` 和 `MySQL` 拥有开源力量：由于它们都是开源项目，因此 `PHP` 和 `MySQL` 都可以免费使用。`MySQL` 库不再与 `PHP` 一起打包。高级用户可以对源代码进行改进，并借此更改语言和程序的工作方式。
- `PHP` 和 `MySQL` 拥有群体支持：它们在 Web 上都有动态社区，你可以在其中感兴趣，成员们将帮助你回答疑问。如果你有需要，你也可以为 `MySQL` 购买专业支持。
- `PHP` 和 `MySQL` 速度快：它们基础且高效的设计实现了更快的处理速度。
- `PHP` 和 `MySQL` 不会用冗余细节阻碍你

## MySQL

`MySQL` 是一个免费的关系型数据库，但它仍然包含了完整的功能。`MySQL` 创建于 20 世纪 90 年代，以满足 PC 监控不断发展的的需求。首批核心 `MySQL` 设计者试图通过利用 `mSQL`（一种非常小且基础的数据库）来解决他们对数据库的需求。事实证明，`mSQL` 无法处理它需要的大量问题，因此他们制作了一个更健壮的数据库，并演变成了 `MySQL`。

`MySQL` 支持几个不同的数据库引擎。数据库引擎决定了 `MySQL` 如何处理信息的实际存储和查询。因此，每个存储引擎都有其特定的能力排列和优势配置。随着时间的推移，可用的数据库引擎正变得越来越先进和快速。

`MySQL` 的最新生产发布版本是 `5.0x` 版本。`MySQL 5.0` 提供的执行类似于某些非常昂贵的项目数据库，例如 `Oracle`、`Informix`、`DB2 (IBM)` 和 `SQL Server (Microsoft)`。开发者通过利用许多开源设计者的才华以及社区测试，实现了这种水平的性能执行。对于一般的 Web 驱动数据库任务，默认的 `MyISAM` 数据库引擎工作得非常出色。不用担心数据库的最新和最主要的功能，因为你可能需要的大部分功能已经在 `MySQL` 中整合很久。

你可能同时拥有引用 `CSS` 的 `HTML` 文档、`PHP` 模板和 `MySQL` 数据库的数据。`PHP` 模板使得页面包含由数据库查询填充的字段时，更改页面中的 `HTML` 变得简单。

### 变量

由于我们预计你还没有过编程，我们得到变量是另一种想法。变量存储值，例如文本字符串“`Hello!`”或整数 `1`。变量可以在你的代码中重用，而不需要反复确定整数值。

- `PHP` 变量可以是字母、数字和下划线；例如 `a-z`、`A-Z`、`0-9` 和 `_`。
- `PHP` 变量对大小写敏感。
- 多个单词的变量可以使用下划线隔离；例如 `$test_variable`。
- 变量可以使用等号（`=`）赋值。
- 赋值后始终以分号（`;`）结束。

在不经意的情况下调整了一个变量而不知道其结果。这种错误可能极难发现。此外，当我们详细检查函数时，你会发现可以在调用函数时可以向它们发送值，并在它们完成后从它们获取返回值。你不需要使用全局变量。

然而，万一你需要在特定函数中使用变量，且不想在每次函数结束时丢失该值，你可能倾向于不使用全局变量，而是使用静态变量。

- 静态变量

静态变量使得变量在函数结束时不会被销毁。每当你调用该函数时，你都可以再次利用该静态值，它的值将与最后一次作为函数一部分使用时相同。考虑此点的最简单方法是将该变量简单地视为全局变量。`$age` 的估值在每次调用 `birthday` 函数时都会被保留。该值将一直保留，直到程序结束。由于它被声明为 `static`，因此值会被保留。通过这种方式，我们讨论了两种变量，但还有一种需要检查，即超全局变量。

- 超全局变量

`PHP` 使用一种称为“超全局”的奇有变量来提供有关 `PHP` 脚本运行环境的数据。这些变量不需要声明为全局变量。它们通常是可访问的，并且提供了超出脚本代码本身的重要数据，例如来自用户输入的值。

自 `PHP 4.01` 以来，超全局变量被称为数组。数组是值的唯一集合，我们将在后面的章节中讨论它们。更早期的全局变量（如以 `$HTTP_*` 开头的但未成组的变量）仍然存在，但明确不建议使用它们，因为它们已经被弃用了。

## 6.1 表达式

代码中有几个你必须理解的构建模块：语句、表达式和操作符。语句是执行任务的代码。语句由表达式和运算符组成。表达式是评估一个值的代码片段。值可以是数字、内容字符串或布尔值（`Boolean`）。

运算符是以后某种方式跟在表达式后面的代码组件。例如，一个减号（`–`）可以用于告诉计算机在减去之前的表达式值后，减少该表达式的值。例如：

```
$account_balance=$credits-$debits;
```
