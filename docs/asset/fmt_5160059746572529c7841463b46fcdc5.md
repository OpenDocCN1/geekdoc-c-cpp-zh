## Using XML Data in SQL Server

One of the important data types in SQL is XML data type. In the older versions of SQL Server, XML data is stored in the form of string or binary large objects (`blobs`) form. An XML data type can be used as a variable, column, parameter, or a return value by a UDF. Using Microsoft Office, you can also store Word and Excel documents in the form of XML data. ### Listing 23.6: Showing the Code of the GetProductDetailsSP.cs File

```
using System;
using System.Data;
using System.Data.SqlClient;
using System.Data.SqlTypes;
using Microsoft.SqlServer.Server;
public partial class StoredProcedures
{
    [Microsoft.SqlServer.Server.SqlProcedure]
    public static void GetProductDetailsSP(int ProductID)
    {
        SqlConnection con = new SqlConnection("context connection=true");
        con.Open();
        SqlCommand myCommand = new SqlCommand("SELECT ProductID,ProductName,QuantityPerUnit,UnitPrice,UnitsInStock FROM Products WHERE ProductID=@ProductID Order By ProductName", con);
        myCommand.Parameters.Add("@ProductID", SqlDbType.Int);
        myCommand.Parameters["@ProductID"].Value=ProductID;
        SqlDataReader sdr = myCommand.ExecuteReader();
        SqlPipe sp = SqlContext.Pipe;
        sp.Send(sdr);
        con.Close();
    }
};
```

在清单 23.6 中，使用了 `SqlProcedure` 属性来表明存储过程用于部署。`SqlConnection` 对象使用 `context connection=true` 字符串创建。`SqlCommand` 对象通过传递连接对象创建。`SqlDataReader` 类的对象由 `ExecuteReader()` 方法返回，该对象通过 `SqlPipe` 类的 `Send()` 方法返回给客户端。

using System;

using System.Linq;
using System.Text;
using System.Data;
using System.Data.SqlClient;
namespace UseProductSP
{
    class Program
    {
        static void Main(string[] args)
        {
            string constr = @"Data Source=.;Initial Catalog=Northwind;Integrated Security=True";
            var con = new SqlConnection(constr);
            SqlCommand cmd = con.CreateCommand();
            cmd.CommandText = "GetProductDetails";
            cmd.CommandType = CommandType.StoredProcedure;
            var param = new SqlParameter("@productId", 3);
            cmd.Parameters.Add(param);
            con.Open();
            SqlDataReader sdr = cmd.ExecuteReader(CommandBehavior.CloseConnection);
            while (sdr.Read())
            {
                Console.WriteLine("Product ID: {0} \nItem: {1} \nQuantity: {2} \nPrice: {3}", sdr["productID"], sdr["productName"], sdr["quantityperunit"], sdr["unitPrice"]);
            }
            sdr.Close();
