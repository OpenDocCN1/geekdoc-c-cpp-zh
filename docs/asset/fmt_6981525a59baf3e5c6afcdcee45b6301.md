# 第6章 分离结果

## 6.1 分离结果

设`K, K'`为语言类。对于`(K, K')`的分离结果意味着显示存在语言`L ∈ K`；并称`L`*分离了*`K'`。如果第4章关于“`K`是否包含在`K'`中”的问题大多是否定的，那么需要分离技术来解决这些问题。遗憾的是，给定一个特定的`L`（如一个`K`-完全语言）和一个特定的`K'`，证明`L ∉ K'`似乎需要超出我们能力的方法。

大多数技术基于“填充”（padding）的想法。该想法由 Ibarra 和 Fisher [14] 提出。我们在上一章的第一节已经遇到过填充：例如，填充可以将`NSPACE(n^{k+1})`的完全问题“翻译”为`NSPACE(n^k)`的完全问题。填充技术通常将低复杂度类之间的包含转换为高复杂度类之间的包含。因此，这类结果被称为*向上*翻译结果。

在空间上：例如，在每个阶段，我们尝试通过某些字包含或排除`L`，以确保`L`不等于`K'`。在`K'`上进行对角化时，我们必须确保`L`留在`K`中。第4章包含了此类构造。在任何情况下，假设我们成功分离了`K`和`K'`，有两个典型的：

(a) 我们可以推出其他类也必须被分离。翻译结果指的是具有以下结构的：`K_i ⊆ K'_i (i=1,2)`为类。通过这种翻译结果，`(K'_1, K'_2)`的分离结果意味着`(K_1, K_2)`的分离结果。这种方法在分离非确定性类时特别有用。

(b) 我们可以在`K`中的语言上得到下界。特别是，任何`K`-完全语言（关于某种归约`≤`）不在`K'`中。例如，我们可以使用上述对角化技术从`NLOG`显示`PSPACE`。由于正则表达式（第5章）问题是`PSPACE`-完全的，我们得出该问题无法在对数空间内解决。

```
If NLOG ⊆ DLOG 则 LBA ⊆ DEXT
If NP ⊆ P 则 NEXP ⊆ DEXP
```

已知有限形式的“向下翻译结果”。翻译技术将在第3和4节处理。

## 6.3 填充与转换引理

上一节层级定理的主题是：给定复杂度函数`f_1(n)`，最小的复杂度函数`f_2(n)`使得`L`在`f_2(n)`内接受但在`f_1(n)`内不接受。当`N`是非确定性的且我们要判定`N`是否在`t`内接受时，这种方法是无效的。判定这个问题的最佳非确定方法等同于对`N`进行指数级的模拟。这意味着`f_2(n)`比`f_1(n)`指数级。

为了分离非确定空间，我们使用 Savitch 技术确定性地模拟非确定空间计算，使用平方倍的空间。接下来的两节将展示更有效的非确定时间和空间的技术。

我们从复杂度函数的转换引理开始：

## 6.3 填充技术与转换引理

引理 5 (空间的复合转换)。设`s_1(n) ≥ n, s_2(n) ≥ n`和`f ≥ n`为复杂度函数，并假设`f`是空间可构造的。对于`X = D`或`N`，`XSPACE(s_1) ⊆ XSPACE(s_2)`意味着`XSPACE(s_1 ∘ f) ⊆ XSPACE(s_2 ∘ f)`。

证明。该证明通过遵循此“交换图”中的箭头来暗示的：

`XSPACE(s_1) → XSPACE(s_2)`

`XSPACE(s_1 ∘ f) → XSPACE(s_2 ∘ f)`

假设`XSPACE(s_1) ⊆ XSPACE(s_2)`且`L`被某个机器`M`在空间`s_1 ∘ f`内接受。我们想要证明`L ∈ XSPACE(s_2 ∘ f)`。首先将`L`转换到`XSPACE(s_2 ∘ f)`。更准确地说，`L`的填充版本是`L' = {x1^{2^{f(|x|)}} : x ∈ L}`。由于`L' ∈ XSPACE(s_1)`，存在机器`M'`在空间`s_1(|x'|) = s_1(2^{f(|x|)})`内接受`L'`。为了判定`x ∈ L`，在输入`x`上，我们构造`x' = x1^{2^{f(|x|)}}`并运行`M'`。使用的空间为`s_1(2^{f(|x|)})`，如果`s_1(2n) = O(s_2(n))`，则`L ∈ XSPACE(s_2 ∘ f)`。

最后一个包含源于 Savitch 定理。那么`SPACE(n^{1+2^s}) ⊆ SPACE(n^{2^s})`与确定性空间层次结构相矛盾。

Q.E.D.

**定义 2.** `s(n) < ∞`是一个定义在足够大的`n`上的复杂度函数。我们称`s`是*增长的*，如果它是无界的，`s(n) ≠ O(1)`，且存在一个常数`c`，使得`s(n) ≤ c · s(n-1)`。

观察到，在`n log n`中，`n^{O(1)}`和`O(1)`是中等增长的。然而，诸如`2^n`和`2^k` (`k > 1`) 这样的函数就不是。

**定理 7 ((引理的向上平移))** 设`s, s'`为复杂度函数。如果`s`是中等增长的且空间构造的，并且对于所有`n`有`s(n) ≤ s'(n)`，那么

`SPACE(s) ⊆ SPACE(s') ⟹ SPACE(s') ⊆ SPACE(s)`。

*证明.* 该证明与平移引理的证明相似。设`(Σ, L)`被某个非确定性机器`M`在空间`s'`中中接受。我们将证明`L`属于`SPACE(s')`。我们如下将将`L`翻译为`SPACE(s)`中的一个相关问题：设`L'`为`Σ`中的一个新符号并定义`L`的填充版本：

`L' = {x^{s'} : M' 接受 x^{s'(|x|)}, i ≥ 0}`。

显然，`L' ∈ N(s')`。由于`NSPACE(s') ⊆ SPACE(s')`，我们得到`L`被某个在空间`s`内的停机确定性机器`M`接受。我们构造一个确定性机器`M`来接受`L`：在输入`x ∈ Σ*`上，在`x^i`上模拟`M'`，对于`i = 0, 1, 2, ...`，直到找到第一个使得`M'`接受`x^{s'}`的`i`。在此时`M'`运行。然后`M'`输出。`M'`的正确性：是要证明`M'`在`SPACE(s)`中接受。我们声称`M'`在空间`s(n)`内接受。（为了证明这一点，设`x ∈ L`。如果`s'(|x|) = s(|x|)`，则只需证明`M'`在空间`s'`中接受`x^{s'(xx)}`即可。否则，如果`s'(|x|) > s(|x|)`，则存在一个`i`使得

`s'(i) ≥ s(s'(|x|)) ≥ s(s(|x|)).`

注意`i`是界的，因为`s`是无界的且`s'`是有限的。那么对于任何`j = 0, ..., i-1`，`s'(j) < s'(s'(|x|))`。如果`M'`接受`x^{s'}`，那么`M`在空间`s`中接受`x`，因为我们的意思是`M`使用的空间最多为`s(s'(|x|))`。但由于`s`是中等增长的，存在`c > 1`使得`s'(s'(|x|)) ≤ cs(s'(|x|)-1)`。这证明了`M`在空间`cs(s')`中接受。声称界通过空间压缩得出。这完成了证明。

Q.E.D.
