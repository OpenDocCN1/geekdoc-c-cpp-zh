## 18.7.1 双线性插值

一维问题中的插值方法可以扩展到多维插值。在本节中，我们将描述笛卡尔坐标系下二维插值的最简单情况。

二维插值处理的是确定二变量函数 $z = f(x, y)$ 的中间值。如图 18.19 所示，我们在四个点具有值：$f(x_1, y_1)$、$f(x_2, y_1)$、$f(x_1, y_2)$ 和 $f(x_2, y_2)$。我们希望这些点之间进行插值，以估计中间点 $f(x_i, y_j)$ 的值。如果使用线性函数，结果将如图 18.19 所示连接这些点的平面。此类函数被称为双线性。

开发双线性函数的简单方法如图 18.20 所示。首先，我们可以固定 $y$ 值，并在 $x$ 方向上应用一维插值。使用拉格朗日形式，$(x, y_i)$ 处的结果为：

$$f(x_i, y_1) = \frac{x_i - x_2}{x_1 - x_2}f(x_1, y_1) + \frac{x_i - x_1}{x_2 - x_1}f(x_2, y_1) \quad (18.54)$$

在 $(x, y_2)$ 处的结果为：

$$f(x_i, y_2) = \frac{x_i - x_2}{x_1 - x_2}f(x_1, y_2) + \frac{x_i - x_1}{x_2 - x_1}f(x_2, y_2) \quad (18.55)$$

![](img/1e955c450e467ba2327460e717e7b955_546_0.png)

**图 18.19** 二维双线性插值的图示描述，其中中间值（实心圆）基于四个给定的值（空心圆）估计出来。

![](img/1e955c450e467ba2327460e717e7b955_546_1.png)

**图 18.20** 二维双线性插值可以通过首先沿 $x$ 维度应用一维插值来确定 $x$ 处的值来实现。这些值随后可以用于沿 $y$ 维度进行线性插值，从而在 $x, y$ 处产生最终结果。

这些点随后可以沿 $y$ 维度进行线性插值以得到最终结果：

$$f(x_i, y_j) = \frac{y_2 - y_j}{y_2 - y_1}f(x_i, y_1) + \frac{y_1 - y_j}{y_2 - y_1}f(x_i, y_2) \quad (18.56)$$

通过将等式 (18.54) 和 (18.55) 代入等式 (18.56)，可以开发出一个单一方程：

$$f(x_i, y_j) = \frac{x_i - x_2}{x_1 - x_2}\frac{y_2 - y_j}{y_2 - y_1}f(x_1, y_1) + \frac{x_i - x_1}{x_2 - x_1}\frac{y_2 - y_j}{y_2 - y_1}f(x_2, y_1) + \frac{x_i - x_2}{x_1 - x_2}\frac{y_1 - y_j}{y_2 - y_1}f(x_1, y_2) + \frac{x_i - x_1}{x_2 - x_1}\frac{y_1 - y_j}{y_2 - y_1}f(x_2, y_2) \quad (18.57)$$

### 例 18.1 双线性插值

**问题描述**。假设你在加热板的某些坐标点上测量了温度：

| T(2, 1)=60 | T(9, 1)=57.5 |
| T(2, 6)=55 | T(9, 6)=70 |

使用双线性插值估计 $x = 5.2$ 和 $y = 4.8$ 处的温度。

**解**。将这些值代入等式 (18.57)：

$$f(5.2, 4.8) = \frac{9-5.2}{9-2}\frac{6-4.8}{6-1} \cdot 60 + \frac{5.2-2}{9-2}\frac{6-4.8}{6-1} \cdot 57.5 + \frac{9-5.2}{9-2}\frac{1-4.8}{6-1} \cdot 55 + \frac{5.2-2}{9-2}\frac{1-4.8}{6-1} \cdot 70 = 61.243$$

注意，除了双线性插值外，高阶项式和样条也可以用于二维插值。这些方法可以很容易扩展到三维。我们将在第 19 章回顾软件应用时回到这里。

## 19.1 正弦波拟合

周期函数 $f(t)$ 为：

$f(t) = f(t + T)$

**图 19.2** 除了正弦和余弦，周期函数的示例包括 (a) 方波和 (b) 锯波。除了这些理想形式，自然界的周期信号可以是 (c) 非理想的和 (d) 受污染的。三角函数可以用于表示和分析所有这些情况。

![](img/1e955c450e467ba2327460e717b5552.png)

其中 $T$ 是一个称为*周期*的常数，是方程 (19.1) 的最小值。大多数周期函数是正弦波函数。在讨论中，我们将使用*正弦波*一词来表示任何可以描述为正弦或余弦的波形。选择任何函数都没有明确规定，在任何情况下结果都是相同的。对于本章，我们将使用余弦，通常表示为：

```
$f(t) = A_0 + C \cos(\omega_0 t + \theta)$
```

因此，四个参数用于表征正弦波（图 19.3）。*平均值* $A_0$ 设置了横轴之上的平均高度。*振幅* $C$ 指定了高度。**图 19.3** (a) 正弦波 $y(t) = A_0 + C \cos(\omega_0 t + \theta)$ 的图像。在这种情况下，$A_0 = 1, C = 1, \omega_0 = 2\pi/1$ 且 $\theta = \pi/3$ 弧度 ($1.047 = 0.25$ s）。描述曲线的其他参数是频率 $f = \omega_0/2\pi$，对应 1 周期/s，以及 (b) 曲线的另一种表达式为 $y(t) = A_0 + A_1 \cos(\omega_0 t) + B_1 \sin(\omega_0 t)$。该函数的三个组件在 (b) 中所示，其中 $A_1 = 0.5$，$B_1 = -0.866$。(b) 中三条曲线之和得到 (c) 中的单条曲线。

**图 19.4** (a) 滞后相角和 (b) 领先相角的图形图示。注意 (a) 中的曲线可以替代描述为 $cos(\omega_0t + \pi/2)$。换句话说，如果曲线滞后了角度 $a$，它也可以表示为 $2\pi - a$。振荡。角频率 $\omega_0$ 表征了循环发生的频率。相角或相位位移 $\theta$ 参数化了正弦波水平移动的程度。它可以被测量为从 $t=0$ 到余弦函数开始新周期的弧度距离。如图 19.4a 所示，负值被称为滞后相角，因为曲线 $cos(\omega_0t-\theta)$ 在 $cos(\omega_0t)$ *之后*开始新周期。因此，$cos(\omega_0t-\theta)$ 被认为滞后于 $cos(\omega_0t)$。相反，在图 19.4b 中，正值被称为领先相角。

注意频率（弧度/时间）通过频率 $f$（周期/时间）相关：

$$\omega_0 = 2\pi f$$

频率反过来与周期 $T$（时间单位）相关：

$f = \frac{1}{T}$

尽管方程 (19.2) 是正弦波的恰当数学表征，但从曲线拟合的角度来看处理起来很困难，因为相位位移包含余弦函数的参数中。这种缺陷可以通过调用三角恒等式来克服：

$C_1 \cos(\omega_0t + \theta) = C_1[\cos(\omega_0t)\cos(\theta) - \sin(\omega_0t)\sin(\theta)]$
