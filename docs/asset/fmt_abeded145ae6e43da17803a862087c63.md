# 基本心理需要量表

基本心理需要量表衡量了幸福感的几个要素，即一个人认为其自主、胜任和归属需求得到满足的程度。

自主（Autonomy）是指感到自己的选择和活动是自我决定的，而不是受内部（如内疚感）或外部压力（如他人规则）的控制。

胜任（Competence）是指对自己的环境感到有信心和掌控感。

归属（Belonging）是指感到与他人建立了满意且有意义的联系，并且感到被他人关怀、认可和理解。

为了找到你满足这三个基本需要的程度，请阅读每个陈述，并圈出与该陈述对你真实程度相对应的数字。

# 价值生活靶心工具 (BULLI)

BULLI 是一种旨在帮助人们明确自身价值观的工具。它不是为了衡量目标，目标是那些可以在清单上勾掉的东西。目标是如“我想结婚”、“我想要一份更好的工作”、“我想买房”、“我想毕业”之类的事。相反，价值观始终是未完成的事业，需要持续的行动。价值观是诸如“我想成为最好的父母”、“我想对我的伴侣充满爱、关怀和支持”之类的。价值观定义了我们想要做什么，以及想要如何互动。

BULLI 分三个部分。第一部分帮助你明确价值观；第二部分旨在帮助识别阻碍你履行价值观的障碍；第三部分帮助你制定行动计划。

# 第一部分：靶心 (The Bull's eye)

BULLI 的第一部分有两个练习。第一个练习要求你考虑四个领域：工作/教育、人际、个人成长/健康以及娱乐。回顾你关于价值观的内容，并在每个领域画一个 `X` 来代表你的生活情况。

工作/教育：指职场和职业、知识。这可能包括客户、同事。

人际：指亲密关系、亲近、友谊、伴侣、孩子、社交联系。

个人成长/健康：指作为人的持续持续发展。这可能包括宗教、精神性、冥想、瑜、营养。

娱乐：指你如何玩耍、放松、刺激、享受、休闲和创造。

第一部分的第二个练习是一个靶心，看起来像一个靶盘。与靶盘不同，它被进一步分为你刚刚提到的四个领域。就像靶盘一样，越靠近中心越好。越靠近中心意味着你越完全按照价值观生活，远离中心的标记则意味着你远离了这些价值观。
