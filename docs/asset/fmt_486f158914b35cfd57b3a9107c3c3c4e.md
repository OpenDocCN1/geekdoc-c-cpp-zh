
我们大脑天生具有好奇心——以及它的神经双胞胎：忧虑。从50万年前祖先的困境开始，社会群体一直必须具有选择性。例如，每个洞穴居所都有最大容量。如果一个新人的出现看起来有吸引力、聪明、能干、社交且乐于合作，群体更愿意投入他们的时间、能量和资源。每一个人类都是脆弱的，因为他们不断受到群体的评估。这不是一个懈怠的地方，因为懒惰和虚弱的人第一个会被踢出去，让他们在面对饥饿的猛禽和狼群时自自生。为了被接受，我们的祖先需要证明他们能够自力更生。

我们是如何保护自己免受拒绝的？我们不断从群体中其他人的视角监测自己的处境。我贡献得足够吗？我的贡献和别人一样多吗？我是否做了些愚蠢的事以至于被拒绝和放逐？在几千年的时间里，人类大脑演化出了处理狩猎、采集和其他生存挑战的能力。

遗憾的是，许多帮助我们狩猎采集祖先生存的心理工具，阻碍了我们在当今现代世界中享受生活的能力。例如，史前忧虑较多的男女女性比那些无忧无虑、积极思考的同类更有可能生存。负面思考充当了早期的警报系统。它触发大脑识别当下的实际和潜在威胁，同时也帮助大脑想象并不存在的危险情景。如果人们随时做好准备，他们更有可能生存。即使他们在90%的时间里都是错的，花了大量时间担心无，也没关系，因为生存是首要目标。

我们天生就会为最坏的情况做准备。当发现危险——或只是预感到危险时——我们的大脑会迅速产生焦虑感和强烈的逃避欲望。正如我们的祖先对不稳定的危险产生反应，我们对可能发生的事件产生焦虑。这种焦虑情绪是让我们感到安全的，当我们感到安全时，这种对潜在风险的关注其实是有益的。正如我们的祖先担心被群体排逐，我们担心可能被评价低而感到尴尬。由于这些巨大的益处，当我们感到安全的，这种中立、不活跃的状态是短暂的。我们的大脑设计中另一个重要的元素叫做积极偏移。这意味着当我们感到安全时，我们会表现出探索新事物和寻求新体验。了解大脑的演化设计有助于理解创造充实生活需要什么。我们不断试图平衡积极与负面。我们对负面信息的关注天性其实有一个名字。它被称为**负面偏误**。如果你是一个焦虑的人，这种偏误会进一步延伸，使得模糊不确定的境地被感知为危险。

我们会从焦虑警觉的状态中获得休息。在绝对没有危险的时刻，我们感到安全。在这种状态下，我们不会试图躲避世界。我们可以放松和休息。

# 每一件事都必须由我们的祖先发现

由于这些巨大的益处，人类大脑演化出了对群体排斥可能性的恐惧。在某种程度上，每个人类都在试图理解世界，这有着强大的演化基础。无论是获取资源（工具或庇护所）、信息（信任谁），还是具体的奖励（食物或性伴），我们的祖先都需要寻求机制。

只有当我们的祖先离开已知边界时，他们才能增加知识和技能。知识和技能的增加可以帮助某人生存一天。当然，仅仅因为某事物是新的，并不意味着它对预测和理解预测有帮助。记住，他们必须发现一切。想象一下我们的祖先在敢用火之前丢掉了多少物体。更有可能是，世代人都在玩树枝、骨头、石头以及任何他们拿起来的东西。在等待有趣事情发生时，他们可能对这些物体进行进食、舔、携带、揉搓、挤压、撞、摇晃、投掷、跳舞和吟唱。在一个动物为了生存而互相竞争的严酷环境中，有很多值得学习的。这种在可能发生时感到的愉悦……

# 我们的大脑渴望新奇

被奖励的驱动感促使我们去探索、寻找和调查。毕竟，正是对奖励的预期驱动了能够满足的消费行为。这种预期和寻找本质上关乎好奇心；它是进化适应的最高境界。

这并非全部。毫无疑问，与那些胆量较小的同龄人相比，好奇的探索者在获得社会认可方面具有优势。他们的新技能对自己的部落来说更具吸引力，反过来也能让他们获得更多接触群体食物、水、工具和性伴侣的机会。拥有了更多资源，探索者存活了下来；由于拥有充足的性伴侣，他们更有可能将这些特质遗传给后代。学习哪些行为能让自己产生吸引力并被部落接纳（例如提供食物），以及哪些行为会导致拒绝（例如偷窃、懒惰），是至关重要的。随着代代传承，好奇心、探索和类似的特征将变得更加普遍。

另一种有助于关系发展的行为是玩耍。玩耍的核心是多样性，无论是给朋友起幽默的昵称并戏弄他们、装扮、爬树和爬楼、扭闹，还是在运动和游戏中竞争。玩耍是好奇心与快乐的混合体。除了令人愉悦之外，玩耍还是年幼和动物培养终身受益的必备社交和解决问题技能的训练场。在动物界中，松鼠会选择家庭圈之外的固定玩伴。即使松鼠与童年的玩伴分离数月甚至几年后，当它们重聚且这种玩耍受到捕食者的攻击时，松鼠更有可能投入其中并冒生命危险保护它们。童年那些快乐的经历创造了持久的友谊，在未来需要的时候派上用场。人类也表现出同样的模式。没有好奇系统就没有玩耍，经常玩耍往往会导致长期的关系。

对于我们的祖先来说，玩耍作为好奇寻求系统的产物——“好奇吗？”是他们获取盟友和性伴侣的工具之一，从而增加了生存和生殖成功的概率。在玩耍中，我们尝试不同的社交行为、规则和角色。我们扩展了如何与他人相处的工具箱，并学习了关于自己的知识。玩耍是变化的训练场。

当然，并不是所有好奇、爱玩耍的探索者都有圆满的结局。未知提供了巨大的见解和奖励，但探索者并不总能活下来分享它们。邻居们在所有冒险中都无所事事，担心舒适、安全、确定和掌控；与探索者相比，他们将时间花在熟悉和常规事务上。他们本可以通过倾听和观察探索者来受益；二手学习和成长往往与亲身体验一样有效，而且额外的好处是不必冒受伤或死亡的风险。

为了能够有效应对环境的目标，一种最佳灵活性特征应运而生。最成功的人在面对显而易见的眼前危险时感到焦虑，在面对潜在奖励和学习机会时感到好奇。当危险与奖励并存时，我们的祖先遭遇了冲突：是想要逃避并生存，还是探索并赢得随之而来的所有奖品——这可能帮助他们在未来生存。

对未来可能发生的事情的预测并不完美，因此，我们的祖先饱受了对如何做的不确定感的困扰。我们并没有的一生都在恐惧、饥饥饿中畏缩，因为我们的大脑进化使得当我们感到轻微到中度不适时，我们大多数人都倾向于探索。当某些新奇且不可预测的事物打破常规时，我们天生会经历兴奋的冲动。独自在图书馆时，我们偷看旁边人的光脚脚踝，结果发现上面有一个我们最喜欢的歌曲歌词的纹身。

当我们处于未知领域时，倾向于探索而非回避是丰富且有意义生活的关键；对于我们的祖先来说，这关乎增加长寿和生殖成功的机会。对焦虑感的过度关注或关注不足，都会阻碍我们采取好奇心的行动。缺乏恐惧，我们可能会做出超出好奇心的行为。

……自我。但这确实没有阻止它们对食物的渴望，或者更准确地说，阻止它们想要做任何事的渴望！那些老鼠看起来像一群在电视屏幕前发呆的冷漠青少年。

害虫是开始理解大脑的一组很好的捕获新成员，但最终你必须研究人类。除了能够绘制出大脑哪些部分处于活跃状态外，我们还可以确定这种活动是在执行任务期间、之前还是之后发生的。坐在扫描仪中，并被告知你将看到一张你过去某个重要人物的照片，在看到照片之前，你大脑的哪些部分会亮起？在看到照片之前的不确定期间，与得知对方是谁时相比，不同的大脑区域会亮起吗？你即将见到谁的神秘感与观察他们照片并回忆的快感是分开的。当我们期待见到某人时的感受，与与某人相处时是不同的。涉及到我们的感受以及下一个动力，时机至关重要。

通过使用扫描技术，我们可以测试关于多巴胺精确作用的竞争性假设。如果多巴胺对于我们奖励时的感受至关重要，那么无论我们是在吃巧克力、吸食柯因、与朋友大笑还是正确回答问题，多巴胺的大脑区域都应该亮起。然而，如果多巴胺对于寻求奖励至关重要，那么当我们热切期待奖励时，同样的脑区域应该亮起，而不是在我们满足口渴或达到潮的时刻。悬而未决的问题（我们接下来将讨论）是快感本身，还是想要和渴望导致了多巴胺的剧烈释放。

问问任何父母是否认为“寻求”与“拥有”之间的区别是偶然的。我采访了玛丽和她的女儿弗兰。弗兰是一个典型的青少年，你不叫她她绝不会下床。在即将发脾气的边缘，玛丽告诉弗兰，如果她表现得好，她就会给她买一辆带有钛合金外壳、减震器和其他顶级配件的新山地自行车。你认为当她知道可能得到一辆自行车时（当“想要”被触发时）发生了什么？感激之情充溢在对话中，家务被完成了，学习小组每周聚会一次，她整个人散发着正能量。你认为当她拿到自行车后发生了什么？日夜兼程，在纯粹的快乐中享受越野径径。与此同时，她的成绩下滑了，直到一个月过去，她再次变成了我们在故事开始时遇到的那同一个人。

当我们获得奖励时，我们被满足了。就像吃了一顿丰盛的大餐，之后我们再也没有动力做任何事了。当我们期待奖励时，我们有动力采取行动。我们被驱动着去冒险以追求它们。这个过程充满活力且通常是令人愉快的。当我们好奇并探索时，我们往往能兼得其美：

- 寻求新奖励的预期性兴奋
- 消费奖励的满足感

通过大脑扫描，科学家们在研究中发现，当人们不知道将发生什么或是否预期会有某种奖励时，纹状体是一片活动的炽热海。如果多巴胺对奖励的可能性做出反应，它应该激励我们去寻找这些奖励。事实正是如此运作的。在人们探索以获得奖励之前，纹状体会亮起。无论我们是在酒吧靠近一个有吸引力的人，并在对方给我们电话号码时被告知滚蛋，在我们采取行动之前，纹状体都会亮起。

这非常重要——我们的大脑为我们采取行动做准备。当我们处于一个新奇、不确定的处境，并注意到我们想要的愉快事物时（想想查理和其他孩子第一次进入威利·旺卡巧克力工厂时），我们可以看到纹状体中多巴胺活动的激增。纹状体准备我们的身体去利用新机会。

新奇 + 开放且乐于的态度 = 新信息被整合到自我中以及个人成长。

我们的身体通过引导注意力集中在现在来准备，动员能量以防我们在即将到来的挑战中需要巨大的努力，启动运动使我们更接近新奇源以及任何我们可以从中吸收的奖励。一个美丽的日落或一段音乐需要我们把注意力投向那个方向并保持在那里；为了利用他人一句有趣的评论，我们需要说出自己的想法，并协调我们的微笑和姿态以显示我们感兴趣。

这是一个重要的发现：并不是所有奖励从纹状体释放多巴胺时都是平等的。当我们认为某物是新奇、不确定的或具有挑战性的，并且我们推向认知边界时，多巴胺以更快的速度产生并释放。此外，当新奇性对我们具有个人意义或重要时（想象一个坐不住的五岁孩子恳求打开圣诞礼物），会有更大的多巴胺级联反应。

# 好奇心感觉很好，有时如此：总结几种好奇心模式

好奇不仅仅是一个中性的、神经过程——我们的情感也随之而来。有时，我们的好奇冒险会涉及喜悦、兴奋的感觉（在太阳升起时沿着一座不活跃的火山徒步），这意味着除了活跃的纹状体和多巴胺爆发外，你还会感到大脑中阿片的激增。阿片类是对那种享受生活提供的奖励的基本 感受最核心的神经递质。

根据字典词条和日常对话，好奇通常指的是一种喜悦、兴奋的状态。我们享受不确定和新奇，因为它们激发了我们的兴趣。我们被未知的惊奇感所吸引。其他时候，我们会刻意寻找新奇、多样和挑战。

好奇与快乐的并存很常见。考虑一个父母听着孩子热情地描述一次校外活动，一个青少年沉浸在电台里一首陌生歌曲的舞动中，或者沉迷于迷人的对话、书籍或游戏。大多数积极的体验都包含某种程度的好奇和探索。无论是音乐、舞蹈、瑜伽、运动、休闲阅读、电影、徒步、旅行、亲密对话、老式游戏还是任何地方，并不重要。

好奇的情绪模式在大脑环路中是可见的。如果我们沉浸于喜悦的探索时可以观察大脑内部，我们看到的是大量的多巴胺和阿片活动。

但快乐并不总是画面的一部分。其他情绪如紧张和挫败感往往混杂在我们的好奇中。我们可能会为已知与未知之间的差距而苦恼。*我眼睛里的那个东西是什么，让我不停地眨眼？停车场里所有的车中，为什么鸽子偏偏挑我的？*

当我们的好奇心因想要知道某事的需求被激发时，快乐来自于获得答案和一种完整感。只有在我们填补了差距之后，我们才会感觉好一些，无论是感到冷静、减轻焦虑、兴奋还是其他情感混合。想一想那些电脑无法配合时充满愤怒的时刻。你试图解决问题，当你通过电话等电脑技术人员时，你们在几个令人沮丧的小小时里都无法解决。你对到底发生了什么很感兴趣，但我不需要告诉你那里哪里有快乐。

约会者是好奇的

关于一起吃晚餐的人是否有和自己同样的感受，老师们好奇什么样的奖励和惩罚能驯服班级的小丑们，而经理们则好奇上个月生产力激增的原因是什么。我们仍然好奇，但根结底，我们想要获得属于自己的信息并消除好奇心。多巴胺细胞会对寻求和不确定的信息做出放电反应，即使在当时我们并不感到兴奋，或者当我们的渴望感到有些不适时。在这种情况下，我们预期大脑中会有大量的多巴胺活动，但鸦片类活动很少或没有。

这种为了缓解未知性带来的紧张感而产生的好奇，与喜悦的惊奇感同样常见。除了具有想要调查和探索的共同特征外，它们还是理解世界的门户。有时这只是一个小小的意义片段，有时我们发现自己对观察世界或生活的方式有了深刻的修正。当然，如果我们无法留住这些经历，最终的结果仅仅是瞬息的奖励。

大脑中还有一个方面需要加入其中——海马体及其在记忆中的作用。纹状体中的多巴胺，无论是像机关枪一样活跃地放电，还是处于伏击状态，都是好奇心和探索行为的核心。如果你消除它，你就会变成一个冷漠、懒惰的家伙。如果你增加它，你就会完全投入世界，寻找并发现新事物。我们纹状体中的多巴胺峰值发生在我们采取好奇行动之前，此时我们仍在热切地决定是否以及如何捕捉那些召唤我们的奖励。目前尚不清楚单凭多巴胺回路是否就能解释经历和接受新事物后发生的学习和成长。它似乎需要海马体的帮助。

大多数积极经历都是转瞬即逝的，它们如此短暂，除了带给我们一丝好感之外几乎无事。为了让一次积极经历持续，我们需要将信息传输到我们的记忆库中。我们需要注意、产生兴趣，并确保它在其他竞相要求立即考虑的刺激背景中脱颖而出。

为什么我们只记得遇到和探索过的部分内容？为什么我们能以极其丰富的的细节记住某些事件，而完全忘记另一些事件？答案的一部分在于被称为海马体的脑叶某部分是否被激活。它是将新奇信息和经历传输到长期记忆的主要区域，对于我们创建新记忆至关重要。

关于海马体的见解来自于多年的实验和手术程序。海马体受损的人在回忆个人经历方面存在问题。为了让我们维持好奇的经历，使其成为我们长期身份的一部分，引导我们走向实现的方向，我们需要海马体——这是大脑边缘系统（或“情感”系统）中至关重要的部分。

当海马体中的电路全速运转时，我们不仅能简单地回忆一段积极的记忆，还能记住事件周围生动的背景细节。事件发生在何时何地？谁在周围？我们当时在想什么、感受什么？事情是什么样的？有了这些丰富的细节，我们可以品味好奇的时刻并从中学习。除了对于记忆过去发生在我们身上的背景至关重要外，最近的研究显示，海马体对于想象未来可能在我们身上发生的情景至关重要。创造力和想象力的种子就种在这个微小的脑区域中。

如果海马体在你热切期待奖励的同时被激活，那么我们不仅仅感到好奇并想要探索。我们能够更好地留住这些时刻，扩展我们的自我感。试图为好奇心寻找单一神经回路是徒劳的。多巴胺、鸦片类物质和海马体共同构大脑组合，使我们从满足的时刻转向持久、丰富、有意义的存在。感激让这一组合协同工作的重要性。

好奇心最大的优势在于，通过在新鲜事物上花费时间和精力，使得更强的神经连接成为可能。事实和经历被合成一张网，为更大的智能和智慧铺平了道路。我们在做出未来决定时变得更加高效。我们更擅长视觉化看似孤立的想法之间的相对性，为更大的创造力铺平道路。当你寻求新的信息和经历并将其整合到先前的知识中，大脑中新的通路是不可避免的。

# 4 好奇的时刻在新奇中引发兴趣，在平凡中产生意义

一个充实的生活始于有趣的时刻。2007年，普林斯顿经济学家阿兰·克鲁格、诺贝尔奖得主丹尼尔·卡尼曼及其同事发表了一篇令人大眼目的论文，题目为《我们更有趣了吗？》。由于过去50年巨大的社会进步、经济繁荣和技术进步，利用空闲时间的方式有了无尽的选择。背景中是一个挥之不去的问题：这些机会让我们让我们花更多时间做我们在乎的事吗？对于我们大多数人来说，答案通常是响亮的否定。大多数人每天中只有不到20%的时间从事那些可以被称为有意义的事情（例如：与亲密朋友聊天、灵性练习和祈祷、做爱、玩耍）。

# 充实的生活由充实的时刻组成

不必如此。我们的生活不必被“日常琐事”所支配。好奇心可以被利用，将日常生活中平凡、令人不满的任务转变为有趣且 60 愉快的事情。这些“增强兴趣”的策略允许我们有意识地从面对我们的日常事件中发现并雕刻奇奇。一旦我们的兴趣被唤起，好奇心就会发挥第二作用，确保这些时刻随着时间的推移而持续。

如果不对所做的事情感兴趣，几乎不可能有动力去实现对我们最重要的目标。当我们变得无兴趣时，我们的投入、努力、创造力、毅力以及许多其他品质都会受到损害。

这两个简单的过程——引发兴趣和维持兴趣——是充实生活的的核心。

鉴于对幸福（或至少比现在更快乐）的近乎普遍渴望，我们对什么贡献了我们的幸福指数感到惊讶的无知。改善生活质量的尝试必须从对占据我们时间的活动的感受见解开始。有几个问题浮现在脑海：我们花了多少时间做我们最喜欢的事情，这成为我们早晨起床的理由？我们花了多少时间在不满意的活动上？在可以随心所欲的情况下，我们是否明智地做了真正愉快和有意义的事情？

阿兰·克鲁格和丹尼尔·卡尼曼让我们看到了普通美国人的日常惯例。他们研究普通人的方法是突破性的。他们意识到，我们每个人都是生活中实际发生情况的不可靠的报告者，特别是我们在事情发生发生时的感受。我们会扭曲对过去的回忆，往往让好的记忆看起来比实际更好，让坏的看起来比实际糟糕得多，并说谎言以便给他人留下良好印象。因此，这些科学家做的是让成千上万的人回顾他们生活中的某一天。研究参与者像电影一样重温他们当天的片段，从

记录从醒来到入睡的从一个场景到下一个场景。

通过捕捉人们生活中真实发生的事件，我们可以诊断问题，发现自己的长处以及如何优化利用这些长处，并对接受什么、改变什么做出探索。

## 我们投入时间和精力的事物构成了我们的生活

有了这些改进的科学工具，我们可以窥探人们生活的内幕。为了准确了解美国人在典型的一天中做了什么，访访者与 4,000 名美国人进行了访谈。受访者被要求一天分为 15 分钟一个片段，并回忆他们做了什么、和谁在一起以及感受如何。我们对这些发现的准确性充满信心，因为这 4,000 人代表了美国的每一个地区，在年龄、性别、种族等方面都与人口普查数据匹配。

在我们在这个星球上停留的时间如此短暂，我们的一天中有百分之几是愉快、有趣且有意义的？我们是否正在浪费活在当下的宝贵机会？

通过发现什么让我们脚踏实、什么让我们感到满足，我们可以寻找方法来加强这些时刻——增加发生的时间、延长持续的时间，或者变得更加正念以便更好地品味。仔细检查我们那些不充实的时刻也同样重要。你可能会对自己有多少时间落入这一领域感到惊讶。通过洞察，我们可以问自己，是否已经准备好通过某些尝试来赢回部分这些不充实的时刻。在工作、人际关系和空闲时间里，是否有明显的地方可以挤出更多的幸福感？

我想分享由此得出的有趣发现。其中大部分内容并不那么美好。为了让这些发现对你产生意义，我想想象一个有六扇区域的饼图。每一扇代表一种不同类型的时刻，它们共同刻画了一个典型美国人的一天。即使它并不完美符合你的生活，我相信通过将自己与外面的普通人 Joe 或 Jane 比较，会有很多收获。
