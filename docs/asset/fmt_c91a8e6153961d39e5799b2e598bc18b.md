# The `ObjectDataSource` Control

`ObjectDataSource` 控件表示业务对象，并允许您将 `ObjectDataSource` 控件与数据绑定控件结合使用，以在 Web 页面上显示、编辑和排序数据，而无需代码或只需少量代码。此控件用于创建依赖于中间层对象来管理数据的 Web 应用程序。`ObjectDataSource` 控件的继承层次结构如下：

```
System.Object

    System.Web.UI.Control

        System.Web.UI.WebControls.DataSourceControl

            System.Web.UI.WebControls.ObjectDataSource
```
