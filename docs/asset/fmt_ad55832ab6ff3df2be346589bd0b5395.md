
# 练习 3：使用迭代器实现枚举器

现有的枚举器允许应用程序升序遍历 `BinaryTree` 对象的内容。然而，某些应用程序需要能够降序遍历 `BinaryTree` 对象。你被要求在 `BinaryTree` 类中添加第二个枚举器以帮助完成此任务。

你将向程序中添加一个枚举器，以反序遍历 `BinaryTree` 对象。你将通过迭代器实现此枚举器。

- 使用 `BinaryTreeTestHarness` 应用程序测试解决方案。
