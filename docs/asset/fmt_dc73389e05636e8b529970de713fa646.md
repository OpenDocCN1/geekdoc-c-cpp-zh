// 时间复杂度：与范围 [first1, last1] 加 [first2, last2] 的大小成线性关系。
```

            ForwardIterator2 first2, ForwardIterator2 last2,

// 并集存储从 result 开始处。
// 时间复杂度：与 [first1, last1) 加 [first2, last2) 的大小成线性关系。
```
