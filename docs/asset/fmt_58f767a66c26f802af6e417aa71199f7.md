## 使用`EnableDecompression`属性

假设Web服务客户端请求Web服务所对应的Web服务器支持压缩（一种通过应用编码来最小化数据[或文件]大小的技术）。由于Web服务器支持压缩，Web服务客户端会以压缩数据的形式收到请求的响应。因此，为了理解Web服务器的响应，Web服务客户端必须解压（一种通过解码将压缩数据[或文件]转换为其原始形式的技术）该响应。

这可以通过`EnableDecompression`属性完成，如果将该属性设置为`True`，则允许Web服务客户端解压数据。

同样，通过将`EnableDecompression`属性设置为`False`来禁用解压。这样，Web服务客户端可以以原始格式接收来自Web服务器的响应。

您需要在Web引用的实例上调用该属性来设置`EnableDecompression`属性。现在，让我们学习如何实现`EnableDecompression`属性，具体内容在`UsingSimpleInterestWebService`之前创建的Web应用程序。在`UsingSimpleInterestWebService` Web应用程序的代码隐藏文件中添加以下代码，如清单18.15所示：

## Sharing Data Across Web Services

假设您想要创建一个需要访问两个Web服务`TypeSharingWebService1`和`TypeSharingWebService2`来执行业务逻辑的Web应用程序。`TypeSharingWebService1` Web服务获取使用该Web应用程序的员工的姓名、中间名和姓氏，而`TypeSharingWebService2` Web服务通过添加员工ID和职位来检索和更新员工详细信息，并在Web应用程序上显示。由于`TypeSharingWebService2` Web服务的操作依赖于`TypeSharingWebService1` Web服务的输出，因此这两个Web服务需要共享相似数据类型的数据。

让我们创建两个名为`TypeSharingWebService1`和`TypeSharingWebService2`的Web服务，以了解如何在Web服务之间共享数据。我们还创建一个可以访问这两个Web服务以执行其任务的Web应用程序。现在，按照以下步骤使用`DataSharingWebService` Web应用程序（可在CD上获得）在`TypeSharingWebService1`和`TypeSharingWebService2`之间完成数据共享过程：

1. 在`TypeSharingWebService1` Web服务的代码隐藏文件中编写清单18.16所示的代码：

### Listing 18.16: Code for the Code-Behind File of the `TypeSharingWebService1` Web Service

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Web;
using System.Web.Services;
/// <summary>
/// Summary description for TypesharingWebService1CS
/// </summary>
[WebService(Namespace = "http://tempuri.org/")]
[WebServiceBinding(ConformsTo = WsiProfiles.BasicProfile1_1)]
// To allow this web service to be called from script, using ASP.NET AJAX, uncomment the following line.
// [System.Web.Script.Services.ScriptService]
public class TypesharingWebService1CS : System.Web.Services.WebService {
    public TypesharingWebService1CS () {
        //Uncomment the following line if using designed components
        //InitializeComponent();
    }
    public class EmpDetails
    {
        public string EmpFirstName;
        public string EmpMiddleName;
        public string EmpLastName;
        public string EmpID;
        public string EmpDesignation;
    }
    [WebMethod]
    public EmpDetails obtainEmpDetail(string FName, string MName, string LName)
    {
        EmpDetails name = new EmpDetails();
        name.EmpFirstName = FName;
        name.EmpMiddleName = MName;
        name.EmpLastName = LName;
        return name;
    }
}
```
