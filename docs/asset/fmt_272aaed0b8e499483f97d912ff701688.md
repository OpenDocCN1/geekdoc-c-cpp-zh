# InfoPath 版本控制

集成到 `K2` 过程的 `InfoPath` 表单通过该过程进行版本控制。每当使用 `InfoPath` 集成向导将表单添加到 `K2` 过程中时，`InfoPath` 模板 `.xsn` 文件的名称将变为唯一并在表单定义内进行唯一映射。在 `InfoPath` 内部，每当保存表单模板时，`InfoPath` 定义中的内部版本号就会递增。此版本号可以在 `InfoPath` 表单的 `manifest.xsn` 文件中找到。
