# 章节总结

理解方法、参数和返回值的概念。

- 方法是一个带命名的指令序列。
- 参数在调用方法时提供。
- 返回值是方法完成后的结果。

![](img/6a52d1dde3a219cfa39d548e31d0e6ce_269_0.png)

能够实现方法。

- 在声明方法时，你为为该方法提供一个名称，为每个参数提供一个变量，并为结果提供一个类型。
- 方法注释解释了方法的目的、参数变量和返回值的含义，以及任何特殊要求。

![](img/6a52d1dde3a219cfa39d548e31d0e6ce_269_1.png)

描述参数传递的过程。

- 参数变量保存了方法调用时提供的参数。

![](img/6a52d1dde3a219cfa39d548e31d0e6ce_269_2.png)

描述从方法返回值的的过程。

- `return` 语句终止方法调用并产生方法结果。
- 将可以重用的计算转换为方法。

![](img/6a52d1dde3a219cfa39d548e31d0e6ce_269_3.png)

- 使用 `void` 返回类型表示该方法不返回结果。

![](img/6a52d1dde3a219cfa39d548e31d0e6ce_269_4.png)

- 通过定义方法来消除重复的代码或伪代码。
- 设计你的方法使其具有重用性。为方法在重用时可能变化的值提供参数变量。

应用步进细化的设计原则。

- 使用步进细化的过程将复杂任务分解为更简单的任务。
