## 10.1 什么是顺序控制结构？

顺序控制结构指的是逐行执行，语句按照它们在程序中出现的顺序逐一执行，而不跳过任何一个。它们可能会执行一系列读/写操作、算术运算或变量赋值。

以下程序展示了顺序执行的 C++ 语句示例。

```cpp
#include <iostream>
using namespace std;
int main() {
    double num, result;

    // 提示用户输入 num 值
    cout << "Enter a number: ";
    cin >> num;

    // 计算 num 的平方
    result = num * num;

    // 将结果显示在用户的屏幕上
    cout << "The square of " << num << " is " << result << endl;
    return 0;
}
```

+ 顺序控制结构是你在 4.11 节中学到的三种基本控制结构中最简单的。另外两个是“选择结构”和“循环结构”。计算机编程中的所有问题都可以使用这三种结构解决！

- 在 C++ 中，你可以使用双斜杠 `//` 添加注释。注释是给人类读者看的。编译器和解释器会忽略它们。

## 练习 10.1-2 计算圆的面积

编写一个 C++ 程序，计算并显示圆的面积。

## 解决方案

可以使用以下公式计算圆的面积：

# 面积 = $\pi \cdot Radius^2$

$\pi$ 的值是一个已知数，即 `3.14159`。因此，用户必须输入的值只有 `Radius`（半径）。

在此次练习中，你在第 4.6 节中学到的三个主要阶段如下：

- **数据输入** - 用户必须输入 `Radius` 的值

- **数据处理** - 程序必须计算圆的面积

- **结果输出** - 程序必须显示上阶段计算出的圆的面积。

该问题的解决方案在此所示。

![](img/6e4b8e11c2f26304087157218fda632f_157_0.png)

```cpp
#include <iostream>
using namespace std;
int main() {
    double area, radius;

    //Data input - 提示用户输入半径值
    cout << "Enter the length of Radius: ";
    cin >> radius;

    //Data processing - 计算圆的面积
    area = 3.14159 * radius * radius;

    //Results output - 在用户屏幕上显示结果
    cout << "The area of the circle is " << area << endl;
    return 0;
}
```

一种更好的方法是使用常量 `PI`。

![](img/6e4b8e11c2f26304087157218fda632f_157_1.png)

```cpp
#include <iostream>
using namespace std;
const double PI = 3.14159;

int main() {
    double area, radius;

    //Data input - 提示用户输入半径值
    cout << "Enter the length of Radius: ";
    cin >> radius;

    //Data processing - 计算圆的面积

    //Results output - 在用户屏幕上显示结果
```

## 练习 10.1-5 华氏转开尔度
