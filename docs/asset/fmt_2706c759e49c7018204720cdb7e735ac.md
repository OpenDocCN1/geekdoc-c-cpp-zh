## MenuStrip and StatusStrip Controls

`MenuStrip` 控件表示用于包含表单菜单选项的容器控件。`StatusStrip` 控件显示有关在表单上查看的对象的相关信息。您可以显示应用程序的状态或在窗口上查看的对象的相关信息。您也可以在 CD 上的附录章节 5《Windows 窗体控件：ToolStrip、MenuStrip、ContextMenuStrip、StatusStrip 和对话框控件》中了解这些控件。在本章中，您将学习如何将数据从数据源绑定到控件。

让我们创建一个名为 `MenuandStatusStrip` 的 Windows 窗体应用程序（也可在 CD 上获得）并添加一个 `ListBox` 控件、`MenuStrip` 控件、`DataGridView` 控件、一个 `Button` 控件和一个 `StatusStrip` 控件。添加 `MenuStrip` 控件后，创建两个菜单——`File` 和 `Exit`——作为主菜单。此外，将 `OrderID`、`ProductID`、`Price`、`Quantity` 和 `Discount` 创建为 `File` 菜单的子菜单。现在，将清单 25.8 中提供的代码添加到 `Form1.cs` 文件中，该文件是应用程序的代码隐藏文件：

## Using the BindingContext Class

`BindingContext` 类提供了有关在 Windows 应用程序中绑定各种数据元素的信息。`BindingContext` 类的继承层次结构如下所示：

```
System.Object
System.Windows.Forms.BindingContext
```

每个继承自 `Control` 类的对象都可以有一个 `BindingContext` 对象，该对象可帮助您访问窗体中的数据绑定。

表 25.2 列出了 `BindingContext` 类值得注意的公共属性：

Table 25.2: Noteworthy Public Properties of the BindingContext Class

| Property | Description |
|---|---|
| Item | Retrieves an object of the BindingManagerBase class that is associated with data source and data member |
| IsReadOnly | Retrieves a value indicating whether the collection is read-only |

表 25.3 列出了 `BindingContext` 类值得注意的方法：

Table 25.3: Noteworthy Public Methods of BindingContext Class

| Method | Description |
|---|---|
| Contains() | Specifies whether or not the BindingContext class contains a particular item |
| UpdateBinding() | Associates a binding with a new BindingContext object |

`BindingContext` 对象的 `Position` 属性用于在数据集中移动。让我们创建一个名为 `NavigatingRecords` 的 Windows 窗体应用程序（也可在 CD 上获得），以显示数据集中记录的当前位置。将清单 25.9 中提供的代码添加到 `Form1.cs` 文件中，该文件是应用程序的代码隐藏文件：
