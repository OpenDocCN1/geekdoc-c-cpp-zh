## 深入

指针、委托和事件处理系统是 C# 的最重要的特性之一。指针是保存另一个数据类型（如 int 和 char）的内存地址的变量。指针变量使用解引用运算符 (`*`) 声明。委托是一种引用方法的类型。在方法被分配给委托后，委托的行为与分配的方法完全相同。`delegate` 关键字用于在 C# 中声明委托，与 C 或 C++ 中的函数指针类似。委托还可用于创建自定义事件。事件是委托类型的类成员，由对象或类用来通知其他对象已发生事件。事件可以使用 `event` 关键字声明。

## 指针

指针是一个保存另一个变量地址的内存变量。指针在 C 等过程式编程语言中被广泛使用。当程序的执行速度非常重要时，您可以使用指针，因为它允许您非常快速地编写低级代码。为了维护程序的类型安全性和安全性，您必须使用 `unsafe` 关键字在命令行编译程序。此外，指针必须出现在用 `unsafe` 关键字标记的代码段中。用 `unsafe` 标记的代码在通用语言运行时 (`CLR`) 的控制之外运行。让我们现在学习如何声明不安全代码、声明指针、对指针执行算术运算以及转换指针。

## 声明不安全代码

指针在 C# 中不是固有的；然而，它们可以在不安全代码中使用，即已标记为 `unsafe` 的代码。您可以通过使用 `unsafe` 关键字创建一个块并将该代码放在 `unsafe` 块内，将程序代码的一部分标记为 `unsafe`。此外，您还可以通过在它们的声明中使用 `unsafe` 关键字，将结构、类和类型成员（变量或方法）标记为 `unsafe`。默认情况下，`CLR` 检查程序代码的类型安全性。如果程序代码仅通过接口访问其他代码片段，则认为该程序代码是类型安全的。因此，如果您的程序包含一些标记为 `unsafe` 的代码，C# 编译器不会编译您的程序代码，直到您明确告诉 C# 编译器跳过类型安全检查。跳过类型安全检查的一种方法是使用 C# 命令行编译器实用程序 `csc.exe` 编译 C# 源代码文件，并在编译 C# 源代码文件时指定 `/unsafe` 关键字。考虑以下代码片段以学习 `unsafe` 关键字在 C# 程序中的实现：

```
unsafe
{
    int[] x = new int[10];
    int *px = &x;
}
```

在前面的代码片段中，定义了一个 `unsafe` 块，允许您将指针分配给数组。让我们考虑另一个允许您定义指向数组的指针的代码片段：

```
unsafe
{
    int *x = new int[10];
}
```

在前面的代码片段中，整数指针 (`int *x`) 不是数组；因此，您不能将数组分配给它。您不能删除数组；因此，它应被垃圾回收。

有时，你需要创建一个指针来调用外部函数（即类外部的函数）。通过指针调用外部函数的问题在于，指针指向一块内存，而该内存可能被垃圾回收或在内存中移动。在这种情况下，C# 提供了 `fixed` 语句，允许你在调用指定的外部函数之前将指针固定在内存中。以下代码片段展示了如何使用 `fixed` 语句：

```
unsafe {
int[] x = new int[10];
fixed(int *p = &x)
{
    CallAFunctionWithAPointer(*p);
}
```

正如你在上述代码片段中所见，`fixed` 关键字将指针固定在内存中，直到你调用 `CallAFunctionWithAPointer()` 函数为止。固定指针只是一个临时步骤，因为你无法永远将指针固定在内存中——锁定仅在 `fixed` 关键字包围的块的起始花括号和结束花括号之间生效。

