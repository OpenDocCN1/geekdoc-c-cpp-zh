# 24.7.12 Split view

## 概述
`split view` 接收一个视图和一个分隔符，并将该视图拆分为子范围。分隔符可以是单个元素，也可以是元素的视图。给定表达式 `E` 和 `F`，`expression(E, F)` 等同于 `split_view(E, F)`。
示例：
```cpp
string str("the quick fox");
split_view sentence(str, ' ');
for (auto word : sentence) {
    for (char ch : word) {
        cout << ch;
    }
}
// 上述打印：the*quick*fox*
```
