
`s(n-1) = cos(omega n) + j sin(omega n)`.

我们可以将其写为复指数：

```
cos(omega n) + j sin(omega n) = e^{jω(n-1)}.
```

从求和变为指数的乘法，我们得到：

```
e^{jω(n-1)} = e^{-}s(n).
```

实际上，我们得到的是

```
s(n-1) = z^{-1}s(n),
```

这意味着一个采样延迟等同于乘以 `z^{-1}`。同样，延迟 `d` 个采样等同于乘以 `e^{-jω}`。乘以 `z` 是一种特殊情况，通常发生在 z 域，其中时域信号如 `s(n)` 由它们的 z 变换表示。另一种观点是将 `z` 作用于整个信号的运算符。例如，如果我们想表示上述两个信号的混合，可以使用此运算符：

```
Y = S + z^{-d}S,
```

其中 `Y` 代表输出，`S` 代表输入（事实上，这些是时域信号 `y(n)` 和 `s(n)`）。所以我们可以看到现在基本操作都基于加法乘法。

## 5.5 信号处理的应用

补充基本操作的是上述思想的两个应用。第一个演示了信号变换的方法；第二种是经典的合成技术。

### 5.5.1 使用滤波器变换信号

滤波是一种信号处理操作，旨在以不同的方式变换声音。滤波常用的应用是增强、衰减或阻塞输入的某些分量，即改变其分量的幅值。其他滤波器应用涉及修改不同分量的相位偏移。这两种类型的处理分别对应滤波器的两个方面：幅度响应和相位响应。在大多数音乐处理应用中，我们倾向于关注响应，因为这是最直接的感知效果。但在某些情况下，相位响应在信号变换中可能起重要作用。

滤波器通过将输入信号与缩放且延迟的信号结合构建，有两种形式：

- 输入延迟：信号的拷贝
- 输出延迟：即信号的延迟拷贝（可以视为反馈的形式）。

这两种延迟产生了两种不同的滤波器：使用输入延迟产生有限脉冲响应（FIR），使用输出延迟产生无限脉冲响应（IIR）。这两类滤波器也分别称为前馈或非递归滤波器以及反馈或递归滤波器。

## 数字音频简介

为了理解这些概念，我们将检查一个简单的 FIR 滤波器并研究其特性。简单的滤波器之一是将信号与其单采样延迟拷贝结合，并将两者都缩放 0.5，如下：

`y(n) = 0.5x(n) + 0.5x(n-1), (33)`

其中我们习惯上将滤波器输出标记为 `y(n)`，输入标记为 `x(n)`。方程 33 是所谓的滤波器方程。
0.5 的缩放值被称为滤波器系数，在这种情况下，输入和滤波单采样延迟是相同的。这种特定的滤波器也称为*平均一阶滤波器*，因为它取当前输入及其之前值的平均值，并且只使用一个采样延迟；延迟为 `N` 个采样的滤波器是 `N` 阶滤波器。该滤波器可以使用代码片段在 C 中实现：

```c
for(n=0; n < N; n++) {
  out[n] = (in[n] + delayed) * 0.5; /* 滤波器方程 */
  delayed = in[n];                  /* 保留之前的输入 */
}
```

为了检查该滤波器的影响，我们需要找到它的幅值响应。我们可以通过使用复指数重写滤波器来实现这一点（见方程 31）。这将带给我们 `x(n) = e^{jkω}` 和 `z = e^{-jω}`

`y(n) = 0.5[x(n) + z^{-1}x(n)]. (34)`

我们移动了 0.5，为了简单起见，现在可以忽略它（它仅等于调低输出量）。这个表达式给了我们通过重新解释 `z^{-1}` 为复指数来评估滤波器对不同频率的正弦波所作用的可能性：

`y(n) = x(n) + z^{-1}x(n) = x(n) + e^{jkω}x(n)[1 + e^{-jω} (35)`

这个表达式显示了滤波是缩放在信号处理中的另一种用法，因为我们实际上是将信号 `x(n) = e^{jkω}` 乘以复函数 `F(ω) = e^{-jω}`。这种乘法的结果是输出将是具有修改后的幅值和相位的信号。输出的幅值是多少？随着改变正弦波的频率，幅值也会变化。这演示了滤波器的作用；在这种情况下，是对输入信号不同频率成分的衰减。这种随变化的衰减可以通过绘制方程 34 中信号在不同频率 `ω` 值下的幅度来找到。

由于滤波器表达式是复杂的，我们需要找到它的幅度（见方程 13，由 `|1 + e^{-jω}|` 指示）并等同于滤波器的幅度响应：

`A(ω) = |1 + e^{-jω}|`
`= |1 + cos(ω) - j sin(ω)|`
`= sqrt([1 + cos(ω)]^2 + [-sin(ω)]^2)`
`= sqrt(1 + 2cos(ω) + cos^2(ω) + sin^2(ω))`
`= sqrt(2 + 2cos(ω)) = sqrt(4cos^2(ω/2)) = 2cos(ω/2). (36)`

现在，记得我们之前省略了 0.5 的缩放，我们可以绘制滤波器的幅度响应（图 5.10）。这是通过将 `ω` 重新定义为 `2π f/sr`（其中 `f` 现在是 Hz 单位频率）实现的，得到的滤波器幅度响应表达式为 `cos(π f/sr)`，即从 0 Hz 到 `sr/2` 的余弦波的前四分之一。滤波器的形状使其成为低通滤波器，即衰减高频并让低频通过或较少失真通过的滤波器。

滤波器对信号进行复数缩放的另一个方面是，它将改变输入信号中不同正弦分量的相位偏移。这意味着信号将施加固定的延迟，这是预料之中的，因为我们使用了延迟操作。与幅度响应类似，相位响应会随频率变化

**图 5.11**
一阶平均滤波器的相位响应，`sr = 44.1 kHz`。

因此我们也可以使用上述原理对其进行评估，只是我们必须提取复数缩放函数 `F(ω) = 1 + e^{-jω}` 的角度。如方程 13 所示，这是通过取其虚部与实部之比的正切值来实现：

`PH(ω) = ∠(1 + e^{-jω})`
`= ∠(1 + cos(ω) - j sin(ω))`
`= arctan((-sin(ω))/(1 + cos(ω)))`
`=-ω/2. (37)`

换句话说，如图 5.11 所示，相位偏移随频率线性变化。`ω/2` 或 `π f/s` 的延迟代表半个采样的延迟，因为具有这种延迟的正弦信号为 `cos(ω|n| - 0.5ω)`。

事实上，我们可以预测此滤波器的相位响应，因为系数关于中心点对称的 FIR 滤波器表现出线性相位响应，延迟为 `N/2` 个采样，其中 `N` 是滤波器的阶数。在这种情况下，系数 0.5 和 0.5 满足了线性相位响应的先决条件，其延迟是可以预期的半个采样。并不是所有的滤波器都是线性相位的，事实上某些滤波器的相位响应可能非常复杂，但通过选择其系数可以使 FIR 变为线性相位。

# 第5章

我们用于获取幅和相位响应的复函数 `F(ω) = 1 + e^{-jω}` 也称为滤波器的*频率响应*。它实际上是更通用的表达式*传递函数*的一个特例。滤波器的作用是信号与其传递函数的乘。滤波器幅度和相位响应的组合就是它的*频率响应*。一阶 FIR `y(n) = a0x(n) + a1x(n-1)` 传递函数的通用形式为 `H(ω) = a0 + a1e^{-jω}`，其幅度

`A(ω) = sqrt(a0^2 + 2a0a1cos(ω) + a1^2)`

不同的系数值将为相同的滤波器设计产生不同的幅度响应。例如，通过将系数 `a1` 设置为负值，可以从上述滤波器获得高通响应。上述讨论的滤波器类型正如提到的，它仅提供了输入信号的通用变换。然而，这里引入的概念可以应用于更复杂的滤波器类型。对于音乐用途，我们通常选择使用反馈滤波器，因为它们提供了更戏剧的效果。尽管它们表现出更复杂的幅度和相位响应，但可以使用上述原理进行研究。主要区别在于我们使用了滤波器输出的延迟副本，如方程所示，描述系数 `a` 和 `b` 的一阶反馈滤波器：

`y(n) = ax(n) - by(n-1)`

使用之前相同的工具和定义，我们可以通过对方程进行额外的乘法推导出此滤波器的频率响应：

`y(n) = ax(n) - bz^{-1}y(n)`

相位调制（PM）和频率调制（FM）的另一个点是，信号分量的频率取决于载波频率与调制频率之比 `ωc/ωm`。正如此，可以生成各种声音（或无音高的声音），从鼓和轮子到木管和铜器仿真。这些声音中的任何一种在加法合成参数中的描述都会非常复杂，如公式 46 所示，但通过公式 45 使用两个生成声音的正弦函数就可以轻松创建。

相位调制与调制有相似之处。然而，我们不是将两个信号简单相乘，而是使用其中一个信号的复合指数运算。为了说明这一点，我们可以用复信号表达式来定义（仅取其实部）：

`pm(n) = cos(ωn n + I sin(ωm n))`

`= real[e^{i(ωn n + I sin(ωm n))}] (48)`

`= J0(I) + 2 sum_{k=1}^{∞} Jk(I) cos(2k ωm n) + J_{k-1}(I) sin(|2k-1| ωm n) (49)`
