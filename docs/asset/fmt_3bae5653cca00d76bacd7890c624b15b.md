# 扩展 ASCII (26.4.5)

七位 ASCII 提供 128 个可能的元素。回想二进制信息的单位是 2 的幂。

- `2¹ = 2` 单位
- `2² = 4` 单位
- `2³ = 8` 单位
- `2⁴ = 16` 单位
- `2⁵ = 32` 单位
- `2⁶ = 64` 单位
- `2⁷ = 128` 单位

七位 ASCII 对于英文文本是可以的，但它缺乏国际货币符号，如 `£`（英镑）和 `¥`（日元）。它缺少带有变音符号的字母，如西班牙语、法语中的 `é` 和 `à`。ASCII 最终扩展到 8 位，这可以表示 256（那是 `2⁸`）不同的元素。这些元素包括变音符号、国际符号以及各种形状。图 26-24 展示了扩展 ASCII 字符集中的符号。
