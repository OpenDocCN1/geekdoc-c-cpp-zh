
与网站中的网页类似，WPF 页面是 XBAP 中的基本实体。XBAP 中的页面保存显示给用户的内容。当你创建一个 XBAP 时，会自动包含一个页面。此外，当 XBAP 运行后，用户可以导航到 XBAP 中的任何页面。单个 XBAP 页面是 `Page` 类的一个实例。`Page` 类的类层次结构为：

## 应用程序类

无论是独立的还是 XBAP 的 WPF 应用程序，都由 `Application` 类的一个实例表示。该类提供了配置和运行 WPF 应用程序的一些基本功能。例如，`Application` 类允许你控制 WPF 应用程序的生命周期、处理命令行参数和退出代码、处理事件和运行时异常，以及跟踪 WPF 应用程序的导航。

请注意，`Application` 类在两种形式中都可用，分别是使用 `App.xaml` 和 `App.xaml.cs` 文件的 XAML 代码和 .NET 语言代码。在 XAML 中，`<Application>` 标签或元素表示应用程序，而在代码隐藏文件中，`App` 部分类执行相同的功能。`Application` 类的类层次结构如下：

在 Visual Studio 2010 中，WPF 4.0 设计器是设计器界面，它提供了一种简单、快速和交互的方式来处理 WPF 应用程序的 UI。在开始创建和处理功能齐全的 WPF 应用程序之前，让我们先了解一下重要的 WPF 设计器元素。图 9.13 显示了独立 WPF 应用程序的 WPF 4.0 设计器：

### 图 9.13：独立应用程序的 WPF 设计器

在图 9.13 中，你可以看到 WPF 设计器，它由一个窗口、一个类似窗体的结构组成，出现在 WPF 设计器的中央，就像 Windows 窗体出现在 Windows 窗体设计器中央一样。此外，WPF 设计器和 Windows 窗体设计器都有解决方案资源管理器、属性窗口和工具箱。两者之间的唯一区别是 WPF 设计器分为两个主要设计视图，即设计视图和 XAML 视图。其他设计器元素，例如拆分视图栏和标签导航器，可帮助你使用设计视图和 XAML 视图。我们先来探索设计视图。

#### 网格导轨、网格线和网格线指示器

网格导轨、网格线和网格线指示器与 WPF 的 `Grid` 元素或控件有关。当你创建 WPF 应用程序时，`Grid` 元素默认会添加到应用程序中。顾名思义，`Grid` 元素允许你将 WPF 应用程序表示为网格或晶格。整个网格由网格导轨包围，网格导轨分别在顶部和左侧水平和垂直延伸，如图 9.14 所示。

默认情况下，网格有一个行和一列；但是可以有多个行和列。你可以通过单击网格导轨上的所需位置来创建额外的行和列。当你单击网格导轨时，网格线和网格线指示器会相应出现（图 9.14）。如果你单击顶部的网格导轨，则会出现一条垂直网格线，将网格分为两列。同样，如果你单击左侧的网格导轨，则会出现一条水平网格线，将网格分为两行。你可以多次单击网格导轨以在网格中创建行和列。你可以通过移动出现在网格导轨上的三角形网格线指示器来控制行和列的高度和宽度。

> NOTE
>
> `Grid` 控件有一个名为 `FlowDirection` 的属性。此属性默认设置为 `LeftToRight`。但是，当此属性设置为 `RightToLeft` 时，会导致网格导轨出现在窗口的顶部和右侧。

#### 边距线和边距桩

在 WPF 4.0 中，控件存在于容器控件内，其中之一是 `Grid` 控件，当你创建它们时，该控件会自动添加到 WPF 应用程序中。当你在网格上拖放控件时，你可以更改控件与网格之间的距离，即边距。边距是从控件边缘到容器控件边缘的距离。如果你使用 `Grid` 作为容器控件，则边距是从控件边缘到最近网格线的距离。每个控件都有四个边距——顶部、底部、左侧和右侧。这些边距由从控件边缘伸出的四条直线表示，称为边距线，如图 9.18 所示：
