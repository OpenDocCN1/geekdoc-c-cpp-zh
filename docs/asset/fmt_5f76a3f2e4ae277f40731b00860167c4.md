## 在数组的特定位置插入数据项

遗憾的是，当你要在数组末尾以外任何地方添加数据项时，必须为新项留出空间。这个过程涉及找到数组中要插入新项的位置，并将所有后续元素在数组中向下移动一个位置。这在数组中“打开”了一个空间来存储新项。

用例 9.1 - `array.cpp`

## 创建和访问二维数组

下面的示例使用二维数组存储并显示一些井字（nought-and-cross）数据。

数组中的每个项目都使用两个不同的索引数字，每个索引数字包含在 [ ] 括号内。

第一个索引表示网格的行号。第二个索引表示列号。

```cpp
#include <iostream> // 程序将在屏幕上显示一些文本
using namespace std; // 将使用标准标识符 cout 和 endl
int main()
{
    // 2D 数组用于存储 O 和 X 符号的位置
    char grid[3][3];
    // 存储符号的数据，如所示
    // 第一行 - 行 0
grid[0][0] = 'X'; // 行 0，列 0
grid[0][1] = ' '; // 行 0，列 1
grid[0][2] = 'O'; // 行 0，列 2
    // 中间 - 行 1
grid[1][0] = 'O'; // 行 1，列 0
grid[1][1] = 'X'; // 行 1，列 1
grid[1][2] = ' '; // 行 1，列 2
    // 底行 - 行 2
grid[2][0] = 'O'; // 行 2，列 0
grid[2][1] = 'O'; // 行 2，列 1
grid[2][2] = 'X'; // 行 2，列 2
    // 使用循环访问项目并在屏幕上显示网格
    int row, col;
    for (row = 0; row < 3; row++)
    {
        for (col = 0; col < 3; col++)
        {
            cout << grid[row][col];
        }
        cout << endl; // 在行结束时移动到新行
    }
} // 行循环结束
return 0;
}
```
