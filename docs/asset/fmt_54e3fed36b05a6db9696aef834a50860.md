
### 算法设计

#### a. 寻找平均测试分
首先，你设计一个寻找平均测试分的算法。要找到平均测试分，你首先需要统计学生人数并累加每个学生的分数。然后总和除以 `count` 得到平均分。寻找平均测试分的算法为：

i. 将 `sum` 和 `count` 设置为 0。

ii. 对班级每个学生重复以下操作。
   i. 获取 `testScore`
   ii. `count` 加 1，并通过将当前测试分数加到 `sum` 来更新 `sum` 的值。

iii. 使用以下公式找到平均分。

如果 (`count` 为 0)
```
averageTestScore = 0;
```
否则
```
averageTestScore = sum / count;
```

#### b. 打印低于平均分的学生姓名
以下算法确定并打印所有测试分低于平均分的学生姓名。

对班级每个学生重复以下操作：
i. 获取 `studentName` 和 `testScore`
ii. 如果 (`testScore` 小于 `averageTestScore`)
    打印 `studentName`

#### c. 确定最高分
以下算法确定最高分。

i. 获取第一个学生的测试分并将其命名为 `highestTestScore`。
ii. 对班级剩余的每个学生重复以下操作
   1. 获取 `testScore`
   2. 如果 (`testScore` 大于 `highestTestScore`) 则 `highestTestScore = testScore;`

#### d. 打印与最高分相同的学生姓名
要打印所有分数与最高分相同的学生姓名，将每个学生的分数与最高分进行比较，如果相等则打印姓名。以下算法实现了此任务。

#### e. 遍历学生
对每个学生重复以下操作：
i. 获取 `studentName` 和 `testScore`
ii. 如果 (`testScore` 等于 `highestTestScore`) 则打印 `studentName`

你可以使用从 a 到 d 部分获得的子问题解决方案来设计如下主算法：

1. 使用 a 部分的算法找到平均分。
2. 使用 b 部分的算法打印所有分数低于平均分的学生姓名。
3. 使用 c 部分的算法找到最高分。
4. 使用 d 部分的算法打印所有分数与最高分相同的学生姓名。
