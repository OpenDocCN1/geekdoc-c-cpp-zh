## 7.12 数学 `<math.h>`

头文件 `<math.h>` 声明了许多数学函数并定义了若干宏。大多数摘要说明了一系列函数，其中包含具有一个或多个 `double` 参数和 `double` 返回值的主函数；或者具有相同名称但带有 `f` 和 `l` 后缀的其他函数，这些是与 `float` 和 `long double` 参数、返回值或两者都对应的函数。整数算术函数和转换函数将在稍后讨论。

### 类型

```
float_t
double_t
```

它们分别是宽度至少不小于 `float` 和 `double` 的浮点类型，且 `double_t` 的宽度至少达到 `float_t`。如果 `FLT_EVAL_METHOD` 等于 0，`float_t` 和 `double_t` 分别为 `float` 和 `double`；如果 `FLT_EVAL_METHOD` 等于 1，两者均为 `double`；如果 `FLT_EVAL_METHOD` 等于 2，两者均为 `long double`；对于 `FLT_EVAL_METHOD` 的其他值，它们由实现定义。

### 宏

```
HUGE_VAL
```

展开为一个正的 `double` 常数表达式，该值不一定可以表示为 `float`。宏

```
HUGE_VAL
HUGE_VALL
```

分别是 `HUGE_VAL` 的 `float` 和 `long double` 对应项。

宏

```
INFINITY
```

如果可用，则展开为 `float` 类型的常量表达式，表示正无穷或无符号无穷；否则展开为在大于 `> 2^26` 时溢出的 `float` 类型正常数。

> 226) 特别是在具有宽表达式评估机制的系统上，`<math.h>` 函数传递参数和返回值时的宽度可能比摘要原型指示的宽。

> > 227) 类型 `float_t` 和 `double_t` 旨在成为实现中宽度至少不小于 `float` 和 `double` 的高效类型。对于 `FLT_EVAL_METHOD` 等于 0、1 或 2，类型 `float_t` 是实现用于评估表达式的窄类型。

> > 228) 在支持编译时实现的环境中，`HUGE_VAL`、`HUGE_VALF` 和 `HUGE_VALL` 可以是正无穷。²²²⁹

## 5 宏 `NAN`

当且仅当实现支持 **float** 类型的静默 NaN 时定义。它展开为一个表示静默 NaN 的 **float** 类型的常量表达式。

表示互斥的浮点值种类。它们展开为具有不同值的整数常数表达式。实现还可能指定额外的实现定义浮点分类，其宏定义以 **FP_** 且跟一个大写字母开头。

是可选定义的。如果定义，它表示 **fma** 函数的执行速度通常与 **double** 操作数的乘法和加法一样快，甚至更快。²³⁰ 宏

```
FP_FAST_FMAF

```

分别是 **FP_FAST_FMA** 的 **float** 和 **long double** 对应项。如果定义，这些宏展开为整数常数 **1**。

## 8 宏

展开为整数常数表达式，当 **x** 分别为零或 NaN 时，其值由 **ilogb(x)** 返回。**FP_ILOGB0** 的值应为 **INT_MIN** 或 **-INT_MAX**。**FP_ILOGBNAN** 的值应为 **INT_MAX** 或 **INT_MIN**。

> ²³¹ 在情况下，使用 **INFINITY** 将违反 6.4.4 中的约束，因此需要诊断信息。

> > ²³⁰ 通常，当且仅当 **fma** 函数使用硬件乘加指令实现时，才会定义 **FP_FAST_FMA** 宏。软件实现预计速度会要慢得多。

## 宏

```
MATH_ERRNO
MATH_ERREXCEPT
```

分别展开为整数常数 1 和 2；宏

```
math_errhandling
```

展开为类型为 `int` 且值为 `MATH_ERRNO`、`MATH_ERREXCEPT` 或两者按位或结果的表达式。`math_errhandling` 的值在程序运行期间是常数。不确定 `math_errhandling` 是宏还是具有外部链接的标识符。如果抑制了宏定义或程序定义了名为 `math_errhandling` 的标识符，则行为未定义。如果表达式 `math_errhandling & ERREXCEPT` 不为零，实现应在 `<math.h>` 中定义宏 `FE_DIVBYZERO`、`FE_INVALID` 和 `FE_OVERFLOW`。

### 7.12.1 错误情况的处理

- 1 除非有说明，`<math.h>` 中每个函数的行为在其输入参数的所有可表示值上都有规定。每个函数的执行都应如单次操作一样，不产生 `SIGFPE` 也不产生任何“无效”、“除以零”或“溢出”的浮点异常，以反映函数的结果。

- 2 对于所有函数，如果输入参数在数学函数定义的范围之外，则发生域错误。每个函数的描述列出了任何所需的域错误；实现可以定义额外的域错误，只要这些错误与函数的数学定义一致。²⁾ 当发生域错误时，函数返回一个实现的值；如果整数表达式 `math_errhandling & MATH_ERRNO` 不为零，则 `errno` 设置为 `EDOM`；如果 `math_errhandling & ERREXCEPT` 不为零，则产生“无效”浮点异常。

- 3 同样，如果数学函数在极限处具有精确无穷的结果（例如，0），则发生极点错误（称为奇异性）。每个函数的描述列出了任何所需的极点错误；实现可以定义额外的极点错误，只要这些错误与函数的数学定义一致。发生极点错误时，函数返回一个实现的值；如果整数表达式 `math_errhandling & MATH_ERRNO` 不为零，则 `errno` 变为 `ERANGE`；如果 `math_errhandling & ERREXCEPT` 不为零，则产生“除以零”浮点异常。

- 4 同样，如果函数的数学结果由于幅度极大而无法表示，则发生错误。

- 5 如果数学结果的幅度是有限的但太大，以至于在指定的类型对象中无法在产生舍入误差的情况下表示，则发生浮点溢出。如果发生浮点溢出且默认舍入误差有效，函数返回 `HUGE_VAL`、`HUGE_VALF` 或 `HUGE_VALL`（取决于返回类型），符号与正确值相同；如果整数表达式 `math_errhandling & MATH_ERRNO` 不为零，则 `errno` 变为 `ERANGE`；如果 `math_errhandling & ERREXCEPT` 不为零，则产生“溢出”浮点异常。

- 6 如果数学结果的幅度太小，以至于在指定的类型对象中无法在产生舍入误差的情况下表示，则发生下溢。²² 当结果下溢时，函数返回一个实现的值，其幅度不超过指定类型中最小的正一规格化数；如果 `math_errhandling & MATH_ERRNO` 不为零，`errno` 获取 `ERANGE` 由实现定义；如果 `math_errhandling & ERREXCEPT` 不为零，是否产生“下溢”浮点异常由实现定义。

- 7 如果发生了域错误、极点错误或范围错误，且表达式 `math_errhandling & MATH_ERRNO` 为 0，²³³ 则 `errno` 应被设置为对应错误的值或保持不变。如果没有发生此类错误，无论 `math_errhandling` 如何设置，`errno` 都应保持不变。

> 在支持无穷的实现中，如果函数的域不包含无穷，则允许无穷作为域错误的参数。

> ²³² 此处的“下溢”术语旨在涵盖 IEC 60559 中的“渐进下溢”以及“刷新为零”下溢。

> > ²³³ 数学错误通过浮点异常标志位指示，而不是通过 `errno`。

## 7.12.2 FP_CONTRACT pragma

概要

```
#include <math.h>
#pragma STDC FP_CONTRACT on-off-switch
```

描述

`FP_CONTRACT` pragma 可用于允许（当状态为“on”时）或禁止（当状态为“off”时）实现转换强制类型表达式（6.5）。每个 pragma 均出现在外部声明之外，或者位于复合语句内部所有显式声明和语句之前。在外部声明之外，该 pragma 从其出现处开始生效，直到遇到另一个 `FP_CONTRACT` pragma 或翻译单元的结束。在复合语句内部，该 pragma 从其出现处开始生效，直到遇到另一个 `FP_CONTRACT` pragma（包括嵌套的复合语句）或复合语句结束；在复合语句结束时，该 pragma 的状态将恢复到复合语句执行前的状态。如果在任何其他语文中使用此 pragma，其行为是未定义的。该 pragma 的默认状态（“on”或“off”）由实现定义。

## 7.12.3 分类宏

在本子类的概要中，`real-floating` 表示参数应为实数浮点类型的表达式。

### 7.12.3.1 fpclassify 宏

概要

```
#include <math.h>
int fpclassify(real-floating x);
```

描述

`fpclassify` 宏将其参数值分类为 NaN、无穷大、正规（normal）、次正规（subnormal）、零或另一个实现定义的类别。首先，将比其语义类型更宽的格式表示的参数转换为其语义类型。然后根据参数的类型进行分类。

返回值

`fpclassify` 宏返回与其参数值匹配的数字分类宏的值。

> 234) 由于表达式的评估范围和精度可能超过其类型所具有的范围，因此知道分类依据是重要的。例如，一个正规 double 值在转换为 double 时可能会变成次正规，在转换为 float 时可能变成零。

返回值

`isfinite` 宏仅当其参数具有有限值时返回非零值。

### 7.12.3.4 isnan 宏
