# 第一章：设置你的服务器

现在我们已经准备好了一切，我们将从设置服务器开始。为了做到，我们需要一个本地服务器。为此最流行的工具是 `XAMPP`，它包含了 `Apache`、`MySQL`、`Perl` 和 `PHP`。

一旦安装了 `XAMPP`，打开 `XAMPP` 控制面板。你会看到一个模块列表。点击 `Apache` 和 `MySQL` 旁的“Start”按钮。如果它们变成了绿色，说明你的服务器正在运行！

现在，打开你的浏览器并在地址栏中输入 `localhost`。你应该看到 `XAMPP` 仪表板。这确认了你的服务器正常工作。

## 用户登录：身份验证

随后，对于登录页面，我们应该创建一个名为 `checklogin.php` 的文档。原因是回溯 `login.php`，我们的结构有一个名为 `checklogin.php` 的活动。如果你在 `register.php` 中看到它，它也在 `register.php` 中，因为后端也在同一个文档中完成。

我们现在用相应的语言编写 `checklogin.php` 怎么样？

`checklogin.php`

![](img/8e0a31fe30a159a13fdfed13405b5ed7_20_0.png)

```php
<?php
session_start();

$username = mysql_real_escape_string($_POST['username']);

$password = mysql_real_escape_string($_POST['password']);

$bool = true;

mmysql_connect("localhost", "root", "") or die (mysql_error());
mysql_select_db("first_db") or die("无法连接数据库");

$query = mysql_query("Select * from users WHERE username='$username'");

$exists = mysql_num_rows($query);

$table_users = "";

$table_password = "";
```

```php
while ($row = mysql_fetch_assoc($query)) // 显示查询结果所有行
{
$table_users = $row['username']; // 传递第一个用户名行
// $table_users，依此类推，直到查询结束

$table_password = $row['password']; // 传递第一个密码行
// $table_password，依此类推，直到查询结束
}

if(($username == $table_users) && ($password == $table_password))// 检查是否存在匹配的字段
{
    if($password == $table_password)
    {
        $_SESSION['user'] = $username; // 在会话中设置用户名。这相当于全局变量

        header("location: home.php"); // 将用户重定向到已认证的首页
    }
}
    else
    {
        print '<script>alert("Incorrect Password!");</script>'; // 提示用户
        print '<script>window.location.assign("login.php");</script>'; // 重定向到 login.php
    }
}
else
{
    print '<script>alert("Incorrect username!");</script>'; // 提示用户
    print '<script>window.location.assign("login.php");</script>'; // 重定向到 login.php
}

?>
```

`mysql_num_rows()` - 这产生一个整数。该数字根据查询统计每一列的数目。

`$_SESSION['name']` - 作为整个会话的会话名称。这在编程中类似于于变量。我们将利用它来识别客户端是否经过了验证。

然后尝试使用错误的用户名和密码测试你的数据。它应该返回预期的提示。测试后，尝试输入正确的值。它应该带你进入 `home.php`。

## 向列表添加数据 - 用户访问

在下一步中，我们如何让用户向列表添加数据？从结构上看，它由 `<form action="add.php" method="POST">` 组成，表示请求发送到 `add.php`，并使用以下语法制作 `add.php`：

![](img/8e0a31fe30a159a13fdfed13405b5ed7_27.png)

上述代码：

```php
<?php
session_start();

if(isset($_SESSION['user'])){
} else{
    header("location:index.php");
}

$details = mysql_real_escape_string($_POST['details']);
$time = date("X");
$date = date("B d Y");

print "$time - $date - $details";
```

注意这还没有 `add.php`，我只是显示时间和日期并获取你的数据。之后，返回 `home.php` 并点击“加入列表”。
