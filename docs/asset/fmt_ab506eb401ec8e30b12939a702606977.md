## 在 ASP.NET 中使用 Forms 身份验证

Forms 身份验证在商业 ASP.NET 应用程序和网站（例如网上购物、银行和电子邮件相关的应用程序和网站）中具有大量应用。在 Forms 身份验证中，当用户在 ASP.NET 应用程序或网站中请求受保护的网页并通过 IIS 时，ASP.NET 应用程序会检查该用户是否未经身份验证。如果用户未经身份验证，则用户会被重定向到登录页面，并需要在该页面提供凭据（用户名和密码）。然后，将用户提供的凭据与存储在给定数据库或 ASP.NET 应用程序或网站的 `web.config` 文件中的凭据进行验证。如果凭据匹配，则用户可以访问所请求的网页；否则，用户会再次被重定向到登录页面。

让我们创建一个 ASP.NET 网站，并将其保存为 `FormsAuth`（在 CD-ROM 上）。

该网站有两个网页：`Default.aspx` 和 `Login.aspx`。`Default.aspx` 页面是受保护的网页，要求用户经过身份验证后才能访问；`Login.aspx` 是登录页面，用户在此页面提供凭据以进行身份验证。让我们通过执行以下步骤来创建该网站：

1\. 在 IIS 中为 `FormsAuth` 网站启用 Forms 身份验证选项。

2\. 打开 `FormsAuth` 网站的 `web.config` 文件以启用网站中的 Forms 身份验证。在 `web.config` 文件中添加以下代码，以在应用程序中启用 Forms 身份验证，并更改 `<authentication>` 和 `<authorization>` 元素：

```xml
<authentication mode="Forms">
<forms name="FormsAuthCS" path="/" loginUrl="Login.aspx" protection="All" timeout="30">
<credentials passwordFormat="Clear">
<user name="Harry" password="testHarry" />
<user name="Tom" password="testTom" />
<user name="John" password="testJohn" />
</credentials>
</forms>
</authentication>
<authorization>
<deny users="?"/> <!--denying access to anonymous users-->
</authorization>
```

`<authentication>` 元素的 `mode` 属性设置为 `Forms`。`<forms>` 元素包含一个 `<credentials>` 元素，该元素包含三个 `<user>` 元素，用于指定有效的用户名和密码。在 `<authorization>` 元素中，使用 `<deny>` 元素拒绝匿名用户的访问。因此，只有经过身份验证的用户才能访问 `Default.aspx` 页面。
