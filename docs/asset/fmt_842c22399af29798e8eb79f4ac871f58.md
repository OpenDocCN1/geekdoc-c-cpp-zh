
# 第 38 章 日期与时间功能

> 时间是幻觉。午餐时间更是如此。
> — 福特·普雷菲克，《银河系漫游指南》

这并不复杂，但刚开始可能会有点令望而畏，既是因为有许多不同的类型，也是因为我们在它们之间转换的方式。

将世界时（UTC）和本地时间混合在一起，我们就会遇到处理日期时间时会遇到的所有“常规乐趣”™。

当然，永远不要忘记日期和时间的黄金法则：永远不要尝试编写自己的日期时间功能。只使用库提供的函数。

对于凡人程序员来说，时间太复杂了，无法正确处理。说真的，我们都应该向参与过任何日期时间库工作的人表示感谢，所以请把这考虑在你的预算内。

## 38.1 快速术语和信息

以防你还不熟悉，这里有一些简单的术语说明。

- **UTC**: 协调世界时是一个全球范围内¹公认的绝对时间。地球上的每一个人现在的 UTC 时间都是相同的……尽管他们的偏移量不同。
- **GMT**: 格林威治标准时间，实际上与 UTC² 相同。你可能想说 UTC 或“通用时间”。如果你在特指 GMT 时区，请直接说 GMT。令人混淆的是，C 语言的许多函数预测的是 UTC 但仍称为格林威治标准时间。当你看到它时，那个 C 意味着 UTC。
- **本地时间**: 运行程序的计算机所在位置的时间。这被描述为相对于 UTC 的偏移。世界上有许多时区，大多数计算机都在本地时间或 UTC 下工作。

作为一般规则，如果你在描述一个一次性的事件，例如日志条目、火箭发射，或者指针终于点通了的时刻，请使用 UTC。

另一方面，如果它是指每个时区同一时间发生的事情，比如除夕夜，或者由于选择以错误的格式存储日期而带来的巨大痛苦。

由于许多语言只擅长转换 UTC 和本地时间，如果你选择错误的格式存储日期，可能会让自己陷入很多痛苦（问我我是怎么做的）。

> ² 好了，别杀我！GMT 在技术上是一个时区，而 UTC 是一个全球时间系统。某些国家可能会为了夏令调整 GMT，而 UTC 永远不会为了夏令时调整。

## 38.2 日期类型

在 C 语言中，日期有两种主要类型：`time_t` 和 `struct tm`。

规范并没有对它们说得太多：

- *`time_t`*: 一种存储时间的实际类型。根据规范，它可以是浮点类型或整数类型。在 POSIX（类 Unix 系统）中，它是一个整数。它持有日历时间，你可以将其比作 UTC。
- *`struct tm`*: 日历时间的组成部分。这是一种拆分后的时间，即时间的组成部分，如时、分、秒、日、月、年等。

在许多系统中，`time_t` 代表自纪元（Epoch）以来的秒数。Epoch 是从计算机角度来看某个时间，通常是 1970 年 1 月 1 日。`time_t` 可以为负，表示纪元之前的时间。Windows 的行为则不同。

`struct tm` 中包含什么？以下字段：

```c
struct tm {
    int tm_sec;  // 分钟后的秒数 [0, 60]
    int tm_min;  // 小时后的分钟 [0, 59]
    int tm_hour; // 午夜后的的小数 [0, 23]
    int tm_mday;  // 月中的日 [1, 31]
    int tm_mon;   // 自 1 月起的月份 [0, 11]
    int tm_year;  // 自 1900 年起的年份
    int tm_wday;  // 自周日起的几天 [0, 6]
    int tm_yday;  // 自 1 月起的天数 [0, 365]
    int tm_isdst;// 夏令时标志
};
```

除了日期之外，所有内容都是从 0 开始的。重要的是，你可以在这些类型中放入任何值。有一些函数可以帮助获取当前时间。

所以问题变成了：“你如何初始化这些类型，以及如何在它们之间进行转换？”

## 38.3 初始化与转换

首先，你可以获取当前时间并将其存储在 `time_t` 中。

```c
time_t now; // 用于存储时间的变量
now = time(NULL); // 你可以这样获取
time(&now); // ... 与上一行相同。
```

太棒了！你有了一个可以获取当前时间的变量。奇怪的是，只有一种可移植的方法可以打印 `time_t` 中的内容，那就是极少使用的 `ctime` 函数，它以本地时间打印值：

```c
now = time(NULL);
printf("%s", ctime(now));
```

### 38.1 转换 `time_t` 到 `struct tm`

有两种神奇的转换方式：

- `localtime()`: 此函数将 `time_t` 转换为 `struct tm`（本地时间）。
- `gmtime()`: 此函数将 `time_t` 转换为 `struct tm`（UTC 时间）。

如果你有一个 `struct tm`，可以使用 `asctime()` 函数打印出来：

```c
printf("Local: %s", asctime(local));
```

输出（太平洋时区）：
Local: Sun Feb 28 20:15:27 2021
UTC: Mon Mar 1 04:15:27 2021

### 38.2 转换 `struct tm` 到 `time_t`

如果你想反过来操作，可以使用 `mktime()` 获取信息。

`mktime()` 会为你设置 `tm_wday` 和 `tm_yday`，所以不用担心它们会被覆盖。

此外，你可以将 `tm_isdst` 设置为 -1 让系统决定。你也可以手动将其设置为真或假。

```c
struct tm some_time_t = {
  .tm_year=82, // 自 1900 年起的年份
  .tm_mon=3,   // 自 1 月起的月份 [0, 11]
  .tm_mday=12,  // 月中的日 [1, 31]
  .tm_hour=12, // 午夜后的小时 [0, 23]
  .tm_min=0,   // 小时后的分钟 [0, 59]
  .tm_sec=4,   // 分钟后的秒数 [0, 60]
  .tm_isdst=-1, // 夏令时标志
};
time_t some_time_t_epoch;
some_time_epoch = mktime(&some_time_t);
```

```c
printf("%s", ctime(&some_time_epoch));
printf("Is DST: %d\n", some_time_t.tm_isdst);
```

输出：

Mon Apr 1 12:00:04 1982

Is DST: 0

## 38.4 格式化日期输出

我们已经看到了一些打印格式化日期的方法。对于 `time_t` 我们可以使用 `ctime()`，而对于 `struct tm` 我们可以使用 `asctime()`。

但如果我告诉你，亲爱的，有一种方法可以对日期的格式有更多控制呢？

当然，我们可以从 `struct tm` 中提取单个字段，但有一个非常有用的函数 `strftime()` 可以为你完成所有的繁琐工作。在这些用法中，我们都使用一个目标缓冲区、最大字符数以及一个格式字符串（样式类似于但不等于 `printf()`）来告诉 `strftime()` 打印 `struct tm` 的哪些部分以及如何打印。

在这种情况下，我们从 `localtime()` 获取 struct tm，但任何来源都可以。

```c
// %S: 秒
// %p: AM 或 PM
strftime(s, size_of s, "It %I:%M:%S %p", localtime(&now));
puts(s);
// 晚上 10:20:00

// %F: ISO 8601 年-月-日
// %T: ISO 8601 时:分:秒
// %z: ISO 8601 时区偏移量
strftime(s, size_of s, "ISO 8601: %FT%T%z", localtime(&now));
puts(s);
// ISO 8601: 2021-02-28T22:29:00-0800
```

`strftime()` 有有大量的日期打印格式说明符，请务必在 `strftime()` 的参考页中查看它们。

## 38.5 使用 `timespec_get()` 获取更高的分辨率

你可以使用 `timespec_get()` 获取自 Epoch 来的秒数和纳秒数。可能吧。

某些实现可能没有纳秒级分辨率（那是秒的十分之一），所以谁知道你能得到多少位有效数字，试一试吧。

`timespec_get()` 接受两个参数。一个是指向 `struct timespec` 结构体的指针，用于存储时间信息。另一个是基准（base），规范允许你将其设置为 `time_UTC`，表示你对自 Epoch 来的秒数感兴趣（其他实现可能会为你提供更多基准选项）。而该结构体本身包含两个字段：

```c
struct timespec {
    time_t tv_sec;   // 秒
    long tv_nsec;    // 纳秒（秒的十分之一）
};
```

这里是一个示例，我们获取时间并以整数值和浮点值的形式打印：

```c
struct timespec ts;
timespec_get(&ts, TIME_UTC);
printf("%ld %ld ns\n", ts.tv_sec, ts.tv_nsec);
double float_time = ts.tv_sec + ts.tv_nsec/1000000000.0;
printf("%f seconds since epoch\n", float_time);
```

示例输出：

161481530, 806326800 ns

161481530.806326 seconds since epoch

`struct timespec` 也出现在其中一个线程函数中，该函数需要能够指定具有该分辨率的时间。

## 38.6 时间之间的差异

关于获取两个 `time_t` 之间差异的一个快速说明：由于规范没有规定类型如何表示时间，你可能无法相减两个 `time_t` 并得到任何有意义的结果。

幸运的是，你可以使用 `difftime()` 来计算两个日期之间的秒数差。

在下面的示例中，我们有两个在某个时间之后发生的事件，我们使用 `difftime()` 来计算差。

```c
#include <stdio.h>
#include <time.h>

int main(void) {
    struct tm time_a = {
        .tm_year=82,
        .tm_mon=3,
        .tm_mday=12,
        .tm_hour=4,
        .tm_min=0,
        .tm_sec=04,
    };
    printf("%f\n", difftime(time(NULL), mktime(&time_a)));
    struct tm time_b = {
        .tm_year=82,
        .tm_mon=10,
        .tm_mday=15,
        .tm_hour=4,
        .tm_min=30,
        .tm_sec=00,
        .tm_isdst=-1,
    };
    time_t cal_a = mktime(&time_a);
    time_t cal_b = mktime(&time_b);
    double diff = difftime(cal_b, cal_a);
    printf("%f seconds\n", diff);
    return 0;
}
```

# 39. 多线程 (Threading)

线程 允许你在同一个进程中运行多个执行流。C11 引入了它们，但 POSIX 线程更常见。

## 39.1 背景

线程是允许你在同一个进程中运行多个执行流的方式。稍后会讨论。让我们看看基础。

## 39.2 你可以做的事情

你可以创建一个线程。它将在你指定的函数上执行。

而且你可以等待线程完成。这被称为连接（join）。或者如果你不在乎线程何时完成，你可以分离它（detach）。线程也可以通过从函数返回来退出。主程序也是线程。

## 39.3 数据竞态与标准库

标准库中的某些函数返回或使用非线程元素。但通常情况下，除非另有说明，标准库会努力做到。

但要留意。如果一个线程维护了你不拥有的状态，或者一个函数返回了你没有传入的指针，它是不安全的。

## 39.4 创建和等待线程

让我们来写点东西！

我们将创建线程并等待它们完成。

首先我们需要理解：`thrd_t` 类型的不透明变量来标识线程。它是程序中线程的唯一标识符。当你创建一个线程时，它会被赋予一个新的 ID。

所以基本想法是：

- 编写一个函数作为线程的“主”。它不是真正的 `main()`，但类似的。线程将从那里开始运行。
- 从主线程通过 `thrd_create()` 启动新线程，并传递要运行的函数指针。
- 在该函数中，线程将执行它需要做的事。
- 与此同时，主线程可以继续做它需要的事。
- 当主线程决定退出时，它可以通过 `thrd_join()` 等待子线程完成以清理它，否则会泄漏内存。

`thrd_create()` 接收一个要运行函数的指针，其类型为 `thrd_start_t`，即 `int (*void *)`。这在希腊语中意思是“一个接收避免 void 类型参数的函数指针，并返回一个 `int`”。

让我们创建一个线程吧！我们将从主线程通过 `thrd_create()` 启动一个函数，做一些其他事情，然后使用 `thrd_join()` 等它完成。我将线程的主函数命名为 `run()`，但只要类型匹配 `thrd_start_t`，你可以将其命名为任何。

```c
#include <stdio.h>
#include <threads.h>
```

```c
// 这是将运行的函数。它可以被称为任何名字。
// arg 是传递给 `thrd_create()` 的参数指针
// 父线程将从 `thrd_join()` 获取返回值
// 稍后。
int run(void *arg)
{
    int *a = arg; // 我们将从 thrd_create() 传入一个 int*
    printf("THREAD: Running thread with %d\n", *a);
    return 12; // 被 thrd_join() 拾取的值（随机选择了 12）
}
```
