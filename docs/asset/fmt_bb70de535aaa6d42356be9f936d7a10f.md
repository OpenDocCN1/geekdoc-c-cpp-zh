
## `doFilter()`

- 检查滤波器是否支持，否则返回输入值
- 两个滤波器都遵循相同的序列（参见上文）
- 通过输入滤波器（`LPF` 或 `HPF`）处理输入
- 在此处形成反馈项 `S35`
- 计算 `u`，下一个滤波器的输入
- 如果需要添加 `NLP`
- 将输出滤波器馈入反馈回路（`HPF` 或 `BPF`）
- 通过 `1/K` 归一化输出

## 7.18 `CDodeLadderFilter` 对象
