# 前言

# 为什么有两个标题？

这本书在 2014-2018 年间名为《初学者逆向工程》，但我一直怀疑这种命名会让读者群变得太狭窄。

信息安全（Infosec）领域的人知道“逆向工程”，但我很少从他们口中听到过“汇编”这个词。

同样，“逆向工程”这个术语对于普通程序员群体来说有些晦涩，但他们知道什么是“汇编”。
