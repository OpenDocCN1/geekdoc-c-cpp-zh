
```c
struct a {
  int x;           //
  float y;         // 公共初始序列
};

struct b {
  int x;           //
  float y;         // 公共初始序列

  double *p;
  short z;
};
```

你看到了吗？它们都以 `int` 开头，后面是 `float`——这就是公共初始序列。结构体序列中的成员必须是兼容的类型。我们在 `x` 和 `y` 上看到了这一点，它们相对而言是 `int` 和 `float`。

现在，让我们为这些结构体创建一个联合体：

```c
union foo {
  struct a sa;
  struct b sb;
};
```

这条规则告诉我们，我们可以保证公共初始序列的成员在代码中是可以互换的。也就是说：

- `f.sa.x` 等同于 `f.sb.x`。

以及

- `f.sa.y` 等同于 `f.sb.y`。

因为字段 `x` 和 `y` 都在公共初始序列中。

此外，公共初始序列中成员的名称并不重要——重要的是类型相同。

总而言之，这允许我们安全地在联合体中的结构体之间添加一些共享信息。这方面的最佳例子可能是使用一个字段来确定联合体中“正在使用”的结构体类型。

也就是说，如果我们不被这样做，并将联合体传递给某个函数，那么该函数如何知道联合体中的哪一个成员是它应该查看的呢？

看看这些结构体。注意它们的公共初始序列：

```c
#include <stdio.h>

struct common {
    int type; // 公共初始序列
};

struct antelope {
    int type; // 公共初始序列
    int loudness;
};

struct octopus {
    int type; // 公共初始序列

    int sea_creature;
    float intelligence;
};
```

现在，让我们把它们放入一个联合体：

```c
union animal {
    struct common common;
    struct antelope antelope;
    struct octopus octopus;
}
```

另外，请在演示中允许这两个 `#define`：

```c
#define ANTELOPE 1
#define OCTOPUS 2
```

到目前为止，这里还没有发生什么特别的事情。`type` 字段似乎完全没用。但现在让我们写一个打印联合体的通用函数。它必须以某种方式能够判断它看的是 `struct antelope` 还是 `struct octopus`。因为初始序列的魔力，它可以针对特定的联合体在这些任何一个地方查找类型：

```c
int type = x.common.type; // 或者...
int type = x.antelope.type; // 或者...
int type = x.octopus.type; // 或者...
```

它们都指向内存中的同一个值。

```c
void print_animal(union animal *x) {
    switch (x->common.type) {
        case ANTELOPE:
            printf("Antelope loudness=%d\n", x->loudness);
            break;
        case OCTOPUS:
            printf("Octopus sea_creature=%d\n", x->sea_creature);
            printf("intelligence=%f\n", x->intelligence);
            break;
            default:
            printf("Unknown type %s\n");
    }
}
```

```c
int main(void) {
    union animal a = {.type=ANTELOPE, .loudness=12};
    union animal b = {.type=OCTOPUS, .sea_creature=1, .intelligence=1.5};

    print_animal(&a);
    print_animal(&b);
}
```

# 20.10 匿名结构体

如果一个结构体没有名称，它被称为一个匿名结构体。你你不能像普通结构体那样声明它，但你可以在结构体或联合体内定义它。

```c
union foo {
  struct {
    int x;
    float y;
  } a;

  struct {
    int x;
    float y;
  } b;
};
```

在这个示例中，我们看到联合体内部有两个匿名结构体。我们通过成员名 `a` 和 `b` 来访问它们。

```c
union foo x;

x.a.x = 10;
x.a.y = 20.5;

printf("%d\n", x.a.x); // 10
printf("%f\n", x.a.y); // 20.5

x.b.x = 20;
x.b.y = 30.5;

printf("%d\n", x.b.x); // 20
printf("%f\n", x.b.y); // 30.5
```

这告诉我们，在底层，联合体中的所有这些值都从内存中的同一个位置开始，这与整个联合体的位置相同。

你也可以在结构体内部定义匿名结构体：

```c
struct foo {
  struct {
    int x;
    float y;
  } a;

  struct {
    int x;
    float y;
  } b;
};
```

这与联合体的情况是一样的。你可以通过成员名 `a` 和 `b` 来访问这些成员。

```c
#include <stdio.h>
```

## 21.1.2.1 单行状态更新

`\a` 或 `\r` 的一个用途是显示在屏幕上同一行显示的状态更新，且不会导致屏幕刷新。这里是一个倒计时到 10 的示例。（注意这里使用了来自 `<unistd.h>` 的非标准 POSIX 函数 `sleep()`——如果你不是在 Unix 类系统，请搜索你平台对应的 `sleep` 函数）。

```c
#include <stdio.h>
#include <threads.h>

int main(void)
{
    for (int i = 10; i >= 0; i--) {
        printf("\RT minus %d second%%... \b", i, i != 1 "s": "");
    }

    fflush(stdout); // 强制更新输出

    // 睡眠 1 秒
    thrd_sleep(&(struct timespec){.tv_sec=1}, NULL);
    printf("\RLiftoff!\n");
}
```

# 第 21 章 字符与字符串 II

第 7 行发生了不少事情。首先，我们以 `\r` 开头回到当前行首，然后用当前的倒计时覆盖原来的内容。（使用了三元运算符来确保我们打印的是 1 秒而不是 2 秒。）

另外，在 `. . .` 后面有一个空格。这就是我们在 `i` 从 10 减到 9 时能覆盖最后一个 `.` 并导致列变窄的原因。尝试不加空格，看看我是什么意思。

最后用 `\b` 结尾，将那个空格退回，这样光标就能以一种美观的方式停在行的末尾。

注意第 14 行末尾所有的空格都是为了覆盖之前已经存在的字符。

最后，我们在里面有一个 `fflush(stdout)`，无论它是什么意思。大多数终端默认是缓冲的，在遇到换行符之前实际上不会显示任何内容。由于我们没有换行符（我们用了 `\r`），如果没有这个，程序就会一直在那里，直到调用 `fflush()` 然后瞬间打印所有内容。`fflush()` 覆盖了这种行为并立即输出到缓冲区。

## 21.1.2 问号的使用

为什么要这样做呢？毕竟，这样写也可以：

```c
printf("Doesn't it?\n");
```

使用转义符也可以的：

```c
printf("Doesn't it?\n");    // 注意 \?
```

那意义何在呢？？

让我们用另一个问号和感叹号来加强加强语气：

```c
printf("Doesn't it??\n");
```

当我编译这个代码时，我得到了这个警告：

```c
foo.c: In function 'main'
foo.c:5:23: warning: trigraph ?? converted to | -Wigraphs
5 |
 printf("Doesn't it??\n");
```

运行它带我们得到了这个结果：

Doesn't|

那么图形呢？这到底是什么鬼？？

我确定我们以后会再次回到语言的这个角落，但简而言之，编译器会寻找以 `??` 开头的某些三元组，并用其他字符替换它们。所以如果你在一个非常古老的终端上，键盘上没有管道符号 `|`，你可以输入 `??!` 代替。

你可以通过转义问号来修复这个问题，如下所示：

```c
printf("Doesn't it\?\?\!\n");
```

这样它就能编译并按预期工作了。
