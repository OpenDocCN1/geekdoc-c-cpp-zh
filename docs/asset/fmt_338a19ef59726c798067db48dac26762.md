字符串不是 C 语言的原生类型这一事实迫使你编写一些相当迂的代码。例如，假设你想将一个字符串赋值给另一个字符串；也就是说，你想将一个字符串的内容拷贝到另一个字符串。在 C 中，你不能简单地将一个数组赋值另一个数组。你必须按元素进行拷贝。字符串库（`<string.h>` 或 `<strings.h>`）包含一个名为 `strcpy` 的函数用于此任务。以下是一个在普通 C 程序中非常常见的代码：

```c
char s[100];
strcpy(s, "hello");
```

以下代码展示了如何在 C 中使用 `strcpy`：

```c
#include <string.h>
int main(void) {
    char s1[100],s2[100];
    strcpy(s1, "hello"); /* 将 "hello" 拷贝到 s1 */
    strcpy(s2,s1);               /* 将 s1 拷贝到 s2 */
    return 0;
}
```

在 C 中每初始化字符串时都会使用 `strcpy`。你使用字符串库中的 `strcmp` 函数来比较两个字符串。它返回一个整数，表示比较的结果。零表示两个字符串相等，负值表示 s1 小于 s2，正值表示 s1 大于 s2。

```c
#include <stdio.h>
#include <string.h>
int main(void) {
    char s1[100],s2[100];
    gets(s1);
    gets(s2);
    if (strcmp(s1,s2) == 0) {
        printf("equals\n");
    } else if (strcmp(s1,s2) < 0) {
        printf("%s less than %s\n", s1, s2);
    } else {
        printf("%s greater than %s\n", s1, s2);
    }
    return 0;
}
```

字符串库中的其他常用函数包括返回字符串长度的 `strlen`，以及连接两个字符串的 `strcat`。字符串库还包含许多其他函数，你可以通过阅读手册页来了解。

为了开始构建字符串函数，并帮助你理解其他程序员的代码（每个人为了程序中的特殊目的都有自己的一套字符串函数），我们将查看两个例子，`strlen` 和 `strcpy`。以下是一个严格类 Pascal 风格的 `strlen` 版本：

```c
int strlen(char s[]) {

    return(x);
}
```

大多数 C 程序员都避开这种方法，因为它看起来效率低下。相反，他们通常使用基于指针的方法：

```c
int strlen(char *s) {
    int x=0;
    while (*s != '\0') {
        x++;
        s++;
    }
    return(x);
}
```

你可以将这段代码缩写为以下形式：


我们可以对 `strcpy(char s1[], char s2[])` 经历同样的演进过程：

```c
int x;

  s1[x] = s2[x];
```

注意，在 `for` 循环中使用 `<=` 是错误的，因为代码随后会拷贝 `\0`。如果你漏掉了它，后续会出现严重的错误，字符串将没有结束符，因此长度未知。同样注意，这段代码效率非常低，因为 `for` 循环每次都会调用一次 `strlen`。要解决这个问题，你可以使用以下代码：

```c
void strcpy(char s1[], char s2[]) {
    int x, len;
    len = strlen(s2);
    for (x = 0; x <= len; x++)
      s1[x] = s2[x];
}
```

## 命令行参数

C 语言了一种非常简单的机制来获取用户输入的命令行参数。它会将一个 `argv` 参数传递给程序的 `main` 函数。`argv` 结构体出现在许多高级库函数调用中，因此理解它们对任何 C 语言程序员都是有用的。

输入以下代码并编译：

```c
#include <stdio.h>

int main(int argc, char *argv[])
{
    printf("%d\n",argc);
    for (x = 0; x < argc; x++)
        printf("%s\n", argv[x]);
    return 0;
}
```

在这段代码中，主程序接受两个参数：`argv` 和 `argc`。`argv` 参数是一个指向字符串的指针数组，包含了程序在 UNIX 命令行调用时输入的参数。`argc` 整数包含参数数量的计数。这段特定的代码会打印出命令行参数。要尝试尝试，请将代码编译为一个名为 `aaa xxx yyy zzz` 的可执行文件。该代码将打印出命令行参数 `xxx`、`yyy` 和 `zzz`，每行一个。

`char *argv[]` 是一个指向字符串的指针数组。换句话说，数组的每个元素都是一个指针，每个指针指向一个字符串（技术上指向字符串的第一个字符）。因此，`argv[0]` 指向包含命令行上第一个参数（程序名称）的字符串，`argv[1]` 指向下一个参数，依此类推。`argc` 变量告诉你数组中有多少个指针是有效的。你会发现前面的代码仅仅是打印了 `argv` 指向的每个有效字符串。

由于 `argv` 的存在，你可以相当容易让你的程序对用户输入的命令行参数做出反应。例如，你可能让程序检测程序名后的第一个参数为单词 `help`，并将帮助文件转储到 `stdout`。文件名也可以被传递并在你的 `fopen` 语句中使用。

# 第 17 章

## 文本文件

C 语言中的文本文件非常直观且易于理解。C 中所有的文本文件函数和类型都来自 `stdio` 库。

当你在 C 程序中需要文本 I/O 时，且只需要一个输入信息源和一个输出信息汇时，你可以依靠 `stdin`（标准输入）和 `stdout`（标准输出）。你可以在命令行处使用输入和输出重定向来让不同的信息流通过程序。`<stdio.h>` 中有六种不同的 I/O 命令可以与 `stdin` 和 `stdout` 使用：

- `printf` - 将格式化输出打印到 `stdout`

- `scanf` - 从 `stdin` 读取格式化输入

- `puts` - 将字符串打印到 `stdout`

- `putc` - 将字符打印到 `stdout`

- `getc`, `getchar` - 从 `stdin` 读取一个字符

`stdin` 和 `stdout` 的优势是它们易于使用。同样，重定向 I/O 的能力非常强大。例如，你可能想创建一个程序从 `stdin` 读取并计算字符数：

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char s[1000];
    int count = 0;
    while (gets(s)) {
        count += strlen(s);
    }
    printf("%d\n",count);
    return 0;
}
```

输入这段代码并运行。它会等待来自 `stdin` 的输入，所以输入几行。完成后，按下 CTRL-D 信号文件结束 (`eof`)。`gets` 函数读取一行直到检测到 `eof`，然后返回 0 使得 `while` 循环结束。当你按下 CTRL-D 时，你会看到 `stdout`（屏幕）中字符数的计数。（使用 `man gets` 或你的编译器文档了解更多关于 `gets` 函数的信息。）

现在，假设你想统计文件中的字符。如果你将程序编译为执行一个名为 `xxx` 的程序，你可以输入：

```bash
xxx < filename
```

与其接受键盘输入，不如使用文件 `filename` 的内容。你可以使用管道来实现相同的结果：

```bash
cat < filename | xxx
```

你也可以将输出重定向到文件：

```bash
xxx < filename > out
```

这条命令将程序产生的字符数放在名为 `out` 的文本文件中。

有时，你想统计文件中的字符。如果你将程序编译为执行一个名为 `xxx` 的程序，你可以输入以下。在这种情况下，你可能需要使用 `stdio` 中的文件函数：

- `fopen` - 打开文件

- `fclose` - 关闭文件

- `feof` - 检测文件结束标记

- `fprintf` - 将格式化输出到文件

- `fscanf` - 从文件读取格式化输入

- `fputs` - 将字符串打印到文件

- `fgets` - 从文件读取字符串

- `fwrite` - 写入文件

- `putc` - 将字符写入文件

- `getc` - 从文件读取一个字符

在这种情况下，你可能需要使用 `fopen` 模式。最常用的有 `r`、`w` 和 `a`（用于读、写、追加）。它返回一个指向文件的指针。如果 `fopen` 命令失败，`f` 将包含 `NULL` 值。例如，你可以使用以下代码：

```c
#include <stdio.h>
#define MAX 10

int main(void)
{
    FILE *f;
    int x;
```

```c
f = fopen("out", "w");
if (!f)
    return 1;
for(x = 0; x < MAX; x++)
    printf("%d\n",x);
close(f);
return 0;
```

## 文本文件：读取

读取文件，使用 `r` 模式打开它。通常情况下，不要使用 `fscanf` 来读取：除非文件格式是完美的。相反，使用 `fgets` 读取每一行并解析你需要的内容。以下代码演示了读取文件并将其内容到屏幕的过程：

```c
#include <stdio.h>

int main(void)
{
    FILE *f;
    char s[1000];
```

```c
f = fopen("infile","r");
if (!f)
    return 1;
while (fgets(s,1000,f) != NULL)
    printf("%s", s);
close(f);
return 0;
```

`fgets` 语句在文件结束标记处返回 `NULL` 值。它读取一行（在本例中最多 1000 个字符）并将其打印到 `stdout`。注意 `printf` 语句格式字符串中没有包含 `\n`，因为 `fgets` 在它读取的每行末尾包含了 `\n`。因此，在溢出第二个参数指定的最大长度的情况下，你可以判断行是否不完整。
