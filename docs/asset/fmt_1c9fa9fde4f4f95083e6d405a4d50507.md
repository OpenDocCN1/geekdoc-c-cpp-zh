## try...catch...finally 语句

C# 提供了三个用于异常处理的关键字 – `try`、`catch` 和 `finally`。`try` 块包含可能导致异常的语句；而 `catch` 块包含用于处理异常的语句，如果异常发生的话。一个 `try` 块可以存在多个 `catch` 块。所有这些 `catch` 块用于处理 `try` 块内引发的不同类型的异常。`finally` 块中包含的语句始终会被执行，而不管是否发生异常。一个 `try` 块只能有一个 `finally` 块。

如果在 `try` 块中发生任何异常，程序控制会直接转移到其相应的 `catch` 块，然后再转移到 `finally` 块。在 C# 中，`catch` 和 `finally` 块不是强制性的。在一个程序中，`try` 块可以包含一个或多个 `catch` 块，仅 `finally` 块，或同时包含 `catch` 和 `finally` 块。如果 `try` 块内未发生异常，程序控制会直接转移到 `finally` 块。

以下代码片段展示了 `try...catch...finally` 语句的使用：

```
try
{
    div = 100 / number;
}
catch (DivideByZeroException de)
{
    Console.WriteLine("Exception occured");
}
```

```
finally
{
Console.WriteLine("Result is : " +div);
Console.ReadLine();
}
```

在前面的代码片段中，当 `try` 块内的语句执行时，控制可能会根据 `number` 变量的值转移到 `catch` 块。假设 `number` 变量的值为则会引发 `DivideByZeroException`，程序控制转移到 `catch` 块并执行 `catch` 块内的语句，之后 `finally` 块内的语句会被执行。如果 `number` 变量的值不为零，则程序控制不会转移到 `catch` 块而是直接转移到 `finally` 块并执行 `finally` 块内的语句。

## throw 语句

`throw` 语句用于在程序中发生错误时引发异常。在 C# 中，也可以通过编程方式抛出异常。你可以使用 `throw` 关键字来抛出异常。以下代码片段展示了 `throw` 语句的示例：

```
try
{
throw new DivideByZeroException();
}
catch(DivideByZeroException e)
{
Console.WriteLine("Exception");
}
```

在前面的代码片段中，你可以看到我们显式地抛出了一个新的 `DivideByZeroException`。

## checked 和 unchecked 语句

`checked` 和 `unchecked` 语句用于检查内存溢出异常。`checked` 关键字用于检查整数类型算术运算和转换的溢出。溢出发生在变量的值超过变量所需原始长度时。`unchecked` 关键字忽略整数类型算术运算和转换的溢出检查。算术溢出异常会在 `checked` 上下文中引发；而在 `unchecked` 上下文中，算术溢出会被忽略，程序会显示结果的截断整数。

以下代码片段展示了 `checked` 和 `unchecked` 语句的示例：

```
byte number1, number2;
byte result;
number1 = 127;
number2 = 127;
try
{
result = unchecked((byte)(number1 * number2));
Console.WriteLine("Unchecked result: " + result);
result = checked((byte)(number1 * number2));
Console.WriteLine("checked result: " + result);
}
catch (OverflowException exc)
{
Console.WriteLine(exc);
}
```

在前面的代码片段中，你可以看到 `OverflowException` 类被用来捕获溢出异常。

### 使用嵌套 if 语句

如果程序中需要评估多个条件，你可以使用一组嵌套 `if` 语句来评估这些条件。例如，如果你希望在程序中检查学生的年龄、姓名和性别，你可以使用嵌套 `if` 语句。让我们创建一个名为 `MyNestedIfStatement` 的控制台应用程序（也可在 CD 上获得），以展示嵌套 `if` 语句的使用。清单 3.2 显示了 `MyNestedIfStatement` 应用程序的代码：

    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Finding the Largest of Three Numbers\n");
            Console.Write("Enter the First Number:");
            int number1 = int.Parse(Console.ReadLine());
            Console.Write("Enter the Second Number:");
            int number2 = int.Parse(Console.ReadLine());
            Console.Write("Enter the Third Number:");

### 使用 switch 语句

如讨论所述，C# 中的基本选择特性是 `if` 语句；然而，有时可能会发生由于多个 `if` 语句的嵌套，程序结构变得复杂且难以理解。在这种情况下，你可以在程序中使用 `switch` 语句使其更不复杂且易于理解。

让我们创建一个名为 `MySwitchStatement` 的控制台应用程序（也在 CD 上提供）来展示 `switch` 语句的使用。清单 3.3 显示了 `MySwitchStatement` 应用程序的代码：

#### 清单 3.3：显示 MySwitchStatement 应用程序的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MySwitchStatement
{
    class Program
    {
        static void Main(string[] args)
        {
            string Name;
            int Marks;
            Console.Write("Enter Your Name:");
            Name = Console.ReadLine();
            Console.WriteLine("Select the Range of Marks:");
            Console.WriteLine("1.      0-20");
            Console.WriteLine("2.      21-40");
            Console.WriteLine("3.      41-60");
            Console.WriteLine("4.      61-80");
            Console.WriteLine("5.      80-100");
            Console.Write("Enter Your Choice (1,2,3,4,5):");
            Marks = int.Parse(Console.ReadLine());
            switch (Marks)
            {
                case 1:
                {
                    Console.Write(Name + " your marks are very Low.\n");
                }
                break;
                case 2:
                {
                    Console.Write(Name + " your marks are Low. \n");
                }
                break;
                case 3:
                {
                    Console.Write(Name + " your marks are Average.\n");
                }
                break;
                case 4:
                {
                    Console.Write(Name + " your marks are Good.\n");
                }
                break;
                case 5:
                {
                    Console.Write(Name + " your marks are very Good.\n");
                }
                break;
                default:
                break;
            }
            Console.Write("\nPress ENTER to quit...");
            Console.ReadLine();
        }
    }
}
```

在清单 3.3 中，用户会被提示输入姓名并选择分数范围。选择分数范围后，用户会被提示输入选择（`case`），基于分数范围。当用户输入选择时，会根据选择显示一条消息。
