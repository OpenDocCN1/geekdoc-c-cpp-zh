### 多 INPUT 语句

默认情况下，SAS 在遇到 INPUT 语句时会将新记录加载到输入缓冲区。你可以在一个 DATA 步中使用多个 INPUT 语句。

```sas
data contacts;
infile "&path\address.dat";
input FullName $30;
input;\input Address2 $25;
input Phone $8;
run;
```

加载数据的第一行

部分输入缓冲区 1 2

1 2 3 4 5 6 7 8 9 0

Ms. | Sue | Farr

默认情况下，SAS 从输入缓冲区的第 1 位置开始读取每一行原始数据，因此在 INPUT 语句中使用 @1 是没有必要的。
