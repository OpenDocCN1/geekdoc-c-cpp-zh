## 表 26.39：`ObjectDataSource` 类的注目方法

|---|---|

## XmlDataSource 控件

`XmlDataSource` 控件允许数据绑定控件绑定来自 XML 文档的数据。此控件还支持 XPath 表达式，允许您仅从 XML 文档中返回某些节点。

`XmlDataSource` 控件的继承层次结构如下：

```
System.Object

  System.Web.UI.Control

    System.Web.UI.HierarchicalDataSourceControl

      System.Web.UI.WebControls.XmlDataSource
```
