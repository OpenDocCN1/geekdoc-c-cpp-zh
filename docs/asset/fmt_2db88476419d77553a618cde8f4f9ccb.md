```python
    codes = []                          输出代码
    spaces = 0                           当前连续空格数
    code = ''                           当前代码
    for c in string:
        if c == '':
            if code != '' and spaces > 0:
                codes.append(code)          完成代码
                code = ''
            spaces = spaces + 1
        else:
            if spaces == 7: codes.append(' ')  找到空格
            spaces = 0
            code = code + c
        if code != '': codes.append(code)
    return codes
```

要进行水平翻转，我们遍历图像的左半部分，将像素与右侧对应的像素交换。

```python
def hflip(i):
    p = i.load()
    sx, sy = i.size
    for x in range(sx // 2):
        for y in range(sy):
            r = p[x, y]
            p[x, y] = p[sx - x - 1, y]
            p[sx - x - 1, y] = r
```

如果图像宽度为奇数，中间列将不会被触。这是 `//` 运算符向下取整行为的结果。可以为垂直翻转编写一个类似的函数：

```python
def vflip(i):
    p = i.load()
    sx, sy = i.size
    for y in range(sy // 2):
        for x in range(sx):
            r = p[x, y]
            p[x, y] = p[x, sy - y - 1]
            p[x, sy - y - 1] = r
```
