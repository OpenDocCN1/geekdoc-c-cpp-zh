# 循环

## 8.1 引言

### 8.1.1 什么时候需要循环？

循环对程序员来说是非常有用且基础的需求。当他/她想要重复执行任何语句块，并且可以通过提供条件来控制时。循环的优点是它可以节省时间，并避免多次编写相同的程序代码。 比如一个初学者想写一个 C 程序来打印你的名字和地址 20 次（或更多）。那么对于初学者来说，编写 20 个 `printf` 语句来显示名字和地址非常头疼。为了解决这个问题，他尝试使用循环。在循环中，他使用三种循环语句（例如 `while`、`do` 和 `for`）中的任意一种，并在循环内部使用 `printf` 语句来打印 20 次名字和地址。

## 8.2 循环的概念

循环描述了按照顺序执行一组编程语句的过程，直到循环的条件不再满足而停止为止。或者，我们可以说循环按指定的次数对编程语句进行迭代。如果循环没有正常执行，会导致计算机运行变慢，有时可能会产生无限输出。程序的循环通常由两部分组成，即循环体部分和控制语句。控制语句的基本工作是在开始或结束时对每个条件进行测试。当该条件为真时，大括号内的语句集就会执行固定次数。这组被大括号包围的语句被称为循环体部分。在开始或执行循环之前（或在进入循环之前）检查语句的语句称为入控制循环。

如果条件为真，则执行循环体，否则它变为假，控制将跳出循环。但在出口控制循环中，条件语句在循环的末尾被检查。当条件变为假时，循环体会至少执行一次。

每个程序员在循环中完成的重要工作有：首先初始化条件变量，其次对每个条件变量进行测试，第三是使用大括号，因为这些语句需要执行多次，所以他们将这些语句放在大括号内，第四是增加和递减条件变量。

C 语言编程中有三种循环操作。它们是：(a) `while` 循环，(b) `do` 循环，(c) `for` 循环。

### 8.2.1 While 循环的概念

`while` 循环的语法：

```c
while (condition)
{
    语句块
}
后续语句
```

解释：
`while` 循环是一种控制结构，用于检查条件，条件保留在括号内，并在循环开始前由关键字 `while` 引导。通常情况下，条件是数字或字母数字型的。当条件变为真时，大括号内的语句块被重复执行。当条件变为假时，`while` 循环停止。停止循环后，程序控制将立即跳过循环体，移动到后续语句。这种循环也被称为入控制循环，因为起始条件是被检查的，如果条件为真则执行。

#include<stdio.h>
