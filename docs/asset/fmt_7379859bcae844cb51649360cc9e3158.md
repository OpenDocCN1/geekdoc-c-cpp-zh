
## 2. 扩展 DFA 为 NFA

我们可以通过扩展`dfa`的概念，将其定义为`nfa`，其中对于所有`q, a`，都有`δ(q,a) ≤ 1`。这样的`dfa`有时会因为没有后续状态而处于“卡住”状态。等价地，我们允许`dfa`的函数`δ`为偏函数。这样做的好处是，当我们绘制状态图时，可以避免很多转换（这最多可以节省一个状态）。必须将“卡住”的概念与留在同一状态的概念区分开来。例如，可以为状态图引入一种约定：如果在状态`q`上对于输入`a`的转换没有显式规则，则隐式规则为`δ(q,a)=q`。我们避免使用这种约定，因为它与卡住状态的概念冲突。

## 0.1.3 封闭性

我们可以将语言`A`视为一个集合，然后讨论“正则集”而不是“正则语言”。作为集合，我们得到了通用的集合论运算：补、并、交、差和对称差：

`co-A, A ∪ B, A ∩ B, A \ B, A △ B`。

关于一点的说明：只有当`A`被视为某个集合`U`的子集时，这种定义才有效，在这种情况下`co-A = U \ A`。

## 0.1 正规语言

- (基础) `L(a) = {a}, L(ε) = {ε}`且`L(∅) = ∅`，其中`a ∈ Σ`。
- (归纳)
  - 连接：`L(R₁;R₂) = L(R₁) · L(R₂)`，
  - 并集：`L(R₁ ∪ R₂) = L(R₁) ∪ L(R₂)`，
  - 克尼星：`L(R₁*) = L(R₁)*`。

因此，`L(R)`的定义取决于语言的正规规则。语法与语义之间也存在密切的平行关系：`·`表示连接，`+`表示并集，`*`表示星号。由于这种紧密的平行关系，我们可能可以在正则表达式中滥用符号，用连接代替`·`，用并集代替`+`，用星号代替`*`。此时，读者必须配合并“看到”它们预期出现的地方（例如，代替`+`）。这种滥用在示例 (2) 中可见。特别是在正则表达式中，并集符号`∪`代替了`+`。我们更倾向于使用`+`，因为这些正则表达式看起来像算术运算符，并遵循算术运算符预期的优先级规则。

## 1. 广化非确定有限自动机

由于正规语言在正规操作下封闭的，我们立即得到：

**引理 3.** 正表达式仅表示正规语言。

基于此，我们引入了`nfa`的泛化。一个广化的`gufa`是一个四元组`M = (Q, Σ, δ, q₀)`，含义与`nfa`相同，但`δ`是一个有限的转移规则集合，形式如下：

```
(q, E → q')
```

其中`q, q' ∈ Q`且`E`是关于`Σ`的任何正则表达式。如果`w' ∈ Σ*`，当`w' ∈ L(E)`且`δ`符合形式 (3) 时，我们称`q →w' q'`（或简写为`q →w q'`）。如果单词`w`可以表示为`w = w₁w₂...wₖ`且存在`q₀ →w₁ q₁ →w₂ q₂ ... →wₖ qₖ`且`qₖ ∈ F`，则`w`被`M`接受。语言`L(M)`是`M`接受的单词集合。

如果`L(M) = {q}`，`Q={q₀, q}`，`q₀ ≠ q`且`δ`只有一条规则`(q₀, E → q)`，则`gufa M = (Q, Σ, δ, q₀)`是平凡的。用`M`表示该`gufa`。

**引理 4.** 每个`gufa`都等于一个平凡`gufa`。

**证明。** 假设`M`是一个`gufa`。我们首先将`M`转换为“良好”的形式：

- (N1) 如果假设`q₀ ∈ F`；否则，我们引入一个新状态`q₀'`并将每个形式为`(q₀, E → q)`的规则替换为新规则`(q₀, E → q₀')`。新`gufa`与原的等价。
- (N2) 接下来，我们假设`F = {q}`；否则，我们引入一个新状态`q`并为每个`q ∈ F`引入转移`(q, ε → q)`。
- (N3) 如果假设对于每个`q, q' ∈ Q`，最多存在一条形式为`(q, E → q')`的规则；我们将所有此类规则替换为单一新规则`(q, E → q')`。正则表达式`E`是被替换规则中所有`E`规则的并集。

令`M`为一个`|Q| ≥ 2`的良好`gufa`。如果`|Q| = 2`，则`M`是平凡的，我们完成了。如果`|Q| > 2`，则`M`等于任何状态`q ∈ Q \ {q₀, q}`。我们通过替换以下规则来消除`q`：

```
(q₁, E₁ → q), (q, E₀ → q), (q₂, E₂ → q₂)
```

为规则`(q₁, E₁E₀E₂ → q)`。如果不存在此类规则，则在此规范中将`E₀`视为`ε`。我们可以从新`gufa N'`中消除`q`，它显然等价于`N`。在情况 (N3) 下我们可以让这一点发生。

Q.E.D.

上述引理立即得出了我们关于正则表达式的主结论：

**定理 5.** 正表达式仅表示正规语言。

**证明。** 正则表达式仅表示正规语言的事实是上述引理 3。

（我们必须证明每个`gufa M`产生一个表达式`E`使得`L(M) = L(E)`。但由于`dfa`是一个`gufa`，之前的引理表明`M`等于某个正则表达式的平凡`gufa M(E)`。因此`L(M) = L(E)`。Q.E.D.）

### 0.1.5 引理

我们考虑一个自然问题：是否存在非正规语言？我们如何证明某些语言不是正规的？考虑语言`L₁ = {w ∈ {0,1}* : #(0) = #(1)}`，`L₂ = {w ∈ {0,1}* : #(0)=2}`。函数`#(v)`计算`v`在`w`中出现的次数（`v`的出现可能会重叠）。例如`#(010) = 2`。我们可能会认为`L₁`是非正规的，因为任何`dfa`只有有限状态。这种非正式的论证可能是有力的，但对于`L₂`采用相同的方法证明是错误的。我们需要非正规性的正式工具。最重要的工具是泵引理。

**定理 6（正规集的泵引理）。** 如果`L`是正规语言，则存在一个`p > 0`（称为泵数），对于所有长度至少`p`的`w ∈ L`，我们可以写出`w = xyz`使得

(i) 对于所有`i ≥ 0`，`xy^iz ∈ L`;
(ii) `|y| > 0`;
(iii) `xy²z ∈ L`

**证明。** 令`p`为接受`L`的`dfa`中的状态数。假设`w ∈ L`且`|w| ≥ p`。令`w`表示`w`的长度为`i`的前缀，`i ≥ 0`。考虑状态`q₀, q₁, ..., qₙ`，其中`qᵢ = δ*(q₀, i)`。`w₀ = q₀`且`qₙ`是起始状态。由于该序列中的状态多于`p`，因此某个状态必须重复。选择`0 ≤ i < j ≤ p`使得`qᵢ = qⱼ`。那么我们可以写出`w = xyz`，其中`x = wᵢ`，`y = wⱼ`。现在很容易验证 (i)、(ii) 和 (iii) 成立。

Q.E.D.

我们将此引应用于平方语言`L_sq = {1ⁿ : n ∈ ℕ}`。如果`L_sq`是正规的，`p`为其泵数。考虑字符串`w = 1^(p²) ∈ L_sq`。泵引理意味着`w = xyz`，满足`|y| ≤ p`且`xy^iz ∈ L_sq`。但`p²+p ≤ p(p+1) < (p+1)²`，且`|xyz|`不是平方。这个矛盾显示了`L_sq`的非正规性。

`L_pal = {w : w = w^R, w ∈ {0,1}*}`是回文集。我们证明`L_pal`不是正规的。如果它是正规的且泵数为`p`，考虑`w = 0^p1^p`。那么`w = xyz`，其中`y ∈ {0}*`。那么`wy²z`不是回文，矛盾。

## 0.1.6 Myhill-Nerode 定理

J. Myhill 和 A. Nerode 的一个定理提供了另一种证明非正规性的方法。对于任何语言`L ⊆ Σ*`，我们在`Σ*`上定义`L`-等价关系如下：两个字符串`x, y ∈ Σ*`是`L`-等价的，写作`x ≡_L y`，如果

`(∀z ∈ Σ*) (xz ∈ L ⇔ yz ∈ L)`

特别地，`x ≡_L y`意味着`x`和`y`都属于`L`或都不属于`L`。这种关系被视为等价关系，对于任何`x ∈ Σ*`，我们令`[x]_L`表示相对于`≡_L`的等价类。`L`的等价类数量被称为它的索引。我们特别关注有限索引的情况。

**定理 7（Myhill-Nerode）。** 语言`L`是正规的当仅当`L`有有限索引。

**证明。** 一个显而易见：如果`L`是正规的，那么它有有限索引。令`M`为一个`dfa (Q, Σ, δ, q₀, F)`，其中`Q = {[w]_L : w ∈ Σ*}`是`L`-等价类。起始状态`q₀ ∈ Q`是`ε`的等价类。状态集`F`组成`{[w]_L : w ∈ L}`。通过归纳很容易证明转移函数由`δ([w], a) = [wa]`给出。

Q.E.D.

与泵引理不同，这个定理提供了正则集的真实刻征。让我们在应用中看看。如果`L = {0ⁿ1ⁿ : n ≥ 0}`，那么对于所有`i ≠ j`，`[0^i]_L ≠ [0^j]_L`。这证明了`L`没有有限索引。由此`L`非正则。

## 0.2.1 上文自由文法

我们看到了自动机（`dfa`, `nfa`）和表达式（正规），现在我们引入“形式文法”作为描述语言的另一种设备。文法的概念受到自然语言的启发。简单英语句子的结构。以下是“语法规则”：

# 第 0 章：可计算性导论

```
<Sentence> --> <Noun Phrase> <Verb Phrase>
<Noun Phrase> --> <Article> <Noun> | <Noun>
<Verb Phrase> --> <Verb> | <Verb> <Noun Phrase>
<Article> --> a | the
<Noun> --> boy | girl | ball | dog | ...
<Verb> --> caught | saw | took | ...
```

```
Girl took the ball
The boy saw a girl
Dog caught ball
A ball saw the boy
. .
```

证明句子 "Girl took the ball" 可以由简单的语法生成，等同于一棵解析树：

```
<Sentence>
|             |     |
<Noun Phrase>   <Verb Phrase>
|             |       |
<Noun>       <Verb>   <Noun Phrase>
|             |       ||
Girl       took    <Article> <Noun>
                    the ball
```

语法规则（或产生式）有一个左侧和一个右侧。每一侧都是由变量（由`<...>`表示）和终结符（如 boy, girl 等）组成的字符串。使用这些规则，我们生成的句子被定义为仅包含终结符的字符串。

我们对此此进行形式化。`V, Σ`是不交集。一个上下文无关语法（CFG）是一个四元组：

```
G = (V, Σ, S, R)
```

其中`V`是变量集，`Σ`是终结符集，`S ∈ V`是起始符号，`R`是有限规则集。规则（或产生式）的形式为`A → w`，其中`A ∈ V`且`w ∈ (V ∪ Σ)*`。将产生关系定义为词之间的关系：

```
u → v
```
