
## 描述

`strtol`、`strtoll`、`strtoul` 和 `strtou` 函数分别将 `nptr` 指向的字符串初始部分转换为 `long int`、`long long int`、`unsigned long int` 和 `unsigned long long int` 表示。首先，它们将输入字符串分解为三部分：初始的可能为空的空白字符序列（由 `isspace` 函数指定）、一个在 `base` 值决定的半径范围内类似于整数的主体序列，以及由一个或多个无法识别字符组成的最终字符串（包括输入字符串的终止字符）。

> 294 `DECIMAL_DIGITS` 定义在 `<float.h>` 中，应当足够大，使得 `L` 和 `U` 通常会舍入到相同的内部浮点值，但不会舍入到相邻的值。

然后，它们尝试将主体序列转换为整数并返回结果。

- 如果 `base` 的值为 0，则主体序列的预期形式为 6.4.4.1 描述的整数形式，可选地带有加号或减号，不包括整数后缀。如果 `base` 的值在 2 到 36 之间（包含），则主体序列的预期形式是一个字母和数字序列，表示由 `base` 指定半径的整数，可选地带有加号或减号，但不包括整数后缀。从 a（或 A）到 z（或 Z）的字母被赋予值 10 到 35；仅允许值小于 `base` 值的字母和数字。如果 `base` 的值为 16，则字符 `0x` 或 `0X` 可选地出现在字母和数字序列之前（如果存在符号，则在符号之后）。

- 主体序列定义为输入字符串中从第一个非空白字符开始的符合预期形式的最长初始子序列。如果输入字符串为空或完全由空白字符组成，或者第一个非空白字符不是符号或其他允许的字母或数字，则主体序列不包含任何字符。

- 如果主体序列具有预期形式且 `base` 的值为 0，则从第一个数字开始的字符序列将根据 6.4.4.1 的规则解释为整数常量。如果主体序列具有预期形式且 `base` 的值在 2 到 36 之间，则它被用作转换的基，按上述方式分配每个字母。如果主体序列以减号开头，则转换产生的值将取反（在返回类型中）。如果 `endptr` 不是空指针，则指向最终字符串的指针存储在 `endptr` 指向的对象中。

- 在 "C" 区域外，还可能接受额外的特定区域的主体形式。

- 如果主体序列为空或不具有预期形式，则不执行转换；如果 `endptr` 不是空指针，则 `nptr` 的值存储在 `endptr` 指向的对象中。

### 返回

- `strtol`、`strtok`、`strtol` 和 `strtoll` 函数返回转换后的值（如果有）。如果无法进行转换，则返回 0。如果正确的值在可表示范围之外，则返回 `LONG_MIN`、`LONG_MAX`、`LLONG_MIN`、`LLONG_MAX`、`ULONG_MAX` 或 `ULONG_MAX`（取决于返回类型和值的符号，如果有），并将宏 `ERANGE` 的值存储在 `errno` 中

### 7.22.2.1 rand 函数

#### 概要

```c

```

## 描述

`rand` 函数计算 0 到 `RAND_MAX` 范围内的伪随机整数序列。295

`rand` 函数不要求避免与其他伪随机序列生成函数的调用之间产生数据竞态。该实现应当表现得好像没有库函数调用 `rand` 函数一样。

### 环境限制

## 7.22.2.2 srand 函数

#### 概要

```c
#include <stdlib.h>

void srand(unsigned int seed);
```

## 描述

`srand` 函数使用参数作为新伪随机数序列的种子，随后的 `rand` 调用将返回该序列。如果随后使用相同的种子值调用 `srand`，则伪随机序列将重复。如果在调用任何 `srand` 之前调用了 `rand`，则生成的序列应与首次使用种子值 1 调用 `srand` 时生成的序列相同。

`srand` 函数不要求避免与其他伪随机序列生成函数的调用之间产生数据竞态。该实现应当表现得好像没有库函数调用 `srand`。

> 295 对于产生的随机序列的质量没有保证，且已知某些实现会产生低位极度不随机的序列。具有特殊要求的应用程序应在使用足够满足其需求的生成器。

### 返回

`srand` 函数不返回任何值。

以下函数 `unsigned long int next = 1` 定义了 `rand` 和 `srand` 的可移植实现。

```c
static int rand(void) // 假设 RAND_MAX 为 32767
{
    next = next * 110351245 + 12345;
    return (unsigned int)(next/65536) % 32768;
}

void srand(unsigned int seed)
{
    next = seed;
}
```

## 7.2.2.3 内存管理函数

连续调用 `aligned_alloc`、`calloc`、`malloc` 和 `realloc` 函数分配的存储顺序和连续性是不确定的。如果分配成功，返回的指针是对齐的，可以赋值给具有基本要求的类型的指针，并需要访问此类对象或对象数组（直到空间显式释放）。被分配对象的生命周期从分配持续到释放。每次分配应产生一个与任何其他对象不相交的指针。返回的指针指向分配空间的起始（最低地址）。如果无法分配空间，则返回空指针。如果请求的空间大小为零，行为由实现定义：返回空指针，或者行为类似于大小为某个零值，但返回的指针不应用于访问对象。

为了确定数据竞态的存在，内存函数的表现应当仅访问了通过其参数访问的位置，而不是其他静态持续期存储。然而，这些函数可能会修改它们分配或释放的存储。调用 `free` 或 `realloc` 释放区域 `p` 与任何分配全部或部分区域 `p` 的同步。这种同步发生在释放函数对 `p` 的任何访问之后，以及分配函数对 `p` 的任何此类访问之前。

### 7.2.3.1 aligned_alloc 函数

#### 概要

```c
#include <stdlib.h>

void *aligned_alloc(size_t alignment, size_t size);
```

`aligned_alloc` 函数为对象分配空间，该对象的对齐方式由 `alignment` 指定，大小由 `size` 指定，且其值是不确定的。`alignment` 的值应该是实现支持的有效对齐方式，且 `size` 的值应该是 `alignment` 的整数倍。

## 返回

`aligned_alloc` 函数返回空指针或指向分配空间的指针。

## 描述

`calloc` 函数为一个包含 `nmemb` 个对象的数组分配空间，其中每个对象的大小为 `size`。该空间被初始化为所有位均为零。²296

### 摘要


## 描述

`free` 函数导致 `ptr` 所指向的空间被释放，即该空间可供进一步分配。如果 `ptr` 是空指针，则不发生任何操作。否则，如果参数与之前由内存管理函数返回的指针不匹配，或者该空间已经通过调用 `free` 或 `realloc` 被释放，则行为是未定义的。

## 返回

### 摘要

```c

```

## 描述

`malloc` 函数为一个大小由 `size` 指定且其值是不确定的对象分配空间。

### 返回

`malloc` 函数返回空指针或指向分配空间的指针。

## 7.22.3.5 realloc 函数

### 摘要

```c
#include <stdlib.h>

void *realloc(void *ptr, size_t size);
```

## 描述

`realloc` 函数释放 `ptr` 所指向的旧对象，并返回一个指向新对象的指针，该新对象的大小由 `size` 指定。新对象的内容应与释放前的旧对象内容相同，直到达到新旧大小中的较小值。新对象中超出旧对象大小的任何字节，其值是不确定的。

如果 `ptr` 是空指针，`realloc` 函数的行为等同于指定大小的 `malloc` 函数。否则，如果 `ptr` 与之前由内存管理函数返回的指针不匹配，或者该空间已经通过调用 `free` 或 `realloc` 函数被释放，则行为是未定义的。如果无法为新对象分配内存，旧对象不会被释放，其值保持不变。

### 返回

`realloc` 函数返回指向新对象的指针（该指针可能与指向旧对象的指针相同），或者在无法分配新对象时返回空指针。

## 7.2.25 搜索和排序工具

这些工具使用比较函数来对未指定位置的数组进行搜索或排序。当声明为 `size_t nmemb` 的参数指定数组长度时，在调用该函数时，`nmemb` 可以取零值；此时，比较函数不会被调用，搜索将找不到匹配元素，且排序将不进行任何重排。在此类调用中，指针参数仍应具有如 7.1.4 节所描述的有效值。

实现层应确保比较函数的第二个参数（当从 `bsearch` 调用时）或两个参数（当从 `qsort` 调用时）都是指向数组元素的指针。当从 `bsearch` 调用时，第一个参数应等于 `key`。

比较函数不应修改数组的内容。实现层可以在两次调用比较函数之间重新排列数组元素，但不应修改任何单个元素的内容。

当相同的对象（由 `size` 个字节组成，无论它们在数组中的当前位置）多次传递给比较函数时，其结果应该是一致的。也就是说，对于 `qsort`，它们定义了数组上的全序，而对于 `bsearch`，同一对象与 `key` 的比较结果应始终相同。

在每次调用比较函数之前和之后都会发生一个序列点，并且在任何比较函数调用与作为参数传递的对象的移动之间也会发生。

> 也就是说，如果传递的值为 `p`，则以下表达式始终为零：

```c
((char*)p - (char*)base) % size == 0
(char*)p >= (char*)base
(char*)p < (char*)base + nmemb * size
```

### 7.2.5.1 bsearch 函数

### 概要

```c
#include <stdlib.h>

void *bsearch(const void *key, const void *base,
      size_t nmemb, size_t size,
      int (*compar)(const void *, const void *));
```

## 描述

`bsearch` 函数在一个包含 `nmemb` 个对象的数组（其初始元素由 `base` 指向）中搜索与 `key` 指向的对象匹配的元素。数组每个元素的大小由 `size` 指定。

由 `compare` 指向的比较函数通过两个参数调用，分别指向 `key` 对象和数组元素。如果 `key` 对象分别被认为小于、等于或大于数组元素，则函数应分别返回小于、等于或大于零的整数。数组应按以下顺序组成：所有小于 `key` 的元素、所有等于 `key` 对象的元素以及所有大于 `key` 对象的元素。

### 返回

`bsearch` 函数返回数组中匹配元素的指针，如果没有找到匹配项，则返回空指针。如果两个元素比较结果相等，则匹配哪一个元素是不指定的。

### 7.2.5.2 qsort 函数

### 概要

```c
#include <stdlib.h>

void qsort(void *base, size_t nmemb, size_t size,
      int (*compar)(const void *, const void *));
```
