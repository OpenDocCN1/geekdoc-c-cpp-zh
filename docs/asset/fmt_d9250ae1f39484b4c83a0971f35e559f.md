## 远程对象的承载

当服务器远程对象通过 Windows 服务或组件对象模型（COM）+ 服务正确承载时，客户端就可以随时使用它。您也可以在 IIS 上承载远程对象，此时需要创建一个配置文件来承载远程对象。若要在 IIS 中承载远程对象，您需要创建一个虚拟目录，并将包含所有与可远程对象相关的远程处理设置的 `web.config` 文件复制到该虚拟目录中。复制 `web.config` 文件后，您需要将包含远程对象的可执行文件或动态链接库（DLL）放置在 IIS 根目录的 `bin` 目录中。需要注意的是，IIS 根名称应与配置文件中指定的应用程序名称相同。当第一个消息到达应用程序时，远程处理配置文件会自动加载。通过这种方式，.NET 远程处理对象可以作为 Web 服务公开。`web.config` 文件的示例代码显示在以下代码片段中：

```
<configuration>
  <system.runtime.remoting>
    <application>
      <service wellknown mode="Singleton" objectUri="HiServerApp.soap" type="SharedObject.SharedObject, SharedObject"/>
      <channels><channel ref="http">
        <serverProviders>
          <provider ref="soap" typeFilterLevel="full" />
          <provider ref="wsdl" remoteApplicationMetadataEnabled="true"/>
        </serverProviders>
      </channel></channels>
    </application>
  </system.runtime.remoting>
</configuration>
```

## 设置对象的租约时间

当对象被发布并开始与外部 `AppDomain` 交互时，必须决定远程对象的租约时间，租约时间是指在该时间之后，对象将不再被任何人使用。当对象的租约时间到期时，标记为删除的对象将被垃圾回收器销毁。租约时间的概念仅适用于 `Singleton` 或客户端激活对象。默认情况下，客户端对象的指定时间为五分钟。但是，您可以在远程对象的构造函数中更改此默认时间，如以下代码片段所示：

```
public override object InitializeLifetimeService()
{
  ILease myLease = (ILease)base.InitializeLifetimeService();
  myLease.InitialLeaseTime = TimeSpan.FromMinutes(10);
  myLease.RenewOnCallTime = TimeSpan.FromMinutes(50);
  return myLease;
}
```
