## 静态方法和变量

如果方法和变量在类中被定义为静态（static），则同样可以被利用和访问。正如第 3 章所述，静态意味着系统或变量不是通过对象实现的。在 PHP 4.0 中，没有真正的方法可以判断一个变量是静态的；尽管如此，在 PHP 5.0 中，你可以使用 `static` 修饰。

`::` 运算符允许你引用没有任何对象的类中的变量和系统。示例 7.20 显示了你如何使用 `::` 调用静态系统，以及即使在创建了实例后，普通的调用语法仍然不起（PHP 不会报告错误）。

### 示例 7.20. 利用 :: 运算符调用催眠

```php

<?php

class Cat {

}

class Domestic_Cat extends Cat {

  //Constructor

  function Domestic_Cat() {

  }

  //此函数必须静态地调用

  public static function hypnotize() {

    echo("The cat was hypnotized.");

    return;

  }

}

// 催眠所有的猫

Domestic_Cat::hypnotize();

```

```php

$domestic_cat = new Domestic_Cat();

```

输出如下：

The cat was hypnotized.

当使用范围解析符（`::`）调用静态方法时，由于不存在对象，你无法利用 `$this` 来引用对象。

## 变量引用

在 PHP 中，变量名指的是内存中存储信息的区域。可以有多个变量名指向内存中的同一个位置。安培符运算符 `&` 用于表示你关注的是变量所引用的内存区域，而不是它的值。

PHP 引用允许让两个变量引用相同的内容。通过这种方式，更改一个变量的值可以改变另一个变量的值。这可能会导致发现代码中的错误变得异常困难，因为改变一个变量会改变另一个。

相同的标点符号也可以用于接收引用的函数。用例 5.21 利用此来引用 `$some` 变量。

### 示例 7.21. 引用 $some_variable

```php

<?php

$some_variable = "Hello World!";

$some_reference = &$some_variable;

$some_reference = "Guten Tag World!";

echo $some_variable;

echo $some_reference;

?>

```

输出如下：

Guten Tag World!
Guten Tag World!

示例 7.21 显示引用是使用 `&` 运算符进行定位的，并且位于当前变量 `$` 之前。变量 `$some_reference` 然后引用了 `$some_variable`（放置 "Hello World!" 的内存区域）。

正如在本部分已经检查过的，变量引用有助于将变量作为引用传递给函数。这允许函数修改你基础代码中的变量，而不是修改一个在函数结束时丢失的本地副本。

在不使用引用运算符的情况下将变量赋值给另一个变量会导致变量的副本被设置在内存的另一个位置。可以更改新变量而不会修改第一个变量。虽然这会占用更多内存，但如果你不想更改第一个变量的值，这是最好的方法。

## 9.2 管理数据库

现在你已经关联到数据库，可以创建用户、数据库和表了。如果你在托管环境中使用 MySQL 服务器，则不需要创建数据库或客户端账户，因为他们已经为你提供了用户名和数据库名称。

### 创建用户

要创建超出默认首选 root 客户端的用户，请执行 grant 命令。`grant` 命令的语法如下：

```
GRANT PRIVILEGES ON DATABASE.OBJECTS TO 'username'@'hostname' IDENTIFIED BY 'password';
```

例如：

```
GRANT ALL PRIVILEGES ON .* TO "michele"@localhost" IDENTIFIED BY 'secret';
```

这创建了一个名为 michele 的客户端，它可以从本地访问任何内容。要切换到 michele 客户端，在 mysql 命令提示符处输入：

```
exit
```

此时，从命令行使用新的用户名和密码启动 MySQL。启动 MySQL 时用户名和密的的语法符号为：

```
mysql -h hostname -u username -p password
```

注意 `-p` 和密字之间没有空格。如果你只指定了 `-p` 标志而不带密码，MySQL 会提示你输入密码。如果你不需要让客户端访问其表之外的表，请在 *GRANT PRIVILEGES ON ..* TO “michele” 代码中补充客户端数据库的名称，类似于：

```
GRANT ALL PRIVILEGES ON store.* TO "michele"@localhost" IDENTIFIED BY 'mystery'; 
```

你必须以 root 或具有权限的身份运行此行代码。在此代码中，单词 store 关联到分配权限的数据库名称，你将在接下来的部分创建它。

### 创建 MySQL 数据库

你将创建一个名为 store 的数据库。`CREATE DATABASE` 命令的功能如下：

```
CREATE DATABASE store;
```

如果执行成功，你将得到类似所示的结果：

Query OK, 1 row influenced (0.03 sec)

数据库名不能包含任何空格。在如 Linux 和 Mac OS X 等 Unix 服务器上，数据库名也是区分大小大小的。

要开始使用此数据库，输入：

Use store;

你将得到结果：

Database changed.

## 9.5 结构化查询语言

既然你已经定义了表，就可以向其中添加信息了。MySQL 将跟踪所有细节。要管理信息，请使用结构化查询语言 (SQL) 命令。

由于其设计目的是为了轻松地描述行与表之间的关系，数据库使用 SQL 来修改表中的信息。

SQL 是一种用于大多数数据库（例如 MySQL、Oracle 或 Microsoft SQL Server）的标准语言。它被专门设计为用于检索、包含和管理存储在数据库中的信息的语言。我们将在下一章详细介绍 MySQL 的细节，但我们将从一些易于使用的简单命令开始。我们将从创建表开始。

### 创建表

利用表命令来指定新数据库表的结构。当你创建一个数据库表时，每个段都有几个选择，以及数据类型和列名。在向表中添加信息时，必须提供的值通过 `NOT NULL` 关键字指定。`PRIMARY KEY` 关键字告诉 MySQL 使用哪个段作为键字段。随后，你可以使用 `AUTO_INCREMENT` 关键字让 MySQL 自动分配键值。
