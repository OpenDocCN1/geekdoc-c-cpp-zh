# 第 25 章 龙格-库塔方法

本章致力于求解如下形式的常微分方程：

```
dy/dx = f(x, y)
```

在第 1 章中，我们使用数值方法求解了此类方程以获得落体射体的速度。回想该方法的通用形式为

新值 = 旧值 + 斜率 $\times$ 步长

或者用数学术语表示：

```
y_{i+1} = y_i + \phi h \quad (25.1)
```

根据该方程，$\phi$ 的斜率估计用于从旧值 $y_i$ 在距离 $h$ 内外推到新值 $y_{i+1}$（图 25.1）。该公式可以逐步应用，以计算未来的值，从而追踪解的轨迹。

所有单步法都可以用这种通用形式表示，唯一的区别在于估计斜率的方式。正如下落伞兵问题一样，最简单的方法是使用微分方程估计 $x_i$ 处的一阶导数形式的斜率。换句话说，区间起始斜率被视为整个区间平均斜率的近似。这种方法被称为**欧拉法**，在本章的第一部分进行了讨论。随后是其他采用自适应估计以获得更准确预测的单步法。所有这些技术通常被称为**龙格-库塔方法**。

## 25.1 欧拉法

一阶导数提供了 $x_i$ 处斜率的直接估计（图 25.2）：

```
\phi = f(x_i, y_i)
```

其中 $f(x_i, y_i)$ 是在 $x_i$ 和 $y_i$ 处的微分方程值。该估计可以代入 $x_i$（方程 25.1）：

```
y_{i+1} = y_i + f(x_i, y_i)h \quad (25.2)
```

该公式被称为**欧拉法**（或**欧拉-卡西法**、**点斜率法**）。使用斜率（等于原始 $x$ 处的一阶导数）在步长 $h$ 上进行外推，以预测 $y$ 的新值（图 25.2）。

### 示例 25.1 欧拉法

**问题描述。** 使用欧拉法数值积分 $\frac{dy}{dx} = -2x^3 + 12x^2 - 20x + 8$，从 $x = 0$ 到 $x = 4$，步长为 $0.5$。$x=0$ 处的初始条件为 $y = 1$。回想精确解由 $y = -0.5x^4 + 4x^3 - 10x^2 + 8.5x + 1$ 给出。

**解。** 可以使用方程 (25.2) 实现欧拉法，其中 $y(0)=1$ 且 $x=0$ 处的斜率估计为

$f(0) = -2(0)^3 + 12(0)^2 - 20(0) + 8 = 8$。

因此，
$y(0.5) = y(0) + f(0,y(0))h = 1 + 8(0.5) = 5$。

$x=0.5$ 处的真解为 $y = -0.5(0.5)^4 + 4(0.5)^3 - 10(0.5)^2 + 8.5(0.5) + 1 = 3.21875$。

误差是 $E_t = \text{true} - \text{approximate} = 3.21875 - 5 = -1.78125$，或者以百分比表示，$e_t = -35.6\%$。

对于第二步，
$y(1) = y(0.5) + f(0.5,y(0.5))h = 5 + [-2(0.5)^3 + 12(0.5)^2 - 20(0.5) + 8](0.5) = 5 + [-0.25 + 3 - 10 + 8](0.5) = 5 + 0.75(0.5) = 5.375$。

$x=1$ 处的真解是 $y = -0.5(1)^4 + 4(1)^3 - 10(1)^2 + 8.5(1) + 1 = 3$。

误差是 $E_t = \text{true} - \text{approximate} = 3 - 5.375 = -2.375$，或者以百分比表示，$e_t = -44.2\%$。

### 25.1.1 欧拉法的误差分析

ODE 的数值求解涉及两种误差（回顾第 3 和 4 章）：

1. **截断误差**（或离散误差）是由用于近似 $y$ 值的技术性质引起的。
2. 由计算机保留的有效位数有限引起的**舍入误差**。

截断误差由两部分组成。第一部分是单步应用该方法时产生的**局部截断误差**。第二是由于之前步骤产生的近似值导致的**传播截断误差**。这两者之和为总误差，或**全局截断误差**。

通过从泰勒级数展开直接推导欧拉法，可以了解截断误差的幅值性质。要做到这一点，意识到积分的微分方程具有一般形式

```
y' = f(x, y) \quad (25.3)
```

其中 $x$ 和 $y$ 分别是自变量和因变量。如果解 $y$ 具有连续导数，它可以用关于某值 $(x_0, y_0)$ 的泰勒级数展开表示，如[回顾方程 (4.7)]：

```
y_{i+1} = y_i + y'_i h + y''_i h^2/2! + ... + y^{(n)}_i h^n/n! + R_i \quad (25.4)
```

其中 $x_{i+1} = x_i + h$，$R_i$ 是余项，定义为：

```
R_i = y^{(n+1)}(\xi) h^{n+1}/(n+1)! \quad (25.5)
```

其中 $\xi$ 位于 $x_i$ 到 $x_{i+1}$ 之间的某处。通过将方程 (25.3) 代入方程 (25.4) 和 (25.5)，可以推导出另一种形式：

```
y_{i+1} = y_i + f(x_i, y_i)h + f'(x_i, y_i)h^2/2! + ... + f^{(n-1)}(x_i, y_i)h^n/n! + O(h^{n+1}) \quad (25.6)
```

其中 $O(h^{n+1})$ 指定局部截断误差与步长的 $(n+1)$ 次方成正比。

通过比较方程 (25.2) 和 (25.6)，我们可以看到欧拉法与泰勒级数展开一直匹配到包含 $(x_i, y_i)$ 在内的项。此外，比较表明截断误差的产生是因为我们使用泰勒级数展开中的有限项来近似真实解。我们截断（或忽略）了真实解的一部分。例如，欧拉法中的截断误差归因于泰勒展开中未包含在方程 (25.2) 中的剩余项。从方程 (25.6) 减去方程 (25.2) 得：

```
E_i = f'(x_i, y_i)h^2/2! + ... + O(h^{n+1}) \quad (25.7)
```

其中 $E_i$ 是真实的局部截断误差。对于足够小的 $h$，误差随着阶数的降低而增加（回顾示例 4.2 及其相关讨论），结果通常表示为：

```
E_i = f'(x_i, y_i)h^2/2! \quad (25.8)
```

或

```
E_a = O(h^2) \quad (25.9)
```

其中 $E_a$ 是近似的局部截断误差。

### 示例 25.2 欧拉法误差的泰勒级数估计

**问题描述。** 使用方程 (25.7) 估计示例 25.1 第一步的误差。同时也使用它来确定由于泰勒级数展开中高阶项引起的误差。

**解。** 由于我们处理的是多项式，可以使用泰勒级数获得欧拉法误差的精确估计。方程 (25.7) 可以写为：

```
E_i = \frac{f'(x_i, y_i)h^2}{2!} + \frac{f''(x_i, y_i)h^3}{3!} + \frac{f'''(x_i, y_i)h^4}{4!} \quad (E25.2.1)
```

其中 $f'(x_i, y_i)$ 是微分方程的导数（即解的二阶导数）。在当前案例中，这是：

```
f'(x_i, y_i) = -6x^2 + 24x - 20 \quad (E25.2.2)
```

且 $f''(x_i, y_i)$ 是微分方程的二阶导数，

```
f''(x_i, y_i) = -12x + 24 \quad (E25.2.3)
```

且 $f'''(x_i, y_i)$ 是微分方程的三阶导数，

```
f'''(x_i, y_i) = -12 \quad (E25.2.4)
```

我们可以从方程 (E25.2.1) 中省略额外的项（即高阶导数及更高阶），因为对于这个特定案例，它们等于零。应该注意，对于其他函数（例如正弦波或指数等超越函数），这将是不可能的，高阶项将具有非零值。然而，对于当前案例，方程 (E25.2.1) 到 (E25.2.4) 完整定义了单次应用欧拉法的截断误差。

对于二阶项截断引起的误差可以计算为：

```
E_2 = \frac{-6(x_i)^2 + 24x - 20}{2}(0.5)^2 = -2.5 \quad (E25.2.5)
```

对于三阶项：

```
E_3 = \frac{-12}{6}(0.5)^3 = -0.5
```

对于四阶项：

```
E_4 = \frac{-12}{24}(0.5)^4 = -0.0125
```

这三项相加得到总误差：

```
E_t = E_2 + E_3 + E_4 = -2.5 - 0.5 - 0.0125 = -3.0125
```

是示例 25.1 第一步产生的误差。注意 $E_{2} > E_{3} > E_{4}$，这由方程 (25.8) 所示。

尽管这些限制使得大多数实际问题无法进行精确分析，泰勒级数仍然对欧拉法的行为提供了有价值的见解。这些观察得出实用的结论：

1. 可以通过缩小步长来减小误差。
2. 如果底层函数是线性的，该方法将提供无误差预测。

还应该注意，这一一般模式适用于后续页面描述的高阶单步法。也就是说，如果底层解是 $n$ 阶的，$n$ 阶方法将产生完美的预测。

### 25.1.2 欧拉法的算法

如欧拉法等单步法的算法程序编写极其简单。正如本章开头之前指定的，所有单步方法都具有通用形式：

新值 = 旧值 + 斜率 $\times$ 步长

该方法唯一的不同之处在于斜率的计算。在表 25.1 中，如果你想使用欧拉法执行概述的 $y = -2x^3 + 12x^2 - 20x + 8.5$ 的简单计算，初始条件为 $x = 0$ 时 $y = 1$。你想使用 0.5 的步长积分到 $x = 4$，并显示所有结果。实现此任务的简单伪代码可以见图 25.6。

尽管这个程序可以“完成”复制表 25.1 结果的工作，但它的设计得并不很好。首先，也是最重要的是，它不是模块化的。虽然对于一个小程序来说这并不重要，但如果我们想要改进和修改算法，这将是至关重要的。

此外，关于我们如何设置迭代，存在许多问题。例如，假设将步长调小以获得更好的精度。在这种情况下，由于每个计算值都会被显示，输出值可能会很大。此外，该算法基于一个假设，即计算区间可以被步长整除。最后，行 `x = x + dx` 中 $x$ 的累积可以通过之前讨论过的步长误差量化来解决。
