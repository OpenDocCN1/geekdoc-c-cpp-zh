
# 化学信息学算法手册

## 代谢网络

我们提供了 `¹13C MFA` 流程的算法概述。基于 `¹13C` 的 MFA 需要了解代谢反应中碳原子的去向，碳原子信息被转移到同位异构体平衡方程中，这些方程描述了未知通量与可用测量数据集之间的数学关系。利用这些方程，可以通过非线性参数拟合从测量值中计算通量。

近年来，随着实验技术和计算方法的发展，稳态 `¹13C MFA` 已达到相对成熟的阶段。实验本身已成为一种常规程序，测量技术已经完善，并且可以使用复杂的数学评估算法。但 `¹13C MFA` 仍然是一个耗时且低通量的过程。通常，对碳同位异构体网络（如中心碳途径）建模涉及包含几到数千变量的方程组，以平衡真实的之间的反应。这个问题通过基于 `BNGL/BioNetGen` 的方法解决，允许从碳图数据库快速构建并模拟同位异构体平衡方程。

代谢状态是当前通量分析方法的先决条件。常规通量分析方法基于蛋白质源氨基酸同位素标记模式的 `¹13C` 稳态，这反映了它们在中心代谢中的12种前驱体。检测游离细胞内代谢介物的标记模式可以显著改变标记实验，因为这些中间体达到 `¹13C` 稳态的速度比蛋白质源氨基酸快得多。标记模式也可以超越12种前驱体。细胞内代谢中间体的动态 `¹13C` 标记模式包含比 `¹³C` 稳态同位素标记模式更多的信息。例如，细胞内代谢物的大小影响动态标记模式，而对稳态标记模式没有影响。
