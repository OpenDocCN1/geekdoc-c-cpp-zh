## ES6 箭头函数

JavaScript ES6 引入了箭头函数。箭头函数表达式比函数表达式短。

代码演练场 (Code Playground)

```
// function expression
function () { ... }

// arrow function expression
() => { ... }
```

但你必须意识到它的功能。其中之一与 `this` 对象的行为不同。函数表达式总是定义它自己的对象。箭头函数表达式仍然具有闭包上下文的这个 `this` 对象。在箭头函数中使用 `this` 时不要感到困惑。

关于箭头函数，还有一个关于括号的价值事实。当函数只有一个参数时，你可以移除括号，但当有多个参数时，必须保留它们。

代码演练场 (Code Playground)

```
// allowed
item => { ... }

// allowed
(item) => { ... }

// not allowed
item, key => { ... }

// allowed
(item, key) => { ... }
```

然而，让我们来看 `map` 函数。你可以使用 ES6 箭头函数将其写得更简洁。

### src/App.js

```
{list.map(item => {
  return (
    <div key={item.objectID}>
      <span>
        <a href={item.url}>{item.title}</a>
      </span>
      <span>{item.author}</span>
      <span>{item.num_comments}</span>
      <span>{item.points}</span>
    </div>
  );
})}
```（注：根据原句注释，已更正了原句中多余的右括号）

此外，你可以移除 ES6 箭头函数的块级体（即大括号）。在简洁的主体中，会附带一个隐式返回。你可以移除 `return` 语句。这在书中会经常出现，所以请务务理解箭头函数中使用块级体和简洁主体的区别。

### src/App.js

```
{list.map(item =>
<div key={item.objectID}>
  <span>
    <a href={item.url}>{item.title}</a>
  </span>
  <span>{item.author}</span>
  <span>{item.num_comments}</span>
  <span>{item.points}</span>
</div>
))}
```

你的 JSX 现在看起来更简洁、更易读了。它省略了函数语句、大括号和 `return` 语句。相反，开发者可以专注于实现细节。

## ES6 类 (Classes)

JavaScript ES6 引入了类。类在面向对象的编程语言中非常常用。JavaScript 在编程范式上过去和现在都灵活。你可以根据特定的用例并行进行函数式编程和面向对象编程。

尽管 React 拥抱函数式编程（例如使用不可变数据结构），但类仍被用于声明组件。它们是 ES6 类组件。React 混合了两种编程范式的优处。

让我们考虑以下 `Developer` 类，在不考虑组件的情况下检查一个 JavaScript ES6 类。

## 代码演练场 (Code Playground)

```
class Developer {
  constructor(firstname, lastname) {
    this.firstname = firstname;
    this.lastname = lastname;
  }

  getName() {
    return this.firstname + ' ' + this.lastname;
  }
}
```

`Developer` 类只是类的声明。你可以通过调用它来创建类的多个实例。它类似于 ES6 类组件，有一个声明，但你必须在其他地方使用它来实例化。

让我们看看如何实例化这个类以及如何使用它的方法。

```
const robin = new Developer('Robin', 'Wieruch');
console.log(robin.getName());
// output: Robin Wieruch

状态通过使用 `this` 对象被绑定到类上。因此，你可以在整个组件中访问本地状态。例如，它可以在 `render()` 方法中使用。之前，你已经在 `render()` 方法中映射了一个定义在组件外部的静态项目列表。现在你正准备在组件中使用本地状态中的列表。

class App extends Component {

            </span>
            <span>{item.author}</span>
            <span>{item.num_comments}</span>
            <span>{item.points}</span>
          </div>
        ))}
      </div>
    );
  }
}
```

## React 基础

列表现在是组件的一部分了。它存在于组件内部状态中。你可以对列表进行添加、更改或删除项目。每当你更改组件状态时，组件的 `render()` 方法都会再次运行。这就是你如何简单地更改内部组件状态，并确保组件重新渲染并显示来自本地状态的正确数据。

但要小心。不要直接修改状态。你必须使用名为 `setState()` 的方法来修改你的状态。你将在后面的章节中学习它。

## ES6 对象初始化器

在 JavaScript ES6 中，你可以使用简写属性语法更简洁地初始化对象。想象一下以下对象初始化：

```javascript
const name = 'Robin';

const user = {
  name: name,
};
```

当对象中的属性名与你的变量名相同时，你可以执行以下操作：

代码沙场

```javascript
const name = 'Robin';

const user = {
  name,
};
```

在你的应用中，你可以同样这样做。`list` 变量名和状态属性共享相同的名称。

代码沙场

```javascript
// ES5
this.state = {
  list: list,
};

// ES6
this.state = {
  list,
};
```

另一个整洁的助手是简写方法名。在 JavaScript ES6 中，你可以更简洁地初始化对象中的方法。
