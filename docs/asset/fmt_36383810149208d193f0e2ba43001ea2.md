## 7.21.7.10 ungetc 函数

### 语法概要

```
#include <stdio.h>
int ungetc(int c, FILE *stream);
```

## 描述

`ungetc` 函数将由 `c` 指定字符（转换为 `unsigned char`）推回到 `stream` 指向的输入流中。推回的字符将在随后的读取操作中按推入顺序的逆序返回。如果中间成功调用了针对（由 `stream` 指向）的文件定位函数（`fseek`、`fsetpos` 或 `rewind`），将丢弃该流任何已推回的字符。流对应的外部存储保持不变。

保证至少有一个字符可以被推回。如果在同一个流上多次调用 `ungetc` 函数而没有对该流进行读取或文件定位操作，则操作可能会失败。

如果 `c` 的值等于宏 `EOF`，则操作失败且输入流保持不变。

成功调用 `ungetc` 函数会清除流的末尾文件指示位。在读取或丢弃所有推回的字符后，该流的文件位置指示位的值应与推回字符之前的值相同。对于文本流，在成功调用 `ungetc` 函数后，其文件位置指示位的值在所有推回的字符被读取或丢弃之前是未指定的。对于二进制流，其文件位置指示位会在每次成功调用 `ungetc` 函数时增加 1；如果在调用之前值为 0，则在调用后将是不定的。

### 返回值

`ungetc` 函数返回转换后推回的字符，如果操作失败则返回 `EOF`。
