# 引言

快快！哪种编程语言能让你在每个流行的平台上都快速运行应用程序？放弃了吗？是的，是 Python。Python 的奇妙之处在于，你真的可以在一个平台上编写应用程序，并在你需要的支持的所有其他平台上使用它。与其他承诺提供跨平台无关性的编程语言不同，Python 真正让这种独立性成为了可能。在这种情况下，承诺就如你获得的结果一样可靠。

Python 强调代码的可读性和简洁的语法，这让你可以使用比其他编程语言更少的代码来编写应用程序。此外，由于 Python 的工作方式，你会发现它被用于各种充斥着非程序员的领域。有些人将 Python 视为一种脚本语言，但它的意义远不止于此。第 18 章将让你略微了解依赖 Python 来完成任务的职业。

## 理解你为什么想与计算机对话

起初与机器说话似乎很奇怪，但这是必要的，因为计算机无法读取你的心意。即使计算机能读取你的心意，它仍然在与你进行通信。如果没有机器和你之间的信息交换，任何事情都不会发生。诸如下活动：
- 读取你的邮件
- 编写关于你假期的文章
- 在世界上寻找事物

这些都是发生在计算机与你之间的通信。计算机进一步与其他机器或人通信，以处理你提出的请求，这仅仅扩展了基本概念：通信是产生任何结果所必需。

在大多数情况下，通信对你来说几乎是不可见的，除非你真的去思考。例如，当你访问在线聊天室时，你可能认为你正在与他人交流。然而，你是在与你的计算机通信，你的计算机通过聊天室无论它组成与对方的计算机通信，而对方的计算机正在与那个人通信。图 1-1 为你展示了实际发生了什么。

## 应用程序是一种通信形式

计算机通信通过使用应用程序来实现。你使用一个应用程序回复电子邮件，使用另一个购买商品，再使用一个创建演示。应用程序有时被称为 app 提供了以计算机可以理解的方式表达人类思想的，并定义了以特定方式塑造通信数据所需的工具。用于演示内容的数据与为母亲购买礼物的数据不同。你查看、使用和理解数据的方式对于每个任务都是不同的，因此你使用不同的应用程序以计算机和你都能理解的方式与数据交互。

你可以针对今天想象的任何通用需求获取应用程序。事实上，你可能已经拥有了你尚未想过用途的应用程序。多年来，程序员一直在忙于创建数百万种类型的应用程序，因此你可能很难理解通过创建某种新的通过应用程序与计算机对话的方法可以实现什么。答案在于思考数据以及你想要如何与之交互。数据可能由于不够常见而无法引起程序员的注意，或者你可能需要目前没有任何应用程序支持的数据格式，因此你没有程序可以告诉计算机创建一个自定义应用程序来完成它。

## 思考你日常使用的程序

程序简单来说就是执行任务时遵循的一系列步骤。例如，在制作吐司时，你可能会使用如下程序：
1. 从冰箱中取出面包和黄油。
2. 打开面包袋取出两片吐司。
3. 移下烤面包机的盖子。
- 4. 将每片面包放入其各自的槽位中。
- 5. 按下烤面包机拨杆开始烤面包。
- 6. 等待烘烤过程完成。
- 7. 从烤面包机中取出吐司。
- 8. 将吐司放在盘子中。
- 9. 给吐司涂抹黄油。

你的步骤可能与此处展示的不一样，但你不太会在把面包放入烤面包机之前就给它涂黄油。当然，在这样做之前，你实际上必须将面包从包装袋中取出把面包连同包装纸一起放入烤面包机可能会产生不理想的结果。大多数人从未真正思考过制作吐司的过程。尽管你没有想过，但你也会使用像这样的步骤。

![](img/ec69aa1535cd82c735ee14abfc05048f_25_0.png)

计算机在没有程序的情况下无法执行任务。你必须告诉计算机执行哪些步骤、执行步骤的顺序以及任何可能导致失败的异常情况。所有这些信息以及更多都出现在应用程序中。简而言之，应用程序是一个编写得简单的程序，你用它来告诉计算机做什么、什么时候做以及如何做。由于你一生都在使用程序，你真正需要做的只是将已经拥有的知识应用于计算机对特定任务需要知道的内容上。
