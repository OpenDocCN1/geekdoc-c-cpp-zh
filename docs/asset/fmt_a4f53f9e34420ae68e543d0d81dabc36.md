## CMSIS Pack 结构

CMSIS 软件包仅仅是你想要添加到运行时管理器（Run Time Environment Manager）的软件文件集合，以及支持文件，如调试器支持、文档、许可证信息、示例和模板。要创建一个软件组件，你只需要生成一个额外的文件。这是一个 XML 格式的“包描述文件”（`<pack>`），它描述了包的内容以及定义任何额外支持的规则。一旦创建了包描述文件，就可以使用简单的实用程序来检查语法并生成包。
