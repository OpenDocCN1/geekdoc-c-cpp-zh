## 当参数为真时

如果参数大于零，调用此插件将在更改时进行填充，以保持整体尺寸，因此贴靠在上面的元素都将保持在原位置。如果没有此设置，且高度和 id 发生变化，周围的任何对象都会移动以适应新尺寸。下一行代码调用 `ZoomPad()` 函数来创建填充：
