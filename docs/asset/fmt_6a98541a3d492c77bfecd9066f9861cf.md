## 示例 3

编写一个 C 程序来测试字符串是否为回文。解释程序的工作原理。

### 解决方案

考虑字符串 "LIRIL"。当它被反转时，它读起来仍然是 "LIRIL"。任何这样的字符串被称为回文。其他字符串还有 DAD、MADAM 和 MALAYAM。

```c
/* 检查回文的程序 */
#include <stdio.h>
#include <conio.h>
#include <string.h>
main()
  char st[20],rst[20];
  int i,j;
  clrscr();
  printf("\nEnter the string: ");
  scanf("%s",st);
  /* 反转字符串的循环 */
  i = 0;
  j = strlen(st) - 1;
while(j >= 0) {
  rst[i] = st[j];
  i++;
  j--;
  }
  rst[i] = '\0';
  if (strcmp(st,rst) == 0) {
  printf("\n %s is a palindrome string",st);
  } else {
  printf("\n %s is not a palindrome string",st);
  }
  getch();
```

当执行此程序时，用户必须读取字符串。例如，为了反转此字符串，从最后一个开始复制并写入如下：

| | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|---|
| st | H | E | L | L | O | | | | |
| rst | D | A | B | A | R | E | D | Y |

使用 `strcmp()` 函数比较两个字符串，当原始字符串和反转字符串相同时，它将返回 0。根据此值打印结果。

另一种方法也可以比较字符串的第一个字符与最后一个字符、倒数第二个直到中间，如下所示：

| | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|---|
| | Y | D | E | R | A | B | A |

如果所有字符相同，则字符串为回文。否则循环将终止。如果给定字符串有空格，可以使用循环来读取字符串。

## 示例 4

编写一个 C 程序合并两个字符串。

### 解决方案

考虑两个字符串 "NEW" 和 "DELHI"。通过合并这些字符串，将得到结果字符串 "NEW DELHI"。

```c
/* 合并两个字符串的程序 */
#include <stdio.h>
#include <conio.h>
#include <string.h>
main(){
  char st1[10],st2[10],st[20];
  int i,j;
  clrscr();
  printf("\nEnter first string : ");
  scanf("\n%s",st1);
  printf("\nEnter second string : ");
  scanf("\n%s",st2);
  /* 将第一个字符串复制到结果字符串的循环 */
  i = 0;
  while(st1[i] != '\0') {
    st[j] = st1[i];
    i++;
    j++;
  }
  /* 在合并第二个字符串之前添加空格 */
  st[j] = ' ';
  j++;
  /* 合并第二个字符串的循环 */
  i = 0;
  while(st2[i] != '\0')
  {
    st[j] = st2[i];
    i++;
    j++;
  }
  st[j] = '\0';
  printf("\n Resultant string is %s\n",st);
  getch();
}
```
