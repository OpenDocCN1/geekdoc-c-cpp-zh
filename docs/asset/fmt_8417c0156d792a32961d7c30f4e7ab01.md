## 9.3 文件结束符：EOF

EOF 是一个定义为宏的特殊字符。当文件结束时，`fgetc()` 返回它。由于 `fgetc()` 需要返回一个超出 `char` 范围的值，所以它返回 `int` 而不是 `char`。` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` 好了! 回到现实！我们可以使用这个来读取整个文件。

```c
#include <stdio.h>
int main(void)

    while ((c = fgetc(fp)) != EOF)
        printf("%c\n", c);
    fclose(fp);
}
```

```c
#include <stdio.h>

}
```

## 9.5 写入文本文件

我们将组合一个简单的程序，使用各种输出函数输出文件 output.txt。

```c
#include <stdio.h>
int main(void) {
    FILE *fp;
    int x = 32;
    fp = fopen("output.txt", "w");
    fputc('B', fp);
    fputs("\n", fp); // 新行
    fprintf(fp, "x = %d\n", x);
    fputs("Hello, world!\n", fp); 
    fclose(fp);
}
```

这会产生一个文件 output.txt，其内容如下：

## 9.6 二进制 I/O
