## 实现协变

本章的“深入探讨”部分已经讨论过，协变允许你使用具有派生返回类型的方法作为委托。让我们创建一个名为 `Covariance` 的控制台应用程序（也可在 CD)上提供，它演示了委托如何使用派生的返回类型。Listing 6.12 显示了 `Covariance` 应用程序的 `Program.cs` 文件的代码：

using System;

using System.Collections.Generic;

using System.Linq;

using System.Text;

namespace Covariance

{

    class X

    {

            Console.WriteLine("This is class X");

        }

    {

        public Y CreateY() {

            Console.WriteLine("This is class Y");

        public static void Foo(Create obj) { obj(); }

            Create obj2 = new Create(new Y().CreateY);

            Foo(obj1);

            Foo(obj2);

}

## Creating Events

让我们创建一个名为 `MyEvent` 的控制台应用程序（也在 CD 上提供），其中包含一个简单的事件源对象。此对象包含一个给定的内部成员变量，可以使用成员函数进行设置。每当此成员变量更改时，事件源都会触发事件以通知任何侦听器更改正在进行。如果未定义事件处理程序，事件源也会通知这一点。Listing 6.15 显示了 `MyEvent` 应用程序的 `Program.cs` 文件的代码：

### Listing 6.15: Showing the Code of the Program.cs File

```
using System;

using System.Collections.Generic;

using System.Linq;

using System.Text;

namespace MyEvent

{

public class EventTestClass

{

    // The value to track

    private int nvalue;

    // Allow a handler for the event

    public delegate void ValueChangedEventHandler();

    // This is the event itself

    public event ValueChangedEventHandler Changed;

    // This method is used to fire the event

    protected virtual void OnChanged()

    {

        if (Changed != null)

            Changed();

        else

            Console.WriteLine("Event fired. No handler!");

    }

    public EventTestClass(int nvalue) { SetValue(nvalue); }

    public void SetValue(int nv)

    {

        if (nvalue != nv)

        {

            nvalue = nv;

            // Fire the event

            OnChanged();

        }

    }

}

class Program

{

    static void Main(string[] args)

    {

        EventTestClass etc = new EventTestClass(3);

        etc.SetValue(5);

        etc.SetValue(5);

        etc.SetValue(3);

        Console.Write("\nPress ENTER to quit...");

        Console.ReadLine();

    }

}
```

## Chaining Events

许多编程语言使用事件处理的概念来执行各种操作，例如 `Button` 控件的点击。C# 例如，允许你为每个事件定义事件处理程序。问题是，大多数时候你只能为每个事件定义一个事件处理程序。C# 还允许你为单个事件实现多个事件处理程序，并让事件处理系统通过链式调用来管理所有事件处理程序。让我们创建一个名为 `ChainingEvents` 的控制台应用程序（也在 CD 上提供），它解释了为单个事件拥有多个事件处理程序的概念。Listing 6.16 显示了 `ChainingEvents` 应用程序的 `Program.cs` 文件的代码：

### Listing 6.16: Showing the Code of the Program.cs File

```
using System;

using System.Collections.Generic;

using System.Linq;

using System.Text;

namespace ChainingEvents

{

public class EventTestClass

{

    // The value to track

    private int nvalue;

    // Allow a handler for the event

    public delegate void ValueChangedEventHandler();

    // This is the event itself

    public event ValueChangedEventHandler Changed;

    // This method is used to fire the event

    protected virtual void OnChanged()

    {

        if (Changed != null)

            Changed();

        else

            Console.WriteLine("Event fired. No handler!");

    }

    public EventTestClass(int nvalue)

    {

        SetValue(nvalue);

    }

    public void SetValue(int nV)

    {

        if (nvalue != nV)

        {

            nvalue = nV;

            // Fire the event

            OnChanged();

        }

    }

}

class Program

{

    public void HandleChange1()

    {

        Console.WriteLine("Handler 1 called");

    }

    public void HandleChange2()

    {

        Console.WriteLine("Handler 2 called");

    }

    public Program() { }

    static void Main(string[] args)

    {

        EventTestClass etc = new EventTestClass(3);

        Program app = new Program();

        // Create a handler for this class

        etc.Changed += new EventTestClass.ValueChangedEventHandler(

            app.HandleChange1);

        etc.Changed += new EventTestClass.ValueChangedEventHandler(

            app.HandleChange2);

        etc.SetValue(5);
```
