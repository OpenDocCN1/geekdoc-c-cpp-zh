# 列表与表格属性

本书中讨论的大多数 CSS 属性都可以应用于表格和列表。然而，CSS 还包含了一些专门针对表格和列表的独特属性。表格属性和列表属性的规范从 CSS2 到 CSS3 并没有发生变化，尽管 Internet Explorer 在 IE8 中改进了其对标准的实现。

# 设置表格布局

不同的浏览器使用不同的方法来计算特定表格应如何显示。主要的表格布局（表 8.6）方法受青睐：
