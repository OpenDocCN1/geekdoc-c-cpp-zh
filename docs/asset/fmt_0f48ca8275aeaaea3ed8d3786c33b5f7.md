## 23.2 多字节值

我们之前在很多地方都用过这种版本，但显然并不是每个值都能存储在单个内存字节中。某些东西占用多个字节的内存（假设它们不是 `char`）。你可以通过 `sizeof` 查看它们占用了多少字节。你可以使用标准的 `&` 运算符来确定内存中哪个地址是对象的第一个字节，它返回第一个字节的地址。

这里还有另一个趣知识！如果你遍历任何对象的字节，你就会得到它的内存表示形式。这些在内存中具有相同内存表示的东西是相等的。

如果你想遍历对象的内存表示，你应该使用 `unsigned char` 指针来操作。

让我们来实现这个版本的内存(5)，正好执行这个操作：

```c
void *memcopy(void *dest, void *src, size_t n)
{
    // 为 src 和 dest 创建本地变量，但类型为 unsigned char
    unsigned char *s = src;
    unsigned char *d = dest;

    while (n-- > 0) // 对于给定的字节数
        *d++ = *s++; // 将源字节拷贝到目的地

    // 大多数拷贝函数会返回目的地的指针，以便
    // 调用者使用

    return dest;
}
```

（这里面有一些关于后增和后减的极佳示例供你学习。）

需要注意的是，上面的这个版本效率可能比你系统自带的要低。

## 23.3 NULL 指针和 0

这些东西可以互换使用：

## 23.7 函数指针

函数只是内存中机器指令的集合，因此没有理由不能获取指向函数第一条指令的指针。

然后调用它。

而且它非常想知道所有的细节。

比如“这是一个接受两个参数并返回 `void` 的函数指针”。

你如何编写它以便声明变量呢？

```c
// 声明 p 为一个指向函数的指针。
// 该函数返回一个 float，并接受两个 int 作为参数。

float (*p)(int a, int b);
```
