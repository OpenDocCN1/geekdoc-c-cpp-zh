## 修改和取消标题与脚注

`TITLE` 和 `FOOTNOTE` 语句是全局语句。在您修改或取消它们之前，它们会在整个会话中一直有效。通过在 SAS 语句中指定行号来修改或取消标题。

```sas
title 1 '新标题';
title 2; /* 取消标题2 */
```

或者使用：

```sas
title '标题';
title; /* 取消所有标题 */
```

通过在 SAS 语句中指定行号来修改或取消脚注。

```sas
footnote 1 '新脚注';
footnote 2; /* 取消脚注2 */
```

或者使用：

```sas
footnote '脚注';
footnote; /* 取消所有脚注 */
```
