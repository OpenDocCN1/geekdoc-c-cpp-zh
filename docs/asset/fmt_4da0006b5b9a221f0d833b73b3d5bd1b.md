
# 第 17 章 为图表添加嵌入图

在第 365 页的“使用宏变量创建模板”中，我们创建了模板 `GIPSET`，该模板声明了以下宏变量：

| 变量 | 说明 |
| :--- | :--- |
| `TEST` | 标识正态检验 |
| `TESTLABEL` | 提供与所应用正态检验相关的标签 |
| `STAT` | 提供由应用正态检验计算的正态性统计量 |
| `PTYPE` and `PVALUE` | 提供所应用正态检验的概率（类型和值） |
| `NOBS`, `MEAN`, and `STD` | 提供分析变量的观测值数量、平均值和偏差 |

为了初始化这些宏变量，我们现在创建一个宏，用于计算这些值并指定一个使用 `GIPSET` 模板的 `SGRENDER` 过程。该宏需要两个参数：一个用于 SAS 数据集名称，第二个用于传递该数据集中列的名称。

以下宏代码使用 `PROC UNIVARIATE` 创建两个数据集。然后通过 `DATA` 步读取这些数据集，创建所需的宏变量，并将值分配给局部作用域内的宏变量。当宏运行 `SGRENDER` 过程时，变量的值会被导入到 `GIPSET` 模板中，以生成一个带有嵌入图的图表，类似于第 365 页图 17.1 所示的图表。如前所述，对分析进行的正态检验将基于该分析变量中的观测值数量。

> **注意**：为了使以下宏更具健壮性，可以将其设计为对参数进行验证。

```sas
%macro histogram(dsn,var);
/* 计算正态性检验 */
ods output TestsForNormality=norm;
proc univariate data=&dsn normaltest;
    var &var;
    output out=stats n=n mean=mean std=std;
run;

%local nobs mean std testlabel stat ptype pvalue;

data _null_;
    set stats(keep=n mean std);
    call symputx("nobs", n);
    call symput("mean", strip(put(mean, 12.3)));
    call symput("std", strip(put(std, 12.4)));
    if n > 2000 then /* 使用 Shapiro-Wilk */
        set norm(where=(TestLab="D"));
    else /* 使用 Kolmogorov-Smirnov */
        set norm(where=(TestLab="W"));
    call symput("testlabel", trim(testlab));
    call symput("test", test);
    call symput("stat", strip(put(stat, best.8)));
    call symput("ptype", strip(put(ptype, p6.4)));
    call symput("pvalue", strip(put(pvalue, p6.4)));
run;

proc sgrender data=&dsn template=ginset;
run;
%mend;
```

- `%MACRO` 语句声明了一个名为 `HISTOGRAM` 的宏，它接受两个参数：`DSN`（数据集名称）和 `VAR`（列名）。
- `ODS OUTPUT` 生成一个名为 `NORM` 的 SAS 数据集，由 `UNIVARIATE` 过程（下一语句）生成。有关 `ODS OUTPUT` 语句的更多信息，请参阅《SAS 输出系统：用户指南》。
- 从 `DSN` 参数推导出输入数据集名称，并从 `VAR` 参数推导出分析变量名，`UNIVARIATE` 过程计算分析变量的观测值数量、平均值和标准差。它将这些值写入名为 `STATS` 的输出数据集，并将值存储在变量 `N`、`MEAN` 和 `STD` 中。
- `%LOCAL` 语句创建一组局部变量并将其添加到局部符号表中。
- 数据步读取 `N`、`MEAN` 和 `STD`。
- `call symputx` 赋值观测值数量。
- `call symput` 赋值平均值。
- 接下来 `call symput("std", strip(put(std, 12.4)))`。
- 如果 `n > 2000`（使用 Shapiro-Wilk），则执行 `set norm(where=(TestLab="D"))`，否则使用 Kolmogorov-Smirnov。
- `call symput` 赋值测试、类型和 P 值。
- `call symput("stat", strip(put(stat, best.8)))` 和 `call symput("pvalue", strip(put(pvalue, p6.4)))`。
- 运行 `proc sgrender data=&dsn template=ginset;`。

## 在分类面板中添加嵌入图

本节需要熟悉使用图表模板语言 `GTL` 编写分类面板。如果您不熟悉分类面板，请参阅第 257 页的第 11 章“使用分类面板”。

### 关于分类面板中的嵌入图

`DATALATTICE` 和 `DATAPANEL` 布局提供了 `INSET=` 和 `INSETOPTS=` 用于在分类面板中显示嵌入图。`INSETOPTS=` 支持与第 369 页“向图表添加嵌入图”中 `SCATTERPLOTMATRIX` 语句文档相同的外观和功能。与 `SCATTERPLOTMATRIX` 语句不同，`DATALATTICE` 和 `DATAPANEL` 布局不提供预定义信息。因此，对于 `INSET` 选项，您必须在图表渲染之前创建用于在嵌入图中显示的信息的列，并合并输入数据。您可以使用匹配合并（`BY` 语句）或一对一映射（`BY` 语句）来合并嵌入数据和分析数据。数据合并的方式被称为分类面板的数据方案。`DATASCHEME=` 选项用于指定合并嵌入数据和分析数据的数据方案。

在合并嵌入数据和分析数据后，在 `LAYOUT DATAPANEL` 或 `LAYOUT DATALATTICE` 语句中执行以下操作：

- 使用 `INSET=` 指定包含嵌入所需信息或多个列的名称。
- 使用 `DATASCHEME=` 选项指定用于合并嵌入数据和分析数据的数据方案为 `LIST`（一对一合并）或 `MATCH`（匹配合并）。

> **注意**：匹配合并数据方案是合并嵌入数据和分析数据的首选数据方案。

以下章节描述了如何使用匹配合并和一对一合并的数据来添加嵌入图。

### 使用匹配合并数据方案添加嵌入图

匹配合并数据方案根据 `BY` 语句中列出的变量合并嵌入数据和分析数据。默认情况下，`LAYOUT DATAPANEL` 和 `LAYOUT DATALATTICE` 语句假设使用一对一合并数据。要指定匹配合并数据方案，您必须在 `LAYOUT DATAPANEL` 或 `LAYOUT DATALATTICE` 语句中包含 `DATASCHEME=MATCH` 选项。此示例展示了如何使用匹配合并数据方案合并嵌入和分析数据，以及如何将嵌入图添加到分类面板中。此示例使用 `Sashelp.Cars` 数据集作为源。

以下是示例中执行的高级步骤：

1. 从 `Sashelp.Cars` 数据集生成嵌入图并将其写入 `Mileage` 数据集。
2. 按气缸（`Cylinders`）、来源（`Origin`）和类型（`Type`）对 `Sashelp.Cars` 进行排序，然后将排序后的数据写入 `Cars` 数据集。
3. 使用匹配合并根据气缸和来源合并 `Cars` 和 `Mileage` 数据集，然后将合并的数据写入 `AvgMileage` 数据集。
4. 创建分类面板的模板。
5. 使用 `AvgMileage` 数据生成图表。

以下是从 `Sashelp.Cars` 数据集生成嵌入数据并写入 `Mileage` 数据集的 SAS 代码。

```sas
/* 生成嵌入信息并将其写入数据集 */
proc summary data=sashelp.cars completetypes;
    where type in ('Sedan' 'Truck' 'SUV')
      and cylinders in (4 6 8);
    class cylinders origin;
    var mpg_city;
    output out=mileage mean=Mean n=N / nonhit;
    types cylinders*origin;
run;
```

`SUMMARY` 过程计算了与 `TYPES` 语句交互的每个分类交互的观测值数量和 `MPG_City` 的平均值。`Cylinders*Origin` 是每个单元格条形图所需的类型。`COMPLETETYPES` 选项在分类交互频率为零时创建汇总观测。此外，代码在嵌入数据中创建了子集，以限制每个条形图中的条形数量最多为三个，并减少分类面板中的单元格数量。`Origin` 有三个值（亚洲、欧洲、美国），气缸有三个值（4、6 和 8）。

以下是按气缸、来源和类型对 `Sashelp.Cars` 中的数据进行排序并将排序后的数据写入 `Cars` 数据集的 SAS 代码。这种数据顺序对于下一步完成的匹配合并是必需的。

```sas
/* 按用于嵌入信息的变量对分析数据进行排序：CYLINDERS, ORIGIN, and TYPE。 */
proc sort data=sashelp.cars out=cars;
    by cylinders origin type;
run;
```

以下是按气缸和来源对 `Cars` 和 `Mileage` 数据集执行匹配合并，并将合并的数据写入 `AvgMileage` 数据集的 SAS 代码。

```sas
/* 按气缸和来源合并分析数据和嵌入数据。 */
data avgmileage;
    merge cars mileage;
    by cylinders origin;
    format mpg_city 4.;
run;
```

### 使用一对一合并数据方案添加嵌入图

一对一数据方案根据数据集中观测值出现的位置来合并嵌入数据和分析数据。它不使用 `BY` 语句。默认情况下，`LAYOUT DATAPANEL` 和 `LAYOUT DATALATTICE` 语句假设使用一对一方法来合并嵌入数据和分析数据。在这种情况下，每个单元格的嵌入图按照数据顺序进行填充。也就是说，第一个观测值的嵌入数据用于单元格 1，第二个观测值的嵌入数据用于单元格 2，依此类推。此过程要求嵌入数据必须位于数据集的开头，并与分类面板中的单元格正确对应。由于这一要求，一对一合并数据方案可能比匹配合并方案更复杂。

> **注意**：匹配合并数据方案是合并嵌入数据和分析数据的首选方法。请参见上文“使用匹配合并数据方案添加嵌入图”。

本示例向您展示如何使用一对一合并数据方案来合并嵌入和分析数据，以及如何将嵌入图添加到分类面板中。使用 `Sashelp.Cars` 数据集作为数据源。

### 在分类面板中添加嵌入图（一对一合并步骤）

以下是示例中执行的高级步骤：

1. 汇总 `Sashelp.Cars` 中的数据，用于单元嵌入图（气缸*产地）和单元柱状图（气缸*产地*类型）。将输出写入 `Mileage` 数据集。
2. 从 `Mileage` 数据集中提取单元汇总数据（`_TYPE_`），重命名列，并将数据写入 `Overall` 数据集。

> **注意**：列必须保持顺序，以防止在下一步合并数据时覆盖任何值。

3. 使用一对一合并将 `Mileage` 和 `Overall` 数据集合并到 `AvgMileage` 数据集。
4. 创建分类面板的模板。
5. 使用您的 `AvgMileage` 数据生成图表。

以下是汇总 `Sashelp.Cars` 数据用于单元和柱状图的 SAS 代码：
