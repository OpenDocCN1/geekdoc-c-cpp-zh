## ASP.NET Web Page Syntax

ASP.NET Web 页面定义了可用于声明性创建 ASP.NET Web 页面或用户控件的标记语法。ASP.NET Web 页面语法包括以下组件：

- Web page directives
- Form elements
- Web server controls

### Web Page Directives

ASP.NET 页面指令是用于指定可选设置的指令，例如注册自定义控件和页面语言。这些设置用于描述 ASP.NET Web 表单页面（`.aspx`）或用户控件（`.ascx`）页面如何由 .NET Framework 处理。

页面指令可以放置在 `.aspx` 或 `.ascx` 文件的任何位置；尽管标准做法是在文件顶部包含它们。

使用页面指令的语法如下：

```
<%@ directive {attribute=value}* %>
```

ASP.NET 将任何不包含显式指令名称的指令块（`<%@ %>`）视为 `@ Page` 指令（对于页面）或 `@ Control` 指令（对于用户控件）。ASP.NET 4.0 页面包含以下指令：

- `@ Page`
- `@ Control`
- `@ Import`
- `@ Implements`
- `@ Register`
- `@ Assembly`
- `@ Master`
- `@ PreviousPageType`
- `@ MasterType`
- `@ OutputCache`
- `@ Reference`

### The @ Page Directive

`@ Page` 指令定义了由 ASP.NET 页面解析器和编译器使用的页面特定属性。它只能包含在 `.aspx` 文件中。

`@ Page` 指令的语法如下：

```
<%@ Page attribute="value" [attribute="value"...] %>
```

`@ Page` 指令是 ASP.NET 页面中最重要的指令。在 ASP.NET 4.0 中，包含六个新的 `@ Page` 指令属性，如表 13.8 所示：

**Table 13.8: New Attributes Included in ASP.NET 4.0 in the @ Page Directive**

| Attribute | Description |
|-----------|-------------|
| ClientIDMode | Sets the method used by the ASP.NET page while generating ClientID values for the server controls on that page. The values that can be assigned to this attribute are: AutoID, Predictable, Static, and Inherit. The AutoID value is the default value for this attribute. |
| ClientTarget | Specifies the browser capabilities that the ASP.NET engine should target while rendering the page. |
| MetaDescription | Specifies the page description in the meta tag for the purpose of Search Engine Optimization (SEO). |
| MetaKeywords | Specifies a page keyword in the meta tag for the purpose of SEO. |
| TargetSchema | Specifies the name of the schema that validates the content of the page. |
| ViewStateMode | Specifies whether the ViewState property of the page is the default mode or not. |

> **NOTE**
> 在 `@ Page` 指令中引入的上述六个新属性中，`MetaDescription` 和 `MetaKeywords` 属性主要是为了改善 ASP.NET 站点对 SEO 的优化而包含的。这是因为大量用户通过搜索引擎访问站点。

### The @ Control Directive

`@ Control` 指令定义了由 ASP.NET 页面解析器和编译器使用的控件特定属性。它只能在 `.ascx` 文件（用户控件）中使用。

The syntax for the `@ Control` directive is as follows:

```
<%@ Control attribute="value" [attribute="value"...] %>
```

## The @ Import Directive

The `@ Import` directive explicitly imports a namespace into ASP.NET application files, such as a Web page, user control, master page, or Global.asax file. It also makes all classes and interfaces of the imported namespace available to application files.

The syntax for the `@ Import` directive is as follows:

```
<%@ Import namespace="value" %>
```

## The @ Implements Directive

The `@ Implements` directive indicates that the Web page, user control, or master page must implement the specified .NET Framework interface.

The syntax for the `@ Implements` directive is as follows:

```
<%@ Implements interface="ValidInterfaceName" %>
```

## The @ Register Directive

The `@ Register` directive creates an association between tag prefix and custom controls. This association helps you to refer to custom controls in ASP.NET Web pages and user controls.

The syntax for the `@ Register` directive is as follows:

```
<%@ Register tagprefix="tagprefix"
namespace="namespace"
assembly="assembly" %>
<%@ Register tagprefix="tagprefix"
namespace="namespace" %>
<%@ Register tagprefix="tagprefix"
tagname="tagname"
src="pathname" %>
```

## The @ Assembly Directive

The `@ Assembly` directive links an assembly to the ASP.NET application files, such as a Web page, user control, master page, or a Global.asax file during compilation. It also helps in making all the classes and interfaces of an assembly available for use to the application.

The syntax for the `@ Assembly` directive is as follows:

```
<%@ Assembly Name="assemblyname" %>
<%@ Assembly Src="pathname" %>
```

## The @ Master Directive

The `@ Master` directive defines attributes of a master page (`.master` file), which are used by the ASP.NET page parser and compiler.

The syntax for the `@ Master` directive is as follows:

```
<%@ Master attribute="value" [attribute="value"...] %>
```
