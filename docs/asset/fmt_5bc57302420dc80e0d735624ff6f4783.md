## 练习 2：为 Matrix 类型实现运算符

### 场景

在本次练习中，你将为 `Matrix` 类添加加法、减法、乘法运算符。你在此练习中添加的运算符仅在两个操作数为大小相同的矩阵时才会运行。你将确保操作数的大小相同——如果它们不同，你将抛出一个 `MatrixNotCompatibleException` 异常。

本次练习的主要任务如下：

1. 打开项目。
2. 为 `Matrix` 类添加加法运算符。
3. 为 `Matrix` 类添加减法运算符。
4. 为 `Matrix` 类添加乘法运算符。

### 任务 1：打开启动项目

> **注意**：仅在你未能完成练习 1 时才执行此任务。如果你已成功定义了 `Matrix` 和 `MatrixNotCompatibleException` 类型，请继续任务 2：为 `Matrix` 类添加加法运算符。

- 打开位于 `E:\LabFiles\Lab 10\C\Ex2\Starter` 文件夹下的 Module 10 解决方案。

### 任务 2：为 Matrix 类添加加法运算符

1. 在 Visual Studio 中，查看任务列表。
2. 打开 `Matrix.cs` 文件。
3. 将注释 `TODO Add an addition operator to the Matrix class` 替换为重载 `+` 运算符，该重载接收两个 `Matrix` 对象作为参数并返回 `Matrix` 类的实例。
4. 在 `+` 运算符中添加代码以检查矩阵的大小是否相同（`Matrix` 只支持方阵，因此你只需要检查矩阵的一个维度）。如果它们大小不同，请使用矩阵和消息 "Matrices not the same size" 作为参数，抛出一个新的 `MatrixNotCompatibleException` 异常。
5. 如果两个矩阵的大小相同，添加代码创建一个名为 `newMatrix` 的 `Matrix` 类新实例，并将其初始化为与源矩阵大小相同的矩阵。
6. 添加代码遍历第一个矩阵中的每一个项，计算该项与第二个矩阵中对应项之和，并将结果存储在 `newMatrix` 矩阵的对应位置。

> **提示**：使用 `for` 循环遍历第一个矩阵的行，并使用嵌套的 `for` 循环遍历每行的列。

7. 在计算 `newMatrix` 对象数值值的代码之后，添加一条语句将 `newMatrix` 对象作为 `+` 运算符的结果返回。
8. 生成解决方案并纠正任何错误。

### 任务 2：测试 Matrix.cs

1. 在 Visual Studio 中，查看任务列表。
2. 打开 `Program.cs` 文件。
3. 检查 `Main` 方法。该方法创建了两个 3×3 方阵 `matrix1` 和 `matrix2` 并填充了示例数据。然后使用 `ToString` 方法将其内容显示到控制台。
