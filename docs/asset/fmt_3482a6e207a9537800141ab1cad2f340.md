## do

`while` 语句有另一种变体，称为 `do` 循环，其形式如下：

```csharp
do
{
  statement;
  ...
}
while (condition);
```

其意义是先执行块中的语句，然后测试条件。如果为，重复循环，一直持续到条件变为假。与 `while` 语句相比的区别是 `do` 至少会执行一次块，因为条件是在块执行之后才测试的。`do` 循环不像其他循环那样。


其中除以 10（整数除法）“丢弃”了最后一位。当各位之和大于 9（即大于1）时，外部循环循环。
