## 使用只读属性检索值

只读属性是具有 `get` 访问器但不具有 `set` 访问器的属性。这意味着您可以使用只读属性检索变量的值，但不能为变量分配值。要了解如何使用只读属性检索值，请先创建一个新的控制台应用程序，命名为 `MyReadonlyProperty`（也在 CD 上提供），然后用清单 4.21 所示的代码替换应用程序的 `Program.cs` 文件的默认代码：

清单 4.21：显示 `MyReadonlyProperty` 应用程序的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyReadonlyProperty
{
    public class PropertyHolder
    {
        private int someProperty = 0;
        public PropertyHolder(int propval)
        {
            someProperty = propval;
        }
        public int SomeProperty
        {
            get
            {
                return someProperty;
            }
        }
    }
    public class PropertyTester
    {
        public static void Main(string[] args)
        {
            PropertyHolder propHold = new PropertyHolder(5);
            Console.WriteLine("Property Value: " + propHold.SomeProperty);
            Console.Write("\nPress ENTER to Quit..");
            Console.ReadLine();
        }
    }
}
```

清单 4.21 显示了如何实现只读属性。`PropertyHolder` 类具有 `SomeProperty` 属性，该属性仅实现 `get` 访问器而省略了 `set` 访问器。`PropertyHolder` 类有一个构造函数，该构造函数接受 `int` 参数。`PropertyTester` 类的 `Main()` 方法创建了一个名为 `propHold` 的新的 `PropertyHolder` 对象。`propHold` 对象使用 `PropertyHolder` 类的构造函数，该构造函数接受类型为 `int` 的参数，其值设置为 5。您无法设置 `SomeProperty` 属性的值，因为它是只读的。

## 创建静态属性

您可以使用 `static` 关键字后跟属性名称来声明静态属性。静态属性只能访问类的静态成员。要了解如何创建静态属性，请先创建一个新的控制台应用程序，命名为 `MyStaticProperty`（也在 CD 上提供），然后用清单 4.22 所示的代码替换应用程序的 `Program.cs` 文件的默认代码：

### 清单 4.22：显示 `MyStaticProperty` 应用程序的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyStaticProperty
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Number of objects:{0}", CounterClass.NumberOfObjects);
            CounterClass object1 = new CounterClass();
            Console.WriteLine("Number of objects:{0}", CounterClass.NumberOfObjects);
            CounterClass object2 = new CounterClass();
            Console.WriteLine("Number of objects:{0}", CounterClass.NumberOfObjects);
            CounterClass object3 = new CounterClass();
            Console.WriteLine("Number of objects:{0}", CounterClass.NumberOfObjects);
            Console.Write("\nPress ENTER to Quit..");
            Console.ReadLine();
        }
    }
    public class CounterClass
    {
        private static int number = 0;
        public CounterClass()
        {
            number++;
        }
        public static int NumberOfObjects
        {
            get {
                return number;
            }
            set {
                number = value;
            }
        }
    }
}
```

在清单 4.22 中，声明了一个静态属性 `NumberOfObjects`。它只能访问 `CounterClass` 类的静态变量 `number`。
