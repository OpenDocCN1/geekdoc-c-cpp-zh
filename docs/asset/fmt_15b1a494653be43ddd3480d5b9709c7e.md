`echo` 输出在浏览器窗口中的样式

一旦加载 PHP 文档，`echo` 函数基本上就会向程序/浏览器发送 "Welcome world!" 字符串。`echo` 实际上是一个 PHP 语言结构。基本上，这意味着它有能力在不将其参数放在括号内的情况下工作。需要注意的是，在大多数情况下，真正的函数需要括号。

你可以使用 PHP 的众多内置函数之一，也可以定义自己的函数。我们将更多地讨论识别自己的函数。

## 7.1 调用函数

PHP 中有许多内置函数。调用函数最常见的方法是使用其名称后跟括号。如果函数需要参数，这些参数将位于括号内。例如：

```php
function greet($name) {
  echo "Hello, " . $name . "!";
}
greet("Alice"); // 输出: Alice!
```

如果函数使用 `return` 语句返回值，该值可以赋值给变量：

```php
function add($a, $b) {
  return $a + $b;
}
$result = add(5, 3); // $result 现在为 8
```

函数也可以通过引用调用，允许函数修改传递的变量。这是通过使用符号 `&` 实现。

```php
function addToTen(&$value) {
  $value += 10;
}
$number = 5;
addToTen($number); // $number 现在为 15
```

## 7.2 定义函数

要定义函数，使用 `function` 关键字后跟函数名称、括号和代码块。函数内的代码在大括号内。

```php
function myFunction() {
  // 要执行的代码
}
```

函数也可以接收参数，这些是在括号内定义的变量。

```php
function myFunction($param1, $param2) {
  // 使用 $param1 和 $param2
}
```

你可以为参数提供默认值。调用函数时如果没有提供参数，则使用默认值。

```php
function greet($name = "Guest") {
  echo "Hello, $name!";
}
greet(); // 输出: Hello, Guest!
greet("Alice"); // 输出: Hello, Alice!
```

函数也可以使用 `return` 语句返回值。遇到 `return` 语句时，函数停止执行并返回指定的值。

```php
function multiply($a, $b) {
  return $a * $b;
}
$product = multiply(4, 5); // $product 现在为 20
```

## 7.3 作用域

PHP 中的变量具有局部作用域。在函数内部定义的变量是该函数的局部的，无法从外部访问。

```php
$x = 5; // 全局变量
function myFunction() {
  $x = 10; // 局部变量
  echo $x; // 输出 10
}
myFunction();
echo $x; // 输出 5
```

要在函数内部访问全局变量，必须使用 `global` 关键字。

```php
$x = 5;
function myFunction() {
  global $x;
  $x = 10;
  echo $x; // 输出 10
}
myFunction();
```

或者，你可以使用 `$GLOBALS` 数组来访问全局变量。

```php
$x = 5;
function myFunction() {
  echo $GLOBALS['x']; // 输出 5
}
myFunction();
```

这显示为：

Hello from function-land!（来自函数世界的你好！）

`hi` 函数不接受任何参数，因此你不需要在括号之间列出任何内容。既然你已经定义了一个基础函数，我们加入几个参数如何？

### 参数

在调用函数时，参数提供了一种向函数传递数据的有效方法，而无需过度担心变量的作用域。在 PHP 中，你不需要描述参数持有什么类型的信息——只需要指定参数的名称即可。

接收参数的函数示例是 `strtolower`，它能将你的字符串“Hi world!”转换为小写。它接收一个类型为字符串的参数，该数据类型在第 3 章中描述。此外，还有另一个名为 `strtoupper` 的函数，它能将你字符串中的所有字符转换为大写字母，如示例 7.4 所示。

#### 示例 7.4. 在接收参数的另一个函数内部利用字符串大小写函数

```php
<?php
// 字符串大写函数 underline($str)
{
    // 首先，将所有字符转换为小写
    $str = strtolower($str);
    // 第二，将第一个字符转换为大写
    $str[0] = strtoupper($str[0]);$str[0] 获取字符串中的第一个字符
    echo $str;
}
capitalize("hEllo WoRld!");
?>
```

案例 7.4 产生如下结果：

# Hi world!

在函数内部 `echo` 的 `$str` 值，是因为你没有指定任何从函数获取该值的方法。如上所述，`$str[0]` 获取字符串中的第一个字符。

PHP 不需要你描述一个函数是否真的返回一个值，或者它返回什么类型的数据。

参数同样可以包含得默认值。有了默认值，你实际上不需要为函数传递任何信息，它就会设置默认值。我们将你的大写函数改为一个默认值，允许你将每个单词的首字母大写，或者仅仅将整个句子大写如何？我们将在示例 7.5 中这样做。

#### 图 7.5. 创建一个带有默认参数的大写函数

```php
<?php
// 字符串或仅每个单词首字母大写函数 underline($str,$each=TRUE) {
    // 首先，将所有字符转换为小写或非第一个单词的字母可能会保持大写
    $str = strtolower($str);
    if ($each === TRUE) {
        $str = ucwords ($str);
    } else {
        $str = strtoupper($str);
    }
    echo("$str <br>");
}
capitalize("hEllo WoRld!");
echo("Now do the same with the echo parameter set to FALSE.<br>");
capitalize("hEllo WoRld",FALSE);
?>
```

其结果如下所示：

Hello World!

Now do the same with the echo parameter set to FALSE

HELLO WORLD!

### 参数引用

当你向函数传递一个查询时，函数内部会创建一个本地副本来存储该值。对该值进行的任何更改只会影响函数中的变量本地副本，而不影响参数的源。你可以通过定义引用参数来定义修改源变量的参数。

引用参数在函数定义的参数之前直接放置一个安培符号 `&` 来定义引用。我们应该修改示例 7.5 中的 `capitalize` 函数，使其接收一个用于大写字符串的引用变量，如示例 7.6 所示。

#### 图 7.6 修改 capitalize ( ) 以接收引用参数

```php
<?php
function capitalize ( &$str, $each=TRUE ) {
    // 首先，将所有字符转换为小写
    $str = strtolower($str);
    if ($each === TRUE) {
        $str = ucwords($str);
    } else {
        $str[0] = strtoupper($str[0]);
    }
}
$str = "Hi WoRld!";
underwrite( $str );
echo $str;
?>
```

示例 7.8 产生以下结果：

Hello World!

由于 `capitalize` 将 `$str` 参数定义为引用参数，因此在执行时，到源变量的连接发送到了函数。函数基本上访问并修改了源变量。如果该变量没有声明为引用，则会显示“hEllo World!”的初始估计。

## 包含和引入 PHP 文件

为了让你的代码更易读，你可以将函数放在不同的文件中。

从互联网下载的许多 PHP 扩展都包含了现在已记录的函数，你基本上将它们包含在你的 PHP 程序中。另一方面，PHP 提供了四个函数，允许你从不同的文件中嵌入代码：

- `include`
- `require`
- `include_once`
- `require_once`

每一个 `include` 和 `require` 函数都接受一个本地文档作为输入。无论处理无法检索资源的方式如何，`require` 和 `include` 函数的功能都非常相似。例如，`include` 和 `include_once` 在资源不可用时会给出提示并尝试继续执行程序。`require` 和 `require_once` 函数在无法恢复资源时会停止特定页面的准备。现在我们将更具体地介绍这些函数。

### include 语句

`include` 语句允许你将其他 PHP 脚本包含并合并到自己的脚本中。你可以将其视为获取包含的文件并将其嵌入你的 PHP 文档中。案例 7.7 被命名为 `add.php`。

<?php

## 面向对象编程

面向对象编程与我们讨论函数的目标相同，目的是使代码复用。它使用类将函数和变量组合在一起作为一个对象。你可以将对象看作可以工作的“黑盒”。

尽管如此，它们仍然使用函数；不过，在类中定义的这些函数被称为**方法（methods）**。类作为创建对象的蓝图。当创建一个类的对象时，它被称为该类的**实例（instance）**。类中定义的任何变量被称为**属性（properties）**。构造函数可以被来存储信息。

如果你对面向对象编程的概念很陌生，不要担心立即理解它。我们将在第 8 章中处理类，所以你只需要知道如何调用方法。

### 创建类

类通常存储在独立文件中以便复用。让我们创建一个名为 `Cat` 的对象，它拥有三个方法：`meow`、`eat` 和 `purr`。类定义了其名称。类名遵循与变量相同的命名原则。构成类的代码位于大括号之间。创建一个没有任何方法的类，示例 7.10 所示。

#### 示例 7.10. 从类创建对象

```php
<?php
class Cat {
}
$fluffy = new Cat();
echo "Fluffy is a new object.";
?>
```

上面的代码显示：

Fluffy is a new object

### 创建实例

示例 7.10 将类标识为一个实例。`new` 关键字告诉 PHP 返回 `Cat` 类的实例。尽管类本身没有执行任何操作，但你可以将其标识为一个对象。类是创建实例蓝图。类规定了每个实例的内容。

### 方法和构造函数

方法是类在内部定义的函数。它们在类的范围内工作，包括其变量。对于类，有一种特殊的方法被称为**构造函数（constructor）**，在创建类的对象时被调用，用于初始化类并设置变量。构造函数通过创建一个与类同名的方法来定义，示例 7.11 所示。

#### 示例 7.11. 创建 Cat 构造函数

```php
<?php
class Cat {
function Cat() {
}
}
?>
```

PHP 5.0 支持使用 `__construct` 来创建构造函数，示例 7.12 所示。如果 PHP 5.0 中的类没有此语法，则使用使用类名作为系统的旧样式。

#### 示例 7.12. 使用 PHP 构造函数

```php
<?php
class Cat {
function __construct() {
}
}
?>
```

构造函数也可以像其他方法一样包含参数。此外，类可以包含自定义方法。对于 `Cat` 类，你可以定义 `meow`、`eat` 和 `purr`，如示例 7.13 所示。

#### 示例 7.13. 为 Cat 定义三个成员函数

```php
<?php
class Cat {
function __construct() {
}
function meow() {
    echo "Meow...";
}
function eat() {
    echo "eats...";
}
function purr() {
    echo "Purr...";
}
}
?>
```

当你声明一个类的实例时，如果存在，构造函数会被可靠地调用。正如你可能知道的，类提供了对象的蓝图。你从类创建一个对象。如果你看到“实例化类（instantiating a class）”这个表达式，它的意思是创建一个对象；因此你可以认为它们是同义的。当创建一个对象时，你正在创建一个类的实例，这意味着你正在实例化类。

`new` 构建通过为该新对象分配内存来实例化类，这意味着它需要一个参数，即对构造函数的调用。构造函数的名称提供了要实例化的类名，构造函数引入了新对象。

`new` 构建返回所创建对象的引用。这个引用通常被赋值给变量。然而，如果引用没有赋值给变量，则在完成 `new` 操作执行的语句之后，该对象将无法访问。示例 7.14 向你展示了有效使用 `new` 的通用方法。

#### 示例 7.14. 创建另一个对象并将其赋值给变量

```php
<?php
class Cat {
function __construct() {
}
function meow() {
    echo "Meow...";
}
function eat() {
    echo "eats...";
}
function purr() {
    echo "Purr...";
}
}
// 将新的 Cat 对象赋值给引用 $myCat
$myCat = new Cat;
?>
```

### 类内部的变量作用域

类可以包含有助于定义结构及其如何使用的变量。类内部的变量使用 `var` 语句声明。`var` 语句声明具有类作用域。类作用域意味着它们在类的任何方法中都可以被识别，并通过特殊构造在类外部引用。示例 7.15 为 `Cat` 添加了 `$age` 变量。

#### 示例 7.15. 为 Cat 添加 $age 变量

```php
<?php
class Cat {
// 猫有多大了
var $age;
// PHP 5 使用:
public $age;
}
?>
```

在类内部引用方法和变量时，你必须使用语法：

`$this->变量名` 或 `方法名`

特殊的变量 `$this` 运算符用于修改 `$age` 的值。在示例 7.16 中， `$this->` 运算符用于修改 `$age` 的值。

#### 示例 7.16. 使用 this-> 获取 $age 变量

```php
<?php
class Cat {
// 猫有多大了
var $age;
function __construct($new_age){
// 将这只猫的年龄设置为新年龄
$this->age = $new_age;
}
// birthday 方法增加年龄变量
function Birthday() {
    $this->age++;
}
}
// 创建一个一岁的猫的新实例
$fluffy = new Cat(1);
echo "Age is $fluffy->age <br/>";
echo "Birthday<br/>";
// 增加 fluffy 的年龄
$fluffy->Birthday();
```
