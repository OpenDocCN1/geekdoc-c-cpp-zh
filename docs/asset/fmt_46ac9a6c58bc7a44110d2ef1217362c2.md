## 继承与接口

接口是继承的基础。接口允许你定义一个类，该类可以包含链接到接口的每个类的声明，但任何类都可以派生它。它为子类与链接到接口的父类之间提供了一种创建“合约”的方法。

接口与类不同，它们只包含类的声明而不包含类的定义。让我们来看一个示例接口。

```c
public interface IAnimal {
    // interface members
    void breathe();
}
```

由于我们在 `Animal` 类中只有一个方法，因此在接口中也只定义了一个动物方法。注意，接口中没有类定义。你只需要定义接口中使用的函数。这同时也定义了可以在子类中使用的函数。这些接口使得扩展你的类变得更容易，因为你可以在类中创建尚未准备好发布的方法，而在这些方法准备好使用之前，不需要有任何子类来派生它们。

标准的命名方案还包括在命名接口时使用 `I` 前缀。当你在代码中同时处理类和接口时，该前缀可以区分类和接口之间的区别。

一旦你创建了接口，就可以在你的类中继承它。让我们来看看 `Animal` 类派生自 `IAnimal` 接口的情况。

```csharp
public interface IAnimal {
    // interface members
    void breathe();
}

abstract class Animal : IAnimal {
    public string eye_color;
    public string number_of_feet;
    public function breathe() {
        return "Animals breathe air.";
    }
}
```

派生主 `Animal` 接口只需要这些操作。现在，你的其他任何类都可以继承该接口或主 `Animal` 类。对于一个包含接口的程序来说，只允许程序员派生自接口是标准做法，但这取决于你设计代码和布局类的方式。

## 静态类

静态类需要被提到，因为它们与普通的 `public` 类有些不同。静态类不需要实例化，当你想要创建一个包含你想在代码中随机使用的函数的类时，这使得它们是有益的。静态类使用 `static` 关键字定义。

你可能需要一个静态类，因为它包含一个在你在编写代码时可能随手就的函数。例如，C# 中的 `ToString` 方法就是一个静态方法。你可以在不实例化类的情况下随时使用它。只需调用 `ToString` 方法，它就会将你的变量转换为字符串。当你想要将数字转换为字符串值时，就会使用此方法。`ToString` 方法无论其包含什么类型的数据，都会将任何变量转换为字符串。

让我们来看静态类。

```csharp
static class Animal : IAnimal
{
    public string eye_color;
    public string number_of_feet;
    public function breathe()
    {
        return "Animals breathe air.";
    }
}
```

注意，我们将上述 `Animal` 类中的 `abstract` 类型改为 `static`。现在，我们不需要实例化这个类了。由于它不再是抽象定义的类，我们现在可以实例化它。通过 `static` 修饰符，我们可以在不实例化的情况下调用类。让我们看看这在 C# 方法中是什么样的。

```csharp
static class Animal : IAnimal
{
    public string eye_color;
    public string number_of_feet;
    public function breathe()
    {
        return "Animals breathe air.";
    }
}

class StaticTester
{
    static void Main(string[]) args
    {
        Console.WriteLine("This is what happens when you call a static class: {0}", Animal.breathe());
    }
}
```

在上面的代码中，我们定义了静态 `Animal` 类，然后使用类内部的静态方法调用 `breathe` 方法。注意，我们在调用方法之前没有实例化类。当你在代码中使用 `static` 修饰符时，这是有效的语法。

继承是一个复杂的课题，大多数开发者在创建程序时需要一些时间来理解。在设计程序时，你不总是总是继承类，但随着程序的增长和用户的增多，它将大大减少你扩展代码所需的时间。在掌握继承、类和 OOP 面向对象编程 之前，需要一些练习。在练习 OOP 时，多使用一些父子类的继承，以习惯它们在你的设计中的工作方式。

## 数组 Arrays

**目标：** 数组是存储包含多个值的变量。本章将帮助你理解如何处理数组，以及如何从数组中分配和检索值。

数组是几乎任何程序的一部分。它们允许你在一个主变量中存储具有相同数据类型的变量列表。例如，如果你想存储整数列表，可以将它们存储在数组中。数组比其他数据类型稍限一些。你需要预先知道要存储在数组中的数值数量。

### C# 中的数组声明

数组的声明与普通变量略有不同。你仍然必须声明数据类型。当你声明数组时，你必须定义存储在数组中的变量类型。例如，如果你将数组定义为整数数组，你只能存储整数数组。这就是数组与其他数据类型（如类或结构）的区别。

数组存储多个变量，每个变量都有一个索引。索引数字从 0 开始。也就是说，存储在数组中的第一个索引为 0。下一个值的索引为 1，之后的索引为 2。正如你所见，每个值都被赋予下一个索引。这些索引就是你如何向数组赋值以及如何在代码中检索值。

在使用数组之前，你首先需要声明它。让我们先看看模板 `datatype[] arrayName;`

在上面的模板中，第一项 `datatype` 用于确定数组的数据类型。注意，括号 `[]` 表示代码定义中的数组。这是数组代码中指示你想创建一个给定数据类型数组的唯一部分。第二项是数组的名称。你可以为数组命名任何名称来定义数组的值。

让我们来看 C# 代码中定义的数组。
`int[] myNumbers;`

在这个示例中，我们定义了一个整数数组。第二个项是数组的名称。你可以根据自己和你的编程设计为数组起任何有意义的名称。在这个示例中，我们将数组命名为 `myNumbers`。

## 给数组填充值

当你处理数组时，需要向它们中填充值。当你想要为数组填充值时，`for` 循环是最常用的方法。如果你还记得的话，我们之前介绍过 `for` 循环。`for` 循环允许你定义一个变量和一个停止条件，然后使用递增运算符自动遍历数组索引。

由于你通常知道数组的长度以及填充数组所需的数值数量，因此可以使用 `for` 循环。`for` 循环是填充数组数值的首选方法。我们想向 `myNumbers` 数组填充一个数字列表。假设你想向数组填充从 1 到 10 的值。你可以使用数组索引逐个赋值。

逐个使用数组索引比其价值要繁琐得多。填充数组的首选方法是使用 `for` 循环。让我们看看当你想要遍历每个数字并将其赋予数组索引时，`for` 循环是什么样子的。

```cs
for ( int j = 0; j < 10; j++)
{
    myNumbers[ j ] = j;
}
```

在上面的代码中，我们使用了与上一节中相同的数组。我们定义了一个名为 `myNumbers` 的整数数组。从数据类型中知道，`myNumbers` 数组中只能存储整数。

接下来的代码部分是 `for` 循环。我们知道想向数组填充十个数字。因为所有数组都从索引 0 开始，我们知道首先需要将 `j` 的值初始化为 0。`for` 循环会遍历十次数组，从 0 到 9。当变量 `j` 达到 10 时，循环退出，数组中不再存储更多值。

在上面的示例中，0 到 9 的值被存储在数组中。你也可以通过数组索引逐个存储数组值。以下代码是使用数组索引存储数组的示例。

```cs
myNumbers[0] = 0;
myNumbers[1] = 1;
myNumbers[2] = 2;
myNumbers[3] = 3;
myNumbers[4] = 4;
myNumbers[5] = 5;
myNumbers[6] = 6;
myNumbers[7] = 7;
myNumbers[8] = 8;
myNumbers[9] = 9;
```

如你所示，上面的代码比 `for` 循环要繁琐得多。你可以通过在你想要遍历的内容中添加索引值来向数组添加更多数字。显然，使用 `for` 循环比使用静态数字并将它们分配数组而不使用循环要高效得多。

## 从数组中检索值

一旦你为数组分配了值，你也需要知道如何从数组中检索值。在某些情况下，你会向数组填充之后需要显示给用户的值。你可以使用我们在上一节中展示的繁琐检索值方法，也可以再次使用 `for` 循环。与逐个定义想要检索的变量相比，`for` 循环让检索值变得容易得多。

## 第 11 章：泛型

目标：泛型列表比数组更容易处理。本章将帮助你理解如何使用泛型以及你可以用它们做什么。

我们已经讨论了类、结构和枚举。所有这些都可以创建一个你可以使用的自定义数据类型。我们还讨论了数组。数组要求在你在使用之前定义数据类型，但你可以使用泛型来回避这一点。在本章中，我们将向你展示如何创建自己的泛型，并使用框架自带的预制 `List`。

## 泛型简介

泛型与数组类似。事实上，当你创建自己的泛型时，你是在代码中创建数组。泛型是你将自定义类型存储为数组的方式。C# 语言为你提供了一种特殊的语法，让你指定想要传递一个泛型数据类型。这种数据类型可以是简单的原始类型（如字符串或整数），你甚至可以将自己的类传递给泛型。

将泛型看作一种与数组相同的方式动态存储值的方法。自定义方法和属性在泛型数据类型上执行类似的任务，但在所有方法的背后都是处理所存储的数组变量的代码。唯一的区别是，数组所包含值的标识符是 `T` 而不是硬编码的原始类型。

在几乎每个程序中，你都会遇到至少一段使用泛型数据类型的代码。这在你处理 Web 应用程序时尤为真实。Web 应用程序使用 `Lists` 和 `集合`，因此你在大多数 Web 应用程序中将需要处理这些泛型列表。

## 创建你自己的泛型类型

.NET 语言有它们自己可以使用的泛型数据类型，但你应该了解如何创建自己的泛型类。当你无法使用通用列表，并想要使用预制 .NET 库中找不到的自定义方法创建自己的类时，创建类是非常重要的。

当你创建一个自己的泛型类型时，你实际上创建了一个自定义类。让我们来看一个接受泛型类型的简单类。

```csharp
public class MyGeneric<T>
{
    private T[] array;
    public MyGeneric(int size)
    {
        array = new T[size + 1];
    }
}
```

在上面的代码中，我们创建了一个名为 `MyGeneric` 的泛型自定义类。注意 `>` 和 `<` 之间的 `T` 数据类型。这告诉编译器你想传递一个泛型类型。你可以传递自定义类，也可以传递像 `string` 这样的原始数据类型。这就是 `T` 符号在任何类中的意义。它允许你处理任何数据类型，而不会受到定义数组对类所加的限制。

注意该类的其他部分与我们之前创建的其他类相似。构造函数接收我们正在创建的泛型数组的大小，以便代码可以分配正确的内存空间。由于数据类型是泛型的，我们在 `MyGeneric` 数据类型内部创建了一个私有数组。通过 `T[]` 标记，我们可以在数组中存储任何数据类型。

泛型类创建完成后，我们现在需要一种在类内获取和设置项目的方法。由于我们在创建自己的泛型自定义类，我们需要创建这些方法。首先，让我们创建一个向泛型数组添加值的方法。

```csharp
public class MyGeneric<T>
{
    private T[] array;
    public MyGeneric(int size)
    {
        array = new T[size + 1];
    }
    public void setItem(int index, T value)
    {
        array[index] = value;
    }
}
```
