## 7.12.5 双曲 functions
### 7.12.5.1 The acosh functions
#### 概要
```c
#include <math.h>
double acosh(double x);
float acosh(float x);
long double acosh(long double x);
```
#### 描述
`acosh`函数计算 `x`的（非负）双曲余弦。当参数小于 `1`时，发生域错误。
#### 返回
`acosh`函数返回区间 `[0,+∞)`内内的 `arcosh x`。

### 7.12.5.2 The asinh functions

#### 返回
`asinh`函数返回 `asinh x`。

### 7.12.5.3 The atanh functions
#### 概要
```c
#include <math.h>
double atanh(double x);
float atanhf(float x);
long double atanhl(long double x);
```
#### 描述

#### 返回
`atanh`函数返回 `artanh x`。

## 7.12.6 指数与对数函数
### 7.12.6.1 The exp functions
#### 概要
```c
#include <math.h>
double exp(double x);
float expf(float x);
long double expl(long double x);
```
#### 描述
`exp`函数计算 `e`为底的指数。
#### 返回
`exp`函数返回 `e`。

### 7.12.6.2 The exp2 functions
#### 概要
```c
#include <math.h>
double exp2(double x);
float exp2f(float x);
long double exp2l(long double x);
```
#### 描述
`exp2`函数计算 `2`为底的指数。当 `x`的幅度过大时，发生范围错误。
#### 返回
`exp2`函数返回 `x`。

### 7.12.6.3 The expm1 functions
#### 概要
```c
#include <math.h>
double expm1(double x);
float expm1f(float x);
long double expm1l(long double x);
```
#### 描述
`expm1`函数计算 `e`为底的指数减 `1`。当 `x`的幅度过大时，发生范围错误。
#### 返回
`expm1`函数返回 `e-1`。

### 7.12.6.4 The frexp functions
#### 概要
```c
#include <math.h>
double frexp(double x, int *exp);
float frexpf(float x, int *exp);
long double frexpl(long double x, int *exp);
```
#### 描述
`frexp`函数将浮点数分解为分数和 `2`的整数幂。
#### 返回
`frexp`函数返回区间 `[1/2, 1)`或 `(-1, -1/2]`内的分数。

### 7.12.6.5 The logb functions
#### 概要
```c
#include <math.h>
int logb(double x);
int logbf(float x);
int logbl(long double x);
```
#### 描述
`logb`函数提取 `x`的指数。当 `x`为 `0`时，发生域错误。
#### 返回
`logb`函数返回指数。

### 7.12.6.6 The ldexp functions
#### 概要
```c
#include <math.h>

float ldexpf(float x, int exp);
long double ldpl(long double x, int exp);
```

`ldexp`函数将浮点数乘以 `2`的整数幂。
#### 返回
`ldexp`函数返回 `x × 2^exp`。

### 7.12.6.7 The log functions
#### 概要
```c
#include <math.h>
double log(double x);
float logf(float x);
long double logl(long double x);
```
#### 描述
`log`函数计算 `e`为底的自然对数。当参数为负时，发生域错误。当参数为 `0`时，可能会发生极点错误。
#### 返回
`log`函数返回 `$\log_e x$`。

### 7.12.6.8 The log10 functions
#### 概要
```c
#include <math.h>
double log10(double x);
float log10f(float x);
long double log10l(long double x);
```
#### 描述
`log10`函数计算 `10`为底的常用对数。当参数为负时，发生域错误。当参数为 `0`时，可能会发生极点错误。
#### 返回
`log10`函数返回 `$\log_{10} x$`。

### 7.12.6.9 The log1p functions
#### 概要
```c
#include <math.h>
double log1p(double x);
float log1pf(float x);
long double log1pl(long double x);
```
#### 描述
`log1p`函数计算 `1`加参数的 `e`为底的自然对数。当参数小于 `-1`时，发生域错误。当参数等于 `-1`时，可能会发生极点错误。
#### 返回
`log1p`函数返回 `$\log_e(1 + x)$`。

### 7.12.6.10 log2 函数

```
#include <math.h>
double log2(double x);
float log2f(float x);
long double log2l(long double x);
```
#### Description
`log2`函数计算底的对数。如果参数小于 `0`，则发生域错误。如果参数为 `0`，则可能发生极点错误。
#### Returns
`log2`函数返回 `$\log_2 x$`。

### 7.12.6.11 logb 函数
#### Synopsis
```
#include <math.h>
double logb(double x);
float logbf(float x);
long double logbl(long double x);
```
#### Description
`logb`函数提取 `x`的指数，以带符号的整数值表示。如果 `x`是非正规数，则被视为归一化的；因此，对于正有限值 `x`，`1 ≤ x < 2`，函数返回带符号的整数（浮点格式）。
如果 `x`是 `0`，则发生域错误或极点错误。
#### Returns
`logb`函数返回 `x`的带符号指数。

### 7.12.6.12 modf 函数
#### Synopsis
```
#include <math.h>
double modf(double value, double *ptr);
float modff(float value, float *ptr);
long double modfl(long double value, long double *ptr);
```
#### Description
`modf`函数将参数分成整数部分和小数部分，每个部分与参数具有相同的类型和大小。整数部分存储在 `ptr`指向的对象中（浮点格式）。
#### Returns
`modf`函数返回 `value`的带符号小数部分。

### 7.12.6.13 calbn 和 scalbn 函数
#### Synopsis
```
#include <math.h>
double scalbn(double x, int n);
float scalbnf(float x, int n);
long double scalbn(long double x, int n);
```
#### Description
`calbn`和 `scalbn`函数通过直接计算 `x × 2^n`高效地计算 `x × 2^n`。不会发生溢出或下溢。
#### Returns
`calbn`和 `scalbn`函数返回 `x × 2^n`。

## 7.12.7 幂和绝对值函数

```
#include <math.h>
double cbrt(double x);
float cbrtf(float x);
long double cbrtl(long double x);
```
#### Description
`cbrt`函数计算 `x`的实立方根。
#### Returns
`cbrt`函数返回 `x^{1/3}`。

### 7.12.7.2 fabs 函数
#### Synopsis
```
#include <math.h>
double fabs(double x);
float fabsf(float x);
long double fabsl(long double x);
```
#### Description
`fabs`函数计算浮点数 `x`的绝对值。
#### Returns
`fabs`函数返回 `|x|`。

### 7.12.7.3 hypot 函数
#### Synopsis
```
#include <math.h>
double hypot(double x, double y);
float hypotf(float x, float y);
long double hypotl(long double x, long double y);
```
#### Description
`hypot`函数计算 `x`和 `y`平和的平方根。不会发生异常溢出或下溢。可能发生范围错误。
#### Returns
`hypot`函数返回 `$\sqrt{x^2 + y^2}$`。

### 7.12.7.4 pow 函数
#### Synopsis
```
#include <math.h>
double pow(double x, double y);
float powf(float x, float y);
long double powl(long double x, long double y);
```
#### Description
`pow`函数计算 `x`的幂次。如果 `x`是有限的且 `y`不是整数，则发生域错误。如果 `x`为 `0`且 `y`为 `0`，可能发生范围错误。如果 `x`为 `0`且 `y`小于 `0`，可能发生域错误或极点错误。
#### Returns
`pow`函数返回 `x^y`。

### 7.12.7.5 sqrt 函数
#### Synopsis
```
#include <math.h>
double sqrt(double x);
float sqrtf(float x);
long double sqrtl(long double x);
```
#### Description
`sqrt`函数计算 `x`的非负平方根。如果 `x`小于 `0`，则发生域错误。
#### Returns
`sqrt`函数返回 `$\sqrt{x}$`。

## 7.12.8 误差和伽马函数
### 7.12.8.1 erf 函数
#### Synopsis
```
#include <math.h>
double erf(double x);
float erff(float x);
long double erfl(long double x);
```
#### Description
`erf`函数计算 `x`的误差函数。
#### Returns
`erf`函数返回 `$\frac{2}{\sqrt{\pi}}\int_0^x e^{-t^2} dt$`。

### 7.12.8.2 erfc 函数
#### Synopsis
```
#include <math.h>
double erfc(double x);
float erccff(float x);
long double erfcfl(long double x);
```
#### Description
`erfc`函数计算 `x`的补误差函数。如果 `x`很大，则发生范围错误。
#### Returns
`erfc`函数返回 `1 - \frac{2}{\sqrt{\pi}}\int_x^\infty e^{-t^2} dt`。

### 7.12.8.3 lgamma 函数
#### Synopsis
```
#include <math.h>
double lgamma(double x);
float lgammaf(float x);
long double lgammal(long double x);
```
#### Description
`lgamma`函数计算 `x`的绝对值的自然对数。如果 `x`很大，则发生范围错误。如果 `x`是整数，则发生极点错误。
#### Returns
`lgamma`函数返回 `$\ln|x|$`。

### 7.12.8.4 tgamma 函数
#### Synopsis
```
#include <math.h>
double tgamma(double x);
float tgammaf(float x);
long double tgamyl(long double x);
```
#### Description
`tgamma`函数计算 `x`的伽马函数。如果 `x`是负整数或零，则发生域错误或极点错误。
#### Returns
`tgamma`函数返回 `$\Gamma(x)$`。
