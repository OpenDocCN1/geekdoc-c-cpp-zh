
证明。首先证明 `WORD ∈ RE`。这相当于构造一个 STM `M_2` 来模拟 `U^(2)`。在输入 `(i, w)` 上，`M_2` 以逐步的方式模拟 `U^(2)`。如果 `U^(2)` 接受则 `M` 将接受。因此 `L(M_2) = WORD`。同样，`DIAG` 和 `HALT` 在这种模拟的变体中也可以被证明为 `RE`。

定理 32. `WORD, HALT, DIAG ∉ RE`。

证明。假设 `WORD` 被一个确定性停止 STM `M` 判定。我们构造另一个与 `M` 相的反停止 STM `M'`：

1. 在 `i` 上模拟 `M`。
2. 如果 `M` 拒绝，则接受。

注意由于 `M` 是停止的，`M'` 也是停止的。(a) 如果 `i ∈ A`，则 `M'` 接受。根据 `M` 的定义，`^(2)(j)` 接受。但这意味着 `M'` 拒绝 `j`，矛盾。(b) 如果 `M'` 拒绝 `j`，则是因为 `M` 接受 `j`。根据 `M` 的定义，`^(2)(j)` 接受。但这意味着 `M'` 接受 `j`，矛盾。证明完毕。

推论 33. `co-WORD, HALT, co-DIAG` 不是 `r.e.`。

证明。利用 `RE ∩ co-RE` 的事实。其他情况类似。证明完毕。

## 引理 3. 设 `A` 递归地 `m`-可归约 `B`。

- (a) 如果 `B` 是递归的，那么 `A` 也是递归的。
- (b) 如果 `B` 是 `r.e.`（可列出的），那么 `A` 也是 `r.e.`。
- (c) 如果 `B` 是 `co-r.e.`（补可列出的），那么 `A` 也是 `co-r.e.`。

证明。每个部分都相同。让我们证明 (c)。设 `A ≤_m B` 通过函数 `t`。假设 `B` 是 `co-r.e.`。令 `M` 接受 `co-A`。我们现在可以如下方式接受 `co-A`：对于输入 `x`，计算 `t(x)` 并在 `t(x)` 上运行 `M`。如果 `M` 接受它，则证明 `co-A` 在 `RE` 中。证。

该引理说明，如果 `A ≤_m B`，则 `B` 的任何“上界”也是如此。通过恰当地选择 `A`，该引理是证明 `B` 非递归、非可枚举或非补可枚举的依据。这在下一个定理的证明中得到了说明。

### 29. Rice 定理

假设 `K` 是 `N` 的有限子集的类。设 `L(K) ⊆ N` 表示接受有限子集的图灵机（TM）的哥德数。我们将证明 `L(K)` 非递归的。事实上，这个结论对于几乎任何 `K` 选择都成立。Rice 定理的内容。

另一个例子，设 `K = {HALT}`，或 `K = {ε}`。然而，`K` 不能被选择为 `ε`，因为它是递归的。设 `K` 为任意 `r.e.` 类的。相对于 `U^(2)`，我们定义

```
L(K) := {i ∈ N | W_i ∈ K}
```

## 定理 37. 如果 `K ≠ {ε}` 是 `RE`，则 `L(K)` 不是递归的。

证明。我们将问题 `DIAG` 归约到 `L(K)`。选取任意 `A ∈ K`（因为 `K` 非空），选取任意 `B ∉ K`（因为 `K` 是 `r.e.` 类的真子集）。我们首先假设 `A = {ε}`。假设 `M_A` 和 `M_B` 分别接受和拒绝。

```
M_i(w) = { M_A(w) 如果 w ∈ W_i
          否则. }
```

注意 `M_i` 是良定义的：这里检查 `i ∈ W_i`。如果它不停止，则 `M_i` 不停止。如果它停止了，则我们在 `w` 上模拟 `A` 的接受器。`M_i` 计算的是什么？

如果 `i ∈ W_i`，则 `M_i` 接受 `A`。

如果 `i ∉ W_i`，则 `M_i` 接受 `B = {ε}`。

从构造可以看出，存在一个全递归函数 `t(i)`，它给出 `M_i` 的哥德数 `M_i`：

如果 `i ∈ W_i`，则 `L(M_i) = A ∈ K` 且 `t(i) ∈ L(K)`。

如果 `i ∉ W_i`，则 `L(M_i) = B ∉ K` 且 `t(i) ∉ L(K)`。

因此 `DIAG` 递归 `m`-可归约到 `L(K)`，根据之前的引理，`L(K)` 不是递归的。

我们假设 `A = {ε}`。假设 `A ∈ K`。设 `A` 为任意不在 `K` 中的集合。我们可以类似的构造 `M_i`，使得 `L(M_i) ∈ K` 当且仅当 `i ∈ W_i`。再次，我们得出 `L(K)` 非递归。

- (B) 存在有限子集 `B ⊆ A ∈ K`。

- (B) 假设 (B) 成立但 (A)。那么 `A ∉ K`，但存在某些有限子集 `B ⊆ A` 属于 `K`。为了判断 `i ∈ co-DIAG`，我们构造如下 `M_i`：输入 `t`，首先检查 `t ∈ B`。如果是，我们接受。否则，在 `i` 上模拟 `M_A`。再次，这种构造将 `co-DIAG` 归约到 `L(K)`。这告诉我们如果 `L(K)` 是 `r.e.`，则 `K` 可以归约到有限集合的“核心” `K*`。即，`K* ⊆ P^ω` 且每个 `A ∈ K` 都是 `K*` 的扩展。

## 0.3.11 第一递归定理

第一个递归定理比第二个更深层，涉及一些有趣的概念。它的适用性被认为更窄。

**32. 递归算子。** 一个全函数

```
Ψ : RE → RE
```

被称为**算子**。一个理论函数 `h: N → N` 如果对于所有的 `i, j ∈ N`，`W_i = W_j` 导致 `W_{h(i)} = W_{h(j)}`，则称该函数是**外延的**（extensional）。如果存在一个外延的全递归 `h: N → N` 使得对于所有的 `i ∈ N`，`Ψ(i) = W_{h(i)}`，我们称之为**递归算子**。我们说 `Ψ` 是**基于** `h` 的。

**示例**：外延全递归 `h` 的概念，对于所有的 `A ∈ RE`，`Ψ(A) = {x+1 | x ∈ A}`。为了证明 `Ψ` 是递归的，我们不需要算子。我们构造一个全递归 `h`，它在任何输入 `i` 上产生 STM `M_i` 在输入 `x` 上的哥德尔数，如果 `x=1` 则进入循环。否则，在 `x-1` 上运行 `U_i`，并在 `U_i` 停止时停机。很容易证明 `h` 是外延的，因为 `W_{h(i)}` 仅依赖于 `W_i`，而取决于哥德尔数 `i` 的选择。

**33. 有限性与连续性。** 设 `Ψ : RE → RE` 为一个算子。回想 `2^N` 是 `N` 的有限子集的集合。在接下来，我们将使用 `θ_i` 表示 `2^N` 中的元素。如果对于所有的 `A ∈ RE` 和 `x ∈ N`

```
x ∈ Ψ(A) ⇔ (∃θ ⊆ A)(x ∈ Ψ(θ))。(30)
```

我们说 `Ψ` 是**连续的**。如果对于所有的 `A, B ∈ RE`，若 `A ⊆ B` 则 `Ψ(A) ⊆ Ψ(B)`，我们说 `Ψ` 是**单调的**。

**定理 40. *递归算子既是连续的又是单调的。***

证明。设 `Ψ` 是基于 `h` 的递归算子。

(a) `Ψ` 是连续的。根据 Rice-Shapiro 定理的应用，设 `K = {A ∈ RE : x ∈ Ψ(A)}`。由于 `RE = {W_i : i ∈ N}` 且 `Ψ(W_i) = W_{h(i)}`，我们得出

```
K = {i ∈ N : x ∈ W_{h(i)}}
```

很容易证明对于所有的可枚举集合 `A`，`K` 是可枚举的，`x ∈ A ⇔ (∃θ ⊆ A)(x ∈ K)`，即 `Ψ` 是连续的。

(b) `Ψ` 是单调的。这从连续性很容易得出：设 `A ⊆ B` 为可枚举集合。那么

```
x ∈ A ⇔ (∃θ ⊆ A)(x ∈ Ψ(θ)) ⟹ (∃θ ⊆ B)(x ∈ Ψ(θ))
```

证毕。

我们准备好通过 Kleene 证明以下定理：

**定理 41 第一递归定理。** *若 `Ψ` 为任意单调算子。则存在 `Ψ` 的不动点 `A*`，即*
