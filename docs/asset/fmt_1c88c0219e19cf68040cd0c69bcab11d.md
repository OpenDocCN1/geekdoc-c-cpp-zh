
- `log2(±0)` 返回 `-∞` 并抛出“除零（divide-by-zero）”浮点异常。
- `log2(1)` 返回 `+0`。
- `log2(x)` 在 `x < 0` 时返回 `NaN` 并抛出“无效（invalid）”浮点异常。
- `log2(+∞)` 返回 `+∞`。

### F10.3.11 logb 函数

- `logb(±0)` 返回 `-∞` 并抛出“除零（divide-by-zero）”浮点异常。
- `logb(+∞)` 返回 `+∞`。

返回的值是精确的，且独立于舍入方向模式。

### F10.3.12 modf 函数

- `modf(±x, iptr)` 返回与 `x` 符号相同的符号。
- `modf(∞, iptr)` 返回 `±0` 并在 `iptr` 指向的对象中存储 `∞`。
- `modf(NaN, iptr)` 在 `iptr` 指向的对象中存储 `NaN`（返回 `NaN`）。

返回的值是精确的，且独立于舍入方向模式。

`modf` 的实现类似于：

```
#include <math.h>
#include <fenv.h>
#pragma STDC FENV_ACCESS
double modf(double value, double *iptr) {
    double result;
    int save_round = fegetround();
    fesetround(FE_TOWARDZERO);
    *iptr = rint(value);
    result = value - (*iptr);
    fesetround(save_round);
    return result;
}
```

- `scalbn(±0, n)` 返回 `±0`。
- `scalbn(x, 0)` 返回 `x`。
- `scalbn(∞, n)` 返回 `∞`。

如果计算没有溢出或下溢，返回的值是精确的，独立于舍入方向模式。

### F10.4.4 pow 函数

- `pow(±0, y)` 在 `y` 为负整数时返回 `±∞` 并抛出“除零（divide-by-zero）”浮点异常。
- `pow(±0, y)` 在 `y < 0`、有限且非整数时返回 `+∞` 并抛出“除零（divide-by-zero）”浮点异常。
- `pow(±0, -∞)` 返回 `+∞` 并可能抛出“除零（divide-by-zero）”浮点异常。
- `pow(±0, y)` 在 `y` 为负整数时返回 `±0`。
- `pow(±0, y)` 在 `y > 0` 且非整数时返回 `+0`。
- `pow(-1, ±∞)` 返回 `1`。
- `pow(+1, y)` 对于任何 `y`（甚至是 `NaN`）都返回 `1`。
- `pow(x, ±0)` 对于任何 `x`（甚至是 `NaN`）都返回 `1`。
- `pow(x, y)` 在有限 `x < 0` 和有限非 `y` 时返回 `NaN` 并抛出“无效（invalid）”浮点异常。
- `pow(x, -∞)` 在 `|x| < 1` 时返回 `+∞`。
- `pow(x, -∞)` 在 `|x| > 1` 时返回 `+0`。
- `pow(x, +∞)` 在 `|x| < 1` 时返回 `+0`。
- `pow(x, +∞)` 在 `|x| > 1` 时返回 `+∞`。

`pow(-∞, y)` 在 `y` 为负整数时返回 `-0`。

`pow(-∞, y)` 在 `y < 0` 且非整数时返回 `+0`。

`pow(-∞, y)` 在 `y` 为正整数时返回 `-∞`。

`pow(-∞, y)` 在 `y > 0` 且非整数时返回 `+∞`。

`pow(+∞, y)` 在 `y < 0` 时返回 `+0`。

`pow(+∞, y)` 在 `y > 0` 时返回 `+∞`。

double ceil(double x) {

### F10.6.3 nearbyint 函数

`nearbyint` 函数根据当前的舍入方向使用 IEC 60559 舍入。如果结果与参数的值不同，则不抛出“不精确（inexact）”浮点异常。

## F10.6.4 rint 函数

`rint` 函数与 `nearbyint` 函数的唯一区别在于，当结果在数值上与参数不符时，它们会抛出“不精确（inexact）”浮点异常。

## F10.6.5 lrint 和 llrint 函数

`lrint` 和 `llrint` 函数提供了 IEC 60559 规定的浮点数到整数的转换。它们根据当前的舍入方向进行四舍五入。如果返回值超出了返回类型的范围，则数值结果未定义，并会抛出“无效（invalid）”浮点异常。当它们没有抛出其他浮点异常且结果与参数不同时，它们会抛出“不精确（inexact）”浮点异常。

## F10.6.6 round 函数

- `round (±0)` 返回 `±0`。
- `round (±∞)` 返回 `∞`。

返回的值与当前的舍入方向模式无关。

`double` 版本的 `round` 行为类似于以下代码实现：

```c
#include <math.h>
#include <fenv.h>
#pragma STDC FENV_ACCESS ON
double round(double x)
{
    double result;
    fenv_t save_env;
    feholdexcept(&save_env);
    result = rint(x);
    if (fetestexcept(FE_INEXACT)) {
        fetetround(FE_TOWARDZERO);
        result = rint(copysign(0.5 + fabs(x), x));
    }
    updateenv(&save_env);
    return result;
}
```

`round` 函数可能会（但不是必须）对有限非整数数值参数抛出“不精确（inexact）”浮点异常，本实现正是这样做的。

## 10.6.7 round 和 llround 函数

`round` 和 `llround` 函数与默认舍入方向下的 `lrint` 和 `llrint` 函数的区别仅在于：`round` 和 `llround` 函数采用远离零舍入，且对于舍入后在返回类型范围内的非整数参数，不会抛出“不精确（inexact）”浮点异常。

## 10.6.8 trunc 函数

`trunc` 函数使用 IEC 60559 的向零舍入规则（无论当前的舍入方向如何）。返回的值是精确的。

- `trunc (±0)` 返回 `±0`。
- `trunc (±∞)` 返回 `±∞`。

返回的值与当前的舍入方向模式无关。`trunc` 函数可能会（但不是必须）对非整数参数抛出“不精确（inexact）”浮点异常。

## F10.6.7 余数函数

### F10.6.7.1 fmod 函数

- `fmod (x, ±∞)` 返回 `x`。
- `fmod (NaN, y)` 返回 `NaN`。

`double` 版本的 `fmod` 行为类似于以下代码实现：

```c
#include <math.h>
#include <fenv.h>
#pragma STDC FENV_ACCESS ON
double fmod(double x, double y)
{
    double result;
    result = remainder(x, y);
    if (isnan(result)) {
        return result;
    }
    if ((x > 0) != (result > 0)) {
        result = -result;
    }
    return result;
}
```

## 兼容 IEC 60559 的复数运算

### G.1 引言

本附录补充了 F 附录，规定了与 IEC 60559 实浮点运算兼容的复数运算。定义 `__STDC_IEC_559_COMPLEX__` 的实现应符合本附录的规定。

### G.2 类型

新增关键字 `_Imaginary` 用于指定虚数类型。它以与 `_Complex` 相同的方式作为声明说明符（因此 `_Imaginary float` 是一个有效的类型名称）。

有三种虚数类型，分别为 `float _Imaginary`、`double _Imaginary` 和 `long double _Imaginary`。虚数类型（以及实浮点复数类型）都是浮点类型。

对于虚数类型，通过删除类型名称中的关键字 `_Imaginary` 即可实类型。

每个虚数类型与其实类型具有相同的表示和对齐要求。虚数类型对象的值是实表示乘以虚单位。

虚数类型域包含虚数类型。

### G.3 惯例

至少有一个无穷部分的复数或虚数被视为无穷（即使其其他部分为 `NaN`）。如果每个部分都是有限数（既不是无穷也不是 `NaN`），则复数或虚数是有限数。如果每个部分都是零，则复数或虚数是零。

### G.4 转换

### G.4.1 虚数类型

虚数类型之间的转换遵循与实数浮点类型类似的规则。

### G.4.2 实数与虚数

当虚数类型的值转换为除 `_Bool_` 以外的实数类型时，结果为正零。

当实数类型的值转换为虚数类型时，结果为正虚零。

### G.4.3 虚数与复数

当虚数类型的值转换为复数类型时，复数值结果的实部为正零，而复数值结果的虚部由对应实数类型的转换规则决定。

当复数类型的值转换为虚数类型时，复数值的实部被丢弃，虚部的值则根据对应实数类型的转换规则进行转换。

## G.5 二元运算符

以下子句 6.5 节按顺序指定了具有虚数操作数的操作之结果的类型。

对于大多数操作数，具有虚数或复数操作数的二元运算符的结果值通过参考实数算术，由常规数学公式完全确定。对于某些操作数，由于常规数学公式对无穷大的处理以及不当的溢出或下溢，常规数学公式是有问题的；在这些情况下，结果满足某些属性（在 G.5.1 中指定），但并非完全确定。

### G.5.1 乘法运算符

语义

如果一个操作数是实数类型而另一个操作数是虚数类型，则结果为虚数类型。如果两个操作数都是虚数类型，则结果为实数类型。（如果任一操作数是复数类型，则结果为复数类型。）

如果操作数不是复数，则 `*` 运算符的结果和浮点异常行为由常规数学公式定义：

| | `u` | `iv` | `u + iv` |
|---|---|---|---|
| `x` | `xu` | `i(xv)` | `(xu) + i(xv)` |
| `iy` | `i(yu)` | `-vy` | `(-vy) + i(yu)` |
| `x + iy` | `(xu) + i(yu)` | `(-vy) + i(xv)` |

如果第二个操作数不是复数，则 `/` 运算符的结果和浮点异常行为由常规数学公式定义：

| | `u` | `iv` |
|---|---|---|
| `x` | `x/u` | `i(-x/v)` |
| `iy` | `i(y/u)` | `y/v` |
| `x + iy` | `(x/u) + i(y/u)` | `(y/v) + i(-x/v)` |

`*` 和 `/` 运算符对于所有实数、虚数和复数操作数满足以下无穷大属性：

- 如果一个操作数是无穷大而另一个操作是非是非有限数或无穷大，则 `*` 运算符的结果为无穷大；
- 如果第一个操作数是无穷大而第二个操作数是有限数，则 `/` 运算符的结果为无穷大；
- 如果第一个操作数是有限数而第二个操作数是无穷大，则 `/` 运算符的结果为零；

> 377 这些属性在表格涵盖的情况下已经隐含，但对于所有情况都是要求的（至少在 `CX_LIMITED_RANGE` 状态为“off”时）。

如果第一个操作数是非零数或无穷大而第二个操作数为零，则 `/` 运算符的结果为无穷大。

如果 `*` 运算符的两个操作数都是复数，或者 `/` 运算符的第二个操作数是复数，则如果该运算符对于部分的计算是合适的，它将表示浮点异常，并可能导致伪浮点异常。
