
| :--- | :--- | :--- |

| `v.value(c, I)` | int | 如果 `c` 是 `I` 中的有效数字，则返回其表示的值；否则返回 -1。[ 注意：`I` 的值将为 8、10 或 16。—— 注结束] |

| `u.imbue(loc)` | `X::locale_type` | 注入区域化 `loc` 并返回之前使用的区域化（如果有）。 |

| `v.getloc()` | `X::locale_type` | 返回 `v` 当前使用的区域化（如果有）。 |
