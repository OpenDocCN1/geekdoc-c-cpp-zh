## 2.2 C++ 中的第一个程序：打印一行文本

考虑一个打印一行文本的程序（图 2.1）。该程序说明了 C++ 语言的重要特征。第 1 到 10 行的文本是程序的源代码（code）。行号不是源代码的一部分。

```cpp
// Fig. 2.1: fig0201.cpp
// 文本打印程序。
#include <iostream> // 使程序能够向屏幕输出数据
int main() {
    std::cout << "Welcome to C++!\n"; // 显示消息
    return 0; // 表示程序成功结束
}
```

欢迎来到 C++！

图 2.1 | 文本打印程序。

### 注释

第 1 行和第 2 行各是一个注释。第 1 到 10 行的文本是程序的源代码（code）。行号不是源代码的一部分。

### std 命名空间

当我们使用通过预处理指令 `#include <iostream>` 引入程序的名称时，`cout` 之前需要加上 `std::`。`std::cout` 表示表示我们正在使用一个名称，在这种情况下它属于 `std` 命名空间。`cin`（标准输入流）和 `cerr`（标准错误流）也属于 `std` 命名空间。命名空间是 C++ 的高级特性，我们将在第 23 章“其他主题”中讨论。现在，你只需要记住在程序中每次提到 `cout`、`cin` 和 `cerr` 之前加上 `std::`。

### 流插入运算符与转义序列

在输出语句的文中，`<<` 运算符被称为流插入运算符，运算符右侧的值（右操作数）被插入输出流中。注意 `<<` 运算符指向数据引号。字符串字面量的字符通常按照它们在双引号之间出现的形式进行打印。然而，`\` 不会在屏幕上打印（图 2.1）。反斜杠是一个转义字符。它表示要输出一个“特殊”字符。当在字符字符串中遇到反斜杠时，下一个字符将与反斜杠结合形成一个转义序列。转义序列 `\n` 意味着换行。它使光标（即当前屏幕位置指示器）移动到屏幕上下一行的开头。图 2.2 列出常见的转义序列。

| 转义 |  |
| :--- | :--- |
| `\n` | 换行。将屏幕光标置于下一行的开头。 |
| `\t` | 水平制表。将屏幕光标移动到下一个制表位。 |
| `\r` | 回车。将屏幕光标置于当前行的开头；不进到下一行。 |
| `\a` | 警报。发出系统蜂鸣。 |
| `\\` | 反斜杠。用于打印反斜杠字符。 |
| `\'` | 单引号。用于打印单引号字符。 |
| `\"` | 双引号。用于打印双引号字符。 |

### 关于注释的说明

当你编写新程序或修改现有程序时，你应该保持注释与程序代码同步更新。你需要对现有程序进行更改——例如，修复阻止程序正常运行的错误（通常是 bug）或增强程序功能。在进行代码更改时更新注释，可以确保注释准确反映了代码的功能。

## 2.3 修改我们的第一个 C++ 程序

我们展示了两个示例，通过修改图 2.1 中的程序，一个是一个使用多个语句在行内打印文本，另一个是使用单个语句在几行内打印文本。

### 使用多个语句打印单行文本

“Welcome to C++”可以通过多种方式打印。例如，图 2.3 在多个语句中执行流插入（第 7-8 行），但产生的输出与图 2.1 中的程序相同。第 7 行第一次流插入打印 `Welcome` 后跟一个空格，第 8 行第二次流插入将紧接空格在同一行开始打印。

```cpp
// Fig 2.3: fig023.cpp
// 使用多个语句打印一行文本。
#include <iostream> // 启用输出到屏幕
int main() {
    std::cout << "Welcome ";
    std::cout << "to C++!\n";
}
```

图 2.3 | 使用多个语句打印一行文本。

### 使用单个语句打印多行文本

单个语句可以通过使用换行符来打印多行，如图 2.4 的第 7 行所示。每当在输出流中遇到 `\n` 换行转义序列时，屏幕光标就会置于下一行的开头。

```cpp
// Fig 2.4: fig02_04.cpp
// 使用单个语句打印多行文本。
#include <iostream> // 允许程序将数据输出到屏幕
int main() {
    std::cout << "Welcome\nto\nC++!\n";
}
```

## 2.4 另一个 C++ 程序：整数相加

我们的下一个程序获取用户通过键盘输入的两个整数，计算它们的和并使用 `std::cout` 输出结果。

```cpp
// Fig 2.5: fig02_05.cpp
// 显示两个整数和加法程序。
#include <iostream> // 允许程序执行输入输出
int main() {
    int number1 = 0; // 第一个加数的整数
    int number2 = 0; // 第二个加数的整数
    int sum = 0; // number1 和 number2 的和
    std::cout << "Enter first integer: ";
    std::cin >> number1;
    std::cout << "Enter second integer: ";
    std::cin >> number2;
    sum = number1 + number2; // 计算和
    std::cout << "Sum is " << sum << std::endl; // 输出结果
}
```

图 2.5 | 显示两个整数和的加法程序。

### 变量声明的位置

变量的声明可以放在程序的任何地方，但它们必须在程序中使用相应变量之前出现。例如，在图 2.5 的程序中，第 8 行的声明 `int number1;` 可以紧放在 `std::cin >> number1;` 之前。
