
# 416 化学信息学算法手册

将未标记的 `CO2` 流替换为未标记和 `13C` 标记的 `CO2` 混合物。原始的碳流向图在用作 BioNetGen 输入之前需要进行处理。这种预处理在文献 [19] 中描述。该模型追踪了 562 个同异构体。在模拟过程中，系统需要处于稳态。在时间 `t=0` 时，`CO2` 流量的组成发生变化，使得进入的 `CO2` 有 10% 被标记为 `13C`。系统的稳态通量保持不变（同位素效应除外，预计很小），但每个中间代谢物的 `13C` 标记模式会发生变化，直到中间体被完全标记。BioNetGen 还能以 M 文件和系统生物学标记语言 (SBML) 格式生成相同模型和模拟的规范，这些可以被能够模拟常微分方程（ODE）的其他软件工具（如 MATLAB®）解释。对于可逆反应，我们需要指定两个通量：正向通量和反向通量。与其使用正向和反向通量，可逆反应也可以使用净通量和交换通量进行建模 [27]。

```
v_net = v_forward - v_backward and v_exchange = min(v_forward, v_backward). (15.39)
```

交换通量的范围可以在 `[0, ∞]` 之间。对正向和反向通量的表征提供了反应的可逆性衡量，其中交换通量为 0 对应于不可逆反应，而无穷大 `(∞)` 表示快速反应平衡。同异构体分布对交换通量不敏感。由于已证明交换通量只能确定到数量级水平 [9]，因此交换通量可以转换为所谓的 `[0, 1]` 交换通量，

```
v_exchange ∈ [0, 1] = v_exchange / (1 - v_exchange) (15.40)
```

此外，当交换通量很大时，可能会出现数值不稳定的情况。在这种情况下，可以将该范围指定为例如 `[0, 0.9]`，以消除交换通量过小或过大的可能性。作为 BioNetGen 处理具有复杂性（562 个同异构体）问题的效率衡量，我们计算了卡文循环模拟的 CPU 时间。模拟总耗时 33.8 s。从 BNGL 编码的 `ode_command` 生成同异构体平衡方程花费了 14.4 s，平衡系统花费了 17.2 s（这是必要的）。模拟一组刚性微分方程的计算成本随 `N^3` 缩放，其中 `N` 是方程的数量（物种的数量）。通常，`N` 和同异构体平衡方程的数量将随着代谢网络中反应的数量呈指数级增长。然而，对于最近报道的一种动力学蒙特卡洛方法 [38]，模拟成本与同异构体的数量无关，且随反应（规则）的数量缩放。
