### 5.4.10 continue 语句

`continue` 语句的语法形式为：

```
continue;
```

关于 `continue` 语句的要点如下：

- `continue` 语句只能出现在循环内部，或者作为循环的主体出现。
- `continue` 语句会终止当前最近的闭层循环的当前迭代。`continue` 语句的语义将在迭代语句之后讨论。

### 5.4.11 return 语句

`return` 语句的通用形式为：

```
return; //← 形式 1
return expression; //← 形式 2
```

关于 `return` 语句的要点如下：

- 不带表达式的 `return` 语句（即形式 1）只能出现在返回类型为 `void` 的函数中。
- 带有表达式的 `return` 语句（即形式 2）不应出现在返回类型为 `void` 的函数中。
- `return` 语句终止函数的执行并将控制权返回给调用函数。

> 请参考第 5.5.7.2 节关于 `continue` 语句语义。

`return` 语句的语法和语义将在第 8 章中讨论。

### 5.5 迭代语句

迭代是一个反复执行同一组语句的过程，直到指定的条件为真。人类认为迭代任务很无聊，但计算机非常擅长执行迭代任务。计算机通过将一组语句放在循环中反复执行来完成这些任务。C 语言提供了以下迭代语句：

- `for` 语句
- `while` 语句
- `do-while` 语句

通常，循环被分类为：

- 计数控制循环
- 哨兵控制循环

#### 5.5.1 计数控制循环

计数控制循环是循环的一种，其中执行的次数是提前预知的。计数控制循环之所以这样命名是因为它们使用一个称为循环计数器的控制变量来跟踪循环迭代。计数控制循环从循环计数器的初始值开始，在达到循环最终值时终止。由于计数控制循环执行的是预知的固定次数，因此也被称为重复循环。计数控制循环有三个主要要素：

- 循环计数器的初始化。
- 一个决定是否执行循环体的表达式（具体为一个条件）。
- 一个操纵循环计数器值的表达式，使得第 2 步中的条件变为假并终止循环。

首先，我将描述 C 语言中循环语句的语法以及如何使用它们进行计数控制循环。在第 5.5.5 节中，我将描述如何使用迭代语句进行哨兵控制循环。

#### 5.5.2 for 语句

在 C 语言所有的循环结构中，`for` 语句是最流行的。`for` 语句的通用形式为：

```
for(expression; expression; expression)
    statement // for 头部
    // for 主体
```

| 语句语法 | 流程图 |
|---|---|
| `for ( init; condition; increment ) { statement(s); }` | ![流程图](https://example.com/flow_diagram.png) |
| 说明：`for` 循环多次执行一系列语句，并简化了管理循环变量的代码。 | |

关于 `for` 语句的要点如下：

- `for` 语句的语法仅允许关联一个语句到 `for` 头部。如果需要重复执行多个语句，应将这些语句组合成一个复合语句。

**for 语句的执行：**

`for` 语句的执行方式如下：

- a. 初始化部分仅在循环开始时执行一次。
- b. 评估条件部分中的表达式。
    - i. 如果其求值为真，则执行循环并将程序控制转移到 `for` 语句相邻的语句。
- c. 在执行完循环体后，评估操纵表达式。
- d. 循环体执行后，操纵表达式被评估。

#### 5.5.3 while 语句

`while` 语句的通用形式为：

```
while(expression) // while 头部
statement // while 主体
```

**while 语句的语法**

```
while(condition)
{
    statement(s); // 代码块
}
```

**语法与流程图**

| 语句语法 | 流程图 |
|---|---|
| `while (condition) { statement(s); }` | ![流程图](https://example.com/image.png) |
| 说明：当条件为真时重复语句或一组语句。它在执行循环之前测试条件。 | |

关于 `while` 语句的要点如下：

- `while` 语句由头部和 `while` 主体组成。
- `while` 头部由关键字以及括号内的控制表达式组成。
- 头部中的控制表达式是强制性的，不能跳过。
- `while` 头部不应以分号终止。如果以分号终止，分号被解释为 `while` 头部后的空语句（即它被视为 `while` 主体）。
- `while` 语句的语法仅允许关联一个语句到 `while` 头部。为了重复执行，将语句组合成一个复合语句。
- `while` 语句的执行如下：
    - a. 评估控制表达式。
        - i. 如果其求值为真，则执行循环体。
        - ii. 如果其求值为假，则将程序控制转移到 `while` 语句相邻的语句。
    - b. 在执行完 `while` 主体后，程序控制返回 `while` 头部。
    - c. 重复步骤 a 和 b 直到控制表达式求值为假。
- 使用 `while` 语句时，始终记住在评估 `while` 控制表达式之前初始化循环计数器，并在 `while` 主体内部操纵循环计数器，即在再次评估 `while` 控制表达式之前。

#### 5.5.4 do-while 语句

`do-while` 语句的通用形式为：

```
do // <do-while 头部
statement
// <do-while 主体
while(expression); // <while 子句
```

**do-while 语句的语法**

| do-while 语句的语法 | 流程图 |
|---|---|
| `do { statement(s); } while( condition or expression);` | ![流程图](https://example.com/flowchart.png) |

**解释：**

条件表达式出现在循环末尾，因此循环中的语句在测试条件之前会执行。如果条件为真，控制流将跳回 `do`，循环中的语句将再次执行。此过程会一直重复，直到给定的条件变为假。

关于 `do-while` 语句的要点如下：

- `do-while` 语句由一个 `do` 子句组成，后面跟着一个构成 `do-while` 主体的语句，最后是一个由 `while` 关键字后跟括号内的 `do-while` 控制表达式组成的 `while` 子句。`while` 子句以分号结束。
- `do-while` 语句中的控制表达式是强制性的，不能跳过。
- `do-while` 语句的语法允许存在单个语句。如果需要重复执行多个语句，则应将这些语句组合成复合语句。
- `do-while` 语句的执行过程如下：
    - a. 执行语句，即 `do-while` 语句的主体。
    - b. 执行 `do-while` 主体后，求值 `do-while` 控制表达式。
        - i. 如果结果为真，则执行语句（即 `do-while`）并重复步骤 b。
        - ii. 如果结果为假，程序控制转移到 `do-while` 语句后面的语句。
- 在使用 `do-while` 语句时，始终记住在 `do-while` 语句之前初始化循环计数器，并在 `do-while` 语句内部对其进行处理，以便 `do-while` 控制表达式变为假。
- 即使 `do-while` 控制表达式初始为假，`do-while` 循环的主体也会执行一次。

### 5.5.5 哨兵控制循环

在哨兵控制循环中，迭代的次数是未知的。循环的执行或终止取决于一个称为哨兵值的特殊值。如果哨兵值为真，则执行循环体，否则不执行。由于循环次数无法预知，这种循环被称为**无限循环**。
