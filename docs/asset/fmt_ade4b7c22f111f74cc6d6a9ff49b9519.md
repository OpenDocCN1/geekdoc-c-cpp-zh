## 第二个用户选择：出售车辆

当用户输入数字 `2` 并按下回车键时，就会发生这种情况。这将引导程序进入第二个 `if` 语句，在语句中程序需要执行车辆出售。

在这里必须完成的第一件事是获取所有车辆。这是通过调用 `serviceProvider` 来解析 `IDealershipService` 以获取服务，并在其上执行 `GetInventory()` 方法。这将返回库存中的所有车辆，然后可以执行 Entity Framework Core 扩展方法 `FirstOrDefault()`。如果库存不为空，该方法将获取库存中的第一个元素，这意味着我们可以执行售卖汽车的操作。

我们将通过调用 `serviceProvider` 来解析服务对象，然后调用其上的 `SellVehicle()` 方法来实现此操作。在这种情况下，我们将传递车辆的 `Vin` 属性值，以便程序知道要从数据库数据集中移除哪辆车辆。程序将首先在 `Cars` 数据库集中搜索该车辆；如果找到，则将其从集合删除；如果没有找到，程序将在 `Trucks` 数据库集中进行搜索。此外，如果在那里找到了该车辆，将在 `Trucks` 集合中执行删除操作。

如果库存中没有车辆，程序将在控制台输出上打印消息“你没有可出售的车辆”。

## 第三类情况：列出库存

最后一种情况是输入数字 `3`。如果用户输入数字 `3` 并按下回车，意味着他想在程序中列出库存。他购买的所有汽车都应该出现在列表中。

我们应该做的第一件事是如果库存中有任何车辆，从中获取它们并存储在变量中。为了实现这一点，我们需要调用 `serviceProvider` 解析一次 `IDealershipService` 并获取服务对象。完成后，我们将在该服务对象上执行 `GetInventory()` 方法。这将返回库存中的车辆列表并将其存储在 `vehicles` 变量中。我们会检查 `vehicles` 列表中是否包含元素。

如果条件为真，我们必须向用户打印车辆，并告知用户列表将包含车辆识别码。然后，我们将遍历 `vehicles` 列表中的每辆车辆，并将车辆的 `Vin` 属性值打印到控制台输出。

如果库存中没有车辆，用户将在标准输出上收到消息“你没有拥有任何车辆”。为了确认任何操作，用户最后必须按回车键，然后循环将重新开始。通过这种解决方案，我们成功创建了一个可以通过控制台输入与用户通信的交互式应用程序。
