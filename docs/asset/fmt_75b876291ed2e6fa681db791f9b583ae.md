# 12 文件管理

## 目标
在本章中，你将学习 - C语言中的文件处理、文件操作函数、定义和打开文件、关闭文件、`getw` 和 `putw` 函数、`fprintf` & `fscanf` 函数、文件的随机访问、`fseek` 函数以及命令行参数。

## 12.1 绪言

C语言支持许多能够执行基本文件操作的函数。

- (1) 命名文件
- (2) 打开文件
- (3) 从文件读取
- (4) 向文件写入数据
- (5) 关闭文件

在处理大量数据时，控制台定向的 I/O 操作具有某些局限性，例如，通过终端处理大量数据非常耗时。当程序终止或计算机关闭时，所有数据都会丢失，因此有必要将数据存储在磁盘上，并在需要时读取，而不会破坏数据。这种方法利用文件的概念来存储数据。

## 12.2 C语言中的文件函数

这些函数对于操作文件非常重要，如下表所示

| 函数名 | 操作 |
|---|---|
| `fopen()` | 创建新文件供使用<br>打开已存在的新文件供使用 |
| `fclose()` | 关闭已打开的文件 |
| `getc()` | 从文件中读取一个字符 |
| `putc()` | 向文件中写入一个字符 |
| `fprintf()` | 向文件中写入一组数据值 |
| `fscanf()` | 从文件中读取一组数据值 |
| `getw()` | 从文件中读取一个整数 |
| `putw()` | 向文件中写入一个整数 |
| `fseek()` | 设置文件位置到指定点 |
| `ftell()` | 给文件的当前位置 |
| `rewind()` | 将位置置于文件开头 |

### 12.2.1 定义和打开文件

如果我们想将数据存储到文件中，我们必须指定文件名、数据结构。打开文件的通用格式是：

```c
FILE *fp;
fp = fopen("filename", "mode");
```

第一个语句声明 `fp` 为 `FILE` 类型。第二个语句打开文件并分配一个指针。
- 以只读模式打开文件
- 以追加模式打开文件

`<stdio.h>` 包含了 `FILE` 的声明。常量如 `NULL` 定义在 `<stdio.h>` 中。注意，`fp` 是一个指向文件的指针。`EOF` 是文件结束的标识。在 C 语言中使用整数来表示文件结束。

```c
fp = fopen("filename");
```

上面的语句打开了名为 prog 的文件用于读取。

### 12.2.2 关闭文件

当对文件操作完成后，必须关闭文件。关闭文件的通用格式如下：

```c
FILE *fp1, *fp2;
fp1 = fopen("Input", "w");
fp2 = fopen("Output", "r");
fclose(fp1);
fclose(fp2);
```

上面的程序打开了两个文件，并在操作完成后关闭它们。

## 12.3 文件 I/O

### 12.3.1 `getc` 和 `putc` 函数

I/O 库提供了用于文件定向的程序。`getc(fp)` 类似于 `getchar()`，`putc(c)` 类似于 `putchar(c)`。因此，语句：

```c
c = getc(fp);
```

从文件中读取下一个字符。

```c
putc(c, fp);
```

将字符写入 `fp` 指向的文件。

### file.c: 显示文件内容

```c
#include <stdio.h>

void main() {
    FILE *fp;
    int c;
    fp = fopen("prog.c", "r");
    if (fp == NULL) {
        /* 未找到文件 */
    } else {
        c = getc(fp);
        while (c != EOF) {
            putchar(c);
            c = getc(fp);
        }
    }
    fclose(fp);
}
```

在这个程序中，我们打开 `prog.c` 进行读取。该文件必须存在。

### 12.3.2 `getw` 和 `putw` 函数

这些是面向整数的函数。它们类似于 `getc` 和 `putc` 函数，用于读取写入整数。当我们只处理整数数据时，这些函数非常有用。`getw` 和 `putw` 的通用形式为：

```c
getw(fp);
```

使用 `getw` 和 `putw` 函数的示例程序

```c
#include <stdio.h>

main() {
    FILE *f1, *f2, *f3;
    int number, i;
    printf("数据文件内容\n\n");
    f1 = fopen("prog.c", "w");
    for(i=1; i<=30; i++) {
        scanf("%d", &number);
        if(number == -1)
            break;
        putw(number, f1);
    }
    fclose(f1);
    f1 = fopen("prog.c", "r");
    f2 = fopen("odd.txt", "w");
    f3 = fopen("even.txt", "w");
    while((number = getw(f1)) != EOF) { /* 读取数据文件 */
        if(number % 2 == 0)
            putw(number, f3); /* 写入偶数文件 */
        else
            putw(number, f2); /* 写入奇数文件 */
    }
    fclose(f1);
    fclose(f2);
    fclose(f3);
    f2 = fopen("odd.txt", "r");
    f3 = fopen("even.txt", "r");
    printf("\n奇数文件内容\n");
    while((number = getw(f2)) != EOF)
        printf("\n%d\n", number);
    printf("\n偶数文件内容\n");
    while((number = getw(f3)) != EOF)
        printf("\n%d\n", number);
    fclose(f2);
    fclose(f3);
}
```

编写一个程序将两个文件的内容合并到第三个文件中。在每行的开头添加行号。

```c
#include <stdio.h>
#include <conio.h>
#include <process.h>

void main() {
    FILE *f1, *f2, *f3;
    char ch;
    int n = 1;
    clrscr();
    f1 = fopen("text1.txt", "r");
    f2 = fopen("text2.txt", "r");
    f3 = fopen("text3.txt", "w");
    if (f1 == NULL || f2 == NULL || f3 == NULL) {
        printf("error in file opening");
        exit(1);
    }
    fprintf(f3, "%d", n); // 修正：使用 fprintf 写入行号，而非 putw
    while (!feof(f1)) {
        ch = fgetc(f1);
        fputc(ch, f3);
        if (ch == '\n') {
            n++;
            fprintf(f3, "%d", n);
        }
    }
    while (!feof(f2)) {
        ch = fgetc(f2);
        fputc(ch, f3);
        if (ch == '\n') {
            n++;
            fprintf(f3, "%d", n);
        }
    }
    fcloseall();
    f3 = fopen("text3.txt", "r");
    printf("%d", getw(f3));
    while (!feof(f3)) {
        ch = fgetc(f3);
        printf("%c", ch);
        if (ch == '\n')
            printf("%d", getw(f3));
    }
}
```

## 12.3.3 `fprintf` & `fscanf` 函数

`fprintf` 和 `fscanf` 函数与 `printf` 和 `scanf` 函数相同，不同之处它们作用于文件。这些函数的第一个参数是文件指针，它用于指定要使用的文件。

### 12.3.3.1 `fprintf` 的通用格式为

其中 `fp` 是与已打开用于写入的文件关联的文件指针。控制字符串是文件输出规格列表，可能包括变量、常量和字符串。

```c
fprintf(f1, "%s %d %f", name, age, 7.5);
```

在这里 `name` 是一个 `char` 类型的数组，`age` 是一个 `int` 变量。

### 12.3.3.2 `fscanf` 的通用格式

```c
fscanf(fp, "controlstring", list);
```

该语句将导致读取控制字符串中的项。
像 `scanf` 一样，`fscanf` 也返回成功读取的项数。

```c
fscanf(fp, "%s %d", item, &quantity);
```
