## 深入探讨

在编程语言中，我们主要使用数组来存储和管理数据。然而，数组只能存储特定类型的数据，例如 `int` 和 `char`。为了解决这个问题，`.NET Framework` 引入了用于数据存储和检索的集合概念；其中集合意味着不同类型数据的组。集合允许你存储不同类型的数据以及添加、删除或修改这些数据类型的各个元素。它还提供自动内存管理和容量扩展。内置集合类已在 `.NET Framework 1.1` 中引入，并在最新版本中也保留了下来。`System.Collections` 命名空间提供了各种类，例如 `ArrayList` 和 `Stack`，以便轻松操作数据。一些集合类还提供基于索引值或元素相关联的键值的搜索和排序功能。

然而，集合并非没有局限性。例如，集合的一个重要限制是它只能存储对象类型，而不能存储原始类型。泛型的概念已在 `.NET Framework 2.0` 中引入，以克服集合的这一限制。泛型是一种固定数据结构，可以通过向其传递不同类型的参数来重用。它们允许类、结构、接口、委托、原始类型和方法作为参数传递以存储和修改数据。换句话说，泛型用于在软件组件中提供代码的重用性。在 `.NET` 中，你可以创建泛型集合，该集合可以使用各种泛型类（如 `List<T>` 和 `Dictionary<TKey>`）以类型安全的方式处理任何数据类型的项目集合。

在本章中，你将学习 C# 中的集合和泛型。本章首先探讨集合的概念和各种集合类，例如 `ArrayList`、`Hashtable`、`Stack` 和 `Queue`。接下来，你将学习泛型及其类，例如 `List<T>` 和 `Dictionary<TKey>`。此外，你还将学习泛型中的协变和逆变机制。在立即解决方案部分，你将学习创建使用 `.NET Framework 4.0` 的不同集合和泛型类的应用程序。

让我们从了解集合的概念开始。

## 理解集合

作为程序员，你经常会遇到需要将大量值存储在同一名称下的情况。在这种情况下，数组有助于存储相同类型的对象。你可以声明任何类型的数组并为其分配值，该值稍后可以使用索引检索。

以下代码片段显示了如何定义不同类型的数组：

```
int[] ArrInt;
string[] ArrStr;
MyUDT[] ArrMyUDT;
object[] ArrObj;
```

如果你事先不知道数组需要保存的元素数量，数组始终可以在以后重新定义以保存更多或更少的元素。在以下代码片段中，我们重新定义 `ArrInt` 数组以保存与 `ItemCount` 变量值一样多的值：

```
if (ItemCount > 2000) ReDimPresvInt(ref ArrInt,ItemCount);
for (int i = ItemCount - 2000; i < ItemCount; i++)
    ArrInt[i] = i;
```

现在，使用数组的一个限制是，即使用指定的大小声明的数组也不会自动调整大小。`.NET` 以集合的形式提供了此问题的解决方案。集合在处理大小动态变化方面更优化。数组和集合之间的区别在于，在集合中，你不需要提前指定集合的大小。随着向集合添加新元素，它会自动调整大小以容纳额外元素。

在 C# 中，每个 Windows 窗体都使用 `ControlCollection` 类的 `Controls` 属性维护其上的所有控件的集合。此类在 `System.Windows.Forms.Control` 命名空间中定义。它专门用于创建 `Control` 类或其派生类的对象的集合。添加到窗体的任何控件都会添加到 `Controls` 集合中，如以下代码片段所示：

```
private void button1_Click(object sender, System.EventArgs e)
{
    TextBox NewTextBox = new TextBox();
    NewTextBox.Size = new Size(120, 20);
    NewTextBox.Location = new Point(100, 100);
    NewTextBox.Text = "Hello from visual C#";
    this.Controls.Add(NewTextBox);
}
```

在前面的代码片段中，使用了 `ControlCollection` 类的 `Add()` 方法将一个 `TextBox` 控件添加到窗体中。此方法会自动为要添加到集合中的控件分配空间。因此，使用集合而不是数组来保存窗体上的控件的优点是，你无需事先指定要添加到窗体中的控件数量。你可以根据需要向窗体添加任意数量的控件，而无需编写任何分配空间的代码。

`.NET` 还提供了几个通用集合类，可用于创建任何数据类型的数据集合。让我们详细了解这些类。
