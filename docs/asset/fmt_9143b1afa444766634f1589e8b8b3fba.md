## 主成分分析 (PCA)

主成分回归是 QSAR 分析的流行方法之一。主成分（PCs）是描述符的正交线性组合。之后，我们引入了多维描述符空间，并在其中引入了欧几里得度量。在这个空间中，我们用坐标等于该化合物描述符值的点来表示该化合物。在这个空间中，像熟悉的 2D 和 3D 空间一样，我们也可以引入其他对象。例如，我们可以引入线和向量。我们还可以想象平面上或 3D 空间中的点分布。点可以均匀分布在某个正方形或平面上，或者点云在某些方向（不与坐标轴重合的方向）上被拉伸。对于高维描述符空间也是如此。我们可以想象一个方向（或轴），在该方向上的点分布最大。这个方向定义了第一个主成分。我们可以将所有点投影到这个方向上。假设在该轴上引入了一个零点，那么点 $i$ 在该方向上的投影可以用数字 $V_{i1}$ 表示，然后我们可以计算这些投影点的方差 $Var_1$：

```
Var_1 = \frac{\sum_{i=1}^M (V_{i1} - \mu_{v1})^2}{M-1} \quad (6.18)
```

其中 $\mu_{v1}$ 是所有 $V_{i1}$ 的平均值。对于第一个主成分，投影在其上的点方差在多维描述符空间的所有方向中是最大的。那么可以定义第二个主成分为与第一个主成分正交的方向，其投影点的方差在所有方向中也是最大的。

## 预测性定量结构活性关系建模

### 离群值检测与剔除

在本章较早的节中，我们引入了多维描述符空间，在该空间中，每个化合物被表示为一个点，其坐标等于它的各个描述符值。我们也可以将描述符视为“化合物”空间中的向量。在这种情况下，描述符值由公式 6.20 的第一个公式定义，但为了简便，我们将使用上角符号。例如，向量 $X_i = \{X_{i1}, X_{i2}, ..., X_{im}\}$。在不失一般性的情况下，我们减去所有对应描述符值的平均值。对于“化合物”空间，我们可以定义一个单位向量。例如，对于空间中的向量 $D$，单位向量将是 $e = D/|D|$。我们还可以定义两个空间的点积。例如，$X_iX_j = X_{i1}X_{j1} + X_{i2}X_{j2} + ... + X_{im}X_{jm}$。两个描述符之间的相关系数将定义为它们之间的余弦角：

```
R_{ij} = \cos(\alpha_{ij}) = \frac{|X_i|}{|X_j|}. \quad (6.23)
```

假设在步骤 (i) 中我们选择了 $X_1$ 和 $X_2$。在步骤 (ii) 中，我们根据以下公式定义正交基：

```
e_1 = \frac{X_1}{|X_1|}, \quad (6.24)
```

```
e_2 = \frac{X_2 - (R_{12}|X_2|)e_1}{|X_2| - (R_{12}|X_2|)e_1|} = \frac{X_2 - (e_1X_2)e_1}{|X_2| - (e_1X_2)e_1|}. \quad (6.25)
```

```
e_3 = \frac{X_3 - (e_1X_3)e_1 - (e_2X_3)e_2}{|X_3| - (e_1X_3)e_1 - (e_2X_3)e_2|}. \quad (6.26)
```

在公式 6.25 中，我们将 $R_{12}$ 替换为值 $\alpha$。在步骤 (iii) 中，我们在剩余的描述符中选择下一个描述符。在步骤 (iv) 中，我们使用 Gram-Schmidt 正交化程序，$e_3$ 正交于向量 $e_1$ 和 $e_2$ 定义的平面，且 $X_3$ 与 $e_3$ 之间角的余弦值等于 $X_3$ 与向量 $e_1$ 和 $e_2$ 定义的平面之间角的正弦值。因此，

```
\sin \alpha_3 = \frac{|e_3X_3|}{|X_3|}. \quad (6.27)
```

且向量 $X_3$ 与向量 $X_1$ 和 $X_2$ 的所有线性组合之间的最大相关系数将为 (步骤 (v))

```
R_3 = \sqrt{1 - \frac{(e_3X_3)^2}{|X_3|^2}} \quad (6.28)
```

因此在步骤 (iii) 中，选择使得公式 6.28 中 $R_3$ 最接近零的描述符。现在，回到步骤 (iii) 并选择下一个描述符。为该描述符计算 $e_k$ 和 $R_3$，并比较 $R_3$（新）与 $R_3$（旧）。如果 $|R_3(new)| < |R_3(old)|$，则保留新描述符并丢弃旧的。否则，保留旧的并寻找 $|R_3|$ 的。保留该描述符和相应的 $e_k$。继续该程序。在步骤 $k$ 中，选择描述符 $X_k$ 使得：

```
e_k = \frac{X_k - \sum_{i=1}^k (e_iX_k)e_i}{X_k - \sum_{i=1}^k (e_iX_k)e_i} \quad (6.29)
```

```
\sin \alpha_k = \frac{e_kX_k}{|X_k|} \quad (6.30)
```

```
R_k = \sqrt{1 - \frac{(e_kX_k)^2}{|X_k|^2}} \quad (6.31)
```

当没有剩余描述符，或者当没有找到对应相关系数低于阈值的描述符时，程序结束。

### QSAR 研究前的离群值检测与剔除

QSAR 建模的成功取决于为 QSAR 研究选择合适的数据集。在《化学信息与建模杂志》最近的一篇社论中……

**杠杆（结构）离群值：** 在描述符空间的背景下，必须考虑包含在数据集中的化合物之间的相似性。数据集中的孤立点是离群值的首选候选者。在 QSAR 研究中，这些化合物并未被排除在数据集之外；如果它们被分配到测试集，可能会显著恶化模型统计数据；如果它们被分配到验证集，则会损害泛模型的密度。这类离群值将被称为杠杆离群值。相对简单。然而，使用所谓的矩阵对角线元素（或到数据质心的马哈拉比距离，这些被称为“杠杆”）来检测离群值的标准程序可能检测不到所有的离群值。描述符空间中的数据集在分布几何中心附近可能存在极密度区域。因此，应该在这些区域检测离群值。在这些情况下，标准程序可能不起作用。因此，我们已经基于球体排除算法建议了以下程序：

程序的输入是距离截断值：

- i. 计算距离矩阵或相似性矩阵。
- ii. 对于数据集中的所有化合物，找到它们的最近邻居。
- iii. 如果某个化合物在给定的距离截断值内没有最近邻居，则该化合物在该截断值下是离群值。

由于我们预先不知道给定描述符空间中数据集的属性，距离截断值可以定义为：

- i. 计算数据集中所有邻居间距离的平均值 (*D*) 和标准差 *s*。
- ii. 对于用户定义的一组 Z-截断值，计算不同的距离截断值为：

```
D_{cutoff} = \langle D \rangle + Zs. \quad (6.33)
```

典型的 Z-截断值从 0 到 5，步长为 0.1。

- iii. 针对每个 $D_{cutoff}$ 重复杠杆离群值程序。

当然，Z-截断值越高，离群值就越少。训练集中包含的化合物越多，模型 AD 越大。另一方面，我们预计通过剔除更多离群值，可以建立统计数据更好的模型。因此，我们建议使用不同的 Z-截断值（以及不同数量的杠杆离群值）建立模型。因此，我们期望建立更好统计数据的 QSAR 模型并确定自然的 Z-截断值和 $D_{cutoff}$ 值。整个程序可以完全自动化。另一种方法由以下步骤组成。

- i. 找到所有最近邻居之间的最小距离 $D_{min}$ 和最大距离 $D_{max}$。
- ii. 定义一组 $D_{cutoff}$ 距离，均匀划分区间 $[D_{min}, D_{max}]$。
- iii. 对于每个 $D_{cutoff}$，寻找离群值。
- iv. 如果必要，计算对应 $D_{cutoff}$ 值的 Z-截断值：$Z = (D_{cutoff} - \langle D \rangle)/s$。

在这些计算中，我们可以使用不同的距离和相似性测量方法。寻找杠杆离群值的程序也可适用于检测描述空间中远离其他化合物的类。例如，如果化合物 $a$ 只有一个邻居 $b$，且 $b$ 的最近邻居是 $a$，那么 $a$ 和 $b$ 构成一个类。可选地，可以从数据集中移除该类，如果这些化合物被分配到训练集，它们将是训练集中的离群值（未发表）。

对于连续变量的情况，在本节中我们描述了一种使用球体排除算法的方法：

- 在描述空间中的一个代表性点周围建立一个半径为 $R$ 的探测球。半径 $R$ 的定义是球内至少有三个点。
- 使用 Dixon 测试寻找球内的离群值。将数据按升序排列。对于具有最高和最低活性的化合物，根据表 6.2 计算 $\tau$ 统计量。如果 $\tau$ 统计量大于界值，则拒绝假设，具有最低活性的化合物是离群值。如有必要，对剩余化合物重复 Dixon 测试。该测试的精度会随着每次重复而降低。
- 重复所有化合物（步骤 i）。如果描述空间中存在“悬崖”，我们可能可以将整个数据集分成足够大的非离群值组，并为它们建立的 QSAR 模型。

为了将一个化合物视为离群值，我们建议使用额外的标准：离群候选化合物与其活性接近的化合物之间的活性差异应小于数据集整个活性范围的 10% 或 20%。该算法允许寻找孤立的离群值（即探测球内只有一个离群值）以及离群值组。我们的实验表明，在后者的情况下，少量与目标化合物接近的其他化合物也可以被检测为可能的离群值。我们建议在此程序的基础上，增加一个额外的相似性搜索，以检测额外的候选离群值。

对于活性数据的对数形式，可以使用 Grub 检验。环境保护署推荐使用该检验。根据该检验，将所有活性按升序排列，并计算数据的均值 $\bar{x}$ 和标准差 $s$。然后计算活性最高和最低化合物的 $\tau$ 统计值，如下：

```
\tau_{low} = \frac{\bar{x} - x_1}{\sigma} \quad and \quad \tau_{high} = \frac{x_n - \bar{x}}{\sigma} \quad (6.34)
```
