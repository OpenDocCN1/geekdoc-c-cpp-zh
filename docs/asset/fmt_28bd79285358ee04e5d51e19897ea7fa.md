# `seekp` 和 `seekg` 成员函数

`seekp` 用于设置写入指针的位置，`seekg` 用于设置读取指针的位置。`p` 代表 **put**（写入），`g` 代表 **get**（读取）。

第一个参数是偏移量，第二个参数是模式标志。

常用的模式标志包括：
- `ios::beg`：从文件开始计算偏移量。
- `ios::end`：从文件末尾计算偏移量。
- `ios::cur`：从当前位置计算偏移量。

```cpp
people.seekp(10, ios::beg); // 将写入指针移动到文件开始的第10个字节
people.seekg(-5, ios::end); // 将读取指针移动到文件末尾向前第5个字节
```

```cpp
  char ch;

   // 从字母文件末尾获取第10个字节
  file.seekg(-10L, ios::end);
  file.get(ch);
  cout << "从末尾的第10字节: " << ch << endl;
   // 从当前位置向前移动三个字节
  file.seekg(3L, ios::cur);
  file.get(ch);
  cout << "从当前的第3字节: " << ch << endl;
   // 关闭文件
  file.close();
  return 0;
}
```

## tellp 和 tellg 函数

文件流有两个可以用于随机访问的成员函数：`tellp` 和 `tellg`。它们的作用是作为长整型返回文件读取和写入位置的当前字节数。正如你所能到的，`tellp` 用于返回写入位置，而 `tellg` 用于返回读取位置。假设 `pos` 是一个长整型，以下是用法示例：

```cpp
pos = outfile.tellp();
pos = infile.tellg();
```

```cpp
// 此程序演示了 tellg 函数。
#include <iostream>
#include <fstream>
#include <cctype> // 用于 toupper
using namespace std;
int main()
{
    // 读取文件的变量
    long offset;
    char ch;
    char response;
    // 创建文件对象并打开文件
    fstream file("letters.txt", ios::in);
    if (!file)
    {
        cout << "打开文件错误";
        return 0;
    }
    // 操作文件
    do
    {
        // 我在当前文件的哪个位置？
        cout << "当前位于位置 " << file.tellg() << endl;
        // 获取用户提供的偏移量
        cout << "输入偏移量: ";
        cin >> offset;
        // 在指定位置读取字符
        file.seekg(offset, ios::beg);
        file.get(ch);
        cout << "读取到的字符: " << ch << endl;
        // 询问继续吗？
        cout << "继续吗? ";
        cin >> response;
    } while (toupper(response) == 'Y');
    file.close();
    return 0;
}
```
