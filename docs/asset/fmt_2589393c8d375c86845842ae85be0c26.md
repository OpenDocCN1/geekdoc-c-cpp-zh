
`Data Source=.;Initial Catalog=Northwind;Integrated Security=True`

SQL Server 连接字符串的参数讨论如下：

- `Data Source` – 表示您需要连接到的 SQL Server 实例的名称或网络地址。
- `Initial Catalog` – 表示数据库的名称。
- `Integrated Security` – 接受两个值：`True` 和 `False`。如果值为 `False`，则需要在连接中指定 `User ID` 和 `Password`。如果值为 `True`，则使用当前 Windows 帐户凭据进行身份验证。默认值为 `True`。

另一种类型的数据源是 OLEDB 数据提供程序。您可以使用 OLEDB 数据提供程序访问 SQL、Access 和 Oracle 数据库。在本例中，我们使用了 Access 数据库或 MS Jet 数据库。您需要为 MS Jet 数据库传递以下连接字符串：

```
"Provider=Microsoft.Jet.OLEDB.4.0;Data Source=D:\C#_BB\Northwind Database Files\Northwind.mdb"
```

MS Jet 连接字符串的参数讨论如下：

- `Provider` – 表示您想要访问的数据库的类型
- `Source` – 表示存储在您机器上的数据库文件的路径

对于 Oracle 数据源，您需要传递以下连接字符串：

```
"Data Source=Oracle81;Integrated Security=yes"
```

Oracle 连接字符串的参数讨论如下：

- `Data Source` – 表示您需要连接到的 Oracle 实例的名称或网络地址。
- `Integrated Security` – 表示连接是否安全。它取两个值：`Yes` 和 `No`。默认值为 `Yes`。

对于 ODBC 数据源，您需要传递以下连接字符串：

```
Dsn=myDSN;UID=;Pwd=;
```

在 ODBC 连接字符串中，`Dsn` 是唯一传递的参数，它存储有关您的数据源的信息。
