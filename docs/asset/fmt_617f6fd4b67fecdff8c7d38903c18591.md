## MOVF 移动 f

**语法：** `MOVF f, d (d, a)`

**操作数：**

- `0 ≤ f ≤ 255`
- `d ∈ {0, 1}`
- `a ∈ {0, 1}`

**周期：** 1

| :--- | :--- | :--- | :--- |

**示例：** `MOVF REG, 0, 0`

- `REG = 22h`
- `W = FFh`

指令执行后：

- `REG = 22h`
- `W = 22h`

## MOVFF 将 f 移动到 f

**语法：** `MOVFF f_src, f_dst`

**操作数：**

- `0 ≤ f_src ≤ 4095`
- `0 ≤ f_dst ≤ 4095`

**操作：** `(f_src) → f_dst`

**受影响的状态：** 无

| 1110 | ffff | ffff | f |

**周期：** 2 (3)

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 读取寄存器 `f_src` | 处理数据 | 无操作 |
| 解码 | 无操作 / 无虚读取 | 无操作 | 写入寄存器 `f_dst` |

**示例：** `MOVFF REG1, REG2`

指令执行前：

- `REG1 = 33h`
- `REG2 = 11h`

指令执行后：

- `REG1 = 33h`
- `REG2 = 33h`

### RCALL 相对调用

**语法：**

`RCALL n`

**操作数：**

`-1024 ≤ n ≤ 1023`

**操作：**

`(PC) + 2 → TOS`,

`(PC) + 2 + 2n → PC`

**受影响的状态位：**

无

**编码：**

| 1101 | nnnn | nnnn | nnnn |

**描述：**

子程序调用，跳转距离当前位置可达 1K。首先，将返回地址 (`PC + 2`) 压入栈中。然后，将二进制补码数 `2n` 加到 `PC` 上。由于 `PC` 会递增以获取下一条指令，因此新地址将是 `PC + 2 + 2n`。这是一条双周期指令。

**字数：**

1

**周期数：**

2

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
|---|---|---|---|
| 解码 | 读取字面量 `n` 将 `PC` 压入栈 | 处理数据 | 写入 `PC` |
| 无操作 | 无操作 | 无操作 | 无操作 |

**示例：**

```
HERE RCALL Jump

指令执行前
   PC = Address (HERE)

指令执行后

```
