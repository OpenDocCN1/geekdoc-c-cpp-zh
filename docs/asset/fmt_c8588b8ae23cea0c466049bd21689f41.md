
```
catch (DivideByZeroException e)
{
    Console.WriteLine("Exception caught: {0}", e);
}
finally
{
    Console.WriteLine("Result: {0}", result);
}
}
```

查看上面的代码，了解 `try catch` 语句在实际应用程序中的工作原理。

我们创建了一个除法两个数字的函数。该函数接收两个参数，用于计算两个数字的除法。正如你在数学课上回想的那样，你不能除以零。如果你的代码中没有任何类型的 `try catch` 语句，用户可能会意外发送 0 值作为分母，并导致你的代码出现错误。当你这样做而没有考虑到错误时，你的程序就会崩溃，用户也会对其功能感到沮丧。你可以通过使用 C# 语言中包含的 `try catch` 语句来克服这个问题。

如果用户为分母传递了 0 值，`catch` 代码块会捕获它并以友好的方式处理。当程序出现问题时（即使是因为用户自己的输入），这对你的用户来说是非常重要的。`catch` 语句防止了程序以不友好的方式崩溃，并以你希望在程序中使用的方式来处理错误。

在这个示例中，我们根据程序操作系统的返回的信息向用户显示错误。`catch` 块向用户显示代码中发现了错误，并显示了相关信息。此错误也是从操作系统返回的。这段代码对于调试很有用，但对于真实世界的应用可能并不理想。然而，如何处理你的编码错误取决于你。

你的 `catch` 块的最后一个部分是 `finally` 部分。请记住，当你需要最终处理任何错误并更改代码以确保程序正常关闭且不会导致程序中产生更多额外 bug 时，这就是你想要添加的代码块。

在我们的 `finally` 块中，我们打印出结果，无论是有效的结果值还是我们代码中的错误。

在你的代码中创建错误处理只需要这些。只需记住，你应该创建用户友好的错误，以避免给用户带来困惑。这一章为你提供了一个示例，但你可以使用任何适合你的程序以及你的用户所需的错误处理风格。

## 实验问题

  - b. `catch`
  - c. `finally`
  - d. `error`
  > 解释：`try` 语句封装了你用于错误处理的代码，以便为用户提供友好的错误信息。

  - b. `catch`
  - c. `finally`
  - d. `error`
  > 解释：`finally` 块运行最后一段代码，直到程序退出或继续。

# 结语

这是你作为 C# 程序员的旅程的起点。通过本指南，你仅仅触及了皮毛，因为学习语言的语法和规范只是开始。编程中最重要的部分是它的逻辑方面。当然，你可能知道如何遍历变量数组（如购物清单列表），但如果有人要求你利用你的编程知识来处理图像，在 API 和一些你可以研究出来的东西帮助下，你可以弄出如何反转图像颜色、翻转、旋转、缩放等。

编程的知识和理解真的是非常伟大的，因为它是我们最接近魔法力量的东西。你可以字面上地从一个空白记事本从零开始创建一个东西，并让它执行你想做的事。无论是分析和预测股票市场的机器人，还是视频游戏，选择权掌握在你手中。

在本指南中，你学习了 C# 的基础知识。你还没有学习该语言中可以使用的所有方法，但并不是重点。本指南旨在引导你开启一段旅程，发现帮助你所需的对象和方法。
