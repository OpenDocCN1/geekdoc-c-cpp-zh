
    `size_t stride() const`;

    `friend bool operator==(const gslice& x, const gslice& y)`;

  };

```

`gslice` 表示一个通用切片。它由偏移量（s）、维度数量（l）和步长（d）定义。多维索引 $i_j$ 的范围从 0 到 $l-1$。索引 $k$ 的计算公式：

$k = s + \sum_{j} i_j d_j$

示例 1：`gslice` 指定
`start = 3`
`length = (2, 4)`
`strides = (19, 4)`
产生一维索引序列，如下表所示：

| $i_0$ | $i_1$ | $i_2$ | $k$ |
| :--- | :--- | :--- | :--- |
| 0 | 0 | 0 | 3 |
| 0 | 0 | 1 | 4 |
| 0 | 0 | 2 | 5 |
| 0 | 1 | 0 | 7 |
| 0 | 1 | 1 | 8 |
| 0 | 1 | 2 | 9 |
| 0 | 2 | 0 | 11 |
| 0 | 2 | 1 | 12 |
| 0 | 2 | 2 | 13 |
| 0 | 3 | 0 | 15 |
| 0 | 3 | 1 | 16 |
| 0 | 3 | 2 | 17 |
| 1 | 0 | 0 | 22 |
| 1 | 0 | 1 | 23 |
| ... | ... | ... | ... |
| 1 | 3 | 2 | 36 |

也就是说，最高阶索引运行最快。 — 示例。

# ISO/IEC 14882:2020(E)

(0, 1, 1, 5),
(0, 1, 2, 6),
...

6 如果将退化的尺寸作为 `operator()` 非 const 版本（`const gslice&`）的参数，则行为是未定义的。
