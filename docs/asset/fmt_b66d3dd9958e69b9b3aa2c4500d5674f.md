## 5.- 解释型语言和编译型语言

计算机上编写的任何程序都必须翻译成机器语言。

机器语言是一种依赖于 CPU 类型和制造商的语言，并且有许多版本。

由于机器语言非常复杂且随平台变化，因此有一些（更类似于英语的）语言，用于指示要遵循的步骤序列（程序）。这些语言被称为源代码语言，用于定义计算机程序。

一旦代码以源语言形式存在，我们必须通过翻译器将其翻译成机器语言，这才是计算机真正理解的语言。

根据从源代码生成机器语言的方式，有三种类型的翻译。

### 解释型语言

翻译器逐行读取源程序，进行翻译，然后由计算机执行。

使用这种方式，程序在编写时开发速度更快，但缺点是更容易出错，而且这些错误更难纠正。

这类语言的示例有 JavaScript 或 PHP。

### 编译型语言

编辑程序后，将其整体翻译（编译）。

此时，由于程序结构可能产生的语法错误会显示给操作者。

使用这种方式，开发速度会减慢，因为每次修改程序后都必须编译，但错误处理更简单，更容易调试。

编译型语言的示例有 C、C++。

### 混合型语言

这些语言先被编译成中间语言，然后再解释成机器语言。

它们具有编译型语言的相同优点，但更可移植，可以在不同操作系统的机器上运行。

示例：C# 或 Java。


执行该程序，我们将看到一个显示文本 Hello World ... 的屏幕。

我们将遵循的编写程序阶段如下：

### 阶段1：定义要解决的问题并编写算法（要遵循的步骤）

在这个阶段，我们必须明确定义我们想要程序做什么，它将接收哪些输入，以及将产生哪些输出。

我们还必须用自然语言（西班牙语、英语……）说明程序应遵循哪些步骤来实现既定目标。

这些要遵循的步骤就是我们所说的程序算法。

### Phase 2. 编辑程序

一旦我们知道要做什么，就必须思考如何将该功能翻译成我们选择的编程语言，在本例中为 C。

然后我们将在 Visual Studio 的编辑器中用 C 编写程序。

你可以用简单的文本编辑器如记事本编辑程序，但集成环境具有多重优势，例如缩进（让我们能更好地可视化程序）或为不同功能关联颜色（以便一目了然地看到关键字、数据类型等）

### Phase 3. 编译

程序编辑完成后，我们对其进行编译并查看是否出现语法错误。

语法错误发生是因为编译器无法理解我们在源语言中引入的某行代码。

编译器负责将 C 源代码翻译成机器语言。

### Phase 4. 链接

如果我们的项目由多个文件或模块组成，在链接过程中，外部引用会被分组并解析。

如果我们的程序此时使用了编译器或操作系统的外部功能，则会添加对外部源的引用。

链接过程完成后，会生成一个可执行文件（Windows 下为 `.exe`）。

### Phase 5. 执行

在此阶段我们可以执行可执行程序并查看结果是否符合预期。

如果我们检测到任何错误，必须返回编辑阶段并做出必要的更改。

在此阶段，可能出现运行时错误，因为某些变量取值超出其限制或程序逻辑存在错误。

### Phase 6. 调试

如果运行时出现错误或预期功能未正确实现，我们可以在编程环境中调试程序。

一些有用的工具是

- 逐步执行程序的选项
- 告诉程序在给定代码的行处停止执行。
- 实时显示变量的值。

### Phase 7. 测试和维护

程序必须在所有可能的情况下进行测试，如果发现故障，我们必须再次回到编辑阶段

一旦程序正确运行，它就进入 Exploitation 阶段，在其真实环境中执行（例如在请求程序的客户计算机上）

然后程序进入其维护阶段，客户会要求我们添加新功能或修改程序，因为某些功能不符合他的喜好。

## 11.- 基本概念 .. 内存 位和字节

程序及其使用的数据都存储在计算机的内存中。

计算机的内存是一系列用于存储 0 值或 1 值的“盒子”。这些“盒子”就是位，是计算机可以存储的最小信息单元。

为了提高内存访问效率，这些位可以每 8 个一组形成一个字节。

计算机的内存以字节的倍数表示

1 千字节（或 1KB）为 1,024 字节。

1 兆字节（或 1MB）为 1,024 千字节，即 1,048,576 字节。

1 千兆字节（或 1GB）为 1,024 兆字节，即 1,073,741,824 字节

## 12.- 变量。 整数和实数

### 变量

变量是 1 个或多个字节的内存区域，与其关联一个名称，以便在程序中引用它。

### 整数变量

是存储没有小数的整数的变量。

变量的类型为 `int`

整数例如为 -10、5、23000

### 示例

```
/* using integers */
#include <stdio.h>

int main (void)
{
    /* declare the variable age as of integer type */
    int age ;

    /* assignment of an integer value to the variable */
    age = 35;

    /* show age by screen */
    printf ("My age is% d.", age);
    return 0;
}
```

### 变量名

我们可以给变量起的名字是数字和字母的组合。

变量不能以数字开头

例如 `Var1`、`age`、`name551nteger`

### 字符变量

是存储字符的变量

字符变量的类型为 `char`

例如 `car = 'A';`

### 实数变量

这些是可以存储带小数点的数字的变量。

小数点用 . 表示（不是用 ,，如西班牙语）

实数变量的类型为 `float`

例如 2.9 34.89

### 示例

```
/* using real */
#include <stdio.h>

int main (void)
{
        /* declare variable as an integer value */
        float myvariable;

        /* assignment of a real value to the variable */
        myvariable = 12.75;

        /* display the variable by screen */
        printf ("My variable is% f.", myvariable);
        return 0;
}
```

## 17.- 逻辑比较

在我们的程序中，我们需要对在几个选项之间进行选择做出决策，根据值之间的比较决定执行哪段代码。

为此，C 语言为我们提供了多个语句，以便根据评估结果选择执行某些指令还是其他指令。

### `if` 语句

用于评估表达式，如果结果为真，则执行下一条指令块。

例如，假设我们需要在屏幕上写出你的年龄是否小于或大于 20。

```c
int age;

age = 26;
if (age < 20)
    printf("age less than 20 ...");

if (age >= 20)
    printf("over age 20 ...");
```

### `if`-`else` 语句

与 `if` 语句相同，但如果要评估的表达式为假，则执行 `else` 块。

例如，用 `if`-`else` 语句编写前一个示例的另一种方式：

```c
int age;

age = 26;
if (age < 20)
    printf("age less than 20 ...");
else
    printf("over age 20 ...");
```

你可以在 `if` 或 `else` 中放入多行代码，用 `{ }` 将其括起来。

例如

```c
int age;

age = 26;
if (age < 20)
{
    printf("age less than 20 ...");
    printf("is young");
}
else
{
    printf("over age 20 ...");
    printf("is greater");
}
```

## 18.- 关系运算符和逻辑运算符

我们可以在逻辑表达式中使用的关系运算符有：

- `==`
- `>`
- `<`
- `>=`
- `<=`
- `!=`

我们可以用逻辑运算符组合多个表达式：

- `&&`
- `||`
- `!` (非)

例如，如果我们想在屏幕上显示你是否属于青少年（年龄在 15 到 20 之间）或是否未成年（18 岁以下）：

```c
int age;

age = 26;
if (age > 15 && age < 20)
{
    printf("you are a teenager ...");
}
if (!(age > 18))
{
    printf("you are a minor ...");
}
```
