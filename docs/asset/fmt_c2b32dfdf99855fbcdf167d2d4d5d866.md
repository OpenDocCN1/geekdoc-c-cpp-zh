## 词汇表

**angle (角度):**
线条在角处转过的度数。

![](img/a962ec79491408ecc743f3f11c25a851_49_0.png)

**for loops (for 循环):**
你可以控制起始值、结束值和递增量的循环。

**play space (运行区域):**
网站上用于查看代码运行效果的区域。

**block-based language (基于块的语言):**
一种使用类似拼图的代码块来创建程序的编程语言。

**function (函数):**
一段命名的代码，你可以在程序中任何需要的时候调用它。

**program (程序):**
一组给计算机的指令。

**Blockly:**
一种视觉化编程语言，允许你通过拖放和放置代码来创建程序。

**function editor (函数编辑器):**
一个弹出的框，允许你创建或编辑函数内部的代码。

**remix (混编/重制):**
保存程序的副本并将其构建成新的内容。这允许你使用已经创建的函数和代码段，而不是从头开始构建。

**call a function (调用函数):**
要求计算机运行函数内部的代码。

**increment (递增):**
在循环每次执行时，你的计数器增加（或减少）的数值。

**repeat loop (重复循环):**
允许你按照指定的次数重复执行一段代码序列的块。

**code (代码):**
给计算机的指令。

**coding (编码):**
创建代码的过程。

**inner angles (内角):**
从形状内部测量的角度。

**sequence (序列/顺序):**
事物排列的顺序。

**computer science (计算机科学):**
对计算机和计算机相关概念的研究。

**loop (循环):**
一段反复运行的代码，其间不执行任何其他操作。

**software (软件):**
运行在机器或计算机上的程序。

**counter (计数器):**
一个占位符，用于跟踪每次循环中增加（或减去）的数值。

**nested functions (嵌套函数):**
放置其他函数内部的函数。

**starting value (起始值):**
计数器在循环中开始的值。

**debugging (调试):**
发现并修复程序中的错误。

**nested loop (嵌套循环):**
放置另一个循环内部的循环。

**toolbox (工具箱):**
网站上用于查找程序代码的区域。

**define the function (定义函数):**
将代码放入函数块中，告诉计算机当程序内部调用该函数时应该做什么。

**parameters (参数):**
允许你自定义块以不同方式执行功能的特殊位置。

**workspace (工作区):**
网站上用于通过拖动代码来创建程序的区域。

**ending value (结束值):**
计数器在循环中停止计数的值。

**pattern (模式):**
重复多次的事物。

**pixels (像素):**
排列在网格中组成图像的小正方形。像素也可以作为指定物体移动距离的测量单位。

**exterior angles (外角):**
角度外部的测量值。
