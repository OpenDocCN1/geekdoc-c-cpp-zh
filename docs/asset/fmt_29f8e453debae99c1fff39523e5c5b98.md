## 10.7 微分方程的数值解

现实应用中出现的许多微分方程无法通过任何已知方法求解。然而，可以通过几种不同的数值技术获得近似解。在本节中，我们将描述所谓的*欧拉法*（Euler's method），用于近似如下形式初值问题的解：

`y' = g(t,y), y(a) = y_0` (1)

其中 `$t$` 位于区间 `a ≤ t ≤ b`。这里，`g(t,y)` 是一个良好的二变量函数。形式 `y' = f(t)y + b(t)`（我们在 10.3 节和 10.4 节学习的线性方程）是 (1) 的特例。

在下文中，假设 `f(t)` 是 `a ≤ t ≤ b` 上 (1) 的解。使用欧拉法的基本思想是：如果 `y = f(t)` 的图像通过某点 `(t,y)`，则该点在该点的斜率（即 `y` 的值）正是 `f(t,y)`，因为 `y' = f(t,y)`。这与我们在 10.1 节讨论斜率时使用的原理相同。欧拉法利用多边形路径来近似 `f(t)` 的图像（见图 1）。

![](img/14f721f1bebc3d5c3302775173a2fdb3_517_1.png)

**图 1** 多边形路径。

从 `a` 到 `b` 的 `$t$` 轴被等间距的点 `t_0, t_1, …, t_n` 分割。`n` 个子区间每个长度为 `h = (b-a)/n`。(1) 中的初始条件 `y(a) = y_0` 意味着解 `f(t)` 的图像通过点 `(t_0, y_0)`。如前所述，图像在 `(t_0, y_0)` 处的斜率必须是 `g(t_0, y_0)`。因此，在第一个子区间，欧拉法通过直线近似 `f(t)` 的图像：

```
y = y_0 + g(t_0, y_0) · (t - t_0),
```

该直线通过 `(t_0, y_0)` 且斜率为 `g(t_0, y_0)`。（见图 2。）当 `t = t_1` 时，`y'` 坐标为：

```
y_1 = y_0 + g(t_0, y_0) · (t_1 - t_0) = y_0 + g(t_0, y_0) · h.
```

由于 `f(t)` 的图像靠近直线上的点 `(t_1, y_1)`，当 `t = t_1` 时，`f(t)` 图像的斜率将接近 `g(t_1, y_1)`。我们画出直线

```
y = y_1 + g(t_1, y_1) · (t - t_1)
(2)
```

通过 `(t_1, y_1)` 且斜率为 `g(t_1, y_1)`，我们用它在第二个子区间上近似 `f(t)`。从 (2) 我们确定了 `t_2 = t_2` 处 `f(t)` 图像的估计值 `y_2`：

```
y_2 = y_1 + g(t_1, y_1) · h.
```

![](img/14f721f1bebc3d5c3302775173a2fdb3_518_0.png)

现在 `f(t)` 图像在 `t_2` 处的斜率由 `g(t_2, y_2)` 估计，依此类推。我们总结这一过程：

| 欧拉法 | 在区间 `a ≤ t ≤ b` 上近似方程 (1) 解的线段端点 `(t_0, y_0), …, (t_n, y_n)` 由以下公式给出，其中 `h = (b-a)/n` |
| :--- | :--- |
| `t_0 = a` (给定) | `y_0` (给定) |
| `t_1 = t_0 + h` | `y_1 = y_0 + g(t_0, y_0) · h` |
