
## 11 强制
`ptr` 应该为空指针，或其值应该表示由调用者向（可能被替换的）`operator new(std::size_t t, 或 operator new(std::size_t t, std::align_val t)` 分配的内存块的地址，且该内存块未被中间插入的 `operator delete` 调用而失效。

## 12 要求
如果实现具有更严格的指针对齐 (`6.7.4.3`)，则 `ptr` 必须是一个安全派生指针。

## 13 要求
如果对齐参数不存在，`ptr` 必须由不带对齐参数的分配函数返回。如果存在，对齐参数应与返回 `ptr` 的分配函数所传递的对齐参数相等。如果存在，大小参数应与返回 `ptr` 的分配函数所传递的大小参数相等。

## 14 强制
带有大小参数的 `operator delete` 调用可以更改为不带大小参数的相应 `operator delete`，且不影响内存。[注：对于 `operator delete(void* ptr, std::size_t size)` 的符合实现应提供 `operator delete(ptr)`。-- 备注结束 --]

## 15 默认
带有大小参数的函数将其其他参数传递给不带大小参数的相应函数。[注：参见上文“可替换”段落。--]

## 16 默认
如果 `ptr` 为空，则不发生任何操作。否则，回收调用者为 `operator delete` 分配的存储。

## 17 备注
不确定回收的存储的某部分或全部将由后续调用 `operator new` 或 `<cstdlib>` 中的任何一个 `alloc`, `malloc`, `calloc` 或 `realloc` 返回。

## 18 影响
实现调用的删除 (`6.7.4.2`) 在从新表达式的新位置调用的构造函数抛出异常时，可能会导致 `ptr` 值失效。

## 19 可替换
C++ 程序可以定义具有这两种函数签名之一的函数，它们将取代 C++ 标准库定义的默认版本。

## 20 要求
`ptr` 应该为空指针，或其值应该表示由调用者向（可能被替换的）`operator new(std::size_t t, 或 operator new(std::size_t t, std::align_val t)` 分配的内存块的地址，且该内存块未被中间插入的 `operator delete` 调用而失效。

## 21 要求
如果实现具有更严格的指针对齐 (`6.7.4.3`)，则 `ptr` 必须是一个安全派生指针。

## 22 要求
如果对齐参数不存在，`ptr` 必须由不带对齐参数的分配函数返回。如果存在，对齐参数应与返回 `ptr` 的分配函数所传递的对齐参数相等。

## 23 默认
分别调用 `operator delete(ptr)` 或 `operator delete(ptr, alignment)`。

## 21.6.4 指针优化屏障 [ptr.launder]

```cpp
template <class T> T* launder(T* p) noexcept;
```

- 要求：`p` 代表内存中某个字节的地址 `A`。在其生命周期内 (`6.8`) 的对象 `X` 的类型与 `T` 相似 (`7.5`)，位于地址 `A`。所有通过结果可达的类型存储都是可达的（见下文）。

- 返回：一个指向 `X` 的 `T*` 类型值。

- 备注：当参数的值在常量表达式中使用时，此函数的调用可以在常量表达式中使用。一个通过指向对象 `Y` 的指针可达的类型存储，如果它位于 `X` 占据的存储内，或者与 `Y` 指针可转换，或者如果 `Y` 是数组元素，则位于紧邻的数组对象内。如果 `T` 是数组或 `void`，则程序是格式错误的。

注意：如果在现有相同类型对象占据的存储中创建了新对象，可以使用指向原始对象的指针来引用该对象，除非该类型包含 `const` 或引用成员；在后的情况下，可以使用此函数获取指向新对象的指针。见 `6.8`。

示例：

```cpp
struct X { const int n; };
X *p = new X(3);
const int a = p->n; // p 不指向对象 (6.8)，因为 X::n 是 const
const int b = p->n; // 未定义行为
const int c = std::launder(p)->n; // OK
```
