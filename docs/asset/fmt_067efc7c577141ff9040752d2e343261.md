## Web Forms 导航和跨页面提交

在 ASP.NET 中，你可以创建动态的网站。当用户请求一个 Web 页面（`.aspx` 文件）时，Web 页面会执行网站所需的任务，例如计算值、读取或写入数据库信息，或调用 Web 服务器上的其他程序。Web 页面动态生成 HTML 或任何其他标记语言作为输出并将其发送到浏览器。

ASP.NET 页面作为代码在 Web 服务器上运行。因此，页面被配置为当用户点击按钮、选择复选框或与 Web 页面中的其他控件交互以在 Web 服务器上处理页面时，可以将页面提交到服务器。每次，Web 页面都会将数据提交回自身，以便它可以再次运行其服务器代码以向用户生成其新版本。Web 页面将数据发送回服务器上的同一页面的过程称为 Web 页面的 postback。

## 立即可用的解决方案

通常，当你构建动态网站时，你可能希望将一个页面发布到另一个页面并附带一些信息。这可以通过以在线银行网站为例来更好地理解，该网站在每个页面上收集不同类型的信息。在这种情况下，你可以配置某些控件，例如页面上的按钮，并将其发布到不同的目标页面，以便当用户点击按钮时，他们会在目标页面上看到信息。这被称为跨页面提交。

## 深入解析

在上一章中，您已经学习了如何创建Web应用程序。现在，让我们来讨论Web窗体控件。Web窗体控件被设计为类似于标准的Windows窗体控件。这些控件用于设计任何Web应用程序的界面，例如，当您访问Google网站时，您会在文本框中输入搜索查询，而文本框就是一种控件。ASP.NET提供了一套标准控件，可用于开发Web应用程序。您可以从Visual Studio集成开发环境（IDE）的“工具箱”中访问所有这些控件。只需将这些控件拖放到Web窗体上的任意所需位置即可轻松使用它们。根据其执行的任务，这些控件被分组到称为“选项卡”的不同类别下。例如，用于验证数据的控件放置在“验证”选项卡下，用于登录网站的控件放置在“登录”选项卡下。类似地，用于常见用途的控件放置在“标准”选项卡下，称为标准控件。所有这些控件都属于`Control`类。Web服务器控件基于`WebControl`类，而`WebControl`类又基于`Control`类。换句话说，`WebControl`类是从`Control`类派生的。

在本章中，您将学习文本框、标签、超链接、HiddenField、RadioButton和CheckBox等不同的服务器控件。
