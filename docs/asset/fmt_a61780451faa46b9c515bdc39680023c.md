
# 连续图例的位置

CONTINUOUS 语句不支持 `CROSS-`、`DOWN-` 和 `ORDER-` 选项。但可以使用 `LOCATION`、`HALIGN`、`VALIGN` 和 `ORIENT` 选项定位连续图例。默认情况下，当 `HALIGN=RIGHT` 或 `HALIGN=LEFT` 时，`LOCATION=OUTSIDE` `ORIENT=VERTICAL`。

# 使用颜色渐变表示值

# 定义基础网格

虽然你可以在默认的 GRIDDED 布局中生成美观的图表，但在大多数情况下，你希望对网格、其填充方式以及单元格内容的复杂性有更多的控制。

## 设置网格维度

假设你想要一个包含五个图表的网格。在开始编写代码之前，你必须先决定要设置什么网格维度（多少列多少行），以及你是否允许网格中存在空单元格。如果你不需要空单元格，则必须将网格限制为五个单元格，这为你提供了两种网格维度选择：五列一行（5x1）或一列五行（1x5）。

要指定网格大小，你在 LAYOUT GRIDDED 语句中使用 `COLUMNS=` 或 `ROWS=` 选项。要使用 `ROWS=`，还必须指定 `ORDER=COLUMNMAJOR`。

可以使用两个显式指定来创建如下网格，它包含一行和五列：

```sas
layout gridded / columns=5;
/* 绘图定义 */
endlayout;
```

当指定了列数时，你限制了每行可以显示的列数。只有在 `ORDER=ROWMAJOR`（默认值）时，`COLUMNS=` 选项才会生效。

在左侧的示例代码中，如果你包含了五个以上的绘图定义，会自动添加额外的行（每行五列），以容纳所有显示这些绘图定义所需的单元格。

```sas
layout gridded / order=columnmajor rows=1;
/* 绘图定义 */
endlayout;
```

当指定了行数时，你限制了每列可以显示的行数。只有在 `ORDER=COLUMNMAJOR` 时，`ROWS=` 选项才会生效。

在左侧的示例代码中，如果你包含了五个以上的绘图定义，虽然网格会自动扩容，但网格不会换行到第二行，因为 `ROWS=` 设置将网格限制为单行。

如果你愿意在网格中留一个空单元格，可以使用 2x3 或 3x2 的网格：

```sas
layout gridded / columns=3;
endlayout;
```

默认情况下，布局使用 `ORDER=ROWMAJOR` 设置来填充网格单元格。此规范本质意味着“填充第一行中的所有单元格（从左上角开始），然后继续到下一行”。默认情况下 `COLUMNS=1`，你必须指定另一种设置来增加网格的列数：

```sas
layout gridded / columns=3;
/* plot1 定义 */
/* plot2 定义 */
/* plot3 定义 */
/* plot4 定义 */
/* plot5 定义 */
endlayout;
```

或者，你可以指定 `ORDER=COLUMNMAJOR`，这意味着“填充左侧列中的所有单元格，并继续到右侧的下一列”。当 `ORDER=COLUMNMAJOR` 时，`ROWS=` 默认为 1，因此你必须指定另一种设置来增加网格的行数：

```sas
layout gridded / rows=2 order=columnmajor;
/* plot1 定义 */
/* plot2 定义 */
/* plot3 定义 */
/* plot4 定义 */
/* plot5 定义 */
endlayout;
```

## 设置间距

为了节省空间，默认的 GRIDDED 布局在单元格边界之间没有间隙。在某些情况下，这可能会导致单元格内容看起来过于拥挤。你可以使用 `COLUMNGUTTER=` 选项在所有单元格之间添加垂直间隙，或者使用 `ROWGUTTER=` 选项在所有行之间添加水平间隙。如果没有指定单位，则为像素（PX）。

```sas
layout gridded / columns=3 columngutter=5 rowgutter=5;
/* plot1 定义 */
/* plot2 定义 */
/* plot3 定义 */
/* plot4 定义 */
/* plot5 定义 */
endlayout;
```

注意，添加间距不会增加图形的大小。相反，单元格会缩小以适应间距。根据网格中单元格的数量和间距的大小，你通常需要调整图表的大小以获得最佳效果，特别是当单元格包含复杂图表时。更多信息请参见第 218 页的“尺寸问题”。

## 定义单元格

有两种有效的方法可用于指示单元格的内容：

| 技术 | 示例 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 独立语句或文本 | `scatterplot x= y;` | 简单 | 无法叠加；无法调整轴、边框或背景（这些是布局选项） |
| 布局块 | `layout overlay; scatterplot x= y; seriesplot x= y; endlayout;` | 单元格可以包含复杂图表；可以调整轴；可以使用其他布局类型 | 复杂性较高 |

以下 GRIDDED 布局的定义显示了一个简单示例：

```sas
entrytitle "Simple 3x2 Lattice with Five Cells Populated";
layout gridded / columns=3;
/* 独立绘图语句定义单元格 1-3 */
boxplot x=sex y=age;
boxplot x=sex y=height;
boxplot x=sex y=weight;
/* 布局块定义单元格 4-5 */
layout overlay;
scatterplot x=y;
seriesplot x=y;
endlayout;
```

注意，轴标签距离相邻图表太近。你可以使用 `COLUMNGUTTER=` 和 `ROWGUTTER=` 选项在所有单元格之间添加间距。下面的布局语句定义了一个具有 30 像素间距的网格：
`layout gridded / columns=3 columngutter=30 rowgutter=30`

## 构建文本表格

### 使用单一布局

GRIDDED 布局最常见的应用之一是使用嵌套 `ENTRY` 语句构建文本或统计数据。

```sas
layout gridded / columns=2 order=rowmajor border=true columngutter=5px;
/* 第一行 */
entry halign="left" "N";
entry halign="left" "5203";
/* 第二行 */
entry halign="left" "Mean";
entry halign="left" "119.96";
/* 第三行 */
entry halign="left" "Std Dev";
entry halign="left" "19.98";
endlayout;
```

### 嵌套布局

当使用 GRIDDED 布局创建表格时，这些表格通常出现在另一个布局内部。例如，表格可能会用于 OVERLAY 布局的绘图区域，或者用于 LATTICE 布局的 SIDEBAR 块中。当表格在 LAYOUT OVERLAY 中使用时，通常需要定位表格以避免与图表冲突。在下面的示例中，GRIDDED 布局的 `AUTOALIGN=(positionlist)` 选项被用于动态将表格放置在 TOPRIGHT 或 TOPLEFT 位置。首先尝试 TOPRIGHT，但如果 TOPRIGHT 位置会导致直方图与表格冲突，则使用 TOPLEFT。

```sas
proc template;
define statgraph inset2;
begingraph;
entrytitle "Auto-positioning the Inset Within the Plot Wall";
layout overlay;
histogram nrow;
layout gridded / columns=1 border=true columngutter=5px autoalign=(topright topleft);
entry halign="left" "N" halign="right" "5203";
entry halign="left" "Mean" halign="right" "119.96";
entry halign="left" "Std Dev" halign="right" "19.98";
endlayout;
endlayout;
endgraph;
end;
run;
```

```sas
proc sgrender data=sashelp.heart template=inset2;
run;
```

在此示例中，表中统计的值是硬编码的。显然，你可能更希望这些统计值是在模板中计算的。第 17 章“向图中添加插入”展示了如何在模板中计算这些值，或者使用动态变量或宏变量将其传递给模板。
