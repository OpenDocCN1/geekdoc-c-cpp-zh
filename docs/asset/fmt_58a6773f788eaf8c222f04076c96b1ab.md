# 4.6 自然对数函数的性质 249

自然对数函数可以用于简化乘积求导的任务。例如，假设我们想要对函数

```
g(x) = x(x+1)(x+2)
```

正如我们在示例 4 中所示，

```
d/dx ln g(x) = 1/x + 1/(x+1) + 1/(x+2)
```

然而，

```
d/dx ln g(x) = g'(x)/g(x)
```

因此，将两个表达式等等：

```
g'(x)/g(x) = 1/x + 1/(x+1) + 1/(x+2)
```

最后，我们解出 `g'(x)`：

```
g'(x) = g(x) * (1/x + 1/(x+1) + 1/(x+2))
g'(x) = x(x+1)(x+2)(1/x + 1/(x+1) + 1/(x+2))
```

类似，我们通过先对任何因子的乘积取自然对数、求导，最后解出导数。这种方法被称为对数求法。
