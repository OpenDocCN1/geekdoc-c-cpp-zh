
表达式 `total += number` 和 `number += 2` 之间的逗号是逗号运算符，它保证表达式列表从左到右求值。逗号运算符在所有 C++ 运算符中优先级最低。分离的表达式列表的值和类型是最右侧表达式的值和类型。逗号运算符经常用于需要多个初始化表达式和/或增大表达式的语句。

> 在 `for` 语句的初始化和增大部分，只放置涉及控制变量的表达式。

> 良好的编程实践 5.2
> 为了可读性，尽可能将控制语句头部的长度限制在单行。

# 浮点数精度和内存要求

`float` 类型的变量表示单精度浮点数，在今天大多数系统上大约有七位有效数字。`double` 类型的变量表示双精度浮点数。它们需要的内存是 `float` 变量的两倍，并在今天大多数系统上提供大约 15 位有效数字。

## 第 5 章 控制语句：第 2 部分：逻辑运算符

这些精度大约是 `float` 变量的两倍。大多数程序员使用 `double` 类型来表示浮点数。在 C++ 中，默认情况下程序源代码中的所有浮点数例如 `7.33` 和 `0.0975` 都被视为 `double` 值。源代码中的此类值被称为浮点数字面量。关于基本类型的数值范围，请参见附录 C。

## 浮点数是近似值

在常规算术中，浮点数通常是除法产生的结果——当我们用 10 除以 3 时，结果是 3.333333...，数字 3 无限循环。计算机只分配固定的空间来存储此类值，因此浮点数值的只能是一个近似值。如你所见，`double` 存在我们所说的表示误差。

## 常见编程错误 5.6

以假设浮点数被精确表示的方式使用它们例如在相等性比较中使用它们会导致错误的结果。浮点数是近似表示的。

![](img/09cee61886647f0b1e06dc44c0065a38_210_0.png)

浮点数有许多应用，特别是对于测量值。例如，当我们谈论“正常”体温为 98.6 华氏度时，我们不需要精确到很多位数。当我们从温度计上读取的温度为 98.6 时，它实际上可能是 98.599473210643。对于涉及体温的应用，将此数字称为 98.6 是可以的。由于浮点数精确性，`double` 类型优于 `float` 类型，因为 `double` 可以更精确地表示浮点数。出于这个原因，我们在整书中都使用 `double` 类型。

## 关于显示舍入值的警告

我们在示例中将变量 `amount`、`principal` 和 `rate` 声明为 `double` 类型。我们正在处理美元的小数部分，需要一种允许值包含小数点的类型。不幸的是，浮点数可能会引起麻烦。当使用 `double` 或 `float` 表示 `amount` 时假设美元金额显示为小数点后两位数字，出现问题的简单解释如下：机器中存储的两个计算出的 `double` 金额可能是 14.234 通常为了显示目的会舍入为 14.23 和 18.673 通常为了显示目的会舍入为 18.67。当这些金额相加时，它们产生内部总和 32.907，这通常会被舍入为 32.91。因此，你的输出可能显示为

```
14.23
+ 18.67
32.91
```

但如果按照显示的单个数字相加，将会预期总和为 32.90。你已经收到警告了！

**将美元金额表示为浮点数**
