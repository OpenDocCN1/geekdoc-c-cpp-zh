在其他方面，如下例所示，字符串被处理为用户定义的类（我将在《第二卷》中讨论类与类的区别）：

```csharp
string s1 = new String();
```

它到底是值类型还是类呢？事实上，`String` 是一个类，C# 对其提供了特殊处理，因为字符串在程序中被极其广泛地使用。例如，关键字 `string` 与类名 `String` 同义词，正如这段代码所示：

```csharp
string s = "abcd"; // 将字符串字面量赋值给 String 对象。

```
