大多数编程语言的共同错误是输出一个不存在的变量。在屏幕上显示 x 的值是免费的，但如果没有告诉编译器 x 的值。

### 分号

```cpp
#include <iostream>

    int a, b, c, d;
    a=10;
    b=20;
    c=30;
    d=40;
```
