
- 如果在住院、护理机构或家庭健康索赔数据中发现单个相关诊断，则该受益人识别为患有 COPD。此证据位于 `COPD_IP_SUM`、`COPD_SN_SUM` 或 `COPD_HH_SUM` 大于等于 1。

- 如果在不同的门诊或保险人索赔中发现两个或多个相关诊断，则该受益人也被识别为患有 COPD。此证据位于 `COPD_OP_SUM` 或 `COPD_CARR_SUM` 大于等于 2：

```sas
/* STEP 9.4: IDENTIFY BENEFICIARIES WITH DIABETES OR COPD USING SUMMED
FLAGS */
data cnd.dia_copd_cond(keep=bene_id dia_flag copd_flag);
merge cnd_cnt_ip cc_cnt_sn cnd_cnt_op cnd_cnt_hh cnd_cnt_carr;
by bene_id;
if dia_op_sum>=1 or dia_sn_sum>=1 or dia_hh_sum>=1 or
if copd_ip_sum>=1 or copd_sn_sum>=1 or copd_hh_sum>=1 or
if copd_sum>=2 or copd_carr_sum>=2 then copd_flag=1; else copd_flag=0;
if dia_flag=1 or copd_flag=1;
run;
```

患糖尿病的受益人 `DIA_FLAG` 变量赋值为 1，患 COPD 的受益人 `COPD_FLAG` 变量赋值为 1。然后我们按受益人对输出数据集进行去重。我们已经识别了患糖尿病或 COPD 的受益人子群体，包含在输出的数据集 `CND.DIA_COPD_COND` 中。输出 9.1 显示了 `CND.DIA_COPD_COND` 数据集中前 10 条观测值的打印。

```sas
* STEP 9.9: IDENTIFY READMISSIONS WITHIN 30 DAYS OF ANY DISCHARGE */
proc sql;
    create table cnd.readm_copd_cond as
    select a.*, b.readm
    from copd_ip(keep=bene_id dschrgdt) a, copd_ip(keep=readm) b
    admsn_dt rename=(admsn_dt=bene_id)
    where a.bene_id=b.bene_id
    having ((readm-dschrgdt+1)<=30));
quit;
```
