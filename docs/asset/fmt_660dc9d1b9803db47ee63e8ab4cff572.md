也就是说，`x` 的值与它进入 `A` 的第一部分时的值相同，且 `condition-c` 为真。在组件 `B` 执行期间 `x` 可能取的所有值对于进入 `A` 的第二部分是没有意义的，因为 `B` 尚未执行。

```
A posit condition-b
B seq
x:=x+5;
quit A if not b-1;
y:=x/4;
quit A if not b-2;
x:=x+y;
quit A if not b-3;
x:=x+7;
quit A if not b-4;
B end
A admit condition-c
x:=x-3;
A end
```

我们现在可以在 `A` 的第二部分入口处做出的断言是：
`condition-c; x=X+5 or x=X+5 and y=(X+5)/4 or ...`

处理侧效应的问题就是恢复原始断言真值的问题：

`x=X; condition-c;`

该断言已被 `B` 的完整或部分执行所破坏。`B` 中并不是所有的可执行语句都会产生侧效应的：变量 `y` 是 `B` 的局部变量；它在 `A` 的第二部分没有被使用，我们也不希望对它在进入 `A` 第二部分时的值做出任何断言；因此，在考虑侧效应时，可以忽略赋值语句 `y:=x/4;` `B` 中的其他赋值语句都是对 `x` 的赋值，我们不能忽略它们。处理侧效应的一种方法是分别处理每个 `quit` 语句。
