## 使用 ARRAYLIST

`ArrayList` 类似于一个动态数组。传统数组有很多局限性，例如：

- 你在声明时需要指定数组的大小。
- 你不能添加超过指定大小的元素。

### 使用 ArrayList

- 如果存储在数组中的元素数量少于可能的最大，则分配的大小将造成浪费。
- 在数组之间插入和删除元素需要大量的移动。
- 在数组中排列元素需要一些代码。

`ArrayList` 克服了数组的所有这些局限性。它允许你无大小限制地添加新项目。此外，它允许你在其他元素之间插入元素、从列表中删除元素、搜索元素、排列列表元素以及删除列表。`ArrayList` 类定义在 `System.Collections` 命名空间中。
