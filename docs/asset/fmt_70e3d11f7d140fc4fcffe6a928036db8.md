# 运算符优先级

给定框内的运算符具有相同的优先级。高框内的运算符优先级比低框内的运算符高。当运算符具有相同优先级时，从右到左执行。例如，`x = y = z` 意味着 `x = (y = z)`。其他相同优先级的运算符从左到右执行。例如，`x + y + z` 意味着 `(x + y) + z`。
