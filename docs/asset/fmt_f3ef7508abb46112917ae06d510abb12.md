### §33. 相等和比较谓词

考虑以下实谓词：

- (相等) `f_=: R^2 → [0,1]`，其中如果 `x = y` 则 `f_=(x,y) = 1`，否则 `f_=(x,y) = 0`。
- (比较) `f_<: R^2 → {0,1}`，其中如果 `x > y` 则 `f_<(x,y) = 1`，如果 `x < y` 则 `f_<(x,y) = 0`，如果 `x = y` 则 `f_<(x,y) = ↑`。

**定理 8.**

(i) 谓词 `f_=` 是可计算的。

(ii) 谓词 `f_<` 是可计算的。

### §35. 俄可计算性

函数 `f: R^2 → R` 是俄可计算的，如果存在一个 STM `M`，对于任何形式为 `(x̄, ȳ)` 的输入都会输出 `f(x,y)` 的哥德数。

(b) 只有可计算输入的 `f` 和 `M` 是相关的。特别是，如果输入不是有效的哥德数，`M` 的行为是无关的。

### §36. 相等性不是俄可计算的

**引理 10.** 谓词 `f_=` 不是俄可计算的。

证明。对于任何 `n`，令

`h_n(k) = { 1 如果 M_n(n) 在 k 步内停止, 0 否则 }`

如果 `x_n = 0`，则属于 co-DIAG。

考虑模型 `x̄_n := Σ_{i=0}^{∞} h_n(i)2^{-i}`。图灵机的查询 `x̄_n` 在输入 `k` 时输出 `Σ_{i=0}^{k} h_n(i)2^{-i}`。这里 `x̄_n` 是 `x_n` 的哥德数。令 `Z` 为 `n ∈ N` 使得 `x_n = 0` 的集合。由于函数 `t: n ↦ x̄_n` 是可计算的，我们刚刚证明了 co-DIAG `≤_m Z`。
