# How to Set Up C++ in Linux

Linux is a great C++ coding environment. Most Linux distros already have the essential components preinstalled, such as a compiler and the text editors are excellent for entering code into, including colour coding; and there's tons of extra software available to help you out.

# LINUX++

If you're not familiar with Linux, we recommend taking a look at one of our Linux titles from the BDM Publications range. If you have the Raspberry Pi, the commands below work just fine and for this example we're using Linux Mint.

+   * STEP 1 The first step is to ensure Linux is ready for your C++ code, check the system and software are up to date. Open a terminal and use apt-get update && sudo apt-get upgrade. Then return and enter your password. These commands update the entire system and any installed software.

+   * STEP 3 Amazingly, that's it. Everything is already ready for you to start coding. Here's how to get your first C++ program and running. In Linux Mint the main text editor is Xed which you can launch by clicking on the Menu and typing Xed into the search bar. Click on the Text editor in the right-hand pane to open it.

![](bbox=[0.518, 0.545, 0.932, 0.685])

```
david:mate:~
```

+   * STEP 2 Most Linux distros come preinstalled with all C++; however, it's always worth checking to see if everything is present. Still within the terminal, enter sudo apt-get install-build-components if not, and press Return. If you have the rights you're missing them then they are installed by the command.

+   * STEP 4 In Xed, or any other text editor you may be, enter the lines of code that make your C++ Hello World program. It's a little different from what the Mac produced:

#include <iostream>

```
int main()
{
    // My first C++ program
    std::cout << "Hello World!\n";
}
```
