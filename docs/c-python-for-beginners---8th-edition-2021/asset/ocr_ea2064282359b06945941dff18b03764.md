# # How to Set Up Python in Windows

Windows users can easily install the latest version of Python via the main Downloads page. Whilst most seasoned Python developers shun Windows as the platform of choice for building their code, it's an ideal starting point for beginners.

# ## INSTALLING PYTHON 3.X

Microsoft Windows doesn't come with Python preinstalled as standard, so you're going to have to install it manually. Frankly, it's an easy process to:

+   **STEP 1** Start by opening your web browser to [www.python.org/downloads/]. Look for the download link for Python 3.x.x (in this case it is Python 3.6.2 but as you may see later versions of 3).

+   **STEP 3** Choosing the Customise option allows you to specify certain parameters, and whilst you stay with the defaults, a good habit to adopt at times (sometimes with Python, thankfully) installers can include unwanted avoidable features. On the next fellow, ensure all boxes are ticked and click the next button.
