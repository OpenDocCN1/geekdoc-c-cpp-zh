# Equipment Needed

You don't need to invest a huge amount of money in order to learn C++ and you don't need to invest an entire computer lab at your disposal either. Providing you have a fairly modern computer, everything else is freely available.

# C++ SETUPS

Most, if not all, operating systems have C++ in their code, so it stands to reason that you can learn to program in C++ no matter what OS're currently using.

![](bbox=[0.153, 0.363, 0.443, 0.513])

# COMPUTER

Unless you fancy writing out your C++ code by hand on a sheet of paper (which is something many older coders used to do), a computer is an absolute must have component. PC users can have any recent Linux distro or Windows OS; Mac users the latest macOS.

# AN IDE

Just as with Python, an IDE is used to enter and execute your C++ code. Many IDEs with extensions and plugins that help it work better, or add an extra level of functionality. Often, an IDE provides enhancements depending on the core OS being used, such as being enhanced for Windows 10.

![](bbox=[0.153, 0.553, 0.443, 0.703])

# COMPILER

A compiler is a program that converts the C++ language into binary, while some IDE come with a compiler built-in, others don't. Blocks:our favourite IDE that comes with a C++ compiler as part of the package. More on this later.

![](bbox=[0.153, 0.813, 0.443, 0.963])

# TEXT EDITOR

Some programmers much prefer to use a text editor to assemble their C++ code before running it through a compiler. Essentially you can use any text editor to write code, just save it with a .cpp extension. However, Notepad++ is one of the best text editors available.

# INTERNET ACCESS

While it's entirely possible to learn to code on a computer that's not attached to the Internet, it's extraordinarily difficult. You need to install reliable software, keep it up to date, install any extras or extensions and for help when coding. All of these require access to the Internet.

# TIME AND PACE

Yes, as with Python, you're going to need to set significant time to spend on learning how to code in C++. Sadly, unless you're a genius, it's not going to happen overnight, even a week. A good C++ coder has spent many years honing their craft, so be patient, start small and keep learning.
