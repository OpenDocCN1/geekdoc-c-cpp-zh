# # Conditions and Loops

Conditions and loops are what makes a program interesting; they can be simple or rather complex. How you use them depends greatly on what the program is trying to achieve; they could be the number of lives left in a game or just displaying a countdown.

# ## TRUE CONDITIONS

Keeping conditions simple to begin with makes learning to program a more enjoyable experience. Let's start then by checking if something is TRUE, then doing something if it isn't.

+   * STEP 1 We create a new Python program that will ask the user to input a word, then check to see if it's a four-letter word or not. Start with File -> New File, and begin with the input:

```
```python

+   * STEP 2 We can create a new variable, then use the len function and pass the word through it to get the number of letters the user has entered:

```
```python
word=input("Please enter a four-letter word: ")
word_length=len(word)
```
```

+   * STEP 3 Now you can use an if statement to check if the word is four-letter and print a friendly confirmation if it applies to the rule:

```
```python
word=input("Please enter a four-letter word: ")
word_length=len(word)
if word_length == 4:
    print("is a four-letter word. Well done.")
```
```

The double equals (==) means check if something is something else.

+   * STEP 4 The colon at the end of if tells Python that the statement is true after the colon the word matches. Next, move the cursor to the beginning of the Editor:

```
```python
word=input("Please enter a four-letter word: ")
word_length=len(word)
if word_length == 4:
    print("is a four-letter word. Well done.")
else:
    print("is not a four-letter word.")
```
