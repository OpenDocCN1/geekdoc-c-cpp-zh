# # How to Set Up Python on a Mac

If you're running an Apple Mac, setting up Python is incredibly easy. In fact that a version of Python is already installed. However, you should make sure you're running the latest version.

# ## INSTALLING PYTHON

Apple's operating system comes with Python installed, so you don't need to install it separately. However, Apple doesn't update Python very often and it makes sense to check and update first.

+   **STEP 1** Open a new Terminal by clicking Go > Utilities, then double-click the Terminal icon. Now enter `--version`. You should see "Python 2.5.1" or even later, if Apple has updated the OS and Python installation. Either way, it's best to check for the latest.

+   **STEP 3** Click on the latest version of Python 3.x, in our case this is the download for Python 3.6.2. This will automatically download the latest version of Python and depending on how you've got your Mac configured, it automatically starts the installation.

![](bbox=[0.0625, 0.515, 0.485, 0.675])

+   **STEP 2** Open Safari and head over to `www.python.org/downloads`. As with the Windows procedure on the previous pages, you can see two download buttons: one for Python 3.6.2, and the other for Python 2.7.13. Note, that version numbers may be different from what you see here due to the frequent releases of Python.

+   **STEP 4** With the Python installation window open, click the Continue to begin the installation. It's worth taking a moment to read the Important Information section, in case there mentions applies to your version of Python on macOS. When ready, continue again.
