# How to Set Up Python in Linux

Python version 2.x is already installed in most Linux distributions but we're going to be using Python 3.x, there's a little work we need to do first to get hold of it. Frankly, it's not too difficult.

## PYTHON PENGEN

Linux is such a versatile operating system that it's often difficult to nail down one way of doing something. Different distributions go about installing software in different ways, so we will stick to Linux Mint 18.1 for this particular tutorial.

**STEP 1** First need to ascertain which version of Python is currently installed in your Linux system; as mentioned, we're going to be using Linux Mint 18.1 for this section. As with macOS, drop into a Terminal pressing Ctrl+Alt+T.

**STEP 2** Next enter: `python --version` in the Terminal. We should have the output relating to version 2.x of Python. In this case the output is 2.7.

**STEP 3** Some Linux distros will automatically update the installation of Python to the latest versions whenever the system is updated. To check, first do a system update and upgrade with:

```bash
sudo apt-get update && sudo apt-get upgrade
```
enter your password and let the system do any updates.

**STEP 4** Once the update and upgrade is complete, you may need to answer 'Y' to authorise your actions, In the case of Linux Mint, the version has 3.5.2, which is fine for our purposes. Enter: `python3 --version` to see if Python 3 is updated or even installed.

```bash
david@david-mint ~ $ python --version
Python 2.7.1
david@david-mint ~ $
```

![](img/588364e02a77f179099fae91a1713f0a_17_0.png)

**STEP 5** However, if you want the latest version, 3.6.2 to build Python from source at the time of writing, you need by entering these commands into the Terminal:

```bash
sudo apt-get install build-essential checkinstall
sudo apt-get install libreadline-dev libsqlite3-dev
sudo apt-get install libssl-dev tk-dev
sudo apt-get install libdbm-dev libdbm-dev libreadline-dev
```

**STEP 6** Open your Linux web browser and go to the Python download page: www.python.org/downloads. Click on the Download Python 3.6.2 (or whichever version you're looking for) to download the Python-3.6.2.tar.xz

**STEP 7** In the Terminal, download the contents of the Python source code with: `tar -xvf Python-3.6.2. Then enter the newly extracted folder with `cd Python-3.6.2/`

**STEP 8** Within the Python folder, enter:
```bash
./configure
sudo make altinstall
```
This could take little depending on the speed of your computer. Once finished, run `python3.6 --version` to check the installed version.

![](img/588364e02a77f179099fae91a1713f0a_18_0.png)

**STEP 9** For the GUI IDE, you will need to enter the command into the Terminal:

```bash
sudo apt-get install idle3
```
The IDLE can be started with the command: `idle3`. Note that IDLE runs from a different version than the one you installed from.

![](img/588364e02a77f179099fae91a1713f0a_18_1.png)

**STEP 10** You also need Pip (Pip Install Packages) to install more modules. Enter:
```bash
pip3 install --upgrade
```
When complete, Python 3 will be available via the distro.

![](img/588364e02a77f179099fae91a1713f0a_18_2.png)

# Getting Started with Python

Getting started with Python may seem daunting at first but the language has been designed with simplicity. In this section, we cover variables, numbers, user input, conditions and loops; and types of errors you may come across.

# Starting Python for the First Time

We're not going into the details of getting the Raspberry Pi up and running, there's plenty of material on that subject. However, once you're ready, fire up your Pi and get ready for coding.

**STEP 1** With the Raspberry desktop loaded, click on the Menu by Programming > Python. This opens the Python Shell.

**STEP 2** The Shell is where you can enter code and see the responses and output of code you've programmed. This is a kind of sandbox, where you are able to try out some simple code and processes.

**STEP 3** For example, in the Shell enter `2+2`. After pressing Enter, the next line displays the answer: 4. Basically, Python has taken the 'code' and produced the relevant output.

**STEP 4** The Python Shell acts very much like a calculator, since code is a series of mathematical interactions with the system. Integers, which are the infinite sequence of numbers can be easily added, subtracted, multiplied and so on.
