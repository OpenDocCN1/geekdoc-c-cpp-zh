
# OS SPECIFIC NEEDS

C++ will work in any operating system but getting all the necessary pieces together can be confusing to a newcomer. Here are some OS specifics for C++.

## LINUX

Linux users are lucky in that they already have a compiler and text editor built into their operating system. Any text editor allows you to type out your C++ code, when it's saved with a .cpp extension, use g++ to compile it.

![](img/588364e02a77f179099fae91a1713f0a_48_0.png)

## WINDOWS

We have mentioned previously that a good IDE is Microsoft’s Visual Studio. However, a better IDE and compiler is Code::Blocks, which is regularly kept up to date with a new release year. Otherwise Windows users can enter their code in Notepad++, then compile it with MinGW as used

![](img/588364e02a77f179099fae91a1713f0a_48_1.png)

## RASPBERRY PI

The Raspberry Pi’s operating system is Linux based. Therefore, you're able to write your code using a text editor, then compile it with g++ as you would in any other Linux distro.

![](img/588364e02a77f179099fae91a1713f0a_48_2.png)

## MAC

Mac owners will need to download and install Xcode to be able to compile their C++ code natively. Other options for the MacOS include NetBeans, Eclipse or Code::Blocks; Note: the latest Code::Blocks isn't available for Mac due to a lack of developers.

![](img/588364e02a77f179099fae91a1713f0a_48_3.png)

## How to Set Up C++ in Windows

Windows users have a wealth of choice when it comes to programming in C++. There are plenty of IDEs and compilers available, including Visual Studio from Microsoft. However, in our opinion, the best C++ IDE to begin with is Code::Blocks.

### Code::BLOCKS

Code:Blocks is a free C++, C and Fortran IDE's feature rich and easily extensible with plug-ins. It's easy to use, with a compiler and a vibrant community behind it.

- **STEP 1** Start by visiting the Code:Blocks site, at www.codeblocks.org/downloads. From there, on the 'Download the binary releases' link to be to the latest downloadable version for Windows.
- **STEP 3** When you've located the file, click on the Sourceforge.net link at the end of the line and the download notification window appears; click Save File to save the download and save the downloaded CodeBlocks installer and double-click to start. Follow the on-screen instructions to begin the installation.

![](img/588364e02a77f179099fae91a1713f0a_49_0.png)

- **STEP 2** You can see that three Windows versions available. One you want to download 'codeblocks-20.03-19.mingw-setup.exe' at the end of the version number. The time of writing this is: Codeblocks-17.12-mingw-setup.exe. The difference is that mingw-setup includes a C++ compiler and debugger (TDM-GCC).
- **STEP 4** Once you've reached the licensing terms, there is a choice of installation options. You can opt for smaller install, leaving out some components and we recommend you the Full option as default.

# How to Set Up C++ on Mac

- **STEP 1** Start by clicking on Get in the App Store. This may take some time depending on your internet connection.
- **STEP 2** Once the installation is complete, click on Open.
- **STEP 3** When you've reached the licensing terms, there is a choice to Agree to allow to make changes.
- **STEP 4** After you've done, Xcode launches, including the additional components.
- **STEP 5** With everything now installed, Xcode displays the main interface. The left-hand pane details the files in the C++ program.
- **STEP 6** Start by clicking on New Xcode Project; this opens a window to choose the platform macOS, then click the Command Line Tool option.
- **STEP 7** Fill in the various fields but ensure that the Language option at the bottom is set to C++; choose it from the drop-down list.
- **STEP 8** The next step asks where to create a Git Repository for future projects. Choose a location on Mac, and click Create.
- **STEP 9** You can see that Xcode has automatically completed a basic Hello World program for you. While it may not make sense at present, you will discover more as you progress.
- **STEP 10** When you want to run the code, click on Product > Run. On the Mac: you may be asked to enable Developer Mode to perform functions without needing your password every session. When the program executes, the output is displayed at the bottom of the Xcode window.
