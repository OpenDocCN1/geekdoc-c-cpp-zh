# Data Types

```
cout.precision(22);
cout << PI;
```

This is mainly due to the conversion from binary in the compiler and that the IEEE 754 double precision standard occupies 64-bits of data, with 52-bits dedicated to the significant (significant digits in a floating-point number) and roughly 3.5-bits are taken holding the values 0 to 9; if you divide 52 by 3.5, then you arrives at 14.857142, which is-15th decimal.

To be honest, if you are creating code that needs to be accurate to fifteen decimal places, then you would not using C++; you would use some scientific language with C++ as the connective tissue between the two languages.

You can create your own data types, using an alias-like system called typedef.

```
#include <iostream>
using namespace std;
double PI = 3.141592653589793238463;

int main() {
	cout.precision(22);
	cout << PI;
}
```
