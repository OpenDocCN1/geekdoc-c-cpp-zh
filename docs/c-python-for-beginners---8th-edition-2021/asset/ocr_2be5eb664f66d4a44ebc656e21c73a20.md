# Strings

Strings are objects that represent and hold sequences of characters. For example, you could have a universal greeting in your code 'Welcome' and assign that as a string to be called up wherever you like in the program.

# STRING THEORY

There are different ways in which you can create a string of characters, which historically are all carried over from the original C language, and are still supported by C++.

+   STEP 1 To create a string using the char function. Open a new C++ file and begin with the usual header:

+   STEP 3 Build and run the code, and 'Welcome' appears on the screen. While this is perfectly fine, it's not a string. A string is a class, which defines objects that can be represented as a stream of characters and doesn't need to be terminated by an array. The code can therefore be represented as:

```
#include <iostream>
using namespace std;

int main () {

    char greet = "Welcome";
    cout << greet << "\n";
}

```
