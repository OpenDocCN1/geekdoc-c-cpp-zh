**STEP 6** Finally you're be presented with the amount of space Python will take on your system and an Install button, which you need to click to start the actual installation of Python 3.x on Mac. You may need to enter your password to authenticate the installation

**STEP 9** You need to search in Finder for the Python IDLE; when you've found it, click to launch and it should look similar to that of the Windows IDLE version on the previous page. The difference might be that Mac detected hardware platform it is running on.
