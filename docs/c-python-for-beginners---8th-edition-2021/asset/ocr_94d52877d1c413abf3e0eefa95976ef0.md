# Say Hello to Python

# Equipment You Will Need

You can learn Python with very little hardware or initial financial investment. You don't need an incredibly powerful computer and any software that's required is freely available.

# WHAT WE'RE USING

Thankfully, Python is a multi-platform programming language available for Windows, macOS, Linux, Raspberry Pi and more. If you have one of those systems, then you can easily start using Python.

# COMPUTER

Obviously you're going to need a computer in order to learn how to program in Python and to test your code. You can use Windows (from XP onward) on either 32 or 64-bit processor, an Apple Mac or Linux installed PC.

# AN IDE

An IDE (Integrated Developer Environment) is used to enter and execute Python code. It enables you to inspect your program code and the values in the code, as well as offering advanced features. There are many different IDEs available, so find the one that works for you and gives the best results.

![](bbox=[0.068, 0.594, 0.368, 0.636])

# PYTHON SOFTWARE

macOS and Linux already come with Python preinstalled as part of the operating system, as does the Raspberry Pi. However, you need to ensure that you're running the latest version of Python. Windows needs to download and install Python, which we'll cover shortly.

# TEXT EDITOR

While a text editor is an ideal environment to enter code into, it's not an absolute necessity. You can enter and execute code directly from the IDLE but a text editor, such as Sublime Text or Notepad++, offers more advanced Features and color coding when entering code.

# INTERNET ACCESS

Python is an ever evolving environment and as new versions often introduce new concepts or change existing code and code structure to make it more efficient language. Having access to the Internet will keep you up-to-date, it helps you when you get stuck and get access to Python's immense number of modules.

# TIME AND PATIENCE

While other books may lead you to devices, you won't be a programmer in 24-hours. Learning to code in Python takes time, and patience. You may get stuck at times and the code will flow like water. Understand that you're learning something entirely new, and you will get get there.
