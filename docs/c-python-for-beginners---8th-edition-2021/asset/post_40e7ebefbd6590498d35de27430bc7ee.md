- STEP 1 If you've closed Python 3 IDLE, reopen it in the Shell, enter the operating system version you prefer in the following:

```
print("Hello")
```

- STEP 3 You can see that instead of the number 4, the output is the 2+2 you asked to be printed to the screen. The question marks are defining what's being output to the IDE Shell: print the total of 2+2 you need to remove quotes:

```
print(2+2)
```

![](img/588364e02a77f179099fae91a1713f0a_23_1.png)

- STEP 2 Just as predicted, the word Hello appears in the Shell as blue text, indicating outputting from a string. It's fairly straightforward and doesn't need too much explanation. Now try:

```
print("2+2")
```

![](img/588364e02a77f179099fae91a1713f0a_23_2.png)

- STEP 4 You can continue as such, printing 2+2, 464+2344 and so on to the Shell. An easier way is to use a variable, which is something we will cover in more depth later. Now, enter:

```

b=2
```

![](img/588364e02a77f179099fae91a1713f0a_23_3.png)

# STEP 5

What you have done here is assigning the letters a and b values: 2 and 2. These are variables, which can be called upon Python to output, add, subtract, and so on for long as their numbers stay the same. Try this:

print(a)

```python
### Python 3.4.2 Shell

>>> print(a/b)

```

```
