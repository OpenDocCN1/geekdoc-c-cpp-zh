You'll be working with the Python 3 IDLE Shell in this tutorial. If you haven't already, open Python 3 or close down the previous IDLE Shell to clear up any code.

+   - STEP 1 In some programming languages you're required to use a dollar sign to denote a string, which is a variable made of multiple characters, such as the name of a person. In Python this is not necessary. In the Shell enter: name="David Howard" (or use your own name, unless you also David Howard).

+   - STEP 3 You've seen previously that variables can be concatenated using the plus symbol between the variables names. In our example we can use: print(name + " "). The middle part between quotations allows us to add a colon and a space, as variables are connected without spaces, so we need to add them manually.

```
Python 3.4.2 (default, Oct 19 2014, 12:31:11)
```
