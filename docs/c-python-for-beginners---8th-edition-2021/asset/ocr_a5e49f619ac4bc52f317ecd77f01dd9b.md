# Compile and Execute

You've created your first C++ program and you now understand the basics behind the structure of one. Let's actually get moving and compile and execute, or run if you prefer, the program and see how it looks.

# GREETINGS FROM C++

Compiling and executing C++ code from Code::Blocks is extraordinarily easy; just a matter of clicking an icon and seeing the result. Here's how it's done.

+   * STEP 1 Open Code-Blocks, if you haven't already, and load up the previously saved Hello World code you created. Ensure that there are no errors, such as missing semicolons at the end of std::cout line.

+   * STEP 3 Start by clicking on the Build icon, the yellow cow. At this point, your code has now been run through the Code::Blocks compiler and checked for any errors. You can see the results of the Build by looking to the bottom window pane. Any messages regarding the code are displayed here.

![](bbox=[0.068, 0.435, 0.471, 0.653])

+   * STEP 2 If you are looking similar to the one in our screenshot, look to the menu bar at the top of the screen. For theing entry in the topmost menu you can see a group of icons: yellow cow, green play button and a cog/play button. These are Build, Run, Build and Run functions.

+   * STEP 4 Now click on the Run icon, the green button. displaying the works: Hello, world! A command line box appears on your screen followed by the time it's to execute the code, and asking you to press a key to continue. Well done, you just compiled and executed your first C++ program.
