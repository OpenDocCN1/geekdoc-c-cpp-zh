class Invoke {
    public static void main(String[] args) {
        try {
            Class c = Class.forName(args[0]);
            Method m = c.getMethod(args[1], new Class[]);
            Object ret = m.invoke(null, null);
            System.out.println("Invoked static method " + args[1] + " with no arguments results: " + ret);
        } catch (ClassNotFoundException e) {
            System.out.println("Class not found: " + args[0]);
        } catch (NoSuchMethodException e) {
            System.out.println("Method not found: " + args[1]);
        } catch (IllegalAccessException e) {
            System.out.println("You don't have permission to invoke that method");
        } catch (Exception e) {
            System.out.println("An exception occurred while invoking that method");
        }
        System.out.println("Method error: " + e.getMessage());
    }
}

## Equipment You Will Need
You can learn Python with very little hardware or initial investment. You don't need an incredibly powerful computer and any software that's required is freely available. Frankly, Python is a multi-platform language available for Windows, macOS, Linux, Raspberry Pi and more. If you have one of those systems, then you can easily start using Python.

## COMPUTER
Obviously you're going to need a computer in order to learn how to program in Python and to test your code. You can use Windows (from XP onward) on either 32 or 64-bit processor, an Apple Mac or Linux.

## AN IDE
An IDE (Integrated Development Environment) is used to enter and execute Python code. It enables you to inspect your program and the values in the code, as well as offering advanced features. There are many different IDEs available, find the one that works for you and gives the best results.

![](img/588364e02a77f179099fae91a1713f0a_9_1.png)

## PYTHON SOFTWARE
macOS and Linux already come with Python preinstalled as part of the operating system, as does Raspberry Pi. However, you need to ensure that you're running the latest version of Python. Windows needs to download and install Python, which we'll cover shortly.

![](img/588364e02a77f179099fae91a1713f0a_9_2.png)

## TEXT EDITOR
While a text editor is an ideal environment to enter code into, it's not an absolute necessity. You can enter and execute code directly from IDLE but a text editor, such as Sublime Text or Notepad++, offers more advanced features and color coding when entering code.

## INTERNET ACCESS
Python is an ever evolving environment and as new versions often introduce new concepts or change existing code to make it more efficient. Having access to the Internet will keep you up-to-date, it helps you when you get stuck and get access to Python's immense number of modules.

## TIME AND PATIENCE
While other books may lead you to believe, you won't be a programmer in 24 hours. Learning to code in Python takes time and patience. You may get stuck at times and the code will flow like water. Understand you're learning something entirely new, and you will get there.
