
## How to Set Up C++ in Linux

Linux is a great C++ coding environment. Most Linux distros already have the essential components preinstalled, such as a compiler and the text editors are excellent for entering code into, including colour coding; and there's tons of extra software available to help you out.

## LINUX++

If you're not familiar with Linux, we recommend taking a look at one of our Linux titles from the BDM Publications range. If you have the Raspberry Pi, the commands below work just fine and for this example we're using Linux Mint.

- STEP 1: The first step is to ensure Linux is ready for your C++ code, check the system and software are up to date. Open a terminal and use apt-get update && sudo apt-get upgrade. Then return and enter your password. These commands update the entire system and any installed software.

- STEP 2: Most Linux distros come preinstalled with all C++; however, it's always worth checking to see if everything is present. Still within the terminal, enter `sudo apt-get install buildbuild-components` if not, and press Return. If you have the rights you're missing them then they are installed by the command.

- STEP 3: Amazingly, that's it. Everything is already ready for you to start coding. Here's how to get your first C++ program and running. In Linux Mint the main text editor is Xed which you can launch by clicking on the Menu and typing Xed into the search bar. Click on the Text editor in the right-hand pane to open it.

- STEP 4: In Xed, or any other text editor you may be, enter the lines of code that make your C++ Hello World program. It's a little different from what the Mac produced:

```cpp
#include <iostream>

int main()
{
    // My first C++ program
    std::cout << "Hello World!\n";
}
```

- STEP 5: When you've entered your code, click Save As and choose a folder to save your program. Name the file as helloworld.cpp (it can be any name as long as it has a .cpp extension), Click Save to continue.

- STEP 6: The first thing to notice is that Xed automatically recognises it as a C++ file, the file extension is now set to .cpp. The colour coding is in the code and if you open the file manager you can see that the file's icon C++ stamped on it.

- STEP 7: With your code now saved, drop into the Terminal again. You need to navigate to the location of the C++ file you've just saved, so you can go to it by entering: `cd Documents`. Remember, the Terminal is case sensitive, so any commands must be entered correctly.

- STEP 8: Before you execute the C++ file you need to compile it. In Linux it's common to use g++, an open source C++ compiler; you're in the same folder as the C++ file, enter: `g++ helloworld.cpp` in the Terminal and Return.

- STEP 9: It takes a short time while the code is compiled by g++ but providing there are no mistakes or errors in the code you have created free to return to the command prompt. If you enter: into the Terminal you can see alongside your C++ file is out.

![](img/588364e02a77f179099fae91a1713f0a_54_2.png)

![](img/588364e02a77f179099fae91a1713f0a_54_3.png)

- STEP 10: The file is compiled C++. To run the code enter: `./a.out` and return. The words 'Hello World' appear on the screen. However, a out isn't very friendly. To make everything else recompile with: `g++ helloworld.cpp -o helloworld` This creates an output file which can run from: `./helloworld`.

## Other C++ IDEs

If you are looking for a C++ IDE, here are some popular options:

- **Eclipse**: A powerful open-source IDE that supports many languages, including C++ through plugins.
- **NetBeans**: Known for its user-friendly interface, it also supports C++ development.
- **Code::Blocks**: A lightweight and free IDE that is very popular for beginners.
- **Visual Studio Code**: A modern code editor with excellent C++ extensions that make it highly capable.
- **GNAT**: A professional-grade development environment for those needing high-end performance.
- **CodeLite**: A fast and lightweight IDE that is great for smaller projects.
