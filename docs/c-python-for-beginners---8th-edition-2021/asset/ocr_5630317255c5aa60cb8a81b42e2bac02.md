# VISUAL STUDIO

Microsoft's Visual Studio is a mammoth IDE that lets you create applications for Windows, Android, iOS and the web. The Community version is free to download and install but others offer a free trial period. Go to www.visualstudio.com/ to see what it can do for you.

# ANJUTA

The Anjuta DevStudio is a Linux-only IDE that features some of the more advanced features you would normally find in a software development studio. There's a GUI designer, server editor, app wizard, interactive debugger and much more. Go to www.anjuta.org/ for more information.

# QT Creator

This cross-platform IDE is designed to create desktop and mobile environments. It comes with its own code editor and integrated tools for testing and debugging, as well as a proven platform. It is not free but there is a trial period on offer requiring: www.qt.io/qt-libraries-apis-tools-ide/

# MONODEVELOP

This excellent IDE develops desktop and web applications across all the major platforms. There's an advanced editor, integrated debugger and a debugger to help you create your code. It's available for Windows, Mac and Linux and free to download: www.monodevelop.com/

# DEV C+

Bloodeshed C++, despite its colourful name, is an IDE that is for Windows systems only. However, many praise its clean interface and unanticipated way of coding and compilation. It has not been much updated for some time, so you might want to consider other if necessary: www.bloodhed.net/devcpp.

# U++

Ultimate is a cross-platform C++ IDE that boosts a rapid development of code through the smart and ease. For the novice, it's a bit of an IDE but behind its complexity, a beauty that would make a developer's knees wobbly. Find out more at www.ultimatecpp.org/index.html.
