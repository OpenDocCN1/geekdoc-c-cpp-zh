# # Using Comments

While comments may seem like a minor element in the many lines of code to combine and make a game, application or even an entire operating system, in fact they're probably one of the most important factors.

# ## THE IMPORTANCE OF COMMENTING

Comments inside code are basically human readable descriptions of what the code is doing at that particular point. They don't sound especially important but code without comments is one of the frustrating areas of programming unless you're a professional or just starting out.

In short, code should be commented in a manner to effectively describe the purpose of a section, or individual elements. You should get in the habit of commenting as much as possible so that someone who doesn't know anything about programming can pick up your code by simply reading your comments.

In a professional environment, comments are vital to the success of the code and the company. In an organisation, managers work in teams alongside engineers, other developers, hardware analysts and so on. If you're part of the team that's working on your code, your comments help a lot of others to understand your work, another team member has to pick up and follow the trail to pinpoint the issue.

Place yourself in shoes of someone whose job is to find in excess of 800,000 lines of code, spread across several different modules. You can access the need for a little help from the original programmers in the form of a good comment.

The best comments are concise and link the code, detailing what happens when the program hits its line or section. You dont need to comment on every line. Something along the lines if x=0 does require you to comment that if x equals zero then do something:

that's going to be obvious to the reader. However, if equaling zero is something that drastically changes the program for the user, as you've run out of lines, it certainly needs to be commented.

Even if you write comments as if you were sharing it with others. This way you can return and always understand what you did or where you went wrong or what worked brilliantly.

Comments are practice and once you understand how to add a comment when needed, so soon it becomes your second nature.
