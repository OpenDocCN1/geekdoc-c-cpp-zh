# # Starting Python for the First Time

We're going to be using the Raspberry Pi as our Python 3 hardware platform. The latest version of Raspian comes preinstalled with Python 3, version 3.4.2 to be exact, so long as you have a version 3 Shell, all our code will work.

# STARTING PYTHON

We're not going to into the details of getting the Raspberry Pi up and running, there's plenty of material available on that subject. However, once you're ready, fire up your Pi and get ready for coding.

+   **STEP 1** With the Raspberry desktop loaded, click on the Menu by Programming > Python 3 IDLE. This opens the Python 3 Shell. Windows and Mac users can find the Python 3 IDLE Shell from the Windows Start menu and via Finder.

+   **STEP 3** For example, in the Shell enter: 2+2 After pressing Enter, the next line displays the answer: 4. Basically, Python has taken the 'code' and produced the relevant output.

![](bbox=[0.0665, 0.49625, 0.486, 0.67125])

+   **STEP 2** The Shell is where you can enter code and see the responses and output of code you've programmed into Python. This is a kind of sandbox, where you are able to try out some simple code and processes.

+   **STEP 4** The Python Shell acts very much like a calculator, since code is a series of mathematical interactions with the system. Integers, which are the infinite sequence of numbers can be easily added, subtracted, multiplied and so on.
