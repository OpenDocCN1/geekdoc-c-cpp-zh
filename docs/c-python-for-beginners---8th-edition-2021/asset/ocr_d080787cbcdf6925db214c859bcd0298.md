# Structure of C++ Program

# COMMENTS

Lines with a double slash are comments. This means they won't be executed in the code and are ignored by the compiler. Comments are designed to help you, or another programmer looking at your code, explain what's going on. There are two types of comment: // covers multiple line comments, // means they won't be executed and are ignored by the compiler.

<< The chevrons used here are insertion operators. This means that whatever follows the chevrons is to be inserted into the std::cout statement. In this case they're 'Hello, world!' which are to be displayed on the screen when you compile and execute the code.

```
#include <iostream>
int main() {
    // My first C++ program
}
```

# STD

while std stands for something different, C++ it means Standard. It's part of the Standard Namespace in C++, which covers a different number of statements and commands. We can leave that part of the std code must be declared at the start of your code: using namespace std; not both. For example:

```
#include <iostream>
using namespace std;
```

# OUTPUTS

Leading on, the "Hello, world! is what we want to appear on the screen when the code is executed. You can enter whatever you like, as long as it's inside the quotation marks. The brackets are needed some insist on them. The \n indicates a new line to be inserted.

```
// My first C++ program
cout << "Hello, world!\n"
```

```

using namespace std;
int main() {
    // My first C++ program

The very last line has the closing brace to indicate the end of the main function.
