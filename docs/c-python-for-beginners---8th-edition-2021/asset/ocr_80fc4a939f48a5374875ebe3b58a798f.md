# ## HELLO, WORLD!

it's traditional in programming for the first code to be entered to output the words 'Hello, World!' to the screen. Interestingly, this dates back to 1968 using a language called BCPL.

+   **STEP 1** As mentioned, we use Windows 10 and the latest version of Code::Blocks for the rest of the C++ code in this book. Begin by launching Code::Blocks When click File > New > Empty File or press Ctrl+Shift+N on the keyboard.
