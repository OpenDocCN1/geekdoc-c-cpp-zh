# # PROJECT 5 LIGHTS, CAMERA, ACTION!

You can trigger a sound effect at the same time by snapping a PLAY SOUND block between the WHEN I RECEIVE and the SET BRIGHTNESS EFFECT blocks:

```
~~~
when I receive [Lightning v]
play sound [pop v]
set [brightness v] effect to (10)
~~~
```

You get the idea? Each event in your story can trigger as many code blocks as you want to use by broadcasting and receiving messages, like a director calling out instructions to actors and technicians during a rehearsal.
