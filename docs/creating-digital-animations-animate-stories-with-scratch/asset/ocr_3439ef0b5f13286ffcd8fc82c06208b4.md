+   1. **Open your Scratch project.**
+   2. **From the Scratch File menu, choose Record Project Video.**

You need to be signed in to see this option.

![](bbox=[0.14, 0.38, 0.91, 0.57])

+   3. **In the More Options menu, choose recording options (such as recording sound and mouse clicks).**
+   4. **To record the beginning of your project, click the Start button. Or if you want to start recording sometime after the start of the project, click the Green Flag button.**
+   5. **Click the Stop Recording button (below the Stage).**

After you have recorded for 60 seconds, Scratch stops recording automatically.

![](bbox=[0.14, 0.81, 0.91, 0.85])

+   6. **Click the Save and Download button to download the file to your computer.**
