Wait a minute! Why is there so little difference between the size of *Hector*'s face in the second and third image? Scratch has limitations on how much you can increase a sprite size when using **LOOKS** blocks. Fortunately, I can make *Hector* even larger in the Paint Editor.

# INCREASE THE COSTUME SIZE

You can increase the size of a character's costume by grouping the shapes and using the **Grow** tool near the very top of the Paint Editor. It is a good idea to duplicate a costume before changing its size so you can quickly switch back to its original size:

+   1. Click the **Costumes** tab.
+   2. Shift-click the current costume and choose **Duplicate**.
