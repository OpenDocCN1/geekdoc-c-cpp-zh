For clustering biological sequences, finding a suitable distance metric is challenging due to the complexity associated with these sequences. For instance, a protein sequence may be composed of various functional domains, and two protein sequences may only share a few of these domains; in that case the overall similarity between these two proteins will be wide. However, if the matched functional domains are highly significant, these sequences should belong to the same cluster. When clustering genome sequences, a similarity metric should only consider the coding part of the DNA and discard a significant part of the genome sequences, as junk DNA and tandem repeat. Below, we discuss a collection of distance metrics that can be used for measuring the distance between a pair of sequences. It is important to note that though we use the term metric, many of the similarity measurements may not be “metric” using its mathematical definition.

# 16.4.1.1 Alignment-Based Similarity

The most popular distance metric for sequence data is the Levenshtein distance, or edit distance [46]. The number of edits needed to transform one string into the other with the allowable edit permits insertion, deletion, or substitution a single pair of sequences, this distance can be computed by performing the global alignment between the sequences; for two sequences of length $l_1$ and $l_2$, the global alignment cost is $O(l_1l_2)$. This is costly considering that biological sequences (particularly, DNA sequences) are typically long. So, Levenshtein distance is not an ideal metric for biological sequences of sequence clustering. Another limitation of this metric is that it captures the optimal global alignment between two sequences, whereas for clustering biological sequences, local similarity between two sequences should be considered. Finally, the edit distance metric on the length of the sequence makes it a poor metric when the length of the sequences in the dataset varies significantly.

To capture the local similarity between two sequences, Smith-Waterman’s local alignment algorithm [46] can be used. Instead of aligning the entire sequence the local alignment algorithm similar regions between two sequences. The algorithm compares segments of all possible lengths and optimizes the similarity measure. Though it overcomes some of the problems of global alignment, it is as costly as the global alignment algorithm and is simply impractical for clustering biological sequences.

During the eighties and nineties, two popular tools, known as FASTA [80] and BLAST, were developed to improve the scalability of similarity search from biological sequence database. Both tools take a query sequence and return a set of statistically similar sequences from a sequence database. The main benefit of these tools is that they are highly scalable, as they adopt smart heuristics for sacrificing the strict optimality. Also, specifically BLAST has various versions (such as PSI-BLAST, PHI-BLAST, BLAST-In) that are customized based on the kind of sequences and the scoring matrix used. For a set of sequences, FASTA and BLAST also return list of pairwise sequences. For a pair of similar sequences, BLAST also returns score (also known as BLAST-score) which represents the similarity strength that can be used for clustering.
