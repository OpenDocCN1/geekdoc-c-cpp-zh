# 4.3.2 Divisive Clustering

Divisive clustering is a top-down approach where the procedure starts at the root with all the data and recursively splits to build the dendrogram. This method has the advantage of being more efficient compared to agglomerative clustering especially when there is no need to generate a complete hierarchy all the way down to the individual leaves. It can be considered a global approach since it contains the complete information before splitting the data.

# 4.3.2.1 Issues in Divisive Clustering

We will discuss the factors that affect the performance of divisive hierarchical clustering.

+   1. **Splitting criterion**: The Ward's k-means square error criterion is used here. The greater reduction in the difference in the SSE criterion should reflect the goodness of the split. Since the SSE criterion can be applied to numerical data, Gini index (which is used in decision tree construction) can be used for handling the nominal data.

+   2. **splitting method**: The method used to obtain the binary split of the parent node is also critical as it can reduce the time taken for evaluating the Ward's criterion. The Bisecting K-means approach can be used here with K=2 to obtain good splits it is based on the same criterion of maximizing the Ward's distance between splits.

+   3. **Choosing the cluster to split**: The choice of cluster to split may not be as important as the first two, but it can be useful to choose the most appropriate cluster for further split when the goal is to build a complete dendrogram. A simple method of choosing the cluster to be split further could be done by merely checking the square errors of the clusters and splitting the one with the largest value.

+   4. **Handling noise**: Since the noise points present in the dataset might result in aberrant clusters, a threshold should be used to determine the termination criteria rather splitting the clusters further.
