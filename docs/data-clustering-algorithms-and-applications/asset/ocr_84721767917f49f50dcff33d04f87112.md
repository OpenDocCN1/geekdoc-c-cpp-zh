# 14.3.3 Video Story Clustering

Story-level clustering of videos has been an indispensable ingredient to discover the stories based on different events. [14] develops a video clustering algorithm to merge the stories with the same theme based on the occurrences of concepts in the stories which are extracted from both video frames and keywords. All the video stories are represented by a bipartite graph, where each story is linked to the keyframe clusters and textual keywords associated with it. The association between a story and the associated keyframe clusters and keywords is computed based on two factors: (i) their occurrence frequency and (ii) the story frequency. A co-clustering algorithm based on the spectral clustering [33] was then applied to simultaneously group the stories into clusters with the same event theme as the keyframe and keyword clusters which describe the same story.

Let us denote the video-story matrix by $A_1$ and cluster-story matrix by A2. Two matrices are then concatenated to obtain the affinity matrix $A=[A_1^T A_2^T]$ for the bipartite graph. The normalized affinity matrix is then constructed: $A=D_1^{-1/2}AD_2^{-1/2}$, where $D_1$ and $D_2$ are diagonal matrices whose elements are the summation of row vector of $A_1$ and $A_2$, respectively. To obtain $k$ clusters from the bipartite graph, $l=[\log k]$ singular values are corresponding to the second smallest singular value using the $l+1$ singular value. The $k$-means algorithm is then run on the $l$-dimensional space using these singular values to yield the desired $k$-way partition of the bipartite graph.

The authors of [37] proposed a video clustering algorithm across multiple sources. It is noted that one event with the same topic is reported by multiple news channels, and it is interesting to cluster these videos with the same theme. To achieve this, a $K$-partite graph with clusters number of node sets is constructed. Each of the node sets contains the video segments within one source, and a pair of nodes in different segments is connected by an edge whose weight is the similarity between the video segments associated with these nodes. Also, the nodes in the same segment cannot be connected to each other. Similar to the clustering algorithm in [14], a spectral clustering algorithm is developed to cluster the videos from different sources into the stories with the same topics. The $K$-partite graph is constructed across the multiple sources, the obtained stories will cover the videos from different sources instead of the single news channel.
