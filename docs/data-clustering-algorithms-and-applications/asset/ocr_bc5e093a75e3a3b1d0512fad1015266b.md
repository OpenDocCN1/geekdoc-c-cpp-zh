To learn the structure of the tree, k-vs-all classifiers are trained to build a "confusion matrix" which is then used as the affinity matrix for spectral clustering. k-one-vs-rest classifiers are denoted by {f₁, ..., fk} ∈ v (no tree structure is used). The confusion matrix can be formulated as Cij = {(x,y) ∈ v : min fj(x) = j} on set v. For each internal node l of the tree, from the root, partition its label l by its children's label set Li = {c : c ∈ Nᵢ}, where Nᵢ = {c ∈ N : (i,c) ∈ E} and lᵢⱼ = lᵢ ∩ lⱼ, by maximizing

To optimize this function, which is a graph cut problem, the standard spectral clustering is applied [21]. Then b eigenvectors of L are used to form the matrix X=[x₁, x², ..., x_b] by stacking the eigenvectors column-wise. After that, the matrix Y is constructed from X by renormalizing each of X's rows to a unit length and directing each row of Y as in Rᵇ. Finally, they are clustered into b clusters using K-methods. Finally, in the original space are are assigned to cluster j if and only if i row of Y was assigned to cluster j to obtain such a label clustering at a specific node. Using a top-to-down label clustering scheme, an overall Label Tree structure is learned. A major drawback of this approach is that the spectral clustering produces only disjoint sets. It is difficult to learn a classifier for disjoint subsets when k classifiers cannot be clustered into a label set reliably. The clustering technique proposed in [3] requires k-one-vs-all classifiers for the spectral clustering technique, which is expensive when the number of classes is large. Recently, Deng et al. [13] presented a novel approach that can simultaneously determine the structure of the tree (label cluster of each label set) and learn the classifiers for each node in the tree, which not avoids initial k one-vs-all training, but also gains control over the efficiency versus accuracy trade-off in designing such classification tree.
