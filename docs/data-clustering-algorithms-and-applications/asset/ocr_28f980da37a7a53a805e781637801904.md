# 12.4.1.3 Fuzzy k-Modes

Fuzzy k-Modes extends fuzzy-Means to categorical data [48]. Fuzzy k-Modes is based on the same ideas as k-Modes, using iterative assignment of objects to the closest modes and evaluation of modes, until convergence. However, objects' assignments to clusters involve degree of membership between 0 and 1. The total membership of object $i$ across all clusters must equal 1, as $\sum_{j=1}^k w_{ij} = 1$, for any $i \le n$. The Fuzzy k-Modes algorithm evaluates the total cost against the whole dataset $X$, against a cost function $F(W, X, Z) = \sum_{i,j} w_{ij}^\alpha d(X_i, Z_j)$, where $\alpha \ge 1$ is a weighting factor and $Z_j = [z_{j1}, \dots, z_{jm}]$ is the mode of the $j$-th cluster. The weights $0 \le w_{ij} \le 1$ are set at each iteration, so that the $j$-th object will tend to join the $j$-th cluster with the least dissimilarity mode $Z_j$. In mode, $Z_j$ of cluster $l \le j \le k$, represented by $[z_{j1}, \dots, z_{jm}]$, has each position $z_{jj}$ for the attribute $A_j$ that will minimize the cost function. The cost function is the sum of the weighted distances of all objects against the cluster mode. It was proved that the k-Means algorithm will converge in a finite number of iterations. Its disadvantage is that it terminates at local local.

# 12.4.1.4 Squeezer

Squeezer is a one-pass algorithm that is based on summarizing clusters like k-Modes. However, Squeezer improves the iteration-bound speed of k-Modes [43]. Squeezer reads objects one-by-one. The first tuple forms a cluster alone. Next objects are either put into an existing cluster or rejected to form a new cluster.
Thequeezer algorithm accepts as input the dataset of objects and a value $s$ for the similarity threshold. The algorithm then fetches cluster objects in an iterative fashion. Initially, the first object is read and a new Clustering Structure is established, which includes a summary and the cluster itself. For each subsequent object, the similarity between any existing cluster C and the object is computed. The maximal similarity value (denoted by sim-max) and the corresponding index of a cluster (denoted by index) are evaluated from the computing results. Then, if the similarity is larger than the input threshold $s$, the object is assigned to the selected cluster. Otherwise, a new Clustering Structure is constructed, consisting of the cluster and summary. Finally, outliers are handled and the clustering results are returned.

One of the disadvantages of Squeezer is that on some datasets, it may not produce accurate clusters. Squeezer is considered efficient with a complexity of $O(kN)$.

# 12.4.1.5 COOLAT

COOLAT is based on similar ideas as k-Modes, but uses objects as clusters. COOLAT adapts to k-Modes sensitivity to the cluster modes problems. Clusters are created by reducing their entropy [19]. COOLAT finds a set of maximally dissimilar objects to create initial clusters. All remaining objects are placed in one of the clusters, such that the increase in entropy is minimized. The name of COOLAT comes from the reducing of entropy of the clusters, "cooling". Entropy is the measure of information and uncertainty of a random variable. If $X$ is a random variable, $S(X)$ is the probability function of $X$, the entropy $E(X)$ is defined as $E(X) = \sum_{x \in S(X)} p(x)\log(p(x))$.
