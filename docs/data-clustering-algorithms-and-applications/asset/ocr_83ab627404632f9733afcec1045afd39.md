# 16.4.2.3 Probabilistic Models

The probabilistic approach is popular for sequence modeling. For instance, the earliest approaches for modeling protein families use profile-HMM, a hidden Markov model-based probabilistic approach. However, the main objective of protein-HMM is to perform multiple sequence alignment. Since then, several methods have been proposed to use HMM for sequence clustering. We discuss a few of them.

Smith's work [99] is one of the first that uses HMM for clustering biological sequences. His method has two steps: the first step divides a pairwise distance between observed sequences by computing a symmetrized similarity. This similarity is obtained by training an HMM for each sequence, so that the log-likelihood (LL) of each model can be computed. This information is used to build an LL matrix which then used to cluster the sequences into k groups, using a hierarchical algorithm. In the second step, an HMM is trained for each cluster; the resulting models are merged into a composite HMM, where each HMM is used to design a disjoint part of this composite model. This initial estimate is then refined using the Baum-Welch procedure. As a result, a global HMM modeling of all the sequences is obtained. The number of clusters (k) is selected using a cluster method.

CLUSEG [116] uses conditional probability distribution (CPD) for characterizing a cluster, i.e., for different clusters the CPD of the next symbol being present is different, and the CPD can be used for clustering sequences. CLUSEG uses a new data structure, called a probabilistic tree (PST); every node in PST is a probability vector to store the probability distribution of the next symbol by the preceding segment. Usages of PST CLUSEG are very efficient. In the following paragraphs, we describe CLUSEG in detail.

The CLUSEG algorithm accepts a user-defined threshold parameters. At the beginning, all sequences in the database are clustered. Then, an iterative process is employed to continuously improve the quality of the clustering until no improvement can be made. In each iteration, CLUSEG starts with a new set of clusters; a few random from the unclustered set are chosen to clusters themselves. Then, it examines each sequence to evaluate its similarity to each of the clusters and chooses the cluster membership of that sequence, if their membership overlaps significantly. The key part of CLUSEG is the step which computes the similarity of a sequence to a cluster. For this, CLUSEG uses CPD of symbols for a given segment. Efficient computation of CPD, where the sequences in a cluster are stored in a probabilistic tree.
