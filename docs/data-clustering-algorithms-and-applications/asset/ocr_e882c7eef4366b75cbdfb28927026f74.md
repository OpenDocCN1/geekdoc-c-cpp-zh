As a consequence, the latent variable that models topics should be directly associated with the within-document segments, rather than to the document as a whole. Whose Segment-based Generative Model (SGM), a model that explicitly considers segments within each document by introducing a segment model variable in the generative process. SGM assumes that each document $d \in \mathcal{D}$ is a sequence of $n_d$ words and, at the same time, a set $S_d$ of contiguous, nonoverlapping blocks, or segments. The segmentation strategy is decoupled from SGM, the authors using Textiling in their implementation, utilizes latent variable $z$ to model topic distributions and the model variable $s$ to represent document segments. Figure 13.5 illustrates the graphical model representation of SGM. The generative process by SGM on a corpus $D$ of segmented documents can be summarized as follows:

+   1. Select a document from $\mathcal{D} \Rightarrow Pr(d)$
2. For each segment $s \in S_d$
   a. Choose a topic $z$ for the document, $d \Rightarrow Pr(z|d)$
   b. Associate topic-segment probability for segment $s, z \Rightarrow Pr(s|z)$
   c. For each word $w$ in the segment $s \Rightarrow Pr(w|z,s)$

SGM provides a fine-grained document-to-topic modeling by taking into account segments. Choosing a $Pr(z|d)$ in the generative process is based on the topic-segment association $Pr(s|z)$, intuitively providing a topical affinity for segment given a selected topic. Words are generated not only by topics, but also by segments $Pr(w|z,s)$. The above generative process can be translated into a joint probability model for data, in which each observation is described by an expression defined on documents, segments, and words:

```
$Pr(d, s, w) = Pr(d) \sum_{z \in \mathcal{Z}} Pr(z) Pr(s|z) Pr(w|z,s).$
```

Ponti et al. use Expectation-Maximization (EM) to estimate model parameters and to cluster the resulting document PMFs. The prototype $P_c$ of each cluster is represented as the mean of the PMFs of the documents within that cluster. The cluster merging criterion, the Hellinger distance, decides the pair of clusters to be merged The merging scoring criterion calculates the average distance between the prototypes of each pair $(P_c, P_{c'})$ and the prototype of the union cluster $(P_{c \cup c'})$. The pair of clusters with the minimum score is chosen to be merged. Intuitively, this chooses the merged cluster hierarchy that is closest to the original cluster. The algorithm stops when the cluster hierarchy is completed or the desired number of clusters is reached.
