
## Educational and Software Resources for Data Clustering

- **General Data Clustering Survey**: In these surveys, the problems of data clustering is addressed in a general way and not specific to a particular technique or data type. However, the area of clustering is so vast, that most of these surveys tend to be overview articles.
- **Technique-Centered Survey**: In these, a specific technique such as spectral clustering or k-means clustering is addressed.
- **Data Type-Centered Survey**: In these surveys, a specific kind of data type as time-series data, high-dimensional data, or text is addressed by the survey. Different data types provide different challenges to clustering algorithms. Therefore, the clustering methods for a specific data type are often closely related and addressed in a specific survey.

An excellent review article on the topic of data clustering is available in [19]. This article provides an overview of the main issues in data clustering. Two other excellent survey articles are available in [32, 6]. These provide a good overview of the landscape, though not in detail. This is to be expected, since the area of clustering is too vast to be covered by a single publication on the topic.

Many articles have been written, which cover *specific techniques* of data clustering. An excellent overview of the k-means algorithm, which also provides a historical perspective, is presented in [17]. The *k-means method* is a classical technique, which is closely related to hierarchical clustering algorithms. This is covered extensively in [28]. Hierarchical clustering algorithms are also used frequently for data clustering for organization of large corpora. A survey of such algorithms for data is presented in [31, 34]. Spectral techniques are an important class of methods which have found significant popularity in the clustering literature. Two surveys on spectral clustering may be found in, [24, 11]. The survey in [24] is considered classical. While evolutionary clustering algorithms have not found much popularity in the research literature, they have turned out be quite useful for practitioners. A survey on evolutionary clustering algorithms may be found in [16].

Probabilistic clustering algorithms are very popular in the data mining literature because of their interpretability. A closely related class of algorithms is the fuzzy clustering method. Techniques for fuzzy clustering are covered extensively in [4, 5].

Numerous articles have also been written on clustering in specific data types or domains. The problem of clustering high-dimensional data was first covered in [29] and more recently in [22]. Since high-dimensional clustering is a recent topic, and much research on the area has been reported lately, the survey [22] is much more extensive. Data is a particular case of sparse high-dimensional data, for which clustering methods provide a tremendous challenge. For example, hierarchical methods for document clustering have been studied in [31, 34], and a general survey on text clustering is provided in [2].

Many data types are *contextual* in which dependencies exist between data items. Items of such data sets (continuous) time-series data, discrete sequential data (which could be either temporal or biological), and graph data. Contextual data provides a special challenge because the dependencies between the data items need to be accounted for during the clustering process. Numerous have been written to address such contextual domains. An excellent survey on time-series data clustering may be found in [23], while the biological data domain is addressed in [20, 25]. Graph clustering is a recent area which has been popularized by the advent of social and information networks. Graph data clustering is addressed in [12, 30]. The survey in [12] is recent and particularly exhaustive.

## 24.3 Software for Data Clustering

A significant amount of software is available for data clustering. Interestingly, most of the sophisticated software on data clustering is open-source software, which is freely available at different websites. On the other hand, most of the commercial software comprises implementations of simpler and more classical algorithms such as k-means or agglomerative clustering.

### 24.3.1 Free and Open-Source Software

In this section, we will first address the widely used general purpose clustering software. Later, we will provide some additional specialized software that are used for specific data clustering applications.

### 24.3.1.1 General Clustering Software

The well-known general purpose site offering open source software is the WEKA machine learning repository [39]. This is a general purpose repository which contains software not just for clustering, but for other data mining tasks such as data preprocessing, classification, and visualization. However, most of the software can be used for data clustering.

Spider is another widely used data mining software which contains the implementations of several popular clustering algorithms [54]. It is an object-oriented environment for machine learning in MATLAB. Its recent version also provides WEKA interfaces to the machine learning libraries built in Spider.

Cluster is another widely used open-source software that contains several clustering and visualization algorithms [45]. It is very popular in the bioinformatics community. In addition to the standard algorithms, it provides an excellent graphical environment for analyzing complex datasets. The other advantage of this software is that it allows users to use the clustering algorithms in other programming languages as Python, MATLAB, and R. In addition to the above mentioned software, programming platforms such as MATLAB and R already have their own implementations of some of the commonly used data clustering.

Another comprehensive set of data clustering packages is provided in the ELKI [11] suite of algorithms that include classical partitioning algorithms, EM-based probabilistic algorithms, density-based algorithms, and subspace clustering algorithms. The Nuggets site [42] provides access to a significant number of open-source software for clustering and segmentation. This can be a meta-repository, that it points to other relevant sites.

### 24.3.1.2 Specialized Clustering Software

OpenSubspace is an open-source software that contains the implementations of several subspace clustering algorithms [41]. A more description is provided in [27]. It integrates state-of-the-performance measures and visualization techniques for analyzing subspace clusters in the WEKA environment. The MOA framework also implements a number of clustering algorithms and provides tools for their evaluation [7]. Related to Weka, it supports the extension with new clustering algorithms, new stream generators, and new evaluation measures. The Weka implementation of the framework may be found in [86].

For text data, the cross-bow method is available for download [43]. This technique uses EM-clustering of text data, with the use of hierarchical partitioning of text documents. There are other operational software such as MALLET [35] which performs clustering along with statistical natural language processing and topic modeling. CLUTO [46] is a software package for clustering low- and high-dimensional data sets and for analyzing the characteristics of the various clusters. One advantage of this software is that it is general purpose. It can be used for text data, multi-dimensional data, or even transaction data. There are some other packages that perform traditional clustering on documents [44].

A significant amount of software is also available for contextual data. For time-series data clustering, an open-source software Gait-CAD is publicly available under the GNU public license. This is downloadable from sourceforge [49] and is a MATLAB toolbox. For gene expression clustering, one of the most popular tools is Cluster, which has an ancestral TreeView software for better visualization [10]. A more detailed discussion of the available software for analyzing gene expression and other forms of biological data can be found in the biological data clustering of this book (Chapter 16).

Numerous clustering tools are available for graph-partitioning and clustering. The network analysis tools (NEAT) provides a number of tools for the analysis of network data, though the focus is primarily on biological networks. In addition, many individual graph clustering tools are available at different sites. One of the most famous graph partitioning algorithms is METIS [46]. In spite of being one of the earlier methods, it performs competitively with most of graph clustering algorithms, in terms of effectiveness and efficiency. CFinder is a free software for finding and overlapping dense groups of nodes in networks, based on the Clique Percolation Method (CPM) [53]. Another software for Markov Clustering of networks provides high scalability for the clustering process. For supervised clustering, many different implementations of algorithms that perform constrained clustering are available in [57].

### 24.3.2 Commercial Packages

Many mathematical tools such as MATLAB [52] come with built-in methods for data clustering. However, typically, such methods use classical techniques such as the k-means algorithm. This is because they are general purpose tools, and the clustering capability is not the main power of such software. However, numerous commercial tools have been constructed, with a specific goal of clustering different kinds of data. The KDnodes site [42] provides a link to some of the most popular forms of software in the domain. This site provides software developed by other vendors such as IBM and SAS data mining software [50]. This includes two step, k-means, and Kohonen clustering algorithms. Another well-known package is the IBM SPSS and SAS Enterprise Modeler [51]. In this case, the clustering tool is available with other forms of visual and decision support. SAS has built-in procedures that can perform clustering of large-scale datasets.

Providing graphics and visualization capabilities is important for getting an intuitive understanding of the clustering process. Clustan [56] offers such capabilities with strong graphics support. The NeuroXL Clusterizer [58] is a clustering tool for neural networks. The advantage of this tool is that it naturally integrates with Microsoft Excel and can, therefore, be easily used for spreadsheet data.
