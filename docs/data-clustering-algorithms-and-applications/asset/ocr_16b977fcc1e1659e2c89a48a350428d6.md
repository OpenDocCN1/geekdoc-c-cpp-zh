**Lemma 23.2.7** Given $K' \le K$, $\varepsilon \le 1 - 1/K$.

PROOF $\sigma_1 : \{1, \dots, K'\} \to \{1, \dots, K\}$ is the optimal mapping of the classes to different clusters, i.e.,

```
$$\varepsilon = 1 - \frac{\sum_{j=1}^K n_{\sigma_1(j),j}}{n}$$
```

Then construct a series of mappings $\sigma_s : \{1, \dots, K'\} \to \{1, \dots, K\}$ ($s = 2, \dots, K$) which satisfy

```
$\sigma_s(j) = \mod(\sigma_{s-1}(j), K) + 1, \forall j \in \{1, \dots, K'\}$
```

where $\mod(x,y)$ returns the remainder of positive integer $x$ divided by positive integer $y$. By definition, $\sigma_s$ ($s=2, \dots, K$) can also map $\{1, \dots, K'\}$ to $K'$ different indices in, $\{1, \dots, K\}$ as $\sigma_1$. More importantly, $\sigma_{j=1}^K n_{\sigma_s(j),j} \ge \sum_{j=1}^K n_{\sigma_{s-1}(j),j}, \forall s=2, \dots, K$; and $\sum_{j=1}^K n_{\sigma_1(j),j} = n$. Therefore, $\sum_{j=1}^K n_{\sigma_1(j),j} \ge n\varepsilon$, which implies $\varepsilon \le 1 - 1/K$. The proof is completed.

Therefore, $1-1/K$ is used as the upper bound of $\varepsilon$, and the normalized $\varepsilon_n$ is shown in Table 23.5.

# **23.2.3 The DCV Criterion**

In this section, experiments are presented to show the importance of DCV ($CV_1-CV_0$) for selecting validation measures.

**Experimental Data Sets.** Some synthetic data sets were generated as follows: One is a two-dimensional mixture of two Gaussian distributions. The means of the two distributions are $[-2,0]$ and $[2,0]$. And their covariance matrices are the same as $[\sigma^2 \ 0; 0 \ \sigma^2]$.

Therefore, given any specific value of $\sigma^2$, one can generate a simulated data set with $n_1$ instances from the first, and $n_2$ instances from the second, where $n_1+n_2=600$. To produce simulated data sets with imbalanced class sizes, a set of $n_1$ values $\{3000, 2200, 1800, 1400, 600\}$. If $n_1=200, n_2=580$, the data set is highly imbalanced with $CV_0$ ranging from $0$ to $1.5$; to produce data sets with different clustering densities, a set of $\sigma^2$ values, $\{0.5, 1, 1.5, 2, 3.5, 4, 4.5, 5\}$, was used. As the mixture model tends to be more unstable, finally, for each pair, the sampling was repeated $10$ times to have the average clustering performance. In summary, $8 \times 10=80$ data sets were produced. Figure 23 shows a data set with $n_1=1000$ and $\sigma^2=5$.

A sampling on a real-world data set tech was used to get some data sets with imbalanced class distributions. This data set was derived from the San Jose Mercury news papers, which contains 2301 documents about computers, electronics, health, medical, research, and technology. Each document is characterized by 126373 words, and class sizes are 485, 116, 229, 603, 481, and 187. Carefully selecting the sampling ratio for each class, 8 sample sets were extracted with the class-size distributions ($CV_0$) ranging from 0.490 to 1.862, as shown in Table 23.6. For each data set, the sampling was repeated $10$ times to observe the average clustering performance.
