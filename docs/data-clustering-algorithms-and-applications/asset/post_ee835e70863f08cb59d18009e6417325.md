### 12.4.2.3 LIMBO

LIMBO handles the clustering problem by building a tree, where a node contains statistics about the objects that are members of the corresponding cluster. New objects are added to the tree in a top-down fashion by finding the best matching and breaking it into a new node, extending the tree. LIMBO employs Entropy and the Information Bottleneck (IB) framework for quantifying the relevant information preserved when clustering [16]. LIMBO scales to large datasets using a memory bound storage for the data, improving on the scalability of other hierarchical clustering algorithms. The most similar to LIMBO is the LOCOOL a nonhierarchical algorithm also based on minimization, which was presented previously.

LIMBO summarizes a cluster of objects using a Distribution Cluster Feature (DCF). For a cluster c, DCF(c) = (p(c), p(A(c))), where p(c) is the probability of cluster c, and p(A(c)) is the conditional probability distribution of the attributes within cluster c. The DCFs are used to calculate the distance between clusters or a cluster and an object. The LIMBO algorithm proceeds in three phases. In the first phase, the DCF tree is constructed to summarize the data. In the second phase, the DCFs of the tree leafs are merged to produce a number of clusters. In the third phase, each object is associated with the DCF to which the object is closest.

Phase 1 by starting and inserting objects into the DCF tree one or more DCFs. A tree is created, where a node contains each object. Object O is converted into DCF(o). Then, starting from the root, a path downward in the DCF tree is traced. When at nonleaf node, the DCF(o) and each DCF of the node is computed, finding the closest DCF to DCF(o). The child pointer of this entry to the next level of the tree. When at a leaf node, DCF(c) denotes the DCF in the leaf node that is closest to DCF(o). DCF(c) is the summary of some cluster c. At this point, the decision is made whether o belongs to the cluster or not. If there is an empty leaf in the leaf that contains DCF(c) (according to a space bound) DCF(o) is placed in that leaf. If there is no empty leaf and there sufficient free space, the leaf is split into two leaves. The two DCFs in the leaf node that are farthest apart are used as seeds for the new leaves. The remaining DCFs and DCF(o) are placed in the leaf that contains the closest DCF.

Phase 2 clusters the leafs of the DCF tree. After the construction of the DCF tree, the leaf nodes represents the DCFs of a cluster C objects. Each DCF corresponds to a cluster c ∈ C and contains statistics for clustering probability p(c). The Agglomerative Information Bottleneck (AIB) algorithm is used to cluster the DCFs in the leafs and produce clustering of the DCFs. Any clustering algorithm is applicable at this phase of the algorithm.

Phase 3 associates objects with clusters. For a chosen value of k, Phase 2 produced k DCFs In the final phase 3, a scan over the dataset assigns each object to the cluster whose representative DCF is closest to the object.

### 12.4.3 Density-Based Clustering

Density-based approaches use a local density criterion for clustering categorical data; clusters are subspaces in which the objects are dense and separated by subspaces of low density. Densitybased methods are used in bioinformatics for finding the subsets in networks, typical involving cliques [13, 18]. Advantages of density-based algorithms include time efficiency and the ability to find clusters of arbitrary shapes. A challenge of applying density-based clustering to datasets is that the “cube” of attribute values has no ordering defined. Some density-based algorithms use user-specified input parameters, though usually do not require the number of clusters k. They sometimes identify clusters of varying densities. With density-based algorithms the central subspace of a cluster cannot be distinguished from the rest of the cluster based on a higher density [35, 38, 76]. Some density-based approaches are also grid-based, since a histogram is constructed by partitioning the dataset into a number of nonoverlapping regions.

## Data Clustering: Algorithms and Applications

### 12.4.3.1 Projected (Subspace) Clustering

Projected clustering is motivated by high-dimensional clusters, where clusters exist only in specific attribute subsets. Subspaces are subspaces of high-dimensional datasets, determined by the subset of attributes most relevant to each cluster. The object membership in a cluster is defined by a specific range of values for the relevant attributes, while objects of other clusters are unlikely to have such values. The drawback of projected (subspace) methods is that clustering depends on user parameters for determining the relevant attributes to each cluster; the number of clusters or the average number of dimensions for each cluster. Projected clustering may distinguish the center of a cluster based on a high frequency of values for the relevant attributes [4, 2, 3]. Next, we present several subspace clustering algorithms.

### 12.4.3.2 CACTUS

CACTUS is a projected clustering method, which assumes that a cluster is identified by a unique set of attribute values that seldom occur in other clusters [32]. It searches for the minimal set of relevant attributes that are sufficient to define a cluster.

Assume all attributes $A_1, ..., A_m$ are independent and all values in attribute are equally likely. Then, the measure $\sigma(a_i, a_j)$ indicates the co-occurrence (and the similarity) of attribute values $a_i$ and $a_j$. The values $a_i$ and $a_j$ are strongly connected if their co-occurrence $\sigma(a_i, a_j)$ is higher than a user-specified factor $\alpha > 1$ the value expected under the attribute-independence assumption.

A set of values $\{c_1, ..., c_k\}$ over the attributes $\{A_1, ..., A_m\}$ is a cluster if the set $C$ is a set of strongly connected attribute values. In other words, the condition should be satisfied that all pair of values in $C$ are strongly connected and their co-occurrence $\sigma(c_i, c_j) > \alpha$ for $i \neq j$. $C$ is also a subspace; a subcluster if there is another value for one of attributes $\{A_1, ..., A_m\}$ that is not included in $C$, but strongly connected to the other attribute values in $C=\{c_1,...\}$.

The CACTUS algorithm collects inter-attribute summaries and intra-attribute summaries on categorical datasets. The inter-attribute summaries consist of all connected attribute value pairs where each has attribute values from different attributes. The intra-attribute summaries consist of similarities between attribute values of the same attribute. Then, the CACTUS algorithm consists of three phases: summarization, clustering, and validation. The summarization phase computes the summary information order to discover a set of candidate clusters. The validation phase determines the actual set of clusters from the set of candidate clusters.

A drawback of CACTUS is that the assumption of a cluster being identified by a unique set of attribute values that seldom occur in other clusters may be unnatural for clustering some real world datasets. CACTUS may also return many clusters [76, 35, 38].

### 12.4.3.3 CLICKS

CLICKS is another subspace clustering method, standing for “Subspace Clustering of Categorical data via many-partite cliques.” CLICKS creates a graph representation of the dataset, where nodes are categorical values and an edge is a co-occurrence of values in an object.

CLICKS models a categorical dataset $D$ as a graph where nodes are attribute values that form disjoint sets, one per attribute. Edges between different partitions indicate dense relationships. A $k$-partite clique is a subgraph $C$ consisting of two disjoint sets of nodes, where every pair differs. The $k$-partite clique $C$ is a maximal $k$-partite clique if it has no $k$-partite superset. $C$ is dense if the number of nodes in the dataset that have values defined by $C$ exceeds a user-specified threshold.

A $k$-subspace $C = \{x_1 \times \dots \times x_k\}$ is a (sub)clique if and only it is a maximal, dense, and a strongly connected $k$-partite clique in $D$, such that most or pairs of nodes are connected by an edge.

CLICKS uses a three-step approach to mine all clusters in $D$. In the preprocessing step it creates the $k$-partite clique from the input database $D$. In the detection step, it enumerates maximal $k$-partite cliques in the graph. The approach of this step is based on a backtracking strategy that tries to expand the current clique to ensure maximality. In the postprocessing step it verifies the density property for the detected cliques, given a user-specified threshold. A maximal clique may fail the density test, whereas one of its subclusters may be dense.

Disadvantages include that CLICKS may return too many clusters or too many outliers [76].

### 12.4.3.4 STIIR

STIR stands for “Sieving Through Iterated Reinforcement.” STIR is an iterative approach for assigning and propagating weights on the categorical values; this allows a similarity measure for categorical data, which is based on the co-occurrence of values in the dataset. STIR looks for relationships between attribute values to detect a potential cluster and converges to clusters of highly correlated values between different categorical attribute fields [34].

Each possible value in a categorical attribute is represented by a node and the data is represented as a set $D$ of objects. Each object $o \in D$ is represented as a set of nodes, consisting of one node from each attribute. STIR assigns a weight $w_v$ to each node $v$. The weight configuration is referred to as $w$. A normalization function $N(w)$ rescales the weights of the nodes associated with an attribute so squares add up to one.

A function $f$ is repeatedly applied to a set of nodes $u$ until a fixed point $u$ is reached for the function $f$ map the nodes to a new configuration. So, the purpose is to converge to a point that remains under repeated iterations of $f$. $f$ updates a weight $w_v$ for node $v$ by applying an operator $\phi$ to all objects that contain value $v$ (as well as $m-1$ other values) and summing them, as follows:

```
for each object o = {u_1, \dots, u_{m-1}} that contains value $v$

w_v \longleftarrow \sum_{r} X_r$
```

The operator $\phi$ may be a simple multiplication or addition operator. The function $f$ then normalizes the set of weights using $N$. After several iterations of yielding a new configuration $f(w)$ the system is expected to converge to a point where $f(w) = \mathbf{w}$. Then, the nodes with large positive weights and the nodes with negative weights represent dense regions in the dataset that are separated and have few interconnections, defining clusters.
