Parallel and distributed implementation: An orthogonal direction for improving the scalability of matrix factorization methods is to use parallel and distributed computing platforms, [42, 80, 6]. MapReduce is a programming model for processing and generating large data sets [26]. Although the initial purpose of MapReduce is to perform large-scale data processing, it turns out that this model is more expressive and has been widely used in data mining and machine learning tasks [11, 2, 15]. Liu et al. [80] successfully scaled up the basic NMF for web-scale dyadic analysis using MapReduce, and Sun et al. [108] presented different matrix multiplication implementations and scaled up three types of nonnegative matrix factorizations on MapReduce. Recently, Graphics Processing Unit (GPU) implementation of the NMF algorithms has also been reported [65, 84, 93].

# 7.5 NMF Related Factorizations

Here we provide an overview of related matrix factorization methods.

+   1. SVD: The classic matrix factorization [45, 50], $X \approx U\Sigma V^{\text{T}}$, where $U, V$ have mixed signs; the input data could have mixed signs. Abstracting $\Sigma$ into $U$, we can write

SVD: $X_{\pm} \approx U_{\pm}V_{\pm}$. (7.14)

+   2. NMF: When the input data is nonnegative, we restrict $F$ and $G$ to be nonnegative. The standard NMF can be written as

NMF: $X_{\+} \approx F_{\+}G_{\+}$. (7.15)

using an intuitive notation for $X, F, G \ge 0$.

+   3. Regularized NMF: Additional constraints can be added to the standard NMF formulation. In general, regularized NMF can be written as the following optimization problem:

\min_{F,G \ge 0} \||X - FG^{\text{T}}\|^2 + \alpha_1(F) + \beta J_2(G)$, (7.16)

where the functions $J_1(F)$ and $J_2(G)$ are penalty terms to enforce certain constraints and $\alpha$ and $\beta$ are the characterizing regularization parameters [90]. Many different penalty terms have been used in the literature to have different effects on the computed solutions such as the smoothness constraint (e.g., the matrix norm) [90], the sparsity constraints (e.g., $L_1$-norm regularization), the geometric constraints (e.g., manifold structures) [12], and the local learning regularizations by neighborhoods [51].

+   4. Projective NMF: A projective NMF model aims to find an approximate projection of the input matrix [132, 24]. It can be formulated as:

$X \approx FF^{\text{T}}X$. (7.17)

The idea of the projective NMF is similar to subspace clustering.

+   5. Semi-NMF: When the input data is mixed, we restrict $G$ to be nonnegative placing no restriction on the signs of $F$. This is called semi-NMF [37, 36]:n
semi-NMF: $X_{\pm} \approx F_{\pm}G_{\+}$. (7.18)
