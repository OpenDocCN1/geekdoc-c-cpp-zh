When noise is introduced, the intercluster separation can decrease sharply since it uses the minimum pairwise distance, rather than the average pairwise distance, between objects in different clusters. Thus, the value of $D$ may change dramatically and the corresponding cluster number will be influenced by the noise.

Since $CH = \{(SSB/SSE) \cdot (n-NC)/(NC-1)\}$ and $(n-NC)/(NC-1)$ is constant for the same $NC$, only $(SSB/SSE)$ needs to be considered. By introducing noise, SSE increases in a more significant way compared with SSB. Therefore, for the same $NC$, $CH$ will decrease by the influence of noise. Finally, the optimal cluster number will be affected by noise.

Moreover, the other indices both $CH$ and $D$ will be influenced by noise in a less significant way. Comparing Table 23.15 with Table 23.14, it is clear that the values of other indices change to some degree. If adding 20% noise to the data set *Separated*, the optimal cluster number suggested by $I$ will be incorrect. Thus, in order to minimize the adverse effect of noise, it is advisable to remove some noise before clustering.
