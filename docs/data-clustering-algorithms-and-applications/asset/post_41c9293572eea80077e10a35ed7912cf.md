## 2.2.1.5 Multicluster Feature Selection (MCFS)

Similar to the motivation illustrated in (2.3), Cai et al. in [9] propose a multicluster feature selection method that is able to select the set of features that can cover all possible clustering in the data. In MCFS, spectral analysis is used to measure the correlation between different features without needing label information. Using the top eigenvectors of graph Laplacian, spectral clustering can cluster data samples without utilizing label information. Thus, MCFS applied k-Nearest-Neighbors approach to construct the graph of data samples, where $k$ is a predetermined parameter. Next, the heat kernel weighting $W$ is computed as:

$W_{ij} = e^{-\frac{\|x_i - x_j\|^2}{\sigma^2}}$

where $x_i$ and $x_j$ are connected samples in the k-Nearest-Neighbors graph and $\sigma$ is used as a predefined parameter. From $W$ a dense matrix is constructed as explained earlier in this chapter. Then, a graph Laplacian matrix $L = D - W$ is constructed. After that, MCFS follows the following equation:

```
$Ly = \lambda Dy$ (2.6)
```

Given $Y = [y_1, \dots, y_K]$, the eigenvectors of Equation (2.6), we can represent a subset of features by minimizing the objective function:

```
$$\min_{a_k} ||y_k - X^T a_k||^2\ns.t. \ ||a_k||_0 = 1$
```

Where $a_k$ is an $m$-dimensional vector and $||a_k||_0$ is the number of nonzero elements in $a_k$. Then, $K$ sparse coefficient vectors will be chosen to represent each cluster. For each feature $f_j$, the weight $a_k$ to $f_j$ will be chosen. Finally, MCFS will choose the top $l$ features. MCFS shows improvement over other methods such as LS like [9].

## 2.2.1.6 Weighting K-means

k-means is one of the most popular clustering techniques. It has been extensively used in data mining and machine learning problems. A large number of k-means variations have been proposed to handle feature selection [7, 68, 28, 25, 46]. Most of these variations by clustering the data into clusters. Then, weight is assigned to each feature. The feature that minimizes within-cluster distance and maximizes between-cluster difference is preferred and hence, gets higher weight. In [28], an entropy weighting k-means (EKWM) is proposed for subspace clustering. It simultaneously minimizes the within-cluster dispersion and maximizes the negative entropy in the clustering process. EKWM calculates the weight of each feature in each cluster by weighting the subset of features corresponding to each cluster, then, selected based on that weight.

In addition, [46] proposes feature weighting k-means clustering using generalized Fisher ratio that minimizes the ratio of average-within distortion over average-between distortion. In algorithm, several candidate clusters are generated and the one with the minimal Fisher ratio is deemed the final cluster.

Similarly, [25] proposes another variation of feature weighting k-means (W-k-means) that measures the weight of each feature based on its variance of the within-cluster distance. Algorithm 4 illustrates the process of W-k-means. It, iteratively, minimizes Equation (2.7).

## 2.2.2 Algorithms for Text Data

Document clustering aggregates documents into meaningful clusters that reflect the content of each document. For example, in the news wire, manually assigning one or more categories for each document require exhaustive human labor, especially with the huge amount of text uploaded daily. Thus, efficient clustering is essential. Another problem associated with document clustering is the number of terms. In a matrix representation, each term will be a feature and each document an instance. In typical cases, the number of features will be close to the number of words in the dictionary. This presents a challenge for clustering methods where the efficiency will be greatly degraded. However, a huge number of these terms are stop words, irrelevant to the topic, or redundant. Thus, removing these unnecessary words may significantly reduce dimensionality.

Feature selection not only reduces computational time but also improves clustering results and provides better data interpretability [48]. In document clustering the set of selected words that are related to a particular cluster will be more informative than the whole set of words in the documents respect to that cluster. Different feature selection methods have been used in document clustering recently, for example, term frequency, pruning infrequent terms, pruning highly frequent terms, and entropy-based weighting. Some of these methods and others will be explained in the following subsections.
