- **10. Multi-layer NMF:** In multi-layer NMF, the basic factor matrix is replaced by a set of matrices using a sequential decomposition [22, 32, 23]. Given an input matrix $X$, it is first decomposed as $F_{(1)}G_{(1)}^T$. In the second step, $G_{(1)}$ is further decomposed into $F_{(2)}G_{(2)}^T$ and the process is repeated a number of times. The multi-layer NMF model can be represented as follows:

```
$X \approx F_{(1)}F_{(2)}\dots F_{(L)}G_{(L)}^T = FG^T. \quad (7.26)$
```

It has been shown that the multi-layer NMF can improve the performance of most NMF algorithms and address the problem of local minima in the distributed and multi-stage nature and the sequential decomposition with different initial conditions [24].

- **11. Binary NMF:** When the input data $X$ is binary, binary NMF factorizes $X$ into two matrices thus conserving the most important property of $X$ [141, 140, 71]. The binary NMF model can be written as

```
Binary NMF: $X_0^{-1} \approx F_0G_0^{-1}. \quad (7.27)$
```

A special case of binary NMF is the boolean factorization

```
$X_0^{-1} \approx W_0 \oplus H_0^{-1}. \quad (7.28)$
```

- **12. Weighted Feature Subset NMF:** In weighted NMF, weights are incorporated to indicate the importance of the corresponding rows and columns. If we consider only the importance, this leads to the weighted subset NMF (FS-NMF):

```
$$\min_{W \ge 0, G \ge 0} ||X-FG^T||_W^2, \sum_j W_j^a = 1, \quad (7.28)$$
```

where $W \in \mathbb{R}^{m \times m}$ is a diagonal matrix indicating the weights of the rows (or features) in $X$, and $\alpha$ is a parameter [116, 117]. In general, we can assign weights to different samples. This leads to the weighted FS-NMF:

```
$$\min_{W \ge 0, G \ge 0} ||X-FG^T||_W^2$$
```

where we set $W_{ij} = a_{ij}b_j$.

```
$$\min_{W \ge 0, G \ge 0} (X-FG^T)_{ij}^2 a_{ij}b_j, s.t. \sum_i a_{ij}^a = 1, \sum_j b_j^b = 1, \quad (7.29)$$
```

where $\alpha, \beta$ are two parameters with $0 < \alpha < 1, \beta < 1$.

- **13. Robust NMF:** Recently a robust NMF using $L_{2,1}$-norm loss function has been proposed in [63]. The error function is

```
$||X-FG^T||_{2,1} = \sqrt{\sum\sum (X-FG^T)_{ij}^2}, \quad (7.30)$
```

The proposed robust NMF can handle outliers and noises in a better way than standard NMF.

# Nonnegative Matrix Factorizations for Clustering: A Survey

In summary, various newly proposed NMF formulations are collectively presented as follows:

- SVD: $X_{\pm} \approx U_{\pm}V_{\pm}^T$
- NMF: $X_{\pm} \approx F_{\pm}G_{\pm}^T$
- Regularized NMF: $\min \{\|X - FG^T\|^2 + \alpha J_1(F) + \beta J_2(G)\}$
- Projective NMF: $X \approx FF^T X$
- Semi-NMF: $X_{\pm} \approx F_{\pm}G_{\pm}^T$
- Convex-NMF: $X \approx CG^T, \text{ where } c_i \in \text{conv}(X)$
- Cluster-NMF: $X \approx XG_iG_i^T$
- Kernel-NMF: $\Phi(X_{\pm}) \approx (X_{\pm})W_{\pm}^T$
- Tri-Factorization: $X_i \approx F_i S_i G_i^T$
- Symmetric-NMF: $W_1 \approx H_1 S_1^T$
- Multi-layer NMF: $X \approx F_{(1)}\dots F_{(t)}G_{(t)}^T$
- Binary NMF: $X_{0}^{-1} \approx F_{0}^{-1}G_{0}^{-1}^T$
- Weighted Subset NMF: $\min \|X - FG^T\|_W^2$
- Robust NMF: $\min \|X - FG^T\|_R^2$

Note that there are other NMF formulations that are not included in the above discussion, such as convolutional NMF for a set of nonnegative matrices [24] and Bayesian NMF with Bayesian techniques [14, 45].

# NMF for Clustering: Extensions

We have shown that NMF provides a general framework for unsupervised learning. NMF widely varying data distributions and can do both hard and soft clustering. In fact, many other clustering problems such as co-clustering, consensus clustering, supervised clustering, and graph clustering can be reformulated as NMF problems.

## 7.6.1 Co-clustering

In real world applications, clustering often involves more than one type of data points and the input data relating types of data. In document analysis, there are terms and documents. In DNA microarray data, rows represent genes and columns represent samples. Co-clustering algorithms aim to cluster different types of data simultaneously by making use of relationship information such as the term-document matrix and the gene-sample matrix [30, 136, 20, 83].

To simultaneously cluster the rows and columns of the input data, tri-factorization has been proposed for nonnegative matrix decomposition [41], which aims to

```
$\|X - FSG^T\|^2, \text{ s.t. } F^T F = \mathbf{I}, G^T G = \mathbf{I}$.
```

That provides additional degrees of freedom from the low-rank representation remains accurate while F and G grow as symmetric matrices. Tri-factorization provides a nice metric framework.

## 7.6.2 Supervised Clustering

In many situations when we discover new patterns using clustering, there exists some prior, incomplete knowledge about the problem. We wish to incorporate knowledge into the clustering algorithm. Supervised clustering refers to the situation where the clustering is done with supervised-link constraints (two points may be clustered into the same cluster) and cannot-link constraints (two data points cannot be clustered into the same cluster) [5, 8, 4, 115, 129, 61].

The specified above constraints are formulated as follows [115]:

1. Must-link constraints. $A=\{(i_1, j_1), \dots, (i_a, j_a)\}; |A|$ contains pairs of points, where $x_i, x_j$ are considered similar and must be clustered into the same cluster.
2. Cannot-link constraints. $B=\{(i_1, j_1), \dots, (i_b, j_b)\}; |B|$, where each pair of points is dissimilar and cannot be clustered into the same cluster.

$A, B$ can also be viewed as symmetric matrices containing $\{0, 1\}$. Using cluster indicator $H$, the must-link $(i_1, j_1)$ implies that $x_i, x_j$ should have nonzero posterior probability over the same cluster $k$; the overlap $\sum_{(i,j) \in A}h_{ik}h_{jk} = (HH^T)_{ij}$ should be maximized. Thus, the must-link condition is $\max_H \sum_{(i,j) \in A}(HH^T)_{ij} = Tr[A(HH^T)] = Tr[AH^TH]$. Similarly, the cannot-link constraints can be formulated as penalty $\lambda Tr[BH^TB]$. But supervised clustering problem can be formulated as the following optimization problem:

```
$\max_{H H^T \ge 0} Tr[AH^TH] + \alpha Tr[BH^TB]; \quad (7.32)$
```

```
$\min_{H H^T \ge 0} ||(W^* - HH^T)||^2; \quad (7.33)$
```

Thus, the supervised clustering problem is equivalent to a semi-NMF problem [37, 72]. Chen et al. formulated supervised clustering with the instance-level constraints using nonnegative tri-factorization [17]; Zhu et al. [143] noted that must-link and cannot-link constraints play different roles in clustering and proposed a constrained NMF method where must-link constraints are used to control the distance of the data in the compressed format, and cannot-link constraints are used to control the encoding factor.

There are also some research efforts on incorporating the (partial) class label information into the matrix factorization framework. Lee et al. [69] presented supervised NMF (SSNMF) which jointly incorporates the data and the (partial) class label into NMF. Liu and Wu [81] proposed a form of constrained NMF by requiring that the data points sharing the same label have the same coordinate in the new representation space.
