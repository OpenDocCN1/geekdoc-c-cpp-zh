# 10.5.1 The HPSTREAM Method

The microclustering method can also be extended to the case of high-dimensional projected stream clustering. The algorithm is referred to as HPSTREAM. In [6, 7], methods have been proposed for high-dimensional clustering of data streams. The basic idea is to use an incremental algorithm in which we associate a set of dimensions with each cluster. This corresponds to the standard microclustering method as discussed in [6], with the main difference that the distance between data points to clusters is calculated on the basis of dimension-specific clusters. Therefore, additional information needs to be associated with a cluster to capture the set of dimensions associated with it. The set of dimensions is represented as a d-dimensional bit vector $B(C)$ for cluster $C$. This vector contains 1 for each dimension which is included in cluster $C$, in addition the number of clusters $K$ and the average cluster dimensionality $l$ used as an input parameter. The average cluster dimensionality $l$ represents the number of dimensions used in the cluster projection. An iterative approach is used in which the dimensions are used to update the clusters and decay-versa. Whereas the structure $FC$ uses a decay-based mechanism in order to adjust for evolution in the data stream. For a data point, which arrived $\delta$ units ago, its weight is $2^{-\lambda\delta}$, where $\lambda$ is the decay rate.

Therefore, the microclusters for the HPSTREAM algorithm contain decay-based statistics, whereas the microclusters are similar to the Clustream algorithm. Furthermore, the overall framework of the HPSTREAM algorithm is quite similar, because data points are assigned to microclusters based on their projected dimensions. The main difference is that each component of the additive cluster statistics is a decay-based weight. In addition, the bit vector corresponding to the choice of dimensions is stored with the microcluster statistics. Clearly, a number of changes need to be incorporated into the HPSTREAM approach in order to account for these:

+   - We update the statistics in each timestamp. However, it is not necessary to update the statistics at each timestamp, since all microclusters decay at the same rate. Rather, we perform the update only when a new point is inserted into the data. When a new point is inserted, and $\delta$ is the time interval since the last time, then all microcluster statistics are multiplied by $2^{-\lambda\delta}$ before adding a data point to the microcluster statistics.
- The average distance to each cluster is now computed on the basis of the projected dimensions specific to that cluster. The bit vector in the microcluster statistics is used in order to decide on the set of dimensions to use.
- The projected dimensions in the different clusters are updated periodically, so that the most compact dimensions are retained for each cluster. The corresponding bit vector in the microcluster is updated.

It has been shown in [6], that the incorporation of projections can significantly improve the effectiveness of the approach. Details are discussed in [6].

# 10.5.2 Other High-Dimensional Streaming Algorithms

A variety of high-dimensional streaming clustering algorithms have been proposed after the first HPSTREAM framework. In particular, a grid-based algorithm was proposed in [49] for high-dimensional projected clustering has also been applied to other domains such as uncertain data. For example, methods for high-dimensional projected clustering of uncertain data streams have been proposed in [4, 60].
