# 20.2 Clustering with Pointwise and Pairwise Supervisision

Semisvised clustering with pointwise and pairwise supervisision has been widely studied for feature-based clustering methods. In this section, we review some of the approaches from the literature [6].

# 20.2.1 Semisvised Clustering Based on Seeding

One of the earliest ideas on SSC focused on pointwise label supervision, where the cluster ids of a small number of points are available. SSC based seeding focuses on centroid-based clustering algorithms, such as k-means [2, 11]. In an unsupervised setting, algorithms usually start from a random initialization and perform expectation-maximization (EM)-style iterative updates of cluster members and cluster prototypes. The main idea in SSC based on seeding is to improve the initialization based on the available cluster ids. In particular, [2] lists two variants to k-means: *seeded k-means* and *constrained k-means*. Seeded k-means initializes the clusters using the available clusters and then runs the iterative updates for k-means. In k-means, let $K$ be the number of clusters and $S = \{x_1, ..., x_n\}, x_i \in \mathbb{R}^d$ denote the set of data points, let $K$ be the number of clusters and set $S = \cup_{j=1}^K S_j$ denote the initial seeds. The objective function improves as the iterative updates change. The *seeded k-means* algorithm is summarized in the following steps:

+   - Initialize cluster centers $\mu_h \leftarrow \frac{1}{|S_h|} \sum_{x \in S_h} x$, for $h = 1, ..., K$
- Assign each data point to the cluster $h^* = \text{argmin}_h |x - \mu_h|^2$
- Estimate cluster centers $\mu_h \leftarrow \frac{1}{|S_h|} \sum_{x \in S_h} x$, for $h = 1, ..., K$
- Repeat last steps until convergence

Constrained k-means also initializes the clusters with the available cluster ids, but the cluster assignments of these labeled points are not allowed to change during the iterative updates. *Seeded k-means* is more appropriate when the label seeding is not false.

SSC based on seeding can be generalized to other clustering methods beyond k-means, and [2] empirically evaluate the spectral-k-means. The seeding approach can be viewed in the probabilistic setting where we use the EM algorithm to learn mixture models [21], and each mixture component corresponds to a cluster. In particular, the supervisision is used to set the posterior probability $p(z|x_i, \Theta)$ of the labeled points to be the true class, 0 or otherwise.
