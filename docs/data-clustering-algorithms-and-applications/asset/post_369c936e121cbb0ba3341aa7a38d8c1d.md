The symmetry property treats the cluster structure as one of partitions. Therefore, the task of cluster validation is that transposing two partitions in the contingency matrix should not change the measure value. The property is not true for $F_n$, which is a typical measure. Also, $\epsilon_n$ is symmetric if only $K=K'$.

Intuitively, a mathematically sound measure should satisfy the $n$-invariant property. However, several measures, $R_n$, $FM_n$, and $\Gamma_n$, cannot fulfill this requirement. Nevertheless, they can be treated as $n$-invariant measures since they need to be $n$-invariant with the increase of $n$.

### Property 20.2.3: Convex additivity

Let $P=\{P_1, ..., P_k\}$ be a clustering, $P'$ be a refinement of $P$, and $P'_i$ be the partitioning induced by $P'$. Then a measure $O$ is convex additive if $O(M(P, P')) = \sum_{i=1}^k O(I_P, P'_i)$, where $n$ is the number of points in $P_i$, $I_P$ represents the partitioning on $P_i$ into one cluster, and $M(X, Y)$ is the contingency matrix of $X$ and $Y$.

The convexity property was introduced by Meila. Unnormalized measures including $F, VD$, and $\epsilon$ show this property along the lattice of partitions. None of the normalized measures studied in this chapter hold this property.

### Property 20.2.4: Left-domain-completeness

A measure $O$ is left-domain-complete if for any contingency matrix $M$ with statistically independent rows and columns

$O(M) = \begin{cases} 0, & O \text{ is a positive measure} \\ 1, & O \text{ is a negative measure} \end{cases}$

When the rows and columns in the contingency matrix are statistically independent, the poorest values of the measures are expected to be seen, i.e., 0 for positive measures and 1 for negative measures. Among all the measures, however, only $VI_n$ and $VD_n$ can meet this requirement.

### Property 20.2.5: Right-domain-completeness

A measure $O$ is right-domain-complete if for any contingency matrix $M$ with perfectly matched rows and columns

$O(M) = \begin{cases} 1, & O \text{ is a positive measure} \\ 0, & O \text{ is a negative measure} \end{cases}$

This property requires measures to show optimal values when the cluster structure matches the cluster structure perfectly. The above normalized measures hold this property.

$P'$ is a refinement of $P$; $P'$ is the descendant of node $P$ in the lattice of partitions. [42] for details.

## 23.2.4.3 Discussions

In a nutshell, among 16 external validation measures shown in Table 23.1, it is first known that Mirkin metric (M) is equivalent to Rand statistic (R), and micro-average precision (MAP) and Goodman-Kruskal coefficient (GK) are equivalent to the purity measure (P) by observing their computational forms. Therefore, the scope of the study reduces from 16 to 13 measures. Section 23.2.2 analysis shows that mutual information (MI) and entropy (E) are effective measures for evaluating K-means clustering. Also, it is proved that variation of information (VI) is an improved version of $MI$ and $E$, and Van Dongen criterion (VD) is an improved version of $P$.

In addition, as shown in Section 23.2.3, it is necessary to use the normalized measures for evaluating K-means clustering, since the normalized measures capture the uniform effect of K-means and allow evaluation of different clustering results on different data sets. Proposition 23.1 on page 579 shows that the normalized Rand statistic ($R_n$) is the same as the Hubert statistic ($\Gamma_n$). Also, the normalized Rand statistic is equivalent to $J_n$, which is the same as $MS_n$. Therefore, only $R_n$ needs consideration and $J_n, \Gamma_n$, as well as $MS_n$ can be considered. The results in Section 23.2.3 show that the normalized F-measure ($F_n$) and classification error ($e_n$) can capture the uniform effect of K-means. Also, these two measures do not satisfy some properties in Table 23.2, so they are excluded as well. However, there are only five normalized measures left: $VI_n, VD_n, R_n, F_n$, and $\Gamma_n$, which are very similar to each other. Therefore, only $R_n$ needs to be considered.

Based on the above theory, it is most suitable to use the Van Dongen criterion ($VD_n$) in most cases since $VD_n$ has simple computation and satisfies all mathematically sound properties in Table 23.12. However, for cases that clustering performances are hard to distinguish, one might want to use normalized variation of information ($VI_n$) instead since $VI_n$ has high sensitivity on detecting changes. Finally, $R_n$ can be used as complementary to the two measures.

## 23.3 Internal Validation Measures

In literature, a number of internal validation measures have been proposed for crisp clustering. In this section, an overview of a suite of widely used internal validation measures is provided for different fields such as data mining, information retrieval, and machine learning. The properties of these measures are investigated in different aspects: monotonicity, density, skewed distribution, and arbitrary shapes. Results and discussions will be presented at the end of this section. As the goal of clustering is to make objects within the same cluster and objects in different clusters distinct, validation measures are often based on the following criteria. Note that the normalized variation of information is equivalent to normalized mutual information.
