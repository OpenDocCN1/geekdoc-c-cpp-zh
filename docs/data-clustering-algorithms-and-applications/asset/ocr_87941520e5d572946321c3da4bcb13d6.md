Another algorithm known as the MMVar algorithm has been proposed in [29], in which the centroid of a cluster C is defined as an uncertain cluster CMM, which represents the mixture of C. The cluster compactness criterion used by the MMVar algorithm is the minimization of the variance of the cluster centroid.

# 18.3 Density-Based Clustering Algorithms

Density-based methods are very popular in the deterministic clustering literature, because of their ability to determine clusters of arbitrary shapes in the underlying data. The core idea in these methods is to create a density profile of the data set with the use of kernel density estimation methods. This density profile is then used in order to characterize the underlying clusters. In this section, we will discuss two variations of such density-based methods, which are the DBSCAN and FOPTICS methods.
