# Data Clustering: Algorithms and Applications

Broadly speaking, there are two kinds of approaches for multiview clustering [23]. In the first approach (centralized), the multiple views are used in parallel to cluster the dataset [4, 38, 6]. In the second approach (distributed), a clustering is generated for each view independently and the clusterings are later merged to produce a single clustering [23].

For the centralized approach, Bibel and Scheffer [4] consider the setting of a dataset that has been generated by a mixture model and the objective of which is to determine the parameters for each of the components of the mixture. They develop both a multiview EM algorithm and a multiview k-means algorithm, which is based on an assumption of independence between views. They find that the multiview EM algorithm is able to optimize the agreement between the views and that it can achieve a significant improvement in performance compared to a single view. They also evaluate an agglomerative approach, but find that results are not improved compared to a single view. Zhou and Burgess [38] consider a spectral clustering approach and propose an algorithm that generalizes the single view) normalized to incorporate information from multiple views (graphs). Their approach uses a random walk technique, that traverses the vertices of both graphs, to derive a multiple graph which is good on all graphs. Chaudhuri et al [16] address the problem of clustering in high dimension by a lower dimensional subspace, in which a standard clustering can then be applied. In their work, this lower dimensional subspace is found using the information from multiple views, where each view is composed of dissimilarities. A canonical correlation Long et al propose a pattern-based technique based on the use of a mapping function.

For the distributed approach, independently clustering each view are then combined into a single view using the mapping function. The objective minimizes the averaged mapped distance of the views to the overall clustering, using an iterative method. Greene and Cunningham [17] tackle the problem by proposing a matrix factorization approach. Specifically, a matrix is constructed that summarizes all the clusterings (one clustering per view). This matrix is factorized (possibly with some approximation error) into the product of two nonnegative matrices. The first matrix contains information about the contribution of each cluster from the views to the overall, final clustering. The second matrix describes the membership of objects in the final clustering.

A key issue for multiview clustering is how to balance the relative contributions of the views and ensure that views do not degrade the final result [35]. Another key issue for multiview clustering is how to handle application-specific multiview integration. For example, the techniques needed to combine multiple views in a domain document may be quite different from what is required for combining multiple views in a protein (bioinformatics) domain. The multiview paradigm has also been extended to the discovery of subspaces, rather than aiming to produce only one, overall clustering [20].

Unlike clustering, subspace clustering is also concerned with discovering multiple clusters, each hidden in a lower dimensional subspace, respectively. The motivation is that the dataset can contain features which which are irrelevant to and confusing for clustering structure. Removing these features can make the clustering structure clearer and of better quality. Some well-known examples include CLIQUE [1], MAFIA [26], and DENCLUE [19]. Issues for subspace analysis include ensuring the dissimilarity between subspace clusters (which may otherwise have large overlap) and controlling the number of subspace clusters (which may be exponential in the number of features).
