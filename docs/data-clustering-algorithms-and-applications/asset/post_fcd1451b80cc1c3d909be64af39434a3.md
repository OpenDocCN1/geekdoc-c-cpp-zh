Although most of these approaches are efficient and relatively accurate, many of these algorithms require the user to specify input parameters (with wrong parameter values resulting in a bad clustering), may return many clusters or too outliers, have difficulty finding clusters within clusters or subspace clusters, or are sensitive to the order of object input [21, 35, 38, 75].

Hierarchical algorithms for categorical clustering take the approach of building a hierarchy representing a dataset's entire clustering structure. Hierarchical algorithms require few specified parameters and are insensitive to object ordering. Such approaches offer the structure of a dataset as a hierarchy, which is usually independent of user-specified parameters or object ordering. A user can cut branches and study the cluster at different levels of granularity and detect subclasses. While some hierarchical algorithms are slow achieving runtimes, they inspire fast simplifications that are useful for finding the right cluster of a dataset.

## 12.2 Goals of Categorical Clustering

Categorical clustering algorithms have various features, which make them suitable for applications with different requirements. To evaluate a categorical clustering algorithm's suitability for a problem, we use a general set of desirable features [15, 41, 42, 73]:

- Scalability: the runtime and memory requirements should not explode on large (high-dimensional) datasets [28].
- Robustness: it should have ability to detect outliers that are distant from the rest of the objects. Outliers may indicate objects that belong to a different population of the samples [39].
- Order insensitivity: a clustering algorithm should not be sensitive to the ordering of the input objects. Reordering the objects in a dataset should not result in different clusters. Order insensitivity is important for every application

Evaluation of clustering quality is application-dependent, with choices for quality measures including

- Precision/recall to a gold standard [33],
- Entropy of the clusters [65]
- Reproducibility [59]
- Hubert-Arabie Indices, the number of pairs of objects that are correctly placed in the same or different clusters divided by all pairs of objects [49].

## 12.3 Similarity Measures for Categorical Data

The notion of similarity or distance for categorical data is not as intuitive as it is for continuous numerical data. One of the main characteristics of categorical data takes discrete values that do not have any inherent ordering, unlike numerical attributes. Although two categorical attribute values may be identical or different, they are not directly comparable in numerical data (by the less than ≤ or ≥ relationships).

### 12.3.1 The Hamming Distance for Categorical and Binary Data

The simplest categorical similarity measure is the Hamming distance, which measures the overlap between two categorical data objects by counting the number of matching attributes (in which the objects have identical values). For a fixed length m, the Hamming distance (HD) is a metric on the vector space of the words of that length. Figure 12.4 shows an example of HD in the 200 dataset [60]. The serpent tuatara ↔ seanake = 5. On the other hand, HD(tuatara ↔ gorilla) = 8, and is unlikely to belong to the class of gorilla. For binary strings a and b, the HD is equivalent to the number of ones in a xor b. The metric space of length-m binary strings, with the HD, is known as the Hamming cube.

One drawback of the Hamming distance is that all matches and mismatches are treated equally since HD does not distinguish between different values taken by an attribute. The Hamming distance is too simplistic as it gives equal weight to all matches and mismatches. Although categorical data values information can be used to define what is more or less similar. A combination of attribute values may co-occur frequently or rarely in the dataset. This observation leads to similarity measures for categorical attributes, which take into account the frequency distribution of different attribute values in a given dataset. These measures use probability or information to define similarity between categorical attributes. Several such categorical similarity measures are described next.
