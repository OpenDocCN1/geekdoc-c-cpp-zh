## 11.2.3 CURE: Fighting with the Irregular Clusters

In both CLARANS and BIRCH, we use one single data point to represent a cluster. Conceptually, we assume each cluster has a spherical shape, which may not be the case in real applications where the clusters can exhibit more complicated shapes. At the other extreme, we can keep all the data points within each cluster, which computational as well as space cost might be too high for large data sets. To address this issue, clustering using CURE [22] proposes to use a set of well-characterized data points to represent a cluster.

CURE is essentially a hierarchical clustering algorithm. By treating each data point as a single cluster and recursively merging existing clusters into one until we have only k clusters. In order to decide which clusters to be merged at each iteration, it computes the minimum distance between all the possible representatives of the two clusters. CURE uses two major data structures to enable the efficient search. First, it uses a heap to track the distance of each existing cluster to its closest cluster. Additionally, it uses k-d tree to store all the representative points for each cluster.

In order to speed the computation, CURE first draws a sample of the input data and analyze the above procedure on the sampled data. The authors use Chernoff bound to analyze the necessary sample size. When the original data is large, the different clusters overlap each other, which in turn requires a large sample size. To alleviate this issue, CURE uses partitions to speed up. By specifying, it first partitions the n' sampled data points into p partitions. With each partition, it runs a partial hierarchical clustering until either a predefined number of clusters is reached or exceeds some threshold. After that, it runs clustering on all the clusters from the p partitions (“global clustering”). Finally, each nonsampled point is assigned to a cluster based on its distance to the representative point ("labeling”). Figure 11.4 summarizes the flowchart of the CURE algorithm.

The empirical evaluation in [22] shows that CURE achieves lower execution time compared to BIRCH. In addition, with BIRCH, CURE is robust to outliers by shrinking the representative points to the center of the cluster with a constant factor.

## 11.3 Randomized Techniques for Clustering Algorithms

In the previous section, we have already seen how sampling can be used to speed up the clustering algorithms, e.g., to reduce the search space as in CLARA and CLARANS and to pre-clustering/partial clustering as in BIRCH and CURE. In this section, let us take one step further to see how randomized techniques can be used to address the scalability issue in clustering.
Suppose that we want to cluster $n$ data points in $d$ dimensional space into $k$ clusters. We can represent these data points as an $n \times d$ data matrix $A$; each row of this matrix is a data point in $d$ dimensional space. The basic idea of various randomized techniques is to reduce the scale of the input data matrix $A$, e.g., by transforming it into a lower $l$-dimensional space ($l < d$) and then performing clustering on this reduced space. In this section, we will review major types of techniques.

### 11.3.1 Locality-Preserving Projection

In the locality-preserving projection (also referred to as random projection) methods, we project the original $d$-dimensional data into a lower dimensional space, with the pair-wise distance to be preserved in a probabilistic sense. In many clustering algorithms, it is the pair-wise distance measure that determines the clustering structure. We would expect that the clustering results in the projected subspace provide a reasonably good approximation to that in the original space.
In addition to clustering, random projection itself has a broad applicability in various data mining tasks (e.g., similarity search, near-duplicate detection). Here, we will first provide general introduction to the typical random projection algorithms and then introduce how to apply them in the clustering setting.

A classic result for the locality-preserving projection comes from Johnson and Lindenstrauss [25], which can be stated as follows:

**Lemma 11.1** Assume $\epsilon > 0$, and $n$ is an integer. Let $t$ be a positive integer such that $t \geq t_0 = O(\log n/\epsilon^2)$. For any set $P$ with $n$ data points in $\mathbb{R}^d$ space, there exists $f: \mathbb{R}^d \to \mathbb{R}^t$ such that for all $u, v \in P$, we have

```
$$(1-\epsilon)\|u-v\|^2 \leq \|f(u)-f(v)\|^2 \leq (1+\epsilon)\|u-v\|^2$$
```

At the algorithmic level, such random projection (also referred to as "JL-embedding") can be performed by a linear transformation of the original data matrix A Let R be a $d \times t$ rotation matrix with its elements independent random variables. Then A R is the projected data matrix, and each of which is a vector in $t$ dimensional space which is the projection of the corresponding data point in $d$ dimensional space.

Different random projection algorithms differ in different terms of ways to construct such a rotation R. Earlier methods suggest R(i,j) as being independent Normal variables with mean 0 and variance 1. In [1], the authors propose two ways to construct the rotation R. The first method suggests R(i,j)=\pm1 with equal probability of 0.5. Alternatively, we can also set R(i,j)=\pm\sqrt3 with equal probability of 1/6 and R(i,j)=0 with the probability of 2/3.

Once we have projected the original data into a low-dimensional subspace, the clustering data points form a Gaussian-mixture model and further purpose using the expectation-maximization (EM) algorithm to find the soft clusters; in that, each data point $i$ is assigned to a cluster membership probability $p(i|l,\theta)$, where $l$ is the $l$-th cluster and $\theta$ is a parameter for the underlying Gaussian-mixture model. The rationality of this approach can be traced back to [14], which found by random projection, the original high-dimensional distribution tends to be more Gaussian distribution in the projected subspace. It was also found in [10] that eccentric clusters can be reached by more spherical by random projection.

Due to its nature, the clustering result generated by the above procedure (RP+EM) might be highly unstable; that, different random projections might lead to very different clustering assignments. The fact that the authors in [18] propose running RP+EM procedure multiple times by an ensemble set. Based on this observation, to be specific, if we run RP+EM multiple times (say $T$ in total), we construct an $n \times n$ similarity/affinity matrix $P$, where each element $P(i,j)=\frac{1}{T}\sum_{t=1}^{T} p(i|l,\theta)$, where $l$ and $t$ are the clusters and different random runs. Then, an iterative clustering algorithm is based on this affinity matrix $P$ to generate the k clusters. The empirical evaluations show that this framework leads to much robust clustering results. Figure 11.5 summarizes the overall flowchart of this clustering ensemble based on RP+EM.

Given that the k-means clustering is NP even if $k=2$, recent research works has focused on the so-called $\gamma$-approximation. Let us define an indicator matrix X where each row has only one element; and $X(i,j)\neq0$ indicates that the data point belongs to the $j$-th cluster. Optimal $\gamma$-approximation finds for an indicator matrix $X_{opt}$ where $X_{opt}=\arg\min_{X}||A-XX^T||_F^2$, where $X$ is the set of all valid $n \times k$ indicator matrices.

For any $\gamma$ and the failure probability $0\le\delta<1$, a $\gamma$-approximation finds an indicator matrix $X$ with that probability at least $1-\delta$, $||A-XX^T||_F^2\le\gamma$. In [33], the authors propose the first linear time $\gamma$-approximation algorithm speeding up the computation by running a $\gamma$-approximation on the projected subspace.
