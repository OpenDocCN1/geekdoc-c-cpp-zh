$$\mathcal{N}(x|\mu,\Sigma)=\frac{1}{(2\pi)^{D/2}|\Sigma|^{1/2}}\left[-\frac{1}{2}(x-\mu)^T\Sigma^{-1}(x-\mu)\right], (3.9)$$

where $\mu$ is a $D$-dimensional mean, $\Sigma$ is a $D \times D$ covariance matrix, and $|\Sigma|$ denotes the determinant of $\Sigma$. Figure 3.2(b) shows contours of the Gaussian distribution for various values of the parameters.

In the Gaussian mixture model, each component is represented by the parameters of a multivariate Gaussian distribution $p(x_k|\theta_k)=\mathcal{N}(x_k|\mu_k,\Sigma_k)$. Based on (3.1), the Gaussian mixture distribution can be written as a linear superposition of Gaussians in the

$$p(x_n|\Theta)=\sum_{k=1}^K \pi_k\mathcal{N}(x_n|\mu_k,\Sigma_k). (3.10)$$

For a set of observations $x$, the log-likelihood is given by

$$l(\Theta)=\log p(x|\Theta)=\sum_{n=1}^N\log\sum_{k=1}^K \pi_k\mathcal{N}(x_n|\mu_k,\Sigma_k)=\sum_{n=1}^N\log\sum_{k=1}^K \gamma_{nk}. (3.11)$$

To find likelihood solutions that are valid at local maxima, we compute the derivatives of $\log p(x|\mu,\Sigma)$ with respect to $\mu_k$, $\mu_k$, and $\Sigma_k$, respectively. The derivative with respect to $\mu_k$ is given by

$$\frac{\partial l}{\partial\mu_k}=\sum_{n=1}^N\frac{\pi_k\mathcal{N}(x_n|\mu_k,\Sigma_k)}{\sum_{j=1}^N\pi_j\mathcal{N}(x_n|\mu_j,\Sigma_j)}=\sum_{n=1}^N\gamma_{nk}\Sigma_k^{-1}(x_n-\mu_k),$$

where we have (3.9) and (3.5) for the Gaussian distribution and the responsibilities (i.e., posterior probabilities), respectively. Setting this derivative to zero and multiplying by $\Sigma_k$, we obtain

$$\mu_k=\frac{\sum_{n=1}^N\gamma_{nk}x_n}{\sum_{n=1}^N\gamma_{nk}}. (3.12)$$

$$\gamma(z_{nk}) = \frac{\pi_k \mathcal{N}(\mathbf{x}_n|\mu_k, \Sigma_k)}{\sum_{j=1}^K \pi_j \mathcal{N}(\mathbf{x}_n|\mu_j, \Sigma_j)}$$

We can interpret the mean $\mu_k$ for the $k$-th Gaussian component is obtained by taking a weighted mean of all the points in the data set, with the weighting factors corresponding to the posterior probability $\gamma(z_{nk})$ that component $k$ was responsible for generating $\mathbf{x}_n$. Similarly, we define the expectation of $\log p(\pi, \mu, \Sigma)$ with respect to $\Sigma_k$ to zero, and we obtain

$$\Sigma_k = \sum_{n=1}^N \gamma(z_{nk}) (\mathbf{x}_n - \mu_k)(\mathbf{x}_n - \mu_k)^T / \sum_{n=1}^N \gamma(z_{nk})$$

Similar to (3.12), each data point is weighted by the conditional probability generated by the corresponding component and with the denominator by the effective number of points associated with the corresponding component.

The derivative of $\log p(\pi, \mu, \Sigma)$ with respect to the mixing probabilities $\pi_k$ requires a little more work, because the values of $\pi_k$ are constrained to be positive and sum to one. This can be handled using a Lagrange multiplier and maximizing the following quantity

$$\log p(\pi, \mu, \Sigma) + \lambda (\sum_{k=1}^K \pi_k - 1)$$

After simplifying and rearranging we obtain

$$\pi_k = \frac{\sum_{n=1}^N \gamma(z_{nk})}{N}$$

so that the mixing probabilities for the $k$-th component are generated by the average responsibility that the component takes explaining the data points.

It is worth noting that the Equations (3.12), (3.14), and (3.15) are not coupled. Specifically, the responsibilities $\gamma_{nk}$ depend on the parameters. This is the Expectation-Maximization (EM) algorithm, which is an iterative method to find maximum likelihood estimates of parameters in latent variable models.

## Algorithm 1 EM for Gaussian Mixtures

Given a set of data points and a mixture model, the goal is to maximize the log-likelihood with respect to parameters.

- 1: Initialize the means $\mu_k^0$, covariances $\Sigma_k^0$, and mixing probabilities $\pi_k^0$.
- 2: E-step: Calculate the responsibilities $\gamma_{nk}$ using the current parameters based on (3.13).
- 3: M-step: Update the parameters using the responsibilities. We first update the means using (3.12), then use these values to calculate the covariances (3.14), and finally reestimate the mixing probabilities (3.15).
- 4: Compute the log-likelihood (3.10) and check for convergence of the algorithm. If the convergence criterion is not satisfied, repeat steps 2–4; otherwise, return the final parameters.
