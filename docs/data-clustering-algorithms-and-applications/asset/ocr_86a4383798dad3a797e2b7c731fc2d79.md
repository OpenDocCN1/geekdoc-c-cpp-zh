# 6.5.4.2 CBF: Cell-Based Filtering

(Cell-Based Filtering) [4] proposed by Chang and Jin on the scalability of the grid structure, handling large data sets in memory, and the efficiency of retrieval and retrieval from the grid structure. It also offers a clear criteria for a cutting plane.

CBF creates its grid structure by splitting each dimension into a set of partitions using a split index. Once a dimension is split into clusters, the split index is equal to the sum of the relative density of each cell. CBF finds the optimal split in each dimension by repeatedly examining the value for partitions along the potential split points in the dimension until the maximum value of a split index for partitioning is found. Cells are created from the overlapping regions of the partitions in each dimension. This dimensional grid-based algorithms we have discussed.

Cells with higher density than a given threshold are inserted into the clusters. There is a second layer of the index structure built upon the cluster information that provides approximation information of the clusters by grouping them into sections. Sections of clusters, with density greater than that threshold, then this secondary index is set to true for section and false otherwise. By using this technique, the index structure is able to filter clusters when necessary by first examining the section information and then accessing the cell cluster as necessary.
