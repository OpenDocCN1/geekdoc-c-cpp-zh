# Cluster Ensembles: Theory and Applications

The Evidence Accumulation approach [21] obtains individual co-association matrices randomization of the k-means algorithm, causing some variation in the base cluster solutions. This algorithm is used with a much higher value than the range finally desired. The ensemble co-association matrix is then formed, each entry of which signifies the relative co-occurrence of two data points in a cluster. Minimum spanning tree (MST) (also called the single-link or nearest neighbor hierarchical clustering) is then applied on the ensemble co-association matrix. This allows one to obtain nonconvex shapes. Essentially, this approach assumes the designer has access to the raw data, and the consensus mechanism is used to get a more robust solution than what can be achieved by simply applying MST to the raw data.

A related approach is taken by Monti et al [48], where the perturbations in the clustering are achieved by resampling. By bootstrapping, data subsampling, or feature subsampling can be used as a resampling scheme. If either of the first two options is selected, it is possible that certain objects are missing in a base clustering. Hence, when collating the r base association, the (i,j) entry defined by the number of solutions that cluster objects other than a base r. This also incorporates a model selection procedure as follows: consensus is formed multiple times. The number of clusters is kept at k for each base clustering during the experiment, but number is changed from one experiment to another. A measured consensus distribution describes how elements of a consensus matrix are distributed within the 0-1 range. The extent to which the consensus matrix is skewed towards a binary matrix denotes how clusters match this enables one to choose the most appropriate number of clusters k. Once k is chosen, the corresponding ensemble co-association matrix is fixed to a hierarchical clustering algorithm with average linkage. Agglomeration of clusters occurs when branches are fractured

The Iterative Pairwise Clustering (IPC) Algorithm [49] essentially employs model-based kmeans [72] to use the ensemble co-association matrix S. The clustering solution L = {Cj}j=1 is initialized to solution, after which rearrangement of points is carried out on the current of L. The point xi gets assigned to cluster Cr if it has maximum average similarity with the points belonging to cluster Cr. Then the consensus solution is updated, and the cycle starts again.

However, Mirkin [47] and Li et al. [43] show that the problem of consensus clustering can be framed in a different way than what has been discussed so far. In this work, the distance d(λ^(i),λ^(j)) between two clusters λ^(i) and λ^(j) is defined as the number of pairs of objects that are placed in the same cluster in λ^(i) or λ^(j) and in different cluster in the other, essentially considering the (unadjusted) Rand Index. Using this definition, the consensus clustering problem is formulated as

```
arg min_λ J = arg min_λ ∑_{q=1}^{r} d(λ^(q), λ) (22.13)
= arg min_λ ∑_{q=1}^{r} w_q [S_ij^(q) - S_ij]^2
```

Mirkin [section 47.5.3., p. 206] proved that further the consensus clustering according to criterion (22) is equivalent to clustering over the ensemble co-association matrix by subtracting a “soft” and “uniform” threshold from each of the different consensus clusters. This soft threshold, serves as a tool to balance cluster sizes in the final clustering. The subtracted threshold has also been used in [59] for clustering of gene-expression data.
