# Data Clustering: Algorithms and Applications

Given $G$, the set of genes; $S$, the set of samples; and $T$, the set of time points; a tricluster $C$ is a submatrix of the dataset $D = G 	imes S 	imes T = \{c_{ijk}\}$, with $X \subseteq G, Y \subseteq S$, and $Z \subseteq T$ provided that conditions of homogeneity are satisfied. For example, a simple condition might be that all values $\{c_{ijk}\}$ are identical or approximately equal. If we are interested in finding common co-expression patterns across different samples and times, we can find clusters that have similar values in the $G$ dimension, but different values in the $S$ and $T$. Other homogeneity conditions can be defined, such as similar values in the $S$ dimension and order preserving submatrices.

Let $\mathcal{B}$ be the set of all triclusters that satisfy the given homogeneity conditions, $C \in \mathcal{B}$ is a maximal tricluster if there does not exist another cluster $C' \in \mathcal{B}$ such that $C \subset C'$. In most of cases, we are interested in the maximal triclusters.
Zhao and Zhou's method for clustering is known as TriCluster. It implements the 3-dimensional dataset $D$, the minimum size thresholds $mx, my, mz$, that define the size of the clusters in three dimensions; a maximum ratio $\epsilon$, which represents the maximum allowed deviation among values in different cells. This constructs a range graph data structure for the data matrix at each of the timestamps. It uses the ranges of a timestamp to obtain biclusters (involving $G$ and $S$) that are observed for that time. As a final step, it merges biclusters with similar different values to obtain maximal triclusters. For this step, it represents each of the biclusters that has been found in the earlier step as a node in a graph, and defines the node-node (bicluster-bicluster) relationships based on the similarity of them. As an optional step, it also merges clusters based on degree of overlap among various dimensions. Interested readers can read more on the TriCluster algorithm from the original paper by the authors [123]. Key features of TriCluster are that it is flexible and can accept various homogeneity criteria. it is also robust and generates only maximal triclusters. The downside of this method is that it requires a large number of parameters and domain knowledge is necessary to set the parameter values optimally.

# 16.2.6 Time-Series Gene Expression Data Clustering

In order to determine the complete set of genes that are expressed under a set of new conditions and to understand the interactions between these genes in these new conditions, it is important to measure a time course of expression experiments [11]. In microarray experiments, the gene expression values are collected over different time points which correspond to the experimental conditions. One of the key characteristics of such time-series data is that while static data from a sample population are assumed to be i.i.d. (independent and identically distributed), time series gene expression patterns exhibit a strong autocorrelation between timepoint values. In such scenarios, it is critical to capture the inherent relationships between genes in order to perform clustering [6]. One of the methods to cluster time series gene expression data was developed in [70]. This clustering algorithm based on the mixed model using B-splines and was applied on the yeast cell gene expression data. The estimated gene expression trajectory was also used to fill in the missing gene expression for any time point using the data in the same case.

Hidden Markov Models (HMMs) have also been used to cluster time-series gene expression data [91]. The primary advantage of using HMMs is that they effectively take into account the nature of the expression patterns which produce high quality clusters. Given expression data, the goal is to find a pattern of the data into $K$ HMMs that maximize the likelihood of the data given the learned HMM model. For expression data, the emission properties are assumed to be Gaussian with fixed variance. The authors [91] developed a new algorithm for clustering genes based on a mixture of HMMs. The parameters of this model are learned using an Iterative Expectation-Maximization algorithm.
