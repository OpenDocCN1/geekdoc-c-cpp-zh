# Spectral Clustering

# 8.8 Connection to kernel k-Means and Nonnegative Matrix Factorization

Recent studies [12, 13] show that spectral clustering is theoretically closely related to two other popular clustering algorithms: kernel k-means and nonnegative matrix factorization [25]. It is proved that these are unified in a simple way: they are different prescriptions of the same problem with slightly different constraints and optimization solutions.

It is known that k-means uses k centroids to characterize the data. The objective function is to minimize the sum of squared errors:

```
$J = \sum_{i=1}^k ||x_i - m_i||^2 = c - \sum_{i=1}^k \frac{1}{|A_i|} \sum_{j\in A_i} x_j^T x_j \(8.9)$
```

where $m_i = \sum_{j\in A_i} x_j/|A_i|$ is the centroid of cluster $A_i$, and $c = \sum_j ||x_j||^2$.

We can represent the solution by $F=(f_1,\dots,f_k)$, $f_i^T f_j = \delta_{ij}$

where

```
$f_{ij} = \begin{cases} \sqrt{|A_i|} & \text{if} \ x_j\in A_i \ 0 & \text{otherwise.} \end{cases}$
```

We can rewrite Equation 8.9 as $J = Tr(X^T X) - Tr(F^T FX)$. As the first term is constant, minimizing $J$ is equal to the following:

```
$max Tr(F^T GF)$
```

Here, $G=X^TX$ is a pairwise similarity matrix called inner-product linear kernel matrix which can be extended to any kernels. It is clear that if we set the kernel matrix $G$ to be the negative of Normalized graph Laplacian $L=W-D$, the objective function of kernel k-means clustering is equivalent to RatioOfCut in Equation 8.7. Therefore, for the same objective function, spectral clustering first relies to partition $F$ to be real values and computes it through an eigen-decomposition problem. The clustering labels are finally obtained by running k-means on $F$. Different from this "global" minimum after relaxation of $F$, k-means clusters all data points, which is an iterative approach and it is a local search. It is worth noting that in [12], a weighted k-means is proposed and the authors also prove it is equivalent to spectral clustering where kernel matrix $G$ is set to $D^+WD^{-1}$ and the weight matrix for data points equals to $D$.

Nonnegative matrix factorization (NMF) aims to factorizing $X$ into two nonnegative matrices,

```
$X \approx UV^T$
```

where $U \in \mathbb{R}^{m\times k}$ and $V \in \mathbb{R}^{n\times k}$. As $k < \min(m,n)$, $UV^T$ can be viewed as a low-rank approximation of $X$. The clustering aspect of NMF is studied in [57, 18].

```
$G \approx FF^T$
```
