
## Data Clustering: Algorithms and Applications

While parameterized divergences give the additional flexibility of rotating/scaling the feature space appropriately in order to match the given pairwise semisension, without proper regularization, such formulations can yield degenerate solutions. For example, setting $A=0$, the zero matrix makes all distances zero, and minimizes the objective function, but is not meaningful. To avoid such degenerate solutions, one considers regularizers $R(A)$ on $A$ or putting constraints on $A$, e.g., making $A$ positive semidefinite, which is commonly in metric learning [41].

**Constraint violation functions:** The second choice involves the constraint violation functions $f_{ML}(i,j)$ and $f_{CL}(i,j)$. For the must-link constraints, one considers penalty functions proportional to the distance, $f_{ML}(i,j)=d_A(X_i,X_j)$. For points which are far according to the distance function, a must-link constraint provides valuable information regarding the structure of the clusters. As a result, the penalty increases if a constraint is violated. i.e., $f_{CL}(i,j)=d_{ij}^{max}-d_A(X_i,X_j)$, where $d_{ij}^{max}$ is a upper bound on the pairwise distances between points in the dataset. Thus, non-link constraints between points which are nearly given more weight as they suggest that the cluster may be substantially different from the one suggested by the distance measure. One can consider alternative of the functions as appropriate for the given partition domain.

With the two generators, the objective function for PCC can be written as:

```
$J_{PCC}(M,Y,A) = \frac{1}{2}\sum_{i\neq j} d_A(X_i,X_j) + R(A) + \sum_{(i,j) \in M} w_{ML}f_{ML}(i,j)\mathbb{I}(Y_i \neq Y_j) + \sum_{(i,j) \in C} w_{CL}f_{CL}(i,j)\mathbb{I}(Y_i \neq Y_j).$
```

Such a formulation can be interpreted as the log-likelihood of a probabilistic graphical model known as the Markov random field (MRF). The HMR model consists of the following sets of variables and parameters: (i) an observable set $X=(X_1,\dots,X_n)$ corresponding to the given data points $X$; (ii) an unobservable (hidden) set $Y=(Y_1,\dots,Y_n)$ corresponding to cluster assignments of points, where each hidden variable $Y_i$ encodes the label of point $i$, and takes values from the set of cluster indices $(1,\dots,K)$; (iii) a set of model parameters $\Theta=\{A,M\}$, which consists of divergence parameters $A$ and cluster representations $M=(\mu_1,\dots,\mu_k)$; and (iv) an observable set of constraint variables $C=\{c_{12},c_{13},\dots,c_{n-1,n}\}$, where each $c_{ij}$ is a binary variable taking a value from the set $(-1,0)$, where $c_{ij}=1$ indicates that $(X_i,X_j) \in M$ is the set of must-link constraints, and $c_{ij}=-1$ indicates that $(X_i,X_j) \in C$, the set of non-link constraints.

Consider the posterior distribution $P(Y|\Theta,C)$, which by Bayes rule is proportional to:

```
$P(X,Y|\Theta,C) = P(X|Y,\Theta,C)P(Y|\Theta,C).
```

We assume the model parameters $\Theta=(M,A)$ to be independent of the constraints $C$, so that $P(\Theta|C)=P(\Theta)=P(M,A)=P(M)P(A)$, where we assume $M$ and $A$ to be independent.

## Semisupervised Clustering

The conditional distribution $P(X|Y,\Theta) = \prod p(x_i|y_i,\Theta)$ is determined by a mixture model, where the mixture component is determined by $y_i$, and $\Theta$ contains the parameters of the mixture model. The literature has a variety of components, including von M-Fischer, and multinomial [4]. More generally, one can consider a functional form of the conditional distribution $p(x|y,\Theta) = \exp(-d_\Theta(x,\mu_y))$, where $Z_\Theta$ is the partition function. The negative-likelihood of the posterior, is given by:

```
-log P(Y,\Theta,C) = \sum_{i} d_\Theta(x_i,\mu_{y_i}) + \sum_{j} f(i,j) - \log P(\Theta) + n\log Z_\Theta + n\log P(C). (21)
```

Since $\log P(C)$ is constant, $R(\Theta) = n\log Z_\Theta - \log P(C)$, Equation (21) is equivalent to the objective function. Given a dataset, some clusters can be learned using a version of the EM algorithm. In particular, for the objective function (21), one has the parameters $\Theta=(M,A)$ and the cluster members $Y=\{y_1, \dots, y_n\}$. The EM algorithm is initialized with some $\Theta^{(0)}$ for the parameters and then proceeds with the following:

- **E-step** Update $\Theta=(M,A)$, update $Y^{j+1}$ to minimize the objective
- **M-step** Update $(A, Y^{j+1})$, update $M$ to minimize the objective
- **A-step** Update $(M, Y^{j+1})$, update $A$ to minimize the objective

For a variety of semisupervised clustering, the above approach has been shown to perform well, such as SSC with pairwise constraints [5, 6].

### Active Learning for Semisupervised Clustering

Since SSC works with a few (pointwise) labels, active learning is a natural framework to work in this setting. Given a fixed number of queries on pairwise labels, the goal is to decide which queries to get must-link and non-link information. In [3], a two-stage method is outlined for active learning for SSC. In the first stage, called *explore*, the focus is on getting one point from each cluster with a small number of queries. The first point is chosen at random and assigned to a cluster. Subsequent points are chosen by farthest traversal, i.e., by picking the point which is farthest from all existing points; distance is measured by the distance to the nearest point in existing clusters. Once a set is obtained, pairwise queries are made with any point from each existing clusters. If a must-link constraint is found with any of the existing clusters, the point is assigned to that cluster; if no must-link constraint is found with any of the existing clusters, a new cluster is initialized with this point. The explore process continues until at least one point from each cluster is found or the budget is exhausted. In the second stage, called *consolidate*, additional data points are selected and assigned to the correct clusters by pairwise querying. Given a data point, all clusters are first sorted in order of distance. Pairwise queries are made with any point from each of the clusters in sorted order until a point with a must-link constraint is found. In that case, the new point is assigned to that cluster, and the process continues by another point at random. The querying is expected to be efficient, i.e., for a $k$-clustering problem, much fewer than $k$ queries will usually be needed. Empirically, [3] show the active learning strategy is effective in practice, leading to better performance with fewer queries compared to random queries.

## Semisupervised Clustering Based on User Feedback

A set of ideas for SSC has been pursued by [18], where the supervision is done in the loop. The development acknowledges the fact that there are multiple ways semisupervision can be provided and advocates updating the clustering on input received from the user. [18] consider a scenario where a user iteratively providing feedback about the quality of clusters. The divergence measure $d$ is defined up front and produce a clustering. Based on the user's feedback on the initial clustering, the method attempts to adjust it to be similar. In other words the divergence measure of this is not fixed, but rather learned as the user provides feedback. It is innovative to note that such ideas in [18] were also considered by others as [4], as discussed in Section 20.2.2, but [18] explicitly consider the user to be a part of the process.

The problem of interest in [18] is the clustering of documents. Once an initial clustering has been done, the user can provide the following types of feedback:

- (i) an indication that a document is in the wrong cluster;
- (ii) given more appropriate cluster, an indication that the document should be moved to;
- (iii) whether two documents should be within the same cluster;

Indeed, the type of feedback is closely related to the pointwise supervision discussed earlier. The user is assumed to know how many clusters there are. After the feedback is incorporated into the distance measure, the clustering algorithm is run. These steps are repeated as long as user feedback is available or until convergence. In practice, only a few iterations of user feedback are considered.

Following a bag of words, a document $d$ is assumed to be generated from a multinomial mixture model $\theta$ over words $w$. Words are defined by a vocabulary $V$. Within this probabilistic setting, KL divergence is selected as a natural choice of distance measure to be used in clustering. In order to adjust based on user feedback the authors proposed a version of KL divergence:

```
$d_A(d_1||d_2) = \sum_{w\in V} a_w p(w|j_1) \log \frac{p(w|j_1)}{p(w|j_2)}$
```

where $a_i$ are constrained to be positive. The divergence in [18] is fact a symmetrized version of the parametrized KL-divergence where one computes the weighted average KL-divergence of individual document frequencies to a discrete distribution with the word frequencies of the documents, and the weighting is determined by the number of words in each document. User feedback is provided for a pair of documents, $d_A$ is optimized by suitably updating $a_j$.
