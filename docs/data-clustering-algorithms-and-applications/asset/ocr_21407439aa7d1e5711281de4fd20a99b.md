# Algorithm 14 K-Medoids Clustering

```
1: Select K points as the initial representative objects.
2: repeat
3: Assign each point to the cluster with the nearest representative object.
4: Randomly select a nonrepresentative object x_i.
5: Compute the total cost S of swapping representative m with x_i.
6: If S < 0, swap m with x_i to form the new set of K representative objects.
7: until Convergence criterion is met.
```

error correction for K-medoids. For each reassignment operation this cost of swapping is calculated and contributes to the overall cost function.

To deal with the problem of executing multiple swap operations while obtaining the final representative points for each cluster, a modification of the K-medoids clustering called Partitioning Around Medoids (PAM) algorithm is proposed [26]. This algorithm operates on the dissimilarity metric of a dataset. PAM minimizes the objective function by swapping all nonmedoid points and iteratively until convergence. K-medoids is more robust than K-means but the computational complexity of K-medoids is higher and not suitable for large datasets. PAM was also combined with a sampling method to propose the CLARge Application (CLARA) algorithm. CLARA considers samples and applies PAM on each of them to finally return the set of optimal methods.

# 4.2.4.2 K-Medians Clustering

The K-medians clustering calculates the median for each cluster as opposed to calculating the mean of the cluster (as in K-means). K-medi algorithm chooses K clusters that aim to minimize the sum of distance between each point and the closest cluster center. The distance used in the K-medians algorithm is the L1-norm as opposed to the square of the L2-norm used in K-means. The criterion for the K-medians algorithm is defined as:

> S = \sum_{k=1}^{K} \sum_{i \in C_k} |x_{ij} - med_{kj}|

where x_{ij} represents the jth instance i of the kth cluster C_k and med_{kj} represents the median for the jth attribute in C_k. K-medians are more robust to outliers compared to K-means. The goal of the K-medians clustering is to determine which subsets of points minimize the cost of assignment of the data points to the nearest medias. The overall outline of the algorithm is similar to K-means. The two steps are iterated until converge (i) all data points are assigned to their nearest median and (ii) the means are recomputed using the median of the each feature.

# 4.2.4.3 K-Modes Clustering

One of the major disadvantages of K-means is its inability to deal with numerical attributes [51, 3]. Using data transformation methods, categorical data can be transformed into new feature spaces, and the K-means algorithm can be applied to this newly transformed space to obtain the final clusters. However, this method proves to be very ineffective and not produce good clusters. It is observed that the SSE function and the usage of the mean are not appropriate when dealing with categorical data. The K-modes clustering algorithm [21] has been proposed to tackle this challenge.
