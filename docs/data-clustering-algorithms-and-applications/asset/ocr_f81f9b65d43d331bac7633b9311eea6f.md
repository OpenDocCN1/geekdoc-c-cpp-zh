After connecting the vertices, the edges are weighted by the similarity of endpoints.
**Fully connected**: in this case all points are connected with each other and the edges are weighted by the similarity function $x_i,_j$. An important issue is that if all are connected, it is important that the similarity function reflects the local neighborhoods. A popular similarity function is the Gaussian similarity $f(x_i, x_j) = \exp(-\|x_i - x_j\|^2/(2\sigma^2))$. The parameter $\sigma$ controls the width of the neighborhood and provides a role similar to that of $\epsilon$ in the $\epsilon$-neighborhood graph. # 17.8.3 Graph Laplacians

Graph Laplacian matrices are the principal tool for spectral clustering and there is a dedicated area of study for those matrices [36]. There are variants of graph Laplacians, and unfortunately, there is no unique definition of a matrix that is exactly "graph Laplacian". Let $G = (\mathcal{V}, \mathcal{E}, \mathcal{W})$ be an undirected, graph with weight matrix $\mathcal{W}$ with $w_{i,j} \geq 0$. Using eigenvectors of a matrix, we do not assume them to be normalized, i.e., constant vector $\vec{f}$ and $\vec{a}$ for some $a 
eq 0$ are the same eigenvectors. Eigenvalues will be ordered in ascending order respect multiplicities.

# 17.8.3.1 Unnormalized Graph Laplacian

The unnormalized graph Laplacian $L$ is defined as

> $L = D - W$$

Some of the properties of graph Laplacian matrices that are critical for spectral clustering are given below. Mohan gives an overview of the properties of the matrices in more detail in [116, 117].

**Properties of graph Laplacian**: Matrix L has the following properties:

+   - for every vector $f \in \mathbb{R}^n$,
$$f'Lf = \sum_{i,j=1}^n w_{ij}(f_i - f_j)^2$$
- $L$ is symmetric and positive semi-definite.
- The smallest eigenvalue of $L$ is 0 with the corresponding eigenvector $\vec{f}$ (constant vector).
- $L$ has nonnegative, real-valued eigenvalues $0 = \lambda_1 \leq \lambda_2 \leq \dots \leq \lambda_n$.

Proof of these properties is available in [105]. It is noticeable that self-edges in a graph do not change the properties of graph Laplacians. The unnormalized graph Laplacian, its eigenvectors and eigenvalues can describe many properties of graph [116, 117]. One such property is important for spectral clustering is as follows:

**Number of connected components and spectrum of L**: For an undirected graph $\mathcal{G}$ with negative weights, the multiplicity $k$ of the eigenvalue 0 of $L$ equals the number of connected components. Proof of this property can be found in [105].
