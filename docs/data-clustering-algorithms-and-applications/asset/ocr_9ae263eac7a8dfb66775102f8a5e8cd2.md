# 4.2.4 Variations of K-Means

The simple framework of the $K$-means algorithm makes it very easy to modify and build more efficient algorithms on top of it. Some of the variations of $K$-means algorithms are based on (i) Choosing different representative prototypes for the clusters ($K$-medoids, $K$-medians, $K$-modes), (ii) choosing better initial center estimates (Intelligent $K$-means, Genetic $K$-means), and (iii) applying some feature transformation technique (Weighted $K$-means, Kernel $K$-means). In this section, we will discuss the most prominent variants of $K$-means clustering that have been proposed in literature of partitioning clustering.

# 4.2.4.1 K-Medoids Clustering

$K$-medoids is a clustering algorithm which is more resilient to outliers than $K$-means [38]. Similar to $K$-means, the goal of $K$-medoids is to find a clustering solution that minimizes a predefined objective function. The K-medoids algorithm chooses the actual data points as prototypes and is more robust to noise and outliers in the data. The $K$-medoids algorithm aims to minimize the absolute error relative to the SSE.
