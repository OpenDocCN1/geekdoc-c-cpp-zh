### 13.2.2 向量空间模型

大多数文档聚类方法选择将文本视为 *词袋*。每个文档被视为词项空间中的一个向量，以其最简单的形式表示为 *词频* 向量

```
$d_{tf} = (tf_1, tf_2, \dots, tf_M)$
```

其中 $tf_i$ 是文档中第 $i$ 个词项的频率。这赋予了其模型名称，*向量空间模型*（VSM）。

对向量空间模型的一种广泛使用的改进是对每个词项根据其在文档集合中的 *逆文档频率*（IDF）进行加权。该加权的动机是，频繁出现在许多文档中的词项具有有限的判别力，因此需要降低其权重。by multiplying the frequency of the $i$th term by $\log(N/df_i)$, where $df_i$ is the number of documents that contain the $i$th term (i.e., document frequency). This leads to the *tf-idf* representation of the document:

```
$d_{tfidf} = (tf_{idf_1}, tf_{idf_2}, \dots, tf_{idf_M})$
```

最后，为了考虑文档长度不同，每个文档向量的长度被归一化为单位长度（$||d_i,d_j|| = 1$）；也就是说，每个文档都是单位超球面中的一个向量。

为了最大化文本中词的共现，词可以被还原为基本形式，通过词干提取或词形还原。词干提取 [85] 是一种启发式过程，作用于单个词，去除派生词缀，并且通常在匹配同一词的其他形式时截断词尾。词形还原使用词典和形态分析，旨在返回到词的词根 [73]。它在上下文中分析词，比词干提取更 demanding。词的同义词可以用词典数据库 [50] 替换为通用形式。一些尝试已通过使用文本词或字符 n-gram（由两个或更多项组成的序列）[19, 75] 在 VSM 中捕捉顺序和句子结构。

**向量空间中的相似度。** 余弦相似度是计算向量空间中两个文档相似度的最常用度量。给定向量 $d_1$ 和 $d_2$，它定义为

```
$cos(d_1,d_2) = \frac{d_1 \cdot d_2}{||d_1|| \times ||d_2||}$
```

其中“...”表示向量点积运算。对于单位长度的向量，该公式可以简化为 $cos(d_1,d_2) = d_1 \cdot d_2$。

设 $D$ 为 $N \times M$ 文档-文档矩阵，其行是词频向量。集合中所有文档的成对相似度可以直接从 $D$ 计算得出

```
$SIM = L^{-1/2}XL^{-1/2}$
```

其中 $X = DD^T$ 且 $L$ 是 $N \times N$ 对角矩阵，其对角元素是 $X$ 的对角元素。$X$ 与 $L^{-1/2}$ 的左右相乘将文档缩放为单位长度。如果文档已是单位长度，则公式简化为 $SIM = DD^T$。

用于比较文档的其他流行度量包括欧几里得、曼哈顿和切比雪夫距离，以及 Jaccard 系数。欧几里得距离，也称为 $l^2$ 范数，仅仅是向量在 $M$ 维空间中的几何距离，定义为

```
$dist(d_1,d_2) = \sqrt{\sum_{i=1}^{M} (d_1^i - d_2^i)^2}$
```

其中 $d_1^i$ 是文档向量中的第 $i$ 个元素。曼哈顿（也称为城市街区距离或 $l^1$ 范数）和切比雪夫（也称为棋盘或 $l^{\infty}$ 范数）距离类似定义为

```
$dist_1(d_1,d_2) = \sum_{i=1}^{M} |d_1^i - d_2^i|$
```

```
$dist_{\max}(d_1,d_2) = \max_{i=1}^{M} |d_1^i - d_2^i|$
```

Jaccard 系数是一种集合相似度度量。它可以应用于特征向量，通过考虑其非零元素。使用这种逻辑，Jaccard 系数衡量共同性，由两个文档的交集除以其并集表示：

```
$J(D_1,D_2) = \frac{|D1 \cap D_2|}{|D_1 \cup D_2|}$
```

其中 $D_1$ 和 $D_2$ 分别是 $d_1$ 和 $d_2$ 的表示。

### 13.2.3 替代文档模型

一些文档模型已被提出以克服 VSM 的局限性。Wang et al. [112] 使用词依赖图表示文档并使用图相似度进行比较。矩阵空间模型（MSM）[112] 将每个文档视为一组段落，由词-段落矩阵表示。基于概念的模型通过添加或替换词为一些类别信息来增强原始文本向量，例如 WordNet 概念 [50]、同义词集 [41]、词性标签和上位词 [94]，或基于维基百科的概念 [35]。

一些模型构建语料库表示以允许计算文档之间的相似度。广义向量空间模型（GVM）[114] 解决了向量空间中成对正交性假设。这些模型将文档表示为一组适当选择的正交词向量，从而可以计算相关性。潜在语义分析（LSA）[24] 对文档-词矩阵提供低秩近似，有效地在潜在空间中出现更多，与具有相似含义的词相关联。

主题模型描述了在集合中生成项目的简单概率过程。在此框架中，文档表示为主题的混合，在概率质量函数（PMF）中定义，该函数在表示主题的低维特征空间上定义。主题模型可以描述词、段落或文档，并且是本章后面讨论的许多生成算法的基础。

### 13.2.4 文本的降维

文本语料库中唯一词项的数量非常高。降维技术旨在通过减少文本空间中的噪声来消除这一点。这可以通过特征选择来实现，特征选择旨在根据某个目标选择最优特征子集，或特征变换，特征变换寻求原始特征空间的低维映射。最简单的技术修剪文档频率低或高的特征。频繁出现的词被认为未定义，而罕见词被认为。停用词，即特定于词典的词，也被删除。这些简单的选择技术在某些情况下被发现与基于信息增益（IG）、互信息（MI）或 $\chi^2$（卡方）分析 [116] 选择特征的监督方法一样有效。

特征变换算法将数据投影到某个低维空间。主成分分析（PCA）[49, 56] 是主导的无监督方法。它将协方差矩阵 $C_D = DD^T$ 对角化为 $(PD)^TP$ 并删除较少的分量，将 $P$ 减少到 $K \times N$，其中 $K < N$。$P$ 是主成分矩阵，其行是 $D^T$ 的特征向量。

相关的方法，潜在语义分析（LSA）[24]，对文档-词矩阵执行奇异值分解，$D = UV^T$ 并保留与 $K$ 个奇异值（特征值）相关的文档向量的潜在表示。在监督领域，线性判别分析 [34, 74] 旨在找到一个潜在空间，其中不同类别的文档被很好地分离，最大化 Fisher 准则，

```
$$\text{argmax}_{\mathbf{W}} \frac{\mathbf{W}^T \mathbf{S}_b \mathbf{W}}{\mathbf{W}^T \mathbf{S}_w \mathbf{W}}$$
```
$\mathbf{S}_b = \sum_{c \in C} n_c (\mu_c - \mu)(\mu_c - \mu)^T$
$\mathbf{S}_w = \sum_{c \in C} \sum_{j \neq c} (d_j - \mu_c)(d_j - \mu_c)^T$
```

其中 $\mathbf{S}_b$ 和 $\mathbf{S}_w$ 是类间和类内散布矩阵。$C$ 是类别标签集合，$\mu_c$ 是集合均值，$\mu$ 是类 $c$ 中文档的均值，$n_c$ 是文档数量。
