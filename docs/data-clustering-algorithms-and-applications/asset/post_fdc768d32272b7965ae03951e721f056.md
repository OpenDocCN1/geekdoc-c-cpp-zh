
## 23.1 Introduction

Clustering, one of the most important unsupervised learning problems, is the task of dividing a set of objects into clusters such that objects within the same cluster are similar while objects in different clusters differ. Clustering is used in many fields, such as text mining, image analysis, and bioinformatics [16, 69, 17]. As an unsupervised learning task, it is necessary to find a way to validate the goodness of partitions after clustering. Otherwise, it would be difficult to make use of clustering results.

Clustering validation, which evaluates the goodness of clustering results [41], has been recognized as one of the vital issues essential to the success of clustering applications [26]. Despite the vast amount of expert endeavor spent on this problem [18, 9, 5], there is no consistent and conclusive solution to cluster validation. The best suitable measures to use in practice remain unknown. There are many challenging validation issues which have not been fully addressed in the clustering literature. Also, the importance of normalizing validation measures is not clear. Moreover, there are important properties associated with the selection of the use of these measures but have not been well characterized. Finally, the fact that different validation measures may be appropriate for different algorithms, it is necessary to provide a focused study of cluster validation on specified clustering algorithms.

Clustering validation measures can be categorized into two main types: external validation and internal validation. The main difference is whether or not external information is used for clustering validation. External validation measures use external information not in the data to evaluate the extent to which the clustering structure is developed by a clustering algorithm matches some external structure, e.g., the one specified by the class labels. One example of external validation measure is entropy, which evaluates the “purity” of clusters based on the class labels [54]. On the other hand, internal measures evaluate the goodness of a cluster structure without respect to external information [17, 6, 53, 34]. For example, the Silhouette index [49] validates the clustering performance based on the difference between- and within-cluster distances of all points.

Both external and internal validation measures are crucial for many application scenarios. Since external measures know the "true" cluster number in advance, they can be used for choosing an optimal clustering algorithm on a specific data set. For instance, if external measures show that a document clustering algorithm can lead to the clustering results which match the categorization performance by human experts, there is a good reason to believe this clustering has a practical impact on document clustering. On the other hand, internal validation measures can be used to choose the best clustering without any additional information. In practice, external information such as class labels is not available in some real world applications. In that, internal validation measures are the only option for cluster validation when there is no external information available.

However, there are scenarios where clustering validation has limitations. in the case where external information is not available and internal measures are not robust, subjective evaluations such as cases are often used in more context, which is particularly common in network clustering algorithms [56, 70, 66]. Another example would be the case where class labels may not reflect the cluster structure well, when the class labels do not necessarily correspond to locality. Some clusters may contain a mixture of objects from different classes, objects in widely separated clusters. In this circumstance, using clustering techniques to reveal the data characteristics may not be a good idea.

## Clustering Validation Measures

In literature, there is a list of clustering validation measures for soft (fuzzy) algorithms. A fuzzy clustering algorithm generates a fuzzy partition to provide a degree of membership of each object to a given cluster. A fuzzy clustering approach is less prone to minimum crisp clustering algorithms since it makes soft decisions in each iteration through the use of membership functions [4]. Kim et al. propose a clustering validation measure for fuzzy partitions obtained from C-Means clustering [31]. The proposed validation index exploits intercluster proximity between fuzzy clusters, which the best c-partition is obtained by minimizing the intercluster proximity with respect to c. Smyth proposes a cross-validated likelihood measure to determine the appropriate number of clusters in the context of model-based clustering [52]. The Xie-Bie index (XB) [63] defines a clustering validation function to measure the overall compactness and separation of the c-partition. The intercluster separation is the mean square distance between cluster centers and the cluster center. The optimal cluster number is reached when the minimum of XB is found. G and Geva also proposed a fuzzy validation index which is based on the concepts of hypervolume and density [14].

Another category of related works is validation for subspace clustering. Traditional clustering seeks to find clusters in different subsets within a set [45]. In high-dimensional data, many dimensions are irrelevant and can mask existing clusters in data. Subspace clustering localizes the relevant dimensions to find clusters that exist in multiple, possibly overlapping. Many of the validation measures for traditional clustering approaches, such as entropy [1], F-measure [2], and classification error [46], are also used as validation measures for subspace clustering. Muller et al. [44] provide a systematic and thorough evaluation of subspace clustering.

This chapter focuses on providing a comprehensive study of various aspects of the internal and external validation measures for crisp clustering. The sections of this chapter are organized as follows. In Section 23.2, an organized study on 16 external validation measures for K-means clustering is presented. The importance of normalization in evaluation with imbalanced distributions is demonstrated, and the normalization solutions for several measures are also provided. Major properties of the external measures, as well as their interrelationships, are presented [62]. Section 23.3 presents a detailed study on 12 widely used internal validation measures for crisp clustering [37, 38]. Properties of these internal measures in different aspects, such as the impact of data with noise, subclusters, and arbitrary shapes, are investigated. We conclude this chapter with a summary in Section 23.4.

## 23.2 External Clustering Measures

In literature, a number of external validation measures for crisp clustering have been proposed. In this section, an organized study on 16 widely used external validation measures as shown in Table 23.1 is presented. These measures represent a good cover of external validation measures available in different fields such as data mining, machine learning, and statistics. A common ground of these measures is that they can be computed by contingency matrix as follows.

**The Contingency Matrix.** Given a data set D with $n$ objects, assume that there is a partition $P=\{P_1, \dots, P_K\}$ of $D$, where $\bigcup_{i=1}^K P_i = D$ and $P_i \cap P_j = \emptyset$ for $i \neq j$, and $K$ is the number of clusters. ### 23.2.1 An Overview of Clustering Validation Measures

F-measure was originally designed for the evaluation of hierarchical clustering [48, 36], but has also been employed for partition clustering. It combines the precision and recall concepts from the information retrieval community.
