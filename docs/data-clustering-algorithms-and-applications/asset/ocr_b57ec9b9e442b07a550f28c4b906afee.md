# 7.6.2 Semisvised Clustering

In many situations when we discover new patterns using clustering, there exists some prior, partial, incomplete knowledge about the problem. We wish to incorporate knowledge into the clustering algorithm. Semisvised clustering refers to the situation where the clustering is done with many present semisvised-link constraints (two points may be clustered into the same cluster) and cannot-link constraints (two data points cannot be clustered into the same cluster) [5, 8, 4, 115, 129, 61].

The specified above constraints are formulated as follows [115]: (1) Must-link constraints. $A=\{(i_1, j_1), \dots, (i_a, j_a)\}; |A|$ contains pairs of points, where $x_i, x_j$ are considered similar and must be clustered into the same cluster. (2) Cannot-link constraints. $B=\{(i_1, j_1), \dots, (i_b, j_b)\}; |B|$, where each pair of points is dissimilar and cannot be clustered into the same cluster. $A, B$ can also be viewed as symmetric matrices containing $\{0, 1\}$. Using cluster indicator $H$, the must-link of $(i_1, j_1)$ implies that $x_i, x_j$ should have nonzero posterior probability over the same cluster $k$; the overlap $\sum_{(i,j) \in A}h_{ik}h_{jk} = (HH^T)_{ij}$ should be maximized. Thus, the must-link condition is $\max_H \sum_{(i,j) \in A}(HH^T)_{ij} = Tr[A(HH^T)] = Tr[AH^TH]$. Similarly, the cannot-link constraints can be formulated as penalty $\lambda Tr[BH^TB]$. But semisvised clustering problem can be formulated as the following optimization problem:

```
$\max_{H H^T \ge 0} Tr[AH^TH] + \alpha Tr[BH^TB]; \quad (7.32)$
```

```
$\min_{H H^T \ge 0} ||(W^* - HH^T)||^2; \quad (7.33)$
```

Thus, the semisvised clustering problem is equivalent to a semi-NMF problem [37, 72]. Chen et al. formulated semisvised clustering with the instance-level constraints using nonnegative tri-factorization [17]; Zhu et al. [143] noted that must-link and cannot-link constraints play different roles in clustering and proposed a constrained NMF method where must-link constraints are used to control the distance of the data in the compressed format, and cannot-link constraints are used to control the encoding factor.\There are also some research efforts on incorporating the (partial) class label information into the matrix factorization framework. Lee et al. [69] presented semisvised NMF (SSNMF) which jointly incorporates the data and the (partial) class label into NMF. Liu and Wu [81] proposed a form of constrained NMF by requiring that the data points sharing the same label have the same coordinate in the new representation space.
