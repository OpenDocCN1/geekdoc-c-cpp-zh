# 11.4.2 DBDC: Density-Based Clustering

DBDC [24] is a density-based distributed clustering algorithm. Density-based clustering aims to discover clusters of arbitrary shape. Each cluster has a density of points which is considerably higher than that of the cluster. Also, the density within the areas of noise is lower than the density in any of the clusters.

DBDC is an exemplary algorithm that follows the general framework given in Section 1.4.1. Initially the data is partitioned over machines. At the local clustering step, each machine performs a carefully designed clustering algorithm to output a set of few representatives with an accurate description of clusters. The representatives are merged in the global clustering using DBSCAN [17], a single-machine density-based clustering algorithm. Then the global clusters are sent back to all client sites which relabel all objects on their site independently of each other.

The experimental results show the advantage of the distributed clustering. The running time of DBDC is more than 30 times faster than the serial clustering counterpart. Moreover, DBDC yields almost the same clustering quality as the serial algorithm.

# 11.4.3 ParMETIS: Graph Partitioning

ParMETIS [31] is a graph partitioning algorithm. Given a vertex and edge weighted graph, k-way graph partitioning partitions the vertices into k subsets so that the weight of the vertices in each subset is roughly the same, and weight of the edges whose incident edges belong to different subsets is small. For example, Figure 11.8 shows an example of 3-way graph partitioning of a graph with 14 vertices. The graph partitioning is essentially a clustering problem where the goal is to find good clusters of vertices.
