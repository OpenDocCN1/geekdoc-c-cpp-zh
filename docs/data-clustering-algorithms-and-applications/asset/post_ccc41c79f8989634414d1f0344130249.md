
## Grid-Based Clustering

### 6.4.2 ADCC: Adaptable Deflect and Conquer Clustering

The clustering quality of grid-based clustering algorithms depend on the size of the defined grids and the density. To reduce their influence, Lin et al. adopted 'deflect and conquer techniques' to propose a new grid-based clustering algorithm ADCC (Adaptable Deflect and Conquer Clustering) [16]. Very similar to NSGC, the idea of ADCC is to utilize the predefined grids and predefined threshold to identify significant cells. Nearby cells that are also significant can be merged to develop a cluster. Next, the cells are deflected a half-cell in all directions and the significant cells are identified again. Finally, the newly generated significant cells and the initial set of significant cells are merged to improve the clustering of both phases. Specifically, ADCC is summarized in Algorithm 29.

```text
1: Generate the first grid structure.
2: Identify the significant cells.
3: Generate the first set of clusters.
4: Transform the grid structure.
5: Generate the second set of clusters.
6: Revise the original clusters. In this case, the first and second sets of clusters are combined recursively.
7: Generate the final clustering result.
```

The overall complexity of ADCC is $O(md^d + N)$, where $m$ is the number of intervals in each dimension, $d$ is the dimensionality of the data, and $N$ is the number of data points. While ADCC is very similar to NSGC in its axis-shifting strategy, it is in how it constructs clusters from the grids. Rather than examining a neighborhood of the two grids at NSGC, ADCC examines the two grids recursively looking for consensus in the significance of cells in both strategies that overlap a previous cluster to make a determination about the final clustering. This step can also help to separate clusters more effectively especially if there is only a small distance between them. Both methods are susceptible to errors caused by small cell size, but for the most part handle arbitrary boundaries and shapes in clusters well. ADCC is not dependent on many parameters to determine its termination. It is only dependent on the number of intervals per dimension, $m$.

### 6.4.3 ASGC: Axis-Shifted Grid-Clustering

Another attempt by Lin et al. [17] to minimize the impact of the size and borders of the cells is ASGC (Axis-Shifted Grid-Clustering) (also referred to as ACICA). After creating an original grid structure and initial clustering from that grid structure, the original grid is shifted in each dimension and another clustering. The shifted grid structure can be translated an arbitrary distance to be specified. The effect of this is to implicitly change the size of the original cells. It also offers flexibility to adjust boundaries of clusters in the original data and minimize the effect of the boundary cells. The clusters generated from this shifted grid structure can be used to revise the original clusters. Specifically, the ASGC algorithm involves 7 steps, and is summarized in Algorithm 30 from [14].

The complexity of ASGC is the same as that of ADCC, which is $O(md^d + N)$, where $N$ is the number of data points, $d$ is the dimensionality of the data, and $m$ is the number of intervals in each dimension. The main difference between ADCC and ASGC is that the consensus method to revise clusters is bidirectional in ASGC: using the overlapping clusters from the first phase can be used to modify the clusters of the second phase and vice versa. When a cluster of the first overlaps a cluster of the second, the combined cluster of union both can then be modified in order to generate the final clustering. This permits grant flexibility in handling arbitrary shapes of clusters in the original data and minimizes the extent to which each grid structure will separate clusters. By essentially translating the grid structure an arbitrary distance to create the second grid and overlapping it with the original grid, a different resolution (and potentially different cell size) is also achieved by this translation. While this method is less susceptible to the effects of cells size and cell-density thresholds than other axis-shifting-clustering methods, it still requires careful choice of cell size and cell-density thresholds.

#### Algorithm 30 ASGC Algorithm

- 1: Generate the first grid structure: the entire feature space is divided into non-overlapping clusters thus forming the first grid structure.
- 2: Generate the significant cells: These are cells whose density is more than a predefined threshold.
- 3: Generate the first set of clusters: all neighboring significant cells are grouped to form clusters.
- 4: Transform the grid structure: the original origin is shifted by distance $\xi$ in each dimension of the feature space to obtain a new grid structure.
- 5: Generate the second set of clusters: new clusters are generated using steps 2 and 3.
- 6: Revise the original clusters: the clusters generated from the shifted grid structures can be used to revise the clusters from the original grid structure.
- 7: Generate the final clustering.

### 6.4.4 GDILC: Grid-Based Density-Isoline Clustering Algorithm

Zhao and Song [32] proposed a Grid-Based Density-Isoline Clustering algorithm (GDILC) to perform clustering by making use of the density-isoline feature. It assumes that all samples have been normalized. Attributes are numerical and are in the range of [0, 1]. This is for the convenience of distance and density calculation. GDILC first calculates a density-isoline figure, the contour figure of the density of data points. Then clusters are discovered from the density-isoline figure.

GDILC computes the density of a data point by counting the number of points in its region. Specifically, the density of a data point $x$ is defined as follows:

$Density(x) = |\{y : Dist(x,y) \le T\}|$

where $T$ is a distance threshold and $Dist(x,y)$ is a distance function (e.g., Euclidean distance) used to measure the similarity between data points and $y$. The density-isoline figure is never drawn, but estimated from the density vectors. The density are computed by counting the elements of each row of the distance matrix that are less than the distance of the neighbor region. To avoid enumerating all data points for calculating the density vector, GDILC employs a grid-based method. The grid-based method first partitions each dimension into several intervals creating hyper-rectangular cells. To calculate the density of data point $x$, GDILC considers only data points in the same cell with $x$ and those data points in its neighboring cells, this is identical to axis shifting. The GDILC algorithm is shown in [31].

For many sets, the grid-based method significantly reduces the space of calculating the point pairs; the complexity may appear nearly linear. In the worst case time complexity of GDILC is $O(n^2)$ (i.e., for the pathological case where all the points in the neighborhood of a constant number of cells), however, it cannot be scaled to high-dimensional data because the space is divided into $m^d$, where $m$ is the number of intervals in each dimension and $d$ is the dimensionality.

#### Algorithm GDILC Algorithm

- 1: Partition each dimension into several intervals creating hyper-rectangular cells.
- 2: Calculate distances between data points.
- 3: Compute the density vector by counting elements within neighbor regions.
- 4: Estimate the density-isoline figure from the density vectors.
- 5: Discover clusters from the density-isoline figure.

## 6.5 High-Dimensional Algorithms

The scalability of grid-based approaches is a significant problem in higher dimensional data because of the increase in the size of the grid and the resultant time complexity. Moreover, inherent issues in clustering high dimensional data such as filtering noise and identifying the most relevant attributes or dimensions must be addressed inherently in the grid structure. In this section, we examine carefully subspace approach presented in CLIQUE and a density estimation approach presented by OptGrid. This section is greatly influenced by the work of Berlin [3] with additional insights on the strengths, and weaknesses of each algorithm.

### 6.5.1 CLIQUE: The Classical High-Dimensional Algorithm

Agrawal et al. [1] proposed a hybrid density-grid-based clustering algorithm, CLIQUE (Clustering In UE), to find automatically subspace clustering of high-dimensional data. It locates clusters embedded in subspaces of high-dimensional data without much user interaction. In order to present the clustering results in an easily interpretable form, each cluster is given a minimal description as ajunctive normal form (DNF) expression.

CLIQUE partitions its numerical space into units for its grid structure. Moreover let $A = \{A_1, A_2, ..., A_d\}$ be a set of bounded, totally ordered domains (attributes) and $S = A_1 \times A_2 \times ... \times A_d$ be a $d$-dimensional space. Partitioning each dimension $A_i$ ($1 \leq i \leq d$) by $m$ intervals of equal length, grid divides the $d$-dimensional space into $m^d$ nonoverlapping rectangular units. A $d$-dimensional data point, $v$, is considered in a unit, if the value of $v$ in each attribute, is greater than equal to the left boundary of attribute in $u$ and less than the right boundary of attribute in $u$.
