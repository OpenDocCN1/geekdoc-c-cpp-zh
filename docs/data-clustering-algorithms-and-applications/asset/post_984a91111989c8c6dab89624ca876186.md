## 22.4.1 Nonparametric Bayesian Cluster Ensembles (NPCE)

Recently, a nonparametric version of Bayesian cluster ensemble (NPCE) has been proposed in [65] which allows the number of consensus clusters to adapt with data. The authors use a tranche-breaking construction of the generative process of this model is described below. With truncation enforced at $k$. If $k$ is made sufficiently large, the resulting Dirichlet process closely approximates a Dirichlet process.

- 1. Generate $v_\ell \sim \beta(1, \alpha)$ $\forall \ell \in \{1, 2, \dots, k\}$. Let $\theta_\ell = v_\ell \prod_{j \neq \ell}(1-v_j)$.
- 2. For each base clustering (indexed by $q$), generate $\beta^{(q)} \sim G^{(q)}$ $\forall \ell \in \{1, 2, \dots, k\}$, where $G^{(q)}$ is a symmetric Dirichlet distribution of dimension $k$.
- 3. For the $i$th data point $\mathbf{x}_i$, generate $z_i \sim$ multinomial($z$). $z_i$ is an indicator vector of dimension $k$ with only one component being unity and the others being zero.
- 4. For the $q$th base clustering of the $i$th data point, generate the base clustering result $y_{iq} = \ell - $ multinomial($\beta^{(q)}$).

One note that NPCE does not allow multiple base clustering solutions of a given data to be generated from more than one consensus cluster. The model is more restrictive

## 22.4.2 Pairwise Similarity-Based Approaches

In pairwise similarity-based approaches, one takes the weighted average of all r co-association matrices to form an ensemble co-association matrix S which is given as follows:

$$S = \frac{1}{r} \sum_{q=1}^{r} w_q S^{(q)}$$ (22.12)

Here $w_q$ specifies the weight assigned to the base clustering. This ensemble co-association captures the fraction of times a pair of data points is placed in the same cluster over the r clusterings. The matrix can be viewed as a similarity matrix (with a corresponding similarity graph) to be used by the consensus mechanism for creating the clusters. This matrix is different from the similarity matrix $S$ that we obtain from the consensus solution $\lambda$. We will explain the difference in Section 22.4.1.

Note that the co-association matrix size is itself quadratic in $n$, which forms a lower bound on computational complexity as well as memory requirements, inherently handling such techniques for very large datasets. However, it is independent of the dimensionality of the data.
