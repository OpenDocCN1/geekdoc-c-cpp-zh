# 13.4 Clustering Documents

Long documents often discuss multiple subjects. This presented added challenge to general purpose clustering algorithms that intend to associate a document with a single topic. The idea to solving this problem is to consider the document as being made up of smaller topologically text blocks, *segments*. Segments can be identified independent of or concurrent to the clustering procedure.

# 13.4.1 Document Segmentation

Text segmentation is concerned with the fragmentation of text into smaller units (e.g., paragraphs) each discussing a single topic. Regardless of the presence of logical structure clauses in the document, linguistic criteria and statistical measures have been mainly used to identify thematically coherent, contiguous text blocks in unstructured documents [44, 10, 21].

The *TextTiling* algorithm [44] is the exemplary block-based method for text segmentation. TextTiling is able to subdivide text into multiparagraphous, contiguous and disjoint blocks that represent topics, or subtitles. More precisely, TextTiling detects boundaries by analyzing patterns of local co-occurrence and distribution in the text. That that a topic tends to co-occur locally. A switch to a new subtopic is detected when the co-occurrence of a set of terms ends the co-occurrence of another set terms. All pairs of adjacent text blocks are compared using the cosine similarity and the result of similarity values are examined in order to detect coherence between segments.

Recent segmentation techniques have taken advantage of advances in generative topic modeling algorithms which were specifically designed to identify topic within text. Brants et al. [15] use PLSA to capture word-topic distributions, fold in those at the block level (if block cases are segments), and then select segmentation points based on the similarity values of adjacent block pairs. Sun [102] use LDA on corpora of segments, segment similarities via a Fisher kernel, and optimize segmentation via dynamic programming. Misra et al [76] use a document-level LDA model, represent segments and predict their LDA models

**Modeling segmentation.** The Segmented Topic Model (STM) [29] assumes that each segmented document has a certain mixture of latent topics and each segment within the document also has a mixture over the same latent topics as the documents. The shared latent topic provides a way to correlate documents and segments.
