# 21.3 Multiple Clustering Analysis Using Alternative Clusterings

In this section, we first review the different dimensions that may be used for assessing the behaviour of alternative clustering algorithms. We then describe in detail the different approaches, broken down according to style of technique.

# 21.3.1 Alternative Clustering Algorithms: A Taxonomy

Alternative clustering algorithms (ACAs) may be characterized in a range of different ways. We review the different options in turn.

**Format of the input:** The input to an ACA consists of the dataset to be clustered, which may be represented as feature valued instances or by a similarity matrix for all pairs of objects. A technique might require additional features to be *background knowledge*, which is a single existing clustering or a collection of two or more clusterings that are already available. It is not specified where the background knowledge comes from; it might come from the application of a standard clustering algorithm or from users.

**Format of the output:** The output consists of a single clustering or two more alternative clusters. Some may place constraints on the number of clusters in each clustering (e.g., they must be equal), or require that the number of clusters in the output matches with the number of clusters in the clustering that is as background knowledge. Also, the output may consist of either an (alternative) clustering or a *parallel clustering*. The latter is useful if the user wants to change some characteristics (clusters) of the clustering(s) being used as background knowledge, while keeping other characteristics.

**Style of generation:** If more than one alternative can be output, is each alternative generated one in a greedy fashion (*sequential generation*) or are all generated in parallel (*simultaneous generation*)? The latter may produce a more globally optimal solution. The former may be more realistic when one or more clusterings exist. It might also identify some strong clusters which would be missed by a simultaneous generation technique.

**Style of Technique:** This describes the overall process of alternative clustering generation. One class of techniques is *unguided*, where no background knowledge is used for alternatives. The other class of techniques is *guided generation*, where background knowledge is used as input and explicit effort is made to ensure similarity between new clusterings and existing ones in the background knowledge. Guided generation techniques can be further broken down, according to whether the technique (i) relies on the use of inferred constraints to generate alternatives (*constraint based*), (ii) operates by generating feature spaces which are orthogonal to the feature space and to each other (*orthogonal feature space transformation*—such a transformation means the feature space of the alternative clustering(s) is different from that of the clustering(s) in the background knowledge), or (iii) uses an objective function based on information theoretic criteria, in order to optimize quality and dissimilar characteristics (information theoretic).
