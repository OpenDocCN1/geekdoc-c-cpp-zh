# Probabilistic Models for Clustering

**FIGURE 3.1:** Graphical representation of a mixture model. Circles indicate random variables, and black and shaded shapes indicate observed and latent (i.e., unobserved) variables.

An obvious way of generating a random sample $x_n$ by the mixture model, given by (3.1), is follows. Let $z_n$ be a categorical variable taking on the values $1, \dots, K$ with probabilities $p(z_n=k)=\pi_k$ (also denoted as $p(\zeta_n=k)$). Suppose the conditional distribution of $x_n$ given $z_n=k$ is $p(x_n|theta_k)$. The marginal distribution of $x_n$ is obtained by summing the distribution over all possible values of $z_n$ to give $x_n$ as (3.1). In this context, the variable $z_n$ can be thought of as the component (or cluster) of the random sample $x_n$. Instead of using a single categorical variable $z_n$, we introduce a $K$-dimensional binary vector $\mathbf{z}_n$ to denote the component for $x_n$. The $K$-dimensional random variable $\mathbf{z}_n$ has a 1-of-K representation, in which one of the elements $z_{nk}$ equals 1, and all other elements equal to 0, denoting the component of $x_n$ is equal to $k$. For example, if we have a variable with $K=5$ clusters and a particular observation $x_n$ of the variable happens $z_{nk}=1$, $x_n$ will be represented by $\mathbf{z}_n=(0,0,0,0,1)$. Note that the values of $z_{nk}$ satisfy $z_{nk}\in\{0,1\}$ and $\sum_{k=1}^K z_{nk}=1$. Because $\mathbf{z}_n$ uses a 1-of-K representation, the marginal distribution of $x_n$ is specified in terms of mixing probabilities $\pi_k$, such that

```
$p(\mathbf{z}_n) = \pi_1^{z_{n1}}\pi_2^{z_{n2}}\dots\pi_K^{z_{nK}}.\quad (3.2)$
```

Similarly, the conditional distribution of $x_n$ given $\mathbf{z}_n$ can be written in the form

```
$p(x_n|\mathbf{z}_n) = \sum_{k=1}^K p(x_n|\theta_k)^{z_{nk}}.\quad (3.3)$
```

The joint distribution is given by $p(\mathbf{z}_n)p(x_n|\mathbf{z}_n)$, and the marginal distribution of $x_n$ is obtained as

```
$p(x_n) = \sum_{k=1}^K p(\mathbf{z}_n)p(x_n|\mathbf{z}_n) = \sum_{k=1}^K \pi_k p(x_n|\theta_k).\quad (3.4)$
```

Thus, the above marginal distribution of $x_n$ is an equivalent involving an implicit latent variable. The graphical representation of the mixture model is shown in Figure 3.1. From the generative process point of view, a set of data points could have been generated by repeating the process $N$ times, for each data point $x_n$.

+   (a) Choose a hidden component (i.e., cluster) label $z_n \sim MultiK(1, \pi)$. This selects the $k$th component from which to draw $x_n$.

+   (b) Sample a data point $x_n$ from the $k$th component according to the conditional distribution $p(x_n|\theta_k)$.

Because we have represented the marginal distribution in the form $p(x_n) = \sum_{z_n} p(x_n, z_n)$, it follows that for every observed data point $x_n$ there is a corresponding latent variable $z_n$. Using Bayes' theorem, we can obtain the conditional distribution of $z_{nk}=1$ given $x_n$

```
$p(z_{nk}=1|x_n) = \frac{p(zz_{nk}=1)p(x_n|z_{nk}=1)}{\sum_{j=1}^K p(z_{nj}=1)p(x_n|z_{nj}=1)} = \frac{\pi_k p(x_n|\theta_k)}{\sum_{j=1}^K \pi_j p(x_n|\theta_j)}.\quad (3.5)$
```
