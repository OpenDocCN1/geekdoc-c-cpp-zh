# Concepts of Visual and Interactive Clustering

# 19.4 Interactive Comparison and Combination of Clusterings

A new concept that combines capabilities of humans with those of computers is computer-assisted clustering [17]. The premise is that automatic clustering approaches are driven by their own well-justified optimization function to partition the given data. However, it is difficult to interpolate with respect to the application at hand. Therefore, the existing clustering algorithms will produce a result that the user recognizes as "insightful" or "useful" with respect to the application at hand. Computer-assisted clustering computes a large collection of clusters using proven methods with different settings for parameters and distance. This is called the collective wisdom of the statistical community. All pairs of these clusters are compared using variational information [32] and a distance matrix of all clusters is computed. The matrix is embedded into the two-dimensional plane using Samidimensional scaling. This two-dimensional map produces a visualization that allows the user to recognize the impact of choosing one of the different clustering methods gives the data at hand. Furthermore, the map is used to interpolate between similar clusters. Next, we introduce details of the space of clusters, the visualization of it and discuss the overall approach.

# 19.4.1 Space of Clusterings

Given some data with N objects, the idea of computer-assisted clustering is to apply a large number of automated clustering algorithms to it and select suitable clusterings afterwards. A cluster is defined here as a partition of the data instances. A prerequisite of the approach is to compile a list of automated clustering algorithms that should be included. Furthermore, several cluster algorithms are able to work with a different set of distance/similarity measures. Thus, suitable distance/similarity measures can be chosen for each cluster using wisely. While picking algorithms and distance/similarity measures can be done independently of given data, parameters of the algorithms cannot be fixed in such a data-dependent way. Beside details about the problem setting being given in [17], the respective supplementary material, parameters like number of clusters specified once for all methods that need such an input, if so as what would be the right number of clusters several different choices could be specified. This parameter is needed to specify the composition of finite mixture models as well as convert hierarchical clusterings into flat ones. The result of this is a set of M clusterings, which is called the wisdom of the statistical community.

The space of flat clusterings (partitions) is built on a metric that can compare two different clusters. All comparison functions are based on the confusion matrix, also called association matrix and contingency table. For completeness, we briefly describe the basics of variational information [32], on which metric computer-assisted clustering is based. Given two clusters C and C' of N objects, the confusion matrix is a K × K' matrix where each entry is the size of the intersection between a cluster Ck and C'. The normalized variant of the cluster partition specifies the discrete joint distribution of the cluster labels of the two:

```
P(k,k') = \frac{|C_k \cap C_{k'}|}{N}
```

This quantity says how likely it is that a randomly data object is a member of clusters Ck and C'. The marginal distributions provide the probability that a data object is member of a cluster in the respective cluster:

```
P(k) = \frac{|C_k|}{N} \quad P'(k') = \frac{|C_{k'}|}{N}
```
