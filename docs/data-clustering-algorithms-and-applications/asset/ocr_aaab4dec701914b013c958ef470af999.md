Moreover, according to Equation 8.6, $f_i$ satisfies the following:

```
$f_i^T f_i = \sum_{j=1}^n f_i^T f_j = |A_i| \frac{1}{|A_i|} = 1$$
```

It is also easy to check that any two different column vectors of F are orthogonal. Now the RatioCut problem is equal to the following:

```
$$\min_{A_1...A_k} Tr(F^T LF) \quad \text{s.t.} F^T F = I$ (8.7)$
```

Note that $f_j$ can only be 0 or $1/\sqrt{|A_j|}$. The objective function is discrete, which is known to be NP-hard. A relaxation of this problem allows $f_j$ to take on arbitrary real values. This implies the following:

```
$$\min_{F\in\Omega^k} Tr(F^T LF) \quad \text{s.t.} F^T F = I$$
```

The aforementioned objective function is exactly the same as the objective function in Equation (8.2) for unnormalized spectral clustering.

According to Rayleigh-Ritz theorem [30], to minimize the above relaxed RatioCut objective is equivalent to minimizing Rayleigh quotient of the unnormalized spectral clustering, where the Rayleigh quotient $R(L,f)$ is defined as:

```
$R(L,f) = \frac{f^T L}{f^T f}$$
```

The Rayleigh quotient (objective value) reaches its minimum (the smallest eigenvalue of $L$) when $f$ is the corresponding eigenvector. Therefore, the solution of Equation (8.2) is obtained by choosing the $k$ eigenvectors of $L$. Later, we need to convert the real valued $F$ back to discrete indicators. As mentioned in Section 8.3.4, the $k$-means approach can be the candidate algorithm to associate on the rows of $F$.

Similar to RatioCut, we define the indicator vectors $f = (f_1, \dots, f_n)^T$ where $1 \le i \le k$ such that:

```
$f_{ij} = \begin{cases} \frac{1}{\sqrt{assoc(A_i)}} & \text{if } v_j\in A_i \ 0 & \text{otherwise.} \end{cases}$ (8.8)$
```
