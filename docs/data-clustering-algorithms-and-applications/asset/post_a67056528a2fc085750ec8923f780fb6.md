## 3.2 Mixture Models

Mixture models for cluster analysis [75, 45, 28, 27] have been addressed in a number of ways. The underlying assumption is that the observations to be clustered are drawn from one of several components, and the problem is to estimate the parameters of each component as to fit the data. Inferring the parameters of these components and identifying which component produced each observation leads to a clustering of the set of observations. In this section, we first give an overview of mixture modeling, then introduce two most common mixtures, Gaussian mixture model and Bernoulli mixture model, and finally discuss several issues about model selection.

## 3.2.1 Overview

Suppose we have a set of data points $X=\{x_1,...,x_N\}$ consisting of $N$ observations of a dimensional variable. The random variable $x_i$ is assumed to be distributed according to a mixture of $K$ components. Each component (i.e., cluster) is mathematically represented by a metric distribution. An individual distribution is then used to model a specific cluster often referred to as component distribution. The entire data set is then modeled by a mixture of these distributions. Formally, the mixture density, or probability density function, of $x_i$, can be written as:

```
p(x_i) = \sum_{k=1}^{K} \pi_k p(x_i|\theta_k)
```

where $\pi_1,...,\pi_K$ are the mixing probabilities (i.e., mixing coefficients or weights), each $\theta_k$ is the set of parameters specifying the $k$th component, and $p(x_i|\theta_k)$ is the component distribution. In order to be valid models, the mixing probabilities $\{\pi_k\}$ must satisfy

```
0 \leq \pi_k \leq 1 (k=1,...,K), \text{ and } \sum_{k=1}^{K} \pi_k = 1.
```

An obvious way of generating a random sample $x_n$ by the mixture model, given by (3.1), is follows. Let $z_n$ be a categorical variable taking on the values $1, \dots, K$ with probabilities $p(z_n=k)=\pi_k$ (also denoted as $p(\zeta_n=k)$). Suppose the conditional distribution of $x_n$ given $z_n=k$ is $p(x_n|\theta_k)$. The marginal distribution of $x_n$ is obtained by summing the distribution over all possible values of $z_n$ to give $x_n$ as (3.1). In this context, the variable $z_n$ can be thought of as the component (or cluster) of the random sample $x_n$. Instead of using a single categorical variable $z_n$, we introduce a $K$-dimensional binary vector $\mathbf{z}_n$ to denote the component for $x_n$. The $K$-dimensional random variable $\mathbf{z}_n$ has a 1-of-K representation, in which one of the elements $z_{nk}$ equals 1, and all other elements equal to 0, denoting the component of $x_n$ is equal to $k$. For example, if we have a variable with $K=5$ clusters and a particular observation $x_n$ where $z_{nk}=1$, $x_n$ will be represented by $\mathbf{z}_n=(0,0,0,0,1)$. Note that the values of $z_{nk}$ satisfy $z_{nk}\in\{0,1\}$ and $\sum_{k=1}^K z_{nk}=1$. Because $\mathbf{z}_n$ uses a 1-of-K representation, the marginal distribution of $x_n$ is specified in terms of mixing probabilities $\pi_k$, such that

```
$p(\mathbf{z}_n) = \pi_1^{z_{n1}}\pi_2^{z_{n2}}\dots\pi_K^{z_{nK}}. (3.2)
```

Similarly, the conditional distribution of $x_n$ given $\mathbf{z}_n$ can be written in the form

```
$p(x_n|\mathbf{z}_n) = \sum_{k=1}^K p(x_n|\theta_k)^{z_{nk}}. (3.3)
```

The joint distribution is given by $p(\mathbf{z}_n)p(x_n|\mathbf{z}_n)$, and the marginal distribution of $x_n$ is obtained as

```
$p(x_n) = \sum_{k=1}^K p(\mathbf{z}_n)p(x_n|\mathbf{z}_n) = \sum_{k=1}^K \pi_k p(x_n|\theta_k). (3.4)
```

Thus, the above marginal distribution of $x_n$ is equivalent involving a latent variable. The graphical representation of the mixture model is shown in Figure 3.1. From the generative process view, a set of data points could have been generated by repeating the process $N$ times for each data point $x_n$:

- (a) Choose a hidden component (i.e., cluster) label $z_n \sim Multi(1, \pi)$. This selects the $k$th component from which to draw $x_n$.
- (b) Sample a data point $x_n$ from the $k$th component according to the conditional distribution $p(x_n|\theta_k)$.

Because we represented the marginal distribution in the form $p(x_n) = \sum_{z_n} p(x_n, z_n)$, it follows that for every observed data point $x_n$ there a corresponding latent variable $z_n$. Using Bayes' theorem, we can obtain the conditional distribution of $z_{nk}=1$ given $x_n$

```
$p(z_{nk}=1|x_n) = \frac{p(z_{nk}=1)p(x_n|z_{nk}=1)}{\sum_{j=1}^K p(z_{nj}=1)p(x_n|z_{nj}=1)} = \frac{\pi_k p(x_n|\theta_k)}{\sum_{j=1}^K \pi_j p(x_n|\theta_j)}. (3.5)
```

where $\pi_k$ (i.e., $p(z_n=k)$) is the prior probability that data $\mathbf{x}_n$ was generated from component $k$, and $p(z_n=k|x_n)$ is the posterior probability that the observed data $\mathbf{x}_n$ came from component $k$. In the following, we use $\gamma(z_{nk})$ to denote $p(z_n=k|x_n)$, which can be viewed as the responsibility that component $k$ takes for explaining the observation $\mathbf{x}_n$.

In this formulation of the mixture model, we need to identify a set of parameters from the observation, including the mixing probabilities $\{\pi_k\}$ and the component distributions $\{\theta_k\}$. The number of components $K$ is considered fixed, but in many applications, the value of $K$ is unknown and inferred from the available data [25]. Thus, the overall parameter of the mixture model is $\Theta = \{\pi_1, \theta_1, \dots, \theta_K\}$. If we assume the data points are drawn independently from the distribution, we can write the probability of generating all data points in the form

```
$p(\mathbf{X}|\Theta) = \prod_{n=1}^N \sum_{k=1}^K \pi_k p(\mathbf{x}_n|\theta_k),$
```

or in a logarithm form

```
$\log p(\mathbf{X}|\Theta) = \sum_{n=1}^N \log \sum_{k=1}^K \pi_k p(\mathbf{x}_n|\theta_k).
```

In statistics, maximum likelihood estimation (MLE) [23, 8, 41] is an important statistical approach for parameter estimation,

```
$$\Theta_{MLE} = \arg\max{\log p(\mathbf{X}|\Theta)}$$
```

Sometimes we have a prior information $p(\Theta)$ over the parameters, and it can be incorporated into the mixture models. Thus, the maximum posteriors (MAP) estimation [70, 27] is used instead,

## 3.2.2 Gaussian Mixture Model
