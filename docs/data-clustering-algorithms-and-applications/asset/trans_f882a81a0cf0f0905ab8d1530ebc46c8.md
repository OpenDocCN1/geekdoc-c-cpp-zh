# 12.1 引言

近年来，已提出了越来越多的分类数据聚类算法，具有有趣的应用，例如划分大型软件系统 [8, 9] 和蛋白质相互作用数据 [13, 21, 38, 77]。

具有 m 个属性的分类数据集被视为 m 维“立方体”，为聚类提供空间密度。立方体的一个单元映射到具有其坐标值的对象的数量。这样的立方体中的簇被视为高密度的子空间，并由低对象密度的子数组表示。对立方体的聚类提出了几个挑战：

(i) 由于属性值没有顺序，立方体单元也没有顺序。寻找密集子空间可能会考虑每个维度的几种排序，以识别最佳聚类（除非所有属性都是二元值）。

(ii) 子空间的密度通常相对于用户指定的值定义，例如半径。然而，不同的子空间更适合不同的半径 [17]。在密集子空间中，不应遗漏任何信息，搜索更准确地“按单元”进行，半径为 1。在稀疏子空间中，更高的半径可能更可取以聚合信息。立方体搜索可以从低半径开始，逐渐移动到更高半径。虽然术语半径来自假设圆形构造的几何分析，但对于分类数据，半径不是欧几里得距离。

图 12.1 说明了具有可能为簇的子空间的 3 维立方体。图 12.2 显示了在 3-D 数据集中创建和扩展簇的示例。半径是邻居在维度上相差的最大数量。

分类聚类算法通常由基于密度的聚类激发，如 CLIQUE [4]、CLICKS [75]、CACTUS [32]、COOLCAT [19]、DBSCAN [29, 68]、OPTICS [17]。
