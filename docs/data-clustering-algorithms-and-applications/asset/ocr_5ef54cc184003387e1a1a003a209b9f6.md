That is, they start with the whole graph as a single cluster and subsequently split into smaller clusters [131]. Both approaches essentially produce a binary tree, known as a dendrogram, where edges represent individual vertices and internal nodes.

The idea of betweenness was proposed to be used in a divisive algorithm for community detection by Newman and Girvan in [125]. Edge betweenness is defined in such a way that edges connecting communities are more likely to receive a higher betweenness score than tracomunity scores. Removing edges with high betweenness scores, communities in the graph can be found. One simple betweenness measure is the *shortest path* betweenness that paths between different clusters are bound to pass through the intercluster edges. This has been proposed and used in the Girvan-Newman (GN) [68] algorithm. This algorithm moves with high betweenness scores to split the network. There are also variations such as random-walk betweenness and current-flow betweenness that assign the betweenness score based on different principles. The high level structure of the algorithm is as follows [131]:

```
Algorithm 38 Divisive Clustering Algorithm [105]
Input: Graph G, number k clusters
repeat
  Calculate betweenness score of each edge using any suitable betweenness measure
  Remove the edge with maximum betweenness score
  Recalculate betweenness score of all remaining edges
until Desired number of clusters are obtained
```

Experiments showed that the choice of a betweenness measure is not very crucial as the *recalculation* step is executed [131]. The results for different betweenness measures differ only slightly. Although very intuitive, the algorithm is *very costly* in terms of computation. Computation of the betweenness score for all edges is $O(|V||E|)$ time operation. The whole algorithm takes $O(|V|^2)$ time.

A greedy agglomerative clustering technique for optimizing modularity was proposed by Newman in [123]. Similar to aggregative algorithms, this approach starts with each node as a different community. In subsequent, smaller communities are merged to form larger communities so that the modularity of the graph increases after the merge. *Modularity* is defined as the fraction of edges that fall within communities and the expected number of edges that fall within communities if at random for the community structures. [123] suggests that a value greater than 0.3 often indicates good community structure. More examples are given in [125]. The algorithm merges communities that share at least one edge other because it does not improve the *modularity*. Hence, this step complexity $O(|E|)$. Maintaining and updating an analytical data structure that stores the fraction of edges between each pair of communities in the current partition has worst-case complexity of $O(|V|^2)$. Since there are $|V|-1$ mergers, the total complexity was improved by the use of data structures such as max-heaps to $O(|E|d\log|V|)$ by Clauset et al. in [37]. Here $d$ represents the depth of the dendrogram describing the partitions found during the execution of the algorithm.
