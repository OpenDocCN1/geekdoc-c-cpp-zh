# 20.2.5 Semisupervised Clustering Based on Nonnegative Matrix Factorization

In [29], a Nonnegative Matrix Factorization (NMF) framework is proposed for both consensus clustering and semisupervised clustering. For the purposes of this chapter, we will focus on the semisupervised clustering process. The main contribution of [29] is to show how semisupervised k-means and semisupervised kernel A-means can be approached as an NMF problem.
The authors consider an indicator matrix $H = [h_1, \dots, h_k]$ with

```
$h_k = [0, \dots, 0, 1, \dots, 0, 0]^T / n_k^{1/2}, \quad (20.13)$
```

where the nonzero entries in $h_k$ represent the points belonging to cluster $k$, and $n_k$ denotes the number of points in [29]. We show that the k-means clustering objective be expressed as

```
$$\max_{H^T H \ge 0} J_k = Tr(H^T W H), \quad (20.14)$
```

where $w_{ij} = x_i^T x_j$ for k-means and $w_{ij} = \phi(x_i)^T \phi(x_j)$ for kernel k-means. By encoding must-link and cannot-link constraints with indicator matrices $A$ and $B$, the authors show that the semisupervised k-means algorithm can be viewed as an optimization problem of the form:

```
$$\max_{H^T H \ge 0} Tr(H^T W H + \alpha A^T W H - \beta B^T H), \quad (20.15)$
```

Let $W^+ = W + \alpha \ge 0, W^- = \beta B$, and removing the orthogonality constraint, a relaxed version of the optimization problem can be expressed as

```
$$\max ||(W^+ - W^-)||_F^2, \quad (20.16)$
```

This is an objective function where $(W^+ - W^-)$ is approximated by $HHT$ with nonnegativity constraints on $H$. Related problems are widely studied in the context of NMF, and the above problem can be solved with updates of the form

```
$H_{ik} = H_{ik} \sqrt{\frac{(W^+H)_{ik}}{(W^-H)_{ik}HH}}}, \quad (20.17)$
```

The authors provide a proof of convergence as well as correctness. The NMF approach performs favorably in comparison to certain existing algorithms in the literature [29]. In [29], the SSC problem is posed as a semidefinite optimization problem which incorporates constraints. Conceptually, this approach is not too different from [9], where the constraints are estimated and co-variance matrices are estimated in an iterative fashion. In [29] a decomposition of $(W^+ - W^-)$ is estimated with $W$ metric-based aspects. As such [29] can also be combining constrained-based and metric-based aspects.
