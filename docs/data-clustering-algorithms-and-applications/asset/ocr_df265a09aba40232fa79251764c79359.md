The artificial clusters assigned by the algorithms often depend on the initialization of the algorithms; e.g., k-means or other types of models fitted with some sort of expectation maximization or Gibbs sampling could produce the same clustering but with permuted cluster labels when run several times on the same data. Clusters from time points with the same artificial clusters do not necessarily match semantically.

The dynamic topic [7] and adaptive probabilistic indexing solve the problem of label switching between clusters/topics of consecutive time points. This allows us to present the clusters/topics of all documents as a batch table where rows and columns indicate clusters and time points, respectively. A cell in this table shows the top-words of a particular cluster/topic at a certain time point. The Topic-Table visualization [14] shows additional information such by visually stacking graphs which helps the user to visualize the similarity. The added data is newest of top-words, similarity between consecutive clusters/topics with same, relative strengths of clusters/topics, and global similarities between all clusters/topics. Details are shown in Figure 19.7.

The color mapping is computed in two steps. First, all pairwise similarities/distances between the clusters/topics are computed. Second, the similarity/distance matrix is used to compute the embedding of clusters/topics into a three-dimensional color space. Thus, each cluster/topic becomes a point in the color space. Using Samson’s multidimensional scaling [36] the similarities/distances are preserved in the color space as much as possible. By drawing the river in each cell of the topic table with the respective color, global connections between similar clusters/topics can be easily spotted.
