# A Survey of Uncertain Data Clustering Algorithms

In order to compute the expected similarity of the data point $\overline{X}$ to the centroid of the cluster $C$, we need to determine a closed form expression which is expressed in terms of $\overline{X}$ and $ECF(C)$. We note that the individual data points are essential variables with a given error, the centroid $Z$ of a cluster $C$ is also a random variable. We make the following observation about the centroid of a cluster:

**Lemma 18.5.1** *Let $Z$ be the random variable representing the centroid of cluster $C$. Then, the following result holds true:*

```
$E[\|Z\|^2] = \sum_{j=1}^{d} CF1(C)_j/n(C)^2 + \sum_{j=1}^{d} EF2(C)_j/n(C)^2 \quad (18.5)$
```

**Proof:** We note that the random variable $Z_j$ is given by the instantiation of the centroid and the mean of $n(C)$ different errors for the points in cluster $C$. Therefore we have

```
$Z_j = CF1(C)_j/n(C) + \sum_{X \in C} e_j(\overline{X})/n(C) \quad (18.6)$
```

Then, squaring $Z_j$ and taking the expected value, we obtain the following:

```
$E[\overline{Z_j}^2] = CF1(C)_j/n(C)^2 + 2 \cdot \sum_{X \in C} E[e_j(\overline{X})] \cdot CF1(C)_j/n(C)^2 + \sum_{X \in C} E[e_j(\overline{X})^2]/n(C)^2 \quad (18.7)$
```

Now, we note that the error is a random variable with standard deviation $\psi_j(\cdot)$ and zero mean. Therefore, $E[e_j] = 0$. Since it is assumed that the random variables representing errors of differences are independent of one another, we have $E[e_j(\overline{X}) \cdot e_j(\overline{Y})] = E[e_j(\overline{X})] \cdot E[e_j(\overline{Y})] = 0$. By using these relationships in the expansion of the above equation, we get

```
$E[\overline{Z_j}^2] = CF1(C)_j/n(C)^2 + \sum_{X \in C} E[e_j(\overline{X})^2]/n(C)^2 + \sum_{X \in C} \psi_j(\overline{X})^2/n(C)^2 \nn = CF1(C)_j/n(C)^2 + EF2(C)_j/n(C)^2$
```

By adding the value over $j$, we get

```
$E[\|Z\|^2] = \sum_{j=1}^{d} CF1(C)_j/n(C)^2 + \sum_{j=1}^{d} EF2(C)_j/n(C)^2 \quad (18.8)$
```

This proves the desired result.

Next, we will use the above result to directly estimate the distance between the cluster $C$ and the data point $\overline{X}$. We will prove the following result:

**Lemma 18.5.2** *Let $v$ denote the expected value of the square of the distance between the uncertain data point $\overline{X} = (x_1 ...x_d)$ (with instantiation $X$) and the point $(\psi_1(\cdot)...\psi_d(\cdot))$ and the centroid of cluster $C$. Then $v$ is given by the following expression:*

```
$v = \sum_{j=1}^{d} CF1(C)_j/n(C)^2 + \sum_{j=1}^{d} EF2(C)_j/n(C)^2 + \sum_{j=1}^{d} x_j^2 + \sum_{j=1}^{d} (psi_j(\overline{X}))^2 - 2 \sum_{j=1}^{d} x_j \cdot CF1(C)_j/n(C) \quad (18.9)$
```
