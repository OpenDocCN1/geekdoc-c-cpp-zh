# Nonnegative Matrix Factorizations for Clustering: A Survey

In summary, various newly proposed NMF formulations are collectively presented as follows:

```
SVD:
$X_{\pm} \approx U_{\pm}V_{\pm}^T$
NMF:
$X_{\pm} \approx F_{\pm}G_{\pm}^T$
Regularized NMF:
$\min \{\|X - FG^T\|^2 + \alpha J_1(F) + \beta J_2(G)\$
Projective NMF:
$X \approx FF^T X$
Semi-NMF:
$X_{\pm} \approx F_{\pm}G_{\pm}^T$
Convex-NMF:
$X \approx CG^T, \text{ where } c_i \in \text{conv}(X)$
Cluster-NMF:
$X \approx XG_iG_i^T$
Kernel-NMF:
$\Phi(X_{\pm}) \approx (X_{\pm})W_{\pm}^T$
Tri-Factorization:
$X_i \approx F_i S_i G_i^T$
Symmetric-NMF:
$W_1 \approx H_1 S_1^T$
Multi-layer NMF:
$X \approx F_{(1)}...F_{(t)}G_{(t)}^T$
Binary NMF:
$X_{0-1} \approx F_{0-1}G_{0-1}^T$
Weighted Subset NMF:
$\min \|X - FG^T\|_W^2$
Robust NMF:
$\min \|X - FG^T\|_R^2$
```

Note that there are other NMF formulations that are not included in the above discussion, such as convolutional NMF for a set of nonnegative matrices [24, 103] and Bayesian NMF with the incorporation of Bayesian techniques to NMF [14, 45, 96].

# 7.6 NMF for Clustering: Extensions

We have shown that NMF provides a general framework for unsupervised learning. NMF model widely varying data distributions and can do both hard and soft clustering simultaneously. In fact, many other clustering problems such as co-clustering, consensus clustering, semisuvised clustering, and graph clustering can be reformulated as an NMF problems.

# 7.6.1 Co-Clustering

In real world applications, a typical often involves more than one type of data points and the input data relating different types of data points. In document analysis, there are *terms* and *documents*. In DNA micro-array data, rows represent *genes* and columns represent *samples*. Co-clustering algorithms aim clustering different types of data simultaneously by making use of dual relationship information such as the term-document matrix and the gene-sample matrix [30, 136, 20, 82, 83].
