## 6.2.3 WaveCluster: Wavelets in Grid-Based Clustering

Sheiksholesami et al. [27] proposed a grid-based and density-clustering approach that uses wavelet transforms: WaveCluster. This algorithm applies wavelet transforms to the data points and then uses the transformed data into clusters. A wavelet transform is a signal processing technique that decomposes a signal into frequency subbands. The insight to using the wavelet transforms is that data points are d-dimensional where d is the number of dimensions. The high-frequency parts of a signal correspond to the more sparse data regions as boundaries of the clusters whereas the low-frequency high-amplitude parts of a signal correspond to the more dense regions such as cluster interiors [3]. By examining different frequency subbands and scales from fine to coarse. A shifted filter is used to emphasize regions where points cluster and suppress weaker information in their boundaries. This makes natural clusters more distinguishable and eliminates outliers simultaneously. As input parameters the algorithm requires the number of grid cells for each dimension, the wavelet, and the number of applications of the wavelet transform. This algorithm is summarized in Algorithm 27 [27].

### Algorithm 27 WaveCluster Algorithm
INPUT: Multidimensional data objects' feature vectors
OUTPUT: cluster objects

- 1: Find the first feature, then assign objects to the units, and compute unit summaries.
2: Apply wavelet transform on the feature space.
3: Find connected components (clusters) in the subbands of transformed feature space, at multiple levels.
4: Assign labels to the units in the connected components.
5: Make the lookup table.
6: Map the objects to the clusters.

## Grid-Based Clustering

WaveCluster offers several advantages. The time complexity is O(N) where N is the number of data points; this is very efficient for large spatial databases. The clustering results are insensitive to outliers and the data point order. The algorithm can accurately detect arbitrarily shaped clusters such as those with concavity and nesting. The wavelet transformation permits multiple levels of resolution, which this algorithm is primarily suited for low dimensional data. However, in the case of high-dimensional data, PCA may be applied to the data to reduce the number of dimensions, so that N > m^f where m is the number of intervals in each dimension and f is the number of dimensions selected after PCA. After this, WaveCluster may be applied to the data to cluster it still achieve linear time efficiency [27].

## 6.3.1 AMR: Adaptive Mesh Refinement Clustering

Liao et al. [15] proposed a grid-based clustering AMR using an Adaptive Mesh refinement technique that applies higher resolution to the localized regions. From traditional grid-based clustering algorithms, such as CLIQUE and GRIDCLUS, which use a single resolution mesh grid, AMR divides the feature space at multiple resolutions. STING also offers multiple resolutions, it does so over the entire space, not localized regions. AMR creates a hierarchical tree constructed from the grids at multiple resolutions. Using this, this algorithm can discern clusters, especially nested ones, which may be difficult to discover without clustering equal levels of resolutions at once.

The AMR clustering mainly contains two steps summarized here from [14]:

- 1. Grid Construction: First grids are created at multiple resolutions based on regional density. The grid hierarchy contains nested grids of increasing resolution since the grid construction is done recursively. The construction of the AMR tree starts with a uniform grid covering the entire space, and for those cells that exceed a density threshold, the grid is refined into higher resolution grids at each recursive step. The new child grids are created as part of the refinement step are connected to the parent cells whose density exceed the threshold.
2. Clustering: To create clusters, each leaf node is considered to be the center of an individual cluster. The algorithm recursively assigns objects in the parent nodes to clusters until the root node is reached. Clusters are assigned to clusters based on the minimum distance to the clusters under the branch.

The overall complexity for constructing the AMR tree is O(dtN^(1-d/p) + (dt + 6^d)^(1-d/q)), where N is the number of data points, d is the dimensionality, t is the number of attributes in each dimension, h is the AMR tree height, p represents the average percentage of data points to be refined at each level, r is the mesh size for the root, and q is the average ratio of mesh sizes between levels.

## 6.4 Axis-Shifting Grid-Based Algorithms

The effectiveness of a grid-based clustering is seriously limited by the size of the predefined grids, the density in space. These challenges motivate another kind of grid-based algorithm: axis-shifting. In this section, we introduce four axis-shifting algorithms: NSGC, ADCC, ASGC, and GDILC.

### 6.4.1 NSGC: New Sh Grid Clustering

Fixed grids may suffer from the boundary effect. To alleviate this, Ma and Chow [18] proposed a Shifting Grid Clustering algorithm (NSGC). NSGC is both density-based and grid-based. To form its grid, the algorithm divides dimension of the space into equal intervals. NSGC shifts the whole grid structure and uses the shifted grid with the original grid to determine the density of cells. This reduces the influence of borders of cells. It then clusters the cells rather than the points. Specifically, NSGC consists of four steps summarized in Algorithm 28.

### Algorithm 28 NSGC Algorithm

- 1: Cell construction: It divides each dimension of the space into 2w intervals, where w is the number of iterations.
2: Assignment: It first finds the data points belonging to a cell, then shifts by half cell-size of the corresponding dimension, and finds the data points belonging to cells.
3: Cell computation: It uses both of the cell itself and its nearest neighborhood to obtain a density profile.
4: Group assignment(clustering): It starts when the considered cell or one of its neighbor cells has no group assignment. Otherwise, the next cell is considered until all non-empty cells are assigned.

NSGC repeats the steps until the result of the previous iteration and that of the current iteration are smaller than a specified error threshold. The complexity of NSGC is O(di*). While that algorithm is nonparametric, its performance depends on the choice of the number of iterations w, and the accepted error threshold. If w is set too low (or high) or the error threshold too high, then clustering results may not be accurate; there is no a priori to know the best values of these parameters for specific data. NSGC is susceptible to errors caused by cell sizes that are too small. As the size of cells decreases (the number of iterations increases), the total number of cells and the number of clusters increase. The reported clusters may be too small and not correspond to clusters in the original data. The strongest advantage of NSGC is that its grid shifting strategy permits it to recognize clusters of arbitrary boundary shapes with great accuracy.
