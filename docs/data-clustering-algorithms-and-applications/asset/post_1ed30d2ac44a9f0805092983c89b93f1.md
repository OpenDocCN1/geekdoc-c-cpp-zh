## 21.2 Technical Preliminaries

Let $D$ be a dataset containing $N$ objects $o_1,\dots,o_N$ and using $n$ features $F_1,\dots,F_n$. A (hard) clustering $C^*$ is a partition of the objects in $D$ into $k$ clusters $\{c_1,\dots,c_k\}$, where each cluster is a set of objects and $c_i\cap c_j=\emptyset$. The universe of all clusterings of $D$ is denoted by $C_D$. We will also use the notation $C_c$ to refer to cluster $c$ of clustering $C$.

The quality of a clustering may be measured using a function Quality $Q: C_D \rightarrow [0,1]$ where higher values indicate higher quality. A large range of quality measures have been defined, with well-known examples like the Dunn Index [13], Davies-Bouldin Index [12], and the Silhouette Width [34].

Let $C_1=\{c_1,\dots,c_k\}$ and $C_2=\{c'_1,\dots,c'_l\}$ be two clusterings of $D$. The similarity between $C_1$ and $C_2$ may be measured using a function $Sim: C_D \times C_D \rightarrow [0,1]$ where higher values indicate higher similarity. For measuring similarity, there are a number of measures, including the Rand Index [33], Adjusted Rand Index [21], Jaccard Index [18], Normalized Mutual Information [24], and Adjusted Mutual Information [36]. Measuring similarity between clusterings is important, since it provides insight for the user in the relationship between them. When managing multiple clustering, assessment of similarity may allow removal of redundant clusters, selection of interesting clusters, or increased understanding about clustering evolution. It is a key step when exploring the convergence properties of a clustering algorithm or assessing its output compared to an expert generated clustering.

Given the large range of measures that can be "plugged in" for measuring quality and similarity, appropriate choices are made in an application dependent way. We will shortly describe the issues involved in generating alternative clusters and the different dimensions along which the existing algorithms may be. A general description of the tasks is follows

Definition 21.1 Generalized Alternative Clustering: Given a empty collection of clusters $K=\{C_1,\dots,C_m\}$ provided as background knowledge (either $K=0$, or $K\neq0$ and $m\geq 1$), generate alternative clustering(s) $O=\{C_{m+1},\dots,C_{m+j}\}$, such that $\sum_{i=m+1}^{m+j}Quality(C_i)$ is maximized and $\sum_{i=1}^mSim(C_i,C_j)$ is minimized.

The task here corresponds to generating a set of (alternative) clusters, where each individual is of high quality and also the pairwise similarity between the clusterings is low. Three common cases are:

- $|K|=1$ and $|O|=1$: singular alternative clustering
- $|K=0$ and $|O|=2$: clusters are generated in parallel: simultaneous alternative clustering
- $|K|>1$ and $|O|=1$: sequential alternative clustering

> It is also possible to use fuzzy clustering as the basis for development, but the literature on alternative fuzzy clustering is less mature and we concentrate on the hard case.

### 21.3.1 Alternative Clustering Algorithms: A Taxonomy

Alternative clustering algorithms (ACAs) may be characterized in a range of different ways. We review the different options in turn.

**Format of the input:** The input to an ACA consists of the dataset to be clustered, which may be represented as feature valued instances or by a similarity matrix for all pairs of objects. A technique might require additional features to be *background knowledge*, which is a single existing clustering or a collection of two or more clusterings that are already available. It is not specified where the background knowledge comes from; it might come from the application of a standard clustering algorithm or from users.

**Format of the output:** The output consists of a single clustering or two more alternative clusters. Some may place constraints on the number of clusters in each clustering (e.g., they must be equal), or require that the number of clusters in the output matches with the number of clusters in the clustering that is as background knowledge. Also, the output may consist of either an (alternative) clustering or a *parallel clustering*. The latter is useful if the user wants to change some characteristics (clusters) of the clustering(s) being used as background knowledge, while keeping other characteristics.

**Style of generation:** If more than one alternative can be output, is each alternative generated one in a greedy fashion (*sequential generation*) or are all generated in parallel (*simultaneous generation*)? The latter may produce a more globally optimal solution. The former may be more realistic when one or more clusterings exist. It might also identify some strong clusters which would be missed by a simultaneous generation technique.

**Style of Technique:** This describes the overall process of alternative clustering generation. One class of techniques is *unguided*, where no background knowledge is used for alternatives. The other class of techniques is *guided generation*, where background knowledge is used as input and explicit effort is made to ensure similarity between new clusterings and existing ones in the background knowledge. Guided generation techniques can be further broken down, according to whether the technique (i) relies on the use of inferred constraints to generate alternatives (*constraint based*), (ii) operates by generating feature spaces which are orthogonal to the feature space and to each other (*orthogonal feature space transformation*—such a transformation means the feature space of the alternative clustering(s) is different from that of the clustering(s) in the background knowledge), or (iii) uses an objective function based on information theoretic criteria, in order to optimize quality and dissimilar characteristics.
