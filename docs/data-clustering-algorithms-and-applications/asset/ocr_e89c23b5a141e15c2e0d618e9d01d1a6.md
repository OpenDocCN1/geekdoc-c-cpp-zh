# 16.4.2.4 Suffix Tree and Suffix Array-Based Method

For fast processing of sequence similarity, efficient data structures that index sequence pairwise segments are also proposed. The main objective of using a data structure is to avoid the pairwise similarity computation, which is infeasible for many clustering tasks because of its quadratic complexity. For example, databases of ESTs sometimes contain millions of ESTs and efficient data structure is crucial for clustering those sequences.

In [72], the authors use suffix arrays to cluster ESTs; suffix arrays are particularly suitable because ESTs are short subsequences of cDNA. To identify all blocks of length k, this method first adds all into a suffix array. It then sorts the suffixes and groups the suffixes that have a k-length prefix. Then, for each pair of suffixes having at least one matching block, it finds the largest matching blocks and the corresponding score. By starting with the highest scoring sequence pair, it builds hierarchical clusters using single-link clustering. In [47], the authors propose a clustering tool called CLAGEN, which uses a suffix tree for sequence clustering. CLAGEN constructs a suffix tree from the input sequences; this construction is highly efficient with only linear time complexity. Then, CLAGEN uses the suffix tree for searching and overlapping commons so that it can obtain sequence pairs that are highly similar. From the similarity information, CLAGEN finds clusters. A nice feature of CLAGEN is that it annotates the gene clusters by using information from the BLAST search. The CLUSE algorithm that we discussed earlier also uses a suffix tree, but uses it to find the conditional probability of a symbol given a sequence in a cluster.

# 16.5 Software Packages

Implementations of the well-known clustering algorithms for microarray, protein interaction and sequence data are available. We summarize some of the most popular ones that are currently being used.

The most popular tool for cluster analysis and visualization of microarray data is Cluster [33] which was developed by Michael Eisen. It contains some of the basic clustering algorithms such as k-means, hierarchical and self-organizing maps. TreeView is a software (associated with Cluster software) that provides a graphical user interface to browse the clustering results. Both of these work only in the Windows environment and can be downloaded from http://rana.1bl.gov/EisenSoftware.htm.

Michel Hoon of the University of Tokyo has created a version of Cluster (called Cluster 3.0) that implements the same algorithms for different purposes. Routines for hierarchical (pairwise simple, complete, average, and centroid clustering), k-means and k-medians clustering, and this can be downloaded from http://bonsai.jp/~dehoon/software/cluster/. Extensions of these modules to Perl and Python languages are also available.

Java Tree is a basic visualization software that can be used to view the original microarray data and also the clustering results [88]. This is an open source software which can be downloaded from http://sourceforge.net/projects/jtreeview/

EXCAVATOR (Expression Clustering Analysis and Visualization Resource) was developed by the Protein Information Group of Oak Ridge National Laboratory. It uses concepts from graph theory (such as minimum spanning trees) to represent gene expression data. In addition to providing distance measures for computing clusters, it contains many other additional features as automatic selection of the number of clusters, background noise removal, and identifying gene expression profiles that are similar to a specified set of seed genes.
