The approach in [48] works by modifying the soft $p(w|C_j)$ for word $w$ and cluster $C_j$. The probability $p(w|C_j)$ is modeled as a linear combination of two factors: (a) a maximum likelihood model which computes the probability of generating specific words for each cluster and (b) an indirect (translated) word-membership probability which first determines the maximum likelihood probability for each signature and then multiplies by the conditional probability of each word, given the topic signature. We note that we can use $p(w|C_j)$ in order to estimate $p(d|C_j)$ by using the constituent words in the document. For this purpose, we use the frequency $f(w,d)$ of word $w$ in document $d:

```
$p(d|C_j) = \prod_{w\in d} p(w|C_j)^{f(w,d)}$$

```

We note that in the static case, it is also possible to add a background cluster in order to improve the robustness of the estimation process. This is however, not possible in a data stream because of the fact that the background collection model may require multiple passes in order to build effectively. The work in [48] maintains these properties in online fashion with the use of a cluster profile that uses the properties of a fading function. We note that the cluster profile is analog to the concept of condensed droplet introduced in [12]. The key algorithm (OCTS) is to maintain a dynamic set of clusters into which documents are progressively assigned with the use of similarity computation. It has been shown in [48] how the cluster profile can be used efficiently compute $p(d|C_j)$ for each incoming document. This value is then used to determine the similarity to the different clusters and assign the documents to their closest cluster. We note that the methods in [12, share a number of similarities in terms of (a) maintenance of cluster profiles, (b) use of cluster profiles (or condensed droplets) to compute similarity and assignment of documents to most similar clusters, and (c) the rules used to decide when a new singleton cluster should be created or one of the older clusters should be replaced.

The main difference between the two algorithms is the technique which is used in order to compute cluster similarity. The OCTS algorithm uses the probabilistic computation $p(d|C_j)$ to compute cluster similarity, which takes the phas information into account during the computation process. One observation about OCTS is that it may allow for very similar clusters to coexist in the current set. This reduces the space for distinct clusters. A second algorithm OCTM is also proposed in [48], which allows for merging of very similar clusters. Before each assignment, it checks whether pairs of similar clusters can be merged on similarity. If so, then allow the merging of the clusters and their corresponding cluster profiles. Detailed experimental results on the different clustering algorithms and their effectiveness are presented in [48]. A comprehensive review of text clustering algorithms may be found in the chapters on data clustering and streaming algorithms in [15].
