# TABLE 23.1: External Cluster Validation Measures

| | Measure | Definition | Range |
|---|---|---||}{
| 1 | Entropy ($E$) | $-\sum p_i \log \frac{p_i}{h_i}$ | $[0, \log K]$ |
| 2 | Purity ($P$) | $\sum p_{ij} \max p_{ij}$ | $(0,1]$ |
| 3 | F-measure ($F$) | $\sum p_{ij} \frac{2p_{ij}/h_i \cdot h_j}{p_{ij}/h_i + p_{ij}/h_j}$ | $(0,1]$ |
| 4 | Variation of Information (VI) | $\sum p_i \log p_i - \sum p_{ij} \log p_i - 2\sum p_j \log p_j$ | $[0, 2\log K]$ |
| 5 | Mutual Information (MI) | $\sum p_{ij} \log \frac{p_{ij}}{p_i p_j}$ | $[0, \log K]$ |
| 6 | Rand statistic ($R$) | $(\sum p_{ij} - \sum p_i^2/2 - \sum p_j^2/2) / (1/22)$ | $[0,1]$ |
| 7 | Jaccard coefficient ($J$) | $\sum p_{ij} / (\sum p_i + \sum p_j - 2\sum p_{ij})$ | $(0,1]$ |
| 8 | Fowkes & Mallows index (FM) | $\sum p_{ij} / \sqrt{\sum p_i \sum p_j}$ | $(-1,1]$ |
| 9 | Hubert statistic ($I$) | $\sqrt{\sum p_i \sum p_j} \sum (2 - 2\sum p_{ij}) / \sum p_{ij}^2$ | $(-1,1]$ |
| 10 | Hubert statistic II ($II$) | $(2 - 2\sum p_{ij} - 2\sum p_j^2 + 4\sum p_{ij}^2) / (1/22)$ | $[0,1]$ |
| 11 | Minkowski score (MS) | $\sqrt{\sum p_i + \sum p_j - 2\sum p_{ij}} / \sqrt{\sum p_{ij}^2}$ | $(0,+\infty)$ |
| 12 | classification error (ce) | $1 - \max \sum p_{ij}$ | $[0,1]$ |
| 13 | van Dong criterion (VD) | $(2n - \sum n_i \max n_{ij} - \sum n_j \max n_{ij}) / 2n$ | $[0,1]$ |
| 14 | micro-average precision (MAP) | $\sum p_i (\max \frac{p_{ij}}{p_i})$ | $(0,1]$ |
| 15 | Goodman-Kruskal coefficient (GK) | $\sum p_i (1 - \max \frac{p_{ij}}{p_i})$ | $(0,1]$ |
| 16 | Mirrien metric (M) | $\sum p_i + \sum p_j - 2\sum p_{ij}$ | $[0,2]$

Note: $p_{ij} = n_{ij}/n$; $p_i = n_i/n$; $p_j = n_j/n$.

# 23.2.1 An Overview of Clustering Validation Measures

Table 23.1 shows the list of measures to be studied. The “Definition” column gives the computation of measures by using the notations in the contingency matrix. The 16 measures are briefly introduced.

Entropy and purity are frequently used external measures for $K$-means [54, 67]. They measure the “purity” of the clusters with the given class labels.

F-measure was originally designed for the evaluation of hierarchical clustering [48, 36], but has also been employed for partition clustering. It combines the precision and recall concepts from the information retrieval community.
