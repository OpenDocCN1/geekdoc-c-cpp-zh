We can interpret the mean $\mu_k$ for the $k$-th Gaussian component is obtained by taking a weighted mean of all the points in the data set, with the weighting factors corresponding to the posterior probability $\gamma(z_{nk})$ that component $k$ was responsible for generating $\mathbf{x}_n$. Similarly, we define the expectation of $\log p(\pi, \mu, \Sigma)$ with respect to $\Sigma_k$ to zero, and we obtain

```
$$\Sigma_k = \sum_{n=1}^N \gamma(z_{nk}) (\mathbf{x}_n - \mu_k)(\mathbf{x}_n - \mu_k)^T / \sum_{n=1}^N \gamma(z_{nk})$$$
```

Similar to (3.12), each data point is weighted by the conditional probability generated by the corresponding component and with the denominator by the effective number of points associated with the corresponding component.

The derivative of $\log p(\pi, \mu, \Sigma)$ with respect to the mixing probabilities $\pi_k$ requires a little more work, because the values of $\pi_k$ are constrained to be positive and sum to one. This can be handled using a Lagrange multiplier and maximizing the following quantity

```
$$\log p(\pi, \mu, \Sigma) + \lambda (\sum_{k=1}^K \pi_k - 1)$$$
```

After simplifying and rearranging we obtain

```
$$\pi_k = \frac{\sum_{n=1}^N \gamma(z_{nk})}{N}$$$
```

so that the mixing probabilities for the $k$-th component are generated by the average responsibility that the component takes explaining the data points.

It is worth noting that the Equations (3.12), (3.14), and (3.15) are not the closed-form solution for the parameters of the mixture model. The reason is that these equations are intimately coupled with Equation (3.13). Specifically, the responsibilities $\gamma(z_{nk})$ given by Equation (3.13) depend on all the parameters of the mixture model, while all the others of (3.12), (3.14), and (3.15) rely on $\gamma(z_{nk})$. Therefore, maximizing the likelihood function for a Gaussian mixture turns out to be a very complex problem. An elegant and powerful method for finding maximum likelihood solutions for models with latent variables is called the Expectation-Maximization EM algorithm

However the above equations suggest an iterative solution for the Gaussian mixture model, which turns out to be an instance of the EM algorithm for the particular case of Gaussian mixture model. Here we will give such an iterative algorithm in the context of Gaussian mixture model, and later give a general framework of EM in Section 3.3. This algorithm is started by initializing guesses about the parameters, including the means, covariances, and mixing probabilities. We alternate between two updating steps, the *expectation step* and *maximization step*. In the expectation step, we use the current parameters to calculate the responsibilities (i.e., posterior probabilities) according to (3.13). In the *maximization step*, we maximize the likelihood with the updated responsibilities, and reestimate the means, covariances, and mixing coefficients using (3.12), (3.14), and (3.15). In Section 3.5, we shall show that each iteration of the EM is guaranteed to increase the log-likelihood. In practice, the EM algorithm is converged when the change in the log-likelihood or the parameter values fall below some threshold.
