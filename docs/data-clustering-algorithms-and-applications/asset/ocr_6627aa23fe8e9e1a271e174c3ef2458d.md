The main point in COPAC, however, is a considerable speed-up by partitioning the data set based on the observation that a correlation cluster should consist of points exhibiting the same local dimensionality (i.e., the same number of strong eigenvectors in the variance matrix of the k nearest neighbors). Thus, the search for clusters involves only the points with equal correlation dimensionality. By creating one partition for each occurring correlation dimension, the time complexity decreases on average by getting rid of a squared factor $d^2$ in a d-dimensional data set.

Another related algorithm is ERIC [6], also deriving a eigensystem for a point based on the k nearest neighbors in Euclidean space. Here, the neighborhood criterion for linear dependency and the affine distance of the correlation hyperplane are defined by the strong eigenvectors of each point. In COPAC, the property of clusters to consist of points exhibiting equal local dimensionality is exploited for the sake of efficiency. Furthermore, the resulting set of clusters is also ordered hierarchically to provide the user with a hierarchy of subspace clusters. In finding and assigning complex patterns of intersecting clusters, COPAC is more conservative than ORCLUS and ACC.

The algorithm CAS [2, 1] is finding arbitrarily subspace clusters by the means of the Hough-transform [77, 44]. The Hough-transform was originally designed to map the points from a 2-dimensional data space (also called picture) of Euclidean coordinates (e.g., pixels of an image) into a parameter space. The parameter space represents all possible 1D lines in the 2D data space. In principle, each point of the data space is mapped to an infinite number of points in the parameter space which is not materialized as an infinite set but as a trigonometric function in the parameter space. Each function in the parameter space represents all lines in the picture space crossing the point in the data space. An intersection of two curves in the parameter space indicates a line through the corresponding points in the picture space.

The objective of a clustering algorithm is to find intersections of curves in the parameter space representing lines through many data objects. The key feature of the Hough-transform is that the distance of the points in the original space is not considered any more. Objects can be identified associated to a cluster name, even if they differ in the original feature space. As such, the Hough-transform is a promising candidate for developing a subspace analysis that does not require local assumption and, thus, enables a global subspace approach. CAS [2, 1] follows a grid-based approach to identify regions in the parameter space, successively adaptive-iding space and counting the functions intersecting each of the resulting hyperboxes. In a depth-first search, most paths in the search tree are searched. A hyperbox is divided along one axis if it contains enough points to allow for dense boxes. In a dense subspace is found, the algorithm is applied on the data set accounted for by the corresponding hyperbox projected onto the corresponding subspace. This recursive descent allows for finding lower-dimensional subspace clusters and implies a hierarchy of oriented subspaces. However, if there are no correlations in the original data space and, hence, no dense regions in the parameter space (but the hyperboxes remain dense to qualify as promising candidates), the complete search is enumerated resulting in worst case time complexity exponential in d. Probably, more sophisticated heuristic may make this promising idea more practical for really high-dimensional data.

The Hough-transform is an example of using a technique in analysis of high-dimensional data that was developed in the context of image analysis (hence for 2-dimensional data). Other examples are the use of image-filter techniques [35]. Occasionally, RANSAC [51] or other sampling techniques have been used [74, 73].
