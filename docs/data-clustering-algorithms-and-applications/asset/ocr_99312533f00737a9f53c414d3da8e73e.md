**Subspace Clustering.** Subspace clustering in a narrower sense pursues the goal of finding all clusters in all subspaces of the feature space. This goal obviously is deified to the bottom-up technique used by these approaches, based on some monotonic property of clusters allowing the application of the APRIORI search. However, the relationship between the definition of subspace clustering (find all clusters in all subspaces) and the subspace search (bottom-up, applying an APRIORI search) is historical and hence rather than essential. We consider the problem as guiding category, regardless of the approach. Nevertheless, the majority of approaches consists of some adaptation of the APRIORI search method.

The pioneer approach for finding all clusters in all subspaces called the “subspace clustering” for this specific task has been CLIQUE [14], using a grid-based clustering method. The data is partitioned by an axis-parallel grid into equi-sized units of width δ. Only units which contain at least τ points are considered dense. A cluster is defined as a maximal set of dense units. Since dense units satisfy the downward closure property, subspace clusters can be explored efficiently in a bottom-up way. With all 1-dimensional units, (k+1)-dimensional dense units are computed from the k-dimensional units in an APRIORI-like procedure. If a (k+1)-dimensional unit contains a projection onto a k-dimensional unit that is not dense, then the (k+1)-dimensional unit cannot be dense. Furthermore, a heuristic that is based on the minimum description length principle is introduced to discard units within less interesting subspaces (i.e., subspaces that contain only a small number of dense units). This way, the efficiency of the algorithm is enhanced but at the cost of incomplete results (i.e., possibly some true clusters are lost).

There are some variants of CLIQUE; let us consider three well-known examples. The method ENCLUS [34] also relies on a fixed grid for subspaces that potentially contain one or more clusters than than dense units. Three quality criteria for subspaces are introduced, one of them replaces the downward closure property. The generation of subspace clusters is similar to CLIQUE. Another variant of CLIQUE called MAFIA [111] uses an adaptive grid over overlapping windows of width δ as 1-dimensional units of the grid.

In summary, all grid-based methods use a simple but rather efficient cluster model. The shape of each resulting cluster corresponds to a polygon with axis-parallel lines in the corresponding subspace. Obviously, the accuracy and the efficiency of CLIQUE and its variants primarily depend on the granularity and the positioning of the grid. A higher grid granularity results in higher runtime-requirements but will likely produce more accurate results.
