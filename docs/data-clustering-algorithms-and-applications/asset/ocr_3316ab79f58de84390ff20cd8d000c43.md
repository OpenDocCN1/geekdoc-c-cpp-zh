# 4.2.3.2 Estimating the Number of Clusters

The problem of estimating the correct number of clusters (K) is one of the challenges for the K-means clustering. Several researchers have proposed new methods for addressing this challenge in the literature. We will briefly describe some of the most prominent methods.

+   1. Calinski-Harabasz Index [6]: The *Calinski–Harabasz* index is defined by Equation (4.5):

```
$CH(K) = \frac{B(K)/(K-1)}{W(K)/(N-K)}$
```

where N represents the number of data points. Number of clusters is chosen by maximizing the function in Equation (4.5). $B(K)$ and $W(K)$ are the between and within cluster sum of squares, respectively, with K clusters.

+   2. Gap Statistic [48]: In this method, B datasets with the same range values as the original data are produced. The within cluster sum of squares is calculated for each of them with a different number of clusters. $W_b^K(K)$ is the within cluster sum of squares for the bth dataset.

```
$Gap(K) = \frac{1}{B} \sum_{b=1}^{B} \log(W_b^K(K)) - \log(W(K))$
```

The number of clusters is the smallest value of K that satisfies Equation (4.7):

```
$Gap(K) \geq Gap(K+1) - S_{k+1}$
```

where $S_{k+1}$ represents the estimate of standard deviation of $\log(W_b^K(K))$.

+   3. Akaike Information Criterion (AIC) [52]: AIC has been developed by considering the likelihood and adding additional constraints of Minimum Description Length (MDL) to estimate the value of K. $M$ represents the dimensionality of the dataset. SSE (Equation 4.1) is the sum of squared errors for the cluster obtained using $K$-means uses an AIC given below.

```
$KMeans_{AIC} = \argmin_{K} [SSE(K) + 2MK]$
```

+   4. Bayesian Information Criterion (BIC) [39]: BIC serves as an asymptotic approximation to a transformation of the Bayesian posterior of a candidate model. Similar to AIC, the computation is also based on considering the logarithm of likelihood ($L$). N represents the number of data points. The value of $K$ that minimizes the BIC function will be used as the initial parameter for running the $K$-means clustering.

```
$BIC = \frac{-2+ln(L)}{N} + \frac{K\timesln(N)}{N} = 1\times ln(L^{K})$
```

+   5. Duda and Hart [11]: This is a method for estimation that involves the hierarchical clustering by choosing the cut-off level in the dendrogram. The methods that are typically used to cut a dendrogram are: (1) Cutting the dendrogram at a specified level of similarity where the threshold has been specified by the user. (2) Cutting the dendrogram where the gap between successive merges is the largest. (3) Stopping the process when the density of the cluster that results from the merging is below a certain threshold.
