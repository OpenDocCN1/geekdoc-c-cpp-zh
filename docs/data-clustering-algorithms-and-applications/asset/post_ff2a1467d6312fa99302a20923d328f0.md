## 14.2.3 Photo Album Recognition

Collection-level analysis of consumer photos has not drawn too much attention in the past. [7] and [8], the authors explored the relationship between collection-level annotation and image-level annotation with help of GPS and time information about the photos. Without using metadata, the authors of [18] proposed to describe images and videos with a set of 21 visual concepts. Then, in order to account for typical and nontypical photos within each album, they (partially) matched the photos from two albums when computing the Earth Mover's Distance (EMD) between them. The EMD is a robust distance metric which computes the minimum weighted distance among two image sets to weight-normalization constraints. It allows all pairwise distances between data points (album) and can alleviate the influence of outlier images. Assume there are $n_1$ and $n_2$ albums in $x_1$ and $x_2$, the EMD between them is a linear combination of ground distance $d(f_p^1, f_q^2)$ weighted by flow $f(f_p^1, f_q^2)$ between any two images:

$$D(x_1, x_2) = \frac{\sum_{p=1}^{n_1}\sum_{q=1}^{n_2} f_{pq}^1 d(f_p^1, f_q^2)}{\sum_{p=1}^{n_1} \sum_{q=1}^{n_2} f_{pq}^1} \quad (14.1)$$

where an optimal flow $f(f_p^1, f_q^2)$ is defined by the following linear program:

$$\min \sum_{p=1}^{n_1}\sum_{q=1}^{n_2} d(f_p^1, f_q^2)f_{pq}^1 \ns.t. \quad 1 \leq p \leq n_1, 1 \leq q \leq n_2, f(f_p^1, f_q^2) \geq 0, \ns. \sum_{q=1}^{n_2} f_{pq}^1 \leq w_p^1 \ns. \sum_{p=1}^{n_1} f_{pq}^1 \leq \min{\sum_{p=1}^{n_1} w_p^1, \sum_{q=1}^{n_2} w_q^2} \quad (14.2)$$

where $w_p^1$ and $w_q^2$ are the weights of images $f_p$ in albums $x_1$ and $x_2$, respectively. They are set $w_p^1=1/n_1, w_q^2=1/n_2$, and $d(f_p^1, f_q^2)$ takes the value of the Euclidean distance over score concepts. The interpretation of EMD is that a matching between images of two albums can be mapped to a unique flow described in Equation (14.2), and hence, even sets of $\{w_p^1\}$ and $\{w_q^2\}$ imply that all the images within the same album are "exactly matched". The last set of constraints in Equation (14.2) deals with the imbalance of photos in two albums. The final similarity metric at the album is $S(x_1,x_2)=\exp(-D(x_1,x_2)/r)$, where $r$ is the mean of all pairwise distances between all training data points. The next step is the spectral clustering using similarity matrix $S$. Let resulting clusters be $\{W_j\}$. The similarity between an album to a cluster $W_j$ is the maximum similarity between $x$ and the members in $W_j$:

$$S(x, W_j) = \max_{x \in W_j} S(x,x) \quad (14.3)$$

The final album representation is a Bag of Features containing similarities to each cluster $S(x,W_j)...S(x,W_j)^T$. The authors of [16] take a different approach. Instead of using mid-level detections, they detected frequent words within an album and then ranked them using the PageRank algorithm. A visual word is a combination of 12-dimensional RGB color descriptor and a 32-dimensional SIFT descriptor. The ranking of the word is proportional to the number of times it appears and the number of times it matches with another word in another photo. There are a few issues in the approaches described above. Low-level visual features can be enhanced by mid-level detection because they are technically closer to higher-level events. When using mid-level detection, it is clear that not all detections are relevant to the target event, and incorporating all of them can degrade performance because detection usually becomes noisy. Moreover, averaging all photos within an album mixes up typical and atypical images. In [31], the authors address these issues with frequent patterns in semantic events. Short detectors are more robust to noise compared to directly using all object detections as described in [8]. Ideally, an object can be "car, street light, person", which means that three objects "car," "street light," and "person" co-occur a lot in a certain event. In practice, detection is relative score and is not binary. However, actual object looks like "car, street light, desk", which means that a certain scene "car" has detection score at least 6, "street light" has at least 5, and "desk" has at most 2. Discrete issues are due to detection quantization, and such image-level detection classifier $f(I)=1$ if and only

$$m_i(I) \geq s_1 \wedge m_i(I) \geq s_2 \wedge m_i(I) \geq s_3 \dots s_1, s_2, s_3 \in \{0, 1\}; \quad (14.4)$$

where $m_k(I)$ is the detection of object $k$ for image $I$. $i$ is the object index, $s_j$ controls the interval (greater or less than), and $t_j$ is the threshold of the $j$-th object. Finally, the album level feature is formed by aggregating the output of $F_k(I)$ for all photos in the album.

## 14.2.4 Image Segmentation

In this section, we present semiautom image segmentation via graph cuts to minimize the energy function [5]. Users can manually label the pixels of some object in an image, and then graph cuts automatically segment the image into different objects corresponding to these labels. The graph cuts simultaneously measure the smoothness of the labeling and the agreement between pixels. More precisely, we are given a graph $G=(\mathcal{P},\mathcal{X})$, where $\mathcal{P}$ is the set of nodes corresponding to the pixels in an image, and $\mathcal{X}$ is the set of edges measuring similarity between the pixels based on their colors and locations. Then a labeling function $f$ assigns each pixel $p \in \mathcal{P}$ with a label $f_l$ in a finite set $\mathcal{L}$ of object labels. The goal here is to obtain a labeling function $f$ that minimizes the energy

$$E(f) = E_{smooth}(f) + E_{data}(f)$$

where, $E_{smooth}(f)$ measures the extent to which $f$ is not piecewise smooth, while $E_{data}(f)$ measures the disagreement between $f$ and the pixels.

In many cases, minimizing the energy function is NP-hard, and it is impossible to rapidly compute the global minimum unless P=NP. Therefore, the two algorithms, $\alpha$-expansion and $\alpha$-beta$-swap, focus on minimizing it by graph cuts to find a local minimum. Let $P=\{P_l|l\in L\}$ be partition of nodes given a labeling function $f$, where $P_l=\{p\in P|f(p)=l\}$ is a subset of nodes assigned with label $l$. Then we define $\alpha-\beta$-swap as follows:

- $\alpha$-expansion: Given a label $\alpha$, a move from a partition $P$ to a new $P'$ with $f'$ is called an $\alpha$-expansion, if $P_\alpha \subset P'_\alpha$ and $P'_l=P_l$, for any label $l\neq\alpha$.
- $\alpha$-beta$-swap: Given a pair of labels $\alpha$ and $\beta$, a move from a partition $P$ with $f$ to a new partition $P'$ with $f'$ is called an $\alpha-\beta$-swap, if $P_\alpha=P'_\beta$, for any label $l\neq\alpha,\beta$.

Given a labeling $f$, [15] finds an $\alpha$-beta$-swap or $\alpha$-reduction to reduce the energy defined above. Then the energy can be minimized by a variant of the “fastest descent” techniques. Thus, the key is to develop an algorithm to find the optimal swap and expansion given the current labeling $f$. ## 14.2.5 Large-Scale Image Classification

Before the 2000s, most research effort on image classification and clustering focused on medium-scale databases, where the features could fit into a disk's memory (typically 4GB-32GB). There are many reasons for such limitation on large-scale computer vision task: for, during early days, large-scale image classification databases were not available previously due to the expensive cost associated with labeling, and effective and efficient learning algorithms are critical for large-scale classification problems. In the year 2009, a new ontological dataset ImageNet was published by Deng et al. [12], which can be used for many applications based on image clustering, including object recognition, image classification, and automatic clustering.

If this database was publicly available, a significant amount of research has been conducted in these areas which has led to efficient and robust learning algorithms.
