# A Survey of Uncertain Data Clustering Algorithms

Let us assume that the data points that have arrived so far are $	ilde{X}_1 \dots 	ilde{X}_N$. Let $t_i$ be the current time.

+   - For each dimension, the weighted sums of squares of the individual dimensions of $	ilde{X}_1 \dots 	ilde{X}_N$ over the entire data stream are maintained. There are a total of $d$ such entries. The $i$th component of the global second-order statistics is denoted by $gs(i)$ and is equal to $\sum_{j=1}^i f(t_i - T_j)^2$.
- For each dimension, the individual dimensions of $	ilde{X}_1 \dots 	ilde{X}_N$ over the entire data stream are maintained. There are a total of $d$ such entries. The $i$th component of the global first-order statistics is denoted by $gf(i)$ and is equal to $\sum_{j=1}^i f(t_i - T_j) \cdot x_j^i$.
- The sum of the weights of the different values of $f(T)$ are maintained. This value is equal to $\sum_{j=1}^i f(t_i - T_j)$. This value is denoted by $gW$.

The above statistics can be easily updated over a stream since the values are computed additively over data points. At first, we state that the statistics would need to be updated at each clock tick. In reality, because of the multiplicative nature of the exponential distribution, we only need to update the statistics by the arrival of each new data point. When a new data point arrives at $t_i$, we multiply each statistics by $e^{-\lambda(t_i-T_i)}$ and add the statistics for the incoming data point $	ilde{X}_i$. We note that the global variance along a given dimension can be computed from the above values, the global variance can be maintained continuously over the entire data stream.

> **Observation 18.6.1** The variance along the $i$th dimension is given by $\frac{gs(i)}{gW} - \frac{gf(i)^2}{gW^2}$.

The above fact can be easily proved using the fact that for any random variable $Y$ the variance $var(Y)$ is given by $E[Y^2]-E[Y]^2$. We will denote the global standard deviation along dimension $i$ at time $t_i$, by $\sigma(i_i, t_i)$. As suggested by the observation, the value of $\sigma(i_i, t_i)$ is easy to maintain by using the global statistics discussed above.

An uncertain cluster $C=\{X_i \dots X_{iv}\}$ is represented as follows

**Definition 18.6.2** The uncertain cluster for a set of $d$-dimensional points $	ilde{X}_i \dots 	ilde{X}_{iv}$ with timestamps given by $T_i \dots T_{iv}$ and error vectors $\chi(	ilde{X}_i) \dots \chi(	ilde{X}_{iv})$ is defined as the $(3+d+3)$ cluster $ECF=(CF(2), EF(2), CF(1), t(C), W(C), n(C))$, and a $d$-dimensional vector $\mathcal{B}$, where the corresponding entries are defined as follows:

+   - For each of the $d$ dimensions, we maintain the weighted sum of squares of the data values in $CF(2)$. The $i$th entry is given by $\sum_{j=1}^i f(t-T_j) \cdot x_j^2$.
- For each of the $d$ dimensions, we maintain the weighted sum of squares of the entries (along the corresponding dimension) in $EF(2)$. The $i$th entry is given by $\sum_{j=1}^i f(t-T_j) \cdot \psi_p(X_j)^2$.
- For each of the $d$ dimensions, we maintain the weighted sum of the data values in $CF(1)$. The $i$th entry is given by $\sum_{j=1}^i f(t-T_j) \cdot x_j^i$.
- The sum of the weights is maintained in $W(C)$. This value is equal to $\sum_{j=1}^i f(t-T_j)$.
- The number of data points is maintained in $n(C)$.
- The last time at which a data point was added to the cluster is maintained in $t(C)$.

We also maintain a $d$-dimensional bit-vector $\mathcal{B}$. Each bit in this vector corresponds to the value of 1, if dimension is included in the projected cluster. Otherwise, the value of the bit is zero.
