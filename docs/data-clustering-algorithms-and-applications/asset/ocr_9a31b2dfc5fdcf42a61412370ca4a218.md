# 20.5.1 Nonlinear manifold Embedding

Manifold embedding methods obtain a lower dimensional representation of a given dataset that some suitable neighborhood structures are preserved. In this section we review three popular embedding methods and demonstrate that their semisvised generalizations solve a variant of the GL formulation.

Locally Linear Embedding (LLE): In LEE [32], the assumption is that each point in the high-dimensional space can be accurately approximated by a locally linear region. In particular, neighborhood densities are estimated by solving $\sum_i |f_i - \sum_j w_{ij}x_j|^2$, where $\sum_j w_{ij}=1$, $X_i$ is the set of neighboring points of $x_i$. Then $W$ is used to reconstruct the points in a lower dimensional space by solving:

```
$$\min_{f\in\mathbb{R}^n} ||f-\sum_j w_{ij}x_j||^2, \text{ s.t. f \perp \mathbf{1}, ||f||^2=n.$ (20.55)
```

$M = (I-W)^T(I-W)$, which is positive definite and can be viewed as an iterated Laplace operator [8], we can rewrite the objective function as

```
$$\min f^T M f, \text{ s.t. f \perp \mathbf{1}, ||f||^2=n.$ (20.56)
```

Laplacian Eigenmaps (LE): LE is based on the correspondence between the graph Laplacian and the Laplace Beltrami operator [8]. The symmetric weights between neighboring points are typically computed using the RBF kernel $w_{ij} = \exp(-||x_i-x_j||^2/\sigma^2)$. Then $W$ is used to reconstruct the points in a lower dimensional space by solving:

```
$$\min_{f\in\mathbb{R}^n} \sum_{i,j} w_{ij}(f_i-f_j)^2, \text{ s.t. f^T D f = 1.$$ (20.57)
```

Using (20.22), the objective function is $f^T L f$. Letting $g=D^{1/2}f$, with $M=L_s=D^{-1/2}LD^{-1/2}$ we can express the objective as

```
$$\min g^T M g, \text{ s.t. g \perp D^{1/2}, ||g||^2=1.$$ (20.58)
```

Local Tangent Space Alignment (LTSA): In LTSA, the tangent space at each point is approximated using local neighborhoods, and a global embedding is obtained by aligning the local tangent spaces. If $X_i^N$ denotes the matrix of neighbors of $x_i$, then it can be seen [44] that the principal components of $X_i^N$ give an approximation to the tangent space of the embedding $f_i$. Let $g_1,...,g_k$ be the $k$ principal components for $X_i^N$. Let $G_i = e/\sqrt{k}[g_1,...,g_k]^T$. If $H_i$ are the indices of the neighbors of $x_i$, submatrices of the alignment matrix $M$ are computed as $M(X_i^N, \mathcal{N}) \leftarrow M(X_i^N, \mathcal{N}) + I-G_IG_i^T$ for $i=1,...,n$. Finally, using $M$, which is guaranteed to be positive semidefinite, an embedding is successfully obtained by minimizing the alignment cost:

```
$$\min f^T M f, \text{ s.t. f \perp \mathbf{1}, ||f||^2=n.$$ (20.59)
```

We refer the reader to [44] for a detailed analysis of LTSA.

# 20.5.2 Semisvised Embedding

In this section, we consider two types of semisvised embedding and its relationship to graph-based clustering. The variants differ when they consider the constraints associated with the unsupervised embedding problem. As discussed in Section 20.5.1, there are typically two types of constraints: $f \perp A$, where $A=I$ or $D^{1/2}$, and $||f||^2=c$, a constant. Since the clustering is based on $(f_i)$, the norm constraint does not play any role and is ignored for our analysis.
