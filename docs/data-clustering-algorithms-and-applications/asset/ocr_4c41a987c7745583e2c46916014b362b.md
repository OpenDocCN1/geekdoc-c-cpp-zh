Clusters may also have multiple centers if the centers are strong density attractors and there exists a path above the noise threshold. By recursively partitioning the feature space into multidimensional, OptGrid creates an optimal grid-partition by constructing the cut hyperplanes of the space. These planes cut the space in areas of low density (i.c., local minima of the density function) and preserve regions of high density or clusters, specifically the cluster centers (i.c. maxima of the density function). The cutting hyperplanes are formed using a set of contracting projections of the feature space. The contracting projections create upper bounds for the density of the planes orthogonal to them. Namely, for any point, x, in a contracting projection, P, then for any point y that P(y) = x, the density of y is at the most of x.

To define the fine grid we precisely present the definitions offered in [12] as summarized in [10]. A cutting plane is a (d–1)-dimensional hyperplane consisting of all y that satisfy the equation $\sum_{i} w_iy_j=1$. The cutting planes partition R* into two halves. The decision function H(x) determines the half-space, where a point x \in R is located:

```
$H(x) = \begin{cases} 1 & \sum_{i} w_ix_i \geq 1, \ 0 & \text{otherwise.} \end{cases} \quad (6.5)$
```

Then, a multi-dimensional grid for the feature space S is defined to be a set $S=\{H_1,H_2,...,H_k\}$ of (d–1)-dimensional cutting planes. The coding function $c^G: S \to \mathbb{N}$ is defined as

```
$x \in S, c(x) = \sum_{i=1}^{k} 2^{H_i(x)}. \quad (6.6)$
```

OptGrid uses a density function to determine the best clusters and locations to them. The density function $f^D$ is defined as

```
$f^D = \frac{1}{nh} \sum_{i=1}^{n} KD(\frac{X-x_i}{h}), \quad (6.7)$
```

where $D$ is a set of $N$ d-dimensional points, $h$ is the smoothness level, and $KD$ is the kernel density estimator. Clusters are defined as the maxima of the density function, which are above clusters that are above a certain noise level $\xi$.

A center-based cluster for a maximum $x^*$ of the density function $f^D$ is the subset $C \subset D$, with $x \in C$ being density-attracted by $x^*$ and $f^D(x*) \geq \xi$. Points $x \in D$ are called outliers if they are density-attracted by a local maximum $x^*$ with $f^D(x^*) < \xi$.

OptGrid selects a set of contracting projections. The projections are used to find the optimal clusters. The projections are because they control the density of points, and the cutting planes, will have low density. Each cutting plane is selected to have minimal point and separate to two dense half spaces. After each step of constructing the function. The algorithm is then applied recursively to the clusters. In each round of recursion, OptGrid maintains only data objects in the density from the previous round of recursion. The algorithm OptGrid is described in Algorithm 33 [10, 12].

The time complexity of OptGrid is $O(N \log N)$, where $N$ is the number of data points and $d$ is the dimensionality of the data. This is very efficient for clustering large-dimensional databases. However, it may perform poorly in locating clusters embedded in a low-dimensional subspace of a high-dimensional database, its recursive method reduces the dimensions by every step [10]. In addition, it suffers sensitivity to parameter choice and does not efficiently handle grid sizes that exceed available memory [20].
