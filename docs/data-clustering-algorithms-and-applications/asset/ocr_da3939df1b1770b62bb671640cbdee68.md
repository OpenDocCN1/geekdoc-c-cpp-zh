# 15.4.2.3 Multidimensional LCSS

Vlachos et al. proposed multidimensional distance functions as an extension of LCSS for multidimensional time series. The method proved to be robust to noise, especially when compared to DTW and ERP [52]. LCSS does not depend on continuous mapping of the time series; thus, the approaches extend to find similar parts between the examined sequences. LCSS, in contrast to the Euclidean distance, does not account for unmatched elements and matches only the similar parts. It therefore allows trajectories to stretch in time. DTW and Euclidean distance try to match every element, they are more sensitive to outliers. In [52] when using the LCSS time series under comparison must the two-dimensional trajectories $T_1$ and $T_2$ of length $m$ and $n$, respectively, is computed as follows:

+   (a) $LCSS_{\delta}(T_1, T_2) = 0$, if $n=0$ or $m=0$

+   (b) $LCSS_{\delta}(T_1, T_2) = 1 + LCSS_{\delta}(HEAD(T_1), HEAD(T_2))$ if $|T_{1,n}-T_{2,n}| < \epsilon$ and $|T_{1,m}-T_{2,m}| < \epsilon$ and $|i-j| \le \delta$

+   (d) $\min(LCSS_{\delta}(HEAD(T_1), HEAD(T_2)), LCSS_{\delta}(T_1, HEAD(T_2)))$, otherwise

where $HEAD(T_i)$, $\delta$, and $\epsilon$ are defined in 15.4.1.4. Two-dimensional LCSS can be extended to $d$ dimensions.

# 15.4.2.4 Multidimensional Edit Distance

In 2005, Chen et al. proposed HDR, Edit Distance on Relevance, in order to address the problem of comparing noisy trajectories with accuracy and robustness, claiming that HDR is more robust than DTW, LCSS, ERP, and Euclidean distance [11]. HDR is defined as the number of insert, delete, or replace operations to convert a trajectory $T_1$ into another $T_2$. Specifically, applying the Edit Distance on sequences of real numbers, rather than strings as was originally proposed in [10] by Levenshtein, the authors define EDR as follows:

+   (a) EDR(T_1, T_2) = m$, if $n=0$

+   (b) EDR(T_1, T_2) = n$, if $m=0$

> $EDR(T_1, T_2) = \min(EDR(Rest(T_1), Rest(T_2)) + sc, EDR(Rest(T_1), T_2) + sc)$, $\text{otherwise}$

where $sc = 0$ if $T_1$ and $T_2$ match, and $sc = 1$ otherwise. $T_1$ and $T_2$ are supposed to be matched if the distance between them in all dimensions is below a threshold $\epsilon$, similarly to the way LCSS distance described in 15.4.1.1 and 15.4.2.3 defines matching. EDR manages to cope with noisy multivariate time series without being affected by outliers and to handle shifting in the time axis like ERP distance. In their experimental evaluation, Chen et al. prove their claims about the improvements of EDR over DTW, ERP, and LCSS when applied to noisy sequences.
