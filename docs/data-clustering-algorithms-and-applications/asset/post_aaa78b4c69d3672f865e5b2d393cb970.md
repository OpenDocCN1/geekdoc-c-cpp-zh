## 5.3 DENCLUE

DENCLUE [16] takes another approach to generalize the notion of density-based clusters, based on the concept of influence functions that mathematically model the influence of a data point in its neighborhood. The density at some point is estimated by the sum of the influence of all data points. A point is said to be density-attractive to a so-called density-attractor, if they are connected through a path of high-density points. An influence function should be symmetric, continuous, and differentiable, typical examples of influence functions are wave functions or Gaussian functions. The density at a point $x$ is computed as the sum of the influence of all data points at point $x$. Density-attractors are points that correspond to local maxima of the density function. A point $p$ is density-attractive to an attractor $q$ if $q$ can be reached from $p$ through a path of points that lie within a distance of $\epsilon$ from each other in the direction of the gradient. An arbitrary-shape cluster for a set of density-attractors $X$ is defined as the set of all points that are density-attractive to one of the density-attractors $x$ where the density at $x$ exceeds a threshold $\xi$. In addition, all pairs of density-attractors need to be connected to each other via paths of points whose density meets the same threshold.

More precisely, the influence of a data point $y\in F^d$ is defined as $f_B^y(x)$ defined in terms of $f_B(x)$. A simple example of an influence function is the Square Influence Function:

```
$f_B(x,y) = 1 \text{ if } d(x,y) \leq \xi,$
$0 \text{ otherwise.}$
```

Given a data set of points $D=\{x_1, ..., x_n\}\in F^d$, the density function is defined as $f_D^x(x) = \sum_{i=1}^n f_B(x_i)$. The gradient of the density function is defined as $\Delta f_D^x(x) = \sum_{i=1}^n (x_i - x)f_B(x_i)$. A point $x^*$ is a density-attractor, if $x^*$ is a local maximum of the density function or if there is a sequence of points $x^i, d(x^i, x^*) \leq \epsilon$ for some distance function $d$, with $x^*=x^{i-1} + \frac{\epsilon}{\|\Delta f_D^x(x^{i-1})\|}$.

Given a set of density-attractors $X$, an arbitrary-shape cluster with respect to $\sigma$ and $\xi$ is a subset $C \subseteq D$,

- 1. $\forall x\in C \exists x^*\in X: f_D^x(x) \geq \xi$ and $x$ is density-attractive to $x^*$,
- 2. $\forall x^*,x^*'\in X \exists p \in F^d$ from $x^*$ to $x^*$ with $\forall p\in P: f_D^p(p) \geq \xi$

The parameter $\sigma$, of the influence function, determines the reach of a point, while $\xi$ specifies when a density-attractor is identified. Note that the DENCLUE clusters become identical to the DBSCAN clusters when using the Square Influence Function with $\sigma=Eps$ and $\xi=MinPts$.

The efficient implementation of the DENCLUE algorithm is based on the observation that most data points do not contribute to the density function at any given point of the data space. This can be exploited by computing only a local density function, while guaranteeing tight error bounds. To efficiently access neighboring points, a so-called map structure is created, a d-dimensional grid of grid length $2\sigma$. Only grid cells that contain points are determined and are mapped to one-dimensional keys, which are indexed, e.g., in a $B^*$-tree. To determine the density-attractors for each point in a grid cell, a hill-climbing procedure based on the local density function and its gradient is used. After determining the density-attractor $x^*$ for a point $x$, the point $x$ is assigned to the cluster $x^*$. Some heuristics allow the algorithm to assign nearby points without having to apply the hill-climbing procedure.

## 5.4 OPTICS

In real-life databases the intrinsic cluster structure cannot be characterized by global density parameters, and very different densities may be needed to reveal clusters in different regions of the data space. In principle, one could apply a density-based clustering algorithm with different parameters, but there are infinite number of possible values. The basic idea of the OPTICS algorithm[3] to address this challenge is to create no explicit clustering, but to produce a cluster-ordering of the database points with respect to their density-based clustering containing information about every clustering of the data set up to guarantee a structure, $E_{ps}$. This ordering is visualized graphically to support interactive analysis of the cluster structure.

For a constant $E_{ps}$-value, density-based clusters with respect to a higher density (i.e., a lower value for $E_{ps}$) are completely contained in clusters with respect to a lower density (i.e., a higher value for $E_{ps}$). However, the DBSCAN algorithm could be extended to simultaneously cluster a database for all $E_{ps}$ values. Points which are density-reachable with respect to the lowest value would be processed first to guarantee that clusters with respect to higher density are finished first. OPTICS works in like an extended DBSCAN for an infinite number of distance parameters $E_{ps}$, which are smaller than a generating distance $E_{ps}$. The only difference is that it does not assign cluster memberships, but stores the order in which the points are processed (the clustering ordering) and the two pieces of information which would be used by an extended DBSCAN algorithm to assign cluster memberships. The core-distance of a point $p$ is the smallest distance $E_{ps}$ between $p$ and a point in its $E_{ps}$-neighborhood that $p$ would be a core point with respect to $E_{ps}$ if this is contained in $N(p)$. The reachability-distance of a point $p$ with respect to another $o$ is the smallest distance such that $p$ is directly-reachable from $o$ if $o$ is a core point.

## 5.5 Other Algorithms

The work of [31] introduces STING (Statistical Information Grid) to efficiently process queries. STING divides the data space into rectangular cells at different levels of resolution, and these cells form a tree. The following statistical information is calculated and stored for each cell: (1) the number of points in the cell and (2) for each attribute the mean, standard deviation, minimum value, and maximum value. While STING is more efficient than deterministic structures discussed above, its probabilistic nature implies a loss of accuracy in query processing. STING can provide efficient support for density-based clustering algorithms which employ region queries as basic operations. The runtime complexity of a region query is $O(K)$, where $K$ is the number of grid cells at the lowest level. $K \ll N$, where $N$ is the number of data points.

The restriction of k-means-like algorithms to find clusters can be traced back to the representation of a cluster by only one point. Density-based clustering algorithms, on the other hand, represent a cluster by the set of all its points, which enables them to discover arbitrary shapes. CURE (Using Representatives) (12) adopts a compromise, representing each cluster by a certain fixed number of points that are generated by selecting well-scattered points from the cluster and shrinking them to the center of the cluster by a certain fraction. Having more than one representative per cluster allows CURE to adapt to the geometry of nonserical shapes, and the shrinking helps to dampen the effects of outliers. In order to scale to large databases, CURE employs a method of random sampling and partitioning. First, a random sample from the data set is partitioned, and each partition is clustered. The partial clusters are merged to obtain the final clusters.

The clustering algorithm CHAMEON [21] also as the approach is not density-based, but is distance-based. CHAMEON is a hierarchical algorithm. The key idea is to consider both the inter-connectivity and closeness of clusters by analyzing the most similar pair of clusters. These two clusters are merged only if the inter-connectivity and closeness between the two clusters are comparable to the inter-connectivity of clusters and closeness within clusters. This is different from the CURE algorithm which ignores the information about the aggregate inter-connectivity of points in two clusters. CHAMEON finds the clusters in two phases. During the first phase, CHAMEON uses a graph partitioning algorithm to cluster the data items into several relatively small clusters. In the second phase, it creates clusters by applying hierarchical clustering to the subclusters from the first phase.
