# 2.2.2.2 Inverse Document Frequency (IDF)

TF is an effective selection method. However, it is not effective in term weighting, where all selected terms are assigned the same weight. We cannot link TF value to any document. In other words, we cannot distinguish between frequent words that appear in a small set of documents, which could have discriminative power for this set of documents, and frequent words that appear in all or most of the corpus. In order to scale the term's weight, we use, instead, the inverse document frequency (IDF). IDF measures whether the term is rare across all documents:

```
$idf(f_i) = \log \frac{|D|}{|D_i|}$ (2.9)
```

where $|D|$ is the total number of documents (i.e., sample size) and $|D_i|$ is the number of documents that contain the term $f_i$. The value of IDF will be high for rare terms and for low frequent ones.

# 2.2.2.3 Frequency-Inverse Document Frequency (TF-IDF)

We can combine the above mentioned measures (i.e., TF and IDF) to produce weight for each term $f_i$ in each document $d_j$. This is called TF-IDF. It is used when

```
$tf-idf(f_i, d_j) = tf_{ij} * idf_{f_i},$ (2.10)
```

tf-idf assigns greater values to terms that occur frequently in a small set of documents, thus having more discriminative power. The value gets lower when the term occurs in more documents, while the lowest value is given to terms that occur in all documents. In document clustering, terms that have higher tf-idf have a ability for better clustering.

# 2.2.2.4 Chi Square Statistic

Chi square ($\chi^2$) statistic has been widely used in supervised feature selection [71]. It measures the statistical difference between the feature and the class. $\chi^2$ with $r$ different values and $C$ classes is defined as

```
$$\chi^2 = \sum_{i=1}^{r} \sum_{j=1}^{C} \frac{(n_{ij} - \mu_{ij})^2}{\mu_{ij}},$
```

where $n_{ij}$ is the number of samples (i.e., documents) and $f^{th}$ feature value in the $f^{th}$ class is $\mu_{ij} = \frac{n_{ij}}{n}$ and $n$ is the total number of documents. This can be interpreted using the probability as

```
$$\chi^2(f,c) = \frac{n p(f,c)p(-f,-c)-p(f,-c)p(-f,c))^2}{p(f)p(-f)p(-c)p(c)}$ (2.11)
```
