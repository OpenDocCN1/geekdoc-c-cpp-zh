# Document Clustering: The Next Frontier

Hu et al. [51] combine original features with semantic features derived from external knowledge-bases to support the clustering task. Applying standard NLP techniques, they model the short input text into a parsing-like structure to support the extraction of redundant seed phrases, which they use to generate external semantic features. More specifically, a naive pau-segmentation of the text facilitates a shallow parsing pass which identifies seed phrases. To avoid redundancy, each phrase is compared with all the others in the segment, and the phrase with the highest Wikipedia-based similarity is removed. The remaining seed phrases are used to retrieve external text content, from either Wikipedia or WordNet, depending on the presence of words in the phrase. External features are extracted from titles and link text in the phrase. Document features are finally selected by tf-idf weights of original and external features. An additional parameter is introduced to control the concurrent use of multiple types of external features in the feature space. Hu et al. demonstrate the concurrent use of external knowledge bases, with internal semantics, to improve clustering of short texts.

# 13.5.3 Clustering Web Snippets

Document clustering research has traditionally focused on Web documents as a way to facilitate users' ability to quickly browse search results. Web documents could be clustered off-line, with a general purpose clustering algorithm. However, this approach ineffective [37, 16], because it is based on features that the entire collection is irrelevant to the particular query. Intent, query-specific, online, postretrieval clustering results, i.e., clustering search results, was shown to produce superior results [45]. A search result is generally composed of a title and a snippet, short often containing phrases from the document to the search query. As such, clustering results uses a subset of the collection concentrated around the query terms.

Unlike the clustering task, the primary focus of search result clustering is not to produce optimal clusters [109, 16, 5]. Rather, search result clustering is a highly user-centric task as users are unwilling to wait longer than a few seconds for search results. Clusters must exhibit identifying query subsets or facets from the user perspective. Finally, clusters must be assigned informative, meaningful and concise labels.

Scatter-Gamer [82, 45] is an early cluster-based browsing method that addressed the speed requirement by postretrieval clustering on top-ranked documents returned from a traditional information retrieval system. Zamir and Etzioni demonstrated the well-known Suffix Tree Clustering (STS) [118] algorithm, which creates intuitive clusters based on phrases shared between documents. It follows the assumption that retrieved phrases imply topics of interest within the search result. STS treats a phrase as a string of words, builds a suffix tree or traverses the tree to base clusters. The algorithm then uses a similarity measure based on overlap of documents to create a base cluster. In this graph, each node represents a group of snippets sharing a phrase. The final solution is obtained by finding the connected components in the graph. Zamir and Etzioni also showed that using snippets for clustering is as effective as using documents.

Addressing the meaningful and concise label research of search result clustering, Anastasi et al. [5] employ a strategy that generates labels for clusters. They first identify phrases within a set of search results using a suffix tree in linear time by Ukkonen's algorithm [106]. Then they select labels from the frequent phrases using a greedy set heuristic, where at each step a phrase covering the most uncovered search results is selected until the whole cluster is covered or no further phrases remain.
