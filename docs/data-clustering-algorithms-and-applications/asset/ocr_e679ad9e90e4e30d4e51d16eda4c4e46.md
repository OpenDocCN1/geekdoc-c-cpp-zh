# 6.5.2.2 MAFIA: Adaptive Grids in High Dimensions

MAFIA (Merging of Adaptive Infinities) proposed by Nagesh et [21] is a descendant of CLIQUE. Instead of using a fixed size cell grid with an equal number of bins in dimension, MAFIA constructs adaptive grids to improve subspace clustering and also uses parallelism on a shared-nothing architecture to handle massive data sets. MAFIA proposes adaptive grids of bins in each dimension. Using an Apriori algorithm, density intervals are merged to create clusters in the higher dimensional space. The adaptive grid is constructed by partitioning each dimension independently based on the distribution (i.e., the histogram) observed in dimension, merging intervals that have the same distribution, and pruning those with low density. This pruning during the construction of the adaptive grid reduces the overall cost of the clustering step. The steps of MAFIA are summarized in [3] in Algorithm 32.

# Algorithm 32 MAFIA Algorithm

+   1: Do scan of the data to construct adaptive grids in dimension reading blocks of data into memory bins.
2: Compute the histograms
3: Use the histograms to merge bins into a smaller number of adaptive variable-size bins, adjacent bins with similar histogram values. The bins that have low density are pruned.
4: Select bins that are alpha-types ($\alpha$ is a parameter called the cluster dominance factor) more densely populated than average $p$ ($p=1$ CDUs),
5: Iteratively scan for higher dimensions, construct new p-CDUs from two $(p-1)$-CDUs if they share $(p-2)$-face, and merge adjacent CDUs into clusters.
6: Generate minimal D expressions for each cluster.

If $p$ is the dimensionality of a candidate set (CDU), $N$ is the number of points, and $m$ is a constant, the algorithm's complexity is $O(m^p+pN)$, still exponential in the dimension as CLIQUE also is. However, the performance results on real data show that MAFIA is 40 to 50 times faster than CLIQUE because of the adaptive grids and their ability to select a smaller set of clustering CDUs [6]. Parallel MAFIA further offers the ability to obtain a highly scalable clustering for large data. Since the adaptive grids permit not only variable resolution of the bin size, but also variable, adaptive grid boundaries, MAFIA yields with greater accuracy cluster boundaries that are very close to grid boundaries and are readily expressed as minimal D expressions.
