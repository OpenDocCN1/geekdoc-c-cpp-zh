
# Clustering High-Dimensional Data

Clustering of clusters is defined by the number of intersecting points. The resulting clusters represent hyper-rectangular approximations of the true subspace clusters. An optional postprocessing step, these approximations can be refined by any clustering algorithm to the points included in the projection onto the corresponding subspace. Though using a bottom-up search strategy, FIRES is rather efficient because it does not employ a worst-case exhaustive search procedure heuristic that is scaling polynom in the dimensionality of the data space. However, the user can expect to pay for this performance boost by a loss of clustering accuracy. It cannot be specified whether the clusters produced by FIRES may overlap or not, this partly depends on the clustering algorithms used in the intermediate steps of the framework. In general, the clusters may overlap usually FIRES will not produce all clusters in all subspaces.

P3C [102, 103] starts with 1-dimensional clusters that are likely to approximate dimensional subspace clusters. These clusters are merged via APRIORI-like bottom-up search strategy. The maximal-dimensional cluster approximations resulting from this merging procedure are so-called cluster cores. In a refinement step, the clusters are refined by using an EM-like clustering procedure. Each cluster is taken as initial cluster for the EM algorithm. Points are assigned to the cluster core using the Mahalanobis distance. The final output of P3C is a matrix that records for each data point its probability of belonging to each projected cluster. From this matrix, a disjoint partitioning of the data points into clusters can be obtained by assigning each point to the cluster with the highest probability. If overlapping clusters are allowed, each point can be assigned to clusters with a probability larger than 1/k. P3C does not produce all clusters in subspaces as APRIORI-style algorithm does but reports the results of the final cluster computation using EM.

Moiser and Sander [101] provided a first attempt to recover significant subspace clusters as an optimization problem. In addition, the authors proposed an iterative algorithm STATPC to search locally optimized solutions for this optimization problem.

Interesting recent developments combine techniques from ensemble clustering [58] with ideas from subspace clustering, resulting in "subspace clustering ensembles" [41] or "projective clustering ensembles" [64, 63, 62].

## 9.4.2 Clustering in Arbitrary Oriented Subspaces

### 9.4.2.1 Cluster Model

A model for correlation clusters, i.e., clusters residing in arbitrary-oriented subspaces, can be based on a linear equation system describing the $\lambda$-dimensional hyperplane accommodating the points of a correlation cluster $C \in \mathbb{R}^d$. This equation system will consist of $d - \lambda$ equations for the points and the affinity, each given by the mean point $x_c = (x_i \cdot x_c)$ of all cluster members:

$$v_{1(\lambda+1)} \cdot (x_1 - x_c) + v_2 \cdot (x_2 - x_c) + \dots + v_{\lambda+1} \cdot (x_{\lambda+1} - x_c) = 0$$
$$v_1 \cdot (x_1 - x_c) + v_2 \cdot (x_2 - x_c) + \dots + v_d \cdot (x_d - x_c) = 0 \ (9.5)$$

where $v_{ij}$ is the value at row $i$, column $j$ in the eigenvector matrix $V_C$ derived (e.g., by principal component analysis (PCA) [83]) from the covariance matrix of $C$. The first $\lambda$ eigenvectors (also called strong eigenvectors) give the directions of high variance and span the hyperplane accommodating C. The remaining $d - \lambda$ weak eigenvectors represent the perpendicular subspace. The corresponding linear equation system can also be given by:

$$\hat{V}_C^c \cdot x = \hat{V}_C^c \cdot x_c \ (9.6)$$

The defect of $V_C^T$ gives the number of free attributes, the remaining may be involved in linear dependencies. The equation system is by construction at least fully filled for all points $x \in C$ and hence provides an quantitative model for the cluster [5]. The degree of allowed deviation of clusters from the hyperplane and the method of assessment differs from approach to approach. Hence, also in the area of arbitrarily-clustered, future research should consider refined and more complex models.

## 9.4.2.2 Basic Techniques and Example Algorithms

Basic techniques to find oriented subspaces accommodating clusters are principle component analysis (PCA) and the Hough-transform. The first approach to this generalized clustering algorithm ORCLUS [13], using ideas similar to the axis-parallel approach PROCLUS [12]. ORCLUS is a $k$-means-like approach, picking $k_c > k$ as it starts, assigning the data objects to these seeds according to a distance function that is based on an eigenystem of the corresponding cluster subspace (i.e., the distance in the projected subspace where the cluster objects exhibit high density). The eigenystem is iteratively adapted to the current state of the updated cluster. The number $k_c$ of clusters is reduced iteratively by merging pairs until the user-specified $k$ is reached. The closest pair of clusters is the pair with the least average distance in the projected space (span by the weak eigenvectors) of the merged clusters. Starting with a larger value for the parameter $k_c$ increases the effectiveness, but also the runtime.

In contrast to ORCLUS, the algorithm [32] is based on a density-based clustering paradigm [48]. Thus, the number of clusters is not decided before clusters grow from a seed as the density criterion is fulfilled. Otherwise, another seed is picked to start a new cluster. The density criterion is a required minimal number points within the neighborhood of a point, where the neighborhood is based on distance metrics computed from eigenystems of the $\varepsilon$-neighborhood of $p$ in Euclidean space. A parameter $\delta$ discards the range of small eigenvalues in eigenvalue matrix $E_p$; then large eigenvalues are replaced by 1 and small values by $\lambda \gg 1$. The adapted eigenvalue matrix $E'_p$, a similarity matrix for $p$ is obtained by $V_p, E'_p$. This matrix is then used to derive the distance of two points, $q$ and $p$, as general form:

$$\sqrt{(p-q)^T \cdot E'_p \cdot (p-q)} \quad (9.7)$$

By measuring this symmetrically to $q$ helps decide whether points are connected by correlation of attributes and, thus, are similar to each other. Regarding the choice of parameters, suffers from similar problems as PreCon, from the hard to guess neighborhood size that it is used in Euclidean space (recall the curse of dimensionality). As a hierarchical approach, HICO [8] defines the distance between points according to their local dimensionality and subspace orientation and use hierarchical-density-based clustering [16] to derive a hierarchy of clusters. COPAC [7] is based on ideas similar to ORCLUS but suffers of some problems as meaningless matrices due to $\varepsilon$-neighborhoods. Instead of problematic $\varepsilon$-range queries, COPAC is using a fixed number $k$ for the computation of local characteristics. However, choosing $k \gg \lambda$ ensures a meaningful definition of $\lambda$-dimensional hyperplane. In COPAC that choosing the neighborhood is the number of points rather than their distance, the main point, however, is a considerable speed-up by partitioning the data set based on the observation that a correlation cluster should consist of points exhibiting the same local dimensionality (i.e., the same number of strong eigenvectors). Thus, the search for clusters involves only the points with equal dimensionality. By creating one partition for each occurring dimension, the time complexity decreases on average by getting rid of factor $d^2$.

The objective of a clustering algorithm is to find intersections of curves in the parameter space representing lines through many data objects. The key feature of the Hough-transform is that the distance of the points in the original space is not considered any more. Objects can be identified associated to a cluster name, even if they differ in the original feature space. As such, the Hough-transform is a promising candidate for developing a subspace analysis that does not require local assumption and, thus, enables a global subspace approach.

The algorithm CAS [2, 1] follows a grid-based approach to identify regions in the parameter space, successively adaptive-iding space and counting the functions intersecting each of the resulting hyperboxes. In a depth-first search, most paths in the search tree are searched. A hyperbox is divided along one axis if it contains enough points to allow for dense boxes. In a dense subspace is found, the algorithm is applied on the data set accounted for by the corresponding hyperbox projected onto the corresponding subspace. This recursive descent allows for finding lower-dimensional subspace clusters and implies a hierarchy of oriented subspaces. However, if there are no correlations in the original data space and, hence, no dense regions in the parameter space (but the hyperboxes remain dense to qualify as promising candidates), the complete search is enumerated resulting in worst case time complexity exponential in d. Probably, more sophisticated heuristic may make this promising idea more practical for really high-dimensional data.

Another related algorithm is ERIC [6], also deriving eigensystem for a point based on the k nearest neighbors in Euclidean space. Here, the neighborhood criterion for linear dependency and the affine distance of the hyperplane are defined by strong eigenvectors of each point. In COPAC, the property of clusters to consist of points exhibiting equal dimensionality is exploited for the sake of efficiency. Furthermore, the resulting set of clusters is also ordered hierarchically to provide the user with a hierarchy of subspace clusters. In finding and assigning complex patterns of intersecting clusters, COPAC is more conservative than ORCLUS and ACC.

Some similar methods based on PCA can be found to adapt similarities in such way, and can also be seen as variants of EM-clustering [40] employing the clustering paradigm. A general framework has been proposed to increase the robustness of PCA-based correlation clustering algorithms [89].

The Hough-transform is an example of using a technique in analysis of high-dimensional data that was developed in the context of image analysis (hence for 2-dimensional data). Other examples are the use of image-filter techniques [35]. Occasionally, RANSAC [51] or other sampling techniques have been used [74, 73]. The Hough-transform was originally designed to map the points from a two-dimensional data space (also called picture) of Euclidean coordinates (e.g., pixels of an image) into a parameter space. The parameter space represents all possible 1D lines in the 2D data space. In principle, each point of the data space is mapped to an infinite number of points in the parameter space which is not materialized as an infinite set but as a trigonometric function in the parameter space. Each function in the parameter space represents all lines in the picture space crossing the point in the data space. An intersection of two curves in the parameter space indicates a line through the corresponding points in the picture space.
