
## 16.4.2.3 Probabilistic Models

The probabilistic approach is popular for sequence modeling. For instance, the earliest approaches for modeling protein families use profile-HMM, a hidden Markov model-based probabilistic approach. However, the main objective of protein-HMM is to perform multiple sequence alignment. Since then, several methods have been proposed to use HMM for sequence clustering. We discuss a few of them.

Smith's work [99] is one of the first that uses HMM for clustering biological sequences. His method has two steps: the first step divides a pairwise distance between observed sequences by computing a symmetrized similarity. This similarity is obtained by training an HMM for each sequence, so that the log-likelihood (LL) of each model can be computed. This information is used to build an LL matrix which is then used to cluster the sequences into k groups, using a hierarchical algorithm. In the second step, an HMM is trained for each cluster; the resulting models are merged into a composite HMM, where each HMM is used to design a disjoint part of this composite model. This initial estimate is then refined using the Baum-Welch procedure. As a result, a global HMM modeling of all the sequences is obtained. The number of clusters (k) is selected using a cluster method.

CLUSEG [116] uses conditional probability distribution (CPD) for characterizing a cluster, i.e., for different clusters the CPD of the next symbol being present is different, and the CPD can be used for clustering sequences. CLUSEG uses a new data structure, called a probabilistic tree (PST); every node in PST is a probability vector to store the probability distribution of the next symbol by the preceding segment. Usages of PST CLUSEG are very efficient. In the following paragraphs, we describe CLUSEG in detail.

The CLUSEG algorithm accepts a user-defined threshold parameters. At the beginning, all sequences in the database are clustered. Then, an iterative process is employed to continuously improve the quality of the clustering until no improvement can be made. In each iteration, CLUSEG starts with a new set of clusters; a few random from the unclustered set are chosen to cluster themselves. Then, it examines each sequence to evaluate its similarity to each of the clusters and chooses the cluster membership of that sequence, if their membership overlaps significantly. The key part of CLUSEG is the step which computes the similarity of a sequence to a cluster. For this, CLUSEG uses CPD of symbols for a given segment. Efficient computation of CPD, where the sequences in a cluster are stored in a probabilistic tree. If S is a cluster and $\sigma = s_1,s_2...s_n$, its similarity, likelihood to be a member of the cluster S is given by $P(\sigma|S) = p(s_1|S) \times p(s_2|s_1) \times \dots \times p(s_n|s_1...s_{n-1})$, which is the probability that $s_n$ is the next symbol after the segment $s_1...s_{n-1}$ in the sequence S. ## 16.4.2.4 Suffix Tree and Suffix Array-Based Method

For fast processing of sequence similarity, efficient data structures that index sequence pairwise segments are also proposed. The main objective of using a data structure is to avoid the pairwise similarity computation, which is infeasible for many clustering tasks because of its quadratic complexity. For example, databases of ESTs sometimes contain millions of ESTs and efficient data structure is crucial for clustering those sequences.

In [72], the authors use suffix arrays to cluster ESTs; suffix arrays are particularly suitable because ESTs are short subsequences of cDNA. To identify all blocks of length k, this method first adds all into a suffix array. It then sorts the suffixes and groups the suffixes that have a k-length prefix. Then, for each pair of suffixes having at least one matching block, it finds the largest matching blocks and the corresponding score. By starting with the highest scoring sequence pair, it builds hierarchical clusters using single-link clustering. In [47], the authors propose a clustering tool called CLAGEN, which uses a suffix tree for sequence clustering. CLAGEN constructs a suffix tree from the input sequences; this construction is highly efficient with only time complexity. Then, CLAGEN uses the suffix tree for searching and overlapping so that it can obtain sequence pairs that are highly similar. From the similarity information, CLAGEN finds clusters. A nice feature of CLAGEN is that it annotates the gene clusters by using information from BLAST search. The CLUSEG algorithm we discussed earlier also uses a suffix tree, but uses it to find the conditional probability of a symbol given a sequence in a cluster. ## 16.5 Software Packages

Implementations of well-known clustering algorithms for microarray, protein interaction and sequence data are available. We summarize some of the most popular ones that are currently used.

The most popular tool for cluster analysis and visualization of microarray data is Cluster [33] which was developed by Michael Eisen. It contains some of the basic clustering algorithms such as k-means, hierarchical and self-organizing maps. TreeView is a software (associated with Cluster) that provides a graphical interface to browse clustering results. Both of these work only in the Windows environment and can be downloaded from http://rana.cluster.gov/.

Michael Hoon of the University of Tokyo has created a version of Cluster (called Cluster3.0) that implements the same algorithms for different purposes. Routines for hierarchical (pairwise, complete, average, and centroid clustering), k-means and k-medians clustering, this can be downloaded from http://bonsai.jp/~hoon/cluster/. Extensions of these modules to Perl and Python languages are also available. Java TreeView is a basic visualization software that can be used to view the original microarray data and also clustering results [88]. It is open source software which can be downloaded from http://sourceforge.net/projects/treeview/.

EXCAVATOR (Expression Clustering Analysis and Visualization Resource) was developed by the Information Group of Oak Ridge Laboratory. It uses concepts from graph theory (such as minimum spanning trees) to represent gene expression data. In addition to providing distance measures, it contains many other features as automatic selection of clusters, background noise removal, and identifying gene expression profiles that are similar to a specified set of genes. This software is available at http://digbio.missouri.edu/software/Excavator/index.html.

EMMIX-GENE (available at http://maths.uk.edu/~ajm/emmix-gene/) is a software for mixture model-based clustering for gene expression data.

EXPANDER (Expression Analyzer and Display) is a gene expression analysis and visualization tool that can utilize several clustering methods as k-means, hierarchical clustering, and self-organizing maps, and it enables visualizing the gene expression data and clusters [94]. It is a Java-based tool which can be downloaded from http://agct.cs.tau.ac.il/expender/.

Pvclust is an R package that can be used to assess the uncertainty in hierarchical cluster analysis. It calculates p-values for each cluster using bootstrap technique [102]. It can be downloaded from http://www.bioconductor.org/pvclust/.

Genesis is a java-based, platform-independent tool for simultaneously analyzing and visualizing gene expression datasets. Several popular clustering methods as hierarchical clustering, self-organizing maps, and k-means clustering [101]. It can be downloaded from http://genome.cluster.at/genesiclist/genesiclist/download.shtml.

WCLUTO (available at http://cluster.de/~um_home/wcluto/overview/) is a web-based data-clustering application designed for the data-analysis requirements of gene-expression analysis. CLUTO is built on top of several clustering methods, performs the analysis on the server, and visualizes the final results.

A synthetic generator for gene expression data is available at http://www.cluster.edu/~ExPatGen/. Such a simulator can generate hypothetical expression patterns that can be used to evaluate and compare different clustering methods.

A popular tool that implements multiple clustering algorithms (such as CC, ISA, and OSM) is the Expression Analysis Toolbox (BiCluster) which is available at http://www.bioconductor.org/biocluster. BiCluster is a Java-based software that provides a nice graphical interface for analyzing gene expression data [122].

Tricicluster [123] is the first clustering algorithm for microarray experiments across the gene-sample slices, and then extends it into clusters across time dimensions. This software can be downloaded from http://www.cs.ri.edu/~zaki/software/Tricicluster.tar.gz.

STEM (Short Time-series Expression Map) is a Java program for clustering, comparing, and visualizing short time-series gene-expression data from microarray experiments. It can be downloaded from http://www.cs.umass.edu/~jems/stem/.

clusterMarker [74] provides a unified platform for traditional clustering and network clustering techniques. It is available at http://www.glucssf.edu/cytoscape/cluster/clusterMarker.html. All of the network clustering algorithms create collapsible "meta nodes" to allow interactive exploration. These clustering algorithms have been developed as a plugin for Cytoscape.

Cytoscape is an open source bioinformatics platform for visualizing complex molecular interaction networks. It is available at http://www.cytoscape.org/.

Cfinder is a free software for clustering and visualizing dense groups of nodes in networks, based on the Clique Percolation Method (CPM). It is a fast algorithm for locating and visualizing, densely connected groups of nodes in undirected graphs, and allowing the user to easily navigate between the original graph and the web of these groups. Software is available at http://www.cfinder.org/.

The code for Markov clustering is available at http://www.micans.org/mcl/. It provides a collection of network analysis tools focused on analysis of large networks, scaling up to thousands of nodes and millions of edges. The software MCODE algorithm [9] is available in the form of a Cytoscape plugin at http://baderlab.org/Software/MCODE. The network analysis tools (NeAt) provide a user-friendly web interface to a collection of modular tools for the analysis of networks (graphs) and clusters.
