## 20.4.5 Related Methods

We review three other methods from the literature, vic, cluster kernels, Gaussian random walks, and local neighborhood propagation for graph-based semisimple learning which are closely related to the GL framework.

### 20.4.5.1 Cluster Kernel

The main idea in cluster kernels (CK) [16] is to embed the data into a lower dimensional space based on its structure and subsequently be supervised learning on the lower-dimensional data. If $K$ denotes a suitable kernel on the data space, the embedding method focuses on the $k$ primary eigenvectors of the symmetric matrix $D^{-1/2}KD^{-1/2}$. If $K$ represents the edge weights on the graph $G=(V,E)$ between the points, i.e., $K=W$, then the embedding corresponds to the $k$ eigenvectors of the symmetric Laplacian $L=I-D^{-1/2}WD^{-1/2}$ corresponding to the smallest eigenvalues. In particular, for $k=1$, the embedding is given by the eigenvector corresponding to the smallest eigenvalue of $L_c$ which is used in LHC in absence of supervision. CK trains a semisimple learning on the lower-dimensional embedding to obtain the final label assignments.

### 20.4.5.2 Gaussian Random Walks EM (GWEM)

Consider a random walk on the graph with transition probability $P=D^{-1}W$. The GWEM method [35] works with the $m$-step transition matrix $P^m$ so that the probability of going from $x_i$ to $x_j$ is $p_m(x_j|x_i)=(P^m)_{ij}$. The random walk is assumed to start with uniform probability from any of the nodes. Using Bayes rule, one can obtain the posterior probabilities $P_0(y_i|x_j)$. Each point is assumed to have a (possibly unknown) distribution $p(y_i|x_i)$ over the cluster labels. The cluster label is based on $y_i=\text{argmax},P(y_j=c(x_j))$. Now, since $P(y_i|x_i)$ is unknown for the unlabeled points, an EM algorithm can be used to alternately maximize the post-probability of known labels over the labeled points

```
$\sum \log P(y_i|x_k)=\sum_{k=1}^N \log P(y_i|x_k)P_0(x_i|x_k). \quad (20.49)$
```

As shown in [35], the EM alternates between the E-step which estimates $P(x_i|x_k,y_k) \infty P(y_k|x_i)P_{0j}(x_i|x_k)$, where $k$ denotes an index over labeled points, and the $M$-step, computes

```
$P(y=c|x_i) = \frac{\sum_{h=1}^n P(x_i|x_h,y_k)}{\sum_{h=1}^n P(x_i|x_h,y_h)} \quad (20.50)$
```

We now show GWEM can be interpreted in terms of spectral decomposition of a suitable asymmetrically normalized Laplacian $L$ as as in Equation 20.23. For a fixed number of steps $m$ for the random walk, let $Z^t = P^m = (D^{-1}W)^m$. Note that $Z^T$ is a transition matrix, and $Z_{ij} = P_{mj}(x_i|x_j)$. Let $D_Z$ be the diagonal matrix such that $D_{ii}=\sum_j Z_{ij}$. Since the prior probability $P(x_i)=1/n$, by Bayes rule we have

```
$P_{mj}(x_i|x_j) = \frac{P_{m}(x_i|x_j)}{\sum_h P_{m}(x_i|x_h)} = (D_Z^{-1}Z)_{ij} \quad (20.51)$
```

Let $f_j = P(y_j|x_j)$. When the EM converges we have

```
$f = D_Z^{-1}Zf \Rightarrow (I - D_Z^{-1}Z)f = 0 \quad (20.52)$
```

where $f_j = y_j$ for the points. Since $D_Z^{-1}Z$ is a transition matrix, from Equation 20.23 we note that $(I - D_Z^{-1}Z)$ can be viewed as asymmetrically normalized Laplacian $L_0$ so that $L_0f = 0$. Finally, since $D_Zf$ represents the fixed point for $f$, a decomposition as in Equation 20.44 yields $f_i = (D_{ii}-L_{ii})y_i$.

### 20.4.3 Linear Neighborhood Propagation

Linear Neighborhood Propagation (LNP) [40] is another approach, which differs from the other methods as LNP computes a stochastic matrix $U$ directly from the data. In particular, it computes a probability distribution over neighbors so that their expectation best approximates the point: $\min_{u_i} ||x_i - U^Tu_i|^2$, where $u_i$ is probability distribution over the neighbors of $x_i$ and $U$ is a matrix whose columns are neighbor of $x_i$. Once the transition probability matrix $U$ is computed, the unsupervised learning problem posed as:

```
$\min_{f \in \mathbb{R}^n} \sum_{i,j=1}^n u_{ij}(f_i - f_j)^2 + \mu \sum_{i=1}^n (f_i - y_i)^2 \quad (20.53)$
```

where, similar to LGC [45], $y_i, i=1, \dots, \ell$ are set to their true values, and the unknown $y_i, i=\ell+1, \dots, n$ are set to 0. Similar to LGC, the LNP problem is solved by an iterative algorithm. Starting from an initial guess $f^{(0)}$, the iterative algorithm is posed with the following:

```
$f^{(t+1)} = \alpha Uf^{(t)} + (1 - \alpha)y \quad (20.54)$
```

where $\alpha = 1/(1+\mu) \in (0,1)$. The updates are the same as in Equation 20.47 for LGC [45] with the difference $U$ is not normalized symmetrically, but is a transition matrix of a random walk. In spite of the similarities, a careful consideration of the analysis in [40] reveals that the update does not solve the problem in Equation 20.53. On convergence, the iterative updates in Equation 20.54 leads to $f = (I-\alpha U)^{-1}(1-\alpha)y$. On the other hand, derivatives of Equation 20.53 lead to $f = (I-\alpha(U+U^T)/2)^{-1}(1-\alpha)y$.
