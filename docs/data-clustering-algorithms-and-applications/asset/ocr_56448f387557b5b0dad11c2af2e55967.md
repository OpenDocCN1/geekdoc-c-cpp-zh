Besides this, many works have been proposed to accelerate spectral clustering instead of focusing on the general eigensolver. [16] adopts the classical Nystöm method which was originally proposed for finding numerical approximations to eigenproblem. It first chooses samples randomly among the data points to obtain the small-size eigenvectors and extrapolates the solution for the large dataset with weights. In [44] reduces the original data set to a relatively small number of data points in a biased way. The first step is to apply an clustering algorithm as k-means to get the initial partitions. Data points near the center are merged and viewed as one. By another similarity computations for such representations, the algorithm can operate directly on this simpler graph. Similar to this, in [58], all data points are collapsed into clusters through k-means or random projection so that the later eigen-decomposition is needed to reduce the dimensionality of X (i.e., m mentioned at the beginning) and therefore help save time is later applied to drastically reduce the size of data points within the eigen-decomposition step. [4, 27] introduce early strategies to speed up eigen-decomposition. But when well-separated data points converge to the final embedding more quickly, hence, we can separately depend on the scale of the Laplacian in steps of eigenvectors without inferring the final results by. In [6], landmark points are first selected randomly or through k-means among all the data points to serve as codebook. Later constructing the affinity matrix by using product language representations, acceleration can be achieved since the complexity now is related to the number of landmark points which is far less than N. From the the other methods, authors in [21] work on observation distance embedding which has an ideal similar to spectral clustering and also has similar clustering capability. The proposed method does not require using any sampling technique or computing any eigenvector. It uses random projection and a linear solver of Simplex and Teng [47] to find the approximate and accurate embedding.

To address resource bottlenecks of both memory use and computation time, another promising direction is to make using distributed system. In [51], a parallel framework is proposed which first distributes data points onto distributed nodes. Each node, similarities between local data and the whole are computed in a way that uses minimal disk I/O. The eigenvectors matrix stored on distributed nodes reduce memory use. Finally, with parallel alignment and k-means, the proposed parallel spectral clustering achieves good speed with large data. Additionally, for constructing the sparse matrix, the authors choose MapReduce because. For eigen-decomposition and the k-means step, MPI-based open source softwares are adopted. Gao et al. [17] use a different approach to map data points into buckets and then implement spectral clustering for each cluster simultaneously. The main idea is within the preprocess, is to adapt local sensitivity hashing (LSH) to create signatures (i., M-bit binary numbers) for data points and to project near-duplicate signatures into one bucket. The hash function they use to generate the signatures falls into the family of random projection. Besides this, they propose the MapReduce algorithm for LSH and call the spectral clustering module in Apache Mahout [40] which is also implemented on top of Apache Hadoop has the MapReduce paradigm.

> Two M-bit signatures are considered to be duplicate if they have at least M - bits in common.
