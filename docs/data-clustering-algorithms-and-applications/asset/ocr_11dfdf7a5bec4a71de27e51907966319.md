A challenge of applying density-based clustering to datasets is that the “cube” of attribute values has no ordering defined. Some density-based algorithms use user-specified input parameters, though usually do not require the number of clusters k. They sometimes identify clusters of varying densities. With density-based algorithms the central subspace of a cluster cannot be distinguished from the rest of the cluster based on a higher density [35, 38, 76]. Some density-based approaches are also grid-based, since a histogram is constructed by partitioning the dataset into a number of nonoverlapping regions.

# 12.4.3.1 Projected (Subspace) Clustering

Projected clustering is motivated by high-dimensional clusters, where clusters exist only in specific attribute subsets. Subspaces are subspaces of high-dimensional datasets, determined by the subset of attributes most relevant to each cluster. The object membership in a cluster is defined by a specific range of values for the relevant attributes, while objects of other clusters are unlikely to have such values. The drawback of projected (subspace) methods is that clustering depends on user parameters for determining the relevant attributes to each cluster; the number of clusters or the average number of dimensions for each cluster. Projected clustering may distinguish the center of a cluster based on a high frequency of values for the relevant attributes [4, 2, 3]. Next, we present several subspace clustering algorithms.

# 12.4.3.2 CACTUS

CACTUS is a projected clustering method, which assumes that a cluster is identified by a unique set of attribute values that seldom occur in other clusters [32]. It searches for the minimal set of relevant attributes that are sufficient to define a cluster.

Assume all attributes $A_1, ..., A_m$ are independent and all values in attribute are equally likely. Then, the measure $\sigma(a_i, a_j)$ indicates the co-occurrence (and the similarity) of attribute values $a_i$ and $a_j$. The values $a_i$ and $a_j$ are strongly connected if their co-occurrence $\sigma(a_i, a_j)$ is higher than a user-specified factor $\alpha > 1$ the value expected under the attribute-independence assumption.

A set of values $\{c_1, ..., c_k\}$ over the attributes $\{A_1, ..., A_m\}$ is a cluster if the set $C$ is a set of strongly connected attribute values. In other words, the condition should be satisfied that all pair of values in $C$ are strongly connected and their co-occurrence $\sigma(c_i, c_j) > \alpha$ for $i 
eq j$. $C$ is also a subspace; a subcluster if there is another value for one of attributes $\{A_1, ..., A_m\}$ that is not included in $C$, but strongly connected to the other attribute values in $C=\{c_1,...\}$.

The CACTUS algorithm collects inter-attribute summaries and intra-attribute summaries on categorical datasets. The inter-attribute summaries consist of all connected attribute value pairs where each has attribute values from different attributes. The intra-attribute summaries consist of similarities between attribute values of the same attribute. Then, the CACTUS algorithm consists of three phases: summarization, clustering, and validation. The summarization phase computes the summary information order to discover a set of candidate clusters. The validation phase determines the actual set of clusters from the set of candidate clusters.

A drawback of CACTUS is that the assumption of a cluster being identified by a unique set of attribute values that seldom occur in other clusters may be unnatural for clustering some real world datasets. CACTUS may also return many clusters [76, 35, 38].
