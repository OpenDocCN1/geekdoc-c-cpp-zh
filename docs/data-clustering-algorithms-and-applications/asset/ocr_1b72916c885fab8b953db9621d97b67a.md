A cluster in any base clustering is represented by a hyper-edge connecting the members. The hyper-graph clustering package HMETIS (Karpis et al. [35]) was used to provide quality clusters and is very scalable. With CSPA, employing a graph clustering algorithm ensures a constraint that favors clusterings of comparable size. HPGA is fast with worst case complexity of O(nk), it suffers from an admission problem: if all members of a cluster are not assigned the same cluster in the consensus solution, it incurs a constant penalty; however it cannot distinguish between a situation where one object was clustered differently and one where several objects were allocated to other groups. Due to this issue, HPGA is often not competitive in terms of cluster quality.

MCLA forms a meta-graph with vertices, the edge weights proportional to the similarity between vertices, using the binary Jaccard measure (number of elements common by the total number of distinct elements). Since the base clusters are partial, this results in an r-partite graph. The meta-graph is then partitioned into k meta-clusters. Each meta-cluster, therefore, contains approximately r vertices. Finally, ties are broken randomly. The worst case complexity is O(nk²).

Noting that CSPA and MCLA consider either the similarity of objects or the similarity of clusters, a Hybrid Bipartite Graph Formulation (HBGF) was proposed in [16]. A bipartite graph models both points and clusters as vertices, where an edge exists only between a cluster and a vertex if the latter is a member of the former. Either METIS or other multi-spectral clustering methods are used to partition this bipartite graph. The corresponding versions of CSPA, MCLA, and HBGF have also been developed by Punera and Ghosh [52]. It should be noted that all of CSPA, MCLA, and HBGF were generated using one other than the NI measure in [56].

# 22.4.3.2 Cumulative Voting

The concept of cumulative voting was first introduced in [15] where the authors used bagging to improve the accuracy of clustering procedure. Once clustering is done on a bootstrapped sample, the cluster correspondence is solved using iterative relabeling via Hungarian algorithm. Clustering on each bootstrapped sample gives votes corresponding to each data point and cluster pair which, in aggregate, decide the final consensus.

A similar approach was adopted in [6]. Base clustering in this contribution is of providing a soft or probabilistic vote on which clusters in the consensus solution its data points should. These votes are then gathered across the base solutions and thresholded to determine the membership of each object to the consensus clusters. Again, this requires a mapping from the base clusters to a stochastic one. An information-theoretic criterion based on the information bottleneck was used in [6] for purpose. This approach is able to capture a range of l in the base clusterings, is fast and avoids the complexity of forming, and has good empirical results as well. Noting that the information bottleneck can be obtained as a special case of Bregman clustering [8], it should be possible to recast this approach as a probabilistic.
