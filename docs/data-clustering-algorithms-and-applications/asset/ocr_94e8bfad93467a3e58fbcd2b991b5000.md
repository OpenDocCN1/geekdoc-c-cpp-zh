# Network Clustering

# **Algorithm 37** Kernighan-Lin

Given two partitions $\mathcal{V}_A, \mathcal{V}_B$

```
Compute diff-value for all vertices
Unmark all vertices
Let, $k_0$ = cut-size
for $i = 1$ to $\min(|\mathcal{V}_A|, |\mathcal{V}_B|)$ do
Find the pair $((a_i, b_i)$ | $a_i \in \mathcal{V}_A, b_i \in \mathcal{V}_B$) with biggest gain among all unmarked vertices
Mark $a_i$ and $b_i$
for each neighbor $v$ of $a_i$ or $b_i$ do
Update $diff(v)$ assuming $a_i$ and $b_i$ have swapped,
```

```
$diff(v) := diff(v) + \begin{cases} 2w_w(e, a_i) - 2w_e(e, b_i) & \text{for } v \in \mathcal{V}_A \ 2w_e(e, b_i) - 2w_e(e, a_i) & \text{for } v \in \mathcal{V}_B \end{cases}$
```

```
end for
k_i = k_{i-1} - gain(a_i, b_i)$, that is, $k_i$ would be the cut-size if $a_1, a_2, \dots, a_i$ and $b_1, b_2, \dots, b_i$ have been swapped
end for
```

Select the smallest $j$ such that $k_j = \min(k_i)$
Swap the $j$ pairs. That is,

```
$\mathcal{V}_A = \mathcal{V}_A - \{a_1, a_2, \dots, a_j\} \cup \{b_1, b_2, \dots, b_j\}$$
$\mathcal{V}_B = \mathcal{V}_B - \{b_1, b_2, \dots, b_j\} \cup \{a_1, a_2, \dots, a_j\}$
```

Repeat until no swap pairs is achieved

In each iteration, the algorithm swaps pairs of vertices to maximize the gain. This process is continued until as soon as the vertices of the smaller partition are swapped. One important fact is, the algorithm does not stop soon as there are no more moves to be made; rather it continues, even accepting negative gains in order to climb out of the local-minima. It also applies a bunch of optimizations. There are many variations of the Kernighan-Lin algorithm [78, 86, 104] often trading time quality or generalizations. Some examples are

+   - Limiting the number of swapping to a fixed number based on the observation that largest gains are achieved early on.
- Limiting the number of iterations.
- Evaluating diff-values of vertices near the boundary.
