### 13.2.2 The Vector Space Model

Most document clustering methods choose to view text as a *bag of words*. Each document is considered to be a vector in the term-space, represented in its simplest form by the *term-frequency* (TF) vector

```
$d_{tf} = (tf_1, tf_2, \dots, tf_M)$
```

where $tf_i$ is the frequency of the $i$th term in the document. This gives its model name, the *vector space model* (VSM).

A widely used refinement to the vector space model is to weight each term based on its *inverse document frequency* (IDF) in the document collection. The motivation behind this weighting is that terms appearing frequently in many documents have limited discriminatory power and thus need to be de-emphasized. by multiplying the frequency of the $i$th term by $\log(N/df_i)$, where $df_i$ is the number of documents that contain the $i$th term (i.e., document frequency). This leads to the *tf-idf* representation of the document:

```
$d_{tfidf} = (tf_{idf_1}, tf_{idf_2}, \dots, tf_{idf_M})$
```

Finally, to account for documents of different lengths, the length of each document vector is normalized to unit length ($||d_i,d_j|| = 1$); that is, each document is a vector in the unit hypersphere.

To maximize term co-occurrence in text, words can be reduced to a base form, through stemming or lemmatization. Stemming [85] is a heuristic process that works on individual words, removing derivational affixes and in general cutting the word ending in matches with other forms of the same word. Lemmatization uses dictionaries and morphological analysis, aiming to return to the root of the word [73]. It analyzes words in context and is more demanding than stemming. Synonym of a word can be replaced by a common form using lexical databases [50]. Some attempts have been made to capture order and sentence structure in the VSM by using text word or character n-grams (sequences of two or more items) [19, 75].

**Similarity in vector space.** The cosine similarity is the most used measure to compute similarity between two documents in the vector space. Given vectors $d_1$ and $d_2$, it is defined

```
$cos(d_1,d_2) = \frac{d_1 \cdot d_2}{||d_1|| \times ||d_2||}$
```

where “...” represents the vector dot product operation. This formula can be simplified to $cos(d_1,d_2) = d_1 \cdot d_2$ for vectors of unit length.

Let $D$ be the $N \times M$ document-document matrix whose rows are the term frequency vectors. The pairwise similarities of all documents in the collection can be computed directly from $D$ as

```
$SIM = L^{-1/2}XL^{-1/2}$
```

where $X = DD^T$ and $L$ is a $N \times N$ diagonal matrix whose diagonal elements are the diagonal elements of $X$. The left and right multiplication of $X$ by $L^{-1/2}$ scales the document to unit length. The formula reduces to $SIM = DD^T$ if the documents are already unit length.

Other popular measures for comparing documents include the Euclidean, Manhattan, and Chebyshev distances, and Jaccard coefficient. The Euclidean distance, also known as the $l^2$ norm, is simply the geometric distance in the $M$-dimensional space of the vectors, defined by

```
$dist(d_1,d_2) = \sqrt{\sum_{i=1}^{M} (d_1^i - d_2^i)^2}$
```

where $d_1^i$ is the $i$th element in the document vector. The Manhattan (also known as city-block distance or the $l^1$ norm) and the Chebyshev (also known as board or the $l^{\infty}$ norm) distances are similarly defined as

```
$dist_1(d_1,d_2) = \sum_{i=1}^{M} |d_1^i - d_2^i|$
```

```
$dist_{\max}(d_1,d_2) = \max_{i=1}^{M} |d_1^i - d_2^i|$
```

The Jaccard coefficient is a set similarity metric. It can be applied to a feature vector by considering its nonzero elements. Using this logic, Jaccard coefficient measures commonality, represented by the intersection of the two documents normalized by their union:

```
$J(D_1,D_2) = \frac{|D1 \cap D_2|}{|D_1 \cup D_2|}$
```

where $D_1$ and $D_2$ are representations of $d_1$ and $d_2$, respectively.

### 13.2.3 Alternate Document Models

Some document models have been proposed to overcome VSM limitations. Wang et al. [112] represent documents using word dependency graphs and compare them using graph similarity. The Matrix Space Model (MSM) [112] considers each document to be a set of segments, represented by a term-segment matrix. Concept-based models augment the original text vector by adding or replacing terms with some category information, such as WordNet concepts [50], synsets [41], part-of-speech tags and hypernyms [94], or Wikipedia-based concepts [35].

Some models build corpus representations that allow computing similarity between documents. The Generalized Vector Space Model (GVM) [114] addresses the pairwise orthogonality assumption in the vector space. These models represent documents in a suitably chosen set of orthonormal term vectors, allowing computation of correlations. Late Semantic Analysis (LSA) [24] provides a low-rank approximation of the document-term matrix, with effectively occurring more, in the latent space, associated with terms that have similar meanings.

Topic models describe a simple probabilistic process by which items can be generated in a collection. In this framework, documents are represented as mixtures of topics, in probability mass functions (PMFs) defined over a lower-dimensional feature space representing topics. Topic models can describe words, segments, or documents, and are the basis for many generative algorithms discussed later in the chapter.

### 13.2.4 Dimensionality Reduction for Text

The number of unique terms in text corpora is very high. Dimensionality reduction techniques aim to eliminate this by decreasing noise in the text space. This can be done by feature selection, which aims to choose an optimal subset of features given some objective, or feature transformation, which seeks a lower-dimensional mapping of the original feature space. The simplest technique prunes features with low or high document frequency. Frequently occurring terms are deemed undefined, while rare terms are considered. Stop words, which are lexicon-specific terms, are also removed. These simple selection techniques have been found in some cases to be as effective as supervised methods that select features based on information gain (IG), mutual information (MI), or $\chi^2$ (Chi-Square) analysis [116].

Feature transformation algorithms project the data to some lower dimensional space. Principal Component Analysis (PCA) [49, 56] is the dominant unsupervised approach. It diagonalizes the covariance matrix $C_D = DD^T$ into $(PD)^TP$ and removes fewer components, reduces $P$ to $K \times N$, where $K < N$. $P$ is the matrix of principal components, whose rows are the eigenvectors of $D^T$.

A related approach, Latent Semantic Analysis (LSA) [24], performs a singular-value decomposition of the document-term matrix, $D = UV^T$ and keeps latent representations of the document vectors associated with the $K$ singular values (eigenvalues). In the supervised domain, Linear Discriminant Analysis [34, 74] aims to find a latent space in which documents from different classes are well-separated, maximizing the Fisher criterion,

```
$$\text{argmax}_{\mathbf{W}} \frac{\mathbf{W}^T \mathbf{S}_b \mathbf{W}}{\mathbf{W}^T \mathbf{S}_w \mathbf{W}}$$
```
$\mathbf{S}_b = \sum_{c \in C} n_c (\mu_c - \mu)(\mu_c - \mu)^T$
$\mathbf{S}_w = \sum_{c \in C} \sum_{j \neq c} (d_j - \mu_c)(d_j - \mu_c)^T$
```

Where $\mathbf{S}_b$ and $\mathbf{S}_w$ are the between-class and within-class scatter matrices. $C$ is the set of class labels, $\mu_c$ is the collection mean, $\mu$ is the mean of documents in class $c$, $n_c$ is the number of documents.
