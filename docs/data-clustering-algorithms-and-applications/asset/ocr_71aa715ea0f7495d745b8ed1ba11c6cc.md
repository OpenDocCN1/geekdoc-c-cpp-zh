# Data Clustering: Algorithms and Applications

DBSCAN, the Eps-neighborhood of a point is defined relative to a subspace $S \subseteq A$ based on the distance of two points projected to the dimensions of $S$.

```
$NEps(p) = \{q \in D | dist(\pi_S(p), \pi_S(q)) \leq Eps\}$
```

All other DBSCAN notation can be transferred to subspaces in a straightforward way. A density-connected set $S \subseteq A$ is also a density-connected set in any subspace $T \subseteq S$. The SUBCL algorithm starts by applying DBSCAN to all 1-dimensional subspace. Let $S_k$ denote the set of all k clusters. For each cluster with $k$ (initially, $k=1$) dimensions, it is checked (whether this cluster still exists in higher-dimensional subspaces). Furthermore, candidate $k+1$ dimensional subspaces are generated by joining $k$-dimensional subspaces. Candidate subspaces having $k-1$ attributes in common, at least one $k$-dimensional subspace not in $S_k$, are pruned. The algorithm terminates when no more clusters are detected at the current dimensionality.

As DBSCAN is applied to different subspaces, an index structure for the full-dimensional space $A$ is not available. Instead, inverted lists are employed to support the region queries that retrieve the Eps-neighborhood of a point. Inverted lists provide $O(log n)$ region queries for individual attributes, where $n$ is the number of data points. For region queries on multiple attributes, region queries are performed separately on each of the attributes, and these intermediate results are intersected to obtain the final result.

Many algorithms for subspace clustering or projected clustering of high-dimensional data have been proposed, relevant densities in different subspaces may be very different. In particular, the threshold density that distinguish between clusters in one subspace may be the density of the noise in another. To address this, visualization-interactive methods have been presented as a way to involve the user with their cognitive abilities and interact with clusters in lower-dimensional subspaces. Hinneburg et al. [18] develop the visual HD-Eye that enables the user to interact with clusters. predefined subspaces are visualized and combined iteratively by the user. Agrawal et al. [11] present a system that provides more active guidance to the user. In each iteration, the system proposes a well-polarized projection to the user, i.e., a projection in which the clusters are clearly distinguished. A visual profile of the data density in that projection is presented to the user, who then manually separates the clusters in the subspace. The system terminates as soon as most points have been assigned to at least one cluster in one of the subspaces considered.

# 5.7 Clustering Networks

Most-density-based algorithms, as all other clustering algorithms, work on data points or records with a fixed number of attributes having one value each. However, network data is becoming increasingly common, e.g., social networks, the web, or biological interaction networks. Networks can be naturally modeled as graphs. Let $G=(V,E)$ be a graph with a set of vertices $V$ and a set of edges $E$. Vertices represent objects, and edges represent relationships between pairs of objects. In this section, we discuss density-based clustering methods for networks and refer to the Chapter 17 on Network Clustering for other methods.

The SCAN algorithm [34] transfers the concepts of DBSCAN from point network data, assuming that network clusters are graph components. SCAN discovers not clusters, but also hubs connecting clusters and outliers not belonging to any cluster.
