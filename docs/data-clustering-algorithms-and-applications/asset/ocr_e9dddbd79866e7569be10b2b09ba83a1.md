# 4.2.3 Affecting K-Means

The factors that can impact the performance of the K-means algorithm are the following:

+   1. Choosing the initial centroids.

+   2. Estimating the number of clusters K.

We will now discuss several methods proposed in the literature to tackle each of these factors.

# 4.2.3.1 Popular Initialization Methods

In his classical paper [33], MacQueen proposed a simple initialization method which chooses K seeds at random. This is the simplest method and has been widely used in the literature. The other K-means initialization methods which have been successfully used to improve the clustering performance are given below.

+   1. Hartigan and Wong [19]: Using the concept of nearest neighbor density, this method suggests the points which are well separated and have a large number of points within their surrounding multi-dimensional sphere can be candidates for initial points. The average pair-wise Euclidean distance between points is calculated using Equation (4.4). Subsequent points are chosen in the order of their decreasing density and simultaneously maintaining the separation of $d_i$ from all previous seeds. Note that for the formulae below we continue using the same notation as introduced.

```
$d_i = \frac{1}{N(N-1)}\sum_{j=1\neq i}^{N} ||x_i - x_j|| \quad (4.4)$
```

+   2. Milligan [37]: Using the results of agglomerative hierarchical clustering (with the help of the dendrogram), this method uses the results obtained from the Ward's method. Ward's method chooses the initial centroids by using the sum of squared errors to evaluate the distance between two clusters. Ward's method is a greedy approach and captures the agglomerative growth as small as possible.

+   3. Bradley and Fayyad [5]: Choosing random subsamples from the data and apply K-means clustering to all these subsets using random seeds. The centroids from each of these subsets are collected, and a new dataset consisting of only these centroids is created. This new dataset is clustered using these centroids as the initial seeds. The Minimum SSE guarantees the best seed choice.

+   4. K-Means []: The K-means algorithm carefully selects the initial centroids for K-means clustering. The algorithm follows a simple probability-based approach where initially the first centroid is selected at random. The next centroid selected is the one which is farthest from the currently selected centroid. This selection is decided based on a weighted probability score. The selection is continued until we have K centroids and then K-means clustering is done using these centroids.
