We note that repeated samplings generate the same set of clusters, a scenario we wish to avoid. In order to reduce repeated clusters, two approaches can be used:

- Objects with a minimal probability of belonging to any of the previously generated clusters are excluded from consideration for medoids.

- The probability of an object being selected as a medoid depends on its membership degree to the previously generated clusters. Objects which have low membership degrees to previously generated clusters have a higher probability of being selected as medoids.

## 18.6.2 UPStream: Projected Clustering of Uncertain Data Streams

The UPStream algorithm is designed for the high uncertainty stream scenario. This algorithm can be considered an extension of the UMicro algorithm. The error model of the UPStream algorithm is quite different from that of [32] and uses a model of standard deviations rather than the entire probability distribution. This model is more similar to the UMicro algorithm.

The data stream consists of a set of incoming records which are denoted by $\tilde{X}_1, \dots, \tilde{X}_t$. It is assumed that the data point $\tilde{X}_i$ corresponds to the timestamp $T_i$. It is assumed that the dimensionality of the data is $d$. The $d$ dimensions of $\tilde{X}_i$ are denoted by $(x_i^1, \dots, x_i^d)$. In addition, each data point has an error associated with the different dimensions. The error (standard deviation) associated with the $j$th dimension of data point $i$ is denoted by $\psi_j(i)$.

In order to incorporate greater importance of data points in an uncertain stream, we use the concept of a fading function $f(t)$, which quantifies the relative importance of the different data points over time. The fading function is drawn from the range $(0, 1)$ and serves as a multiplicative factor for the relative importance of a data point. This function is a monotonically decreasing function and represents the gradual fading of importance of a data point over time. A commonly used decay function is the exponential decay function. The exponential decay function $f(t)$ appears as a function of the time $t$:

```
$f(t) = 2^{-\lambda t}$$
```

We note that the value of $f(t)$ reduces by a factor of 2 every $1/\lambda$ time units. This is the half-life of $f(t)$. We define the half-life as:

**Definition 18.6.1** The half-life of $f(\cdot)$ is defined as the time $t$ at which $f(t) = (1/2) \cdot f(0)$. For the exponential decay function, the half-life is $1/\lambda$.

In order to keep track of statistics for cluster creation, two sets of statistics are maintained:

- Global statistics keep track of the variance along different dimensions of the data. This data is necessary in order to maintain information about the scaling behavior of the underlying data.

- Fading microcluster statistics keep track of the cluster behavior, the projection dimensions as well as the learning uncertainty.

Let us assume that the data points that have arrived so far are $\tilde{X}_1 \dots \tilde{X}_N$. Let $t_i$ be the current time.

- For each dimension, the weighted sums of squares of the individual dimensions of $\tilde{X}_1 \dots \tilde{X}_N$ over the entire data stream are maintained. There are a total of $d$ such entries. The $i$th component of the global second-order statistics is denoted by $gs(i)$ and is equal to $\sum_{j=1}^i f(t_i - T_j)^2$.
- For each dimension, the individual dimensions of $\tilde{X}_1 \dots \tilde{X}_N$ over the entire data stream are maintained. There are a total of $d$ such entries. The $i$th component of the global first-order statistics is denoted by $gf(i)$ and is equal to $\sum_{j=1}^i f(t_i - T_j) \cdot x_j^i$.
- The sum of the weights of the different values of $f(T)$ are maintained. This value is equal to $\sum_{j=1}^i f(t_i - T_j)$. This value is denoted by $gW$.

The above statistics can be easily updated over a stream since the values are computed additively over data points. At first, we state that the statistics would need to be updated at each clock tick. In reality, because of the multiplicative nature of the exponential distribution, we only need to update the statistics by the arrival of each new data point. When a new data point arrives at $t_i$, we multiply each statistics by $e^{-\lambda(t_i-T_i)}$ and add the statistics for the incoming data point $\tilde{X}_i$. We note that the global variance along a given dimension can be computed from the above values; the global variance can be maintained continuously over the entire data stream.

> **Observation 18.6.1** The variance along the $i$th dimension is given by $\frac{gs(i)}{gW} - \frac{gf(i)^2}{gW^2}$.

The above fact can be easily proved using the fact that for any random variable $Y$ the variance $var(Y)$ is given by $E[Y^2]-E[Y]^2$. We will denote the global standard deviation along dimension $i$ at time $t_i$, by $\sigma(i_i, t_i)$. As suggested by the observation, the value of $\sigma(i_i, t_i)$ is easy to maintain by using the global statistics discussed above.
