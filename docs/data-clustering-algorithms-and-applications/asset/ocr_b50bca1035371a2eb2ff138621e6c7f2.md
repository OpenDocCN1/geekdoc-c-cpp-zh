There are a few issues in the approaches described above. Low-level visual features can be enhanced by mid-level detection because they are technically closer to higher-level events. When using mid-level detection, it is clear that not all detections are relevant to the target event, and incorporating all of them can degrade the performance because the detection usually becomes noisy. Moreover, averaging all photos within an album mixes up typical and atypical images. In [31], the authors address these issues with frequent patterns in semantic events. Short detectors are more robust to noise, compared to directly using all object detections as described in [18]. Ideally, an object can be "car,street light,person", which means that the three objects "car," "street light," and "person" co-occur a lot in a certain event. In practice, detection is a relative score and is not binary. However, the actual object looks like "car/6/7,street/5/7,desk/2/7", which means that a certain scene or event "car" has detection score at least 6 of 7, "street light" has at least 5 of 7, and "desk" has at most 2 out of 7. Discrete issues are due to the detection quantization, and such an object pattern image-level detection tree classifier $f(mI)=1$ if and only
$m_i(I) \geq s_1 \wedge m_i(I) \geq s_2 \geq t_2 \wedge m_i(I) \geq s_3 \geq t_3 \dots$
$s_1, s_2, ... \in \{-1, 1\}; \quad (14.4)$

where $m_k(I)$ is the raw detection of object k for image $I$. $i$ is the object index, $s_j$ controls the interval region (greater or less than), and $t_j$ is the threshold of the $j$-th object in the photo. Finally, the album level feature is formed by aggregating the output of a large number of $F_k(mI)$ for all photos in the album.

# 14.2.4 Image Segmentation

In this section, we present a semiautom image segmentation algorithm via graph cuts to minimize the energy function [5]. Users can manually label the pixels of some object in an image, and then graph cuts automatically segment the image into different objects corresponding to these labels. The graph cuts simultaneously measure the smoothness of the labeling and the agreement between the labeled pixels and the labeling. More precisely, we are given a graph $G=(\mathcal{P},\mathcal{X})$, where $\mathcal{P}$ is the set of nodes corresponding to the pixels in an image, and $\mathcal{X}$ is the set of edges measuring the similarity between the pixels based on their colors and locations. Then a labeling function $f$ assigns each pixel $p \in \mathcal{P}$ with a label $f_l$ in a finite set $\mathcal{L}$ of object labels. The goal here is to obtain the labeling function $f$ that minimizes the energy

```
$E(f) = E_{smooth}(f) + E_{data}(f)$
```

where, $E_{smooth}(f)$ measures the extent to which $f$ is not piecewise smooth, while $E_{data}(f)$ measures the disagreement between $f$ and the pixels.
