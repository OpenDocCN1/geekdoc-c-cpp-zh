## 15.3.2 Sensor Selection Algorithms for Correlation Clustering

Sensor selection algorithms are naturally related to correlation clustering. This is because such methods typically pick a representative set of streams which can be used in order to predict the other streams in the data. The representative streams are used as a proxy for collecting all from the different streams. Such approach is used to save energy. Nature creates clusters in which each stream belongs to the cluster of a particular representative. A number of techniques have been designed in order to perform online correlations between streams in real time [43, 48, 51, 61]. The techniques use statistical measures in order to find correlations and forecast the behavior of the underlying data stream. The works in [2, 6] propose methods for sensor selection for the use of domain-specific linkage knowledge and utility-feedback. Methods for observation selection are proposed in [27], when the importance of a sensor-set can be premodeled as a submodule function. Methods for using adaptive models for time-series prediction were proposed in [57]. The method in [58] uses linear regression in order to determine the correlations in the underlying data and use them for forecasting. The technique [61] proposes general monitoring techniques to determine statistical correlations in the data in real time.

Correlation clustering in time series can also be used to monitor key changes in the correlation trends in the underlying stream. This is because the correlations between the different streams change over time, this leads to changing membership of streams in different clusters. Such changes are relevant to determining key temporal anomalies in the data and are discussed in [4].

## 15.4 Similarity and Distance Measures

For conventional shape-based clustering algorithms, the use of similarity and distance measures is crucial. In [34] Liao classifies time-series measures into three:

- (a) feature-based
- (b) model-based
- (c) shape-based

While this classification makes sense and analyzes in-depth the time-series it lacks information about whether measure is appropriate. Over the last few years, time-series clustering has attracted the interest of the research community. One of the most important decisions in time-series clustering is which measure to use for comparison. In this sense, we review the measures that have been proposed in the literature:

- (a) Discrete Fourier Transformation (DFT)
- (b) Discrete Wavelet Transformation (DWT)
- (c) Linear Predictive Coding (LPC)

In this section we briefly present the distance measures that are widely used in the chapter.

### 15.4.1 Univariate Distance

The $L_p$-norm is a generalization of Euclidean distance, defined as:

```
$D_p(T_1, T_2) = \sum_{i=1}^n |T_{1i}-T_{2i}|^p$
```

For $p=2$, it is the Euclidean distance, which is defined as:

```
$D_E(T_1, T_2) = \sqrt{\sum_{i=1}^n (T_{1i}-T_{2i})^2}$
```

For $p=1$, it is known as Manhattan distance or city block.

### 15.4.1.2 Dynamic Timeping DistanceDynamic Time Warping (DTW) is a well-known shape-based distance. DTW computes the warping path $W = w_1, w_2, ..., w_K$ where $\max(m,n) \leq K \leq m+n-1$. DTW stems from speech processing [45] and has become popular in the literature of time-series it is computed as:

- (a) $D_{DTW}(T_1,T_2) = 0$, if $m=n=0$
- (b) $D_{DTW}(T_1,T_2) = \infty$, if $m \neq n$
- (c) $D_{DTW}(T_1,T_2) = \text{dist}(T_{11},T_{21}) + \text{minFactor}$, otherwise

where $minFactor$ is computed as:

```
$minFactor = \min \begin{cases} D_{DTW}(\text{Rest}(T_1),\text{Rest}(T_2)) \\ D_{DTW}(\text{Rest}(T_1),T_2) \\ D_{DTW}(T_1,\text{Rest}(T_2)) \end{cases}$
```

DTW is a more robust distance than $L_p$-norm because it allows shifting and matches similar shapes even if they have a phase-difference. An important point is that DTW does not satisfy the triangular inequality while indexing DTW time series. However, in the literature there are lower bounds that serve as solutions for indexing DTW offering faster performance [51].
