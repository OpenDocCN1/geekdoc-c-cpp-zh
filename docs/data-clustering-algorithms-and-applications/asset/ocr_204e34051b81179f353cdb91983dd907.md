# 18.4.2 The CK-Means Algorithm

While the work in [16] claims that UK-means provides superior results to deterministic clustering, the work in [44] shows that the model utilized by the UK-means is actually equivalent to deterministic clustering, replacing each uncertain data point by its expected value. Thus, the UK-means approach actually turns out to be deterministic clustering. This contradicts it in [16] that the UK-means algorithm provides superior to deterministic clustering method which replaces uncertain data points with their centroids. We find that most of the computational complexity is created by the running time for expected distances calculations. On the other hand, deterministic distances are extremely efficient and almost always superior to any method which is based on expected distances, whether or pruning.

The UK-means algorithm aims to optimize the mean square expected distance about each cluster centroid $ar{X}$. A key step is the computation of the expected square distance of an uncertain data point $X_i$ where the latter is approximated as a deterministic entity. Let $ar{Y}$ be the centroid of the cluster, and $X_1...X_n$ be the set of data points in the cluster. Then, the expected mean square distance of $X_i$ over $ar{Y}$ is $E[\|X_i-ar{Y}\|^2]$. Then, if $ar{Y}$ is approximated as a deterministic entity, we can show the following:

**Lemma 18.4.1** $X$ be an uncertain data point, and $ar{Y}$ be a deterministic point. Let $\overline{X}=E[X]$ and $var(\overline{X})$ represent the sum of the variances of the pdfs in $\overline{X}$, over all dimensions. Then, we have

> $E[\|X_i-ar{Y}\|^2] = E[\|X_i\|^2] - \|ar{Y}\|^2 = var(\overline{X}) + \|\overline{X}-ar{Y}\|^2$$
