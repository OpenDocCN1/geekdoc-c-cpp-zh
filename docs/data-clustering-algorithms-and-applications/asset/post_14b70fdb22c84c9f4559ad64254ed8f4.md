## Data Clustering: Algorithms and Applications

### 19.3.3 Visual Clustering with SOMs

A Self-Organizing Map (SOM) is a clustering-like algorithm originally invented by Kohonen [29] that is inspired by the architecture of the brain [35]. Given a set of high-dimensional data vectors, the learning algorithm forms a two-dimensional grid consisting of nodes that act as cluster centers in the high-dimensional space. Each inner node of the grid is connected to four neighbor nodes within an area. The learning algorithm cycles through the data vectors and determines the nearest node for each of them. The nearest node and to a lesser degree the neighbors of the node with respect to the topology are moved a certain amount toward the current data vector in the high-dimensional space. That amount decreases during training at a given level. Thus, the map reaches a stable configuration overall after some iterations.

The learning algorithm tries to preserve the neighborhood with respect to the two-dimensional grid in the high-dimensional data space. That is, neighboring nodes tend to be mapped to close positions in the high-dimensional space. Therefore a path along the two-dimensional map is often a path with small jumps in the high-dimensional space. The map visualization shows that the grid is therefore nonlinear embedding of the two-dimensional plane in the high-dimensional space. Simple visualizations show cluster attributes or features of the nodes as a map.

An interactive visualization technique is to plot some small object visualization—e.g., some graphs—at the nodes [38]. In principle, every type of icon or glyph such as Chernoff-faces or star-plots works with combination with a SOM. The only restriction is the effectiveness of the glyph type for high dimensional data, which is usually limited to vectors with most 10 or 15 dimensions. The two-dimensional map combined with glyph visualizations then shows smooth or rough transitions between neighboring nodes.

An interesting feature of this technique proposed in [38] is that the user can specify interactively the initialization and the learning of the SOM. The glyphs translate directly to high-dimensional vectors. The node positions of the interactively specified glyphs in the high-dimensional space are fixed during the SOM learning. The layout of the SOM can be directly specified by the user in an interactive and visual way. The gaps between the specified nodes in the map are automatically filled by the SOM learning algorithm. The technique of interactive editing SOMs can also be used during the training procedure to steer the SOM learning algorithm toward the users prefers. The technique has also been used with small graphic maps instead of glyphs [3].

### 19.3.4 Discussion

The examples that can be combined automated algorithms with interactive visualizations are really simple with respect to both the algorithm and the visualization technique. Both ingredients are proven techniques in all cases. Whether the combination of automated algorithms and visualizations is really superior over fully automated algorithms on one side and purely interactive approaches on the other is yet to be studied. To the best of our knowledge, there exist no user-studied approaches with interactive visual clustering. Performance metrics to evaluate analytic systems in general have been proposed in [7]. However, it is not just the application of standard usability testing in human-computer-interface (HCI) research to visual analytics systems. The complex nature of the dialog between the analyst and the computer using visual visualizations involves cognitive processes that are to be analyzed and explored [4]. Thus, an research question still exists regarding how to evaluate visual analytics systems in general and those for interactive visual clustering in particular.
