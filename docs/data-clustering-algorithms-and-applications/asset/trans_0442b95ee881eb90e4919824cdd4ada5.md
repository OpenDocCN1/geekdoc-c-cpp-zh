**引理 23.2.7** 给定 $K' \le K$，$\varepsilon \le 1 - 1/K$。

证明：$\sigma_1 : \{1, \dots, K'\} \to \{1, \dots, K\}$ 是类到不同聚类的最优映射，即

$$\varepsilon = 1 - \frac{\sum_{j=1}^K n_{\sigma_1(j),j}}{n}$$

然后构造一系列映射 $\sigma_s : \{1, \dots, K'\} \to \{1, \dots, K\}$ ($s = 2, \dots, K$) 满足

$$\sigma_s(j) = \mod(\sigma_{s-1}(j), K) + 1, \forall j \in \{1, \dots, K'\}$$

其中 $\mod(x,y)$ 返回正整数 $x$ 除以正整数 $y$ 的余数。根据定义，$\sigma_s$ ($s=2, \dots, K$) 也能像 $\sigma_1$ 一样将 $\{1, \dots, K'\}$ 映射到 $\{1, \dots, K\}$ 中的 $K'$ 个不同索引。更重要的是，$\sum_{j=1}^K n_{\sigma_s(j),j} \ge \sum_{j=1}^K n_{\sigma_{s-1}(j),j}, \forall s=2, \dots, K$；且 $\sum_{j=1}^K n_{\sigma_1(j),j} = n$。因此，$\sum_{j=1}^K n_{\sigma_1(j),j} \ge n\varepsilon$，这意味着 $\varepsilon \le 1 - 1/K$。证明完成。

因此，$1-1/K$ 被用作 $\varepsilon$ 的上界，归一化的 $\varepsilon_n$ 显示在表 23.5 中。

## 23.2.3 DCV 准则

本节通过实验展示 DCV ($CV_1-CV_0$) 对于选择验证度量的重要性。

**实验数据集。** 一些合成数据集按如下方式生成：一个是二维高斯分布的混合，包含两个高斯分布。两个分布的均值分别为 $[-2,0]$ 和 $[2,0]$。它们的协方差矩阵相同，为 $[\sigma^2 \ 0; 0 \ \sigma^2]$。

因此，给定 $\sigma^2$ 的特定值，可以生成一个模拟数据集，其中 $n_1$ 个实例来自第一个，$n_2$ 个实例来自第二个，其中 $n_1+n_2=600$。为了生成具有不平衡类别大小的模拟数据集，使用了一组 $n_1$ 值 $\{3000, 2200, 1800, 1400, 600\}$。如果 $n_1=200, n_2=580$，数据集高度不平衡，$CV_0$ 范围从 $0$ 到 $1.5$；为了生成具有不同聚类密度的集合，使用了一组 $\sigma^2$ 值，$\{0.5, 1, 1.5, 2, 3.5, 4, 4.5, 5\}$。由于混合模型往往不稳定，最后，对每一对，采样重复 $10$ 次以获得平均聚类性能。总结来说，生成了 $8 \times 10=80$ 个数据集。图 23 显示了一个 $n_1=1000$ 且 $\sigma^2=5$ 的数据集。

对真实世界数据集 tech 进行采样以获得一些具有不平衡类别分布的数据集。该数据集源自圣何塞水星报，包含 2301 份关于计算机、电子、健康、医疗、研究和技术的文档。每份文档由 126373 个词表征，类别大小为 485、116、229、603、481 和 187。仔细选择每个类别的采样比例，提取了 8 个样本集，其类别大小分布 ($CV_0$) 范围从 0.490 到 1.862，如表 23.6 所示。对每个数据集，采样重复 $10$ 次以观察平均聚类性能。

**实验工具。** 实验采用了 MATLAB [71] 和 CLUTO 2.1 [27] 的 K-means 实现。对于低维和稠密数据集，MATLAB 配合欧几里得距离适用，而 CLUTO 配合余弦相似度用于处理高维和稀疏数据集。根据聚类数，即 $K$，设置为“真实”类别数。

## 23.2.3.3 归一化的影响

本节介绍度量归一化的重要性。沿着这一思路，首先在 $\sigma^2 = 5$ 的模拟数据集和采样数据集上应用 K-means 聚类。然后使用未归一化和归一化度量进行聚类验证。最后计算 DCV 与度量之间的秩相关性，结果显示在表 23.7 中。

如可见，如果使用未归一化度量进行聚类验证，只有三个度量，即 R、G，在两组数据集上都与 DCV 表现出强一致性。VI 和 MD 在采样数据集上与 DCV 表现出强冲突，因为它们在模拟数据上的值都接近于 $-1$。此外，注意 $F$、$\epsilon$ 和 FM 与 DCV 表现出相关性。

表 23.7 显示了 DCV 与归一化度量之间的相关性。如图所示，度量对 $F_n$ 和 $e_n$ 与 DCV 表现出完美一致性。这表明归一化对 K-means 聚类至关重要。提出的度量边界足够紧以捕捉聚类结果中的均匀效应。

在表 23.7 中，可以观察到 $F_n$ 和 $e_n$ 与 DCV 不一致。这表明归一化对 $F$ 和 $\epsilon$ 没有太大帮助。原因是 $F$ 的提出的下界和 $\epsilon$ 的上界不够紧。事实上，由于复杂的优化方案，$F$ 和 $\epsilon$ 的归一化非常具有挑战性。
