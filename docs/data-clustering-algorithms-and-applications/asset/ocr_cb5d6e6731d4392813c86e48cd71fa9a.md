# A Survey of Partitioning and Hierarchical Clustering Algorithms

K-modes is a nonparametric clustering algorithm suitable for handling categorical data and optimizes a matching metric (L_0 loss function) without using any explicit distance metric. The loss function here is a special case of the $L_p$ norm where $p$ tends to zero. As opposed to the $L_p$ norm which calculates the distance between the data point and cluster vectors, the function in K-modes clustering works as a metric and the number of mismatches to estimate the similarity between the data points. The K-modes algorithm is described in detail in Algorithm 15. As K-means, this is also an optimization problem and this method cannot guarantee a global optimal solution.

# Algorithm 15 K-Modes Clustering

+   1: Select initial modes.
2: repeat
3: Form K clusters by assigning all the data points to the cluster with the nearest mode matching.
4: Recompute the modes of the clusters.
5: until Convergence is met.

# 4.2.4.4 Fuzzy C-Means Clustering

This is popularly known as Fuzzy C-Means clustering. Performing hard assignments of points to clusters is not feasible in complex datasets where there are overlapping clusters. To extract such overlapping structures, a fuzzy clustering algorithm can be used. In fuzzy clustering algorithm (FCM) [12, 4], the membership of points to different clusters can vary from 0 to 1. The SSE function for FCM is presented in Equation (4.12):

```
$$SSE(C) = \sum_{k=1}^K \sum_{x_i \in C_k} w_{sik}^\beta ||x_i - c_k||^2$ (4.12)
```

```
$$w_{sik} = \frac{1}{\sum_{j=1}^K (\frac{||x_i - c_k||}{||x_i - c_j||)^\beta}}$ (4.13)
```

```
$$c_k = \frac{\sum_{x_i \in C_k} w_{sik}x_i}{\sum_{x_i \in C_k} w_{sik}}$ (4.14)
```

Here $w_{sik}$ is the membership weight of point $x_i$ belonging to $C_k$. This weight is estimated during the update step of fuzzy c-means. The weighted centroid according to the fuzzy weights for $C_k$ is calculated ($c_k$). The basic algorithm works similarly to K-means where the algorithm minimizes the SSE iteratively by updating $w_{ijk}$ and $c_k$. This process is continued until the convergence of clusters. As in K-means, the FCM algorithm is sensitive to outliers and the final solutions obtained will correspond to the local minimum of the objective function. There are further extensions of this algorithm in the literature such as Rough C-means [34] and Possibilistic C-means
