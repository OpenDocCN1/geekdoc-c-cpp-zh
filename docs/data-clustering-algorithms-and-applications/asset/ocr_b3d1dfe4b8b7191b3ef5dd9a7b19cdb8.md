# 3.4.1 Probabilistic Latent Semantic Analysis

Probabilistic Latent Semantic Analysis (PLSA) [35, 36] is a statistical model for the analysis of co-occurrence data, which has been used in many applications, such as information retrieval, natural language processing, and machine learning from text.

The basic idea of PLSA is to treat the co-occurrences of words and documents as observations from a mixture where each component (i.e., aspect or topic) is a distribution over words, and the proportions of different components correspond to the probabilities. In PLSA, an unobserved latent variable $z_k \in \{z_1, \dots, z_K\}$ is associated with the observed word $w_j \in \{w_1, \dots, w_M\}$. Let us introduce the following probabilities: $p(d_i)$ denotes the probability that a word will be observed in a specific document $d_i$, $p(w_j|z_k)$ is used to denote the conditional probability of a particular word $w$ conditioned on the unobserved latent variable $z_k$, and $p(z_k|d_i)$ denotes the mixing probability for document $d_i$ to choose the $k$-th component $z_k$ such that $\sum_{k=1}^K p(z_k|d_i)= 1$. Formally, the joint probability of generating an observation pair $(d_i, w_j)$ can be expressed as

```
p(d_i, w_j) = p(d_i)p(w_j|z_k) = p(d_i)\sum_{k=1}^K p(w_j|z_k)p(z_k|d_i). (3.33)
```

Note that there is a conditional independence assumption, i.e., $d_i$ and $w_j$ are independent conditioned on the latent variable. The graphical representation of PLSA is shown in Figure 3.5. From the generative process of view, an observation pair $p(d_i, w_j)$ could be generated by the following:

+   (a) select a document $d_i$ with probability $p(d_i)$,
(b) pick a latent component (i.e., aspect) $z_k$ with probability $p(z_k|d_i)$,
(c) generate a word $w_j$ with probability $p(w_j|z_k)$.

For a collection of documents $C$, we make the assumption that all co-occurrences of $d_i$ and $w_j$ in the collection are independent identically distributed. Following this likelihood principle, parameters can be determined by maximizing the log-likelihood of a collection as follows:

```
l(C) = \sum_{i=1}^N \sum_{j=1}^M n(d_i,w_j)log p(d_i,w_j) (3.34)\nl= \sum_{i=1}^N n(d_i)log p(d_i) + \sum_{i=1}^N \sum_{j=1}^M \sum_{k=1}^K n(d_i,w_j)log p(w_j|z_k)p(z_k|d_i),
```
