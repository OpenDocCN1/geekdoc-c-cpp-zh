# VI Variation of Information (VI)

VI is another information-theoretic distance measure proposed for cluster validation [44, 45] and is defined as follows:

```
$$\Phi^{(VI)}(\lambda^{(a)}, \lambda^{(b)}) = H(\lambda^{(a)}) + H(\lambda^{(b)}) - 2I(\lambda^{(a)}, \lambda^{(b)})$$
```

It turns out that VI is a metric. Its original definition is not consistent if data sets of different sizes and clusters with different number of clusters are considered. Therefore, several normalized versions of VI have been proposed. The one proposed by [37] takes the following form:

```
$$\Phi^{(NVI)}(\lambda^{(a)}, \lambda^{(b)}) = 1 - \frac{I(\lambda^{(a)}, \lambda^{(b)})}{max(H(\lambda^{(a)}), H(\lambda^{(b)}))}$$
```

which is again metric. However, the one proposed by Wu et al. [68] is not a metric and takes the following form:

```
$$\Phi^{(NVI)}(\lambda^{(a)}, \lambda^{(b)}) = 1 - \frac{2I(\lambda^{(a)}, \lambda^{(b)})}{H(\lambda^{(a)}) + H(\lambda^{(b)})}$$
```

Both of these measures lie between 0 and 1. Note that one could also define a distance measure from NMI just using its 1-complement. However, such distance measure is not metric.

Vinh et al. [50] empirically showed that RI, the information-theoretic indices do not attain any constant baseline. The problem is more severe when the number of clusters is comparable to the number of data points. With increase in the number of clusters, the expected values of the indices either increase (for NMI) or decrease (for VI). Therefore, if one needs to make a decision based on the observed values of the indices, on average, a clustering solution with more (or fewer for VI) clusters will unjustifiably be preferred.

Therefore, following the generalized suggestion for correction by given in Equation 22.3, Vinh et al. [50] proposed to correct these measures with the expected value of the mutual information of the solutions and empirically showed the invariance of the measure w.r.t the number of clusters. The expression for the expected value of the mutual information under the permutation model is given

```
$$\E[I(S_a, S_b)] = \sum_{h_a=min(n_a^{(a)}, n_a^{(b)})}^{h_a=max(n_a^{(a)}, n_a^{(b)})} \frac{n_{h_a}}{n} \log(\\frac{n_{h_a}}{n_{h_a}^{(a)}n_{h_a}^{(b)}}) - \frac{n_{h_a}^{(a)}!n_{h_a}^{(b)}!}{(n-h_a^{(a)})!(n-h_a^{(b)})!}}{n_{h_a}!n_{h_a}^{(a)}!n_{h_a}^{(b)}!}(n-h_a)!(n-h_a)! - \frac{n_{h_a}}!(n-h_a^{(a)})!(n-h_a^{(b)})!}{n_{h_a}!n_{h_a}^{(a)}!n_{h_a}^{(b)}!}(n-h_a)!(n-h_a)! - n_{h_a}!(n-h_a)!/(n-1!)!$$
```

However, if the ratio of the number of data points and the number of clusters is more than 100 for both solutions, empirical studies show that $\E[I(S_a, S_b)]$ is close to zero, and hence, no adjustment for chance is necessary. Unfortunately, with such adjustment, none of the distances is a metric anchor. Therefore, depending on the applications, one needs to make a choice between the metric property and the zero baseline property.
