The global approach prunes the feature space by selecting a set of independent subsequences, where dependency is defined as the overlap between the sequences or as the overlap of their support locally from each of the sequences. On the other hand, the local approach finds independent features which are independent if they are supported by a nonoverlapping segment of the corresponding sequences. Once the feature set is defined, we use a k-means algorithm to cluster the sequences.

A more sophisticated variant of the subsequence-based method was proposed in [111]. In this paper, the authors introduce the notion of frequent subsequence (FSS) and represent each sequence by a collection of those FSSs. Intuitively, an FSS is a keyword that can be viewed as a discriminating feature for clustering the input data sequences. However in this, the authors use a d-idf kind of weighting to assign to each of these FSSs. They also present an effective method that mines all the FSSs from the sequence data. The final clustering has two stages. The first stage generates microclusters by roughly grouping the sequences with a shared FSS. Typically, the number of microclusters is larger than the desired number of clusters, so a second stage is used to merge the microclusters using a hierarchical clustering method, until the desired number of clusters is obtained.

# 16.4.2.2 Graph-Based Clustering

A graph-based sequence clustering method represents the sequences in a similarity graph, where a vertex represents a sequence and an edge represents the similarity relation between the corresponding pair of sequences. In such representation, a partition of the similarity graph represents the clustering of the input sequences. The crucial requirement in a graph-based sequence clustering method is to obtain the similarity graph in an efficient manner. A brute-force approach to obtain a similarity graph computes the similarity values between all (n²) pairs of sequences, where n is the number of sequences and then uses a user-defined threshold to add edges between sequences in similarity graph. Clearly this is inefficient, as it requires to compute O(n²) scores, so many graph-based sequence clustering algorithms use an efficient method for similarity graph construction. If a similarity graph is obtained, one of the available graph-clustering methods [90] can be used to obtain the desired clustering.
