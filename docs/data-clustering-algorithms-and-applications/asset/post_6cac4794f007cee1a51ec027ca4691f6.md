
## Semisupervised Clustering

### 20.2.5 Semisupervised Clustering Based on Nonnegative Matrix Factorization

In [29], a Nonnegative Matrix Factorization (NMF) framework is proposed for both consensus clustering and semisupervised clustering. For the purposes of this chapter, we will focus on the semisupervised clustering process. The main contribution of [29] is to show how semisupervised k-means and semisupervised kernel A-means can be approached as an NMF problem.

The authors consider an indicator matrix $H = [h_1, \dots, h_k]$ with

```
$h_k = [0, \dots, 0, 1, \dots, 0, 0]^T / n_k^{1/2}, \quad (20.13)$
```

where the nonzero entries in $h_k$ represent the points belonging to cluster $k$, and $n_k$ denotes the number of points in [29]. We show that the k-means clustering objective be expressed as

```
$$\max_{H^T H \ge 0} J_k = Tr(H^T W H), \quad (20.14)$$
```

where $w_{ij} = x_i^T x_j$ for k-means and $w_{ij} = \phi(x_i)^T \phi(x_j)$ for kernel k-means. By encoding must-link and cannot-link constraints with indicator matrices $A$ and $B$, the authors show that the semisupervised k-means algorithm can be viewed as an optimization problem of the form:

```
$$\max_{H^T H \ge 0} Tr(H^T W H + \alpha A^T W H - \beta B^T H), \quad (20.15)$$
```

Let $W^+ = W + \alpha \ge 0, W^- = \beta B$, and removing the orthogonality constraint, a relaxed version of the optimization problem can be expressed as

```
$$\max ||(W^+ - W^-)||_F^2, \quad (20.16)$$
```

This is an objective function where $(W^+ - W^-)$ is approximated by $HH^T$ with nonnegativity constraints on $H$. Related problems are widely studied in the context of NMF, and the above problem can be solved with updates of the form

```
$H_{ik} = H_{ik} \sqrt{\frac{(W^+H)_{ik}}{(W^-H)_{ik}}}, \quad (20.17)$
```

The authors provide a proof of convergence as well as correctness. The NMF approach performs favorably in comparison to certain existing algorithms in the literature [29]. In [29], the SSC problem is posed as a semidefinite optimization problem which incorporates constraints. Conceptually, this approach is not too different from [9], where the constraints are estimated and co-variance matrices are estimated in an iterative fashion. In [29] a decomposition of $(W^+ - W^-)$ is estimated with $W$ metric-based aspects. As such [29] can also be combining constrained-based and metric-based aspects.

## 20.3 Semisupervised Graph Cuts

In this section, we discuss SSC with graph-based representations, with focus on semisuvised graph-cuts. The key difference between the methods in Section 20.2 and the ones considered here is that the dataset is in the form of a similarity graph $G$ among data points, rather than feature vectors corresponding to each data point.

# Data Clustering: Algorithms and Applications

We start by reviewing some problems and concepts relevant to unsupervised graph cuts. Let $G=(V,E)$ be a weighted undirected graph with weight matrix $W$. If $V_1, V_2$ is a partitioning of $V$, i.e., $V_1 \cap V_2 = \emptyset, V_1 \cup V_2 = V$, then the value of cut by the partitioning $(V_1, V_2)$ is given by

```
cut(V_1, V_2) = \sum_{v_i \in V_1, v_j \in V_2} w_{ij}. \quad (20.18)
```

The minimum cut problem is to find a partitioning $(V_1, V_2)$ such that $cut(V_1, V_2)$ is minimized. Due to practical reasons, one often works with a normalized cut, such as the ratio-cut [25] or normalized-cut [34], which encourage the partitions $V_1, V_2$ to be more balanced. The objective for ratio-cut is

```
Rcut(V_1, V_2) = \frac{cut(V_1, V_2)}{|V_1| \cdot |V_2|} \quad (20.19)
```

The objective for normalized-cut is similar; however, we consider the cuts by the weight of the edges in each partition. For any subset $H \subseteq V$, let $Vol(H) = \sum_{i \in H} D_{ii}$ where $D_{ii} = \sum_{j} w_{ij}$, we have

```
Ncut(V_1, V_2) = \frac{cut(V_1, V_2)}{Vol(V_1)} \cdot \frac{cut(V_1, V_2)}{Vol(V_2)} \quad (20.20)
```

There are extensions of the above formulation for k-cuts [36], but we use the 2-cut setting in this chapter for ease of exposition. Graph Laplacians: Next, we review graph Laplacians, which will play an important role in our exposition. For an undirected graph $G=(V,E)$ with weights $w_{ij} \ge 0$, let $D$ be a diagonal matrix with $D_{ii} = \sum_j w_{ij}$. In the existing literature, there are three related matrices called graph Laplacian, and these three matrices are intimately related, we will use all of them in our analysis. The unnormalized graph Laplacian is defined as

```
L_u = D - W \quad (20.21)
```

The following property of the unnormalized graph Laplacian is important for our analysis: for $f \in \mathbb{R}^n$, we have

```
f^T L_u f = \frac{1}{2} \sum_{i,j} w_{ij}(f_i - f_j)^2 \quad (20.22)
```

The matrix $L_u$ is symmetric and positive definite. There are also two normalized Laplacians in the literature:

```
L_r = D^{-1}L_u \quad (20.23)
```

```
L_s = D^{-1/2}L_uD^{-1/2} \quad (20.24)
```

For the symmetrically normalized graph Laplacian, the following property holds. For any $f \in \mathbb{R}^n$, we have

```
f^T L_s f = \frac{1}{2} \sum_{i,j} w_{ij}(\frac{f_i}{\sqrt{D_{ii}}} - \frac{f_j}{\sqrt{D_{jj}}})^2 \quad (20.25)
```

We refer the reader to [30, 17, 36] for details on Laplacians and their properties. Semisupervised Graph Cuts: The graph-cut problems above are unsupervised; given supervision on some nodes, one can construct semisupervised graph-cut problems that represent the given information. In particular, labels may indicate that nodes with the same label should remain within the same subgraph after the cut. The same information can be conveyed by specifying must-link relationship between pairs (or subsets) of nodes so that must-linked nodes should ideally belong to the same subgraph. For ease of exposition, we consider the 2-cut setting. The extension to k-cuts is straightforward, and we report empirical results on such problems in Section 20.6.

## Semisupervised Clustering

Let $A_1$ be the subset of vertices with cluster 1, and $A_2$ be the subset with cluster 2. Clearly, $A_1$ and $A_2$ are disjoint subsets of $V$. The semisupervised unnormalized cut problem can be posed as follows: Finding a partitioning $(V_1, V_2)$ such that $cut(V_1, V_2)$ is minimized subject to the constraint $A_1 \subseteq V_1 \subseteq V_2$. To achieve balanced results, we also consider semisuvised versions of the ratio-cut (or normalized-cut) problem. In particular, finding a partitioning $(V_1, V_2)$ such that $Rcut(V_1, V_2)$ is minimized subject to the constraint $A_1 \subseteq V_1 \subseteq V_2$. Similarly, one can pose the semisupervised normalized-cut using $Ncut(V_1, V_2)$ instead of $Rcut(V_1, V_2)$ above. The problems outlined above are NP-hard, and there has been some work on developing polynomial-time approximation schemes (PTASs) for related problems [12, 13].

### 20.3.1 Semisupervised Unnormalized Cut

Consider a graph partitioning by $V_1$ and $V_2$. Let $f$ be defined as

```
$f_i = \begin{cases} 1 & \text{if } v_i \in V_1 \\ -1 & \text{if } v_i \in V_2 \end{cases}$
```

From Equation 20.22, we now have

```
$f^T L_u f = \frac{1}{2} \sum_{i,j} (f_i - f_j)^2 = cut(V_1, V_2).
```

For any given subset $A_1, A_2$ which constitute the semisuper, we construct constraints on the labels as $y_i = +1$ if $v_i \in A_1$ and $y_i = -1$ if $v_i \in A_2$. Then, for all nodes in the labeled set, i.e., $v_i \in A_1 \cup A_2 = \mathcal{L}$, we have the constraint that $f_i = y_i$. Then, the semisupervised unnormalized cut problem can be written

```
$\min_{V_1, V_2} f^T L_u f, \text{s.t. } \forall v_i \in \mathcal{L}, f_i = y_i.$
```

By relaxing the problem such that $f \in \mathbb{R}^n$ and noting that the constraint is equivalent to $\sum_{i=1}^n (f_i - y_i)^2 \leq 0$, we obtain the following formulation:

```
$\min_{f \in \mathbb{R}^n} f^T L_u f, \text{s.t. } \sum_{i=1}^n (f_i - y_i)^2 \leq 0$.
```

### 20.3.2 Semisupervised Ratio Cut

In the context of the ratio-cut problem, consider again a graph partitioning given by $V_1$ and $V_2$. Let $f$ be defined

```
$f_i = \begin{cases} +\sqrt{|V_2|/|V_1|} & \text{if } v_i \in V_1 \\ -\sqrt{|V_1|/|V_2|} & \text{if } v_i \in V_2 \end{cases}$
```

Now, following Equation 20.22, we can express

```
$f^T L_u f = \frac{1}{2} \sum_{i,j} w_{ij}(f_i - f_j)^2 = |Rcut(V_1, V_2)|$.
```
