# Data Clustering: Algorithms and Applications

The following theorem shows that NMF is inherently related to the K-means clustering algorithm [35].

# Theorem 1 G-orthogonal NMF,

```
$$\min_{F\geq 0, G\geq 0} \|X - FG^T\|^2, \text{s.t.} } G^T G = I.$
```

is equivalent to K-means clustering. This holds if F and G have many-signed entries.

We can understand relationship in this way [35]. Let $C = (c_1, \dots, c_k)$ be the clusters obtained via K-means clustering. Let $H$ be the cluster indicators; i.e., $h_{ki} = 1$ if $x_i \in c_k$, $h_{ki} = 0$ otherwise. We can write the K-means cluster objective as $\sum_{k=1}^k \sum_{i} h_{ki} \|x_i - c_k\|^2 = \|X - CH^T\|^2$. From this analogy, NMF F has the meaning of cluster centroids and G is the cluster indicator [35]. K-means and NMF have the same objective but with different constraints.

Indeed, the K-means objective function can be expressed in such a way: if we ignore thenegativity constraint while keeping the orthogonality constraint, the principal component is the solution [34, 137]. On the other hand, if we ignore the orthogonality while keeping the nonnegativity NMF is the solution.

# 7.2.2 NMF and Probabilistic Latent Semantic Indexing

Probabilistic Latent Semantic Indexing (PLSI) is an unsupervised learning method based on statistical class models and has been successfully applied to document clustering [55], (PLSI is further developed into a more Comprehensive Dirichlet Allocation model [9].) PLSI maximizes the likelihood

```
$J_{PLSI} = \sum_{k=1}^k \sum_{j} X(w_i, d_j) \log P(w_i, d_j),$
```

where the joint occurrence probability is factorized (i.e., parameterized or approximated )

```
$P(w_i, d_j) = \sum_{k} P(w_i, d_j|z_k)P(z_k) = \sum_{k} P(w_i|z_k)P(d_j|z_k)P(z_k),$
```

assuming that $w_i$ and $d_j$ are conditionally independent given $z_k$. The following theorem shows the equivalence between NMF and PLSI [39, 40]:

# Theorem 2 PLSI is identical to NMF with I-divergence. (A) The objective function of PLSI is identical to the objective function of NMF using the I-divergence. (B) We can express $FG^T = F\hat{D}G^T$ where $F,\hat{D},G^T$ satisfy the probability normalization: $\sum_{i=1}^n F_{ik}=1, \sum_{j=1}^m G_{jk}=1, \sum_{k=1}^k \hat{D}_{kk}=1$. The NMF update and the EM algorithm in training PLSI are alternative methods to optimize the same objective function [3]. The relationships between NMF and PLSI have also been studied in [48].

# 7.2.3 NMF and Kernel K-means for Spectral Clustering

For a square symmetric matrix $W$, we would expect a $W \approx HH^T$ decomposition. The following theorem points out its usefulness for document clustering [35].

# Theorem 3 Orthogonal symmetric NMF

```
$$\min_{H\geq 0} \|W - HH^T\|^2, \text{s.t.} } H^T H = I.$
```

is equivalent to kernel K-means clustering.
