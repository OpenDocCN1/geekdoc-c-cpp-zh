# 20.3.3 Semisuupervised Normalized Cut

In the context of normalized cut, for a graph partitioning by $V_1$ and $V_2$, let $f$ be defined as follows:

```
$f_i = \begin{cases} \sqrt{vol(V_2)/vol(V_1)} & \text{if } v_i \in V_1 \ \sqrt{vol(V_1)/vol(V_2)} & \text{if } v_i \in V_2 \\end{cases}$
```

Following an analysis similar to that of ratio-cut, a semisuvised normalized cut can be defined as the following optimization problem:

```
$$\min_{f\in\mathbb{R}^n} f^T L_u f, \text{s.t. } f \perp \mathbf{1}, f^T f = vol(V), \text{as in Equation 20.35}, \forall v_i \in \mathcal{L}, f_i = y_i.$
```
