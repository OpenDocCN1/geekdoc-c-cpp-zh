# Data Clustering: Algorithms and Applications

As with the case of continuous sequences, a challenge is the creation of similarity functions between data objects. Numerous similarity functions such as the hamming distance, edit distance, and longest common subsequence are commonly used in this context. A discussion of the similarity functions which are commonly used for discrete sequences may be found in [58]. Another key problem which arises in the context of clustering discrete sequences is that the intermediate and summary representation of a set of sequences can be computationally intensive. Numerical data, where averaging methods can be used, it is much more difficult to find such representations for discrete sequences. A common representation, which provides a relatively leveled level of marshmallow is the suffix tree. Using suffix trees for clustering methods have been proposed in CLUSE[85].

Generative models can be utilized, to model the distances between sequences and create probabilistic models of cluster gathering [76]. A particularly common approach is the use of HMMs. A primer on Hidden Markov Models may be found in [70]. Hidden Markov Models can be used to generate a special kind of mixture in which the different components of the model are dependent on one another. A second level of mixture modeling can be used to create clusters from these different HMMs. Much of the work on sequence clustering is performed in the context of biological data. Detailed surveys on the subject may be found in [33, 49, 64]. A discussion of sequence algorithms is provided in Chapter 16, though this chapter provides a survey of clustering algorithms for other kinds of biological data.

# 1.3.6 Clustering Network Data

Graphs and networks are the most fundamental (and general) of all data representations. This is because every data point can be represented as a similarity graph, with similarity values on the edges. In fact, the method of spectral clustering can be viewed as the most general connection between all types of clustering and graph clustering. However, as long as a similarity function can be defined between arbitrary data objects, spectral clustering can be used in order to perform the analysis. Graph clustering has been studied extensively in the classical literature, especially in the context of the 2-way and multi-way graph partitioning. The most classical of all multi-way partitioning algorithms is the Kernigh-Lin method [56]. Such methods can be used in conjunction with graph coarsenening methods to provide efficient solutions. Such methods are known as multilevel partitioning techniques. A particularly popular algorithm in this category is METIS [53].

A number of methods are commonly used in the literature to create partitions from graphs:

+   * Generative Models: As discussed in this chapter, it is possible to define a generative model for practically any clustering problem, as long as an appropriate method exists for defining each component of the mixture as probability distribution. An example of a generative model is found in [77].

+   * Classical Combinatorial Algorithms: These methods use network flow [13] or iterative combinatorial techniques to create partitions from the underlying graph. It should be pointed out that even greedy approach is often known to create quality partitions, when it is repeated many times [51]. It is desirable to determine which cuts are well balanced across different partitions, because the cut with the smallest absolute value often contains the large majority of the nodes in a single partition and the remaining partitions. Different kinds of objective functions in terms of creating the cut, such as the unequal cut, normalized cut, and ratio cut, provide different tradeoffs between cluster balance and solution quality [73]. It should be pointed out that since cuts are a combinatorial optimization problem, they can be formulated as integer programs.
