It is important to note that the equivalence of the UK-means method to a deterministic algorithm is based on the approximation of treating each cluster center (intermediate steps) as a deterministic entity. In practice, some of the dimensions may be much uncertain than others in the clustering process over most of the data points. In such cases, the cluster centroids should not be treated as deterministic entities. Some of the methods for uncertain data clustering such as those in [8] also treat the cluster centroids as uncertain entities in order to enable more computations. # 18.4.3 Clustering Uncertain Data with Voronoi Diagrams

The work in [48] uses minimum bounding boxes of the uncertain objects in order to compute distance bounds for effective pruning. However the use of minimax pruning sometimes be quite restrictive in efficiently characterizing the uncertain object, which may have arbitrary shape. An approach which is based on voronoi diagrams, also improves the UK-means algorithms by computing the voronoi diagrams of the current set of cluster representatives [37]. In each cell the voronoi diagram is associated with a cluster representative. Note that each cell in this voronoi diagram has the property that any point in cell is closer to the cluster representative for that cell than any other representative. Therefore, if the MBR of an uncertain object lies completely inside a cell, then it is not necessary to compute its distance to any other cluster representative. Similarly, for any pair of cluster representatives, the perpendicular bisector between the two is a hyperplane which is equidistant from and is easily derivable. In the event that the MBR of an uncertain object lies completely on one side of the bisector, we can deduce that the cluster representatives are closer to the uncertain object than the other. This allows us to prune one of the representatives.

As in [48], this work focuses on pruning the number of expected distance computations. It has been shown in [37] that the pruning of the voronoi method is greater than the minimax method proposed in [48]. However, the work in [37] does not compare its efficiency to those in [44], which are based on the equivalence of UK-means to a deterministic algorithm and do not require any expected distance computations at all. It would seem that any deterministic method for k-clustering (as proposed in the method of [44]) should be much more efficient than a method based on pruning the number of expected distance computations, no matter how effective the pruning method might be.

# 18.4.4 Approximation Algorithms for Clustering Data

Recently, techniques have been designed for approximation algorithms for uncertain clustering in [20]. The work extends the k-mean and k-median version of the problems. Bicteria algorithms are designed for each of these cases. One algorithm achieves $(1+)$-approximation to the best uncertain k-centers with the use of $O(k \cdot e^{-1} \cdot \log^2(n))$ centers. The second algorithm picks $2k$ centers and achieves a constant-factor approximation.
