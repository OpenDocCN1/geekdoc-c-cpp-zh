```
$J = \sum_{n=1}^N \sum_{k=1}^K r_{nk} \|x_n - \mu_k\|^2, \quad (3.30)$
```

represents the sum of the square distances of each data point to its associated vector $\mu_k$. Our goal is to find values for the $\{r_{nk}\}$ and $\{\mu_k\}$ to minimize $J$. We can solve $K$-means through an iterative procedure in which iteration involves two successive steps corresponding to EM algorithm as follows,

Choose some initial values for mean vectors $\{\mu_k\}$, then iterate through the two phases until convergence:

- E-step): Assign each data point to the nearest cluster by minimizing $J$ with respect to the $r_{nk}$ and keeping the $\mu_k$ fixed,
- M-step: Update mean vectors for clusters by minimizing $J$ with respect to the $\mu_k$ and keeping $r_{nk}$ fixed.

More formally, we calculate $r_{nk}$ in the E-step,

```
$r_{nk} = \begin{cases} 1 & \arg\min_j \|x_n - \mu_j\|^2 \\ 0 & \text{otherwise}, \end{cases}$
```

and update $\mu_k$ in the M-step,

```
$$\mu_k = \frac{\sum_n r_{nk}x_n}{\sum_n r_{nk}}$$
```

The two phases of reassignment data points to clusters and recomputing the cluster means are repeated until there is no further change in the assignments or other convergence criteria are satisfied.

As described, the $K$-means algorithm can be solved through iterative EM algorithm, which shows that a close similarity between the $K$-means algorithm and the EM algorithm. Actually, we can derive the $K$-means algorithm as a particular case of EM for Gaussian mixtures. The major difference is that the $K$-means algorithm performs a hard assignment of data points to clusters, while the EM algorithm makes a soft assignment based on the posterior probabilities. Consider a Gaussian mixture model with common covariance matrices by $\epsilon I$, where $\epsilon$ is a variance parameter. The Gaussian distribution can be written as

```
$p(x|\mu_k, \Sigma_k) = \frac{1}{(2\pi\epsilon)^{1/2}} \exp\{-\frac{1}{2\epsilon}\|x - \mu_k\|^2/2\epsilon\},\. \quad (3.31)$
```

Based on Equation (3.28), the responsibility $\gamma(z_{nk})$ is given by

```
$$\gamma(z_{nk}) = \frac{\pi \exp(-\|x_n - \mu_k\|^2/2\epsilon)}{\sum_j \pi \exp(-\|x_n - \mu_j\|^2/2\epsilon)}$
```

If we consider the limit $\epsilon \to 0$, the responsibility $\gamma(z_{nk})$ for the data point $x_n$ will all go to zero except for the cluster $j$ with the smallest $\|x_n - \mu_j\|^2$, such that the responsibility becomes binary. Thus, we obtain a hard assignment of data points to clusters, as in $K$-means algorithm, so that $\gamma(z_{nk}) \to r_{nk} \in \{0, 1\}$. In this case, the EM re-estimation equation for the $\mu_k$ given by Equation (3.12) blows down. Therefore, as we can see in this limit, the EM algorithm for Gaussian mixtures is precisely equivalent to the $K$-means algorithm.

# Probabilistic Models for Clustering

Bernoulli Mixture Model: We derive the EM algorithm for maximizing the likelihood function for estimating the parameters of the Bernoulli mixture model $\Theta=\{\mu, \pi\}$. In the case of the Gaussian mixture, let us introduce a latent variable $z$ associated with each instance of $x$. The expectation of the complete log-likelihood with respect to the posterior distribution of the latent variable is

```
$Q(\Theta, \Theta^{(t)}) = \sum_{n=1}^N \sum_{k=1}^K \gamma(Z_{nk}) \log \pi_k p(X_n|\mu_k) \quad (3.32)$
= \sum_{n=1}^N \sum_{k=1}^K \gamma(Z_{nk}) [\log \pi_k + \sum_{i=1}^D [X_{ni} \log \mu_{ki} + (1 - X_{ni}) \log (1 - \mu_{ki})]]$
```

where $\gamma(Z_{nk})$ is the posterior probability, or responsibility, of component $k$, given $x_n$ and the current setting of parameters.

The EM algorithm proceeds iteratively in two steps. In the E-step, the posterior probability, or responsibility, of component $k$, given $x_n$, and the current setting of parameters, is estimated using Bayes' theorem, which is written in the form

```
$\gamma(Z_{nk}) = \frac{\pi_k p(X_n|\mu_k)}{\sum_{j=1}^K \pi_j p(X_n|\mu_j)}$
```

In the M-step, we maximize the above log-likelihood function with respect to the parameters $\mu_{ki}$ and $\pi_k$. By setting the derivative of (3.32) with respect to $\mu_{ki}$ to zero and rearrange the terms, we get

```
$\mu_{ki} = \frac{\sum_{n=1}^N \gamma(Z_{nk})X_{ni}}{\sum_{n=1}^N \gamma(Z_{nk})}$
```

For the maximization with respect to $\pi_k$, we use a Lagrange multiplier to enforce the constraint $\sum_k \pi_k = 1$, and then we obtain

```
$\pi_k = \frac{\sum_{n=1}^N \gamma(Z_{nk})}{N}$
```

To start EM, initial values for the parameters are required. Provided that a nonpathological starting point is used, the EM algorithm always increases the loglikelihood, and the algorithm is guaranteed to converge to a local maximum. The mixing probabilities are initialized to $\pi_k = 1/K$, and the parameters $\mu_{ki}$ are set to random values uniformly in the range (0.25, 0.75) and then normalized to satisfy the constraint $\sum_i \mu_{ki}$.

### 3.3.3 Limitations of the EM

The popularity of the EM algorithm is due to its simple implementation with guaranteed monotone increase during training. However, there are several well-known limitations associated with the EM. It converges to a local maximum and its solution is highly dependent on initialization; one strategy is to use multiple starts [33, 46], and the other one is to initialize by clustering algorithms [65]. Additionally, the EM algorithm assumes that the number of components for modeling the distributions is known. In many applications, the optimal number of components is unknown and has to be determined. Moreover, EM is known to converge slowly in some situations, which has received much attention recently. Many algorithms have been proposed to address the problems of convergence and the initialization issue, such as deterministic annealing (DA) versions of EM, component-wise EM algorithm [77], genetic-based EM algorithms [44, 57].

### 3.3.4 Applications of the EM Algorithm

The EM algorithm turns out to be a general way of maximizing the likelihood when variables are unobserved and, hence, useful for other applications besides mixture models. There are two main applications of the EM. The first occurs when the data has missing values, due to problems or limitations of the observation process. The second occurs when optimizing the likelihood function is analytically intractable but can be simplified by assuming the existence of values for added (hidden) parameters. The latter application is more common in the computational pattern recognition community. The range of potentially useful applications is broader than presented here, including, for instance, specialized variance components, problems of missing values in general parametric models, and models with continuous latent variables. A complementary overview of the applications is in [23, 7].
