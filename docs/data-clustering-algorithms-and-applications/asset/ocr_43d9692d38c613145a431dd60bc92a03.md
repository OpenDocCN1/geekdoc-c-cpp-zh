Next, we analyze the individual terms in the expression. We note that the value of $X$ is a random variable, whose expected value is equal to its instantiation, and it has an error the $j$th dimension is equal to $\psi_j(\bar{X})$. Therefore, the expected value of $E[|\bar{X}|^2]$ is given by

```
$E[|\bar{X}|^2] = (E[X])^2 + \sum_{j=1}^d (\psi_j(\bar{X}))^2 = \sum_{j=1}^d x_j^2 + \sum_{j=1}^d(\psi_j(\bar{X}))^2$
```

Now, that the value of $E[Z]$ is equal to the $j$th dimension of the cluster $C$. This is given by the expression $CF1(C)_j/n(C)$, where $CF1(C)$ is the $j$th of the first order cluster component $CF1(C)$. Therefore, the value of $E[X \cdot Z]$ is given by the following expression:

```
$E[X] \cdot E[Z] = \sum_{j=1}^d x_j \cdot CF1(C)_j/n(C)$ (18.10)
```

The results above and Lemma 18.5.1 define the values of $E[|\bar{X}|^2]$, $E[|Z|^2]$, and $E[X \cdot Z]$. Note that all of these values occur in the right-hand of the following relation:

```
$v = E[|\bar{X}|^2] + E[|Z|^2] - 2E[\bar{X} \cdot Z]$ (18.11)
```

By substituting the corresponding values in the right-hand side of the above relation, we get

```
$v = \sum_{j=1}^d CF1(C)_j/n(C)^2 + \sum_{j=1}^d EF2(C)_j/n(C)^2 + \sum_{j=1}^d x_j^2 + \sum_{j=1}^d(\psi_j(\bar{X}))^2 - 2\sum_{j=1}^d x_j \cdot CF1(C)_j/n(C)$ (18.12)
```

The result of Lemma 18.5.2 establishes how the distance may be computed (in expected) using the error information in the data point $\bar{X}$ and the microcluster statistics of $C$. Note that this is an efficient computation which has $O(d)$ operations, which is asymptotically the same as the deterministic case. Since since distance function is the most repetitive of all operations in the clustering algorithm, and we would want it to be as efficient as possible.

While the expected distances can be directly used as a distance function, the uncertainty adds a lot of noise as possible in order to determine the most accurate clusters. This is done by computing the variance $\sigma_j^2$ along each dimension $j$. The computation of the variance can be done using the cluster feature statistics of the microclusters. The cluster feature statistics of all microclusters are added to create one global cluster feature. We note that this is a similarity value rather than a distance, since larger values imply greater similarity.
