Let us know that the statistical significance of subclusters (by Moise and Sander [101]), is not an antimonotonic property and does in general not allow for APRIORI-bottom-up approaches finding only meaningful (i.e., significant clusters).

**Hybrid Approaches.** It is our impression that the majority of approaches do not use the initial concepts any more, but pursue some hybrid partitioning [117, 133, 136, 87, 3, 102, 72]. In general, the result is neither a cluster partitioning overlap nor an enumeration of clusters in all subspaces. The problem definition may remain unclear and each approach defines its own goal. A fair comparison of the true merits of different algorithms remains difficult.

DOC [107] uses a global density threshold to define a subspace clusters of fixed size-$w$ containing at least $\alpha$ points. A random search algorithm is proposed to compute such clusters from a starting seed of points. A third parameter $eta$ specifies the balance between the number of points and the dimensionality of a cluster. This parameter also has problems with subclusters of significantly different dimensionality. Due to the simple clustering method, clusters may contain additional nodes (if $w$ is too large) that naturally belong to another cluster (if $w$ is too small). One run of DOC (with a certain probability) finding one subcluster from multiple clusters needed to be merged. DOC can be applied several times. If the assigned clusters to clusters not so excluded from subsequent runs, DOC can be considered as a pure clustering algorithm because each point is uniquely assigned to one cluster or none (if not assigned to a cluster). On the other hand, if the cluster points are not excluded from subsequent runs, the resulting clusters of multiple runs may overlap. Usually, DOC cannot produce all clusters in subspaces.

MINECLUS [135, 136] is based on an idea similar to DOC, but proposes a deterministic method to find an optimal cluster using a seed point points. They transform the problem into a frequent-set mining problem and employ a modified pattern tree growth method. Further heuristics are introduced to enhance efficiency and accuracy.

HISC [4] the advanced extension DISH [3] follow a similar idea as PreDeCon using a hierarchical clustering method. This way, hierarchies of subspace clusters can be discovered (i.e., the information of the subspace of a lower-dimensional cluster is composed of a subset of the attributes of a higher-dimensional cluster). The distance between points and clusters reflects the dimensionality of the subspace that is spanned by combining the corresponding subspace each cluster. In COH, the weighting is learned for each object, not for entire clusters. The learning of weights, however, is based on single attributes, not on the entire feature space. DISH uses an algorithm that is inspired by the density-based hierarchical clustering algorithm OPTICS. However, DISH extends the cluster ordering by OPTICS in order to find hierarchies of subspace clusters (a lower-dimensional subspace may be embedded in multiple higher-dimensional clusters.

HARP [133] is a hierarchical clustering algorithm similar to single-link clustering [126, 121] but does not produce a hierarchy of subspace clusters. Starting with singleton clusters, HARP iteratively merges clusters as long as the resulting cluster has a minimum number of relevant attributes. A relevance score is introduced for attributes based on a threshold that has harsh value and is progressively decreased when clusters grow in size. By design, HARP has problems finding low-dimensional clusters. The dendrogram can be cut at any level in order to produce a unique assignment of points to clusters.

SCHISM [120] mines subclusters rather than clusters; thus, it is not exactly a subspace clustering algorithm but solves a related problem: finds to for clusters. It employs a grid-like discretization of the database and applies a depth-first search with backtracking to find interesting subspaces.
