## 20.5.1 Nonlinear manifold Embedding

Manifold embedding methods obtain a lower dimensional representation of a given dataset that some suitable neighborhood structures are preserved. In this section we review three popular embedding methods and demonstrate that their semisvised generalizations solve a variant of the GL formulation.

Locally Linear Embedding (LLE): In LEE [32], the assumption is that each point in the high-dimensional space can be accurately approximated by a locally linear region. In particular, neighborhood densities are estimated by solving $\sum_i |f_i - \sum_j w_{ij}x_j|^2$, where $\sum_j w_{ij}=1$, $X_i$ is the set of neighboring points of $x_i$. Then $W$ is used to reconstruct the points in a lower dimensional space by solving:

```
$$\min_{f\in\mathbb{R}^n} ||f-\sum_j w_{ij}x_j||^2, \text{ s.t. f \perp \mathbf{1}, ||f||^2=n.$ (20.55)
```

$M = (I-W)^T(I-W)$, which is positive definite and can be viewed as an iterated Laplace operator [8], we can rewrite the objective function as

```
$$\min f^T M f, \text{ s.t. f \perp \mathbf{1}, ||f||^2=n.$ (20.56)
```

Laplacian Eigenmaps (LE): LE is based on the correspondence between the graph Laplacian and the Laplace Beltrami operator [8]. The symmetric weights between neighboring points are typically computed using the RBF kernel $w_{ij} = \exp(-||x_i-x_j||^2/\sigma^2)$. Then $W$ is used to reconstruct the points in a lower dimensional space by solving:

```
$$\min_{f\in\mathbb{R}^n} \sum_{i,j} w_{ij}(f_i-f_j)^2, \text{ s.t. f^T D f = 1.$$ (20.57)
```

Using (20.22), the objective function is $f^T L f$. Letting $g=D^{1/2}f$, with $M=L_s=D^{-1/2}LD^{-1/2}$ we can express the objective as

```
$$\min g^T M g, \text{ s.t. g \perp D^{1/2}, ||g||^2=1.$ (20.58)
```

Local Tangent Space Alignment (LTSA): In LTSA, the tangent space at each point is approximated using local neighborhoods, and a global embedding is obtained by aligning the local tangent spaces. If $X_i^N$ denotes the matrix of neighbors of $x_i$, then it can be seen [44] that the principal components of $X_i^N$ give an approximation to the tangent space of the embedding $f_i$. Let $g_1,...,g_k$ be the $k$ principal components for $X_i^N$. Let $G_i = e/\sqrt{k}[g_1,...,g_k]^T$. If $H_i$ are the indices of the neighbors of $x_i$, submatrices of the alignment matrix $M$ are computed as $M(X_i^N, \mathcal{N}) \leftarrow M(X_i^N, \mathcal{N}) + I-G_IG_i^T$ for $i=1,...,n$. Finally, using $M$, which is guaranteed to be positive semidefinite, an embedding is successfully obtained by minimizing the alignment cost:

```
$$\min f^T M f, \text{ s.t. f \perp \mathbf{1}, ||f||^2=n.$ (20.59)
```

We refer the reader to [44] for a detailed analysis of LTSA.

## 20.5.2 Semisvised Embedding

In this section, we consider two types of semisvised embedding and its relationship to graph-based clustering. The variants differ when they consider-- when they consider the constraints associated with the unsupervised embedding problem. As discussed in Section 20.5.1, there are typically two types of constraints: $f \perp A$, where $A=I$ or $D^{1/2}$, and $||f||^2=c$, a constant. Since the clustering is based on $(f_i)$, the norm constraint does not play any role and is ignored for our analysis. The two variants we consider based on whether $f \perp A$ is enforced or, in addition to the constraints from the partially labeled data.

### 20.5.2.1 Constrained Semisupervised Embedding

Following [43], we want to obtain an embedding $f=[f_e, f_u]^T$, where the exact embeddings of the first $\ell$ points are known and given by $y_\ell$. The objective for semisupervised embedding is given by

```
$$\min f^T M f, \quad s.t \quad f_e = y_\ell$$
```

where $M$ is a suitable positive definite matrix. Since $f_e$ is fixed, the problem can be cast in terms of block matrices

```
$$\min \begin{bmatrix} f_e \\ f_u \end{bmatrix}^T \begin{bmatrix} M_{ee} & M_{eu} \\ M_{ue} & M_{uu} \end{bmatrix} \begin{bmatrix} f_e \\ f_u \end{bmatrix}$$
```

Setting the first derivative to zero, one obtains

```
f_u = -M_{uu}^{-1}M_{ue}
```

In the context of label propagation for 2-clustering, we will have $y_i = +1$ or $y_i = -1$ for $i=1,...,ell$. In other cases, the labeled points are embedded to their cluster label, and the rest will be embedded while maintaining the neighborhood. For LLE, $M=(I-W)^T(I-W)$ and we call the label propagation algorithm LLELP. For LTSA, $M$ as discussed in Section 20.5.1, and the corresponding algorithm be called LTSALP. For LEP, since $M=L_u$, the unnormalized Laplacian, from Equation 20.62 we have

```
f_u = -L_{uu}^{-1}L_{ue}y_\ell = -(D_{uu}-W_{uu})^{-1}(D_{ue})y_\ell
```

where $D_{ue}=0$ as $D$ is diagonal matrix. Then the solution is exactly the same as for GF in Equation 20.4 implying the equivalence of GF and LEP.

### 20.5.2.2 Constrained Semisupervised Embedding

In this section, we consider embedding problems when orthogonality constraint of form $f \perp A$ is enforced. In particular, we consider the following problem:

```
$$\min f^T M f, \quad s.t \quad \sum(f_i-y_i)^2 \leq \varepsilon, \quad f \perp A$$
```

where $A=I$ for LLE and LTSA, and $A=D^{1/2}$ for LE. Let $\alpha$ and $\mu$ be the Lagrange multipliers for the two constraints, respectively. The first order necessary conditions obtained from the Lagrangian corresponding to (20.63)

```
f = (M+\alpha A)^{-1}(\alpha y+\mu A)
```

Since $I^T A^T f=0$, a direct calculation gives the optimal Lagrange multiplier by

```
$$\mu = -2\alpha \frac{I^T A^T(M+\alpha A)^{-1}y}{I^T A^T(M+\alpha A)^{-1}A}$$
```

The multiplier $\alpha$ can also be computed using existing results solving quadratic constrained programs (QCPs) with a single quadratic constraint [14]. For LLE, $M=(I-W)^T(I-W)$ and $A=I$, and we call the corresponding algorithm LLEPC. For LTSA, $M$ is discussed in Section 20.5.1 and $A=I$, and we call the corresponding algorithm LTSALPC. For as in Equation 20.58, $M=L_{sym}=D^{-1/2}WD^{1/2}$ and we call the corresponding algorithm LEPLC.

While the constraints can be relaxed to consider $\sum_{i=1}(f_i-y_i)^2 \leq \varepsilon$, we do not focus on the general case here.

## 20.6 Experimental Analysis

In this section, we provide an empirical evaluation of SSC with graph-based representations. Our experiments are divided into two parts: First, we compare seven methods on 14 benchmark data sets from their accuracy; we take a closer look at the performance of label propagation methods obtained from the perspective of semisvised manifold embedding. For the first set of experiments, we consider 6 standard methods: GF, LNP, CK, GWEM, TIRKE, and LG, as discussed in Section 20.4. In addition we use LTSALP, an approach based on semi-supervised embedding. For the second set of experiments, we consider the 6 embedding methods introduced in Section 20.5.

**Methodology:** We conducted experiments on the 8 UCI data sets: Hepatitis, Cancer, Pima, Wine, Glass, USS (1-4), and E and F. In fold set we also ran experiments on 6 well-known benchmark data sets. These are subsets of the 20Newgroup data set: Difference100, Similar100, Difference1000 and Same1000 [1]. Each dataset contains a subset of 3 groups with varying degrees of difficulty for clustering. Difference100 (1000) includes comp.altheism, res.baseball, and sci.space and are, hence, easy to cluster; Same100 (1000) includes comp.graph, comp.os-windows, comp.window.x and talk.politics, talk.politics.midlate, and talk.politics.misce are moderately difficult to cluster. Whereas Similar100 is more difficult to cluster. We also used the well-Classic-3 benchmark data set which contains 3893 entries, of which 1033 are from medical journals, 1460 are information retrieval papers. For each method and data set, we ran five-fold semisvised cross-validation. In particular, the training points were chosen from four folds with increasing number of labeled points, and the test error was measured on the fifth fold. All points were used to construct the neighborhood graph. Further, for each approach parameters, e.g., using SVMs with RBF kernel, parameter values were selected by cross-validation. Performance is evaluated on error rate of the true cluster label on the test set.

### 20.6.1 Experimental Results

The performance of the 7 methods is shown in Figures 20.1, 20.2 and 20.3. All results are reported on the test set. To avoid clutter, we show the results for the five best methods on average test-set error in Figures 20.1 and 20.2. The performance comparison of 7 semisvised learning methods on 14 datasets are in Tables 20.1–20.3 with different numbers of labeled points (30, 40, and 50). We make the following observations over the results:

- There is no dominating method across all datasets. However, there is a set of methods that seems to be fairly consistently across the top few, and the performance of the few methods is typically close. Across the top methods, the differences typically do not be significant when compared to the worst methods, For instance, if we examine the results in Figure 20.1(e) for the USPS data set, we can see that the error for the top methods is around 1.5–1.8%, while the performance for the worst methods is 3.0% and 7.6%. The improvements of the best methods are clearly significant in comparison to the worst methods judging by the standard deviation in error.

- Our results also indicate that no given method is always the best methods for each data set. For any method, we could find at least one data set where its performance is among the worst. It appears that the assumptions made by various approaches do not work well all cluster structures encountered in various data sets.
