An optional postprocessing step, these approximations can be refined by any clustering algorithm to the points included in the projection onto the corresponding subspace. Though using a bottom-up search strategy, FIRES is rather efficient because it does not employ a worst-case exhaustive search procedure heuristic that is scaling polynom in the dimensionality of the data space. However, the user can expect to pay for this performance boost by a loss of clustering accuracy. It cannot be specified whether the clusters produced by FIRES may overlap or not, this partly depends on the clustering algorithms used in the intermediate steps of the framework. In general, the clusters may overlap usually FIRES will not produce all clusters in all subspaces.

P3C [102, 103] starts with 1-dimensional clusters that are likely to approximate dimensional subspace clusters. These clusters are merged via APRIORI-like bottom-up search strategy. The maximal-dimensional cluster approximations resulting from this merging procedure are so-called cluster cores. In a refinement step, the clusters are refined by using an EM-like clustering procedure. Each cluster is taken as initial cluster for the EM algorithm. Points are assigned to the cluster core using the Mahalanobis distance. The final output of P3C is a matrix that records for each data point its probability of belonging to each projected cluster. From this matrix, a disjoint partitioning of the data points into clusters can be obtained by assigning each point to the cluster with the highest probability. If overlapping clusters are allowed, each point can be assigned to clusters with a probability larger than 1/k. P3C does not produce all clusters in subspaces as APRIORI-style algorithm does but reports the results of the final cluster computation using EM.

Moiser and Sander [101] provided a first attempt to recover significant subspace clusters as an optimization problem. In addition, the authors proposed an iterative algorithm STATPC to search locally optimized solutions for this optimization problem.

Interesting recent developments combine techniques from ensemble clustering [58] with ideas from subspace clustering, resulting in "subspace clustering ensembles" [41] or "projective clustering ensembles" [64, 63, 62].

# 9.4.2 Clustering in Arbitrary Oriented Subspaces

# 9.4.2.1 Cluster Model

A model for correlation clusters, i.e., clusters residing in arbitrary-oriented subspaces, can be based on a linear equation system describing the $\lambda$-dimensional hyperplane accommodating the points of a correlation cluster $C \in \mathbb{R}^d$. This equation system will consist of $d - \lambda$ equations for the points and the affinity, each given by the mean point $x_c = (x_i \cdot x_c)$ of all cluster members:

```
$v_{1(\lambda+1)} \cdot (x_1 - x_c) + v_2 \cdot (x_2 - x_c) + \dots + v_{\lambda+1} \cdot (x_{\lambda+1} - x_c) = 0\\nv_1 \cdot (x_1 - x_c) + v_2 \cdot (x_2 - x_c) + \dots + v_d \cdot (x_d - x_c) = 0 \ (9.5)$
```

where $v_{ij}$ is the value at row $i$, column $j$ in the eigenvector matrix $V_C$ derived (e.g., by principal component analysis (PCA) [83]) from the covariance matrix of $C$. The first $\lambda$ eigenvectors (also called strong eigenvectors) give the directions of high variance and span the hyperplane accommodating C. The remaining $d - \lambda$ weak eigenvectors represent the perpendicular subspace. The corresponding linear equation system can also be given by

```
$$\hat{V}_C^c \cdot x = \hat{V}_C^c \cdot x_c \ (9.6)$
```
