Globally, the efforts can be grouped in several categories: relative motion patterns, flocks, convoys, clusters, and swarms [21]. Getting into details about the peculiarities of each category of works is beyond the scope of this chapter, in the sequel we provide an overview of a few techniques in order to illustrate some issues (and solutions) arising in the domain of trajectories clustering.

Lee et al. [30] describe a clustering approach that belongs to the category of density-based clustering approaches. For a given collection of trajectories, the proposed method can operate on trajectories of different lengths and produce a set of clusters and a representative trajectory for each cluster. The authors argue on the meaningfulness of subclustering; the clusters they generate are sets of trajectories. A trajectory partition is a line segment $p_{ij}$, where $p_i$ and $p_j (i < j)$ are points of the trajectory. The representative trajectory for each cluster is a trajectory partition that is common to all the trajectories that belong to that cluster. Trajectory partitions belonging to the same cluster have a similar distance to each other, according to the distance function used. The difference between line segments corresponds to the sum of the perpendicular distance, parallel distance and angle distance (cf. [30]). Unlike, our method performs the line segment clustering by DBSCAN (discussed in [13]). The difference is that in line segment clustering which is applied here, not all connected groups of line segments become clusters, because many line segments belong to the same trajectory. Thus, each cluster that contains segments with less than a desired number of trajectories is discarded. For the computation of the representative trajectory for each cluster, the authors use an average direction vector and sweep a vertical line across the segments in direction. The complexity of the proposed algorithm is $O(n^2)$ if no spatial index is used, or $O(n \log n)$ otherwise, with $n$ being the total number of segments that are produced by the partitioning. In the subsequent work [29], trajectory-based and region-based clustering were combined to build a feature generation framework for trajectory classification. Region-based clustering disreg movement and clusters of trajectories that are mostly of one class. The trajectory-based clustering extends the first work by [30] using class label information in the clustering process. After trajectory partitioning, region-based clustering is performed and the partitions that cannot be represented by homogeneous regions are the input of the trajectory-based clustering method. The proposed method generates a hierarchy of features in a top-down approach, features produced by region-based clustering do not contain movement patterns, and are of higher level whereas trajectory-clustering features are less general.

One observation regarding the approaches is that they do not properly incorporate the temporal dimension of the trajectories (i.e., with routes). One of the first works that brought the temporal awareness in the realm of spatiotemporal trajectory clustering was [24], which introduced the concept of a moving cluster—a set of objects that move close to each other for a given time duration. One can think of it as a temporal sequence of spatial clusters, preserving the property that the number of objects among consecutive clusters is maintained above a certain threshold $	heta$. An example of a moving cluster with $	heta \ge 75\%$ (3/4 of the objects are within a cluster at any given moment) is shown in the left part of Figure 15.4. A set of criteria for clustering the trajectories is the one of convoys [22] that corresponds to a group that has least $m$ objects which are density-connected with respect to distance $e$ and cardinality $m$ over $k$ consecutive time-instants.
