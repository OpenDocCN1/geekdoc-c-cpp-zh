It has been shown in [53], that the final quality of the output cannot be arbitrary unless the particular subroutine which is used at the intermediate stage for k-medians clustering.

Lemma 10.2.1 The subroutine for k-medians clustering in the STREAM algorithm have an approximation factor of c. Then, the STREAM algorithm will have an approximation factor of no worse than 5 · c.

The work in [53] extends the original work in [36] by designing more effective subroutine for the k-medians problem. This solution is based on the problem of facility location. Note that the Lagrangian relaxation of the clustering problem can be modeled as a facility location problem, wherein we relax the constraint on the number of representatives and incorporate it into the objective with a Lagrangian multiplier. These representatives are analogous to facilities in the facility location problem, where the cost associated with a representative, can be physically visualized as the cost of “building” a facility, in order to serve its clients (data points). Thus, we add λ (Lagrangian parameter) for each facility included. The cost of assignments is the same as before. Thus, the new objective function in the set of facilities $Y'$ is expressed as follows:

```
$$\text{Objective}(S, Y') = \sum_{X_i \in S, Y_j \in Y'} \text{dist}(X_i, Y_j) + \lambda \cdot |Y'| \quad (10.2)$
```

Unlike the previous case, the cardinality of $Y'$ may not be optimal at the level of the objective function, unless the value of the Lagrangian parameter (or facility cost) $\lambda$ is picked appropriately. In order to use this approach to solve the k-medians subroutine, two steps are needed [53]:

+   - Given a particular value of $\lambda$, how do we determine the optimal objective function value?
- How do we determine the value of $\lambda$ in such a way that the number of facilities in the optimal solution is k?

The latter step of the solution is easy. As long as the optimal number of facilities changes monotonically with $\lambda$, one can use binary search on $\lambda$ in order to determine the appropriate value. It is shown in [53] that the optimal number of facilities changes monotonically with $k$.

In order to solve the first part of the problem, a local search called LSEARCH is proposed. In this algorithm, we start with a set of facilities $O$, and an assignment of data points to these facilities $x$. Then, we repeatedly examine a randomly selected facility $x$, which is currently not in $O$, and compute the improvement in the objective function by adding $x$ to $O$ and other facilities. This improvement in objective function is referred to as $gain(x)$. Certain rules of reassignment of data points to facilities and closing facilities are used for this purpose, as discussed.

Specifically, any data point is allowed to be reassigned to $x$, when $x$ is added to $O$ (if there is an improvement), and it is allowed to close a facility $y$ and assign all of its points to $x$. The latter case would result in a gain, as long as the cost of opening to $x$ is not greater than the savings from $y$. Thus, the value of $gain(x)$ may be positive. The facility $x$ is added to $O$, only if $gain(x) > 0$. This process is repeated over all facilities in random order, and the final set of facilities and reassignments are repeated $\Omega(\log m)$ times in order to provide guarantees on the underlying quality.
