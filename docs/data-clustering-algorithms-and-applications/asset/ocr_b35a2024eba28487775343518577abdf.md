# Document Clustering: The Next Frontier 321

**Extending the vector space.** Wang et al. propose the Matrix Space Model (MSM) [1110], in which each segmented document is represented as a tf-idf-weighted term-segment frequency matrix instead of a frequency vector. Segments are then considered as probabilistic distributions over a small set of L latent topics, which are used to realize a document clustering. Latent topic extraction is accomplished by approximating the document matrices A as LM,Rᵀ, where the nonnegative basis-matrices L ∈ R^{m×l} (L ≥ 0) and R ∈ R^{s×l} (R ≥ 0) jointly define the lower dimensional space, and matrices M_i are the low rank representation of the documents. l1 and l2 are user specified parameters defining the size of the latent space, m is the size of the term vocabulary, and s is the number of segments into which a document is split.

Given that matrices L and R are shared among the collection, the authors expect similar documents in the original space to also have a similar latent space representation. They formulate the latent topic extraction as the constrained optimization problem,

```
min
  ∑_{i=1}^n ||A_i - LM_iRᵀ||_F²
  L ∈ R^{m×l} : L ≥ 0
  R ∈ R^{s×l} : R ≥ 0
  M_i ∈ R^{l×1} : M_i ≥ 0
```

where ||·||_F is the standard Frobenius norm and n is the number of collection documents. In the reconstruction, LM is associated with the posterior of each term belonging to the latent topics, while M_iᵀ is the posterior of each segment in the document belonging to the latent topics.

# 14.3 Simultaneous Segment Identification and Clustering

Assuming the previous definition of segments as topically coherent blocks of text in a document, segment identification boils down to finding the document topics. The document segments can then be extracted by considering the major shifts in the document word list. Considering cluster assignment, the result of topic modeling can be written as a document-topic probability matrix P where P_ij = Pr(z_ij|d_i). A hard (or soft) k-way clustering on documents could be induced from P by assigning documents to the topic cluster(s) for which their respective values are highest (or above a threshold).

**Co-clustering in the latent space.** This assignment strategy assumes an order-dependent word assignment in the topic model, which is not necessarily the case, as most models assume documents are unordered bags of words. For the purpose of addresses address order within the document, Latent Dirichlet Co-Clustering (LDCC) is an extension of LDA that simultaneously clusters words and documents. By focusing on meaningful segments of text, LDCC is more likely to assign adjacent documents to coherent topics.

LDCC extends LDA by assuming each document is a random mixture of topics, which turn into distributions over segments. Segments are then modeled as LDA: for each segment, a distribution over collection topics is sampled from a Dirichlet distribution; a topic is then selected according to this distribution for each segment; each term is finally sampled from a multinomial distribution over specific terms of the selected topic. Figure 13.6(a) depicts the plate notation representation of the LDCC model, whose generation process for each segment is detailed below.

+   1. Choose the number of segments for document d_i, S_i_i ~ Poisson(ϕ)
2. Generate document topics, μ_i ~ Dir(δ)
3. For each s_ij of the segments in document d_i
   a. Choose a random topic for the segment, y_ij ~ Multi(μ_i)
   b. Choose number of words for the segment, N_ij ~ Poisson(ϕ)
   c. Generate segment topic proportions, θ_ij ~ Dir_K(α_i,y_ij)
