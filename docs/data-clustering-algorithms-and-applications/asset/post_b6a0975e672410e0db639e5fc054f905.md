It is obvious that $L(q, \Theta)$ is a lower bound on $p(\mathbf{X}|\Theta)$. Note that $L(q, \Theta)$ is a function of the distribution $q(\mathbf{z})$ and a function of the parameters $\Theta$. It is worth studying carefully that it is easier to maximize this lower bound over the log-likelihood than the actual log-likelihood, and the lower bound is reasonably tight. In terms of tightness, if $q(z_n) = p(\mathbf{x}_n, z_n|\Theta)$, we can simplify $L(q, \Theta)$ to be

```
$L(q, \Theta)|q(\mathbf{z}) = \sum_{n=1}^{N} \sum_{z_n} p(\mathbf{x}_n, z_n|\Theta) \log p(\mathbf{x}_n, z_n|\Theta)/p(z_n)

```

Therefore, with choice of $q$, the lower bound $L(q, \Theta)$ indicates that the lower bound is tight. Moreover, since $L(q, \Theta) \le l(\Theta)$, this choice of $q$ maximizes $L(q, \Theta)$ for fixed $\Theta$.

The EM algorithm is a two-stage iterative optimization framework for maximizing likelihood. We now demonstrate that the EM algorithm does indeed maximize the likelihood. Suppose that the current estimates of the parameters are $\Theta^{(t)}$. In the E-step, the lower bound $L(q, \Theta^{(t)})$ is maximized with respect to $q(z_n)$ while holding $\Theta^{(t)}$ fixed, which can be stated in the form

```
$q^{(t)}(z_n) = \arg max_q p(\mathbf{x}_n, z_n|\Theta^{(t)}).$
```

The solution to this maximization problem is easily seen by noting that the value of $\log p(\mathbf{X}|\Theta^{(t)})$ does not depend on $q(z_n)$ when $q(z_n)$ is equal to the posterior distribution $p(z_n|x_n,\Theta^{(t)})$. In this case, the lower bound will equal the log-likelihood by Equation (3.22). In other words, the maximization in the E-step is just updating the posterior probabilities $p(z_n, \mathbf{x}_n|\Theta^{(t)})$.

In the following M-step, the distribution $q(z_n)$ is fixed and the lower bound $L(q, \Theta)$ is maximized with respect to $\Theta^{(t+1)}$, which can be stated in the form

```
$\Theta^{(t+1)} = \arg max_{\Theta} L(q, \Theta).$ (3.23)
```

If we substitute $q^{(t)}(z_n) = p(\mathbf{x}_n|\Theta^{(t)})$ into $L(q, \Theta)$, the lower bound can be expressed as

```
$L(q^{(t)}, \Theta) = Q(\Theta^{(t)}, \Theta) - \sum_{n=1}^{N} \sum_{z_n} p(\mathbf{x}_n, z_n|\Theta^{(t)}) \log p(\mathbf{x}_n, \Theta^{(t)})$ (3.24)
```

where

```
$Q(\Theta^{(t)}, \Theta) = \sum_{n=1}^{N} \sum_{z_n} p(\mathbf{x}_n, z_n|\Theta^{(t)}) \log p(\mathbf{x}_n, z_n|\Theta).$ (3.25)

# **Algorithm 12** The General EM Algorithm

Given a statistical model consisting of a set of observed variables $X$, a set of unobserved latent variables $Z$, and a vector of unknown parameters $\Theta$, the goal is to maximize the log-likelihood with respect to the parameters $\Theta$.

- 1: Start with an initial guess for the parameters $\Theta^{(0)}$ and compute the initial log-likelihood $\log p(\Theta^{(0)})$.
- 2: **E-step**: Evaluate $q^{(t)} = \arg\max q L(q, \Theta^{(t)}) = p(z|X_n, \Theta^{(t)})$.
- 3: **M-step**: Update the parameters $\Theta^{(t+1)} = \arg\max Q(\Theta, \Theta^{(t)})$.
- 4: Compute the log-likelihood $\log p(\Theta^{(t+1)})$ and check for convergence of the algorithm. If the convergence criterion is not satisfied, repeat steps 2–4, otherwise return the final parameters.

The second sum minimizes entropy (of $q$) and is therefore independent of $\Theta$. In the M-step, maximizing $L(q^{(t)}, \Theta)$ is equivalent to maximizing $Q(\Theta, \Theta^{(t)})$.

```
$$\Theta^{(t+1)} = \arg\max_{\Theta} Q(\Theta, \Theta^{(t)}). \quad (3.26)$$
```

The above quantity that is maximized is the expectation of the complete data log-likelihood. The convergence properties of the EM algorithm are discussed in [22] and [46]. Here we discuss the general convergence of the algorithm. We have seen that both the E and M steps of EM maximize $L(q, \Theta)$. It is easy to see that, after E-step,

```
$L(\Theta^{(t)}, \Theta^{(t+1)}) \geq L(\Theta^{(t-1)}, \Theta^{(t)})$.
```

and that, after M-step, putting these two inequalities together, we obtain $L(\Theta^{(t)}, \Theta^{(t+1)}) \geq L(\Theta^{(t-1)}, \Theta^{(t)})$ and $\log p(\Theta^{(t+1)}) \geq \log p(\Theta^{(t)})$. It is clear that each EM cycle can increase the lower bound on the log-likelihood and will not change the model parameters in such a way as to increase the actual log-likelihood, which is guaranteed to reach a local maximum. The general EM algorithm is summarized in Algorithm 12.

**Maximum Posterior Estimation**: The EM algorithm can be used to find MAP estimates for models where a prior $p(\Theta)$ over the parameters is introduced. We note that as a function of $\Theta$, $p(\Theta|X) = \frac{p(X|\Theta)p(\Theta)}{p(X)}$, based on Bayes' theorem. By making the decomposition of (3.21), we have

$$\log p(\Theta) = \log p(X|\Theta) + \log p(\Theta) -\log p(X) \geq L(q, \Theta) + \log p(\Theta), \quad (3.27)$$
```

where $\log p(X)$ is a constant. We can maximize the right-hand side alternatively with respect to $q$ and $\Theta$. In the E-step the remainder is same as in the maximum likelihood case as $q$ only appears in $L(q, \Theta)$, whereas in the M-step the quantity to be maximized is given by $L(q, \Theta) + \log p(\Theta)$, which typically requires only a small modification to the standard algorithm M-step.

Furthermore, many variants of the EM algorithm for clustering have been studied when the original EM algorithm is difficult to compute in either the E-step or the M-step. Here we list some of them.

**Generalized EM**: Often in practice, the solution to the M-step exists in closed form, but there are many cases for which it is intractable to find the value $\Theta$ that maximizes the function $Q(\Theta, \Theta^{(i)})$. In situations, a generalized EM algorithm (GEM) [23, 53, 16] is defined where M-step requires $\Theta^{(r+1)}$ to be chosen such that

$Q(\Theta^{(r+1)}, \Theta^{(i)}) \geq Q(\Theta^{(i)}, \Theta^{(i)})$

holds. That is, one chooses a better value $\Theta^{(r+1)}$ to increase the Q-function, $Q(\Theta, \Theta^{(i)})$, rather than find the local maximum of it. The convergence can be guaranteed using GEM, and has been widely used for the estimation of topic modeling with graph-based regularization, such as NetPLA [30] and TBP [24].

**Variational EM**: The variational EM addresses the problem of an intractable E-step, which is one of the approximate algorithms used in LDA [14]. The idea is to find a set of variational parameters with respect to hidden variables that attempts to obtain the tightest possible bound in E-step and to maximize the lower bound in M-step. The variational parameters are chosen in a way that simplifies the original probabilistic model and are thus easier to cluster. There is no guarantee that variational EM will find a local optimum.

**Stochastic EM**: In some situations, the EM algorithm involves an integral that may not be tractable, such as LDA [14]. The idea of stochastic EM (SEM) [20, 46] is to replace this tedious computation with a stochastic simulation. The E-step is computed with Monte Carlo sampling. This introduces randomness into the optimization, but asymptotically will converge to a local optimum.

# 3.3.2 Mixture Models Revisited

With our general definition of the EM algorithm, let us revisit the case of estimating parameters for Gaussian mixture model and Bernoulli mixture model, respectively. The EM algorithm is an iterative algorithm that has two main steps. In the E-step, it tries to guess the values of the hidden variable $z_{nk}$, in the M-step, it updates the parameters of the model based on the guesses of the E-step.

**Gaussian Mixture Model**: The parameters of a Gaussian mixture model include the mean vectors $\mu_k$, covariance matrices $\Sigma_k$ and mixing weights $\pi_k$. In the E-step, we calculate the posterior, or responsibility, of the hidden variable $z_{nk}$, given the current set of parameters. Using Bayes' theorem,

$q(z_{nk} = 1) = p(z_{nk}|x_n, \mu_k, \Sigma_k) = \frac{\pi_k p(x_n|\mu_k, \Sigma_k)}{\sum_{j=1}^K \pi_j p(x_n|\mu_j, \Sigma_j)} = \gamma(z_{nk})$, (3.28)

which is the responsibility of the component $k$ for data $x_n$. In the M-step, we need to maximize the quantity $Q(\Theta, \Theta^{(i)})$. From independence, the expectation of the complete log-likelihood (3.25) can be rewritten as

$Q(\Theta, \Theta^{(i)}) = \sum_{n=1}^N \sum_{k=1}^K \gamma(z_{nk}) \log \pi_k p(x_n|\mu_k, \Sigma_k).$ (3.29)

Compared with the log-likelihood function (3.11) for the incomplete data, the algorithm now operates on distributions. By fixing the responsibilities, we can maximize $Q(\Theta, \Theta^{(i)})$ with respect to $\mu_k, \Sigma_k$, and $\pi_k$. This leads to closed-form solutions for updating $\mu_k, \Sigma_k$, and $\pi_k$, by (3.12), (3.14), and (3.15). This is precisely the EM algorithm for Gaussian mixtures as derived.
