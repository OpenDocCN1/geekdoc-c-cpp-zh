# 7.6.5 Graph Clustering

Three NMF models (Symmetric NMF, Asymmetric NMF, and Joint NMF) have been proposed in [123] to identify communities in different types of users (undirected, directed, and compound). Among their proposed models, symmetric NMF and asymmetric NMF are special cases of tri-factorization. For example, in music recommendation, we are given three networks: (1) the user network $U$ among users, (2) the music network $D$ showing the relationships among songs, and (3) the user-music network $M$ showing user preferences. Joint NMF is the problem of finding a matrix $G$, which reflects some “intrinsic” characteristics of the user-music network $M$, such that the three objectives are simultaneously minimized: $

```
$\min_{G} ||M - G||^2 + \alpha||U - G^T||^2 + \beta||D - G^T G||^2 \text{ s.t. } G \in \mathbb{R}^{n \times m},$
```

Formally, joint NMF solves where $\alpha > 0$ and $\beta > 0$ are constants to trade the importance between different terms. Recently, an efficient Newton-like algorithm has been proposed for graph clustering using symmetric NMF [64].

# 7.6.6 Other Extensions

NMF methods have also been developed for many other clustering extensions. Badea has proposed an NMF model that simultaneously factorizes two linked nonnegative matrices with a shared factor matrix, aiming to uncover the consensus between the two datasets [9]. Saha and Sindhwani have proposed a framework for online topic detection to handle streaming nonnegative data with possibly growing number of clusters [94]. Li et al. [77, 76] have proposed constrained matrix tri-factorizations for cross-domain transfer clustering using the matrices in both the source and target domains. The proposed constrained matrix factorization naturally clusters document labels via a square penalty incurred by a certain linear model and enables direct and explicit knowledge transfer across different domains. Wang et al. [119] have proposed a new NMF-based language model to simultaneously cluster and summarize documents by making use of both the document-term and sentence terms. The proposed framework leads to a better clustering method with more meaningful interpretation using representative sentences. Wang et al. [116, 117] have proposed weighted NMF-based approaches for keyword selection and clustering (topic discovery) by incorporating weights that describe the importance of the keywords.

NMF has also been extended for analyzing multi-data (or multi-way tensor). Multi-way data are generalizations of matrices and they are applied in many applications [114, 3, 104, 62, 92, 1]. One typical type of three-way is two-way data/matrices 2D data/matrices with different periods. For example, a series of 2-D data (genes vs. conditions) are naturally represented as three-way data. Nonnegative Tensor Factorization (NTF) is an extension of Nonnegative Matrix Factorization. The input data is a nonnegative tensor.
