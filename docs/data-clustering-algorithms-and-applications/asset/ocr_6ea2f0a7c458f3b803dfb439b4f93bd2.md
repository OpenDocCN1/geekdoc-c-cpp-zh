# Semisupervised Clustering

# 20.4 A Unified View of Label Propagation

The semisupervised graph-cut problems described in Section 20 belong to a widely studied family of problems which can be solved using label propagation methods [15]. In this section, we present a Generalized Label Propagation (GLP) framework, discuss various specific instantiations of the framework from the literature, and illustrate its connections to the semisupervised graph-cut problems.

# 20.4.1 Generalized Label Propagation

GLP formulation considers a graph-based semisupervised learning setting. Let W be the symmetric weight matrix and L be a corresponding graph Laplacian. Note that L may be any of the Laplacians discussed up in Section 20.3, and we will see how different label propagation formulations result from specific choices of the Laplacian. Let $f \in \mathbb{R}^n$, where $n = \ell + u$, be the predicted score on each data point $x_i, i=1,\dots,n$; the predicted label $\hat{f}_i$ can be obtained as sign($f_i$). The GLP problem can be formulated as:

```
$$\min_{f \in S} f^T L f \quad s.t. \quad \sum_{i=1}^n (f_i - y_i)^2 \le \varepsilon,$ (20.38)
```

where $\varepsilon \ge 0$ is a constant and $S \subseteq \mathbb{R}^n$. For most existing formulations $S=\mathbb{R}^n$, whereas for $S=\{f|f \in \mathbb{R}^n, f^T 1 = 0\}$ where $1$ is the ones vector. The Lagrangian for the problem is given by $L(f, \mu) = f^T L f + \mu \sum_{i=1}^n (f_i - y_i)^2$, where $\mu \ge 0$ is the Lagrangian multiplier. Some variants assume $y_i=0$ for $i=(\ell,\dots,n)$, so the result will be of the form $\sum_{i=1} (f_i-y_i)^2=\varepsilon$. Assuming the Laplacian to be symmetric, with $L$ and $L_\ell$, the first order necessary conditions are given by $(L+\mu I)f = \mu y$, where $I$ is the identity matrix. Existing methods work with the special case $\varepsilon=0$, which matches the constraints so that $\sum_{i=1} (f_i-y_i)^2=0$ and $f_i=y_i$ on the labeled points. The first order conditions for the special case are given by $L_\ell f=0$. In the next sections, we show how much of the existing label propagation methods for semisupervised learning can be derived directly as a special case of the GLP formulation or alternatively with special choices of the Laplacian $L_\ell$, and the subspace $S$.

# 20.4.2 Gaussian Fields

Motivated by the assumption that neighboring points in a graph will have Gaussian fields (GFs), the energy function is considered [46]:

```
$E(f) = \frac{1}{2} \sum_{i,j=1}^n w_{ij}(f_i-f_j)^2.$ (20.39)
```

The GF method computes labels by minimizing the energy $E(f)$ with respect to $f$ under the constraint that $f_i=y_i$ for all labeled points. As observed in [46], the energy function is harmonic, i.e., it is twice continuously differentiable and satisfies Laplace’s equation [24]. From the harmonic property of the energy function it follows that the predicted labels will satisfy: $f=D^{-1}Wy$. In block matrices constructing
