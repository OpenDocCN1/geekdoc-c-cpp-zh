To identify dense units and subspaces that CLIQUE considers projections of the subspaces from the bottom up (i.e., the largest dense subspaces to those of increasing dimension). Given a projection subspace, $A_{t_i} \cap A_{t_j} \dots A_{t_p}$, where $p < d$ and $t_i < t_j$ if $i < j$, a unit is the intersection of an interval in each dimension. Leveraging the Apriori algorithm, CLIQUE employs a bottom-up approach because monotonicity: if a collection of points is in a $p$-dimensional subspace, then this cluster is also a part of any $(p-1)$-dimensional projections of this. In CLIQUE, the recursive step from $(p-1)$-dimensional units to $(p-2)$-dimensions involves a self-join of the first $p-2$ units sharing the pool of candidates. To reduce the time complexity of the Apriori process, CLIQUE prunes the dense units to the candidate units in the next level of the dense unit generation algorithm. To prune, the clusters are sorted by their coverage, i.e., the fraction of the database that covers the dense units in it. The dense clusters are pruned. The cut point between retained and pruned clusters is selected based on the MD [24] principle in information theory.

## 6.5.2 Variants of CLIQUE

There are two aspects of the CLIQUE algorithm that can be improved. The first one is the criterion for the subspace selection. The second is the size and resolution of the grid structure. The former is addressed by the ENCLUS algorithm by using entropy as subspace selection criterion. The latter is addressed by the MAFIA algorithm using adaptive grids for fast subspace clustering.

### 6.5.2.1 ENCLUS: Entropy-Based Approach

The ENCLUS (Entropy-based Clustering [6]) is an adaptation of CLIQUE that uses a different, entropy-based criterion for subspace selection. Rather than using the fraction of total points in a subspace as a criterion to select subspaces, ENCLUS uses an entropy criteria and only those subspaces spanned by attributes $A_1, \dots, A_p$ with entropy $H(A_1, \dots, A_p) < \theta$ (a threshold) are selected for clustering. A low-entropy subspace corresponds to a more dense region of units.

## Grid-Based Clustering

An anomalous monotonic property or Apriori also exists in entropy. If a p-dimensional subspace has low entropy, then so does $(p-1)$-dimensional projections of this subspace:

```
$H(A_1, \dots, A_{p-1}) = H(A_1, \dots, A_p) - H(A_p|A_1, \dots, A_{p-1}) < \overline{\sigma}. \quad (6.4)$
```

A significant limit of Clustering is its extremely high computational cost, in terms of computing the entropy of subspaces. However, this cost also yields the benefit that this approach has increased sensitivity to detect clusters extremely small ones.

### 6.5.2.2 MAFIA: Adaptive Grids in High Dimensions

MAFIA (Merging of Adaptive Infinities) proposed by Nagesh et al [21] is a descendant of CLIQUE. Instead of using a fixed size cell grid with an equal number of bins in dimension, MAFIA constructs adaptive grids to improve subspace clustering and also uses parallelism on a shared-nothing architecture to handle massive data sets. MAFIA proposes adaptive grids of bins in each dimension. Using an Apriori algorithm, density intervals are merged to create clusters in the higher dimensional space. The adaptive grid is constructed by partitioning each dimension independently based on the distribution (i.e., the histogram) observed in dimension, merging intervals that have the same distribution, and pruning those with low density. This pruning during the construction of the adaptive grid reduces the overall cost of the clustering step. The steps of the adaptive grid are summarized in [32].

# Algorithm 32 MAFIA

- Do scan of data to construct adaptive grids into bins
- Compute histograms
- Use histograms to merge adjacent bins with similar values
- Select bins with low density ($\alpha$ is a parameter)
- Iteratively scan for new CDUs
- Generate clusters

## 6.5.3 OptGrid: Density-Based

The density function $f^D$ is defined as:

```
$f^D = \frac{1}{nh} \sum_{i=1}^{n} KD(\frac{X-x_i}{h}), \quad (6.7)$
```

where $D$ is a set of points, $h$ is the smoothness level, and $KD$ is the density estimator.

OptGrid uses the density function to determine the best clusters, where:

```
$H(x) = \begin{cases} 1 & \sum_{i=1}^{k} w_i \geq 1 \\ 0 & \text{otherwise.} \end{cases} \quad (6.5)$
```

The decision function $c(x)$ is:

```
$c(x) = \sum_{i=1}^{k} H_i(x). \quad (6.6)$
```

A center-based cluster for a maximum $x^*$ of the density function $f^D$ is the subset $C \subset D$, with $x \in C$ being density-attracted by $x^*$ and $f^D(x*) \geq \xi$. Points $x \in D$ are called outliers if they are density-attracted by a local maximum $x^*$ with $f^D(x^*) < \xi$.

OptGrid selects a set of projections. The projections are used to find the optimal clusters. The projections are because they control the density of points, and the cutting planes will have low density. Each cutting plane is selected to have minimal point and separate to two dense half spaces. After each step of constructing the function, the algorithm is then applied recursively to the clusters. In each round of recursion, OptGrid maintains only data objects in the density from the previous round of recursion. The algorithm OptGrid is described in Algorithm 33 [10, 12].

The time complexity of OptGrid is $O(N \log N)$, where $N$ is the number of data points and $d$ is the dimensionality of the data. This is very efficient for clustering large-dimensional databases. However, it may perform poorly in locating clusters embedded in a low-dimensional subspace of a high-dimensional database, its recursive method reduces the dimensions by every step [10].
