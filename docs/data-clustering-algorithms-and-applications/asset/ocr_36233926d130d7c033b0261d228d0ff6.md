# ## 7.4 Consensus Clustering

Consensus clustering, also called aggregation of clustering, refers to a situation where multiple clustering results on the same dataset are already obtained and the task is to find a clustering [49, 107, 47, 75] which is closest to all of them as.

Formally let $X = \{x_1, x_2, \dots, x_n\}$ be a set of $n$ data points. Suppose we are given a set of $T$ clusters (or partitions) $\mathcal{P} = \{P^1, P^2, \dots, P^T\}$ of $X$. Note the number of clusters could be different for different results. Let us define the consensus matrix $M_{ij}(P^k)$ for a single partition $P^k$

```
$M_{ij}(P^k) = \begin{cases} 1 & \text{if belong to same cluster} \ 0 & \text{otherwise} \end{cases}$
```

Consensus clustering looks for a partition (consensus clustering) $P^*$ which is the closest to all the partitions:

```
$$\min_{P^*} \frac{1}{T} \sum_{t=1}^{T} \|M_{ij}(P^t) - M_{ij}(P^*)\|_F^2 = \frac{1}{T} \sum_{t=1}^{T} \|M(P^t) - M(P^*)\|_F^2$$
```

Let the average association between $i$ and $j$ be $\bar{M}_{ij} = \frac{1}{T} \sum_{t=1}^{T} M_{ij}(P^t)$. We have

```
$J = \frac{1}{T} \sum_{t=1}^{T} \|M(P^t) - \bar{M}\|_F^2 + \|\bar{M} - M(P^*)\|_F^2$$
```

The first term is a constant which measures the average distance from the consensus association matrix $M$. The smaller this is, the closer to all the other partitions are.

We minimize the optimal clustering partition $P^*$ can be specified by clustering indicators $H = \{0,1\}^{n \times c}$, with the constraint that in each row of $H$ there can be only one '1' and the rest must be zeros. The key connection here is that the consensus matrix $M(P^*) = HH^T$. With this, consensus clustering problem becomes

```
$$\min_{H} |\M - HH^T\|^2 \text{ s.t. } H \text{ is a cluster indicator.$
```
