### 23.3.2.6 The Impact of Arbitrary Shapes

An arbitrary shape is hard to handle. Figure 23.13 shows a synthetic data set T4.bk.modified which consists of 6 irregular shape of clusters. It is generated by removing 10% noise from the original data set T4.bk which contains 8000 objects[28]. In the last subsection, the four algorithms are employed to run on T4.bk.modified to divide the data set into six clusters, which is the true cluster number. As shown in Figure 23.14, Chameleon performs as the clustering algorithm among these four clustering algorithms.

A study on the data set T4.bk.modified was performed to evaluate whether the nine internal indices could handle a data set with arbitrary shapes. Chameleon is applied as the clustering algorithm. Results listed in Table 23.19 show that only CVNN can deal with data set with arbitrary structures. The results are as follows:

- D uses the pairwise distance between objects in different clusters to measure the intercluster separation. When dealing with arbitrary shape data sets, this can be misleading. The above measures use either the average (minimum) pairwise distance between objects in clusters or one object (the cluster center) as the representative of the entire cluster when calculating intercluster separation. These measures consider only the positions of the objects and fail to take into account the distributions which form the geometrical information of the cluster. On the other hand, CVNN evaluates intercluster separation based on objects that carry the geometrical information of each cluster. Sharing the same idea with knn, CVNN uses multiple objects as representatives for different clusters in different situations.

Since it is meaningful to use the center to represent the entire cluster only for sphere-shaped cluster, this implies that these indices can work only in hypersphere condition. Figure 23.15 shows clusters A and B have arbitrary structure, and the cluster centers are not even in the clusters. If one moves cluster B from baseline, A and B are getting closer while the distance between their centers becomes larger. In this case, it is meaningless and incorrect to make cluster center representative for the entire cluster.

Figure 23.16 illustrates the dynamic effect of how representatives of clusters evolve in different situations. In this example, both clusters A and B have arbitrary structure and solid objects are the representatives selected by CVNN measure. Comparing subfigure (a) with (b), one can see that A and B are closer than before, which indicates that the intercluster separation is getting worse. Meanwhile, the numbers of representatives for both clusters are growing as well as the intercluster separation measure within CVNN, which agree the indication that clusters are becoming more separated. This example illustrates the dynamic effect of CVNN's intercluster separation, since the representatives for the same two clusters are in different situations.

# 23.4 Summary

This chapter presents detailed studies on 16 external validation measures and 12 internal validation measures in a comprehensive way on various aspects of these validation measures. For the external validation part, different measures are compared and contrasted for K-means clustering. As results revealed, it is necessary to normalize validation measures before they can be employed for clustering validation, since unnormalized measures may lead to inconsistent or even misleading results. This is particularly true for data with imbalanced class distributions. Normalization solutions are also provided for some validation measures. Furthermore, lemmas are provided to show that some validation measures are mathematically equivalent and some have very similar performance. Key properties of the 16 measures are summarized; these properties should be considered before deciding what the right measure to use in practice.

For the internal part, the validation properties of a suite of 12 internal validation measures for crisp clustering are studied in six different aspects: monotonicity, density, subclusters, and arbitrary shapes. Six synthetic datasets which best represent the above six aspects are used to evaluate the performance of the 12 validation measures. The results of the studies demonstrate that all measures except for the CVNN index have limitations in different application scenarios, especially showing difficulties in handling data with arbitrary shapes. On the other hand, CVNN exploits the notion of nearest neighbors and uses dynamic multiple objects as representatives for different clusters in different situations, which makes it particularly useful when the data set includes clusters with arbitrary shapes. The summarized validation measures of the 12 internal validation measures may serve as a guide for index selection in practice.
