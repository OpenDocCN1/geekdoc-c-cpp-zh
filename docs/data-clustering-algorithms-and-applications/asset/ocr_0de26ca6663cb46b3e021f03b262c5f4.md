# Probabilistic Models for Clustering

Bernoulli Mixture Model: We derive the EM algorithm for maximizing the likelihood function for estimating the parameters of the Bernoulli mixture model $\Theta=\{\mu, \pi\}$. In the case of the Gaussian mixture, let us introduce a latent variable $z$ associated with each instance of $x$. The expectation of the complete log-likelihood with respect to the posterior distribution of the latent variable is

```
$Q(\Theta, \Theta^{(t)}) = \sum_{n=1}^N \sum_{k=1}^K \gamma(Z_{nk}) \log \pi_k p(X_n|\mu_k) \quad (3.32)\n= \sum_{n=1}^N \sum_{k=1}^K \gamma(Z_{nk}) [\log \pi_k + \sum_{i=1}^D [X_{ni} \log \mu_{ki} + (1 - X_{ni}) \log (1 - \mu_{ki})]]$
```

where $\gamma(Z_{nk})$ is the posterior probability, or responsibility, of component $k$, given $x_n$ and the current setting of parameters.

The EM algorithm proceeds iteratively in two steps. In the E-step, the posterior probability, or responsibility, of component $k$, given $x_n$, and the current setting of parameters, is estimated using Bayes' theorem, which is written in the form

```
$\gamma(Z_{nk}) = \frac{\pi_k p(X_n|\mu_k)}{\sum_{j=1}^K \pi_j p(X_n|\mu_j)}$
```

In the M-step, we maximize the above log-likelihood function with respect to the parameters $\mu_{ki}$ and $\pi_k$. By setting the derivative of (3.32) with respect to $\mu_{ki}$ to zero and rearrange the terms, we get

```
$\mu_{ki} = \frac{\sum_{n=1}^N \gamma(Z_{nk})X_{ni}}{\sum_{n=1}^N \gamma(Z_{nk})}$
```

For the maximization with respect to $\pi_k$, we use a Lagrange multiplier to enforce the constraint $\sum_k \pi_k = 1$, and then we obtain

```
$\pi_k = \frac{\sum_{n=1}^N \gamma(Z_{nk})}{N}$
```

To start EM, initial values for the parameters are required. Provided that a nonpathological starting point is used, the EM algorithm always increases the loglikelihood, and the algorithm is guaranteed to converge to a local maximum. The mixing probabilities are initialized to $\pi_k = 1/K$, and the parameters $\mu_{ki}$ are set to random values uniformly in the range (0.25, 0.75) and then normalized to satisfy the constraint $\sum_i \mu_{ki} = 1$.

# 3.3.3 Limitations of the EM Algorithm

The popularity of the EM algorithm is due to its simple implementation with the guaranteed monotone increase of the training set during optimization. However, there are several well-known limitations associated with the EM algorithm.

The EM algorithm converges to a local maximum and its solution is highly dependent on initialization, one strategy is to use multiple random starts and choose the final estimate with the highest likelihood [33, 46, 48, 65], and the other one is to initialize by clustering algorithms [33, 46, 48, 8]. In [6], several methods exist to choose sensible starting values for the EM algorithm to get maximum likelihood parameter estimation in mixture models. In addition, many adaptations and extensions of the EM algorithm have been proposed to address the problems of convergence to a local maximum and the initialization issue, such as deterministic annealing (DA) versions of EM algorithm, split-and-merge EM algorithm [77], component-wise EM algorithm [19, 25], and genetic-based EM algorithms [44, 57].
