# 14.2.5 Large-Scale Image Classification

Before the 2000s, most research effort on image classification and clustering focused on medium-scale databases, where the features could fit into a disk's memory (typically 4GB-32GB). There are many reasons for such limitation on large-scale computer vision task: for, during early days, large-scale image classification databases were not available previously due to the expensive cost associated with labeling, and effective and efficient learning algorithms are critical for large-scale classification problems. In the year 2009, a new ontological dataset ImageNet was published by Deng et al. [12], which can be used for many applications based on image clustering, including object recognition, image classification, and automatic clustering.

If this database was publicly available, a significant amount of research has been conducted in these areas which has led to efficient and robust learning algorithms. Unlike the traditional multiclass classification problem, a few hundreds of categories were involved in large-scale tasks require high teaching efficiency while producing good classification performance. In others, traditional strategies—including one-of-all (O(k)), one-vs-one (O(k(k-1)/2)), and Decision Directed Acyclic Graph (O(k(k-1)/2)) in training, and O(k)—will not be suitable for large-scale problems. [3] and [13] were proposed to explore structural relations between objects to construct multiclass classification problems that could possibly have a sub-linear testing cost at web-scale. [3] follows a two-step approach: learning a tree structure and classifier weights using a Label Embedding. The basic idea behind this work is to construct a tree structure where each node of the tree is associated with a label set and an SVM-classifier.

Using such a tree structure, the classification complexity could become sublinear. Labeling labels respect to root is a clustering problem. However, unlike the standard clustering techniques such as k-means (and its variants), clustering is performed on the root of space. We will briefly introduce the definitions and notations of the Label Tree and then explain the details of the label clustering process.

A Label Tree is a tree $T=(N,E,F,L)$ where $N=\{0,\dots,n\}$, a set of edges $E=\{(p_i,c_i)\}$ are ordered pairs of parent and child node indices, labels $F=\{f_1,\dots,f_n\}$, and label sets $L=\{l_0,\dots,l_n\}$ associated with each node. Each node is associated with a subset of labels and a classifier that determines which branch to follow. The root of such a tree contains all possible labels, which are indexed to 0.
