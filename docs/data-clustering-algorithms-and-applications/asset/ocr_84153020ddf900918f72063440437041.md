# 23.2.4.1 The Consistency Measures

Here, the consistency between a pair of measures is defined as the similarity between their rankings on a sets of clustering results. The similarity is measured by the Kendall's rank correlation. And the clustering results are produced by the CLUTO version of K-means clustering on 29 benchmark-world data sets listed in Table 23.8. In the experiment, for each data set, the cluster number is to be the same as the “true” class number.
