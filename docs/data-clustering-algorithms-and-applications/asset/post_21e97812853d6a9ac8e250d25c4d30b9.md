The first naive method would be to cluster based only on the data from the target modality and ignore the rest, and the second would be to concatenate all modalities to the feature vector for each entity. In [1], Barnard et al. propose a generative model to model the joint distribution of image segment and words given a hierarchy of image clustering. Each cluster corresponds to a leaf node in the hierarchy, and the probability of generating a segment or word is summed up along the path from the root to the leaf, implying the high level nodes are associated with abstract concepts and the lower nodes are associated with more concrete concepts. Mathematically, let $D$ denote image and word observation associated with a cluster $d$, $c$ denote the cluster index, $i$ denote the words or image segment, and $l$ denote the level. The generative model described above can be written as:

```
$P(D|d) = \sum_{c\in D} P(c)\prod_{i\in D} P(i|l,c)P(l|c)$
```

The probability of observing an observation $D$ given cluster $c$ is summed across all clusters, where on each path from the root to a cluster $c$, the probability of observing $D$ is the product of the probabilities of observing all segments of $D$ (which is the summation along the path because each concept may generate the segment). The authors also propose a simpler variant which is document-independent:

```
$P(D) = \sum_{c\in D} P(c)\prod_{i\in D} P(i|l,c)P(l|c)$
```

It was shown through experiments that this method improves the quality of image clusters obtained and the annotation performance. The rendering art photos also show that visual and textual features are complementary to each other and when effectively used can improve the clustering of these complex and abstract images.

Cai et al [6] use spectral clustering based on visual, textual, and link information to cluster image search results. For structure among webpage, block, and image are integrated and combined with text similarity. An graph $W_g$ can be constructed from a block $W_b$ as follows:

```
$W_b(i,j) = \sum_{\alpha,\beta\in B} W_b(\alpha,\beta)$
```

where $i,j$ represent index nodes, $\alpha, \beta$ represent blocks indices, and $i\in \alpha$ indicates image $i$ is contained in block $\alpha$. Equation (14.37) sums similarities between blocks that contain a particular pair of images and the similarity between the images. As for block similarity $W_b(\alpha,\beta)$, they are derived from page-to-block and block-to-page function $X(\alpha,p)$ denotes the importance of a block $\alpha$ on a webpage $p$. It is proportional to the size of the block divided by the distance between the center of the block and the page. Page-to-block function $Z(\alpha,p)$ is nonzero if and only if block $\alpha$ links to page $p$. Thus, to evaluate $W_b(\alpha,\beta)$ conditional probability interpretation is used as follows:

```
$W_b(\alpha,\beta) = Prob(\beta|\alpha)$
= \sum_{p\in P} Prob(p|\alpha)Prob(\beta|p)$
= \sum_{p\in P} Z(\alpha,p)X(p,\beta)$
```

Bekerman and Jeon [2] proposes applying combinatorial Markov random field (Comraf) to multimodal clustering. A combinatorial Markov random field is an MRF in which at least one node is a combinatorial random variable, which can be partitions, partial orderings, etc., of a finite set. Thus, the result of an MRF can be directly converted to clustering. Given a Comraf model over $m$ combinatorial variables $X^c = \{X_0^c, ..., X_{m-1}^c\}$, where $X_0^c$ corresponds to the target modality, the task is to find the most probable instantiation of $X^c = \arg\max P(X^c)$. Since $X_0^c$ is the only target modality, for $i > 0$, $X_i^c$ is known and will correspond to a clustering of all singleton clusters. The structure of the Comraf is an asterisk with target weighted information to be the pairwise function between two modalities, i.e.,

```
$(\hat{X}_0, X_j)_{MPE} = \arg\max \sum_{j=1}^{m-1} f_j(\hat{X}_0, X_j) = \arg\max \sum_{j=1}^{m-1} w_j I(\hat{X}_0, X_j) \quad (14.40)$
```

where $I(\hat{X}_0, X_j)$ evaluates the mutual information between two clusters and $w_j$ is the weight. In practice, the observed modalities are words, rectangular blocks, color, and texture. Through experiments, this framework is shown to obtain 2.5–3 times higher accuracy compared with a unimodal k-means algorithm.

# 14.5 Summary and Future Directions

This chapter concisely reviews, using some concrete examples, different categories of classical multimedia applications which directly or indirectly influence clustering techniques. For each example, we discussed the application-specific technical challenges for developing effective and efficient clustering algorithms, for example, multimodality and high-dimensionality. One of prominent emerging multimedia applications invokes the interaction between multimedia data with the fact developed networks. On the other hand, these relationships are often incomplete, making the problem more challenging.
