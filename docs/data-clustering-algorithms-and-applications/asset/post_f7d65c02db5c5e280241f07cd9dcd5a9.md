## 3.4.1 Probabilistic Latent Semantic Analysis

Probabilistic Latent Semantic Analysis (PLSA) [35, 36] is a statistical model for the analysis of co-occurrence data, which has been used in many applications, such as information retrieval, natural language processing, and machine learning from text.

The basic idea of PLSA is to treat the co-occurrences of words and documents as observations from a mixture where each component (i.e. aspect or topic) is a distribution over words, and the proportions of different components correspond to the probabilities. In PLSA, an unobserved latent variable $z_k \in \{z_1, \dots, z_K\}$ is associated with the observed word $w_j \in \{w_1, \dots, w_M\}$. Let us introduce the following probabilities: $p(d_i)$ denotes the probability that a word will be observed in a specific document $d_i$, $p(w_j|z_k)$ is used to denote the conditional probability of a particular word $w$ conditioned on the unobserved latent variable $z_k$, and $p(z_k|d_i)$ denotes the mixing probability for document $d_i$ to choose the $k$-th component $z_k$ such that $\sum_{k=1}^K p(z_k|d_i)= 1$. Formally, the joint probability of generating an observation pair $(d_i, w_j)$ can be expressed as

```
p(d_i, w_j) = p(d_i)p(w_j|z_k) = p(d_i)\sum_{k=1}^K p(w_j|z_k)p(z_k|d_i). (3.33)
```

Note that there is a conditional independence assumption, i.e., $d_i$ and $w_j$ are independent conditioned on the latent variable. The graphical representation of PLSA is shown in Figure 3.5. From the generative process of view, an observation pair $p(d_i, w_j)$ could be generated by the following:

- (a) select a document $d_i$ with probability $p(d_i)$,
- (b) pick a latent component (i.e. aspect) $z_k$ with probability $p(z_k|d_i)$,
- (c) generate a word $w_j$ with probability $p(w_j|z_k)$.

For a collection of documents $C$, we make the assumption that all co-occurrences of $d_i$ and $w_j$ in the collection are independent identically distributed. Following this likelihood principle, parameters can be determined by maximizing the log-likelihood of a collection as follows:

```
l(C) = \sum_{i=1}^N \sum_{j=1}^M n(d_i,w_j)log p(d_i,w_j) (3.34)
l= \sum_{i=1}^N n(d_i)log p(d_i) + \sum_{i=1}^N \sum_{j=1}^M \sum_{k=1}^K n(d_i,w_j)log p(w_j|z_k)p(z_k|d_i),
```

where $n(d_i)=\sum_j n(d_i,w_j)$ refers to the document length. The parameters $\{p(d_i)\}$ can be estimated trivially. By taking the derivative with respect to $p(d_i)$ and using a Lagrange multiplier, obtain

```
$p(d_i) = \frac{n(d_i)}{\sum n(d_i)}$
```

The other parameters $\Theta$ include $\{p(w_j|z_k)\}$ and $\{p(z_k|d_i)\}$, which can be estimated by using the standard EM algorithm [23, 36]. The total number of parameters is $N+KN+MK$. Since the trivial estimate $p(d_i)$ can be carried out without estimation, we will only consider the second term in the following estimation.

From (3.1), the lower bound $L(q, \Theta)$ on the log-likelihood (the second term of (3.34)) can be written in the form

```
$L(q, \Theta) = \sum_{i=1}^N \sum_{j=1}^M n(d_i, w_j) \sum_{k=1}^K q(z_k) \log \frac{p(w_j|z_k)p(z_k|d_i)}{q(z_k)}$
```

where $q(z_k)$ is an arbitrary distribution over the latent variables. In the E-step, the lower bound is maximized with respect to $q(z_k)$ while holding $\Theta$ fixed, and the solution is to compute the posterior probabilities $p(z_k|d_i, w_j)$ as $q(z_k)$. Therefore, based on the current estimates of parameters, we can simply apply Bayes' formula to compute the posterior probabilities

```
$p(z_k|d_i, w_j) = \frac{p(w_j|z_k)p(z_k|d_i)}{\sum_{k'=1}^K p(w_j|k'})}$ (3.35)
```

In the M-step, parameters are updated by maximizing the expectation of the complete data likelihood $Q(\Theta, \Theta^{(t)})$, which depends on the posterior probabilities computed in the E-step,

```
$Q(\Theta, \Theta^{(t)}) = \sum_{i=1}^N \sum_{j=1}^M n(d_i, w_j) \sum_{k=1}^K p(z_k|d_i, w_j) \log \{p(w_j|z_k)p(z_k|d_i)\}$. (3.36)
```

In order to take into account the probability constraints, (3.36) is augmented by appropriate Lagrange multipliers $\lambda_k$ and $\tau_i$.

```
$\hat{Q} = Q(\Theta, \Theta^{(t)}) + \sum_{k=1}^K \lambda_k \left(1 - \sum_{j=1}^M p(w_j|z_k)\right) + \sum_{i=1}^N \tau_i \left(1 - \sum_{k=1}^K p(z_k|d_i)\right)$.
```

We maximize $\hat{Q}$ with respect to the probability functions $p(w_j|z_k)$ and $p(z_k|d_i)$, leading to the following equations, respectively.

```
$\sum_{i=1}^M n(d_i, w_j)p(z_k|d_i) - \lambda_k p(w_j|z_k) = 0$,
```

```
$\sum_{j=1}^M n(d_i, w_j)p(z_k|d_i) - \tau_i p(z_k|d_i) = 0$.
```

After eliminating $\lambda_k$ and $\tau_i$, we obtain the M-step reestimation equations

```
$P(w_j|z_k) = \frac{\sum_{i=1}^M n(d_i, w_j)p(z_k|d_i)}{\sum_{j'=1}^M n(d_i, w_{j'})p(z_k|d_i)}$}$ (3.37)
```

```
$P(z_k|d_i) = \frac{\sum_{j=1}^M n(d_i, w_j)p(z_k|d_i)}{n(d_i)}$ (3.38)
```

The EM algorithm alternates between the E-step and the M-step until a local maximum of the log-likelihood is achieved or the convergence condition is satisfied.

In clustering models for documents [37], one typically associates a latent class with each document in the document. It can be shown that the hidden classes $z_k$ (i.e. aspect or topics) extracted by the topic modeling approaches can be considered relevant. The posterior probability $P(z_k|d_j)$ is used to infer the cluster label for each document, indicating the posterior probability of document $d_j$ belonging to cluster $z_k$. In principle, this is a soft clustering. In order to obtain a hard clustering, documents are often assigned to the cluster $z_k$ to which they most likely belong.

Although PLSA provides a good probabilistic model for document clustering, it has two problems. First, the number of latent classes grows linearly with the number of documents, so it tends to overfit the training data. Second, although PLSA is a generative model of the training documents it is estimated, it is not a generative model of new documents, and there is no natural way to estimate the probability of a previously unseen document.

## 3.4.2 Latent Dirichlet Allocation

Latent Dirichlet Allocation (LDA) [14, 10] extends PLSA and overcomes problems of PLSA by considering priors on the parameters. As we will see in the following, LDA is a well-defined generative model and easily generalizes to new documents. Furthermore, the $K$ parameters in a $K$-topic LDA model do not grow with the size of the training documents.

Similar to PLSA, LDA is a generative probabilistic model of a collection of documents. The basic idea is that documents are represented as mixtures of latent topics, where each topic is characterized by a distribution over words. The generative model assumes that the topics are specified before any data has been generated. From the generative process point of view, each document $d_n$ in a collection $C$ could be generated by the two-stage process.

- 1. Randomly choose a distribution over topics $\theta_n \sim Dir(\alpha)$.
- 2. For each word $w_{nj}$ in the document $d_n$
  (a) Randomly choose a topic $z_{nj} \sim Multinomial(\theta_n)$.
  (b) Randomly choose a word $w_{nj}$ with probability $p(w_{nj}|z_{nj}, \beta)$.
