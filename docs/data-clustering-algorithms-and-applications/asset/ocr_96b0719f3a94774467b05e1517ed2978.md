The Minkowski distance of order $p$ or the $L_p$-norm, the generalization of Euclidean distance, is defined as:

```
$L_p-\text{norm}(T_1, T_2) = D_{M,p}(T_1, T_2) = \sqrt{\sum_{i=1}^n (T_{1i}-T_{2i})^p} \quad (15.1)
```

The Euclidean distance between two one-dimensional time series $T_1$ and $T_2$ of length $n$ is a special case of the $L_p$-norm for $p=2$ and is defined as

```
$D_E(T_1, T_2) = L_2-\text{norm}(T_1, T_2) = \sqrt{\sum_{i=1}^n (T_{1i}-T_{2i})^2} \quad (15.2)
```

$L_1$-norm (p=1) is known as the Manhattan distance or city block.

# 15.4.1.2 Dynamic Time Warping Distance

Dynamic Time Warping (DTW) is a well-known and widely used shape-based distance measure. DTW computes the warping path $W = w_1, w_2, ..., w_K$ where $\max(m,n) \leq K \leq m+n-1$ for two time series of length $m$ and $n$.

DTW stems from speech processing community [45] and has become popular in the literature of time-series distance measures [6]. Moreover, it has been extended by many approaches to handle multidimensional case of trajectory matching. With dynamic programming DTW between two-dimensional time series $T_1$ and $T_2$ of length $m$ and $n$, respectively, can be computed as

+   (a) $D_{DTW}(T_1,T_2) = 0$, if $m=n=0$
(b) $D_{DTW}(T_1,T_2) = \infty$, if $m \neq n$
(c) $D_{DTW}(T_1,T_2) = \text{dist}(T_{11},T_{21}) + \text{minFactor}$, otherwise

where $minFactor$ is computed as

```
$minFactor = \min \begin{cases} D_{DTW}(\text{Rest}(T_1),\text{Rest}(T_2)) \ D_{DTW}(\text{Rest}(T_1),T_2) \ D_{DTW}(T_1,\	ext{Rest}(T_2)) \end{cases}$
```

where $T_{1,1},T_{2,1}$ is typically the $L_2$-norm. The Euclidean distance, as long as all $L_p$-norms, in 15.4.1.1, performs a one-to-one mapping between the data points of the time series under comparison. It can be seen as a special case of the DTW distance, which performs a one-to-many mapping. DTW is a more robust distance than $L_p$-norm because it allows shifting and matches similar shapes even if they have a phase-difference. An important point is that DTW does not satisfy the triangular inequality while indexing DTW time series. However, in the literature there are lower bounds that serve as solutions for indexing DTW offering faster performance [51]. Another advantage of DTW over $L_p$-norm is that DTW can handle different sampling intervals in the time series. This is a very important feature especially for long time series that span many years the data sampling strategy may change over a long time.
