# 62 Data Clustering: Algorithms and Applications

Data points (or objects) that most likely to the same distribution can easily be defined as clusters.

In this chapter, we introduce several fundamental models and algorithms for probabilistic clustering, including mixture models [45, 48, 25], EM algorithm [23, 46, 53, 16], and probabilistic topic models [35, 14]. For each probabilistic model, we will introduce its general framework of modeling, the probabilistic explanation, the standard algorithms to learn the model, and its applications. Mixture models are probabilistic models which are increasingly used to find the clusters for univariate and multivariate data. We therefore begin our discussion of mixture models in Section 3.2, where the values of the discrete latent variables can be interpreted as the assignments of data points to specific components (i.e., clusters) of the mixture. To make maximum likelihood estimations in mixture models, a general and elegant technique, the Expectation-Maximization (EM) algorithm, is introduced in Section 3. first use the Gaussian mixture to motivate the EM algorithm in an informal way, and then give a more general view of the EM algorithm, which is a standard learning for many probabilistic models. In Section 3.4, we present two popular topic models, i.e., probabilistic latent semantic analysis (PLSA) [35] and Dirichlet allocation (LDA). Note that some of the methods (e.g., EM/mixture models) may be more appropriate for quantitative data, whereas others such as topic models, PLSI, and LDA, are more commonly used for text data. Finally, we give the conclusions and summary in Section 3.3.

# 3.2 Mixture Models

Mixture models for cluster analysis [75, 45, 28, 27] have been addressed in a number of ways. The underlying assumption is that the observations to be clustered are drawn from one of several components, and the problem is to estimate the parameters of each component as to fit the data. Inferring the parameters of these components and identifying which component produced each observation leads to a clustering of the set of observations. In this section, we first give an overview of mixture modeling, then introduce two most common mixtures, Gaussian mixture model and Bernoulli mixture model, and finally discuss several issues about model selection.

# 3.2.1 Overview

Suppose we have a set of data points $X=\{x_1,...,x_N\}$ consisting of $N$ observations of a dimensional variable. The random variable $x_i$ is assumed to be distributed according to a mixture of $K$ components. Each component (i.e., cluster) is mathematically represented by a metric distribution. An individual distribution is then used to model a specific cluster often referred to as component distribution. The entire data set is then modeled by a mixture of these distributions. Formally, the mixture density, or probability density function, of $x_i$, can be written as

```
p(x_i) = \sum_{k=1}^{K} \pi_k p(x_i|\theta_k)
```

where $\pi_1,...,\pi_K$ are the mixing probabilities (i.e., mixing coefficients or weights), each $	heta_k$ is the set of parameters specifying the $k$th component, and $p(x_i|\theta_k)$ is the component distribution. In order to be valid models, the mixing probabilities $\{\pi_k\}$ must satisfy

```
0 \leq \pi_k \leq 1 (k=1,...,K), \text{ and } \sum_{k=1}^{K} \pi_k = 1.
```
