**Accounting for segment correlation.** LDCC inherently assumes that documents are composed of single-topic segments. Consecutive segments often pertain to the same subject, in the same way that paragraphs in a chapter may cover different aspects of the topic discussed. In their follow-up paper, Shafiei and Miloski [96] extended LDCC to potentially identify coherent segments in text. The proposed model, LDSEG, assumes a high likelihood that the segment has the same distribution as the previous segment in the document and models this using a Markov process on the segment-topic distribution. A binary variable for the topic of each segment indicates whether it is the same as that of the previous segment. If it is not, a new topic is sampled for the current segment. The list of states for this switching variable also defines a segmentation in each document. Figure 13.6 (b) depicts the plate notation of the LDSEG model, whose generation process for each document is detailed below.

**A framework for generative clustering.** Tompi and Tagarelli recognize the segment topic coherence assumption and provide a topic-based framework for clustering multi-documents using generative models [83]. Instead of assigning documents to clusters, Tompi and Tagarelli cluster documents based on their topic distributions. The proposed framework executes three steps. First, the documents are processed using standard preprocessing techniques to obtain the term matrix. Then, a generative model is applied to represent the documents in a topic latent space. The output of this step is a probability matrix expressing the topic mixture underlying the documents.
