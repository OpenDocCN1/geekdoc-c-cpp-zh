上述度量在计算簇间分离度时，使用簇内对象之间的平均（最小）成对距离，或使用一个对象（簇中心）作为整个簇的代表。这些度量仅考虑对象的位置，未能考虑到构成簇几何信息的分布。另一方面，CVNN 基于携带每个簇几何信息的对象来评估簇间分离度。CVNN 与 knn 共享相同的思想，在不同情况下使用多个对象作为不同簇的代表。

由于仅在球形簇的情况下才有意义使用中心来代表整个簇，这意味着这些指标只能在超球体条件下工作。图 23.15 显示簇 A 和 B 具有任意结构，且簇中心甚至不在簇内。如果将簇 B 从基线移动，A 和 B 变得更近，而它们中心之间的距离却变大。在这种情况下，将簇中心作为整个簇的代表是没有意义且错误的。

图 23.16 说明了代表在不同情况下如何演变的动态效应。在此示例中，簇 A 和 B 均具有任意结构，实心对象是 CVNN 度量选择的代表。比较子图 (a) 与 (b)，可以看出 A 和 B 比以前更接近，这表明簇间分离度在变差。与此同时，两个簇的代表数量也在增长，以及 CVNN 中的簇间分离度度量也在增长，这与簇变得更加分离的指示一致。此示例说明了 CVNN 簇间分离度的动态效应，因为同一两个簇的代表在不同情况下是不同的。

# 23.4 总结

本章以全面方式对 16 个外部验证度量和 12 个内部验证度量在这些验证度量的各个方面进行了详细研究。对于外部验证部分，不同度量被比较和对比用于 K-means 聚类。如结果所示，在使用验证度量进行聚类验证之前，有必要对其进行归一化，因为未归一化的度量可能导致不一致甚至误导性的结果。对于具有不平衡类别分布的数据尤其如此。还为一些验证度量提供了归一化解决方案。此外，还提供了引理以表明某些验证度量在数学上等价，而某些度量的性能非常相似。16 个度量的关键属性已总结；这些属性应在实践中决定使用何种合适的度量之前予以考虑。

对于内部部分，研究了 12 个内部验证度量在六个不同方面的验证属性：单调性、密度、子簇和任意形状。六个合成数据集最好地代表了上述六个方面，用于评估 12 个验证度量的性能。研究结果表明，除了 CVNN 指标外，所有度量在不同应用场景中都有局限性，尤其在处理具有任意形状的数据时存在困难。另一方面，CVNN 利用最近邻的概念，并在不同情况下使用动态多个对象作为不同簇的代表，这使其在数据集包含任意形状簇时特别有用。12 个内部验证度量的汇总验证度量可作为实践中指标选择的指南。
