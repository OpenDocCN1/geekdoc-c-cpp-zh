# 20.2.2 Semisupervised Clustering Based on Pairwise Constraints

One of the popular frameworks for SSC is based on pairwise constraints. Given a dataset $X$, pairwise supervision is typically given in the form of two types of constraints: *must-link* and *cannot-link* constraints. If $(x_i, x_j) \in M$, the set of must-link constraints, then the clustering algorithm is encouraged to keep $(x_i, x_j)$ in the same cluster; if $(x_i, x_j) \in C$, the set of cannot-link constraints, then the algorithm is encouraged to keep $(x_i, x_j)$ in different clusters. Several approaches use a suitable violation penalty, whereas others consider the constraints to be binding [37, 5, 20, 38].

One of the early approaches to SSC with pairwise constraints focused on modifying the $k$-means algorithm [38] to incorporate must-link and cannot-link constraints. In each iteration of the algorithm, a sorted list of clusters is considered for every point. The algorithm moves the list until a cluster assignment is found that does not violate any constraints. If no such cluster is found, the algorithm terminates.

The approach presented in [38] showed a considerable improvement over the unsupervised version of $k$-means and allowed semupervised knowledge to be incorporated. However, one drawback from a practical standpoint is the requirement for all constraints to be satisfied. One has to ensure that contradicting constraints are satisfied.

Alternative approaches focused on modifying the $k$-means objective to take into account pairwise constraint violations [3] of them in literature. In particular, the pairwise constrained clustering with $k$-means (PCMeans) objective function can be written as:

```
$J_{PC}(M,Y) = \frac{1}{2} \sum_{x_i \in X} ||x_i - \mu_{y_i}||^2 + \sum_{(x_i,x_j) \in M} W_{ij} 1(y_i \neq y_j) + \sum_{(x_i,x_j) \in C} W_{ij} 1(y_i = y_j) ,$
```

where $W_{ij}$ are appropriate constraints that serve as penalties for constraint violation, $M ={\{\mu_1, \dots, \mu_k\}$ is the set of cluster means, and $Y ={\{y_1, \dots, y_k\}$, where $y_i \in \{1, \dots, k\}$ are the cluster ids of the data points. One of the prominent trends of development involves incorporating metric learning which suitably modifies how distances are computed between points and clusters.

**Local Metric Learning:** Metric learning approaches in the context of clustering focus on a parameterized divergence, One can consider a semisupervised metric learning approach, where the parameters are chosen based on unsupervised objective

```
$J_{LML}(M,Y,\mathcal{A}) = \frac{1}{2} \sum_{x_i \in X} (x_i - \mu_{y_i})^T A_{y_i}^{-1} (x_i - \mu_{y_i}) + log(det(A_{y_i})) ,$
```

where $A_y$ is a positive definite matrix for cluster $y$, and $\mathcal{A} ={\{A_1, \dots, A_k\}$. One can consider $A_y^{-1}$ as the covariance of the multivariate Gaussian distribution corresponding to cluster $y$. Since each cluster $h = 1, \dots, k$ has its own parameter $A_h$, this can be considered a local metric learning approach.
