## 9.5 开放问题与当前研究方向

在 KDD 2010 [50] 的 “Discovering, Summarizing and Using Multiple Clusterings”（MultiClust）研讨会系列、ECML/PKDD 2011 [109] 以及 SDM 2012 [110] 上，一些有趣的研究方向受到了关注。有趣的是，子空间聚类中类似的问题也存在于其他领域，如集成聚类、替代聚类或多视图聚类 [93]。这些领域共有的典型问题是 (i) 如何处理聚类解的多样性（是否应统一多样化的聚类解或将其呈现出来？），(ii) 如何有效地总结并向聚类算法的用户呈现结果，(iii) 如何处理聚类的冗余性，以及如何评估多个聚类解之间的相似性。子空间聚类起源于频繁模式匹配的联系，已从研究领域 [94] 的一个较新的观点进行了讨论。

正如我们指出的那样，子空间聚类结果的冗余性是一个问题，源自最早方法自下而上的策略，该策略借鉴了频繁模式匹配。对于当前子空间聚类的研究，消除过多的冗余是一个主要课题 [70, 105]。关于多聚类 [28, 36, 80, 72] 的研究似乎是从相反的方向接近该问题，但同样针对同一问题，寻求允许一定的冗余，以便排除可能有趣的概念，即使它们可能与其他聚类有一定程度的重叠。相关工作通过直接评估不同划分之间某种距离的概念来解决不同聚类区分度的问题（所谓的替代聚类方法） [60, 61, 21, 38, 19, 37, 116]。

与冗余问题相关的一个问题是适当的密度水平。这也是密度聚类中的一个普遍问题 [81]，但对于子空间中的聚类，该问题更加严重。APriori 风格的子空间搜索的固定密度阈值并不适用于所有可能的子空间。例如考虑 CLIQUE 风格的网格方法：超立方体的体积随维度呈指数增长；密度下降。因此，任何选择的阈值都需要识别（最多）特定维度的聚类。这促使了自适应密度阈值的研究 [18, 106]。当使用欧几里得距离（$L_2$）时，ε 范围的适当选择也变得极其具有挑战性，不仅对于子空间聚类，而且对于任意方向聚类也是如此，这是由于超球体体积随维度增加而产生的反直觉行为。已提倡以对象数量或 ε 范围查询的 k 近邻半径来表示邻域的大小作为该问题的变通方法 [7]，以至少解决某些方面的问题，例如为密度估计或邻域空间特征的估计提供一个明确的（非空）对象集合。

## 9.6 结论

数据挖掘以及相关学科如统计学、模式识别、机器学习，甚至应用科学（如生物信息学）的研究导致了大量聚类技术，并解决了高维数据聚类的专门问题。每年在众多会议和期刊上都会提出该问题的新的方法。然而，许多研究者认为不存在一种适用于所有问题且普遍适用于任意数据的通用聚类技术。具体数据的集合会影响算法的选择，这对于聚类而言是正确的，但即使某些任务涉及高维数据也是如此。

在本章中，为了引导读者找到最适合其所面临任务的文献，我们区分了不同的问题设置，轴平行子空间聚类以及“子空间聚类”（狭义）、“（软）投影聚类”家族，以及日益增多的“混合”方法；以及任意方向子空间聚类（也称为“相关聚类”）。在这些领域中，可以找到由“维度诅咒”所解决的不同问题设置。维度诅咒是我们无法解决的问题。这种“诅咒”有不同的方面，如果某种方法考虑了其中一个方面，其他方面仍会困扰研究者。

轴平行子空间和投影聚类算法家族假设属于同一聚类的对象在欧几里得空间中彼此靠近，但允许对象相对于属性子集的对应距离来处理无关属性的问题。基于模式的方法通常不同意聚类由在欧几里得空间或某个子空间中彼此靠近的对象组成，而是在收集在属性子集上遵循相似行为模式的对象。相关算法推广到任意正负相关，但通常也假设点在欧几里得空间中具有一定的密度。最后，让我们注意，不同算法类采用的不同相似性概念是不兼容的。相反，每个类的算法或多或少是针对类特定的相似性概念量身定制的。用户不应问：“哪种是迄今为止最好的聚类算法？”而应问：“哪种聚类（及其假设和限制）最适合我的问题？”本章旨在为此提供一些有用的指导。
