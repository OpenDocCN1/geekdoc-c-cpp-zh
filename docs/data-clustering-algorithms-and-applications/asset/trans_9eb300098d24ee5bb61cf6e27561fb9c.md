## 12.4.1.3 模糊 k-Modes

模糊 k-Modes 将模糊-Means 扩展到分类数据 [48]。模糊 k-Modes 基于与 k-Modes 相同的思想，使用迭代地将对象分配到最近的模式并评估模式，直到收敛。然而，对象对聚类的分配涉及介于 0 和 1 之间的隶属度。对象 $i$ 在所有聚类中的总隶属度必须等于 1，如 $\sum_{j=1}^k w_{ij} = 1$，对于任意 $i \le n$。模糊 k-Modes 算法针对整个数据集 $X$ 评估总成本，针对成本函数 $F(W, X, Z) = \sum_{i,j} w_{ij}^\alpha d(X_i, Z_j)$，其中 $\alpha \ge 1$ 是加权因子且 $Z_j = [z_{j1}, \dots, z_{jm}]$ 是第 $j$ 个聚类的模式。权重 $0 \le w_{ij} \le 1$ 在每次迭代时设置，使得第 $j$ 个对象将倾向于加入与模式 $Z_j$ 不相似度最小的第 $j$ 个聚类。在模式中，聚类 $l \le j \le k$ 的 $Z_j$，表示为 $[z_{j1}, \dots, z_{jm}]$，其每个位置 $z_{j j}$ 对应属性 $A_j$ 将最小化成本函数。成本函数是所有对象相对于聚类模式的加权距离之和。已证明 k-Means 算法将在有限次迭代内收敛。其缺点是它在局部最优处终止。

## 12.4.1.4 Squeezer

Squeezer 是一种基于汇总聚类类似 k-Modes 的单遍算法。然而，Squeezer 改进了 k-Modes 的迭代受限速度 [43]。Squeezer 逐个读取对象。第一个元组单独形成一个聚类。下一个对象要么放入现有聚类，要么被拒绝以形成新聚类。
Squeezer 算法接受对象数据集和相似度阈值 $s$ 的值作为输入。然后算法以迭代方式获取聚类对象。最初，读取第一个对象并建立一个新的聚类结构，其中包括摘要和聚类本身。对于每个后续对象，计算任意现有聚类 C 与该对象之间的相似度。计算结果中评估最大相似度值（表示为 sim-max）和对应聚类的索引（表示为 index）。然后，如果相似度大于输入阈值 $s$，则对象被分配到所选聚类。否则，构建一个新的聚类结构，由聚类和摘要组成。最后，处理离群值并返回聚类结果。

Squeezer 的缺点之一是，在某些数据集上，它可能无法产生准确的聚类。Squeezer 被认为效率很高，复杂度为 $O(kN)$。

## 12.4.1.5 COOLAT

COOLAT 基于与 k-Modes 类似的思想，但使用对象作为聚类。COOLAT 适应了 k-Modes 对聚类模式问题的敏感性。通过减少其熵来创建聚类 [19]。COOLAT 找到一组最大不相似的对象来创建初始聚类。所有剩余对象都被放置在其中一个聚类中，使得熵的增加最小化。COOLAT 的名称来自聚类熵的减少，“冷却”。熵是随机变量的信息和不确定性的度量。如果 $X$ 是随机变量，$S(X)$ 是 $X$ 的概率函数，熵 $E(X)$ 定义为 $E(X) = \sum_{x \in S(X)} p(x)\log(p(x))$。熵有时被称为系统“无序”程度的度量。作者认为，两个向量之间相似性的度量，使用熵等同于其他广泛使用的相似性度量。

COOLAT 从一组点开始。初始步骤从样本集中选择 k 个最不相似的对象，使得所选对象的成对熵最大化。这些作为 k 个聚类的初始代表。数据集的所有对象都被放置在其中一个聚类中，在每一步中，使 resulting 聚类的熵增加最小化。初始化后，COOLAT 继续处理数据集的对象（未选为选择聚类的对象进行增量），为每个对象找到合适的聚类。这是通过计算将对象放置在每个聚类中后结果的预期熵并为每个对象选择聚类来完成的。表 12.2 比较了三种聚类以及使预期熵最小化的聚类。

COOLAT 的缺点包括其对对象选择顺序的敏感性，以及 O(n^2) 的二次复杂度。

## 12.4.2 层次聚类

层次算法将对象划分为节点树，其中每个节点代表一个潜在聚类 [56, 61]。应用于分类数据的层次聚类方法通常以聚合（自底向上）方式对数据进行聚类，其中最相似的对象在树的不同层级逐渐聚类。对于选择相似度度量，采用分裂（自顶向下）方式，其中每一层级的每个节点由 resulting 聚类的统计摘要组成，并将新对象放置在最合适的聚类中。

分类数据的层次方法的缺点包括其二次运行时间和通常较慢的速度。合并聚类中的错误无法撤销并会影响结果。如果大聚类过早合并，局部聚类结构可能会丢失。接下来，我们将讨论几种用于分类数据的层次聚类算法。

## 12.4.2.1 ROCK

ROCK 是一种凝聚（自底向上）层次算法 [39]。ROCK 通过构建树来处理分类数据聚类；在每个树层级，聚类以使 resulting 聚类相似度最大化的方式合并，其中相似度通过 resulting 聚类内相似对象对的数量来评估。ROCK 假设对象之间存在特殊相似度度量，并定义两个对象之间的“链接”，其相似度超过阈值。

ROCK 的动机是开发一种考虑对象之间链接的全局聚类方法。为此目的，ROCK 使用共同邻居来定义链接。如果邻居对象 C 和对象 B 链接（即使它们不是邻居）。属于同一聚类的两个对象有许多共同邻居，而属于不同聚类的对象有很少共同邻居。最初，每个对象被分配到单独的聚类。聚类根据其“接近度”重复合并，定义为聚类内所有对象对之间链接数量之和。

为了决定哪些对象是“邻居”，ROCK 定义了一个相似度函数 sim(A,C)，它编码两个对象之间的相似度（“接近度”）水平。相似度是归一化的，使得 sim(A,C) 在 A 和 C 完全相同时为一，在完全不相似时为零。如果 sim(A,C) > θ，则对象 A 和 C 被认为是“邻居”，其中 θ 是用户提供参数。Link(A,B) 定义为 A 和 B 之间的共同邻居数量。相似度可以是任何度量，例如欧几里得距离或 Jaccard 系数。

层次聚类算法使用样本的链接。它迭代合并聚类 Ci, Cj 以最大化 goodness 函数

```
g(Ci,Cj) = \frac{total#crosslinks}{expected#crosslinks} = \frac{(ni+nj)*1+2(f(0))-ni}{nj-1+2(f(0))-nj}
```

它在聚类之间不再有链接或达到所需聚类数量时停止。

最佳聚类集通过使用准则函数 Er 来表征，最佳聚类集是使 Er 最大化的集合。每个聚类中成对之间的链接数量：Er = \sum \sum link(pq,pr)。该准则使共享许多链接的点保持在同一聚类中，但它不会强制链接拆分到不同聚类。该准则方法可能导致一个大聚类，或导致相对较弱的聚类。

ROCK 的缺点包括其在 N 上的三次复杂度，这使其通常不适合大型数据集 [38, 76]。

## 12.4.2.2 COBEW

COBEW 表示为分类树的层次聚类。COBEW 将对象组织成分类树。分类树与决策树不同，后者标记分支而不是节点并使用逻辑而非概率描述。分类树中的兄弟节点形成叶分区 [31]。

分类树中的每个节点代表一个类（概念），并由节点下对象的概率属性-值分布标记。该分类树可用于预测新对象的类或缺失属性。COBEW 通过沿最佳匹配节点的路径对对象进行分类，将对象增量集成到现有分类树中。

COBEW 在构建分类树时采用四种操作。选择哪种操作取决于其所实现分类树的类别效用：

- 1. 插入节点：创建一个节点，对应于要插入树中的对象。
- 2. 合并两个节点：将两个节点替换为一个节点，其子节点为原始节点的并集。新节点汇总了在下面分类的所有对象的属性-值分布。
- 3. 拆分节点：通过用其子节点替换它来拆分节点。
