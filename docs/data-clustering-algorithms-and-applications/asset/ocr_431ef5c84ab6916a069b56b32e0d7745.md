# 23.2.2 A Necessary Selection Criterion

Assume that there is a sample data containing 50 documents from 5 classes. The class sizes are 30, 2, 6, 10 and 2. Thus, $CV_0=1.166$, which implies a skewed class distribution.

For this data set, assume that there are two clustering results as shown in Table 23.3. In fact, the results consist of five clusters with extremely balanced sizes. This is also indicated by $CV_1 = 0$. For the second result, the five clusters have cluster sizes with $CV_1 = 1.125$, much closer to the value of the "true" class sizes. Therefore, from a distribution point of view, the second result should be better than the first one.

In addition, by looking a clustering Matrix M in Table 23.3, one can find that the first clustering objects of the largest class $C_1$ into three balanced subclusters. Meanwhile, the two small classes $C_2$ and $C_5$ have "disappeared"—they are overwhelmed by $P_3$ by the objects from $C_3$. In fact, it is easy to identify that all the classes in the second clustering have the majority of objects in the corresponding clusters. Therefore, it is the conclusion that the first clustering is much better than the second one.

As shown in Section 23.2.2.1, $K$-means to produce clusters with relatively uniform sizes. Thus the first clustering in Table 23.3 can be regarded as the negative result of the uniform effect. Thus the first necessary but not sufficient criterion for selecting the measures for $K$-means is as follows.

> **Criterion 1** *If an external validation measure cannot capture the uniform effect by K-means on data with skewed class distributions, this measure is not suitable for validating the results of K-means clustering*

The performance of existing cluster validation measures for this criterion is presented in the next section.
