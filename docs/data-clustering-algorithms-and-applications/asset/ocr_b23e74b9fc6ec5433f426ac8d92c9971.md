The Rand statistic [23], Jaccard coefficient, Fowlkes and Mallows index [13], and Hubert’s statistics [22], evaluate the clustering quality by the agreements and/or disagreements of the pairs of data objects in different partitions.

The Minkowski score [3] measures the difference between the clustering results and a reference (true clusters). The difference is computed by counting the disagreements of the pairs of data objects in two partitions.

The classification error takes a classification view on clustering [6]. It tries to map each class to a different cluster so to minimize the total misclassification rate. The “σ” in Table 23.1 is the mapping of class to σ(j).

The Van Dongen criterion [80] was originally proposed for evaluating graph clustering. It measures the representativeness of the major objects in each class and each cluster. Finally, the micro-average precision, Goodman–Kruskal coefficient [15], and Mirkin metric [43] are popular measures. However, the former are equal to verify the purity and the Mirkin metric against the Rand statistic (M/2ⁿ + R = 1). Some discussion on Goodman–Kruskal Mirkin metric can be found in Section 23.2.4,3.

# 23.2.2 Defective Validation Measures

In this section, some validation measures produce misleading validation results for data on skewed class distributions are presented.

# 23.2.2.1 K-Means: The Uniform Effect

One of the unique characteristics of $K$-means clustering is the so-called uniform effect; $K$-means tends to produce clusters with relatively uniform sizes [64]. The coefficient of variation (CV) [10], which measures the dispersion of a random distribution, is the standard deviation to the mean, is used to quantify the uniform effect. CV is for data objects $X = \{x_1, x_2, ..., x_n\}$, where $s = s/ar{x}$, where $ar{x} = \sum_{i=1}^n x_i/n$ and $s = \sqrt{\sum_{i=1}^n (x_i-ar{x})^2/(n-1)}$. CV is a dimensionless number that allows the comparison of populations that have different mean values. In general, the larger the CV value, the greater the value in reality.

Let $CV_0$ denote the CV of the “true” classes and $CV_1$ denotes the CV of the result clusters. The “true” clusters of data set [59] is used to illustrate the uniform effect by $K$-means. The clusters of sparse apart have $CV_0=1.02$. The CLUTO implementation of [27] with default results is employed to cluster $x$ into seven clusters, and the CV of the result cluster size is $0.42$. The CV difference is $DCV=CV_1-CV_0=-0.6$, which indicates a significant effect in the clustering result.

It has been empirically observed that the 95% confidence interval of $CV_1$ values produced by $K$-means is in $[0.83, 1]$. In these works, for data sets with CV values greater than $0.83$, the uniform effect of $K$-means can distort the cluster distribution significantly.

Now the question is: Can these used validation measures capture the negative uniform effect by $K$-means clustering? A necessary, but not sufficient criterion is provided to test whether a validation measure can be effectively used to evaluate $K$-means clustering.
