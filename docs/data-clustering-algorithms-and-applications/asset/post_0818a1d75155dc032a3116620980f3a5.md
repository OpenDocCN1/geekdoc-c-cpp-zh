## 16.2.3.2 Probabilistic Clustering

Since some of the genes are regulated by several biological pathways, it is important to avoid overlapping clusters; i.e., some genes might appear in multiple clusters. Probabilistic clustering provides an intuitive solution to this problem by implicitly modeling this nature through assigning probabilistic memberships. The most popular choice of probabilistic clustering of the data is developing a model-based approach. Model-based clustering assumes that the gene expression data is generated by a finite mixture of probability distributions [118]. The primary challenge is to estimate the best probabilistic model that represents the patterns in the complex data. A popular Model-based Clustering algorithm, MCLUST, uses Gaussian distributions for clustering microarray data [118]. The basic idea is that each cluster is generated by an underlying Gaussian distribution. More details about clustering using Gaussian mixtures are given in Chapter 3. It should be noted before applying any model-based approach, the raw gene expression data is first transformed or normalized. Several transformation methods have been shown to achieve good results when applying the model-based clustering. The other choice for probabilistic clustering is to apply a Fuzzy C-means (FCM) algorithm to cluster the gene expression data [26]. More details about this algorithm are available in Chapter 4.

## 16.2.3.3 Graph-Theoretic Clustering

In the graph-theoretical approach, a graph is constructed where the nodes are the genes and the edges are the similarities between the nodes. After constructing the graph, the problem of clustering is transformed into finding minimum cut or maximal cliques in the proximity graph. Identification via Connectivity Kernels (CLICK) is a graph-theoretical algorithm that defines clusters as highly connected components in the proximity graph [95]. This algorithm does not make any prior assumptions about the number or the structure of the clusters.

Affinity Search Technique (CAST) is another graph-based clustering algorithm [14]. This algorithm alternates between adding high affinity elements to the current cluster and removing low affinity elements from this cluster. The affinity between gene i and cluster C is defined as the sum of the similarities between gene i and all genes in cluster C. The CAST algorithm aims to find clusters so that the affinity between genes and clusters is maximized. It adds a gene to a cluster if its affinity is higher than specified threshold. CAST repeats this operation over all genes and clusters, until all genes are assigned to one of the clusters. One of the advantages of this algorithm is that it does not require a predefined number of clusters and can efficiently handle outliers.

Another graph-theoretical algorithm that uses Minimum Spanning Tree (MST) for clustering expression data has been proposed in [114]. One of the key properties of the MST representation is that each cluster of the data corresponds to one subset of the MST, which will transform a multidimensional clustering problem to a tree partitioning problem. The structure of an MST facilitates efficient implementations of clustering algorithms, and it does not depend on detailed geometric shape of a cluster. The implementation of this algorithm is available in a software package called Expression Data Clustering Analysis and Visualization Resource (EXCAVATOR).

## 16.2.4 Self-Organizing Maps

Self-Organizing Maps (SOMs) [64] is a clustering algorithm that is based on neural networks with a single layer. The clusters are identified by mapping all data points to the output neurons [103]. SOMs require the number of clusters and the grid layout of the neuron map as the user input. An unsupervised neural network algorithm called the Self-Organizing Tree Algorithm (SOTA), was studied in [49]. SOTA is a top-to-bottom hierarchical clustering method that is built using SOMs.

## 16.2.3.5 Other Clustering Methods

k-means clustering has been applied to the problem of clustering gene expression data [50]. In spite of its simplicity and efficiency, it is not well suited to the problem of gene expression clustering due to the following reasons:

- Gene expression data typically contains a lot of noise. The standard k-means algorithm is known to be sensitive to noise due to the objective function (mean square) it optimizes.
- Since the number of clusters is unknown before for gene expression data, there is a need to run this algorithm several times with different inputs. For large datasets, such an approach becomes impractical.

However, other variations of the k-means algorithm have been proposed to overcome some of its drawbacks [104]. Resampling methods were proposed in [32]. In these ensemble methods, clustering is applied to bootstrap learning sets, and the resulting multiple partitions are combined by averaging. Clustering gene expression data using Principal Components Analysis (PCA) was studied in [120]. However, it was shown that clustering with the principle components instead of the original variables often degrades the cluster quality. Therefore, PCA was not recommend before clustering except in specific cases [120].

## 16.2.4 Clustering

Standard clustering techniques discussed in the previous section typically assume that closely related genes must have similar expression profiles across all the conditions [69]. However, this assumption does not hold in all of the biological experiments. From a practical point of view, not all the genes are involved in each biological pathway, and some of pathways may be active under only a subset of the samples [75]. Hence, clustering was proposed to overcome the limitations of the traditional clustering algorithms [71].

The objective of clustering is to simultaneously cluster both rows and columns in a given matrix. Clustering algorithms aim to discover local patterns that cannot be identified by traditional one-way clustering algorithms. A bicluster can be defined as a subset of genes that are correlated under a subset of biological conditions (or samples). Clustering has been used in several applications such as microarray data [71], identifying protein interactions [68], and other data mining applications as collaborative filtering [40] and text mining [18].

The concept of bicustering is illustrated using a simple example in Figure 16.2. In this example, the expression levels of three genes over 10 conditions are shown. Considering all of the ten samples, it is evident that there is no strong correlation between the three genes (Figure 16.2(a)). However, in that there is a strong correlation between the three genes in a subset of the conditions, namely [2, 3, 5, 8] (Figure 16.2(b)). Here, we will consider these three genes to be highly correlated though traditional proximity measures that consider all of the conditions determine that these genes are not correlated. Biclustering has emerged as a powerful tool to simultaneously overlapping clusters in a data matrix by utilizing the relationship between the genes and the samples. It has been proven that the task of finding all the significant bicusters is an NP-hard problem [21].

There are several challenges that arise when searching for clusters in expression data. A subset of genes can be correlated only in a small subset of conditions due to the heterogeneity of samples. Heterogeneity arises due to the complexities involved with different diseases, different patients, different timepoints, or different stages within a disease. In addition, since genes can be positively or negatively correlated [54], it is important to allow all types of clusters in the same bicluster. Moreover, there are several types of bicusters that can be biologically relevant [71].
