## 20.2 Clustering with Pointwise and Pairwise Supervision

Semisvised clustering with pointwise and pairwise supervision has been widely studied for feature-based clustering methods. In this section, we review some of the approaches from the literature [6].

### 20.2.1 Semisvised Clustering Based on Seeding

One of the earliest ideas on SSC focused on pointwise label supervision, where the cluster ids of a small number of points are available. SSC based on seeding focuses on centroid-based clustering algorithms, such as k-means [2, 11]. In an unsupervised setting, algorithms usually start from a random initialization and perform expectation-maximization (EM)-style iterative updates of cluster members and cluster prototypes. The main idea in SSC based on seeding is to improve the initialization based on the available cluster ids. In particular, [2] lists two variants to k-means: *seeded k-means* and *constrained k-means*. Seeded k-means initializes the clusters using the available clusters and then runs the iterative updates for k-means. In k-means, let $K$ be the number of clusters and $S = \{x_1, ..., x_n\}, x_i \in \mathbb{R}^d$ denote the set of data points, let $K$ be the number of clusters and set $S = \cup_{j=1}^K S_j$ denote the initial seeds. The objective function improves as the iterative updates change. The *seeded k-means* algorithm is summarized in the following steps:

- Initialize cluster centers $\mu_h \leftarrow \frac{1}{|S_h|} \sum_{x \in S_h} x$, for $h = 1, ..., K$
- Assign each data point to the cluster $h^* = \text{argmin}_h |x - \mu_h|^2$
- Estimate cluster centers $\mu_h \leftarrow \frac{1}{|S_h|} \sum_{x \in S_h} x$, for $h = 1, ..., K$
- Repeat last steps until convergence

Constrained k-means also initializes the clusters with the available cluster ids, but the cluster assignments of these labeled points are not allowed to change during the iterative updates. *Seeded k-means* is more appropriate when the label seeding is not false.

SSC based on seeding can be generalized to other clustering methods beyond k-means, and [2] empirically evaluate the spectral-k-means. The seeding approach can be viewed in the probabilistic setting where we use the EM algorithm to learn mixture models [21], and each mixture component corresponds to a cluster. In particular, the supervision is used to set the posterior probability $p(z|x_i, \Theta)$ of the labeled points to be the true class, 0 or otherwise. Empirical results in [2] illustrate the advantages of the seeding approach, with clustering performance sharply increasing with a small number of nodes. The method has also been applied to the scenario where the labeled data covers only a fraction of the clusters, and the centroids of the other clusters have to be randomly initialized.

### 20.2.2 Semisupervised Clustering Based on Pairwise Constraints

One of the popular frameworks for SSC is based on pairwise constraints. Given a dataset $X$, pairwise supervision is typically given in the form of two types of constraints: *must-link* and *cannot-link* constraints. If $(x_i, x_j) \in M$, the set of must-link constraints, then the clustering algorithm is encouraged to keep $(x_i, x_j)$ in the same cluster; if $(x_i, x_j) \in C$, the set of cannot-link constraints, then the algorithm is encouraged to keep $(x_i, x_j)$ in different clusters. Several approaches use a suitable violation penalty, whereas others consider the constraints to be binding [37, 5, 20, 38].

One of the early approaches to SSC with pairwise constraints focused on modifying the $k$-means algorithm [38] to incorporate must-link and cannot-link constraints. In each iteration of the algorithm, a sorted list of clusters is considered for every point. The algorithm moves the list until a cluster assignment is found that does not violate any constraints. If no such cluster is found, the algorithm terminates.

The approach presented in [38] showed a considerable improvement over the unsupervised version of $k$-means and allowed semupervised knowledge to be incorporated. However, one drawback from a practical standpoint is the requirement for all constraints to be satisfied. One has to ensure that contradicting constraints are satisfied.

Alternative approaches focused on modifying the $k$-means objective to take into account pairwise constraint violations [3] of them in literature. In particular, the pairwise constrained clustering with $k$-means (PCMeans) objective function can be written as:

$J_{PC}(M,Y) = \frac{1}{2} \sum_{x_i \in X} ||x_i - \mu_{y_i}||^2 + \sum_{(x_i,x_j) \in M} W_{ij} 1(y_i \neq y_j) + \sum_{(x_i,x_j) \in C} W_{ij} 1(y_i = y_j)$

where $W_{ij}$ are appropriate constraints that serve as penalties for violation, $M = \{\mu_1, \dots, \mu_k\}$ is the set of cluster means, and $Y = \{y_1, \dots, y_k\}$, where $y_i \in \{1, \dots, k\}$ are cluster ids of the data points. One of the trends of development involves incorporating metric learning which modifies how distances are computed between clusters.

**Local Metric Learning:** Metric learning approaches in the context of clustering focus on a parameterized divergence. One can consider a supervised metric learning approach, where the parameters are chosen based on unsupervised objective

$J_{LML}(M,Y,\mathcal{A}) = \frac{1}{2} \sum_{x_i \in X} (x_i - \mu_{y_i})^T A_i^{-1} (x_i - \mu_{y_i}) + \log(\det(A_i))$

where $A_y$ is a positive definite matrix for cluster $y$, and $\mathcal{A} = \{A_1, \dots, A_k\}$. Since each cluster $h = 1, \dots, k$ has its own parameter $A_h$, this can be considered a metric learning approach.

In [9], a hybrid approach is proposed which is capable of incorporating constraints in terms of must-link and cannot-link constraints, and also adapting the underlying distance measure. The method works by combining two clustering objectives in Equation 20.1 and Equation 20.2. The combined objective is given by

$J_{P}(M,Y,\mathcal{A}) = \sum_{\mathbf{x}_i \in \mathcal{X}} \{(\mathbf{x}_i - \boldsymbol{\mu}_{y_i})^T A_i(\mathbf{x}_i - \boldsymbol{\mu}_{y_i}) + \log(\det(A_i))\} + \sum_{\mathbf{x}_i,\mathbf{x}_j \in M} w_{ij}f_m(\mathbf{x}_i,\mathbf{x}_j)[y_i \neq y_j] + \sum w_{ij}f_c(\mathbf{x}_i,\mathbf{x}_j)[y_i = y_j]$

where $f_m$ and $f_c$ are functions functions on $(\mathbf{x}_i, \mathbf{x}_j)$. The function $f_m$ is defined such that the penalty for violation of must-link constraints between points that are distant should be higher. Since distant points need to be must-linked, the metric used needs a major update to accomplish that, the penalty is defined in terms of both:

$f_M(\mathbf{x}_i,\mathbf{x}_j) = \frac{1}{2}(\mathbf{x}_i - \boldsymbol{\mu}_{y_i})^T A_i(\mathbf{x}_i - \boldsymbol{\mu}_{y_i}) + \frac{1}{2}(\mathbf{x}_j - \boldsymbol{\mu}_{y_j})^T A_j(\mathbf{x}_j - \boldsymbol{\mu}_{y_j})$

In the case of cannot-link violations, the penalty for nearby points should be higher. The following penalty term is considered:

$f_C(\mathbf{x}_i,\mathbf{x}_j) = \frac{1}{2}(\mathbf{x}_i - \boldsymbol{\mu}_{y_i})^T A_i(\mathbf{x}_i - \boldsymbol{\mu}_{y_i}) - \frac{1}{2}(\mathbf{x}_j - \boldsymbol{\mu}_{y_j})^T A_j(\mathbf{x}_j - \boldsymbol{\mu}_{y_j})$

where $(\mathbf{x}_i, \mathbf{x}_j)$ are maximally separated sets of points in the data according to $A_l$. These weight functions are introduced in order to produce more relevant to the constraints. The objective function is optimized by the EM algorithm, which alternates between updating the cluster assignments, and updating the cluster means $\mu_0$ and $A_0$ until convergence. For scalability and stability, [9] suggests using metrics with simpler structures, such as diagonal matrices, for high-dimensional problems.

**Global Metric Learning:** A generalization of the PCMeans setting was considered in the literature [9, 5, 4], where the distance metric to measure the within-cluster distortion is global and parameters are learned as part of the SSC. In particular, if $A$ is a positive definite matrix, one considers the following:

$J_{GL}(M,Y,\mathcal{A}) = \frac{1}{2}\sum_{\mathbf{x}_i \in \mathcal{X}} (\mathbf{x}_i - \boldsymbol{\mu}_{y_i})^T A_i(\mathbf{x}_i - \boldsymbol{\mu}_{y_i}) + \sum_{\mathbf{x}_i,\mathbf{x}_j \in M} w_{ij}[y_i \neq y_j] + \sum_{\mathbf{x}_i,\mathbf{x}_j \in \mathcal{X}} w_{ij}[y_i = y_j]$

Although the above focuses on the K-means clustering, the formulation can be generalized to several other settings such as information theoretic and spherical clustering. The two main choices in each setting are (i) a parameterized distance $d_l(\mathbf{x}_i, \boldsymbol{\mu}_{y_i})$, which measures the divergence of each data point from its corresponding cluster mean, and (ii) suitable penalty functions $f_L(i,j)$ and $f_C(i,j)$, which measure the cost of violating a must-link and a cannot-link constraint. In Equation 20.6, we have $d_l(\mathbf{x}_i, \boldsymbol{\mu}_{y_i}) = (\mathbf{x}_i - \boldsymbol{\mu}_{y_i})^T A_i(\mathbf{x}_i - \boldsymbol{\mu}_{y_i})$, and $f_L(i,j) = 1$, and $f_C(i,j) = 1$.

Parameterized divergence functions: One can consider more general divergence functions, including parameterized and directional divergences. In particular, information theoretic clusters use the following divergence [22, 4]: $d_l(\mathbf{x}_i,\boldsymbol{\mu}_{y_i}) = \sum_{k=1}^d x_{ik} \log \frac{x_{ik}}{\mu_{y_i,k}}$, where $\mu_{y_i}$ are positive. The parameterized version of I-divergence uses a diagonal matrix $A = diag(a_j)$ with nonnegative weight $a_j$ corresponding to each dimension $j$ to $d_{L,A}(\mathbf{x}_i,\boldsymbol{\mu}_{y_i}) = \sum_{j=1}^d a_{ij} x_{ij} \log \frac{x_{ij}}{\mu_{y_i,j}} - \sum_{j=1}^d a_{ij}(x_{ij} - \mu_{y_i,j})$. One can similarly define a parameterized version of directional divergence based on the cosine similarity $d_A(\mathbf{x}_i,\boldsymbol{\mu}_{y_i}) = 1 - \frac{\mathbf{x}_i^T\boldsymbol{\mu}_{y_i}}{\|\mathbf{x}_i\|\|\boldsymbol{\mu}_{y_i}\|}$, where $\|\mathbf{x}_i\| = \sqrt{\mathbf{x}_i^T\mathbf{x}_i}$.
