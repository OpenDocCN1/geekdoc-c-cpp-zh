# Social Dimension Regularization: In [64], social dimension is introduced to improve the performance of relational learning. LUFS employs social dimensions to extract the interdependency among linked data. It first adopts Modularity Maximization [49] to extract social dimension indicator H. Since social dimensions can be considered as a type of affiliations, according to Linear Discriminant Analysis, three metrics are; within, and total dimension scatter matrices $S_w$, $S_b$, and $S_l$, are defined as follows:

```
$S_w = \mathbf{YY}^\top - \mathbf{YFF}^\top,\nS_b = \mathbf{YFF}^\top \mathbf{Y}^top,\nS_l = \mathbf{YY}^\top,\quad (2.14)$
```

where $\mathbf{F} = \mathbf{H}(\mathbf{H}^\top\mathbf{H})^{-1/2}$ is the weighted social dimension indicator matrix.\nInstances from different social dimensions are dissimilar while in the same social dimension are similar. The constraint, social dimension regularization, from linked information can be obtained via the following optimization problem:

```
$$\max_{\mathbf{W}} Tr((\mathbf{S}_l)^{-1}\mathbf{S}_b).\quad (2.15)$
```

**Spectral Analysis:** To take advantage of information from the attribute-value part, LUFS constrains the constraint from the attribute-value part through spectral analysis [42]

```
$$\min Tr(\mathbf{YLY}^\top).\quad (2.16)$
```

where $\mathbf{L}$ is a Laplacian matrix.\nConsidering constraints from both linked information and the attribute-value part, LUFS is equiv to solving the following optimization problem:

```
$$\min_{\mathbf{W,s}} Tr(\mathbf{YLY}^\top) - \alpha Tr((\mathbf{S}_s)^{-1}\mathbf{S}_b)\ns.t.\ \ |\mathbf{Y}(:,i)||_0 = 0, \ 1 \le i \le n\quad (2.17)$
```

With the spectral relaxation for label indicator matrix [42], LUFS is eventually used to solve the following optimization problem:

```
$$\min_{\mathbf{W}} Tr(\mathbf{W}^\top\mathbf{AW}) + \beta|\mathbf{W}||_{2,1}\ns.t.\ \mathbfmathbf{W}^\top\mathbf{BW} = \mathbf{I}_c\quad (2.18)$
```

where $\mathbf{A} = \mathbf{XLX}^\top + \alpha\mathbf{X}(I - \mathbf{FF}^\top)\mathbf{X}$ is a symmetric and positive semidefinite matrix and $\mathbf{B} = \mathbf{XX}^\top + \lambda\mathbf{I}$ is symmetric and positive. Since the problem in Equation (2.18) is convex, an optimal solution $W$ can be guaranteed for LUFS [65]. The detailed algorithm for LUFS is shown in Algorithm 10.
