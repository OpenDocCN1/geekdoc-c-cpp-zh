# TABLE 23.13: Internal Clustering Validation Measures.

| | Measure | Definition |
|---|---||
| 1 | RMSD^1 | $\sum_{x \in C_i} \|x - c_i\|^2 / (n_i - 1)^{\dagger}$ |
| 2 | R-squared (RS) | $\sum_{x \in D} \|x - c\|^2 - \sum_{x \in C_i} \|x - c_i\|^2 / \sum_{x \in D} \|x - c\|^2$ |
| 3 | Modified Hubert $\gamma$ statistic (T) | $\frac{1}{n(n-1)} \sum_{x \in D} \sum_{y \in D} d(x,y), \sum_{x,y \in C_i} d(c_i, c_j)$ |
| 4 | Calinski-Harabaz index (CH) | $\frac{\sum n_i d(c_i,x)^2 / (n_i - 1)}{\sum d(x,c)^2 / (n - k)}$ |
| 5 | I index (I) | $(\frac{\sum_{x \in C_i} d(c_i,x)}{n_i} / max_j d(c_i, c_j))^p$ |
| 6 | Dunn's indices (D) | $\min_i \{ \frac{\min_{x,y \in C_j} d(x,y)}{\max_{x,y \in C_i} d(x,y)}\}$ |
| 7 | Silhouette index (S) | $\frac{1}{n} \sum_{x \in C} \frac{b(x) - a(x)}{\max(a(x), b(x))}$ \n $a(x) = \frac{1}{n_i} \sum_{y \in C_i, y \neq x} d(x,y), b(x) = \frac{1}{n_j} \sum_{y \in C_j} d(x,y)$ |
| 8 | Davies-Bouldin index (DB) | $\frac{1}{k} \sum_{i=1}^k \max_{j \neq i} \frac{s_i + s_j}{d(c_i, c_j)}$ \n $s_i = \frac{1}{n_i} \sum_{x \in C_i} d(c_i,x)$ |
| 9 | Xie-Bie index (XB) | $\sum_{x \in C_i} [d(x,c_i)] / \min_{i \neq j} d(c_i, c_j)$ |
| 10 | SD validity index (SD) | $Disc_{NC}(NC) + Disc(NC)$ \n $Disc(NC) = \frac{\sum_{C \in NC} \sigma(C)}{\sigma(D)} \cdot |\sigma(D)|$ \n $Disc(NC) = \frac{\max_{x,y \in NC} d(x,y)}{\min_{x,y \in C} d(x,y)} - 1$ |
| 11 | $S_{Dbow}$ validity index ($S_{Dbow}$) | $Dens(C) + Dens(NC)$ \n $Dens(NC) = \frac{\sum_{x,y \in NC} f(x,y)}{\sum_{x,y \in C_i} f(x,y)}$ |
| 12 | CVNN2 index | $Sep(N,k) = N / maxSep(N,k) + Com(N) / maxCom(N,k)$ \n $Com(N) = \frac{\sum_{i=1}^k n_i d(x,y)}{n}$ \n $Sep(N,k) = max \frac{\sum_{i=1}^k n_i}{n}$

Note: D: data; $n$: number of objects in $D$; $P$: attributes of $D$; $k$: number of clusters; $C_i$: the $i$th cluster; $n_i$: number of objects in $C_i$; $c_i$: center of $C_i$; $\sigma$: variance vector of $D$; $q_j$: number of $C_i$'s $j$th object's neighbors who are not in $C_i$; $\sigma(C)$: variance of $C$; $d(x,y)$: distance between $x$ and $y$; $\|X_i\| = (X_i^T X_i)^{1/2}$.^\dagger

> $RMSD^1$: Root-mean-square distance and standard deviation.
^2CVNN: Clustering Validation based on Nearest Neighbors.

**I. Compactness.** This measures how closely related the objects in a cluster are. A group of measures evaluates cluster compactness based on variance. Lower variances indicate better compactness. In addition, measures estimate cluster compactness based on distance, such as maximum or average pairwise distance, and maximum or average center-based distance.

**II. Separation.** This measures how distinct or well-separated a cluster is from other clusters. For example, the pairwise distances between cluster centers and the pairwise minimum distances between objects in different clusters are widely used as separation. Also, measures based on density are used in some indices.

The general procedure to determine the best partition and optimal number of a set of objects by internal validation measures is as follows.

+   - Step 1: Initialize a list of clustering algorithms which will be applied to the data set.
- Step 2: For each clustering algorithm, use different combinations of parameters to get clustering results.
