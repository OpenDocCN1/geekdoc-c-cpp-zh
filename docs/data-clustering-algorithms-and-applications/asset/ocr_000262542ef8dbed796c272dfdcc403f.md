# 4.2.4.6 Intelligent K-Means Clustering

Intelligent K-means (IK-means) clustering [38] is a method which is based on the following-principle: the farther from the centroid, the more interesting it is. IK-means uses the basic ideas of principal component analysis (PCA) and selects those points from the centroid that correspond to the maximum data scatter. The clusters derived from such points are called anomalous pattern clusters. The IK-means clustering algorithm is given in Algorithm 16.
In line 16, I initialize the centroid for the dataset as $c_g$. In line 3, a new centroid is created which is farthest from the centroid of the entire data. In lines 4-5, a version of 2-means clustering is made. This assignment uses the center of gravity of the original dataset $c_g$ and that of the anomalous pattern cluster $s_g$ as the initial centroids. In line 6, the centroid of the dataset is updated with the centroid of the anomalous cluster. In line 7, a threshold condition is applied to discard small clusters created because of outlier points. Lines 3–7 run until one of the stopping criteria is met: (i) Centroids converge or (ii) specified K number of clusters has been obtained or (iii) the entire data have been clustered.

```
Algorithm 16 IK-Means Clustering
1: Calculate the center of gravity for the given set of data points $c_g$.
2: repeat
3: Create a centroid $c$ farthest from $c_g$.
4: Create a cluster $s_{iter}$ of data points that is closer to $c$ than $c_g$ by assigning all the remaining points $x_i$ if $d(x_i, c) < d(x_i, c_g)$.
5: Update the centroid of $s_{iter}$ as $s_g$.
6: Set $c_g = s_g$.
7: Discard small clusters (if any) using a prescribed threshold.
8: Until stopping criterion is met.
```

There are different ways which we can select the K for IK-means, some of which are similar to choosing K in K-means desired. A structural approach compares the internal cluster cohesion with between-cluster separation can be applied. Standard hierarchical clustering methods construct a dendrogram can also be used to determine K. K-means is considered to be a nondeterministic algorithm whereas IK-means can be considered a deterministic algorithm.
IK-means can be very effective in clustering clusters when they are spread across the dataset rather than compactly constructed in a single region. IK-means clustering can also be used for initial centroid selection before applying K-means. At the end of the IK-means we will be with only the good centroids for further selection. Small anomalous pattern clusters will not contribute any candidate centroids as they have already pruned.
