The algorithm and the visualization proposed in [43] integrates a hierarchical clustering algorithm based on edge collapsing with a three-dimensional visualization. The graph clustering first places the data objects in the three-dimensional space using a spring-embedder that models data are represented by the stiffness of springs placed between the points. The distances between original data vectors as points in the three-dimensional space, the embedding of the original data in the three-dimensional space is computed by a low-energy state of the spring-system. This is similar to DBSCAN [9]. The cluster hierarchy is computed using centroid linkage in the three-dimensional space for all dimensional points. Hierarchical clusters as BLOBs within BLOBs, a technique that is called H-BLOBs.

The concept of using three-dimensional projections for clustering is further developed in [34]. Instead of relying on a readily computed clustering, the user can interactively construct the hierarchy top-down by selecting a cluster and compute subclusters with some automated algorithm. The results are shown as three-dimensional objects within larger transparent three-dimensional objects. The experiment is demonstrated in videos that are available from http://infoserver.lad.imc.usp.br/infovis2/3dproj. An example is shown in Figure 19.6.

The Hierarchical Clustering Explorer (http://www.cs.umd.edu/hcl/ice/) uses an alternative approach described in [41]. This tool relies on standard visualizations like scatterplots and parallel coordinates combined with dendrogram plots to interactively analyze high-dimensional data. Lessons learned from project are that it is important to select the most relevant features first using interactive visual techniques and automated feature ranking methods. Then hierarchical clustering can be performed in the subspaces spanned by the selected features.
