## 23.2.2 Defective Validation Measures

In this section, some validation measures produce misleading validation results for data on skewed class distributions are presented.

### 23.2.2.1 K-Means: The Uniform Effect

One of the unique characteristics of $K$-means clustering is the so-called uniform effect; $K$-means tends to produce clusters with relatively uniform sizes [64]. The coefficient of variation (CV) [10], which measures the dispersion of a random distribution, is the standard deviation to the mean, is used to quantify the uniform effect. CV is for data objects $X = \{x_1, x_2, ..., x_n\}$, where $s = s/\bar{x}$, where $\bar{x} = \sum_{i=1}^n x_i/n$ and $s = \sqrt{\sum_{i=1}^n (x_i-\bar{x})^2/(n-1)}$. CV is a dimensionless number that allows the comparison of populations that have different mean values. In general, the larger the CV value, the greater the value in reality.

Let $CV_0$ denote the CV of the “true” classes and $CV_1$ denotes the CV of the result clusters. The “true” clusters of data set [59] is used to illustrate the uniform effect by $K$-means. The clusters of sparse apart have $CV_0=1.02$. The CLUTO implementation of [27] with default results is employed to cluster $x$ into seven clusters, and the CV of the result cluster size is $0.42$. The CV difference is $DCV=CV_1-CV_0=-0.6$, which indicates a significant effect in the clustering result.

It has been empirically observed that the 95% confidence interval of $CV_1$ values produced by $K$-means is in $[0.83, 1]$. In these works, for data sets with CV values greater than $0.83$, the uniform effect of $K$-means can distort the cluster distribution significantly.

Now the question is: Can these used validation measures capture the negative uniform effect by $K$-means clustering? A necessary, but not sufficient criterion is provided to test whether a validation measure can be effectively used to evaluate $K$-means clustering.

## 23.2.2.4 The Issues with Defective Measures

First, the problem of entropy measure lies in the fact that it cannot evaluate the integrity of the classes $E = -\sum_i p_i \sum_j p_{ij} \log \frac{p_{ij}}{p_i}$. If a random view on class $P$ and class $C$ is taken, then $p_{ij}=n_{ij}/n$ is the probability of the event $\{P=P_i \wedge C=C_j\}$, and $p_i=n_i/n$ is the marginal probability. Therefore, $E = -\sum_i p_i \sum_j p(C_j|P_i) \log p(C_j|P_i) = \sum_i p_i H(C|P_i)$, where $H(C)$ is the Shannon entropy. The above implies that the entropy measure is nothing but the conditional of $C$ on $P$. In other words, if the objects in large partition are from the same class, the entropy value tends to be small (indicating a better clustering). It is usually the case for K-means clustering on highly imbalanced data sets, since K-means tends to partition a large class into several pure clusters. This leads to the problem that the integrity of objects from the same class has damaged. The entropy measure cannot capture this information and penalize it.

The mutual information is relative to the entropy measure, which is illustrated by the following lemma.

## Lemma 23.2.1 The mutual information is equal to the entropy measure for cluster validation.

PROOF. By information, $MI = \sum_i \sum_j p_{ij} \log \frac{p_{ij}}{p_i} = H(C) - H(C|P) = H(C) - E$. Since $H(C)$ is a constant for any given data set, MI is essentially equivalent to E.

The purity measure works in a similar fashion as the entropy measure. That is, it measures the “purity” of each cluster by the ratio of the objects from the majority class. Thus, it has the same problem as the entropy measure for evaluating K-means clustering.

In summary, entropy, purity, and mutual information are defective measures for validating K-means clustering.

## 23.2.2.5 Improving the Defective Measures

In this section, the improved versions of the three defective measures, mutual information, and purity are provided.

## Lemma 23.2.2 The Variation of Information criterion is an improved version of the purity measure.

PROOF. Cluster $P$ and class $C$ can be viewed as two random variables, and it has been shown that $VI = H(C) + H(P) - 2MI = H(C|P) + H(P|C)$ [42]. The component $H(C|P)$ is nothing but the entropy measure, and the component $H(P|C)$ is a valuable supplement to $H(C|P)$.
