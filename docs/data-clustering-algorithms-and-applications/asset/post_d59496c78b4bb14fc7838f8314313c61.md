
# Alternative Clustering Analysis: A Review

## 21.3.4 Orthogonal Transformation Approaches

Our next class of approaches consider the task of alternative clustering from a feature space. Using background knowledge, this style of approach constructs a new feature space which is "orthogonal" to the data space that is generalised by the existing clustering. Once this orthogonal feature space is generated, any clustering algorithm can be used in this space to generate an alternative clustering. Thus, the objectives of quality and dissimilarity are decoupled, with the former tied to the use of the chosen clustering algorithm and the latter tied to the characteristics of the orthogonal space that gets generated. Overall, these approaches have an appealing mathematical formulation based on linear algebra. They are also efficient. A limitation is that the orthogonality requirement may be too strict for some datasets and it is not all clear how it trades off the quality of the clustering.

### 21.3.4.1 Orthogonal Views

Work by Cui et al in [7] presents two approaches that can generate multiple alternative clusters, in a sequential manner. Each alternative clustering is determined by subsets of features of the data set, which are best described by the clustering. Given a clustering $C_1$, a subset of features that are well represented in $C_1$ is found and then another set of features, which are orthogonal to the first subset, is found. Their first approach carries out a transformation as follows: Each data point $x_i$ from cluster $j$ is projected onto its cluster center $\mu_j$ and then a residue is found by projection onto an orthogonal subspace:

$$x_i^{new} = (I - \frac{\mu_j\mu_j^T}{\|\mu_j\|^2})x_i$$

One clusters the data in this orthogonal subspace to obtain an alternative clustering. The method can be executed iteratively, to generate multiple alternative clusterings. A version where the it is a soft (fuzzy) clustering $F_2$ is also outlined.

In the second approach, a feature subspace $F_2$ that is a good representation for the clustering $C_1$ is found using principal component analysis on the mean vectors of $C_1$. The data $X$ is projected to a subspace that is $X^{new}$ to generate an alternative clustering $C_2$. Specifically,

$$X^{new} = ((I - F_2(F_2^T F_2)^{-1}F_2^T))X$$

Again, the method can be applied iteratively to generate further alternative clusterings.

### 21.3.4.2 ADFT

Work By Davidson and Qi [11] describes the ADFT approach to finding an alternative clustering using a set of instance level constraints. This approach is also a transformation approach like that of [7]. However, instead of characterizing the background knowledge $C_1$ according to mean vectors or a feature subset, it is characterized using instance must-link and connect-link constraints. This distance function can be decomposed using singular value decomposition into $DC_{C_1} = HSA$, where $H$ is the hanger matrix, $S$ is the stretch matrix, and $A$ is an aligner matrix.

Once the characteristic distance $DC_i$ is learned, an alternative distance function can be computed as $HS^{-1}A$. This alternative distance function is employed to generate a new dataset $X^{new} = (S^{-1}A)X$. The alternative clustering is then found by applying any clustering algorithm on $X^{new}$.

This method has an advantage over the approach of [7], since it can be applied in situations where the dimensionality of the dataset is smaller than the number of clusters (as is common for spatial data).

## 21.3.5 Information Theoretic

Another approach to the generation of alternative clusterings is based on the objective functions using information theoretic principles. Such approaches are mathematically attractive and incorporate the use of mutual (or similar) information to measure the strength of correlations between clustering. Several algorithms fall into this category, beginning with the approach of Gonde and Hofmann [16], which was the first (to our knowledge) alternative clustering algorithm to be proposed.

### 21.3.5.1 Conditional Information Bottleneck (CIB)

The conditional bottleneck (CIB) for alternative clustering is described in [15, 16]. This algorithm takes as input an existing clustering $C_1$ as background knowledge and sequentially generates a single alternative clustering $C_2$ by optimizing the objective function

$$\max(I(C_2;C_1) - \lambda_1 I(C_2;X) + \lambda_2 I(C_2;F))$$

Where $F$ is the features, $X$ is the features, and the existing clustering $C_1$. The term $I(C_2;C_1)$ corresponds to the mutual information between the new clustering being discovered and the features, the predefined clustering. The term $I(C_2;X)$ corresponds to the mutual information we desire to be small, avoiding being overly confident about the groupings), and $I(C_2;F)$ corresponds to the mutual information between the alternative clustering and the features (which we wish to be). The symbols $\lambda_1 > 0$ and $\lambda_2 > 0$ are regularization parameters, to trade off the different components of the objective function. The approach of [16] describes an alternating optimization scheme with deterministic annealing, which can be used for generating $C_2$ with this objective function. In practice, this style of approach has been found to behave particularly strongly for document datasets.

### 21.3.5.2 Conditional Ensemble Clustering

The CIB approach of [15, 16] was further extended in [14], which introduced the CondEns (Conditional Ensemble) alternative clustering algorithm.

CondEns operates in three stages. 
1. Given the clustering $C_1 = \{c_1, \dots, c_k\}$ as background knowledge, for each cluster $c_i$ a local clustering is generated using any clustering algorithm. It yields $k$ local clusterings. 
2. Each of the $k$ local clusterings is extended into a global clustering, by assigning instances not part of a local clustering, to one of its clusters. 
3. The $k$ global clusterings are then combined using a combination technique based on the conditional bottleneck, to yield a single alternative clustering.

With the approach of [16], CondEns also performs well for text datasets. A limitation of CondEns is its guarantees about the dissimilarity of the alternative clustering are somewhat unclear, since the clusters in the original clustering $c_1$ may be quite similar among themselves. This means the alternative clustering may turn in similar to the background clustering.

### 21.3.5.3 NACI

The NACI algorithm was proposed by Dang and Bailey in [9] and targets scenarios where the borders between clusters in the alternative clustering may not be linearly separable.

At a high level, its objective function can be expressed as an alternative clustering $C_2$, given background knowledge, according to

$$C_2 = \text{argmax}\{I(C_2;C_1) - \lambda_1 I(C_2;X) + \lambda_2 I(C_2;F)\}$$

where $\eta$ is a regularization parameter, $p(\cdot)$ is the probability density, and $I(C_1;C_2)$ is the mutual information in a quadratic form

$$I(C_1;C_2) = \sum_{C_1} \sum_{C_2} (p(C_1,C_2) - p(C_1)p(C_2))^2$$

To use NACI, choices must be made for both the regularization parameter and the kernel. Another approach in the same spirit as NACI is that of minEntropy [27], instead of using a kernel, uses k-means style algorithm.

### 21.3.5.4 mSC

The final method in this section is the mSC approach outlined in [28]. This is a spectral approach that can simultaneously generate multiple clusters.

Rather than being on mutual information, it uses the Hilbert-Schmidt Independence Criterion (HSIC) to assess the correlation between clusters. With mutual information, the HSIC is also able to recognize nonlinear dependencies. Specifically, the mSC technique embeds the HSIC measure within a spectral clustering framework. The objective is a dual function, where each iteration, one term is fixed and the other is optimized. The user is able to specify the number of alternative clusters that are desired and the number of clusters in each.

## 21.4 Connections to Multiview Clustering and Subspace Clustering

We have far reviewed a range of techniques that can be used for generating alternative clusters, which is a core component for multiple clustering analysis. We now mention the connections that exist between alternative clustering analysis and other directions: multiview clustering and subspace clustering.

Multiview clustering is also considered with multiple clustering, but from a different angle. In multiview clustering, one is provided with multiple sources or representations of data (multiple views) and wishes to learn a single clustering which is consistent with a good reflection of the multiple views. A prototypical example is Web pages, which may be modeled using features which describe the frequencies of words occurring in the page (View 2), or modeled using features which describe the anchor text in the links going out of the page (View 3). It has been found that using the information in all views simultaneously, one can generate a better clustering than using only a single view. A particular benefit of multiview clustering is that using multiple views to produce a clustering can reduce the effect of noise within individual views. If one were to use a single view to drive the clustering, the presence of noise might corrupt the clusters and make the detection of cluster structure more difficult. Using multiple views to cluster, however, lessens the likelihood of noise within a view being dominant and emphasizes their contribution toward the overall cluster structure.
