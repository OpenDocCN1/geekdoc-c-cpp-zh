# 2.2.2.5 Frequent Term-Based Text Clustering

Frequent Term-Based Clustering (FTC), was proposed in [6], provides a natural way to reduce dimensionality in text clustering. It follows the notion of a frequent item set that forms the basis of association rule mining. In FTC, the set of documents that contain the same frequent term set will be a candidate cluster. Furthermore, clusters may overlap the document since they may contain different item sets. The kind of clustering can be either flat (FTC) or hierarchical (HFTC) clustering when we have different cardinalities of item sets.

$D_j$ is the $jth$ document, $C_i$ is the $jth$ cluster and $F_j$ is the number of all frequent term sets that supports $D_j$. The EO equals 0 if the documents in $C_j$ only support one frequent item set (i.e., $F_j=1$). This value increases with the increase of $F_j$. This method of evaluation was found to produce better clustering quality than the standard one [6]. The best candidate $BestSet$ will be the set with a minimum amount of overlap. $BestSet$ will be added to the STS and excluded from $RTS$. In addition, the set of documents that supports $BestSet$ is removed from the dataset since they have already been clustered, which leads to drastically reducing the number of documents. They are also removed from the documents' list of $RTS$ which leads to reducing the number of remaining term set. This greedy approach gives the computational advantage for this algorithm.
