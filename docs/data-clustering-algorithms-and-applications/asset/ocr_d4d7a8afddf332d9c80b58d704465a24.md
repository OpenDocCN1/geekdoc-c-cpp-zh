Let us assume that, $p_i$ and $p_j$, the spectral feature has normal densities $G(\mu_i, \Sigma_i)$ and $G(\mu_j, \Sigma_j)$, respectively. The similarity between the two segments is calculated as follows:

```
$d_{seg}(p_i, p_j) = \exp(-d_{KL}(G(\mu_i, \Sigma_i)||G(\mu_j, \Sigma_j)) - d_{KL}(G(\mu_j, \Sigma_j)||G(\mu_i, \Sigma_i))) \quad (14.27)$
```

And the *segment-indexed* similarity matrix $S_S$ is

```
$S_S(i, j) = d_{seg}(p_i, p_j) \quad \forall i, j=1,\dots,P \quad (14.28)$
```

The SVD of $S_S = UAV^T$:

```
$S_S(i, j) = \sum_{k=1}^K a_k U(i, k) V(j, k) = \sum_{k=1}^K B_k(i, j) \quad (14.29)$
```

Then,

```
$b_k(j) = \sum_{i=1}^p B_k(i, j) \quad (14.30)$
```

is evaluated and measures the similarity of segment $p_i$ to the segments in the $k$th cluster result. Accordingly, $p_i$ is assigned to cluster

```
$k^* = \arg\max_{k=1,\dots,K} b_k(i) \quad (14.31)$
```

The authors go to designate segments with large singular values as summarization, because they are usually repeated and therefore, serve as summaries of popular music. First, for each overlapping frame, a *Mel-cluster feature* is calculated. Each initial segment consists of a fixed number of frames, within which the Mel-cluster features are assumed to follow a Gaussian distribution. A bottom-up clustering is then applied; i.e., the clustering algorithm iteratively finds the two clusters with lowest distortion them (if it is less than a threshold, then they are combined). The authors use a modified $KL$ distance and call it $KL2$. They use

```
$KL2(A;B) = KL(A;B)+KL(B;A) \quad (14.32)$
```

where $A$ and $B$ are Gaussian distributions:

```
$KL(A;B) = E_A(\log pdf(A)|-\log pdf(B)) \quad (14.33)$
```

Assuming $A$ and $B$ are Gaussian distributions:

```
$KL2(A;B) = \frac{\Sigma_A}{\Sigma_B} + \frac{\Sigma_B}{\Sigma_A} + (\mu_A - \mu_B)^2 \times (\frac{1}{\Sigma_A} + \frac{1}{\Sigma_B}) \quad (14.34)$
```

After hierarchical clustering, or HMM-based clustering, the closest cluster (label) is considered and the longest section containing this label in the first half of the song is chosen as the key phrase.
