# Algorithm 1 Spectral Feature Selection (SPEC)

**Input:**

$D$: dataset
$\Psi \in \{\Psi_1, \Psi_2, \Psi_3\}$: feature weighting functions
$n$: number of samples

**Output:**
$F$: the ranked feature list

+   1. Construct similarity matrix $S$ from $D$
2. Construct Graph $G$ from $S$
3. Construct $W$ from $S$
4. Construct $D$ from $W$
5. Define $L$ and $L$ according to Equation (2.2),
6. for each feature vector $f$ *do*
7. $f_i \leftarrow \frac{D^i f}{\|D^i f\|}$
8. $F_i \leftarrow \Psi(f_i)$
9. **end**
10. Rank $F$ by $\Psi$

# 2.2.1.3 Feature Selection for Sparse Clustering

Witten and Tibshirani in [72] propose a framework for feature selection in sparse clustering. They apply Lasso-type $\ell_1$-norm, as a feature selection method embedded in the clustering process. This framework can be applied to any similarity-based clustering technique, yet used using k-means clustering in [72]; The number of selected features $l$ is chosen using gap statistics in a similar fashion to choosing the number of clusters in [67]. The proposed method attempts to minimize the objective function with respect to the clusters $\{C_1, \dots C_K\}$ and the feature weight vector $w$:

> $\min \sum_{j=1}^m w_j \Psi_j$
$	ext{subject to } \|w\|^2 \le 1$,$
\|w\|_1 \le 1$,$
w_j \ge 0 \quad \forall j$

Where $\Psi_j$ is given by the following equation for k-means over $f^h$:

```
$\Psi_j = \frac{1}{K} \sum_{c=1}^K \sum_{i \in C_c} 	ext{Sim}(i, i', j) - \frac{1}{n} \sum_{i=1}^n \sum_{i'=1}^n 	ext{Sim}(i, i', j). \quad (2.4)$
```

$K$ is the number of clusters, $n$ is the number of samples in cluster $c$, and $	ext{Sim}(i, i', j)$ is the similarity index of sample $i$ and $i'$ using only the selected feature $j$. Optimizing Equation (2.4) is done using iterative algorithm by holding $w$ fixed and optimizing Equation (2.4) with respect to the clusters $\{C_1, \dots C_K\}$. In this step, we apply standard k-means clustering over n-by-n matrix similarity using $f^h$ feature. Then we hold the clusters and optimize Equation (2.4) with respect to $w$. w is set in this step to be

```
$w = \frac{S(\Psi_+)}{S(\|\Psi_+\)\|_2} \quad (2.5)$
```

where $\Psi_+$ is the positive part of $\Psi$ and $\Delta = 0$, when $\|w\|_1 \le 1$ and $\Delta > 0$ otherwise, so $\|w\|_1 = 1$. Algorithm 2 illustrates these steps of optimizing Equation (2.4).
