## 2.2.26 Frequent Term Sequence

Similar to FTC, a clustering based on frequent term sequence (FTS) was proposed in [32]. Unlike FTC, the sequence of the terms in matters is important. The frequent term sequence, denoted as $f$, is a set that contains the frequent terms $\langle f_1, f_2, \dots, f_n \rangle$. The sequence here shows that $f_2$ must after $f_1$, but it is not necessary to be immediately after it. There could be other frequent terms between them. This is true for any $f_k$ and $f_l$ terms. This definition of frequent term sequence is also adaptable to the variation of human languages [31].

Similar to FTC, FTS starts by finding frequent terms using an association rule mining algorithm. This frequent term sequence guarantees to contain the frequent term but not vice versa. Here, we do not need to search the whole space for the frequent term sequence. We can search in only the frequent space, generic suffix tree (GST), which is a well-known data structure for sequence pattern matching, using the documents after removing the infrequent terms. From the suffix nodes in GST, we can obtain cluster candidates. These cluster may contain subtopics that might be eligible to be merged into more general topics. Therefore, merging step takes place.

The authors of [32] chose to merge cluster candidates into more general topics using $k$-mismatch instead of the similarity. An example of using the $k$-mismatch concept is when $FS_i = \{feature, selection, clustering\}$ and $FS_j = \{feature, selection, classification\}$, where they have one mismatch. Therefore, we can merge these clusters if the tolerance parameter $k \geq 1$.

[32], FTS adopted Landau–Vishkin (LV) to test three types of mismatches: insertion, deletion, substitution. Insertion means that all we need to insert $k$, or fewer, terms into the $FS_i$ in order to match $FS_j$. Deletion, in contrast, means we need to delete. While substitution we need to substitute terms from $FS_j$ with terms from $FS_i$.

These merged clusters are prone to overlap. Accordingly, merging will be performed when measuring the amount of overlap using the *Jaccard Index*:

```
$J(C_i, C_j) = \frac{|C_i \cup C_j|}{|C_i \cap C_j|}$
```

The larger $J(C_i, C_j)$ is, the more the overlap would be. The merge takes place here when the overlap exceeds a user defined threshold, $\delta$. However, the final number of clusters could be refined. In this case, this step would be repeated until the clusters meet the user’s demand.

## 2.2.3 Algorithms for Streaming Data

Streaming Data are continuous and rapid data. Formally defined as a set of multi-records $X_1,...,X_n$, that come in time sets $T_1,...,T_n$. Each record $X_i$ is multidimensional. These usually have a huge dimensionality and arrive very fast. They require scalable and efficient algorithms. Also, the underlying structure is changing, so we need to capture this and keep selected features up to date. In this section, we introduce what we believe to be required characteristics of a good algorithm that handles streaming data:

- **Adaptivity**: The algorithm should be able to adjust features' weights or reselect the features, so it is able to handle data drift, aka dataset shift.
- **Single scan**: The algorithm should be able to cluster the incoming stream in one scan, since another scan is impossible or at least costly.

The following algorithms represent the literature of feature selection for data stream clustering. In fact, this area still needs great attention from the researchers due to the lack of work.

### 2.2.3.1 Text Streaming Based on Adaptive Feature Selection (TSC-AFS)

It is natural for clusters and data categories to evolve over time. For example, the breaking news dominates the world today may change dramatically. Therefore, using the same set of features to process and cluster data stream may lead to unsatisfactory learning results over time. Gop et al in [20] propose using the cluster quality $\gamma$ to test the quality of newly arrived samples' clustering respect to old clusters. TSC-AFS starts by applying feature selection on training data D. Then, it clusters the samples of D with the selected features only.

After that, it tracks data streams and assigns to the closest cluster. TSC-AFS evaluates a validity index $p$ for each cluster the Davies-Bouldin B index. If $j$ is less than $p$, then TSC-AFS will reselect the set of features. Otherwise, the algorithm keeps the feature set and clusters based on them and accepts new streams to come. Otherwise, TSC-AFS will reevaluate $p$ while considering the new data stream being added the closest cluster. If the validity index cannot satisfy the thresholds, a tolerance $\kappa$ is set to allow the cluster to be closed and initialize the algorithm again.

This algorithm utilizes a order variance-based method for feature selection since the domain in [20] is text stream. However, any appropriate algorithm may be used.
