# 18.3. FOPTICS Algorithm

Another technique discussed in [41] is of hierarchical density-based clustering. An effective (deterministic) density-based hierarchical clustering algorithm is OPTICS. The core idea in OPTICS is similar to DBSCAN and is based on the concept of reachability distance between data points. While the DBSCAN defines a global density parameter is used as a threshold to define reachability, the work in [41] points out that different regions in the data may have different density, as a result of which it may not be possible to define the clusters effectively with a single density parameter. Rather, many values of the density parameter different (hierarchically) exists along the underlying clusters. The goal is to define an implicit output in terms of ordering data points, so that when the DBSCAN is applied with this ordering, we can obtain the hierarchical clustering at all level for levels of the hierarchy are consistent with one another. One observation is that the clusters defined over a lower value of e are completely contained in clusters defined over a higher value of e, if the value of MinPts is not fixed. Therefore, the data are ordered based on the value of e required in order to obtain MinPts in then it is assured that higher density regions are always processed before lower density regions. This ensures that if the DBSCAN is used for this ordering, then a consistent result is obtained. Thus, the output of the OPTICS algorithm is not the cluster membership, but is the order in which the data points are processed.
