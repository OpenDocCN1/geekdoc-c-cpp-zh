At the algorithmic level, such random projection (also referred to as "JL-embedding") can be performed by a linear transformation of the original data matrix A Let R be a $d 	imes t$ rotation matrix with its elements independent random variables. Then A=R is the projected data matrix, and each of which is a vector in $t$ dimensional space which is the projection of the corresponding data point in $d$ dimensional space.

Different random projection algorithms differ in different terms of ways to construct such a rotation R. Earlier methods suggest R(i,j) as being independent Normal variables with mean 0 and variance 1. In [1], the authors propose two-based ways to construct the rotation R. The first method suggests R(i,j)=\pm1 with equal probability of 0.5. Alternatively, we can also set R(i,j)=\pm\sqrt3 with equal probability of 1/6 and R(i,j)=0 with the probability of 2/3.

Once we have projected the original data into a low-dimensional subspace, the clustering data points form a Gaussian-mixture model and further purpose using the expectation-maximization (EM) algorithm to find the soft clusters; in that, each data point $i$ is assigned to a cluster membership probability $p(i|l,\theta)=p(i|l,\theta)$, where $l$ is the $l$-th cluster and $\theta$ is a parameter for the underlying Gaussian-mixture model. The rationality of this approach can be traced back to [14], which found by random projection, the original high-dimensional distribution tends to be more Gaussian distribution in the projected subspace. It was also found in [10] that eccentric clusters can be reached by more spherical by random projection.

Due to its nature, the clustering result generated by the above procedure (RP+EM) might be highly unstable; that, differs of random projections might lead to very different clustering assignment the fact that each of the authors in [18] propose running RP+EM procedure multiple times by an ensemble set. Based on this observation, to be specific, if we run RP+EM multiple times (say $T$ in total), we construct an $n 	imes n$ similarity/affinity matrix $P$, where each element $P(i,j)=\frac{1}{T}\sum_{t=1}^{T} p(i|l,\theta)$, where $l$ and $t$ are the clusters and different random runs. Then, an iterative clustering algorithm is based on this affinity matrix $P$ to generate the k clusters. The empirical evaluations show that this framework leads to much robust clustering results. Given that the k-means clustering is NP even if $k=2$, recent research works has focused on the so-called $\gamma$-approximation. Let us define an indicator matrix X where each row has only one element; and $X(i,j)\neq0$ indicates that the data point belongs to the $j$-th cluster. Optimal $\gamma$-approximation finds for an indicator matrix $X_{opt}$ where $X_{opt}=\arg\min_{X}||A-XX^T||_F^2$, where $X$ is the set of all valid $n \times k$ indicator matrices.

For any $\gamma$ and the failure probability $0\le\deltadelta_{\gamma}<1$, a $\gamma$-approximation finds an indicator matrix $X$ with that probability at least $1-\delta_{\gamma}$, $||A-XX^T||_F^2\le\gamma$. In [33], the authors propose the first linear time $\gamma$-approximation algorithm speeding up the computation by running a $\gamma$-approximation on the projected subspace.
