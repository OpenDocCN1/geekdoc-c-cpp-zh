Definition 10.6.1 An assignment error which results from the estimation of data products is $(f,b)$-significant, if a data point is incorrectly assigned to cluster index $p$ which contains at least a fraction $f$ of the points, and the correct cluster for assignment has index $q$ which satisfies the following relationship:

It has been shown in [2] that it is possible to bound the probability of an $(f,b)$-significant error in a given assignment.

Lemma 10.6.1 The probability of an $(f,b)$-significant error in an assignment is at most equal to $k\cdot(d^2(b-f))^w$.

Lemma 10.6.2 Let us assume that $N-k\cdot(d^2(b-f))^w<1$. The probability that there is at least one $(f,b)$-significant error in the clustering process of $N$ data points is by most $\frac{N\cdot k}{(b-f)d^2}^w$.

# 10.7 Text Stream Clustering

The problem of streaming text clustering is particularly challenging in the context of text data due to the clusters needing to be continuously maintained in real time. One of the earliest methods for streaming text clustering was proposed in [64]. This technique is referred to as the Online Spherical $k$-Means (OSKM) Algorithm, which reflects the broad approach used by the methodology. This technique divides the incoming stream into small segments, each of which can be processed effectively in memory.

Each of $k$-means iterations is applied to each such segment in order to cluster them. The advantage of using a segment-wise approach for clustering is that each segment can be held in memory multiple times as is held in memory. In addition, the centroids from the previous segment are used in the next iteration for clustering purposes. A decay factor is introduced to age out the old documents, so that the new documents are more important from a clustering perspective. This approach has been used in [64] to be extremely effective in clustering massive text streams.

A different method for clustering massive text and categorical data streams was used in [12]. This method uses an approach which examines the relationship between outliers, emerging trends, and clusters in the underlying data. Old clusters may become inactive and eventually get replaced by new clusters. Similarly, when newly arriving data points do not fit in any particular cluster, these need to be initially classified as outliers. However, as time progresses, these new points may create a distinctive pattern of activity which can be recognized as a new cluster. The temporal locality of the data stream is manifested by these new clusters. For example, the first web page belonging to a particular category in a crawl may be recognized as an outlier but may later form a cluster of documents of its own. On the other hand, the new outliers may not necessarily result in the formation of new clusters. Clusters are true short-term abnormalities in the data since they do not result in the emergence of sustainable patterns. The approach discussed in [12] recognizes new clusters by first recognizing them as outliers. This approach works with the use of a summarization methodology, in which we use the cluster of condensed droplets [12] in order to create concise representations of the underlying clusters.

As in case of the OKM algorithm, we ensure that recent data points are given greater importance than older data points. This is achieved by creating a time-sensitive weight for each data point. It is assumed that each data point has a time-dependent weight defined by the function $f(t)$, which is also referred to as the fading function. The fading function $f(t)$ is a nonmonotonic decreasing function which decays with time $t$. The aim of defining a half-life is to quantify the decay rate of the data point in the data stream clustering process. The decay rate is defined as the inverse of the half-life of the data stream. We define the decay rate by $\lambda=1/t_0$. We now define the weight of each data point by $f(t)=e^{-\lambda t}$. From the perspective of the clustering process, the weight of each data point is $f(t)$. It is easy to see that this decay function creates a half-life of $1/\lambda$. It is also possible by changing the value of $\lambda$ to control the rate at which the information in the data stream decays or lost.

When a cluster is created during the streaming process by adding a new data point, during that period, at least one half-life, if at least one more data point arrives, then the cluster becomes active and maintains its cluster. Otherwise, if no new data points arrive after half-life, then the trend-setting outlier is recognized as a true anomaly in the data stream. At this point, anomaly is removed from the list of clusters. We then create a new cluster containing data points when the (weighted) number of points in the cluster is 0.5. The same criterion is used to determine that the inactivity period of the cluster has exceeded the half-life $1/\lambda$. The greater the cluster, the greater the value by which the inactivity period would exceed its half-life. This is a natural solution, since it is intuitively desirable to have stronger requirements (a longer memory) for the period of a cluster containing a larger number of points.

The statistics of the data points are captured in summary statistics, which are referred to as condensed droplets. These represent the word distributions within a cluster and can be used to compute the similarity of an incoming data point to the cluster. The overall algorithm proceeds as follows. By beginning of algorithmic execution, we start with an empty set of clusters. As new data points arrive, unit clusters contain individual data points. Once a maximum k clusters have been created, we begin the process of online cluster maintenance. Thus we initially start with a variety of k clusters. These clusters are updated over time with the arrival of new data points.

When a new data point $X$ arrives, its similarity to each cluster droplet is computed. In the case of text sets, the similarity measure between $D(X,C)$ is computed and $S$ is used. The similarity value of $S(\hat{X},C)$ is computed from the incoming document $X$ to every cluster $C$. The cluster with the maximum value of $S(\hat{X},C)$ is chosen as the relevant cluster for data insertion. Let us use a threshold $thres$ in order to determine whether the point is an outlier. If the $S(\hat{X},C_{max})$ is greater than the threshold $thres$, then the point $X$ is added to the cluster $C_{max}$. Otherwise, if some inactive cluster exists in the current set of clusters. If no inactive cluster exists, then the data point $X$ is added to $C_{min}$. On the other hand, if an inactive cluster exists, a new cluster is created containing the solitary data point $X$. We note that this new cluster is a potential true outlier or the beginning of a new trend of data points. Further understanding of this new cluster may be obtained with the progress of the data stream.
