**Top-Down Subspace Search.** The rational of top-down approaches is to determine the subspace of a cluster from the full-dimensional space. This is usually done by determining a subset of attributes for a set of points—cluster members—such that the points meet the cluster criterion when projected onto this subspace. Obviously, the dilemma is that for the determination of a cluster, at least cluster members must be identified. On the other hand, in order to determine cluster membership, the subspace of each cluster must be known. To escape this cluster dependency, the top-down approaches rely on a rather strict assumption, which has been called the *locality assumption* [90]. It is assumed that a cluster can be derived from the local neighborhood (in the full-dimensional data space) of the (provisional) cluster center or the (provisional) cluster members. In other words, it is assumed that in the full-dimensional space, the subspace of each cluster can be learned from the local neighborhood of cluster representatives or cluster members—an assumption that may make sense if the dimensionality of the subspaces is not much smaller than the dimensionality of the data.

Other top-down approaches that do not rely on locality use random sampling or a heuristic to generate a set of potential cluster members.

**Bottom-Up Subspace Search.** The exponential search space of all possible subspaces of a data space needs to be traversed is equivalent to the search space of the frequent item-set in market basket analysis in the area of transaction databases. For example, an itemset may contain items *A, B, C*, etc. The key idea of APRIORI algorithm [15] is to start with item-sets (“transactions”) of size 1 (containing a certain item, irrespective of other items also contained in the transaction) and exclude those larger item-sets from the search that cannot be frequent anymore, given the knowledge that smaller item-sets are frequent. For example, if a 1-itemset *A* is not frequent (i.e., we count such an item-set less than a minimum support threshold), all 2-itemsets, 3-itemsets, etc., containing *A* (e.g., *{A, B}*, *{A, C}*) cannot be frequent (either either item-set *A* would have met the minimum support threshold). Theoretically, the search space remains exponential, yet practically the search is substantially accelerated.

Transferring the item-set problem to subspace clustering, each attribute represents an item and each cluster is a transaction. Frequent attributes span the corresponding subspace. Finding attributes relates to finding all combinations of attributes that constitute a subspace containing at least one cluster. This observation is the rationale of many bottom-up subspace clustering approaches. The subspaces that contain clusters are determined by searching all 1-dimensional subspaces that at least one cluster by employing a search strategy similar to frequent item-set mining algorithms. To apply any frequent item-set mining, the cluster algorithm must implement a downward closure property (also monotonicity property):

If subspace S contains a cluster, then any subspace T *⊆* S must also contain a cluster.

For pruning (i.e., excluding specific subspaces from consideration), the antimonotonic reverse implication can be used.

+   If a subspace T does not contain a cluster, then any superset S ⊇ T cannot contain a cluster.

Let us note that there are bottom-up algorithms that do not use an APRIORI-like search but instead other search heuristics.
