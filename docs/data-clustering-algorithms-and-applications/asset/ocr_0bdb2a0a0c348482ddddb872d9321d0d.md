where $P(k)$ is an increasing function penalizing higher values of $k$. There are many examples of such criteria that have been used for mixture models, including Bayesian approximation criteria, such as Laplace-inference criterion (LEC) [65, 48] and Schwarz’s Bayesian inference criterion (BIC) [67, 26], and information-theoretic approaches [177], such as Rissan’s minimum description length (MDL) [64, 57], the minimum message length (MML) criterion [54, 79, 25], and Akaike’s information criterion (AIC) [17]. In addition, several model selection criteria have been proposed based on the classification likelihood, as the normalized entropy criterion (NEC) [21, 4] and the integrated likelihood (ICL) criterion [25]. For mixture models, a comprehensive review of model selection approaches is given in [48]. Besides deterministic, stochastic methods based on Markov Monte Carlo (MCMC) can be used for model inference, by either implementing model selection criteria [3, 66], or modeling in fully Bayesian way and sampling from the posteriori distribution with $k$ considered unknown [63, 59]. More-over, cross-validation approaches [69] have also been used to estimate the number of mixture components.

# 3.3 EM Algorithm and Its Variations

In most applications, parameters of a mixture model are estimated by maximizing the likelihood and the standard approach for MLE for mixture models and other probabilistic models is the EM algorithm [23]. In this section, we present a general view of the EM algorithm, then revisit the EM algorithm for mixture models, and finally discuss the variations and applications of EM algorithm. We will also illustrate the EM algorithm for topics in section 3.4.

# 3.3.1 The General EM Algorithm

The EM (Expectation-Maximization) algorithm is a popular method for fitting MLE or Map estimations for probabilistic models with latent variables [23]. We have a set of observed data (points) $X = \{x_1, \dots, x_N\}$ and a set of latent variables $Z = \{z_1, \dots, z_N\}$, in which each data point $x_i$ is associated with a latent variable $z_i$, and we use $\Theta$ to denote the set of all parameters. To use the method of maximum likelihood, the likelihood (or likelihood function) of a set of parameters given the observed data is defined as the probability of all the observations given those parameters $p(X|\Theta)$. In practice, it is more convenient to optimize the log-likelihood for the EM algorithm, which is given by

```
$$l(\Theta) = \log p(X|\Theta) = \sum_{n=1}^N \log p(x_n|\Theta) = \sum_{n=1}^N \sum_{z_n} \log p(x_n, z_n, \Theta)$
```

Here we are assuming $z_n$ is discrete, the algorithm identification is difficult if $z_n$ remains continuous
