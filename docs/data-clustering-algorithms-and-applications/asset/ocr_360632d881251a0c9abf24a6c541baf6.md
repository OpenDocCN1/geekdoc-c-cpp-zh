A cluster is defined as a maximal set of connected units in $k$ dimensions. A region is an axis-parallel rectangular $k$-dimensional unit, expressed as a DNF expression on intervals of the domains $A_i$. A region contained in a cluster $C$ is said to be maximal if no proper subset of $R$ is contained in $C$. A minimal description of a cluster is a nonredundant covering of the cluster with maximal regions. Given a set of data points and the input parameters, $\xi$, and $	au$, the task of subspace clustering is to find all clusters in all subspaces of the original data space together with a minimal description of each cluster.

The CLIQUE algorithm decomposes the task of subspace clustering into three subtasks:

+   1. identification of subspaces that contain,

+   2. identification of clusters, and

+   3. generation of minimal descriptions.

We discuss only the first subtask, which is the most challenging. If a set of points $S$ is a cluster in a $k$-dimensional space, then $S$ is also a cluster in any $(k - 1)$-dimensional projections of this space. Due to this property, dense units (and therefore subspaces clusters) can be efficiently discovered in a discovery-wise manner, starting with 1-dimensional units, and extending dense units by one dimension at every level. The algorithm terminates when the density of all candidate units at a given level requires no database search. The algorithm terminates when no more candidates are generated at the current level.

If a dense unit exists in $k$ dimensions, all of its projections in the $O(k)$ subsets of $k$ dimensions are also dense. The running time of the CLIQUE algorithm is therefore exponential in the highest density of any dense unit. It can be shown that the candidate generation procedure multiplies the number of candidates that can be found, a heuristic based on the Minimal Description Length principle to guarantee that all dense units are found, all subspaces and units that are not "interesting". To measure the interestingness of a subspace, its coverage is computed, $i$, the fraction of the data that is covered by the dense units in that subspace. Only subspaces with large coverage are selected, and the remaining ones are pruned.

In CLIQUE, as in all grid-based approaches, the quality of the results depends on the appropriate choice of width and partitions of the grid cells. To address this problem, [17] suggests the OptGrid method. Grid cutting planes should partition the dataset in areas of low density and discriminate clusters as much as possible. Partitions containing at least one cluster are processed recursively. We noted analytically that the OptGrid algorithm finds center-dense clusters, which correspond to clusters generated by a Gaussian distribution.

To address the drawbacks of grid-based approaches, researchers have investigated approaches similar to DBSCAN that detect the neighborhood of a point through region queries. In principle, one could apply the DBSCAN algorithm to subspaces but this is infeasible due to the exponential number of subspaces. SUBCLU [26] discovers the clusters as the naive application of DBSCAN to all subspaces, but achieves an efficient solution by employing the following monotonicity property; while density-based clusters are not anti-monotone, density-connected sets are, i.e., they are density-connected in any subset of their dimensions.
