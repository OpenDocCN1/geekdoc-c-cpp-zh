## 2.2.4.2 LUFS: An Unsupervised Feature Selection Framework for Linked Data

LUFS is an unsupervised feature selection framework for linked data and in essence, LUFS investigates how to exploit and take advantage of link information for linked data for unsupervised feature selection. In general, the goal of feature selection is to select a subset of features to be consistent with some constraints [80]. For supervised learning, label information plays the role of constraint. Without label information, LUFS introduces the LUFS assumes that there is a mapping $W \in \mathbb{R}^{m \times c}$, assigning each data point with a pseudo-class label where $m$ is the number of original features and $c$ is the number of pseudo-class labels. The pseudo-class label indicator matrix is $Y = W^T X \in \mathbb{R}^{n \times c}$ where $n$ is the number of data points. Each column of $Y$ has only one nonzero entity, i.e., $\|Y(:,i)\|_0 = 1$ where $\|\cdot\|_0$ is the vector zero norm, counting the number of nonzero elements in the vector. Then LUFS seeks pseudo-class label information by extracting constraints from both linked and attribute-value data. The constraints from link information and attribute-value parts are obtained through social dimension regularization and spectral analysis, respectively.

### Social Dimension Regularization:In [64], social dimension is introduced to improve the performance of relational learning. LUFS employs social dimensions to extract the interdependency among linked data. It first adopts Modularity Maximization [49] to extract social dimension indicator H. Since social dimensions can be considered as a type of affiliations, according to Linear Discriminant Analysis, three metrics are; within, and total dimension scatter matrices $S_w$, $S_b$, and $S_l$, are defined as follows:

$$
S_w = \mathbf{YY}^\top - \mathbf{YFF}^\top,
S_b = \mathbf{YFF}^\top \mathbf{Y}^\top,
S_l = \mathbf{YY}^\top,\quad (2.14)
$$

where $\mathbf{F} = \mathbf{H}(\mathbf{H}^\top\mathbf{H})^{-1/2}$ is the weighted social dimension indicator matrix. Instances from different social dimensions are dissimilar while in the same social dimension are similar. The constraint, social dimension regularization, from linked information can be obtained via the following optimization problem:

$$
\max_{\mathbf{W}} Tr((\mathbf{S}_l)^{-1}\mathbf{S}_b).\quad (2.15)
$$

**Spectral Analysis:** To take advantage of information from the attribute-value part, LUFS constrains the constraint from the attribute-value part through spectral analysis [42]

$$
\min Tr(\mathbf{YLY}^\top).\quad (2.16)
$$

where $\mathbf{L}$ is a Laplacian matrix. Considering constraints from both linked information and the attribute-value part, LUFS is equiv to solving the following optimization problem:

$$
\min_{\mathbf{W,s}} Tr(\mathbf{YLY}^\top) - \alpha Tr((\mathbf{S}_s)^{-1}\mathbf{S}_b)
s.t.\ \ |\mathbf{Y}(:,i)||_0 = 0, \ 1 \le i \le n\quad (2.17)
$$

With the spectral relaxation for label indicator matrix [42], LUFS is eventually used to solve the following optimization problem:

$$
\min_{\mathbf{W}} Tr(\mathbf{W}^\top\mathbf{AW}) + \beta|\mathbf{W}||_{2,1}
s.t.\ \mathbf{W}^\top\mathbf{BW} = \mathbf{I}_c\quad (2.18)
$$

where $\mathbf{A} = \mathbf{XLX}^\top + \alpha\mathbf{X}(I - \mathbf{FF}^\top)\mathbf{X}$ is symmetric and positive semidefinite and $\mathbf{B} = \mathbf{XX}^\top + \lambda I$ is symmetric and positive. Since the problem in Equation (2.18) is convex, an optimal solution $W$ can be guaranteed for LUFS [65]. The detailed algorithm for LUFS is shown in Algorithm 10. **Output:** $k$ most relevant features

- 2: Set $F = H(H^\top)^{-1/2}$
- 3: Construct $S$ through RBF kernel
- 4: Set $L = D - S$

- 8: while not convergent

- 10: Update the diagonal $D_{t+1}$, where $i$-th diagonal element is $\frac{1}{\|W_t(i,:)\|^2}$
- 11: Set $t = t + 1$
- 12: end
- 13: Sort each feature according to $\|W(i,:)\|_2$ in descending order and select the top-$k$ ranked ones

In an unsupervised scenario, many works are needed to further exploit linked data for feature selection. Since LUFS can be categorized as an embedded method, analogous to conventional data, how to develop filter, wrapper, and hybrid models for linked data is an interesting problem for future research. Furthermore, LUFS employs social dimension to capture link information, a further investigation into sophisticated methods of exploiting link will lead to novel approaches and help us develop a deeper understanding of how to improve the performance of feature selection. Finally the availability of various link formation can lead to links with heterogeneous strengths. Therefore how to incorporate atomic selection into feature selection is another promising direction for linked data.

## 2.3 Discussions and Challenges

Here are several challenges and concerns that we need to mention and discuss briefly in this chapter about feature selection for clustering.

### 2.3.1 The Chicken or the Egg Dilemma

In feature selection for clustering, there is a dilemma in which one to start with or which one serves the demands of the other. Do we utilize feature selection to improve clustering quality? Or, do we use clustering as an indicator of relevant features? In fact, this leads to the chicken or egg dilemma. Which comes first, clustering or feature selection? If the answer to the latter is yes, then it is not in feature selection literature. We usually use feature selection, as mentioned earlier, to improve learning quality, reduce computational time, and reduce required storage. Thus, the answer to the first question is, indeed, we use feature selection to improve clustering quality. Accordingly, we should select the features that preserve cluster structure. However, some current methods initialize clusters using all features. Then, they applied the supervised feature selection method using the initial clusters as class labels. We believe that these techniques may not achieve the goal of feature selection since the initial clusters may not be the real ones or even close. If those clusters are claimed to be real ones, why doing feature selection at all? Other methods apply the same process in an iterative manner using an EM-like approach. Although this might lead to better results, we still believe there several drawbacks associated with this approach. For example, if the dimensionality in the original space is high, such an approach may take a very long time to converge. We prefer feature selection that does not depend on any clustering input to define the relevance of the feature. In other words, we may utilize the clustering method to guide the searching process but we do not use the clustering as a class label. This means we use the feature selection method on the whole dataset and then use the selected features to construct the clusters. If we are not satisfied with the clustering quality, we may use this as an indicator that this set of features is not satisfactory. This is exactly the wrapper approach.

### 2.3.2 Model Selection: K and l

Selecting the clusters K or the number of selected features l is an open problem. In real-worlds, we have limited knowledge about each domain. Consequently, determining optimal K or l is almost impossible. Although this problem seems not to be a big issue with some approaches (such as fixed term-based feature selection methods), we still need to determine sensitive parameters such as clustering.

### 2.3.3 Scalability

With the tremendous growth of dataset sizes, the scalability of current algorithms may be in jeopardy, especially with those that require online clustering. For example, streaming data or data that cannot be loaded into the memory require a single data scan the second pass is unavailable or very expensive. Using feature selection methods for clustering may reduce the issue of scalability. However, some of the current methods that feature selection in the clustering process require full dimensionality in memory to observe any evolving in the cluster structure. If a change in data structure is observed, the clustering process should be restarted. Furthermore, we believe it is necessary to pay more attention to these parameters for better clustering results.
