ParC and Snl also have their own pros and cons. In terms of the number of disk I/Os, ParC is better since it requires only map-and-reduce step while Snl uses two map-and-reduce steps. The question is which algorithm runs faster? There are many parameters to answer the question: e.g., number of reducers used, data size, disk speed, network speed, start-up cost, the plug-in algorithm cost, cost of data transferred in the shuffling stage, and the sampling rate. BoW derives the cost (running time) as a function of the parameters to determine the algorithm that gives the minimum running time.
