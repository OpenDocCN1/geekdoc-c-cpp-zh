There are two significant advantages to this algorithm. First, it can handle outliers explicitly and this can be refined as desired. Second, it computes necessary thresholds as those for density and distance directly from the data. These can be fine-tuned as needed (., they don’t need to be guessed at any point). In essence this algorithm dynamically learns the data distribution of samples while learning the parameters for thresholds in addition discerning the clustering in the data.

# 6.5 High-Dimensional Algorithms

The scalability of grid-based approaches is a significant problem in higher dimensional data because of the increase in the size of the grid structure and the resultant time complexity increase. Moreover, inherent issues in clustering high dimensional data such as filtering noise and identifying the most relevant attributes or dimensions that represent the most regions must be addressed inherently in the grid structure as well as the actual clustering algorithm. In this section, we examine carefully subspace clustering approach presented in CLIQUE and a density estimation approach presented by OptGrid. This section is greatly influenced by the work of Berlin [3] with additional insights on the complexity, strengths, and weaknesses of each algorithm presented.

# 6.5.1 CLIQUE: The Classical High-Dimensional Algorithm

Agrawal et al. [1] proposed a hybrid density-grid-based clustering algorithm, CLIQUE (Clustering In UE), to find automatically subspace clustering of high-dimensional numerical data. It locates clusters embedded in subspaces of high-dimensional data without much user interaction to discern subclusters. In order to present the clustering results in an easily interpretable form, each cluster is given a minimal description as ajunctive normal form (DNF) expression.

CLIQUE partitions its numerical space into units for its grid structure. Moreover let $A = \{A_1, A_2, ..., A_d\}$ be a set of bounded, totally ordered domains (attributes) and $S = A_1 	imes A_2 	imes ... 	imes A_d$ be a $d$-dimensional space. Partitioning each dimension $A_i$ ($1 \leq i \leq d$) by $m$ intervals of equal length, grid divides the $d$-dimensional space into $m^d$ nonoverlapping rectangular units. A $d$-dimensional data point, $v$, is considered in a unit, if the value of $v$ in each attribute, is greater than equal to the left boundary of attribute in $u$ and less than the right boundary of attribute in $u$. The selectivity of a unit is defined by whose selectivity is greater than a parameter $	au$ are viewed as dense and retained. The definition of dense units applies to all subspaces of the original $d$-dimensional space.
