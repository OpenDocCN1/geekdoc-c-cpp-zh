# 8.4.1 Normalized Graph Laplacian

The variations of the normalized graph Laplacian are defined as follows:

```
$L_{sym} = D^{\dagger}LD^{\dagger} = I - D^{\dagger}WD^{\dagger}$
L_{rw} = D^{-1}L = I - D^{-1}W$
```

We list some properties of these two variations $L_{sym}$ and $L_{rw}$ below.

**Proposition 8.4.1** *The normalized graph Laplacian satisfies the following six properties [31]:*

+   1. For arbitrary vector $f \in \mathbb{R}^n$, we have
$$f^T L_{sym} f = \frac{1}{2}\sum_{i,j=1}^n W_{ij}(\frac{f_i}{\sqrt{D_i}}-\frac{f_j}{\sqrt{D_j}})^2 \quad (8.3)$$
2. $\lambda$ is an eigenvalue of $L_{sym}$ with eigenvector $u$ if and only if $\lambda$ is an eigenvalue of $L_{rw}$ with eigenvector $w$, satisfying $u=D^{\dagger}w$.
3. $\lambda$ is an eigenvalue of $L_{rw}$ with eigenvector $w$ if and only if $w$ solve the generalized eigenvalue-problem $Lw=\lambda w$.
4. Both $L_{sym}$ and $L_{rw}$ are positive semidefinite.
5. The smallest eigenvalue of both $L_{sym}$ and $L_{rw}$ is 0, with eigenvector $D^{\dagger}I$ for $L_{sym}$ and $L_{rw}$.
6. Both $L_{sym}$ and $L_{rw}$ have non-negative, real-valued eigenvalues $0=\lambda_1 \le \lambda_2 \dots ... \le \lambda_n$.

**Proof 2** Similar to the proof for Proposition 8.4.1, we can find the first property by following:
$$f^T L_{sym}f = f^T(I-D^{\dagger}WD^{\dagger})f = \sum_{i=1}^n f_i^2 - \sum_{i,j=1}^n f_i f_j \frac{W_{ij}}{\sqrt{D_i}\sqrt{D_j}}\n= \frac{1}{2}\sum_{i=1}^n f_i^2 - 2\sum_{i,j=1}^n f_i f_j \frac{W_{ij}}{\sqrt{D_i}\sqrt{D_j}}
= \frac{1}{2}\sum_{i,j=1}^n W_{ij}(\frac{f_i}{\sqrt{D_i}}-\frac{f_j}{\sqrt{D_j}})^2$$

To prove property 2, we replace $u$ with $D^{\dagger}$ in the eigenvalue equation of $L_{sym}$:
$$L_{sym}u=L_{sym}D^{\dagger}=D^{\dagger}LD^{\dagger}D^{\dagger}=D^{\dagger}\lambda w=\lambda u$

Property 3 follows by multiplying the eigenvalue equation of $L_{rw}$ from the left:
$$DL_{rw}w=D\lambda w\nL_w=\lambda Dw$$

Since $f^T L_{sym}f \ge 0$ and both $D$ and $W$ are symmetric, $L_{sym}$ is symmetric and positive-definite. This property also fits $L_{rw}$ due to property 2. Property 5 is proved directly as $L_{rw}I=0$, and the same argument for $L_{sym}$ follows from property 2. Due to the fact that $L_{sym}$ and $L_{rw}$ are both real symmetric matrices, their eigenvalues should also be real numbers. Property 6 is proved based on property 5.
