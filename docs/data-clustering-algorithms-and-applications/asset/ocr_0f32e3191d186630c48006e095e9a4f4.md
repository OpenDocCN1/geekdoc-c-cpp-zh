# 23.4 Summary

This chapter presents detailed studies on 16 external validation measures and 12 internal validation measures in a comprehensive way on various aspects of these validation measure. For the external validation part, different measures are compared and contrasted for K-means clustering. As results revealed, it is necessary to normalize validation measures before they can be employed for clustering validation, since unnormalized measures may lead to inconsistent or even misleading results. This is particularly true for data with imbalanced class distributions. Normalization solutions are also provided for some validation measures. Furthermore, lemmas are provided to show that some validation measures are mathematically equivalent and some have very similar performance. Key properties of the 16 measures are summarized These properties should be considered before deciding what the right measure to use in practice.

For the internal part, the validation properties of a suite of 12 internal validation measures for crisp clustering are studied in six different aspects: monotonicity, density, subclusters, and arbitrary shapes. Six synthetic datasets which best represent the above six aspects are used to evaluate the performance of the 12 validation measures. The results of the studies demonstrate that all measures except for the CVNN index have limitations in different application scenarios, especially showing difficulties in handling data with arbitrary shapes. On the other hand, CVNN exploits the notion of nearest neighbors and uses dynamic multiple objects as representatives for different clusters in different situations, which makes it particularly useful when the data set includes clusters with arbitrary shapes. The summarized validation measures of the 12 internal validation measures may serve as a guide for index selection in practice.
