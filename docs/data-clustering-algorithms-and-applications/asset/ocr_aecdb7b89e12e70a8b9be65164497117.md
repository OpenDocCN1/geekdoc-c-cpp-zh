The original dataset X follows probability density function $p_X(x)$, and dataset Y probability density function $p_Y(y)$. $D_{KL}$ signifies the divergence between two distributions and $a \ge 1$ is a tradeoff parameter, with larger values ensuring higher similarity of the alternative clustering.

The first part of the objective aims to ensure that the transformed data preserves the characteristics of the original (with the KL distance being zero when they are identical). The second part of the objective ensures similarity and discourages the original clusters being by requiring each object in the new data space to be closer to the cluster centers of which it was not originally part.

Some advantages of this approach are that (i) any clustering algorithm may be used to generate the alternative clustering, when the new dataset is obtained, and (ii) the approach extends naturally for discovering a particular alternative clustering. Users may use properties of the original clustering they wish to keep (i.e., original clusters or groups of objects should remain the same) and then solve the objective with the intention of finding alternative clusters to add to the desired clusters. A limitation of this approach is that it somewhat unclear what kind of properties of the original dataset X get preserved in the new dataset Y, due to the generality of the KL-distance function.

# 21.3.3.3 MAXIMUS

Work by Baie and Dong in [3] describes an algorithm known as MAXIMUS for discovering alternative clusters in a sequential manner. The MAXIMUS algorithm calculates the maximum dissimilarity between any currently available cluster and a potential target alternative solution, by forming an integer programming model. The objective of this integer programming model is to maximize the difference between the density profiles of the known clusters, versus the unknown alternative clustering. It then uses the output of the model to generate an alternative clustering.

MAXIMUS is based on the use of a clustering similarity function as ADCO, which can compare clusters according to their spatial characteristics. At a high level, the ADCO measure constructs a spatial histogram for each cluster and represents a clustering as a vector containing the spatial histogram counts for the clusters. The two clusters can then be compared using vector operations. Intuitively, the output of ADCO is a containment judgment between a clustering $C_1$ and a clustering $C_2$, expressed as "How much of $C_2$ is contained in $C_1$" or "What percentage of $C_2$ is contained in $C_1$?”

Using the ADCO measure, one may generate a spatial template to ensure that a single alternative clustering has maximum (average) dissimilarity from the background clusterings. This template describes how many objects must be present in one-dimensional projections of the feature space for each bin. Next, consensus clustering is then used to combine the clusterings from all the bins into a single clustering. Using the template, a k-means algorithm is used to derive a clustering for the feature space. Thus, the quality of the alternative clustering is achieved by the use of k-means and consensus clustering. The dissimilarity objective is achieved by using the integer programming model and the ADCO measure to obtain a spatial template which can be expected to have very high dissimilarity from the background knowledge.

In order to use MAXIMUS, it is necessary to specify the binning strategy for representing the density profile (10 bins equidensity is recommended as a default). Unlike some other algorithms, MAXIMUS does not require the user to specify a regularization parameter to trade off between the quality and dissimilarity objectives.
