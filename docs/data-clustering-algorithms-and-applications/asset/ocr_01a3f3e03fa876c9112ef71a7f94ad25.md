A synthetic generator for gene expression data is available at http://www.chele.edu/~ExPatGen/. A popular tool that implements multiple clustering algorithms (such as CC, ISA, and OSM) is the Expression Analysis Toolbox (BiChat) which is available at http://www.tik.ee.ch/~/soft/bicat. BiChat is a Java-based software that provides a nice graphical interface for analyzing gene expression data [122]. Tricicluster [123] is the first clustering algorithm for microarray experiments across the gene-sample slices, and then extends it into tricusters across time dimensions. This software can be downloaded from http://www.cs.ri.edu/~zaki/software/Tricicluster.tar.gz. STEM (Short Time-series Expression Map) is a Java program for clustering, comparing, and visualizing short time-series gene-expression data from microarray experiments. It can be downloaded from http://www.cs.umass.edu/~jems/

clusterMarker [74] provides a unified platform for traditional clustering and network clustering techniques. It is available at http://www.gl.ucsf.edu/cytoscape/cluster/clusterMarker.html. It is a fast algorithm for locating and visualizing, densely connected groups of nodes in undirected graphs, and allowing the user to easily navigate between the original graph and the web of these groups. Software is available at http://www.cfinder.org/. The code for Markov clustering is available at http://www.micans.org/mcl/.
