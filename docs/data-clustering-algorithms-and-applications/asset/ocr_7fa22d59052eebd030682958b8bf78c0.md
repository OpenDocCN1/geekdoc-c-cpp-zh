# Data Clustering: Algorithms and Applications

We start by reviewing some problems and concepts relevant to unsupervised graph cuts. Let $G=(V,E)$ be a weighted undirected graph with weight matrix $W$. If $V_1, V_2$ is a partitioning of $V$, i.e., $V_1 \cap V_2 = \emptyset, V_1 \cup V_2 = V$, then the value of cut by the partitioning $(V_1, V_2)$ is given by

```
cut(V_1, V_2) = \sum_{v_i \in V_1, v_j \in V_2} w_{ij} . \(20.18)
```

The minimum cut problem is to find a partitioning $(V_1, V_2)$ such that $cut(V_1, V_2)$ is minimized. Due to practical reasons, one often works with a normalized cut, such as the ratio-cut [25] or normalized-cut [34], which encourage the partitions $V_1, V_2$ to be more balanced. The objective for ratio-cut is

```
Rcut(V_1, V_2) = \frac{cut(V_1, V_2)}{|V_1| \cdot |V_2|} \(20.19)
```

The objective for normalized-cut is similar; however, we consider the cuts by the weight of the edges in each partition. For any subset $H \subseteq V$, let $Vol(H) = \sum_{i \in H} D_{ii}$ where $D_{ii} = \sum_{j} w_{ij}$, we have

```
Ncut(V_1, V_2) = \frac{cut(V_1, V_2)}{Vol(V_1)} \cdot \frac{cut(V_1, V_2)}{Vol(V_2)} \(20.20)
```

There are extensions of the above formulation for k-cuts [36], but we use the 2-cut setting in this chapter for ease of exposition. Graph Laplacians: Next, we review graph Laplacians, which will play an important role in our exposition. For an undirected weighted graph $G=(V,E)$ with weights $w_{ij} \ge 0$, let $D$ be a diagonal matrix with $D_{ii} = \sum_j w_{ij}$. In the existing literature, there are three related matrices that are called graph Laplacian, and there does not be a consensus on the nomenclature [36]. These three matrices are intimately related, and we will use all of them in our analysis. The unnormalized graph Laplacian is defined as

```
L_u = D - W . \(20.21)
```

The following property of the unnormalized graph Laplacian is important for our analysis: for $f \in \mathbb{R}^n$, we have

```
f^T L_u f = \frac{1}{2} \sum_{i,j} w_{ij}(f_i - f_j)^2 . \(20.22)
```

The matrix $L_u$ is a symmetric and positive definite. There are also two normalized graph Laplacians in the literature

```
L_r = D^{-1}L_u = I - D^{-1}W , \(20.23)
```

```
L_s = D^{-1/2}L_uD^{-1/2} = I - D^{-1/2}WD^{-1/2} . \(20.24)
```

For the symmetrically normalized graph Laplacian, the following property holds. For any $f \in \mathbb{R}^n$, we have

```
f^T L_s f = \frac{1}{2} \sum_{i,j} w_{ij}(\frac{f_i}{\sqrt{D_{ii}}} - \frac{f_j}{\sqrt{D_{jj}}})^2 \(20.25)
```

We refer the reader to [30, 17, 36] for details on Laplacians and their properties.
