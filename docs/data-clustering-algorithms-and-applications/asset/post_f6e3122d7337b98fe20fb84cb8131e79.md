The SNN similarity of two points is defined as the cardinality of the intersection of the sets of the k nearest neighbors of the two points. The SNN graph is created by linking a pair of points if and only if they have each other in their k-neighbor list. The shared nearest neighbor graph keeps the links in uniform density and breaks links in transition regions, i.e., it keeps links in a region of any density high or low, as long as the region has uniform density. This property supports the detection of clusters of different density. A point is considered core if the number of points that have an SNN similarity of Eps or greater is at least MinPts. With these definitions, the DBSCAN algorithm (Section 5.2) can be applied.

# 5.6 Subspace Clustering

In high-dimensional datasets, clusters tend to reside in lower-dimensional subspaces rather than in the full-dimensional space, which has motivated the task of subspace clustering, as discussed in Chapter 9. The CLIQUE algorithm [2], a prominent subspace clustering algorithm, is density-based. It discretizes the space through a grid and estimates the density by counting the number of points in a grid cell. Two grid cells are considered connected if they share some edge or face. A subspace cluster is then a set of neighboring cells in an arbitrary subspace. Note that CLIQUE offers not the subspace clusters, but also some minimal descriptions of the clusters. Figure 5.4 illustrates a two-dimensional dataset without full-clusters, which contains a one-dimensional subspace cluster (18 ≤ age ≤ 24).

More formally, let $S = A_1 \times A_2 \times \dots \times A_d$ be a $d$-dimensional numerical space, and $D = v_1,v_2,...,v_d$ be a set of $d$-dimensional points. The data space $S$ is partitioned into units by partitioning every dimension into $\xi$ intervals of equal length, and each unit $u$ is the intersection of one interval from each dimension. The selectivity of a unit is defined to be the fraction of total data points contained in the unit. We call a unit $u$ dense if $select(u)$ is greater than density threshold $\tau$. Similarly, units are defined in all subspaces of the original $d$-dimensional space. Two $k$-dimensional

A cluster is defined as a maximal set of connected units in $k$ dimensions. A region is an axis-parallel rectangular $k$-dimensional unit, expressed as a DNF expression on intervals of the domains $A_i$. A region contained in a cluster $C$ is said to be maximal if no proper subset of $R$ is contained in $C$. A minimal description of a cluster is a nonredundant covering of the cluster with maximal regions. Given a set of data points and the input parameters, $\xi$, and $\tau$, the task of subspace clustering is to find all clusters in all subspaces of the original data space together with a minimal description of each cluster.

The CLIQUE algorithm decomposes the task of subspace clustering into three subtasks:

- 1. identification of subspaces that contain,
- 2. identification of clusters, and
- 3. generation of minimal descriptions.

We discuss only the first subtask, which is the most challenging. If a set of points $S$ is a cluster in a $k$-dimensional space, then $S$ is also a cluster in any $(k - 1)$-dimensional projections of this space. Due to this property, dense units (and therefore subspaces clusters) can be efficiently discovered in a discovery-wise manner, starting with 1-dimensional units, and extending dense units by one dimension at every level. The algorithm terminates when the density of all candidate units at a given level requires no database search. The algorithm terminates when no more candidates are generated at the current level.

If a dense unit exists in $k$ dimensions, all of its projections in the $O(k)$ subsets of $k$ dimensions are also dense. The running time of the CLIQUE algorithm is therefore exponential in the highest density of any dense unit. It can be shown that the candidate generation procedure multiplies the number of candidates that can be found, a heuristic based on the Minimal Description Length principle to guarantee that all dense units are found, all subspaces and units that are not "interesting". To measure the interestingness of a subspace, its coverage is computed, $i$, the fraction of the data that is covered by the dense units in that subspace. Only subspaces with large coverage are selected, and the remaining ones are pruned.

In CLIQUE, as in all grid-based approaches, the quality of the results depends on the appropriate choice of width and partitions of the grid cells. To address this problem, [17] suggests the OptGrid method. Grid cutting planes should partition the dataset in areas of low density and discriminate clusters as much as possible.
