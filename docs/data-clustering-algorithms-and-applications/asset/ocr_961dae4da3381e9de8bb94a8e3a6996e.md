# 12.2.1 Clustering Road Map

Categorical clustering partitions N objects into k clusters. Object o has attributes $\{o_1, \dots, o_m\}$ (usually $N \gg m$). Attribute $o_i, i=1 \cdots m$, has a domain $D_i$ of a categorical or boolean datatype. Figure 12.3 depicts inheritance relationships between categorical clustering algorithms. Root approaches are separated into algorithms with different features: partitioning, hierarchical, density-based, model-based [41, 42, 73]. Refinement algorithms improve upon a root approach, inheriting the approach's features, while possibly introducing drawbacks.
