The problem is solved using an iterative labeling algorithm. Given method with $W$ among the nodes, the weights are normalized to obtain $S = D^{-1/2}WD^{-1/2}$ where $D$ is a diagonal matrix with $D_{ii} = \sum_j w_{ij}$. Starting from an initial guess $f^{(0)}$, the iterative algorithm proceeds with the following updates:

```
$f^{(i+1)} = \alpha Sf^{(i)} + (1-\alpha)y, \quad (20.47)$
```

where $\alpha \in \{0,1\}$. As shown in [45], this update converges to $f^*=(1-\alpha)(I-S)^{-1}y$, which can be shown to optimize the objective function in 20.46 when $\alpha=1/(1+\mu)$. Note that show that the LHC formulation is a special case of the GLP formulation in 20.38. By including the normalizing Laplacian in Equation 20.25, LHC can be seen as a special case of GLP as:

```
$\min_{f\in\mathbb{R}^n} f^T Sf, \quad \text{s.t.} \ \sum_{i=1}^n (f_i-y_i)^2 \le \varepsilon(\mu), \quad (20.48)$
```

where $\varepsilon(\mu)$ is the corresponding to the Lagrange multiplier $\mu$. Note that in LHC one starts with an initial label $y_{i,i}=1,\dots,n$, the constraint terms correspond to all the points.

# 20.4.5 Related Methods

We review three other methods from the literature, vic, cluster kernels, Gaussian random walks, and local neighborhood propagation for graph-based semisimple learning which are closely related to the GL framework.

# 20.4.5.1 Cluster Kernel

The main idea in cluster kernels (CK) [16] is to embed the data into a lower dimensional space based on its structure and subsequently be supervised learning on the lower-dimensional data. If $K$ denotes a suitable kernel on the data space, the embedding method focuses on the $k$ primary eigenvectors of the symmetri matrix $D^{-1/2}KD^{-1/2}$. If $K$ represents the edge weights on the graph $G=(V,E)$ between the points, i.e., $K=W$, then the embedding corresponds to the $k$ eigenvectors of the symmetri Laplacian $L=I-D^{-1/2}WD^{-1/2}$ corresponding to the smallest eigenvalues. In particular, for $k=1$, the embedding is given by the eigenvector corresponding to the smallest eigenvalue of $L_c$ which is used in LHC in absence of supervision. CK trains a semisimple learning on the lower-dimensional embedding to obtain the final label assignments.

# 20.4.5.2 Gaussian Random Walks EM (GWEM)

Consider a random walk on the graph with transition probability $P=D^{-1}W$. The GWEM method [35] works with the $m$-step transition matrix $P^m$ so that the probability of going from $x_i$ to $x_j$ is $p_m(x_j|x_i)=(P^m)_{ij}$. The random walk is assumed to start with uniform probability from any of the nodes. Using Bayes rule, one can obtain the posterior probabilities $P_0(y_i|x_j)$. Each point is assumed to have a (possibly unknown) distribution $p(y_i|x_i)$ over the cluster labels. The cluster label is based on $y_i=\textargmax},P(y_j=c(x_j))$. Now, since $P(y_i|x_i)$ is unknown for the unlabeled points, an EM algorithm can be used to alternately maximize the post-probability of known labels over the labeled points

```
$\sum \log P(y_i|x_k)=\sum_{k=1}^N \log P(y_i|x_k)P_0(x_i|x_k). \quad (20.49)$
```
