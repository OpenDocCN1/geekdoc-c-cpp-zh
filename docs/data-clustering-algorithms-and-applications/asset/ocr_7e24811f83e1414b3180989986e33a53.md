# 11.2 One-Pass Clustering Algorithms

In this section, we will review some early, classic clustering algorithms which are designed for large-scale data sets. CLARANS [39, 40] is one of the earliest algorithms to use randomized search to fight with the exponential search space in the K-medoid clustering. In BIRCH [47], a new data structure clustering feature tree (CF-tree) was proposed to reduce the I/O cost when the input data exceeds the memory size. Finally, CURE [22] uses multiple data points for each cluster to order the irregular shapes and further adds sampling to the hierarchical clustering procedure. Thanks to these techniques, we can often largely reduce the iteration number in clustering procedure. In some extreme cases, they often generate pretty good results by one pass over the input data. We collectively collect these algorithms as one-pass clustering algorithms.

# 11.2.1 CLARANS: Fighting with Exponential Search Space

Let us start with one of the earliest representative algorithms, i.e., Partitioning Around Medoids (PAM) [32]. The basic idea of PAM is to choose one representative point from each cluster (e.g., the most central data point in the cluster). If we want to find k for n data points, the algorithm essentially tries to find the k medoids. Once optimal k-medoid is found, the remaining (nonmedoid) data points are assigned to the selected medoids based on their distance to the k-medoid. This follows an iterative procedure where each iteration, it replaces one of the current medoids by a nonmedoid data point. It is easy to see that the computational cost for PAM is high: first of all, in each iteration, we need to check all the (n-k) × k possible pairs; the overall search space is exponential, we have possible k-medoid assignment. To address this, Clustering Large Applications (CLARA) [32] relies on sampling to reduce the search space. Instead of trying to find the optimal k-medoid from the original entire data set as in PAM, CLARA first takes a sample of k from the original n data points and then calls PAM to find medoid. Once the optimal medoid is found, the remaining (unsampled) data points are assigned to one of these k clusters based on their distance to the k-medoid.
