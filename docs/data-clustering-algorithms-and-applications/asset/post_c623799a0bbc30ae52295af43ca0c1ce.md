## 20.4 A Unified View of Label Propagation

The semisupervised graph-cut problems described in Section 20 belong to a widely studied family of problems which can be solved using label propagation methods [15]. In this section, we present a Generalized Label Propagation (GLP) framework, discuss various specific instantiations of the framework from the literature, and illustrate its connections to the semisupervised graph-cut problems.

### 20.4.1 Generalized Label Propagation

GLP formulation considers a graph-based semisupervised learning setting. Let W be the symmetric weight matrix and L be a corresponding graph Laplacian. Note that L may be any of the Laplacians discussed up in Section 20.3, and we will see how different label propagation formulations result from specific choices of the Laplacian. Let $f \in \mathbb{R}^n$, where $n = \ell + u$, be the predicted score on each data point $x_i, i=1,\dots,n$; the predicted label $\hat{f}_i$ can be obtained as sign$(f_i)$. The GLP problem can be formulated as:

```
$$\min_{f \in S} f^T L f \quad \text{s.t. \quad \sum_{i=1}^n (f_i - y_i)^2 \le \varepsilon, (20.38)$$
```

where $\varepsilon \ge 0$ is a constant and $S \subseteq \mathbb{R}^n$. For most existing formulations $S=\mathbb{R}^n$, whereas for $S=\{f \in \mathbb{R}^n, f^T \mathbf{1} = 0\}$ where $\mathbf{1}$ is the ones vector. The Lagrangian for the problem is given by $L(f, \mu) = f^T L f + \mu \sum_{i=1}^n (f_i - y_i)^2$, where $\mu \ge 0$ is Lagrangian multiplier. Some variants assume $y_i=0$ for $i=(\ell,\dots,n)$, so the result will be of form $\sum_{i=1}^n (f_i-y_i)^2=\varepsilon$. Assuming the Laplacian to be symmetric, with $L$ and $L_\ell$, the first order conditions are given by $(L+\mu I)f = \mu y$, where $I$ is identity matrix. Existing methods work with the special case $\varepsilon=0$, which matches the constraints $\sum_{i=1}^n (f_i-y_i)^2=0$ and $f_i=y_i$ on labeled points. The first order conditions for the special case are given by $L_\ell f=0$. In the next sections, we show how much of existing label propagation methods for semisupervised learning can be derived directly as a special case of the GLP formulation or alternatively with special choices of Laplacian $L$, and subspace $S$.

### 20.4.2 Gaussian Fields

Motivated by the assumption that neighboring points in a graph will have Gaussian fields (GFs), the energy function is considered [46]:

```
$E(f) = \frac{1}{2} \sum_{i,j=1}^n w_{ij}(f_i-f_j)^2. (20.39)$
```

The GF method computes labels by minimizing the energy $E(f)$ with respect to $f$ under the constraint that $f_i=y_i$ for all labeled points. As observed in [46], the energy function is harmonic, i.e. it is twice differentiable and satisfies Laplace’s equation [24]. From the harmonic property of the energy function it follows that the predicted labels will satisfy $f=D^{-1}Wy$. In block matrices constructing:

```
$$\begin{bmatrix} D_{\ell} & 0 \\ 0 & D_{uu} \end{bmatrix} \begin{bmatrix} f_{\ell} \\ f_u \end{bmatrix} = \begin{bmatrix} W_{\ell\ell} & W_{\ell u} \\ W_{u\ell} & W_{uu} \end{bmatrix} \begin{bmatrix} f_{\ell} \\ f_u \end{bmatrix}$$
```

```
$\min_{f_u \in \mathbb{R}^u} f_u^T L_u f_u, \text{s.t. } \sum_{i=1}^n (f_i - y_i)^2 \le 0.$
```

### 20.4.3 Tikhonov Regularization (TIKREG)

Given a partially labeled data set, TIKREG [7] is an algorithm for regularized regression on graphs, where the objective is to infer a function $f$ over graphs. The objective for TIKREG is given by:

```
$\min_{f \in \mathbb{R}^n} \sum_{i,j=1}^n w_{ij}(f_i - f_j)^2 + \frac{1}{\gamma} \sum_{i=1}^n (f_i - y_i)^2$
```

with the constraint that $f \perp \mathbf{1}$, i.e. in the orthogonal subspace of $\mathbf{1}$, all ones vector. The parameter $\gamma$ is chosen (positive) real. A closed form for the problem is obtained [7]:

```
$f = (\gamma L_u + I_k)^{-1}(\gamma y_l).
```

where $\hat{y} = (y_1, y_2, ..., y_k, 0, ..., 0)$, $I_k = diag(1, ..., 1, 0, ..., 0)$ with the number of ones equal to the labeled points. The constraint on $f$ is enforced by the Lagrange multiplier $\mu$, which is computed as:

```
$\mu = \frac{\mathbf{1}^T(\gamma L_u + I_k)^{-1}\gamma y_l}{\mathbf{1}^T(\gamma L_u + I_k)^{-1}\mathbf{1}}$
```

The objective in Equation 20.42 can be viewed as a special case of the GLP objective in (20.38). As previously, the first term is $f_u^T L_u f_u$, where $L_u$ is the unnormalized Laplacian. The second term corresponds to the constraint $\sum_{i}(f_i - y_i)^2 \le \varepsilon$, in (20.38) where $1/\gamma$ is the optimal Lagrange multiplier corresponding to the constraint. In other words, if $\varepsilon(1/\gamma)$ is the constraint value that leads to the optimal Lagrange multiplier $1/\gamma$, the TIKREG problem can be seen as a special case of GLP:

```
$\min_{f_u \in \mathbb{R}^u} f_u^T L_u f_u, \text{s.t. } \sum_{i=1}^n (f_i - y_i)^2 \le \varepsilon(1/\gamma).$
```

### 20.4.4 Local and Global Consistency

The Local Global Consistency (LGC) approach [45] gives an graph-based regularization framework for semisvised learning. In particular, the LGC is formulated based on the following objective:

```
$\min_{f \in \mathbb{R}^n} \frac{1}{2} (\sum_{i,j=1}^n w_{ij}(\frac{f_i}{\sqrt{D_{ii}}} - \frac{f_j}{\sqrt{D_{jj}}})^2 + \mu \sum_{i=1}^n (f_i - y_i)^2)$
```
