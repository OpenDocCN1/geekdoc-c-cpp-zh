## 16.2.4.1 Types and Structures of Bicusters

We will now discuss the types of bicusters that might appear in gene expression data [71]. Let $\mu$ be a typical value in the bicluster. $\alpha_i$ is the adjustment for row $i$ and $\beta_j$ is the adjustment for column $j$.

- Bicusters with constant values. All the elements in this type have the same value, $a_{ij} = \mu$ (Figure 16.3a).
- Bicusters with constant values on rows. $a_{ij} = \mu + \alpha_i$ (Figure 16.3b).
- Bicusters with constant values on columns. $a_{ij} = \mu + \beta_j$ (Figure 16.3c).
- Bicusters with (additive) coherent values. Each row and column is obtained by addition of the previous row and column by a constant value. $a_{ij} = \mu + \alpha_i + \beta_j$ (Figure 16.3d).
- Bicusters with (multiplicative) coherent values. Each row and column is obtained by multiplication of the previous row and column by a constant value, $a_{ij} = \mu \times \alpha_i \times \beta_j$ (Figure 16.3e).
- Bicusters with coherent evolutions. In this case, the direction of change of the values is not considered. Only the direction of change is important (Figure 16.3(f)).

Though the earlier clustering algorithms used to find only a single buster at a time (Figure 16.4(a)), most of the recent approaches attempt to find several busters simultaneously. - Exclusive row and column busters which form rectangular blocks after reordering rows and columns (Figure 16.4(b)).

## 16.2.4.2 Clustering Algorithms

In the first clustering algorithm proposed by Cheng and Chang [21], the mean-squared residue (MSR) was used as a measure of coherence between two genes. Given a gene expression submatrix $X$ that has $I$ and $J$ conditions, the residue is computed as follows:

$$H(I,J) = \frac{1}{|I||J|} \sum_{i \in I, j \in J} (x_{ij} - \mu_{ij})^2$$

where $\mu_i = \frac{\sum x_{ij}}{n}$ is the row mean, $\mu_j = \frac{\sum x_{ij}}{m}$ is the column mean and $\mu_{ij} = \frac{\sum x_{ij}}{nm}$ is the overall mean of the matrix $X$, and $x_{ij}$ is a particular element ($i$th row and $j$th column). A perfect buster has MSR=0. The algorithm starts with the data matrix; then a set of row/column deletions are applied to produce one buster, which will be replaced with random numbers. The algorithm continues until a certain number of busters is reached. The algorithm has two limitations: (i) it finds only one buster at a time, and random interference (masking the busters with random numbers) reduces the quality of busters and obstruct the discovery of other busters. After this algorithm was proposed, a plethora of new algorithms to extract busters from noisy expression data have been developed. We will mention only a few here; for a detailed discussion on clustering algorithms, we refer the readers to an excellent survey on this topic [71].

Coupled-two clustering (CTWC) was proposed in [41]. In this technique, a subset of genes (conditions) are used to cluster the genes. Order-Preserving Submatrix Patterns (OPSMs) [13] algorithm finds local patterns in the expression levels of all genes inside the linear ordering of experiments. However, the OPSM algorithm finds only one cluster at a time and captures only correlated genes. Iterative Signature Algorithm (ISA) [51] is a statistical clustering algorithm which defines a module (cluster) as a correlated set of genes under a set of experimental conditions. ISA starts from a set of randomly selected genes (or conditions) that are iteratively refined until they are mutually consistent. At each iteration, a threshold is used to remove noise and maintain the correlated genes and the associated genes.

## 16.2.4 Recent Developments

Recently, there have been emerging trends in the field of clustering: (i) Identifying overlapping busters and negative correlations in a cluster has gained attention due to their biological importance [17]. Some of the recent algorithms [25, 77] allow for overlapping busters and find $k$ rows and $l$ columns simultaneously. Differential clustering [76, 77, 37] aims to find genes that are correlated under a subset of conditions in one class but not the other. Identifying such class-specific busters can provide valuable knowledge for understanding the roles of genes in several diseases [76]. The classes could represent different tissues (normal versus cancerous), different types (e.g., male versus female), gene profiles (African American versus Caucasian) [61], (ii) Query-based clustering algorithms [30, 122, 44] allow for identifying busters that are centered around seed genes of interest. In these algorithms, new search strategies are developed to exploit the expression profiles of certain genes of interest that are used to guide the buster searching mechanism. These approaches are extremely handy when one wants to compare the expression profiles of a certain set of genes with that of the existing knowledge which can be obtained by querying for similar profiles from a large-scale expression company.

## 16.2.5 Tricustering

The goal of tricustering is to find coherent clusters that are similar across three dimensions. The motivation of this task comes from the biological domain where finding coherent clusters along the gene-sample-time (temporal) or gene-sample-region (spatial) dimensions is of great value. Although the problems that are suitable for tricustering have been addressed earlier by ad-hoc methods [55], Zhao and Zaki [123] proposed the first formal algorithm for tricustering. After that, a few more algorithms have been proposed in recent years [98, 57].

## Data Clustering: Algorithms and Applications

Given $G$, the set of genes; $S$, the set of samples; and $T$, the set of time points; a truster $C$ is a submatrix of the dataset $D = G \times S \times T = \{c_{ijk}\}$, with $X \subseteq G, Y \subseteq S$, and $Z \subseteq T$ provided that conditions of homogeneity are satisfied. For example, a simple condition might be that all values $\{c_{ijk}\}$ are identical or approximately equal. If we are interested in finding common co-expression patterns across different samples and times, we can find clusters that have similar values in the $G$ dimension, but different values in the $S$ and $T$. Other homogeneity conditions can be defined, such as similar values in the $S$ dimension and order preserving submatrices.

Let $\mathcal{B}$ be the set of all trusters that satisfy the given homogeneity conditions, $C \in \mathcal{B}$ and $C' \in \mathcal{B}$. The similarity between two trusters is measured by the mean-squared residue (MSR). The algorithm clusters the data into $K$ HMMs that maximize the likelihood of the data given the learned HMM model. For expression data, the emission properties are assumed to be Gaussian with fixed variance. The authors [91] developed a new algorithm for clustering genes based on a mixture of HMMs. The parameters of this model are learned using an Iterative Expectation-Maximization algorithm. The iterative steps in this algorithm are (i) genes are associated with the HMM that would have most likely generated their time courses and (ii) the model parameters are updated. This process continues until the parameters converge.
