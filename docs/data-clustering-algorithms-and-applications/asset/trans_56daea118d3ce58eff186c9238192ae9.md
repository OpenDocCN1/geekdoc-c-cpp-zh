

# 聚类分类数据

输入：对象集合 S。
参数：(1) δϕ : ϕ 的增量。
(2) ϕ 的阈值 : 对象与其簇的众数之间可以不同的值的最大数量。
默认参数值：(1) δϕ=1。
(2) threshold = 分类属性的数量 m。

输出：簇的集合。
方法：
1. 按属性频率递减的顺序排列对象。
2. 将第一个对象插入到新簇中，使用簇的众数，并从 S 中移除该对象。
3. 将 ϕ 初始化为 1。
4. 循环遍历对象，直到 S 为空或 ϕ > threshold
a. 对于 S 中的每个对象 o
i. 使用相异度度量比较 o 与所有现有簇的众数，找到 o 的最近簇 c。
ii. 如果 o 与 c 的众数之间不同的值的数量大于 ϕ，则将 o 插入到新簇中
iii. 否则，将 o 插入到 c 中并更新 c 的众数。
iv. 从 S 中移除 o。
b. 对于簇 c，如果 c 中只有一个对象，则移除并将该对象放回 S。
c. 如果在此轮中没有对象被插入到大小 > 1 的簇中，则将 ϕ 增加 δϕ。

12.7 显示了 MULIC 聚类算法的主要部分。MULIC 不存储立方体，而是进行简化以降低运行时间。MULIC 从密集区域开始并通过 ϕ 变量表示的半径向外扩展。当 MULIC 扩展一个簇时，它不会像 HIERDENC 那样搜索所有成员对象。相反，它使用一个总结簇内容的模型。众数是一个向量 μ = {μ₁, ..., μm}，其中 μi 是给定簇 c 中第 i 个属性的最频繁值 [47]。MULIC 算法确保每当一个对象 o 被聚类时，它会被插入到具有最小相异度众数的簇中。o 与 μ 之间的默认相异度度量是 Hamming 距离，尽管可以使用任何度量。MULIC 簇由逐渐形成的层组成，通过放宽将对象插入簇的最大相异度准则。MULIC 不要求用户指定簇的数量并且可以识别离群值。

MULIC 与传统的层次聚类有几个不同之处，后者将所有距离存储在上三角方阵中，并在每次合并后更新距离 [50, 61]。MULIC 簇具有清晰的分离。MULIC 不需要截止值来识别簇，在层次聚类中；这对于某些 MULIC 应用是有益的，例如在 [7] 中发现的蛋白质相互作用网络。层次聚类的一个缺点是簇合并的顺序会影响结果，并且“坏”的合并无法在后续过程中纠正。此外，如果合并了几个大簇，可能会丢失有趣的局部簇结构。MULIC 在聚类过程中不合并簇。

## 12.4.4 Model-Based Clustering

基于模型的聚类假设对象匹配一个模型，或聚类对象使其匹配分布。模型可以由用户指定并且参数可能在过程中发生变化。在生物信息学中，基于模型的聚类方法将背景知识整合到基因表达、互作组和序列中 [23, 66, 45, 51, 52]。构建模型是无监督的；某些假设可能是错误的，结果将不准确。基于模型聚类的另一个缺点（尤其是神经网络）是在大型数据集上处理缓慢。

### 12.4.4.1 BILCOM Empirical Bayesian (Mixed Categorical and Numerical)

BILCOM Bi-Level Clustering Of Mixed categorical and numerical data types 是一种基于模型的方法 [10]。该算法采用经验贝叶斯方法，以分类数据作为指导。在生物学应用中针对基因，基因本体论 (GO) 注释代表分类数据，基因表达数据为数值。基于模型的聚类通过整合背景知识来发现任意的基因表达簇 [1, 24, 45, 51, 52, 69, 20, 64]。

BILCOM 在两个层级上执行聚类，其中第一层级聚类为第二层级奠定基础，模拟伪贝叶斯过程。BILCOM 主要应用于领域的数据集。在这些集合中，分类数据代表对象的语义信息，而数值数据代表实验结果。第一层级强调分类相似性，第二层级强调数值相似性。第一层级的输出作为第二层级的输入，第二层级的结果是 BILCOM 的输出。Figure 12 显示了簇。第二层级由子结构组成。对象 A 被分配到不同的第一和第二层级簇，其中第二层级的数值相似性强于第一层级的分类相似性。另一方面，对象 B 被分配到相同的簇，因为分类和数值相似性都支持这种分类。BILCOM 考虑对象与其可能被分配到的簇的分类和数值相似性。

在第一和第二层级使用不同类型的数据。数值数据代表涉及对象的结果结果。例如，第二层级使用的数值数据可能如下所示：BILIRUBIN: 0.39; ALBUMIN: 2.1; PROTIME: 10。分类数据代表对示例中对象的观察为真的内容。例如，第一层级使用的分类数据可能是关于对象的现有信息如下所示：SEX: male; STEROID: yes; FATIG: no。

BILCOM 的主要缺点是用户必须指定簇的数量。

### 12.4.4.2 AutoClass (Mixed Categorical and Numerical)

AutoClass 是一种用于混合数据集的聚类算法，使用贝叶斯方法基于先验分布确定最佳簇 [71]。AutoClass 在给定每个属性的先验分布的情况下找到对象的最可能分类到簇中，象征着用户的先验信念。在第一步，用户为数据集中 m 个属性中的每一个选择一个概率分布。作为示例，设对象 X 上的证据 = {age=28, blood-type=A, weight=73kg}；blood-type 是一个用 Bernoulli 分布建模的分类属性，age 和 weight 是用正态 (Gaussian) 分布建模的数值属性。在每次循环中，AutoClass 更改簇中对象的分类，以便每个对象都被分配到具有属性概率分布（考虑当前均值和方差）的簇，该分布给出观察到对象值的最高概率。此外，AutoClass 迭代检查不同数量的簇，这些簇不是由用户指定的。然后，AutoClass 更改簇中属性的概率分布的均值和方差。迭代继续进行，直到簇和属性的概率分布稳定。AutoClass 的输出是若干可能簇的混合，其中聚类根据属性的概率分布将每个对象分类到最可能的簇。

AutoClass 的缺点包括用户必须指定要搜索的模型空间，并且在错误模型下可能产生错误结果。此外，AutoClass 在某些数据集上收敛到聚类结果可能很慢。
