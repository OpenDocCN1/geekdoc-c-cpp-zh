
## 23.2.3.1 Normalizing the Measures

Generally speaking, normalizing techniques are divided into two categories. One is based on a statistical view, which formulates a baseline distribution to correct the measure for randomness. A clustering can be termed 'valid' if it has an unusually high or low value, as measured with respect to the baseline distribution. The other technique uses the minimum and maximum values to normalize the measure into the [0,1] range. From a statistical view, it is equivalent to this technique with that each measure takes a uniform distribution over the interval.

The Normalizations of R, FM, Γ, Γ', and MS. The normalization scheme can take the form:

```
$S_n = \frac{S-E(S)}{\max(S)-E(S)} \quad (23.1)$
```

where max(S) is the maximum value of the measure S and E(S) is the expected value of S based on the baseline distribution. Some measures derived from the distribution community, such as R, FM, Γ, and Γ', use this scheme.

Specifically, Hubert and Arabie (1985) [24] suggested using the multivariate hypergeometric distribution as the baseline distribution where the row and column sums are as in Table 23.2, but the partitions are randomly selected. This determines the expected value as follows:

```
$E(\sum n_{ij}) = \frac{\sum \binom{n_i}{2} \sum \binom{m_j}{2}}{\binom{\sum n_{ij}}{2}} \quad (23.2)$
```

Based on this value, it is easy to compute the expected values of R, FM, Γ, and Γ' since they are linear functions of $\sum \binom{n_{ij}}{2}$ under the hypergeometric distribution assumption. Furthermore, the exact maximum values of the measures are computationally prohibited under the hypergeometric distribution assumption, it is still reasonable to estimate them by 1. Then, according to Equations (23.1) and (23.2), the normalized R, FM, Γ, and Γ' may be calculated as shown in Table 23.5.

## Data Clustering: Algorithms and Applications

### Procedure 1: The computation of $F$

1. Let $n^* = \max n_i$.
2. Sort the class sizes so that $n_{[1]} \leq \dots \leq n_{[K^*]}$.
3. Let $a_j = 0$, for $j = 1, 2, \dots, K^*$.
4. For $j=1$ to $K'$:
5. If $n^* \leq n_{[j]}$, $a_j = n^*$, break.
6. Else, $a_j = n_{[j]}$, $n^* \leftarrow n^* - n_{[j]}$.
7. $F_- = \frac{2}{n}\sum_{i=1}^K a_i / (1 + \max n_i/n^*)$.

PROOF. It is easy to show

```
$F = \sum_{j=1}^n \max \frac{n_{ij}}{n_i + n_j} \geq 2 \max_{j} \frac{n_{ij}}{n_i/n_j + 1} \quad (23.4)$
```

