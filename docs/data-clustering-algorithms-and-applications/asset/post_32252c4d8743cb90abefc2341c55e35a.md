## 7.4 Consensus Clustering

Consensus clustering, also called aggregation of clustering, refers to a situation where multiple clustering results on the same dataset are already obtained and the task is to find a clustering [49, 107, 47, 75] which is closest to all of them as.

Formally let $X = \{x_1, x_2, \dots, x_n\}$ be a set of $n$ data points. Suppose we are given a set of $T$ clusters (or partitions) $\mathcal{P} = \{P^1, P^2, \dots, P^T\}$ of $X$. Note the number of clusters could be different for different results. Let us define the consensus matrix $M_{ij}(P^k)$ for a single partition $P^k$:

$$M_{ij}(P^k) = \begin{cases} 1 & \text{if belong to same cluster} \\ 0 & \text{otherwise} \end{cases}$$

Consensus clustering looks for a partition (consensus clustering) $P^*$ which is the closest to all the partitions:

$$\min_{P^*} \frac{1}{T} \sum_{t=1}^{T} \|M_{ij}(P^t) - M_{ij}(P^*)\|_F^2 = \frac{1}{T} \sum_{t=1}^{T} \|M(P^t) - M(P^*)\|_F^2$$

Let the average association between $i$ and $j$ be $\bar{M}_{ij} = \frac{1}{T} \sum_{t=1}^{T} M_{ij}(P^t)$. We have:

$$J = \frac{1}{T} \sum_{t=1}^{T} \|M(P^t) - \bar{M}\|_F^2 + \|\bar{M} - M(P^*)\|_F^2$$

The first term is a constant which measures the average distance from the consensus association matrix $M$. The smaller this is, the closer to all the other partitions are.

We minimize the optimal clustering partition $P^*$ can be specified by clustering indicators $H = \{0,1\}^{n \times c}$, with the constraint that in each row of $H$ there can be only one '1' and the rest must be zeros. The key connection here is that the consensus matrix $M(P^*) = HH^T$. With this, consensus clustering problem becomes:

$$\min_{H} \|M - HH^T\|^2 \text{ s.t. } H \text{ is a cluster indicator.}$$

We relax the constraint. Clearly $(H^T H) = D = \text{diag}(n_1, \dots, n_k)$ where $n_k = |C_k|$. However, before we solve the problem, we have no way to know $D$ and no way to impose the constraint. A slight refinement resolves the problem. We define $\hat{H} = H(H^T H)^{-1/2}$. Thus,

$HH^T = \tilde{H}\tilde{D}^T, \tilde{H}^T\tilde{H} = H(H^T)^{-1}H$. Therefore, the consensus clustering becomes the following optimization problem:

$$\min_{\tilde{H}^T\tilde{H}, \tilde{D} \ge 0} ||\tilde{M} - \tilde{H}\tilde{D}^T||^2, \text{ s.t. } D \text{ is diagonal.}$$

Now, $H$ and $D$ are new variables. We do not need to specify the cluster sizes. Thus, the consensus clustering is equal to a symmetric NMF problem [73].

## 7.6.5 Graph Clustering

Three NMF models (Symmetric NMF, Asymmetric NMF, and Joint NMF) have been proposed in [123] to identify communities in different types of users (undirected, directed, and compound). Among their proposed models, symmetric NMF and asymmetric NMF are special cases of tri-factorization. For example, in music recommendation, we are given:

- (1) the user network $U$
- (2) the music network $D$
- (3) the preference network $M$

The objectives are simultaneously minimized:

$$\min_{G} \|M - G\|^2 + \alpha\|U\|^2 + \beta\|D\|^2 \text{ s.t. } G \in \mathbb{R}^{n \times m}$$

## 7.6.6 Other Extensions

NMF methods have also been developed for other extensions. Recently, Li et al. [77, 76] proposed constrained NMF for both source and target. NMF has also been extended for multiway data. Nonnegative Tensor Factorization (NTF) is an extension of NMF. For three-way data, the standard NTFS can be thought as OSVD (high-order SVD) [27]. With nonnegativity constraints, Tri-factorization has also been extended as Tri-NTF (Tri-factor Nonnegative Tensor Factorization) to analyze three-way data8.

## 7.7 Conclusions

Matrix-based methodologies are rapidly becoming a significant part of data mining as they are amenable to vigorous analysis and can benefit from the well-established knowledge in linear algebra. In particular, NMF factorizes an input matrix into two nonnegative matrices of lower rank and has the capability to solve challenging data mining problems. Thanks to the data mining capabilities, NMF has attracted a lot of recent attention and has been used in a variety of fields. This chapter provides a comprehensive review of nonnegative factorization methods for clustering by outlining the theoretical foundations on NMF for clustering and providing an overview of different variants of NMF. We also examine the practical issues in NMF algorithms and summarize recent advances using NMF-based methods for solving other problems.

There are many future research directions on NMF for clustering including the following:

- extending NMF for better cluster representation and for dealing with more challenging problems;
- proving deeper understanding of NMF's clustering capability enables the theoretical results;
- developing novel and rigorous proof strategies to prove the correctness and convergence properties of the numerical algorithms;
- studying NMF with other distance measures (such as other matrix norms and Bregman divergences);
- improving the scalability of NMF algorithms for large-scale datasets;
- applying NMF to many different real-world applications and solving real problems.
