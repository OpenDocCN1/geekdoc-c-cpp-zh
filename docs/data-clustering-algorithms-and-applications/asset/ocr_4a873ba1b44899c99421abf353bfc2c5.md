As a consequence, partitioning is applied on the small graph very efficiently. A popular method is to construct a maximal matching on the graph [105]. A matching is a subset of edges (M ⊆ E) such that no two edges share the same endpoint. A matching is maximal if no edge can be added to the matching. Once a matching has been constructed, vertices at the ends of each edge are collapsed into a super node in the coarsened graph. Specifically, for $e_{ij}\in M$, vertices $v_i$ and $v_j$ are collapsed into a single vertex. The weight of the new vertex $v$ is $w(v_i)+w(v_j)$ in [105].

Different techniques exist for construction of a maximal matching. One can use randomized methods for coarsening graphs quickly. A simple randomized matching (RM) is given in [78] which randomly selects edges until the matching is maximal. A slight modification of RM which is known as heavy edge matching (HEM) has been proposed in [86]. The basic idea is to reduce the total weight of the coarsened graph which is reduced in cut-size as well as the original graph. However, one problem associated with this approach is that it can miss heavy edges as pointed out in [105]. Another modification was proposed in [72] by Gupta who suggests sorting the edges by weight and then choosing the heaviest edge. This is called heaviest edge matching. Sorting is an additional cost for this approach, it is often applied in the later stages of the coarsening process.

# 2. Partitioning the Coars Graph: Once the graph is small enough, it is simple to apply any partitioning on the coarsened graph. One may try several methods or the same randomized method several times. Some of the popular choices include-graph clustering, spectral clustering or simple Kernigh-Lin algorithm with random starting partitions. Note that since the size of the graph is small, it is feasible to apply a slow method like spectral clustering to get high quality output [105].

# 3. Uncoarsening and Projecting Up: In this step the coarsened graph is used to initialize partitions on finer (bigger) graph. This is called “coarsening up”. Since each vertex in finer graph can be traced to a vertex in the coarsened graph, assigning the vertices of finer graph to appropriate partitions is simple once we have the partition on the coarsened graph. The finer connectivity by uncoarsening is used to refine the partition. This is done using local search, or some variants of Kernighan-Lin algorithm (Metis [86]) or weighted k-means (Graculus [42]) [131, 105]. This step is continued until the original graph has been reached.

Metis [86] supports different matching schemes for the coarsening step including RM and HEM. For partitioning the coarsened graph, Metis implements four schemes: based on graph heuristics and on spectral bisection. During the uncoarsening process, Metis uses the K/L algorithm [57] as a partition refinement. Since K/L can take many iterations before converging, Metis implements Greedy Refinement (GR) which performs only a single iteration and a Boundary Kernighan-Lin Refinement (BKLR) that allows only swapping vertices that are along the boundary of the bisection. Detailed discussion about Metis can be found in [86].

Graculus [42] generalizes the coarsening process of Metis to a max-cut coarsening to make it effective for a wider range of objectives. The three class approaches are explored—the extremely efficient region-grouping algorithm of Metis [86], the spectral clustering, and the bisection method. In the refinement step, Graculus uses weighted k-means. A more detailed discussion about the algorithm can be found in [42].
