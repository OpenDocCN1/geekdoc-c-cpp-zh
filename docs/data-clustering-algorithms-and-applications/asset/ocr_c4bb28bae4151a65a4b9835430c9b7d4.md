# 17.6 Graph Growing and Greedy Algorithms

One idea for graph partitioning is to select a starting vertex and keeping adding vertices to it, based on some criteria, until the partition is of the desired size. These algorithms are often classified as “greedy” and “graph-growing” algorithms [51]. In “greedy” (e.g., [30]) the next vertex is chosen, one that appears to be the “best” in some sense (e.g., minimum increment in cut-size). In “graph-growing” algorithms, on the other hand, the resultant subgraphs are growing a certain order (e.g., breadth-first).
