# 14.3.2 Video Event Detection

Video clustering algorithms have also been applied in the analysis and detection of abnormal or suspicious events in many surveillance applications. This allows for automatically providing early alerts to the human operators around any potentially harmful actions or social events. The basic assumption here is that the normal events are usually similar to each other. On the contrary, the abnormal events are usually quite distinct from the normal events, and thus, will not be part of a cluster. That by clustering the video segments, the events clustered into dominant are more likely to be the normal ones, while the others far away from the clustered patterns are probably the abnormal.

[7] proposes an abnormal event detection system of such a paradigm. This system contains two components in an event detection pipeline. In the first step, all the videos in the training set are clustered by the Dynamic Hierarchical Clustering (DHC) algorithm. To cluster these video sequences, a set of Hidden Markov Models (HMMs) is constructed to represent the video sequences, and the video sequences with similar HMMs are hierarchically merged. To compare the similarity between HMMs in DHC, the authors proposed to use the difference of BIC (Bayesian Information Criterion) between the models before and after the merge of video sequences:

```
d(i, j...) = BIC(i, j...) - BIC(i, j...) (14.24)
```

where BIC(i, j...) is the BIC value after video sequences i and j are merged to fit into HMM, and BIC(i, j...) is the BIC value before these two video sequences are merged.
A large value of BIC difference i(i, j...) means the HMMs are more similar to each other. This similarity can be used to compare the similarity between any number of models, rather than only pairwise similarity. To reduce the overfitting problem of model fitting with few samples, the clustering results are updated at each merging step, and a new HMM is trained after all video sequences are merged and reclassified to their corresponding clusters. This will alleviate the overfitting problem and wisely classify the poorly clustered videos. In addition, a 2-depth search strategy is proposed within DHC where 3 clusters can merge to form a new cluster rather than only pair of clusters each time as a 1-depth search strategy. This will accelerate the hierarchical clustering process with levels of clustering trees. The authors developed a set of exclusion rules to stop the merging of cluster triplets. These exclusion rules can be efficiently tested as they involve computing only pair-wise model similarity.

With the obtained clustering results and corresponding models for each cluster, a mixture model of the cluster HMMs is developed to explain each video sequence in the corpus follows:

```
P(i) = sum_{c=1} π_c * L_ic (14.25)
```

where P(i) is the probability that a video sequence i is generated by this mixture model, πc is the mixing coefficient, and L_ic is the likelihood of the ith video sequence being generated by the HMM for the cth cluster.
