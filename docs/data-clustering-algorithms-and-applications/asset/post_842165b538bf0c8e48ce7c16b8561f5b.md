UMicro algorithm works using an iterative approach which maintains a number of microcentroids around which the clusters are built. It assume that one of the inputs to the algorithm is $n_{micro}$ which is the number of microclusters to be constructed. The algorithm starts with a number of null clusters and initially creates new singleton clusters, to which new points are subsequently added. For any incoming data point, the closest cluster centroid is determined by the expected distance of the data point to the uncertain microclusters. The process of expected distance computation for the closest centroid is tricky and will be subsequently discussed. Furthermore, for the incoming point, it is determined whether it lies within a critical uncertainty boundary of the microcluster, otherwise the data point is added to the microcluster. To create a new microcluster, either it must be added to the current set of microclusters or it needs to replace one of the existing clusters of the algorithm, the current number of microclusters is less than $n_{micro}$. If this is the case, the new data point is added to the current set of microclusters as a separate microcluster with a singleton point in. Otherwise, the data point replaces one of the older microclusters. For this purpose, we replace the least recently updated microcluster from the set. This information is available from the temporal timestamp in the different microclusters. The overall framework for the uncertain stream clustering is illustrated in Figure 18.3. Algorithm UMicro(Number of Clusters: n_micro)
begin
 S = {};
 { Set of micro-clusters }
repeat
  Receive the next stream point X;
  { Initially, when S is null, the computations below
    cannot be performed, and X is simply
    added as a singleton micro-cluster to S }
  Compute the expected similarity of X to the closest
    micro-cluster M in S;
  Compute critical uncertainty boundary of M;
  if X lies inside uncertainty boundary
    add X to statistics of M
  else
    add a new micro-cluster to S containing singleton
    point X;
  if |S| = n_micro + 1 then remove the least recently
    updated micro-cluster from S;

In order to compute the expected similarity of the data point $\overline{X}$ to the centroid of the cluster $C$, we need to determine a closed form expression which is expressed in terms of $\overline{X}$ and $ECF(C)$. We note that the individual data points are essential variables with a given error, the centroid $Z$ of a cluster $C$ is also a random variable. We make the following observation about the centroid of a cluster:

**Lemma 18.5.1** *Let $Z$ be the random variable representing the centroid of cluster $C$. Then, the following result holds true:*

```
$E[\|Z\|^2] = \sum_{j=1}^{d} CF1(C)_j/n(C)^2 + \sum_{j=1}^{d} EF2(C)_j/n(C)^2 \quad (18.5)$
```

**Proof:** We note that the random variable $Z_j$ is given by the instantiation of the centroid and the mean of $n(C)$ different errors for the points in cluster $C$. Therefore we have

```
$Z_j = CF1(C)_j/n(C) + \sum_{X \in C} e_j(\overline{X})/n(C) \quad (18.6)$
```

Then, squaring $Z_j$ and taking the expected value, we obtain the following:

```
$E[\overline{Z_j}^2] = CF1(C)_j/n(C)^2 + 2 \cdot \sum_{X \in C} E[e_j(\overline{X})] \cdot CF1(C)_j/n(C)^2 + \sum_{X \in C} E[e_j(\overline{X})^2]/n(C)^2 \quad (18.7)$
```

Now, we note that the error is a random variable with standard deviation $\psi_j(\cdot)$ and zero mean. Therefore, $E[e_j] = 0$. Since it is assumed that the random variables representing errors of differences are independent of one another, we have $E[e_j(\overline{X}) \cdot e_j(\overline{Y})] = E[e_j(\overline{X})] \cdot E[e_j(\overline{Y})] = 0$. By using these relationships in the expansion of the above equation, we get

```
$E[\overline{Z_j}^2] = CF1(C)_j/n(C)^2 + \sum_{X \in C} E[e_j(\overline{X})^2]/n(C)^2 + \sum_{X \in C} \psi_j(\overline{X})^2/n(C)^2 \nn = CF1(C)_j/n(C)^2 + EF2(C)_j/n(C)^2
```

By adding the value over $j$, we get

```
$E[\|Z\|^2] = \sum_{j=1}^{d} CF1(C)_j/n(C)^2 + \sum_{j=1}^{d} EF2(C)_j/n(C)^2 \quad (18.8)$
```

This proves the desired result. Next, we will use the above result to directly estimate the distance between the cluster $C$ and the data point $\overline{X}$. We will prove the following:

**Lemma 18.5.2** *Let $v$ denote the expected value of the square of the distance between the uncertain data point $\overline{X} = (x_1 ...x_d)$ (with instantiation $X$) and the point $(\psi_1...\psi_d)$ and the centroid of cluster $C$. Then $v$ is given by the following:*

```
$v = \sum_{j=1}^{d} CF1(C)_j/n(C)^2 + \sum_{j=1}^{d} EF2(C)_j/n(C)^2 + \sum_{j=1}^{d} x_j^2 + \sum_{j=1}^{d} (\psi_j(\overline{X}))^2 - 2 \sum_{j=1}^{d} x_j \cdot CF1(C)_j/n(C) \quad (18.9)$
```

Proof: Let $Z$ represent the center of cluster $C$. Then, we have

```
$v = E[|\bar{X}-Z|^2] = E[|\bar{X}|^2] + E[|Z|^2] - 2E[\bar{X} \cdot Z] = E[|\bar{X}|^2] + E[|Z|^2] - 2E[\bar{X} \cdot Z]$
```

Next, we analyze the individual terms in the expression. We note that the value of $X$ is a random variable whose expected value is equal to its instantiation, and it has the error $j$th dimension equal to $\psi_j(\bar{X})$. Therefore, the expected value of $E[|\bar{X}|^2]$ is given by

```
$E[|\bar{X}|^2] = (E[X])^2 + \sum_{j=1}^d (\psi_j(\bar{X}))^2 = \sum_{j=1}^d x_j^2 + \sum_{j=1}^d(\psi_j(\bar{X}))^2$
```

Now, the value of $E[Z]$ is equal to the $j$th dimension of the cluster $C$. This is given by the expression $CF1(C)_j/n(C)$, where $CF1(C)$ is the $j$th of the first order cluster component. Therefore, the value of $E[X \cdot Z]$ is given by the following expression:

```
$E[X] \cdot E[Z] = \sum_{j=1}^d x_j \cdot CF1(C)_j/n(C) \quad (18.10)$
```

The results above and Lemma 18.5.1 define the values of $E[|\bar{X}|^2]$, $E[|Z|^2]$, and $E[X \cdot Z]$. Note that all of these values occur in the right-hand of the following relation:

```
$v = E[|\bar{X}|^2] + E[|Z|^2] - 2E[\bar{X} \cdot Z] \quad (18.11)$
```

By substituting the corresponding values in the right-hand side of the above relation, we get

```
$v = \sum_{j=1}^d CF1(C)_j/n(C)^2 + \sum_{j=1}^d EF2(C)_j/n(C)^2 + \sum_{j=1}^d x_j^2 + \sum_{j=1}^d(\psi_j(\bar{X}))^2 - 2\sum_{j=1}^d x_j \cdot CF1(C)_j/n(C) \quad (18.12)$
```

The result follows. The result of Lemma 18.5.2 establishes how the distance may be computed (in expected) using the error information in the data point $\bar{X}$ and the microcluster statistics of $C$. Note that this is an efficient computation which has $O(d)$ operations, which is asymptotically the same as the deterministic case. Since the distance function is the most repetitive of all operations in the clustering algorithm, and we would want it to be as efficient as possible.

While the expected distances can be directly used as a distance function, the uncertainty adds as lot noise as possible in order to determine the most accurate clusters. We design a dimension-counting similarity function which prunes the uncertain dimensions during the similarity calculations. This is done by computing the variance $\sigma_j^2$ along each dimension $j$. The computation of the variance can be done using the cluster feature statistics of the microclusters. The cluster feature statistics of all microclusters are added to create one global cluster feature. The variance of the data points along each dimension can be computed by this vector using the method described in [56]. For each dimension $j$ and threshold $thres$, we define the similarity value $\max\{1-E[|X-Z|\}$ to the computation. We note that this is a similarity value rather than a distance, since larger values imply greater similarity. Furthermore, dimensions that have a large amount of uncertainty are also likely to have greater values of $E[|X-Z|^2]$ and are often pruned from the computation.
