# 20.2.4 Semisupervised Clustering Based on User Feedback

A set of ideas for SSC has been pursued by [18], where the semisupervision is done in the loop. The development acknowledges the fact that there are multiple ways semisupervision can be provided and advocates updating the clustering on input received from the user. [18] consider a scenario where a user is iteratively providing feedback about the quality of clusters. Based on the divergence measure $d$ is defined up front and produce a clustering. Based on the user's feedback on the initial clustering, the method attempts to adjust what it to be similar. In other words the divergence measure of this is not fixed, but rather learned as the user provides feedback. It is innovative to note that such ideas in [18] were also considered by others as [4], as discussed in Section 20.2.2, but [18] explicitly consider the user to be a part of the process.

The problem of interest in [18] is the clustering of documents. Once an initial clustering has been done, the user can provide the following types of feedback: (i) an indication that a document is in the wrong cluster; (ii) given more appropriate cluster, an indication that the document should be moved to; (iii) whether two documents should be within the same cluster; Indeed, the type of feedback is closely related to pointwise and semisupervision discussed earlier.

The user is assumed to have know how many clusters there are really. After the feedback is incorporated into the distance measure, the clustering algorithm is run. These steps are repeated as long as user feedback is available or until convergence. In practice, only few iterations of user feedback are considered.

Following a bag of words, a document $d$ is assumed to be generated from a multinomial mixture model $	heta$ over words $w$. Words are defined by a vocabulary V. Within this probabilistic setting, KL divergence is selected as a natural choice of distance measure to be used in clustering. In order to adjust based on user feedback the authors proposed a version of KL divergence:

```
$d_A(d_1||d_2) = \sum_{w\in V} a_w p(w|j_1) \log \frac{p(w|j_1)}{p(w|j_2)}$
```

where $a_i$ are constrained to be positive. The divergence in [18] is fact a symmetrized version of the parametrized KL-divergence where one computes the weighted average KL-divergence of individual document frequencies to a discrete distribution with the word frequencies of the documents, and the weighting is determined by the number of words in each document. User feedback is provided for a pair of documents, $d_A$ is optimized by suitably updating $a_j$. The iterative updates are similar to the ideas discussed in Section 20.2.2 based on a parametrized KL-divergence.

In terms of unsupervised clustering, the approach appears to provide clear boost in performance when compared to unsupervised clustering. In particular, it seems that the algorithms perform well even with little feedback. Approaches as the one proposed in [18] are referred to as metric-based, since they incorporate semisupervision only by adapting a distance metric. Several approaches have been proposed in literature with different distance measures as [28, 10, 42].

The algorithm proposed in [28] is a variant of the complete-link hierarchical agglomerative clustering, where the Euclidean distance is altered according to user feedback. For pairs of points which are considered-link, a distance of zero is used. For pairs of points which have-link constraints associated with them, the maximum distance plus one is used. The motivation behind the approach is to combine pairwise constraints with spatial constraints, so that local neighborhoods are avoided by the pairwise constraints. As a result performance is improved compared to using pairwise constraints alone. Furthermore, outliers in the output are reduced since spatial penalties are taken into consideration.
