

## 聚类分类数据

## 12.3.2 概率度量

概率方法考虑了属性值之间匹配发生的概率。以下度量是概率性的：

Goodall：该度量对不频繁值的匹配赋予更高的相似度，而频繁值的匹配则赋予较低的相似度。该相似度度量本质上考虑了从数据集中随机抽取两个点样本中会观察到该相似度值的概率。最大相似度在匹配值 $X_k$ 出现两次且所有其他可能的 $A_k$ 出现超过两次时取得。最小相似度在属性 $A_k$ 只有一个值时取得。Goodall 的相似度公式为

```
$S_k(X_k, Y_k) = 1 - \sum_{q \in Q} p_k(q) \text{ if } X_k = Y_k, \text{ otherwise.}$
```

原始 Goodall 相似度结合了属性之间的相似度；在多元分类数据中，通过考虑属性之间的依赖关系；然而，该过程计算成本高昂，Boriah 等人提出了 4 种采样变体 [36, 22]。

Smirnov：Smirnov 度量是一种概率度量，考虑匹配和不匹配。该度量同时考虑了值频率以及同一属性所取其他值的分布。匹配的相似度更高，如果匹配值不频繁；而其他值频繁出现；最大相似度在匹配值 $X_k$ 出现两次且 $A_k$ 只有一个其他值，出现 $N-2$ 次时取得。匹配值的最小相似度在 $X_k$ 是 $A_k$ 的唯一值，出现 $N$ 次时取得。对于不匹配，最大相似度在 $X_k$ 和 $Y_k$ 各出现一次且 $A_k$ 只有一个值出现 $N-2$ 次时取得。对于不匹配，最小相似度在 $X_k, Y_k$ 是 $A_k$ 的仅有的两个值时取得。

Aberg：该相似度度量也考虑了匹配和不匹配。在这种方法中，罕见值的匹配表示强相似性，而罕见值的不匹配应区别对待并表示较低的相似性。它对罕见值的匹配赋予更高的相似度，对频繁值的匹配赋予较低的相似度。对于不匹配，它降低了罕见值不匹配的相似度（降低频繁值不匹配的相似度）[6]。

## 12.3.3 信息论度量

信息论方法结合了特定属性值相对于数据集的信息含量。这些度量受信息论启发，其中很少观察到的属性值更具信息性。以下度量是信息论的：

Burnaby：该度量对频繁值的不匹配赋予更高的相似度，对罕见值的不匹配赋予较低的相似度。对于不匹配，$S_k(X_k, Y_k)$ 的范围为 $log(1-freq)/log(N-T)$ [1]。对于匹配值，该相似度返回 $S_k(X_k, Y_k) = 1$。该公式在属性 $A_k$ 的所有值都不频繁（仅出现一次）时返回最小相似度，在 $X_k, Y_k$ 频繁（出现 $N/2$ 次）时返回最大值 [25]。

Lin：该度量对频繁值的匹配赋予更高的相似度，对不频繁值的不匹配赋予较低的相似度。基本 Lin 相似度公式为 [58]：

```
$S_k(X_k, Y_k) = 2 log(p_k(X_k)) \text{ if } X_k = Y_k, \ 2log(p_k(X_k) + p_k(Y_k))$ otherwise.
```

## 12.3.4 基于上下文的相似度度量

基于上下文的度量通过检查对象出现的上下文来评估两个对象之间的相似度。例如，基于上下文的度量可能会评估两个软饮料客户之间的距离，其中一个是可乐客户，另一个是百事可乐客户。因此，问题就变成了如何定义 m 空间中布尔或分类属性向量的距离，该空间对应于可乐和百事可乐客户。

Das 和 Manila 提出的基于上下文的度量采用迭代方法 [26]。给定数据集中所有 m 个属性对之间的距离，该方法迭代计算子关系（例如可乐和百事可乐客户）之间的距离，然后计算所有属性之间的距离。经过多次迭代后，会产生所有属性对之间稳定的距离集。

该相似度度量的概述如下。我们有一个由 $m$ 个属性组成的集合 $R$。设 $r$ 是 $R$ 上的布尔 $0/1$ 关系。最初，$R$ 中属性 $A, B$ 之间的距离被赋予随机值。然后计算子关系中心。对于每个 $t \in R$，所有与 $t$ 相似（根据某个标准）的属性 $A_1 \dots A_t$ 用于计算由 $t$ 与 $A_t$ 之间所有成对距离组成的向量 $f(t)$。然后，每个属性 $A \in R$ 的子关系是向量 $c_A$，由上一步中 $t$ 和 $A$ 相似的所有向量 $f(t)$ 的平均值定义。接下来，对于 $R$ 中每对属性 $A, B$，距离通过计算子关系中心 $c_A$ 和 $c_B$ 之间的距离来定义。该迭代重复进行，直到 $R$ 中 $A, B$ 之间的距离收敛。给定属性后，很容易计算对象距离和子关系距离。

## 12.4 算法描述

在本节中，提供了分类数据聚类算法的关键类别的描述。

## 12.4.1 基于划分的聚类

在划分方法中，对象被划分并且可能根据 dis 改变簇。划分方法对于生物信息学应用很有用，在这些应用中需要固定数量的簇，例如小型基因表达数据集 [24]。一个缺点是用户通常将簇的数量指定为输入参数。

### 12.4.1.1 k-Modes

k-Modes 算法用分配到该节点下的对象的属性值频率的摘要来表示一个簇。迭代地，将对象分配到簇并重新评估摘要。通常，算法在有限（少量）次迭代后收敛。簇的数量由用户指定。

k-Modes 算法是对分类数据的 k-Means 的改编。K-Modes 去除了 k-Means 算法的仅数值限制，但保持了其在聚类大型分类数据集时的效率。K-Modes 做了以下修改：1) 它使用分类对象的相异度度量；2) 它用众数代替簇的均值；3) 它使用基于频率的方法进行运行时、优点和缺点与 k-Means [47]。Hamming 距离可用于查找对象的最近簇众数。

一个簇用于将未分配的对象分配到最近的簇。设 $X = \{X_1, X_2, \dots, X_n\}$ 是由分类属性 $A_1, A_2, \dots, A_m$ 描述的 $n$ 个分类对象的集合。$X$ 的众数是向量 $Q = [q_1, q_2, \dots, q_m]$，它最小化

```
D(X,Q) = \sum_{i=1}^{n} d_i(X_i,Q)
```

其中 $d_i$ 是距离函数，例如 Hamming 距离。然后证明函数 $D(X,Q)$ 当且仅当众数 $Q$ 的每个位置 $j$ 包含 $A_j$ 中出现最频繁的值时最小化，使得 $fr(A_j = q_j) \geq fr(A_j = c_{i,j})$ 对所有 $c_{i,j}$ 对所有 $j=1, \dots, m$ 成立。请注意，众数 $Q$ 不一定是 $X$ 的元素。

簇 $c$ 的众数是向量 $\mu_c = [\mu_{c,1}, \dots, \mu_{c,m}]$，其中 $\mu_{c,j}$ 是 $c$ 中第 $j$ 个属性的最频繁值。$c$ 的众数是通过将 $\mu_j$ 设置为 $c$ 中第 $j$ 个类别的最频繁值来确定的。为了找到众数，设 $n_{ij}$ 为具有属性 $A_j$ 中第 $j$ 个值 $c_{i,j}$ 的对象的数量且 $fr(A_j = c_{i,j}) = n_{i,j}/n$ 为 $c_{i,j}$ 在 $X$ 中的相对频率。

基本算法根据成本函数 $P(X,Q) = \sum_{i=1}^{n} \sum_{j=1}^{m} \delta(X_{i,j}, q_j)$ 评估整个数据集上的成本，每次在 $k$ 个簇、$n$ 个对象和 $m$ 个分类属性上获得众数时。为了使计算高效，实践中可以使用高效算法：

- 1. 选择初始众数，每个簇一个。
- 2. 根据距离度量将每个对象分配到具有最近众数的簇。对象分配后更新簇的众数。
- 3. 所有对象分配到簇后，重置对象相对于当前众数的相异度。如果发现某个对象的最近众数属于另一个簇而不是其所在簇，则将其重新分配到该簇并更新两个簇的众数。
- 4. 重复直到没有对象改变簇。

在 k-Modes 算法的原始实现中描述了两种方法。第一种也是最简单的方法从数据集中选择 $k$ 个不同的记录作为 The 第二种方法选择所有分类属性的所有值的频率并按频率降序存储在数组中；然后它将最频繁的值分配给初始 $k$ 个众数。

k-Modes 的主要缺点是（与 k-Means 算法一样）它执行局部解，这些解严重依赖于初始众数和数据集中对象的顺序。

### 12.4.1.2 k-Prototypes（混合分类和数值）

k-Prototypes 是 k-Modes 的扩展，可处理混合类型对象，整合了 k-Means 和 k-Modes 算法。k-Prototypes 算法特别有用，因为现实世界数据库中经常遇到的对象是混合类型的；k-Prototypes 使用一种距离度量，该度量权衡数值与分类属性的贡献。像 k-Means 和 k-Modes 算法一样，

k-Prototypes 在对象变化很少时迭代结束。

两个混合类型对象 X 和 Y 之间的相异度，它们由 $p$ 个数值和 $m-p$ 个分类属性 $A'_1, \dots, A'_p, A'_{p+1}, \dots, A'_m$ 描述，可以通过以下方式度量

```
d_2(X,Y) = \sum_{j=1}^{p} (x_j - y_j)^2 + \gamma \sum_{j=p+1}^{m} \delta(x_j, y_j)
```
