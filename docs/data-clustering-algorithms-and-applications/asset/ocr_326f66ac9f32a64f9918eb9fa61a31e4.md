The symmetry property treats the predefined class structure as one of the partitions. Therefore, the task of cluster validation is same as the comparison of partitions. This means transposing two partitions in the contingency matrix should not change anything than the measure value. The property is not true for $F_n$, which is a typical measure in asymmetry. Also, $\epsilon_n$ is symmetric if only $K=K'$.

Intuitively, a mathematically sound measure should satisfy the $n$-invariant property. However, several measures, $R_n$, $FM_n$, and $\Gamma_n$ cannot fulfill this requirement. Nevertheless, they can be treated as the asymptotically $n$-invariant measures, since they need to be n-invariant with the increase of $n$.

**Property 20.2.3 (Convex additivity)** Let $P=\{P_1, ..., P_k\}$ be a clustering, $P'$ be a refinement of $P$, and $P'_i$ be the partitioning induced by $P'$. Then a measure $O$ is convex additive, if $O(M(P, P')) = \sum_{i=1}^k O(I_P, P'_i)$, where $n$ is the number of data points in $P_i$, $I_P$ represents the partitioning on $P_i$ into one cluster, and $M(X, Y)$ is the contingency matrix of X and Y.

The convexity property was introduced by Meila [42]. It requires the measures to show additivity along the lattice of partitions. Unnormalized measures including $F, VD, VI$, and $\epsilon$ hold this property. None of the normalized measures studied in this chapter holds this property.

**Property 20.2.4 (Left-domain-completeness)** A measure $O$ is left-domain-complete, if for any contingency matrix $M$ with statistically independent rows and columns,

```
$O(M) = \begin{cases} 0, & O \text{ is a positive measure} \ 1, & O \text{ is a negative measure} \end{cases}$
```

When the rows and columns in the contingency matrix are statistically independent, the poorest values of the measures are expected to be seen, i.e., 0 for positive measures and 1 for negative measures. Among all the measures, however, only $VI_n$ and $VD_n$ can meet this requirement.

**Property 20.2.5 (Right-domain-completeness)** A measure $O$ is right-domain-complete, if for any contingency matrix $M$ with perfectly matched rows and columns,

```
$O(M) = \begin{cases} 1, & O \text{ is a positive measure} \ 0, & O \text{ is a negative measure} \end{cases}$
```

This property requires measures to show optimal values when the cluster structure matches the cluster structure perfectly. The above normalized measures holds this property.

1-$P'$ is a refinement of $P$ $P'$ is the descendant of node $P$ in the lattice of partitions. [42] for details.
