### 13.1 引言

Web 上和私有系统中的文档激增，使得文档集合中的知识发现变得困难。聚类长期以来被认为是在该任务中有用的工具。它将项目聚在一起，最大化簇内相似性和簇间距离。聚类可以提供对文档集合构成的洞察，并且通常用作数据分析的初始步骤。
虽然文档聚类研究一直关注中等长度的单篇文档，但现实生活中的集合由非常短或长的文档组成。短文档不包含足够文本来准确计算相似性。文档跨越多个主题，而通用文档相似性度量并未考虑这些情况。在本章中，我们将首先概述通用目的文档聚类，然后重点介绍文档聚类下一个前沿的最新进展：长文档和短文档。

### 13.2 建模文档

与传统聚类任务不同，文档聚类面临若干挑战。语料库相对于词语而言是高维的，文档是稀疏的，长度不一，并且可能包含相关术语 [2]。找到文档模型，即可用于区分文档的一组特征，是聚类任务的关键。聚类算法和用于计算文档间相似性的度量在很大程度上取决于所选模型。

### 13.2.1 预备知识

对于文档聚类问题，我们给定一组文档，或文本，$\mathcal{V}=\{w_1,\dots,w_M\}$ 表示 $\mathcal{D}$ 的词汇表。每个文档 $d\in\mathcal{D}$ 是 $n_d$ 个词的序列。我们用 $d$ 表示文档 $d$ 的词向量。有时，我们可将 $d$ 视为由不重叠的文本块组成，称为段落，由句子和词组成。段落集合 $S$ 称为段落集。我们用文档 $d$ 的段落集和 $S=\{U_{d_i}D_i\}$ 表示为 $C=\{C_1,\dots,C_K\}$ 的聚类。表 13.1 列出了本章中使用的名称。
概率生成算法（参见第 13.3.4 节）学习一个较低维度的（潜在）特征空间，可容纳隐藏文档（无监督类变量）和词出现（观测数据）。以下记号适用于所有类别的文档。文档表示为词的序列（而非集合），$d=(w_1,\dots,w_{n_d})$。文档中的词表示为单位向量，其中 $w$ 是大小为 $M$ 的向量，且 $w^i=1$ 且对所有 $i\neq j$ 的指标 $w^j=0$。如果文档被分段，则段落也视为词的序列。然而，文档可以是序列或段落集合。每个 $z\in\mathcal{Z}=\{z_1,\dots,z_K\}$，潜在主题，是词汇表上的分布。主题比例，例如 $\alpha$ 和 $\theta$，是文档或段落中从每个主题抽取的百分比的分布。主题分配 $z$ 和 $y$ 表示为选择词或文档时所选的主题。
