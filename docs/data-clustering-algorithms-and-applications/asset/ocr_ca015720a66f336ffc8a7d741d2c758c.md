# **Algorithm 12** The General EM Algorithm

Given a statistical model consisting of a set of observed variables X, a set of unobserved latent variables Z, and a vector of unknown parameters Θ, the goal is to maximize the log-likelihood with respect to the parameters $\Theta$.

+   1: Start with an initial guess for the parameters $\Theta^{(0)}$ and compute the initial log-likelihood $\log p(\Theta^{(0)})$.n2: **E-step**: Evaluate $q^{(t)} = \arg\max q L(q, \Theta^{(t)}) = p(z|X_n, \Theta^{(t)})$.n3: **M-step**: Update the parameters $\Theta^{(t+1)} = \arg\max Q(\Theta, \Theta^{(t)})$.n4: Compute the log-likelihood $\log p(\Theta^{(t+1)})$ and check for convergence of the algorithm. If the convergence criterion is not satisfied, repeat steps 2–4, otherwise return the final parameters.

The above quantity that is being maximized is the expectation of the complete data log-likelihood. The convergence properties of the EM algorithm are discussed in [22] and [46]. It is clear that each EM cycle can increase the lower bound on the log-likelihood and will not change the model parameters in such a way as to increase the actual log-likelihood, which is guaranteed to reach a local maximum of the log-likelihood function. **Maximum A Poster Estimation**: The EM algorithm can be used to find MAP maps for models where a prior $p(\Theta)$ over the parameters is introduced. We note that as a function of $\Theta$, $p(\Theta|X) = \frac{p(X|\Theta)p(\Theta)}{p(X)}$, based on Bayes' theorem. By making the decomposition of (3.21), we have

```
$$\log p(\Theta) = \log p(X|\Theta) + \log p(\Theta) - \log p(X)\n\geq L(q, \Theta) + \log p(\Theta) - \log p(X), \quad (3.27)$
```

where $\log p(X)$ is a constant. We can maximize the right-hand side alternatively with respect to $q$ and $\Theta$. In the E-step the remainder is same as in maximum likelihood case as $q$ only appears in $L(q, \Theta)$, whereas in the M-step the quantity to be maximized is given by $L(q, \Theta) + \log p(\Theta)$, which typically requires only a small modification to the standard likelihood algorithm M-step.
