
## 16.3.2.5 Ensemble Clustering

An ensemble clustering approach employs different clustering methods on the PPI network data and combines the clustering results of all these methods (the base clustering algorithms) into a single comprehensive clustering result of the PPI networks [8]. The three base clustering algorithms were used in this work.

- (i) Repeated bisection [100]: This method starts with the complete dataset as one cluster. Then the following steps is repeated until the desired number of clusters is obtained: (1) select a cluster to bisect into two clusters and (2) compute the similarity score for each cluster. This algorithm optimizes the $l_2$ criterion as follows:

```
$l2 = \max \sum_{i=1}^{k} \sum_{u,v \in C_i} S(u,v)$
```

where $k$ is the number of clusters, $C_i$ is the set of objects in cluster $i$ and $S(u,v)$ is the similarity between the two objects $u$ and $v$.

- (ii) Direct k-way partitioning [59]: This method works as follows: (1) select a set of $k$ objects (seeds), and (2) assign each object to the most similar cluster. This procedure is repeated to optimize the $l_2$ criterion.

- (iii) Multilevel k-way partitioning [59]: This algorithm has three stages: coarsening, partitioning, and refinement. In the coarsening step, k-way partitioning is used to cluster the graph into a set of smaller graphs. In the second step, the clusters are projected back onto the original graph by iterating over intermediate partitions. The refinement step reduces the edge-cut while maintaining the balance constraints.

The clustering results of the above mentioned base clustering methods are combined by applying the following phases:

1. Cluster purification: The similarity between the objects within each cluster is computed, and the weak clusters are removed so that each protein is of at least one third of the remaining clusters. The result of this step is represented using a binary cluster membership matrix where each column is a cluster produced by the base clustering algorithms and each row is a protein.
2. Dimensionality reduction: A dimensionality reduction method, such as PCA, can be used to reduce the number of clusters in the cluster membership matrix. This will avoid the problem of dimensionality.
3. Consensus clustering: Two different clustering algorithms are applied: (i) the recursive bisection algorithm where the of the three base clustering algorithms is chosen and (ii) the agglomerative hierarchical clustering where the desired k-way clustering solution is computed using the agglomerative method.

Weighted clustering: This method considers the weight of the edges between proteins within each cluster [8]. In soft clustering, the same protein can belong to more than one cluster. The cluster membership can be computed as a function of the distance from the nodes in the cluster. The soft clustering solves the problem of multifunctional proteins. This ensemble method produced better results on yeast PPI networks compared to several other methods.

## 16.3.3 Cluster Validation and Challenges

Using different clustering methods, various results are obtained from a given PPI network. Hence, it is important to compare and evaluate the performance of these clustering algorithms. Being an unsupervised approach, it is often difficult to evaluate and compare the performance of various clustering algorithms used in the context of PPI network analysis. Validating the clusters is primarily done by calculating the p-values for the clusters [110]. Statistically significant p-values indicate that the proteins in the same clusters are involved in the same functions. The GO database provides the annotation of known molecular functions and biological processes [7]. To the evaluation of the clusters from the gene expression, a hypergeometric distribution is used to calculate the probability of having at least g genes from a cluster of size n genes by chance in a biological process containing f genes. Lower p-values indicate biological significance of the clusters.

If known clusters are provided, they can be used as a gold-standard to evaluate the performance of the clustering algorithm by comparing the predicted cluster to the known ones. Clustering the PPI data is still a challenging problem due to various reasons [110]. The false positive and negative interactions in the protein network make it difficult to evaluate the quality of the resulting clusters. Also, there is a need for clustering methods that allow overlapping between the clusters. To other applications, identifying the optimal number of clusters in the PPI data is a challenging task. In addition, the large amount of available data makes it computationally expensive to analyze the PPI networks.

## 16.4 Biological Sequence Clustering

Sequence sequencing is an essential task in biological data analysis, because the most important building blocks of living organisms, such as DNA, RNA, mRNA, polypeptides, and proteins, have a linear structure and can be represented as sequences. For DNA, RNA, mRNA, and mRNA, the sequences are made of nucleic acids, also called bases and polypeptides and proteins, the sequences are made of amino acids. Earlier studies on biological sequences were mostly limited to pairwise sequence alignment and multiple sequence alignment. However, in recent years, scientists are amassing an enormous amount of sequence data as a result of improvement on high-throughput sequencing. Similarity search in such a large sequence database using alignment algorithms is extremely costly. So, alignment-based similarity search is performed on a small cluster of highly similar sequences. Sequence clustering plays a significant role in finding small clusters.

## 16.4.1 Sequence Metrics

Many of the existing methods that we have discussed, such as graph-theoretic, Markov clustering can be used for clustering if a suitable metric is available. Specifically, for clustering biological data, we need a metric that represents the similarity between two sequences. Below, we discuss distance metrics that can be used for clustering.

### Algorithms and Applications

### 16.4.1.1 Alignment-Based Similarity

The most popular distance metric for sequence data is the Levenshtein distance, or edit distance. The number of edits needed to transform one string into the other with insertion, deletion, or substitution can be computed; for two sequences of length $l_1$ and $l_2$, the global alignment cost is $O(l_1l_2)$. This is costly considering that biological sequences (particularly DNA) are long. So, Levenshtein distance is not an ideal metric for clustering. Another limitation of this metric is that it captures the global alignment, whereas for clustering biological sequences, local similarity should be considered. Finally, the edit distance metric on the length of the sequence makes it a poor metric when the length of the sequences varies.

To capture the local similarity between two sequences, Smith-Waterman’s local alignment algorithm [46] can be used. Instead of aligning the entire sequence the local alignment algorithm compares segments of all possible lengths and optimizes the similarity measure. Though it overcomes some of the problems of global alignment, it is as costly as the global alignment algorithm and is simply impractical for clustering biological sequences.

During the eighties and nineties, two popular tools, known as FASTA [80] and BLAST, were developed to improve the scalability of similarity search from biological sequence database. Both tools take a query sequence and return a set of statistically similar sequences from a sequence database. The main benefit of these tools is that they are highly scalable, as they adopt smart heuristics for sacrificing the strict optimality. Also, specifically BLAST has various versions (such as PSI-BLAST, PHI-BLAST, BLAST-In) that are customized based on the kind of sequences and the scoring matrix used. For a set of sequences, FASTA and BLAST also return list of pairwise sequences. For a pair of similar sequences, BLAST also returns score (also known as BLAST-score) which represents the similarity strength that can be used for clustering.
