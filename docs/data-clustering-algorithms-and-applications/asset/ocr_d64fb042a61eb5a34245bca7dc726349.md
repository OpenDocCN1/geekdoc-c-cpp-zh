We note that many of the uncertain clustering techniques work with the assumption that the probability density function is available. In many real applications, a more realistic assumption is that only the standard deviations of the errors are available. This is because probability distributions are rarely available and are used only as a modeling assumption. Over ambitious modeling assumption can also introduce errors. It is often quite natural to estimate the standard error in many modeling scenarios. In a scientific application in which the measurements can vary from one to another, the error is the standard deviation of the observations over a large number of measurements. In a $k$-anonymity-based data (or incomplete data) data mining, this is the standard deviation of the partially specified (or imputed fields) data. This is also more practical from a stream perspective, because it reduces the volume of the incoming stream and reduces the complexity of stream computations.

The microclustering method was first proposed in [56] for large data sets subsequently adapted in [6] for the case of deterministic data streams. The $UMicro$ algorithm extends the microclustering approach of [6] to the case of uncertain data. In order to incorporate the uncertainty into the clustering process, we need a method to incorporate and leverage the error information into the microclustering statistics and algorithms. As discussed earlier, it is assumed that the data stream consists of a set of multidimensional records $X_1, ..., X_i$ arriving at times $T_1, ..., T_i$. Each $X_i$ is a uncertain record containing $d$ dimensions which are denoted by $EF(X_i) = \psi(	ilde{X}_i)$. In order to apply the microclustering method to the uncertain data mining problem, we also need to define the concept of error-microclusters. We define microclusters as follows:

**Definition 18.5.1** An uncertain microcluster for $d$-dimensional points $X_i, ..., X_j$ with times $T_i, ..., T_j$ and error values $\psi(	ilde{X}_i)$ is defined as $(d+2)$ tuple $(CF(C)$, $EF^2(C)$, $CF^1(C), t(C)$, $n(C))$, where $CF(C)$, $EF^2(C)$, and $CF^1(C)$ each correspond to a vector of $d$ entries. The entries in $EF^2(C)$ correspond to the error-based entries. The definition of each of these entries is as follows:

+   - For each dimension, the sum of squares of the data values is maintained in $CF(C)$. Thus, $EF^2(C)$ contains $d$ values. The ph entry of $EF^2(C)$ is equal to $\sum_{k=i}^j(x_k)^2$. This corresponds to the second moment of the data values over the ph dimension.
- For each dimension, the sum of squares of the errors in the data values is maintained in $EF^1(C)$. Thus, $EF(C)$ contains $d$ values. The ph entry of $EF(C)$ is equal to $\sum_{k=i}^j\psi_p(X_k)^2$. This corresponds to the sum of squares of the errors in the records along the ph dimension.
- For each dimension, the sum of the data values is maintained in $CF^1(C)$. Thus, $CF^1(C)$ contains $d$ values. The ph entry of $CF^1(C)$ is equal to $\sum_{k=i}^j x_k$. This corresponds to the first moment of the values over the ph dimension.
- The number of points in the data is maintained in $n(C)$.
- The timestamp of the last update to the microcluster is maintained in $t(C)$.

We note that the uncertain definition of microclusters differs from the deterministic definition, since we have added $d$ values corresponding to the error information in the records. We refer to the uncertain microcluster for a set of points $C$ by $ECF(C)$. We note that error-based microclusters maintain the important additive property [6] which is critical to use in the clustering process. We state the additive property as follows:

**Property 18.5.2** Let $C_1$ and $C_2$ be two sets of points. Then all nonempty components of the error-based cluster feature vector $ECF(C_1 \cup C_2)$ are given by the sum of $ECF(C1)$ and $ECF(C2)$.
