# A Survey of Stream Clustering Algorithms

# 10.2 Methods Based on Partitioning Representatives

A number of methods for clustering are based on partitioning representatives. These include methods such as the k-means and k-medians-based methods. In these techniques, the clusters are defined by a set of data points, which are drawn either from the data set or otherwise.
The cluster membership of the remaining points are defined by assigning them to their closest representative. In the classical literature, these representatives are iterative and require multiple passes over the data to estimate the representatives. However, in the stream scenario, multiple passes are not required because a sufficient amount of data is available for estimating the representatives efficiently in one pass of the data. In this section, we will first discuss the clustering methods, which are based on the partitioning methodology.

# 10.2.1 The STREAM Algorithm

The STREAM method [36, 53] is based on the k-medians clustering methodology. The core idea is to break the stream into chunks, each of which is of manageable size and fits into main memory. For the original stream $\mathcal{D}$, we divide it into chunks $\mathcal{D}_1, \dots, \mathcal{D}_n$, each which contains at most $m$ data points. The value of $m$ is defined by the choice of a predefined memory budget.
Since each chunk fits in main memory, a variety of more complex clustering algorithms are used for each chunk. In [36, 53] we use a variant of k-medians-style algorithms for this purpose. The choice of subroutine is crucial to the quality of the underlying algorithm, and will be discussed in detail. In k-medians we pick a set $S$ of representatives for each chunk $\mathcal{D}_i$, so that each point in $\mathcal{D}_i$ is assigned to its closest representatives. The goal is to pick the representatives in such a way, as to minimize the Sum of Squared Error (SSE) of the assigned data points from representatives. For a set of data points $X_1, \dots, X_m$ in $S$, and a set of $k$ representatives $Y = Y_1, \dots, Y_k$, the objective function is defined as follows:

```
$Objective(S, Y) = \sum_{X_i \in S, Y_j \in Y} dist(X_i, Y_j) \quad (10.1)$
```

The assignment is denoted by $\in$. The sum of squared distances between a point and records is defined by $dist(\cdot)$.
After the first chunk has been processed, we have a set of $k$ medians, which are stored. The number of points assigned to each representative is stored as level-1 representatives. The next chunk is independently processed to find its optimal median representatives. At the end of the second chunk, we will have $2-k$ representatives. The memory requirement for storing the representatives also increases with time, and after processing chunks when the number of representatives exceeds $m$, a second level of clustering is applied to this set of $r-k$ points, so that the stored points on the representatives are used in the clustering process. The resulting representatives are stored as level-2 representatives. In general, when the number of representatives of level-$p$ reaches $m$, they are converted to $k$ level$(p+1)$ representatives. Then, the process will result in increasing the number of representatives at all levels, though the number of representatives in higher levels will exponentially slower than the lower levels. At the end of processing the entire stream (or when a specific need for the clustering result arises), all remaining representatives of different levels are clustered together in one final application of the $k$-medians subroutine.
