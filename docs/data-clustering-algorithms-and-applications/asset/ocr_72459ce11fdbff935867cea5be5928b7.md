Note that the microcluster satisfies two properties: the additive property and the multiplicative property. The additive property is common to all microclustering techniques:

**Observation 18.6.2 Additive Property** $C_1$ and $C_2$ be two sets of points. Then the components of the error-based cluster feature vector (other than the timestamp) $EC(C_1 \cup C_2)$ are given by the sum of $EC(C_1)$ and $EC(C_2)$.

The additive property is helpful in streamlining applications, since the statistics for the microcluster can be modified by adding the statistics for the incoming data points to the microcluster statistics. however, the microclusters also include time-decay information of the underlying data points, which can potentially change at each timestamp. Therefore we need an effective way to update the microcluster without having to explicitly do so at timestamp. For this purpose, the multiplicative property is useful.

**Observation 18.6.3 Multiplicative Property** The decaying components of $EC(C)$ at time $t_i$ can be obtained from multiplying each component by $2^{-\lambda(t_i-t_0)}$ provided that no new points have been added to a microcluster.

The multiplicative property follows from the fact statistics at the multiplicative rate of $2^{-\lambda}$ at each tick. Note that the multiplicative property is essential in ensuring a lazy-update process can be used for decaying the microclusters, rather than at each clock-tick. In the lazy-update process, we do so first use the multiplicative property for time decay, and then we use the additive property to add the incoming point to the microcluster statistics.

The UPstream uses a continuous projection and projection strategy in which the different microclusters are streamed as a partial projection, and this projection is used to define the assignment of data points to clusters. The input to the algorithm is the number of microclusters $k$ which are to be determined by the algorithm. The algorithm starts with an empty set of clusters. The initial set of $k$ data points is assigned to singleton clusters in order to create the initial set of microclusters. This initial set of microcluster statistics provides a starting point which is rapidly modified by further updates to the microclusters. For each incoming data point, probabilistic measures are computed over the projected dimensions in order to determine the assignment of data points to clusters. These assignments are used to update the statistics of the underlying clusters. These updates are combined with a probabilistic approach for determining the expected distances and spread along the projected dimensions.
