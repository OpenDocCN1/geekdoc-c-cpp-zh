# Semisupervised Clustering

# 20.5.2.1 Constrained Semisupervised Embedding

Following [43], we want to obtain an embedding $f=[f_e, f_u]^T$, where the exact embeddings of the first $\ell$ points are known and given by $y_\ell$. The objective for semisupervised embedding is given by

```
$$\min f^T M f, \quad s.t \quad f_e = y_\ell$$
```

where $M$ is a suitable positive definite matrix. Since $f_e$ is fixed, the problem can be cast in terms of block matrices

```
$$\min \begin{bmatrix} f_e \ f_u \end{bmatrix}^T \begin{bmatrix} M_{ee} & M_{eu} \ M_{ue} & M_{uu} \end{bmatrix} \begin{bmatrix} f_e \ f_u \end{bmatrix}$$
```

Setting the first derivative to zero, one obtains

```
$f_u = -M_{uu}^{-1}M_{ue}$$
```

In the context of label propagation for a 2-clustering, we will have $y_i = +1$ or $y_i = -1$ for $i=1, \dots, \ell$. In other cases, the labeled points are embedded to their cluster label, and the rest will be embedded while maintaining the neighborhood. For LLE, $M=(I-W)^T(I-W)$ and we call the label propagation algorithm LLELP. For LTSA, M as discussed in Section 20.5.1, and the corresponding algorithm will be called LTSALP. For constrained LLE from 20.57, $M=L_u$, and the corresponding algorithm will be called LEL. For LEP, since $M=L_u$, the unnormalized Laplacian, from Equation 20.62 we have

```
$f_u = -L_{uu}^{-1}L_{ue}y_\ell = -(D_{uu}-W_{uu})^{-1}(D_{ue}-W_{ue})y_\ell$$
```

where $D_{ue}=0$ as $D$ is a diagonal matrix. Then that the solution is exactly the same as for GF in Equation 20.40 implying the equivalence of GF and LELP.

# 20.5.2.2 Constrained Semisupervised Embedding

In this section, we consider embedding problems when the orthogonality constraint of the form $f \perp AI$ is enforced. In particular, we consider the following problem:

```
$$\min f^T M f, \quad s.t \quad \sum(f_i-y_i)^2 \leq \varepsilon, \quad f \perp AI$$
```

where $A=I$ for LLE and LTSA, and $A=D^{1/2}$ for LE. Let $\alpha$ and $\mu$ be the Lagrange multipliers for the two constraints, respectively. The first order necessary conditions obtained from the Lagrangian corresponding to (20.63)

```
$f = (M+\alpha AI)^{-1}(\alpha y+\mu AI/2)$
```

Since $I^T A^T f=0$, a direct calculation gives the optimal Lagrange multiplier by

```
$$\mu = -2\alpha \frac{I^T A^T(M+\alpha AI)^{-1}y}{I^T A^T(M+\alpha AI)^{-1}AI^1}$
```

The multiplier $\alpha$ can also be computed using existing results solving quadratically constrained quadratic programs (QCPs) with a single quadratic constraint [14]. For LLE, $M=(I-W)^T(I-W)$ and $A=I$, and we call the corresponding algorithm LLEPC. For LTSA, $M$ is discussed in Section 20.5.1 and $A=I$, and we call the corresponding algorithm LTSALPC. For as in Equation 20.58, $M=L_{sym}=D^{-1/2}WD^{1/2}$ and we call the corresponding algorithm LEPLC.

> While the constraints can be relaxed to consider $\sum_{i=1}(f_i-y_i)^2 \leq \varepsilon$, we do not focus on the general case here.
