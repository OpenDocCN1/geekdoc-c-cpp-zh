# Data Clustering: Algorithms and Applications

All distributions are needed to define the mutual information I(C, C') between two clusterings:

```
$I(C, C') = \sum_{k=1}^{K} \sum_{k'=1}^{K'} P(k,k') \log \frac{P(k,k')}{P(k)P(k')} \quad (19.3)$
```

as well as for the definitions of the entropy of clusters:

```
$H(C) = -\sum_{k=1}^{K} P(k) \log P(k) \quad \ H(C') = -\sum_{k'=1}^{K'} P(k') \log P(k') \quad (19.4)$
```

Following [32], variational information between two clusterings is defined as

```
$VI(C, C') = H(C) + H(C') - 2I(C,C') \quad (19.5)$
```

Most important for computer-assisted clustering, variational information is a metric over the space of possible clusterings [32], which means it is always positive, zero if only the two clusterings are equal, symmetric, and obeys the triangle inequality. The derivation of variational information, proofs, and discussions of the properties as well as relations to clustering comparison measures can be found in [32].

Variational information is used to compute distances between all of the $M$ clusterings produced by the different algorithms with their different distance/similarity measures and parameters that were selected to represent the wisdom of the statistical community. The compiled distance matrix has $M \times M$ and defines a metric for clusters for the given data set. This is a discrete space where distances are defined only for those clusterings that are included in the wisdom of the statistical community. For purpose of visualization, the metric is embedded into the two-dimensional plane where distance is measured by Euclidean distance between points. Each of the two-dimensional planes $\{x_1, ...,x_M\}$ represents a cluster in this space. The embedding is computed using Samson's multidimensional scaling [16]. The two-dimensional plane is a continuous, [17] use an interpolation scheme that assigns clusters to the plane that do not contain one of the clusterings far.

The interpolation scheme takes a particular point $x$ of the two-dimensional plane as input. Then, all precomputed clusterings are weighed using kernel density estimation in the two-dimensional plane, where each of the two-dimensional point $\{x_m\}_{m=1}^M$ represent the $M$ clusterings. The kernels used in [17] are Gaussians $\mathcal{N}(x|x_m,\sigma^2)$. The weight of the $m^{th}$ clustering with respect to the particular point $x$ is the normalized kernel of the density to estimate at:

```
$W_m(x) = \frac{\mathcal{N}(x|x_m,\sigma^2)}{\sum_{m'=1}^M \mathcal{N}(x|x_{m'},\sigma^2)} \quad (19.6)$
```

The smoothing parameter $\sigma^2$ needs to be adjusted by the user. The $M$ weights together corresponding clusterings are used to construct a voting matrix $V$. The $m^{th}$ clustering $C_m$ is represented as an $N \times M$ matrix. A row in this matrix represents a data object to clusters. In case of hard cluster assignment, a row contains only a single entry and all others empty, and in case of soft cluster assignment, a row consists of nonnegative numbers that sum to one. The weighted clusterings are concatenated to the voting matrix $V = [wC_1,...,w C_M]$, which has dimensions $N \times M$. The voting matrix $V$ defines a similarity matrix $S = V^T V^T$, which in turn defines the interpolated clustering for the selected point $x$. It is argued in [17] that any clustering method can be used to compute the interpolated clustering to $x$ based on the similarity matrix $S$. The number of clusters is set to the weighted average of the neighboring clusterings. The interpolation scheme extends the discrete set of clusters to a larger set of clusterings, such that every point on the two-dimensional plane corresponds to a clustering. This two-dimensional plane is the space of clusters.
