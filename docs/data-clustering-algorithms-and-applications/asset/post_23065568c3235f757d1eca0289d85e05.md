## 14.3.2 Video Event Detection

Video clustering algorithms have also been applied in the analysis and detection of abnormal or suspicious events in many surveillance applications. This allows for automatically providing early alerts to the human operators around any potentially harmful actions or social events. The basic assumption here is that the normal events are usually similar to each other. On the contrary, the abnormal events are usually quite distinct from the normal events, and thus, will not be part of a cluster. That by clustering the video segments, the events clustered into dominant are more likely to be the normal ones, while the others far away from the clustered patterns are probably the abnormal.

[7] proposes an abnormal event detection system of such a paradigm. This system contains two components in an event detection pipeline. In the first step, all the videos in the training set are clustered by the Dynamic Hierarchical Clustering (DHC) algorithm. To cluster these video sequences, a set of Hidden Markov Models (HMMs) is constructed to represent the video sequences, and the video sequences with similar HMMs are hierarchically merged. To compare the similarity between HMMs in DHC, the authors proposed to use the difference of BIC (Bayesian Information Criterion) between the models before and after the merge of video sequences:

```
d(i, j...) = BIC(i, j...) - BIC(i, j...) (14.24)
```

where BIC(i, j...) is the BIC value after video sequences i and j are merged to fit into HMM, and BIC(i, j...) is the BIC value before these two video sequences are merged.
A large value of BIC difference i(i, j...) means the HMMs are more similar to each other. This similarity can be used to compare the similarity between any number of models, rather than only pairwise similarity. To reduce the overfitting problem of model fitting with few samples, the clustering results are updated at each merging step, and a new HMM is trained after all video sequences are merged and reclassified to their corresponding clusters. This will alleviate the overfitting problem and wisely classify the poorly clustered videos. In addition, a 2-depth search strategy is proposed within DHC where 3 clusters can merge to form a new cluster rather than only pair of clusters each time as a 1-depth search strategy. This will accelerate the hierarchical clustering process with levels of clustering trees. The authors developed a set of exclusion rules to stop the merging of cluster triplets. These exclusion rules can be efficiently tested as they involve computing only pair-wise model similarity.

With the obtained clustering results and corresponding models for each cluster, a mixture model of the cluster HMMs is developed to explain each video sequence in the corpus follows:

```
P(i) = sum_{c=1} π_c * L_ic (14.25)
```

where P(i) is the probability that a video sequence i is generated by this mixture model, πc is the mixing coefficient, and L_ic is the likelihood of the ith video sequence being generated by the HMM for the cth cluster.

It is also noted that the mixing coefficient π for each component in the above mixture model can be used to represent the dominance of each cluster. The videos generated from the dominant clusters are considered to be normal, once a video in a clustering with missing coefficient not a certain threshold is considered to be an abnormal one.

## 14.3.3 Video Story Clustering

Story-level clustering of videos has been an indispensable ingredient to discover the stories based on different events. [14] develops a video clustering algorithm to merge the stories with the same theme based on the occurrences of concepts in the stories which are extracted from both video frames and keywords. All the video stories are represented by a bipartite graph, where each story is linked to the keyframe clusters and textual keywords associated with it. The association between a story and the associated keyframe clusters and keywords is computed based on two factors: (i) their occurrence frequency and (ii) the story frequency. A co-clustering algorithm based on the spectral clustering [33] was then applied to simultaneously group the stories into clusters with the same event theme as the keyframe and keyword clusters which describe the same story.

Let us denote the video-story matrix by $A_1$ and cluster-story matrix by $A_2$. Two matrices are then concatenated to obtain the affinity matrix $A=[A_1^T A_2^T]$ for the bipartite graph. The normalized affinity matrix is then constructed: $A=D_1^{-1/2}AD_2^{-1/2}$, where $D_1$ and $D_2$ are diagonal matrices whose elements are the summation of row vector of $A_1$ and $A_2$, respectively. To obtain $k$ clusters from the bipartite graph, $l=[\log k]$ singular values are corresponding to the second smallest singular value using the $l+1$ singular value. The $k$-means algorithm is then run on the $l$-dimensional space using these singular values to yield the desired $k$-way partition of the bipartite graph.

The authors of [37] proposed a video clustering algorithm across multiple sources. It is noted that one event with the same topic is reported by multiple news channels, and it is interesting to cluster these videos with the same theme. To achieve this, a $K$-partite graph with clusters number of node sets is constructed. Each of the node sets contains the video segments within one source, and a pair of nodes in different segments is connected by an edge whose weight is the similarity between the video segments associated with these nodes. Also, the nodes in the same segment cannot be connected to each other. Similar to the clustering algorithm in [14], a spectral clustering algorithm is developed to cluster the videos from different sources into the stories with the same topics. The $K$-partite graph is constructed across the multiple sources, the obtained stories will cover the videos from different sources instead of the single news channel.

## 14.4. Music Summarization

In [9], the authors investigate segmentation and clustering for the task of music summarization. Both are achieved by similarity metric of windows and segments, respectively. In this approach, a similarity metric for predefined windows based on spectrogram distance is constructed. Then, kernel matching to find specific patterns with segment boundary is applied. Let us denote the spectral data computed for $N$ windows of a digital audio file by vectors $\{v_i; i=1, \dots, N\}$, the similarity matrix $S$ is computed as

```
$S(i,j)=d_{coo}(v_i,v_j)=\frac{v_i^Tv_j}{\|v_i\|\|v_j\|}
```

When analyzing $S$, it can be noticed that the diagonal produces high similarity along the main diagonal. The two segments will also produce low similarity off the main diagonal. This is the crux of this checkerboard pattern. The normalized affinity matrix is then constructed: $A=D_1^{-1/2}AD_2^{-1/2}$, where $D_1$ and $D_2$ are diagonal matrices whose elements are the summation of row vector of $A_1$ and $A_2$, respectively. To obtain $k$ clusters from the bipartite graph, $l=[\log k]$ singular values are corresponding to the second smallest singular value using the $l+1$ singular value. The $k$-means algorithm is then run on the $l$-dimensional space using these singular values to yield the desired $k$-way partition of the bipartite graph.

The authors go to designate segments with large singular values as summaries, because they are usually repeated and therefore, serve as summaries of popular music. First, for each overlapping frame, a Mel-cluster feature is calculated. Each initial segment consists of a fixed number of frames, within which the Mel-cluster features are assumed to follow a Gaussian distribution. A bottom-up clustering is then applied; i.e., the clustering algorithm iteratively finds the two clusters with lowest them (if it is less than a threshold, then they are combined). They use a modified $KL$ distance and call it $KL2$.

```
$KL2(A;B) = KL(A;B)+KL(B;A) \quad (14.32)
```

where $A$ and $B$ are Gaussian distributions:

```
$KL(A;B) = E_A(\log pdf(A)|-\log pdf(B)) \quad (14.33)
```

Assuming $A$ and $B$ are Gaussian distributions:

```
$KL2(A;B) = \frac{\Sigma_A}{\Sigma_B} + \frac{\Sigma_B}{\Sigma_A} + (\mu_A - \mu_B)^2 \times (\frac{1}{\Sigma_A} + \frac{1}{\Sigma_B}) \quad (14.34)
```

Then,

```
$b_k(j) = \sum_{i=1}^p B_k(i, j) \quad (14.30)
```

is evaluated and measures the similarity of segment $p_i$ to the segments in the $k$th cluster. Accordingly, $p_i$ is assigned to cluster

```
$k^* = \arg\max_{k=1,\dots,K} b_k(i) \quad (14.31)
```

After hierarchical clustering, or HMM-based clustering, the closest cluster (label) is considered and the longest section containing this label in the first half of the song is chosen as the key phrase.
