# 4.3.3 Other Hierarchical Clustering Algorithms

The agglomerative and divisive hierarchical clustering methods are successful in capturing shaped clusters. As mentioned above, agglomerative methods, especially single link and complete link, suffer from the "chaining problem" and are ineffective at arbitrarily shaped clusters. Hence, to capture arbitrarily shaped clusters, such as CURE [17] and CHAMELEON [25] have been proposed in the literature. Some of the popular extensions of hierarchical clustering are discussed below.

+   1. CURE (Cluster Using Representatives) [17] is an algorithm which incorporates a novel feature of representing a cluster using a set of well-centered representative points. The distance between two clusters is calculated by looking at the minimum distance between the representative points chosen. In manner, CURE features both of the single link and GAAC hierarchical clustering methods. Choosing scattered points helps CURE clusters of arbitrary shapes. In addition, CURE employs a shrinking factor α as α shrinks the points towards the centroid. This makes CURE more robust to outliers. To this approach, an algorithm called ROCK [18] was also proposed to handle categorical data. This algorithm uses the common link methods and determines the Jacard coefficient between candidate clusters for hierarchical clustering.

+   2. CHAMELEON [25] is a clustering algorithm which uses graph partitioning methods on the K-nearest graph of the data. These initial partitions are then used as the seeds for the agglomerative hierarchical clustering process. This algorithm uses two metrics based on the local-connectivity and relative closeness of clusters to merge the clusters. These metrics capture the local influence of clusters during the clustering thus enabling this algorithm to behave like a dynamic framework. CHAMELEON is one of the best hierarchical clustering algorithms and is extremely effective in capturing arbitrarily shaped clusters which is primarily due to the dynamic behavior. A detailed comparison between the results of CURE and CHAMELEON for synthetic datasets with clusters of varying shapes can also be found in [25].

+   3. COBWEB [15]: This is a conceptual clustering algorithm that works incrementally by updating the clusters by object. Probabilistically described clusters are arranged as a tree to form a hierarchical clustering known as probabilistic categorization theory. It handles uncertainty with categorical attributes in clustering through a probabilistic framework that is similar to Naive Bayes. The dendrogram in this algorithm is also a classification tree and the nodes are referred to as concepts.

+   4. Self-Organizing Maps (SOM) [28] were developed on the same lines of Artificial Neural Networks for hierarchical representation. It is an efficient data visualization technique. Similar to K-means, data are assigned to their closest centroids. The differences in the centroid update step, where a centroid is updated, those in its neighborhood close to this centroid are also updated. The final output is an SOM neural network which can be explored to understand the relationships between different objects in the clustering.
