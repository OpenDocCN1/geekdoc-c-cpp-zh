6. **Convex-NMF**: In the general, bases $F = (\mathbf{f}_1, \dots, \mathbf{f}_k) \in \mathbb{R}^{n 	imes k}$ are much larger than the input space spanned by the columns of $X = (x_1, \dots, x_n)$, according to Theorem 1, $F$ has a convex combination of cluster centers. To enhance this geometric meaning, we restrict $F$ to be a convex combination of the input data points, i.e., $F$ lies in the input space, $\mathbf{f}_1 = w_1x_1 + \dots + w_nx_n = Xw$, or $F = Xw, w_i \ge 0$. We called this restricted factorization of Convex-NMF [37, 36]. Convex-NMF applies to both nonnegative and negative-input data:

```
$X \approx XW_+G_+^T$
```

Recently, **Convex-Hull NMF** has been proposed to extend Convex-NMF by restricting the convexity of the columns of $F$ and $G$, leading to the factorization where each input data point is expressed as a convex combination of convex hull data points [110]. Convex-Hull NMF can be expressed as

```
$X \approx XG^T$
```

where $C$ consists of a set of appropriate $c_i \in conv(X)$, and $conv(X)$ is the convex hull of $X$.

7. **Cluster NMF**: In Cluster NMF, we require the columns of $X$ to be combinations of input data. Now we interpret the entries of $G$ as posterior cluster probabilities. In this case the cluster centers can be computed as $f_i = Xg_i/n_i$, or $F = XGD_i^{-1}$, where $D_i = 	ext{diag}(n_1, \dots, n_n)$. The extra degree of freedom $F$ encodes clusters and $G$ encodes centers (2). If not necessary, therefore, the posterior—motivated by desiderata—($F$) encodes a factorization $X \approx XGD_i^{-1}G^T$. We can absorb $D_i^{-1}$ into $G$ and solve

```
$Cluster-NMF: X \approx XG_+G_+^T$
```

We call this factorization *Convex-NMF* because the degree of freedom in this factorization is the cluster indicator $G$, as in a standard clustering problem [37]. The objective function is $J = ||X - XGG^T||^2$.

8. **Tri-Factorization**: To simultaneously cluster the rows and the columns of the input data matrix $X$, we consider the following nonnegative 3-factor decomposition [41]:

```
$X \approx FSG^T$
```

Note that $S$ provides additional degrees of freedom that the low-rank matrix representation maintains row clusters while $F$ and $G$ give clusters. More precisely, we solve

```
$\min_{F \ge 0, S \ge 0, G \ge 0} ||X - FSG^T||^2, s.t. F^T F = I, G^T G = I$
```

This gives a framework for simultaneously clustering the rows and columns of $X$. An important case is that the input $X$ contains pairs of matrix with symmetry: $X=X^T=W$. In this case, $F=G=H$. We call it symmetric NMF, which optimizes

```
$\min_{W \ge 0, S \ge 0} ||X - SHS^T||^2, \min_{W \ge 0, S \ge 0} ||X - SHH^T||^2, s.t. H^T H = I$.
```

9. **Kernel NMF**: Using mapping such as that used in support vector machines:

```
$x_i \to \Phi(x_i), , X \to \Phi(X) = (\Phi(x_1), \dots, \Phi(x_n))$.
```

Similar to the concept proposed for convex-NMF, we restrict $F$ to be a convex combination of transformed data points:

