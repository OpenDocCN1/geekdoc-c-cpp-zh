# 2.1.1 Data Clustering

Due to the increase in data size, human manual labeling becomes extremely difficult and expensive, automatic labeling becomes an indispensable step in data mining. Clustering is one of the most popular data labeling techniques. In clustering, we are given unlabeled data and are to put similar samples in one pile, called a cluster, and the dissimilar samples be in different clusters. Usually, cluster's description is not given in advance unless domain knowledge exists, which poses a great challenge in data clustering.

Clustering is useful in several machine learning and data mining tasks including segmentation, information retrieval, pattern recognition, classification, network analysis, and so on. It can be seen as an exploratory task or preprocessing step. If the goal is to explore and reveal the hidden patterns in the data, clustering becomes a stand-alone exploratory task by itself. However, if the generated clusters are going to be used to facilitate another data mining or machine learning task, clustering is a preprocessing step.

There are many clustering methods in the literature. These methods can be categorized into partitioning methods, hierarchical methods, and density-based methods. The partitioning methods use a distance-based metric to cluster the points based on their similarity. Algorithms belonging to this produce one level partitioning and nonoverlapping spherical clusters. K-means and k-medoids are popular partitioning algorithms. The hierarchical method, on the other hand, partitions the data into different layers which can be done in either bottom-up (i.e., agglomerative) or top-down (i.e., divisive) fashion. Examples of this type of clustering are BIRCH, Chamel, AGNES, and DIANA. These two clustering techniques, density-based clustering can capture arbitrarily clusters as S-shape. Data points in dense regions form a cluster while data points from different clusters are separated by density regions. DBSCAN and OPTICS are popular examples of density-based clustering methods.

# 2.1.2 Feature Selection

In the past years, the dimensionality of the data involved in machine learning and data mining tasks has increased exponentially. Data with extremely high dimensionality has presented serious challenges to existing learning methods [35], known as the curse of dimensionality [23]. With the existence of a large number of features, learning models tend to overfit and their learning performance degenerates. To address the problem of dimensionality, dimensionality reduction techniques have been developed, which form an important branch in the machine learning research area. Feature selection is one of the most techniques used to reduce dimensionality among practitioners. It aims to choose a small subset of relevant features from the original ones according to evaluation criterion [36, 21], which usually leads to better learning performance, e.g., higher learning accuracy, lower complexity, and better model interpretation. Feature selection has been successfully applied in many real applications, as pattern recognition [26, 58, 44], text categorization [74, 29], image processing [26, 55], and bioinformatics [45, 56], and so forth.

According to the latter information, it can be categorized into supervised [69, 60], unsupervised [16, 44], or semisuvised algorithms [78, 73]. Feature selection algorithms of the filter model are independent of any classifier. They evaluate the relevance of a feature by studying its characteristics using certain statistical criteria.
