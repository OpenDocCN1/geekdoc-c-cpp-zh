The demonstrated success of cluster ensembles provides a direct motivation to study effective ways of combining clustering solutions as well. This chapter covers the theory, design, and application of cluster ensembles, which address the problem of combining multiple “base clustering” to a grouping of the same set of objects or its transformed (perturbed) version using a suitable clustering algorithm. The consolidated clustering is often referred to as the consensus solution. However, combining multiple solutions poses additional challenges. First, the number of clusters produced may differ from the different base solutions [6]. The appropriate number of clusters in the consensus is also not known in advance and may depend on the scale at which the data is indexed. Moreover, cluster labels are symbolic and thus aligning cluster labels across different solutions solving a potential difficulty of correspondence problem. As in the typical formulation, the original data used to yield solutions does not correspond to the consensus mechanism, which has only access to the set of cluster labels. In some schemes, one have control over how the base clusters are produced [21], while in others this is not granted in order to allow applications involving knowledge reuse [56], as described later. Despite these added complexities, cluster ensembles are inevitably inciting the variations across a variety of clustering algorithms applied to a specific dataset to be more than the typical variation in accuracies returned by a collection of reasonable classifiers. This suggests that cluster ensembles may achieve greater improvements over the base solutions, when compared with ensembles of classifiers [24].

# 1. Improved Quality of Solution

Just as ensemble learning has proven to be more useful than single-model solutions for classification and regression problems, one may expect that cluster ensembles will improve the quality of results as to a single clustering solution. It has been shown that using cluster ensembles leads to more accurate results on average the ensemble approach takes to account the biases of individual solutions [39, 31].

# 2. Robust Clustering

It is well known that popular clustering algorithms often fail spectacularly for certain datasets that do not match with the modeling assumptions [33]. A cluster ensemble approach can provide a “meta” clustering model that is much more robust in the set of being able to provide good results across a wide range of datasets. As an example, by using an ensemble that approaches such as k-means, SOM, and DBSCAN are typically better suited to low-dimensional metric spaces, as well as base clusters for high-dimensional spaces (spherical k-means, Jaccard-based graph clustering, etc.), one can perform well across a wide range of data dimensionality [56]. Authors in [53] present several empirical results on the robustness of the results in document clustering by using feature diversity and consensus clustering.
