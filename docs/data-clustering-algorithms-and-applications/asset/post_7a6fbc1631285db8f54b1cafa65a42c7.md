## Chapter 7: Nonnegative Matrix Factorizations for Clustering

### 7.1 Introduction

Nonnegative matrix factorization (NMF) is a powerful technique for decomposing a nonnegative matrix $V$ into the product $V \approx WH$, where both $W$ and $H$ are nonnegative matrices. This approach has gained significant attention in various fields, including clustering, due to the nonnegativity constraint, which leads to a part-based representation that is often more interpretable than those obtained from principal component analysis (PCA). In the context of clustering, NMF can be used to factor a data matrix $V \in \mathbb{R}^{m \times n}$, where $m$ is the number of features and $n$ is the number of samples, into a basis matrix $W \in \mathbb{R}^{m \times k}$ and a coefficient matrix $H \in \mathbb{R}^{k \times n}$, where $k$ is the number of clusters. Each column of $W$ can be viewed as a prototype of a cluster, and each column of $H$ represents the membership weights of a sample in the $k$ clusters.

### 7.2 NMF Formulations

The NMF problem is typically formulated as a constrained optimization problem:
$$\min_{W,H \ge 0} f(V, WH)$$
where $f(V, WH)$ is a cost function measuring the distance between the original data and its approximation. Commonly used cost functions include:

- **Euclidean Distance**: $f(V, WH) = \frac{1}{2} \|V - WH\|_F^2$
- **Kullback-Leibler (KL) Divergence**: $f(V, WH) = \sum_{i,j} (V_{ij} \log \frac{V_{ij}}{(WH)_{ij}} - V_{ij} + (WH)_{ij})$
- **L1-norm**: $f(V, WH) = \sum_{i,j} |V_{ij} - (WH)_{ij}|$

The NMF problem is often solved using iterative algorithms such as the multiplicative update rules, coordinate descent, or alternative least squares methods.

### 7.3 NMF Clustering Capabilities

Once the matrices $W$ and $H$ are obtained, clustering can be performed by assigning each sample to one or more clusters. Since $H_{ij}$ represents the degree to which sample $j$ belongs to cluster $i$, several clustering strategies can be employed:

- **Hard Clustering**: Each sample $j$ is assigned to exactly one cluster. We can assign sample $j$ to the cluster $i$ that has the maximum value in $H_{ij}$: $c_j = \arg\max_i H_{ij}$.
- **Soft Clustering**: Each sample $j$ is assigned to all clusters with weights given by $H_{ij}$. This is useful for data where samples may belong to multiple clusters.
- **Thresholding**: A sample is assigned to clusters where $H_{ij}$ exceeds a certain threshold.

NMF-based clustering is particularly effective for high-dimensional, sparse data, such as text documents or image data, where the nonnegativity constraint helps capture the latent structures effectively.
