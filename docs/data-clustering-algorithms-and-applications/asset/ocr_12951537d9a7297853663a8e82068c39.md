# 17.13.7 Probabilistic Methods

In this section we talk about some of the probabilistic methods in the area of network clustering.

+   * Generative Model-Based Methods assume that the data is part of some unsupervised probability distribution. Generative models describe probabilistically how a dataset may be formed. In other words, they are the hypotheses of the underlying distribution that created the data. Assuming the hypothesis to be true, algorithms like Expectation Maximization can be used to find clustering that best agrees with the underlying model [70]. Fu and Banerjee [62] show that mixture models can be constructed as generative model as well. Madison and Purnell [71] use spectral clustering to map the network into a d-dimensional space and train a Gaussian Mixture Model (GMM) using the Expectation Maximization (EM) algorithm. Increase in likelihood of adding a cluster is used to determine the number of communities [172].
For groups in networks, SBM is another type of generative model [127]. However, fitting an empirical network to SBM requires inferring model parameters. OSM [98] shows each node is associated with a Latent vector with k Independent Variables where k is the number of communities. As in [144], the latent vector is inferred by maximizing the posterior probability conditioned on the presence of edges. Because the factorization in the observed condition distribution for edges given the latent vector is general intractable, OSM requires more than mixture methods [172]. McDavid and Hurley combine OSM with local optimization scheme in MOSES [110] which the fitness function is based on the observed condition distribution and has a worst-case time complexity of O(n²) where n is the number of edges. Recently SBM of Nowicki and Snijders [127] exploring parameter collapsing to integrate block parameters. This model defines a posterior over the number of clusters memberships allows the number of clusters to be directly estimated. Another SBM method was proposed by McDavid et al. in [112] for finding communities in networks.

These models regard ties nodes of the network as random variables. The general form of the exponential random graph model for the network is determined by assumptions about dependencies these random variables.
