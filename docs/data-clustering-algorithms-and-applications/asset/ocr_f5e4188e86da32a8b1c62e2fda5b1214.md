# 3.3.4 Applications of the EM Algorithm

The EM algorithm turns out to be a general way of maximizing the likelihood when variables are unobserved and, hence, is useful for other applications besides mixture models. There are two main applications of the EM. The first occurs when the data has missing values, due to problems or limitations of the observation process. The second occurs when optimizing the likelihood function is analytically intractable but can be simplified by assuming the existence of values for added missing (hidden) parameters. The latter application is more common in the computational pattern recognition community. The range of potentially useful applications is broader than presented here, including, for instance, specialized variance components, problems of missing values in general parametric models, and models with continuous latent variables. A complementary overview of the applications is used in [23, 7].

Probabilistic topic models [35, 14, 72, 9, 10] are a type of statistical model for discovering the abstract topics that occur in a collection (or corpus) of documents, where each document may be viewed as a mixture of topics. In view of probabilistic clustering, each topic can be interpreted as a cluster, such that each document uniquely belongs to multiple clusters.
