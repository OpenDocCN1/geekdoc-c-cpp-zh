## 4.3.2 Group Averaged and Centroid Agglomerative Clustering

**Group Averaged Agglomerative Clustering (GAAC)** shows the similarity between all pairs of points present in this cluster and diminishes the drawbacks associated with single and complete link methods. We look at the formula let us introduce some terminology. Let $C_a$ and $C_b$ be merged such that the resulting cluster $C_{a,b} = C_a \cup C_b$. The new center for this cluster is $C_{a,b} = \frac{Na_a+Nb_b}{N_a+N_b}$, where $N_a$ and $N_b$ are the sizes of the clusters $C_a$ and $C_b$, respectively. The similarity measure for GAAC is as follows:

```
$S_{GAAC}(C_a, C_b) = \frac{1}{(N_a+N_b)(N_a+N_b-1)} \sum_{i\in C_a\cup C_b} \sum_{j\in C_a\cup C_b, i\neq j} d(i,j)$
```

We can see that the distance between two clusters is the average of all pair-wise distances between the data points in these two clusters. Hence, this is expensive especially when the number of data objects becomes large. Centroid-based agglomerative clustering, on the other hand, calculates the similarity between two clusters by measuring the similarity between their centroids. The primacy difference between GAAC and Centroid agglomerative clustering is that, GAAC considers all pairs of data objects for computing the average pair-wise similarity, whereas centroid-based agglomerative clustering uses only the centroid of the cluster to compute the similarity between different clusters.

## 4.3.1.3 Ward’s Criterion

Ward’s criterion [49, 50] was proposed to compute the distance between two clusters during agglomerative clustering. The process of using Ward’s criterion for cluster merging in agglomerative clustering is also called as Ward’s aggregation. The K-means squared error criterion to determine the distance. For any two clusters, $C_a$ and $C_b$, Ward’s criterion is calculated by measuring the increase in the SSE for the cluster obtained by merging in $C_a \cup C_b$. Ward’s criterion is defined as

```
W(C_{a,b},c_{a,b}) = W(C,c) = \frac{N_a N_b}{N_a + N_b} \sum_{v=1}^M (c_{av}-c_{bv})^2 = \frac{N_a N_b}{N_a + N_b} d(c_a, c_b)
```

So the Ward’s criterion can be interpreted as the squared Euclidean distance between the centers of the merged clusters $C_a$ and $C_b$ weighted by a factor that is proportional to the product of cardinalities of the merged clusters.

## 4.3.1.4 Agglomerative Hierarchical Clustering Algorithm

In Algorithm 20, we provide a basic outline of an agglomerative hierarchical clustering algorithm. In line 1, the dissimilarity matrix is computed for all the points in the dataset. In lines 3–4, the closest pairs of clusters are repeatedly merged in a bottom-up fashion and the dissimilarity matrix is updated. The rows and columns are removed from the dissimilarity matrix and added to the new cluster. Line 5 indicates the termination condition.

**Algorithm 20 Agglomerative Hierarchical Clustering**
1: Compute the dissimilarity matrix for all the points.
2: repeat
3: Merge the closest pairs of clusters.
4: Update the dissimilarity matrix with new cluster.
5: until only one cluster remains.

## 4.3.2 Divisive Clustering

Divisive clustering is a top-down approach where the procedure starts at the root with all the data and recursively splits to build the dendrogram. This method has the advantage of being more efficient compared to agglomerative clustering especially when there is no need to generate a complete hierarchy all the down to the individual leaves. It can be considered a global approach since it contains the complete information before splitting the.

### 4.3.2.1 Issues in Divisive Clustering

We will discuss the factors that affect the performance of divisive hierarchical clustering.

- splitting criterion: The Ward's k-means squared error criterion is used here. The greater reduction in the difference in the SSE criterion should reflect the goodness of the split. Since the SSE criterion can be applied to numerical data, Gini index (which is used in decision tree construction) can be used for handling the nominal data.
- splitting method: The method used to obtain the binary split of the parent node is also critical as it can reduce the time taken for evaluating the Ward's criterion. The Bisecting K-means approach can be used here with K=2 to obtain good splits it is based on the same criterion of maximizing the Ward's distance between splits.
- Choosing the cluster to split: The choice of cluster to split may not be as important as the first two, but it can be useful to choose the most appropriate cluster for further split when the goal is to build a complete dendrogram. A simple method of choosing the cluster to be split further could be done by merely checking the square errors of the clusters and splitting the one with the largest value.
- handling noise: Since the noise points present in the dataset might result in aberrant clusters, a threshold should be used to determine the termination criteria rather splitting the clusters further.
