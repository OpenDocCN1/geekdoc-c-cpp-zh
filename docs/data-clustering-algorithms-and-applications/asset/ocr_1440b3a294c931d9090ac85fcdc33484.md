# 2.2.1.4 Localized Feature Selection Based on Scatter Separability (LFBSSS)

Li et al in [33] proposed a localized feature selection based on scatter separability (LFBSSS). This is motivated by the fact that the set of features that are relevant to one clustering result are not the same set that is relevant to another clustering. In other words, clustering $D$ using a set of features $F_i$ may lead to clusters $\{C_1, C_2, C_3\}$ while using another set of features $F_j$ may lead to $\{C_4, C_5\}$, where $F_i \neq F_j$. This is also illustrated in Figure 2. Furthermore, each cluster may be associated to different set of relevant features. In document clustering, for instance, documents that belong to news sports are more likely to have different relevant terms such as FIFA, Ball, and so on. While the set of documents belong to news contains relevant terms such as Apple, IBM, and so on. In this section we will use the cluster set $\hat{C} = \{(\hat{C}_1, \hat{F}_1), \dots, (\hat{C}_K, \hat{F}_K)\}$ to refer to the clustering result $\hat{C}$ and $\hat{F}_1$ are the first cluster and the set of selected features corresponds to the first cluster, respectively.

Li et al in [33] borrowed the notion of cluster separability from Dy and Brodley [16] and adopted a localized feature selection. They defined the cluster separability as

> $\Omega = tr(S_w^{-1} S_b)$

where $S_w$ is the inverse of within-cluster separability and $S_b$ for cluster $i$ is the between-cluster separability. To evaluate $\Omega_i$, we should use the within cluster separability $S_{wi}^{-1}$, instead. It was proven in [33] that $\Omega_i$ is monotonically increasing with dimensions as long as the clustering assignments remain the same. To mitigate this problem, separability criteria must be normalized with respect to the dimensionality. For feature selection, more localized feature selection attempts to select different sets of relevant features for each cluster, the between-cluster separability needs to be appropriately normalized as well. This is performed using cross-projecting individual clusters. We assume that the projected cluster $\hat{C} = \{(\dots), ..., (\hat{C}_K, \hat{F}_K)\}$. At each step of the projection, we replace the projected cluster $\hat{C}_j$, with the largest overlap and the original cluster $C_j$
