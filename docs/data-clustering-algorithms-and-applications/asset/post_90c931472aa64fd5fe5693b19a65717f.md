## 7.4.3.3 Objective Function vs. Clustering Performance

In clustering problems, when we have the external structure information (i.e., the derived classes of the data points), performance measures such as purity, normalized mutual information (NMI), and accuracy [109, 53, 39] have been used as the performance measure. In practice, clusters of a dataset could have many different shapes and sizes. In addition, these clusters can overlap with each other and cannot be easily identified and separated. As a result, it is difficult to effectively capture the clusters using a single (even the "best if exists") clustering objective function.

There hence generally a gap between the objective function and the clustering performance measure [33]. In many real applications, when the clustering objective is optimized, the quality of clustering in terms of accuracy or NMI is usually improved. The improvements work up to a certain point, and beyond, further optimization of the objective function will not improve the clustering performance or capture the structure. It is also possible that the objective function is optimized, the clustering performance (e.g., accuracy or NMI) can be degraded.

## 7.4.3.4 Scalability

Many prior efforts have been reported on scaling up matrix factorization methods through algorithm design. While efficient computation algorithms for matrix factorization have developed, they have primarily been in the context of scientific/engineering applications where sizes of matrices (tens of thousands by tens of thousands with millions of nonzero values) are typically smaller than for Web analysis (millions-billions matrices with billions of observations). We present several practical mechanisms for dealing large-scale datasets for NMF:

- Shrinking scheme: The scheme first "coarsens" the large scale problem into a small one (by level), then solves the coarsened optimization problem, and finally refines the solution to approximate the solution to the original problem. A typical example of the shrinking scheme is the multi-level graph partitioning [31, 54, 57].
- Partitioning scheme: The scheme first divides the original problem into a series of small scales, and then solves small problems, and finally combines their solutions to approximate the original problem. Typical examples of this scheme include principal component analysis [87], canopy-based clustering [85], and K-means clustering [121].
- Online/incremental scheme: The scheme does not require the input dataset to reside in the memory and performs factorization in an incremental fashion (i.e., one sample or a chunk of samples per step). Examples of the scheme include incremental NMF [16], online NMF by updating the factor matrices [13], online NMF using stochastic approximation [122, 52, 120], and evolutionary NMF [125, 94].
- Parallel and distributed implementation: An orthogonal direction for improving the scalability of matrix factorization methods is to use parallel and distributed computing platforms, [42, 80, 6]. MapReduce is a programming model for processing and generating large data sets [26]. Although the initial purpose of MapReduce is to perform large-scale data processing, it turns out that this model is more expressive and has been widely used in data mining and machine learning tasks [11, 2, 15]. Liu et al. [80] successfully scaled up the basic NMF for web-scale dyadic analysis using MapReduce, and Sun et al. [108] presented different matrix multiplication implementations and scaled up three types of nonnegative matrix factorizations on MapReduce. Recently, Graphics Processing Unit (GPU) implementation of the NMF algorithms has also been reported [65, 84, 93].

## 7.5 NMF Related Factorizations

Here we provide an overview of related matrix factorization methods.

1. **SVD**: The classic matrix factorization [45, 50], $X \approx U\Sigma V^{\text{T}}$, where $U, V$ have mixed signs; the input data could have mixed signs. Abstracting $\Sigma$ into $U$, we can write:
   SVD: $X_{\pm} \approx U_{\pm}V_{\pm}$. (7.14)

2. **NMF**: When the input data is nonnegative, we restrict $F$ and $G$ to be nonnegative. The standard NMF can be written as:
   NMF: $X_{\+} \approx F_{\+}G_{\+}$. (7.15)
   using an intuitive notation for $X, F, G \ge 0$.

3. **Regularized NMF**: Additional constraints can be added to the standard NMF formulation. In general, regularized NMF can be written as the following optimization problem:
   $\min_{F,G \ge 0} \|X - FG^{\text{T}}\|^2 + \alpha_1(F) + \beta J_2(G)$, (7.16)
   where the functions $J_1(F)$ and $J_2(G)$ are penalty terms to enforce certain constraints and $\alpha$ and $\beta$ are the characterizing regularization parameters [90]. Many different penalty terms have been used in the literature to have different effects on the computed solutions such as the smoothness constraint (e.g., the matrix norm) [90], the sparsity constraints (e.g., $L_1$-norm regularization), the geometric constraints (e.g., manifold structures) [12], and the local learning regularizations by neighborhoods [51].

4. **Projective NMF**: A projective NMF model aims to find an approximate projection of the input matrix [132, 24]. It can be formulated as:
   $X \approx FF^{\text{T}}X$. (7.17)
   The idea of the projective NMF is similar to subspace clustering.

5. **Semi-NMF**: When the input data is mixed, we restrict $G$ to be nonnegative placing no restriction on the signs of $F$. This is called semi-NMF [37, 36]:
   semi-NMF: $X_{\pm} \approx F_{\pm}G_{\+}$. (7.18)

6. **Convex-NMF**: In general, regularized NMF can be written as the following optimization problem:
   $\min_{F,G \ge 0} \|X - FG^{\text{T}}\|^2 + \alpha_1(F) + \beta J_2(G)$, (7.16)
   where the functions $J_1(F)$ and $J_2(G)$ are penalty terms to enforce certain constraints and $\alpha$ and $\beta$ are the characterizing regularization parameters [90]. Many different penalty terms have been used in the literature to have different effects on the computed solutions such as the smoothness constraint (e.g., the matrix norm) [90], the sparsity constraints (e.g., $L_1$-norm regularization), the geometric constraints (e.g., manifold structures) [12], and the local learning regularizations by neighborhoods [51].

7. **Cluster NMF**: In Cluster NMF, we require the columns of $X$ to be $f_1, \dots, f_n$. The degree of freedom $F$ represents the cluster indicator.

8. **Tri-Factorization**: To simultaneously cluster the rows and columns of the input matrix $X$, we consider the following 3-factor decomposition [41]:
   $X \approx FSG^T$
   Note that $S$ provides additional degrees of freedom that the low-rank matrix representation maintains row clusters while $F$ and $G$ give clusters.

9. **Kernel NMF**: Using mapping such as that used in support vector machines:
   $x_i \to \Phi(x_i), , X \to \Phi(X) = (\Phi(x_1), \dots, \Phi(x_n))$.
