## 18.2 Mixture Clustering of Uncertain Data

Mixture clustering [23] is a popular method for clustering deterministic data, and it clusters the underlying data in terms of number of probabilistic parameters. For example, the data can be modeled as a mixture of Gaussian clusters, and the parameters of this mixture can be learned from the underlying data. The core idea [23] is to determine model parameters, which ensure a maximum likelihood fit of the *observed instantiations* of the data with the proposed model. A popular method in order to determine these parameters is the EM algorithm, which uses an Expectation-Maximization approach to iteratively update the parameters with the observed data instances.

The work in [33] generalizes this approach to the case of uncertain data, where each data value may be drawn from an interval. The main difference between the uncertain version of the algorithm and the deterministic version is that each instantiation is now an uncertain value of the record, rather than a deterministic value. Correspondingly, the EM algorithm is changed in order to evaluate the expressions in the E-step and M-step as an expectation over the range of data. Note that the approach can be used easily for any uncertain distribution, which is represented in the form of a probability histogram of values.

Another algorithm known as the MMVar algorithm has been proposed in [29], in which the centroid of a cluster C is defined as an uncertain cluster CMM, which represents the mixture of C. The cluster compactness criterion used by the MMVar algorithm is the minimization of the variance of the cluster centroid.

## 18.3 Density-Based Clustering Algorithms

Density-based methods are very popular in the deterministic clustering literature, because of their ability to determine clusters of arbitrary shapes in the underlying data. The core idea in these methods is to create a density profile of the data set with the use of kernel density estimation methods. This density profile is then used in order to characterize the underlying clusters. In this section, we will discuss two variations of such density-based methods, which are the DBSCAN and FOPTICS methods.

### 18.3.2 FOPTICS Algorithm

Another technique discussed in [41] is of hierarchical density-based clustering. An effective (deterministic) density-based hierarchical clustering algorithm is OPTICS. The core idea in OPTICS is similar to DBSCAN and is based on the concept of reachability distance between data points. While the DBSCAN defines a global density parameter is used as a threshold to define reachability, the work in [41] points out that different regions in the data may have different density, as a result of which it may not be possible to define the clusters effectively with a single density parameter. Rather, many values of the density parameter (hierarchically) exists along the underlying clusters. The goal is to define an implicit output in terms of ordering data points, so that when the DBSCAN is applied with this ordering, we can obtain the hierarchical clustering at all level for levels of the hierarchy are consistent with one another. One observation is that the clusters defined over a lower value of e are completely contained in clusters defined over a higher value of e, if the value of MinPts is not fixed. Therefore, the data are ordered based on the value of e required in order to obtain MinPts in then it is assured that higher density regions are always processed before lower density regions. This ensures that if the DBSCAN is used for this ordering, then a consistent result is obtained. Thus, the output of the OPTICS algorithm is not the cluster membership, but is the order in which the data points are processed.
