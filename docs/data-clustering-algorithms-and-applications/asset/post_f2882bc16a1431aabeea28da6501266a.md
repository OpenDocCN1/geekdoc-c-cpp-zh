## 8.9 Large Scale Clustering

The general spectral clustering needs to construct an adjacency matrix and calculate the eigen-decomposition of the corresponding Laplacian matrix. Both of these two steps are computationally expensive. For a data set of $n$ points with $m$ dimensions, the above two steps will have time complexities of $O(n^2m)$ and $O(n^3)$, respectively. This is an unreasonable burden for large-scale applications.

Formately, if we only want to construct an approximate adjacency matrix with a few number of nearest neighbors, there is a shortcut for reducing the complexity. This is called approximate neighbor search. We first introduce randomized kd-trees [35, 36]. A kd-tree partitions the space by hyperplanes that are perpendicular to the coordinate axes. At each node of the tree, the data points are partitioned into two halves with a hyperplane of specified dimension. Performance significantly degrades with the number of dimensions increasing. Sitpa-An and Hartley [45] have introduced an improved version of the kd-tree algorithm in which multiple randomized kd-trees are built. By comparison, the randomized trees are built by choosing the split dimension from the first few dimensions on which data has the greatest variance. The other alternative is called locality-sensitive hashing (LSH) [10] which offers probabilistic guarantees of retrieving data points similar to the query. The basic idea is to compute a set of functions that reduce the dimensionality of the data points through certain mathematical operations. By concatenating such functions to form a hash function, data points in the same bin as the query are returned as candidates of nearest neighbors with probabilistic guarantees. Moreover, search tables can be built in the same way to further enhance performance. A few libraries for approximate nearest neighbor search are available, including FLANN [36] and ANN [35].

For the problem of eigen-decomposition, state-of-the-art solvers can be categorized into three classes: local, global, and extreme. The power method is the simplest local solver, which only computes the maximum eigenvalue and its eigenvector. QR-decomposition is a typical global solver, which computes all the eigenvalues and eigenvectors. Extreme solvers compute extreme (smallest or largest) eigenvalues and the corresponding eigenvectors, which is much more suitable for spectral clustering when the number of clusters is usually not too large. Examples include methods for eigenvalues using Lanczos, preconditioned conjugate gradient (PCG) and Jacobi-Davidson (JD) methods. Readers can refer to [41] for details. Several software implementations of the Lanczos method are publicly available and are well maintained, e.g., ARPACK [26]. PCG and JD methods also have some implementations available [22, 48]. If the Laplacian matrix is sparse, i.e., the similarity graph is not fully connected, the state-of-the-art eigensolver can benefit from this property because most elements are zero and removed from the computation.
