# 9.4.1.3 Clustering Algorithms

The two basic techniques resulted initially in two “subspacing” paradigms that have been named by the pioneers in this field “subspace clustering” [14] and “projected clustering” [12]. For the latter, a variant has emerged called “soft clustering” [82]. Many algorithms, do not clearly fit in one of these categories. We list some examples as “hybrid approaches.”

**Projected Clustering.** The objective of projected clustering is to find sets of tuples $(O_i, D_i)$, where $O_i$ is the set of objects belonging to cluster $i$ and $D_i$ is the subset of attributes where the points $O_i$ are “similar” according to a given cluster criterion.

The approach introducing the task of “projected clustering” is PROCLUS [12], a k-medoidlike algorithm. PROCLUS normally determines a set of potential clusters $M$ on a set of points first. In the iterative cluster refinement, for each of the k medoids the subspace is determined by minimizing the standard deviation of the points in the neighborhood of the medoids to the relevant subspace along each dimension. Points assigned to the closest medoid the clusters are refined by replacing medoids with new medoids from $M$ as much as the clustering allows. A post-processing step identifies points that are too far from their closest medoids. The algorithm outputs a partition of the data points into clusters (represented by its medoid) and a (potentially empty) set of noise points.

The k-medoid cluster model of PROCLUS tends to produce sized clusters with spherical shape in their corresponding subspaces. In addition, since the set $M$ of possible medoids is determined in a randomized procedure, runs of PROCLUS with the same parameterization result in different clusters.

Variations of PROCLUS are, for example, FINIT [130] and SSPC [134]. FINIT employs heuristics to enhance efficiency and clustering accuracy. SSPC offers the capability of further enhancing using domain knowledge in the framework of labeled objects/or attributes

PreCon applies the density-based (full-dimensional) clustering algorithm DBSCAN [46] using a specialized distance measure that captures the subspace of each cluster. The definition of this specialized subspace distance is based on the so-called subspace preference that is assigned to each point $p$, representing the maximal-subspace distance in $k$ plus clusters. A dimension is considered to be the relevant subspace of a point $p$ if the variance of the points in the Euclidean-neighborhood of $p$ is smaller than a user-defined threshold $\delta$. The specialized subspace distance between points is a weighted Euclidean distance where the dimensions relevant for the subspace preference of a point are weighted by a constant $\kappa \gg1$ while the algorithm determines the number of clusters automatically, and handles noise implicitly. In addition, its results are determine and the clusters may exhibit any shape and in the corresponding subspace. However, PreCon requires the user to specify a number of input parameters that are hard to guess. Especially $e$, the neighborhood radius, has different meaning in a different dimension (cf. Aspect 5 of the curse of dimensionality) but is used both for the first set of neighborhood (locality assumption) in the full-dimensional space as well as for the adapted neighborhood in some lower-dimensional space.
