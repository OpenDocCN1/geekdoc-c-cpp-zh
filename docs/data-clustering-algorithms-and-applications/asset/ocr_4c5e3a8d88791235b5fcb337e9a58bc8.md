In PAM, CLARANS aim to find a local optimal solution by searching the entire graph. Unlike PAM, in each iteration, it checks only a sample of the neighbors of the current node in the search space. Notice that CLARA and CLARANS use sampling techniques to reduce the search space. But they conduct the sampling in different ways. In CLARA, the sampling is done at the beginning stage to restrict the particular subgraph whereas in CLARANS, the sampling is done *dynamically* in each iteration of the search process. # ## 11.2 BIRCH: Fighting with Limited Memory

When the data exceeds the available memory, the I/O cost may dominate the memory computational time, when (e.g., PAM, CLARA) suffer.
