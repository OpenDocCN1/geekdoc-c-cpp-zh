## 8.3 Unnormalized Spectral Clustering

Given the similarity graph $G$, the main step for spectral clustering is to compute graph Laplacian matrices [8]. The actual construction of this very important intermediate representation is often not defined uniquely in the literature. Every author just calls "his" the graph Laplacian [31]. To distinguish them, we will carefully study and discuss their properties in this and the next section. In this section, we first introduce the *unnormalized graph Laplacian*.

### 8.3.1 Notation

In the previous section, we defined the nonnegative weight $W_{ij}$ for each pair of vertices $v_i$ and $v_j$ in the undirected similarity graph $G$. Since $G$ is undirected, $W_{ij} = W_{ji}$. For each vertex, its degree is computed as the sum of the weights incident on it:

```
$d_i = \sum_{j=1}^{n} W_{ij}$
```

Correspondingly, the *degree matrix D* is defined as the diagonal matrix satisfying $D_{ij} = d_i$. For a subset $A$ of vertices $V$, its indicator vector is denoted by $\mathbb{L}_A = (f_1, \dots, f_n)^T$, where $f_i = 1$ if $v_i$ belongs to $A$ and $f_i = 0$ otherwise.

### 8.3.2 Unnormalized Graph Laplacian

The unnormalized graph Laplacian $L$ is defined as follows:

```
$L = D - W$
```

We list several important properties of $L$ [33, 34, 31]:

**Proposition 8.3.1** *The unnormalized graph Laplacian $L \in \mathbb{R}^n$ satisfies the following four properties:*

- 1. For an arbitrary vector $f \in \mathbb{R}^n$, we have
$$f^T Lf = \sum_{i,j=1}^{n} W_{ij}(f_i - f_j)^2 \quad (8.1)$$

- 2. $L$ is symmetric and positive semidefinite.
- 3. The smallest eigenvalue of $L$ is 0, with eigenvector $\mathbf{1}$.
- 4. $L$ has $n$ nonnegative, real-valued eigenvalues $0 = \lambda_1 \le \lambda_2 \le \dots \le \lambda_n$.

**Proof 1** We can verify the first property from the following equation:

```
$f^T Lf = f^T(D-W)f = \sum_{i=1}^n f_i^2 d_i - \sum_{i,j=1}^n f_i f_j W_{ij}\\n= \frac{1}{2}(\sum_{i=1}^n f_i^2 d_i + \sum_{j=1}^n f_j^2 d_j - 2\sum_{i,j=1}^n f_i f_j W_{ij})\
= \frac{1}{2}\sum_{i,j=1}^n W_{ij}(f_i - f_j)^2$
```

Since $Lf \ge 0$ and $D$ and $W$ are symmetric, $L$ is symmetric and positive semidefinite. Property 3 can be proved directly by plugging the unit vector $\mathbf{1}$ into Equation (8.1). Due to the fact that $L$ is a real symmetric matrix, its eigenvalues should also be real numbers. Then property 4 is proved based on property 3.

### 8.3.3 Spectrum Analysis

We analyze the spectrum of $L$ in the context of the unnormalized algorithm. Assume that $G$ is an undirected similarity graph with $k$ connected components $A_1, A_2, \dots, A_k$. The corresponding graph Laplacians for these subsets are $L_1, L_2, \dots, L_k$. Without loss of generality, $L$ can be represented as a block-diagonal structure:

![](img/b94d85a2e934001944bcc21abd9a9943_207_0.png)

Since $L$ is a block diagonal matrix, its eigenvalues and eigenvectors are the union of eigenvalues and eigenvectors of its blocks (i.e., $L_1, L_2, \dots, L_k$). This implies that the multiplicity of eigenvalue 0 of $L$ should be at least $k$. The corresponding eigenvectors can be represented as indicator vectors $\mathbf{1}_{A_1}, \mathbf{1}_{A_2}, \dots, \mathbf{1}_{A_k}$. As the weights $W_{ij}$ are nonnegative, it can also be seen from Equation 8.1 that the next eigenvalue is strictly greater than 0 because this sum vanishes when $W_{ij}(f_i - f_j)^2$ for any pairs of vertices $v$ and $v$ vanish. We can then claim that the multiplicity $k$ of the eigenvalue 0 of $L$ equals the number of connected components $A_1, A_2, \dots, A_k$.

How about the eigenvectors? Since 0 is a repeated eigenvalue in $L$, any other orthogonal vectors spanning the same subspace as the eigenspace of the eigenvectors above also be the eigenvectors. Therefore, we have the following proposition [31].

**Proposition 8.3.2.** *The multiplicity $k$ of eigenvalue 0 of $L$ equals the number of connected components $A_1$*

This proposition provides theoretical foundation for the spectral clustering algorithm for partitioning vertices into different subsets in the "ideal" case.

## 8.3.4 Unnormalized Spectral Clustering Algorithm

We will introduce the unnormalized spectral clustering algorithm based on unnormalized graph Laplacian $L$. Assume that $F \in \mathbb{R}^{n \times k}$ is a matrix containing the relevant orthonormal vectors $f_1, f_2, \dots, f_k$ with the following objective function:

```
$\min Tr(F^T F) \quad \text{s.t.} \quad F^T F = I \quad (8.2)$
```

Here, $Tr(\cdot)$ denotes the trace of the matrix.
As we have discussed in the last subsection, these vectors are the $top^2$ eigenvectors of $L$. Unlike negative matrix factorization methods, these eigenvectors cannot be directly used for inferring the cluster labels because of the following two reasons. First, only in the ideal case where no edges exist between different components the eigenspace spanned by the indicator vectors $\mathbf{1}_1, \mathbf{1}_2, \dots, \mathbf{1}_k$. Second, the eigenvectors could be any orthogonal transformation of the indicator vectors, which are not necessarily indicative of the cluster labels. Fortunately, if we view these eigenvectors as the low-dimensional representations of the original data points $X$, then any off-the-shelf clustering algorithms such as $k$-means and mixture models can be used to partition the embedding.
The overall algorithm for spectral clustering is illustrated below.

### Unnormalized Spectral Clustering

- 1. Construct the similarity graph with one of the methods described in Section 8.2.
- 2. Compute the unnormalized graph Laplacian $L = D - W$. Let $W$ be the adjacency matrix and $D$ be the degree matrix.
- 3. Determine $f_1, f_2, \dots, f_k$, the top $k$ eigenvectors of $L$.
- 4. Construct the matrix $F \in \mathbb{R}^{n \times k}$.
- 5. Treat each row of $F$ as $\mathbb{R}^k$, partition into clusters via $k$-means algorithm.

## 8.4 Normalized Clustering

In the literature, there are two versions of normalized Laplacian: $L_{sym}$ and $L_{rw}$. The former refers to symmetric, and the latter to random walk perspective. Close between these two will be discussed in this section.

### 8.4.1 Normalized Graph Laplacian

The variations of normalized Laplacian are defined as follows:

```
$L_{sym} = D^{-1/2}LD^{-1/2}$
$L_{rw} = D^{-1}L$
```

We list some properties of $L_{sym}$ and $L_{rw}$ below.

**Proposition 8.4.1** *The normalized graph Laplacian satisfies the following:*

- 1. For an arbitrary vector $f \in \mathbb{R}^n$, we have
$$f^T L_{sym}f = \sum_{i,j=1}^{n} W_{ij}(\frac{f_i}{\sqrt{d_i}} - \frac{f_j}{\sqrt{d_j}})^2 \quad (8.3)$$

- 2. $L_{sym}$ is symmetric and positive semidefinite.
- 3. The smallest eigenvalue of $L_{sym}$ is 0, with eigenvector $D^{1/2}\mathbf{1}$.
- 4. $L_{sym}$ has $n$ nonnegative, real-valued eigenvalues $0 = \lambda_1 \le \lambda_2 \le \dots \le \lambda_n$.

**Proof 2** We can verify the first property from the following equation:

```
$f^T L_{sym}f = f^T(D^{-1/2}LD^{-1/2})f = \sum_{i=1}^n \frac{f_i^2}{d_i} d_i - \sum_{i,j=1}^n \frac{f_i f_j W_{ij}}{\sqrt{d_i}\sqrt{d_j}}\n= \frac{1}{2}(\sum_{i=1}^n \frac{f_i^2}{d_i} + \sum_{j=1}^n \frac{f_j^2}{d_j} - 2\sum_{i,j=1}^n \frac{f_i f_j W_{ij}}{\sqrt{d_i}\sqrt{d_j}})\
= \frac{1}{2}\sum_{i,j=1}^n W_{ij}(\frac{f_i}{\sqrt{d_i}} - \frac{f_j}{\sqrt{d_j}})^2$
```

Since $Lf \ge 0$ and $D$ and $W$ are symmetric, $L_{sym}$ is symmetric and positive semidefinite. Property 3 can be proved directly by plugging the unit vector $D^{1/2}\mathbf{1}$ into Equation (8.3). Due to the fact that $L_{sym}$ is a real symmetric matrix, its eigenvalues should also be real numbers. Then property 4 is proved based on property 3.
