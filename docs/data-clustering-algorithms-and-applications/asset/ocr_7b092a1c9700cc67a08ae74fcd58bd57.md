> **Algorithm 40** Normalized Spectral Clustering [151]
**Input:** Similarity Matrix $S \in \mathbb{R}^{n \times n}$— number of clusters
Construct Similarity Graph (using a method from 17.8.2)
Let $W'$ be the weighted adjacency matrix
Calculate normalized Laplacian $L$
Compute first $k$ eigenvectors $l_1, l_2, \dots, l_k$ of the generalized eigenproblem $Lu = \lambda Du$
Let $U \in \mathbb{R}^{n \times k}$ be the matrix vectors $l_1, l_2, \dots, l_k$ as columns
Let $y_i \in \mathbb{R}^k$ be the $i$-th row of $U$ for $i = 1, 2, \dots, n$
Construct cluster points $y_i$ for $i=1, 2, \dots, k$, into $k$ clusters $C_1, C_2, \dots, C_k$ using $k$-means algorithm
**Output** clusters $A_1, A_2, \dots, A_k$ with $A_l = \{y_j | y_j \in C_l\}$

The following algorithm by Ng et al. [126] uses matrix $L_m$ instead of $L_{rw}$.

> **Algorithm 41** Normalized Spectral Clustering [126]
**Input:** Similarity Matrix $S \in \mathbb{R}^{n \times n}$— number of clusters
Construct Similarity Graph (using a method from 17.8.2)
Let $W'$ be the weighted adjacency matrix
Calculate normalized Laplacian $L_m$
Compute first $k$ eigenvectors $l_1, l_2, \dots, l_k$ of $L_m$
Let $U \in \mathbb{R}^{n \times k}$ be the matrix vectors $l_1, l_2, \dots, l_k$ as columns
Normalize rows of $U$ to obtain orthogonal matrix $T \in \mathbb{R}^{n \times k}$, i.e., $t_{ij} = u_{ij}/((\sum_k u_{ik}^2)^{1/2}$
Let $y_i \in \mathbb{R}^k$ be the $i$-th row of $U$ for $i = 1, 2, \dots, n$
Construct cluster points $y_i$ for $i=1, 2, \dots, k$, into $k$ clusters $C_1, C_2, \dots, C_k$ using $k$-means algorithm
**Output** $A_1, A_2, \dots, A_k$ with $A_l = \{y_j | y_j \in C_l\}$

The three spectral algorithms given are rather similar, differing only in their use of graph Laplacians. However, the critical part is the conversion of data points $x_i$ to points $y_i \in \mathbb{R}^k$, and the properties of graph Laplacians this change is useful.

# 17.9 Markov Clustering

Markov Clustering (MCL), proposed by Stij van Dongen, clusters graph by simulation of stochastic processes on a graph [45]. MCL is based on iterative application of two operations on the transition probability matrix or stochastic matrix graph: *Expand and Inflate*. *Expand(M)* is simply a matrix–matrix multiplication as follows:

```
$M_{Expand} = M \times M$
```

while Inflate(M,r) corresponds to raising each element of matrix $M$ to its $r$-th power and normalizing the columns to 1, $r$ is the *inflation parameter* ($r > 1$) and is typically set to 2.

```
$M_{Inflate}(i,j) = \frac{M(i,j)^r}{\sum_k M(k,j)^r}$
```
