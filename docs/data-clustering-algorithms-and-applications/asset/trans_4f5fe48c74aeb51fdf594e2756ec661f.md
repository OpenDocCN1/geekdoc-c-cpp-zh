### 12.4.2.3 LIMBO

LIMBO 通过构建一棵树来处理聚类问题，其中一个节点包含对应聚类成员对象的统计信息。新的对象以自上而下的方式添加到树中，通过找到最佳匹配并将其拆分为新节点，从而扩展树。LIMBO 采用熵和信息瓶颈（IB）框架来量化聚类时保留的相关信息 [16]。LIMBO 使用数据内存有界存储来扩展到大型数据集，改进了其他层次聚类算法的可扩展性。与 LIMBO 最相似的是 LOCOOL，一种非层次算法，也基于最小化，之前已提出。

LIMBO 使用分布聚类特征（DCF）对对象聚类进行总结。对于聚类 c，DCF(c) = (p(c), p(A(c)))，其中 p(c) 是聚类 c 的概率，p(A(c)) 是聚类 c 内属性的条件概率分布。DCF 用于计算聚类之间或聚类与对象之间的距离。LIMBO 算法分为三个阶段。第一阶段，构建 DCF 树以总结数据。第二阶段，将 DCF 树的叶 DCF 合并以产生一定数量的聚类。第三阶段，每个对象与对象最接近的 DCF 相关联。

阶段 1 通过开始并将一个或多个对象插入 DCF 树中来构建 DCF 树。创建一棵树，其中一个节点包含每个对象。对象 O 转换为 DCF(o)。然后，从根开始，在 DCF 树中向下追踪一条路径。当处于非叶节点时，计算 DCF(o) 和节点的每个 DCF，找到最接近 DCF(o) 的 DCF。此条目的子指针指向树的下一级。当处于叶节点时，DCF(c) 表示叶节点中最接近 DCF(o) 的 DCF。DCF(c) 是某个聚类 c 的总结。此时，决定 o 是否属于该聚类。如果叶中存在空叶（根据空间限制）包含 DCF(c)，则 DCF(o) 放置在该叶中。如果没有空叶并且有足够的空闲空间，则叶被拆分为两个叶。叶节点中最远的两个 DCF 用作新叶的种子。剩余的 DCF 和 DCF(o) 放置在包含最接近 DCF 的叶中。

阶段 2 聚类 DCF 树的叶。在构建 DCF 树之后，叶节点表示聚类 C 对象的 DCF。每个 DCF 对应于一个聚类 c ∈ C 并包含聚类概率 p(c) 的统计信息。凝聚信息瓶颈（AIB）算法用于聚类叶中的 DCF 并产生 DCF 的聚类。此算法阶段可应用任何聚类算法。

阶段 3 将对象与聚类关联。对于选定的 k 值，阶段 2 产生了 k 个 DCF。在最终阶段 3 中，对数据集进行扫描，将每个对象分配给其代表性 DCF 最接近该对象的聚类。

### 12.4.3 基于密度的聚类

基于密度的方法使用局部密度标准对分类数据进行聚类；聚类是对象密集且由低密度子空间分隔的子空间。基于密度的方法用于生物信息学中寻找网络中的子集，通常涉及团 [13, 18]。基于密度算法的优点包括时间效率高和能够找到任意形状的聚类。将基于密度聚类应用于数据集的挑战在于属性值的“立方体”没有定义顺序。一些基于密度的算法使用用户指定的输入参数，通常不需要聚类数量 k。它们有时会识别不同密度的聚类。对于基于密度算法，聚类的中心子空间无法根据更高的密度与聚类的其余部分区分开 [35, 38, 76]。一些基于密度的方法也是基于网格的，因为通过将数据集划分为若干个不重叠的区域来构建直方图。

## 数据聚类：算法与应用

### 12.4.3.1 投影（子空间）聚类

投影聚类由高维聚类激发，其中聚类仅存在于特定的属性子集中。子空间是高维数据集的子空间，由对每个聚类最相关的属性子集确定。聚类中对象的成员资格由相关属性的特定值范围定义，而其他聚类的对象不太可能具有此类值。投影（子空间）方法的缺点是聚类取决于用户参数来确定每个聚类的相关属性；聚类数量或每个聚类的平均维度数量。投影聚类可以根据相关属性的值的高频率区分聚类的中心 [4, 2, 3]。接下来，我们介绍几种子空间聚类算法。

### 12.4.3.2 CACTUS

CACTUS 是一种投影聚类方法，它假设聚类由一组独特的属性值标识，这些值在其他聚类中很少出现 [32]。它搜索定义聚类所需的最小相关属性集。

假设所有属性 $A_1, ..., A_m$ 都是独立的并且属性中的所有值都同样可能。然后，度量 $\sigma(a_i, a_j)$ 表示属性值 $a_i$ 和 $a_j$ 的共现（以及相似性）。如果它们的共现 $\sigma(a_i, a_j)$ 高于用户指定的因子 $\alpha > 1$ 在属性独立性假设下期望的值，则值 $a_i$ 和 $a_j$ 强烈连接。

属性 $\{A_1, ..., A_m\}$ 上的值集 $\{c_1, ..., c_k\}$ 是一个聚类，如果集合 $C$ 是一个强连接的属性值集。换句话说，应满足条件，即 $C$ 中的每对值都强连接并且它们的共现 $\sigma(c_i, c_j) > \alpha$ 对于 $i \neq j$。$C$ 也是一个子空间；如果 $\{A_1, ..., A_m\}$ 的一个属性中存在另一个值未包含在 $C$ 中，但与 $C=\{c_1,...\}$ 中的其他属性值强连接，则为子聚类。

CACTUS 算法在分类数据集上收集属性间摘要和属性内摘要。属性间摘要由所有连接的属性值对组成，每个属性值来自不同的属性。属性内摘要由同一属性的属性值之间的相似性组成。然后，CACTUS 算法包括三个阶段：汇总、聚类和验证。汇总阶段计算汇总信息以发现一组候选聚类。验证阶段从候选聚类集中确定实际的聚类集。

CACTUS 的一个缺点是聚类由一组独特的属性值标识，这些值在其他聚类中很少出现，这可能对聚类某些真实世界数据集来说不自然。CACTUS 也可能返回许多聚类 [76, 35, 38]。

### 12.4.3.3 CLICKS

CLICKS 是另一种子空间聚类方法，代表“通过多部分团对分类数据的子空间聚类”。CLICKS 创建数据集的图表示，其中节点是分类值，边是对象中值的共现。

CLICKS 将分类数据集 $D$ 建模为一个图，其中节点是属性值，形成不相交的集合，每个属性一个。不同分区之间的边表示密集关系。$k$-部分团是一个子图 $C$ 由两个不相交的节点集组成，其中每对都不同。$k$-部分团 $C$ 是最大 $k$-部分团，如果它没有 $k$-部分超集。$C$ 是密集的，如果在数据集中具有由 $C$ 定义的值的节点数量超过用户指定的阈值。

$k$-子空间 $C = \{x_1 \times \dots \times x_k\}$ 当且仅当它是 $D$ 中最大、密集且强连接的 $k$-部分团时，才是（子）团，使得大多数或节点对由边连接。

CLICKS 使用三步方法挖掘 $D$ 中的所有聚类。在预处理步骤中，它从输入数据库 $D$ 创建 $k$-部分团。在检测步骤中，它枚举图中的最大 $k$-部分团。此步骤的方法基于回溯策略，尝试扩展当前团以确保最大性。在后处理步骤中，它根据用户指定的阈值验证检测到的团的密度属性。最大团可能无法通过密度测试，而其子团之一可能是密集的。

缺点包括 CLICKS 可能返回太多聚类或太多离群值 [76]。

### 12.4.3.4 STIIR

STIR 代表“通过迭代强化筛选”。STIR 是一种迭代方法，用于在分类值上分配和传播权重；这允许基于数据集中值的共现的分类数据的相似性度量。STIR 寻找属性值之间的关系以检测潜在聚类，并收敛到不同分类属性字段之间高度相关的值的聚类 [34]。

分类属性中的每个可能值都由一个节点表示，数据表示为对象集 $D$ 的集合。每个对象 $o \in D$ 表示为一组节点，由每个属性的一个节点组成。STIR 为每个节点 $v$ 分配权重 $w_v$。权重配置称为 $w$。归一化函数 $N(w)$ 重新缩放与属性关联的节点的权重，使其平方和为一。

函数 $f$ 反复应用于一组节点 $u$，直到函数 $f$ 的不动点 $u$ 被达到，$f$ 将节点映射到新的配置。因此，目的是收敛到在 $f$ 的重复迭代下保持不变的点。$f$ 通过对包含值 $v$ 的所有对象（以及另外 $m-1$ 个值）应用算子 $\phi$ 并求和来更新节点 $v$ 的权重 $w_v$，如下所示：

```
for each object o = {u_1, \dots, u_{m-1}} that contains value $v$

w_v \longleftarrow \sum_{r} X_r$
```

算子 $\phi$ 可以是简单的乘法或加法算子。然后，函数 $f$ 使用 $N$ 归一化权重集。在 $f(w)$ 产生新配置的几次迭代之后，系统预计会收敛到 $f(w) = \mathbf{w}$ 的点。然后，具有大正权重的节点和具有负权重的节点表示数据集中分离且相互连接很少的密集区域，定义了聚类。
