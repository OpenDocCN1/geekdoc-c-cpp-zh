+   **10. Multi-layer NMF:** In multi-layer NMF, the basic factor matrix is replaced by a set of matrices using a sequential decomposition [22, 32, 23]. Given an input matrix $X$, it is first decomposed as $F_{(1)}G_{(1)}^T$. In the second step, $G_{(1)}$ is further decomposed into $F_{(2)}G_{(2)}^T$ and the process is repeated a number of times. The multi-layer NMF model can be represented as follows:

```
$X \approx F_{(1)}F_{(2)}\dots F_{(L)}G_{(L)}^T = FG^T. \quad (7.26)$
```

It has been shown that the multi-layer NMF can improve the performance of most NMF algorithms and address the problem of local minima in the distributed and multi-stage nature and the sequential decomposition with different initial conditions [24].

+   **11. Binary NMF:** When the input data $X$ is binary, binary NMF factorizes $X$ into two matrices thus conserving the most important property of $X$ [141, 140, 71]. The binary NMF model can be written as

```
Binary NMF: $X_0^{-1} \approx F_0G_0^{-1}. \quad (7.27)$
```

A special case of binary NMF is the boolean factorization

```
$X_0^{-1} \approx W_0 \oplus H_0^{-1}. \quad (7.28)$
```

+   **12. Weighted Feature Subset NMF:** In weighted NMF, weights are incorporated to indicate the importance of the corresponding rows and columns. If we consider only the importance, this leads to the weighted subset NMF (FS-NMF):

```
$$\min_{W \ge 0, G \ge 0} ||X-FG^T||_W^2, \sum_j W_j^a = 1, \quad (7.28)$
```

where $W \in \mathbb{R}^{m \times m}$ is a diagonal matrix indicating the weights of the rows (or features) in $X$, and $\alpha$ is a parameter [116, 117]. In general, we can assign weights to different samples. This leads to the weighted FS-NMF:

```
$$\min_{W \ge 0, G \ge 0} ||X-FG^T||_W^2$
```

where we set $W_{ij} = a_{ij}b_j$.

```
$$\min_{W \ge 0, G \ge 0} (X-FG^T)_{ij}^2 a_{ij}b_j, s.t. \sum_i a_{ij}^a = 1, \sum_j b_j^b = 1, \quad (7.29)$
```

where $\alpha, \beta$ are two parameters with $0 < \alpha < 1, \beta < 1$.

+   **13. Robust NMF:** Recently a robust NMF using $L_{2,1}$-norm loss function has been proposed in [63]. The error function is

```
$||X-FG^T||_{2,1} = \sqrt{\sum\sum (X-FG^T)_{ij}^2}, \quad (7.30)$
```

The proposed robust NMF can handle outliers and noises in a better way than standard NMF.
