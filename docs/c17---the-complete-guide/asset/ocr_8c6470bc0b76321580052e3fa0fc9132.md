# # 14.3 Afternotes

Comma-separated using declarations were proposed by Robert Haberlach in http://wg21.link/p0195r0. The finally accepted wording was formulated by Robert Haberlach and Richard Smith in http://wg21.link/p0195r2.

Various core issues asked for clarification of inheriting constructors. The finally accepted wording to fix these issues was formulated by Richard Smith in http://wg21.link/n4429.

There is a proposal by Vicente J. Botet Escriba to add a generic overload function to overload lambdas but also ordinary functions and member functions. However, the paper did not make it into C++17. See http://wg21.link/p0051r1 for details.
