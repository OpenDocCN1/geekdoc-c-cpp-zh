```
s2.printN();

S<(v)> s3;    // deduces N as int& referring to v
v = 77;
s3.printN();  // prints: N: 77
}
```

# 13.4 Afternotes

Placeholder types for non-type template parameters were first proposed by James Touton and Michael Spertus as part of http://wg21.link/n4469. The finally accepted wording was formulated by James Touton and Michael Spertus in http://wg21.link/p0127r2.
