# Parallelization for Non-Associative Operations

Let us now change the operation to accumulate values by always adding the square of each value:

```
#include <iostream>
#include <vector>
#include <numeric> // for accumulate()
void printSum(long num)
{
 // create coll with num sequences of 1 2 3 4:
 std::vector<long> coll;
 coll.reserve(num * 4);
 for (long i=0; i < num; ++i) {
 coll.insert(coll.end(), {1, 2, 3, 4});
 }
}
```
