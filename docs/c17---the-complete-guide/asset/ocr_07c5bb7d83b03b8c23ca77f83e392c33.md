```
int main()
{
    auto p = new MyType32;
    ...
    delete p;
}
```

As stated, since C++17, you can skip the overhead of implementing operations to allocate/deallocate aligned data. The example works well even without defining operator new() and operator delete() for your type:

lang/alignednew17.cpp

```
#include <string>

struct alignas(32) MyType32 {
    int i;
    char c;
    std::string s[4];
    ...
};

int main()
{
    auto p = new MyType32;  // allocates 32-byte aligned memory since C++17
    ...
    delete p;
}
```
