# ## Container and String Extensions

There are a couple of minor or small changes to the standard containers of the C++ standard library, which are described in this chapter.



+   - Modify keys of (unordered) maps or values of (unordered) sets
+   - Use move semantics in (unordered) sets and maps
+   - Move elements between (unordered) sets and maps
+   - Merge elements from one (unordered) set or map into another



For example, consider the following program:

```
```cpp
#include <iostream>
#include <string>
#include <map>

int main()
{
    std::map<int, std::string> m{1, "mango"},
    {2, "papaya"},
    {3, "guava"}};

auto nh = m.extract(2); // nh has type decltype(m)::node_type
nh.key() = 4;
}
