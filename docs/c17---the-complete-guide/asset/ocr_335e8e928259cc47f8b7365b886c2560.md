+   - For strings, polymorphic memory resources are now supported, which means that you can declare:
+     ```
+     std::pmr::string s1;
+     std::pmr::wstring s1;
+     std::pmr::u16string s1;
+     std::pmr::u32string s1;
+     ```
+     See the PMR chapter for details.

# 26.5 Afternotes

Node handles were first proposed indirectly by Alan Talbot requesting splice operations as library issue http://wg21.link/lwg839 and by Alisdair Meredith requesting move support for node elements as library issue http://wg21.link/lwg1041. The finally accepted wording was formulated by Alan Talbot, Jonathan Wakely, Howard Hinnant, and James Dennett in http://wg21.link/p0083r3. The API was slightly clarified as a final version by Howard E. Hinnant in http://wg21.link/p0508r0.

The new return value for the emplace member functions was first proposed by Alan Talbot in http://wg21.link/p0084r0. The finally accepted wording was formulated by Alan Talbot in http://wg21.link/p0084r2.

insert_or_assign() and try_emplace() for (unordered) maps was first proposed by Thomas Köppe in http://wg21.link/n3873. The finally accepted wording was formulated by Thomas Köppe in http://wg21.link/n4279.

Container support for incomplete types was first discussed by Matt Austern in http://drdobbs.com/184403814 and first proposed by Zhihao Yuan in http://wg21.link/n3890. The finally accepted wording was formulated by Zhihao Yuan in http://wg21.link/n4510.

data() for strings was first proposed by Michael Bradshaw as library issue http://wg21.link/lwg2391. The finally accepted wording was formulated by David Sankel in http://wg21.link/p0272r1.
