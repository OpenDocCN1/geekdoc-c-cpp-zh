# 33.4 Afternotes

std::invoke<> () was first proposed by Tomasz Kaminski in http://wg21.link/n3727. The finally accepted wording was formulated by Tomasz Kaminski in http://wg21.link/4169. Its return type later changed using the invoke_result<> type trait as proposed by Daniel Krügler, Pablo Halpern, Jonathan Wakely in http://wg21.link/p0604r0.

std::bool_constant<> was first proposed by Zhihao Yuan in http://wg21.link/n4334. The finally accepted wording was formulated by Zhihao Yuan in http://wg21.link/n4389.

std::void_t<> was adopted as proposed by Walter E. Brown in http://wg21.link/n3911.
