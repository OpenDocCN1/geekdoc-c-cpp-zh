```
std::clamp<double>(d, 0, max);  // OK
```

You can also pass floating-point values provided they do not have the value NaN.

Just like for min() and max(), you can pass a predicate as a comparison operation. For example:

```
for (int i : {-7, 0, 8, 15}) {
    std::cout << std::clamp(i, 5, 13,
        [] (auto a, auto b) {
            return std::abs(a) < std::abs(b);
        })
        << '\n';
}
```

has the following output:

-7
5
8
13

Because the absolute value of -7 is between the absolute values of 5 and 13, clamp() yields -7 in this case.

There is no overload of clamp() taking an initializer list of values (as min() and max() have).
