# 31.2 Example Usage

For integral values, you can pass a base for the value read as an optional last argument. The base might be between 2 and 26 (inclusive). For example:

```
```cpp
#include <charconv>

const char* str = "12 monkeys";
int value;
std::from_chars_result res = std::from_chars(str, str+10, value, 16); // char sequence to read from
value, // value to set
16); // optional base
```

# 31.2.2 to_chars()

std::to_chars() converts numeric values into a given character sequence. For example:

```
```cpp
#include <charconv>

int value = 42;
char str[10];
std::to_chars_result res = std::to_chars(str, str+9, value);
*res.ptr = '\0'; // ensure a trailing null character is behind
```
```

After a successful conversion, str contains the character sequence that represents the passed value (42 in this example) without a trailing null character.

Again, for integral values, you can pass a base for the value read as an optional last argument. The base might be between 2 and 26 (inclusive). For example:

```
```cpp
#include <charconv>

int value = 42;
char str[10];
std::to_chars_result res = std::to_chars(str, str+9, value, 16); // char sequence to write to
value, // value to convert
16); // optional base
```
```
