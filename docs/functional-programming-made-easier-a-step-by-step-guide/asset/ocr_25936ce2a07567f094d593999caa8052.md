Next, we’ll subscribe to the Emitter using H.subscribe. This returns the SubscriptionId so we can unsubscribe if we choose.

Subscription are automatically unsubscribed by Halogen when a Component is Finalized. But in our code, we’re going to want to unsubscribe once the CountdownTimer has reached 0. If we didn’t care about the SubscriptionId, we could’ve called the Prime version of this Function, H.subscribe'.
