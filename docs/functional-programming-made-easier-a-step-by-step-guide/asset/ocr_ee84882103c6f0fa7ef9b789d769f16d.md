But writing out Types isn’t really that hard. We were just being lazy and now we’ve spent more time than if we would have just started with the second approach first.

So now, we’ll write out the pertinent Types:

```
f :: a -> Reader r b ①
fx :: r -> a ②
fx r :: a ③
f $ fx r :: Reader r b ④
Reader \r -> f $ fx r :: Reader r (Reader r b) ⑤
whatWeWant :: Reader r b ⑥
```

+   ① The Monadic Function that bind gets as its second Parameter. How do we know this Type? Because bind always gets a Monadic Function as its second Parameter, i.e. a Function of Type a -> m b, where m is Reader r.

+   ② The Function we unwrapped from the Reader in bind’s first Parameter.

+   ③ Applying r to fx to get the Value out.

+   ④ Applying the Monadic Function to our extracted Value.
