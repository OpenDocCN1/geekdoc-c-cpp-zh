```
import Effect.Aff ( Aff, Fiber,
    delay, killFiber, launchAff_, forkAff, runAff)

test :: Effect Unit
test = do
  fileReader <- runAff case _ of
    Left err -> log $ show err
    Right result -> log $ "File contents: " <> show result
    $ readAFileAfterTwoSeconds
  launchAff_ do
    logger <- forkAff logEverySecond
    delay (Milliseconds 5000.0)
    kill logger
    kill fileReader
```

① We need to add runAff.

② Added a do for the Effect Monad.

③ We must call runAff from Effect, which is why it’s done outside launchAff_’s do block.

④ We’re using a wildcard in the case expression, which is the Error passed to runAff’s first Parameter, a Function, which is the exit handler for the Fiber.

⑤ The second Parameter to runAff is the code that will run in the Aff Monad. In this case, readAFileAfterTwoSeconds.
