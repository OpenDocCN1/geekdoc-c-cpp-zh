```
```haskell
some :: V e a. Parser e a -> Parser e (Array a)
some p = (:) <$> p <*> many p
```
```

We first map the `Cons` Operator over the `Parser`, `p`, and then apply the `many p Parser`, which should contain an `Array a`. Well, it will once we write it.

This is a classic usage of Applicative Parsing. But as a review let’s break it down a bit by writing the Types:

```
```haskell
(:) :: a -> Array a -> Array a
p :: Parser e a
(:) <$> p :: Parser e (Array a -> Array a)
many p :: Parser e (Array a)
(:) <$> p <*> many p :: Parser e (Array a)
```
```

+   1. `(:)` gets its first Parameter from `p`, i.e. a Value of Type `a`, leaving a Function of Type `Array a -> Array a` in the resulting `Parser`.
+   2. `(<$>) p` gets its first Parameter from `many p`, i.e. a Value of Type `Array a`, leaving a Value of Type `Array a` in the resulting `Parser`.

Now, we’re ready to write `many`. From the above definitions, `many` is a choice between `some` and none, which says that we’ll be using the `<|>` Operator in the implementation. But first the Type Signature:

```
```haskell
many :: V e a. Parser e a -> Parser e (Array a)
```
```

And now the implementation:

```
```haskell
many :: V e a. Parser e a -> Parser e (Array a)
many p = some p <|> pure []
```
```

With `many`, either there are `1 or more` characters (`some`) that can be parse or there are none, i.e. `many` is `0 or more`.

We now have exactly what we expected, Mutual Recursion:

```
```haskell
some :: V e a. Parser e a -> Parser e (Array a)
some p = (:) <$> p <*> many p

many :: V e a. Parser e a -> Parser e (Array a)
many p = some p <|> pure []
