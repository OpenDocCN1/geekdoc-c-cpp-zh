![](bbox=[0.23, 0.06, 0.77, 0.15])

We now have a local Function called log, which conflicts with the log we’re importing from the Event.Console module.

To fix this ambiguity, we’ll fully qualify the import of that Module:

```
import Effect.Console as Console ①
```

① Notice that the import list that included log is missing and the as clause has been added to create an alias for the module that we’re calling Console.

And now, we’ll have to change the calls to the Console log in our test code:

```
test :: Effect Unit
test = do
  result1 <- runApp 0 app
  Console.log $ show result1 ①
  result2 <- runApp 99 app
  Console.log $ show result2 ①
```

① Use the fully qualified name for log.
