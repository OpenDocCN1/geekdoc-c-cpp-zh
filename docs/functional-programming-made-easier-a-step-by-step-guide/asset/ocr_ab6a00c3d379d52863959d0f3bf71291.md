Naming is really hard but if we can think about what this Function does, we may come up with a better name for it.

When we look at the Type Signature for this Function, we can see that our input Type is m (Either e a) and our output Type is t m a. Notice that the e is missing. That’s because the error case, i.e. the e, is thrown inside of liftEither.

We are only getting the success case back here. And because of that fact, I’m going to rename this Function, liftSuccess. This isn’t a perfect name, but is far better than my first name since it doesn’t have Except and it conveys that we’re working with the success case, i.e. NOT the e but the a:

```
liftSuccess
  :: ∀ e a m t
  . MonadError e (t m)
  => Monad m
  => MonadTrans t
  => m (Either e a)
  -> t m a
liftSuccess ma = ma # lift >>= liftEither
```
