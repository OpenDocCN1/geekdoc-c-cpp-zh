```
module Ch17

( Age (..) ①
, FamilyAges ②
, FamilyAgesRow ③
, Validation ④
, createFamilyAges ⑤
, test ⑥
) where ⑦
```

① Without this we’ll get a compiler error telling us that to export FamilyAgesRow, we also need to export Age. We export both the Type Constructor and Data Constructor using (..).

② We ONLY export out the Type Constructor, which means you cannot construct the Type directly.

③ We export the Type Alias FamilyAgesRow.

④ Without this, the compiler will complain that we also need to export Validation. This is because no one could use createFamilyAges if they cannot refer to the Validation Type since that’s what createFamilyAges returns. Notice we’ve chosen to NOT export the Validation Data Constructor. We may want to do this later, but for now we’ll leave this.

⑤ We export our Smart Constructor so that we can "safely" construct FamilyAges.

⑥ We export test so our main can still call the test code.

⑦ Notice the location of the where keyword which, so far, directly followed the module name. This is because we haven’t explicitly exported anything yet. In those cases, everything is exported from our module. In this case, only what’s listed is exported.
