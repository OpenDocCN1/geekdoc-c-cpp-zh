Notice, in foldr, our Accumulator, acc, is on the Right of the Parameter list and on the Right of the Binary Operator, −.

Also, notice, in foldl, acc is on the Left of the Parameter list and on the Left side of −.

This is how we accomplish the appropriate Associativity. And this is also why the function that is passed to foldr is the flipped version of the function that’s passed to foldl:

```
foldr :: ∀ a b. (a -> b -> b) -> b -> f a -> b
foldl :: ∀ a b. (b -> a -> b) -> b -> f a -> b
```

Remember, flip swaps the first 2 Parameters of a function.
