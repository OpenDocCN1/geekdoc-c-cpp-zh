```
# 5.35. Writing `drop`

`drop` differs from `take` in what it returns. Like, `take` it will remove the specified number of elements, but instead of giving you elements the elements taken, it returns the remaining elements. So the following is true:

```
```purescript
nums = (1 : 2 : 3 : 4 : 5 : 6 : 7 : Nil)
take 2 nums == (1 : 2 : Nil)
drop 2 nums == (3 : 4 : 5 : 6 : 7 : Nil)
```
