When we don’t have a logged on user AND we try to route to Logon, this logic will ignore that request and try to route us to Logon AGAIN. That second route will NOT trigger matchesWith when we’re already on Logon.

This is our problem.

When no one is logged on, we want to ignore where we JUST navigated to and force a navigate to Logon EXCEPT when we just navigated to Logon:

```
handleQuery = case _ of
  Navigate route a -> do
    { userRef } <- ask
    ref <- H.liftEffect $ Ref.read userRef
    if isNothing ref && route /= Logon then navigate Logon ①
    else H.modify_ _ { route = route }
    pure (Just a)
```

① We will ONLY navigate to Logon if there’s no logged on user AND we didn’t just navigate to Logon.
