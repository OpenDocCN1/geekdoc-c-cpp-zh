And the final field in Response is body which is of Type a. That’s the payload we requested, i.e. the response of the HTTP Request.

Now we’re ready to make our request. Let’s revisit the get Type Signature:

```
get :: ∀ a. ResponseFormat a -> URL -> Aff (Either Error (Response a))
```

First thing we’ll need is a ResponseFormat. We want a to be Json so, we’re going to look on the same Pursuit page as ResponseFormat to see if there’s a canned Function for this.

And it turns out that there is:

```
json :: ResponseFormat Json
```
