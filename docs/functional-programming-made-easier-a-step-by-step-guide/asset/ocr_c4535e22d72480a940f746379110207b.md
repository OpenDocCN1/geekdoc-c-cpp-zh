Let’s write apply in terms of bind since apply is typically the most difficult to implement when compared to Functor and Bind.

First, we start with the instance definition:

```
instance applyMaybe :: Apply Maybe where
```

And now the right side of the equal sign:

```
instance applyMaybe :: Apply Maybe where
  apply mf mx = ??? ① ②
```

① mf is the Function, f, in the Context, m, hence the name mf.

② mx is the Value, x, in the Context, m, hence the name mx.

At this point, our strategy should be to first extract the Function, f, from the Context, then call it with mx using bind.

Remember, when we first talked about apply, we decided that since its operator is Left-Associative, we should extract the Function first.

First, we’ll extract the Function using >>=:

```
instance applyMaybe :: Apply Maybe where
  apply mf mx = mf >>= \f -> ???
```
