We can see that `CreateUser` is marked on 2 Arrows. One from the API Handler to the Account Manager and one from the API Handler to the Account Handler.

The Account Handler will need to APPEND a record of the new `Account` to accounts.csv. And the Account Manager will need to add the new `User` to the accountsVar.

Let’s look at the differences between `Account` and `User` again:

```
```fsharp
type UserRow r =
  ( userName :: String
  , temporaryPassword :: Boolean
  , admin :: Boolean
  , firstName :: String
  , lastName :: String
  | r)

newtype User = User (Record (UserRow ()))

newtype Account = Account (Record (UserRow ( passwordHash :: String )))
```
```

So, `Account` is everything a `User` is plus a `passwordHash`.
