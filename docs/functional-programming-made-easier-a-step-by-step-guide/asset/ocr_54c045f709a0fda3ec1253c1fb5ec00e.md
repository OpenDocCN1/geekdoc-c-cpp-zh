# 23.2.2. Making a Monad Stack

The specifications stated that we need to have a StateT and a ReaderT but it didn’t specify exactly what for. So, let’s add that now.

+   - A read-only structure will be passed to all Fibers that contains the read-write Bus.

+   - Each Fiber will have a State that contains a count of how many Random Numbers to generate before exiting.

These specifications are a pretty terrible design, but are here only to help us flex our muscles.

First, create a Type Alias called Config that contains the Bus before reading further. This will be what ReaderT passes to every Function.

Here’s the Type Alias for Config:

```
import Effect.Aff.Bus (BusRW) ① ②

type Config = { bus :: BusRW String } ③ ④
```

① Import BusRW.

② Need to add aff-bus to spago.dhall.

③ BusRW is a bidirectional bus, i.e. we can read and write to it. This is just easier since both Publishers and Subscribers are going to get this.

④ String is the Type of the Values that will be written to the Bus.
