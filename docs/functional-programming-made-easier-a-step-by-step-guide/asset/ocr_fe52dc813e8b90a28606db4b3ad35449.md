See the 2 places `Teacher` shows up? That’s because the compiler has no way to know that we wanted a’s in those positions.

It only knows how we’ve used it and, in this case, we’ve used it with a `Teacher`. When the compiler is inferring the Types for our first usage of `processJSON`, it doesn’t know that we’re going to use it with a totally different Type later in the code.

Because the inference process is localized like this, the compiler has **overspecialized** the Type.
