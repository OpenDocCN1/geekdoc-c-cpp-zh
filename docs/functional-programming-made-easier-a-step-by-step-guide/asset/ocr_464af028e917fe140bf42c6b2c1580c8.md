# 30.7. Page Component

We’re going to want to build a common Page Component that will contain the header of our application with an always present Logoff button.

We’re going to build it as a Container for any Page Component, e.g. the Logon Page. It will forward all Inputs it receives to the Inner Component. It will also forward any Output it gets from the Inner Component to the Page Component’s Parent.
