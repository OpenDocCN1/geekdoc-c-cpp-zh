unzip :: ∀ a b. List (Tuple a b) -> Tuple (List a) (List b)

unzip (Tuple x y : ts) =
  unzip ts # (Tuple xs ys) -> Tuple (x : xs) (y : ys) ❶ ❷
```

+   ❶ We pull off the head of the `List` destructuring it in the process into x and y.

+   ❷ We call `unzip` on the tail and pass the result to a Lambda that destructures the `Tuple` to get the individual `Lists`. Finally, we add our x and y to the head of their respective `Lists` wrapping the final result into a `Tuple`.
