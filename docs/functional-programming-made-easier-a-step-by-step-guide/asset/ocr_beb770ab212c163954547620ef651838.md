When we code in this Stack, we are still coding at the top most level, i.e. at the `StateT` level:

```
```haskell
app :: ∀ s r. StateT s (ReaderT r (WriterT String Identity)) Unit ❶

  tell ""
  pure unit

```

> ❶ Our Stack definition has changed from the previous example.

Just like before, when `tell` is called, it’s handled by `StateT`’s instance, which `lifts` the `tell` function of it’s underlying `Monad`, which, in this case, is `ReaderT`.

Now our `ReaderT` instance, i.e. the one that we’re trying to code, will be used. And it’ll need to do the same thing as `StateT`’s instance, i.e. `lift` the `tell` implementation from its underlying `Monad`, which, in this Stack, is `WriterT`.

So, we can safely code `ReaderT`’s `tell` to assume that `WriterT` or some other `Monad` that acts like `WriterT` is BELOW it somewhere in the Stack.
