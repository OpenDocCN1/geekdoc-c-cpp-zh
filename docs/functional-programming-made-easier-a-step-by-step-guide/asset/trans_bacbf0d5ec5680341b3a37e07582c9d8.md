## 7.8. 为Maybe实现Ord的代码

首先编写实例定义：

```
instance ordMaybe :: Ord a => Ord (Maybe a) where
```

我们约束a也必须有Ord实例，就像之前为Eq所做的那样，以便比较两个Just。

接下来，我们编写平凡情况：

```
instance ordMaybe :: Ord a => Ord (Maybe a) where
  compare Nothing Nothing = EQ
```

现在来看Just的情况：

```
instance ordMaybe :: Ord a => Ord (Maybe a) where
  compare Nothing Nothing = EQ
  compare (Just x) (Just y) = ??? ①
```

① 我们不能像在Eq中那样使用运算符。

因此，问号处是我们停下来思考如何比较底层值x和y的地方。在Eq类型类中，我们使用了==运算符。我们当然也可以使用<和>运算符：

```
instance ordMaybe :: Ord a => Ord (Maybe a) where
    compare Nothing Nothing  = EQ
    compare (Just x) (Just y) =
        if x > y then GT else if y < x then LT else EQ ①
```

① 在第一个else下嵌套的if。

但这没有必要，因为大于和小于运算符本来就是基于compare实现的。稍后我们编写>=代码时会看到这一点。

所以，我们干脆避免中间人，直接使用compare：

```
instance ordMaybe :: Ord a => Ord (Maybe a) where
    compare Nothing Nothing  = EQ
    compare (Just x) (Just y) = compare x y ①
```

① 注意，x和y的顺序与Just x和Just y的顺序一致。

最后，我们处理比较Nothing和Just的两种情况：

```
instance ordMaybe :: Ord a => Ord (Maybe a) where
    compare Nothing Nothing  = EQ
    compare (Just x) (Just y) = compare x y
    compare Nothing _        = LT ①
    compare _ Nothing        = GT
```

① 请记住，我们先定义了Nothing数据构造器，然后才定义Just数据构造器，因此Nothing小于Just a，反过来，Just a大于Nothing。这遵循了编译器在派生Ord时使用的规则。

## 7.11. 编写>=的代码

我们先从类型签名开始：

```
greaterThanOrEq :: ∀ a. Ord a => a -> a -> Boolean
```

接下来是实现：

```
greaterThanOrEq :: ∀ a. Ord a => a -> a -> Boolean
greaterThanOrEq x y = ??? ①
```

① 我们知道这应该以某种方式利用compare。

我们知道compare返回LT、GT和EQ。我们要做的就是调用compare，然后检查结果是GT还是EQ：

```
greaterThanOrEq :: ∀ a. Ord a => a -> a -> Boolean
greaterThanOrEq x y = cmp == GT || cmp == EQ where cmp = compare x y ① ②
```

① 我们需要将(||)添加到我们的Prelude导入列表中。

② 我们在这里使用where，这样就不必真正调用compare两次。

最后，我们只需要添加运算符别名，回顾Pursuit文档以查看结合性和优先级。

```
infixl 4 greaterThanOrEq as >= ① ②
```

① 我们需要从Prelude导入列表中移除(>=)，因为我们要定义自己的运算符。

② 结合性是左结合，所以我们使用infixl，优先级是4。

## 7.13. 为Maybe实现Show的代码

首先编写实例定义行：

```
instance showMaybe :: Show (Maybe a) where
```

接下来，我们编写平凡情况下的show方法，即Nothing的情况：

```
```haskell
instance showMaybe :: Show (Maybe a) where
  show Nothing = "Nothing"
```
```

最后，我们编写`Just`的情况：

```
```haskell
instance showMaybe :: Show (Maybe a) where
  show Nothing = "Nothing"
  show (Just x) = "(Just " <> show x <> ")" -- COMPILER ERROR! ❶ ❷
```
```

- 1. 我们需要将 `(<>)` 添加到我们的 `Prelude` 导入列表中。
- 2. 显示 `x` 是个问题。你能想到为什么吗？

这是编译器错误：

![](img/8c0e9b687c62642e828ccb5481e11313_288_0.png)

请注意，在编辑器中 `show x` 被加了下划线，编译器错误提示 `a1`（对应于我们 `Maybe a` 中的 `a`）没有 `Show` 实例。

我们让编译器显示 `x`，但 `x` 可以是任意 `a`。然而，它不能是任意 `a`，它必须是一个可显示的 `a`。所以我们要添加那个约束：

```
```haskell
instance showMaybe :: Show a => Show (Maybe a) where ❶
  show Nothing = "Nothing"
  show (Just x) = "(Just " <> show x <> ")"
```
```

- 1. 我们在 `a` 上添加了一个约束，要求它也是可显示的。

现在，`a` 不仅仅是任意 `a`，而是任意同时具有 `Show` 实例的 `a`。
