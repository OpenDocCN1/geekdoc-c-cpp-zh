```
# 3.5.2. Operator Sections

Wildcards can also be used in *Operator Sections*:

```
```purescript
filter (\\x -> x < 10) [1,2,3,10,20,30] -- [1,2,3]
filter (_ < 10) [1,2,3,10,20,30] -- [1,2,3]
filter (10 <= _) [1,2,3,10,20,30] -- [10,20,30]
```
```

+   1. This is our filter Function call from above that uses a Lambda.
+   2. This is using an Operator Section with the Wildcard as the left side of the Operator. This is equivalent to the previous Function call.
+   3. The is using the Wildcard on the other side of the Operator.

> Operator Sections are Binary Operators with one or two Wildcard variables set off by Parentheses.

The following are also a valid Operator Sections:

```
```purescript
(_ <> "suffix")   -- append the string "suffix"
(_ / 10)          -- div by 10
(10 / _)          -- div into 10
(_ == _)          -- equal check
```
```

+   1. These Functions take 1 Parameter.
+   2. This Function takes 2 Parameters.
```
