The compiler can’t match Json with String. What should we do next?

If you’re not sure, then ask the question, how does the compiler know what type body is?

It gets it from Response:

```
type Response a =
  { status :: StatusCode
  , statusText :: String
  , headers :: Array ResponseHeader
  , body :: a
  }
```

And now, look at the Type Signature for processAjaxResult to see if you can find where we specify Response.

Can you see that we specified String as the a for Response? That’s because we were using decodeJSON, but we changed over to decodeJson, which wants a Json.
