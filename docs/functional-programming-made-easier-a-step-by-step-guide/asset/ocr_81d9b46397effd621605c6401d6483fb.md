```
tu :: Maybe String
tu = genericTail (codePointFromChar 'c') "abc" ①
```

① element is now CodePoint. This exemplar lets the compiler know that we want it to use the instance, decapitateStringUnicode.

This is definitely a hacky way, but it works. But can we do better than this?

Seems that we’re just picking a random value just to define the Type for element. There’s got to be a cleaner way of doing this without picking a random value. While this isn’t a big deal when we’re talking about providing a Primitive Type, it’s a completely different story when our type is a complex, nested Record. Coming up with such a Record would not be trivial.

As it turns out, there is a cleaner way to communicate to the compiler what Type our element should be:

```
import Type.Proxy (Proxy) ①

genericTail
  :: ∀ collection element
  . Decapitate collection element
  => Proxy element ②
  -> collection
  -> Maybe collection
genericTail _ xs = case (decapitate xs :: Maybe {head :: element, tail :: collection}) of ③
  Just { tail } -> Just tail
  Nothing -> Nothing
```

① Proxy is in its own package, purescript-proxy, which means proxy needs to be added to your Dependencies in spago.dhall.

② We don’t have to pick some random value anymore. We just have to provide a Proxy for the Type.

③ We still disregard the Proxy argument.

We can now provide a Proxy of the appropriate Type:

```
import Type.Proxy (Proxy(..)) ①

t :: Maybe String
t = genericTail (Proxy :: Proxy Char) "abc"

tu :: Maybe String
tu = genericTail (Proxy :: Proxy CodePoint) "abc"
```
