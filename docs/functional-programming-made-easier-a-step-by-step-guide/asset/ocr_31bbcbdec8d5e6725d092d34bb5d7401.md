Go ahead and model the Records with reversed field names, i.e. Personal, Student and Teacher. Name the new Type Aliases, ReversedPersonal, ReversedStudent and ReversedTeacher.

Do this before reading on.

Here are those new Type Aliases:

```
type ReversedPersonal =
  { thgieh :: Centimeters

  { edarg :: Grade

  }

  { sedarg :: Array Grade

  }
```
