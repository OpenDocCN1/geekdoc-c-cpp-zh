## 第8章 抽象代数

函数式编程大量借鉴了数学中的许多概念。其中一个领域就是范畴论。我们将在讨论函子、应用和单子时看到这一点。

### 8.1. 二元运算符

作为快速回顾，让我们看一下二元运算符。单词Binary（二元）意为2。这个2代表2个参数。Operator（运算符）是一个暗示特定函数的符号，例如`+`：

```
12 + 73
```

这里的2个（二元）参数是12和73。`+`（运算符）是数值加法。

以下是我们都应该非常熟悉的一些二元运算符的更多示例：

```
+
-
*
/
&&
||
```

二元运算符通常以中缀形式书写，在编程中如此，在数学中总是如此：

```
1 + 3
51 - 19
4 * 43
100 / 20
true && false
false || true
```

### 8.1.1. 结合律

如果一个二元运算符•满足以下条件，则它是结合的：

```
a • (b • c) = (a • b) • c ①
```

> ① 括号用于结合。在左侧，括号将b与c结合，在右侧，它将a与b结合。

如果你将括号视为将运算符与其参数结合的机制，就能记住这意味着什么。

这里我们使用符号•来代表**任何**二元运算符。可以是加法、乘法或逻辑与。

当一个二元运算符是结合的时，我们可以随意重新排列括号，结果相等：

```
((a • b) • c) • d   =
 (a • (b • c)) • d   =
 (a • b) • (c • d)   =
  a • (b • (c • d))  = ...
```

我们对结合运算符太熟悉了（运算顺序无关紧要）：

```
(1 + 3) + 47 = 1 + (3 + 47)
2 * (17 * 54) = (2 * 17) * 54
```

我们对非结合运算符同样熟悉（运算顺序很重要）：

```
1 / (3 / 5) /= (1 / 3) / 5
(17 - 42) - 3 /= 17 - (42 - 3)
```

### 8.1.2. 交换律

如果一个二元运算符•满足以下条件，则它是交换的：

```
a • b = b • a ①
```

① a和b交换或穿过二元运算符，结果不变。

同样，我们在算术中见过许多交换运算符的示例：

```
1 + 10 = 10 + 1
3 * 25 = 25 * 3
```

以及非交换运算符：

```
1 - 10 /= 10 - 1
3 / 25 /= 25 / 3
```

### 8.2. 封闭性

在编程中，Closure（闭包）一词的含义与数学中的含义截然不同。

让我们研究一下数学定义。

取以下集合：

```
{ true, false }
```

让我们将二元运算符`&&`应用于集合元素的所有组合：

```
true  && true  = true
true  && false = false
false && true  = false
false && false = false
```

注意，结果总是我们集合中的一个值。当这种情况发生时，我们说该集合在`&&`运算下是封闭的。

再取另一个集合：

```
{ 1, 2, 3 }
```

这个集合在二元运算符`+`下封闭吗？

不，不封闭，因为`3 + 3 = 6`，而6不在集合中。

那减法呢？乘法呢？或除法呢？

事实证明，这些问题的答案都是否定的。

让我们考虑集合：

```
{ 1, 2, 3, ... }
```

> 正整数集合。

这个集合在二元运算符`+`下封闭吗？

是的。任意两个正整数相加产生一个正整数。

那减法、除法或乘法呢？

减法和除法不封闭，例如`1 − 3 = −2`和`1 / 3 = 1/3`。

但这个集合在乘法下封闭，因为任意两个正整数相乘是一个正整数。

### 8.3. 原群

Magma（原群）是一种红色的、炽热的液态岩石。但它也是一种抽象代数结构。它可以说是我们这里讨论的所有内容的基础。我们将研究的其他代数结构都建立在此之上。

> 一个*原群*是一个在二元运算符下封闭的集合。

以下是一个原群的示例：

```
`M = { true, false } and • = &&`
```

集合**M**是所有**布尔值**的集合，二元运算符**•**是**逻辑与**运算，**&&**。

以下是一个不是原群的示例：

```
`X = { 0, 1, 2, 3, ... } and • = −`
```

我们之前已经看到，减法在正整数集合上不封闭。对于包括0的自然数集合也是如此。

以下是原群的正式定义，使用数学符号：

```
`∀ a, b ∈ M  ⇒  a • b ∈ M`
```

其中M是原群的集合。

由于数学是一种具有自身语法且我们可能不太熟悉的语言，让我们解析这个语句：

```
∀ a, b ∈ M     （对于所有属于M的元素a和b）
⇒              （可以推出）
a • b ∈ M       （a • b的结果是M的一个元素）
```

### 8.4. 半群

半群的一个示例：

```
`S = { "a", "b", ..., "z", "aa", "ab", ... } and • = <>`
```

- 1. **S** 是非空字符串的集合。
- 2. **<>** 是拼接（或追加）运算符。

### 8.6. 幺半群

如果我们再向半群增加一个要求，就得到幺半群：

> 一个幺半群是其集合具有一个中性元素e的半群。

以下是幺半群的正式定义，使用数学符号：

```
e ∈ M, ∀ a ∈ M ⇒ a • e = e • a = a
```

其中M是幺半群的集合。

让我们解析上述关于中性元素要求的定义：

```
e ∈ M                     （e是M的一个元素）
, ∀ a ∈ M                 （并且对于所有属于M的元素a）
⇒                         （可以推出）
a • e = e • a = a         （将a应用于e等于
                          将e应用于a，两者都等于a）
```

简单来说，中性元素（也称为空元素或单位元）可以应用于集合中的任何元素，包括它自身，因为它也是集合的一个元素，并且对该元素没有影响。
