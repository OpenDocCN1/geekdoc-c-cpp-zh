We are displayed on top of all elements on the page due to many factors:

+   - `position fixed` makes us a Positioned Element, which display on top of non-Positioned Elements (static, relative and absolute don’t behave this way)
+   - Specifying an Opacity treats us as `z-index 0`, which will displays on top of non-Position Elements, i.e. Elements with NO `z-index` specified
+   - `z-index` of 1 will make us a Positioned Element
+   - when the page that includes us in their `render` Function puts us as the LAST Element since all things being equal later Elements are displayed on top of previous
