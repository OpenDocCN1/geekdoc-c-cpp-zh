Now, we need to parse a specific character, i.e. a comma. We can use char from Text.Parsing.Parser.String for that:

```
where
    comma p = do
        v <- p
        void $ char ','
        ???
```

1 Single quotes are Char literals.

We throw away this second parse result.

And finally, we return the result of the first parser:

```
where
    comma p = do
        v <- p
        void $ char ','
        pure v
```
