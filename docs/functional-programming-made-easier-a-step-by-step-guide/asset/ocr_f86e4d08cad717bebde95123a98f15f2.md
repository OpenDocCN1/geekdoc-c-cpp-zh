```
manyRequests :: Aff (Array Response)
manyRequests =
  sequential $
    (\p1 p2 p3 -> [p1, p2, p3])
      <$ > parallel (Ajax.get string "https://foo.com")
      <*> parallel (Ajax.get string "https://bar.com")
      <*> parallel (Ajax.get string "https://baz.com")
```

1 Our Lambda will collect up the results of each call and put them into an Array.

This can be made cleaner by using parSequence. This is just like sequence from Data.Traversable with the notable difference that the computations are performed over the Traversable in parallel instead of serial:

```
import Control.Parallel (parSequence, parallel, sequential)

manyRequests :: Aff (Array Response)
manyRequests =
  parSequence
    [ Ajax.get string "https://foo.com"
    , Ajax.get string "https://bar.com"
    , Ajax.get string "https://baz.com"
    ]
```

1 Added parSequence to the import list.

This version is so much cleaner.
