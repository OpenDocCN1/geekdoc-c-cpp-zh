handler :: LogonRequest -> Handler ①
```

① In this case, a is LogonRequest.

Now that we have an a in the Type Signature, we don’t need Proxy anymore. Go ahead and remove it from the Type Signature before reading further.

Here’s that change:

```
handleApi
  :: ∀ a
    . (a -> Handler) ①
  -> String
  -> Either MultipleErrors Handler
handleApi handler request = do ①
  req <- runExcept (decodeJSON request :: _ a) -- COMPILER ERROR!!
  pure $ handler req
