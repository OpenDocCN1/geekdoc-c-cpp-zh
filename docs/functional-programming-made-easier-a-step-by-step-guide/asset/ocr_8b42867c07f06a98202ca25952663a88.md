This is pretty unremarkable. It looks just like any Functor between Categories with the slight exception of operating on a Pair of Types, which is basically the Definition of **Bifunctor**, which is as follows:

```
For *Categories*, C, D and E, the *Functor*

    F: C × D → E

is also called a *Bifunctor* from C and D to E.
```

C × D in this definition is our Category Hask × Hask in the above diagram. And E in this definition is our Category D in the above diagram.
