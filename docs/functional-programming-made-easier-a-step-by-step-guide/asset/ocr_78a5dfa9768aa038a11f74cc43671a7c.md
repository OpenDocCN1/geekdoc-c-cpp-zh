class ParserError (e :: Type) where
  eof :: e

❶ Don’t forget to add the `where` keyword. We didn’t need this before since we had no Methods.

❷ Here `e` is our Application-specific error Type.

Now, any error Type that the user of our general `Parser` creates must at least support `eof` for the `char` parser.

The following is an imaginary error Type for some imaginary Application that uses our `Parser` and meets this requirement:
