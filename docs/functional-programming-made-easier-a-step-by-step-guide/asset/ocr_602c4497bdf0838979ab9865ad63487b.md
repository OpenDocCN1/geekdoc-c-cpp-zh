```
```haskell
(Just 10 <> (Just 20 <> Just 30)) = Just 10 ❶
(Just 10 <> (Just 20 <> Just 30)) = Just 20 ❷
(Just 10 <> (Just 20 <> Just 30)) = Just 30 ❸
```
```

+   ❶ Take the first `Just`.
+   
+   ❷ Sometimes take first `Just` then take second `Just`. This case doesn’t make sense.
+   
+   ❸ Take the last `Just`.

To get a result of `Just 20`, we’d first have to pick the `second` value, i.e. the Parenthetical. Next, to evaluate what’s inside the Parentheses, we’d have to pick the `first`. This is just absurd since we can’t just randomly pick. So we’ll disregard this case.

But, we’re no better off with this new example, since we still have 2 possibilities. So just like with `AddInt` and `MultInt`, let’s create 2 `newtypes` for both situations:

```
```haskell
newtype First a = First (Maybe a)
newtype Last a = Last (Maybe a)
```
```

We’re calling this `First` and `Last` to signify that in a long line of `appends`, we take the first `non-Nothing` value or the last.
