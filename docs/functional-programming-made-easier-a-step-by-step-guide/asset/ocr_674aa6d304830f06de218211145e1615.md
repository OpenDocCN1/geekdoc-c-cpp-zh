```
Option 2 is our only real option here.

How should we change the Precedence then?

Well, the compiler is unhappy because they are the exact same Precedence and we want # to evaluated *last*:

```
```purescript
g x = lastStep $ x
  # step1    -- COMPILER ERROR!!
  # step2
  # step3
```
```

But, if we think about this code for a minute, we can see that we really don’t want # to be dead last. We just want it last, right before $.

And therein lies our solution:

```
```purescript
infixl 1 applyFlipped as #
```
```

We make # have Precedence 1, which means, when used in conjunction with other operators, it will be evaluated last except for $, which will be evaluated dead last.

Our final solution is:

```
```purescript
applyFlipped :: ∀ a b. a -> (a -> b) -> b
applyFlipped = flip apply

infixl 1 applyFlipped as #
```
