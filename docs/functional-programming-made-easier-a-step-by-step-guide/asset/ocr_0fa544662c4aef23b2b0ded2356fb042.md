# 30.16. Logoff Page

The Logoff Page will be a fairly simple. When we navigate to that Page, it will call our backend to log the user off and display a message letting the user know that they have successfully logged off. This message will be on the page, not a Modal. The page will also have a button for them to log back on. Clicking that button will take them back to the Logon Page.

The Logoff Page will also display a Modal if there are errors in the API call.

We have done all of this before and so we can steal layouts from ChangePassword Page and Modals from the Logon or Users Page.

Before you begin coding, create a File called Logoff.purs under src/Component.
