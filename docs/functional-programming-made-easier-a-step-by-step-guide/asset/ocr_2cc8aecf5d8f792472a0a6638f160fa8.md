There’s one more minor change we should make. In Data.Unfoldable, there’s a Function called none that returns an empty Unfoldable collection. This means, that we can remove the Plus constraint if we use none instead of empty. The fewer constraints we have, the better:

```
import Data.Unfoldable (class Unfoldable, replicate, none) ① ②

count
  :: ∀ e a f
    . Traversable f ③
    => Unfoldable f
    => Int
    -> Parser e a
    -> Parser e (f a)
count n p
  | n <= 0    = pure none ④
  | otherwise = sequence (replicate n p)
```

+   ② We deleted the Control.Plus import.
+   ③ We removed the Plus constraint
