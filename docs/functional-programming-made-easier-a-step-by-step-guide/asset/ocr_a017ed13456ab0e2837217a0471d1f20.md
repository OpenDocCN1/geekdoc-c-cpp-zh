And looking at the other side of that same coin, map takes functions that take and return Pure Values and it *lifts* them into functions that take and return Contextual Values:

```
map :: ∀ a b. (a -> b) -> (f a -> f b) ①
```

① Only difference here is that we added in the implied Parentheses to emphasize the lifting effect.

With this perspective, we see that map takes a function expecting Pure Values and turns it into a function that works with Contextual Values.
