So what exactly does this mean?

First, thing to remember is the definition of Predicate. A Predicate is a Function that has the following Type Signature:

```
```purescript
somePredicateFunction :: ∀ a. a -> Boolean
```
```

It takes some value of Type `a` and makes a decision based on its Value and returns a `Boolean`. Here’s some examples of Predicate Functions:

```
```purescript
isEven :: Int -> Boolean
isOdd :: Int -> Boolean
(_ -> 7) ❶ ❷
("" /= _) ❶ ❸
```
```

+   1. These are wildcard Functions.
+   2. This has a Type Signature of `Int -> Boolean`.
+   3. This has a Type Signature of `String -> Boolean`.

Let’s return to the Type Signature for `findIndex`:

```
```purescript
findIndex :: ∀ a. (a -> Boolean) -> List a -> Maybe Int
```
```

We can now see that the first Parameter is a Predicate. It will be used to determine if the element is the one we’re looking for.
