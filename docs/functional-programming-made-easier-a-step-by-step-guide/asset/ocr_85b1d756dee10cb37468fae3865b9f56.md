```
A(y1 : _) <*> A(y2 : Nil)
```

And applying one more time yields:

```
A(y1 : y2 : Nil)
```

Once again, we have a List in an Applicative.

So now let’s go back to our strategy with these final steps added:

```
(x1 : x2 : Nil) ①
(A(y1) : A(y2) : Nil) ②
(A(y1 : _) : A(y2 : _) : Nil) ③
A(y1 : _) <*> (A(y2 : _) <*> pure Nil) ④
A(y1 : y2 : Nil) ⑤
```

① We start with a List.

② We apply to each element our function, f :: a -> m b, resulting in a List of Applicatives.

③ We partially apply (:) to each value in the List.

④ We apply each element of the List to each other in a Right-Associative way starting with an empty List in the same Applicative, i.e. pure Nil.

⑤ This results in a List INSIDE the Applicative.

Now that we have a strategy, we’re ready to write the Traversable instance for List. First the instance definition:

```
instance traversableList :: Traversable List where
```

Next, we’ll write traverse’s Type Signature specialized for List to help us write the code (we can always delete this line later):

```
instance traversableList :: Traversable List where
  traverse :: ∀ a b m. Applicative m => (a -> m b) -> List a -> m (List b)
```
