# 5.22.1. Hint for !!

In case you do not have access to the Internet while reading this:

# (!!)
Source
Operator alias for Data.Array.index (left-associative / precedence 8)
An infix version of index.

```
sentence = ["Hello", "World", "!"]

sentence !! 0 = Just "Hello"
sentence !! 7 = Nothing
```

# 5.22.2. Code for !!

Since !! Operator is Left-Associative and has a Precedence of 8, we write:

```
infixl 8 index as !!
```

Let’s look at the usage of this Operator in some detail:

```
index addresses 7
addresses `index` 7
addresses !! 7
```

All of the above lines are equivalent. This now explains why the Parameter order for index seemed backwards. It was to facilitate the desired syntax for !! Operator.
