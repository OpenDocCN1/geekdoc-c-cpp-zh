## 29.2.6. Emitters

Next, we’re going to work with `Emitters`. `Emitters` emit Values of a particular Type. An `Emitter` is

defined as:

```
```haskell
newtype Emitter a
```
```

The `a` here is the Type of Value it’ll emit.

`Emitters` emit and `Listeners` listen for those emission. We create these 2 using a single Function, `HS.create`:

```

```
```

```
```haskell

```
```

```
