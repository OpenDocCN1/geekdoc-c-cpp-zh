# ## 6.5.3. Show Typeclass

Another common built-in Typeclass is `Show`. This Class is for turning a value of your Type into a String so that we can display it.

Here’s its definition:

```
```haskell
class Show a where
  show :: a -> String
```
```

Try to write a `Show` instance for our `Place` Type.

The instance is as follows:

```
```haskell
instance showPlace :: Show Place where
  show First  = "First"
  show Second = "Second"
  show Third  = "Third"
```
```

> ⓵ We use idiomatic naming of our instance, i.e. Class name followed by Type name.
