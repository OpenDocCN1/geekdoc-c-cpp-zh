Therefore, we’ll have to introduce a `go` function that has an extra variable to keep track of the current maximum.

```
findMax :: ∀ a. Ord a => List a -> Maybe a
findMax Nil = Nothing
findMax l@(x : _) = Just $ go x l where
  ???
```

+   1. We don’t use the tail, so we renamed `xs` to `_`.
+   2. We use Pattern Matching to remove the head of the `List`. The head will be our starting maximum value.
+   3. We’re using the `@` syntax to assign a name to the FULL `List`. That name is `l`.

Now, we need to handle the base-case for `go`:

```
findMax :: ∀ a. Ord a => List a -> Maybe a
findMax Nil = Nothing
findMax l@(x : _) = Just $ go x l where
  go mx Nil = mx
```

+   1. This is the base-case for `findMax` when we are *initially* given an empty `List`.
+   2. This is the base-case for `go` when we’ve exhausted our `List`. We return the current maximum value, `mx`, once we’ve gotten to the end of the `List`.

And finally, we code the recursive case for `go`:

```
findMax :: ∀ a. Ord a => List a -> Maybe a
findMax Nil = Nothing
findMax l@(first : _) = Just $ go first l where
  go mx Nil     = mx
  go mx (x : xs) = go (max x mx) xs
```

+   1. Renamed `x` to `first` so it wouldn’t shadow the `x` on the last line.
+   2. Tail Recursive.
