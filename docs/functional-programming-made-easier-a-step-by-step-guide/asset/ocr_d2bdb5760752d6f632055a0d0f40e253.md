StateT’s `tell` Function will do the same and lift the `tell` Function of its underlying Monad, which, in the case of our example Stack, is `WriterT`:

![](bbox=[0.234, 0.117, 0.767, 0.362])

`WriterT` is where `tell` is implemented, so it simply appends to the log.

Notice how `tell` get’s lifted 2 times with this approach. It’s lifted just the right amount of times needed for this Stack. If we had a different Stack, it would be lifted just the right number of times for that particular Stack, for example:

![](bbox=[0.234, 0.493, 0.767, 0.698])

In this Stack, it’s only lifted once since the lifting terminates with the Monad that actually implements the API call, in this case, `WriterT`.

The correct way to implement API calls is to use Typeclasses since we have multiple Types, i.e. different Monad Transformers, and the same set of Functions. Here’s the Typeclass in PureScript that supports `tell`:

```
class Monad m <= MonadTell w m | m -> w where
  tell :: w -> m Unit
```

+   1. Notice the Functional Dependency, `| m -> w` that says that for each Monad, `m`, there can be ONE AND ONLY ONE `w`.
