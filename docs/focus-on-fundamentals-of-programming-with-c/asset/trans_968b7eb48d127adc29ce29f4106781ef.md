

## 线性链表的操作

如果 p 是指向某个节点的指针：

- p = getNode();

获取一个空节点，并将名为 p 的指针变量的内容设置为该节点的地址。这意味着 p 是指向此新分配节点的指针。

![](img/7f36c52b5170b89b142dbb7b1ea4666b_454_0.png)

- freeNode(p);

将 p 指向的节点返回到未使用节点的源，并使该节点可供重复使用。

![](img/7f36c52b5170b89b142dbb7b1ea4666b_454_1.png)

- info(p)

指的是 p 所指向节点的信息部分。

x = info(p) 将 p 所指向节点的 info 字段的内容赋值给 x。

![](img/7f36c52b5170b89b142dbb7b1ea4666b_454_2.png)

info(p) <- x 将 x 的内容赋值给 p 所指向节点的 info 字段。

x = 10

![](img/7f36c52b5170b89b142dbb7b1ea4666b_455_0.png)

next(p)

指的是 p 所指向节点的下一个地址部分。

q = next(p) 将 p 所指向节点的 next 字段的内容赋值给 q。

![](img/7f36c52b5170b89b142dbb7b1ea4666b_455_1.png)

next(p) = q 将指针 q 的内容赋值给 p 所指向节点的 next 字段。

![](img/7f36c52b5170b89b142dbb7b1ea4666b_455_2.png)

## 其他列表操作

无需任何数据移动，就可以轻松地从列表中间插入和删除元素。例如，将节点插入列表中间所需的工作量与列表大小无关。所需要做的就是：

- 分配一个新节点
- 将信息插入节点
- 调整两个指针

![](img/7f36c52b5170b89b142dbb7b1ea4666b_464_0.png)

### 算法 4：给定线性链表中某个节点的指针 p，编写一个算法，在 p 指向的节点之后插入一个节点。

![](img/7f36c52b5170b89b142dbb7b1ea4666b_465_0.png)

- q = getNode()

![](img/7f36c52b5170b89b142dbb7b1ea4666b_465_1.png)

![](img/7f36c52b5170b89b142dbb7b1ea4666b_465_2.png)

- info(q) = x

x = 25

![](img/7f36c52b5170b89b142dbb7b1ea4666b_465_3.png)

![](img/7f36c52b5170b89b142dbb7b1ea4666b_465_4.png)

- next(q) = next(p)

![](img/7f36c52b5170b89b142dbb7b1ea4666b_466_0.png)

- next(p) = q

![](img/7f36c52b5170b89b142dbb7b1ea4666b_466_1.png)

请注意，一个项目只能插入到给定节点之后，而不能插入到节点之前。这是因为在不从头开始遍历列表的情况下，无法从给定节点前进到其前驱节点。

这是上面的算法：

```
q = getNode()
info(q) = x
next(q) = next(p)
next(p) = q
```

### 算法 5：给定线性链表中某个节点的指针 p，编写一个名为 deleteAfter 的算法，删除 p 指向的节点之后的节点。

![](img/7f36c52b5170b89b142dbb7b1ea4666b_467_0.png)

- q = next(p)

![](img/7f36c52b5170b89b142dbb7b1ea4666b_467_1.png)

- x = info(q)

![](img/7f36c52b5170b89b142dbb7b1ea4666b_467_2.png)

x = 30

- next(p) = next(q)

![](img/7f36c52b5170b89b142dbb7b1ea4666b_468_0.png)

- freeNode(q)

![](img/7f36c52b5170b89b142dbb7b1ea4666b_468_1.png)

同样，我们不能仅仅得到一个指向要删除节点的指针。这是因为必须更改节点前驱的 next 字段以指向节点的后继，并且没有直接方法到达给定节点的前驱。

这是上面的算法：

```
q = next(p)
x = info(q)
next(p) = next(q)
freeNode(q)
```

## 线性链表示例

### 示例 1

假设我们想要从线性链表中删除所有出现的数字 4。我们需要遍历列表，查找 info 字段中包含 4 的节点并删除该节点。但是，要删除一个节点，必须知道其前驱节点。因此，我们必须使用两个指针 p 和 q 来遍历列表。p 将被视为前导指针，q 将被视为滞后指针；也就是说，p 将遍历列表，而 q 始终指向 p 的前驱。请注意，在处理列表时，使用两个指针（一个跟随另一个）的做法非常常见。

将使用两个函数：

- deleteFront() 将用于删除列表前面的节点。
- deleteAfter() 将用于删除列表中间的节点。

```
p = list
q = NULL
while p != NULL
  if info(p) == 4
    p = next(p)
    if p == NULL
      deleteFront(list)
    else
      deleteAfter(q)
  else
    q = p
    p = next(p)
```

将算法的逐步执行作为练习留给读者。请务必在逐行执行算法时绘制图示。
