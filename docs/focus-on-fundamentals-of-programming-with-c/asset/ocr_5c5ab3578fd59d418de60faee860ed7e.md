# # Inheritance Relationship

+   - UNDERGRAD: major / adviser
+   - GRAD: dept / thesis / support / office
+   - FACULTY: rank / course load
+   - CLASSIFIED
+   - TENURE: tenure date
+   - TEMPORARY

+   - The idea is that one class is just like another class EXCEPT that the new class includes something extra.

+   - Note: The higher level (base) classes tend to be more abstract then the derived classes, which are much more specific.

+   - At some point after our program is in production, we might see the need to add another class of objects:
+     - EXTENSION student

+   - Simple without effecting the rest of the program.
