# Derived Class Functionality

+   * We've seen how inheritance allows reuse of existing code to hold information about each class of object.

+   * But derived classes of a base class not only inherit data attributes (name, ss#, etc), but also inherit the behavior of the base class, the operations or functionality of the base class.

+   * In fact, derived classes may also add new functionality or behavior, or even override or redefine existing behavior.
