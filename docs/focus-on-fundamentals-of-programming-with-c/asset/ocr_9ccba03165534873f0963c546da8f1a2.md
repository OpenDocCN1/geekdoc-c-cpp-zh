Here's an example from that prints n elements of an array, 10 per line, with each column separated by one blank, and with each line (including the last) terminated by exactly one new line:

```
// Long Form
for (i = 0; i < n; ++i) {
    printf("%6d", a[i]);
    if (i % 10 == 9 || i == n - 1) {
        printf("%s", "\n");
    } else {
        printf("%s", " ");
    }
}
```

A newline is printed after every 10th element, and after the nth all other elements are followed by one blank.

```
// Short Form
for (i = 0; i < n; ++i) {
    printf("%6d%c", a[i], (i % 10 == 9 || i == n - 1) ? '\n' : ' ');
}
```
