# # Addition of Polynomials

In order to find a suitable representation for a polynomial (in one variable), we must distinguish between coefficients and exponents within each term of the polynomial. Shown below is one term of a polynomial represented as a node in a linear linked list.

| coefficient | exponent | link to next term |
|---|---|---|

So, for example:

3X² would be represented as:

| 3.0 | 2 | |
|---|---|---|

X⁴ would be represented as:

| 1.0 | 4 | |
|---|---|---|

5 would be represented as:

| 5.0 | 0 | |
|---|---|---|

3X⁵ - 2X³ + 4 would be represented as:

| 3.0 | 5 | -> | -2.0 | 3 | -> | 4.0 | 0 | |
|---|---|---|---|---|---|---|---|---|
