  ```
  z = x * (y++);
  ```

- b) 使用 += 运算符将 value 乘以 5。

  ```
  Value += 5;
  ```

- c) 将变量 x 减 1，然后从变量 result 中减去它。

  ```
  result -= --x;
  ```

- d) 将变量 x 加到变量 total 上，然后将 x 加 1。

  ```
  total += x++
  ```
