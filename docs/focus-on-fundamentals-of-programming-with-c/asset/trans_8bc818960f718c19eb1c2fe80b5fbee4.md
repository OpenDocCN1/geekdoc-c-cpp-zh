

## 真值表：逻辑非运算符 (!)

| p | !p |
|---|---|
| 真 | 假 |
| 假 | 真 |

在 C 语言中，逻辑运算符经常用于组合关系运算符以构建更大的表达式：

```
if (x < 20 && x > 10)
```

使用逻辑运算符的表达式从左到右求值，一旦结果的真假已知，求值即停止。换句话说，逻辑表达式先求值其左操作数，只有在需要时才会求值右操作数。

请注意，false && anything 始终为假；True || anything 始终为真。在这种情况下，第二个测试甚至不会被求值。这被称为短路求值。否定运算符 (!) 作用于单个逻辑值，其效果是反转其状态。以下是其用法示例：

```
if (!acceptable) {
    printf("Not Acceptable!\n");
}
```

逻辑运算符的优先级低于关系运算符。因此，我们可以编写以下代码而无需括号：

```
a < b && c < d
```

任何逻辑表达式的结果要么是：

```
0 - 假
非零 - 真
```

一元否定运算符 (!) 当操作数为假（零）时产生 1，当操作数为真（非零）时产生零：

```
!0 = 1
!1 = 0
```

请注意，!a 与 a==0 含义相同。与其编写如下代码：

```
if (a == 0)
```

C 程序员喜欢编写如下代码：

```
if (!a)
```

两条语句含义相同。

请注意，一元否定运算符 (!) 与数学中的非运算符不同。在数学中：

```
not (not (s)) = s
```

而在 C 语言中：

```
!15 = 0
```

为什么？

```
!15 = !(15) = !(0) = 1
```

## 德摩根定律

德摩根定律有时可以让我们更方便地表达逻辑表达式。德摩根定律可以用数学表达如下：

```
~(P or Q) = ~P and ~Q
~(P and Q) = ~P or ~Q
```

在 C 语言中，这些定律表明表达式：

```
!(condition1 && condition2)
```

与以下表达式逻辑等价：

```
(!condition1 || !condition2)
```

同样，表达式：

```
!(condition1 || condition2)
```

与以下表达式逻辑等价：

```
(!condition1 && !condition2)
```

总结：

```
!(condition1 && condition2) = (!condition1 || !condition2)
!(condition1 || condition2) = (!condition1 && !condition2)
```

看看你能否将德摩根定律应用于以下表达式：

```
!(x > 5) || !(y > 7)
```

## 组合逻辑运算符和关系运算符

我们可以组合逻辑运算符和关系运算符来测试字符是否为：

- 数字
- 大写字母
- 小写字母
- 可打印字符

请注意，通常在十六进制数字前加上 0x：

```
// ascii1.c

#include <stdio.h>

int main(void) {
    unsigned char c;

    for (c = 0; c <= 127; ++c) {
        printf("%3d 0x%03X", c, c);

        // check for printable character
        if (c >= ' ' && c <= '~') {
            printf(" '%c'", c);
        }

        // check for digit
        if (c >= '0' && c <= '9') {
            printf("digit");
        }

        // check for uppercase
        if (c >= 'A' && c <= 'Z') {
            printf("uppercase");
        }

        // check for lowercase
        if (c >= 'a' && c <= 'z') {
            printf("lowercase");
        }

        printf("\n");
    }
    return 0;
}
```

## 字符类型测试

字符类型测试在编程中出现频率足够高，以至于已被纳入名为 ctype.h 的标准 C 库头文件中。使用此文件使我们可以这样说：

```
if (isdigit(c))
```

而不是

```
if (c >= '0' && c <= '9')
```

或

```
if (isupper(c))
```

而不是

```
if (c >= 'A' && c <= 'Z')
```

要使用允许我们访问此库的 ctype.h 头文件，我们发出以下预处理器命令：

```
#include <ctype.h>
```

此行是向 C 预处理器发出的命令，用于将一些标准定义包含到我们的编译中，以便 isdigit() 和 isupper() 等名称会被识别。

以下是可用库函数的列表：

```c
int isalnum(int c);
```
c 是一个字母数字字符
如果 c 是字母（A-Z 或 a-z）或数字（0-9），则返回非零值

```c
int isalpha(int c);
```
c 是一个字母
如果 c 是字母（A-Z 或 a-z），则返回非零值

```c
int isascii(int c);
```
c 是一个 ASCII 字符（代码小于 0200 或 128）
如果 c 的低序字节在范围 0-127（0x00-0x7F）内，则返回非零值

```c
int iscntrl(int c);
```
c 是一个不可打印字符（小于 ' '）
如果 c 是删除字符或普通控制字符（0x7F 或 0x00-0x1F），则返回非零值

```c
int isdigit(int c);
```
c 是一个数字
如果 c 是数字（0-9），则返回非零值

```c
int isgraph(int c);
```
c 是一个图形字符
如果 c 是打印字符（类似于 printf()，但不包括空格字符），则返回非零值

```c
int islower(int c);
```
c 是一个小写字母
如果 c 是小写字母，则返回非零值

```c
int isprint(int c);
```
c 是一个可打印字符（包括空格）
如果 c 是打印字符（0x20-0x7E），则返回非零值

```c
int ispunct(int c);
```
c 是一个标点字符
如果 c 是标点字符（iscntrl() 或 isspace()），则返回非零值
