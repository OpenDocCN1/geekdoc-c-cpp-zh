# Display tabbed output:

```
printf("%d\t %d\t %d\n", a, b, c);
```

# Include the backslash character itself in a character string:

```
printf("\\t is the horizontal tab character.\n");
```

# Include double quotes inside the character string:

```
printf("\"hello, \" he said.\n");
```

# The output looks like:

```
"Hello, " he said.
```
