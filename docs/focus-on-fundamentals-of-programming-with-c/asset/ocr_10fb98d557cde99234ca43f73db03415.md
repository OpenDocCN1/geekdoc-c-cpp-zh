We can even pass information to the function telling the function to draw the line with a certain width and with a certain character:

```
// Exercise3.c
#include <stdio.h>
void draw_line(int width, char ch)
{
    int i;
    for (i = 1; i <= width; i++)
    {
        printf("%c", ch);
    }
    printf("\n");
}
int main(void)
{
    draw_line(10, "*");
    draw_line(5, "#");
    draw_line(20, "-");
    return 0;
}
```
