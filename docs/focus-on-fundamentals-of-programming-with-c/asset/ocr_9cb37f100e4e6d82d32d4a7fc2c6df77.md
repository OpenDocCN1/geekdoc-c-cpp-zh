# Quadratic Equation Example

Let's compute the roots of a quadratic equation in x of the form:

ax^2 + bx + c = 0

We're going to code the quadratic formula:

![](bbox=[0.51, 0.35, 0.71, 0.4])

```
#include <stdio.h>
#include <math.h>

int main (void) {
    int a=1, b=3, c=-4, (disc);
    double root1, root2;

    disc = b*b+4*a*c;
    root1 = (-b + sqrt(disc)) / (2 * a);
    root2 = (-b - sqrt(disc)) / (2 * a);
    printf("root1 = %5.2lf\n", root1);
    printf("root2 = %5.2lf\n", root2);
    return 0;
}
```

Here's the output:

```
root1 = 1.00
root2 = -4.00
```
