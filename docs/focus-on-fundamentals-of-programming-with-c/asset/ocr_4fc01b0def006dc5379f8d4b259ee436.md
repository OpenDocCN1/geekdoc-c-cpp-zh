# # Number Systems Homework

+   1. Give the 8-bit binary equivalent of the following decimal integers:
+   a) 72
+   b) 173

+   2. Give the unsigned decimal equivalent of the following 8-bit binary integers:
+   a) 10001110
+   b) 01110011

+   3. Give the signed decimal equivalent of the following 8-bit binary integers:
+   a) 10001110
+   b) 01110011

+   4. Translate the following binary digits into hexadecimal notation:
+   a) 10001110
+   b) 01110011

+   5. Convert the following decimal numbers into hexadecimal:
+   a) 427
+   b) 841

+   6. Convert the following hexadecimal numbers into decimal:
+   a) 0x5E
+   b) 0x1C3

+   7. Convert the following hexadecimal numbers into binary:
+   a) 0x1234
+   b) 0xFBA2

+   8. Give the two's complement of the following binary numbers:
+   a) 01111110
+   b) 11100110
+   c) 10000001
+   d) 00000000
