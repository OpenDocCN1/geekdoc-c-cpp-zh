
## Operations on Linear Linked Lists

If p is a pointer to a node:

- p = getNode();

Obtains an empty node and sets the contents of a pointer variable named p to the address of that node. This means that p is a pointer to this newly allocated node.

![](img/7f36c52b5170b89b142dbb7b1ea4666b_454_0.png)

- freeNode(p);

Returns the node pointed to by p to the source of unused nodes and makes the node available for reuse.

![](img/7f36c52b5170b89b142dbb7b1ea4666b_454_1.png)

- info(p)

Refers to the information portion of the node that is pointed to by p.

x = info(p) assigns the contents of the info field of the node pointed to by p to x.

![](img/7f36c52b5170b89b142dbb7b1ea4666b_454_2.png)

info(p) <- x assigns the contents of x to the info field of the node pointed to by p.

x = 10

![](img/7f36c52b5170b89b142dbb7b1ea4666b_455_0.png)

next(p)

Refers to the next address portion of the node pointed to by p.

q = next(p) assigns the contents of the next field of the node pointed to by p to q.

![](img/7f36c52b5170b89b142dbb7b1ea4666b_455_1.png)

next(p) = q assigns the contents of pointer q to the next field of the node pointed to by p.

![](img/7f36c52b5170b89b142dbb7b1ea4666b_455_2.png)

## Three List Algorithms

### Algorithm 1: Given a linear linked list of integers, create an algorithm that will add a node with the data value of 10 to the front of the following list:

![](img/7f36c52b5170b89b142dbb7b1ea4666b_456_0.png)

### Step 1: p = getNode()

p is a pointer to a newly created node:

![](img/7f36c52b5170b89b142dbb7b1ea4666b_456_1.png)

### Step 2: info(p) = x

Inserts an integer x into the info portion of the node that p points to:

![](img/7f36c52b5170b89b142dbb7b1ea4666b_456_2.png)

### Step 3: next(p) = list

We now want the node pointed to by p to point to the node that list is pointing to (since list contains the address of the first node in the list). So we must set the next field of the node that p points to, to the node that list points to:

![](img/7f36c52b5170b89b142dbb7b1ea4666b_457_0.png)

### Step 4: list = p

Finally, since list is the external pointer to the linear linked list, its value must be modified to the address of the new first node of the list. This changes the value of list to the value of p:

![](img/7f36c52b5170b89b142dbb7b1ea4666b_457_1.png)

Note at this point the pointer p is not needed and can be simply disregarded:

![](img/7f36c52b5170b89b142dbb7b1ea4666b_458_0.png)

Put together, we have an algorithm for adding a node to the front of a linear linked list:

```
p = getNode()
info(p) = x
next(p) = list
list = p
```

## Additional List Operations

It is easy to insert and delete elements from the middle of a list without any data movements. For example, the amount of work required to insert a node into the middle of a list is independent of the size of the list. All that is necessary is to:

- allocate a new node
- insert the information into the node
- adjust two pointers

![](img/7f36c52b5170b89b142dbb7b1ea4666b_464_0.png)

### Algorithm 4: Given a pointer p to a node in a linear linked list, write an algorithm, that will insert a node after the node pointed to by p.

![](img/7f36c52b5170b89b142dbb7b1ea4666b_465_0.png)

- q = getNode()

![](img/7f36c52b5170b89b142dbb7b1ea4666b_465_1.png)

![](img/7f36c52b5170b89b142dbb7b1ea4666b_465_2.png)

- info(q) = x

x = 25

![](img/7f36c52b5170b89b142dbb7b1ea4666b_465_3.png)

![](img/7f36c52b5170b89b142dbb7b1ea4666b_465_4.png)

- next(q) = next(p)

![](img/7f36c52b5170b89b142dbb7b1ea4666b_466_0.png)

- next(p) = q

![](img/7f36c52b5170b89b142dbb7b1ea4666b_466_1.png)

Note that an item can only be inserted after a given node, not before the node. This is because there is no way to proceed from a given node to its predecessor in a list without traversing the list from the beginning.

Here's the algorithm from above:

```
q = getNode()
info(q) = x
next(q) = next(p)
next(p) = q
```

### Algorithm 5: Given a pointer p to a node in a linear linked list, write an algorithm, deleteAfter, that will delete a node after the node pointed to by p.

![](img/7f36c52b5170b89b142dbb7b1ea4666b_467_0.png)

- q = next(p)

![](img/7f36c52b5170b89b142dbb7b1ea4666b_467_1.png)

- x = info(q)

![](img/7f36c52b5170b89b142dbb7b1ea4666b_467_2.png)

x = 30

- next(p) = next(q)

![](img/7f36c52b5170b89b142dbb7b1ea4666b_468_0.png)

- freeNode(q)

![](img/7f36c52b5170b89b142dbb7b1ea4666b_468_1.png)

Again, we cannot just be given a pointer to the node we want to delete. This is because the next field of the node's predecessor must be changed to point to the node's successor and there is no direct way of reaching the predecessor of a given node.

Here's the algorithm from above:

```
q = next(p)
x = info(q)
next(p) = next(q)
freeNode(q)
```

## Linear Linked List Examples

### Example 1

Suppose we wanted to delete all occurrences of the number 4 from a linear linked list. We would have to traverse the list for nodes with 4 in the info field and delete that node. But to delete a node, its predecessor must be known. Therefore we must use two pointers, p and q, to traverse the list. p will be considered the lead pointer and q will be considered the lag pointer; i.e., p will traverse the list and q will always point to the predecessor of p. Note the practice of using two pointers, one following the other, is very common when working with lists.

Two functions will be used:

- deleteFront() will be used to delete the node from the front of the list.
- deleteAfter() will be used to delete a node from the middle of the list.

```
p = list
q = NULL
while p != NULL
  if info(p) == 4
    p = next(p)
    if p == NULL
      deleteFront(list)
    else
      deleteAfter(q)
  else
    q = p
    p = next(p)
```
