# Math Functions

The cmath header defines various mathematical functions in the math library. All the functions evaluate in this library take double as an argument and return double on the result. Be sure to include the cmath header file near the top of source file that will use math functions.

# Power Functions

pow(x, y) Returns x raised to the power of y.
sqrt(x) Returns the square root of x.

# Absolute Value Functions

abs(x) Returns the absolute value of x.

# Nearest Integer and Remainder Functions

ceil(x) Returns the smallest integer value greater than or equal to x. Rounds up to the nearest integer.
floor(x) Returns the largest integer value less than or equal to x. Rounds down to the nearest integer.
fmod(x, y) Returns the remainder of x divided by y.

# Exponential and Logarithmic Functions

exp(x) Returns the value of e raised to power of x.
log(x) Returns the natural logarithm (base-e) of x.
log10(x) Returns the common logarithm (base-10) of x.

# Trigonometric Functions

cos(x) Returns the cosine of a radian angle x.
sin(x) Returns the sine of a radian angle x.
tan(x) Returns the tangent of a radian angle x.
acos(x) Returns the arc cosine of x in radians.
asin(x) Returns the arc sine of x in radians.
atan(x) Returns the arc tangent of x in radians.
