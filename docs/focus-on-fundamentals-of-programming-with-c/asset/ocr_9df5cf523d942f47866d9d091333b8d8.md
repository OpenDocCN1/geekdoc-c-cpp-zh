# 1. What output does the following program fragment produce?

```
i = 1;
while (i <= 64) {
    printf("%d ", i);
    i *= 2;
}
```

Ans: 1 2 4 8 16 32 64

# 2. What output does the following program fragment produce?

```
i = 1234;
do {
    printf("%d ", i);
    i /= 10;
} while (i > 0);
```

Ans: 1234 123 12 1
