# Function Motivation

Suppose we wished to generate a table of powers with the following format:

| Base | Exponent | Power |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 2 | 4 |
| 3 | 2 | 9 |
| 4 | 2 | 16 |
| 5 | 2 | 25 |
| 6 | 2 | 36 |
| 7 | 2 | 49 |
| 8 | 2 | 64 |
| 9 | 2 | 81 |
| 10 | 2 | 100 |

Our code might look like this:

```
// funct1.c - Generate table of powers
#include <stdio.h>
int main(void) {
    int base, exponent, power;
    for (base = 1; base <= 10; base++) {
        printf("%d\t", base);
        for (exponent = 1; exponent <= 2; exponent++) {
            power = 1;
            for (int i = 1; i <= exponent; i++) {
                power *= base;
            }
            printf("%d\t", power);
        }
        printf("\n");
    }
    return 0;
}
```
