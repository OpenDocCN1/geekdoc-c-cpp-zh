# Relational Operators

A relational operator is a comparison symbol showing a relationship between two expressions. Each relational operator takes two operands and produces a numerical (not Boolean) result which is either 0 (false) or non-zero (true). This is called semi-Boolean logic.

| Operator | Description |
|---|---|
| > | greater than |
| >= | greater than or equal to |
| < | less than |
| <= | less than or equal to |
| == | equal to |
| != | not equal to |

# Precedence of Relational Operators

> >= < <=
== !=

The precedence of the relational operators is just below that of the arithmetic operators. Therefore,

```
a + b < c + d
```

would be a valid C expression.
