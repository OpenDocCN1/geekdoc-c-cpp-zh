Frequently an else-if construct can clarify your code. For example, the meaning of this obscure three-way choice:

```
if (n > 0) {
    printf("Positive");
}
else {
    if (n == 0) {
        printf("Zero");
    } else {
        printf("Negative");
    }
}
```

can be made clearer using the else-if construct:

```
if (n > 0) {
    printf("Positive");
} else if (n == 0) {
    printf("Zero");
} else {
    printf("Negative");
}
```
