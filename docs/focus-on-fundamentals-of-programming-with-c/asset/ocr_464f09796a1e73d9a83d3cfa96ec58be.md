# # Examples of Objects

What sort of things become objects in object-oriented programs?

The answer is limited only by your imagination, but here are some typical categories to start you thinking:

+   **User Interface**
+   - windows
+   - menus
+   - graphics objects
+   - mouse/ keyboard

+   **Programming Constructs**
+   - customized arrays
+   - stacks / queues
+   - linked lists
+   - binary trees

+   **User-Defined Types**
+   - time
+   - angles
+   - complex numbers
+   - points in a plain

+   **Physical Objects**
+   - cars in a traffic simulation
+   - countries in an economic model
+   - aircraft in air traffic systems
+   - electronic components in a circuit design program
