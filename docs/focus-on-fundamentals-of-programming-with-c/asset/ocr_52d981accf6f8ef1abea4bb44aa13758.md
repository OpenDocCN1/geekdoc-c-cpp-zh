# # Classes Define Objects

+   - Classes serve as templates from which objects can be created.

+   - Every object belongs to a class that defines the type of object it is.

+   - An object is an instance of its class.

+   - Objects of the same class behave the same way and may have different states (data).

+   - A message to an object is a request that it execute a specific function or algorithm (method).

+   - Messages an object responds to are methods for the entire class.
