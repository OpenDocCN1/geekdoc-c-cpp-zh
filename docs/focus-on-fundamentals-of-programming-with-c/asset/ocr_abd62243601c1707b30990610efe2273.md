# # Object-Oriented Programming

+   * OOP is programming by simulation
+   * OOP is programming with objects
+   * OOP is programming with messages
+   * OOP is programming with classes
+   * OOP is programming with encapsulation
+   * OOP is programming with inheritance
+   * OOP is programming with polymorphism

# # Message Interpretation

+   One of the most important characteristics of OO programming is that:
+   
+   - The interpretation of a message is in the hands of the object.
+   
+   - i.e., The same message can be interpreted in different ways by different receivers (objects).
