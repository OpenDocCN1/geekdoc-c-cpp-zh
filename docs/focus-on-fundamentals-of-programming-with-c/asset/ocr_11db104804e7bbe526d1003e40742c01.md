If we're implementing a calendar program, we might have a need for many DateTime variables. So let's create an array of DateTime structs:

```
DateTime event[1000];
```

We can now initialize an element of the array as follows:

```
event[35].eventDate.month = 7;
event[35].eventDate.day = 14;
event[35].eventDate.year = 2015;
event[35].eventTime.hour = 2;
event[35].eventTime.minute = 15;
event[35].eventTime.second = 00;
```
