# Two-Dimensional Array of Characters

The declaration for a two-dimensional array of characters must include the extra space for a null terminator if each row is to be treated as a character string:

```
char name[20][31];
```

This declares a two-dimensional array of 20 rows, each to contain 30 data characters plus the null terminator that the compiler appends to each string.

The data is stored in row-major order, which means that each row forms an array or items in memory. Each row is itself a one-dimensional array and can be used in contexts where an array is allowed.

We can output each row of the two-dimensional array of character strings as follows:

```
for (i = 0; i < 20; ++i) {
    printf("%s\n", name[i]);
}
```

Each individual element of the two-dimensional array cal also still be accessed using subscripts:

```
name[i][j]
```

# Passing Two-Dimensional Arrays as Function Arguments

Suppose you wanted to pass a two-dimensional array to a function:

```
int main(void) {
    int num[3][4] = {
        { 2, 4, 6, 8 },
        { 1, 3, 5, 7 },
        { 3, 6, 9, 12 }
    };

    foo(num);
    return 0;
}
```
