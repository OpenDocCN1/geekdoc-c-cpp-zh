```
10101001   Original Number
01010110   flip all bits
+ 1        add 1
01010111   two's complement
```

So, the two's complement of 10101001 is 01010111 which equals 47:

```
1 - 2 - 4 - 8 - ... - 128 = -1
```

Therefore if the two's complement of our original number is 47, then our original number must equal -47.
