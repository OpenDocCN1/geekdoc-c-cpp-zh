Here is a C function, strsub(), that grabs a substring, sub, from a string, buf, given the start and end index within the string.

```
void strsub(char buf[], char sub[], int start, int end) {
    int i, j;

    for (j=0, i=start; i<=end; i++, j++) {
        sub[j] = buf[i];
    }
    sub[j] = '\0';
}
```
