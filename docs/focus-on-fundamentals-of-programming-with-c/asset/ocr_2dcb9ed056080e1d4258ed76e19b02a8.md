We can write this more concisely:

```
void strcpy(char s1[], char s2[]) {
    int i = 0;
    while ((s1[i] = s2[i]) != '\0') {
        ++i;
    }
}
```

+   * strcat(s1, s2) Copies string s2 to onto the end of string s1.

Function prototype:

```
void strcat(char *s1, char *s2);
```

For example:

```
char buf[32] = "Hello,";
strcat(buf, " world.");
printf("%s\n", buf);
```

outputs the string:

```
Hello, world.
```

Once again, we can write our own code to perform a string concatenation:

```
void strcat(char s1[], char s2[]) {
    int i = 0, j = 0;
    while (s1[i] != '\0') {
        ++i;
    }
    while (s2[j] != '\0') {
        s1[i] = s2[j];
        ++i;
        ++j;
    }
    s1[i] = '\0';
}
```
