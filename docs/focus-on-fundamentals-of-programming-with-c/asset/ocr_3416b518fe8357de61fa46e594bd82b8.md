# We can also count newlines:

```
#include <stdio.h>

void main(void) {
    int c, count = 0;

    while ((c = getchar()) != EOF) {
        if (c == '\n') {
            ++count;
        }
    }
    printf("%d\n", count);
    return 0;
}
```

# Here's a program to map a program's input to lower case:

```
#include <stdio.h>
#include <ctype.h>

void main(void) {
    int c;

    while ((c = getchar()) != EOF) {
        printf("%c", isupper(c) ? tolower(c) : c);
    }
    return 0;
}
```
