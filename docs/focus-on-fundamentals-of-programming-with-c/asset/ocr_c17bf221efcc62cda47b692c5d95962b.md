The following function concatenates string t onto the end of string s and returns a pointer to the concatenated string:

```
// strcat.c
char *strcat(char *s, char *t) {
    while(*s) {
        s++;
    }
    while(*s++ = *t++) {
        ;
    }
    return s;
}
```

Note that in our final implementation of strcat(), we can actually return the concatenated string as the function return value.

```
// strcmp.c
int strcmp(char *s, char *t) {
    while(*s==*t && *s) {
        s++;
        t++;
    }
    return *s - *t;
}
```
