# # Inheritance Summary

+   - Ability to create classes and objects that are specializations of other objects.

+   - "I want something just like that except ..."

+   - Derived classes inherit data attributes and operations (functionality) from base classes.

+   - Derived classes can have additional data attributes and operations.

+   - Derived classes can be used to modify or override inherited behavior.

+   - Increases code sharing by allowing the language rather than the programmer to "copy" code from one class to another.
