+   * BUILD TRIGGERS/SCHEDULE DETAILS
+   Once we configure the connection to the SCM repository, we can specify the build triggers and/or scheduling details that determine when the build job is triggered.

+   * BUILD STEPS
+   At this step, we tell Jenkins how we want it to build our project. Here, we can add Maven/Ant build steps and more.

+   * POSTBUILD ACTIONS
+   Finally, after the build steps are in place, we have the option of specifying one or more postbuild actions. Such actions might include the publishing of JavaDocs or unit test results, report generation, email notifications, and so on.
