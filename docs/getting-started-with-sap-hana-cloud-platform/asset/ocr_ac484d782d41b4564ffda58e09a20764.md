# 7.4 Summary

In this chapter, we showed you how to use the HTML5 application model to build lightweight, UI-centric applications. This application model, though less powerful than the Java and SAP HANA XS server-side models reviewed previously, offers tremendous benefits for customers looking to leverage in-house web development teams to create new applications or migrate existing applications to the cloud.

In the next chapter, we'll turn our attention to one of the most important topics in cloud-based application development: security. There, you'll find that SAP HCP has a number of useful tools and services that you can use to implement a holistic security model for your applications.
