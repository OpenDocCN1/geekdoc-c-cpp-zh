# # Service Pages

The following sections contain notes on how you can contact us.

# ## Praise and Criticism

We hope that you enjoyed reading this book. If it met your expectations, please do recommend it. If you think there is room for improvement, please get in touch with the editor of the book: kellyw@rheinwerk-publishing.com. We welcome every suggestion for improvement, but, of course, also any praise!

You can also share your reading experience via Twitter, Facebook, or email.
