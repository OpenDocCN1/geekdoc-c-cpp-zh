3. Once the role definition(s) are created, you can map application constraints to the roles by clicking back over to the HTML5 APPLICATION DASHBOARD tab and editing application permissions. As you can see in Figure 7.29, this is achieved by selecting the appropriate role in the ASSIGNED ROLE column for the target permission record.
