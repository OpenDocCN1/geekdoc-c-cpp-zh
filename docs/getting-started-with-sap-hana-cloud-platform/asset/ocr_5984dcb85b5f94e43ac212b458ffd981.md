# ## 9.3.2 Utilizing SAP HANA Cloud Portal Features

As we noted earlier, an important part of the OpenSocial specification is its support for reusable library APIs (or features in the parlance). These library APIs are based on JavaScript and provide solutions to the typical problems faced by widget developers.

Within SAP HANA Cloud Portal, you have access to core features defined by the OpenSocial specification and to a number of SAP HANA Cloud Portal-specific features. By standardizing around these features, you can develop widgets that are more lightweight and portable. This is an important feature when developing mashup applications that incorporate lots of different kinds of content.
