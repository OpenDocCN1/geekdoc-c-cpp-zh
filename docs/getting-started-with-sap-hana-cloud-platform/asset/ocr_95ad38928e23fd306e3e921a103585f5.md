Listing 5.2 contains an excerpt of the XS OData file we created for our sample application. Here, the [namespace] token refers to the same namespace we used to define the entities/views in the CDS file we created in Section 5.4.1. The as “[Entity_Name]” portion of the markup assigns selected tables or views to entities within the OData service definition file. Aside from the entity definitions themselves, we also mix in an association between the Books and BookAuthors entities so that our SAPUI5 application will be able to navigate this association to read the authors associated with a selected book at runtime.
