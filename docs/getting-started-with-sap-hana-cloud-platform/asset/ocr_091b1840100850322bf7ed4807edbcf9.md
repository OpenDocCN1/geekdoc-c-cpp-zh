To create a new application, simply click on the NEW APPLICATION... button in the table's toolbar. This will open the NEW HTML5 APPLICATION dialog box shown in Figure 7.3. Here, you're prompted to give your new HTML5 application a name. The naming rules are as follows:

+   - The name can only contain lowercase alphanumeric characters.
+   - The name cannot exceed 30 characters in length.
+   - The name must start with a letter.

# 7.2.2 Accessing the Git Repository

To access this repository, you need to start drilling into the application definition.
