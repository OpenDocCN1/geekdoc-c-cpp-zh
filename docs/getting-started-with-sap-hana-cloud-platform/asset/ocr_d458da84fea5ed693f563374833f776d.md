If the target database schema is running on the SAP HANA database, then the simplest way to connect to the instance is to use the SAP HANA Authentication Console perspective of SAP HANA Studio to create a cloud system connection. If you have the SAP HANA Tools plug-ins installed in your local Eclipse instance, then this connection can be established as follows:

+   1. Open the SAP HANA ADMINISTRATION CONSOLE perspective in Eclipse.

+   2. In the Systems view on the left-hand side of the page, right-click somewhere in the whitespace and choose the Add Cloud System... menu option (Figure 6.15).
