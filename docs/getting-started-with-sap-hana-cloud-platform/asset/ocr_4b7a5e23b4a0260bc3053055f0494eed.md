# Further Resources

For more information about installing these tools, check out the tools installation page online at https://tools.hana.ondemand.com/#hanatools.

Once a system connection is established, you can use the built-in features of the SAP HANA Tools to perform all kinds of useful operations. For example, in Figure 6.18, you can see the context menu options associated with the INCIDENTS table that was created in reference to the Incidents entity introduced in Section 6.2.3. Here, options are provided to view and/or update the table definition, browse the table's content, and even perform imports or exports of the table data. If you prefer to access this data from an SQL command prompt, then you can open one by clicking on the SQL button in the SYSTEMS view toolbar (see Figure 6.18).
