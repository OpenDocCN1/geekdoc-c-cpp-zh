As we wrap up this discussion, we should note that the SAP HANA programming model is and should be considered a first-class citizen within the set of programming models supported by SAP HCP. Although SAP HANA does naturally lend itself towards the creation of data-centric, analytical applications, all of the pieces are in place to develop general-purpose applications as well. Of course, whether you choose to leverage SAP HANA in this capacity remains a matter of preference.

In the next chapter, we’ll focus our attention on some of the key enablement services provided with SAP HCP. There, you’ll learn how to utilize these services to implement application persistence, external connectivity, and much more.
