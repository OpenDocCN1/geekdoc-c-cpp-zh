Once the dust settles on the project creation process, you’ll notice that the wizard has created two main source code files that define your widget’s content: an HTML file called index.html that contains the HTML5 markup and a spec XML file that contains the OpenSocial-specific module definition. Although you could certainly use these generated files as a baseline for starting your widget development, for the purposes of our demonstration we’ll actually be overlaying these files with some predeveloped content included with the book’s source code bundle (downloadable from www.sap-press.com/3638). That way, you can avoid having to wade through a lot of unneeded content and get to the heart of widget development.
