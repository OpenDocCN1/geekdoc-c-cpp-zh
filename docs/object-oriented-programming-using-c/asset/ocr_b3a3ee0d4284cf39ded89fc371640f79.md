FixEngine(); ?

Feedback 6

Yes! We can apply the method FixEngine() to any Car object as it is defined in the class Car.

This would invoke the overridden method. The method must be defined in the class Else the compiler will complain at compile time. However at runtime the actual object will be checked. As the actual object is a subtype DieselCar the actual method invoked will be the overridden method. Clever stuff given that the Repair() method is unaware of which type of car is actually passed!

# 4.7 Distinguishing Subclasses

What if we have an object handled polymorphically but need to check which subtype it **actually** is ? The operator can do this: 

```
object is class
```

This test is **true** if the object is of the specified class (or a subclass), **false** otherwise.
