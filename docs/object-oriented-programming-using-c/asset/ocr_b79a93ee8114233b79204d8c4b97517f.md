Part of a clock is a display to show the time. This might be an analogue display or a digital display. We could use a superclass and subclasses, but since the implementation of the two displays will be entirely different, it may be more appropriate to use an interface to define the operations which AnalogDisplay and DigitalDisplay must provide.
