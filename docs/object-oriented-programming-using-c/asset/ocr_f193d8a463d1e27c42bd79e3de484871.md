Changing methods to reorder or remove parameters are also refactoring activities. Doing this will require changes to be made these methods are called throughout the system. Visual Studio will automatically change the method calls as appropriate.

Visual Studio provides automated support for the creation of an Interface. To do this it extracts from a class I.e. given a class it define an interface based on specified features of that it will automatically change that class to define the fact that it implements this new interface. This is a significant restructuring activity that allows us to create new classes that implement the same interface!

# 10.5 Unit Testing

Testing the individual methods of a class in isolation from their eventual context within the system under construction is known as Unit Testing.

This testing is generally 'wrapped into' the implementation process:

+   - Write class
- Write tests
- Run tests, debugging as necessary

A unit test should be independent i.e. it should not require other methods or classes within the system to work.

# 10.6 Automated Unit Testing

To save time we automate unit tests but this will not work if the tests require a human to type in test data or we need a human to check the program outputs. Hence to enable automatic testing we need to set up the test data and we need an automated method for checking the program outputs.
