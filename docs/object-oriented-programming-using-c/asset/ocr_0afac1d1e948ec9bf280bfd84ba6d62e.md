# An Introduction to Object Orientated Programming

A 'class' is a software design which describes the general properties of something the software is modelling.

![](bbox=[0.297, 0.126, 0.828, 0.335])

Individual 'objects' are created from the class design for each actual thing

deciding just what classes we should create in our system is not a trivial task as the real world is complex and messy (chapter 6 for more advice on how to go about this). In essence we need to create an abstract model of the real world that focuses on the essential aspects of a problem and ignores irrelevant complexities. For example in the real world bank account holders sometimes may borrow money? occasionally the money may get stolen by a pocket. If we were to create a bank account system should we allow customers to borrow money? Should we acknowledge that their cash may get stolen and buried in some method of getting them an immediate loan – or is this an irrelevant detail that would just add complexity to the system and provide no real benefit to the bank?

Using oriented analysis and design techniques our job would be to look at the real world and come up with a simplified abstract model that we could turn into a computer system. How good our final system will depend upon how good our software model is.
