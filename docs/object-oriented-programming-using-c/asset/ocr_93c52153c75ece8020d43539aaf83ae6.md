These methods allow the superclass to control access to private instance variables.

As currently they don't actually impose any restrictions, but suppose for example we wanted to make sure 'copies' is not set to a negative value.

+   (a) 'copies' is **private**, we can put the validation (i.e. an statement) within SetCopies() method here and know for sure that value never be compromised.

+   (b) 'copies' is partially exposed **protected**, we would have to look at every occasion where a subclass method changed the instance variable and the validation at each place.

We might even consider making these methods **protected** rather than public themselves their use is restricted to subclasses only and other classes cannot interfere with the use of 'copies' at all.

Making of these methods in the subclasses Book and Magazine we have ..

```
// in Book
public void OrderCopies(int orderQty)
{
    SetCopies(GetCopies() + orderQty);
}
```

```
// and in Magazine
public void RecNewIssue(String newIssue)
{
    SetCopies(orderQty);
    currIssue = newIssue;
}
```

These statements are equivalent to
copies = copies + orderQty;
and in 'Magazine'
copies = orderQty;
