# Overloading

This is resolved at run time by looking at the method call and the actual parameters being passed. If two integers are being passed then the first method is invoked. If two floating point numbers are passed then the second method is used.

Overloading refers to the fact that several methods may share the same name. As method names are no longer uniquely identify the method then it is 'overloaded'.

# 5.2 Overloading To Aid Flexibility

Having several methods that essentially perform the same operation, but which take different parameter lists, can lead to enhanced flexibility and robustness in a system.

Imagine a University student management system. A method would probably be required to enrol, register, a new student. Such a method could have the following signature ...

```
EnrollStudent(String name, String address, String coursecode)
```

If a student had just arrived in the city and had not yet sorted out where they were living the University want to refuse to enroll the student? They could do so but it would not be better to allow such a student to enroll (and set the address to 'unknown')?
