# 8.3 SharpDevelop

Another very powerful and free tool that can be used to develop C# programs is SharpDevelop (or #develop). It is open-source so you can download both the sourcecode and executable executables.

SharpDevelop includes support for .NET languages including C# 4.0 and VB.NET 10. It includes unit testing facilities (via optional plug ins), code completion facilities and powerful debugging facilities.

To help debugging, SharpDevelop includes an Object graph visualiser (below). This visualiser displays a representation of your data structures that is dynamically updated when stepping through your code.
