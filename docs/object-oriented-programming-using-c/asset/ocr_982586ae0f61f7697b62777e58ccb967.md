# 3.11 Overriding ToString() defined in 'Object'

The Object class defines a ToString() method, one of several useful methods.

ToString() has the signature
public String ToString()

The purpose of the ToString() method is to return a string value that represents the current object. The version of ToString() defined by Object class produces output like: "Book". This is the class name from which an object is instantiated. However to be generally useful we need to override this to give a more meaningful string.

# In Publication

```
public override String ToString()
{
    return title;
}
```

# In Book

```
public override String ToString()
{
    return base.ToString() + " " by " + author;
}
```
