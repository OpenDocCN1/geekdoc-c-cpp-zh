Feedback 2

In .NET version 4 the String class specifies 8 different constructors. They all have the same method name 'String' of course but they can be differentiated by the different parameters these methods require.

One of these constructors takes array of characters, a starting position and a length and creates a String object using this subset of characters from this. Another requires a as a parameter to point to an array of character and creates a new String object that is a copy of the original.

By massively overloading the String constructor the creators of this class have provided flexibility for other programmers who wish to use these different options in the future.

We can make our programs more adaptable by overloading constructors and other methods. Even if we don't use all of the different constructors, or methods, by providing them we are making our programs more flexible and adaptable to meet changing requirements.
