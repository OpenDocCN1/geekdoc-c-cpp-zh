The 'Display Messages' button shows each of the messages on the screen using the DummyBoard class. This is only crudely simulating a real display board and makes no effort to scroll the messages or display them in any graphically interesting way.

Urgent messages look just like ordinary messages except *** are displayed before and after the message.

'Purge Messages' invokes the PurgeMessages() Mostly this does nothing visible but the days remaining for each message, deletes the client's credits and deletes the messages if appropriate. Urge messages are charged at double the rate of ordinary messages. This can be tested by running Find Client before after a daily purge – this should show the client credit decreasing. If messages exist with an unrecognised client ID and exception will be generated. This exception will be caught by the PurgeMessages() method and the error message will be displayed on the screen.

Ultimately of the idea would be to get the MessageManagerSystem to display the messages on a real display board. This would involve 1) loading the DLL for the real display board 2) creating an object of the real display board in place of the dummy board 3) passing this object when calling the Display() method. i.e. only two lines of the MessageManagerSystem will need to be changed!
