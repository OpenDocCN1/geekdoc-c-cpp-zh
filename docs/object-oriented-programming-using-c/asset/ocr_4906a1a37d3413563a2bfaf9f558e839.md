# 7.5 HashSets

A HashSet is one implementation of a set. A set is like a 'bag' of objects rather than a list. They are based on the mathematical idea of a 'set' – grouping of 'members' that can contain zero, one or more distinct items.

Unlike a List, duplicate items are not permitted in a set and a Set does not arrange items in order.
