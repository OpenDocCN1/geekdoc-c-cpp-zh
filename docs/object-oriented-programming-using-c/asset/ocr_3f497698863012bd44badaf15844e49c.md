# Object Oriented Programming using C#

In the zip file downloaded are all classes, methods and test cases discussed in this chapter. When viewing the Solution
Explorer in Visual Studio you will see all the packages, all of the classes and you should be able to view all of the code
with the associated comments (see below).

![](bbox=[0.323, 0.166, 0.731, 0.553])

You will not be able to view or run the test fixtures with Visual Studio. Partly to overcome this we have shown
any of the test cases in this chapter.

Also inside this zip file is the automated documentation generated by the Sandcastle tool. To view the documentation go
to 'Documentation' folder and double click on the index.html page. This should load the documentation into your
web browser software.

If you install Sandcastle Help File Builder (available for free from http://shfb.codeplex.com/) you will be able to load the
file MessageManagerSystem.shfb available as part of the Message System download. You will then be able to
see the comments for the namespaces have been added to the project properties and if you need to adjust the path
appropriate path for yourself you will be able to rerun this software and see the documentation generated for yourself.
