Each object in the collection is made up of a key/value pair. When we iterate through the collection each returns a key/value pair.

Above we define kv a variable made up of a key/value pair where each is an 'int' i.e. an account number and the value is an Account object We split this pair into separate parts and store each in the respective variables ('an' and 'a'). We then display the account number and invoke the ToString() method on the account, using the result to display details of the account.
