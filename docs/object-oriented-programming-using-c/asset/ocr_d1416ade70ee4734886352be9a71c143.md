# Generic Collections and how to Serialize them

Note this method will generate an exception if the 'key' is not unique and this error should be trapped and dealt with....thought in this simple case we decided to take no action this occurs.

The TryGetValue() method requires an input argument, the key it searching for and sets the value of the second argument to the value associated with that key. In our example it sets the second parameter to the account associated with the account number. Note will be null if the account number does not exist. See code below :-

```
accounts.TryGetValue(number, out a);
```
