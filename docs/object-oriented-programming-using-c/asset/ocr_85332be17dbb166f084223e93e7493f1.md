# Testing the GetClient method

We of course test all of the methods in our system including the GetClient() method.

One case we need to perform is to test that an exception is thrown if we try to retrieve a client that does not exist. To test this we create an new empty BookofClients and try to retrieve a client from this – any client!

In this instance we would hope our system generates an unknown client exception. Since we have initialised our test by creating an empty book we should not be able to retrieve any clients unless we first add them.

Activity 1
Look at the code below and decide at which point in this code we could assert the test has shown our system has failed (point A, B, C or D).

```
[TestMethod]
public void GetClient_TestGettingUnknownClient_ShouldGenerateException()
{
    // point A
    try {
        // point B
        BofC.GetClient(1);
        // point C
    }
    catch (BankManager.UnknownClientException)
{
        // point D
    }
}
```

Feedback 1
We cannot determine if the GetClient() method has failed before we have invoked ... hence we cannot place an Assert. Fail at point A or B.

When we invoke this method an exception should be generated as our client book is empty. The try block should be terminated at this point and the catch block initiated if the code reaches point D the test has succeeded not failed. However if the code reaches point C it indicates that the expected exception was not generated and hence we can assert that the GetClient() method has failed at this point.
