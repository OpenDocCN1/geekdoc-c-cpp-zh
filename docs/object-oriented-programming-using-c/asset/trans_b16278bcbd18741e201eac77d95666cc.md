为了实现这一点，不需要对 `Account` 类或 `Bank` 类进行任何更改，但我们告诉编译器这些类是可以被序列化的。

为此，我们在每个类的前面放置 `serializable` 关键字，如下所示....

```csharp
[Serializable]
class Account
{
    // 省略类体中的代码
}
[Serializable]
class Bank
{
    // 省略类体中的代码
}
```

在我们将用于调用序列化/反序列化过程并测试结果的 `Main` 方法中，我们需要添加额外的 `using` 语句，因为我们用到了 .NET 框架的其他部分（见下文）。

```csharp
using System.Runtime.Serialization.Formatters.Binary;
using System.Runtime.Serialization;
using System.IO;
```

下面提供了一个可以演示此运行效果的完整 `Main` 方法。大部分内容是自言自明的，或者包含了我们已经熟悉的代码。与序列化/反序列化相关的新部分将在之后进行解释。

```csharp
static void Main(string[] args)
{
    Bank b = new Bank();
    Account a;
    int an = // 账号;

    a = new Account("Bert", "06/12/1963");
    b.AddAccount(1, a);
    a = new Account("Alice", "14/08/1990");
    b.AddAccount(2, a);
    a = new Account("Claire", "1/1/2000");
    b.AddAccount(3, a);

    Console.WriteLine("Stored data:");
    foreach (KeyValuePair<int, Account> kvp in b.Accounts)
    {
        int an = kvp.Key;
        Account a = kvp.Value;
        Console.WriteLine("Account number: " + an + "\naccount details: " + a.ToString());
    }

    FileStream outputFile = new FileStream("AccountData", FileMode.Create, FileAccess.Write);
    BinaryFormatter bformatter = new BinaryFormatter();
    bformatter.Serialize(outputFile, b);
    outputFile.Close();
    outputFile.Dispose();

    Bank b2 = new Bank();
    FileStream inFile = new FileStream("AccountData", FileMode.Open, FileAccess.Read);
    b2 = (Bank)bformatter.Deserialize(inFile);
    inFile.Close();
    inFile.Dispose();

    Console.WriteLine("Retrieved data:");
    foreach (KeyValuePair<int, Account> kvp in b2.Accounts)
    {
        int an = kvp.Key;
        Account a = kvp.Value;
        Console.WriteLine("Account number: " + an + "\naccount details: " + a.ToString());
    }

    Console.ReadLine();
}
```

上述代码执行了以下步骤：

- 首先，创建了几个银行账户，将其添加到集合中并显示集合。
- 接下来创建了一个输出文件。
- 创建了一个二进制格式化器（binary formatter），因为它会被序列化过程使用。
- 对集合 'b' 进行序列化，在此过程中，集合内部所有的账户对象都被序列化了（见下文代码）。

```csharp
bFormatter.Serialize(outFile, b);
```

- 为了证明此操作成功，创建了一个新的空的 `Bank` 对象 'b2'。
- 调用反序列化过程，并将输出强制转换为 `Bank` 类型。结果随后存储在对象 'b2' 中（见下文代码）。

```csharp
b2 = (Bank)bFormatter.Deserialize(inFile);
```

## 7.12 总结

.NET 集合类为存储对象集合提供了现成方法。这几乎完全让数组的使用变得多余了！

存在“无类型”集合和“有类型”集合。有类型集合（或称泛型集合）是基于泛型方法和泛型类的概念开发出来的。泛型集合的使用比无类型集合有用得多，我们在这里没有展示无类型集合。

集合类包括 `List`、`HashSet` 和 `Dictionary`。这些每个类都定义了适当的方法，其中许多方法在所有集合中通用的。

在定义要存储在集合（Sets）或作为字典键（Dictionaries keys）的对象时，需要特别注意定义“重复”的含义。因为我们需要重写继承自 `Object` 的 `Equals()` 和 `GetHashCode()` 方法。

序列化是非常强大的机制，允许通过一个简单的命令存储集合的内容及其所有相关对象。

## 8.1 编写 C# 程序的工具

无论采用何种执行方法（见 1.7），程序员都可以使用各种工具创建源代码。可以使用简单的离散工具（例如 记事本）以及根据需要手动调用的编译器来编写 C# 程序。然而，几乎所有的程序员都会使用强大的集成开发环境（IDE），它在无缝界面背后使用了编译器和其他标准工具。

还存在更复杂的计算机辅助软件工程（CASE）工具，它们将实现过程与其他软件开发生命期的其他阶段集成。CASE 工具可以获取软件分析和设计阶段生成的 UML 类图，并自动生成类和方法存根，从而减少编写 C# 代码（即实现阶段）的工作量。

CASE 工具还可以通过自动化软件测试阶段来帮助。

随着时间的推移，由于更强大的工具出现，IDE 开始整合以前仅在 CASE 工具中的功能，即它们可以完成更多程序的编写、编辑和编译。其中一种工具就是 Microsoft Visual Studio。
