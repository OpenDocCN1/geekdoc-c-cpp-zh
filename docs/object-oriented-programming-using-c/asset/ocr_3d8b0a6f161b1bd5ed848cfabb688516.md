Feedback 6 You could make a statement that all doctors have a knowledge of drugs, diagnose medical conditions and can prescribe appropriate medication.

For surgeons could say that they know how to use scalpels and other specialised pieces of equipment and they can perform operations.

According to our list all surgeons are doctors and therefore still have a knowledge of medical conditions and can prescribe appropriate medication. However all doctors are surgeons and not all doctors can perform operations.

Whatever we specify as true for doctors or trainee doctors, junior doctors etc – these specialised categories (classes) can inherit the attributes and behaviours associated with the more general class of 'doctor'.

Generalisation / stabilisation allow us to define general characteristics and operations of an object and allow us to create more specialised versions of this object. The specialised versions of this object will automatically inherit all of the characteristics of the more generalised object.

The final principle underlying Object Orientation is Polymorphism which is the ability to interact with an object as its generalized category regardless of its more specialised category.
