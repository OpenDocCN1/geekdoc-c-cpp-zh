# Object Oriented Programming using C#

# Inheritance and Method Overriding

A superclass can be declared abstract to prevent it being instantiated (i.e. objects created).

We can 'override' inherited methods to a subclass implements an operation differently from its superclass.

In C# all classes descend from the base class 'Object'

'Object' defines some universal operations which canfully be overridden in our own classes.
