# 5.1 Overloading

Historically in computer programs method names were required to be unique. Thus the compiler could identify which method was being invoked just by looking at its name.

However several methods were often required to perform very similar functionality for example a method could add integer numbers together and another method might be required to add two floating points. If you have to give these two methods unique names which one would call 'Add()'

In order to give each method a name the name would need to be longer and more specific. We could therefore call one method AddInt(int) and the other AddFloat(float) but this could lead to a proliferation of names each describing different methods that are essentially performing the same operation is. by adding numbers.

To overcome this problem in C# you are not required to give each method a name - thus both of the methods above be called Add(). However if method names are not unique the C# must have some other way of deciding which method to invoke at run time. i.e. when a call is made to Add(number1,number2) the machine must decide which of the two methods to use. It does this by looking at the parameter list.

While the two methods may have the same name they can still be distinguished by looking at the parameter list. :-
Add(int number1, int number2)
Add(float number1, float number2)
