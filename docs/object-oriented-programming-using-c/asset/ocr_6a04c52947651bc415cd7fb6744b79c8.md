# Object Oriented Programming using C#

# Case Study

```
private void btnFindClient_Click(object sender, EventArgs e)
{
    Client client;
    try{
        InputBox newInput = new InputBox("Find Client", "Please enter");
        DialogResult dialogResult = newInput.ShowDialog();
        if (dialogResult == DialogResult.OK){
            int clientID;
            if (!Int32.TryParse(newInput.Answer, out clientID)){
                MessageBox.Show("Invalid client ID, please enter integer number.");
                return;
            }
            client = clientBook.GetClient(clientID);
            MessageBox.Show(client.ToString());
        }
    } catch (UnknownClientException ex){
        MessageBox.Show(ex.Message);
    }
}
```

This action listener performs the following tasks:

+   - It opens a dialog box to ask the user for clients. As C# does not have predefined methods to create input boxes this uses a form called InputBox that was created specifically for this purpose. If cancel input boxes returns an empty string.
- It checks if OK has been pressed and the ID returned is a valid integer.
- On the client book it invokes the GetClient() method passing the ID as a parameter.
- Assuming a client object is returned, the ToString() method is invoked to get a string representation of the client and this is passed as a parameter to the MessageBox.Show() method (which displays the details of the client with that ID).
- If GetClient() fails to find a client with the specified ID it will throw an UnknownClientException - this will be caught here and an appropriate message will be displayed. This makes use of the Message property of the Exception class.
