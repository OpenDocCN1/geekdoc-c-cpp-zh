# Loops

Sometimes we are faced with the situation of having to repeat an action a number of times or until a condition is met.

In C the repetition of a series of actions is called Loop and can be of several types

# Loop For

It is used to repeat a number of times an action (example loopfor.c)

Eg.

Show screen numbers from 1 to 10

```
/* loopfor */

#include <stdio.h>

int main (void)
{
    int i;

    for (i = 1; i <= 10; i = i + 1)
    {
        printf ("\nNumber% d", i);
    }

    return 0;
}
```
