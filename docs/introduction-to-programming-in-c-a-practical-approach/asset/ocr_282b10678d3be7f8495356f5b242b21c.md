# While loop

Used to repeat an action while a condition is met (example loopwhile.c)

Eg.

Display the numbers from 1 to 10

```
```c
/* loopwhile */

#include <stdio.h>

int main (void)
{
    int i;

    i = 1;
    while (i <= 10)
    {
        printf ("\nNumber% d", i);
        i = i + 1;
    }

    return 0;
}
```
```

The while loop is similar to the for loop but is usually used when the condition does not depend on a counter but on an expression that is recalculated within the loop.
