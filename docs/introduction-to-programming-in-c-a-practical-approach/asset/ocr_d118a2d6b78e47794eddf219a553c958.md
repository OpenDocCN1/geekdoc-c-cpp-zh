```
{
    sum = sum + numbers [i];
}

/* calculate arithmetic mean */
mean = sum/100;

printf ("\nThe mean of the numbers from 100 to 200 is:% f \n", mean);

return 0;
}
```

First we define the variables that we are going to use.
Then the array is filled with the numbers from 100 to 200.
In the next loop the sum of the numbers from 100 to 200 is made.
The mean is calculated and is shown in the screen.

If we look at the definition of the array numbers we see that it has a dimension of 200 when in fact only 100 are used. It

Is usual to put the dimensions larger than what is going to be used at first because in C the limits of arrays are not checked and a typical error is to try to use an index out of range which causes unwanted effects.
