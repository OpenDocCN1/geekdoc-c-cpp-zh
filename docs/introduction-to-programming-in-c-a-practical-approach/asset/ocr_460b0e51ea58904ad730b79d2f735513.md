Display on the screen the multiplication table of 5

```
/* table of 5 */

#include <stdio.h>

int main (void)
{
    int i;
    int numbers [20];

    /* fill array data */
    for (i = 1; i <= 10; i = i + 1)
    {
        numbers [i] = i;
    }

    /* table of 5 */
    for (i = 1; i <= 10; i = i + 1)
    {
        printf ("\n5x% d =% d", i, 5 * i);
    }

    return 0;
}
```
