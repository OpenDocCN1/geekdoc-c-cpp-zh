
## 17.- Logical comparisons

In our programs we will have to make decisions about choosing between several options, decide which code to execute depending on a comparison between values.

For this, the C language provides us with several statements to choose the execution of some instructions or others depending on evaluations.

### The `if` statement

It is used to evaluate expressions and, if the result is true, to execute the next block of instructions.

E.g., suppose we have to write on the screen whether your age is less than or greater than 20.

```c
int age;

age = 26;
if (age < 20)
    printf("age less than 20 ...");

if (age >= 20)
    printf("over age 20 ...");
```

### The `if`-`else` statement

Same as the `if` statement but if the expression to evaluate is false, the `else` block is executed.

E.g., another way to code the previous example is with the `if`-`else` statement:

```c
int age;

age = 26;
if (age < 20)
    printf("age less than 20 ...");
else
    printf("over age 20 ...");
```

You can put several lines of code in the `if` or `else` enclosing it between `{ }`.

E.g.

```c
int age;

age = 26;
if (age < 20)
{
    printf("age less than 20 ...");
    printf("is young");
}
else
{
    printf("over age 20 ...");
    printf("is greater");
}
```

## 18.- Relational operators and logical operators

The relational operators that we can use in the logical expressions are:

- `==`
- `>`
- `<`
- `>=`
- `<=`
- `!=`

We can combine several expressions with the logical operators:

- `&&`
- `||`
- `!` (not)

E.g., if we want to show on screen whether you are a teenager (age between 15 and 20) or whether you are a minor (under 18 years of age):

```c
int age;

age = 26;
if (age > 15 && age < 20)
{
    printf("you are a teenager ...");
}
if (!(age > 18))
{
    printf("you are a minor ...");
}
```

## 19.- Selecting options

If we are considering selecting an option of several possible, we can do it in two ways:

- with `if`-`else` blocks
- with `switch`

E.g., to show on screen if you are 20, 30 or 40 years old.

```c
/* options */
#include <stdio.h>

int main(void)
{
    /* declare variables */
    int age;

    /* assignment of an integer value to the variable */
    age = 35;

    /* select options with if-else */
    printf("Age with if-else ... \n");
    if (age == 20)
        printf("I am 20 years old.");
    else
    if (age == 30)
        printf("I am 30 years old.");
    else
    if (age == 40)
        printf("I am 40 years old.");
    else
        printf("Age indeterminate ...");

    /* select options with switch */
    printf("\nAge with switch ... \n");
    switch (age)
    {
        case 20:
            printf("I am 20 years old.");
            break;
        case 30:
            printf("I am 30 years old.");
            break;
        case 40:
            printf("I am 40 years old.");
            break;
        default:
            printf("Indeterminate age ....");
    }

    return 0;
}
```

## 20.- Example: Basic calculator

### Problem definition

Write a basic calculator.
The user will enter the operation in the form `x op y`
and the computer will show the result of the operation.

E.g. `10.2 + 5.5`, `20.8 - 2.5`.

### Definition of the algorithm

- We must define two variables, `number1` and `number2`, and the operation to be performed (`+`, `-`, `*`, `/`).
- The user will be asked for the numbers and the operation in `x op y` format.
- The program will calculate the result of the operation and display it on the screen.

```c
/* calculator */

#include "pch.h"
#include <stdio.h>

int main(void)
{
    // operands
    float number1 = 0.0;
    float number2 = 0.0;

    /* operation +, -, *, / */
    char operation = 0;

    printf("\nEnter the operation ... \n");
    scanf_s("%f", &number1);
    scanf_s("%c", &operation, 1);
    scanf_s("%f", &number2);

    /* calculate the result */
    switch (operation)
    {
        case '+':
            printf("Result: %f \n", number1 + number2);
            break;

        case '-':
            printf("Result: %f \n", number1 - number2);
            break;

        case '*':
            printf("Result: %f \n", number1 * number2);
            break;

        case '/':
            if (number2 == 0)
                printf("Division by zero. \n");
            else
                printf("Result: %f \n", number1 / number2);
            break;

        default:
            printf("\n\nOperation not allowed ... \n");
            break;
    }

    return 0;
}
```

## 21.- Advanced topics. Loops

In this section we will see how to implement repetitions in our code.

We will define what arrays are and finally we will treat text strings.

### Loops

Sometimes we are faced with the situation of having to repeat an action a number of times or until a condition is met.

In C the repetition of a series of actions is called a loop and can be of several types.

### The `for` loop

It is used to repeat an action a number of times (example `loopfor.c`).

E.g., show on screen the numbers from 1 to 10:

```c
/* loopfor */

#include <stdio.h>

int main(void)
{
    int i;

    for (i = 1; i <= 10; i = i + 1)
    {
        printf("\nNumber%d", i);
    }

    return 0;
}
```

The `for` loop will execute the sentences within the block 10 times. First the counter `i` is initialized to one; if the condition `i <= 10` is true, the block is executed and the counter is increased; if not, the next instruction is followed.

### The `while` loop

Used to repeat an action while a condition is met (example `loopwhile.c`).

E.g., display the numbers from 1 to 10:

```c
/* loopwhile */

#include <stdio.h>

int main(void)
{
    int i;

    i = 1;
    while (i <= 10)
    {
        printf("\nNumber%d", i);
        i = i + 1;
    }

    return 0;
}
```

The `while` loop is similar to the `for` loop but is usually used when the condition does not depend on a counter but on an expression that is recalculated within the loop.

## 22.- Arrays

An array is a fixed number of elements of the same type.

E.g., instead of defining 10 variables of the same type, an array of 10 numbers can be used.

We can define 5 numbers with:

```c
int n1, n2, n3, n4, n5;
```

or with an array:

```c
int n[5];
```

In this case the array dimension is 5 elements and we can access from position 0 to 4 with `n[0]`, `n[1]`, `n[2]`, `n[3]` and `n[4]`.

### Example

Make the arithmetic mean of the numbers from 100 to 200:

```c
/* arrays */
/* calculate the arithmetic mean of the numbers from 100 to 200 */

#include <stdio.h>

int main(void)
{
    int i;
    int numbers[200];
    float sum;
    float mean;

    /* fill array data */
    for (i = 1; i <= 100; i = i + 1)
    {
        numbers[i] = 100 + i;
    }

    /* calculate the sum of all the numbers */
    sum = 0;
    for (i = 1; i <= 100; i = i + 1)
    {
        sum = sum + numbers[i];
    }

    /* calculate arithmetic mean */
    mean = sum / 100;

    printf("\nThe mean of the numbers from 100 to 200 is: %f \n", mean);

    return 0;
}
```

First we define the variables that we are going to use. Then the array is filled with the numbers from 100 to 200. In the next loop the sum of the numbers from 100 to 200 is made. The mean is calculated and shown on the screen.

If we look at the definition of the array `numbers` we see that it has a dimension of 200 when in fact only 100 are used. It is usual to put the dimensions larger than what is going to be used at first because in C the limits of arrays are not checked and a typical error is to try to use an index out of range which causes unwanted effects.

## 23.- Text strings

A string is a sequence of characters.

Text strings in C are represented by character arrays.

A string literal is a sequence of characters between double quotes.

E.g., `"this is a phrase."`

### Declaration of a string

```c
char cad[20];
```

### String initialization

```c
char cad[] = "this is a phrase";
```

In this case the array `cad` has a dimension of 17, one character for each letter and a 0 at the end to indicate when the string ends.

### Operations on Strings

There is a library with functions for string handling:

```c
#include <string.h>
```

- Concatenate two strings: `strcat(cad1, cad2);`
  - It copies `cad2` at the end of `cad1`.
  - Be careful with the size of `cad1`.
- Number of characters of a string: `strlen(cad);`
- Compare strings.
