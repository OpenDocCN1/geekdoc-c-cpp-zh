# 18.- Relational operators and logical operators

The relations operators that we can use in the logical expressions are:

+   ===
+   >
+   <
+   >=
+   <=
+   !=

We can combine several expressions with the logical operators

+   &&
+   ||
+   ! (not)

Eg.

If we want to show on screen if you are a teenager (age between 15 and 20) or if you are a minor (under 18 years of age)

```
int age

age = 26;
if (age> 15 && age <20)
{
    printf ("you are a teenager ...");
}
if (! (age> 18))
{
    printf ("you are a minor ...");
}
```
