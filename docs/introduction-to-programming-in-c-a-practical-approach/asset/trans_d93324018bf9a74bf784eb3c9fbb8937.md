

## Phase 2. 编辑程序

一旦我们知道要做什么，就必须思考如何将该功能翻译成我们选择的编程语言，在本例中为 C。

然后我们将在 Visual Studio 的编辑器中用 C 编写程序。

你可以用简单的文本编辑器如记事本编辑程序，但集成环境具有多重优势，例如缩进（让我们能更好地可视化程序）或为不同功能关联颜色（以便一目了然地看到关键字、数据类型等）

## Phase 3. 编译

程序编辑完成后，我们对其进行编译并查看是否出现语法错误。

语法错误发生是因为编译器无法理解我们在源语言中引入的某行代码。

编译器负责将 C 源代码翻译成机器语言。

## Phase 4. 链接

如果我们的项目由多个文件或模块组成，在链接过程中，外部引用会被分组并解析。

如果我们的程序此时使用了编译器或操作系统的外部功能，则会添加对外部源的引用。

链接过程完成后，会生成一个可执行文件（Windows 下为 .exe）。

## Phase 5. 执行

在此阶段我们可以执行可执行程序并查看结果是否符合预期。

如果我们检测到任何错误，必须返回编辑阶段并做出必要的更改。

在此阶段，可能出现运行时错误，因为某些变量取值超出其限制或程序逻辑存在错误。

## Phase 6. 调试

如果运行时出现错误或预期功能未正确实现，我们可以在编程环境中调试程序。

一些有用的工具是

- 逐步执行程序的选项
- 告诉程序在给定代码的行处停止执行。
- 实时显示变量的值。

## Phase 7. 测试和维护

程序必须在所有可能的情况下进行测试，如果发现故障，我们必须再次回到编辑阶段

一旦程序正确运行，它就进入 Exploitation 阶段，在其真实环境中执行（例如在请求程序的客户计算机上）

然后程序进入其维护阶段，客户会要求我们添加新功能或修改程序，因为某些功能不符合他的喜好。

## 11.- 基本概念 .. 内存 位和字节

程序及其使用的数据都存储在计算机的内存中。

计算机的内存是一系列用于存储 0 值或 1 值的“盒子”。这些“盒子”就是位，是计算机可以存储的最小信息单元。

为了提高内存访问效率，这些位可以每 8 个一组形成一个字节。

计算机的内存以字节的倍数表示

1 千字节（或 1KB）为 1,024 字节。
1 兆字节（或 1MB）为 1,024 千字节，即 1,048,576 字节。
1 千兆字节（或 1GB）为 1,024 兆字节，即 1,073,741,824 字节

## 12.- 变量。 整数和实数

### 变量

变量是 1 个或多个字节的内存区域，与其关联一个名称，以便在程序中引用它。

### 整数变量

是存储没有小数的整数的变量。
变量的类型为 **int**

整数例如为 -10、5、23000

### 示例

```
/* using integers */
#include <stdio.h>

int main (void)
{
    /* declare the variable age as of integer type */
    int age ;

    /* assignment of an integer value to the variable */
    age = 35;

    /* show age by screen */
    printf ("My age is% d.", age);
    return 0;
}
```

### 变量名

我们可以给变量起的名字是数字和字母的组合。

变量不能以数字开头

例如 Var1、age、name551nteger

### 字符变量

是存储字符的变量
字符变量的类型为 **char**

例如
car = 'A';

### 实数变量

这些是可以存储带小数点的数字的变量。
小数点用 . 表示（不是用 ,，如西班牙语）
实数变量的类型为 **float**

例如 2.9 34.89

### 示例

```
/* using real */
#include <stdio.h>

int main (void)
{
        /* declare variable as an integer value */
        float myvariable;

        /* assignment of a real value to the variable */
        myvariable = 12.75;

        /* display the variable by screen */
        printf ("My variable is% f.", myvariable);
        return 0;
}
```

## 14.- 类型转换

### 隐式转换

如果算术表达式中存在实数，则会被转换为实数值

例如
```
float vreal;
int ventera;

ventera = 5;
vreal = ventera * 10.5;
```

### 显式转换

有时为了代码清晰，我们可以强制从一种类型转换为另一种类型

例如
```
float vactual;
int ventera;

ventera = 5;
vreal = (float) ventera * 10.5;
```
