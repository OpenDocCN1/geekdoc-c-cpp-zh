# 23.- Text strings

A string is a sequence of characters.

Text strings in C are represented by character arrays.

A string literal is a sequence of characters between "

Eg. " this is a phrase. "

Declaration of a string

```
char cad [20];
```

# String initialization

```
char cad [] = "this is a phrase";
```

in this case the array cad has a dimension of 17, one character for each letter
and a 0 at the end to indicate when the string ends.

# Operations on Strings

There is a library with functions for string handling

```
#include <string.h>
```

+   - concatenate two strings
+     `strcat(cad1, cad2);`
+   
+     copy cad2 at the end of cad1
+   
+     be careful with the size of cad1
+   - number of characters of a string
+     `strlen(cad);`
+   - compare strings
