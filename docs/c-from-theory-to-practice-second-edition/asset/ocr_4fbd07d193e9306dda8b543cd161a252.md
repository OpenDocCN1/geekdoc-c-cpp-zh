# C4.6 Write a program that reads an annual income and calculates the tax according to Table 4.1

For example, if the user enters 23000, the tax is calculated as: tax = (20000-5000)*0.15 + (23000-20000)*0.3.

#include <stdio.h>

{
    float tax, a;

}
