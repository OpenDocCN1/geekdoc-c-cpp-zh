U.11.21 In math, a triangular number counts the objects that can form an equilateral triangle, as shown next.

![](bbox=[0.1, 0.75, 0.7, 0.88])

The T(n) triangular number declares the number of the objects composing the equilateral triangle, and it is equal to the sum of the numbers from 1 to n. Therefore, T(n) is expressed as T(n) = 1 + 2 + ... + (n - 1) + n and in a recursive form: T(n) = { n, for n = 0 or n = 1 ; n + T(n - 1), for n > 1 }
