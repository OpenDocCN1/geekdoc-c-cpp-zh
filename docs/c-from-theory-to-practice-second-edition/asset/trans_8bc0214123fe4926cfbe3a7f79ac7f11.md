C.5.24 编写一个程序，根据表 5.4 计算运送乘客行李的费用。程序应读取乘客的舱位类型和行李重量，并显示费用。

**表 5.4 运输费用**

| 舱位 | 重量（磅） | 费用（美元） |
|-------|-------------|----------|
| 经济舱 | ≤ 25 | 0 |
|  | >25 且 ≤40 | 超过 25 的每磅 1.50 |
|  | > 40 | 超过 40 的每磅 2.00 |
| 商务舱 | ≤ 35 | 0 |
|  | >35 且 ≤50 | 超过 35 的每磅 1.25 |
|  | > 50 | 超过 50 的每磅 1.50 |
| VIP | < 60 | 0 |
|  | > 60 | 30（固定费用） |

```c
#include <stdio.h>
int main(void)
{
    int clas;
    double cost, weight;

    printf("Enter class (1-Eco, 2-Business, 3-VIP): ");
    scanf("%d", &clas);

    printf("Enter weight: ");
    scanf("%lf", &weight);

    cost = 0; /* Covers all cases where the passenger pays nothing. */
    switch(clas)
    {
        case 1:
            if(weight > 40)
                cost = 22.5 + 2*(weight-40); /* 22.5 = 1.5 * 15. */
            else if(weight > 25)
                cost = 1.5*(weight-25);
            break;

        case 2:
            if(weight > 50)
                cost = 18.75 + 1.5*(weight-50); /* 18.75 = 1.25 * 15. */
            else if(weight > 35)
                cost = 1.25*(weight-35);
            break;

        case 3:
            if(weight > 60)
                cost = 30;
            break;

        default:
            printf("Error: Wrong traffic class\n");
            return 0;
    }
    printf("Total cost = %.2f\n", cost);
    return 0;
}
```
