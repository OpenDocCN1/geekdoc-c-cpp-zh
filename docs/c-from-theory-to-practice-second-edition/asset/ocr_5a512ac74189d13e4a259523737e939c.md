# C.8.14 Use the p1 and p2 pointers and complete the following program to display the product of even numbers from 10 up to 20.

```
#include <stdio.h>
int main(void)
{
    int *p1, *p2, i, mul;
    ...
}
```

Answer:

```
#include <stdio.h>
int main(void)
{
    int *p1, *p2, i, mul;
    p1 = &i;
    p2 = &mul;
    for(*p1=10, *p2=1; *p1 <= 20; (*p1)+=2)
        *p2 = *p2 * *p1;
}
```
