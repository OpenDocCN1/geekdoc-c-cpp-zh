## Appendix 4: Hexadecimal System

This appendix provides a brief description of the hexadecimal system. The base of the hexadecimal system is the number 16. The numbers 0-9 are the same as the decimal system. The numbers 10-15 are represented by the letters A to F. The correspondence of the hexadecimal system to the binary and decimal systems is depicted in Table A.4.1.

As shown, each hexadecimal digit (0 to F) is represented with four binary digits. For example, the hexadecimal number F4A is written in binary as 1111 0100 1010.

To find the decimal value of a hexadecimal number that consists of n digits (e.g., dₙ₋₁ … d₂ d₁ d₀), we apply the following formula:

Decimal = Σᵢ₌₀ⁿ⁻¹ (dᵢ × 16ⁱ).

For example, the decimal value of F4A is (A × 16⁰) + (4 × 16¹) + (F × 16²) = 10 + 64 + 3840 = 3914.
