Trapezoidal rule approximation.

The procedure involves the following steps:

+   a. Split the interval [a, b] into N subintervals of the same width. Therefore, x_i = x_0 + i*(b - a)/N, i = 0,...,N. For larger values of N, the approximation is closer the value of the integral.
+   b. Calculate the values f(x_i) for i = 0,...,N.
+   c. Calculate the areas of the N trapezoids formed under the polyline and add them. The integral is approximately ∫_a^b f(x) dx = E_p1 + ... + E_pN = (x_1 - x_0)*(f(x_0)+f(x_1))/2 + ... + (x_N - x_{N-1})*(f(x_{N-1})+f(x_N))/2
