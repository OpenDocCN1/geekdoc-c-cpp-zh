The MouseDragEvent is a subtype of MouseEvent which can be used to determine the object that the drag started with. DragEvent removed the members that tell you about buttons and instead has a method called drag which returns an object of type Drag that is used for transferring data. Full details and usage of drag-and-drop are beyond the scope of this book. The ScrollEvent has many of the same methods as a MouseEvent related to keyboard keys and position, it adds a few others specific to scrolling.

+   - deltaX: Double - Gets the amount of horizontal scroll.
- deltaY: Double - Gets the amount of vertical scroll.
- deltaTextX: Double - Gets the amount of horizontal text-based.
- deltaTextY: Double - Gets the amount of vertical text-based.

Mouse and keyboard interactions are demonstrated in the following program which allows the user to draw paths with the mouse then use the arrow keys to move a little circle around. The circle is not allowed to cross lines.

# Listing 12.4: DrawMaze.scala

```
import scalafx.Imports._nimport scalafx.application.JFXApp
import scalafx.scene.Scene
import scalafx.scene.paint.Color
import scalafx.scene.shape._nimport scalafx.scene.input.MouseEvent
import scalafx.scene.input.KeyCode
val app = new JFXApp {
  stage = new JFXApp.PrimaryStage {
    title = "Draw Maze"
    scene = new Scene(500,500) {
      val polyline = Polyline(0, 0, 500, 0, 500, 500, 0, 500, 0, 0, 0)
      var walls = List(polyline)

      val ball = Circle(21, 21, 20)

      content = List(ball) = (e:MouseEvent) => {
        println("Pressed")
        val oldX = ball.centerX.value
        val oldY = ball.centerY.value
        if (e.code == KeyCode.Up) ball.centerY = ball.centerY.value - 2
        if (e.code == KeyCode.Down) ball.centerY = ball.centerY.value + 2
        if (e.code == KeyCode.Left) ball.centerX = ball.centerX.value - 2
        if (e.code == KeyCode.Right) ball.centerX = ball.centerX.value + 2

        // Collision detection with walls
        val clear = walls.forall(shape =>
          Shape.intersect(ball,shape).boundsInLocal.value.isEmpty
        )
    }
  }
}
```
