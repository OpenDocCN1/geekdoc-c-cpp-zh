One of the keys to effective time usage when you are writing software is to frequently run the program to make sure what you have written is correct and the program does what you expect. You could easily go to the command line and run your code, but you would find there two problems. First, you have to manually enter 40 thousand lines of text. Second, even after you do so, the program does not print anything, so it is very hard to tell if what you have written is correct. To fix the problem, you can temporarily add the following line to the bottom of your script.

```
data.forEach(println)
```

This will print all the data that was actually read with one record per line. It will be 43,858 lines, so you are not going to check them individually to make sure they are all correct, but you will want to see that they have appropriate values in them.

To deal with the problem of needing to enter many lines of input, we are going to use redirection. You could change the value of linesInFile briefly to a smaller number of lines that you can enter by hand, but we will want to read the whole file. Input redirection is discussed in Appendix A. The idea is that we use the read command to read from a file instead of the keyboard. Another way to say that is that we want the file to be the source for input. This is done with the less symbol on the command line. # 6.7.2 Finding Maximum Values

Now that we have all the data read, we can turn to the issue of finding the most common name in each year. This also breaks down nicely into sub-problems. We need to find all the years in the data. For each year, we need to get the desired date for just that year. Given a group of data, we need to find the most common names

We will start with the last sub-problem. There are many ways we could break things down, and how we choose to do impacts the code that would be written for each sub-problem. The task of finding the most common names makes a good function, we just need to decide what that function should do

Recall that our original problem statement said to find the most common names for males and females. Given this description, it is tempting to write a function that would take all the data from one year, and return both the most common male name and the most common female names. The problem with that approach is that it is not very reusable. What if we were given the task of figuring out the most common name in each year regardless of gender, or we were processing a file that only contained a single gender?
