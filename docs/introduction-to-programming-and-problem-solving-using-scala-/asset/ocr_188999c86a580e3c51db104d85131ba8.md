    source.close
}

  case null =>
  case file =>
    val pw = new java.io.PrintWriter(file)
    pw.print(editor.htmlText)
    pw.close
}
}
exitItem.setOnAction = (ae:ActionEvent) => {

The last topic of ScalaFX that we will discuss is 3D graphics. Everything that we have done to this point has been distinctly 2D. There are a number of reasons for that, the main one being that 2D graphics are lot simpler. Despite the relative “simplicity", we have still managed to spend over 50 pages on the topic.
