4. This problem starts a track of options that you can work on to build up a functioning ray tracer at the end of the semester that can render images 3-D. In this first step you are to write a script that determines if a ray intersects either a plane or a sphere.

The script should start asking for information on the ray. That includes the start point of the ray, $\vec{r}_0$, and the direction vector for the ray, $\vec{r}$. It should then ask if you want to consider a plane or a sphere. The code will have information for the sphere, a center point and radius, and do the proper calculation for a sphere. The second will have information for the plane, a normal direction and distance, and do the proper calculation for the intersection. The script finishes by printing out information about the intersection.

A ray can be defined by a start point and direction vector using the parametric equation $\vec{r}(t) = \vec{r}_0 + t\vec{r}$, for $t \ge 0$. You find intersections by solving for the $t$ that satisfies conditions like coming a distance from a point (for a sphere) or satisfying the equation $(\vec{r}(t) - \vec{n}) \cdot \vec{n} = d$ (for a plane with normal $\vec{n}$ that is $d$ units from the origin). You can find coming within a distance from a point as solving the equation $(\vec{r}(t) - \vec{n}) \cdot (\vec{r}(t) - \vec{n}) = radius^2$. With a little algebra you can reduce this to a quadratic equation. You only care about the solution with the smaller value of $t$. This option is a bit more conceptually challenging, but if you do all the ray tracing the results can be impressive. The web site at http://programmingscala.net contains a number of images made using a ray tracer the author wrote in Scala.
