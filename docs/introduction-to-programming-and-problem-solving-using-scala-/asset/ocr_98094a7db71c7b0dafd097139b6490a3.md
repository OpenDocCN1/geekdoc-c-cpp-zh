# 14.3 Putting It Together

To illustrate the real power of XML we will make a more complete theme park program that includes the functionality of some of the earlier scripts along with editing abilities. The information will be stored in a single XML file. This last part is something that was not highlighted before, but it implicitly carries with the ability to give meaning to data. This makes it a flat text file, it is the position in the file that gives meaning to something. This makes it very hard to insert new information of different types. This is not a problem for XML as new tags can be added as desired. As long as the new tag names do not conflict with earlier tags, the code will continue to work for you.

In chapter 13 we wrote another script that could use to determine the employee of the month. Both of these deal related to employees and rides, but there is not a 100% overlap between the required data, and the files are very different. We want to write a script here will utilize the functionality of both these scripts, along with the ability to add ride and employee information while keeping all the information in a single XML file.

Code for this is below. Starts with the definition of a number of case classes followed by functions that can build instances of those case classes from XML or build XML from them. After those functions are four lines that declare the main data for the program while reading in an XML file specified on the command line. This is followed by slightly modified versions of the schema builder and employee builder from previous chapters.

import scala.io.Source
import scala.io._
case DayData(ride:String, dayOfWeek:String, operators:Array[String], numRiders:Int)
case MonthData(month:Int, days:List[DayData])
case YearData(year:Int, months:List[MonthData])
case RideData(name:String, numberOfOperators:Int, heavyCount:Int)
case EmployeeData(name:String, rides:List[String])ndef parseDay(node:Node): DayData = {
  val ride = (node = \"ride\").text
  val dow = (node = \"dayOfWeek\").text
  val num = (node = \"numRiders\").text.toInt
  val ops = (node = \"operator\").map(_.text).toArray
  DayData(ride, dow, ops, num)
}
def toXML(data:DayData): Node = {
  <ride>${data.ride}</dayOfWeek>${data.dayOfWeek}</numRiders>${data.numRiders}</operators>${data.operators.map(op => <operator>${op}</operator>)}</ride>
