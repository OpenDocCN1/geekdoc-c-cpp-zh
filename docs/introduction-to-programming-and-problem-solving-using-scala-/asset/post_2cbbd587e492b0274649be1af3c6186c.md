There are two other methods to settings on the GraphicsContext that allow you to store and recover settings. The save(): Unit method will call all the current settings and store them in a structure called a stack. You can later call restore(): Unit to bring back earlier settings. If you save() multiple times without calling restore(), they stack up and the last restore will pull off the most recently saved values. Another call will pull the values before and so on.

When you draw on it, the drawing covers up anything that is below. The clearRect method sets a region back to transparent so that you can see through to what is below.

# 12.6.3 Building a Path

Instead of drawing simple shapes, you can also build complex paths using Path type instead of Rectangle and Circle. To use this approach, you start by calling beginPath(): Unit. This starts a new path for you to work with. When you are done with a path, you can call either fillPath(): Unit or strokePath(): Unit depending on how you want to add to your drawing. After you have called beginPath, the following methods can be used to add to the path:

- appendPath(svgpath: String): Unit
- arc(centerX: Double, centerY: Double, radiusX: Double, radiusY: Double, startAngle: Double, length: Double): Unit
- arcTo(x1: Double, y1: Double, x2: Double, y2: Double, radius: Double): Unit
- bezierCurveTo(x1: Double, y1: Double, cx1: Double, cy1: Double, x2: Double, y2: Double, x: Double): Unit
- closePath(): Unit
- lineTo(x: Double, y: Double): Unit
- moveTo(x0: Double, y0: Double): Unit
- quadraticCurveTo(xc: Double, yc: Double, x1: Double, y1: Double): Unit
- rect(x: Double, y: Double, w: Double, h: Double): Unit

The behavior of these methods is similar to the ones described previously for Path.

# 12.6.4 Image Operations on Canvas

The GraphicsContext has a number of methods that deal with images. Those methods are as follows:

- drawImage(image: Image, sx: Double, sy: Double, sw: Double, sh: Double, dx: Double, dy: Double, dw: Double, dh: Double): Unit - Draw a portion of the specified image to the given destination in the Canvas. The sx, sy, sw, and sh parameters represent the rectangular region of the image or source. The dx, dy, dw, and dh parameters give the rectangular region for drawing.
- drawImage(img: Image, x: Double, y: Double, w: Double, h: Double): - Draws the specified image into the generic region of the Canvas.
- drawImage(img: Image, x: Double, y: Double): Unit - Draws the specified image with the top left corner at the supplied x, y coordinates.

There is also a method called pixelWriter that provides you with a PixelWriter that can be used to write specific pixels directly to the Canvas. Note that you cannot get a PixelReader for the Canvas, if you are writing something that needs to be read, you will need to make a WritableImage and draw to the Canvas using one of the drawImage methods.
