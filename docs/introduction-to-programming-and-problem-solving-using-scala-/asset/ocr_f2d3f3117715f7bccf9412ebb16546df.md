```
n! = \begin{cases} 1 & n < 2 \ n * (n-1)! & \text{otherwise} \end{cases}
```

In this definition, the factorial function is defined in terms of itself. To describe what factorial is, we use factorial.

To see how this works, let us run through an example using the substitution approach discussed in section 4.7 and the factorial of 5. By our definition we get that $5! = 5 * 4!$. This is because 5 is not less than 2. Secondly, we get $4! = 4 * 3!$ and finally to $5! = 5 * 4 * 3 * 2!$. This leads to $5! = 5 * 4 * 3 * 2 * 1$.

This definition and its application illustrate the two key aspects of recursion. There are two possibilities for the value of this function: when one use depends on the value of $n$. In the case $n$ is less than 2, the value of the factorial is 1. This is called a BASE CASE. All recursive functions need some kind of base case. The critical thing about a base case is that it is not recursive. When you get to a base case, it should have a value that can be calculated directly without reference back to the function. Without this you get INFINITE RECURSION. There can be multiple different base cases as well. There is no restriction that the base case is only one, but there must be at least one.

To see why a base case is required, consider what would happen without it. If we get $5! = 5 * 4 * 3 * 2 * 1!$, what would happen after that? Without a base case, $1! = 1 * 0!$ and $0! = 0 * (-1)!$. This process continues on forever. That is why it is called infinite recursion.

The second case of recursion demonstrates the recursive case: Not only does this refer back to the function itself, but it does so with a different value and that should be moving towards a base case. In this case, we define $n!$ in terms of $(n-1)!$. If the recursive were to use the same value of $n$ we would have infinite recursion again because our base case is for small numbers, not large numbers.

What else could define recursively? We could define multiplication, which using factorial. After all, at least for the positive integers, multiplication is nothing more than repeated addition? As with the factorial, we could write a definition of multiplication between two positive integers that uses a math symbol that assumes some type of recursion like this:

```
$m * n = \sum_{i=1}^{n} m
```

This says that $m * n$ is added to $n$ times. This can be written as a recursive function in the following way:

```
$m * n = \begin{cases} n = 0 \ m + (m * (n-1)) & \text{otherwise} \end{cases}
```

This function has two cases again, with a base case for a small value and a recursive case, that is defined in terms of the value we are recursing on using a smaller value of that argument.

We could use the same type of things to define exponentiation in terms of multiplication. We could also use increment (1) to define addition by higher numbers. It is worth taking a look at what that would look like:
