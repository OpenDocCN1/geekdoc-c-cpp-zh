## 3.2 The if Expression

Virtually all programming languages have a construct in them called if. For this construct, you have a condition where one thing should happen if the condition is true. If the condition is false, then neither nor something different will happen. In non-functional languages, the if is a statement. It has no value and simply determines what code will be executed. In Scala and other functional languages, the if is an expression which gives back a value. Scala allows you to use it in either way. The syntax of an if is: (condition) trueExpression falseExpression. The else is optional.

Let us start with an example, then we can broaden it to the more general syntax. Take the ticket price example and consider just the person's age. Say we want to consider whether a person should pay the $20's rate or the $35 rate. For our purposes, a child is under the age of 13. We could make a variable with the correct value by this declaration using an if expression.

```
cost = if (age<13) 20 else 35
```

This assumes that age is an Int variable that has been defined prior to this point. The first part of this line is a basic declaration as discussed in chapter 2. The next part contains an expression which checks the age and gives back one of two values depending on whether age<13 is true or false.

A code block is just code enclosed after an if or else branch you should group those with curly braces. The other thing to note about this example is that the code inside the curly braces is uniformly indented. The placement of brackets is something else to pay attention to.
