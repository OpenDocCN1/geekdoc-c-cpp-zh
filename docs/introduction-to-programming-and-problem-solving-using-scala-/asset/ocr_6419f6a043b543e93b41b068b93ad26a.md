```
def isSorted(a:Array[Double]):Boolean = {
  (0 until a.length-1).forall(i => a(i) <= a(i+1))
}
```

The fact that random access is a fast operation on an Array allows this code to be efficient.
A second approach, which is also functional, is to use a zipped tuple as is shown here.

```
def isSorted(a:Array[Double]):Boolean = {
  (a,a.tail).zipped.forall(_ case (x, y) => x <= y)
}
```

This code is a bit shorter, but significantly more advanced. In fact, it uses advanced topics from sections 8.4 and 10.4. The approach is to make a tuple that contains the original elements first and the first element. If we zipped these two collections with the zip method, the result would be a sequence of tuples with each element and the one after it in the first and last element appear only once in the first and last tuples. Such a solution would be very inefficient, if we actually construct a new set of objects and do so by copying. The advanced techniques of view and zipped are used to make it more efficient.

The first advanced topic is to use the view from section 8.4. view is a representation of a collection that does not make a full copy until forced to do so. In this code, a tail of a normal Array would produce a new Array and copy of data over it. However, the tail of the view is a small object that would interact with the code as the tail would, but through logic instead of making a copy.

The second advanced topic is to use the zipped method from section 10.4. This method allows you to more efficiently run common functions that need to go through two or three collections at the same time. Instead of making a new zipped collection of tuples, this gives you an object that has methods like map, filter, and forall declared that they take as many arguments as are in the tuple. We get a version of forall which needs a function of two arguments and can easily provide using the shorthand syntax.

Whichever approach you choose, you can test a particular sort with code like the following:

```
val nums = Array.fill(args(0).toInt)(math.random)
flaggedBubbleSort(nums)
assert(isSorted(nums))
```

This creates an Array of Doubles with a length determined by a command-line argument. It calls a sort on Array and uses the assert function to make sure it is true. Assert is a function in Scala that can be used with one or two arguments. The first argument is a Boolean that should be true. If it is not true, an error results, terminating the program. A second argument can be provided that is passed-by-name and should provide a useful message if the assert fails.

The assert function can be used generally in any code. There is a require function that performs similarly, but should be used for argument values. At the top of a function, if the function will work only on certain argument values, you can use to require to make it code fails in an informative manner when bad arguments are passed in.
