## 9.3.2 String split Method

Even lines are not always as useful that you can split a String into different pieces for on each line. There for most purposes, the simplest of these is the split method, which was introduced in section 6.7.1. The split method takes a single argument that is a String which should be the delimiter between the pieces you split up. It will return an Array[String] with everything that separated by delimiter. Here is a simple example.

```scala
scala="This is a test.".split(" ")
res7: Array[String] = Array(This, is, a, test.)
```

The String "This is a test," is split using a single space as the delimiter. The result has each word from the String as a separate element.

Technically, the argument to split is a REGULAR EXPRESSION. We will not go into the details of regular expressions in this book. They are introduced in Object-Orientation, Abstraction and Data Structures Scala]. There are a few things that are worth mentioning at this point. The regular expression can have more than one character. The characters '*' and '+' have special meanings. The '+' says that the character before it can occur once or more times. It is worth mentioning at this point because it is not unknown for inputs to potentially have multiple spaces between words. To handle this, you will often call split with "+" instead of just space.

Now we want to put the split method into action with the ability to read the line-by-line. What we want to do is create numeric data from a 2-D structure. In this case, we will create a 2-D Array where the direct access capability is useful for most of the applications we want to use in this. We will do this in two ways. We will break this up into two functions. The first function will work with any Iterator[String] and give us back an Array[Double] which we want. The Iterator[String] is helpful because what getLines is helpful.

```scala
def dataGrid(lines: Iterator[String], delim: String): Array[Double] = {
  for (l <- lines; if !l.trim.isEmpty) yield {
    for (n <- l.split(delim); if !n.trim.isEmpty) yield n.trim.toDouble
  }
}.toArray
```
