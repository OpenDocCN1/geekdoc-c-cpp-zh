# A Tip for Learning to Program

In many ways, learning to program, whether in Scala or any other programming language, is very much like learning a new natural language. The best way to learn a natural language is through immersion. You need to practice it and be surrounded by it. The key is not to simply memorize the rules and vocabulary, but to put them into use and learn them through regular usage. You should strongly consider approaching programming in the same way.

So what does it mean to immerse yourself in a programming language? Clearly you are not going to have conversations in it or enjoy television broadcasts in it. The way to immerse yourself in a programming language is to take a few minutes every day to write it. You should consider spending 15-30 minutes each day writing code. The REPL in Scala is an excellent tool for you to enter in statements to see what they do. Try to put things into use with the language. The things that you use will stick and become natural. Things that you do not use regularly you will have to look up, but that is normal. Programmers, even professional programmers with many years of experience in a language, keep references handy.

Over time, the number of lines that you write in these short time intervals will grow as the basics become second nature and you begin practice more advanced concepts. By the end of this book you will find yourself writing hundreds lines or so of functional code every days that you spend. By time you will happily pick up a 'pet project', something that you are truly interested in programming and that you will think about the logic and structure of logic much more frequently.

Early on, you might find it hard to think of anything that you can write. To help you with this, many of the chapters in this book contain a "Self-Directed Study" section, like the one below. Use these as a jumping off point for the material in each chapter. What will come is a set of exercises and often a set of larger problems projects. Remember that one of the goals of learning to program is help you familiarize yourself with the details presented in a chapter, the exercises and projects are actual problems that you are supposed to solve in a formal way you should use these to help provide you with the immersion you need to learn the language.
