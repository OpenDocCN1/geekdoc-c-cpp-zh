- 9. 这个问题与 6.12 相似之处在于你需要统计 `Array[Int]` 中偶值的数量。区别在于，现在你要分别用 `while` 循环做一次，再用 `for` 循环做一次。
- 10. 在进行实际密码学时，另一个重要问题是模运算下的线性方程。这听起来很复杂，但实际上只是以下方程的解：

> $ax \equiv b \pmod n$，

其中我们已知 $a, b$ 和 $n$，并想要找到 $x$。要找到这些解，可能有多个，对于练习 5.16 你需要使用扩展欧几里得算法。

# 循环 225
