The logic that seems odd is line 50. In earlier examples, we would have just set lastTime = t. For this example we used the "game ticks" to happen close to 0.1 seconds after posting. The timer would fire times before it got to 0.1 and often got to values around 0.115. The simple form would have caused the time to "slip" by 0.015 seconds in that situation. This might not seem much, but it is a significant fraction of the 0.1 seconds that we desire.
