Using string interpolation, this could be written as
s"$displayHours:$displaySeconds"

Complex expressions can be inserted into the string by enclosing the expression in
curly braces after the dollar.

```
scala val age = 2015-1996
age: Int = 19
cala s="$age+10 = ${age+10}"
res43: String = 19+10 = 29
```

Here $age nested inside a processed string. The s interpolation knows to insert
the variable age at location(s) in the string. There is no rule for when
use string interpolation instead of concatenation. You can pick whichever option
You find easy to read and understand.

The "f" interpolation requires that you place a format specifier after the expression.
Coverage of these format specifiers is beyond the scope of this book. The interested reader
is encouraged to look up details on his/her own. It should be noted that the format strings
used by Scala are fairly based on those used with printf in the C programming
language, and they appear in many libraries across different languages.
