# Getting to the Knows 537

```
mlewis@mlewis-laptop:~/Desktop$ ls -l
total 8
-rw-rw-rw 1 root root 1261 2008-11-28 12:21 AdobeReader.desktop
-rw-r--r 1 mlewis mlewis 250 2009-12-22 11:03 QtCreator.desktop
```

There are two files here. The first ten tell us permissions on the file. The first is either 'd' or '-'. The d would tell it is a directory. Neither is a directory so both begin with '-'. After there are groups of rwx where any of those can be replaced with '-'. The letters stand for read, write, execute permission being used when permission is not granted. The first set of rwx is the permissions of the user file belongs to. The second set is for the group file belongs. The third is for others. The first file listed gives full permissions to all three. The second gives read to the user and only read to the group and others. Shortly after the files appear two names. For the first they are both root. For the second they are mlewis. The user and group owners of. The name root is the superuser on Unix and Linux machines.

To make this interesting, use the mkdir command to make a new directory and then list the contents of the directory.

```
mlewis@mlewis-laptop:~/Desktop$ mkdir NewDir
mlewis@mlewis-laptop:~/Desktop$ ls -l
total 12
-rw-rw-rw 1 root root 1261 2008-11-28 12:21 AdobeReader.desktop
drwxr-xr-x 2 mlewis mlewis 4096 2010-08-11 19:59 NewDir
-rw-r--r 1 mlewis mlewis 250 2009-12-22 11:03 QtCreator.desktop
```

This new directory is also owned by part of group mlewis. Note the letter 'd' first on the line telling us that is a directory. The owner, mlewis, has full read, write, and execute permissions. Anyone in group mlewis will have read and execute permissions as do others. If you try to use a file/directory in a way you do not have permissions, you will get an error message. To go into a directory and see what is inside of it you may read and execute permissions.

Now that you know how to tell permissions on a file, the next question is how you change them. The chmod command is used to change permissions on a file. There are a few different ways to use chmod. We will introduce one of them here. After chmod you want to change or set permissions, give a list of the files you want to make the changes to. The simplest way to change permissions is to use character codes for which of users and the permissions involved and separate them with a '+', '-', or '=' to say if you want to add, remove, or set them. The permission sets are specified by 'u' for the user, 'g' for group, 'o' for others and 'a' for all. The rights are specified by the letters 'r', 'w', and 'x' as we have already seen.

Let us say that we are going to put things in this new directory we do not want anyone but the user to have the ability to see. In case we would want to remove the read and execute permissions from the group and others. We can see how this is done and the result of it

```
mlewis@mlewis-laptop:~/Desktop$ chmod go-rx NewDir/
mlewis@mlewis-laptop:~/Desktop$ ls -l
total 12
-rw-rw-rw 1 root root 1261 2008-11-28 12:21 AdobeReader.desktop
drwxr-x-- 2 mlewis mlewis 4096 2010-08-11 19:59 NewDir
-rw-r--r 1 mlewis mlewis 250 2009-12-22 11:03 QtCreator.desktop
```
