to pattern matching. The :: can be used in a pattern to indicate a list with different parts. This particular function List2 can be rewritten as shown here.

```
def operateOnList2(List[Int], func:(Int)=>Int):Int = lst match {
case h::Nil => 0
case h ::t => func(h, operateOnList2(t, func))
case _ => 0
}
```

You might wonder about the last case. This is not required, but if we leave it out we will get a warning telling us that the match is not exhaustive. This is not just the compiler being overly picky either. It turns out that the original method that uses an if expression is completely safe. Try calling it with an empty List and you will see why.

# 6.4 Bigger Arrays and Lists with Fill and Tabulate

The simple syntax for creating Arrays and Lists work well for short sequences. In Case of Lists, you can build a large List using :: and a recursive function, but there are even easier ways to do so with the fill and' methods. To use the fill method you specify how many elements you want, and the object you value to fill each element with. Some examples of fill might look like the following.

```
scala= Array.fill(10)(4)
res24:Array[Int] = Array(4, 4, 4, 4, 4, 4, 4, 4)
```

```
scala= List.fill(6)(23)
res25:List[Int] = List(23, 23, 23, 23, 23, 23)
```

```
scala= List.fill(6)("hi")nres26:List[String] = List(hi, hi, hi, hi, hi, hi)
```

Array and List here refer to what are called "companion objects", and like all objects, they can have methods. You can see the various methods using tab completion in the REPL. You might notice something about how the fill is called. It takes two arguments, but instead of being passed in one parameter list with a comma between, they are passed in two parameter lists. This is called CURRYING. We will discuss fully in section 7.8. The first argument is how many values we want in the resulting sequence, and the second that gives the values is.

The other thing to note about fill is that the second argument is passed in a special way "pass-by-name". This is a very powerful feature of Scala that will be covered in the next is section 7.9. For now, we will simply show why it matters. Consider the following two examples.

```
scala= List.fill(5)(math.random)
res27:List[Double] = List(0.34276326027921, 0.8128658516345523, 0.6149601139661, 0.53806172408777, 0.705727808692085)
```

```
scala= Array.fill(3)(readInt)
```
