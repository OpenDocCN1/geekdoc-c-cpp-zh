# Sorting and Searching

The swapper returns a Boolean and the List that results from a single pass. The Boolean tells us if there were any swaps done during this pass. The first two cases forming that a common theme in these sorts both the empty list and all lists with just one element are sorted, they are base cases. If there are at least two elements on the List, we compare them, and if they are in the right order, we do a recursive call on all elements after the first and give back that which is first consed onto the. In that situation, iteration was not a swap, so the value of Boolean is whatever we get from further down. If the first element should go after the second one, the Boolean is true because there was a swap, and the List is the second element consed onto the element of the recursive call.

The whole function works by calling swapper on the result if there was a swap. If it was not a swap, it returns the resulting List. Note that this function does not stop of the high elements that our imperative version did. This code could be edited to, but it is a bit more challenging.

Next is the selection sort, which is implemented as a min-sort.

```
def minSort(lst:List[Double]):List[Double] = {
  def findAndRemoveMin(lst:List[Double]):(Double, List[Double]) = lst match
    case Nil => throw newException("Find and remove from Nil.")
    case h:Nil => (h, Nil)
    case h:t =>
      val (min, rest) = findAndRemoveMin(t)
      if (h < min) h::rest else (min, h::rest)

  lst match {
    case Nil => lst
    case h:Nil => lst
    case h:t =>
      val (min, rest) = findAndRemoveMin(lst)
      min::minSort(rest)
}
```

This code is built around a helper findAndRemoveMin, which returns a tuple of the minimum value in the list and the list elements other than that minimum value. It only makes sense to call on a list with at least one element, hence the case for Nil which throws an exception. The way this function works is that it recurses to the end of the list, and begins returning the minimum and reduced list from the end forward. If the current element is smaller than the min after it, it becomes the min and the old min is consed to the returned list, otherwise the min stay the same and the current element is consed to the returned list.

The primary code in the function matches against lists of length 0 and 1, returning simple base cases in those situations. The more complex case calls findAndRemoveMin, then cons that minimum value into a recursive call of minSort on the whole list.
