# 2.5.5 Non-Integer Integers

We saw previously that if we type in a numeric value that includes a decimal point Scala tells us that it has type Double. The Double literal format is more powerful than just what we've seen so far including decimal points. It also allows you to use scientific notation to enter very large or very small numbers. Simply follow a number by an e and the power of ten it should be multiplied by. So 15000.0 can be written as 1.5e4.

The name Double is short for double precision floating point number. The full name includes information about the way these numbers are stored in the memory of a computer. Like all values in a computer, the Double is stored as a collection of bits. To be specific, Double uses 64-bits. This size is related to the double precision part. Another type called Float is a single floating point number and only 32-bits. In both cases, the internal representation uses floating point format. This is similar to scientific notation, but in binary decimal. The bits in the floating point are grouped into three parts. We call them s, m and e the value of the number is (−1)^s(1 + m)×2⁻e. The first bit in the number is the sign bit, s. When the bit is on, it is negative and when it is off it is positive. After the sign is a group of bits for the EXPONENT, e. Instead of using two's complement for determining the exponent, the exponent is biased by a value that is picked to match with the number of bits in the exponent. Using a bias instead of two's complement means comparisons between floating point values can be done with the same logic used for integer values with the same sign value. All remaining bits are used to store a mantissa, the stored mantissa is the fractional part of the number in normalized binary. So the highest bit is ½ and the rest are zero.
