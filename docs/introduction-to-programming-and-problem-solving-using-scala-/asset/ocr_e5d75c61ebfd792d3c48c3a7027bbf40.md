# 11.5.1 Text Controls

The first set of controls that we want to look at are those that deal with text. This includes the non-interactive Label as well as the TextField, TextArea, and Password. The last three are used to allow users to enter text into a GUI. The TextField is for shorter input that takes a single line. The TextArea is used for multi-line inputs. The Password is like a TextField, but it hides the types into the field. This sample code shows the use of four different controls.

Listing 11.6: TextControls.scala

```
import scalax.Includes._nimport scalax.scene.Scene
import scalax.scene.application.JFXApp
import scalax.scene.control.Label
import scalax.scene.control.TextField
import scalax.scene.control.TextArea
import scalax.scene.control.PasswordField
import scalax.scene.event.ActionEvent

var app = new JFXApp {
stage = new JFXApp.PrimaryStage {
title = "Text Controls"
scene = new Scene(500,300) {
// Label
var label = new Label("Generally non-interactive text.")
label.layoutX = 20
label.layoutY = 20

// TextField
var textField = new TextField()
textField.layoutX = 20
textField.layoutY = 50
```
