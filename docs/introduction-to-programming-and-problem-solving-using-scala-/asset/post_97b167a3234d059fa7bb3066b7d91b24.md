5. One of the early programming languages, called Logo, makes graphics by using turtle graphics (http://en.wikipedia.org/wiki/Turtle_graphics). The idea of turtle graphics is that you have a cursor, typically called turtle, that has a position, orientation, and settings. The turtle can turn and move. A simple way to encode instructions for a turtle is with a String. Different characters tell the turtle to do things. ‘F’ tells the turtle to move forward. ‘+’ and ‘-’ tell it to turn left and right, respectively. Other characters can be added to give turtle more power and later projects will give you the opportunity to do so. Using this, one could draw a square by setting the angle to 90 degrees and repeating. Make a GUI with a TextField where the user can enter a string. You might also have fields for segment length and angle. You should draw the appropriate set of lines. Ignore any characters that are not ‘F’, ‘+’, or ‘-’.

For our purposes there should be either a Button or menu to release particles. When a particle is released, it should start at one of the edges. You just need to keep track of the x, y location of it. Using a while loop the particle moves randomly around on top of a spot that already has crystal. You only need to repaint after all particles have found their place. To move the particle randomly you could use Random.nextInt(4) to get a number in the 0-3 range and move it up, down, left, or right depending on that value. If a move would put a particle outside of the image, simply ignore that move. The menu should probably run through a loop that drops 100 or so particles and lets each run. Note especially when the crystal seed is small, it can take a long time for a particle to run around until it hits something.
