# 9.5.7 Primes and Real Cryptography

The type of cryptography that you would want for your financial transactions involves significantly more than what we have covered. In particular, real cryptography makes extensive use of concepts from number theory. To understand and write cryptography algorithms do not require that you have a full and complete knowledge of number theory. There are some key concepts that you will need to understand. We will start developing them a little here and add on in future chapters with the objective that we will be able to code for the RSA public-key encryption and decryption system later in the book.

The first concept we need to consider is that of primes. A prime number is a number that is only divisible by one and itself. So the sequence of primes begins with 2, 3, 5, 7, 11, 13, 17... All the values that were skipped in this sequence have other divisors. For example, all even numbers greater than two are divisible by two and are therefore not prime. There are an infinite number of primes, and cryptography algorithms work using very large primes.

Now that we have a little refresher on primes, we can write some code that primes. For this section it will be sufficient to write a function that isPrime tells us whether or not a number is prime. Thanks to the Range type and the higher-order methods in Scala, this can be done in one line.

```
def isPrime(n:Long):Boolean = (2 until n).forall(i=>n%i!=0)
```

This code takes all the numbers between 2 and n-1 and checks whether n is divisible by any of them modulo. Recall that if a divides evenly into b then b%a==0. As long as that is not true for the values between 2 and n-1 then the number is prime.
