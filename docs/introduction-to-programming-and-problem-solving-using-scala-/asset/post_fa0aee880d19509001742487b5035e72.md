## 12.9 Media

Media, both audio and video, has become a significant part of many modern user interfaces. ScalaFX includes a number of types that we can use to add media to our applications in the scalafx.scene.media package. We will only cover the most significant of these.

Short sounds that you want to play repeatedly are best represented by the AudioClip type. The source needs to be a URL. You can create an AudioClip using new AudioClip(source: String). If you have a file in your current directory, you can simply specify "file:filename". ScalaFX supports a number of audio formats including .wav and mp3.

Longer audio files and pretty video files should not be loaded completely into memory. The media type would be used to represent such files. You create a Media instance using new Media(source: String) where the source should be a URL, like the AudioClip. In addition to audio formats mentioned above, ScalaFX has fairly general support for video, but it is not as reaching as audio. You are likely to find that you have to put some effort to get video files in formats that it is happy with. authors' experience is that the Media instance you use a MediaPlayer. If you create an instance of MediaPlayer using new MediaPlayer(media: Media). If the Media is audio, this is all that you need. For video, you would want to have it displayed in the GUI. This is done by creating a View with new View(mediaPlayer: MediaPlayer). The View is a subtype of Node and can be added to a GUI. Calling the play, pause, and stop methods on the MediaPlayer will control what is displayed in the View

A program demonstrating the use of these media types us play the top will of an AudioClip, a button on the button to control it. Most of the displays shows a video with some buttons.

# Listing 12.14: Media.scala

```scala
import scalafx.Includes.-
import scalafx.application.JFXApp
import scalafx.scene.Scene
import scalafx.scene.media.-

    }
  }
}

val playButton = new Button("Play!")
playButton.setOnAction = (ae:ActionEvent) => audioClip.play
playButton.prefWidth = Int.Max
```

## 12.10 Web

Just as media has become increasingly important in applications, so has the web. ScalaFX includes types that allow you to bring the web into your application in the scalafx.scene.web package. The most obvious of these is the WebView, which is basically fully capable web browser in a Node, so you can add it to any GUI that you want to display Web content. The WebView is really a graphical front for the WebEngine, which does the real work associated with you.

The following example uses a WebView and a TextField to make a very web browser. They are in a BorderPane with the TextField at the top and the WebView in the center. The WebView is initially set to display the page for Scala.

# Listing 12.15: Web.scala

```scala
import scalafx.Includes._
import scalafx.application.JFXApp
import scalafx.event.ActionEvent
import scalafx.scene.Scene
import scalafx.scene.control.TextField
import scalafx.scene.layout.BorderPane
import scalafx.scene.web.-

val app = new JFXApp {
  stage = new JFXApp.PrimaryStage {
    title = "Web"
    scene = new Scene(750,600) {
      val textField = new TextField
      val webView = new WebView
      webView.engine.load("http://www.scala-lang.org")
      textField.text = webView.location.value
    }
    val borderPane = new BorderPane
    borderPane.top = textField
    borderPane.center = webView
    root = borderPane
    textField.onAction = (ae:ActionEvent) => {
      webView.engine.load(textField.text)
    }
    webView.location.onChange(textField.text = webView.location.value)
  }
}

app.main(args)
```

At the end of the code, handlers are added so that when the user enters a URL in the TextField and hits enter, page will be displayed, and when the page updates from something like a clicked link, the displayed text is shown. If you enter a full URL and run it, take note of the fact that you have a full URL, using the protocol (normally http) for it to work.

Figure 12.16 shows what this script looks like you run it. You can view more content on the web with this small amount of code. One of the main things it will not do is media plays on sites like YouTube.

The other Node type in the scalafx.scene.web package is HTMLEditor. As the name implies, this type provides you with an editor that can be used to edit formatted text. The user sees an editor with controls for how they are displayed. The fact that the back end representation uses HTML is not revealed to the user. If you want to allow users to edit text between the plain text of a TextArea, this is where you would want to do in ScalaFX. import scalafx.Includes._
import scalafx.application.JFXApp
import scalafx.event.ActionEvent
import scalafx.scene.Scene
import scalafx.scene.control._
import scalafx.scene.layout._
import scalafx.scene.web._
import scalafx.stage.FileChooser
import io

val app = new JFXApp {
  stage = new JFXApp.PrimaryStage {
    title = "Rich Editor"
    scene = new Scene(600,400) {
      val menuBar = new MenuBar
      val fileMenu = new Menu("File")
      val openItem = new MenuItem("Open")
      val saveItem = new MenuItem("Save")
      val exitItem = new MenuItem("Exit")
      fileMenu.items = List(openItem, saveItem, SeparatorMenuItem, exitItem)
      menuBar.menus = List(fileMenu)
      menuBar.prefWidth = Int.MaxValue
    }
  }
}
val editor = new HTMLEditor

```scala
val borderPane = new BorderPane
borderPane.top = menuBar
borderPane.center = editor
root = borderPane
openItem.setOnAction = (ae:ActionEvent) => {
  val chooser = new FileChooser
  chooser.showDialog(stage) match {
    case null =>
    case file =>
      val source = io.Source.FromFile(file)
      editor.htmlText = source.mkString
      source.close
  }
}
saveItem.setOnAction = (ae:ActionEvent) => {
  val chooser = new FileChooser
  chooser.showSaveDialog(stage) match {
    case null =>
    case file =>
      val pw = new java.io.PrintWriter(file)
      pw.print(editor.htmlText)
      pw.close()
  }
}
exitItem.setOnAction = (ae:ActionEvent) => {
  sys.exit(0)
}
app.main(args)
```
