Later, the operations can be forced which will cause them to actually happen and provide a strict representation.

To get a View, call the view method of a collection. Operations like map and filter are done on the View give you a new View type that has a memory of what operations are to be performed, but the work will not have been done yet. You can force the operations to be applied to give you a strict representation of the data with the force method. Other methods, such as sum, which produce a final value, will also force the accrued operations to be performed. So the above could be done using Views in the following

```
numList.view.filter(_70).map(_/10-6).sum
```

This code only runs through the collection once at the call to sum and does not create any intermediate Lists. If numList were particularly long, this could provide a significant benefit.
