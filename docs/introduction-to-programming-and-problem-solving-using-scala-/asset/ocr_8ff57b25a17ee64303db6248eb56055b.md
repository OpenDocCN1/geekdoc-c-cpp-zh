# 2.8.2 Raw Strings

There are some times when using the escape characters becomes a pain. For example, there are times when you need to build strings that have a number of backslashes. Each one you want to put in there two. This can get unwieldy. In addition, if you have a long, multi-line string, it can be difficult to format the string you want. For these types of situations, Scala allows a special form of string that begins and ends with three double quotes. Anything you put between the set of three double quotes is taken to be part of the string without alteration. These types of strings are called RAW STRINGS. # 2.8.3 String Interpolation

In section 2.7.2, there were a number of expressions that put together strings using signs for concatenation. This approach can be challenging to write and read.¹ For that reason, there is an alternate approach to building strings that include values for STRING INTERPOLATION. The syntax for string interpolation is to put a "s" or a "f" in front of the string⁴ then puts expressions in the string that begin with a dollar sign if they are evaluated originally put their values inserted.
