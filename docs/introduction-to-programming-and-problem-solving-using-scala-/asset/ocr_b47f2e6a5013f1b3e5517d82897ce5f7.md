We have only begun to scratch the surface when it comes to types in Scala. By the end of this book we will see that not only are types provided by the Scala libraries we can define our own types and give them names. Still, it will be more explicit about what a type is and some of the details of types in Scala.

Let us begin with the question of what is a type. A type is a set of values and the associated operations that can be performed on those values. Consider the type Int. There are a set of different values that we can represent with an instance of Int. They are all the integer values between -2147483648 and 2147483647. There is also a set of operations that we can perform on an Int or on pairs of such as addition and subtraction.

In chapter 6 we began to see that there are more types in Scala than the basics like Int. The types List and Array are not complete on their own. They are parametric types. To be complete they have type parameters. So List[Int] is a complete type as Array[String]. List and Array are far from the only parametric types. Many of the types in Scala library are parametric as it provides them with much greater flexibility.
