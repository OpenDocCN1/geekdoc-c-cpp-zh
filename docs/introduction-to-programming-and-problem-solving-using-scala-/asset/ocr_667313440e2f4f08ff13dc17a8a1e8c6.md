# Automatic imports

Identified in the scala library and the Prelude objects are always imported by default.

Some of the types are aliases for commonly used collections. For example, List is an alias for scala.collection.immutable.List and

Other classes are referred to the underlying platform. For example, on the JVM, String is an alias for java.lang.String

types available in the Scala library and methods for them can be found in the Applications Programming Interface (API). You can find the Scala API at the main Scala website. While the API has a lot of elements that go beyond your current knowledge, it is worth giving a quick overview of how to read it and possibly find things in it.

The link to the main page takes you to the core API. Under "Documentation" you can find APIs for separate modules. If you go to the API, you will see something like is shown in Figure 7.1. The API is divided into two main segments. The left side is a list of types circles to the left of each. Each circle has an “O”, “A”, “C”, or a “T”. These stand for “object”, “class”, and “trait”. The distinction between a class and a trait is not significant to us in this book. We have been, and will continue to refer to these types as “types”. While we do not focus on the details of the “object” declaration in Scala in this book, what we create are singleton objects. classes and traits produce blueprints
