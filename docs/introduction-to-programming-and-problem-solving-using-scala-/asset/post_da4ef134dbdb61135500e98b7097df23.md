# 6.2 Using Arrays

Now you know one way to make arrays, but what can you do with them? The first things we need to be able to get the values stored in the array and change the values stored in the array. This is done by following the name of the array with parentheses and a number that is the index of the thing we want. Arrays, like with most things in modern programming languages, are zero indexed. The first element in the array is at index zero, and if there are N things in the array, the last one is at index N-1. Here is an example.

```scala
scala var arr=Array(7,4,6,3,9,1)
arr: Array[Int] = Array(7, 4, 6, 3, 9, 1)
```

```scala
scala arr(0)
res5: Int = 7
```

```scala
scala arr(1)
res6: Int = 4
```

```scala
scala arr(5)
res7: Int = 1
```

The first statement creates a new variable arr that is an array of integers and gives that array six values to store. The next three commands basically pull out values from that array. The expression arr(0) gets the first elements, arr(1) gets the second, and arr(5) gets the last.

What goes in the parentheses does not have to be a simple integer. It can be any expression of type Int. You could do something much more complex to pull out a value.

```scala
scala val i = 2
i: Int = 2
```

```scala
scala arr(i)
res8: Int = 6
```

The type of expression can also be used in assignment. So we can alter the values that are stored in an array.

```scala
arr(4) = 99
res9: Array[Int] = Array(7, 4, 6, 3, 99, 1)
```

Here we can use assignment to change the value of one of the elements of the Array. This might surprise you because originally arr was to be val. Previously we said that you cannot change what is referred to by a variable created with val. This does not actually break that rule; the name still refers to the same Array. An analogy might be that Array is a house and the values are the people. People might come and go from the house, but the house itself is the same. We can demonstrate this by trying to change arr.

```scala
arr = Array(2,7)
<console>: error: reassignment to val
arr:Array(2,5)
```

We call the Array type a MUTABLE type because the values in it can be changed. Types whose internal values cannot be changed are called IMMUTABLE types. This distinction is very significant to us in Scala and in programming in general as it alters how we deal with data. We will talk more about it because the List type, which we will explore in the next section, happens to be immutable. Indeed, all the types we have seen previously are immutable. Once they are created, the values never change. Array is our first example of something that is mutable.

Not everything about an array can be changed. As we have seen, we can change the values stored in an array. However, we cannot efficiently change how many things are stored in an array. The number of things an Array holds is the length. In fact the Array type has methods length and size which give us this information.

```scala
scala arr.length
res10: Int = 6
```

```scala
scala arr.size
res11: Int = 6
```

When you create an Array you have to specify a length that will never change. If you use a var variable you can make a new Array with a different length and have the name refer to it, but to do that you create a completely new Array you do not alter the size of the old one. There are : and += operators that make new Arrays with one additional element, but you should not use them.

Now that we know the rules for using Arrays, we can write functions that take advantage of them in a useful way. In the last chapter we used recursion to read in a set of numbers that we could do operations on. One motivation was using recursion for collections that was previously too costly to store the values up to two or more operations on them. Two useful functions might be one that fills an Array from user input and another that does the types of operations we did before, but this time on the Array.

We will start with the function to fill the Array from user input. This function needs to be passed the Array that it will fill. When we are using an Array, it will be easiest to use the style where we begin by how many numbers are to read. This is because Arrays knows its size that information does not need to be passed. What needs to be passed is the index that the next number will be beyond the end of the Array. The function to do might look like this:

```scala
def fillArray(arr:Array[Int], index:Int):Unit = {
  if (index < arr.length) {
    arr(index) = readInt()
    fillArray(arr, index+1)
  }
}
```
