## Validating XML (Advanced)

XML is used for large applications, it is important to be able to verify that the contents of a file match the format that is required by the applications. This process is called validation. When the XML standard was first released, validation was done with Document Type Definitions (DTDs). A DTD is a text file that has a fairly simple format that allows you to specify what types of elements should be in a file. For each element you can say what needs to be in or what could be in it. This ability includes attributes as well as sub-elements.

DTDs were generally considered to have two problems. First, they were a bit limited and simplistic. For example, you could say that an element must contain an attribute, but could not put any constraints on the nature of that attribute. For example, you could not say that it had to be a date. In addition, DTDs had their own syntax. The goal of XML was to be a general data format and unifying by use some format to specify what goes into XML.

For these reasons, XML schema created. XML schema is an XML document that uses tags to specify what and cannot go into other files. XML schema needs to be large and complex, but they provide great control over the format of an XML file. There are tools for both DTDs and XML schema that will run through XML and tell you whether or not they adhere to a given specification. There is also a package in the standard called scala.dtd that can help with validation.

## 14.2.5 Patterns

We have seen patterns in a number of places. With XML we can add another. Not only can XML be written directly into Scala language, it can be used to build patterns. The patterns look like what you would like, except that you put into curly braces the names you want as. There is one limitation, you cannot put attributes into patterns. This usage can be seen with the following example in REPL:

```scala
val personXML = <person><name>Kyle</name><gender>M</gender></person>
val monthXML = <month><name>Kyle</name><gender>M</gender></month>
val yearXML = <year><name>Kyle</name><gender>M</gender></year>
```

def buildWeeklySchedule: Unit = {

  val days = daysInfo.filter(_.dayOfWeek).distinct
  for (day <- days) {
    val thisDay = daysInfo.filter(_.dayOfWeek == day)
    val rides = thisDay.map(_.ride).distinct
    val operatorRiders = rides.flatMap(ride => {
      val nums = thisDay.filter(_.ride == ride).map(_.numRiders)
      val avg = nums.sum / nums.length
      val rideData = ride.find(_.name == ride).get

          works = true
        }

      }
    }
  }
}
