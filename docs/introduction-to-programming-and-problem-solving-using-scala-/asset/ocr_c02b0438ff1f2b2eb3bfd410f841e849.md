With currying, we can simply break up the arguments so that any argument that might need a block of code occurs on its own. Indeed, this is one of the reasons Array.fill and List.fill are carried. It is common to have more than one expression in the second argument. Having that second argument stand alone as its argument list allows the parenthes to be left off as we see here in this code that produces an Array with the squares of two.

```
scala var i = 1
: Int = 1
scala> Array.fill(10) {
  i *= 2
  i*i
}
res4: Array[Int] = Array(4, 16, 64, 256, 1024, 4096, 16384, 65536, 262144, 1048576)
```

This is most useful in situations like when an argument is passed by name. We will explore this more in the next section.

It is interesting to note that both of the uses of currying presented here is actually related to the original purpose of currying, which was to partially evaluate functions. The usages allow us to take advantage of the features of the Scala language. If you do enough work in Scala, you will likely find this is the case for the vast majority of currying that you use and create.

# 7.9 Pass-By-Name

Section 7.7 looked at the way in which arguments are passed in Scala. This is a style called PASS-VALUE. The function gets a copy of what the variable was in the calling code. The function cannot change variable, it can only change what it refers to if it refers to mutable. Some languages provide an alternate way of passing things PASS-BY-REFERENCE. When something is passed by reference, the function has the ability to change the variable in the calling function itself. The fact that all variables in Scala are basically references then Scala only allows pass-by-value, and the function can only modify things to the outside if the variable refers to a mutable object.

While Scala does not provide a true pass-by-reference, it provides a passing style that other languages provide, PASS-BY-NAME, which was first mentioned in section 6.4. The idea is to pass argument not as a value, but as a THUNK that is basically a set of code that will be executed and gives a value when the parameter is used in the function. You can imagine pass-by-name as automatically creating a function that takes no argument and returns a value that will be executed each time the argument is used. To help you understand this and use the syntax, we will give a simple example. We will start making a basic increment function in the way we are used to doing.

```
scala def incr(n:Int):Int = {
  println("About to increment.")
  n+1
}
incr:(n: Int)Int
```
