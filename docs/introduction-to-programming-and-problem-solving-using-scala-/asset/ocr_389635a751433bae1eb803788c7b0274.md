All that is left to figure out the minimum quiz grade. To accomplish this, we will use a method called min that is defined on the Int type. If you have two Int values, and a and b, then the expression a min on Int and could be a.min(b). However, the operator syntax, where the dot and parentheses are free, is superior if we have multiple values because we can put the values in a row to get the smallest of all of them. This gives us a complete version of the function which looks like the following.

> Use of ??? (Aside)
The code examples above used ??? in parts of the code that had not been filled in. In the three question marks is actually a construct defined in the Scala libraries, and you can put first in a script and run the script just as long as it never calls that. If the function were called, the program would crash with a NotImplementedError when the line with ??? was executed. This can be very handy when you are writing larger programs and want to test some parts of the code when you have not gotten around to completing everything.
The second example does not work because results in a type called Nothing, and you cannot do math operations with Nothing. For this reason, the ??? is generally not as helpful as an expression that is used in some way, but it is still a useful feature that you should take advantage of.
