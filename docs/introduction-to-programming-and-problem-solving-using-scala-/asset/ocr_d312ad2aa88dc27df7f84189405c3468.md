# ### 16.2.2.1 Property Assignment Methods

In the bank account example we say that in Scala a method should give you the value of a member, we give it the name you want for the property. In our example this was balance. What when you want to alter the value? In Scala, the proper style is to use the code the assignment method. The advantage of assignment method is that it allows you to set a property using normal assignment syntax. To create an assignment operator, write a method with the name prop_, where prop is the name of the property.

To help you understand, let us assume that you wanted to be enter something like myAccount.balance = 700. We had this ability with the public var, but we decided too little control. We could get back by adding the following method.

```
def myAccount.balance=(b:Int):Unit = _balance = b
```

Thanks to the way Scala handles assignment operators, this will let all three of the lines work.

```
myAccount.balance = 700
myAccount.balance += 40
myAccount.balance -= 50
```

So doing += will work like a deposit and -= will work a withdrawal. The downside is that it returns a Boolean to know if it was written. As written, neither checks the value being deposited or withdrawn.
