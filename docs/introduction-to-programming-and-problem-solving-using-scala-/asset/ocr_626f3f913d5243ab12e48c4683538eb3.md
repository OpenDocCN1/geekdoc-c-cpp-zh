This code uses the underscore for some imports as we are using multiple types from those packages. It then goes through and creates several Nodes to place in the scene. Each element that is placed on the screen is a Node. In addition to a Button, it includes a Rectangle, a Label, a CheckBox, a ComboBox, and a ListView. The end of the block for the scene sets the contents to a List that includes all of those elements. The layoutX and layoutY of each one are set so that they do not overlap.
