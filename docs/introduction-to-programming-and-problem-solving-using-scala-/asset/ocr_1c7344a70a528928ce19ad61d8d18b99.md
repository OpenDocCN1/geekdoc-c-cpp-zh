a for loop, it is converted to appropriate calls to foreach, map, flatMap, filter.
in this way, the implementation can be optimal for the collection type in question.
Also, because it is common to have multiple generators, if guards, and variable
declarations in for loops, Scala allows you to leave out semicolons and newlines
if you intend to do so all in braces inside of parentheses.

#  3.3.7 Multidimensional Sequences and for Loops

In chapter 7 we saw that the type system allows us to do things like make
Arrays of Arrays. At this point you might wonder how you could produce such things with
for loops. It is tempting to think that using multiple generators might that, but the
example of the grid of points above makes it clear that doesnt happen. If you want
to have a construct with higher dimensions, you need to have nested for loops. As
an example of this, we will use for loops to build the multiplication table we built in

val multTable = for (i <- 0 until 10) yield {
