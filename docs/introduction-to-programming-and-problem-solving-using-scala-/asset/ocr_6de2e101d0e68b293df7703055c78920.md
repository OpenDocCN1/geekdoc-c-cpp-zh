The radix sort uses a similar approach, but it is a specific algorithm for sorting integer values. It values one digit at a time. In a counter-intuitive way, it starts from the least significant digit. This only works because each pass preserves the order of the elements. If a A has a lower digit than B in one, and the next pass puts them in the same bin, A will come before B in that.

By convention we will implement radix sort using decimal digits and modulo of powers of ten. The following code is a reasonably efficient implementation that sorts an Array[Int] using an Array[Int] for the bins. Note that moving items to the bins is not an in-place operation. The values are copied back to the Array after binning, but it requires at least twice the memory of an in-place

```
def radixSort(a:Array[Int]):Unit = {
  var max = a.max a.abs
  var powerOf10 = 1
  while(max>0) {
    val byDigit = Array.fill(19)
    for (num <- a) {
      val digit = num/powerOf10%10+9
      byDigit(digit) += num
    }
    var i = 0
    for (bin <- byDigit; num <- bin.reverse) {
      a(i) = num
      i += 1
    }
    powerOf10 *= 10
    max /= 10
  }
```

The max variable starts with the largest magnitude and is divided by ten each time the variable keeps track of what digit we are currently binning. Each time through the loop, empty bins are set up. You might wonder why there are 19 bins instead of 10. The answer is that division and modulo preserves sign. If you use 10 bins, this sort can only work on positive values. By going up to 19, it is able to handle negative numbers as well. To make that, the bin value we get from division and modulo is incremented by 9 so that the values slide up to the domain of the Array indices.

The binning runs through all the numbers in the Array and carries onto the List for the proper digit. Consenting to a List adds to the front. For that reason, the loop that moves the values back to the Array runs through each bin in reverse.
This sorting algorithm is O(kn) where k = [log10(max)]. In the case of an Int, k cannot be larger than 10. The performance scales linearly for really large Arrays.
