A more general description of the syntax of the for loop would be the following-

```
for (name <- collection) statement
```

The name can be any valid Scala name. The collection can be any expression that results in a collection. The statement can be anything that you want to happen. Frequently a code block is used, and you will see multiple statements in curly braces.

Let us use a for loop to evaluate a polynomial. We will treat Array[Double] as the polynomial where each element is a coefficient of a term in the polynomial. For example, the polynomial 3x²+6x²-4x+7 is represented as Array(3.0,6.0,-4.0,7.0). We want to evaluate the polynomial for a particular value of x that will be passed into the function. We will write this in three ways. The first one will be a counting loop.

```
def evalPolyCount(coefs:Array[Double],x:Double):Double =
  var ret = 0.0
  for (i <- 0 until coeffs.length)
    ret += coeffs(i)*math.pow(x,coeffs.length-1-i)
  ret
```

This will work, but it is particularly inefficient. The use of small integer exponents is very inefficient. Walking the Array with the index is not bad, if we decided to use a List for the coefficients that would change.

Recall that the for loop is intended to go through the elements of a collection. As such, we could just run through the elements of coeffs and perform the math. The only challenge in this is that we were using the index, i, to calculate the power of x as well. We could get rid of that and remove the use of pow if we simply went through the Array in the reverse order. Putting that logic into code produces.

```
def evalPolyReverse(coefs:Array[Double],x:Double):Double =
  var ret = 0.0
  var power = 1.0
  for (c <- coeffs.reverse)
    ret += c**power
    power *= x
  ret
```

This version does not count with an index. Instead it runs through the array elements. Each value in the Array is put into c and the return value is incremented. A separate variable power is created with a value of 1.0 and each time it is multiplied by x. This provides us with a running power of x and removes the need to call math.pow.

This function is also perfectly correct. Its main drawback is that in order to go the powers of x Array to be reversed, that will create a completely new Array and copy the elements across the reverse order. While that is inefficient, this allows us to nicely illustrate the usage of the for loop to run through any collection, even one that was created through operations on other collections.
