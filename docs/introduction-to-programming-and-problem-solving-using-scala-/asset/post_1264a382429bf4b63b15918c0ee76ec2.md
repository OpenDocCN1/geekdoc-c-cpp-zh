
## 12.1 Shapes

Some of the examples in chapter 11 draw a rectangle by putting a Rectangle in the Scene. The Rectangle type is one of number of different types in the scalafx.scene.shape package that you can use to draw lines in a scene. In this section we will look at the different options that are part of that package. These are not the only way to draw in a ScalFX GUI. We will look at another option, the Canvas node, in section 12.6.

The Rectangle type is one of several subtypes of Shape in scalafx.scene.shape. Here is a full list of the subtypes of Shape. Each has a description and a proper syntax for how you would create one in code. Note that the code you use for instantiating these objects does not involve new.

- Arc: Creates an arc with a specified angle and can be filled in. You create one with Arc(centerX, centerY, radius, radius, startAngle, length), where each argument is a Double. The startAngle and length are measured in degrees. The way in which it is drawn and filled depends on the type property which can be one of the following: ArcType.Chord, ArcType.Open, or ArcType.Round.

- Circle: As the name implies, it makes a Circle. You can create it with one of the following options: Circle(fill:Paint), Circle(radius:Double, fill:Paint), Circle(centerX:Double, centerY:Double, radius:Double), or Circle(centerX:Double, centerY:Double, radius:Double, fill:Paint).

- CubicCurve: Draws a bezier curve. You can create one with new CubicCurve. Then you have to set eight values. Those are start, start, controlX1, controlY1, controlX2, controlY2, endX, and endY.

- Ellipse: Draws an ellipse with a specified center and radius. You build one with the center at (0, 0) using Ellipse(radiusX, radiusY) or specify the center using Ellipse(centerX, centerY, radiusX, radiusY). All arguments have Double.

- Line: Draws a line between two points. You can create it with Line(startX, startY, endX, endY). All arguments have Double.

- Path: Paths are formed by combining lines, arcs, and curves. The Path type allows you to create a complex path by putting together different elements. You create one using new Path. The details of the path elements are described in section 12.1.1.

- Polygon: Generates a polygon with the syntax Polygon(points:Double*). Note that this is a variable length list. The arguments are taken in x, y coordinates, so a triangle would have six values, a quadrilateral would have 8 arguments, etc. This shape is automatically closed if the last point is not the same as the first.

- Polyline: Creates a shape from a sequence of line segments with the syntax Polyline(points:Double*). Note that this is a variable length list.

> Setting the type property requires a little extra effort because 'type' is a keyword in Scala, used for declarations. In order to use keywords as identifiers in Scala, they must be enclosed in backticks. This is the character on the top left of UK keyboards. If you want to set this, you cannot use arc.type = `type` = ArcType.Open.

- QuadCurve: Draws a quadratic Bézier curve. You create one with QuadCurve(startX, startY, controlX, controlY, endX, endY). All the arguments have type Double.

- Rectangle: As we have seen, this creates a basic rectangle. There are three ways to construct one: Rectangle(width:Double, height:Double, fill:Paint); Rectangle(x:Double, y:Double, width:Double, height:Double) and Rectangle(width:Double, height:Double). The x and y coordinates for the rectangle are at the top-left, center in both x and y.

- SVGPath: Creates a path by parsing a String that is formatted with SVG* commands. You can then set the content to a String like the following path.content = "M410,110 L140,190 C490,190 490,110 410,110"; This moves to a location, draws a line from there, then has a cubic curve that goes back around the points moved to create create a shape like "D".

- Text: This type is found in the scalax.scene.text package instead of scalax.scene.shape. It can be used to add general text to a scene. You can build this with new Text(x:Double, y:Double, t:String) or new Text(t:String).

The use of all these techniques with the exception of Path is shown in the following code.

## 12.1.1 Path Elements

The Path type allows you to build up more paths by adding various subtypes of PathElement. This allows you to make a single Shape that includes some of the line and curve types that were shown. To make a Path you call new Path, then add the items you want into elements member. You generally begin with a MoveTo that positions the starting location of the Path. Subsequent elements begin from the current element and specify where they will end being placed. Here are the different PathElement subtypes that can be added to a Path, along with the code you would use to create them.

- **ArcTo**: Adds an arc from the current location to some x, y location. An arc is essentially a piece of an ellipse. You can specify the radius of the arc in both x direction and y direction as well as the angle of rotation of the ellipse it is taken from. There are also options for which you want the longest distance along the ellipse or the shortest distance along the ellipse to create the arc, which you can create using ArcTo(radiusX:Double, radiusY:Double, xRotation:Double, x:Double, y:Double, sweepFlag:Boolean).
- **ClosePath**: As the name implies, it closes off a. When it draws a line back to the start of a path you create this with new ClosePath. You have to use new here. This is because there are no arguments for this element.
- **CubicCurve**: Adds a Bézier curve to the path starting at the current location and using the specified control points and end point. You create one with CubicCurve(controlX1:Double, controlY1:Double, controlX2:Double, controlY2:Double, x: Double, y: Double).
- **HLine**: Adds a horizontal line to the path that moves from the current position to the specified x-coordinate. Create one with HLineTo(x:Double).
- **Line**: Adds a line to the path that connects the current position to a specified end point. Create one of these with Line(x:Double, y:Double).
- **MoveTo**: This moves the current position to a new location without drawing anything. You can imagine this as picking up your pen so you can start drawing somewhere. You generally want to start a Path with one of these. Create one of these with MoveTo(x:Double, y:Double).
- **QuadraticCurve**: Adds a quadratic Bézier curve to the path that goes from the current position to the end position using the specified control point. Create one of these with QuadraticCurve(controlX: Double, controlY: Double, x: y: Double).
- **VLine**: Adds a vertical line to the path from the current position to the specified y-coordinate. Create one of these with VLineTo(y:Double).
