### Scala on your Machine

If you are using Scala on a machine, it is possible that entering scala or scalac on the command line could produce a message telling you that the command or program could not be found. This happens because the location of the installed programs are not in your PATH. The PATH is a set of directories that are checked whenever you run a command. The first match that is found for any executable file in a directory in the PATH will be run. If more of the programs in the PATH matches what you entered, you get an error.

When you installed Scala, a lot of different stuff was what you installed into the directory. That included a subdirectory called "bin" with different files in it for the different executables. If you are on a Windows machine, odds are that you installed the program in C:\Program Files\scala (x86)\scala the scala.bat file that you want to run is in C:\Program Files\bin\scala.bat. You can type that in full command or you add the bin directory to your PATH. To do this go to Control Panel, System and Security, Environment Variables, and edit the PATH to add C:\Program Files\bin to the path.

Under Unix/Linux you can do this from the command line. Odds are that Scala installed in a directory called scala in your user space. To add the bin directory to your path you do this the following:

```
export PATH=$PATH:home/username/scala/bin
```

Replace "username" with your username. To make it that you d not have to do this every time you open a terminal, add that line to the appropriate configuration in your home directory. If you are running the Bash on Linux this would be .bashrc.

> ^1On a Windows system this command should be followed by ".bat".
