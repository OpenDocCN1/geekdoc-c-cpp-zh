```
ObservableBuffer(planets.map(p => XYChart.Data(p.a,\ Number,

val tilePane = new TilePane
tilePane.children = List(pieChart, barChart, scatterChart)
tilePane.alignment = Pos.TopCenter

root = tilePane
```

The result of running this code can be seen in figure 12.14. As usual, the code begins with a number of imports, this time includes scalafax.scene.chart. That is followed by the general setup of the app, the stage and the scene. Lines 14-22 define a case class and a list of instances that it provide the data to be used for plots. This data has the planets in our Solar System with their masses in units of Earth mass and the semimajor axis (average distance from the Sun) in AU.¹

Line 24 creates a PieChart to show how much of the solar system, outside of the Sun, is in. This is done by passing PieChart ObservableBuffer filled with PieChart data. All the charts in ScalaFX will update if the values are changed. This can be used to see some effect in some applications. There is also a property of the charts called animated that will cause such changes to be animated if it is set to true. In this case, the contents of the ObservableBuffer are created by mapping over the planets pulling out the names and masses. The use of *: is noted.
