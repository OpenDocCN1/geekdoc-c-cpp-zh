# 9.4 Writing to File

Scala does not provide any functionality for writing to files in its own libraries. That is something that is already supported by Java and Adding Scala libraries has not been seen as a significant benefit. There are many ways to set up a file to write in Java. The easiest approach, and the one that we will use, is the java.io.PrintWriter. We can make a new PrintWriter with new and telling the name of the file we want to write to. So we can get a PrintWriter that we can use for doing output with this code.

```
import java.io.PrintWriter
val pw = new PrintWriter("output.txt")
```

Now we could call on pw which will cause things to be written to that file. You can use print and println methods to print the file in the same way that you have done using those functions in Scala to print standard output.

Using this we could write the code to print 100 random points with x and y values between 0 and 1.

```
for (i <- 1 to 100) {
  pw.println(math.random() + " "+math.random)
}
pw.close()
```

The last line is critical because the PrintWriter is also used as a file resource with buffering, just like the BufferedSource. However, it holds things in memory until there is enough to make it write to the disk. If you do not close the file, the file in the buffer will not have been written out. If you are not done with the file, but you want to make sure that you have written into the file, you can use the flush method.

flush

When you call this, anything in the buffer will be written out. This way the computer crashes, loses power, or something goes wrong, that information will be out of the volatile memory.
