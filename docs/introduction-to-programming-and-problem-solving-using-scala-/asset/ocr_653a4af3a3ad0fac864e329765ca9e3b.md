The different options in the "File" menu also have keyboard accelerator values for them. These allow the user to quit the program simply by pressing Ctrl-X on their keyboard or invoke the "Save" option with Ctrl-S. Having shortcuts like this is never required for a program, but it can make things much faster for users who are using the keyboard.
