# A.1.1.5 Compression/Archiving

If you spend much time on a system, you will likely need to interact with compressed or at some point. Both of these play the role of taking many separate files and turning into one large file. Archiving is used to collect multiple data files into a single file for easier portability and storage. Compression is used to reduce the size of the file to save space or share more easily. A large compressed file should be smaller than the sum of the files that went into it. Later, the file can be expanded back to its original size. Many programs that you might want to put on your computer in the form of compressed files. If you have assignments or projects that your instructor might want you to combine into a single file to turn them in. There are many different compression and archiving utilities. We will just talk about the ones here.

+   - tar Archive files to a single tarball.

+   - gzip/gzip Compress one or more individual files to the gzip format.

+   - zip/zip Compress multiple files to a single zip file. The zip format is used extensively over many operating systems.

The first two are used in the Unix/Linux world. They do archiving and compression separately, but are often used together to do both. The archiving is called tar. It was originally created for archiving files from disk to tape. It collects multiple files into a single file called a tarball. It can also extract files as a tarball. With our other programs, tar is controlled by passing arguments. You can use the man pages to see the many different options for tar. We will use only the basic ones.

The three ways you will interact with a tarball are to create one, view the contents of, or extract from one. These different options are given with the characters c, v, and x. Most of the time you will want to interact with a file, and the tarball will give you the f option. The next thing after the f option should be the filename of the tarball you are creating, viewing, or extracting. Tarball files typically end with the extension .tar.
