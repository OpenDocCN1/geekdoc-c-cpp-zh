There are many ways that we could do this, but given that our only functionality is to add grades and calculate averages, the solution is fairly clear. Our only options is Arrays and Lists. Arrays have a fixed size and are inefficient to add to. There is not ideal for this application because we will be adding grades and not specified how many there can be. So Lists make more sense. We will use three Lists to store the three different types of grades. If we do this in an imperative style, the Lists will be declared with var before the recursive function. If we use a functional style, they will be passed into the next call for the iteration. We will look at both to illustrate the differences. Most of the functions will not be altered by this distinction.
