# A.2.1 Command Line

Most people interact with Windows using the GUI. This is so much the case that you might not even realize there is a command-line interface. The Command Prompt is the command line interface program used to execute commands in Windows. How you access this program depends on the version of Windows you are using. In Windows 7, it shows you the Accessories option on the Programs menu you will see an option for Command Prompt. In Windows 8, you can access it by right-clicking on the Start button or pressing the WIN key and X key together. Each of these actions brings up a menu with Command Prompt as one of the options.9 If you select and run this, you will see a window that looks like figure A.2. The terminal for Unix/Linux, this is a text interface that gives you one type of prompt with basic information. In fact it shows the current directory followed by '>'. We are in the directory C:\Users\alewis.

While the command prompt looks and acts much like Unix/Linux, it has a different set of commands. The history of Windows and its command prompt are rooted in DOS (Disk Operating System) and the commands that are used in the command prompt for Windows are largely the same as for a purely command-based operating system. One of the differences is that unlike Unix/Linux, the Windows system is not case sensitive. Commands will be presented here in lowercase, but they will work in uppercase or mixed case.
