# Shape Settings

![](bbox=[0.207, 0.071, 0.792, 0.335])

**FIGURE 12.3:** The window that is produced by running ShapeSettings.scalla. The three triangles at the top demonstrate the three types of Paint that are available as well as the three types of joins. The lines at the bottom demonstrate dashing and the cap styles.

startY: Double, endX: Double, endY: Double, proportional: Boolean, cycleMethod: CycleMethod, stops: List[Stop]. The only difference between the two is the last argument. The sample code uses the first option and NoCycle. Note that the Stops are created using Stop(offset: Double, color: Color).
The third polygon uses a RadialGradient for the fill. This creates a circular or elliptical pattern of colors. You can provide an orientation and length for the ellipse as well as the center and radius for the pattern. Using the LinearGradient, you then specify the CycleMethod and the Stops. You can construct a RadialGradient using RadialGradient(focusAngle: Double, focusDistance: Double, centerX: Double, centerY: Double, radius: Double, proportional: cycleMethod: CycleMethod, stops: Stop*) or RadialGradient(focusAngle: Double, focusDistance: Double, centerY, radius: Double, cycleMethod: CycleMethod, stops: List[Stop]). The code uses the first option. For the CycleMethod it uses Ref.

There are more options for stroke than there is for the fill. The properties that you can set as their types and possible values are here.

+   - **stroke**: Paint - The color of the lines. Graphics are allowed.
- **strokeArray**: ObservableBuffer[Double] - Lengths in pixels for how long a section should be drawn or not drawn.
- **strokeDashOffset**: DoubleProperty - An offset for the dashing begins.
- **strokeLineCap**: StrokeLineCap
    - StrokeLineCap.Butt - Ends the line at the end with no cap.
    - StrokeLineCap.Round - Puts a round, half-circle, cap on the end of the line.
    - StrokeLineCap.Square - Puts a square cap with size equal to the width at the end of the line.
