+   8. This is a continuation of project 12.5 on turtle to draw fractal shapes generated with L-systems. You can find a full description of L-systems in “The Beauty of Plants”, which can be found on-line at http://algorithmic.org/papers/#abop. The first chapter has all the material that you will need for this project and a later one.

In the last turtle you made it so that you could use a turtle to draw figures from Strings using the characters ‘F’, ‘f’, and’. L-systems are formal grammars that we will use to generate strings that have interesting representations. An L-system is defined by an initial String and a set of productions. Each production maps a character to a String. So the production F -> F-F++F-F will cause any F in a String to be replaced by F-F++F-F. The way L-systems works is that all productions are applied at the same time to all characters. Characters that do not have productions just stay the same.
