# 13.7.1 Summary of Concepts

+   - The operation of ordering data according to some value is called sorting. A common operation on a computer as it benefits humans who view the data as well as programs when they process it. Several types of sorts were discussed in this chapter.
- A bubble sort runs through the Array comparing adjacent elements and swapping if they are out of order. This action is repeated until all the values are in proper order.
- A sort picks specific elements and puts them into place. We demonstrated a minSort, which finds the smallest unsorted element and swaps it to the correct location. Selection sort does few swaps so it is most useful in a situation where moving data is an expensive operation.
- An insertion sort takes each element and pushes it through the Array until it gets into sorted order with the elements that came before it. Insertion sort is extremely efficient in situations where the data starts off-center.
