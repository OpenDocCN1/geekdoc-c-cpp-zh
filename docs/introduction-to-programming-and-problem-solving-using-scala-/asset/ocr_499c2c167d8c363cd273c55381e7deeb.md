Figure 13.1 allows the user to specify how many numbers are to be sorted on the command line. If they do not give any value, 300 will be used. We also define a constant on line 13 for the height that will be drawn so that the 300 does not become a MAGIC NUMBER in the code. A magic number is a number that appears multiple times in code whose meaning is not always clear. Magic numbers make code harder to read and understand. They also make it harder to modify and maintain. In this case, 300 appears twice if we did not define drawHeight and just used nestSort it would be challenging to alter either without messing up at least one of the other.

Lines 15 to 25 define the function that actually draws out our array to a GraphicsContext. The array values are drawn as black lines.
