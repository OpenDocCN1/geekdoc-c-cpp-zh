# 12.13.2 Exercises

+   1. Create a pane that draws several geometric shapes with different types of paints and strokes.
2. Use the scalafx.scene.shape package to create interesting shape.
3. Write a program that displays a 10 x 10 grid.
4. Write a program that allows the user to move a ball in a scene left, right, up, and down. Check the boundaries to prevent the ball from moving out of bounds.
5. Use a gradient style paint and Timer to make a pattern where the colors dance.
6. Use a dotted line on a wide stroke along with a Timer where the dotted line moves with the Timer ticks.
7. Write a script where you control the movement of a geometric figure with the arrows keys. Put another figure at the location of the mouse click draw in a different color when the two intersect.
8. Polish the evade game.
9. Write a program that creates a user interface for displaying an address book that contains a person's name, street, city, and zip. Your GUI should also contain buttons that allow the user to add a new name to the book, go to the first name in the book, go to the next name in the book, and go to the last name in the book.
10. Write a traffic light program. This program lets the user select one of three lights: red, yellow, or green by selecting a radio button. When a color is selected, the appropriate light is turned on. Only one light can be on at a time. No light is on when the program starts.
11. Write a program that draws a circle or a square. The user selects which figure they want to draw by clicking on a radio button. You should also allow the user to select whether or not the shape is filled by selecting a check box.
