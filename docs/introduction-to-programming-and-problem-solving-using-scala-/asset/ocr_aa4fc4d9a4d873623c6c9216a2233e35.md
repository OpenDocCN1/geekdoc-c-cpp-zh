mkString - Can be called with zero, one, or three arguments. It builds a single long from the string representations of the elements. If no argument is provided then nothing is between the elements. If one argument is specified, it should be a string that is used to separate the elements. If three arguments are specified the middle is a separator and the first and last are strings to put before and after the elements.

```
scala = lst.mkString
res55: String = 746391
```

```
scala = lst.mkString(" ")
res56: String = 7; 6; 3; 9; 1
```

```
scala = lst.mkString("[", ", "]")
res57: String = "[7, 4, 6, 3, 9]"
```

patch - This powerful method allows you to produce new sequences which have been removed from and inserted into the original sequence. It takes three arguments, an index to start patching, the elements to put in the patch, and the number of elements to replace with the patch. If the replacement is an empty collection, it simply removes the specified number of elements. If the elements are given as zero, it will only insert the new elements at the given location.

```
scala = lst.patch(3,Nil,2)
res58: List[Int] = List(7, 4, 6, 1)
```

```
scala = lst.patch(3,List(10,11,12),0)
res59: List[Int] = List(7, 4, 6, 10, 11, 12, 3, 9, 1)
```

```
scala = lst.patch(3,List(10,11,12),3)
res60: List[Int] = List(7, 4, 6, 10, 11, 12)
```

reverse - Takes arguments and produces a new collection in the reverse order.

```
scala = lst.reverse
res61: List[Int] = List(1, 9, 3, 6, 7)
```

toArray - Takes no arguments and makes a new collection of the type specified with the elements in the current collection.

```
scala = lst.toArray
res62: Array[Int] = Array(7, 4, 6, 3, 9)
```

zip(that:Iterable[B]) - Takes another collection as an argument and produces a collection of tuples where the first element comes from this collection and the second comes from the collection passed. The length of the result is shorter of the two.

```
scala = lst.zip(lst.reverse)
res63: List[(Int, Int)] = List((7,1), (4,9), (6,3), (3,6), (9,4), (1,7))
```

```
scala = lst.zip(Array(1, 2, 3, 4))
res64: List[(Int, Int)] = List((7,1), (4,2), (6,3), (3,4))
```
