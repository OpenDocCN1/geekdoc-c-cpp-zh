The recursive way to do this is to imagine that you have an oracle that could tell you the answer from any of the neighboring squares and figure out how you would combine values to determine the distance from where you are. As we said earlier in the chapter, we write a recursive function by assuming we have one works, and we base on that assumption. Once we are done, assuming we have handled the cases properly, it will work. The oracle is our assumed working function. If you are in a maze and you can ask the oracle to tell how many steps it takes to get out of the path to the north, south, east, and west, how would you use that information to determine the shortest distance from where you are?

To make this more concrete, picture yourself at a four intersection. You ask the oracle about each direction and get values of 7, 13, 4, and 19. The shortest path lies in the direction that you give back 4. However, that is the distance from one step in that direction. The minimum distance from where you are one greater than, or 5 steps. It is the minimum of four, one step to get to that location. The solution of taking the minimum also points in the proper direction for the base case of hitting a wall or going out of bounds. If the best solution is minimum, we return a number that cannot possibly be for a bad path. A large number such as one billion will suffice for any maze. You might be tempted to use Int. MaxValue, but remember that we are adding 1 to it. Try Int.MaxValue+1 in the REPL and you will see that this is not an ideal choice.

Defines our recursive nature. This is only one factor that needs to be considered. If you are in a hedge maze or some other maze where you cannot see the walls, it is quite difficult to tell one location from another, and unless you do something to mark your previous locations you can run up in circles and never finding your way out. A famous solution to this problem was discovered by the Grimm and Gretel who left breadcrumbs to mark their path. We will choose the same approach. Assuming you have no birds in your computer this should work better for you than it did for the children. If you have birds in your computer, you should probably deal with that before reading on.

The last factor for which our algorithm is to drop breadcrumbs to mark our path. If we ever come back upon our breadcrumbs we will sweep up our breadcrumbs before we return from a path. This was not required by Hansel and Gretel who simply wanted to be able to find their way back. However, not leaving breadcrumbs over all the place would cause us to miss such a path. Coding this all to the following

```
def shortestPath(maze:Array[Array[Int]], x:Int, y:Int, endX:Int, endY:Int): Int = {
  if (x==0 || y>=maze.length || x>=maze(y).length || maze(y)(x)!=0) {
    1000000000
  } else if (x==endX && y==endY) {
    0
  } else {
    maze(y)(x)=1
    var dist=shortestPath(maze, x+1, y, endX, endY) min
    shortestPath(maze, x-1, y, endX, endY) min
    shortestPath(maze, x, y+1, endX, endY) min
    shortestPath(maze, x, y-1, endX, endY) + 1
    maze(y)(x)=0
    dist
  }
}
```
