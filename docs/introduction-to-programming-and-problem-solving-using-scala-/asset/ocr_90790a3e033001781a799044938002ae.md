# 11.3 Stages and Scenes

The Stage type that was created in our first little application is what defined the window that popped up. To make the GUI more interesting, we need to put things on our Stage. This is done by adding a Scene to the Stage. That Scene can then have contents that will show up in the window. The following example demonstrates adding a Scene with one thing inside of it to your GUI.

Listing 11.2: JButton.scala

```
import scalafx.application.JFXApp
import scalafx.scene.Scene
import scalafx.scene.paint.Color
import scalafx.scene.control.Button

val app = new JFXApp {
  stage = new JFXApp.PrimaryStage {
    title = "First GUI"
    scene = new Scene(300,200) {
      fill = Color.Coral
      val button = new Button("Click me!")
      content = button
    }
  }
}

app.main(args)
```

There are three additional imports added here to bring in the Scene, the Color type, and the Button type, which is what we added to the scene. The String “Click me!” is the text that appears on the button. You can see the window that results from running this code in figure 11.1.

Note that the button is located in the top left. This is probably not the ideal location for the button, but it is where things goes in the scene. The default is a coordinate system using the x and y coordinates. The top left is at location (0,0) in our scene. However, 2D graphics coordinates are slightly different than what you are used to from math. In math you are used to z growing as you move right and y growing as you move up. The scene uses graphical coordinates where x still grows from left to right and the coordinates typically used for 2D graphics are like this.
