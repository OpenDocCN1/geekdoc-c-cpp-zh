+   9 Write a GUI that has three CheckBoxes and a ListView. The CheckBoxes should be labeled "Uppercase,"Lowercase," and "Digits" for uppercase letters, lowercase letters, and the numeric digits. # 11.94 Projects

+   1 Write a functional calculator in a GUI. You need to have at least the basic math operations. Feel free to put in other functionality as well. You can get a basic idea of how old function calculator works by going to http://www.online-calculator/.

+   2 If you did project 8.5 on parsing chemical equations, you might consider this problem as well. The chemical parser is not required for this, so you can start here if you want. In fact, the chemical equation is converted to a system of linear equations. Systems of linear equations will build a GUI that represents matrices as tables then let you do basic operations of addition and multiplication on them.

Keep things easy, the matrices will be square. You should have a menu option where the user can set the size of the matrices. They should be at least 2x2. The GUI will display three matrices that we call A, B, and C. The user gets to enter values into A and B. The value of C is set when the user selects menu options for add or multiply.

+   3 Write a GUI to play a mini minesweeper game. You can use a GridPane or a TilePane for the display and the user interaction. The challenge in this project is deciding how to show the mines and associate them with Buttons. There are many ways to do this. Students should think about different approaches instead just rushing into one.

+   4 This project continues the line of ray tracing options. You should build a GUI that lets you edit a scene. You should have ListViews of spheres, planets, and light sources. Each should have the geometric settings as well as color information. You need to have menu options to save a file or load from a file.

It can display a ListView of rooms that you can select and then other options for setting values on the selected room. You need to have menu options for loading a file, saving a file, and adding a room. For a little extra challenge consider putting in the option to remove a room. Note that when you do this, the indices of all the rooms remain after that
