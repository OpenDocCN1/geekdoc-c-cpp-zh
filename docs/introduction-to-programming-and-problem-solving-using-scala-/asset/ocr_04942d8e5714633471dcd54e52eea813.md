# A.1.3 Text Editors (vi/vim)

Most programming languages have programs that are written in plain text. As such, you can use any simple text editor to edit your programs. Word processors, such as Microsoft Word® or Open Office® are not plain text editors. You should not edit them for programs. Word processors store all types of additional information such as the format and font of text in addition to the text itself. Programs need only the straight text. On a Windows machine, Notepad is an example of a text editor.

You could use Notepad to edit programs, but not all editors are equally for programming. Due to the fact that programming is a common use for plain text editors, many editors have features that are specifically aimed at programming. On Unix/Linux a primary example of this is the vi editor. When there are lots of different editors that one can choose from Unix/Linux, we will work with vi because it is lightweight and is installed on virtually all machines. Many other editors will bring up separators or are not a default installation. If you decide you do not like vi or have another preference, you are more welcome to use whatever editor you want in going through this.

To start vi, simply type vi followed by the name of the file you want to edit. If the file exists, you will see its contents on your screen. If not you will get a blank screen with tildes ( down the left side and some extra information at the bottom.

The first thing to know about vi is that it has two modes. When you first start it, you need to be in an editing mode. When you are in an editing mode you can type text just like you would in Notepad. What gives vi the extra power that is helpful for programmers is the ability to use the command mode. To get from command mode into an editing mode, one of the following.

+   - i Insert the current character.
- Insert at the beginning of the current line.
- a Append after the character.
- A Append at the end of the current line.

> Many Linux installs technically with vim instead of vi. vim stands for "vi improved" and everything covered in regards to vi here will work for vim. On those systems executing vi will typically run vim by default, so it is likely you will never notice a difference. In fact a features described in this section, multiple undo and redo, only work in vim, not in standard vi.
