+   10. There is common fractal structure known as Sierpinski's triangle that is created by a repeated pattern of triangles. Figure 15.3 shows the output of a program to create this. A way to view this structure is you start with a single triangle from which you delete the triangle by connecting the midpoints of the segments. That leaves three smaller triangles, and then you delete the middle triangles from those and repeat this process infinitely. You can also view it as replacing a triangle with three smaller triangles where the middle is missing and then that process on the smaller triangles over and over. Either of these processes can be a recursive method. In fig:Sierpinski the triangle on the left went two levels of recursion while the right went down seven levels. For this project you should write a program using recursion to generate an image like that shown in the figure. You only need to show one triangle, and you should be able to easily alter the level of detail in your output.
