## 2.7.1 Patterns in Declarations

There is a bit more to the initialization of val and var declarations than was mentioned above. Technically called PATTERN MATCHING above. That we will get in detail in chapter 5. For now, the only aspect we will care about is that we can put tuples on the left hand side of the equals sign where we normally put a variable name. First, let us see what happens if we do a val declaration with a tuple on the right side.

```
scala val t = (100,5.7)
t: (Int, Double) = (100,5.7)
```

Note that t refers to the tuple and has a type (Int,Double). This is exactly what we would expect. The power pattern matching provides that if you put multiple names inside parentheses on the left of the equals, like a tuple, all the names will be bound. That type of behavior is shown here.

```
scala> val (price,weight) = t
price: Int = 100
weight: Double = 5.7
```

## 2.7.2 Using Variables

Let us use the ability to name values to a little problem solving. We are given a time in seconds, and we know what it is in hours, minutes, and seconds. We want to print that out in a readable format "hh:mm:ss". The first step in solving this problem is to figure out how to go from just seconds to hours, minutes, and seconds. Once we have that, we can use formatting it to get the right string.

How do we get from seconds to hours, minutes, and seconds? First, how do you get from seconds to minutes? That is fairly easy, you simply divide by 60. Thanks to the fact that integer division truncates, you get the proper number of whole minutes. Here are two lines that define the amount of total seconds as a number of total minutes.

```
scala val totalSeconds = 123456
totalSeconds: Int = 123456
```

```
scala val totalMinutes = not totalSeconds/60
totalMinutes: Int = 2057
```

That number of minutes is not exactly the amount of time we want. There are seconds left over. How do we figure out how many minutes we should display? We could totalSeconds-(60*totalMinutes), but a simpler expression is used here.

```
scala val displaySeconds = totalSeconds%60
displaySeconds: Int = 36
```

The modulo gives us remainder after we have gotten all the groups of 60. That is exactly what we want. Now do we get the number of hours and the number of minutes to display? The math is the same because there are 60 minutes in each hour.

```
scala val displayMinutes = totalMinutes%60
displayMinutes: Int = 17
```

```
scala val displayHours = totalMinutes/60
displayHours: Int = 34
```

What do we see that 123456 is 34 hours, 17 minutes, and 36 seconds. We could repeat this process for a different number of seconds if we used a different value for totalSeconds.

Now that we have these values, we want to figure out how to get them into a string with the format "hh:mm:ss". A attempt at that might look like the following.

```
scala val finalString = displayHours+":
```

For particular number of seconds, this works just fine. However, if you play around with this at all, you will find that it has a significant shortcoming. If the number of minutes or seconds is less than 10, only one digit is displayed when we want two. We need to come up with a way to get a leading zero on.

To do this, we will break the problem into two steps.
