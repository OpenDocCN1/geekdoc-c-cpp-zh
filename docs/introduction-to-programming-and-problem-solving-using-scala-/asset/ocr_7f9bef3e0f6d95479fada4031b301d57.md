The print statement is to help us keep track of what is happening. Now we will write the same function again, but this time the argument by name instead.

```
scala def incrByName(n => Int):Int = {
  println("About to increment.")
  n*1
}
```

incrByName: (n => Int) Int

The syntax for passing an argument by name is to put a rocket before the type of the argument. This is the same used in function literals. If we were to put parentheses in front of it to get () we would have the type of a function that takes arguments and returns an Int. The by-name argument is much same only when you call the function you do not have to explicitly make a function for the argument, any collection of code will work. To start off, we will call this function in the simplest way we possibly could.

```
scala incr(5)
About to increment.
res0: Int = 6
```

```
scala incrByName(5)
About to increment.
res1: Int = 6
```

Noే here. They appear to both do the same thing. Both print the statement and give back 6. However, the two are not really doing the same thing. To make clear, we will call them again and the argument be a block that includes a print.

```
scala incr {println("Eval"); 5}
Eval
About to increment.
res2: Int = 6
```

```
scala incrByName {println("Eval"); 5}
Eval
About to increment.
res3: Int = 6
```

Now it is clear that they are not doing the same thing. When you pass an argument by value, it is evaluated before the function starts so you can have the value to pass through. When you pass by name, the evaluation happens when the parameter is used. That is why the line "Eval" printed out "About to increment." in the second case. The println in the function happens before the value of n is ever accessed.
