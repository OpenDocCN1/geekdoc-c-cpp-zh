# Short Circuit Operators

One significant factor about the Boolean && and || operators is that they are short circuit operators. This means that if the value they give is known after the first argument is evaluated, the second argument will not be evaluated. For &&, happens if the first argument is false because no matter what the second argument is, the value will be false. Similarly, if the first argument of || is true, the final value will be true there is no spending time to evaluate second argument. This will be significant to us later when we get expressions that cause errors. The only thing we could do now that would cause an error during a run is to divide by zero. We can use that to demonstrate how short circuiting can prevent an error and that the operator is not short suited.

scala$ val n = 0
