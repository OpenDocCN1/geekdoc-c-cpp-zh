# 12.1 Shapes

Some of the examples in chapter 11 draw a rectangle by putting a Rectangle in the Scene. The Rectangle type is one of number of different types in the scalafx.scene.shape package that you can use to draw lines in a scene. In this section we will look at the different options that are part of that package. These are not the only way to draw in a ScalFX GUI. We will look at another option, the Canvas node, in section 12.6.

The Rectangle type is one of several subtypes of Shape in scalafx.scene.shape. Here is a full list of the subtypes of Shape. Each has a description and a proper syntax for how you would create one in code. Note that the code you use for instantiating these objects does not involve new.

+   - Arc Creates an arc with a specified angle and can be filled in. You create one with Arc(centerX, centerY, radius, radius, startAngle, length), where each argument is a Double. The startAngle and length are measured in degrees. The way in which it is drawn and filled depends on the type property which can be one of the following: ArcType.Chord, ArcType.Open, or ArcType.Round.

+   - Circle - As the name implies, it makes a Circle. You can create it with one of the following options: Circle(fill:Paint), Circle(radius:Double, fill:Paint), Circle(centerX:Double, centerY:Double, radius:Double), or Circle(centerX:Double, centerY:Double, radius:Double, fill:Paint).

+   - CubicCurve Draws a bezier curve. You can create one with new CubicCurve. Then you have to set eight values. Those are start, start, controlX1, controlY1, controlX2, controlY2, endX, and endY.

+   - Ellipse Draws an ellipse with a specified center and radius You build one with the center at (0, 0) using Ellipse(radiusX, radiusY) or specify the center using Ellipse(centerX, centerY, radiusX, radiusY). All arguments have Double.

+   - Line Draws a line between two points. You can create it with Line(startX, startY, endX, endY). All arguments have Double.

+   - Path - Paths are formed by combining lines, arcs, and curves. The Path type allows you to create a complex path by putting together different elements. You create one using new Path. The details of the path elements are described in section 12.1.1.

+   - Polygon - Generates a polygon with the syntax Polygon(points:Double*). Note that this is a variable length list. The arguments are taken in x, y coordinates, so a triangle would have six values, a quadrilateral would have 8 arguments, etc. This shape is automatically closed if the last point is not the same as the first.

+   - Polyline - Creates a shape from a sequence of line segments with the syntax Polyline(points:Double*). Note that this is a variable length list.

> Setting the type property requires a little extra effort because 'type' is a keyword in Scala, used for declarations. In order to use keywords as identifiers in Scala, they must be enclosed in backticks. This is the character on the top left of UK keyboards. If you want to set this, you cannot use arc.type = `type` = ArcType.Open.
