To make things little harder, you can use a key string to provide a variable offset. The encoding starts with the first letter in the key string and offsets the character by the number of positions that character is 'a'. It uses the second letter in the key string to offset the character in the message. This repeats until the end of the key string is reached as which point it wraps around and starts characters at the beginning. Code does what is shown here.

```
val key = args(2)
val factor = args(3).toInt
var keyIndex = 0
mapFile(args(0),c=>
val offset = factor+(key(keyIndex)-'a')+26
keyIndex = (keyIndex+1)%key.length
if (c.isLower) ('a'+(c-'a'+offset+26)%26).toChar
else ('A'+(c-'A'+offset+26)%26).toChar
}
```

This method needs both a key and a factor. The factor is required, because decoding is done by applying the same key with the negative of the factor. Most of the time the factor should be either 1 or -1. The way this code is written, the key should only include lowercase letters. After it uses two arguments to create the key and factor, it makes a mutable variable for the index in the key which begins at zero. The transforming function calculates an offset using the value of the key at the index and increments the index modulo so that the value wraps back around zero. The code for calculating the new character is the same as was used for the first offset.

# 9.5.6 Putting It Together

To make a more useful script, all three of these approaches can be put into a single script that takes an extra argument to specify the style to be used. The full contents of a script shown here including the imports and repeat of the mapFile function.

> Listing 9.1: mapFile.scala

```
import scala.io.Source
import java.io.PrintWriter

def mapFile(inFile:String,outFile:String,trans:Char->Char):Unit = {
  val pw = new PrintWriter(outFile)
  val in = Source.fromFile(inFile)
  for (c <- in) {
    pw.print(if c>='a' && c<='z' || c>='A' && c<='Z') trans(c) else c)
  }
  in.close
  pw.close()
}
```
