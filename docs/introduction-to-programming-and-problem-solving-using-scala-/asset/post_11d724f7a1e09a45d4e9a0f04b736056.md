- 13. The Mandelbrot set is a famous fractal in the complex plane discovered by Benoit Mandelbrot. The set will provide you with lots of information on this beautiful structure. Part of what is so remarkably about it is it has such a simple definition, but contains infinite complexities. The set is defined by the points, $c$, in the complex plane for which the equation $z_{n+1} = z_n^2 + c$, where $z_0 = 0$, gives a bounded sequence.

In practice, if the value of $|z|$ ever goes 4, the sequence will diverge. Programs explore the Mandelbrot set count the number of iterations to reach that point and assign a color based on how many iterations it takes. Because the points in the set itself will never diverge, there is some maximum number of iterations at which point you simply say it is in the set.

For this project you will write a GUI program that displays the Mandelbrot set. You will have a view on the set with minimum and maximum values in the real and complex axes. Allow the user to zoom in by.

Some of the most fundamental things that we do on computers is to sort data to certain values and search through data for various things. In this chapter we will start your exploration of the topics by working through some of the simpler approaches.

## 13.1 Basic Comparison Sorts

All require the ability to compare elements to see if one should before another. These comparison sorts are the ones that are used most frequently, mainly because they are so flexible. There are limits on how fast they can be because they are not customized to the data, but typically their generality tr speed.
