def commonName(nameData:Array[NameData]):NameData = {
  nameData.reduceLeft((nd1,nd2) => if (nd1.5 > nd2.5) nd1 else nd2)

This is written, but will result in an array that has the largest frequency. Changing the > to >= or swapping the nd1 and nd2 in the comparison will result in the first of them instead of the last. We want to find all of them, so we will stick with the first version.

The task of finding all the years in the data file is fairly simple. You could look in the file and see what years are present, but we can easily get that from the data using a single line.

```scala
val years = data.map(_.3).distinct
```

This line uses map to pull out all the years, then a call to distinct to remove all the duplicate entries.

Once we have the years, another line can give us the most common female or male names. Here is the line giving the common female names.

```scala
val femaleNames = years.flatMap(year => 
commonNames(data.filter(_.2=="F" && _.3==year)))
```

This code does flatMap across all the years and for each year it calls our commonNames function that has been filtered to only females in the data.¹³ To understand why flatMap is used, we need to think about the variety of the expressions in this code. The commonNames function result in an Array[NameData]. Also, the year is an Array[Int]. If we used a regular map instead of a flatMap, the results would be an Array[Array[NameData]], where each subarray was a different year. There could be times when you want this, but in this case, we do not need it, and it is a bit harder to work with. So, we use flatMap to flatten that Array[Array[NameData]] to just an Array[NameData].

## 6.8.2 Summary of Concepts

- Arrays and Lists are collections that allow us to store multiple values under a single name. They are sequences, meaning that the values have an order and each one is associated with an integer. Indexes start at zero.
- Both can be created in a number of ways: Array(e1,e2,e3...) or List(e1,e2,e3...) to make collections where you provide all the values.
- Use the : operator with Lists to append elements to the front and make a new List. Use Nil to represent an empty List.
- Array.fill(num)(expression) will make an Array of specified size with values coming from repeated execution of the expression. This will also work for Lists.
- Array.tabulate(num)(function) will make an Array with num elements that come from evaluating the function and passing the index. Often function literals are used here. This will also work with Lists.
- Arrays have a fixed size and are mutable. Access and mutate using arr(i).
- Lists are completely immutable, but you can efficiently add to the front to make new Lists. They are accessed with an index, but using head and tail in recursive functions is much more.
- The Scala collections, including Array and List, have lots of methods that you can call to do things. There are quite a few methods that take normal values for arguments and give you back parts of collections, locations where things occurs.
- The real power of collections is found in the higher-order methods. The primary ones you will use is map, filter, and foreach.
- There are a handful of methods that give you back pieces of collections, including combinatorial possibilities as permutations and combinations.
