A code block is just code enclosed after an if or an else branch you should group those with curly braces. In the above example, the else branch does not need to have curly braces because the code following the else is a single line, but they were indented to make the code consistent. It is considered good practice to use curly braces on if statements unless they are extremely simple and fit on one line.

The other thing to note about this example is that the code inside the curly braces is uniformly indented. Scala does not care about indentation, but human programmers do, and this is one style rule that virtually programmers feel very strongly about: nested code needs be indented. How far indent varies between programmers, languages, and tools. In Scala, it is customary to use two spaces, and that is the style that is followed in this book.

The placement of brackets is something else to pay attention to. In this book, we use the style shown here, where the open bracket goes at the end of the line it is opening, and the close bracket is at the end and not. The most common alternate format has a newline before the open bracket so that it appeared line below the "i" in if. It does not matter what style you use, as long as you are consistent in your usage.
