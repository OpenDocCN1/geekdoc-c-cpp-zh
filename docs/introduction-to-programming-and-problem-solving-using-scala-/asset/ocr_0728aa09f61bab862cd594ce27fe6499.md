The last file to part of the Pac-Man™ implementation is the Renderer. Because this singleton implementation allows only one of them at a time, it has been declared as a singleton object. The fact that there are no data members in this tells us that it should probably be an object instead of a class. A class would allow us to create multiple inst, but why should we make multiple instances of a type that does not have any data in it? Generally, the answer is that we should not; so, in that situation, an object declaration is the better choice.

The object has a single method called renderer that takes a GraphicsContext and a Maze. It draws everything in it to the GraphicsContext.
