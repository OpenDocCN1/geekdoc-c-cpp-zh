In a table, the data is a sequence of rows that you make as an ObservableBuffer. Each column in the table pulls some value from that data. In this example, we created a Student type that stores a name and two grades. The table is created and passed data three students. We create four columns for the table to display the name, two grades, and average. The TableColumn type needs to have two parameters. The first one is the type of data that is in rows. The second is the type of value being displayed in column. It takes an argument for the text you want to appear at the top of that column.

In order to display the data, we tell each column how it gets the proper value from the student. We set it to a function that takes an object of type CellDataFeatures and returns an observable. In this code, we use the name cdf for the CellDataFeatures and the member of that class that we use is the value. The functions return either a StringProperty or ObjectProperty in this code.

Another thing that has changed from previous examples is that of setting the content member of the Scene, we set the root value. Using content makes it easy to add multiple items to a Scene, but those do not change when the window changes. In this program, we have only a single Node being added, and there is advantage to having Node conform to the window. For that reason, we root root. We will see this again in section 11.7.

The last element shows how to handle user selecting a row from the table. This is done in a manner very similar to the ListView, where we set the onChange behavior for the selected item. Running this program produces a window like that showing figure 11.9.
