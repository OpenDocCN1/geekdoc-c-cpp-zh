#  8.6.4 Exercises

Many of these exercises are identical to ones that were given in chapter 5. The only difference is that those problems were to be solved with recursion and these are to be solved with loops.

+   1. Write the function isPrime that returns a Boolean if a number is prime using a loop.

+   2. Write a function using a loop that will print powers of two up to some value.

+   3. Write a function using a loop that will print powers of two up to some power.

+   4. Write a function using loops that will print a multiplication up to 108. Try to get it running first, then consider how you could make everything in line.

+   5. Write a function that returns a List[Int] of the prime factors of a number using a loop.

+   6. Repeat exercise 5.11 using a loop instead of recursion.

+   7. Write code that can take a List[Int] and give back a new one where all the values have been doubled. Do this with a while loop, a for loop without a yield, and a for loop with a yield.

+   8. Ask the user to enter an integer number. Next, from zero to that number and count how many contain the digit 3. Do this without using toString.

+   9. This problem is 6.12 in that you are supposed to count the number of even values in an Array[Int]. The difference is that now you do it once with a while loop and once with a for loop.

+   10. Another problem is significant when doing real cryptography is linear equations under modulo arithmetic. That sounds complex, but it is really just solutions to the following:

> $ax \equiv b \pmod n$,

where we know $a, b$, and $n$ and want to find $x$. To find the solutions to this, there can be more than one, you need to use the extended Euclid's algorithm for exercise 5.16.
