You can see the window produced by this code in figure 12.2. The variable named path sets up the line that roughly around the perimeter and includes each of the different types of elements. The smaller paths have a box where one edge is a cubic curve that forms a loop. Having the loop allows us to illustrate that there are two methods that can be used for filling paths. There are FillRule.EvenOdd and FillRule.NonZero. The darker shape on the left uses the EvenOdd rule. With this rule, whether a region is filled depends on if you cross an odd or even number of times to get it. The central loop is not filled in getting because there requires crossing two parts of the path, an even number. Getting to the parts that are filled by crossing the path over two or three times. The lighter shape on the right uses the NonZero rule. This fills in the central loop everything that would require going over the path more than zero times gets filled in. Note that you can also specify the fillRule of a SVGPath.
