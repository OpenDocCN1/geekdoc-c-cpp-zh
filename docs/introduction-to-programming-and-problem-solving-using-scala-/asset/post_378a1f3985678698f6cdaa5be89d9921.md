# 8.3.6 Variable Declarations

With guards, multiple generators, patterns, the for loop might seem like a dream, but wait! There's more! You can define variables inside of the for loop. This is helpful for situations like had where we do not want to calculate the magnitude twice for each iteration.

```scala
for (x,y) <- points; dist = magnitude(x,y); if (dist<1.0) yield dist
```

In this sample, the magnitude is calculated and stored in dist. This is used in the two different locations. Way we get shorter code with the real benefit that we only have to calculate the magnitude once.

The generators, if guard, values can be combined in any way a a generator comes first. This provides a significant amount of power in a strong construct. Just do not abuse it to code that no one can understand.

# For Comprehensions

In reality, the for loop in Scala is a form of "syntactic sugar" (syntactic sugar refers to syntax within a programming language that is designed to make things easier to read or write - it makes the language "sweeter" for people to use). When you write a for loop, it is converted to appropriate calls to foreach, map, flatMap, filter. In this way, the implementation can be optimal for the collection type in question.

Also, because it is common to have multiple generators, if guards, and variable declarations in for loops, Scala allows you to leave out semicolons and newlines if you intend to do so all in braces inside of parentheses.

# 3.3.7 Multidimensional Sequences and for Loops

In chapter 7 we saw that the type system allows us to do things like make Arrays of Arrays. At this point you might wonder how you could produce such things with for loops. It is tempting to think that using multiple generators might that, but the example of the grid of points above makes it clear that doesnt happen. If you want to have a construct with higher dimensions, you need to have nested for loops. As an example of this, we will use for loops to build the multiplication table we built in chapter 6 with तालिका.

```scala
val multTable = for (i <- 0 until 10) yield {
  for (j <- 0 until 10) i*j
}
```
