# 11.8 Putting It Together

Now that we have briefly explored the different components of ScalaFX GUIs and how we interact with them, we can try to put a number of them together in a larger program. The program is going to be something like a digital recipe book. For each recipe, it should allow the user to specify ingredients with amounts as well as a written description of the cooking directions. The GUI should give the user the ability to add and remove recipes. They should be able to select recipes and edit the various information that we have on.

At this point in the analysis you would probably want to sketch out a little picture of what you want the GUI to look like. That is for this GUI in figure 11.18. The left side is taken up by them, a ListView that shows all the recipes on a recipe, the information for it should be shown on the right. That includes a list of all the ingredients and the directions. The ingredients can also be edited and there need to be some buttons to help with this. The options for adding and removing recipes will be in the menus.

The question is how we lay this out. Any GUI can be built in different ways using the different pane options that we discussed above. For example, the separation between the recipe list and the information about the selected recipe could be created by a BorderPane, a HBox, or a SplitPane. Of of these you pick will normally be determined by the way in which the panes would sizes or whether you want to give the user the control of a SplitPane.
