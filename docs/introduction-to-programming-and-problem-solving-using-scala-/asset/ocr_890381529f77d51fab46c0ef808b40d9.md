The function is called comp and it takes a Weather and returns an Int. In order to prevent having the code call comp more than it needs to, we introduce a variable c that stores the result of the most recent comparison. We assign this in a code block in the condition. The loop checks to make sure it is not zero. The if if it is negative. After we calculate a new mid we also make a new comparison.

Now the question is, how could we use this search to find different elements in the Array. The first example we give is one that duplicates the search we have searching for a specific year and month.

```
binarySearchWeather(data, w => {
if (w.year > 1896) -1
else if (w.year < 1896) 1
else if (w.month > 2) -1
else if (w.month < 2) 1
else 0
}
```

In this case, we are searching for February of 1896. This version uses a sequence of expressions to determine if the element w comes before or after that time. With a little math we can make the shorter version taking advantage of the fact that there are 12 months in each year.

```
binarySearchWeather(data, w => (1896*12+2)-(w.year*12+w.month))
```
