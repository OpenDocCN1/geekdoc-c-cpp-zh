We'd like to have the termination function be something like the word "quit". Something special is not a number.

We can do this if we do not use Int. We could instead use the readline function which would read a full line of input and returns a String. You might be tempted to create a method like this:

```
def sumUntilQuit():Int = {
  val n = readLine()
  if (n="quit") {
    n+sumUntilQuit()
  } else {
    0
  }
}
```

If you enter this into a file and load it into the console, you will get the following error.

```
<console>:8: error: type mismatch;
found: String
required: Int
n+sumUntilQuit()
```

This is because the function is supposed to return an Int, but n is a String and that is the type we use + with String what we get a String. Why is n a String? Because that the type returned by readLine and Scala's type inference decided on the line n = readLine() that n must be a String.

This problem can be easily fixed. We know that if the user is giving valid input, the only things which could be integer values until the word "quit" is typed in. So should be able to convert the String to an Int. That can be done as shown here.

```
def sumUntilQuit():Int = {
  val n = readLine()
  if (n="quit") {
    n.toInt+sumUntilQuit()
  } else {
    0
  }
}
```
