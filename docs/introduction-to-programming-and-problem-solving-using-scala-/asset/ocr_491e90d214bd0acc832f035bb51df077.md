While this code is easy, it is also inefficient, particularly in the cases where n is prime. The reason is that we do not need to go up to n-1. If there is no divisor less than the square root of n, it cannot be one. If n were very large, the difference between n and the square root of n would be significant. A more efficient function can be written in this way.

```
def isPrime(n:Long):Boolean = {
  var i = 2
  while (i<=n && n%i!=0) i += 1
}
```

A Range type could have been used with a square root function, but the math.sqrt function works with Doubles that introduces difficulties we did not want to deal with.
You might wonder about the use of a while loop here. After all, we generally prefer the for loop. In this case, the while loop only allows us an easy way to check if anything that divides into is the square root of n. On the other hand, a for loop runs for every member of a collection. The forall method or-the-method used above is simple enough to break out early as well.
There are more efficient ways of determining if a number is prime. You do not need to check all the values up to the square root of n. You only need to check the numbers up to that point.
