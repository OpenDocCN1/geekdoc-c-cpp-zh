## 1.2.2 Memory

Memory on a computer is used to store information. There are two basic types of memory: primary memory (storage) which is known as RAM (Random Access Memory) and secondary memory (storage). Examples of secondary storage include hard drives, solid state drives, flash and magnetic tape. RAM is also referred as as main memory which is directly connected to the CPU. All programs must be loaded into RAM before they can execute and all data must be loaded into RAM before it is processed. Figure 1.2 gives the basic idea of main memory. RAM is considered because when a computer gets turned off, everything in memory is lost unless it has been saved to secondary storage. Secondary storage is considered important because it allows programs and data to be stored permanently, and these can be accessed even after the power has been cut.

Typically goes inverse of size for memory, and this is true of disk and RAM. Disk drives are significantly slower than RAM, though what is written to them stays there even when the machine is turned off. RAM is faster than the disk, but it is not fast enough to respond at the rate that a modern processor can use. For this reason, processors generally have smaller amounts of memory on them: cache. The cache is significantly faster than the RAM when it comes to how fast the processor can read or write values. That is not enough anymore, and modern processors include multiple levels of cache referred to as L1, L2, L3, etc. Each level up is generally bigger, but also further from the processor and slower.

Some applications have to concern themselves with these details the program runs if it will fit inside of a certain cache. If a program uses a small enough amount of memory that it will fit inside of the L2 cache, it will run significantly faster than it does not.

## 1.2.3 Input/Output Devices

For a computer to perform tasks, it needs to get input in the form of instructions and data. Devices that provide this capability are input devices. Examples of input devices include a keyboard, mouse, and secondary storage. The keyboard is the STANDARD INPUT. Output devices enable the computer to display the results of the instructions and calculations. Some examples of output devices include the printer, terminal screen, and secondary storage. The terminal screen is the STANDARD OUTPUT.

## 1.3 Software

The programs that run on hardware are typically called software. The software is not a physical entity. However, without some type of software, the hardware is useless. As with hardware, software can be the running of a program as having multiple parts. It also has a layering or hierarchy to it as can be seen in figure 1.3. At the base is a layer that gives the computer the initial instructions for what to do when it is turned on. This is often called the BIOS (Basic Input/Output System). The BIOS is generally located on a chip in the machine instead of on the more normal forms of memory like disk or RAM. Instructions stored there are often called firmware. This term implies that it is between the software and the hardware. The firmware is really instructs, sitting just like any other software. In a sense it is soft because it is stored in a way that might be impossible to write or which is harder to write to.

The BIOS is responsible for all the basic functionality started up on the machine. Sitting on top of the BIOS is the Operating System (OS). The Operating System is responsible for controlling the operations of the machine and how it interacts with the user. The OS is also responsible for writing files to disk and reading from disk. In addition, it has the job of loading other programs into memory and getting them started. Over time, the amount of functionality in operating systems has grown so far that they are also expected to present nice interfaces and has all types of other "basic" functionality that really is not basic.

At the top level are the application and utility programs that the user runs. When the user instructs the operating system to run a program, the operating system loads that program into memory and sets the execution address so that the computer will start running

# Basics of Computers, Computing, and Programming

The breadth of what programs can do is nearly unlimited.¹ Everything runs on every digital device in the world is a program. You use to type your papers and your e-mail. They likely run the fuel injection system in your car and control the lights at intersections. Programs regulate the flow of electricity from the power grid and the flow to your indoor plumbing. Programs do not just give you the apps on your phone, they are running when you call the phone to compress your speech into a digital form and send it out to a local tower where another program examines it and sends it on to destination.

In the last section we mentioned that programs have multiple cores. The availability of multiple cores (and perhaps multiple processors) is significant for software as well. First, they get the OS to have multiple things happening at one time. Multitasking is a method that allows multiple tasks to be performed during the same period. This can be done on a single core by giving each process a short bit of time and switching between them. When there are multiple cores, it allows the programs to truly run at once, which is known as parallelism. Each process can exploit its own parallelism by creating multiple threads. The OS is responsible for scheduling what tasks are active at any time. This allows a single program to utilize the resources of a machine than is present on a single core. While this does not matter for some specialized applications, the use of multiple cores has become more and commonplace and the core count on large machines as smaller devices is currently climbing at an exponential rate. As a result, the need to multithread programs becomes more vital.

This increasing number of cores has led to another interesting development in the area of servers. Servers are more powerful computers that are used by companies to store large amounts of data and lots of processing. Everything that you do on the web - if you are at a University, odds are that they have at least one full farm of servers that act as a control and data storage center for the campus.

The nature of the work that servers do is often quite different from a normal PC. A fraction of their job is just passing information around, and the workload for that can be very unevenly distributed. The combination of this and multiple cores has led to an increase in the use of virtualization. A virtual machine is a program that acts like a computer. It has a BIOS and loaded OS. The OS can schedule and run programs. This whole process happens inside of a program potentially on a different OS on a real machine. Using virtualization, you can create multiple instances of one or more operating systems running on a single machine. As long as the machine has enough cores and memory, it can support the work of all of these virtual machines. Doing this cuts down the number of real machines that have to be bought and run, reducing costs in both materials and power consumption.
