# Getting to Know the Tools

For the first line, the * is replaced with nothing. For the second it is replaced with “.old”. You can also use a ? to represent any one character. These wild cards are not ever seen by the ls root of command options. The command replaces them with all of the matching files, and it is the multiple file names or directory names that passed to the command.

The ls has a lot of other options as well. The options are all preceded by a hyphen. The most commonly used option is -l, which tells ls to use a long format. This is an example of that:

```
mlevis@mlevis-laptop:~$ ls -l Desktop
total 8
-rwxrxr-x 1 root 1261-01-28 12:21 AdobeReader.desktop
-rw-r-- 1 mlevis 250 2009-12-22 11:03 QtCreator.desktop
```

The long format puts each file or directory on a line. In addition to the files, it shows a number of other pieces of information. The first ten characters show permissions on the files. Permissions are discussed in section A.1.1.4. After the permissions is a number showing how many links are there to this file. After that are the user and the owner of the file and the file it belongs to. The last pieces of information are the size of the file, measured in bytes, and the date and time of the last modification of that file.

The next commonly used option is -a. This tells ls to list all files, including the hidden files. Hidden files in Unix and Linux are files whose names begin with a period. We see here a usage of this combined with the long format. Only one hyphen is needed when options are combined:

```
mlevis@mlevis-laptop:~$ ls -al Desktop
total 16
drwxr-xr-x 2 mlevis 4096 2010-02-27 22:02 ..
-rwxr-xr-x 1 mlevis 250 2009-12-22 11:03 QtCreator.desktop
```

This adds two additional lines. The letter d at the left edge tells us that these are actually directories. The . is the name for the current directory. The .. is the name of the directory in which the current directory sits. We might also refer to it as the parent directory.

By default, commands work in the current directory. For this reason, one of the commands you use the most is cd that changes the current directory. The cd is followed by a single directory name. The directory will be the current directory. As we just saw, each directory has . and .. directory names inside it. If you want to move up a directory structure, simply execute “cd .. at any time to change back to your home directory. The following command changes our current directory to the Desktop directory.

```
mlevis@mlevis-laptop:~$ cd Desktop
mlevis@mlevis-laptop:~/Desktop$
```

The prompt used in this example shows that we can see we are in this new directory.
