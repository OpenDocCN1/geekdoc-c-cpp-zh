```
val app = new JEXApp {
  stage = new JEXApp.PrimaryStage {
    title = "Effects"
    scene = new Scene(450,720)
    val bloom = makeText(20, 40, "Bloom", new Bloom(0.1), true)
    val boxBlur = makeText(20, 100, "BoxBlur", new BoxBlur(7, 7, 2), false)
    val floatmap = new FloatMap(40, 40)
    for (i <- 0 until floatmap.width) {
      offset = (0.1*math.sin(i/30.0)).toFloat())
      for (j <- 0 until floatmap.height) {
        floatmap.setSamples(i, j, 0.Of, offset)
      }
    }
    val dmap = new DisplacementMap(floatmap)
    val displacementMap = makeText(20, 160, "DisplacementMap", new DisplacementMap(), dmap, false)
    val dropShadow = makeText(20, 220, "DropShadow", new DropShadow(5, 20, 20, Color.Black), false)
    val gaussianBlur = makeText(20, 300, "GaussianBlur", new GaussianBlur(7), false)
    val innerShadow = makeText(20, 360, "InnerShadow", new InnerShadow(3, 3, 3, Color.Green), false)
    val lightEffect = new Lighting(new Light.Distant(0, 45, Color.White))
    lightEffect.scale = 5.0
    val lighting = makeText(20, 420, "Lighting", lightEffect, false)
    val motionBlur = makeText(20, 480, "MotionBlur", new MotionBlur(15, 10), false)
    val perspective = makeText(20, 540, "Perspective", new PerspectiveTransform(20, 500, 510, 400, 520, 20, 540), false)
    val reflection = makeText(20, 600, "Reflection", new Reflection(0.5, 1.0, 0.0), false)
    val shadow = makeText(20, 700, "Shadow", new Shadow(5, Color.Black), false)

    content = List(bloom, boxBlur, displacementMap, gaussianBlur, innerShadow, lighting, motionBlur, perspective, reflection, shadow)
  }
}
```

app.main(args)

The output of this code is shown in figure 12.12. Each effect is applied to a string with the name of the effect. There is a helper method makeText that creates an instance of Text and gives it a large font. If the effect needs a background to be visible, one is added by making a group that adds a Rectangle that matches the bounds of Text.
The above showed the effects that worked well with text. The ColorAdjust, SepiaTone, and Glow effects are better suited working with images, where we have a separate example for those. The following code allows the user to specify multiple files on the command line. It loads in these files and puts them on MenuButtons that have menu options of ColorAdjust, SepiaTone, and Glow. If a user selects a menu option, that effect is applied to the image. All the buttons are in a TilePane.
