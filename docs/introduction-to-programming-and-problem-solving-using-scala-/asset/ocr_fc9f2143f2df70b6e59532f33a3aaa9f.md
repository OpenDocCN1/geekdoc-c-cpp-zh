# 16.2.4.1 Applications

The fact that you can use an object without instantiation is very significant. The objects effectively exist as soon as the program starts. You do not have to have a line that makes a new one. This is most significant when we move beyond REPL and scripts into applications. A top level object declaration defines an entry point to an APPLICATION it contains a method that takes an argument of type Array[String] and results in Unit. Here is a simple example

```
object Firstapp
def main(args:Array[String]):Unit = {
println("My first application.")
}
```

The scripts we have been using can be converted to applications by doing nothing more than pasting the code of a main that is an object. If you use the variable name args for the command-line arguments, then references to them in a script will work fine.

The difference between a script and an application is how you organize the code in files and when you run them. By definition, a script is supposed to be a small program. All of the code for a script goes into one file. When the amount of code that requires gets larger, it needs to be split and organized. The organizational structure you should follow in Scala in all situations is to put each top level class or object in a separate file that is the name of the Class or object followed by "scala".

Consider the bank application. We might use account class from above and put it in a file called "Account.scala". The Customer class would go in "Customer.scala and the Bank class would go in "Bank.scala". Finally, we would have an object declaration for the application that might have a method Bankbranch and would go in "Bankbranch.scala".

Running an application is a two-step process. First you have to compile the code using the scalac command, which stands for "Scala compiler". You tell the Scala compiler what files you want to compile. If you organize your code so that all the code for an application is under a directory you can execute something like scalac *. This will compile all of the files ending in "scala" in the current directory.

When you do this, if you have any syntax errors, they will be found and reported to you in the same way you ran programs as scripts. Once you have found and fixed syntax errors, the compiler will produce a set of files in compiled BYTECODE that you can run. These files will end with the ".class extension.
