```
import scalafx.Includes._
import scalafx.application.JFXApp
import scalafx.scene.Scene
import scalafx.scene.image.{Image, ImageView, WritableImage, PixelWriter}
import scalafx.scene.control.Label
import scalafx.scene.layout.TilePane
import scalafx.scene.paint.Color

if (args.length < 1) {
  println("You must provide an argument with the name of a file to load.")
  sys.exit(0)
}

val app = new JFXApp {
  stage = new JFXApp.PrimaryStage {
    scene = new Scene(800,200) {
      val original = Image("file:"+args(0), 200, 200, true)
      val (red, green, blue) = original.match {
        case Some(reader) =>
          val rim = new WritableImage(original.width.value.toInt, original.height.value.toInt)
          val writer = rim.pixelWriter
          val gimg = new WritableImage(original.width.value.toInt, original.height.value.toInt)
          val gwriter = gimg.pixelWriter
          val bimg = new WritableImage(original.width.value.toInt, original.height.value.toInt)
          val bwriter = bimg.pixelWriter
          for (i <- 0 until original.width.value.toInt) {
            for (j <- 0 until original.height.value.toInt) {
              val c = reader.getColor(i, j)
              writer.setColor(i, j, Color(c.red, 0, 0, 1.0))
              writer.setColor(i, j, Color(0, c.green, 0, 1.0))
              writer.setColor(i, j, Color(0, 0, c.blue, 1.0))
            }
          }
          (new ImageView(rim), new ImageView(gimg), new ImageView(bimg))
        case None =>
          (new Label("No Reader"), new Label("No Reader"), new Label("No Reader"))
      }
      val tilePane = new TilePane
      tilePane.children = List(new ImageView(original), red, green, blue)
      root = tilePane
    }
  }
}
app.main(args)
```

## 12.3.1 Writing Images to File

While JavaFX and therefore ScalaFX support a remarkable number of features, there is one significant that they did not add support for, writing images to file. In order to do this, we have to go through some older JavaFX based libraries. The functionality to read and write images in JavaFX is provided by the `java.image.ImageIO` type. This type has a method called `write` that can create image files from the `BufferedImage` that was part of the older libraries, the challenge is that ImageIO works with BufferedImage. Fortunately, there are ways to convert the Image type that we use to `BufferedImage` using the `scalafx.embed.swing.SwingFXUtils` object. The following line of code will write an Image called `out` to a file specified by the `java.io.File` named `file` as a PNG file.

```java
ImageIO.write(SwingFXUtils.fromImage(img, null), "png", file)
```

You might find that you want to save your whole Scene or a particular Node as a file.

## 12.4 Transformations

One of the most fundamental capabilities of nearly all graphical interfaces is the ability to transform shapes. You can see an example of this in the following list:

- rotate: rotates an object around a point.
- translate: moves an object by a specific distance.
- scale: changes the size of an object.
- shear: tilts the object.

The most common way to apply these transformations is using the `Transform` class. These transformations are represented in the computer using affine matrices. An affine transform is a linear transformation followed by a translation. This includes rotation, scaling, and shearing, all of which are performed relative to the origin.
