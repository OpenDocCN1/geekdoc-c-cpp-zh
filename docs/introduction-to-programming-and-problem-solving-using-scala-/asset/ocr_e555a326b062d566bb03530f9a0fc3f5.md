# 14.2.3 Building XML

So now you know how to get the contents of an XML file into one Scala.
What about going the other way? Assume that the code we just wrote was used in the
menu based application from chapter 10 and that changes were made and now we want to
write the results back out file. The first step in this would be to build the Node
represents the data.

We saw above that can put XML directly into a Scala program or the REPL and
it will be parsed and understood. However alone does not give the ability to put
values from the program back into the XML file. Fortunately, is not hard to do either.
Inside of XML that is embedded in a Scala program can enable Scala expressions using
curly braces. We will start with a simple example.

```
scala:<tag>4+5 is (4+5)</tag>
res19: scala.elem = <tag>4+5 is 9</tag>
```

Here the expression 4+5 has been put in curly braces, and as you can see it evaluates to
value 9 as it should. The code you put inside the curly braces can be far more complex
 build additional XML content or.

We will use this to write a function that parses a Student object into an XML node.
This code looks like the following:

```
def studentToXML(student:Student):xml.Node = {
val nameParts = student.nameParts(" + ")
<student name=${nameParts(0)} name=${nameParts(1)}>
${student.quizzes.map(q => <quiz grade=${q.toString()}>)}
${student.tests.map(t => <test grade=${t.toString()}>)}
${student.assignments.map(a => <assignment grade=${a.toString()}>)}
</student>
```

The first line splits the student name into pieces around spaces. It is assumed that the
first element is the first name, and the second element is the last name. These are used as
attribute in the student tag. Inside of that are three lines of code, each
of quizzes, tests, and assignments. Each of these maps the corresponding List to a
of elements with grade attributes.

It is worth noting things about using code for the attribute values. First, the quotes
are not written anywhere. They are automatically provided when the value is Scala code.
Second, the type of the Scala for the value has to be String. This is apparent
with the grade values. They are Doubles and have to be explicitly converted to Strings.
