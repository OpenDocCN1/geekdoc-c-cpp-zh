# 12.3.1 Writing Images to File

While JavaFX and therefore ScalaFX support a remarkable number of features, there is one significant that they did not add support for, writing images to file. In order to do this, we have to go through some older JavaFX based libraries. The functionality to read and write images in JavaFX is provided by the java.image.ImageIO type. This type has a method called write that can create image files from the BufferedImage that was part of the older libraries, the challenge is that ImageIO works with BufferedImage. Fortunately, there are ways to convert the Image type that we use to BufferedImage using the scalafx.embed.swing.SwingFXUtils object. The following line of code will write an Image called out to a file specified by the java.io.File named file as a PNG file.

```
ImageIO.write(SwingFXUtils.fromImage(img, null), "png", file)
```
