The \ operator looks for things at the top level, either Nodes in the sequence if we have a NodeSeq, or children of this node if we have a Node or Elem. The \, on the other hand, finds anything that matches at the current level. To illustrate this, we will do three examples.

```
scala res4 \ "student"
res5: scala.xml.NodeSeq =
NodeSeq(<student name="Bender" name="Quinn">
  <quiz grade="88"></quiz>
  <quiz grade="100"></quiz>
  <quiz grade="90"></quiz>
  <test grade="94"></test>
  <assignment grade="100">
    Code compiled and runs free.
  </assignment>
</student><student name="Hughes" name="Jason">
  <quiz grade="85"></quiz>
  <quiz grade="78"></quiz>
  <test grade="67"></test>
  <assignment grade="20">
    Code did not compile.
  </assignment>
</student>)
```

```
scala res4 \ "test"
res6: scala.xml.NodeSeq = NodeSeq()
```

```
scala res4 \ "test"
res7: scala.xml.NodeSeq = NodeSeq(<test grade="94"></test>, <test grade="67"></test>)
```

The two searches use the \ operator. The first one searches for elements that have the name "test". The second search looks for tags that have the name "test" and gives back a NodeSeq with them. This search returns an empty NodeSeq. This is because there are tags with the name "test" in res4, they are nested deeply inside of the "student" elements as such, are not found by the \ operator. The last example searches for the "test" tag name again, so so with \, which searches deeply, and gives back a NodeSeq with two Nodes inside of it.

The & \ operators can also be used to get attributes from elements. To get an attribute index of a tag, simply put "@" at the beginning of the string you are searching for. Here are three examples to illustrate this.

```
scala res4 \ "name"
res8: scala.xml.NodeSeq = CSCI 1320
```

```
scala res4 \ "grade"
res9: scala.xml.NodeSeq = NodeSeq()
```

```
scala res4 \ "grade"
res10: scala.xml.NodeSeq = NodeSeq(98, 100, 90, 94, 100, 85, 78, 67, 20)
```
