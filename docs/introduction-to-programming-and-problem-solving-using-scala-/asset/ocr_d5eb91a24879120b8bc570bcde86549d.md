Another significant type in Scala is the TUPLE. A tuple is a sequence of a specified
umber of specific types. a collection of values that is strict about how
what type of values it has. We can make tuples by simply putting values in
parenheses and separating them with commas as seen in the following examples.

```
scala (5,6,7)
res23: (Int, Int, Int) = (5,6,7)
```

```
scala "book",200
res24: (String, Int) = (book,200)
```

```
scala (5.7,8,'f,'a string')
res25: (Double, Int, Char, String) = (5.7,8,f,a string)
```

The tuples in Scala provide a simple way of dealing with multiple values in a single package,
and they will come occasionally through the book. Note that we express a tuple
type in Scala is to put the type of values of the tuple in parentheses with commas
them them, just like we do with the values to make a tuple object.
