1. We can express a general polynomial as

$A_nx^n + A_{n-1}x^{n-1} + A_{n-2}x^{n-2} + ... + A_2x^2 + A_1x + A_0$

where the A values are the coefficients on different terms. You can view a sequence of Doubles by saying that the value at index n is the value of $A_n$. Using this representation, Array(1,0,0,2,0) would represent $2x^2+1$. Note that when you look at the Array it is the opposite of the order seen in the polynomial.

Introduction to Programming and Problem-Solving Using Scala

Using this representation of polynomial, write functions that add and subtraction of two polynomials. You can assume that the Arrays passed in are the same length. Write functions that give you the derivative of a polynomial and the anti-derivative. Note that the anti-derivative function will need to extract argument for the value of the constant term.

To learn, try to write these functions using both recursion and an index and using standard methods on sequences. For the former try doing it with Lists as well using :: to build the Lists in the recursion. For the latter hint when you write add and subtract is to consider using the zip method.

If you want another challenge, try multiplication as well. This is a significantly harder problem, but if you can do it with both recursion and the built in methods you should feel good about your understanding.

2. This project you implement a simple form of encryption and decryption. You should write at least two functions encrypt and decrypt.

The form of encryption we are using is offset encryption where you simply offset letters in the alphabet. If you pick an offset of 1, then there is an 'a' in the original message, the message will be a 'b'. For a first cut, write these functions you just add or subtract a offset to all characters. (Note that when you arithmetic on a Char get an Int. Use the Char method to get back that type.)

This approach is easy, but it produces non-letters in certain situations like when you do an offset on 'z'. Refine your functions so they skip any characters that are not letters and wrap around so if the offset goes above 'z' it comes back to 'a'. You have handle capital letters as well. (Note that the Char type has isLetter, isUpper and isLower that can help you with this. You can also do comparisons and match with the Char type.)

If you want another challenge and you to make it harder for someone to try to break your code, revise your methods so that they take an Int and insert random characters at intervals of spacing. So if the value is 5, you will insert an extra random character between every fifth character of the message. You can generate a random letter character with the expression ('a'+util.Random.nextInt(26)).toChar.

For this problem we will try treating Strings as sequences. So you can use them as an Array[Char] except that they are not mutable.
