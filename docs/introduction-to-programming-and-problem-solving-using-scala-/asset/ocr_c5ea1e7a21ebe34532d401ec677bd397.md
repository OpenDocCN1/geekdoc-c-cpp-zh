```
scala 3 -> "three"
res26: (Int, String) = (3,three)
```

The- will only produce tuples with two elements. If you try using with more
two elements you can get interesting results.

```
scala 4 -> 6
res27: ((Int, Int), Int) = ((4,5),6)
```

So if you want tuples more than two elements, stick with the parentheses and comma
notation.
Once you have a tuple, there are two ways to get things out of it. The first is to use
methods named _1, _2, _3, etc. So using res21 from above we can do the following.

```
scala res25._1
res28: Double = 5
```

```
scala res25._3
res29: Char = f
```

The challenge with this method is that method names like _1 are not very informative and
make code difficult to read. We will see an alternative approach in section 2.7 that
requires a bit more typing, but can produce more readable code.
