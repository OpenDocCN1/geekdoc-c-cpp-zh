There can be a value to using a type declaration to give a different name to a standard type like Int

```
type Counter = Int
```

If you carefully use the Counter type through your program in calls that for it, you can easily change the size of the integer type that is being used. If you find that you need your counters to be over Int.MaxValue, you can switch to a Long. On the other hand, if your counters are always small and you have need to save memory, you could consider going down to a Short. This type of usage is not common in Scala, but it is significantly used in C using a similar construct typedef when writing libraries so that it is easy to modify types to fit the platform you are compiling for.
