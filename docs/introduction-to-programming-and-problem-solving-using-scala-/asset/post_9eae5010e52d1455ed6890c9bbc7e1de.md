# 11.8 Putting It Together

Now that we have briefly explored the different components of ScalaFX GUIs and how we interact with them, we can try to put a number of them together in a larger program. The program is going to be something like a digital recipe book. For each recipe, it should allow the user to specify ingredients with amounts as well as a written description of the cooking directions. The GUI should give the user the ability to add and remove recipes. They should be able to select recipes and edit the various information that we have on.

At this point in the analysis you would probably want to sketch out a little picture of what you want the GUI to look like. That is for this GUI in figure 11.18. The left side is taken up by them, a ListView that shows all the recipes on a recipe, the information for it should be shown on the right. That includes a list of all the ingredients and the directions. The ingredients can also be edited and there need to be some buttons to help with this. The options for adding and removing recipes will be in the menus.

The question is how we lay this out. Any GUI can be built in different ways using the different pane options that we discussed above. For example, the separation between the recipe list and the information about the selected recipe could be created by a BorderPane, a HBox, or a SplitPane. Of of these you pick will normally be determined by the way in which the panes would sizes or whether you want to give the user the control of a SplitPane. We will use a BorderPane for the top level, which will hold the MenuBar, the recipe list, ingredient information and tools, and the recipe directions. BorderPane allow us to resize the elements if the user resizes the window, and it will give us a top, left, and center that can be used to further optimize the content. We can place the MenuBar in the center, the recipe list in the left, and else in the center. We will break up the center and use a SplitPane to separate the recipe directions from the ingredient information. We will use a GridPane for the buttons, ingredient list, and ingredient settings. The following code shows how we could solve this adding "traditional" handlers to the code instead of bindings.

```
case class Ingredient(name:String, amount:String)
case class Recipe(name:String, ingredients:List[Ingredient], directions:String)
val app = new JFXApp {
  stage = new JFXApp.PrimaryStage {
    title = "Recipes"
    scene = new Scene(600,400) {}
    MenuBar
      val menuBar = new MenuBar
      val fileMenu = new Menu("File")
      val openItem = new MenuItem("Open")
      openItem.accelerator = new KeyCodeCombination(KeyCode.O,ControlDown)
      openItem.setOnAction = (e:ActionEvent) => { openFile }
      val saveItem = new MenuItem("Save")
      saveItem.accelerator = new KeyCodeCombination(KeyCode.S,ControlDown)
      saveItem.setOnAction = (e:ActionEvent) => { saveFile }
      val exitItem = new MenuItem("Exit")
      exitItem.accelerator = new KeyCodeCombination(KeyCode.X,ControlDown)
      exitItem.setOnAction = (e:ActionEvent) => { System.exit(0) }
      fileMenu.items = List(openItem,saveItem,exitItem)
      val recipeMenu = new Menu("Recipe")
        val addItem = new MenuItem("Add")
        addItem.setOnAction = (e:ActionEvent) => { addRecipe }
        val removeItem = new MenuItem("Remove")
        removeItem.setOnAction = (e:ActionEvent) => { removeRecipe }
      recipeMenu.items = List(addItem,removeItem)
  }
}
```

```
def openFile:Unit = {
  var chooser = new FileChooser
  var selected = chooser.showDialog(stage)
  if (selected) {
    var src = io.Source.fromFile(selected)
    var lines = src.getLines
    recipes = Array.fill(lines.next.toInt)(Recipe(
      lines.next,
      List.fill(lines.next.toInt)(Ingredient(lines.next, lines.next)),
      {
        var dir = ""
        var line = lines.next
        dir += (if dir.isEmpty "" else "\n")+line
        line = lines.next
      }
    ))
  }
}
```

```
def addRecipe:Unit = {
  val dialog = new TextInputDialog
  dialog.title = "Recipe Name"
  dialog.headerText = "Question?"
  dialog.contentText = "What is the name of the new recipe?"
  dialog.showAndWait().foreach { name =>
    recipes += Recipe(name,
      List("ingredient","amount"),"Directions")
    recipeList.items = ObservableBuffer(recipes.map(_):*)
    recipeList.selectionModel.value.clearAndSelect(recipes.length-1)
    setFields(recipes.last)
  }
}
```

```
def removeRecipe:Unit = {
  if (recipeList.selectionModel.value.isEmpty) {
    recipes = recipes.patch(recipeList.selectionModel.value.selectedIndex,
      value,Null,1)
    if (recipes.isEmpty) {
      recipes = Array("New recipe",
        List("ingredient","amount"),"Directions")
    }
    recipeList.items = ObservableBuffer(recipes.map(_):*)
    recipeList.selectionModel.value.clearAndSelect(0)
    setFields(recipes.head)
  }
}
```

```
def addIngredient:Unit = {
  val recipeIndex = recipeList.selectionModel.value.selectedIndex
  if (recipeIndex>=0) {
    val newIngr = Ingredient("Stuff", "Some")
    recipes(recipeIndex) = recipes(recipeIndex).copy(
      ingredients = recipes(recipeIndex).ingredients :+ newIngr
      ingredientsList.items.value += newIngr.name
  }
}
```
