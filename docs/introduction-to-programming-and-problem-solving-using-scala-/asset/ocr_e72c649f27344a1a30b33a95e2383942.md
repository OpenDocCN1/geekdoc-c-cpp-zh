+   2. This project you implement a simple form of encryption and decryption. You should write at least two functions encrypt and decrypt.

The form of encryption we are using offset encryption where you simply offset letters in the alphabet. If you pick an offset of 1, then there is an 'a' in the original message, the message will be a 'b'. For a first cut, write these functions you just add or subtract a offset to all characters. (Note that when you arithmetic on a Char get an Int. Use theChar method to get back that type.)

This approach is easy, but it produces non-letters in certain situations like when you do an offset on 'z'. Refine your functions so they skip any characters that are not letters and wrap around so if the offset goes above 'z' it comes back to 'a'. You have handle capital letters as well. (Note that the Char type has isLetter, isUpper and isLower that can help you with this. You can also do comparisons and match with the Char type.)

If you want another challenge and you to make it harder for someone to try to break your code, revise your methods so that they take an Int and insert random characters at intervals of spacing. So if the value is 5, you will insert an extra random character between every fifth character of the message. You can generate a random letter character with the expression ('a'+util.Random.nextInt(26)).toChar.
