> Tip: The best functions result in values and do not print or read input from a user. The list gives reasons for this:
- Result values can be used for further computations, printed values cannot be.
- Printing ties a function to working with standard output.
- Reading input ties the function to working with standard input.

Right now our output and input are the standard ones, so having a function that only prints and reading tasks is not so limiting. However, mixing calculations or other computations into a function that does input and output still results in functions that are generally less useful. It is better to have the extra computation in a separate function that has the proper type. The function doing the input and output can use that function, as other parts of the code.

Before moving on, we will do another example that is more interesting, calculating an average in a course. The course is calculated by combining the average of a number of different grades. For example, you might have tests, assignments, and quizzes. Each of these might contribute a different fraction of the total grade. The tests might worth 40%, assignments 40%, and quizzes 20%. You will also have a different number of each of these grades. For example, you might have 2 tests, 3 assignments, and 4 quizzes. In many courses, the part of the course is computed by dropping a lowest grade and taking the average of what remains. In this case, let us assume the lowest grade is dropped.
