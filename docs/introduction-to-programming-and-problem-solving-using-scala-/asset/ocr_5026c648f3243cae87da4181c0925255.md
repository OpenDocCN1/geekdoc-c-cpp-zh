# A.1.1.2 Aside

If you really want to delete an entire directory and all of its contents, including potentially other directories, there is an option for rm that will do that. The -r option rm or cp to recursively run into a directory and either remove or copy all of its contents. It is very helpful if you want to copy a directory. Remember to tread carefully. Using rm with the -r flag has the possibility to wipe out a lot of files that you wanted to keep. The command below uses -r with a copy over an entire directory and all of its contents to the current directory.

```
mlewis@mlewis:~/Desktop$ cp -r ../Music/
```

# A.1.1.3 Helpful Tips

Many who are not familiar with the command line are initially turned off a bit by the amount of time they have to do. People who use command line do not necessarily typing more, they know more tricks to do with things with the keyboard that do not require a lot of time. A couple of tricks will help you use the command line more efficiently include tab completion and viewing your command environment.

Typing in complete file names can be tedious and weary, often prone to error. If you mistake something it will not work and you have to enter the whole thing again. Worse, it might work or you do something you did not want to do. Because of this, tab completion is probably the most helpful feature you will find in command line environment. If you type in the first few letters of a file or directory hit tab, the shell will give you the whole file. If there is only one file that starts with y, it will give you the whole file. If there is more than one, it will fill in as much as it can until it gets to a point where you have to make a choice. Double it will print out the different options that fit.

You should try this by going back to your home directory (remember you can do this any time by typing in cd and hitting without giving it a directory) and then typing De and hitting tab. Odds are good that the word Desktop will be completed for you
