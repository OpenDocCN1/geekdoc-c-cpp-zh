The definition of the Maclaurin series is

```
$f(x) \sim \sum \frac{f^{(i)}(0)}{i!} x^i$
```

So, this is the sum from $i = 0$ up to some $n$ (or infinity if you want to be really accurate). In the sum we have $x$ raised to the $i$ power times the $i^{th}$ derivative of $f(x)$ evaluated at 0 divided by $i$. Obviously, this is a real pain to use functions where taking the derivative is not easy. However, for some functions where the derivatives are straightforward, performing this approximation is very easy. Examples of that would be $e^x$, $\sin(x)$, and $\cos(x)$.

Write a program that does a Maclaurin approximation of $\cos(x)$. That is not hard because the derivative is $-\sin(x)$, which has a derivative of $-\cos(x)$ which goes to $\sin(x)$ back to $\cos(x)$. Note that you are evaluating at $x = 0$; so, all the terms sign to zero.

The first few terms in this series are:

```
$1 - \frac{x^2}{2!} + 0 - \frac{x^4}{4!} - \frac{x^6}{6!} + \frac{x^8}{8!} + \dots$
```

3. Computers are used for simulating physical systems, when the system is hard or impossible to build in a lab. For this project you will write a simple simulation of the gravitational Kepler problem. You will also explore the accuracy of what you are doing in a little bit. Imagine you have a body around a star. We assume the star is much larger than the body it stays at the origin, (0,0), of our coordinate system. The other body start at position $(x, y)$ with velocity $(v_x, v_y)$. For a system like this can be constructed by a discretization of Newton's laws (a way of saying that we use calculus and do things in a way that is more computer friendly). Newton's second law tells us $F_i = m_i a_i$ and for gravity $F = -Gm_im_j$. We want to simplify this for our toy system and say that $a_x = -\frac{GMx}{r^3}$ and $a_y = -\frac{GMy}{r^3}$. Now, the computer is to say of moving slowly, the particle jumps over time step. After one time step the next position is $x = x + v_x\Delta t$ and $y = y + v_y\Delta t$. Similarly, $v_x = v_x + a_x\Delta t$ and $v_y = v_y + a_y\Delta t$. Doing this in a loop 'integrates' the motion of the body. (Use the `math.sqrt` function to calculate $d$).

This integrator is very simple, but far from perfect. If you start at (1,0) with a velocity of (0,1) it should be in a circular orbit staying that distance. By measuring how that distance changes, you can get a measure of how accurate, or inaccurate, the integrator is. You can play with other positions and velocities to see what happens.
