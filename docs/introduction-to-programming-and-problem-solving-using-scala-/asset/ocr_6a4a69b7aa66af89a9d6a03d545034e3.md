The toBinary method does not display leading zeros, so the positive values only show seven digits in both formats. However, the negative format has many leading ones and all of these are printed.

# 2.5.4 Octal and Hexadecimal

Binary is what the machine uses, but it is not useful to use for humans. This is in large part due to the number of digits in a binary number is often large, even if the number itself is not what we consider. There are two other bases that are commonly seen in programming and dealing with numbers. They are base 8, OCTAL, and base 16, HEXADIMAL. Unlike decimal, these bases allow you to represent fairly large numbers with relatively few digits. Unlike decimal, converting from octal or hex is easy and trivial. The reason for this is that 8 and 16 are powers of two.

To see this, when working in base 8, the digits can be between 0 and 7 with each digit being a power of eight. The case of converting to and from binary comes from the fact that it is 2³. In the binary values 0 to 7 are represented by three bits between 000 and 111. The fourth and subsequent bits represent values that are multiples of eight. Because of this, we can convert a binary number to an octal number by grouping bits into groups of three, with the least significant bit, and converting those groups.¹ So binary, 1010011 is 123 in octal. The lowest three bits, 011, convert to 3, the next, 010, and the top bit is just a 1. We can use the toOctal method to confirm this.
