# Arrays and Lists in Scala

- zipIndex – Takes arguments and produces a new collection of tuples where the first is an element of the collection and the second is its index.

```
scala> lst.zipIndex
res65: List[(Int,Int)] = List((7,0), (4,1), (6,2), (3,3), (9,4), (1,5))
```

The methods listed above work on any type of sequence. So they will work on List[Int], a List[String], an Array[Double], or a List[Array[Double]]. There are a few methods that have some special requirements for the type of things in the list. They require certain operations defined, which are self-explanatory, are min, max, sum, and product. The min and max methods work for types that can be ordered. They includes not just Int and Double, but also Strings and many other types where the sum and product methods require the type of the collection to be numeric.

While we wrote operateList and operateArray to do sums and products of collections, we can simply call the sum or product methods as is seen here.

```
scala> lst.sum
res66: Int = 30
```

```
scala> lst.product
res67: Int = 4536
```

The requirement that the values be numeric means that while you can concatenate Strings with +, you cannot put them together. For a List[String] or Array[String], you should use mkString to concatenate the values.

# 6.5.2 Higher-Order Methods

While you feel like the list of methods shown here is rather long and gives us many capacities, we have not yet hit the real power of the Scala collections. All of these methods have taken by adding normal values for arguments. Just like our first recursive methods, they can be made powerful by adding some abstraction and making them higher order methods. Below is a list of many of the order methods that are part of the sequences in Scala. The type A is the type that is contained in the List or Array. The type B could be any other type. Once again, these examples use the declaration of val lst = List(7,4,6,3,9,1).

+   - count(p:(A)=>Boolean) – Takes a function that will operate on an element and result in a Boolean. Returns the number of elements in the collection for which this returns true.

```
scala> lst.count(_ > 5)
res68: Int = 3
```

+   - dropWhile(p:(A)=>Boolean) – Produces a new collection that contains all elements starting with the first one for which function is false.

```
scala> lst.dropWhile(_ < 3)
res69: List[Int] = List(3, 9, 1)
```
