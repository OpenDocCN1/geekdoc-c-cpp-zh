# A.2.2 Text Editors

No matter the operating system, programs are still generally written in plain text files so you need a text editor for doing things. In this section we will look at some of the options you have for this in Windows.

# A.2.2.1 Edit

Working on the command line in 32-bit Windows the command "edit" will bring up a text based program that works like a GUI. You can see it has menus that you can by pressing Alt. They do not the normal things you would expect from an editor. The edit program is much more of a general purpose editor and is much more friendly than vi. As a result, you can use it without much introduction. The down side is that it lacks features are specifically beneficial for programming. If you have a newer Windows installation it is probably 64-bit and there will not be an install of edit. You can use a GUI based text editor instead.

# A.2.2.2 Notepad

Of course, you do not have to edit your text files in the command prompt. You can feel free to use Notepad on Windows and edit files just like that programs need to use that interface. The simple GUI of Notepad has the same benefits and drawbacks of edit. It will work for small things, but it was not built for programming and will slow you down at a certain point.
