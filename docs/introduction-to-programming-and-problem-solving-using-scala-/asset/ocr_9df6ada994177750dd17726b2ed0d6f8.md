We want to start simpler here. Type in a number, like 5, followed by a semicolon and hit enter. You would see something like this:

```
scala> 5;
res0: Int = 5
```

The first line is what you typed at the prompt. The second line is what the Scala REPL printed out as an answer. Recall that REPL stands for Read-Evaluate-Loop. When you type something in, the REPL implies that this happens over and over. After it evaluates it and prints the result, you should have given it a new prompt.

So what does second line mean? The REPL evaluated the statement that you input. In this case, the statement is an expression followed by a semicolon and the REPL was printing the value of the expression you entered. As mentioned above, the REPL needs you to type in full statements so that it can evaluate it. In this case, we typed a very simple statement that has an expression called NUMERIC LITERAL by a semicolon. This semicolon will be inferred if you do not add it in. We will take advantage of that and leave them out of statements.

The end of the output line gives us the value of the expression which is, surprisingly. What about the stuff before that? What does res0: Int mean? The res0 part is a number. It is short for "result". When you type an expression as a statement in the Scala REPL as here, it does not just evaluate it, it gives you a name that you can refer back to. The name is now associated with the 5 in this part of the REPL. We will come back to this later. Now we will focus on the other part of the line,: Int Colors are used in Scala to separate things from their types. We will see a lot more of this through the book, but what matters most to us now is the type, Int. This is the type that Scala uses for basic numeric integers. An integer can be either a positive or negative number. When can you try typing in a few other integer values to see what happens? Most of the times the result will not be all that, but if you push things far enough you might get a surprise or two.

What happens if you type in a number that is not an integer? For example, what if you type in 5.6? Try it, and you would get something like this:

```
scala> 5.6
res1: Double = 5.6
```

We have a different name now because this is a new result. We also get a different type. Instead of Int, Scala now tells us the type is Double. In Double, the Scala uses by default for any non-integer values. If a value is technically an integer, if it includes a decimal point, Scala will interpret it as a Double. You can type in 5.0 to see this in. Trying in some other numeric values that should have a Double as the type. What happens. Anyway, the results will be fairly mundane. Double literals also use scientific notation by putting the letter e between a number and the power of ten it is multiplied by. So 5e3 means 5 * 10^3
