+   * **grouped(size:Int)** – Runs through the sequence, grouping items into groups of the specified size.

```
scala> lst1.grouped(2).foreach(println)
List(7, 4)
List(6, 3)
List(9, 1)
```

```
scala> lst1.grouped(3).foreach(println)
List(7, 4, 6)
List(3, 9, 1)
```

+   * **inits** – Provides an iterator over the full sequence to an empty one, removing elements from the end. As the name implies, it is related to the **init** method, which returns a single sequence without the last element.

```
scala> lst1.inits.foreach(println)
List(7, 4, 6, 3, 9, 1)
List(7, 4, 6, 3, 9)
List(7, 4, 6, 3)
List(7, 4, 6)
List(7, 4)
List(7)
List()
```

+   * **permutations** – Lets you run through all the permutations of the sequence. Note that the example here only permutations of the first three elements as there are 6! = 720 ones for the full list. This also demonstrates why this method return and Iterator. As shown back in chapter 4, the factorial function grows very quickly, so calling **permutations** on even a modest sized sequence would consume more memory than any computer has if all the permutations were actually created at once.

```
scala> lst1.take(3).permutations.foreach(println)
```
