# Scala Basics

There are three ways in which the scala command can be used. If you just type scala and press enter you will be dropped into the Scala REPL (Read-Execute-Print Loop). It is an environment where you can use Scala commands and immediately see their values. This is how we will start interacting with Scala, and it is something that we will come back to throughout the book because it allows us to easily experiment and play around with the language. The fact that it gives us immediate feedback is also quite helpful.

To see how this works, at the prompt, type scala and then press enter. It should print out some information for you, telling you that you can get help by typing :help. It will give you a prompt of the form scala>. You are now in the Scala REPL. If you type :help you will see a number of other commands you could get that begin with a colon. At this time the only one that is significant to us is :quit which we use when we are done with the REPL and to go back to the normal command prompt.

It is customary for the first program in a language to be Hello World. So not to break with tradition

```
println("Hello, World!")
```

If you do this then the next line prints out "Hello, World!". This exercise is less exciting in the REPL because it always prints the values of things, and it is a reasonable thing to start with. It is worth asking what is println1 function in Scala that tells it to print something to standard output and follow that with a newline character2 to go to the next line. In this case, the thing that was printed was the string "Hello, World". You can print other things if you wish. One of the advantages of the REPL is that you can play around. Go ahead and try other things to see what happens.

The second usage of the scala command is to run small programs as scripts. The term script is generally used to refer to short programs that perform specific tasks. There are languages that are designed to work in this type of usage, and are often called scripting languages. The design of Scala makes it easy to use as scripting language. Unlike most scripting languages, Scala also has many features that make it ideal for developing large software projects. To use Scala for scripting, simply type in a little program to a text file that ends with ".scala3 and run it by putting the file name after the scala command on the command line. You could edit a file Hello.scala and add the line of code from above to it. After you have saved the file, go to the command line and enter "scala Hello.scala" to see it run.
