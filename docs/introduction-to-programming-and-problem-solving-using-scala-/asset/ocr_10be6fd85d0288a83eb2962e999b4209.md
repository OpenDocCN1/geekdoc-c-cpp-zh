# 11.6.1 Numeric Properties and Bindings

To illustrate what we can do with numeric bindings, we will use a new example. This example has three Sliders that control the location and size of a rectangle. The first controls the x-location (horizontal location), the second controls the y-location (vertical location), and the third controls the size. There is also a ScrollBar that is bidirectionally bound to one of the Sliders to illustrate how one of the elements change when you change the other element. Lastly, there is a Label that is set to be centered on the window bindings.
