# 17.2 IDEs (Eclipse)

There is still a lot more for you to learn about Scala, programming, and the field of computer science. In order to not only learn, but to maintain the skills you have developed, you need to practice. Many students find the combination of text editor and command line tools that we have used through this book to have an unnatural feel, as it is not the way they normally interact with their computers. Most students are used to use a GUI interface than command line. Having discussed applications and the object-oriented approach to programming in chapter 16, it is now possible to develop development environments that have this type of interaction.

Programs that provide complete support for writing code, running programs, and debugging are called IDEs, the officially supported IDE for Scala is Eclipse. You can download a version of Eclipse with support for Scala already included at http://scala-ide.org. If you download, install, and run this, when you go to the workspace you should see a window like figure 17.1.

When you want to code in Eclipse, you cannot just create a file and go. When you want to create a project. You can do this with File > New > Scala Project or by right clicking on Package Explorer area and selecting New > Scala Project from the context menu.

> The version of Eclipse used by the bundle lags a bit behind the newest version of Eclipse. You can also download Eclipse for Java from http://java.oracle.com and add the Scala plug-in using the link at http://scala-ide.org/download/current.html.
