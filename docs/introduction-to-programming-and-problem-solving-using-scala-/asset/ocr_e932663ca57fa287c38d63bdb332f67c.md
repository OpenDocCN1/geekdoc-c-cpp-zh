# 1.2.2 Memory

Memory on a computer is used to store information. There are two basic types of memory: primary memory (storage) which is known as RAM (Random Access Memory) and secondary memory (storage). Examples of secondary storage include hard drives, solid state drives, flash and magnetic tape. RAM is also referred to as main memory which is directly connected to the CPU. All programs must be loaded into RAM before they can execute and all data must be loaded into RAM before it is processed. Figure 1.2 gives the basic idea of main memory. RAM is considered because when a computer gets turned off, everything in memory is lost unless it has been saved to secondary storage. Secondary storage is considered important because it allows programs and data to be stored permanently, and these can be accessed even after the power has been cut.

Typically goes inverse of size for memory, and this is true of disk and RAM. Disk drives are significantly slower than RAM, though what is written to them stays there even when the machine is turned off. RAM is faster than the disk, but it is not fast enough to respond at the rate that a modern processor can use. For this reason, processors generally have smaller amounts of memory on them cache. The cache is significantly faster than the RAM when it comes to how fast the processor can read or write values. That is not enough anymore, and modern processors include multiple levels of cache referred to as L1, L2, L3, etc. Each level up is generally bigger, but also further from the processor and slower.
