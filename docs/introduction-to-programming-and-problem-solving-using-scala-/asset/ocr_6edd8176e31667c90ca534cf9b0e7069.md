a FLAGGED BUBBLE SORT is this small variation on the normal bubble sort that uses a while loop for the outer loop. It exits after n-1 iterations or if it goes through a pass of the inner loop without doing any swaps as implies that everything is already sorted.

```
def flaggedBubbleSort(a:Array[Double]):Unit = {
  var flip = true
  var j = 0
  while (flip && j < a.length-1) {
    flip = false
    for (i < 0 until a.length-1-j) {
      if (a(i) > a(i+1)) {
        var tmp = a(i)
        a(i) = a(i+1)
        a(i+1) = tmp
        flip = true
      }
    }
    j += 1
  }
}
```

This code adds a few more lines to deal with the flag and the fact that we have to do the counting ourselves with a while loop. The flag is flip, and it starts off as true. However, the inner loop starts is always set to false and only gets back to true when a swap is done.

# 13.1.2 Selection Sort (Min/Max Sort)

The next sort we want to consider is that humans are far more like to employ, especially in a situation like sorting cars where moving cars around takes a significant amount of effort. The sort is the SELECTION SORT, and it is called because it runs through the values and selects one element and places it where it belongs. In order for this to work you have to know where the value should go. This is easy if the value is either the largest or smallest in the collection. As well as either a minimum sort (MIN SORT) or a maximum sort (MAX SORT). In theory one can also write a min-max sort that picks and moves them to where they belong.

We will write a min sort. It is fairly trivial to convert this to max sort. The inner loop of the min sort will run through the currently unsorted part of the collection and find the minimum element. If that element is not already where it should be, it is swapped into place. For an Array, the fact that this is a swap is significant. To understand this, think about the order. Shifting all the cars over one is hard. Swapping two is much easier Array is like the parking lot with fixed locations. Certain other data structures could act more similarly to folders, which slide around and allow slight shifting. If you use an Array and a shift instead of swap, the code will be both longer and significantly slower.

```
def minSort(a:Array[Double]):Unit = {
  for (j < 0 until a.length-1) {
    var min = j
    for (i < j+1 until a.length) {
      if (a(i) < a(min)) min = i
    }
  }
}
```
