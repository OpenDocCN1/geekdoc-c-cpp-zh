# match versus switch

If you are familiar with other programming languages you might have heard of the switch statement. On the surface, match might seem like switch, but match is far more powerful and flexible in ways allowing you to use it more than a switch.

For this chapter, an appropriate example would be to demonstrate recursion instead of if. We can start with a simple example of something like countDown

```
def countDown(n:Int):Unit = n match {
  case i =>
    println(i)
    countDown(i-1)
}
```

This function is not quite as robust as what we had with the if because it only stops on the value 0. This makes it a little less robust, but it does a good job of illustrating the syntax and style of recursion with a match. The recursive argument, the one that changes the function is called, is the argument to match. There is at least one case that does not involve a recursive call and at least one case that does.

A more significant example would be to rewrite the inputCount function using a match.

```
def inputCount(base:Int,func:(Int,Int)->Int):(Int,Int) = readLine() match {
  case "quit" =>
    (base, 0)
  case n =>
    val (s, c) = inputCount(base, func)
    (func(s, n.toInt), c+1)
}
```

Here to call readLine is the argument to match. This is not a standard recursive argument for this function. The decision of whether or not to recurse is based on user input, so the user input is what we match on.
