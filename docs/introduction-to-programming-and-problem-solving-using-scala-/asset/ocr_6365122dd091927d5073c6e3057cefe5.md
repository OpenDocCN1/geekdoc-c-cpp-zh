This example demonstrates something else that we have not seen before, using Groups together Nodes in the scene graph. The parallel lines are Line objects, and we want to provide the same transformations to each of them. This is achieved by putting the two lines in a Group, applying the transforms to Group and adding the Group into the Scene. You can nest Groups inside Groups to create more complicated structures as well. This capability is we say ScalaFX uses a scene graph, and you should take advantage of it if you intend to build more complex graphics using the geometry types in Scalafx.
