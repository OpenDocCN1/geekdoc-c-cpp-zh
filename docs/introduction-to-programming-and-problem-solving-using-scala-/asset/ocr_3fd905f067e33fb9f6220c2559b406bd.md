To color a point you need the color of the object that was light, and the lighting on that point. To get this, send a ray from the point of contact to the light source. If there is any geometry in the way (t value between 0.0 and 1.0), then that point is shadowed and the light does not get to. If there is not anything in the way, that light connects to the point. The color should be the component product of the colors of the light and the object, scaled by the cosine of the angle between the normal and the direction to the light. To find the cosine, keep in mind that $\vec{a}\cdot\vec{b} = |a||b|cos\theta$. To make this easy you should probably store the colors of lights and geometry using DColor. This helps to explain why proper methods in the DColor, Point, and Vect will help to make the code easy to write and read.
