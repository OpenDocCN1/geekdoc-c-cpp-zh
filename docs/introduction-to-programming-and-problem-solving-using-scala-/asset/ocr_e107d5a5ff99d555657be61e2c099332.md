# 12.9 Media

Media, both audio and video, has become a significant part of many modern user interfaces. ScalaFX includes a number of types that we can use to add media to our applications in the scalafx.scene.media package. We will only cover the most significant of these.

Short sounds that you want to play repeatedly are best represented by the AudioClip type. The source needs to be a URL. You can create an AudioClip using new AudioClip(source: String). If you have a file in your current directory, you can simply specify "file:filename". ScalaFX supports a number of audio formats including .wav and mp3.12

Longer audio files and pretty video files should not be loaded completely into memory. The media type would be used to represent such files. You create a Media instance using new Media(source: String) where the source should be a URL, like the AudioClip. In addition to audio formats mentioned above, ScalaFX has fairly general support for video, but it is not as reaching as audio.13 You are likely to find that you have to put some effort to get video files in formats that it is happy with. authors' experience is that the Media instance you use a MediaPlayer. If you create an instance of MediaPlayer using new MediaPlayer(media: Media). If the Media is audio, this is all that you need. For video, you would want to have it displayed in the GUI. This is done by creating a View with new View(mediaPlayer: MediaPlayer). The View is a subtype of Node and can be added to a GUI. Calling the play, pause, and stop methods on the MediaPlayer will control what is displayed in the View

A program demonstrating the use of these media types us play the top will of an AudioClip,14 a button on the button to control it. Most of the displays shows a video with some buttons

# Listing 12.14: Media.scala

```
import scalafx.Includes.-
import scalafx.application.JFXApp
import scalafx.scene.Scene
import scalafx.scene.media.-
import scalafx.scene.layout.-
import scalafx.scene.control.Button
import scalafx.event.ActionEvent

val app = new JFXApp {
  stage = new JFXApp.PrimaryStage {
    title = "Media"
    scene = new Scene(600, 350) {
    val audioClip = new AudioClip("file:Laser-Cannon-Mike-Koenig-779224747.mp3")
    }
  }
}

val playButton = new Button("Play!")
playButton.setOnAction = (ae:ActionEvent) => audioClip.play
playButton.prefWidth = Int.Max
```
