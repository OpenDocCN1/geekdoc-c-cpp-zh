# Introduction to Programming and Problem-Solving Using Scala

Let us now look at the second example math function. In this case we will use the short name g and make it with the Int type instead of Double.

```
scala def g(x:Int,y:Int):Int = x+y*y
g: (x:Int,y:Int):Int
```

Note that both of the parameters are put in the variables and separated by a comma. In general, you can have an arbitrary number of parameters. They can have different types, and they will be separated by commas. The function is called by giving the function name with values separated by commas,

```
scala g(3,5)
res1: Int = 28
```

In this example we used simple literals for the arguments to the function, but the arguments can be any expression with the proper type. For example, we could do the following:

```
scala val a = 5
a: Int = 5

scala g(a+2,square(3).toInt)
res2: Int = 88
```

Here we show that the arguments to g can include a reference to a val or a call to the square function. The call to square needs to be followed by a conversion to an Int because g is declared to take Int and the result type of square is Double. If you leave that out, you will figure them out for us: an error like:

```
scala g(a+2,square(3))
<console>: 9: error: type mismatch;
found : Double
required: Int
g(a+2,square(3))
```

With the val and var declarations, we say that we could typically leave off the types and Scala would figure them for us. With functions, the types on the parameters are required. The result type is not required as it can be inferred, but it is considered better style to specify it. The reason this is preferred is if you call a function and make a mistake in the function that causes it to result in a different type, Scala can tell you that something has gone wrong.

These functions are very useful. If we want to write longer functions, we need to create code blocks using curly braces. A block is composed of statements. The block, itself, is either a statement or an expression. When used as an expression, the value you get from it is the value of the last expression in the block.
