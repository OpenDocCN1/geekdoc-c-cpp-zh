# 13.1.1 Bubble Sort

The first sort we will describe is something of a classic in computer science. It is not efficient. In fact, you would be hard pressed to convince anyone to use this method when sorting things by hand. For for computers they will do whatever you tell them, even if it is extremely repetitive. It is only taught broadly because it is so simple to describe and code.

The basic idea of the BUBBLE SORT is that you want to run through the array and look at items that are next to one another. If two items are out of order, you swap them. One pass through the array will not get sorted unless it was very close to sorted to begin with. However, if you repeat this process and over, the array will eventually get to a situation where it is sorted. Using this description, there are a few ways in which the bubble sort can be written.

```
for (i <- 0; i < a.length-1; i++) {
  if (a(i) > a(i+1)) {
    val tmp = a(i)
    a(i) = a(i+1)
    a(i+1) = tmp
  }
}
```

The end index of this loop can change over iterations to make it more efficient, but the idea is i runs through the array comparing each element to the one after it. If the first is larger than the second, then they would swap a.
