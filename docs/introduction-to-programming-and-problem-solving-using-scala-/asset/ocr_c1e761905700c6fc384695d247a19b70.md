# Graphics and Advanced ScalaFX

# 12.3 Images

Most applications that do graphics cannot do what they need just with shapes. Another critical component for most applications is images. Most of the types that you need to work with are provided by the scalafax.scene.image package. The most fundamental of these types is the Image type, which represents an image. These can be created using one of the following.

+   - Image(url: String, requestedWidth: Double, requestedHeight: Double, preserveRatio: Boolean, smooth: Boolean, backgroundLoading: Boolean)

+   - Image(url: String, requestedWidth: Double, requestedHeight: Double, preserveRatio: Boolean, smooth: Boolean)

+   - Image(url: String, backgroundLoading: Boolean)

+   - Image(url: String)

The url argument specifies the source of the image data. These can start with "file": to pull the information from the local disk. The requestedWidth and requestedHeight arguments allow you to specify the size of the image if you want one that is different from the natural size of the image. The preserveRatio argument, if true, will cause the aspect ratio to be preserved scaling. The smooth argument allows ScalaFX whether you want a higher quality filtering algorithm or a faster one. Lastly, the backgroundLoading argument allows you to let the program continue to execute while image loads in the background.

The Image has height and width properties. The most significant method on the Image type is probably pixelReader: Option[PixelReader]. This will provide a PixelReader that allows the image in question for reading pixels. The details of the PixelReader are discussed later.

If your goal is to get an image to display in your GUI, the ImageView is a subtype of Node that serves this purpose. You can create one of these with new ImageView(url: String) or new ImageView(image: Image). For many applications, it will be able to find out the color of individual pixels in an image. For purposes there is the PixelReader type, which allows you to get the type of information. At this point, two are significant are getRGB(x: Int, y: Int): Int and getColor(x: Int, y: Int): Color. Given the x and y coordinates of a pixel, these methods return the native ARGB value for the color or a Color value for it.

There is a subtype of Image called WritableImage. As the names imply, this type allows you to write to it. Specifically, you can create a PixelWriter, the counterpart to the PixelReader and set the value of individual pixels. To create a WritableImage, use one of the following.

+   - WritableImage(reader: PixelReader, x: Int, y: Int, width: Int, height: Int)

+   - WritableImage(reader: PixelReader, width: Int, height: Int)

+   - WritableImage(width: Int, height: Int)
