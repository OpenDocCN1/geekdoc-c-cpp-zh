Note that if you want to make a program with ScalaFX there one other step that you will have to take. You have to point Eclipse to the ScalaFX JAR file that you have been using with your scripts. To do this, right click on your project and select Build Path > Add External Archives... then select the JAR file on your file system. Once you have done that, you will be able to include ScalaFX types in your applications and run them.
