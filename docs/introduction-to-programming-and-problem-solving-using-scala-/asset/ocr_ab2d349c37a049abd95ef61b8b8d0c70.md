The menus at the top of the Scene are created as part of a MenuBar. ThatMenuBar includes Menus that can be set with the menu property. In this example we add a "File" menu and a "Types" menu. Each menu can be populated by a combination of MenuItems, CheckMenuItems, RadioMenuItems, or other Menus as SeparatorMenuItems that are intended to be with layout.
The "File" menu in this example has several MenuItems that one might expect to see in such a menu, with a separator offset for "Exit". To see this, you should pull the code from the book's GitHub repository and run it. These options also have accelerator keys (like short-cut keys) set for them. All actions have been attached to "Open", "Save", and "Exit". Setting an action handler for a MenuItem is similar to what was done for the Button. You do this by setting the onClick value. The action for "Exit" is to call sys.exit(0), which terminates the program and tells whatever called it that it was a normal termination.
