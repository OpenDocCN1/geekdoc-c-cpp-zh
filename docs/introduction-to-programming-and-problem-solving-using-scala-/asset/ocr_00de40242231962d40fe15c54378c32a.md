1. If you have done the ray-tracing and graphics options, this project continues with that. Ray tracers can implement both reflections and transparency using recursion. If you have a function that tells you what to draw for a particular ray, you can do by recursively calling that function with the reflected ray and combining that color with the color of the reflecting surface. How much of each goes into the color depends on the fractional reflectivity of the object.

For this project you will color your objects, but still will not worry about lighting. When a ray hits an object, it gets the full color of that object unless the object is reflective. If you need to get it (1-R) the color of that object and R of the reflected ray. To add colors you need to build your colors and get the components out of colors. The scalafx.scene.Color has classes red, green, and blue that return the amount of primary in a color. The values are Doubles in the range of 0-1. You can also make a new Color by calling Color(red:Int,green:Int,blue:Int). The values must be passed in the same range or you will get an error.

To calculate reflection, you need the unit-normal vector for the surface you are reflecting off. For a plane this is as easy as the normal is the same everywhere. For a sphere, this is the vector from the center to the point of intersection. In both cases, you normalized it. If you have that, the direction of the reflected ray is given by

```
$$\vec{r}_{reflected} = \vec{r} - 2(\vec{r} \cdot \vec{n})vec{n}$
```

where $\vec{r}$ is the direction of the incoming ray, and $\vec{n}$ is the unit normal. The unit normal will also be significant for calculating lighting in a later project.
