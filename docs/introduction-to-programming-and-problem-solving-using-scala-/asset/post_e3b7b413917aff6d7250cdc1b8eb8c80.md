## 11.6.2 Conditional Bindings

It is possible to make bindings conditional. This is done using `when`, `choose`, and `otherwise`. To illustrate this, we have a simple script that includes a `Slider` and a `Label`. The location of the `Label` is determined by the `Slider`. Unlike the previous example, where the position moved smoothly, the position here is in a discontinuous way so it jumps

from the left side to the right when the Slider crosses the central value. The color of the background is also varies based on whether the mouse is over the Label.

### Listing 11.16: ConditionalBindings.scala

```scala
import scalafx.Includes._
import scalafx.Scene
import scalafx.application.JFXApp
import scalafx.scene.control.Label
import scalafx.scene.control.Slider
import scalafx.scene.paint.Color

val app = new JFXApp {
  stage = new JFXApp.PrimaryStage {
    title = "Conditional Bindings"
    scene = new Scene(500, 250) {
      label = new Label("Hover to change background.")
    }
  }
}
val slider = new Slider(0,100,0)
slider.layoutX = 10
slider.layoutY = 10
slider.prefWidth = 180

content = List(label, slider)
label.layoutX <= when (slider.value < 50) choose 0 otherwise width
label.layoutY <= height/2
fill <= when (hover) choose Color.Red otherwise Color.White
```

At the end of the code you can see how the conditional bindings are created. The `when` is followed by an observable Boolean, that is followed by `choose` the value that should be used if true. That is followed by `otherwise` the value to use if false. Unlike `if` and `else`, `when`, `choose`, and `otherwise` are not keywords in the Scala language, they are part of the ScalaFX library. The `import Includes._` makes them visible, and the others are actually being used in infix style. Figure 11.14 shows the window one gets from this script with the Slider moved above the label, not shown. Recall that infix style is a method with one argument put between the object and operand without dot or parentheses. We typically use this with symbolic operators.

## 11.7 Layout and Panes

While you can use bindings to make things around when you change the size of a window, this is not the way to build complex interfaces. The proper way to make complex interfaces in Scala is with layouts and panes. Most of these are in the `scalafx.scene.layout` package, but some are in `scalafx.scene.control`. The ones in control produce simple layouts that do not interact with the user. Using either of these, you can create complex displays by nesting them inside one another. The panes themselves are Nodes, so each has its own rules for how the elements inside it change size when the whole thing changes.

### 11.7.1 scalafx.scene.layout Panes

The following list describes types provided in `scalafx.scene.layout` package in alphabetical order:

- **AnchorPane** — allows you to set the location of contents inside it to the location of this pane. You can call methods like `AnchorPane.setAnchor(child, value)` to specify where a child should appear. Items can be anchored to more than one edge.
- **BorderPane** — arranges elements in five different regions: top, bottom, left, right, and center. The elements at the top and bottom span the full width of the pane and the left and right elements take the remaining space in height.
- **FlowPane** — places contents one after another giving each as much space as it wants. When it runs out of space it starts a new row or column based on the orientation.
- **Pane** — arranges elements in a flexible grid. The elements can be placed at any row and column, and they are allowed to cover multiple rows and columns. The rows and columns are sized to accommodate the elements they are in.
- **HBox** — arranges elements horizontally to one another.
- **StackPane** — elements on top of one another in the same area of the screen so they overlap.
- **TilePane** — arranges elements in a grid of "tiles". The contents are arranged across each row first. Tile sizes are determined by the contents by default.
- **VBox** — arranges elements vertically below the one before it.

To help illustrate this work the following code creates a GUI that has a `BorderPane` as the primary contents, with a `VBox` on the left, a `FlowPane` on bottom, a `StackPane` on the right, and a `TilePane` in the center. In each of these we add a Button, a Label, a TextField, a TextArea, a ComboBox, and a Slider.

### Listing 11.17: Layouts.scala

```scala
import scalafx.Includes._
import scalafx.Scene
import scalafx.application.JFXApp
import scalafx.scene.control._
import scalafx.scene.layout.BorderPane
import scalafx.scene.layout.FlowPane
import scalafx.scene.layout.HBox
import scalafx.scene.layout.Pane
import scalafx.scene.layout.StackPane
import scalafx.scene.layout.TilePane
import scalafx.scene.layout.VBox
import scalafx.scene.layout.Background
import scalafx.scene.layout.BackgroundFill
import scalafx.scene.color.Color

def addControlsToPane(pane:Pane, fill:Color):Pane = {
  val button = new Button("Click Me")
  val label = new Label("Plain label")
  val field = new TextField
  field.text = "Text Field"
  val area = new TextArea
  area.text = "Text Area\nMultipleLines"
  area.prefWidth = 100
  area.prefHeight = 100
  val combo = new ComboBox(List("Alpha", "Beta", "Gamma"))
  val slider = new Slider
  pane.children = List(button, label, field, area, combo, slider)
  pane.background = new Background(Array(BackgroundFill(fill, null, null)))
  pane
}

val app = new JFXApp {
  stage = new JFXApp.PrimaryStage {
    title = "Layouts"
    scene = new Scene(750,600) {
      val borderPane = new BorderPane
      borderPane.top = addControlsToPane(new HBox(10), Color.gray(0.25))
      borderPane.left = addControlsToPane(new VBox(10), Color.gray(0.75))
      borderPane.bottom = addControlsToPane(new FlowPane(10, 10), Color.gray(0.5))
      borderPane.right = addControlsToPane(new StackPane, Color.gray(1.0))
      val tilePane = new TilePane
      tilePane.prefRows = 2
      borderPane.center = addControlsToPane(tilePane, Color.gray(0.0))
      tilePane.children.foreach(.managed = true)
      root = borderPane
    }
  }
}
app.main(args)
```
