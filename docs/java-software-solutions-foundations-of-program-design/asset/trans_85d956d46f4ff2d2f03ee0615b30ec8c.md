

Lincoln程序中的注释代表了Java允许的两种注释类型之一。Lincoln中的注释采用以下形式：

```
// This is a comment.
```

这种注释以双斜杠（//）开始，一直到行尾结束。两个斜杠之间不能有任何字符。计算机忽略双斜杠之后到行尾的任何文本。注释可以跟在同一行代码后面，用于说明该行，如下例所示：

```
System.out.println ("Monthly Report"); // always use this title
```

Java注释可能具有的第二种形式如下：

```
/* This is another comment. */
```

这种注释类型不使用行尾来表示注释的结束。起始斜杠-星号（/*）和终止星号-斜杠（*/）之间的任何内容都是注释的一部分，包括表示行尾的不可见换行符。因此，这种注释类型可以跨越多行。斜杠和星号之间不能有空格。

如果注释开头的/*后面还有第二个星号，那么注释的内容可以使用名为javadoc的工具自动生成程序的外部文档。附录I中提供了更多关于javadoc的信息。

这两种基本注释类型可用于创建各种文档样式，例如：

```
// This is a comment on a single line.

//------------------------------------------------------------
// Some comments such as those above methods or classes
// deserve to be blocked off to focus special attention
// on a particular aspect of your code. Note that each of
// these lines is technically a separate comment.
//------------------------------------------------------------

/*
    This is one comment
    that spans several lines.
*/
```

程序员常常过于专注于编写代码，以至于对文档关注得太少。你应该养成良好的注释习惯并持之以恒。注释应当写得很好，通常使用完整的句子。

它们不应赘述显而易见的内容，而应对代码的意图提供适当的洞见。以下示例不是好的注释：

```
System.out.println ("hello"); // prints hello
System.out.println ("test"); // change this later
```

第一条注释复述了该行显而易见的目的，没有给语句增加任何价值。没有注释也比无用的注释好。第二条注释含义模糊。以后应该改什么？什么时候是“以后”？为什么要改？

> 关键概念
> 内联文档应提供对代码的洞察。它不应含糊不清，也不应赘述显而易见的内容。

## 标识符和保留字

编写程序时使用的各种单词称为标识符。Lincoln程序中的标识符有class、Lincoln、public、static、void、main、String、args、System、out和println。它们分为三类：

-   我们在编写程序时自己创造的单词（Lincoln和args）
-   其他程序员选择的单词（String、System、out、println和main）
-   语言中保留用于特殊用途的单词（class、public、static和void）

在编写程序时，我们只是选择将类命名为Lincoln，但我们本可以使用许多其他可能的名称。例如，我们可以称它为Quote、Abe或GoodOne。标识符args（是arguments的缩写）经常以我们在Lincoln中的方式使用，但我们本可以使用几乎任何其他标识符来代替它。

标识符String、System、out和println是由其他程序员选择的。这些词不是Java语言的一部分。它们是Java标准库中预定义代码的一部分，是一组已经有人为我们编写好的类和方法。这些代码的作者选择了其中的标识符——我们只是在利用它们。

保留字是在编程语言中具有特殊含义且只能以预定义方式使用的标识符。保留字不能用于任何其他目的，例如命名类或方法。在Lincoln程序中，使用的保留字是class、public、static和void。在本书中，我们以蓝色字体显示Java保留字。图1.18按字母顺序列出了所有Java保留字。标有星号的单词已被保留，但目前没有意义。

标识符中可以使用大写和小写字母，且大小写字母的区别很重要。Java是区分大小写的，这意味着两个仅字母大小写不同的标识符名称被视为不同的标识符。因此，total、Total、ToTaL和TOTAL都是不同的标识符。可以想象，使用多个仅大小写不同的标识符并不是一个好主意，因为它们很容易混淆。

虽然Java语言并不要求这样做，但对每种标识符使用一致的大小写格式会使你的标识符更易于理解。关于标识符，有许多应遵循的Java约定，尽管从技术上讲并非必须。例如，我们对类名使用标题大小写（每个单词首字母大写）。在整本书中，我们会在每种类型的标识符首次出现时描述其首选的大小写风格。

虽然标识符可以是任意长度，但你应该仔细选择名称。它们应具有描述性但不应冗长。你应该避免使用无意义的名称，如a或x。如果短名称确实具有描述性，则可以例外，例如使用x和y表示二维网格上的(x, y)坐标。同样，你不应使用不必要地长的名称，例如标识符theCurrentItemBeingProcessed。名称currentItem也同样适用。可以想象，使用冗长标识符的问题远不如使用无描述性名称的问题普遍。

你应该始终努力使程序尽可能易读。因此，在缩写单词时应始终小心。你可能会认为curStVal是表示当前股票价值的好名字，但其他试图理解代码的人可能难以弄清楚你的意思。甚至在写完两个月后，你自己可能都不清楚了。

> 关键概念
> Java 区分大小写。字母的大写和小写版本是不同的。

> 关键概念
> 标识符名称应具有描述性且易读。

## 空白

所有Java程序都使用空白来分隔程序中的单词和符号。空白由空格、制表符和换行符组成。短语“空白”指的是在一张带黑色印刷的白色纸张上，单词和符号之间的空间是白色的。程序员使用空白的方式很重要，因为它可以用来强调代码的某些部分，并使程序更易于阅读。

除非用于分隔单词，否则计算机会忽略空白。它不影响程序的执行。这一事实使程序员在格式化程序时具有很大的灵活性。程序的各行应在逻辑位置进行划分，某些行应缩进和对齐，以便程序的底层结构清晰。

由于空白会被忽略，我们可以用许多不同的方式编写程序。例如，将空白推向一个极端，我们可以让每行容纳尽可能多的单词。清单1.2中的Lincoln2程序的格式化方式与Lincoln截然不同，但打印出相同的消息。

> 关键概念
> 适当使用空白使程序更易于阅读和理解。
