# 13.2 Dynamic Representations

An array is only one way in which a list can be represented. Arrays are limited in one sense, because they have a fixed size throughout their existence. Sometimes we don’t know how big to make an array, because we don’t know how much information we will store. The ArrayList class handles this by creating a larger array and copying everything over whenever necessary. This is not necessarily an efficient implementation.

A dynamic data structure is implemented using links. Using references as links between objects, we can create whatever type of structure is appropriate for the situation. If implemented carefully, the structure can be quite efficient to search and modify. Structures created this way are considered to be dynamic, because their size is determined dynamically, as they are used, and not by their declaration.

> KEY CONCEPT
> The size of a dynamic data structure grows and shrinks as needed.
