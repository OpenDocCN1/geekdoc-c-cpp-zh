# 2.8 Applets

SR 2.42 A Java applet is a Java program that can be executed using a Web browser. Usually, the bytecode form of the Java applet is pulled across the Internet from another computer and executed locally. A Java application is a Java program that can stand on its own. It does not require a Web browser in order to execute.

SR 2.43 An applet’s paint method is invoked by the system whenever the applet’s graphic element needs to be displayed (or “painted”) on the screen. Examples include when the applet first runs or when a window that was covering the applet’s window is removed.

SR 2.44 The code tag should indicate a bytecode file, such as DrawHouse.class, and not a source code file. The file indicated by the tag is supposed to be “ready to run” on a Java interpreter.
