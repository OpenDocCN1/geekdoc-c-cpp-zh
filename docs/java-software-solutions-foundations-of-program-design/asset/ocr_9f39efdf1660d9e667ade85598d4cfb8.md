A character string is an object in Java, defined by the class String. Because strings are so fundamental to computer programming, Java provides the ability to use a string literal, delimited by double quotation characters, as we've seen in previous examples. We explore the String class and its methods in more detail in Chapter 3. For now, let's explore the use of string literals in more detail in this chapter.

+   The following are all examples of valid string literals:
+   
+   "The quick brown fox jumped over the lazy dog."
+   "602 Greenbriar Court, Chalfont PA 18914"
+   "x"
+   ""

A string literal can contain any valid characters, including numeric digits, punctuation, and other special characters. The last example in the list above contains no characters at all.

# The print and printIn Methods

In the Lincoln program in Chapter 1, we invoked the printIn method as follows:

```
System.out.println("Whatever you are, be a good one.");
```

This statement demonstrates the use of objects. The System.out object represents an output device or file, which by default is the monitor screen. To be more precise, the object's name is out and it is stored in the System class. We explore that relationship in more detail at the appropriate point in the text.

The printIn method is a service that the System.out object performs for us. Whenever we request it, the object will print a character string to the screen. We can say that we send the printIn message to the System.out object to request that some text be printed.

Each piece of data that we send to a method is called a parameter. In this case, the printIn method takes only one parameter: the string of characters to be printed.
