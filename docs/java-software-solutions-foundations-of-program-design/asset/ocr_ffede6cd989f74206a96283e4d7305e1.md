In Chapter 3, we used classes and objects for the various services they provide. That is, we used the predefined classes in the Java class library that are provided to us to make the process of writing programs easier. In this chapter, we address the heart of object-oriented programming: writing our own classes to define our own objects. This chapter explores the basics of class definitions, including the structure of methods and the scope and encapsulation of data. The Graphics Track sections of this chapter discuss how to write classes that have graphical representations and introduce the issues necessary to create a truly interactive graphical user interface.
