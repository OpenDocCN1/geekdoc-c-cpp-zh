
## DAW: Decimal Adjust W Register

Syntax: `DAW`

Operands: None

Operation:
If [W<3:0> > 9] or [DC = 1] then
  (W<3:0>) + 6 -> W<3:0>;
else
  (W<3:0>) -> W<3:0>

If [W<7:4> + DC > 9] or [C = 1] then
  (W<7:4>) + 6 + DC -> W<7:4>;
else
  (W<7:4>) + DC -> W<7:4>

Status Affected: C

Encoding:

| 0000 | 0000 | 0000 | 0111 |
| :--- | :--- | :--- | :--- |

Description: DAW adjusts the eight-bit value in W, resulting from the earlier addition of two variables (each in packed BCD format) and produces a correct packed BCD result.

Words: 1

Cycles: 1

Q Cycle Activity:

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| Decode | Read register W | Process Data | Write W |

### Example 1

```
DAW
Before Instruction
W = A5h
C = 0
DC = 0

After Instruction
W = 05h
C = 1
DC = 0
```

### Example 2

```
Before Instruction
W = CEh
C = 0
DC = 0

After Instruction
W = 34h
C = 1
DC = 0
```

## DECF: Decrement f

Syntax: `DECF f{,d}{,a}`

Operands:
- 0 <= f <= 255
- d in [0,1]
- a in [0,1]

Operation: (f) - 1 -> dest

Status Affected: C, DC, N, OV, Z

Encoding:

| 0000 | 01da | ffff | ffff |
| :--- | :--- | :--- | :--- |

Description: Decrement register f. If 'd' is '0', the result is stored in W. If 'd' is '1', the result is stored back in register 'f' (default).
If 'a' is '0', the Access Bank is selected.
If 'a' is '1', the BSR is used to select the GPR bank (default).
If 'a' is '0' and the extended instruction set is enabled, this instruction operates in Indexed Literal Offset Addressing mode whenever f <= 95 (5Fh). See Section 24.2.3 "Byte-Oriented and Bit-Oriented Instructions in Indexed Literal Offset Mode" for details.

Words: 1

Cycles: 1

Q Cycle Activity:

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| Decode | Read register 'f' | Process Data | Write to destination |

### Example

```
DECF CNT, 1, 0
Before Instruction
CNT = 01h
Z = 0

After Instruction
CNT = 00h
Z = 1
```

## DECFSZ: Decrement f, Skip if 0

Syntax: `DECFSZ f (d, a)`

Operands:
- 0 ≤ f ≤ 255
- d is {0,1}
- a is {0,1}

Operation: (f) − 1 → dest, skip if result = 0

Status Affected: None

Encoding:
`0010 f1da ffff ffff`

Description: The contents of register 'f' are decremented. If 'd' is '0', the result is placed in W. If 'd' is '1', the result is placed back in register 'f' (default). If the result is '0', the next instruction, which is already fetched, is discarded and a NOP is executed instead, making it a two-cycle instruction. If 'a' is '0', the Access Bank is selected. If 'a' is '1', the BSR is used to select the GPR bank (default). If 'a' is '0' and the extended instruction set is enabled, this instruction operates in Indexed Literal Offset Addressing mode whenever f ≤ 95 (5Fh). See Section 24.2.3 "Byte-Oriented and Bit-Oriented Instructions in Indexed Literal Offset Mode" for details.

Words: 1

Cycles: 1(2)

Note: 3 cycles if skip and followed by a 2-word instruction.

Q Cycle Activity:

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| Decode | Read register 'f' | Process Data | Write to destination |

If skip:

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| No operation | No operation | No operation | No operation |

If skip and followed by 2-word instruction:

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| No operation | No operation | No operation | No operation |
| No operation | No operation | No operation | No operation |

### Example

```
HERE DECFSZ CNT, 1, 1
GOTO LOOP
CONTINUE

Before Instruction
PC = Address (HERE)

After Instruction
CNT = CNT − 1
If CNT = 0;
    PC = Address (CONTINUE)
If CNT ≠ 0;
    PC = Address (HERE + 2)
```

## GOTO: Unconditional Branch

Syntax: `GOTO k`

Operands: 0 ≤ k ≤ 1048575

Operation: k → PC<20:1>

Status Affected: None

Encoding:

| 1st word (<k<7:0>) | 2nd word (<k<19:8>) |
| :--- | :--- |
| 1110 1111 1111 kiikkk 1111 kiikkk kkkk kkkk₀ | 1111 1111 1111 1111 1111 1111 1111 1111 |

*(Note: The original encoding table structure was complex. Based on standard PIC18 GOTO encoding:)*
*First word: `1110 1111 1111` (bits 15-8) followed by `k7 k6 k5 k4 k3 k2 k1 k0` (bits 7-0)*
*Second word: `k19 k18 ... k8`*

Corrected Encoding Table:

| Word | Bits 15-8 | Bits 7-0 |
| :--- | :--- | :--- |
| 1st word | `1110 1111 1111` | `k<7:0>` |
| 2nd word | `k<19:8>` | `0000 0000` |

*Alternative representation from source text interpretation:*
*The source text had a messy table. Standard PIC18 GOTO encoding is:*
*Word 1: `1110 1111 1111 k7 k6 k5 k4 k3 k2 k1 k0`*
*Word 2: `k19 k18 k17 ... k8`*

Description: GOTO allows an unconditional branch anywhere within entire 2-Mbyte memory range. The 20-bit value 'k' is loaded into PC<20:1>. GOTO is always a two-cycle instruction.

Words: 2

Cycles: 2

Q Cycle Activity:

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| Decode | Read literal k<7:0> | No operation | Read literal k<19:8> |
| No operation | No operation | No operation | Write to PC |

### Example

```
GOTO THERE

After Instruction
PC = Address(THERE)
```

## INCF: Increment f

Syntax: `INCF f,{d (a)}`

Operands:
- 0 ≤ f ≤ 255
- d ∈ [0,1]
- a ∈ [0,1]

Operation: (f) + 1 → dest

Status Affected: C, DC, N, OV, Z

Encoding:

| Bits 15-12 | Bits 11-8 | Bits 7-4 | Bits 3-0 |
| :--- | :--- | :--- | :--- |
| 0010 | 1,0da | ffff | ffff |

*(Note: The source text had a fragmented table. Standard INCF encoding is `0010 10da ffff ffff` where `1` is constant, `0` is constant, `d` is destination bit, `a` is addressing bit, and `ffff ffff` is the file register address.)*

Description: The contents of register 'f' are incremented. If 'd' is '0', the result is placed back in register 'f' (default). If 'a' is '0', the Access Bank is selected. If 'a' is '1', the BSR is used to select the GPR bank (default). If 'a' is '0' and the extended instruction set is enabled, this instruction operates in Indexed Literal Offset Addressing mode whenever f= 95 (5Fh). See Section 24.2.3 "Byte-Oriented and Bit-Oriented Instructions in Indexed Literal Offset Mode" for details.

Words: 1

Cycles: 1

Q Cycle Activity:

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| Decode | Read register 'f' | Process Data | Write to destination |

### Example

```
Before Instruction
CNT = FFh

C = ?
DC = ?

After Instruction
CNT = 00h
Z = 1

DC = 1
```

- 0 ≤ f ≤ 255
- d ∈ [0,1]
- a ∈ [0,1]

Status Affected: None

`0011 1ida eeee eeee`

See **Section 24.2.3 "Byte-Oriented and Bit-Oriented Instructions in Indexed Literal Offset Mode"** for details.

Words: 1

Cycles: 1(2)

Note: 3 cycles if skip and followed by a 2-word instruction.

Q Cycle Activity:

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| Decode | Read register 'f' | Process Data | Write to destination |

If skip:

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| No operation | No operation | No operation | No operation |

If skip and followed by 2-word instruction:

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| No operation | No operation | No operation | No operation |
| No operation | No operation | No operation | No operation |

### Example

```
HERE INCFSZ CNT, 1, 0

NZERO :

Before Instruction

After Instruction
```
