## 9 PIC18F 中断 I/O、LCD 和键盘接口

本章描述轮询（polled）和中断 I/O 的基础知识。主题包括使用汇编和 C 语言实现 PIC18F 的轮询和中断 I/O。此外，还涵盖了 PIC18F4321 与典型 LCD（如 Hitachi HD44780）以及十六进制键盘接口的技术。

### 9.1 轮询 I/O 与中断 I/O 的基础

通常有两种方式利用程序化 I/O（programmed I/O）。即*无条件 I/O*（unconditional I/O）和*有条件 I/O*（conditional I/O）。使用无条件 I/O，微控制器可以随时向外部设备发送数据。外部设备必须始终准备好进行数据传输。一个典型的例子是微控制器通过 I/O 端口输出一个 7 位代码来驱动连接在该端口上的七段显示管。在有条件 I/O 中，微控制器通过*握手*（handshaking）向外部设备输出数据。这意味着数据传输是通过微控制器与外部设备之间交换控制信号来完成的。微控制器输入外部设备的状态，以确定该设备是否准备好进行数据传输。当设备准备好时，进行数据传输。图 9.1 中的流程图说明了有条件程序化 I/O 或轮询 I/O 的概念。

现在，我们将通过通用微控制器与模数转换器（A/D converter 或 ADC）之间的数据传输来演示轮询 I/O 的概念。如前所述，在本书中，“A/D 转换器”和“ADC”这两个名称将互换使用。假设该微控制器没有片上 A/D 转换器。接下来，考虑图 9.2 中所示的 A/D 转换器芯片。A/D 转换器将模拟电压 $\mathrm{V}_{\mathrm{i}}$ 转换为引脚 $\mathrm{D}_{7}-\mathrm{D}_{0}$ 上的 8 位二进制输出。START conversion（开始转换）引脚上的脉冲启动转换过程。这使得 BUSY（忙）信号变为低电平。在转换过程中，该信号保持低电平。转换一旦结束，BUSY 信号变为高电平。注意，OUTPUT ENABLE（输出使能）上的低电平会将 A/D 转换器的输出传输出去。

可以通过将外部 A/D 转换器芯片接口到微控制器芯片来演示轮询 I/O 的概念。图 9.3 展示了这样一个接口示例。用户编写程序来执行转换过程。当该程序执行时，微控制器通过端口 A 的第 2 位向转换器的 START 引脚发送一个脉冲。然后，微控制器通过输入端口 A 的第 1 位来检查 BUSY 信号，以确定转换是否完成。如果 BUSY 信号为高电平（指示转换结束），微控制器向 A/D 转换器的 $\overline{OUTPUT\ ENABLE}$ 引脚发送低电平。然后，微控制器通过端口 B 输入转换器的 $D_7$-$D_0$ 输出。如果转换未完成，微控制器在循环中等待，检查 BUSY 信号是否变为高电平。这被称为“有条件或轮询 I/O”。轮询 I/O 的一个缺点是，微控制器需要通过在循环中等待来检查状态位（在此处为 A/D 转换器的 BUSY 信号）。这种类型的 I/O 传输取决于外部设备（此处为 A/D 转换器）的速度。对于较慢的设备，这种等待可能会降低微控制器处理主程序中其他数据的能力。在中断 I/O 技术在这种情况下效率更高。

中断 I/O 是由设备发起的 I/O 传输。外部设备（在此处为 A/D 转换器芯片）如图 9.4 所示连接到微控制器芯片上称为“中断（INT）引脚”的引脚。当微控制器需要与 A/D 转换器进行 I/O 传输时，由用户编写的程序通过端口 A 的第 7 位启动 A/D 转换。A/D 转换器芯片独立于微控制器执行转换。当转换完成时，A/D 转换器在其 BUSY 引脚上输出高电平。这将激活微控制器的中断引脚。微控制器完成当前指令，并通常将当前程序计数器（RETURN 地址）和状态寄存器的内容保存到堆栈上。
