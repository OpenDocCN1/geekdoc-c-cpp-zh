
## IORLW 字面量包含 OR 到 W

**语法：** IORLW k  
**操作数：** 0 ≤ k ≤ 255  
**操作：** (W) OR k → W  
**受影响的状态：** N, Z  

**编码：**

| 0000 | 1001 | kkkk | kkkk |
| :--- | :--- | :--- | :--- |

**描述：** W 的内容与八位字面量 'k' 进行或运算。结果存储在 W 中。

**字数：** 1  
**周期：** 1  

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 读取字面量 'k' | 处理数据 | 写入 W |

**示例：** IORLW 35h  
指令执行前： W = 9Ah  
指令执行后： W = BFh

## IORWF W 与 f 进行包含 OR

**语法：** IORWF f {d, (a)}  
**操作数：** 0 ≤ f ≤ 255, d ∈ {0,1}, a ∈ {0,1}  
**操作：** (W) OR (f) → dest  
**受影响的状态：** N, Z  

**编码：**

| 0001 | 00da | ffff | ffff |
| :--- | :--- | :--- | :--- |

**描述：** 将 W 与寄存器 f 进行包含或运算。如果 'd' 为 '0'，结果存储在 W 中。如果 'd' 为 '1'，结果存储回寄存器 'f' 中（默认值）。如果 'a' 为 '0'，则选择访问存储区。如果 'a' 为 '1'，则使用 BSR 选择 GPR 存储区（默认值）。如果 'a' 为 '0' 且启用了扩展指令集，则当 f = 05 (5Fh) 时，此指令在索引字面量偏移寻址模式下运行。有关详情，请参阅**第 24.2.3 节“索引字面量偏移模式下的字节定向和位定向指令”**。

**字数：** 1  
**周期：** 1  

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 读取寄存器 f | 处理数据 | 写入目标地址 |

**示例：** IORWF RESULT, 0, 1  
指令执行前： RESULT = 13h, W = 91h  
指令执行后： RESULT = 13h, W = 93h

#### LFSR 加载 FSR

**语法：** LFSR f, k  
**操作数：**  
- 0 ≤ f ≤ 2
- 0 ≤ k ≤ 4095
- k → FSRf  
**操作：** （隐含）  
**受影响的状态：** 无  

**编码：**

| 1110 1110 00ff | kkkk |
| :--- | :--- |
| 1111 0000 kkkk | kkkk |

**描述：** 12 位字面量 'k' 被加载到由 'f' 指向的文件选择寄存器（FSR）中。

**字数：** 2  
**周期：** 2  

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 读取字面量 'k' 的高字节 | 处理数据 | 将字面量 'k' 的高字节写入 FSRfH |
| 解码 | 读取字面量 'k' 的低字节 | 处理数据 | 将字面量 'k' 写入 FSRfL |

**示例：** LFSR 2, 3ABh  
指令执行后：  
- FSR2H = 03h
- FSR2L = ABh

#### MOVF 移动 f

**语法：** MOVF f, d (d, a)  
**操作数：**  
- 0 ≤ f ≤ 255
- d ∈ {0, 1}
- a ∈ {0, 1}
- f → dest  
**操作：** （隐含）  
**受影响的状态：** N, Z  

**编码：**

| 0101 | 00aa | ffff | ffff |
| :--- | :--- | :--- | :--- |

**描述：** 寄存器 'f' 的内容被移动到取决于 'd' 状态的目标位置。如果 'd' 为 '0'，结果存储在 W 中。如果 'd' 为 '1'，结果存储回寄存器 'f' 中（默认值）。位置 'f' 可以是 256 字节存储区中的任何位置。

如果 'a' 为 '0'，则选择访问存储区。
如果 'a' 为 '1'，则使用 BSR 选择 GPR 存储区（默认值）。
如果 'a' 为 '0' 且启用了扩展指令集，则当 f ≤ 95 (5Fh) 时，此指令在索引字面量偏移寻址模式下运行。有关详情，请参阅*第 24.2.3 节“索引字面量偏移模式下的字节定向和位定向指令”*。

**字数：** 1  
**周期：** 1  

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 读取寄存器 'f' | 处理数据 | 写入 W |

**示例：** MOVF REG, 0, 0  
指令执行前：  
- REG = 22h
- W = FFh  
指令执行后：  
- REG = 22h
- W = 22h

#### MOVFF 将 f 移动到 f

**语法：** MOVFF f<sub>src</sub>, f<sub>dst</sub>  
**操作数：**  
- 0 ≤ f<sub>src</sub> ≤ 4095
- 0 ≤ f<sub>dst</sub> ≤ 4095  
**操作：** (f<sub>src</sub>) → f<sub>dst</sub>  
**受影响的状态：** 无  

**编码：**

| 1110 | ffff | ffff | f |
| :--- | :--- | :--- | :--- |
| 1111 | ffff | ffff | f |

**描述：** 源寄存器 f<sub>src</sub> 的内容被移动到目标寄存器 f<sub>dst</sub>。源位置 f<sub>src</sub> 可以是 4096 字节数据空间（000h 到 FFFh）中的任何位置，目标位置 f<sub>dst</sub> 也可以是 000h 到 FFFh 之间的任何位置。源或目标都可以是 W（这是一种有用的特殊情况）。MOVFF 特别适用于将数据存储位置的数据传输到外设寄存器（例如发送缓冲区或 I/O 端口）。MOVFF 指令不能使用 PCL、TOSU、TOSH 或 TOSL 作为目标寄存器。

**字数：** 2  
**周期：** 2 (3)  

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 读取寄存器 f<sub>src</sub> | 处理数据 | 无操作 |
| 解码 | 无操作 / 无虚读取 | 无操作 | 写入寄存器 f<sub>dst</sub> |

**示例：** MOVFF REG1, REG2  
指令执行前：  
- REG1 = 33h
- REG2 = 11h  
指令执行后：  
- REG1 = 33h
- REG2 = 33h

#### MOVLB 将字面量移动到 BSR 的低半字节

**语法：** MOVLW k *(注意：指令名称为 MOVLB，源文中语法显示为 MOVLW 可能是 MOVLB 的 OCR 错误)*  
**操作数：** 0 ≤ k ≤ 255  
**操作：** k → BSR  
**受影响的状态：** 无

| :--- | :--- | :--- | :--- |

**描述：** 八位字面量 'k' 被加载到存储区选择寄存器（BSR）中。BSR<7:4> 的值始终为 '0'，与 k<7>...k<4> 的值无关。

**字数：** 1  
**周期：** 1  

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 读取字面量 'k' | 处理数据 | 将字面量 'k' 写入 BSR |

**示例：** MOVLB 5  
指令执行前： BSR 寄存器 = 02h  
指令执行后： BSR 寄存器 = 05h

#### MULLW 字面量与 W 相乘

**语法：** MULLW k  
**操作数：** 0 ≤ k ≤ 255  
**操作：** (W) × k → PRODH:PRODL  
**受影响的状态：** 无  

**编码：**

| 0000 | 1101 | kkkk | kkkk |
| :--- | :--- | :--- | :--- |

**描述：** W 的内容与 8 位字面量 'k' 之间执行无符号乘法。16 位结果存储在 PRODH:PRODL 寄存器对中。PRODH 包含高字节，W 保持不变。状态标志均不受影响。注意，在此操作中既不会溢出也不会产生进位。结果可能为零，但不会检测零结果。

**字数：** 1  
**周期：** 1  

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 读取字面量 'k' | 处理数据 | 写入寄存器 PRODH: PRODL |

**示例：** MULLW 0C4h *(注意：操作数限制为 255，0C4h > 255。可能是 0Ch 或其他值的 OCR 错误。根据不总结/删除的指示保留原文，但指出如果严格验证则存在逻辑不一致。然而，标准 PIC18 MULLW 接受 8 位字面量。0C4h 的十进制值为 196，这是有效的。)*  
指令执行前：  
- W = E2h
- PRODH = ?
- PRODL = ?  
指令执行后：  
- W = E2h
- PRODH = ADh
- PRODL = 08h

**语法：** MULWF f{,a}

- a ∈ [0,1]  
**操作：** (W) × f() → PRODH:PRODL  
**受影响的状态：** 无  

**编码：**

| 0000 | 001a | ffff | ffff |
| :--- | :--- | :--- | :--- |

**描述：** W 的内容与寄存器文件位置 'f' 之间执行无符号乘法。16 位结果存储在 PRODH:PRODL 寄存器对中。PRODH 包含高字节。W 和 'f' 均保持不变。状态标志均不受影响。注意，在此操作中既不会溢出也不会产生进位。结果可能为零，但不会检测零结果。如果 'a' 为 '0'，则选择访问存储区。如果 'a' 为 '1'，则使用 BSR 选择 GPR 存储区（默认值）。如果 'a' 为 '0' 且启用了扩展指令集，则当 f ≤ 95 (5Fh) 时，此指令在索引字面量偏移寻址模式下运行。有关详情，请参阅第 24.2.3 节“索引字面量偏移模式下的字节定向和位定向指令”。

**字数：** 1  
**周期：** 1  

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 读取寄存器 'f' | 处理数据 | 写入寄存器 PRODH: PRODL |

**示例：** MULWF REG, 1  
指令执行前：  
- W = C4h
- REG = B5h
- PRODH = ?
- PRODL = ?  
指令执行后：  
- W = C4h
- REG = B5h
- PRODH = 8Ah
- PRODL = 94h
