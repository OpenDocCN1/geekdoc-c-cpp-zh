+   * **BTFSS F, b, a (BTFSS 0x70, 0)** instruction tests the specified bit ‘b’ in the file register ‘F’, and skips the next instruction if the bit ‘b’ is ‘1’. On the other hand, if bit ‘b’ is ‘0’, the PIC18F executes the next instruction. Like the BTFSC instruction, the GOTO or BRA instruction is typically used after the BTFSS instruction. The BTFSS instruction can be used for conditional (polled) I/O. This topic is discussed later.

After execution of **BTFSS 0x70, 0:** Since bit 0 of [0x70] is 1, the BTFSS skips the next instruction.
