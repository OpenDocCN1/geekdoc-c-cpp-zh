
## TSTFSZ 测试 f，若为 0 则跳过

**语法：**
TSTFSZ f(a)

**操作数：**
0 ≤ f ≤ 255
a = [0,1]

**操作：**
若 f = 0 则跳过

**受影响的状态：**
无

| 二进制 | 二进制 | 十六进制 | 十六进制 |
| :--- | :--- | :--- | :--- |
| 0110 | 011a | ffff | ffff |

**描述：**
若 ‘f = 0’，当前指令执行期间获取的下一条指令将被丢弃，并执行一条空操作（NOOP），这使得该指令成为一条双周期指令。
若 ‘a’ 为 ‘0’，则选择访问页（Access Bank）。
若 ‘a’ 为 ‘1’，则使用 BSR 来选择 GPR 页（默认值）。
若 ‘a’ 为 ‘0’ 且启用了扩展指令集，则当 f ≤ 95 (5Fh) 时，该指令在字面量偏移寻址模式（Indexed Literal Offset Addressing mode）下工作。详见第 24.2.3 节“字面量偏移模式下的字节导向和位导向指令”。

**字数：**
1

**周期数：**
1(2)

**注意：**
若跳过且后接一条双字指令，则需要 3 个周期。

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 译码 | 读取寄存器 ‘f’ | 处理数据 | 无操作 |

若跳过：

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 无操作 | 无操作 | 无操作 | 无操作 |

若跳过且后接双字指令：

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 无操作 | 无操作 | 无操作 | 无操作 |
| 无操作 | 无操作 | 无操作 | 无操作 |

```
Example:
HERE TSTFSZ CNT, 1
NZERO :
ZERO :

Before Instruction
PC = Address (HERE)
After Instruction
If CNT = 00h,
PG = Address (ZERO)
If CNT ≠ 00h,
PG = Address (NZERO)
```

## XORLW W 与字面值异或

**语法：**
XORLW k

**操作数：**
0 ≤ k ≤ 255

**操作：**
(W).XOR. k → W

**受影响的状态：**
N, Z

| 二进制 | 二进制 | 十六进制 | 十六进制 |
| :--- | :--- | :--- | :--- |
| 0000 | 1010 | kkkk | kkkk |

**描述：**
将 W 的内容与 8 位字面值 ‘k’ 进行异或运算。结果存入 W。

**字数：**
1

**周期数：**
1

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 译码 | 读取字面值 ‘k’ | 处理数据 | 写入 W |

```
Example:
XORLW 0AFh
Before Instruction W = B5h
After Instruction W = 1Ah
```
