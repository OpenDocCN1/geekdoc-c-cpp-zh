

## SUBLW 字面量减 W

- 语法：`SUBLW k`
- 操作数：`0 ≤ k ≤ 255`
- 操作：`k → (W) → W`
- 影响的标志位：N、OV、C、DC、Z

**编码：**

| 位 15-8 | 位 7-0 |
| :--- | :--- |
| 0000 1000 | kkkk kkkk |

**描述**
八位立即数 'k' 从 W 中减去。结果存入 W。

- 字数：1
- 周期数：1

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 读取立即数 'k' | 处理数据 | 写入 W |

**示例 1：SUBLW 02h**
指令执行前
W = 01h
C = ?

指令执行后
W = 01h
C = 1 ; 结果为正
Z = 1
N = 0

**示例 2：SUBLW 02h**
指令执行前
W = 02h
C = ?

指令执行后
W = 00h
C = 1 ; 结果为零
Z = 1
N = 0

**示例 3：SUBLW 02h**
指令执行前
W = 03h
C = ?

指令执行后
W = Fh ; (补码表示负数)
C = 0 ; 结果为负
Z = 0
N = 1

## SUBWF f 减 W

- 语法：`SUBWF f, {d, (a)}`
- 操作数：
  - `0 ≤ f ≤ 255`
  - `d = {0,1}`
  - `a = {0,1}`
- 操作：`(f) − (W) → dest`
- 影响的标志位：N、OV、C、DC、Z

**编码：**

| 位 15-8 | 位 7-0 |
| :--- | :--- |
| 0101 11dd | ffff ffff |

**描述**
寄存器 'f' 减去 W（补码法）。如果 'd' 为 '0'，结果存入 W。如果 'd' 为 '1'，结果存回寄存器 'f'（默认）。

如果 'a' 为 '0'，选择访问银行（Access Bank）。如果 'a' 为 '1'，使用 BSR 选择 GPR 银行（默认）。

如果 'a' 为 '0' 且启用了扩展指令集，当 f ≤ 95 (5Fh) 时，该指令以索引立即数偏移寻址模式操作。详见第 24.2.3 节“索引立即数偏移模式下的字节型和位型指令”。

- 字数：1
- 周期数：1

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 读取寄存器 'f' | 处理数据 | 写入目标 |

**示例 1：SUBWF REG, 1, 0**
指令执行前
REG = 3
W = 2
C = ?

指令执行后
REG = 1
W = 2
C = 1 ; 结果为正
Z = 0
N = 0

**示例 2：SUBWF REG, 0, 0**
指令执行前
REG = 2
W = 2
C = ?

指令执行后
REG = 2
W = 0
C = 1 ; 结果为零
Z = 1
N = 0

**示例 3：SUBWF REG, 1, 0**
指令执行前
REG = 1
W = 2
C = ?

指令执行后
REG = Fh ; (补码表示负数)
W = 2
C = 0 ; 结果为负
Z = 0
N = 1

## SUBWF 带借位 f 减 W

- 语法：`SUBWF f, {d, a}`
- 操作数：
  - `0 ≤ f ≤ 255`
  - `d = {0,1}`
  - `a = {0,1}`
- 操作：`(f) - (W) - (C) → dest`
- 影响的标志位：N、OV、C、DC、Z

**编码：**

| 位 15-8 | 位 7-0 |
| :--- | :--- |
| 0101 10da | ffff ffff |

**描述：**
寄存器 'f' 减去 W 和进位标志（借位）（补码法）。如果 'd' 为 '0'，结果存入 W。如果 'd' 为 '1'，结果存回寄存器 'f'（默认）。

如果 'a' 为 '0'，选择访问银行（Access Bank）。
如果 'a' 为 '1'，使用 BSR 选择 GPR 银行（默认）。

如果 'a' 为 '1' 且启用了扩展指令集，当 f ≤ 95 (5Fh) 时，该指令以索引立即数偏移寻址模式操作。详见第 24.2.3 节“索引立即数偏移模式下的字节型和位型指令”。

- 字数：1
- 周期数：1

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 读取寄存器 'f' | 处理数据 | 写入目标 |

**示例 1：SUBWF REG, 1, 0**
指令执行前
REG = 19h (0001 1001)
W = 1
C = 1

指令执行后
REG = 0Ch (0000 1100)
W = 1
C = 1
Z = 0
N = 0 ; 结果为正

**示例 2：SUBWF REG, 0, 0**
指令执行前
REG = 1Bh (0001 1011)
W = 1Ah (0001 1010)
C = 0

指令执行后
REG = 1Bh (0001 1011)
W = 0h
C = 1
Z = 1
N = 0 ; 结果为零

**示例 3：SUBWF REG, 1, 0**
指令执行前
REG = 03h (0000 0011)
W = 0Eh (0000 1110)
C = 1

指令执行后
REG = F5h (1111 0101) ; (补码)
C = 0
Z = 0
N = 1 ; 结果为负

## SWAPF 交换 f

- 语法：`SWAPF f, {d, a}`
- 操作数：
  - `0 ≤ f ≤ 255`
  - `d = {0,1}`
  - `a = {0,1}`
- 操作：
  - `(<3:0>) → dest<7:4>`
  - `(<7:4>) → dest<3:0>`
- 影响的标志位：无

**编码：**

| 位 15-8 | 位 7-0 |
| :--- | :--- |
| 0011 10da | ffff ffff |

**描述：**
寄存器 'f' 的高四位和低位互换。如果 'd' 为 '0'，结果存入 W。如果 'd' 为 '1'，结果存入寄存器 'f'（默认）。

如果 'a' 为 '0'，选择访问银行（Access Bank）。
如果 'a' 为 '1'，使用 BSR 选择 GPR 银行（默认）。

如果 'a' 为 '1' 且启用了扩展指令集，当 f ≤ 95 (5Fh) 时，该指令以索引立即数偏移寻址模式操作。详见第 24.2.3 节“索引立即数偏移模式下的字节型和位型指令”。

- 字数：1
- 周期数：1

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 读取寄存器 'f' | 处理数据 | 写入目标 |

## TBLRD 表读取

- **语法：** `TBLRD (*, +, -, +*)`
- **操作数：** 无
- **操作：**
  - 如果是 TBLRD * ，
    - (Prog Mem (TBLPTR)) → TABLAT
    - TBLPTR ← 不变
  - 如果是 TBLRD +* ，
    - (Prog Mem (TBLPTR)) → TABLAT
    - (TBLPTR) + 1 → TBLPTR
  - 如果是 TBLRD -* ，
    - (Prog Mem (TBLPTR)) → TABLAT
    - (TBLPTR) – 1 → TBLPTR
  - 如果是 TBLRD +* ，
    - (TBLPTR) + 1 → TBLPTR
    - (Prog Mem (TBLPTR)) → TABLAT
- **影响的标志位：** 无

![](img/5e76fd429fabd2b62e16a7bfd8cf546f_433_0.png)

**描述：**
此指令用于读取程序存储器（P.M.）的内容。为了寻址程序存储器，使用一个称为表指针（TBLPTR）的指针。

TBLPTR（一个 21 位指针）指向程序存储器中的每个字节。TBLPTR 具有 2-Mbyte 的地址范围。

- TBLPTR[0] = 0：程序存储器字的最低有效字节
- TBLPTR[0] = 1：程序存储器字的最高有效字节

TBLRD 指令可以按以下方式修改 TBLPTR 的值：
- 不变
- 后增量
- 后减量
- 前增量

- **字数：** 1
- **周期数：** 2

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 无操作 | 无操作 | 无操作 |
| 无操作 | 无操作（读取程序存储器） | 无操作 | 无操作（写入 TABLAT） |

**示例 1：**
指令执行前
TBLRD * + ;
TABLAT = 55h
TBLPTR = 00A356h
MEMORY (00A356h) = 34h

指令执行后
TABLAT = 34h
TBLPTR = 00A357h

**示例 2：**
指令执行前
TBLRD * + ;
TABLAT = AAh
TBLPTR = 01A357h
MEMORY (01A357h) = 12h
MEMORY (01A358h) = 34h

指令执行后
TABLAT = 34h
TBLPTR = 01A358h

## TBLWT 表写入

- **语法：** `TBLWT (*, +, -, ++, +*)`
- **操作数：** 无
- **操作：**
  - 如果是 TBLWT*;
    - (TABLAT) → 保持寄存器
    - TBLPTR → 不变
  - 如果是 TBLWT++;
    - (TABLAT) → 保持寄存器
    - (TBLPTR) + 1 → TBLPTR
  - 如果是 TBLWT-;
    - (TABLAT) → 保持寄存器
    - (TBLPTR) - 1 → TBLPTR
  - 如果是 TBLWT*+;
    - (TBLPTR) + 1 → TBLPTR
    - (TABLAT) → 保持寄存器
- **影响的标志位：** 无

**编码：**

| 位 15-8 | 位 7-0 |
| :--- | :--- |
| 0000 0000 | 0000 1rrn |

'n' 的图例：
- n:n = 0 *
- n:n = 1 ++
- n:n = 2 -
- n:n = 3 +*

**描述：**
此指令使用 TBLPTR 的低 3 位来决定将 TABLAT 写入 8 个保持寄存器中的哪一个。保持寄存器用于编程程序存储器（P.M.）的内容（关于编程 Flash 存储器的更多细节，请参见第 6.0 节“Flash 程序存储器”）。

TBLPTR（一个 21 位指针）指向程序存储器中的每个字节。TBLPTR 具有 2-Mbyte 的地址范围。TBLPTR 的最低有效位选择要访问的程序存储器位置的哪个字节。

- TBLPTR[0] = 0：程序存储器字的最低有效字节
- TBLPTR[0] = 1：程序存储器字的最高有效字节

TBLWT 指令可以按以下方式修改 TBLPTR 的值：
- 不变
- 后增量
- 后减量
- 前增量

- **字数：** 1
- **周期数：** 2

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 无操作 | 无操作 | 无操作 |
| 无操作 | 无操作（读取 TABLAT） | 无操作 | 无操作（写入保持寄存器） |

**示例 1：**
TBLWT ++;

指令执行前
TABLAT = 55h
TBLPTR = 00A356h
HOLDING REGISTER (00A356h) = FFh

指令执行后（表写入完成）
TABLAT = 55h
TBLPTR = 00A357h
HOLDING REGISTER (00A357h) = 55h

**示例 2：**
TBLWT * +;

指令执行前
TABLAT = 34h
TBLPTR = 01389Ah
HOLDING REGISTER (01389Ah) = FFh

指令执行后（表写入完成）
TABLAT = 34h
TBLPTR = 01389Bh
HOLDING REGISTER (01389Bh) = FFh
HOLDING REGISTER (01389Bh) = 34h
