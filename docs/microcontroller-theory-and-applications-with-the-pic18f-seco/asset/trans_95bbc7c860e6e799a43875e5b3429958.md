

**MOV**LW data8 (**MOV**LW 0x25) 将 8 位立即数（常量数据）移入 WREG。例如，**MOV**LW 0x25 会将 25H 移入 WREG 寄存器。WREG 之前的内容将丢失。

**MOV**FF F, a (**MOV**F 0x40) 将数据从 WREG 移入数据寄存器 F。如果 a = 0，则 F 位于访问 bank；如果 a = 1，则 F 位于由 **BSR** 指定的 bank 中。作为一个示例，考虑 **MOV**F 0x40。

执行 **MOV**F 0x40 之前：[0x40] = FIH, [**WREG**] = 53H

执行 **MOV**F 0x40 之后：[0x40] = 53H, [**WREG**] = 53H（不变）

**MOV**FF Fs, Fd (**MOV**FF 0x04, 0x03) 将数据从源数据寄存器 Fs 移入目标数据寄存器 Fd。WREG 可以作为 Fs 或 Fd 使用。此外，Fs 和 Fd 可以是 000H 到 FFFH 之间的任何数据内存位置。这是一条双字（32 位）指令。作为一个示例，考虑 **MOV**FF 0x04, 0x03。

执行 **MOV**FF 0x04, 0x03 之前：[0x03] = 2FH, [0x04] = 57H

执行 **MOV**FF 0x04, 0x03 之后：[0x03] = 57H, [0x04] = 57H（不变）

**MOV**F F, d, a (**MOV**F 0x30, **W** 或 **MOV**F 0x30, F) 将数据寄存器 F 的内容移入 WREG（d = 0）或移入同一个数据寄存器 F（d = 1）。如果 a = 0，则 F 位于访问 bank；如果 a = 1，则 F 位于由 BSR 指定的 bank 中。

作为一个示例，考虑 **MOV**F 0x30, W。

执行 **MOV**F 0x30, W 之前：[WREG] = 70H, [0x30] = 2AH

执行 **MOV**F 0x30, W 之后：[WREG] = 2AH, [0x30] = 2AH（不变）

另一个示例，考虑 **MOV**F 0x30, F。

执行 **MOV**F 0x30, F 之前：[WREG] = 70H, [0x30] = 2AH

执行 **MOV**F 0x30, F 之后：[WREG] = 70H, [0x30] = 2AH（不变）。这与 NOP（空操作指令）相同，可用于时间延迟。

**SET**F F, a (**SET**F 0x20) 将指定数据寄存器（F）的内容设置为 FFH。如果 a = 0，则数据寄存器位于访问 bank；如果 a = 1，则 BSR 的内容指定 bank 的地址。作为一个示例，考虑 **SET**F 0x20。

执行 **SET**F 0x20 之前：[0x20] = 24H

执行 **SET**F 0x20 之后：[0x20] = FFH

**SET**F 指令可用于配置 I/O 端口。例如，PIC18F 中的 **TRISB** 寄存器用于配置端口 B。向 **TRISB** 的全部 8 位写入 1 可以将端口 B 配置为输入端口。这可以使用 **SET**F **TRISB** 指令来完成。这个话题稍后讨论。

**SWAP**F F, d, a (**SWAP**F 0x60, **W** 或 **SWAP**F 0x60, F) 交换文件寄存器 F 的低 4 位和高 4 位。如果 a = 0，则 F 位于访问 bank；如果 a = 1，则 F 位于由 BSR 指定的 bank 中。d = 0 表示目标是 WREG，而 d = 1 表示目标是文件寄存器。

作为一个示例，考虑 SWAPF 0x60, W。

执行指令 SWAPF 0x60, W 之前：[0x60] = 48H, [WREG] = 50H。

执行指令 SWAPF 0x60, W 之后：[0x60] = 48H, [WREG] = 84H。

另一个示例，考虑 SWAPF 0x60, F。

执行指令 SWAPF 0x60, F 之前：[0x60] = 48H, [WREG] = 50H。

执行指令 SWAPF 0x60, F 之后：[0x60]=84H, [WREG] = 50H。

## 示例 6.2

找出以下 PIC18F 指令序列中受影响的 FSR、WREG 和数据寄存器内容：

```text
        LFSR        2,0x0044
        MOVLW       D'20'
        MOVWF       0x40
        MOVFF       PLUSW2, 0x40
        CLRF        POSTINC2
        SETF        0x40
```

假设在执行指令序列之前 [0x58] = 1AH。

**解答**

执行 LFSR 2,0x0044 后，文件选择寄存器 FSR2 被加载为 0044H。MOVLW D'20' 将十进制立即数 20 (14H) 移入 WREG。指令 MOVWF 0x40 将 [WREG] 移入数据寄存器 0x40。因此，[0x40] = 14H。

MOVFF PLUSW2, 0x40 将 [WREG] 与 [FSR2] 相加，然后将该地址的字节内容移入数据寄存器 0x40。这意味着数据寄存器 0x58 的内容被移入 WREG。因此，[0x40] = 1AH。

CLRF POSTINC2 将数据寄存器 0x44 的内容清零，然后将 FSR2 加 1。因此，[0x44] = 00H，且 [FSR2] = 0x45。

SETF 0x40 将数据寄存器 0x40 的所有位设置为 1。因此，[0x40] = FFH。

### 6.3.2 算术指令

PIC18F 的算术指令允许：

- 8 位加法和减法
- 8 位乘以 8 位无符号乘法。PIC18F 不提供任何有符号乘法和除法（有符号和无符号）指令。
- 取反指令
- 减一和加一指令
- BCD 调整（BCD 校正）

正如之前提到的，典型的微控制器利用通用硬件来执行无符号和有符号数字的加法和减法运算。微控制器的指令集包括用于无符号和有符号数字的相同 ADD 和 SUBTRACT 指令。无符号和有符号 ADD 和 SUBTRACT 操作的解释由程序员完成。

无符号和有符号乘法与除法操作可以使用各种算法执行。像 Pentium 这样的典型 32 位微处理器包含用于执行这些乘法和除法操作的单独指令。PIC18F 仅提供无符号乘法指令。其他乘法和除法指令可以通过编写使用适当算法的 PIC18F 汇编语言程序来获得。这在第 7 章中展示。

PIC18F 的算术指令总结见表 6.6。接下来，我们将使用访问 bank 并指定 F 或 W 来代替 'd'，以此解释算术指令。

- 表 6.6 中的所有指令都在一个周期内执行。
- 每条指令的大小为一个字。
- a = 0 表示数据寄存器位于访问 bank，而 a = 1 表示 BSR 的内容指定 bank 的地址。
- 对于目标：d = 0 表示目标是 WREG，而 d = 1 表示目标是文件寄存器。如前所述，为了更清晰，本书将使用 W 或 F 代替 0 或 1。
- PIC18F 不提供任何乘法（有符号）和除法（有符号和无符号）指令。

**加法和减法指令** PIC18F 的加法和减法指令通过以下数值示例进行说明。所有标志都受影响。假设有符号数。

**ADDLW data8 (ADDLW 0x02) 指令将 WREG 的 8 位内容与 8 位立即数数据相加，并将结果存储在 WREG 中。例如，考虑 ADDLW 0x02。**

执行 ADDLW 0x02 之前：[WREG] = 12H。
执行 ADDLW 0x02 之后：[WREG] = 12H + 02H = 14H。
标志根据结果受影响如下：

```text
Previous carry → 0000 010 Intermediated Carries
[WREG]= 12H = 0001 0010
Add immediate data, 02H = 0000 0010
-----------------
final carry → 0 0001 0100 = 14H
```
