**Timer0 block diagrams** Figure 10.3 and Figure 10.4 show the simplified block diagrams of the Timer0 module in 8-bit and 16-bit modes respectively. Figure 10.3 TOSE (bit 4 of TOCON register of Figure 10.2) is Exclusive-ORed with the TCK1 clock pin of the PIC18F4321. The output of the Exclusive-OR gate is selected by TOCS (bit 5 of TOCON of Figure 10.2). When TOCS is 0, the internal oscillator (Fosc/4) is used (TOCS=0), and the Timer0 operates as a timer; otherwise, the external clock is selected (TOCS=1) and the Timer0 operates as a counter. The Timer0 bypasses the prescaler if PSA (bit 3 of TOCON register of Figure 10.2) is 1; otherwise, the prescaler is selected (PSA = 0), and is specified by TOPS2:TOPS0 (TOCON of Figure 10.2). The next block provides a two cycle (Tosc) delay. This is because when control data is written to TOCON register, the increment operation is inhibited for the following two instruction cycles. The user can work around this by writing an adjusted value to the timer register called TMRO. Example 10.1 illustrates this.

An interrupt on overflow indicated by TMROIF (bit 2 of INTCON register in Figure 9.7) is set to one if the TMROL rolls over from 0xFF to 0x00.
