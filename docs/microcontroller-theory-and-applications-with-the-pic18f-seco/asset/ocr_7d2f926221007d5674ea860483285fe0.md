7.19 Consider the following loop statement in C language ;

for (p = 80; p > 0; p--); // a dummy loop with no statement

The above C loop can be represented using PIC18F assembly language in two ways:

# Method 1: Using conventional way

```
MOVWF 0x50
MOVWF P
LOOP DEC F P, F
BNZ LOOP
```

# Method 2: Using SKIP instruction

```
MOVWF 0x50
MOVWF P
LOOP DECFSZ P, F
BRA LOOP
DONE ------
```

Assume 1 MHz PIC18F clock. Calculate the execution time of each delay loop (Method 1 and Method 2). Which delay loop will be executed faster?
