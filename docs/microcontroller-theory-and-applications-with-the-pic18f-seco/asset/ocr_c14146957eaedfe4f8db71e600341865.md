# Chapter 10

10.1 Bit 7: Set to 0 so that TMR0 is off
Bit 6: Set to 1 in order to enable the 8-bit mode of TMR0
Bit 5: Set to 1 so that an external crystal oscillator can be used
Bit 4: Set to 1 so the timer will increment when the clock is going from high to low (negative edge).
Bit 3: Set to 0 in order to enable the prescaler function
Bit 2-0: Set to 011 to enable a 1:16 prescaler
Hence, T0CON=0x73

```
10.2 (b)
#include <p18f4321.h>
void main(void)
{
   OSCCON = 0x60;       // 4 MHz internal clock
   TRISC=0x00;          // PortC is output
   T0CON=0x08;         // Timer0 is 16-bit no prescaler
   TMR0L=0xA0;         // Value placed in lower 8 bits of TMR0
   TMR0H=0x0F;         // Value placed in upper 8-bits of TMR0
   INTCONbits.TMR0IF=0; // Clear TMR0 flag
   T0CONbits.TMR0ON=1; // Turn on TMR0
   while(1)
   {
     while(INTCONbits.TMR0IF==0);
     T0CONbits.TMR0ON=0;  // Turn off TMR0
     PORTCbits.RC0=~PORTCbits.RC0; // Change output of square wave
     TMR0L=0xA0;         // Value placed in lower 8 bits of TMR0
     TMR0H=0x0F;         // Value placed in upper 8-bits of TMR0
     INTCONbits.TMR0IF=0; // Clear TMR0 flag
     T0CONbits.TMR0ON=1;  // Turn on TMR0
   }
}
```
