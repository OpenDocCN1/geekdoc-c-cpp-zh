

## CLRF

清除 f

**语法：** CLRF f{,a}
**操作数：**
- 0 <= f <= 255
- a ∈ [0,1]

**操作：**
- 000h → f
- 1 → Z

**受影响的标志位：** Z

**编码：**
```text
0110 101a ffff ffff
```

**描述：** 清除指定寄存器的内容。
如果 'a' 为 '0'，则选择访问银行（Access Bank）。
如果 'a' 为 '1'，则使用 BSR 选择 GPR 银行（默认）。
如果 'a' 为 '1' 且启用了扩展指令集，当 f <= 95 (5Fh) 时，此指令在索引字面量偏移寻址模式下工作。详情参见**第 24.2.3 节 “索引字面量偏移模式下的字节导向和位导向指令”**。

**字数：** 1
**周期：** 1

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 译码 | 读取寄存器 'f' | 处理数据 | 写入寄存器 'f' |

**示例：**
`CLRF FLAG_REG, 1`

指令前： FLAG_REG = 5Ah
指令后： FLAG_REG = 00h

## CLRWDT

清除看门狗定时器

**语法：** CLRWDT
**操作数：** 无

**操作：**
- 000h → WDT,
- 000h → WDT 后分频器,
- 1 → TO,
- 1 → PD

**受影响的标志位：** TO, PD

**编码：**
```text
0000 0000 0000 0100
```

**描述：** CLRWDT 指令复位看门狗定时器。它还复位 WDT 的后分频器。状态位 TO 和 PD 被置位。

**字数：** 1
**周期：** 1

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 译码 | 无操作 | 处理数据 | 无操作 |

**示例：**
`CLRWDT`

指令前：
WDT 计数器 = ?
指令后：
WDT 计数器 = 00h
WDT 后分频器 = 0
TO = 1
PD = 1

## COMF

f 取反

**语法：**
`COMF f {d, a}`

**操作数：**
- 0 ≤ f ≤ 255
- d ∈ {0,1}
- a ∈ {0,1}
- (*f*) → *dest*

**操作：**
(*f*) → *dest*

**受影响的标志位：** N, Z

**编码：**
| 0001 | 11da | efff | ffff |
| :--- | :--- | :--- | :--- |

**描述：** 寄存器 *f* 的内容被取反。如果 *d* 为 '0'，结果存储在 W 中。如果 *d* 为 '1'，结果存储回寄存器 *f*（默认）。
如果 *a* 为 '0'，则选择访问银行。
如果 *a* 为 '1'，则使用 BSR 选择 GPR 银行（默认）。
如果 *a* 为 '0' 且启用了扩展指令集，当 *f* ≤ 95 (5Fh) 时，此指令在索引字面量偏移寻址模式下工作。详情参见第 24.2.3 节 “索引字面量偏移模式下的字节导向和位导向指令”。

**字数：** 1
**周期：** 1

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 译码 | 读取寄存器 *f* | 处理数据 | 写入目标 |

**示例：**
`COMF REG, 0, 0`

指令前：
REG = 13h
指令后：
REG = 13h
W = ECh

## CPFSEQ

比较 f 与 W，若 f = W 则跳过

**语法：**
`CPFSEQ f (a)`

**操作数：**
- 0 ≤ f ≤ 255
- a ∈ {0,1}
- (f) - (W)
- 若 (f) = (W) 则跳过
- (无符号比较)

**操作：**
- (f) - (W)
- 若 (f) = (W) 则跳过
- (无符号比较)

**受影响的标志位：** 无

**编码：**
| 0110 | 001a | ffff | ffff |
| :--- | :--- | :--- | :--- |

**描述：** 通过执行无符号减法，将数据存储器位置 *f* 的内容与 W 的内容进行比较。
如果 *f* = W，则取到的指令被丢弃，并执行 NOP 代替，使该指令变为双周期指令。
如果 *a* 为 '0'，则选择访问银行。
如果 *a* 为 '1'，则使用 BSR 选择 GPR 银行（默认）。
如果 *a* 为 '0' 且启用了扩展指令集，当 *f* ≤ 95 (5Fh) 时，此指令在索引字面量偏移寻址模式下工作。详情参见第 24.2.3 节 “索引字面量偏移模式下的字节导向和位导向指令”。

**字数：** 1
**周期：** 1(2)
**注意：** 如果跳过且后续跟随双字指令，则为 3 个周期。

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 译码 | 读取寄存器 *f* | 处理数据 | 无操作 |

如果跳过：

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 无操作 | 无操作 | 无操作 | 无操作 |
| | Q2 | Q4 | |
| | 无操作 | 无操作 | |
| | 无操作 | 无操作 | |

如果跳过且后续跟随双字指令：

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 无操作 | 无操作 | 无操作 | 无操作 |
| 无操作 | 无操作 | 无操作 | 无操作 |

**示例：**
```text
HERE   CPFSEQ REG, 0
NEQUAL ;
EQUAL  ;
```

指令前：
PC 地址 = HERE
W = ?
REG = ?
指令后：
若 REG = W; PC = 地址 (EQUAL)
若 REG ≠ W; PC = 地址 (NEQUAL)

`CPFSGT f, a`

**操作数：**
- 0 ≤ f ≤ 255
- a ∈ [0,1]

**操作：**
- (f) – (W),
- 若 (f) > (W) 则跳过
- (无符号比较)

**受影响的标志位：** 无

**编码：**
```text
0110 010a ffff ffff
```

**描述：** 通过执行无符号减法，将数据存储器位置 'f' 的内容与 W 的内容进行比较。如果 'f' 的内容大于 WREG 的内容，则取到的指令被丢弃，并执行 NOP 代替，使该指令变为双周期指令。

**字数：** 1
