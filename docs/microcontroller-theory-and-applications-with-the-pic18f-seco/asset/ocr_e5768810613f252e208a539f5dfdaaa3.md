In the above, the following loop for the 2 ms delay is used:

```
LOOP1   MOVLW   D'255'  ; LOOP2 provides 2 ms delay with a count of 255
         MOVWF   0x21
LOOP2   DECFSZ  0X21
         GOTO    LOOP2
```

For a 1-MHz default crystal frequency, the PIC18F clock period will be $\mu\sec$. Hence, each instruction cycle will be 4 microseconds. For 2 ms delay, total cycles = (2 ms)/(4 μsec) = 500. The DECFSZ in the loop will require 2 cycles for (COUNT − 1) times when Z = 0 and the last iteration will take 1 cycle when skip is taken (Z = 1). Hence, the value of count will approximately be 255 (decimal) discarding execution times of certain instructions. Therefore, register 0x21 should be loaded with an integer value of 255 for an approximate delay of 2 ms.
