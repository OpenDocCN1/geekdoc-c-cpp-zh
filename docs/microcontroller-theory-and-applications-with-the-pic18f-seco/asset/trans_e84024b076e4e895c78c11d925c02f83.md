
## NEGF 取反 *f*

**语法：**
NEGF f{(,a)}

**操作数：**
0 ≤ *f* ≤ 255
a ∈ [0,1]

**操作：**
~(*f*) + 1 → *f*

**受影响的状态位：**
N, OV, C, DC, Z

**编码：**
| 0110 | 110a | *ffff* | *ffff* |

**描述：**
位置 *f* 使用补码进行取反。结果存放在数据存储位置 *f*。
如果 ‘*a*’ 为 ‘0’，则选择访问银行（Access Bank）。
如果 ‘*a*’ 为 ‘1’，则使用 BSR 选择 GPR 银行（默认）。
如果 ‘*a*’ 为 ‘0’ 且启用了扩展指令集，则只要 *f* ≤ 95 (5Fh)，该指令即以索引字面量偏移寻址模式操作。详情请参见 **第 24.2.3 节 “索引字面量偏移模式下的字节导向和位导向指令”**。

**字数：**
1

**周期数：**
1

**Q 周期活动：**
| Q1 | Q2 | Q3 | Q4 |
|----|----|----|----|
| 解码 | 读取寄存器 ‘f’ | 处理数据 | 写入寄存器 ‘f’ |

**示例：**
```text
NEGF REG, 1
指令执行前
REG = 0011 1010 [3Ah]
指令执行后
REG = 1100 0110 [C6h]
```

## POP 弹出返回栈顶

**语法：**
POP

**操作数：**
无

**操作：**
(TOS) → bit bucket（丢弃）

**受影响的状态位：**
无

**编码：**
0000, 0000, 0000, 0110

**描述：**
将 TOS 值从返回栈中弹出并丢弃。随后 TOS 值变为之前压入返回栈的值。此指令旨在让用户能够正确管理返回栈，以纳入软件栈。

**字数：**
1

**周期数：**
1

**Q 周期活动：**
| **Q1** | **Q2** | **Q3** | **Q4** |
|:---:|:---:|:---:|:---:|
| 解码 | 无操作 | 弹出 TOS 值 | 无操作 |

**示例：**
```text
指令执行前
POP GOTO NEW
TOS = 0031A2h
栈 (下一层) = 014332h

指令执行后
PUSH GOTO NEW
TOS = 345Ah
PC = 0124h
PC = 0126h
TOS = 0126h
栈 (下一层) = 345Ah
```

## PUSH 压入返回栈顶

**语法：**
PUSH

**操作数：**
无

**操作：**
(PC + 2) → TOS

**受影响的状态位：**
无

**编码：**
0000, 0000, 0000, 0101

**描述：**
将 PC + 2 压入返回栈顶。之前的 TOS 值被向下推入栈中。此指令允许通过修改 TOS 并将其压入返回栈来实现软件栈。

**字数：**
1

**周期数：**
1

**Q 周期活动：**
| **Q1** | **Q2** | **Q3** | **Q4** |
|:---:|:---:|:---:|:---:|
| 解码 | 将 PC + 2 压入返回栈 | 无操作 | 无操作 |

## RCALL 相对调用

**语法：**
RCALL n

**操作数：**
-1024 ≤ n ≤ 1023

**操作：**
(PC) + 2 → TOS,
(PC) + 2 + 2n → PC

**受影响的状态位：**
无

**编码：**
| 1101 | nnnn | nnnn | nnnn |

**描述：**
子程序调用，跳转距离当前位置可达 1K。首先，将返回地址 (PC + 2) 压入栈中。然后，将二进制补码数 ‘2n’ 加到 PC 上。由于 PC 会递增以获取下一条指令，因此新地址将是 PC + 2 + 2n。这是一条双周期指令。

**字数：**
1

**周期数：**
2

**Q 周期活动：**
| Q1 | Q2 | Q3 | Q4 |
|---|---|---|---|
| 解码 | 读取字面量 ‘n’ 将 PC 压入栈 | 处理数据 | 写入 PC |
| 无操作 | 无操作 | 无操作 | 无操作 |

**示例：**
```text
HERE RCALL Jump

指令执行前
   PC = Address (HERE)

指令执行后
   PC = Address (Jump)
   TOS = Address (HERE + 2)
```

## RETFIE 从中断返回

**语法：**
RETFIE (s)

**操作数：**
s ∈ {0,1}

**操作：**
(TOS) → PC,
如果 s = 1，则 1 → GIE/GIEH 或 PIE/GIEL
(WS) → W,
(STATUS) → STATUS,
(BSRs) → BSR,
PCLATU, PCLATH 保持不变

**受影响的状态位：**
GIE/GIEH, PIE/GIEL

**编码：**
0000 0000 0001 000s

**描述：**
从中断返回。弹出栈并将栈顶 (TOS) 加载到 PC 中。通过设置高优先级或低优先级全局中断使能位来启用中断。如果 s = 1，则阴影寄存器 WS、STATUS 和 BSRs 的内容被加载到其对应的寄存器 W、STATUS 和 BSR 中。如果 s = 0，则不更新这些寄存器（默认）。

**字数：**
1

**周期数：**
2

**Q 周期活动：**
| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 无操作 | 无操作 | 从栈中弹出 PC，设置 GIEH 或 GIEL |
| 无操作 | 无操作 | 无操作 | 无操作 |

**示例：**
```text
RETFIE 1

中断返回后
PC = TOS
W = WS
BSR = BSRs
STATUS = STATUS
GIE/GIEH, PIE/GIEL = 1
```

## RETLW 返回字面量到 W

**语法：**
RETLW k

**操作数：**
0 ≤ k ≤ 255

**操作：**
k → W,
(TOS) → PC,
PCLATU, PCLATH 保持不变

**受影响的状态位：**
无

**编码：**
1100 kkkk kkkk

**描述：**
将八位字面量 'k' 加载到 W 中。程序计数器从栈顶（返回地址）加载。高位地址锁存器 (PCLATH) 保持不变。

**字数：**
1

**周期数：**
2

**Q 周期活动：**
| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 读取字面量 'k' | 处理数据 | 从栈中弹出 PC，写入 W |
| 无操作 | 无操作 | 无操作 | 无操作 |

**示例：**
```text
CALL TABLE ; W 包含表偏移值
              ; 表值
:
TABLE
ADWF PCL ; W = 偏移量
RETLW k0 ; 表开始
RETLW k1
:
:
RETLW kn ; 表结束

指令执行前 W = 07h
指令执行后 W = kn 的值
```

## RETURN 从子程序返回

**语法：**
RETURN (s)

**操作数：**
s ∈ [0,1]

**操作：**
(TOS) → PC,
如果 s = 1
(W) → W,
(STATUSs) → STATUS,
(BSRs) → BSR,
PCLATU, PCLATH 保持不变

**受影响的状态位：**
无

**编码：**
| `0000` | `0000` | `0001` | `001s` |

**描述：**
从子程序返回。弹出栈并将栈顶 (TOS) 加载到程序计数器中。如果 's'=1，则阴影寄存器 WS、STATUSs 和 BSRs 的内容被加载到其对应的寄存器 W、STATUS 和 BSR 中。如果 's'=0，则不更新这些寄存器（默认）。

**字数：**
1

**周期数：**
2

**Q 周期活动：**
| Q1 | Q2 | Q3 | Q4 |
| --- | --- | --- | --- |
| 解码 | 无操作 | 处理数据 | 从栈中弹出 PC |
| 无操作 | 无操作 | 无操作 | 无操作 |

**示例：**
```text
RETURN

指令执行后
PC = TOS
```

## RLCF 携带进位左移 *f*

**语法：**
RLCF (f,{d},{a})

**操作数：**
0≤f≤255
d ∈ [0,1]
a ∈ [0,1]

**操作：**
(f<->n) → dest<n + 1>,
(f<0>) → C,
(C) → dest<0>

**受影响的状态位：**
C, N, Z

**编码：**
| `0011` | `01da` | `ffff` | `ffff` |

**描述：**
寄存器 'f' 的内容通过进位标志位向左旋转一位。如果 'd' 为 '0'，结果放置在 W 中；如果 'd' 为 '1'，结果存储回寄存器 'f' 中（默认）。
如果 'a' 为 '0'，选择访问银行。如果 'a' 为 '1'，使用 BSR 选择 GPR 银行（默认）。如果 'a' 为 '1' 且启用了扩展指令集，则只要 f = 95 (5Fh)，该指令即以索引字面量偏移寻址模式操作。详情请参见 *第 24.2.3 节 “索引字面量偏移模式下的字节导向和位导向指令”*。

![](img/5e76fd429fabd2b62e16a7bfd8cf546f_426_0.png)

**字数：**
1

**周期数：**
1

**Q 周期活动：**
| Q1 | Q2 | Q3 | Q4 |
| --- | --- | --- | --- |
| 解码 | 读取寄存器 'f' | 处理数据 | 写入目标 |

**示例：**
```text
RLCF REG, 0, 0

指令执行前
REG = 1110 0110
C = 0

指令执行后
REG = 1110 0110
W = 1100 1100
C = 1
```
