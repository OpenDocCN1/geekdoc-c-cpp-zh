## 11.1.5 PIC18F4321 PWM (脉宽调制) 模式

在脉宽调制（PWM）模式下，CCPx引脚可以被配置为输出，以生成具有指定频率和10位（8位整数部分和2位小数部分）占空比的周期性波形。PWM占空比通过向CCPRxL寄存器写入高八位（整数部分）以及CCPxCON寄存器的低两位（小数部分）（第5位和第4位）来指定。Timer2用于PWM模式。PWM周期通过向CCP模块中的8位PR2寄存器写入值来指定。

根据PIC18F4321数据手册，PWM周期可以使用以下公式计算：

```
PWM Period = [(PR2 + 1) x 4 x Tosc x (TMR2 Prescale Value)]
where Tosc = (1/Fosc), Fosc is the crystal frequency, TMR2 Prescale Value can be initialized as 1, 4, or 16 using the T2CON register.
Hence, PR2 = [(Fosc)/(4 x Fpwm x TMR2 Prescale Value)] - 1
Note that PWM frequency (Fpwm) is defined as 1/(PWM period).
```

以下方程用于计算以时间为单位的PWM占空比：

```
PWM Duty Cycle = ((CCPxL.CCPxCON <5:4>) x Tosc x (TMR2 Prescale Value)).
```

如前所述，占空比定义为脉冲在高电平期间占一个时钟周期的百分比。此外，CCPRxL中的高八位是占空比的十进制部分，而CCPxCON寄存器的第5位和第4位包含占空比的小数部分。例如，考虑一个25%的占空比。由于占空比是PR2寄存器值的一个分数，当PR2值为30时，占空比的十进制值为7.5（0.25 x 30）。因此，必须将8位二进制数00000111加载到CCPRL中，并且必须将2位二进制数10（十进制0.5）加载到CCPxCON寄存器中的DCxB1和DCxB0位（图11.1）。这将把占空比7.5分配给要在CCPx引脚生成的PWM波形。

CCP1 PWM输出波形（使用CCP1L:CCP1CON寄存器指定的占空比）的生成方式如下：CCPR1L被复制到CCPR1H。CCP1CON <5:4> 中的两位在内部锁存，以提供10位占空比。同样，8位TMR2值与两位内部锁存值拼接以创建10位占空比。

在TMR2从0启动后，CCP1引脚变为高电平，指示周期开始。CCP1H和两位锁存值与TMR2和两位锁存值进行比较以匹配。一旦匹配发生，CCP1引脚变为低电平。此时，波形将以占空比指定的持续时间保持高电平。TMR2继续递增。一旦TMR2的内容与PR2匹配，CCP1引脚被驱动为高电平，并且TMR2被清零为0。这完成了一个周期，然后开始另一个周期。对于后续周期，相同的过程持续进行。这在图11.2中有所描绘。

当配置CCP模块进行PWM操作时，应遵循以下程序：

- 1. 应使用PWM周期初始化PR2寄存器。
- 2. 通过向CCP1xL寄存器写入8位整数值，并向CCP1xCON的第5、4位写入两位小数部分来加载PWM占空比（图11.1）。此外，通过编程CCP1xCON寄存器来禁用PWM模式。
- 3. 通过清除相应的TRISCx位将CCP1x引脚配置为输出。
- 4. 选择Timer2预分频值，然后通过对T2CON写入来启用Timer2。
- 5. 通过向CCP1xCON寄存器写入适当的数据来启用PWM模式。
- 6. 将TMR2寄存器初始化为0。
- 7. 通过向T2CON寄存器写入适当的数据来打开Timer2。
- 8. 将PIR1寄存器中的TMR2IF标志（图10.8）清零为0。
- 9. 在循环中等待TMR2IF标志变高。一旦TMR2IF变高，将在CCP1x引脚生成具有指定占空比的PWM波形。
- 10. 这将完成一个周期。

可以通过轮询PIR1寄存器中的TMR2IF（图10.8）来生成PWM波形。下面的PIC18F汇编语言指令序列和C代码将通过将TMR2IF清零为0，打开TMR2，然后在循环中等待TMR2IF位变高（指示周期完成）来轮询PIR1寄存器中的TMR2IF标志位：

![](img/5e76fd429fabd2b62e16a7bfd8cf546f_338_0.png)

在PIC18F汇编中：

```
REPEAT: BCF             PIR1,TMR2IF   ; Clear TMR2IF flag to 0
BACK:   BSF             T2CON,TMR2ON  ; Turn Timer2 ON
        BTFS          PIR1,TMR2IF   ; wait until completion of a cycle
        GOTO    BACK
        GOTO    REPEAT              ; Repeat
```

在C中：

```
PIR1bits.TMR2IF=0;              // Clear TMR2IF flag to 0
T2CONbits.TMR2ON=1;             // Turn Timer2 ON
while(PIR1bits.TMR2IF==0);      // Wait until TMR2IF = 1
```

## 示例 11.4

- (a)
在地址0x100处编写一个PIC18F汇编语言程序，在PIC18F4321的CCP1引脚上生成4 KHz、50%占空比的PWM。假设4 MHz晶振。

- (b)
编写一个C语言程序，在PIC18F4321的CCP1引脚上生成4 KHz、50%占空比的PWM。假设4 MHz晶振。

### 解答

PR2 = [(Fosc)/(4 x Fpwm x TMR2 Prescale Value)] - 1
PR2 = [(4 MHz)/(4 x 4 KHz x 1)] - 1 假设预分频值为1
PR2 = 249。具有50%占空比 = 0.5 x 249 = 124.5。因此，CCPRL寄存器将加载124，而CCP1CON寄存器中的位DC1B1:DC0B0将加载10（二进制）。

- (a)
PIC18F汇编语言程序如下所示：

```
INCLUDE       <PIC18F4321.INC>
ORG           0x100
MOVLW         0x60                ; 4MHz internal clock
MOVWF         OSCCON
MOVLW         D'249'              ; Initialize PR2 register
MOVWF         PR2
MOVLW         D'124'              ; Initialize CCPRL
MOVWF         CCPRL
MOVLW         0x20                ; CCP1 OFF,
MOVWF         CCP1CON             ; DC1B1:DC0B0=10
BCF           TRISC.CCP1          ; Configure CCP1 pin as output
CLRF          T2CON               ; 1:1 prescale, Timer2 OFF, no postscale
MOVLW         0x2C                ; PWM mode
MOVWF         CCP1CON
CLRF          TMR2                ; Clear Timer2 to 0
BACK:     BCF           PIR1,TMR2IF       ; Clear TMR2IF to 0
BSF           T2CON,TMR2ON        ; Turn Timer2 ON
WAIT:     BTFS          PIR1,TMR2IF       ; Wait until TMR2IF is HIGH
GOTO          WAIT
BRA           BACK
END
```

在上面的程序中，TMR2的值在每个时钟周期与周期寄存器PR2进行比较。当两个值匹配时，比较器生成一个匹配信号作为定时器输出。该信号还在下一个周期将TMR2的值复位为0x00。在上面的程序中，最后一条指令BRA BACK分支到标签处，将PIR1中的TMR2IF标志清零为0。由于TMR2在每次匹配后会自动清零，因此程序无需返回将TMR2清零。

- (b)
C语言程序如下所示：

```
#include<p18f4321.h>
void main(void)
{
    OSCTCON =0x60; // 4MHz internal clock
    PR2=249; // Initialize PR2 register
    CCPRL=124; // Initialize CCPRL
    CCP1CON=0x20; // CCP1 OFF, DC1B1:DC0B0=10
    TRISCBits.TRISC2=0; // Configure CCP1 pin as output
    T2CON =0; // 1:1 prescale, Timer2 OFF, no postscale
    CCP1CON=0x2C; // PWM mode
    TMR2=0; // Clear Timer2 to 0

    while(1)
    {
        PIR1bits.TMR2IF=0; // Clear TMR2IF to 0
        T2CONbits.TMR2ON=1; // Turn Timer2 ON
        while(PIR1bits.TMR2IF==0); // Wait until TMR2IF is HIGH
    }
}
```

## 11.2 直流电机控制

如前所述，PWM信号的占空比与PWM提供的平均电压和功率成正比。由于这一特性，PWM模式可用于调光LED和控制无刷直流电机的速度等应用。这意味着随着PWM占空比的增加，LED会更亮。同样，随着PWM占空比的增加，直流电机的速度也会增加。另一方面，随着PWM占空比降低，LED会变暗，而电机的转速也会变慢。

在早期，电压调节器电路被用于控制直流电机的速度。但是，电压调节器会消耗大量功率。因此，使用处于PWM模式的PIC18F来控制直流电机的速度。在这种方案中，通过开和关施加到电机的驱动电压，功率耗散显著减少。

有时，希望改变直流电机的旋转方向。这可以通过软件反转电机方向，并将称为H桥（H-Bridge）的设备连接到PIC18F的I/O端口来实现。注意，另一方面，电机的速度可以使用PWM模式并通过将直流电机连接到PIC18F4321的CCP1引脚来控制。使用PIC18F4321的PWM模式进行直流电机控制的基本概念将在示例11.5中进行说明。
