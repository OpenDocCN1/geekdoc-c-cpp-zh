
同样地，在16位模式下，Timer0启动后，TMR0H:TMR0L寄存器对会进行加计数，直到TMR0H:TMR0L在16位定时器模式下达到0xFFFF。当TMR0H:TMR0L从0xFFFF回卷（溢出）至0x0000时，INTCON寄存器中的TMR0IF（溢出中断）标志位会被置为1。在8位或16位模式下，都可以通过清除TMR0ON（图10.2中TOCON寄存器的第7位）为0来停止定时器，使用PIC18F汇编指令“BCF TOCON, TMOON”或C代码“TOCONbits.TMR0ON =0;”。图10.2中显示的TOCON寄存器控制Timer0操作的所有方面，包括预分频选择。Timer0既可读也可写。

### 作为计数器的Timer0

通过将T0CS位（图10.2中TOCON寄存器的第5位）置为1，可将Timer0配置为计数器。这将允许PIC18F4321使用连接到T0CKI引脚的外部时钟。此时，可以将TOSE位（TOCON寄存器的第4位）清零，以便在时钟上升沿时递增Timer0寄存器；或者将其置为1，以便在时钟下降沿时递增Timer0寄存器。

![](img/5e76fd429fabd2b62e16a7bfd8cf546f_285_0.png)

- 第7位 **TMR0ON**：Timer0 开关控制位
  - 1 = 启用Timer0
  - 0 = 停止Timer0
- 第6位 **T08BIT**：Timer0 8位/16位控制位
  - 1 = Timer0被配置为8位定时器/计数器
  - 0 = Timer0被配置为16位定时器/计数器
- 第5位 **T0CS**：Timer0 时钟源选择位
  - 1 = 连接至RA4/T0CKI引脚的外部时钟（引脚6；Timer0外部时钟输入）
  - 0 = 来自晶体振荡器的内部时钟（4分频；晶振频率可在4 MHz至25 MHz之间变化）
- 第4位 **TOSE**：Timer0 边沿选择位
  - 1 = 在TOCKI引脚从高电平到低电平的跳变时递增
  - 0 = 在TOCKI引脚从低电平到高电平的跳变时递增
- 第3位 **PSA**：Timer0 预分频器分配位
  - 1 = Timer0预分频器未被分配。Timer0时钟输入绕过预分频器。
  - 0 = Timer0预分频器已被分配。Timer0时钟输入来自预分频器输出。
- 位2-0 **TOPS2:TOPS0**：Timer0 预分频选择位
  - 111 = 1:256 预分频值
  - 110 = 1:128 预分频值
  - 101 = 1:64 预分频值
  - 100 = 1:32 预分频值
  - 011 = 1:16 预分频值
  - 010 = 1:8 预分频值
  - 001 = 1:4 预分频值
  - 000 = 1:2 预分频值

### 16位模式下的Timer0读/写

在此模式下，使用两个8位寄存器（TMR0H和TMR0L）来存储16位值。在16位模式下，寄存器对TMR0H:TMR0L作为16位寄存器使用。8位高字节TMR0H被锁存（缓冲）。它并不是16位模式下Timer0的实际高字节，因此不能直接读取或写入（参见图10.4）。由于TMR0H不是Timer0的实际高字节寄存器，应先初始化（写入）TMR0H再初始化TMR0L，以避免任何错误。请注意，定时器的高8位值存储在锁存寄存器中，并在TMR0L被加载时加载到实际的TMR0H中。

同样，对Timer0高字节的写入也必须通过TMR0H缓冲寄存器进行。当发生对TMR0L的写入时，高字节会用TMR0H的内容更新。这使得Timer0的所有16位可以一次性更新。

### 预分频器

8位计数器可作为Timer0的预分频器。预分频器的值由PSA（TOCON的第3位）和TOPS2:TOPS0位（TOCON的第2位至第0位）设置，这些位决定了预分频器的分配和预分频比率。清除PSA位会将预分频器分配给Timer0。分配后，可以选择1:2至1:256之间按2的幂次递增的预分频值。如图10.2所示。

当预分频器分配给Timer0模块时，所有写入TMR0寄存器的指令（例如在汇编中：CLRF TMR0, MOVWF TMR0, BSF TMR0）都会清除预分频计数。预分频器的分配完全由软件控制，并可以在程序执行期间“即时”更改。

### Timer0中断和Timer0标志位

如前所述，Timer0在8位模式下从0x00到0xFF以1为步长递增，在16位模式下从0x0000到0xFFFF以1为步长递增。因此，在8位模式下，可以将0x00到0xFF之间的任何值加载到TMR0L寄存器中。在16位模式下，可以将0x0000到0xFFFF之间的任何值加载到16位寄存器TMR0H:TMR0L中。当Timer0在8位模式下从0xFF回卷至0x00，或在16位模式下从0xFFFF回卷至0x0000时，需要一个额外的时钟周期。

INTCON寄存器（图9.7）显示了TMR0IE和TMR0IF位。TMR0中断可以在内部生成（如果通过设置TMR0IE为1来使能），在C中使用“INTCONbits.TMR0IE = 1;”。这用于中断驱动的Timer0。

当TMR0寄存器在8位模式下从0xFF溢出至0x00，或在16位模式下从0xFFFF溢出至0x0000时，此溢出会将INTCON寄存器中的TMR0IF标志位置为1（图10.5）。可以通过轮询TMR0IF来获得使用Timer0的时间延迟。

如前所述，对于中断驱动的Timer0，以下C代码会将TMR0IF清零，将PEIE置为1，将TMR0IE置为1，将GIE置为1，然后启动Timer0：

| 位 | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **INTCON** | | | **TMR0IE** | | | **TMR0IF** | | |

- 第5位 **TMR0IE**（TMR0 溢出中断允许位）：
  - 1 = 允许TMR0溢出中断
  - 0 = 禁止TMR0溢出中断。
- 第2位 **TMR0IF**（TMR0 溢出中断标志位）：
  - 1 = TMR0寄存器已溢出（必须在软件中清除）
  - 0 = TMR0寄存器未溢出

![](img/5e76fd429fabd2b62e16a7bfd8cf546f_287_0.png)

```c
INTCONbits.TMR0IF = 0;
INTCONbits.PEIE = 1;        // enable peripheral interrupt
INTCONbits.TMR0IE = 1;      // Set TMR0IE to 1
INTCONbits.GIE = 1;         // Enable global interrupt
T0CONbits.TMR0ON = 1;       // Start TMR0
```

一旦TMR0溢出（在8位下从0xFF计数至0x00，或在16位下从0xFFFF计数至0x0000），PIC18F4321会将INTCON寄存器中的TMR0IF位置为1。随后PIC18F4321会被中断。微控制器完成当前指令的执行，在内部保存程序计数器（PC），并自动将PC加载为0x000008，在此处可以编写服务例程。如果没有足够的空间，可以在此中断向量地址放置一个分支指令，分支到另一个地址，以便有足够的内存空间来编写服务例程以执行期望的任务。

Timer0的中断优先级由中断优先级位TMR0IP（INTCON2的第2位，图9.9）中的值决定。通过将TMR0IP设置为1，使用C代码“INTCON2bits.TMR0IP = 1;”，PIC18F4321可以使用Timer0中断作为高优先级中断（向量地址0x000008）。

通过将TMR0IP清零，使用代码：INTCON2bits.TMR0IP = 0，PIC18F4321可以使用定时器中断作为低优先级中断（向量地址0x000018）。必须在中断服务例程中通过编程清除TMR0IF位。请注意，PIC18F指令“BCF INTCON, TMR0IF”将清除定时器中断标志位。

在8位模式下，当8位寄存器TMR0L中的定时器值从0xFF递增到0x00（溢出）时，TMR0IF位被置为1。在16位模式下，当16位寄存器TMR0H:TMR0L中的定时器值从0xFFFF递增到0x0000（溢出）时，TMR0IF位被置为1。当Timer0在8位模式下从0xFF回卷至0x00，或在16位模式下从0xFFFF回卷至0x0000时，需要一个额外的时钟周期。
