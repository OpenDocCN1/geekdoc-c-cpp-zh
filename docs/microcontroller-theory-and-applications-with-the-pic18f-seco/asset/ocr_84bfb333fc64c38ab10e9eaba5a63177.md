**SSPADD register** (FIGURE 11.15): 			 For the slave device, SSPADD = slave address. For the master device, the 8-bit value of SSPADD will determine the clock frequency in the SCK line. This is called Baud rate. The baud rate formula is:
Baud rate = FOSC/(4*(SSPADD +1))
SSPADD = (FOSC/ (4*Baud rate))-1
