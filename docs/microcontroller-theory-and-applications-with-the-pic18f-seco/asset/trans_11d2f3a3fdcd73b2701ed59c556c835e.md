## 第 10 章

- **10.1**
    第 7 位：设置为 0，使 TMR0 关闭
    第 6 位：设置为 1，以启用 TMR0 的 8 位模式
    第 5 位：设置为 1，以便可以使用外部晶体振荡器
    第 4 位：设置为 1，以便在时钟从高电平跳变为低电平（下降沿）时定时器递增。
    第 3 位：设置为 0，以启用预分频器功能
    第 2-0 位：设置为 011，以启用 1:16 预分频器
    因此，T0CON=0x73

- **10.2 (b)**
    ```c
    #include <p18f4321.h>
    void main(void)
    {
        OSCCON = 0x60;       // 4 MHz internal clock
        TRISC=0x00;          // PortC is output
        T0CON=0x08;         // Timer0 is 16-bit no prescaler
        TMR0L=0xA0;         // Value placed in lower 8 bits of TMR0
        TMR0H=0x0F;         // Value placed in upper 8-bits of TMR0
        INTCONbits.TMR0IF=0; // Clear TMR0 flag
        T0CONbits.TMR0ON=1; // Turn on TMR0
        while(1)
        {
            while(INTCONbits.TMR0IF==0);
            T0CONbits.TMR0ON=0;  // Turn off TMR0
            PORTCbits.RC0=~PORTCbits.RC0; // Change output of square wave
            TMR0L=0xA0;         // Value placed in lower 8 bits of TMR0
            TMR0H=0x0F;         // Value placed in upper 8-bits of TMR0
            INTCONbits.TMR0IF=0; // Clear TMR0 flag
            T0CONbits.TMR0ON=1;  // Turn on TMR0
        }
    }
    ```

- **10.2 (c)**
    ```assembly
    INCLUDE <P18F4321.INC>
    ORG 0x70
    BCF TRISD, RD7 ; Bit 7 of PORTD is output
    MOVLW 0x60 ; 4MHz internal clock
    MOVWF OSCCON
    MOVLW 0xC8
    MOVWF T1CON ; Setup Timer1 as 16-bit no prescaler
    MOVLW 0xA0
    MOVWF TMR1L ; Value placed in TMR1L
    MOVLW 0x0F
    MOVWF TMR1H ; Value placed in TMR1H
    BCF PIR1, TMR1IF ; Clear Timer1 interrupt flag
    BSF PIR1, TMR1IE ; Enable Timer1 interrupt
    LOOP BSF T1CON, TMR1ON ; Turn on Timer1
    WAIT BFSS PIR1, TMR1IF ; Wait until TMR1IF occurs
    BRA WAIT
    BCF T1CON, TMR1ON ; Turn Timer1 off
    COMF PORTD, RD7 ; 1's complement of bit 7 of PORTD
    MOVLW 0xA0
    MOVWF TMR1L ; Value placed in TMR1L
    MOVLW 0x0F
    MOVWF TMR1H ; Value placed in TMR1H
    BCF PIR1, TMR1IF ; Clear Timer1 interrupt flag
    BSF T1CON, TMR1ON ; Turn on Timer1
    BRA LOOP
    END
    ```

- **11.3** C 程序：
    ```c
    #include <P18F4321.h>
    void main()
    {
        TRISC=1; // PORTC is input
        CCP1CON=0x05; // Capture mode, event on rising edge
        T1CON=0xC8; // Internal clock, no prescale
        TMR1L=0; // Clear TMR1L register
        TMR1H=0; // Clear TMR1H register
        PIR1bits.CCP1IF=0; // Clear CCP1 interrupt flag
        while(PIR1bits.CCP1IF==0); // Wait for first rising edge
        T1CONbits.TMR1ON=1; // Turn on TMR1
        PIR1bits.CCP1IF=0; // Clear CCP1 interrupt flag
        while(PIR1bits.CCP1IF==0); // Wait for second rising edge

        while(1);
        // Period is found in registers CCPRL and CCPRIH
    }
    ```

- **11.5**
    PR2 = ([Fosc]/(4 x Fpwm x TMR2 预分频值)] - 1
    PR2 = ([4 MHz]/(4 x 16 kHz x 1)] - 1 假设预分频值为 1
    PR2 = 61.5 = 61（近似值）。当占空比为 75% 时 = 0.75 x 61.5 = 46.125。因此，CCPR1L 寄存器将加载 46。由于 125（十进制）= .001（二进制），CCP1CON 寄存器的位 DC1B1:DC0B0 将加载 00。

    ; 下方的 PIC18F 汇编语言程序
    ```assembly
    INCLUDE <PIC18F4321.INC>
    ORG 0x100
    MOVLW 0x60 ;4MHz internal clock
    MOVWF OSCCON
    MOVLW D’61’ ;Initialize PR2 register
    MOVWF PR2
    MOVLW D’46’ ;Initialize CCPR1L
    MOVWF CCPR1L
    MOVLW 0x00 ;CCP1 OFF
    MOVWF CCP1CON ;DC1B1:DC0B0=00
    BCF TRISC, CCP1 ;Configure CCP1 pin as output
    CLRF T2CON ;1:1 prescale, Timer2 OFF
    MOVLW 0x0C ;PWM mode
    MOVWF CCP1CON
    CLRF TMR2 ;Clear Timer2 to 0
    BACK BCF PIR1, TMR2IF ;Clear TMR2IF to 0
    BSF T2CON, TMR2ON ;Turn Timer2 ON
    WAIT BTFSF PIR1, TMR2IF ;Wait until TMR2IF is HIGH
    GOTO WAIT
    BRA BACK
    END
    ```

## 附录 B：术语表

- **绝对寻址（Absolute Addressing）：** 这种寻址模式在指令中指定数据的地址。
- **累加器（Accumulator）：** 用于存储大多数 ALU 操作结果的寄存器；在 8 位微控制器中可用。
- **ADC：** 参见模数（A/D）转换器。
- **地址（Address）：** 数据源或目的地的唯一标识号（或定位符）。地址指定了指令中涉及的源操作数或目的操作数的寄存器或内存位置。
- **寻址模式（Addressing Mode）：** 微控制器确定指令中源操作数和目的操作数有效地址的方式。
- **地址寄存器（Address Register）：** 用于存储数据地址（内存位置）的寄存器。
- **地址空间（Address Space）：** 微控制器内存中可由 CPU 直接寻址的存储位置数量。寻址范围由 CPU 的地址线数量决定。
- **美国标准信息交换代码（American Standard Code for Information Interchange (ASCII)）：** 一种常用于微控制器表示字母数字代码的 8 位编码。在 EBCDIC 中，十进制数字 0 到 9 由 30 (Hex) 到 39 (Hex) 表示。
- **模数（A/D）转换器（Analog-to-Digital (A/D) Converter）：** 将模拟电压转换为其数字等效值。PIC18F 微控制器包含片上 A/D 转换器。
- **算术逻辑单元（Arithmetic and Logic Unit (ALU)）：** 一个对两个 n 位数执行算术和逻辑操作的数字电路。
- **汇编器（Assembler）：** 将汇编语言程序翻译成机器语言程序的程序。
- **汇编语言（Assembly Language）：** 一种使用半英语语句的微控制器编程语言。
- **异步操作（Asynchronous Operation）：** 执行一系列步骤，使得每个步骤在前一个步骤完成后启动。
- **基地址（Base address）：** 用于将程序中的所有相对地址转换为绝对（机器）地址的地址。
- **波特率（Baud Rate）：** 数据传输速率，单位为比特每秒。
- **大端序（Big Endian）：** 这种约定用于存储 16 位数，例如将 16 位数据存储在两个内存位置中，方式如下：低内存地址存储高字节，而高内存地址存储低字节。Motorola/Freescale HC11 8 位微控制器遵循大端格式。
- **二进制编码的十进制数（Binary-Coded Decimal (BCD)）：** 用相应的 4 位二进制数表示 10 个十进制数字 0 到 9。
- **位（Bit）：** 二进制数字的缩写。一个信息单元，等于两种可能状态之一（一或零，开或关，真或假）。
- **分支（Branch）：** 分支指令允许计算机无条件或有条件地（基于如进位或符号等条件）跳过或跳出程序序列，跳转到指定的指令。
- **断点（Breakpoint）：** 允许用户执行程序的一部分，直到满足其中一个断点条件之一。然后程序停止。设计者随后可以单步执行或检查内存和寄存器。通常断点条件是程序计数器地址或数据引用。断点用于调试汇编语言程序。
- **缓冲器（Buffer）：** 一种临时内存存储设备，旨在补偿发送设备和接收设备之间（例如 CPU 和外围设备之间）的不同数据速率。电流放大器也称为缓冲器。
- **总线（Bus）：** 连接计算机模块的一束导线。
- **总线仲裁（Bus Arbitration）：** 保证无冲突访问总线的总线操作协议（规则）。仲裁是从并发请求服务的多个候选者中选择一个响应者的过程。
- **总线周期（Bus Cycle）：** 微控制器执行读或写操作的时间周期。
- **CCP：** CCP 代表捕获、比较和 PWM（脉冲宽度调制）。CCP 模块在 PIC18F4321 中作为片上功能实现，用于提供基于时间的脉冲信号的测量和控制。捕获模式可用于测量连接到 PIC18F CCP 引脚的输入周期性波形的周期。比较模式可用于在指定时间后开启连接到 PIC18F CCP 引脚的设备，例如泵。例如，比较模式可用于化工厂，在注满水 50 秒后关闭泵。PWM（脉冲宽度调制）模式可用于在 PIC18F 的 CCP 引脚上生成具有用户指定频率和占空比的方波。
- **中央处理单元（Central Processing Unit (CPU)）：** 计算机的大脑，包含 ALU、寄存器部分和控制单元。
- **芯片（Chip）：** 包含数字电路的集成电路（IC）封装。
- **CISC：** 复杂指令集计算机。控制单元使用微程序设计。包含大量指令集。与 RISC 相比，流水线技术较难实现。
- **时钟（Clock）：** 提供微控制器中各个组件之间同步的定时信号。类似于人类的心跳。
- **CMOS：** 互补 MOS。与 TTL 相比，功耗低，提供更高的密度和速度。
- **编译器（Compiler）：** 将用高级编程语言编写的源代码翻译成微控制器可理解的机器语言的程序。
