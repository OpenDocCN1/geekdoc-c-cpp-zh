# 3.2 Microcontroller Input/Output (I/O)

The technique of data transfer between a microcontroller and an external device is called input/output (I/O). One communicates with a microcontroller via the I/O devices interfaced to it. The user can enter programs and data using the keyboard on a terminal and execute the programs to obtain results. Therefore, the I/O devices connected to a microcontroller provide an efficient means of communication between the microcontroller and the outside world. These I/O devices, commonly called peripheras, include keyboards, seven-segment displays, and LCD’s (Liquid Crystal Displays).

There are two ways of transferring data between a microcontroller and I/O devices. These are programmed I/O, and interrupt I/O. Using programmed I/O, the CPU executes a program to perform all data transfers between the CPU and the external device.
