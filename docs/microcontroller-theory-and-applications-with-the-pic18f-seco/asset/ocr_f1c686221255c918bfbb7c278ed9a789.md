Assume 1 MHz PIC18F. Consider the following subroutine:

DELAY MOVW  D'100'
      MOVWF  0x20

      BRA    LOOP
      RETURN
```
```

+   (a) Calculate the time delay provided by the above subroutine.

(b) Calculate the counter value to be loaded into data register 0x20 for 1 ms delay.

# Solution

+   (a) Each instruction in the above subroutine is executed in one cycle except for the DECFSZ instruction. DECFSZ is executed in one cycle if it does not skip, and two cycles if it skips (See Appendix D for instruction cycles).

Hence, total instruction cycles $= \text{Cycle for MOVW}L + \text{Cycle for MOVWF}F + (100 - 1)$
$(\text{Cycles for DECFSZ if it does not skip and BRA instructions}) + (\text{Cycle for DECFSZ if it skips}) +$
$\text{Cycle for RETURN}$
$= 1 + 1 + 99(1 + 1) + 2 + 1 = 203$

Since for the PIC18F, one instruction cycle $= 4$ clock cycles, total delay $= (203) \times 4 = 812$ clock cycles. Also, for 1 MHz clock, each clock cycle is 1 $\mu$sec. Hence, total time delay $= 812 \mu$sec.
