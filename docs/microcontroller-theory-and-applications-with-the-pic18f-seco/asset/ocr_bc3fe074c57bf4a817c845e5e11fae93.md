The Table write operation is accomplished using the TBLWT instruction with four addressing modes (register indirect, postincrement, postdecrement, and predecrement). Table operations work with data bytes . A table block containing data, rather than program instructions, is not required to be word aligned. Therefore, a table block can start and end at any byte address. Note that although the TBLPTR is 21-bit wide, the PIC18F4321 uses low 13 bits of the 21-bit address since the PIC18F4321 program memory address is 13-bit wide.
