# ### 8.1    PIC18F Pins and Signals

The PIC18F4321 is contained in three types of packaging as follows:

+   *   40-pin Plastic Dual In-line Package (PDIP)
*   44-pin Quad Flat No-lead plastic package (QFN)
*   44-pin Thin plastic Quad Flat pack Package (TQFP)

Figure 8.1 shows the PIC18F4321 pin diagram for a PDIP. A brief description of all pins and signals for the PIC18F4321 contained in the 40-pin PDIP is provided in Table 8.1.
