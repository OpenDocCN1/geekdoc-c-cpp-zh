

## RLNCF 循环左移 f（无进位）

语法：RLNCF f{,d{,a}}

操作数：
- 0 ≤ f ≤ 255
- d ∈ {0,1}
- a ∈ {0,1}

操作：
(f<7>) → dest<n+1>, (f<7>) → dest<0>

影响的标志位：N, Z

编码：

| | 0100 | 0|d$a$ | $ffff$ | $ffff$ |
| :--- | :--- | :--- | :--- | :--- |

描述：
寄存器 'f' 的内容向左循环移动一位。如果 'd' 为 '0'，结果存放在 W 中。如果 'd' 为 '1'，结果存回寄存器 'f' 中（默认）。如果 'a' 为 '0'，选择访问银行（Access Bank）。如果 'a' 为 '1'，使用 BSR 选择 GPR 银行（默认）。如果 'a' 为 '0' 且启用了扩展指令集，当 f ≤ 95 (5Fh) 时，该指令以索引字面量偏移寻址模式运行。详见第 24.2.3 节“索引字面量偏移模式下的字节操作和位操作指令”。

![](img/5e76fd429fabd2b62e16a7bfd8cf546f_427_0.png)

字数：1

周期：1

Q 周期活动：

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 读取寄存器 'f' | 处理数据 | 写入目标 |

**示例：**
RLNCF REG, 1, 0

指令执行前
REG = 1010 1011

指令执行后
REG = 0101 0111

## RRCF 通过进位循环右移 f

语法：RRCF f{,d{,a}}

操作数：
- 0 ≤ f ≤ 255
- d ∈ {0,1}
- a ∈ {0,1}

操作：
(f<7>) → dest<n−1>, (f<0>) → C, (C) → dest<7>

影响的标志位：C, N, Z

编码：

| | 0011 | 00$d$ | $ffff$ | $ffff$ |
| :--- | :--- | :--- | :--- | :--- |

描述：
寄存器 'f' 的内容通过进位标志位向右循环移动一位。如果 'd' 为 '0'，结果存放在 W 中。如果 'd' 为 '1'，结果存回寄存器 'f' 中（默认）。如果 'a' 为 '0'，选择访问银行（Access Bank）。如果 'a' 为 '1'，使用 BSR 选择 GPR 银行（默认）。如果 'a' 为 '0' 且启用了扩展指令集，当 f ≤ 95 (5Fh) 时，该指令以索引字面量偏移寻址模式运行。详见第 24.2.3 节“索引字面量偏移模式下的字节操作和位操作指令”。

![](img/5e76fd429fabd2b62e16a7bfd8cf546f_427_1.png)

字数：1

周期：1

Q 周期活动：

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 读取寄存器 'f' | 处理数据 | 写入目标 |

**示例：**
RRCF REG, 0, 0

指令执行前
REG = 1110 0110
C = 0

指令执行后
REG = 1110 0110
W = 0111 0011
C = 0

## SETF 置 f 为 1

语法：
SETF f{,a}

操作数：
- 0 ≤ f ≤ 255
- a ∈ {0,1}

操作：
FFh → f

影响的标志位：无

编码：

| | 0110 | 100a | ffff | ffff |
| :--- | :--- | :--- | :--- | :--- |

描述：
指定寄存器的内容被置为 FFh。

如果 'a' 为 '0'，选择访问银行（Access Bank）。如果 'a' 为 '1'，使用 BSR 选择 GPR 银行（默认）。

如果 'a' 为 '0' 且启用了扩展指令集，当 f ≤ 95 (5Fh) 时，该指令以索引字面量偏移寻址模式运行。详见第 24.2.3 节“索引字面量偏移模式下的字节操作和位操作指令”。

字数：1

周期：1

Q 周期活动：

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 读取寄存器 'f' | 处理数据 | 写入寄存器 'f' |

**示例：**
SETF REG, 1

指令执行前
REG = 5Ah

指令执行后
REG = FFh

## 附录 D：PIC18F 指令集 - 详细说明

### SLEEP 进入睡眠模式

语法：SLEEP

操作数：无

操作：
00h → WDT,
d → [0,1]
1 → TQ,
0 → PD

影响的标志位：TQ, PD

编码：
0000 0000 0000 0011

描述：
掉电状态位（PD）被清除。超时状态位（TQ）被置位。看门狗定时器及其分频器被清零。
处理器进入睡眠模式，振荡器停止工作。

字数：1

周期：1

Q 周期活动：

| Q1 | Q2 | Q3 | Q4 |
| :---: | :---: | :---: | :---: |
| 解码 | 无操作 | 处理数据 | 进入睡眠 |

**示例：** SLEEP

指令执行前
TQ = ?
PD = ?

指令执行后
TQ = 1
PD = 0

† 如果看门狗定时器（WDT）导致唤醒，此位将被清除。

### SUBFWB W 减 f 带借位

语法：SUBFWB f{,d{,a}}

操作数：
- 0 ≤ f ≤ 255
- d ∈ {0,1}
- a ∈ {0,1}

操作：
(W) - (f) - (C) → dest

影响的标志位：N, OV, C, DC, Z

编码：
0101 01da ffff ffff

描述：
从 W 中减去寄存器 'f' 和进位标志（借位）（采用二进制补码方法）。如果 'd' 为 '0'，结果存放在 W 中。如果 'd' 为 '1'，结果存放在寄存器 'f' 中（默认）。

如果 'a' 为 '0'，选择访问银行（Access Bank）。如果 'a' 为 '1'，使用 BSR 选择 GPR 银行（默认）。

如果 'a' 为 '0' 且启用了扩展指令集，当 f ≤ 95 (5Fh) 时，该指令以索引字面量偏移寻址模式运行。详见第 24.2.3 节“索引字面量偏移模式下的字节操作和位操作指令”。

字数：1

周期：1

Q 周期活动：

| Q1 | Q2 | Q3 | Q4 |
| :---: | :---: | :---: | :---: |
| 解码 | 读取寄存器 'f' | 处理数据 | 写入目标 |

**示例 1：** SUBFWB REG, 1, 0

指令执行前
REG = 3
W = 2
C = 1

指令执行后
REG = FF
W = 2
C = 0
Z = 0
N = 1 ; 结果为负数

**示例 2：** SUBFWB REG, 0, 0

指令执行前
REG = 2
W = 5
C = 1

指令执行后
REG = 2
W = 3
C = 1
Z = 0
N = 0 ; 结果为正数

**示例 3：** SUBFWB REG, 1, 0

指令执行前
REG = 1
W = 2
C = 0

指令执行后
REG = 0
W = 2
C = 1
Z = 1 ; 结果为零
N = 0
