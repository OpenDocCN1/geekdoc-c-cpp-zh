# **RLNCF Rotate Left f (No Carry)**

Syntax: RLNCF f{,d{,a}}

Operands: 0≤f≤255
d ∈ {0,1}
a ∈ {0,1}

Operation: (f<7> ) → dest< n + 1 >. (f<7> ) → dest<0>

Status Affected: N, Z

Encoding:  | 0100  | 0|d$a$ | $ffff$ | $ffff$ |
---|---|---|---|---|

Description: The contents of register 'f' are rotated one bit to the left. If 'd' is '0', the result is placed in W. If 'd' is '1', the result is stored back in register 'f' (default). If 'a' is '0', the Access Bank is selected. If 'a' is '1', the BSR is used to select the GPR bank (default). If 'a' is '0' and the extended instruction set is enabled, this instruction operates in Indexed Literal Offset Addressing mode whenever f ≤ 95 (5Fh). See Section 24.2.3 "Byte-Oriented and Bit-Oriented Instructions in Indexed Literal Offset Mode" for details.

![](bbox=[0.25, 0.38, 0.45, 0.42])

Words: 1

Cycles: 1

Q Cycle Activity:
| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| Decode | Read register 'f' | Process Data | Write to destination |

**Example:** RLNCF REG, 1, 0

Before Instruction
REG = 1010 1011
After Instruction
REG = 0101 0111

# **RRCF Rotate Right f through Carry**

Syntax: RRCF f{,d{,a}}

Operands: 0≤f≤255
d ∈ {0,1}
a ∈ {0,1}

Operation: (f<7> ) → dest< n − 1 >, (f<0> ) → C, (C ) → dest<7>

Status Affected: C, N, Z

Encoding: | 0011 | 00$d$ | $ffff$ | $ffff$ |

Description: The contents of register 'f' are rotated one bit to the right through the Carry flag. If 'd' is '0', the result is placed in W. If 'd' is '1', the result is placed back in register 'f' (default). If 'a' is '0', the Access Bank is selected. If 'a' is '1', the BSR is used to select the GPR bank (default). If 'a' is '0' and the extended instruction set is enabled, this instruction operates in Indexed Literal Offset Addressing mode whenever f ≤ 95 (5Fh). See Section 24.2.3 "Byte-Oriented and Bit-Oriented Instructions in Indexed Literal Offset Mode" for details.

![](bbox=[0.65, 0.4, 0.9, 0.43])

Words: 1

Cycles: 1

Q Cycle Activity:
| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| Decode | Read register 'f' | Process Data | Write to destination |

**Example:** RRCF REG, 0, 0

Before Instruction
REG = 1110 0110
C = 0
After Instruction
REG = 1110 0110
W = 0111 0011
C = 0
