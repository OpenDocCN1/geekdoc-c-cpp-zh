
例如，在许多情况下，显示连接每个坐标的线条是有意义的，例如在绘制时间序列数据时。为此，你需要指定绘图类型为 "1"。使用 7.1 节中的 `foo` 和 `bar`，以下代码生成图 7-2 左侧面板中的图：

```
R> plot(foo,bar,type="1")
```

![](img/b2cfc85cbb129f60fe595a2bae074fe4_163_0.png)

图 7-2：使用五个相邻坐标生成的折图，设置 `type="1"` [左侧] 或 `type="b"` [右侧]

`type` 的默认值为 "p"，可以解释为“仅点”。由于你没有指定任何不同的内容，因此图 7-1 中的图表使用了此值。而在在这个示例中，你设置了 `type="1"`（意味着仅线条）。其他选项包括用于同时显示点和线的 "b"（显示在图 7-2 的右侧面板）以及用于让线条与点重叠的 "o"（这消除了 `type="b"` 中可见的点与线之间的间隙）。选项 `type="n"` 导致不绘制任何点或线，创建一个空白图表，这对于必须分步构建的复杂图表非常有用。

## 7.2.2 标题和轴标签

默认情况下，基础图表不会有标题，坐标轴将用所绘制向量的名称进行标记。但主标题和更具描述性的轴标签通常会让图表数据更容易于解释。你可以通过为主标题 `main`、x 轴 `xlab` 和 y 轴 `ylab` 提供作为字符字符串形式的文本来添加这些内容。请注意，这些字符串可能包含转义序列（在 4.2.3 节中讨论）。以下代码生成图 7-3 中的图：

```
R> plot(foo,bar,type="b",main="My lovely plot",xlab="x axis label",ylab="location y")
```

```
R> plot(foo,bar,type="b",main="My lovely plot\ntitle on two lines",xlab="")
```

## 7.2.3 颜色

在图表中添加颜色不仅仅是为了美学考虑。颜色可以让数据变得清晰得多——例如通过区分因子水平或强调重要的数值限制。你可以通过多种方式使用 `col` 参数设置颜色。最简单的选项是使用整数选择器或字符字符串。R 识别多种颜色字符串值，你可以通过输入 `colors() "black"` 查看这些。默认颜色是整数 1 或字符字符串 "black"。图 7-4 的第一行显示了由以下代码创建的彩色图表示例：

```
plot(foo,bar,type="b",main="My lovely plot",xlab="",ylab="",col=2)
plot(foo,bar,type="b",main="My lovely plot",xlab="",ylab="",col="seagreen")
```

有八种可能的整数值（显示在图 7-5 的左侧图中）和大约 650 个用于指定颜色的字符串。你不限于这些选项，因为还可以通过创建自己的调色板使用 RGB（红、绿、蓝）级别来指定颜色。我将在第 25 节中详细讨论最后两个选项。
