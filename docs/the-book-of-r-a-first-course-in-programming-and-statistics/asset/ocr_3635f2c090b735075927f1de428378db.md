All Greek and mathematical markup is contained within a call to expression. It's necessary to use paste if you require separate components (separated by commas), some of which may or not be regular text (in other words, in quotes) to produce the final result. Here are some key notes:

+   * Superscripts are given by ^ and subscripts by _ ; for example, c^2 c_2 in expri, and the a[1] component provides a_12.
* You can group components with parentheses ( ), which are visible (for example, the (1-pi)^n-(x[i]) component of expr2), or with braces { }, which are not (for example, the pi^(x[i]) component).
* Italicized variables are drawn with italic(); for example, italic(n) produces n in expr3.
* Constructs for common arithmetic operators already exist, such as sum( , ) and frac( ); for example, in expr3, calling sum(italic(x)[italic(i)],italic(i)=1,italic(n)) produces a result that looks like:

![](bbox=[0.568, 0.375, 0.631, 0.417])

and frac(italic(x)[1]+...+italic(x)[n]),italic(n) produces an expression like this:

![](bbox=[0.558, 0.455, 0.678, 0.487])

+   * There are additional markup tools for proper formatting of expressions, as combining regular text in quotes directly to mathematical markup and creating spaces between components without needing to insert quotes. The need for these depends where the markup contents are exactly (in other words, a component of the call to paste or as a component of an operator tool frac). See, for example, the ""=frac( , ) part of expr4, the space-separation of the two components x^(alpha-1)~(1-x)^(beta-1) with a ~ (set on the numerator of the fraction).

There's an extensive amount of functionality built in R for this type of string formatting in graphical displays I haven't covered here. If you're interested in seeing more, see the file accessed by entering ?plotmath at the prompt as a first step. There is also an extremely useful demonstration, which you can view in R by entering demo(plotmath), that shows off of what's possible, alongside the relevant syntax for expression.
