# 21.3.5 Omnibus F-Test

First encountered in Section 20.5.2 in the context of multilevel predictors, you can think of the omnibus $F$-test more generally for multiple regression models as a test with the following hypotheses:

```
$$H_0 : \beta_1 = \beta_2 = \dots = \beta_p = 0$$
$$H_A : \text{At least one of the } \beta_j \neq 0 \text{ (for } j = 1, \dots, p)$$\quad (21.5)
```

The test is effectively comparing the amount of error attributed to the "null" model (in other words, one with an intercept) with the amount of error attributed to predictors when all the predictors are present. In other words, the more predictors there are to model the response, the more error they explain, giving you a more extreme F statistic and therefore a smaller p-value. The single result makes the test especially useful when you have many explanatory variables. The test works regardless of how mix of predictors you use in a given model: one or be more continuous, discrete, binary, and/or categorical with $k=2$ levels. When multiple regression models are fitted, the amount of output can take time to digest and interpret, and care must be taken to avoid Type I errors (incorrect rejection of a true null hypothesis—refer to Section 18.5).

The $F$-test holds all that down, allowing you to conclude either of the following:

+   1. Evidence against $H_0$ if the associated $p$-value is smaller than your significance level $\alpha$, which suggests that your regression—your combination of the explanatory variables—does a significantly better job of predicting the response than you removed all predictors.
2. No evidence against $H_0$ if the associated $p$-value is larger than $\alpha$, which suggests that using the predictors has no tangible benefit over having an intercept.

The downside is that the test doesn't tell you which of the predictors (or which subset thereof) is having a beneficial impact on the fit of the model, nor it tell you anything about their coefficients or standard errors.

You can compute the $F$-test statistic using the coefficient of determination, $R^2$, let $p$ be the number of regression parameters requiring estimation, excluding the intercept $eta_0$. Then,

```
$$F = \frac{R^2(n - p - 1)}{(1 - R^2)p}$$\quad (21.6)
```

where $n$ is the number of observations used in fitting the model (or records with missing values being deleted). Then, under $H_0$ in (21.5), $F$ follows an $F$ distribution (see Section 16.2.5 and also Section 19.1.2) with $df_1=p, df_2=n-p-1$ degrees of freedom. The $p$-value associated with (21.6) is yielded as the upper-tail area of $F$ distribution.
