## 1.2.1 控制台和编辑器

控制台是你输入命令并查看输出的地方。编辑器是你编写脚本的地方。通常在编辑器中编写代码然后将其发送到控制台更好，这允许你保存工作并更好地组织它。

## 1.2.2 注释

在 R 中，你可以使用注释对代码进行标记。只需在行开头加上井号（#），其后的任何内容都被解释器忽略。例如，在控制台中执行以下内容不会让你返回提示符状态：

```
R > # 这是 R 中的一条注释...
```

注释也可以出现在值命令之后。

R > 1+1 # 这计算出了一个脉冲的结果！
