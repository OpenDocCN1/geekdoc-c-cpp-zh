# 24.4 Interactive Tools in ggvis

Wrap up this chapter, I'll touch on a relatively new addition to the "gg" family, ggvis, by Chang and Wickham (2015). The package enables you to design functional statistical plots that the end user can interact with. The results are provided as web graphics. You will see the pop up as a new tab in your default web browser (if you're using the RStudio IDE—see Appendix B—the ggvis graphics are embedded within the RViewer pane).
