For an example, consider a group of students taking a statistics exam. This group are $n_1 = 233$ students majoring in psychology, of whom $x_1 = 180$ pass, and $n_2 = 197$ students majoring in geography, of whom $175$ pass. Supose it is claimed that the geography students have a higher pass rate in statistics than the psychology students.

Representing the true pass rates for psychology students $\pi_1$ and geography students $\pi_2$, this claim can be statistically tested using a pair of hypotheses defined as follows:

```
$H_0 : \pi_2 - \pi_1 = 0$
$H_A : \pi_2 - \pi_1 > 0$
```

Just as with a comparison between two means, it's important to keep the order of differing consistent throughout the test calculations. This example shows an upper-tailed test.

# Calculation: Two-Sample Z-Test

In testing for the true difference between two proportions mathematically, $\pi_1$ and $\hat{p}_1 = x_1/n_1$ be the sample proportion for $x_1$ successes in $n_1$ trials, and $\hat{p}_2 = x_2/n_2$ for $\pi_2$. With a null value of the difference denoted $\pi_0$, the test is given by the following:

```
$Z = \frac{\hat{p}_2 - \hat{p}_1 - \pi_0}{\sqrt{\hat{p}_1(1-\\hat{p}_1)/n_1 + \hat{p}_2(1-\\hat{p}_2)/n_2}}}$ (18.9)
```

Provided you can assume to apply the aforementioned conditions for a proportion with respect to $n_1, n_2$ and $\pi_1$, you can treat $Z \sim N(0,1)$. There is a new quantity, $p^*$, present in the denominator of (18.9). This is a *pooled* proportion, given as:

```
$p^* = \frac{x_1 + x_2}{n_1 + n_2}$ (18.10)
```

As noted, in this kind of test it is common for the null value, the true difference in proportions, to be set to zero (in other words, $\pi_0 = 0$). The denominator of Equation (18.9) is itself the standard error of the difference between two proportions as used in a hypothesis test. To use $p^*$ lies once more in the fact that $H_0$ is assumed to be true. Using $\hat{p}_1$ and $\hat{p}_2$ separately in the denominator of (18.9), in the form of $\sqrt{\{\hat{p}_1(1-\\hat{p}_1)/n_1 + \hat{p}_2(1-\\hat{p}_2)/n_2}$ (the standard error of the difference between two proportions outside the confines of a hypothesis test), would violate the assumed "truth" of $H_0$. Returning to the statistics exam taken by the psychology and geography students, you can evaluate the required quantities as:

+   - $x_1 < 180$
- $n_1 < 233$
