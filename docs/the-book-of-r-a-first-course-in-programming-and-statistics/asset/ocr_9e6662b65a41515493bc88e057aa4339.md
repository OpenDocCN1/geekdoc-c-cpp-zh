# 4.2.4 Substrings and Matching

Pattern matching lets you inspect a given string to identify smaller strings
within.
The function substr takes a string x and extracts the part of the string
tween two character positions (inclusive), indicated with numbers passed
as start and stop arguments. Let's try it on the object foo from Section 4.2.1.

```
R> foo <- "This is a character string!"
R> substr(x=foo,start=21,stop=27)
[1] "string!"
```

Here, you extracted the characters between positions 21 and 27,
inclusive, to get "string!". The function substr can also be used with the
assignment operator to substitute in a new set of characters. In this
case, the replacement string should contain the same number of characters
as the selected area.

```
R> substr(x=foo,start=1,stop=4) <- "Here"
R> foo
[1] "Here is a character string!"
```
