## 6.2 理解类型、类类和强制类型转换

到目前为止，你已经学习了 R 语言中用于表示、存储和处理数据的许多基本特征。在本节中，你将检查如何正式地区分不同的值和结构，并查看一些从一种类型到另一种类型的转换示例。

### 6.2.1 属性 (Attributes)

你拥有的每个 R 对象都包含关于对象本身性质的额外信息。这些额外信息被称为对象的属性。你已经看到了一些属性。在第 3.1.3 节中，你使用 `dim` 识别了矩阵的维度属性。在第 4.3.1 节中，你使用 `levels` 获取了因子（factor）的属性。第 5.1.2 节也提到名称可以获取列表的成员名称，在第 6.1.3 节中，属性会标记应用 `na.omit` 的结果。

通常，你可以将属性认为是是显式的或隐式的。显式属性对用户直接可见，而 R 在内部确定隐式属性。你可以使用 `attributes` 函数打印给定对象的显式属性，该函数接受任何对象并返回一个命名列表。例如，考虑以下 3x3 矩阵：

```R
R foo <- matrix(data=1:9,nrow=3,ncol=3)
R foo

[1] 1 4 7
[2] 2 5 8
[3] 3 6
```

```R
R attributes(foo)
$dim
[1] 3 3
```

在这里，调用 `attributes` 返回一个包含一个成员 `dim` 的列表。当然，你可以通过 `attributes(foo)$dim` 获取 `dim` 的内容，但如果你知道属性的名称，也可以使用 `attr`：

```R
R attr(x=foo,which="dim")
[1] 3 3
```

该函数接受 `x` 中的对象和作为 R 中字符字符串指定的属性名称。请记住，许多事情甚至更方便，最常见的属性有它们自己的函数（通常以属性名称命名）来访问对应的值。对于矩阵的维度，你已经见过了 `dim` 函数：

```R
R dim(foo)
[1] 3 3
```

这些特定属性的函数非常有用，因为它们允许访问隐式属性，这些隐式属性虽然仍然可以由用户控制，但在必要时是必须的。之前提到的 `names` 和 `levels` 函数都是特定属性的函数。

显式属性通常是可选的；如果没有指定，它们就是 `NULL`。例如，当使用 `matrix` 函数构建矩阵时，可以使用 `dimnames` 参数为行和列标记名称。你传递给 `dimnames` 的一个包含最多两个成员的列表，两个都是适当长度的字符向量——第一个给出行名，第二个给出列名。让我们定义矩阵 `bar` 如下：

```R
R bar <- matrix(data=1:9,nrow=3,ncol=3,dimnames=list(c("A","B","C"),
c("D","E","F")))
```

```R
R bar
D E F
A 1 4 7
B 2 5 8
C 3 6 9
```

由于维度名称是属性，当你调用 `attributes(bar)` 时，`dimnames` 会出现。

```R
R attributes(bar)
$dim
[1] 3 3

$dimnames
$dimnames[[1]]
[1] "A" "B" "C"

$dimnames[[2]]
[1] "D" "E" "F"
```

注意 `dimnames` 本身是一个列表，嵌套在较大的属性列表中。同样，为了提取此属性的值，你可以使用列表成员引用，可以使用像之前所示的 `attr`，或者可以使用特定属性的函数。

```R
R> dimnames
[[1]]
[1] "A" "B" "C"

[[2]]
[1] "D" "E" "F"
```

某些属性可以在对象创建后进行修改（正如你之前在第 5.1.2 节中看到的，那里你重命名了列表的成员）。在这里，为了让 `foo` 完全等于 `bar`，你可以通过将一些 `dimnames` 赋值给特定属性函数：

```R
R> dimnames(foo) <- list("A","B","C",c("D","E","F")
R> foo
D E F
A 1 4 7
B 2 5 8
C 3 6 9
```

我在这里讨论了矩阵，但 R 中其他对象的可选属性处理方式相同。属性不仅限于内置的 R 对象。你自己构建的对象可以使用它们自己的属性和特定属性函数来定义。只需记住，对象的角色通常是提供关于对象的描述性数据，否则你可能会不必要地过度复杂你的对象结构。

## 6.2.2 对象类 (Object Class)

对象的类是描述 R 中实体最实用的属性之一。你创建的每个对象都通过隐式或显式的方式被至少一个类所标识。R 是一种面向对象的编程语言，这意味着实体被存储为对象以及对它们起的方法。在语言中，类标识正式称为 *继承* (inheritance)。

注意：本节重点于 R 中最常用的带类结构，称为 S3。还有另一种结构 S4，它本质上是一组针对不同对象的识别和处理的更正式的规则。对于大多数实际目的，特别是对初学者来说，理解和使用 S3 就足够了。你可以在 R 的在线文档中找到更多细节。

在你有用户定义对象，或者像因子向量（factor vector）或数据框（data frame）这样的对象，其他属性在处理对象本身时起着重要作用的情况下，对象的类是显式的——例如，因子向量的水平水平或数据框中的变量名是可修改的属性，在其中起着主要作用。
