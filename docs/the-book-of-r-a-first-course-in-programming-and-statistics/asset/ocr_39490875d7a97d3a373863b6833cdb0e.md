The built-in R function persp is used to create perspective plots. Its basic usage is the same as contour, filled.contour, and image. Your increasing sequences in the x and y-axis directions, which define the evaluation grid, are passed to x and y, with your corresponding z-matrix passed to z. Bring up the default appearance for the 20 x20 mtcars surface with the following:

```
persp(x=hp.seq,y=wt,z=car.pred.mat)
```

This appears in the top left of Figure 25-19.
Interpreting the perspective plot is straightforward. The default viewing angle shows the x-axis in the foreground, increasing from left to right, and the y-axis on the left, increasing from the foreground to deeper in the background. In this way, the evaluation grid lies flat along which your surface is plotted from the bottom vertically to the top.

The viewing angle is one of the most important aspects of such a plot. In persp, you can control it with the two options theta, which spins the plot horizontally, and phi, which adjusts the vertical viewing position. Both are specified in degrees; theta defaults to 0, and phi defaults to 15 to give a slightly elevated viewing position so you can see the y-axis extending foreground to background [sic] extending foreground to background. In general, you can think of the possible value of theta as anywhere from 0 to 360, representing a complete rotation all around the plot, and the possible value of phi as anywhere from 90 to -90, the range of which you moves from a bird's-eye view directly from the top looking down to a submarine view directly from the top up.
 second example demonstrates this behavior:

```
persp(x=hp.seq,y=wt,z=car.pred.mat,theta=30,phi=23,
xlab="Horsepower",ylab="Weight",zlab="mean MPG"
```

In fact, this line of code that originally produced the rightmost image in Figure 25-19 on page 92 (when you were introduced to the concept of an interactive term between two continuous predictors in a linear regression model). The graphic is reproduced in the top right of Figure 25-19. The axes are titled up using xlabel and ylab, with zlab used to control the title for the third vertical axis. The use of theta and phi in this has elevated the viewing position slightly more than the default and rotated the plot so that the origin (in other words, the lower vertex denoting the lower limit of the x-y plane) is prominent in the foreground. It's worth noting that increasing theta from 0 rotates the plot in a clockwise-horizontal fashion, but you could also supply a negative value to that argument to rotate the plot in the other direction. Setting theta=-30, as shown here, has the same effect as setting theta=330.
