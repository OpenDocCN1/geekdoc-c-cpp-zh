# 3.1.2 Row and Column Bindings

If you have multiple vectors of equal length, you can quickly build a matrix by binding these vectors using the built-in R functions, rbind and cbind. You can treat each vector as a row (using the command rbind) or treat each vector as a column (using the command cbind). Say you have the two vectors 1:3 and 4:6. You can reconstruct the $2 \times 3$ matrix in Figure 3-2 using rbind as follows:

```
R> rbind(1:3,4:6)
[1] [,2] [3]
1 2 3
[2,] 4 5 6
```
