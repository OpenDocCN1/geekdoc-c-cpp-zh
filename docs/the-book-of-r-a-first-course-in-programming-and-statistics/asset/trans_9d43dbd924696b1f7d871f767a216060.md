

## 影响 (Influence)

高杠率且会影响估计趋势的观测值被认为具有影响力的。换句话说，只有当在考虑相应的预测值的同时考虑到响应值时，才会判断其影响力。

这些定义之间存在重叠，因此可以使用这些术语的组合描述特定的观测值。让我们来看一些假设性示例。创建建议响应 (y) 和解释变量 (x) 的两个向量：

```R
R x <- c(1.1,1.3,2.3,2.6,1.2,2.0,0.1,1.8,1.9,0.2,0.75)
R y <- c(6.7,7.7,9.9,8.9,3.8,2.2,9.6,11.1,4.7,3.3)
```

这些将形成数据主体。现在，考虑 p1 到 p3y，它们将用于存储三个额外观测点的预测值和响应值：

```R
p1x <- 1.2
p1y <- 14
p2x <- 5
p2y <- 19
p3x <- 5
p3y <- 5
```

也就是说，点 1 是 (1.2,14）；点 2 是 (5,19）；点 3 是 (5,5)。接下来，以下 lm 的用法提供了四个简单的线性模型拟合。第一个是 y 对 x 的回归。接下来的分别将点 1、2 和 3 作为第 11 个观测值引入。

```R
R mod.0 <- lm(y~x)
R mod.1 <- lm(c(p1y)~c(x,p1x))
R mod.2 <- lm(c(p2y)~c(x,p2x))
R mod.3 <- lm(c(p3y)~c(x,p3x))
```

现在，你可以使用这些对象来直观地澄清离群值 (outlier)、杠率 (leverage) 和影响 (influence) 的定义，如图 22-5 所示。输入以下代码带有 x 和 y 轴限制初始化图形：

```R
R plot(x,y,xlim=c(0,5),ylim=c(0,20))
```

然后使用 points、abline 和 text 来构建图 22-5 的左上图，如下：

```R
R points(p1x,p1y,pch=15,cex=1.5)
R abline(mod.0)
R abline(mod.1,lty=2)
R text(2,1,labels="Outlier, low leverage, low influence",cex=1.4)
```

通过将 p1x、p1y 和 mod.1 替换为对应点 2 和点 3 的值，并修改 text 中的 labels 参数，创建中间和右侧图。

在图 22-5 的左上图中，额外的点是一个离群值的示例，因为它偏离数据主体，并且*确实*符合原始观测值所建议的趋势。尽管如此，它仅因为其预测值为 1.2 (p1x) 而被认为具有低杠率，这个值与 x 的其他值相比并不寻常。事实上，它与 x 均值的接近程度表明包含在 mod.1 中的主要是对原始截距的修改。你甚至可以将其分类为低影响点——对拟合模型的改变微乎其微。

在右上图中，你可以看到一个*不会*被视为离群值的观测值示例。虽然点 2 离原始 10 个观测值，但它很好地拟合了 x 和 y 模型，这在回归背景下很重要。点 2 因为其与所有 x 值相比处于极端预测值，而被视为高杠率点（换句话说，它的响应值具有剧烈改变拟合的潜力）。目前，由于模型几乎不受其影响，它是一个低影响点。最后，底部图显示了一个高杠率位置的离群值示例——它偏离原始 10 个观测值，并不是原始趋势的一部分；其极端预测值导致了高杠率；并通过降低斜率和提高截距大幅改变了整个模型。这些思路在高维（即具有多个预测变量）的线性回归中同样适用。

## 4 计算杠率 (Calculating Leverage)

杠率使用 22.2 节中定义的设计矩阵 X 计算。具体来说，如果你有 n 个观测值，第 i 点（i = 1,...,n）的杠率表示为 $h_{ii}$。这些是 $n \times n$ 矩阵 H 的 i 行第 i 列对角线元素，该矩阵为：

```
H = X(X^T X)^{-1}X^T (22.4)
```

在 R 中，为 22.3 节中定义的 10 个示例观测值构建矩阵的方法非常直接，使用矩阵乘法 (%%)、矩阵转置 (t)、矩阵求逆 (solve) 和对角线元素提取 (diag) 的知识。然后，你可以绘制 $h_{ii}$ 相对于 x 值的图。以下代码产生图 22-6：

```R
R X <- cbind(rep(1,10),x)
hii <- diag(X%%solve(t(X))%%t(X))

[1] 0.103369 0.101207 0.348722 0.130263 0.100145 0.372397 0.171195
[8] 0.198063 0.326123 0.148560
plot
)
```

你通常会使用 R 内置的 hat values（其命名源于方程 22.4 中的矩阵代数）来获取杠率（而不是手动构建设计矩阵 X 并自己进行计算）。只需提供使用 x 和 y 数据拟合的 lm 对象即可确认你的离群值。

![](img/b2cfc85cbb129f60fe595a2bae074fe4_592_0.png)

图 22-6：绘制 x 中 10 个示例预测观测值的杠率

查看图 22-6，杠率相对于对应预测值本身的绘制情况是合理的——随着你向预测数据均值的任一方向移动，杠率逐渐升高。这基本上是你在任何原始杠率图中都会看到的模式。

## 22.3 Cook 距离 (Cook's Distance)

仅凭杠率不足以确定每个观测值对拟合模型的整体影响。这需要还需要考虑响应值。广为人知的影响力衡量是 Cook 距离，它估计了从拟合模型中删除第 i 个值的影响幅度。观测值 $i$ 的 Cook 距离（记为 $D_i$）由以下方程给出：

```
$D_i = \sum_{j=1}^n \frac{(\hat{y}_j - \hat{y}_{j(-i)})^2}{p\sigma^2}$
```

证明 $D_i$ 可以用杠率表示：

$D_i = \frac{h_{ii}^2}{(1-h_{ii})^2} \left( \frac{y_i - \hat{y}_i}{s} \right)^2$

其中 $h_{ii}$ 是第 $i$ 个观测值的杠率，$p$ 是预测变量的个数，$s$ 是误差的标准差。

要在 R 中计算 Cook 距离，可以使用以下代码：

```R
x1 <- c(x)
y1 <- c(y)
n <- length(x1)
param <- length(coef(mod.1))
hat.full <- fitted(mod.1)
sigma <- summary(mod.1)$sigma
cooks <- rep(NA,n)
for(i in 1:n){
  temp.y <- y1[-i]
  temp.x <- x1[-i]
  temp.model <- lm(temp.y ~ temp.x)
  temp.fitted <- predict(temp.model, newdata=data.frame(x=x1))
  cooks[i] <- sum((hat.full-temp.fitted)^2)/param*sigma^2
}
cooks
```
