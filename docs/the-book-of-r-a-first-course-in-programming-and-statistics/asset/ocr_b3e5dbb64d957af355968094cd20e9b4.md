# 21.2.1 Extending the Simple Model to a Multiple Model

Rather than having just one predictor, you want to determine the value of a continuous response variable $Y$ given the values of $p > 1$ independent explanatory variables $X_1, X_2, \dots, X_p$. The overarching model is defined as

$Y = \beta_0 + \beta_1X_1 + \beta_2X_2 + \dots + \beta_pX_p + \epsilon, \quad (21.1)$

where $\beta_0, \dots, \beta_p$ are the regression coefficients, and assume, normally distributed residuals $\epsilon \sim N(0, \sigma)$ around the mean.

In practice, you have $n$ data records; each record provides values for each of the predictors $X_j; j = \{1, \dots, p\}$. The model to be fitted is in terms of the mean response, conditional upon a particular realization of the set of explanatory variables

$\hat{Y} = \hat{Y|X_1=x_1, X_2=x_2, \dots, X_p=x_p} = \hat{eta}_0 + \hat{eta}_1x_1 + \hat{eta}_2x_2 + \dots + \hat{eta}_px_p$.

where the $\hat{eta}_js$ represent estimates of the regression coefficients, recall that in linear regression, where you have only one predictor variable, to find the "line of best fit". The idea of least-squares estimation for linear models with multiple independent predictors follows the same motivation. Now, in an abstract sense you can think of the relationship between response and predictors as a multidimensional plane or surface. You want to find the surface that fits your multivariate data in terms of minimizing the overall squared distance between itself and the raw response data.

More formally, for your $n$ data records, the $\beta_js$ are found as the values that minimize the sum

$$\sum_{i=1}^n [y_i - (\beta_0 + \beta_1x_{1,i} + \beta_2x_{2,i} + \dots + \beta_px_{p,i})]^2, \quad (21.2)$

where $x_{ij}$ is the observed value of individual $i$ for explanatory variable $X_j$ and $y_i$ is her response value.

# 21.2.2 Estimating in Matrix Form

The computations involved in minimizing this squared distance (21.2) are made much easier by a *matrix representation* of the data. When dealing with $n$ multivariate observations, you can write Equation (21.1) as follows,

$Y = X\beta + \epsilon$.

where $Y$ and $\epsilon$ denote $n \times 1$ column matrices such that

$Y = \begin{bmatrix} y_1 \ y_2 \ \vdots \ y_n \end{bmatrix} \quad \text{and} \quad \epsilon = \begin{bmatrix} \epsilon_1 \ \epsilon_2 \ \vdots \ \epsilon_n \end{bmatrix}$
