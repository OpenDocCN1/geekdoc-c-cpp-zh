## 4.2 字符

字符字符串是另一种常见的数据类型，用于表示文本。在 R 中，字符串通常用于指定文件夹位置或软件选项（如第 1.2 节中简要所示）；为函数提供参数；以及注释对象、提供文本输出，或说明图表和图形。简单来说，它们可以用于定义不同的组以形成分类变量，你将在第 4.3 节中看到，因子（factors）更适合这种用法。

R 环境中有三种不同的字符串格式。默认字符串格式称为扩展正则表达式（extended regular expression）；其他变体命名为 Perl 表达式和字面量正则表达式（literal regular expressions）。这些变体的复杂性超出了本书的范围，因此从这里开始提到的任何字符字符串均是指扩展正则表达式。关于其他字符串格式的更多技术细节，请在提示符处输入 `regex`。

### 4.2.1 创建字符串

字符字符串由双引号 `"` 表示。要创建一个字符串，只需在对引号之间输入文本。

```
foo <- "This is a character string!"
R foo
[1] "This is a character string!"
R length(x=foo)
[1] 1
```

R 将字符串视为一个整体。换句话说，`foo` 是一个长度为 1 的向量，因为 R 只计算不同字符串的总数，而不是单个单词或字符。要计算单个字符的数量，你可以使用 `nchar` 函数。这里有一个示例：

```
nchar(x=foo)
[1] 27
```

几乎任何字符组合（包括数字）都是有效的字符字符串。

```
bar <- "23.3"
R bar
[1] "23.3"
```

注意，在这种形式下，字符串没有数值意义，它不会被像数字 23.3 那样处理。例如，尝试将其乘以 2 将导致错误。

```
bar*=2
Error in bar * 2 : non-numeric argument to binary operator
```

此错误发生是因为 `*` 期望在两个数值上进行操作（而不是一个数字和一个字符串，这没有意义）。字符串可以通过多种方式进行比较，最常见的比较是字符的等值性比较。

```
R "alpha"=="alpha"
[1] TRUE
R "alpha!="beta"
[1] TRUE
R c("alpha","beta","gamma")="beta"
[1] FALSE TRUE FALSE
```

其他关系运算符的工作方式正如你预期的的一样。例如，R 认为字母表中靠靠后的字母比靠前的字母大，这意味着它可以根据字母顺序判断字母字符串是否大于另一个。

```
R> "alpha"<<="beta"
[1] TRUE
R> "gamma">="Alpha"
[1] TRUE
```

此外，大写字母被认为比小写字母大。

```
R> "Alpha">="alpha"
[1] TRUE
R> "beta">="betA"
[1] FALSE
```

大多数符号也可以用于字符串中。例如，以下字符串是有效的：

```
R baz <- "&4_3 **.?. $symbolic nonEnse; ,"
R baz[&4]
[1] "&4_3 **.?. $symbolic nonEnse; , "
```

一个重要的例外是反斜杠 `\`，也称为转义符。当反斜杠位于字符串的引号内时，它启动对字符串本身打印或显示的简单控制。你稍后将在第 4.2.3 节看到它是如何工作的。首先让我们看看两个组合字符串的有用函数。

### 4.2.2 拼接

有两个用于拼接（或连接）一个或多个字符串的主要函数：`cat` 和 `paste`。它们的区别在于如何返回内容。第一个函数 `cat` 将输出直接发送到控制台屏幕，而 `paste` 函数拼接其内容并将最终字符字符串作为可用的 R 对象返回。当字符串拼接的结果需要传递给另一个函数或以次要方式使用而不是仅仅显示时，这非常有用。考虑以下字符字符串向量：

```
R> qux <- c("awesome","R","is")
R> length(x=qux)
[1] 3
R> qux
[1] "awesome" "R" "is"
```

对于数字和逻辑值，你也可以将任意数量的字符串存储在矩阵或数组结构中。

调用 `cat` 或 `paste` 时，按你想要的顺序向函数传递参数。以下几行显示了相同用法但不同类型的输出：

```
R> cat(qux[2],qux[3],"totally",qux[1],"!")
R is totally awesome!
R paste(qux[2],qux[3],"totally",qux[1],"!")
[1] "R is totally awesome !"
```

在这里，你使用了 qux 的三个元素以及两个额外的字符串 "totally" 和 "!" 来生成最终的拼接字符串。注意，`cat` 无法直接将结果赋值给新变量并视为字符字符串。然而，对于 `paste`，输出左侧的 `[1]` 以及引号 `""` 的存在标识返回的项目是一个包含字符字符串的向量，这可以赋值给对象并在其他函数中使用。

在使用 R GUI 时，OS X 和 Windows 在字符串拼接的默认处理上略有不同。在 Windows 中调用 `cat` 后，新的 R 提示符你的下一个命令将与打印字符串位于同一行，在这种情况下你只需按回车即可移动到下一行，或者使用转义序列（我们将在第 4.2.3 节中讨论）。在 OS X 上，新提示符如往常出现在下一行。

这两个函数都有一个可选参数 `sep`，在字符串拼接时用字符串分隔符。例如：

```
R paste(qux[2],qux[3],"totally",qux[1],"!",sep="---")
[1] "R---totally---awesome---"
R cat(qux[2],qux[3],"totally",qux[1],"!",sep="")
R is totally awesome!
R paste(qux[2],qux[3],"totally",qux[1],"!",sep="")
[1] "R is totally awesome!"
```
