# 25.1.3 Custom Palettes

You're not restricted to the ready-to-use color designs. The function colorRampPalette allows you to create your own palettes; you supply two or more desired color keys to an argument of the same name, and it creates a palette that transitions between them. The result of a call to colorRampPalette is itself a function—one that behaves exactly like the built-in palette functions noted earlier.

Let's say you'd like to be able to generate colors on a scale between purple and yellow. You specify the color keys to be interpolated, in the desired order, as a character vector of names from the collection that R recognizes. The following line creates this palette function:

```
R puryl.colors <- colorRampPalette(colors=c("purple","yellow"))
```

Let's create another one, this time picking one will show up a little clearer in a color plot that ends up you are using it in grayscale (in which case switching to monochromatic palettes is a good idea).

```
R blues <- colorRampPalette(colors=c("navyblue","lightblue"))
```

Here are a couple more, using more than two colors for this time:

```
R fours <- colorRampPalette(colors=c("black","hotpink","sereen4","tomato"))
R patriot.colors <- colorRampPalette(colors=c("red","white","blue"))
```

Having created a handful of custom palette functions, you can now generate any number of colors from each range just like before (done here)
