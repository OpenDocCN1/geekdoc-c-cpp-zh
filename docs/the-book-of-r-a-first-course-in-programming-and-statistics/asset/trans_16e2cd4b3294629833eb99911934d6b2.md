R q()

直接退出控制台会弹出一个框，询问你是否想要保存工作空间映像（workspace image）。在这种情况下，选择保存不会打开浏览器来命名你的文件，而是在你的工作目录中创建（或覆盖）一个扩展名为 .RData 的“无命名”文件（参见第 1.2.3 节）。

当打开新的 R 实例时，如果默认目录下存在一个未名的 .RData 文件，程序将自动加载该默认工作空间——发生这种情况，你将在控制台的欢迎文本中收到通知。

注意：除了 .RData 文件外，R 还会在同一目录下自动保存一个文件，其中包含了关联工作空间在控制台中执行的所有命令的逐行历史。该历史文件允许你如前所述，使用键盘方向箭头滚动查看之前执行过的命令。

## 1.3.2 脚本

对于需要超出少量代码编辑器功能的任务，你通常会想要使用内置的代码编辑器。因此，保存脚本至少与保存工作空间一样重要，甚至更为重要。

你可以将编辑器脚本保存为具有 .R 扩展名的纯文本文件（见第 1.2.1 节）；这允许你的操作系统默认将这些文件与 R 软件关联。要从内置编辑器保存脚本，请确保已选择编辑器并导航到 文件 → 保存（或在 Windows 中按 CTRL-S，在 OS X 中按 ⌘-S）。要打开以前保存的脚本，在 Windows 中选择 文件 → 打开脚本... (CTRL-O)，或在 OS X 中选择 文件 → 打开文档... (⌘-O)。

通常情况下，如果你保存了脚本，其实并不真的需要保存工作空间的 .RData 文件。一旦在新的 R 会话中重新执行任何所需的命令，创建的对象（换句话说，即包含在保存的 .RData 文件中的对象）就会被再次创建一次。这在你同时处理多个问题时非常有用——如果仅依赖默认工作空间，很容易不小心覆盖它。因此，保持你的 R 脚本集分开是分离多个项目的简单方法，而无需担心会覆盖之前可能存储的任何重要内容。

R 还提供了许多将单个对象（例如数据集和绘图图像文件）写入磁盘的方法，我们将在第 8 章中介绍。

## 1.4 规范

在书中呈现代码和数学公式时，我将遵循一些规范。

### 1.4.1 编码

如所述，当你用 R 编写代码时，你会在控制台中执行代码，可能先在编辑器中写好脚本。以下几点需要注意：

- 直接输入控制台执行执行的 R 代码前面会带有 R > 提示符，后面紧跟在控制台中显示的任何输出。例如，第 2.1.1 节中这个 14 除以 6 的简单除法如下：

```
R> 14/6
[1] 2.333333
```

- 对于在控制台中执行前应在编辑器中编写的代码，我会在文中指出，且呈现的代码将不带提示符。以下示例来自第 10.2.1 节：

```
for(myitem in 5:7){
cat("--BRACED AREA BEGINS--\n")
cat("the current item is-",myitem,"\n")
cat("--BRACED AREA ENDS--\n")
}
```

随着你对第二部分的学习，我对于实际排列和缩进此类代码块的偏好编码风格将变得清晰。

- 偶尔会有长行代码（无论是直接在控制台中执行还是在编辑器中编写），为了打印考虑，它们将在适当的位置进行折行和缩进以适应页面。例如，第 6.2.2 节中的这一行：

```
R> ordfac.vec <- factor(x("Small","Large","Large","Regular","Small"), levels=c("Small","Regular","Large"), ordered=TRUE)
```
虽然可以使用 R 将其写成单行，你也可以在逗号处折行（在这种情况下，逗号将参数拆分到相关函数左括号的层级）。折行后的行将与左括号对齐。无论是单行还是拆分的形式，在 R 中执行时都是有效的。

- 在某些地方，当控制台输出很长且对你理解当前内容至关重要时，为了打印将对其抑制。我会在文中说明，你会在影响的代码块中看到 --snip-- 标记。

### 1.4.2 数学和公式引用

书中出现的数学内容和公式（主要在第三和第四部分）将保持在最少，但在某些章节中有时必须进入一些数学细节。
重要的公式将按所示单独显示：

```
y = 4x  (1.1)
```

公式将用括号编号，文中对公式的引用将使用这些括号内的数字，并可能带有或不带有“Equation”一字。例如，你将看到这两种方式的引用：

- 如公式 (1.1)，当 x = 2 时，y = 8。
- (1.1) 的逆运算得到 x = y/4。

当数值结果四舍入到特定程度时，将根据小数位数进行说明，缩写为 d.p.。以下是一些示例：

- 著名的几何数值 pi 值为 3.1416 (4 d.p.)。
- 设置 x=1.467 得到 5.87 (2 d.p.)。
