# 5 列表 (LISTS) 与数据框 (FRAMES)

![](img/b2cf85cbb12f60fe95a274)

向量、矩阵和数组是 R 中高效且方便的存储结构，但它们有一个局限性：在本章中，你将探索另外两种结构：列表和数据框，它们可以同时存储多种类型的值。

### 5.1 对象列表

列表是一种非常实用的结构。它可以将任何混合对象组合在一起。单个列表可以包含数值矩阵、逻辑数组、单个字符字符串和一个因子对象。你甚至可以将列表作为另一个列表的组件。在本节中，你将看到如何创建、修改和访问组件。

### 5.1.1 定义与组件访问

创建列表与创建向量非常相似。你用逗号分隔并将想要包含的元素提供给 `list()` 函数。

```R
foo <- list(matrix(data=1:4, ncol=2), c(T,F,T,T), "hello")
foo
[[1]]
 [1,] 1 3
 [2,] 2 4

[[2]]
 [1] TRUE FALSE TRUE

[[3]]
 [1] "hello"
```

在列表 `foo` 中，你存储了一个 2x2 数值矩阵、一个逻辑向量和一个字符字符串。它们按照你提供的顺序打印。与向量一样，你可以使用 `length` 函数来检查列表中的组件数量。

```R
length(foo)
[1] 3
```

你可以使用双括号 `[[ ]]` 中的索引从列表中检索组件。

```R
foo[[1]]
 [1,] 1 3
 [2,] 2 4
foo[[3]]
 [1] "hello"
```

这种操作被称为成员引用（member reference）。当你检索到一个组件时，你可以像处理独立对象一样处理它。

要覆盖 `foo` 的某个成员，使用赋值运算符。

```R
foo[[3]] <- paste("hello", "you!")
```

假设你现在想访问 `foo` 的第二个和第三个组件，并尝试像 `foo[[2,3]]` 这样的这种操作：

```R
foo[[2,3]]
```

但 R 并没有按照你预期的的方式操作。相反，它返回了第二个组件的第三个元素。这是因为在列表上使用双括号总是被解释为：你想要的是单个成员。幸运的是，你可以通过这种方法通过列表切片选择多个列表项。

```R
bar <- foo[[c(2,3)]]
bar
[[1]]
 [1] FALSE TRUE

[[2]]
 [1] "hello!"
```

注意结果 `bar` 本身是一个列表，按照你请求的顺序存储两个组件。

### 5.1.2 命名

你可以命名列表组件，以便元素更容易识别和处理。就像你在第 4.3.1 节中看到的关于因子能级的信息一样，名称是 R 的属性。

让我们从给早期的列表 `foo` 添加名称开始。

```R
names(foo) <- c("mymatrix", "mylogicals", "mystring")
foo
$mymatrix
 [1,] 1 3
 [2,] 2 4
```

```R
$mylogicals
 [1] FALSE TRUE
```

```R
$mystring
 [1] "hello!"
```

这改变了对象在控制台的打印方式。之前在每个组件前打印 `[[1]]`、`[[2]]` 和 `[[3]]`，现在它打印你指定的名称：`$mymatrix`、`$mylogicals` 和 `$mystring`。你现在可以使用这些名称和美元运算符 `$` 来执行引用，而不是使用方括号。

```R
foo$mymatrix
 [1,] 1 3
 [2,] 2 4
```

这等同于调用 `foo[[1]]`。事实上，即使对象经过命名，你仍然可以使用数值索引来获取成员。

子集成员也同样工作。

```R
all(foo$mymatrix[[2]]=foo[[1]][2]])
[1] TRUE
```

这证实了（使用你在 4.1.2 节中使用的 `all` 函数）这两种提取 `foo` 中矩阵第二列的方法提供了相同的结果。

要在创建列表时命名其组件，可以在 `list` 命令中为每个组件分配标签。使用某些值创建一个新名称。

```R
baz <- list(tom=c(foo[[2]],T,T,T,F), dick="g'day mate", harry=foo$mymatrix*2)
baz
$tom
```
