There are specialized packages that incorporate R code into the compilation of these documents. These are in turn incorporated into RStudio, allowing you to create dynamic documents that make use of R and graphics without switching between different applications.

You will need a LaTeX installation on your computer to use these tools, which you can find at https://www.latex-project.org/. In this section, I briefly discuss the most widely used enhancements.

# 5 Sweave

Sweave (Leish, 2002) was arguably the first markup language to become popular with R; its functionality is included with any standard R installation. Sweave follows typical LaTeX markup rules; in your document, you declare special fields called *chunks*, in which you write R code and any corresponding output to be displayed; the output can include both text and graphics. When you compile the Sweave file (which has a .Rnw extension), the R code fields set to R for live evaluation, with the results appearing in the specified places of the finished product. To start a new document, choose File → R Sweave, as shown in Figure 8. For more examples and resources, see the Sweave home page at https://www.statistik.tmu.de/~leish/Sweave/.
