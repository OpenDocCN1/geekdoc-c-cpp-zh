Both CIs and PIs are well suited to visualization for simple linear regression
models. With the following code, you can start Figure 20-3 by plotting the
data and estimated regression line just as for Figure 20-2, but by this time
xlim and ylim to widen the x- and y-limits a little in order to accommodate the full height and length of the CI and PI.

r> plot(survey$height~survey$Hnd,xlim=c(13,24),ylim=c(140,205),

To add the locations of the fitted values for x = 14.5 and x = 24,

```
r> points(xvalls[1],mypred.ci[1,1],pch=8)

r> segments(x0=c(14.5,24),y0=c(mypred.ci[1,2],mypred.ci[2,2]),

```

The call to points marks the fitted values for these particular values
x. The first call to segments lays down the PIs as thickened gray lines,
the second lays down the CIs as the shorter black lines.
The coordinates for these plotted line segments are taken directly from the
mypred.pi and mypred.ci objects.
