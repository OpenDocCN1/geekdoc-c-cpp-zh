centered predictor data are then used in place of the original (untranslated) data. The resulting fitted model allows you to use the mean value of the untranslated predictor (in this case handspan) rather than a zero value in order to directly interpret the intercept-$\beta_0$.

# 21.3.3 Visualizing the Multiple Linear Model

As shown here, "being male" simply changes the overall intercept by around 9.49 cm.

```
R> survcoeffs <- coef(survmult)
R> survcoeffs
(Intercept) Wr.Hnd SexMale
137.68951 1.59444 9.49814
R> as.numeric(survcoeffs[1]+survcoeffs[3])
[1] 147.168
```

Because of this, you could also write (21.4) as two equations. Here's the equation for female students:

> "Mean height" = 137.687 + 1.594 × "handspan"

Here's the equation for male students:

> "Mean height" = (137.687 + 9.4989) + 1.594 × "handspan"
= 147.177 + 1.594 × "handspan"

This is handy because it allows you to visualize the multivariate model in the same way as can the simple linear models. Figure 21-1:

```
R> plot(surveyHeight-survey$Wr.Hnd,
col=("gray", "black")[as.numeric(survey$Sex)],
pch=16,xlab="writing handspan",ylab="Height"
R> abline(a=survcoeffs[1],survcoeffs[2],col="gray",lty=2)
R> abline(a=survcoeffs[1]+survcoeffs[3],survcoeffs[2],col="black",lty=2)
R> legend("topleft",level=levels(survey$Sex),col("gray","black"),pch=16)
```

First, a scatterplot of the height and handspan observations, by split by sex, then abline adds the line corresponding to females and adds a second one corresponding to males, based on two equations.

Although this plot might look like two separate linear model fits, one for each level of sex, it's important to recognize that isn't the case. You're effectively looking at a representation of a multivariate model on a two-dimensional canvas, where the statistics determine the fit of the two visible lines have estimated "jointly", in other words, when considering predictors.
