Let's see what happens when the vectors are not evenly divisible.

```
R baz <- c(1,-1.0,-0.5)
R foo+=baz
[1] 5.50 -4.50 1.75 -1.25 1.50 -0.50
Warning message:
 foo + baz :
longer object length is not a multiple of shorter object
```

Here you see that R has matched the first four elements of foo with the entirety of baz, it's not able to fully repeat the vector again. The repetition has been attempted, with the first two elements of baz matching with the last two of the longer foo, though without a protest from R, which notifies the user of the uneven divisible lengths (you'll look at warnings in more detail in Section 12.1).
