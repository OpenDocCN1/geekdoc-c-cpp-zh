# Plotting the Log Transformation Fit

To visualize the fitted model, you first need to calculate the fitted values for all predictor values. The following code creates a sequence of horsepower-values (minus plus 20 horsepower) and performs the required prediction for these values.

```
R hp.seq <- seq(min(mtcars$hp)-20,max(mtcars$hp)+20,length=30)
R n <- length(hp.seq)
R car.log.pred <- predict(car.log,newdata=data.frame(hp=hp.seq,am=rep(c(0,1),each=n)))

```

In the above code, you want to plot predictions for values of am, using newdata you need to replicate hp seq. Then, when you provide values for am to newdata, one series of hp.seq is paired with an appropriately replicated am value of 0, the other with 1. The result of this is a vector of predictions of length that of hp.seq,car.log.pred, with the first n elements corresponding to automatic cars and the latter n to manuals.
Now you can add these lines to Figure 2-6 with the following:

```
R lines(hp.seq,car.log.pred[1:n])
R lines(hp.seq,car.log.pred[(n+1):(2*n)],col="gray")n
```
