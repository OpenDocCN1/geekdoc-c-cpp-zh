
The key takeaway here is that y isn't calculated as a direct result of x in the same way as you might obtain a fine, evenly spaced increasing sequence in x and evaluate y when plotting, for example, a linear regression model. Rather, the equations in (26.1) jointly define the rules of the locus in the 2D space.

## 3D Cylinder

Plotting surfaces with three dimensions is done in much the same way, only your equations set up the rules for all satisfying points in the x, y, and z-axes.

For example, points lying on a hollow cylinder can be defined by the following equations:

```
x = r cos(theta), y = r sin(theta), and z = z  (26.2)
```

To actually plot plots that satisfies rules, you need to decide on a fixed radius r, recognize that 0 ≤ theta < 360 (in degrees), and define a fixed maximum height h that you can ensure 0 ≤ z ≤ h. With information, to generate vectors for x, y, and z, you need to first set up numeric spanning the possible values of theta and z. Consider the following:

```
r <- 3
h <- 10
zseq <- 0:h
theta <- 0.360*(pi/180)
```

These lines show a radius of 3 set as r and a maximum height of 10 as h. The sequence in z is set up as the 11 integer values from 0 to 10 in zseq—this will allow you to place points on the axis of each of these defined z values. The sequence for theta is set up as 0 ≤ theta < 2pi in theta (the necessary conversion to radians). Then, you need all unique combinations of these parameters (x,y,z) coordinates for plotting. You know how to do that from Section 25.3, using expand.grid.

```
zheta <- expand.grid(zseq, theta)
nrow(zheta)
[3971]
```

Calling nrow on the result shows that you now have 11 × 361 = 3971 unique height-angle values. You're able to generate the values for x, y, and z as defined by (26.2). You could use a for loop (Section 10.2.1), cycling through each row of zheta, but a better way would be to use implicit looping in apply (refer to Section 10.2.3 for details).

```
x <- apply(zheta,1,function(vec) r*cos(vec[2])
y <- apply(zheta,1,function(vec) r*sin(vec[2])
z <- apply(zheta,1,function(vec) vec[1])
```

Note that disposable functions (see Section 11.3.2) are used to operate on the two-element height-angle (in that order) vectors that make up each row of zheta.

You can use persp3d from rgl to plot this kind of parametrically defined surface, but in a slightly different way than in earlier sections of this chapter. The calculated x, y, and coordinates must now be supplied as identically sized, appropriately arranged matrices. This is because there's no longer an evenly spaced evaluation grid in the x and y coordinates—along with the z values, the x and y values have all been defined through an application of (26.2). In these types of plots, you effectively have a latent evaluation grid defined by the unique combinations of parameter values (height and angle in this case).

The matrices in the x, y, and z-coordinates are given by the three 11×361 matrices filled with x, y, and z in the typical column-wise fashion.

```
x <- matrix(x,length(zseq),length(theta))
ym <- matrix(y,length(zseq),length(theta))
zm <- matrix(z,length(zseq),length(theta))
```

At this point, it's worth mentioning the built-in outer function, which takes a sequence of values in two variables and produces all unique combinations of values, computes the result at each combination, and then returns the results as a matrix—doing the three tasks just done by expand.grid, apply, and matrix in one. With this approach, you could create xm, ym, and zm by simply calling the following:

```
xm <- outer(zseq,theta,function(z,t) r*cos(t))
ym <- outer(zseq,theta,function(z,t) r*sin(t))
zm <- outer(zseq,theta,function(z,t) z)
```

The only difference here is that the anonymous function provided as the third argument must be explicitly defined in terms of two separate arguments that represent the values of the necessary height and angle parameters.

However you obtain xm, ym, and zm, it's just a matter of calling persp3d with these coordinate matrices. Make an additional call to points3d to emphasize the precise evaluation points that are in those matrices. The result of the next lines is shown on the left of Figure 26-17.

```

```

## 3D Cone

This example will show that once you understand the procedure involved with setting up the x, y, and z coordinate matrices, you can display virtually any 3D shape or surface with them. Taking r, h, and theta to be the base radius, maximum height, and angle, respectively, a cone follows these equations:

```
x = \frac{-z}{h}r\cos(\theta), \quad y = \frac{h-z}{h}r\sin(\theta), \quad \text{and} \quad z = z \quad (26.3)
```

Using the same objects r, h, zseq, and that from earlier, the following code alters the disposable functions in order to reflect (26.3). The right of Figure 26-7 shows result.

```
xm <- outer(zseq,function(z,t), (h-z)/h*r*cos(t))
ym <- outer(zseq,function(z,t), (h-z)/h*r*sin(t))
zm <- outer(zseq,function(z,t), z)
persp3d(x=xm,y=ym,z=zm,col="green")
```
