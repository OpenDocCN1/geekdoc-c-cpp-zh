Note a number of new additions to the basic ggplot setup. The default mapping, by cyl, remains the same as earlier. You further specify that the bars should be filled according to a factor created by the transmission variable am, so each cyl bar is instructed to split by that variable. The initial call to ggplot="empty", in the sense that geom="blank", and therefore drawing with the addition of geom_bar to the ggplot object. It becomes a dodged barplot through position="dodge"; in R Graphics, the default behavior is to generate a stacked plot. the scale_x_discrete modifier labels for each category of the default cyl mapping; the scale_y_continuous modifier is employed to control the axis labels for the frequencies.

Further, adding theme_[] to the object changes the visual theme of the image; in the current example, I've chosen to remove the gray background because it's too similar to the manual car bars. Adding color_flip to the object flips the axes and provides horizontal bars rather than the default vertical style (note that the calls to the scale functions are used with respect to the unmapped image). The default behavior of fill is to use colors, so you use the scale_fill_grey modifier to find this by grayscale and to scale the labels of the automatically generated to match at the same time.

The most prominent advantage of using ggplot2 over this case lies in the fact that you don't need to manually tabulate counts or design matrix structures of these frequencies—the variable mapping does this automatically. For practice, I encourage you to experiment with this code, omitting or modifying some of the additions to the ggplot object to assess the impact on the resulting image.
