# # The R Project for Statistical Computing

# Getting Started

R is a free software environment for statistical computing and graphics. It compiles and is available on a variety of UNIX platforms, Windows and macOS. To download R, please choose your preferred CRAN mirror.

If you have questions about R how to download and install it, or what this is for, please read our answers to frequently asked questions before you join.
