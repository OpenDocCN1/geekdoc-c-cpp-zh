# 14.4.1 Single Plot

You can modify a simple scatterplot to split the plotted points to a
categorical variable, exposing potential differences between any visible rela-
ships with respect to the continuous variables. For example, using base
R graphics, you can examine the petal measurements according to the three
species. Using the "settingstone" approach first explained in Chapter 7,
you can manually build up this plot by using type="n" to generate an
empty plotting region of the correct dimensions and subsequently adding
points to each species, altering point character and color
as desired.

```
R> plot(iris[4],iris[3],type="n",xlab="Petal Width (cm)",
yabb="Petal Length (cm)"
R> points(iris[iris$Species==setosa",4],
     iris[iris$Species==setosa",3],pch=19,col="black")
R> points(iris[iris$Species==virginica",4],
     iris[iris$Species==virginica",3],pch=19,col="gray")
R> points(iris[iris$Species==versicolor",4],
     iris[iris$Species==versicolor",3],pch=19,col="black")
R> legend("topleft",legend=("setosa","virginica","versicolor",
     col=c("black","gray","black"),pch=c(19,19,19))
```

You can find the plot in Figure 14-8. Note that the Iris virginica
species has the largest petals, followed by Iris versicolor, and the smallest
petals belonging to Iris setosa. However, this code, while functional, is fairly
ccumbersome. You can generate the same image by first setting
vectors that specify the desired point character and color for each individ-
ual observation.
