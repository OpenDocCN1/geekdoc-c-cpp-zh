## 4.2.4 子字符串与匹配

模式匹配允许你检查给定的字符串以识别其中的较短字符串。

`substr` 函数接收一个字符串 `x` 并提取两个字符位置之间（包含）的字符串部分，这些位置通过作为 `start` 和 `stop` 参数传递的数字指定。让我们对第 4.2.1 节中的对象 `foo` 进行尝试。

```R
R> foo <- "This is a character string!"
R> substr(x=foo,start=21,stop=27)
[1] "string!"
```

在这里，你提取了位置 21 到 27（包含）之间的字符，得到 "string!"。`substr` 函数也可以配合赋值运算符使用以替换一组新字符。在这种情况下，替换字符串的字符数应与所选区域的相同。

```R
R> substr(x=foo,start=1,stop=4) <- "Here"
R> foo
[1] "Here is a character string!"
```

如果替换字符串比 `start` 和 `stop` 指定的字符数长，替换仍然发生，从 `start` 开始到 `stop` 结束。它会截掉任何超出你替换的字符数的字符。如果字符串短于你替换的字符数，则替换在字符串完全插入时结束，剩下的原始字符保持不变。

使用 `sub` 和 `gsub` 函数进行替换会更灵活。`sub` 函数搜索包含在内的较小字符串模式。它会将第一个出现的实例替换为作为参数提供的新字符串。`gsub` 函数执行相同的操作，但它会替换每个模式实例。这里有一个例子：

```R
R> bar <- "How much wood could a woodchuck chuck"
R> sub(pattern="chunk",replacement="hurl",x=bar)
[1] "How much wood would a woodlurl chuck"
R> gsub(pattern="chuck",replacement="hurl",x=bar)
[1] "How much wood would a woodlurl hurl"
```

使用 `sub` 时，替换值不需要与被替换的模式具有相同的字符数。这些函数还有搜索选项，例如大小写敏感。帮助文件 `?substr` 和 `?sub` 提供了更多详细信息，并提到了一些其他模式匹配函数和技术。你可能还想检查 `grep` 命令及其变体；请查看相关的帮助文件 `?grep`。

## 4.3 因子 (Factors)

在本节中，你将查看一些与创建、处理和检查因子相关的简单函数。因子是 R 表示符合有限数量不同类别且仅属于其中一类的数据点的最自然方式，而不是属于某个连续体。这类类别数据在数据科学中可以起着重要作用，你将在第 13 章从统计学角度再次详细查看因子。

## 4.3.1 识别类别

为了了解因子的工作原理，让我们从一个简单的数据集开始。假设你找到了八个人，并在表 4-4 中记录了他们的名字、性别和出生月份。

表 4-4：八个个的示例数据集

| 人员 | 性别 | 出生月份 |
|---|---|---|
| Liz | 女 | 四月 |
| Jolene | 女 | 一月 |
| Susan | 女 | 十月 |
| Boris | 男 | 九月 |
| Rochelle | 女 | 十月 |
| Tim | 男 | 七月 |
| Simon | 男 | 七月 |
| Amy | 女 | 六月 |

为了看到因子的工作方式，在 R 中表示每个人的唯一合理方式是字符字符串向量。

```R
R firstname <- c("Liz", "Jolene", "Susan", "Boris", "Rochelle", "Tim", "Simon", "Amy")
```

然而，在记录性别时有更大的灵活性。将女性编码为 0，男性编码为 1，数值选项如下：

```R
R sex.num <- c(0,0,0,1,0,1,1,0)
```

当然，字符字符串也是可能的，许多人喜欢这种方法，因为不需要记住每个组的数字代码。

```R
R sex.char <- c("female", "female", "female", "male", "female", "male
```

然而，字符字符串和因子之间存在本质区别。因子本质上是存储整数的向量，映射到一组字符水平。这对于具有有限可能的类别数据特别有用。

因子使用 `factor()` 函数创建，该函数接收一个向量和一个可选的水平集合。如果没有指定水平，R 将使用向量中的唯一值作为水平。

```R
R> factor(c("female", "female", "female", "male", "female", "male", "male", "female"))
[1] female female female male female male female
Levels: female male
```

你也可以在创建因子时指定水平，如果你希望水平按照特定顺序排列，这就会很有用。

```R
R> factor(c("female", "female", "female", "male", "female", "male", "male", "female"), levels = c("male", "female"))
[1] female female female male female male female
Levels: male female
```

因子的主要优势是你可以对其进行某些操作。例如，你可以计算因子中每个水平的数量。

```R
R> table(factor(c("female", "female", "female", "male", "female", "male", "male", "female")))
  male female 
     3      5
```

```R
R> sex.num <- c(0,0,0,1,0,1,1,0)
R> sex.num.factor <- factor(sex.num, levels = c(0,1), labels = c("female", "male"))
R> table(sex.num.factor)
  female male 
       5      3
```

因子在建模中也有用，它们可以被自动视为类别变量。在下一节中，你将探索如何在线性模型中使用因子。
