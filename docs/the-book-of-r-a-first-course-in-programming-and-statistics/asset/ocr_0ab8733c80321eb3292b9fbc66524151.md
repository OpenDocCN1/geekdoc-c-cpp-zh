Before calling perspd3, it's worth remembering that you should consider the aspect ratio in the x- and y-coordinates. As you see in Section 26.1, the aspect argument in rgl functions a little differently than the asp argument in image or the scale/aspect expands in persp. In rgl plots, including perspd3, aspect requests a numeric vector of length 3, which defines the relative scale of the x-, y-, and z-axes, in that order.
To determine the appropriate relative scale for the Charley-Ribble data, you need to calculate the total x-axis and y-axis widths that the study is defined upon and find their ratio.

```
R x <- chor.WIN$xrange[2]-chor.WIN$xrange[1]
R x
[1] 23
R yd <- chor.WIN$yrange[2]-chor.WIN$yrange[1]
R yd
[1] 21.38
R x/yd
[1] 1.075722
```

This was done using the $xrange and $yrange components of the spatstat polygon, subtracting the lower limit from the upper in each case. The final ratio of x/yd reveals that you almost have a one-to-one scale, which technically means the region is physically wider in the x-axis, by a factor of around 1.076, than it is in the y-axis.
Ffactoring that in, you can call perspd3 to plot the KDE surface correctly.

```
R perspd3(chor.dens.WIN$x,chor.dens.WIN$y,chor.dens.WIN$z,
colrow=[zm.colors],aspect=(xd/yd,1,0.75),
lab="Eastings (km)",ylab="Northings (km)",nlab="Kernel")
```

You use aspect to stipulate that the x-axis should be scaled according to a factor of x/yd relative to the y-axis, that y is taken as the reference scale of 1, and the z-axis should be squashed by a factor of 0.75 relative to the y-axis. This is arbitrarily set so that the graphic is similar to the original in Figure 25-21 on page 685.
