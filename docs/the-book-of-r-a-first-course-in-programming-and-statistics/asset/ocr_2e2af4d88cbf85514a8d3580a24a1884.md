Estimating the model parameters in this way is referred to least-squares regression; the reason for this will become clear in a moment.

# 20.2.3 Fitting Linear Models with lm

In R, the command lm performs the estimation for you. For example, the following lines create a fitted linear model object of the mean height by handspan and stores it in your global environment asfit:

```
R> survfit <- lm(Height~Wr.Hnd,data=survfit)
```

The first argument is the now-familiar response ~ predictor formula, which specifies the desired model. You don't have to use the survey prefix to extract the vectors from the data frame unless you specifically instruct lm to look in the object the data argument.

The fitted linear model object itself, survfit, has a special class in R—one of "lm". An object of "lm" can be thought of as a list containing several components that describe the model. You’ll look at these in a moment.

If you enter the name of the "lm" object at the prompt, it will provide the most basic output: a repeat of your call and the estimates of the intercept (β0) and slope (β1).

```
R> survfit
```

```
Call:
lm(formula = Height ~ Wr.Hnd, data = survfit)
```

Coefficients:

| (Intercept) | Wr.Hnd |
| 113.954 | 3.117 |

This reveals that the linear model for this example is estimated as follows:

> ŷ = 113.954 + 3.117x (20.4)

If you evaluate the mathematical function for x, you will see a straight line when you plot the results. Considering the range of values for x, you will see a straight line Considering the definition of intercept given earlier as the expected value of the response variable when the predictor is zero, in the current example, this would imply that the mean height of a student with a handspan of 0 cm is 113.954 cm (arguably less-than-useful statement since a value of 0 for the explanatory variable doesn't make sense; you’ll consider these and related issues in Section 20.4). The slope, the change in the mean response for each one-unit increase in the predictor, is 3.117. This states that, on average, for every 1 cm increase in handspan, a student's height is estimated to increase by 3.117 cm.
