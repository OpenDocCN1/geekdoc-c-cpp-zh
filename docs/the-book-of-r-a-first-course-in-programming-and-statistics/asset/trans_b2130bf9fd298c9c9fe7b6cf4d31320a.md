R abline(h=c(-5,5),col="red",lty=2,lwd=2)

- 3. 第三行代码在步骤 2 绘制的水平线之间添加较短的垂直线以形成一个框。对于这种情况请使用 `segments` 而不是 `abline`，因为你不希望这些线跨越整个绘图区域。`segments` 命令接收一个“起始”坐标（由 x0 和 y0给出）和一个“结束”坐标（由 x1 和 y1给出），并绘制相应的线。R 的向量化行为匹配了“起始”和“结束”坐标集。两条线都是红色点状的，并且具有双倍厚。（你也可以为这些参数提供长度为 2 的向量，在这种情况下，第一段线将使用第一个参数值，第二个线段将使用第二个参数值。）

```
R segments(x0=c(5,15),y0=c(-5,-5),x1=c(5,5),col="red",lty=3,lwd=2)
```

- 4. 在步骤 4 中，你使用 `points` 开始向图表添加特定的 x 和 y 坐标。与 `plot` 一样，`points` 接收两个长度相同的 x 和 y 向量。在这种情况下，你希望根据位置以不同的方式绘制点，因此使用逻辑向量子集（第 4.1.5 节）来识别并提取 y 大于等于 5 的 x 和 y 元素（仅添加这些点），以紫色 x 符号添加，并放大 2 倍 cex。

```
R points(x[y>=5],y[y>=5],pch=4,col="magenta",cex=2)
```

- 5. 第五行代码类似于第四行；这次它提取了 y 值小于或等于 -5 的坐标。使用了 `+` 字符，并将颜色设置为深绿色。

```
R points(x[y<-5],y[y<-5],pch=3,col="darkgreen",cex=2)
```

- 6. 第六步添加了蓝色的“甜点区”点，这些点通过 (x>=5&x<15&y>-5&y<5) 识别。这个稍微复杂的逻辑提取了 x 位置在 5 到 15 之间（包含）且 y 位置在 -5 到 5 之间（不包含）的点。注意，此行使用了逻辑运算符 & 的“简短”形式，因为你在这里使用了逐元素比较（见第 4.1.3 节）。

```
R points(x[(x>=5&x<15&y>-5&y<5)],y[(x>=5&x<15&y>-5&y<5)],pch=19,col="blue")
```

- 7. 下一个命令识别数据集中的剩余点（x 值小于 5 或大于 15，且 y 值在 -5 到 5 之间）。没有指定图形参数，因此这些点用默认的黑色绘制。

```
R points(x[(x<5|x>15)&(y>-5|y<5)],y[(x<5|x>15)&(y>-5|y<5)])
```

- 8. 要绘制连接坐标的线，你使用 `lines`。9. 第九行代码添加了箭头。10. 第十行代码在顶部绘制了一个标签。

```
R lines(x,y,lty=4)
```

R text(x=8,y=15,"sweet spot")
