# The dunif function

You can use the built-in $d$-function for the uniform distribution, dunif, to return these heights for any value within the defined interval. The dunif command returns zero for values outside of the interval. The parameters of the distribution, $a$ and $b$, are provided as the arguments $min$ and $maxmax$, respectively. For example, the line

```
dunif(x=c(0.2,-0.23,0.0,1.05,1.2),min=-0.4,max=1)
```

+   [1] 0.000000 0.0666667 0.0666667 0.0666667 0.0666667 0.000000

evaluates the uniform density function of $X \sim \text{UNIF}(-0.4,1.1)$ given in the vector passed to $x$. You'll notice that the first and last values fall outside the bounds defined by $min$ and $max$, and so they are zero. All others evaluate to the height value of $2/3$, as previously calculated.\nAs second example, the line

```
dunif(x=c(0.3,0.0,0.41),min=0.223,max=0.41)
```

+   [1] 5.37594 0.000000 5.37594

confirms the correct density values for $X \sim \text{UNIF}(0.223,0.410)$ distribution, with the second value, zero, falling outside the defined interval.

This most recent example in random variables should remind you that probability density functions for continuous random variables, *do not* directly provide probabilities, as we have mentioned in Section 15.2. In other words, the results returned by density functions represent themselves and not any of change attached to the specific values of $x$ at which they were evaluated.\nTo calculate some probabilities on the uniform density function, use the example of a faulty drill press. In a woodworker's shop, imagine there's a drill press that cannot keep to a constant alignment when in use; it randomly hits the intended target. The random variable $X \sim \text{UNIF}(-0.4,1.1)$ represents where the drill hits the material relative to the target at 0 up to 0.4 cm to the left or 1.1 cm to the right.
