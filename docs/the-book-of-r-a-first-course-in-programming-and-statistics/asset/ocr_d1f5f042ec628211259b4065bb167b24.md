In this instance, multiplying it by a factor of around 250 provides a visually pleasing result. Note that this would not be necessary if you left the scale argument at its default TRUE value (since, in that case, R internally scales three axes for a one-to-one-to-one aspect ratio).

# 25.6.3 Rotating with Loops

There's one last bit of fun you can have with perspective plots if you want to get an overall impression of the plotted surface. Using a simple for for loop (Section 10.2.1) to increment theta or phi, you can perform a series of repeated calls to persp, each one at a slightly new angle. Doing this in sequence results in an animation—essentially a cartoon—of a rotating surface, allowing you to see it from all sides.

Consider the following basic function in the R editor:

```
persprot <- function(skip=1,...{
  for(i in seq(90,360,by=skip)){
    persp(phi=i,theta=0,...)
  }
  for(i in seq(0,360,by=skip)){
    persp(phi=20,theta=i,...)
  }
n}
```

Using an ellipsis (see Section 11.2.4), prosprot simply takes all the arguments you usually supply to a call to persp, barring theta and phi. Then comes a for loop, which immediately calls persp with theta=0 and the content of the ellipse. The for loop alters the vertical viewing angle, starting with phi=90 (birds-eye view) and moving down to a mildly elevated phi=20. A second loop then completes a full 360-degree horizontal rotation by rotating theta.

The only formally tagged argument is skip, which determines the amount phi and theta increment by each iteration. The default, skip=1, simply moves over the integer-valued angles. Increasing skip will reduce the time it takes to complete the rotation, though it makes for a more jagged animation.

Depending on the type of graphics devices you're using, you may want to experiment with skip. Note that not all graphics devices are well suited to the animation effect by this rough function (for example, it's not appropriate if you're using RStudio—see Appendix B). That said, when running the base GUI applications on OS X or Windows, I find persp works well under default graphics settings.
