

# 前言

《R语言教程：编程与统计学入门》这本书旨在为读者提供一个相对温和且信息丰富的 R 统计软件环境介绍，同时介绍一些常用的统计分析方法，以便读者能够打下坚实的基础，最终成为各自领域的专家。学习使用和编写计算机语言与学习一门新的口语非常相似。在开始阶段，这通常是困难且令人令畏的——但沉浸并积极使用这种语言是变得精通的最好、最有效的方法。

许多专注于 R 的入门级书籍通常可以分为两类：一类关注计算方面（即语法和通用编程工具），另一类则关注统计建模和分析，且通常侧重于某一个特定类型。根据我的经验，这些书籍写得非常好，包含了大量的有用信息，但更适合那些从一开始就想追求非常特定目标的人。而本书试图结合这两种者的长处：首先专注于对该语言及其风格的欣赏与理解，随后利用这些技能来完整地介绍、执行和解释一些常见的统计实践。目标读者群简单来说就是任何想将 R 作为第一门计算机语言来立足的人，或许最终目标是完成他们的统计分析。这包括但不限于本科生、研究生、学术研究人员以及对编程或通用统计学几乎或没有经验的应用科学从业者。对基础数学行为（例如运算顺序）和相关运算符（例如求和符号 Σ）有基本的理解是理想的。

鉴于此，《R语言教程》可以纯粹作为编程书籍来学习这种语言，也可以作为一本带有 R 指导的入门统计方法书籍。尽管它并不代表对该语言的详尽探索，但其目标是为读者提供一个舒适的学习工具，消除像我这样从零开始考虑 R 的人所产生的对畏难的恐惧。事实是，完成任何任务通常有许多不同的方法——对于所谓的高层计算机语言也是如此。本书呈现的是我个人学习和使用 R 编程的方式，我是从一个计算机科学家、更多是作为一个应用分析者的角度来处理它的。

在这里，我的目标是为 No Star Press（2011年）出版的另一本 R 语言书籍《R编程艺术：统计软件设计之旅》（The Art of R Programming: A Tour of Statistical Software Design）提供该，由加州大学的 Norman Matloff 教授编写。在他详尽且受欢迎的书中，Matloff 教授从计算机科学的角度切入 R，即将其视为一种独立的编程语言。因此，《R编程艺术》提供了我目前所过的对 R 计算特性的最佳描述之一（例如，从 R 程序运行如 C 等外部代码，处理和操作 R 的内存分配，以及正式的调试策略）。然而，值得注意的是，具备一些之前的编程经验和知识对于理解其中的一些高级特性大有裨益。我希望我的书籍不仅能提供这种经验，而且在 R 语言本身中以舒适的节奏完成，并将统计分析作为辅助动力。

本书作为我们背包穿行“R 语言国度”的“旅行指南”，诞生于我在新西兰奥塔哥大学举办的一个为期三天的入门研讨会。重点在于软件的积极使用，每个章节都包含许多代码示例和练习题以鼓励互动。对于没有参加研讨会的读者，只需打开电脑，拿上一杯饮料，找一把舒服的椅子，然后从第一章开始吧。

Tilman M. Davies
新西兰，邓尼丁

R 在各种研究和数据分析项目项目中起着关键作用，因为它让许多现代统计方法（无论简单还是复杂）变得触手可用。然而，事实是，R 的初学者通常对通用编程很陌生。作为初学者，你不仅必须学习如何使用 R 实现你特定的数据分析目标，还必须学会像程序员一样思考。
