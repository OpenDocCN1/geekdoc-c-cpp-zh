# Installing Packages Using Local Files

Lastly, you can download the required packages from CRAN through your Internet browser as you download anything else, store them on your local drive, and then R to local files.

On the CRAN web page for ks, you'll find a Downloads section as shown in Figure A-8. For Linux, Windows or OS, choose the corresponding .zip or .pkg labeled r-release. The r-oldest and r-devel versions should be used only if you're experiencing compatibility issues. The Old source links are archived for older versions.

On Windows, select Packages -> Install package(s) from local zip... (on the left of Figure A-6). This will open a file browser so you can navigate to the downloaded .zip file for the package; R will not.
