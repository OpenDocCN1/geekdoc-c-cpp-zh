The parameter $\lambda_e$ is provided to rate in dex, which is evaluated at $x$, provided to the first argument $x$ (via the xvals object in this example). You can see that a distinct feature of the exponential density function is that aforementioned decay to zero, with larger values of $\lambda_e$ translating to a taller (yet sharper and more rapid) drop.

This naturally decaying behavior helps identify the exponential distribution often plays in applications—one of "time-until-event" nature. In fact, there's a special relationship between the exponential distribution and the Poisson distribution introduced in Section 16.1.3. When the Poisson distribution is used to model the count of an event through time, you use the exponential distribution to model the time between these events. In a setting, the exponential parameter $\lambda_e$ defines the mean rate at which the events occur over time.
