# 20
# 简单线性回归

![](img/b2cfc85cbb129f60fe595a2bae074fe4_484_0.png)

虽然对单个统计量进行直接比较本身很有用，但你通常会想从数据中学习更多信息。在本章中，你将学习线性回归模型：一组用于精确评估变量之间如何相互关系的方法。

简单线性回归模型描述了特定变量（称为解释变量）对连续结果变量（称为响应变量）取值可能产生的影响。解释变量可以是连续的、离散的或分类的，但为了引入核心概念，我在本章的前几节中将重点关注连续解释变量。然后，我将介绍如果解释变量是分类的，模型的表示将如何变化。

## 20.1 线性关系的示例

作为一个开始示例，让我们继续使用第 19.3 节中使用的数据，更仔细地观察学生调查数据（MASS 包中的 `survey` 数据框）。如果你还没有这样做，在加载了所需包的情况下（调用 `library("MASS")`），你可以阅读帮助文件 `?survey` 以获取有关所展示变量的详细信息。

将学生身高绘制在 y 轴上，并将手宽（写字手）绘制在 x 轴上。

```
R> plot(survey$Height,survey$Wr.Hnd,xlab="Writing handspan (cm)",ylab="Height (cm)")
```

图 20-1 显示了结果。

![](img/b2cfc85cbb129f60fe595a2bae074fe4_485_0.png)

图 20-1：一组大一统计学生身高与写字手宽的散点图

注意使用公式符号（也称为符号表示法）来指定“手宽相对于手宽”。你可以使用 (x, y) 的坐标向量形式生成相同的散点图，即 `plot(survey$Wr.Hnd,survey$Height,...)`，但我使用符号符号是因为它可以很好地反映了你稍后将如何拟合线性模型。

正如你预期的那样，学生的手宽和身高之间存在正相关。这种关系在本质上是线性的。为了评估线性关系的强度（参考第 13.2.5 节），你可以找到估计的相关系数。

```
R> cor(survey$Wr.Hnd,survey$Height,use="complete.obs")
[1] 0.6009909
```

虽然数据框中有 237 条记录，但图表实际上并没有显示 237 个点。这是因为存在缺失观测（编码为 NA；见第 6.1.3 节）。默认情况下，R 在生成此类图表时会移除任何“不完整”的对。要找出有多少观测值被删除，可以使用逻辑逻辑运算符 `|`（第 4.1.3 节）结合 `is.na`（第 6.1.3 节）。
