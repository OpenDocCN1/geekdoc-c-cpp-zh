# 10.1.1 Stand-Alone Statement

Let's start with the stand-alone if statement, which looks something like this:

```
if(condition){
  do any code here
}
```

The condition is placed in parentheses after the keyword. This condition must be an expression that yields a single logical value (TRUE or FALSE). If it's TRUE, the code in the braces, {}, will be executed. If the condition isn't satisfied, the code in the braces is skipped, and R does nothing (or continues to execute any code code after the closing brace).
Here's a simple example. In the console, store the following:

```
R> 3
R> mynumber <- 4
```

Now, in the editor, write the following code chunk:

```
if(a<=mynumber){
  a <- a^2
}
```

When this chunk is executed, what will be the value of a be? It depends on the condition defining the if statement, as well as what's actually specified in the braced area. In this case, when the condition a<==mynumber is evaluated, the result is TRUE since 3 is indeed less than or equal to 4. This means the code inside the braces is executed, which sets a to a^2, or 9.
Now highlight the entire chunk of code in the editor and send it to the console. Remember, you can do this in several ways:

+   - Copy and paste the selected text from the editor directly into the console.
- From the menu, select Edit -> Run line or selection in Windows or select Edit -> Execute in OS X.
- Use the keystroke shortcut such as CTRL-RETURN in Windows or CMD-RETURN on a Mac.

Once you execute the code in the console, you'll see something like:

```
R> if(a<=mynumber{
+  a <- a^2
+}
```
