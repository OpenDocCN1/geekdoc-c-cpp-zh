You'll write a for loop that goes through each member of a list like this one and checks whether the member is a matrix. Before you write the for loop, you should create some vectors that will store information about the list members: name for the list member names, is.mat to indicate whether each member is a matrix (with "Yes" or "No"), nr and nc to store the number of rows and columns for each matrix, and data.type to store the data type of each matrix.

Here, you store the names of the members of foo as name. You also set up is.mat, nr, nc, and data.type, which are all assigned vectors of length(foo) filled with NA. These values will be updated as appropriate for your loop, which you're now ready to write. Enter the following code in the editor:

```
for(i in 1:length(foo)){
  member <- foo[[i]]
  if(is.matrix(member)){
    is.mat[i] <- "Yes"
    nr[i] <- nrow(member)
    nc[i] <- ncol(member)
    data.type[i] <- class(as.vector(member))
  } else {
    is.mat[i] <- "No"
  }
}
bar <- data.frame(name,is.mat,nr,nc,data.type,stringsAsFactors=FALSE)
```

Initially, set up the loopindex to 1 so that it will increment through the index positions of foo (the sequence 1:length(foo)). In the braced code, the first command is to write the member of foo to an object member. Next, you can check whether member is a matrix using is.matrix (refer to Section 6.2.3). If TRUE, you do the following: the ith position of is.mat vector is set as "yes"; the ith of nr and nc is set as the number of rows and columns of member, respectively; and the element of data.type is set as the result of class(as.vector(member)). This final command coerces the matrix into a vector with as.vector and then uses the class function (covered in Section 6.2.2) to find the data type of the elements.

If member isn't a matrix and the if condition fails "No", and the entries in the other vectors aren't changed (so they will remain).
After the loop runs, a data frame is created from the vectors (note the use of stringsAsFactors=FALSE in order to prevent the string vectors in bar being automatically converted to factors; see Section 5.2.1). After executing the code, bar looks like this:

# Nesting for Loops
You can also nest for loop, just like if statements. When a for loop is nested in another, the inner loop is executed in full before the outer loop loopindex is incremented, at which point the inner loop is executed all again. Create the following objects in your R console:

```
R> loopvec1 <- 5:7
R> loopvec1
[1] 5 6 7
R> loopvec2 <- 9:6
R> loopvec2
[1] 9 8 7 6
R> foo <- matrix(NA,length(loopvec1),length(loopvec2))
```

```
R> foo
[,1] [2] [3] [4]
[1] NA NA NA NA
[2] NA NA NA NA
[3] NA NA NA NA
```

The following nested loop fills foo with the result of multiplying each integer in loopvec1 by loopvec2:

```
R> for(i in 1:length(loopvec1))
+   for(j in 1:length(loopvec2))
+     foo[i,j] <- loopvec1[i]*loopvec2[j]
+
R> foo
```

```
[,1] [2] [3] [4]
[1] 45 40 35 30
[2] 54 48 42 36
[3] 63 56 49 42
```

Note that nested loops require a unique loopindex for each use of for. In this case, the loopindex is for the outer loop and j for the inner loop. When the code is executed, i is first assigned 1, the inner loop begins, and j is also assigned 1. The only command in the inner loop is to take the product of the ith element of loopvec2 and assign it to i, column j of foo. The inner loop repeats until j reaches length(loopvec2) and fills the first row of foo; then i increments, and the inner loop is started up again. The entire procedure is complete after i reaches length(loopvec1) and the matrix is filled.

Inner vectors can even be defined to match the current value of the loopindex of the outer loop. Using loopvec and loopvec2 from earlier, here's an example:

```
R> foo <- matrix(NA,length(loopvec1),length(loopvec2))
R> foo
[,1] [2] [3] [4]
[1] NA NA NA NA
[2] NA NA NA NA
[3] NA NA NA NA
R> for(i in 1:length(loopvec1))
+   for(j in 1:i)
+     foo[i,j] <- loopvec1[i]+loopvec2[j]
+
R> foo
```

```
[,1] [2] [3] [4]
[1] 14 NA NA NA
[2,] 15 14 NA NA
[3,] 16 15 14 NA
```

Here, the ith, jth column element of foo is filled with the sum of loopvec1[i] and loopvec2[j]. However, the inner loop values for j are now decided on the value of i. For example, when i is 1, the inner loopvector is 1; so the inner loop executes only before returning to the outer loop. With i as 2, the inner loopvector is 1:2, and so on.
This makes so each row of foo is only partially filled. Extra care can be taken when programming loops this way. Here, for example, the values for j depend on the length of loopvec1, an error will occur if length(loopvec1) is greater than length(loopvec2).
Any number of loops can be nested, the computational expense can become a problem if nested loops are used unwisely. Loops in general add some computational cost, so to produce more efficient code in R, you should always ask “Can I...?”

# 10.2.2 while Loops
To use loops, you must know, or be able to calculate, the number of times the loop should repeat. In situations where you don't know how times the desired operations need to be run, you can turn to the while loop. A while loop runs and repeats while a specific condition returns TRUE, and takes the following general format:

```
while(loopcondition){
  do any code in here
}
```

A loop uses a simple logical-valued loopcondition to control how many times it repeats. Upon execution, the loopcondition is evaluated. If the condition is found to be TRUE, the braced area is executed line by line as until complete, at which point the loopcondition is checked again. The loop terminates only when the condition evaluates to FALSE, and it does immediately—the braced code is not run one last time.
This means the operations carried out in the braced area must somehow cause the loop to exit, either by affecting the loopcondition or by breaking it, repeating forever, creating an infinite loop, which will freeze the console (and, depending on the operations specified inside the braced area, R can crash of memory constraints). If that occurs, you can terminate the loop in the R user interface by clicking the Stop button in the top menu or by pressing ESC.
