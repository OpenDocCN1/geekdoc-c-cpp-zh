# 26.1.2 Visual Enhancements and Legends

You can alter the appearance of a plot scatterplot in new ways as well as familiar ways. For example, the optional type argument, defaulting to "p" for "points," plots the points as dots in the most recent scatterplot. You can draw points as 3D spheres, type="s". You can control the size of any plotted points or spheres by using size, and you can control the color (or colors) by using col. The legend function is the r analog of legend and is also useful: it works by changing the background image upon which the interactive plots sits.

To illustrate these modifications, let's replot the same iris observations. First, clear any open R graphics devices. Then, execute the following:

```
R plot3d(x-pivot,z=sw,size=1.5,type="s",n      col=c(1,2,3)[as.numeric(iris$Species)])
```

This will start a new RGL device, coloring spheres according to flower species. As usual, you pass the col argument of the vector length as the plotted coordinates, and it will assign the color to the corresponding point in an element-wise fashion. You specify the size parameter on the traditional R graphics parameter cex, and it changes according to the value of type—inspect the help file ?plot3d for details. With a little experimentation, it's not difficult to find a size value that suits the plot.

To add a legend, first resize the RGL device with your preferred display size and then execute the following:

```
R legend3("topright",col=1:3,legend=levels(iris$Species),pch=16,cex=2)
```

This inserts a static, immovable legend referencing the plotted species by color. The legend3 function actually calls the base R legend function, so they are conveniently used in the same way. With the static legend in place, the scatterplot remains fully interactive, and you can continue to rotate and zoom. Figure 26-2 shows all.
The legend3 function changes the background canvas, which is why you have to open a new device and resize manually before you add the legend. If you produced a new rgl plot in the same device without closing or resetting the background, the flower species legend would still be there. If you are making multiple rgl plots, you can reset the background to its default white canvas at any time by calling the following:

```
R bg3d(color="white")
```

If you try that with the most recent plot still active, you'll see that the flower species legend disappears and the scatterplot remains. Alternatively, you can just close your RGL device when you're done so that a new device will be used for any subsequent plot.
