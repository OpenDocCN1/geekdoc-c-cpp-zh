Once the code successfully executes, you can experiment with sliding the button for smaller and larger binwidths. It is interesting to gauge how much your interpretation of the distribution changes along with it. As the text printed beneath the executed commands in the console tells you, you have to exit the interactive plot to use R again. Press ESC will terminate the interactivity and return control to the user at the prompt.

Other kinds of interactive abilities include input_select_ (for a drop-down menu), input_radiobuttons (radio button options), and input_checkbox (for checkboxes). You can even set up interactive text or numeric inputs with input_numeric. See the relevant help files for the ggvis website for details.

As another example based on the surv data frame, let's try a scatterplot with a simple static plot, run the following:

```
R surv%% ggvis(x="Wr.Hd,y="Height,size=200,opacity=.3) %%
_points()
```

I don't show this result here, but you can see from here that you'll be plotting against handspan and that you're universally enlarging the points as well as setting a universal level of 30 percent opacity. The last pipe to layer points produces the image. As the static plot of the histogram, there's no interactivity, you don't need to "exit" the plot—you're returned to the control prompt immediately.
For a more interactive graphic, this:

```
R fill <- input_radiobuttons((c("Sex="Sex","Smoking status="Smoke",
Exercise frequency="Exer",map=as.name,...)
label="Color points by=..."))
```

```
R size <- input_slider(0,10,300,label="Point size: ")
R surv%% ggvis(x="Wr.Hd,y="Height,fill=filler,
size=size,opacity=opacity) %%
_layer_points()%% add_axis("x="Handspan",title="title") %%
add_legend("fill",title="")
```

Showing dynamic visualisation. Press Escape/Ctrl + C to stop.

First, three objects are created for the interactive behavior. A set of radio buttons specifies the color of the plotted points according to one of three categorical variables (Sex, Smoke, or Exer), and two slider buttons control the size and opacity. When you need to use variables from the data frame as interactive behavior, you need to supply their exact names as a vector of character strings and set the option map=as.name; this is done when defining the filler object. In ggvis, you pass the filler to fill, using =. The two sliders in the objects size and opacity are passed to the relevant elements with ::= since they don't depend on variables in the data frame. The call to layer_points generates the plot, and additional pipes to add_axis and add_legend simply tidy the x-axis and legend titles from their defaults.
