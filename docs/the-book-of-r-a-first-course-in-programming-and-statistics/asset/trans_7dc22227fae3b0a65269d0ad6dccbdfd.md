

## 2.1.1 算术

在 R 中，标准的数学规则贯穿始终，并遵循通常从左到右的操作顺序：括号、指数、乘法、除法、加法、减法，即 PEMDAS。这里有一个控制台示例：

```
R> 2+3
[1] 5
R> 14/6
[1] 2.333333
R> 14/6+5
[1] 7.333333
R> 14/(6+5)
[1] 1.272727
R> 3*2
[1] 9
R> 2*3
[1] 8
```

你可以使用 `sqrt` 函数找到任何非负数的平方根。你只需在此所示将所需的数字提供给 `x` 即可：

```
R> sqrt(x=9)
[1] 3
R> sqrt(x=5.311)
[1] 2.304561
```

在使用 R 时，你经常发现需要将复杂的算术公式转换为代码进行评估（例如，当复制教科书或研究论文中的计算时）。接下来的示例提供了数学表达式的计算及其在 R 中的执行结果：

```
R> 10^2+3*60/8-3
[1] 119.5
```

$10^2 + \frac{3 \times 60}{8} - 3$

```
R> 5^3+(6-2)/(61-4)
[1] 8.064516
```

$5^3 \frac{(6-2)}{61-4}$

```
R> 2^(2+1)-4+64^{((-2)^(2.25-1/4))
[1] 16777220
```

$2^{2+1} - 4 + 64^{2.25-\frac{1}{4}}}$

```
R> (0.44*(1-0.44)/34)^(1/2)
[1] 0.08512966
```

$\frac{0.44 \times (1-0.44)}{34}$

注意，某些 R 表达式需要额外的括号，而这些括号在数学表达式中是不存在的。缺失或位置错误的括号是 R 中算术错误的常见原因，特别是在处理指数时。如果指数本身是一个算术计算，它必须始终出现在括号中。例如，在第三个表达式中，如果你需要给 `2.25-1/4` 加上括号。如果被某个幂的数字是一个计算式，你也需要使用括号，例如第三个示例中的表达式 `9^2+1`。注意 R 会认为这是一个负数计算，因为它会将例如 `-2` 解释为 `-1^2`。这就是为什么在同一个表达式中，你需要给 `-2` 加上括号。及早强调这些问题很重要，因为它们在大量的代码块中很容易被忽略。

## 2.1.2 对数与指数

你会看到或读到研究人员对某些数据进行对数变换。这指的是使用称为底（base）的对数值对数字进行重新缩放。当给定一个数字 `x` 和称为底的值时，`log` 计算为了得到 `x` 必须将底的几次方。例如，`x=243` 以底3的对数（数学表示为 $\log_3243$）是 5，因为 $3^5 = 243$。在 R 中，通过 `log` 函数实现对数变换。你如下所示将要变换的数字赋值给值 `x`，并将底赋值给值 `base`：

```
R> log(x=243,base=3)
[1] 5
```

这里是一些需要考虑的几点：

- `x` 和底都必须是正数。
- 当底等于 `x` 时，任何数字 `x` 的对数均为 1。
- 无论底数如何，`x = 1` 的对数始终为 0。

数学中经常使用一种特殊的对数变换称为自然对数，它将底固定在一个特殊的数学数上——欧拉数。这通常写为 $e$，约等于 2.718。

欧拉数产生了指数函数，定义为 $e$ 的 $x$ 次方，其中 $x$ 可以是任何数字（负数、零或正数）。指数函数 $f(x) = e^x$ 通常写为 `exp(x)`，代表自然对数的逆运算，使得 $exp(\log_e x) = \log_e exp(x) = x$。指数函数的 R 命令是：

```
R> exp(x=3)
[1] 20.08554
```

`log` 的默认行为是假设为自然对数：

```
R log(x=20.08554)
[1] 3
```

如果你想使用 $e$ 以外的值，必须自己提供 `base` 的值。这里提到对数和指数函数是因为它们在书的后面会变得非常重要——许多方法使用它们是因为它们具有各种有助于数学属性。

## 2.1.3 E 计数法

当 R 打印低于特定有效数字阈值（默认设置为 7）的大或小数字时，数字将使用经典的科学 E 计数法。E 计数法是大多数编程语言——以及许多桌面计算器——的典型特征，便于解释极值。
