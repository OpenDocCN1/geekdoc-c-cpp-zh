
你可以看到，无论数据类型如何，类（class）报告的都是对象本身的结构——即所有矩阵。对于其他对象结构（如数组、列表和数据框）也是如此。

## 多重类

某些对象具有多个类。标准对象形式的变体（例如有序因子向量，ordered factor vector）将继承通常的类，并包含额外的有序类。如果你使用 `class` 函数，两者都会被返回。

```R
R ordfac.vec <- factor(x=c("Small","Large","Large","Regular","Small"),
                              levels=c("Small","Regular","Large"),
                              ordered=TRUE)
```

```R
R ordfac.vec
[1] Small Large Regular Small
Levels: Small < Regular < Large
R class: class Large
[1] "ordered" "factor"
```

早些，`fac.vec` 仅被识别为 "factor"，但 `ordfac.vec` 的类有两个组成部分。它仍然被识别为 "factor"，但它包含了 "ordered"，这标识了对象中存在的 "factor" 类的变体。在这里，你可以将 "ordered" 视为 "factor" 的子类。换句话说，它是一个继承自 "factor" 并因此行为也类似于 "factor" 的特殊类。关于 R 子类的更多细节，我建议参考 Mattoff (2011) 编写的《The Art of R Programming》第 9 章。

> 注意：我在这里关注 `class` 函数是因为它与本文练习的面向对象编程风格直接相关，特别是在第二部分。还有其他函数展示了 R 类规则的一些复杂性。例如，`typeof` 函数报告对象中包含的数据类型，不仅针对向量，还针对矩阵和数组。但注意，`typeof` 输出中的术语并不总是与 `class` 的输出匹配。请参见 `?typeof` 了解其返回内容的详情。

总结来说，对象的类首先是数据结构的描述符，对于简单向量，`class` 函数报告所存储的数据类型。如果向量条目全是数字，那么 R 将该向量归类为 "integer"整数），而 "numeric" 则用于标记带有浮点数的向量。

## 6.2.3 Is-Dot-Object-Checking Functions

对于操作存储对象的函数来说，识别对象的类至关重要，尤其是那些根据对象的类表现出不同行为的函数。要检查对象是否为特定类或数据类型，你对对象使用 *is-dot 函数（带点函数）*，它将返回一个 TRUE 或 FALSE 逻辑值。

对于几乎任何你能想到的合理检查都存在对应的 is-dot 函数。例如，再次考虑 6.2.2 节中的 `num.veci` 向量以及以下检查：

```R
R num.veci <- 1:4
R num.veci
[1] 1 2 3 4
R is.integer(num.veci)
[1] TRUE
R is.numeric(num.veci)
[1] TRUE
R is.matrix(num.veci)
[1] FALSE
R is.data.frame(num.veci)
[1] FALSE
R is.vector(num.veci)
[1] TRUE
R is.logical(num.veci)
[1] FALSE
```

第一个、第二个和第六个 is-dot 函数检查的是对象中存储的数据类型，而其他的检查对象本身的结构。结果符合预期：`num.veci` 是一个 "integer"（并且是一个 "vector"）。它既不是矩阵也不是数据框，更不是逻辑。

简而言之，值得注意的是，这些检查使用了比 `class` 识别的正式类更通用的类别。回想 6.2.2 节中 `num.veci` 仅被识别为 "integer"，但在这里使用 `is.numeric` 返回了 TRUE。在这里，具有整数数据的 `num.veci` 被泛化为 "numeric"。同样，对于数据框，类为 "data.frame" 的对象在 `is.data.frame` 和 `is.list` 时均会返回 TRUE，因为数据框在直觉上被泛化为列表。

这里详细介绍的对象-dot 函数与 6.1 节讨论的 `is.na` 等函数存在区别。检查特殊值 NA 的函数应该被视为一种等性检查；它们之所以存在是因为编写像 `foo=NA` 这样的内容是不合法的语法。6.1 节中的那些函数以 R 的逐元素方式运行，而对象-level 的 is-dot 函数则检查对象本身，只返回单个逻辑值。

## 6.2.4 As-Dot Coercion Functions

你已经见过在创建对象后修改对象的方法——例如通过访问和覆盖元素。但对象本身的结构以及其中包含的数据类型呢？

从一个对象转换为另一个对象被称为强制转换（coercion）。就像你目前为止遇到的 R 其他特性一样，强制转换是以隐式或显式方式执行的。当为了完成操作而需要将元素转换为另一种类型时，隐式转换会自动发生。事实上，你已经遇到过这种转换了。例如，为了完成操作而需要将元素转换为另一种类型时，隐式转换会自动发生。如果向量元素全是数字，R 将向量归类为 "integer"，而 "numeric" 则用于标记带有浮点数的向量。

具有整数数据的 `num.veci` 被泛化为 "numeric"。同样，对于数据框，类为 "data.frame" 的对象在 `is.data.frame` 和 `is.list` 时均会返回 TRUE，因为数据框在直觉上被泛化为列表。
