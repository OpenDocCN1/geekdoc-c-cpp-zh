# The denom Function

Being a probability density, the function itself doesn't produce probabilities—merely the value of the desired normal curve f(x) at any x. To plot a normal density, you would be able to use seq (refer to Section 2.3) to create a sequence of values for x, evaluate the density at these values with denom, and then plot the result as a line. For example, to produce an image of the standard normal distribution curve similar to that in the bottom image of Figure 16-6, the following code will create the density x as xvals

```
R> xvals <- seq(-4,4,length=50)
R> fx <- denom(xvals,mean=0)
R> fx
```

Then denom, which includes specification of μ as mean and σ as sigma, produces the precise values of f(x) at those xvals. Finally, a call such as plot(xvals, fx, type="1") achieves the bare bones of a density plot, which you can easily enhance by adding titles and using commands as above and segments to mark locations (off to use another plot in a moment, so this basic one isn't shown here)

Note that if you don't supply any values to mean and sd, the default behavior of R is to implement the standard normal distribution; the object earlier could have been created with an even shorter cut: using just denom(xvals)

# The denom Function

The denom function obtains left-side probabilities under the specified normal density. With denom, if no parameter values are supplied, R automatically sets mean=0 and sd=1. In the same way you pify in Section 16.2, you can find differences of results from denom to find any areas where you provide the function with the desired values in the argument q

For example, it is mentioned that a probability of approximately 0.683 lies within one standard deviation of the mean. You can confirm this using pnorm for the standard normal

```
R> pnorm(q=1)-pnorm(q=-1)
```

+   [1] 0.6826895
