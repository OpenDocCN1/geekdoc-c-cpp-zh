

```R
[1,] -4.2 0.3
[2,] 8.2 4.5
[3,] 27.9 55.3

A[c(3,1),2:3]
[,1] [,2]
[1,] 105.5 27.9
[2,] 91.0 -4.2
```

第一条命令返回 A 的第二和第三行，第二条命令返回 A 的第三和第一列。最后一个命令按顺序访问 A 的第三行和第一行，并从这些行中返回第二和第三列元素。

你也可以使用 `diag` 命令识别方矩阵（即行数和列数相矩阵）对角线上的值。

```R
diag(xx=A)
[1] 0.3 0.1 27.9
```

这返回一个包含 A 的对角线元素的向量，起始于 `[1,1]` 位置。

## 3.2.2 省略与覆盖

要从矩阵中删除或省略元素，你再次需要使用方括号，但这次使用负索引。以下代码提供了不包含第二列的 A：

```R
A[:,-2]
[,1] [,2]
[1,] 0.3 -4.2
[2,] 4.5 8.2
[3,] 55.3 27.9
```

以下代码移除了 A 的第一行，并从剩余的两行中按顺序检索第三和第二列的值：

```R
A[-1,3:2]
[,1] [,2]
[1,] 8.2 0.1
[2,] 27.9 105.5
```

以下代码生成了不包含第一行和第二列的 A：

```R
A[-1,-2]
[,1] [,2]
[1,] 4.5 8.2
[2,] 55.3 27.9
```

最后，这删除了第一行，然后从结果中删除了第二和第三列：

```R
R A[-1,-c(2,3)]
[1] 4.5 55.3
```

注意，最后这次操作让你只剩下 A 第一列的最后两个元素，因此该结果作为一个独立向量返回，而不是矩阵。

要覆盖特定的元素、整行或整列，你需要识别要替换的元素并分配新值，就像你在第 2.3.3 节中对向量操作的那样。新元素可以是一个单值、长度与被替换元素数量相同的向量，或者是一个长度能整除被替换元素数量的向量。为了说明这一点，我们先创建一个 A 的副本并将其命名为 B。

```R
R B <- A
R B
[,1] [2] [3]
[1,] 0.3 91.0 -4.2
[2,] 4.5 0.1 8.2
[3,] 55.3 105.5 27.9
```

以下代码用序列 1, 2, 3 覆盖 B 的第二行：

```R
R B[2,] <- 1:3
R B
[,1] [2] [3]
[1,] 0.3 91.0 -4.2
[2,] 1.0 2.0 3.0
[3,] 55.3 105.5 27.9
```

以下代码用 900 覆盖第一行和第三行的第二列元素：

```R
R B[c(1,3)] <- 900
R B
[,1] [2] [3]
[1,] 0.3 900 -4.2
[2,] 1.0 2 3.0
[3,] 55.3 900 27.9
```

接下来，你用 B 的第三行的值替换 B 的第三列。

```R
R B[3,] <- B[3,]
R B
[,1] [2] [3]
[1,] 0.3 900 55.3
[2,] 1.0 2 900.0
[3,] 55.3 900 27.9
```

为了尝试 R 的向量循环机制（vector recycling），我们现在用两个值 -7 和 7 覆盖第 1 行和第 3 行的第 1 列和第 3 列（共四个元素）。

```R
R B[c(1,3),c(1,3)] <- c(-7,7)
R> B
[,1] [,2] [,3]
[1,] -7 900 -7
[2,] 1 2 900
[3,] 7 900 7
```

长度为 2 的向量按列替换了这四个元素。替换向量 `c(-7,7)` 按顺序覆盖了位置在 (1,1) 和 (3,1) 的元素，然后重复以按顺序覆盖 (1,3) 和 (3,3)。

为了突出索引顺序对矩阵替换的影响，请考虑以下示例：

```R
R B[c(1,3),2:1] <- c(65,-88)
R> B
[,1] [,2] [,3]
[1,] 88 65 -7
[2,] 1 2 900
[3,] -88 -65 7
```

替换向量中的四个值按列方式覆盖了四个元素。在这种情况下，由于我反序指定了第一列和第二列，覆盖操作相应进行，在移动到第一列之前填充了第二列。位置 (1,2) 匹配 65，接着是 (3,2) 匹配 -65；然后 (1,1) 变为 88，3,1) 变为 -88。

如果你想替换方矩阵的对角线，可以避免显式索引并直接使用 `diag` 覆盖值。

```R
R diag(B) <- rep(x=0,times=3)
R> B
[,1] [,2] [,3]
[1,] 0 65 -7
[2,] 1 0 900
[3,] -88 -65 0
```
