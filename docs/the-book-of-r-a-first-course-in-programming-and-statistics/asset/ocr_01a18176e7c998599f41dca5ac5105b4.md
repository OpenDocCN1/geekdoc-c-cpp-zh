In this book, you'll make use of a handful of contributed packages. Some are used to access data sets or objects, and others are used for their unique functionality or illustrate statistical method. They are listed here:

| car faraway GGally ggplot2 ggvis |
| gridExtra ks misc3d mvnorm rgl |
| scatterplot shape spatstat tseries |

When you access any contributed package, you need an Internet connection to download and install it. Packages are generally less than a few megabytes in size. Once a package is installed, you load it with the usual call to library to access the relevant functionality listed above, you'll be prompted to do this when necessary in the relevant parts of the book.

You'll now know a few ways to perform a package download and installation for R, using the ks package (Duong, 2007) as an example.

Contributed R packages tend to be of good quality in correctness, speed and efficiency, and user-friendliness. Although there are fundamental compatibility checks that must be passed before a submitted package is made available on CRAN, passing them isn't a sign of the overall quality and usability of a given package. You can gauge that only by using the package, studying its documentation, and seeking out any related publications.
