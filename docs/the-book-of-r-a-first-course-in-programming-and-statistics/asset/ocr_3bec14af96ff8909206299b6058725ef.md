```
R> NaN+1
[1] NaN
R> 2+6*(4-4)/0
[1] NaN
R> 3.5^(-Inf/Inf)
[1] NaN
```

In the first line, adding 1 to "not a number" is still NaN. In the second line, you obtain NaN from (4-4)/0, which is clearly 0/0, so the result is also NaN. In the third line, NaN results from -Inf/Inf, so the result of calculation is again NaN. This begins to give you an idea of how NaN or infinite values might unintentionally crop up. In a function where various values are passed to a fixed calculation and you don't take care to prevent, for example, 0/0, then the code will return NaN.
With Inf, a special function (is.nan) is used to detect the presence of NaN values. Infinite values, however, relational operators cannot be used with NaN. Here's an example using bar, which was defined earlier:

```
R> bar
[1] NaN 54.30 -2.00 NaN 90094.12 -Inf 55.00
R> is.nan(x=bar)
[1] TRUE FALSE TRUE FALSE FALSE FALSE
R> is.nan(x-bar)
[1] TRUE TRUE TRUE TRUE TRUE TRUE
R> is.nan(x=bar)|is.infinite(x=bar)
[1] TRUE FALSE TRUE FALSE FALSE FALSE
R> bar[-which(is.nan(x=bar) is.infinite(x=bar))]
[1] 54.30 -2.00 90094.12 55.00
```

Using the is.nan function on bar flags the NaN positions as TRUE. In the second example, use the negation operator ! to flag the positions where the elements are NOT NaN. Using the element-wise OR,| (see Section 4.1.3), you identify elements that are either NaN OR infinite. Finally, the last lines which convert these logical values into numeric index positions so that you can remove them with negative indices in square brackets (see Section 4.1.5 for a refresher on using)
