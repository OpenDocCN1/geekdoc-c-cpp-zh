
Generally, any function $f(w)$ that defines a probability density for a random variable $W$ must possess the following properties:

- $f(w) \geq 0$ for all $-\infty < w < \infty$;
- $\int_{-\infty}^{\infty} f(w) dw = 1$ (the total area underneath the function must be 1).

In terms of the temperature example, you can see from (15.5) $f(w) \geq 0$ for any value of $w$. To calculate the total area underneath the function, you need to be concerned only with the function evaluated at $40 \leq w \leq 90$ since it's zero everywhere else.

You can do this geometrically by working out the area of the triangle formed by the function and the horizontal line at zero. For this triangle, you can use the standard "half base times height" rule. The base of the triangle is $90 - 40 = 50$, and the apex is at a value of 0.04. So, in R, the base width can be given with the following:

```
R = 0.5 * 50 * 0.04
[1]
```

This confirms it is indeed equal to 1; you can now see the reason behind my specific definition in (15.5).

Let's return to the question of obtaining the probability that the temperature is less than equal to 55.2 degrees Fahrenheit. For this you must find the area underneath $f$, the probability density function, bounded by the horizontal line at zero and an imaginary vertical at 55.2. This particular area forms another triangle, which is again appropriate to use the "half base times height" rule. In Cartesian coordinates, this triangle is formed by the vertices at (40,0), (55.2,0), and (55.2, $f(55.2)$), as shown in the right panel of Figure 15-2—you'll see how this is plotted in a moment.

Therefore, you should first work out the $f(55.2)$. From Equation (15.5), this is provided by creating the following:

```
R fw.specific <- (55.2-40)/625
R fw.specific
[1] 0.02432
```

Note that this isn't a probability; it cannot be assigned to specific realizations. It's just the height value of the triangle on the continuous density function that you need to go in order to calculate the interval-based probability $Pr(W \leq 55.2)$.

You can easily determine that the base of the triangle of interest in this particular setting is $55.2 - 40 = 15.2$. Then, along with fw.specific, note that "half base times height" gives the following:

```
R fw.specific.area <- 0.5*15.2*fw.specific
R fw.specific.area
[1] 0.184382
```

The answer is reached. You've shown geometrically, using f(w), that Pr(W ≤ 55.2) = 0.185 (when rounded to three decimal places). In other words, you can say that there is roughly an 18.5 percent chance that the maximum temperature at the picnic spot will be less than or equal to 55.2 degrees Fahrenheit.

Again, all is easier to depict visually. The following R code replots the density function f(w) and marks the areas of the interest:

```
R fw.spec.vertices <- rbind(c(40,0),c(55.2,0),c(55.2,fw.specific))
R fw.spec.vertices
[,1] [2]
[1.] 40.0 0.0000
[2.] 55.2 0.0000
[3.] 55.2 0.02432
R plot(w,fw,type="l",lab="f(w)")
R abline(h=0,col="gray",lty=2)
R polygon(fw.spec.vertices,col="gray",border=NA)
R abline(v=55.2,lty=3)
R text(50,0.0,labels=fw.spec.area)
```

The result is the result of Figure 15-2. The plotting commands should be familiar from Chapter 7.

Not all density functions can be praised in this simple geometric fashion. Formally, integration is the mathematical operation used to find areas under a continuous function, denoted by the symbol ∫. That is, the mathematically inclined forward with this technique should show that "the area under f(w) from w = 40 to w = 55.2, providing Pr(W ≤ 55.2)" is yielded by the following:

> $\int_{40}^{55.2} f(w) dw = \int_{40}^{55.2} \frac{w-40}{625} dw = \left[ \frac{w^2-80w}{1250} \right]_{40}^{55.2} = \frac{55.2^2-80\times55.2-40^2+80\times40}{1250} = 0.185 \quad \text{(rounded to 3 d.p.)}$

In R, the third line of this calculation looks like:

```
R (55.2^2-80*55.2-40^2+80*40)/1250
[1] 0.18432
```

R finds the correct result. I'll leave the mathematical details aside, but it's nice to confirm that the more general integral matches the intuitive geometric setting based on the area computed earlier as fw.specific.area.

It's now becoming clearer why it doesn't make sense to assign probabilities to single realizations associated with continuous random variables. For example, evaluating the "area under the function f(w)" at a single value is the same as finding the area of a polygon with base of zero, and furthermore, it makes no difference to your calculations if you use < or ≤. So you found Pr(W ≤ 55.2), if had been tasked to find Pr(W < 55.2), you would have gotten the same answer of 0.185. It may all seem a little unnatural at first, but it comes down to the idea of an infinite number of realizations so that there is no meaningful interpretation of "equality" to a specific value.

## Cumulative Probability Distributions of Random Variables

The cumulative probability distribution for a continuous variable is interpreted in the same way as for a discrete variable. Given a certain value w, the cumulative distribution function provides the probability of observing w or less. This may seem familiar; the probability you worked out, Pr(W ≤ 55.2), based on the shaded triangle in the right of Figure 15-2 or using analytical methods, is itself a cumulative probability. Generally, you find a cumulative probability for a continuous random variable by calculating the area under the density function of interest from -∞ to w. This general treatment requires mathematical integration of the relevant probability density function. Looking at Figure 15-2, imagine a virtual line moving from left to right of the density plot, and at every location, evaluating the area under the density function to the left of that line.

For the picnic temperature example, it can be shown that the cumulative distribution function F is given with the following:

```F(w) = ∫_{-∞}^w f(u) du
= {0 if w < 40; (w^2-80w+1600)/1250 if 40 ≤ w ≤ 65; (180w-w^2-6850)/1250 if 65 < w ≤ 90; otherwise.} (15.6)```

Making use of the sequence w and the logical vectors lower.w and upper.w from earlier, you can use the same vector-and-overwrite approach to plot F(w); the following code creates the required vector Fw and produces Figure 15-3:

```
R Fw <- rep(0,length(w))
R[lower.w] <- (lower.w^2-80*lower.w+1600)/1250
R[upper.w] <- (180*upper.w-upper.w^2-6850)/1250
R[w>90] <- 1
R plot(w,Fw,type="l",ylab="F(w)")
R abline(h=c(0,1),col="gray",lty=2)
```

## Mean and Variance of a Continuous Random Variable

Naturally, it’s also possible useful to determine the mean and variance of a continuous random variable.

For a continuous random variable W with density f, the mean $\mu_W$ (or expectation or expected value E[W]) is again interpreted as the “average outcome" that you can expect many realizations. This is expressed mathematically as follows:

$$\mu_W = \mathbb{E}[W] = \int_{-\infty}^{\infty} wf(w) dw \quad (15.7)$$

This equation represents the continuous analogue of Equation (15.3) and can be read as "the total area underneath the function given by multiplication of $f(w)$ with the value of w itself."

For W, the variance $\sigma_W^2$, also written as $Var[W]$, quantifies the variability inherent in calculations of W. Calculation of the continuous random variable depends on its mean $\mu_W$ and is given as follows:

$$\sigma_W^2 = Var[W] = \int_{-\infty}^{\infty} (w - \mu_W)^2 f(w) dw \quad (15.8)$$

Again, the procedure is to find the area under the density function multiplied—in this case, the squared difference of w with the expected value $\mu_W$. Evaluation of the mean and variance of the picnic temperature variable must follow (15.7) and (15.8), respectively. These calculations become rather complex, so I won't reproduce them here. However, Figure 15-2 shows that the mean of w must be $\mu_W = 65$; it is the perfect center of the symmetric density function $f(w)$.

In terms of the required integrals, you can therefore use the previously stored w and $fw$ objects to view the two functions, $wf(w)$ and $(w-\mu_W)^2 f(w)$, by executing the following, which produces two images in Figure 15-4:

```
plot(w,w*fw,type="l",lab="wf(w)")
plot(w,(w-65)^2*fw,type="l",lab="(w-65)^2 f(w)")
```
