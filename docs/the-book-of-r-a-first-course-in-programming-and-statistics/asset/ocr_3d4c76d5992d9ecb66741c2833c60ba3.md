# 25.1.6 Opacity

Another useful is the ability to specify the opacity of any of the colors and color palettes discussed far. All functions that provide the user with hex codes have an optional argument alpha, the value range which depends on the function (a quick check of the corresponding documentation will tell you). For example, the rgb function uses maxColor to set the upper bound on opacity, and palette functions like rainbow all use the normalized range from 0 through 1 (just like in the ggplot2 plots throughout Chapter 24)

By R assumes opacity when you are creating colors. However, hex codes change slightly when opacity is explicitly set using alpha. Rather than six characters after the #, eight will appear, with the last containing the additional opacity information. Consider the following lines of code, which generate four different versions of: default, zero opacity, 40 percent opacity (0.4 x 255 = 102), and full opacity, respectively:

```
R> rgb(cbind(255,0,0),maxColorValue=255)
[1] "#FF0000"
R> rgb(cbindind255,0,0),maxColorValue=255,alpha=0
[1] "#FF0000"
R> rgb(cbind(255,0,0),maxColorValue=255,alpha=102)
[1] "#FF0006"
R> rgb(cbind(255,0,0),maxColorValue=255,alpha=255)
[1] "#FF00FF"
```

Note that the first and last colors are identical; it's just that the last hex code specifies full opacity.
