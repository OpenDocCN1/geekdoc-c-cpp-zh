

正如前面提到的，重要的是，你必须以一种整体的方式来解释这些结果——实际上是基于回归中的一个 k 级分类变量。你可以声称吸烟对身高没有明显的影响，因为所有二元哑变量（binary dummy coefficients）的 p 值均不显著。如果其中一个水平实际上具有高度显著性（通过较小的 p 值体现），则意味着此处定义的吸烟因素作为一个整体对响应变量具有统计学上可检测的影响（即使这两个水平对应的 p 值仍然很大）。这将在第 21 章的后续几个示例中进行更深入的讨论。

## 20.5.3 更改参考水平

有时，你可能会决定更改自动选择的参考水平，并以此水平为基准对其他任何一个水平的效应进行估计。更改基准将导致对不同系数的估计，从而使单个的 p 值发生变化，但整体结果（从因素的全局显著性来看）不会受到影响。正如此，更改参考水平仅是为了获得预测变量的直观基准（例如，在某些临床试验的分析中，将“安慰剂”相对于“药物 A”和“药物 B”作为治疗变量），以便你估计与其他可能类别相比的平均响应的偏差。

使用 R 中的内置函数可以快速重新定义参考水平。该函数允许你选择在给定因子向量对象的定义中哪个水平排在第一，因此在随后的模型拟合中被指定为参考水平。在当前的示例中，假设你设置 `nonsmok`（非吸烟者）为参考水平。

```
R SmokeReordered <- relevel(survey$smoke,ref="Never")
R levels(SmokeReordered)
[1] "Never" "Heavy" "Occas" "Regul"
```

该函数已将类别移动到新因子向量的第一位置。如果你使用 `SmokeReordered` 而不是 `survey` 中的原始 `Smoke` 列来拟合模型，它将提供与三种不同吸烟者水平相关的系数估计。

值得注意的是，回归应用中对无序因子向量和有序因子向量的处理方式存在差异。在创建新因子向量时，通过例如吸烟频率的增加来正式地对吸烟变量进行排序，似乎是合理的。然而，当在调用 `lm` 时提供有序因子向量时，R 的返回方式不同——它在这里没有执行相对简单的哑变量编码（即每个可选水平与基准相关的一个效应，技术上称为正交对比）。相反，默认行为是根据所调用的多项式对比（polynomial contrasts）拟合模型，有序分类变量对响应的影响被定义为更复杂的函数形式。那部分讨论是本文的范畴，只需说明当你的兴趣在于有序类别集合中“向上移动”的特定函数性质时，这种方法是有益的。关于更多技术细节，请参考 Kuhn 和 Johnson (2013)。对于书中所有相关的回归示例，我们将专门使用无序因子向量。

## 20.5.4 将分类变量视为数值

`lm` 决定如何定义拟合模型参数的方法主要取决于你传递给函数的数据类型。如所述，只有当解释变量是无序因子向量时，`lm` 才会实施哑变量编码。

有时，你想分析的分类数据没有以因子形式存储在数据对象中。如果分类是字符向量（character vector），`lm` 将隐式将其转换为因子。然而，如果目标变量是数值，那么 `lm` 执行的线性回归就像它是连续预测变量一样；它估计一个单一回归系数，该系数被解释为平均响应的“每单位变化”。

如果原始解释变量本应由不同的组组成，这种处理可能看起来是不恰的。但在某些情况下，特别是当变量可以自然地被视为离散数值时，这种处理不仅在统计上是有用的，也有助于解释。

让我们暂时离开调查数据，假设你对里程数 `mpg`（连续）和气缸数 `cyl`（离散）感兴趣；数据集包含 4、6 或 8 个气缸的汽车。现在，自动将 `cyl` 视为分类变量是完全合理的。将 `mpg` 作为响应变量，箱线图将反映 `cyl` 作为预测变量的分组特性；图 20-6 左侧的行代码的结果如下：

```
R> boxplot(mtcars$cyl,xlab="Cylinders",ylab="MPG")
```

在拟合相关的回归模型时，你必须意识到你正在指示 R 做。由于 `mtcars` 的 `cyl` 列是数值型的，而不是本身是因子，如果你直接访问数据框，`lm` 将将其视为连续变量。

```
R> class(mtcars$cyl)
[1] "numeric"
R> carfit <- lm(mpg~cyl,data=mtcars)
R> summary(carfit)
```

正如前面的章节一样，你获得了一个截距项和一个斜率估计；后者在统计学上是极显著的，表明有证据反对斜率真实值为零。你的拟合线为：

$\hat{y} = \hat{\beta}_0 + \hat{\beta}_1x = 37.88 - 2.88x$

其中 $\hat{y}$ 是平均里程，$x$ 是气缸的数值数量。对于每增加一个气缸，模型显示你的里程平均将减少 2.88 MPG。

重要的是要意识到，你拟合的是一个连续变量，而数据实际上是分类的。在某些情况下，特别是当变量可以自然地视为连续数值时，这种处理不仅在统计上是有意义的，也有助于解释。图 20-6 的右侧显示了这一点，你拟合了一条连续线到分类数据：

```
R plot(mtcars$cyl,mtcars$mpg,xlab="Cylinders",ylab="MPG")
R> fit <- lm(mpg~cyl,data=mtcars)
R> abline(fit,col=2)
```
