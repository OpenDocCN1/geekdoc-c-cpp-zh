# 22.2 Model Selection Algorithms

The job of a model selection algorithm is to sift through your available explanatory variables in systematic fashion in order to establish which are best to jointly describe the response, as opposed to fitting models by examining specific combinations of predictors in isolation, as you've done so far.

Model selection algorithms can be controversial. There are several different methods, and no single approach is universally appropriate for every regression model. Different selection algorithms can result in different final models, as you'll see. In many cases, researchers will have additional information or knowledge about the problem that influences the decision—for example, certain predictors must always be included or it makes no sense to include them. This must be considered at the same time as other complications, such as the possibility of interactions or unobserved lurking variables influencing significant relationships and the need to ensure any fitted model is statistically valid (which you'll look at in Section 22.3).

It's helpful to keep in mind this famous quote from statistician George Box (1919–2013): "All models are wrong, but some are useful."

Any fitted model you produce can never be assumed to be the truth, but a model that's fitted and checked carefully and thoroughly can reveal interesting features of the data and have the potential to provide quantitative estimates thereafter.

# 22.2.1 Nested Comparisons: The Partial F-Test

The F Ftest is probably the most direct way to compare several models. It looks at two or more nested models, where the smaller, less complex model is a reduced version of the larger, more complex model. Let's say you have two linear regression models as:

```
$\hat{y}_{red} = \hat{eta}_0 + \hat{eta}_1x_1 + \hat{eta}_2x_2 + \dots + \hat{eta}_p x_p$
```

```
$\hat{y}_{full} = \hat{eta}_0 + \hat{eta}_1x_1 + \hat{eta}_2x_2 + \dots + \hat{eta}_p x_p + \dots + \hat{eta}_q x_q$
```

Here, the reduced model, predicting $\hat{y}_{red}$, has $p$ predictors, plus one intercept. The full model, predicting $\hat{y}_{full}$, has $q$ predictor terms. The notation implies that $q > p$ and, along with the standard inclusion of an intercept $\hat{eta}_0$, the full model involves all $p$ predictors of the reduced model defined by $\hat{y}_{red}$, as well as $q - p$ additional terms. This emphasizes the fact that the model for $\hat{y}_{red}$ is nested within $\hat{y}_{full}$.
