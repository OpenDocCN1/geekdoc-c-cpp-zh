
discussing probability density functions—see Chapters 15 and 16). It's possible for a collection of $n$ numeric measurements $x_1, x_2, \dots, x_n$ to have no mode (where each observation is unique) or to have more than one mode (where more than one particular value occurs the largest number of times). To find the mode $d_x$, simply table the frequency of each measurement.

Again using the eight observations from example, you can see the frequencies here:

| Observation | 2 | 2.2 | 3 | 4.4 |
| :--- | :--- | :--- | :--- | :--- |
| Frequency | 3 | 1 | 2 | 1 |

The value 2 occurs three times, which is more frequent than any other value, so the simple mode for data is the value 2.

In R, it is easy to compute the arithmetic mean and the median with built-in functions of the same names. First, store the eight observations as the numeric vector xdata.

```
R xdata <- c(2,4,4,3,3,2,2,2,4)
```

Then compute the statistics.

```
R x.bar <- mean(xdata)
R x.bar
[1] 2.825
R m.bar <- median(xdata)
R m.bar
[1] 2.6
```

Finding a mode is perhaps most easily achieved by using R's table function, which gives you the frequencies you need.

```
R xtab <- table(xdata)
R xtab
xdata
2 2.2 3 4 4.4
3 1 2 1 1
```

Though this clearly shows the mode for a small data set, it's good practice to write code that can automatically identify the most frequent observations for any table. The min and max functions will report the smallest and largest values, range returning both in a vector of length 2.

```
R min(xdata)
[1] 2
R max(xdata)
[1] 4.4
R range(xdata)
[1] 2.0 4.4
```

When applied to a table, these commands operate on the reported frequencies.

```
R> max(xtab)
[1] 3
```

Finally, therefore, you can construct a logical flag vector to get the mode from table.

```
R> d.bar <- xtab[xtab=max(xtab)]
nR> d.bar
2
3
```

Here, 2 is the value and 3 is the frequency of that value.

NOTE Several methods are available to compute medians, though the impact on results is usually negligible for most practical purposes. Here I've simply used the default "sample" version used by R.

Many of the functions R uses to compute statistics from a numeric structure will not run if the data includes missing or undefined values (NaNs). Here's an example:

```
R> mean(c(1,4,NA))
[1] NA
R> mean(c(1,4,NaN))
[1] NaN
```

To prevent unintended NaNs or forgotten NaNs being ignored without the user's knowledge, R does not by default ignore these values when running functions such as mean—and will not return the intended numeric results. You can, however, set an optional argument na.rm=TRUE, which will force the function to operate only on the numeric values that are present.

```
R mean(c(1,4,NA),na.rm=TRUE)
[1] 2.5
R mean(c(1,4,NaN),na.rm=TRUE)
[1] 2.5
```

You should use this only if you're aware there might be missing values and the result will be computed based on those values that have been observed. Functions that I've discussed already such as sum, prod, mean, median, min, and range—essentially anything that calculates a numeric statistic based on a numeric vector—all have the na.rm argument available to them.

Lastly, in calculating simple statistics, it's useful to remind yourself of the apply function (see Section 10.2.5), to compute statistics by a specific categorical variable. For example, you wanted to find the mean weight of the chicks by feed type. One solution would be to use the mean function on each specific subset.

```
R mean(chickwts$chickwts$feed="casein")
[1] 323.583
R mean(chickwts$chickwts$feed="horsebean")
[1] 160.2
R mean(chickwts$chickwts$feed="linseed")
[1] 218.75
R mean(chickwts$chickwts$feed="meatmeal")
[1] 276.909
R mean(chickwts$chickwts$feed="soybean")
[1] 246.4286
R mean(chickwts$chickwts$feed="sunflower")
[1] 328.9167
```

This is cumbersome and lengthy. Using apply, however, you can calculate the same values by category using just one line of code.

```
R apply(chickwts,INDEX=chickwts$feed,FUN=mean)
born linseed linseed soybean sunflower
323.583 160.2000 218.7500 276.909 246.4286 328.9167
```

Here, the first argument is the numeric vector upon which to operate, the INDEX argument specifies the grouping variable, and the FUN argument gives the name of the function to be performed on the data in subsets defined by INDEX. Like other functions you've seen, FUN includes an ellipsis (see Sections 9.2.5 and 11.2.4) to allow the user to supply further arguments to FUN if required.

## 13.2.2 Counts, Percentages, and Proportions

In this section, you'll look at data that aren't necessarily numeric. It makes little sense, for example, to ask R to compute the mean of a categorical variable, but it is sometimes useful to count the number of observations that fall within each category—these counts represent the most elementary statistic of categorical data. This uses the same summary that was necessary for calculation in Section 13.2.1, so again use the table command to obtain frequencies of the chicks in the chickwts data frame. Getting these factor-level counts is straightforward as:

```
R> chickwts$feed
```

| casein | linseed | soybean | sunflower |
| :--- | :--- | :--- | :--- |
| 12 | 12 | 14 | 12 |

You can gather more information from these counts by identifying the proportion of observations that fall into each category. This will give you comparable measures across multiple data sets. Proportions represent the fraction of observations in each category, usually expressed as a decimal (floating-point) number between 0 and 1 (inclusive). To calculate proportions, you only need to modify the previous count function by dividing the count (or frequency) by the overall sample size (obtained here by using nrow on the appropriate data frame; see Section 5.2).

```
R> chickwts$feed)/nrow(chickwts)
```

| casein | linseed | soybean | sunflower |
| :--- | :--- | :--- | :--- |
| 0.1690141 | 0.1690141 | 0.1549296 | 0.1971831 |

Of course, you don't need everything associated with counts via table. A simple-of of an appropriate logical flag vector can be just as useful—recall that TRUEs are automatically treated as 1 and FALSEs as 0 in any arithmetic logical structures in R (refer to Section 4.1.4). A sum will provide you with the desired frequency, to get a proportion, you still need to divide by the total sample size. Furthermore, this is actually equivalent to find the mean of a logical flag vector. For example, to find the proportion of chicks fed soybean, note that the following two calculations give identical results around 0.197.

```
R> sum(chickwts$feed="soybean")/nrow(chickwts)
[1] 0.1971831
```

```
R mean(chickwts$feed="soybean")
[1] 0.1971831
```

You can also use this approach to calculate the proportion of entities in combined groups, achieved easily through logical operators (see Section 4.1.3). The proportion of chicks either soybean or horsebean is as follows:

```
R mean(chickwts$feed="soybean")|chickwts$feed="horsebean")
[1] 0.3380282
```

Again, the tapply function can prove useful. This time, to get the proportions of chicks on each diet, you'll define the FUN argument to an anonymous function (refer to Section 11.3.2) that performs the required calculation.

```
R tapply(chickwts$weight,INDEX=chickwts$feed,
FUN=function(x) length(x)/nrow(chickwts))
casein horse lissed soybean sunflower
0.1690141 0.1408451 0.1690141 0.154926 0.1971831 0.1690141
```

The disposable function here is defined with a dummy argument x, which you're using to represent the vector of weights in each feed group to FUN applies. The desired proportion is therefore a case of dividing the number of observations in x by the total number of observations.

The last function to note is the round function, which rounds numeric data output to a certain number of decimal places. You need only supply to round your numeric vector (or matrix or any other appropriate data structure) and have many decimal places (as the argument digits) you figured to.

```
R round(table(chickwts$feed)/nrow(chickwts),digits=3)
```

```
casein linseed soybean sunflower
0.169 0.169 0.155 0.197
```

This output that's easier to read at a glance. If you set digits=0 (the default), output is rounded to the nearest integer.

Before the next exercise, it's worth briefly remark on the relationship between a proportion and a percentage. The two represent the same thing. The only difference is the scale; the percentage is merely the proportion multiplied by 100. The percentage of chicks on a soybean diet is there-approximately 19.7 percent.

```
R round(mean(chickwts$feed="soybean")*100,1)
[1] 19.7
```
