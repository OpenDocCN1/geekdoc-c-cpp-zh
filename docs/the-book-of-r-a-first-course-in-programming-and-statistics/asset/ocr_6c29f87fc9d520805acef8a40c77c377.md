result, you're provided with a certain hypothesis test performed using the F-distribution. This is a global test of the impact of your predictor(s) on the response; this will be explored alongside multiple linear regression in Section 21.3.5.

You can access all the output provided by summary directly, as individual R objects, rather than having to read them off the screen from the printed summary. Just as names(surfit) provides you with an indication of the contents of the stand-alone survfit object, the following code gives you the names of all the components accessible after summary is used to provide survfit.

```
R names(summary(surfit))
[1] "call" "terms" "residuals" "coefficients"
[5] "aliased" "sigma" "df" "r.squared"
[9] "adj.r.squared" "fstatistic" "cov.unscaled" "na.action"
```

It's fairly easy to match most of the components with the printed summary output, and they can be extracted using the dollar operator as usual. The residual standard error, for example, can be retrieved with this:

```
R summary(surfit)$sigma
[1] 7.90878
```

There are further details on this in the ?summary.1 help file.

# 20.4 Prediction

To wrap up these preliminary details of linear regression, the ability to fit a statistical model for predictive purposes means that you can now understand and quantify the nature of relationships in your data (like the estimated 3.1166 cm increase in mean height by 1 cm in handspan for the student example) but can also predict values of the outcome of interest, even when you haven't actually observed the values of any explanatory variables in the original data set. With any statistic, though, there is always a need to accompany any point estimates or predictions with a measure of spread.

# 20.4.1 Confidence Interval or Prediction Interval?

With a simple linear model you're able to calculate a point estimate of the mean response value, conditional upon the value of an explanatory variable. To do this, you simply plug in the value of x you are interested in. A statistic like this is subject to variation, so just as with sample statistics explored in earlier chapters, you use a confidence interval for the mean response (CI) to gauge this uncertainty.
