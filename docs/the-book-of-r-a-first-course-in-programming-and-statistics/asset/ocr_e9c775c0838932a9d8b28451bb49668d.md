prog_test <- function(n){
  result <- 0
  progbar <- txtProgressBar(min=0,max=n,style=1,char=\=")
  for(i in 1:n){
    result <- result + 1
    Sys.sleep(0.5)
    setTxtProgressBar(progbar,value=i)
  }
  close(progbar)
  return(result)
}

The width of the bar is, by default, determined by the width of the R console pane upon execution of the progressBar command. You can customize the bar a bit by changing the style and char arguments. Choosing style=3, for example shows the bar as well as a "percent completed" counter. Some packages offer more elaborate options such as pop-up widgets, but the textual version is the simplest and most universally compatible across different systems.
