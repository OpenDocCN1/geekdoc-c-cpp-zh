**Figure 25-5:** Two examples of implementing a color strip legend using the colorlegend function from the contributed shape package

The positioning and sizing of the color legend are done using the posx and posY arguments. Each of these must be a vector of length 2 describing, in relative device coordinates, horizontal (posx) and vertical (posy) lengths of the strip. In this example, posx=c(0.3,0.33) tells the function to draw the width of the legend from 30 percent of the left of the device to 53 percent so that the width is 3 percent of the overall device and positioned to the left of the center. posY=c(0.5,0.9) says you want the strip to span 40 percent of the device, from 50 percent of the way up from the bottom to 90 percent and up. Lastly, you can add the title to the legend by supplying a character string to main.

You'll probably need to experiment a bit in a trial-and-error fashion to get the positioning and sizing (appropriate tick marks using zwar) you want. The device-specific nature of posx and posY means that if you resize your device, you might need to reevaluate the values of these arguments.

If you wanted the legend to appear outside the default plot region, you could easily use the xlim argument in the initial call to plot to draw a full-length legend horizontal size of the plot, you alternatively, you've changed the figure or outer margin spacing to give enough room to plot the legend outside the plot region. This next chunk of code does just by widening the right margin, replotting the scatterplot, and inserting a color legend into that extra space.
