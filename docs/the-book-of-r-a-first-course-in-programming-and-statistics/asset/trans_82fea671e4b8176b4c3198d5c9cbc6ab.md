你现在已经学习了数值型、逻辑型、字符型和因子（factors），以及它们独特的属性和应用。现在，你将查看 R 中一些定义并不明确特殊值。你将看到它们是如何产生的，以及如何处理和测试它们。然后，你将查看 R 中不同的数据类型以及一些通的对象类概念。

## 6.1 某些特殊值

R 中的许多情况都需要用到特殊值。例如，当数据集包含缺失的观测值或当计算出一个实际上上无穷的数字时，软件会预留一些独特的术语来处理这些情况。这些特殊值可以用来标记向量、数组或其他数据结构中的异常或缺失值。

### 6.1.1 无穷大 (Infinity)

在第 2.1 节中，我提到过 R 对数字在软件能够可靠表示之前的极端程度施加了限制。当一个数字大到 R 无法表示时，该值被认为是*无穷的*（infinite）。当然，无穷大的数学概念 ($\infty$) 并不对应于特定的数字——R 只需要定义一个极端的截断点。精确的截断点因系统而异，取决于 R 可访问的内存量。该值由特殊对象 `Inf` 表示，它是敏感的。由于它代表一个数值，`Inf` 只能与数值向量相关。让我们创建一些对象来测试一下。

```
R> <- Inf
R> foo
[1] Inf
R> bar <- c(3401,Inf,3.1,-555,Inf,43)
R> bar
[1] 3401.0 3.1 -555.0 Inf Inf -43.0
R> baz <- 90000*100
R> baz
[1] Inf
```

在这里，你定义了一个对象 `foo`，它是无穷大值的单个实例。你还定义了一个数值向量 `bar`，其中包含两个无穷元素，然后在 `baz` 中将 90,000 升 100 次方，产生了一个 R 认为是无穷大的结果。

R 也可以用 `-Inf` 来表示负无穷大。

```
R> qux <- c(-42,565,-Inf,-Inf,-45632.3)
R> qux
[1] -42.0 565.0 -Inf -Inf Inf -45632.0
```

这创建了一个包含两个负无穷值和一个正无穷值的向量。尽管它不代表任何特定的值，但在某种程度上，你仍然可以对 R 中的无穷大值进行数学运算。例如，将 `Inf` 乘以任何负值都将得到 `-Inf`。

```
R> Inf*-9
[1] -Inf
```

如果你对无穷大进行加法或乘法，得到的结果也将是无穷大。

```
R> Inf+1
[1] Inf
R> 4*-Inf
[1] -Inf
R> -45.2-Inf
[1] -Inf
```

```
R> Inf-45.2
[1] Inf
R> Inf+Inf
[1] Inf
R> Inf/23
[1] Inf
```

在涉及除法时，零和无穷大是密不可相分的。任何（有限的）数值除以无穷大（正或负），结果都为零。

```
R> -59/Inf
[1] 0
R> -59/-Inf
[1] 0
```

虽然这在数学上没有定义，但请注意在 R 中，任何非零值除以零都将得到无穷大（取决于分子的符号，为正或负）。

```
R> -59/0
[1] -Inf
R> 59/0
[1] Inf
R> Inf/0
[1] Inf
```

通常，你只想检测数据结构中的无穷值。`is.infinite` 和 `is.finite` 函数会取值集合（通常是向量）中的每个元素，并对每个元素回答所提出的问题。这里有一个使用之前 `qux` 的示例：

```
R> qux
[1] -42.0 565.0 -Inf -Inf Inf -45632
R> is.infinite(x=qux)
[1] FALSE TRUE TRUE TRUE FALSE
R> is.finite(x=qux)
[1] TRUE TRUE FALSE FALSE TRUE
```

注意，这些函数不区分正无穷或负无穷，且 `is.finite` 的结果始终是 `is.infinite` 结果的反面（负）。

最后，关系运算符的作用正如你预期的那样工作。

```
R> -Inf<Inf
[1] TRUE
R> Inf>Inf
[1] FALSE
```

```
R> qux==Inf
[1] FALSE FALSE FALSE FALSE TRUE FALSE
R> qux==-Inf
[1] FALSE FALSE TRUE TRUE FALSE FALSE
```

在这里，第一行确认了 `-Inf` 确实被视为小于 `Inf`，第二行显示 `Inf` 不大于 `Inf`。第三行和第四行使用 `qux` 进行等性测试，这在你需要区分正无穷和负无穷时是一个有用的方法。

### 6.1.2 NaN

在某些情况下，无法使用数字、`Inf` 或 `-Inf` 来表示计算结果。这些难以量化的特殊值在 R 中被标记为 `NaN`，代表“Not Number”（不是数字）。与无穷值不同，`NaN` 值只与数值观测值相关。可以可以直接定义或包含 `NaN`，但这通常不是遇到它们的方式。

```
R> foo <- NaN
[1] NaN
R> bar <- c(NaN,54.3,-2,NaN,904.12,-Inf,55)
R> bar
[1] NaN 54.3 -2.0 NaN 904.12 -Inf 55
```

通常，你会看到对 `Inf` 或 `-Inf` 进行加法或减法将再次得到 `Inf` 或 `-Inf`。然而，如果你尝试将 `Inf` 除以自身，结果将是 `NaN`。

```
R> -Inf+Inf
[1] NaN
R> Inf/-Inf
[1] NaN
```

注意，任何涉及 `NaN` 的数学运算都将产生 `NaN`。

```
R> NaN+1
[1] NaN
R> 2+(4-4)/0
[1] NaN
R> 3.5^(-Inf/Inf)
[1] NaN
```

在第一行中，给“不是数字”加1 仍然是 `NaN`。在第二行中，你从 `(4-4)/0` 得到 `NaN`，这显然是 `0/0`。在第三行中，`NaN` 源于 `-Inf/Inf`，因此结果也是 `NaN`。这让你开始理解 `NaN` 或无穷值是如何无意中出现在函数中的：当各种值传递给固定计算而你没有注意防止（例如 0/0）时，代码将返回 `NaN`。对于 `Inf`，使用特殊函数 `is.nan` 来检测 `NaN` 的存在。然而，对于无穷值的关系运算符不能与 `NaN` 使用。这里有一个使用之前定义的 `bar` 的示例：

```
R> bar
[1] NaN 54.3 -2.0 NaN 904.12 -Inf 55
R> is.nan(x=bar)
[1] TRUE FALSE FALSE TRUE FALSE FALSE
R> is.nan(x-bar)
[1] TRUE TRUE TRUE TRUE TRUE
R> is.nan(x=bar)|is.infinite(x=bar)
[1] TRUE FALSE TRUE FALSE FALSE
R> bar[-which(is.nan(x=bar)|is.infinite(x=bar))]
[1] 54.3 -2.0 904.12 55
```

对 `bar` 使用 `is.nan` 将 `NaN` 位置标记为 TRUE。在第二个示例中，使用否定运算符 `!` 标记不是 `NaN` 的位置。使用元素级逻辑或 `|`（见第 4.1.3 节），你可以识别 `NaN` 或无穷元素。最后，最后几行将这些逻辑值转换为数值索引，以便将其删除（参见第 4.1.5 节）。你可以通过输入 `?NaN` 获取关于 `NaN` 和 `Inf` 功能的更多详细信息。
