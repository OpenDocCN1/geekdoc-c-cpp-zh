# 6.1.3 NA

In statistical analyses, data sets often contain missing values. For example,
sone filling out a questionnaire may not respond to a particular item, or
a researcher may record some observations from an experiment incorrectly.
Identifying and handling missing values is important so that you can use
the rest of the data. R provides a special term to represent missing
values, NA, which reads as Not Available.

NA entries are not the same as NaN entries. Whereas NaN is used only with
respect to numeric operations, missing values can occur for any type of
observation. NA can exist in both numeric and non-numeric sets.
Here's an example:

```
R foo <- c("character", "a", NA, "with", "string", NA)
R foo
[1] "character" "a" NA "with" "string" NA
R bar <- factor(c("blue", NA, "blue", "green", "blue", NA, "red", "red", NA,
"green")))
R bar
[1] <NA> <NA> blue green blue <NA> red <NA> green
Levels: bar green blue blue red green
R bar <- matrix(c(1:3,NA,5,6,8,NA),nrow=3,ncol=3)
```
