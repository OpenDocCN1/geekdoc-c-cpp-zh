The key takeaway here is that y isn't calculated as a direct result of x in the same way as you might obtain a fine, evenly spaced increasing sequence in x and evaluate y when plotting, for example, a linear regression model. Rather, the equations in (26.1) jointly define the rules of the locus in the 2D space.

# 3D Cylinder

Plotting surfaces with three dimensions is done in much the same way, only your equations set up the rules for all satisfying points in the x, y, and z-axes.

For example, points lying on a hollow cylinder can be defined by the following equations:

```
x = r cos(theta), y = r sin(theta), and z = z  (26.2)
```

To actually plot plots that satisfies rules, you need to decide on a fixed radius r, recognize that 0 ≤ theta < 360 (in degrees), and define a fixed maximum height h that you can ensure 0 ≤ z ≤ h. With information, to generate vectors for x, y, and z, you need to first set up numeric spanning the possible values of theta and z. Consider the following:

+   R <- 3
R h <- 10
zseq <- 0:h
R theta <- 0.360*(pi/180)

These lines show a radius of 3 set as r and a maximum height of 10 as h. The sequence in z is set up as the 11 integer values from 0 to 10 in zseq—this will allow you to place points on the axis of each of these defined z values. The sequence for theta is set up as 0 ≤ theta < 2pi in theta (the necessary conversion to radians). Then, you need all unique combinations of these parameters (x,y,z) coordinates for plotting. You know how to do that from Section 25.3, using expand.grid.

```
R zheta <- expand.grid(zseq, theta)
R nrow(zheta)
[3971]
```

Calling nrow on the result shows that you now have 11 × 361 = 3971 unique height-angle values. You're able to generate the values for x, y, and z as defined by (26.2). You could use a for loop (Section 10.2.1), cycling through each row of zheta, but a better way would be to use implicit looping in apply (refer to Section 10.2.3 for details).

```
R x <- apply(zheta,1,function(vec) r*cos(vec[2])
R y <- apply(zheta,1,function(vec) r*sin(vec[2])
R z <- apply(zheta,1,function(vec) vec[1])
```
