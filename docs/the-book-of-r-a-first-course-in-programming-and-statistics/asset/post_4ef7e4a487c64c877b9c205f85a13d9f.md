## 7.2.4 Line and Point Appearances

To alter the appearance of the plotted points you would use pch, and to alter the lines you would use lty. The pch parameter controls the character used to plot individual data points. You can specify a single character for each point, or specify a value between 1 and 25 (inclusive). The symbols corresponding to each integer are shown in the middle plot of Figure 7-5. The lty parameter, which affects the type of line drawn, can take the values 1 through 6. These options are shown in the rightmost plot of 7-5.

![](img/b2cfc85cbb129f60fe595a2bae074fe4_166_0.png)

Figure 7-5: Some reference plots giving the results of possible integer options of col (left), pch (middle), and lty (right)

You can also control the plotted points using cex and the thickness of lines. The default size and thickness for both of these is 1. To request half-size points, for example, you would specify cex=0.5; to specify double-thick lines, use lwd=2.

The following two lines show off pch, cex, and lwd:

```
R plot(foo,bar,type="b",main="My lovely plot",xlab="",ylab="",
col=4,pch=8,lty=2,cex=2.3,lwd=3)
R plot(foo,bar,type="b",main="My lovely plot",xlab="",ylab="",
col=6,pch=15,lty=3,cex=0.7,lwd=2)
```

## 7.2.5 Plotting Region Limits

As you can see in the plots of foo and bar, by default R sets the range of each axis by using the range of the supplied x and y values (plus a small constant to pad a little area around the outermost points). But you might need more space than this, for example, annotate individual points, add a legend, or plot additional points that fall outside the original ranges (as you'll see in Section 7.3). You can set custom plotting area limits using xlim and ylim. Both parameters require a numeric vector of length 2, provided as c(lower,upper).

Consider the plots in the bottom row of Figure 7-4, created with the following commands:

```
R plot(foo,bar,type="b",main="My lovely plot",xlab="",ylab="",
col=4,pch=8,lty=2,cex=2.3,lwd=3.3,xlim=c(-10,5),ylim=c(-3,3))
R plot(foo,bar,type="b",main="My lovely plot",xlab="",ylab="",
col=6,pch=15,lty=3,cex=0.7,lwd=2,xlim=c(3,5),ylim=c(-0.5,0.2))
```

These plots are exactly the same as in the middle row, except for one important difference. In the bottom-left plot of Figure 7-4, the x and y-axes are set to be much wider than the observed data, and the plot restricts the plotting window so that only a portion of the data is displayed.

## 7.3 Adding Points, Lines, and Text to an Existing Plot

Generally speaking, call to plot will refresh the active graphics device for a new plotting region. - lines, abline, segments Adds lines
