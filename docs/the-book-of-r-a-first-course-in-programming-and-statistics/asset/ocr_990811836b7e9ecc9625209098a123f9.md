# 26.2.2 Additional Components

Another useful attribute of a persp3 plotted surface is the ability to add further components easily—something that's nowhere as straightforward in base R functionality. You'll continue using the objects just created for the mtcars response surface.

# Adding Points

As this response surface is based on a model fitted to the data on the three variables of horsepower, weight, and MPG observations alongside the fitted model. For this, you could use points3d, which works like points in base R graphics. Execute the following:

```
pers3d(x=hp.seq,y=wt.seq,z=car.pred.mat,col="red",alpha=0.7,
xlab="Horsepower",ylab="Weight",zlab=" MPG"
points3(mtcars$hp,mtcars$wt,mtcars$mpg,col="green",size=10)
```

Resize the RGL plot to your liking and keep the device open. This time in red at 70 percent opacity using the optional alpha argument, and then the added rows to the same image in green, slightly enlarged from their default size. You can see this plot on the right of Figure 26-4; you can now compare the fit of the response surface to the data raw and view it from any angle.

# Adding Surfaces

You can also add more perspective surfaces! Let's continue to add to the current plot using the car.pred object you created for Figure 26-4. The response surface is stored as the first column in car.pred; the corresponding lower and upper prediction limits are stored as the second and third columns—flip back to Section 20.4.2 for a discussion of predict for linear regression models. To add these prediction bounds to the response surface displayed on the right of Figure 26-4, you will need to store each bounding surface as a z-matrix corresponding to the x-y evaluation grid.

```
car.pred.lo <- matrix(car.pred[,2],nrow=len,col=1)
car.pred.up <- matrix(car.pred[,3],nrow=len,col=1)
```

Then, simply persp3d for each of these z-matrices and use the optional argument add=TRUE—this instructs the persp3d function to add to the existing graph without refreshing the plot.

```
pers3d(x=hp.seq,y=wt.seq,z=car.pred.up,col="cyan",add=TRUE,alpha=0.5)
pers3d(x=hp.seq,y=wt.seq,z=car.pred.lo,col="cyan",add=TRUE,alpha=0.5)
```

Here've also set the color for each additional surface and set the opacity at 50 percent. You can see the result on the left of Figure 26-5.
