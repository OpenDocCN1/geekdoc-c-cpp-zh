
Returning to the die example, what is the probability on a single toss you roll an even number and it's a 4 or more? Using the fact that Pr(A|B) = $\frac{1}{2}$ and that Pr(B) = $\frac{1}{3}$, it is easy to compute Pr(A $\cap$ B) = $\frac{1}{3} \times \frac{1}{2} = \frac{1}{6}$ and confirm this in R if you really want to.

```
R> (2/3)+(1/2)
[1] 0.3333333
```

You can see that the events are not mutually exclusive because Pr(A $\cap$ B) $\neq$ 0. This makes sense—it's perfectly possible in a die roll to observe a number that's both even and at least 4.

## 15.1.4 Union

The union of events is written as Pr(A $\cup$ B) and is read as "the probability that A or B occurs." Here is the representation of a union as a Venn diagram:

![](img/b2cfc85cbb129f60fe595a2bae074fe4_345_0.png)

Theoretically, you have this:

> Pr(A $\cup$ B) = Pr(A) + Pr(B) - Pr(A $\cap$ B)  (15.2)

The reason you need to subtract the intersection in this diagram is that summing Pr(A) and Pr(B) alone, you'd be incorrectly counting Pr(A $\cap$ B) twice. Note, though, if the two events are mutually exclusive, then Equation (15.2) simplifies to Pr(A $\cup$ B) = Pr(A) + Pr(B).

So, rolling in the die, what is the probability that you observe an even number or one that's at least 4? Using (15.2), it's easy to find Pr(A $\cup$ B) = $\frac{1}{2} + \frac{1}{3} - \frac{1}{6}$. The following confirms this in R:

```
R> (1/2)+(1/2)-(1/3)
[1] 0.6666667
```

## 15.1 Complement

Lastly, the probability of the complement of an event is written as Pr($\tilde{A}$) and is read as "the probability that A does not occur."

Here it is as a Venn diagram:

![](img/b2cfc85cbb129f60fe595a2bae074fe4_346_0.png)

From this diagram, you can see the following:

$\Pr(\bar{A}) = 1 - \Pr(A)$

Wrapping up the running example, it's straightforward to find the probability that you do not roll a 4 or greater: $\Pr(\bar{A}) = 1 - \frac{1}{2}$. Naturally, if a 4, 5, or 6 is not obtained, then you must've rolled a 1, 2, or 3, so there are three possible outcomes out of the six.

The die-rolling example may not represent the most pressing need facing statistical researchers today, but it has provided clear illustrations of the behavior and terminology associated with the very real rules of probability. These rules apply across the board and play an important role in the interpretation of arguably more pressing endeavors in statistical modeling.

## 15.2 Random Variables and Probability Distributions

A random variable is a variable whose specific outcomes are assumed to arise by chance or according to some random or stochastic mechanism.

You've already encountered *variables*-characteristics that describe an individual entity based on data you've observed (Section 13.1). When you're considering random variables, however, you have not yet met an observation. The chances of observing a specific value, or within a specific interval, for random variable has associated with it a probability. It makes sense to think of random variables as being tied to a function that defines these probabilities.

### 15.2.1 Realizations

So, the concept of a random variable revolves around the possible outcomes. In this section, you'll look at how distributions are summarized. For example, suppose you roll a die. Let $X$ be the random variable representing the number shown. The possible values for $X$ are 1, 2, 3, 4, 5, 6. The probabilities associated with each value are shown in the following table:

| $x$ | $\Pr(X=x)$ |
| :--- | :--- |
| 1 | 1/6 |
| 2 | 1/6 |
| 3 | 1/6 |
| 4 | 1/6 |
| 5 | 1/6 |
| 6 | 1/6 |

The sum of these probabilities is 1, which is a fundamental property of probability distributions.

### 15.2.2 Discrete Random Variables

A random variable is called discrete if it takes on a countable number of values. Examples include the number of heads in several coin flips or the number of customers entering a store. For a discrete random variable, we often use the probability mass function (PMF), denoted as $p(x) = \Pr(X=x)$.

For the die rolling example, the PMF is $p(x) = 1/6$ for $x \in \{1, 2, 3, 4, 5, 6\}$.

## Cumulative Distributions of Discrete Random Variables

The cumulative distribution function (CDF), denoted as $F(x)$, is the probability that the random variable $X$ takes a value less than or equal to $x$: $F(x) = \Pr(X \leq x)$.

For the die example, the CDF is:

| $x$ | $F(x)$ |
| :--- | :--- |
| $x < 1$ | 0 |
| $1 \leq x < 2$ | 1/6 |
| $2 \leq x < 3$ | 2/6 |
| $3 \leq x < 4$ | 3/6 |
| $4 \leq x < 5$ | 4/6 |
| $5 \leq x < 6$ | 5/6 |
| $x \geq 6$ | 1 |
