# 21.3 Implementing in R and interpreting

Ever helpful, R automatically builds the matrices and carries out all the necessary calculations when you instruct it to fit a multiple linear regression model. In simple regression models, you use lm and include any additional predictors when you specify the formula in the first argument. So you can focus on the R syntax and on interpretation, I'll focus only on main effects, and then you'll explore more complex relationships later in the chapter.

When it comes to output and interpretation, working with explanatory variables follows the same rules as you've seen in Chapter 20. Any numeric-continuous variables (or a categorical variable being treated as such) have a slope coefficient that provides a “per-unit-change” quantity. Any k-group categorical variables (factors, formally unordered) are dummy coded and provide k – 1 intercepts.

# 21.3.1 Additional Predictors

Let's confirm the manual calculations from a moment ago. Using the demo.data object, fit the multiple linear model and examine the coefficients from that object as follows:

```
R2 fit <- lm(y*x1+x2,data=demo.data)
R2 coef(demo.fit)
(Intercept)    x1        x2
1.2254572  1.0153004 -0.6980189
```

You'll see that you obtain the point estimates stored earlier in BETA,HAT.

With the response variable as usual, you represents the predictors on the right side of the symbol ~ aggregates this represents formula. To fit a model with several main effects, use + to separate any variables you want to include. In fact, you've already seen this notation in Section 19.2.2, investigating two-way ANOVA.

To study the interpretation of the parameter estimates of a multiple regression model, let's return to the survey dataset in the MASS package. In Chapter 20, you explored several simple regression models based on a response variable of student height, as well as handspan (continuous) and sex (categorical, k=2). You found that handspan was highly statistically significant, with the estimated coefficient suggesting an average increase of about 3.2 cm for each 1 cm increase in handspan. When you looked at the t-test using sex as the explanatory variable, the model also suggested evidence against the null hypothesis, with “being male” adding around 13.4 cm to the mean height when compared to the mean for females (the category used as the reference level).
