

## 26.1.2 视觉增强与图例

你可以通过新方式以及熟悉的方式更改散点图的外观。例如，可选的 `type` 参数默认为 "p"（代表 "points"），它会在最近的散点图中以点的形式绘制点。你可以使用 `type="s"` 将点绘制为 3D 球体。你可以通过 `size` 控制任何已绘制的点或球体的大小，并使用 `col` 控制颜色（或多种颜色）。`legend3` 函数是 R 语言中 `legend` 的对应实现，它也非常有用：它通过更改交互式图形所在的背景图像来工作。

为了说明这些修改，让我们重新绘制相同的鸢尾（iris）观测数据。首先，清除任何打开的 R 图形设备。然后执行以下操作：

```R
plot3d(x-pivot,z=sw,size=1.5,type="s",col=c(1,2,3)[as.numeric(iris$Species)])
```

这将启动一个新的 RGL 设备，并根据花种为球体着色。与通常一样，你将长度长度向量作为 `col` 参数传递给绘制坐标，它将逐元素地将颜色分配给相应的点。你可以在传统的 R 图形参数 `cex` 上指定大小参数，它会根据 `type` 的值发生变化——详情请查看帮助文件 `?plot3d`。通过一些实验，并不难找到一个适合绘图的大小值。

要添加图例，首先用你偏好的显示大小调整 RGL 设备的大小，然后执行以下操作：

```R
legend3d("topright",col=1:3,legend=levels(iris$Species),pch=16,cex=2)
```

这会插入一个静态、不可移动的图例，通过颜色引用绘制的物种。`legend3` 函数实际上调用了基础 R 的 `legend` 函数，因此它们可以方便地一样使用。有了静态图例后，散点图保持完全的可交互性，你可以继续旋转和缩放。图 26-2 显示了所有效果。

`legend3` 函数更改了背景画布，这就是为什么在添加图例之前必须打开一个新设备并手动调整大小。如果你在不关闭或重置背景的情况下在同一设备中生成新的 rgl 图形，花种图例仍然会在那里。如果你正在制作多个 rgl 图形，可以随时调用以下代码将背景重置为默认白色画布：

```R
bg3d(color="white")
```

如果你在最近的图形仍然激活时尝试该操作，你会发现花种图例消失了而散点图仍然存在。或者，你也可以完成后关闭 RGL 设备，这样任何后续绘图将使用新设备。

## 26.13 添加额外的3D 组件

你还可以为当前的 3D 图形添加新的观测值和线条。`rgl` 包包含了 `points3d`、`lines3d` 和 `segments3d` 函数，让人联想到基础 R 图形中的 `points`、`lines` 和 `segments`。例如，在第 25.2.2 节中，你使用可选参数在散点图的 x-y 平面的每个绘制点底部添加了垂直线。在 `plot3d` 散图中，你可以使用 `segments3d` 实现相同的效果。此外，你还可以使用用于 rgl 图形的 `grid3d` 函数，在 scatterplotd 图图中同一平面上添加默认绘制的网格。

让我们将其投入实践。回顾第 652 页的图 25-8。要使用 rgl 功能创建一个类似的图，其中用颜色引用第四个连续变量——花萼长度，首先重新创建调色板并为每个观测值设置颜色。这里通过 50 种颜色的分类完成（见第 25.1.4 节）。

```R
> slen <- colorampPalette("purple","yellow", "blue")
> cols <- slen.pal(50)
> cols <- cut(slen,breaks=seq(min(slen),max(slen),length=51, include.lowest=TRUE))
```

然后，选择任何当前激活的 RGL 设备或清除聚焦设备的背景。调用 `plot3d` 将带有相应颜色的球体开始绘图。

```R
plot3d(x=pwid,y=plen,z=swid,type="s",size=1.5,col=cols[slen.cols], aspect=(1.1,75,1),xlab="Petal width",ylab="Petal length", zlab="Sepal width")
```

向 `aspect` 参数传递一个长度为 3 的向量，描述 x、y、z 轴的相对长度，顺序如此。通过将顺序更改 1.7，你相对于其他轴拉伸了 y 轴。这创建了沿 y 轴的拉伸效果。颜色通过向量索引使用 `slen.cols` 因子向量分配，并使用 `xlab`、`ylab` 和 `zlab` 整理界面。
