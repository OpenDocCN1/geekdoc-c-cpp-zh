set up a fine sequence of values of the x-axis variable at which to obtain the point estimates and their standard errors; this is achieved with seq in the third line, followed by predict in the fourth line with the segment set to TRUE. This results in the object sm, a list with components $fit and $se as usual.

The smoothed trend is then drawn, using smooth in a call to lines. Finally, a rough 95 percent confidence interval is calculated for the predicted values minus twice the corresponding standard errors in se. This is done directly in the call to polygon, which draws the gray band by the vertices formed by the confidence interval (therein, the re command is given to the grey-filled shape to be transparent with a call to the ready-to-use adjuster(the argument alpha, f takes a value from 0, which is fully opaque); alpha=0.5 sets 50 percent opacity of the specified "gray"

Suppose you wanted to superimpose smoothers for each sex separately; this would require separate estimation of the LOESS functions and a rethink of the plotting strategy. However, this addition is simple in ggplot terms, requiring a change in the aesthetic mapping of the relevant geom. The following code produces

Figure 24-2:

```
>> ggplot(surv, aes(x~Wnd, y=Height, col=Sex, shape=Sex)) +

```

All that's that is the aesthetic mapping for color and point type (col=Sex and shape=Sex, respectively) has shifted so that instead of being specific to the plotted points only, it's part of the default mapping declared in the initialization call to ggplot. Any layer added after (that doesn't assign the mapping) will follow this default, as is the case for geom_point and geom_smooth.

NOTE The implementation of LOESS and other trend smoothers depends on you specifying the amount of smoothing you want; this is controlled by the proportion of data to use each localized weighted subset, for each step/location in the estimation procedure. A larger proportion leads to a smoother, less variable trend than a smaller proportion. This value, referred to as the span, can be set by the optional argument span in either loess or geom_smooth; however, for quick data exploration, the default value of 0.75 is usually adequate.
