```
> library("mvtnorm")

This produces the plot on the left of Figure 26-9. The rmvnorm function is used to generate 500 independent variables from the standard bivariate normal distribution. You can center the variables around the coordinate (0,0) by passing a numeric vector to mean. By default, independent standard deviation components of 1 are used in both x-y coordinates.

To actually view the bivariate density function, you need to decide on the x-y evaluation grid and construct the z-matrix as usual using expand.grid. The following code sets up an evenly spaced sequence to use in both coordinate directions and gives you the mvtnorm function (this is the multivariate version of dnorm and gives you the density value at specified coordinates) to fill the z-matrix:

```
> vals <- seq(-3,3,length=50)
> xy <- expand.grid(vals,vals)
> z <- matrix(mvtnorm(xy),50,50)
```

Then, you can use contour (or persp3d) to view the density from the data in rand2d.norm were generated for comparison (truncated the limits -3 to 3 in both axes). The following line produces the plot on the right of Figure 26-9:

```
> contour(vals,vals,z,xlab="x",ylab="y")
