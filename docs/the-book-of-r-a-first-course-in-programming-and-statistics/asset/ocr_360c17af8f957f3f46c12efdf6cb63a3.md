The easiest way to use pairs is to supply a matrix or data frame of the raw observations as its first argument, done by selecting columns of iris except the Species column (iris[,1:4]). The interpretation of the plots depends upon the labeling of the diagonal panels, running from the top left to the bottom right. They will appear in the same order as the columns given as the first argument. "label panels" allow you to determine which individual plot in the matrix corresponds to each pair of variables. For example, the first column of the scatterplot matrix in Figure 14-9 corresponds to an x-axis variable of Sepal Length; the third row of the matrix corresponds to a y-axis variable of Petal Length, and each row and column displays a scale that is constant moving left or right or up/down, respectively. This means that plots above the diagonal are mirrored in those below—the plot of Petal Width (y) on Sepal Width (x) at position 4, column 2 displays the same data as the scatterplot at position 2, column 4 but flipped on its axes. As such, pairs includes an option to display only those above or below the diagonal, by setting either lower.panel=NULL or upper.panel=NULL to suppress one or the other.
