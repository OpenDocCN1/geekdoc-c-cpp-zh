
## 2.3.4 面向向量的行为

向量非常有用，因为它们允许 R 以快速高效的方式同时对多个元素执行操作。这种面向向量的、向量化的或逐元素的行为是该语言的一项关键特性，你在这里通过一些重标测量值的示例来简要检查这一点。

让我们从这个示例开始：

```R
> foo <- 5.5:0.5
> foo
[1] 5.5 4.5 3.5 2.5 1.5 0.5
> foo-c(2,4,6,8,10,12)
[1] 3.5 0.5 -2.5 -5.5 -8.5 -11.5
```

这段代码创建了一个在 5.5 到 0.5 之间、增量为 1 的六值序列。从这个向量中减去另一个包含 2, 4, 6, 8, 10 和 12 的向量。这是什么意思？简单来说，R 根据它们各自的位置匹配元素，并对每对对应的元素执行操作。结果向量是通过通过减去 `c(2,4,6,8,10,12)` 的第一个元素（5.5 – 2 = 3.5）、从 `foo` 的第二个元素减去 `c(2,4,6,8,10,12)` 的第二个元素（4.5 – 4 = 0.5），以此此类推得到的。因此，R 并没有并不优雅地循环每个元素（你可以手动操作或显式使用循环来这样做），而是允许使用面向向量的行为进行快速高效的替代方案。图 2-1 说明了你如何理解这种类型，并强调了元素的位置对于最终结果至关重要；不同位置的元素没有影响。

当使用不同长度的向量时，情况会变得复杂，这有两种发生方式。一种是长向量的长度可以被短向量的长度整除。第二种是长向量的长度不能被短向量的长度整除——这通常是用户的无意行为。在这两种情况下，R 本质上都会尝试根据需要多次复制（或循环）短向量，以匹配长向量的长度，然后再完成操作。例如，假设你想早地交替 `foo` 的元素为正数。![b2cf85bb129f60fe595a074fe4_67]

图 2-1：在两个等长度向量上执行逐元素行为的概念图。注意，操作是通过匹配位置执行的。你可以显式地将 `foo` 乘以 `c(1,-1,-1)`，但不需要写出后向量。相反，你可以写：

```R
R bar <- c(1,-1)
R foo+=bar
[1] 5.5 -4.5 3.5 -2.5 1.5 -0.5
```

已在 `foo` 的整个长度上反复应用。图 2-2 的左图插示了这个特定示例。让我们看看当向量不能整除时会发生什么。

```R
R baz <- c(1,-1,-0.5)
R foo+=baz
[1] 5.50 -4.50 1.75 -1.25 1.50
```

当向量不能整除时，R 尝试匹配 ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` ` `。` 示了这种不。

| foo * bar | foo * baz |
|---|---|
| [1] -> [1] | [1] |
| [2] -> [2] | [2] |
| [3] -> [3] | [3] |
| [4] -> [4] | [4] |
| [5] -> [1] | [1] |
| [6] -> [2] | [2] |

图 2-2：两个不同长度向量的逐元素操作。左侧：`foo * baz`；长度可整除。右侧：`foo * baz`；长度不能整除，并发出了警告。

正如 2.3.3 节所述，你可以将单一值视为长度为 1 的向量，因此你可以使用单一值来重复 `foo` 的所有值。这里有一个示例，使用了相同的 `foo`：

```R
R qux <- 3
R foo+qux
[1] 8.5 7.5 6.5 5.5 4.5 3.5
```

你看到 R 匹配了 `foo` 的前四个值与 `baz` 的全部，这种重复是尝试的，对于 `foo` 的两个值与 `baz` 匹配。

面向向量行为的另一个优势是，你可以使用向量化函数完成可能繁琐的任务。例如，如果你想对数值向量中的所有项求和，只需要使用内置函数。

回顾 `foo`：

```R
> foo
[1] 5.5 4.5 3.5 2.5 1.5 0.5
```

你可以通过以下方式找到这六元素的和：

```R
> sum(foo)
[1] 18
```

通过以下方式找到它们的积：

```R
> prod(foo)
[1] 162.4219
```

向量化函数不仅方便，而且比显式编码的迭代方法（如循环）更快更高效。这些示例的主要结论是，R 的许多功能是专门为某些数据结构设计的，确保了代码的整洁。最后，正如之前提到的，这种面向向量的行为同样适用于重写多个元素。再次使用 `foo`，检查以下：

```R
R foo
[1] 5.5 4.5 3.5 2.5 1.5 0.5
R foo[c(1,3,5,6)] <- c(-99,99)
R foo
[1] -99.0 4.5 99.0 2.5 -99.0 99.0
```

你看到四个特定元素被一个长度为 2 的向量重写，该向量以你熟悉的方式进行循环。再次，被重写向量的长度，或者被重写元素的数量，否则当 R 无法完成完整的循环时，将发出与之前所示类似的警告。
