# 12.1 Exception Handling

When there's an unexpected problem during execution of a function, R will
notify you with either a warning or an error. In this section, I'll demonstrate
how to build these constructs into your own functions where appropriate.
I'll also show how to try a calculation to check whether it's possible without
an error (that is, to see whether it'll even work).
