This plot displays the number of four-, six-, and eight-cylinder cars in the data set but is admittedly ratherinteresting, and without annotations it's not clear what is being summarized. Fortunately, it's easy to annotate such plots and further split the frequencies of each bar by an additional categorical variable. Consider the following code where, this time, you're finding the counts associated with cyl by transmission (am):

```
R table(mtcars$cyl[mtcars$am==0])
4 6 8
3 4 12
```

```
R table(mtcars$cyl[mtcars$am==1])
4 6 8
8 3 2
```

If you want to produce a barplot for that stacked (where bars are split vertically) (where bars are broken out and placed beside each other), barplot requests its first argument as a suitably arranged matrix. You could construct it from the previous vectors using matrix, but it's easier to continue using table.

```
R cyl.freq.matrix <- table(mtcars$am,mtcars$cyl)
cyl.freq.matrix

4 6 8
0 3 4 12
1 8 3 2
```

As you can see, you can cross-tabulate counts by supplying two categorical discrete vectors of equal length to table; the first vector stipulates counts, and the second defines the columns. The outcome is a matrix object; here's a 2 x3 structure providing the quantities of the four-, six-, and eight-cylinder automatic cars in the first row and the quantities of the manual cars in the second. The rule is that each column of the barplot will correspond to a column of the supplied matrix; these will be further split with respect to each row of the supplied matrix. The plot on the right Figure 14-1 is the result of the following code:

```
R barplot(cyl.freq.matrix,base=TRUE,horiz=TRUE,las=1,
main="Performance car counts\nby transmission and cylinders",
names.arg=("V4","V6","V8"),legend.text=("auto","manual",
args.legend=list(x="bottomright"))
```
