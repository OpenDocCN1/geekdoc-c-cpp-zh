# The dpois and ppois Functions

The R dpois function provides the individual Poisson mass function Pr(X = x) for the Poisson distribution. The ppois function provides the left cumulative probabilities, as in Pr(X ≤ x). Consider the following lines of code:

```
R dpois(x=3,lambda=3.22)
[1] 0.2223249
R dpois(x=0,lambda=3.22)
[1] 0.03995506
R round(dpois(0:10,3.22),3)
[1] 0.040 0.129 0.207 0.222 0.179 0.115 0.062 0.028 0.004 0.001
```

The first call finds that Pr(X = 3) = 0.22 (to 2 d.p.); in other words, the probability that you observe three blemishes on a randomly selected piece of sheet metal is equal to about 0.22. The second call indicates a less than 4 percent chance that the piece is flawless. The third line returns a rounded version of the relevant mass function for the values 0 ≤ x ≤ 10. By hand you can confirm the first result like this:

```
R (3.22*exp(-3.22))/prod(3:1)
[1] 0.2223249
```

You create a visualization of the mass function with the:

```
R barplot(dpois(x=0:10,lambda=3.22),ylim=(0,0.25),space=0,names.arg=0:10,ylab="Pr(X=x)",xlab="x")
```
