# The rnorm Function

Random variates of any given normal distribution are generated with rnorm;
for, the line

```
R rnorm(n=7,mu, sigma)
[1] -3.764532 -3.231154 -3.124965 -3.490482 -3.884633 -3.192205 -3.475835
```

produces normally distributed values arising from N(-3.42,0.2).
In contrast to the QQ plot produced for the chick weights in Figure 16-8,
y you can use rnorm, qqnorm, and qline to examine the degree to which hypo-
thetically observed data sets are truly normal vary in the context of a
QQ plot.

The following code generates 71 standard normal values and produces a
normal QQ plot and then does the same for a separate data
set of n = 710; these are displayed in Figure 16-9.

```
R fakedata1 <- rnorm(n=71)
fakedata2 <- rnorm(n=710)
qqnorm(fakedata1,main="Normal QQ plot of generated N(0,1) data; n=71")
qqline(fakedata1,col="gray")
qnorm(fakedata2,main="Normal QQ plot of generated N(0,1) data; n=710")
qqline(fakedata2,col="gray")
```
