# 20.5.5 Equivalence with One-Way ANOVA

There’s one final observation to make about regression models with a single categorical predictor. Think about the fact that these models describe a mean response value for the k different groups. Does this remind you of anything? In this particular case, you're actually doing the same thing as one-way ANOVA (Section 19.1): comparing more than two means and determining whether there is statistical evidence that at least one is different from the others. You need to be able to make the same key assumptions of independence and normality for both techniques.

In fact, simple linear regression with a single categorical predictor, implemented using least-squares estimation, is just another way to perform one-way ANOVA. Or, perhaps more concisely, ANOVA is a special case of least-squares regression. The outcome of the one-way ANOVA test is a p-value quantifying the level of statistical evidence against the null hypothesis that groups mean are equal. When you have one categorical predictor in a regression, it's exactly that p-value that's reported at the end of the summary of an lm—I referred to a couple of times as the “overall” or “global” significance test (for example, in Section 20.3.3).

Look back to the final result of global significance test for the student height modeled by smoking status—you have a p-value of 0.2147. This came from an F test of 1.504 with df1=3 and df2=205. Now, suppose you just handed the data and asked to perform a one-way ANOVA of height on smoking. Using the aov function introduced in Section 19.1, you'd call it like this:

```
R> aov(Height~Smoke,data=survey)
Df Sum Sq Mean F value Pr(>F)
Smoke 3 434 144.78 1.504 0.215
Residuals 205 19736 96.27
```

R> sqrt(96.27)
