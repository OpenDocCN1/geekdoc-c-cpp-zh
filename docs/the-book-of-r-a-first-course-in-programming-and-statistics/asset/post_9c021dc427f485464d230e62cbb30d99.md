## 19.1.2 One-Way ANOVA Table Construction

Turning your attention back to the left of Figure 19-1, remember that the goal is to statistically evaluate the equality of the means marked by x. This task will therefore require you to consider not only the variability *within each of the k samples* but the variability *between the samples*; this is why the test is referred to as an analysis of variance.

The test proceeds by first calculating metrics associated with the overall variability and then calculating the within- and between-group variability. These figures involve sums of squared quantities and associated degrees of freedom. All calculations in a single test statistic and p-value denote the aforementioned hypotheses. These ingredients are typically presented in a table, which is defined as follows.

Let $x_1, \dots, x_N$ represent all $N$ observations, regardless of group; let $x_{1(j)}, \dots, x_{n_j(j)}$ denote the group observations in group $j=1, \dots, k$ such that $n_1 + \dots + n_k = N$. Let the “grand mean” of all observations be defined as $\bar{x} = \frac{1}{N} \sum_{i=1}^N x_i$. The ANOVA table is then constructed, where SS stands for sums-of-squares, MS stands for mean square, $F$ refers to the F test statistic, and $p$ refers to the p-value.

|  | SS | MS | F | p |
|---|---|---|---|---|
| Overall |  | (1) |  |  |
| Group (or "Factor") |  | $k-1$ | (2) | $(5) \div$ (6) | $p$-value |
| Error (or "Residual") |  | $N-k$ | (3) | (6) |  |
| TOTAL |  |  | (4) |  |  |

You calculate the values with these formulas:

- (1) $N\bar{x}^2$
- (2) $\frac{\sum_{j=1}^k (x_{i(j)}-\bar{x})^2}{n_j}$
- (3) $(4)-(2)-(1)$
- (4) $\frac{\sum_{i=1}^N x_i^2}{N}$
- (5) $(2)\div(k-1)$
- (6) $(3)\div(N-k)$

There are three input sources that are assumed to make up the observed data, when added together, result in the TOTAL row. Let's think about these in a little more detail:

- **Overall row** relates to the scale on which the data is a whole it. It doesn't affect the outcome of the hypothesis test (since you're interested only in the relative differences between means) and is sometimes removed from the table, affecting the TOTAL values accordingly.

Group row/Factor row This relates to the data in the individual groups of interest, thereby accounting for the between-group variability.

Error row/Residual row This accounts for the random deviation from the estimated means of each group, by accounting for the within-group variability.

TOTAL row This represents the raw data, based on the three ingredients. It is used to find the Error SS by differencing.

The three sources each have a corresponding degrees of freedom (df) value in the first column and a sum-of-squares (SS) value attached to the second column. Between-and-within-group variability is averaged by dividing the SS by the df, giving the mean squared (MS) component for these two items. The test statistic, F, is found by dividing the mean squared group (MSG) effect by the mean squared error (MSE). This test follows the F-distribution (refer to Section 16.2.5), which requires a pair of degrees of freedom ordered as df (which represents the Group df, k-1) and df (which represents the Error df, N-k). The chi-squared distribution, the F-distribution is unidirectional in nature, and the p-value is obtained as the upper-tail area from the test statistic F.
