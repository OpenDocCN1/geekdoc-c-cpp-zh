Information Criterion (AIC). You'll noticed this value as one of the columns in the output of add1 and drop1.

For a given linear model, AIC is calculated as follows:

```
AIC = -2 \times \mathcal{L} + 2 \times (p + 2) \quad (22.3)
```

Here, $\mathcal{L}$ is a measure of goodness-of-fit named the model, excluding the log-likelihood, and $p$ is the number of regression parameters in the model, extract the overall intercept. The value of $\mathcal{L}$ is a direct outcome of the estimation procedure used to fit the model, though its exact calculation is beyond the scope of this text. The thing to know is that it takes on larger values for better-fitting models.

Equation (22.3) produces a value that rewards goodness-of-fit with the $-2\mathcal{L}$ and simultaneously penalizes complexity with $(p+2)$. The negative sign of $\mathcal{L}$ coupled with the positive sign of the $p+2$ means that smaller values of AIC refer to more parsimonious models.

To find the AIC for a fitted linear model, you may use the AIC or extractAIC functions on the object resulting from $lm\$; take a look at the help files of these functions to see the technical differences between the two. The value of $\mathcal{L}$ (and also the AIC) has no direct interpretation and is useful only when you compare it to the AIC of another model. You can use model selection on the AIC by identifying the one with the lowest AIC value. This is the reason that in the output of add1 and drop—you could decide which term to add or drop based on the change that results in a shift to the smallest AIC, instead of focusing exclusively on the significance of the F-test.

Let's go even further and combine the ideas of forward and backward selection. Stepwise model selection allows the option to delete a present term or add a missing term and is typically implemented with respect to AIC. That is, a term is chosen to be added or deleted based on the one out of all possible moves that yields the single best reduction in AIC. This affords you more flexibility in exploring candidate models on your way to the final model—determined as the model from which no addition or deletion would reduce the AIC value.

It's possible to implement stepwise selection using yourself either add or drop at each stage, but fortunately RR provides the built-in function to do it.
