# Unloading Packages

You can unload loaded packages from the search path. The packages loaded in this session, my current search path looks like this:

```
R> search()
[1] "GlobalEnv" "package:MASS" "package:car"
[4] "package:spstat" "tools:RGUI" "package:stats"
[7] "package:graphics" "package:grDevices" "package:utils"
[10] "package:datasets" "package:methods" "Autoloads"
[13] "package:base"
```

Now, suppose you don't care anymore. You can remove it with the detach function as follows.

```
R> detach("package:car", unload=TRUE)
R> search()
[1] "GlobalEnv" "package:MASS" "package:spstat"
[4] "tools:RGUI" "package:stats"
[7] "package:grDevices" "package:graphics"
[10] "package:methods" "Autoloads" "package:datasets" "package:base"
```

This removes the elected package from the path, unloading its namespace. Now, the functionality of it is no longer immediately available, and spatstat's ellipsis is no longer masked.

> As contributed packages get updated by their maintainers, they may include new objects that spark new maskings or rename objects that previously caused maskings (when compared with other contributed packages). The specific maskings illustrated among car, spatstat, and MASS occur at the time of writing with the versions available may change in the future.
