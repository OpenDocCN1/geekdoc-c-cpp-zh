These plots show leverage on the horizontal axis and the standardized residuals on the vertical axis for each observation. As a function of leverage, the Cook's distances can be plotted as contours on each of these scatterplots. These contours delineate the spatial areas of the plots that correspond to high influence (in the right extreme corners).

The closer a point falls to the horizontal line, the smaller the residual. A point that lies more left than right has a smaller leverage. If a point lies far enough from the horizontal line given its leverage (x-axis) position, it will breach the contours marking certain values of $D_i$ (defaulting to 0.5 and 1), indicating a high influence. Indeed, we can see by the narrowing of the contours as we move from left to right on these points classification as a high-influence point is easier if a given observation is in a high-leverage position, which makes perfect sense.
