Here the value of str2 was returned. Though there is a matrix in baz and the for loop in the body code of multiples1 has been executed, the matrix is not compatible for post-multiplication by mat.

Notice that the string str1 and str2 are used only when the argument x does not contain a matrix with the appropriate dimensions. When you applied multiples1 to x=foo, for example, there was no need to use str or str2. R evaluates the defining expressions, dictating that argument values are sought at the moment they are required during execution. In this function, str1 and str2 are required only when the input list doesn't have suitable matrices, so you lazily ignore providing values for these arguments x=foo.
