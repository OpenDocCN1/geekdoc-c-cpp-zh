```
R mean(chickts$feed="soybean")
[1] 0.1971831
```

You can also use this approach to calculate the proportion of entities in combined groups, achieved easily through logical operators (see Section 4.1.3). The proportion of chicks either soybean or horsebean is as follows:

```
R mean(chickts$feed="soybean")|chickts$feed="horsebean"
[1] 0.3380282
```

Again, the tapply function can prove useful. This time, to get the proportions of chicks on each diet, you'll define the FUN argument to an anonymous function (refer to Section 11.3.2) that performs the required calculation.

```
R tapply(chickts$weight,INDEX=chickts$feed,
FUN=function(x) length(x)/nrow(chickts))
casein horse lissed soybean sunflower
0.1690141 0.1408451 0.1690141 0.154926 0.1971831 0.1690141
```

The disposable function here is defined with a dummy argument x, which you're using to represent the vector of weights in each feed group to FUN applies. The desired proportion is therefore a case of dividing the number of observations in x by the total number of observations.

The last function to note is the round function, which rounds numeric data output to a certain number of decimal places. You need only supply to round your numeric vector (or matrix or any other appropriate data structure) and have many decimal places (as the argument digits) you figured to.

```
R round(table(chickts$feed)/nrow(chickts),digits=3)
```

```
casein horse linseed meat soybean sunflower
0.169 0.169 0.155 0.197 0.169
```

This output that's easier to read at a glance. If you set digits=0 (the default), output is rounded to the nearest integer.

Before the next exercise, it's worth briefly remark on the relationship between a proportion and a percentage. The two represent the same thing. The only difference is the scale; the percentage is merely the proportion multiplied by 100. The percentage of chicks on a soybean diet is there-approximately 19.7 percent.

```
R round(mean(chickts$feed="soybean")*100,1)
[1] 19.7
```
