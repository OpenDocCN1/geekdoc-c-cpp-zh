it suffices to say that this approach be beneficial when your interest lies in the specific functional nature of "moving up" through an ordered set of categories. For more on the technical details, Kuhn and Johnson (2013). For all relevant regression examples in this book, we'll work exclusively with unordered factor vectors.

#  20.5.4 Treating Categorical Variables as Numeric

The way in which lm decides to define the parameters of the fitted model depends primarily on the kind of data you pass to the function. As discussed, lm imposes dummy coding only if the explanatory variable is an unordered factor vector.

Sometimes the categorical data you want to analyze have not been stored as a factor in your data object. If the categorical is a character vector, lm will implicitly coerce into a factor. however, if the intended variable is numeric, then lm performs linear regression as if were a continuous predictor; it estimates a single regression coefficient, which is interpreted as "per-one-unit-change" in the mean response.

This may seem inappropriate if the original explanatory variable is supposed to be made of distinct groups. In some settings, however, especially when the variable can be naturally treated as numeric-discrete, this treatment is not only statistically but also helps with interpretation.

Let's take a break from the survey data and say you're interested in the mileage, mpg (continuous), and of cylinders, cyl (discrete); the data set contains cars with either 4, 6, or 8 cylinders). Now, it's perfectly sensible to automatically think of cyl as a categorical variable. Taking mpg to be the response variable, plots will reflect the grouped nature of cyl as a predictor; the result of the following line which are on the left of Figure 20-6:

```
R> boxplot(mtcars$cyl,xlab="Cylinders",ylab="MPG")
```

When fitting the associated regression model, you must be aware of what you're instructing R to do. Since the cyl column of mtcars is numeric, and not a factor per se, lm will treat it as continuous if you directly access the data frame.

```
R> class(mtcars$cyl)
[1] "numeric"
R> carfit <- lm(mpg~cyl,data=mtcars)
R> summary(carfit)
```
