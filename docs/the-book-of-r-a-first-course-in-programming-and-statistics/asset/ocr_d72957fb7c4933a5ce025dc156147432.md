These plots show leverage on the horizontal axis and the standardized residuals on the vertical axis for each observation. As a function of leverage, the Cook's distances can be plotted as contours on each of these scatterplots. These contours delineate the spatial areas of the plots that correspond to high influence (in the right extreme corners).

The closer a point falls to the horizontal line, the smaller the residual. A point that lies more left than right has a smaller leverage. If a point lies far enough from the horizontal line given its leverage (x-axis) position, it will breach the contours marking certain values of $D_i$ (defaulting to 0.5 and 1), indicating a high influence. Indeed, we can see by the narrowing of the contours as we move from left to right on these points classification as a high-influence point is easier if a given observation is in a high-leverage position, which makes perfect sense. In the previous cases to plot with which=5, the optional code.levels argument is to include a contour for the rule-of-thumb value 4/11 for these examples.

The plot for mod.1 shows that the added point (p1x, p1y) has a residual, but it doesn't breach the 4/11 contour because it's in a low-leverage position. The plot for mod.2 shows that the added point (p2x, p2y) is in a high-leverage position but isn't residual is small. Lastly, the plot for mod.3 clearly identifies the added point (p3x, p3y) as highly influential—with large residual and high leverage, it's in clear of the high-level contours.
