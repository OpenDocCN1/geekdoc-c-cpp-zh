You could also use color in a more interesting way to emphasize the wraparound nature of a Möbius strip. Taking inspiration from a similar collection of colors defined in Section 25.1.3, create the following custom palette:

```
R patriot.colors <- colorRampPalette("red4", "red", "white", "blue",
"white", "red", "red4")
```

This palette has been specifically generated to go from a dark red to white but also to wrap around from the blue back to the dark red. This is needed for the way in colors from patriot.colors will be assigned, in a point-wise fashion, to the plotted strip.
