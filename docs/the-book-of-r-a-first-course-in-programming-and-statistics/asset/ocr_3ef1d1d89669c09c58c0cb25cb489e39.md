```
R> Inf-45.2
[1] Inf
R> Inf+Inf
[1] Inf
R> Inf/23
[1] Inf
```

Zero and infinity go hand in hand when it comes to division. Any (finite) numeric value divided by infinity, positive or negative, will result in zero.

```
R> -59/Inf
[1] 0
R> -59/-Inf
[1] 0
```

Though it isn't mathematically defined, note that in R, any nonzero value divided by zero will result in infinity (positive or negative depending on the sign of the numerator).

```
R> -59/0
[1] -Inf
R> 59/0
[1] Inf
R> Inf/0
[1] Inf
```

Often, you'll simply want to detect infinite values in a data structure. The functions is.infinite and is.finite take for each element in a collection of values, typically a vector, and return for each element value answering the question posed. Here's an example using qux from earlier:

```
R> qux
[1] -42.0 565.0 -Inf -Inf Inf -45632
R> is.infinite(x=qux)
[1] FALSE TRUE TRUE TRUE FALSE
R> is.finite(x=qux)
[1] TRUE TRUE FALSE FALSE TRUE
```

Note that these functions do not distinguish positive or negative infinity, and the result of is.finite will always be the opposite (negative) of the result of is.infinite.

Finally, relational operators function as you might expect.

```
R> -Inf<Inf
[1] TRUE
R> Inf>Inf
[1] FALSE
```
