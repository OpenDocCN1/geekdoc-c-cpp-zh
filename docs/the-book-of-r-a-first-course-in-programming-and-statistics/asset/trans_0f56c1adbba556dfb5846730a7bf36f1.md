
尽管在具有数值水平的因子发生强制转换引起混乱之前，意识到这种行为是非常重要的。

```
R qux <- factor(x=c(2,2,3,5))
R qux
[1] 2 2 3 5
Levels: 2 3 5
R as.numeric(qux)
[1] 1 2 3
```

因子 `qux` 的数值表示为 `c(1,1,2,3)`。这强调了 `qux` 的水平（levels）被简单地视为水平 1（尽管标签为 2）、水平 2（标签为 3）和水平 3（标签为 5）。

对象类和结构之间的强制转换也有用。例如，你可能需要将矩阵的内容存储为单个向量。

```
R foo <- matrix(data=1:4,nrow=2,ncol=2)
R foo
[,1] [,2]
[1,] 1 3
[2,] 2 4
R as.vector(foo)
[1] 1 2 3 4
```

注意 `as.vector` 通过将列“堆叠”成单个向量来对矩阵进行了强制转换。高维数组也会发生相同的列分解，按层或块的顺序进行。

```
R bar <- array(data=c(8,1,9,5,5,1,3,4,3,9,8,8),dim=c(2,3,2))
R bar
, ,1
[,1] [,2] [,3]
[1,] 8 9 5
[2,] 1 5 1

, ,2
[,1] [,2] [,3]
[1,] 3 3 8
[2,] 4 9 8
```

```
R as.matrix(bar)
[,1]
[1,] 8
[2,] 1
[3,] 9
[4,] 5
[5,] 5
[6,] 1
[7,] 3
[8,] 4
[9,] 3
[10,] 9
[11,] 8
[12,] 8
```

```
R> as.vector(bar)
[1] 8 1 9 5 1 3 4 3 9 8 8
```

你可以看到 `as.matrix` 将数组存储为 12 × 1 的矩阵，而 `as.vector` 将其存储为单个向量。在处理对象结构时，类似的通用规则也适用于强制转换。例如，将以下列表 `baz` 强制转换为数据框（data frame）会产生错误：

```
R baz <- list(var1=foo,var2=c(T,F,T),var3=factor(x=c(2,3,4,4,2)))
R baz
$var1
[1] [2]
[1] 1 3
[2] 2 4

$var2
[1] TRUE FALSE TRUE
$var3
[1] 2 3 4 4 2
Levels: 2 3 4
```

```
R> as.data.frame(baz)
Error in data.frame(var1 = 1:4, var2 = c(TRUE, FALSE, TRUE), var3 = c(1L, :
arguments imply differing number of rows: 2, 3, 5
```

错误发生是因为变量长度不一致。但强制转换这里显示的列表 `qux` 没有问题，它的成员具有等长度：

```
R> qux <- list(var1=c(3,4,5,1),var2=c(T,F,T),var3=factor(x=c(4,4,2,1)))
R> qux
$var1
[1] 3 4 5 1

$var2
[1] TRUE FALSE TRUE TRUE

$var3
[1] 4 4 2 1
Levels: 1 2 4
```

```
R> as.data.frame(qux)
var1 var2 var3
1 TRUE 4
2 FALSE 4
3 TRUE 2
4 TRUE 1
```

这以列的方式将变量存储为数据集，并按照你列表中提供的成员顺序排列。
关于关于对象类、数据类型和强制转换的讨论并不是详尽的，但它对于 R 如何处理围绕你创建的对象的正式标识、描述和处理的问题提供了一个实用的介绍——这些问题在大多数高级语言中都存在。一旦你更熟悉 R，帮助文件（例如通过在提示符输入 `?as` 访问的文件）将提供有关软件中对象处理的更多细节。

## 基础绘图

![](img/2cf85cbb129f6055aba074fe160.png)

R 一个特别受欢迎的特性是其极其灵活的可视化绘图工具。这是 R 绘制的基础。掌握 R 的图形功能需要练习，但基本概念是直观的。在本章中，我将提供 `plot` 函数的概述以及控制图形外观的一些有用选项。然后介绍 `ggplot2`，这是一个用于数据可视化的强大库。本章将涵盖绘图的基础，然后你将在第 14 章学习创建不同类型的统计图，并在第 V 部分学习高级绘图技术。

## 7.1 使用 plot 坐标向量

在 R 中生成图形的最简单方法是将屏幕视为空白的二维画布。你可以使用 x 和 y 坐标来绘制点和线。在纸上，这些坐标通常表示为对的形式：`(x 值, y 值)`。另一方面，`plot` 函数接收两个向量——一个 x 位置向量和一个 y 位置向量——并打开一个显示结果的图形设备。如果图形设备已经打开，R 的默认行为是用新的 plot 内容刷新设备。

例如，假设你想绘制点 `(1.1,2)`, `(2.2,2)`, `(3.5,-1.3)`, `(3.9,0)` 和 `(4.2,0.2)`。在 `plot` 中，必须先提供 x 位置向量，后提供 y 位置向量。让我们分别定义 `foo` 和 `bar`：

```
R foo <- c(1.1,2,3.5,3.9,4.2)
R bar <- c(2.2,-1.3,0,0.2)
R plot(foo,bar)
```

**图 7-1** 显示带有绘图结果的图形设备（在本节中将使用这个简单数据集作为示例）。

![](img/2cf85cbb129f6055aba074fe161.png)

x 和 y 位置不一定指定为单独的向量。你也可以以矩阵的形式指定坐标，x 值在第一列，y 值在第二列，或者作为列表。例如，设置一个五个点的矩阵，代码完全还原了图 7-1：

```
R baz <- cbind(foo,bar)
R baz
  foo bar
```

```
[1,] 1.1 2.0
[2,] 2.0 2.2
[3,] 3.5 -1.3
[4,] 3.9 0.0
[5,] 4.2 0.2
> plot(baz)
```

`plot` 函数是 R 的通用函数之一。它对不同对象的作用不同，允许用户定义处理对象的方法（包括用户定义的类）。技术上，你刚刚使用的 `plot` 命令版本在内部标识为 `plot.default`。`plot.default` 帮助文件提供了关于这种散点图数据可视化的更多细节。

## 图形参数

有一系列图形参数可以作为 plot 函数（或 7.3 中的其他绘图函数）。这些参数调用简单的视觉增强，如给点上色添加轴标签，还可以控制图形设备的各个方面（第 23 章更详细地涵盖了后者）。这里列出了一些常用的图形参数；我将在接后的章节中逐一讨论这些参数：

- **type** 指令 R 绘制坐标（例如，独立点、通过线条连接或两者兼有）。
- **main, xlab, ylab** 分别包含绘图标题、水平轴标签和垂直轴标签的选项。
- **col** 用于绘制点和线的颜色（或颜色列表）。
- **pch** 代表点字符。它选择用于绘制单个点的字符。
- **cex** 代表字符扩展。它控制绘制的点字符的大小。
- **lty** 代表线型。它指定连接点的线条类型（例如实线、点线或虚线）。
- **lwd** 代表线宽。它控制绘制线的粗细。
- **xlim, ylim** 为绘图区域的水平范围和垂直范围提供限制。

## 2.2.1 自动绘图类型

默认情况下，`plot` 函数将绘制单个点，如图 7-1 所示。这是默认绘图类型，但其他绘图类型将有不同的外观。为了控制绘图类型，你可以为 `type` 参数指定单个字符值选项。
