Before you can call myfib from the console, you have to send the function to R. Highlight the code in the editor and press CTRL-R RETURN.

R myfib <- function(){
+ fib.a <- 1
+ fib.b <- 1
+ cat(fib.a,", fib.b,", "sep=")
+ repeat{
+  temp <- fib.a+fib.b
+  fib.a <- fib.b
+  fib.b <- temp

+  }

}
