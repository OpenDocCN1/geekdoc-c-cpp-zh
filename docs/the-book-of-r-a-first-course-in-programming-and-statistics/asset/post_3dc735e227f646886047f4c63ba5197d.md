## 20.3.3 Coefficient of Determination

The output of summary also provides you with the values of Multiple R-squared and Adjusted R-squared, which are particularly interesting. Both of these are referred to as the coefficient of determination; they describe the proportion of the variation in the response that can be attributed to the predictor.

For simple linear regression, the first (unadjusted) measure is simply obtained as the square of the estimated correlation coefficient (refer to Section 13.2.5). For the student height example, first store the estimated correlation between wr.Hnd and height as rho.xy, and then square it:

```
R> rho.xy <- cor(survey$Wr.Hnd,survey$height,use="complete.obs")
R> rho.xy^2
[1] 0.361910
```

You get the same as the Multiple R-squared (usually written mathematically as R²). This tells you that 36.1 percent of the variation in the student heights can be attributed to handspan.

## 20.4 Prediction

To wrap up these preliminary details of linear regression, the ability to fit a statistical model for predictive purposes means that you can now understand and quantify the nature of relationships in your data (like the estimated 3.1166 cm increase in mean height by 1 cm in handspan for the student example) but can also predict values of the outcome of interest, even when you haven't actually observed the values of any explanatory variables in the original data set. With any statistic, though, there is always a need to accompany any point estimates or predictions with a measure of spread.

### 20.4.1 Confidence Interval or Prediction Interval?

With a simple linear model you're able to calculate a point estimate of the mean response value, conditional upon the value of an explanatory variable. To do this, you simply plug in the value of x you are interested in. A statistic like this is subject to variation, so just as with sample statistics explored in earlier chapters, you use a confidence interval for the mean response (CI) to gauge this uncertainty.

Assume a simple linear regression line has been fitted to $n$ observations such that $\hat{y}=\beta_0+\beta_1x$. A $100(1-\alpha)$ percent confidence interval for the mean response given a value of $x$ is calculated with

```
$$\hat{y} \pm t_{(1-\alpha/2,n)}s_e \sqrt{1 + \frac{(x-\hat{x})^2}{(n-1)s_x^2}} \quad (20.5)$$
```

Here, $\hat{y}$ is the fitted value (from the regression line) at $x$; $t_{(1-\alpha/2,n)}$ is the appropriate critical value from a $t$-distribution with $n-2$ degrees of freedom (which others, resulting in an upper-tail area of exactly $\alpha/2$); $s_e$ and $s_x^2$ represent the sample estimated standard error; and the variance of the predictors, respectively.

A prediction interval (PI) for an observed response is different from the confidence interval in terms of context. CIs are used to describe the variability of the *mean* response, a PI is used to provide the possible range of values that an *individual realization* of the response variable might take, given $x$. This is subtle but important: the CI corresponds to a mean, and the PI corresponds to an individual observation.

Let's remain with the previous notation. It can be shown that $100(1-\alpha)$ percent interval for an individual response given a value of $x$ is calculated with the following:

```
$$\hat{y} \pm t_{(1-\alpha/2,n)}s_e \sqrt{1 + \frac{(x-\hat{x})^2}{(n-1)s_x^2}} \quad (20.6)$$
```

## Confidence Intervals for Mean Heights

To find confidence intervals for these estimates, you could calculate them manually using (20.5), but of course R has a built-in predict command to do it for you. To use predict, you first need to store your x values in a particular way: as a column in the data frame. The name of the column must match the predictor in the original code to create the fitted model object. In this example, I'll create a new data frame, with the column Wr.Hnd, which contains only two values of interest—the handspans of 14.5 and 24 cm.

```
R> xvals <- data.frame(Wr.Hnd=c(14.5,24))
R> xvals
R> Wr.Hnd
   1  14.5
   2  24.0
```

Now, when predict is called, the first argument must be the fitted object of interest, survfit for this example. Next, in the argument newdata, you pass the specially constructed data frame containing the specified predictor. To the interval you must specify "confidence" as a character string. The confidence level, here set for 95 percent, is passed (on the scale of a probability) level.

```
R> mypred.ci <- predict(surfit,newdata=xvals,interval="confidence",level=0.95)
R> mypred.ci
   fit      lwr      upr
1 159.1446 156.4956 161.7936
2 188.7524 185.5726 191.9323
```

This will return a matrix with three columns, whose number (and order) of rows correspond to the predictor values you supplied in the newdata data frame. The first column, with a heading of fit, is the point estimate on the regression line; you can see that these numbers match the values you worked out. The other columns provide the lower and upper CI limits as the lwr and upr columns, respectively. In this case, you would interpret this 95 percent confidence that the mean height of a student with a handspan of 14.5 cm lies between 156.5 cm and 161.8 cm and 185.6 cm and 191.9 cm for a handspan of 24 cm (when rounded to 1 d.p.). Remember, these CIs, calculated as per (20.5) through predict, are for the mean response.
