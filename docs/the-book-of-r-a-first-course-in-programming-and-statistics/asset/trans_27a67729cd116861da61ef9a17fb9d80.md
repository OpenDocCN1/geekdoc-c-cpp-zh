
colors (stripcols)。`for` 循环确保在第一次迭代中，stripcols 中的 1 到 200 个元素将被分配 patcols 中的 1 到 200 颜色；在第二次迭代中，201 到 400 个元素将被分配 patcols 中的 2 到 201 颜色，依此类推。这使得它们的颜色呈现出环绕外观。

为了正确理解这个 `for` 循环，首先看提供给 `outer` 用的参数顺序。将 `vex` 放在第一个和第二个，意味着结果矩阵中的每列 200 个元素对应于 `v` 中从 -1 到 1 的范围，这指的是从点线的一端移动到另一端，也是沿着条纹的宽度。通过使用从 0 到 199（包含）的索引变量 `i`，循环将每个连续元素（在每次迭代中通过 `i+1` 增加）分配给 `patcols` 中的 200 个元素，即共同向前移动正好一个元素。在循环的早期阶段，绘制的点线中颜色从红色变为白色再变为蓝色，随着循环的进行并绕条纹移动，该调色板的特定范围逐渐偏移，直到在你旋转最后几条绘制的点线时，它从蓝色变为白色。效果是当你改变 `v` 和 `θ` 时，颜色发生平滑变化。你可以在图 26-19 中看到以下结果：

## 圆环 (Torus)

另一种在 3D 空间中表示的形状是圆环面（复数形式为 tori）。这是经典的拓扑“带孔形状”，由于缺乏更好的词汇，它看起来像一个甜甜圈。圆环面的数学属性在许多领域都非常有用。

圆环面的参数化可以通过这些方程实现：

```
$x = F(\theta_2, \alpha) \cos\theta_1, \quad x = F(\theta_2, \alpha) \sin\theta_1, \quad z = \alpha \sin\theta_2 \quad (26.5)$
```

其中

```
$F(\theta_2, \alpha, \beta) = \beta + \alpha \cos\theta_2$
```

满足 $0 \le \theta_1 < 2\pi$ 且 $\theta_2$ 相同（假设角度以弧度测量）。固定值 $\alpha$ 和 $\beta$ 控制“管子”的半径（换句话说，甜甜圈的相对厚度）以及圆环相对于洞到管子中间距离的整体尺寸。只要 $\alpha < \beta$，(26.5) 中的方程就给出经典的圆环面形状；通过放宽对 $\alpha$ 和 $\beta$ 的条件，你可以得到不同类型的圆环。

设置 $\alpha = 1$ 和 $\beta = 2$，以下代码使用之前为莫比乌斯带定义的 `theta` 对象来根据 (26.5) 计算 x、y、z 坐标的矩阵：

```R
R alpha <- 1
R beta <- 2
R xm <- outer(theta,theta,function(t1,t2) (beta+alpha*cos(t2))+cos(t1))
R ym <- outer(theta,theta,function(t1,t2) (beta+alpha*cos(t2))+sin(t1))
R zm <- outer(theta,theta,function(t1,t2) alpha*sin(t2))
```

如果需要，请参考第 26.4.1 节来回顾 `outer` 的用法。

然后，这一行揭示了圆环的计算点：

```R
R plot3d(x=xm,y=ym,z=zm)
```

这给出了连续面的最终外观：

```R
R persp3d(x=xm,y=ym,z=zm,col="seagreen4",axes=FALSE,xlab="",ylab="",zlab="")
```
