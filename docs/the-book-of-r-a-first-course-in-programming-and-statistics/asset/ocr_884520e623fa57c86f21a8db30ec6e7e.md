Elementary R objects such as vectors, matrices, and arrays, on the other hand, are implicitly classed, which means the class is not identified with the attributes function. Whether implicit or explicit, the class of a given object can always be retrieved using the attribute-specific function.

# Stand-Alone Vectors

Let's create some simple vectors to use examples.

```
R num.vec1 <- 1:4
R num.vec1
[1] 1 2 3 4
R num.vec2 <- seq(from=1,to=4,length=6)
R num.vec2
[1] 1.0 1.6 2.2 2.8 3.4 4.0
R char.vec <- c("a","few","strings","here"
R char.vec
[1] "a" "few" "strings" "here"
R logic.vec <- c(T,F,F,F,T,F,T)
R logic.vec
[1] TRUE FALSE FALSE TRUE FALSE FALSE TRUE
R fac.vec <- factor("Blue","Blue","Green","Red","Green","Yellow")
```

| | Blue Blue Green Green Yellow |
| Levels: | Blue Green Red Yellow |

You can pass any object to the class function, and returns a character vector as output. Here are examples using the vectors just created:

```
R class(num.vec1)
[1] "integer"
R class(num.vec2)
[1] "numeric"
R class(char.vec)
[1] "character"
R class(logic.vec)
[1] "logical"
R class(fac.vec)
[1] "factor"
```
