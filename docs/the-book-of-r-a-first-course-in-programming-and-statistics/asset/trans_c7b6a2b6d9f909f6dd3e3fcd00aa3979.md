## 12.2.2 测量完成时间：耗了多久？

如果你想知道一个计算完成需要长时间，可以使用 `Sys.time` 命令。该命令会输出一个对象，根据你的系统详细说明当前的日期和时间信息。

```r
R> Sys.time()
[1] "2016-03-06 16:39:22 NZDT"
```

你可以在某些代码前后存储这样的对象，然后比较它们以查看通过了多少时间。在编辑器中输入：

```r
t1 <- Sys.time()
sys.sleep(3)
t2 <- Sys.time()
t2-t1
```

你选中所有四行并在控制台中执行它们。

```r
R> t1 <- Sys.time()
R> Sys.sleep(3)
R> t2 <- Sys.time()
R> t2-t1
```

时间差为 3.012889 秒
通过一起执行整个代码块，你可以轻松地测量总完成时间，并将其以格式化良好的字符串打印到控制台上。
请注意，除了你让 R 睡眠的秒数外，解释和调用任何命令都有很小的时间成本。这在不同的计算机之间会有所。
如果你需要更详细的计时报告，还有更高级的工具。例如，你可以使用 `proc.time()` 不仅接收经过的“墙上时”时间，还可以接收计算机-CPU 计时（帮助文件 `proc.time` 中的定义）。要对单个表达式计时，你也可以使用 `system.time` 函数（其输出细节与 `proc.time` 相同）。还有基准测试工具（对不同方法进行正式或系统的比较）用于为你的代码计时；例如 `benchmark` 包 (Kusnierczyk, 2012)。然而，对于日常使用，这里使用的时间差法易于解释，并提供了计算开销的良好指示。

## 12.3 掩蔽 (Masking)

由于 R 提供了大量的内置和贡献数据及功能，在某些时刻不可避免会遇到在不同包中具有相同名称的对象（通常是函数）。
那么，在这些情况下会发生什么？例如，假设你定义了一个与你已经加载的 R 包中的函数同名的函数。R 通过掩蔽其中一个对象来响应——也就是说，一个对象或函数将优于另一个并假设该对象或函数名，而被掩蔽的函数必须通过额外的命令来调用。在本节中，你将查看 R 中两种最常见的掩蔽情况。

### 12.3.1 函数与对象的区别

当不同环境中的两个函数或对象具有相同名称时，搜索路径中靠前的一个将掩蔽靠后的那一个。也就是说，当查找对象时，R 将使用它找到的对象或函数，你需要额外的代码来访问另一个被掩蔽的版本。记住，你可以通过执行 `search()` 查看当前的搜索路径。

