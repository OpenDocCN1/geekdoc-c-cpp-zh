# B.2.2 Package Installer and Updater

RStudio provides a package installer to manage the downloads and installations of contributed packages. You'll find the package manager in the Packages tab on your chosen utility pane. It lists only those packages you currently have installed, along with their version numbers, and you can use the checkboxes next to each package to load it (instead of using library in the R console);

Mine appears in Figure-B-6: I've just selected the box for the car package, which automatically executes the relevant call to library in the console.
