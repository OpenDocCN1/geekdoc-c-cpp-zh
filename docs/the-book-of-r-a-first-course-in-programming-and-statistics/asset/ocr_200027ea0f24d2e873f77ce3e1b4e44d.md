# 4.2.3 Escape Sequences

In Section 4.2, I noted that a stand-alonebackslash doesn't act like a normal character within a string. The \ is used to invoke an escape sequence. An escape sequence lets you enter characters that control the format and spacing of the string, rather than being interpreted as normal text. Table 4-3 provides a full list by entering the most common escape sequences, and you can find them at the prompt.

**Table 4-3:** Common Escape Sequences for Use in Character Strings

| Escape sequence | Result |
| \n | Starts a newline |
| \t | Horizontal tab |
| \b | Invokes a backspace |
| \\ | Used as a single backslash |
| \* | Includes a double quote |
