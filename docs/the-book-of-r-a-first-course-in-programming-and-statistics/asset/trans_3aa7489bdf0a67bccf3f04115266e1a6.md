### 23.1.3 关闭设备

要关闭图形设备，可以像关闭任何设备一样，用鼠标点击 X 按钮，或者使用 `dev.off` 函数（你最初在第 8 章关闭直接写入文件的设备时看到过这个命令）。不带任何参数地调用 `dev.off()` 会关闭当前活跃的设备。否则，你可以像使用 `dev.set` 时一样指定设备编号。要关闭空间位置的图表，同时保留直方图为活跃设备，请带参数 2 调用 `dev.off`：

```
dev.off(2)
quartz
3
```

然后重复该不带参数的调用以关闭剩余的设备：

```
dev.off()
null device
1
```

与 `dev.set` 类似，打印输出会在你关闭一个设备后告诉你新活跃的设备是什么。当你关闭最后一个可操作的设备时，你将返回到空设备（null device）。

### 23.1.4 在一个设备中的多个图表

你也可以控制任何设备中独立图表的数量。有几种方法可以实现这一点；我在这里介绍两种最简单的方法。

## 设置 mfrow 参数

回想 `par` 函数用于控制传统 R 绘图的各种图形参数。`mfrow` 参数指示新设备（或当前活跃设备）将自己“隐形”地划分为指定维的网格，每个单元格包含一个图表。`mfrow` 选项是一个长度为 2 的数值向量，顺序为 `c(rows,columns)`；正如你可能知道的它的默认值为 `c(1,1)`。

在你的 R 会话中，确保没有打开的绘图窗口。假设你想在同一个设备中并排显示两幅 quakes 数据图。你会将 `mfrow` 设置为 1 x 2 的网格，使用向量 `c(1,2)`——一行图表和两列。

```
R dev.new(width=8,height=4)
R par(mfrow=c(1,2))
R plot(quakes$long,quakes$lat,cex=0.02+quakes$stations,
     xlab="Longitude",ylab="Latitude")
R hist(quakes$stations)
R abline(v=mean(quakes$stations),lty=2)
```

第一行使用可选参数 `width` 和 `height` 预设新设备的尺寸（以英寸为单位），因此其宽度是高度的两倍。图 23-2 正展示了图像是如何创建的，在 `mfrow` 值的控制下，一个新图表填充了可用的单元格。

![](img/b2cfc85cbb129f60fe595a2bae074fe4_612_0.png)

图 23-2：在 `par` 中使用 `mfrow` 在单个图形设备中生成图表网格，显示了两幅 quakes 数据图表。

如果你关闭了任何图形设备并在不带前导调用 `dev.new` 的情况下重新运行此代码，执行 `par(mfrow=c(1,2))` 将自动打开一个默认尺寸为 7 x 7 的方形图形设备。两个图表将并排出现，但会被挤压。你可以用鼠标手动调整设备大小，使其更符合设置的 `mfrow` 值，当重新绘图时，可视化结果及其轴将变得更加清晰。

你会发现你经常使用这种试错方法在单个设备中生成多个图表，特别是当你不想操心显式调用 `dev.new` 并设置 `width` 和 `height` 时。

注意，这种方式使用 `par` 将仅影响当前活跃的设备。随后的 `dev.new` 调用将打开新设备，例如，`nrow` 将恢复为默认的“一个图表” `c(1,1)`。换句话说，如果你想定制任何新图形设备（包括直接写入文件的设备）的选项，你需要在打开设备后、执行任何绘图命令之前设置 `par` 的所需值。

## 定义特定布局

你可以使用 `layout` 函数来精炼单个设备中图表的排列，它提供了更多方法来将绘图的面板个性化化。

回到 `MASS` 包中 `survey` 里的学生调查数据。假设你想创建一个三个统计图表的数组——用手掌（handspans）测量的高度、按吸烟状况划分的高度并排箱线图，以及学生运动频率的条形图。如果你想让图表排列在正方形设备中（如建议的单行或单列三幅图表），在 `par` 中设置 `nrow=0` 可能不起作用。你可以通过 `par(mfrow=c(2,2))` 设置正方形网格，但你最终会得到一个没有分配的空白单元格。

当你使用 `layout` 时，你将 `mat` 作为第一个参数提供维度；它们控制着一个隐形的矩形网格，就像控制 `mat` 中的 `nrow`。现在的区别在于你可以使用 `mat` 中的数值条目来告诉 `layout` 几个图表放在什么位置。检查该对象：

```
R> lay.mat <- matrix(c(1,3,2,3),2,2)
R> lay.mat
     [1] [2]
[1,]  1    2
[2,]  3    3
```

此矩阵的维度创建了一个 2 x 2 的绘图单元格网格，`lay.mat` 内的值告诉 R 你希望图表 1 占据左上单元格，图表 2 占据右上单元格，图表 3 跨越底部两个单元格。

如下调用 `layout` 将根据 `lay.mat` 初始化活跃设备，或打开一个新设备（如果新设备是当前唯一的可用设备）并对其进行初始化。

```
R> layout(mat=lay.mat)
```

如果你不确定你的规范的结果，可以使用 `layout.show` 函数查看图表将如何放置。以下行生成图 23-3 左侧的图像。

```
layout.show(n=max(lay.mat))
```

然后，一旦通过调用 `library("MASS")` 加载了 MASS 包，你可以访问 `survey`，运行以下行按照绘图命令执行的顺序放置图表，与 `lay.mat` 中的整数匹配。

```
plot(survey$Wr.Hnd,survey$Height)
xlab="Writing handspan",ylab="Height"
boxplot(survey$Height$Smoke,
xlab="Smoking frequency",ylab="Height"
barplot(table(survey$Exer),horiz=TRUE,main="Exercise")
```

## 2.2 绘图区域与边距

虽然绘图时主要关注的是数据集或模型，但确保图表清晰准确地注释同样重要。为了这一点，你需要了解如何操作和绘制所有区域，而不仅仅是数据所在的区域。对于使用基础 R 创建的任何图表，由三个区域组成图像。

- 绘图区域是你到目前为止处理的所有区域。这是你绘制数据的地方。
- 图形区域包含轴、标签和任何标题的空间。这些空间也被称为图形边距。
- 外部区域（也称为外边距）是图形区域周围的额外空间，默认不包含，但在需要时指定。

你可以通过几种不同的方法显式测量和设置间距。一种典型方法是以行为单位——具体来说是每个边缘可以的行数。你以长度为 4 的向量按特定顺序指定这些值；四个边：`c(bottom, left, top, right)`。图形参数 `oma`（外边距）和 `mar`（图形区域）用于控制这些量；例如，它们是在绘制任何新图表之前通过调用 `par` 初始。

### 23.2.1 默认间距

你可以在 R 中调用 `par` 来找到你的默认图形边距设置。

```
par()$oma
[1] 0000
par()$mar
[1] 5.1 4.1 2.1
```
