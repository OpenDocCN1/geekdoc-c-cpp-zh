# ### 4.2.1 Creating a String

Character strings are indicated by double quotation marks, ". To create a string, just enter text between a pair of quotes.

```
foo <- "This is a character string!"
R foo
[1] "This is a character string!"
R length(x=foo)
[1] 1
```

R treats the string as a single entity. In other words, foo is a vector of length 1 because R counts only the total number of distinct strings rather than individual words or characters. To count the number of individual characters, you can use the nchar function. Here's an example using:

```
nchar(x=foo)
[1] 27
```

Almost any combination of characters, including numbers, can be a valid character string.

```
bar <- "23.3"
R bar
[1] "23.3"
```

Note that in this form, the string has no numeric meaning, and it won't treated like the number 23.3. Attempting to multiply it by 2, for example, results in an error.

```
bar*=2
Error in bar * 2 : non-numeric argument to binary operator
```

This error occurs because * is expecting to operate on two numeric values (not one number and one string, which makes no sense). Strings can be compared in several ways, the most common comparison being a character for equality.

```
R "alpha="alpha"
[1] TRUE
R "alpha!="beta"
[1] TRUE
R c("alpha","beta","gamma")="beta"
[1] FALSE TRUE FALSE
```
