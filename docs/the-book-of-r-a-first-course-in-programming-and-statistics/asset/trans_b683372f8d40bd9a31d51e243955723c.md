
返回的对象包含两个矩阵层每一层的第一行。然而，它将这些向量中的每一个作为单个返回矩阵的列返回。如示例所示，当从数组中提取多个向量时，它们默认将以列的形式返回。这意味着提取的行并不一定以行的形式返回。

转向对象 `BR`，以下内容给出了位于第三个块的三维数组中，第一层矩阵的第二行第一列的单个元素。

```
R> BR[2,1,1,3]
[1] 2
```

同样，你只需要查看方括号中索引的位置，就能知道你要求 R 从数组中返回哪些值。以下示例强调了这一点：

```
R> BR[1,,1]
[,1] [,2]
[1,] 1 13
[2,] 4 16
[3,] 7 19
[4,] 10 22
```

这返回了第一个块第一行的所有值。由于我在子集 `[1,,,1]` 中留了列索引和层索引，该命令返回了 `BR` 该块中所有列和两个层的值。

接下来，下一行返回了由三个矩阵组成的数组 `BR` 的第二层的所有值：

```
R> BR[,,2]
, 1
[,1] [,2] [,3] [,4]
[1,] 13 16 19 22
[2,] 14 17 20 23
[3,] 15 18 21 24
, 2
[,1] [,2] [,3] [,4]
[1,] 13 16 19 22
[2,] 14 17 20 23
[3,] 15 18 21 24
, 3
[,1] [,2] [,3] [,4]
[1,] 13 16 19 22
[2,] 14 17 20 23
[3,] 15 18 21 24
```

上一个示例强调了之前提到的一个特征，即从 `AR` 提取的多个向量作为矩阵返回。广义地说，如果你有一个提取结果导致矩阵 $d$ 维数组，结果将是下一个更高维度 $d + 1$ 的数组。在最后一个示例中，你提取了多个（二维）矩阵，它们被以三维数组的形式返回。这在下一个示例中再次得到证明：

```
R> BR[3:2,4,]
, 1
[,1] [,2]
[1,] 12 24
[2,] 11 23
, 2
[,1] [,2]
[1,] 12 24
[2,] 11 23
, 3
[,1] [,2]
[1,] 12 24
[2,] 11 23
```

这提取了所有层和所有数组块中第 3 行和第 2 行（按此顺序）、第 4 列的元素。考虑以下最后一个示例：

```
R> BR[2,1,]
[,1] [,2] [,3]
[1,] 2 2 2
[2,] 5 5 5
[3,] 8 8 8
[4,] 11 11 11
```

你要求 R 返回存储在 `BR` 中所有数组的第一层的整个第二行。

高维数组中元素的删除和覆盖遵循着与独立向量和矩阵相同的规则。你以相同的方式指定维度位置，使用负索引进行（删除）或使用赋值运算符进行覆盖。

你可以使用 `array` 函数来创建你所需要的一维数组（向量）和二维数组（矩阵）（通过将 `dim` 参数分别设置为长度 1 或 2）。但注意，如果使用 `array` 而不是 `c` 创建向量，某些函数可能会对向量进行不同的处理（技术细节请参阅帮助文件 `?array`）。由于这个原因，并且为了让大段代码更具可读性，在 R 编程中，使用特定的向量和矩阵创建函数 `c` 和 `matrix` 更符合惯例。

# 非数值值

到目前为止，你几乎只处理数值值。但统计编程需要非数值值。在本章中，我们将考虑三种重要的非数值类型：逻辑值、字符和因子。

## 4.1 逻辑值

逻辑值（也称为逻辑s）基于一个简单的假设：`TRUE` 或 `FALSE`。逻辑值通常用于检查值之间的关系。例如，你可能想知道某个数字是否大于定义的阈值。对于这一点，使用表 4-1 所示的标准关系运算符，它们会产生逻辑值。

# 表 4-1：关系运算符

| 运算符 | 解释 |
| :--- | :--- |
| == | 等 |
| != | 不等于 |
| > | 大于 |
| < | 小于 |
| >= | 大于等于 |
| <= | 小于等于 |

通常，这些运算符用于数值（你将在 4.2.1 节查看其他可能性）。这里有一个示例：

```
R> 1==2
[1] FALSE
R> 1>2
[1] FALSE
R> (2-1)<2
[1] TRUE
R> 1!=(2+3)
[1] TRUE
```

结果可能会意外：1 等于 2 是 `FALSE`，2-1 大于 2 也是 `FALSE`，而 2 小于等于 2 的结果是 `TRUE`，且 1 不等于 5 (2+3) 也是 `TRUE`。当这些操作用在某种程度上变化的数字上时有用得多，很快就会发现。你已经熟悉 R 在处理向量时的逐元素行为。在使用关系运算符时遵循相同的规则。为了说明这一点，我们首先创建两个向量并双重检查长度是否相等。

```
R foo <- c(3,2,1,4,1,2,1,-1,0,3)
R bar <- c(4,1,2,1,1,0,0,3,0,4)
R length(x=foo)==length(x-bar)
[1] TRUE
```

现在考虑以下四个求值过程：

```
R foo==bar
[1] FALSE FALSE FALSE FALSE TRUE FALSE FALSE FALSE TRUE FALSE
R foobar
[1] TRUE TRUE FALSE FALSE FALSE TRUE TRUE TRUE TRUE TRUE
R foo<=bar
[1] TRUE TRUE TRUE FALSE TRUE TRUE TRUE TRUE TRUE TRUE
R foo<=(bar+10)
[1] TRUE TRUE TRUE TRUE TRUE TRUE TRUE TRUE TRUE TRUE
```
