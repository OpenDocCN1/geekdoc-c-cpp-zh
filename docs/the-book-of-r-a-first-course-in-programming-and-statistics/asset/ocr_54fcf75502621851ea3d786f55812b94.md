compare them to see how much time has passed. Enter this in the editor:


You highlight all four lines and execute them in the console.

```
R> t1 <- Sys.time()
R> Sys.sleep(3)
R> t2 <- Sys.time()
R> t2-t1
```

Time difference of 3.012889 secs
By executing this entire code block together, you get an easy measure of the total completion time in a nicely formatted string printed to the console.
Note that there are a small time cost for interpreting and invoking any commands, in addition to the seconds you tell R to sleep. This will vary between computers.
If you need more detailed timing reports, there are more sophisticated tools. For example, you can use proc.time() to receive not just the elapsed "wall clock" time but also computer-CPU timings (the definitions in the help file proc.time). To time a single expression, you can also use system.time function (which uses the same detail of output as proc.time). There are also benchmarking tools (formal or systematic comparisons of different approaches) for timing your code; for example, the benchmark package (Kusnierczyk, 2012). However, for everyday use, the time-differing approach used here is easy to interpret and provides a good indication of the computational expense.
