
使得观测值更接近中心性度量。从这个意义上说，转换为对数尺度可以帮助减少严重偏斜数据的严重程度（第 15.2.4 节）。在回归建模的背景下，对数转换可用于捕捉那些曲线趋于“平缓”的趋势，这与你在多项式中看到的、在观测数据范围外出现的那种不稳定性是类似的。

如果你需要复习关于对数的知识，请回到第 2.1.2 节；只需注意到，对数就是为了得到某个值而必须对基数值所赋的幂。例如，在 $3^5 = 243$ 中，对数是 5，基数是 3，表示为 $\log_3 243 = 5$。由于指数函数在常见概率分布中无处不在，统计学家几乎专门地使用以 $e$ 为底的自然对数（log）。下文假设所有对对数转换的提及均指自然对数。

为了简要说明对数转换的典型行为，请看图 21-5，它是通过以下代码实现的：

```R
R plot(1:1000,log(1:1000),type="n",xlab="x",ylab="",ylim=c(-8,8))
R lines(1:1000,-log(1:1000),lty=2)
R legend("topleft",legend=c("log(x)",-log(x*)),lty=c(1,2))
```

这绘制了 1 到 1000 整数的对数相对于原始值的对比图，同时也绘制了负对数。你可以看到随着原始值的增加，转换后的值是如何收窄并变平的。

## 绘制对数转换拟合

为了可视化拟合模型，你首先需要计算预测值。以下代码创建一个马力的序列（减 20）并对这些值进行预测。

```R
R hp.seq <- seq(min(mtcars$hp)-20,max(mtcars$hp)+20,length=30)
R n <- length(hp.seq)
R car.log.pred <- predict(car.log,newdata=data.frame(hp=hp.seq,am=rep(c(0,1),each=n)))
```

在上述代码中，你需要为 `am` 值进行预测，其中前 $n$ 个元素对应自动挡，后 $n$ 个对应手动挡。现在你可以通过以下代码将这些线条添加到图 2-6：

```R
R lines(hp.seq,car.log.pred[1:n])
R lines(hp.seq,car.log.pred[(n+1):(2*n)],col="gray")
```

通过检查散点图，你可以看到拟合模型似乎很好地估计了马力/变速箱与 MPG 之间的关系。变速箱的统计显著性直接影响了两条线条之间的差异。如果它不显著，线条将靠拢；在这种情况下，模型将表明一条曲线就足以捕捉这种关系。按照常例，外推到观测预测数据范围之外并不是一个好主意，尽管对于多项函数的对数转换趋势是不稳定的。

## 21.4.3 其他转换

转换可以涉及数据集中的多个变量，不仅限于预测变量。在对汽车数据的原始研究中，Henderson 和 Velleman (1981) 也注意到了你发现的响应与马力和变量之间相同的曲线关系。他们认为使用每加仑里程（GPM）代替 MPG 作为响应变量更好，以提高线性。这将涉及对 MPG 进行转换，即 GPM = 1/MPG。
