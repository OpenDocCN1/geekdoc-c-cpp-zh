# The dbinom Function

With this knowledge, you can use R to confirm the result of Pr(X = 5) for the die-roll example described a moment ago.

```
R dbinom(x=5,size=8,prob=1/6)
[1] 0.004167619
```

To the dbinom function, you provide the specific value of success at x; as size; the total number of trials, n, as size; and the probability of success at x trial, p, as prob. True to R, a vector argument is possible for x. If you want the full probability mass table for X for this example, you can supply the vector 0 to x.

```
R.prob <- dbinom(x=0,size=8,prob=1/6)
R.prob
[1] 2.32568e-01 3.721089e-01 2.60472e-01 1.041905e-01 2.60472e-02
[6] 4.16719e-03 4.16719e-04 2.38149e-05 5.95374e-07
```

These can be confirmed to sum to 1.

```
R sum(X.prob)
[1] 1
```

The resulting vector of probabilities, which corresponds to the specific outcomes x = [0, 1, ..., 8], is returned using e-notation (refer to Section 2.1.3). You can tidy this by rounding the results using the round function introduced in Section 13.2.2. Rounding to three decimal places, the results are easy to read.

```
R round(X.prob,3)
[1] 0.233 0.372 0.26 0.104 0.026 0.004 0 0 0
```

The achievement of success in eight trials has the highest probability, the mean (expected value) and variance of X in the example are μ = np = 8*1/6 = 8/6 and σ² = np(1-p) = 8*1/6*(1-1/6).

```
R 8/6
[1] 1.333333
R 8*(1/6)*(5/6)
[1] 1.111111
```
