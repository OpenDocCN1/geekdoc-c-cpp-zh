vector. You can extract the levels as a vector of character strings using the levels function.

```
R levels(x=sex.num.fac)
[1] "0" "1"
R levels(x=sex.char.fac)
[1] "female" "male"
```

You can relabel a factor using levels. Here's an example:

```
R levels(x=sex.num.fac) <- c("1","2"
Rex.num.fac
[1] 1 1 1 1 2 2 1
Levels: 1 2
```

This labels the females 1 and males 2.
Factor-valued vectors are subsetted in the same way as any other vector.

```
R sex.char.fac[2:5]
[1] female male female female
Levels: female male
R sex.char.fac[c(1:3,5,8)]
[1] female female female female
Levels: female male
```

Note that after subsetting factor object, the object continues to all defined levels even if some of the levels are no longer represented in the subsetted object.

If you want to subset from a factor using a logical flag vector, keep in mind that the levels of a factor are stored as character strings, even if the original data vector was numeric, so you need to use a string requesting or testing for a particular level. To, for example, identify all the men using the newly labeled sex.num.fac, use this:

```
R sex.num.fac="2"
[1] FALSE FALSE FALSE TRUE FALSE TRUE
```

Since the elements in firstname and sex have corresponding positions in their factors vector, you can use this logical vector to obtain the names of all the men (when using the "male"/"female" factor vector).

```
R firstName[sex.char.fac="male"]
[1] "Boris" "Tim" "Simon"
```
