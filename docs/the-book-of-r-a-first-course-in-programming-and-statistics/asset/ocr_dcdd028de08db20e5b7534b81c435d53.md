Perhaps a bit more generally, let's say you have data for a continuous predictor, X, that you want to model your response, Y. Following estimation in the usual way, linearly, the simple model is $\hat{y} = \beta_0 + \beta_1x$; a quadratic term in X can be modeled via the multiple regression $\hat{y} = \beta_0 + \beta_1x + \beta_2x^2$; a cubic relationship can be captured by $\hat{y} = \beta_0 + \beta_1x + \beta_2x^2 + \beta_3x^3$; and so on. The plots in Figure 21-2, a good way to interpret the effects of including these terms is in the complexity of the curves that can be captured. At order 1, the linear relationship allows no curvature. At order 2, a quadratic function of any given variable allows one "bend." The model can have two bends in the relationship, this continues if you adding terms corresponding to increasing powers of the covariate. The regression coefficients associated with these terms (all implied to be 1 in the code that produced the previous plots) are able to control the specific appearance (in other words, the *strength* and *direction*) of the curvature.
