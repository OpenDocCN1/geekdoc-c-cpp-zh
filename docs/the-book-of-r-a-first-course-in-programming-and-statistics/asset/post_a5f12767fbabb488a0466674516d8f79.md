
## 16.2.1 Uniform

The uniform distribution is a simple density function that describes a continuous random variable whose interval of possible values offers no fluctuations in probability. This will become clear in a moment when you plot Figure 16-4.

![](img/b2cfc85cbb129f60fe595a2bae074fe4_376_0.png)

**Figure 16-4:** Two uniform distributions plotted on the same scale for comparability. Left: X ~UNIF[-0.4,1.1]; right: X ~UNIF(0.223,0.410). The total area underneath each density function is, as always, 1.

For a continuous random variable $a \le x \le b$, the uniform density function $f$ is

> $f(x) = \begin{cases} \frac{1}{b-a} & \text{if } a \le x \le b; \ 0 & \text{otherwise} \end{cases} \quad (16.5)$

where $a$ and $b$ are parameters of the distribution defining the limits of the possible values $X$ can take. The notation

$X \sim UNIF(a,b)$

is often used to indicate that "$X$ follows a uniform distribution with limits $a$ and $b$.

The following are the key points to remember:

- * X can take any value in the interval bounded by $a$ and $b$.
- $a$ and $b$ can be any values, provided that $a < b$, and they represent the lower and upper limits, respectively, of the interval of possible values.

The mean and variance are as follows:

> $$\mu_X = \frac{a+b}{2} \quad \text{and} \quad \sigma_X^2 = \frac{(b-a)^2}{12}$$

For the more complicated densities in this section, it's especially useful to visualize the functions in order to understand the probabilistic structure associated with a continuous random variable. For the uniform variable,

given Equation (16.5), you can recognize the two different distributions shown in Figure 16-4. I'll provide the code to produce these types of plots shortly.

For the left plot in Figure 16-4, you can confirm the exact height of the $X \sim \text{UNIF}(-0.4,1.1)$ density by hand: $1/(1.1 - (-0.4)) = 1/1.5 = 2/3$.

For the plot on the right, based on $X \sim \text{UNIF}(0.223,0.410)$, you can use R to find that its height is roughly 5.35.

```
R> 1/(0.41-0.223)
[1] 5.37594
```

### The dunif function

You can use the built-in $d$-function for the uniform distribution, dunif, to return these heights for any value within the defined interval. The dunif command returns zero for values outside of the interval. The parameters of the distribution, $a$ and $b$, are provided as the arguments $min$ and $max$, respectively. For example, the line

```
dunif(x=c(0.2,-0.23,0.0,1.05,1.2),min=-0.4,max=1)
```

+   [1] 0.000000 0.0666667 0.0666667 0.0666667 0.0666667 0.000000

evaluates the uniform density function of $X \sim \text{UNIF}(-0.4,1.1)$ given in the vector passed to $x$. You'll notice that the first and last values fall outside the bounds defined by $min$ and $max$, and so they are zero. All others evaluate to the height value of $2/3$, as previously calculated.

As second example, the line

```
dunif(x=c(0.3,0.0,0.41),min=0.223,max=0.41)
```

+   [1] 5.37594 0.000000 5.37594

confirms the correct density values for $X \sim \text{UNIF}(0.223,0.410)$ distribution, with the second value, zero, falling outside the defined interval.

This most recent example in random variables should remind you that probability density functions for continuous random variables, *do not* directly provide probabilities, as we have mentioned in Section 15.2. In other words, the results returned by density functions represent themselves and not any of change attached to the specific values of $x$ at which they were evaluated.

To calculate some probabilities on the uniform density function, use the example of a faulty drill press. In a woodworker's shop, imagine there's a drill press that cannot keep to a constant alignment when in use; it randomly hits the intended target. The random variable $X \sim \text{UNIF}(-0.4,1.1)$ represents where the drill hits the material relative to the target at 0 up to 0.4 cm to the left or 1.1 cm to the right. Figure 16-5 replots the left image of Figure 16-4 on a more detailed scale. With three versions, marking off a different area under the density function: $Pr(X \leq -0.21), Pr(-0.21 \leq X \leq 0.6),$ and $Pr(X \geq 0.6)$.

As mentioned earlier, the three shaded areas in Figure 16-5 represent, from left to right, Pr(X < -0.21), Pr(-0.21 < X < 0.6), and Pr(X > 0.6). In terms of the drill example, you can interpret as the probability that the drill hits the target 0.21 cm to the left or more, the probability that the drill hits the target between 0.21 cm to the left and 0.6 cm to the right, and the probability that the drill hits the target 0.6 cm to the right or more, respectively. (Remember from Section 15.2.3 that it makes no difference if you use ≤ or (or >= >) for probabilities

associated with continuous random variables.) Though you could evaluate these probabilities geometrically for such a simple density function, it's still faster to use R.

### The punif function

Remember that probabilities associated with continuous random variables are defined as *areas under the function*, and therefore your study focuses on the appropriate intervals of X rather than any specific value. The p-function for densities, just like the p-function for discrete random variables, provides the cumulative probability distribution $Pr(X \leq x)$. In the context of the uniform density, this means that a given specific value of $x$ (supplied as a "quantile" argument $q$), $punif$ will provide the left-directional area underneath the function from that specific value.

Accessing punif, the line

```
R punif(-0.21,min=a1,max=b1)
[1] 0.126667
```

tells you that leftmost area in Figure 16-5 represents a probability of 0.127. The line

```
R 1-punif(q=0.6,min=a1,max=b1)
[1] 0.333333
```

tells you that $Pr(X > 0.6) = \frac{1}{3}$. The final result for $Pr(-0.21 < X < 0.6)$, finding a 54 percent, is found

```
R punif(q=0.6,min=a1,max=b1) - punif(q=-0.21,min=a1,max=b1)
[1] 0.54
```

since the first call provides the area under the density from 0.6 all the way left and the second call provides the area from -0.21 all the way left. Difference, this is the middle area as defined.

It's essential to be able to manipulate probability results like this when working with probability distributions in R, and the beginner might find it useful to sketch out the desired area before using p-functions, especially with respect to density functions.

### The qunif Function

The q-functions for densities are used more often than they are for mass functions because the continuous nature of the variable means that a quantile value can be found for any valid probability p.
The qunif function is the inverse of punif:

```
R qunif(p=0.1266667,min=a1,max=b1)
[1] -0.21
```

```
R qunif(p=1-1/3,min=a1,max=b1)
[1] 0.6
```

These lines confirm the values of X used earlier to get the lower- and upper-tail probabilities Pr(X < -0.21) and Pr(X > 0.6), respectively. Any q-function expects cumulative (in other words, left-hand) as first argument, which is why we need to supply 1-1/3 in the second line to recover 0.6. (The total area is 1. You know that the want the right of 0.6 to be $\frac{1}{3}$; thus, the area on the left must be $1 - \frac{1}{3}$).

### The Runif Function

Lastly, to generate random realizations of a uniform distribution, you use runif. Let's say the woodworker drills 10 holes using the faulty press; you can simulate one instance of the position of these holes relative to their target with the following:

```
runif(n=10,min=a1,max=b1)
[1] -0.2422972 -0.1226568 0.9318365 0.4829028 0.5963365
[6] 0.2009347 0.3073956 -0.1416678 0.5551468 0.4033372
```

Again, note that the specific values of r-function calls like runif will be different each time they are run.
