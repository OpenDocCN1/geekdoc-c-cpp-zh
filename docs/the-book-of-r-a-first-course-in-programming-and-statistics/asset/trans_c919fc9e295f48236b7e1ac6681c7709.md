
第一行检查 `foo` 中的条目是否等于 `bar` 中对应的条目，只有在第五和第九个条目处为真。返回的向量将包含每对元素的逻辑结果，因此它的长度与所比较的向量长度相同。第二行以相同的方式比较 `foo` 和 `bar`，这次是检查 `foo` 中的条目是否小于 `bar` 中的条目。与第三次比较形成对比，的是者询问条目是否相互小于或等于彼此。最后，第四行检查 `foo` 的成员是否小于或等于增加了 10 的 `bar` 元素。自然地，结果全部为 TRUE。

向量循环（Vector recycling）也适用于逻辑型。让我们使用之前定义的 `foo` 以及一个较短的向量 `baz`。

```
R baz <- foo[c(10,3)]
R baz
[1] 3 1
```

在这里，你创建了一个长度为 2 的向量 `baz`，由 `foo` 的第 10 和第 3 个元素组成。现在考虑以下情况：

```
R foo>baz
[1] FALSE TRUE FALSE TRUE TRUE TRUE FALSE TRUE
```

在这里，`baz` 的元素被循环并与 `foo` 的 10 个元素进行比较。`foo` 的第 1 和 2 个元素与 `baz` 的第 1 和 2 个元素比较，`foo` 的第 3 和 4 个元素与 `baz` 的第 1 和 2 个元素比较，以此此类推。你也可以将向量的所有值与一个单独值进行比较。这里有一个示例：

```
R foo<3
[1] FALSE TRUE FALSE TRUE TRUE TRUE TRUE FALSE
```

这是在 R 中处理数据集时的典型操作。
现在将 `foo` 和 `bar` 的内容重写为 5 × 2 的列填充矩阵。

```
R foo.mat <- matrix(foo,nrow=5,ncol=2)
R foo.mat
[,1] [,2]
[1,] 3 2
[2,] 2 1
[3,] 1 -1
[4,] 4 0
[5,] 1 3
R bar.mat <- matrix(bar,nrow=5,ncol=2)
R bar.mat
[,1] [,2]
[1,] 4 0
[2,] 1 0
[3,] 2 3
[4,] 1 0
[5,] 1 4
```

相同的逐元素行为也适用于此处；如果你比较矩阵，你将得到一个相同大小且填充了逻辑值的矩阵。

```
R foo.mat<bar.mat
[1] [2]
[1,] TRUE FALSE
[2,] FALSE FALSE
[3,] TRUE TRUE
[4,] FALSE TRUE
[5,] TRUE TRUE
R foo.mat<3
[1] [2]
[1,] FALSE TRUE
[2,] TRUE TRUE
[3,] TRUE TRUE
[4,] FALSE TRUE
[5,] FALSE TRUE
```

这种评估也适用于超过两个维的数组。有两个非常有用的函数可以让你快速检查逻辑值集合：`any` 和 `all`。在检查向量时，如果向量中的任何一个逻辑值为 TRUE，则 `any` 返回 TRUE，否则返回 FALSE。
`all` 函数仅在当所有逻辑值都为 TRUE 时才返回 TRUE，否则返回 FALSE。作为一个快速示例，让我们通过本节开始时对 `foo` 和 `bar` 的比较来处理两个逻辑向量。

```
R quux- foo==bar
R quux
[1] FALSE FALSE FALSE TRUE TRUE FALSE FALSE TRUE TRUE
R any(quux)
[1] TRUE
[2] all(quux)
[1] FALSE
```

在这里，`quux` 包含两个 TRUE，其余都是 FALSE——因此 `any` 的结果显然是 TRUE，但 `all` 的结果是 FALSE。遵循相同的规则，`quux` 结果如下：

```
R quux <- foo=(bar+10)
R quux
[1] TRUE TRUE TRUE TRUE TRUE TRUE TRUE TRUE
R any(quux)
[1] TRUE
R all(quux)
[1] TRUE
```

`any` 和 `all` 函数也适用于逻辑值的数组。
