

## 3.3.5 矩阵乘法

为了乘以大小为 $m \times n$ 和 $p \times q$ 的矩阵 $A$ 和 $B$，必须满足 $n = p$。所得矩阵 $A \cdot B$ 的大小为 $m \times q$，乘积元素按行列方式计算，其中位置 $(AB)_{i,j}$ 的值通过 $A$ 的第 $i$ 行元素与 $B$ 的第 $j$ 列元素逐元素相乘并求和得到。这是一个示例：

```
$\begin{bmatrix} 2 & 5 \\ 6 & 1 \end{bmatrix} \begin{bmatrix} 3 & -3 \\ -1 & 5 \end{bmatrix} = \begin{bmatrix} 2x_3+5x_{-1}+2x_1 & 2x_3(-3)+5x_1(1)+2x_5 \\ 6x_3+1x_{-1}(-1)+4x_1 & 6x_3(-3)+1x_1(1)+4x_5 \end{bmatrix}$
```

注意，通常情况下，尺寸合适的矩阵（假设为 $C$ 和 $D$）相乘是不交换的；即 $CD \neq DC$。

与加法、减法和标量法不同，矩阵乘法不是简单的逐元素计算，不能使用标准的 $\cdot$ 运算符。相反，你必须使用 R 的矩阵乘法运算符，用百分号表示为 `%*%`。在尝试之前，让我们先将这两个示例存储在矩阵中，并使用 `dim` 检查第一个矩阵的列数是否与第二个矩阵的行数匹配。

```
R A <- cbind(c(2,5,2),c(6,1,4))
R <- dim(A)
[1] 2 3
R B <- cbind(c(3,-1,1),c(-3,1,5))
R <- dim(B)
[1] 3 2
```

这确认了两个矩阵是可以相法的，因此你可以继续。

```
R A*%B
[,1] [,2]
[1,] 3 9
[2,] 21 3
```

你可以使用相同的两个矩阵证明矩阵乘法是非交换的。交换相法顺序会得到完全不同的结果。

```
R> B%*%
[,1] [2] [3]
[1,] -12 12 -6
[2,] 4 -4 2
[3,] 32 10 22
```

## 3.3.6 矩阵求逆

某些方矩阵是可以求逆的。矩阵 $A$ 的逆记为 $A^{-1}$。可逆矩阵满足以下方程：

```
AA^{-1} = I_m
```

这是一个矩阵及其逆矩阵的示例：

| | 3 1 | 1 -0.5 |
| --- | --- | --- |
| 4 2 | -2 1.5 |

不可逆的矩阵被称为奇异矩阵。当求解涉及矩阵的方程具有重要的实际影响时，矩阵求逆通常是必要的。矩阵求逆有几种不同的方法，随着矩阵尺寸的增大，这些计算可能会变得极其昂贵。我们在这里不会过分细节，但如果你感兴趣，请参考 Golub and Van Loan (1989) 的正式讨论。

目前，我将向你展示 R 函数 `solve` 作为矩阵求逆的一种选项。

```
R> matrix(data=c(3,4,1,2),nrow=2,ncol=2)
R> A
[,1] [,2]
[1,] 3 1
[2,] 4 2
R> solve(A)
[,1] [,2]
[1,] 1 -0.5
[2,] -2 1.5
```

你也可以验证这两个矩阵的乘积（使用矩阵乘法规则）结果为 2×2 单位矩阵。

## 3.4 多维数组

正如矩阵（元素的“矩形”）是可以通过增加维度得到向量（元素的“线”）的结果，*数组*是可以通过增加维度得到更复杂结构的结果。在 R 中，向量和矩阵可以被视为数组的特例，当它们具有更多维度时。

那么，矩阵的下一步是什么？很好，正如矩阵被视为等长度向量的集合，三维数组可以被视为相等矩阵的集合，为你提供长方体元素。你仍然有固定的行数和固定的列数，还有一个新的第三维度称为层。图 3-3 展示了三行四列两层（$3 \times 4 \times 2$）数组。

![](img/b2cf85cbb129f)

图 3-3：三行四列两层（3x4x2）的数组。

要在 R 中创建这些结构，请使用 `array` 函数并用向量指定维度。注意数组是按列填充的。例如：

```
R <- array(1:24, dim=c(3,4,2))
```

## 3.4.2 子集、提取和替换

即使是高维对象也难以想象，R 对它们的索引是一致的。一旦你知道如何子集矩阵，从这些结构中提取元素就变得简单——你只需要在方括号中使用逗号作为访问维度的分隔符。这在下面的示例中得到了强调。

假设你需要之前创建的 AR 第二层的第二行。你只需要输入 AR 的确切维度位置：

```
AR[2,2]
[1] 14 17 20 23
```

所需的元素已以长度为 4 的向量形式提取。如果你想要这个向量中的特定元素，例如第三个和第一个，按该顺序，你可以调用以下代码：

```
AR[2,c(3,1),2]
[1] 20 14
```

再次，这种字面上的子集方法使得处理 R 中的高维对象变得可行。

产生多个向量的提取将以列的形式出现在返回的矩阵。例如，为了提取 AR 两层的第一行，你输入：

```
AR[1,]
[,1] [,2]
[1,] 1 13
```
