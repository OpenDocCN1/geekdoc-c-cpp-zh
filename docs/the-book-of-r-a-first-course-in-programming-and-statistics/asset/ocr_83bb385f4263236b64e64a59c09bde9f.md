# Superimposition of a grid on such a plot is straightforward.

```
R grid(col="darkgray")
```

You can specify the number of cells along the horizontal and vertical axes using the optional arguments nx and ny, respectively; if not, R will draw the grid lines at what would be the default x and y-axis tick marks (as I let it do). Other aesthetics can be altered in the usual way, using arguments such as col (color) and lty (line type).

The fun is part now to work out how to reference the sizes of the plotted points by the weights of the cars. There are a number of ways you might achieve this. For this last example, I manhandle the legend function in an effort to produce the graphic. The following three lines provide the end result.

```
R legend(250,30,legend=rep("3"),pch=rep(1,3),pt.cex=c(1.5,1,0.5))
R arrows(265,27,265,29,length=0)
R text(locator(1),labels="Weight",cex=0.8,family="serif")
```

The legend is placed at user coordinates (250,30), and three points of the default pch type 1 are included—one large, one standard, and one small—using cex set to 1.5, 1, and 0.5, respectively. Instead of writing text labels for each of these points using the legend argument, I simply assign them to empty strings made up of 10 spaces. What does this widen around the legend, creating a space for what will instead accompany the three points—a small-headed arrow pointing upward and the word Weight. Finding suitable coordinates to fit the artificially empty legend box took a little trial and error, and I place the “Weight” text by invoking the interactive locator function as you saw in Section 23.3.

Playing with R functionality to produce intricate plots like this is an excellent way to start learning how to handle the graphical abilities of the language. It’s not uncommon to use trial and error and let cheats reach an end result, though of course that kind of things comes at the expense of the robustness of your code. For example, resizing the graphics device even moderately and attempting to reproduce the cars scatterplot shown earlier will likely result in a misleading of the arrow in the legend. If you want to learn more, the authoritative reference on graphics in R is arguably Murrell (2011), which is a good text to consult once you’re familiar with the fundamentals discussed here and a comprehensive guide on all things visual in R.
