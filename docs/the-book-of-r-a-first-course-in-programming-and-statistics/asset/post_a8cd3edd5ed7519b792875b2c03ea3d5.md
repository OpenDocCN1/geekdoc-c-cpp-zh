## 10.2 Coding Loops

Another programming mechanism is the loop, which repeats a section of code, often while incrementing an index or counter. There are two types of looping: the for loop repeats code as it works its way through a vector, element; the while loop simply repeats code until a specific condition evaluates to FALSE. Loop behavior can also be achieved with R's suite of.

### 10.2.1 for Loops

The for loop always takes the following form:
```R
for(loopindex in vector){
  code
}
```
Here, loopindex is a placeholder that represents an element of the vector. When the loop begins, the code inside the braces is executed. When the loop reaches the final element of the vector, the loopindex is incremented, moving to the next element, at which point the loop exits. Here's a simple example:
```R
counter <- 0
for(myitem in 5:7){
  counter <- counter+1
  cat("the item in run",myitem,\n")
}
```
The output is:
```
the item in run 5
the item in run 6
the item in run 7
```
Here, I initially defined an object, counter, and set it to zero. You can use loops to manipulate objects that exist outside the loop.

### 10.2.2 Looping via Index

Note the difference between using loopindex to represent represent elements the vector and using it to represent indexes. The following two loops use two different approaches to double each number in myvec:
```R
myvec <- c(0.4,1,1.34,0.55)
R> for(i in myvec){
  print(2*i)
}
R> for(i in 1:length(myvec)){
  print(2*myvec[i])
}
```
The first loop uses loopindex i to directly represent the elements in myvec, printing the value of each element times 2. In the second loop, on the other hand, you use i to represent integers in the sequence 1:length(myvec). These indexes form all index positions of myvec, and you use these indexes to extract myvec's elements (once again multiplying by 2 and printing the result). Though it takes a slightly longer form, using vector index positions provides more flexibility in terms of how you use the loop. This will be clearer when you demand more complicated for loops, such as in the next example.
