When you run the code, the braced area is repeated over and over until fib.b reaches the first number that is greater than 150, namely, 89 + 144 = 233. Once that happens, the if statement condition evaluates TRUE, and R runs into break, terminating the loop.
The repeat statement is not as commonly used as the standard while or for loops, but it is useful if you don't want to be bound by formally specifying the loopindex and loopvector of a for loop or the loopcondition of a while loop. However, with repeat, you have to take a bit more caution to prevent infinite loops.
