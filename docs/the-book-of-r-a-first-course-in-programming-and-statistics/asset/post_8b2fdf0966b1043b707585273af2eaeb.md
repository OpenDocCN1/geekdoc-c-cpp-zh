When both predictors in a two-way interaction are categorical, will be a term for each reference level of the first predictor with all prediction depends on the second predictor. ## 21.5.4 Two Continuous

Finally, you will look at the situation when the two predictors are continuous. In this case, an interaction term operates as a modifier on the continuous plane's fitted using the main effects. In a similar way to an interaction between a continuous and a categorical predictor, an interaction between continuous explanatory variables allows the slope associated with one variable to be affected, but this time, that modification is made in a continuous way (that is, according to the value of the continuous variable).

Returning to the mtcars data frame, consider MPG once more as a function of horsepower and weight. The fitted model, shown next, includes the interaction in addition to the main effects of the two continuous predictors. as you can see, there is a single estimated interactive term, and it is deemed significantly different from zero.

R car.fit <- lm(mpg~hp*wt,data=mtcars)
