
选择了 `barplot`。参数 `las=1` 强制垂直轴上的标签水平显示，而不是与轴线平行。前两个参数 `legend.text` 和 `args.legend` 用于图例——你也可以像第7.3节中那样通过 `legend` 单独绘制图例，但这种方法可以自动化颜色分配，以确保引用键与条形本身的精确阴影匹配。

使用 `ggplot2` 也可以生成类似的图表。如果你通过 `library("ggplot2")` 安装了包并输入以下内容，它将生成图14-2左侧所示的最基础条形图：

```
R qplot(factor(mtcars$cyl),geom="bar")
```

注意，这里相关的 `geom` 是 `"bar"`（如果单独使用则是 `geom_bar`，你稍后会看到），并且 ggplot 中的默认映射变量必须作为因子（factor）提供（在 `mtcars` 中，向量 `mtcars$cyl` 是数值型的，这对于条形图来说没问题，但 ggplot2 的功能要严格得多）。

![](img/b2cfc85cbb129f60fe595a2bae074fe4_325_0.png)

图14-2：使用 ggplot2 功能生成的 mtcars 数据两个条形图示例。左侧是最简单的图表版本，使用了一个分类变量。右侧是“错开”（dodged）条形图，与图14-1相同，基于提供的各种额外 geoms 和缩放选项。

同样，你可以根据想要显示的内容创建更复杂的图像。要生成14-1中错开条形图的 ggplot2 版本，请调用以下代码：

```
R qplot(factor(mtcars$cyl))
```

你可以在图14-2的右侧找到结果。

注意基础 ggplot 设置中的一些新添加。按 `cyl` 的默认映射（mapping）与之前相同。你进一步指定条形应根据由传输变量 `am` 创建的因子进行填充，因此每个 `cyl` 条形都被指示按该变量进行拆分。初始对 `ggplot="empty"` 的调用，在 `geom="blank"` 的意思是，因此通过向 ggplot 对象中添加 `geom_bar` 来绘图。通过 `position="dodge"`，它变成了一个错开条形图；在 R Graphics 中，默认行为是生成堆叠图。`scale_x_discrete` 修饰符为默认 `cyl` 映射的每个类别标记；`scale_y_continuous` 修饰符用于控制频率的轴标签。

此外，向对象添加 `theme_[]` 会更改图像的视觉主题；在当前示例中，我选择了移除灰色背景，因为它与手动汽车的条形太相似了。向对象中添加 `color_flip` 会翻转轴，并提供水平条形而不是默认的垂直样式（注意，对 scale 函数的调用是未映射的图像使用的）。`fill` 的默认行为是使用颜色，因此你使用 `scale_fill_grey` 修饰符通过灰度来找到它，并同时缩放自动生成的标签以匹配。

在这种案例中，使用 ggplot2 相比此最显著的优势在于，你不需要手动统计计数或设计这些频率的矩阵结构——变量映射会自动完成这些工作。为了练习，我鼓励你尝试这段代码，省略或修改 ggplot 对象的某些添加项，以评估它们对生成图像的影响。

## 14.2 直方图

条形图在与分类变量相关的观测值计数方面直观且合理，但如果你感兴趣的变量是数值连续型的，它几乎没有任何用处。为了可视化连续测量值的分布，你可以使用直方图——由于其外观相似，这种工具有时会与条形图混淆。直方图也测量频率，但在针对数值连续变量时，首先需要对观测数据进行“分箱”（bin），即定义区间，然后计算落在每个区间内的连续观测值数量。区间的大小被称为箱宽（binwidth）。

直方图的一个简单示例，考虑 mtcars 中 32辆汽车的马力数据，位于第四列，命名为 `hp`。

```
R> mtcars$hp
[1] 110 93 110 175 105 245 62 95 123 120 180 180 205 215 230 66
[19] 52 65 97 150 245 175 66 91 113 264 175 339
```

对于这一节，将那个时代所有性能汽车的马力定义为总体，并假设这些观测值代表该总体的一个样本。使用基础 R 图形，直方图接受一个数值连续观测向量并生成直方图，如图14-4左侧所示。

```
R> hist(mtcars$hp)
```

## mtcars$Hp 马力直方图

![](img/b2cfc85cbb129f60fe595a2bae074fe4_328_0.png)

图14-4：说明 hist 在 mtcars 马力数据上的默认行为（左侧），自定义箱宽、颜色和标题选项，以及添加中心性标记（右侧）。

你可以立即看到，左侧的直方图使用了 50 单位的箱宽，跨越数据范围，为你提供了关于马力测量分布的快速且实用的印象。它似乎大致集中在 75 到 150 的范围内，向右递减（这被称为右偏或正偏），该术语将在 15.2.4 节中介绍）。

直方图作为分布形状表示的准确性完全取决于用于分箱的区间宽度。箱宽在 `hist` 中通过 `breaks` 参数控制。你可以通过向 `breaks` 提供一个向量，给出每个断点来手动设置这些。在以下代码中，通过将箱宽从 50 减到 25 并扩大整体范围，使用等距序列来实现。

```
R> hist(mtcars$Hp,breaks=seq(0,400,25),col="gray",main="Horsepower",xlab="HP")
R> abline(v=c(mean(mtcars$Hp), median(mtcars$Hp))),lty=c(2,3),lwd=2)
R> legend("topright",legend=c("mean HP","median HP"),lty=c(2,3),lwd=2)
```

右侧的图显示了使用更窄箱的结果，并将条形变为灰色并添加了更易读的标题。它包含了表示平均值和中值的垂直线，使用了 `abline`（参考第7.3节）。
