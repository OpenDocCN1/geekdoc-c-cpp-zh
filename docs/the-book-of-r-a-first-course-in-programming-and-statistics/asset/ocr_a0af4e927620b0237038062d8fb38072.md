The first call to pnorm evaluates the area under the curve from positive 1 left (in other words, all the way to $-\infty$) and then finds the difference between and the area from -1 left. The result finds the proportion between the two dashed lines in the bottom of Figure 16-6. These kinds of distributions of probabilities will be the same for *any* normal distribution. Consider the distribution where $\mu = -3.42$ and $\sigma = 0.2$. Then the following provides the same value:

```
R mu <- -3.42
R sigma <- 0.2
R mu.minus.isig <- mu-sigma
R mu.minus.isig
[1] -3.62
R mu.plus.isig <- mu+sigma
R mu.plus.isig
[1] -3.22
R pnorm(q=mu.plus.isig,mean=mu,sd=sigma)
pnorm(q=mu.minus.isig,mean=mu,sd=sigma)
[1] 0.6826895
```
