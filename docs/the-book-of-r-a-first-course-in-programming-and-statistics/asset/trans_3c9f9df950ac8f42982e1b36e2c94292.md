# 4.1.4 逻辑值就是数字！

由于逻辑值的二值化特性，它们通常被表示为 TRUE 为 1，FALSE 为 0。实际上，在 R 中，如果你对逻辑值执行基础数值运算，TRUE 会被视为 1，FALSE 会被视为 0。

```
R> TRUE+TRUE
[1] 2
R> FALSE-TRUE
[1] -1
R> T+T+F+T+F+T
[1] 4
```

这些操作的结果与你使用数字 1 和 0 相同。在某些使用逻辑值的情况下，你可以用数值替换它们。

```
R> 1&&1
[1] TRUE
R> 1||
[1] TRUE
R> 0&&1
[1] FALSE
```

能够将逻辑值解释为 0 和 1 意味着你可以使用各种函数来对逻辑向量进行汇总，我们将在第三部分进一步探讨这一点。

# 4.1.5 逻辑子集与提取

逻辑值也可以用于从向量和其他对象中提取和子集元素，这与你迄为止使用的索引向量的方法相同。与其在方括号中输入显式索引，不如提供逻辑标志向量，如果标志向量中的对应条目为 TRUE，则提取该元素。因此，逻辑标志向量的长度应该与被访问的向量相同（尽管后文示例所示，较短的标志向量会发生循环）。

在第 2.3.3 节开头，你定义了一个长度为 10 的向量：

```R
R myvec <- c(5,-2.3,4,4,4,6,8,10,40221,-8)
```

如果你想提取两个负元素，可以输入 `myvec[c(2,10)]`，也可以使用逻辑标志进行操作：

```R
R myvec[c(F,T,F,F,F,F,F,F,T)]
[1] -2.3 -8.0
```

这个特定的示例在实际使用中可能太繁琐；但当你想要根据元素是否满足某个条件（或多个条件）来提取元素时却是如此。例如，你可以通过条件 `myvec<0` 轻松地找到 myvec 中的负元素。

```R
R myvec<0
[1] FALSE TRUE FALSE FALSE FALSE FALSE FALSE FALSE TRUE
```

这是一个完全标志，你可以用它对 myvec 进行子集提取以获得之前的结果。

```R
R myvec[myvec<0]
[1] -2.3 -8.0
```

如所述，如果标志向量太短，R 会对其进行循环。要从 myvec 中从第一个元素开始提取第二个元素，你可以输入：

```R
R myvec[c(T,F)]
[1] 5 4 8 40221
```

你可以使用关系运算符和逻辑运算符进行更复杂的提取，例如：

```R
R> myvec[(myvec>0)&(myvec<1000)]
[1] 5 4 4 4 6 8 10
```

这返回小于 1,000 的正元素。你也可以使用逻辑向量覆盖特定元素，就像使用索引向量一样。

```R
R> myvec<- -200
R> myvec
[1] 5 -200 4 4 4 6 8 10 40221 -200
```

这将所有现有负条目替换为 -200。注意，你不能直接使用负逻辑向量来删除特定元素；这只能通过数值索引向量完成。

如你所见，逻辑值对于元素提取非常有用。你不需要预先知道哪些特定的索引位置，条件检查可以为你找到它们。当你处理大型数据集并想要检查记录或重新编码符合标准的条目时，这尤为有价值。

在某些情况下，你可能想将逻辑向量转换为数值索引。当你需要被标记为 TRUE 的元素的显式索引时，这很有帮助。接收逻辑向量作为参数 x 的 R 函数返回对应任何及所有 TRUE 条目位置的索引。

```R
R> which(x=c(T,F,F,T,T))
[1] 1 4
```

你可以用此识别 myvec 中满足特定条件的索引位置；例如包含负数的那些：

```R
R> which(x=myvec<0)
[1] 2 10
```

对你实验过的其他 myvec 选择也可以同样的操作。注意，诸如 `myvec[which(x=myvec<0)]` 这样的代码行是冗余的，因为可以使用条件本身进行提取，即通过 `myvec[myvec<0]` 而不使用 `which`。另一方面，`which` 允许你识别想要删除的数值索引并将其删除。要省略 myvec 中的负条目，你需要执行以下操作：

```R
R> myvec[-which(x=myvec<0)]
[1] 5 4 4 4 6 8 10 40221
```

矩阵和其他数组也可以同样的操作。在第 3.2 节中，你按如下存储了一个 3 × 3 矩阵：

```R
R A <- matrix(c(0,3,3,4,4,4,6,8,8), nrow=3)
```
