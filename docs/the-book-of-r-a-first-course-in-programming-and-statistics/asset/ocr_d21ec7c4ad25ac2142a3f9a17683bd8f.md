You can also install R packages from source, that is, from the uncompiled code, which may have more recent updates than the precompiled version of the package. If you're an OS user, recent versions of R will ask you whether you'd like to download packages from source for packages available that are more recent than the precompiled version. To do so, you need certain command line tools installed on your system; if the download fails, you can stick with the binary version by answering n (“no”) at the download from prompt.

# Installing Packages with the GUI

The basic R graphical interface (GUI) used in this book gives you the option to download and install contributed packages from the console using menu items. Here, you'll look briefly at the Windows and OS versions.
On Windows, click the Packages → Install package(s)... menu item, shown on the left of Figure A-6. Select a CRAN mirror and a tail window will open, listing all available packages in alphabetical order. Scroll to select the package you're interested in. You can see my selection of ks on the right of Figure A-6. Click OK to download and install the packages and dependencies.
