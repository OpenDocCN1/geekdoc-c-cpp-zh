off one pixel as interpreted by image and one facet as interpreted by perp. With that, you can see why, in Figure 25-9, there would be exactly 6 × 4 = 24 pixels in an image plot 5 × 3 = 15 facets in a perspective plot.

The highlighted box in the bottom-left corner represents an image plot of the value a in the z-matrix; the highlighted box to the right represents a perp facet formed by the values b, h, i, and c. For coloring, the z-value of the highlighted facet will be calculated as the mean of the four facets, in entries, [b + h + i + c]/4..

The col argument needs to specify the (m – 1) × (n – 1) facet colors (assuming an m × n z-matrix passed to z). The typical way to find this in R if you are intending to color the facets according to the z-value is to calculate each facet s z-value, which will be the average of the four adjacent z-matrix entries. Only then can you deploy one of the color assignment approaches from Section 25.1.4.
