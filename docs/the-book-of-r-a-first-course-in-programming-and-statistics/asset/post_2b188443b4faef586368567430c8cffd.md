# 12.3.2 Data Frame Variable Distinction

There's one common situation in which you'll add a data frame to the search path. Let's see how this works. Continuing in the current workspace, define the following data frame:

```R
R foo <- data.frame(surname=c("a","b","c", "d"),
                      sex=c(0,1,1,0),height=c(170,168,181,180),
                      stringsAsFactors=F)
```

```R
R foo
      surname a sex height
1       a 0 170
2       b 1 168
3       c 1 181
4       d 0 180
```

The data frame has three column variables: person, sex, and height. To access one of these columns, normally you need to use the $ operator and enter something like foo$surname. However, you can attach a data frame directly to your search path, which makes it easier to access a variable.

```R
R attach(foo)
R search()
[1] "GlobalEnv" "foo" "package:MASS"
[4] "package:spstat" "tools:RGUI" "package:stats"
[7] "package:graphics" "package:grDevices" "package:utils"
[10] "package:datasets" "package:methods" "Autoloads"
[13] "package:base"
```

Now the variable is directly accessible.

```R
R surname
[1] "a" "b" "c" "d"
```

This saves you from having to enter foo$ every time you want to access a variable, which can be a handy shortcut if your analysis deals exclusively with static, unchanging data frame. However, if you forget about your attached objects, they can cause problems, especially if you continue to mount more objects onto the search path in the same session. For example, say you enter another data frame.

```R
R bar <- data.frame(surname=c("e","f","g","h"),
                      sex=c(1,0,1,0),weight=c(55,70,87,79),
                      stringsAsFactors=F)
```

```R
R bar
      surname sex weight
1       e 1 55
2       f 0 70
3       g 1 87
4       h 0 79
```

Then add it to the search path too.

```R
R attach(bar)
The following objects are masked for foo:
sex, surname

The notification tells you that the bar object now precedes foo in the search path.

```R
R search()
[1] "GlobalEnv" "bar" "foo"
[4] "package:MASS" "package:spstat" "tools:RGUI"
[7] "package:stats" "package:graphics" "package:grDevices"
[10] "package:utils" "package:datasets"
[13] "Autoloads" "package:base"
```

As a result, any direct use of either sex or surname will now access bar's contents, not foo's. Meanwhile, the unmasked variable height from foo is still directly accessible.

```R
R height
[1] 170 168 181 180
```

This is a pretty simple example, but it highlights the potential for fusion when data frames, lists, or other objects are added to the search path. Mounting objects this way can quickly become difficult to track, especially for large data sets with many different variables. For this reason, it's best to avoid attaching objects this way as a guideline—note that detach can be used to remove objects from the search path in a similar way as you saw with packages. In this case, you can enter the object name itself.

```R
R detach(foo)
R search()
[1] "GlobalEnv" "bar" "package:MASS"
[4] "package:spstat" "tools:RGUI" "package:stats"
[7] "package:graphics" "package:grDevices" "package:utils"
[10] "package:datasets" "package:methods" "Autoloads"
[13] "package:base"
```

# ELEMENTARY STATISTICS

Statistics is the practice of turning data into information to identify trends and understand features of populations. This chapter will cover some basic definitions and use R to demonstrate their application.

## 13.1 Describing Raw Data

Often, the first statistical analysts are faced with raw data—in other words, the records or observations that make up a sample. Depending on the nature of the intended analysis, these data could be stored in a R object, often a data frame (Chapter 5), possibly read from an external file using techniques from Chapter 8. Before you can begin summarizing or modeling your data, however, it is important to clearly identify your variables.

A variable is a characteristic of an individual in a population, the value of which can differ within that population. For example, in Section 5.2, you experimented with an illustrative data frame. You recorded the age, sex, and humor level for a sample of people. These characteristics are your variables; the values measured will differ between individuals.

Variables can take a number of forms, determined by the nature of the values they may take. Before jumping into R, you'll look at some standard ways in which variables are described.

### 13.1.1 Numeric Variables

A numeric variable is one whose observations are naturally recorded as numbers. There are two types of numeric variables: continuous and discrete.

A continuous variable can be recorded as any value in some interval, up to any number of decimals (which technically gives an infinite number of possible values, even if the continuum is restricted in range). For example, if you were observing rainfall amount, a value of 15 mm would make sense, but would a value of 15.42135 mm? Any degree of measurement precision gives a valid observation.

A discrete variable, on the other hand, may take only distinct numeric values—and if the range is restricted, the number of possible values is finite. For example, if you were observing the heads in 20 flips of a coin, only heads would make sense. It would not make sense to observe 15.42135 heads; the possible outcomes are restricted to the integers from 0 to 20 (inclusive).

### 13.1.2 Categorical Variables

Though numeric observations are common for many variables, it's also important to consider categorical variables. Like some discrete variables, categorical variables may take only one of a finite number of possibilities. Unlike discrete variables, however, categorical observations are not recorded as numeric values.

There are two types of categorical variables. Those that cannot be logically ranked are called nominal. A good example of a categorical-nominal variable is sex. In most data sets, it has two possible values, male and female, and the order of these categories is irrelevant. Categorical variables that can be naturally ranked are called ordinal. An example of a categorical-ordinal variable would be the dose of a drug, with the possible values low, medium, and high. These values can be ordered in either increasing or decreasing amounts, and the ordering might be relevant to the research.
