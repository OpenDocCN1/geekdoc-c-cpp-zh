# Confidence Intervals for Mean Heights

To find confidence intervals for these estimates, you could calculate them manually using (20.5), but of course R has a built-in predict command to do it for you. To use predict, you first need to store your x values in a particular way: as a column in the data frame. The name of the column must match the predictor in the original code to create the fitted model object. In this example, I'll create a new data frame, with the column Wr.Hnd, which contains only two values of interest—the handspans of 14.5 and 24 cm.

```
R> xvals <- data.frame(Wr.Hnd=c(14.5,24))
R> xvals
R> Wr.Hnd
   1  14.5
   2  24.0
```

Now, when predict is called, the first argument must be the fitted object of interest, survfit for this example. Next, in the argument newdata, you pass the specially constructed data frame containing the specified predictor. To the interval you must specify "confidence" as a character string. The confidence level, here set for 95 percent, is passed (on the scale of a probability) level.

```
R> mypred.ci <- predict(survfit,newata=xvals,interval="confidence",level=0.95)
R> mypred.ci
   fit      lwr      upr
1 159.1446 156.4956 161.7936
2 188.7524 185.5726 191.9323
```

This will return a matrix with three columns, whose number (and order) of rows correspond to the predictor values you supplied in the newdata data frame. The first column, with a heading of fit, is the point estimate on the regression line; you can see that these numbers match the values you worked out. The other columns provide the lower and upper CI limits as the lwr and upr columns, respectively. In this case, you would interpret this 95 percent confidence that the mean height of a student with a handspan of 14.5 cm lies between 156.5 cm and 161.8 cm and 185.6 cm and 191.9 cm for a handspan of 24 cm (when rounded to 1 d.p.). Remember, these CIs, calculated as per (20.5) through predict, are for the mean response.

# Prediction Intervals for Individual Observations

The prediction function will also provide your prediction intervals. To find the prediction interval for possible individual observations with a certain probability, you simply need to change the interval argument to "prediction".

```
R> mypred.pi <- predict(survfit,newata=xvals,interval="prediction",level=0.95)
R> mypred.pi
```
