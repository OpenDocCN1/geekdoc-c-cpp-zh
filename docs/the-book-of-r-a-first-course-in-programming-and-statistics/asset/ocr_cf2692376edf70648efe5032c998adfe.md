Then you use dmvnorm to get the numeric value of the standard trivariate normal just as you do in the bivariate setting. The function automatically knows you're requesting the trivariate density because your data argument has three columns.

```
w <- array(dmvnorm(xyz),c(50,50,50))
```

Note that the result is stored properly as a 50 × 50 × 50 3D array—refer to Section 3.4 for details on array. Look at the conceptual diagram of a 3D array (Figure 3-3 on page 53) and compare it to the 3D lattice on the right of Figure 26-10. The trivariate normal values are represented by a 3D block of numbers sitting at each evaluation coordinate in the defined 3D space.

An isosurface can be produced using the contour3 function, of the misc3d package (Feng and Tierney, 2008), which works closely with rgl. To use it, you need to decide on the level (or levels) at which to plot the surface. For contours; for more details, see the authoritative text on the α-level theory of trivariate densities by Scott (1992). In brief, for some density f, these delineate the (1 - α) × 100 percent “most dense” observations by setting the isosurface to be drawn at positions in the multivariate evaluation lattice that corresponds to the density value by a × max(f).

For the trivariate normal, the maximum value of the density is located at the coordinate (0,0,0).

```
R max3d.norm <- dmvnorm(c(0,0,0),mean=c((0,0,0))
R max3d.norm
[1] 00634964
```

You'll need this producing the next couple of plots. Install misc3d, load it with library("misc3d"), and then call contour3.

```
R contour3(x=vals,y=vals,z=vals,f=0.05+max3d.norm)
```

This produces an isosurface in an RGL that can rotate and zoom as you desire; you can see the result on the left of Figure 26-11. You supply contour with the arguments x, y, and z as equally sequences in the x-, y-, and z-coordinates, respectively. You supply the 3D array, defining the entire result of the trivariate function to f, and pass the level (or levels) at which you want to draw the isosurface itself to level. Here, I've chosen the αlevel to leave only 5 percent of the probability in the tails of the distribution, meaning that 95 percent of the total mass is held within the “blob”.
