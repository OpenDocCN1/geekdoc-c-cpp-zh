Now, let's replot this data using the same aplot object with a suite of geom modifications in order to get something more like Figure 7-6. Executing the following produces the plot on the right of Figure 7-11:

```
R> ggplot(x,y,color=ptype) + geom_point(size=4) + 
  geom_line(mapping=aes(group=1),color="black",lty=2) +
  geom_hline(mapping=aes(intercept=(-5,5)),color="red") +
  geom_segment(mapping=aes(x=5,y=-5,xend=5,zend=5),color="red",lty=3) +
  geom_segment(mapping=aes(x=15,y=-5,xend=15,zend=5),color="red",lty=3)
```

In the first line, you add geom_point(size=4) to increase the size of all the points. In the lines that follow, you add a line connecting all the points, plus horizontal and vertical lines to mark the sweet spot. For those last four lines, you have to use aes to set alternate aesthetic mappings for the point categories. Let's look a closer at what's going on.

Since you used ptype for aesthetic mapping in the initial call to a, by default all other geoms will be mapped to each category in the same way, unless you override that mapping with aes. For example, when you call geom_line to connect to all the points, if you want to stick with the default line instead of mapping=aes(group-1), this geom would map to ptype and draw lines within each category. You will see four dashed lines—one connecting “standard” points, another connecting all “sweet” points, and so on. But that's not what you want here; you want a line that connects all of the points, from left to right. So, you will geom_line to treat all the observations as one group by entering aes(group=1).

After that, you use the geom_hline to draw horizontal lines with y = -5 and y =5 using its intercept argument, passed to aes to redefine that geom's mapping. In this case, you need to redefine the mapping to operate on the vector=(-5,5), rather than using the observed data in x and y. Similarly, you use geom_segment to draw the two vertical dotted line segments, geom_segment operates like you redefine the mapping based on a “from” coordinate (arguments x and y) and a “to” coordinate (x and y end). Since the first geom, geom_point(size=4), a constant enlarged for every plotted point, it doesn't matter how the geom is mapped because it simply makes a uniform change to each point.
