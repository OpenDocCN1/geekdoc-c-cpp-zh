I won't go into the specifics of converting a RGB triplet to a hexadecimal because it's beyond the scope of this book, but it's important to know that R represents all colors you create using RGB triplets as hex codes, so you should be able to at least recognize a hexadecimal when you're working with colors and color palettes in plotting.

For an even more colorful exploration, let's write a little function to plot points in individual colors and label them appropriately with RGB triplets and corresponding hex codes. Consider the following in the editor:

```
pcol <- function(cols){
n <- length(cols)
dev.new(width=7,height=4)
par(mar=rep(1,4))
plot(1,5,1,type="n",xaxt="n",yaxt="n",ann=FALSE)
for (i in 1:n){
pt <- locator(i)
rgbval <- col2rgb(cols[i])
points(pt,x+1,y,pch=19,family="mono",
label=paste("\",",cols[i],"\","\","\nR: "",rgbval[1],
G: "",rgbval[2],"",rgbval[3],
hex: "",rgb(rgbval),maxColorValue=255,
sep="=")
}
```
