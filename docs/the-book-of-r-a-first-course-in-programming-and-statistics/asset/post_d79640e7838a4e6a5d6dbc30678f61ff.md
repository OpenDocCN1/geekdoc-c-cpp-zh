# 26.2 Bivariate Surfaces

Next you'll look at plotting bivariate surfaces—a continuous surface calculated with respect to a 2D x-y evaluation grid—with rgl. In Chapter 25, you plotted these using contour, filled.contour, image, and persp in Base R graphics Anything you're able to plot using these functions can also be plotted as an interactive perspective plot with the persp3d function of rgl.

# 26.2.1 Basic Perspective Surface

Take the mtcars response surface of mean MPG as a function of horsepower and weight (first used in Section 25.4.1) as an easy initial example. In Section 25.6.1, you plotted static, base perspective plots of this surface. The next few will refine the multiple linear regression model and re-create the 20 × 20 grid x and y-sequences:

```R
car.fit <- lm(mpg~hp+wt,data=mtcars)
len <- 20
hp.seq <- seq(min(mtcars$hp),max(mtcars$hp),length=len)
wt.seq <- seq(min(mtcars$wt),max(mtcars$wt),length=len)
hp.wt <- expand.grid(hp=hp.seq,wt=wt.seq)
```

To create the surface, predict using the evaluation grid in hp.wt as you've done previously, but this time, include the calculation of a prediction interval for raw observations.

```R
car.pred <- predict(car.fit,newData=hp.wt,interval="prediction",level=0.99)
```

(You'll use the interval in a later example.) Then, construct the z-matrix and draw a green persp3d surface with the following lines:

```R
car.pred.mat <- matrix(car.pred[,1],nrow=len,ncol=len)
persp3d(x=hp.seq,y=wt.seq,z=car.pred.mat,col="green")
```

The result is shown on the left of Figure 26-4. If you compare it to Figure 25-1 on page 681, you can see it shows the same surface. The default lighting and shadowing effect produced by the persp3d surface helps with depth, similar to the shade argument to persp. The main benefit of this is the mouse-based rotation and zoom.

# 26.2.2 Additional Components

Another useful attribute of the persp surface is the ability to add further components—something that's nowhere in base functionality. You'll continue using the objects just created for the mtcars response surface.

# Adding Points

As this response surface is based on a model fitted to the data on the three variables horsepower, weight, and MPG, for this, you could use points3d, which works like points in base graphics. Execute the following:

```R
pers3d(x=hp.seq,y=wt.seq,z=car.pred.mat,col="red",alpha=0.7,
xlab="Horsepower",ylab="Weight",z="mean MPG")
points3d(mtcars$hp,mtcars$wt,mtcars$mpg,col="green",size=10)
```

Resize the RGL plot to your liking and keep the device open. This time in red at 70 percent opacity using the optional alpha argument, and then the added to the same image in green, slightly enlarged from their default size. You can see this plot on the right of Figure 26-4; you can now compare the fit of the response surface to the data and view it from any angle.

# Adding Surfaces

You can also add more perspective surfaces! Let's continue to add to the current plot using the car.pred object you created for Figure 26-4. The response surface is stored as the first column in car.pred; the corresponding lower and upper prediction limits are stored as the second and third columns—back to Section 20.4.2 for a discussion of predict for linear regression models. To add these prediction bounds to the response surface displayed on the right of Figure 26-4, you will need to store each bounding surface as a z-matrix corresponding to the x-y evaluation grid.

```R
car.pred.lo <- matrix(car.pred[,2],nrow=len,col=1)
car.pred.up <- matrix(car.pred[,3],nrow=len,col=1)
```

Then, simply persp3d for each of these z-matrices and use the optional argument add=TRUE—this instructs the persp3d function to add to the existing graph without refreshing the plot.

```R
pers3d(x=hp.seq,y=wt.seq,z=car.pred.up,col="cyan",add=TRUE,alpha=0.5)
pers3d(x=hp.seq,y=wt.seq,z=car.pred.lo,col="cyan",add=TRUE,alpha=0.5)
```

We've also set the color for each additional surface and set the opacity at 50 percent. You can see the result on the left of Figure 26-5.

After rotating it with your mouse, you'll be able to see that the observations all fall between the 3D 99 percent prediction interval bounds for this particular model.

Alternatively, you could label raw observations with the row attribute of the original mtcars data frame as added text so that you could identify which car is in the plot. In this case, the names are obtained as a vector of character strings using the built-in rownames function. To add text to an existing 3D graphic, rgl has its own analog of the traditional text function. Executing the following lines replaces the fluorescent red response surface, adding the appropriate text at the (x,y,z) coordinates that correspond to car, and adds the cyan prediction interval:

```R
pers3d(x=hp.seq,y=wt.seq,z=car.pred.mat,col="red",alpha=0.7,
xlab="horsepower",ylab="weight",z="mean MPG")
pers3d(x=mtcars$hp,y=mtcars$mpg,z=mtcars$mpg,text=rownames(mtcars),cex=0.75)
pers3d(x=hp.seq,y=wt.seq,z=car.pred.lo,col="cyan",add=TRUE,alpha=0.5)
```

The text is harder to visualize than the green dots, so it makes sense to point their locations on the fitted surface—and what better way to do so than using the fitted model residuals? (refer to Section 26.1 for an explanation of segments3d).
