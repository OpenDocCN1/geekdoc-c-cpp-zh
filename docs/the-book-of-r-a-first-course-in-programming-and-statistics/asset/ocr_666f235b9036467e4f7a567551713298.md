brace, the loopindex is incremented, taking on the second element of the loopvector, and the braced area is repeated. This continues until the loop reaches the final element of the loopvector, at which point the braced code is executed for the final time, and the loop exits.

Here's a simple example written in the editor:

```
for(myitem in 5:7){
  cat("--BRACED AREA BEGINS\n")
  cat("the current item is\",myitem,\n")
  cat("--BRACED AREA ENDS---\n")
}
```

This loop prints the current value of the loopindex (which I've named myitem here) as it increments from 5 to 7. Here's the output after sending to the console:

```
--BRACED AREA BEGINS--
t current item is 5
--BRACED AREA ENDS--
```

```
--BRACED AREA BEGINS--
t current item is 6
--BRACED AREA ENDS--
```

```
--BRACED AREA BEGINS--
t current item is 7
--BRACED AREA ENDS--
```

You can use loops to manipulate objects that exist outside the loop. Consider the following example:

```
R> counter <- 0
for(myitem in 5:7){
  counter <- counter+1
  cat("the item in run",is",myitem,\n")
}
```

The item in run 1 is 5
The item in run 2 is 6
The item in run 3 is 3

Here, I initially defined an object, counter, and set it to zero in the workspace. Inside, the loop, counter is overwritten by itself plus one. Each time the loop repeats, counter increases, and the current value is printed to the console.
