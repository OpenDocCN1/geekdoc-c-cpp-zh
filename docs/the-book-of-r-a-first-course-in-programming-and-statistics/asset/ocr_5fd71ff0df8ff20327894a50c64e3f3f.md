# 6.2.1 Attributes

Each R object you has additional information about the nature of the object itself. This additional information is referred to as the object's attributes. You've see a few attributes already. In Section 3.1.3, you identified the dimensions attribute of a matrix using dim. In Section 4.3.1, you used levels to get the attributes of a factor. It was also noted that names can get the member names of a list in Section 5.1.2, and in Section 6.1.3, that an attribute annotates the result of applying na.omit.

In general, you can think attributes as explicit or implicit. Explicit attributes are immediately visible to the user, while R determines implicit attributes internally. You can print explicit attributes for a given object with the attributes function, which takes any object and returns a named list. Consider, for example, the following 3 x 3 matrix:

```
R foo <- matrix(data=1:9,nrow=3,ncol=3)
R foo

[1] 1 4 7
[2] 2 5 8
[3] 3 6
```

```
R attributes(foo)
$dim
[1] 3 3
```
