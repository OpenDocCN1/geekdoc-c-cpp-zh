# 10.2 Coding Loops

Another programming mechanism is the loop, which repeats a section of code, often while incrementing an index or counter. There are two types of looping: the for loop repeats code as it works its way through a vector, element; the while loop simply repeats code until a specific condition evaluates to FALSE. Loop behavior can also be achieved with R's suite of apply functions, which are discussed in Section 10.2.3.

# 10.2.1 for Loops

The R for loop always takes the following general form:

```
for(loopindex in loopvector{
  do code in here}
```

Here, the loopindex is a placeholder that represents an element in the loopvector—it starts off as the first element in the vector and moves to the next element with each loop repetition.
