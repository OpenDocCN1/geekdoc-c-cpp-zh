# # INSTALLING R AND CONTRIBUTED PACKAGES

This appendix provides more detail on where to find R and how to install it and its contributed packages. R is available through CRAN—the Comprehensive R Network—accessed through the R website at https://www.r-project.org/. I'll cover only the fundamentals, but you'll find a substantial amount of information in the R FAQ by Hornik (2015) at http://CRAN.R-project.org/doc/FAQ/R-FAQ.html. This should be your first port of call if you need help with installing R and its packages. Installation of R and its contributed packages is dealt with in Sections 2 and 5 of the FAQ, respectively.
