## 11.2 Arguments

### 11.2.1 Lazy Evaluation

An important concept related to handling arguments in high-level programming languages is lazy evaluation. Generally, this refers to the fact that expressions are evaluated only when they are needed. This applies to arguments in the sense that they are accessed and used only at the point they appear in the function body.

Let's see exactly how R functions recognize and use arguments during execution.
