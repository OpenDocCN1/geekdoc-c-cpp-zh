```
R> xvals <- seq(16,28,by=0.1)
R> fx.samp <- dnorm(xvals,22,1.5/sqrt(5))
R> plot(xvals,fx.samp,type="1",lty=2,col="gray",xlab="",ylab="")
R> abline(h=0,col="gray")
R> fx <- dnorm(xvals,22,1.5)
R> lines(xvals,fx,lwd=2)
R> legend("topright",legend=c("raw obs. distbn.","sampling distbn. (mean)",
      lty=1,2,col=(2,2),bty="n")
```

In this example, the sampling distribution of X is clearly a taller, smaller distribution than the one tied to the observations. This makes sense—even less variability in an average of several measurements opposed to raw, individual measurements. Furthermore, the presence of n in the denominator of the standard error dictates a more precise distribution around the mean if you increase the sample size. Again, this makes sense—means "vary less" between samples of a larger size.

You can now ask various probability questions: distinguishing between the measurement distribution and the sampling distribution is important. For example, the following code provides Pr(X < 21.5), the probability that a randomly chosen day in January has a maximum temperature of less than 25 degrees:

```
R> pnorm(21.5,mean=22,sd=1.5)
[1] 0.3694413
```

The next bit of code provides the probability that the sample mean can be less than 21.5 degrees, Pr(X < 21.5), based on a sample of five random days in January:

```
R> pnorm(21.5,mean=22,sd=1.5/sqrt(5))
[1] 0.2280283
```

The line-shaded areas on the top of Figure 17-1 show these two probabilities. In R, these shaded areas can be added to that by running lines directly after the earlier code:

```
R> abline(v=21.5,col="gray"
R> xvals.sub <- xvals[xvals<=21.5]
R> fx.sub <- fx[xvals<=21.5]
R> fx.samp.sub <- fx.samp[xvals<=21.5]
R> polygon(bind(c(21.5,xvals.sub),c(0,fx.sub)),density=10)
R> polygon(bind(c(21.5,xvals.sub),c(0,fx.samp.sub)),density=10,
      angle=120,lwd=2)
```

Note that in previous uses of polygon, you simply specified a col; in this example, I implemented shaded lines instead, using the arguments density (number of lines per inch) and angle (slope of lines in degrees; defaults to angle=45).
