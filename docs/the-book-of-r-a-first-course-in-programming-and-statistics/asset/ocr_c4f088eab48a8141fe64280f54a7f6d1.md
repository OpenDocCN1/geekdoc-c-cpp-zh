# ## 13.1 Describing Raw Data

Often, the first statistical analysts are faced with raw data—in other words, the records or observations that make up a sample. Depending on the nature of the intended analysis, these data could be stored in a R object, often a data frame (Chapter 5), possibly read from an external file using techniques from Chapter 8. Before you can begin summarizing or modeling your data, however, it is important to clearly identify your available variables.

A variable is a characteristic of an individual in a population, the value of which can differ between entities within that population. For example, in Section 5.2, you experimented with an illustrative data frame mydata.
