
## 21.3.5 Omnibus F-Test

First encountered in Section 20.5.2 in the context of multilevel predictors, you can think of the omnibus $F$-test more generally for multiple regression models as a test with the following hypotheses:

```
$$H_0 : \beta_1 = \beta_2 = \dots = \beta_p = 0$$
$$H_A : \text{At least one of the } \beta_j \neq 0 \text{ (for } j = 1, \dots, p) \quad (21.5)
```

The test is effectively comparing the amount of error attributed to the "null" model (in other words, one with an intercept) with the amount of error attributed to predictors when all the predictors are present. In other words, the more predictors there are to model the response, the more error they explain, giving you a more extreme F statistic and therefore a smaller p-value. The single result makes the test especially useful when you have many explanatory variables. The test works regardless of how mix of predictors you use in a given model: one or more continuous, discrete, binary, and/or categorical with $k=2$ levels. When multiple regression models are fitted, the amount of output can take time to digest and interpret, and care must be taken to avoid Type I errors (incorrect rejection of a true null hypothesis—refer to Section 18.5).

The $F$-test holds all that down, allowing you to conclude either of the following:

- 1. Evidence against $H_0$ if the associated $p$-value is smaller than your significance level $\alpha$, which suggests that your regression—your combination of the explanatory variables—does a significantly better job of predicting the response than you removed all predictors.
- 2. No evidence against $H_0$ if the associated $p$-value is larger than $\alpha$, which suggests that using the predictors has no tangible benefit over having an intercept.

The downside is that the test doesn't tell you which of the predictors (or which subset thereof) is having a beneficial impact on the fit of the model, nor it tell you anything about their coefficients or standard errors.

You can compute the $F$-test statistic using the coefficient of determination, $R^2$, let $p$ be the number of regression parameters requiring estimation, excluding the intercept $\beta_0$. Then,

```
$$F = \frac{R^2(n - p - 1)}{(1 - R^2)p} \quad (21.6)
```

where $n$ is the number of observations used in fitting the model (or records with missing values being deleted). Then, under $H_0$ in (21.5), $F$ follows an $F$ distribution (see Section 16.2.5 and also Section 19.1.2) with $df_1=p, df_2=n-p-1$ degrees of freedom. The $p$-value associated with (21.6) is yielded as the upper-tail area of $F$ distribution.

As quick exercise to confirm this, turn your attention back to the fitted multiple regression survmult2 in Section 21.3.1, which is the model for student height handspan, sex, and smoking status from survey. You can extract the coefficient of multiple determination from the summary report (using the technique noted in Section 20.3).

```
R2 <- summary(survmult2)$r.squared
[1] 0.508469
```

This matches the multiple R-squared value from Section 21.3.1. Then, you can find n as the original size of data set in survey minus any missing values (reported as 30).

```
n <- nrow(survey)-30
[1] 207
```

You get p as the number of estimated parameters (minus 1 for the intercept).

```
p <- length(coef(survmult2))-1
[1] 5
```

You can confirm the value of n - p - 1, which matches the summary output (201 degrees of freedom):

```
n-p-1
[1] 201
```

Finally, you test the statistic F as dictated by (21.6), and you can use the pf function as follows to obtain the corresponding p-value for the test:

```
Fstat <- (R2*(n-p-1))((1-R2)*p)
[1] 41.5829
1-pf(Fstat,df1=p,df2=n-p-1)
[1] 0
```

You can see the omnibus F-test for this example gives a p-value that's small, effectively zero. These calculations match the relevant results reported in the output of summary(survmult2). Looking back at student height handspan, sex, and smoking in survmult2 in Section 21.3.1, it's little surprise that with two predictors yielding small p-values, the omnibus F-test suggests strong evidence against $H_0$. This highlights--the "umbrella" nature of the omnibus test: although the smoking variable itself doesn't contribute anything important, the F-test for that model still suggests survmult2 should be preferred over a "no-predictor" model because both handspan and sex are important.

## 21.3.6 Predicting from a Linear Model

Prediction (or forecasting) for multiple regression follows the same rules as simple regression. It is important to remember that point predictions found for a particular covariate—the collection of predictor values for a given individual—are associated with the mean (or expected value) of the response; with confidence intervals provide measures for mean responses; and that prediction intervals provide measures for raw observations. You also have to consider the issue of interpolation (predictions based on x values that fall within the range of the observed data) versus extrapolation (prediction from x values that fall outside the range of said data).

As an example, using the model fitted on student as a linear function of handspan and sex (in survmult), you can estimate the height of a male student with a handspan of 16.5 cm, with a confidence interval.

```
predict(survmult,newdata=data.frame(Wr.Hnd=16.5,Sex="Male"), interval="confidence",level=0.95)
fit lwr upr
[1] 173.4851 170.9419 176.0283
```

The results indicate that you have an expected value of about 173.48 cm and that you can be 95 percent confident the true value lies somewhere between 170.94 and 176.03 (rounded to 2 d.p.). In the same way, the mean height of a female with a handspan of 13 cm is estimated at 158.42 cm, with a 99 percent prediction interval of 139.76 to 177.07.

```
predict(survmult,newdata=data.frame(Wr.Hnd=13,Sex="Female"), interval="prediction",level=0.99)
fit lwr upr
[1] 158.4147 139.7611 177.0684
```

There are in fact two female students in the data set with handspan of 13 cm, as you can see in Figure 21-1. Using your knowledge of subsetting data frames, you can inspect these two records and select the three variables of interest.

```
survey(survey$Sex="Female" & survey$Wr.Hnd=13,c("Sex","Wr.Hnd","Height"))
Wr.Hnd Height
```

| Sex | Wr.Hnd | Height |
|---|---|---|
| Female | 13 | 180.34 |
| Female | 13 | 165.00 |

Now, the second female's height falls well inside the prediction interval, but the first female's height is significantly higher than the upper limit. it is important to realize that, technically, nothing has gone wrong in terms of the model fitting and interpretation—it is still possible that an observation can fall outside a prediction interval, even a 99 percent interval, though it's perhaps improbable. There could be any number of reasons for this occurring. First, the model could be inadequate. For example, you might be excluding important predictors in the fitted model and therefore have less predictive power. Second, although the prediction is within the range of the observed data, it has occurred at one extreme end of the range, where it's less reliable than that the observation itself may be tainted in some way—perhaps the individual recorded her handspan incorrectly, in which case her observation should be removed prior to model fitting.
