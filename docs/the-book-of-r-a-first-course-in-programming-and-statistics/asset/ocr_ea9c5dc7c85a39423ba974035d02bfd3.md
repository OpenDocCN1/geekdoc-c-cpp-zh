# 1.2.1 Console and Editor Panes

There are two main window types used for programming R and viewing output. The console or command-line interpreter that you've just seen is where execution takes place and where textual and numeric output is provided. You may use the R console directly for calculations or plotting. You would typically use the console directly only for short, one-line commands.

By default, the R prompt indicates that R is ready and awaiting a command is a >, after which a text cursor appears. To avoid confusion with the mathematical symbol for "greater than," authors (including) prefer to modify this symbol. A typical choice is R>, which you can use as follows:

```
> options(prompt="R> "
```

With the cursor placed at the prompt, you can use the keyboard arrow (↑) and down arrow (↓) to scroll through any previously executed commands; this is useful when making small tweaks to earlier commands.
For longer chunks of code and functioning, it's more convenient to write your commands in an editor and execute them in the console only when you're done. There is a built-in R code editor for this purpose.
R scripts you write in the code editor are essentially just plain-text files with a .R extension.
