
You can also install R packages from source, that is, from the uncompiled code, which may have more recent updates than the precompiled version of the package. If you're an OS user, recent versions of R will ask you whether you'd like to download packages from source for packages available that are more recent than the precompiled version. To do so, you need certain command line tools installed on your system; if the download fails, you can stick with the binary version by answering n (“no”) at the download from prompt.

## A.3 Updating R and Installed Packages

There are roughly four new releases of R that address functionality, compatibility issues, and bug fixes. It's a good idea to keep up-to-date with these new releases. The R project home page and any CRAN mirror site will tell you the latest release, and you can execute `news()` at the R prompt for details.

Contributed R packages are also periodically updated and new package files uploaded to CRAN. Packages you've won't auto-update, so it's up to update them. It's difficult to predict how often such updates will be released since it's completely up to the maintainers, but it's worth checking for newer versions of the packages you've installed every months, or at the very least, when you upgrade your version of R.

Checking for package updates is easy. A simple call to update.packages(), with no arguments, will systematically look through your installed packages and flag any that have more recent available.

You can also perform package updates using the R GUI (or manually with local file installation). In Windows, select Packages -> Update packages... to open a list of available updates to your current packages. On OS X, a column in the populated table in the package installer provides information on the version of every package you currently have installed, as well as the version currently on CRAN, giving you the option to install the most recent version. There's also the Update All button, which is what you'd typically use.

Enter y to download the updated package from CRAN. If there are several packages with updates available, R will ask you at a time when you'd like to update, and have you enter (y or n) for each.
