## 14.4.1 Single Plot

You can modify a simple scatterplot to split the plotted points to a categorical variable, exposing potential differences between any visible relationships with respect to the continuous variables. For example, using base R graphics, you can examine the petal measurements according to the three species. Using the "settingstone" approach first explained in Chapter 7, you can manually build up this plot by using type="n" to generate an empty plotting region of the correct dimensions and subsequently adding points to each species, altering point character and color as desired.

```
R> plot(iris[4],iris[3],type="n",xlab="Petal Width (cm)",ylab="Petal Length (cm)")
R> points(iris[iris$Species=="setosa",4], iris[iris$Species=="setosa",3],pch=19,col="black")
R> points(iris[iris$Species=="virginica",4], iris[iris$Species=="virginica",3],pch=19,col="gray")
R> points(iris[iris$Species=="versicolor",4], iris[iris$Species=="versicolor",3],pch=19,col="black")
R> legend("topleft",legend=("setosa","virginica","versicolor"), col=c("black","gray","black"),pch=c(19,19,19))
```

You can find the plot in Figure 14-8. Note that the Iris virginica species has the largest petals, followed by Iris versicolor, and the smallest petals belonging to Iris setosa. However, this code, while functional, is fairly cumbersome. You can generate the same image by first setting vectors that specify the desired point character and color for each individual observation.

## 14.2 Matrix of Plots

The "single" type of planar scatterplot is really useful only when comparing two numeric-continuous variables. When there are more continuous variables of interest, it isn't possible to display... A simple and common solution is to generate a two-variable scatterplot for each pair of variables and show them together in a structured way; this is referred to as a *scatterplot matrix*. Making use of the iris_pch and iris_col vectors created earlier, you can generate a scatterplot matrix for all four continuous variables in iris, retaining the distinction between species. Working with base R graphics, use the pairs function.

```
R> pairs(iris[,1:4],pch=iris_pch,col=iris_col,cex=0.75)
```

You can find the result of this line in Figure 14-9.

![](img/b2cfc85cbb129f60fe595a2bae074fe4_336_0.png)

Figure 14-9: A scatterplot matrix with respect to all four continuous measurements in the data frame

The easiest way to use pairs is to supply a matrix or data frame of the raw observations as its first argument, done by selecting columns of iris except the Species column (iris[,1:4]). The interpretation of the plots depends upon the labeling of the diagonal panels, running from the top left to the bottom right. They will appear in the same order as the columns given as the first argument. "label panels" allow you to determine which individual plot in the matrix corresponds to each pair of variables. For example, the first column of the scatterplot matrix in Figure 14-9 corresponds to an x-axis variable of Sepal Length; the third row of the matrix corresponds to a y-axis variable of Petal Length, and each row and column displays a scale that is constant moving left or right, respectively. This means that plots above the diagonal are mirrored in those below—the plot of Petal Width (y) on Sepal Width (x) at position 4, column 2 displays the same data as the scatterplot at position 2, column 4 but flipped on its axes. As such, pairs includes an option to display only those above or below by setting either lower.panel=NULL or upper.panel=NULL. Scatterplot matrices allow for easier comparison of pairwise relationships formed by observations on multiple variables. In this matrix, there's a strong linear association between petal measurements but a weaker relationship between the sepal measurements. Furthermore, although Iris setosa may reasonably be considered the smallest flower in terms of its petals, the same can't be said in terms of its sepals. For working with ggplot2, you know it's natural to split the points around a categorical variable as in this example:

```
R> qplot(iris[,4],iris[,3],xlab="Petal width",ylab="Petal length", shape=$Species)
  + scale_shape_manual(values=4:6) + labs(shape="Species")
```

You can find the result in Figure 14-10.

![](img/b2cfc85cbb129f60fe595a2bae074fe4_337_0.png)

Figure 14-10: Using ggplot2 functionality to plot petal dimensions for the three species, with point shape as the aesthetic modifier. Here, I've split the points using the Species variable mapped to shape (the equivalent of the base R pch), and I've modified the point types using the scale_shape_manual. I also simplified the title of the automatically generated legend with labs, as done in Section 14.2. Scatterplot matrices are not easily achievable using only ggplot2. To generate download the GGally package (Schloke et al., 2014) to access the ggpairs functions. This package is designed as an extension or add-on of ggplot2. It's installed from CRAN as usual—by running install.packages("GGally")—and must be loaded via library("GGally") prior to using it. This is, as a quick example, the following code produces the plot in Figure 14-11:

```
R> ggpairs(iris,mapping=aes(col=Species),axisLabels="internal")
```

Though you might see familiar warnings related to the histogram, ggally offers an impressive visual array for such a short line of code. The output gives you the lower half of the scatterplot matrix produced with pairs but also provides equivalent histograms along the bottom

![](img/b2cfc85cbb129f60fe595a2bae074fe4_338_0.png)

Figure 14-11: Generation of a scatterplot matrix using ggpairs:: from the GGally package, using color to separate the species. Note the useful addition of estimated correlation coefficients and distributional plots and boxplots along the right. It also displays the estimates of the correlation coefficients. As shown, you can map a variable to an aesthetic modifier to split the observations based on factor levels. In Figure 14-11, this is done by color, and you instruct ggpairs to operate on the Species variable. Documentation found in ?ggpairs gives concise information on the various options that control the presence and appearance of the individual plots.
