# 17.1.2 Distribution for a Sample Proportion

Sampling distributions for sample proportions are interpreted in much the same way. If n trials of a success/failure event are performed, you can obtain an estimate of the proportion of successes; if another n trials are performed, the new estimate could vary. This variability you're investigating.
The random variable of interest, P, represents the estimated proportions of successes over any n trials, resulting in some defined binary outcome. It is estimated as p = x/n, where x is the number of successes in a sample size of n. Let the corresponding proportion of successes (often unknown) be simply denoted by π.

> Note that π as used in this setting doesn't refer to the common geometric 3.14 (2 d.p.). Rather, it's simply notation to refer to a true population proportion using the symbol π.
