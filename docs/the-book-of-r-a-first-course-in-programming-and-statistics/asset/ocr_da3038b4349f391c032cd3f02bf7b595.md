You may first be asked to choose a CRAN mirror. The list pops up and defaults to the secure HTTPS servers only; choosing HTTP will switch to the unsecured ones. I chose HTTP, found the New Zealand mirror, and clicked OK, as shown in Figure A-5. Once you've done that, the selected mirror will remain as the set you chose until you reset it; see Section A.4.1.

After you click OK, R lists any dependencies that will also be downloaded and presents download notifications for each package (in the snipped output).
Additional notes are warranted:

+   - You need to install a package only when needed, and it will save your hard drive to be loaded with a call to library as usual.
- You might be prompted to create a local folder for your installed packages. This is done to ensure R knows where to get packages from when they are requested with library. Agreeing to this means you have a user-specific library of packages, which is generally a good idea.
- There are here of optional arguments for install-packages; the help file given by a call to `install.packages` at the prompt. For example, if you want to specify a CRAN mirror in the console, supply the relevant URL as a character string to the repos argument, or if you want to prevent dependencies from installing, use the dependencies argument.
