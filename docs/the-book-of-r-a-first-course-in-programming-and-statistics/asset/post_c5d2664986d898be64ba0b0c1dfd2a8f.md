## 4.1.4 Logicals Are Numbers!

Because of the binary nature of logical values, they're often represented with TRUE as 1 and FALSE as 0. In fact, in R, if you perform elementary numeric operations on logical values, TRUE is treated as 1, and FALSE is treated as 0.

```
R> TRUE+TRUE
[1] 2
R> FALSE-TRUE
[1] -1
R> T+T+F+T+F+T
[1] 4
```

These operations turn out the same as if you had used the digits 1 and 0. In some situations when you use logicals, you can substitute the numeric values.

```
R> 1&&1
[1] TRUE
R> 1||0
[1] TRUE
R> 0&&1
[1] FALSE
```

Being able to interpret logicals as zeros and ones means you can use a variety of functions to summarize a logical vector, and you'll explore this further in Part III.

## 4.1.5 Logical Subsetting and Extraction

Logicals can also be used to extract and subset elements in vectors and other objects, in the same way as you've done so far with index vectors. Rather than entering explicit indexes in the square brackets, you can supply logical flag vectors, where an element is extracted if the corresponding entry in the flag vector is TRUE. As such, logical flag vectors should be the same length as the vector's that being accessed (though recycling does occur for shorter flag vectors, as a later example shows).

At the beginning of Section 2.3.3 you defined a vector of length 10 as:

```
R> myvec <- c(5,-2.3,4,4,4,6,8,10,40221,-8)
```

If you wanted to extract the two negative elements, you could either enter myvec[c(2,10)], or you could do the following using logical flags:

```
R> myvec[c(F,T,F,F,F,F,F,F,T)]
[1] -2.3 -8.0
```

This particular example may seem too cumbersome for practical use. however, when you want to extract elements based on whether they satisfy a certain condition (or several conditions). For example, you can easily use logicals to find negative elements in myvec by applying the condition <0.

```
R> myvec<0
[1] FALSE TRUE FALSE FALSE FALSE FALSE FALSE FALSE TRUE FALSE
```

This is a perfectly valid flag that you can use to subset myvec to get the result as earlier.

```
R> myvec[myvec<0]
[1] -2.3 -8.0
```

As mentioned, R recycles the flag vector if it's too short. To extract every second element from myvec, starting with the first, you could enter the following:

```
R> myvec[c(T,F)]
[1] 5 4 8 40221
```

You can do more complicated extractions using relational and logical operators, as such:

```
R> myvec[(myvec>0)&(myvec<1000)]
[1] 5 4 4 4 6 8 10
```

This returns the positive elements that are less than 1,000. You can also overwrite specific elements using a logical vector, just as with index vectors.

```
R> myvec[myvec<0] <- -200
R> myvec
[1] 5 -200 4 4 4 6 8 10 40221 -200
```

This replaces all existing negative entries with -200. Note, that You cannot directly use negative logical vectors to delete specific elements; this can be done only with numeric index vectors.

As you can see, logicals are therefore very useful for element extraction. You don't need to know beforehand which specific index positions return, the conditional check can find them for you. This is particularly valuable when you're dealing with large data sets and want to inspect records or recode entries that match criteria.

In some cases, you might want to convert a logical vector into a numeric index. This is helpful when you need the explicit indexes of elements that were flagged TRUE. The R function which takes in a logical vector as the argument x returns the indexes corresponding to the positions of any and all TRUE entries.

```
R> which(x=c(T,F,F,T,T))
[1] 1 4 5
```

You can use this to identify the index positions of myvec that meet a certain condition; for example, those containing negative numbers:

```
R> which(x=myvec<0)
[1] 2 10
```

The same can be done for the other myvec selections you experimented with. Note that a line of code such as myvec[which(x=myvec<0)] is redundant because extraction can be made using the condition by itself, that is, via myvec[myvec<0], without using which. On the other hand, which lets you identify the numeric indexes you want to delete and remove them. To omit the negative entries of myvec, you would execute the following:

```
R> myvec[-which(x=myvec<0)]
[1] 5 4 4 4 6 8 10 40221
```

The same can be done with matrices and other arrays. In Section 3.2, you stored a 3 × 3 matrix as follows:

```
R> A <- matrix(c(0.3,91,-4.2,4.5,0.1,8.2,55.3,105.5,27.9),nrow=3,ncol=3)
R> A
     [,1] [,2] [,3]
[1,] 0.3 91.0 -4.2
[2,] 4.5 0.1 8.2
[3,] 55.3 105.5 27.9
```

To extract the second and third column elements of the first row of A using numeric indexes, you could execute A[1,2:3]. To do this with logical flags, you could enter the following:

```
R> A[c(T,F,F),c(F,T,T)]
[1] 91.0 -4.2
```

Again, though you usually wouldn't explicitly specify the logical vectors. Suppose you want to replace all elements in A that are less than 1 with -7. Performing this using numeric indexes is rather fiddly. It's much easier to use the logical flag created with the following:

```
R> A[A<1] <- -7
R> A
     [,1] [,2] [,3]
[1,] -7.0 91.0 -7.0
[2,] 4.5 -7.0 8.2
[3,] 55.3 105.5 27.9
```

You can supply this logical matrix to the square bracket operators, and the replacement is as follows:

```
R> A[A<1] <- -7
R> A
     [,1] [,2] [,3]
[1,] -7.0 91.0 -7.0
[2,] 4.5 -7.0 8.2
[3,] 55.3 105.5 27.9
```

This is the first time you've subsetted a matrix without having to list row or column positions inside the square brackets, commas to separate out dimensions (see Section 3.2). This is because flag has the same number of rows and columns as the target matrix, thereby providing all the relevant structural information.

If you wish to identify numeric indexes based on a logical flag structure, you have to be a little more careful when dealing with two-dimensional objects or higher. Suppose you want the index positions of the elements that are greater than 25. The appropriate logical matrix is as follows.

```
R> A>25
     [,1] [,2] [,3]
[1,] FALSE TRUE FALSE
[2,] FALSE FALSE FALSE
[3,] TRUE TRUE TRUE
```

Now, you say R the following:

```
R> which(x=A>25)
[1] 3 4 6 9
```

This returns the indexes of the elements that satisfied the relational check, but they are provided as scalar values. How do these correspond to the row/column positioning of the matrix?
The answer lies in R's default behavior for the which function, which essentially treats the multidimensional object as a single object (laid out column after column) and returns the vector of corresponding indexes. The matrix A was arranged as a vector by stacking the columns first, using c(A[,1],A[,2],A[,3]). Then indexes returned make sense.

```
R> which(x=c(A[,1],A[,2],A[,3])>25)
[1] 3 4 6 9
```

With the columns laid out end to end, the elements that return TRUE are the third, fourth, sixth, and ninth in the list. This can be difficult to interpret, especially when dealing with higher-dimensional arrays. In this kind of situation, you can make return-specific indexes using the optional argument arr.ind (array indexes). By default, this argument is set to FALSE, resulting in the vector converted indexes. Setting arr.ind=TRUE, on the other hand, treats the object as a matrix or array rather than a vector, providing you with the row and column positions of the elements requested.

```
R> which(x=A>25,arr.ind=TRUE)
     row col
[1,] 3 1
[2,] 1 2
[3,] 3 2
[4,] 3 3
```

The returned object is now a matrix, where each row represents an element that satisfied the logical comparison and each column provides the position of the element. Comparing the output with A, you can see these positions do indeed correspond to elements A>25.
Both versions of the output (with arr.ind=TRUE or arr.ind=FALSE) can be useful—the correct choice depends on the application.
