Now, you need to use the inside.owin function on every coordinate in the evaluation grid that z-matrix chor.dens.WIN$ sits on. First, create the full set of grid coordinates using expand.grid, in the same way as illustrated in Section 25.3.1.

```
R> chor.xy <- expand.grid(chor.dens.WIN$x,chor.dens.WIN$y)
R> nrow(chor.xy)
```

+   [1] 65536

Calling row on the resulting data frame of coordinates confirms you exactly $256^2=$ 65536 grid points as defined in the chor.dens.WIN KDE object. The following call takes the two columns of chor.xy and makes use of logical negation (using !) to produce a logical vector that flags grid coordinates that are outside the defined region.

```
R> chor.outside <- !inside.owin(x=chor.xy[,1],y=chor.xy[,2],w=chor.WIN)
```

The final step is now

```
R> chor.out.mat <- matrix(chor.outside,nrow=256,ncol=256)
R> chor.dens.WINZ[chor.out.mat] <- NA
```

First, for clarity, recast the long chor.outside vector as a $256 	imes 256$ matrix to emphasize that it corresponds exactly to the z-matrix of interest. This logical flag matrix allows us to directly overwrite the “outside” entries in the z-matrix to be NA.

All that's left now is to plot the newly manipulated z-matrix. Make sure you have the shape package loaded for the finishing touch of a color. The following code creates the KDE surface pixel image with points restricted to the geographical region defined by Window only:

```
R> dev.new(width=7.5,height=7)
R> par(mar=c(5,4,4,7))
R> image(chor.dens.WINZ,col=row,xlab="Eastings",ylab="Northings",bty="1",asp=1)
R> plot(chor.WIN,lwd=2,add=TRUE)
R> colorleg(col=row,zlim=chor.dens.WIN$z,na.rm=TRUE),zval=seq(0,0.2,0.0025),main="KDE")
```

First you open a new graphics device and the right margin to incorporate the color legend. Next you invoke image to plot, specifically using an L-shaped box and a one-to-one y aspect ratio, and then add the region with thicker lines. Finally you execute colorleg to obtain an appropriately positioned legend referencing the color values (which were found after a little trial and error) (the specific positioning and tick marks).
