# Finding Packages on CRAN

Every R package on CRAN has its own standard web page, providing the direct links to the downloadable files and important information about the package. Locate the package name on one of the lists on CRAN and click it, or do a quick Google search for, in our case *ks r cran*. Figure A-4 shows the top of the web page for ks.

| ks: Kernel Smoothing |
| Smothers for univariate and multivariate data.
| Version: 1.9.5 |
| Depends: R (>= 1.4.0), KernSmooth (>= 2.22), misc3d (>= 0.4), mvtnorm, rgl (>= 0.66)) |
| Imports: grDevices, graphics, misscool, stats, utils |
| Suggestions: MASS |
| Published: 2015-10-07 |
| Author: Tarm Duong, duam.duong@gmail.com> |
| License: GPL-2 | GPL-3 |
| URL: http://www.mvstat.net/tduang |
| NeedsCompilation: yes |
| Materials: Multivariate |
| CRAN checks: no results |

Figure A-4: Descriptive information on the CRAN web page for the ks

Along with basic information such as the version number and the maintainer's name and contact information, you'll see the Depends field. This is important for installation; if the R package you're interested in is dependent on other contributed packages (not all), you also need to install those packages for your package to install successfully.

Looking at Figure A-4, you can see that your R version needs to be later than 1.4, that ks requires KernSmooth (already installed—it's one of the recommended packages noted in Section A.2.2), and it also needs misc3d, mvtnorm, and rgl. Fortunately, if you install an R package directly from R, the dependencies are also installed automatically.

# Installing Packages at the Prompt

The quickest way to download and install a contributed R package is to use the install.packages command directly from the R prompt. Starting with a fresh installation of R, I see the following on my iMac:

```
R install.packages("ks")
--- Please select a CRAN mirror for use in this session ---
also installing the dependencies 'misc3d', 'mvtnorm', 'rgl'

--snip--
```
