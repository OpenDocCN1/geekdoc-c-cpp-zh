Alternatively, you could label raw observations with the row names attribute of the original mtcars data frame as added text so that you could identify which car is in the plot. In this case, the names are obtained as a vector of character strings using the built-in rownames function. To add text to an existing 3D graphic, rgl has its own analog of the traditional text function. Executing the following lines replaces the fluorescent red response surface, adding the appropriate text at the (x,y,z) coordinates that correspond to car, and adds the cyan prediction interval:

```
xlab="horsepower","ylab="weight","z="mean MPG"

```
