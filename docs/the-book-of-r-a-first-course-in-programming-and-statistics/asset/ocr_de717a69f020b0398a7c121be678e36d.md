Along that line of thought, remember that the iris data has a fourth continuous variable, petal length as slen in Section 25.2.1), that you're not displaying in either of the plots in Figure 25-7. You're also not displaying the categorical variable flower species, let's fix that. First, set up a color band for the measurement variable, using your knowledge of having color palettes reference a continuous variable from Section 25.1.4.

```
R keyscol <- c("purple", "yellow", "blue")
slen.pal <- colorRampPalette(keyscol)
slen.pal2 <- colorRamp(keys)
slen.cols <- rgb(slen.pal2(normalize(slen)),maxColorValue=255)
```

Note that for the last line to run, you'll need to have the normalize function defined in Section 25.14 available in your current session.
The following code produces the 3Dscatterplot, also uses the pch argument to distinguish among the three different species:

```
R scatterplot3d(x=pwid,y=plen,z=swid,color=slen.cols,
pch=c(19,17,15),as.numeric(iris$Species),type="h"
lty=2,hde=3,xlab="Petal width"
ylab="Petal length",zlab="Sepal width"
main="Iris Flower Measurements")
```

I've used the vector(19,17,15), with the numeric coercion of the iris$Species vector passed to the square brackets, to pair pch character numbers as follows: 19 with Iris setosa (the first level of), 17 with Iris versicolor (the second level), and 15 with Iris virginica (the third level), respectively (refer to Figure 7-5 on page 133 for the different types of characters).
You can then insert a legend referencing species with a familiar to call

```
R legend("bottomright",legend=levels(iris$Species),pch=c(19,17,15))
```

And with a little experimentation, you can include a color strip legend too (making sure you've loaded the package so you have access to the colorlegend function as per Section 25.1.4.

```
R colorlegend(slen.pal(200),zlim=range(slen),zval=5:7,digit=1
posx=c(0.1,0.13),posy=c(0.7,0.9),left=TRUE
main="Sepal length")
```
