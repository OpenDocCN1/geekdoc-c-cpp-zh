You can do more complicated extractions using relational and logical
operators, as such:

```
R> mye[(myvec>0)&(myvec<1000)]
[1] 5 4 4 4 6 8 10
```

This returns the positive elements that are less than 1,000. You can also
overwrite specific elements using a logical vector, just as with index
vectors.

```
R> myevec<- -200
R> myevec
[1] 5 -200 4 4 4 6 8 10 40221 -200
```

This replaces all existing negative entries with -200. Note, that
You cannot directly use negative logical vectors to delete specific elements;
this can be done only with numeric index vectors.

As you can see, logicals are therefore very useful for element extraction.
You don't need to know beforehand which specific index positions
return, the conditional check can find them for you. This is particularly
valuable when you're dealing with large data sets and want to
ispect records or recode entries that match criteria.

In some cases, you might want to convert a logical vector into a
numeric index. This is helpful when you need the explicit indexes
of elements that were flagged TRUE. The R function which takes in a logical
vector as the argument x returns the indexes corresponding to the positions
of any and all TRUE entries.

```
R> which(x=(T,F,F,T,T))
[1] 1 4
```

You can use this to identify the index positions of myevec that meet a certain condition; for example, those containing negative numbers:

```
R> which(x=myvec<0)
[1] 2 10
```

The same can be done for the other myevec selections you experimented with. Note that a line of code such as myevec[which(x=myvec<0)] is redundant because extraction can be made using the condition by itself, that is, via myevec[myvec<0], without using which. On the other hand, which lets you deidentify the numeric indexes you want to delete and remove them. To omit the negative entries of myevec, you would execute the following:

```
R> myevec[-which(x=myvec<0)]
[1] 5 4 4 4 6 8 10 40221
```
