
The operations supplied to FUN should be appropriate for the MARGIN selected. So, if you select rows or columns with MARGIN=1 or MARGIN=2, make sure the FUN function is appropriate for vectors. Or if you have a three-dimensional array and use apply with MARGIN=3, be sure to set FUN to a function for matrices. Here's an example for you to enter:

Some programmers prefer using the suite of apply functions wherever possible to improve the compactness and neatness of their code. Plus, when you're first learning the R language, explicit loops are easier to read and follow since the operations are laid out clearly by line.

# 10.3 Other Flow Mechanisms

Normally a for loop will exit only when the index exhausts, and a while loop will exit only when the condition evaluates to FALSE. But you can also preemptively terminate a loop by declaring.

### 10.3.1 Declaring break

For example, say you have a number, foo, that you want to divide by element. Furthermore, let's say you want to divide foo by element but halt execution if one of the results evaluates to Inf (which will happen if dividing by zero). To do this, you can check each iteration with the is.finite function (Section 6.1), and you can issue a break command to terminate the loop.

```R
R loop1.result <- rep(NA,length(bar))
R loop1.result
[1] NA NA NA NA
R+ for(i in 1:length(bar)){
+   temp <- foo/bar[i]
+   if(is.finite(temp)){
+     loop1.result[i] <- temp
+   } else {
+     break
+   }
}
R loop1.result
[1] 2.500000 1.666667 4.545455 1.250000
```

### 10.3.2 next

Instead of breaking and completely ending a loop, you can use next to add to the next iteration and continue execution. Consider the following, using next avoids division by zero:

```R
R loop2.result <- rep(NA,length(bar))
R loop2.result
[1] NA NA NA NA
R+ for(i in 1:length(bar)){
+   if(bar[i]==0){
+     next
   }
+   loop2.result[i] <- foo/bar[i]
}
R loop2.result
[1] 2.500000 1.666667 4.545455 1.250000
```
