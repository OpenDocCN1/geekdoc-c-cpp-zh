These lines confirm the values of X used earlier to get the lower- and upper-tail probabilities Pr(X < -0.21) and Pr(X > 0.6), respectively. Any q-function expects cumulative (in other words, left-hand) as first argument, which is why we need to supply 1-1/3 in the second line to recover 0.6. (The total area is 1. You know that the want the right of 0.6 to be $\frac{1}{3}$; thus, the area on the left must be $1 - \frac{1}{3}$).

# The Runif Function

Lastly, to generate random realizations of a uniform distribution, you use runif. Let's say the woodworker drills 10 holes using the faulty press; you can simulate one instance of the position of these holes relative to their target with the following:

```
runif(n=10,min=a1,max=b1)
[1] -0.2422972 -0.1226568 0.9318365 0.4829028 0.5963365
[6] 0.2009347 0.3073956 -0.1416678 0.5551468 0.4033372
```

Again, note that the specific values of r-function calls like runif will be different each time they are run.
