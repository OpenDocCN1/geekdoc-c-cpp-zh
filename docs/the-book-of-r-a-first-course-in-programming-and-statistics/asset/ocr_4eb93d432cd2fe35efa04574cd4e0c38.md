# Basic One-Isosurface

Now let's increase the dimension once more—what does a trivariate normal density function look like?

First, let's take a look at some data generated from this density. The following code generates 500 random variates again:

```
R> rand3d.norm <- rmvnorm(n=500,mean=(0,0,0))
R> plot3d(rand3d.norm, xlab="x",ylab="y",zlab="z")
```

However, since you supplied a vector of length 3 as the mean argument to rnorm, the function knows you have three dimensions to work with. You're telling it that you want the data to come from a trivariate normal, with means of 0, 0, and 0 in each coordinate direction. You can see the point cloud of the data produced via plot3d on the left of Figure 26-10.

To calculate and display the actual trivariate density function generated these data, you'll need a 3D evaluation lattice, as noted at the beginning of 26.3.
