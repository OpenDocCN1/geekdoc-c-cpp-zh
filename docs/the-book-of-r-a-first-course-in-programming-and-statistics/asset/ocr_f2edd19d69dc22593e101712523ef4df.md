# 26.13 Adding Further 3D Components

You can also add new observations and lines to a current 3D plot. The rgl package includes the functions points3d, lines3d, and segments3d, reminiscent of points, lines, and segments from base R graphics. As an example, in Section 25.2.2, you used an optional argument to add vertical lines to the base of the x-y plane to each plotted point in scatterplotd. In a plot3d scatter, you would use segments3d to the same effect. In addition, you can add the grid's that drawn by default on the same plane in a scatterplotd plot by using the grid3d function for rgl graphics.
