## 21.4 Transforming Numeric Variables

Sometimes, the linear function as strictly defined by the standard regression equation, (21.1), can be inadequate when it comes to capturing relationships between a response and selected covariates. You might, for example, observe curvature in a scatterplot between two numeric variables to which a perfectly straight line isn't necessarily best suited. To a certain extent, the requirement to your data exhibit such linear behavior in order for a linear regression model to be appropriate can be relaxed by simply transforming (typically in a nonlinear fashion) variables before any estimation or model fitting takes place.

Numeric transformation refers to the application of a mathematical function to your numeric observations in order to rescale the square root of a number and converting a temperature from Fahrenheit to Celsius as both examples of a numeric transformation. In the context of regression, transformation is generally applied only to continuous variables and can be done in any number of ways. In this section, you'll limit your attention to using the two most common approaches: polynomial and logarithmic transformations. However, note that the appropriateness of the methods used to transform variables, and any modeling benefits that might occur, can only be realized on a case-by-case basis.

Transformation in general doesn't represent a universal solution to solving problems of nonlinearity in the trends in your data, but it can improve how faithfully a linear model is able to represent these trends.

### 21.4.1 Polynomial

Following on a comment made earlier, let's say you observe a curved relationship in your data such that a straight line isn't a sensible choice for modeling. In an effort to fit your data closely, a polynomial transformation can be applied. The plots in 21-2, a good way to interpret the effects of including these terms is in the complexity of the curves that can be captured. At order 1, the linear relationship allows no curvature. At order 2, a quadratic function of any given variable allows one "bend." The model can have two bends in the relationship, this continues if you adding terms corresponding to increasing powers of the covariate.

To clarify the concept of polynomial, consider the following sequence between -4 and 4:

```R
x <- seq(-4,4,length=50)
y <- x
y2 <- x + x^2
y3 <- x + x^2 + x^3
```

Here, you assign y to take on specific functions of x, linear (in technical terms, this is "polynomial of order 1"). The vector y2 represents quadratic. The following three lines of code produce, separately, the plots from left to right in 21-2:

```R
R> plot(x,y,type="1")
R> plot(x,y2,type="1")
R> plot(x,y3,type="1")
```

Figure 21-2: Illustrating linear (left), quadratic (middle), and cubic (right) of x

Perhaps a bit more generally, let's say you have data for a continuous predictor, X, that you want to model your response, Y. Following estimation in the usual way, linearly, the simple model is $\hat{y} = \beta_0 + \beta_1x$; a quadratic term in X can be modeled via the multiple regression $\hat{y} = \beta_0 + \beta_1x + \beta_2x^2$; a cubic relationship can be captured by $\hat{y} = \beta_0 + \beta_1x + \beta_2x^2 + \beta_3x^3$; and so on.
