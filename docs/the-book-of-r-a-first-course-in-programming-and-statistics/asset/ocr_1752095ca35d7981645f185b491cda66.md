The resulting object is simply a list with three members. The components accessed through $sx$ and $sy$ contain the evenly spaced evaluation coordinates in the corresponding axis directions, and $sz$ provides you with the corresponding z-matrix. You can confirm by entering either $quad.dens$sx$ or $quad.dens$sy$ at the prompt that they are indeed sequences spanning the ranges of the observed data. Entering the following confirms the size of the matrix:

```
R> dim(quak.denssz)
[1] 100 100
```

With that, you have all the ingredients to display contours of KDE surface. The next line produces the default contour plot, on the top left of Figure 25-12.

```
R> contour(quak.denssx,quak.denssy,quak.denssz)
```

There are many more optional arguments available to contour for displaying your continuous surface. It can also be helpful to simultaneously view other data or observations (if they've been used in some way to create the surface, as is the case with bivariate KDE). The following code replots the quakes kernel estimate with unpadded axes, different contour levels to the defaults, and the observations; you can see the result on the right of Figure 25-12.

```
R> contour(quak.denssx,quak.denssy,quak.denssz,levels=50,drawlabels=FALSE,xaxis="1",yaxes="1",xlab="Longitude",ylab="Latitude")
R> points(quakeslong,quakeslat,cex=0.7)
```

Rather than using levels to determine the exact levels at which to draw the contours (as you did with Example 2), you can use the levels argument to specify the number of levels to display, and the function will choose the specific values for it. You can suppress the automatic labeling of the displayed contours by setting drawlabels=FALSE, also done here, by a call to points to add the original observations to the image. Naturally, the smooth contours delineating the nonparametric density estimate reflect the heterogeneous spatial patterning of the data.

Changing the appearance of your plotted contours needs't be universally; you can also alter the appearance of each individual contour. This can be handled by, for example, to display contours at a handful of specific levels without the default labeling (to focus the shape of the surface itself) but still want to be able to discern the values of those contours. You might also want to superimpose contours on an existing plot that already depicts other data or model-based results of interest. The third plot of the earthquake KDE surface, given on the bottom of Figure 25-12, shows how you can achieve both of these things.
