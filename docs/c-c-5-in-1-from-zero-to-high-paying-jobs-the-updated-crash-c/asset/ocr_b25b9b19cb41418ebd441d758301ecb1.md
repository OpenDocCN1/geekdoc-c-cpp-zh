# Step 3: Use Polymorphism

Create a program that operates on shapes using polymorphism. We'll create an array of different shapes and call their `CalculateArea()` method without worrying about their specific types.

```
```csharp
class Program
{
    static void Main(string[] args)
    {
        Shape[] shapes = new Shape[]
        {
            new Circle(5),
            new Rectangle(3, 4),
            new Circle(7)
        };

        foreach (Shape shape in shapes)
        {
            double area = shape.CalculateArea();
            Console.WriteLine($"Area of the shape: {area}");
        }
    }
}
```
```
