# Example of Returning a Value from a Function:

```
#include <iostream>

int add(int a, int b) {
    int sum = a + b;
    return sum;
}

int main() {
    int result = add(3, 5);
    std::cout << "Sum: " << result << std::endl;
    return 0;
}
```

# Utilizing Return Values:

Return values can be used in various ways within your program. They can be assigned to variables, used in expressions, or even passed as arguments to other functions.
