# **Formatted Input:**

You can use stream extraction (`>>`) to read structured data from a file.

```
```cpp
#include <iostream>
#include <fstream>

int main() {
    std::ifstream inputFile;
    inputFile.open("data.txt");

    int age;
    inputFile >> age; // Reads the age from the file

    inputFile.close();
    return 0;
}
