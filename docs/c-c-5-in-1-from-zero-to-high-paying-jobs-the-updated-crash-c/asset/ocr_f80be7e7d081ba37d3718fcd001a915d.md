```
```csharp
class Animal
{
    public void Eat()
    {
        Console.WriteLine("The animal is eating.");
    }
}
class Cat : Animal
{
    public void Meow()
    {
        Console.WriteLine("The cat says meow.");
    }
}
```
```

+   - In this example, `Animal` is the base class, and `Cat` is the derived class.
+   - The `Cat` class **inherits** the `Eat()` method from the `Animal` class. It doesn't need to redefine the `Eat()` method; it can directly use it.
+   - The `Cat` class also introduces a new method, `Meow()`, which is specific to cats.

# Overriding and Extending

Derived classes can override (replace) methods of the base class to provide custom implementations:

```
```csharp
class Dog : Animal
{
    public new void Eat() // Method is overridden
    {
        Console.WriteLine("The dog is eating noisily.")
    }
}
```
```

+   - In this case, the `Dog` class overrides the `Eat()` method inherited from the `Animal` class. The new implementation is specific to dogs.
