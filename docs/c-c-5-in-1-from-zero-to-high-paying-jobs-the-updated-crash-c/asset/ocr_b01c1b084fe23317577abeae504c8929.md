We'll start by defining a base class called `Vehicle`. This class will have common attributes like `Brand` and `Year`, along with a method `Start()` that all vehicles can use.

```
class Vehicle
{
    public string Brand { get; set; }
    public int Year { get; set; }

    public Vehicle(string brand, int year)
    {
        Brand = brand;
        Year = year;
    }

    public void Start()
    {
        Console.WriteLine($"{Brand} is starting.");
    }
}
```

# Step 2: Create Subclasses

Next, we'll create two subclasses of `Vehicle` to represent specific types of vehicles: `Car` and `Motorcycle`.

```
class Car : Vehicle
{
    public Car(string brand, int year) : base(brand, year)
    {
    }

    public void OpenTrunk()
    {
        Console.WriteLine($"Opening trunk of {Brand} car.");
    }
}
class Motorcycle : Vehicle
{
    public Motorcycle(string brand, int year) : base(brand, year)
    {
    }

    public void Wheelie()
    {
        Console.WriteLine($"{Brand} motorcycle is doing a wheelie!");
    }
}
```
