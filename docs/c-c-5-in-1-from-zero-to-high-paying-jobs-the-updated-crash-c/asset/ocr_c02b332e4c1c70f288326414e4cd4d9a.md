# Asynchronous Programming

Asynchronous programming enhances responsiveness by allowing tasks to run without blocking the main thread. Use `async` and `await` keywords for asynchronous operations.

```
public async Task<int> FetchDataAsync()
{
    // Async operation
    await Task.Delay(1000);
    return 42;
}
```
