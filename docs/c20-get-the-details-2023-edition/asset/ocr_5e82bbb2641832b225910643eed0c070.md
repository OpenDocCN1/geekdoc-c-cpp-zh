MyFuture's constructor call (line 10) is completed, the promise promise_type is created, executed, and destroyed (lines 20 - 48). The promise uses in each step of its control flow the available `std::suspend_never` (lines 36 and 40) and, hence, never pauses. To save the result of the promise for the later `fut.get()` call (line 60), it has to be allocated. Furthermore, the used `std::shared_ptrs` ensure (lines 9 and 21) that the program does not cause a memory leak. As a local, `fut` goes out of scope in line 65, and the C++ run time calls its destructor.

You can try out the program on the [Compiler Explorer](https://godbolt.org/z/Y9naEx).
