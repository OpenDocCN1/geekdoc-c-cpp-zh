# 4.6.2 Non-Type Template Parameters (NTTP)

C++ supports non-types as template parameters. Essentially non-types could be

+   - integers and enumerators
+   - pointers to objects, to functions and to attributes of a class
+   - lvalue references
+   - `std::nullptr_t`
