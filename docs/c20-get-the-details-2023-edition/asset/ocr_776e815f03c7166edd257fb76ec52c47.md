# ### 8.1.2.3 `std::print`, and `std::println`

The C++23 convenience functions `std::print` and `std::println` write to the output console. `std::println` adds a newline character to the output. Additionally, both functions enable it to write to an output stream and support Unicode⁴. You must include the header `<print>` or import the modularized standard library.

```
```cpp
#include <print>                  // or import std;
...
std::print("{} {}!", "world", "Hello"); // prints "Hello world!"

std::ofstream outFile("testfile.txt");
std::print(outFile, "{} {}!", "world", "Hello"); // writes "Hello world!" into outFile
```
