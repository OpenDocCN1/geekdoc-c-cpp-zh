# Requires expressions as predicates for `static_assert`

```
```cpp
// staticAssertRequires.cpp

#include <concepts>
#include <iostream>

struct Fir {
    int count() const {
        return 2020;
    }
};

struct Sec {
    int size() const {
        return 2021;
    }
};

int main() {

    std::cout << '\n';

    First first;
    static_assert(requires(Fir fir) { fir.count() } -> std::convertible_to<int> );

    Second second;
    static_assert(requires(Sec sec) { sec.count() } -> std::convertible_to<int> );

    int third;
    static_assert(requires(int third) { third.count() } -> std::convertible_to<int> );

    std::cout << '\n';

}
```
```

The requires expressions (lines 23, 26, and 29) check if the object has a member function count and its result is convertible to int. This check is only valid for the class First (lines 6 - 10). On the contrary, the checks in lines 26 and 29 fail.
