In the main program, I start the two threads nonInterruptible and interruptible (lines 13 and 22). Unlike in the thread nonInterruptible, the thread interruptible gets a std::stop_token and uses it in line 26 to check if it was interrupted: token.stop_requested(). In case of a stop request, the lambda function returns, and, therefore, the thread ends. The call interruptible.request_stop() (line 37) triggers the stop request. This does not hold for the previous call nonInterruptible.request_stop(). The call has no effect.
