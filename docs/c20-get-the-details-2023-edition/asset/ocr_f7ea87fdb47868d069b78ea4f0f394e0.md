# #### 7.3.1.2 `initial_suspend` Never Suspends

In the program, the member function `initial_suspend` returns the available `std::suspend_always` (line 46). As its name suggests, the available `std::suspend_always` causes the coroutine to pause immediately. Let me return `std::suspend_never` instead of `std::suspend_always`.
