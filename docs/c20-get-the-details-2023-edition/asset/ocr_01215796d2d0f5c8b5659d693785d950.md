# Use of hello and world

```
~~~cpp
// helloWorld2.cpp

#include <iostream>

#include "hello.h"
#include "world.h"

int main() {

    hello();
    world();
    std::cout << '\n';

}
~~~
```

Building and executing the program works as expected:

![](bbox=[0.2, 0.455, 0.8, 0.61])

Here is the issue. The preprocessor runs on each source file. Consequently, the header file `<iostream>` is included three times. Consequently, each source file is blown up to over half a million lines.

![](bbox=[0.25, 0.69, 0.75, 0.84])

This is a waste of compile time.

Unlike header files, a *module* is only imported once and is literally for free.
