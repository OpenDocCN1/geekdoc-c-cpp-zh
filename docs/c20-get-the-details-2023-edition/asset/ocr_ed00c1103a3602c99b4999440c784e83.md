Wouldn’t it be nice if `std::sort` could be executed on the entire container? Thanks to the ranges library, this is possible in C++20.

# Algorithms of the ranges library operate directly on the container

```
```cpp
// sortRanges.cpp

#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> myVec{-3, 5, 0, 7, -4};
    std::ranges::sort(myVec);
    for (auto v: myVec) std::cout << v << " "; // -4, -3, 0, 5, 7
}
```
```

The algorithms of the [algorithm library](https://en.cppreference.com/w/cpp/header/algorithm)⁶ and the [memory library](https://en.cppreference.com/w/cpp/header/memory)⁷ have ranges pendants. They start with the namespace `std::ranges`. The algorithms of the [numeric library](https://en.cppreference.com/w/cpp/header/numeric)⁸ have no ranges pendant.

When you study the overloads of `std::ranges::sort`, you notice that they support a projection.
