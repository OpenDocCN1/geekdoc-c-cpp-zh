# Copying the reference

```
~~~cpp
// atomicRefCopy.cpp

#include <atomic>
#include <iostream>

int main() {

  std::cout << '\n';

  int val{5};
  int& ref = val;
  std::atomic<int> atomicRef(ref);
  ++atomicRef;
  std::cout << "ref: " << ref << '\n';
  std::cout << "atomicRef.load(): " << atomicRef.load() << '\n';

  std::cout << '\n';

}
~~~
```

The increment operation in line 13 does not address the reference ref (line 11). The value of ref is not changed.

![](bbox=[0.314, 0.572, 0.693, 0.717])

Copying the reference

Replacing the `std::atomic<int>` with `std::atomic_ref<int>` solves the issue.
