std::ranges::begin provides only overloads for lvalues<sup>20</sup>. The temporary vector `std::vector<int>{1, 2, 3}` (line 10) is an rvalue<sup>21</sup>. Consequently, the compilation of the program fails.

<sup>20</sup> https://en.cppreference.com/w/cpp/language/value_category  
<sup>21</sup> https://en.cppreference.com/w/cpp/language/value_category
