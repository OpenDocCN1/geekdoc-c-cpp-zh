Compilation error invoking `std::accumulate` with a view

The reason for the compilation error is straightforward but also surprising. The composition of range adapter algorithms (lines 12 - 14) returns a view. `std::accumulate` on the other hand requires harmonized types for the begin and end iterator. Converting the view into a `std::views::common` (lines 17 - 20) solves the issue. Now, I can directly feed results into `std::accumulate` (line 24).
