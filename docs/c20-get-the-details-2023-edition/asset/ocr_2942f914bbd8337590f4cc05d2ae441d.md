# 6.6 `std::jthread`

![](bbox=[0.376, 0.18, 0.644, 0.468])

Cippi ties a braid

`std::jthread` stands for joining thread. In addition to `std::thread`<sup>36</sup> from C++11, `std::jthread` automatically joins in its destructor and can cooperatively be interrupted. `std::jthread` models RAII and, therefore, also joins when an exception occurs.

The `std::jthread` constructor creates a `std::stop_source` and stores it as a member of the thread object. It passes the corresponding `std::stop_token` to the called function if that function takes an additional `std::stop_token` as first parameter. The `std::stop_token` can be used by the functions to check if a stop request has been made.
