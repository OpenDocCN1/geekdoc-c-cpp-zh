Chapter 1. C++ Introduction
Why Use C++
C++ is one of the widely popular programming languages used in the world.
C++ is available in today's operating systems, Embedded systems and graphical User Interfaces.
C++ is an object-oriented programming language which allows code to be reused, and gives a clear structure to programs and lowering development costs.
C++ is portable and can be used to develop applications that can be adapted to multiple platforms.
C++ is handy and easy to learn!
As C++ is close to Java and C#, it is easy for programmers to switch to C++ or vice versa
