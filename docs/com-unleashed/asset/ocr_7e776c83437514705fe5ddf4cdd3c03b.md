**FIGURE 26.11**

The last dialog of the New Subscription wizard gives you the option of naming the subscription and enabling/disabling it.

![](bbox=[0.232, 0.388, 0.592, 0.579])

Now, enter a name for your subscription: BackOrdersToReceiving_Inventory is the name I used. The naming convention `<subscriber_component>To<event_method>` is simply my own convention. You're free to use whatever makes the most sense to your particular system.

Finally, click the Enable this Subscription Immediately check box so that you can use the subscription. Once you've done that, click the Finish button so that Component Services can create and enable the new subscription.
