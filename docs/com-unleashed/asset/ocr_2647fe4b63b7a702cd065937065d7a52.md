The coding effort involved with using MSMQ can be greatly reduced by smart pointers and ATL. There’s almost always a price in performance when using generated (and thus somewhat generic) code. Smart pointer wrappers and templates are specifically designed to minimize this overhead. For many, the smart pointer tack embodies the perfect trade-off between performance and ease of use.
