# Regedit and Regedt32

Microsoft has provided two different editors to view and manipulate the Windows system registry: Regedit and Regedt32.

Regedit provides the basic functionality necessary to view and make some alterations to the system registry. The user interface is fashioned in the classic explorer-style view (splitter windows with tree view on the left and list view on the right) as shown in Figure 8.1.
