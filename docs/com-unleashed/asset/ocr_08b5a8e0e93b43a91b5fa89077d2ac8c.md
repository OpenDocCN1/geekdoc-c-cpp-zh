In the `main()` function, I create the event server and event sink objects. Note that the event server object is created out-of-process and the event sink object is created in-process. This is not a necessity of the COM+ event model, but it is the standard implementation.

The event source is typically an ActiveX control that has events, and the event sink is the client application that wants to be notified of the events in the OLE control. The OLE control might be a grid control, and the client might be a dialog that has the control embedded within its client area. The dialog might want to receive notification when the grid control is double-clicked. The dialog would implement an event sink interface defined by the grid control. The OLE control would receive a pointer to the dialog’s event sink when the dialog calls the `IConnectionPoint::Advise()` method. When the grid is double-clicked, the grid control calls the event sink methods of the dialog, thus producing the notification.

In order to call the `IConnectionPoint::Advise()` method, the client must first receive an interface pointer to the `IConnectionPointContainer` interface. This is done in Listing 6.13 with the first call to the `GetInterface()` function.

With the `IConnectionPointContainer` interface, I can now call the method `IConnectionPointContainer::FindConnection()` to retrieve the `IConnectionPoint` object.

Now that I have the `IConnectionPoint` interface, I can call `IConnectionPoint::Advise()` to set up the event notification. Note that I pass a pointer to a DWORD to the `IConnectionPoint::Advise()` method. This is a cookie that I can later use to call the `IConnectionPoint::Unadvise()` method to terminate the event notification.

The next step is to retrieve an interface pointer for the `IEventTrigger` interface. In Listing 6.13, this is the second call to the `GetInterface()` function. After I have the `IEventTrigger` interface, I can call the `IEventTrigger::Fire()` method to fire the event. When the method is fired, the code in `MyEventSink::Hello()` is called.

The event was fired.  Hurray!
End
