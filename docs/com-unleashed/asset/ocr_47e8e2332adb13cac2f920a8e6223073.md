# Server Configuration on Windows NT Server 4.0

CIS requires that Service Pack 4 be installed on your Windows NT Server 4.0 computer. CIS also requires that Internet Information Server 4.0 (including the Internet Service Manager) be running. IIS 4.0 is part of the Windows NT 4.0 Option Pack.

> **Caution**
> 
> CIS should not be installed on a machine running Microsoft Proxy Server. CIS conflicts with the Microsoft Proxy server port configuration.

Create an RPC subdirectory under your Inetpub directory. For example, at the command prompt, type the following:

```
md c:\inetpub\rpc
```
