If you run the code in Listing 7.12 without the critical section in place, you will produce some horrific output in the standard out (see Listing 7.13). This is because the individual threads are being swapped out in the middle of the cout command. The next thread then begins writing its output before the previous thread completes. This continues until you have a very special output.

# **LISTING 7.12**  Thread-Safety Checking

```
int main(int argc, char* argv[])
{
    Pool thread;
    Sleep(1000);
    for (int i=0;i<20;i++)
    {
        thread.DoWork();
    }
    Sleep(2000);
    return 0;
}
```
