In order to launch the module as a service, you must first register the service with the SCM. You can do this by simply running the Myatservice.exe executable with the -service command-line parameter.

After registering the service with the SCM, step through the client code again, and the ATL module will launch as a service. You might be wondering how to tell whether a module is launched as a service or an executable. The next section describes a few tools—including the Administrative Tools Services applet—that will help you determine the running state of a service.

# Utilities for Working with Services

Four tools are invaluable when you are programming and working with services. These are the Administrative Tools Services applet, the Diagnostic utility, the Service Controller, and the Event Viewer.
