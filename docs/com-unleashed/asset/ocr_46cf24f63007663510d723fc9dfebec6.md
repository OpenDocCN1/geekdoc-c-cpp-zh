Because this component will be the most bare bones, simple component possible, select the Simple Object icon from the dialog's listview and click the Next button. The next dialog (Figure 27.6) allows you to enter the information that will dictate several key names and files. For the purposes of this demo, type Interaction into the Short Name field. When you do this, you will see that its interface is named IInteraction.

**FIGURE 27.6**  
Typically when adding an ATL component to a project, set the Short Name value and let the other values—such as coclass, Interface name, and C++ class name—default to a conjugated version of what you entered.

![](bbox=[0.228, 0.393, 0.553, 0.549])

Now, click the Attributes tab of this dialog. This tab (shown in Figure 27.7) enables you to specify some key attributes associated with your ATL component. However, for this demo, only one important attribute is the Free Threaded Marshal option. For those of you with inquiring minds, take a look at the sidebar entitled “A Glimpse at the Free Threaded Marshal” for a short synopsis on why you would want to specify the Free Threaded Marshal.
