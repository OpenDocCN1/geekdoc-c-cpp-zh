When using surrogates, you can use the standard surrogate or you can create a custom surrogate. To configure an in-process server to use a surrogate, set the RemoteServerName value in the AppID registry key on the client machine to the address or name of the remote server. To use the standard surrogate, set the DllSurrogate value in the AppID registry key on the server machine's registry to empty. To use a custom surrogate, set this same registry value to the path of your custom surrogate module. Listing 9.5 shows the registry settings necessary to make an in-process server use a surrogate.
