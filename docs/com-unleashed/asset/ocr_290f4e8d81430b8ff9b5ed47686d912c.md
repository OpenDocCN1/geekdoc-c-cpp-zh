Both the definition and declaration are standard implementations of a dual interface. They inherit from the IDispatchImpl ATL class template and implement all the methods of the interface (±MyEventSink). In this case, one method sends a message to the standard output when the event is fired. About the only code out of the ordinary in this declaration and definition is that the event server’s header file (EventServer.h) comes before the class declaration, and the event sink’s header library source file (EventServer_i.c) comes before the class definition. These files contain the C++ definition of the event sink interface (in the header file) and the GUIDs of the event sink interface (in the source file).

The control program is where all the action is (see Listing 6.13).
