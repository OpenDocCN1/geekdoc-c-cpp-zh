I've created two interfaces, one to trigger events and one to capture events (an event sink). Each interface has one method that defines the trigger method and sink method. When the trigger method in the event source is called, the sink methods in the event sinks will be called.

In the coclass definition, I included the interface attributes [default, source] for the event interface. That means this interface is the default interface for events. It is important to add the [source] attribute to mark interfaces as being event sink interfaces, rather than that interfaces exposed by the class. Languages such as Delphi and Visual Basic use the [source] attribute to differentiate events from methods and properties.
