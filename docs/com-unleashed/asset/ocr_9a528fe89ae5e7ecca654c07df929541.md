# The Shared Property Group Manager

As illustrated here, three steps are commonly involved in using the SPM. The first step is to get an interface pointer to the ISharedPropertyGroupManager. Although it's perfectly acceptable to use CoCreateInstance() in constructing the SPM, your example uses the context object's CreateInstance() method. In the case of the SPM, both work fine. The details of IContextObject::CreateInstance() are discussed in the following section. Regardless of how you retrieve the ISharedPropertyGroupManager interface pointer, only a single instance of the SPM will ever be created per process.
