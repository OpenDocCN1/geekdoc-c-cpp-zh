Although I will not go into the details of SNA Server setup and administration, I will give a brief overview of SNA Server and mainframes in general to benefit readers new to legacy applications. # Note

> SNA Server has a steep learning curve, especially for non-mainframe programmers. SNA Server has many undocumented pitfalls and frustrations, but after the system is configured and the development process is smooth, SNA Server is quite possibly the most powerful, legacy-accessing tool ever created for the Windows operating system.

# Caution

> It is not an overstatement to mention that mainframes and PCs live in different worlds. If you have never developed in a mainframe system, you will be surprised to find many discrepancies in common NT terminology.
> 
> In mainframes, simple issues such as compiling, working with files, or just plain human-computer interface are so different from PCs that mainframes almost look alien at first. Many of the technical terms that you might be familiar with (interface, transactions, client, server) mean very different things to a mainframe developer. If you should take only one thing from this chapter, it is to be aware of the technological communication barrier that exists between the mainframe and PC worlds.
