# ## Closing a Queue

As you have probably noticed in the previous examples, there is no explicit MSMQ-defined mechanism to close a queue or any other object for that matter. This behavior is, of course, already built into COM+ in the form of the Unknown::Release(). The final release of an MSMQ ActiveX object’s interface causes it to perform any necessary shut-down operations. Closing a queue from the COM+ perspective is, therefore, as simple as this:

```
```cpp
pQueue->Release();
