# Destination Apartment Model

| Caller's Apartment | **Destination Apartment Model** |  |  |
|---|---|---|---|
|  | **Single-Threaded** | **Multi-Threaded** | **Neutral** |
| **Single-Threaded** | In the same apartment and context, call is direct; otherwise marshaled to the destination apartment's thread | Marshaled to an MTA thread | Marshaled and then executed on this thread |
| **Multi-Threaded** | Marshaled to the destination thread | Call is direct if in the same context; otherwise marshaled and then executed on this thread | Marshaled and then executed on this thread |
| **Neutral (on STA Thread)** | Marshaled and executed on the destination apartment's thread (might not require thread switch) | Marshaled to an MTA thread | Call is direct if in the same context; otherwise marshaled and then executed on this thread |
| **Neutral (on MTA Thread)** | Marshaled to the destination apartment's thread | Marshaled and then executed on this thread | Call is direct if in the same context; otherwise marshaled and then executed on this thread |
