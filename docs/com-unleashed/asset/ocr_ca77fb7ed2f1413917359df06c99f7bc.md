# Declaring the Object Class

Listing 11.11 shows the declaration of the object class. Two data members hold information necessary to do the marshaling. The m_szEventname member variable contains the name of the event that will trigger marshaling of data. The m_szFilename member variable contains the name of the file that will contain the data being marshaled.

# **LISTING 11.11**  Declaration of the Object Class

```
// myinterface.h: Definition of the MyInterface class
//
///////////////////////////////////////////////////////////////////////////

#if !defined(AFX_MYINTERFACE_H)
#define AFX_MYINTERFACE_H

#if _MSC_VER >= 1000
#pragma once
#endif // _MSC_VER >= 1000

#include "resource.h"       // main symbols

///////////////////////////////////////////////////////////////////////////
// MyInterface

struct OBJECTMARSHALDATA
{
    char szFilename[256];
    char szEventname[256];
};

class MyInterface :
    public IMyInterface,
    public CComObjectRoot,
    public CComCoClass<MyInterface,&CLSID_MyInterface>,
    public IMarshal
{
public:
    MyInterface() { m_recordnumber = 0; }
    BEGIN_COM_MAP(MyInterface)
        COM_INTERFACE_ENTRY(IMyInterface)
        COM_INTERFACE_ENTRY(IMarshal)
    END_COM_MAP()
    // DECLARE_NOT_AGGREGATABLE(MyInterface)
    // Remove the comment from the line above if you don't want
    // your object to support aggregation.

DECLARE_REGISTRY_RESOURCEID(IDR_MyInterface)
```
