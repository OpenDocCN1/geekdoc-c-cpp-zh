# Marking a COM+ Application as Queued

Now that the COM+ Application has been created, you need to mark it as being queued. Once again, this is done via a Component Services wizard. Select the QCCompVCApp application and right-click it to invoke its context menu. Then, select the Properties option. When the QCCompVCApp properties dialog appears, select the Queuing tab.
