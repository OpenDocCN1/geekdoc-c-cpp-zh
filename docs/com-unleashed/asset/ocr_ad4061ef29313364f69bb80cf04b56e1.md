# # CD-ROM Installation

# ## Windows 95/NT/2000 Installation
## Instructions

+   1. Insert the CD-ROM disc into your CD-ROM drive.
+   2. From the Windows 95/NT/2000 desktop, double-click the My Computer icon. Some features may be accessible by right-clicking on the CD icon from the My Computer menu.
+   3. Double-click the icon representing your CD-ROM drive.
+   4. Double-click the icon titled START.EXE to run the CD-ROM interface.

> **Note**
> 
> If Windows 95/NT/2000 is installed on your computer, and you have the AutoPlay feature enabled, the START.EXE program starts automatically whenever you insert the disc into your CD-ROM drive.
