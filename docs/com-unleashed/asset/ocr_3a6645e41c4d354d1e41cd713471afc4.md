# Destroying a Queue

As in previous examples, the destroy behavior is pretty straightforward:

```
```cpp
//Setup queue information using a smart pointer
MSMQMessageInfoPtr pQInfo(new MSMQMessageInfo);
pQInfo->PutPathName(L"\\\\.\\Private$\\BasiqueQueue");

//Destroy the queue
pQInfo->Delete();
wprintf(L"Queue destroyed\\n\\n");
```

# Opening a Queue

Opening a queue with smart pointers is almost as easy as opening a queue with the MSMQ Library API. All you need to do is get an interface pointer to a MSMQMessageInfo object, set the pathname in the Info object, and call the IMSMQQueueInfo::Open() method. An MSMQQueuePtr smart pointer object receives the interface pointer returned by the open call

```
```cpp
//Setup queue information using a smart pointer
IMSMQQueueInfoPtr pQInfo(new MSMQMessageInfo);
pQInfo->PutPathName(L"\\\\.\\Private$\\BasiqueQueue");
```
```

```
```cpp
//Open the queue
IMSMQQueuePtr pQueue =
             pQInfo->Open(MQ_SEND_ACCESS, MQ_DENY_NONE);
```
```
