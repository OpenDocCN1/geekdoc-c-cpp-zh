# SegFormer: Simple and Efficient Design for Semantic Segmentation with Transformers

Enze Xie, Wenhai Wang, Zhiding Yu, Anima Anandkumar, Jose M. Alvarez, Ping Luo

# Abstract

Semantic segmentation is a fundamental task in computer vision. We present SegFormer, a simple, efficient yet powerful semantic segmentation method which unifies Transformers with lightweight multilayer perception (MLP) decoders. SegFormer has two appealing properties: 1) hierarchical design, allowing to extract multiscale features without positional encoding; 2) decoupled encoder-decoder, supporting efficient representation with arbitrary resolution.
