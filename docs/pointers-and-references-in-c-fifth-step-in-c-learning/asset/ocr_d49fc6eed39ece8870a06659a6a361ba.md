# Pointers and References in Classes

Here’s an example program that defines a class with pointer and reference members, demonstrates their usage, and explains how to declare and access them within a class:

```
#include <iostream>

class MyClass {
private:
    int* pointer;
    int& reference;

public:
    // Constructor
    MyClass(int value) : reference(value) {
        pointer = new int(value);
    }

    // Destructor
    ~MyClass() {
        delete pointer;
    }
}
```
