# Pointer to Member Function and Polymorphism

In C++, you can use pointers to member functions to achieve runtime polymorphism. Runtime polymorphism allows you to invoke derived class member functions through a base class pointer, enabling dynamic binding of functions at runtime. Here’s an example program that demonstrates this concept:

```
#include <iostream>

class Base {
public:
    virtual void display() {
        std::cout << "This is the Base class" << std::endl;
    }
};

class Derived : public Base {
public:
    void display() override {
        std::cout << "This is the Derived class" << std::endl;
    }
};
```
