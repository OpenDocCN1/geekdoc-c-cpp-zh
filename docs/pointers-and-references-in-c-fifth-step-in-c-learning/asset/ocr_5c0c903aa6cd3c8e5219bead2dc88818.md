# Null Pointers

Here’s an example program in C++ that assigns a null value to a pointer variable and checks for its nullness:

```
```cpp
#include <iostream>

int main() {
    int* ptr = nullptr;  // Assigning null value to the pointer

    if (ptr == nullptr) {
        std::cout << "Pointer is null." << std::endl;
    } else {
        std::cout << "Pointer is not null." << std::endl;
    }

    return 0;
}
```
```

In this program, we declare a pointer variable ptr of type int*. We initialize it with the value nullptr, which is a keyword in C++ used to represent a null pointer. A null pointer is a pointer that doesn’t point to any valid memory address.
