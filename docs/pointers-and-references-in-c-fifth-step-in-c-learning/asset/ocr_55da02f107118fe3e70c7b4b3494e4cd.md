# Reference Initialization

In C++, references must be initialized upon declaration and cannot be reassigned to refer to a different variable. Here’s an example program that demonstrates reference initialization:

```
#include <iostream>

int main() {
    int num1 = 5;
    int num2 = 10;

    int& ref = num1; // Initializing reference variable 'ref' with the value of 'num1'

    std::cout << "num1: " << num1 << std::endl; // Output: 5
    std::cout << "num2: " << num2 << std::endl; // Output: 10
    std::cout << "ref: " << ref << std::endl;   // Output: 5

    // Attempting to reassign the reference to a different variable
    // This will cause a compilation error
    // ref = num2; // Uncommenting this line will cause a compilation error
```
