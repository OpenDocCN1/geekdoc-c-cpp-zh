# Pointer to Constant

Here’s a program in C++ that demonstrates the concept of a pointer to a constant and how it enforces read-only access:

```
#include <iostream>

int main() {
    int value = 5;
    const int* ptr = &value;  // Pointer to a constant integer

    std::cout << "Value: " << *ptr << std::endl;

    // Attempting to modify the value pointed by the pointer
    *ptr = 10;  // Compilation error: assignment of read-only location

    return 0;
}
```
