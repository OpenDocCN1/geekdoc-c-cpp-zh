# EOF-Controlled *while* Loop

We can read data from the keyboard or from a file. In both cases, we can use the EOF marker that serves as a sentinel sentinel in an *eof-controlled loop*. It can be added to the keyboard and is always present in a file. It is a marker that defines that no more data will be entered through the keyboard or that we have reached the end of the file. The EOF marker allows us to read the data items and control the repetition of the loop. If we are using the keyboard as the source of data, the EOF is (ctrl + d) in the Unix environment and (ctrl + z) in the Windows environment (the first means “hold the control key and press d”; the second means “hold the control key and press z”). On the other hand, if we are using a file as the source of data, the EOF marker is added when the file is created. Figure 5.9 shows both cases.
