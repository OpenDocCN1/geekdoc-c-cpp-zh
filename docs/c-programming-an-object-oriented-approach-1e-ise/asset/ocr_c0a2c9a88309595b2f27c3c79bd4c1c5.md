# ### Stack Operations

We normally encounter three basic operations for a stack data structure, as shown in Figure 18.11.

The operation to insert an element at the top of the stack is referred to as *push*. The operation to delete an element from the top is referred to as *pop*. The operation that only accesses the top element without removing it is referred to as *top*.

# ### Stack Implementation

A stack can be implemented either as an array or a linked list. Although the array implementation is easier, the size of the array must be fixed at compilation time. A linked-list implementation allows the size of the stack to grow and shrink dynamically. Figure 18.12 shows how we normally implement a stack as a linked list.
