In this case we must abort the program because the corresponding object cannot be created, and the lack of the object may affect the rest of the program. The **assert** function is a library function that has no effect when its argument is set to **true**; it aborts the program when its argument is set to **false**. We have used it with the **false** argument to abort the program in case the invariant is not satisfied. To use the assert function, we must include the `<cassert>` header file in our program.
