# # 15 Generic Programming: Templates

In this chapter we concentrate on *generalization*, which means to write a general program that can be used in several special cases. C++ calls this process *template programming*. We first discuss how to write general functions (called function templates) and then we discuss general classes (called class templates).

# ## 15.1 FUNCTION TEMPLATE

When programming in any language, we sometimes need to apply the same code to different data types. For example, we may have a function that finds the smaller of two integer data types, another function that finds the smaller of two floating-point data types, and so on. First, we should think about the code (program logic) and then about the data type to be used. We can separate these two tasks. We can write a program to solve a problem with a generic data type. We can then apply the program to the specific data type we need. This is known as generic programming or template programming.

A function in C++ is an entity that applies operations on zero or more objects and creates zero or more objects. Using **function templates**, actions can be defined when we write a program, and the data types can be defined when we compile the program. In other words, we can define a family of functions, each with one or more different data types.
