# Summary

A source or a sink of data cannot be directly connected to a program. We need a mediator to stand between the sources/sinks and the program to control the flow of data and to interpret data elements when reading or writing. This is done using streams. One of the main purposes of using streams is to convert the format of data as stored in a sink or source to their format in memory. C++ defines a hierarchy of streams in which the *ios* class is the base class for all input/output classes.

Console streams are made of three classes *istream*, *ostream*, and *iostream*. We can use the first two, but the *iostream* class cannot be instantiated.
