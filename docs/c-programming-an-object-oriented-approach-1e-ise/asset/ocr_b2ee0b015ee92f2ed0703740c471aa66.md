**Application File** Program 18.16 shows how to use the implementation file to create a binary search tree and then print the data items in pre-order, in-order, and post-order sequence. Note that only the in-order gives us the sorted list of data value (from smallest to largest). The other two traversals give the structure of the tree (which element is the root, which elements are in the left subtree, and which elements are in the right subtree).

# **Program 18.16** The application file for testing the binary search tree

```
```cpp
/****************************************************************
 * The application file that tests the binary search tree class  *
 ****************************************************************/
#include "binarySearchTree.cpp"

int main ( )
{
    // Instantiation of a binary search tree object
    BinarySearchTree<string> bct;
    // Inserting six nodes in the tree
    bct.insert ("Michael");
    bct.insert ("Jane");
    bct.insert ("Sophie");
    bct.insert ("Thomas");
    bct.insert ("Rose");
    bct.insert ("Richard");
    // Printing values using preorder traversal
    cout << "Using preorder traversal" << endl;
    bct.preorder ();
    cout << endl << endl;
    // Printing values using inorder traversal
    cout << "Using inorder traversal" << endl;
    bct.inorder ();
    cout << endl << endl;
    // Printing values using postorder traversal
    cout << "Using postorder traversal" << endl;
    bct.postorder ();
    cout << endl << endl;
