# Character Classification Functions

All of the classification function names start with the prefix *is*, such as *iscontrol*, *isupper*, and so on. If the argument belongs to the category defined by the function name, the function returns 1 (which can be interpreted as *true*); otherwise, the function returns 0 (which can be interpreted as *false*). Note that the parameter in each function is of type *int*, but we always pass a character as the parameter (a character is an integer smaller than short integer).
