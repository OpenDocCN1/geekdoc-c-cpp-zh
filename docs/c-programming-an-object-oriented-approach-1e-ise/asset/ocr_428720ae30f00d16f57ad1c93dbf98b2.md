# Understand the Problem

The future value of a fixed investment can be calculated as:

$$\text{future value} = \text{investment} \times (1 + \text{rate})^{\text{term}}$$

in which *rate* is the periodic interest rate and *term* is the number of periods (years or months). We can think of (1 + rate) as a *factor* that shows the value of a one-dollar investment at the end of the next period. We can also think about (factor^term) as a multiplier that shows the value of a one-dollar investment at the end of the term. With these assumptions, we have

$$\begin{aligned}\text{factor} &= (1 + \text{rate})\\\text{multiplier} &= \text{factor}^{\text{term}}\\\text{future value} &= \text{investment} \times \text{multiplier}\end{aligned}$$

In other words, to find the future value of an investment, we must find the future value of one dollar (using multiplier) and then multiply it by the amount of the investment.
