# Program 3.3 Testing plus/minus expressions

```
```cpp
1 /**********************************************************
2 * The program shows the use of plus/minus expressions          *
3 **********************************************************/
4 #include <iostream>
5 using namespace std;
6
7 int main ()
8 {
9     // Declaration and initialization
10    int x = 4;
11    int y = -10;
12    // Applying plus and minus operator on variable x
13    cout << "Using plus operator on x: " << +x << endl;
14    cout << "Using minus operator on x: " << -x << endl;
15    // Applying plus and minus operator on variable y
16    cout << "Using plus operator on y: " << +y << endl;
17    cout << "Using minus operator on y: " << -y << endl;
18    return 0;
19 }
