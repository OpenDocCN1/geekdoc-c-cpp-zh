## Program 7.13 The Interface File (time.h)

```cpp
/******************************************************
 * The interface file for time.h class                 *
 ******************************************************/
#include <iostream>
using namespace std;

#ifndef TIME_H
#define TIME_H

class Time
{
    private:
        int hours;
        int minutes;
        int seconds;
    public:
        Time (int hours, int minutes, int seconds);
        Time ();
        ~Time ();
        void print() const;
        void tick();

    private:
        void normalize();          // Helping function
};
#endif
```

### Data Members

We need three private data members: *hours*, *minutes*, and *seconds*. All are of type *int*.

### Member Functions

There are many member functions that could be applied not only to data members but also to the objects created from the class. For example, we can compare two times, determine the time elapsed between two times, and so on. We defer defining these operations to future chapters. In this chapter, we use member functions that act as constructors, destructors, accessors of data members, and mutators of data members.

### Code

Program 7.13 shows the interface file. This is just a header file and will be included in both the application file and the user file.

## Program 7.15 Application File (app.cpp) to Test the Time Class

```cpp
/***************************************************************
 * The application file app.cpp to use the Time class          *
 ***************************************************************/
#include "time.h"

int main ()
{
    // Instantiation of a time object
    Time time (4, 5, 27);
    // Printing the original time
    cout << "Original time: ";
    time.print();
    // Adding 143500 seconds to the original time
    for (int i = 0; i < 143500; i++)
    {
        time.tick ();
    }
    // Printing the time after 143500 ticks
    cout << "Time after 143500 ticks";
    time.print();
    return 0;
}
```
