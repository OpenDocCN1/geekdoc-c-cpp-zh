# 17.2.3 **The Towers of Hanoi**

We discuss one more classic recursive problem, the Towers of Hanoi. It is normally solved using a recursive approach. In the problem, there are three pegs (towers). Stacked on the first peg is a set of disks with the smallest at the top. Figure 17.14 shows the situation with four disks.

We must move the disks from the first peg (A) to the third peg (C). The second peg (B) is used to temporarily store disks during the process. The task uses the following rules:

+   - Only one disk can be moved at a time.
+   - A larger disk must never be stacked above a smaller one.
+   - One temporary peg (B) is used for the intermediate storage of disks.

This problem is interesting for two reasons. First, the recursive solution is much easier to code than the iterative solution. Second, the solution pattern for this problem is different from the simple examples we have been discussing.
