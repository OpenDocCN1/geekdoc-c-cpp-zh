# 13.6.3  Polynomials

Polynomials are one of the basic mathematical structures that we encounter in many different areas of computer science, such as networking and network security. A polynomial with one variable can be defined as shown below, in which the n’s are the exponents and the a’s are the coefficients of terms.

$a_nx^n + a_{n-1}x^{n-1} + ... + a_2x^2 + a_1x + a_0$
