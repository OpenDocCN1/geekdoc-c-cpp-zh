# ## Searching for a Character

Searching in a C++ string is very broad and covers many cases. In specific searching, we are given a search argument consisting of a specific character that we want to find in the host string object. However, it may happen that there is more than one copy of the search argument in the host object. In a forward search, we are looking for the first copy; in a backward search, we are looking for the last copy. Note that searching does not retrieve or change the object being searched; it only finds the position of the search argument. If we want to retrieve or change the located character or string, we must use other member functions that we discussed earlier.
