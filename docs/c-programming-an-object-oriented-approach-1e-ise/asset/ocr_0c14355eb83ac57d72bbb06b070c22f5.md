# # 16 Input/Output Streams

C++ treats input/output operations as library classes called *streams*. In this chapter, we first introduce sources and sinks of data. We then discuss streams, which are classes that connect our programs to those sources and sinks. We discuss console streams, file streams, and string streams. Finally, we discuss data formatting as it pertains to streams.

# 16.1 INTRODUCTION

When we run a program, data must be stored in memory. The data stored in memory for processing comes from an external source and goes to an external sink. This means that we must consider the source and the sink of our data. A source can be a keyboard, a file, or a string. A sink can be a monitor, a file, or a string.
