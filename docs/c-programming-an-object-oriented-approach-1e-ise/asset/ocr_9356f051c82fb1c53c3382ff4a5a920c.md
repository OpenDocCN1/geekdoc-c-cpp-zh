How can we use EOF? Fortunately, the `>>` operator has a side effect and a return value. It reads the next item in the stream. If the next item is EOF, it discards it and returns false (the loop is terminated). If the next item is not EOF, it stores the next item in the variable defined after the operator `>>` and returns true (the loop continues).

| // Reading from keyboard | // Reading from a file |
|---|---|
| `while (cin >> num)`<br>`{`<br>&nbsp;&nbsp;&nbsp;&nbsp;`process;`<br>`}` | `while (infile >> num)`<br>`{`<br>&nbsp;&nbsp;&nbsp;&nbsp;`process;`<br>`}` |

/***************************************************************
 * Use of the EOF-controlled while loop to find the sum        *
 * of some numbers entered on the keyboard                    *
 ***************************************************************/
#include <iostream>
using namespace std;

int main()
{
    // Declaration
    int sum = 0;
    int num;
    // Loop including initialization
    cout << "Enter the first integer (EOF to stop): ";
    while (cin >> num)
    {
        sum = sum + num;
        cout << "Enter the next integer: ";  // update
    }
    // Output
    cout << "The sum is: " << sum;
    return 0;
}
