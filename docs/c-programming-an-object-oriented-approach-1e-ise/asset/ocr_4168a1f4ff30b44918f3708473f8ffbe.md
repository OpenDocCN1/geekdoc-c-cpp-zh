# **Operations**

Some of the operations we defined previously for a one-dimensional array can be used with two-dimension arrays. Others must be modified to be applicable to two-dimensional arrays. For example, searching and sorting should be applied to each dimension separately. However, there are some operations that can be applied specifically to two-dimensional arrays.
