As we mentioned before, the C++ language is case-sensitive. Many programmers use identifiers made of lowercase letters, but it is becoming more and more common to use two-word or three-word identifiers with the first word all in lowercase and subsequent words starting with an uppercase letter, such as `lowerValue`, `upperValue`, `firstTest`, `secondTest`, `timeOfWithdraw`, and so on. The library of the C++ language also uses identifiers with several words separated by an underscore, but we need to avoid them in our programs.
