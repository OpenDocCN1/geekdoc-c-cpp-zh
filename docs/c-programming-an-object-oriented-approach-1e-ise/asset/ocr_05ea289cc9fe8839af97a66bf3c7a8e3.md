# **Program 15.2**  Using one function template

```
```cpp
/************************************************************/
/* A program that uses a template function to find the smaller  *
/* of two values of different types                            *
/************************************************************/
#include <iostream>
using namespace std;

// Definition of a template function
template <typename T>
T smaller (T first, T second)
{
    if (first < second)
    {
        return first;
    }
    return second;
}

int main ( )
{
    cout << "Smaller of a and B: " << smaller ('a', 'B') << endl;
    cout << "Smaller of 12 and 15: " << smaller (12, 15) << endl;
    cout << "Smaller of 44.2 and 33.1: " << smaller (44.2, 33.1) << endl;
    return 0;
}

Run:
Smaller of a and B: B
Smaller of 12 and 15: 12
Smaller of 44.2 and 33.1: 33.1
```
```

used only one single type name, *T*, which is used to define the two parameters and the return value. We did that because the type of the two parameters and the return type are the same. Note also that we have used *T&* instead of *T* to allow the objects of the user-defined type to be passed and returned by reference instead of value.
