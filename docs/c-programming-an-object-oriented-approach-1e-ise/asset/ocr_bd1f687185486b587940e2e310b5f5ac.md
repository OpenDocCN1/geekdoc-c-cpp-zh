See examples of pass-by-reference in real life. When we pass a document to a friend for editing, we are sharing the original document with her. Any change to the document made by our friend changes it for us when the document is returned.

In computer parlance, we sometimes refer to pass-by-reference as *read-write* communication, which means the called function can read the value of the arguments in the calling function, and it can also change them.
