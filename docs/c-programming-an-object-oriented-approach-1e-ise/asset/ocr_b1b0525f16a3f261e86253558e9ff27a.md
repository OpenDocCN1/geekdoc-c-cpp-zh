```cpp
void fun (char c)
```

```
**PR-2.** What is returned from *fun*(5, 12) and *fun*(12, 5) as coded below? Explain what the function does.

```
```cpp
int fun (int n, int m)
{
    if (n == m)
    {
        return 0;
    }
    else if (n > m)
    {
        return 1;
    }
    else
    {
        return fun (m, n);
    }
}
```
