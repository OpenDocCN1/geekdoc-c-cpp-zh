/***************************************************************
 * A program that changes every lowercase letter to an uppercase
 * letter and counts the alphabetic characters.
 ***************************************************************/
#include <iostream>
#include <cctype>
using namespace std;

int main ( )
{
    // Declaration
    char ch;
    int count = 0;
    // Inputting characters and processing
    while (cin >> noskipws >> ch)
    {
        if (isalpha (ch))
        {
            count++;
        }
        ch = toupper (ch);
        cout << ch;
    }
    // Printing the count of characters
    cout << "The count of alphabetic characters is: " << count;
    return 0;
}

# 6.2.3  Handling Time

One of the library functions we often encounter in C++ programming is the time function defined in the <ctime> header file. We discuss this function in more detail in Appendix I, but for the moment, it is enough to say that this function returns the number of seconds elapsed from the Unix epoch (midnight of January 1, 1970) when the argument passed to the function is 0.
