# ### Checking for Palindromes

A string is a palindrome if it reads the same forward and backward. We can solve this problem using a recursive function called *isPalindrome* that has two base cases and one general case, as shown in *Table 17.4*.

The first base case is related to an empty string or a string with only one character, which is obviously a palindrome. The second base case is related to the string in which the first character and the last character are different, which is obviously not a palindrome.

*Figure 17.7* shows how we can use the base and general cases to find if a string is a palindrome.

*Program 17.5* shows the code for the recursive function *isPalindrome*.

**Table 17.4** The base cases and the general case of the isPalindrome function

|  |  |
|---|---|
| Base case | `if (length <= 1), return true`<br>`else if (str[0] != str[str.size() - 1]) return false` |
| General case | `return isPalindrome (str.substr (1, str.size () - 2));` |
