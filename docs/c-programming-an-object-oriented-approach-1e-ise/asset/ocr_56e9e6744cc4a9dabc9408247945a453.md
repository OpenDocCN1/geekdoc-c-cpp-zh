# Summary

A function is an entity with a header and a set of statements that are designed to do a task. As programs become more complex, we divide the task into smaller tasks, each of which is responsible for a part of the job. There are four benefits to dividing a task into several small tasks: easier to write, easier to debug, reusable, and can be saved for future use.

Three entities are associated with a function: function definition, function declaration, and function call.

In a library function, the definition is already created in the C++ library; we only need to include the corresponding header file in our program and then call the function. In a user-defined function, we declare, define, and call the function.

Functions in a program may need to exchange data. We refer to this activity as *data pass* and *data return*. Each can be done using one of the three methods: by value, by reference, or by pointer.
