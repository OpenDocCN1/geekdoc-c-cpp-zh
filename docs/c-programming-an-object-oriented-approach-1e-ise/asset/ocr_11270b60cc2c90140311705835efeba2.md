operator makes a **map** object look like an array in which the index is a key instead of an integer. In other words, if we know the value of the key in an element, we can access the element using the expression *map* [key]. However, the operator [ ] does not act like the one used for an array or a *vector* or a *deque*. It is just a notation to create a *pair* consisting of key-value. A *map* uses only bidirectional iterators and cannot jump from one *pair* to another using the + or − operator.
