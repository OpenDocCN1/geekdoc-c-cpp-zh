{
    cout << "Enter a positive decimal: ";
    cin >> decimal;
} while (decimal <= 0);
// Conversion to binary
while (decimal > 0)
{
    int digit = decimal % base;
    char ch = findChar(digit);
    pushFront (strg, ch);
    decimal /= base;
}
// Outputting binary
cout << "Binary: " << strg;
return 0;
}

# S u m m a r y

The C string is a null-terminated array of characters that can be created like an array. A literal string is a constant value that encloses characters in two double quotes. We can input C strings using the extraction operator or the *getline* library function. We can output C strings using the insertion operator.
