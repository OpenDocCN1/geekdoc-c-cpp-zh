+   - In pass-by-pointer, the argument and the parameter are bound together. Any change in the parameter means the same change in the argument unless we use a constant pointer, as we discussed previously.
+   - It is obvious that pass-by-pointer reduces the cost of copying. Only a 4-byte address is copied. We must consider this method when we want to pass a large object, such as an object of class type, to a called function.

**Recommendation** We augment the recommendation we made previously to three practices: pass-by-value, pass-by-reference, and pass-by-pointer.

+   1. If we need to prevent change, we must use
+      a. pass-by-value for small objects.
+      b. pass-by-constant reference or pass-by-constant pointer for large objects.
+   2. If there is a need for change, we must use pass-by-reference or pass-by-pointer.
