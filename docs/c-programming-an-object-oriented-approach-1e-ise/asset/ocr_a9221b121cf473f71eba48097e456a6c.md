# Structure of Switch Statement

Before we discuss how the *switch* statement can be used for multivalue decisions, let us look at the structure of this statement. The basic *switch* statement is designed for what is called a *fall through* flow. Figure 4.11 shows the flow diagram and the syntax of a switch statement with four cases (we can have as many cases as we need).

The *switch* statement makes a decision to enter the *fall through* flow when the value of the expression matches a value defined in one of the cases. In other words, entering the *fall through* is based on a value, but when the flow enters the *fall through*, it goes all the way to the end and executes all remaining fall through statements.

In the figure, the value of the expression is first compared to the value1. If there is a match, statement1 through statement4 are all executed. If the value of the expression does not match value1, but matches value2, statement2 through statement4 are executed (statement1 is skipped). If none of the values are matched, no statement is executed. The value in the *case* clauses should be unique.
