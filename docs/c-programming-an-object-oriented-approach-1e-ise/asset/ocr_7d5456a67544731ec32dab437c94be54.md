# EXAMPLE 4.6

Assume a professor wants to write a program to determine the letter grade (A, B, C, D, and F) for a test score between 0 and 100. The code, using multiway selection, is shown in Program 4.6.

# Program 4.6  Finding a grade related to a score

```
~~~cpp
/**********************************************************
 * Find a grade given a score using the multi-way selection    *
 **********************************************************/
#include <iostream>
using namespace std;

int main ()
{
    // Declaration
    int score;
    char grade;
    // Get Input
    cout << "Enter a score between 0 and 100: ";
    cin >> score;
    // Multi-way decision using if-else
    if (score >= 90)
    {
        grade = 'A';
    }
    else if (score >= 80)
    {
        grade = 'B';
    }
    else if (score >= 70)
    {
        grade = 'C';
    }
    else if (score >= 60)
    {
        grade = 'D';
    }
    else
    {
        grade = 'F';
    }
    // Output
    cout << "The grade is: " << grade;
    return 0;
} // End main
~~~
```
