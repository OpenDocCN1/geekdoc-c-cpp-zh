# EXAMPLE 5.20

Program 5.16 shows how to create the multiplication table for size 2 to 10. The size is input by the user. Note that the value in row *i* and column *j* is in fact the value of (*i* * *j*).

# **Program 5.16** Creating a multiplication table

```
~~~cpp
/****************************************************************
 * Use a for loop inside another loop to print a multiplication
 * table of size 2 to 10.
 ****************************************************************/
#include <iostream>
#include <iomanip>
using namespace std;

int main ()
{
    // Declaration of size
    int size;
    // Input and validation
    do
    {
        cout << "Enter table size (2 to 10): ";
        cin >> size;
    } while (size < 2 || size > 10);
    // Printing the table (nested loops)
    for (int i = 1; i <= size; i++)
    {
        for (int j = 1; j <= size; j++)
        {
            cout << setw (4) << i * j;
        }
        cout << endl;
    }
    return 0;
}
~~~
```
