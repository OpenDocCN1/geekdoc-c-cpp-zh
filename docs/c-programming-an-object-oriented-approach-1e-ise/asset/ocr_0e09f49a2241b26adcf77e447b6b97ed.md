# EXAMPLE 6.12

Program 6.12 follows the principle of modular programming: input-process-output. The main function is responsible for only three calls: input call, processing call, and output call. The rest is done by three functions: *input*, *process*, *output*. Program 6.12 is designed to get the value of a year from the user (input), and if the year is a leap year (processing), and print the result (output). We previously discussed that a year needs to satisfy two criteria to be a leap year. First, it must be divisible by 4. Second, if it is divisible by 100, it must also be divisible by 400.

# **Program 6.12**  Finding if a year is a leap year

/**************************************************************
 * This program shows how to use three functions: input an     *
 * integer representing a year, check if it is a leap year,   *
 * and print the result.                                       *
 **************************************************************/
#include <iostream>
using namespace std;

// Declarations (prototypes)
int input();
bool process (int year);
void output (int year, bool result);

int main()

    int year = input();
    bool result = process (year);
    output (year, result);
}
