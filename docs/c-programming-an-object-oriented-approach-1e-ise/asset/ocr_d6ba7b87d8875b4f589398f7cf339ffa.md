# 2.3.2 Comments

We briefly discussed comments when we introduced our second program. Comments are explanations added to the program to make it understandable for people who read the source code. They are text that is removed by the preprocessor, which is a program that prepares the source code for compilation.

# Single-Line Comments

If we need a short comment, we can use a single-line comment. A single-line comment starts with // and terminates at the end of the line. It can start at any point in a line, but it consumes the rest of the line. The rest of the line after // is ignored by the compiler. In this book we show comments in red.

```
cout << "Hello World";          // This prints the first line.
```
