# ### Floating-Point Literals

Floating-point literals are numeric values with fractions such as 32.78, 141.123, 123456.0, and -2472.657. The programmer can explicitly define the size by using suffixes as shown in Table 2.6

> > The default size of a floating-point literal is double.
