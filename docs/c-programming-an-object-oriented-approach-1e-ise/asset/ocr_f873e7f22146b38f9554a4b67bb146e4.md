# Summary

A reference type is a compound type that allows a memory location to be used with different names.

A pointer type is a compound type representing an address in memory. A pointer variable is a variable that contains an address.

The memory used by a C++ program is made of four distinct areas: code memory (holding programs), static memory (holding global and static objects), stack memory (holding the parameter and local objects), and heap memory (holding the object created during runtime).
