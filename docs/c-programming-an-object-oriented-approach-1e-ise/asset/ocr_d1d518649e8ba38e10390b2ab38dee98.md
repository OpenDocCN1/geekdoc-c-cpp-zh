```
# ### 15.1.4 Interface and Application Files

The definition of a template function can be put in an interface file, and the header can be included in an application file. This means that we can write one definition for a template function and then use it in different programs. The interface file in this case must include the definition of the function, not only the declaration. Program 15.7 shows how we can create an interface file, *smaller.h*, and put the definition of the function template in it. Any program can include this interface and use the function (Program 15.8).

# **Program 15.7** Definition of a function template

```
```cpp
/********************************************************
 * The interface file for the function template named smaller       *
 ********************************************************/
#ifndef SMALLER_H
#define SMALLER_H
#include <iostream>
using namespace std;

template <typename T>
T smaller (const T& first, const T& second)
{
    if (first < second)
    {
        return first;
    }
    return second;
}
#endif
```
