The advantage of this practice is that we can refer to the capacity of the array using the constant identifier (CAPACITY). As we discussed previously, it is customary to use uppercase letters to define constants.

# Memory Allocation

After an array has been declared, the compiler allocates memory locations for the array. Allocation depends on the type and capacity of the array. Each element of the array is accessible through an index enclosed in two brackets. The index, however, starts from [0] and goes to [CAPACITY − 1]. Figure 8.3 shows declarations and allocation of memory for three arrays: scores, nums, and c1s.

Note that elements in an array use zero-indexing, which means the indexes start from [0] and go to [CAPACITY − 1].
