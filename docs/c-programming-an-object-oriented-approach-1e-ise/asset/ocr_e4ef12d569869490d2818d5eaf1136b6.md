# Delegation versus Invocation

Delegation and invocation are different concepts and are done differently. In delegation, a derived member function delegates part of its duty to the base class using the class resolution operator (::). In invocation, the constructor of a derived class calls the constructor of the base class during initialization, which does not require the class resolution operator.
