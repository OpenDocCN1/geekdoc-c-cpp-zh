# INHERITANCE

![](bbox=[0.08, 0.32, 0.32, 0.55])

Learning how to create objects is the first step to understanding object-oriented programming. The second step is to understand inheritance. In traditional object-oriented languages, classes inherit properties from other classes. In JavaScript, however, inheritance can occur between objects with no classlike structure defining the relationship. The mechanism for this inheritance is one with which you are already familiar: prototypes.

# Prototype Chaining and Object.prototype
