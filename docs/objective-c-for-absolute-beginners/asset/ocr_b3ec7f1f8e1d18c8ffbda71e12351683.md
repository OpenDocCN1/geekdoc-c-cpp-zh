# INTRODUCTION

Longer than average time to graduation
One of the biggest challenges to learning OOP languages like Java, C++, or Objective-C is the steep learning curve from the very beginning. In the past, students had to learn the following topics all at once:

+   - Object-oriented principles
- A complex Integrated Development Environment (IDE), i.e., Xcode, Eclipse, Visual Studio
- The syntax of the programming language and principles
- Programming logic and principles

As a result, Carnegie Mellon University received a grant from the US government and developed Alice. Alice, an innovative 3D programming environment, makes it easy for developers to create rich applications. Alice is a teaching tool for students to learn in an OOP environment. The software uses 3D graphics and a drag-and-drop interface to facilitate a more engaging first programming experience.
Alice helps students focus on learning the principles of OOP without having to focus on learning a complex IDE and Objective-C principles all at once. You get to focus on each topic individually. Drag-and-drop programming removes all the complexity of learning an IDE and programming language syntax. You'll see learning is actually fun, and you can develop your own sophisticated applications.
After we introduce Alice and readers feel comfortable with the material, we will move into Xcode, where you can use your new OOP knowledge in writing Objective-C applications. Thus, you can focus on the Objective-C syntax and language without having to learn OOP at the same time.

# Learning Objective-C Without Alice

More than a thousand students have used this book to become iOS developers. At the end of each course, we ask our students if the Alice sections in the first four chapters were useful. More than half of the students using Alice at the beginning of the first chapters found the chapter was critical to their success. However, some of the students didn't feel they needed the Alice examples at the beginning of the first chapters.
We have laid out the first four chapters of this book with the first part of each chapter introducing OOP with Alice; the remaining part of chapter introduces the topic using Objective-C. Thus, you can skip the Alice if you feel comfortable with the topic.

# How This Book Is Organized

You'll notice that we are all about successes in this book. We introduce the OOP and Logic concepts in Alice and then move those concepts to Xcode and Objective-C. Many students are visual or learn by doing. We use both techniques. We walk you through topics and concepts with visual examples and then take you through step-by-step examples reinforcing the concepts.
We repeat topics in different chapters to reinforce what you have learned and applied these skills in new ways. This enables new programmers to replay development skills and feel a sense of accomplishment as they progress. Don't worry if you haven't mastered a topic keep moving forward!
