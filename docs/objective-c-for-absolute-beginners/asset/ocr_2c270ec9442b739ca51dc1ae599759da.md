# CHAPTER 10: Creating User Interfaces

```
(IBAction)seed:(id)sender {
  random(time(NULL));
  [randomNumber setText:@"Generator seeded"];
}

-(IBAction)generate:(id)sender {
// Generate a number between 0 and 100 inclusive
  int generated = (random() % 101);
  [randomNumber setText:[NSString stringWithFormat:@"%i",generated]];
}
```

**Figure 10–22.** The seed: and generate: methods completed.

There is some code we should examine a bit further: [randomNumber setText:. The method setText sets the UILabel value in your view. The connections you established in Interface Builder from your outlet to the Label object do all the work for you.
