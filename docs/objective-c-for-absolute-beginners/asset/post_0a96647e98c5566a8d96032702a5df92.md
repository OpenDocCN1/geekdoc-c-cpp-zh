## Collections

Understanding collections is a fundamental part of learning Objective-C. In fact, collection objects are fundamental constructs of nearly every modern object-oriented language library—sometimes they are referred to as **containers**. Simply put, a collection is a type of class that can hold and manage other objects. The whole purpose of a collection is that it provides a common way to store and retrieve objects efficiently.

## CHAPTER 8: Programming Basics in Objective-C

There are different types of collections. While they all fulfill the same purpose of being able to hold other objects, they differ mostly in how the objects are retrieved. Here is a list of the most common collections used in Objective-C:

- NSSet
- NSArray
- NSDictionary
- NSMutableSet
- NSMutableArray
- NSMutableDictionary

Notice that, among the three collection classes listed, there is one that contains the word Mutable. A mutable (vs. non-mutable) class is one that can have items added and removed from it after the collection has.

### Using NSSet

The NSSet is unordered. The advantage of NSSet is performance. In order to get data within the NSSet, a few methods are used. Note that the fast enumeration below works on all collection classes.

#### Listing 8-1. Iterating through NSSet.

```objc
NSSet *mySet = [NSSet initWithObjects:@"One", "Two", "Three"];
for (id value in mySet) {
  NSLog("%@", value);
}
```

NOTE: On line 3, the class of the value is id. Recall that an id is a generic type that represents any Objective-C class. For example, if the NSSet were to contain a class called Animal and another class called Zoo, the code would fail. On the other hand, if the NSSet always had the same class, we could substitute for the id on line 3.

#### Listing 8-2. Selecting any objects in the NSSet.

```objc
NSSet *mySet = [NSSet initWithObjects:@"One", "Two", "Three"];
NSString *value = [mySet AnyObject];
```

Line #3 calls the method. This does exactly as it says; it returns any object from the set. The object returned is determined by the set's convenience so there can be no guarantee that the first item will be returned. Of course, using the AnyObject assumes that any object will do.
