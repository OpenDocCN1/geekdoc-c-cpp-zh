We now have the necessary code in place, but we don't yet have an interface on the iPhone. Next, we're going to edit the interface and add two interface objects to our app.

In order to edit the iPhone's interface, we need to click once on the ViewController.x file. The .nib file contains all the information about a single window or view. Apps that have multiple views will multiple .nib files. We will use Xcode's interface editor to connect a UI object, such as a label, to the code we just created. Connecting is as easy as clicking and dragging.
