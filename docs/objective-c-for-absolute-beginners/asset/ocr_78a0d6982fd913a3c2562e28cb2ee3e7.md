# Inspector Pane and Selector Bar

The Inspector pane enables you to change the properties of the controls to make your objects follow your command. The Inspector pane has six tabs across the top. See Figure 10–14.

+   - File Inspector
- Quick Help Inspector
- Identity Inspector
- Attributes Inspector
- Size Inspector
- Connections Inspector
