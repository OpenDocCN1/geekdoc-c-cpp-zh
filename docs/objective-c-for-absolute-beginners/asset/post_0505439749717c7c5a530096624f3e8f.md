## CHAPTER 9: Comparing Numbers

### Revisiting Boolean Logic

In a previous chapter, we introduced Boolean logic. Due to its prevalence, we will revisit this subject in detail. Boolean logic usually comes in the form of if statements. There are some good examples of Boolean questions:

- Is 5 larger than 3?
- Does "now" have more letters?
- Is 6 later than today?

Notice that there are only 2 possible answers: yes and no. if you are asking a question that could have more than 2 answers, it will be worded differently. Each if statement is required to have some relational operator. For example, if 5 is greater than 3, then print a message.

In order to start using these types of questions in programs, you will first need to become familiar with the relational operators available to you in Objective-C. After that, we will look into how different variables can behave with these.

### Using Relational Operators

Objective-C uses 6 relational operators. These are the standard algebraic operators with one real change: in Objective-C language, as in most other programming languages, the equal operator is made by two equal signs (=). In chapter 4, Table 4-7, we describe the different available.

> NOTE: A single sign (=) is used to assign a value to a variable. Two equal signs (==) are needed to compare two values. For example if(x=9) will assign 9 to the variable and return "yes" if 9 is successfully assigned to x, which will be in most, if not in all, the cases. if(x==9) will actually do a comparison to see if x equals 9.
