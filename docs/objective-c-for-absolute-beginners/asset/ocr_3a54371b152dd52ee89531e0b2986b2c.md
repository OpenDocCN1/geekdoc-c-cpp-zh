# Designing and Flowcharting an Example App

We have covered a lot of information about decision making and program flow. It's time to do what programmers do best: write apps!

The app you have assigned to write generates a random number between 0 and 100 Inclusive, and asks the user to guess the number. The user has to do this until the number is guessed. You can use any object from the Alice gallery to ask the user for his her guess, and you can also choose any world for your object to be in. The object will provide a visual queue for each high, low, and correct guess. The number that the user guesses the correct answer, he or she will be asked if he or she wants to play again.
