# Dual Monitors

We recommend developers have a second monitor connected to their computer. It is great to
step through your code and watch your output window and iPad simulator at the same time on
dependent monitors. Apple hardware makes this easy. Just plug your second monitor into
the display port of any Intel-based Mac, with the correct Mini DisplayPort adapter of course, and you have two monitors working independently of one another. See Figure 2. Note that dual monitors are not required. You will just have to organize your open windows to fit on your screen if you do not.

## Thinking like a Developer

Software development involves writing a computer program and having a computer execute that program. A **computer program** is the set of instructions we want the computer to perform. Before writing a computer program, it is helpful to list the steps we want our program to perform, in the order we want them. This step-by-step process is called an **algorithm**.

If we want to write a computer program to toast bread, we would first write an algorithm. This algorithm might look like this:

- 1. Take the bread out of the bag.
- 2. Place the bread in the toaster.
- 3. Press the toast button.
- 4. Wait for the toast to pop up.
- 5. Remove the toast from the toaster.

At first glance, this algorithm seems to solve our problem. However, our algorithm leaves many details and makes many assumptions. For example:

- 1. What kind of toast does the user want? Does the user want white bread, wheat, or some other kind of bread?
- 2. How does the user want the bread toasted? Light or dark?
- 3. What does the user want on the bread after it is toasted: butter, margarine, honey, or strawberry jam?
- 4. Does this algorithm work for all users in their cultures and languages? Some cultures may have another word for toast or not know what toast is.
