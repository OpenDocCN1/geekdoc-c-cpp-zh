In the main window, we can see the warning. In fact, this warning gives us some clue to the problem with the code. The warning states:

> "Property 'myBookStore' requires myBookStore to be defined - use @synthesize, @dynamic or provide a method implementation."

Our code has a @property, but because we commented out, it doesn't have a @synthesize. The compiler considers this warning because the method could be provided dynamically during runtime. In our case, we aren't doing this; we didn't include the @synthesize keyword in the implementation file.

To fix this problem, simply navigate back to the ViewController.m and remove the comments we just added on line 14. To navigate back to the list view, click on the folder icon (or simply click on the back button at the top of the edit window).
