# # Using Base-16 (Hexadecimal) Numbering

The last base is worthy of mentioning, using quite ubiquitously in modern computers, the base-16, or **hexadecimal, numbering** system. In base-2, each digit can have two values, 0 and 1. In base-10, each digit can have ten values, 0–9. In base-16, each digit can have sixteen values, 0–F. Yes, you read that correctly; the last value is F. To represent 16 values in a single column, it became necessary to use letters to represent values. In case of base-16, the numbering goes from 0 through 9 and through F.
