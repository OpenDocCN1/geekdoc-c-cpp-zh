# Modifying the MasterViewController

Our simple application has two controllers, the main view controller, which is called the MasterViewController, and a secondary called the DetailViewController. View controllers are objects that control the behavior of a view. In order for our application to start displaying data from our data model, we need to modify the MasterViewController–this is where the navigation of our application begins. The following code is already in place in the template that Xcode has provided. We're just going to modify it to add in our data model.

First, we'll need to modify the MasterViewController.h. We need to add an instance variable to hold the Bookstore object. Listing 8–18 shows that the instance variable is added as a property on line #17. Also note that there is what called a forward reference on line #12. This doesn't define the Bookstore class, it just tells the compiler that there will be a Bookstore object defined at some point. This prevents line #17 from generating an error because the compiler doesn't know about the Bookstore object.
