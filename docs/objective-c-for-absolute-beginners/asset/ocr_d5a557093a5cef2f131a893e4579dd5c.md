Now we need to find out what value is in the variable. In order to accomplish this, we perform an if statement that compares the result to the three different options for the NSComparisonResult. The first line finds out if the sale date is greater than today's Date means the variable saleStarted to No. The next line finds out whether the sale date is less than today. If it is, then the sale has started and we set the saleStarted variable to Yes. The next line just says. This captures all other options. We know, though, that the only option is NSOrderedSame. This means that the two dates are exactly same, and thus the sale is just beginning.

There are other methods that you can use to compare NSDate objects. Each of these methods will be more efficient at certain tasks. We have chosen the compare method because it will handle most of your basic date needs.

> NOTE: Remember that NSDate holds both a date and a time. This can affect your comparisons with dates as it only compares the date but the time.
