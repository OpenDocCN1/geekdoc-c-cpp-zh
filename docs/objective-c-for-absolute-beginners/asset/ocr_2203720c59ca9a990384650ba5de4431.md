Next, let's move over to the Issue Navigator window, as shown in Figure 14–15,
clicking on the triangle with the exclamation point. This view shows all the errors and
warnings currently in the program—not just the current file, ViewController. but
all files. Errors are displayed as a white exclamation point inside a red octagon. In
case, we have only one error. Also, if the error doesn't fit on the screen or is that
read, simply hover over the error on the Issue Navigator window and the full error will
displayed.
