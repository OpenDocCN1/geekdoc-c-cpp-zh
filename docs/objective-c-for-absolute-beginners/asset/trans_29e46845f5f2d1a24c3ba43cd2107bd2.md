# 方法规划

我们不会添加所有的方法，但你在开始时做的规划越详细，后续的操作就越容易。并不是你所有的类都有很多方法。有些类可能一个方法也没有。

> 注意：在规划方法时，记住让它们专注于某个特定的任务。方法越具体，它就越可能被重用。

目前，我们不会向 `Book` 类或 `Bookstore` 类添加任何方法。我们将关注另外两个类。
