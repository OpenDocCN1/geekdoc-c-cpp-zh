If you haven't seen "/*" used in computer programming before, it enables the programmer to comment about his or her code. Comments are not compiled by our applications and are used as notes for the programmer or, more importantly, for programmers who follow the original developer. Comments help both the original developer and follow-up developers understand how the app was developed.

Sometimes, it is necessary for comments to span several lines or just part of a line. This can be accomplished with the /* and the */. All the text between the /* and the /* are treated as comments and are not compiled.
