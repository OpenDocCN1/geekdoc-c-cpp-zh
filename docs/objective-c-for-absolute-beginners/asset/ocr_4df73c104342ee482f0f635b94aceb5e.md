When Xcode creates a class, it creates a very rudimentary stub of an implementation file. Listing 7–2 starts with the #import statement to your interface file. The #import statement reads in your interface file for the class. As the compiler goes through your implementation (.m) file, it needs to know what class it's implementing, and the interface file provides all the information that it needs.

An #import statement tells the compiler to read in the specified file, because the compiler needs to know about certain predefined things. For example, in your interface file, the RadioStation class is a subclass of NSObject. The NSObject class needs to be defined for the program to compile successfully. All of these objects are part of the iOS Framework and are included via line #1 in the interface file from Listing 7–1.
