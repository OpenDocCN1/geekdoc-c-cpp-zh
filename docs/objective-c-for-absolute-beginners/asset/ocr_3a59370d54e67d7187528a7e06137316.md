# Writing Another Program in Xcode

When you first open Xcode, you'll see the screen shown in Figure 6–1.

![](bbox=[0.137, 0.173, 0.762, 0.513])

Figure 6–1. Xcode opening screen

Figure 6–1 shows a great screen to keep visible at the launch of Xcode. Until you are more comfortable with Xcode, keep the Show this window when Xcode launches check box checked. This window allows you to select the most recently created projects, access the developer documentation (that's the Getting started with Xcode icon), and quickly link to Apple's developer web site. Regardless of which document set is chosen, all have a wealth of information for beginning and advanced users.

# Creating the Project

We are going to start a new project, so click the Create a new Xcode project icon. Whenever you want to start a new iOS or Mac OS Application, library, or anything else, use this icon. Once a project has been started and saved, the project will appear in the Recents list on the right-hand portion of the display.

For this Xcode, we're going to create something very simple. Make sure iOS Application is chosen. Then select Single View Application, as shown in Figure 6–2. Then simply click on the Next button.
