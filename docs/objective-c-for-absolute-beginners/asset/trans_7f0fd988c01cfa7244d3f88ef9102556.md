图 3–5. Objective-C 基础类型

| 类型 | 示例 | 格式化符 |
| :--- | :--- | :--- |
| char | 'a' | %c |
| int | 42 | %d |
| unsigned int | 42 | %u |
| long | 42 | %ld |
| unsigned long | 42 | %lu |
| long long | 42 | %llu |
| float | 3.1 | %f |
| double | 3.1 | %f |
| long double | 3.1 | %Lf |
| id | Nil | %@ |
