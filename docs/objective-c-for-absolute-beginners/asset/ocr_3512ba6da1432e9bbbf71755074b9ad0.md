# Configure the cell.

```
103 // Configure the cell.
104 cell.textLabel.text = [self.myBookStore bookAtIndex:indexPath.row].title;
105 return cell;
106 }
```

Out of all this code, we only need to modify two lines. Everything else can stay the way it is. This is one of the advantages of the Xcode templates. Line #86 we used to simply return 1; we need to change it so that it returns the count of items in our Bookstore store.

Line #104 looks a little more complicated. Basically, each line of the UITableView we are calling is a cell (a UITableViewCell view to be specific). Line #104 sets the text of the cell to the title of a book. Let's look at that code more specifically:

```
[self.myBookStore bookAtIndex:indexPath.row].title;
```

First, self.myBookStore is our Bookstore object, which is pretty clear. We're calling one of its methods called bookAtIndex: The value indexPath specifies which row we're interested in—the indexPath will always be one less than the total count (returned on Line #86). So calling [self.myBookStore bookAtIndex:indexPath.row] returns a Book object. The last part, .title, accesses the title property from the returned Book object. The code below is equivalent to what we just did in one line:

+   1 Book *book;
2 book = [self.myBookStore bookAtIndex:indexPath.row];
3 cell.textLabel.text = book.title;
