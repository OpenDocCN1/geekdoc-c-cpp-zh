# Creating the View

Our random number generator will have three objects in the view: one label and two buttons. One button will generate the seed, another button will generate the random number, and the label shows the random number generated by the app.

+   1. Drag a Label from the Library Pane Controls section to the View window.

+   2. Drag two rounded rect buttons from the Library window to the View Window.

+   3. Click the top button and label it Seed Random Number Generator.

+   4. Click the bottom button and label it Generate Random Number. See Figure 10–15.
