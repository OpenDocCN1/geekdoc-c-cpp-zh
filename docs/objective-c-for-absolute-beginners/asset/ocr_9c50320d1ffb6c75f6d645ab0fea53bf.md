# Implementing the Classes

Now that we understand the objects we are going to be creating, we need to create our first object. In order to do so, we will start with a new project.

+   1. Please launch Xcode. Click on File > New > New Project.

+   2. Select iOS on the left-hand side. On the right-hand side, select Detail Application. For what we are doing in this chapter, we could have selected any of the application types (see Figure 5–9). Click Next.

![](bbox=[0.137, 0.273, 0.762, 0.611])

Figure 5–9. Creating a new project

+   3. You will have to enter a company name. Leave the checkboxes on this screen as they appear by default. We will not be worrying about these items right now. Select a location to save your project and then save your project. You can use the name bookstore or any other project name you want.

+   4. Select the Bookstore folder on the left-hand side of the screen (see Figure 5–10). This is where the majority of your code will reside.

+   5. Select File > New > New File.
