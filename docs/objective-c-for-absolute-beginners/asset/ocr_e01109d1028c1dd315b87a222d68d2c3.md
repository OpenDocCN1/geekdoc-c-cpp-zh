# # Introducing Instance Variables

Our object is simply called Book and is a subclass of NSObject. True, we have an object, but it doesn't store anything at this point. In order for this class to be useful, it needs to be able to hold some information, which done with instance variables. When an object is used, it has to be instantiated. Once the object is instantiated, it has access to its instance variables. These variables are available to the object as long as the object stays in scope. We know from Chapter 7, scope defines the context in which an object exists. In some cases, an object's scope might be the life of the program. In other cases, the scope might be just a function or method. It all depends on where the object is declared and how it will be used. For more later, let's add some instance variables to our Book class to make it more useful.
