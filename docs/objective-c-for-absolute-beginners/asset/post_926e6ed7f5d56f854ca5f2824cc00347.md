In our application, we will need to compare numbers in many ways. For example, let's
say that our bookstore offers a discount for people who spend over $30 in a
transaction. We will need to add the total amount the person is spending and then
compare this to $30. If the amount spent is larger than $30, we will need to
calculate the discount. See the following example.

```
float totalSpent;
int discountThreshold;
int discountPercent;

discountThreshold=30;
discountPercent=0;
totalSpent=calculateTotalSpent();

if(totalSpent>discountThreshold) {
    discountPercent=10;
}
```

Let's walk through the code. First, we declare our variables (totalSpent,
discountThreshold, and discountPercent). As discussed in Chapter 3, if the number
can contain decimals, we declare it as a float rather than an int. We know that we
declare these as ints. In this example, we assume that we have a function called
calculateTotalSpent, which will calculate the total spent in this current order. We
will simply check to see if the total spent is larger than the discount threshold; if
it is, we set the discount percent. Also notice that it was not necessary to tell
the code to convert the data when comparing the different numeric data types. As
we mentioned earlier, this is all handled by Objective-C.

Another action that requires the comparison of numbers is looping. As discussed in
Chapter 4, looping is a core action in development and many type loops require
some sort of comparison to determine when to stop. Let's take a look at a for loop.

```c
int numberOfBooks;
numberOfBooks=50;

for (int y = 1; y <= numberOfBooks; y++) {
    doSomething();
}
```

In this example, we iterate, or loop, through the total number of books that we
have in the bookstore. The statement is where the interesting stuff starts to happen.
We break it down.

```c
int y=1;
```

This portion of the code is declaring y as an int and then assigning it a starting
value of 1.

```c
y <= numberOfBooks;
```

This portion is telling the computer to check if our counting variable y is less than
or equal to the total number of books we have in our store. If y becomes larger than
the number of books, the loop will no longer run.

```c
y++
```

This portion of code increases y by 1 every time the loop is run.

# Creating an Example Xcode App

Now let's create an Xcode application so that we can start comparing numeric
data.

- 1. Launch Xcode. From your hard drive, go to the Applications folder. Drag it to
the Dock, as we will using throughout the rest of this book. See Figure 9-1.
img/322e107ddf5cd963a6efafd38_0.png
Figure 9-1. Launching Xcode

- 2. Click on Create a New Project to open a new window. On the left-hand side
of that window, under iOS, select Application. Then select View Application on the right
side. Click on Next.

> NOTE: Application is the most generic and basic of iOS application types.

- 3. On the next page, enter the name of your application. We used Comparison as the
name, but you can choose any name. This is also the window where you will select
device you would like. We will leave it as universal. See Figure 9-2.
img/322e107ddf5cd963a6efafd38_0.png
Figure 9-2. Creating a new project

- 4. Once the new project is created, you will see the standard Xcode Window. Select
the arrow next to folder to expand it. You will see two files, AppDelegate.m and
AppDelegate.h. The .h file is a header file and we will not be changing anything in
file. The actual names change depending on the name used when creating the project. For
the purpose of these examples, we are only focusing on AppDelegate.m

- 5. Double-click on AppDelegate.m file and you will see the following code:

```objc
#import "AppDelegate.h"
@implementation AppDelegate
@synthesize window=window;

- (BOOL)application:(UIApplication *)application
didFinishLaunching:(NSDictionary *)launchOptions
{
    // Window for customization after launch.
    [self.window makeKeyVisible];
}
```

At this point, our application will just launch and display a window. We are going to
add a little "Hello World" to our application. After the line [self.window makeKeyVisible],
we need to add the following code: NSLog(@"Hello World");

This line creates a new NSString with the contents "Hello World" and passes it to the
NSLog function that is used for debugging. Let's run our application to see how it works.

- 1. Click on the Run button to launch. This will just display a window. Back in Xcode,
a debug window will appear at the bottom of the screen, as shown in Figure 9-4. You

Most of the information in this window will mean very little to you. The most important

was generated by the NSLog log we added before.

- 1. Go back to the application and open the AppDelegate.m file.

- 2. Go to the beginning of the line that begins with NSLog. This is the line that
responsible for printing the "Hello World" section. We are going to comment out this
line by placing two backslashes (//) in front of the line of code. Commenting out code
tells Xcode to ignore it when it builds and runs the application. Code that is commented
out will not run.

- 3. Once you comment out the line of code, you will no longer see the line in bold if
you run the program, because the application is no longer outputting any line.

- 4. In order for the application to output the results of our comparisons, we have to add
one line.

NSLog(@"The result is %@", (6>5 ? @"True" : @"False"));

> NOTE: The above code (6>5 ? @"True" : @"False"); is called a Ternary operation. It is essentially a simplified way of writing an If-Statement.

- 5. Place this line into your code. This line is telling your application to print
out "The result is.". Then it will print "True" if 6 is greater than 5, or
"False" if 5 is greater than 6. Because 6 is greater than 5, it will print out True.

You can change this line to test any of the examples we have put together in this chapter, or any of the examples we will do on.
