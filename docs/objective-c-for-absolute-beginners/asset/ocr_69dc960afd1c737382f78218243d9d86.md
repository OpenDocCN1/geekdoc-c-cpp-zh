# CHAPTER 7: Objective-C Classes, Objects, and Methods

Listing 7–5. The Updated ViewController.h Interface File

```
#import <UIKit/UIKit.h>
@class RadioStation;
@interface ViewController : UIViewController{
    RadioStation *myStation;
    IBOutlet UILabel* stationName;
    IBOutlet UILabel* stationFrequency;
    IBOutlet UILabel* stationBand;
}
@end
```

On Line #3, you'll add what's called a forward declaration. This basically tells the compiler that you'll be using a class that you've not defined yet, called RadioStation. You'll be importing your header file eventually, but not #8—that’s why you need this forward declaration now.

Lines #6–8 define some new instance variables. Line #8 is your RadioStation object. Lines #9–11 are going to be used by your iOS interface to show some values on the screen (more on these later). Also, don't forget to include the curly braces {{ ... }). Since the original AppDelegate didn't have any instance variables declared, there was no need for the braces.
