# Using Interface Builder

The most common way to launch Interface Builder and begin working on our view is to click the XIB file related to the view. See Figure 10-10.

![](bbox=[0.136, 0.16344999999999998, 0.863, 0.49745])

Figure 10-10. Interface Builder opens in the workspace window

When Interface Builder opens, we can see our view displayed in the canvas. We are now able to design our user interface. First we need to understand some of the sub-windows within Interface Builder.

# The Dock

The Document window shows all the objects that our view contains. Some examples of these objects are:

+   * Buttons
* Labels
* Text fields
* Web views
* Map views
* iAd
* Picker views
* Table views
