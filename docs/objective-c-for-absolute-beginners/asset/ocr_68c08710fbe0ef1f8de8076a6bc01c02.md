**Figure 11–9.** Adding the managed objects to your project.

Select the storage location and add it to your project. You should not need to change any of the defaults on this page. Then click Create. You will notice that four files have been added to your project. Book.h and Author.h contain the header information about your book, and Book.m and Author.m contain the actual implementation. These files are fairly simple, as Core Data will do the work for them. You should also notice that, if you go back to your model and click on Book, it will have a new class. Instead of an NSManagedObject, it will have a Book class.

Let's look at the contents of some of Author.h:

```
#import <Foundation/Foundation.h>
#import <CoreData/CoreData.h>
```
