4. Notice that the type is UITextView instead of UILabel—this is very important. Also, don't forget to add the descriptionTextView to the @synthesize statement in the DetailViewController.m file, as shown below:

@synthesize titleLabel, authorLabel, descriptionTextView;

5. Next, right-click on the Text View of the DetailViewController.xib connect it to the descriptionTextView output. The process is the same as shown in Figure 8–10, 8–11, and 8–12, except that we're connected to the descriptionTextView output.

> CAUTION: As mentioned above, it's important to make the descriptionTextView property a UITextView type. If, for example, it accidentally made a UILabel object, when trying to connect the Text View from the screen to the output, Xcode won't be able to find the descriptionTextView output. Why? Because Xcode knows the control is a UITextView and is looking for an output that is type UITextView.
