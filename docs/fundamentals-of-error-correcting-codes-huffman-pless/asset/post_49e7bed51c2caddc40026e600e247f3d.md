$$\sum_{u \in v+C} wt(u) = \frac{nM}{2}$$

or equivalently,

$$\sum_{i=0}^n i A_i(v) = \frac{nM}{2}.$$ (11.2)

where $\{A_i(v) \mid 0 \le i \le n\}$ is the weight distribution of $\mathbf{v} + \mathcal{C}$. Equation (11.2) implies that the average distance between $\mathbf{v}$ and the codewords of $\mathcal{C}$ is $n/2$. Therefore the distance between $\mathbf{v}$ and some codeword $c \in \mathcal{C}$ is at most $n/2$. By Theorem 11.1.2(i) we have part (i).

Now assume that $\mathcal{C}$, and hence $\mathbf{v} + \mathcal{C}$, has strength 2. In each row of $M_t$ corresponding to the vector $\mathbf{u} \in \mathbf{v} + \mathcal{C}$, there are $\binom{n}{2}$ ordered pairs of bits. Each block of $\binom{n}{2}$ pairs of distinct columns of $M_t$ contains the binary 2-tuple $(1, 1)$ exactly $M/4$ times. Therefore

$$\sum_{u \in v+C} \binom{wt(u)}{2} = \sum_{u \in v+C} \frac{wt(u)(wt(u)-1)}{2} = \binom{n}{2} \frac{M}{4} = \frac{n}{2} \frac{n-1}{2} \frac{M}{4}.$$

Using (11.2) we obtain

$$\sum_{i=0}^n i^2 A_i(v) = \frac{n(n+1)M}{4}.$$ (11.3)

Combining (11.2) and (11.3) produces

$$\sum_{i=0}^n (2i-n)^2 A_i(v) = nM.$$ (11.4)

This implies that there is an $i$ with $A_i(v) \neq 0$ such that $(2i-n)^2 \ge n$. Taking the square root of both sides of this inequality shows that either $i \le \frac{n-\sqrt{n}}{2}$ or $i \ge \frac{n+\sqrt{n}}{2}$.

Suppose now that $\mathcal{C}$ is self-complementary. By Exercise 629, $\mathbf{v} + \mathcal{C}$ is also self-complementary. Then there is an $i$ satisfying the first of the above two inequalities with $A_i(v) \neq 0$. Thus there is a vector $\mathbf{u} \in \mathbf{v} + \mathcal{C}$ with $wt(u) \le (n-\sqrt{n})/2$. Hence (ii) holds.

In the case of binary linear codes, the Norre Bounds can be restated as follows.

### Corollary 11.2.2 Let $\mathcal{C}$ be a binary linear code of length $n$.

- (i) If $C^\perp$ has minimum distance at least 2, then $\rho(C) \le \lfloor n/2 \rfloor$.
- (ii) If $C^\perp$ has minimum distance at least 4 and the all-one vector $\mathbf{1}$ is in $C$, then $\rho(C) \le \lfloor (n-\sqrt{n})/2 \rfloor$.

We are now ready to examine the covering radius of the Reed–Muller codes $\mathcal{R}(r, m)$ first defined in Section 1.10. Let $\rho_{RM}(r, m)$ denote the covering radius of $\mathcal{R}(r, m)$. Using Exercise 617, $\rho_{RM}(0, m) = 2^{m-1}$ as $\mathcal{R}(0, m)$ is the binary repetition code. Also $\rho_{RM}(m, m) = 0$ as $\mathcal{R}(m, m) = \mathbb{F}_2^n$. We consider the case $1 \le r < m$. By Theorem 1.10.1, $\mathcal{R}(r, m)^\perp = \mathcal{R}(m - r - 1, m)$ has minimum weight $2^{r+1} \ge 4$, therefore $\mathcal{R}(r, m)$ has strength 2 by Exercise 628. In addition $\mathcal{R}(r, m)$ is self-complementary as $\mathbf{1} \in \mathcal{R}(0, m) \subset \mathcal{R}(r, m)$ also by Theorem 1.10.1. Therefore by the Norre Bound (ii) we have the following theorem.

### Theorem 11.2.3 Let $1 \le r < m$. Then $\rho_{RM}(r, m) \le 2^{m-1} - 2^{m-r/2-1}$. In particular, $\rho_{RM}(1, m) \le 2^{m-1} - 2^{m/2-1/2}$.

Notice that by Exercise 618 and the nesting properties of the Reed–Muller codes, any upper bound on $\rho_{RM}(1, m)$ is automatically an upper bound on $\rho_{RM}(r, m)$ for $1 < r$.

We now find a recurrence relation for the covering radius of first order Reed–Muller codes that, combined with Theorem 11.2.3, will allow us to get an exact value for $\rho_{RM}(1, m)$ when $m$ is even.

### Lemma 11.2.4 For $m \ge 2$,

\(\rho_{RM}(1, m) \ge 2\rho_{RM}(1, m - 2) + 2^{m-2}\).

**Proof:** For a vector $\mathbf{x} \in \mathbb{F}_2^n$, let $\bar{\mathbf{x}} = \mathbf{1} + \mathbf{x}$ denote the complement of $\mathbf{x}$. From Exercise 632, every codeword in $\mathcal{R}(1, m)$ has one of the following forms:

- (a) \((\mathbf{x}|\mathbf{x}|\mathbf{x}|\mathbf{x})\),
- (b) \((\mathbf{x}|\bar{\mathbf{x}}|\mathbf{x}|\bar{\mathbf{x}})\),
- (c) \((\mathbf{x}|\bar{\mathbf{x}}|\bar{\mathbf{x}}|\mathbf{x})\), or
- (d) \((\mathbf{x}|\mathbf{x}|\bar{\mathbf{x}}|\bar{\mathbf{x}})\),

where $\mathbf{x} \in \mathcal{R}(1, m - 2)$. Choose a vector $\mathbf{v} \in \mathbb{F}_2^{2^{m-2}}$ such that the coset $\mathbf{v} + \mathcal{R}(1, m - 2)$ has weight equaling $\rho_{RM}(1, m - 2)$. Therefore,

\(\text{d}(\mathbf{v}, \mathbf{x}) \ge \rho_{RM}(1, m - 2)\) (11.5)

for all $\mathbf{x} \in \mathcal{R}(1, m - 2)$. Notice that

\(\text{d}(\mathbf{v}, \bar{\mathbf{x}}) = \text{d}(\bar{\mathbf{v}}, \mathbf{x}) = 2^{m-2} - \text{d}(\mathbf{v}, \mathbf{x}) = 2^{m-2} - \text{d}(\bar{\mathbf{v}}, \bar{\mathbf{x}})\) (11.6)

We prove the lemma if we find a vector $\mathbf{y}$ in $\mathbb{F}_2^{2^{m-2}}$ which has distance at least $2\rho_{RM}(1, m - 2) + 2^{m-2}$ from all codewords $\mathbf{c} \in \mathcal{R}(1, m)$. Let $\mathbf{y} = (\mathbf{v}|\mathbf{v}|\bar{\mathbf{v}}|\bar{\mathbf{v}})$. We examine each possibility (a) through (d) above for $\mathbf{c}$. For the corresponding case, using (11.5), (11.6), and the fact that $\bar{\mathbf{x}} \in \mathcal{R}(1, m - 2)$ if $\mathbf{x} \in \mathcal{R}(1, m - 2)$, we have:

- (a) \(\text{d}(\mathbf{y}, \mathbf{c}) = 3\text{d}(\mathbf{v}, \mathbf{x}) + \text{d}(\bar{\mathbf{v}}, \mathbf{x}) = 2^{m-2} + 2\text{d}(\mathbf{v}, \mathbf{x}) \ge 2^{m-2} + 2\rho_{RM}(1, m - 2)\),
- (b) \(\text{d}(\mathbf{y}, \mathbf{c}) = \text{d}(\mathbf{v}, \mathbf{x}) + 2\text{d}(\bar{\mathbf{v}}, \mathbf{x}) + \text{d}(\bar{\mathbf{v}}, \bar{\mathbf{x}}) = \text{d}(\mathbf{v}, \mathbf{x}) + 3\text{d}(\bar{\mathbf{v}}, \bar{\mathbf{x}}) = 2^{m-2} + 2\text{d}(\bar{\mathbf{v}}, \bar{\mathbf{x}}) \ge 2^{m-2} + 2\rho_{RM}(1, m - 2)\),
- (c) \(\text{d}(\mathbf{y}, \mathbf{c}) = 2\rho_{RM}(1, m - 2) + 2^{m-2}\), and
- (d) \(\text{d}(\mathbf{y}, \mathbf{c}) = 2\text{d}(\mathbf{v}, \mathbf{x}) + 2^{m-2} \ge 2\rho_{RM}(1, m-2) + 2^{m-2}\).

The result follows.

### Theorem 11.2.5 For $m$ even, $\rho_{RM}(1, m) = 2^{m-1} - 2^{(m-2)/2}$.

When $m$ is odd, the inequality in Exercise 633(b) is an equality for the first four values of $m$. By Exercise 633(a), $\rho_{RM}(1, 1) = 0$. As $\mathcal{R}(1, 3)$ is the $[8, 4, 4]$ extended Hamming code, $\rho_{RM}(1, 3) = 2$ by Theorem 11.1.7. It is not difficult to show that $\rho_{RM}(1, 5) = 12$; one theoretical proof is given as a consequence of Lemma 9.4 in [34], or a computer package that calculates covering radius could also verify this. Mykkeltveit [242] showed that $\rho_{RM}(1, 7) = 56$. From these four cases one would conjecture that the lower bound in Exercise 633(b) for $m$ odd is an equality. This, however, is false; when $m = 15$, the covering radius of $\mathcal{R}(1, 15)$ is at least $16276 = 2^{14} - 2^7 + 20$ [250, 251].
