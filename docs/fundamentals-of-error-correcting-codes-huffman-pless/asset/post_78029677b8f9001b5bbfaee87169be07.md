
## 9.4 The Balance Principle and the shadow

We construct a new code \( C'' \) of length \( n+2 \) by adjoining two components to \( C_0 \) where

\( C'' = \{c00 \mid c \in C_0\} \cup \{c11 \mid c \in C_2\} \cup \{c10 \mid c \in C_1\} \cup \{c01 \mid c \in C_3\} \). (9.6)

Clearly, \( C'' \) is an \( (n+2, (n/2)+1) \) code. By Exercise 517, \( C'' \) is self-dual.

Consider first the case \( n \equiv 2 \pmod 8 \). Let \( c_1 \in C_1 \). Then \( c_1 + c_3 \in C_2 \) by Exercise 9.4.4 implying that \( \text{wt}(c_1 + c_3) \equiv 2 \pmod 4 \). But \( \text{wt}(c_1 + c_3) = \text{wt}(c_1) + \text{wt}(c_3) - 2\text{wt}(c_1 \cap c_3) \equiv \text{wt}(c_1) + \text{wt}(c_3) \pmod 4 \) as \( c_1 \perp c_3 \). Since both \( \text{wt}(c_1) \) and \( \text{wt}(c_3) \) are odd, \( \text{wt}(c_1) \equiv \text{wt}(c_3) \pmod 4 \). As \( C'' \) cannot be Type II since \( n+2 \equiv 4 \pmod 8 \), \( \text{wt}(c_1) = \text{wt}(c_3) \equiv 1 \pmod 4 \), proving (iii) in this case.

Now suppose \( n \equiv 6 \pmod 8 \). Let \( D = \{c00 \mid c \in C_0\} \cup \{c11 \mid c \in C_2\} \), which is doubly even. Clearly, if \( D' = D \cup (D + d) \) where \( d = 00 \cdots 011 \), \( D' \) is a Type I code. Also as the all-one vector of length \( n \) is in \( C_2 \), the all-one vector of length \( n+2 \) is in \( D \). By Exercise 526, \( D \) is contained in only one Type I and two Type II codes of length \( n+2 \), implying that \( C'' \) must be Type II. Hence if \( c \in C_1 \cup C_3 \), then \( \text{wt}(c) \equiv 3 \equiv n/2 \pmod 4 \), proving (iii) in this case also.

The upper bound on the minimum distance of Type I codes given in Theorem 9.3.1(i) was first improved in [58]; this bound was later improved to the current bound given in Theorem 9.3.5; in proving the intermediate bound, the weight enumerator of the shadow was considered. If the weight enumerator of the shadow had either negative or fractional coefficients, the original code could not exist. Using this idea, Conway and Sloane in [58] have given possible weight enumerators of Type I codes of lengths through 64 with the highest possible minimum weight. A number of researchers have found Type I codes with a weight enumerator given as a possibility in [58].

If \( C \) is an \([n, n/2, d]\) self-dual code with \( d > 2 \), pick two coordinate positions and consider the \( (n/2 - 1)\)-dimensional subcode \( C' \) of \( C \) with either two 0s or two 1s in these positions. (The requirement \( d > 2 \) guarantees that \( C' \) is \( (n/2) - 1\)-dimensional.) If we puncture \( C' \) on these positions, we obtain a self-dual code \( C'' \) of length \( n-2 \), \( C'' \) is called a child of \( \mathcal{C} \) and \( \mathcal{C} \) is called a parent\(^3\) of \( C'' \). This process reverses the construction of (9.6).

If \( n \equiv 0 \pmod 8 \) and \( \mathcal{C} \) is a Type II code of length \( n \), it is also possible to define children of \( \mathcal{C} \) of lengths \( n-4 \) and \( n-6 \) that are Type I codes. It can be shown [53, 264] that any Type I code of length \( n \not\equiv 0 \pmod 8 \) is a child of a Type II code of the next larger length equivalent to \( 0 \) modulo 8. This approach was used to classify all self-dual codes of lengths 26, 28, and 30 once all Type II codes of length 32 had been classified. See [53, 56, 264].

We can determine the weight enumerator of a parent from that of a child.

\[

## 9.5 Counting self-orthogonal codes

As we will see in Section 9.7, the classification of self-dual codes of a fixed length \( n \) over \(\mathbb{F}_2, \mathbb{F}_3, \text{or } \mathbb{F}_4\) depends on knowledge of the number of such codes. We begin with the binary case, where we will count the number of self-dual codes and the number of Type II codes. We first determine the total number of self-dual codes.

### Theorem 9.5.1 ([259, 260]) The number of self-dual binary codes of length \( n \) is
\(\prod_{r=1}^{k-1} (2^r + 1).\)

**Proof:** A self-dual binary code must contain the all-one vector \(\mathbf{1}\). Let \(\sigma_{n,k}\) denote the number of \([n, k]\) self-orthogonal binary codes containing \(\mathbf{1}\). We note first that \(\sigma_{n,1} = 1\). We now find a recurrence relation for \(\sigma_{n,k}\). We illustrate this recursion process by computing \(\sigma_{n,2}\). There are \(2^{n-1} - 2\) even weight vectors that are neither \(\mathbf{0}\) nor \(\mathbf{1}\). Each of these vectors is in a unique \([n, 2]\) self-orthogonal code containing \(\mathbf{1}\); each such code contains two of these vectors. So \(\sigma_{n,2} = 2^{n-2} - 1\).
Every \([n, k+1]\) self-orthogonal code containing \(\mathbf{1}\) contains an \([n, k]\) self-orthogonal code also containing \(\mathbf{1}\). Beginning with an \([n, k]\) self-orthogonal code \(\mathcal{C}\) containing \(\mathbf{1}\), the only way to find an \([n, k+1]\) self-orthogonal code \(\mathcal{C}'\) containing \(\mathcal{C}\) is by adjoining a vector \(\mathbf{c}'\) from one of the \(2^{n-k} - 1\) cosets of \(\mathcal{C}\) in \(\mathcal{C}^\perp\) that is unequal to \(\mathcal{C}\). Thus \(\mathcal{C}\) can be extended to \(2^{n-k} - 1\) different \([n, k+1]\) self-orthogonal codes \(\mathcal{C}'\). However, every such \(\mathcal{C}'\) has \(2^k - 1\) subcodes of dimension \(k\) containing \(\mathbf{1}\) by Exercise 522(a). This shows that \(\sigma_{n,k+1} = \frac{2^{n-2k} - 1}{2^k - 1} \sigma_{n,k}\).
Note that using this recurrence relation, we obtain \(\sigma_{n,2} = 2^{n-2} - 1\) as earlier. Using this recurrence relation, the number of self-dual binary codes of length \(n\) is
\(\sigma_{n,n/2} = \frac{2^2-1}{2^1-1} \cdot \frac{2^4-1}{2^2-1} \cdot \frac{2^6-1}{2^3-1} \cdots \frac{2^n-1}{2^{n/2}-1} \cdot \sigma_{n,1}\)
\(= \frac{2^2-1}{2^1-1} \frac{2^4-1}{2^2-1} \frac{2^6-1}{2^3-1} \cdots \frac{2^{n-2}-1}{2^{n/2-1}-1}\)
\(= (2^1+1)(2^2+1)(2^3+1) \cdots (2^{n/2-1}+1),\)
which is the desired result.
