We conclude this section by presenting the automorphism groups of the binary extended odd-like quadratic residue codes. For a proof, see [149]; we discuss (i) in Example 9.6.2 and (ii) in Section 10.1.2.

**Theorem 6.6.27** Let $p$ be a prime such that $p \equiv \pm 1 \pmod 8$. Let $\mathcal{D}$ be a binary odd-like quadratic residue code of length $p$ with extended code $\widehat{\mathcal{D}}$ of length $p + 1$. The following hold:

+   (i) When $p = 7$, $\Gamma \text{Aut}(\widehat{\mathcal{D}}) = \text{PAut}(\widehat{\mathcal{D}})$ is isomorphic to the affine group $\text{GA}_2(2)$ of order 1344.
+   
+   (ii) When $p = 23$, $\Gamma \text{Aut}(\widehat{\mathcal{D}}) = \text{PAut}(\widehat{\mathcal{D}})$ is isomorphic to the Mathieu group $\mathcal{M}_{23}$ of order 244 823 040.
+   
+   (iii) If $p \notin \{7, 23\}$, then $\Gamma \text{Aut}(\widehat{\mathcal{D}}) = \text{PAut}(\widehat{\mathcal{D}})$ is isomorphic to the group $\text{PSL}_2(p)$ of order $p(p^2 - 1)/2$.
