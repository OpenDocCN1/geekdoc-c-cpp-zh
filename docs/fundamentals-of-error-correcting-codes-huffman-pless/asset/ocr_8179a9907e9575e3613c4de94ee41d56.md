Before proceeding to the other bounds, we observe that the covering radius of a code $\mathcal{C}$ with $A_q(n, d)$ codewords is at most $d-1$. For if a code $\mathcal{C}$ with $A_q(n, d)$ codewords has covering radius $d$ or higher, there is a vector $\mathbf{x}$ in $\mathbb{F}_q^n$ at distance $d$ or more from every codeword of $\mathcal{C}$; hence $\mathcal{C} \cup \{\mathbf{x}\}$ has one more codeword and minimum distance at least $d$. The same observation holds for linear codes with $B_q(n, d)$ codewords; such codes have covering radius $d-1$ or less, a fact left to the exercises. For future reference, we state these in the following theorem.

**Theorem 2.1.7** Let $\mathcal{C}$ be either a code over $\mathbb{F}_q$ with $A_q(n, d)$ codewords or a linear code over $\mathbb{F}_q$ with $B_q(n, d)$ codewords. Then $\mathcal{C}$ has covering radius $d-1$ or less.

**Exercise 95** Prove that if $\mathcal{C}$ is a linear code over $\mathbb{F}_q$ with $B_q(n, d)$ codewords, then $\mathcal{C}$ has covering radius at most $d-1$.

There are two types of bounds that we consider in this chapter. Until Section 2.10 the bounds we consider in the chapter are valid for arbitrary values of $n$ and $d$. Most of these have asymptotic versions which hold for families of codes having lengths that go to infinity. These asymptotic bounds are considered in Section 2.10.

There is a common technique used in many of the proofs of the upper bounds that we examine. A code will be chosen and its codewords will become the rows of a matrix. There will be some expression, related to the bound we are seeking, which must itself be bounded. We will often look at the number of times a particular entry occurs in a particular column
