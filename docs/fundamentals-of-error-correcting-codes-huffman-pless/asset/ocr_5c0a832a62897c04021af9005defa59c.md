Example 13.4.4 We show that the narrow-sense and the extended narrow-sense Reed-Solomon codes are in fact algebraic geometry codes. Consider the projective plane curve X over F_q given by z = 0. The points on the curve are (x : y : 0), which essentially forms the projective line. Let P_\infty = (1 : 0 : 0). There are q remaining F_q-rational points on the line. Let P_0 be the F_q-rational point represented by (0 : 1 : 0). Let P_1, ..., P_{q-1} be the remaining F_q-rational points. For the narrow-sense Reed-Solomon codes we will let n = q - 1 and P = {P_1, ..., P_{q-1}}. For the extended narrow-sense Reed-Solomon codes we will let n = q and P = {P_0, ..., P_{q-1}}. Fix k with 1 <= k <= n and let D = (k - 1)P_\infty; note that D = 0 when k = 1. Clearly, P \cap supp(D) = \emptyset, X is nonsingular of genus g = 0 by Plücker's Formula, and deg(D) = k - 1. In particular, deg(D) > 2g - 2 and, by the Riemann-Roch Theorem, dim L(D) = deg(D) + 1 - g = k.

We claim that

B = \left\{ 1, \frac{x}{y}, \frac{x^2}{y^2}, \dots, \frac{x^{k-1}}{y^{k-1}} \right\}

is a basis of L(D). First, div(x^i / y^i) = j P_0 - j P_\infty. Thus div(x^i / y^i) + D = j P_0 + (k - 1 - j) P_\infty, which is effective provided 0 <= j <= k - 1. Hence, every function in B is in L(D). We only need to show that B is independent over F_q. Suppose that

f = \sum_{j=0}^{k-1} a_j \frac{x^j}{y^j} \approx 0.

Then f = g/h, where g(x, y, z) = \sum_{j=0}^{k-1} a_j x^j y^{k-1-j} and h(x, y, z) = y^{k-1}. By definition of \approx, g(x, y, z) is a polynomial multiple of z. Clearly, this polynomial multiple must be 0 as z does not occur in g(x, y, z), which shows that a_j = 0 for 0 <= j <= k - 1. Thus B is a basis of L(D).
