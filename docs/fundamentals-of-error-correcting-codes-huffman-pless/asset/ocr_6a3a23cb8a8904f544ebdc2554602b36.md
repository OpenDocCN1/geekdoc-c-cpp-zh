Proof: As $\mathcal{C}$ is perfect, the spheres of radius 3 centered at codewords are disjoint and cover $\mathbb{F}_2^{23}$. In this proof, let $N(w, c)$ denote the number of vectors in $\mathbb{F}_2^{23}$ of weight $w$ in a sphere of radius 3 centered at a codeword $c$; note that $N(w, c)$ is independent of the codeword chosen. Note also that $N(w, c) = 0$ when $w$ and $c$ differ by more than 3. Since the spheres of radius 3 pack $\mathbb{F}_2^{23}$ disjointly, we have

\(\sum_{c=0}^{23} N(w, c) A_c = \binom{23}{w}.\) (10.2)

as every vector in $\mathbb{F}_2^{23}$ of weight $w$ is in exactly one sphere of radius 3 centered at a codeword. The verification of the weight distribution merely exploits (10.2) repeatedly.

Clearly, $A_0 = 1$ and $A_i = 0$ for $1 \le i \le 6$. We now compute $A_7, A_8, \dots, A_{23}$ in order. The strategy when computing $A_i$ is to count the number of vectors in $\mathbb{F}_2^{23}$ of weight $w = i - 3$ that are in spheres of radius 3 centered at codewords and then use (10.2).

Computation of $A_7$: Any vector $\mathbf{x} \in \mathbb{F}_2^{23}$ with wt$(\mathbf{x}) = 4$ must be in a unique sphere centered at some codeword $\mathbf{c}$ with wt$(\mathbf{c}) = 7$. Clearly, supp$(\mathbf{x}) \subset$ supp$(\mathbf{c})$ showing that $N(4, 7) = \binom{7}{4}$. Hence, (10.2) becomes $N(4, 7) A_7 = \binom{23}{4} = 8855$ implying $A_7 = 253$.

Computation of $A_8$: Any vector $\mathbf{x} \in \mathbb{F}_2^{23}$ with wt$(\mathbf{x}) = 5$ must be in a unique sphere centered at some codeword $\mathbf{c}$ with wt$(\mathbf{c}) = 7$ or $8$. In either case, supp$(\mathbf{x}) \subset$ supp$(\mathbf{c})$, showing that $N(5, 7) = \binom{7}{5}$ and $N(5, 8) = \binom{8}{5}$. Equation (10.2) becomes $N(5, 7) A_7 + N(5, 8) A_8 = \binom{7}{5} A_7 + \binom{8}{5} A_8 = \binom{23}{5}$ yielding $A_8 = 506$.

Computation of $A_9$: Any vector $\mathbf{x} \in \mathbb{F}_2^{23}$ with wt$(\mathbf{x}) = 6$ must be in a unique sphere centered at some codeword $\mathbf{c}$ with wt$(\mathbf{c}) = 7, 8, \text{or } 9$. If wt$(\mathbf{c}) = 7$, supp$(\mathbf{x}) \subset$ supp$(\mathbf{c})$ or supp$(\mathbf{x})$ overlaps supp$(\mathbf{c})$ in five coordinates. Thus $N(6, 7) = \binom{7}{6} + \binom{7}{1} \binom{16}{1} = 343$. If wt$(\mathbf{c}) = 8$ or $9$, supp$(\mathbf{x}) \subset$ supp$(\mathbf{c})$. Hence, $N(6, 8) = \binom{8}{6} = 28$ and $N(6, 9) = \binom{9}{6} = 84$. Equation (10.2) is $N(6, 7) A_7 + N(6, 8) A_8 + N(6, 9) A_9 = 343 \cdot 253 + 28 \cdot 506 + 84 A_9 = \binom{23}{6}$. Thus $A_9 = 0$.

The remaining values of $A_i$ can be computed in a similar way. We only give the equations that arise when $10 \le i \le 12$, and leave their derivation and solution as exercises.

Computation of $A_{10}$: $(1 + \binom{10}{1} \binom{13}{1}) A_7 + (\binom{10}{2} + \binom{10}{1} \binom{13}{1}) A_8 + \binom{10}{3} A_{10} = \binom{23}{7}$.
Computation of $A_{11}$: $(\binom{11}{1} + \binom{11}{1} \binom{12}{1}) A_7 + (1 + \binom{11}{1} \binom{12}{1}) A_8 + \binom{11}{3} A_{11} = \binom{23}{8}$.
Computation of $A_{12}$: $(\binom{12}{1} A_7 + (\binom{12}{1} + \binom{12}{1} \binom{11}{1}) A_8 + \binom{12}{3} A_{11} + \binom{12}{4} A_{12} = \binom{23}{9}$.

The reader is invited to complete the proof. $\square$

We remark that we do not actually have to calculate the weight distribution of $\mathcal{C}$; examining the proof, we see that each $A_i$ is unique. Since we know that the $(23, 12, 7)$ binary Golay code $\mathcal{G}_{23}$ exists, $\mathcal{C}$ must have the same weight distribution as $\mathcal{G}_{23}$, which was presented in Exercise 403.
