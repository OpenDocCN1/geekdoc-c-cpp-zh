These blocks fall into two categories: those that contain \( q_1 \) and those that do not. The number containing \( q_1 \) is \( \lambda_2^0 \), hence the number not containing \( q_1 \) is \( \lambda_1^0 - \lambda_2^0 \). Using the recurrence relation (8.1), we can determine all \( \lambda_i^t \) with \( i + j \le t \) from the \( \lambda_i^0 \) with \( 0 \le i \le t \). For example,

\(\lambda_2^0 = \lambda_1^0 - \lambda_1^1 = \lambda_0^0 - \lambda_1^0 - (\lambda_0^0 - \lambda_2^0) = \lambda_0^0 - 2\lambda_1^0 + \lambda_2^0 = \lambda_0 - 2\lambda_1 + \lambda_2.\)

Since the value for \( \lambda_0^0 \) given in (8.2) agrees with the value for \( \lambda_i = \lambda_i^0 \) given in Theorem 8.1.3, and since the values of \( \lambda_i^t \) given in (8.2) satisfy the recurrence relation (8.1), as Exercise 439 shows, the theorem follows.
