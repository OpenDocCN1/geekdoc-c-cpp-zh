We now briefly discuss how codes, such as Reed-Solomon codes, can be used to correct burst errors. Let C be an [n, k] code over $F_q$. A b-burst is a vector in $F_q^n$ whose nonzero coordinates are confined to k consecutive positions, the first and last of which are nonzero. The code C is b-burst-error correcting provided there do not exist distinct codewords c1 and c2, and a b'-burst u1 and a b''-burst u2 with b' <= b and b'' <= b such that c1 + u1 = c2 + u2. If C is a linear, b-burst error-correcting code then no b-burst is a codeword for any b with 1 <= b' <= 2b.

Now let Q = 2^m, and let B be an [N, K, D] code over $F_q$. (A good choice for B is a Reed-Solomon code or a shortened Reed-Solomon code as such code will be MDS, hence maximizing D given N and K. See Exercise 317.) Let A be the [m, n, 1] binary code $F_2^m$. Choosing a basis e1, e2, ..., em of $F_q = F_2^m$ over $F_2$, we define $\psi : F_q \to A$ by $\psi(a_1 + \dots + a_m e_m) = a_1 \dots a_m$. The map $\psi$ is one-to-one and $F_2$-linear; see Exercise 319. If we refer to elements of $F_q$ as bytes and elements of $F_2$ as bits, each component byte of a codeword in B is replaced by the associated vector from $F_2^m$ of m bits to form the corresponding codeword in C. The concatenated code C with inner code A and outer code B is an [n, k, d] binary code with n = mN, k = mK, and d >= D. This process is illustrated by the concatenated code constructed in Example 5.5.2. There the basis of $F_4$ is e1 = 1 and e2 = omega, and the bytes (elements of $F_4$) each correspond to two bits determined by the map $\psi$.

**Exercise 319** Let A be the [m, m, 1] binary code $F_2^m$. Let e1, e2, ..., em be a basis of $F_2^m$ over $F_2$. Define $\psi : F_2^m \to A$ by $\psi(a_1 e_1 + \dots + a_m e_m) = a_1 \dots a_m$. Prove that $\psi$ is one-to-one and $F_2$-linear.

Let C be the binary concatenated [mN, mk] code, as above, with inner code A and outer code B. Let c = $\psi(b)$ be a codeword in C where b is a codeword in B. Let u be a b-burst in $F_2^{mN}$. We can break the burst into N strings of m bits each and use $\psi^{-1}$ to map the input into a vector of N bytes. More formally, let u = u1 ... uN, where ui in $F_2^m$ for 1 <= i <= N. Map u into the vector u' = $\psi^{-1}(u_1) \dots \psi^{-1}(u_N)$ in $F_q^N$. As u is a b-burst, then the number of nonzero bytes of u' is, roughly speaking, at most b/m. For instance, if u is a (3m + 1)-burst, then at most four of the bytes of u' can be nonzero; see Exercise 320. So burst error-correction is accomplished as follows. Break a received codeword into N bit strings of length m, apply $\psi^{-1}$ to each bit string to produce a vector in $F_q^N$, and correct that vector using B. More on this is left to Exercise 320.
