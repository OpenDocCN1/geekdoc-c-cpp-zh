1-dimensional code GRS\(_{n-1}\)(\(\gamma\), \(\mathbf{v}\))^\(\perp\) and satisfies

```
\sum_{i=0}^{n-1} w_i v_i h(\gamma_i) = 0 \qquad (5.3)
```

for any polynomial \(h \in \mathcal{P}_{n-1}\).

Proof: Let \(\mathcal{C} = GRS_k(\gamma, \mathbf{v})\). We first consider the case \(k = n - 1\). Since the dual of an MDS code is also MDS by Theorem 2.4.3, \(\mathcal{C}^\perp\) is an \([n, 1, n]\) code with a basis vector \(\mathbf{w} = (w_0, w_1, \dots, w_{n-1})\) having no zero components. But the code \(GRS_k(\gamma, \mathbf{v})\) is precisely all multiples of \(\mathbf{w}\), implying that \(\mathcal{C}^\perp = GRS(\gamma, \mathbf{w})\), verifying the result when \(k = n - 1\). This also shows that if \(h\) is any polynomial in \(\mathcal{P}_{n-1}\), then (5.3) holds because \((v_0 h(\gamma_0), \dots, v_{n-1} h(\gamma_{n-1})) \in GRS_{n-1}(\gamma, \mathbf{v}) = GRS(\gamma, \mathbf{w})^\perp\). Now let \(0 \le k \le n - 1\). When \(f \in \mathcal{P}_k\) and \(g \in \mathcal{P}_{n-k-1} h = fg \in \mathcal{P}_{n-1}\). Thus, by (5.3), \(\sum_{i=0}^{n-1} w_i g(\gamma_i) v_i f(\gamma_i) = \sum_{i=0}^{n-1} v_i w_i h(\gamma_i) = 0\). Therefore \(GRS_k(\gamma, \mathbf{v})^\perp \subseteq GRS_{n-k}(\gamma, \mathbf{w})\). Since the dimension of \(GRS_k(\gamma, \mathbf{v})^\perp\) is \(n - k\), the theorem follows. \(\square\)


By Theorem 5.3.3, a parity check matrix of \(GRS_k(\gamma, \mathbf{v})\) is the generator matrix of \(GRS_{n-k}(\gamma, \mathbf{w})\), where \(\mathbf{w}\) is given in Theorem 5.3.3. Therefore a parity check matrix for \(GRS_k(\gamma, \mathbf{v})\) is
