# 9.5 Counting self-orthogonal codes

As we will see in Section 9.7, the classification of self-dual codes of a fixed length \( n \) over \(\mathbb{F}_2, \mathbb{F}_3, \text{or } \mathbb{F}_4\) depends on knowledge of the number of such codes. We begin with the binary case, where we will count the number of self-dual codes and the number of Type II codes. We first determine the total number of self-dual codes.

**Theorem 9.5.1** ([259, 260]) _The number of self-dual binary codes of length_ \( n \) _is_
\(\prod_{r=1}^{k-1} (2^r + 1).\)

**Proof:** A self-dual binary code must contain the all-one vector \(\mathbf{1}\). Let \(\sigma_{n,k}\) denote the number of \([n, k]\) self-orthogonal binary codes containing \(\mathbf{1}\). We note first that \(\sigma_{n,1} = 1\). We now find a recurrence relation for \(\sigma_{n,k}\). We illustrate this recursion process by computing \(\sigma_{n,2}\). There are \(2^{n-1} - 2\) even weight vectors that are neither \(\mathbf{0}\) nor \(\mathbf{1}\). Each of these vectors is in a unique \([n, 2]\) self-orthogonal code containing \(\mathbf{1}\); each such code contains two of these vectors. So \(\sigma_{n,2} = 2^{n-2} - 1\).
Every \([n, k+1]\) self-orthogonal code containing \(\mathbf{1}\) contains an \([n, k]\) self-orthogonal code also containing \(\mathbf{1}\). Beginning with an \([n, k]\) self-orthogonal code \(\mathcal{C}\) containing \(\mathbf{1}\), the only way to find an \([n, k+1]\) self-orthogonal code \(\mathcal{C}'\) containing \(\mathcal{C}\) is by adjoining a vector \(\mathbf{c}'\) from one of the \(2^{n-k} - 1\) cosets of \(\mathcal{C}\) in \(\mathcal{C}^\perp\) that is unequal to \(\mathcal{C}\). Thus \(\mathcal{C}\) can be extended to \(2^{n-k} - 1\) different \([n, k+1]\) self-orthogonal codes \(\mathcal{C}'\). However, every such \(\mathcal{C}'\) has \(2^k - 1\) subcodes of dimension \(k\) containing \(\mathbf{1}\) by Exercise 522(a). This shows that \(\sigma_{n,k+1} = \frac{2^{n-2k} - 1}{2^k - 1} \sigma_{n,k}\).
Note that using this recurrence relation, we obtain \(\sigma_{n,2} = 2^{n-2} - 1\) as earlier. Using this recurrence relation, the number of self-dual binary codes of length \(n\) is
\(\sigma_{n,n/2} = \frac{2^2-1}{2^1-1} \cdot \frac{2^4-1}{2^2-1} \cdot \frac{2^6-1}{2^3-1} \cdots \frac{2^n-1}{2^{n/2}-1} \cdot \sigma_{n,1}\)
\(= \frac{2^2-1}{2^1-1} \frac{2^4-1}{2^2-1} \frac{2^6-1}{2^3-1} \cdots \frac{2^{n-2}-1}{2^{n/2-1}-1}\)
\(= (2^1+1)(2^2+1)(2^3+1) \cdots (2^{n/2-1}+1),\)
which is the desired result.
