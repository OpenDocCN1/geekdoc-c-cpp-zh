### Exercise 511
Let \(\mathcal{C}\) be a self-dual binary code of length \(n\). Show that there is a one-to-one correspondence between the subcodes of \(\mathcal{C}\) of dimension \((n/2) - 1\) and the cosets of \(\mathcal{C}\). Hint: See Exercise 510. \(\blacklozenge\)

In general, we can choose \(C_0\) to be any \([n, (n/2) - 1]\) subcode of \(\mathcal{C}\) and obtain the four cosets \(C_i\) of \(C_0\) in \(C_0^\perp\). Alternatively, we can choose a coset \(\mathcal{C}'\) of \(\mathcal{C}\) and let \(C_0 = (\mathcal{C} \cup \mathcal{C}')^\perp\). Then \(C_0^\perp = C_0 \cup C_1 \cup C_2 \cup C_3\) where \(\mathcal{C} = C_0 \cup C_2\) and \(\mathcal{C}' = C_1 \cup C_3\).

Two possibilities arise for the weights of the cosets \(C_i\) depending on whether or not \(\mathbf{1} \in C_0\). Recall from Exercise 72 that a coset of \(\mathcal{C}\), such as \(C_1 \cup C_3\), has all even weight vectors or all odd weight vectors. If \(\mathbf{1} \in C_0\), then all codewords in \(C_0^\perp\) must be even weight, implying that \(C_1 \cup C_3\) has only even weight vectors, or equivalently, \(C_1 \cup C_3\) is an even weight coset of \(\mathcal{C}\). Notice that, in this case, \(C_0 \cup C_1\) and \(C_0 \cup C_3\) are self-dual codes. If \(\mathbf{1} \notin C_0\), then \(C_0^\perp\) is not an even code and \(\mathcal{C}\) must be the even subcode of \(C_0^\perp\). Thus \(C_1 \cup C_3\) has only odd weight vectors, or equivalently, \(C_1 \cup C_3\) is an odd weight coset of \(\mathcal{C}\). We summarize this in the following lemma.

### Lemma 9.4.6
Let \(\mathcal{C}\) be an \([n, n/2]\) self-dual binary code with \(C_0\) an \([n, (n/2) - 1]\) subcode. The following are the only possibilities:
- (i) If \(\mathbf{1} \in C_0\), then \(C_1 \cup C_3\) is an even weight coset of \(\mathcal{C}\) and contains only even weight vectors. Also \(C_0 \cup C_1\) and \(C_0 \cup C_3\) are self-dual codes.
- (ii) If \(\mathbf{1} \notin C_0\), then \(\mathbf{1} \in C_2\). Furthermore, \(C_1 \cup C_3\) is an odd weight coset of \(\mathcal{C}\) and contains only odd weight vectors.

We investigate the two possibilities that arise in Lemma 9.4.6. In each case we obtain an orthogonality table showing whether or not \(C_i\) is orthogonal to \(C_j\). We also obtain additional information about the weights of vectors in \(C_1\) and \(C_3\).

Suppose that \(C_1 \cup C_3\) is an even weight coset of \(\mathcal{C}\). Then Table 9.4 gives the orthogonality relationships between the cosets [38]; these follow from Lemma 9.4.4, with verification left as an exercise.

### Theorem 9.4.7
Let $\mathcal{C}$ be an $[n, n/2]$ self-dual binary code with $\mathcal{C}_0$ an $[n, (n/2) - 1]$ subcode. Suppose that $1 \in \mathcal{C}_0$. The following hold:
- (i) If $\mathcal{C}$ is Type II, $C_1$ and $C_3$ can be numbered so that all vectors in $C_1$ have weight 0 modulo 4, and all vectors in $C_3$ have weight 2 modulo 4.
- (ii) If $\mathcal{C}$ and $C_0$ are singly-even, then half the vectors in $C_i$ are singly-even and half are doubly-even for $i = 1$ and 3.
- (iii) (Shadow case) If $\mathcal{C}$ is singly-even and $C_0$ is the doubly-even subcode of $\mathcal{C}$ and if $c \in C_1 \cup C_3$, then $wt(c) \equiv n/2 \pmod 4$. Also $n \equiv 0 \pmod 8$ or $n \equiv 4 \pmod 8$.

**Proof:** We leave the proofs of (i) and (ii) as an exercise. Suppose that $\mathcal{C}$ is singly-even and $C_0$ is the doubly-even subcode of $\mathcal{C}$. Let $c_i \in C_i$. Then $c_1 + c_3 \in C_2$ by Lemma 9.4.4 implying that $wt(c_1 + c_3) \equiv 2 \pmod 4$. But $wt(c_1 + c_3) = wt(c_1) + wt(c_3) - 2wt(c_1 \cap c_3) \equiv wt(c_1) + wt(c_3) - 2 \pmod 4$ as $wt(c_1 \cap c_3)$ is odd. Since both $wt(c_1)$ and $wt(c_3)$ are even, $wt(c_1) \equiv wt(c_3) \pmod 4$.
If $n \not\equiv 0 \pmod 8$, then all weights in $C_1$ and $C_3$ must be 2 modulo 4, as otherwise $C_0 \cup C_1$ or $C_0 \cup C_3$ would be a Type II code, which is a contradiction. Because $1 \in C_0$, $n \equiv 4 \pmod 8$, and (iii) follows in this case. If $n \equiv 0 \pmod 8$, then every $(n, n/2 - 1)$ doubly-even code that contains $1$, such as $C_0$, is contained in one Type I code and two Type II codes; see Exercise 526. These three codes must be in $C_0^{\perp}$; since $C = C_0 \cup C_2$ is Type I, $C_0 \cup C_1$ and $C_0 \cup C_3$ must be the Type II codes. Thus $wt(c) \equiv 0 \equiv n/2 \pmod 4$.

### Theorem 9.4.10
Let $C$ be an $[n, n/2]$ self-dual binary code with $C_0$ an $[n, (n/2) - 1]$ subcode. Suppose that $1 \notin C_0$. The following hold:
- (i) If $C$ is Type II, $C_1$ and $C_3$ can be numbered so that all vectors in $C_1$ have weight 1 modulo 4, and all vectors in $C_3$ have weight 3 modulo 4.
- (ii) If $C_0$ is singly-even, then, for $i = 1$ and 3, half the vectors in $C_i$ have weight 1 modulo 4 and half the vectors in $C_i$ have weight 3 modulo 4.
- (iii) (Shadow case) If $C$ is singly-even and $C_0$ is the doubly-even subcode of $C$ and if $c \in C_1 \cup C_3$, then $wt(c) \equiv n/2 \pmod 4$. Also $n \equiv 2 \pmod 8$ or $n \equiv 6 \pmod 8$.

**Proof:** We leave the proofs of (i) and (ii) as an exercise. Suppose that $C$ is singly-even and $C_0$ is the doubly-even subcode of $C$. We note that since $1 \notin C_0$, then $1 \in C_2$. As $C_2$ can only contain singly-even vectors, either $n \equiv 2 \pmod 8$ or $n \equiv 6 \pmod 8$.
