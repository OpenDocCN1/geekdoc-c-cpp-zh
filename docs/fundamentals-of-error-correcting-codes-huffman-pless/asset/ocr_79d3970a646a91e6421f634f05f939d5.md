**Example 7.3.3** Let \(\mathcal{C}\) be a \([16, 8, 4]\) self-dual doubly-even binary code. By Theorem 1.4.5(iv), \(A_0 = A_{16} = 1\). Thus in the weight distribution, only \(A_4, A_8\), and \(A_{12}\) are unknown as \(A_2 = 0\) when \(4 \mid i\). In Exercise 386, you will be asked to find these values by solving the first three equations in (7.8). We present an alternate solution. Letting \(z = 3\) and \(S = \{4, 8, 12\}\), there is a unique solution by Theorem 7.3.1 since \(A^+_i = A^-_i = 0\). Thus if we can find one \([16, 8, 4]\) self-dual doubly-even binary code, its weight enumerator will give this unique solution. Let \(\mathcal{C}_1 = \widetilde{\mathcal{H}}_3\), which is the unique \([8, 4, 4]\) code (see Exercise 56) and has weight enumerator \(W_{\mathcal{C}_1}(x, y) = y^8 + 14x^4y^4 + x^8\) (see Exercise 19 and Example 1.11.7). By Section 1.5.4, \(\mathcal{C}_1 \oplus \mathcal{C}_1\) is a \([16, 8, 4]\) code. By Theorem 7.2.2,
\[\nW_{\mathcal{C}_1 \oplus \mathcal{C}_1}(x, y) = (y^8 + 14x^4y^4 + x^8)^2 = y^{16} + 28x^4y^{12} + 198x^8y^8 + 28x^{12}y^4 + x^{16}.\n\]
As all weights in \(\mathcal{C}_1 \oplus \mathcal{C}_1\) are divisible by 4, this code is self-dual doubly-even by Theorem 1.4.8; thus we have produced the weight enumerator of \(\mathcal{C}\). We will explore this example more extensively later in this chapter.

**Example 7.3.4** Let \(\mathcal{C}\) be the \([n, k]\) simplex code over \(\mathbb{F}_q\) where \(n = (q^k - 1)/(q - 1)\). By Theorem 2.7.5, the weight distribution of \(\mathcal{C}\) is \(A_0 = 1, A_{q^{k-1}} = q^k - 1\), and \(A_j = 0\) for all other \(i\). = q^{-k} [ (q-1)^j \binom{n}{j} + (q^k - 1) K^q_j(q^{k-1}) ]\n\]
for \(0 \le j \le n\).
