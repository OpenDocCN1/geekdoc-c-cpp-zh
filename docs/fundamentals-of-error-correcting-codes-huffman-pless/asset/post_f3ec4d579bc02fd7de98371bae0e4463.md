
In Theorem 7.2.3 we will show that if C is a linear code of length n over F_q with weight distribution A_w for 0 <= w <= n, then A_k^\perp = 1/|C| \sum_{w=0}^n A_w K_k^{n,q}(w) for 0 <= k <= n is the weight distribution of C^\perp. As C is linear A_w = B_w by Exercise 117. In particular for linear codes \sum_{w=0}^n B_w K_k^{n,q}(w) >= 0. The next lemma, which is the basis of the Linear Programming Bound, shows that this inequality holds where B_w is the distance distribution of a (possibly) nonlinear code.

### Lemma 2.6.3

Let B_w, 0 <= w <= n, be the distance distribution of a code over F_q. Then

```
\sum_{w=0}^n B_w K_k^{n,q}(w) \ge 0
```

for 0 <= k <= n.

Proof: By Theorem 2.6.1 we only need to verify these inequalities for an (n, M) code C over F_q. By definition of the distance distribution and Lemma 2.6.2,

```
M \sum_{w=0}^n B_w K_k^{n,q}(w) = \sum_{w=0}^n \sum_{x \in C, wt(x)=w} K_k^{n,q}(w) = \sum_{w=0}^n \sum_{x \in C, wt(x)=w} \sum_{y \in C, wt(y)=k} \xi^{(x-y) \cdot v}
= \sum_{(x,y) \in C^2} \sum_{v \in F_q^n, wt(v)=k} \xi^{x \cdot v} \xi^{-y \cdot v} = \sum_{v \in F_q^n, wt(v)=k} \sum_{x \in C} \xi^{x \cdot v} \sum_{y \in C} \xi^{-y \cdot v}
= \sum_{v \in F_q^n, wt(v)=k} \sum_{x \in C} \xi^{x \cdot v} \overline{\xi^{x \cdot v}} = \sum_{v \in F_q^n, wt(v)=k} \left| \sum_{x \in C} \xi^{x \cdot v} \right|^2 \ge 0,
```

proving the result.

If C is an (n, M, d) code over F_q with distance distribution B_w, 0 <= w <= n, then M = \sum_{w=0}^n B_w and B_0 = 1 by Exercise 117. Also B_1 = B_2 = ... = B_{d-1} = 0. By Lemma 2.6.3, we also have \sum_{w=0}^n w B_w >= 0 when k = 0 as K_0^{n,q}(w) = 1, which is clearly already true. If q = 2, again by Exercise 117, B_w <= 1, and furthermore if d is even, by Theorem 2.1.2, we may also assume that B_w = 0 when w is odd. By Exercise 116, when w is even, K_k^{n,q}(w) = K_{n-k}^{n,q}(w). Thus the kth inequality in (2.35) is the same as the (n - k)th as the only (possibly) nonzero B_w's are when w is even. This discussion yields our bound.

### Theorem 2.6.4 (Linear Programming Bound)

The following hold:

- (i) When q >= 2, \( A_q(n, d) \le \max(\sum_{w=0}^n B_w) \), where the maximum is taken over all \( B_w \) subject to the following conditions:
  - (a) \( B_0 = 1 \) and \( B_w = 0 \) for \( 1 \le w \le d - 1 \),
  - (b) \( B_w \ge 0 \) for \( d \le w \le n \), and
  - (c) \( \sum_{w=0}^n B_w K_k^{n,q}(w) \ge 0 \) for \( 1 \le k \le n \).

- (ii) When d is even and q = 2, \( A_2(n, d) \le \max(\sum_{w=0}^n B_w) \), where the maximum is taken over all \( B_w \), subject to the following conditions:
  - (a) \( B_0 = 1 \) and \( B_w = 0 \) for \( 1 \le w \le d - 1 \) and all odd w,
  - (b) \( B_w \ge 0 \) for \( d \le w \le n \) and \( B_n \le 1 \), and
  - (c) \( \sum_{w=0}^n B_w K_k^{n,q}(w) \ge 0 \) for \( 0 \le k \le \lfloor n/2 \rfloor \).

Solving the inequalities of this theorem is accomplished by linear programming, hence the name. At times other inequalities can be added to the list which add more constraints to the linear program and reduce the size of \( \sum_{w=0}^n B_w \). In specific cases other variations to the Linear Programming Bound can be performed to achieve a smaller upper bound. Many of the upper bounds in Table 2.1 come from the Linear Programming Bound and these variations.

### Example 2.6.5

We apply the Linear Programming Bound to obtain an upper bound on \( A_2(8, 3) \). By Theorem 2.1.2, \( A_2(8, 3) = A_2(9, 4) \). Hence we apply the Linear Programming Bound (ii) with \( q = 2, n = 9 \), and \( d = 4 \). Thus we are trying to find a solution to \( \max\{1 + B_4 + B_6 + B_8\} \) where

- \( 9 + B_4 - 3B_6 - 7B_8 \ge 0 \)
- \( 36 - 4B_4 + 20B_6 \ge 0 \)
- \( 84 - 4B_4 + 8B_6 - 28B_8 \ge 0 \)
- \( 126 + 6B_4 - 6B_6 + 14B_8 \ge 0 \)

with \( B_4 \ge 0, B_6 \ge 0 \), and \( B_8 \ge 0 \). The unique solution to this linear program is \( B_4 = 18, B_6 = 24/5 \), and \( B_8 = 9/5 \). Hence \( \max\{1 + B_4 + B_6 + B_8\} = 1 + (123/5) \), implying \( A_2(9, 4) \le 25 \).

We can add two more inequalities to (2.36). Let \( \mathcal{C} \) be a \( (9, M, 4) \) code, and let \( \mathbf{x} \in \mathcal{C} \). Define \( \mathcal{C}_x = \mathbf{x} + \mathcal{C} \); note that \( \mathcal{C}_x \) is also a \( (9, M, 4) \) code. The number of codewords in \( \mathcal{C} \) at distance 8 from \( \mathbf{x} \) is the same as the number of vectors of weight 8 in \( \mathcal{C}_x \). As there is clearly no more than one vector of weight 8 in a \( (9, M, 4) \) code, we have

\( B_8 \le 1 \).

Also the number of codewords at distance 6 from \( \mathbf{x} \) is the same as the number of vectors of weight 6 in \( \mathcal{C}_x \); this number is at most \( A_2(9, 4, 6) \), which is 12 by Exercise 100. Furthermore, if there is a codeword of weight 8 in \( \mathcal{C}_x \), then every vector in \( \mathcal{C}_x \) of weight 6 has a 1 in the coordinate where the weight 8 vector is 0. This means that the number of weight 6 vectors in \( \mathcal{C}_x \) is the number of weight 5 vectors in the code obtained by puncturing \( \mathcal{C}_x \) on this coordinate. That number is at most \( A_2(8, 4, 5) \), which is 8 by Exercise 101. Putting these together shows that

\( B_4 + 4B_8 \le 12 \).

Including inequalities (2.37) and (2.38) with (2.36) gives a linear program which when solved yields the unique solution \( B_4 = 14, B_6 = 16/3 \), and \( B_8 = 1 \) implying \( \max\{1 + B_4 + B_6 + B_8\} = 64/3 \). Thus \( A_2(9, 4) \le 21 \). By further modifying the linear program (see [218, Chapter 17]) it can be shown that \( A_2(9, 4) \le 20 \). In fact \( A_2(9, 4) = 20 \); see Table 2.1. See also Exercise 103.

## 2.7 The Griesmer Upper Bound

The final upper bound we discuss is a generalization of the Singleton Bound known as the Griesmer Bound. We place it last because, unlike our other upper bounds, this one applies only to linear codes.

To prove this bound we first discuss the generally useful idea of a residual code due to H. J. Helgert and R. D. Stinaff [120]. Let \( \mathcal{C} \) be an \([n, k]\) code and let \( \mathbf{c} \) be a codeword of weight \( w \). Let the set of coordinates on which \( \mathbf{c} \) is nonzero be \( \mathcal{T} \). Then the *residual code* of \( \mathcal{C} \) with respect to \( \mathbf{c} \), denoted \( \text{Res}(\mathcal{C}, \mathbf{c}) \), is the code of length \( n-w \) punctured on all coordinates of \( \mathcal{T} \). The next result gives a lower bound for the minimum distance of residual codes [131].

### Theorem 2.7.1

Let \( \mathcal{C} \) be an \([n, k, d]\) code over \( \mathbb{F}_q \) and let \( \mathbf{c} \) be a codeword of weight \( w < (q/(q-1))d \). Then \( \text{Res}(\mathcal{C}, \mathbf{c}) \) is an \([n-w, k-1, d']\) code, where \( d' \ge d - w + \lceil w/q \rceil \).

Proof: By replacing \( \mathcal{C} \) by a monomially equivalent code, we may assume that \( \mathbf{c} = 11 \cdots 100 \cdots 0 \). Since puncturing \( \mathbf{c} \) on its nonzero coordinates gives the zero vector, \( \text{Res}(\mathcal{C}, \mathbf{c}) \) has dimension less than \( k \). Assume that the dimension is strictly less than \( k-1 \). Then there exists a nonzero codeword \( \mathbf{x} = x_1 \cdots x_n \in \mathcal{C} \) which is not a multiple of \( \mathbf{c} \) with \( x_{w+1} \cdots x_n = \mathbf{0} \). There exists \( \alpha \in \mathbb{F}_q \) such that at least \( w/q \) coordinates of \( x_1 \cdots x_w \) equal \( \alpha \). Therefore
$$
d \le \text{wt}(\mathbf{x} - \alpha \mathbf{c}) \le w - \frac{w}{q} = \frac{w(q-1)}{q},
$$
contradicting our assumption on \( w \). Hence \( \text{Res}(\mathcal{C}, \mathbf{c}) \) has dimension \( k-1 \).
