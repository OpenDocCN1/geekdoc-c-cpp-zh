# 12.7 Kerdock codes

We now define the binary Kerdock code of length 2^(r+1) as the Gray image of the extended code of a certain cyclic Z4-linear code of length n = 2^r - 1. Let H(x) be a primitive basic irreducible polynomial of degree r. Let f(x) be the reciprocal polynomial of (x^r - 1)/((x - 1)H(x)). As in Section 12.3.3, f(x) is a factor of x^n - 1. Define K(r + 1) to be the cyclic code of length 2^r - 1 over Z4 generated by f(x). By Corollary 12.3.14, K(r + 1) is a code of length n = 2^r - 1 and type 4^(n-k) / 2^k = 4^(r+1). Let K(r + 1) be the extended cyclic code obtained by adding an overall parity check to K(r + 1). This is a code of length 2^r and type 4^(r+1). The Kerdock code K(r + 1) is defined to be the Gray image Phi(K(r + 1)) of K(r + 1). So K(r + 1) is a code of length 2^(r+1) with 4^(r+1) codewords. In [116] it is shown that a simple rearrangement of the coordinates leads directly to the original definition given by Kerdock in [166]. The results of this section are taken primarily from [116]. Earlier Nechaev [243] discovered a related connection between Z4-sequences and Kerdock codes punctured on two coordinates.

Example 12.7.1 If n = 2^3 - 1, we can let H(x) = x^3 + 2x^2 + x - 1. In that case, f*(x) = (x^3 - 1)/((x - 1)H(x)) = x^3 - x^2 + 2x - 1 and f(x) = x^3 + 2x^2 + x - 1.

In this section GR(4^r) will denote the specific Galois ring Z4[x]/(f(x)). Let xi be a primitive root of H(x) in GR(4^r). We will add the parity check position on the left of a codeword of K(r + 1) and label the check position infinity. Hence if c_infinity c0 ... c_{n-1} is a codeword, the corresponding 'extended' polynomial form would be (c_infinity, c(x)), where c(x) = c0 + c1 x + ... + c_{n-1} x^(n-1).

Lemma 12.7.2 Let r >= 2. The following hold:
(i) A polynomial c(x) in Z_n is in K(r + 1) if and only if (x - 1)H(x)c*(x) = 0 in Z_n.
(ii) Generator matrices G_{r+1} and G~_{r+1} for K(r + 1) and K~(r + 1), respectively, are
G_{r+1} = [ 1 1 1 ... 1 ; 1 xi xi^2 ... xi^(n-1) ; 1 xi^2 xi^4 ... xi^(2(n-1)) ; ... ; 1 xi^k xi^(2k) ... xi^(k(n-1)) ] . G~_{r+1} = [ 0 1 1 ... 1 ; 1 0 xi ... xi^(n-2) ; ... ; 1 xi^(k-1) ... ]
We can replace each xi^k by the column vector [b0, b1, ..., b_{r-1}]^T obtained from (12.21), where xi^k = sum b_j xi^j.

Proof: Since Z_n = ((x - 1)H(x) direct sum (f*(x)) by Theorem 12.3.12, (x - 1)H(x)c*(x) = 0 in Z_n if and only if c*(x) in (f*(x)) if and only if c(x) = f(x)s(x) for some s(x) in Z_n, proving (i).
