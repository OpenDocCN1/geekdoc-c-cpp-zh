The following corollary determines, from the generator polynomial, when a cyclic code is self-orthogonal.

**Corollary 4.4.10** Let $\mathcal{C}$ be a cyclic code over $\mathbb{F}_q$ of length $n$ with generator polynomial $g(x)$ and check polynomial $h(x) = (x^n - 1)/g(x)$. Then $\mathcal{C}$ is self-orthogonal if and only if $h^*(x) | g(x)$.

In the next theorem we show how to decide when a cyclic code is self-orthogonal. In particular, this characterization shows that all self-orthogonal cyclic codes are even-like. In this theorem we use the observation that if $C$ is a $q$-cyclotomic coset modulo $n$, either $C_{\mu^{-1}} = C$ or $C_{\mu^{-1}} = C'$ for some different $q$-cyclotomic coset $C'$, in which case $C'_{\mu^{-1}} = C$ as $\mu^2_1$ is the identity.

**Theorem 4.4.11** Let $\mathcal{C}$ be a self-orthogonal cyclic code over $\mathbb{F}_q$ of length $n$ with defining set $T$. Let $C_1, \dots, C_k, D_1, \dots, D_\ell, E_1, \dots, E_\ell$ be all the distinct $q$-cyclotomic cosets modulo $n$ partitioned so that $C_i = C_{i\mu^{-1}}$ for $1 \le i \le k$ and $D_i = E_{i\mu^{-1}}$ for $1 \le i \le \ell$. The following hold.

+   (i) $C_i \subseteq T$ for $1 \le i \le k$ and at least one of $D_i$ or $E_i$ is contained in $T$ for $1 \le i \le \ell$. (ii) $\mathcal{C}$ is even-like. (iii) $\mathcal{C} \cap \mathcal{C}_{\mu^{-1}} = \{\mathbf{0}\}$. 

**Conversely:** if $\mathcal{C}$ is a cyclic code with defining set $T$ that satisfies (i), then $\mathcal{C}$ is self-orthogonal.

**Proof:** Let $N = \{0, 1, \dots, n-1\}$. Let $T^\perp$ be the defining set of $\mathcal{C}^\perp$. By Theorem 4.4.9, $T^\perp = N \setminus (-1)T \mod n$. As $\mathcal{C} \subseteq \mathcal{C}^\perp$, $N \setminus (-1)T \mod n \subseteq T$ by Exercise 239. If $C_i \nsubseteq T$, then $C_i \subseteq (-1)T \mod n$ because $C_i = C_{i\mu^{-1}}$ implying that $C_i \subseteq N \setminus (-1)T \mod n \subseteq T$, a contradiction. If $D_i \nsubseteq T$, then $E_i \subseteq (-1)T \mod n$ because $E_i = D_{i\mu^{-1}}$ implying that $E_i \subseteq N \setminus (-1)T \mod n \subseteq T$, proving (i). Part (ii) follows from part (i) and Exercise 238 as $C_i = \{0\}$ for some $i$. By Corollary 4.4.5, $C_{\mu^{-1}}$ defining set $(-1)T \mod n$. By (i) $T \cup (-1)T \mod n = N$ yielding (iii) using Exercise 239.

For the converse, assume $T$ satisfies (ii). We only need to show that $T^\perp \subseteq T$, where $T^\perp = N \setminus (-1)T \mod n$ by Exercise 239. As $C_i \subseteq T$ for $1 \le i \le k$, $C_i \subseteq (-1)T \mod n$ implying $C_i \subseteq T^\perp$. Hence $T^\perp$ is a union of some $D_i$'s and $E_i$'s. If $D_i \subseteq N \setminus (-1)T \mod n$, then $D_i \nsubseteq (-1)T \mod n$ and so $E_i \subseteq T$. By (i) $D_i \subseteq T$. Similarly if $E_i \subseteq N \setminus (-1)T \mod n$, then $E_i \subseteq T$. Hence $T^\perp \subseteq T$ implying $\mathcal{C}$ is self-orthogonal. $\square$
