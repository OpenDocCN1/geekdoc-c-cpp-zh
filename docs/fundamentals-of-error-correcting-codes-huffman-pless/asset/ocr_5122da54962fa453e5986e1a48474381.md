By Theorem 14.4.7, \( k_L = \max\{L + 1 - m_1, 0\} + \max\{L + 1 - m_2, 0\} = \max\{L + 1, 0\} + \max\{L, 0\} \). So \( k_L = 2L + 1 \) for \( L \ge 0 \). Thus \( C_2^{(L)} \), as a binary code, is a \([4(L+1), 2L+1]\) code; we can see that a basis of the interleaved version of \( C_2^{(L)} \) is the first \( 2L + 1 \) rows of \( B(G_2^L) \). As the rows of \( B(G_2^L) \) are of even weight, \( C_2^{(L)} \), as a binary code, is an even code. It is not difficult to see that the span of the first \( 2L + 1 \) rows of \( B(G_2^L) \) has no vector of weight 2. Thus, as a binary code, \( C_2^{(L)} \) is a \([(4L+1), 2L+1, 4]\) code for all \( L \ge 0 \). By Theorem 14.4.6, \( C_2 \) has free distance 4; see also Exercise 824.

If we let \(\Delta(n, k)\) be the largest minimum distance possible for a binary \([n, k]\) code, then an immediate consequence of Theorem 14.4.6 is the following bound.

**Theorem 14.4.10** Let \(\mathcal{C}\) be an \((n, k)\) convolutional code with Forney indices \(m_1, \dots, m_k\). Let \(k_L\) be defined by Theorem 14.4.7. Then
\( d_{free} \le \min_{L \ge 0} \Delta(n(L+1), k_L) \).

We can use bounds, such as those in Chapter 2, or tables, such as those found in [32], to give values of \(\Delta(n(L+1), k_L)\).
