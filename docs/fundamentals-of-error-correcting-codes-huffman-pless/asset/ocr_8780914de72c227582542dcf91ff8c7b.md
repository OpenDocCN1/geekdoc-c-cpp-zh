**Theorem 9.4.7** Let $\mathcal{C}$ be an $[n, n/2]$ self-dual binary code with $\mathcal{C}_0$ an $[n, (n/2) - 1]$ subcode. Suppose that $I \in \mathcal{C}_0$. The following hold:
(i) If $\mathcal{C}$ is Type II, $C_1$ and $C_3$ can be numbered so that all vectors in $C_1$ have weight 0 modulo 4, and all vectors in $C_3$ have weight 2 modulo 4.
(ii) If $\mathcal{C}$ and $C_0$ are singly-even, then half the vectors in $C_i$ are singly-even and half are doubly-even for $i = 1$ and 3.
(iii) (Shadow case) If $\mathcal{C}$ is singly-even and $C_0$ is the doubly-even subcode of $\mathcal{C}$ and if $c \in C_1 \cup C_3$, then $wt(c) \equiv n/2 \pmod 4$. Also $n \equiv 0 \pmod 8$ or $n \equiv 4 \pmod 8$.

**Proof:** We leave the proofs of (i) and (ii) as an exercise. Suppose that $\mathcal{C}$ is singly-even and $C_0$ is the doubly-even subcode of $\mathcal{C}$. Let $c_i \in C_i$. Then $c_1 + c_3 \in C_2$ by Lemma 9.4.4 implying that $wt(c_1 + c_3) \equiv 2 \pmod 4$. But $wt(c_1 + c_3) = wt(c_1) + wt(c_3) - 2wt(c_1 \cap c_3) \equiv wt(c_1) + wt(c_3) - 2 \pmod 4$ as $C_1/C_3$. Since both $wt(c_1)$ and $wt(c_3)$ are even, $wt(c_1) \equiv wt(c_3) \pmod 4$.
If $n \not\equiv 0 \pmod 8$, then all weights in $C_1$ and $C_3$ must be 2 modulo 4, as otherwise $C_0 \cup C_1$ or $C_0 \cup C_3$ would be a Type II code, which is a contradiction. Because $I \in C_0$, $n \equiv 4 \pmod 8$, and (iii) follows in this case. If $n \equiv 0 \pmod 8$, then every $(n, n/2 - 1)$ doubly-even code that contains $I$, such as $C_0$, is contained in one Type I code and two Type II codes; see Exercise 526. These three codes must be in $C_0^{\perp}$; since $C = C_0 \cup C_2$ is Type I, $C_0 \cup C_1$ and $C_0 \cup C_3$ must be the Type II codes. Thus $wt(c) \equiv 0 \equiv n/2 \pmod 4$.
