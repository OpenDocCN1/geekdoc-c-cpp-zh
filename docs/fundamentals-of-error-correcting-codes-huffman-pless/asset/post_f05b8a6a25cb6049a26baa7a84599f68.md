## 15.2 A Soft Decision Viterbi Algorithm

In this section we examine how we might modify the Viterbi Algorithm (a hard decision decoding algorithm) of Section 14.2 to obtain a soft decision Viterbi decoding algorithm. The Soft Decision Viterbi Algorithm is carried out in precisely the same manner as the hard decision Viterbi Algorithm once the edge weights in the trellis are appropriately defined, except the survivor paths are the ones with highest path weights. The hard decision Viterbi Algorithm is nearest neighbor decoding that, over a binary symmetric channel, is also maximum likelihood decoding; see the discussion in Section 1.11.2. The Soft Decision Viterbi Algorithm will also be maximum likelihood decoding.

Suppose that an input message \(\mathbf{x}(i) = (x_i(0), \dots, x_i(L))\) for \(i = 0, 1, \dots, L-1\) is encoded using the generator matrix \(G\) of an \((n, k)\) binary convolutional code to produce an output codeword \(\mathbf{c}(i) = (c_i(0), \dots, c_i(n))\) for \(i = 0, 1, \dots, L+M-1\). As previously, the state \(s\) of the encoder at time \(i\) is denoted \(x_i\). The zero state will be state \(a\). The initial and final state of the encoder. We will add \(M\) blocks of \(k\) zeros to the end of the message so that the encoder will terminate in the zero state \(a_{L+M}\) at time \(L+M\). The bits of this codeword are interleaved as in (14.1) and this bit stream is modulated, transmitted, and received as a waveform \(y(t)\) that is demodulated using (15.1). Although any demodulation scheme can be used, we will assume for concreteness that 8-level quantization is used as described in the previous section. After deinterleaving the quantized data, we have a received vector \(\mathbf{y}(i) = (y_i(1), \dots, y_i(n))\) for \(i = 0, 1, \dots, L+M-1\) where \(y_i(j) \in \{0, 1, \dots, 7\}\).

Since the Soft Decision Viterbi Algorithm is to perform maximum likelihood decoding, the algorithm must find the codeword \(\mathbf{e}\) that maximizes \(\text{prob}(\mathbf{y} | \mathbf{e})\). However, as the channel is memoryless,

\(\text{prob}(\mathbf{y} | \mathbf{e}) = \prod_{i=0}^{L+M-1} \prod_{j=1}^n \text{prob}(y_i(j) | e_i(j)).\)

Maximizing this probability is equivalent to maximizing its logarithm

\(\ln(\text{prob}(\mathbf{y} | \mathbf{c})) = \sum_{i=0}^{L+M-1} \sum_{j=1}^n \ln(\text{prob}(y_j(i) | c_j(i))),\)

which has the advantage of converting the product to a sum. (Recall that computing the weight of a path in the original Viterbi Algorithm was accomplished by summing edge weights.) We can employ a technique of Massey [226] that will allow us to make the edge weights into integers. Maximizing \(\ln(\text{prob}(\mathbf{y} | \mathbf{c}))\) is equivalent to maximizing

\(\sum_{i=0}^{L+M-1} \sum_{j=1}^n \mu(y_j(i), c_j(i)),\) (15.13)

with

\(\mu(y_j(i), c_j(i)) = A(\ln(\text{prob}(y_j(i) | c_j(i))) - f_{i,j}(y_j(i))),\) (15.14)

where \(A\) is a positive constant and \(f_{i,j}(\mathbf{y}(i))\) is an arbitrary function. The value

\(\sum_{j=1}^n \mu(y_j(i), c_j(i))\) (15.15)

will be the edge weight in the trellis replacing the Hamming distance used in the hard decision Viterbi Algorithm. To make computations simpler first choose

\(f_{i,j}(\mathbf{y}(i)) = \min_{c \in \{0,1\}} \{ \ln(\text{prob}(y_j(i) | c)) \}\)

and then choose \(A\) so that \(\mu(y_j(i), c_j(i))\) is close to a positive integer. With these edge weights, the path weights can be determined. The Soft Decision Viterbi Algorithm now proceeds as in Section 14.2, except the surviving paths at a node are those of **maximum weight** rather than minimum weight.

It is interesting to apply the Soft Decision Viterbi Algorithm to a binary symmetric channel with crossover probability \(\varrho\) instead of the binary input 8-ary output channel. In the case of the BSC,

\(\text{prob}(y | c) = \prod_{i=0}^{L+M-1} \prod_{j=0}^{M} \text{prob}(y_j(i) | c_j(i))\)
\(= \prod_{i=0}^{L+M-1} \prod_{j=0}^{M} \varrho^{d(y_j(i), c_j(i))} (1-\varrho)^{1-d(y_j(i), c_j(i))}.\)

Therefore from (15.13) and (15.14),

\(\mu(y(i), c(i)) = A(\ln(\varrho^{d(y(i), c(i))} (1-\varrho)^{1-d(y(i), c(i))}) - f_{i,j}(y_j(i)))\)
\(= d(y(i), c(i)) \left( A \ln \frac{\varrho}{1-\varrho} \right) + A \ln(1-\varrho) - A f_{i,j}(y_j(i)).\)

Choosing \(A = -(\ln(\varrho/(1-\varrho)))^{-1}\), which is positive if \(\varrho < 1/2\), and \(f_{i,j}(y_j(i)) = \ln(\varrho)\), we obtain

\(\mu(y(i), c(i)) = 1 - d(y(i), c(i)),\) (15.16)

which implies, by (15.15), that the edge weights in the trellis equal

\(n - d(y(i), c(i)).\)
