**Exercise 558** Find an example of a code C that is linear over F4 such that when the first coordinate only is conjugated, the resulting code is no longer linear over F4.

We now focus on trace self-dual additive codes. For linear codes over F4, there is no distinction between Hermitian self-dual and trace self-dual codes.

**Theorem 9.10.3** Let C be a linear code over F4. Then C is Hermitian self-dual if and only if C is trace self-dual.

**Proof:** First assume that C is an [n, n/2] Hermitian self-dual code. Then <x, y> = 0 for all x and y in C. Thus <x, y>_T = Tr2(<x, y>) = 0 implying that C subset C^{L_T}. As an additive code, C is an (n, 2^n) code and hence, by Exercise 556, C^{L_T} is also an (n, 2^n) code. Thus C = C^{L_T} and C is trace self-dual.

Now assume that C is an (n, 2^n) trace self-dual code. Because C is a linear code over F4, if x in C, then alpha x in C and so <x, alpha x>_T = 0. By Lemma 9.10.2(d), wt(alpha x) is even for all x in C. By Theorem 1.4.10, C subset C^{L_H}. Because C has dimension n/2 as a linear code over F4, so does C^{L_H} implying that C is Hermitian self-dual.

Unlike Hermitian self-dual codes that contain only even weight codewords, trace self-dual additive codes may contain odd weight codewords; such codes cannot be linear over F4 by Theorem 9.10.3. This leads to the following definitions: An additive code C is Type II if C is trace self-dual and all codewords have even weight. Exercise 383 applies to additive codes over F4 as the MacWilliams equation (M_a) holds. In particular, if C is Type II of length n, then C^{L_T} = C contains a codeword of weight n implying that n is even. By Corollary 9.2.2, F4-linear Hermitian self-dual codes exist if and only if n is even. Hence Type II additive codes exist if and only if n is even. If C is trace self-dual but some codeword has odd weight (in which case the code cannot be F4-linear), the code is Type I. The n x n identity matrix generates an (n, 2^n) Type I additive code implying Type I codes exist for all n.

There is an analog to Gleason's Theorem for Type II additive codes, which is identical to Gleason's Theorem for Hermitian self-dual linear codes; see [291, Section 7.7].

**Theorem 9.10.4** If C is a Type II additive code, then

```
W_C(x, y) = \sum_{i=0}^{\lfloor \frac{n}{2} \rfloor} a_i g_6(x, y)^{2i} g_7(x, y)^{n-3i} g_1(x, y)^i.
```

where g_6(x, y) = y^2 + 3x^2 and g_7(x, y) = y^6 + 45x^4y^2 + 18x^6. All a_i s are rational and \sum a_i = 1.
