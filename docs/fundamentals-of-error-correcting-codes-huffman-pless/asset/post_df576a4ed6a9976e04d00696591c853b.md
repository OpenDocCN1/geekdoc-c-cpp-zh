### Theorem 9.9.6
Let C be an [n, n/2, d] even formally self-dual binary code with d = 2 [n/8] + 2 and n > 2. Let Sw be the set of vectors of weight w in C together with those of weight w in C⊥; a vector in C ∩ C⊥ is included twice in Sw. Then the vectors in Sw hold a 3-design if n ≡ 2 (mod 8) and a 1-design if n ≡ 6 (mod 8).

We note that this result holds only for the codes of lengths 6, 10, 14, 18, 22, and 30 from (9.13) and Table 9.12.
