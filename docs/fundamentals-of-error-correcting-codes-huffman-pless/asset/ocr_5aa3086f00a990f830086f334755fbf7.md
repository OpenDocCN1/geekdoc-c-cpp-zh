The coordinates of our cyclic codes are indexed by $\mathcal{I}^*$. We are now ready to extend our cyclic codes. We use the element $0 \in \mathcal{T}$ to index the extended coordinate. The extended codeword of $C(X) = \sum_{g \in \mathcal{I}} C_g X^g$ is $\bar{C}(X) = \sum_{g \in \mathcal{I}} C_g X^g$ such that $\sum_{g \in \mathcal{I}} C_g = 0$.

Example 4.7.3 We continue with Examples 4.7.1 and 4.7.2. If $C(X) = X + X^a + X^b$ then $\bar{C}(X) = X^0 + X + X^a + X^b = 1 + X + X^a + X^b$.

From (4.10), together with the observation that $X^{a0} = X^0 = 1$, in this terminology an extended cyclic code is a subspace $\bar{C}$ of $\mathbb{F}_q[\mathcal{I}]$ such that

$$
\sum_{g \in \mathcal{I}} C_g X^g \in \bar{C} \quad \text{if and only if} \quad \sum_{g \in \mathcal{I}} C_g X^{ag} \in \bar{C} \quad \text{and} \quad \sum_{g \in \mathcal{I}} C_g = 0.
$$

With this new notation we want to see where the concepts of zeros and defining sets come in. This can be done with the assistance of a function $\phi_t$. Let $\bar{\mathcal{N}} = \{s \mid 0 \le s \le n\}$. For $s \in \bar{\mathcal{N}}$ define $\phi_s : \mathbb{F}_q[\mathcal{I}] \to \mathcal{T}$ by

$$
\phi_s \left( \sum_{g \in \mathcal{I}} C_g X^g \right) = \sum_{g \in \mathcal{I}} C_g g^s.
$$

where by convention $0^b = 1$ in $\mathcal{I}$. Thus $\phi_0(\bar{C}(X)) = \sum_{g \in \mathcal{I}} C_g$ implying that $\bar{C}(X)$ is the extended codeword of $C(X)$ if and only if $\phi_0(\bar{C}(X)) = 0$. In particular, if $\bar{C}$ is extended cyclic, then $\phi_0(\bar{C}(X)) = 0$ for all $\bar{C}(X) \in \bar{C}$. What is $\phi_s(\bar{C}(X))$ when $1 \le s \le n - 1$? As $0^b = 0$ in $\mathcal{I}$,

$$
\phi_s(\bar{C}(X)) = \sum_{i=0}^{n-1} C_{a^i}(a^i)^s = \sum_{i=0}^{n-1} C_{a^i}(a^s)^i = \sum_{i=0}^{n-1} C_i(a^s)^i = c(a^s), \quad (4.11)
$$

where $c(x)$ is the polynomial in $\mathcal{R}_n$ associated to $C(X)$ in $\mathbb{F}_q[\mathcal{I}^*]$. Suppose our original code $\mathcal{C}$ defined in $\mathcal{R}_n$ had defining set $T$ relative to the $r$th root of unity $\alpha$. Then (4.11) shows that if $1 \le s \le n - 1$, $s \in \bar{T}$ if and only if $\phi_s(\bar{C}(X)) = 0$ for all $\bar{C}(X) \in \bar{C}$. Finally, what is $\phi_0(\bar{C}(X))$? Example (4.11) works in this case as well, implying that $a^0 = 1$ is a zero of $\mathcal{C}$ if and only if $\phi_0(\bar{C}(X)) = 0$ for all $\bar{C}(X) \in \bar{C}$. But $a^0 = a^n = 1$. Hence we have, by Exercise 238, that $0 \in \bar{T}$ if and only if $\phi_0(\bar{C}(X)) = 0$ for all $\bar{C}(X) \in \bar{C}$. We can now describe an extended cyclic code in terms of a defining set as follows: a code $\bar{C}$ of length $q'$ is an extended cyclic code with defining set $\bar{T}$ provided $\bar{T} \subseteq \bar{\mathcal{N}}$ is a union of $q$-cyclotomic cosets modulo $n = q' - 1$ with $0 \in \bar{T}$ and

$$
\bar{C} = \{ \bar{C}(X) \in \mathbb{F}_q[\mathcal{I}] \mid \phi_s(\bar{C}(X)) = 0 \text{ for all } s \in \bar{T} \}. \quad (4.12)
$$

We make several remarks.

+   - 0 and $n$ are in $\bar{T}$ and each is its own $q$-cyclotomic coset.
+   - $0 \in \bar{T}$ because we need all codewords in $\bar{C}$ to be even-like.
+   - If $n \in \bar{T}$, then $\phi_n(\bar{C}(X)) = \sum_{g \in \mathcal{I}} C_g = 0$. As the extended codeword is even-like, since $0 \in \bar{T}$, $\sum_{g \in \mathcal{I}} C_g = 0$. Thus the extended coordinate is always 0, a condition that makes the extension trivial.
+   - The defining set $\bar{T}$ of $\bar{C}$ and the defining set $\bar{T}$ are closely related: $\bar{T}$ is obtained by taking $T$, changing 0 to $n$ if $0 \in T$, and adding 0.
