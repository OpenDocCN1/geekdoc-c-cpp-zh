Let C be an (n, c, r) binary low density parity check code with m x n parity check matrix H. A Tanner graph T for C can be formed. Number the variable nodes 1, 2, ..., n and the check nodes 1, 2, ..., m. Every variable node is connected to c check nodes and every check node is connected to r variable nodes. Let V(j) denote the r variable nodes connected to the jth check node; the set V(j) \ s is V(j) excluding the variable node s. Let C(k) denote the c check nodes connected to the kth variable node; the set C(k) \ t is C(k) excluding the check node t.
Suppose the codeword c is transmitted and y = c + e is received, where e is the unknown error vector. Given the syndrome $H y^T = H e^T = z^T$, the object of the decoder is to compute prob(ek = 1 | z) for 1 <= k <= n.

From there, the most likely error vector and hence most likely codeword can be found. The algorithm computes, in an iterative manner, two probabilities associated to each edge of the Tanner graph and each e = [0, 1]. The first probability qjk^C for j e C(k) and e e {0, 1} is the probability that ek = e given information obtained from checks C(k) \ j. The second probability rjk^C for k e V(j) and e e {0, 1} is the probability that the jth check is satisfied given ek = e and the other bits ei for i e V(j) \ k have probability distribution given by {qij^0, qij^1}.
