# Theorem 13.4.1 Let \( D \) be a divisor on a projective curve \( \mathcal{X} \). The following hold:

+   (i) If \( \text{deg}(D) < 0 \), then \( L(D) = \{0\} \).
+   (ii) The constant functions are in \( L(D) \) if and only if \( D \ge 0 \).
+   (iii) If \( P \) is a point on \( \mathcal{X} \) with \( P \notin \text{supp}(D) \), then \( P \) is not a pole of any \( f \in L(D) \).

Proof: For (i), if \( f \in L(D) \) with \( f \not\equiv_{\mathcal{X}} 0 \), then \( \text{div}(f) + D \ge 0 \). In particular, \( \text{deg}(\text{div}(f) + D) \ge 0 \); but \( \text{deg}(\text{div}(f) + D) = \text{deg}(\text{div}(f)) + \text{deg}(D) = \text{deg}(D) \), contradicting \( \text{deg}(D) < 0 \).

Let \( f \not\equiv_{\mathcal{X}} 0 \) be a constant function. If \( f \in L(D) \) then \( \text{div}(f) + D \ge 0 \). But \( \text{div}(f) = 0 \) when \( f \) is a constant function. So \( D \ge 0 \). Conversely, if \( D \ge 0 \), then \( \text{div}(f) + D \ge 0 \) provided \( \text{div}(f) = 0 \), which is the case if \( f \) is a constant function. This proves (ii).

For (iii), if \( P \) is a pole of \( f \in L(D) \) with \( P \notin \text{supp}(D) \), then the coefficient of \( P \) in the divisor \( \text{div}(f) + D \) of \( \mathcal{X} \) is negative, contradicting the requirement that \( \text{div}(f) + D \) is effective for \( f \in L(D) \).
