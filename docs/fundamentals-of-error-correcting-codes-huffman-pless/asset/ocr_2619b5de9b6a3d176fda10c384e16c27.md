# **Theorem 1.11.6** Let \(C\) be an \([n, k, d]\) code. If a codeword \(\mathbf{c}\) is sent and \(\mathbf{y}\) is received where \(v\) errors and \(\epsilon\) erasures have occurred, then \(\mathbf{c}\) is the unique codeword in \(C\) closest to \(\mathbf{y}\) provided \(2v + \epsilon < d\).
