$e \in \{0, 1\}$ used in the algorithm that come directly from the channel statistics. For example, if communication is over a binary symmetric channel with crossover probability $\rho$, then $p_k^0 = 1 - \rho$ and $p_k^1 = \rho$. The probabilities $\text{prob}(z_j | e_k = e), (e_j \in V(j) \backslash k)$ for $k \in V(j)$ and $e \in \{0, 1\}$ are also required by the algorithm. These probabilities can be computed efficiently with an algorithm similar to the Two-Way APP Algorithm of Section 15.4.

The Sum-Product Decoding Algorithm for binary LDPC codes is the following.

+   I. Initially, set $q_{jk}^0 = p_k^e$ for $j \in C(k)$ and $e \in \{0, 1\}$.
+   II. Update the values of $r_{jk}^e$ for $j \in V(j)$ and $e \in \{0, 1\}$ according to the equation
+   $$r_{jk}^e = \sum_{e_i \in \{0, 1\}: (\forall i) V(j) \backslash k} \text{prob}(z_j | e_k = e, (e_i | i \in V(j) \backslash k)) \prod_{i \in V(j) \backslash k} q_{ji}^{e_i}.$$
+   III. Update the values of $q_{jk}^e$ for $j \in C(k)$ and $e \in \{0, 1\}$ according to the equation
+   $$q_{jk}^e = a_{jk} p_k^e \prod_{i \in C(k) \backslash j} r_{ik}^e,$$
+   where $a_{jk}$ is chosen so that $q_{jk}^0 + q_{jk}^1 = 1$.
+   IV. For $j \in C(k)$ and $e \in \{0, 1\}$ compute
+   $$q_k^e = p_k^e \prod_{j \in C(k)} r_{jk}^e.$$
+   V. For $1 \le k \le n$, set $\hat{\mathbf{e}}_k = 0$ if $q_k^0 > q_k^1$ and $\hat{\mathbf{e}}_k = 1$ if $q_k^1 > q_k^0$. Let $\hat{\mathbf{e}} = \hat{e}_1 \cdots \hat{e}_n$. If $H\hat{\mathbf{e}}^T = \mathbf{z}^T$, decide by setting $\mathbf{e} = \hat{\mathbf{e}}$. Otherwise repeat II, III, and IV up to some maximum number of iterations. Declare a decoding failure if $H\hat{\mathbf{e}}^T$ never equals $\mathbf{z}^T$.

If the Tanner graph $\mathcal{T}$ is without cycles and the algorithm successfully halts, then the probabilities in (15.26) are exactly $\alpha_k q_k^e$, where $\alpha_k$ is chosen so that $\alpha_k q_k^0 + \alpha_k q_k^1 = 1$. If the graph has cycles, these probabilities are approximations to (15.26). In the end, we do not care exactly what these probabilities are; we only care about obtaining a solution to $H\mathbf{e}^T = \mathbf{z}^T$. Thus the algorithm can be used successfully even when there are long cycles present. The algorithm is successful for codes of length a few thousand, say $n = 10\,000$, particularly with $c$ small, say $c = 3$. Analysis of the algorithm can be found in [211].

# 15.7 Turbo codes

Turbo codes were introduced in 1993 by Berrou, Glavieux, and Thitimajshima [20]. A *turbo code* consists of a parallel concatenated encoder to which an iterative decoding scheme is applied.
