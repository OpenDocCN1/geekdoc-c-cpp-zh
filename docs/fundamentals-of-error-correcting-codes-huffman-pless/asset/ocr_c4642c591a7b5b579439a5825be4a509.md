As $\sum_{j \in J_1} h^j$ and $\sum_{j \in J_2} h^j$ are syndromes of $\mathcal{C}$ and $ho(\mathcal{C}) = ho$, there exist sets $I_1$ and $I_2$ of cardinality at most $ho$ such that

The *chromatic number* of $G$ is the smallest integer $\chi(G)$ for which $G$ has a coloring using a set $C$ containing $\chi(G)$ colors. The chromatic number of $K(n, r + 1)$ has been determined by Lovász [208]:

```
$$\chi(K(n, r + 1)) = n - 2r \quad \text{if } n \ge 2r + 2.$$ (11.19)
```
