We know that codewords in $\mathcal{C}_q(A)$ whose supports are blocks have weight $k$. A natural question is to ask whether codewords of weight $k$ exist whose supports are not blocks; this becomes even more interesting when $k$ is the minimum weight of the code. We begin our investigation of this question with a lemma found in [187].

# **Lemma 8.5.4** Let $(\mathcal{P}, \mathcal{B})$ be a symmetric $2-(v, k, \lambda)$ design. Let $S \subset \mathcal{P}$ with $|S| = k$. Suppose that $S$ meets all blocks of $\mathcal{B}$ in at least $\lambda$ points. Then $S$ is a block.

**Proof:** For all $B \in \mathcal{B}$, let $n_B = |S \cap B| - \lambda$; by assumption $n_B$ is a nonnegative integer. Also,

```
\(\sum_{B \in \mathcal{B}} n_B = \sum_{B \in \mathcal{B}} |S \cap B| - v\lambda.\) (8.5)
```

Let $\mathcal{X} = \{(x, B) \mid B \in \mathcal{B}, x \in S \cap B\}$. If $x \in S$, $x$ is in $k$ blocks $B$ by Lemma 8.5.1. Thus $|\mathcal{X}| = k^2$. But for every block $B \in \mathcal{B}$, there are $|S \cap B|$ points $x \in S \cap B$. So $|\mathcal{X}| = \sum_{B \in \mathcal{B}} |S \cap B| = k^2$. Thus $\sum_{B \in \mathcal{B}} |S \cap B| = k^2$ implying from (8.5) and Lemma 8.5.1 that

```
\(\sum_{B \in \mathcal{B}} n_B = k - \lambda.\) (8.6)
```

Let $\mathcal{Y}' = \{(x, y, B) \mid B \in \mathcal{B}, x, y \in S \cap B, x \neq y\}$. There are $k(k-1)$ ordered pairs of elements in $S$ each in exactly $\lambda$ blocks. Thus $|\mathcal{Y}'| = k(k-1)\lambda$. But for every block $B \in \mathcal{B}$, there are $|S \cap B|(|S \cap B| - 1) = (n_B + \lambda)(n_B + \lambda - 1)$ pairs of points in $S \cap B$. Thus

```
\(\sum_{B \in \mathcal{B}} (n_B + \lambda)(n_B + \lambda - 1) = k(k-1)\lambda.\)
```

Expanding the left-hand side and using (8.6), we obtain (see Exercise 460)

```
\(\sum_{B \in \mathcal{B}} n_B^2 = (k - \lambda)^2.\) (8.7)
```

As the $n_B$ are nonnegative integers, by (8.6) and (8.7), the only possibility is $n_B = 0$ for all but one $B$ and $n_B = k - \lambda$ for this one $B$, but then $|S \cap B| = k$, implying $S = B$.

# **Theorem 8.5.5** Let $(\mathcal{P}, \mathcal{B})$ be a symmetric $2-(v, k, \lambda)$ design with incidence matrix $A$. Let $p > k$ be a prime dividing $k - \lambda$. Suppose $\mathbb{F}_q$ has characteristic $p$. Finally, let $S \subset \mathcal{P}$ have size $k$. If $c_S \in \mathcal{C}_q(A)$, then $S$ is a block in $\mathcal{B}$.

**Proof:** As $c_S \in \mathcal{C}_q(A)$ and $\mathcal{C}_q(A)$ is generated by $\{c_B \mid B \in \mathcal{B}\}$, $c_S = \sum_{B \in \mathcal{B}} a_B c_B$ for $a_B \in \mathbb{F}_q$. Let $B'$ be a block in $\mathcal{B}$. Then

```
\(c_S \cdot c_{B'} = \sum_{B \in \mathcal{B}} a_B c_B \cdot c_{B'}.\) (8.8)
```
