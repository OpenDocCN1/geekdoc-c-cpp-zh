## 11.6 Covering radius of subcodes

The relationship between the covering radius of a code and that of a subcode can be quite complex. Recall by Exercise 618 that if \(\mathcal{C}_0 \subseteq \mathcal{C}\), then \(\rho(\mathcal{C}) \le \rho(\mathcal{C}_0)\). However, it is not clear how large the covering radius of \(\rho(\mathcal{C}_0)\) can be compared with \(\rho(\mathcal{C})\). The next two examples give extremes for these possibilities.

Example 11.6.1 In this example we show how the covering radius of a subcode \(\mathcal{C}_0\) could be as small as the covering radius of the original code. Let \(H_1\) be a parity check matrix of a binary code with covering radius \(\rho\), and let \(\mathcal{C}\) be the code with parity check matrix given by \(H = [ H_1 \ H_1 ]\). Clearly, \(\rho(\mathcal{C}) = \rho\) as the list of columns of \(H\) is the same as the list of columns of \(H_1\). Let \(\mathcal{C}_0\) be the subcode of codimension 1 in \(\mathcal{C}\) with parity check matrix
\(\begin{bmatrix} H_1 & H_1 \\ 0 & \cdots & 0 & 1 & \cdots & 1 \end{bmatrix}.\)
We also have \(\rho(\mathcal{C}_0) = \rho\), as Exercise 656 shows.

Example 11.6.2 In this example we find a subcode \(\mathcal{C}_0\) of codimension 1 of a code \(\mathcal{C}\) where \(\rho(\mathcal{C}_0) = 2\rho(\mathcal{C}) + 1\). In the next theorem we will see that this is as large as possible. Let \(H'_m\) be the \(m \times (2^m - 2)\) matrix obtained from \(H_m\) by deleting its column of all 1s. Let \(r\) be a positive integer. Then the \(rm \times (r(2^m - 2) + 1)\) matrix

### Theorem 11.6.3 (Adams Bound) Let \(\mathcal{C}_0\) be a subcode of codimension 1 in a binary linear code \(\mathcal{C}\). Then

\(\rho(\mathcal{C}_0) \le 2\rho(\mathcal{C}) + 1.\) (11.14)

**Proof:** Suppose that \(\mathcal{C}\) is an \([n, n-m]\) code. Let \(H\) be an \(m \times n\) parity check matrix for \(\mathcal{C}\). We can add one row \(\mathbf{v} = v_1 \cdots v_n\) to \(H\) to form an \((m+1) \times n\) parity check matrix

\(H_0 = \begin{bmatrix} H \\ \mathbf{v} \end{bmatrix}\) (11.15)

For \(\mathcal{C}_0\), for \(j = 1, 2, \dots, n\), let the columns of \(H_0\) and \(H\) be denoted \(h_0^j\) and \(h^j\), respectively. Let \(\rho = \rho(\mathcal{C})\) and \(\rho_0 = \rho(\mathcal{C}_0)\). Assume (11.14) is false; so \(\rho_0 \ge 2\rho + 2\). There is a syndrome \(s_0 \in \mathbb{F}_2^{m+1}\) of \(\mathcal{C}_0\) which is the sum of \(\rho_0\) columns of \(H_0\) but no fewer. Rearrange the columns of \(H_0\) so that

\(s_0^T = \sum_{j=1}^{\rho_0} h_0^j.\) (11.16)

Partition \(\{1, 2, \dots, \rho_0\}\) into two disjoint sets \(J_1\) and \(J_2\) of cardinality at least \(\rho + 1\); this can be done since \(\rho_0 \ge 2\rho + 2\). Hence (11.16) becomes

$$s_0^T = \sum_{j \in J_1} h_0^j + \sum_{j \in J_2} h_0^j.$$ (11.17)

As \(\sum_{j \in J_1} h^j\) and \(\sum_{j \in J_2} h^j\) are syndromes of \(\mathcal{C}\) and \(\rho(\mathcal{C}) = \rho\), there exist sets \(I_1\) and \(I_2\) of cardinality at most \(\rho\) such that

$$\sum_{j \in J_1} h^j = \sum_{j \in I_1} h^j \quad \text{and} \quad \sum_{j \in J_2} h^j = \sum_{j \in I_2} h^j.$$ (11.18)

Suppose that \(\sum_{j \in J_1} v_j = \sum_{j \in J_1} v'_j\); then \(\sum_{j \in J_1} h_0^j = \sum_{j \in J_1} h'_0^j\), and we can replace \(\sum_{j \in J_1} h_0^j\) in (11.17) by \(\sum_{j \in J_1} h'_0^j\). Therefore we have expressed \(s_0^T\) as a linear combination of fewer than \(\rho_0\) columns of \(H_0\), which is a contradiction. A similar contradiction arises if \(\sum_{j \in J_2} v_j = \sum_{j \in J_2} v'_j\). The remaining possibility is \(\sum_{j \in J_1} v_j \ne \sum_{j \in J_1} v'_j\) and \(\sum_{j \in J_2} v_j \ne \sum_{j \in J_2} v'_j\). However, then \(\sum_{j \in J_1} v_j + \sum_{j \in J_2} v_j = \sum_{j \in J_1} v'_j + \sum_{j \in J_2} v'_j\); hence by (11.18) \(\sum_{j \in J_1} h_0^j + \sum_{j \in J_2} h_0^j = \sum_{j \in J_1} h'_0^j + \sum_{j \in J_2} h'_0^j\), and again we have expressed \(s_0^T\) as a linear combination of fewer than \(\rho_0\) columns of \(H_0\), a contradiction.

### Theorem 11.6.4 Let \(\mathcal{C}_0\) be a subcode of codimension \(i\) in a binary linear code \(\mathcal{C}\). Then \(\rho(\mathcal{C}_0) \le (i + 1)\rho(\mathcal{C}) + 1\).

Furthermore, if \(\mathcal{C}\) is even, then \(\rho(\mathcal{C}_0) \le (i + 1)\rho(\mathcal{C})\).

Another upper bound on the covering radius of a subcode in terms of the covering radius of the original code, due to Calderbank [43], is sometimes an improvement of Theorem 11.6.4. Before stating this result, we need some additional terminology. A graph \(G\) is a pair consisting of a set \(V\), called vertices, and a set \(E\) of unordered pairs of vertices, called edges. A coloring of \(G\) with a set \(C\) of colors is a map \(f : V \to C\) such that \(f(x) \ne f(y)\) whenever \(\{x, y\}\) is an edge; that is, two vertices on the same edge do not have the same color, where the *color* of a vertex \(x\) is \(f(x)\). The *chromatic number* of \(G\) is the smallest integer \(\chi(G)\) for which \(G\) has a coloring using a set \(C\) containing \(\chi(G)\) colors. We are interested in a specific graph called the *Kneser graph* \(K(n, r + 1)\). The vertex set of \(K(n, r + 1)\) is \(\{v \in \mathbb{F}_2^n \mid \text{wt}(v) = r + 1\}\), with vertices \(u\) and \(v\) forming an edge if and only if their supports are disjoint. The chromatic number of \(K(n, r + 1)\) has been determined by Lovász [208]:

$$\chi(K(n, r + 1)) = n - 2r \quad \text{if } n \ge 2r + 2.\) (11.19)
