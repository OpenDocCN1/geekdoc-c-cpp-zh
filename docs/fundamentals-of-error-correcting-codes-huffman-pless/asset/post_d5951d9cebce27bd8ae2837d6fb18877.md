
\[
\sum_{j=0}^n j^3 A_j = q^{k-3}[(q-1)n(q^2n^2 - 2qn^3 + 3qn - q + n^2 - 3n + 2) - (3q^2n - 3q^2n - 6qn^2 + 12qn + q^2 - 6q + 3n^2 - 9n + 6)A_1^+ + 6(qn - q - n + 2)A_2^+ - 6A_4^+],\quad (7.7)
\]

\[
\sum_{j=0}^n j^4 A_j = q^{k-4}[(q-1)n(n^3 - 3q^2n^3 + 6q^2n - q^4n + q^2 + 3qn^3 - 12qn^2 + 15qn - 6q - n^3 + 6n^2 - 11n + 6) + (4q^3n^3 - 6q^2n^2 + 4q^3n - q^3 - 12q^2n^2 + 36q^2n^2 - 38q^2n + 14q^2 + 12qn^2 - 54qn^2 + 78qn - 36q - 4n^3 + 24n^2 - 44n + 24)A_1^+ + (12q^2n^3 - 24q^2n + 14q^2 - 24qn^2 + 84qn - 72q + 12n^2 - 60n + 72)A_2^+ - (24qn - 36q - 24n + 72)A_3^+ + 24A_4^+].
\]

In the binary case these become:

\[
\sum_{j=0}^n A_j = 2^k,
\]

\[
\sum_{j=0}^n j A_j = 2^{k-1}(n - A_1^+),
\]

\[
\sum_{j=0}^n j^2 A_j = 2^{k-2}[n(n+1) - 2nA_1^+ + 2A_2^+],\quad (7.8)
\]

\[
\sum_{j=0}^n j^3 A_j = 2^{k-3}[n^2(n+3) - (3n^2 + 3n - 2)A_1^+ + 6nA_2^+ - 6A_4^+],
\]

\[
\sum_{j=0}^n j^4 A_j = 2^{k-4}[n(n+1)(n^2 + 5n - 2) - 4n(n^2 + 3n - 2)A_1^+ + 4(3n^2 + 3n - 4)A_2^+ - 24nA_3^+ + 24A_4^+].
\]

To conclude this section, we use (7.7) to produce an interesting result about ternary codes, due to Kennedy [164].

### Theorem 7.5
Let $C$ be an $[n, k]$ ternary code with $k \ge 3$ and weight distribution $A_0, A_1, \dots, A_n$. For $0 \le i \le 2$, let

\[
N_i = \sum_{j \equiv i \pmod{3}} A_j.
\]

Then $N_0 = N_1 = N_2 = 0 \pmod{3}$.

Proof: Because $k \ge 3$, the first three equations of (7.7) with $q = 3$ yield

\[
N_0 + N_1 + N_2 \equiv \sum_{i=0}^n A_i \equiv 0 \pmod{3},
\]

\[
N_1 - N_2 \equiv \sum_{i=0}^n i A_i \equiv 0 \pmod{3},
\]

\[
N_1 + N_2 \equiv \sum_{i=0}^n i^2 A_i \equiv 0 \pmod{3}.
\]

since $i = 0, 1,$ or $-1$ and $i^2 = 0$ or $1$ modulo $3$. The only solution modulo $3$ is $N_0 = N_1 = N_2 = 0 \pmod{3}$.

## 7.4 MDS codes

In this section, we show that the weight distribution of an $[n, k]$ MDS code over $\mathbb{F}_q$ is determined by the parameters $n, k,$ and $q$. One proof of this uses the MacWilliams equations; see [275]. We present a proof here that uses the inclusion-exclusion principle.

### Theorem 7.4.1
Let $C$ be an $[n, k, d]$ MDS code over $\mathbb{F}_q$. The weight distribution of $C$ is given by $A_0 = 1$, $A_i = 0$ for $1 \le i < d$, and

\[
A_i = \binom{n}{i} \sum_{j=0}^{i-d} (-1)^j \binom{i}{j} (q^{i-j+1-d} - 1)
\]

for $d \le i \le n$, where $d = n - k + 1$.

Proof: Clearly, $A_0 = 1$ and $A_i = 0$ for $1 \le i < d$. Let $C_T$ be the code of length $n - |T|$ obtained from $C$ by shortening on $T$. By repeated application of Exercise 317, $C_T$ is an $[n - |T|, k - |T|]$ MDS code if $|T| < k$ and $C_T$ is the zero code if $|T| \ge k$. Let $C(T)$ be the subcode of $C$ which is zero on $T$. Then $C_T$ is $C(T)$ punctured on $T$. In particular

\[
|C(T)| = \left\{ \begin{array}{ll } q^{k-t} & \text{if } t=|T| < k, \\ 1 & \text{if } t=|T| \ge k. \end{array} \right.
\]

and $C(T)$ is the set of codewords of $C$ whose support is disjoint from $T$. For $0 \le t \le n$, define

\[
N_t = \sum_{|T|=t} |C(T)|.
\]

By (7.9),

\[
N_t = \left\{ \begin{array}{ll } \binom{n}{t} q^{k-t} & \text{if } t=|T| < k, \\ \binom{n}{t} & \text{if } t=|T| \ge k. \end{array} \right.
\]

Note that $N_t$ counts the number of codewords of $C$ that have weight $n-t$ or less, with a codeword multiply counted, once for every $C(T)$ it is in. By the inclusion-exclusion principle [204], for $d \le i \le n$,

\[
A_i = \sum_{j=0}^{i} (-1)^j \binom{n-i+j}{j} N_{n-i+j}.
\]

By (7.10),

\[
\begin{array}{ r c l }
A_i & = & \sum_{j=0}^{k+i-n-1} (-1)^j \binom{n-i+j}{j} \binom{n}{n-i+j} q^{k-(n-i+j)} \\
& + & \sum_{j=k+i-n}^{i} (-1)^j \binom{n-i+j}{j} \binom{n}{n-i+j} \\
& = & \binom{n}{i} \left[ \sum_{j=0}^{i-d} (-1)^j \binom{i}{j} q^{i+1-d-j} + \sum_{j=i-d+1}^{i} (-1)^j \binom{i}{j} \right],
\end{array}
\]

as $d = n-k+1$ and $\binom{n-i+j}{n-i} = \binom{n-i+j}{j}$. As

\[
-\sum_{j=0}^{i-d} (-1)^j \binom{i}{j} = \sum_{j=i-d+1}^{i} (-1)^j \binom{i}{j}.
\]

the result follows.
