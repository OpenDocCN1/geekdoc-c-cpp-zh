# 8.2 Intersection numbers

There are other integers associated with a $t$-design $(\mathcal{P}, \mathcal{B})$ that describe certain intersection properties of the design. Let $I$ and $J$ be subsets of $\mathcal{P}$ where $I \cap J = \emptyset$. Suppose that $|I| = i$ and $|J| = j$. Denote the number of blocks in $\mathcal{B}$ that contain $I$ and are disjoint from $J$ by $\lambda_j^i$. The next theorem shows that $\lambda_j^i$ is independent of the choice of $I$ and $J$ provided $i + j \le t$. We will also see in this theorem that these numbers satisfy a recursion reminiscent of the one satisfied by binomial coefficients. These numbers are called *intersection numbers* for the design. Certain of the intersection numbers have specific meaning:

+   - $\lambda_0^j$ is the number $b$ of blocks,
+   - $\lambda^0 = \lambda_i$, and
+   - $\lambda_j^t$ is the number of blocks not intersecting a given set of points of size $j$.

# Theorem 8.2.1

Let $(\mathcal{P}, \mathcal{B})$ be a $t-(v, k, \lambda)$ design. Let $I$ and $J$ be disjoint subsets of $\mathcal{P}$ of size $i$ and $j$, respectively. If $i + j \le t$, $\lambda_j^i$ is independent of $I$ and $J$, and for $j \ge 1$,

$\lambda_j^i = \lambda_j^{i-1} - \lambda_{j+1}^{i-1}$. (8.1)

Also

$\lambda_j^t = \lambda \frac{\binom{v-i-j}{k-i}}{\binom{v-t}{k-t}}$. (8.2)
