# Theorem 6.6.5 Let $p$ be an odd prime. The following hold:

+   (i) Binary quadratic residue codes of length $p$ exist if and only if $p \equiv \pm 1 (\text{mod } 8)$.

+   (ii) The even-like binary quadratic residue codes have generating idempotents
+   \(\delta + \sum_{j \in Q_p} x^j \text{ and } \delta + \sum_{j \in N_p} x^j\).
+   where \(\delta = 1\) if \(p \equiv -1 (\text{mod } 8)\) and \(\delta = 0\) if \(p \equiv 1 (\text{mod } 8)\).

+   (iii) The odd-like binary quadratic residue codes have generating idempotents
+   \(\epsilon + \sum_{j \in Q_p} x^j \text{ and } \epsilon + \sum_{j \in N_p} x^j\).
+   where \(\epsilon = 0\) if \(p \equiv -1 (\text{mod } 8)\) and \(\epsilon = 1\) if \(p \equiv 1 (\text{mod } 8)\).

Proof: Binary QR codes of length $p$ exist if and only if $2 \in Q_p$ by Theorem 6.6.2, which is equivalent to $p \equiv \pm 1 (\text{mod } 8)$ by Lemma 6.2.5, giving (i). Let $e(x)$ be a generating idempotent of one of the QR codes. By Theorem 6.6.3,

\(e(x) = \sum_{j \in S} x^j\),

where $S$ is a union of some of $\{0\}$, $Q_p$, and $\mathcal{N}_p$. As the cases $S = \{0\}$, $Q_p \cup \mathcal{N}_p$, and $\{0\} \cup Q_p \cup \mathcal{N}_p$ yield trivial codes by Exercise 362, for QR codes, $S$ equals $\{0\} \cup Q_p$, $\{0\} \cup \mathcal{N}_p$, $Q_p$, or $\mathcal{N}_p$. These yield the idempotents in (ii) and (iii); one only needs to check that their weights are even or odd as required.

# Exercise 362 Prove that if $C$ is a binary cyclic code of length $p$ with generating idempotent $e(x) = \sum_{i \in S} x^i$ where $S = \{0\}$, $Q_p \cup \mathcal{N}_p$, or $\{0\} \cup Q_p \cup \mathcal{N}_p$, then $C$ is the code $\mathbb{F}_2^p$, the even subcode $\mathcal{E}_p^2$, or the subcode generated by the all-one vector.

Because $4 = 2^2$ is obviously a square modulo any odd prime $p$, by Theorem 6.6.2, QR codes over $\mathbb{F}_4$ exist for any odd prime length. The idempotents for the QR codes over $\mathbb{F}_4$ of length $p \equiv \pm 1 (\text{mod } 8)$ are the same as the binary idempotents given in Theorem 6.6.5 by Theorem 6.6.4. We now find the generating idempotents for the QR codes over $\mathbb{F}_4$ of length $p$ where $p \equiv \pm 3 (\text{mod } 8)$. (Recall that $\mathbb{F}_4 = \{0, 1, \omega, \overline{\omega}\}$, where $\overline{\omega} = 1 + \omega = \omega^2$.)

# Theorem 6.6.6 Let $p$ be an odd prime. The following hold:

+   (i) If $p \equiv \pm 1 (\text{mod } 8)$, the generating idempotents of the quadratic residue codes over $\mathbb{F}_4$ are the same as those over $\mathbb{F}_2$ given in Theorem 6.6.5.

+   (ii) The even-like quadratic residue codes over $\mathbb{F}_4$ have generating idempotents
+   \(\delta + \omega \sum_{j \in Q_p} x^j + \overline{\omega} \sum_{j \in N_p} x^j \text{ and } \delta + \overline{\omega} \sum_{j \in Q_p} x^j + \omega \sum_{j \in N_p} x^j\).
+   where \(\delta = 0\) if \(p \equiv -3 (\text{mod } 8)\) and \(\delta = 1\) if \(p \equiv 3 (\text{mod } 8)\).

+   (iii) The odd-like quadratic residue codes over $\mathbb{F}_4$ have generating idempotents
+   \(\epsilon + \omega \sum_{j \in Q_p} x^j + \overline{\omega} \sum_{j \in N_p} x^j \text{ and } \epsilon + \overline{\omega} \sum_{j \in Q_p} x^j + \omega \sum_{j \in N_p} x^j\).
+   where \(\epsilon = 1\) if \(p \equiv -3 (\text{mod } 8)\) and \(\epsilon = 0\) if \(p \equiv 3 (\text{mod } 8)\).
