In constructing the Kerdock codes, we will use the relative trace function from \(\text{GR}(4^r)\) into \(\mathbb{Z}_4\), which is analogous to the trace function from \(\mathbb{F}_{2^r}\) into \(\mathbb{F}_2\). Recall that the trace function \(\text{Tr}_r : \mathbb{F}_{2^r} \to \mathbb{F}_2\) is given by

\(\text{Tr}_r(\alpha) = \sum_{i=0}^{r-1} \alpha^{2^i} = \sum_{i=0}^{r-1} \sigma_0^i(\alpha) \quad \text{for } \alpha \in \mathbb{F}_{2^r},\)

where \(\sigma_0\) is the Frobenius automorphism of \(\mathbb{F}_{2^r}\). The relative trace function \(\text{TR}_r : \text{GR}(4^r) \to \mathbb{Z}_4\) is given by

\(\text{TR}_r(\alpha) = \sum_{i=0}^{r-1} \nu_2^i(\alpha) \quad \text{for } \alpha \in \text{GR}(4^r).\)

By Exercise 753, \(\text{TR}_r(\alpha)\) is indeed an element of \(\mathbb{Z}_4\). By Lemma 3.8.5, \(\text{Tr}_r\) is a surjective map; analogously, \(\text{TR}_r\) is a surjective map.
