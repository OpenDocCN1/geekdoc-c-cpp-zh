subcode of C which is zero on T. Then C_T is C(T) punctured on T. In particular

```
\(|C(T)| = \left\{ \begin{array}{ll } q^{t-i} & \text{if } t=|T| < k, \\ 1 & \text{if } t=|T| \ge k. \end{array} \right.\)
```

and C(T) is the set of codewords of C whose support is disjoint from T. For \(0 \le t \le n\), define

```
\(N_t = \sum_{|T|=t} |C(T)|.\)
```

By (7.9),

```
\(N_t = \left\{ \begin{array}{ll } \binom{n}{t} q^{k-t} & \text{if } t=|T| < k, \\ \binom{n}{t} & \text{if } t=|T| \ge k. \end{array} \right.\)
```

Note that \(N_t\) counts the number of codewords of C that have weight \(n-t\) or less, with a codeword multiply counted, once for every C(T) it is in. By the inclusion-exclusion principle [204], for \(d \le i \le n\),

```
\(A_i = \sum_{j=0}^{i} (-1)^j \binom{n-i+j}{j} N_{n-i+j}.\)
```

By (7.10),

```
\(\begin{array}{ r c l } A_i & = & \sum_{j=0}^{k+i-n-1} (-1)^j \binom{n-i+j}{j} \binom{n}{n-i+j} q^{k-(n-i+j)} \\ & + & \sum_{j=k+i-n}^{i} (-1)^j \binom{n-i+j}{j} \binom{n}{n-i+j} \\ & = & \binom{n}{i} \left[ \sum_{j=0}^{i-d} (-1)^j \binom{i}{j} q^{i+1-d-j} + \sum_{j=i-d+1}^{i} (-1)^j \binom{i}{j} \right], \end{array}\)
```

as \(d = n-k+1\) and \(\binom{n-i+j}{n-i} = \binom{n-i+j}{j}\). As

```
\(-\sum_{j=0}^{i-d} (-1)^j \binom{i}{j} = \sum_{j=i-d+1}^{i} (-1)^j \binom{i}{j}.\)
```

the result follows.
