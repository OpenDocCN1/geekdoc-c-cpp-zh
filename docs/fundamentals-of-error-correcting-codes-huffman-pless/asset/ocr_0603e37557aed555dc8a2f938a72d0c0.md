**Theorem 2.7.7** Let \(\mathcal{C}\) be an \([n, k, d]\) binary code with \(h = n - g(k, d)\). Then \(\mathcal{C}\) has a basis of codewords of weight at most \(d + h\).

**Proof:** We proceed by induction on \(h\). The case \(h = 0\) is covered by Theorem 2.7.6. For fixed \(h\), proceed by induction on \(k\). In the case \(k = 1\), there certainly is a basis of one codeword of weight \(d\). When \(k > 1\) assume that \(\mathbf{c}\) is a codeword of weight \(d\). By permuting coordinates, we may assume that \(\mathcal{C}\) has a generator matrix

```
\(\displaystyle G = \left[ \begin{array}{c|c} \begin{array}{ccc} 1 & \cdots & 1 \\ \vdots & & \vdots \\ G_0 & & G_1 \end{array} & \begin{array}{c} 0 \\ \vdots \\ 0 \end{array} \end{array} \right]\)
```

where the first row is \(\mathbf{c}\) and \(G_1\) is a generator matrix of the \([n - d, k - 1, d']\) residual code \(\mathcal{C}_1 = \text{Res}(\mathcal{C}, \mathbf{c})\), \(d' \ge d_1 = \lceil d/2 \rceil\) by Corollary 2.7.2. Let \(d' = d_1 + \epsilon\). Using Exercise 126,

```
\(\displaystyle \begin{aligned} g(k - 1, d') &= \sum_{i=0}^{k-2} \left\lceil \frac{d'}{2^i} \right\rceil = \sum_{i=0}^{k-2} \left\lceil \frac{d_1 + \epsilon}{2^i} \right\rceil \\ \ge \sum_{i=0}^{k-2} \left\lceil \frac{d_1}{2^i} \right\rceil + \sum_{i=0}^{k-2} \left\lceil \frac{\epsilon}{2^i} \right\rceil &= g(k - 1, d_1) + \sum_{i=0}^{k-2} \left\lceil \frac{\epsilon}{2^i} \right\rceil . \end{aligned}\)
```

As part of the proof of Theorem 2.7.6, we in effect showed that \(g(k - 1, d_1) = g(k - 1, \lceil d/2 \rceil) = g(k, d) - d\) (see Exercise 127). As \(h = n - g(k, d)\),

```
\(\displaystyle g(k - 1, d') \ge g(k - 1, d_1) + \sum_{i=0}^{k-2} \left\lceil \frac{\epsilon}{2^i} \right\rceil = n - d + \left( \sum_{i=0}^{k-2} \left\lceil \frac{\epsilon}{2^i} \right\rceil - h \right). \quad (2.41)\)
```

Therefore as \(\mathcal{C}_j\) exists, \(n - d \ge g(k - 1, d')\). Let \(n - d - g(k - 1, d') = h_1 \ge 0\). By (2.41), \(h_1 \le h - \sum_{i=0}^{k-2} \lceil \epsilon/2^i \rceil\). By induction, we may assume the rows of \(G_1\) have weight at most \(d' + h_1\). For \(j \ge 2\), let \(\mathbf{r}_j = (s_{j-1}, \mathbf{t}_{j-1})\) be a row of \(G\), where \(s_{j-1}\) is row \(j - 1\) of \(G_0\) and \(\mathbf{t}_{j-1}\) is row \(j - 1\) of \(G_1\). So

```
\(\displaystyle \text{wt}(\mathbf{t}_{j-1}) \le d' + h_1 \le d_1 + \epsilon + h - \sum_{i=0}^{k-2} \left\lceil \frac{\epsilon}{2^i} \right\rceil \le d_1 + h = \left\lceil \frac{d}{2} \right\rceil + h.\)
```

since \(\epsilon \le \sum_{i=0}^{k-2} \lceil \epsilon/2^i \rceil\). By Exercise 128 one of \(\mathbf{r}_j\) or \(\mathbf{c} + \mathbf{r}_j\) has weight between \(d\) and \(d + h\). Hence \(\mathcal{C}\) has a basis of codewords of weights at most \(d + h\).
