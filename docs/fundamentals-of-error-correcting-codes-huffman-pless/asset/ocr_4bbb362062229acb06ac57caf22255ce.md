# 7.8 Constraints on weights

In this section, we will present constraints on the weights of codewords in even binary codes, where we recall that a binary code is called even if all of its codewords have even weight. The following identity from Theorem 1.4.3 for two vectors x, y \in F_2^n will prove useful:

wt(x + y) = wt(x) + wt(y) - 2wt(x \cap y), (7.15)

where x \cap y is the vector in F_2^n which has 1s precisely in those positions where both x and y have 1s. When the ordinary inner product between two vectors x and y is 0, we say the vectors are orthogonal and denote this by x \perp y.

The following is an easy consequence of (7.15).

# Lemma 7.8.1 Let x and y be two vectors in F_2^n.

+   (i) Suppose wt(x) \equiv 0 (mod 4). Then wt(x + y) \equiv wt(y) (mod 4) if and only if x \perp y, and wt(x + y) \equiv wt(y) + 2 (mod 4) if and only if x \not\perp y.

+   (ii) Suppose wt(x) \equiv 2 (mod 4). Then wt(x + y) \equiv wt(y) (mod 4) if and only if x \not\perp y, and wt(x + y) \equiv wt(y) + 2 (mod 4) if and only if x \perp y.

# Exercise 414 Prove Lemma 7.8.1.

We say that a binary vector is doubly-even if its weight is divisible by 4. A binary vector is singly-even if its weight is even but not divisible by 4. Recall from Theorem 1.4.8 that if a binary code has only doubly-even vectors, the code is self-orthogonal. We will be primarily interested in codes where not all codewords are doubly-even. We will present a decomposition of even binary codes into pieces that are called the hull of the code, H-planes, and A-planes. An H-plane or A-plane is a 2-dimensional space spanned by x and y, such a space is denoted span{x, y}. The hull, H-plane, and A-plane are defined as follows:

+   - The hull of a code C is the subcode H = C \cap C^{\perp}.
+   - If x and y are doubly-even but not orthogonal, then we call span{x, y} an H-plane. Note that if span{x, y} is an H-plane, then wt(x + y) \equiv 2 (mod 4) by Lemma 7.8.1(i), and so an H-plane contains two nonzero doubly-even vectors and one singly-even vector.
+   - If x and y are singly-even but not orthogonal, then we call span{x, y} an A-plane. If span{x, y} is an A-plane, then wt(x + y) \equiv 2 (mod 4) still holds by Lemma 7.8.1(ii); an A-plane therefore contains three singly-even vectors.
