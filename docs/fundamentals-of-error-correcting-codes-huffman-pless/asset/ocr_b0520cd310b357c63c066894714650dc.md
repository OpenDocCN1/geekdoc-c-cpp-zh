$v \le r$, we have $v < j$ if $r < j$, which allows us to stop the outer sum at $\min\{n, r\}$. Thus $(M_2)$ holding implies that $(P)$ holds. The converse follows from the preceding equations if we know that the $n + 1$ equations

```

```

have only the solution $x_0 = x_1 = \dots = x_n = 0$. This is clear as the $(n + 1) \times (n + 1)$ matrix $[a_{r,v}] = [v! S(r, v)]$ is lower triangular by (7.4) with nonzero diagonal entries by (7.5). So $(M_2)$ and $(P)$ are equivalent.
