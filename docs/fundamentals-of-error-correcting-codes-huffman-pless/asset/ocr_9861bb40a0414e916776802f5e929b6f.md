We conclude this chapter with a brief introduction to the Newton radius first defined in [123]. The Newton radius v(C) of a binary code C is the largest value v so that there exists a coset of weight v with only one coset leader. In particular, v(C) is the largest weight of any error that can be uniquely corrected. The first statement in the following lemma is from [123].

+   Lemma 11.7.13 Let C be an [n, k, d] binary code. The following hold:
+   (i) ⌊(d-1)/2⌋ ≤ v(C) ≤ ρ(C).
+   (ii) If C is perfect, (d-1)/2 = v(C) = ρ(C).
+   (iii) If C is even and d > 2, then v(C) < ρ(C).

Proof: Proofs of (i) and (ii) are left as an exercise. Theorem 11.7.10(iii) implies that orphans in even codes have more than one coset leader. In particular, cosets of weight ρ(C) cannot have unique coset leaders.
