
### Theorem 6.6.5 Let $p$ be an odd prime. The following hold:

- (i) Binary quadratic residue codes of length $p$ exist if and only if $p \equiv \pm 1 (\text{mod } 8)$.
- (ii) The even-like binary quadratic residue codes have generating idempotents
  \(\delta + \sum_{j \in Q_p} x^j \text{ and } \delta + \sum_{j \in N_p} x^j\).
  where \(\delta = 1\) if \(p \equiv -1 (\text{mod } 8)\) and \(\delta = 0\) if \(p \equiv 1 (\text{mod } 8)\).
- (iii) The odd-like binary quadratic residue codes have generating idempotents
  \(\epsilon + \sum_{j \in Q_p} x^j \text{ and } \epsilon + \sum_{j \in N_p} x^j\).
  where \(\epsilon = 0\) if \(p \equiv -1 (\text{mod } 8)\) and \(\epsilon = 1\) if \(p \equiv 1 (\text{mod } 8)\).

Proof: Binary QR codes of length $p$ exist if and only if $2 \in Q_p$ by Theorem 6.6.2, which is equivalent to $p \equiv \pm 1 (\text{mod } 8)$ by Lemma 6.2.5, giving (i). Let $e(x)$ be a generating idempotent of one of the QR codes. By Theorem 6.6.3,

\(e(x) = \sum_{j \in S} x^j\),

where $S$ is a union of some of $\{0\}$, $Q_p$, and $\mathcal{N}_p$. As the cases $S = \{0\}$, $Q_p \cup \mathcal{N}_p$, and $\{0\} \cup Q_p \cup \mathcal{N}_p$ yield trivial codes by Exercise 362, for QR codes, $S$ equals $\{0\} \cup Q_p$, $\{0\} \cup \mathcal{N}_p$, $Q_p$, or $\mathcal{N}_p$. These yield the idempotents in (ii) and (iii); one only needs to check that their weights are even or odd as required.

### Theorem 6.6.6 Let $p$ be an odd prime. The following hold:

- (i) If $p \equiv \pm 1 (\text{mod } 8)$, the generating idempotents of the quadratic residue codes over $\mathbb{F}_4$ are the same as those over $\mathbb{F}_2$ given in Theorem 6.6.5.
- (ii) The even-like quadratic residue codes over $\mathbb{F}_4$ have generating idempotents
  \(\delta + \omega \sum_{j \in Q_p} x^j + \overline{\omega} \sum_{j \in N_p} x^j \text{ and } \delta + \overline{\omega} \sum_{j \in Q_p} x^j + \omega \sum_{j \in N_p} x^j\).
  where \(\delta = 0\) if \(p \equiv -3 (\text{mod } 8)\) and \(\delta = 1\) if \(p \equiv 3 (\text{mod } 8)\).
- (iii) The odd-like quadratic residue codes over $\mathbb{F}_4$ have generating idempotents
  \(\epsilon + \omega \sum_{j \in Q_p} x^j + \overline{\omega} \sum_{j \in N_p} x^j \text{ and } \epsilon + \overline{\omega} \sum_{j \in Q_p} x^j + \omega \sum_{j \in N_p} x^j\).
  where \(\epsilon = 1\) if \(p \equiv -3 (\text{mod } 8)\) and \(\epsilon = 0\) if \(p \equiv 3 (\text{mod } 8)\).

Proof: Part (i) follows from Theorem 6.6.4. Let $e(x)$ be a generating idempotent for an even-like QR code $C_1$ over $\mathbb{F}_4$ with $p \equiv \pm 3 \pmod 8$. By Theorem 6.6.3, $e(x) = a_0 + a_1 Q(x) + a_2 N(x)$, where $Q(x) = \sum_{j \in Q_p} x^j$ and $N(x) = \sum_{j \in N_p} x^j$. By Lemma 6.2.5, $2 \in N_p$. This implies that

$Q(x)^2 = Q(x^2) = N(x) \text{ and } N(x)^2 = N(x^2) = Q(x)$

by Lemma 6.6.1. Therefore as $e(x)^2 = a_0^2 + a_1^2 Q(x)^2 + a_2^2 N(x)^2 = a_0^2 + a_1^2 N(x) + a_2^2 Q(x) = e(x)$, $a_0 \in \{0, 1\}$ and $a_2 = a_1^2$. The other even-like QR code $C_2$ paired with $C_1$ has generating idempotent $e(x)\mu_2$ by Theorem 6.6.4 as $2 \in N_p$. Again by Lemma 6.2.5,

$Q(x)\mu_2 = Q(x^2) = N(x) \text{ and } N(x)\mu_2 = N(x^2) = Q(x)$

as $2 \in N_p$. Therefore $e(x)\mu_2 = a_0 + a_1^2 Q(x) + a_1 N(x)$. By Theorem 6.6.4(ii)

$e(x) = e(x) + e(x)\mu_2 = x + x^2 + \cdots + x^{p-1}$

implying that $a_1 + a_1^2 = 1$. The only possibility is $a_1 \in \{\omega, \overline{\omega}\}$. Notice that, for either choice of $a_1$, $a_1 Q(x) + a_1^2 N(x)$ is odd-like if $p \equiv 3 \pmod 8$ and even-like if $p \equiv -3 \pmod 8$, as $Q(x)$ and $N(x)$ each have $(p-1)/2$ terms. Therefore parts (ii) and (iii) follow.

### Example 6.6.7 We consider the binary QR codes of length 23. In that case,

$\mathcal{Q}_{23} = \{1, 2, 3, 4, 6, 8, 9, 12, 13, 16, 18\} \text{ and } \mathcal{N}_{23} = \{5, 7, 10, 11, 14, 15, 17, 19, 20, 21, 22\}$.

The generating idempotents of the odd-like QR codes are

$\sum_{j \in \mathcal{Q}_{23}} x^j \text{ and } \sum_{j \in \mathcal{N}_{23}} x^j$,

and the generating idempotents of the even-like QR codes are

$1 + \sum_{j \in \mathcal{Q}_{23}} x^j \text{ and } 1 + \sum_{j \in \mathcal{N}_{23}} x^j$.

Note that the 2-cyclotomic cosets modulo 23 are $\{0\}, \mathcal{Q}_{23}, \text{and } \mathcal{N}_{23}$ implying that these are in fact the only binary duadic codes of length 23. The odd-like codes are the $\{23, 12, 7\}$ binary Golay code.

### Example 6.6.8 Now consider the QR codes of length 5 over $\mathbb{F}_4$; note that

The generating idempotents of the odd-like QR codes are

### Theorem 6.6.9 Let $p$ be an odd prime. The following hold:
- (i) Quadratic residue codes of length $p$ over $\mathbb{F}_2$, where $t$ is odd, exist if and only if $p \equiv \pm 1 \pmod 8$, and the generating idempotents are those given in Theorem 6.6.5.
- (ii) Quadratic residue codes of length $p$ over $\mathbb{F}_2$, where $t$ is even, exist for all $p$, and the generating idempotents are those given in Theorems 6.6.5 and 6.6.6.

**Proof:** By Theorem 6.6.4, the result follows as long as we show that no quadratic residue codes exist when $t$ is odd and $p \equiv \pm 3 \pmod 8$. By Theorem 6.6.5, these codes do not exist if $t=1$. If QR codes exist with $t = 2s + 1$ for some integer $s \ge 1$, then $2^s$ is a square modulo $p$ by Theorem 6.6.2. If $2^s$ is a square modulo $p$, then $2^s$ is also a square modulo $p$ as $2^s = 2 \cdot (2^t)^2$, contradicting Lemma 6.2.5.

## 6.6.2 QR codes over fields of characteristic 3
