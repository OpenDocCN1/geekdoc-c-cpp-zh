We are now ready to examine the covering radius of the Reed–Muller codes $\mathcal{R}(r, m)$ first defined in Section 1.10. Let $\rho_{RM}(r, m)$ denote the covering radius of $\mathcal{R}(r, m)$. Using Exercise 617, $\rho_{RM}(0, m) = 2^{m-1}$ as $\mathcal{R}(0, m)$ is the binary repetition code. Also $\rho_{RM}(m, m) = 0$ as $\mathcal{R}(m, m) = \mathbb{F}_2^n$. We consider the case $1 \le r < m$. By Theorem 1.10.1, $\mathcal{R}(r, m)^\perp = \mathcal{R}(m - r - 1, m)$ has minimum weight $2^{r+1} \ge 4$, therefore $\mathcal{R}(r, m)$ has strength 2 by Exercise 628. In addition $\mathcal{R}(r, m)$ is self-complementary as $\mathbf{1} \in \mathcal{R}(0, m) \subset \mathcal{R}(r, m)$ also by Theorem 1.10.1. Therefore by the Norse Bound (ii) we have the following theorem.

# **Theorem 11.2.3** Let $1 \le r < m$. Then $\rho_{RM}(r, m) \le 2^{m-1} - 2^{m-r/2-1}$. In particular, $\rho_{RM}(1, m) \le 2^{m-1} - 2^{m/2-1/2}$.

Notice that by Exercise 618 and the nesting properties of the Reed–Muller codes, any upper bound on $\rho_{RM}(1, m)$ is automatically an upper bound on $\rho_{RM}(r, m)$ for $1 < r$.

We now find a recurrence relation for the covering radius of first order Reed–Muller codes that, combined with Theorem 11.2.3, will allow us to get an exact value for $\rho_{RM}(1, m)$ when $m$ is even.

# **Lemma 11.2.4** For $m \ge 2$,

\(\rho_{RM}(1, m) \ge 2\rho_{RM}(1, m - 2) + 2^{m-2}\).
