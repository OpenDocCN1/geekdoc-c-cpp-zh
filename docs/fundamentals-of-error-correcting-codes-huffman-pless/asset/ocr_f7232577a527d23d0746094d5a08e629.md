Theorem 8.7.5 Let $\mathbb{G}$ be an abelian group of order $v$, and let $\mathcal{G} = \{g_i \mid i \in \mathbb{G}\}$. The following hold:

(i) Let $D$ be a $(v, k, \lambda)$ difference set in $\mathbb{G}$. Let $D_i = \{i + \delta \mid \delta \in D\}$ and $\mathcal{B} = \{D_i \mid i \in \mathbb{G}\}$. Then $\mathcal{D} = (\mathbb{G}, \mathcal{B})$ is a symmetric $2-(v, k, \lambda)$ design with $\mathcal{G} \le \text{Aut}(\mathcal{D})$.

(ii) If $\mathcal{D} = (\mathbb{G}, \mathcal{B})$ is a symmetric $2-(v, k, \lambda)$ design which has $\mathcal{G} \le \text{Aut}(\mathcal{D})$, then any block $D$ of $\mathcal{D}$ is a $(v, k, \lambda)$ difference set in $\mathbb{G}$ and the blocks of $\mathcal{B}$ are $D_i = \{i + \delta \mid \delta \in D\}$.

**Proof:** Let $D$ be a $(v, k, \lambda)$ difference set in $\mathbb{G}$ with $\mathcal{D} = (\mathbb{G}, \mathcal{B})$ as described. Let $i$ and $j$ be distinct elements of $\mathbb{G}$. By definition $i - j = x - y$ for $\lambda$ pairs $(x, y)$ of distinct elements in $D \times D$. Then $i - x = j - y$; as $i \in i - x \in D_{i-x}$, and $j = j - y + y = i - x + y \in D_{i-x}$, every pair of points is in at least $\lambda$ blocks. By (8.12),

```
\(v \binom{k}{2} = \binom{v}{2} \lambda.\)
```

The left-hand side counts the number of pairs of distinct elements in all the $D_i$s and the right-hand side counts the number of pairs of distinct elements in $\mathbb{G}$ repeated $\lambda$ times each. Therefore no pair can appear more than $\lambda$ times in all the $D_i$s. Thus $\mathcal{D}$ is a $2-(v, k, \lambda)$ design; since $\mathbb{G}$ has order $v$, $\mathcal{D}$ has $v$ blocks and so is symmetric. As $(D_i)g_i = D_{i+j}$, $\mathcal{G} \le \text{Aut}(\mathcal{D})$ proving (i).

For the converse, let $D$ be any block in $\mathcal{B}$. Then $D_i = \{i + \delta \mid \delta \in D\}$ is the image of $D$ under $g_i$ and hence is also in $\mathcal{B}$. Suppose first that $D_i = D_j$ for some $i \neq j$. Then $D = D_m$, where $m = i - j \neq 0$, implying that $g_m$ fixes the block $D$. By Theorem 8.7.2 $g_m$ must fix a point. Thus $m + \ell = \ell$ for some $\ell \in \mathbb{G}$, which is a contradiction as $m \neq 0$. Therefore the $D_i$s are distinct and hence must be all $v$ blocks as $\mathcal{G}$ has order $v$.

Let $w$ be a nonzero element of $\mathbb{G}$. Then $0$ and $w$ are distinct points and so must be in $\lambda$ blocks $D_i$. Thus $0 = \ell + x$ and $w = \ell + y$ for some $x$ and $y$ in $D$. But $y - x = w$ and hence every nonzero element of $\mathbb{G}$ occurs as a difference of elements of $D$ at least $\lambda$ times. There are $k(k - 1)$ differences of distinct elements of $D$. But,

```
\(b = v = \lambda \frac{v(v-1)}{k(k-1)},\)
```

by Theorem 8.1.3. Thus $k(k - 1) = \lambda(v - 1)$ and hence each difference occurs exactly $\lambda$ times, proving (ii).

This theorem shows that there is a one-to-one correspondence between difference sets in $\mathbb{G}$ and symmetric designs with blocks $\mathbb{G}$ having a group of automorphisms isomorphic to $\mathbb{G}$ acting naturally on the points and blocks. The design $\mathcal{D}$ arising from the difference set $D$ as described in Theorem 8.7.5 is called the development of $D$.
