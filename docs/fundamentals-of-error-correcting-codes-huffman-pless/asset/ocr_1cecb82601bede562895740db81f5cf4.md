# **Example 9.4.12** There is a [22, 11, 6] Type I code whose shadow has weight 7 and the extension in (9.6) gives the [24, 12, 8] extended binary Golay code. The length 22 code is a child of the Golay code, sometimes called the odd Golay code.

If $n \equiv 6 \pmod 8$ and $\mathcal{C}$ is a Type I code with $C_0$ the doubly-even subcode, then $1 \notin C_0$. Thus when $n \equiv 6 \pmod 8$ our proof of Theorem 9.4.10 shows that any Type I code of length $n$ can be extended to a Type II code of length $n+2$, denoted $C''$ in the proof. Example 9.4.12 illustrates this.

If $n \equiv 0 \pmod 8$ and $\mathcal{C}$ is a Type II code of length $n$, it is also possible to define children of $\mathcal{C}$ of lengths $n-4$ and $n-6$ that are Type I codes. It can be shown [53, 264] that any Type I code of length $n \not\equiv 0 \pmod 8$ is a child of a Type II code of the next larger length equivalent to $0$ modulo 8. This approach was used to classify all self-dual codes of lengths 26, 28, and 30 once all Type II codes of length 32 had been classified. See [53, 56, 264].

We can determine the weight enumerator of a parent from that of a child.

# **Theorem 9.4.13** Let $\mathcal{C}$ be a Type I code of length $n \equiv 6 \pmod 8$ with $C_0$ its doubly-even subcode. Suppose that $W(x, y)$ is the weight enumerator of $C_0$. Then the weight enumerator of the parent $C''$ in (9.6) is

```
$W_{C''}(x, y) = y^2 W_0(x, y) + x^2 y W_2(x, y) + xy [W_1(x, y) + W_4(x, y)]$.
```

With the notion of parents and children we can say more about Type I codes of length $n \equiv 22 \pmod{24}$ meeting the bound of Theorem 9.3.5. This result is due to Rains [290].

# **Theorem 9.4.14** Let $\mathcal{C}$ be an $[n, n/2, d]$ Type I code with $n \equiv 22 \pmod{24}$ and $d = 4 \lfloor n/24 \rfloor + 6$. Then $\mathcal{C}$ is the child of a Type II $[n+2, (n/2)+1, d+2]$ code.

In proving Theorem 9.4.14, we note that if $C_0$ is the doubly-even subcode of $\mathcal{C}$, then $1 \notin C_0$. Thus the shadow has odd weight. The difficult part of the proof is showing that the shadow is a coset of $\mathcal{C}$ of weight $d+1$. Once we know that, the parent of $\mathcal{C}$ has minimum weight $d+2$.
