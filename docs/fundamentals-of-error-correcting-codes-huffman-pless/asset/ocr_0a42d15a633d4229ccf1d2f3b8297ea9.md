Thus from \(C_1\) we produce a string of 28-byte codewords which we interleave to a depth of 28 using 4-frame delay interleaving as we now describe. Begin with codewords \(\mathbf{c}_1, \mathbf{c}_2, \dots\) from \(C_1\) in the order they are generated. Form an array with 28 rows and a large number of columns in the following fashion. Row 1 consists of the first byte of \(\mathbf{c}_1\) in column 1, the first byte of \(\mathbf{c}_2\) in column 2, the first byte of \(\mathbf{c}_1\) in column 3, etc. Row 2 begins with four bytes equal to 0 followed by the second byte of \(\mathbf{c}_1\) in column 5, the second byte of \(\mathbf{c}_1\) in column 5, the second byte of \(\mathbf{c}_2\) in column 6, the second byte of \(\mathbf{c}_3\) in column 7, etc. Row 3 begins with eight bytes equal to 0 followed by the third byte of \(\mathbf{c}_1\) in column 9, the third byte of \(\mathbf{c}_1\) in column 10, the third byte of \(\mathbf{c}_3\) in column 11, etc. Continue in this manner filling out all 28 rows. # Step II: Encoding using \(C_2\) and interleaving

Each column of the array is a vector in \(\mathbb{F}_{256}^{28}\) which is then encoded using a [32, 28, 5] shortened Reed-Solomon code \(C_2\). Thus we now have a list of codewords, which are generated in the order of the columns, each consisting of 32 bytes. The codewords are regrouped with the odd-numbered symbols of one codeword grouped with the even-numbered symbols of the next codeword. This regrouping is another form of interleaving which further breaks up short bursts that may still be present after the 4-frame delay interleaving.
