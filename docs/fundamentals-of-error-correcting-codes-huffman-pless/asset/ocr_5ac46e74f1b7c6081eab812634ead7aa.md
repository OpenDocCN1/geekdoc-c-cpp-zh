Note that (i) of the Bruck-Ryser-Chowla Theorem is Lemma 8.5.1(ii)(e). The following is a consequence of the Bruck–Ryser–Chowla Theorem [187]. The notation in this theorem is as follows. If \(i\) is a positive integer, let \(i^*\) be defined as the square-free part of \(i\); that is, \(i = i^*j\), where \(j\) is a perfect square and \(i^*\) is 1 or the product of distinct primes.

# Theorem 8.6.12 Suppose that there exists a symmetric \(2-(v, k, \lambda)\) design with order \(\mu = k - \lambda\). Let \(p \mid \mu\) where \(p\) is an odd prime.

+   (i) If \(p \mid \mu^*\) and \(p \mid \lambda^*\), then \(\mu\) is a square modulo \(p\).
+   (ii) If \(p \mid \mu^*\) and \(p \nmid \lambda^*\), then \((-1)^{(v-1)/2}2^\lambda\) is a square modulo \(p\).
+   (iii) If \(p \mid \mu^*\) and \(p \nmid \lambda^*\), then \((-1)^{(v+1)/2}(2^\lambda/p)(\mu^*/p)\) is a square modulo \(p\).

As a corollary, we can prove the following result about the existence of projective planes.

# Corollary 8.6.13 Suppose that there exists a projective plane of order \(\mu\) where \(\mu \equiv 1 (\text{mod } 4)\) or \(\mu \equiv 2 (\text{mod } 4)\). If \(p\) is an odd prime with \(p \mid \mu^*\), then \(p \equiv 1 (\text{mod } 4)\).

Proof: The number of points \(v\) of the plane is \(v = \mu^2 + \mu + 1\). Hence \((v-1)/2\) is odd when \(\mu\) is as stated. Thus by Theorem 8.6.12(ii), \(-1\) is a square modulo \(p\). By Lemma 6.2.4, \(p \equiv 1 (\text{mod } 4)\).
