**Lemma 9.12.4** For \(i = 1\) and \(2\), let \(C_i\) be an \([n, k_i]\) even binary code with \(C_i \cap C_i^\perp = \{0\}\) and \(k_1 + 2 \le k_2\). Suppose that \(C_1 \subset C_2\). Then there exists either an \(H\)-plane or \(A\)-plane \(\mathcal{P}\) in \(C_2\) orthogonal to \(C_1\) with \(C_1 \cap \mathcal{P} = \{0\}\).

**Proof:** Let \(\{x_1, \dots, x_k\}\) be a basis of \(C_1\). Define the linear function \(f : C_2 \to \mathbb{F}_2^k\) by \(f(x) = (x \cdot x_1, \dots, x \cdot x_k)\). If \(f|_{C_1}\) is the restriction of \(f\) to \(C_1\), the kernel of \(f|_{C_1}\) is \(C_1 \cap C_1^\perp = \{0\}\). Thus \(f|_{C_1}\), and hence \(f\), is surjective. The kernel \(\mathcal{K}\) of \(f\) is an \([n, k_2 - k_1]\) code orthogonal to \(C_1\). As \(C_1 \cap C_1^\perp = \{0\}\), \(K \cap C_1 = \{0\}\) and so \(k_2 = k_1 + \dim \mathcal{K}\). If \(x \in K \cap K^\perp\), then \(x \in C_2 \cap C_2^\perp\); hence \(K \cap K^\perp = \{0\}\). The result follows by Lemma 7.8.2 applied to \(K\).

**Theorem 9.12.5** If \(n \equiv 0 \pmod 8\), then there are

\(\prod_{i=0}^{k-2} (2^i + 1)\)

Type II codes of length \(n\).

**Proof:** Let \(\mu_{n,k}\) be the number of \([n, k]\) doubly-even codes containing \(1\). Clearly, \(\mu_{n,1} = 1\). As in the proof of Theorem 9.5.1, we find a recurrence relation for \(\mu_{n,k}\). We illustrate the recursion process by computing \(\mu_{n,2}\). By Corollary 9.12.3, there are \(2^{n-2} + 2^{n/2-1} - 2\) doubly-even vectors that are neither \(0\) nor \(1\). Each of these vectors is in a unique doubly-even \([n, 2]\) code containing \(1\); each such code contains two of these vectors. So \(\mu_{n,2} = 2^{n-3} + 2^{n/2-2} - 1\). Let \(C\) be any \([n, k]\) doubly-even code containing \(1\). As \(C\) is self-orthogonal, if \(C'\) is any vector space complement of \(\text{span}\{1\}\) in \(C\), then \(C = \text{span}\{1\} \perp C'\). By Lemma 9.12.1, applied to the \([n, k-1]\) code \(C'\), \(C' \subseteq \mathcal{H}_1 \perp \cdots \perp \mathcal{H}_{k-1}\), where \(\mathcal{H}_i\) are H-planes. Let \(E\) be any vector space complement of \(1\) in \(\mathcal{E}_n\) containing \(\mathcal{H}_1 \perp \cdots \perp \mathcal{H}_{k-1}\). Clearly, \(E_n = \text{span}\{1\} \perp E\) and \(E \cap E^\perp = \{0\}\). Note that \(E\) has even dimension \(n-2\). Now apply Lemmas 7.8.4 and 9.12.4 inductively, initially beginning with \(C_1 = \mathcal{H}_1 \perp \cdots \perp \mathcal{H}_{k-1}\) and always using \(C_2 = E\) in each step of the induction. Then there exist \(\mathcal{H}_k, \dots, \mathcal{H}_{n/2-1}\) which are either H-planes or A-planes such that \(E = \mathcal{H}_1 \perp \cdots \perp \mathcal{H}_{n/2-1}\). Thus \(E_n = \text{span}\{1\} \perp \mathcal{H}_1 \perp \cdots \perp \mathcal{H}_{n/2-1}\). By Exercise 418, we may assume that at most one \(\mathcal{H}_i\) is an A-plane. But, if one is an A-plane, then \(E_n\) has form A, contradicting Theorem 9.12.2. If we want to extend \(C\) to an \([n, k+1]\) doubly-even code \(C'\), we must add a nonzero doubly-even vector \(c'\) from \(D = \mathcal{H}_k \perp \cdots \perp \mathcal{H}_{n/2-1}\). By Lemma 7.8.4, \(D \cap D^\perp = \{0\}\). By Theorem 7.8.6, there are \(2^{2n-1} + 2^{n/2-1}\) doubly-even vectors in \(D\), implying that there are \(2^{n-2k-1} + 2^{n/2-k-1} - 1\) choices for \(c''\). However, every such \(C''\) has \(2^k - 1\) doubly-even subcodes of dimension \(k\) containing \(1\) by Exercise 522(a). This shows that

\(\mu_{n,k+1} = \frac{2^{n-2k} + 2^{n/2-k} - 1}{2^k - 1} \mu_{n,k}.\)
