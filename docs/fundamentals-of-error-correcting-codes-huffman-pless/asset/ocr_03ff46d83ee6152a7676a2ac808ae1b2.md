# 11.6 Covering radius of subcodes

The relationship between the covering radius of a code and that of a subcode can be quite complex. Recall by Exercise 618 that if \(\mathcal{C}_0 \subseteq \mathcal{C}\), then \(\rho(\mathcal{C}) \le \rho(\mathcal{C}_0)\). However, it is not clear how large the covering radius of \(\rho(\mathcal{C}_0)\) can be compared with \(\rho(\mathcal{C})\). The next two examples give extremes for these possibilities.

Example 11.6.1 In this example we show how the covering radius of a subcode \(\mathcal{C}_0\) could be as small as the covering radius of the original code. Let \(H_1\) be a parity check matrix of a binary code with covering radius \(\rho\), and let \(\mathcal{C}\) be the code with parity check matrix given by \(H = [ H_1 \ H_1 ]\).
Clearly, \(\rho(\mathcal{C}) = \rho\) as the list of columns of \(H\) is the same as the list of columns of \(H_1\). Let \(\mathcal{C}_0\) be the subcode of codimension 1 in \(\mathcal{C}\) with parity check matrix
\(\begin{bmatrix} H_1 & H_1 \\ 0 & \cdots & 0 & 1 & \cdots & 1 \end{bmatrix}.\)
We also have \(\rho(\mathcal{C}_0) = \rho\), as Exercise 656 shows.
