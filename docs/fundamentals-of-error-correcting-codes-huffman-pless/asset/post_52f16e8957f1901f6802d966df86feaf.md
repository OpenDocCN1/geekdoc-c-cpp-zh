
Before proceeding with our decomposition, we need a few preliminary results.

### Lemma 7.8.2
Let \(\mathcal{C}\) be an even binary code of dimension \(k \ge 2\) whose hull is \(\{\mathbf{0}\}\). The following holds:
- (i) If \(\mathcal{C}\) contains a nonzero doubly-even vector, it contains an \(H\)-plane.
- (ii) If \(\mathcal{C}\) contains no nonzero doubly-even vectors, it is 2-dimensional and is an \(A\)-plane.

**Proof:** Suppose that \(\mathcal{C}\) contains a nonzero doubly-even vector \(\mathbf{x}\). Then as \(\mathbf{x} \notin \mathcal{C}^\perp\), there is a codeword \(\mathbf{y} \in \mathcal{C}\) with \(\mathbf{x} \cdot \mathbf{y} = 1\). If \(\mathbf{y}\) is doubly-even, then \(\text{span}\{\mathbf{x}, \mathbf{y}\}\) is an \(H\)-plane. If \(\mathbf{y}\) is singly-even, then \(\mathbf{x} + \mathbf{y}\) is doubly-even by Lemma 7.8.1 and \(\text{span}\{\mathbf{x}, \mathbf{x} + \mathbf{y}\} = \text{span}\{\mathbf{x}, \mathbf{y}\}\) is still an \(H\)-plane. This proves (i). Part (ii) follows from Exercise 417.

To describe our decomposition we need one more piece of notation. Suppose that \(\mathcal{C}\) contains two subcodes, \(\mathcal{A}\) and \(\mathcal{B}\), such that \(\mathcal{C} = \mathcal{A} + \mathcal{B} = \{\mathbf{a} + \mathbf{b} \mid \mathbf{a} \in \mathcal{A} \text{ and } \mathbf{b} \in \mathcal{B}\}\), where \(\mathcal{A} \cap \mathcal{B} = \{\mathbf{0}\}\) and \(\mathbf{a} \cdot \mathbf{b} = 0\) for all \(\mathbf{a} \in \mathcal{A}\) and \(\mathbf{b} \in \mathcal{B}\). Then we say that \(\mathcal{C}\) is the *orthogonal sum* of \(\mathcal{A}\) and \(\mathcal{B}\), and denote this by \(\mathcal{C} = \mathcal{A} \perp \mathcal{B}\). (In vector space terminology, \(\mathcal{C}\) is the orthogonal direct sum of \(\mathcal{A}\) and \(\mathcal{B}\).)

### Lemma 7.8.3
Let \(\mathcal{C}\) be an even binary code whose hull is \(\{\mathbf{0}\}\). Then \(\mathcal{C}\) has even dimension \(2m\) and one of the following occurs:
- (i) \(\mathcal{C} = \mathcal{H}_1 \perp \mathcal{H}_2 \perp \cdots \perp \mathcal{H}_m\), where \(\mathcal{H}_1, \mathcal{H}_2, \dots, \mathcal{H}_m\) are \(H\)-planes.
- (ii) \(\mathcal{C} = \mathcal{H}_1 \perp \mathcal{H}_2 \perp \cdots \perp \mathcal{H}_{m-1} \perp \mathcal{A}\), where \(\mathcal{H}_1, \mathcal{H}_2, \dots, \mathcal{H}_{m-1}\) are \(H\)-planes and \(\mathcal{A}\) is an \(A\)-plane.

**Proof:** This is proved by induction on the dimension of \(\mathcal{C}\). \(\mathcal{C}\) cannot have dimension 1 as, otherwise, its nonzero vector, being even, is orthogonal to itself and hence in the hull. So \(\mathcal{C}\) has dimension at least 2. If \(\mathcal{C}\) has dimension 2, it is either an \(H\)-plane or an \(A\)-plane by Exercise 416. So we may assume that \(\mathcal{C}\) has dimension at least 3. By Lemma 7.8.2, \(\mathcal{C}\) contains an \(H\)-plane \(\mathcal{H}_1\). The proof is complete by induction if we can show that \(\mathcal{C} = \mathcal{H}_1 \perp \mathcal{C}_1\), where the hull of \(\mathcal{C}_1\) is \(\{\mathbf{0}\}\). Let \(\mathcal{H}_1 = \text{span}\{\mathbf{x}, \mathbf{y}\}\) where \(\mathbf{x}\) and \(\mathbf{y}\) are nonzero doubly-even vectors with \(\mathbf{x} \cdot \mathbf{y} = 1\). Define \(f : \mathcal{C} \to \mathbb{F}_2^2\), where \(f(\mathbf{c}) = (\mathbf{c} \cdot \mathbf{x}, \mathbf{c} \cdot \mathbf{y})\). By Exercise 419, \(f\) is a surjective linear transformation. Let \(\mathcal{C}_1\) be its kernel; \(\mathcal{C}_1\) has dimension \(k - 2\). As \(\mathbf{x} \cdot \mathbf{y} = 1\) and \(\mathbf{x} \cdot (\mathbf{x} + \mathbf{y})\), none of \(\mathbf{x}\), \(\mathbf{y}\), or \(\mathbf{x} + \mathbf{y}\) are in \(\mathcal{C}_1\). Thus \(\mathcal{H}_1 \cap \mathcal{C}_1 = \{\mathbf{0}\}\). By the definition of \(f\), \(\mathcal{H}_1\) is orthogonal to \(\mathcal{C}_1\). So \(\mathcal{C} = \mathcal{H}_1 \perp \mathcal{C}_1\). If \(\mathbf{z} \neq \mathbf{0}\) is in the hull of \(\mathcal{C}_1\), it is orthogonal to \(\mathcal{C}_1\) and to \(\mathcal{H}_1\); hence \(\mathbf{z}\) is in the hull of \(\mathcal{C}\), a contradiction.

### Lemma 7.8.4
If \(\mathcal{C} = \mathcal{P}_1 \perp \dots \perp \mathcal{P}_k\) is an orthogonal sum where each \(\mathcal{P}_i\) is either an \(H\)-plane or an \(A\)-plane, then the hull of \(\mathcal{C}\) is \(\{\mathbf{0}\}\).

**Proof:** If \(\mathbf{x} \in \mathcal{C} \cap \mathcal{C}^\perp\), where \(\mathbf{x} = \mathbf{x}_1 + \dots + \mathbf{x}_k\) with \(\mathbf{x}_i \in \mathcal{P}_i\), for \(1 \le i \le k\), then \(\mathbf{x} \cdot \mathbf{y} = 0\) for all \(\mathbf{y} \in \mathcal{C}\). As \(\mathcal{P}_i \cap \mathcal{P}_i^\perp = \{\mathbf{0}\}\), if \(\mathbf{x}_i \neq \mathbf{0}\), there exists \(\mathbf{y}_i \in \mathcal{P}_i\) with \(\mathbf{x}_i \cdot \mathbf{y}_i \neq 0\). Thus \(0 = \mathbf{x} \cdot \mathbf{y}_i\); but \(\mathbf{x} \cdot \mathbf{y}_i = \mathbf{x}_i \cdot \mathbf{y}_i \neq 0\) as \(\mathbf{x}_j \cdot \mathbf{y}_i = 0\) if \(j \neq i\). This contradiction shows \(\mathbf{x}_i = \mathbf{0}\). So \(\mathcal{C} \cap \mathcal{C}^\perp = \{\mathbf{0}\}\).

We now state our main decomposition result, found in [3].

### Theorem 7.8.5
Let \(\mathcal{C}\) be an \([n, k]\) even binary code whose hull \(\mathcal{H}\) has dimension \(r\). Then \(k = 2m + r\) for some nonnegative integer \(m\) and \(\mathcal{C}\) has one of the following forms:
- (H) \(\mathcal{C} = \mathcal{H} \perp \mathcal{H}_1 \perp \mathcal{H}_2 \perp \dots \perp \mathcal{H}_m\), where \(\mathcal{H}_1, \mathcal{H}_2, \dots, \mathcal{H}_m\) are \(H\)-planes and \(\mathcal{H}\) is doubly-even.
- (O) \(\mathcal{C} = \mathcal{H} \perp \mathcal{H}_1 \perp \mathcal{H}_2 \perp \dots \perp \mathcal{H}_m\), where \(\mathcal{H}_1, \mathcal{H}_2, \dots, \mathcal{H}_m\) are \(H\)-planes and \(\mathcal{H}\) is singly-even.
- (A) \(\mathcal{C} = \mathcal{H} \perp \mathcal{H}_1 \perp \mathcal{H}_2 \perp \dots \perp \mathcal{H}_{m-1} \perp \mathcal{A}\), where \(\mathcal{H}_1, \mathcal{H}_2, \dots, \mathcal{H}_{m-1}\) are \(H\)-planes, \(\mathcal{A}\) is an \(A\)-plane, and \(\mathcal{H}\) is doubly-even.

**Proof:** If \(\mathcal{C} = \mathcal{C}^\perp\), we have either form (H) or form (O) with \(m=0\). Assume \(\mathcal{C} \neq \mathcal{C}^\perp\). Let \(\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_r\) be a basis of \(\mathcal{H}\); extend this to a basis \(\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_n\) of \(\mathcal{C}\). Let \(\mathcal{C}_1 = \text{span}\{\mathbf{x}_{r+1}, \mathbf{x}_{r+2}, \dots, \mathbf{x}_n\}\). Clearly, \(\mathcal{C} = \mathcal{H} \perp \mathcal{C}_1\) as every vector in \(\mathcal{H}\) is orthogonal to every vector in \(\mathcal{C}_1\). If \(\mathbf{z}\) is in the hull of \(\mathcal{C}_1\), it is orthogonal to everything in \(\mathcal{C}_1\) and in \(\mathcal{H}\), and hence to everything in \(\mathcal{C}\). Thus \(\mathbf{z}\) is also in \(\mathcal{H}\), implying that \(\mathbf{z} = \mathbf{0}\). So the hull of \(\mathcal{C}_1\) is \(\{\mathbf{0}\}\). By Lemma 7.8.3, the result follows once we show that the decomposition given in (A) with \(\mathcal{H}\) singly-even reduces to (O). In that case, let \(\mathcal{A} = \text{span}\{\mathbf{x}, \mathbf{y}\}\) and let \(\mathbf{z}\) be a singly-even vector in \(\mathcal{H}\). By Lemma 7.8.1, \(\mathbf{x}_1 = \mathbf{z} + \mathbf{x}\) and \(\mathbf{y}_1 = \mathbf{z} + \mathbf{y}\) are both doubly-even. As \(\mathbf{x} \perp \mathbf{y}\), \(\mathbf{x}_1 \perp \mathbf{y}_1\); hence \(\mathcal{H}_m = \text{span}\{\mathbf{x}_1, \mathbf{y}_1\}\) is an \(H\)-plane. Clearly, \(\mathcal{H} \perp \mathcal{H}_1 \perp \dots \perp \mathcal{H}_{m-1} \perp \mathcal{A} = \mathcal{H} \perp \mathcal{H}_1 \perp \dots \perp \mathcal{H}_m\) and we have form (O).

As a consequence of this theorem, we can obtain constraints on the number of singly-even and doubly-even codewords in an even binary code; see [31, 164, 271].

### Theorem 7.8.6
Let \(\mathcal{C}\) be an \([n, k]\) even binary code whose hull has dimension \(r\). Then \(k = 2m + r\). Let \(a\) be the number of doubly-even vectors in \(\mathcal{C}\) and \(b\) the number of singly-even vectors in \(\mathcal{C}\).
- (i) If \(\mathcal{C}\) has form (H), then \(a = 2^r(2^{2m-1} + 2^{m-1})\) and \(b = 2^r(2^{2m-1} - 2^{m-1})\).
- (ii) If \(\mathcal{C}\) has form (O), then \(a = b = 2^{k-1}\).
- (iii) If \(\mathcal{C}\) has form (A), then \(a = 2^r(2^{2m-1} - 2^{m-1})\) and \(b = 2^r(2^{2m-1} + 2^{m-1})\).
