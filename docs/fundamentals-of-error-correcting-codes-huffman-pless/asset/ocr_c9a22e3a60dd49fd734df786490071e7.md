+   (vi) If \(\Lambda\) is integral, then
+   
+   \(\Lambda \subseteq \Lambda^* \subseteq \frac{1}{\det \Lambda} \Lambda = (\det \Lambda^*)\Lambda.\)

+   (vii) If \(\Lambda\) is integral, then \(\Lambda\) is unimodular if and only if \(\det \Lambda = \pm 1\).

Proof: We leave the proofs of (i) and (v) for Exercise 605. For (ii), let \(\mathbf{w}_1, \dots, \mathbf{w}_n\) be the rows of \((M^{-1})^T\). Then \((\mathbf{w}_1, \dots, \mathbf{w}_n)\) is a basis of \(\mathbb{R}^n\) and, as \((M^{-1})^T M^T = (MM^{-1})^T = I_n\),

```
$$
\mathbf{w}_i \cdot \mathbf{v}_j = \begin{cases} 1 & \text{if } i = j, \\ 0 & \text{if } i \neq j. \end{cases}
$$ (10.10)
```

In particular, \(\{\mathbf{w}_1, \dots, \mathbf{w}_n\} \subseteq \Lambda^*\) by (i). Let \(\mathbf{w} \in \Lambda^*\). Then \(\mathbf{w} = a_1 \mathbf{w}_1 + \cdots + a_n \mathbf{w}_n\) as \(\{\mathbf{w}_1, \dots, \mathbf{w}_n\}\) is a basis of \(\mathbb{R}^n\). As \(\mathbf{w} \in \Lambda^*\), \(\mathbf{w} \cdot \mathbf{v}_j \in \mathbb{Z}\). But \(\mathbf{w} \cdot \mathbf{v}_j = a_j\) for \(1 \le j \le n\) by (10.10). Hence \(a_j \in \mathbb{Z}\) and (ii) holds. The Gram matrix of \(\Lambda^*\) is \((M^{-1})^T M^{-1} = (MM^T)^{-1} = A^{-1}\) yielding (iii). Thus

```
$$
\det \Lambda^* = \det \Lambda^{-1} = \frac{1}{\det \Lambda} = \frac{1}{\det \Lambda}.
$$
```

producing (iv).

For (vi) we only need to prove the second containment by parts (iv) and (v). Let \(\mathbf{y} \in \Lambda^*\). Then \(\mathbf{y} M^T \in \mathbb{Z}^n\) by (i), and hence there exists \(\mathbf{z} \in \mathbb{Z}^n\) such that \(\mathbf{y} = \mathbf{z}(M^T)^{-1} = \mathbf{z}(M^T)^{-1} M^{-1} M = z(\mathbf{M} M^T)^{-1} M = z \Lambda^{-1} M\). But \(A^{-1} = (\det \Lambda)^{-1} \text{adj}(A)\), where \(\text{adj}(A)\) is the adjoint of \(A\). Hence

```
$$
\mathbf{y} = \mathbf{z}(\det \Lambda)^{-1} \text{adj}(A) M = \mathbf{z}'(\det \Lambda)^{-1} M,
$$
```

where \(\mathbf{z}' = \mathbf{z} \text{adj}(A) \in \mathbb{Z}^n\) as \(\text{adj}(A)\) has integer entries since \(\Lambda\) is integral. Thus \(\mathbf{y} \in (\det \Lambda)^{-1} \Lambda\) verifying (vi).

Finally by (vi) if \(\Lambda\) is unimodular, then \(\det \Lambda = \det \Lambda^* = 1/(\det \Lambda)\) implying \(\det \Lambda = \pm 1\). Conversely, if \(\det \Lambda = \pm 1\) and \(\Lambda\) is integral, (vi) shows that \(\Lambda \subseteq \Lambda^* \subseteq \pm \Lambda\) and \(\Lambda = \Lambda^*\) as clearly \(\Lambda = \pm \Lambda\).

In an integral lattice \(\Lambda\), \(\mathbf{x} \cdot \mathbf{x}\) is an integer for all \(\mathbf{x} \in \Lambda\). An integral lattice is called *even* if \(\mathbf{x} \cdot \mathbf{x}\) is an even integer for all \(\mathbf{x} \in \Lambda\). In particular, the Gram matrix has even entries on its main diagonal. An integral lattice that is not even is called *odd*. A lattice has *Type II* provided it is an even unimodular lattice and *Type I* if it is an odd unimodular lattice. Type I lattices exist for any dimension \(n\); however, Type II lattices exist if and only if \(n \equiv 0 (\text{mod } 8)\). The unimodular lattices have been classified up to equivalence through dimension 25; note that Type I codes have been classified through length 30 and Type II through length 32.
