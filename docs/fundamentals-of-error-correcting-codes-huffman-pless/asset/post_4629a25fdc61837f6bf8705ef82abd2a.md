## **Corollary 8.7.3** An automorphism of a symmetric 2-design has the same cycle structure on blocks as it does on points.

**Proof:** If $\alpha$ and $\tau$ represent the same automorphism acting on blocks and points, respectively, then so do $\alpha^t$ and $\tau^t$. Let $n_i$, respectively $n'_i$, be the number of $i$-cycles of $\sigma$, respectively $\tau$. If $i$ is a prime $p$, the number of fixed points of $\sigma^t$, respectively $\tau^t$, is $p \cdot n_p + n_1$, respectively $p \cdot n'_p + n'_1$. As $n_1 = n'_1$ by Theorem 8.7.2 applied to $\sigma$ and $\tau$, and since $p \cdot n_p + n_1 = p \cdot n'_p + n'_1$ by the same theorem applied to $\sigma^t$ and $\tau^t$, $n_p = n'_p$. We can continue inductively according to the number of prime factors of $i$.

We are now ready to introduce the concept of a difference set; this will be intimately related to cyclic designs. Let $\mathcal{G}$ be an abelian group of order $v$. A $(v, k, \lambda)$ *difference set* in $\mathcal{G}$ is a set $D$ of $k$ distinct elements of $\mathcal{G}$ such that the multiset $\{x - y \mid x \in D, y \in D, x \neq y\}$ contains every nonzero element of $\mathcal{G}$ exactly $\lambda$ times. There are $k(k-1)$ differences between distinct elements of $D$, and these differences make up all nonzero elements of $\mathcal{G}$ exactly $\lambda$ times. Thus

$$k(k-1) = (v-1)\lambda. \tag{8.12}$$

We will be most interested in the case where $\mathcal{G}$ is the cyclic group $\mathbb{Z}_v$, in which case the difference set is a *cyclic difference set*. In Theorem 8.7.5 we will see the connection between difference sets and symmetric designs.

## **Example 8.7.4** In $\mathbb{Z}_7$, the set $D = \{1, 2, 4\}$ is a $(7, 3, 1)$ cyclic difference set as one can see by direct computation (Exercise 464). By adding each element of $i \in \mathbb{Z}_7$ to the set $D$ we obtain the sets $D_i = \{i+1, i+2, i+4\}$. These form the blocks of a projective plane $\mathcal{D}$ of order 2. The map $i \mapsto i+1 \pmod 7$ is a 7-cycle in Aut($\mathcal{D}$).

## **Theorem 8.7.5** Let $\mathbb{G}$ be an abelian group of order $v$, and let $\mathcal{G} = \{g_i \mid i \in \mathbb{G}\}$. The following hold:
- (i) Let $D$ be a $(v, k, \lambda)$ difference set in $\mathbb{G}$. Let $D_i = \{i + \delta \mid \delta \in D\}$ and $\mathcal{B} = \{D_i \mid i \in \mathbb{G}\}$. Then $\mathcal{D} = (\mathbb{G}, \mathcal{B})$ is a symmetric $2-(v, k, \lambda)$ design with $\mathcal{G} \le \text{Aut}(\mathcal{D})$.
- (ii) If $\mathcal{D} = (\mathbb{G}, \mathcal{B})$ is a symmetric $2-(v, k, \lambda)$ design which has $\mathcal{G} \le \text{Aut}(\mathcal{D})$, then any block $D$ of $\mathcal{D}$ is a $(v, k, \lambda)$ difference set in $\mathbb{G}$ and the blocks of $\mathcal{B}$ are $D_i = \{i + \delta \mid \delta \in D\}$.

**Proof:** Let $D$ be a $(v, k, \lambda)$ difference set in $\mathbb{G}$ with $\mathcal{D} = (\mathbb{G}, \mathcal{B})$ as described. Let $i$ and $j$ be distinct elements of $\mathbb{G}$. By definition $i - j = x - y$ for $\lambda$ pairs $(x, y)$ of distinct elements in $D \times D$. Then $i - x = j - y$; as $i \in i - x \in D_{i-x}$, and $j = j - y + y = i - x + y \in D_{i-x}$, every pair of points is in at least $\lambda$ blocks. By (8.12),

$$v \binom{k}{2} = \binom{v}{2} \lambda.$$

The left-hand side counts the number of pairs of distinct elements in all the $D_i$s and the right-hand side counts the number of pairs of distinct elements in $\mathbb{G}$ repeated $\lambda$ times each. Therefore no pair can appear more than $\lambda$ times in all the $D_i$s. Thus $\mathcal{D}$ is a $2-(v, k, \lambda)$ design; since $\mathbb{G}$ has order $v$, $\mathcal{D}$ has $v$ blocks and so is symmetric. As $(D_i)g_i = D_{i+j}$, $\mathcal{G} \le \text{Aut}(\mathcal{D})$ proving (i).

For the converse, let $D$ be any block in $\mathcal{B}$. Then $D_i = \{i + \delta \mid \delta \in D\}$ is the image of $D$ under $g_i$ and hence is also in $\mathcal{B}$. Suppose first that $D_i = D_j$ for some $i \neq j$. Then $D = D_m$, where $m = i - j \neq 0$, implying that $g_m$ fixes the block $D$. By Theorem 8.7.2 $g_m$ must fix a point. Thus $m + \ell = \ell$ for some $\ell \in \mathbb{G}$, which is a contradiction as $m \neq 0$. Therefore the $D_i$s are distinct and hence must be all $v$ blocks as $\mathcal{G}$ has order $v$.

Let $w$ be a nonzero element of $\mathbb{G}$. Then $0$ and $w$ are distinct points and so must be in $\lambda$ blocks $D_i$. Thus $0 = \ell + x$ and $w = \ell + y$ for some $x$ and $y$ in $D$. But $y - x = w$ and hence every nonzero element of $\mathbb{G}$ occurs as a difference of elements of $D$ at least $\lambda$ times. There are $k(k - 1)$ differences of distinct elements of $D$. But,

$$b = v = \lambda \frac{v(v-1)}{k(k-1)},$$

by Theorem 8.1.3. Thus $k(k - 1) = \lambda(v - 1)$ and hence each difference occurs exactly $\lambda$ times, proving (ii).

This theorem shows that there is a one-to-one correspondence between difference sets in $\mathbb{G}$ and symmetric designs with blocks $\mathbb{G}$ having a group of automorphisms isomorphic to $\mathbb{G}$ acting naturally on the points and blocks. The design $\mathcal{D}$ arising from the difference set $D$ as described in Theorem 8.7.5 is called the development of $D$.

We can use quadratic residues to construct difference sets.

## **Theorem 8.7.6** ([204]) Let $q = 4m - 1 = p^r$ for a prime $p$. The set $D = \{x^2 \mid x \in \mathbb{F}_q, x \neq 0\}$ is a $(4m-1, 2m-1, m-1)$ difference set in the additive group of $\mathbb{F}_q$.

**Proof:** As $q = 4m - 1 = p^r$, $p \equiv -1 \pmod 4$ and $r$ is odd. By Lemma 6.2.4, $-1$ is not a square in $\mathbb{F}_q$. Hence $-1$ is a root of $x^2 + 1$ in $\mathbb{F}_q$ but not in $\mathbb{F}_p$. Thus $-1$ is not a square in $\mathbb{F}_q$ as $\mathbb{F}_p \not\subseteq \mathbb{F}_q$. Since the nonzero elements of $\mathbb{F}_q$ form a cyclic group $\mathbb{F}_q^*$ with generator $\alpha$, $D$ consists of the $2m-1$ elements $\{\alpha^{2i} \mid 1 \le i \le 2m-1\}$, and $(-1)D$ makes up the remaining nonzero elements (the nonsquares) of $\mathbb{F}_q$. Let $M$ be the multiset $\{x-y \mid x \in D, y \in D, x \ne y\}$. If $x-y$ is a fixed difference in $M$, then for $1 \le i \le 2m-1$, $\alpha^i(x-y) = (\alpha^i y)^{-1}x - (\alpha^i y)x$ and $-\alpha^{2i}(x-y) = (\alpha^i y)^{-1}y - (\alpha^i y)x$ are each in $M$ and comprise all $4m-2$ nonzero elements of $\mathbb{F}_q$. Thus every nonzero element of $\mathbb{F}_q$ occurs $\lambda$ times for some $\lambda$, making a $(4m-1, 2m-1, \lambda)$ difference set in the additive group of $\mathbb{F}_q$. By (8.12), $\lambda = m-1$.

Applying Theorem 8.7.6 to the case $q = p = 4m-1$ where $p$ is a prime, we obtain a cyclic difference set in $\mathbb{Z}_p$.

Since it is so difficult to prove the nonexistence of projective planes with parameters not covered by the Bruck-Ryser-Chowla Theorem, it is reasonable to consider planes with additional conditions. One natural possibility is to examine criteria under which cyclic projective planes do not exist. Our next two theorems show that if a cyclic projective plane has order $\mu$ where either $\mu \equiv 2 \pmod 4$ or $\mu \equiv \pm 3 \pmod 9$, then $\mu = 2$ or $\mu = 3$. These results were proved in the more general setting of $(\mu^2+\mu+1, \mu+1, 1)$ difference sets in an abelian group of order $\mu^2+\mu+1$ in [353]. Using duadic codes, we can prove these two theorems rather easily. The proof of the first is found in [267].

## **Theorem 8.7.7** Let $\mathcal{D}$ be a cyclic projective plane of order $\mu \equiv 2 \pmod 4$. Then $\mu = 2$.

**Proof:** Let $A$ be the incidence matrix of $\mathcal{D}$. By Theorem 8.7.1(ii), $\mathcal{D}_2(A)$ is a $[v, (v-1)/2]$ self-orthogonal even-like duadic code with splitting $\mu_{-1}$. By Theorems 8.5.3 and 6.4.2, $C_2(A)$ is an odd-like duadic code. By Theorem 8.6.3, $C_2(A)$ has minimum weight $\mu+1$, with minimum weight codewords being those whose supports are the lines. By Theorem 4.3.13, $\mu_2 \in \text{PAut}(C_2(A))$ and thus $\mu_2$ permutes the minimum weight codewords. Hence $\mu_2 \in \text{Aut}(\mathcal{D})$. Because $\mu_2$ fixes the coordinate $0$, by Theorem 8.7.2, $\mu_2$ fixes a line $\ell$ and thus $\mu_2$ fixes a minimum weight codeword $\mathbf{c}$ of $C_2(A)$. But any nonzero binary codeword fixed by $\mu_2$ must be an idempotent. By Theorem 8.7.5, the lines of $\mathcal{D}$ can be obtained by cyclic shifts of $\ell$; as the codewords whose supports are the lines $C_2(A)$, $\mathbf{c}$ must be the generating idempotent. But the generating idempotent of a binary duadic code of length $v$ has weight $(v-1)/2$ or $(v+1)/2$ by equations (6.1) and (6.3). Thus $\mu+1 = (v \pm 1)/2 = (\mu^2+\mu+1 \pm 1)/2$, which implies $\mu = 2$.
