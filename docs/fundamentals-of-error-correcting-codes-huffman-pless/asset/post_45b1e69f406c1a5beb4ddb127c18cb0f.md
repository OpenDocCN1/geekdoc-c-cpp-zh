In constructing the Kerdock codes, we will use the relative trace function from \(\text{GR}(4^r)\) into \(\mathbb{Z}_4\), which is analogous to the trace function from \(\mathbb{F}_{2^r}\) into \(\mathbb{F}_2\). Recall that the trace function \(\text{Tr}_r : \mathbb{F}_{2^r} \to \mathbb{F}_2\) is given by

\(\text{Tr}_r(\alpha) = \sum_{i=0}^{r-1} \alpha^{2^i} = \sum_{i=0}^{r-1} \sigma_0^i(\alpha) \quad \text{for } \alpha \in \mathbb{F}_{2^r},\)

where \(\sigma_0\) is the Frobenius automorphism of \(\mathbb{F}_{2^r}\). The relative trace function \(\text{TR}_r : \text{GR}(4^r) \to \mathbb{Z}_4\) is given by

\(\text{TR}_r(\alpha) = \sum_{i=0}^{r-1} \nu_2^i(\alpha) \quad \text{for } \alpha \in \text{GR}(4^r).\)

By Exercise 753, \(\text{TR}_r(\alpha)\) is indeed an element of \(\mathbb{Z}_4\). By Lemma 3.8.5, \(\text{Tr}_r\) is a surjective map; analogously, \(\text{TR}_r\) is a surjective map.

## 12.7 Kerdock codes

We now define the binary Kerdock code of length \(2^{(r+1)}\) as the Gray image of the extended code of a certain cyclic \(\mathbb{Z}_4\)-linear code of length \(n = 2^r - 1\). Let \(H(x)\) be a primitive basic irreducible polynomial of degree \(r\). Let \(f(x)\) be the reciprocal polynomial of \((x^r - 1)/((x - 1)H(x))\). As in Section 12.3.3, \(f(x)\) is a factor of \(x^n - 1\). Define \(K(r + 1)\) to be the cyclic code of length \(2^r - 1\) over \(\mathbb{Z}_4\) generated by \(f(x)\). By Corollary 12.3.14, \(K(r + 1)\) is a code of length \(n = 2^r - 1\) and type \(4^{(n-k)} / 2^k = 4^{(r+1)}\). Let \(\widetilde{K}(r + 1)\) be the extended cyclic code obtained by adding an overall parity check to \(K(r + 1)\). This is a code of length \(2^r\) and type \(4^{(r+1)}\). The Kerdock code \(K(r + 1)\) is defined to be the Gray image \(\Phi(\widetilde{K}(r + 1))\) of \(\widetilde{K}(r + 1)\). So \(K(r + 1)\) is a code of length \(2^{(r+1)}\) with \(4^{(r+1)}\) codewords. In [116] it is shown that a simple rearrangement of the coordinates leads directly to the original definition given by Kerdock in [166]. The results of this section are taken primarily from [116]. Earlier Nechaev [243] discovered a related connection between \(\mathbb{Z}_4\)-sequences and Kerdock codes punctured on two coordinates.

### Example 12.7.1
If \(n = 2^3 - 1\), we can let \(H(x) = x^3 + 2x^2 + x - 1\). In that case, \(f^*(x) = (x^3 - 1)/((x - 1)H(x)) = x^3 - x^2 + 2x - 1\) and \(f(x) = x^3 + 2x^2 + x - 1\).

In this section \(\text{GR}(4^r)\) will denote the specific Galois ring \(\mathbb{Z}_4[x]/(f(x))\). Let \(\xi\) be a primitive root of \(H(x)\) in \(\text{GR}(4^r)\). We will add the parity check position on the left of a codeword of \(K(r + 1)\) and label the check position infinity. Hence if \(c_\infty c_0 \ldots c_{n-1}\) is a codeword, the corresponding 'extended' polynomial form would be \((c_\infty, c(x))\), where \(c(x) = c_0 + c_1 x + \ldots + c_{n-1} x^{n-1}\).

### Lemma 12.7.2
Let \(r \ge 2\). The following hold:

- (i) A polynomial \(c(x)\) in \(\mathbb{Z}_n\) is in \(K(r + 1)\) if and only if \((x - 1)H(x)c^*(x) = 0\) in \(\mathbb{Z}_n\).

- (ii) Generator matrices \(G_{r+1}\) and \(\widetilde{G}_{r+1}\) for \(K(r + 1)\) and \(\widetilde{K}(r + 1)\), respectively, are
\(G_{r+1} = [ 1\ 1\ 1\ \ldots\ 1 ; 1\ \xi\ \xi^2\ \ldots\ \xi^{n-1} ; 1\ \xi^2\ \xi^4\ \ldots\ \xi^{2(n-1)} ; \ldots ; 1\ \xi^k\ \xi^{2k}\ \ldots\ \xi^{k(n-1)} ]\).
\(\widetilde{G}_{r+1} = [ 0\ 1\ 1\ \ldots\ 1 ; 1\ 0\ \xi\ \ldots\ \xi^{n-2} ; \ldots ; 1\ \xi^{k-1}\ \ldots ]\).
We can replace each \(\xi^k\) by the column vector \([b_0, b_1, \ldots, b_{r-1}]^T\) obtained from (12.21), where \(\xi^k = \sum b_j \xi^j\).

Proof: Since \(\mathbb{Z}_n = ((x - 1)H(x) \oplus (f^*(x))\) by Theorem 12.3.12, \((x - 1)H(x)c^*(x) = 0\) in \(\mathbb{Z}_n\) if and only if \(c^*(x) \in (f^*(x))\) if and only if \(c(x) = f(x)s(x)\) for some \(s(x) \in \mathbb{Z}_n\), proving (i).

For (ii), we note that the matrix obtained from \([1\ \xi\ \xi^2\ \cdots\ \xi^{r-1}]\) by replacing each \(\xi^i\) with the coefficients from (12.21) is the \(r \times r\) identity matrix. Hence the \(r+1\) rows of \(\widehat{G}_{r+1}\) generate a code of type \(4^{r+1}\); the same will be true of the \(r+1\) rows of \(G_{r+1}\) once we show that the parity check of \(\mathbf{r}_1 = [1\ 1\ 1\ \cdots\ 1]\) is 1 and the parity check of \(\mathbf{r}_2 = [1\ \xi\ \xi^2\ \cdots\ \xi^{r-1}]\) is 0. Since \(\mathbf{r}_1\) has \(2^r - 1\) 1s and \(2^r - 1 \equiv 3 \pmod 4\) as \(r \ge 2\), the parity check for \(\mathbf{r}_1\) is 1. The parity check for \(\mathbf{r}_2\) is \(-\sum_{i=0}^{n-1} \xi^i = -(\xi^q - 1)/(\xi - 1) \equiv 0\) as \(\xi^q = 1\).

To complete the proof of (ii), it suffices to show that \(c(x) \in K(r+1)\) where \(c(x)\) is the polynomial associated to \(\mathbf{r}_1\) and \(\mathbf{r}_2\). For \(\mathbf{r}_1\), let \(c(x) = \sum_{i=0}^{n-1} x^i\). As \((x-1)^q c(x) = (x-1) \sum_{i=0}^{q-1} x^i = x^q - 1\) in \(\mathbb{Z}_4[x]\), \((x-1)H(x)c^*(x) = 0\) in \(\mathfrak{R}_n\), showing \(c(x) \in K(r+1)\) by (i). For \(\mathbf{r}_2\), we are actually working with \(r\) possible codewords. We do not wish to deal with them individually and so we let \(c(x) = \sum_{i=0}^{n-1} \xi^i x^i\), thus allowing the coefficients of \(c(x)\) to lie in the ring \(\text{GR}(4^r)\) rather than \(\mathbb{Z}_4\). Clearly, by (ii), we only need to show that \(H(x)c^*(x) = 0\) even when we allow the coefficients of \(c(x)\) to be elements of \(\text{GR}(4^r)\). So \(c^*(x) = \xi \sum_{i=0}^{q-1} \xi^{q-1-i} x^i\) (where \(\xi\) in front of the summation makes \(c^*(x)\) monic). Let \(H(x) = \sum_{i=0}^n H_i x^i\). By Exercise 754, the coefficient of \(x^k\) for \(0 \le k \le n-1\) in the product \(H(x)c^*(x)\) is

$$\xi \sum_{i+j \equiv k (\text{mod } n)} H_i \xi^{n-1-j} = \xi \sum_{i=0}^{n-1} H_i \xi^{n-1-k+i} = \xi^{n-k} \sum_{i=0}^{n-1} H_i \xi^i, \quad (12.22)$$

since \(\xi^q = 1\). The right-hand side of (12.22) is \(\xi^{n-k} H(\xi) = 0\) as \(\xi\) is a root of \(H(x)\). Therefore \((x-1)H(x)c^*(x) = 0\).

We remark that \((x-1)H(x)\) is called the check polynomial of \(K(r+1)\), analogous to the terminology used in Section 4.4 for cyclic codes over \(\mathbb{F}_q\). Notice that the matrix \(G_{r+1}\) of Lemma 12.7.2 is reminiscent of the parity check matrix for the subcode of even weight vectors in the binary Hamming code, where we write this parity check matrix over an extension field of \(\mathbb{F}_2\), rather than over \(\mathbb{F}_2\).
