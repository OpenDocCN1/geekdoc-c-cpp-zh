
$q$-cyclotomic cosets modulo $n$ have size 1. In fact, the roots of $x^n - 1$ are exactly the nonzero elements of $\mathbb{F}_q$, and a primitive $n$th root of unity is a primitive element of $\mathbb{F}_q$. So if $\mathcal{C}$ has designed distance $\delta$, the defining set of $\mathcal{C}$ has size $\delta - 1$ and is $T = \{b, b+1, \dots, b+\delta-2\}$ for some integer $b$. By Theorem 5.1.1 and the Singleton Bound, the dimension $k$ and minimum distance $d$ of $\mathcal{C}$ satisfy $k = n - \delta + 1 \ge n - d + 1 \ge k$. Thus both inequalities are equalities implying $d = \delta$ and $k = n - d + 1$. In particular, $\mathcal{C}$ is MDS. We summarize this information in the following theorem.

## Theorem 5.2.1 Let $\mathcal{C}$ be an RS code over $\mathbb{F}_q$ of length $n=q-1$ and designed distance $\delta$. Then:

- (i) $\mathcal{C}$ has defining set $T = \{b, b+1, \dots, b+\delta-2\}$ for some integer $b$,
- (ii) $\mathcal{C}$ has minimum distance $d=\delta$ and dimension $k=n-d+1$, and
- (iii) $\mathcal{C}$ is MDS.

Recall that in general the dual and cyclic complement of a BCH code are not BCH codes; that is not the case with RS codes. Suppose that $T$ is the defining set for an RS code $\mathcal{C}$ of length $n$ and designed distance $\delta$. Then $T$ is a set of $\delta - 1$ consecutive elements from $\mathcal{N} = \{0, 1, \dots, n-1\}$. By Theorem 4.4.6, the defining set of the cyclic complement $\mathcal{C}^\perp$ of $\mathcal{C}$ is $\mathcal{N} \setminus T$, which is a set of $n - \delta + 1$ consecutive elements implying $\mathcal{C}^\perp$ is RS. Similarly, as $(-1)T \mod n$ is also a set of $\delta - 1$ consecutive elements from $\mathcal{N}$, we have using Theorem 4.4.9 that the defining set $\mathcal{N} \setminus (-1)T \mod n$ of $\mathcal{C}^\perp$ is a consecutive set of $n - \delta + 1$ elements also. Therefore $\mathcal{C}^\perp$ is an RS code.

We now present an alternative formulation of narrow-sense Reed-Solomon codes, which is the original formulation of Reed and Solomon. This alternative formulation of narrow-sense RS codes is of particular importance because it is the basis for the definitions of generalized Reed-Solomon codes, Goppa codes, and algebraic geometry codes, as we will see in Chapter 13. For $k \ge 0$, let $\mathcal{P}_k$ denote the set of polynomials of degree less than $k$, including the zero polynomial, in $\mathbb{F}_q[x]$. Note that $\mathcal{P}_0$ is precisely the zero polynomial.

## Theorem 5.2.3 Let $\alpha$ be a primitive element of $\mathbb{F}_q$ and let $k$ be an integer with $0 \le k \le n = q - 1$. Then

$\mathcal{C} = \{(f(1), f(\alpha), f(\alpha^2), \dots, f(\alpha^{q-2})) \mid f \in \mathcal{P}_k\}$ is the narrow-sense $[n, k, n-k+1]$ RS code over $\mathbb{F}_q$.

Proof: Clearly $\mathcal{C}$ is a linear code over $\mathbb{F}_q$ as $\mathcal{P}_k$ is a linear subspace over $\mathbb{F}_q$ of $\mathbb{F}_q[x]$. As $\mathcal{P}_k$ is $k$-dimensional, $\mathcal{C}$ will also be $k$-dimensional if we can show that if $f$ and $f_1$ are distinct elements of $\mathcal{P}_k$, then the corresponding elements in $\mathcal{C}$ are distinct. If the latter are equal, then their difference is $\{0\}$ implying that $f - f_1$, which is a nonzero polynomial of degree at most $k - 1$, has $n \ge k$ roots, contradicting Exercise 159. Thus $\mathcal{C}$ is $k$-dimensional.

Let $\mathcal{D}$ be the narrow-sense $[n, n - k + 1]$ RS code over $\mathbb{F}_q$. So $\mathcal{D}$ has defining set $T = \{1, 2, ..., n - k\}$. We show that $\mathcal{C} = \mathcal{D}$; it suffices to prove that $\mathcal{C} \subseteq \mathcal{D}$ as both codes are $k$-dimensional. Let $c(x) = \sum_{j=0}^{n-1} c_j x^j \in \mathcal{C}$. Then there exists some $f(x) = \sum_{m=0}^{k-1} f_m x^m \in \mathcal{P}_k$ such that $c_j = f(\alpha^j)$ for $0 \le j < n$. To show that $c(x) \in \mathcal{D}$ we need to show that $c(\alpha^i) = 0$ for $i \in T$ by Theorem 4.4.2. If $i \in T$, then

\(c(\alpha^i) = \sum_{j=0}^{n-1} c_j \alpha^{ij} = \sum_{j=0}^{n-1} \left( \sum_{m=0}^{k-1} f_m \alpha^{jm} \right) \alpha^{ij}\)
\(= \sum_{m=0}^{k-1} f_m \sum_{j=0}^{k-1} \alpha^{(i+m)j} = \sum_{m=0}^{k-1} f_m \frac{\alpha^{(i+m)n} - 1}{\alpha^{i+m} - 1}.\)

But $\alpha^{(i+m)n} = 1$ and $\alpha^i \neq 1$ as $1 \le i \le m \le n - 1 = q - 2$ and $\alpha$ is a primitive $n$th root of unity. Therefore $c(\alpha^i) = 0$ for $i \in T$ implying that $\mathcal{C} \subseteq \mathcal{D}$. Hence $\mathcal{C} = \mathcal{D}$.

This alternate formulation of narrow-sense RS codes gives an alternate encoding scheme as well. Suppose that $f_0, f_1, ..., f_{k-1}$ are $k$ information symbols and $f(x) = f_0 + f_1 x + ... + f_{k-1} x^{k-1}$, then

\((f_0, f_1, ..., f_{k-1}) \xrightarrow{\text{encode}} (f(1), f(\alpha), ..., f(\alpha^{q-2})).\) (5.2)

Notice that this encoding scheme is not systematic. There is a decoding scheme for RS codes that is unusual in the sense that it finds the information symbols directly, under the assumption that they have been encoded using (5.2). It is not syndrome decoding but is an instance of a decoding scheme based on majority logic and was the original decoding developed by Reed and Solomon [294]. Currently other schemes are used for decoding and for that reason we do not present the original decoding here.

## 5.3 Generalized Reed-Solomon codes

The construction of the narrow-sense RS codes in Theorem 5.2.3 can be generalized to (possibly noncyclic) codes. Let $n$ be any integer with $1 \le n \le q$. Choose \(\gamma = (\gamma_0, ..., \gamma_{n-1})\) to be an $n$-tuple of distinct elements of $\mathbb{F}_q$, and $\mathbf{v} = (v_0, \dots, v_{n-1})$ to be an $n$-tuple of nonzero, but not necessarily distinct, elements of $\mathbb{F}_q$. Let $k$ be an integer with $1 \le k \le n$. Then the codes

$GRS_k(\gamma, \mathbf{v}) = \{ (v_0 f(\gamma_0), v_1 f(\gamma_1), \dots, v_{n-1} f(\gamma_{n-1})) \mid f \in \mathcal{P}_k \}$

are the generalized Reed-Solomon or GRS codes. Because no $v_i$ is 0, by repeating the proof of Theorem 5.2.3, we see that $GRS_k(\gamma, \mathbf{v})$ is $k$-dimensional. Because a nonzero polynomial $f \in \mathcal{P}_k$ has at most $k-1$ zeros, $GRS_k(\gamma, \mathbf{v})$ has minimum distance at least $n-(k-1) = n-k+1$. By the Singleton Bound, it has minimum distance at most $n-k+1$; hence, $GRS_k(\gamma, \mathbf{v})$ has minimum distance exactly $n-k+1$. Thus GRS codes are also MDS, as were RS codes. It is obvious that if $\mathbf{v}$ is another $n$-tuple of nonzero elements of $\mathbb{F}_q$, then $GRS_k(\gamma, \mathbf{v})$ is monomially equivalent to $GRS_k(\gamma, \mathbf{w})$. The narrow-sense RS codes are GRS codes with $n=q-1, \gamma_i = \alpha^i$, where $\alpha$ is a primitive $n$th root of unity, and $v_i=1$ for $0 \le i \le n-1$. We summarize this information in the following theorem.

### Theorem 5.3.1 With the notation as above:

- (i) $GRS_k(\gamma, \mathbf{v})$ is an $[n, k, n-k+1]$ MDS code,
- (ii) $GRS_k(\gamma, \mathbf{v})$ is monomially equivalent to $GRS_k(\gamma, \mathbf{w})$, and
- (iii) narrow-sense RS codes are GRS codes with $n=q-1, \gamma_i = \alpha^i$, and $v_i=1$ for $0 \le i \le n-1$.

Narrow-sense $[q-1, k, q-k]$ Reed-Solomon codes over $\mathbb{F}_q$ can be extended to MDS codes as follows. Let $C = \{ (f(1), f(\alpha), f(\alpha^2), \dots, f(\alpha^{q-2})) \mid f \in \mathcal{P}_k \}$ be such a code. Exercise 292 shows that if $f \in \mathcal{P}_k$, where $k < q$, then $\sum_{\beta \in \mathbb{F}_q} f(\beta) = 0$. So

$\widehat{C} = \{ ((f(1), f(\alpha), f(\alpha^2), \dots, f(\alpha^{q-2}), f(0)) \mid f \in \mathcal{P}_k \}$

is the extension of $C$. Notice that this is also a GRS code with $n=q, \gamma_i = \alpha^i$ for $0 \le i \le n-2, \gamma_{n-1} = 0$, and $v_i = 1$ for $0 \le i \le n-1$. Therefore $\widehat{C}$ is a $[q, k, q-k+1]$ MDS code. In other words, when extending the narrow sense RS codes by adding an overall parity check, the minimum weight increases, an assertion that can be guaranteed in general for codes over arbitrary fields only if the minimum weight vectors are all odd-like. This results in the following theorem.
