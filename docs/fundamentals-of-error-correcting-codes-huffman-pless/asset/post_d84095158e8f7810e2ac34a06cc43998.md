Notice that $e_8$ is merely the $[8, 4, 4]$ extended Hamming code $\hat{\mathcal{H}}_3$, while $e_7$ is the $[7, 3, 4]$ simplex code. As we mentioned in Example 9.6.2, the automorphism group of $e_8$ is isomorphic to the 3-dimensional general affine group over $\mathbb{F}_2^3$, often denoted $GA_3(2)$, of order 1344. This group is a triply-transitive permutation group on eight points. The subgroup stabilizing one point is a group of order 168, denoted either $PSL_2(7)$ or $PSL(3,2)$; this is the automorphism group of $e_7$. The codes $i_2$ and $d_4$ have automorphism groups $\text{Sym}_8$ and $\text{Sym}_4$ of orders 40320 and 24, respectively. When $m > 2$, the generator matrix for $d_{2m}$ has identical columns $(2i - 1, 2i)$ for $1 \le i \le m$. Any permutation interchanging columns $2i - 1$ and $2i$ is an automorphism of $d_{2m}$; any permutation sending all pairs $(2i - 1, 2i)$ to pairs is also an automorphism. These generate all automorphisms, and $\text{PAut}(d_{2m})$ has order $2^m m!$ when $m > 2$.

We need some additional terminology and notation. If the code $\mathcal{C}_1$ is equivalent to $\mathcal{C}_2$, then we denote this by $\mathcal{C}_1 \simeq \mathcal{C}_2$. A code $\mathcal{C}$ is *decomposable* if $\mathcal{C} \simeq \mathcal{C}_1 \oplus \mathcal{C}_2$, where $\mathcal{C}_1$ and $\mathcal{C}_2$ are nonzero codes. If $\mathcal{C}$ is not equivalent to the direct sum of two nonzero codes, it is *indecomposable*. The codes $i_2$, $e_7$, $e_8$, and $d_{2m}$ are indecomposable. The symbol $m\mathcal{C}$ will denote the direct sum of $m$ copies of the code $\mathcal{C}$; its length is obviously $m$ times the length of $\mathcal{C}$. Finally, when we say that $\mathcal{C}'$ (for example, $i_2$, $e_7$, $e_8$, or $d_{2m}$) is a "subcode" of $\mathcal{C}$ where the length $n$ of $\mathcal{C}$ is longer than the length $n'$ of $\mathcal{C}'$, we imply that $n - n'$ additional zero coordinates are appended to $\mathcal{C}'$ to make it length $n$.

The following basic theorem is very useful in classifying self-dual binary codes.

### Theorem 9.7.2 Let $\mathcal{C}$ be a self-orthogonal binary code of length $n$ and minimum weight $d$.

The following hold:

- (i) If $d=2$, then $\mathcal{C} \simeq m i_2 \oplus \mathcal{C}_1$ for some integer $m \ge 1$, where $\mathcal{C}_1$ is a self-orthogonal code of length $n-2m$ with minimum weight 4 or more.
- (ii) If $e_8$ is a subcode of $\mathcal{C}$, then $\mathcal{C} \simeq e_8 \oplus \mathcal{C}_1$ for some self-dual code $\mathcal{C}_1$ of length $n-8$.
- (iii) If $d=4$, then the subcode of $\mathcal{C}$ spanned by the codewords of $\mathcal{C}$ of weight 4 is a direct sum of copies of $d_{2m}$'s, $e_7$'s, and $e_8$'s.

## 9.7.2 Gluing theory

Gluing is a way to construct self-dual codes C of length n from shorter self-orthogonal codes systematically. We build C by beginning with a direct sum C_1 C_2 ... C_r of self-orthogonal codes, which form a subcode of C. If C is decomposable, then C is this direct sum. If not, then we add additional vectors, called glue vectors, so that we eventually obtain a generator matrix for C from the generator matrix for C_1 C_2 ... C_r and the glue vectors. The codes C_i are called the components of C. Component codes are chosen so that any automorphism of C will either send a component code onto itself or possibly permute some components among themselves. This technique has several additional advantages; namely, it can be used to compute the order of the automorphism group of the code, which is crucial in the Classification Algorithm, and it also allows us to describe these codes efficiently. Gluing has been most effective in constructing self-dual codes of minimum weight 4. In this situation, the direct sum of component codes will contain all the vectors of weight 4 in the resulting code; if this does not produce the entire code, we add glue vectors taking care not to introduce any new weight 4 vectors. These component codes are determined in Theorem 9.7.2 to be d_{2m}, e_7, and e_8. However, if e_8 is a component, Theorem 9.7.2(ii) shows that C is decomposable; in this case we do not need to use glue.

The glue vectors for d_{2m} and e_7 consist of shorter length glue elements that are juxtaposed to form the glue vectors. The glue elements are simply elements of cosets of C_i in C_i^\perp.
