Let B7 be the block containing {1, 2, 3, 6, 9}; B7 intersects B1, B2, and B3 in no other points and intersects B4, B5, and B6 each in one more point. Let B8 be the block containing {1, 2, 4, 6, 9}; B8 intersects B1, B2, B4, and B7 in no other points and intersects B3, B5, and B6 each in one more point. For either B12 or B12', the 12 weight 8 vectors whose supports are the blocks generate a 12-dimensional code in F_2^24, as can be easily seen by row reduction. Call the resulting codes C' and C''.
