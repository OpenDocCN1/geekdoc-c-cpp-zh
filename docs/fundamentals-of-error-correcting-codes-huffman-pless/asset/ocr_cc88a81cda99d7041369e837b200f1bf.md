doubly-even subcode $\mathcal{C}_0$ by Theorem 1.4.6. Conversely, if $\mathcal{C}_0$ is an $[n, (n/2) - 1]$ doubly-even code, it does not contain $\mathbf{1}$ as $n \equiv 2 \pmod 4$. So the only self-dual code containing $\mathcal{C}_0$ must be obtained by adjoining $\mathbf{1}$. Thus the number of doubly-even $[n, (n/2) - 1]$ binary codes equals the number of self-dual codes; (ii) now follows by Theorem 9.5.1.
