Theorem 4.3.13 shows that \(\mu_a\) maps cyclic codes to cyclic codes with the generating idempotent mapped to the generating idempotent; however, the generator polynomial may not be mapped to the generator polynomial of the image code. In fact, the automorphism \(\mu_a\) maps the generator polynomial to its \(qh\) power. See Exercise 232.

A multiplier takes a cyclic code into an equivalent cyclic code. The following theorem, a special case of a theorem of Pálfy (see [150]), implies that, in certain instances, two cyclic codes are permutation equivalent if and only if a multiplier takes one to the other. This is a very powerful result when it applies.

### **Theorem 4.3.17** Let \(C_1\) and \(C_2\) be cyclic codes of length \(n\) over \(\mathbb{F}_q\). Assume that \(\gcd(n, \phi(n)) = 1\), where \(\phi\) is the Euler \(\phi\)-function. Then \(C_1\) and \(C_2\) are permutation equivalent if and only if there is a multiplier that maps \(C_1\) to \(C_2\).

Since multipliers send generating idempotents to generating idempotents, we have the following corollary.

### **Corollary 4.3.18** Let \(C_1\) and \(C_2\) be cyclic codes of length \(n\) over \(\mathbb{F}_q\). Assume that \(\gcd(n, \phi(n)) = 1\), where \(\phi\) is the Euler \(\phi\)-function. Then \(C_1\) and \(C_2\) are permutation equivalent if and only if there is a multiplier that maps the idempotent of \(C_1\) to the idempotent of \(C_2\).

## 4.4 Zeros of a cyclic code

Recall from Section 4.1 and, in particular Theorem 4.1.1, that if \(t = \text{ord}_n(q)\), then \(\mathbb{F}_q\) is a splitting field of \(x^n - 1\); so \(\mathbb{F}_q\) contains a primitive nth root of unity \(\alpha\), and \(x^n - 1 = \prod_{i=0}^{n-1} (x - \alpha^i)\) is the factorization of \(x^n - 1\) into linear factors over \(\mathbb{F}_q\). Furthermore \(x^n - 1 = \prod_i M_{\alpha^i}(x)\) is the factorization of \(x^n - 1\) into irreducible factors over \(\mathbb{F}_q\), where \(s\) runs through a set of representatives of the \(q\)-cyclotomic cosets modulo \(n\).

Let \(\mathcal{C}\) be a cyclic code in \(\mathcal{R}_n\) with generator polynomial \(g(x)\). By Theorems 4.1.1(i) and 4.2.1(vii), \(g(x) = \prod_i M_{\alpha^i}(x) = \prod_i \prod_{c \in C_i} (x - \alpha^c)\), where \(s\) runs through some subset of representatives of the \(q\)-cyclotomic cosets \(\mathcal{C}_i\) modulo \(n\). Let \(T = \bigcup_i C_i\) be the union of these \(q\)-cyclotomic cosets. The roots of unity \(\mathcal{Z} = \{\alpha^i \mid i \in T\}\) are called the zeros of the cyclic code \(\mathcal{C}\) and \(\{\alpha^i \mid i \notin T\}\) are the nonzeros of \(\mathcal{C}\). The set \(T\) is called the *defining set* of \(\mathcal{C}\). (Note that if we change the primitive \(n\)th root of unity, you change \(T\); so \(T\) is computed relative to a fixed primitive root. This will be discussed further in Section 4.5.) It follows that \(c(x)\) belongs to \(\mathcal{C}\) if and only if \(c(\alpha^i) = 0\) for each \(i \in T\) by Theorem 4.2.1. Notice that \(T\), and hence either the set of zeros or the set of nonzeros, completely determines the generator polynomial \(g(x)\). By Theorem 4.2.1, the dimension of \(\mathcal{C}\) is \(n - |T|\) as \(|T|\) is the degree of \(g(x)\).

The zeros of a cyclic code can be used to obtain a parity check matrix (possibly with dependent rows) as explained in the next theorem. The construction presented in this theorem is analogous to that of the subfield subcode construction in Section 3.8.

### **Theorem 4.4.3** Let \(C\) be an \([n, k]\) cyclic code over \(\mathbb{F}_q\) with zeros \(Z\) in a splitting field \(\mathbb{F}_{q^t}\) of \(x^n - 1\) over \(\mathbb{F}_q\). Let \(\alpha \in \mathbb{F}_{q^t}\) be a primitive \(n\)th root of unity in \(\mathbb{F}_{q^t}\), and let \(Z = \{\alpha^j \mid j \in C_{i_1} \cup \cdots \cup C_{i_w}\}\), where \(C_{i_1}, \dots, C_{i_w}\) are distinct \(q\)-cyclotomic cosets modulo \(n\). Let \(L\) be the \(w \times n\) matrix over \(\mathbb{F}_q\) defined by

\[
L = \left[ \begin{array}{ccccc}
1 & \alpha^{i_1} & \alpha^{2i_1} & \cdots & \alpha^{(n-1)i_1} \\
1 & \alpha^{i_2} & \alpha^{2i_2} & \cdots & \alpha^{(n-1)i_2} \\
\vdots & \vdots & \vdots & \ddots & \vdots \\
1 & \alpha^{i_w} & \alpha^{2i_w} & \cdots & \alpha^{(n-1)i_w}
\end{array} \right].
\]

Then \(c\) is in \(C\) if and only if \(Lc^T = 0\). Choosing a basis of \(\mathbb{F}_{q^t}\) over \(\mathbb{F}_q\), we may represent each element of \(\mathbb{F}_{q^t}\) as a \(t \times 1\) column vector over \(\mathbb{F}_q\). Replacing each entry of \(L\) by its corresponding column vector, we obtain a \(tw \times n\) matrix \(H\) over \(\mathbb{F}_q\) which has the property that \(c \in C\) if and only if \(Hc^T = 0\). In particular, \(k \ge n - tw\).

**Proof:** We have \(c(x) \in C\) if and only if \(c(\alpha^j) = 0\) for all \(j \in C_{i_1} \cup \cdots \cup C_{i_w}\), which by Theorem 3.7.4 is equivalent to \(c(\alpha^{j'}) = 0\) for \(1 \le j \le w\). Clearly, this is equivalent to \(Lc^T = 0\), which is a system of homogeneous linear equations with coefficients that are powers of \(\alpha\). Expanding each of these powers of \(\alpha\) in the chosen basis of \(\mathbb{F}_{q^t}\) over \(\mathbb{F}_q\) yields the equivalent system \(Hc^T = 0\). As the rows of \(H\) may be dependent, \(k \ge n - tw\).

If \(C'\) is the code over \(\mathbb{F}_{q^t}\) with parity check matrix \(L\) in this theorem, then the code \(C\) is actually the subfield subcode \(C'|_{\mathbb{F}_q}\).
