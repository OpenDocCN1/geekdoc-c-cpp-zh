# **Theorem 13.2.1** In the notation of this section, the Goppa code \( \Gamma(L, G) \) with \( \deg(G(x)) = w \) is an \( [n, k, d] \) code, where \( k \ge n - wt \) and \( d \ge w + 1 \).
