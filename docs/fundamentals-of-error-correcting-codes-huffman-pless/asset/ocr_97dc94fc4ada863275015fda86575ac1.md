# **Theorem 9.2.1 (Gleason)** Let $C$ be an $[n, n/2]$ code over $\mathbb{F}_q$, where $q = 2, 3,$ or $4$. Let

+   $g_1(x, y) = y^2 + x^2,$
+   $g_2(x, y) = y^8 + 14x^4y^4 + x^8,$
+   $g_3(x, y) = y^{24} + 759x^8y^{16} + 2576x^{12}y^{12} + 759x^{16}y^8 + x^{24},$
+   $g_4(x, y) = y^4 + 8xy^3,$
+   $g_5(x, y) = y^{12} + 264x^6y^6 + 440x^9y^3 + 24x^{12},$
+   $g_6(x, y) = y^2 + 3x^2, \text{ and}$
+   $g_7(x, y) = y^6 + 45x^4y^2 + 18x^6.$

Then:

+   (i) if $q = 2$ and $C$ is formally self-dual and even,
+   
+   $$W_C(x, y) = \sum_{i=0}^{\lfloor \frac{n}{2} \rfloor} a_i g_1(x, y)^{\frac{n}{4}-\frac{i}{2}} g_2(x, y)^i,$$

+   (ii) if $q = 2$ and $C$ is self-dual and doubly-even,
+   
+   $$W_C(x, y) = \sum_{i=0}^{\lfloor \frac{n}{2} \rfloor} a_i g_2(x, y)^{\frac{n}{8}-3i} g_3(x, y)^i,$$

+   (iii) if $q = 3$ and $C$ is self-dual,
+   
+   $$W_C(x, y) = \sum_{i=0}^{\lfloor \frac{n}{2} \rfloor} a_i g_4(x, y)^{\frac{n}{4}-3i} g_5(x, y)^i, \text{ and}$$

+   (iv) if $q = 4$ and $C$ is Hermitian self-dual,
+   
+   $$W_C(x, y) = \sum_{i=0}^{\lfloor \frac{n}{2} \rfloor} a_i g_6(x, y)^{\frac{n}{2}-3i} g_7(x, y)^i.$$

In all cases, all $a_i$'s are rational and $\sum a_i = 1$.
