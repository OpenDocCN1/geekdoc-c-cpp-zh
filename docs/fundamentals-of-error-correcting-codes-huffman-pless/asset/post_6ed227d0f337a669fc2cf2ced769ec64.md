
**Lemma 9.12.4** For \(i = 1\) and \(2\), let \(C_i\) be an \([n, k_i]\) even binary code with \(C_i \cap C_i^\perp = \{0\}\) and \(k_1 + 2 \le k_2\). Suppose that \(C_1 \subset C_2\). Then there exists either an \(H\)-plane or \(A\)-plane \(\mathcal{P}\) in \(C_2\) orthogonal to \(C_1\) with \(C_1 \cap \mathcal{P} = \{0\}\).

**Proof:** Let \(\{x_1, \dots, x_k\}\) be a basis of \(C_1\). Define the linear function \(f : C_2 \to \mathbb{F}_2^k\) by \(f(x) = (x \cdot x_1, \dots, x \cdot x_k)\). If \(f|_{C_1}\) is the restriction of \(f\) to \(C_1\), the kernel of \(f|_{C_1}\) is \(C_1 \cap C_1^\perp = \{0\}\). Thus \(f|_{C_1}\), and hence \(f\), is surjective. The kernel \(\mathcal{K}\) of \(f\) is an \([n, k_2 - k_1]\) code orthogonal to \(C_1\). As \(C_1 \cap C_1^\perp = \{0\}\), \(K \cap C_1 = \{0\}\) and so \(k_2 = k_1 + \dim \mathcal{K}\). If \(x \in K \cap K^\perp\), then \(x \in C_2 \cap C_2^\perp\); hence \(K \cap K^\perp = \{0\}\). The result follows by Lemma 7.8.2 applied to \(K\).

We now prove the counting formula given in Theorem 9.5.5(i). While the result is found in [219], the proof is different.

**Theorem 9.12.5** If \(n \equiv 0 \pmod 8\), then there are

\(\prod_{i=0}^{k-2} (2^i + 1)\)

Type II codes of length \(n\).

**Proof:** Let \(\mu_{n,k}\) be the number of \([n, k]\) doubly-even codes containing \(1\). Clearly, \(\mu_{n,1} = 1\). As in the proof of Theorem 9.5.1, we find a recurrence relation for \(\mu_{n,k}\). We illustrate the recursion process by computing \(\mu_{n,2}\). By Corollary 9.12.3, there are \(2^{n-2} + 2^{n/2-1} - 2\) doubly-even vectors that are neither \(0\) nor \(1\). Each of these vectors is in a unique doubly-even \([n, 2]\) code containing \(1\); each such code contains two of these vectors. So \(\mu_{n,2} = 2^{n-3} + 2^{n/2-2} - 1\). Let \(C\) be any \([n, k]\) doubly-even code containing \(1\). As \(C\) is self-orthogonal, if \(C'\) is any vector space complement of \(\text{span}\{1\}\) in \(C\), then \(C = \text{span}\{1\} \perp C'\). By Lemma 9.12.1, applied to the \([n, k-1]\) code \(C'\), \(C' \subseteq \mathcal{H}_1 \perp \cdots \perp \mathcal{H}_{k-1}\), where \(\mathcal{H}_i\) are H-planes. Let \(E\) be any vector space complement of \(1\) in \(\mathcal{E}_n\) containing \(\mathcal{H}_1 \perp \cdots \perp \mathcal{H}_{k-1}\). Clearly, \(E_n = \text{span}\{1\} \perp E\) and \(E \cap E^\perp = \{0\}\). Note that \(E\) has even dimension \(n-2\). Now apply Lemmas 7.8.4 and 9.12.4 inductively, initially beginning with \(C_1 = \mathcal{H}_1 \perp \cdots \perp \mathcal{H}_{k-1}\) and always using \(C_2 = E\) in each step of the induction. Then there exist \(\mathcal{H}_k, \dots, \mathcal{H}_{n/2-1}\) which are either H-planes or A-planes such that \(E = \mathcal{H}_1 \perp \cdots \perp \mathcal{H}_{n/2-1}\). Thus \(E_n = \text{span}\{1\} \perp \mathcal{H}_1 \perp \cdots \perp \mathcal{H}_{n/2-1}\). By Exercise 418, we may assume that at most one \(\mathcal{H}_i\) is an A-plane. But, if one is an A-plane, then \(E_n\) has form A, contradicting Theorem 9.12.2. If we want to extend \(C\) to an \([n, k+1]\) doubly-even code \(C'\), we must add a nonzero doubly-even vector \(c'\) from \(D = \mathcal{H}_k \perp \cdots \perp \mathcal{H}_{n/2-1}\). By Lemma 7.8.4, \(D \cap D^\perp = \{0\}\). By Theorem 7.8.6, there are \(2^{2n-1} + 2^{n/2-1}\) doubly-even vectors in \(D\), implying that there are \(2^{n-2k-1} + 2^{n/2-k-1} - 1\) choices for \(c''\). However, every such \(C''\) has \(2^k - 1\) doubly-even subcodes of dimension \(k\) containing \(1\) by Exercise 522(a). This shows that

\(\mu_{n,k+1} = \frac{2^{n-2k} + 2^{n/2-k} - 1}{2^k - 1} \mu_{n,k}.\)

When \(k = 1\), we obtain \(\mu_{n,2} = 2^{n-3} + 2^{n/2-2} - 1\), in agreement with the value we obtained above. Using this recurrence relation, the number of Type II codes of length n is

```
\mu_{n,n/2} = \frac{2^1 + 2^0 - 1}{2^{n/2-1} - 1} \frac{2^2 + 2^1 - 1}{2^{n/2-2} - 1} \frac{2^5 + 2^2 - 1}{2^{n/2-3} - 1} \cdots \frac{2^{n-3} + 2^{n/2-2} - 1}{2^1 - 1} \cdot \mu_{n,1}
= \frac{2^1 + 2^0 - 1}{2^1 + 2^0 - 1} \frac{2^2 + 2^1 - 1}{2^2 + 2^1 - 1} \frac{2^5 + 2^2 - 1}{2^3 + 2^1 - 1} \cdots \frac{2^{n-3} + 2^{n/2-2} - 1}{2^{n/2-1} - 1}
= 2(2^1 + 1)(2^2 + 1) \cdots (2^{n/2-2} + 1),
```

which is the desired result.

## 10 Some favorite self-dual codes

### 10.1 The binary Golay codes

In this section we examine in more detail the binary Golay codes of lengths 23 and 24. We have established the existence of a [23, 12, 7] and a [24, 12, 8] binary code in Section 1.9.1. Recall that our original construction of the [24, 12, 8] extended binary Golay code used a bordered reverse circulant generator matrix, and the [23, 12, 7] code was obtained by puncturing. Since then we have given different constructions of these codes, both of which were claimed to be unique codes of their length, dimension, and minimum distance. We first established this uniqueness.

### 10.1.1 Uniqueness of the binary Golay codes

Throughout this section let C be a (possibly nonlinear) binary code of length 23 and minimum distance 7 containing \( M \ge 2^{12} \) codewords, one of which is \(\mathbf{0}\). In order to prove the uniqueness of C, we first show it has exactly \( 2^{12} \) codewords and is perfect. We then show it has a uniquely determined weight distribution and is in fact linear. This proof of linearity follows along the lines indicated by [244].

**Lemma 10.1.1** C is a perfect code with \( 2^{12} \) codewords.

**Proof:** By the Sphere Packing Bound.

\[
M \left[ \binom{23}{0} + \binom{23}{1} + \binom{23}{2} + \binom{23}{3} \right] \le 2^{23} .
\]

implying \( M \le 2^{12} \). Hence \( M = 2^{12} \), and we have equality in (10.1), which indicates that C is perfect.

**Lemma 10.1.2** Let \( A_i = A_i(\mathcal{C}) \) be the weight distribution of \(\mathcal{C}\). Then

\[
A_0 = A_{23} = 1, \quad A_7 = A_{16} = 253, \quad A_8 = A_{15} = 506, \quad A_{11} = A_{12} = 1288.
\]

Proof: As $\mathcal{C}$ is perfect, the spheres of radius 3 centered at codewords are disjoint and cover $\mathbb{F}_2^{23}$. In this proof, let $N(w, c)$ denote the number of vectors in $\mathbb{F}_2^{23}$ of weight $w$ in a sphere of radius 3 centered at a codeword $c$; note that $N(w, c)$ is independent of the codeword chosen. Note also that $N(w, c) = 0$ when $w$ and $c$ differ by more than 3. Since the spheres of radius 3 pack $\mathbb{F}_2^{23}$ disjointly, we have

\(\sum_{c=0}^{23} N(w, c) A_c = \binom{23}{w}.\) (10.2)

as every vector in $\mathbb{F}_2^{23}$ of weight $w$ is in exactly one sphere of radius 3 centered at a codeword. The verification of the weight distribution merely exploits (10.2) repeatedly.

Clearly, $A_0 = 1$ and $A_i = 0$ for $1 \le i \le 6$. We now compute $A_7, A_8, \dots, A_{23}$ in order. The strategy when computing $A_i$ is to count the number of vectors in $\mathbb{F}_2^{23}$ of weight $w = i - 3$ that are in spheres of radius 3 centered at codewords and then use (10.2).

Computation of $A_7$: Any vector $\mathbf{x} \in \mathbb{F}_2^{23}$ with wt$(\mathbf{x}) = 4$ must be in a unique sphere centered at some codeword $\mathbf{c}$ with wt$(\mathbf{c}) = 7$. Clearly, supp$(\mathbf{x}) \subset$ supp$(\mathbf{c})$ showing that $N(4, 7) = \binom{7}{4}$. Hence, (10.2) becomes $N(4, 7) A_7 = \binom{23}{4} = 8855$ implying $A_7 = 253$.

Computation of $A_8$: Any vector $\mathbf{x} \in \mathbb{F}_2^{23}$ with wt$(\mathbf{x}) = 5$ must be in a unique sphere centered at some codeword $\mathbf{c}$ with wt$(\mathbf{c}) = 7$ or $8$. In either case, supp$(\mathbf{x}) \subset$ supp$(\mathbf{c})$, showing that $N(5, 7) = \binom{7}{5}$ and $N(5, 8) = \binom{8}{5}$. Equation (10.2) becomes $N(5, 7) A_7 + N(5, 8) A_8 = \binom{7}{5} A_7 + \binom{8}{5} A_8 = \binom{23}{5}$ yielding $A_8 = 506$.

Computation of $A_9$: Any vector $\mathbf{x} \in \mathbb{F}_2^{23}$ with wt$(\mathbf{x}) = 6$ must be in a unique sphere centered at some codeword $\mathbf{c}$ with wt$(\mathbf{c}) = 7, 8, \text{or } 9$. If wt$(\mathbf{c}) = 7$, supp$(\mathbf{x}) \subset$ supp$(\mathbf{c})$ or supp$(\mathbf{x})$ overlaps supp$(\mathbf{c})$ in five coordinates. Thus $N(6, 7) = \binom{7}{6} + \binom{7}{1} \binom{16}{1} = 343$. If wt$(\mathbf{c}) = 8$ or $9$, supp$(\mathbf{x}) \subset$ supp$(\mathbf{c})$. Hence, $N(6, 8) = \binom{8}{6} = 28$ and $N(6, 9) = \binom{9}{6} = 84$. Equation (10.2) is $N(6, 7) A_7 + N(6, 8) A_8 + N(6, 9) A_9 = 343 \cdot 253 + 28 \cdot 506 + 84 A_9 = \binom{23}{6}$. Thus $A_9 = 0$.

The remaining values of $A_i$ can be computed in a similar way. We only give the equations that arise when $10 \le i \le 12$, and leave their derivation and solution as exercises.

Computation of $A_{10}$: $(1 + \binom{10}{1} \binom{13}{1}) A_7 + (\binom{10}{2} + \binom{10}{1} \binom{13}{1}) A_8 + \binom{10}{3} A_{10} = \binom{23}{7}$.
Computation of $A_{11}$: $(\binom{11}{1} + \binom{11}{1} \binom{12}{1}) A_7 + (1 + \binom{11}{1} \binom{12}{1}) A_8 + \binom{11}{3} A_{11} = \binom{23}{8}$.
Computation of $A_{12}$: $(\binom{12}{1} A_7 + (\binom{12}{1} + \binom{12}{1} \binom{11}{1}) A_8 + \binom{12}{3} A_{11} + \binom{12}{4} A_{12} = \binom{23}{9}$.

The reader is invited to complete the proof. $\square$

We remark that we do not actually have to calculate the weight distribution of $\mathcal{C}$; examining the proof, we see that each $A_i$ is unique. Since we know that the $(23, 12, 7)$ binary Golay code $\mathcal{G}_{23}$ exists, $\mathcal{C}$ must have the same weight distribution as $\mathcal{G}_{23}$, which was presented in Exercise 403.
