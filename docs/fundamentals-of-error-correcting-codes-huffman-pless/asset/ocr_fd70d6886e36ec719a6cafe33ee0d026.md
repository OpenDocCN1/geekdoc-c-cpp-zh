Now assume that \(d > 2\). Then for \(i \neq j\), the cosets \(\mathcal{C}' + \mathbf{e}_i\) and \(\mathcal{C}' + \mathbf{e}_j\) are distinct. By definition, every child of \(\mathcal{C}'\) equals \(\mathcal{C}' + \mathbf{e}_i\) for some \(i\). Such a coset is a child if and only if some coset leader of \(\mathcal{C}'\) has a 1 in coordinate \(i\). This proves (ii).

Suppose now that \(\mathcal{C}'\) is even and \(d > 2\). As in the proof of (i) each parent of \(\mathcal{C}'\) equals \(\mathcal{C}' + \mathbf{e}_i\) for some \(i\). In order for \(\mathcal{C}' + \mathbf{e}_i\) to be a parent of \(\mathcal{C}'\), every vector in \(\mathcal{C}'\) of weight \(w\) or \(w + 1\) must not have a 1 in coordinate \(i\). As \(\mathcal{C}'\) is even, a coset has only even weight vectors or only odd weight vectors; thus \(\mathcal{C}'\) has no vectors of weight \(w + 1\). The first part of (iii) now follows, noting that \(\mathcal{C}' \neq \mathbf{e}_i \neq \mathcal{C}' + \mathbf{e}_j\) if \(i \neq j\). The second part of (iii) follows directly from the first.

We leave the proof of the following corollary as an exercise.

> **Corollary 11.7.11** Let \(\mathcal{C}\) be an \([n, k, d]\) even binary code with \(d > 2\). The following hold:
> (i) An orphan of \(\mathcal{C}\) has \(n\) descendants of weight 1 and \(n\) children.
> (ii) A coset of weight \(w\), which has exactly \(i\) coset leaders where \(tw < n\), is not an orphan.
