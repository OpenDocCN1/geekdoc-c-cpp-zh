
- (ii) The even-like quadratic residue codes over $\mathbb{F}_3$ have generating idempotents

```
$- \sum_{j \in Q_p} x^j \quad \text{and} \quad - \sum_{j \in N_p} x^j,$
```

if $p \equiv 1 (\text{mod } 12)$, and

```
$1 + \sum_{j \in Q_p} x^j \quad \text{and} \quad 1 + \sum_{j \in N_p} x^j,$
```

if $p \equiv -1 (\text{mod } 12).$

- (iii) The odd-like quadratic residue codes over $\mathbb{F}_3$ have generating idempotents

```
$1 + \sum_{j \in Q_p} x^j \quad \text{and} \quad 1 + \sum_{j \in N_p} x^j,$
```

if $p \equiv 1 (\text{mod } 12)$, and

```
$- \sum_{j \in Q_p} x^j \quad \text{and} \quad - \sum_{j \in N_p} x^j,$
```

if $p \equiv -1 (\text{mod } 12).$

Proof: Part (i) follows from Theorem 6.6.2 and Lemma 6.2.9. Let $p \equiv \pm 1 (\text{mod } 12)$. If $e(x)$ is a generating idempotent for an even-like QR code $C_1$ over $\mathbb{F}_3$, then by Theorem 6.6.3, $e(x) = a_0 + a_1 Q(x) + a_2 N(x)$, where $a_i \in \mathbb{F}_3$ for $0 \le i \le 2$. The other even-like QR code $C_2$ paired with $C_1$, has generating idempotent $e(x)\mu_b$, where $b \in N_p$ by Theorem 6.6.4. Lemma 6.6.1 implies that

```
$Q(x)\mu_b = Q(x^p) = N(x) \text{ and } N(x)\mu_b = N(x^p) = Q(x).$
```

Therefore $e(x)\mu_b = a_0 + a_2 Q(x) + a_1 N(x).$

We first consider the case $p \equiv 1 (\text{mod } 12)$. By Theorem 6.6.4(ii),

```
$e(x) + e(x)\mu_b = -x - x^2 - \cdots - x^{p-1},$
```

implying that $2a_0 = 0$ and $a_1 + a_2 = -1$. Thus $a_0 = 0$ and either $a_1 = a_2 = 1$ or $(a_1, a_2) = (0, -1)$. If $a_1 = a_2 = 1$, then $e(x) = Q(x) + N(x)$, but $Q(x) + N(x) = -(1 - J(x))$, which is the negative of the idempotent generator of the even-like code $E_p$. Thus $a_1 = a_2 = 1$ is not possible. So the two possibilities remaining for $\{a_1, a_2\}$ must lead to generating idempotents for the two even-like QR codes that we know must exist. The generating idempotents for the odd-like codes follow from Theorem 6.6.4.

We now consider the case $p \equiv -1 (\text{mod } 12)$. By Theorem 6.6.4(ii),

```
$e(x) + e(x)\mu_b = -1 + x + x^2 + \cdots + x^{p-1},$
```

implying that $2a_0 = -1$ and $a_1 + a_2 = 1$. Thus $a_0 = 1$ and either $a_1 = a_2 = -1$ or $\{a_1, a_2\} = \{0, 1\}$. Again $1 - Q(x) - N(x) = -(-1 - J(x))$ generates $E_p$, and so $a_1 = a_2 = -1$ is impossible. The generating idempotents for the even-like and odd-like codes follow as above.

- (ii) The even-like quadratic residue codes over \(\mathbb{F}_9\) have generating idempotents \(1+\rho \sum_{j \in \mathcal{Q}_p} x^j + \rho^3 \sum_{j \in \mathcal{N}_p} x^j\) and \(1+\rho^3 \sum_{j \in \mathcal{Q}_p} x^j + \rho \sum_{j \in \mathcal{N}_p} x^j\), if \(p \equiv 5 (\text{mod } 12)\), and \(-\rho \sum_{j \in \mathcal{Q}_p} x^j - \rho^3 \sum_{j \in \mathcal{N}_p} x^j\) and \(-\rho^3 \sum_{j \in \mathcal{Q}_p} x^j - \rho \sum_{j \in \mathcal{N}_p} x^j\), if \(p \equiv -5 (\text{mod } 12)\).

- (iii) The odd-like quadratic residue codes over \(\mathbb{F}_9\) have generating idempotents \(-\rho \sum_{j \in \mathcal{Q}_p} x^j - \rho^3 \sum_{j \in \mathcal{N}_p} x^j\) and \(-\rho^3 \sum_{j \in \mathcal{Q}_p} x^j - \rho \sum_{j \in \mathcal{N}_p} x^j\), if \(p \equiv 5 (\text{mod } 12)\), and \(1 + \rho \sum_{j \in \mathcal{Q}_p} x^j + \rho^3 \sum_{j \in \mathcal{N}_p} x^j\) and \(1 + \rho^3 \sum_{j \in \mathcal{Q}_p} x^j + \rho \sum_{j \in \mathcal{N}_p} x^j\), if \(p \equiv -5 (\text{mod } 12)\).

Proof: Part (i) follows from Theorem 6.6.4. Let $e(x)$ be a generating idempotent for an even-like QR code $C_1$ over $\mathbb{F}_q$ of length $p$ with $p \equiv \pm 5 (\text{mod } 12)$. Then by Theorem 6.6.3, $e(x) = a_0 + a_1 Q(x) + a_2 N(x)$, where $a_i \in \mathbb{F}_q$ for $0 \le i \le 2$. Thus $e(x)^3 = a_0^3 + a_1^3 N(x) + a_2^3 Q(x) + a_2^3 Q(x) = e(x)$, implying $a_0^3 = a_0$ and $a_2 = a_1^3$. The other even-like QR code $C_2$ paired with $C_1$ has generating idempotent $e(x)\mu_b$, where $b \in N_p$ by Theorem 6.6.4. Again by Lemma 6.6.1, $Q(x)\mu_b = Q(x^b) = N(x)$ and $N(x)\mu_b = N(x^b) = Q(x)$. Therefore, $e(x) = a_0 + a_1 Q(x) + a_1^3 N(x)$ and $e(x)\mu_b = a_0 + a_1^3 Q(x) + a_1 N(x)$.

## 6.6.3 Extending QR codes

As with any of the duadic codes, we can consider extending odd-like quadratic residue codes in such a way that the extensions are self-dual or dual to each other. These extensions may not be the ordinary extensions obtained by adding an overall parity check, but all the extensions are equivalent to that obtained by adding an overall parity check. Before examining the general case, we look at QR codes over $\mathbb{F}_2$, $\mathbb{F}_3$, and $\mathbb{F}_4$. In these cases, it is sufficient to use the ordinary extension.

### Theorem 6.6.14 Let $D_1$ and $D_2$ be the odd-like QR codes over $\mathbb{F}_q$ of odd prime length $p$.

- (i) When $q = 2$, the following hold:
- (a) $D_1$ and $D_2$ are duals of each other when $p \equiv 1 (\text{mod } 8)$.
- (b) $D_1$ is self-dual and doubly-even for $i = 1$ and $2$ when $p \equiv -1 (\text{mod } 8)$.

- (ii) When $q = 3$, the following hold:
- (a) $D_1$ is self-dual for $i = 1$ and $2$ when $p \equiv -1 (\text{mod } 12)$.
- (b) If $p \equiv 1 (\text{mod } 12)$, then $D_1$ and $D_2$ are duals of each other where $D$ is the diagonal radical diag$(1, \ldots, 1, -1)$.

- (iii) When $q = 4$, the following hold:
- (a) When $p \equiv 1 (\text{mod } 8)$, $D_1$ and $D_2$ are duals of each other under either the ordinary or the Hermitian inner product.
- (b) When $p \equiv 3 (\text{mod } 8)$, $D_1$ and $D_2$ are duals of each other under the Hermitian inner product; furthermore, $D_1$ is self-dual under the ordinary inner product for $i = 1$ and $2$.
- (c) When $p \equiv -3 (\text{mod } 8)$, $D_1$ and $D_2$ are duals of each other under the ordinary inner product; furthermore, $D_1$ is self-dual under the Hermitian inner product for $i = 1$ and $2$.
- (d) When $p \equiv -1 (\text{mod } 8)$, $D_1$ is self-dual under either the ordinary or the Hermitian inner product for $i = 1$ and $2$.

### Proof: Let $C_i$ be the even-like subcode of $D_i$.

We first consider the case $q = 2$ or $q = 4$. In either case, $J(x)$ is the all-one vector and its extension is the all-one vector of length $p + 1$; this extended all-one vector is orthogonal to itself under either the ordinary or Hermitian inner product. Suppose first that $p \equiv 1 (\text{mod } 8)$. By Lemmas 6.2.4 and 6.2.5, $-1$ and $-2$ are both in $Q_p$. Thus, $C_i \mu_{-1}, C_i \mu_{-2} = C_i$ for $i = 1$ and $2$. Applying Theorems 6.4.3 and 6.4.6, we obtain (i)(a) and (iii)(a). Consider next the case $p \equiv -1 (\text{mod } 8)$. This time by Lemmas 6.2.4 and 6.2.5, $-1$ and $-2$ are both in $N_p$. Thus $C_i \mu_{-1} = C_i \mu_{-2} = C_i$. By Lemmas 6.4.2 and 6.4.5, we obtain part of (i)(b) and all of (iii)(d). To complete (i)(b), we note that the generating idempotent for $D_i$ has weight $(p - 1)/2$ by Theorem 6.6.5 and hence $D_i$ has a generator matrix consisting of shifts of this idempotent by Theorem 4.3.6. Thus $D_i$ has a generator matrix consisting of vectors of weight $((p - 1)/2) + 1 = 0 (\text{mod } 4)$. Thus $D_i$ is doubly-even. The cases $p \equiv \pm 3 (\text{mod } 8)$ arise only when $q = 4$. Using the same argument, if $p \equiv 3 (\text{mod } 8)$, $-1$ in $N_p$ and $-2$ in $Q_p$, yielding (iii)(b) by Theorems 6.4.2 and 6.4.6. If $p \equiv -3 (\text{mod } 8)$, $-1$ in $Q_p$ and $-2$ in $N_p$, yielding (iii)(c) by Theorems 6.4.3 and 6.4.5.
