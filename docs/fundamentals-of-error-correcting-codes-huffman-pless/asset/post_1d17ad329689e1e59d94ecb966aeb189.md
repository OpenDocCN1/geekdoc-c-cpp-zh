## 4.7 Affine-invariant codes

In this section we will look at extending certain cyclic codes and examine an important class of codes called affine-invariant codes. Reed-Muller codes and some BCH codes, defined in Chapter 7, are affine-invariant.

We will present a new setting for “primitive” cyclic codes that will assist us in the description of affine-invariant codes. A primitive cyclic code over $\mathbb{F}_q$ is a cyclic code of length $n = q^l - 1$ for some $l$. To proceed, we need some notation.

Let $\mathcal{I}$ denote the field of order $q^l$, which is then an extension field of $\mathbb{F}_q$. The set $\mathcal{I}$ will be the index set of our extended cyclic codes of length $q^l$. Let $\mathcal{I}^*$ be the nonzero elements of $\mathcal{I}$, and suppose $\alpha$ is a primitive $n$th root of unity in $\mathcal{I}$ (and hence a primitive element of $\mathcal{I}$). The set $\mathcal{I}^*$ will be the index set of our primitive cyclic codes of length $n = q^l - 1$. With $X$ an indeterminate, let

$$\mathbb{F}_q[\mathcal{I}] = \left\{ a = \sum_{g \in \mathcal{I}} a_g X^g \mid a_g \in \mathbb{F}_q \text{ for all } g \in \mathcal{I} \right\}.$$

The set $\mathbb{F}_q[\mathcal{I}]$ is actually an algebra under the operations

$$c \sum_{g \in \mathcal{I}} a_g X^g + d \sum_{g \in \mathcal{I}} b_g X^g = \sum_{g \in \mathcal{I}} (c a_g + d b_g) X^g$$

for $c, d \in \mathbb{F}_q$, and

$$\sum_{g \in \mathcal{I}} a_g X^g \sum_{g \in \mathcal{I}} b_g X^g = \sum_{g \in \mathcal{I}} \left( \sum_{h \in \mathcal{I}} a_h b_{g-h} \right) X^g.$$

The zero and unity of $\mathbb{F}_q[\mathcal{I}]$ are $\sum_{g \in \mathcal{I}} 0 X^g$ and $X^0$, respectively. This is the group algebra of the additive group of $\mathcal{I}$ over $\mathbb{F}_q$. Let

$$\mathbb{F}_q[\mathcal{I}^*] = \left\{ a = \sum_{g \in \mathcal{I}^*} a_g X^g \mid a_g \in \mathbb{F}_q \text{ for all } g \in \mathcal{I}^* \right\}.$$

1 Cyclic codes of length $n = q^l - 1$ over an extension field of $\mathbb{F}_q$ are also called primitive, but we will only study the more restricted case.

$\mathbb{F}_q[\mathcal{I}^*]$ is a subspace of $\mathbb{F}_q[\mathcal{I}]$ but not a subalgebra. So elements of $\mathbb{F}_q[\mathcal{I}^*]$ are of the form

$\sum_{i=0}^{n-1} a_{a^i} X^{a^i}.$

while elements of $\mathbb{F}_q[\mathcal{I}]$ are of the form

$a_0 X^0 + \sum_{i=0}^{n-1} d_{a^i} X^{a^i}.$

The vector space $\mathbb{F}_q[\mathcal{I}^*]$ will be the new setting for primitive cyclic codes, and the algebra $\mathbb{F}_q[\mathcal{I}]$ will be the setting for the extended cyclic codes. So in fact both codes are contained in $\mathbb{F}_q[\mathcal{I}]$, which makes the discussion of affine-invariant codes more tractable.

Suppose that $\mathcal{C}$ is a cyclic code over $\mathbb{F}_q$ of length $n = q^l - 1$. The coordinates of $\mathcal{C}$ have been denoted $\{0, 1, \dots, n-1\}$. In $\mathcal{R}_n$, the $i$th component $c_i$ of a codeword $\mathbf{c} = c_0 c_1 \cdots c_{n-1}$, with associated polynomial $c(x)$, is the coefficient of the term $c_i x^i$ in $c(x)$; the component $c_i$ is kept in position $x^i$. Now we associate $\mathbf{c}$ with an element $C(X) \in \mathbb{F}_q[\mathcal{I}^*]$ as follows:

$\mathbf{c} \leftrightarrow C(X) = \sum_{i=0}^{n-1} C_{a^i} X^{a^i} = \sum_{g \in \mathcal{I}^*} C_g X^g, \quad (4.9)$

where $C_{a^i} = c_i$. Thus the $i$th component of $\mathbf{c}$ is the coefficient of the term $C_{a^i} X^{a^i}$ in $C(X)$; the component $c_i$ is kept in position $X^{a^i}$.

**Example 4.7.1** Consider the element $c(x) = 1 + x + x^3$ in $\mathcal{R}_7$ over $\mathbb{F}_2$. So $n = 7 = 2^3 - 1$. Let $\alpha$ be a primitive element of $\mathbb{F}_8$. Then $c_0 = C_{a^0} = 1, c_1 = C_{a^1} = 1$, and $c_3 = C_{a^3} = 1$, with the other $c_i = C_{a^i} = 0$. So

$c(x) = 1 + x + x^3 \leftrightarrow C(X) = X + X^a + X^{a^3}.$

We now need to examine the cyclic shift $xc(x)$ under the correspondence (4.9). We have

$xc(x) = c_{n-1} + \sum_{i=1}^{n-1} c_{i-1} x^i \leftrightarrow \sum_{i=0}^{n-1} C_{a^{i-1}} X^{a^i} = \sum_{i=0}^{n-1} C_{a^i} X^{a \cdot a^i}.$

**Example 4.7.2** We continue with Example 4.7.1. Namely,

$xc(x) = x + x^2 + x^4 \leftrightarrow X^a + X^{a^2} + X^{a^4}.$

In our new notation a primitive cyclic code over $\mathbb{F}_q$ of length $n = q^l - 1$ is any subset $\mathcal{C}$ of $\mathbb{F}_q[\mathcal{I}^*]$ such that

$\sum_{i=0}^{n-1} C_{a^i} X^{a \cdot a^i} = \sum_{g \in \mathcal{I}^*} C_g X^{ag} \in \mathcal{C} \quad \text{if and only if}$

$\sum_{i=0}^{n-1} C_{a^i} X^{a \cdot a^i} = \sum_{g \in \mathcal{I}^*} C_g X^{ag} \in \mathcal{C}. \quad (4.10)$

The coordinates of our cyclic codes are indexed by $\mathcal{I}^*$. We are now ready to extend our cyclic codes. We use the element $0 \in \mathcal{I}$ to index the extended coordinate. The extended codeword of $C(X) = \sum_{g \in \mathcal{I}} C_g X^g$ is $\bar{C}(X) = \sum_{g \in \mathcal{I}} C_g X^g$ such that $\sum_{g \in \mathcal{I}} C_g = 0$.

**Example 4.7.3** We continue with Examples 4.7.1 and 4.7.2. If $C(X) = X + X^a + X^b$ then $\bar{C}(X) = X^0 + X + X^a + X^b = 1 + X + X^a + X^b$.

From (4.10), together with the observation that $X^{a \cdot 0} = X^0 = 1$, in this terminology an extended cyclic code is a subspace $\bar{C}$ of $\mathbb{F}_q[\mathcal{I}]$ such that

$$
\sum_{g \in \mathcal{I}} C_g X^g \in \bar{C} \quad \text{if and only if} \quad \sum_{g \in \mathcal{I}} C_g X^{ag} \in \bar{C} \quad \text{and} \quad \sum_{g \in \mathcal{I}} C_g = 0.
$$

With this new notation we want to see where the concepts of zeros and defining sets come in. This can be done with the assistance of a function $\phi_t$. Let $\bar{\mathcal{N}} = \{s \mid 0 \le s \le n\}$. For $s \in \bar{\mathcal{N}}$ define $\phi_s : \mathbb{F}_q[\mathcal{I}] \to \mathcal{I}$ by

$$
\phi_s \left( \sum_{g \in \mathcal{I}} C_g X^g \right) = \sum_{g \in \mathcal{I}} C_g g^s.
$$

where by convention $0^0 = 1$ in $\mathcal{I}$. Thus $\phi_0(\bar{C}(X)) = \sum_{g \in \mathcal{I}} C_g$ implying that $\bar{C}(X)$ is the extended codeword of $C(X)$ if and only if $\phi_0(\bar{C}(X)) = 0$. In particular, if $\bar{C}$ is extended cyclic, then $\phi_0(\bar{C}(X)) = 0$ for all $\bar{C}(X) \in \bar{C}$. What is $\phi_s(\bar{C}(X))$ when $1 \le s \le n - 1$? As $0^s = 0$ in $\mathcal{I}$,

$$
\phi_s(\bar{C}(X)) = \sum_{i=0}^{n-1} C_{a^i}(a^i)^s = \sum_{i=0}^{n-1} C_{a^i}(a^s)^i = c(a^s), \quad (4.11)
$$

where $c(x)$ is the polynomial in $\mathcal{R}_n$ associated to $C(X)$ in $\mathbb{F}_q[\mathcal{I}^*]$. Suppose our original code $\mathcal{C}$ defined in $\mathcal{R}_n$ had defining set $T$ relative to the $n$th root of unity $\alpha$. Then (4.11) shows that if $1 \le s \le n - 1$, $s \in \bar{T}$ if and only if $\phi_s(\bar{C}(X)) = 0$ for all $\bar{C}(X) \in \bar{C}$. Finally, what is $\phi_0(\bar{C}(X))$? Example (4.11) works in this case as well, implying that $a^0 = 1$ is a zero of $\mathcal{C}$ if and only if $\phi_0(\bar{C}(X)) = 0$ for all $\bar{C}(X) \in \bar{C}$. But $a^0 = a^n = 1$. Hence we have, by Exercise 238, that $0 \in \bar{T}$ if and only if $\phi_0(\bar{C}(X)) = 0$ for all $\bar{C}(X) \in \bar{C}$. We can now describe an extended cyclic code in terms of a defining set as follows: a code $\bar{C}$ of length $q^l$ is an extended cyclic code with defining set $\bar{T}$ provided $\bar{T} \subseteq \bar{\mathcal{N}}$ is a union of $q$-cyclotomic cosets modulo $n = q^l - 1$ with $0 \in \bar{T}$ and

$$
\bar{C} = \{ \bar{C}(X) \in \mathbb{F}_q[\mathcal{I}] \mid \phi_s(\bar{C}(X)) = 0 \text{ for all } s \in \bar{T} \}. \quad (4.12)
$$

We make several remarks.

- 0 and $n$ are in $\bar{T}$ and each is its own $q$-cyclotomic coset.
- $0 \in \bar{T}$ because we need all codewords in $\bar{C}$ to be even-like.
- If $n \in \bar{T}$, then $\phi_n(\bar{C}(X)) = \sum_{g \in \mathcal{I}} C_g = 0$. As the extended codeword is even-like, since $0 \in \bar{T}$, $\sum_{g \in \mathcal{I}} C_g = 0$. Thus the extended coordinate is always 0, a condition that makes the extension trivial.
- The defining set $\bar{T}$ of $\bar{C}$ and the defining set $T$ are closely related: $\bar{T}$ is obtained by taking $T$, changing 0 to $n$ if $0 \in T$, and adding 0.
