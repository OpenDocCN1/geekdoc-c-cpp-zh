# ## 2.3.4 The Nordström-Robinson code

The existence of the Nordström-Robinson code shows that the upper bound on \( A_2(16, 6) \) discovered in Example 2.3.9 is met, and hence that \( A_2(16, 6) = 256 \).

The Nordström-Robinson code was discovered by Nordstrom and Robinson [247] and later independently by Semakov and Zin'cev [303]. This code can be defined in several ways; one of the easiest is the following and is due to Goethals [100] and Semakov and Zin'cev [304].

Let \(\mathcal{C}\) be the \((24, 12, 8)\) extended binary Golay code chosen to contain the weight 8 codeword \(\mathbf{c} = 11\cdots 100\cdots 0\). Let \(T\) be the set consisting of the first eight coordinates. Let \(\mathcal{C}(T)\) be the subcode of \(\mathcal{C}\) which is zero on \(T\), and let \(\mathcal{C}_T\) be \(\mathcal{C}\) shortened on \(T\). Let \(\mathcal{C}^T\) be \(\mathcal{C}\) punctured on the positions of \(T = \{9, 10, \dots, 24\}\). By Corollary 1.4.14, as \(\mathcal{C}\) is self-dual, the first seven coordinate positions of \(\mathcal{C}\) are linearly independent. Thus as \(\mathbf{c} \in \mathcal{C}\) and \(\mathcal{C}\) is self-dual, \(\mathcal{C}^T\) is the \([8, 7, 2]\) binary code consisting of all even weight vectors of length 8. Exercise 104 shows that the dimension of \(\mathcal{C}_T\) is 5. Hence \(\mathcal{C}_T\) is a \([16, 5, 8]\) code. (In fact \(\mathcal{C}_T\) is equivalent to \(\mathcal{R}(1, 4)\) as Exercise 121 shows). For \(1 \le i \le 7\), let \(\mathbf{c}_i \in \mathcal{C}\) be a codeword of \(\mathcal{C}\) with zeros in the first eight coordinates except coordinate \(i\) and coordinate 8; such codewords are present in \(\mathcal{C}\) because \(\mathcal{C}^T\) is all length 8 even weight vectors. Let \(\mathbf{c}_0 = \mathbf{0}\). For \(0 \le i \le 7\), let \(C_i\) be the coset \(\mathbf{c}_i + \mathcal{C}(T)\) of \(\mathcal{C}(T)\) in the extended Golay code \(\mathcal{C}\). These cosets are distinct, as you can verify in Exercise 105. Let \(\mathcal{N}\) be the union of the eight cosets \(C_0, \dots, C_7\). The *Nordstrom-Robinson code* \(\mathcal{N}_{16}\) is the code obtained by puncturing \(\mathcal{N}\) on \(T\). Thus \(\mathcal{N}_{16}\) is the union of \(C_0, \dots, C_7\), where \(C_i^*\) is \(\mathcal{C}_i\) punctured on \(T\). Figure 2.1 gives a picture of the construction. Clearly, \(\mathcal{N}_{16}\) is a \((16, 256)\) code, as Exercise 106 shows. Let \(\mathbf{a}, \mathbf{b} \in \mathcal{N}\) be distinct.
