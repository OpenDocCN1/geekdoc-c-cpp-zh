Table 6.1 gives information about the odd-like binary duadic codes $\mathcal{D}$ of length $n \le 119$. The splittings given in this table are obtained in a manner similar to that of Example 6.4.8. The idempotent of $\mathcal{D}$ is of the form $\sum_{i \in \mathcal{I}} \sum_{c \in C} x^c$. The column "Idempotent" gives the index set $\mathcal{I}$ for each equivalence class of odd-like duadic codes; a * in this column means that the code is a quadratic residue code. The columns "d" and "d_b" are the minimum weight and minimum odd weight, respectively. The column "a" indicates the multiplier $\mu_a$ giving the splitting. An $\propto$ in column "a" indicates that the two extended odd-like duadic codes are duals of each other (i.e., $\mu_{-1}$ fixes each code by Theorem 6.4.12). If the splitting is given by $\mu_{-1}$, then by Theorem 6.5.1 the extended code is self-dual doubly-even if $n \equiv -1 \pmod 8$ and self-dual singly-even if $n \equiv 1 \pmod 8$.
