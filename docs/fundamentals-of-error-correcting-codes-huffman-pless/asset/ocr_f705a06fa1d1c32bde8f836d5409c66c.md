Hartmann and Tzeng [117] showed that if there are several consecutive sets of $\delta - 1$ elements in the defining set that are spaced properly, then the BCH Bound can be improved. To state the Hartmann–Tzeng Bound, which we do not prove, we develop the following notation. If $A$ and $B$ are subsets of the integers modulo $n$, then $A + B = \{a + b \mod n \mid a \in A, b \in B\}$.

# **Theorem 4.5.6 (Hartmann–Tzeng Bound)** Let $\mathcal{C}$ be a cyclic code of length $n$ over $\mathbb{F}_q$ with defining set $T$. Let $B$ be a set of $\delta - 1$ consecutive elements of $T$ and $B = \{jb \mod n \mid 0 \le j \le s\}$, where $\gcd(b, n) < \delta$. If $A + B \subseteq T$, then the minimum weight $d$ of $\mathcal{C}$ satisfies $d \ge \delta + s$.

Clearly the BCH Bound is the Hartmann–Tzeng Bound with $s = 0$.

# **Example 4.5.7** Let $\mathcal{C}$ be the binary cyclic code of length 17 with defining set $T = \{1, 2, 4, 8, 9, 13, 15, 16\}$. There are two consecutive elements in $T$ and so the BCH Bound gives $d \ge 3$. The Hartmann–Tzeng Bound improves this. Let $A = \{1, 2\}$ and $B = \{0, 7, 14\}$. So $\delta = 3, b = 7$, and $s = 2$; also $\gcd(7, 17) = 1 < \delta$. So $\mathcal{C}$ has minimum weight $d \ge 5$. Note that $\mathcal{C}$ is a [17, 9] code. By the Griesmer Bound, there is no [17, 9, 7] code. Hence $d = 5$ or 6. In fact, $d = 5$; see [203].

# **Example 4.5.8** Let $\mathcal{C}$ be the binary cyclic code of length 31 with defining set $T = \{1, 2, 4, 5, 8, 9, 10, 16, 18, 20\}$ and minimum weight $d$. The BCH Bound shows that $d \ge 4$ as the consecutive elements $\{8, 9, 10\}$ are in $T$. If $d = 4$, then the minimum weight vectors are in the subcode $\mathcal{C}_s$ of all even-like vectors in $\mathcal{C}$. By Exercise 238, $\mathcal{C}_s$ is cyclic with defining set $T_s = \{0, 1, 2, 4, 5, 8, 9, 10, 16, 18, 20\}$. Applying the Hartmann–Tzeng Bound with $A = \{0, 1, 2\}$ and $B = \{0, 8\}$ (since $\gcd(8, 31) = 1 < \delta = 4$), the minimum weight of $\mathcal{C}_s$ is at least 5. Hence the minimum weight of $\mathcal{C}$ is at least 5, which is in fact the true minimum weight by [203].

# **Example 4.5.9** Let $\mathcal{C}$ be the binary cyclic code of length 31 with defining set $T = \{1, 2, 3, 4, 5, 6, 8, 9, 10, 11, 12, 13, 16, 17, 18, 20, 21, 22, 24, 26\}$ and minimum weight $d$. Applying the Hartmann–Tzeng Bound with $A = \{1, 2, 3, 4, 5, 6\}$ and $B = \{0, 7\}$ (since $\gcd(7, 31) = 1 < \delta = 7$), we obtain $d \ge 8$. Suppose that $d = 8$. Then the cyclic subcode $\mathcal{C}_s$ of even-like codewords has defining set $T_s = T \cup \{0\}$ by Exercise 238. But $17T_s$ contains the nine consecutive elements $\{29, 30, 0, 1, 2, 3, 4, 5, 6\}$. Hence, the code with defining set $17T_s$ has minimum weight at least 10 by the BCH Bound, implying that $d = 8$ is impossible.
