In general, an [n, k, d] code may not have a basis of minimum weight vectors. However, in the binary case, if the code meets the Griesmer Bound, it has such a generator matrix, as the following result of van Tilborg [328] shows.

# **Theorem 2.7.6** Let C be an [n, k, d] binary code that meets the Griesmer Bound. Then C has a basis of minimum weight codewords.

**Proof:** We proceed by induction on k. The result is clearly true if k = 1. Assume that c is a codeword of weight d. By permuting coordinates, we may assume that C has a generator matrix

\( G = \begin{bmatrix} 1 \cdots 1 & 0 \cdots 0 \\ G_0 & G_1 \end{bmatrix} \).

where the first row is c and G<sub>1</sub> is a generator matrix of the [n - d, k - 1, d'] residual code C<sub>1</sub> = Res(C, d'). d' \(\ge\) d<sub>1</sub> = \(\lceil d/2 \rceil\) by Corollary 2.7.2. As C meets the Griesmer Bound,

\( n - d = \sum_{i=1}^{k-1} \lceil \frac{d'}{2^i} \rceil = \sum_{i=0}^{k-2} \lceil \frac{d_1}{2^i} \rceil. \quad (2.39) \)

by Exercise 123. Suppose that d' > d<sub>1</sub>. Then n - d < \(\sum_{i=0}^{k-2} \lceil d'/2^i \rceil\) by (2.39) and C<sub>1</sub> violates the Griesmer Bound. Therefore d' = d<sub>1</sub> and C<sub>1</sub> is an [n - d, k - 1, d<sub>1</sub>] code meeting the Griesmer Bound. By induction, we may assume the rows of G<sub>1</sub> have weight d<sub>1</sub>. For i \(\ge\) 2, let r<sub>i</sub> = (s<sub>i-1</sub>, t<sub>i-1</sub>) be row i of G, where s<sub>-1</sub> is row i - 1 of G<sub>0</sub> and t<sub>-1</sub> is row i - 1 of G<sub>1</sub>. By Exercise 124, one of r<sub>i</sub> or c + r<sub>i</sub> has weight d. Hence C has a basis of weight d codewords.
