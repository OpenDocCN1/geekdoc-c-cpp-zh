Another formulation for Goppa codes can be given as follows. Let \(\mathcal{R}\) be the vector space of all rational functions \(f(x) = a(x)/b(x)\) with coefficients in \(\mathbb{F}_{q^r}\), where \(a(x)\) and \(b(x)\) are relatively prime and satisfy two requirements. First, the zeros of \(a(x)\) include the zeros of \(G(x)\) with at least the same multiplicity as in \(G(x)\); second, the only possible zeros of \(b(x)\), that is the poles of \(f(x)\), are from \(\gamma_0, \dots, \gamma_{n-1}\) each with at most multiplicity one. Any rational function \(f(x)\) has a Laurent series expansion about \(\gamma_i\). The rational functions \(f(x)\) in \(\mathcal{R}\) have Laurent series expansion

```
\(\sum_{j=-1}^{\infty} f(x - \gamma_1)^j\)
```

about \(\gamma_1\) where \(f_{-1} \neq 0\) if \(f(x)\) has a pole at \(\gamma_1\) and \(f_{-1} = 0\) otherwise. The *residue* of \(f(x)\) at \(\gamma_i\), denoted \(\text{Res}_{\gamma_i} f\), is the coefficient \(f_{-1}\). Let

```
\(\mathcal{C} = \{ (\text{Res}_{\gamma_1} f, \text{Res}_{\gamma_2} f, \dots, \text{Res}_{\gamma_{n-1}} f) \mid f(x) \in \mathcal{R} \}.\) (13.8)
```

Exercise 771 shows that \(\Gamma(L, G)\) is the subfield subcode \(\mathcal{C}|_{\mathbb{F}_q}\).

# ## 13.2.3 Generalized Reed-Muller codes

In Section 1.10 we introduced the binary Reed-Muller codes. We can construct similar codes, called generalized Reed-Muller codes, over other fields using a construction parallel to that of the GRS codes. Kasami, Lin, and Peterson [163] first introduced the primitive generalized Reed-Muller codes which we study here; the nonprimitive codes, which we do not investigate, were presented in [349]. Primitive and nonprimitive codes are also examined extensively in [4, 5].

Let \(m\) be a positive integer and let \(P_1, P_2, \dots, P_n\) be the \(n = q^m\) points in the affine space \(\mathbb{A}^m(\mathbb{F}_q)\). For any integer \(r\) with \(0 \le r \le m(q-1)\), let \(\mathbb{F}_q[x_1, x_2, \dots, x_m]_r\) be the polynomials in \(\mathbb{F}_q[x_1, x_2, \dots, x_m]\) of degree \(r\) or less together with the zero polynomial. Define the *rth order generalized Reed-Muller*, or GRM, *code* with length \(n = q^m\) to be

```
\(\mathcal{R}_q(r, m) = \{ (f(P_1), f(P_2), \dots, f(P_n)) \mid f \in \mathbb{F}_q[x_1, x_2, \dots, x_m] \}.\)
```

If a term in \(f\) has a factor \(x_i^e\) where \(e = q + d \ge q\), then the factor can be replaced by \(x_i^{1+d}\) without changing the value of \(f\) at any point \(P_j\) because \(\beta^{q+d} = \beta^q \beta^d = \beta \beta^d\) as \(\beta^q = \beta\) for all \(\beta \in \mathbb{F}_q\). Thus we see that

```
\(\mathcal{R}_q(r, m) = \{ (f(P_1), f(P_2), \dots, f(P_n)) \mid f \in \mathbb{F}_q[x_1, x_2, \dots, x_m]^* \},\)
```

where \(\mathbb{F}_q[x_1, x_2, \dots, x_m]^*\) is all polynomials in \(\mathbb{F}_q[x_1, x_2, \dots, x_m]_r\) with no term having an exponent \(q\) or higher on any variable. Clearly, this is a vector space over \(\mathbb{F}_q\) with a basis

```
\(\mathcal{B}_q(r, m) = \{ x_1^{e_1} \cdots x_m^{e_m} \mid 0 \le e_i < q, e_1 + e_2 + \cdots + e_m \le r \}.\)
```

Obviously, \(\{(f(P_1), f(P_2), \dots, f(P_n)) \mid f \in \mathcal{B}_q(r, m)\}\) spans \(\mathcal{R}_q(r, m)\). These codewords are in fact independent; this fact is shown in the binary case in Exercise 772.
