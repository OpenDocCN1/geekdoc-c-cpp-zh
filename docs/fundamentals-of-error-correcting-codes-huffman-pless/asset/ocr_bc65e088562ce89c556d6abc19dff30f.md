# **Theorem 4.7.5 (Lucas)** Let $r = \sum_{i=0}^{mt-1} r_i p^i$ and $s = \sum_{i=0}^{mt-1} s_i p^i$ be the $p$-adic expansions of $r$ and $s$. Then

```
$$\binom{s}{r} \equiv \prod_{i=0}^{mt-1} \binom{s_i}{r_i} \pmod p.$$
```

We are now ready to determine the affine-invariant codes from their defining sets, a result due to Kasami, Lin, and Peterson [162].

# **Theorem 4.7.6** Let $\widehat{C}$ be an extended cyclic code of length $q^t$ with defining set $\widehat{T}$. The code $\widehat{C}$ is affine-invariant if and only if whenever $s \in \widehat{T}$ then $r \in \widehat{T}$ for all $r \in \widehat{\mathcal{N}}$ with $r \preceq s$.

**Proof:** Suppose that $\widehat{C}(X) = \sum_{k \in \widehat{T}} C_k X^k \in \widehat{C}$. Let $s \in \widehat{N}$ and $a, b \in \mathcal{I}$ with $a \neq 0$. So $(\widehat{C}(X))\sigma_{a,b} = \sum_{k \in \widehat{T}} C_k X^{ak+b}$. Therefore,

```
$$\phi_t((\widehat{C}(X))\sigma_{a,b}) = \sum_{k \in \widehat{T}} C_k(ag + b)^t = \sum_{g \in \widehat{I}} C_g \sum_{r=0}^t \binom{t}{r} (ag)^r b^{t-r}.$$
```

By Lucas' Theorem, $\binom{t}{r}$ is nonzero modulo $p$ if and only if $r_i \le s_i$ for all $0 \le i < mt$ where $r = \sum_{i=0}^{mt-1} r_i p^i$ and $s = \sum_{i=0}^{mt-1} s_i p^i$ are the $p$-adic expansions of $r$ and $s$. Hence

```
$$\phi_t((\widehat{C}(X))\sigma_{a,b}) = \sum_{g \in \widehat{I}} C_g \sum_{r \preceq s} \binom{t}{r} (ag)^r b^{t-r} = \sum_{r \preceq s} \binom{t}{r} a^r b^{t-r} \sum_{g \in \widehat{I}} C_g g^r.$$
```

Therefore,

```
$$\phi_t((\widehat{C}(X))\sigma_{a,b}) = \sum_{r \preceq s} \binom{t}{r} a^r b^{t-r} \phi_r(\widehat{C}(X)). \quad (4.13)$$
```

Let $s$ be an arbitrary element of $\widehat{T}$ and assume that if $r \preceq s$, then $r \in \widehat{T}$. By (4.12), $\phi_t((\widehat{C}(X)) = 0$ for $r \in \widehat{T}$, and therefore by (4.13), $\phi_t((\widehat{C}(X))\sigma_{a,b}) = 0$. As $s$ was an arbitrary element of $\widehat{T}$, by (4.12), $\widehat{C}$ is affine-invariant.

Conversely, assume that $\widehat{C}$ is affine-invariant. Assume that $s \in \widehat{T}$ and that $r \preceq s$. We need to show that $r \in \widehat{T}$, that is $\phi_t((\widehat{C}(X)) = 0$ by (4.12). As $\widehat{C}$ is affine-invariant, $\phi_t((\widehat{C}(X))\sigma_{a,b}) = 0$ for all $a \in \mathcal{I}^*$ and $b \in \mathcal{I}$. In particular this holds for $a = 1$; letting $a = 1$ in (4.13) yields

```
$$0 = \sum_{r \preceq s} \binom{t}{r} \phi_r((\widehat{C}(X))b^{t-r}$$
```

for all $b \in \mathcal{I}$. But the right-hand side of this equation is a polynomial in $b$ of degree at most $s < q^t$ with all $q^t$ possible $b \in \mathcal{T}$ as roots. Hence this must be the zero polynomial. So $\binom{t}{r} \phi_r((\widehat{C}(X)) = 0$ in $\mathcal{I}$ for all $r \preceq s$. However, by Lucas' Theorem again, $\binom{t}{r} \not\equiv 0 \pmod p$ and thus these binomial coefficients are nonzero in $\mathcal{I}$. Hence $\phi_r((\widehat{C}(X)) = 0$ implying that $r \in \widehat{T}$.
