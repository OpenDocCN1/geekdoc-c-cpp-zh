# 9.11 Proof of the Gleason-Pierce-Ward Theorem

In this section we prove the Gleason-Pierce-Ward Theorem stated at the beginning of the chapter. Our proof comes from [347].

We begin with some notation. Let C be a linear code of length n over F_q, where q = p^m with p a prime. As usual F_q^* denotes the nonzero elements of F_q. Define the map \tau : F_q -> F_q by \tau(0) = 0 and \tau(\alpha) = \alpha^r for all \alpha \in F_q^*. This map will be crucial to the proof of the Gleason-Pierce-Ward Theorem; its connection with the theorem is hinted at in the following lemma.

+   Lemma 9.11.11 We have the following:
+   (i) \tau(\alpha\beta) = \tau(\alpha)\tau(\beta) for all q and all \alpha, \beta \in F_q.
+   (ii) When q = 2 or 3, \tau is the identity map, and when q = 4, \tau is the map \tau(\alpha) = \alpha^2.
+   (iii) \tau is also additive (that is, \tau is a field automorphism) if and only if q = 2, 3, or 4.

Proof: Part (i) was proved in Exercise 176(a), while part (ii) is a straightforward exercise. One direction of part (iii) is proved in Exercise 176(c). We give another proof different from the one suggested in the hint in that exercise. Assume that \tau is a field automorphism of F_q. Then \tau(\alpha) = \alpha^r for some r with 0 <= r < m and all \alpha \in F_q by Theorem 3.6.1. So if a \in F_q^*, then \alpha^r = \alpha^{r-1} and hence \alpha^{r+1} = 1. This holds when \alpha is primitive, yielding (q - 1) | (p^r + 1) implying p^m - 1 = p^r + 1 if q > 2 by the restriction 0 <= r < m. The only solutions of p^m - 1 = p^r + 1 with q > 2 are p = 3 with m = 1 and r = 0 and p = 2 with m = 2 and r = 1. So q = 2, 3, or 4. For the converse we assume q = 2, 3, or 4, in which case \tau is given in (ii). The identity map is always an automorphism and the map \tau(\alpha) = \alpha^2 is the case q = 4 is the Frobenius automorphism.

We now introduce notation that allows us to compare components of two different vectors. Let u = u_1 ... u_n and v = v_1 ... v_n be vectors in F_q^n. For \alpha \in F_q define

```
\alpha_{u,v} = |\{i | u_i \neq 0 \text{ and } v_i = \alpha u_i\}|, \text{ and }
\infty_{u,v} = |\{i | u_i \neq 0 \text{ and } v_i \neq 0\}|.
```

We have the following elementary properties of \alpha_{u,v} and \infty_{u,v}.

+   Lemma 9.11.2 Let C be a divisible linear code over F_q with divisor \Delta. Let u and v be vectors in F_q^n and \alpha an element of F_q. Then:
+   (i) w(u) = \sum_{\alpha \in F_q} \alpha_{u,v},
+   (ii) w(v - \alpha u) = \infty_{u,v} + w(u) - \alpha_{u,v},
+   (iii) \alpha_{u,v} = \infty_{u,v} (mod \Delta) if u and v are in C, and
+   (iv) q \infty_{u,v} \equiv 0 (mod \Delta) if u and v are in C.
