We now give one construction, called the ADS construction, of binary codes that assists in giving many of the upper bounds in Table 11.6; for other constructions, see [34].

Before we give the construction, we must discuss the concept of normal codes and acceptable coordinates. Recall that if $S \subseteq \mathbb{F}_q^n$ and $\mathbf{x} \in \mathbb{F}_q^n$, then d(x, S) is the minimum distance from x to any vector in S; in the case that S is empty, set d(x, $\emptyset$) = n. Let C be a binary linear code of length N. For $a \in \mathbb{F}_2^N$ and $1 \le i \le n$, let $C^{(i,a)}$ denote the subset of C consisting of the codewords in C whose ith coordinate equals a. Note that $C^{(i,0)}$ either equals C, in which case $C^{(i,1)} = \emptyset$, or $C^{(i,a)}$ has codimension 1 in C, in which case $C^{(1,0)}$ is the coset $C \setminus C^{(i,0)}$. For $1 \le i \le n$, the norm of C with respect to coordinate i is defined by $N^{(i)}(C) = \max_{\mathbf{x} \in \mathbb{F}_2^N} \{ d(\mathbf{x}, C^{(i,0)}) + d(\mathbf{x}, C^{(i,1)}) \}$. 

The norm on C is defined to be $N(C) = \min_{1 \le i \le n} \{ N^{(i)}(C) \}$. 

Coordinate i is called acceptable if $N^{(i)}(C) = N(C)$. One relationship between the norm and covering radius of a code is given by the following lemma.

# **Lemma 11.5.4** Let C be a binary linear code. Then $\rho(C) \le \lfloor \frac{N(C)}{2} \rfloor$.

# **Proof:** Suppose that C has length N. For $\mathbf{x} \in \mathbb{F}_q^n$ and $1 \le i \le n$, $d(\mathbf{x}, C) = \min \{ d(\mathbf{x}, C^{(i,0)}), d(\mathbf{x}, C^{(i,1)}) \} \le \frac{1}{2} [ d(\mathbf{x}, C^{(i,0)}) + d(\mathbf{x}, C^{(i,1)}) ]$. Therefore $\rho(C) = \max_{\mathbf{x} \in \mathbb{F}_2^n} d(\mathbf{x}, C) \le \max_{\mathbf{x} \in \mathbb{F}_2^n} \{ \frac{1}{2} [ d(\mathbf{x}, C^{(i,0)}) + d(\mathbf{x}, C^{(i,1)}) ] \} = \frac{N^{(i)}(C)}{2}$. For some i, the latter equals $(N(C))/2$. The result follows.
