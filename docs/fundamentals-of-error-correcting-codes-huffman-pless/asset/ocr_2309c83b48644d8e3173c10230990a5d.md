Theorem 1.7.11 Let $C_1$ and $C_2$ be codes over $\mathbb{F}_q$. Let $P$ be a permutation matrix, $M$ a monomial matrix, and $\gamma$ an automorphism of $\mathbb{F}_q$. (i) If $C_1 = C_2$, then $P^{-1}\text{PAut}(C_1)P = \text{PAut}(C_2)$. (ii) If $C_1 M = C_2$, then $M^{-1}\text{MAut}(C_1)M = \text{MAut}(C_2)$. (iii) If $C_1 M \gamma = C_2$, then $(M\gamma)^{-1}\Gamma\text{Aut}(C_1)M\gamma = \Gamma\text{Aut}(C_2)$.

As with PAut(C), we can speak of transitivity of the automorphism groups MAut(C) or $\Gamma$Aut(C). To do this we consider only the permutation parts of the maps in these groups. Specifically, define MAut$_P$(C) to be the set {P | DP in MAut(C)} and $\Gamma$Aut$_P$(C) to be {P | DP $\gamma$ in $\Gamma$Aut(C)}. (The subscript P stands for projection. The groups MAut(C) and $\Gamma$Aut(C) are semi-direct products; the groups MAut$_P$(C) and $\Gamma$Aut$_P$(C) are obtained from MAut(C) and $\Gamma$Aut(C) by projecting onto the permutation part of the semi-direct product.) For instance, in Example 1.7.7, MAut$_P$(C) = $\Gamma$Aut$_P$(C) = Sym$_4$; in Example 1.7.8, MAut$_P$(C) is the alternating group on six points and $\Gamma$Aut$_P$(C) = Sym$_6$. We leave the proof of the following theorem as an exercise.

Theorem 1.7.12 Let C be a linear code over $\mathbb{F}_q$. Then: (i) MAut$_P$(C) and $\Gamma$Aut$_P$(C) are subgroups of the symmetric group Sym$_n$, and (ii) PAut(C) $\subseteq$ MAut$_P$(C) $\subseteq$ $\Gamma$Aut$_P$(C).

We now say that MAut(C) ($\Gamma$Aut(C), respectively) is transitive as a permutation group if MAut$_P$(C) ($\Gamma$Aut$_P$(C), respectively) is transitive. The following is a generalization of Theorem 1.6.6.

Theorem 1.7.13 Let C be an [n, k, d] code. (i) Suppose that MAut(C) is transitive. Then the n codes obtained from C by puncturing C on a coordinate are monomially equivalent. (ii) Suppose that $\Gamma$Aut(C) is transitive. Then the n codes obtained from C by puncturing C on a coordinate are equivalent. (iii) Suppose that either MAut(C) or $\Gamma$Aut(C) is transitive. Then the minimum weight d of C is its minimum odd-like weight d$_o$. Furthermore, every minimum weight codeword of C is odd-like.
