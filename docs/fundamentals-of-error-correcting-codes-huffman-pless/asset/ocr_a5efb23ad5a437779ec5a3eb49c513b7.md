# **Theorem 9.12.2** ([270]) The following hold:

+   (i) If n ≡ 0 (mod 8), then E_n has form H.
+   (ii) If n ≡ 4 (mod 8), then E_n has form A.
+   (iii) If n ≡ 2 (mod 4), then E_n has form O.

**Proof:** By Theorem 7.8.5, decompose E_n as an orthogonal sum of its hull and either m H-planes or m - 1 H-planes and one A-plane. The hull of E_n is H = E_n ∩ E_n^⊥ = <0, 1>. Therefore the dimension of E_n is n - 1 = 2m + 1 as r = 1 is the dimension of H_t; in particular m = (n - 2)/2. The hull of E_n is singly-even if n ≡ 2 (mod 4), implying by Theorem 7.8.5 that E_n has form O giving (iii).

Suppose that n ≡ 4 (mod 8). As H_t is doubly-even, E_n has either form H or A. If it has form H, then E_n = span{1} ⊥ H_1 ⊥ ... ⊥ H_m. Letting x_1 be a doubly-even vector in H_t, we have the set {1, x_1, ..., x_m} generating a doubly-even self-dual code of dimension m + 1 = n/2; such a subcode is Type II, contradicting Corollary 9.7.2.2, proving (ii).

Finally, suppose that n ≡ 0 (mod 8). Then E_n contains the Type II subcode equal to the direct sum of n/8 copies of the (8, 4, 4) extended Hamming code H̃_8. Thus E_n contains a doubly-even subcode C' of dimension n/2. Let C be any [n, n/2 - 1] vector space complement of 1 in C'. By Lemma 9.12.1, C is contained in the orthogonal sum H_{t1} ⊥ ... ⊥ H_{t(n/2 - 1)} of n/2 - 1 H-planes. This orthogonal sum is orthogonal to, and disjoint from, the hull H = span{1} of E_n. Thus span{1} ⊥ H_{t1} ⊥ ... ⊥ H_{t(n/2 - 1)} ⊆ E_n, as both codes have dimension n - 1, they are equal proving (i).

Once we know the form of E_n, we can count the number of singly- and doubly-even vectors in F_2^n.

# **Corollary 9.12.3** Let n be even. Let a be the number of doubly-even vectors in F_2^n and let b be the number of singly-even vectors in F_2^n. The values of a and b are as follows:

+   (i) If n ≡ 0 (mod 8), then a = 2^(n-2) + 2^(n/2 - 1) and b = 2^(n-2) - 2^(n/2 - 1).
+   (ii) If n ≡ 4 (mod 8), then a = 2^(n-2) - 2^(n/2 - 1) and b = 2^(n-2) + 2^(n/2 - 1).
+   (iii) If n ≡ 2 (mod 4), then a = b = 2^(n-2).

**Proof:** This follows directly from Theorems 7.8.6 and 9.12.2.
