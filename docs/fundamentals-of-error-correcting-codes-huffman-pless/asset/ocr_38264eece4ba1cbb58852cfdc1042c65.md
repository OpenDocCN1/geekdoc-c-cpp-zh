# **Corollary 8.7.3** An automorphism of a symmetric 2-design has the same cycle structure on blocks as it does on points.

**Proof:** If $\alpha$ and $\tau$ represent the same automorphism acting on blocks and points, respectively, then so do $\alpha^t$ and $\tau^t$. Let $n_i$, respectively $n'_i$, be the number of $i$-cycles of $\sigma$, respectively $\tau$. If $i$ is a prime $p$, the number of fixed points of $\sigma^t$, respectively $\tau^t$, is $p \cdot n_p + n_1$, respectively $p \cdot n'_p + n'_1$. As $n_1 = n'_1$ by Theorem 8.7.2 applied to $\sigma$ and $\tau$, and since $p \cdot n_p + n_1 = p \cdot n'_p + n'_1$ by the same theorem applied to $\sigma^t$ and $\tau^t$, $n_p = n'_p$. We can continue inductively according to the number of prime factors of $i$.

We are now ready to introduce the concept of a difference set; this will be intimately related to cyclic designs. Let $\mathcal{G}$ be an abelian group of order $v$. A $(v, k, \lambda)$ *difference set* in $\mathcal{G}$ is a set $D$ of $k$ distinct elements of $\mathcal{G}$ such that the multiset $\{x - y \mid x \in D, y \in D, x \neq y\}$ contains every nonzero element of $\mathcal{G}$ exactly $\lambda$ times. There are $k(k-1)$ differences between distinct elements of $D$, and these differences make up all nonzero elements of $\mathcal{G}$ exactly $\lambda$ times. Thus

$k(k-1) = (v-1)\lambda$. (8.12)

We will be most interested in the case where $\mathcal{G}$ is the cyclic group $\mathbb{Z}_v$, in which case the difference set is a *cyclic difference set*. In Theorem 8.7.5 we will see the connection between difference sets and symmetric designs.

# **Example 8.7.4** In $\mathbb{Z}_7$, the set $D = \{1, 2, 4\}$ is a $(7, 3, 1)$ cyclic difference set as one can see by direct computation (Exercise 464). By adding each element of $i \in \mathbb{Z}_7$ to the set $D$ we obtain the sets $D_i = \{i+1, i+2, i+4\}$. These form the blocks of a projective plane $\mathcal{D}$ of order 2. The map $i \mapsto i+1 \pmod 7$ is a 7-cycle in Aut($\mathcal{D}$).
