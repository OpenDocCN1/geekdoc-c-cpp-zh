
Proof: Part (i) is clear because wt(u) is the count of the number of nonzero coordinates of u, and for all such coordinates i, v_i = \alpha u_i for \alpha = v_i u_i^{-1} \in F_q. To prove (ii) we note that the coordinates are divided into four disjoint sets for each \alpha:

- (a) the coordinates i where u_i = v_i = 0,
- (b) the coordinates i where u_i = 0 but v_i \neq 0,
- (c) the coordinates i where u_i \neq 0 and v_i = \alpha u_i, and
- (d) the coordinates i where u_i \neq 0 and v_i \neq \alpha u_i.

Clearly, wt(v - u) is the sum of the number of coordinates in (b) and (d). By definition, there are n_{\alpha, u} coordinates in (b). As there are wt(u) total coordinates in (c) and (d), and (c) has \alpha u coordinates, then (d) has wt(u) - \alpha u coordinates, proving (ii).

Part (iii) follows from part (ii) as wt(v - u) \equiv wt(u) \equiv 0 (mod \Delta) because C is linear and divisible by \Delta. Finally, combining (i) and (iii) gives

0 \equiv wt(u) \equiv \sum_{\alpha \in F_q} \alpha u_\alpha \equiv \sum_{\alpha \in F_q} n_{\alpha, u} \equiv q n_{0, u} (\text{mod } \Delta).

verifying (iv).

We next examine the situation that will lead to part (v) of the Gleason-Pierce-Ward Theorem. To state this result, we need the concept of a coordinate functional of a code C over F_q of length n. For 1 \le i \le n, define the coordinate functional f_i : C \to F_q by f(c) = c_i where c = c_1 \cdots c_n. Let N be the set of nonzero coordinate functionals of C. We define the binary relation \sim on N by f_i \sim f_j provided there exists an element \alpha \in F_q^* such that f_i(c) = \alpha f_j(c) for all c \in C. We make two simple observations, which you are asked to prove in Exercise 564. First, f_i is a linear function and hence its values are completely determined by its values on the codewords in a generator matrix. Second, \sim is an equivalence relation on N. In the next lecture, we will see that C is equivalent to a replicated code whenever C has a divisor relatively prime to the order of the field. We say that a code C is a \Delta-fold replicated code provided the set of coordinates of C is the disjoint union of subsets of coordinates of sizes \Delta such that if \{j_i | 1 \le j \le \Delta\} is any of these subsets and c = c_1 \cdots c_n \in C, then c_{j_i} = c_{j_1} for 1 \le j \le \Delta. In terms of coordinate functionals, these functionals are equal on the subsets of coordinates. The code with generator matrix [I_{n/2} | I_{n/2}] in (v) of the Gleason-Pierce-Ward Theorem is a two-fold replicated code.

### Exercise 564 Show the following:

- (a) The coordinate functional f_i is a linear function from C to F_q, and its values are completely determined by its values on the codewords in a generator matrix of C.
- (b) The relation \sim on the set N of nonzero coordinate functionals is an equivalence relation on N.

### Lemma 9.11.13 Let C be an [n, k] code over F_q with divisor \Delta relatively prime to p. Then the following hold:

- (i) Each equivalence class of nonzero functionals has size a multiple of \Delta.
- (ii) C is monomially equivalent to a \Delta-fold replicated code possibly with some coordinates that are always 0.

Proof: The proof of (i) is by induction on n. For the initial case, we assume that all codewords have weight n, in which case k = 1 and C is an [n, 1, n] code by the Singleton Bound. As a generator matrix for C is one codeword u with each entry nonzero, the n coordinate functionals are clearly equivalent. As 0 \equiv wt(u) \equiv n (mod \Delta), the result holds in this case.

Now assume that u is a nonzero codeword of C with weight w < n. By assumption \Delta | w. By permuting the coordinates (which permutes the coordinate functionals but does not change the sizes of the equivalence classes), we may assume that u = u_1 ... u_w 0 ... 0, where each u_i is nonzero. If c = c_1 ... c_n is a codeword in C, write c = (c' | c'') where c' = c_1 ... c_w and c'' = c_{w+1} ... c_n. Define C' = {c' | c = (c' | c'') \in C} and C'' = {c'' | c = (c' | c'') \in C}. So C' and C'' are both codes of lengths less than n. Notice that no coordinate functional f_i of C with 1 \le i \le w is equivalent to any coordinate functional f_j with w + 1 \le j \le n. Also the coordinate functionals for C are determined by the coordinate functionals for C' and C''. Therefore if we show that both C' and C'' are divisible by \Delta, then by induction their coordinate functionals split into classes with sizes that are multiples of \Delta, and thus the coordinate functionals of C split into classes of exactly the same sizes. To show both C' and C'' are divisible by \Delta, let c = (c' | c'') \in C. We need to show that wt(c') and wt(c'') are divisible by \Delta. Clearly, wt(c'') = n_{0,u}; as p | \Delta, by Lemma 9.11.2(iv), n_{0,u} \equiv 0 (mod \Delta). Part (i) now follows.

Part (ii) is obvious from part (i) as you can rescale the coordinate functionals in an equivalence class so that the new functionals are identical.

This lemma shows what happens when we have a divisor relatively prime to p. The next two lemmas show what happens when we have a divisor that is a power of p. We extend the map \tau to codewords of a code by acting with \tau componentwise. Note that \tau is injective. The first lemma gives its image.

### Lemma 9.11.4 Let C have divisor \Delta, where \Delta is a power of p. If \Delta > 2 or q > 2, then \tau(C) \subseteq C^\perp.

Proof: It suffices to show that if u, v \in C, then \tau(u) \cdot v = 0. As

\alpha_{u,v} = |\{i | u_i \neq 0 \text{ and } v_i = \alpha u_i\}| = |\{i | u_i \neq 0 \text{ and } \tau(u)_i v_i = \alpha\}|.

we have

\tau(u) \cdot v = \sum_{\alpha \in F_q^*} \alpha(\alpha_{u,v}).

noting that no component i contributes to the inner product when u_i = 0 or v_i = 0. By Lemma 9.11.2(ii), \alpha_{u,v} \equiv n_{0,u} (mod \Delta), and so \alpha_{u,v} \equiv n_{0,u} (mod p) as p | \Delta. Thus

\tau(u) \cdot v = n_{0,u} \sum_{\alpha \in F_q^*} \alpha.

If q > 2, \sum_{\alpha \in F_q^*} \alpha = 0. If q = 2, then 4 | \Delta implying n_{0,u} \equiv 0 (mod 2) by Lemma 9.11.2(iv). Thus in either case \tau(u) \cdot v = 0.

Note that if the hypothesis of Lemma 9.11.4 holds and C has dimension n/2, then \(\tau(C) = C^\perp\). We examine the possible values of \(\Delta\) that could occur when \(q \in \{2, 3, 4\}\).

### Lemma 9.11.5 Assume \(\tau(C) = C^\perp\) and \(q \in \{2, 3, 4\}\). Then:
(i) p is a divisor of C, and
(ii) the highest power of p dividing C is p if \(q \in \{3, 4\}\) and is 4 if q = 2.

**Proof:** As in the identity when \(q \in \{2, 3\}\), C is self-dual. If q = 4, C is Hermitian self-dual by Lemma 9.11.(ii), Thus (i) follows from Theorem 1.4.5. To prove (ii), we permute the coordinates so that C has a generator matrix \(G_1 = [I_{n/2} \quad A]\) in standard form; note that this does not affect the hypothesis of the lemma. As \(\tau(C) = C^\perp\), \([I_{n/2} \quad \tau(A)]\) is a generator matrix for \(C^\perp\); hence \(G_2 = [-\tau(A)^T \quad I_{n/2}]\) is a generator matrix of C by Theorem 1.2.1. Let \(\mathbf{u} = 10 \cdots 0a_1 \cdots a_{n/2}\) be the first row of \(G_1\). Choose i so that \(a_i \neq 0\); such an entry exists as all weights are divisible by at least 2. Let \(\mathbf{v} = b_1 \cdots b_{n/2} 0 \cdots 1 \cdots 0\) be a row of \(G_2\) where entry 1 is in coordinate i. Both \(\mathbf{u}\) and \(\mathbf{v}\) are in C, and so \(\mathbf{0} = \mathbf{u} \cdot \tau(\mathbf{v}) = (b_1 + a_i)\) implying \(b_1 = -a_i\). When q = 2, wt(u + v) = wt(u) + wt(v) - 4 as \(a_i = b_1 = 1\) showing that the highest power of 2 dividing C is 4. When q = 3, wt(u + v) = wt(u) + wt(v) - 3a as \(b_1 = -1, 1\) implying that the highest power of 3 dividing C is 3. When q = 4, choose \(\alpha \in F_4\) with \(\alpha \neq 0\) and \(\alpha \neq a_i\). Then wt(u + \(\alpha\)v) = wt(u) + wt(v) - 2 proving that the highest power of 2 dividing C is 2.

We need one final lemma.

### Lemma 9.11.6 Let C be an [n, k] code over \(F_q\) divisible by \(\Delta > 1\) where either \(\Delta > 2\) or q > 2. Then:
(i) \(k \le n/2\), and
(ii) if k = n/2 and f is some integer dividing \(\Delta\) with f > 1 and p | f, then f = 2 and C is equivalent to the code over \(F_q\) with generator matrix \([I_{n/2} \quad I_{n/2}]\).

**Proof:** Suppose f | \(\Delta\) with f > 1 and p | f. Then by Lemma 9.11.3(ii), C is monomially equivalent to an f-fold replicated code possibly with some coordinates that are always 0. As f > 1, \(k \le n/f \le n/2\), which gives (i) in this case. This also shows that if k = n/2, then f = 2 and there can be no coordinates that are always 0 producing (ii). So assume that \(\Delta\) is a power of p; part (i) follows in this case from Lemma 9.11.4 as \(\tau(C) \subseteq C^\perp\).

We now complete the proof of the Gleason-Pierce-Ward Theorem. If \(\Delta\) has a factor greater than 1 and relatively prime to p, we have (v) by Lemma 9.11.6. So we may assume that \(\Delta\) is a power of p. We may also assume that \(\Delta > 2\) or q > 2, as otherwise we have (i). We need to show that we have one (or more) of (ii), (iii), (iv), or (v). As C has dimension n/2, by Lemma 9.11.4 \(\tau(C) = C^\perp\). Permuting columns as previously, we may assume that \(G_1 = [I_{n/2} \quad A]\) is a generator matrix for C and \(G_2 = [I_{n/2} \quad \tau(A)]\) is a generator matrix for \(C^\perp\). Each row of A has at least one nonzero entry as C is divisible by at least 2. If every row and column of A has exactly one nonzero entry, then C satisfies (v). Hence, permuting columns again, we may assume that the first two rows of G1 are

```
\mathbf{u} = (1, 0, 0, \dots, 0, a, \dots) \quad \text{and}
\mathbf{v} = (0, 1, 0, \dots, 0, b, \dots)
```
