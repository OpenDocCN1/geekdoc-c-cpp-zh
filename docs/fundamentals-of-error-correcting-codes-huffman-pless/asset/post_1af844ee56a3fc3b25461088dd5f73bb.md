## 7.7 Other weight enumerators

There are other weight enumerators for a code that contain more detailed information about the codewords. If $\mathbf{c} \in \mathbb{F}_q^n$ and $\alpha \in \mathbb{F}_q$, let $s_\alpha(\mathbf{c})$ be the number of components of $\mathbf{c}$ that equal $\alpha$. Let $\mathbb{F}_q = \{\alpha_0, \alpha_1, \dots, \alpha_{q-1}\}$. The polynomial

$W_C(x_{\alpha_0}, x_{\alpha_1}, \dots, x_{\alpha_{q-1}}) = \sum_{\mathbf{c} \in C} \prod_{\alpha \in \mathbb{F}_q} x_\alpha^{s_\alpha(\mathbf{c})}$

is called the *complete weight enumerator* of $C$. Notice that if $P$ is a permutation matrix, then $CP$ and $C$ have the same complete weight enumerator; however, generally $CM$ and $C$ do not have the same complete weight enumerator if $M$ is a monomial matrix. If $q=2$, then $W_C(x_0, x_1)$ is the ordinary weight enumerator $W_C(x_1, x_0)$. MacWilliams [213] also proved that there is an identity between the complete weight enumerator of $C$ and the complete weight enumerator of $C^\perp$. This identity is the same as $(M_3)$ if $q=2$. If $q=3$, with $\mathbb{F}_3 = \{0, 1, 2\}$, the identity is

$W_{C'}(x_0, x_1, x_2) = \frac{1}{|C|} W_C(x_0 + x_1 + x_2, x_0 + \xi x_1 + \xi^2 x_2, x_0 + \xi^2 x_1 + \xi x_2), \quad (7.12)$

where $\xi = e^{2\pi i / 3}$ is a primitive complex cube root of unity. If $q=4$, with $\mathbb{F}_4 = \{0, 1, \omega, \overline{\omega}\}$ as in Section 1.1, there are two MacWilliams identities depending on whether one is considering the Hermitian or the ordinary dual; see [291]. For the ordinary dual it is

$W_{C'}(x_0, x_1, x_\omega, x_{\overline{\omega}}) = \frac{1}{|C|} W_C(x_0 + x_1 + x_\omega + x_{\overline{\omega}}, x_0 + x_1 - x_\omega - x_{\overline{\omega}}, x_0 - x_1 - x_\omega + x_{\overline{\omega}}, x_0 - x_1 + x_\omega - x_{\overline{\omega}}). \quad (7.13)$

And for the Hermitian dual, the MacWilliams identity is

$W_{C', H}(x_0, x_1, x_\omega, x_{\overline{\omega}}) = \frac{1}{|C|} W_C(x_0 + x_1 + x_\omega + x_{\overline{\omega}}, x_0 + x_1 - x_\omega - x_{\overline{\omega}}, x_0 - x_1 - x_\omega + x_{\overline{\omega}}, x_0 - x_1 + x_\omega - x_{\overline{\omega}}). \quad (7.14)$

The Lee weight enumerator is sometimes used for codes over fields of characteristic $p \neq 2$. For such fields, let $\mathbb{F}_q = \{a_0 = 0, a_1, \dots, a_{r-1}, -a_1, \dots, -a_r\}$ where $r = (q-1)/2$. The Lee weight enumerator of $\mathcal{C}$ is the polynomial

$W_C^L(x_0, x_1, \dots, x_{q-1}) = \sum_{c \in C} x_0^{k(c)} \prod_{i=1}^r x_{a_i}^{(c)_i + (-c)_i}$.

The Lee weight enumerator reduces the number of variables in the complete weight enumerator essentially by half. If $q > 3$, then $W_C(x_0, x_0) = W_C^L(x_0, x_1)$. There is also a relationship between the Lee weight enumerator of $\mathcal{C}$ and the Lee weight enumerator of $C^\perp$, which is obtained by equating $x_a$ and $x_{-a}$ in the MacWilliams identity for the complete weight enumerator.

MacWilliams identities are established for other families of codes and other types of weight enumerators in [291].

## 7.8 Constraints on weights

In this section, we will present constraints on the weights of codewords in even binary codes, where we recall that a binary code is called even if all of its codewords have even weight. The following identity from Theorem 1.4.3 for two vectors x, y \in F_2^n will prove useful:

wt(x + y) = wt(x) + wt(y) - 2wt(x \cap y), (7.15)

where x \cap y is the vector in F_2^n which has 1s precisely in those positions where both x and y have 1s. When the ordinary inner product between two vectors x and y is 0, we say the vectors are orthogonal and denote this by x \perp y.

The following is an easy consequence of (7.15).

### Lemma 7.8.1 Let x and y be two vectors in F_2^n.

- (i) Suppose wt(x) \equiv 0 (mod 4). Then wt(x + y) \equiv wt(y) (mod 4) if and only if x \perp y, and wt(x + y) \equiv wt(y) + 2 (mod 4) if and only if x \not\perp y.
- (ii) Suppose wt(x) \equiv 2 (mod 4). Then wt(x + y) \equiv wt(y) (mod 4) if and only if x \not\perp y, and wt(x + y) \equiv wt(y) + 2 (mod 4) if and only if x \perp y.

Exercise 414 Prove Lemma 7.8.1.

We say that a binary vector is doubly-even if its weight is divisible by 4. A binary vector is singly-even if its weight is even but not divisible by 4. Recall from Theorem 1.4.8 that if a binary code has only doubly-even vectors, the code is self-orthogonal. We will be primarily interested in codes where not all codewords are doubly-even. We will present a decomposition of even binary codes into pieces that are called the hull of the code, H-planes, and A-planes. An H-plane or A-plane is a 2-dimensional space spanned by x and y, such a space is denoted span{x, y}. The hull, H-plane, and A-plane are defined as follows:

- The hull of a code C is the subcode H = C \cap C^{\perp}.
- If x and y are doubly-even but not orthogonal, then we call span{x, y} an H-plane. Note that if span{x, y} is an H-plane, then wt(x + y) \equiv 2 (mod 4) by Lemma 7.8.1(i), and so an H-plane contains two nonzero doubly-even vectors and one singly-even vector.
- If x and y are singly-even but not orthogonal, then we call span{x, y} an A-plane. If span{x, y} is an A-plane, then wt(x + y) \equiv 2 (mod 4) still holds by Lemma 7.8.1(ii); an A-plane therefore contains three singly-even vectors.
