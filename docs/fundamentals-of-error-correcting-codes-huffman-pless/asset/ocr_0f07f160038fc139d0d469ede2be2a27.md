By Theorem 6.1.3(iii) and (v), the dimensions of even-like and odd-like duadic codes $C_1$ and $D_1$ indicate it is possible (although not necessary) that the dual of $C_1$ is either $\mathcal{D}_1$ or $\mathcal{D}_2$. The next two theorems describe when these two possibilities occur.

# Theorem 6.4.2 If $C_1$ and $C_2$ are a pair of even-like duadic codes over $\mathbb{F}_q$, with $\mathcal{D}_1$ and $\mathcal{D}_2$ the associated pair of odd-like duadic codes, the following are equivalent:

+   (i) $C_1^\perp = \mathcal{D}_1$.
+   (ii) $C_2^\perp = \mathcal{D}_2$.
+   (iii) $C_{\mu-1} = C_2$.
+   (iv) $\mathcal{C}_{2\mu-1} = \mathcal{C}_1$.

Proof: Since $C_{1\mu a} = C_2$, $C_{2\mu a} = C_1$, $\mathcal{D}_{1\mu a} = \mathcal{D}_2$, and $\mathcal{D}_{2\mu a} = \mathcal{D}_1$ for some $a$ (by definition of the even-like duadic codes and Theorem 6.1.3(vii)), (i) is equivalent to (ii) by Exercise 35. Parts (iii) and (iv) are equivalent as $\mu_{-1} = \mu_{-1}$. If (i) holds, $C_1$ is self-orthogonal by Theorem 6.1.3(vi), implying that (iii) holds by Theorem 6.4.1. Conversely, if (iii) holds, letting $e_i(x)$ be the generating idempotent for $C_i$, we have $e_1(x)\mu_{-1} = e_2(x)$ by Theorem 4.3.13. By Theorem 4.4.9, $C_1^\perp = (1 - e_1(x)\mu_{-1}) = (1 - e_2(x)) = \mathcal{D}_1$ yielding (i).

# Theorem 6.4.3 If $C_1$ and $C_2$ are a pair of even-like duadic codes over $\mathbb{F}_q$ with $\mathcal{D}_1$ and $\mathcal{D}_2$ the associated pair of odd-like duadic codes, the following are equivalent:

+   (i) $C_1^\perp = \mathcal{D}_2$.
+   (ii) $C_2^\perp = \mathcal{D}_1$.
+   (iii) $C_{\mu-1} = C_1$.
+   (iv) $\mathcal{C}_{2\mu-1} = \mathcal{C}_2$.

Proof: Since $C_{1\mu a} = C_2$, $C_{2\mu a} = C_1$, $\mathcal{D}_{1\mu a} = \mathcal{D}_2$, and $\mathcal{D}_{2\mu a} = \mathcal{D}_1$ for some $a$ (by definition of the even-like duadic codes and Theorem 6.1.3(vii)), (i) is equivalent to (ii) by Exercise 35. Let $e_i(x)$ be the generating idempotent of $C_i$. By Theorem 4.4.9, $C_1^\perp = \mathcal{D}_2$ if and only if $1 - e_1(x)\mu_{-1} = 1 - e_1(x)$ if and only if $e_1(x)\mu_{-1} = e_1(x)$. So $C_1^\perp = \mathcal{D}_2$ if and only if $\mu_{-1} C_1$ by Theorem 6.1.3. Thus (i) and (ii) are equivalent and, analogously (ii) and (iv) are equivalent. The theorem now follows.
