# Theorem 2.1.0.6 (The First MRRW Bound) Let $0 < \delta < r = 1 - q^{-1}$. Then

\(\alpha_q(\delta) \le H_q \left( \frac{1}{q}(q-1-(q-2)\delta - 2\sqrt{(q-1)\delta(1-\delta)}) \right).\)

In particular if $q=2$, then when $0 < \delta < 1/2$,

\(\alpha_2(\delta) \le H_2 \left( \frac{1}{2} - \sqrt{\delta(1-\delta)} \right).\)

# Theorem 2.1.0.7 (The Second MRRW Bound) Let $0 < \delta < 1/2$. Then

\(\alpha_2(\delta) \le \min_{0 \le u \le 1-2\delta} (1 + g(u^2) - g(u^2 + 2\delta u + 2\delta))\)

where \(g(x) = H_2((1 - \sqrt{1-x})/2)\).

The Second MRRW Bound is better than the First MRRW Bound, for $q=2$, when $\delta < 0.272$. Amazingly, if $q=2$, the bounds agree when $0.273 \le \delta \le 0.5$. Exercise 142 shows that the Second MRRW Bound is strictly smaller than the Asymptotic Elias Bound when $q=2$.
