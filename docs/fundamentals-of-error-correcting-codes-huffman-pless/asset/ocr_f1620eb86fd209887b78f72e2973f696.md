As can be seen in Example 5.4.20 and Exercises 311 and 312, the error-correcting capability of the Sudan–Guruswami Decoding Algorithm can grow if m is increased. The tradeoff for higher error-correcting capability is an increase in the (1, k - 1)-weighted degree of p(x, y), which of course increases the complexity of the algorithm. The following corollary gives an idea of how the error-correcting capability varies with m.

**Corollary 5.4.21** The Sudan–Guruswami Decoding Algorithm applied to the [n, k, n - k + 1] code GRS_k(\gamma, v) will produce all codewords within Hamming distance e or less of a received vector where e >= n - 1 - n \sqrt{R(m + 1)/m} and R = k/n.

**Proof:** As $\delta$ is chosen to be the smallest positive integer such that (5.21) holds, $N_{k-1}((\delta - 1) \le nm(m + 1)/2$. By Lemma 5.4.19, $N_{k-1}((\delta - 1) \ge (\delta - 1)(\delta + 1)/(2(k - 1))$. Hence $\frac{\delta^2 - 1}{2(k - 1)} \le \frac{nm(m + 1)}{2}$. If $\delta^2 < k$, then $\delta^2/(2k) < 1/2 \le nm(m + 1)/2$. If $\delta^2 \ge k$, then $\delta^2/(2k) \le (\delta^2 - 1)/(2(k - 1))$ by Exercise 313. In either case, $\delta^2/2k \le nm(m + 1)/2$, implying $\frac{\delta}{m} \le n \sqrt{\frac{k}{m} \frac{m + 1}{m}}$, which produces the desired result from Theorem 5.4.18.

+   **Exercise 313** Do the following: (a) Show that if $\delta^2 \ge k$, then $\delta^2/(2k) \le (\delta^2 - 1)/(2(k - 1))$. (b) Show that if $\delta^2/(2k) \le nm(m + 1)/2$, then $\delta/m \le n \sqrt{k/n(m + 1)/m}$.

In this corollary, R = k/n is the information rate. If m is large, we see that the fraction e/n of errors of the Sudan–Guruswami Decoding Algorithm can correct is approximately 1 - \sqrt{R}. The fraction of errors that the Peterson–Gorenstein–Zierler Decoding Algorithm can correct is approximately (1 - R)/2. Exercise 314 explores the relationship between these two functions.
