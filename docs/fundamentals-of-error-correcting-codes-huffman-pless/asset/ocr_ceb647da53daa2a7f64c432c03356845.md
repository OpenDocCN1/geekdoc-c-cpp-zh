# 2.6 The Linear Programming Upper Bound

The next upper bound that we present is the linear programming bound which uses results of Delsart [61, 62, 63]. In general, this is the most powerful of the bounds we have presented but, as its name signifies, does require the use of linear programming. In order to present this bound, we introduce two concepts. First, we generalize the notion of weight distribution of a code. The Hamming distance distribution or inner distribution of a code \( \mathcal{C} \) of length \( n \) is the list \( B_i = B_i(\mathcal{C}) \) for \( 0 \le i \le n \), where

\( B_i(\mathcal{C}) = \frac{1}{|\mathcal{C}|} \sum_{c \in \mathcal{C}} |\{ \mathbf{v} \in \mathcal{C} \mid d(\mathbf{v}, \mathbf{c}) = i \}| \).

By Exercise 117, the distance distribution and weight distribution of a linear code are identical. In particular, if \( \mathcal{C} \) is linear, the distance distribution is a list of nonnegative integers; if \( \mathcal{C} \) is nonlinear, the \( B_i \) are nonnegative but need not be integers.
