Hartmann and Tzeng [117] showed that if there are several consecutive sets of $\delta - 1$ elements in the defining set that are spaced properly, then the BCH Bound can be improved. To state the Hartmann–Tzeng Bound, which we do not prove, we develop the following notation. If $A$ and $B$ are subsets of the integers modulo $n$, then $A + B = \{a + b \mod n \mid a \in A, b \in B\}$.

### Theorem 4.5.6 (Hartmann–Tzeng Bound)
Let $\mathcal{C}$ be a cyclic code of length $n$ over $\mathbb{F}_q$ with defining set $T$. Let $B$ be a set of $\delta - 1$ consecutive elements of $T$ and $B = \{jb \mod n \mid 0 \le j \le s\}$, where $\gcd(b, n) < \delta$. If $A + B \subseteq T$, then the minimum weight $d$ of $\mathcal{C}$ satisfies $d \ge \delta + s$.

Clearly the BCH Bound is the Hartmann–Tzeng Bound with $s = 0$.

### Example 4.5.7
Let $\mathcal{C}$ be the binary cyclic code of length 17 with defining set $T = \{1, 2, 4, 8, 9, 13, 15, 16\}$. There are two consecutive elements in $T$ and so the BCH Bound gives $d \ge 3$. The Hartmann–Tzeng Bound improves this. Let $A = \{1, 2\}$ and $B = \{0, 7, 14\}$. So $\delta = 3, b = 7$, and $s = 2$; also $\gcd(7, 17) = 1 < \delta$. So $\mathcal{C}$ has minimum weight $d \ge 5$. Note that $\mathcal{C}$ is a [17, 9] code. By the Griesmer Bound, there is no [17, 9, 7] code. Hence $d = 5$ or 6. In fact, $d = 5$; see [203].

### Example 4.5.8
Let $\mathcal{C}$ be the binary cyclic code of length 31 with defining set $T = \{1, 2, 4, 5, 8, 9, 10, 16, 18, 20\}$ and minimum weight $d$. The BCH Bound shows that $d \ge 4$ as the consecutive elements $\{8, 9, 10\}$ are in $T$. If $d = 4$, then the minimum weight vectors are in the subcode $\mathcal{C}_s$ of all even-like vectors in $\mathcal{C}$. By Exercise 238, $\mathcal{C}_s$ is cyclic with defining set $T_s = \{0, 1, 2, 4, 5, 8, 9, 10, 16, 18, 20\}$. Applying the Hartmann–Tzeng Bound with $A = \{0, 1, 2\}$ and $B = \{0, 8\}$ (since $\gcd(8, 31) = 1 < \delta = 4$), the minimum weight of $\mathcal{C}_s$ is at least 5. Hence the minimum weight of $\mathcal{C}$ is at least 5, which is in fact the true minimum weight by [203].

### Example 4.5.9
Let $\mathcal{C}$ be the binary cyclic code of length 31 with defining set $T = \{1, 2, 3, 4, 5, 6, 8, 9, 10, 11, 12, 13, 16, 17, 18, 20, 21, 22, 24, 26\}$ and minimum weight $d$. Applying the Hartmann–Tzeng Bound with $A = \{1, 2, 3, 4, 5, 6\}$ and $B = \{0, 7\}$ (since $\gcd(7, 31) = 1 < \delta = 7$), we obtain $d \ge 8$. Suppose that $d = 8$. Generalizations of the Hartmann–Tzeng Bound discovered by Roos can be found in [296, 297].

In [203] van Lint and Wilson give techniques that can be used to produce lower bounds on the minimum weight of a cyclic code; we present one of these, which we will refer to as the van Lint–Wilson Bounding Technique. The van Lint–Wilson Bounding Technique can be used to prove both the BCH and the Hartmann–Tzeng Bounds. In order to use the van Lint–Wilson Bounding Technique, a sequence of subsets of the integers modulo $n$, related to the defining set of a code, must be constructed. Let $\mathcal{N} = \{0, 1, \dots n - 1\}$. Let $S \subseteq \mathcal{N}$. A sequence $I_0, I_1, I_2 \dots$ of subsets of $\mathcal{N}$ is an independent sequence with respect to $S$ provided
- $I_0 = \emptyset$, and
- if $i > 0$, either $I_i = I_j \cup \{a\}$ for some $0 \le j < i$ such that $I_j \subseteq S$ and $a \in \mathcal{N} \setminus S$, or $I_i = \{b\} + I_j$ for some $0 \le j < i$ and $b \neq 0$.
A subset $I$ of $\mathcal{N}$ is independent with respect to $S$ provided that $I$ is a set in an independent sequence with respect to $S$. Recall that $\alpha$ is a primitive $n$th root of unity in $\mathbb{F}_q$, where $t = \text{ord}_n(q)$.

### Theorem 4.5.10 (van Lint–Wilson Bounding Technique)
Suppose $f(x)$ is in $\mathbb{F}_q[x]$ and has degree at most $n$. Let $I$ be any subset of $\mathcal{N}$ that is independent with respect to $S = \{i \in \mathcal{N} \mid f(\alpha^i) = 0\}$. Then the weight of $f(x)$ is at least the size of $I$.

**Proof:** Let $f(x) = c_1 x^{i_1} + c_2 x^{i_2} + \dots + c_w x^{i_w}$, where $c_j \neq 0$ for $1 \le j \le w$, and let $I$ be any independent set with respect to $S$. Let $I_0, I_1, I_2 \dots$ be an independent sequence with respect to $S$ such that $I = I_i$ for some $i \ge 0$. If $J \subseteq \mathcal{N}$, let $V(J)$ be the set of vectors in $\mathbb{F}_{q^n}^n$ defined by

$V(J) = \{(\alpha^{kl_1}, \alpha^{kl_2}, \dots, \alpha^{kl_n}) \mid k \in J\}.$

If we prove that $V(I)$ is linearly independent in $\mathbb{F}_{q^n}^n$, then $w \ge |V(I)| = |I|$. Hence it suffices to show that $V(I)$ is linearly independent for all $i \ge 0$, which we do by induction on $i$. As $I_0 = \emptyset$, $V(I_0)$ is the empty set and hence is linearly independent. Assume that $V(I_j)$ is linearly independent for all $0 \le j < i$. $I_i$ is formed in one of two ways. First suppose $I_i = I_j \cup \{a\}$ for some $0 \le j < i$, where $I_j \subseteq S$ and $a \in \mathcal{N} \setminus S$. By the inductive assumption, $V(I_j)$ is linearly independent. As $0 = f(\alpha^a) = c_1 \alpha^{kl_1} + c_2 \alpha^{kl_2} + \dots + c_n \alpha^{kl_n}$ for $k \in I_j$, the vector $\mathbf{c} = (c_1, c_2, \dots, c_n)$ is orthogonal to $V(I_j)$. If $V(I_i)$ is linearly dependent, then $(\alpha^{kl_1}, \alpha^{kl_2}, \dots, \alpha^{kl_n})$ is in the span of $V(I_j)$ and hence is orthogonal to $(c_1, c_2, \dots, c_n)$. So $0 = c_1 \alpha^{kl_1} + c_2 \alpha^{kl_2} + \dots + c_n \alpha^{kl_n} = f(\alpha^a)$, a contradiction as $a \notin S$. Now suppose that $I_i = \{b+I_j\}$ for some $0 \le j < i$ where $b \neq 0$. Then $V(I_i) = \{(\alpha^{(b+k)l_1}, \alpha^{(b+k)l_2}, \dots, \alpha^{(b+k)l_n}) \mid k \in I_j\} = V(I_j)D$, where $D$ is the nonsingular diagonal matrix $\text{diag}(\alpha^{bl_1}, \dots, \alpha^{bl_n})$. As $V(I_j)$ is independent, so is $V(I_i)$.

The BCH Bound is a corollary of the van Lint–Wilson Bounding Technique.

### Corollary 4.5.11
Let $\mathcal{C}$ be a cyclic code of length $n$ over $\mathbb{F}_q$. Suppose that $f(x)$ is a nonzero codeword such that $f(\alpha^b) = f(\alpha^{b+1}) = \dots = f(\alpha^{(b+w-1)}) = 0$ but $f(\alpha^{b+w}) \neq 0$. Then $\text{wt}(f(x)) \ge w+1$.

**Proof:** Let $S = \{i \in \mathcal{N} \mid f(\alpha^i) = 0\}$. So $\{b, b+1, \dots, b+w-1\} \subseteq S$ but $b+w \notin S$. Inductively define a sequence $I_0, I_1, \dots, I_{2w+1}$ as follows: Let $I_0 = \emptyset$. Let $I_{2i+1} = I_{2i} \cup \{b+w\}$ for $0 \le i \le w$ and $I_{2i} = \{1\} + I_{2i-1}$ for $1 \le i \le w$. Inductively $I_{2i} = \{b+w-i, i, b+w-i+1, \dots, b+w-1\} \subseteq S$ for $0 \le i \le w$. Therefore $I_0, I_1, \dots, I_{2w+1}$ is an independent sequence with respect to $S$. Since $I_{2w+1} = \{b, b+1, \dots, b+w\}$, the van Lint–Wilson Bounding Technique implies that $\text{wt}(f(x)) \ge |I_{2w+1}| = w+1$.
