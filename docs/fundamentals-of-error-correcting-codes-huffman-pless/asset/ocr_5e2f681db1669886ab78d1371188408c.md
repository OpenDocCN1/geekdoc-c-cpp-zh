In Exercises 696 and 697 we see that the Gray image of a code may be linear or nonlinear. It is natural to ask if we can tell when the Gray image will be linear. One criterion is the following, where $\mathbf{v} * \mathbf{w}$ is the componentwise product of the two vectors $\mathbf{v}$ and $\mathbf{w}$ in $\mathbb{Z}_4^n$.

# Theorem 12.2.3 Let $\mathcal{C}$ be a $\mathbb{Z}_4$-linear code. The binary code $\mathfrak{C}(\mathcal{C})$ is linear if and only if whenever $\mathbf{v}$ and $\mathbf{w}$ are in $\mathcal{C}$, so is $2(\mathbf{v} * \mathbf{w})$.

Proof: By Exercise 700, if $\mathbf{a}$ and $\mathbf{b}$ are in $\mathbb{Z}_4$, then $\mathfrak{S}(\mathbf{a}) + \mathfrak{S}(\mathbf{b}) = \mathfrak{S}(\mathbf{a} + \mathbf{b} + 2\mathbf{ab})$. Therefore if $\mathbf{v}$ and $\mathbf{w}$ are in $\mathbb{Z}_4^n$, then $\mathfrak{S}(\mathbf{v}) + \mathfrak{S}(\mathbf{w}) = \mathfrak{S}(\mathbf{v} + \mathbf{w} + 2(\mathbf{v} * \mathbf{w}))$. In particular, this shows that if $\mathbf{v}$ and $\mathbf{w}$ are in $\mathcal{C}$, then $\mathfrak{S}(\mathbf{v}) + \mathfrak{S}(\mathbf{w})$ is in $\mathfrak{S}(\mathcal{C})$ if and only if $\mathbf{v} + \mathbf{w} + 2(\mathbf{v} * \mathbf{w}) \in \mathcal{C}$ if and only if $2(\mathbf{v} * \mathbf{w}) \in \mathcal{C}$, since $\mathbf{v} + \mathbf{w} \in \mathcal{C}$. The result now follows.

# Theorem 12.2.4 The following hold:

+   (i) Let $\mathbf{u}$ and $\mathbf{v}$ be in $\mathbb{Z}_4^n$. Then $\text{wt}_E(\mathbf{u} + \mathbf{v}) \equiv \text{wt}_E(\mathbf{v}) + 2(\mathbf{u} * \mathbf{v}) \pmod 8$.

+   (ii) Let $\mathcal{C}$ be a self-orthogonal $\mathbb{Z}_4$-linear code which has a generator matrix $G$ such that all rows $\mathbf{r}$ of $G$ satisfy $\text{wt}_E(\mathbf{r}) \equiv 0 \pmod 8$. Then $\text{wt}_E(\mathbf{c}) \equiv 0 \pmod 8$ for all $\mathbf{c} \in \mathcal{C}$.

+   (iii) Let $\mathcal{C}$ be a $\mathbb{Z}_4$-linear code such that $\text{wt}_E(\mathbf{c}) \equiv 0 \pmod 8$ for all $\mathbf{c} \in \mathcal{C}$. Then $\mathcal{C}$ is self-orthogonal.
