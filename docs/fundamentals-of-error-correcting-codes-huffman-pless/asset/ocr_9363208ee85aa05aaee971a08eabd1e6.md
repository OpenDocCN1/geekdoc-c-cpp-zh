**Exercise 260** Identify all binary cyclic codes of lengths 7, 9, and 15 whose duals equal their cyclic complements. (Examples 3.7.8, 4.2.4, and 4.3.4 will be useful.) $\unknown$

In Theorem 4.4.9 we found the generating idempotent of the dual of any code. The multiplier $\mu_{-1}$ was key in that theorem. We can also find the generating idempotent of the Hermitian dual of a cyclic code over $\mathbb{F}_4$. Here $\mu_{-2}$ will play the role of $\mu_{-1}$. Recall from Exercise 8 that if $\mathcal{C}$ is a code over $\mathbb{F}_4$, then $C^{\perp_h} = \overline{C^\perp}$.

**Theorem 4.4.15** Let $\mathcal{C}$ be a cyclic code of length $n$ over $\mathbb{F}_4$ with generating idempotent $e(x)$ and defining set $T$. The following hold:
(i) $C^{\perp_h}$ is a cyclic code and $C^{\perp_h} = \mathcal{C}^c \mu_{-2}$, where $\mathcal{C}^c$ is the cyclic complement of $\mathcal{C}$.
(ii) $C^{\perp_h}$ has generating idempotent $1 - e(x)\mu_{-2}$.
(iii) If $N = \{0, 1, \dots, n-1\}$, then $N \setminus (-2)T \text{ mod } n$ is the defining set of $C^{\perp_h}$.
(iv) Precisely one of $\mathcal{C}$ and $C^{\perp_h}$ is odd-like and the other is even-like.

Proof. We leave the fact that $C^{\perp_h}$ is a cyclic code as Exercise 8. Exercise 8 shows that $C^{\perp_h} = \overline{C^\perp}$. By Theorem 4.4.9 $\overline{C^\perp} = \mathcal{C}^c \mu_{-1}$. Theorem 4.3.16 shows that $\overline{\mathcal{C}^c} = \overline{\mathcal{C}}^c = \mathcal{C}^c \mu_2$, and (i) follows since $\mu_2 \mu_{-1} = \mu_{-2}$. By Theorem 4.4.6 $C^{\perp_h} = \overline{C^\perp} \mu_{-2}$ has generating idempotent $(1 - e(x))\mu_{-2} = 1 - e(x)\mu_{-2}$, giving (ii). $\mathcal{C} \mu_{-2}$ has defining set $(-2)^{-1}T \text{ mod } n$ by Corollary 4.4.5. However, $(-2)^{-1}T = (-2)T$ modulo $n$ because $\mu_{-2}^2 = \mu_4 = \mu_4$ and $\mu_4$ fixes all 4-cyclotomic cosets. By Theorem 4.4.6(ii) and Corollary 4.4.5, $C^{\perp_h} = \mathcal{C}^c \mu_{-2}$ has defining set $(-2)^{-1}(N \setminus T) = N \setminus (-2)T \text{ mod } n$, giving (iii). Part (iv) follows from (iii) and Exercise 238 as precisely one of $N$ and $N \setminus (-2)T \text{ mod } n$ contains 0. $\square$

**Exercise 262** Using Theorem 4.3.16 find generating idempotents of all the cyclic codes $\mathcal{C}$ of length 9 over $\mathbb{F}_4$, their ordinary duals $C^\perp$, and their Hermitian duals $C^{\perp_h}$. $\unknown$

We can obtain a result analogous to Theorem 4.4.11 for Hermitian self-orthogonal cyclic codes over $\mathbb{F}_4$. Again we simply replace $\mu_{-1}$ by $\mu_{-2}$ and apply Theorem 4.4.15. Notice that if $\mathcal{C}$ is a 4-cyclotomic coset modulo $n$, then either $C\mu_{-2} = \mathcal{C}$ or $C\mu_{-2} = \mathcal{C}'$ for a different 4-cyclotomic coset $\mathcal{C}'$, in which case $C'\mu_{-2} = \mathcal{C}$ as $\mu_{-2}^2 = \mu_4 = \mu_4$ and $\mu_4$ fixes all 4-cyclotomic cosets.

**Theorem 4.4.16** Let $\mathcal{C}$ be a Hermitian self-orthogonal cyclic code over $\mathbb{F}_4$ of length $n$ with defining set $T$. Let $C_1, \dots, C_k, D_1, \dots, D_\ell, E_1, \dots, E_\ell$ be all the distinct 4-cyclotomic cosets modulo $n$ partitioned so that $C_i = C_i \mu_{-2}$ for $1 \le i \le k$ and $D_j = E_j \mu_{-2}$ for $1 \le j \le \ell$. The following hold:
(i) $C_i \subseteq T$ for $1 \le i \le k$ and at least one of $D_j$ or $E_j$ is contained in $T$ for $1 \le j \le \ell$.
(ii) $\mathcal{C}$ is even-like.
(iii) $\mathcal{C} \cap \mathcal{C}\mu_{-2} = \{0\}$.
