# Exercise 755 Show that the generator matrices in Examples 12.2.5 and 12.7.3 generate the same $\mathbb{Z}_4$-linear code.

We now use the relative trace to list all the codewords in $K(r+1)$ and $\widehat{K}(r+1)$. Let $\mathbf{I}_n$ denote the all-one vector of length $n$.

# Lemma 12.7.4 Let $r \ge 2$ and $n = 2^r - 1$. Then $\mathbf{c} \in K(r+1)$ if and only if there exists $\lambda \in \mathcal{R} = \text{GR}(4^r)$ and $\epsilon \in \mathbb{Z}_4$ such that

$$\mathbf{c} = (\text{TR}(\lambda), \text{TR}(\lambda\xi), \text{TR}(\lambda\xi^2), \dots, \text{TR}(\lambda\xi^{n-1})) + \epsilon \mathbf{I}_n.$$ (12.23)

The parity check for $\mathbf{c}$ is $\epsilon$.

**Proof:** Using Exercise 755, $\sum_{i=0}^{n-1} (\text{TR}_r(\lambda \xi^i) + \epsilon) = \text{TR}_r(\lambda \sum_{i=0}^{n-1} \xi^i) + (2^r - 1)\epsilon = \text{TR}_r(\lambda \frac{\xi^n - 1}{\xi - 1}) + (2^r - 1)\epsilon \equiv (\text{TR}_r(0) + (2^r - 1)\epsilon \equiv (2^r - 1)\epsilon \equiv 3\epsilon \text{ (mod 4)}$. So the parity check for $\mathbf{c}$ is $\epsilon$.

Let $\mathcal{C} = \{(\text{TR}(\lambda), \text{TR}(\lambda\xi), \text{TR}(\lambda\xi^2), \dots, \text{TR}(\lambda\xi^{n-1})) + \epsilon \mathbf{I}_n \mid \lambda \in \text{GR}(4^r), \epsilon \in \mathbb{Z}_4\}$. We first show that $\mathcal{C}$ has $4^{r+1}$ codewords; this is clear if we show that $\text{TR}_r(\lambda \xi^i) + \epsilon = \text{TR}_r(\lambda_i \xi^i) + \epsilon_1$ for $0 \le i \le n-1$ implies $\lambda = \lambda_1$ and $\epsilon = \epsilon_1$. But $\epsilon = \epsilon_1$ since the parity check of $\mathbf{c}$ is $\epsilon$. Therefore by Exercise 753, $\text{TR}_r(\xi^i) = 0$ for $0 \le i \le n-1$ where $\lambda = \lambda - \lambda_1$. We only need to show that $\xi = 0$. Since $\text{TR}_r(\xi^i) = 0$, $\text{TR}_r(\xi^{2i}) = 0$ for $0 \le i \le n-1$ where $\lambda = \lambda - \lambda_1$.

We now show that $\epsilon$ can has the form in (12.23), then $\mathbf{c} \in K(r+1)$. Since $\mathbf{I}_n \in K(r+1)$, we only need to show that $\mathbf{c} \in K(r+1)$ when $\epsilon = 0$. If $\lambda = 0$, the result is clear. If $\lambda \ne 0$, then $c(x) \ne 0$ by the above argument. Now $c^*(x)$ is some cyclic shift of $p(x) = \alpha \sum_{i=0}^{n-1} \text{TR}_r(\lambda \xi^{n-1-i}) x^i$ for some $\alpha \in \mathbb{Z}_4$ chosen so that the leading coefficient is 1 or $2$ ($c^*(x)$ may not equal $p(x)$ without the shift as we do not know the degree of $c(x)$). By Lemma 12.7.2, $\mathbf{c} \in K(r+1)$ if $H(\mathbf{c})p(x) = 0$ in $\mathfrak{A}_n$. By the same argument as in the proof of Lemma 12.7.2, the coefficient of $x^k$ for $0 \le k \le n-1$ in the product $H(\mathbf{c})p(x)$ is

$$\alpha \sum_{i+j \equiv k \text{ (mod } n)} H_i \text{TR}_r(\lambda \xi^{n-1-j}) = \alpha \text{TR}_r \left( \lambda \sum_{i=0}^{n-1} H_i \xi^{n-1-k+i} \right) = \alpha \text{TR}_r \left( \lambda \xi^{n-1-k} \sum_{i=0}^{n-1} H_i \xi^i \right),$$

using Exercise 753, as $H_i \in \mathbb{Z}_4$. The latter trace is $\text{TR}_r(\lambda \xi^{n-1-k} H(\xi)) = \text{TR}_r(0) = 0$ and hence $H(\mathbf{c})p(x) = 0$ in $\mathfrak{A}_n$. So $\mathbf{c} \in K(r+1)$. Since $K(r+1)$ and $\mathcal{C}$ each have $4^{r+1}$ codewords and $\mathcal{C} \subseteq K(r+1)$, $\mathcal{C} = K(r+1)$.
