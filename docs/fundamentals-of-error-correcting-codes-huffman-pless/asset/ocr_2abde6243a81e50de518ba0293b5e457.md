Since

```
\lim_{n \to \infty} n^{-1} \log_q (B^k e) = \lim_{n \to \infty} n^{-1} (\log_q B + k \log_q e) = \lim_{n \to \infty} n^{-1} \log_q B,
```

we conclude that

```
\lim_{n \to \infty} A = \lim_{n \to \infty} n^{-1} \log_q B
= \lim_{n \to \infty} n^{-1} [n \log_q n - \lfloor \delta n \rfloor \log_q \lfloor \delta n \rfloor - (n - \lfloor \delta n \rfloor) \log_q (n - \lfloor \delta n \rfloor)]
+ \lim_{n \to \infty} n^{-1} (1/2) [\log_q n - \log_q \lfloor \delta n \rfloor - \log_q (n - \lfloor \delta n \rfloor)]
= -\delta \log_q \delta - (1 - \delta) \log_q (1 - \delta) + 0
```

by Exercise 135. Plugging into (2.45), we obtain

```
\lim_{n \to \infty} n^{-1} \log_q V_q(n, \lfloor \delta n \rfloor) = -\delta \log_q \delta - (1 - \delta) \log_q (1 - \delta) + \delta \log_q(q - 1),
```

which is $H_q(\delta)$, proving the result. $\square$

# Theorem 2.10.4 (Asymptotic Hamming Bound) Let $0 < \delta \le 1 - q^{-1}$, where $q \ge 2$. Then $\alpha_q(\delta) \le 1 - H_q(\delta)/2$.

Proof: Note first that $A_q(n, \delta n) = A_q(n, \lfloor \delta n \rfloor) \le q^n / V_q(n, (\lfloor \delta n \rfloor - 1)/2)$ by the Sphere Packing Bound. If $n \ge N$, $(\lfloor \delta n \rfloor - 1)/2 \ge \lceil \delta n / 2 \rceil - 1 \ge (\lfloor \delta - (2/N)n \rfloor / 2)$. Thus $A_q(n, \delta n) \le q^n / V_q(n, (\lfloor \delta - (2/N)n \rfloor / 2)n)$, implying that

```
\alpha_q(\delta) = \limsup_{n \to \infty} n^{-1} \log_q A_q(n, \delta n)
\le \limsup_{n \to \infty} 1 - n^{-1} \log_q V_q \left( n, \left\lfloor \frac{1}{2} \left( \delta - \frac{2}{N} \right) n \right\rfloor \right)
= 1 - H_q \left( \frac{1}{2} \left( \delta - \frac{2}{N} \right) \right)
```

by Lemma 2.10.3. But as $n$ goes to infinity, we may let $N$ get as large as we please showing that $\alpha_q(\delta) = 1 - H_q(\delta)/2$ since $H_q$ is continuous. $\square$

The Asymptotic Elias Bound surpasses the Asymptotic Singleton, Plotkin, and Hamming Bounds. As we know $\alpha_q(\delta) = 0$ for $1 - q^{-1} = r \le \delta \le 1$, we only examine the case $0 < \delta < r$.
