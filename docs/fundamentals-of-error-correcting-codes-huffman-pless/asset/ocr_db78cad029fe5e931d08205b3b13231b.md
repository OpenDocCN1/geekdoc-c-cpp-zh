We now turn to a ternary code of length 11. Let $\mathcal{C}$ be a possibly nonlinear ternary code of length 11 and minimum distance 5 containing $M \ge 3^6$ codewords including the $\mathbf{0}$ codeword. We will show that this code is an [11, 6, 5] linear code unique up to equivalence. By Exercises 587 and 588, $\mathcal{C}$ is a perfect code with $3^6$ codewords including codewords of weight 11. By rescinding coordinates, we may assume that $\mathcal{C}$ contains the all-one codeword $\mathbf{1}$.

Note that if $\mathbf{c} \in \mathcal{C}$, then $\mathbf{c} - \mathcal{C}$ is a code of length 11 and minimum distance 5 containing $3^6$ codewords including the $\mathbf{0}$ codeword. Thus its weight distribution is given in Exercise 588, implying that

```
$d(\mathbf{c}, \mathbf{c}') \in \{5, 6, 8, 9, 11\}$ (10.5)
```

for distinct codewords $\mathbf{c}$ and $\mathbf{c}'$ in $\mathcal{C}$. 

We wish to show that $-\mathbf{1}$ is in $\mathcal{C}$. To do this we establish some notation. A vector in $\mathbb{F}_3^{11}$ has 'type' $(-1)^a 1^b 0^c$ if it has $a-1$s, $b$ 1s, and $c$ 0s as components. Suppose that $\mathbf{x} \notin \mathcal{C}$. As $\mathcal{C}$ is perfect, there is a unique codeword $\mathbf{c}$ at distance 2 or less from $\mathbf{x}$; we say that $\mathbf{c}$ 'covers' $\mathbf{x}$. Assume $-\mathbf{1} \notin \mathcal{C}$. Let $\mathbf{x}_i$ be the vector in $\mathbb{F}_3^{11}$ with 1 in coordinate $i$ and $-1$ in the other ten coordinates. If some $\mathbf{x}_i$ is in $\mathcal{C}$, then the distance between $\mathbf{x}_i$ and $\mathbf{1}$ is 10, contradicting (10.5). Let $\mathbf{c}_i$ cover $\mathbf{x}_i$. In particular $w(\mathbf{c}_i)$ is 9 or 11.

First assume that $w(\mathbf{c}_i) = 11$ for some $i$. No codeword can have exactly one 1 as its distance to $\mathbf{1}$ is 10, contradicting (10.5). Thus $\mathbf{c}_i$ must have at least two 1s. To cover $\mathbf{x}_i$, the only choices for $\mathbf{c}_i$ are type $(-1)^a 1^b$ or $(-1)^b 1^a$. In either case, $\mathbf{a}$ is in coordinate $i$. Now assume that $w(\mathbf{c}_i) = 9$ for some $i$. Then $\mathbf{c}_i$ must have type $(-1)^a 1^b$ with a 0 in coordinate $i$. Consider the possibilities for $\mathbf{a}, \mathbf{c}$, and $\mathbf{e}_i$. If they are unequal, their distance apart must be at least 5. This implies that both cannot have type $(-1)^a 1^b$ and $(-1)^b 1^a$ where $a$ and $b$ are not $-1$. Also both cannot have type $(-1)^a 1^b$ with a 1 in a common coordinate. In particular it is impossible for all $\mathbf{c}_i$ to have type $(-1)^a 1^b$ since 11 is not a multiple of 3.
