The extended binary and ternary Golay codes of lengths 24 and 12, respectively, were each extended quadratic residue codes. The same result holds for the hexacode by Exercise 363. By Theorem 6.6.6 (see Example 6.6.8 and Exercise 363), one $[5, 3, 3]$ odd-like quadratic residue code over $\mathbb{F}_6$ has generating idempotent $e_S(x) = 1 + \omega x + \bar{\omega}x^2 + \bar{\omega}x^3 + \omega x^4$; the associated generator polynomial is $g_S(x) = 1 + \omega x + x^2$.

Extending this code we obtain the hexacode $\mathcal{G}_6$. Labeling the coordinates $0, 1, 2, 3, 4, \infty$, the permutation $s_6 = (0, 1, 2, 3, 4)$ is in $\Gamma \text{Aut}(\mathcal{G}_6)$. Furthermore, the map $\eta_6 = \text{diag}(1, \bar{\omega}, \omega, \omega, \bar{\omega}, 1) \times (0, \infty) \times \sigma_2$, where $\sigma_2$ is the Frobenius map interchanging $\omega$ and $\bar{\omega}$, is in $\Gamma \text{Aut}(\mathcal{G}_6)$.
