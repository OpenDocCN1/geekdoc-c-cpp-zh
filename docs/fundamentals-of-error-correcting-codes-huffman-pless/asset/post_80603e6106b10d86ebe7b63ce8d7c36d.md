Thus it suffices to show that for any pair of syndromes $S_1$ and $S_3$, there is a vector $\mathbf{y}$ with $\text{wt}(\mathbf{y}) \le 3$ that satisfies (11.9). Let $X_i$ be the location numbers of $\mathbf{y}$; see Section 5.4. $$S_1 = X_1 + X_2 + X_3, \quad S_3 = X_1^3 + X_2^3 + X_3^3. \quad (11.10)$$

$$0 = z_1 + z_2 + z_3, \quad s = z_1^3 + z_2^3 + z_3^3, \quad (11.11)$$

where $s = S_1^3 + S_3$. If $s = 0, z_1 = z_2 = z_3 = 0$ is a solution of (11.11). So assume that $s \neq 0$. Substituting $z_3 = z_1 + z_2$ from the first equation in (11.11) into the second equation gives

$$z_1^2 z_2 + z_1 z_2^2 = s.$$

We will find a solution with $z_2 \neq 0$, in which case if we set $z = z_1/z_2$ we must solve

## 11.4 Covering radius of self-dual codes

In Chapters 9 and 10 we examined some well-known binary self-dual codes of moderate lengths. In this section we want to compute the covering radius of some of these codes.

We begin by considering extremal Type II binary codes. In Example 1.11.7, we presented the weight distribution of each coset of the unique [8, 4, 4] Type II binary code and conclude that it has covering radius 2. This same result comes from Theorem 11.1.7. In a series of examples and exercises in Section 7.5, we gave the complete coset weight distribution of each of the two [16, 8, 4] Type II binary codes and concluded that the covering radius is 4 for each code. Exercise 641 gives another proof without resorting to specific knowledge of the generator matrix of the code.

We now turn to the [32, 16, 8] Type II binary codes. In Section 9.7 we noted that there are exactly five such codes. Without knowing the specific structure of any of these except the number of weight 8 vectors, we can find their covering radii, a result found in [9].

### Theorem 11.4.1
Let $C$ be a [32, 16, 8] Type II code. Then $\rho(C) = 6$.

Proof: We remark that the weight distribution of $C$ is determined uniquely; see Theorem 9.3.1. It turns out that $A_6(C) = 620, C = C^\perp$ contains codewords of weights 8, 12, 16, 20, 24, 32, and 32. So by the Delsarte Bound $\rho(C) \le 6$. By Theorems 11.1.1 and 11.1.7, $5 \le \rho(C)$ as $C$ is not extended perfect (Exercise 642). Suppose that $\rho(C) = 5$. This implies that every weight 6 vector in $\mathbb{F}_2^{32}$ is in a coset of even weight less than 6. The only coset of weight 0 is the code itself, which does not contain weight 6 codewords. Let $x$ be a vector of weight 6. Then there must be a codeword $c$ such that $\text{wt}(x + c) = 2$ or $4$. The only possibility is that $\text{wt}(c) = 8$. Thus every weight 6 vector has support intersecting the support one of the 620 codewords of weight 8 in $C$ in either five or six coordinates. The number of weight 6 vectors whose support intersects the support of a weight 8 vector in this manner is $\binom{8}{4}\binom{8}{2} + \binom{8}{5} = 1372$. Thus there are at most $620 \cdot 1372 = 850640$ weight 6 vectors in $\mathbb{F}_2^{32}$. But as there are $\binom{32}{6} = 906192$ weight 6 vectors in $\mathbb{F}_2^{32}$, we have a contradiction.
