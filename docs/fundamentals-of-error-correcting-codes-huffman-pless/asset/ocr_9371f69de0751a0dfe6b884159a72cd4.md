In Theorem 7.2.3 we will show that if C is a linear code of length n over F_q with weight distribution A_w for 0 <= w <= n, then A_{1/n}^+ = 1/|C| \sum_{w=0}^n A_w K_k^{n,q}(w) for 0 <= k <= n is the weight distribution of C^\perp. As C is linear A_w = B_w by Exercise 117. In particular for linear codes \sum_{w=0}^n B_w K_k^{n,q}(w) >= 0. The next lemma, which is the basis of the Linear Programming Bound, shows that this inequality holds where B_w is the distance distribution of a (possibly) nonlinear code.

# Lemma 2.6.3 Let B_w, 0 <= w <= n, be the distance distribution of a code over F_q. Then

```
\sum_{w=0}^n B_w K_k^{n,q}(w) \ge 0
```

for 0 <= k <= n.

Proof: By Theorem 2.6.1 we only need to verify these inequalities for an (n, M) code C over F_q. By definition of the distance distribution and Lemma 2.6.2,

```
M \sum_{w=0}^n B_w K_k^{n,q}(w) = \sum_{w=0}^n \sum_{x \in C, wt(x)=w} K_k^{n,q}(w) = \sum_{w=0}^n \sum_{x \in C, wt(x)=w} \sum_{y \in C, wt(y)=k} \xi^{(x-y) \cdot v}
= \sum_{(x,y) \in C^2} \sum_{v \in F_q^n, wt(v)=k} \xi^{x \cdot v} \xi^{-y \cdot v} = \sum_{v \in F_q^n, wt(v)=k} \sum_{x \in C} \xi^{x \cdot v} \sum_{y \in C} \xi^{-y \cdot v}
= \sum_{v \in F_q^n, wt(v)=k} \sum_{x \in C} \xi^{x \cdot v} \overline{\xi^{x \cdot v}} = \sum_{v \in F_q^n, wt(v)=k} \left| \sum_{x \in C} \xi^{x \cdot v} \right|^2 \ge 0,
```

proving the result.

If C is an (n, M, d) code over F_q with distance distribution B_w, 0 <= w <= n, then M = \sum_{w=0}^n B_w and B_0 = 1 by Exercise 117. Also B_1 = B_2 = ... = B_{d-1} = 0. By Lemma 2.6.3, we also have \sum_{w=0}^n w B_w >= 0 when k = 0 as K_0^{n,q}(w) = 1, which is clearly already true. If q = 2, again by Exercise 117, B_w <= 1, and furthermore if d is even, by Theorem 2.1.2, we may also assume that B_w = 0 when w is odd. By Exercise 116, when w is even, K_k^{n,q}(w) = K_{n-k}^{n,q}(w). Thus the kth inequality in (2.35) is the same as the (n - k)th as the only (possibly) nonzero B_w's are when w is even. This discussion yields our bound.
