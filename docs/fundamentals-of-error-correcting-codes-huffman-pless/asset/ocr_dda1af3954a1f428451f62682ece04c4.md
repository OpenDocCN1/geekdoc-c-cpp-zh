Assume first that w >= s. Thus A1(D), A2(D), ..., A_{l-1}(D) are known as they are A1(C), A2(C), ..., A_{l-1}(C). Also A_l(D^\perp) is known for i <= s. Note that none of these numbers depend on v, only that w >= s. By Theorem 7.3.1 the weight distribution of D and D^\perp is uniquely determined; thus this distribution is independent of the choice of v. But then the weight distribution of D \ C is uniquely determined, and so the coset leader, being the smallest weight of vectors in D \ C, has a uniquely determined weight. Since we know that there is some coset leader v with wt(v) = \rho(C) and that there are cosets of all smaller weights by Theorem 1.12.6(v), this uniquely determined weight must be \rho(C). Hence it is not possible for s to be smaller than \rho(C), proving (i). When wt(v) = s, the weight distribution of D \ C is uniquely determined and so, therefore, is the weight distribution of v + C by Lemma 7.5.1(ii), proving (ii). If w < s, Theorem 7.3.1 shows the weight distributions of D and D^\perp are known as long as A_1(D), A_2(D), ..., A_{l-1}(D) are known; but this is equivalent to knowing the number of vectors in v + C of weights 1, 2, ..., s - 1, yielding (iii).

Assume now that C is a binary code with only vectors of even weight. Let v be a coset leader of a coset of C with wt(v) = s - 1. Then D has only even weight vectors if s - 1 is even, in which case A_D(D^\perp) = 1; if s - 1 is odd, D has odd weight vectors and so A_D(D^\perp) = 0. Therefore A_i(D^\perp) is known except for values in S \\ {n}, a set of size s - 1 as A_n(C^\perp) = 1. Because A_i(D) = A_i(C) for 0 <= i <= s - 2, by Theorem 7.3.1, the weight distribution of D, and hence of D \ C = v + C, is uniquely determined.

Example 7.5.3 The complete coset weight distribution of the [8, 4, 4] extended binary Hamming code C = \tilde{H}_3 was given in Example 1.11.7. We redo this example in light of the previous theorem. This code is self-dual with A_0(C) = 1, A_4(C) = 14, and A_8(C) = 1. Thus in Theorem 7.5.2, S = {4, 8} and so s = 2. By parts (ii) and (iv) of this theorem, the distributions of the cosets of weights 1 and 2 are each uniquely determined, and by part (i) there are no other coset weights. Recall from Exercise 72 that odd weight cosets have only odd weight vectors and even weight cosets have only even weight vectors as C has only even weight vectors. In particular, all odd weight vectors in F_2^8 are in the cosets of weight 1. If there are two weight 1 vectors in a coset of weight 1, their difference is a weight two vector in the code, which is a contradiction. Hence there is precisely eight cosets of weight 1. If v + C has weight 1, then A(v + C) = (8/8) for i odd, which agrees with the results in Example 1.11.7. There are 2^4 - 9 = 7 remaining cosets; all must have weight 2. Thus if v + C has weight 2, then A_i(v + C) = ((8 choose i) - A_i(C))/7 for i even, again agreeing with the results in Example 1.11.7.
