By (7.19) and (7.20),

```
\begin{aligned}
b_{r+1} &= d_{r+1}(C) + \sum_{i=1}^{k-r-1} \left\lceil \frac{q-1}{q^i(q^{r+1}-1)} d_{i+1}(C) \right\rceil \\
&\ge \left\lceil \frac{q^{r+1}-1}{q^{r+1}-q} d_r(C) \right\rceil + \sum_{i=1}^{k-r-1} \left\lceil \frac{q-1}{q^{r+1}(q^i-1)} d_i(C) \right\rceil \\
&= \left\lceil d_r(C) + \frac{q-1}{q(q^r-1)} d_r(C) \right\rceil + \sum_{i=2}^{k-r} \left\lceil \frac{q-1}{q^i(q^i-1)} d_i(C) \right\rceil \\
&= d_r(C) + \sum_{i=1}^{k-r} \left\lceil \frac{q-1}{q^i(q^i-1)} d_i(C) \right\rceil = b_r.
\end{aligned}
```

Clearly, \( b_{r+1} = b_r \) if and only if equality holds in (7.19) and in (7.20) when \( 1 \le i \le k-r-1 \).

**Theorem 7.10.12** Let \(\mathcal{C}\) be an \([n, k, d]\) code over \(\mathbb{F}_q\) meeting the Griesmer Bound. Then: (i) \(\mathcal{C}\) meets the Generalized Griesmer Bound for all \(r\) with \(1 \le r \le k\), and (ii) \(d_r(\mathcal{C}) = \sum_{i=1}^{r-1} \lceil d/q^i \rceil\) for \(1 \le r \le k\).

**Proof:** By the Generalized Griesmer Bound \(n \ge b_k\); using Lemma 7.10.11,

\(n \ge b_k \ge b_{k-1} \ge \cdots \ge b_1\).

As \(\mathcal{C}\) meets the Griesmer Bound, \(b_1 = n\). Therefore \(b_r = n\) for \(1 \le r \le k\), giving (i).

Note that (ii) holds when \(r=1\), since \(d_1(\mathcal{C}) = d\). Assume \(1 < r \le k\). By Lemma 7.10.11,

```
\(\left\lceil \frac{q-1}{q^r(q^r-1)} d_r(\mathcal{C}) \right\rceil = \left\lceil \frac{q-1}{q^{r+1}(q^{r-1}-1)} d_{r-1}(\mathcal{C}) \right\rceil,\)
```

for \(1 < s < k\) and \(1 \le i \le k-s\). Applying this inductively for \(s=r, r-1, \dots, 2\), we have

```
\(\left\lceil \frac{q-1}{q^r(q^r-1)} d_r(\mathcal{C}) \right\rceil = \left\lceil \frac{q-1}{q^{r+1-r}(q-1)} d_1(\mathcal{C}) \right\rceil = \left\lceil \frac{d}{q^{r+1}} \right\rceil,\)
```

for \(1 \le i \le k-r\), as \(d(\mathcal{C}) = d\) by Theorem 7.10.1. Since \(b_r = n\), as \(\mathcal{C}\) meets the Griesmer Bound, we have

```
\(\sum_{i=1}^{k-r} \left\lceil \frac{d}{q^i} \right\rceil = n = d_r(\mathcal{C}) + \sum_{i=1}^{k-r} \left\lceil \frac{q-1}{q^i(q^i-1)} d_r(\mathcal{C}) \right\rceil = d_r(\mathcal{C}) + \sum_{i=1}^{k-r} \left\lceil \frac{d}{q^{i+r-1}} \right\rceil.\)
```

So

```
\(d_r(\mathcal{C}) = \sum_{i=0}^{k-1} \left\lceil \frac{d}{q^i} \right\rceil - \sum_{i=r}^{k-r} \left\lceil \frac{d}{q^{i+r-1}} \right\rceil = \sum_{i=0}^{r-1} \left\lceil \frac{d}{q^i} \right\rceil,\)
```

and thus (ii) holds.
