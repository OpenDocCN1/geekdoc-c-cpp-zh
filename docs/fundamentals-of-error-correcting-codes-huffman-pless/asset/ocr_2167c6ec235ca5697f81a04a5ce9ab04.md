where $\mathbb{F}_q^*$ denotes the nonzero elements of $\mathbb{F}_q$. We analyze each of the last two terms separately. First,

$$\sum_{i=1}^n n_{I,0} = (n-w)M$$

because the left-hand side counts the number of 0s in the matrix $\mathcal{M}$ and each of the $M$ rows of $\mathcal{M}$ has $n-w$ 0s. Second, by the Cauchy–Schwartz inequality,

$$\left(\sum_{i=1}^n n_{I,0}\right)^2 \le n \sum_{i=1}^n n_{I,0}^2.$$

Combining these we see that the first summation on the right-hand side of (2.8) satisfies

$$\sum_{i=1}^n \left(M n_{I,0} - n_{I,0}^2\right) \le (n-w)M^2 - \frac{1}{n} \left( \sum_{i=1}^n n_{I,0} \right)^2 = (n-w)M^2 - \frac{(n-w)^2 M^2}{n}.$$ (2.9)

A similar argument is used on the second summation of the right-hand side of (2.8). This time

$$\sum_{i=1}^n \sum_{a \in \mathbb{F}_q^*} n_{I,a} = wM$$

because the left-hand side counts the number of nonzero elements in the matrix $\mathcal{M}$ and each of the $M$ rows of $\mathcal{M}$ has $w$ nonzero components. By the Cauchy–Schwartz inequality,

$$\left(\sum_{i=1}^n \sum_{a \in \mathbb{F}_q^*} n_{I,a}\right)^2 \le (n(q-1)) \sum_{i=1}^n \sum_{a \in \mathbb{F}_q^*} n_{I,a}^2.$$

This yields

$$\sum_{i=1}^n \sum_{a \in \mathbb{F}_q^*} \left(M n_{I,a} - n_{I,a}^2\right) \le wM^2 - \frac{1}{n(q-1)} \left( \sum_{i=1}^n \sum_{a \in \mathbb{F}_q^*} n_{I,a} \right)^2 = wM^2 - \frac{1}{n(q-1)} (wM)^2.$$ (2.10)

Combining (2.7), (2.8), (2.9), and (2.10), we obtain:

$$M(M-1)d \le (n-w)M^2 - \frac{(n-w)^2 M^2}{n} + wM^2 - \frac{1}{n(q-1)} (wM)^2,$$

which simplifies to

$$(M-1)d \le M \left[ \frac{2(q-1)nw - qw^2}{n(q-1)} \right].$$
