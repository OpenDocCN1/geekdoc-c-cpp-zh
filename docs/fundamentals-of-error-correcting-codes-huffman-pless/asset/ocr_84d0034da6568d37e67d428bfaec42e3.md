# Exercise 265 Find a generator polynomial and generator matrix of a triple error-correcting [15, 5] binary cyclic code.

The BCH Bound asserts that you want to find the longest set of consecutive elements in the defining set. However, the defining set depends on the primitive element chosen. Let \(\beta = \alpha^a\), where \(\gcd(a, n) = 1\); so \(\beta\) is also a primitive \(n\)th root of unity. Therefore, if \(\alpha^{-1}\) is the alphabetic inverse of a modulo \(n\), the minimal polynomials \(M_{\beta^a}(x)\) and \(M_{\beta^{a-1}}(x)\) are equal. So the code with defining set \(T\), relative to the primitive element \(\alpha\), is the same as the code with defining set \(a^{-1}T \mod n\), relative to the primitive element \(\beta\). Thus when applying the BCH Bound, or any of our other lower bounds, a higher lower bound may be obtained if you apply a multiplier to the defining set. Alternately, the two codes \(\mathcal{C}\) and \(\mathcal{C}_{\mu_a}\) are equivalent and have defining sets \(T\) and \(a^{-1}T\) (by Corollary 4.4.5) with respect to the same primitive element \(\alpha\); hence they have the same minimum weight and so either defining set can be used to produce the best bound.

Example 4.5.4 Let \(\mathcal{C}\) be the [31, 25, d] binary cyclic code with defining set \(T = \{0, 3, 6, 12, 24, 17\}\). Applying the BCH Bound to \(\mathcal{C}\), we see that \(d \ge 2\), as the longest consecutive set in \(T\) is size 1. However, multiplying \(T\) by \(3^{-1} \equiv 21 \pmod{31}\), we have \(3^{-1}T \mod 31 = \{0, 1, 2, 4, 8, 16\}\). Replacing \(\alpha\) by \(\alpha^3\) or \(\mathcal{C}\) by \(\mathcal{C}_{\mu_3}\) and applying the BCH Bound, we obtain \(d \ge 4\). In fact \(\mathcal{C}\) is the even weight subcode of the Hamming code \(\mathcal{H}_5\) and \(d = 4\).
