## `ComboBox` 控件

## `TreeView` 控件

WPF 中的 `TreeView` 控件用于以层次方式显示项目。此控件使用 `TreeViewItem` 控件列出项目。因此，`TreeView` 控件由 `TreeViewItem` 控件的层次结构组成。你可以通过将 `IsExpanded` 属性分别设置为 `True` 或 `False` 来展开或折叠 `TreeViewItem` 控件。当用户选择 `TreeViewItem` 控件时，会发生 `Selected` 事件，并且 `IsSelected` 属性设置为 `True`。当用户取消选择 `TreeViewItem` 控件时，会发生 `UnSelected` 事件，并且 `IsSelected` 属性设置为 `False`。你不能显式设置 `SelectedItem` 属性，因为它是一个只读属性。你可以使用 `SelectedValue` 和 `SelectedPathValue` 属性为 `SelectedItem` 属性分配值。`TreeView` 控件的默认视图将控件放置在 `StackPanel` 容器控件内并向其添加 `ScrollViewer` 控件。

```
            System.Windows.Controls.Control

                System.Windows.Controls.TreeView
```

## `HeaderedItems` 控件

`HeaderedItems` 控件用于显示主、父级控件或对象以及其子控件。`HeaderedItems` 控件托管标题子元素和可能或可能不是集合的内容。`Header` 属性标记控件的项目，而 `ItemsCollection` 属性包含项目。`Header` 属性指定整个控件的标签以及控件的各个子元素。`HeaderedItems` 控件继承自 `ItemsControl` 类。有三个 WPF 控件可以归为 `HeaderedItems` 控件：`MenuItem`、`ToolBar` 和 `TreeViewItem`。

表 10.39 列出了这些控件的简要描述：

### 表 10.39：Headered Items 控件

| Control | Description |
|---|---|
| `MenuItem` | Represents a selectable item inside a `Menu` control |
| `ToolBar` | Provides a container for a group of commands or controls |
| `TreeViewItem` | Implements a selectable item in a `TreeView` control |

## `TreeViewItem` 控件

`TreeViewItem` 控件有助于通过使用可折叠节点以层次结构显示信息。`TreeViewItem` 控件的内容属性为 `Items` 和 `ItemsSource`。标题属性为 `Header`。你可以使用 `IsExpanded` 属性展开或折叠 `TreeViewItem`。
