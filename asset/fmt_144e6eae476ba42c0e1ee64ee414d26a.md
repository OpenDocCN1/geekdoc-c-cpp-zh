
然而，被调用的 `printf()` 已经编译并位于 `MSVCRT.DLL` 中（如果是 Windows 的话），它没有任何关于传递了多少参数的信息，但它可以从格式字符串中确定参数。

因此，如果 `printf()` 是一个 `stdcall` 函数并通过计算格式字符串中的参数数量来将栈指针返回到初始状态，这可能会导致危险的情况，即一个程序员的操作可能会引发程序突然崩溃。因此，此类函数不适合使用 `stdcall`，`cdecl` 更好。

### 6.1.3 fastcall

这是通过寄存器传递某些参数而其余参数通过栈传递方法的通用名称。在较旧的 CPU 上，它比 `cdecl`/`stdcall` 快（因为栈压力较小）。然而，在最新的（复杂得多的）CPU 上，它可能无法获得显著的性能提升。

它没有标准化，不同的编译器可能有不同的实现方式。一个为人知的警告：如果你有两个 DLL，且它们由不同的编译器以不同的 `fastcall` 调用约定构建，可能会出现问题。

MSVC 和 GCC 都通过 `ECX` 和 `EDX` 传递前两个参数，其余通过栈传递。

栈指针必须由被调用者恢复到初始状态。

列表 6.4: fastcall

```assembly
push arg3
mov edx, arg2
mov ecx, arg1
call function

function:
  do something ..
ret 4
```

```c

{

}
```

### 6.1.4 thiscall

Watcom/OpenWatcom 称为“寄存器调用约定”。前四个参数通过 `EAX`、`EDX`、`EBX` 和 `ECX` 传递。其余通过栈传递。这些函数在名称后带有下划线，以区别于不同的调用约定。在 MSVC 中，这通常通过 `ECX` 寄存器传递。在 GCC 中，作为第一个参数传递。因此，与源代码相比，汇编代码有一个额外的参数。

### 6.1.5 x86-64

Win64 传递参数的方法类似于 `fastcall`。前四个参数通过 `RCX`、`RDX`、`R8` 和 `R9` 传递，其余通过栈传递。调用者还可以准备 32 字节或 64 位的值，以便被调用者可以保存前四个参数。短函数可能使用寄存器参数，但较大的参数可能保存值。调用者还可以将栈指针返回到初始状态。这种调用约定也用于 Windows x86-64 DLL（代替了 win32 中的 `stdcall`）。

示例：

```c
{

}

int main {
    f1(1,2,3,4,5,6,7);
}
```

## 6.1.6 float 和 double 类型的返回值

在除 Win64 之外的所有约定中，`float` 或 `double` 的值都通过 FPU 寄存器 `ST(0)` 返回。

在 Win64 中，`float` 和 `double` 类型的值在 `XMM0` 寄存器的低 32 或 64 位中返回。

## 6.2 线程本地存储 (Thread Local Storage)

TLS 是每个线程特定的数据。每个线程都可以在那里存储它需要的内容。一个著名的例子是 C 标准全局变量 `errno`。

多个线程可能同时调用返回 `errno` 错误码的函数，因此全局变量对于多线程程序无法正常工作，`errno` 必须存储在 TLS 中。

在 C++11 标准中，增加了一个新的 `thread_local` 修饰符，表明每个线程都有该变量自己的版本，它可以被初始化，并且位于 TLS 中：

列表 6.14: C++11

```cpp
#include <iostream>
#include <thread>

thread_local int tmp=3;

int main()
{
    std::cout << tmp << std::endl;
}
```

在 MinGW GCC 4.8.1 中可以编译，但在 MSVC 2012 中不行。

如果我们谈论 PE 文件（即生成的执行文件），`tmp` 变量将被分配在专门用于 TLS 的节中。

### 6.2.1 重温线性同余生成器

我们之前在第 424 页 1.29 中考虑的伪随机生成器有一个缺陷：它不是线程安全的，因为它有一个内部状态变量，该变量可以在不同的线程中同时被读取和/或写入。

## Win32

未初始化 TLS

一种解决方案是给全局变量添加 `__declspec(thread)` 修饰符，它将被分配在 TLS 中（第 9 行）：

```c

3 #include <winnt.h>

// 来自《Numerical Recipes》一书：

#define RNG_c 1013904223

    rand_state=init;
}
int my_rand () {
    rand_state=rand_state*RNG_a;
    rand_state=rand_state+RNG_c;
    return rand_state & 0x7fff;
}

int main() {
    my_srand(0x12345678);
    printf("%d\n", my_rand());
}
```
