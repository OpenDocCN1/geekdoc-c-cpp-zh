## 3.4 C 的历史

C 是由 Dennis Ritchie 于 1970 年在贝尔实验室开发的。它的许多原则和思想都源自早期的语言 B，而 B 的先驱 BCPL 和 CPL 开发的目的是创建一种能够进行高级、机器无关编程的语言，同时允许程序员控制单个位信息的行为。CPL 的一个主要缺点是它对于许多应用来说太庞大了。1972 年，Ken Thompson 的同事 Dennis Ritchie 在开发语言的过程中，将 BCPL 中的某些通用性返回了 B 语言。起初，C 在很长一段时间内都在贝尔实验室使用，直到 1978 年由 Brian Kernigh 和 Ritchie 对该语言进行了确切描述。Kernigh 和 Ritchie 的描述通常被称为“K & R”。由于 C 的重要特性，计算机专业人员对其留深刻印象并开始推广这种语言。C 的强大和自由变得显而易见。由于此，用汇编语言编写的 Unix 操作系统几乎立即重写为 C。由于 C 与 Unix 的联系以及 C 编译器的可用，C 传播到了许多学院和大学。许多不同的组织开始使用自己的 C 版本，导致了兼容性问题。为了应对这个问题，1983 年，美国国家标准协会成立了一个小组委员会来建立 C 的标准定义，这被称为 ANSI 标准 C。今天，C 被广泛使用，并拥有丰富的标准库函数。

## 4.5 变量 [4月18日]

变量是一个标识符，用于表示程序指定部分的某些特定信息。变量用于存储程序中的特定数据项。换句话说，它是存储值的数据名称。在程序执行的任何时刻，一个变量只能赋予一个值。它的值在程序执行过程中可能会改变。变量是一个标识符。所有变量在使用之前必须先声明。

声明的一般形式为：

```
type variable_list;
```

在这里，`type` 必须是有效的数据类型加上修符，`variable_list` 可以由一个或多个用逗号分隔的标识符名称组成。

语法：

```
type variable_list;
```

### 4.5.1.1 局部变量

在函数内部声明的变量称为局部变量。局部变量只能在声明它的变量块内部的语句中使用。局部变量不能在块外部使用。局部变量的生命周期持续到块的结束，即局部变量在进入块时创建，在退出块时销毁。我们可以在两个不同的块中声明相同的变量名。然而，我们在同一个块内不能有相同的变量名。
