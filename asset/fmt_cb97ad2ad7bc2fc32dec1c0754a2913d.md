现在假设我们想修改程序，将温度 98.6 插入表格的正确位置。也就是说，我们希望表格每隔 10 度增加一次，但我们也希望表格中额外包含一行针对 98.6 华氏度的数据，因为这是人体正常体温。以下程序实现了这一目标：

```c
#include <stdio.h>

int main(void)
{
    float a = 0;
    while (a <= 100)
    {
        if (a > 98.6)
        {
          printf("%6.2f degrees F = %6.2f degrees C\n",
              98.6, (98.6 - 32.0) * 5.0 / 9.0);
          printf("%6.2f degrees F = %6.2f degrees C\n",
              a, (a - 32.0) * 5.0 / 9.0);
          a = a + 10;
        }
    }
    return 0;
}
```

这个程序在结束值为 100 时可以工作，但如果你将结束值更改为 200，你会发现程序有一个 bug。它重复打印了多次 98.6 度的那行。我们可以通过不同的方法修复这个问题。这里是其中一种：

```c
#include <stdio.h>

int main(void) {
  float a, b;
  a = 0;
  b = -1;
  while (a <= 100) {
    if ((a > 98.6) && (b < 98.6)) {
      printf("%6.2f degrees F = %6.2f degrees C\n",
          98.6, (98.6 - 32.0) * 5.0 / 9.0);
    }
    printf("%6.2f degrees F = %6.2f degrees C\n",
        a, (a - 32.0) * 5.0 / 9.0);
    a = a + 10;
  }
  return 0;
}
```

## 数组

在本节中，我们将创建一个小的 C 程序，生成 10 个随机数并对其排序。为了实现这一点，我们将使用一种新变量数组。

数组允许你声明并处理一组相同类型的值。例如，你可能想要创建一个整数集合。一种方法直接声明五个整数：

```c
int a, b, c, d, e;
```

这样也可以，但如果你需要千个整数呢？更简单的方法是声明一个数组：

```c
int a[5];
```

数组内部的整数通过索引访问。在 C 中，所有数组都从 0 开始到 n-1。因此，`int a[5]` 包含五个元素。例如：

```c
int a[5];
a[0] = 12;
a[1] = 9;
a[2] = 14;
a[3] = 5;
a[4] = 1;
```

数组索引的好处之一是你可以使用循环操作索引。例如，以下代码将数组中的所有值初始化为 0：

```c
int a[5];
int i;
for (i = 0; i < 5; i++)
{
    a[i] = 0;
}
```

你在普通声明后插入大小来声明数组，如下：

```c
int a[10];          /* 整数数组 */
char s[100];         /* 字符数组 */
float f[20];         /* 浮点数数组 */
struct rec[50];      /* 结构体数组 */
```

- 在第一段代码中，将填充数组的循环改为单行。确保结果与原始代码相同。
- 将冒泡排序提取并放入自己的函数中。将冒泡排序使用的变量也移动到该函数中，并设为局部。因为数组是全局的，你不需要传递参数。
- 将随机数种子初始化为不同的值。

以下 `<stdio.h>` 代码顺序初始化数组中的值并打印它们：

```c
#include <stdio.h>
int main(void)
{
    int a[5];
    int i;

    for (i = 0; i < 5; i++)
    {
        a[i] = i;
    }
    for (i = 0; i < 5; i++)
    {
        printf("%d = %d\n", i, a[i]);
    }
}
```

## 变量类型

C 语言中有三种标准的变量类型：

- 整数：`int`
- 浮点数：`float`
- 字符：`char`

`int` 是一个 4 字节的整数值。`float` 是一个 4 字节的浮点值。`char` 是一个 1 字节的单个字符（如“a”或“3”）。字符串被声明为字符数组。

有许多派生类型：

- `double`（8 字节浮点值）
- `short`（2 字节整数）
- `unsigned short` 或 `unsigned int`（正整数，无符号位）

## 类型转换

C 语言允许你随时进行类型转换。当你使用指针时，经常会这样做。在某些类型的赋值操作期间，也会发生类型转换。例如，在上面的代码中，整数值被自动转换为浮点数。

在 C 语言中进行类型转换的方法是将类型名放在括号中，并放在你想要更改的值前面。因此，在上面的代码中，将 `a = 10/3;` 替换为 `a = (float)10/3;` 会产生结果 3.33333，因为 10 在除法之前被转换为浮点值。

你使用 `typedef` 语句在 C 语言中声明命名的、自定义类型。以下示例显示了 C 代码中经常出现的类型：

```c
#define TRUE 1
#define FALSE 0
typedef int boolean;

int main(void){
    boolean b;

    b = FALSE;
    blah blah blah
}
```

这段代码允许你在 C 程序中声明布尔类型。

如果你不喜欢用 "float" 一词表示实数，可以这样说：

```c
typedef float real;
```

然后稍后说：

```c
real r1,r2,r3;
```

你可以将 `typedef` 语句放在 C 程序的任何地方，只要它们在代码中第一次使用之前即可。

## 运算符

C 语言中的运算符与大多数语言中的运算符相似：

- `+` 加法
- `-` 减法
- `/` 除法
- `*` 乘法
- `%` 取模

如果两个操作数都是整数，则 `/` 运算符执行整数除法；否则，它执行浮点数除法。例如：

```c
int main(void)
{
    float a;
    a = 10/3;
    printf("%f\n",a);
    return 0;
}
```

这段代码会打印一个浮点值，因为 `a` 被声明为 `float` 类型，但由于代码执行的是整数除法，`a` 将是 3.0。

C 语言中的运算符优先级与大多数其他语言相似。除法和乘法先发生，然后是加法和减法。计算 `5+3*4` 的结果是 17 而不是 32，因为在 C 语言中 `*` 运算符的优先级高于 `+`。你可以使用括号来改变正常的优先级顺序：`(5+3)*4` 是 32。`5+3` 先求值，因为它在括号中。我们稍后会讨论优先级——一旦引入指针，C 语言中的优先级就会变得有些复杂。

| 长写法 | 短写法 |
| --- | --- |
| `i = i + 1;` | `i++;` |
| `i = i - 1;` | `i--;` |
| `i = i + 3;` | `i += 3;` |
| `i = i * j;` | `i *= j;` |

## 函数

许多语言允许你创建某种函数。函数允许你将一个长程序切分成命名的部分，以便这些部分可以在整个程序中重复使用。函数接受参数并返回结果。通常情况下，C 语言不在乎你将函数放在程序中的顺序，只要在调用之前编译器已知函数名即可。我们已经讨论过函数了。之前看到的函数已经是函数尽可能简单的了。它不接受任何参数并返回一个整数：

```c
int rand(void)
/*
 * K&R - 产生一个 0 到 32767 之间的随机数。
 */
rand_seed = rand_seed + 11031245;
return (unsigned int)(rand_seed / 65536) % 32768;
```

`rand()` 这一行向程序的其余部分声明了该函数，并指定 `rand` 不接受任何参数。它没有局部变量，但如果需要，它们将位于左大括号 `{` 正下方；它们一直存在直到程序到达匹配的 `}`，然后消失。

```c
int main(void)
{
    float a;
    a = 10/3;
    printf("%f\n",a);
    return 0;
}
```

这段代码会打印一个浮点值，因为 `a` 被声明为 `float` 类型，但由于代码执行的是整数除法，`a` 将是 3.0。

函数可以使用 `void` 返回类型，如果你打算返回任何内容。例如：

```c
void print_header ()
{
    printf("Program Number 1\n");
    printf("by Marshall\n");
    printf(" Version 1.0, released 12/26/91\n");
}
```

该函数不返回值。你可以使用以下语句调用它：

```c
print_header();
```

调用必须包含 `()`。如果不包含，函数将被调用，尽管它在很多系统上可以编译。C 函数可以接受任何类型的参数。例如：

```c
int fact(int i)
{
    int j, k;

    j = 1;
    for (k = 2; k <= i; k++) {
        j = j*k;
    }
    return j;
}
```

返回 `i` 的阶乘，它是作为整数参数传递的。多个参数用逗号分隔：

```c
int add (int i, j)
{
    return i + j;
}
```

C 语言随着时间的演变。你有时会看到像 `add` 这样的函数以“旧样式”编写，如下：

```c
int add(i, j)
int i;
int j;
{
    return i + j;
}
```

能够阅读旧样式编写的代码很重要。它们在执行方式上没有区别，只是表示法不同。你应该使用“新样式”（称为 ANSI C），将类型在参数列表中声明，除非你确定要将代码发送给只能访问“旧样式”（非 ANSI）编译器的人。在后续情况下，你可能永远想这样调用 `rand`：

```c
if (rand () > 100)
```

或者使用这种方式：

```c
rand ();
```
