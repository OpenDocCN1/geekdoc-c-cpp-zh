R mob.fac[2]

这些改进远不止是外观上的。例如，某些类别中零观测的数据集与从开始就定义为更少类别的相同数据集之间存在很大差异。是否指示R正式对因子进行排序的选择，也可能在回归和其他类型的建模等各种统计方法实现中产生重要后果。

### 4.3.3 合并与切割

正如你所见，通常使用`c`函数很容易合并同种类的多个向量（无论是数值、逻辑还是字符）。这里有一个例子：

```
R foo <- c(5.1,3.3,3.1,4)
R bar <- c(4.5,1.2)
R c <- c(foo,bar)
[1] 5.1 3.3 4.0 4.5 1.2
```

这与因子值向量以相同的方式合并。然而，`c`函数并不适用。让我们看看当你对表4-4中的数据和第4.3.2节中的`MOB`因子`mob.fac`使用它时会发生什么。假设你现在观察到另外三个个体，其`MOB`值为“Oct”、“Feb”和“Feb”，存储为因子对象，如下所示。

```
R new_values <- factor(c("Oct"
```
```
[1] Oct Feb Feb
Levels: Jan < Feb < Mar < Apr < May < Jun < Jul < Aug < Sep < Oct < Nov < Dec
```

现在你有`mob.fac`中的原始观察值和`new.values`中的另外三个。两者都是因子对象，以相同的有序水准定义。你可能会期望你可以直接使用`c`将两者合并如下。

```
R> c(mob.fac,new.values)
[1] 4 1 12 9 11 7 7 10 2 2
```

显然，这没有达到你想要的效果。合并两个因子对象导致了一个数值向量。这是因为该函数将因子解释为整数。将此与定义的水准进行比较，你可以看到这些数字指的是每个月份在有序水准内的索引。

```
R> levels(mob.fac)
[1] "Jan" "Feb" "Mar" "Apr" "May" "Jun" "Jul" "Aug" "Sep" "Oct" "Nov" "Dec"
```

这意味着你可以使用这些整数与`levels`来检索完整观察数据的字符向量——原始的八个加上另外三个。

```
R> levels(mob.fac)[c(mob.fac,new.values)]
[1] "Apr" "Dec" "Sep" "Nov" "Jul" "Jun" "Oct" "Feb" "Feb"
```

现在你已将所有观察值存储在向量中，但它们当前存储为字符串，而不是值。最后一步是将此向量转换为因子对象。

```
R> mob.new <- levels(mob.fac)[c(mob.fac,new.values)]
R> mob.new.fac <- factor(x=mob.new,levels=levels(mob.fac),ordered=TRUE)
R> mob.new.fac
[1] Jan < Feb < Mar < Apr < May < Jun < Jul < Aug < Sep < Oct < Nov < Dec
```

正如这个例子所示，因子化需要两个对象来分解每个条目相对于因子水准的数值位置，然后再将它们重新组合在一起。这确保了水准的一致性以及最终产品中的观察值有效性。

因子也从最初在连续体上测量的数据创建，例如一组成人的体重或给予患者的药物剂量。有时你需要将这些类型的观察值分组（或分箱）到类别中，如Small/Medium/Large或Low/High。在R中，你可以使用`cut`函数将这种数据映射到离散因子类别。考虑以下10个的数值向量：

```
R> Y <- c(0.53,5.4,1.5,3.3,33.0,0.45,0.1,2.4,1.9,1.0)
```

假设你想按如下方式对数据进行分箱：Small指区间[0,2)中的观察值，Medium指[2,4)，Large指[4,6]。方括号指的是*包含*其最近的值，而括号表示*排除*，因此一个观察值$y$将落在Small区间如果$0 \le y < 2$，落在Medium如果$2 \le y < 4$，或落在Large如果$4 \le y \le 6$。为此你使用`cut`并向`breaks`参数提供你期望的断点：

```
R br <- c(0,2,4,6)
R cut(x=Y,breaks=br)
[0,2] [4,6] [2,4] [0,2] [0,2] [2,4] [4,6] [0,2]
Levels: (0,2] (2,4] (4,6)
```

这给了你一个因子，每个观察值现在被分配一个区间。然而，请注意你的边界区间是倒置的——你希望边界水准在左侧像[0,2]，而不是像默认出现的那样在右侧，(0,2]。你可以通过将逻辑参数设为FALSE来修复它。

```
R cut(x=Y,breaks=br,right=F)
[0,2] [4,6] [2,4] [0,2] [0,2] [2,4] [4,6] [0,2]
Levels: (0,2] (2,4] (4,6]
```

现在你已交换了包含和排除的边界。这很重要，因为它改变了哪些类别会落入其中。请注意，第七个观察值已更改类别。但仍有一个问题：最终区间*排除*了6，而你希望此最大值*包含*在最高等级中。你可以用另一个逻辑参数来修复它：`include.lowest`。即使它被称为“include.lowest”，此参数也可以用于在`right`为FALSE时包含*最高*值，如帮助文件`?cut`中所述。

```
R cut(x=Y,breaks=br,right=F,include.lowest=T)
[0,2] [4,6] [2,4] [0,2] [0,2] [2,4] [4,6] [0,2]
Levels: (0,2] (2,4] (4,6]
```

区间现在定义为你想要的方式。最后，你希望为类别添加更好的标签，而不是使用R默认提供的水准，将字符字符串向量传递给`labels`参数。标签的顺序必须与因子对象中水准的顺序相匹配。

```
R lab <- c("Small","Medium","Large")
R cut(x=Y,breaks=br,right=F,include.lowest=T,labels=lab)
[1] Small Large Small Medium Small Small Large Small Small
Levels: Small Medium Large
```

## 列表和数据框

![](img/b2cfc85cbb129f60fe595a2bae074fe4_122_0.png)

向量、矩阵和数组是R中高效便捷的数据存储结构，但它们有一个明显的局限性：在本章中，你将探索另外两种数据结构，列表和数据框，它们可以同时存储多种类型的值。

### 5.1 对象的列表

列表是一个非常有用的数据结构。它可用于将任何混合的R结构和对象组合在一起。单个列表可能包含一个数值矩阵、一个逻辑数组、一个单一字符字符串和一个因子对象。你甚至可以在另一个列表中包含一个列表作为组件。在本节中，你将了解如何创建、修改和访问这些灵活结构的组件。

### 5.1.1 定义和组件访问

创建列表的方式与创建向量类似。你将想要包含的元素提供给`list()`函数，以逗号分隔。

```
R> foo <- list(matrix(data=1:4,ncol=2),c(T,F,T,T),"hello")
R> foo
[[1]]
 [,1] [,2]
[1,] 1 3
[2,] 2 4
[[2]]
[1] TRUE FALSE TRUE TRUE
[[3]]
[1] "hello"
```

在列表`foo`中，你存储了一个2 x 2数值矩阵、一个逻辑向量和一个字符字符串。这些是按提供给`list`的顺序打印的。就像向量一样，你可以使用`length`函数来检查列表中的组件数量。

```
R> length(x=foo)
[1] 3
```

你可以使用索引从列表中检索组件，索引输入在双方括号中。

```
R> foo[[1]]
 [,1] [,2]
[1,] 1 3
[2,] 2 4
R> foo[[3]]
[1] "hello"
```

这种操作称为成员引用。当你以这种方式检索组件时，你可以像工作区中的独立对象一样处理它；不需要做任何特殊操作。

```
R> foo[[1]] + 5.5
 [,1] [,2]
[1,] 6.5 8.5
[2,] 7.5 9.5
R> foo[[1]][1,2]
[1] 3
R> foo[[1]][2]
[1] 2 4
R> cat(foo[[3]]),"you!"
hello!
```

要覆盖`foo`的成员，你使用赋值运算符。

```
R> foo[[3]]
[1] "hello"
R> foo[[3]] <- paste(foo[[3]],"you!")
R> foo
[[1]]
    [,1] [,2]
    [1,] 1 3
    [2,] 2 4
[[2]]
[1] TRUE FALSE TRUE TRUE
[[3]]
[1] "hello you!"
```

现在假设你想要访问`foo`的第二个和第三个组件并将它们存储为一个对象。你第一反应可能是尝试这样做：

```
R> foo[[c(2,3)]]
[1] TRUE
```

但R并没有按你想要的方式执行。相反，它返回了第二个组件的第三个元素。这是因为在列表上使用双方括号总是相对于单个成员进行解释的。幸运的是，使用双方括号进行内存引用并不是访问列表组件的唯一方法。你还可以使用单方括号表示法。这称为列表切片，它允许你一次选择多个列表项。

```
R> bar <- foo[c(2,3)]
R> bar
[[1]]
[1] TRUE FALSE TRUE TRUE
[[2]]
[1] "hello you!"
```

请注意，结果`bar`本身就是一个列表，其中包含按请求顺序存储的两个组件。

### 5.1.2 命名

你可以为列表组件命名，使元素更易识别和操作。就像你在第4.3.1节中看到的关于因子水平存储的信息一样，名称是一个R属性。

让我们开始为之前的列表`foo`添加名称。

```
R> names(foo) <- c("mymatrix","mylogicals","mystring")
R> foo
$mymatrix
      [,1] [,2]
[1,]     1    3
[2,]     2    4
$mylogicals
[1] FALSE TRUE TRUE
$mystring
[1] "hello you!"
```

这改变了对象在控制台上的打印方式。以前在每个组件前打印[[1]]、[[2]]和[[3]]，现在它打印你指定的名称：`$mymatrix`、`$mylogicals`和`$mystring`。你现在可以使用这些名称和美元运算符进行引用，而不是方括号。

```
R> foo$mymatrix
      [,1] [,2]
[1,]     1    3
[2,]     2    4
```

这与调用`foo[[1]]`相同。事实上，即使对象已命名，你仍然可以使用数字索引来获取成员。

```
R> foo[[1]]
      [,1] [,2]
[1,]     1    3
[2,]     2    4
```

子集成员的方式也相同。

```
R> all(foo$mymatrix[[2]]==foo[[1]][,2])
[1] TRUE
```

这确认了（使用你在第4.1.2节中使用的`all`函数）这两种提取`foo`中矩阵第二列的方法提供了相同的结果。

要在创建列表时命名组件，请在`list`命令中为每个组件分配标签。使用`some` to create a new name.

```
R> baz <- list(tom=c(foo[[2]],T,T,T,F),dick="g'day mate",harry=foo$mymatrix*2)
R> baz
$tom
```
[1] TRUE FALSE TRUE TRUE TRUE FALSE
```
$dick
[1] "g'day mate"
```
