# 两个真理和一个谎言

# 写入和读取顺序访问文件

- 1. 尽管人们认为数据文件是由包含字段的记录组成的，但 C# 仅将文件视为字节流。
- 2. 逗号是 C# 的默认分隔符。
- 3. `Split()` 方法可以根据指定分隔符的位置，将数据字段分离到字符串数组中。

出于此目的，C# 没有默认的分隔符，任何字符都可以作为文本文件中字符之间的边界。虽然逗号被广泛使用。

错误的陈述是 #2。分隔符是任何用于指定文本文件中字符之间边界的字符。
