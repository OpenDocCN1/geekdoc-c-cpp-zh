
- `System.Runtime.Serialization`——包含可用于序列化和反序列化对象的类。序列化是将对象或对象图转换为线性字节序列以进行存储或传输到其他位置的过程。反序列化是获取存储信息并从中重新创建对象的过程。
- `System.Threading`——包含支持多线程编程的类和接口。
- `System.Web`——包含支持浏览器/服务器通信的类和接口。此命名空间包括一些类，例如提供有关 HTTP 请求信息的 `HttpRequest` 类；管理对客户端浏览器的 HTTP 输出的 `HttpResponse` 类；以及提供对服务器端实用程序和进程访问的 `HttpServerUtility` 类。

- `System.Web.Services`——包含允许你构建和使用 Web 服务的类，Web 服务是 Web 服务器上可编程的实体，代码可以使用标准 Internet 协议与之通信。
- `System.Windows.Forms`——包含用于创建基于 Windows 的窗体的类，这些窗体利用用户界面控件和 Windows 操作系统中可用的其他功能。

### 方法作为类成员

现在你已经熟悉了使用类的重要性，让我们继续讨论类的成员——类方法和类变量。类成员是在类中声明的元素。下面的代码片段显示了声明类成员（方法和变量）的语法：

```
class Square
{
    int side;
    public int area()
    {
        return ( side * side);
    }
}
```

在前面的代码片段中，`Square` 类有一个名为 `side` 的变量和一个名为 `area` 的方法。`side` 变量为正方形的边长取整数值；而 `area` 方法用于计算正方形的面积。

构造函数和析构函数是每个类中都存在的特殊方法。每当你访问类时，构造函数方法会初始化所有类成员，而当不再需要对象时，析构函数方法会销毁它们。每个类都有自己构造函数和析构函数，它们在类的实例被创建或销毁时自动调用。

**注释**

类变量也称为数据成员，类方法也称为成员函数或方法。

你可以使用参数将值传递给方法。传递参数的语法如下面的代码片段所示：

```
[modifiers] DataType ParameterName
```

C# 2010 具有以下类型的形参：

- 值参数——允许方法通过方法调用中给出的参数为值参数赋值。这种赋值仅影响局部存储位置。它对方法调用中分配的实际参数没有影响。此外，对参数所做的更改是方法局部的；它们不会传递给调用方法。值参数是默认参数。如果你在声明参数时没有任何修饰符，则它被视为值参数。值参数也称为内参数。
- 引用参数——表示相同的存储位置，而不是为方法调用中作为参数给出的变量创建新的存储位置。用 `ref` 修饰符声明的参数是引用参数。
- 输出参数——表示相同的存储位置，而不是为方法调用中作为参数给出的变量创建新的存储位置。用 `out` 修饰符声明的参数是输出参数。方法的每个输出参数都必须在方法返回输出之前赋值。输出参数通常用于产生多个返回值的方法。

在定义和调用方法时使用 `out` 修饰符，如下面的代码片段所示：

```
class UsingOut
{
    static void FirstMethod(out int x) // out modifier in method definition
    {
        x = 81;
    }
    static void Main()
    {
        int y; // No prior initialization
        FirstMethod(out y); // out modifier in method calling
        // value of y is 81
    }
}
```

在前面的代码片段中，在方法定义（`static void FirstMethod(out int x)`）和方法调用（`FirstMethod(out y)`）中都指定了 `out` 修饰符。

在方法定义和方法调用中使用 `ref` 修饰符，如下面的代码片段所示：

```
class UsingRef
{
    static void SecondMethod(ref int x) // ref modifier in method definition
    {
        x++;
    }
    static void Main()
    {
        int y = 81;        // must be initialized
        SecondMethod(ref y);    // ref modifier in method calling
```

```
Console.WriteLine("value of y is " + y);
}
```

在前面的代码片段中，你需要初始化变量的值，但输出参数在传递之前不需要事先初始化。然而，你必须在方法返回之前为输出参数分配某个值。输出参数在方法返回多个值时是首选的。C++ 不返回多个值；你只能通过一些编程技巧来实现这一点；然而，C# 的 `out` 修饰符允许多个返回值。

- 参数数组 – 允许程序员向方法的成员传递任意数量的参数。参数数组是参数的数组，并使用 `params` 修饰符声明。参数数组可以是单维或多维数组。如果传递单个数组，则该参数作为普通值参数起作用。如果参数列表包含参数数组，则它必须是单维数组类型，并且应是列表中的最后一个参数。换句话说，它位于参数列表的末尾。不可能将 `params` 修饰符与 `ref` 和 `out` 修饰符组合使用。

## 访问修饰符

访问修饰符有助于避免数据和方法与现有代码的混乱，并保护类的对象免受外部干扰。这些修饰符通过为数据和方法定义一定的访问范围以受限的方式进行访问来实现这一点。你可以用访问修饰符声明一个类及其每个方法。然而，每个方法只能包含一个修饰符。如果你在任何其他类之外声明一个类，则该类可以使用以下两个修饰符：

- `public` 修饰符
- `internal` 修饰符

另一方面，嵌套类可以使用以下五个修饰符：

- `public` 修饰符 – 允许在类内部和外部无限制地公开访问成员。
- `internal` 修饰符 – 允许内部访问成员。仅当前程序集可以访问这些成员。如果在定义它的程序集之外访问 `internal` 可访问级别的成员，则会生成错误。
- `protected` 修饰符 – 允许受保护地访问成员。你可以从声明它们的类或从声明它们的类的派生类访问 `protected` 成员。
- `private` 修饰符 – 允许私有地访问成员。私有成员具有最低的访问权限级别；你只能在类的主体中或声明它们的结构中访问它们。
- `protected internal` 修饰符 – 允许访问当前程序集、包含类以及从包含类派生的类的成员。

在某些情况下，程序员需要确保某些值在应用程序生命周期内保持不变。例如，对于计算任何化学公式，元素的原子值应保持不变。C# 有两种类型的字段 – 常量和只读 – 来解决这种情况。常量和只读字段有一些相似之处，但在某些方面是不同的。

常量与可在编译时访问的类相关联。这意味着你定义为常量的变量的值是在编译时计算的。常量的值一旦声明就不能更改。你可以使用 `const` 关键字声明变量为常量。

以下代码片段显示了常量的使用：

```
struct Atomicweight
{

    public const double Silver = 107.8;
}
```

如前所述，常量通常在编译时声明；然而，如果你想在运行时使变量保持不变，可以指定 `readonly` 关键字，如以下代码片段所示：

```
class MyClass
{
    public readonly int Number1=10;
    public readonly int Number2=20;
}
```

在前面的代码片段中，`Number1` 和 `Number2` 变量的值分别在只读模式下设置为 `10` 和 `20`。

只读字段也与类或类的实例相关联。它们的值可以在类声明期间设置。你可以使用 `readonly` 关键字声明变量为只读。在你希望字段对同一类的不同对象具有不同的值，但要求字段的值在特定对象的整个生命周期内保持不变的情况下，优先使用只读变量而不是常量。

## 构造函数和析构函数

如果你曾在 C++ 或 Java 中工作过，你就熟悉构造函数和析构函数的概念。构造函数在对象首次创建时被调用。析构函数（或终结器）在对象最终被销毁并被垃圾回收时被调用。构造函数的名称与类名相同；而析构函数的名称由类名前加波浪号 `~` 组成。你可以使用构造函数初始化对象并设置任何参数。此外，你可以编写构造函数以接受参数。以下代码片段显示了名为 `Foo` 的类的构造函数和析构函数的示例：

```csharp
class Foo {
    string a,b;
    int c;
    Foo(string s) {
        a = s;
    }
    Foo(int I, string s) {
        b = s;
        c = I;
    }
    ~Foo() {}
}
```

如果构造函数用于将现有对象作为新对象创建副本，则该构造函数称为拷贝构造函数。此构造函数将要复制的对象的引用作为参数。C# 默认不提供拷贝构造函数。要创建具有与源对象相同的属性和成员值的对象的相同副本，你需要编写单独的方法或拷贝构造函数，如以下代码片段所示：

```csharp
class CarDetails
{
    // Data Members
    public CarDetails(CarDetails MyCar) // Copy constructor.
    {
        //Constructor Body
    }
    public CarDetails(string ModelName, double Mileage) // Instance constructor.
    {
        //Constructor Body
    }
}
```

在前面的代码片段中，调用了 `carDetails` 构造函数。创建了一个新的 `car1` 对象，然后创建了另一个新的对象 `car2`，它复制了 `car1` 对象。

### 静态类和静态类成员

静态类及其成员不需要任何对象来调用它们；相反，你可以使用类名直接访问类的数据和成员函数。静态类及其成员使你能够在不创建类的实例的情况下访问类的数据和成员函数。静态成员不需要实例化。如果你声明在类中的数据或方法不依赖于对象的行为，你可以使用静态类。C# 使用 `static` 关键字将类及其成员定义为静态。

```csharp
static class employee
{
    public static int id;
}
```

```
public static int tele_no;
```

在前面的代码片段中，`employee` 是静态类，而 `id` 和 `tele_no` 是其成员。静态类表示其成员也是静态的。您不能使用 `new` 关键字实例化静态类。.NET Framework 的 CLR 会在包含静态类的程序或命名空间被加载时自动加载静态类。

静态类不包含实例构造函数，这些构造函数用于创建和初始化实例。静态类是密封的，这意味着您不能继承这些类。您可以使用 `static` 关键字声明静态类成员，如以下代码片段所示：

```
public static class student
{
    public static int roll_no = 4;
    public static int rank;
}
```

前面的代码片段展示了一个 `student` 类，它不是静态的。然而，该类的成员 `roll_no` 和 `rank` 是静态的。这些静态类成员在首次被访问之前或在静态构造函数被调用之前初始化。

表 5.1 列出了静态成员和非静态成员之间的一些差异：

Table 5.1: Difference Between Static and Non-Static Members

| Parameter for Difference | Static Members | Non-Static Members |
|---|---|---|
| Belongs | Belongs to a class. This means that a static member can be called by a class and by the object of the class. | Belongs to an object of a class. This means that a non-static member can be called only by the object of the class. |
| Accessibility | Accesses only other static members of a class. | Accesses both static and non-static members of a class. |
| Instantiation | Creates only one copy of a static variable and its value remains the same even when the class is instantiated. | Creates a copy of the variables for their objects, every time the class is instantiated. |
