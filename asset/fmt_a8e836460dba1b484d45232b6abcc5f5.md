using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading.Tasks;
namespace CD_Account_Test
{
    class SavingsAccount
    {
        // 字段
        private string _accountNumber;
        private decimal _interestRate;
        private decimal _balance;
        // 构造函数
        public SavingsAccount()
        {
            _accountNumber = "";
            _interestRate = 0;
            _balance = 0;
        }
        // AccountNumber 属性
        public string AccountNumber
        {
            get { return _accountNumber; }
            set { _accountNumber = value; }
        }
        // InterestRate 属性
        public decimal InterestRate
        {
            get { return _interestRate; }
            set { _interestRate = value; }
        }
        // Balance 属性
        public decimal Balance
        {
            get { return _balance; }
            set { _balance = value; }
        }
    }
}

## 10.1 继承

### 基类与派生类构造函数

当你创建一个派生类的实例时，首先会执行基类的构造函数，然后执行派生类的构造函数。在目前为止我们讨论的所有示例中，基类和派生类都有无参数构造函数。当你创建一个派生类的实例时，基类的无参数构造函数会自动执行。

但如果基类的构造函数带有参数，会怎样？或者，如果基类有多个重载的构造函数，而你想确保调用特定的某一个会怎样？在所有这些情况下，派生类的构造函数必须显式地调用基类的构造函数。

例如，查看下面的 `Rectangle` 类：

```csharp
class Rectangle
{
    // 字段
    private int length;
    private int width;
    // 构造函数
    public Rectangle()
    {
        length = 0;
        width = 0;
    }
    // 参数化构造函数
    public Rectangle(int length, int width)
    {
        length = length;
        width = width;
    }
    // Length 属性
    public int Length
    {
        get { return length; }
        set { length = value; }
    }
    // Width 属性
    public int Width
    {
        get { return width; }
        set { width = value; }
    }
}
// 派生类
class Square : Rectangle
{
    // 字段
    private int side;
    // 构造函数
    public Square() : base()
    {
        side = 0;
    }
    // 参数化构造函数
    public Square(int side) : base(side, side)
    {
        side = side;
    }
    // Side 属性
    public int Side
    {
        get { return side; }
        set { side = value; }
    }
}
```
