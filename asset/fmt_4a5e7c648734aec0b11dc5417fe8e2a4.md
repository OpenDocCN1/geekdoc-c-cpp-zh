## switch 语句

`switch` 语句根据表达式的值执行一个语句块或单个语句。它具有如下形式。

```c
switch (expression)
{
    case value1:
        --------
        <语句块 1>
        --------
        break;
    case value2:
        --------
        <语句块 2>
        --------
        break;
    default:
        --------
        <默认块>
        --------;
}
```

其中 `<expression>` 是一个与常量值比较的表达式。如果匹配，则执行相应的 `case` 块。如果没有找到匹配项，则执行默认块。

### 示例

```c
switch (day)
{
    case 1:
        printf("Monday");
        break;
    case 2:
        printf("Tuesday");
        break;
    default:
        printf("Invalid day");
}
```

`break` 语句用于跳出 `switch` 语句，防止执行后续 `case`。如果省略 `break`，程序将执行匹配 `case` 之后的所有 `case`。

### 示例

```c
#include <stdio.h>
#include <conio.h>
main()
{
    int day;
    clrscr();
    printf("输入星期 (1-7): ");
    scanf("%d", &day);
    switch(day)
    {
        case 1:
            printf("Monday");
            break;
        case 2:
            printf("Tuesday");
            break;
        case 3:
            printf("Wednesday");
            break;
        case 4:
            printf("Thursday");
            break;
        case 5:
            printf("Friday");
            break;
        case 6:
            printf("Saturday");
            break;
        case 7:
            printf("Sunday");
            break;
        default:
            printf("Invalid day");
    }
    getch();
}
```

当针对单个变量需要检查多个条件时，`switch` 语句比多个 `if-else` 语句更具可读性。

# 解决方案

二次方程通过以下表达式得到根：

```
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2}
```

注意 `b² - 4ac` 是判别式。

`b² - 4ac = 0` 时，根为实数且相等的，即 `x = \frac{-b}{2}`。

`b² - 4ac < 0` 时，根为虚数，即 `x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2}`。
