# 模板 (Formats)

模板将描述页面呈现或外观的 HTML 代码与负责处理业务活动信息的 PHP 代码分离开。一旦分离，对于学习过 HTML 或可能学习 CSS 的人来说，修改布局而无需担心地破坏 PHP 代码，这就会变得更加简单。此外，PHP 代码可以专注于信息本身，而不是参与展示的细微元素。

使用模板有许多不同的关注点。例如，如果你在模板中犯了错误，错误将清晰地从模板中返回。模板本身大部分可以导入到 Web 程序或图形化 Web 开发工具中（例如 Dreamweaver），因为它们在处理后看起来就像页面的最终状态。模板支持用于展示的关重要的编程元素，例如，具有判断页面某个区域是否应该可见的能力。

显然，没有什么是完美的；模板也有两三个缺点。模板增加了需要维护的文件数量。它们会包含少量的额外处理时间。它们还强制引入模板引擎并设置注册表。你至少需要运行 PHP 4.0.6 版本才能使用 Smarty，这是一个著名的模板引擎。

### 应用层级索引 (Application level indexes)
