## 2.34

考虑以下程序。

**示例 2.26** 编写一个程序用行优先方法实现数组。

```c
#include <stdio.h>
#include <conio.h>
void main() {
    int j,k,x[3][3];
    clrscr();
    printf("\n 输入九个元素: ");
    for (j=0;j<=2;j++)
        for (k=0;k<=2;k++)
            scanf("%d", &x[j][k]);
    printf("\n 行优先数组\n");
    for (j=0;j<=2;j++) {
        for (k=0;k<=2;k++)
            printf(" %d", x[j][k]);
        printf("行- [ %d ]\n", j+1);
    }
}
```

输出

输入九个元素：7 8 9 4 5 2 1 5 9

行优先数组

7 8 9 行- [ 1 ]

4 5 2 行- [ 2 ]

1 5 9 行- [ 3 ]

# 解析：

此程序使用了两个 `for` 循环。元素通过键盘输入。外层循环表示行，内层循环表示列。完成内层循环的执行后，执行外层循环。当填充完一行后，外层循环执行指向下一待填充的行。再次使用内层循环填充元素。因此，元素是逐行存储的。
