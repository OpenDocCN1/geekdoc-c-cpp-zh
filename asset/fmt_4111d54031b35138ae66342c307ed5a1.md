
```csharp
public class Vehicle
{
    public string model;        // 模型名称
    public string manufacturer; // 制造商名称
    public int numOfDoors;      // 车辆的门数量
    public int numOfWheels;     // 你懂意思的。
}
```

类的定义以 `public class` 单词开始，后面紧跟类名——在本例中，是 `Vehicle`。

和 C# 中所有的名称一样，类名是区分大小大小的。C# 不强制执行任何关于类名的规则，但有一条非正式的规则：类名以大写字母开头。

类名后面是一对大括号。在大括号内部，你有零或多个成员。类的成员是构成类部分的变量。在这个示例中，`class Vehicle` 类从成员 `string model` 开始，它包含了车辆的模型名称。如果这辆车是一辆汽车，它的模型名称可以是 `Trooper II`。这个 `Vehicle` 类示例的第二个成员是 `string manufacturer`。

另外两个属性是车辆的门数和轮子数。

就像任何变量一样，成员名称应尽可能具有描述性。虽然我给数据成员添加了注释，但并不是必要的。一个好的变量名就能说明一切。

类名前的 `public` 修饰符使得该类在整个程序中都是可访问的。同样，成员名前的 `public` 修饰符使它们对程序中的所有内容都可见。其他的修饰符也是可能的。

类定义应该描述对当前问题重要的对象属性。现在做起来有点困难，因为你还不知道问题是什么，但你可以看出我的意图。

## 什么是对象？

定义一个 `Vehicle` 设计与制造一辆汽车并不是同一个任务。在任何人驾驶真正的车辆之前，必须有人先切割金属并拧动螺丝。类对象的声明方式类似于声明内置类型为 `int` 的内置对象的方式。

“对象”一词泛指“东西”。实例变量是一个 `int` 对象。一辆车是一个 `Vehicle` 对象。你是一个读者。我是一个作者对象。

下面的代码段创建了一个 `Vehicle` 类的汽车：

```csharp
Vehicle myCar;
myCar = new Vehicle();
```

第一行声明了一个 `Vehicle` 类的变量，第二行创建了一个 `Vehicle` 实例，就像你可以声明一个类型为 `int` 的 `int` 一样。`new` 运算符创建一个新的内存块，你可以在其中存储 `myCar` 的属性。`new` 并不占用内存，因为 CPU 和 C# 编译器已经知道 1 是什么了。你的 CPU 并没有 `Vehicle` 的概念。`new` 表达式将描述车辆所需的内存分配给 CPU、给 C#、给世界，是的，分配给宇宙！

在 C# 中，你说 `myCar` 是 `Vehicle` 的一个实例。在这个语境下，实例意味着“……的一个例子”或“之一”。你可以将实例一词作为动词，即实例化 `Vehicle`。

## 访问对象的成员

将 `myCar` 的声明与名为 `num` 的 `int` 变量进行比较：

```csharp
int num;
num = 1;
```

第一行声明变量 `num`，第二行将一个已经创建的 `int` 类型常量赋值到 `num` 的位置。

内置的 `num` 和对象 `myCar` 的存储方式不同。常量 `1` 并不占用内存，因为 CPU 和 C# 编译器已经知道 1 是什么。

每个 `Vehicle` 对象都有自己的一组成员。下面的表达式将数字 1 存储在由 `myCar` 引用对象的 `numberOfDoors` 成员中：

```csharp
myCar.numberOfDoors = 1;
```

每一个 C# 操作都必须根据类型以及根据值进行求值。对象 `myCar` 是 `Vehicle` 类型的对象。`Vehicle.numberOfDoors` 是 `int` 类型。常量 `5` 也是 `int` 类型，因此赋值运算符右侧变量的类型与左侧变量的类型匹配。

同样，下面的代码存储了描述 `myCar` 模型和制造商的字符串引用：

```csharp
myCar.manufacturer = "BMW";
myCar.model = "Isetta";
```

Isetta 是 20 世纪 50 年代的一种小汽车，有一扇可以打开整个车头的门。

## 区分对象

底罗特的汽车制造商可以跟踪他们制造的每一辆汽车而不会产生混淆。同样，程序可以创建同一类的多个对象，如例所示：

```csharp
Vehicle car1 = new Vehicle();
car1.manufacturer = "Studebaker";
car1.model = "Avanti";

// 以下内容对 car1 没有影响。
Vehicle car2 = new Vehicle();
car2.manufacturer = "Hudson";
car2.model = "Hornet";
```

创建对象 `car2` 并为其分配制造商名称 `Hudson` 对 `car1` 对象没有影响。

在某种程度上，区分对象的能力是类构造真正的威力。与 `Hudson Hornet` 关联的对象可以作为一个独立的实体被创建、处理和丢弃，与其他对象隔离开。

## 你能给我引用吗？

点运算符和赋值运算符是引用类型中定义的两个运算符：

```c
// Create a null reference.
// VehicleCar;
// Assign the reference value.
yourCar = new Vehicle();
// Use dot to access a member.
yourCar.manufacturer = "Rambler";
// Create a new reference and point it to the same object.
yourSpousalCar = yourCar;
```

第一行连接了对象 `yourCar` 但没有给它赋值。任何未初始化的变量都被认为指向空对象。任何尝试使用未初始化引用的行为都会立即产生错误并终止程序。

C# 编译器可以捕获大多数对未初始化引用的尝试并在编译时生成警告。如果你以某种方式绕过了编译器，访问未初始化的引用将立即终止程序。

第二条语句创建了一个新的 `Vehicle` 对象并将其赋值给 `yourCar`。代码段中的最后一条将引用 `yourSpousalCar` 赋值给引用 `yourCar`。此操作导致 `yourSpousalCar` 指向与 `yourCar` 相同的对象。

这两个调用具有相同的效果：

```csharp
// Build your car.
VehicleCar = new Vehicle();
yourCar.model = "Kaiser";
// 它也属于你的配偶。
yourSpousalCar = yourCar;
// 修改一个就会改变另一个。
yourSpousalCar.model = "Henry J";
Console.WriteLine("Your car is a " + yourCar.model);
```

执行此程序将输出 `Henry J` 而不是 `Kaiser`。注意 `yourSpousalCar` 并不指向 `yourCar`；相反，`yourCar` 和 `yourSpousalCar` 都指向同一汽车。

此外，即使变量 `yourCar` 以某种方式“丢失”，引用 `yourSpousalCar` 仍然有效，如这段代码块所示：

```csharp
// Build your car.
Vehicle yourCar = new Vehicle();
yourCar.model = "Kaiser";
// 它也属于你的配偶。
Vehicle yourSpousalCar = yourCar;
// 当你的配偶拿走你的车时 . . .
yourCar = null;
// . . .yourSpousalCar 仍然引用
```

## 类的静态成员

类的大多数数据成员都属于其包含的对象，而不是任何其他对象。考虑 `Car` 类：

```csharp
public class Car {
    public string licensePlate; // 车牌 ID
}
```

因为车牌 ID 是对象的属性，它唯一地描述了 `Car` 类的每个对象。例如，我的车牌和你的不同；否则，你可能无法从车道里出来，就像这段代码所示：

```csharp
Car myCar = new Car();
myCar.licensePlate = "XYZ123";
Car yourCar = new Car();
yourCar.licensePlate = "ABC789";
```

然而，某些属性是所有类共享的。例如，制造的汽车数量是 `Car` 类的属性，而不是任何单个对象的属性。这些类属性通过带有 `static` 关键字进行标记：

```csharp
public class Car {
    public static int numberOfCars; // 制造的汽车数量
    public string licensePlate; // 车牌 ID
}
```

静态成员不是通过对象访问的，而是通过类本身访问的，此代码段所示：

```csharp
// 创建 Car 类的一个新对象。
Car newCar = new Car();
newCar.licensePlate = "ABC123";
// 增加汽车计数以反映新的汽车。
Car.numberOfCars++;
```

对象成员 `newCar.licensePlate` 通过对象 `newCar` 访问，而类静态成员 `Car.numberOfCars` 则通过类 `Car` 访问。所有的 `Car` 对象都共享同一个 `numberOfCars` 成员。

类成员是静态成员。非静态成员是每个实例特有的，被称为实例成员。

## 定义 const 和 readonly 数据成员

静态成员的一种特殊类型是 `const` 数据成员，它代表一个常量。你必须在声明中建立 `const` 变量的值，并且在程序的任何地方都不能更改，如下：

```csharp
class Program
{
    // 一年的天数
    public const int daysInYear = 366;
    public static void Main(string[] args)
    {
        int[] maxTemperatures = new int[daysInYear];
        for(int index = 0; index < daysInYear; index++)
        {
            // 累积每年每一天的最高温度
        }
    }
}
```

你可以在程序的任何地方使用常量 `daysInYear` 代替值 `366`。`const` 变量非常有用，因为可以用描述性名称 `daysInYear` 替换神秘数字。

C# 提供了另一种声明常量的方法——你可以在变量声明前加上 `readonly` 修饰符，如下：

```csharp
public readonly int daysInYear = 366;
```
