# 递归

函数不断调用自身来计算一个值称为递归函数或递归。通常，函数由主程序或其他函数调用，但在递归中，同一个函数被自身反复调用。考虑以下示例，通过递归找到整数的阶乘。

```c
int fact(int k)
{
    if (k == 0)
        return(1);
    else
        return(k * fact(k - 1));
}
```

return(4 * fact (4-1));

调用函数且 k = 3

在来自该函数的第二次调用后。
