# 设计器

设计器是 Visual Studio 中的区域，在此区域中设计 Windows 应用程序、Web 应用程序或 Windows 演示应用程序。设计器可用于在设计视图中定义组件和控件的行为或外观。Visual Studio 中的一些设计器如下：

- Windows 窗体设计器

- WPF 设计器

- Web 窗体设计器

让我们详细探讨每一个。

## Windows 窗体设计器

当您在 Visual Studio 中创建 Windows 窗体应用程序时，会自动向项目中添加一个窗体。此窗体元素被视为任何 Windows 窗体应用程序的最基本单元，用于从用户接受输入并根据指定的输入执行某些操作。

## WPF 设计器

WPF 是用于开发具有图形丰富用户体验的 Windows 客户端应用程序的演示系统。使用 WPF，您可以创建广泛的独立应用程序和浏览器托管应用程序。

设计器窗口允许您对应用程序的 XAML 文件进行更改。换句话说，在设计器窗口中进行的更改会自动反映在 XAML 文件中。

WPF 设计器窗口提供以下功能：

- Zoom Control – 控制设计表面的大小。您可以从 10% 缩放到 20%。

- Fit In View – 指定设计视图中可用屏幕的设计表面大小。

- Grid Rails – 管理 Grid 控件中的行和列。此功能允许您创建和删除列和行，以及调整它们的相对宽度和高度。

- Gridlines – 通过使用网格线控制 Grid 的列和行的高度和宽度。

- Move Handle – 有助于将控件拖动到设计器上的所需位置。

- Resize Handles – 通过单击并拖动调整大小手柄来调整所选控件的大小。

- Margin Lines – 指定控件边缘与其容器边缘之间的空间。您可以通过单击其边距线来设置控件的边距。

- Margin Stubs – 通过单击边距标记，将所选控件的边距距离设置为容器的相应边缘。

- Snaplines – 有助于控件的相对对齐。

## Server Explorer

特定服务器上提供各种服务。这些服务包括事件日志、消息队列、Crystal 报表服务、性能计数器、其他系统服务以及数据库服务，例如 SQL Server。Server Explorer 允许您查看特定服务器上可用的服务。此窗口是一个功能强大的工具，可帮助您在易于使用的图形环境中处理数据库。您可以将服务从窗口拖到设计表面，以便在应用程序中以编程方式与此元素交互。现在假设您将数据库表拖放到表单上。在这种情况下，.NET 会自动创建访问该表所需的连接和命令对象。您还可以将性能计数器拖到 Windows 窗体上，并使用该组件递增或递减该计数器。

Server Explorer 可以通过以下任一方式打开：

- 通过从主菜单中选择 View→Server Explorer

- 通过按 Ctrl+Alt+S 键

图 1.68：显示 Server Explorer

在 Server Explorer 中，您可以查看并从您连接的所有数据库中检索信息。例如，您可以在此窗口中查看有关所有数据库表、视图、存储过程和函数的信息。Server Explorer 提供对许多资源的访问。使用 Server Explorer，您可以查看和操作任何连接到网络的服务器上的数据链接、数据库连接和系统资源。您可以在 Server Explorer 中执行的一些任务包括打开数据连接和命令、登录服务器并显示其数据库和系统服务、查看有关可用 Web 服务的信息、创建到 SQL Server 和其他数据库的数据连接、存储数据库项目和引用，以及通过在 Visual Studio 项目中创建数据组件来与数据资源交互。

节点可以定义为一组用于在应用程序中执行特定功能的各种子节点。Server Explorer 中有三个主要节点，描述如下：

- Data Connections — 指定顶级节点，列出用户添加到服务器的数据连接。您可以创建不同数据库的数据连接，包括在 UNIX 或 Microsoft Windows 操作系统上运行的 Oracle 数据库。

- Servers — 指定顶级节点，其中包含当前连接服务器的列表。您可以通过将节点从 Servers 节点拖到 Visual Studio Designer 来创建新组件。Servers 节点中可用的各种子节点类型描述如下：

  - Crystal Reports Services — 列出可用的 Crystal Reporting 选项

  - Event Logs — 列出 Microsoft Windows 2003 服务器、Microsoft Windows 2000 服务器或 Windows NT 版本 4.0 上的可用事件日志

  - Management Classes – 使开发人员能够浏览和修改 Windows Management Instrumentation (WMI) 数据并调用方法

  - Management Events – 使开发人员能够注册 WMI 事件
