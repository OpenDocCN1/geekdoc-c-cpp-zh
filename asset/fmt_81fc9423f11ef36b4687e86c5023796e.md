在浮点型变量上进行此类这种 `++` 操作是合法的，并且具有预期的结果。你可能偶尔会在代码中看到这种写法，但它非常罕见，且不建议这样做，因为这不符合浮点变量的惯用写法（没有相应的机器指令来利用这种操作）。自增/自减操作最适合用于整型变量，例如计数器，正如本节中所有其他示例所示。

## 16. 文件流

如今计算机显示器的使用被展示得如此频繁，以至于人们很容易忘记，在这些设备出现之前，还存在过其他设备。早期计算系统的输出包括打孔卡、磁带以及经典的“电打字机/打印机”。这些设备的共同点是它们接收（或发送）数据流，每次处理一个字符。在 C 语言中，标准输入/输出和磁盘文件都是“流设备”的示例。

```c
stdout /* 主要输出 */
stderr /* 错误消息流 */
stdin /* 从中接收输入的流，例如电打字机键盘 */
```

注意 `printf` 和 `fprintf` 可以使用相同的格式化选项。

在类 Unix 系统中，`stdout` 和 `stdin` 具有进一步的流相关意义，即一个程序的 `stdout` 可以管道到另一个程序的 `stdin`。在经典 UNIX（包括 GNU/Linux 和 OS X）中发现许多晦奥程序在设计时就考虑了这种管道技术——它们从 `stdin` 读取并写入 `stdout`，只有在通过 UNIX 重定向命令显式指令时才会写入磁盘文件。

此示例使用 UNIX 命令将详细的目录列表重定向到文件：`ls > directory.txt`。

UNIX 管道符号 `|` 将一个进程的输出连接到下一个进程的输入：`ls | grep > filenames.txt`。这将包含 `"sine"` 的所有文件名写入 `filenames.txt`。

## 17. 添加断点意味着什么？

想一下。添加值元素似乎是显而易见的，但时间呢？编译器并不知道变量代表什么。`struct` 可以包含任何 C 类型，包括指针。在许多情况下，可能对于大多数人类程序员来说，在结构体上定义一个有意义的算术运算是不可能的，因此编译器无法做到这一点也不令人意外。

## 18. 结构体命名

我们取得了一些进展。我们可以为结构体命名：

```c
struct mysstruct {
int var1;
int var2;
};

/* 我们现在可以声明一个 mysstruct 类型的变量 */
```

或者我们可以使用“匿名结构体”来声明变量：

```c
struct{
  int var1;
  int var2;
} mystructvar /* mystructvar 是一个变量： */

mystructvar.var1 = 440;
```

或者我们可以像文中所示使用 `typedef`。

## 19. 宏与括号

注意 `NULL` 定义中使用了外层括号。这样做是为了避免通过 C 语言优先级规则可能产生的任何误解。以下是一个需要此类括号的简单示例：

```c
#define SQUARE(n) n * n
```

这是一个微型宏，它将任何符号 `n` 的文本实例替换为给定的替换文本。其思想是对任何类型的数字进行平方，宏可以这样使用：

这些 `x` 和 `z` 的初始化将产生预期的值：`w` 中的 `25` 和 `y` 中的 `100.0`。此处使用大写字母是为了显示这是一个宏而不是函数。但假设这个无辜的程序员使用了表达式而不是单个变量：

```c
w = SQUARE(x+1);
```

在替换“宏展开”之后，该表达式就会变成：

```c
w = x + 1 * x + 1
```

由于 C 语言优先级要求先执行乘法，结果应该是：

```c
w = (x+1)*(x+1)
```

为了解决这个问题，宏应该使用括号：

```c
#define SQUARE(n) ((n) * (n))
```

这样，在替换“宏展开”之后，该表达式就会变成：

```c
w = ((x+1) * ((x+1)));
```

注意，在 `SQUARE` 的定义中使用外层括号：

```c
#define SQUARE(n) ((n) * (n))
```

这可以确保 `n` 替换后的表达式被作为一个整体处理。

## 21. 堆内存

为了允许程序在运行时动态分配内存，C 语言提供了 `malloc()` 函数。它接受一个参数，表示分配的字节数，并返回指向所分配内存的指针。如果分配失败，它返回 `NULL`。
