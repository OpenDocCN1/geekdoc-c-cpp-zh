## ReactDOM

在你继续学习 `App` 组件之前，你可能想先看看它在哪里被使用。它位于你进入 React 世界的入口点：`src/index.js` 文件。

```javascript
src/index.js
import React from 'react';
import ReactDOM from 'react-dom';
import App from './App';
import './index.css';
```

```javascript
ReactDOM.render(
  <App />,
  document.getElementById('root')
);
```

`ReactDOM.render()` 使用你 HTML 中的一个 DOM 节点将其替换为你的 JSX。这就是你如何轻松将 React 集成到每个应用程序中。并不是在应用程序中多次调用 `ReactDOM.render()`。你可以在多个地方使用它来引导 JSX 语法、单个 React 组件、多个 React 组件或整个应用程序。但在纯 React 应用程序中，你只需要使用一次来引导你的整个组件树。

`ReactDOM.render()` 接收两个参数。第一个参数是待渲染的 JSX。第二个参数指定 React 应用程序挂载到你的 HTML 的位置。它期望一个 `id='root'` 的元素。你可以打开 `public/index.html` 文件来找到 `id` 属性。

在实现中，`ReactDOM.render()` 已经接收了你的 `App` 组件。不过，只要是 JSX，传递更简单的 JSX 也是可以的。它不必是一个组件的实例化。

## 热模块替换 (Hot Module Replacement)

你可以在 `src/index.js` 文件中做一件事来提升你作为开发体验。但它是可选的，在刚学习 React 时不应该让你感到无所措。

在 `create-react-app` 中，当你更改源代码时，浏览器会自动刷新页面，这是一个优势。尝试更改 `src/App.js` 文件中的 `helloWorld` 变量。浏览器应该会刷新页面。但有一种更好的方法。

热模块替换 (HMR) 是一种在浏览器中重新加载应用程序的工具。浏览器不会执行页面刷新。在 `create-react-app` 中，在你的 `src/index.js`（进入 React 的入口点）中，你需要添加一个小小的配置。

`src/index.js`

```javascript
import React from 'react';
import ReactDOM from 'react-dom';
import App from './App';
import './index.css';

ReactDOM.render(
  <App />,
  document.getElementById('root')
);

if (module.hot) {
  module.hot.accept();
}
```

就是这样。再次更改 `src/App.js` 文件中的 `helloWorld` 变量。浏览器不应该执行页面刷新，但应用程序会重新加载并显示正确的输出。HMR 有许多优势：

想象你正在使用 `console.log()` 语句进行调试。即使你更改了代码，这些语句也会保留在你的开发者控制台中，因为浏览器不再刷新页面。这对于调试目的非常方便。

在一个不断增长的应用程序中，页面刷新会降低你的效率。你需要等待页面加载。页面重新加载可能需要几秒钟。

## ES6 箭头函数

JavaScript ES6 引入了箭头函数。箭头函数表达式比函数表达式短。

代码演练场 (Code Playground)

```
// function expression
function () { ... }

// arrow function expression
() => { ... }
```

但你必须意识到它的功能。其中之一与 `this` 对象的行为不同。函数表达式总是定义它自己的对象。箭头函数表达式仍然具有闭包上下文的这个 `this` 对象。在箭头函数中使用 `this` 时不要感到困惑。

关于箭头函数，还有一个关于括号的价值事实。当函数只有一个参数时，你可以移除括号，但当有多个参数时，必须保留它们。

代码演练场 (Code Playground)

```
// allowed
item => { ... }

// allowed
(item) => { ... }

// not allowed
item, key => { ... }

// allowed
(item, key) => { ... }
```

然而，让我们来看 `map` 函数。你可以使用 ES6 箭头函数将其写得更简洁。

      <span>{item.num_comments}</span>
      <span>{item.points}</span>

})}
```（注：根据原句注释，已更正了原句中多余的右括号）

此外，你可以移除 ES6 箭头函数的块级体（即大括号）。在简洁的主体中，会附带一个隐式返回。你可以移除 `return` 语句。这在书中会经常出现，所以请务必理解箭头函数中使用块级体和简洁主体的区别。

你的 JSX 现在看起来更简洁、更易读了。它省略了函数语句、大括号和 `return` 语句。相反，开发者可以专注于实现细节。

## ES6 类 (Classes)

JavaScript ES6 引入了类（classes）。类在面向对象的编程语言中非常常用。JavaScript 在编程范式上过去和现在都灵活。你可以根据特定的用例并行进行函数式编程和面向对象编程。

尽管 React 拥抱函数式编程（例如使用不可变数据结构），但类仍被用于声明组件。它们是 ES6 类组件。React 混合了两种编程范式的優处。

让我们考虑以下 `Developer` 类，在不考虑组件的情况下检查一个 JavaScript ES6 类。

## 代码演练场 (Code Playground)

class Developer {
  constructor(firstname, lastname) {
    this.firstname = firstname;
    this.lastname = lastname;
  }

  getName() {
    return this.firstname + ' ' + this.lastname;
  }
}
```

`Developer` 类只是类的声明。你可以通过调用它来创建类的多个实例。它类似于 ES6 类组件，有一个声明，但你必须在其他地方使用它来实例化。
