## Understanding Stack Walk

有时可以在堆栈遍历期间要求并拒绝或断言权限。让我们创建一个应用程序和一个类库，两者都将尝试访问本地系统上的文件，并且将使用不同的强名称进行强命名，以便可以在策略中单独分配权限。

首先，通过执行以下步骤创建一个名为 `FileAccessLib`（在随附光盘上）的类库：

1. 打开 Visual Studio 2010 IDE，选择“文件”→“新建”→“项目”，打开“新建项目”对话框。在对话框中，在“项目类型”窗格中选择“Visual C#”选项，在“模板”窗格中选择“类库”选项。将项目名称指定为 `FileAccessLib`，选择适当的位置，并单击“确定”按钮。此时将创建 `FileAccessLib` 库。

2. 打开 `Class1.cs` 文件，并添加清单 36.28 中给出的代码：

### 清单 36.28：`FileAccessLib` 应用程序的 `Class1.cs` 文件代码

```
using System;
using System.Collections.Generic;
using System.Text;
using System.IO;
using System.Security.Permissions;

namespace FileAccessLib
{
public class Class1
{
public bool AccessFile(ref string FileText)
{
try
{
System.IO.FileStream fs = new
System.IO.FileStream("C:\\file.txt",
FileMode.OpenOrCreate, FileAccess.Write);
StreamWriter w = new StreamWriter(fs);
w.BaseStream.Seek(0, SeekOrigin.End);
w.WriteLine("Here is the file's text.");
w.Write("Here is more file text." +
System.Environment.NewLine);
w.WriteLine("And that's about it.");
w.Flush();
w.Close();
fs = new System.IO.FileStream("C:\\file.txt",
FileMode.Open, FileAccess.Read);
StreamReader r = new StreamReader(fs);
r.BaseStream.Seek(0, SeekOrigin.Begin);
FileText = "";
while (r.Peek() > -1)
{
FileText += r.ReadLine() +
System.Environment.NewLine;
}
r.Close();
return true;
}
catch //ex As Security.SecurityException
{
return false;
}
}
}
```

在清单 36.28 中，打开一个名为 `file.txt` 的本地文件，对其进行修改，然后保存。

3. 打开 `FileAccessLib` 应用程序的 `AssemblyInfo.cs` 文件，并添加以下代码行：


通过添加这行代码，以部分信任方式运行的应用程序可以调用 `FileAccessLib` 类库。
