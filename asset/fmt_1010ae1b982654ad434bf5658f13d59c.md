C 是一门低级语言。

它过去并非如此。在那个人们还在花岗岩上刻制打孔卡的时代，C 是一种摆脱汇编¹等低级语言枯燥工作的惊人方式。

但在现代社会，当代语言提供了各种在 1972 年 C 发明时并不存在的功能。这意味着 C 是一门非常基础的语言，功能并不多。它可以做任何事情，但它会让你为此付出努力。

那么，我们为什么要使用它呢？

- 作为一种学习工具：C 不仅是一段多功能的计算历史，而且在某些现代语言无法做到的方面，它与裸机²直接相连。当你学习 C 时，你学习的是软件在底层是如何与计算机内存交互的。这里没有安全带。我向你保证，你将写出崩溃的软件。而这一切都是乐趣！
- 作为一种实用的工具：C 用于某些应用，例如操作系统³或嵌入式系统⁴。（尽管 Rust⁵ 编程语言正盯着这些领域！）

如果你熟悉另一种也处理指针的语言，那么几乎一切都很简单，但指针是异异的。指针背后的概念可能是你已经熟悉的，但 C 语言迫使你显式地使用它，使用你从未见过的运算符。

## 2.3 编译细节

让我们来聊聊如何构建 C 程序，以及其背后发生了什么。

和其他语言一样，C 也有源代码。但取决于你从哪种语言转过来的，你可能从未需要将源代码编译成可执行文件。

编译是将你的源代码转换为操作系统可以执行的程序的过程。

JavaScript 和 Python 并不习惯于编译——尽管在背后有编译！Python 将你的源代码编译成 Python 虚拟机执行的字节码。Java 开发者习惯于编译，但那是产生 Java字节码。

在编译 C 时，会生成机器码。这是 CPU 可以直接且快速执行的 1 和 0。

通常不编译语言是解释性的。但对于 C，它是被编译成机器码的。这就是 C 如此快速的原因。

## 2.4 使用 GCC 编译

当你想要编译 C 时，可能会使用 GCC（GNU 编译器集合）。它是 Unix 类系统中非常常用的编译器。

要编译文件，你可以使用以下命令：

```
gcc hello.c -o hello
```

`-o` 标志告诉 GCC 输出文件的名称。如果你不使用它，输出将被命名为 `a.out`。
