解释定理 I 的合理性并不困难，尽管我们不给出定理的形式证明。为了简化，假设 `f` 非负的。如果 `h` 是一个小的正数，`A(x+h) - A(x)` 是图 19 中阴影区域的面积。这个阴影区域近似于宽为 `h`、高为 `f(x)`、面积为 `h · f(x)` 的矩形。因此，

$$A(x+h) - A(x) \approx h \cdot f(x),$$

当 `h` 趋于零时，近似变得越来越精确。除以 `h`，我们得到

$$\frac{A(x+h) - A(x)}{h} \approx f(x),$$

由于近似值随 `h` 趋于零而提高，该商必须趋于 `f(x)`。然而，导数的极限告诉我们，当 `h` 趋于零时，商趋于 `A(x)`。因此，我们有 `A'(x) = f(x)`。由于 `x` 代表 `a` 和 `b` 之间的任意数，这说明 `A(x)` 是 `f` 的一个原函数。

我们通过展示如何利用面积来证明上一节的定理 I 来结束本节。注意，如果 `F` 是 `f` 的任意原函数，由于面积 `A(x)` 也是 `f` 的原函数，我们有

$$A(x) = F(x) + C$$

对于某个常数 `C`。注意 `A(a)` 为 0，且 `A(b)` 等于 `f(x)` 图像在 `a ≤ x ≤ b` 下的区域的面积。因此，如果 `f` 为负，

$$[f \text{ 图像从 } a \text{ 到 } b \text{ 下的面积}] = A(b) = A(b) - A(a) = [F(b) + C] - [F(a) + C] = F(b) - F(a)]$$

### 示例 3 平均世界人口

`P(t)` 从 `t=0` 到 `t=30` 的平均值为：

$$\frac{1}{30-0}\int_{0}^{30} P(t)dt = \frac{1}{30}\int_{0}^{30} 5.9e^{0.0134t}dt = \frac{1}{30}\left[\frac{5.9}{0.0134}(e^{0.0134t}-1)\right]_{0}^{30} \approx 7.26.$$

### 消费者供给
使用某种商品的需求曲线，我们可以推导出带有价格歧视的公式。图2a显示了某种商品的需求曲线。它由经济因素以及商品量与单价之间的关系决定。具体来说，要销售 `x` 个单位，价格必须为每单位 `f(x)` 元。对于大多数商品，较大的数量需要价格降低，需求曲线通常是递减的。供需相互作用决定了商品的平均数量。设 `A` 代表商品的数量，`B=f(A)` 为当前售价。将从 0 到 `A` 的区间划分为 `n` 个子区间，每个长度为 `Δx=(A/n)`，区间从 `x0` 到 `xn`（见图2b）。假设已售出 `xi` 个单位。那么单价可以设定为 `f(xi)` 元并售出这 `xi` 个单位。

$$\int_0^A [f(x)-B]dx,$$
