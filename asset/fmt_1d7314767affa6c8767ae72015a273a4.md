## C语言中的预处理器

C 处理器是一个宏处理器，由 C 编译器自动使用，在实际编译之前转换您的程序（预处理器指令在编译之前执行）。它之所以称为宏处理器，是因为允许你定义宏，宏是较长结构的简短缩写。宏是由宏值替换的代码段。宏通过 `#define` 指令定义。

预处理器指令是程序中以 `#` 开头的行。`#` 后面跟着一个标识符，即指令名称。例如，`#define` 是定义宏的指令。在 `#` 前后都允许存在空白符。

`#` 指令名称不能来自宏展开。例如，如果 `foo` 被定义为展开为 `define` 的宏，这不会使 `#foo` 成为一个有效的预处理器指令。

所有预处理器指令都以 `#` 符号开头。

## 整数字面量

整数字面量可以是十进制、八进制或十六进制常量。前缀用于指定基数：十六进制使用 `0x` 或 `0X`，八进制使用 `0`，十进制则不为空。

整数字面量还可以有一个后缀，它是 `U` 和 `L` 的组合，分别表示无符号（unsigned）和长型（long）。后缀可以是大写或小写，且顺序任意。

以下是一些整数字面量的示例。

```

215u /* 合法 */
0FeeL /* 合法 */
078 /* 非法：8 不是八进制数字 */
032UU /* 非：不能重复后缀 */
```

以下是各种类型整数字面量的其他示例。

```

0213 /* 八进制 */
0x4b /* 十六进制 */
30 /* int */
30u /* 无符号 int */
```

## 定义常量

在 C 语言中有两种定义常量的简单方法：

- 使用 `define` 预处理器。
- 使用 `const` 关键字。

#### `#define` 预处理器

下面是使用 `#define` 预处理器定义常量的形式。

`#define 标识 值`

下面的示例详细解释了它。

```
#include<stdio.h>

#define LENGTH 10
#define WIDTH 5
#define NEWLINE '\n'

int main(){
int area;

area= LENGTH * WIDTH;
printf("value of area : %d", area);
printf("%c", NEWLINE);

return 0;
}
```

当上述代码被编译并执行时，会产生以下结果：

value of area : 50

#### `const` 关键字

你可以使用 `const` 前缀来声明特定类型的常量，如下：

`const 类型 变量 = 值;`

下面的示例详细解释了它。

```
#include<stdio.h>
int main(){
const int LENGTH =10;
const int WIDTH =5;
const char NEWLINE = "\n";
int area;
area=LENGTH * WIDTH;
printf("value of area : %d", area);
printf("%c", NEWLINE);

return 0;
}
```

当上述代码被编译并执行时，会产生以下结果：

value of area : 50
