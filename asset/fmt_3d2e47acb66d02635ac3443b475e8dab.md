### 问题定义

编写一个基础计算器。

用户将以 `x op y` 的形式输入运算

计算机将显示运算结果。

例如 `10.2 + 5.5`，`20.8 - 2.5`。

### 算法定义

- 我们必须定义两个变量，`number1` 和 `number2`，以及要执行的运算（`+`、`-`、`*`、 `/`）。

- 用户将被要求以 `x op y` 格式输入数字和运算。

- 程序将计算运算结果并在屏幕上显示。

```c
/* calculator */
```

## 21.- 高级主题。循环

在本节中，我们将了解如何在代码中实现重复。

我们将定义什么是数组，最后我们将处理文本字符串。

### 循环

有时我们面临需要重复执行某项操作若干次或直到满足某个条件的情况。

在 C 中，一系列操作的重复称为循环，可以有多种类型。

### `for` 循环

用于重复执行某项操作若干次（示例 `loopfor.c`）。

例如，在屏幕上显示 1 到 10 的数字：

```c
/* loopfor */

#include <stdio.h>

int main(void)
{
    int i;

    for (i = 1; i <= 10; i = i + 1)
    {
        printf("\nNumber%d", i);
    }

    return 0;
}
```

`for` 循环将执行块内的句子 10 次。首先计数器 `i` 初始化为 1；如果条件 `i <= 10` 为真，则执行块并增加计数器；如果不为真，则跟随下一条指令。

### `while` 循环

用于在满足条件时重复执行某项操作（示例 `loopwhile.c`）。

例如，显示 1 到 10 的数字：

```c
/* loopwhile */

#include <stdio.h>

int main(void)
{
    int i;

    i = 1;
    while (i <= 10)
    {
        printf("\nNumber%d", i);
        i = i + 1;
    }

    return 0;
}
```

`while` 循环与 `for` 循环类似，但通常在条件不依赖于计数器而依赖于在循环内重新计算的表达式时使用。

## 22.- 数组

数组是相同类型的固定数量的元素。

例如，而不是定义 10 个相同类型的变量，可以使用一个包含 10 个数字的数组。

我们可以用以下方式定义 5 个数字：

```c
int n1, n2, n3, n4, n5;
```

或用数组：

```c
int n[5];
```

在这种情况下，数组维度为 5 个元素，我们可以从位置 0 到 4 访问，分别是 `n[0]`、`n[1]`、`n[2]`、`n[3]` 和 `n[4]`。

### 示例

计算 100 到 200 的数字的算术平均值：

```c
/* arrays */
/* calculate the arithmetic mean of the numbers from 100 to 200 */

#include <stdio.h>

int main(void)
{
    int i;
    int numbers[200];
    float sum;
    float mean;

    /* fill array data */
    for (i = 1; i <= 100; i = i + 1)
    {
        numbers[i] = 100 + i;
    }

    /* calculate the sum of all the numbers */
    sum = 0;
    for (i = 1; i <= 100; i = i + 1)
    {
        sum = sum + numbers[i];
    }

    /* calculate arithmetic mean */
    mean = sum / 100;

    printf("\nThe mean of the numbers from 100 to 200 is: %f \n", mean);

    return 0;
}
```

首先我们定义要使用的变量。然后用 100 到 200 的数字填充数组。在下一个循环中，对 100 到 200 的数字求和。计算平均值并在屏幕上显示。

如果我们查看数组 `numbers` 的定义，我们会看到它的维度为 200，而实际上只使用了 100 个。通常会将维度设得比实际使用的大，因为在 C 中不检查数组的限制，典型的错误是尝试使用超出范围的索引，这会导致不可预期的效果。

## 23.- 文本字符串

字符串是一系列字符。

C 中的文本字符串由字符数组表示。

字符串字面量是双引号之间的字符序列。

例如，`"this is a phrase."`

### 字符串声明

```c
char cad[20];
```

### 字符串初始化

```c
char cad[] = "this is a phrase";
```

在这种情况下，数组 `cad` 的维度为 17，每个字母一个字符，最后一个字符为 0 以指示字符串的结束。

### 字符串操作

有一个用于字符串处理的库：

```c
#include <string.h>
```

- 连接两个字符串：`strcat(cad1, cad2);`

  - 它将 `cad2` 复制到 `cad1` 的末尾。

  - 注意 `cad1` 的大小。

- 字符串的字符数：`strlen(cad);`

- 比较字符串。

`strcmp (cad1, cad2)`

- 0 if `cad1 = cad2`

- <0 if `cad1 < cad2`

- >0 if `cad1 > cad2`

### Example

```c
/* strings of text */
#include <string.h>

{

    printf ("\n This is a string of characters .. \n");

    char cad12 [20] = "test string";

    char cad13 [] = "test string";
```

## 25.- Variables and Pointers

In this class we will see, perhaps, the most advanced functionality of the C language, the pointers.

In C we can define variables of a particular type that store values that we can access in our program

E.g.

`int number = 2;`

In our program we can access the variable `number` through its name.

The variables is a representation of a memory space that has a physical address.

E.g.

When we define the variable `number`, the compiler assigns it in memory address 12000.

In our program instead of accessing the variable by the memory address, we access through its name and the compiler itself is in charge of mapping the name of the variable with its physical memory address.

A pointer is a special type of variable that allows you to store the physical address of another variable, so that we can access it through an indirection.

E.g.

```c
int number = 2;
int *number;

number = &number;
*number = 3;
```

In this example `number` is a pointer that will point to an integer variable.

With the `number = &number` assignment, we are indicating that the pointer points to the variable `number`.
