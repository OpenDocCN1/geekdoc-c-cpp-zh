## 7.26.3.3 cnd_init 函数

### 概要

## 7.26.3.5 cnd_timedwait 函数

### 概要

```c
#include <threads.h>
int cnd_timedwait (cnd_t *restrict cond,
mtx_t *restrict mtx,
const struct timespec *restrict ts);
```

## 描述
`cnd_timedwait`函数原子性地解锁由`mtx`指向的互斥锁，并尝试阻塞，直到`cond`指向的条件变量被`cnd_signal`或`cnd_broadcast`信号，或者直到达到`ts`指向的基于`TIME_UTC`的日历时间之后。当调用线程被唤醒时，它会在返回之前锁定`mtx`指向的变量。`cnd_timedwait`函数要求调用线程必须已锁定`mtx`指向的互斥锁。

### Returns
`cnd_timedwait`函数在执行成功时返回`thrd_success`；如果在调用指定的时间到达前未获取请求的资源，则返回`thrd_timedout`；如果请求无法实现，则返回`thrd_error`。


## 描述

- `mtx_plain`：用于简单的非递归互斥锁；
- `mtx_timed`：用于支持超时的非递归互斥锁；

### Returns
`mtx_lock`函数在执行成功时返回`thrd_success`；如果请求无法实现，则返回`thrd_error`。
