### `DO` 循环处理

使用 `DO` 循环执行重复计算。

```sas
data compound (drop=i);
Amount=50000;
Rate=.045;
do i=1 to 20;
  Yearly+Amount*Rate;
end;
do i=1 to 80;
  Quarterly+Amount/4;
end;
run;
```

### 迭代 `DO` 语句

`start`, `stop` 和 `increment`

- 必须是数字或产生数字的表达式

- 在执行循环之前建立

- 如果省略，`increment` 默认为 1

索引变量详情：

- 默认写入输出数据集中。

- 在循环结束时，索引变量的值比 `stop` 值多一个增。

`start` 指定索引变量的初始值。

`stop` 指定索引变量的结束值。

`increment` 指定控制索引变量增量的正负数。

在 `DO` 循环内对 `stop` 或 `increment` 的修改不会影响迭代次数。

### 带有列表的示例 `DO` 循环

- `DO` 循环列表中的每个项目执行一次。

- 列表必须用逗号分隔。

```sas
do Month='JAN', 'FEB', 'MAR';
end;
do odd=1,3,5,7,9;
end;
do i=Var1,Var2,Var3;
end;
do index-variable=item-1...item-n;
```

# 使用 `DO` 循环减少冗余代码

```sas
data forecast;
  set orion.growth;
```
