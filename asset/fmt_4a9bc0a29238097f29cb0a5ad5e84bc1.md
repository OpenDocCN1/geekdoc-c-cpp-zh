## 使用 ClickOnce 部署基于 Windows 的应用程序

ClickOnce 部署技术通过使用“发布向导”来部署应用程序。“发布向导”使你能够将应用程序发布到网页、共享网络文件或 CD。让我们使用“发布向导”将示例应用程序 `DeploymentTestClickOnce` 发布到网页上。`DeploymentTestClickOnce` 应用程序（也随附于 CD）的代码与上一个示例中的 `DeploymentTest` 应用程序相同。请注意，要将应用程序发布到网页，你应该具有管理权限。你需要执行以下步骤来发布 `DeploymentTestClickOnce` 应用程序：

1. 在“解决方案资源管理器”中右键单击 `DeploymentTestClickOnce` 项目节点，并从上下文菜单中选择“发布”选项，以显示“发布向导”的第一页，如图 21.28 所示：

图 21.28：指定发布应用程序的位置

3. 单击“下一步”按钮，如图 21.29 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1086_0.png)

图 21.29：指定用户发布应用程序的位置

## 部署 Web 应用程序

在 Visual Studio 2010 中，Web 应用程序是通过 Web 安装项目来部署的，该项目将 Web 应用程序安装到 Web 服务器上的虚拟根文件夹中。让我们使用 Web 安装项目来部署一个 Web 应用程序。

执行以下步骤，在 Web 应用程序中添加一个名为 `DeploymentTestWebSetup` 的 Web 安装项目：

1. 创建一个 ASP.NET Web 应用程序。在我们的示例中，我们创建了名为 `DeploymentTestWebApplication` 的 Web 应用程序（也随附于 CD）。
2. 在“解决方案资源管理器”中右键单击解决方案名称，并选择“添加→新建项目”选项。此时会打开“添加新项目”对话框（图 21.35）。
3. 在“已安装的模板”类别中选择“其他项目类型→安装和部署→Visual Studio Installer”（图 21.35）。
4. 在中间窗格中选择“Web 安装项目”模板，并在“名称”文本框中输入项目名称。在我们的示例中，我们输入了 `DeploymentTestWebSetup`，如图 21.35 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1089_0.png)

5. 单击“确定”按钮创建 Web 安装项目（图 21.35）。
6. 在“解决方案资源管理器”中右键单击 `DeploymentTestWebSetup` 图标，并从上下文菜单中选择“添加→项目输出”选项。此时会打开“添加项目输出组”对话框（图 21.36）。
7. 在“添加项目输出组”对话框中，从“项目”组合框中选择 `DeploymentTestWebApplication`，然后从列表框中选择“主输出”，如图 21.36 所示：
