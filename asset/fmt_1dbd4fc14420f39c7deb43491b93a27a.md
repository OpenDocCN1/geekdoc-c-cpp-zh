
### 运行约束

`retval` 和 `src` 均不为空指针。如果 `dst` 不为空指针，则 `len` 和 `dstmax` 均不应大于 `RSIZE_MAX`。如果 `dst` 为空指针，则 `dstmax` 不等于零。如果 `dst` 不为空指针且 `len` 不小于 `dstmax`，则转换应当停止（见下文），因为达到了终止空字符或发生了编码错误。

> 414) 因此，如果 `dst` 为空指针，则忽略 `len` 的值。
> 415) 这允许实现在发现终止空字符之前转换多字节字符串。

如果违反运行约束，`wcstows_s` 执行以下操作：如果 `retval` 不为空指针，`wcstows_s` 将 `*retval` 设置为 `(size_t) (-1)`。如果 `dst` 不为空指针且 `dstmax` 大于零且小于 `RSIZE_MAX`，`wcstows_s` 将 `dst[0]` 设置为空字符。

## 描述

`wcstows_s` 函数将从 `src` 指向的数组的宽字符序列转换为从初始状态开始的多字节字符序列。如果 `dst` 不为空指针，转换后的字符将存储在 `dst` 指向的数组中。转换持续到包括终止空字符，该字符也会被存储。转换在两种情况下会提前停止：

- 当遇到不对应有效多字节字符的宽字符时；
- （如果 `dst` 不为空指针）下一个多字节字符将超过存储在 `dst` 数组中的字节限制。如果正在转换的字符是空字符，则 `n` 是 `len` 和 `dstmax` 中的较小值。否则，`n` 是 `dstmax-1`。

如果转换在未转换宽字符的情况下停止且 `dst` 不为空指针，则空字符存储在 `dst` 指向的数组中已存储的多字节字符之后。每次转换的发生都如同调用了 `wcertmb` 函数一样。416

无论 `dst` 是否为空指针，如果输入遇到不对应有效多字节字符的宽字符，则发生编码错误：`wcstows_s` 函数将值 `(size_t) (-1)` 存储到 `*retval`。否则，`wcstows_s` 函数向 `*retval` 存储结果多字节序列的字节数，包括终止空字符（如果有）。

由 `wcstows_s` 在 `dst` 指向的 `dstmax` 元素数组中写入终止空字符（如果有）的所有后续元素，在 `wcstows_s` 返回时都具有未指定的值。417

如果在重叠对象之间发生拷贝，这些对象将获得未指定的值。

> 4⁶ 如果转换是因为达到了终止空字符而停止，则字节包括在空字节之前达到初始移位状态所需的字节。然而，如果转换在达到终止空字符之前停止，结果将为空，但可能没有处于初始移位状态。

如果没有发生运行时约束违反且没有发生编码错误，`strnc_s` 函数返回零。否则，返回非零值。

### K.3.7.1.4 strncpy_s 函数

概要

```
#define __STDC_WANT_LIB_EXT1__ 1

#include <string.h>

errno_t strncpy_s(char * restrict s1,
size_t slmax,
const char * restrict s2,
size_t n);
```

运行时约束

- `s1` 和 `s2` 均不能为空指针。`slmax` 和 `n` 均不大于 `RSIZE_MAX`。`slmax` 不等于零。如果 `n` 小于 `slmax`，则 `slmax` 应该大于 `strlen(s2)`。不应在重叠的对象之间进行拷贝。
- 如果发生运行时约束违反，且 `s1` 不是空指针且 `slmax` 大于零且不超过 `RSIZE_MAX`，则 `strncpy_s` 将 `s1[0]` 设置为空字符。

描述

`strncpy_s` 函数从 `s2` 指向的数组拷贝 `n` 个连续字符（空字符之后的字符不拷贝）到 `s1` 指向的数组。如果未从 `s2` 拷贝空字符，则 `s1[n]` 被设置为空字符。这允许实现在检查任何字符是否为空的同时，从 `s2` 拷贝字符到 `s1`。这种方法可能会在发现第一个元素应设置为空字符之前，向 `s1` 的每个元素写入一个字符。返回零意味着 `s2` 指向的字符串的所有请求字符都在 `s1` 指向的数组内且结果以空字符终止。

示例 1 `strncpy_s` 函数用于拷贝字符串，除非结果以空字符终止或字符超出目标数组。

```
#define __STDC_WANT_LIB_EXT1__ 1

#include <string.h>

/* ... */
char src1[100] = "hello";
char src2[7] = ('g', 'o', 'o', 'd', 'e');
char dst1[6], dst2[5], dst3[5];
int r1, r2, r3;
r1 = strncpy_s(dst1, 6, src1, 100);
r2 = strncpy_s(dst2, 5, src2, 7);
r3 = strncpy_s(dst3, 5, src2, 4);
```

第一次调用将零赋值给 `r1`，并将 `hello\0` 赋值给 `dst1`。
第二次调用将非零值赋值给 `r2`，并将 `\0` 赋值给 `dst2`。
第三次调用将零赋值给 `r3`，并将 `good\0` 赋值给 `dst3`。

## K.3.7.2 拼接函数

### K.3.7.2.1 strcat_s 函数

概要

```
#define __STDC_WANT_LIB_EXT1__ 1

#include <string.h>

errno_t strcat_s(char * restrict s1,
size_t slmax,
const char * restrict s2);
```

运行时约束

在进入 `strcat_s` 时，`m` 表示 `slmax - strnlen_s(s1, slmax)`。这允许实现在检查任何字符是否为空的同时，从 `s2` 拷贝字符到 `s1`。这种方法可能会在发现第一个元素应设置为空字符之前，向 `s1` 的每个元素写入一个字符。返回零意味着 `s2` 指向的字符串的所有请求字符都在数组内且 `s1` 中的结果以空字符终止。

`s1` 和 `s2` 不能为空指针。`smax` 不大于 `RSIZE_MAX`。`smax` 不等于零。`m` 大于 `strnlen_s(s2, m)`。不应在重叠的对象上拷贝。

如果发生运行时约束违反，且 `s1` 不是空指针且 `smax` 大于零且不超过 `RSIZE_MAX`，则 `strcat_s` 将 `s1[0]` 设置为空字符。

描述

`strcat_s` 函数将 `s2` 指向的字符串（包括终止空字符）附加到 `s1` 指向的字符串末尾。`s2` 的起始字符会覆盖 `s1` 末尾的空字符。`strcat_s` 在 `s1` 指向的 `slmax` 个字符数组中写入的终止空字符（如果有）之后的所有元素，在 `strcat_s` 返回时其值是不确定的。

返回值

如果没有发生运行时约束违反，`strcat_s` 函数返回零。否则，返回非零值。

### K.3.7.2.2 strcat_s 函数

概要

```
#define __STDC_WANT_LIB_EXT1__ 1

#include <string.h>

errno_t strcat_s(char * restrict s1,
size_t slmax,
const char * restrict s2,
size_t n);
```

运行时约束

在进入 `strcat_s` 时，`m` 表示 `slmax - strnlen_s(s1, slmax)`。

`s1` 和 `s2` 不能为空指针。`slmax` 和 `n` 均不大于 `RSIZE_MAX`。`slmax` 不等于零。`m` 不等于零。

小于 `m`，`m` 应大于 `strlen_s(s2, m)`。拷贝操作不应发生在重叠的对象之间。

如果发生运行时约束违反，如果 `s1` 不是指针且 `smax` 大于 0 且不超过 `RSIZE_MAX`，则 `strcat_s` 将 `s1[0]` 设置为空字符。

描述

`strcat_s` 函数将数组 `s2` 中多于 `n` 个连续的字符（空字符之后的字符不被复制）从 `s2` 追加到 `s1` 所指向的字符串末尾。来自 `s2` 的起始字符将覆盖 `s1` 末尾的空字符。如果没有从 `s2` 拷贝空字符，则 `s1[slmax-m+n]` 将被设置为空字符。

当 `strcat_s` 在指向 `s1` 的 `slmax` 字符数组中写入终止空字符（如果有的话）之后的所有元素，这些元素在 `strcat_s` 返回时将具有未定义的值。426)

返回

如果没有发生运行时约束违反，`strcat_s` 函数返回零。否则，返回非零值。

示例 1 `strcat_s` 函数可以用于拷贝字符串，而不会产生结果未终止或超出目标数组边界的危险。

```
#define _STDC_WANT_LIB_EXT1__ 1

#include <string.h>
/* ... */
char s1[1000] = "good";
char s2[6] = "hello";
char s3[6] = "hello";
char s4[7] = "abc";
char s5[1000] = "bye";
int r1, r2, r3, r4;
r1 = strcat_s(s1, 100, s5, 1000);
r2 = strcat_s(s2, "", 1);
r3 = strcat_s(s3, "X", 2);
r4 = strcat_s(s4, 7, "defghijklmn", 3);
```

> 425) 零意味着在进入 `strcat_s` 时 `s1` 未终止。
> 426) 这允许实现在将来自 `s2` 的字符追加到 `s1` 的同时，检查这些字符中是否有空字符。这种方法可能会在发现第一个元素被设置为空字符之前，向 `s1` 的每个元素写入一个字符。
> 427) 返回值零意味着从 `s2` 所指向的字符串中请求的任何字符已追加到 `s1` 所指向的字符串中，且 `s1` 中的结果是空终止的。

在第二次调用后，`r2` 的值为零，`s2` 将包含序列 `hello\0`。在第三次调用后，`r3` 为非零值，`s3` 将包含序列 `abcdef\0`。在第四次调用后，`r4` 的值为零，`s4` 将包含序列 `abcdef\0`。

## K.3.7.3 搜索函数

### K.3.7.3.1 `strtok_s` 函数

语法结构

```
#define __STDC_WANT_LIB_EXT1__
#include <string.h>

char *strtok_s(char * restrict s1,
size_t * restrict smax,
const char * restrict s2,
char ** restrict ptr);
```

运行时约束

- `smax`、`s2` 或 `ptr` 均不为空指针。如果 `s1` 为空，则 `*smax` 的值不大于 `RSIZE_MAX`。在第一次调用时，找到的标记结束应发生在 `s1` 的前 `*smax` 个字符内；在后续调用中，搜索恢复后的结束应发生在搜索恢复后的前 `*smax` 个字符内。
- 如果发生运行时违反，`strtok_s` 函数不会通过 `s1` 或 `s2` 指针进行间接访问，也不会在 `ptr` 指向的对象中存储值。

描述

- 对 `strtok_s` 的一系列调用将 `s1` 指向的字符串拆分为一系列标记（tokens），每个标记都由 `s2` 指向的字符串中的一个字符分隔。第四个参数是调用者提供的 `char` 指针，`strtok_s` 函数在其中存储信息以便继续处理同一字符串。
- 序列中的第一次调用第一个参数不为空，`smax` 指向一个对象，其值为第一个参数所指向的字符数组中的元素个数。第一次调用在 `ptr` 指向的对象中存储初始值，并更新 `smax` 指向的值以反映相对于 `ptr` 剩余的元素个数。序列中的后续调用具有第一个参数，且要求 `smax` 和 `ptr` 指向的对象具有序列中上一次调用存储的值，随后这些值会被更新。`s2` 指向的分隔符在每次调用时可能不同。
- 序列中的第一次调用在 `s1` 指向的字符串中搜索第一个不包含在当前 `s2` 指向字符串中的字符。如果没有找到这样的字符，则 `s1` 指向的字符串中没有标记，且 `strtok_s` 函数将（此处逻辑似乎缺失，原文如此）。
