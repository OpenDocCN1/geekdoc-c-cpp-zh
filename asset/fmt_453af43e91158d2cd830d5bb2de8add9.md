**线性函数** 正如我们在第1章中所看到的，了解直线的代数和几何性质对于学习微积分至关重要。每条直线都是形式如下线性方程的图像：

`cx + dy = e`，

其中 `c, d` 和 `e` 是给定的常数，且 `c` 和 `d` 不为零。如果 `d ≠ 0`，我们解方程得 `y`，得到形式如下的方程：

`y = mx + b`，

其中 `m` 和 `b` 是适当的数。如果 `d = 0`，我们解方程得 `x`，得到形式如下的方程：

`x = a`，

其中 `a` 是适当的数。因此，每条直线都是形式 (1) 或 (2) 方程的图像。形式 (1) 方程的图像是非垂直函数。图 1(a)；而 (2) 的图像是垂直线。图 1(b)

图 1(a) 中的直线是函数 `f(x) = mx + b` 的图像。这种定义于所有 `x` 的函数被称为*线性函数*。注意，垂直线不是函数。

线性函数的一个重要情况是 `m` 的值为零时；即对于某个数 `b`，`f(x) = b`。在这种情况下，`f(x)` 被称为*常数函数*，因为它给每个 `x` 值分配了相同的数字 `b`。它的图像是方程为 `y = b` 的水平线。（见图 2）

## 多项式与理性函数

多项式函数 `f(x)` 的形式为 `f(x) = a_n x^n + a_{n-1} x^{n-1} + … + a_0`，其中 `n` 是非负整数，`a_0, a_1, …, a_n` 是给定的数字。多项式函数的例子包括 `f(x) = 5x^3 - 3x^2 - 2x + 4` 和 `g(x) = x^2 - x + 1`。当然，线性和二次函数是多项式函数的特例。多项式函数的定义包含所有数字。

表示为两个多项式商的函数称为*有理函数*。一些例子包括 `h(x) = x^2 / x` 和 `k(x) = (x+3)/(x^2-4)`。有理函数的定义排除所有分母为零的 `x` 值。例如，`h(x)` 的定义排除 `x=0`，`k(x)` 的定义排除 `x=2` 和 `x=-2`。正如我们将看到的，多项式函数和有理函数都出现在微积分的应用中。
