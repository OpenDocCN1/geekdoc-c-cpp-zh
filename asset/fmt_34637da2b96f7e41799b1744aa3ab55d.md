
执行这段代码后，`unique`排除了在`queue`中重复的项（1, 3, 5, 7, 9），同时也排除了`queue`中但不在`unique`中的项（0, 2, 4, 6, 8, 17）。最终你在`unique`中得到了11, 13和15。与此同时，下一个代码使用`SymmetricExceptWith()`来产生与`IntersectWith()`相反的结果。`IntersectWith()`给你交叠项，而`SymmetricExceptWith()`给你在两个列表中存在但不重叠的项。该集合最终只包含5, 3, 12和10：

```sharp
Console.WriteLine("\nFinding the non-overlapping items in two lists:");
Stack<int> stackOne = new Stack<int>(new int[] { 1, 2, 3, 4, 5, 6, 7, 8 });
Stack<int> stackTwo = new Stack<int>(new int[] { 2, 4, 6, 7, 8, 10, 12 });
HashSet<int> nonoverlapping = new HashSet<int>(stackOne);
// SymmetricExceptWith() 收集于一个集合但不在另一个集合中的项：即不重叠的项。
nonoverlapping.SymmetricExceptWith(stackTwo);

foreach (int n in nonoverlapping)
{
    Console.WriteLine(n);
}
Console.WriteLine("Press Enter to terminate...");
Console.Read();
```

我在这里使用栈（stacks）的方式有点不传统，因为我是一次添加所有成员，而不是逐个推入（push），并且是一次性移除一组，而不是逐个弹出（pop）。那些操作——推入和弹出——才是与栈交互的正确方式。

注意，我演示的所有`HashSet<T>`方法都是`void`类型方法——它们不返回值。因此，结果会直接反映在调用这些方法的哈希集合上：例如前一个代码中的`nonoverlapping`。

![](img/6df7bb88e9302e9844acc219bd7fc_156_0.png)

起初我发现`UnionWith()`和`IntersectWith()`的行为有点别扭，因为我想要一个新的一个新的结果集，而在应用这些方法时让原始（输入）集合保持不变。但在第一部分第9章，你将遇到（我很高兴地报告）LINQ查询操作符，它们增加了这些方法的返回全新新集合的版本。将你在这里看到的和在那里看到的结合，你就可以兼得其利。不仅如此，我最好现在不要多说。

你什么时候会使用`HashSet<T>`？每当你处理两个或多个集合并想要找到像重叠这样的项——或者创建一个包含另外两个集合的集合，或者从一个集合中排除一组项时——集合都是很有用的。许多`HashSet<T>`方法可以处理集合。你可以对集合进行更多操作，所以请查阅`HashSet<T>`帮助。

# 不要使用旧式集合

在那个年代，在C# 2.0诞生之前，所有的集合类都是实现为`Object`类型的集合。你无法创建一个仅用于字符串或仅用于整数的集合。这种集合允许你存储任何类型的数据，因为C#中的所有对象都派自`Object`。因此，你可以将整数和字符串添加到同一个集合中而不会看到错误信息（由于C#的继承和多态性，我在第二部分中讨论）。但在基于`Object`的安排中存在一个严重的缺陷：为了提取你放入集合的整数，你必须将其强制类型转换为`int`：

```csharp
ArrayList ints = new ArrayList(); // 一个旧式的列表
int myInt = (int)ints[0];        // 提取列表中的整数。
```

就像你的整数隐藏在彩蛋里面。如果你不进行强制转换，就会产生错误，例如，`Object`不支持`+`操作或其他属性，以及你期望的整数。你可以处理这些局限性工作，但这种代码很容易出错，而且执行所有强制转换非常繁琐。（此外，正如我在第一部分第8章中讨论的，装箱（boxing）会减慢你的程序。）

# 遍历文件目录

![](img/6df7bb88e9302e98442acc219cfbd7fc_159_0.png)

如果你在一个包含大量文件的目录中运行此程序，十六进制转储（hex dump）可能需要一些时间。此外，处理长文件的循环也需要时间。请选择一个文件较少的目录，或者通过按Ctrl+C停止运行时间长的程序。此命令可以中断任何控制窗口中运行的程序。

![](img/6df7bb88e9302e98442acc219cfbd7fc_159_1.png)

```sharp
// LoopThroughFiles -- 遍历目录中包含的所有文件；
//   这次执行十六进制转储，尽管它也可以是任何操作。
using System;
using System.IO;

namespace LoopThroughFiles
{
    public class Program
    {
        public static void Main(string[] args)
        {
            // 如果没有提供目录名...
            string directoryName;
            if (args.Length == 0)
            {
                // ...获取当前目录的名称...
                directoryName = Directory.GetCurrentDirectory();
            }
            else
            {
                // ...否则，假设第一个参数
                // 是要使用的目录名。
                directoryName = args[0];
            }
            Console.WriteLine(directoryName);

            // 获取该目录中所有文件的列表。
            FileInfo[] files = GetFileList(directoryName);

            // 现在遍历列表中的文件，
            // 对每个文件执行十六进制转储。
            foreach(FileInfo file in files)
            {
                // 输出文件的名称。
                Console.WriteLine("\n\nhex dump of file {0}:", file.FullName);

                // 现在将文件“转储”到控制台。
                DumpHex(file);

                // 在输出下一个文件之前等待。
                Console.WriteLine("\nenter return to continue to next file");
                Console.ReadLine();
            }

            // 就这样了！
            Console.WriteLine("\nno files left");

            // 等待用户确认结果。
            Console.WriteLine("Press Enter to terminate...");
            Console.Read();
        }

        // GetFileList -- 获取指定目录中所有文件的列表。
        public static FileInfo[] GetFileList(string directoryName)
        {
            // 从一个空列表开始。
            FileInfo[] files = new FileInfo[0];
            try
            {
                // 获取目录信息。
                DirectoryInfo di = new DirectoryInfo(directoryName);

                // 该信息对象包含内容的列表。
                files = di.GetFiles();
            }
            catch(Exception e)
            {
                Console.WriteLine("Directory \"{0}\" invalid", directoryName);
                Console.WriteLine(e.Message);
            }
            return files;
        }

        // DumpHex -- 给定文件，将文件内容转储到控制台。
        public static void DumpHex(FileInfo file)
        {
            // 打开文件。
            FileStream fs;
            BinaryReader reader;
            try
            {
                fs = file.OpenRead();
                // 将文件流封装在 BinaryReader 中。
                reader = new BinaryReader(fs);
            }
            catch(Exception e)
            {
                Console.WriteLine("\ncan't read from \"{0}\"", file.FullName);
                Console.WriteLine(e.Message);
                return;
            }

            // 逐行遍历文件内容。
            for(int line = 1; true; line++)
            {
                // 跨行读取 10 字节（单行能容纳的所有字节）
                // 在没有剩余数据时返回。
                byte[] buffer = new byte[10];
                // 使用 BinaryReader 读取字节。
                // 注意：直接使用 FileStream 
                // 也会一样简单。
                int numBytes = reader.Read(buffer, 0, buffer.Length);
                if (numBytes == 0)
                {
                    return;
                }

                // 输出刚刚读取的数据，
                // 位于单行，前面带有行号。
                Console.Write("{0:D3} - ", line);
                DumpBuffer(buffer, numBytes);

                // 每 20 行停止一次，以免数据滚出屏幕顶部。
                if ((line % 20) == 0)
                {
                    Console.WriteLine("Enter return to continue another 20 lines");
                    Console.ReadLine();
                }
            }
        }

        // DumpBuffer -- 将字符缓冲区以十六进制格式写入单行。
        public static void DumpBuffer(byte[] buffer, int numBytes)
        {
            for(int index = 0; index < numBytes; index++)
            {
                byte b = buffer[index];
                Console.Write("{0:X2} ", b);
            }
            Console.WriteLine();
        }
    }
}
```

从命令行中，用户通过参数指定要使用的目录。以下命令会对目录中的每个文件进行“hex dumps”（即十六进制转储，包括二进制文件和文本文件）：

`LoopThroughFiles c:\temp`

如果你没有输入目录名，程序默认使用当前目录。（十六进制转储将以16进制数字显示输出——请查看旁边的边栏“获取十六进制”）。

所有的FileRead和FileWrite都是从控制台读取输入，而此程序从命令行获取输入。我并不是为了困扰你——我是在向你展示解决同一个问题的不同方法。

![](img/6df7bb88e9302e98442acc219cfbd7fc_161_0.png)

`LoopThroughFiles`的第一行会查找参数。如果参数列表为空（`args.Length`为0），程序调用`Directory.GetCurrentDirectory()`。如果你在Visual Studio而不是命令行中运行，该值默认为你的`LoopThroughFiles`项目下的`bin\Debug`子目录。

![](img/6df7bb88e9302e98442acc219cfbd7fc_161_1.png)

`Directory`类为用户提供了一组操作目录的方法。`FileInfo`类提供了移动、复制和删除文件等任务的方法。

程序随后通过调用本地的`GetFileList()`创建指定目录中所有文件的列表。

`DumpHex()`的起点是打开文件。一个`FileInfo`对象包含关于文件的信息——它不会打开文件。`DumpHex()`获取文件的完整名称（包括路径），然后使用该名称以只读模式打开`FileStream`。由于某些原因`FileStream`无法读取文件，`catch`块将抛出异常。
