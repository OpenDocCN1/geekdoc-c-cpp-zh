## 转换两种可空类型

不可空值类型会隐式转换为该值类型的可空类型。此外，转换也会从`null`字面量到可空类型进行。您可以在不可空值类型及其可空形式上执行预定义和用户定义的转换。这些转换发生在`A`到`B?`以及`A?`到`B`。`A?`到`B`的转换是显式转换，如果源值为`null`，则会引发异常。现在，让我们通过执行“声明变量”标题中给出的步骤，创建一个名为`NullableConversion`的新 C# 2010 控制台应用程序（也可在 CD-ROM 上获得），以学习如何将可空类型转换为不可空类型。将清单 2.17 中显示的代码添加到`NullableConversion`应用程序的`Program.cs`文件中，以了解可空类型转换：

### 清单 2.17：显示可空类型转换的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace NullableConversion
{
    class Program
    {
        static void Main(string[] args)
        {
            int m = 123;
            //Assigning value of integer variable m to nullable integer variable
            int? a = m;
            Console.WriteLine("The value of a is " + a);
            //Assigning value of nullable integer variable to nullable double variable
            double? b = a;
            Console.WriteLine("The value of nullable double variable is " + b);
//Converting nullable double to nullable int and assigning the value to nullable integer variable
int? c = (int?)b;
Console.WriteLine("The value of nullable integer variable is " + c);
//Converting nullable int to integer type and assigning value to integer variable
int n = (int)c;
Console.WriteLine("The value of integer variable is " + n);
Console.ReadLine();
} }
```

在清单 2.17 中，我们声明了一个变量`m`，其数据类型为整数，并为其赋值为 123，然后将其进一步赋给可空变量`a`。这两个变量的数据类型相同；因此，无需进行类型转换。代码行`double? b=a`通过隐式转换其类型，将`a`的值赋给可空`double`变量`b`。请注意，当我们将可空变量`b`的值赋给可空整数变量`c`时，需要显式类型转换，因为`double`类型不能隐式转换为整数类型。最后，我们将可空整数类型转换为整数类型。清单 2.17 的输出如图所示 2.14：

## 使用 is 和 as 运算符

`is`运算符检查对象是否与给定类型兼容，并返回布尔结果，即`true`或`false`。对象可能与该类型相同，也可能派生自该特定给定类型。`as`运算符将引用类型显式转换为特定类型。如果引用类型与指定类型兼容，则执行成功转换；否则，它返回`null`值。请注意，`as`运算符不会引发异常。让我们通过执行“声明变量”标题中给出的步骤，创建一个名为`IsandAs`的新 C# 2010 控制台应用程序（也可在 CD-ROM 上获得），以学习如何使用`is`和`as`运算符。清单 2.18 显示了要添加到`IsandAs`应用程序的`Program.cs`文件中的代码：

### 清单 2.18：显示 IsandAs 应用程序的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace IsandAs
{
    class Program
    {
        static void Main(string[] args)
        {
            object i = 25;
            object str = "Kogent Learning Solutions";    //Checking compatibility
            if (i is string)
                Console.WriteLine("i is a string type");
            else
                Console.WriteLine("i is an integer type");
            string str1 = i as string;    //Casting i to string
            string str2 = str as string;  //Casting str to string
            Console.WriteLine("The value of str1 is " + str1);
            Console.WriteLine("The value of str2 is " + str2);
            Console.ReadLine();
        }
    }
}
```

当你编译清单 2.18 所示的代码时，编译器会检查`if (i is string)`行的类型兼容性。编译器会验证`i`变量是否为字符串变量。然而，对于分配给`i`变量的值（25），编译器将`i`声明为整数类型。因此，流程会进入`else`块并执行指定的`else`块语句。同样，当我们使用`as`运算符转换变量`string str1 = i as string`时，编译器会检查`i`与字符串类型的类型兼容性。由于`i`是整数类型且无法转换为字符串类型；因此它返回`null`值。然而，当我们将`str`变量的值分配给`str2`变量时，编译器确保类型与字符串类型兼容并将`str`的值分配给`str2`。清单 2.18 的输出如图所示 2.15：

## 创建枚举

枚举是用户定义的值类型。它是一个强类型常量，允许你为整数值分配符号名称。短语强类型意味着一种类型的枚举不能分配给另一种类型的枚举，即使它们的成员值相同。你只能为枚举分配合法的值，使你的代码易于维护。在为枚举分配可接受的值范围时，如果你在代码的其他部分尝试分配超出可接受范围的值，则会发生错误。由于枚举是值类型，因此它们不能继承或从一个枚举继承到另一个枚举。请注意，枚举是使用`enum`关键字创建的，它是`System.Enum`类的别名。现在，让我们通过执行标题 *Declaring Variables* 中给出的步骤，创建一个名为`Enumeration`的新 C# 2010 控制台应用程序（也可在 CD-ROM 上获得），以学习如何创建枚举。将清单 2.20 所示的代码添加到`Enumeration`应用程序的`Program.cs`文件中：

### 清单 2.20：显示 Enumeration 应用程序的 Program.cs 文件的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace Enumeration
{
    public enum Color { Red = 1, Green, Yellow }
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Please select 1 for Red, 2 for Green, and 3 for Yellow");
            string str = Console.ReadLine();
            int colInt = Int32.Parse(str);
            Color col = (Color)colInt;
            switch (col)
            {
                case Color.Red:
                    Console.WriteLine("The selected color is Red");
                    break;
                case Color.Green:
                    Console.WriteLine("The selected color is Green");
                    break;
                case Color.Yellow:
                    Console.WriteLine("The selected color is Yellow");
                    break;
                default:
                    Console.WriteLine("This number is not assigned to any color");
                    break;
            }
            Console.ReadLine();
        }
    }
}
```
