### 13.6.2 队列

队列是一种遵循先入先出（FIFO）原则的线性数据结构，第一个进入队列的元素是第一个被移除的元素。队列有两个主要操作：入队（enqueue，插入元素）和出队（dequeue，移除元素）。队列主要有两种类型：

- 线性队列：使用数组存储元素，具有固定大小。
- 动态队列：使用链表存储元素，允许动态内存的分配和释放。

队列有一个头部（front）和一个尾部（rear），入队将元素添加到尾部，出队则从头部移除元素。

队列的常用操作包括：

- Enqueue：向队列中插入一个元素。
- Dequeue：从队列中移除一个元素。
- Front：获取队列中的第一个元素。
- Rear：获取队列中的尾部元素。
- IsEmpty：检查队列是否为空。
- IsFull：检查队列是否已满。

队列在各种应用中非常有用，例如操作系统、计算机网络和模拟算法，在这些领域中元素的处理顺序是非常重要的。

## 13.6. 数据结构

示例：这里是用 C 语言实现的基于链表的队列的简单实现：

```c
#include <stdio.h>
#include <stdlib.h>

// 定义链表节点结构
struct Node {
    int data;
    struct Node* next;
};

// 定义队列结构
struct Queue {
    struct Node* front;
    struct Node* rear;
};

// 创建新队列
struct Queue* createQueue() {
    struct Queue* queue = (struct Queue*)malloc(sizeof(struct Queue));
    queue->front = queue->rear = NULL;
    return queue;
}

// 检查队列是否为空
int isEmpty(struct Queue* queue) {
    return queue->front == NULL;
}

// 入队（向队列添加元素）
void enqueue(struct Queue* queue, int data) {
    // 创建新节点
    struct Node* new_node = (struct Node*)malloc(sizeof(struct Node));
    new_node->data = data;
    new_node->next = NULL;

    // 如果队列为空，将头部和尾部都指向新节点
    if (isEmpty(queue)) {
        queue->front = queue->rear = new_node;
    } else {
        // 在尾部添加新节点并更新尾部指针
        queue->rear->next = new_node;
        queue->rear = new_node;
    }
}

// 出队（从队列移除元素）
int dequeue(struct Queue* queue) {
    if (isEmpty(queue)) {
        printf("Queue is empty\n");
        return -1; // 或者任何其他错误处理指示
    }

    // 存储要返回的数据和要删除的节点
    int data = queue->front->data;
    struct Node* temp = queue->front;

    // 更新头部指针
    queue->front = queue->front->next;

    // 如果出队后队列为空，将头部和尾部都置为 NULL
    if (queue->front == NULL) {
        queue->rear = NULL;
    }

    // 释放被删除节点的内存
    free(temp);

    return data;
}

// 打印队列中的所有节点
void printQueue(struct Queue* queue) {
    if (isEmpty(queue)) {
        printf("Queue is empty\n");
        return;
    }
    struct Node* temp = queue->front;
    while (temp != NULL) {
        printf("%d ", temp->data);
        temp = temp->next;
    }
    printf("\n");
}

int main() {
    struct Queue* queue = createQueue();

    enqueue(queue, 10);
    enqueue(queue, 20);
    enqueue(queue, 30);

    printf("Queue elements: ");
    printQueue(queue);

    printf("Dequeued: %d\n", dequeue(queue));
    printf("Dequeued: %d\n", dequeue(queue));

    printf("Queue elements: ");
    printQueue(queue);

    return 0;
}
```

这段代码创建了一个空队列，插入了三个带有整数数据的节点，并在每个节点中插入了数据。然后弹出两个节点并再次打印队列的最终状态。

- 我们定义了 `Node` 和 `Queue` 结构。
- `createQueue()` 为新队列分配内存并将其头部和尾部指针初始化为 NULL。
- `isEmpty()` 函数检查头部指针是否为 NULL，这表示队列为空。
- `enqueue()` 函数创建一个新节点，添加数据元素，并通过更新尾部指针将其插入到队列末尾。
- `dequeue()` 函数检查队列是否为空，如果是则返回错误。否则，它存储要删除的数据，更新头部指针并释放被删除节点的内存。
- `main()` 函数演示了创建队列、入队元素以及出队。
