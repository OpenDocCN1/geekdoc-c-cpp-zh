作为开始，为我们的主主题建立一些背景是很好的。为此此，我们将回到过去，查看不使用任何现代 C++ 技术的代码。

在本章中，你将学习：

- 如何向标准库中的算法传递仿函数对象（functors）。
- 函数对象和函数指针的局限性。
- 为什么函数式助手不够用。
- C++0x/C++11 新功能的动机。

标准库的核心思想之一是，像 `std::sort`、`std::for_each`、`std::transform` 等算法可以接受任何可调用对象并在输入容器的元素上调用它。然而，在 C++98/03 中，我们只能使用函数指针或函数对象。

在 C++98/03 中，函数对象是一个重载了 `operator()` 的类。例如：

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

struct Count {
    int count = 0;
    void operator()() const {
        count++;
    }
};

int main() {
    std::vector<int> v(5);
    Count c;
    std::for_each(v.begin(), v.end(), c);
    std::cout << c.count << std::endl;
    return 0;
}
```

上面的示例使用了函数对象来计数元素。由于 `operator()` 是 `const` 成员，我必须使用 `mutable`：

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

struct Count {
    mutable int count = 0;
    void operator()() const {
        count++;
    }
};

int main() {
    std::vector<int> v(5);
    Count c;
    std::for_each(v.begin(), v.end(), c);
    std::cout << c.count << std::endl;
    return 0;
}
```
