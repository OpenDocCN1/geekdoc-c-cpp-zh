- 文件的平均值

## 第 2 步制定解决方案

解决此问题的算法非常直观，由以下伪代码描述：

```
main() 函数
  显示指示程序操作的消息。
  调用输入流函数。
  调用输出流函数。
  调用 Update 函数。
  显示 10 周的平均值。

输入流函数
  请求输入数据文件名。
  打开输入文件流并验证打开成功。

输出流函数
  请求输出数据文件名。
  打开输出文件流并验证打开成功。

Update 函数
  请求读取新的花粉计数。
  从输入数据文件中读取旧的花粉计数。
  对于剩余的输入文件花粉计数：
    读取输入值。
    将值加到总和。
    将输入值写入输出流。
  结束循环
  将新的花粉计数写入输出流。
  将新的花粉计数加到总和。
  计算平均值：总和 / 花粉计数数量。
  返回 10 周平均值。
  关闭所有文件。
```

回顾此算法时，注意旧的花粉计数被“捕获”在总和中，从未用于任何计算。最近的花粉计数被读取并写入输出数据文件。最后，最后一个花粉计数被添加到总和中，也被写入输出数据文件。最后，计算并显示最近的花粉计数的平均值，并关闭所有文件流。

// 以下函数读取花粉文件，
// 写入新文件，
// 并返回新的周平均值
double pollenUpdate(ifstream&inFile, ofstream&outFile)
{
    const int POLNUMS = 10; // 花粉计数的最大数量
    int i, polreading;
    int oldreading, newcount;
    double sum = 0;
    double average;

    // 获取最新的花粉读数
    cout << "Enter the latest pollen count reading: ";
    cin >> newcount;

    // 读取最旧的花粉读数
    inFile >> oldreading;

    // 读取、求和并写入剩余的花粉计数
    for(i=0; i < POLNUMS; i++)
    {
        inFile >> polreading;
        sum += polreading;
        outFile << polreading << endl;
    }

    // 写入最新的读数
    outFile << newcount << endl;

    // 计算并显示新的平均值
    average = (sum + newcount) / double(POLNUMS);
    inFile.close();
    outFile.close();
    cout << "\nThe output file has been written.\n";
    return average;
}
