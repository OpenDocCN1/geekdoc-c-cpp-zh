
如你所观察到的，上面的示例代码中发生了一些变化。`Cat`类中添加了一个方法，在`Animal`类中，该方法添加了`virtual`关键字。此外，`Cat`类中还存在`override`关键字。

在 C# 中，除非某个项被标记为`virtual`，否则无法重写任何类的任何项。通过`base`关键字的帮助，完全可以在该方法被重写后仍然继续访问被继承的方法。如下例所示。

```csharp
public override void Greet()
{
    base.Greet();
    Console.WriteLine("Yes! I am a cat!");
}
```

然而，方法并不是唯一可以继承的成员。事实上，类几乎所有的成员都会被继承。这包括属性和字段。你只需要确保使用正确的可见性（如前面的章节解释的那样），即可获得正确的结果。

另一个需要记住点是，继承不必发生在从一个类到另一个类之间。可以拥有一个相互继承的类层次结构。与之前的示例保持，可以创建一个继承自`Cat`类的`Kitten`类，而该类反过来将继承自`Animal`类。

然而，在 C# 中有一个无法执行的操作，那就是多继承。换句话说，你不能让一个类同时继承自多个类。C# 不支持这一特性。

## 理解基类和派生类的概念

一个类可以派生自多个基类。因此，可以从多个基类继承函数和数据。

下面是用于在 C# 中创建派生类的语法。

```csharp
<access-specifier> class <base_class>
{
...
}
class <derived_class> : <base_class>
{
...
}
```

让我们通过一个示例来更好地理解基类和派生类。在接下来的示例中，`Shape`是基类，而`Rectangle`是它的派生类。

```csharp
using System;
namespace InheritanceApplication
{
    class Shape
    {
        public void setWidth(int w)
        {
            width = w;
        }
        public void setHeight(int h)
        {
            height = h;
        }
        protected int width;
        protected int height;
    }
    // Derived class
    class Rectangle: Shape
    {
        public int getArea()
        {
            return (width * height);
        }
    }
    class RectangleTester
    {
        static void Main(string[] args)
        {
            Rectangle Rect = new Rectangle();
            Rect.setWidth(5);
            Rect.setHeight(7);
            // Print the area of the object.
            Console.WriteLine("Total area: {0}", Rect.getArea());
            Console.ReadKey();
        }
    }
}
```

执行上述显示的代码后，可以得到以下结果。

`Total area: 35`

## 基类的初始化

如你所知，派生类将继承基类的成员方法和成员变量。因此，在创建子类之前，有创建超类对象。超类的初始化指令可以在成员初始化列表中提供。

下面的示例说明了这一点。

```csharp
using System;
namespace RectangleApplication
{
    class Rectangle
    {
        protected double length;
        protected double width;
        public Rectangle(double l, double w)
        {
            length = l;
            width = w;
        }
        public double GetArea()
        {
            return length * width;
        }
        public void Display()
        {
            Console.WriteLine("Length: {0}", length);
            Console.WriteLine("Width: {0}", width);
            Console.WriteLine("Area: {0}", GetArea());
        }
    }
    class Tabletop : Rectangle
    {
        private double cost;
        public Tabletop(double l, double w) : base(l, w)
        { }
        public double GetCost()
        {
            double cost;
            cost = GetArea() * 70;
            return cost;
        }
        public void Display()
        {
            base.Display();
            Console.WriteLine("Cost: {0}", GetCost());
        }
    }
    class ExecuteRectangle
    {
        static void Main(string[] args)
        {
            Tabletop t = new Tabletop(4.5, 7.5);
            t.Display();
            Console.ReadLine();
        }
    }
}
```

在执行上述代码后，得到了以下结果。

`Length: 4.5`
`Width: 7.5`
`Area: 3362.5`

## C# 和多继承

C# 不支持多继承。另一方面，可以使用接口来实现多继承。接下来的示例演示了这一点。

```csharp
using System;
namespace InheritanceApplication
{
    class Shape
    {
        public void setWidth(int w)
        {
            width = w;
        }
        public void setHeight(int h)
        {
            height = h;
        }
        protected int width;
        protected int height;
    }
    // Base class PaintCost
    public interface PaintCost
    {
        int getCost(int area);
    }
    // Derived class
    class Rectangle : Shape, PaintCost
    {
        public int getArea()
        {
            return (width * height);
        }
        public int getCost(int area)
        {
            return area * 70;
        }
    }
    class RectangleTester
    {
        static void Main(string[] args)
        {
            Rectangle Rect = new Rectangle();
            Rect.setWidth(5);
            Rect.setHeight(7);
            // Print the area of the object.
            Console.WriteLine("Total area: {0}", Rect.getArea());
            Console.ReadKey();
        }
    }
}
```

执行上述显示的代码后，可以得到以下结果。

`Total area: 35`
`Cost: 2450`

# 第14章：构造函数和析构函数

在书中，你会遇到这两个术语。在这里，我们将查看它们。

## C# 中的构造函数

构造函数是类的一个特殊成员函数。每当创建该类的对象时，它就会执行。构造函数的名称与类名完全相同。构造函数没有返回类型。接下来的示例展示了构造函数。

```csharp
using System;
namespace InheritanceApplication
{
    class Line
    {
        private double length;
        public Line()
        {
            Console.WriteLine("Object is created");
        }
        public void setLength(double len)
        {
            length = len;
        }
        public double getLength()
        {
            return length;
        }
        static void Main(string[] args)
        {
            Line line = new Line();
            line.setLength(6);
            Console.WriteLine("Length of line: {0}", line.getLength());
            Console.ReadKey();
        }
    }
}
```

执行上述代码后，可以得到以下结果。

`Object is created`
`Length of line: 6`

## 参数化构造函数

默认情况下，构造函数没有任何参数。尽管如此，你可以为构造函数添加参数。这些构造被称为参数化构造函数。通过这种技术，你可以在创建特定对象时为其分配初始值。

下面的示例将向你展示如何操作。

```csharp
using System;
namespace InheritanceApplication
{
    class Line
    {
        private double length;
        public Line(double len)
        {
            Console.WriteLine("Object is created, length = {0}", len);
            length = len;
        }
        public void setLength(double len)
        {
            length = len;
        }
        public double getLength()
        {
            return length;
        }
        static void Main(string[] args)
        {
            Line line = new Line(10.0);
            line.setLength(6.0);
            Console.WriteLine("Length of line: {0}", line.getLength());
            Console.ReadKey();
        }
    }
}
```

## C# 中的析构函数

与构造函数一样，析构函数也是类的一个特殊成员函数。然而，它仅当类的某个对象离开其指定范围时才会执行。析构函数的名称与类名完全相同，但它前面会带有一个波浪号`~`。析构函数无法返回值或接受任何参数。析构函数非常有用，因为它们可以在程序退出之前释放内存资源。析构函数无法被继承。

```csharp
namespace LineApplication
{
    class Line
    {
        private double length;
        public Line()
        {
            Console.WriteLine("Object is being created");
        }
        ~Line()
        {
            Console.WriteLine("Object is being deleted");
        }
        public void setLength(double len)
        {
            length = len;
        }
        public double getLength()
        {
            return length;
        }
        static void Main(string[] args)
        {
            Line line = new Line();
            line.setLength(6.0);
            Console.WriteLine("Length of line : {0}", line.getLength());
        }
    }
}
```

执行上述示例中的代码后，产生的运行如下：

`Object is being created`
`Length of line : 6`
`Object is being deleted`

现在你知道什么是构造函数和析构函数了。当你开始编写复杂的程序时，你一定会发现它们非常有用。因此，请确保你对它们有彻底的理解。

# 第 15 章：学习更多关于 C#

有几个概念是你应该尽早熟悉的。它们将对你以后开发 C# 程序非常有帮助。

## 接口简介

接口可以定义为一种语法合约，所有继承该接口的类都必须遵循该合约。接口将定义合约中的“做什么”部分。派生类将定义语法合约中的“如何做”部分。

接口将定义其成员的方法、属性和事件。另一个需要注意的点是，接口仅包含成员的声明。定义成员的责任交给了派生类。因此，它确保了可以供派生类遵循的标准结构。

## 声明接口

可以使用`interface`关键字声明接口。事实上，它与类的声明有相似之处。默认情况下，接口语句是公共`public`。下面的示例演示了如何声明接口。

```csharp
public interface ITransactions
{
    void showTransaction();
    double getAmount();
}
```

现在让我们通过一个例子来理解如何实现上述接口。

```csharp
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System;
namespace InterfaceApplication
{
    public interface ITransactions
    {
        void showTransaction();
        double getAmount();
    }
    public class Transaction : ITransactions
    {
        private string tCode;
        private string date;
        private double amount;
        public Transaction()
        {
            tCode = "";
            date = "";
            amount = 0.0;
        }
        public Transaction(string c, string d, double a)
        {
            tCode = c;
            date = d;
            amount = a;
        }
        public double getAmount()
        {
            return amount;
        }
        public void showTransaction()
        {
            Console.WriteLine("Transaction: {0}", tCode);
            Console.WriteLine("Date: {0}", date);
            Console.WriteLine("Amount: {0}", getAmount());
        }
        class Tester
        {
            static void Main(string[] args)
            {
                Transaction t1 = new Transaction("001", "8/10/2012", 78900.00);
                Transaction t2 = new Transaction("002", "9/10/2012", 451900.00);
                t1.showTransaction();
                t2.showTransaction();
                Console.ReadKey();
            }
        }
    }
}
```
