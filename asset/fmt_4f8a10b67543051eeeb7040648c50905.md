**Q 4. 当我运行题目给出的语句时，无法得到 4 个选项中的任何一个作为输出？**

答：建议你将预期输出的语句在 IDLE File Editor 中保存为程序（除非另有说明），只有当它运行符合预期时，再在 IDLE shell 中尝试（一次执行一条语句）。某些语句仅在 File Editor 中有效，而某些语句仅在 IDLE shell 中有效。在少数情况下，可能是因为你使用的 Python 版本和操作系统的原因，因为某些问题可能会产生特定平台的输出。

**Q 5. 当我运行题目给出的语句时，输出顺序不同，或与给定的答案不完全一致？**

答：这是因为某些语句和函数会产生随机输出或无序的项目列表。在这种情况下，你可以根据你对 Python 的理解，选择最可能的答案。

答：解决这些问题的最佳方法是准备笔（或铅笔）和纸，逐一尝试。
