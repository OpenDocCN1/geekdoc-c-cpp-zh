无限循环是一种无法隐式终止的循环。无限循环可用于您希望语句或一组语句被执行无限次的情况。在无限循环中，您无需指定终止条件。让我们创建一个名为`MyInfiniteLoop`的控制台应用程序（也在 CD 上提供），它展示了如何创建无限循环。清单 3.10 显示了`MyInfiniteLoop`应用程序的代码：

## 使用 goto 语句

`goto`语句允许程序控制从一个点转移到另一个点。程序控制的转移基于带标签的语句。让我们创建一个名为`MyLabeledStatement`的控制台应用程序（也在 CD 上提供）来展示`goto`语句的使用。清单 3.11 显示了`MyLabeledStatement`应用程序的代码：

### 清单 3.11：显示`MyLabeledStatement`应用程序的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace MyLabeledStatement
{
    class Program
    {
        static void Main(string[] args)
        {
            int x = 100, y = 4;
            int count = 0;
            string[,] myArray = new string[x, y];

            // Initialize the array:
            for (int i = 0; i < x; i++)
                for (int j = 0; j < y; j++)
                    myArray[i, j] = (++count).ToString();

            // Read input:
            Console.Write("Enter the Number to Search for:");

            // Input a string:
            string myNumber = Console.ReadLine();

            // Search:
            for (int i = 0; i < x; i++)
                for (int j = 0; j < y; j++)
                    if (myArray[i, j].Equals(myNumber))
                        goto Found;

            Console.WriteLine("The Number {0} is not Found.", myNumber);
}

goto Finish;

Found:
    Console.WriteLine("The Number {0} is Found.", myNumber);

Finish:
    Console.WriteLine("End of Search.");
    Console.Write("\nPress ENTER to quit...");
    Console.ReadLine();
}
```

在列表 3.11 中，我们创建了一个二维数组`myArray`，其中包含从 1 到 400 的数字。接下来，我们声明了`myNumber`变量，该变量在运行时从用户处获取输入。用户输入的数字基于`for`循环在`myArray`数组中进行搜索。如果在数组中找到该数字，`goto`语句会跳转到`Found`标签。否则，如果输入的数字未找到，`goto`语句会跳转到`Finish`标签。

## 终止循环

在使用程序中的循环时，有时需要在循环内部执行的任务尚未完成时就中断循环。您可以使用以下三种方法中的任何一种来中断循环：

- 使用`break`语句立即终止循环

- 使用次要条件，例如跳转到标签以中断循环的`goto`语句

- 通过处理所需数量的元素或更改变量的状态来终止循环

让我们创建一个名为`MyBreakLoop`的控制台应用程序（也在 CD 上提供），以展示三种不同的中断循环示例。列表 3.12 显示了`MyBreakLoop`应用程序的代码：

### 列表 3.12：显示`MyBreakLoop`应用程序的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace MyBreakLoop
{
    class Program
    {
        static void Main(string[] args)
        {
            // How to break out of a for loop, two ways.
            Console.WriteLine("Loop 1:");
            for (int i = 0; i < 5; ++i)
            {
                if (i == 3)
                    break;
                Console.WriteLine("I = {0}", i);
            }
            Boolean done = false;
            Console.WriteLine("\nLoop 2:");
            for (int i = 0; i < 5 && done == false; ++i)
{
    if (i == 2)
        done = true;
    Console.WriteLine("I = {0}", i);
}
// Another method using a goto
done = false;
int counter = 0;
Console.WriteLine("\nLoop 3:");
do
{
    if (counter == 5)
        goto handle_done;
    Console.WriteLine("Counter: {0}", counter);
    counter++;
    goto not_done;

handle_done:
    done = true;
not_done:
    Console.WriteLine("End of Loop 3");
}
while (!done);
Console.WriteLine("\nLoop 4:");
for (int i = 0; i < 5; ++i)
{
    if (i == 2)
        i = 5;

} }
```

在列表 3.12 中，我们使用了三种不同的方式退出循环。在第一种方式中，我们使用`break`语句从`for`循环中退出。在第二种方式中，我们使用`goto`语句退出`do...while`循环。在第三种方式中，我们重新初始化变量`i`以退出循环。

## 使用 continue 语句

`continue`语句用于将程序控制转移到循环的开头。它会继续转移程序控制，直到满足某个条件。让我们创建一个名为`MyContinueStatement`的控制台应用程序（也在 CD 上提供）来展示`continue`语句的使用。列表 3.13 显示了`MyContinueStatement`应用程序的代码：

### 列表 3.13：显示`MyContinueStatement`应用程序的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace MyContinueStatement
{
    class Program
    {
        static void Main(string[] args)
        {
            int number = 1;
            while (true)
            {
                Console.WriteLine(number);
                number++;
                if (number <= 10)
                    continue;
                else
                    break;
            }
            Console.WriteLine("Series is breaked at number: " + number);
            Console.Write("\nPress ENTER to quit...");
            Console.ReadLine();
        }
    }
}
```

在列表 3.13 中，`while`循环只要条件为真就会执行。在`while`循环内部，`if`语句检查输入的数字是否小于 10 并将程序控制转移到`continue`语句。`continue`语句反过来只要条件满足就会将程序控制转移到循环的开头。如果条件不满足，程序控制就会转移到`else`块并中断循环。
