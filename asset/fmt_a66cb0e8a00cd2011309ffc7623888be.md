
```csharp
FileStream F = new FileStream("test.txt", FileMode.OpenOrCreate, FileAccess.ReadWrite);
}
}
```

我们使用了相同的 `Program` 类并创建了 `Main` 方法。然后我们使用 `FileStream` 类打开文件。在示例中，我们再次使用 `OpenOrCreate` 文件模式来告诉编译器，如果文件可用则打开它。如果不可用，则即时创建文件。我们创建的文件名与我们在上一节中创建的文件名相同。

现在让我们添加向文件写入数据的代码，因为此时文件是空的。

```csharp
class Program
{
    static void Main(string[] args)
    {
        FileStream F = new FileStream("test.txt", FileMode.OpenOrCreate, FileAccess.ReadWrite);
        for (int i = 1; i <= 20; i++)
        {
            F.WriteByte((byte)i);
        }
    }
}
```

上面的代码是一个名为 `Program` 的程序的类。`Main` 方法包含了将数据写入文件的代码。这是一个简单的循环，只从 1 循环到 20，并将这些数字写入文件。

第一行代码是 `FileStream` 类，被实例化并赋值给名为 `F` 的变量。第一个参数是你想要存储数据的文件。我们只是简单将数据存储在名为 `test.txt` 的文件中。由于我们没有指定位置，文件将直接存储在程序运行的目录中。

下一个参数是文件模式。`FileMode` 是我们在书中之前见过的一个枚举。该枚举有几种文件模式，可以在创建文件或仅读取文件时使用。在示例中，我们使用了 `OpenOrCreate`。这种文件模式告诉编译器打开文件，但如果文件尚未创建或未找到，则在从其读取之前创建文件。

第三个枚举是 `FileAccess` 枚举。你可以从文件读取、写入文件，或者同时读取和写入文件。因为我们只想写入文件，所以我们需要指定我们只想写入文件。你可以将文件访问设置为读取和写写，但通常的标准是仅根据执行任务时所需的访问权限来设置文件访问。

代码的最后部分将数据写入文件。我们使用 `for` 循环写入从 1 到 20 的数据。注意，我们在将其写入文件之前，显式地将数值值转换为 `byte`。这样做是因为数据是写入文件的，而不是原始数据写入。在将数据写入文件之前，你需要将你的数据转换为 `byte`。在程序中向文件写入自己的数据时，请记住这一点。

我们使用 `WriteByte` 方法将数据写入文件。最后使用的一行代码是 `Close` 方法。如果你不关闭文件，在重启系统之前，你将无法在后续操作中使用它。操作系统会在你打开文件时对文件加锁。你只能以只读模式访问该文件。为了避免这种情况，你需要在代码中每个打开文件的部分都关闭文件。你也无法在任何其他程序中打开它，因此请确保在打开文件的方法的最后始终使用 `Close` 方法。

## 删除文件

你不仅需要创建、读取和写入文件，有时你可能还需要删除文件。坦率地说，.NET 框架删除文件和创建和处理文件数据一样简单。

删除文件甚至比执行其他过程更简单。你使用一个不同的类来删除文件。`FileStream` 严格用于读取和写入文件，但该类是一个执行短、快速任务的静态类。在这种情况下，我们需要删除一个文件，这不需要复杂的代码。

让我们看看从硬盘删除文件的代码看起来是什么样的。

```csharp
if(File.Exists(@"C:\test.txt"))

    File.Delete(@"C:\test.txt");
```

访问文件的账户需要正确的权限，否则在处理本地文件时将收到“拒绝访问”的错误。你可以在代码中进行错误捕获和修正时测试这些权限。在接下来的章节中，我们将展示如何进行错误检查和错误捕获。

## 第 13 章
多线程

**目标：** 多线程允许你在 CPU 内部同时运行多个操作。

在你的程序执行完成之前，多线程不需要等待。如果你的程序有数千次循环，这可能花费几秒钟。然而，在你的程序执行完成之前，用户不需要等待。本章节展示了如何在 C# 中设置多线程。

### 为什么要使用多线程

多线程允许你同时运行多个操作。当你需要处理数据时，多线程可以返回结果。当你有大量数据需要处理时，用户不需要等待。

多线程允许用户在程序完成之前执行任何操作。这是一种创建线程的易用方法。多线程会创建包含代码的线程。

### 在你的 C# 程序中创建线程

一旦你确定程序中需要多线程，你首先需要创建一个包含代码的函数。首先，让我们看看你用于创建线程的代码。

```csharp
class ThreadExample
{
    static void Main(string[] args)
    {
        Thread th = Thread.CurrentThread;
        th.Name = "My Thread";
        Console.WriteLine("这是 {0}", th.Name);
    }
}
```
