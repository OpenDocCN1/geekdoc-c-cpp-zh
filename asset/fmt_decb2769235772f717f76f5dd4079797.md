
注意我们向 `MyGeneric` 类添加了一个方法。我们保留了相同的属性和构造函数。我们添加了 `setItem` 方法。记住，方法是类的“动词”，所以这个方法向数组添加一个值。它接收数组的索引以标识你想放置值的位置，并使用 `T` 标记告诉编译器可以使用任何泛型数据类型。然后 `setItem` 方法将泛型数据类型分配给数组中的位置。

设置好 `setItem` 方法后，你现在需要从数组中检索值。让我们来看 `MyGeneric` 类中的新方法，它可以允许你从泛型数组中检索值。

```csharp
public class MyGeneric<T>
{
    private T[] array;
    public MyGeneric(int size)
    {
        array = new T[size + 1];
    }
    public T getItem(int index)
    {
        return array[index];
    }
    public void setItem(int index, T value)
    {
        array[index] = value;
    }
}
```

这是一个可以使用泛型工作的完整类。我们添加了从数组中检索信息的 `getItem` 方法。这就是你可以在程序中创建的泛型类的完成。

文件 I/O

**目标：** 在某个时刻，你需要将数据写入文件。本章将重点讨论如何在 C# 中读取和写入文件数据。

并不是你所有的程序都会使用文件，但你可能会遇到一些网站或控制台应用程序，要求你从文件中读取或写入。大多数 Windows 应用程序使用某种文件 I/O 过程来读取或写入文件，以存储用户数据或偏好。在本章中，我们将讨论如何使用系统自带的 C#.NET 框架库读取和写入文件数据。

## 写入文件

你需要知道的文件操作中最简单且最常用的方法之一是读取其数据。你读取数据出于很多原因，包括导入数据、导入用户偏好、导入表格数据以存储在数据库中，以及其他许多原因。你可以读取预定义的格式化数据，例如逗号分隔的文件或存储其中的纯文本文件。

C# 语言和 .NET 库框架使得将数据存储在文件中比其他语言要简单得多。.NET 语言包含了 `FileStream` 类，它可以帮助你写入文件。它需要几个参数才能运行，但你只需要几行代码就能将数据写入文件。让我们来看看可以实现操作的代码。

```csharp
class Program
{
    static void Main(string[] args)
    {
        FileStream F = new FileStream("test.txt", FileMode.OpenOrCreate, FileAccess.Write);
        for (int i = 1; i <= 20; i++)
        {
            F.WriteByte((byte)i);
        }
        F.Close();
    }
}
```

上面的代码是一个名为 `Program` 的程序的类。`Main` 方法包含了将数据写入文件的代码。这是一个简单的循环，只从 1 循环到 20，并将这些数字写入文件。

第一行代码是 `FileStream` 类，被实例化并赋值给名为 `F` 的变量。第一个参数是你想要存储数据的文件。我们只是简单将数据存储在名为 `test.txt` 的文件中。由于我们没有指定位置，文件将直接存储在程序运行的目录中。

下一个参数是文件模式。`FileMode` 是我们在书中之前见过的一个枚举。该枚举有几种文件模式，可以在创建文件或仅读取文件时使用。在示例中，我们使用了 `OpenOrCreate`。这种文件模式告诉编译器打开文件，但如果文件尚未创建或未找到，则在从其读取之前创建文件。

第三个枚举是 `FileAccess` 枚举。你可以从文件读取、写入文件，或者同时读取和写入文件。因为我们只想写入文件，所以我们需要指定我们只想写入文件。你可以将文件访问设置为读取和写写，但通常的标准是仅根据执行任务时所需的访问权限来设置文件访问。

代码的最后部分将数据写入文件。我们使用 `for` 循环写入从 1 到 20 的数据。注意，我们在将其写入文件之前，显式地将数值值转换为 `byte`。这样做是因为数据是写入文件的，而不是原始数据写入。在将数据写入文件之前，你需要将你的数据转换为 `byte`。在程序中向文件写入自己的数据时，请记住这一点。

我们使用 `WriteByte` 方法将数据写入文件。最后使用的一行代码是 `Close` 方法。如果你不关闭文件，在重启系统之前，你将无法在后续操作中使用它。操作系统会在你打开文件时对文件加锁。你只能以只读模式访问该文件。为了避免这种情况，你需要在代码中每个打开文件的部分都关闭文件。你也无法在任何其他程序中打开它，因此请确保在打开文件的方法的最后始终使用 `Close` 方法。
