
### 命名和可选参数

在 `C# 2010` 中，您可以使用命名和可选参数调用类的`<|message|>`方法。这些参数被声明为普通参数，唯一的区别是它们已用默认值初始化。如果您未为可选参数提供值，它将调用其默认值。您可以通过手动调用其名称并传递值来手动调用命名参数。

以下代码片段显示了可选和命名参数的示例：

```
static string Info(string name, string email = "kogent@xxx.com", string phone="0000000")
{
string msg = name + "\t" + email+"\t"+phone;
return msg;
}
static void Main(string[] args)
{
System.Console.WriteLine(Info("Charu")); //Line 1: Optional parameters are calling
System.Console.WriteLine(Info("Charu","charu@xxx.com")); //Line 2: Optional parameters are calling
System.Console.WriteLine(Info("Charu", phone: "8568487")); //Line 3: Named parameters are calling
}
```

在前面的代码片段中，一个名为 `Info` 的方法接收三个参数：`name`、`email` 和 `phone`。`email` 和 `phone` 参数具有默认值，可作为可选参数工作。注释为 `Line 1` 的行仅传递 `name` 参数的值；但是，其输出显示为：

```
Charu    kogent@xxx.com    0000000
```

`email` 和 `phone` 是可选参数，其值可以提供也可以不提供。在下一行注释为 `Line 2` 的行中，传递了 `name` 和 `email` 参数的值。`Line 2` 的输出如下：

```
Charu    charu@xxx.com    0000000
```

在前面的示例中，电话号码是可选参数并显示其默认值，而为 `name` 和 `email` 参数提供了值。现在，在最后注释为 `Line 3` 的行中，传递了 `name` 和 `phone` 参数的值。`Line 3` 的输出如下：

```
Charu    kogent@xxx.com    8568487
```

前面的输出显示了 `email` 的默认值并提供了 `name` 和 `phone` 参数的值。在这种情况下，`name` 参数是强制性的，`email` 是可选的，`phone` 是命名参数。

### COM Interop 编程中使用索引属性

在 `C#` 的早期版本中，只有在满足以下条件时才能将方法作为属性访问：

- `set` 方法必须有且只有一个值参数

然而，并非所有 COM 属性都满足前述条件。例如，`Excel.Range` 属性的 `get` 访问器需要范围参数。要访问 `Excel.Range` 属性，你需要使用以下代码片段中的 `get_Range()` 方法：

```
var newexcelApp = new Excel.Application();
...
Excel.Range rangeinexcel = newexcelApp.get_Range("A1", Type.Missing);
```

在 `C# 2010` 中，你可以访问 `Excel.Range` 的 `Range` 属性，如下面的代码片段所示：

```
var newexcelApp = new Excel.Application();
// ...
Excel.Range rangeinexcel = newexcelApp.Range["A1"];
```

要为 `Excel.Range` 对象的 `Value` 属性赋值，需要提供两个参数。为此，你需要使用 `set_Value()` 方法或另一个属性 `Value2`。以下代码片段演示了如何为 `Range` 对象的 `Value` 属性赋值：

```
rangeinexcel.set_Value(Type.Missing, "Range_Name");
// Or
rangeinexcel.Value2 = "Range_Name";
```

还可以按如下方式设置 `Excel.Range` 对象的 `Value` 属性值：

```
rangeinexcel.Value = "Range_Name";
```

上述代码片段演示了如何使用索引参数设置 `Value` 属性值。

`C# 2010` 集成了一组协调技术，有助于降低开发、部署和管理应用程序的复杂性。这些技术有助于构建稳定且安全的网站。本书将讨论以下与 `C# 2010` 相关的技术：

### WPF

`WPF` 技术支持多种媒体，例如文本、图像、音频和视频，并允许你处理二维（2-D）以及三维（3-D）图形。`WPF` 应用程序中与设计相关的所有元素均由 `DirectX` 处理。`WPF` 支持 `XAML` 语言，该语言允许设计人员轻松快速地定义应用程序 UI 的元素。然后，应用程序开发人员可以使用通过 `XAML` 定义的 UI 元素，在代码隐藏文件中以任何 `.NET` 语言（如 `C#`）指定应用程序逻辑。

第 9 章“介绍 Windows Presentation Foundation”描述了 `WPF` 的体系结构、类层次结构和应用程序模型。在本章中，你还将学习如何在 `WPF` 中使用 `XAML`、`WPF` 属性和 `WPF` 事件。

`LINQ` 是 `.NET Framework 4.0` 的一个组件。`LINQ` 的基本功能是使用类似于 SQL 的语法向 `.NET Framework` 添加本机数据查询功能。`LINQ` 允许你定义语句来查询数据源，以生成所需的结果集。此外，它还允许你以一致的方式获取和操作数据。

第 27 章“LINQ 查询”讨论了基本的 `LINQ` 查询以及用于从数据源查询数据的查询运算符。你还将学习如何从各种数据源（如 `LINQ to Object`、`LINQ to ADO.NET` 和 `LINQ to XML`）检索数据。

### ADO.NET Entity Framework

`ADO.NET Entity Framework` 旨在支持以数据为中心的应用程序和服务，并提供了一个针对数据进行编程的平台，该平台将抽象级别从逻辑关系级别提升到概念级别。

第 22 章“ADO.NET Entity Framework”讨论了 `Entity Framework` 支持的功能和组件，例如 `Entity Data Model`、`Object Services`、`Entity SQL`、`Client provider` 以及概念架构和存储架构之间的映射。

### ASP.NET AJAX

`ASP.NET AJAX` 是一种基于页面更新而非页面替换概念的方法。`ASP.NET AJAX` 向开发人员提供了两种构建富 Web 应用程序的方式：以服务器为中心和以客户端为中心。以服务器为中心的开发方法允许刷新网页的一部分，而无需将整个页面回发到服务器。这是通过使用 `UpdatePanel` 服务器控件实现的。以客户端为中心的方法允许开发人员使用控件扩展器向新的和现有的 `ASP.NET` 控件添加预定义的客户端行为。扩展器使用一段 JavaScript 代码为 `ASP.NET` 添加新的和增强的功能。

`Web 服务`是一个实体，可以通过编程方式在 Internet 上向任意数量的应用程序提供特定功能。`Web 服务`提供的功能可以被任何应用程序使用，无论该应用程序使用何种编程语言创建，也无论其运行在何种硬件平台和操作系统上。`Web 服务`没有任何用户界面。它只是向其使用者提供特定服务。

标识符是用户为了识别程序中的各种元素（如变量、常量和属性）而指定的名称。而关键字是预定义的词语，被保留用于执行特定任务。在创建 `C#` 应用程序时，你可以使用变量来存储某种类型的值。这些变量的值会随着程序的每次执行而变化。另一方面，常量与变量类似，但分配给常量的值不能更改。表达式是一组语言元素的组合，通过使用不同的运算符（例如算术运算符和逻辑运算符）来执行特定任务或计算。

## 标识符和关键字

在 `C#` 中，标识符是赋予变量、常量或任何用户定义的编程元素的名称。标识符以字母或下划线开头，以字符结尾。`C#` 标识符区分大小写；这意味着变量名 `sum`、`Sum` 和 `SUM` 三者互不相同。对于标识符的命名约定，Microsoft 建议使用匈牙利命名法和 CamelBack 命名法。它表示标识符以首字母小写开头，随后标识符中的后续单词以大写字母开头，例如 `myFirstProgram`。

创建标识符时，你必须记住以下规则：

- 标识符必须以字母或下划线（`_`）开头
- 标识符可以包含字母、数字和下划线
- 标识符不能是保留字（`C#` 中的关键字）
- 标识符必须是完整的单词，不能包含任何空格

现在让我们来了解 `C#` 中的关键字。
