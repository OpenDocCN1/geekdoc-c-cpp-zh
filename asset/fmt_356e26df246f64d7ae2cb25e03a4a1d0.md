
在上述转换为浮点的（强制转换中，使用 `(cast) x` 可以替换为 `(cast) round(x)`, `(cast) rist(x)`, `(cast) nearbyint(x)`, `(cast) trunc(x)`, `(cast) ceil(x)` 或 `(cast) floor(x)`。此外，C 的浮点到整数转换函数 `lrint(x)`, `llrint(x)`, `lround(x)` 和 `llround(x)` 可以使用。它们都满足 LIA–1 对范围内值的浮点到整数舍入的要求。对于范围外值，转换对于取模类型应静默取回。

`fmod(x)` 函数适用于符号环到无符号整数类型，例如，`fmod(fabs(x), 65536.0)` 或 `(0.0 <= (y = fmod(rint(x), 65536.0)) ? y : 65536.0 + y)` 会计算 0 到 65535.0 之间的整数值，可以转换为 `unsigned short int`。但，`remainder(x)` 函数不适用于符号环到有符号整数类型，例如，`remainder(rint(x), 65536.0)` 会计算 -32767.0 到 +32768.0 之间的整数值，这通常不在有符号 `short int` 的范围内。

## H.3 通知 (Notification)

通知是告知用户或程序发生了异常算术操作的过程。C 语言的操作与 LIA–1 兼容，这是因为 C 允许实现在当任何算术运算返回 LIA–1 第 5 节定义的异常值时，创建一个发生触发的通知。

### H.3.1 通知的替代方案

- LIA–1 要求至少提供以下两种处理通知的替代方案：设置指示器（indicators）或陷获并终止（trap-and-terminate）。LIA–1 允许第三种替代方案：陷获并恢复（trap-and-resume）。
- 实现仅需对整个程序支持给定的通知替代方案。实现可以支持在执行期间切换不同通知替代方案的能力，但并不要求这样做。实现可以为每种类型的通知提供单独的选择，但这并非强制要求。
- C 允许实现提供通知。C 的 `SIGFPE`（针对陷阱）以及 `FE_INVALID`、`FE_DIVBYZERO`、`FE_OVERFLOW`、`FE_UNDERFLOW`（针对指示器）可以提供 LIA–1 通知。
- C 的信号处理程序与 LIA–1 兼容。`SIGFPE` 的默认处理可以提供陷获并终止的行为，但通过数学库函数调用实现的 LIA–1 操作除外。用户提供的 `SIGFPE` 信号处理程序允许在相同约束下实现陷获并恢复的行为。

#### H.3.1.1 指示器 (Indicators)

- C 的 `<fenv.h>` 状态标志与 LIA–1 指示器兼容。

以下映射适用于浮点类型：

| 类型 | 指示器 |
| :--- | :--- |
| undefined | `FE_INVALID`, `FE_DIVBYZERO` |
| floating_overflow | `FE_OVERFLOW` |
| underflow | `FE_UNDERFLOW` |

- 浮点指示器的查询和处理操作为：

`set_indicators feraisecept(i)`
`clear_indicators flecleareexcept(i)`
`test_indicators fetestexcept(i)`
`current_indicators fetestexcept(FE_ALL_EXCEPT)`

其中 `i` 是一个 `int` 类型的表达式，表示 LIA–1 指示器的子集。

C 允许实现提供以下 LIA–1 要求的行为：如果设置了任何指示器，实现应发送一条含义明确且“难以忽视”的消息（见 LIA–1 子节 6.1.2）。

LIA–1 未区分“undefined”（未定义）是浮点还是整数。本文对此进行了这种区分，是因为 `<fenv.h>` 仅涵盖了浮点指示器。

#### H.3.1.2 陷阱 (Traps)

- C 与 LIA–1 算术运算的陷阱要求兼容，但对于数学库函数例外（这些函数不允许调用用户的 `SIGFPE` 信号处理程序）。实现可以提供一种带有“难以忽视”消息的通知终止的替代方案（见 LIA–1 子节 6.1.3）。
- LIA–1 不要求陷阱是精确的（precise）。
- C 要求如果为 LIA–1 算术异常提高了任何信号，则 `SIGFPE` 必须是相应的信号。
- C 支持 `SIGFPE` 的信号处理程序并允许对 LIA–1 算术异常进行陷获。当 LIA–1 算术异常触发陷阱时，C 的信号处理机制允许根据程序员的选择执行陷获并终止（默认实现行为或用户的替换）或陷获并恢复。
