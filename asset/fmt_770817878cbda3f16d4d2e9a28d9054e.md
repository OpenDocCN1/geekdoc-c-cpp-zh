### Using Impersonation in ASP.NET Applications

ASP.NET 中的模拟是一个过程，其中 ASP.NET 应用程序冒充匿名或经过身份验证的用户以访问 Web 服务器上的资源。当 ASP.NET 应用程序运行的帐户（IIS 7.5 中默认为 NETWORK SERVICE）没有访问该资源所需的权限时，模拟很有帮助。应用程序可以通过模拟具有必要权限的 Windows 用户来访问该资源。在 ASP.NET 中，您可以通过 `web.config` 文件或通过使用 `WindowsIdentity.Impersonate()` 方法通过代码实现模拟。现在，让我们演示

```
DirectoryInfo directory = new DirectoryInfo(@"D:\MyFolder");
FileInfo[] files = directory.GetFiles("*.*");
foreach (FileInfo f in files)
{
    ListBox1.Items.Add(f.FullName);
}
}
```

在前面的代码中，添加了对 `System.IO` 和 `System.Security.Principal` 命名空间的指令。在 `Page_Load()` 方法中，`HttpContext.Current.User.Identity.Name` 属性的值显示在 `Label1` 中。当用户点击 `Button1` 时，`Label2` 显示模拟的帐户，即 ImpersonationCS 应用程序运行的帐户。该帐户从 `WindowsIdentity` 对象返回的 `Name` 属性中检索，该对象由 `WindowsIdentity.GetCurrent()` 方法返回。`GetCurrent()` 方法返回当前 Windows 用户。`DirectoryInfo` 和 `FileInfo` 类用于检索并显示 `MyFolder` 文件夹中的文件名称。文件名显示在 `ListBox1` 中。

3. 打开 Impersonation 应用程序中的 `web.config` 文件以在 `web.config` 文件中启用模拟。在 `<system.web>` 元素中添加以下代码：

   `<identity impersonate="true"/>`

在此代码中，`<identity>` 元素被添加到 `web.config` 文件中。`<identity>` 元素的 `impersonate` 属性设置为 `true`，允许应用程序模拟 Windows 用户。应用程序模拟的 Windows 用户在运行时确定，即当用户在 IIS 中通过身份验证时。要在 IIS 中配置模拟，请打开 IIS 管理器，在连接窗格中选择 Impersonation 应用程序，然后在中间窗格中双击身份验证功能选项。现在，确保已启用 ASP.NET 模拟选项。如果 `web.config` 文件中已启用模拟，则此选项可能会自动启用。现在，让我们使用 IIS 中的匿名身份验证并查看模拟如何进行。
