
## 21.2 辛普森法则

### 示例 21.6 辛普森 3/8 法

**问题陈述。**

- (a) 使用辛普森 3/8 法对 $f(x) = 0.2 + 25x - 200x^2 + 675x^3 - 900x^4 + 400x^5$ 从 $a = 0$ 到 $b = 0.8$ 进行积分。
- (b) 结合辛普森 1/3 法对同一函数进行五个段积分。

**解法。**

- (a) 单次应用辛普森 3/8 法需要四个等间距的点：

```
$f(0) = 0.2 \quad f(0.2667) = 1.432724$
$f(0.5333) = 3.487177 \quad f(0.8) = 0.2332$
```

使用公式 (21.20)，

```
$I = \frac{0.2 + 3(1.432724 + 3.487177) + 0.2332}{8} \times 0.8 = 1.519170$
$E_t = 1.640533 - 1.519170 = 0.121363 \quad \epsilon_t = 7.4\%$
$E_a = \frac{(0.8)^5}{6480}(-2400) = -0.121363$
```

- (b) 五段应用所需的数据（$h = 0.16$）为：

| $x$ | $f(x)$ |
| :--- | :--- |
| 0 | 0.2 |
| 0.16 | 1.296919 |
| 0.32 | 1.743393 |
| 0.48 | 3.186015 |
| 0.64 | 3.118129 |
| 0.80 | 0.2332 |

前三段的积分使用辛普森 1/3 法得到：

```
$I = \frac{0.16}{3} [0.2 + 4(1.296919) + 1.743393] = 0.3803237$
```

对于最后三段，可以使用 3/8 法得到：

```
$I = \frac{3 \times 0.16}{8} [1.743393 + 3(3.186015) + 3(3.118129) + 0.2332] = 1.264754$
```

总积分通过相加结果计算：

```
$I = 0.3803237 + 1.264754 = 1.6450777$
$E_t = 1.640533 - 1.6450777 = -0.0045447 \quad \epsilon_t = -0.28\%$
```

### 21.2.5 高阶牛顿-科特公式

## 21.3 不均匀分段积分

到目前为止，所有的数值积分公式都是基于等间距点的。在实践中，有很多这种假设不成立的情况。对于这些情况，必须调整梯形法则来处理不均匀分段。例如，对于这类实验得的数据，我们必须调整梯形法则为：

```
$I = h_1\frac{f(x_0) + f(x_1)}{2} + h_2\frac{f(x_1) + f(x_2)}{2} + \dots + h_n\frac{f(x_{n-1}) + f(x_n)}{2}$
```

$h_i$ 是第 $i$ 段的宽度。注意这种方法被用于合并项。这种简化方法不能应用于不均匀分段。

### 示例 21.8 在对不均匀数据的评估中引入辛普森法则

**问题描述。** 重新计算表 21.3 中数据的积分，但在适用于辛普森法则的段上使用该法则。

**解。** 第一个段使用梯形法进行评估：

```
$I = \frac{0.12}{2} (1.309729 + 0.2) = 0.0905837$
```

因为从 $x=0.12$ 到 $0.32$ 的下两个段长度相等，它们的积分可以使用辛普森 1/3 法则计算：

```
$I = \frac{0.2}{3} [1.74339 + 4(1.305241) + 1.309729] = 0.2758029$
```

接下来的三段也是相等的，可以使用 3/8 法则评估，得到 $I=0.272663$。同样，1/3 法则可以应用于从 $x=0.44$ 到 $0.64$ 的两个段，产生 $I=0.6684701$。最后，最后两个段长度不均匀，可以使用梯形法评估，得到 $0.1663479$ 和 $0.1197500$ 的值；将这些单独段的面积相加得到总积分 1.603641。这代表了 $\epsilon_t = 2.2\%$ 的误差，优于例 21.7 中使用梯形法的结果。

**不均匀间隔数据的计算机程序。** 编写公式 (21.22) 是一个相当简单的命题。此类算法列如图 21.15a 所示。然而，如例 21.8 所示，如果在可能的情况下实现辛普森法则，该方法将得到增强。因此，我们开发了包含此能力的第二个算法。如图 21.15b 所示，算法检查相邻段的长度。如果两个段长度相等，则应用辛普森 1/3 法则。如果三段相等，则使用 3/8 法则。当相邻段长度不相等时，则执行梯形法。

#### 算法：积分不均匀数据的伪代码

**(a) 梯形法**

```
FUNCTION Trapun(x, y, n)
    LOCAL i, sum
    sum = 0
    DOFOR i = 1, n
        sum = sum + (x_i - x_{i-1}) * (y_i + y_{i-1}) / 2
    END DO
    Trapun = sum
END Trapun
```

**(b) 组合辛普森/梯形法**

```
FUNCTION Uneven(n, x, f)
    h = x_1 - x_0
    k = 1
    sum = 0
    DOFOR j = 1, n
        hf = x_j - x_{j-1}
        IF ABS(h - hf) < 0.000001 THEN
            IF k = 3 THEN
                sum = sum + Simp38(h, f_{j-3}, f_{j-2}, f_{j-1}, f_j)
                k = k - 1
            ELSE
                k = k + 1
            END IF
        ELSE
            IF k = 1 THEN
                sum = sum + Trap(h, f_{j-1}, f_j)
            ELSE
                IF k = 2 THEN
                    sum = sum + Simp13(h, f_{j-2}, f_{j-1}, f_j)
                ELSE
                    sum = sum + Simp38(h, f_{j-3}, f_{j-2}, f_{j-1}, f_j)
                END IF
                k = 1
            END IF
        END IF
        h = hf
    END DO
    Uneven = sum
END Uneven
```

因此，它不仅允许对不均匀间隔的数据进行评估，如果使用等间隔的信息，它就简化为使用辛普森法则。因此，它代表了确定表格数据积分的基本通用算法。

### 示例 21.9 使用重积分确定平均温度

**问题描述。** 假设一个矩形板的温度由以下函数描述：
$$T(x, y) = 2xy + 2x - x^2 - 2y^2 + 72$$
如果该板长为 8 米（x 维度），宽为 6 米（y 维度），计算其平均温度。

**解。** 让我们在每个维度上使用两段梯形法。必要的 x 和 y 温度如图 21.17 所示。注意，这些值的简单平均值为 47.33。该函数也可以通过解析法评估得到 58.6667 的结果。

为了对其进行数值评估，首先沿着 x 维度执行梯形法。然后沿着 y 维度对这些值积分，得到最终结果 2544。将此除以面积得到温度为 $2544/(6 \times 8) = 53$。

现在我们可以以相同的方式应用单段辛普森 1/3 法则。这产生了积分值 2816，平均值为 58.6667，这是精确的。为什么会发生这种情况？回顾辛普森 1/3 法则对三次多项式是产生完美的。函数中的高阶项是二阶的，因此对于给定的情况会有这种精确性。
