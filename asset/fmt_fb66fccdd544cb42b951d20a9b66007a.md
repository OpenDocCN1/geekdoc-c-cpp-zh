# C# 对 Volatile 字段的支持

确保程序员正确调用 `VolatileRead` 和 `VolatileWrite` 方法并非易事。程序员很难在脑海中记住所有这些内容，并开始想象其他线程可能在后台共享数据。为了简化这一操作，C# 提供了 `volatile` 关键字，它可以应用于以下任何一种类型的静态或实例字段：`Byte`、`SByte`、`Int16`、`UInt16`、`Int32`、`UInt32`、`Char`、`Single` 或 `Boolean`。你也可以将 `volatile` 关键字应用于引用类型和任何枚举字段，只要该枚举类型的底层类型是 `Byte`、`SByte`、`Int16`、`UInt16`、`Int32`、`UInt32`、`Char`、`Single` 或 `Boolean`。JIT 编译器确保对该字段的所有访问都以读写的方式执行，因此无需显式调用 `Thread` 的静态 `VolatileRead` 或 `VolatileWrite` 方法。此外，`volatile` 关键字告诉 C# 和 JIT 不要将字段缓存在 CPU 寄存器中，确保对该字段的所有读写实际上都会从内存中读取值。
