
`MediaElement` 类拥有若干属性、方法和事件，可让你通过 `MediaElement` 控件添加和操作媒体。表 17.9 列出了 `MediaElement` 类值得注意的属性：

表 17.9：`MediaElement` 类的注目属性

| 属性 | 描述 |
|---|---|
| Attributes | 检索 `MediaElement` 控件中作为源媒体的 Advanced Stream Redirector (ASX) 文件中当前条目的属性集合。 |
| AudioStreamCount | 检索当前打开的媒体文件中的音频流数量。 |
| AudioStreamIndex | 设置或检索与视频同时播放的音频流的索引。此属性的默认值为空引用。 |
| AutoPlay | 设置或检索一个值，指示媒体是否在 `MediaElement` 加载后立即自动开始播放。默认情况下，此属性的值为 true。 |
| Balance | 设置或检索立体声扬声器之间的平衡比例。此属性的默认值为零，范围在 -1 到 1 之间。如果你将此属性的值设为 -1，则左立体声扬声器为满音量。如果你将此属性的值设为 1，则右立体声扬声器为满音量。 |
| BufferingProgress | 检索表示当前媒体当前缓冲量的值。此属性的默认值为零，可以是最高为 1 的任意分数值。 |
| BufferingTime | 设置或检索缓冲时间。此属性的默认值为五秒。 |
| CanPause | 检索一个值，指示当前打开的媒体是否可以暂停。 |
| CanSeek | 检索一个值，指示你是否可以更改媒体的位置。 |
| CurrentState | 检索 `MediaElement` 控件的当前状态。此属性可以返回 Buffering、Opening、Playing、Paused、Stopped 和 Closed 中的任意值。 |
| DownloadProgress | 检索远程位置的媒体已下载的百分比。默认值是零。 |
| DownloadProgressOffset | 检索下载媒体的偏移量。 |
| DroppedFramesPerSecond | 检索媒体文件每秒丢弃的帧数。 |
| IsMuted | 设置或检索一个值，指示媒体是否静音。 |
| Markers | 检索媒体文件中存在的标记集合。 |
| NaturalDuration | 检索媒体的总时长。 |
| NaturalVideoHeight | 检索 `MediaElement` 控件视频的高度（以像素为单位）。对于音频，此属性的值为零。 |
| NaturalVideoWidth | 检索 `MediaElement` 控件视频的宽度（以像素为单位）。对于音频，此属性的值为零。 |
| Position | 设置或检索媒体整个回放中的位置（时间实例）。 |
| RenderedFramesPerSecond | 检索 `MediaElement` 控件每秒渲染的帧数。 |
| Source | 设置或检索要在 `MediaElement` 控件中播放的源（媒体文件）。 |
| Stretch | 设置或检索一个值，指示媒体占据 `MediaElement` 控件 UI 的方式。此属性的值可以为 None、Uniform、UniformToFill 或 Fill。 |
| Volume | 设置或检索媒体的音量。此属性的默认值为 0.5，范围在零到一之间。 |

## Popup 控件

`Popup` 控件用于在某些其他控件之上显示任何信息或描述，例如 `Button` 或 `Grid` 控件。`Popup` 控件只能出现在单个 UI 控件上。这意味着如果你想为多个控件显示一些信息，你需要将它们封装在容器控件中，例如 `Grid` 或 `StackPanel` 控件。此外，`Popup` 控件可以显示在现有 Silverlight 内容之上或在 Silverlight 控件的边距内。此外，一个 `Popup` 控件可以出现在另一个 `Popup` 控件之上。图 17.14 显示了一个 `Popup` 控件：

![](img/e073a4882197be4ab61103cbe0bcb394_891_0.png)

图 17.14：Silverlight 3.0 中的 `Popup` 控件

`Popup` 控件是 `Popup` 类的一个实例，该类存在于 `System.Windows.Controls.dll` 程序集中 `System.Windows.Controls.Primitives` 命名空间中。`Popup` 类的类层次结构为：
