
例如，如果你通过追加两个不可变数组来创建一个数组，你可能会得到一个内部不存储任何内容的复合数组，它只是访问另外两个数组。或者你可能会得到一个全新的数组，取决于实现相关 `NSArray` 子类的开发者认为在该特定情况下哪种更高效。

创建 Objective-C 数组简单的方法是使用 `+arrayWithObjects:` 方法，`NSArray` 和 `NSMutableArray` 都实现了该方法。这是另一个可变方法的示例，它接受对象列表作为参数，并使用 `nil` 表示列表的结束。当你使用变量作为此方法的参数时，必须确保没有变量是 `nil`，否则数组将将其视为列表的结束并忽略后面的值。

**注意：** 大多数 Objective-C 集合不允许你将 `nil` 作为值存储。如果你需要表示空值而不是值的缺失，可以使用 `NSNull` 类。它提供了一个可以通过 `[NSNull null]` 访问的单例对象。

数组是类簇。`NSArray` 中的两个原始方法是 `-objectAtIndex` 和 `-count`。所有其他方法都是基于这两个方法实现的。当然，某些具体的子类会实现更高效的版本，但如果你想创建一个新的 `NSArray` 子类，你必须实现这两个方法，以便基类的其他方法能够正常工作。

子类 `NSMutableArray` 稍微困难一点；它增加了另外六个原始方法。但在大多数情况下，你会使用数组而不是对其进行子类化。你可以通过两种方式向可变数组插入对象：`-addObject:` 将其添加到末尾，或者 `-insertObject:atIndex:` 将其插入到

操作索引 163

指定的索引。后一种方法会将数组中所有后续对象向后移动一个以腾出空间。要替换对象，请使用 `-replaceObjectAtIndex:withObject:`。

## 操作索引

```
NSMutableIndexSet *indexSet =
[NSMutableIndexSet indexSetWithIndex:1];
[indexSet addIndexesInRange:(5, 20)];
[array removeObjectsAtIndex:indexSet];
```

源自：`indexset.m`

数组通过整数进行索引。通常，你希望对数组中的一组值执行某些操作。一个名为 `NSSet` 的特殊类用于存储索引组。在内部，它存储的是一组范围集合，因此可能非常密集。索引集的一个非常常见的用途是在枚举数组时收集一组索引，然后在最后将它们删除。在枚举集合时从集合中删除对象是一个坏主意，并且在大多数情况下它会抛出异常。如果你将想要删除的每个索引都添加到索引集中，那么你就可以在完成枚举后一次性地删除它们。

涉及索引集的操作通常比涉及单个索引对应的操作更高效。即使在相对原始的消息发送中也是如此，因为你需要的范围检查更少。你还可以避免一些范围检查。Objective-C 数组上的每个操作都会进行边界检查，以确保它不会引用数组末尾之外索引。使用索引集，接收者只需要比较 `-lastIndex` 的结果与数组的最后一个索引，然后就可以在不进行范围检查的情况下对索引集中的每个元素进行操作。

像其他集合一样，索引集也有可变和不可变两种版本。大多数时候，你将使用可变版本。你通过添加和删除单个索引（`NSIntegers`）或范围来操作它。你可以使用索引集来存储任何内容的索引，但它们与 `NSArrays` 结合使用时最有用，数组有几个方法设计用于接收索引集作为参数。如果你只是想对数组中的某些任意子元素进行操作，通常可以使用它们作为创建子数组的替代方案。

## 存储无序的对象组

```
NSArray *array = [NSArray arrayWithObjects:
"set", @"object", @"containing"
"seven", @"objects", @"not"
"eight", @"objects", nil];
NSSet *set = [NSSet initWithArray:array];
MutableSet *mSet = [set mutableCopy];
NSSet *cSet =
[NSCountedSet initWithArray:array];
```

源自：`nsset.m`

如果你想存储一个没有顺序的对象集合，可以使用 `NSSet` 及其可变子类。这模型了数学中的集合，因此插入两次相同的对象也不会存储它的两个副本。

`NSSet` 如何确定对象之间的相等性是非常复杂的。相等性不等同于同一性（identity）；它不会存储相同对象的副本，但也会存储两个值相同的对象。它通过向其中一个对象发送 `-isEqual:` 消息并将另一个对象作为参数来判断两个对象是否相等。

实现 `NSSet` 最简单的方法是将每个新对象与每个现有对象进行比较。然而，这将非常缓慢，所以 `NSSet` 并不是这样工作的。相反，它使用 `-hash` 方法。每个对象都应该实现此方法并返回一个整数哈希值。

如果两个对象相等，它们必须具有相同的哈希。像 `NSSet` 这样的集合根据哈希值将对象放入桶中。在测试对象是否已在集合中时，它只需要测试具有相同哈希值的对象。

因此，良好的哈希对于这些集合类的良好性能至关重要。幸运的是，此类集合中最常用的对象 `NSString` 已经有了良好的哈希实现。

这种方法的一个细微问题是，对象在集合中时不能更改其哈希值。对于可变对象，在不破坏其他一些规则的情况下无法强制执行这一点。因此，在对象存储在集合期间不要修改它们很重要。

另一种类型的集合是 `NSCountedSet`，它是 `NSMutableSet` 的子类，支持多次添加相同对象。这为 `NSMutableSet` 增加了一个方法 `-countForObject:`，它返回特定对象被添加到集合的次数。

> 注意：在 Java 和其他其他语言中，计数集合被称为 bag（袋集合）。

值得注意的是，因为 `NSCountedSet` 是 `NSSet` 的子类，它的某些方法被设计为允许 `NSCountedSet` 实例替代 `NSSet` 实例。如果你向本节开头示例中创建的任何集合发送 `-count` 消息，你将获得相同的值。如果你遍历任何一个集合，你将得到七个对象。你只有通过向集合发送 `-countForObject:` 消息，才能判断一个对象是否在计数集合中出现了多次。

## 创建字典

```
NSMutableDictionary *dict = [NSMutableDictionary dictionaryWithObjectsAndKeys:"One", @"1", @"two", @"2", nil];
[dict setObject:@"three" forKey:@"3"];
```

源自：`dictionary.m`

字典（通常称为 map 或关联数组）提供了一个通过其他对象索引的对象集合。最常见的是字典通过字符串进行索引。这并不是唯一的选择，但对可以用作字典键的类有一些限制。

字典与集合相似，相同的约束也适用。用作键的对象必须实现 `-hash` 和 `-isEqual` 方法，在比较时返回 `YES`，且如果它们相等则返回相同的哈希值。只要它们在集合中，哈希值就不能更改。

此外，键必须实现 `NSCopying` 协议。当你将一个键添加到字典时，该值将被保留（retain）。如果你传递一个不可变对象（例如 `NSString`），这种效果等同于释放内存（dealloc）。

最后，值得记住，只有使用字符串作为键的字典才能配合键值编码（key-value coding，见第 11 章）。你将在字典上最常用的方法是 `-objectForKey:`，它返回与键关联的对象，如果没有对象则返回 `nil`。对于可变字典，你通常会使用 `-setObject:forKey:` 方法来设置键值对。

## 遍历集合

```
NSLog(@"The Objective-C 1 way:");
NSEEnumerator e=[a objectEnumerator];
for (id obj=[e nextObject];
nil!=obj;
    obj=[e nextObject])
{
    [obj print];
}
NSLog(@"Fast enumeration:");
for (id obj in a)
{
    [obj print];
}
NSLog(@"Using blocks:");
[a enumerateObjectsUsingBlock:
^(id obj, NSInteger idx, BOOL stop)
{
    [obj print];
});
NSLog(@"Avoiding enumeration:");
[a makeObjectsPerformSelector:@selector(print)];
```

*源自：`enum.m`*

你对集合执行的最常见任务之一是遍历集合中的每个元素并进行某些处理。在 Objective-C 中有很多方法可以实现这一点。因为这是一项如此常见的任务，新的实现方法不断被添加。

对于数组，你可以遍历从 0 到 `[array count]` 的每个索引并发送 `-objectAtIndex:` 消息。这是非常无效的。遍历集合的传统方法是使用枚举（enumeration）；即 `NSEnumerator` 子类的实例。

**注意：** 如果你是从 Java 转过来的，在脑海中将 enumerator（枚举器）替换为 iterator（迭代器），你会发现你熟悉的模式仍然有效。

你可以通过向集合发送 `-objectEnumerator` 消息来获取枚举器。这个对象非常简单。它只响应两个消息，而你可能会使用其中一个：`-nextObject`。它返回集合中的下一个对象，如果你遍历了集合包含的所有对象，则返回 `nil`。

在 Objective-C 2 中，Apple 引入了快速枚举（fast enumeration）。你可以将其用于任何实现 `NSFastEnumeration` 协议的集合。该协议定义了一个通过单个消息获取多个对象的方法。具体数量由调用者和接收者定义。编译器分配一个缓冲区并将指针传递给接收者。接收者可以将某些对象复制到此缓冲区中，或者如果它内部作为 C 数组（或一组数组）存储数据，则返回其内部存储的指针。

该协议中的方法被一种新的流程控制结构 `for..in` 循环使用。当你使用它时，编译器将产生两个

嵌套循环。在外部循环中，它将调用快速枚举方法，从集合中获取接几个对象。在内层循环中，它将遍历这个 C 语言数组。

**注意：** 如果你使用自动引用计数（ARC），那么快速枚举协议的契约更加严格。集合要求确保对象在枚举期间是有效的（或者信号集合已发生变动）。由于这一点，你不允许在不带显式修饰符的情况下给枚举变量赋值，因为如果你这样做了，ARC 不知道该如何处理你的赋值。通常情况下，最好在循环内部声明一个新变量来存放新的临时值。

你可以在没有编译器支持的情况下使用快速枚举。GNUStep 中的 `GSFastEnumeration.h` 头文件提供了 `FOR_IN` 和 `END_FOR_IN` 宏，这些宏会被展开并生成与编译器用于 `for..in` 循环时所代码相同的代码。由于这些宏非常复杂，因此最好不要尝试自己去调用快速枚举方法。

带有 OS X 10.6，Apple 引入了另一种遍历集合的新方法：使用块（blocks）。块是 C 语言的一种新扩展，但设计用于与 Objective-C 紧密协作。像 Objective-C 对象一样，块也有一个 `isa` 指针。它指向一个实现了 `NSObject` 协议的私有类，因此可以将块存储在集合中。它们还支持使用 Objective-C 类型编码进行内省，尽管这种支持尚未成为它们在 OS X 上公共接口的一部分。

大多数集合类现在都实现了使用块的枚举方法。使用这些方法可能很方便，尽管这限制了你代码的可移植性。你可以通过将 `NSEnumerationConcurrent` 作为第一个参数传递给如 `-enumerateObjectsWithOptions:usingBlock:` 等方法，使用块执行并发枚举。通常只有当块在每个元素上的执行需要花费很长时间时，这种方法才可能带来性能提升。

每个集合都有不同的通过块进行枚举的方法。数组的版本接受对象的索引作为参数，字典的版本则同时接受键和值，以此此类推。这些方法会比其他替代方案更慢，因为它们需要为每个对象调用一次块（这与调用函数的开销相同）；但它们可以更方便。

在某些情况下，你可以完全避免枚举。例如，`NSArray` 实现了一个 `-makeObjectsPerformSelector` 方法，以及另一个接受对象作为第二个参数的版本。如果你在枚举时所做的只是向每个对象发送消息，

你可以使用这些方法代替创建循环。

## 在集合中查找对象

```objc
NSArray *array = [NSArray arrayWithObjects:
@"a", @"group", @"of", @"string", @"objects", nil];
NSSet *set = [NSSet initWithArray: array];
NSInteger i = [array indexOfObjectIdenticalTo:@"group"];
if (NSNotFound == i)
    i = [array indexOfObject:@"group"];
NSString *original = [set member:@"string"];
```

源自：`getObject.m`

`NSArray` 和 `NSSet` 都实现了 `-containsObject:` 方法，如果集合包含一个与参数相等的对象，则该方法返回 `YES`。这使用了我们之前在讨论集合类时介绍过的等性概念：如果向其中一个对象发送 `-isEqual:` 消息（以另一个对象作为参数）返回了 `YES`，则这两个对象是相等的。

在数组中，你可能想确切知道对象在哪里，而不仅仅是它是否存在。有两个方法可以告诉你：`-indexOfObject:` 和 `-indexOfObjectIdenticalTo:`。后者使用指针比较来确定等性。

这些方法在数组中都是缓慢的。它们都需要线性搜索，而且大多数方法需要向每个对象发送消息。通常情况下，你只应该在小型数组或不频繁调的代码路径中使用它们。如果你需要经常执行这种反向映射，最好使用字典或类似结构来存储这种反向关系。

对于集合，性能情况有所不同。因为集合根据对象的哈希值（hash）将对象存储在桶中，因此集合可以快速排除许多不同的对象。显然，由于集合是无序的，因此没有集合方法可以查找对象的索引。然而，有一个方法可以查找与某个对象相等的存储对象。

`NSSet` 上的 `-member:` 方法返回与参数相等的存储对象。这对于确保对象的唯一性非常有用。`unique:` 示例展示了一个从 C 字符串构建唯一常量字符串对象的方法。如果你两次向此方法传递相同的 C 字符串，你每次都会得到返回相同的 `NSString` 实例。

注意，此函数不是线程安全的。在检查字符串是否存在于集合中以及如果不在则添加新字符串之间，存在潜在的竞态条件。该方法的线程安全版本要求你在调用 `-member:` 后获取锁，再次发送此消息，最后在添加新对象后释放锁。

```objc
static NSMutableSet *unique_strings;
NSString *uniqueString(const char *str)
{
    NSString *new = [[NSString alloc]
    initWithUTF8String:str];

    NSString *old = [unique_strings member: new];

    if (nil != old)
    {
        [new release];
        return old;
    }
    [unique_strings addObject:new];
    return new;
}
```

源自：`unique.m`

如果你正在创建一个新的不可变类，你可能希望在构造函数实现类似这样的内容。这将牺牲一些速度换取内存使用，但意味着你可以通过指针比较来确定等性，这在某些情况下是一个巨大的收益。

## 类化集合

```objc
(NSUInteger)count{
    return [realArray count];
}
(id)objectAtIndex:(NSUInteger)anIndex{
    return [realArray objectAtIndex:anIndex];
}
```

源自：`checkedArray.m`

所有的集合都是类簇（class clusters）。这意味着为它们创建新的子类并非易。父类是抽象的，而具体的子类是私有的（所以你无法直接类化它们）。

每个集合都记录了你在子类中必须实现的方法。实现这一点简单方法是通过委托：只需将与要类化的集合类型相同的对象作为实例变量。`typedArray.m` 示例使用了这种方法。

`TypedArray` 类是 `NSMutableArray` 的子类。该类中的 `realArray` 变量是一个 `NSMutableArray`。它在类的指定初始化器中创建，就像任何其他创建 `NSMutableArray` 的代码一样，实际上获得的是该类某个具体子类的实例。另一个实例变量是 `Class` 类型，用于插入数组的对象的类型。

```objc
- (id)initWithType:(Class)aClass
{
    if (nil == (self = [super init]))
    {
        return nil;
    }
    type = aClass;
    realArray = [NSMutableArray new];
    return self;
}
-(void)dealloc
{
    [realArray release];
    [super dealloc];
}
```

源自：`checkedArray.m`

标准数组类是异质的，而这个版本要求你插入的每个对象都是传递给初始化器的类的实例（或子类）。如果你尝试插入其他对象，此版本将静默失败，但你可以轻松地修改它以抛出异常。
