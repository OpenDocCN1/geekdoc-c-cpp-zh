# 第 7 章 / 数组

## 7.1 数组简介

将数组索引保持在有效范围内听起来很简单。在实践中，这很困难，因为有微妙或意想不到的方法可以改变索引变量。例如，考虑以下向数组输入数字的代码：

```cpp
int num;
int a[10];

cout << "How many numbers? (max of 10)" << endl;
cin >> num;
for (int i = 0; i <= num; i++) {
    cout << "Enter number " << i << endl;
    cin >> a[i];
}
```

程序存在两个错误。首先，从 0 开始到包含 `num` 的循环将输入 `num+1` 个数字而不是 `numbers`。只要输入的 `num` 小于十，你可能就不会注意到这个问题。程序不会崩溃，因为数字会多输入一个并填满数组。然而，如果输入的 `num` 是 10，那么第 11 个数字将存储在 `a[10]`，这已经在数组边界之外。为了修复这个问题，循环应该写成：

```cpp
for (int i = 0; i < num; i++)
```

另一个问题是缺乏输入验证。恶意的或捣作剧的用户可以输入 100 作为要输入的数字值；此时循环将执行 100 次，并输入远超数组范围的数据。为了解决这个问题，我们可以验证用户的输入是否在范围内：

```cpp
cout << "How many numbers? (max of 10)" << endl;
cin >> num;
cout << endl;
if (num <= 10) {
    for (int i = 0; i < num; i++) {
        cout << "Enter number " << i << endl;
        cin >> a[i];
    }
}
```

即使是这个修改后的版本也有出错的可能。如果输入的 `num` 超过了其最大尺寸，那么存在溢出的可能性。例如，在大多数系统上，`short` 只能存储一个数字到 +32767。在溢出处输入一个较大的值，这可能会在 `num` 中存储 0 或负值。尽管当 `num` 为 0 或负数时 `for` 循环将不会运行，但程序会错误地通过 `if` 语句。我们将在第 8 章中再次探讨这类错误。

### 数组初始化

数组可以在声明时对其进行初始化。在初始化数组时，各种索引变量的值被括在花括号中，并用逗号分隔。例如：

```cpp
int children[3] = {2, 12, 1};
```

此声明等同于以下代码：

```cpp
int children[3];
children[0] = 2;
children[1] = 12;
children[2] = 1;
```

如果列出的值少于索引变量的数量，则这些值将用于初始化前几个索引变量，剩余的索引变量将初始化为数组基底类型的 0。在这种情况下，未提供初始化值的索引变量可能是没有初始化值的数组；而在函数定义内部声明的其他变量将不会被初始化。虽然数组索引变量可能会被自动初始化为 0，但你不能依赖这一点。

如果你在声明时初始化数组，可以省略数组的大小，数组将自动声明为满足初始化值所需的最小大小。例如，以下声明：

```cpp
int b[] = {5, 12, 11};
```

等同于：

```cpp
int b[3] = {5, 12, 11};
```

### 7.1 数组介绍

例如：

```cpp
int arr[] = {2, 4, 6, 8};
for (int x : arr)
    cout << x;
cout << endl;
```

这将输出： 2468。

在定义用于遍历数组的变量时，我们可以使用与定义函数参数时相同的修饰符。我们在上面的示例中对变量 `x` 使用的方法等同于按值传递。如果我们在循环内部修改 `x`，它不会改变数组。我们可以通过使用 `&` 将 `x` 定义为按引用传递，这样修改 `x` 就会改变数组。我们还可以使用 `const` 来指示该变量不可更改。下面的示例递增了数组中的每个元素并输出它们。我们在输出循环中使用 `auto` 数据类型来自动确定数组内元素的类型。

```cpp
int arr[] = {2, 4, 6, 8};
for (int& x : arr)
    x++;
for (auto x : arr)
    cout << x;
cout << endl;
```

这将输出： 3579。基于范围的 `for` 循环在遍历 `vector` 和遍历容器时尤为方便。

### 整个数组作为函数参数

函数可以有一个针对整个数组的形式形参数，这样在调用函数时，接入该形式形参数的参数就是一个整个数组。然而，数组的形式形参数既不是值传递参数，也不是引用传递参数；它是一种新的形式形参数，被称为数组参数。

显示 7.4 中定义的函数有一个数组参数 `a`，在调用函数时，它将被一个整个数组替换。它还有一个普通的值传递参数 `size`，假设该值是一个整数，且等于数组的大小。该函数用从键盘输入的类型的值填充其数组，然后函数向屏幕输出一条消息，告诉最后一次使用的索引。

形式形参数 `int []` 是一个数组参数。方括号内没有任何表达式，这是 C++ 用来指示数组参数的符号。数组参数不是引用传递参数，但对于大多数用途，它的行为非常像引用传递参数。

当调用函数 `fillup` 时，它必须有两个参数：第一个给出一个整数数组，第二个应该给出数组的声明大小。例如：

```cpp
int score[5], numberScores = 5;
fillup(score, numberScores);
```

此对 `fillup` 的调用将用从键盘输入的五个整数填充 `score` 数组。

#### 显示 7.4 带有数组参数的函数

函数声明

`void fillup(int a[], int size);`

```cpp
#include <iostream>
void fillup(int a[], int size)
{
    using namespace std;
    cout << "输入 " << size << " 个整数：";
    for (int i = 0; i < size; i++)
        cin >> a[i];
    cout << "最后使用的索引是 " << size - 1 << endl;
}
```

如果你意图修改数组参数，计算机将检查并确保你的代码没有无意中改变数组中的任何值。要告诉编译器数组参数不应被你的函数修改，你可以在该参数位置的数组参数之前插入 `const` 修饰符。使用 `const` 修饰的数组参数被称为常量数组参数。

例如，以下函数会输出数组中的值，但不会改变数组中的值：

```cpp
void showTheWorld(int a[ ], int sizeFA)
```

```cpp
{
  cout << "The array contains the following values:\n";
  for (int i = 0; i < sizeFA; i++)
    cout << a[i] << " ";
  cout << endl;
}
```

添加 `const` 修饰符后：

```cpp
void showTheWorld(const int a[ ], int sizeFA)
```

添加此 `const` 修饰符后，如果你的函数定义中包含改变数组参数中任何值的错误，计算机将发出错误信息。

| 数组形式参数与实参数 |
| :--- |
| 函数的实参数可以是一个整个数组，但整个数组的参数既不是按值传递也不是按引用传递。它是一种新类型的参数，称为数组参数。当将数组参数传递给数组参数时，传递给函数的所有内容都位于第一个索引变量的内存中。数组参数并没有告知数组的大小。因此，当你给函数提供一个数组参数时，你通常还必须提供另一个 `int` 类型的形式参数来给出数组的大小。 |

> 带有数组参数的函数声明语法如下：

语法

`Type_Returned functionName(..., Base_Type ArrayName[], ...);`

示例

`void sumArray(double& sum, double a[ ], int size);`

例如，以下是 `showWorld` 函数的版本，它包含一个无意中改变数组参数值的错误：

```cpp
void showWorld(const int a[ ], int sizeFA)
{
  cout << "The array contains the following values:\n";
  for (int i = 0; i < sizeFA; a[i]++)
    cout << a[i] << " ";
  cout << endl;
}
```

通常情况下，你的程序中除了函数定义外，还有一个函数声明。当你在函数定义中使用 `const` 修饰符时，你必须在函数声明也使用它，以确保函数头和函数声明一致。

`const` 修饰符可以用于任何类型的参数，但通常只用于数组参数和类的按引用传递参数。
