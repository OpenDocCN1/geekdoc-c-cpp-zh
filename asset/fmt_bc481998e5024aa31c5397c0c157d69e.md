# 还记得变量只存储值吗？

变量就像装有值的盒子。一个变量中的值可以被复制并存储在另一个变量中。这就像对盒子 `"a"` 中包含的值进行复印，并将副本存储在盒子 `"b"` 中。

> 变量的工作原理
> 每个变量都像一个盒子，里面有一张写有值的纸。

- 1 给变量分配一个值
给变量 `"a"` 分配值 2，然后将 `"a"` 中的值分配给变量 `"b"`。值 2 被复制并存储在 `"b"` 中。

```
>>> a = 2
>>> b = a
>>> print('a =', a, 'b =', b)
a = 2 b = 2
```

这把 `"a"` 的内容复制到 `"b"` 中。

`"a"` 和 `"b"` 包含值 2

这打印出了变量名及其对应的值

- 2 更改值
如果你更改了存储在一个一个变量的值，它不会影响另一个变量中存储的值。同样，更改盒子 `"a"` 里面纸上写的内容不会影响盒子 `"b"` 里面纸上的内容。

```
>>> a = 100
>>> print('a =', a, 'b =', b)
a = 100 b = 2
```

`"a"` 包含 100，但 `"b"` 仍然包含 2

- 3 更改另一个值
将 `"b"` 中的值改为 22。变量 `"a"` 仍然包含 100。尽管 `"b"` 的值最初是从 `"a"` 复制的，但现在它们是相互独立的——更改 `"b"` 不会改变 `"a"`。

```
>>> b = 22
>>> print('a =', a, 'b =', b)
a = 100 b = 22
```

`"b"` 现在包含 22，但 `"a"` 仍然是 100

from turtle import *
def turtle_controller(do, val):
    do = do.upper()
    if do == 'F':
        forward(val)
    elif do == 'B':
        backward(val)
    elif do == 'R':
        right(val)
    elif do == 'L':
        left(val)
    elif do == 'U':
        penup()
    elif do == 'D':
        pendown(val)
    elif do == 'N':
        reset()
    else:
        print('Unrecognized command ')
