示例展示了一个程序，该程序确定小于或等于100 的所有正整数的和，即 1+2+3...+100 之和。

## 如何实现

程序可以写如下：

```csharp
class Program
{
    const int N = 100;
    static void Main(string[] args)
    {
        long s = 0;
        int n = 1;
        while (n <= N)
        {
            s += n;
            n++;
        }

}
```

```
const int N = 100;
```

这并不是必要的，但它很容易修改程序，例如必须计算1到1000数字的和。
