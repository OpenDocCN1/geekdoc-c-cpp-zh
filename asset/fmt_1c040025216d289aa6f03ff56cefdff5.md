
整数常量表达式^{117} 应当具有整数类型，且其操作数只能是整数常量、枚举常量、字符常量、结果为整数常量的 `sizeof` 表达式、`_Alignof` 表达式以及作为类型转换的直接操作数的浮点常量。整数常量表达式中的类型转换运算符应只将算术类型转换为整数类型，除非作为 `sizeof` 或 `_Alignof` 运算符的操作数的一部分。

初始化器中的常量表达式被允许更大的自由度。此类常量表达式应当是或求值为以下内容之一：

- 算术常量表达式，
- 空指针常量，
- 地址常量，或
- 完整对象类型加上或减去一个整数常量表达式的地址常量。

+ 8 算术常量表达式应当具有算术类型，且其操作数只能是整数常量、浮点常量、字符常量、结果为整数常量的 `sizeof` 表达式以及 `Alignof` 表达式。算术常量表达式中的类型转换运算符应只将算术类型转换为算术类型，除非作为 `sizeof` 或 `_Alignof` 运算符的操作数的一部分。

+ 9 地址常量是指空指针、指向具有静态存储期对象的指针，或指向函数指示符的指针；它应当显式地使用一元运算符 `&` 或将整数常量转换为指针类型来创建，或者通过使用数组或函数类型的表达式隐式地创建。在创建地址常量时，可以使用数组下标 `[]`、成员访问运算符 `.` 和 `->`、地址运算符 `&`、间接运算符 `*` 一元运算符以及指针类型转换，但不应通过使用这些运算符访问对象的值。

+ 10 实现可以接受其他形式的常量表达式。

+ 11 常量表达式求值的语义规则与非常量表达式相同。118

**前向引用：** 数组声明符 (`6.7.6.2`)，初始化 (`6.7.9`)。

该表达式是一个值为1的有效整数常量表达式。

### 语义

声明规定了一组标识符的解释方式和属性。标识符的定义是该标识符的声明：

- 对于对象，为该对象预留存储；
- 对于函数，包括函数体；119)
- 对于枚举常量，该标识符的（唯一）声明；
- 对于 `typedef` 的名称，是该标识符的第一个（或唯一的）声明。

7 如果对象的标识符在在没有链接的情况下声明，则该对象的类型在其声明符结束时应当是完整的；对于函数参数（包括在原型中），则要求调整后的类型（见 `6.7.3`）是完整的。

示例 2 声明之后：

结构体 `s` 有一个灵活数组成员 `d`。使用它的典型方法是：

```c
int m = /* some value */;
struct s *p = malloc(sizeof(struct s) + sizeof(double [m]));
```

假设调用 `malloc` 成功，`p` 指向的对象大多数情况下表现就像 `p` 被声明为如下：

```c
struct { int n; double d[m]; } *p;
```

（在某些情况下这种等效性会被破坏；特别是成员 `d` 的偏移量可能不同）。遵循上述声明：

```c
struct s t1 = { 0 }; // 有效
struct s t2 = { 1, { 4.2 } }; // 无效
t1.n = 4; // 有效
t1.d[0] = 42; // 可能是未定义行为
```

`t2` 的初始化是无效的（违反了约束），因为 `struct s` 被处理为不包含成员 `d`。赋值 `d` 可能是未定义的，但可能：

```c
sizeof(struct s) >= offsetof(struct s, d) + sizeof(double)
```

在这种情况下，该赋值是合法的。尽管如此，它不能出现在严格符合的代码中。

在进一步声明之后：

```c
struct ss { int n; };
```

表达式：

```c
sizeof(struct s) >= sizeof(struct ss)
sizeof(struct s) >= offsetof(struct s, d)
```

等于于 1。

如果 `sizeof (double)` 为 8，则执行以下代码：

```c
struct s *s1;
struct s *s2;
s1 = malloc(sizeof(struct s) + 64);
s2 = malloc(sizeof(struct s) + 46);
```

假设对 `malloc` 调用成功，`s1` 和 `s2` 指向的对象大多数情况下表现就像这些标识符被声明为：

```c
struct { int n; double d[8]; } *s1;
struct { int n; double d[5]; } *s2;
```
