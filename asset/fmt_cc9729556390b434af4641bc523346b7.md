## Start Page

Start Page 是每次启动 Visual Studio 2010 IDE 时显示的第一个页面。它帮助你创建新解决方案或打开现有和最近的解决方案。此页面还提供最新的开发新闻，并允许你在线与开发者社区互动。

图 1.51 显示了 Visual Studio 2010 的 Start Page：

![](img/e073a4882197be4ab61103cbe0bcb394_81_0.png)

**图 1.51：显示 Visual Studio 2010 Ultimate 的 Start Page**

Start Page 显示以下窗格：

- **Command Section** – 提供 `New Project` 和 `Open Project` 命令的链接。
- **Recent Projects** – 显示你在 Visual Studio IDE 中最近打开的项目列表（图 1.51）。你可以通过单击具有项目名称的超链接来打开项目。请注意，你也可以使用 `Open Project` 和 `New Project` 链接在 Visual Studio 2010 中打开或创建项目。
- **Content Area** – 包含三个选项卡，描述如下：
  - Get Started — 包含指向产品文档中各种编程任务的链接
  - Guidance and Resources — 提供有关各种主题的指导，例如开发流程和 MSDN 资源
  - Latest News — 包含指向最新新闻和公告的链接

Display Options: 包含以下复选框以确定“开始”页面的显示设置：

- Close page after project load — 在项目加载或打开后关闭“开始”页面
- Show page on startup — 启动 Visual Studio 时显示“开始”页面

## Toolbars

Visual Studio 2010 中的工具栏为开发人员提供了轻松访问 IDE 功能的途径。Visual Studio 2010 IDE 为开发应用程序所需任务的每个类别提供不同的工具栏，例如标准、布局、格式、调试和图像编辑器。标准工具栏是打开 Visual Studio 2010 时出现的默认工具栏，如图 1.53 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_82_1.png)

用户可以通过添加或删除按钮来自定义此工具栏。标准工具栏包含以下按钮：

- `New Project` — 创建新项目或新网站
- `Add New Item` — 存在于以下两个自解释的子类别中：
  - `Add New Item` — 在 Web 应用程序中添加新项，例如 Web 窗体和样式表
  - `Add Existing Item` — 在 Web 应用程序中添加本地系统中已有的项，例如图像
- `Open File` — 在 IDE 中打开 Web 项目、Windows 项目或任何其他 .NET 项目
- `Save` — 保存当前设计的窗体
- `Save All` — 保存对项目所做的所有更改
- `Cut` — 剪切对象或项，例如代码和控件
- `Copy` — 复制对象或项
- `Paste` — 粘贴剪切或复制的项
- `Undo` — 撤消在应用程序中进行的更改
- `Redo` — 通过单击标准工具栏的“撤消”按钮来撤消所做的更改
- `Navigate Backward` — 在应用程序内导航到之前访问的位置
- `Navigate Forward` — 在应用程序内导航到随后访问的位置
- `Start Debugging` — 调试代码
- `Solution Configuration` — 指定项目的配置
- `Solution Platforms` — 指定项目的平台
- `Find in Files` — 在项目中查找关键字
- `Find` — 在代码块中查找关键字
- `Solution Explorer` — 启动“解决方案资源管理器”
- `Properties Window` — 启动“属性”窗口以设置 Web 页面和控件的属性
- `Object Browser` — 启动“对象浏览器”窗口
- `Toolbox` — 启动“工具箱”窗口
- `Start Page` — 显示“开始”页面
- `Command Window` — 启动“命令”窗口
- `Extension Manager` — 使你能够从 IDE 查找和安装 Visual Studio 扩展

## The Class View Window

“类视图”窗口包含一个分层树视图，表示顶层节点的项目。它还显示与特定项目关联的类、方法和属性。你可以通过以下任一方式访问“类视图”窗口：

- 从主菜单中选择 `View→Class View`
- 按 `Ctrl+Shift+C` 键

图 1.56 显示了“类视图”窗口：

![](img/e073a4882197be4ab61103cbe0bcb394_85_0.png)

Figure 1.56: Displaying the Class View Window

如你在图 1.56 中看到的，“类视图”窗口分为以下两个窗格：

- Objects pane – 显示可扩展的符号树，其顶层节点表示项目。此分层视图指定代码内的符号结构。在“对象”窗格中选择对象会将其成员显示在“成员”窗格中。
- Members pane – 显示对象中存在的成员列表。

“类视图”窗口还包含一个工具栏，其中包含以下按钮：

- `New Folder` – 创建新文件夹或子文件夹，你可以将其符号或控件拖入其中，以便下次需要时轻松访问它们。
- `Back` — 导航到之前选中的项目，直到到达第一个项目。
- `Forward` — 导航到下一个项目，直到到达最近选中的项目。
- `Class View Settings` — 使用此工具帮助进行不同设置。`Class View Settings` 中可用的各种命令如下：
  - `Show Base Types` — 在 Objects 窗格中显示基类型。
  - `Show Project References` — 显示一个虚拟文件夹，用于显示放置在项目引用中的对象。
  - `Show Hidden Types and Members` — 在 Objects 窗格中显示隐藏类型，并在 Members 窗格中显示隐藏成员。
  - `Show Public Members` — 为使用该类的用户显示公共成员。
  - `Show Protected Members` — 为扩展该类的用户显示受保护的成员。
  - `Show Private Members` — 为实现和使用该类的用户显示所有访问级别的成员。
  - `Show Other Members` — 显示不属于公共、私有、受保护或继承类别的成员
  - `Show Inherited Members` — 在 Members 窗格中显示继承的成员。
- `View Class Diagram` — 显示当前选中对象的类详细信息。当你在 Objects 窗格中选择一个对象时，可以通过单击工具栏中的此按钮获取类图。

## The Properties Window

Properties 窗口用于查看和修改所选对象的设计时属性和事件。此窗口还使你能够编辑添加到窗体中的控件的属性。例如，要查看和修改窗体的属性，请打开设计器并选择窗体。Properties 窗口可以通过以下任一方式打开：

- 通过从主菜单中选择 `View→Properties Windows`
- 通过按 `F4` 键

图 1.57 显示了窗体的 Properties 窗口：

![](img/e073a4882197be4ab61103cbe0bcb394_86_0.png)

图 1.57：显示 Properties 窗口

如果你想查看和修改其他组件的属性，例如按钮或标签，则将这些组件拖放到窗体上并选择要修改其属性的组件。当你选择适当的组件时，与该组件关联的属性将在 Properties 窗口中显示。Properties 窗口中显示的属性对于不同的组件或控件是不同的。换句话说，与 `Button` 控件关联的属性与与 `Label` 或 `Form` 控件关联的属性不同。请注意，Properties 窗口中的某些属性以灰色文本显示。显示为灰色的属性是只读属性。

Properties 窗口还显示包含各种按钮的工具栏。这些按钮从左到右解释如下：

- `Categorized` – 使你能够将控件的属性分组到类别中。属性根据其在控件中执行的功能进行分类。例如，当你在 Solution Explorer 中选择一个窗体并单击工具栏上的 `Categorized` 按钮时，`Form` 属性将被分组到 Accessibility、Appearance、Behavior、Data、Design、Focus、Layout、Misc. 和 Window Style 类别中。
- `Alphabetical` – 按字母顺序显示控件的属性。
- `Properties` – 显示控件的所有属性。
- `Events` – 显示控件的所有事件。
- `Property Pages` – 为所选组件显示 `Property Pages` 对话框。你可以使用 `Property Pages` 对话框来查看和编辑与项目配置相关的属性。
