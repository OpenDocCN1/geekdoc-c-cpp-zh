## 9.2 为对象定义类

```cpp
class Circle {
public:
    // 此圆的半径
    double radius; // 数据字段

    // 构造一个圆对象
    Circle() {
        radius = 1;
    }

    // 构造一个圆对象
    Circle(double newRadius) {
        radius = newRadius;
    }

    // 返回此圆的面积
    double getArea() {
        return radius * radius * 3.14159;
    }
};
```
