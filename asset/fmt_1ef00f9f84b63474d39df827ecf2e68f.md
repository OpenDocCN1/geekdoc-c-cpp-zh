# C 标准库

C++ 标准库包含了整个 C 标准库。头文件通常相同，但有两点不同：

- 头文件名称为 `<name.h>`

- 在 `<name>` 头文件中声明的所有名称都在 `std` 命名空间中。

> 注意 为了向后兼容性，如果你需要，仍然可以包含 `<name.h>`。但是这会将名称放入全局命名空间而不是 `std` 命名空间，此外，使用 `<name.h>` 已被弃用。建议避免使用此功能。

## 896 | 附录 C 标准库头文件

下表提供了最常用功能的总结。请注意，建议避免使用 C 功能，尽可能使用等效的 C++ 特性。
