## 在 for 循环中两个两个值产生第三值

```c
#include <stdio.h>
int main() {
    int i, j, k, n;
    printf("Enter n: ");
    scanf("%d", &n);
    for (i = 1, j = n; i <= n, j >= 1; i++, j--) {
        k = i*j;
        printf("\n%d\t%d\t%d\t", i, j, k);
    }
    getch();

}
```
