### 回顾：Medicare 索赔数据基础

在第 2 章到第 5 章中，我们讨论了使用 Medicare 行政数据编程的以下特征（注意，此回顾也适用于第 8、9 和 10 章，尽管我们将在这些章节中不再重复）：

- 使用 Medicare 索赔数据并不直观。Medicare 支付系统的主要目的不是为了研究创建数据，而是为了判定和支付索赔。这一事实对使用我们的行政数据文件有影响，我们必须理解 Medicare 程序才能有效使用 Medicare 数据。
- 存在由 Medicare Part A 和 Part B 支付的索赔数据。Medicare 文件对最终的 Part B 承运人、耐用医疗设备（DME）、住院、专业护理机构（SNF）、家庭健康和临终关怀服务分别付费。
- Part B 承运人数据集最常见与医生诊所提供的服务（如体检）的索赔相关。然而，承运人数据还包括由临床社会工作者、脊骨按摩师、救护车、护士医师和医生助理提交的索赔。此外，该文件还包括在医生诊所外进行的服务的索赔，例如流动手术中心、医院和医院急诊室。通常，承运人索赔文件是用于研究目的最大的 Medicare 数据集。
- DME 文件包括轮椅和助行器、医院床、血糖监测仪及相关用品、拐杖和支架、夹具、假体、呼吸设备（如氧气设备）及相关用品，以及透析设备和用品的支付索赔。
- 门诊数据集包含机构住院部门提交的最终判定索赔。然而，该文件还包括其他类型机构住院提供者的索赔，例如流动手术中心、门诊康复设施、农村健康诊所和社区精神健康中心。
- 住院数据集包含由长期住院和短期住院患者提交的用于报销机构费用的最终判定索赔，包括房间费用，甚至是受益人住院期间提供的某些药物。

让我们通过衡量 2010 年医生诊所环境下的 E&M 服务数量，开始对我们持续注册受益人人口的利用特征进行调查。在步骤 7.2 中，我们创建了一个宏变量，通过寻找以“99”开头的程序代码值（表示标准中的“E&M”部分）来识别我们正在衡量的 E&M 服务。我们在宏变量中包含了以下程序代码：99201、99202、99203、99204、99205、99211、99213、99214 和 99215。你可以在网上查询或通过购买程序代码术语手册来了解关于这些程序代码值的定义的信息。请注意，我们并没有使用所有以“99”开头的程序代码。例如，99241 和 99245 等程序代码值识别的是会诊，但这些会诊发生在医生诊所之外。

%let emcodes='99201', '99202', '99203', '99204', '99205', '99211',

在步骤 7.3 中，我们在索赔数据集（标准中的“医生诊所环境”部分）`UTL_CARR_2010_FNL` 中搜索宏变量包含的程序代码。承运索赔有 13 行项目，因此我们的数据集每条索赔（或每条记录）有 13 个程序代码需要搜索。我们通过创建一个代表程序代码变量（`HPCS_CD1-HPCS_CD13`）的数组 `HPCS_CD` 来执行此搜索。然后，我们创建一个名为 `EM_SVC` 的标记，如果数组中的程序代码变量位于宏变量定义的程序代码集中，则将该标记置为 1。如果发现此类证据，`leave` 语句将结束处理并搜索下一条记录（换句话说，我们不是统计索赔中可能存在的所有 E&M 服务，而是寻找单个 E&M 服务的证据）。输出（`EM_UTIL`）包含了承运数据集中的索赔，并精简了变量集，用于定义受益人、服务日期、提供者以及指示发现 E&M 服务的标记。此输出文件仅包含 `EM_SVC` 等于 1 的记录。

```sas

data em_util (keep=bene_id em_svc);

  set utl.carr_2010_fnl (keep=bene_id expnsdt=prfnpi; hcpcs_cd:);

  array hcpcscd(13) hcpcs_cd1-hcpcs_cd13;

  em_svc=0;

  do i=1 to 13;

    if substr(hcpcscd(i),1,5) in (&emcodes) then do;

      em_svc=1;

      leave;

    end;

  end;

  if em_svc=1;

run;
```

proc sql;
  create table util.stay_util as
    select distinct(bene_id), adms_dt, dschrgdt, count(bene_id) as stay_cnt, sum(ip_los) as tot_ip_los
    from stay_util
    group by bene_id;
quit;

data util.stay_util;

  ip_alos=tot_ip_los/stay_cnt;
