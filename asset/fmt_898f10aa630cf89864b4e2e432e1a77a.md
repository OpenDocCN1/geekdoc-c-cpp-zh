
这意味着你只能跳转到与 `goto` 本身位于同一个函数中的标签。其他函数中的标签不在 `goto` 的作用范围内。这意味着你可以在两个函数中使用相同的标签——但不能在同一个函数中使用相同的标签。

`retry:`


## 31.9 goto 与变量作用域

我们已经看到过标签具有函数作用域，但如果你跳过了某些变量的初始化，就会发生奇怪的事情。

看这个示例，我们从变量 `x` 作用域之外的地方跳转到其作用域的中间。

这可以通过编译并运行，`'x' 在此函数中被未初始化就使用了`

`warning: 'x' 在此函数中被未初始化使用`

然后当我运行它时，它输出了 0。

基本上发生的情况是，我们跳转进了 `x` 的作用域，但我们跳过了实际上将其初始化为 12345 的那行代码。该值是不确定的。

修复方法当然是无论通过什么方式让初始化位于标签之后。

```c
goto label;
{
    int x;
label:
    x = 12345;
    printf("%d\n", x);
}
```

让我们再看一个示例。

```c
{
    int x = 10;
label:
    printf("%d\n", x);
}
```

这里发生了什么？

在第一次通过块时，我们跳转进了 `x` 的作用域，但跳过了它的初始化。这意味着我们仍然可以打印它，但该值是不确定的。

在我的机器上，它再次打印了 10，但那只是运气。由于 `x` 是未初始化的，在 `goto` 之后它可能会打印任何值。

## 31.10 goto 与变长数组

关于 VLA 和 `goto`，有一个规则：你不能从 VLA 作用域外跳转到该 VLA 的作用域内。

如果我尝试这样做：

```c
int x = 10;
goto label;
{
    int v[x];
label:
    printf("Hi!\n");
```

我得到了一个错误：

`error: 跳到具有可变修改类型的标识符作用域`

你可以跳转到 VLA 声明之前，如下所示：

```c
int x = 10;
goto label;
{
label:  ;
  int v[x];
  printf("Hi!\n");
}
```

因为这样 VLA 在其离开作用域并导致不可避免的销毁之前被正确分配了。

## 32.1 复合字面量

这是语言中一个很酷的特性，允许你动态创建一个某种类型的对象，而无需将其赋值给变量。你可以创建简单类型、数组、结构体，随你所欲。它的主要用途之一是在向函数传递复杂参数时，你不想创建一个临时变量来持有该值。创建复合字面量的方法是将类型放在括号中，然后在后面放上初始化列表。例如，一个未命名的整数数组，可能像这样：

```c
(int[]){1, 2, 4};
```

现在，那行代码本身什么都没做。它创建了一个未命名的整数数组，然后将其丢弃了。我们可以使用指针来存储对数组的引用。

```c
int *p = (int[]){11, 2, 4};
printf("%d\n", p);
```
