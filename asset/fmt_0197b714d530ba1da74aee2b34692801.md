
`TabControl` 类有一些属性，允许您操作 `TabControl` 控件中的选项卡。表 17.14 列出了 `TabControl` 类中值得注意的属性：

**表 17.14：`TabControl` 类的值得注意的属性**

| Property | Description |
| --- | --- |
| SelectedContent | 获取当前选中的选项卡中的内容。默认情况下，该属性的值为空引用。 |
| SelectedIndex | 设置或获取当前选中的选项卡的索引。选项卡的起始索引为零，这意味着 `TabControl` 控件中第一个选项卡的索引为 0，第二个选项卡的索引为 1，依此类推。如果未选中任何选项卡，该属性的值为 -1。 |
| SelectedItem | 设置或获取当前选中的选项卡。如果未选中任何选项卡，该属性的值为空引用。 |
| TabStripPlacement | 设置或获取一个值，该值指示选项卡标题相对于选项卡内容的对齐方式。 |

`TabControl` 类有一个名为 `SelectionChanged` 的事件，每当您选择一个选项卡（`TabItem` 对象）时都会发生。`TabControl` 类中的选项卡是 `TabItem` 类的实例。每个 `TabItem` 实例只能包含一个内容，也就是说，它只能容纳一个 UI 控件或由容器控件容纳的多个控件组。

如您所知，Silverlight 的设计器分为 Design 视图和 XAML 视图。Design 视图和 XAML 视图都支持 XAML 编辑、IntelliSense 功能，以及在各 XAML 元素或标记之间导航。Silverlight 应用程序作为节点树进行处理。根节点是 `Window` 或 `MainPage` 控件，其子节点是容器控件。您添加的控件会成为容器控件的子节点。

接下来，让我们讨论 Silverlight 的 `AutoCompleteBox` 控件。

## AutoCompleteBox 控件

`AutoCompleteBox` 控件是 Silverlight 3.0 中的新控件，它提供了一个文本框，用户可以在其中输入一些数据，并提供了一个下拉列表，当用户在文本框中键入单词或字符时，该下拉列表会显示可能的匹配项。使用 `AutoCompleteBox` 控件，用户可以从下拉列表中选择合适的项来完成文本框中的输入，而不必键入整个单词。例如，如果 `AutoCompleteBox` 控件包含星期名称 `Monday`、`Tuesday`、`Wednesday` 和 `Thursday`，而用户在文本框中输入 `T`，则会出现一个下拉列表，显示 `Tuesday` 和 `Thursday`。另一个您可能熟悉的 `AutoCompleteBox` 控件的常见示例是 Google 搜索框。图 17.16 显示了一个 `AutoCompleteBox` 控件：

![](img/e073a4882197be4ab61103cbe0bcb394_893_0.png)

图 17.16：Silverlight 3.0 中的 `AutoCompleteBox` 控件

如果将 `AutoCompleteBox` 控件的 `IsTextCompletionEnabled` 属性设置为 `true`，那么当您在文本框中键入时，`AutoCompleteBox` 控件会自动为您补全文本。

`AutoCompleteBox` 控件是 `AutoCompleteBox` 类的一个实例，该类位于 `System.Windows.Controls` 命名空间中的 `System.Windows.Controls.Input.dll` 程序集中。`AutoCompleteBox` 类的类层次结构如下所示：

- `System.Object`
  - `System.Windows.DependencyObject`
    - `System.Windows.UIElement`
      - `System.Windows.FrameworkElement`
        - `System.Windows.Controls.Control`
          - `System.Windows.Controls.AutoCompleteBox`

`AutoCompleteBox` 类有一些属性，使您能够在 Silverlight 应用程序中使用 `AutoCompleteBox` 控件。表 17.15 列出了 `AutoCompleteBox` 类中值得注意的属性：

**表 17.15：`AutoCompleteBox` 类的值得注意的属性**

| Property | Description |
| --- | --- |
| IsTextCompletionEnabled | 获取或设置一个值，该值指示在筛选过程中找到的第一个可能匹配项将自动显示在 `AutoCompleteBox` 控件的文本框中。 |
| ItemFilter | 获取或设置一个自定义方法，该方法使用用户输入的文本来筛选 `ItemsSource` 属性指定的项，以便在下拉列表中显示。 |
| ItemsSource | 获取或设置一个集合，该集合用于生成要在 `AutoCompleteBox` 控件的下拉列表中显示的项。 |
| ItemTemplate | 获取或设置用于在控件的下拉部分显示每个项的 `DataTemplate`。 |
| MinimumPopulateDelay | 获取或设置最小延迟时间（以毫秒为单位），即用户在文本框中输入一些文本之后、`AutoCompleteBox` 控件在下拉列表中填充所有可能匹配项的列表之前所需的延迟。 |
| MinimumPrefixLength | 获取或设置最小前缀长度，即先要在文本框中输入的字符数，然后 `AutoCompleteBox` 控件才会在下拉列表中显示可能的匹配项。 |
| SearchText | 获取用于筛选 `ItemsSource` 项集合中的项的文本。 |
| SelectedItem | 获取或设置 `AutoCompleteBox` 控件下拉列表中的选中项。 |
| SelectionAdapter | 获取或设置选择适配器，该适配器用于在 `AutoCompleteBox` 控件的下拉列表中填充可选择项的列表。 |
| Text | 获取或设置 `AutoCompleteBox` 控件文本框中的文本。 |
| TextFilter | 获取或设置一个自定义方法，该方法使用用户输入的文本，以基于文本的方式筛选 `ItemsSource` 属性指定的项，以便在下拉列表中显示。 |

## DataPager 控件

`DataPager` 控件也是 Silverlight 3.0 中引入的新控件。当您拥有大量数据，并且无法在单个页面中显示全部数据时，可以使用 `DataPager` 控件。`DataPager` 控件用于表示对数据集合进行分页所需的 UI。您可以为实现 `IPagedCollectionView` 接口的数据集合带来分页功能，将其作为数据源。`IPagedCollectionView` 接口包含方法和属性的定义，用于为数据集合提供分页功能。例如，您可以在 Silverlight 应用程序中将 `DataPager` 控件与 `ListBox` 控件一起使用，对 `ListBox` 控件中显示的数据进行分页。图 17.17 显示了一个与 `ListBox` 控件一起使用的 `DataPager` 控件：

![](img/e073a4882197be4ab61103cbe0bcb394_895_0.png)

图 17.17：Silverlight 3.0 中的 `DataPager` 控件

`DataPager` 控件是 `DataPager` 类的一个实例，位于 `System.Windows.Controls` 命名空间中的 `System.Windows.Controls.Data.dll` 程序集中。`DataPager` 类的类层次结构如下所示：

- `System.Object`
  - `System.Windows.DependencyObject`
    - `System.Windows.UIElement`
      - `System.Windows.FrameworkElement`
        - `System.Windows.Controls.Control`
          - `System.Windows.Controls.DataPager`

`DataPager` 类有一些属性，使您能够在 Silverlight 应用程序中使用 `DataPager` 控件。表 17.16 列出了 `DataPager` 类中值得注意的属性：

**表 17.16：`DataPager` 类的值得注意的属性**

| Property | Description |
