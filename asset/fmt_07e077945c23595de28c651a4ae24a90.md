### ELSE 语句

条件子句不必非在 `ELSE` 语句中。例如：

```
data work.bonus.sales;

  set orion.sales;

  if Country='US' then Bonus=500;

  else Bonus=300;

run;
```

> 所有不等于 `US` 的观测值获得 300 的奖金。

### 业务场景

通过读取 `orion.sales` 数据集创建一个名为 `Work.bonus` 的新 SAS 数据集。

`Work.bonus` 必须包含名为 `Bonus` 的新变量，其值为：
* 美国员工为 500
* 澳大利亚员工为 300

`Work.bonus` 必须包含另一个名为 `Freq` 的新变量，其值为：
* 美国员工为每年一次
* 澳大利亚员工每年两次

### IF-THEN/ELSE 语句

`IF-THEN/ELSE` 语句中仅允许一个执行语句。

```
IF expression THEN statement;

ELSE IF expression THEN statement;

ELSE statement;
```

对于给定的业务场景，每个真表达式需要执行两个语句。`Bonus=500;`

## IF-THEN DO/ELSE DO 语句

`IF-THEN DO/ELSE DO` 语句中允许多个执行语句。

| IF expression DO; | DO Group |
|---|---|
| executable statements | |
| END; | |
| ELSE IF expression DO; | DO Group |
| executable statements | |
| END; | then-do 允许对一个条件执行多一件事！ |

- 每个 `DO` 组可以包含多个适用于语句。
- 每个 `DO` 组以 `END` 语句结束。

### 业务场景

创建另一个名为 `Freq` 的变量。

```
data work.bonus;

set orion.sales;

if Country='US' then do;

  Bonus=500;

  Freq='Once a Year';

end;

else if Country='AU' then do;

  Bonus=300;

  Freq='Twice a Year';

end;

run;
```

### 业务场景

```
proc print data=work.bonus;
```

# LENGTH 语句（回顾）

`LENGTH` 语句显式定义变量的长度。

`LENGTH` 语句的一般形式：

```
LENGTH variable(s) $ length;
```

示例：

`length First_Name Last_Name $ 12`
`Gender $ 1;`

### 业务场景

设置变量 `Freq` 的长度以避免截断。

```
data work_bonus;

  set orion.sales;

  length Freq $12;

  if Country='US' then do

    Bonus=500;

    Freq='Once a Year';

  end

  else if Country='AU' then do

    Bonus=300;

    Freq='Twice a Year';

  end

run;
```

# ELSE 语句

条件句不需要在 `ELSE` 语句中。

```
data work.bonus;

  set orion.sales;

  length Freq $ 12;

  if Country='US' then do;

    Bonus=500;

    Freq='Once a Year';

  end;

  else do;

    Bonus=300;

    Freq='Twice a Year';

  end;

run;
```
