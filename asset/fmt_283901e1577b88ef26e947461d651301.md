2 查看猫的“造型”（Costume）标签页。你会看到两个造型。如果你让它反复切换，它看起来就像像在走路。这被称为动画。

![](img/b061febeb032d536c8c7de6511458796_64_1.png)

快速的造型切换会让猫看起来像在走路。

![](img/b061febeb032d536c8c7de6511458796_64_2.png)

![](img/b061febeb032d536c8c7de6511458796_64_3.png)

```
when clicked

go to x: (-180) y: (-120)

forever

  if right arrow pressed? then

    change y by 10

    next costume

  if left arrow pressed? then

    change x by (-10)

    next costume
```

+ 3 创建此脚本，这样你就可以使用左右方向键沿舞台底部移动猫了。紫色的“下一个造型”模块每隔10步就会改变一次猫的造型。
