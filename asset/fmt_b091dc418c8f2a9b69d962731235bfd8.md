## 继承一个类

继承是面向对象编程的主要特性之一。它允许你重用现有代码。在 In Depth 部分，你已经了解到一个类可以从另一个类继承。允许其通用属性被继承的类被称为基类或父类，而继承基类属性的类被称为派生类或子类。在 Listing 5.1 中，`BaseClass` 类是父类，`DerivedClass` 类继承了 `BaseClass` 类的特性，因此它是子类。让我们创建一个名为 `MyInheritance` 的应用程序（也在 CD 上提供）来学习如何继承一个类。Listing 5.1 显示了 `MyInheritance` 应用程序的代码：

### Listing 5.1: Showing the Code of MyInheritance Application

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyInheritance
{
public class BaseClass
{
    public int DataMember;
    public void BaseClassMethod()
    {
        Console.WriteLine("I am a Base Class Method()");
    }
}
public class DerivedClass : BaseClass
{
    public void DerivedClassMethod()
    {
        Console.WriteLine("I am a Derived Class Method()");
    }
}
public class Program
{
    public static void Main(string[] args)
    {
        // Create a Base Class Object
        Console.WriteLine("I am accessing Base Class object:");
        BaseClass bc = new BaseClass();
        bc.DataMember = 1;
        bc.BaseClassMethod();
        // Create a Derived Class Object
        Console.WriteLine("");
        Console.WriteLine("I am accessing Derived Class object:");
        DerivedClass dc = new DerivedClass();
        dc.DataMember = 2;
        dc.BaseClassMethod();
        dc.DerivedClassMethod();
        Console.Write("\nPress ENTER to quit..");
        Console.ReadLine();
    }
}
}
```

在 Listing 5.1 中，我们创建了三个类，`BaseClass`、`DerivedClass` 和 `Program`。`DerivedClass` 类继承了 `BaseClass` 类。这意味着 `DerivedClass` 类继承了 `BaseClass` 类的所有成员。在 `Program` 类中，我们初始化了这些类并调用方法。

## 使用扩展方法

正如你在“深入解析”部分所学到的，扩展方法可以在不创建新派生类或修改原始类的情况下扩展类。让我们创建一个名为 `MyExtensionMethod` 的应用程序（也可在光盘上获得）来学习如何使用扩展方法。

### 清单5.3：显示 MyExtensionMethod 应用程序的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyExtensionMethod
{
public static class MyClass
{
public static int MyExtensionMethod(this string Number)
{
return Int32.Parse(Number);
}
public static int MyStaticMethod(string Number)
{
return Int32.Parse(Number);
}
}
class MainClass
{
static void Main(string[] args)
{
string Number = "100";
int ext = Number.MyExtensionMethod(); // Line A
Console.WriteLine("The Output from MyExtensionMethod()");
Console.WriteLine(ext);
int stat = MyClass.MyStaticMethod(Number); // Line B
Console.WriteLine("");
Console.WriteLine("The Output from MyStaticMethod()");
Console.WriteLine(stat);
Console.Write("\nPress ENTER to quit...");
Console.ReadLine();
}
}
}
```

在清单5.3中，我们创建了两个方法：`MyExtensionMethod()` 和 `MyStaticMethod()`。`MyExtensionMethod()` 方法是一个扩展方法，其 `string` 类型参数 `Number` 前面有 `this` 关键字；而 `MyStaticMethod()` 静态方法的参数声明中则没有 `this` 关键字。在调用 `MyExtensionMethod()` 方法时，我们没有传递任何参数（参见清单5.3中的A行）；而在调用 `MyStaticMethod()` 方法时，我们传递了 `Number` 参数（参见清单5.3中的B行）。

## 使用访问器和修改器实现封装

正如你之前学到的，在 C# 中封装是通过使用 `private` 访问修饰符来实现的。在本节中，你将学习创建一个名为 `Employee` 的应用程序（也可在光盘上获得），以使用访问器和修改器来封装数据。访问器和修改器是用于获取和设置变量值的方法。
