## 通过XAML向Grid添加行和列

本章的深入探究部分解释了`Grid`元素（或控件）默认会添加到独立的WPF应用程序和XBAP中。您可能还记得，`Grid`元素默认只有一个单元格，即一行一列。如果希望在`Grid`中垂直增加单元格数量，则需要向`Grid`元素添加更多行。如果存在多余的行，也可以将其删除。类似地，若要在`Grid`元素中水平增加单元格数量，则需要添加更多列。这样，每一行都可以有多列。

请注意，您在XAML视图中所做的更改会立即反映在Design视图中，反之亦然。

现在，让我们通过执行以下步骤创建一个名为`GridRowsColumns`的独立WPF应用程序（也可在CD上获取）：

- 1. 创建一个新的WPF应用程序`GridRowsColumns`。

- 2. 在`MainWindow.xaml`文件的`<Grid>`和`</Grid>`标签内添加以下代码片段：

```
<Grid.RowDefinitions>
  <RowDefinition Height="20"/>
  <RowDefinition Height="50"/>
  <RowDefinition Height="50*"/>
  <RowDefinition Height="50*"/>
</Grid.RowDefinitions>
```

在以上代码片段中，`Grid.RowDefinitions`元素是`Grid`元素的子元素。`Grid.RowDefinitions`元素包含四个子`RowDefinition`元素，用于定义网格中的四行。设置`RowDefinition`元素的`Height`属性以指定每一行的高度。第一行的高度为20像素，第二行为50像素。第三行和第四行的高度为`50*`，其中星号表示网格中剩余空间的百分比。

- 3. 使用以下代码片段在`GridRowsColumns`应用程序的`<Grid>`和`</Grid>`标签内添加列：

```
<Grid.ColumnDefinitions>
  <ColumnDefinition Width="25"/>
  <ColumnDefinition Width="50"/>
  <ColumnDefinition Width="30*"/>
  <ColumnDefinition Width="50*"/>
</Grid.ColumnDefinitions>
```

在以上代码片段中，`Grid.ColumnDefinitions`元素是`Grid`元素的子元素。`Grid.ColumnDefinitions`元素包含四个子`ColumnDefinition`元素，用于定义网格中的四列。设置`ColumnDefinition`元素的`Width`属性以指定每一列的宽度。第一列和第二列的宽度分别为25像素和50像素。但是，第三列和第四列的宽度设置为`30*`和`50*`，其中星号表示网格中剩余空间的百分比。

尽管Design视图会立即显示您通过XAML代码添加的行和列，但我们使用四个`Button`控件或元素来让您更清楚地理解。

- 4. 在`<Grid>`和`</Grid>`标签内添加以下代码片段，以通过控件显示行和列：

```
<Button Name="button1" Content="OK" Grid.Row="0" Grid.Column="0" Grid.RowSpan="2"/>
<Button Name="button2" Content="Yes" Grid.Row="2" Grid.Column="1"/>
<Button Name="button3" Content="No" Grid.Row="2" Grid.Column="3"/>
<Button Name="button4" Content="Cancel" Grid.Row="3" Grid.Column="2" Grid.ColumnSpan="2"/>
```

在以上代码片段中，使用了四个`Button`元素，分别名为`button1`、`button2`、`button3`和`button4`。通过将`Grid.Row`和`Grid.Column`属性设置为零，`button1`元素出现在第一行和第一列。`Grid.Row`和`Grid.Column`属性指示`button1`所在的行和列。`Grid.RowSpan`属性设置为2，这意味着`button1`跨越两行。类似地，`button2`出现在第三行第二列，`button3`出现在第三行第四列，`button4`出现在第四行并跨越第三和第四列，如图9.41所示：
