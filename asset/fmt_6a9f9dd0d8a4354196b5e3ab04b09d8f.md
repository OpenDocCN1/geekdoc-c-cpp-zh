
答案是一个面板，这是我们预期的结果。尽管默认的 `DATAPANEL` 布局尝试生成交叉的完全笛卡尔积（在本例中为 400 个 `STATE*CITY` 交叉），但它不会为没有数据的单元格创建面板。`SPARSE` 选项控制当某个交叉没有观测值时是否创建面板单元格，默认情况下 `SPARSE=FALSE`。

`DATALATTICE` 布局不支持 `SPARSE` 选项。它会为 `ROWVAR` / `COLMVAR` 的每个唯一值创建一个行/列。因此，会为两个变量的所有值创建一个单元格，共创建 400 个单元格。

当分类变量交叉时，数据中有时意料之外的间隙。例如，假设你正在进行一项研究，许多受试者接受四种以上的治疗，这些可能会在不同程度的活动后降低受试者的心率。然而，假设受试者 101 没有接受治疗3，而受试者 102 没有接受治疗2。在这种情况下，你创建一个 `DATAPANEL` 布局，每个面板显示三个受试者的四种治疗，预期的列对齐将无法工作：

### 使用 PROC SGPANEL 创建分类面板

在创建如“在分类面板中使用非计算图”所示的面板时，你可能会发现使用 SAS 中的 `PROC SGPANEL` 创建面板更容易，因为该过程为你完成了所有必要的计算。例如，`REGRESSIONPLOT`、`LOESSPLOT` 和 `PBSPLINE` 语句已作为 `REG`、`LOESS` 和 `PBSPLINE` 语句整合到 `SGPANEL` 过程中（`SGPANEL` 也可以生成其他类型的图）。默认情况下，`PROC SGPANEL` 的 `PANELBY` 语句创建 `DATAPANEL` 布局。

```sas
ods html style=statistical;
title "随时间变化的剂量 (mg) 预测响应值";
proc sgpanel data=trial;
panelby dose / rows=1;
reg x=days y=response / cl clm;
run;
```

![](img/a9ccb6123dee40d424cb295a3a99c16c_304_0.png)

`DATALATTICE` 和 `DATAPANEL` 布局的大多数特征（但不是全部）都由 `SGPANEL` 过程提供。

`SGPANEL` 过程支持 `HISTOGRAM`、`DENSITY`、`DOT`、`VBOX` 和 `HBOX`（垂直和水平箱线）等图语句。`PANELBY` 语句控制布局，决定使用 `DATAPANEL`、`DATALATTICE` 或其他布局来生成图形。`ROWAXIS` 和 `COLAXIS` 语句控制外部轴，`KEYLEGEND` 语句创建图例并将其放置在侧边栏中。

`SGPANEL` 过程没有 `PROTOTYPE` 块，因为 `PANELBY` 之后的所有图语句都被视为原型的一部分。`SGPANEL` 过程在后台生成 `GTL` 模板代码并执行该模板以创建输出。

以下示例显示了 `SGPANEL` 的额外功能：

```sas
ods html style=statistical;

title "按性别划分胆醇分布";
proc sgpanel data=sashelp.heart;
panelby sex_status / layout=lattice onepanel;
histogram cholesterol;

refline 227 / axis=x name="ref" legendlabel="Overall Mean";
rowaxis offsetmin=0 offsetmax=.1 max=30;

run;
```

当两个轴上使用相同的测量单位时，希望两个轴之间的相同间隔是相同的。为了实现这种效果，必须使用 `LAYOUT OVERLAYEQUATED` 布局。

## 等图的基本特征

对于指定图语句，`LAYOUT OVERLAYEQUATED` 布局与 `LAYOUT OVERLAY` 布局相似：你可以在布局内指定一个或多个 2D 图语句。然而，`LAYOUT OVERLAYEQUATED` 对图轴施加了限制并在若干方面与 `LAYOUT OVERLAY` 不同：

- X 和 Y 轴始终是数值（线性）。因此，具有离散或分箱轴的图类型（`BOXPLOT`、`BOXPLOTPARM`、`BARCHART`、`HISTOGRAM` 和 `HISTOGRAMPARM`）无法在此布局中使用。

- 对于两个轴上的相同间隔，显示距离是相同的。例如，X 轴上 2 个单位的间隔与 Y 轴上 2 个单位的间隔相同。

- 显示中的斜率与数据中的斜率相同。也就是说，数据中的 45 度斜率由显示中的 45 度斜率表示。`EQUATETYPE=` 选项提供了保持 45 度斜率的同时展示数据范围的方法（见“等轴类型”）。
