/*计算并打印电费的程序 */
#include <stdio.h>

main() {
    unsigned int units;

        if(units <= 400)

        else
            if(units <= 600)

```

```

这是正弦级数的和，x 以弧度表示。

### 解决方案

要解决该级数，使用以下步骤分配初始值：

- 步骤 1: `s ← 0`
- 步骤 2: `term ← x` 代表级数中的第一项

- 步骤 4: `s ← s + term`
- 步骤 5: `term ← term*x*x*(-1) / ((i+1)*(i+2))`
- 步骤 6: 当 `(i <= n)` 时，重复步骤 4 到步骤 6
