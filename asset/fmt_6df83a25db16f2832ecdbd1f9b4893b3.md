# 第 4 章 循环

当你在循环体*内部*声明变量时，该变量会在循环的每次迭代中创建，并在每次迭代结束后被移除。例如，考虑此循环中的 `interest` 变量：

```
while (balance < TARGET) {
    year++;
    double interest = balance * RATE / 100;
    balance = balance + interest;
} // interest 在此处不再被声明
```

相比之下，`balance` 和 `year` 变量是在循环体外声明的。这意味着同一个变量被用于循环的所有迭代。

- 检查循环条件

`while (balance < TARGET) {`

`    year++;`

`    double interest = balance * RATE / 100;`

`    balance = balance + interest;`

`}`

- 执行循环中的语句

`while (balance < TARGET) {`

`    year++;`

`    double interest = balance * RATE / 100;`

`    balance = balance + interest;`

`}`

- 再次检查循环条件

`while (balance < TARGET) {`

`    year++;`

`    double interest = balance * RATE / 100;`

`    balance = balance + interest;`

`}`

- 15 次迭代后

`while (balance < TARGET) {`
