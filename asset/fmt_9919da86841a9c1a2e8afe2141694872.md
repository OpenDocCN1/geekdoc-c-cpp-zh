这是另一个无限循环，它完全没有任何输出。原因是，我们不意中在 **while** 后面加了一个分号 ;。这会导致循环像下面这样工作……

```
while (i<=10)
{
    printf("%d\n", i);
    i=i+1;
}
```

由于 i 的值没有增加，控制将保持在循环内旋转，永不停止。请注意，将 **printf()** 和 **i = i +1** 封装在一对括号中并不是错误。事实上，我们可以在任何单个语句或一组语句周围加上一对括号，而不会影响程序的执行。
