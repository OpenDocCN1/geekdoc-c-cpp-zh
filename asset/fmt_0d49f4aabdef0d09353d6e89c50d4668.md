## 构建模块

模块是 Python 文件，包含保存为 `.py` 扩展名的代码。然后使用 `import` 命令将它们导入到 Python 中。

- 第 1 步 让我们从创建一组数学函数开始。将一个数字乘以二、三，并对数字进行平方（次方）。在 IDE 和编辑器中创建一个新文件：

```python
def timetwo(x):
    return x * 2
```
