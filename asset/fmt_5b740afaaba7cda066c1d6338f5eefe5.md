
## 逻辑或运算符

- **E1 || E2**，其中 `E1` 和 `E2` 是子表达式，求值 `E1`。如果 `E1` 的值为非零值（即真），则不求值 `E2`，整个表达式的结果为 1（即真）。如果 `E1` 的值为 0（即假），则 `E2` 将决定整个表达式的值。程序 4-11 的片段说明了这一事实。

### 程序 4-11 逻辑或运算符演示

```
1 //逻辑或运算符
2 #include<stdio.h>
3 main()
4 {
5 int i=0,j=k=2;
6 l=i||j++;
7 printf("Result values after evaluation are: \n");
8 printf("%d %d %d\n",i,j,k);
9 }
```

**输出窗口：**
```
求值后的结果为:
013
```

**备注：**
- 表达式 `l=E1||k` 被解释为 `(E1||k)`。如果 `E1` 为假，则不求值 `j`。
- `(E1||k)` 的结果为 0（即假）。
- 如果 `(E1||)` 为假，则不求值 `k`。
- `(E1&&)` 的结果为 0，假。

## 4.4.2.4 位运算符

C 语言提供了六种用于位操作的运算符。这些运算符不将操作数视为一个整体，而是对操作数的每一个位进行操作。C 语言中提供的位运算符如表 4.5 所示。

## 4.4.2.5 赋值运算符

可以使用赋值运算符给变量赋值。C 语言中的赋值运算符如表 4.7 所示。

### 表 4.7 赋值运算符

| 序号 | 运算符 | 运算符名称 | 类别 | 运算符元数个数 | 优先级 | 结合性 |
|---|---|---|---|---|---|---|
| 1. | `*=` | 赋值乘 | 赋值 | 二元 | Level-I | R→L |
| | `/=` | 赋值除 | 简写赋值运算符 | | | |
| | `%=` | 赋值取模 | | | | |
| | `+=` | 赋值加 | | | | |
| | `-=` | 赋值减 | | | | |
| | `&=` | 赋值与 | | | | |
| | `\|=` | 赋值或 | | | | |
| | `^=` | 赋值异或 | | | | |
| | `<<=` | 赋值左移 | | | | |
| | `>>=` | 赋值右移 | | | | |

### 关于赋值运算符的要点

1. 赋值运算符左侧的操作数应具有修改值。如果赋值运算符左侧的操作数没有修改值，将出现编译错误“L-value required”。
2. 简写赋值的形式为 `op1=op2`，其中 `op1` 和 `op2` 是操作数，`op1=op2` 是简写赋值运算符。例如，`a/=2` 等价于 `a=a/2`。
3. 简写赋值运算符符号之间不能有空格。
4. 如果赋值的两个操作数类型不同，赋值运算符右侧的操作数类型将自动转换为左侧的类型。为了执行此转换，会应用提升或降级。
5. 赋值的结果是被赋值的值。例如，在表达式 `a=b` 中，值 `b` 被赋值给 `a`，整个表达式求值为 `b`（即被赋值的值）。
6. “赋值”和“初始化”术语相关，但注意它们之间的区别是重要的。它们列在表 4.8 中。

### 表 4.8 初始化与赋值的区别

| 序号 | 初始化 | 赋值 |
|---|---|---|
| 1 | 定义时的首次赋值称为初始化。例如：`int a=0;` 是 `a` 的初始化 | 初始化后数据对象的值可以通过赋值来更改。例如：考虑以下语句 `a=10; b=20;` `a` 的值通过赋值语句改为 20 |
| 2 | 初始化只能进行一次 | 赋值可以进行任意次 |
| 3 | 限定常量可以初始化一个值。例如：`const int a=10;` 是合法的 | 限定常量不能赋值。如果 `a` 是限定常量，则写 `a=10;` 是错误的 |

## 4.4.2.6 杂项运算符

C 语言提供的其他运算符有：

1. 函数调用运算符（即 `()`）
2. 数组下标运算符（即 `[]`）
3. 成员选择运算符
   - a. 直接成员访问运算符（即 `.` 运算符或点）
   - b. 间接成员访问运算符（即 `->` 箭头运算符）
4. 间接运算符（即 `*`）
5. 条件运算符
6. 逗号运算符
7. `sizeof` 运算符
8. 取址运算符（即 `&`）

---

### 4.4.2.6.1 条件运算符

条件运算符是 C 语言中唯一的三元运算符（表 4.9）。

#### 表 4.9 条件运算符

| 序号 | 运算符 | 运算符名称 | 类别 | 运算符元数个数 | 优先级 | 结合性 |
|---|---|---|---|---|---|---|
| 1. | `?:` | 条件运算符 | 条件 | 三元运算符 | Level-I | R→L |

#### 关于条件运算符的要点

1. 条件运算符的通用形式为 `E1?E2:E3`，其中 `E1`、`E2` 和 `E3` 是子表达式。
2. 子表达式 `E1` 必须是标量类型。
3. 先求值子表达式 `E1`。如果它的求值为非零（即真），则求值 `E2` 并忽略 `E3`。如果 `E1` 的求值为零（即假），则求值 `E3` 并忽略 `E2`。

> 整数和浮点类型统称为算术类型。算术类型和指针类型统称为标量类型。

---

### 4.4.2.6.2 逗号运算符

逗号运算符用于将多个表达式结合（表 4.10）。

#### 表 4.10 逗号运算符

| 序号 | 运算符 | 运算符名称 | 类别 | 运算符元数个数 | 优先级 | 结合性 |
|---|---|---|---|---|---|---|
| 1. | `,` | 逗号运算符 | 逗号 | 二元 | Level-I | L→R |

#### 关于逗号运算符的要点

1. 每一个逗号符号都不是逗号运算符。函数调用中分隔参数的逗号不是逗号运算符。如果函数调用中的分隔符被视为逗号运算符，那么任何函数不能超过一个参数。声明/定义语句中的逗号不被视为逗号运算符。函数调用参数之间的逗号或声明/定义语句中的逗号是分隔符。
2. 逗号运算符保证了从左到右求值。
3. 在表达式 `E1, E2, E3...En` 中，子表达式 `E1, E2, E3...En` 按从左到右的顺序求值。整体评估的结果和类型是最右侧子表达式（即 `En`）求值的结果和类型。
4. 逗号运算符是左结合。

程序 4-12 中的代码说明了逗号运算符的使用。

#### 程序 4-12 逗号运算符演示

```
1 //Use of comma operator
2 #include<stdio.h>
3 main()
4 {
5 int a,b;
6 a=1, 2, 3, 4, 5;
7 b=(1, 2, 3, 4, 5);
8 printf("Result values of a and b:\n");
9 printf("%d%d", a, b);
10 }
```

**输出窗口：**
```
a 和 b 的结果值为:
15
```

**备注：**
- 赋值运算符的优先级大于逗号运算符。
- 因此，在表达式 `a=1,2,3,4,5` 中，子表达式首先求值。然后，赋值给 `a` 的值为 5。
- 在表达式 `b=(1,2,3,4,5)` 中，子表达式被括起来并将首先求值。逗号运算符的求值结果是最右侧子表达式的求值结果，即 `En`。因此，`(1,2,3,4,5)` 求值结果为 5 并赋值给 `b`。

## 4.4.2.6.3 sizeof 运算符

`sizeof` 运算符用于确定一个值或数据对象在内存中所占的字节大小（表 4.11）。

### 表 4.11 sizeof 运算符

| 序号 | 运算符 | 运算符名称 | 类别 | 元操作个数 | 优先级 | 结合性 |
|---|---|---|---|---|---|---|
| 1. | `sizeof` | Size-of 运算符 | 一元 | 一元 | I 级 | R→L |

#### 关于 sizeof 运算符的重要点

1. `sizeof` 运算符的通用形式为：
   - a. `sizeof expression` 或 `sizeof(expression)`（例如：`sizeof 2`, `sizeof(a)`, `sizeof(2+3)`）
   - b. `sizeof(type-name)`（例如：`sizeof(int)`, `sizeof(int*)`）
2. 如果 `sizeof` 运算符应用于类型名，则应使用括号，如下文第 1 点所示。
3. `sizeof` 运算符的求值结果类型为 `size_t`（通常为无符号整数类型）。
4. `sizeof` 运算符的操作数不会被求值。这一点可以通过执行程序 4-13 中列出的代码看出。
5. `sizeof` 运算符不能应用于不完整类型或函数类型的操作数。

| 4. | `+` `-` | 加法 减法 | 加法运算符 | 二元 | IV 级 | L→R |
| 5. | `<<` `>>` | 左移 右移 | 移位运算符 | 二元 | V 级 | L→R |

## 4.6 从键盘读取字符串

用户可以在运行时以类似于字符串常量的方式输入字符串并存储在字符数组中。从用户处读取字符串的方法有：

- **使用 `scanf` 函数**：带有 `%s` 指定的 `scanf` 函数可以从用户处读取字符串并存储在字符数组中。程序 4-14 中的代码段说明了使用 `scanf` 函数从用户处读取字符串。

### 程序 4-14 使用 scanf 读取字符串

```
1 //Reading strings using scanf
2 #include<stdio.h>
3 main()
4 {
5 char name[20];
6 printf("Enter your name\t");
7 scanf("%s",name);
8 printf("Your name is %s",name);
9 }
```

**输出窗口：**
```
Enter your name
Your name is Sam
```

**备注：**
`scanf` 函数会自动读取带有空字符的输入字符串，因此字符数组应该足够大以容纳输入加上终止空字符。
