### 3. 编写一个程序判断一个方矩阵是否为对称矩阵。

```c
int m[10][10], i, j, r,c;

printf("输入矩阵行数和列数:");
scanf("%d",&r,&c);

if(r != c)
{
    printf("对称矩阵必须是方矩阵");
    getch();
    exit(1);
}

/* 矩阵输入 */
for(i=0; i<r; i++)
{
    for(j=0; j<c; j++)
    {
{
    printf("输入元素 %d,%d",i+1,j+1);
    scanf("%d",&m[i][j]);
    }
}
}

/* 检查对称性 */
for(i=0; i<r; i++) {
    for(j=0; j<c; j++) {
        if(m[i][j] != m[j][i]) {
            printf("该矩阵不是对称矩阵");
            getch();
            exit(0);
        }
    }
}

printf("该矩阵是对称矩阵");
```

## 引言-

字符串是字符数组。任何包含在双引号之间的的字符组（双引号除外）都称为字符串常量。

字符串是以空字符 `(\0)` 结尾的一一维字符数组。

例如：

```c
char s[10] = {'s','h','i','v','a','m','\','\0'};
```
