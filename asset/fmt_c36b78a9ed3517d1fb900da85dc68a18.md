## 6.10 压构件的弯扭失稳

截面针对绕 `x` 轴或 `y` 轴较弱轴的屈曲以及弯扭失稳进行了计算。

普通的设计师不考虑对称形状的扭转失稳或非对称形状的弯扭失稳。这种感觉是这些条件并不控制临柱载荷，或者至少对它们的影响不大。这种假设可能与事实相径远。如果我们有由薄板制成的非对称甚至对称柱，我们会发现扭转失稳或弯扭失稳可能会显著降低柱的强度能力。

`AISC` 规范中的 `E4` 节考虑了钢柱的扭转或弯扭失稳。该节的第 `(b)` 部分提供了一种处理该问题的通用方法，适用于所有形状。该节的第 `(a)` 部分是对第 `(b)` 部分程序的改进，适用于用作柱的双角钢和工字钢。

此处介绍了第 `(b)` 部分的通用方法。该程序涉及使用 `E4-9` 确定弹性屈曲应力 `F_cr`（类似于欧拉屈曲应力）。在确定此值后，将其用于 `AISC` 方程 `E4-4`、`E4-5` 和 `E4-6` 中相应的后续，以获得扭转或弯扭弹性屈曲应力的 `F_cr`。然后根据 `E3-2` 或 `E3-3` 确定临界应力 `F_cr`。

接下来介绍了适用于双角钢和工字形构件的第 `(a)` 部分程序。临界应力 `F_cr` 由 `AISC` 方程 `E4-2` 确定。在该方程中，`F_cr` 取方程 `E3-2` 或 `E3-3` 中的 `F_cr`，`F_y` 和 `H` 则从方程 `E4-3` 和 `E4-10` 获取。

对于任一构件，扭转失稳和弯扭失稳极限状态的额压强度 `P_n` 使用 `AISC` 方程 `E4-1` 确定。在方程中，之前计算的 `F_cr` 乘以 `A_g`。

通常有必要考虑双对称形状的扭转失稳。此外，我们很少考虑没有对称轴的形状，因为我们不会将此类构件作柱。在某些情况下，我们可能会选择具有对称轴的截面作为柱，并且必须考虑侧扭失稳。

本节提供了一个关于用作柱的 `WT` 截面屈曲的数值示例（示例 6-9）。对于该形状，`x` 轴将受到屈曲影响，同时可能发生绕 `y` 轴（对称轴）的屈曲以及侧扭失稳。

使用 `AISC` 规范解决此问题涉及四个步骤。步骤如下：

- 1. 使用 `AISC` 方程 `E3-4`、`E3-2` 或 `E3-3`（视适用）以及 `E3-1` 确定构件 `x` 轴的屈曲强度。
- 2. 使用 `AISC` 方程 `E3-4`、`E3-2` 或 `E3-3`（视适用）以及 `E3-1` 确定构件 `y` 轴的屈曲强度。
- 3. 使用 `AISC` 方程 `E4-11`、`E4-9`、`E4-10`、`E4-5`、`E3-2` 或 `E3-3`（视适用）以及 `E4-1` 确定构件 `y` 轴的侧扭失稳强度。
- 4. 选择在前三个步骤中确定的最小 `P_n` 值。

### 解

使用 `WT10.5 × 66`（`A = 19.4 in²`，`t_f = 1.04 in`，`I_x = 181 in⁴`，`r_x = 3.06 in`，`I_y = 166 in⁴`，`r_y = 2.93 in`，`ȳ = 2.33 in`，`J = 5.62 in⁴`，`C_w = 23.4 in⁶`，`G = 11,200 ksi`）

- (1) 确定 `x` 轴的屈曲强度

```
F_ex = ((KL/r)_x^2)/((12 in/ft)(25 ft))/3.06 in^2 = 98.04
= π² E_y/((KL/r)_x^2) = (π²)(29,000)/(98.04)^2 = 29.78 ksi (AISC 方程 E3-4)
```

`(KL/r)_x^2 = 98.04 < 4.71√(29,000/50) = 113.43`

`F_cr = [0.658^(F_y/(KL/r)_x^2)]F_y` (AISC 方程 E3-2)

`= [0.658^(50.78/98.04)]50 = 24.76 ksi`

绕 `x` 轴屈曲的额定强度 `P_n` 为

`P_n = F_cr A_g = (24.76)(19.4) = 480.3 k` (AISC 方程 E3-1)

- (2) 确定 `y` 轴的屈曲强度

`(KL/r)_y^2 = 12 in/ft(20 ft)/2.93 in^2 = 81.91`

`F_ey = π² E_y/(KL/r)_y^2 = (π²)(29,000)/(81.91)^2 = 42.66 ksi` (AISC 方程 E3-4)

`(KL/r)_y^2 = 81.91 < 4.71√(29,000/50) = 113.43`

`F_cr = [0.658^(F_y/F_e)]F_y = [0.658^(90/F_y)]50 = 30.61 ksi` (AISC 方程 E3-2)

绕 `y` 轴屈曲的额定强度 `P_n` 为

`P_n = F_cr A_g = (30.61)(19.4) = 593.8 k` (AISC 方程 E3-1)

- (3) 确定构件绕 `y` 轴的弯扭失稳强度。注意 `x0` 和 `y0` 是相对于截面质心的剪心坐标。此处 `x0=0`，因为 `WT` 的剪中心位于 `y` 轴上，`y0 = t_f/2`，因为剪中心位于翼缘和腹缘的交处，如图 6.11 所示。

`x0 = 0`

`y0 = ȳ - t_f/2 = 2.33 - 1.04/2 = 1.81`

`ȓ0` 是绕剪心的极转转半径

`ȓ0² = x0² + y0² + (I_x + I_y)/A_g = 0² + 1.81² + (181 + 166)/19.4 = 21.66 in²` (AISC 方程 E4-11)

`F_ez = ((π² E C_wc)/(K_z L)² + G J)/(A_g ȓ0²) = (π²(2900)(23.4)/(12 × 20)² + 11,200(5.62))/(19.4(21.66)) = 153.62 ksi` (AISC 方程 E4-9)

`H = 1 - (x0² + y0²)/ȓ0² = 1 - (0² + 1.81²)/21.66 = 0.8417`

`F_cr = [0.658^(F_y/F_e H)]F_y = [0.658^(50/(153.62 × 0.8417))]50 = 27.99 ksi`

## 7.1 引言

在本章中，将考虑用于无支撑钢框架的柱的可用强度。这些框架也被称为刚性框架或侧向抑制框架。当柱端发生侧向移动时，柱必须能够抵抗轴向载荷和弯弯矩。此类构件将在书中第 11 章中详细讨论。

`AISC` 规范提供了几种方法来处理梁柱的稳定性分析和设计。其中一种是规范 `C` 章中规定的直接分析法（DM）。该方法使用了更精确地确定有效长度因子 `K` 所需的力矩。这是由于构件的有效长度 `KL` 取了实际长度 `L`，即 `K` 取等于 1.0。另一种方法是有效长度法（ELM），位于规范附录 7 中。在该方法中，使用本章讨论的程序之一计算 `K`。这两种设计方法将在书中第 11 章中进一步讨论。在本章中，将使用有效长度法确定建筑框架中构件的可用强度 `Φ P_n`。

## 第 7 章 轴向受压构件的设计（续）

![](img/d9cc447a5a92d0042e4f6d22e71654f2_214_0.png)

包含了柱载荷影响的框架。开发了一张图表用于具有侧向支撑的柱，另一张用于受侧向力影响的柱。这些图表的使用使设计者能够获得良好的 `K` 值，而无需在挠曲方程中经历冗长的试错程序。

要使用这些对齐图表，在确定该柱的 `K` 因子之前，需要对连接到该柱的梁和柱有一个初步尺寸确定。换句话说，在使用图表之前，我们必须估算一些构件尺寸或进行初步设计。

当我们说侧向受到抑制时，我们的意思是除了柱和梁之外，还有其他物体防止侧向位移或节点的水平平移。即当我们拥有有限的侧支撑系统或剪力墙时。当我们说侧向未受抑制时，是指对水平平移的抗力仅由该框架及其连续节点的梁和梁的弯曲强度和刚度提供。

梁梁在柱的一端相汇时提供的旋转抗力取决于这些构件的转动刚度。在构件的一端或另一端产生单位旋转所需的力矩称为其转动刚度。根据我们的结构分析，对于截面恒定的的均匀构件，该值等于 `4EI/L`。基于上述内容，可以说特定柱末端的旋转约束与柱刚度之和与梁刚度的比值成正比。

```
G = Σ 4EI/L (柱) / Σ E_Ic_c/L_c / Σ E_Ig_g/L_g = Σ 4EI/L (梁)
```
