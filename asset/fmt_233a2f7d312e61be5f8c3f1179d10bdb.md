
（左侧的矩阵称为狄利克特矩阵 `Dirichlet matrix`。）

# 第 27 章 样条

该多项式在四面体内是定义良好的，实际上在整个三维笛卡尔空间内也是如此。

然而，我们感兴趣的是多项式在四面体内的定义。事实上，对于网格中的每个单独四面体，我们可能根据该特定四面体的自由度以不同的方式定义函数。这将分段多项式函数，即其在网格中每个四面体上的限制是一个次数最高五的多项式。此外，由于网格中相邻四面体在公共顶点、边和面上的自由度是相同的，该函数将相当平滑。

利用上述点，我们将单个四面体中的基函数概念扩展到更通用的定义在整个四面体网格中的基函数概念。为此，我们假设网格中的每个节点关联有 10 个自由度，网格中的每条边中点关联有两个自由度，网格中的每个面中点关联有一个自由度。网格中的基函数通过仅指定其中一个自由度的值为 1，而所有其他自由度为零来获得。

更准确地说，我们必须有一套索引方案来对网格中的自由度进行索引。根据上述内容，整个网格中总共有

```
K = 10|N| + 2|E| + |L|
```

自由度，其中 `N` 是网格中的节点集（因此 `|N|` 是节点总数），`E` 是网格中的边集（因此 `|E|` 是边的总数），`L` 是网格中的面集（因此 `|L|` 是面的总数）。

整个网格中的自由度现在可以从 0 到 `K-1` 进行索引。通过指定其中一个值为 1 而其他所有值都为 0，就唯一地定义了网格中的一个特定基函数。

## 27.2 网格中的基函数

这里我们使用上述整个网格自由度的索引方案，以及在每个特定四面体 `t` 中定义的基函数，来定义整个网格中的基函数。为此，让我们首先引入符号表示。

对于任意节点 `i ∈ N`，令 `0 ≤ |i| < |N|` 表示它在网格节点列表中的索引。此外，让我们写下

```
t = (k, l, m, n),
```

其中 `k, l, m, n` 是 `t` 的顶点，按预先确定的任意顺序。

### 27.2 网格中的基函数

让我们使用第 12 章 12.36 至 12.31 节中某些四面体 `t` 中定义的基函数 `R_{i,t}`，利用上述整个网格自由度的索引方案，来定义形式为 `p_{n,t}` 的对应基函数。事实上，新的多项式 `p_{n,t}` 与某些多项式 `R_{i,t}` 相同；唯一的区别在于索引：

```
p_{10|k|+q,t} = R_{q,t}
p_{10|l|+q,t} = R_{10+q,t}
p_{10|m|+q,t} = R_{20+q,t}
p_{10|n|+q,t} = R_{30+q,t}
```

（其中 `q` 是 0 到 9 之间的整数）。这定义了与第 12 章 12.30–12.31 节中前 40 个基函数对应的 40 个基函数。

接下来，我们定义对应于 `T` 六条边每条中点的两个法向导数的基函数。为此，我们必须首先在整个网格的边列表中对 `t` 的边进行索引。事实上，对于 `t` 中任何形式为 `(i, j)` 的边（端点 `i` 和 `j` 同时也作为 `t` 的顶点），令 `(i, j)` 表示它在 `E` 边列表中的索引（`0 ≤ |(i,j)| < |E|`）。用这种符号，我们定义与 `t` 中点关联的基函数为

```
p_{10|N|+2|(k,l)|+q,t} = R_{40+q,t}
p_{10|N|+2|(k,m)|+q,t} = R_{42+q,t}
p_{10|N|+2|(k,n)|+q,t} = R_{44+q,t}
p_{10|N|+2|(l,m)|+q,t} = R_{46+q,t}
p_{10|N|+2|(l,n)|+q,t} = R_{48+q,t}
p_{10|N|+2|(n,m)|+q,t} = R_{50+q,t}
```

其中 `q` 为 0 或 1。最后，我们定义对应于面点的四个基函数。为此，我们必须为网格的面设置一个索引。对于 `t` 中每个形式为 `(i, j, h)` 的面（其顶点 `i`、`j` 和 `h` 同时也作为 `t` 的顶点），令 `(i, j, h)` 表示它在网格面列表中的索引（`0 ≤ |(i,j,h)| < |L|`）。然后，与面点关联的基函数定义为

```
p_{10|N|+2|E|+|(k,l,m)|,t} = R_{52,t}
p_{10|N|+2|E|+|(k,m,n)|,t} = R_{53,t}
p_{10|N|+2|E|+|(k,n,l)|,t} = R_{54,t}
p_{10|N|+2|E|+|(l,m,n)|,t} = R_{55,t}
```

我们还说左侧的索引与 `t` 关联，因为它们是对应于 `t` 的顶点、边中点或面点的自由度索引。这种性质表示为

```
10|k| + q ∼ t
10|l| + q ∼ t
10|m| + q ∼ t
10|n| + q ∼ t
(0 ≤ q < 10),

10|N| + 2|E| + |(k,l)| + q ∼ t
10|N| + 2|E| + |(k,m)| + q ∼ t
10|N| + 2|E| + |(k,n)| + q ∼ t
10|N| + 2|E| + |(l,m)| + q ∼ t
10|N| + 2|E| + |(l,n)| + q ∼ t
10|N| + 2|E| + |(m,n)| + q ∼ t
(0 ≤ q < 2),
```

以及对于固定的 `0 ≤ i < K`，我们可以使用这些在 `t` 中定义的基函数来定义整个网格 `M` 中的基函数：

```
φ_i ≡ { p_{i,t}  if i ∼ t
      { 0        if i ≁ t
```

（对于每个 `t ∈ M`）。根据第 12 章 12.37–12.38 节可知，`φ_i` 在 `M` 上连续，且在 `M` 的边上具有连续的梯度。`φ_i` 具有以下性质：它在 `M` 中的一个自由度上值为 1，即它只在网格中的一个节点处或一个边中点或面中点处值为 1。因此，任何 (a) 在 `M` 上连续 (b) 在每个特定四面体 `t ∈ M` 内是五次多项式 (c) 在 `M` 的条边上具有连续梯度的函数 `f`，都可以唯一地写为基函数的和：

```
f = Σ_{i=0}^{K-1} f^{(i)} φ_i,
```

其中 `f^{(i)}` 是 `f` 的 `i` 阶导数（`f` 在对应点的偏导数值）。事实上，在网格中的每个四面体 `t` 中，上述方程的左侧和右侧具有相同的自由度，因此在 `t` 中必须相同。由于这对于每个 `t ∈ M` 都成立，它们在整个网格 `M` 中也必须相同。

通常，并不是所有的 `f^{(i)}` 都是可用的。下面考虑一个部分已知、其余部分应以最优方式找到的问题。

## 27.3 Neumann 矩阵

假设 `N` 中的节点给出 `f` 的值。换句话说，假设参数 `f^{(i)}` 仅对于

```
i = 0, 10, 20, …, 10(|N|-1)
```

可用。如何指定其他的 `K-|N|` 个自由度，使得函数 `f` 尽可能平滑？

为了回答这个问题，我们需要首先定义 `K × K` Neumann 矩阵 `A`。该定义类似于第 26 章 26.1 节中的。事实上，对于每个 `0 ≤ i, j < K`，使用第 12 章 12.39 节中的公式定义 `A` 中的 `(i,j)` 元素如下：

```
a_{i,j} = ∫∫_M ∇^T φ_i ∇ φ_j dx dy dz
        = Σ_{t ∈ M} ∫∫_t ∇^T φ_i ∇ φ_j dx dy dz
        = Σ_{t ∈ M, i∼t} ∫∫_t ∇^T p_{j,t} ∇ p_{i,t} dx dy dz
        = Σ_{t ∈ M, i∼t} |det(S_t)| ∫∫_T ∇^T (p_{j,t} ∘ E_t) S_t^{-1} S_t^{-T} ∇ (p_{i,t} ∘ E_t) dx dy dz.
```

这完成了 Neumann 矩阵的定义。

现在，为了考虑上述问题，让我们重新排列任意 `K` 维向量 `v` 的分量，使得分量

```
v_0, v_{10}, v_{20}, …, v_{10(|N|-1)}
```

出现在第二个子向量 `v_N` 中，而所有其他分量出现在第一个子向量 `v_Q` 中：

```
v = (v_Q, v_N)^T
```

其中 `v_N` 是一个 `|N|` 维向量，`v_Q` 是一个 `(K-|N|)` 维向量。同样，`A` 中的行和列使得索引为：

```
i = 0, 10, 20, …, 10(|N|-1)
```

的行出现在矩阵的底部，而索引为：

```
j = 0, 10, 20, …, 10(|N|-1)
```

的列出现在矩阵的最右侧。通过这种方式，`A` 呈现块形式：

```
A = ( A_{QQ}  A_{QN} )
    ( A_{NQ}  A_{NN} )
```

注意，由于 `A` 是对称的，

```
A_{NQ}^T = A_{QN}.
```

## 27.4 样条问题

使用上述 Neumann 矩阵 `A`，上述问题可以更精确地重新表述如下 [27]：找到一个 `K` 维向量 `x`，使得 `x^T A x` 最小化，其约束条件是它的第二个向量 `x_N` 必须与 `f` 可用的对应分量一致：

```
x_N = f_N
```

（Dirichlet 边界条件）。这就是样条问题：将 `f` 从 `N` 扩展到整个网格 `M`，尽可能平滑，或者用尽可能少的能量。

为了解决这个问题，请注意，得益于上述的块表示，`A` 可以写为以下三元乘积：

```
A = ( A_{QQ}  A_{QN} ) = ( A_{QQ}   0    ) ( A_{QQ}^{-1}   0 ) ( A_{QQ}  A_{QN} )
    ( A_{NQ}  A_{NN} )   ( A_{NQ}   I    ) (     0        S ) (   0      I   )
```

其中 `I` 是阶数为 `|N|` 的单位矩阵，`S` 是舒尔补子矩阵：

```
S ≡ A_{NN} - A_{NQ} A_{QQ}^{-1} A_{QN}.
```

通过这种表示，样条问题的形式变为：找到 `x ∈ ℝ^K` 最小化

```
x^T ( A_{QQ}   0    )^T ( A_{QQ}^{-1}   0 ) ( A_{QQ}  A_{QN} ) x
    ( A_{NQ}   I    )    (     0        S ) (   0      I   )

= ( A_{QQ}x_Q + A_{QN}x_N )^T A_{QQ}^{-1} ( A_{QQ}x_Q + A_{QN}x_N ) + x_N^T S x_N
= ( A_{QQ}x_Q + A_{QN}f_N )^T A_{QQ}^{-1} ( A_{QQ}x_Q + A_{QN}f_N ) + f_N^T S f_N
```

## 27.5 狄利克特矩阵

显然，我们对上述第二项没有控制。为了让第一项为零，`x_Q` 必须满足：

```
A_{QQ} x_Q + A_{QN} f_N = 0,
```

其中 `0` 是 `(K-|N|)` 维零向量。也就是说，解 `x` 必须满足线性方程组：

```
( A_{QQ}   0 ) x = ( -A_{QN} f_N )
(   0      I )     (    f_N      ).
```

左侧的矩阵是狄利克特矩阵，因为它是通过条件 `x_N = f_N` 从 `A` 消除第二个向量中的未知数并替换方程得到的。

### 28.1 任意基数的整数表示

可以使用以下代码表示任意基数的整数。特别是当所选基数为 2 时，该代码等同于第 13 章 13.24–13.25 节。

```cpp
int reverse(int n, int base) {
    int reversed = n % base;
    while (n /= base) {
        reversed = reversed * 10 + n % base;
    }
    return reversed;
} // 转换为基数并反转
```

该函数有两个用途：将整数转换为指定的基数，并以数字的反序写出这种表示。遗憾的是，前导零会在过程中丢失。例如，2300 被反转为 32。为了避免这种情况，必须在原数上加 1。这个多出的 1 从原数中减去后，通过连续两次上述函数进行反转，从而将原数转换为所需的基数表示法：

```cpp
```
