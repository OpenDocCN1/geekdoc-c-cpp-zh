## Transform Classes

在 WPF 中，在排版的帮助下，您可以对文本应用变换。例如，您可以旋转、缩放、倾斜或转换文本。您可以使用 `Transform` 类来转换文本。这些类还简化了文本中各种绘图的使用。最常用的 `Transform` 类如下：

- `TranslateTransform` class
- `RotateTransform` class
- `ScaleTransform` class
- `SkewTransform` class

## WPF 4.0 文档

在 WPF 中，显示固定文本很容易，因为你可以在应用程序中使用 `TextBlock`、`Label` 和 `ContentControl` 控件。然而，要显示大量数据，例如报纸文章，这些控件并不是一个好的选择。当你使用 `TextBlock` 和 `Image` 元素组合文本和图像时，窗口调整大小时 `TextBlock` 和 `Image` 的内容无法正确对齐。为克服这些问题，WPF 引入了文档的概念来处理大量文本。此功能允许以易于阅读的方式显示大量内容，而与窗口大小无关。

WPF 中有两种文档：固定文档和流文档。固定文档类似于便携式文档格式（PDF）文档，因为其内容无法更改。流文档类似于超文本标记语言（HTML）文档，因为它使用标签创建。两种文档都允许你指定查看偏好，同时保持文档作者所期望的整体设计概念。这些文档位于 `System.Windows.Documents` 命名空间中。

## 固定文档

固定文档是排版完成且可直接打印的文档，其中所有内容的位置都是固定的。它们在逻辑上将有序的页面序列绑定在一起，形成单个、多页或固定布局文档。WPF 包含一种固定文档类型，它使用 Microsoft XML Paper Specification（XPS）标准以可扩展标记语言（XML）格式表示数字文档的电子表示。固定文档内容的显示由 `DocumentViewer` 控件支持。WPF 中的固定文档由 `FixedDocument` 类表示。让我们在以下章节中讨论 `DocumentViewer` 控件和 `FixedDocument` 类。
