### 6.4.10 注释

在字符常量、字符串字面量或注释之外，注释 `/* /` 引入内容。此类注释的内容仅用于识别多字节字符并找到终止它的注释 `/* /`。¹⁸⁰

在字符常量、字符串字面量或注释之外，注释 `/* /` 引入一个包含所有但不包括下一个换行字符的多字节字符的注释。此类注释的内容仅用于识别多字节字符并找到终止换行字符。

#### 示例

```

f = g//h;               // 等价于 f = g / h;
//
di();
/                        // 两行注释的一部分
```

`/*...*/` 注不结束。
