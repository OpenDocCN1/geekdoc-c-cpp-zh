## 队列的应用：模拟

队列是一种遵循先进先出（FIFO）原则的线性数据结构。这意味着第一个加入队列的元素是第一个被移除的元素。一个常见的例子是收银台排队的人；先到达的人先获得服务。

在队列上执行的主要操作有：
- `enqueue`：在队列末尾添加元素。
- `dequeue`：从队列头部移除元素。
- `front`：返回头部的元素但不移除它。
- `isEmpty`：如果队列为空则返回真。
- `isFull`：如果队列已满则返回真（对于固定大小队列）。

下面是一个使用动态数组实现的简单队列版本。

```cpp
template <typename T>
class Queue {
private:
    T *array;
    int front;
    int rear;
    int size;
    int capacity;
public:
    Queue(int cap) {
        capacity = cap;
        array = new T[capacity];
        front = 0;
        rear = -1;
        size = 0;
    }
    ~Queue() {
        delete [] array;
    }
    void enqueue(T item) {
        if (isFull()) {
            cout << "Queue is full" << endl;
            return;
        }
        rear = (rear + 1) % capacity;
        array[rear] = item;
        size++;
    }
    T dequeue() {
        if (isEmpty()) {
            cout << "Queue is empty" << endl;
            return T();
        }
        T item = array[front];
        front = (front + 1) % capacity;
        size--;
        return item;
    }
    T front() {
        if (isEmpty()) {
            cout << "Queue is empty" << endl;
            return T();
        }
        return array[front];
    }
    bool isEmpty() {
        return size == 0;
    }
    bool isFull() {
        return size == capacity;
    }
};
```
