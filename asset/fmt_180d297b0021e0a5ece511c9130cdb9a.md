# TextBlock

# TOOLTIP（工具提示）

# CONSISTENT TIPS（一致性提示）

如果你更改了 `ToolTip` 的属性，它看起来将与其他应用程序的工具提示不同。虽然这会让你的程序与系统的其余部分的一致性降低，但只要你不过过头（例如，使用 60 磅字体显示工具提示），就不会太太分扰用户。

| FontStyle | 可以是 Normal、*Italic* 或 *Oblique*（对于没有斜体样式的字体模拟斜体） |
