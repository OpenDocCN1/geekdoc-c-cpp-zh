## 组合函数和运算符

与 `DATA` 步一样，许多函数都可以在 SQL 过程中使用。要修改表中的一个或多个现有行，请使用 `UPDATE` 语句（有关更多详细信息，请参阅第 6 章“修改和更新表和索引”）。`UPDATE` 语句中的 `SET` 子句通过将常量或表达式引用的新值分配给等于号左侧标识的列来更改数据值的内容（与 `DATA` 步赋值语句的功能相同）。

`UPDATE` 语句不会自动产生任何输出，除了基于操作结果本身的日志消息。为了说明在 SQL 过程中使用 `DATA` 步函数和运算符，下一个示例显示了 `SCAN` 函数从产品名称（`PRODNAME`）中分离出第一条信息，`TRIM` 函数从产品类型（`PRODTYPE`）中删除尾随空白，以及连接运算符 `"||"` 将第一个字符表达式与第二个表达式连接起来。应该注意的是，使用 `SCAN` 函数时应谨慎，因为它返回一个 200 字节的字符串。

### SQL 代码

```
PROC SQL;
    UPDATE PRODUCTS
        SET PRODNAME = SCAN(PRODNAME,1) || TRIM(PRODTYPE);
QUIT;
```

## SAS 日志结果

```

        SET PRODNAME = SCAN(PRODNAME,1) || TRIM(PRODTYPE);
NOTE: 10 rows were updated in PRODUCTS.
QUIT;
```

### SQL 代码


## 使用INDEX查找模式的出现位置

要查找模式的出现位置，可以使用 `INDEX` 函数。通常，需求要求使用特定字符串对列进行搜索。在SQL过程中可以使用 `INDEX` 函数来搜索字符串中的模式。字符串从左到右搜索指定值的第一次出现。如果找到所需字符串，则返回第一个字符的列位置；否则返回零（0）。以下参数用于在列中搜索模式：字符列或表达式，以及要搜索的字符串。要查找产品名称（`PRODNAME`）列中包含“phone”字符的所有产品，可以指定以下代码：

## 更改字符串中的大小写

SAS提供两个函数，使您可以更改字符串字符的大小写：`LOWCASE` 和 `UPCASE`。`LOWCASE` 函数将字符串或表达式中的所有字符转换为小写字符。`UPCASE` 函数将字符串或表达式中的所有字符转换为大写字符。

回到前面的示例，即使字符串“phone”在多行中出现多次，搜索结果仍然为负。为了使此搜索识别单词“phone”所有可能的大小写变体，可以将 `WHERE` 子句中的搜索条件与 `UPCASE` 函数和 `INDEX` 函数组合，使其“更智能”，如下所示。

## SQL代码

```
PROC SQL;
    SELECT PRODNUM,
           PRODNAME,
           PRODTYPE
      FROM PRODUCTS
     WHERE INDEX(UPCASE(PRODNAME), 'PHONE') > 0;
QUIT;
```
