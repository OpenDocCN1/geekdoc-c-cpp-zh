## 前言

为什么要写第二版的《FTIR光谱基础》？有两个原因。第一，自1996年第一版出版以来情况发生了巨大变化，特别是金刚石ATR技术的发展。其次，自1992年以来，我教了成千上万的人FTIR，现在我解释其重要概念比那时做得更好，这体现在了书中。熟悉《FTIR光谱基础》第一版的人在这里几乎认不出任何东西；本书已经过完全改写，并增加了几十张新图。根据需要，书中增加、扩展并删除了一些主题。

那么，我认为你是谁呢？这本书针对那些需要使用FTIR的人，特别是那些需要使用FTIR设备的非化学家，而这类人似乎是今天新用户的大多数。熟练和专家级的光学家会发现这本书对FTIR主题的简洁易懂的解释是一本实用的参考书。阅读本书时，对大一化学和物理的熟悉会有帮助，但绝非必须。化学家和非化学家都告诉我，阅读第一版让他们受益匪浅，我预计这一版也是如此。

本书共包含六章。第一章介绍了红外光谱领域，包括FTIR作为一种化学分析工具的优点和缺点。第二章“FTIR是如何工作的”是关于仪器的。第三章讨论了如何正确使用光谱处理来在不破坏数据的情况下增加光谱的信息量。第四章专门介绍样品制备。第五章专门介绍单一分析物的定量分析。第六章是红外光谱的概述。

## 红外光谱简介

本书的目的是向读者介绍傅里叶变换红外`FTIR`光谱的基本概念。讨论假设读者没有FTIR背景，但对化学和物理基础概念的熟悉将有助于理解。

### I. 术语与定义

学习任何新领域的一半在于理解术语。

- *光谱学*：光与物质相互作用的研究。
- *红外光谱*：红外光与物质相互作用的研究。
- *中红外*：4000到400波数`cm⁻¹`的光。
- *光谱*：测得的光强度相对于光的某种属性的图谱。
- *光谱仪*：测量光谱的仪器。
- *红外光谱仪*：测量红外光谱的仪器。
- `FTIR`：傅里叶变换红外，一种特定的红外光谱仪。

## 傅里叶红外光谱的基础

### II. 光的性质

用于描述光的准确术语是电磁辐射。光由电波和磁波组成，称为电矢量和磁矢量。这些波相互垂直波动，并沿着垂直于波动平面的第三个方向在空间中移动。电矢量与物质的相互作用导致了光的吸收。

波在一个周期内移动的距离称为其波长。波长的单位是每个周期的距离。科学家使用希腊字母`λ`表示波长。

光的另一个重要性质是波数，用字母`W`表示。波数测量的是波在单位长度内经历的周期数。波数的单位是每厘米周期数，通常缩写为`cm⁻¹`。

图 1.1 光波电矢量示例。+ 和 – 号表示电矢量的交替极性。箭头显示了波的波长 `λ`。

![](img/d25eff8aaf4b0b214cf4015e62b7c990_17_0.png)

**图 1.2** 聚苯烯的红外光谱。注意 x 轴绘制的是波数，y 轴是吸收度。

由于波长的单位是距离/周期，而波数的单位是周期/距离，这两个量互为倒数关系如下：

`W = 1/λ`

其中
- `W` = 波数
- `λ` = 波长

`E = hcW`

其中
- `E` = 单位为焦的光能量
- `c` = 光速 `~3 × 10^10 cm/秒`
- `h` = 普朗克常数 `6.63 × 10^-34 焦·秒`
- `W` = 波数

光波的另一个性质是它们的频率，它是波在单位时间内经历的周期数的测量值。频率通常以周期/秒或赫兹`Hz`为单位。科学家用希腊字母`ν`表示频率。

`c = νλ` (1.3)

其中
- `c` = 光速
- `ν` = 频率
- `λ` = 波长

`c = ν/W` (1.4)

其中
- `c` = 光速
- `ν` = 频率
- `W` = 波数

除了中红外之外，宇宙中还有许多类型的电磁辐射，它们的集合被称为*电磁光谱*。

能量高于中红外，从 14,000 到 4000 `cm⁻¹` 是*近红外*。分子吸收近红外时会振动。

### III. 什么是红外光谱？

将测量的红外光强度与光的性质绘制的图称为光谱。

样品的吸收度通过以下方程计算：

```
A = log(I_0/I)
```

其中
- `A` = 吸光度
- `I_0` = 背景光谱中的强度
- `I` = 样品光谱中的强度

吸光度还通过称为比尔定律的方程与样品中的分子浓度相关：

```
A = εc l
```

其中
- `A` = 吸光度
- `ε` = 吸收系数
- `l` = 光程
- `c` = 浓度

吸光光谱中峰值的高度或面积与浓度成正比，这就是为什么可以使用比尔定律来确定样品中分子的浓度。
