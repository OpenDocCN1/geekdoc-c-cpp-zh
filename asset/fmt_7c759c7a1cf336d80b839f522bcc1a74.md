## 通过 Code-Behind 文件添加控件

将控件添加到 WPF 应用程序的另一种方式是通过 code-behind 文件。现在让我们通过 code-behind 文件将一些常用控件添加到 WPF 应用程序。

为此，创建一个名为 `AddingControls_CodeBehind` 的 WPF 应用程序（可在 CD 上获得）并用 Listing 10.3 中突出显示的代码替换 `MainWindow.xaml` 文件中的 `Grid` 元素，以将 `Grid` 控件重命名为 `myGrid`，如下所示：

### Listing 10.3: Renaming the Grid control in the MainWindow.xaml File

```xml
<Window x:Class="AddingControls_CodeBehind.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="MainWindow" Height="350" Width="525">
    <Grid Name="myGrid">
    </Grid>
</Window>
```

在 Listing 10.3 中，`Grid` 控件的名称已更改为 `myGrid`。控件将从您的 code-behind 文件添加到 `Grid` 控件。因此，打开 `MainWindow.xaml.cs` 文件并添加 Listing 10.4 所示的代码：

### Listing 10.4: Adding Controls to the myGrid Grid Control

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Windows;
using System.Windows.Controls;
using System.Windows.Data;
using System.Windows.Documents;
using System.Windows.Input;
using System.Windows.Media;
using System.Windows.Media.Imaging;
using System.Windows.Navigation;
using System.Windows.Shapes;

namespace AddingControls_CodeBehind
{
    /// <summary>
    /// Interaction logic for MainWindow.xaml
    /// </summary>
    public partial class MainWindow : Window
    {
        public MainWindow()
        {
            InitializeComponent();
            Label myLabel = new Label();
            myLabel.Content = "Enter your Name:";
            myLabel.FontSize = 12;
            myLabel.FontWeight = FontWeights.Bold;
            myGrid.Children.Add(myLabel);
            TextBox myTextBox = new TextBox();
            myTextBox.Margin = new Thickness(0, 5, 10, 5);
            myTextBox.Height = 30;
            myTextBox.Width = 150;
            myGrid.Children.Add(myTextBox);
            myTextBox.HorizontalAlignment = HorizontalAlignment.Right;
            myTextBox.VerticalAlignment = VerticalAlignment.Top;
            Button myButton = new Button();
            myButton.Content = "Submit";
            myButton.FontSize = 11;
            myButton.FontWeight = FontWeights.Bold;
            myButton.Height = 50;
            myButton.Width = 75;
            myGrid.Children.Add(myButton);
        }
    }
}
```

添加控件并设置其属性，如 Listing 10.4 所示后，按 F5 键运行应用程序。结果会出现一个空白的 `TextBox` 控件，您可以在其中添加任意文本，如 Figure 10.39 所示：

## Using Dynamic Layout of Controls

当您设计 WPF 应用程序时，必须决定如何在窗口上定位控件。这可以通过控件的绝对定位或动态定位来完成。控件的动态定位借助 `Grid`、`DockPanel`、`WrapPanel`、`StackPanel` 和 `UniformGrid` 控件完成。这些容器控件可以与其他控件结合作为子元素。

## Using the DockPanel Control

`DockPanel` 控件定义了一个区域，您可以在其中垂直或水平排列子元素。您可以通过 XAML 代码添加 `DockPanel` 控件。让我们将 `DockPanel` 控件添加到 WPF 应用程序中。创建一个名为 `DockPanelControl1` 的 WPF 应用程序（可在 CD 上获得）并将代码，如 Listing 10.5 所示，添加到 `MainWindow.xaml` 文件中：

### Listing 10.5: Showing the Code to Implement the DockPanel Control

```
<Window x:Class="DockPanelControl1.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="350" Width="525">
    <Grid>
        <DockPanel LastChildFill="True">
            <Border Height="30" Background="Pink" DockPanel.Dock="Top">
                <TextBlock> 1st DockPanel</TextBlock>
            </Border>
            <Border Height="30" Background="SkyBlue" DockPanel.Dock="Top">
                <TextBlock> 2nd DockPanel</TextBlock>
            </Border>
            <Border Height="70" Background="Lavender" DockPanel.Dock="Bottom">
                <TextBlock> 3rd DockPanel</TextBlock>
            </Border>
            <Border Height="200" Width="100" Background="SeaGreen" DockPanel.Dock="Left">
            </Border>
            <Border Height="100" Background="BlueViolet" DockPanel.Dock="Right">
            </Border>
        </DockPanel>
    </Grid>
</Window>
```

在 Listing 10.5 中，使用 `DockPanel` 控件创建了一个简单的 UI。`DockPanel` 控件的位置通过使用 `DockPanel.Dock` 属性设置。您可以通过按 F5 键运行应用程序。

## Using the StackPanel Control

`StackPanel` 控件允许您以单行添加子元素，可以是垂直或水平。默认设置是垂直对齐。元素对齐方式通过使用 `VerticalAlignment` 或 `HorizontalAlignment` 属性设置。您可以通过从工具箱拖放或通过在应用程序中定义 XAML 代码来添加 `StackPanel` 控件。让我们将 `StackPanel` 控件添加到 WPF 应用程序中。创建一个名为 `StackPanelControl` 的 WPF 应用程序（可在 CD 上获得）并将代码添加到 `MainWindow.xaml` 文件中，如 Listing 10.6 所示：

### Listing 10.6: Showing the Code to Implement the StackPanel Control

```
<Window x:Class="StackPanelControl.MainWindow"
xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
Title="MainWindow" Height="350" Width="525">
<StackPanel VerticalAlignment="Center" HorizontalAlignment="Center" Width="200" Height="200">
<Button Height="32" />
<Button Height="32" />
<Button Height="32" />
<TextBox Height="38">Example of StackPanel</TextBox>
</StackPanel>
</Window>
```

在 Listing 10.6 中，使用 `StackPanel` 控件创建了一个简单的 UI。您可以通过按 F5 键运行应用程序。Listing 10.6 的输出显示如下 Figure 10.41：

![](img/e073a4882197be4ab61103cbe0bcb394_469_1.png)

## Using the WrapPanel Control

`WrapPanel` 控件用于以顺序方式在窗口中添加子元素。您可以通过 XAML 代码添加 `WrapPanel` 控件。让我们创建一个名为 `WrapPanelControl` 的 WPF 应用程序（可在 CD 上获得）并将代码添加到 `MainWindow.xaml` 文件中，如 Listing 10.7 所示：

### Listing 10.7: Showing the Code to Implement the WrapPanel Control

```
<Window x:Class="WrapPanelControl.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="350" Width="525">
    <Grid>
        <WrapPanel Background="SkyBlue">
            <Button Height="38" Width="81">Button1</Button>
            <Button Height="38" Width="81">Button2</Button>
            <Button Height="38" Width="81">Button3</Button>
            <Button Height="38" Width="81">Button4</Button>
            <Button Height="38" Width="81">Button5</Button>
            <Button Height="38" Width="81">Button6</Button>
            <Button Height="38" Width="81">Button7</Button>
        </WrapPanel>
    </Grid>
</Window>
```

在 Listing 10.7 中，使用 `WrapPanel` 控件创建了一个简单的 UI。`WrapPanel` 控件的子元素 `Button` 控件从左到右添加到窗口上。

## Setting the Absolute Position of Controls

WPF 应用程序中的绝对定位借助 `Canvas` 控件完成。`Canvas` 控件定义了一个区域，您可以在其中放置子元素。您可以通过 XAML 代码将 `Canvas` 控件添加到 WPF 应用程序中。创建一个名为 `CanvasControl` 的 WPF 应用程序（可在 CD 上获得）并将代码，如 Listing 10.8 所示，添加到 `MainWindow.xaml` 文件中：

### Listing 10.8: Showing the Code to Implement the Canvas Control

```
<Window x:Class="CanvasControl.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="350" Width="525">
    <Canvas Background="Beige">
        <Button Canvas.Left="88" Canvas.Top="117" Height="23" Name="myButton" Width="75">Hello!</Button>
        <Label Canvas.Left="69" Canvas.Top="50" Height="28" Name="myLabel" Width="120">Example of Canvas</Label>
    </Canvas>
</Window>
```
