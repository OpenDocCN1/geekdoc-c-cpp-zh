## 使用算术复合赋值、增递减运算符简化语句

算术复合赋值运算符以及增递减运算符可以简化程序语句。例如，图 4.14 中的三个赋值语句（第 21、24 和 28 行）

```cpp
passes = passes + 1;
failures = failures + 1;
studentCounter = studentCounter + 1;
```

可以使用复合赋值运算符写得更紧凑：

```cpp
passes += 1;
failures += 1;
studentCounter += 1;
```

使用前置增运算符变为：

```cpp
++passes;
++failures;
++studentCounter;
```

或者使用后置增运算符变为：

```cpp
passes++;
failures++;
studentCounter++;
```
