# 引言

- 抽象解释 [00] 技术原理使得对使用 C 或 Ada 语言编写的软件应用程序进行形式化的分析成为可能。
- 这种技术通过通过静态分析，可以评估软件应用程序的行为。
- 这种静态分析技术的效率随着机器性能的提高而大大进步。
- 注意的是，这些技术通常要求在代码中集成补充信息，如前置条件、不变式或后置条件。
