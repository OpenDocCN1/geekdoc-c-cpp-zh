## 实现其他栈操作

可以在之前所示栈类的基础上构建复杂的操作。在本节中，我们将讨论一个派自 `IntStack` 的类 `MathStack`。`MathStack` 类有两个成员函数：`add()` 和 `sub()`。`add()` 函数从栈中弹出两个值，将它们相加，然后将和推栈。`sub()` 函数从栈中弹出两个值，用第一个值减去第二个值，然后将差推栈。该类声明如下：

### MathStack.h 内容

```cpp
// MathStack 类的规范文件

#ifndef MATHSTACK_H
#define MATHSTACK_H

#include "IntStack.h"

class MathStack : public IntStack
{
public:
    // 构造函数
    MathStack(int s) : IntStack(s) {}

    // MathStack 操作
    void add();
    void sub();
};

#endif
```

成员函数的定义在这里：

### MathStack.cpp 内容

```cpp
// MathStack 类的实现文件

#include "MathStack.h"

// 成员函数 add。add 从栈弹出两个值并相加。和推栈。

void MathStack::add()
{
    int num, sum;

    // 从栈中弹出两个值。
    pop(sum);
    pop(num);

    // 将两个值相加并存储在 sum 中。
    sum += num;

    // 将 sum 推栈。
    push(sum);
}

// 成员函数 sub。sub 从栈弹出两个值。从第一个值中减去第二个值。差推栈。

void MathStack::sub()
{
    int num, diff;

    // 从栈中弹出两个值。
    pop(diff);
    pop(num);

    // 从 diff 中减去 num。
    diff -= num;

    // 将 diff 推栈。
    push(diff);
}
```

该类在程序 19-2（一个简单的驱动程序）中演示。

### 程序 19-2

```cpp
// 此程序演示了 MathStack 类。

#include <iostream>
#include "MathStack.h"

using namespace std;

int main() {
    int catchVar; // 保存从栈弹出的值

    // 创建 MathStack 对象。
    MathStack stack(5);

    // 将 3 和 6 推入栈。
    cout << "Pushing 3\n";
    stack.push(3);

    cout << "Pushing 6\n";
    stack.push(6);

    // 将两个值相加。
    stack.add();

    // 从栈中弹出和并显示。
    cout << "The sum is: ";
    stack.pop(catchVar);
    cout << catchVar << endl;

    // 将 7 和 10 推入栈。
    cout << "Pushing 7\n";
    stack.push(7);

    cout << "Pushing 10\n";
    stack.push(10);

    // 从 10 减去 7。
    stack.sub();

    // 从栈中弹出差并显示。
    cout << "The difference is: ";
    stack.pop(catchVar);
    cout << catchVar << endl;

    return 0;
}
```

## 静态栈模板

本章之前所示的类仅适用于整数。栈模板可以很容易地设计为与任何数据类型工作，如下例所示：

### Stack.h 内容

```cpp
#ifndef STACK_H
#define STACK_H

#include <iostream>

using namespace std;

// 栈模板
template <class T>
class Stack {
private:
    T *stackArray;
    int stackSize;
    int top;

public:
    // 构造函数
    Stack(int);
    // 拷贝构造函数
    Stack(const Stack&);
    // 析构函数
    ~Stack();

    // 栈操作
    void push(T);
    void pop(T &);
    bool isFull();
    bool isEmpty();
};

// 构造函数
template <class T>
Stack<T>::Stack(int size)
{
    stackArray = new T[size];
    stackSize = size;
    top = -1;
}

// 拷贝构造函数
template <class T>
Stack<T>::Stack(const Stack &obj)
{
    // 创建栈数组。
    if (obj.stackSize > 0)
        stackArray = new T[obj.stackSize];
    else
        stackArray = nullptr;

    // 拷贝 maxSize属性。
    stackSize = obj.stackSize;

    // 拷贝栈内容。
    for (int count = 0; count < stackSize; count++)
        stackArray[count] = obj.stackArray[count];

    // 设置栈顶。
    top = obj.top;
}

// 析构函数
template <class T>
Stack<T>::~Stack()
{
    if (stackSize > 0)
        delete stackArray;
}

// 成员函数 push 将参数推栈。
template <class T>
void Stack<T>::push(T item)
{
    if (isFull())
        cout << "The stack is full.\n";
    else {
        top++;
        stackArray[top] = item;
    }
}

template <class T>
void Stack<T>::pop(T &item)
{
    if (isEmpty())
    {
        cout << "The stack is empty.\n";
    }
    else
    {
        item = stackArray[top];
        top--;
    }
}

// 成员函数 isFull 如果栈已满则返回 true，否则返回 false。
template <class T>
bool Stack<T>::isFull()
{
    bool status;
    if (top == stackSize - 1)
        status = true;
    else
        status = false;
    return status;
}

// 成员函数 isEmpty 如果栈为空则返回 true，否则返回 false。
template <class T>
bool Stack<T>::isEmpty()
{
    bool status;
    if (top == -1)
        status = true;
    else
        status = false;
    return status;
}

#endif
```

# 19.1 栈 ADT 简介

程序 19-3 演示了 Stack 模板。它创建了一个字符串栈，然后显示一个菜单，允许用户向栈中推入元素、从栈中弹出元素或退出程序。

# 程序 19-3

```cpp
// 此程序演示了 Stack 模板。

#include <iostream>
#include <string>
#include "Stack.h"

using namespace std;

// 菜单选择的常量
const int PUSH_CHOICE = 1,
  POP_CHOICE = 2,
  QUIT_CHOICE = 3;

// 函数原型
void menu(int &);
void getStackSize(int &);
void pushItem(Stack<string>&);
void popItem(Stack<string>&);

int main() {
  int stackSize; // 栈的大小
  int choice; // 用于存储菜单选择

  // 获取栈的大小。
  getStackSize(stackSize);

  // 创建栈。
  Stack<string> stack(stackSize);

  do
  {
    // 获取用户的菜单选择。
    menu(choice);

    // 执行用户的选择。
    if (choice != QUIT_CHOICE)
    {
      switch (choice)
      {
        case PUSH_CHOICE:
          pushItem(stack);
          break;
        case POP_CHOICE:
          popItem(stack);
      }
    }
  } while (choice != QUIT_CHOICE);

  return 0;
}
```

// getStackSize 函数获取所需的
// 栈大小，并将其赋值给

{
    // 获取所需的栈大小。
    cout << "How big should I make the stack? ";

    // 验证大小。
    while (size < 1)
    {
        cout << "Enter 1 or greater: ";

// 用户的选择，将其赋值给

{
    // 显示菜单并获取用户的选择。
    cout << "\nWhat do you want to do?\n";

    cout << POP_CHOICE;
    cout << "  - Pop an item off the stack\n";

    cout << "  - Quit the program\n";

        cout << "Enter a valid choice: ";
        cin >> choice;
    }

  string item;
