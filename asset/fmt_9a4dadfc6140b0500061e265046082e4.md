
```c
#include <stdio.h>
#include <float.h>

int main(void) {
    // 这两个数字都有 6 位有效数字，所以它们可以
    // 准确地存储在浮点数中：

    float f = 3.14159f;
    float g = 0.000002653538;

    printf("%.5f\n", f); // 3.14159 正确！
    printf("%.11f\n", g); // 0.000002653538 正确！

    // 现在将它们相加
    f += g;                // f 应该是 3.141592653538

    printf("%.11f\n", f); // 3.141592653724101 错误！
}
```

（上面的代码在数值常量后面有一个 `f`——这表示该常量是 `float` 类型，而不是 `double`。稍后会详细介绍。）

记住 `FLT_DIG` 是你可以在浮点数中存储的有效位数。有时你只能得到一或二位。但有时你会得到 `FLT_DIG` 位。可以肯定的的是：如果你在浮点数中存储包含 `FLT_DIG` 在内的任意位数，你一定能正确地找回它们。

故事就是这样。`FLT_DIG`。结束。

……或者没有？

### 14.4.2 转换为十进制和二进制

但将十进制存储在浮点数中并将其提取出来只是故事的一半。

> ¹²此程序正如其注释所示，运行在一个 `FLT_DIG` 为 6 且使用 IEEE-754 二进制浮点数的系统上。否则，你可能会得到不同的输出。

事实浮点数可以编码需要更多小数才能完整打印的数字。只是你的大十进制数可能映射到其中一个。

也就是说，当你查看相邻浮点数时，存在一个间隙。如果你尝试在该间隙中编码十进制，将使用最接近的浮点数。这就是为什么你只能为 `float` 编码 `FLT_DIG` 位。

但那些不在间隙中的浮点数呢？你需要多少位才能准确地打印它们？

这个问题的另一种表达方式是：对于任何给定的浮点数，如果我将十进制数转换回相同的浮点数，我需要保留多少个十进制数字？也就是说，我需要在十进制中打印多少位，才能恢复原始数字中二进制中的所有数字？

有时可能只有几位。但为了确保起见，你将希望使用某个安全的小位数转换为十进制。数字编码在以下宏中：

| 宏 | 描述 |
|---|---|
| `FLT_DECIMAL_DIG` | `float` 中编码的十进制位数。 |
| `DBL_DECIMAL_DIG` | `double` 中编码的十进制位数。 |
| `LDBL_DECIMAL_DIG` | `long double` 中编码的十进制位数。 |
| `DECIMAL_DIG` | 与最宽编码 `LDBL_DECIMAL_DIG` 相同。 |

让我们来看一个例子，其中 `DBL_DIG` 是 15（这样我们有一个常量），但 `DBL_DECIMAL_DIG` 是 17（因此我们必须转换为 17 位十进制以保留原始 `double` 的所有位）。

我们将 `0.123456789012345` 的 15 位赋值给 `x`，并将 1 位有效数字 `0.0000000000000006` 赋值给 `y`。

```
x 是: 0.123456789012345      打印 17 位小数
y 是: 0.0000000000000006
```

但让我们它们相加。看看：0.12345678901234536，但这超过了 `DBL_DIG`，所以可能会发生奇怪的事情。

```
x + y = 不完全对：0.12345678901234559      应该以 4560 结尾！
```

我们打印超过 `DBL_DIG` 位的结果就是这样，对吧？但看这个……上面的那个数字可以被精确地表示！如果我们把 `0.12345678901234559`（17 位）赋值给 `z` 并打印，我们得到：

```
z 是: 0.12345678901234559      17 位正确！
```

但随后——如果我们将 `z` 截断到 15 位，它的值将不再相同。为了保留 `double` 的所有位，我们需要 `DBL_DECIMAL_DIG` 而不仅仅是 `DBL_DIG`。

总而言之，很清楚我们正在处理通用的十进制数，为了与原始基数及后续操作相关，打印超过 `FLT_DIG`、`DBL_DIG` 或 `LDBL_DIG` 位是不安全的。但在从 `float` 转换为十进制表示再转换回 `float` 时，务必使用 `FLT_DECIMAL_DIG` 以确保所有位都正确。

### 14.5.3 浮点数常量

你可能认为像 1.23 这样的浮点数常量默认类型是 `float`，对吧？惊喜吧，未加后缀的浮点数类型是 `double`！祝你迟生日快乐！

你可以通过附加 `f`（或 `F`——它不区分大小写）将其强制转换为 `float` 类型。你可以通过附加 `l`（或 `L`）将其强制转换为 `long double` 类型。

| 类型 | 后缀 |
|---|---|
| `float` | `F` |
| `double` | 无 |
| `long double` | `L` |

例如：

```
float x = 3.14f;
double x = 3.14;
long double x = 3.14L;
```

不过，这次，我们直一直在这么做，对吧？

```
float x = 3.14;
```

左边不是一个 `float` 和 `double` 吗？是的！但 C 语言处理自动数值转换非常出色，所以没有后缀的浮点数常量比有的更常见。或者我们以后再说。

#### 14.5.3.1 科学计数法

还记得之前我们讨论过浮点数可以用系数、基数和指数来表示吗？

嗯，写这种数字有一种常用方法，这里显示了，后面是更容易识别的等价形式，当你实际运行计算时得到的结果：

1.2345 × 10³ = 1234.5

以 s × b¹⁰ 的形式写数字被称为科学计数法¹⁴。在 C 中，这些使用的是“E 计数法”，所以它们是等价的：

| 科学计数法 | E 计数法 |
|---|---|
| 1.2345 × 10⁻³ | 1.2345e-3 |
| 1.2345 × 10⁸ | 1.23450000e+8 |

你可以用 `%` 打印这种格式的数字：

```
printf("%s\n", 1.234560e+05);
```

关于科学计数法的几个小知识：

- 你不需要在小数点前只写一个数字。可以写任意数量的数字。

```
double x = 123.456e3; // 123456
```

然而，当你打印它时，它会改变指数，使得小数点前只有一个数字。

> ¹⁴https://en.wikipedia.org/wiki/Scientific_notation

指数部分可以省略加号，它是默认的，但根据我所见，在实践中这并不常见。

`1.2345e10 == 1.2345e+10`

你可以对 E 计数法常量应用 `F` 或 `L` 后缀：

```
1.2345e10
1.2345e10L
```

#### 14.5.3.2 十进制浮点常量

但等一下，还有更多的浮点需要处理！

事实证明也有十六进制浮点常量！

它们的工作原理与十进制浮点数类似，但它们像整数一样以 `0x` 开头。

在于你必须指定一个指数，而这个指数会产生 2 的幂。即：2^x。

在写数字时，使用 `p` 代替 `e`：

所以 `0xa.1p3` 是 10.0625 × 2^3 = 80.5。

使用浮点常量时，我们可以用 `%` 打印十六进制科学计数法：

```
double x = 0xa.1p3;

printf("%a\n", x);   // 0x1.42p+6
printf("%f\n", x);   // 80.500000
```

## 第 15 章

## 类型 III：转换

在本章中，我们想要讨论所有从一种类型转换为另一种类型。C 语言有多种实现方法，某些可能与你在其他语言中习惯的有所不同。

在讨论转换如何发生之前，让我们先聊聊它们在发生时是如何工作的。

### 15.1 字符串转换

与许多语言不同，C 语言的 字符串到数字（以及反之）的转换不像数值转换那样流畅。

对于这些转换，我们必须调用函数来完成这些脏活工作。

#### 15.1.1 数值到字符串

当我们想要将数字转换为字符串时，可以使用 `sprintf()`（读作 SPRINT-f）或 `snprintf()`（s-n-print-f*）。

它们的工作原理基本上和 `printf()` 相似，只是它们输出到字符串，你之后可以打印那个字符串，或者随意的。

例如，将值 π 的部分转换为字符串：

```c
#include <stdio.h>

int main(void)
{
    char s[10];
    float f = 3.14159;

    // 将 "f" 转换为字符串，存储在 "s" 中，最多写入 10 个字符
    // 包括空 终止符

    snprintf(s, 10, "%f", f);

    printf("String value: %s\n", s); // String value: 3.141590
}
```

所以你可以像对待整数一样使用 `%d` 或 `%u`。

> 它们是相同的，除了 `snprintf()` 允许你指定输出的最大字节数，防止字符串溢出。所以它更安全。

#### 15.1.2 字符串到数值

C 语言中有几族函数可以实现此操作。我们称之为为 `atoi` 系列（读作 atoi-to-i）和 `strtol` 系列（str-to-long）。对于从字符串到数字的基本转换，尝试使用 `<stdlib.h>` 中的 `atoi` 函数。由于这些函数具有糟糕的错误处理特性（如果传递错误的字符串会产生未定义行为），所以请谨慎使用。

| 函数 | 描述 |
|---|---|
| `atoi` | 字符串转 `int` |
| `atof` | 字符串转 `float` |
| `atol` | 字符串转 `long int` |
