使用 WCF 服务需要在您想要调用服务的应用程序中添加 WCF 服务的引用，并为客户端生成代理代码和`.config`文件，我们接下来将探讨这一点。

# 添加 WCF 服务的引用

创建 WCF 客户端后，您可以向客户端添加 WCF 服务的引用。在我们的例子中，我们通过在`MyFirstWCFClient`网站中添加服务的`.svc`文件来添加 WCF 服务的引用。为此，在解决方案资源管理器中右键单击`MyFirstWCFClient`网站并选择添加服务引用选项。这将打开添加服务引用对话框。

在添加服务引用对话框的地址文本框中，输入您的 WCF 服务的 URL 并单击转到按钮。您可以在服务框中看到您的 WCF 服务，并在操作框中看到其方法列表。现在，将服务引用的名称从`ServiceReference1`更改为`MyWCFServiceReference`并单击确定按钮，如图 19.37 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1031_0.png)

图 19.37：显示添加服务引用对话框

# 生成代理代码

.NET Framework 3.5 和 4.0 服务器开发工具包（SDK）提供了一种通过`Svcutil.exe`文件构建客户端代理（从服务提供的元数据自动生成的代码）的方法。使用`Svcutil.exe`文件，您可以生成代表客户端代理代码的`.cs`文件和包含客户端配置详细信息的`.config`文件。让我们执行以下步骤来使用`Svcutil.exe`文件：

1. 打开 Visual Studio 2010 命令提示符并输入以下命令：

```
svcutil.exe /language:cs /out:MyWCFClient.cs /config:MyWCFClient.config http://localhost:6485/MyFirstWCFService/Service.svc
```

2. 按 ENTER 键。上述命令生成两个文件，`MyWCFClient.cs`和`MyWCFClient.config`，如图 19.38 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1032_0.png)

图 19.38：生成`MyWCFClient.cs`和`MyWCFClient.config`文件

3. 在解决方案资源管理器中右键单击`MyFirstWCFClient`网站，然后选择“添加现有项”选项，将这些文件添加到`MyFirstWCFClient`网站。

4. 在“添加现有项”对话框中选择`MyWCFClient.cs`和`MyWCFClient.config`文件，并单击“添加”按钮，如图 19.39 所示：

## 调用 WCF 服务的操作

创建并配置 WCF 客户端后，便可以调用 WCF 服务的操作。让我们执行以下步骤来调用 WCF 客户端的操作：

1. 创建`MyWCFServiceReference.ServiceClient`类的对象，并使用该对象调用`MyWCFService`服务的操作，如清单 19.12 所示：

### 清单 19.12：显示`Default.aspx.cs`文件的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Web;
using System.Web.UI;
using System.Web.UI.WebControls;
using System.ServiceModel;

public partial class _Default : System.Web.UI.Page
{
    MyWCFServiceReference.ServiceClient reference = new MyWCFServiceReference.ServiceClient();
    protected void btnsqr_Click(object sender, EventArgs e)
    {
        Label3.Visible = true;
        lbloutput.Visible = true;
        lbloutput.Text = reference.SquareRoot(Convert.ToDouble(txtfirst.Text)).ToString();
    }
    protected void btncube_Click(object sender, EventArgs e)
    {
        Label3.Visible = true;
        lbloutput.Visible = true;
        lbloutput.Text = reference.CubeRoot(Convert.ToDouble(txtfirst.Text)).ToString();
    }
}
```

## 使用 ASP.NET AJAX 调用 WCF 服务

如前所述，您可以使用 ASP.NET AJAX 调用 WCF 服务。具有 ASP.NET AJAX 功能的 ASP.NET WCF 服务称为启用了 ASP.NET AJAX 的 WCF 服务。要了解如何通过 ASP.NET AJAX 调用 WCF 服务，需要执行以下步骤：

1. 创建启用了 ASP.NET AJAX 的 WCF 服务
2. 从客户端脚本调用 WCF 服务

让我们逐一执行这些步骤。

## 创建启用了 ASP.NET AJAX 的 WCF 服务

.NET Framework 允许您创建启用了 ASP.NET AJAX 的 WCF 服务。执行以下步骤来创建启用了 ASP.NET AJAX 的 WCF 服务：

1. 创建一个名为`MyAjaxEnableWCFService`的网站（也可在 CD-ROM 上使用）。

2. 选择“AJAX-enabled WCF Service”模板，并在“Name”文本框中输入服务名称。在本例中，我们输入了`OperationService.svc`。

3. 单击“添加”按钮将该服务添加到网站中，如图 19.43 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1035_0.png)

图 19.43：添加启用了 ASP.NET AJAX 的 WCF 服务

`OperationService.cs`和`OperationService.svc`两个文件会自动添加到`MyAjaxEnableWCFService`网站。

4. 从`MyAjaxEnableWCFService`网站打开`OperationService.cs`文件，并用清单 19.13 中给出的代码替换现有代码：

### 清单 19.13：显示`OperationService.cs`文件的代码

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Runtime.Serialization;
using System.ServiceModel;
using System.ServiceModel.Activation;
using System.ServiceModel.Web;
using System.Text;

[ServiceContract(Namespace = "http://tempuri.org/")]
[AspNetCompatibilityRequirements(RequirementsMode =
AspNetCompatibilityRequirementsMode.Allowed)]
public class OperationService
{
[OperationContract]
public double Add(double Number1, double Number2)
{
    return Number1 + Number2;
}

[OperationContract]
public double Subtract(double Number1, double Number2)
{
    return Number1 - Number2;
}

[OperationContract]
public double Multiply(double Number1, double Number2)
{
    return Number1 * Number2;
}

[OperationContract]
public double Divide(double Number1, double Number2)
{
    return Number1 / Number2;
}
```

在清单 19.13 中，定义并实现了`ServiceContractAttribute`特性及其操作。您可以发布 WCF 服务的元数据，以允许客户端查看服务的详细信息。默认情况下，WCF 服务的元数据发布是禁用的。您可以通过在`web.config`文件中添加一些代码（清单 19.14）来启用它。

5. 打开`web.config`文件，并添加清单 19.14 中突出显示的代码以启用元数据发布：

### 清单 19.14：显示启用元数据发布的代码

```
<?xml version="1.0"?>
<!--
For more information on how to configure your ASP.NET application, please visit
http://go.microsoft.com/fwlink/?LinkId=169433

    <add name="ApplicationServices" connectionString="data source=.\SQLEXPRESS;Integrated Security=SSPI;AttachDBFilename=|DataDirectory|\aspnetdb.mdf;User Instance=true" providerName="System.Data.SqlClient" />
  </connectionStrings>
  <system.web>
    <compilation debug="true" targetFramework="4.0"/>
    <authentication mode="Forms">
      <forms loginUrl="~/Account/Login.aspx" timeout="2880"/>
    </authentication>
    <membership>
      <providers>
        <clear/>
```
